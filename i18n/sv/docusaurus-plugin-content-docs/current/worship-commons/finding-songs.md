# Hitta låtar på WorshipCommons

<div class="article-intro">

Sidan **Upptäck** är WorshipCommons låtbibliotek. Sök efter en låt du redan känner till, eller begränsa listan med filter för att hitta något nytt till söndagen. Du behöver inte logga in för att söka efter eller spela upp låtar.

</div>

## Söka i biblioteket

1. Gå till [worshipcommons.org](https://worshipcommons.org) och klicka på **Upptäck** (eller **Bläddra bland låtar**) högst upp på sidan.
2. Skriv i sökrutan. Du kan söka på titel, första rad, melodinamn, tema, bibelställe eller låtskrivare. Resultaten uppdateras medan du skriver.
3. Använd menyn **Sortera efter** för att ordna resultaten efter **Flest nedladdningar**, **Flest sparade**, **Nyast** eller **Titel A–Ö**.
4. Klicka på en låttitel för att öppna dess [låtsida](./song-page.md).

:::tip
Tryck på tangenten `/` var som helst på sidan Upptäck för att hoppa till sökrutan.
:::

Varje rad visar låtens låtskrivare, år, bibelställe (om den har ett), antal nedladdningar och sparningar, upp till tre teman, tonart och tempo i BPM. Klicka på uppspelningsknappen i början av en rad för att höra en demoinspelning eller en pianoförhandsvisning utan att lämna listan.

## Filtrera låtar

Klicka på **Filter** för att öppna eller stänga filterpanelen (den är öppen från början på större skärmar). Inom en grupp kan du välja fler än ett värde; mellan grupper måste en låt matcha alla filter du har angett. Siffran bredvid varje alternativ visar hur många låtar som matchar.

- **Tema** -- Ämnen som Lovsång, Nåd, Hopp eller Jul. Klicka på **Visa fler** för hela listan.
- **Säkerhet** -- Hur kompletta låtens material är: **Söndagsklar**, **Partitur**, **Ej granskat partitur**, **Endast ackord** eller **Endast text**.
- **Redo att använda** -- **Fungerar med bara en gitarr**, **Har ackompanjemang**, **Har ackord**, **Har partitur** och **Har stämmor**.
- **Tonart** och **Taktart** -- Välj en viss tonart eller psalmtaktart.
- **Tempo** -- **Långsamt** (under 73 BPM), **Måttligt** (73–100) eller **Livligt** (över 100).
- **Språk** -- Låtar på ett visst språk.
- **Källa** -- Låtens licens, till exempel **Public domain**, **Fri för gudstjänst** eller en Creative Commons-licens. Licenser märkta med ⚠ är icke-kommersiella.
- **Extra** -- **Har demoinspelning**.

Aktiva filter visas som brickor ovanför resultaten. Klicka på brickans **X** för att ta bort den, eller klicka på **Rensa alla filter** för att börja om.

:::info
Filtret **Språk** startar på det språk du har valt för webbplatsen, så att du ser låtar på ditt språk först. För att se låtar på alla språk, ta bort språkbrickan ovanför resultaten. För att ändra webbplatsens språk, använd klotväljaren längst ned på valfri sida.
:::

## När en låt inte finns där

Om inget matchar, ta bort ett filter eller rensa din sökning. WorshipCommons innehåller bara låtar som är i public domain eller som upphovspersonerna valt att dela, så de flesta upphovsrättsskyddade låtar finns inte här. När en sökning ger tomt resultat, klicka på **Sök i SongSelect →** för att leta efter låten i CCLI-katalogen i stället.

## Andra sätt att bläddra

Länkarna längst ned på varje sida leder till färdiga listor:

- **Nya låtar** -- Alla låtar som lagts till i biblioteket, nyast först.
- **Psalmer i public domain** -- Psalmer som är fria att använda på alla sätt.
- **Ingen CCLI behövs** -- Låtar som din församling kan använda utan att rapportera till CCLI.
- **Julsånger** -- En säsongsbetonad samling.

Klicka på **Lyssna** i den övre menyn för att höra nyligen delade låtar från låtskrivare, i slumpvis ordning, en efter en. Medan en låt spelas kan du klicka på **+ Spara låt** för att lägga till den bland dina sparade låtar (du uppmanas att logga in).
