# Gruppen zuweisen

<div class="article-intro">

Wenn Sie auf dem Bildschirm zur Haushaltsprüfung auf eine Gottesdienstzeit-Schaltfläche tippen, öffnet die App den Bildschirm zur Gruppenauswahl. Hier wählen Sie aus, welche Gruppe oder Klasse ein Familienmitglied zu dieser bestimmten Gottesdienstzeit besuchen soll.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- [Prüfen Sie Ihren Haushalt](./household-review.md) auf dem Bildschirm zur Haushaltsprüfung
- Klappen Sie das Mitglied auf, das Sie zuweisen möchten, und tippen Sie auf eine Gottesdienstzeit-Schaltfläche
- Stellen Sie sicher, dass Ihr Gemeindeadministrator [Gruppen erstellt](../../b1-admin/groups/creating-groups.md) und sie in B1 Admin mit Gottesdienstzeiten verknüpft hat

</div>

## So sind Gruppen organisiert

Gruppen werden in **Kategorien** angezeigt. Jede Kategorie erscheint als Karte mit:

- dem **Kategorienamen** (zum Beispiel „Kinder“, „Jugend“, „Erwachsene“)
- der **Anzahl der Gruppen** in dieser Kategorie

Tippen Sie auf eine Kategoriekarte, um sie aufzuklappen und die einzelnen Gruppen darin zu sehen. Tippen Sie erneut, um sie wieder einzuklappen.

## Eine Gruppe auswählen

1. Tippen Sie auf eine **Kategorie**, um sie aufzuklappen.
2. Prüfen Sie die Liste der Gruppen in dieser Kategorie. Jede Gruppe zeigt ihren Namen mit einem Auswahlsymbol rechts.
3. Tippen Sie auf den **Gruppennamen**, den Sie zuweisen möchten.

Die App speichert Ihre Auswahl und bringt Sie zurück zum [Bildschirm zur Haushaltsprüfung](./household-review.md). Die Gottesdienstzeit-Schaltfläche für dieses Mitglied zeigt nun den Namen der ausgewählten Gruppe an.

## Hinweise zu Alter und Klassenstufe

Wenn Ihre Gemeinde für ihre Räume Alters- oder Klassenstufenbereiche festgelegt hat, führt Sie die Liste zum richtigen Raum: Räume, für die die Person infrage kommt, sind **hervorgehoben**, und Räume außerhalb ihres Alters oder ihrer Klassenstufe sind **abgeblendet**. Ein abgeblendeter Raum kann trotzdem ausgewählt werden, allerdings muss ein Mitarbeiter die Auswahl bestätigen. Alter und Klassenstufe werden anhand des Stichtags für die Klassenstufenversetzung Ihrer Gemeinde berechnet, sodass die Räume auch beim Schuljahreswechsel korrekt bleiben.

## „Keine“ wählen

Wenn Sie entscheiden, dass ein Familienmitglied zu dieser Gottesdienstzeit keiner Gruppe zugewiesen werden soll, tippen Sie unten auf dem Bildschirm auf die Schaltfläche **Keine**. Dadurch wird eine bestehende Gruppenzuweisung für diese Gottesdienstzeit entfernt, und Sie kehren zum Bildschirm zur Haushaltsprüfung zurück.

:::tip
Verwenden Sie die Option **Keine** für Erwachsene, die am Hauptgottesdienst teilnehmen und nicht in eine bestimmte Gruppe oder Klasse einchecken müssen.
:::

## Eine Gruppenzuweisung ändern

So ändern Sie eine bereits erfolgte Gruppenzuweisung:

1. Kehren Sie zum [Bildschirm zur Haushaltsprüfung](./household-review.md) zurück.
2. Klappen Sie das Mitglied auf, dessen Gruppe Sie ändern möchten.
3. Tippen Sie auf die Gottesdienstzeit-Schaltfläche (die nun den aktuell zugewiesenen Gruppennamen anzeigt).
4. Wählen Sie eine andere Gruppe oder tippen Sie auf **Keine**.

:::info
Gruppen und Kategorien werden von Ihrem Gemeindeadministrator in B1 Admin konfiguriert. Wenn eine Gruppe fehlt oder in der falschen Kategorie steht, bitten Sie Ihren Administrator, die [Gruppeneinstellungen](../../b1-admin/groups/creating-groups.md) zu aktualisieren.
:::

## Nächste Schritte

Kehren Sie nach dem Zuweisen von Gruppen zum [Bildschirm zur Haushaltsprüfung](./household-review.md) zurück, um:

- weiteren Familienmitgliedern Gruppen zuzuweisen
- [einen Gast hinzuzufügen](./adding-guests.md), wenn jemand mit Ihrer Familie zu Besuch ist
- [den Check-in abzuschließen](./completing-checkin.md), wenn alle Zuweisungen bereit sind
