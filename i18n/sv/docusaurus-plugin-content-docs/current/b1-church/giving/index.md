# Gåvor

<div class="article-intro">

B1App gör det enkelt att stödja din församling genom onlinedonationer. Oavsett om du vill göra en snabb enskild gåva eller hantera återkommande givande finns allt du behöver på din kyrkas B1.church-webbplats.

</div>

## Översikt

B1App stödjer två sätt att ge:

- **Offentliga donationer** -- Vem som helst kan göra en donation utan att logga in. Besök din församlings donationssida, välj en fond och ange dina betalningsuppgifter. Inget konto krävs.
- **Inloggad givande** -- När du [loggar in](../getting-started/logging-in.md) innan du donerar kopplas dina gåvor till ditt konto. Då får du tillgång till hela din donationshistorik, utskrivbara givandeintyg, hantering av återkommande donationer och sparade betalningsmetoder.

## Vad du kan göra

Här är vad som finns i avsnittet om givande:

- **Ge till specifika fonder** -- Din församling kan ha flera fonder, till exempel en allmän fond, en byggfond eller en missionsfond. Du kan välja vilken fond din donation ska gå till.
- **Betala med kort eller bankkonto** -- Donationer behandlas säkert via Stripe. Du kan betala med kredit- eller betalkort. Instruktioner för ACH-banköverföring finns också tillgängliga.
- **Ställ in återkommande donationer** -- Inloggade medlemmar kan schemalägga automatiska återkommande donationer så att du aldrig missar en gåva.
- **Visa donationshistorik** -- Se en fullständig lista över dina tidigare donationer, inklusive datum, metod, fond och belopp.
- **Skriv ut givandeintyg** -- Skapa utskrivbara givandeintyg för innevarande år eller föregående år för dina skatteunderlag.
- **Hantera betalningsmetoder** -- Spara och hantera dina betalningsmetoder för snabbare givande i framtiden.

Din församling kan begränsa vilka år av givandehistorik medlemmarna ser, eller dölja den helt, och kan lägga till en givandenotis som visas på din sida för givande och på intygen. Se [Donationshistorik](./donation-history.md#if-your-church-limits-giving-history).

:::info
Donationer behandlas säkert via **Stripe**. Dina betalningsuppgifter lagras aldrig på B1.church-servrar.
:::
