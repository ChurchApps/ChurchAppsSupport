# Tjänstgöring

<div class="article-intro">

Avsnittet Tjänstgöring på B1.church låter dig bläddra bland volontärsuppdrag och anmäla dig till positioner i din församling. Utöver att se dina tilldelade planer och tjänsteordningar kan du nu själv välja positioner som behöver bemannas.

</div>

## Vad du kan göra

- **Bläddra bland volontärsuppdrag** -- Se kommande tjänstplaner med lediga positioner som behöver volontärer.
- **Anmäl dig till positioner** -- Välj en position och anmäl dig själv med ett klick.
- **Visa dina planer** -- Se dina kommande och tidigare [tjänstgöringsuppdrag](../plans/viewing-plans.md).
- **Svara på uppdrag** -- Acceptera eller avböj positioner du har blivit schemalagd för, från sidan Planer eller avsnittet **Du tjänstgör** på startsidan. Om dina planer ändras efter att du har accepterat kan du [avböja ett accepterat uppdrag](../plans/viewing-plans.md#declining-an-accepted-assignment) fram till dess att tjänsten är över.
- **Ta bort anmälningar** -- Avboka en självanmälan om dina planer ändras (före sista anmälningsdag).

## Så fungerar det

Din församlingsadministratör skapar tjänstplaner och markerar vissa positioner som tillgängliga för självanmälan. Dessa positioner visas på sidan för volontäranmälan, ordnade efter kategori (till exempel "Band", "Gästvänlighet" eller "Barnverksamhet"). Du ser hur många platser som är lediga för varje position och kan anmäla dig till de du är tillgänglig för.

:::info
Endast positioner som din församlingsadministratör har aktiverat för självanmälan visas på volontärsidan. Vissa positioner kan endast bemannas genom direkt tilldelning.
:::
