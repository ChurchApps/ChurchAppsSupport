# Blogg

<div class="article-intro">

Bloggsidan delar nyheter, uppdateringar och andakter från din församling. Inläggen är ordnade efter kategori och tagg, så att du enkelt kan bläddra bland de ämnen som intresserar dig mest.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- Du behöver inte logga in för att läsa blogginlägg. Bloggsidan är offentligt tillgänglig.
- Din församling måste ha publicerat minst ett inlägg för att bloggsidan ska visas.

</div>

## Bläddra bland inlägg

1. Gå till sidan **Blogg** från din församlings webbplatsnavigering.
2. Inläggen visas med de senaste först, 10 per sida. Använd länkarna **Äldre**/**Nyare** längst ned för att bläddra i arkivet.
3. Klicka på ett inlägg för att läsa det i sin helhet.

## Filtrera efter kategori eller tagg

Klicka på en **kategori** eller **tagg** på något inlägg, eller i bloggistan, för att filtrera listan till inlägg som matchar. Det gör det enkelt att ta igen det du missat i ett visst ämne eller en viss serie.

## Relaterade inlägg

I slutet av varje inlägg hittar du avsnittet **Relaterade inlägg**, som föreslår andra inlägg från samma kategori.

## Prenumerera via RSS

Varje församlingsblogg publicerar ett RSS-flöde som flödesläsare och automatiseringsverktyg kan prenumerera på. Då får du automatiskt besked när ett nytt inlägg publiceras, i stället för att själv kontrollera sidan.

## Tillgänglighet

Bloggsidan är tillgänglig när din församling har publicerat minst ett inlägg. Om du inte ser någon länk till **Blogg** i din församlings navigering kan det vara så att din församling ännu inte har konfigurerat detta. Kontakta din församlingsadministratör för mer information.
