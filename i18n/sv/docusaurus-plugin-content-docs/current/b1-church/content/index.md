# Innehåll

<div class="article-intro">

B1.church ger din församling en central plats där den kan ta del av det innehåll som kyrkan delar. Beroende på vad din kyrka har konfigurerat kan du ha tillgång till predikningar, livesändningar, bibelläsning, dagens vers och lektionsmaterial -- allt från medlemsportalen.

</div>

## Tillgängliga innehållsfunktioner

### Predikningar

Bläddra bland och se inspelade predikningar från din kyrka. Kyrkans predikningsbibliotek är organiserat i spellistor och serier, vilket gör det enkelt att hitta tidigare budskap.

### Livesändning

Se kyrkans direktsändning direkt i B1.church. När en gudstjänst sänds live kan du ansluta till strömmen och interagera med andra tittare via chatten.

### Bibeln

Läs Skrift med hjälp av den inbyggda bibelläsaren. Du kan navigera bland böcker, kapitel och verser utan att lämna webbplatsen.

### Dagens vers

Visa en vackert formaterad bibelvers som ändras varje dag. Bilden anpassar sig automatiskt efter skärmen. Du kan också dela eller ladda ner dagens vers och bläddra bland verser från tidigare dagar.

### Lektioner

Visa schemalagda lektioner från din kyrkas planer. Om du är lärare eller ledare kan du använda **Lärarvyn** för att se lektioner i helskärm i ett lättnavigerat format som är perfekt för undervisning eller presentation.

### Lektioner (Utfasad - inbäddad flik)

Den inbäddade fliken **Lektioner** har utfasats. Uppspelning av läroplaner finns nu i **[FreePlay](/docs/freeplay/)**, ChurchApps kostnadsfria TV-app för klassrumsskärmar. För att bläddra bland läroplaner på mobil, surfplatta eller dator, logga in direkt på [Lessons.church](https://lessons.church). Se [referenssidan för Lektioner](./lessons.md) för mer information.

## Hitta innehåll

Innehållssidorna finns tillgängliga via din kyrkas webbplatsnavigering. Din kyrkoadministratör bestämmer vilka innehållsfunktioner som är aktiverade och hur de visas i menyn. Om du inte ser en viss innehållsfunktion som listas ovan kan den vara ej konfigurerad för din kyrka.

:::info
[Predikningar](./sermons.md) och [Bibeln](./bible.md) är tillgängliga offentligt. Andra funktioner kan kräva att du är [inloggad](../getting-started/logging-in.md).
:::
