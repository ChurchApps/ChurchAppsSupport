# Svar på evenemang

<div class="article-intro">

Gruppevenemang kan samla in svar så att ledarna vet vem som kommer. På gruppens sida och i kalendern har varje kommande evenemang knapparna **Kommer**, **Kanske** och **Kan inte komma**. Svara med ett tryck, ändra dig när du vill och se direkt hur många andra som kommer.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- Du måste vara [inloggad](../getting-started/logging-in.md) och medlem i gruppen
- Evenemanget måste tillåta svar (det är aktiverat som standard, men ledare kan stänga av det för varje evenemang)

</div>

## Svara på ett evenemang

1. Öppna din grupp i medlemsportalen. Gruppens nästa evenemang visas i avsnittet **Nästa händelse**. För andra evenemang trycker du på **Alla händelser**: i kalendervyn trycker du på en dag för att se dess evenemang, eller byter till **Lista** för att se alla kommande evenemang för den här månaden på en gång.
2. Varje kommande evenemang visar tre knappar: **Kommer**, **Kanske** och **Kan inte komma**.
3. Tryck på ditt svar. Ditt val markeras, och varje knapp visar ett löpande antal personer som har gett det svaret.
4. Tryck på ditt markerade svar igen för att ta bort det, eller tryck på en annan knapp för att ändra svaret.

Ditt svar gäller just det specifika tillfället. För ett veckomöte svarar du separat för varje veckas evenemang.

## För gruppledare

- **Visa svar** -- Ledare ser en länk **Visa svar** på varje evenemang i gruppens kalender (**Alla händelser**). Den öppnar bladet **Svar** som listar alla efter svar: Kommer, Kanske och Kan inte komma. Om ingen har svarat ännu visas ”Inga svar än.”
- **Slå på eller av svar** -- När du skapar eller redigerar ett evenemang använder du reglaget **Tillåt svar**. Evenemang där svar är avstängda visar inga svarsknappar. Personal som skapar evenemang i bulk från B1 Admin har samma inställning. Se [Gruppkalender](../../b1-admin/groups/group-calendar#event-rsvps).

:::tip
Svar är en enkel deltagarräkning. Om ditt evenemang behöver anmälningsuppgifter, kapacitetshantering eller betalning, använd i stället [evenemangsanmälan](../events/registering).
:::
