# Gemenskap

<div class="article-intro">

Avsnittet **Gemenskap** i B1.church hjälper dig att hålla kontakten med din församlingsfamilj. Här finns medlemskatalogen, där du kan hitta och lära känna andra medlemmar i församlingen.

</div>

## Vad du hittar här

- **[Medlemskatalog](./member-directory.md)** -- Bläddra i och sök i din församlings medlemskatalog. Slå upp personer med namn eller filtrera efter grupp för att hitta den du letar efter. Klicka på en medlem för att visa dess profiluppgifter.
- **[Tidslinje](./timeline.md)** -- Det gamla, samlade aktivitetsflödet, som nu har tagits bort. Den här sidan förklarar var varje typ av uppdatering finns i dag.

## Komma igång

Du måste vara [inloggad](../getting-started/logging-in.md) för att använda gemenskapsfunktionerna. Om du inte är inloggad visas en inloggningsuppmaning i fliken **Gemenskap** i stället för katalogen.

Medlemsportalen öppnas på [startsidans instrumentpanel](../getting-started/navigating.md). Fliken **Gemenskap** ger åtkomst till medlemskatalogen.

:::info
Vilka medlemmar och uppgifter du kan se i katalogen beror på din församlings integritetsinställningar. Du kanske inte kan se varje medlems fullständiga profil. Om du har frågor om vad som delas, kontakta din församlingsadministratör.
:::

:::tip
Använd gemenskapsfunktionerna tillsammans med [Grupper](../groups/) för att hålla dig engagerad i din församling under hela veckan.
:::
