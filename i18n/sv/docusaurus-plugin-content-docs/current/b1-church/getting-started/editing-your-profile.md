# Redigera din profil

<div class="article-intro">

Din profilsida i medlemsportalen låter dig uppdatera dina kontaktuppgifter, hantera ditt hushåll, ändra e-postadressen och lösenordet för ditt konto samt bestämma vem som kan se din adress, ditt telefonnummer och din e-postadress.

## Öppna din profil

Tryck på din profilbild i den övre appraden, eller tryck på **Redigera profil** överst på sidan **Mer** eller på din [Mig-sida](./me-page.md), för att öppna **Din profil** på `/mobile/profileEdit`. Sidan består av en samlad vy med avsnitten **Foto och namn**, **Kontakt**, **Hushåll**, **Konto** och **Integritet**. Varje avsnitt visar dina nuvarande uppgifter med en länk **Redigera** (eller **Lägg till familjemedlem** / **Ändra**) som öppnar en panel där du gör ändringarna.

## Foto och namn samt kontakt

Dessa avsnitt innehåller de uppgifter som din församling ser på din personpost:

- **Foto och namn** — tryck på **Byt foto** för att ladda upp en ny bild, och redigera ditt förnamn, mellannamn och efternamn.
- **Kontakt** — e-post, mobiltelefon, hemtelefon, arbetstelefon, födelsedatum och din adress (gata, ort, län och postnummer). Om du aktiverar textpåminnelser i [Aviseringsinställningar](./notification-preferences.md) skickas de till ditt mobilnummer.

Gör dina ändringar i panelen och tryck på **Spara ändringar**.

:::info
Om din församling kräver godkännande för ändringar i katalogen står det “Ändringar av din profil skickas till församlingens personal för godkännande.” och knappen heter **Skicka för godkännande**. Dina ändringar skickas då som en begäran i stället för att tillämpas direkt. Se [Godkänna profiländringar](/docs/b1-admin/profile/approving-profile-changes) för hur din församling granskar dessa.
:::

## Hushåll

Avsnittet Hushåll visar de andra personer som är kopplade till ditt hushåll, var och en med sin hushållsroll (Huvudperson, Make/maka, Barn och så vidare). Tryck på en hushållsmedlem för att se hens uppgifter.

Om du vill lägga till en familjemedlem som ännu inte finns i systemet trycker du på **Lägg till familjemedlem**, anger förnamnet och trycker på **Lägg till**. Nya familjemedlemmar läggs i en väntelista och skickas tillsammans med dina övriga profiländringar för församlingen att granska.

## Konto

Avsnittet Konto hanterar din inloggning snarare än din församlingsprofil. Tryck på **Redigera** för att öppna det:

- **Visningsnamn** — förnamnet och efternamnet som visas för din inloggning (skiljer sig från namnet i din församlingsprofil).
- **Ändra e-post** — uppdatera den e-postadress du använder för att logga in.
- **Ändra lösenord** — ange ditt nuvarande lösenord och sedan ditt nya lösenord två gånger. Det nya lösenordet måste vara minst 8 tecken.

Varje del har sin egen knapp **Spara**.

## Integritet

Avsnittet Integritet visar vem som kan se dina kontaktuppgifter inom ChurchApps. Tryck på **Ändra** för att öppna **Synlighetsinställningar**:

- **Dölj mig från medlemskatalogen** — en omkopplare som tar bort dig helt från [medlemskatalogen](../community/member-directory.md).
- **Adressynlighet**, **Telefonsynlighet** och **E-postsynlighet** — var och en har en egen rullgardinsmeny, så att du till exempel kan dela din e-post med hela församlingen men hålla din adress mer privat. Alternativen är:

| Nivå | Vem kan se det |
|---|---|
| **Alla** | Synligt för alla som kan se katalogen. |
| **Endast medlemmar** | Synligt för andra inloggade medlemmar i församlingen. |
| **Endast mina grupper** | Synligt endast för medlemmar i grupper som du tillhör. |
| **Endast mina gruppledare och personal** | Synligt endast för församlingens personal och ledarna i de grupper du tillhör. |
| **Endast personal** | Synligt endast för församlingens personal (personer med statusen Personal som medlemskap eller behörigheten Visa personer). |

Tryck på **Spara** för att tillämpa dina val. Din församling anger en standardinställning för vart och ett av dessa tre fält. Se [Inställningar för mobilappen](/docs/b1-admin/settings/mobile-app). Det du väljer här har dock företräde framför standardinställningen för din egen post.

:::tip
Du ser alltid din egen information oavsett dessa inställningar, och personal med behörighet att visa personer kan alltid se den också.
:::
