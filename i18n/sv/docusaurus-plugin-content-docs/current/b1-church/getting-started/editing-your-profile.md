# Redigera din profil

<div class="article-intro">

Din profilsida i medlemsportalen låter dig uppdatera dina kontaktuppgifter, hantera ditt hushåll, ändra e-postadressen och lösenordet för ditt konto samt styra vem som kan se din adress, ditt telefonnummer och din e-postadress.

## Öppna din profil

Tryck på din profilbild i det övre appfältet, eller tryck på **Redigera profil** överst på sidan **Mer** eller på din [Min sida](./me-page.md), för att öppna **Din profil** på `/mobile/profileEdit`. Sidan består av ett enda blad med avsnitten **Foto och namn**, **Kontakt**, **Hushåll**, **Konto** och **Integritet**. Varje avsnitt visar dina aktuella uppgifter med en länk **Redigera** (eller **Lägg till familjemedlem** / **Ändra**) som öppnar en panel där du gör ändringarna.

## Foto och namn samt Kontakt

Dessa avsnitt innehåller de uppgifter som din församling ser på din personpost:

- **Foto och namn** — tryck på **Byt foto** för att ladda upp en ny bild, och redigera din **Titel** samt för- och efternamn samt mellannamn. För **Titel** kan du välja ett förslag (Mr, Mrs, Miss, Ms, Dr, Prof, Rev eller Pastor) eller skriva in en egen, upp till 10 tecken.
- **Kontakt** — e-post, mobiltelefon, hemtelefon, arbetstelefon, födelsedatum och din adress (gata, ort, län och postnummer). Om du aktiverar sms-påminnelser i [Aviseringsinställningar](./notification-preferences.md) skickas de till ditt mobilnummer.

Gör dina ändringar i panelen och tryck på **Spara ändringar**.

:::info
Om din församling kräver godkännande för ändringar i katalogen visar sidan texten "Ändringar i din profil skickas till församlingens personal för godkännande." och knappen heter **Skicka för godkännande**. Dina ändringar skickas då som en begäran i stället för att tillämpas direkt. Se [Godkänna profiländringar](/docs/b1-admin/profile/approving-profile-changes) för hur din församling granskar dessa.
:::

## Hushåll

Avsnittet Hushåll visar de andra personer som är kopplade till ditt hushåll, var och en med sin hushållsroll (Huvudperson, Make/maka, Barn och så vidare). Tryck på en hushållsmedlem för att se deras uppgifter.

Så här lägger du till en familjemedlem som ännu inte finns i systemet:

1. Tryck på **Lägg till familjemedlem**.
2. Ange deras **Förnamn**. **Efternamn** är ifyllt med ditt efternamn från början; ändra det om deras är ett annat.
3. Lägg eventuellt till deras **Titel** och **Mobiltelefon**.
4. Välj deras **Hushållsroll**: **Huvudperson**, **Make/maka**, **Barn** eller **Annan** (standardvärdet).
5. Tryck på **Lägg till**. De visas under **Väntande familjemedlemmar** med sin roll. Tryck på **Ta bort** för att ta bort någon från listan. Upprepa för alla andra.
6. Tryck på **Spara ändringar** (eller **Skicka för godkännande**).

Om din församling granskar ändringar i katalogen skickas de nya familjemedlemmarna tillsammans med dina övriga ändringar för godkännande av församlingen. Annars läggs de till i ditt hushåll så snart du sparar.

## Konto

Avsnittet Konto hanterar din inloggning snarare än din församlingsprofil. Tryck på **Redigera** för att öppna det:

- **Visningsnamn** — det för- och efternamn som visas vid din inloggning (skilt från namnet på din församlingsprofil).
- **Byt e-post** — uppdatera e-postadressen du använder för att logga in.
- **Byt lösenord** — ange ditt nuvarande lösenord och sedan ditt nya lösenord två gånger. Ditt nya lösenord måste vara minst 8 tecken långt.

Varje del har sin egen knapp **Spara**.

## Integritet

Avsnittet Integritet visar vem som kan se dina kontaktuppgifter inom ChurchApps. Tryck på **Ändra** för att öppna **Synlighetsinställningar**:

- **Dölj mig från medlemskatalogen** — en omkopplare som tar bort dig helt från [medlemskatalogen](../community/member-directory.md).
- **Synlighet för adress**, **Synlighet för telefon** och **Synlighet för e-post** — var och en har sin egen rullgardinsmeny, så du kan till exempel dela din e-post med hela församlingen men hålla din adress mer privat. Alternativen är:

| Nivå | Vem som kan se det |
|---|---|
| **Alla** | Synligt för alla som kan se katalogen. |
| **Endast medlemmar** | Synligt för andra inloggade medlemmar i församlingen. |
| **Endast mina grupper** | Synligt endast för medlemmar i grupper du tillhör. |
| **Endast mina gruppledare och personal** | Synligt endast för församlingens personal och ledarna i grupper du tillhör. |
| **Endast personal** | Synligt endast för församlingens personal (personer med medlemsstatus Personal eller behörigheten att visa personer). |

Tryck på **Spara** för att tillämpa dina val. Din församling anger ett standardvärde för vart och ett av dessa tre fält — se [Inställningar för mobilappen](/docs/b1-admin/settings/mobile-app) — men det du väljer här åsidosätter standardvärdet för din egen post.

:::tip
Du ser alltid dina egna uppgifter oavsett dessa inställningar, och personal med behörighet att visa personer kan alltid se dem också.
:::
