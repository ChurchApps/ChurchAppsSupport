# Tjänster

<div class="article-intro">

Avsnittet Tjänster är din startpunkt för att samordna volontärer och planera kyrkans gudstjänster. Oavsett om du organiserar söndagsgudstjänster, midveckosamlingar eller särskilda evenemang är det här du samlar allt så att dina team vet exakt vem som tjänar och när.

</div>

## Så fungerar sidan Tjänster

När du öppnar sidan **Tjänster** ser du dina ministerier som flikar överst. Varje ministerium har egna plantyper och team, så att du kan hantera flera ministerier oberoende av varandra. Du kan till exempel ha separata flikar för Lovsång, Barnverksamhet och Värdskap.

Personal utan adminbehörighet som är medlemmar i ett ministerium kan också komma åt sidan Tjänster. De ser endast de ministerier de tillhör och kan skapa och redigera planer, uppdrag, plantyper och gudstjänstordningen för sitt ministerium utan att ha fullständiga adminbehörigheter.

:::tip
Om du är admin visar flikarna de ministerier du tillhör (**Mina**). Välj **Alla** för att se samtliga ministerier. Det är praktiskt när du behöver kontrollera uppdrag över flera team. Om din kyrka har många ministerier visas en rutan **Hitta ett ministerium** så att du kan filtrera flikarna efter namn.
:::

## Underavsnitt

Avsnittet Tjänster innehåller dessa huvudområden:

- **[Planer](./plans.md)** -- Skapa tjänsteplaner för specifika datum och tilldela volontärer till team. Planer hjälper dig att organisera vem som tjänar när, så att alla känner till sin roll i förväg. Ställ in automatiska [påminnelser till volontärer](./plans.md#volunteer-reminders) via push, e-post eller sms så att ditt team får besked innan varje gudstjänst, och använd **[Planöversikten](./plans-overview.md)** för att se alla kommande uppdrag över flera veckor i ett rutnät.
- **[Låtar](./songs.md)** -- Hantera ditt bibliotek med lovsångslåtar, inklusive texter, arrangemang och externa länkar. Ditt lovsångsteam kan använda detta för att förbereda kommande gudstjänster.
- **[Uppgifter](./tasks.md)** -- Tilldela och följ upp uppgifter för dina teammedlemmar från **Mitt arbete**.
- **[Arbetsflöden](./workflows.md)** -- Flytta personer genom en serie steg på en visuell Kanban-tavla, till exempel uppföljning av nya besökare eller en medlemsprocess. Steg kan köra automatiska åtgärder (skicka e-post, vänta några dagar, lägga till i en grupp), och kort går vidare via utfallsknappar, villkorsstyrd routing eller händelse- och schemautlösare -- med inbyggda rapporter.

## Komma igång

1. I B1 Admin öppnar du [Hoppmenyn](../introduction.md#getting-around-with-the-jump-menu) (sökfältet överst till vänster), expanderar **Tjänster** och klickar på **Planer**.
2. Klicka på **Lägg till ministerium** för att skapa ett nytt ministerium, eller välj **Alla** för att visa alla befintliga ministerier. Välj en **ministeriflik** för att se dess plantyper och tjänandeteam.
3. Klicka på **Skapa plantyp** (eller **Lägg till plantyp**) eller välj en befintlig plantyp för att börja [skapa tjänsteplaner](./plans.md), eller utforska underavsnitten [Låtar](./songs.md) och [Uppgifter](./tasks.md).

:::info
Innan du kan skapa planer behöver du skapa dina ministerier i området Tjänster och team inom varje ministerium.
:::
