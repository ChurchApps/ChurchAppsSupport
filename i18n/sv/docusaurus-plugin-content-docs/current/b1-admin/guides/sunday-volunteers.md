# Hantera söndagsvolontärer

<div class="article-intro">

Skapa dina volontärteam, planera veckovisa gudstjänster, tilldela positioner, bygg gudstjänstordningen med lovsångsmusik och tilldela söndagsuppgifter. När du är klar kan dina volontärer se sina uppdrag på B1-webbplatsen och i B1-appen, och kan acceptera eller tacka nej direkt.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- Ett B1 Admin-konto med administratörsbehörighet
- Volontärer [tillagda i din personregistret](../people/adding-people.md)

</div>

## Steg 1: Skapa volontärteam

Organisera dina volontärer i team så att du kan hantera uppdrag per verksamhetsområde.

Följ guiderna [Skapa grupper](../groups/creating-groups.md) och [Gruppmedlemmar](../groups/group-members.md) för att:

1. Skapa en kategori (t.ex. "Söndagsmorgonteam")
2. Skapa grupper som "Lovsångsteam", "Ljud och media", "Välkomstteam", "Barnverksamhetens volontärer"
3. Lägg till volontärer i varje grupp genom att söka efter deras namn och klicka på Lägg till

:::tip
Utse teamledare med stjärnikonen (**Gör till ledare**) i gruppens medlemslista (klicka på **Alla medlemmar** på gruppsidan). Ledare kan hantera sin grupps kalender och samordna sitt team.
:::

## Steg 2: Bygg ditt sånglager

Lägg till lovsånger så att du kan hämta dem till gudstjänstplaner varje vecka.

Följ guiden [Sånger](../serving/songs.md) för att:

1. Lägga till lovsånger med titlar, artister och längd
2. För varje sång, lägga till arrangemang med texter och tonartsangivelser
3. Lägga till externa länkar till YouTube-framföranden, ackordschema eller noter

:::info
Sånger som läggs till här kan senare hämtas till vilken gudstjänstplan som helst. Bygg ditt bibliotek en gång och använd det varje vecka.
:::

## Steg 3: Skapa en gudstjänstplan

Planer är de veckovisa uppdragen som visar volontärerna var de behövs.

Följ guiden [Planer](../serving/plans.md) för att:

1. Gå till Serving, välj din verksamhetsflik och öppna din plantyp
2. Klicka på **Ny plan** och välj gudstjänstdatum. För att ställa in flera söndagar samtidigt, kopiera från föregående plan och ange hur många i **Antal planer**
3. I planens avsnitt **Tilldelningar i serveringsteam**, lägg till positioner och tilldela volontärer till dem
4. Volontärer kommer att se sin uppdragsstatus (Begärd, Bekräftad, Väntande)
5. Aktivera [volontärpåminnelser](../serving/plans.md#volunteer-reminders) för plantypen så att volontärerna påminns via push, e-post eller sms innan varje gudstjänst

## Steg 4: Bygg gudstjänstordningen

Planera gudstjänstens förlopp från början till slut.

Följ guiden [Gudstjänstordning](../serving/service-order.md) för att:

1. Öppna din plan och hitta avsnittet **Gudstjänstordning** högst upp
2. Klicka på **Lägg till** för att lägga till moment: lovsånger (från ditt bibliotek), böner, skriftläsningar, meddelanden, predikan, offer och avslutning
3. Dra och släpp objekt för att ändra ordningen i gudstjänsten

:::info
Gudstjänstordningar är specifika för varje plan. Ändringar här påverkar inte andra planer eller det gemensamma sånglagret.
:::

## Steg 5: Tilldela söndagsuppgifter

Följ upp engångsuppgifter för söndagen så att ingenting faller mellan stolarna.

Följ guiden [Uppgifter](../serving/tasks.md) för att:

1. Skapa uppgifter för ansvarsområden som "Förbered nattvardselement", "Skriv ut programblad" eller "Ställ in ljudutrustning"
2. Tilldela varje uppgift till ansvarig person eller grupp
3. Uppgifter visas under **Serving > Mitt arbete**, på den tilldelades instrumentpanel och i mobilappen

:::info
B1 Admin skapar inte längre uppgifter enligt ett återkommande schema. För återkommande processer som för människor genom steg, använd [Arbetsflöden](../serving/workflows.md) med en schematrigger.
:::

## Steg 6: Aktivera självanmälan (valfritt)

Låt volontärer anmäla sig till positioner själva i stället för att vänta på administratörens tilldelning.

1. När du skapar eller redigerar en plan, ange en **Sista anmälningsdag** (timmar före gudstjänsten) för att styra när självanmälan stängs. Timmarna räknas bakåt från planens första gudstjänsttid. Lämna tomt för ingen sista dag. Nya planer börjar med föregående plans sista anmälningsdag.
2. Valfritt, aktivera **Visa volontärernas namn på anmälningssidan** så att volontärer kan se vilka andra som är anmälda.
3. För varje position, markera kryssrutan **Tillåt självanmälan** för att göra den tillgänglig för självbetjäning.
4. Lägg till en **Beskrivning** till varje position så att volontärerna vet vad rollen innebär.

När positionerna för självanmälan har skapats visas de automatiskt på volontärernas anmälningssidor på [B1.church](../../b1-church/serving/volunteer-signup.md) och i [B1 Mobile-appen](../../b1-church/serving/volunteer-signup.md). Medlemmar kan bläddra bland lediga positioner, se hur många platser som återstår och anmäla sig med ett enda klick.

:::tip
Blanda positioner som tilldelas av administratören och positioner för självanmälan i samma plan. Tilldela till exempel din lovsångsledare direkt, men låt välkomstteamet och kaffeservering välja själva.
:::

## Steg 7: Informera volontärerna

Tilldelade volontärer ser automatiskt sina planer och kan svara.

1. Volontärer ser sina planer på [B1.church](../../b1-church/plans/viewing-plans.md) och i [B1 Mobile-appen](../../b1-church/plans/viewing-plans.md)
2. De kan acceptera eller tacka nej till uppdrag direkt från någon av plattformarna
3. De kan ange spärrdatum för veckor då de inte är tillgängliga
4. Planer kan skrivas ut för genomgångar eller sättas upp bakom scenen
5. Volontärer kan bläddra bland och anmäla sig till lediga positioner via [anmälningssidan för volontärer](../../b1-church/serving/volunteer-signup.md)

:::tip
Pushnotiser i mobilappen informerar volontärer när de får nya uppdrag eller när planer ändras.
:::

## Du är klar!

Ditt system för volontärhantering är konfigurerat. Skapa en ny plan varje vecka, tilldela positioner, så ser ditt team allt i sin telefon eller dator.
