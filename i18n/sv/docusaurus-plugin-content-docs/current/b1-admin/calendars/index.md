# Kalendrar

<div class="article-intro">

Avsnittet Kalendrar i B1 Admin låter dig skapa utvalda kalendrar för din kyrka genom att samla händelser från dina grupper. Gruppledare hanterar sina egna gruppers händelser, och som administratör kan du skapa kalendrar som visar dessa händelser på din B1.church-webbplats för din församling att se.

</div>

## Visa dina kalendrar

1. Öppna [Hoppmenyn](../introduction.md#getting-around-with-the-jump-menu) i B1 Admin (sökfältet uppe till vänster), expandera **Calendars** och klicka på **Calendars**.
2. Sidan Calendars listar alla dina kalendrar i en tabell med namn och status. Använd rutan **Find a calendar** för att filtrera listan.
3. Varje rad har en länk **Manage Events** för att öppna kalendern och en länk **Edit** för att byta namn på eller ta bort den.

## Vad du kan göra

- **Lägg till en ny kalender** -- Klicka på **Add Calendar** överst på sidan för att skapa en kalender för ett specifikt ministerium, en viss typ av händelse eller ett visst syfte. Se [Skapa kalendrar](./creating-calendars.md) för steg-för-steg-instruktioner.
- **Redigera en kalender** -- Klicka på **Manage Events** för valfri kalender för att öppna den och hantera vilka grupper som ingår i den.
- **Publicera kalendrar** -- Kalendrar kan visas på din B1.church-webbplats så att besökare kan se kommande händelser i din kyrka.
- **Skapa utvalda kalendrar** -- Hämta händelser från flera grupper till en enda kalendervy för en heltäckande bild av allt som händer i din kyrka. Se [Utvald kalender](./curated-calendar.md) för detaljer.
- **Hantera rum och resurser** -- Håll reda på bokningsbara utrymmen och utrustning och hantera godkännandeförfrågningar. Se [Rum och resurser](./rooms-resources.md) för detaljer.
- **Visa tillgänglighet** -- Se alla rums- och resursbokningar i en enda kalender och boka utrymmen för kommande händelser. Se [Tillgänglighetskalender](./availability.md) för detaljer.

:::info
Kalendrar fungerar nära tillsammans med [Grupper](../groups/creating-groups.md). När grupper har schemalagda händelser kan dessa händelser hämtas in i dina kalendrar. Se sidan [Skapa kalendrar](./creating-calendars.md) för att lära dig hur du kopplar grupper till kalendrar.
:::
