# Gåvosammanfattning

<div class="article-intro">

Rapporten Gåvosammanfattning ger dig en tydlig bild av din kyrkas givande. Använd den för att följa upp totala gåvobelopp, bevaka givandetrender och ta fram ekonomiska rapporter till ditt ledarteam.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- Se till att gåvor [registreras konsekvent](../donations/recording-donations.md) i ditt system
- Du behöver rätt [behörigheter](../settings/roles-permissions.md) för att öppna ekonomiska rapporter

</div>

## Köra rapporten

1. Gå direkt till **admin.b1.church/reports/donationSummary** i din webbläsare. Rapporterna finns inte i navigeringsmenyn, så det enklaste sättet att komma tillbaka till dem är att bokmärka adressen.
2. Ange **datumintervallet** för att definiera rapportperioden.
3. Använd ytterligare filter, till exempel **fond** eller andra kriterier, för att avgränsa resultaten.
4. Rapporten visar därefter givandesammanfattningen för den valda perioden.

## Vad rapporten visar

Rapporten Gåvosammanfattning innehåller:

- **Totala gåvor** -- Det sammanlagda givandebeloppet för den valda perioden.
- **Antal givare** -- Antalet unika givare som bidragit.
- **Belopp per fond** -- En uppdelning av givandet på olika fonder, om tillämpligt.

## Praktiska användningsområden

- **Ekonomisk planering** -- Granska givandetrender för att prognostisera framtida intäkter och planera din budget.
- **Styrelserapporter** -- Ta fram sammanfattningar inför regelbundna styrelse- eller ledningsmöten med tydliga givandedata.
- **Årsgranskningar** -- Kör rapporten för hela året för att förbereda årliga ekonomiska sammanfattningar.
- **Kampanjuppföljning** -- Filtrera per fond för att följa upp framstegen i särskilda givandekampanjer eller byggprojekt.
- **Säsongsanalys** -- Jämför givandet över olika perioder för att förstå säsongsmönster.

:::tip
Kör den här rapporten varje månad för att hålla dig informerad om din kyrkas ekonomiska hälsa. Att jämföra data från månad till månad hjälper dig att upptäcka trender tidigt.
:::

:::warning
Gåvodata kommer från registrerade bidrag i ditt system. Se till att gåvor registreras konsekvent, oavsett om de kommer via onlinegivande, kontrollhantering eller manuell inmatning, för att rapporterna ska bli så korrekta som möjligt. Se [Registrera gåvor](../donations/recording-donations.md) för mer information.
:::
