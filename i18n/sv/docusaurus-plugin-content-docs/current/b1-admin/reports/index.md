# Rapporter

<div class="article-intro">

B1 Admin ger dig flera sätt att hämta data om din församling, närvaro och gåvor. Rapportering finns inbyggd i de relevanta delarna av appen i stället för på en enda rapportsida.

</div>

## Var hittar du rapporter

### Personer
- **[Födelsedags- och årsdagslistor](./birthday-report.md)** -- Filtrera efter födelsemånad eller årsdagsmånad under **Personer → Avancerad sökning** för att få en lista över kommande födelsedagar eller årsdagar.

### Närvaro
- **[Närvarorapporter](./attendance-reports.md)** -- Närvarotrender och närvarodata för grupper finns i avsnittet **Närvaro**.

### Gåvor
- **[Gåvosammanfattning](./donation-summary.md)** -- Totala gåvor och fördelning per fond finns i avsnittet **Gåvor**.

### Inställningar
- **[Granskningslogg](./audit-log.md)** -- Spåra alla ändringar och åtgärder i ditt församlingshanteringssystem (finns under **Inställningar → Granskningslogg**).

:::info
Rapportdata bygger på konsekvent datainmatning. Se till att ditt team [registrerar närvaro](../attendance/tracking-attendance.md), [registrerar gåvor](../donations/recording-donations.md) och håller [personposter](../people/adding-people.md) uppdaterade för att få så korrekta resultat som möjligt.
:::
