# Lista över bröllopsdagar

<div class="article-intro">

Behöver du en lista över alla som har bröllopsdag under en viss månad, till församlingsbladet, kort eller meddelanden? Med sökningen i Personer kan du filtrera på **Bröllopsdagens månad** och visa datumen direkt i resultaten.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- Se till att bröllopsdagar är angivna i varje persons profil. Mer information finns i [Lägga till personer](../people/adding-people.md).
- Du behöver behörighet att visa Personer. Se [Roller och behörigheter](../settings/roles-permissions.md).

</div>

## Så här hämtar du en lista över bröllopsdagar för en månad

1. Öppna [Hoppmenyn](../introduction.md#getting-around-with-the-jump-menu) (sökfältet längst upp till vänster i B1 Admin), expandera **Personer** och klicka på **Personer**.
2. Klicka på **Avancerat** under sökrutan.
3. Expandera avsnittet **Demografi**, markera **Bröllopsdagens månad** och välj sedan månad.
4. Kör sökningen. Alla med bröllopsdag den månaden visas i resultaten.
5. För att se datumen, ändra **Visa som** till **Tabell** och klicka sedan på ikonen **Välj kolumner** i sidhuvudet och aktivera kolumnen **Bröllopsdag**. Använd **Exportera** om du vill ladda ner listan som ett kalkylblad för att sortera eller skriva ut den.

## Praktiska användningsområden

- **Veckovisa församlingsblad** -- Kör listan för innevarande månad och ta med bröllopsdagarna i ditt församlingsblad eller dina meddelanden.
- **Kort till bröllopsdagar** -- Exportera månadens lista och lämna den till teamet som skriver kort.
- **Milstolpsfirande** -- Kombinera med filtret **Antal år gifta** för att hitta jämna bröllopsdagar.

:::tip
Kör den här listan i början av varje månad så att du har tid att förbereda kort eller meddelanden innan bröllopsdagarna infaller.
:::

:::info
Bröllopsdagar hämtas från fältet för bröllopsdag i varje persons profil. Om någon saknas behöver bara datumet läggas till i profilen. Se [Lägga till personer](../people/adding-people.md).
:::
