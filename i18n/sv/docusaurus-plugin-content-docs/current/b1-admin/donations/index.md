# Donationer

<div class="article-intro">

Avsnittet Donationer i B1 Admin innehåller allt du behöver för att hantera din kyrkas givande. Från registrering av de veckovisa offergåvorna till att skapa årliga skattebesked är alla dina donationsverktyg samlade på ett ställe, så att du kan hålla koll på kyrkans ekonomi.

</div>

## Underavsnitt

Du hittar följande sidor i avsnittet Donationer:

### Sammanfattning

Sidan **Sammanfattning** ger dig en visuell översikt över all givandeaktivitet. Den visar diagram och filtrerade rapporter, så att du snabbt kan se donationstrender i hela din kyrka. Se [Donationsrapporter](donation-reports.md) för mer information om hur du använder sammanfattningen och rapportverktygen.

### Batcher

**[Batcher](batches.md)** låter dig gruppera donationer, till exempel alla checkar och kontanter som samlades in under en söndagsoffer. Varje batch visar antalet donationer och det totala beloppet, vilket gör avstämningen enkel. När en batch har räknats kan någon med behörigheten **Redigera donationer** stänga den, så att de som räknat inte längre kan ändra i den. Volontärer med behörigheten **Registrera donationer** kan lägga till gåvor i öppna batcher utan att se resten av avsnittet Donationer.

### Fonder

**[Fonder](funds.md)** kategoriserar dina donationer efter syfte. Vanliga exempel är Allmänna fonden, Byggfonden och Missionsfonden. Du kan markera varje fond som avdragsgill eller inte.

### Besked

Sidan **[Besked](giving-statements.md)** skapar årliga givandebesked till dina givare. Du kan ladda ner enskilda CSV-filer eller skriva ut alla besked på en gång.

### Stripe-import

Om du tar emot onlinedonationer via Stripe kan verktyget **[Stripe-import](stripe-import.md)** hämta dessa transaktioner till B1 Admin, så att allt finns i ett och samma system.

## Onlinegivande

B1 Admin integrerar med **Stripe** och **PayPal** för att ta emot onlinedonationer. När det är konfigurerat kan medlemmar ge via din B1.church-webbplats, och donationerna visas automatiskt i dina register. Se [Konfigurera onlinegivande](online-giving-setup.md) för att komma igång.

:::tip
Om du är ny med donationer i B1 Admin, börja med att [konfigurera dina fonder](funds.md) och [skapa din första batch](batches.md), och [registrera donationer](recording-donations.md) i den.
:::
