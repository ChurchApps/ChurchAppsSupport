# Gruppernas hälsa

<div class="article-intro">

Instrumentpanelen för gruppernas hälsa ger dig en överblick över hur alla dina grupper mår: medlemsutveckling, genomsnittlig närvaro och tillväxt eller minskning under de senaste 90 dagarna, allt i en enda sorterbar tabell.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- Du behöver minst några grupper med medlemmar för att se meningsfulla data. Se [Skapa grupper](./creating-groups.md).
- Närvarodata hämtas från registrerade sessioner. Se avsnittet [Närvaro](../attendance/index.md).

</div>

## Öppna gruppernas hälsa

I B1 Admin öppnar du [Hoppmenyn](../introduction.md#getting-around-with-the-jump-menu) (sökfältet längst upp till vänster), expanderar **People**, klickar på **Groups** och sedan på knappen **Group Health** i sidhuvudet. Instrumentpanelen laddar en tabell med en rad per grupp.

## Kolumner

| Kolumn | Vad den visar |
|--------|--------------|
| **Name** | Gruppens namn, länkat till gruppens detaljsida |
| **Category** | Gruppens kategori |
| **Members** | Nuvarande antal aktiva medlemmar |
| **Joined (90d)** | Medlemmar som gick med under de senaste 90 dagarna |
| **Left (90d)** | Medlemmar som lämnade under de senaste 90 dagarna |
| **Churn (90d)** | Nettoomsättning i procent under 90 dagar |
| **Avg Attendance** | Genomsnittligt antal närvarande per närvarosession |

Klicka på valfri kolumnrubrik för att sortera tabellen efter den kolumnen. Klicka igen för att vända sorteringsriktningen.

## Använda hälsodata

- **Hög omsättning + få nya medlemmar**: en grupp som krymper och inte ersätter förlorade medlemmar. Värt ett samtal med gruppledaren.
- **Många nya medlemmar + låg närvaro**: personer anmäler sig men dyker inte upp. Överväg uppföljning för att öka engagemanget.
- **Hög genomsnittlig närvaro**: en frisk, aktiv grupp. Kan fungera som förebild för andra grupper.

:::tip
Om du klickar på ett gruppnamn kommer du direkt till gruppens detaljsida, där du kan granska enskilda medlemmar, närvaroregistreringar och kalenderhändelser.
:::
