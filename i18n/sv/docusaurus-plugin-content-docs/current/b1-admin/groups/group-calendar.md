# Gruppkalender

<div class="article-intro">

Varje grupp i B1 kan ha sin egen händelsekalender. Gruppledare använder den för att schemalägga möten, aktiviteter och återkommande händelser, medan alla gruppmedlemmar kan se kommande händelser och delta i samtal om dem. Kalendern håller din grupp organiserad och ser till att alla håller sig informerade om vad som är på väg.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- Du behöver en grupp skapad i B1 Admin med minst en medlem. Se [Skapa grupper](creating-groups.md) och [Gruppmedlemmar](group-members.md).
- För att lägga till eller redigera kalenderhändelser måste du vara utsedd till gruppledare. Se [Utse gruppledare](group-members.md) för instruktioner.

</div>

## Öppna gruppkalendern

Gruppkalendern finns i B1.church, appen för medlemmar:

1. Klicka på **rullgardinsmenyn** längst upp till höger på skärmen i B1 Admin.
2. Välj **Byt app**.
3. Välj **B1.church**.
4. Öppna **Grupper** (en flik i det nedre navigeringsfältet på en telefon, eller i det övre sidhuvudet på en dator).
5. Välj din grupp i listan.
6. Under **Nästa händelse** klickar du på **Alla händelser** för att öppna gruppens vy **Händelser**. Använd växlingsknappen **Kalender** där för en månadsvy.

:::info
Gruppkalendern hanteras via B1.church (medlemsappen) snarare än via B1 Admin. Gruppledare öppnar den genom att byta app från adminpanelen.
:::

## Lägga till en händelse

1. Klicka på **Lägg till händelse** i gruppkalendern.
2. Ange en **titel** för händelsen.
3. Skriv en kort **beskrivning** av vad händelsen handlar om.
4. Ange **starttid** och **sluttid**.
5. Klicka på **Spara** för att lägga till händelsen i kalendern.

## Ställa in återkommande händelser

Om din grupp träffas regelbundet kan du ställa in att händelser upprepas automatiskt:

1. När du skapar eller redigerar en händelse markerar du rutan **Återkommande**.
2. Välj hur händelsen ska upprepas:
   - **Intervall** -- Ange antal dagar mellan tillfällena. Om du till exempel anger "7" upprepas händelsen var sjunde dag.
   - **Frekvens** -- Välj att upprepa per **dag**, **vecka** eller **månad**.
3. Spara händelsen. Den visas nu i kalendern vid varje schemalagt tillfälle.

:::tip
För en grupp som träffas varje lördag, ställ in frekvensen på "vecka" och välj lördag. Händelsen fylls då automatiskt i kalendern framöver.
:::

## Skapa flera händelser samtidigt i B1 Admin

Gruppens sida i B1 Admin har också ett avsnitt **Kalender** där personal kan schemalägga en hel termin med möten på en gång:

1. Öppna gruppen i B1 Admin och klicka på **Alla händelser** i avsnittet **Kalender**.
2. Klicka på **+ Lägg till händelser** för att öppna dialogrutan **Lägg till återkommande händelser**.
3. Välj schema (varje vecka, varannan vecka, varje månad eller ett enstaka tillfälle), datum för **första möte** och **sista möte** samt, om du vill, **Hoppa över helgdagar**.
4. Granska förhandsvisningen av mötesdatum och avmarkera de datum du vill hoppa över.
5. Lämna **Tillåt OSA** ikryssat om du vill att medlemmarna ska kunna svara på dessa händelser (se nedan), och spara sedan.

## OSA för händelser

Grupphändelser kan samla in OSA, det vill säga ett **Ja**, **Nej** eller **Kanske** för varje tillfälle av händelsen.

- **Tillåt OSA** är påslaget som standard för händelser som skapas via dialogrutan för flera händelser. Avmarkera rutan om du vill stänga av svar för dessa händelser. Händelser med avstängda OSA visas som **Inaktiverad** i gruppens händelselista.
- I gruppens händelselista i B1 Admin visar varje händelse en svarssammanfattning (till exempel "5 ja · 2 kanske · 1 nej"). Klicka för att öppna listan **OSA-svar**, som visar vem som svarade ja, kanske och nej för just det tillfället.

:::tip
OSA ger ledare en uppfattning om antalet deltagare utan den formalitet som full eventanmälan innebär. För betalda anmälningar eller händelser med begränsat antal platser, använd i stället [eventanmälan](../calendars/creating-calendars.md#enabling-event-registration).
:::

## Visa kalendern

Gruppkalendern har flera visningslägen:

- **Månad** -- Se hela månaden i ett ögonkast.
- **Vecka** -- Fokusera på innevarande vecka.
- **Dag** -- Visa en enskild dag i detalj.
- **Agenda** -- Se en lista över kommande händelser i kronologisk ordning.

Byt mellan vyerna med knapparna överst i kalendern.

## Händelsedetaljer och samtal

Klicka på en händelse för att se dess detaljer. Från detaljvyn för händelsen gäller följande:

- **Medlemmar och ledare** kan starta samtal och lämna kommentarer om händelsen.
- **Ledare** kan redigera händelsens uppgifter, ändra tider eller ta bort händelsen.

:::warning
Om du tar bort en händelse försvinner den permanent. Om du behöver ställa in ett enskilt tillfälle av en återkommande händelse som inställt bör du i stället överväga att redigera den.
:::

## Prenumerera på kalendern

Du kan synkronisera gruppkalendern med din personliga kalender:

1. Klicka på **Prenumerera** på gruppkalendersidan.
2. Följ anvisningarna för att lägga till kalendern i Google Kalender, Apple Kalender, Outlook eller någon annan kalenderapp som stöder prenumerationer.

:::tip
Med en prenumeration hålls ditt personliga schema synkat med gruppens händelser utan att du behöver kontrollera B1 separat. Alla ändringar som gjorts av gruppledare visas automatiskt i din synkade kalender.
:::
