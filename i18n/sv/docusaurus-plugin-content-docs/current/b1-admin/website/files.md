# Filer

<div class="article-intro">

Sidan Filer är den centrala lagringsplatsen för all media och alla dokument som används på din kyrkas webbplats. Här kan du ladda upp, bläddra bland och hantera varje bild, dokument och mediefil som din webbplats behöver.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- Slutför [Första inställningen](initial-setup) för din webbplats
- Optimera bilder innan du laddar upp dem för snabbare sidladdningstider
- Förbered dina filer i vanliga webbformat (PNG, JPG, PDF m.fl.)

</div>

## Ladda upp filer

1. I B1 Admin öppnar du [Hoppmenyn](../introduction.md#getting-around-with-the-jump-menu) (sökfältet överst till vänster), expanderar **Webbplats** och klickar på **Filer**.
2. I panelen **Ladda upp filer** till höger klickar du på **Välj fil** och väljer en fil från din dator. (Knappen **Ladda upp filer** överst på sidan öppnar samma panel.)
3. Din fil laddas upp och visas i filtabellen.

Panelen Ladda upp filer visar också hur mycket lagringsutrymme du använder. 100 MB ingår gratis. Vill du ha mer kan du koppla ditt eget Google Drive, Dropbox, OneDrive eller S3-bucket under **Inställningar**, i avsnittet **Fillagring**.

:::tip
För bästa resultat bör du optimera bilder innan du laddar upp dem. Mindre filstorlekar hjälper din webbplats att laddas snabbare för besökarna. Verktyg som TinyPNG eller Squoosh kan komprimera bilder utan märkbar kvalitetsförlust.
:::

## Bläddra bland filer

Filtabellen listar alla uppladdade filer med deras **Namn** och **Storlek**. Klicka på en fils namn för att öppna den i en ny flik. Ge filerna tydliga, beskrivande namn innan du laddar upp dem så att ditt team snabbt kan hitta dem.

## Använda filer på din webbplats

1. Hitta filen i filtabellen.
2. Klicka på **Kopiera länk** för att kopiera filens URL. Du kan klistra in den här URL:en i bildelement, nedladdningslänkar eller var som helst annars där en filadress accepteras.
3. Filer du laddar upp här är tillgängliga för användning på alla dina webbplatssidor och innehållsblock.

:::info
När du bygger sidor i [Hantera sidor](managing-pages) kan du referera till vilken fil som helst som laddats upp här med dess URL. Det håller all din media organiserad på ett och samma centrala ställe.
:::

## Ta bort filer

1. Hitta filen du vill ta bort i filtabellen.
2. Klicka på **Ta bort** bredvid den och bekräfta för att permanent ta bort den från ditt bibliotek.
3. Se till att filen inte används på någon sida innan du tar bort den, eftersom länkar eller bilder som refererar till den då slutar fungera.

:::warning
Borttagna filer kan inte återställas. Kontrollera dubbelt att en fil inte längre används på någon sida innan du tar bort den.
:::
