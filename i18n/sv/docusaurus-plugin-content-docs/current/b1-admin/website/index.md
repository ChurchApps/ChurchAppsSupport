# Webbplats

<div class="article-intro">

Avsnittet Webbplats i B1 Admin ger dig en fullständig webbplatsbyggare för din kyrka. Du kan skapa sidor, anpassa din webbplats utseende och känsla, hantera mediefiler och publicera evenemangskalendrar, utan att skriva någon kod.

</div>

## Vad du kan göra

Webbplatsbyggaren är indelad i följande huvudområden:

### Sidor

Skapa och hantera alla sidor på din kyrkas webbplats. Tabellen **Sidor** visar varje sida. Sidor som systemet skapat automatiskt har en märkning **Genererad**, och resten är anpassade sidor som du har skapat. Du kan lägga till nya anpassade sidor, redigera befintliga eller omvandla automatiskt genererade sidor till anpassade sidor för full kontroll över deras innehåll.

Dina navigeringslänkar visas i en trädstruktur. Du kan ändra ordningen på länkarna genom att dra och släppa dem, så att du får exakt den hierarki och ordning som besökarna ska se.

### Blogg

Publicera nyheter, uppdateringar och andakter som blogginlägg på `/blog` på din webbplats, med ett RSS-flöde. Se guiden [Blogg](./blog.md).

### Block

Skapa återanvändbara innehållskomponenter som du kan placera på flera sidor. Block sparar tid när du har innehåll, till exempel en uppmaning till handling, ett meddelandebanner eller ett kontaktavsnitt, som förekommer på mer än ett ställe. Uppdatera ett block en gång, så gäller ändringen överallt där det används.

### Utseende

Anpassa din webbplats tema, färger, typsnitt, logotyp och avstånd. Du kan använda förinstallerade temastilar för en snabb start eller finjustera varje detalj med färgpaletteditorn, typografiinställningar och anpassad CSS. Se guiden [Utseende](./appearance.md) för fullständig information.

### Filer

Ladda upp och hantera alla dina mediefiler, till exempel bilder, dokument och andra filer, på en central plats, och kopiera fillänkar för att använda dem var som helst på din webbplats. Se [Filer](./files.md) för mer information.

### Kalendrar

Publicera evenemangskalendrar på din webbplats så att besökare kan se vad som händer i din kyrka. Skapa utvalda kalendrar som samlar evenemang från flera grupper i en enda vy. Kalendrar har en egen post **Kalendrar** i menyn i B1 Admin, separat från **Webbplats**.

:::tip
Börja med [Första installationen](./initial-setup.md) om du konfigurerar din webbplats för första gången. Den guidar dig genom domäninställning, skapande av din första sida och konfiguration av din webbplats utseende.
:::
