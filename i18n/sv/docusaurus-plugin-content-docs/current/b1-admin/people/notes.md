# Anteckningar

<div class="article-intro">

Sidan **Anteckningar** samlar de senaste anteckningarna från hela B1 Admin på ett ställe, så att du kan hålla dig uppdaterad om själavård, uppföljningar och planering utan att öppna varje post. Den visar anteckningar om personer, grupper du leder, kalenderhändelser och arbetsflödeskort, med de senaste överst, och länkar varje anteckning tillbaka till platsen där den skrevs.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- Sidan **Anteckningar** visas i menyn om du har behörigheten **Redigera personer** eller leder minst en grupp. Se [Tilldela roller](./roles-permissions.md).
- Sidan visar bara anteckningar som du redan har rätt att läsa. Varje flik följer samma regler som posten som anteckningarna hör till (se [Vad varje flik visar](#what-each-tab-shows)).

</div>

## Öppna sidan Anteckningar

1. Öppna [Hoppmenyn](../introduction.md#getting-around-with-the-jump-menu) (sökfältet överst till vänster i B1 Admin) och expandera **Personer**.
2. Klicka på **Anteckningar**.
3. Sidan öppnas på fliken **Personer**. Använd flikarna i sidhuvudet för att växla mellan **Personer**, **Grupper**, **Händelser** och **Arbetsflöden**.

## Läsa listan

Varje anteckning i listan visar:

- **Var den skrevs** -- personens namn, gruppens namn, händelsens titel eller arbetsflödeskortets titel. Klicka på namnet för att öppna posten och läsa hela tråden eller lägga till en anteckning.
- **Konfidentiell** -- en märkning på personanteckningar som kommer från personens avsnitt för konfidentiella anteckningar.
- **Vem som skrev den och när** -- "Av" följt av författarens namn, och datum och klockslag för när den publicerades.
- **Själva anteckningen** -- långa anteckningar förkortas i listan. Öppna posten för att läsa hela anteckningen.

Listan visar de senaste anteckningarna först. Klicka på **Ladda fler** längst ner för att se äldre.

Anteckningar som skrivits om en person som sedan har raderats eller slagits samman med en annan post visas inte på fliken **Personer**.

Sidan Anteckningar är skrivskyddad. Om du vill lägga till, redigera eller svara på en anteckning klickar du på postens namn för att öppna den.

## Vad varje flik visar {#what-each-tab-shows}

| Flik | Visade anteckningar | Vem kan se dem | Klicka på namnet för att öppna |
|-----|-------------|------------------|-------------------------|
| **Personer** | Anteckningar på personposter | Personer med **Redigera personer**. Konfidentiella anteckningar kräver dessutom **Visa konfidentiella anteckningar** | Personens anteckningar |
| **Grupper** | [Ledaranteckningar](../groups/group-members.md#leader-notes) på grupper | Endast gruppens ledare, även för administratörer | Gruppens anteckningar |
| **Händelser** | [Händelseanteckningar](../calendars/creating-calendars.md#event-notes) | Personal som kan redigera innehåll eller administrera kalendrar, samt alla som tillåts av inställningen **Vem kan visa anteckningar** för händelsen | Händelsens grupps kalender |
| **Arbetsflöden** | Anteckningar på [arbetsflödeskort](../serving/workflows.md#working-the-board) | Alla som kan öppna kortet, inklusive personen eller gruppen det är tilldelat till | Kortets arbetsflödestavla |

Om en flik inte har något du kan se ännu, står det så -- till exempel "Inga anteckningar för grupper du leder ännu."

:::tip
Anteckningstrådar har en klockikon för aviseringar. Klicka på den för att få meddelanden om nya anteckningar i tråden (ikonen ändras direkt), och klicka igen för att stänga av dem. Dessa på/av-inställningar visas aldrig som anteckningar på sidan Anteckningar.
:::
