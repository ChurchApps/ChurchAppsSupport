# Inställningar

<div class="article-intro">

Avsnittet Inställningar är där du konfigurerar din kyrkas konto, grafiska profil och administrativa alternativ i B1 Admin. Härifrån kan du hantera allt från kyrkans namn och subdomän till användarbehörigheter och konfiguration av mobilappen.

</div>

## Vad du hittar här

Området Inställningar är indelat i följande underavsnitt:

1. **Inställningar** -- Konfigurera kyrkans grundläggande information, grafiska profil, subdomän, region (datum- och telefonformat), sms-leverantör och fillagring. Se [Kyrkoinställningar](./church-settings.md) för mer information. Om du vill använda ditt eget domännamn (t.ex. dinkyrka.org), se [Anpassad domän](./custom-domain.md).
2. **Campus** -- Lägg till och hantera flera fysiska platser för din kyrka. När campus har skapats visas de på personprofiler, i närvaroinställningarna och på instrumentpanelen för demografi. De nås som en sektion på huvudsidan för Inställningar i stället för som ett eget navigeringsobjekt. Se [Campus](./campuses.md) för mer information.
3. **Anpassade fält** -- Definiera egna fält att följa upp för personer (ett datum, ett tal, ett ja/nej-svar eller en vallista), fyll sedan i dem på profiler och sök efter dem. De nås också som en sektion på huvudsidan för Inställningar. Se [Anpassade fält](./custom-fields.md) för mer information.
4. **E-postmallar** -- Spara återanvändbart e-postinnehåll för att skicka manuellt eller från ett arbetsflöde. Se [E-postmallar](./email-templates.md) för mer information.
5. **Granskningslogg** och **Batcher** -- Granska ändringar som gjorts i ditt konto ([Granskningslogg](../reports/audit-log.md)), och granska eller ångra massimporter och åtgärder (**Batcher**).
6. **Serveradministration** -- Åtkomst till avancerade administrationsverktyg för att hantera kyrkans serverinställningar.

:::info
**Mobilappar**-konfigurationen och **Formulär** har nu egna navigeringsobjekt på översta nivån -- **Mobil** och **Formulär** (under **Personer**) -- i stället för att ligga inne i Inställningar. Se [Inställningar för mobilappen](./mobile-app.md) och [Skapa formulär](/docs/b1-admin/forms/creating-forms) för mer information.
:::

## Huvudsidan för Inställningar

När du först öppnar sidan Inställningar visar panelen till vänster din **kyrkas namn**, **subdomän** och adress, samt en länk till **Import/Export** som öppnar verktyget för import och export av data mellan system.

Under det finns en lista över **Konfiguration** med länkar till varje inställningssektion: **Kyrkinformation**, **Allmänt**, **Region**, **Givande**, **Sms**, **Fillagring**, **Domäner**, **Klassflyttning**, **Incheckning**, **Campus**, **Anpassade fält** och **Utvecklare**. Sektioner som fortfarande behöver konfigureras (till exempel Givande, Sms eller Domäner) markeras med en liten prick. Alla sektioner finns på samma sida -- klicka på ett namn i listan för att hoppa dit, eller bara scrolla ner. Varje sektion visar sina aktuella inställningar; klicka på **Redigera** i en sektion för att ändra dem.

**E-postmallar**, **Granskningslogg** och **Batcher** är separata sidor -- öppna dem från [Hoppmenyn](../introduction.md#getting-around-with-the-jump-menu) under **Inställningar**.

Börja med sektionen **Kyrkinformation** för att redigera din kyrkas namn, adress och kontaktuppgifter -- se [Kyrkoinställningar](./church-settings.md). För att hantera användarroller, öppna [Hoppmenyn](../introduction.md#getting-around-with-the-jump-menu) och välj **Inställningar > Roller** -- se [Roller och behörigheter](./roles-permissions.md).

:::tip
Börja med att konfigurera din kyrkas namn och grafiska profil under **Kyrkinformation**, och ställ sedan in [Roller](./roles-permissions.md) för att bjuda in dina teammedlemmar med rätt behörighetsnivå.
:::

:::info
Information om hur dina data skyddas finns i [Datasäkerhet](./data-security.md).
:::
