# Formulär

<div class="article-intro">

Avsnittet Formulär låter dig skapa anpassade formulär för anmälningar, enkäter, datainsamling och mycket mer. Oavsett om du behöver ett besökskort, en anmälan till en händelse eller ett bönebegäran-formulär kan du skapa det här och dela det med din församling via en offentlig länk eller din B1.church-webbplats.

</div>

## Sidan Formulär

När du öppnar **Formulär** ser du dessa flikar:

- **Formulär** -- Visar alla dina aktiva formulär.
- **Arkiverade formulär** -- Visar formulär som har arkiverats. Du kan återställa arkiverade formulär när som helst. Den här fliken visas först när minst ett formulär har arkiverats.

Varje formulär i listan visar sitt namn och, om det är konfigurerat, en offentlig webbadress som du kan dela externt.

## Vad du kan göra

Från sidan Formulär kan du:

- **Lägga till ett formulär** -- Klicka på **Lägg till formulär** för att skapa ett nytt anpassat formulär.
- **Hitta ett formulär** -- Skriv i rutan **Hitta ett formulär** för att filtrera listan efter namn.
- **Redigera ett formulär** -- Klicka på ett formulärnamn för att öppna det och ändra dess frågor, medlemmar eller inställningar.
- **Arkivera ett formulär** -- Flytta formulär som du inte längre behöver till fliken **Arkiverade formulär** för att hålla listan ren.
- **Återställa ett formulär** -- Växla till fliken **Arkiverade formulär** och återställ de formulär du vill göra aktiva igen.

## Arbeta med ett formulär

Klicka på ett formulärnamn för att öppna det. Formulärredigeraren har upp till tre flikar:

- **Frågor** -- Bygg formulärets struktur genom att lägga till fält med olika typer. Se [Skapa formulär](./creating-forms.md) för mer information.
- **Formulärmedlemmar** -- Styr vem som kan öppna och hantera formuläret (gäller endast fristående formulär).
- **Formulärsvar** -- Visa svar som har skickats in. Se [Hantera svar](./managing-submissions.md) för mer information.

:::tip
Formulär med en offentlig webbadress kan delas via länk, bäddas in på din webbplats eller tas med i e-postmeddelanden. Det gör det enkelt att samla in information från personer som kanske inte har ett konto i kyrkan.
:::

:::info
Du kan styra vem som har åtkomst till varje formulär med fliken **Formulärmedlemmar**. Tilldela rollerna **Admin** eller **Endast visning** för att ge ditt team rätt åtkomstnivå.
:::
