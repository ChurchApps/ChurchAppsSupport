# Profil

<div class="article-intro">

Avsnittet Profil låter dig hantera dina personliga kontoinställningar i ChurchApps. Din profil delas mellan alla ChurchApps-verktyg, så ändringar du gör här gäller överallt -- från B1 Admin till appen B1 Mobile.

</div>

## Vad du kan göra

I avsnittet Profil kan du:

- **Uppdatera ditt namn och din e-postadress** -- Håll dina kontaktuppgifter aktuella.
- **Ändra ditt lösenord** -- Ange ett nytt lösenord för ditt konto.
- **Aktivera tvåfaktorsinloggning** -- Kräv en kod från en autentiseringsapp när du loggar in. Se [Tvåfaktorsinloggning](./managing-profile.md#two-factor-sign-in).
- **Byta tema** -- Växla mellan ljust och mörkt läge från användarmenyn (klicka på din profilbild i det övre högra hörnet).
- **Hantera anslutna enheter** -- Se och styr vilka ChurchAppsPlayer-enheter som är kopplade till ditt konto.
- **Visa kopplade konton** -- Se och hantera externa tjänster som är anslutna till ditt ChurchApps-konto.
- **Godkänna ändringsbegäranden för profiler** -- Granska och tillämpa uppdateringar som medlemmar har skickat in.

## Profilens underavsnitt

Profilområdet har följande sidor:

1. **[Hantera din profil](./managing-profile.md)** -- Redigera dina personuppgifter, ändra ditt lösenord, hantera kopplade konton, aktivera tvåfaktorsinloggning, justera temainställningar och hantera kontoradering.
2. **[Godkänna profiländringar](./approving-profile-changes.md)** -- Granska och godkänn uppdateringsbegäranden för profiler som medlemmar har skickat via B1 Mobile.
3. **[Hantera enheter](./devices.md)** -- Visa, lägg till och hantera ChurchAppsPlayer-enheter som är kopplade till ditt konto.

:::tip
Håll din e-postadress uppdaterad. Den används för kontoåterställning och viktiga meddelanden från din församling.
:::
