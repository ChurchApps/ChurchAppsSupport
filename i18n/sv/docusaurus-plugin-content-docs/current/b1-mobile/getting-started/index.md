# Komma igång

:::danger B1 Mobile är utfasad
Den inbyggda B1 Mobile-appen har ersatts av [B1.church Progressive Web App (PWA)](../../b1-church/getting-started/installing-pwa.md). Nya användare bör installera PWA:n från valfri sida på `https://yourchurchname.b1.church` i stället för att ladda ner B1 Mobile från App Store eller Google Play.
:::

<div class="article-intro">

Det tar bara några minuter att komma igång med B1 Mobile. Ladda ner appen, logga in med ditt ChurchApps-konto, välj din kyrka, så är du redo.

</div>

## Snabbstart

1. **Ladda ner** appen från [App Store](https://apps.apple.com) (iOS) eller [Google Play Store](https://play.google.com) (Android). Sök efter "B1.church".
2. **Logga in** med ditt befintliga ChurchApps-konto -- samma e-postadress och lösenord som du använder på B1.church. Om du inte har något konto ännu trycker du på **Registrera** för att skapa ett.
3. **Välj din kyrka** genom att söka efter den med namn. Skriv minst 3 tecken för att se resultat.
4. **Utforska startsidan** -- din personliga startskärm visar snabblänkar till de funktioner som din kyrka erbjuder.

Det var allt. När du har valt din kyrka laddar appen kyrkans grafiska profil, navigeringslänkar och innehåll. Du kan börja använda grupper, givande, incheckning och allt annat som din kyrka har aktiverat.

## I det här avsnittet

- [Logga in](./logging-in) -- Hur du loggar in eller skapar ett nytt konto.
- [Byta kyrka](./switching-churches) -- Hur du byter mellan kyrkor om du tillhör fler än en.

B1 Mobile använder samma ChurchApps-konto som alla andra ChurchApps-produkter. Om du redan har ett konto från [B1.church](../../b1-church/), B1 Admin eller Lessons.church kan du använda samma uppgifter för att logga in.
:::
