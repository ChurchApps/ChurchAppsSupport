# Tjänstgöring

<div class="article-intro">

Avsnittet **Tjänstgöring** i B1 Mobile ger dig ett snabbt och enkelt sätt att hålla koll på dina tjänstgöringsåtaganden. Oavsett om du ingår i lovsångsteamet, hälsar välkommen vid dörren eller hjälper till i barnverksamheten är det här du kan se när du är schemalagd och vilken roll du har.

</div>

## Vad du hittar här

- **Kommande uppdrag** -- Se alla dina framtida tjänstgöringstillfällen på ett ögonkast, så att du alltid vet när du behövs härnäst.
- **Tidigare tjänstgöringshistorik** -- Gå igenom de tjänster du redan har utfört för att följa ditt engagemang över tid.
- **Positionstilldelningar** -- Varje uppdrag visar den position du har fått, tillsammans med dess aktuella status: om den är begärd, bekräftad eller väntar på ditt svar.
- **Volontärmöjligheter** -- Bläddra bland lediga positioner och [anmäl dig själv](./volunteer-signup) till kommande tjänster.

## Komma igång

För att se ditt tjänstgöringsschema trycker du på **Tjänstgöring** i den nedre navigeringen i appen. Du måste vara inloggad för att se dina uppdrag. Om du inte är inloggad uppmanas du att först [logga in](../getting-started/logging-in).

:::info
Du ser bara planer som du har tilldelats till. Om du inte ser några uppdrag betyder det att du ännu inte har lagts till i något tjänstgöringsteam. Kontakta din församlingsadministratör eller din ledare för tjänsten för att komma med.
:::
