# B1 Mobile (föråldrad)

:::danger Föråldrad: använd B1.church istället
Den inbyggda B1 Mobile-appen för iOS och Android är **föråldrad** och utvecklas inte längre. Dess funktioner levereras nu via **B1.church-webbappen (PWA)** på `https://yourchurchname.b1.church`. Den kan läggas till på startskärmen på vilken iPhone eller Android-telefon som helst och ger samma medlemsportal utan nedladdning från App Store.

**Om du är medlem i en kyrka:** se [Installera som app (PWA)](../b1-church/getting-started/installing-pwa.md) för att konfigurera ersättningen på din telefon.

**Om du är kyrkoadministratör:** be dina medlemmar att gå till din kyrkas webbplats (`https://yourchurchname.b1.church`) i stället för App Store- eller Google Play-listningarna. De kan installera PWA:n från vilken sida som helst.

Sidorna nedan finns kvar som referens för kyrkor som fortfarande använder den äldre, inbyggda appen.
:::

<div class="article-intro">

B1 Mobile *var* den kompletterande inbyggda appen för B1.church på iOS och Android. Den gav kyrkomedlemmar tillgång på språng till grupper, gåvor, incheckning, tjänstplaner, medlemskatalogen, privata meddelanden, predikningar, Bibeln, dagens vers, lektioner med mera.

</div>

Appen använde ditt ChurchApps-konto, samma konto som du använder på B1.church. Efter inloggning och val av kyrka anpassade sig appen efter kyrkans grafiska profil och inställningar. Om du tillhörde flera kyrkor kunde du byta mellan dem när som helst.

B1 Mobile stödde pushnotiser så att du inte missade viktiga uppdateringar från din kyrka eller dina grupper. Startskärmen anpassade sig efter hur du använde appen. Funktioner som du besökte oftast flyttades upp till toppen för snabb åtkomst.

## Viktiga funktioner

- **Grupper** -- Se dina grupper, delta i samtal och håll kontakten med gruppmedlemmar.
- **Gåvor** -- Ge bidrag till din kyrka direkt från telefonen.
- **Evenemang** -- Bläddra bland kommande evenemang och anmäl dig direkt från telefonen.
- **Incheckning** -- Checka in dig själv och dina hushållsmedlemmar till gudstjänster och evenemang.
- **Tjänstplaner** -- Se kommande tjänstplaner, dina tilldelade volontärroller och anmäl dig till lediga platser.
- **Medlemskatalog** -- Bläddra i din kyrkas katalog och se medlemsprofiler.
- **Meddelanden** -- Skicka och ta emot privata meddelanden till andra kyrkomedlemmar.
- **Predikningar** -- Titta på eller lyssna på predikningar från din kyrka.
- **Bibeln** -- Läs Bibeln i appen.
- **Dagens vers** -- Börja dagen med en daglig vers.
- **Lektioner** *(föråldrad, ersatt av [FreePlay](/docs/freeplay/))* -- Användes för att bädda in lektioner från Lessons.church i appen.
