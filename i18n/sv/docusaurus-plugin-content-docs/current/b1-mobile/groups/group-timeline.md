# Gruppentidslinje

<div class="article-intro">

Skärmen Grupper i B1 Mobile innehåller ett tidslinjeflöde som samlar aktivitet från alla dina grupper i ett enhetligt flöde. Istället för att kontrollera varje grupp för sig kan du bläddra i ett enda flöde och se allt som händer.

</div>

:::info
Gruppentidslinjen är tillfälligt otillgänglig medan förbättringar görs. Under tiden kan du fortfarande bläddra i dina enskilda grupper från skärmen Grupper.
:::

<div class="prereqs">
<h4>Innan du börjar</h4>

- [Installera B1 Mobile](../getting-started/installing.md) och [logga in](../getting-started/logging-in.md) på ditt konto
- Vara medlem i minst en grupp i din kyrka

</div>

## Så fungerar det

Gruppentidslinjen samlar inlägg, samtal och uppdateringar från varje grupp du är med i. När gruppledare och medlemmar delar innehåll visas det i tidslinjen i kronologisk ordning. Det innebär att du får en komplett bild av ditt gruppliv utan att behöva byta mellan olika grupper.

## Vad som visas i tidslinjen

Tidslinjen innehåller olika typer av innehåll från dina grupper:

- **Inlägg** -- Meddelanden och uppdateringar som delas av gruppledare och medlemmar.
- **Samtal** -- Pågående diskussioner inom dina grupper.
- **Uppdateringar** -- Meddelanden, påminnelser om evenemang och annan aktivitet från dina grupper.

Varje objekt i tidslinjen visar vilken grupp det kommer från, så du alltid vet sammanhanget för det du läser.

## Håll dig uppdaterad

Tidslinjen är ett bra sätt att hålla kontakten med din kyrkogemenskap med en snabb överblick. Här är några tips för att få ut mesta möjliga av den:

- **Kolla in regelbundet** -- Öppna skärmen Grupper och bläddra i tidslinjen för att se vad som hänt på sistone.
- **Tryck för mer** -- Om ett inlägg fångar din uppmärksamhet trycker du på det eller på gruppnamnet för att gå till hela [gruppdetaljsidan](./group-details.md) och få mer sammanhang.
- **Allt på ett ställe** -- Du behöver inte besöka varje grupp separat. Tidslinjen för all aktivitet till dig.

:::info
Tidslinjen visar endast aktivitet från grupper som är kopplade till din kyrka. Om du inte ser några inlägg kan det bero på att dina grupper inte har haft någon nylig aktivitet, eller att du ännu inte är medlem i någon grupp.
:::

:::tip
Aktivera [pushnotiser](../community/notifications.md) för att få ett meddelande när nya inlägg visas i dina grupper, även när du inte använder appen.
:::
