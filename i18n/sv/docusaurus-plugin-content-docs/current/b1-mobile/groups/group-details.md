# Gruppdetaljer

<div class="article-intro">

När du trycker på en grupp på skärmen Grupper öppnas gruppens detaljsida. Här kan du se allt om gruppen och interagera med dess innehåll, inklusive inlägg, medlemslistor och gruppinformation.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- [Installera B1 Mobile](../getting-started/installing) och [logga in](../getting-started/logging-in) på ditt konto
- Öppna skärmen [Grupper](./index.md)

</div>

## Vad du ser

Gruppens detaljsida ger dig en fullständig profil av gruppen:

- **Gruppinfo** -- Gruppens namn, beskrivning, mötesdetaljer och annan information som gruppledarna har angett.
- **Inlägg och tidslinje** -- Ett flöde med inlägg och aktiviteter som är specifika för den här gruppen. Du kan se vad ledare och medlemmar har delat, inklusive uppdateringar, meddelanden och samtal.
- **Medlemmar** -- Se vilka som ingår i gruppen. Det hjälper dig att se vem du knyter kontakt med och känna igen bekanta ansikten.

## Interagera med gruppens innehåll

Från gruppens detaljsida kan du engagera dig i gruppen på flera sätt:

- **Läs inlägg** -- Bläddra igenom gruppens tidslinje för att se den senaste aktiviteten.
- **Visa medlemsprofiler** -- Tryck på en medlem för att se deras profilinformation i [medlemskatalogen](../community/member-directory.md).
- **Håll dig informerad** -- Kolla in regelbundet för att se nya inlägg, meddelanden och uppdateringar från dina gruppledare och andra medlemmar.

## Så tar du dig dit

1. Öppna skärmen **Grupper** i B1 Mobile.
2. Tryck på valfri grupp -- din främsta grupp, ett utvalt kort eller vilken grupp som helst i listan.
3. Gruppens detaljsida öppnas med allt dess innehåll och all dess information.

:::tip
Din mest besökta grupp visas som huvudkortet överst på skärmen Grupper, så du når din favoritgrupp med ett enda tryck.
:::
