# Grupper

<div class="article-intro">

Grupper i B1 Mobile hjälper dig att hålla kontakten med de människor och verksamheter som betyder något för dig. Oavsett om du tillhör en smågrupp, en bibelstudiegrupp, ett volontärteam eller en verksamhet är skärmen Grupper din startpunkt för allt som händer i din församlingsgemenskap.

</div>

## Vad du kommer att se

När du öppnar skärmen **Grupper** ordnas dina grupper efter hur ofta du besöker dem:

- **Huvudgrupp** -- Din mest besökta grupp visas framträdande överst på skärmen som ett stort huvudkort. Tryck på det för att gå direkt till gruppens detaljsida.
- **Utvalda grupper** -- Dina nästa mest besökta grupper visas som utvalda kort precis under huvudkortet. Här får du snabb åtkomst till de grupper du engagerar dig mest i.
- **Alla grupper** -- Under den utvalda sektionen kan du bläddra bland resten av din församlings grupper.

Layouten gör det enkelt att nå de grupper som betyder mest för dig med ett enda tryck, samtidigt som du fortfarande har tillgång till allt annat.

## Vad du kan göra

Här är vad du kan göra från skärmen Grupper:

- **Bläddra bland grupper** -- Scrolla genom din församlings tillgängliga grupper och upptäck nya att gå med i.
- **Visa gruppdetaljer** -- Tryck på valfri grupp för att se hela profilen, inklusive inlägg, medlemmar och gruppinformation.
- **Följ tidslinjen** -- Ett samlat tidslinjeflöde visar inlägg och aktivitet från alla dina grupper på ett ställe, så att du aldrig missar en uppdatering.
- **Håll kontakten** -- Se vad dina gruppmedlemmar delar, följ med i samtalen och engagera dig i gruppinnehållet.

:::tip
Skärmen Grupper anpassar sig efter hur du använder appen, precis som [instrumentpanelen](../dashboard/). De grupper du besöker oftast flyttas upp överst för snabb åtkomst.
:::
