# Profil

<div class="article-intro">

Din profil i B1 Mobile är där du hanterar dina personuppgifter, ditt hushåll och dina integritetsinställningar. Allt du uppdaterar här visas i alla ChurchApps-tjänster, så du behöver bara göra ändringar på ett ställe.

</div>

## Profilflikar

Profilskärmen är indelad i flera flikar:

### Profil

Fliken **Profil** låter dig visa och redigera dina personuppgifter, inklusive ditt namn, kontaktuppgifter och profilbild. Om din profil är uppdaterad hjälper det din församling att hålla kontakten med dig.

### Hushåll

Fliken **Hushåll** visar dina familjemedlemmar och deras roller inom ditt hushåll. Informationen används för funktioner som [incheckning](../checkin/), där du kan checka in hela din familj samtidigt.

### Synlighet

Fliken **Synlighet** låter dig styra vad andra församlingsmedlemmar kan se om dig i [katalogen](../community/member-directory.md). Du bestämmer vilka personuppgifter som delas och vilka som förblir privata.

### Väntande

Fliken **Väntande** visar eventuella profiländringar du har skickat in som väntar på godkännande av en administratör.

### Konto

Fliken **Konto** ger dig åtkomst till dina säkerhetsinställningar.

## Mina kort och mina uppgifter

Om din församling tilldelar dig [arbetsflödeskort](../../b1-admin/serving/workflows.md) eller [uppgifter](../../b1-admin/serving/tasks.md) visar skärmen **Jag** avsnitten **Mina kort** och **Mina uppgifter**, och **Start** visar en kort lista med **Dina uppföljningar**. Dessa avsnitt visas bara när något har tilldelats dig, och avslutade uppgifter visas aldrig. Tryck på **Alla kort**, **Alla uppgifter** eller **Alla** för att se allt som tilldelats dig.

Tryck på ett kort för att öppna det. Du kan:

- Se dess steg, förfallodatum och vilken person det gäller. Personens namn öppnar deras katalogprofil när katalogen visar dem för dig.
- Trycka på **Slutför** (eller stegets utfallsknapp) när steget är klart.
- **Skjuta upp** det i 1, 3 eller 7 dagar.
- Läsa och lägga till **Anteckningar**. Dessa är samma anteckningar som personalen ser på kortet i B1 Admin.

Tryck på en vanlig uppgift för att se vem den kommer från, vem den gäller och dess anteckningar. Att avsluta en vanlig uppgift görs fortfarande i B1 Admin.

## Så här kommer du till din profil

1. Öppna sidomenyn.
2. Tryck på **Profil** för att öppna din profilskärm.
3. Använd flikarna överst för att navigera mellan avsnitten.
