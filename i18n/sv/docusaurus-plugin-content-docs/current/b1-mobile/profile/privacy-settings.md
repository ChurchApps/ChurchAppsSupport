# Sekretessinställningar

<div class="article-intro">

Fliken **Synlighet** på skärmen Profil låter dig styra vad andra kyrkomedlemmar kan se om dig i katalogen. Du bestämmer vilka personliga uppgifter som delas offentligt och vilka som förblir privata.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- [Installera B1 Mobile](../getting-started/installing.md) och [logga in](../getting-started/logging-in.md) på ditt konto

</div>

## Styra din synlighet

1. Öppna sidomenyn och tryck på **Profil**.
2. Välj fliken **Synlighet**.
3. Granska varje fält och välj om det ska vara synligt för andra medlemmar.
4. Spara dina ändringar.

Du kan styra synligheten för uppgifter såsom:

- **Telefonnummer** -- Om andra medlemmar kan se ditt telefonnummer
- **E-postadress** -- Om din e-post visas i [katalogen](../community/member-directory.md)
- **Adress** -- Om din hemadress är synlig för andra

Som standard kan din kyrka ha vissa fält synliga eller dolda. Du kan justera dessa inställningar när som helst så att de passar dig.

:::tip
Om du är osäker på vad andra kan se, gå till fliken **Synlighet** och granska dina nuvarande inställningar. Du kan alltid göra ändringar senare.
:::

## Väntande ändringar

Fliken **Väntande** visar eventuella profiluppdateringar du har skickat in som väntar på godkännande från en administratör. Vissa kyrkor kräver att en administratör granskar och godkänner vissa ändringar innan de träder i kraft. Om du har gjort en ändring som kräver godkännande visas den här tillsammans med dess aktuella status.

:::info
Om en ändring du gjort ännu inte har trätt i kraft, kontrollera fliken **Väntande**. Din kyrkoadministratör kan behöva godkänna den först.
:::

## Kontoinställningar

Fliken **Konto** ger tillgång till dina säkerhetsinställningar. Använd den här fliken för att hantera inställningar som rör din kontoåtkomst och säkerhet.

## Sammanfattning av profilflikar

| Flik | Syfte |
|---|---|
| **Profil** | [Redigera dina personuppgifter](./editing-profile.md) och foto |
| **Hushåll** | [Visa dina familjemedlemmar](./household.md) |
| **Synlighet** | Styr vad andra ser i katalogen |
| **Väntande** | Granska profiländringar som väntar på godkännande |
| **Konto** | Hantera säkerhetsinställningar |

Dessa flikar fungerar tillsammans för att ge dig full kontroll över dina personuppgifter och hur de delas inom din kyrkogemenskap.
