# Hushåll

<div class="article-intro">

Fliken **Hushåll** på skärmen Profil visar dina familjemedlemmar. Här kan du se vem som ingår i ditt hushåll och hur medlemmarna är kopplade till varandra, vilket är nödvändigt för funktioner som incheckning.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- [Installera B1 Mobile](../getting-started/installing.md) och [logga in](../getting-started/logging-in.md) på ditt konto

</div>

## Vad du kommer att se

När du öppnar fliken **Hushåll** ser du en lista över personerna i ditt hushåll. Varje medlems post visar:

- **Namn** -- Personens för- och efternamn
- **Roll** -- Deras roll inom hushållet (till exempel Huvudperson eller Annan)
- **Profilbild** -- Deras bild, om en har laddats upp

Ditt hushåll är en gemensam grupp som binder samman dina familjemedlemmar inom kyrkans system.

## Varför hushåll är viktigt

Informationen om ditt hushåll används av flera funktioner i B1 Mobile och inom hela ChurchApps:

- **Incheckning** -- När du [checkar in](../checkin/self-checkin.md) till en gudstjänst eller ett evenemang kan du checka in hela ditt hushåll på en gång i stället för att checka in varje person separat.
- **Kyrkans register** -- Din kyrka använder hushållsdata för att hålla familjeregistren ordnade och för att kommunicera med din familj som en enhet.
- **Katalog** -- Andra medlemmar kan se din hushållsinformation i [medlemskatalogen](../community/member-directory.md), beroende på dina [integritetsinställningar](./privacy-settings.md).

## Visa ditt hushåll

1. Öppna sidomenyn och tryck på **Profil**.
2. Välj fliken **Hushåll**.
3. Bläddra igenom listan över familjemedlemmar i ditt hushåll.

:::info
Hushållsmedlemskap hanteras vanligtvis av kyrkans administratör. Om du behöver lägga till eller ta bort någon från ditt hushåll, kontakta kyrkans kansli för hjälp.
:::

## Håll informationen uppdaterad

Om en familjemedlems uppgifter behöver uppdateras kan de [redigera sin egen profil](./editing-profile.md), eller så kan du kontakta kyrkans administratör för att göra ändringar. Att hålla hushållsinformationen korrekt säkerställer att funktioner som [incheckning](../checkin/index.md) fungerar smidigt för hela din familj.
