# Evenemang

<div class="article-intro">

Funktionen Evenemang i B1 Mobile låter dig bläddra bland kommande kyrkliga evenemang och anmäla dig direkt från din telefon. När din kyrka aktiverar registrering för ett evenemang kan du anmäla dig själv och dina familjemedlemmar med bara några tryck.

</div>

## Hitta evenemang med registrering

Evenemang med registrering aktiverad visas i dina gruppkalendrar. När du trycker på ett evenemang där registrering är tillgänglig ser du en knapp **Registrera** i evenemangets detaljer.

Evenemang kan visa olika statusar:

- **Öppen** -- Registrering är tillgänglig och du kan anmäla dig.
- **Ännu inte öppen** -- Registreringsperioden har ännu inte börjat.
- **Stängd** -- Registreringsfristen har passerat.
- **Fullbokad** -- Alla tillgängliga platser är tagna.

## Vad du behöver

- [B1 Mobile installerad](../getting-started/installing) och [inloggad](../getting-started/logging-in)
- Din kyrka måste ha evenemangsregistrering aktiverad för evenemanget
