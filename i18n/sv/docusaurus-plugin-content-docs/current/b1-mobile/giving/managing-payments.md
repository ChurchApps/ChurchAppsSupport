# Hantera betalningsmetoder

<div class="article-intro">

Fliken **Hantera** i avsnittet för gåvor låter dig visa och hantera dina sparade betalningsmetoder. Genom att spara ett kort kan du göra framtida gåvor snabbare utan att behöva ange dina uppgifter varje gång.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- [Installera B1 Mobile](../getting-started/installing) och [logga in](../getting-started/logging-in) på ditt konto

</div>

## Visa dina betalningsmetoder

När du öppnar fliken **Hantera** ser du en lista över alla dina sparade betalningsmetoder. Varje post visar korttypen och de sista fyra siffrorna i kortnumret, så att du enkelt kan se vilket kort som är vilket.

## Lägga till en ny betalningsmetod

För att lägga till ett nytt kort:

1. Öppna avsnittet **Gåvor** i B1 Mobile.
2. Tryck på fliken **Hantera**.
3. Tryck på alternativet för att lägga till en ny betalningsmetod.
4. Ange dina kortuppgifter. Uppgifterna skickas säkert till **Stripe** för behandling.
5. När kortet har sparats visas det nya kortet i din lista över betalningsmetoder.

Ditt sparade kort blir sedan tillgängligt som betalningsalternativ nästa gång du [gör en gåva](./making-donations) från fliken **Donera**.

## Ta bort en betalningsmetod

Om du inte längre vill ha ett kort sparat kan du ta bort det från fliken **Hantera**:

1. Hitta kortet du vill ta bort i din lista över sparade betalningsmetoder.
2. Tryck på alternativet för att ta bort kortet bredvid det.
3. Bekräfta borttagningen.

Kortet visas inte längre som betalningsalternativ när du gör en gåva.

:::info
Att ta bort en betalningsmetod påverkar inte tidigare gåvor. Din [gåvohistorik](./donation-history) förblir oförändrad.
:::

:::tip
Behåll minst en betalningsmetod sparad för snabb givning. På så sätt kan du använda knappen **Upprepa** på fliken **Översikt** för att ge igen med ett enda tryck.
:::
