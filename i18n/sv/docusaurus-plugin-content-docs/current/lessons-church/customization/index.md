# Anpassning

<div class="article-intro">

Lessons.church erbjuder ett bibliotek med färdigt lektionsinnehåll, men varje församling är olika. Anpassningsfunktionerna låter dig skräddarsy lektionsinnehållet så att det passar just dina klassrum, din undervisningsstil och dina åldersgrupper, så att dina volontärer bara ser det som är relevant för dem.

</div>

## Varför anpassa?

Lektionsinnehållet på Lessons.church är utformat för att vara flexibelt. En enskild lektion kan innehålla avsnitt för flera åldersgrupper, valfria aktiviteter eller roller som inte gäller för varje klassrum. I stället för att be dina volontärer att själva hoppa över delar som inte är aktuella kan du anpassa lektionen så att de bara ser det som är relevant för dem.

Till exempel kan en lektion innehålla en hantverksaktivitet som fungerar utmärkt för förskolebarn men som inte passar i din femteklassgrupp. Med anpassning kan du dölja det avsnittet för de äldre barnen men behålla det för de yngre.

## Vad du kan anpassa

- **Ta bort avsnitt** -- Dölj hela avsnitt i en lektion som inte gäller för ett visst klassrum eller en viss åldersgrupp.
- **Dölj roller eller åtgärder** -- Ta bort enskilda roller eller åtgärder inom ett avsnitt om de inte behövs.
- **Ändra ordning på innehållet** -- Flytta om avsnitt och åtgärder så att flödet passar ditt klassrum bäst.

## Klassrumsspecifik eller global

När du sparar en anpassning väljer du hur brett den ska gälla:

- **Ett enskilt klassrum** -- Anpassningen påverkar bara det aktuella klassrummet. Andra klassrum ser det ursprungliga innehållet.
- **Alla klassrum** -- Anpassningen gäller för alla klassrum i din församling.

Den här flexibiliteten gör att du kan skapa olika vyer av samma lektion för olika åldersgrupper, eller göra en ändring som gäller överallt på en gång.

:::tip
Om du är ny på anpassning bör du börja med ett enskilt klassrum för att se hur det fungerar innan du tillämpar ändringar på alla klassrum.
:::
