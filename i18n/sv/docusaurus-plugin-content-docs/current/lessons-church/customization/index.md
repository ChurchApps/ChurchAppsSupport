# Anpassning

<div class="article-intro">

Lessons.church erbjuder ett bibliotek med färdigt lektionsinnehåll, men varje församling är unik. Anpassningsfunktionerna låter dig skräddarsy lektionsinnehållet efter dina specifika klassrum, undervisningsstil och åldersgrupper, så att dina volontärer bara ser det som är relevant för dem.

</div>

## Varför anpassa?

Lektionsinnehållet på Lessons.church är utformat för att vara flexibelt. En enskild lektion kan innehålla avsnitt för flera åldersgrupper, valfria aktiviteter eller roller som inte gäller för varje klassrum. I stället för att be dina volontärer att mentalt hoppa över delar som inte är relevanta kan du anpassa lektionen så att de bara ser det som gäller dem.

Till exempel kan en lektion innehålla en hantverksaktivitet som passar förskolebarn utmärkt men inte är lämplig för din femteklassskola. Med anpassning kan du dölja det avsnittet för den äldre gruppen samtidigt som du behåller det för den yngre.

## Vad du kan anpassa

- **Ta bort avsnitt** -- Ta bort hela avsnitt i en lektion som inte gäller för ett specifikt klassrum eller en åldersgrupp.
- **Ta bort roller eller åtgärder** -- Ta bort enskilda roller eller åtgärder inom ett avsnitt om de inte behövs.
- **Ordna om innehåll** -- Flytta om avsnitt och åtgärder för att passa det flöde du föredrar för ditt klassrum.

## Klassrumsspecifikt eller globalt

Varje gång du gör en ändring väljer du hur brett den ska gälla:

- **Detta klassrum** -- Ändringen påverkar endast det aktuella klassrummet. Andra klassrum ser det ursprungliga innehållet.
- **Alla klassrum** -- Ändringen gäller för varje klassrum i din församling.

Den här flexibiliteten innebär att du kan skapa olika vyer av samma lektion för olika åldersgrupper, eller göra en ändring som gäller överallt på en gång.

:::tip
Om du är ny på anpassning, börja med ett enskilt klassrum för att se hur det fungerar innan du tillämpar ändringar på alla klassrum.
:::
