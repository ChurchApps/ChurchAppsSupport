# Komma igång

<div class="article-intro">

Lessons.church är helt gratis att använda. Det finns inga prenumerationer, ingen provperiod och inga funktionsbegränsningar. Det här avsnittet guidar dig genom att skapa ditt konto, koppla din församling och navigera i portalen så att du kan börja schemalägga lektioner direkt.

</div>

## Det här behöver du

För att komma igång med Lessons.church behöver du:

1. **Skapa ett konto** -- Registrera dig på [Lessons.church](https://lessons.church) med ditt namn, din e-postadress och ett lösenord. Detta använder samma ChurchApps-konto som du kanske redan har från B1.church.
2. **Koppla din församling** -- Efter registreringen ansluter du till din befintliga församlingsprofil eller skapar en ny. Detta kopplar dina klassrum och scheman till din församling.
3. **Ställ in klassrum** -- Skapa klassrum som passar din verksamhet (till exempel "Förskola", "Årskurs 1–3" eller "Ungdom"). Klassrum är där du schemalägger och organiserar lektioner.
4. **Börja schemalägga lektioner** -- Bläddra i innehållsbiblioteket, hitta ett studiematerial som passar dina behov och schemalägg lektioner till dina klassrum.

När dina klassrum är inställda och lektionerna schemalagda kan dina volontärer komma åt innehållet via portalen och presentera lektionerna för sina klasser.

:::tip
Om du redan har ett ChurchApps-konto från B1.church kan du logga in på Lessons.church med samma uppgifter -- du behöver inte registrera dig igen.
:::
