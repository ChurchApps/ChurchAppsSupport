# Portalöversikt

<div class="article-intro">

När du har loggat in på Lessons.church kommer du till **Portalen** -- din kyrkas instrumentpanel för att hantera klassrum och lektionsscheman. Det är här du kommer att tillbringa större delen av tiden när du organiserar läroplanen för din kyrka.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- [Skapa ett konto](./creating-account.md) och anslut till din kyrka
- Logga in på [Lessons.church](https://lessons.church)

</div>

## Vad du ser

Portalen är indelad i två huvudområden:

- **Klassrum** (till höger) -- En lista över din kyrkas klassrum. Klicka på ett klassrumsnamn för att se dess schemalagda lektioner. Du kan också lägga till nya klassrum eller redigera befintliga härifrån.
- **Schemalagda lektioner** (till vänster) -- När du har valt ett klassrum visas här de lektioner som har schemalagts för det. Om du ännu inte har skapat några klassrum ser du en videoguide för installation som hjälper dig komma igång.

## Vad du kan göra från portalen

Från portalen kan du:

1. **Hantera klassrum** -- Lägg till, redigera eller ta bort klassrum. Varje klassrum kan kopplas till ett volontärteam (så att de ser kommande lektioner i B1-appen) och en förälder-/elevgrupp (så att de kan komma åt de senaste lektionerna). Kyrkor som fortfarande använder den här klassrumsvägen: föräldrar öppnar klassrumssidan (utan `?upcoming=1`) för att se material att ta med hem. Kyrkor som använder B1Admin-plantyper ser i stället kortet med material att ta med hem på den tillhörande gruppens sida i B1.
2. **Visa och hantera schemalagda lektioner** -- Se vilka lektioner som är på väg för varje klassrum och gör ändringar vid behov.
3. **Prenumerera på klassrumsflöden** -- Klicka på flöderikonen bredvid ett klassrum för att få en spellisteadress (feed-URL) som du kan använda i kompatibla appar.
4. **Använd externa leverantörer** -- Använd sidan **Externa leverantörer** för att konfigurera tredjepartsinnehållskällor som stöder Open Lesson Format. Det gör att du kan hämta lektioner från andra leverantörer utöver det inbyggda Lessons.church-biblioteket.
5. **Öppna adminområdet** -- Om du har adminbehörighet ser du alternativet **Admin** i navigeringen. Adminområdet låter dig hantera program, studier och lektioner på innehållsnivå.

## Navigering

Portalens navigering innehåller:

- **Start** -- Gå tillbaka till Lessons.churchs publika startsida för att bläddra bland innehållet.
- **Scheman** -- Portalens huvudvy för att hantera klassrum och lektionsscheman.
- **Externa leverantörer** -- Konfigurera tredjepartsleverantörer av lektioner.
- **Admin** -- Hantera program, studier och lektionsinnehåll (syns endast om du har adminbehörighet).

:::info
Alternativet **Admin** visas endast om ditt konto har beviljats behörighet att redigera innehåll. De flesta medarbetare i kyrkan kommer att använda sidorna **Scheman** och **Externa leverantörer** för den dagliga hanteringen.
:::

## Komma igång

Om du besöker portalen för första gången och ännu inte har skapat några klassrum, börja med att klicka på **Lägg till första klassrum** i klassrumspanelen. Ge ditt klassrum ett namn (till exempel "Förskola" eller "Årskurs 3-5") och spara det. Därifrån kan du börja [schemalägga lektioner](../classrooms/scheduling-lessons.md).
