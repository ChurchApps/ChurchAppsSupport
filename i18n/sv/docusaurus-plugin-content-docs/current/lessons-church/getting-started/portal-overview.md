# Portalöversikt

<div class="article-intro">

Efter inloggning på Lessons.church kommer du till **portalen** -- din kyrkas instrumentpanel för att hantera klassrum och lektionsscheman. Det är här du kommer att tillbringa större delen av tiden när du organiserar läroplanen för din kyrka.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- [Skapa ett konto](./creating-account.md) och anslut till din kyrka
- Logga in på [Lessons.church](https://lessons.church)

</div>

## Vad du ser

Portalen öppnas på sidan **Klassrumshantering**, som är indelad i två huvudområden:

- **Klassrum** (till höger) -- En lista över din kyrkas klassrum. Klicka på ett klassrumsnamn för att se dess schemalagda lektioner. Du kan även lägga till nya klassrum eller redigera befintliga härifrån.
- **Lektionsschema** (till vänster) -- När du har valt ett klassrum visas de lektioner som har schemalagts för det i detta område. Om du inte har konfigurerat några klassrum än ser du en installationsvideo som hjälper dig komma igång.

## Vad du kan göra från portalen

Från portalen kan du:

1. **Hantera klassrum** -- Lägg till, redigera eller ta bort klassrum. Varje klassrum kan kopplas till ett volontärteam (så att de ser kommande lektioner i B1-appen) och till en förälder-/elevgrupp (så att de kan komma åt senaste lektionerna). Kyrkor som fortfarande använder denna klassrumsschemaväg: föräldrar öppnar klassrumssidan (utan `?upcoming=1`) för att se hemmaterialet. Kyrkor som använder B1Admin-plantyper ser i stället hemmaterialkortet på den tillhörande gruppens sida i B1.
2. **Visa och hantera schemalagda lektioner** -- Se vilka lektioner som är på väg för varje klassrum och gör ändringar vid behov.
3. **Prenumerera på klassrumsflöden** -- Klicka på flödesikonen bredvid ett klassrum för att få en spellistelänk som du kan använda med kompatibla appar.
4. **Öppna externa leverantörer** -- Använd sidan **Externa leverantörer** för att konfigurera tredjepartsinnehållskällor som stöder Open Lesson Format. Detta gör det möjligt att hämta lektioner från andra leverantörer utöver det inbyggda Lessons.church-biblioteket.
5. **Öppna administrationsytan** -- Om du har administratörsbehörighet ser du alternativet **Admin** i navigeringen. Administrationsytan låter dig hantera program, studier och lektioner på innehållsnivå.

## Navigering

Portalens navigering innehåller:

- **Hem** -- Återgå till Lessons.churchs offentliga startsida för att bläddra bland innehållet.
- **Scheman** -- Portalens huvudvy för att hantera klassrum och lektionsscheman.
- **Externa leverantörer** -- Konfigurera tredjepartsleverantörer av lektioner.
- **Admin** -- Hantera program, studier och lektionsinnehåll (syns endast om du har administratörsbehörighet).

:::info
Alternativet **Admin** visas endast om ditt konto har beviljats behörighet att redigera innehåll. De flesta medarbetare i kyrkan använder sidorna **Scheman** och **Externa leverantörer** för den dagliga hanteringen.
:::

## Komma igång

Om du besöker portalen för första gången och inte har skapat några klassrum ännu, börja med att klicka på **Lägg till första klassrum** i klassrumspanelen. Ge ditt klassrum ett namn (till exempel "Förskola" eller "3-5 klass") och spara. Därefter kan du börja [schemalägga lektioner](../classrooms/scheduling-lessons.md).
