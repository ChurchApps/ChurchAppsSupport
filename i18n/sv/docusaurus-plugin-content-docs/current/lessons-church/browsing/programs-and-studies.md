# Program och studier

<div class="article-intro">

Allt läroplansmaterial på Lessons.church är organiserat i en tydlig hierarki. Om du förstår den strukturen hittar du snabbt rätt innehåll för din kyrka och kan enkelt navigera mellan relaterade lektioner.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- Läs översikten [Bläddra bland innehåll](./index.md) för att förstå de olika sätten att hitta innehåll

</div>

## Innehållets hierarki

Innehållet är ordnat från det bredaste till det mest specifika:

- **Leverantör** -- Organisationen som publicerar läroplanen (Lessons.church eller en tredjepartsleverantör).
- **Program** -- En läroplansserie, till exempel "Ark Kids" eller "NextLevel". Varje program är en samling relaterade studier kring ett tema eller en åldersgrupp.
- **Studie** -- En enhet inom ett program, till exempel "Den barmhärtige samariern". Varje studie innehåller en uppsättning lektioner som är avsedda att undervisas tillsammans, ofta under flera veckor.
- **Lektion** -- En enskild undervisningssession inom en studie. Varje lektion innehåller avsnitt, roller, aktiviteter och material som kan laddas ner.
- **Variant** -- En åldersanpassad version av en lektion, till exempel Förskola eller Lågstadiet. Med varianter kan du anpassa samma lektion för olika målgrupper.

## Bläddra bland program

Så här utforskar du program:

1. Gå till startsidan för Lessons.church.
2. Scrolla igenom listan över tillgängliga program eller titta på de utvalda programmen överst.
3. Klicka på ett **programnamn** eller dess bild för att öppna programsidan.

Varje programsida innehåller:

- **Beskrivning** -- En översikt över vad läroplanen omfattar och vem den är avsedd för.
- **Programbild** -- En visuell identitet för serien.
- **Videotrailer** -- Vissa program har en kort videoförhandsvisning så att du kan se stil och kvalitet på innehållet innan du väljer det.
- **Studier** -- En lista över alla studier i programmet, som kan vara indelade i kategorier.

## Bläddra bland studier

Från en programsida:

1. Bläddra i listan över studier. Om programmet delar in studierna i kategorier visas de grupperade på motsvarande sätt.
2. Klicka på ett **studienamn** för att öppna studiesidan.
3. Studiesidan visar alla lektioner som ingår i studien, listade i undervisningsordning.

Härifrån kan du klicka på valfri lektion för att se hela innehållet, inklusive avsnitt, roller och material som kan laddas ner. Se [Visa lektioner](./viewing-lessons.md) för en detaljerad genomgång.

:::info
Program och studier hanteras av läroplansleverantörer. Om du är innehållsskapare kan du hantera egna program och studier i området [Administration](../admin/index.md).
:::
