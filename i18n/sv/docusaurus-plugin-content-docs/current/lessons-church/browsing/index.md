# Bläddra i innehåll

<div class="article-intro">

Lessons.church erbjuder ett kostnadsfritt bibliotek med kyrkliga läroplaner som vem som helst kan utforska. Du behöver varken konto eller inloggning för att bläddra i det tillgängliga innehållet -- besök bara webbplatsen och börja titta runt. Det här avsnittet beskriver alla sätt att hitta och utforska läroplanerna.

</div>

## Startsidan

När du första gången kommer till Lessons.church ger startsidan dig en snabb överblick över allt som finns tillgängligt:

- **Utvalda program** -- Utvalda läroplansserier visas överst, vilket gör det lätt att upptäcka populärt eller nyligen uppdaterat innehåll.
- **Alla program** -- Under det utvalda avsnittet hittar du en fullständig lista över varje tillgängligt läroplansprogram, tillsammans med statistik som antal lektioner och studier i varje program.
- **Innehåll från leverantörer** -- Innehåll från både Lessons.church och externa läroplansleverantörer visas tillsammans, så att du har en enda plats att utforska.

## Sätt att hitta innehåll

Det finns flera sätt att navigera i läroplansbiblioteket:

1. **Bläddra efter program** -- Klicka på valfritt program på startsidan för att se dess studier och lektioner. Detta är det bästa sättet när du vill utforska en specifik läroplansserie. Se [Program och studier](./programs-and-studies.md) för mer information.

2. **Sök** -- Använd söksidan för att hitta lektioner med nyckelord i hela biblioteket. Detta är till hjälp när du känner till ett ämne men inte vet vilket program som täcker det. Se [Sökning](./searching.md) för mer information.

3. **Utforska externa leverantörer** -- En del innehåll kommer från tredjepartsleverantörer av läroplaner som publicerar i Open Lesson Format. Du kan bläddra bland deras program och studier precis som med det inbyggda innehållet. Se [Externa leverantörer](./external-providers.md) för mer information.

## Ingen inloggning krävs

Bläddring är helt öppen. Du kan visa program, studier, lektioner, nedladdningsbart material och videor utan att skapa ett konto. Om du senare vill schemalägga lektioner för dina klassrum eller anpassa innehållet kan du [skapa ett kostnadsfritt konto](../getting-started/creating-account.md) då.

:::tip
Börja med att utforska några program på startsidan för att få en känsla för hur läroplanen är organiserad innan du går in på en specifik studie.
:::
