# Visa lektioner

<div class="article-intro">

Varje lektion på Lessons.church är ett komplett undervisningspass med strukturerat innehåll, material som kan laddas ner och stöd för flera åldersgrupper. Den här guiden förklarar hur du navigerar och använder en lektionssida för att förbereda din klass.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- Läs om hur innehållet är organiserat i [Program och studier](./programs-and-studies.md)
- Bläddra till ett program och en studie för att hitta lektionen du vill visa

</div>

## Så hittar du en lektion

För att visa en lektion navigerar du genom innehållshierarkin:

1. Klicka på ett **program** på startsidan.
2. Välj en **studie** på programsidan.
3. Klicka på den **lektion** du vill visa på studiesidan.

## Det här ser du

Lektionssidan är indelad i flera områden:

### Video

Om lektionen innehåller en video visas den överst på sidan. Klicka för att spela upp den direkt i webbläsaren. Videor används ofta som huvudsegment i undervisningen, särskilt inom barnverksamheten.

### Avsnitt och roller

Varje lektion är indelad i **avsnitt** (till exempel "Inledning", "Bibelberättelse", "Aktivitet" och "Avslutning"). Inom varje avsnitt är innehållet organiserat efter **roll**:

- **Ledare** -- Den främsta läraren eller presentatören
- **Hjälpare** -- Stödjande volontärer
- Andra anpassade roller som läroplanens skapare har definierat

Varje roll listar sina **åtgärder**, som talar om för volontären exakt vad som ska göras:

- **Säg** -- Manus eller talpunkter att läsa upp
- **Gör** -- Fysiska instruktioner eller aktiviteter att utföra
- **Notera** -- Bakgrundsinformation eller tips till volontären
- **Spela** -- Signaler för att spela upp en video- eller ljudklipp

### Material att ladda ner

Lektioner kan innehålla filer som du kan ladda ner och skriva ut, till exempel:

- PDF-häften
- Aktivitetsblad
- Målarbilder
- Hantverksinstruktioner
- Hemlektioner för föräldrar

Leta efter nedladdningslänkar på lektionssidan för att komma åt dessa resurser. Se [Nedladdningar och material](../presenting/downloads.md) för mer information om hur du förbereder utskrivna resurser.

## Växla mellan åldersgrupper

Många lektioner stöder flera **åldersgrupper**, som representerar olika åldersgrupper såsom Förskola, Mellanstadie eller Pre-tonår. Åldersgrupper gör det möjligt att anpassa samma lektionsämne till rätt nivå för varje grupp.

Så här växlar du mellan åldersgrupper:

1. Leta efter **väljaren för åldersgrupp** på lektionssidan.
2. Klicka på ett annat namn på åldersgrupp (till exempel byt från **Mellanstadie** till **Förskola**).
3. Sidan uppdateras och visar innehållet, manuset och materialet som är utformat för den åldersgruppen.

:::tip
Om du undervisar flera åldersgrupper bör du granska varje åldersgrupp innan passet så att du ser hur innehållet anpassas för olika nivåer.
:::
