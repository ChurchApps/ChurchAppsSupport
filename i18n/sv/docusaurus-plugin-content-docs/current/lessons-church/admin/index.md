# Administration

<div class="article-intro">

Administrationsområdet i Lessons.church är där innehållsskapare och administratörer hanterar lektionsbiblioteket. Härifrån kan du bygga upp din läroplansstruktur, ladda upp resurser, granska användningsstatistik och ansluta tredjepartsleverantörer av innehåll.

</div>

:::warning
Administratörsåtkomst kräver lämpliga behörigheter. Om du inte ser administrationsalternativen, kontakta din kyrkoadministratör för att begära åtkomst.
:::

## Vad du kan göra

Administrationsområdet ger dig full kontroll över ditt innehåll:

- **Skapa och redigera program** -- Ställ in övergripande läroplanserier med namn, beskrivningar, bilder och slugs.
- **Hantera studier** -- Organisera grupper av relaterade lektioner inom varje program.
- **Bygga lektioner** -- Lägg till enskilda lektioner med platser, avsnitt, roller och åtgärder.
- **Ladda upp resurser** -- Bifoga nedladdningsbara filer (PDF:er, aktivitetsblad, bilder) på program-, studie- eller lektionsnivå.
- **Visa statistik** -- Se vilket innehåll som laddas ner, av vem och var.
- **Konfigurera leverantörer** -- Anslut externa läroplansleverantörer som använder Open Lesson Format. Detta görs från sidan **External Providers**, inte från administrationsområdet.
- **Årsplaner** -- Publicera vecka 1, 2, 3… följder för valfri läroplan. Kyrkor tillämpar dem i B1 Admin.

## Innehållshierarki

Som administratör är det bra att förstå hur innehållet är strukturerat:

1. **Program** innehåller en eller flera studier.
2. **Studier** innehåller en eller flera lektioner.
3. **Lektioner** innehåller en eller flera platser (variationer för åldersgrupper).
4. **Platser** innehåller avsnitt, och avsnitt innehåller rollbaserade åtgärder.

Varje nivå kan ha sina egna nedladdningsbara resurser bifogade.
