# Administration

<div class="article-intro">

Adminytan i Lessons.church är där innehållsskapare och administratörer hanterar lektionsbiblioteket. Här kan du bygga upp din läroplansstruktur, ladda upp material, granska användningsstatistik och koppla externa innehållsleverantörer.

</div>

:::warning
Adminåtkomst kräver lämpliga behörigheter. Om du inte ser adminalternativen, kontakta din församlingsadministratör för att begära åtkomst.
:::

## Vad du kan göra

Adminytan ger dig full kontroll över ditt innehåll:

- **Skapa och redigera program** -- Ställ in övergripande läroplansserier med namn, beskrivningar, bilder och slugs.
- **Hantera studier** -- Organisera grupper av relaterade lektioner inom varje program.
- **Bygga lektioner** -- Lägg till enskilda lektioner med venues, avsnitt, roller och åtgärder.
- **Ladda upp material** -- Bifoga nedladdningsbara filer (PDF:er, aktivitetsblad, bilder) på program-, studie- eller lektionsnivå.
- **Visa statistik** -- Se vilket innehåll som laddas ner, av vem och var.
- **Konfigurera leverantörer** -- Anslut externa läroplansleverantörer som använder Open Lesson Format.
- **Årsplaner** -- Publicera sekvenser för vecka 1, 2, 3 … för valfri läroplan. Församlingar tillämpar dem i B1 Admin.

## Innehållets struktur

Som administratör är det bra att förstå hur innehållet är strukturerat:

1. **Program** innehåller en eller flera studier.
2. **Studier** innehåller en eller flera lektioner.
3. **Lektioner** innehåller en eller flera venues (variationer för åldersgrupper).
4. **Venues** innehåller avsnitt, och avsnitt innehåller rollbaserade åtgärder.

Varje nivå kan ha egna nedladdningsbara resurser bifogade.
