# Hantera årsplaner

<div class="article-intro">

En årsplan är en ordnad lista med lektioner — vecka 1, vecka 2, vecka 3 — som kyrkor tillämpar i B1 Admin. Du kan publicera en plan för vilket läroplansmaterial som helst i biblioteket. Valfria kalenderfält talar om för B1 Admin vilken månad vecka 1 tillhör och vilka veckor som måste infalla på påsk eller jul.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- Ha administratörsbehörighet för Lessons.church
- Ha minst ett [program](./managing-programs.md) med publicerade lektioner

</div>

## Skapa en plan

1. Öppna **Admin → Årsplaner**.
2. Klicka på **Lägg till**.
3. Ange ett namn (till exempel "Barn 2026–27" eller "High Voltage År 1") och eventuellt ett slug.
4. Ange eventuellt en **standardplatspreferens** — kommaseparerade platsnamn som används när en vecka inte anger någon plats.
5. Ange eventuellt **Året börjar i** (till exempel januari) så att kyrkor tillämpar planen mot ett verkligt kalenderår i stället för ett fristående startdatum.
6. Markera **Publicera** när kyrkor ska kunna se planen i B1 Admin. Lämna den avmarkerad för ett utkast.
7. Lägg till veckor från valfritt läroplansmaterial: välj en **källa** och sedan program, studie, lektion och plats. Klicka på **Lägg till**. En enskild plan kan blanda program om du vill. Använd pilarna för att ändra ordningen.
8. För säsongsbetonade studier, ställ in en veckas **Ankare** till påsk eller jul. Ankra studiens sista vecka så att serien hamnar på söndagarna före den högtiden.
9. Spara.

Kyrkor tillämpar en publicerad plan från **B1 Admin → Serving → Plans → Schedule Lesson → Apply Year Plan**. Kalenderankrade planer frågar efter ett målår och ett datumintervall; andra planer använder fortfarande ett första klassdatum och antal veckor. Därefter redigerar de enskilda veckor där; FreePlay spelar upp det som finns i planen.
