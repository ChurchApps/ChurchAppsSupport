# Hantera program

<div class="article-intro">

Program är de översta behållarna för läroplaner i Lessons.church. Ett program representerar en hel läroplansserie, till exempel "Ark Kids" eller "Youth Foundations". Den här guiden beskriver hur du skapar, redigerar och organiserar program i administrationsområdet.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- Ha administratörsbehörighet för Lessons.church (se [Översikt över administration](./index.md))
- Förbered ett programnamn, en beskrivning och en miniatyrbild

</div>

## Skapa ett program

1. Gå till området **Admin**.
2. Klicka på **Lägg till program**.
3. Fyll i följande fält:
   - **Namn** -- Det visningsnamn som programmet ska ha (t.ex. "Ark Kids").
   - **Slug** -- En URL-vänlig identifierare (t.ex. "ark-kids"). Den används i webbadresser.
   - **Beskrivning** -- En kort sammanfattning av vad programmet täcker.
   - **Bild** -- Ladda upp en miniatyrbild som representerar programmet.
4. Spara programmet.

Ditt nya program visas nu i programlistan i administrationen och, när det har studier och lektioner, på den publika webbplatsen.

## Redigera ett program

1. Klicka på programmets namn i administrationslistan.
2. Uppdatera valfria fält (**Namn**, **Slug**, **Beskrivning** eller **Bild**).
3. Spara dina ändringar.

## Organisera studier inom ett program

När ett program finns kan du lägga till studier i det. Studierna visas nästlade under programmet i administrationsvyn. Klicka på expandera-pilen bredvid ett program för att se dess studier, eller lägg till en ny därifrån. Se [Hantera studier](./managing-studies.md) för mer information.

## Studiekategorier

Om ditt program har många studier kan du ordna dem i **kategorier**. Kategorier grupperar studier efter ämne, åldersintervall eller andra kriterier du väljer. Det gör det enklare för användare att bläddra i ett stort program.

## Ladda upp programövergripande resurser

Du kan bifoga nedladdningsbara filer till ett program. Dessa resurser gäller för programmet som helhet snarare än för en specifik studie eller lektion, till exempel ett dokument med omfattning och progression eller en handbok för volontärer.

1. Öppna programmet i administrationsvyn.
2. Gå till avsnittet **Resurser**.
3. Ladda upp dina filer.

## Rensa cacheminnet

Efter att du har gjort ändringar i ett program kan du behöva rensa cacheminnet för att uppdateringarna ska synas på den publika webbplatsen. Använd alternativet **Rensa cache** i administrationsområdet för att uppdatera innehållet.

:::tip
Välj ett beskrivande programnamn och skriv en tydlig beskrivning. Det här är det första kyrkor ser när de bläddrar i läroplansbiblioteket, så en bra sammanfattning hjälper dem att avgöra om programmet passar deras behov.
:::
