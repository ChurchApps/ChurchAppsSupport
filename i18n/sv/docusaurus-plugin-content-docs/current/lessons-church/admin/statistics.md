# Statistik

<div class="article-intro">

Statistiksidan ger administratörer insikt i hur deras innehåll används. Du kan se vilka studier som är mest populära, vilka kyrkor som laddar ner dina resurser och var dessa kyrkor finns geografiskt.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- Ha administratörsbehörighet för Lessons.church (se [Administrationsöversikt](./index.md))
- Ha minst ett [program](./managing-programs.md) med publicerat innehåll

</div>

## Så öppnar du statistiken

1. Gå till området **Admin**.
2. Välj sidan **Stats** eller **Statistics**.
3. Välj det **program** vars statistik du vill se.

## Vad du kan se

Statistiksidan visar flera vyer av dina nedladdningsdata:

### Nedladdningar per studie

En uppdelning av unika nedladdningar för varje studie inom det valda programmet. Här ser du vilka serier som får mest genomslag, vilket hjälper dig att avgöra var du ska lägga din tid på att skapa innehåll.

### Kyrkolista

En lista över kyrkor som har laddat ner resurser från ditt program. Den ger dig en uppfattning om din publik och hur brett ditt innehåll används.

### Geografisk fördelning

En kartvy som visar var kyrkorna som laddar ner finns. Den hjälper dig att förstå hur långt din läroplan når geografiskt och att identifiera regioner där ditt innehåll är populärt.

### Filtrering på datumintervall

Du kan filtrera all statistik efter ett datumintervall för att fokusera på en viss tidsperiod. Det är användbart för att se trender över tid eller för att mäta effekten av en nyligen släppt studie.

1. Ange **startdatum** och **slutdatum** med datumväljarna.
2. Statistiken uppdateras och visar endast aktivitet inom det intervallet.

## Så använder du statistiken effektivt

Här är några sätt att använda dina nedladdningsdata:

- **Identifiera populärt innehåll** -- Fokusera på att skapa mer material i de stilar och ämnen som får flest nedladdningar.
- **Följ nya släpp** -- Efter att du publicerat en ny studie kan du filtrera efter datum för att se hur snabbt den tas emot.
- **Förstå din publik** -- Använd kyrkolistan och kartan för att se vem som använder ditt innehåll, och överväg att nå ut till de församlingarna.

:::info
Statistiken baseras på unika nedladdningar. Om samma kyrka laddar ner en resurs flera gånger räknas den bara en gång.
:::
