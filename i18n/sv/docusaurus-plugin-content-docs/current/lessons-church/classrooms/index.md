# Klassrum

<div class="article-intro">

Klassrum är grunden för hur du organiserar undervisningen i din kyrka i Lessons.church. Ett klassrum representerar ett fysiskt eller virtuellt rum där lektioner hålls, till exempel "Förskolerummet", "Mellanstadiet F-2" eller "Vuxen bibelstudie". Det här avsnittet handlar om att skapa klassrum och schemalägga lektioner för dem.

</div>

## Varför klassrum är viktiga

När du skapar klassrum får du en tydlig struktur för barnverksamheten, ungdomsgrupperna eller andra undervisningsmiljöer. Varje klassrum får sitt eget schema, så dina volontärer vet alltid exakt vad de ska undervisa om och när. I stället för att skicka runt pappersscheman eller skicka brådskande mejl kan alla se i portalen vad som är på väg.

## Vad du kan göra med klassrum

- **Skapa obegränsat många klassrum** -- Skapa så många klassrum som din kyrka behöver. Det finns ingen gräns, så du kan ha separata klassrum för varje åldersgrupp, församlingsplats eller program.
- **Schemalägg lektioner** -- Tilldela specifika lektioner till varje klassrum på specifika datum. Ditt schema visar både tidigare och kommande lektioner på en överblick.
- **Anpassa innehåll** -- Skräddarsy lektionsinnehållet för varje klassrum så att volontärerna bara ser det som är relevant för deras åldersgrupp. Se [Anpassning](../customization/index.md) för mer information.

## Hur klassrum hänger ihop

Klassrummen kopplar lektionsinnehållet på Lessons.church till din kyrkas verkliga undervisningsschema. Så här ser det typiska arbetsflödet ut:

1. [Bläddra](../browsing/index.md) bland de tillgängliga programmen och studierna på Lessons.church.
2. Skapa dina klassrum så att de motsvarar kyrkans rum och åldersgrupper.
3. Schemalägg lektioner till varje klassrum för kommande datum.
4. Volontärerna öppnar sitt klassrum för att se vad som är schemalagt och förbereda sig.
