# Konfigurera klassrum

<div class="article-intro">

Innan du kan schemalägga lektioner behöver du skapa klassrum som representerar era undervisningsmiljöer. Den här guiden visar dig hur du skapar, namnger och hanterar klassrum i Lessons.church-portalen.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- [Skapa ett konto](../getting-started/creating-account.md) och anslut till din församling
- Bekanta dig med [Portalöversikten](../getting-started/portal-overview.md)

</div>

## Skapa ett klassrum

1. Logga in på ditt konto på [Lessons.church](https://lessons.church).
2. Gå till din **Portal**. Det här är din församlings centrala knutpunkt för hantering av klassrum och scheman.
3. I rutan **Classrooms** klickar du på **Add**. Om du inte har några klassrum ännu klickar du på **Add First Classroom** i stället.
4. Ange ett **Classroom Name**. Välj något beskrivande som dina volontärer känner igen, till exempel "Förskola", "Lågstadiet årskurs 1–2" eller "Mellanstadiet".
5. Klicka på **Save**. Ditt nya klassrum visas direkt i listan **Classrooms**.

Upprepa stegen för varje rum eller åldersgrupp i din församling. Du kan skapa så många klassrum som du behöver.

## Första gångens konfiguration

Om du inte har konfigurerat några klassrum ännu visar din portal en installationsvideo som guidar dig genom processen. Videon går igenom grunderna i att skapa klassrum och schemalägga dina första lektioner. Det är en bra utgångspunkt om du är ny på Lessons.church.

:::tip
Namnge dina klassrum så att de stämmer överens med hur dina volontärer redan tänker kring era rum. Om alla kallar det "Förskoleklassrummet" bör du namnge det "Förskola" i stället för något formellt som "Pedagogiskt rum 101 för tidig barndom".
:::

## Hantera klassrum

Dina klassrum visas på portalens instrumentpanel, där du när som helst kan hantera dem. Härifrån kan du:

- **Byta namn på ett klassrum** -- Klicka på ikonen **Edit classroom** (penna) bredvid det, ändra **Classroom Name** och klicka på **Save**.
- **Ta bort ett klassrum** -- Klicka på **Edit classroom**, klicka sedan på ikonen **Delete classroom** (papperskorg) och bekräfta.
- **Visa schemat** -- Klicka på ett klassrum för att se dess lektionsschema.

## Nästa steg

När dina klassrum är konfigurerade är du redo att börja [schemalägga lektioner](./scheduling-lessons.md) så att dina volontärer vet vad de ska undervisa om varje vecka.
