# Konfigurera klassrum

<div class="article-intro">

Innan du kan schemalägga lektioner behöver du skapa klassrum som representerar dina undervisningsmiljöer. Den här guiden visar dig hur du skapar, namnger och hanterar klassrum i Lessons.church-portalen.

</div>

<div class="prereqs">
<h4>Innan du börjar</h4>

- [Skapa ett konto](../getting-started/creating-account.md) och anslut till din församling
- Bekanta dig med [portalöversikten](../getting-started/portal-overview.md)

</div>

## Skapa ett klassrum

1. Logga in på ditt konto på [Lessons.church](https://lessons.church).
2. Gå till din **portal**. Det här är din församlings centrala knutpunkt för att hantera klassrum och scheman.
3. Klicka på **Lägg till klassrum**.
4. Ange ett namn för ditt klassrum. Välj något beskrivande som dina volontärer känner igen, till exempel "Förskola", "Lågstadiet åk F-2" eller "Mellanstadiet".
5. Spara ditt nya klassrum. Det visas direkt på din portals instrumentpanel.

Upprepa stegen för varje rum eller åldersgrupp i din församling. Du kan skapa så många klassrum som du behöver.

## Första gångens konfiguration

Om du inte har konfigurerat några klassrum än visar din portal en installationsvideo som guidar dig genom processen. Videon går igenom grunderna i att skapa klassrum och schemalägga dina första lektioner. Den är en bra utgångspunkt om du är ny på Lessons.church.

:::tip
Namnge dina klassrum så att de stämmer överens med hur dina volontärer redan tänker kring era rum. Om alla kallar det "förskolerummet" bör du namnge det "Förskola" snarare än något formellt som "Rum 101 för tidig barnpedagogik".
:::

## Hantera klassrum

Dina klassrum visas på portalens instrumentpanel, där du när som helst kan hantera dem. Härifrån kan du:

- **Byta namn på ett klassrum** -- Uppdatera namnet om dina rum eller åldersgrupper förändras.
- **Ta bort ett klassrum** -- Radera klassrum som du inte längre behöver.
- **Visa schemat** -- Klicka på valfritt klassrum för att se dess lektionsschema.

## Vad händer härnäst

När dina klassrum är konfigurerade är du redo att börja [schemalägga lektioner](./scheduling-lessons.md) så att dina volontärer vet vad de ska undervisa om varje vecka.
