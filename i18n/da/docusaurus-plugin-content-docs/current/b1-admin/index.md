# B1 Admin Oversigt

<div class="article-intro">

B1 Admin er dit kirkestyrings dashboard. Det giver værktøjer til at administrere ethvert aspekt af din kirkes operationer -- fra medlemmer kataloger og donationer til websted opbygning og live streaming -- alt fra ét sted.

</div>

## Kom i gang

1. Åbn din browser og gå til [admin.b1.church](https://admin.b1.church)
2. Log ind med dit brugernavn og adgangskode
3. Du lander på **Dashboard**, som giver en oversigt over dine kirkedata sammen med **Hurtige handlinger** til almindelige opgaver som tilføj folk, opret grupper, registrer donationer og mere

:::tip
Ny til B1 Admin? Start med [Introduktion](./introduction.md) til en video gennemgang, derefter besøg [Indstillinger](./settings/index.md) for at konfigurere dine kirkeoplysninger og inviter dit hold.
:::

## Vigtigste funktioner

- **[Folk](./people/index.md)** - Administrer dit kirkekatolog, tilføj medlemmer, spor husstande
- **[Grupper](./groups/index.md)** - Opret og organiser kirkegrupper, hold og ministerier
- **[Tilstedeværelse](./attendance/index.md)** - Opsætning af campusser, tjeneste gange, og spor tilstedeværelse
- **[Donationer](./donations/index.md)** - Registrer givning, administrer fonde, generer sætninger
- **[Tjeneste](./serving/index.md)** - Koordiner frivillige, opret tjenesteplaner, administrer opgaver
- **[Formularer](./forms/index.md)** - Byg tilpassede formularer til registreringer og dataindsamling
- **[Rapporter](./reports/index.md)** - Se fødselsdags-, tilstedeværelse- og donationsrapporter
- **[Websted](./website/index.md)** - Byg og administrer dit kirkewebsted
- **[Prædikener](./sermons/index.md)** - Administrer dit prædikenbibliotek og live streaming
- **[Kalendere](./calendars/index.md)** - Opret og udgiv event kalendere
- **[Indstillinger](./settings/index.md)** - Konfigurer kirke info, roller og tilladelser

:::info
Klik spørgsmålstegnet ikonet i øverste højre hjørne af enhver side for hurtig adgang til hjælp og dokumentation.
:::
