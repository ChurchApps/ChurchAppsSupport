# Profil

<div class="article-intro">

Afsnittet Profil giver dig mulighed for at administrere dine personlige kontoindstillinger i ChurchApps. Din profil deles på tværs af alle ChurchApps-værktøjer, så ændringer, du foretager her, gælder overalt -- fra B1 Admin til B1 App.

</div>

## Hvad du kan gøre

Fra afsnittet Profil kan du:

- **Opdatere dit navn og din e-mail** -- Hold dine kontaktoplysninger opdaterede.
- **Skifte adgangskode** -- Angiv en ny adgangskode til din konto.
- **Aktivere tofaktorlogin** -- Kræv en kode fra en autentifikator-app, når du logger ind. Se [Tofaktorlogin](./managing-profile.md#two-factor-sign-in).
- **Skifte tema** -- Skift mellem lys og mørk tilstand fra brugermenuen (klik på dit profilbillede i øverste højre hjørne).
- **Administrere tilsluttede enheder** -- Se og styr, hvilke ChurchAppsPlayer-enheder der er knyttet til din konto.
- **Se tilknyttede konti** -- Se og administrer eksterne tjenester, der er forbundet med din ChurchApps-konto.
- **Godkende anmodninger om profilændringer** -- Gennemgå og anvend opdateringer, som medlemmer har indsendt.

## Underafsnit under Profil

Profilområdet har følgende sider:

1. **[Administrer din profil](./managing-profile.md)** -- Rediger dine personlige oplysninger, skift din adgangskode, administrer tilknyttede konti, aktiver tofaktorlogin, justér temapræferencer og håndter sletning af konto.
2. **[Godkendelse af profilændringer](./approving-profile-changes.md)** -- Gennemgå og godkend profilopdateringsanmodninger, som medlemmer har indsendt via B1 App.
3. **[Administrer enheder](./devices.md)** -- Se, tilføj og administrer ChurchAppsPlayer-enheder, der er parret med din konto.

:::tip
Hold din e-mailadresse opdateret. Den bruges til kontogendannelse og vigtige meddelelser fra din kirke.
:::
