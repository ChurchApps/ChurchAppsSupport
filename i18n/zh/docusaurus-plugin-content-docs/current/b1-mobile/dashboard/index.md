# 仪表板

<div class="article-intro">

仪表板是您在 B1 Mobile 中的主屏幕。它让您可以快速访问教会提供的各项功能，并根据您使用应用的方式进行组织。布局会随时间调整，将您最常用的功能放在最显眼的位置。

</div>

:::info 本页介绍的是已弃用的原生应用
B1.church 应用中的主页（`/mobile`）取代了 B1 Mobile，其工作方式有所不同：它会显示您最新的讲道、即将进行的服事、您的小组、即将举行的活动和奉献等部分，以及教会为标签页配置的照片图块。请参阅 [浏览 B1App](../../b1-church/getting-started/navigating.md#home)。管理员可以在[移动应用设置](../../b1-admin/settings/mobile-app.md#home-screen-tiles)中选择这些照片图块的布局方式。
:::

## 欢迎部分

仪表板顶部会显示欢迎信息，以及教会的标志（若未设置标志，则显示教会名称）和"保持联系"的标语。此部分可确认您当前查看的是哪个教会。

## 精选链接

在欢迎部分下方，您最常访问的功能会以带有背景图片和功能名称的大型**主打卡片**显示。这是您使用最频繁的功能，被置于顶部，方便您一键访问。

## 精选卡片

在主打卡片下方，最多会有两张**精选卡片**并排显示。它们分别代表您第二和第三常用的功能。每张卡片都显示背景图片和功能名称。点击任一卡片即可直接进入该功能。

## 快捷操作

其余功能会显示在精选卡片下方的**快捷操作**网格中。每个项目都显示图标和标签。这些是您教会配置的所有其他导航链接，让您可以访问从[小组](../groups/)和[奉献](../giving/)到[签到](../checkin/)、[讲道](../content/sermons.md)等各项功能。

## 布局如何调整

仪表板的布局会根据您的使用习惯进行个性化设置。每次您点击某项功能，应用都会记录您访问它的频率。您使用得越频繁的功能，就会越靠近仪表板顶部：

- 您**最常访问**的功能会成为主打卡片。
- 您**第二和第三常访问**的功能会成为精选卡片。
- **其他所有功能**都会显示在快捷操作网格中。

如果您还没有使用过该应用，功能将按照教会配置的默认顺序显示。随着时间推移，仪表板会根据您的使用习惯重新排列。

:::info
仪表板上可用的功能由您的教会管理员通过 [B1 Admin](../../b1-admin/) 进行配置。如果您没有看到预期的功能，请联系您的教会办公室。
:::

## 刷新仪表板

在仪表板上向下拉动即可刷新。这将重新加载您教会的链接和内容，确保您看到的是最新信息。

## 导航

在仪表板上，您可以访问应用的任何部分：

- 点击左上角的**汉堡图标**（三条水平线）即可打开包含所有导航选项的抽屉菜单。
- 点击右上角的**铃铛图标**即可查看您的[通知](../community/notifications.md)。
- 点击任意卡片或快捷操作项目即可直接进入对应功能。
