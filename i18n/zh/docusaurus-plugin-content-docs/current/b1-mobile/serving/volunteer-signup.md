# 志愿者报名

<div class="article-intro">

通过 B1 Mobile 浏览可用的志愿者职位，并报名参加即将举行的礼拜。查看哪些职位需要人手、还有多少名额空缺，只需轻点几下即可加入团队。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [安装 B1 Mobile](../getting-started/installing)，并[登录](../getting-started/logging-in)您的账户
- 教会管理员必须至少为一个职位开启自主报名

</div>

## 浏览志愿服事机会

1. 从应用导航中打开**志愿者（Volunteer）**板块。
2. 将显示一份有空缺职位的即将举行的服事计划列表。如果您的教会只显示每种计划类型的下一周，那么当前一周过去后，之后的周次才会出现。
3. 每张计划卡片会显示：
   - **计划名称**和**礼拜日期**
   - **总体进度条**，显示已填补的名额总数
   - **状态** -- 仍然空缺的名额数量，如果所有名额都已满则显示“Full”（已满）
   - **职位标签**，显示每个角色及其空缺名额数
4. 点击 **View and Sign Up**（查看并报名），即可查看某个计划的完整职位列表。

## 报名职位

1. 点击某个计划，打开其详情。
2. 职位按类别分组（例如“Band”（乐队）、“Hospitality”（接待）、“Kids Ministry”（儿童事工））。
3. 每个职位会显示角色名称、描述和可报名名额。
4. 点击您想要的职位旁边的 **Sign Up**（报名）。
5. 系统会弹出确认提示：“You're signed up! Thank you for volunteering.”（您已报名成功！感谢您的志愿服事。）
6. 该职位会显示绿色标记，确认您已报名。

:::info
您必须登录才能报名职位。如有需要，应用会提示您登录。
:::

## 取消报名

1. 找到您已报名的职位——它会显示绿色的“You're signed up”（您已报名）标记。
2. 点击 **Remove**（移除）。
3. 系统会弹出确认对话框，询问您是否确定。
4. 确认后即可将您从该职位中移除。

## 截止时间和名额

- **截止时间** -- 您的教会可能会设置礼拜前的截止时间。截止时间过后，您将无法报名或取消报名。计划顶部的横幅会显示截止时间已过。
- **名额** -- 每个职位的名额都是有限的。名额报满后，报名按钮将被禁用。如果有人取消报名，名额会重新开放。

:::tip
开启[推送通知](../community/notifications.md)，以便及时了解新的志愿服事机会以及您的安排变动。
:::
