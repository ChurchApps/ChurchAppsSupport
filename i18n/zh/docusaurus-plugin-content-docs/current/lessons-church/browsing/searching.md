# 搜索

<div class="article-intro">

当您知道想教什么主题，但不确定哪个课程系列或学习单元包含它时，搜索功能可以帮助您快速找到合适的内容。搜索涵盖 Lessons.church 库中的课程系列、学习单元和课程。

</div>

</div>

## 如何搜索

1. 在 Lessons.church 网站顶部点击**搜索**图标以打开搜索框。
2. 输入关键词或短语（例如，"饶恕"、"大卫与歌利亚"或"祷告"）。输入时，匹配结果会显示在搜索框下方的列表中 -- 点击其中一项即可直接前往。
3. 按**回车键**打开完整的搜索结果页面。

## 搜索原理

搜索会查看 Lessons.church 库中每个课程系列、学习单元和课程的名称、描述、类别和年龄组。它还会匹配单词的开头部分，例如搜索"bapt"可以找到"baptism"（洗礼）。名称中的匹配权重最高，课程系列和学习单元的排名略高于单独的课程。外部提供商的内容不包括在搜索结果中。

## 浏览结果

每个结果都标注为**课程系列**、**学习单元**或**课程**，如果设置了年龄组，还会显示年龄组。学习单元会显示其所属的课程系列，课程会显示其所属的学习单元和课程系列。点击任何结果即可直接前往该页面。课程页面会显示完整的内容、章节、角色和可下载材料。

## 何时使用搜索

搜索在以下情况最为有用：

- 您有特定的圣经故事或主题，想查看所有涵盖它的可用课程。
- 您正在规划一个特别系列，需要找到关于特定主题的课程。
- 您还不熟悉可用的课程系列，想快速了解有什么内容。

:::tip
匹配您更多词汇的结果排名更靠前。如果您想要的结果被埋没，请添加另一个具体的词。例如，搜索"好撒玛利亚人"会把关于该比喻的课程排到最前面。
:::

如果您已经知道想要哪个课程系列，按课程系列浏览通常更快。详见[课程系列与学习单元](./programs-and-studies.md)了解如何浏览内容层级。
