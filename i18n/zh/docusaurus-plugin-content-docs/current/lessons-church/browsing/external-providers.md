# 外部课程提供方

<div class="article-intro">

Lessons.church 并不局限于自身的课程内容。第三方课程提供方可以通过**开放课程格式**发布其内容。您的教会添加提供方后，就可以在 Lessons.church 课程库旁边，为教室安排其课程。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 阅读[项目与学习单元](./programs-and-studies.md)，了解内容的组织方式
- 要添加提供方连接，您需要一个有权访问教会教室排程的 [Lessons.church 账户](../getting-started/creating-account.md)

</div>

## 什么是外部课程提供方？

外部课程提供方是指使用开放课程格式发布教会课程的任何机构。开放课程格式是一种让课程内容能够跨平台共享的标准。当提供方以此格式提供其内容时，Lessons.church 便能读取并以与自有课程相同的版面显示这些课程。

这意味着您无需访问多个网站，就能获得更广泛的课程选择。

## 添加提供方连接

如果您的教会使用支持开放课程格式的课程提供方：

1. 登录您的 Lessons.church 账户。
2. 点击导航栏中的**外部课程提供方**。
3. 点击**添加提供方**，输入**提供方名称**和提供方的 **API 网址**，然后点击**保存**。

完整步骤请参阅[第三方提供方](../admin/third-party-providers.md)。

:::info
外部课程提供方仅为您的教会添加。其项目不会出现在 Lessons.church 公开首页或搜索结果中。
:::

## 使用外部内容

添加提供方后，其项目、学习单元和课程即可在您安排课程时使用：

1. 当您[将课程添加到教室的排程](../classrooms/scheduling-lessons.md)时，在**提供方**下拉选项中选择该提供方。
2. 选择**项目**、**学习单元**、**课程**和**场地**，方式与选择 Lessons.church 课程相同。
3. 在教室的排程中，点击已排定的外部课程下方的**查看课程**即可打开。其版面与内置课程相同，包括各个环节、角色、行动、视频和可下载的材料。

:::note
来自外部提供方的课程无法进行[自定义](../customization/customizing-lessons.md)。只有 Lessons.church 课程会显示**自定义**链接。
:::

## 面向内容创作者

如果您是课程发布者，有意在 Lessons.church 上提供您的内容，开放课程格式为分享您的项目、学习单元和课程提供了一种标准化的方式。请联系 Lessons.church 团队，或查阅开发者文档以了解整合细节。

:::tip
有关添加、编辑和删除提供方的分步说明，请参阅[第三方提供方](../admin/third-party-providers.md)。
:::
