# 呈现

<div class="article-intro">

Lessons.church 提供工具来帮助您的志愿者自信地教授每堂课。无论您是在屏幕上投影内容、分发印刷指南还是分发活动表，您需要的一切都内置在平台中。

</div>

## 呈现者模式

当到了教学时间时，您可以直接从任何课程启动**呈现者模式**。这为您提供了一个全屏、投影友好的视图，为教室屏幕和投影仪设计。它也与 FreeShow 呈现软件和 [FreePlay](https://freeplay.church) 集成以进行自动化显示。

## 志愿者指南

每堂课都包括基于角色的指南，所以您的志愿者确切知道要说和做什么。一个欢迎者看到他们的说明，一个小组领导看到他们的，以此类推。指南可以在课堂期间在手机或平板电脑上查看，或提前打印。

## 可下载的材料

课程附带可下载的资源，如活动表、着色页、领导指南和补充 PDF。这些材料在程序、研究和课程级别可用，所以您可以在一个地方获得所需的一切。

## 将其全部整合在一起

典型的周日上午工作流程可能如下所示：

1. 在一周早些时候下载并打印任何活动表或着色页。
2. 与您的团队分享志愿者指南链接，以便他们可以查看他们的角色。
3. 在教室计算机或电视上以**呈现者模式**打开课程。
4. 逐步完成课程部分，志愿者跟随他们各自的指南。

:::tip
在课堂前几天准备材料和分享指南链接，使志愿者有时间查看并在周日上午到达时充满信心。
:::
