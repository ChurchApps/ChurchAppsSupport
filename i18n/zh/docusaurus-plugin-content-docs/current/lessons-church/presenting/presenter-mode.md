# 呈现者模式

<div class="article-intro">

呈现者模式将课程转变为全屏、投影友好的显示。它为在教室屏幕、投影仪或电视上显示课程内容而设计，以便房间中的每个人都可以在课堂时间跟随。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [安排课程](../classrooms/scheduling-lessons.md)到教室，或通过[内容库](../browsing/index.md)导航课程
- 确保您的显示（投影仪、电视或监视器）已连接并配置

</div>

## 进入呈现者模式

1. 打开您想要呈现的课程。
2. 单击课程页面上的**呈现**按钮。
3. 课程将切换到具有黑色背景和大的、易于阅读的文本的全屏视图。

一旦在呈现者模式中，您可以使用屏幕上的导航控件逐个部分地移动课程。

## 它看起来如何

呈现者模式使用干净、深色背景，因此内容在投影屏幕上脱颖而出。课程的每个部分一次显示一个，将焦点保持在当前活动上。文本、图像和视频嵌入都格式化为从房间对面可读。

## 与 FreeShow 一起使用

Lessons.church 与 [FreeShow](https://freeshow.app)（一个免费呈现应用）集成。FreeShow 可以直接从 Lessons.church 提取课程内容，允许您将课程幻灯片合并到您现有的呈现工作流中。如果您已经对敬拜歌词或公告使用 FreeShow，这特别有用。

## 与 FreePlay 一起使用

**[FreePlay](https://freeplay.church)**让您在没有单独计算机的情况下在电视上显示课程。在 Android TV、Fire TV 或 Apple TV 设备上安装应用，将其连接到您的 Lessons.church 教室，计划的课程将自动出现。这是具有专用屏幕的教室的一个很好的免提选项。查看 [FreePlay 文档](/docs/freeplay/)了解设置。

:::tip
如果您使用投影仪，确保您的显示在进入呈现者模式前设置为镜像或扩展到投影仪。这确保全屏视图出现在正确的屏幕上。
:::

## 退出呈现者模式

要离开呈现者模式，按**Escape**键或单击屏幕角中的退出按钮。您将返回到正常课程视图。
