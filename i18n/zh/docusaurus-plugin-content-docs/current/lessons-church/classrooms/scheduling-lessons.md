# 安排课程

<div class="article-intro">

教室设置完成后，下一步是安排课程，让志愿者清楚知道何时该教什么。安排课程可以将 Lessons.church 的课程内容与您的教室日历连接起来。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [在门户中至少设置一个教室](./setting-up-classrooms.md)
- [浏览内容库](../browsing/index.md)，找到您想教授的项目和学习单元

</div>

## 查看教室课程表

1. 登录并进入您的**门户**。
2. 点击您要安排课程的**教室**。
3. **课程表**框会按日期从近到远列出该教室的所有已安排课程。每节课都标有**即将开始**、**今天**或**已过去**，让您一目了然地看到最近教过什么，以及接下来要教什么。

## 将课程添加到课程表

1. 在**课程表**框中，点击**添加课程安排**。如果该教室尚未安排任何课程，请改为点击**添加首个课程安排**。
2. 输入该课程的**安排日期**。
3. 如果您已添加任何[外部提供商](../admin/third-party-providers.md)，请选择**提供商**。若保持为 **Lessons.church**，即可从 Lessons.church 课程库中安排课程。
4. 选择您要教授的**项目**（例如“儿童圣经故事”）。
5. 在该项目中选择**学习单元**（例如“创造与早期故事”）。
6. 选择您要安排的具体**课程**。
7. 为该教室选择合适的**场地**。场地代表课程内容针对不同年龄段的版本（例如“学前”或“小学”）。选择正确的场地，可确保志愿者看到的内容符合其教室的年龄段。
8. 点击**保存**。如需先检查课程内容，请点击**预览/打印**，在新标签页中打开。

该课程随即会出现在教室课程表中对应的日期。

:::info
项目、学习单元和课程是 Lessons.church 上的内容层级结构。一个项目包含多个学习单元，每个学习单元又包含多节独立课程。场地则提供同一课程针对不同年龄段的版本。完整说明请参阅[项目与学习单元](../browsing/programs-and-studies.md)。
:::

## 志愿者如何使用课程表

安排好课程后，志愿者可以打开门户，选择自己的教室，立即看到接下来要教的内容。他们可以提前查阅课程内容，下载所需的材料，并做好充分准备。再也不必猜测下一节该教什么。

## 安排课程的建议

- **提前规划** —— 教会可以在 [B1 Admin](../../b1-admin/serving/scheduling-lessons.md) 中安排教室课程，包括应用已发布的年度计划。
- **保持连贯** —— 按顺序跟进一个项目，有助于孩子们在前一周所学的基础上继续学习。
- **查看历史记录** —— 利用已过去课程的列表，确保不会无意中重复讲授相同的内容。

:::warning
请务必为您教室的年龄段选择正确的场地。选错场地，志愿者看到的内容将是为另一个年龄段设计的。
:::

## 下一步

安排好课程后，您可能希望[自定义课程内容](../customization/customizing-lessons.md)，以便针对特定教室调整，符合您的教学风格和年龄段需求。到了授课的时候，请了解[演示](../presenting/index.md)，以更有效地呈现课程。
