# 设置教室

<div class="article-intro">

在安排课程之前，您需要先创建代表您教学场所的教室。本指南将逐步介绍如何在 Lessons.church 门户中创建、命名和管理教室。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [创建账户](../getting-started/creating-account.md)并连接到您的教会
- 熟悉[门户概览](../getting-started/portal-overview.md)

</div>

## 创建教室

1. 登录 [Lessons.church](https://lessons.church) 账户。
2. 进入您的**门户**。这是您教会管理教室和日程安排的中心枢纽。
3. 在**教室**区域中，点击**添加**。如果您还没有任何教室，请改为点击**添加第一个教室**。
4. 输入**教室名称**。请选择一个描述性强、志愿者一看就能认出的名称，例如"学前班"、"小学 K-2"或"初中"。
5. 点击**保存**。您的新教室会立即出现在**教室**列表中。

对教会中的每个房间或年龄组重复以上步骤即可。您可以根据需要创建任意数量的教室。

## 首次设置

如果您尚未设置任何教室，门户会显示一段设置视频，指导您完成整个过程。该视频涵盖了创建教室和安排首次课程的基础知识。如果您是 Lessons.church 的新用户，这是很好的入门起点。

:::tip
请将教室命名为志愿者平时对房间的称呼。如果大家都叫它"学前室"，就直接命名为"学前室"，而不要使用"幼儿教育 101 室"之类的正式名称。
:::

## 管理教室

您的教室会显示在门户仪表板上，您可以随时在此管理它们。在这里，您可以：

- **重命名教室** -- 点击教室旁边的**编辑教室**（铅笔）图标，修改**教室名称**，然后点击**保存**。
- **删除教室** -- 点击**编辑教室**，然后点击**删除教室**（垃圾桶）图标并确认。
- **查看日程** -- 点击任意教室即可查看其课程日程。

## 下一步

教室设置完成后，您就可以开始[安排课程](./scheduling-lessons.md)，让志愿者清楚每周需要教授的内容。
