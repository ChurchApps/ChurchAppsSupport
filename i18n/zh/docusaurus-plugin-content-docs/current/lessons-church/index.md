# Lessons.church

<div class="article-intro">

Lessons.church 是一个完全免费的教会课程平台。没有订阅、没有费用，也没有使用限制。它提供 1,100+ 来自 12+ 提供商的 189+ 研究中的基于视频的课程，涵盖从学前班到成人的年龄组。

</div>

## 您可以做什么

使用 Lessons.church，您的教会可以：

- **浏览内容**——浏览来自多个提供商的日益增长的程序和研究库，按年龄组和主题组织。
- **设置教室**——创建与您的事工结构相匹配的教室（例如，学前班、小学、青年或成人）。
- **安排课程**——将特定课程分配给您的教室，在您需要的日期。
- **根据您的需要自定义**——调整课程内容以适应您的教会的教学风格和偏好。
- **向班级呈现**——使用内置呈现者模式在课堂时间中逐步完成课程。

## 内容是如何组织的

Lessons.church 以清晰的层次结构组织课程：

1. **程序**——来自提供商的顶级课程系列（例如，儿童事工程序）。
2. **研究**——程序内一组相关课程（例如，关于特定主题的四周系列）。
3. **课程**——研究内单个教学会话，通常用于单个班级会议。
4. **场地**——针对特定年龄组或设置调整的课程不同版本（例如，学前班版本和小学版本）。

## 集成

Lessons.church 与其他 ChurchApps 工具配合工作，帮助您交付内容：

- **B1.church**——志愿者和家长可以通过 B1 应用访问即将到来和最近的课程。
- **FreeShow**——使用 FreeShow 呈现软件在屏幕上显示课程内容。
- **[FreePlay](https://freeplay.church)**——使用 FreePlay 应用针对 Android TV、Fire TV 和 Apple TV 直接在电视上显示课程。
