# 管理年度计划

<div class="article-intro">

年度计划是一个有序的课程列表 — 第 1 周、第 2 周、第 3 周 — 教会在 B1 Admin 中应用。您可以为库中的任何课程发布计划。计划存储在数据库中，不与日历年份相关联。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 拥有 Lessons.church 的管理员权限
- 至少拥有一个[项目](./managing-programs.md)与发布的课程

</div>

## 创建计划

1. 打开**管理 → 年度计划**。
2. 单击**添加**。
3. 输入名称（例如"初等部 2026–27"或"高压年份 1"）和可选的 slug。
4. 可选设置**默认地点偏好** — 当周未指定地点时使用的逗号分隔的地点名称。
5. 当教会应该在 B1 Admin 中看到计划时检查**发布**。对于草稿，请将其关闭。
6. 从任何课程中添加周：选择**来源**、项目、研究、课程和地点。单击**添加**。单个计划可以混合项目（如果需要）。使用箭头重新排序。
7. 保存。

教会从 **B1 Admin → 服务 → 计划 → 安排课程 → 应用年度计划**应用已发布的计划。这会在他们的服务计划中填充接下来的 12-52 周。他们之后在那里编辑各个周；FreePlay 播放计划上的任何内容。
