# 管理

<div class="article-intro">

Lessons.church 中的管理区域是内容创建者和管理员管理课程库的地方。在这里，您可以搭建课程结构、上传资源、查看使用统计数据，并连接第三方内容提供商。

</div>

:::warning
访问管理区域需要相应的权限。如果您看不到管理选项，请联系您的教会管理员申请访问权限。
:::

## 您可以做什么

管理区域让您完全掌控内容：

- **创建和编辑项目** -- 设置顶级课程系列，包括名称、描述、图片和网址标识（slug）。
- **管理学习单元** -- 在每个项目中组织相关课程的分组。
- **编写课程** -- 添加单个课程，包括场地、环节、角色和操作。
- **上传资源** -- 在项目、学习单元或课程层级附加可下载文件（PDF、活动单、图片）。
- **查看统计数据** -- 查看哪些内容被下载、由谁下载以及在哪里下载。
- **配置提供商** -- 连接使用 Open Lesson Format 的外部课程提供商。这需要在**外部提供商**页面中完成，而不是在管理区域中。
- **年度计划** -- 为任何课程发布第 1 周、第 2 周、第 3 周……的序列。教会可在 B1 Admin 中应用这些计划。

## 内容层级

作为管理员，了解内容的结构会有所帮助：

1. **项目**包含一个或多个学习单元。
2. **学习单元**包含一个或多个课程。
3. **课程**包含一个或多个场地（不同年龄段的版本）。
4. **场地**包含环节，环节中包含基于角色的操作。

每个层级都可以附加自己的可下载资源。
