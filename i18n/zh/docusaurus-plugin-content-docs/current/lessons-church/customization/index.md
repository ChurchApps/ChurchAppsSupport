# 自定义设置

<div class="article-intro">

Lessons.church 提供了大量现成可用的课程内容，但每个教会的情况各不相同。自定义功能可以让您根据具体的教室、教学风格和年龄段调整课程内容，使志愿者只看到与他们相关的部分。

</div>

## 为什么要自定义？

Lessons.church 上的课程内容设计得十分灵活。一节课可能包含面向多个年龄段的部分、可选的活动，或并非每个教室都适用的角色。与其让志愿者自己跳过不适用的部分，不如通过自定义，让他们只看到与自己相关的内容。

例如，某节课中可能有一个手工活动非常适合学龄前儿童，但并不适合您的五年级教室。通过自定义，您可以为年龄较大的班级隐藏该部分，同时为年龄较小的班级保留它。

## 您可以自定义哪些内容

- **删除部分内容** -- 删除课程中不适用于特定教室或年龄段的整个部分。
- **删除角色或活动** -- 如果某些角色或活动不需要，可将其从相应部分中删除。
- **调整内容顺序** -- 重新排列各部分和活动，使其符合您教室偏好的流程。

## 仅针对本教室还是全局生效

每次进行更改时，您都可以选择其应用范围：

- **本教室** -- 更改仅影响当前教室，其他教室仍显示原始内容。
- **所有教室** -- 更改将应用于您教会的每一间教室。

这种灵活性意味着您可以为不同年龄段的教室设置同一课程的不同版本，也可以一次性做出适用于所有教室的更改。

:::tip
如果您刚开始使用自定义功能，建议先在单个教室中试用，熟悉操作方法后再将更改应用到所有教室。
:::
