# 门户概览

<div class="article-intro">

登录 Lessons.church 后，您会进入**门户**——这是您教会管理班级和课程排期的仪表板。在为教会规划课程时，您将大部分时间都在这里操作。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [创建账户](./creating-account.md)并关联您的教会
- 登录 [Lessons.church](https://lessons.church)

</div>

## 您会看到什么

门户打开后显示**班级管理**页面，主要分为两个区域：

- **班级**（右侧）——教会班级列表。点击班级名称即可查看其已排定的课程。您也可以在此添加新班级或编辑现有班级。
- **课程排期**（左侧）——选择班级后，此区域会显示该班级已排定的课程。如果您还没有设置任何班级，将看到一段设置说明视频，帮助您入门。

## 在门户中可以做什么

在门户中，您可以：

1. **管理班级**——添加、编辑或删除班级。每个班级可以关联一个志愿者团队（使其在 B1 应用中看到即将到来的课程），也可以关联一个家长/学生小组（使其能够访问最近的课程）。仍在使用此班级排期方式的教会，家长可打开班级页面（不带 `?upcoming=1`）查看居家学习内容。使用 B1Admin 方案类型的教会，则会在 B1 中相关小组的页面上看到居家学习卡片。
2. **查看并管理已排定的课程**——查看每个班级即将到来的课程，并根据需要进行调整。
3. **订阅班级订阅源**——点击班级旁边的订阅图标，即可获取播放列表订阅源网址，用于兼容的应用程序。
4. **访问外部提供方**——使用**外部提供方**页面配置支持开放课程格式（Open Lesson Format）的第三方内容来源。这使您可以引入 Lessons.church 内置课程库之外的其他提供方的课程。
5. **进入管理区域**——如果您拥有管理权限，导航栏中会显示**管理**选项。管理区域可让您在内容层面管理项目、研习和课程。

## 导航

门户导航包括：

- **首页**——返回公开的 Lessons.church 首页，浏览内容。
- **排期**——用于管理班级和课程排期的主门户视图。
- **外部提供方**——配置第三方课程提供方。
- **管理**——管理项目、研习和课程内容（仅在您拥有管理权限时可见）。

:::info
只有当您的账户被授予内容编辑权限时，才会显示**管理**选项。大多数教会工作人员日常管理主要使用**排期**和**外部提供方**页面。
:::

## 入门指南

如果您是首次访问门户，且尚未创建任何班级，请先点击班级面板中的**添加第一个班级**。为班级命名（例如"学龄前"或"三至五年级"）后保存。之后，您就可以开始[安排课程](../classrooms/scheduling-lessons.md)了。
