# 出席设置

<div class="article-intro">

在你可以追踪出席之前，你需要告诉 B1 Admin 关于你的教会的物理位置、服侍何时发生以及哪些小组在每个服侍中聚会。这个一次性设置创建了为你的教会的所有出席追踪和报告赋予动力的结构。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要一个活跃的 B1 Admin 帐户，有权限管理出席。如果你不确定你的访问级别，见[角色和权限](../people/roles-permissions.md)。
- 如果你计划将小组分配给服侍时间，请确保你的[小组已创建](../groups/creating-groups.md)。

</div>

## 关键概念

- **校园** — 你的教会聚会的物理位置（例如"主校园"、"北校园"）。校园在**设置**下管理。
- **服侍** — 在校园的定期聚集（例如"主日服侍"、"周中聚集"）。
- **服侍时间** — 服侍发生的具体时间（例如"上午 9:00"、"上午 11:00"）。
- **已排定小组** — 分配给特定服侍时间的小组。出席在该服侍的背景下被追踪。
- **未排定小组** — 在没有与服侍时间相关联的情况下自行追踪出席的小组。

## 设置你的出席结构

1. 打开 **B1 Admin**，点击左上角的**部分菜单**（部分名称和小箭头），并选择**人员**。
2. 在导航栏中，点击**出席**标签页。默认选中**设置**标签页。
3. 点击**管理校园**（设置面板的右上方）。这会带你到**设置→校园**。点击**添加校园**，输入你的位置名称（地址和时区是可选的），然后点击**保存**。
4. 返回**人员→出席→设置**。你的校园现在出现在设置表中。
5. 点击你的校园下的**服侍列中的 + 按钮**。输入服侍名称，例如"主日服侍"，然后点击**保存**。
6. 点击服侍下的**时间列中的 + 按钮**。输入一个时间，例如"上午 9:00"，然后点击**保存**。对每个服侍时间重复。
7. 要将小组连接到服侍时间，请从**小组**标签页打开小组，点击**编辑**铅笔，并使用**添加服侍时间** — 见下一部分。

### 在小组上启用追踪出席

在小组可以记录出席之前，必须为该小组打开追踪出席。

1. 在侧栏中点击**小组**，然后选择小组。
2. 点击**编辑**铅笔图标。
3. 将**追踪出席**设置为**是**。
4. 点击**保存**。

:::tip
如果你在上一步中将小组分配给了服侍时间，也在小组的编辑屏幕上使用**添加服侍时间**选项将其链接到正确的服侍。这可以确保课程与正确的校园和时间相连。
:::

:::tip
如果小组在定期服侍之外聚会 — 比如追踪其自己出席的周中小组 — 你可以将其保留为未排定小组。它仍然会出现在小组标签页上用于出席报告。
:::

## 编辑你的设置

你可以随时更新你的设置。选择校园、服侍时间或小组，点击**编辑**更改其细节，或**删除**移除它。

:::info
删除服侍时间不会删除过去的出席记录。即使你改变你的日程，你的历史数据也被保留。
:::

## 接下来是什么

一旦你的校园、服侍时间和小组就位，你就准备好开始[记录出席](recording-attendance.md)手动或设置[自助签到](check-in.md)用于你的服侍。
