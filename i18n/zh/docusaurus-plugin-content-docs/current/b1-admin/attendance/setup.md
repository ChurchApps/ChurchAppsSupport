# 考勤设置

<div class="article-intro">

在开始跟踪出勤之前，你需要告诉 B1 Admin 教会的实体地点、礼拜的时间，以及每个礼拜中有哪些小组聚会。这项一次性设置会建立起支撑全教会出勤跟踪与报告的整体结构。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要拥有一个有效的 B1 Admin 账号，并具备管理出勤的权限。如果你不确定自己的访问权限级别，请参见[角色与权限](../people/roles-permissions.md)。
- 如果你计划为礼拜时间分配小组，请先确保[已创建小组](../groups/creating-groups.md)。

</div>

## 核心概念

- **校区** —— 教会聚会的实体地点（例如“主校区”“北校区”）。校区在 **Settings** 下管理。
- **礼拜（Service）** —— 在某个校区定期举行的聚会（例如“周日礼拜”“周中聚会”）。
- **礼拜时间（Service Time）** —— 礼拜举行的具体时间（例如“上午 9:00”“上午 11:00”）。
- **已排定小组（Scheduled Group）** —— 分配到特定礼拜时间的小组。出勤将在该礼拜的上下文中进行跟踪。
- **未排定小组（Unscheduled Group）** —— 独立跟踪出勤、不与某个礼拜时间关联的小组。

## 设置你的考勤结构

1. 打开 **B1 Admin**，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），并展开 **People**。
2. 点击 **Attendance**，然后点击左侧栏中的 **Setup**。**Service structure** 表格会打开，顶部显示你的校区数量、礼拜时间数量，以及已排定和未排定小组的数量。在表格中添加、编辑或删除任何内容时，这些计数都会立即更新。
3. 点击 **Manage Campuses**（位于 **Service structure** 面板右上角）。这会带你进入 **Settings → Campuses**。点击 **Add Campus**，输入你的地点名称（地址和时区为可选项），然后点击 **Save**。
4. 返回 **People → Attendance**，点击 **Setup**。你的校区现在会出现在设置表格中。
5. 点击校区下方 **Service** 列中的 **+** 按钮。输入礼拜名称，例如“周日礼拜”，然后点击 **Save**。
6. 点击礼拜下方 **Time** 列中的 **+** 按钮。输入**礼拜时间**名称，例如“9:00 AM”，可选择填写[签到计划](#setting-a-check-in-schedule)，然后点击 **Save**。每个礼拜时间都需重复此操作。
7. 要将小组关联到某个礼拜时间，请从 **People > Groups** 打开该小组，点击 **Edit**，然后使用 **Add Service Time**——参见下一节。

### 为小组启用考勤跟踪

在为某个小组记录出勤之前，必须先为该小组开启 Track Attendance。

1. 在跳转菜单中，选择 **People > Groups**，然后选择该小组。
2. 点击小组名称下方的 **Edit** 按钮。
3. 将 **Track Attendance** 设置为 **Yes**。
4. 点击 **Save**。

:::tip
如果你在上一步中已为该小组分配了礼拜时间，也请在小组的编辑页面中使用 **Add Service Time** 选项，将其关联到正确的礼拜。这样可以确保场次与正确的校区和时间相连。
:::

:::tip
如果某个小组在常规礼拜之外聚会——例如自行跟踪出勤的周中小组——你可以将其保留为未排定小组。它仍会出现在**小组出勤**报告中，用于出勤统计。
:::

## 设置签到计划 {#setting-a-check-in-schedule}

每个礼拜时间都可以选择设置签到计划，使[自助签到](check-in.md)每周自动开放和关闭。如果没有设置计划，该礼拜时间的签到将始终可用（前提是该房间未因其他原因关闭，例如已满员）。

1. 在**Setup**视图中，点击某个礼拜时间在 **Time** 列中的名称（或添加新的礼拜时间）。
2. 在 **Check-in Schedule** 下，选择该礼拜时间举行的**星期**。
3. 设置**开始时间**，以及可选的**结束时间**。
4. 输入 **Open check-in (minutes before start)**——例如，填写 `30` 表示在礼拜开始前半小时开放签到。
5. 输入 **Close check-in (minutes after end)**——例如，填写 `15` 表示在结束时间后 15 分钟内仍保持签到开放。如果你没有设置结束时间，则从开始时间起算。
6. 点击 **Save**。

该计划每周重复，并以礼拜所在校区的时区为准。如果该校区未设置时区，则使用教会的[时区](../settings/church-settings.md#time-zone)；若教会也未设置，则依次使用第一个设有时区的校区的时区，最后使用东部时间（America/New_York）。如果签到开放的时间不对，请在[校区](../settings/campuses.md)中检查该校区的**时区**。要删除计划，请将**星期**设回 **No schedule**，然后点击 **Save**。只有同时设置了**星期**和**开始时间**，计划才会生效。

当某个礼拜时间的签到窗口关闭时：

- **B1.church 上的自助签到**会将该礼拜时间显示为 **Closed**（或例如 **Closed · opens Sun 9:30 AM**），且无法选择。如果某个礼拜的所有时间都未开放，家庭会看到签到何时开放，例如“签到将于周日 9:30 AM 开放”。
- **B1 Checkin 自助机应用**同样会将该礼拜时间显示为 **Closed** 并告知开放时间。如果某个礼拜的所有时间都已关闭，自助机会说明该礼拜的签到何时开放。已在已关闭礼拜时间签到的人员，其小组会改为显示 **Checked in**。如果签到过程中窗口关闭，自助机将无法完成该次签到，并显示 **Can't check in yet** 页面，列出受影响的房间，以便家庭选择其他房间。

已为较早的礼拜时间签到的家庭，即使该较早的签到窗口已经关闭，仍可以返回并添加一个仍处于开放状态的较晚礼拜时间。他们之前的签到记录会被保留。

:::tip
将开放窗口设置得宽裕一些（例如开始前 45 分钟），使提早到达的家庭和志愿者都能签到；将关闭窗口设置得短一些，使迟到者在礼拜开始后仍能签到。
:::

## 编辑你的设置

你可以随时更新设置。选择某个校区、礼拜时间或小组，然后点击 **Edit** 修改其详细信息，或点击 **Delete** 将其删除。

:::info
删除礼拜时间不会删除过去的出勤记录。即使你更改了排期，历史数据仍会被保留。
:::

## 下一步

一旦校区、礼拜时间和小组设置完成，你就可以开始[手动记录出勤](recording-attendance.md)，或为你的礼拜设置[自助签到](check-in.md)。
