# 出席设置

<div class="article-intro">

在您可以跟踪出席情况之前，您需要告诉 B1Admin 您的教会的物理位置、服务何时进行以及哪些小组在每项服务中聚集。这个一次性设置创建了在您的教会中为所有出席跟踪和报告提供支持的结构。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要一个活跃的 B1Admin 帐户，有权管理出席。如果您不确定您的访问级别，请参见[角色和权限](../people/roles-permissions.md)。
- 如果您计划将小组分配给服务时间，请确保首先[创建了您的小组](../groups/creating-groups.md)。

</div>

## 关键概念

- **校区** — 您的教会聚集的物理位置（例如"主校区"、"北校区"）。校区在**设置**下管理。
- **服务** — 在校区进行的定期聚集（例如"周日服务"、"周中"）。
- **服务时间** — 服务发生的具体时间（例如"上午 9:00"、"上午 11:00"）。
- **定时小组** — 分配给特定服务时间的小组。出席是在该服务的背景下跟踪的。
- **未定时小组** — 自行跟踪出席的小组，不与服务时间联系。

## 设置您的出席结构

1. 打开 **B1Admin**，单击左上角的**部分菜单**（部分名称带小箭头），然后选择**人员**。
2. 在导航栏中，点击**出席**标签。**设置**标签默认被选中。
3. 单击**管理校区**（设置面板右上角）。这会将您带到**设置 > 校区**。单击**添加校区**，输入您的位置名称（地址和时区是可选的），然后单击**保存**。
4. 返回**人员 > 出席 > 设置**。您的校区现在出现在设置表中。
5. 单击校区下**服务列中的 + 按钮**。输入服务名称（如"周日服务"）然后单击**保存**。
6. 单击服务下**时间列中的 + 按钮**。输入时间（如"上午 9:00"）然后单击**保存**。为每个服务时间重复。
7. 要将小组连接到服务时间，从**小组**标签打开小组，单击**编辑**铅笔，并使用**添加服务时间** — 参见下一部分。

### 在小组上启用跟踪出席

在小组可以记录出席情况之前，必须为该小组启用"跟踪出席"。

1. 打开左上角的**部分菜单**并选择**人员**，然后单击**小组**标签并选择小组。
2. 单击**编辑**铅笔图标。
3. 将**跟踪出席**设置为**是**。
4. 点击**保存**。

:::tip
如果您在上一步中将小组分配给服务时间，还应在小组的编辑屏幕上使用**添加服务时间**选项将其链接到正确的服务。这确保会议连接到正确的校区和时间。
:::

:::tip
如果小组在正常服务之外聚集 — 比如跟踪自己出席的周中小组 — 您可以将其保留为未安排的小组。它仍将在小组标签上出现以用于出席报告。
:::

## 编辑您的设置

您可以随时更新您的设置。选择一个校区、服务时间或小组，然后单击**编辑**更改其详情，或**删除**删除它。

:::info
删除服务时间不会删除过去的出席记录。即使您更改了日程，您的历史数据也会被保留。
:::

## 下一步

一旦您的校区、服务时间和小组就位，您就可以开始[手动记录出席情况](recording-attendance.md)或设置[自助签到](check-in.md)为您的服务。
