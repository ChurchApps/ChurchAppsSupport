# 出勤设置

<div class="article-intro">

在您可以跟踪出勤之前，您需要告诉 B1 Admin 您的教会的物理位置、服务何时发生以及哪些小组在每个服务中会面。这个一次性设置创建了支持整个教会所有出勤跟踪和报告的结构。

</div>

<div class="prereqs">
<h4>在开始之前</h4>

- 您需要有权管理出勤的活跃 B1 Admin 帐户。如果您不确定您的访问级别，请参阅[角色与权限](../people/roles-permissions.md)。
- 如果您计划将小组分配给服务时间，请确保首先[创建小组](../groups/creating-groups.md)。

</div>

## 关键概念

- **校园** -- 您的教会会面的物理位置（例如，"主校园"、"北校园"）。校园在**设置**下进行管理。
- **服务** -- 校园的定期集会（例如，"星期日服务"、"中周聚会"）。
- **服务时间** -- 服务发生的具体时间（例如，"上午 9:00"、"上午 11:00"）。
- **定时小组** -- 分配给特定服务时间的小组。出勤是在该服务的背景下进行跟踪的。
- **非定时小组** -- 一个在自己的基础上跟踪出勤的小组，不与服务时间相关联。

## 设置您的出勤结构

1. 打开**B1 Admin**，打开[Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），并展开**人员**。
2. 单击**出勤**。**设置**选项卡默认被选中。
3. 单击**管理校园**（设置面板右上角）。这会带您进入**设置 → 校园**。单击**添加校园**，输入您的位置的名称（地址和时区是可选的），然后单击**保存**。
4. 返回**人员 → 出勤 → 设置**。您的校园现在出现在设置表中。
5. 单击您的校园下**服务列中的 + 按钮**。输入服务名称，如"星期日服务"，然后单击**保存**。
6. 单击服务下**时间列中的 + 按钮**。输入时间，如"上午 9:00"，然后单击**保存**。对每个服务时间重复。
7. 要将小组连接到服务时间，请从**人员 > 小组**打开小组，单击**编辑**铅笔，并使用**添加服务时间** — 请参阅下一部分。

### 在小组上启用跟踪出勤

在可以记录出勤前，必须为该小组打开跟踪出勤。

1. 在 Jump 菜单中，选择**人员 > 小组**并选择小组。
2. 单击**编辑**铅笔图标。
3. 将**跟踪出勤**设置为**是**。
4. 单击**保存**。

:::tip
如果您在上一步中将小组分配给服务时间，还应在小组的编辑屏幕上使用**添加服务时间**选项将其链接到正确的服务。这确保会话连接到正确的校园和时间。
:::

:::tip
如果小组在定期服务之外会面 — 比如跟踪自己出勤的中周小小组 — 您可以将其保留为非定时小组。它仍然会出现在出勤报告的小组选项卡上。
:::

## 编辑您的设置

您可以随时更新您的设置。选择校园、服务时间或小组，并单击**编辑**以更改其详细信息，或**删除**以将其删除。

:::info
删除服务时间不会删除过去的出勤记录。即使您更改日程，您的历史数据也会保留。
:::

## 下一步

设置好校园、服务时间和小组后，您就可以开始[手动记录出勤](recording-attendance.md)或为您的服务设置[自助签到](check-in.md)。
