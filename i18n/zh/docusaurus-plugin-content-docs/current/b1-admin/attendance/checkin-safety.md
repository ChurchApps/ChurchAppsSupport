# 签到安全

<div class="article-intro">

B1 包括一套针对签到的儿童安全控制：房间容量限制和志愿者与儿童比率、自助服务终端的年龄和年级指导、区分成员、访客和志愿者的签到类型，以及在签出时验证的每个家庭的受信任接送人员名单。此页面说明如何在 B1 Admin 中配置每个安全功能。

</div>

<div class="prereqs">
<h4>在开始之前</h4>

- 设置您的[出勤结构](setup.md)和[签到自助服务终端](check-in.md)
- 房间是[小组](../groups/creating-groups.md)，与服务时间相关联 — 下面的安全设置位于小组上
- 通知家长和紧急广播需要已连接的短信服务提供商（[Text In Church](../integrations/services/text-in-church)、[Clearstream](../integrations/services/clearstream) 或 Mutual Ministry）

</div>

## 房间容量和关闭房间

每个签到房间（小组）可以强制执行其自己的限制。打开小组，单击**铅笔图标**编辑其设置，并查找**签到容量**部分：

- **容量** -- 可以同时签到到此房间的最大人数。当房间满时，对其签到被阻止，自助服务终端指出房间已满。
- **访客容量** -- 房间可以容纳的访客数的可选单独上限。
- **已关闭签到** -- 设置为**是**可立即停止对此房间的所有签到（例如，当课程被取消或房间不可用时）。签出仍然有效。

## 志愿者比率

小组上相同的**签到容量**部分包括员工配置规则：

- **每位志愿者的儿童数** -- 每位签到的志愿者可以覆盖的最大儿童数（例如 5 表示每五名儿童一位志愿者）。
- **最少志愿者数** -- 儿童可以签到到房间之前必须签到的最少志愿者数。

当志愿者在自助服务终端使用**志愿者**类型签到时，他们计入这些规则（请参阅下面的[签到类型](#check-in-types)）。

### 选择警告与阻止

比率如何严格执行是全教会范围的设置：

1. 在 B1 Admin 中，转到**设置**并打开**签到**部分。
2. 设置**志愿者比率实施**：
   - **警告（允许并确认）** -- 当房间超出比率或志愿者不足其最少数量时，自助服务终端显示警告，员工可以确认继续。这是默认设置。
   - **阻止（防止签到）** -- 拒绝对房间的签到，直到足够的志愿者签到。

:::info
容量和已关闭签到始终是硬性限制 — 警告/阻止选择仅适用于志愿者比率。
:::

## 签到类型

每次签到都记录该人是**成员**、**访客**还是**志愿者**。类型是在自助服务终端家庭屏幕上用芯片选择的（成员是默认值）。类型反馈安全规则 — 志愿者提供比率覆盖，访客计入房间的访客容量。

## 年龄和年级房间指导

您可以为每个房间提供年龄或年级范围，以便自助服务终端指导家庭选择合适的房间：

- 在小组的设置上，使用**年龄与年级**部分设置房间的最小/最大年龄（年和月）和/或年级。
- 在自助服务终端，儿童符合条件的房间会被突出显示，他们不符合的房间会被变暗。变暗的房间仍然可以通过员工确认选择 — 指导永远不会硬阻止。

年级在您的教会的**年级晋升日期**上滚动：

1. 在 B1 Admin 中，转到**设置**并打开**年级晋升**部分。
2. 设置您的教会晋升学生的月份和日期（例如 8 月 1 日）。自助服务终端处的年龄和年级是根据最近的晋升日期计算的。

## 受信任和未授权接送人员

每个家庭都可以携带一份允许 — 或不允许 — 接送其儿童的人员名单。

1. 在**人员**中打开一个人的页面，并查找**接送**卡。
2. 单击**添加**。搜索现有人员，或通过输入其**名称**、**关系**和照片来添加系统中没有的人员。
3. 设置**状态**：
   - **受信任** -- 在签出时，此人作为可点击的接送卡与其照片一起显示，使验证接送快速进行。
   - **未授权** -- 如果有人尝试以此名义接送，自助服务终端会用警告阻止签出。员工可以覆盖，并在出勤记录上记录覆盖。

单击卡上人的状态芯片在受信任和未授权之间切换。

:::tip
尽可能为受信任的接送人员添加照片 — 签出屏幕显示照片，以便志愿者可以目视验证站在他们面前的人。
:::

## 通知家长和紧急广播

两个功能都通过您的教会已连接的短信服务提供商发送短信 — 没有内置短信服务，因此必须首先配置一个受支持的提供商。

- **通知家长** -- 从有人值班的自助服务终端的签出屏幕，员工可以向签到的儿童的父母/监护人发送短信（例如，"请到托儿所"）。
- **紧急广播** -- 从自助服务终端的管理员设置，员工可以立即向选定服务的每个签到家庭的监护人发送短信。发送需要输入**紧急情况**来确认。

选择退出文本或文件中没有手机号码的人员会被自动跳过 — 自助服务终端报告发送的消息数和跳过的数量。

有关自助服务终端的演练，请参阅[签出与儿童安全](../../b1-checkin/check-in/checking-out)。
