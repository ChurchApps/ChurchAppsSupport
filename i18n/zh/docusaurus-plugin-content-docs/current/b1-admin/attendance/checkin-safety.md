# 签到安全

<div class="article-intro">

B1 包含一整套面向签到环节的儿童安全控制功能：房间容量限制和志愿者与儿童的比例、签到亭上的年龄与年级指引、区分成员、访客与志愿者的签到类型，以及在签退时进行核实的每个家庭可信接送人员名单。本页介绍如何在 B1 Admin 中配置各项安全功能。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置好你的[签到结构](setup.md)和[签到亭](check-in.md)
- 房间是与服务时间关联的[小组](../groups/creating-groups.md)——以下安全设置存在于小组中
- 寻呼家长和紧急广播功能需要已连接的短信服务提供商（[Text In Church](../integrations/services/text-in-church)、[Clearstream](../integrations/services/clearstream) 或 Mutual Ministry）

</div>

## 房间容量与关闭房间

每个签到房间（小组）都可以设置自己的限制。打开该小组，点击**铅笔图标**编辑其设置，找到**签到容量**部分：

- **容量** -- 该房间同一时间可容纳的最大签到人数。房间已满时，将阻止签到，签到亭会提示该房间已满。
- **访客容量** -- 一个可选的单独上限，用于限制该房间可容纳的访客人数。
- **关闭签到** -- 设为**是**可立即停止对该房间的所有签到（例如某个班级取消或某个房间不可用时）。签退功能仍可正常使用。

## 志愿者比例

小组上的同一个**签到容量**部分还包含人员配置规则：

- **每位志愿者负责的儿童数** -- 每位已签到志愿者可负责的最大儿童数量（例如 5 表示每 5 名儿童配一位志愿者）。
- **最少志愿者人数** -- 儿童可以签到进入该房间之前，必须已签到的最少志愿者人数。

当志愿者在签到亭以**志愿者**类型签到时（参见下方[签到类型](#check-in-types)），他们会计入这些规则。

### 选择警告还是阻止

比例规则的执行严格程度是一项全教会范围的设置：

1. 在 B1 Admin 中，前往**设置 > 管理教会**，打开**签到**卡片。
2. 设置**志愿者比例执行方式**：
   - **警告（确认后允许）** -- 当房间超出比例或未达到最少志愿者人数时，签到亭会显示警告，工作人员可以确认后仍然继续。这是默认设置。
   - **阻止（阻止签到）** -- 在有足够志愿者签到之前，将拒绝对该房间的签到。

:::info
容量和关闭签到始终是硬性限制——警告/阻止的选择仅适用于志愿者比例。
:::

## 签到类型

每次签到都会记录该人是**成员**、**访客**还是**志愿者**。类型通过签到亭家庭屏幕上的芯片选择（默认是成员）。类型会影响安全规则——志愿者提供比例覆盖，访客计入该房间的访客容量。

## 年龄与年级房间指引

你可以为每个房间设置年龄或年级范围，以便签到亭引导家庭前往合适的房间：

- 在小组设置中，使用**年龄与年级**部分为该房间设置最小/最大年龄（年和月）和/或年级。
- 在签到亭，儿童符合条件的房间会高亮显示，不符合条件的房间会变暗。变暗的房间仍可在工作人员确认后选择——该指引从不做硬性阻止。

年级会在你教会的**年级晋升日期**进行更新：

1. 在 B1 Admin 中，前往**设置 > 管理教会**，打开年级晋升卡片。
2. 设置你教会晋升学生的月份和日期（例如 8 月 1 日）。签到亭上的年龄和年级会按最近一次晋升日期计算。

## 可信与未授权接送人员

每个家庭都可以维护一份被允许（或不被允许）接送其儿童的人员名单。

1. 在**人员**中打开某人的页面，找到**接送**卡片。
2. 点击**添加**。搜索系统中已有的人员，或通过输入**姓名**、**关系**和照片来添加系统中没有的人。
3. 设置**状态**：
   - **可信** -- 在签退时，此人会显示为可点击的接送卡片，带有照片，使核实接送更快捷。
   - **未授权** -- 如果有人以此姓名尝试接送，签到亭会阻止签退并显示警告。工作人员可以进行覆盖操作，该覆盖会记录在签到记录中。

点击卡片上的人员状态芯片可在可信和未授权之间切换。

:::tip
尽量为可信接送人员添加照片——签退屏幕会显示照片，方便志愿者对眼前的人进行视觉核实。
:::

## 寻呼家长与紧急广播

这两项功能都通过教会连接的短信服务提供商发送短信——没有内置的短信服务，因此必须先配置受支持的提供商之一。

- **寻呼家长** -- 在有人值守的签到亭签退屏幕上，工作人员可以给已签到儿童的家长/监护人发短信（例如"请到婴儿室来"）。
- **紧急广播** -- 在签到亭的管理设置中，工作人员可以一次性给选定服务中所有已签到家庭的监护人发短信。发送需要输入**EMERGENCY**以确认。

已选择不接收短信或没有登记手机号码的人会被自动跳过——签到亭会报告发送了多少条短信、跳过了多少条。

参见 [签退与儿童安全](../../b1-checkin/check-in/checking-out) 中面向签到亭的操作说明。
