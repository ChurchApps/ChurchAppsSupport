# 签到

<div class="article-intro">

B1 Admin 通过配套的 **B1 Checkin** 应用支持礼拜自助签到。成员到达时可以在自助机或专用设备上为自己和家人签到，这样既快捷，又能减轻志愿者的工作负担。每一次签到都会自动记录为出勤。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你的校区、礼拜时间和小组必须已在[考勤设置](setup.md)中配置完成。
- 你需要在数据库中有[人员](../people/adding-people.md)，并设置好[家庭](../people/adding-people.md#managing-households)，这样家人才能一起签到。
- 你需要一台平板电脑，另外还可以选配兄弟牌（Brother）标签打印机（参见下方的[硬件推荐](#recommended-hardware)）。

</div>

## 工作原理

B1 Checkin 应用与你在 B1 Admin 中的考勤设置相连。成员签到时，其出勤会自动记录到正确的校区、礼拜时间和小组下。对于使用签到系统的成员，你无需手动录入出勤。

## 设置签到

1. **先配置考勤结构。** 在 B1 Admin 中，进入 **People > Attendance**，点击 **Setup**，确保校区、礼拜时间和小组已经建立。签到应用依赖于这些配置。你也可以为每个礼拜时间设置一个[签到计划](setup.md#setting-a-check-in-schedule)，使签到每周自动开放和关闭。计划使用的是礼拜所在校区的时区；如果校区未设置时区，则使用教会的时区。自助机会将签到窗口已关闭的礼拜时间显示为 **Closed**，并告知家庭签到何时开放。详见[考勤设置](setup.md)。
2. **在你计划使用的设备上安装 B1 Checkin 应用。** 该应用支持以下平台：
   - **iPad/iOS：** [Apple App Store](https://apps.apple.com/us/app/b1-church-check-in/id6775081998)
   - **Android/三星平板：** [Google Play Store](https://play.google.com/store/apps/details?id=church.b1.checkin)
   - **Amazon Fire 平板：** [Amazon App Store](https://www.amazon.com/Live-Church-Solutions-B1-Check-In/dp/B0FW5HKRB5/)
3. **使用教会账号登录 B1 Checkin 应用。**
4. **为当前聚会选择校区和礼拜时间。**
5. 成员现在可以在设备上搜索自己的名字并完成签到。

:::tip
将签到设备放在醒目、易于到达的位置，例如大厅入口或迎宾台。在礼拜期间简短地宣布一下，能让成员知道有这项服务。
:::

:::tip
如果你的教会有多个校区，需要在[考勤设置](setup.md)中为每个校区分别进行设置。每台签到设备都可以配置为不同的校区。
:::

## 推荐硬件 {#recommended-hardware}

**平板电脑**——以下任何一款都能很好地运行该应用：

- **紧凑型：** Samsung Galaxy Tab A7 Lite 8.7"
- **大屏幕：** Samsung Galaxy Tab A8 10.5"
- **经济型：** Amazon Fire HD 10

**打印机**——签到支持使用兄弟牌标签打印机打印名牌：

- **最佳：** Brother QL-1110NWB（支持通过蓝牙和 WiFi 连接多台平板）
- **良好：** Brother QL-810W（支持通过 WiFi 连接多台平板）
- **经济型：** Brother QL-1100（仅支持 WiFi）

**标签纸：** Brother DK-1201（1-1/7" x 3-1/2"）

:::warning
只有兄弟牌标签打印机与 B1 Checkin 应用兼容。其他品牌的打印机无法用于打印名牌。
:::

:::info
请按照打印机的设置说明，将其连接到与平板电脑相同的 WiFi 网络。你可以在[兄弟牌支持网站](https://support.brother.com)上找到兄弟牌打印机驱动程序和设置指南。
:::

## 自定义自助机外观

你可以自定义 B1 Checkin 应用的外观，使其与教会的品牌风格保持一致。在 B1 Admin 中，进入 **Mobile > B1 CheckIn**，使用 **Kiosk Theme** 卡片进行以下设置：

### 颜色

自定义八项颜色设置，以匹配教会的品牌形象：

- **Primary** 和 **Primary Contrast** —— 主品牌色及其文字颜色。
- **Secondary** 和 **Secondary Contrast** —— 强调色及其文字颜色。
- **Header Background** 和 **Subheader Background** —— 自助机顶部区域的颜色。
- **Button Background** 和 **Button Text** —— 交互按钮的颜色。

### 背景图片

可选择上传背景图片，用于自助机的欢迎屏幕和查找屏幕。推荐尺寸为 1920x1080 像素。

### 待机屏幕 / 屏幕保护

设置一个在无操作一段时间后启动的屏幕保护：

1. 将待机屏幕切换为**开启**或**关闭**。
2. 设置**超时时间**（无操作多少秒后启动屏幕保护，最少 10 秒）。
3. 添加一张或多张**幻灯片**——每张幻灯片包含一张图片和显示时长（最少 3 秒）。

:::tip
当自助机未被使用时，可以利用待机屏幕展示公告、即将举行的活动或欢迎信息。
:::

## 通过二维码进行访客登记

签到自助机可以显示一个二维码，访客扫描后即可在自己的手机上为自己和家人登记。这能加快首次到访的访客的签到流程。

访客扫描二维码后，会进入[访客登记页面](../../b1-church/checkin/guest-registration)，在该页面填写家人的姓名以及你选择要求填写的其他信息。之后，志愿者可以在自助机上查找访客并为其签到。

### 启用二维码访客登记

要开启二维码显示：

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（位于左上角的搜索栏），展开 **Mobile**。
2. 点击 **B1 CheckIn**。
3. 将 **QR Guest Registration** 切换为开启，然后点击 **Save**。

:::note
此设置位于 **Mobile > B1 CheckIn**（与 **Kiosk Theme** 卡片位于同一页面），而不在考勤下。考勤页面中的 **Kiosk** 操作带有指向此页面的链接。
:::

开启切换后，下方的其他选项会显示在同一个 **QR Guest Registration** 卡片中。更改任何选项后，请点击该卡片上的 **Save**。

### 选择报名字段

**Sign-up fields** 清单用于控制登记表单要求填写的内容。**First Name** 和 **Last Name** 始终显示在表单中，且每位家庭成员都必须填写。对于其他每个字段，开启 **Include** 即可将其添加到表单中；如果访客必须填写该字段，再开启 **Required**。只有在已包含某字段的情况下才能开启 **Required**，而关闭 **Include** 会同时清除其 **Required** 设置。

| 字段 | 收集对象 | 默认是否包含 |
|-------|-----------|---------------------|
| **Email** | 仅主要联系人 | 是（可选） |
| **Phone** | 仅主要联系人 | 是（可选） |
| **Home address** | 每个家庭填写一次——街道、地址第二行、城市、州/省和邮编。设为必填时，除地址第二行外的所有内容都必须填写。该地址会保存到每位家庭成员的记录中。 | 否 |
| **Birth date** | 每位家庭成员 | 否 |
| **Gender** | 每位家庭成员 | 否 |
| **Marital status** | 仅主要联系人 | 否 |
| **Grade** | 每位家庭成员（学前班至 12 年级，或已毕业） | 否 |
| **Comments** | 整体填写一次，位于家庭成员列表下方的文本框中（最多 1,000 个字符） | 否 |

关闭的字段即使有人通过其他方式将其提交到报名表，也绝不会被保存。留言会作为一条备注保存在主要联系人的记录上（标注为“Guest sign-up”），因此你可以在其个人资料的 **Notes** 部分查看。

### 将访客添加到小组

使用 **Add new guests to group** 可自动将所有报名的人员添加到你的某个小组中——例如“新来者”小组，或本周活动的小组。选择 **None**（默认值）即可跳过此项。访客永远看不到也无法选择小组；该设置只能在这里进行。每次活动前请更改此设置，以便你可以将该活动的访客归类跟进。

### 记录出勤

选择某个小组后，会出现 **Also record attendance** 开关。开启后，访客一旦报名即被标记为出席，无需你再单独签到。

只有在报名发生于所选小组的某个**已排定**礼拜时间内，才会记录出勤：

- 该小组必须已关联一个或多个礼拜时间，且这些礼拜时间必须设有[签到计划](setup.md#setting-a-check-in-schedule)（包括**星期**和**开始时间**）。
- “期间”指该礼拜时间的签到窗口内——从开始前 **Open check-in** 分钟，到结束后 **Close check-in** 分钟（若未设置结束时间，则从开始时间后计算），所使用的时区与签到计划相同。
- 对于其中每一个在当前时刻开放的礼拜时间，每位家庭成员都会在今天的日期下被标记为该小组的出席者。
- 在其他时间报名，或报名的小组其礼拜时间没有设置计划，则访客会被添加到小组中，但不会计入出勤。

### 页眉照片

在 **Header photo** 下，点击 **Change photo**，选择或上传一张图片（裁剪为 16:9 比例），用于替代默认图标显示在登记页面顶部。点击 **Remove** 即可恢复为图标。

### 分享登记链接

开启二维码访客登记后，卡片底部会出现 **Share registration QR code** 部分。除自助机二维码外，你还可以通过以下两种方式让访客进入登记表单：

- **Copy link** —— 复制登记网址，以便粘贴到教会网站、电子邮件或任何网络位置。
- **Download PNG** —— 将二维码下载为图片，用于印制传单、周报或标识牌。

:::tip
将登记链接添加到教会网站的“规划您的到访”或“我是新人”页面，这样访客甚至在到达之前就能完成登记。
:::

### 访客报名之后会发生什么

每次报名都会创建一个新的家庭，以主要联系人的姓氏命名，并为每位家庭成员创建一条人员记录。所有人都会以**访客（Visitor）**的会员状态添加到**人员**中，主要联系人为户主。

要自动跟进，可以添加一个[工作流触发器](../serving/workflows.md#triggers)，例如条件为*会员状态为 Visitor* 的 **Person · Created**，或针对你上面所选小组的 **Group · Member Joined**。

## 记录内容

每次签到都会在 B1 Admin 中生成一条出勤记录。你可以在[出勤](tracking-attendance.md)页面以及每个[小组](../groups/group-members.md)的聚会记录中查看这些记录，与手动录入的出勤完全一样。两种方式的数据呈现没有任何区别——两者都会汇入相同的报告。
