# 签到

<div class="article-intro">

B1 Admin 通过配套的 **B1 Checkin** 应用支持礼拜自助签到。会众到达时，可以在自助终端或专用设备上为自己和家人签到，过程快速，也能减轻志愿者的工作负担。每次签到都会自动记录为考勤。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您的堂点、礼拜时间和小组必须已在[考勤设置](setup.md)中配置完成。
- 您需要在[数据库中有人员](../people/adding-people.md)，并设置[家庭](../people/adding-people.md#managing-households)，以便家人可以一起签到。
- 您需要一台平板电脑，另外可选配 Brother 标签打印机（参见下方的[硬件推荐](#recommended-hardware)）。

</div>

## 工作原理

B1 Checkin 应用与您在 B1 Admin 中的考勤设置相连接。会众签到时，其考勤会自动记录到正确的堂点、礼拜时间和小组下。对于使用签到系统的会众，您无需手动录入考勤。

## 设置签到

1. **先配置考勤结构。** 在 B1 Admin 中，进入 **人员 > 考勤**，点击 **设置**，确保堂点、礼拜时间和小组已经建立。签到应用依赖于这些配置。您也可以为每个礼拜时间设置[签到时间表](setup.md#setting-a-check-in-schedule)，使签到每周自动开始和关闭。时间表采用该礼拜所在堂点的时区；如果堂点未设置时区，则采用您教会的时区。在签到窗口关闭时，终端会将礼拜时间列为 **已关闭**，并告知家人签到何时开始。详情参见[考勤设置](setup.md)。
2. **在您计划使用的设备上安装 B1 Checkin 应用。** 该应用支持以下平台：
   - **iPad/iOS：** [苹果应用商店](https://apps.apple.com/us/app/b1-church-check-in/id6775081998)
   - **Android/三星平板：** [Google Play 商店](https://play.google.com/store/apps/details?id=church.b1.checkin)
   - **Amazon Fire 平板：** [Amazon 应用商店](https://www.amazon.com/Live-Church-Solutions-B1-Check-In/dp/B0FW5HKRB5/)
3. **使用具有 **Checkin** 考勤权限（或 **Edit Attendance**）的账户登录 B1 Checkin 应用。** 参见[签到自助终端账户](../settings/roles-permissions.md#check-in-kiosk-accounts)。
4. **为当前聚会选择堂点和礼拜时间。**
5. 会众现在即可在设备上搜索自己的姓名并完成签到。

:::tip
请将签到设备放在显眼、易于取用的位置，例如大厅入口或迎宾台。在礼拜中简短宣布一下，可以让会众知道这一选项的存在。
:::

:::tip
如果您的教会有多个堂点，需要在[考勤设置](setup.md)中为每个堂点分别完成设置。每台签到设备都可以配置为不同的堂点。
:::

## 推荐硬件

**平板电脑**——以下任何一款都能很好地运行该应用：

- **小巧型：** Samsung Galaxy Tab A7 Lite 8.7"
- **大屏型：** Samsung Galaxy Tab A8 10.5"
- **经济型：** Amazon Fire HD 10

**打印机**——签到支持使用 Brother 标签打印机打印名牌：

- **最佳：** Brother QL-1110NWB（支持通过蓝牙和 WiFi 连接多台平板）
- **良好：** Brother QL-810W（支持通过 WiFi 连接多台平板）
- **经济型：** Brother QL-1100（仅支持 WiFi）

**标签纸：** Brother DK-1201（1-1/7" x 3-1/2"）

:::warning
只有 Brother 标签打印机与 B1 Checkin 应用兼容。其他品牌的打印机无法用于打印名牌。
:::

:::info
请按照打印机的设置说明，将其连接到与平板电脑相同的 WiFi 网络。您可以在 [Brother 支持网站](https://support.brother.com)上找到 Brother 打印机驱动程序和设置指南。
:::

## 自定义自助终端外观

您可以自定义 B1 Checkin 应用的外观，使其与教会的品牌风格保持一致。在 B1 Admin 中，进入 **移动 > B1 CheckIn**，使用 **自助终端主题** 卡片进行设置：

### 颜色

自定义八项颜色设置，以匹配教会的品牌形象：

- **主色** 和 **主色文字** —— 主品牌色及其文字颜色。
- **辅助色** 和 **辅助色文字** —— 强调色及其文字颜色。
- **页眉背景** 和 **副页眉背景** —— 自助终端页眉区域的颜色。
- **按钮背景** 和 **按钮文字** —— 交互按钮的颜色。

### 背景图片

可选上传一张背景图片，用于自助终端的欢迎和查询界面。建议尺寸为 1920x1080 像素。

### 待机屏幕 / 屏保

设置在一段时间无操作后启动的屏保：

1. 将待机屏幕切换为 **开启** 或 **关闭**。
2. 设置 **超时时间**（无操作多少秒后启动屏保，最少 10 秒）。
3. 添加一张或多张 **幻灯片**——每张幻灯片包含一张图片和显示时长（最少 3 秒）。

:::tip
在自助终端闲置时，可以利用待机屏幕展示通知、即将举行的活动或欢迎语。
:::

## 通过二维码进行访客登记

签到自助终端可以显示一个二维码，访客用自己的手机扫码，即可为自己和家人登记信息。这能加快首次到访的访客的签到过程。

访客扫描二维码后，会进入[访客登记页面](../../b1-church/checkin/guest-registration.md)，在那里填写家人的姓名以及您选择要求填写的其他信息。随后，志愿者可以在自助终端上找到他们并为其签到。

### 启用二维码访客登记

要开启二维码显示：

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（位于左上角的搜索栏），展开 **移动**。
2. 点击 **B1 CheckIn**。
3. 将 **二维码访客登记** 切换为开启，然后点击 **保存**。

:::note
此设置位于 **移动 > B1 CheckIn**（与 **自助终端主题** 卡片所在的页面相同），而不是考勤页面下。考勤页面中的 **自助终端** 操作带有一个指向此页面的链接。
:::

开关打开后，下方的其他选项会出现在同一张 **二维码访客登记** 卡片中。更改其中任何设置后，请点击该卡片上的 **保存**。

### 选择登记字段

**登记字段** 清单用于控制登记表单询问的内容。**名字** 和 **姓氏** 始终在表单中，并且对每位家庭成员都是必填项。对于其他每个字段，打开 **包含** 即可将其加入表单，再打开 **必填** 则要求访客必须填写。只有在已包含某字段的情况下才能开启 **必填**，并且关闭 **包含** 会同时清除该字段的必填设置。

| 字段 | 询问对象 | 默认包含 |
|-------|-----------|---------------------|
| **称谓** | 每位家庭成员，以下拉菜单形式显示在姓名前面（先生、夫人、小姐、女士、博士、教授、牧师、Pastor 牧师） | 否 |
| **电子邮件** | 仅主要联系人 | 是（可选） |
| **电话** | 每位家庭成员。设为必填时，仅主要联系人必须填写。 | 是（可选） |
| **家庭角色** | 主要联系人之后的每位家庭成员——配偶、子女或其他。主要联系人为新家庭的户主。未选择角色的成员将被保存为“其他”。 | 是（可选） |
| **家庭住址** | 整个家庭填写一次——街道、地址第二行、城市、州/省和邮政编码。设为必填时，除地址第二行外的所有内容都必须填写。该地址会保存到每位家庭成员的记录中。 | 否 |
| **出生日期** | 每位家庭成员 | 否 |
| **性别** | 每位家庭成员 | 否 |
| **婚姻状况** | 仅主要联系人 | 否 |
| **年级** | 每位家庭成员（学前班至 12 年级，或已毕业） | 否 |
| **备注** | 整体填写一次，位于家庭成员下方的文本框中（最多 1,000 个字符） | 否 |

即使有人以其他方式将已关闭的字段提交到登记表，这些字段也绝不会被保存。备注会以笔记的形式保存在主要联系人的记录中（标注为“访客登记”），因此您可以在其个人资料的 **笔记** 部分查看。

### 将访客添加到小组

使用 **将新访客添加到小组** 可以自动将所有登记的人员加入您的某个小组，例如“新朋友”小组或本周活动的小组。选择 **无**（默认值）即可跳过此步骤。访客无法看到或选择小组，小组只能在此处设置。请在每次活动前更改此设置，以便您可以集中跟进该次活动的访客。

### 记录考勤

选择小组后，会出现 **同时记录考勤** 开关。打开它后，访客一完成登记即被标记为出席，无需另行签到。

只有当登记发生在所选小组的某个**已安排**礼拜时间内时，才会记录考勤：

- 该小组必须关联一个或多个礼拜时间，且这些礼拜时间必须设有[签到时间表](setup.md#setting-a-check-in-schedule)（包括**星期**和**开始时间**）。
- “期间”指该礼拜时间的签到窗口之内——从开始前的**提前开放签到**分钟数，直到结束后的**延后关闭签到**分钟数为止（若未设置结束时间，则以开始后的分钟数为准；若既无结束时间也无关闭分钟数，则直到当天结束）。计算采用签到时间表所使用的时区。
- 对于该小组的每一个在此时刻处于开放签到状态的礼拜时间，每位家庭成员都会在当天日期下被标记为该小组的出席者。
- 在其他时间登记，或登记的小组其礼拜时间没有设置时间表，则访客会被添加到小组中，但不计为出席。

### 页眉照片

在 **页眉照片** 下，点击 **更换照片**，选择或上传一张图片（会裁剪为 16:9 的比例），用于替代默认图标，显示在登记页面顶部。点击 **移除** 即可恢复为图标。

### 分享登记链接

启用二维码访客登记后，卡片底部会出现 **分享登记二维码** 部分。除了自助终端上的二维码外，您还可以通过以下两种方式让访客进入登记表：

- **复制链接**——复制登记网址，以便将其粘贴到教会网站、电子邮件或任何网络平台上。
- **下载 PNG**——将二维码下载为图片，可印在传单、主日周报或标识牌上。

:::tip
将登记链接添加到教会网站的“计划您的到访”或“我是新朋友”页面，让访客在到达之前就能完成登记。
:::

### 访客登记后会发生什么

B1 会首先在**人员**中查找已存在的人员。当恰好有一人的名字相同，并且电子邮件或电话也相同时，家庭成员会与该现有人员匹配。未填写电子邮件或电话的儿童，会在已匹配的家庭内按名字进行匹配。匹配到的人员将按原样沿用——登记不会更改其资料或会员状态——而新的人员则会加入已匹配的家庭。

若没有匹配结果，登记会创建一个以主要联系人姓氏命名的新家庭，并为每位家庭成员建立人员记录。所有新增人员都会以会员状态“访客”添加到**人员**中，主要联系人为户主。

无论是匹配到的还是新增的人员，如果尚未在您选择的小组中，都会被添加到该小组；若已开启相关选项，还会记录其考勤。备注会保存为主要联系人的笔记。

若要自动跟进，可以添加[工作流触发器](../serving/workflows.md#triggers)，例如条件为*会员状态为访客*的 **人员 · 已创建**，或针对上文所选小组的 **小组 · 成员已加入**。

## 记录内容

每次签到都会在 B1 Admin 中生成一条考勤记录。您可以在[考勤](tracking-attendance.md)页面以及每个[小组](../groups/group-members.md)的聚会记录中查看这些记录，与手动录入的考勤完全一样。两种方式的数据显示没有任何区别——两者都会汇入相同的报表。
