# 签到

<div class="article-intro">

B1 Admin 通过配套的 **B1 Checkin** 应用支持在服侍中进行自助签到。成员可以在抵达时在亭子或专用设备上为自己和家人签到，让过程快速高效，减轻志愿者的工作量。每次签到都会自动记录为出席记录。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你的校园、服侍时间和小组必须在[出席设置](setup.md)中配置。
- 你需要数据库中[有人员](../people/adding-people.md)并[建立家庭](../people/adding-people.md#managing-households)，以便家庭可以一起签到。
- 你需要一台平板电脑，可选地需要一台Brother标签打印机（见下面的[硬件建议](#recommended-hardware)）。

</div>

## 工作原理

B1 Checkin 应用连接到你的 B1 Admin 出席设置。当成员签到时，他们的出席会自动记录到正确的校园、服侍时间和小组。你不需要为使用签到系统的任何人手动输入出席记录。

## 设置签到

1. **首先配置你的出席结构。** 在 B1 Admin 中，转到 **出席 > 设置**，确保你的校园、服侍时间和小组已就位。签到应用依赖于此配置。详见[出席设置](setup.md)。
2. **在你计划使用的设备上安装 B1 Checkin 应用**。该应用可在以下平台上获得：
   - **iPad/iOS：**[Apple App Store](https://apps.apple.com/us/app/b1-church-check-in/id6775081998)
   - **Android/Samsung 平板电脑：**[Google Play 商店](https://play.google.com/store/apps/details?id=church.b1.checkin)
   - **Amazon Fire 平板电脑：**[Amazon App Store](https://www.amazon.com/Live-Church-Solutions-B1-Check-In/dp/B0FW5HKRB5/)
3. **使用你教会的帐户凭证登录 B1 Checkin 应用**。
4. **选择当前聚会的校园和服侍时间**。
5. 成员现在可以在设备上搜索他们的名字并签到。

:::tip
将签到设备放在显眼、易于到达的位置，例如大厅入口或欢迎台。在服侍中进行简短的宣布有助于成员了解此选项可用。
:::

:::tip
如果你的教会有多个校园，你需要在[出席设置](setup.md)中为每个校园重复设置。每个签到设备可以针对不同的校园进行配置。
:::

## 推荐硬件

**平板电脑** — 以下任何型号都能很好地与应用兼容：

- **紧凑型：** Samsung Galaxy Tab A7 Lite 8.7"
- **大屏幕：** Samsung Galaxy Tab A8 10.5"
- **预算型：** Amazon Fire HD 10

**打印机** — 签到适用于 Brother 标签打印机以打印名卡：

- **最佳：** Brother QL-1110NWB（通过蓝牙和 WiFi 支持多台平板电脑）
- **良好：** Brother QL-810W（通过 WiFi 支持多台平板电脑）
- **预算型：** Brother QL-1100（仅 WiFi）

**标签：** Brother DK-1201（1-1/7" × 3-1/2"）

:::warning
只有 Brother 标签打印机与 B1 Checkin 应用兼容。其他打印机品牌不能用于打印名卡。
:::

:::info
按照打印机的设置说明将其连接到与平板电脑相同的 WiFi 网络。你可以在 [Brother 支持网站](https://support.brother.com) 上找到 Brother 打印机驱动程序和设置指南。
:::

## 自定义亭子外观

你可以自定义 B1 Checkin 应用的外观以匹配你教会的品牌。在 B1 Admin 中，转到 **出席 > 亭子主题** 来配置：

### 颜色

自定义八种颜色设置以匹配你的教会品牌：

- **主色** 和 **主色对比** — 主品牌颜色及其文本颜色。
- **次色** 和 **次色对比** — 强调色及其文本颜色。
- **标题背景** 和 **副标题背景** — 亭子标题区域的颜色。
- **按钮背景** 和 **按钮文本** — 交互按钮的颜色。

### 背景图像

为亭子欢迎和查询屏幕上传可选的背景图像。推荐尺寸为 1920x1080 像素。

### 闲置屏幕/屏幕保护程序

配置在一段不活动后激活的屏幕保护程序：

1. 切换闲置屏幕**开启**或**关闭**。
2. 设置**超时**（不活动多少秒后屏幕保护程序启动，最少 10 秒）。
3. 添加一个或多个**幻灯片** — 每个幻灯片有一个图像和显示时长（最少 3 秒）。

:::tip
使用闲置屏幕在亭子未被积极使用时显示公告、即将举行的活动或欢迎信息。
:::

## 通过二维码进行访客登记

签到亭子可以显示访客可以扫描的二维码，以在他们自己的手机上为自己和家人登记。这加快了首次来访者的签到过程。

当访客扫描二维码时，他们会被带到一个[访客登记页面](../../b1-church/checkin/guest-registration)，在那里他们输入他们的名字、电子邮件和家庭成员。然后志愿者可以在亭子上查找他们并为他们签到。

### 启用二维码访客登记

要打开二维码显示：

1. 在 B1 Admin 中，打开左上角的**部分菜单**（部分名称和小箭头）并选择**移动**。
2. 选择 **B1 CheckIn** 标签页。
3. 切换**二维码访客登记**打开并点击**保存**。

:::note
此设置在**移动**下，不在出席 > 亭子主题下。
:::

### 共享登记链接

启用二维码访客登记后，会在切换下方出现**共享登记二维码**部分。这为你提供了两种方式让访客访问登记表单，除了亭子二维码之外：

- **复制链接** — 复制登记 URL，以便你可以将其粘贴到你的教会网站、电子邮件或任何在线位置。
- **下载 PNG** — 下载二维码作为图像，你可以在传单、通讯或标志上打印。

:::tip
将登记链接添加到你教会网站的"计划你的访问"或"我是新的"页面，这样访客甚至可以在到达之前进行登记。
:::

## 记录什么

每次签到都会在 B1 Admin 中创建一条出席记录。你可以像手动输入的出席一样在[出席](tracking-attendance.md)和[小组](../groups/group-members.md)标签页中查看这些记录。两种方法的数据显示没有区别 — 两种方法都输入相同的报告中。
