# 签到

<div class="article-intro">

B1 Admin 通过配套的 **B1 Checkin** 应用程序支持在服务中进行自助签到。成员可以在到达时在自助服务终端或专用设备上为自己和家人签到，使过程快速进行，并减少志愿者的工作量。每次签到都会自动记录为出勤率。

</div>

<div class="prereqs">
<h4>在开始之前</h4>

- 您的校园、服务时间和小组必须在[出勤设置](setup.md)中配置。
- 您需要在数据库中[添加人员](../people/adding-people.md)，并[设置家庭](../people/adding-people.md#managing-households)，以便家庭成员可以一起签到。
- 您需要一台平板电脑，以及可选的 Brother 标签打印机（请参阅下面的[硬件建议](#recommended-hardware)）。

</div>

## 工作原理

B1 Checkin 应用程序连接到您的 B1 Admin 出勤设置。当成员签到时，其出勤率会自动根据正确的校园、服务时间和小组进行记录。您无需为使用签到系统的任何人手动输入出勤率。

## 设置签到

1. **首先配置您的出勤结构。** 在 B1 Admin 中，转到**出勤 > 设置**，并确保您的校园、服务时间和小组已就位。签到应用程序依赖于此配置。有关详细信息，请参阅[出勤设置](setup.md)。
2. **在您计划使用的设备上安装 B1 Checkin 应用程序**。该应用程序可在以下平台上使用：
   - **iPad/iOS：** [Apple App Store](https://apps.apple.com/us/app/b1-church-check-in/id6775081998)
   - **Android/Samsung 平板电脑：** [Google Play Store](https://play.google.com/store/apps/details?id=church.b1.checkin)
   - **Amazon Fire 平板电脑：** [Amazon App Store](https://www.amazon.com/Live-Church-Solutions-B1-Check-In/dp/B0FW5HKRB5/)
3. **使用您的教会帐户凭据登录 B1 Checkin 应用程序**。
4. **为当前集会选择校园和服务时间**。
5. 成员现在可以在设备上搜索其名称并签到。

:::tip
将签到设备放在明显、易于到达的位置，例如大厅入口或欢迎台。在服务期间进行简短宣布有助于成员了解此选项的可用性。
:::

:::tip
如果您的教会有多个校园，您需要在[出勤设置](setup.md)中为每个校园重复此设置。每个签到设备都可以配置用于不同的校园。
:::

## 推荐硬件

**平板电脑** — 以下任何一款都可以很好地与应用程序配合使用：

- **紧凑型：** Samsung Galaxy Tab A7 Lite 8.7"
- **大屏幕：** Samsung Galaxy Tab A8 10.5"
- **预算型：** Amazon Fire HD 10

**打印机** — 签到可与 Brother 标签打印机配合使用以打印名称标签：

- **最佳：** Brother QL-1110NWB（支持通过蓝牙和 WiFi 连接多个平板电脑）
- **不错：** Brother QL-810W（支持通过 WiFi 连接多个平板电脑）
- **预算型：** Brother QL-1100（仅 WiFi）

**标签：** Brother DK-1201（1-1/7" x 3-1/2"）

:::warning
只有 Brother 标签打印机与 B1 Checkin 应用程序兼容。其他打印机品牌将无法用于打印名称标签。
:::

:::info
按照打印机的设置说明将其连接到与您的平板电脑相同的 WiFi 网络。您可以在[Brother 支持网站](https://support.brother.com)上找到 Brother 打印机驱动程序和设置指南。
:::

## 自定义自助服务终端外观

您可以自定义 B1 Checkin 应用程序的外观和风格，使其与您的教会品牌相匹配。在 B1 Admin 中，转到**移动 > B1 CheckIn**，并使用**自助服务终端主题**卡配置：

### 颜色

自定义八个颜色设置以匹配您的教会品牌：

- **主要**和**主要对比** -- 主品牌颜色及其文本颜色。
- **辅助**和**辅助对比** -- 强调颜色及其文本颜色。
- **页眉背景**和**副页眉背景** -- 自助服务终端页眉区域的颜色。
- **按钮背景**和**按钮文本** -- 交互按钮的颜色。

### 背景图像

为自助服务终端欢迎和查询屏幕上传可选的背景图像。建议大小为 1920x1080 像素。

### 空闲屏幕 / 屏幕保护程序

配置在一段时间不活动后激活的屏幕保护程序：

1. 切换空闲屏幕**打开**或**关闭**。
2. 设置**超时**（在屏幕保护程序启动之前不活动的秒数，最少 10 秒）。
3. 添加一个或多个**幻灯片** -- 每张幻灯片都有一个图像和显示时长（最少 3 秒）。

:::tip
使用空闲屏幕在自助服务终端未主动使用时显示公告、即将发生的事件或欢迎消息。
:::

## 通过二维码进行访客注册

签到自助服务终端可以显示一个二维码，访客可以在他们自己的电话上扫描该二维码，以便为自己和家人注册。这加快了首次访客的签到过程。

当访客扫描二维码时，他们会被带到[访客注册页面](../../b1-church/checkin/guest-registration)，他们在那里输入其名称、电子邮件和家庭成员。志愿者可以在自助服务终端上查找他们并为其签到。

### 启用二维码访客注册

要打开二维码显示：

1. 在 B1 Admin 中，打开[Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏）并展开**移动**。
2. 单击**B1 CheckIn**。
3. 打开**二维码访客注册**并单击**保存**。

:::note
此设置位于**移动 > B1 CheckIn**（与**自助服务终端主题**卡相同的页面）下，而不是出勤下。
:::

### 共享注册链接

一旦启用了二维码访客注册，**共享注册二维码**部分将显示在切换下方。这为您提供了两种方法来获取访客访问注册表单，除了自助服务终端二维码外：

- **复制链接** — 复制注册 URL，以便您可以将其粘贴到您的教会网站、电子邮件或任何在线位置。
- **下载 PNG** — 将二维码下载为图像，您可以将其打印在传单、公告或标志上。

:::tip
将注册链接添加到您的教会网站的"计划您的访问"或"我是新的"页面，以便访客可以在到达之前注册。
:::

## 记录的内容

每次签到都会在 B1 Admin 中创建出勤记录。您可以在[出勤](tracking-attendance.md)和[小组](../groups/group-members.md)选项卡上查看这些记录，就像手动输入的出勤率一样。数据显示方式没有区别 — 两种方法都会进入相同的报告。
