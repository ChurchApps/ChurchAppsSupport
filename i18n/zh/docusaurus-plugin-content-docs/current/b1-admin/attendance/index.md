# 考勤

<div class="article-intro">

B1 Admin中的考勤部分为您提供了一个完整的视图,可以了解谁在您的教会中出现以及您的团队随时间的增长情况。从配置校园和服务时间到审查趋势和设置自动签到,您需要的所有内容都在此页面进行管理以跟踪和理解考勤。

</div>

## 页面概览

要打开此页面,请打开[Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)(左上角的搜索栏),展开**人员**,然后单击**出勤**。页面打开时显示**本周**(周日至周六)的摘要。

左列显示本周的日期以及**在场**人数总计 -- 如果本周输入了人数,则为人数总计,否则为已签到人数。总计下方显示已签到、已计数和访客人数,如果有多个服务,还会按服务拆分。如果本周尚无人签到,则显示最近一个有出勤记录的周。

页面主区域显示:

- **房间** -- 本周有人签到的每个小组,以及签到人数(对于设有签到容量的小组,还会显示容量条)。单击小组即可打开。
- **访客** -- 本周以访客身份签到的人员。单击姓名即可打开其记录。
- **最近 13 周** -- 每周签到次数的小型柱状图,以及其中有签到记录的周数。
- **本周人数** -- 为本周服务输入的人数。

## 操作

左列还包含页面的操作。每项操作都会在主区域打开;单击**考勤**返回链接即可返回每周摘要。

### 设置

单击**设置**以配置考勤跟踪的基础模块。在这里,您定义校园,向每个校园添加服务和服务时间(包括每个服务时间可选的签到时间表),并查看哪些[团队](../groups/creating-groups.md)分配给这些服务时间。页面顶部显示校园、服务时间、已计划和未计划团队以及团队总数的计数。您只需要进行一次此操作,但每当日程更改时可以更新它。有关完整的演练,请参阅[考勤设置](setup.md)。

### 所有年份(报告)

单击**所有年份**以打开考勤报告。顶部的选项卡可在**考勤趋势**(整个教会随时间的趋势)、**人数统计趋势**(按周汇总的人数总计)和**团队考勤**(按单个团队分解的考勤)之间切换。使用过滤器按日期范围、校园或服务时间缩小结果。有关使用报告和过滤器的详细信息,请参阅[跟踪考勤](tracking-attendance.md)。

### 输入人数

单击**输入人数**可为服务、服务时间或团队记录一个简单的总计数,而不是已命名的名单。有关详细信息,请参阅[人数统计输入和趋势](headcount-entry.md)。

### 自助服务终端

单击**自助服务终端**以打开**自助服务终端主题**设置,您可以在其中设置签到自助服务终端的背景图像和空闲屏幕行为。**签到自助服务终端、二维码和标签**链接会带您进入完整的[B1 CheckIn 设置](check-in.md)。
