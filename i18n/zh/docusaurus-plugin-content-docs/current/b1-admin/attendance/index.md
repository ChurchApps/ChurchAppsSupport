# 考勤

<div class="article-intro">

B1 Admin 中的考勤板块让你全面掌握教会的到场情况，以及各小组随时间的增长状况。从配置堂区和聚会时间，到查看趋势和设置自助签到，你所需要的一切用于跟踪和了解考勤的功能都可以在此页面管理。

</div>

## 页面概览 {#page-overview}

要打开此页面，请打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **People**，然后点击 **Attendance**。页面默认显示**本周**（周日至周六）的摘要。

左侧栏显示本周的日期以及**在场**的总人数——如果本周登记过人数，则为人数登记的总计；否则为已签到的人数。总数下方会显示已签到、已计数的人数以及访客人数；如果有多个聚会，还会按聚会分列。如果本周尚无人签到，页面会说明这一情况，并显示最近一次记录考勤的日期（例如"上次记录：2026 年 1 月 25 日：10"）。

页面主区域显示以下内容：

- **Rooms**——本周有人签到的每个小组，以及签到人数（对于设有签到容量的小组，还会显示容量进度条）。点击某个小组即可打开。
- **Guests**——本周以访客身份签到的人员。点击姓名即可打开其记录。
- **Last 13 weeks**——每周签到次数的小型柱状图，以及其中有签到记录的周数。其 **All years** 链接可打开报表。
- **Headcounts this week**——为本周聚会登记的人数。

## 操作 {#actions}

左侧栏也包含本页面的各项操作。每项操作都会在主区域打开；点击 **Attendance** 返回链接即可回到每周摘要。

### Setup {#setup}

点击 **Setup** 配置考勤跟踪的基本组成部分（仅对拥有 **Edit Services** 考勤权限的人员显示）。在这里，你可以定义堂区、为每个堂区添加聚会和聚会时间（可为每个聚会时间选择性地设置签到时间表），并查看哪些[小组](../groups/creating-groups.md)被分配到这些聚会时间。页面顶部会显示堂区、聚会时间、已排定和未排定的小组以及小组总数的统计。此设置通常只需完成一次，但当你的时间安排发生变化时，可随时更新。完整的操作说明请参阅[考勤设置](setup.md)。

### All years（报表） {#all-years-reports}

点击 **All years** 打开考勤报表。顶部的标签可在 **Attendance Trend**（教会整体随时间的趋势）、**Headcount Trend**（按周统计的人数总计）和 **Group Attendance**（按各个小组细分的考勤）之间切换。使用筛选器可按日期范围、堂区或聚会时间缩小结果范围。有关使用报表和筛选器的详细信息，请参阅[跟踪考勤](tracking-attendance.md)。

### Enter headcount {#enter-headcount}

点击 **Enter headcount**，为某场聚会、某个聚会时间或某个小组登记一个简单的总人数，而无需使用记名名单。详情请参阅[人数登记与趋势](headcount-entry.md)。

### Kiosk {#kiosk}

点击 **Kiosk** 打开 **Kiosk Theme** 设置，在此可设置签到亭的背景图片和待机屏幕。**Check-in kiosk, QR, and labels** 链接会带你进入完整的 [B1 CheckIn 设置](check-in.md)，其中还包括二维码访客登记以及[标签设计器](labels.md)。签到亭的颜色来自 **Mobile > App Theme**。
