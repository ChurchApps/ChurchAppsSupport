# 考勤

<div class="article-intro">

B1 Admin 中的"考勤"部分让您全面了解教会的出席情况以及各小组随时间的发展趋势。从配置堂点和聚会时间，到查看趋势和设置自助签到，跟踪和了解考勤所需的一切都在这一页面中管理。

</div>

## 页面概览

打开"考勤"页面后，您会在顶部看到一个标题栏，其中包含有关教会考勤设置的关键统计数据：

- **堂点** -- 您已配置的实体场所数量
- **聚会时间** -- 所有堂点的聚会总数
- **已安排的小组** -- 分配给特定聚会时间的小组
- **未安排的小组** -- 独立于聚会时间跟踪考勤的小组

标题栏下方有三个标签页，用于组织您的考勤工具。

## 标签页

### 设置

**设置**标签页用于配置考勤跟踪的基础模块。您可以在此定义堂点、为每个堂点添加聚会时间，并将[小组](../groups/creating-groups.md)分配给这些聚会时间。这项工作通常只需完成一次，但您可以随着日程变化随时更新。有关完整操作说明，请参阅[考勤设置](setup.md)。

### 考勤

**考勤**标签页显示随时间变化的考勤趋势。使用筛选器按日期范围、堂点或聚会时间缩小结果范围，快速发现数据中的规律。有关使用报表和筛选器的详细信息，请参阅[跟踪考勤](tracking-attendance.md)。

### 小组

**小组**标签页按单个小组细分考勤数据。当您想查看某个特定小组、班级或事工团队的具体情况，而不是查看全教会数据时，这个功能非常有用。
