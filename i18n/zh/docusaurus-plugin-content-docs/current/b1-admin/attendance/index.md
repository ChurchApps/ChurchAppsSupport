# 考勤

<div class="article-intro">

B1 Admin中的考勤部分为您提供了一个完整的视图,可以了解谁在您的教会中出现以及您的团队随时间的增长情况。从配置校园和服务时间到审查趋势和设置自动签到,您需要的所有内容都在此页面进行管理以跟踪和理解考勤。

</div>

## 页面概览

当您打开考勤页面时,您将看到一个标题,其中包含有关教会考勤设置的关键统计数据:

- **校园** - 您已配置的物理位置数量
- **服务时间** - 所有校园中的服务总数
- **已计划的团队** - 分配给特定服务时间的团队
- **未计划的团队** - 独立于服务时间跟踪考勤的团队

标题下方,三个选项卡组织您的考勤工具。

## 选项卡

### 设置

**设置**选项卡是您配置考勤跟踪的基础模块的地方。在这里,您定义校园,向每个校园添加服务时间,并将[团队](../groups/creating-groups.md)分配给这些服务时间。您只需要进行一次此操作,但每当日程更改时可以更新它。有关完整的演练,请参阅[考勤设置](setup.md)。

### 考勤

**考勤**选项卡显示随时间推移的考勤趋势。使用过滤器按日期范围、校园或服务时间缩小结果,并快速发现数据中的模式。有关使用报告和过滤器的详细信息,请参阅[跟踪考勤](tracking-attendance.md)。

### 团队

**团队**选项卡将考勤按单个团队分解。当您想查看特定的小组、班级或事工团队的表现而不是查看教会范围内的数字时,这很有帮助。

### 人数统计和人数统计趋势

**人数统计**选项卡允许您为服务、服务时间或团队记录一个简单的总计数,**人数统计趋势**选项卡按周对这些总计进行制图。有关详细信息,请参阅[人数统计输入和趋势](headcount-entry.md)。
