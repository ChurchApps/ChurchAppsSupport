# 人数登记与趋势

<div class="article-intro">

人数让您记录简单的总出勤人数 — 针对服务、服务时间或小组 — 无需检查已命名的花名册。当您只需要"有多少人在这里"时使用此功能，并将其与人数趋势报告配对以观看该数字随时间的变化。

</div>

<div class="prereqs">
<h4>在开始之前</h4>

- 您的校园、服务和服务时间必须被配置。请参阅[出勤设置](setup.md)。
- 输入人数需要**出勤 > 编辑**权限；查看趋势报告需要**出勤 > 查看**。请参阅[角色与权限](../settings/roles-permissions.md)。

</div>

:::info
人数是[记录出勤](recording-attendance.md)的仅总计替代方案。如果您需要知道**谁**出席了 — 例如，要跟进那些没有回来的人 — 继续在小组的会话选项卡上使用已命名的会话出勤。人数只存储一个数字。
:::

## 记录人数

1. 打开**B1 Admin**，打开[Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**人员**，然后单击**出勤**。
2. 选择**人数**子选项卡。
3. 填写表单：
   - **服务** *（必需）*
   - **服务时间** -- 留空以记录所有服务时间的总计
   - **小组** -- 可选；仅列出启用了跟踪出勤的小组。留空为"无小组（整个服务）"。
   - **日期**
   - **人数** -- 在场的人数总数
4. 单击**保存**。

右侧的**最近人数**表列出您最后几个条目及其日期、服务、服务时间、小组和数量。单击一行可将其重新加载到表单中，如果您需要更正或删除。

## 人数趋势报告

1. 从同一**出勤**页面，选择**人数趋势**选项卡。
2. 使用**校园**、**服务**、**服务时间**和**小组**过滤器缩小报告范围。

报告显示您记录的人数按周汇总，既显示为折线图也显示为表格 — 与[出勤和小组趋势选项卡](tracking-attendance.md)使用的相同报告样式。
