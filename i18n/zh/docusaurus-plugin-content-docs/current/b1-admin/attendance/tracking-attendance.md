# 跟踪出勤

<div class="article-intro">

配置好校园、服务时间和小组后，B1 Admin 可以轻松查看出勤数据和发现趋势。出勤页面提供两个报告视图 — **出勤趋势**选项卡用于整个教会的趋势，**小组出勤**选项卡用于小组级别的细节。使用这些工具了解增长模式、识别参与度下降，并为您的教会做出数据驱动的决策。

</div>

<div class="prereqs">
<h4>在开始之前</h4>

- 您的出勤结构必须设置至少一个校园和服务时间。如果您还没有这样做，请参阅[出勤设置](setup.md)。
- 在报告显示结果之前，需要记录出勤数据。数据可以来自[手动输入](recording-attendance.md)或[自助签到](check-in.md)。

</div>

## 查看出勤趋势

1. 打开**B1 Admin**，打开[Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**人员**，然后单击**出勤**。
2. 单击**出勤趋势**选项卡。
3. 报告在选项卡打开时自动运行，显示每周的总出勤人数。

## 过滤您的数据

使用**过滤报告**框中的过滤器缩小结果，然后单击**运行报告**：

- **校园** -- 选择一个校园以仅查看该位置的出勤。
- **服务** -- 将报告限制为一个服务。
- **服务时间** -- 选择一个服务时间以深入了解特定的集会。
- **小组** -- 显示单个小组的出勤。
- **开始日期**和**结束日期** -- 要包含的日期范围。默认情况下，报告涵盖过去的一年，从一年前到今天，并且结束日期完全包括在内。

报告显示条形图和每周总访问次数的表格。每周都标有该周星期天的日期。该表还有一个**会话日期**列，列出该周有出勤的实际日期（例如"9/27, 9/30"），这样您可以看到何时中周集会与星期天在同一周内计算。

:::info
报告在每次打开出勤趋势选项卡时自动运行，因此您始终会看到最新的数字，而无需单击刷新按钮。
:::

## 小组出勤

**小组出勤**选项卡显示谁参加了每个小组会议。当您想监视特定班级、事工团队或小小组而不是查看整体服务数字时，这非常有用。

1. 选择**小组出勤**选项卡。
2. 可选择选择一个**校园**和**服务**。
3. 设置**开始日期**和**结束日期**。默认情况下，报告涵盖上星期天到今天。
4. 单击**运行报告**。

结果按会话日期分组，然后按服务时间和小组分组，每个小组下列出参加的人。服务时间、小组和名称按字母顺序排序，因此每个标题只显示一次。每个人的行还显示一个**签到**列，其中包含其出勤记录的时间（在文件中没有时间时为空白）和**成员身份状态**列（例如成员或访客），因此您可以一目了然地发现客人。

要下载数据，请单击**下载选项**并选择**摘要**。CSV 每个小组成员一行，按小组然后名称排序，以及范围内每个已约定会话的列（例如，"星期天 - 上午 9:00 (2026-09-27)"）标记为**出席**或**缺席**。

:::tip
小组出勤对于想跟踪其小组内随时间参与度的[小小组](../groups/creating-groups.md)领导者特别有价值。
:::

## 使用出勤数据的提示

- 每月查看趋势，以早期发现季节性模式。
- 比较校园级别的数据以了解哪些位置增长中。
- 使用小组级别的报告跟进显示出勤率下降的[小组](../groups/group-members.md)。
- 将出勤见解与[AI 搜索](../people/ai-search.md)工具结合，以找到最近没有参加的人。
