# 跟踪出席情况

<div class="article-intro">

配置校区、服务时间和小组后，B1Admin 可以轻松查看出席数据和发现趋势。出席页面提供两个报告视图 — **出席**标签用于教会范围内的趋势，**小组**标签用于小组级详情。使用这些工具来理解增长模式、识别参与度下降，并为您的教会做出数据驱动的决策。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您的出席结构必须设置至少一个校区和服务时间。如果您还没有做过，请参见[出席设置](setup.md)。
- 在报告显示结果之前，需要记录出席数据。数据可以来自[手动输入](recording-attendance.md)或[自助签到](check-in.md)。

</div>

## 查看出席趋势

1. 打开 **B1Admin**，然后打开左上角的**部分菜单**并选择**人员**。
2. 单击**出席**标签。
3. 打开标签时报告会自动运行，显示默认日期范围内的出席情况。

## 筛选您的数据

使用页面顶部的筛选器来缩小结果：

- **日期范围** — 选择开始和结束日期以专注于特定时期。
- **校区** — 选择校区以仅查看该位置的出席情况。
- **服务时间** — 选择服务时间以深入了解特定聚集。

当您更改筛选器时，图表和数据会立即更新，因此您可以快速比较不同的时间段或位置。

:::info
每次打开出席标签时报告会自动运行，因此您将始终看到最新的数字，无需点击刷新按钮。
:::

## 小组出席

**小组**标签按各个小组显示出席情况。当您想要监控特定班级、事工团队或小组而不是查看总体服务数字时，这非常有用。

1. 选择**小组**标签。
2. 从列表中选择小组以查看其出席历史。
3. 使用日期范围筛选器调整报告时间窗口。

:::tip
小组出席对于想要跟踪其小组随时间推移参与度的[小组](../groups/creating-groups.md)领导者特别有价值。
:::

## 使用出席数据的提示

- 每月审查趋势以早期发现季节性模式。
- 比较校区级数据以了解哪些位置在增长。
- 使用小组级报告跟进显示出席率下降的[小组](../groups/group-members.md)。
- 将出席见解与[AI 搜索](../people/ai-search.md)工具结合使用，以查找最近没有参加的人。
