# 签到标签设计器

<div class="article-intro">

标签设计器让你创建和自定义家庭在为其儿童签到时打印的名卡和接送单据模板。你可以确切地控制每个标签上显示的信息、其位置以及外观。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 设置[出席](setup)并配置至少一个启用签到的服侍时间
- 设置[签到](check-in)以便标签打印
- 你需要对出席部分的管理员访问权限

</div>

## 打开标签设计器

在 B1 Admin 中，点击左上角的**部分菜单**（当前部分名称和其旁边的小箭头），选择**移动**。在导航栏中，选择 **B1 CheckIn**，然后点击签到标签卡上的**设计标签**按钮。你会看到保存的标签模板的列表，按类型分离：**名卡**和**接送单据**。

## 标签类型

- **名卡** — 打印并附加到儿童身上。通常包括儿童的名字、他们的教室/课程和安全代码。
- **接送单据** — 给父母或监护人。通常包括安全代码和他们签到的儿童的列表。

B1 为你提供了一个默认名卡和一个默认接送单据模板，尺寸为标准 3.5 × 1.1 英寸热敏标签。

## 创建标签模板

1. 点击**添加名卡**或**添加接送单据**（或使用下拉菜单选择）。
2. 新模板在标签编辑器中打开。

### 标签编辑器

编辑器显示配置尺寸的标签的缩放预览。沿着左面板，你可以配置：

- **名字** — 模板名字（仅供你参考）
- **标签类型** — 名卡或接送单据
- **宽度 / 高度** — 标签尺寸（英寸）

### 添加块

标签是由块构建的 — 定位在标签画布上的单个内容片段。点击**添加块**插入新块并选择其类型：

- **字段** — 在打印时提取数据值：
  - `person.displayName` — 此人的全名
  - `sessions` — 他们签到的服侍/教室
  - `securityCode` — 随机生成的接送安全代码
  - `children` — 儿童列表（用于接送单据）
  - `person.nametagNotes` — 此人记录上的任何特殊注释
  - `campus` — 校园名称
- **文本** — 你输入的静态文本（用于标题、标签或说明）
- **条形码** — 编码安全代码的条形码

### 定位块

每个块有 **X**、**Y**、**宽度** 和 **高度** 字段，以标签画布的百分比表示（0–100）。调整这些以精确定位内容。你也可以设置：

- **字体大小** — 文本大小（点数）
- **粗体** — 切换粗体文本
- **对齐** — 左对齐、居中或右对齐文本
- **条件** — 可选地如果字段为空则隐藏块（例如，仅在 nametagNotes 有值时显示）

### 保存

点击**保存**保存模板。更新的模板将在 B1 Checkin 中下次打印标签时使用。

## 重新排序模板

如果你有多个名卡或接送单据模板，B1 Checkin 默认将使用列表中的第一个模板。拖动模板以重新排序。

## 删除模板

点击任何模板行上的删除图标并确认。删除一种类型的最后一个模板会恢复默认的内置模板。

:::tip
编辑模板后进行测试打印，以确保布局在下次服侍前看起来正确。
:::
