# 签到标签设计器

<div class="article-intro">

标签设计器让您创建和自定义当家庭为其儿童签到时打印的名称标签和接送单据模板。您可以精确控制每个标签上显示的信息、其位置和显示方式。

</div>

<div class="prereqs">
<h4>在开始之前</h4>

- 设置[出勤](setup)并配置至少一个启用了签到的服务时间
- 设置[签到](check-in)以便标签打印
- 您需要有出勤部分的管理员权限

</div>

## 打开标签设计器

在 B1 Admin 中，打开[Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**移动**，然后单击**B1 CheckIn**。然后单击签到标签卡上的**设计标签**按钮。您将看到保存的标签模板列表，按类型分开：**名称标签**和**接送单据**。

## 标签类型

- **名称标签** — 打印并贴在儿童身上。通常包括儿童的名称、其教室/会话和安全代码。
- **接送单据** — 给父母或监护人。通常包括安全代码和他们签到的儿童列表。

B1 为您提供了一个默认名称标签和一个默认接送单据模板，大小适用于标准 3.5 x 1.1 英寸热敏标签。

## 创建标签模板

1. 单击**添加**并从菜单中选择起点：**名称标签 3.5" x 1.1"**、**接送单据 3.5" x 1.1"**或**空白**。
2. 新模板在标签编辑器中打开。

### 标签编辑器

编辑器显示配置大小的标签的缩放预览。沿左面板，您可以配置：

- **名称** — 模板名称（仅供您参考）
- **标签类型** — 名称标签或接送单据
- **宽度 / 高度** — 标签大小（英寸）

### 添加块

标签由块构建 — 位于标签画布上的单个内容片段。单击**添加块**插入新块并选择其类型：

- **字段** — 在打印时提取数据值：
  - `person.displayName` — 人物的全名
  - `sessions` — 他们签到的服务/教室
  - `securityCode` — 随机生成的接送安全代码
  - `children` — 儿童列表（用于接送单据）
  - `person.nametagNotes` — 人物记录上的任何特殊说明
  - `person.isBirthdayWeek` — 如果该人的生日（月和日）在签到日期前后 3 天内，则为真
  - `campus` — 校园名称
- **文本** — 您输入的静态文本（用于标题、标签或说明）
- **条形码** — 编码安全代码的条形码

### 定位块

每个块都有以标签画布百分比（0-100）表示的**X**、**Y**、**宽度**和**高度**字段。调整这些字段以精确定位内容。您还可以设置：

- **字体大小** — 文本大小（以点为单位）
- **粗体** — 切换粗体文本
- **对齐** — 左对齐、居中或右对齐文本对齐
- **条件** — 如果字段为空，可选地隐藏块（例如，仅在有值时显示 nametagNotes）。这也适用于 `person.isBirthdayWeek`，以仅在生日在签到前后几天内的儿童的名称标签上显示生日图形或文本。

### 保存

单击**保存**以保存模板。更新的模板将在下次在 B1 Checkin 中打印标签时使用。

## 重新排序模板

如果您有多个名称标签或接送单据模板，B1 Checkin 默认将使用列表中的第一个模板。拖动模板以重新排序它们。

## 删除模板

单击任何模板行上的删除图标并确认。删除某个类型的最后一个模板将恢复默认的内置模板。

:::tip
编辑模板后进行测试打印以确认布局在下一个服务之前看起来正确。
:::
