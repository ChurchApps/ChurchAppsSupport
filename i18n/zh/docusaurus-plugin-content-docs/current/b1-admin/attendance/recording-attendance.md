# 记录出勤

<div class="article-intro">

设置校园、服务时间和小组后，您可以在每次集会后手动记录出勤。B1 Admin 围绕**会话**组织出勤 -- 每个小组每个会议日期一个会话。您创建会话、标记谁出席，数据直接进入您的出勤报告。

</div>

<div class="prereqs">
<h4>在开始之前</h4>

- 您的校园、服务时间和小组必须被配置。如果您还没有这样做，请参阅[出勤设置](setup.md)。
- 您想要跟踪的小组必须启用**跟踪出勤**。有关详细信息，请参阅[出勤设置](setup.md)。

</div>

## 创建会话

会话代表小组会议的一次发生 — 例如，您的 K-3 年级班级在特定的星期天。

1. 打开**B1 Admin**，打开[Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**人员**，然后单击**小组**。
2. 选择您想要记录出勤的小组。
3. 单击**会话**选项卡。
4. 单击**新建**以创建新会话。
5. 如果小组被分配给服务时间，选择**服务时间**。如果它是未安排的小组，此字段将不会出现。
6. 选择**会话日期** — 这可以是今天、过去的日期或未来的日期。
7. 单击**保存**。

### 为服务时间中的每个班级添加会话

如果其他小组在同一服务时间会面（例如，您的所有儿童班级在星期天上午 9:00），您可以一步创建他们的会话，而不是访问每个小组。

1. 按照上述步骤操作，选择**服务时间**。
2. 选中**也为_service time_中的其他_N_个小组添加**。该复选框显示有多少其他小组被分配到该服务时间。它仅在添加新会话且至少一个其他小组在该时间会面时出现。
3. 单击**保存**。

为当前小组和在同一日期和服务时间会面的每个其他小组创建一个会话。已经为该日期和服务时间有会话的小组被跳过，所以您不会得到重复。

:::tip
您可以为过去的日期创建会话以赶上您尚未记录的出勤，或提前创建它们以便在小组会面时准备就绪。
:::

## 标记出勤

选择一个会话以查看其出勤列表。每个小组成员都被列出，带有复选框，按姓氏排序，任何已记录为出席的人都被选中。

1. 选中每个出席的人旁边的框。使用**全选**或**取消选择全部**一次更改每个人。
2. 列表上方的计数（例如，"15 个中的 12 个出席"）随着您选中框而更新。
3. 单击**保存出勤**。在您保存之前，没有任何内容被记录，并且消息在保存完成时确认。

取消选中已记录为出席的人，然后保存会将他们从会话中删除。

### 添加访客

要记录不是小组成员的人，请在出勤列表旁边的人员搜索中搜索他们。如果他们还不在您的数据库中，您可以从搜索创建他们。他们被添加到列表中已选中。单击**保存出勤**以记录他们。

在自助服务终端签到的人显示**志愿者**或**访客**芯片。不是小组成员的人显示**访客**芯片。

## 检查哪些小组仍需要出勤

当几个班级在同一服务时间会面时，您可以一目了然地看到哪些仍需要为该日期输入其出勤。

1. 打开具有服务时间的会话。
2. 单击出勤列表顶部的**谁仍然需要出勤**。
3. 对话框列出分配给该服务时间的每个小组，顶部带有摘要，如"已输入 5 个小组中的 8 个"。

对于该日期没有人标记为出席的小组显示**未输入**芯片，并首先列出。具有出勤的小组显示**已输入**和标记出席的人数（例如，"已输入（12）"）。单击小组名称以跳转到该小组并记录其出勤。

:::tip
将其与**打印所有班级**和[为服务时间中的每个班级添加会话](#adding-sessions-for-every-class-in-a-service-time)配对：创建会话，分发点名表，然后使用**谁仍然需要出勤**查看尚未输入哪些表。
:::

## 打印点名表

点名表是一份可打印的班级名单，教师可以手工标记并交回给您以供稍后输入。每张表显示教会名称、班级、班级名称下的大**日期**行和服务时间。成员列在两列中（向下阅读左列，然后是右列），以便更多名称适应一页，每个成员都有**出席**和**缺席**框。有访客的空白行和**教师 / 说明**区域。

- **从会话** -- 单击会话出勤列表顶部的**打印点名表**（打印机）图标。表的日期为会话的日期。
- **服务的所有班级** -- 如果会话具有服务时间，单击**打印所有班级**以为分配给该服务时间的每个班级打印一张表。每个班级在其自己的页面上打印。
- **从成员选项卡** -- 单击小组的成员列表上方的**打印点名表**图标并选择**出勤表**以打印未标记日期的表。同一菜单中还有**联系人名册**布局，包含每位成员的电话、电子邮件和地址 -- 请参阅[打印成员列表](../groups/group-members.md#printing-the-member-list)。

表在新选项卡中打开，您的浏览器的打印对话框自动出现。

## 将出勤导出到电子表格

您可以下载会话的记录作为 CSV 文件，以在 Excel、Numbers 或 Google Sheets 中使用。

1. 打开您想要导出的会话。
2. 单击出勤列表顶部的**导出**按钮。
3. 在您的电子表格应用程序中打开下载的文件。

## 查看已记录的出勤

记录会话后，数据显示在您的出勤报告中。

- **出勤趋势选项卡** -- 显示整个教会随时间的趋势。请参阅[跟踪出勤](tracking-attendance.md)。
- **小组出勤选项卡** -- 显示按个别小组分解的出勤。请参阅[出勤报告](../reports/attendance-reports.md#group-attendance)。

:::tip
如果您刚刚创建的会话没有立即出现在报告中，请确保会话日期落在报告过滤器中选择的日期范围内。
:::
