# 记录出席情况

<div class="article-intro">

设置校区、服务时间和小组后，您可以在每次聚集后手动记录出席情况。B1Admin 围绕**会议**组织出席情况 — 每个小组每个会议日期一个会议。您创建会议，标记谁出席了，数据直接进入您的出席报告。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您的校区、服务时间和小组必须配置。如果您还没有做过，请参见[出席设置](setup.md)。
- 您要跟踪的小组必须启用**跟踪出席**。详情请参见[出席设置](setup.md)。

</div>

## 创建会议

一个会议代表一个小组会议的一次发生 — 例如，您的 K-3 年级班级在特定星期日。

1. 打开 **B1Admin**，打开左上角的**部分菜单**并选择**人员**，然后点击**小组**标签。
2. 选择要记录出席情况的小组。
3. 单击**会议**标签。
4. 点击**新建**创建新会议。
5. 如果小组被分配到服务时间，选择**服务时间**。如果它是一个未安排的小组，此字段将不出现。
6. 选择**会议日期** — 这可以是今天、过去日期或未来日期。
7. 点击**保存**。

:::tip
您可以为过去的日期创建会议以赶上您还没有记录的出席情况，或提前创建会议以便在您的小组聚集时准备好。
:::

## 标记出席

保存会议后，小组的成员出现在页面的右侧。

1. 检查每个出席的人旁边的复选框。
2. 更改会自动保存 — 出席标记没有额外的"保存"按钮。

:::info
只有当前小组成员显示在会议列表中。如果有人出席但还不在小组中，[首先将他们添加到小组](../groups/group-members.md)，然后记录他们的出席情况。
:::

## 将出席情况导出到电子表格

您可以将会议记录下载为 CSV 文件，以在 Excel、Numbers 或 Google Sheets 中使用。

1. 打开要导出的会议。
2. 点击**下载 CSV** 按钮。
3. 在您的电子表格应用程序中打开下载的文件。

## 查看记录的出席情况

记录会议后，数据会出现在您的出席报告中。

- **出席标签** — 显示教会范围内的随时间推移的趋势。参见[跟踪出席情况](tracking-attendance.md)。
- **小组标签** — 按各个小组显示出席情况。

:::tip
如果您刚创建的会议没有立即出现在报告中，请确保会议日期在报告过滤器中选择的日期范围内。
:::
