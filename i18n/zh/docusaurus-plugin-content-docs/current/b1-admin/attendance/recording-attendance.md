# 记录出勤

<div class="article-intro">

一旦设置好校区、礼拜时间和小组，你就可以在每次聚会后手动记录出勤。B1 Admin 以**场次（session）**来组织出勤——每个小组每个聚会日期对应一个场次。你创建场次、标记谁出席，数据会直接汇入你的出勤报告。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你的校区、礼拜时间和小组必须已配置完成。如果你还没有完成此项，请参见[考勤设置](setup.md)。
- 你要跟踪的小组必须已启用 **Track Attendance**。详见[考勤设置](setup.md)。
- 你需要具备 **Edit Attendance** 权限才能保存出勤。仅拥有人员 **View People Names Only** 权限的志愿者仍可以这种方式记录出勤——他们从**小组**中打开班级，只能按姓名查看成员。参见[仅显示姓名的人员权限](../settings/roles-permissions.md#people-names-only)。

</div>

## 创建场次

一个场次代表一次小组聚会——例如，某个周日的小学 K 至三年级班级。

1. 打开 **B1 Admin**，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **People**，然后点击 **Groups**。
2. 选择你要记录出勤的小组。
3. 在小组页面的 **Sessions** 部分，点击 **All sessions**。
4. 点击 **New** 创建新场次。
5. 如果该小组已分配礼拜时间，请选择 **Service Time**。如果是未排定的小组，则不会出现此字段。
6. 选择 **Session Date**——可以是今天、过去的日期或未来的日期。
7. 点击 **Save**。

### 为礼拜时间内的每个班级添加场次 {#adding-sessions-for-every-class-in-a-service-time}

如果其他小组也在同一礼拜时间聚会（例如，周日上午 9:00 的所有儿童班级），你可以一次性为他们创建场次，无需逐个进入每个小组。

1. 按上述步骤操作，并选择一个 **Service Time**。
2. 勾选 **Also add for the other _N_ groups in _service time_**。复选框会显示分配到该礼拜时间的其他小组数量。只有在添加新场次且至少还有一个其他小组在该时间聚会时，此选项才会出现。
3. 点击 **Save**。

系统会为当前小组以及同一日期和礼拜时间的其他每个小组创建场次。已在该日期和礼拜时间拥有场次的小组会被跳过，因此不会出现重复。

:::tip
你可以为过去的日期创建场次，以补记尚未录入的出勤；也可以提前创建场次，使其在小组聚会时已经准备就绪。
:::

## 场次备注 {#session-notes}

每个场次都可以添加备注——例如本次讲授内容的回顾、公告或代祷事项。

1. 添加场次时，或点击列表中某个场次旁的**编辑**（铅笔）图标后，在日期下方的 **Notes (what was covered, announcements, prayer requests)** 文本框中输入内容。工具栏支持加粗文字、列表和链接。
2. 点击 **Save**。

备注会显示在场次出勤列表的顶部。它们同时也是 B1.church 上小组页面**聚会**部分中，小组成员阅读的聚会备注，小组负责人也可以在那里撰写和编辑。参见[小组详情](../../b1-church/groups/group-details.md#meeting-notes-and-attendance)。

## 标记出勤

选择一个场次即可查看其出勤列表。每位小组成员都会显示一个复选框，按姓氏排序，已记录为出席的人员会被勾选。

1. 勾选每位出席者旁边的复选框。使用 **Select All** 或 **Select None** 可一次性更改所有人。
2. 列表上方的计数（例如“15 人中 12 人出席”）会随着你勾选复选框而更新。
3. 点击 **Save Attendance**。在保存之前不会记录任何内容，保存完成后会显示确认消息。如果你在保存仍在进行时尝试关闭或刷新浏览器标签页，浏览器会先发出警告，以防更改丢失。

如果你取消勾选一位已记录为出席的人员并保存，该人员将从场次中移除。

### 添加访客

要记录不属于该小组成员的人员，请使用出勤列表旁的人员搜索进行查找。如果其尚未在你的数据库中，你可以在搜索时直接创建。无论哪种方式，他们都会以已勾选的状态添加到列表中。点击 **Save Attendance** 即可记录。

在小组中通过自助机签到的人员会显示 **Volunteer** 或 **Guest** 标签。不属于该小组成员的人员会显示 **Guest** 标签。

## 查看尚未录入出勤的小组

当多个班级在同一礼拜时间聚会时，你可以一目了然地看出哪些班级仍需录入该日期的出勤。

1. 打开一个设有礼拜时间的场次。
2. 点击出勤列表顶部的 **Who Still Needs Attendance**。
3. 对话框会列出分配到该礼拜时间的每个小组，并在顶部显示摘要，例如“8 个小组中已录入 5 个”。

该日期没有人被标记为出席的小组会显示 **Not entered** 标签，并排在最前面。已有出勤的小组会显示 **Entered** 以及出席人数（例如“Entered (12)”）。点击小组名称即可打开该小组的场次列表，并自动选中相同日期的场次，方便你立即录入其出勤。如果该小组在该日期还没有场次，则会打开其场次列表，供你添加。

:::tip
可将此功能与**打印所有班级**以及[为礼拜时间内的每个班级添加场次](#adding-sessions-for-every-class-in-a-service-time)结合使用：先创建场次，分发点名表，然后使用**Who Still Needs Attendance**查看哪些点名表尚未录入。
:::

## 打印点名表

点名表是一份可打印的班级名单，老师可以手动标记，之后交回给你录入。每张点名表都会显示教会的标志（如果你已上传过，则为 [Website > Appearance](../website/appearance.md) 中的**浅色背景标志**），标志下方是教会名称，然后是班级名称、班级名称下方一条较大的**日期**栏，以及礼拜时间。成员分为两列排列（先读左列，再读右列），以便每页容纳更多姓名，每位成员都有**Present**和**Absent**复选框。另有空白行供访客填写，以及一个**Teacher / Notes**区域。

- **从场次打印** —— 点击场次出勤列表顶部的**打印点名表**（打印机）图标。点名表会标注该场次的日期。
- **礼拜的所有班级** —— 如果场次设有礼拜时间，请点击**打印所有班级**，为分配到该礼拜时间的每个班级打印一张点名表。每个班级各占一页。
- **从成员名单打印** —— 在小组页面上，点击**所有成员**，然后点击成员列表上方的**打印点名表**图标，选择**Attendance Sheet**即可打印一张不带日期的空白表格。同一菜单中还有**Contact Roster**版式，显示每位成员的电话、电子邮件和地址——参见[打印成员名单](../groups/group-members.md#printing-the-member-list)。

点名表会在新标签页中打开，并自动弹出浏览器的打印对话框。

## 将出勤导出为电子表格

你可以将场次记录下载为 CSV 文件，以便在 Excel、Numbers 或 Google Sheets 中使用。

1. 打开要导出的场次。
2. 点击出勤列表顶部的 **Export** 按钮。
3. 在电子表格应用中打开下载的文件。

## 查看已记录的出勤

记录场次后，数据会显示在你的出勤报告中。

- **Attendance Trend 标签页**（位于出勤页面的 **All years** 下）—— 显示教会整体随时间的趋势。参见[跟踪出勤](tracking-attendance.md)。
- **Group Attendance 标签页** —— 显示按各个小组细分的出勤情况。参见[出勤报告](../reports/attendance-reports.md#group-attendance)。

:::tip
如果你刚创建的场次没有立即出现在报告中，请确认该场次日期在报告筛选条件所选的日期范围之内。
:::
