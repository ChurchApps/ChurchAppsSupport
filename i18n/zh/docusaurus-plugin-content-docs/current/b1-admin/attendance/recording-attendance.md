# 记录考勤

<div class="article-intro">

在校区、礼拜时间和小组设置完成后，您可以在每次聚会结束后手动记录考勤。B1 Admin 以**课次**为单位组织考勤，即每个小组在每个聚会日期对应一次课次。您创建课次并标记出席人员，数据会直接进入您的考勤报告。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 必须先配置好您的校区、礼拜时间和小组。如果您还没有完成这些设置，请参阅[考勤设置](setup.md)。
- 需要记录考勤的小组必须启用**记录考勤**功能。详情请参阅[考勤设置](setup.md)。

</div>

## 创建课次

课次指小组的一次聚会，例如某个周日幼儿园至三年级班级的那一次课。

1. 打开 **B1 Admin**，打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（位于左上角的搜索栏），展开 **People**，然后点击 **Groups**。
2. 选择您要记录考勤的小组。
3. 在小组页面的 **Sessions** 部分，点击 **All sessions**。
4. 点击 **New** 创建新课次。
5. 如果该小组已安排礼拜时间，请选择 **Service Time**。如果是未安排时间的小组，则不会显示此字段。
6. 选择 **Session Date**——可以是今天、过去的日期或未来的日期。
7. 点击 **Save**。

### 为礼拜时间内的所有班级创建课次

如果同一礼拜时间还有其他小组聚会（例如周日上午 9:00 的所有儿童班级），您可以一次性为它们创建课次，无需逐个小组操作。

1. 按照上述步骤操作，并选择一个 **Service Time**。
2. 勾选 **Also add for the other _N_ groups in _service time_**。复选框会显示同一礼拜时间下还有多少个其他小组。只有在新增课次且该时间还有其他小组聚会时，此选项才会出现。
3. 点击 **Save**。

系统会为当前小组以及同一日期和礼拜时间的其他小组分别创建课次。已经在该日期和礼拜时间存在课次的小组会被跳过，因此不会产生重复记录。

:::tip
您可以为过去的日期创建课次，以补录尚未记录的考勤；也可以提前创建课次，以便小组聚会时直接使用。
:::

## 标记考勤

选择一个课次即可查看其考勤名单。所有小组成员都会以复选框的形式列出，按姓氏排序，已记录为出席的人员会自动勾选。

1. 勾选每位出席者旁边的复选框。您可以使用 **Select All** 或 **Select None** 一次性全选或全不选。
2. 名单上方的人数统计（例如“12 of 15 present”）会随着您勾选而更新。
3. 点击 **Save Attendance**。只有保存后才会真正记录，保存完成后会显示提示信息。

如果您取消勾选一位已记录为出席的人员并保存，该人员将从课次中移除。

### 添加访客

如需记录不属于该小组的人员，可在考勤名单旁边的人员搜索框中搜索。如果该人员尚未存在于您的数据库中，您可以直接在搜索中新建。无论哪种方式，他们都会以已勾选的状态添加到名单中。点击 **Save Attendance** 即可记录。

在服务台通过自助签到机签到的人员会显示 **Volunteer** 或 **Guest** 标签。不属于该小组成员的人员会显示 **Guest** 标签。

## 查看哪些小组仍需记录考勤

当多个班级在同一礼拜时间聚会时，您可以一目了然地看到哪些班级尚未录入该日期的考勤。

1. 打开一个已设置礼拜时间的课次。
2. 点击考勤名单顶部的 **Who Still Needs Attendance**。
3. 弹出的对话框会列出该礼拜时间下的所有小组，顶部会显示类似“5 of 8 groups entered”的摘要。

该日期没有任何出席人员的小组会显示 **Not entered** 标签，并排在最前面。已有考勤的小组会显示 **Entered**，并附上出席人数（例如“Entered (12)”）。点击小组名称即可打开该小组的课次列表，并自动选中同一日期的课次，方便您立即录入考勤。如果该小组在该日期还没有课次，则会打开其课次列表，方便您添加。

:::tip
可以将此功能与 **Print All Classes** 以及[为礼拜时间内的所有班级创建课次](#adding-sessions-for-every-class-in-a-service-time)结合使用：先创建课次，分发点名表，然后使用 **Who Still Needs Attendance** 查看哪些点名表尚未录入。
:::

## 打印点名表

点名表是一份可打印的班级名单，老师可以手写点名，然后交还给您以便之后录入。每张点名表都会在顶部显示您的教会标志（如果您已上传，则使用 [Website > Appearance](../website/appearance.md) 中的 **Light Background Logo**），下方是教会名称，接着是班级名称，班级名称下方有一个较大的 **Date** 栏，以及礼拜时间。成员名单分为两列排列（先读左列，再读右列），以便在一页中容纳更多姓名，每位成员旁边都有 **Present** 和 **Absent** 复选框。页面底部还有供访客填写的空白行以及 **Teacher / Notes** 区域。

- **从课次打印** -- 点击课次考勤名单顶部的 **Print Roll Sheet**（打印机）图标。点名表会标注该课次的日期。
- **打印某个礼拜时间的所有班级** -- 如果课次已设置礼拜时间，请点击 **Print All Classes**，即可为该礼拜时间下的每个班级分别打印一张点名表。每个班级各占一页。
- **从成员名单打印** -- 在小组页面点击 **All members**，然后点击成员名单上方的 **Print Roll Sheet** 图标，选择 **Attendance Sheet** 即可打印一份不带日期的空白点名表。同一菜单中还有 **Contact Roster** 版式，会列出每位成员的电话、电子邮件和地址——请参阅[打印成员名单](../groups/group-members.md#printing-the-member-list)。

点名表会在新标签页中打开，并自动弹出浏览器的打印对话框。

## 将考勤导出为电子表格

您可以将课次记录下载为 CSV 文件，以便在 Excel、Numbers 或 Google Sheets 中使用。

1. 打开您要导出的课次。
2. 点击考勤名单顶部的 **Export** 按钮。
3. 在电子表格应用中打开下载的文件。

## 查看已记录的考勤

记录课次后，数据会显示在您的考勤报告中。

- **Attendance Trend 标签页**（位于考勤页面的 **All years** 下）-- 显示全教会随时间变化的趋势。请参阅[考勤追踪](tracking-attendance.md)。
- **Group Attendance 标签页** -- 按各个小组分别显示考勤情况。请参阅[考勤报告](../reports/attendance-reports.md#group-attendance)。

:::tip
如果您刚创建的课次没有立即出现在报告中，请确认该课次的日期在报告筛选条件所选的日期范围之内。
:::
