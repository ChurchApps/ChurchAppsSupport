# 记录出勤

<div class="article-intro">

设置好校区、礼拜时间和小组之后，你可以在每次聚会后手动记录出勤。B1 Admin 以**课次**组织出勤数据——每个小组每个聚会日期对应一个课次。你创建课次、标记出席人员，数据会直接用于出勤报表。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你的校区、礼拜时间和小组必须已经配置好。如果你还没有完成这些设置，请参阅[出勤设置](setup.md)。
- 你要跟踪的小组必须启用了 **Track Attendance**。详情请参阅[出勤设置](setup.md)。

</div>

## 创建课次

课次代表一次小组聚会——例如某个星期日的 K–3 年级班。

1. 打开 **B1 Admin**，打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **People**，然后点击 **Groups**。
2. 选择你要记录出勤的小组。
3. 在小组页面的 **Sessions** 部分，点击 **All sessions**。
4. 点击 **New** 创建新课次。
5. 如果该小组已分配到某个礼拜时间，请选择 **Service Time**。如果是非固定时间的小组，则不会显示此字段。
6. 选择 **Session Date**——可以是今天、过去的日期或未来的日期。
7. 点击 **Save**。

### 为礼拜时间内的每个班级添加课次 {#adding-sessions-for-every-class-in-a-service-time}

如果同一礼拜时间还有其他小组聚会（例如周日上午 9:00 的所有儿童班），你可以一步创建所有班级的课次，而无需逐个访问每个小组。

1. 按照上述步骤操作，并选择一个 **Service Time**。
2. 勾选 **Also add for the other _N_ groups in _service time_**。复选框会显示分配到该礼拜时间的其他小组数量。只有在添加新课次且至少有一个其他小组在该时间聚会时，才会显示此选项。
3. 点击 **Save**。

系统会为当前小组以及同一日期和礼拜时间的其他每个小组创建课次。已经在该日期和礼拜时间拥有课次的小组会被跳过，因此不会产生重复记录。

:::tip
你可以为过去的日期创建课次，以补录尚未记录的出勤；也可以提前创建课次，使其在小组聚会时已经准备就绪。
:::

## 课次备注 {#session-notes}

每个课次都可以添加备注——内容可以是授课回顾、通知或代祷事项。

1. 添加课次时，或在列表中点击课次旁边的 **Edit**（铅笔）图标后，在日期下方的 **Notes (what was covered, announcements, prayer requests)** 框中输入内容。工具栏支持加粗文字、列表和链接。
2. 点击 **Save**。

备注会显示在课次出勤列表的顶部。它们同时也是小组成员在 B1.church 上小组页面的 **Meetings** 部分中阅读的聚会备注，小组负责人也可以在那里撰写和编辑。请参阅[小组详情](../../b1-church/groups/group-details.md#meeting-notes-and-attendance)。

## 标记出勤

选择一个课次即可查看其出勤列表。每位小组成员都会列出并带有复选框，按姓氏排序；已记录为出席的人员会被勾选。

1. 勾选每位出席者旁边的复选框。使用 **Select All** 或 **Select None** 可一次性更改所有人员。
2. 列表上方的计数（例如 "12 of 15 present"）会随着你勾选复选框而更新。
3. 点击 **Save Attendance**。在保存之前不会记录任何内容，保存完成后会显示确认消息。

取消勾选已记录为出席的人员并保存后，该人员将从课次中移除。

### 添加访客

要记录不属于该小组的人员，请在出勤列表旁边的人员搜索框中搜索他们。如果他们尚未存在于你的数据库中，你可以直接从搜索框中创建他们。无论哪种方式，他们都会被添加到列表中并已勾选。点击 **Save Attendance** 即可记录。

在自助签到机上签到的人员会显示 **Volunteer** 或 **Guest** 标签。不属于该小组成员的人员会显示 **Guest** 标签。

## 查看哪些小组仍需录入出勤

当多个班级在同一礼拜时间聚会时，你可以一目了然地看到哪些班级仍需录入该日期的出勤。

1. 打开一个设有礼拜时间的课次。
2. 点击出勤列表顶部的 **Who Still Needs Attendance**。
3. 对话框会列出分配到该礼拜时间的每个小组，顶部显示摘要，例如 "5 of 8 groups entered"。

该日期没有标记任何出席人员的小组会显示 **Not entered** 标签，并排在最前面。已有出勤记录的小组会显示 **Entered** 以及出席人数（例如 "Entered (12)"）。点击小组名称即可打开该小组的课次列表，并自动选中相同日期的课次，以便你立即录入其出勤。如果该小组在该日期还没有课次，则会打开其课次列表，方便你添加。

:::tip
可将此功能与 **Print All Classes** 以及[为礼拜时间内的每个班级添加课次](#adding-sessions-for-every-class-in-a-service-time)结合使用：先创建课次，分发点名表，然后使用 **Who Still Needs Attendance** 查看哪些点名表尚未录入。
:::

## 打印点名表 {#printing-a-roll-sheet}

点名表是可打印的班级名单，教师可以手动标记后交还给你以便稍后录入。每张表单上都会显示你的教会标志（如果你上传过 [Website > Appearance](../website/appearance.md) 中的 **Light Background Logo**），标志下方是教会名称，然后是班级名称、班级名称下方的大号 **Date** 行以及礼拜时间。成员分为两列排列（先读左列，再读右列），以便页面容纳更多姓名；每位成员都有 **Present** 和 **Absent** 复选框。还设有空白行供记录访客，以及 **Teacher / Notes** 区域。

- **从课次打印** —— 点击课次出勤列表顶部的 **Print Roll Sheet**（打印机）图标。表单上的日期即为该课次的日期。
- **某礼拜时间的所有班级** —— 如果课次设有礼拜时间，点击 **Print All Classes**，即可为分配到该礼拜时间的每个班级打印一张表单。每个班级各占一页。
- **从成员列表打印** —— 在小组页面点击 **All members**，然后点击成员列表上方的 **Print Roll Sheet** 图标，选择 **Attendance Sheet** 即可打印一张不带日期的表单。同一菜单中还有 **Contact Roster** 布局，其中包含每位成员的电话、电子邮件和地址——请参阅[打印成员列表](../groups/group-members.md#printing-the-member-list)。

表单会在新标签页中打开，并自动弹出浏览器的打印对话框。

## 将出勤导出为电子表格

你可以将课次记录下载为 CSV 文件，以便在 Excel、Numbers 或 Google Sheets 中使用。

1. 打开要导出的课次。
2. 点击出勤列表顶部的 **Export** 按钮。
3. 在电子表格应用程序中打开下载的文件。

## 查看已记录的出勤

记录课次后，数据会显示在出勤报表中。

- **Attendance Trend 标签页**（位于出勤页面的 **All years** 下）—— 显示全教会随时间变化的趋势。请参阅[跟踪出勤](tracking-attendance.md)。
- **Group Attendance 标签页** —— 按单个小组细分显示出勤。请参阅[出勤报表](../reports/attendance-reports.md#group-attendance)。

:::tip
如果你刚创建的课次没有立即出现在报表中，请确保课次日期落在报表筛选器所选的日期范围内。
:::
