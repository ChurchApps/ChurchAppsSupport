# 记录考勤

<div class="article-intro">

设置校园、服务时间和团队后,您可以在每次聚集后手动记录考勤。B1 Admin围绕**会话**组织考勤 - 每个团队每次会议日期一个会话。您创建会话,标记出席的人,数据直接进入考勤报告。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 必须配置校园、服务时间和团队。如果您还未完成此操作,请参阅[考勤设置](setup.md)。
- 您要跟踪的团队必须启用**跟踪考勤**。有关详细信息,请参阅[考勤设置](setup.md)。

</div>

## 创建会话

会话代表一个团队会议的出现 - 例如,您的K-3年级班在特定周日。

1. 打开**B1 Admin**,在左上角打开**部分菜单**,选择**人员**,然后单击**团队**选项卡。
2. 选择要记录考勤的团队。
3. 单击**会话**选项卡。
4. 单击**新建**创建新会话。
5. 如果团队被分配给服务时间,选择**服务时间**。如果这是一个未计划的团队,此字段将不会出现。
6. 选择**会话日期** - 这可以是今天、过去日期或未来日期。
7. 单击**保存**。

:::tip
您可以为过去的日期创建会话来补补您还未记录的考勤,或提前创建会话,以便在您的团队聚集时准备好。
:::

## 标记考勤

选择会话查看其考勤列表。每个团队成员都列有复选框,按姓氏排序,任何已记录为出席的人都已被勾选。

1. 检查出席的每个人旁边的框。使用**全选**或**取消全选**一次更改所有人。
2. 列表上方的计数(例如,"15人中有12人在场")在您检查框时更新。
3. 单击**保存考勤**。在您保存之前不会记录任何内容,并且消息会在保存完成时确认。

取消选中已记录为出席的人然后保存会将其从会话中删除。

### 添加访客

要记录不是团队成员的人,在考勤列表旁边的人员搜索中搜索他们。如果他们还不在您的数据库中,您可以从搜索中创建他们。他们被添加到已检查的列表中。单击**保存考勤**记录他们。

在自助服务亭签到的人显示**志愿者**或**来宾**芯片。不是团队成员的人显示**来宾**芯片。

## 打印花名册

花名册是教师可以手工标记并返回给您以供以后输入的可打印班级列表。每张表都显示教会名称、班级、服务时间和日期行。每个成员都有**出席**和**缺席**框,访客有空行和**教师/笔记**区域。

- **从会话** - 单击会话考勤列表顶部的**打印花名册**(打印机)图标。该表以会话的日期为准。
- **一项服务的所有班级** - 如果会话有服务时间,单击**打印所有班级**为分配给该服务时间的每个班级打印一张纸。每个班级在其自己的页面上打印。
- **从成员选项卡** - 单击团队成员列表上方的**打印花名册**图标以打印未日期的纸张。

该表在新选项卡中打开,您的浏览器的打印对话框会自动出现。

## 将考勤导出到电子表格

您可以将会话的记录下载为CSV文件,以在Excel、Numbers或Google Sheets中使用。

1. 打开要导出的会话。
2. 单击考勤列表顶部的**导出**按钮。
3. 在您的电子表格应用程序中打开下载的文件。

## 查看记录的考勤

记录会话后,数据会出现在您的考勤报告中。

- **考勤趋势选项卡** - 显示随时间推移的教会范围内的趋势。请参阅[跟踪考勤](tracking-attendance.md)。
- **团队考勤选项卡** - 显示按个别团队分解的考勤。

:::tip
如果您刚创建的会话不会立即出现在报告中,请确保会话日期在报告过滤器中选择的日期范围内。
:::
