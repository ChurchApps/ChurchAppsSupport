# 通知与消息

<div class="article-intro">

B1 Admin 会将你的通知与私人消息保存在每个页面右上角的用户菜单中。你的个人头像上的红色数字会显示有多少未读的通知与消息，并会在你工作时自动更新，无需刷新页面。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 登录 [B1 Admin](https://admin.b1.church)。每位已登录的用户都有通知与消息。
- 通知与消息是个人专属的：你只会看到发送给你的内容。

</div>

## 打开用户菜单 {#opening-the-user-menu}

点击右上角的个人头像（或其旁边的箭头）。菜单会显示你的**当前教会**以及以下项目：

- **Messages**与**Notifications**，各自带有未读数量
- **Edit Profile**——**Edit Account**会打开你的[个人资料](./profile/managing-profile.md)，**Edit Church Profile**则会打开你在教会 B1 网站上的通讯录资料
- **Theme Preferences**——**Default**、**Classic**或**Custom**颜色，以及**Light Mode**或**Dark Mode**
- **Logout**、**Switch App**（B1.Church 或 Lessons.church），以及**Switch Church**（列出你的账户所属的教会）

## 通知 {#notifications}

通知会告诉你有哪些事情需要你处理，例如：

- 有[任务](./serving/tasks.md)分派给你，或为你建立了小组入会申请的任务
- 你已被排入[计划](./serving/plans.md)中服事
- 你管理的[表单](./forms/managing-submissions.md)收到了新的提交
- 有人在你的小组中发帖，或发送了公告

阅读通知的方式：

1. 打开用户菜单，点击**Notifications**。
2. 每则通知会显示一段简短的讯息、距今多久（例如**1d**），以及尚未查看时会出现的**New**标签。打开列表即会将它们标记为已读，并清除数字。
3. 点击**View Details**（或该则通知），即可前往相关内容：
   - 任务会在 B1 Admin 中打开该任务。
   - 表单提交会在 B1 Admin 中打开该表单的提交内容。
   - 服事安排会在新的分页中打开教会 B1 网站上的计划，你可以在该处接受或婉拒。
   - 其他通知若有链接，则会在新的分页中打开该链接。
4. 点击垃圾桶图标即可删除单则通知，或点击**Clear All**（并确认）以删除全部通知。

当没有任何通知时，列表会显示**No notifications -- You're all caught up!**

:::tip
你要以何种方式接收通知（推送、电子邮件、应用程序内的铃铛或短信），以及勿扰时段，都可以在教会 B1 网站或 B1 应用程序中的[通知偏好设置](../b1-church/getting-started/notification-preferences.md)中设置。
:::

## 消息 {#messages}

**Messages**保存你与教会中其他人的一对一私人对话——也就是你在教会 B1 网站和 B1 应用程序上看到的同一批对话。

### 阅读与回复 {#reading-and-replying}

1. 打开用户菜单，点击**Messages**。每段对话会显示对方的姓名、最新的一则讯息（若由你发送，前面会加上**You:**）、发送时间，以及尚未阅读时的**New**标签。
2. 点击某段对话即可打开。在**Type a message**...中输入内容，然后点击发送箭头。表情符号按钮可加入表情符号。
3. 点击返回箭头即可回到列表。

若要删除对话，请点击其垃圾桶图标并确认。

### 开始新的消息 {#starting-a-new-message}

1. 在**Messages**中，点击圆形的**+**按钮。
2. 在**Search for a person**下输入姓名，然后点击**Search**。
3. 点击该人员，撰写讯息并发送。
