## 演练

1. 使用Google Chrome,转到[admin.b1.church](https://admin.b1.church)并用你的用户名和密码登录。
2. 这将带你到**仪表板**,即B1.church Admin主页。它显示本周的敬拜和谁在签到和服侍中,以及你的任务和小组。使用**Jump 菜单**(左上角的搜索栏,见下文)来访问人员、捐赠、网站和应用程序的其余部分。点击搜索栏旁边的小教会标志可随时返回仪表板。
3. 打开Jump 菜单并选择**设置**以设置教会的信息、管理角色和其他详细信息。
4. 点击**编辑铅笔**以设置你的教会信息。
5. 返回周日,点击右上角的**问号图标**以获取帮助和教程。
6. 点击**查看文档**以查看帮助你开始使用B1.church的教程列表。
7. 导航回仪表板并点击你的个人资料图片旁边的**箭头**并选择**切换应用**。
8. 选择**Lessons.church**以管理你的教会的在线课程和课程。
9. 通过点击你的个人资料图片旁边的箭头并再次选择**切换应用**来切换回B1.church。
10. 你现在可以通过**成员门户**或**管理员门户**进入B1.church。成员门户允许你查看B1.church如何显示给你的成员、查看你的小组并管理你的个人捐赠。

:::tip
从[设置](./settings/)页面开始以配置你的教会名称、品牌和团队权限。这确保了你设置的所有其他内容都将正确显示。
:::

## 用Jump 菜单导航

B1 Admin的所有内容都可以通过标题左上角的**Jump 菜单**访问。在小教会标志(它将你带回仪表板)旁边是一个搜索栏,显示你在哪里,例如**捐赠 › 批次**,以及一个**Ctrl K**(或**⌘ K**)的提示。

### 浏览部分和页面

1. 点击搜索栏,或按**Ctrl+K**(**Cmd+K**在Mac上),或在你不在文本字段中输入时按**/**。
2. 菜单列出你可以访问的所有部分——仪表板、人员、捐赠、服侍、讲道、网站、日历、移动和设置。你在其中的部分已经展开,你当前的页面被高亮显示。
3. 点击一个部分来展开它并查看其页面(例如,**人员**包含**人员**、**小组**、**出席**和**表单**)。一次只有一个部分展开。
4. 点击一个页面进入其中。

你也可以使用键盘:**向上**和**向下**箭头在列表中移动,**向右**展开一个部分,**向左**折叠它,**Enter**打开高亮的项目。按**Esc**关闭菜单而不进入任何地方。

在这些文档中,诸如"在Jump 菜单中,选择**人员 > 小组**"之类的步骤意味着打开Jump 菜单,展开**人员**,然后点击**小组**。

### 搜索

与其浏览,你可以在菜单打开后立即开始输入,以直接跳转到一个人、小组、计划、基金或任何管理页面:

1. 输入一个名称或你想要的页面(例如,一个人的名称、"批次"、"歌曲"或"我的工作")。
2. 结果按类型分组——人员、小组、计划、基金和要跳转的页面。使用箭头键在结果之间移动,按**Enter**选择一个,或用鼠标点击一个结果。

搜索也可以开始常见任务。输入你想做什么并选择它:

- **创建一个页面**、**创建一个小组**、**设置FreeShow**或**设置FreePlay**打开匹配的快速设置向导,就在你所在的地方,而不需要返回仪表板。
- **添加一个人**打开新人员表单。
- **开始签到**打开签到应用。

你看到的操作取决于你的权限。

### 快速操作

Jump 菜单中的最后一个组是**快速操作**——以前出现在仪表板上的设置快捷方式。展开它以找到步骤,如**添加你的教会标志**、**创建你的第一个网页**、**设置在线捐赠**、**创建你的第一个小组**和**邀请团队成员**。设置操作在第一次打开其快速设置向导;一旦你设置了该功能,它们将带你进入其页面。

:::tip
搜索通常是到达一个页面的最快方式——输入部分页面名称(如"角色"或"基金")而不是手动展开设置、服侍或捐赠。
:::
