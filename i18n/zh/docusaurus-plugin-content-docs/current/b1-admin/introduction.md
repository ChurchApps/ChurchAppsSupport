## 演练

1. 使用Google Chrome，转到[admin.b1.church](https://admin.b1.church)并使用您的用户名和密码登录。
2. 这将带您到**仪表板**，即B1.church Admin主页。它显示本周的服务和谁在签到和服务中，以及您的任务和小组。使用**命令面板**（见下文）或菜单来访问人员、捐赠、网站和应用程序的其余部分。
3. 点击**设置**以设置教会的信息、管理角色和其他详细信息。
4. 点击**编辑铅笔**以设置您的教会信息。
5. 返回周日，点击右上角的**问号图标**以获取帮助和教程。
6. 点击**查看文档**以查看帮助您开始使用B1.church的教程列表。
7. 导航回仪表板并点击您的个人资料图片旁边的**箭头**并选择**切换应用**。
8. 选择**Lessons.church**以管理您的教会的在线课程和课程。
9. 通过点击您的个人资料图片旁边的箭头并再次选择**切换应用**来切换回B1.church。
10. 您现在可以通过**成员门户**或**管理员门户**进入B1.church。成员门户允许您查看B1.church如何显示给您的成员、查看您的小组并管理您的个人捐赠。

:::tip
从[设置](./settings/)页面开始以配置您的教会名称、品牌和团队权限。这确保了您设置的所有其他内容都将正确显示。
:::

## 使用命令面板快速查找任何内容

与其通过菜单点击不同，您可以从B1 Admin中的任何地方直接跳转到人员、小组、计划、基金或任何管理页面：

1. 按**Ctrl+K**（或在Mac上按**Cmd+K**），或在您不在文本字段中输入时按**/**以打开搜索栏。您也可以点击顶部导航中的**搜索或跳转...**按钮。
2. 开始输入您想要的名称或页面（例如，人的名称、"批次"或"歌曲"）。
3. 结果按类型分组——人员、小组、计划、基金和要跳转的页面。使用箭头键在结果之间移动，按**Enter**选择一个，或用鼠标点击结果。
4. 按**Esc**关闭搜索栏而不选择任何内容。

:::tip
命令面板通常是到达隐藏在子菜单中的页面的最快方式——输入部分页面名称，而不是手动通过设置、服务或捐赠导航。
:::
