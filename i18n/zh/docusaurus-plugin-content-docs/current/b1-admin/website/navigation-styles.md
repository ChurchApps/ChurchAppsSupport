# 导航样式

<div class="article-intro">

自定义教会网站的导航栏颜色，使其与你的品牌形象保持一致。你可以分别为实心背景和透明叠加层配置颜色，从而完全掌控导航栏在不同页面上的外观。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要拥有编辑网站内容的权限。详情请参阅[角色与权限](../settings/roles-permissions.md)。
- 准备好你的品牌颜色，包括十六进制颜色代码（例如 #03A9F4）。
- 了解网站上实心和透明导航样式之间的区别。

</div>

## 了解导航模式 {#understanding-navigation-modes}

根据页面的不同，你的网站导航可以呈现两种不同的样式：

- **实心导航** -- 带有背景颜色的导航栏，通常用于内容页面
- **透明导航** -- 叠加在页面内容之上的导航，通常用于带有横幅大图或全屏背景的页面

你可以分别独立自定义这两种模式的颜色。

## 进入导航样式 {#accessing-navigation-styles}

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），并展开 **Website**（网站）。
2. 点击 **Appearance**（外观）。
3. 在 **Style Settings**（样式设置）列表中，点击 **Navigation**（导航）。

**Navigation Styling**（导航样式）编辑器包含两张卡片：**Header (solid)**（页眉（实心））和 **Header over hero (transparent)**（横幅上方的页眉（透明））。

## 配置实心导航 {#configuring-solid-navigation}

实心导航会在导航栏后方显示背景颜色。这些设置位于 **Header (solid)** 卡片中。每种颜色都是可选的：在其 **Override**（覆盖）开关关闭时，导航会沿用你网站的常规颜色。你可以自定义以下项目：

### 背景颜色 {#background-color}

1. 打开 **Background color**（背景颜色）的 **Override** 开关
2. 点击颜色选择器
3. 选择你想要的背景颜色（选择器默认从白色 #FFFFFF 开始）

### 链接颜色 {#link-color}

1. 打开 **Link color**（链接颜色）的 **Override** 开关
2. 选择导航链接文字的颜色
3. 此设置会影响链接的默认状态（选择器默认从深灰色 #555555 开始）

### 链接悬停颜色 {#link-hover-color}

1. 打开 **Link hover color**（链接悬停颜色）的 **Override** 开关
2. 选择用户鼠标悬停在链接上时链接变成的颜色
3. 这为可点击的链接提供了视觉反馈（选择器默认从浅蓝色 #03A9F4 开始）

### 活动颜色 {#active-color}

1. 打开 **Active link color**（活动链接颜色）的 **Override** 开关
2. 选择当前所在页面链接的颜色
3. 这可以帮助用户了解自己当前所在的页面（选择器默认从浅蓝色 #03A9F4 开始）

## 配置透明导航 {#configuring-transparent-navigation}

透明导航直接叠加在页面内容之上，没有背景。这些设置位于 **Header over hero (transparent)** 卡片中。在某个 **Override** 开关关闭时，该颜色会自动与横幅版块的文字颜色保持一致。你可以自定义以下项目：

### 链接颜色 {#link-color-1}

1. 打开 **Link color** 的 **Override** 开关
2. 选择一种与页面背景对比鲜明的颜色
3. 在深色背景上，白色或浅色通常效果最佳

### 链接悬停颜色 {#link-hover-color-1}

1. 打开 **Link hover color** 的 **Override** 开关
2. 选择悬停状态的颜色
3. 确保它在页面背景上清晰可见

### 活动颜色 {#active-color-1}

1. 打开 **Active link color** 的 **Override** 开关
2. 选择活动页面指示器的颜色
3. 应当足够醒目，同时又与你的设计风格相协调

:::info
透明导航没有背景颜色设置，因为它直接叠加在页面内容之上。
:::

## 保存更改 {#saving-your-changes}

1. 配置好颜色后，点击 **Save Navigation**（保存导航）
2. 你的更改会立即应用到正在线上运行的网站
3. 访问你的网站，查看两种模式下的导航效果

## 恢复默认值 {#resetting-to-defaults}

如果你想恢复默认颜色：

1. 关闭所有自定义颜色的 **Override** 开关
2. 点击 **Save Navigation**
3. 导航会恢复为网站的常规颜色（在横幅上方时，则恢复为横幅的文字颜色）

或者点击 **Cancel**（取消）以放弃所有更改而不保存。

## 最佳实践 {#best-practices}

### 颜色对比度 {#color-contrast}

- **可读性** -- 确保链接颜色与背景之间有足够的对比度
- **WCAG 合规** -- 为了无障碍访问，建议对比度至少达到 4.5:1
- **测试两种模式** -- 分别以实心和透明导航预览你的网站

### 品牌一致性 {#brand-consistency}

- **使用品牌颜色** -- 与你的徽标和网站主题相匹配
- **限制配色数量** -- 保持在 2 到 3 种颜色，以获得统一的视觉效果
- **考虑你的图片** -- 如果使用透明导航，请用常见的页面背景进行测试

### 悬停和活动状态 {#hover-and-active-states}

- **清晰的反馈** -- 让悬停状态与默认链接明显区分开来
- **区分活动页面** -- 使用独特的颜色，让用户知道自己所在的位置
- **平滑过渡** -- 系统会自动为颜色变化添加动画效果

## 故障排除 {#troubleshooting}

### 颜色看起来不对 {#colors-dont-look-right}

- **清除缓存** -- 浏览器缓存可能会显示旧的颜色
- **检查十六进制代码** -- 确保你输入的是有效的十六进制颜色代码
- **在不同背景上测试** -- 颜色在不同页面上的显示效果可能有所不同

### 导航不可见 {#navigation-not-visible}

- **透明模式** -- 如果在浅色图片上使用透明导航，深色文字可能难以看清
- **解决方法** -- 调整链接颜色，或使用较深的页面背景
- **替代方案** -- 在导航区域添加轻微的阴影或背景叠加层

## 技术细节 {#technical-details}

导航样式以 JSON 形式存储，并通过 CSS 变量应用：

- 更改会立即生效，无需重新构建网站
- 颜色会层叠应用到所有导航元素
- 覆盖设置是可选的；未设置的颜色使用主题默认值
