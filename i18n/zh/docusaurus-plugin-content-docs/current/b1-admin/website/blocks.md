# 可复用区块

<div class="article-intro">

区块是你只需构建一次、即可在任意多个页面中重复使用的网站内容片段 -- 例如行动号召横幅、联系信息条或礼拜时间面板。当你编辑某个区块时，所有使用该区块的页面都会显示更改。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要拥有编辑网站内容的权限
- 请使用电脑或平板；区块编辑器与页面编辑器使用相同的全屏编辑器

</div>

## 打开区块 {#opening-blocks}

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），并展开 **Website**（网站）。
2. 点击 **Blocks**（区块）。**Reusable Blocks**（可复用区块）页面会列出每个区块及其 **Name**（名称）和 **Type**（类型）。

如果你的教会有多个网站，请使用页面顶部的网站切换器查看每个网站的区块。你的网站页脚也是一个区块，但它需要在[外观](./appearance.md)中的 **Site Footer**（网站页脚）里编辑，不会列在这里。

## 添加区块 {#adding-a-block}

1. 点击 **Add Block**（添加区块）。
2. 输入团队能够识别的 **Name**（名称）。
3. 选择 **Block Type**（区块类型）：
   - **Element(s)**（元素）-- 一个或多个元素（文字、图片、按钮等），可拖放到页面的某个版块中。
   - **Section(s)**（版块）-- 一个或多个完整版块，可拖放到页面中其他版块之间。
4. 点击 **Save**（保存）。该区块会出现在列表中。

## 编辑区块内容 {#building-a-blocks-content}

1. 点击区块名称，或点击其所在行上的 **Edit**（编辑）。该区块会在[页面编辑器](./page-editor.md)中打开。
2. 像在页面上一样，从版块开始添加和设置内容的样式。
3. 更改会自动保存。点击工具栏中的 **Exit**（退出）即可返回区块列表。

## 在页面中使用区块 {#using-a-block-on-a-page}

1. 在[页面编辑器](./page-editor.md)中打开某个页面，并点击 **Add Content**（添加内容）。
2. 在 **Add Elements**（添加元素）面板中选择 **Blocks**（区块）标签页。（只有在至少存在一个区块后，该标签页才会出现。）
3. 将区块拖放到页面上：元素区块放入某个版块中，版块区块则放在版块之间。

页面会显示该区块的当前内容。若要更改内容，请从 **Blocks** 页面编辑区块本身；所有使用它的页面都会随之更新。

## 重命名或删除区块 {#renaming-or-deleting-a-block}

1. 点击区块所在行上的 **Rename**（重命名）。
2. 更改 **Name**（名称）或 **Block Type**（区块类型），然后点击 **Save**；或点击 **Delete**（删除）并确认，以永久移除该区块。

:::warning
使用已删除区块的页面将不再显示其内容。在删除正在使用中的区块之前，请先检查相关页面。
:::
