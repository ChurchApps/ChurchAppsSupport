# 外观

<div class="article-intro">

"外观"页面让您自定义教会网站的整体外观和风格。从颜色和字体到间距和自定义 CSS，您可以从一个地方控制网站的每个视觉方面。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 为您的网站完成[初始设置](initial-setup)
- 准备好您的教会logo，PNG格式，透明背景，宽高比4:1
- 如果您有现有的样式指南，了解教会的品牌颜色（十六进制值）

</div>

## 访问外观设置

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏）并展开**网站**。
2. 点击**外观**。
3. 网站样式页面加载，左侧显示您网站的实时预览，右侧显示**样式设置**选项。

## 调色板

1. 在样式设置面板中点击**调色板**。
2. 您将看到**基础颜色**（浅色、强调色和深色）和**语义颜色**（主色、副色、成功、警告和错误）。
3. 点击任何色块以打开颜色选择器。拖动选择器或输入十六进制值以选择您的颜色。
4. **颜色组合预览**显示您选定的颜色如何协调使用。
5. 使用**建议调色板**快速应用预设计的配色方案。
6. 满意后点击**保存**。

## 排版

1. 在样式设置面板中点击**排版设置**。
2. 点击**选择字体**打开字体浏览器。您可以按名称搜索或浏览衬线、无衬线、展示、手写和等宽等类别。
3. 为标题和正文设置字体。
4. 点击**排版缩放**调整标题1至标题4的大小层级。使用缩放乘数和基础大小字段进行微调。
5. 点击**保存**应用您的字体选择。

## 间距

1. 在样式设置面板中点击**间距缩放**。
2. 调整超小到超大的间距值。实用示例显示每个值如何影响布局。
3. 点击**保存间距**将这些值应用到您的整个网站。

## Logo和品牌

1. 在样式设置面板中点击**Logo**。
2. 上传您的**浅色背景Logo**和**深色背景Logo**。使用透明背景的图像和4:1宽高比可获得最佳效果。
3. 上传**社交媒体图像**用于链接预览，以及**网站图标**用于浏览器标签。

:::tip
为获得最佳效果，请使用透明背景的PNG格式logo。这确保它在整个网站和[移动应用](../settings/mobile-app.md)的浅色和深色背景上都看起来很好。
:::

## 导航样式

自定义网站导航栏颜色，用于实心和透明模式：

1. 滚动到**导航样式**部分
2. 点击**编辑导航样式**
3. 为实心导航（带背景）和透明导航（叠加模式）配置颜色
4. 点击**保存**应用导航颜色

有关详细说明，请参阅[导航样式](./navigation-styles.md)。

## 公告和小部件

网站小部件出现在网站的每个页面上，浮动在页面内容上方：

- **公告横幅** -- 网站顶部的可关闭栏，用于时间敏感的消息，如即将举行的活动或服务变更。
- **启动程序** -- 一个浮动按钮，打开快速访问菜单，例如捐献、签到或查看公告栏的链接。

1. 在样式设置面板中点击**公告和小部件**。
2. 打开您需要的小部件，并配置它们的文本、链接和颜色。
3. 点击**保存**。

## 重定向和分析

样式设置中的**重定向和分析**面板包含两个不相关但通常需要的设置：

- **分析** -- 添加您的**Google分析4测量ID**以跟踪网站访客流量。
- **重定向** -- 将旧URL路径映射到新URL路径，这样指向已移动或重命名页面的链接可以继续工作，而不是返回404。输入旧的**来源**路径和新的**目标**路径，然后点击**保存**。

## 自定义CSS和JavaScript

1. 在样式设置面板中点击**CSS和Javascript**。
2. 添加**自定义CSS**以覆盖默认样式进行高级自定义。
3. 添加**自定义HTML**以用于跟踪代码或其他脚本。
4. 使用**常见Javascript示例**部分获取代码片段，如Google分析集成。

:::warning
自定义CSS功能强大，但如果使用不当可能破坏网站的布局。大多数教会可以使用内置的颜色、字体和间距控制实现他们想要的外观。仅当您熟悉网页开发时才使用自定义CSS。
:::

:::info
您的网站强制实施内容安全策略，该策略阻止来自任何其他来源的内联脚本。**自定义JavaScript**字段是唯一受信任的例外 -- 您保存在那里的代码按原样运行，因此仅从您信任的来源粘贴脚本（分析标签、聊天小部件和类似的嵌入）。
:::

## 样式主题

如果您想要一个快速起点，颜色调色板部分中的**建议调色板**提供预建的主题，一键设置协调的颜色。应用主题后，您总是可以微调单个设置。
