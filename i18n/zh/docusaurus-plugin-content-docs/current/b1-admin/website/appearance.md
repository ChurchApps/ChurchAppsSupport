# 外观

<div class="article-intro">

外观页面可让您自定义教会网站的整体外观和风格。从颜色和字体到间距和自定义 CSS，您都可以在一个地方控制网站的每个视觉方面。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 完成网站的[初始设置](initial-setup)
- 准备好 PNG 格式的教会标志，要求背景透明且宽高比为 4:1
- 如果您已有品牌风格指南，请了解教会的品牌颜色（十六进制值）

</div>

## 访问外观设置

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），并展开**网站**。
2. 点击**外观**。
3. **网站样式**页面加载。**主题、字体与页脚**卡片左侧显示**样式设置**列表，右侧显示示例网站的预览。其下方是**公告与小组件**和**重定向与分析**卡片。

## 调色板 {#color-palette}

1. 在样式设置面板中点击**调色板**。
2. 您将看到**基础颜色**（浅色、强调色和深色色调）和**语义颜色**（主要、次要、成功、警告和错误）。
3. 点击任意颜色色块以打开颜色选择器。拖动选择器或输入十六进制值以选择您的颜色。
4. **颜色组合预览**会显示您所选颜色的搭配效果。
5. 使用**推荐调色板**快速应用预设计的配色方案。
6. 对结果满意后，点击**保存调色板**。

## 字体排版

1. 在样式设置面板中点击**字体**。
2. 点击**标题字体**或**正文字体**按钮以打开字体浏览器。您可以按名称搜索，或浏览衬线、无衬线、展示、手写和等宽等类别。您也可以选择**热门字体组合**之一。
3. 点击**保存字体**以应用您的字体选择。
4. 要调整标题 1 至标题 4 的大小层级，请在样式设置面板中点击**字体排版比例**。使用**类型比例**乘数、**基础字号**和**行高**字段进行微调，然后点击**保存字体排版**。

## 间距

1. 在样式设置面板中点击**间距比例**。
2. 调整从特小到特大的间距值。实际示例会展示每个值如何影响布局。
3. 点击**保存间距**，将这些值应用到整个网站。

## 标志与品牌 {#logo-and-branding}

1. 在样式设置面板中点击**标志**。
2. 上传您的**浅色背景标志**和**深色背景标志**。为获得最佳效果，请使用背景透明且宽高比为 4:1 的图片。
3. 上传用于链接预览的**社交媒体图片**，以及用于浏览器标签页图标的**网站图标**。
4. 点击**保存更改**。上传的图片要到保存后才会存储，因此如果您先尝试关闭或刷新浏览器标签页，浏览器会警告您有未保存的更改。

:::tip
为获得最佳效果，请使用 PNG 格式、背景透明的标志。这可确保它在您的网站和[移动应用](../settings/mobile-app.md)中，无论在浅色还是深色背景上都显示良好。
:::

## 导航样式

自定义网站导航栏在实色和透明两种模式下的颜色：

1. 在样式设置面板中点击**导航**
2. 为**页眉（实色）**和**页眉覆盖于主视觉上（透明）**配置颜色
3. 点击**保存导航**以应用您的导航颜色

有关详细说明，请参阅[导航样式](./navigation-styles.md)。

## 公告与小组件

网站小组件会出现在您网站的每个页面上，浮动于页面内容之上：

- **公告横幅** -- 位于网站顶部的可关闭栏，用于显示时效性消息，例如即将举行的活动或礼拜时间的变更。
- **启动器** -- 一个浮动按钮，可打开快捷访问菜单，例如奉献、签到或查看周报的链接。

1. 在样式设置下方找到**公告与小组件**卡片。
2. 打开您想要的小组件，并配置其文字、链接和颜色。
3. 点击**保存**。

## 重定向与分析

**重定向与分析**卡片（位于样式设置下方）包含两项不相关但常用的设置：

- **分析** -- 添加您的 **GA4 衡量 ID**（格式为 `G-XXXXXXXXXX`），以跟踪网站访客流量。同一 ID 还会跟踪您教会 B1 应用（位于 `/mobile` 的成员门户，包括已安装的应用）中的页面浏览量，并标记 `display_mode` 为 `installed` 或 `browser`，以便您在 Google Analytics 中区分已安装应用的访问与浏览器访问。
- **重定向** -- 将旧的网址路径映射到新路径，这样移动或重命名的页面链接就能继续工作，而不会出现 404 错误。输入旧的**来源**路径和新的**目标**路径，然后点击**保存**。重定向还会优先于 B1 内置页面（`/sermons`、`/stream`、`/donate`、`/bible` 和 `/votd`），因此您可以将该地址指向其他地方（例如您自己的讲道页面或 YouTube 频道）。它不会覆盖您在同一地址上自行构建的页面。如果您希望重定向生效，请先删除该页面。

## 自定义 CSS 与 JavaScript

1. 在样式设置面板中点击**CSS 与 Javascript**。
2. 添加**自定义 CSS** 以覆盖默认样式，实现高级自定义。
3. 添加**自定义 HTML**，用于跟踪代码或其他脚本。
4. 使用**常用 JavaScript 示例**部分中的代码片段，例如 Google Analytics 集成。

:::warning
自定义 CSS 功能强大，但如果使用不当可能会破坏网站布局。大多数教会只需使用内置的颜色、字体和间距控件即可实现所需的外观。只有在您熟悉网页开发时才使用自定义 CSS。
:::

:::info
您的网站实施了内容安全策略，会阻止来自任何其他来源的内联脚本。此处的**自定义 HTML** 字段，以及各个页面上的 [HTML 元素](page-editor#using-the-html-element)，是受信任的例外——您在那里保存的代码会按原样运行，因此请只粘贴来自您信任来源的脚本（分析标签、聊天小组件及类似嵌入内容）。
:::

## 样式主题

如果您想要一个快速的起点，调色板部分中的**推荐调色板**提供了预先构建的主题，可一键设置协调的颜色。应用主题后，您始终可以微调各项单独设置。
