# 文件

<div class="article-intro">

文件页面是教会网站上所有媒体和文档的中央存储库。你可以在此上传、浏览和管理网站所需的每一张图片、文档和媒体文件。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 完成网站的[初始设置](./initial-setup.md)
- 上传前请先优化图片，以加快页面加载速度
- 请将文件准备为常见的网页格式（PNG、JPG、PDF 等）

</div>

## 上传文件 {#uploading-files}

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **Website**（网站），然后点击 **Files**（文件）。
2. 点击页面顶部的 **Upload Files**（上传文件），或点击右侧 **Upload Files** 面板中的 **Choose File**（选择文件），然后从电脑中选择文件。
3. 文件在你选择后会立即上传，并出现在文件表格中。

**Upload Files** 面板还会显示你已使用的存储空间。系统免费提供 100 MB；存储空间用满后，上传按钮会被隐藏，直到你删除文件或增加存储空间。若要获得更多空间，请在 **Settings**（设置）的 **File Storage**（文件存储）部分链接你自己的 Google Drive、Dropbox、OneDrive 或 S3 存储桶。此后文件会保存到你链接的账户中，面板会显示 **Stored in your linked account**（存储在你链接的账户中）。

:::tip
为获得最佳效果，请在上传前优化图片。较小的文件体积有助于加快访客的网站加载速度。TinyPNG 或 Squoosh 等工具可以在不明显降低画质的情况下压缩图片。
:::

## 浏览文件 {#browsing-files}

文件表格会列出所有已上传的文件，显示其 **Name**（名称）和 **Size**（大小）。点击文件名称即可在新标签页中打开该文件。上传前请为文件取一个清晰、具有描述性的名称，以便团队快速找到它们。

## 在网站上使用文件 {#using-files-on-your-website}

1. 在文件表格中找到该文件。
2. 点击 **Copy link**（复制链接）复制该文件的网址（按钮会变为 **Copied**（已复制））。你可以将此网址粘贴到图片元素、下载链接或任何接受文件网址的地方。
3. 你在此上传的文件可在你网站的所有页面和内容区块中使用。

:::info
在[页面管理](./managing-pages.md)中构建页面时，你可以通过网址引用此处上传的任何文件。这样可以将所有媒体集中保存在一个统一的位置。
:::

## 删除文件 {#deleting-files}

1. 在文件表格中找到你要移除的文件。
2. 点击其旁边的 **Delete**（删除），并确认以将其从库中永久移除。
3. 删除文件前，请确保该文件当前未被任何页面使用，否则将导致引用它的链接或图片失效。

:::warning
已删除的文件无法恢复。在移除文件之前，请仔细确认该文件已不再被任何页面使用。
:::
