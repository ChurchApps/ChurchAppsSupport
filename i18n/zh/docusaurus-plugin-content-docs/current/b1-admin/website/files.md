# 文件

<div class="article-intro">

文件页面是教会网站使用的所有媒体和文档的中央存储库。从这里您可以上传、组织、浏览和管理您的网站需要的每个图像、文档和媒体文件。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 为您的网站完成[初始设置](initial-setup)
- 在上传前优化图像以加快页面加载速度
- 以常见的网络格式准备您的文件（PNG、JPG、PDF等）

</div>

## 上传文件

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**网站**，然后点击**文件**。
2. 直接将文件拖放到上传区域，或点击上传按钮浏览您的计算机。
3. 您的文件会上传并立即出现在文件库中。

:::tip
为获得最佳效果，请在上传前优化图像。较小的文件大小帮助您的网站为访问者加载得更快。TinyPNG或Squoosh等工具可以在不明显质量损失的情况下压缩图像。
:::

## 使用文件夹组织

1. 创建文件夹来分组相关文件 -- 例如，"讲道图形"、"活动横幅"或"员工照片"。
2. 在文件夹之间移动文件以在库增长时保持整洁。
3. 使用清晰、描述性的文件夹名称，这样您的团队可以快速找到文件。

## 浏览和搜索

- 滚动浏览文件库查看所有已上传文件的缩略图。
- 当库变大时，使用**搜索**功能按名称查找文件。
- 点击任何文件查看其详细信息，包括文件名、大小和URL。

## 在您的网站上使用文件

1. 点击文件查看其详细信息。
2. **复制文件URL**以在您的网站页面中使用它。您可以将此URL粘贴到图像元素、下载链接或任何其他接受文件URL的地方。
3. 您在这里上传的文件可用于整个网站页面和内容块。

:::info
在[管理页面](managing-pages)中构建页面时，您可以通过URL引用此处上传的任何文件。这将所有媒体保持在一个中央位置。
:::

## 删除文件

1. 选择要删除的文件。
2. 点击**删除**按钮将其从库中永久删除。
3. 确保该文件当前未在任何页面上使用，因为这会破坏任何引用它的链接或图像。

:::warning
已删除的文件无法恢复。在删除文件前请仔细检查该文件在任何页面上不再使用。
:::
