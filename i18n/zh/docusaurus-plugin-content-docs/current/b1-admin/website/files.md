# 文件

<div class="article-intro">

文件页面是教会网站使用的所有媒体和文档的中央存储库。从这里您可以上传、浏览和管理您的网站需要的每个图像、文档和媒体文件。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 为您的网站完成[初始设置](initial-setup)
- 在上传前优化图像以加快页面加载速度
- 以常见的网络格式准备您的文件（PNG、JPG、PDF等）

</div>

## 上传文件

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**网站**，然后点击**文件**。
2. 在右侧的**上传文件**面板中，点击**选择文件**并从您的计算机中选择一个文件。（页面顶部的**上传文件**按钮会打开同一面板。）
3. 您的文件会上传并出现在文件表格中。

上传文件面板还会显示您正在使用的存储空间。免费提供100 MB；如需更多，请在**设置**的**文件存储**部分关联您自己的Google Drive、Dropbox、OneDrive或S3存储桶。

:::tip
为获得最佳效果，请在上传前优化图像。较小的文件大小帮助您的网站为访问者加载得更快。TinyPNG或Squoosh等工具可以在不明显质量损失的情况下压缩图像。
:::

## 浏览文件 {#browsing-files}

文件表格列出所有已上传的文件及其**名称**和**大小**。点击文件名称可在新标签页中打开它。上传前请为文件使用清晰、描述性的名称，以便您的团队快速找到它们。

## 在您的网站上使用文件

1. 在文件表格中找到该文件。
2. 点击**复制链接**以复制文件的URL。您可以将此URL粘贴到图像元素、下载链接或任何其他接受文件URL的地方。您可以将此URL粘贴到图像元素、下载链接或任何其他接受文件URL的地方。
3. 您在这里上传的文件可用于整个网站页面和内容块。

:::info
在[管理页面](managing-pages)中构建页面时，您可以通过URL引用此处上传的任何文件。这将所有媒体保持在一个中央位置。
:::

## 删除文件

1. 在文件表格中找到要删除的文件。
2. 点击其旁边的**删除**并确认，即可将其从库中永久删除。
3. 确保该文件当前未在任何页面上使用，因为这会破坏任何引用它的链接或图像。

:::warning
已删除的文件无法恢复。在删除文件前请仔细检查该文件在任何页面上不再使用。
:::
