# 博客

<div class="article-intro">

博客页面可让你将新闻、动态和灵修短文发布到教会网站上。文章会显示在 `/blog` 的卡片列表中、各自的网址上，并会出现在 RSS 订阅源中，其他工具（例如 Zapier）可以监测该订阅源以获取新文章。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 完成你网站的[初始设置](./initial-setup.md)
- 如果希望访客通过菜单找到你的博客，请在[管理页面](./managing-pages.md)中添加指向 `/blog` 的导航链接

</div>

## 访问博客

1. 在 B1 Admin 中，打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），并展开 **Website**。
2. 点击 **Blog**。
3. 博客页面会列出每篇文章及其状态和发布日期。

## 添加文章

1. 点击右上角的 **Add Post**（添加文章）。
2. 输入 **Title**（标题）。在你输入时，系统会自动生成一个便于网址使用的 **Web address**（网址，即 slug）。如果你想要其他网址，可以直接编辑。
3. 添加 **Excerpt**（摘要）——一段简短的概要，会显示在文章列表、元描述和 RSS 订阅源中。如果留空，系统会根据文章正文的开头自动生成。
4. 使用 Markdown 在 **Content**（内容）编辑器中撰写文章正文。点击 **Preview**（预览），查看格式化后的文章效果。
5. 选择一个 **Category**（分类）（可选择现有分类，或输入新分类），并可选填以逗号分隔的 **Tags**（标签）。
6. 点击 **Select Image**（选择图片），从你的[文件](./files.md)图库中选择照片，或上传新照片。上传的照片会在内置的裁剪工具中打开，比例锁定为 16:9，因此你可以调整任何照片，使其适合文章页眉和列表卡片。
7. 设置 **Author**（作者）——默认为你本人，但你也可以搜索并选择数据库中的任何人员。
8. 准备好将文章公开时，开启 **Published**（已发布）并设置 **Publish Date**（发布日期）。如果关闭此项，文章将保存为草稿。

:::tip
将 **Publish Date** 设为未来的日期即可定时发布文章。在该日期到来之前，文章对访客是隐藏的，并会在博客列表中显示 **Scheduled**（已排期）标签。
:::

## 文章状态

列表中的每篇文章会显示以下三种状态之一：

- **Draft**（草稿）—— 未发布。仅在管理后台可见。
- **Scheduled**（已排期）—— 已开启发布，但发布日期在未来。
- **Published**（已发布）—— 已在你的网站上线，并包含在 RSS 订阅源中。

## 编辑、预览和删除文章

- 点击文章旁边的 **Edit**（编辑）即可进行修改。
- 点击 **View on Site**（在网站上查看）（已发布的文章会显示此按钮），即可在新标签页中打开你网站上的已发布文章。
- 点击 **Delete**（删除）即可永久删除文章。

## 访客如何查看你的博客

已发布的文章会显示在 `{yoursite}/blog`，每页 10 篇，并通过 **Older**（更早）/**Newer**（更新）链接翻阅存档，同时还提供分类筛选，以及每篇文章的署名和照片。标签同样会显示为可点击的标签按钮，访客可以用同样的方式按标签筛选列表。单篇文章的网址为 `{yoursite}/blog/{slug}`，并会显示同一分类下的相关文章。博客页面还会发布 RSS 订阅源，可被订阅阅读器和 Zapier 等自动化工具自动识别。

:::info
博客文章是与普通网站页面不同的内容类型——它们不在[页面编辑器](./page-editor.md)中构建，也不会出现在页面列表中。这样可以让博客创作更快捷，更专注于写作本身。
:::

## 在文章下方添加评论

B1 本身不提供博客评论功能，但你可以添加评论服务。你还可以在每篇文章下方放置其他内容，例如电子报订阅或奉献按钮。

1. 注册 [Hyvor Talk](https://talk.hyvor.com)、[FastComments](https://fastcomments.com) 或 [Disqus](https://disqus.com) 等评论服务，并复制其嵌入代码。
2. 在博客页面中，向下滚动到 **Below Every Post**（每篇文章下方）。
3. 粘贴嵌入代码，然后点击 **Save**。

该代码会显示在每篇已发布文章的内容下方。评论服务负责审核和垃圾信息过滤，因此请定期查看其后台。

:::tip
清空文本框并点击 **Save**，即可从所有文章中移除该代码。只有有权编辑教会设置的人员才能看到此文本框。
:::
