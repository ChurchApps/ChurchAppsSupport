# 博客

<div class="article-intro">

博客页面让您向教会网站发布新闻、更新和灵修内容。帖子在`/blog`的卡片列表中显示、在自己的URL处显示、以及在其他工具（如Zapier）可以观看新帖子的RSS源中显示。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 为您的网站完成[初始设置](initial-setup)
- 如果您希望访问者从菜单找到您的博客，请从[管理页面](managing-pages)添加指向`/blog`的导航链接

</div>

## 访问博客

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏）并展开**网站**。
2. 点击**博客**。
3. 博客页面列出每篇帖子及其状态和发布日期。

## 添加帖子

1. 在右上角点击**添加帖子**。
2. 输入**标题**。当您输入时会自动为您生成URL友好的slug -- 如果您需要不同的地址，可以直接编辑。
3. 添加**摘录** -- 在帖子列表、元描述和RSS源中显示的简短摘要。如果留空，会自动从您的帖子内容开头生成。
4. 在**内容**编辑器中使用Markdown编写帖子正文。点击**预览**查看格式化后的帖子样子。
5. 选择**分类**（选择现有的或输入新的）和可选的逗号分隔的**标签**。
6. 点击**选择图像**从您的[文件](files)库中选择照片，或上传新的。上传的照片在内置的裁剪工具中打开，锁定为16:9比例，这样您可以为帖子标题和列表卡片框架任何照片。
7. 设置**作者** -- 默认为您，但您可以搜索并选择数据库中的任何人。
8. 打开**已发布**并在准备好将帖子公开发布时设置**发布日期**。关闭以将帖子保存为草稿。

:::tip
设置未来的**发布日期**来计划帖子。它对访问者保持隐藏，并在博客列表中显示**已计划**芯片，直到那个日期到来。
:::

## 帖子状态

列表中的每篇帖子显示三种状态之一：

- **草稿** -- 未发布。仅在管理员中可见。
- **已计划** -- 已发布打开，但发布日期在未来。
- **已发布** -- 在您的网站上线并包含在RSS源中。

## 编辑、预览和删除帖子

- 点击帖子旁的**编辑**图标进行更改。
- 点击**查看**图标（在已发布帖子上可见）在新标签中打开您网站上的实时帖子。
- 点击**删除**图标永久删除帖子。

## 访问者如何看待您的博客

已发布的帖子在`{yoursite}/blog`显示，每页10篇，带有**更早**/**更新**链接来浏览存档，以及分类过滤器和每篇帖子的署名和照片。标签也作为可点击的芯片呈现，让访问者以相同的方式按标签过滤列表。各个帖子位于`{yoursite}/blog/{slug}`并包括来自同一类别的相关帖子。博客页面也发布RSS源，可由提要阅读器和Zapier等自动化工具自动发现。

:::info
博客帖子是独立于常规网站页面的内容类型 -- 它们不在[页面编辑器](page-editor)中构建，也不出现在页面列表中。这使博客创作快速专注于写作。
:::
