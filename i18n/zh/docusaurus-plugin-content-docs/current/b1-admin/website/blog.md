# 博客

<div class="article-intro">

博客页面让你可以向教会网站发布新闻、更新和灵修内容。文章会显示在 `/blog` 的卡片列表中、拥有自己的网址，并出现在其他工具（如 Zapier）可以监听新文章的 RSS 订阅源中。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 完成网站的[初始设置](initial-setup)
- 如果希望访客能从菜单中找到你的博客，请在[管理页面](managing-pages)中添加一个指向 `/blog` 的导航链接

</div>

## 访问博客

1. 在 B1 Admin 中，点击左侧菜单中的**网站**。
2. 点击网站页面视图顶部的**博客**标签。
3. 博客页面会列出每篇文章及其状态和发布日期。

## 添加文章

1. 点击右上角的**添加文章**。
2. 输入**标题**。系统会在你输入时自动生成一个对网址友好的 slug——如果你想要不同的地址，可以直接编辑它。
3. 添加**摘要**——在文章列表、元描述和 RSS 订阅源中显示的简短摘要。如果留空，会自动根据文章内容开头生成一个摘要。
4. 在**内容**编辑器中使用 Markdown 撰写文章正文。点击**预览**查看格式化后文章的效果。
5. 选择一个**类别**（选择已有类别或输入新类别）以及可选的、以逗号分隔的**标签**。
6. 点击**选择图片**，从你的[文件](files)库中选择照片，或上传新照片。上传的照片会打开内置的裁剪工具，固定为 16:9 比例，方便你将任意照片调整以适应文章头图和列表卡片。
7. 设置**作者**——默认是你自己，但你可以搜索并选择数据库中的任何人。
8. 准备公开文章时，打开**已发布**并设置**发布日期**。若保持关闭，则文章会保存为草稿。

:::tip
将**发布日期**设置为未来某个日期即可安排文章定时发布。在该日期到来之前，文章对访客保持隐藏，并在博客列表中显示**已安排**芯片。
:::

## 文章状态

列表中的每篇文章都会显示以下三种状态之一：

- **草稿** -- 未发布。仅在后台可见。
- **已安排** -- 已开启发布，但发布日期在未来。
- **已发布** -- 已在你的网站上线，并包含在 RSS 订阅源中。

## 编辑、预览和删除文章

- 点击文章旁的**编辑**图标进行修改。
- 点击**查看**图标（在已发布文章上可见）在新标签页中打开网站上的实时文章。
- 点击**删除**图标永久移除一篇文章。

## 访客如何浏览你的博客

已发布的文章显示在 `{yoursite}/blog`，每页 10 篇，并带有**更早**/**更新**链接以翻阅存档，此外还有分类筛选器以及每篇文章的作者信息和图片。标签也会渲染为可点击的芯片，让访客可以用同样的方式按标签筛选列表。单篇文章位于 `{yoursite}/blog/{slug}`，并包含来自同一类别的相关文章。博客页面还会发布 RSS 订阅源，可被订阅阅读器和 Zapier 等自动化工具自动发现。

:::info
博客文章是与普通网站页面不同的内容类型——它们不是在[页面编辑器](page-editor)中构建的，也不会出现在页面列表中。这使博客写作保持快捷，专注于写作本身。
:::
