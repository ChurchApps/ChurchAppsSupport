# 博客

<div class="article-intro">

博客页面让您可以向教会网站发布新闻、动态和灵修文章。文章会以卡片列表的形式显示在 `/blog`，每篇文章也有自己的网址，并且会出现在 RSS 订阅源中，供 Zapier 等其他工具监控新文章。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 完成您网站的[初始设置](./initial-setup.md)
- 如果您希望访客能从菜单找到您的博客，请通过[管理页面](./managing-pages.md)添加一个指向 `/blog` 的导航链接

</div>

## 访问博客

1. 在 B1 Admin 中，打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），并展开 **Website**。
2. 点击 **Blog**。
3. 博客页面会列出每篇文章及其状态和发布日期。

## 添加文章

1. 点击右上角的 **Add Post**（添加文章）。
2. 输入**标题**。系统会在您输入时自动生成一个对 URL 友好的**网址**（slug）。如果您想要不同的地址，可以直接编辑。
3. 添加**摘要**（Excerpt）——在文章列表、元描述和 RSS 订阅源中显示的简短概要。如果留空，系统会根据文章内容开头自动生成一段摘要。
4. 使用 Markdown 在**内容**（Content）编辑器中撰写文章正文。点击 **Preview**（预览）可查看格式化后的文章效果。
5. 选择**类别**（Category）（选择现有类别或输入新类别），并可选填以逗号分隔的**标签**（Tags）。
6. 点击 **Select Image**（选择图片）从您的[文件](./files.md)库中选择照片，或上传新照片。上传的照片会在内置的裁剪工具中打开，比例锁定为 16:9，因此您可以将任何照片裁剪到适合文章页眉和列表卡片的样式。
7. 设置**作者**（Author）——默认为您本人，但您可以搜索并选择数据库中的任何人员。
8. 在您准备公开文章时，开启 **Published**（已发布）并设置**发布日期**（Publish Date）。若关闭，文章会保存为草稿。

:::tip
将**发布日期**设为未来的某一天即可定时发布文章。在该日期到来之前，文章对访客保持隐藏，并会在博客列表中显示 **Scheduled**（已排定）标签。
:::

## 文章状态

列表中的每篇文章都会显示以下三种状态之一：

- **Draft**（草稿）——未发布。仅在管理后台可见。
- **Scheduled**（已排定）——已开启 Published，但发布日期在未来。
- **Published**（已发布）——在您的网站上上线，并包含在 RSS 订阅源中。

## 编辑、预览和删除文章

- 点击文章旁边的 **Edit**（编辑）即可进行修改。
- 点击 **View on Site**（在网站上查看）（显示在已发布的文章上）可在新标签页中打开您网站上的已发布文章。
- 点击 **Delete**（删除）即可永久删除文章。

## 访客如何看到您的博客

已发布的文章会显示在 `{yoursite}/blog`，每页 10 篇，并附有 **Older**（更早）/**Newer**（更新）链接，用于翻阅归档；页面还提供类别筛选，以及每篇文章的署名和照片。标签也会显示为可点击的标签，访客同样可以按标签筛选列表。单篇文章位于 `{yoursite}/blog/{slug}`，并会显示同一类别的相关文章。博客页面还会发布 RSS 订阅源，可被订阅阅读器和 Zapier 等自动化工具自动发现。

如果您开启了此功能，已发布的文章还可以显示在教会应用主屏幕的 **News**（新闻）区块中——参见[主屏幕区块](../settings/mobile-app.md#home-screen-sections)。

:::info
博客文章与普通网站页面是不同的内容类型——它们不是在[页面编辑器](./page-editor.md)中构建的，也不会出现在页面列表中。这样可以让博客写作更快捷，并专注于写作本身。
:::

## 在文章下方添加评论

B1 本身不托管博客评论，但您可以添加评论服务。您也可以在每篇文章下方放置其他内容，例如电子报订阅或奉献按钮。

1. 注册 [Hyvor Talk](https://talk.hyvor.com)、[FastComments](https://fastcomments.com) 或 [Disqus](https://disqus.com) 等评论服务，并复制其嵌入代码。
2. 在博客页面上，滚动到 **Below Every Post**（每篇文章下方）。
3. 粘贴嵌入代码，然后点击 **Save**。

该代码会显示在每篇已发布文章的内容下方。您的评论服务负责审核和垃圾信息过滤，因此请定期检查其后台。

:::tip
清空输入框并点击 **Save**，即可从每篇文章中移除该代码。只有有权编辑教会设置的人员才能看到此输入框。
:::
