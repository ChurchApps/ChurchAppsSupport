# 初始设置

<div class="article-intro">

每个 B1 帐户都附带一个现成的网站。本指南将指导您完成设置教会域、配置网站外观、创建首个页面和组织导航。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要具有管理员访问权限的 B1.church 帐户
- 如果使用自定义域，请准备好您的 DNS 提供商登录凭据（例如 GoDaddy、Cloudflare 或 AWS）
- 准备您的教会徽标，PNG 格式，具有透明背景以获得最佳效果

</div>

## 设置您的域

您的教会会在 B1.church 上自动收到子域（例如 `yourchurch.b1.church`）。您也可以将自己的自定义域指向您的 B1 网站。

1. 通过访问 admin.b1.church 或单击您的档案下拉菜单并选择**切换应用**来转到 **B1.church Admin**。
2. 打开左上角的**菜单**（带小箭头的菜单名称）并选择**设置**。
3. 单击**管理**以查看您的子域。将其设置为简短和易记的内容，不带空格。
4. 要使用自定义域，请登录您的 DNS 提供商（如 GoDaddy、Cloudflare 或 AWS）并添加两条记录：
   - 您根域的 **A 记录**指向 `3.23.251.61`
   - `www` 的 **CNAME 记录**指向 `proxy.b1.church`
5. 返回 B1.church Admin，将您的自定义域添加到列表中，然后单击**添加**然后**保存**。您的网站将在几分钟内可从自定义域访问。

:::tip
如果您看不到设置选项，请要求设置您教会帐户的人员向您授予"编辑教会设置"权限。有关详细信息，请参阅[角色和权限](../settings/roles-permissions.md)。
:::

## 创建您的首个页面

1. 在 B1 Admin 中，单击左菜单中的**网站**以打开网站页面视图。
2. 单击右上角的**添加页面**。
3. 选择**空白**作为页面类型并将其命名为 "Home"。
4. 单击**页面设置**并将 URL 路径设置为 `/`（单个正斜杠，没有文本）作为您的首页。其他页面使用 `/page-name`。
5. 单击**编辑内容**以开始构建。每个页面必须以**部分**开始 -- 这是所有其他元素的容器。
6. 添加部分后，再次单击**添加内容**以插入文本、图像、视频、卡片、表单等，通过将其拖入您的部分中。

:::info
有关使用页面和导航的详细说明，请参阅[管理页面](managing-pages)。有关可视化编辑器的完整指南，请参阅[使用页面编辑器](page-editor)。
:::

## 配置网站外观

1. 从网站页面视图中，单击顶部的**外观**选项卡。
2. 使用**颜色调色板**为主色、辅助色和强调色设置您的品牌颜色。
3. 在**排版设置**下，从字体浏览器中选择您的标题和正文字体。
4. 在样式设置中的**徽标**下上传您的教会徽标。提供浅色背景和深色背景版本。
5. 使用您教会的联系信息和链接配置您的**网站页脚**。

:::info
您在外观中所做的更改会应用到整个网站。有关每个设置的详细说明，请参阅[外观](appearance)页面。
:::

## 设置导航

您的导航链接显示在网站页面视图中。要组织它们：

1. 单击**添加**以创建新导航链接并将其指向您的一个页面。
2. 拖放链接以重新排序它们或将其嵌套在父项下。
3. 预览您的网站以确认导航看起来正确。
