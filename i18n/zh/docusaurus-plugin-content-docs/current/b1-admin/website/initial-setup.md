# 初始设置

<div class="article-intro">

每个B1账户都带有一个准备好的网站。本指南将引导您设置教会域名、配置网站外观、创建第一个页面和组织导航。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 您需要具有管理员访问权限的B1.church账户
- 如果使用自定义域名，准备好您的DNS提供商登录凭据（如GoDaddy、Cloudflare或AWS）
- 为获得最佳效果，准备您的教会logo，PNG格式，透明背景

</div>

## 设置您的域名

您的教会自动在B1.church上获得一个子域（例如，`yourchurch.b1.church`）。您也可以将您自己的自定义域指向您的B1网站。

1. 访问admin.b1.church或点击您的个人资料下拉菜单并选择**切换应用**以进入**B1.church Admin**。
2. 打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**设置**，然后点击**设置**。
3. 打开**教会信息**部分查看您的子域。将其设置为简短且易识别的名称，无空格。
4. 要使用自定义域，登录您的DNS提供商（如GoDaddy、Cloudflare或AWS）并添加两条记录：
   - 您的根域的**A记录**指向`3.23.251.61`
   - `www`的**CNAME记录**指向`proxy.b1.church`
5. 返回B1.church Admin，将您的自定义域添加到列表中，然后点击**添加**然后**保存**。您的网站将在几分钟内可从您的自定义域访问。

:::tip
如果您看不到设置选项，请要求设置您教会账户的人员授予您"编辑教会设置"权限。详情请参阅[角色和权限](../settings/roles-permissions.md)。
:::

## 创建您的首个页面

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**网站**，然后点击**页面**。
2. 在右上角点击**添加页面**。
3. 选择**空白**作为页面类型，将其命名为"首页"。
4. 点击**页面设置**并将URL路径设置为`/`（仅正斜杠，无文本）用于您的首页。其他页面使用`/page-name`。
5. 点击**编辑内容**开始构建。每个页面必须以**部分**开始 -- 这是所有其他元素的容器。
6. 添加部分后，再次点击**添加内容**以通过将文本、图像、视频、卡片、表单等拖入您的部分来插入它们。

:::info
关于使用页面和导航的详细说明，请参阅[管理页面](managing-pages)。关于可视化编辑器的完整指南，请参阅[使用页面编辑器](page-editor)。
:::

## 配置网站外观

1. 在Jump菜单中，选择**网站 > 外观**。
2. 使用**调色板**为主色、副色和强调色设置品牌颜色。
3. 在**排版设置**下，从字体浏览器选择标题和正文字体。
4. 在样式设置中的**Logo**下上传您的教会logo。提供浅色背景和深色背景版本。
5. 使用您教会的联系信息和链接配置您的**网站页脚**。

:::info
您在外观中所做的更改应用于整个网站。请参阅[外观](appearance)页面了解每个设置的详细说明。
:::

## 设置导航

您的导航链接出现在网站页面视图中。要组织它们：

1. 点击**添加**创建新的导航链接并将其指向您的一个页面。
2. 拖放链接以重新排序或将其嵌套在父项下。
3. 预览您的网站以确认导航看起来正确。
