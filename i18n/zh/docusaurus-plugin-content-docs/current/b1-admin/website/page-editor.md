# 使用页面编辑器

<div class="article-intro">

B1 页面编辑器是一款可视化的拖放式构建工具，让你无需编写任何代码即可设计教会网站页面。你可以添加版块和内容区块、自定义样式、预览作品，并撤销更改 -- 所有操作都在浏览器中完成。

</div>

## 打开编辑器 {#opening-the-editor}

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **Website**（网站），然后点击 **Pages**（页面）。
2. 在页面表格中找到要编辑的页面，然后点击 **Edit Content**（编辑内容）。

编辑器会以全屏模式打开，并实时预览你的页面。顶部工具栏包含 **Exit**（退出）、页面的发布状态、**Undo**（撤销）和 **Redo**（重做）、保存状态、**Publish**（发布）、桌面和移动端预览按钮、**Add Content**（添加内容）、无障碍检查，以及 **More**（更多）（⋮）菜单。点击 **Add Content** 可在左侧打开 **Add Elements**（添加元素）面板；点击某个版块或元素，即可在右侧打开其设置。

编辑器需要至少约 880 像素宽的屏幕。在手机上，你会看到提示，要求你改用平板或电脑打开该页面。

:::info
无论你的 B1 Admin 主题设置如何，编辑器始终以浅色模式显示，并使用你在[外观](./appearance.md)中选择的标题和正文字体。这可以确保预览准确反映访客所看到的页面效果。
:::

## 页面结构：版块与元素 {#page-structure-sections-and-elements}

每个页面都由两个层级构成：

- **版块**（Sections）-- 顶层容器，将页面划分为水平的区域（例如横幅版块、内容区块或页脚条）。每个页面在添加内容之前，都必须至少有一个版块。
- **元素**（Elements）-- 放置在版块内的各个内容组件，例如文字、图片、按钮、卡片、表单和日历。

### 添加版块 {#adding-a-section}

1. 点击 **Add Content**，然后将 **Section**（版块）拖放到页面上。你也可以将鼠标悬停在两个版块之间，然后点击出现的 **+**（**Add section**（添加版块））按钮。
2. 在 **Choose a Section Layout**（选择版块布局）对话框中，选择开始方式：
   - **From a template**（从模板开始）-- 按类别浏览版块模板（Hero（横幅）、About（关于）、Services（服事）、People（人员）、Media（媒体）、Giving（奉献）和 Call to Action（行动号召）），点击其中一个即可插入一个已完成样式设置、预先填充内容的版块。添加后，你可以自由自定义其中的所有内容。
   - **Blank Section**（空白版块）-- 一个空白版块，从零开始构建。若要将其分为多列，请在其中添加一个 **Row**（行）元素。
3. 新版块会出现在预览中。点击它即可选中，并配置其背景、颜色和其他样式选项。

将鼠标悬停在某个版块上，会显示其工具栏：拖动手柄、**Section settings**（版块设置）、**Move section up**（上移版块）、**Move section down**（下移版块）、**Duplicate section**（复制版块）、**Try another layout**（尝试其他布局）和 **Delete section**（删除版块）。

### 切换版块布局 {#switching-a-sections-layout}

如果你已经搭建好某个版块，但想要不同的结构，请点击该版块工具栏上的 **Try another layout**（尝试其他布局），即可从图库中换用另一种排列方式，同时保留现有的内容和元素。

### 向版块中添加元素 {#adding-elements-to-a-section}

1. 点击 **Add Content** 打开 **Add Elements** 面板。使用 **Search Elements**（搜索元素）或标签页（**All**（全部）、**Common**（常用）、**Media**（媒体）、**Church**（教会）、**Advanced**（高级），以及在你创建了[可复用区块](./blocks.md)后出现的 **Blocks**（区块））查找元素。
2. 将元素拖放到预览中的某个版块里；或者先在页面上选中一个元素，然后点击某张卡片，即可在该元素之后紧接着添加新元素。元素包括：
   - **Row**（行）-- 将版块分为并排的多列
   - **Box**（盒子）-- 将元素组合在带样式的容器中
   - **Carousel**（轮播）-- 循环播放一组全宽幻灯片
   - **White Space**（留白）-- 添加空白的垂直间距
   - **Text**（文字）-- 标题、段落和富文本
   - **Image**（图片）-- 上传照片或链接到照片
   - **Button Link**（按钮链接）-- 可点击的行动号召按钮
   - **Card**（卡片）-- 带有标题和描述的图片
   - **Form**（表单）-- 直接在页面上嵌入[表单](../forms/creating-forms.md)。如果表单设有[页眉图片](../forms/creating-forms.md#adding-a-header-photo)，它会显示在问题上方
   - **Calendar**（日历）-- 显示活动日历
   - **Expandable**（可展开）-- 手风琴式的问答区块
   - **Video**（视频）-- 通过网址嵌入视频
   - **Groups Browser**（小组浏览器）-- 所有教会小组的可筛选名录，可选择搜索、分类筛选和标签筛选。其 **Layout**（布局）可以是 **Grid**（网格，默认）或 **Scrolling (automatic)**（自动滚动）-- 参见[滚动布局](#scrolling-layouts)
   - **Group List**（小组列表）-- 你的公开小组图块，可选择仅显示带有特定标签的小组。其 **Layout** 可以是 **Grid**（网格，默认；每行最多三个图块）或 **Scrolling (automatic)** -- 参见[滚动布局](#scrolling-layouts)
   - **Icon Feature**（图标特色）-- 带有图标、标题和简短描述的内容，用于突出特色或事工亮点
   - **Gallery**（图库）-- 多图网格或瀑布流布局
   - **Testimonial**（见证）-- 一条或多条引言，包含作者姓名、角色和照片
   - **Social Icons**（社交图标）-- 指向教会社交媒体资料的链接图标：Facebook、Instagram、WhatsApp、YouTube、X、TikTok、Vimeo 和 Podcast（播客）。为每个要显示的图标填写链接；对于 **WhatsApp**，请使用包含你的号码的 `https://wa.me/` 链接，或小组邀请链接
   - **Countdown**（倒计时）-- 倒计时至某个日期或每周礼拜时间的计时器
   - **Stats**（数据）-- 一排带标签的大号数字（例如成员人数、年数、校区数）
   - **Campaign Progress**（活动进度）-- 奉献活动的实时进度条，显示为某个基金目标已筹集的总额
   - **Staff Grid**（工作人员网格）-- 小组成员的照片卡片；该小组必须开启 **public roster**（公开名单）选项
   - **Service Times**（礼拜时间）-- 你各校区的礼拜时间表，自动从出勤设置中提取
   - **Sermons**（讲道）-- 你的讲道库，可显示为完整浏览器，或网格、列表或精选最新布局
   - **Location**（地点）-- 以教会地址为中心的嵌入式地图
   - **Table**（表格）-- 用于表格内容的简单行列网格
   - **Text with Photo**（文字与图片）-- 并排显示的文字和图片
   - **Logo**（徽标）-- 你的教会徽标，取自[外观](./appearance.md)
   - **Stream**（直播）-- 直接嵌入页面的直播播放器
   - **Podcast**（播客）-- 从你提供的外部播客 RSS 订阅源网址中提取的单集列表，可设置显示的单集数量，以及是否显示日期和描述。在线网站上，每一集都带有音频播放器和 **Download**（下载）链接，可将该集的音频文件以单集标题命名保存。此元素用于在你的网站上推荐任意播客订阅源；若要将你自己的讲道发布为播客，请改为参见[管理讲道](../sermons/managing-sermons.md#your-podcast-feed)。
   - **Donation**（奉献）-- 嵌入页面的完整奉献表单
   - **Donate Link**（奉献链接）-- 打开你奉献页面的按钮
   - **HTML** -- 你自己的原始 HTML，适用于高级用途，例如嵌入第三方小组件（参见[使用 HTML 元素](#using-the-html-element)）
   - **Embedded Page**（嵌入页面）-- 通过网址在框架中嵌入另一个网页
3. 在出现的设置面板中配置该元素。

### 使用 HTML 元素 {#using-the-html-element}

**HTML** 元素包含两个输入框：

- **HTML Content**（HTML 内容）-- 要在页面上显示的标记代码。你在此包含的任何 `<script>` 标签都会在线上网站中运行。
- **JavaScript (exclude script tag)**（JavaScript（不含 script 标签））-- 页面加载时运行的脚本代码。你也可以将供应商提供的嵌入代码片段（包含其 `<script>` 标签）粘贴到此处，它同样会在线上网站中运行。

如果你只在 JavaScript 输入框中粘贴一个网址（例如图片链接），该输入框会变为红色，并显示警告 *"This is a web address, not JavaScript."*（这是网址，而不是 JavaScript。）。该输入框中的单独网址不会产生任何效果。若要显示图片，请使用 **Image** 元素，或在 **HTML Content** 中放入 `<img src="...">`。

### 使用日历元素 {#using-the-calendar-element}

**Calendar** 元素会显示你某个日历中的活动：

1. 在 **Select**（选择）下，选择 **Group Calendar**（小组日历，即一个小组的活动 -- 列表中显示你所属的小组）或 **Curated Calendar**（精选日历，即你在 **Calendars**（日历）下创建的日历；参见[精选日历](../calendars/curated-calendar.md)）。
2. 在 **Select Calendar**（选择日历）下，选择小组或日历。
3. 在 **Display**（显示）下，选择显示方式：
   - **Month calendar**（月历）-- 访客可以翻页浏览的月份网格。每个活动都会按其所属小组着色，因此同一小组的活动在每个日历上颜色都相同。B1 会自动选择颜色，无需任何设置。
   - **Upcoming events**（即将到来的活动）-- 显示接下来 12 个活动的图块网格，重复活动只会在其下一个日期显示一次。每个图块会显示活动的照片（若无照片，则在你主题的深色背景上显示其标题）、日期标记、星期和时间，以及描述的第一行。图块上方的 **Subscribe**（订阅）按钮允许访客复制日历的 ICS 链接或下载该日历。此显示方式下会出现 **Layout**（布局）设置：**Grid**（网格，默认）或 **Scrolling (automatic)**（自动滚动），后者会将图块排列在一行中，并自行横向滚动（参见[滚动布局](#scrolling-layouts)）。对于 **Curated Calendar**，请开启 **Group badge**（小组标记）设置，以在每个图块的右上角显示该活动的小组名称，并以该小组的日历颜色显示。已归档或保密小组的活动不会显示标记。
4. 若只想显示部分活动，请在 **Only events tagged**（仅显示带有以下标签的活动）中输入标签，例如 `youth`。只有 **Tags**（标签）中包含该词的活动才会显示。留空则显示所有活动。标签在每个活动上设置；参见[添加和编辑活动](../calendars/creating-calendars.md#adding-and-editing-events)。

无论采用哪种显示方式，点击某个活动都会打开其在你网站上的独立页面。活动页面会显示活动照片、标题、日期和时间以及描述，并附有一个方框，内容包括 **When**（何时）（对于重复活动，包括重复模式）和 **Where**（何地）（为该活动预订的场地）。若已开启报名功能，页面上还会显示 **Register for this Event**（报名参加此活动）按钮，以及 **Add to my calendar**（添加到我的日历）链接，可下载该活动的日历文件。该页面经过设置，使搜索引擎能够在搜索结果中显示活动的日期和详情。在你的页面上显示的精选日历活动页面（针对未来六个月内的活动）也会列入你网站的网站地图，以便搜索引擎找到它们。

### 滚动布局 {#scrolling-layouts}

**Groups Browser**（小组浏览器）、**Group List**（小组列表）以及日历元素的 **Upcoming events**（即将到来的活动）显示方式中的 **Scrolling (automatic)**（自动滚动）布局，会将图块排列为一行，而非网格。在手机上，每个图块占满整行；在电脑上，两个图块并排显示。当图块数量超过可容纳的数量时，该行会：

- 大约每四秒前进一个图块，并在最后一个图块之后回到第一个继续循环。
- 当访客将鼠标悬停、触摸或通过键盘进入该行时暂停，并在几秒钟后恢复。
- 在下方显示一排圆点，每个图块对应一个圆点，当前图块的圆点会被填充。访客可以点击圆点直接跳转到对应图块。

在设置了减少动态效果的设备上，该行保持静止，访客可自行滑动或滚动它。如果所有图块都能放得下，该行不会移动，也不会显示圆点。

### 重新排列内容 {#reordering-content}

拖动每个项目左侧的手柄图标（六个点）即可对版块或元素重新排序。你可以在版块内拖动元素，也可以将元素移动到其他版块中。

## 设置页面样式 {#styling-your-page}

### 版块样式 {#section-styles}

点击任意版块即可打开其样式面板。你可以设置：

- **Colors**（颜色）-- 在 **Suggested**（推荐）标签页中，点击配色方案中的某一种颜色组合。在 **Custom**（自定义）标签页中，设置 **Background Type**（背景类型）（**Color**（颜色）、**Image**（图片）或 **YouTube Video**（YouTube 视频）），以及标题、正文和链接的颜色。若使用图片背景，请点击图片以设置焦点（图片裁剪时保持在可视范围内的部分），并使用 **Overlay Color**（叠加颜色）和 **Background Opacity**（背景不透明度）为图片添加色调，以确保文字清晰可读。
- **Visibility**（可见性）-- **Hide on desktop**（在桌面端隐藏）或 **Hide on mobile**（在移动端隐藏）
- **Styles**（样式）-- 添加单独的样式设置，例如上下内边距，可应用于所有设备、仅桌面端或仅移动端
- **Animations**（动画）-- 版块滚动进入视野时的效果和速度
- **Shape Dividers**（形状分隔线）-- 位于版块顶部或底部边缘的装饰形状（wave（波浪）、waves（多重波浪）、slant（斜线）、curve（曲线）、peaks（山峰）和 triangle（三角形）），可设置颜色、高度和翻转选项

版块设置中还提供 **Duplicate**（复制）和 **Convert To Block**（转换为区块）功能，后者会将版块复制为一个新的[可复用区块](./blocks.md)。

### 元素样式 {#element-styles}

点击任意元素即可打开其样式面板。常用选项包括字号、颜色、对齐方式、外边距和内边距。对于图片，你可以设置替代文字和链接目标。

### 单个版块或元素的样式 {#styles-for-one-section-or-element}

若需要更精细的控制，请在版块或元素设置中打开 **Styles**（样式）面板，然后在 **All**（全部）、**Desktop Only**（仅桌面端）或 **Mobile Only**（仅移动端）下点击 **Add a style**（添加样式）。每项样式只作用于该版块或元素，不会影响页面的其他部分。

:::tip
如果你需要在整个网站范围内应用样式 -- 例如自定义字体或全局颜色 -- 请使用[外观](./appearance.md)设置，而不是在单个页面上编写自定义 CSS。
:::

## 预览页面 {#previewing-your-page}

使用工具栏中的预览控件，检查页面在不同屏幕尺寸下的显示效果：

- **Desktop**（桌面）-- 全宽浏览器视图
- **Mobile**（移动端）-- 手机尺寸的窄视图

在手机上，除非你在行的设置中为其指定了 **Mobile Width**（移动端宽度），否则行中的各列会以全宽纵向堆叠显示。在手机上，讲道和播客列表也会将每集的文字堆叠在缩略图下方。

若要以访客看到的方式查看在线页面，请返回页面列表并点击页面的路径，它会在新的浏览器标签页中打开。

## 检查无障碍 {#checking-accessibility}

点击工具栏中的 **Check accessibility**（检查无障碍）图标（发现问题时会显示数量），即可快速检查常见问题 -- 例如缺少替代文字的图片、颜色对比度不足或标题顺序错误。每个问题都会直接链接到需要处理的元素，方便你就地修复。

## 撤销更改 {#undoing-changes}

编辑器会自动记录你的编辑历史。使用工具栏按钮或键盘快捷键即可进行导航：

- **Undo**（撤销）（Ctrl+Z / Cmd+Z）-- 撤回你的上一步操作
- **Redo**（重做）（Ctrl+Shift+Z 或 Ctrl+Y / Cmd+Shift+Z）-- 重新执行已撤销的操作

你也可以跳转到较早的某个时间点。打开工具栏中的 **More**（更多）（⋮）菜单，然后点击 **View history**（查看历史）。**Edit History**（编辑历史）对话框会列出每项更改及其时间，并将你当前所处的位置标记为 **(current)**（当前）。点击某个条目（或其 **Restore to this point**（恢复到此时间点）按钮），即可将页面恢复到该时间点的状态。

:::info
在你所恢复的时间点之后所做的更改仍会保留在历史记录中，因此你可以使用 **Redo** 或选择较晚的条目再次前进。一旦你进行了新的编辑，这些较晚的条目就会被新编辑所替代。
:::

## 保存与发布 {#saving-and-publishing}

你的更改会在编辑过程中自动保存。工具栏中的状态指示器会显示你的更改是否已保存。

### 草稿与发布状态 {#draft-and-published-state}

页面可以具有**已发布**状态，该状态决定访客何时能看到你的更改。工具栏会显示一个状态标签，指示当前状态：

- **Live on save**（保存即上线）-- 页面未使用发布流程。每次保存的更改都会立即上线。这是新页面的默认设置。
- **Unpublished changes**（有未发布的更改）-- 页面此前已发布过，但你在上次发布之后又做了更改。访客仍会看到此前已发布的版本。
- **Published**（已发布）-- 页面已上线，你保存的内容与访客所看到的内容一致。

若要发布你的更改，请点击工具栏中的 **Publish**（发布）按钮。页面会立即上线。

若要恢复到上次已发布的版本，同时不影响访客所看到的内容，请打开更多菜单（⋮），然后点击 **Discard unpublished changes**（放弃未发布的更改）。

若要停止使用发布流程，请打开更多菜单，然后点击 **Turn off publishing**（关闭发布功能）。此后，编辑内容会再次立即上线。

:::tip
当你希望提前准备某个页面（例如为即将举行的活动准备页面），并只在恰当的时机让其上线时，请使用草稿/发布流程。先构建并预览页面，准备就绪后再点击 Publish。
:::
