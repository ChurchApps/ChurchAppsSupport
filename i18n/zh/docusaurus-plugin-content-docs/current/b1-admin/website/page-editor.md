# 使用页面编辑器

<div class="article-intro">

B1 页面编辑器是一款可视化的拖放式构建工具，让您无需编写任何代码即可设计教会网站页面。您可以添加区块和内容模块、自定义样式、预览作品并撤销更改——所有操作都在浏览器中完成。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 完成[初始设置](initial-setup)，配置您的网站
- 在[管理页面](managing-pages)中至少创建一个页面
- 您需要 **content.edit** 权限才能访问编辑器

</div>

## 打开编辑器

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **网站**，然后点击 **页面**。
2. 在页面表格中找到您要编辑的页面，然后点击 **编辑内容**。

编辑器将以全屏模式打开。左侧面板显示页面结构和可用的内容元素；中间区域显示页面的实时预览。

:::info
编辑器始终以浅色模式显示，不受 B1 Admin 主题设置的影响，并使用您在[外观](appearance)中选择的标题和正文字体。这样可确保预览与网站访客看到的页面效果一致。
:::

## 页面结构：区块和元素

每个页面由两个层级构成：

- **区块** -- 顶层容器，将页面划分为水平的条带（例如英雄区块、内容区块或页脚条带）。每个页面在添加内容之前都必须至少有一个区块。
- **元素** -- 放置在区块内的单个内容，例如文本、图片、按钮、卡片、表单和日历。

### 添加区块

1. 点击 **添加区块**（或左侧面板顶部的 **+** 按钮）。
2. 选择开始方式：
   - **从模板创建** -- 按类别（英雄区、关于、服务、奉献等）浏览区块模板库，点击一个模板即可插入一个已完整设置样式、预先填充内容的区块。添加后您可以随意自定义。
   - **空白区块** -- 选择列布局（单列、两列、三列等），然后从头开始构建。
3. 新区块会出现在预览中。点击它即可选中，并配置其背景颜色、内边距和其他样式选项。

### 切换区块布局

如果您已经构建好某个区块，但想换一种结构？使用该区块上的布局切换器，从库中选择另一种列排列方式，同时保留现有内容和元素。

### 向区块添加元素

1. 在预览中点击区块内部以选中它。
2. 点击 **添加内容**，然后从列表中选择元素类型：
   - **文本** -- 标题、段落和富文本
   - **图片** -- 上传照片或链接到照片
   - **按钮** -- 可点击的行动号召链接
   - **卡片** -- 带标题和描述的图片
   - **表单** -- 直接在页面上嵌入[表单](../forms/creating-forms)
   - **日历** -- 显示活动日历
   - **常见问题** -- 手风琴式的问答模块
   - **视频** -- 通过网址嵌入视频
   - **群组浏览器** -- 教会所有群组的可筛选目录，可选搜索、类别筛选和标签筛选
   - **图标特性** -- 带图标、标题和简短描述，用于突出特色或事工
   - **图库** -- 多张照片的网格或瀑布流布局
   - **见证** -- 一条或多条引言，附带作者姓名、角色和照片
   - **社交图标** -- 指向教会社交媒体资料的链接图标
   - **倒计时** -- 距离某个日期或每周礼拜时间的计时器
   - **统计数据** -- 一排带标签的大号数字（成员数、年数、校区数）
   - **奉献活动进度** -- 奉献活动的实时进度条，显示为某项基金目标已筹集的总额
   - **员工网格** -- 群组成员的照片卡片；该群组必须开启其 **公开名册** 选项
   - **礼拜时间** -- 您各校区的礼拜时间表，自动从考勤设置中提取
   - **讲道** -- 您的讲道库，可选完整浏览器，或网格、列表、精选最新等布局
   - **地图** -- 以教会地址为中心的嵌入式地图
   - **表格** -- 用于表格内容的简单行列网格
   - **图文** -- 文字与图片并排显示
   - **标志** -- 您的教会标志，取自[外观](appearance)
   - **直播** -- 直接嵌入页面的直播播放器
   - **播客** -- 显示您提供的外部播客 RSS 订阅源中的单集列表，可设置显示的单集数量，以及是否显示日期和描述。此功能用于在您的网站上推荐任何播客订阅源；如需将您自己的讲道发布为播客，请参见[管理讲道](../sermons/managing-sermons.md#your-podcast-feed)。
   - **奉献** -- 奉献按钮或嵌入式奉献表单
   - **HTML** -- 您自己的原始 HTML，供高级用途使用，例如嵌入第三方小组件（参见[使用 HTML 元素](#using-the-html-element)）
   - **iFrame** -- 通过网址嵌入外部内容
3. 使用出现的设置面板配置元素。

### 使用 HTML 元素 {#using-the-html-element}

**HTML** 元素有两个文本框：

- **HTML 内容** -- 要在页面上显示的标记。您在此处添加的任何 `<script>` 标签都会在您的线上网站上运行。
- **JavaScript（不含 script 标签）** -- 页面加载时运行的脚本代码。您也可以将供应商的嵌入代码片段（包括其 `<script>` 标签）粘贴到此处，它同样会在线上网站上运行。

如果您只在 JavaScript 文本框中粘贴网址（例如图片链接），文本框会变红并显示警告 *"这是网址，不是 JavaScript。"* 该文本框中的单独网址不会产生任何效果。若要显示图片，请使用 **图片** 元素，或将 `<img src="...">` 放入 **HTML 内容** 中。

### 使用日历元素 {#using-the-calendar-element}

**日历** 元素显示您某个日历中的活动：

1. 在 **选择** 下，选择 **群组日历**（某一个群组的活动——列表中显示您所属的群组）或 **精选日历**（您在 **日历** 下构建的日历；参见[精选日历](../calendars/curated-calendar)）。
2. 在 **选择日历** 下，选择群组或日历。
3. 在 **显示方式** 下，选择显示方式：
   - **月历** -- 访客可以翻页浏览的月份网格。
   - **即将举行的活动** -- 以网格磁贴显示接下来的 12 个活动，重复性活动仅显示其下一次日期。每个磁贴显示活动图片（若无图片，则显示主题深色背景上的标题）、日期徽标、星期和时间，以及描述的第一行。活动磁贴上方的 **订阅** 按钮允许访客复制该日历的 ICS 链接或下载该日历。
4. 若只显示部分活动，请在 **仅显示带有标签的活动** 中输入标签，例如 `youth`。只有 **标签** 包含该词的活动才会显示。留空则显示所有活动。标签在每个活动上设置；参见[添加和编辑活动](../calendars/creating-calendars.md#adding-and-editing-events)。

在任一显示方式下，点击活动都会打开其在您网站上的专属页面。活动页面显示活动图片、标题、日期和时间以及描述，并包含一个方框，内有 **时间**（包括重复性活动的重复模式）和 **地点**（为该活动预订的房间）。当开启报名功能时，页面上还会出现 **报名参加此活动** 按钮；**添加到我的日历** 链接可将活动下载为日历文件。该页面经过设置，搜索引擎可在搜索结果中显示活动的日期和详细信息。

### 重新排列内容

拖动区块或元素，使用每个项目左侧的拖动手柄（六个点）即可重新排序。您可以在区块内拖动元素，也可以将元素移动到其他区块。

## 设置页面样式

### 区块样式

点击任意区块即可打开其样式面板。您可以设置：

- **背景** -- 纯色、渐变或图片。使用图片背景时，**焦点** 选择器可让您点击设置图片中在区块缩放时保持居中的部分；**遮罩** 颜色选项可在图片上添加半透明色调，以提高文字的可读性。
- **内边距** -- 区块内部的上下间距
- **宽度** -- 全宽或居中/容器宽度
- **分隔线** -- 位于区块顶部或底部边缘的装饰性形状分隔线（波浪、斜线、曲线、三角形等），可设置颜色、高度和翻转选项

### 元素样式

点击任意元素即可打开其样式面板。常用选项包括字体大小、颜色、对齐方式、外边距和内边距。对于图片，您可以设置替代文本和链接目标。

### 自定义 CSS

若需要进行高级样式设置，每个区块和元素都有一个 **自定义 CSS** 字段，您可以在其中编写自己的 CSS 规则。这些规则仅作用于该元素，不会意外影响页面的其他部分。

:::tip
如果您需要对整个网站应用样式——例如自定义字体或全局颜色——请使用[外观](appearance)设置，而不是在单个页面上使用自定义 CSS。
:::

## 预览页面

使用工具栏中的预览控件，查看页面在不同屏幕尺寸下的显示效果：

- **桌面** -- 全宽浏览器视图
- **移动端** -- 窄幅手机尺寸视图

若要查看访客实际看到的线上页面，请返回页面列表，然后点击该页面的路径。它将在新的浏览器标签页中打开。

## 检查无障碍性

点击工具栏中的 **无障碍** 图标，运行快速检查，以发现常见问题——例如图片缺少替代文本、颜色对比度低或标题顺序错误。每个问题都会直接链接到需要关注的元素，方便您就地修复。

## 撤销更改

编辑器会自动记录您的编辑历史。使用工具栏按钮或键盘快捷键进行导航：

- **撤销**（Ctrl+Z / Cmd+Z）-- 撤销上一步操作
- **重做**（Ctrl+Shift+Z 或 Ctrl+Y / Cmd+Shift+Z）-- 重新执行已撤销的操作

您还可以将页面恢复到之前的快照。点击工具栏中的 **查看历史记录**，即可看到带描述的已保存快照列表，点击任意条目即可恢复到该时间点。

:::warning
恢复快照会用快照版本替换您当前的页面内容。此操作无法通过标准的撤销按钮撤销。如果您希望保留返回的选项，请在恢复旧快照之前先保存当前状态的快照。
:::

## 保存和发布

更改会在您编辑时自动保存。工具栏中的状态指示器会显示您的更改是否已保存。

### 草稿和已发布状态

页面可以具有 **已发布** 状态，用于控制访客何时看到您的更改。工具栏会显示一个状态标签，指示当前状态：

- **保存即上线** -- 页面不使用发布流程。每次保存的更改都会立即上线。这是新页面的默认设置。
- **未发布的更改** -- 页面之前已发布过，但自上次发布以来您有新的更改。访客仍会看到之前已发布的版本。
- **已发布** -- 页面已上线，您保存的内容与访客看到的内容一致。

若要发布您的更改，请点击工具栏中的 **发布** 按钮。页面将立即上线。

若要恢复到上次发布的版本，同时不影响访客看到的内容，请打开溢出菜单（⋮）并点击 **放弃未发布的更改**。

若要停止使用发布流程，请打开溢出菜单并点击 **关闭发布功能**。之后的编辑将再次立即上线。

:::tip
当您希望准备页面（例如为即将举行的活动准备），并只在恰当的时机让其上线时，请使用草稿/发布流程。先构建并预览页面，准备就绪后再点击发布。
:::
