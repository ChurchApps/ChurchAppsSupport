# 使用页面编辑器

<div class="article-intro">

B1 页面编辑器是一款可视化的拖放式构建工具，让您无需编写任何代码即可设计教会网站页面。您可以添加分区和内容块、自定义样式、预览作品以及撤销更改，所有操作都在浏览器中完成。

</div>

## 打开编辑器

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（位于左上角的搜索栏），展开 **网站**，然后点击 **页面**。
2. 在页面表格中找到您要编辑的页面，然后点击 **编辑内容**。

编辑器以全屏模式打开。左侧面板显示页面结构和可用的内容元素；中间区域显示页面的实时预览。

:::info
无论您的 B1 Admin 主题设置如何，编辑器始终以浅色模式显示，并使用您在[外观](./appearance.md)中选择的标题和正文字体。这可以确保预览与网站访问者看到的页面效果一致。
:::

## 页面结构：分区与元素

每个页面由两个层级构成：

- **分区** —— 将页面划分为水平区块的顶层容器（例如，主视觉区、内容区块或页脚条）。在添加内容之前，每个页面都必须至少有一个分区。
- **元素** —— 放置在分区内的单个内容，例如文本、图片、按钮、卡片、表单和日历。

### 添加分区

1. 点击 **添加分区**（或左侧面板顶部的 **+** 按钮）。
2. 选择起始方式：
   - **从模板添加** —— 浏览按类别（主视觉、关于、服务、奉献等）组织的分区模板库，点击其中一个即可插入一个已完成样式设置并预先填充内容的分区。添加后您可以自由修改所有内容。
   - **空白分区** —— 选择列布局（单列、双列、三列等），然后从零开始构建。
3. 新分区会出现在预览中。点击它以选中，然后设置其背景颜色、内边距和其他样式选项。

### 切换分区布局

如果您已经构建了一个分区，但想要不同的结构？请使用该分区上的布局切换器，从库中选择另一种列排列方式，同时保留现有的内容和元素。

### 为分区添加元素

1. 在预览中点击分区内部以选中它。
2. 点击 **添加内容**，然后从列表中选择元素类型：
   - **文本** —— 标题、段落和富文本
   - **图片** —— 上传照片或链接到照片
   - **按钮** —— 可点击的行动号召链接
   - **卡片** —— 包含图片、标题和说明的卡片
   - **表单** —— 直接在页面上嵌入[表单](../forms/creating-forms.md)。如果表单设有[标题图片](../forms/creating-forms.md#adding-a-header-photo)，它会显示在问题上方
   - **日历** —— 显示活动日历
   - **常见问题** —— 手风琴式的问答区块
   - **视频** —— 通过网址嵌入视频
   - **小组浏览器** —— 所有教会小组的可筛选目录，可选择搜索、类别筛选和标签筛选。其**布局**可以是**网格**（默认）或**滚动（自动）**——请参见[滚动布局](#scrolling-layouts)
   - **小组列表** —— 您公开小组的图块，可选择仅显示带有特定标签的小组。其**布局**可以是**网格**（默认，每行最多三个图块）或**滚动（自动）**——请参见[滚动布局](#scrolling-layouts)
   - **图标特色** —— 带有图标、标题和简短说明的内容，用于突出特色或事工亮点
   - **图库** —— 多张照片的网格或瀑布流布局
   - **见证** —— 一条或多条引言，附带作者姓名、身份和照片
   - **社交图标** —— 指向教会社交媒体资料的链接图标：Facebook、Instagram、WhatsApp、YouTube、X、TikTok、Vimeo 和 Podcast。为每个要显示的平台填写链接；对于 **WhatsApp**，请使用包含您号码的 `https://wa.me/` 链接或群组邀请链接
   - **倒计时** —— 倒数至某个日期或每周礼拜时间的计时器
   - **统计数据** —— 一行带标签的大号数字（会众人数、年数、分堂数）
   - **奉献活动进度** —— 奉献活动的实时进度条，显示为某项基金目标已筹集的总额
   - **服事人员网格** —— 小组成员的照片卡片；该小组必须开启其**公开名册**选项
   - **礼拜时间** —— 您各分堂的礼拜时间表，自动从出席设置中提取
   - **讲道** —— 您的讲道库，可呈现为完整浏览器，或网格、列表或精选最新内容布局
   - **地图** —— 以您教会地址为中心的嵌入式地图
   - **表格** —— 用于表格内容的简单行列网格
   - **文字与图片** —— 文字与图片并排显示
   - **标志** —— 您的教会标志，取自[外观](./appearance.md)
   - **直播** —— 直接嵌入页面的直播播放器
   - **播客** —— 从您提供的外部播客 RSS 订阅网址提取的单集列表，可设置显示的单集数量，以及是否显示日期和描述。在线网站上的每一集都有音频播放器和**下载**链接，可将该集的音频文件以单集标题保存。此功能用于在您的网站上推荐任何播客订阅源；如果要将您自己的讲道发布为播客，请参见[管理讲道](../sermons/managing-sermons.md#your-podcast-feed)
   - **奉献** —— 奉献按钮或嵌入式奉献表单
   - **HTML** —— 您自己的原始 HTML，适用于高级用途，例如嵌入第三方小工具（请参见[使用 HTML 元素](#using-the-html-element)）
   - **iFrame** —— 通过网址嵌入外部内容
3. 使用出现的设置面板配置该元素。

### 使用 HTML 元素

**HTML** 元素有两个文本框：

- **HTML 内容** —— 要在页面上显示的标记。您在此处包含的任何 `<script>` 标签都会在您的在线网站上运行。
- **JavaScript（不含 script 标签）** —— 页面加载时运行的脚本代码。您也可以将供应商的嵌入代码片段（包括其 `<script>` 标签）粘贴到此处，它将在在线网站上运行。

如果您只将网址（例如图片链接）粘贴到 JavaScript 框中，该框会变红，并显示警告*“这是网址，不是 JavaScript。”* 该框中的单纯网址不会产生任何效果。若要显示图片，请使用**图片**元素，或将 `<img src="...">` 放入 **HTML 内容**中。

### 使用日历元素 {#using-the-calendar-element}

**日历**元素显示您某个日历中的活动：

1. 在**选择**下，选择**小组日历**（一个小组的活动——列表中显示您所属的小组）或**精选日历**（您在**日历**下构建的日历；请参见[精选日历](../calendars/curated-calendar.md)）。
2. 在**选择日历**下，选择小组或日历。
3. 在**显示方式**下，选择显示方式：
   - **月历** —— 访问者可以翻页浏览的月份网格。每个活动会按其所属小组着色，因此同一小组的活动在每个日历上都是相同颜色。B1 会自动选择颜色，无需任何设置。
   - **即将举行的活动** —— 下 12 个即将举行活动的图块网格，重复性活动会在其下一次日期显示一次。每个图块显示活动照片（若无照片，则以您主题的深色显示标题）、日期标记、星期和时间，以及说明的第一行。图块上方的**订阅**按钮让访问者复制日历的 ICS 链接或下载该日历。此显示方式下会出现**布局**设置：**网格**（默认）或**滚动（自动）**，后者会将图块排成一行并自动滚动（请参见[滚动布局](#scrolling-layouts)）。对于**精选日历**，请开启**小组标记**设置，以在图块右上角显示每个活动的小组名称，颜色与该小组的日历颜色一致。已归档或保密小组的活动不会显示标记。
4. 若只显示部分活动，请在**仅显示带有以下标签的活动**中输入标签，例如 `youth`。只有**标签**包含该词的活动才会显示。留空则显示所有活动。标签在每个活动上设置；请参见[添加和编辑活动](../calendars/creating-calendars.md#adding-and-editing-events)。

无论哪种显示方式，点击活动都会打开其在您网站上的专属页面。活动页面显示活动照片、标题、日期和时间以及说明，还包括一个方框，其中有**时间**（对于重复性活动，包括重复规律）和**地点**（为该活动预订的房间）。当开启报名功能时，页面还会显示**报名参加此活动**按钮，以及一个**添加到我的日历**链接，可将活动下载为日历文件。该页面经过设置，搜索引擎可以在搜索结果中显示活动的日期和详细信息。在您的页面上显示的精选日历活动页面（针对未来六个月内的活动）也会列在您网站的网站地图中，方便搜索引擎找到它们。

### 滚动布局 {#scrolling-layouts}

**小组浏览器**、**小组列表**以及日历元素的**即将举行的活动**显示方式中的**滚动（自动）**布局，会将图块排成一行，而不是网格。在手机上，每个图块占满整行；在电脑上，两个图块并排显示。当图块数量超过可显示的数量时，该行会：

- 大约每四秒前进一个图块，最后一个之后会回到第一个图块继续播放。
- 当访问者将鼠标悬停、触摸或通过 Tab 键切换到该行时暂停，并在几秒钟后继续。
- 在下方显示一排圆点，每个图块对应一个圆点，当前图块的圆点为实心。访问者可以点击圆点跳转到对应图块。

在设置为减少动态效果的设备上，该行保持静止，访问者可以自行滑动或滚动。如果所有图块都能放得下，该行不会移动，也不会显示圆点。

### 重新排列内容

拖动分区或元素，使用每个项目左侧的拖动手柄（六个点）进行重新排序。您可以在分区内拖动元素，也可以将其移动到其他分区。

## 设置页面样式

### 分区样式

点击任意分区以打开其样式面板。您可以设置：

- **背景** —— 纯色、渐变或图片。使用图片背景时，**焦点**选择器允许您点击设置分区缩放时保持居中的图片部分；**遮罩**颜色选项允许您在图片上添加半透明的色调，以提高文字的可读性。
- **内边距** —— 分区内部的上下间距
- **宽度** —— 全宽，或居中/包含式
- **分隔线** —— 位于分区上边缘或下边缘的装饰性形状分隔线（波浪、斜线、曲线、三角形等），可设置颜色、高度和翻转选项

### 元素样式

点击任意元素以打开其样式面板。常见选项包括字体大小、颜色、对齐方式、外边距和内边距。对于图片，您可以设置替代文字和链接目标。

### 自定义 CSS

对于高级样式设置，每个分区和元素都有一个**自定义 CSS**字段，您可以在其中编写自己的 CSS 规则。这些规则仅作用于该元素，因此不会意外影响页面的其他部分。

:::tip
如果您需要在整个网站上应用样式——例如自定义字体或全局颜色——请使用[外观](./appearance.md)设置，而不是在各个页面上使用自定义 CSS。
:::

## 预览页面

使用工具栏中的预览控件，检查页面在不同屏幕尺寸下的显示效果：

- **桌面** —— 全宽浏览器视图
- **移动端** —— 窄幅手机尺寸视图

在手机上，除非您在行设置中为其设置了**移动端宽度**，否则同一行中的列会以全宽上下堆叠显示。讲道和播客列表在手机上也会将每集的文字堆叠在缩略图下方。

要查看访问者实际看到的在线页面，请返回页面列表并点击该页面的路径。它会在新的浏览器标签页中打开。

## 检查无障碍性

点击工具栏中的**无障碍**图标，快速检查常见问题——例如图片缺少替代文字、颜色对比度过低或标题顺序错误。每个问题都会直接链接到需要关注的元素，方便您就地修复。

## 撤销更改

编辑器会自动记录您的编辑历史。使用工具栏按钮或键盘快捷键进行导航：

- **撤销**（Ctrl+Z / Cmd+Z）—— 撤回您上一步操作
- **重做**（Ctrl+Shift+Z 或 Ctrl+Y / Cmd+Shift+Z）—— 重新应用已撤销的操作

您也可以将页面恢复到较早的快照。点击工具栏中的**查看历史记录**，以查看带有描述的已保存快照列表，然后点击任意条目即可恢复到该时间点。

:::warning
恢复快照会用快照版本替换当前页面内容。标准的撤销按钮无法撤销此操作。如果您希望保留返回的可能性，请在恢复旧快照之前先保存当前状态的快照。
:::

## 保存与发布

更改会在您编辑时自动保存。工具栏中的状态指示器会显示您的更改是否已保存。

### 草稿和已发布状态

页面可以设有**已发布**状态，用于控制访问者何时看到您的更改。工具栏会显示一个状态标签，指示当前状态：

- **保存即上线** —— 页面不使用发布流程。每次保存的更改都会立即上线。这是新页面的默认设置。
- **有未发布的更改** —— 页面之前已发布过，但自上次发布后您又做了更改。访问者仍会看到之前发布的版本。
- **已发布** —— 页面已上线，您保存的内容与访问者看到的内容一致。

要发布更改，请点击工具栏中的**发布**按钮。页面会立即上线。

若要恢复到上次发布的版本而不影响访问者所见内容，请打开溢出菜单（⋮）并点击**放弃未发布的更改**。

若要停止使用发布流程，请打开溢出菜单并点击**关闭发布功能**。此后编辑内容将再次立即上线。

:::tip
当您想要准备页面时（例如为即将举行的活动），请使用草稿/发布流程，并在恰当的时机才让页面上线。先构建并预览页面，准备就绪后再点击发布。
:::
