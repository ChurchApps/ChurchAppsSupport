# 使用页面编辑器

<div class="article-intro">

B1页面编辑器是一个可视化拖放构建器，让您在无需编写任何代码的情况下设计教会网站页面。您可以添加部分和内容块、自定义样式、预览工作成果和撤销更改 -- 所有这些都从您的浏览器中完成。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 完成[初始设置](initial-setup)以获得您的网站配置
- 在[管理页面](managing-pages)中创建至少一个页面
- 您需要**content.edit**权限来访问编辑器

</div>

## 打开编辑器

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**网站**，然后点击**页面**。
2. 在页面表格中找到您想要编辑的页面，然后点击**编辑**。

编辑器在全屏模式下打开。左侧面板显示您的页面结构和可用的内容元素；中央区域显示您页面的实时预览。

:::info
编辑器始终显示为浅色模式，无论您的B1 Admin主题设置如何。这确保预览准确匹配您的页面对网站访问者的显示方式。
:::

## 页面结构：部分和元素

每个页面都建立在两个级别上：

- **部分** -- 将页面分成水平条带的顶级容器（例如英雄部分、内容块或页脚条带）。每个页面必须至少有一个部分，然后才能添加内容。
- **元素** -- 放置在部分内的个别内容片段，例如文本、图像、按钮、卡片、表单和日历。

### 添加部分

1. 点击**添加部分**（或左侧面板顶部的**+**按钮）。
2. 选择如何开始：
   - **从模板** -- 浏览按类别（英雄、关于、服务、捐献等）组织的部分模板库，并点击一个以将其作为完全设置的预填充部分插入。添加后，您可以自定义一切。
   - **空白部分** -- 选择列布局（单、两列、三列等）并从头开始构建。
3. 新部分出现在预览中。点击它以选择它并配置其背景颜色、填充和其他样式选项。

### 切换部分的布局

已经构建了一个部分但想要不同的结构？对该部分使用布局切换器以交换其列排列为来自库的不同的，同时保持您现有的内容和元素。

### 向部分添加元素

1. 在预览中点击部分内部以选择它。
2. 点击**添加内容**并从列表中选择元素类型：
   - **文本** -- 标题、段落和富文本
   - **图像** -- 上传或链接到照片
   - **按钮** -- 可点击的号召行动链接
   - **卡片** -- 带有标题和描述的图像
   - **表单** -- 在页面上直接嵌入[表单](../forms/creating-forms)
   - **日历** -- 显示事件日历
   - **常见问题** -- 手风琴样式的问答块
   - **视频** -- 按URL嵌入视频
   - **组浏览器** -- 所有教会组的可过滤目录，带有可选搜索、类别过滤和标签过滤
   - **图标功能** -- 带有标题和简短描述的图标，用于功能或事工亮点
   - **库** -- 多照片网格或砌体布局
   - **推荐证词** -- 一个或多个带有作者名称、职务和照片的引用
   - **社交图标** -- 链接的图标，用于教会的社交媒体资料
   - **倒计时** -- 倒计时器，计数到日期或每周服务时间
   - **统计数据** -- 一行大数字，带有标签（成员、年份、校区）
   - **活动进度** -- 捐献活动的实时进度栏，显示筹集的总数对照基金目标
   - **员工网格** -- 组成员的照片卡片；该组必须打开其**公开花名册**选项
   - **服务时间** -- 您校区的服务时间表，从出勤设置自动拉取
   - **讲道** -- 您的讲道库，作为完整浏览器或网格、列表或特色最新布局
   - **地图** -- 以教会地址为中心的嵌入地图
   - **表格** -- 用于表格内容的行和列的简单网格
   - **文本和照片** -- 文本和图像并排
   - **Logo** -- 您的教会logo，从[外观](appearance)拉取
   - **实时流** -- 您的实时流播放器，直接嵌入在页面上
   - **播客** -- 从您提供的外部播客RSS源URL拉取的剧集列表，带有设置可显示多少剧集以及是否显示日期和描述。这用于在您的网站上特色任何播客源；要将您自己的讲道发布为播客，请参阅[管理讲道](../sermons/managing-sermons.md#your-podcast-feed)。
   - **捐献** -- 捐献按钮或嵌入捐献表单
   - **原始HTML** -- 用于高级用例的自定义HTML标记
   - **iFrame** -- 按URL嵌入外部内容
3. 使用出现的设置面板配置元素。

### 重新排序内容

使用每个项目左侧的手柄图标（六个点）拖动部分或元素以重新排序它们。您可以在部分内拖动元素或在部分之间移动它们。

## 设置页面样式

### 部分样式

点击任何部分打开其样式面板。您可以设置：

- **背景** -- 纯色、渐变或图像。使用图像背景时，**焦点**选择器让您点击设置当部分缩放时图像的哪部分保持居中，**叠加**颜色选项让您在图像上添加半透明的色调以改进文本可读性。
- **填充** -- 部分内的上下间距
- **宽度** -- 全宽或居中/包含
- **分隔符** -- 装饰形状分隔符（波浪、倾斜、曲线、三角形等）在部分的顶部或底部边缘，带有颜色、高度和翻转选项

### 元素样式

点击任何元素打开其样式面板。常见选项包括字体大小、颜色、对齐、边距和填充。对于图像，您可以设置替代文本和链接目标。

### 自定义CSS

对于高级样式，每个部分和元素都有一个**自定义CSS**字段，您可以在其中编写自己的CSS规则。这些作用于该元素，所以它们不会意外影响页面的其余部分。

:::tip
如果您需要在整个网站应用样式 -- 如自定义字体或全局颜色 -- 使用[外观](appearance)设置而不是单个页面上的自定义CSS。
:::

## 预览您的页面

使用工具栏中的预览控件检查您的页面在不同屏幕大小下的显示方式：

- **桌面** -- 全宽浏览器视图
- **移动** -- 狭窄手机大小的视图

点击**预览**在新浏览器标签中打开页面的实时版本，正如访问者将看到的一样。

## 检查可访问性

点击工具栏中的**可访问性**图标以快速检查常见问题 -- 图像缺少替代文本、颜色对比度低或标题顺序不对。每个问题直接链接到需要注意的元素，以便您可以就地修复它。

## 撤销更改

编辑器自动跟踪您的编辑历史。使用工具栏按钮或键盘快捷键导航：

- **撤销**（Ctrl+Z / Cmd+Z）-- 恢复您的上一个操作
- **重做**（Ctrl+Y / Cmd+Y）-- 重新应用一个未完成的操作

您也可以将页面恢复到之前的快照。点击工具栏中的**历史**查看带有描述的已保存快照列表，然后点击任何条目恢复到该点。

:::warning
恢复快照用快照版本替换您当前的页面内容。这不能用标准撤销按钮撤销。如果您想要保留返回的选项，在恢复旧快照前保存您当前状态的快照。
:::

## 保存和发布

更改自动保存，当您工作时。工具栏中的状态指示器显示您的更改是否已保存。

### 草稿和已发布状态

页面可以有**已发布**状态，这控制访问者何时看到您的更改。工具栏显示一个状态芯片，显示当前状态：

- **保存时上线** -- 页面不使用发布工作流。每个保存的更改立即上线。这是新页面的默认值。
- **未发布更改** -- 页面之前已发布，但您已在上次发布后做出更改。访问者仍然看到之前已发布的版本。
- **已发布** -- 页面在线，您的保存的内容匹配访问者看到的内容。

要发布您的更改，点击工具栏中的**发布**按钮。页面立即上线。

要在不影响访问者看到的内容的情况下恢复到上次发布的版本，打开溢出菜单（⋮）并点击**放弃更改**。

要完全脱机一个页面，打开溢出菜单并点击**取消发布**。访问者将不再看到该页面，直到您再次发布它。

:::tip
当您想要准备页面时使用草稿/发布工作流 -- 例如，对于即将举行的事件 -- 并仅在正确的时刻将其上线。构建和预览页面，然后在您准备好时点击发布。
:::
