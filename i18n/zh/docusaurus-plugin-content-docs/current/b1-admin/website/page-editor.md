# 使用页面编辑器

<div class="article-intro">

B1 页面编辑器是一个可视化的拖放式构建工具，无需编写任何代码即可设计教会网站页面。你可以在浏览器中添加区块和内容模块、自定义样式、预览作品，并撤销更改。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 完成[初始设置](initial-setup)，配置好你的网站
- 在[管理页面](managing-pages)中至少创建一个页面
- 你需要拥有 **content.edit** 权限才能访问编辑器

</div>

## 打开编辑器

1. 在 B1 Admin 中，打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **Website**，然后点击 **Pages**。
2. 在页面表格中找到你要编辑的页面，然后点击 **Edit Content**（编辑内容）。

编辑器会以全屏模式打开。左侧面板显示页面结构和可用的内容元素；中间区域则是页面的实时预览。

:::info
无论你的 B1 Admin 主题设置如何，编辑器始终以浅色模式显示，并使用你在[外观](appearance)中选择的标题和正文字体。这样可以确保预览与访客看到的页面效果准确一致。
:::

## 页面结构：区块与元素

每个页面都由两个层级构成：

- **区块（Sections）** —— 最顶层的容器，将页面划分为水平的板块（例如首图区块、内容区块或页脚条）。每个页面在添加内容之前，都必须至少有一个区块。
- **元素（Elements）** —— 放置在区块内的单个内容模块，例如文本、图片、按钮、卡片、表单和日历。

### 添加区块

1. 点击 **Add Section**（添加区块）（或左侧面板顶部的 **+** 按钮）。
2. 选择开始方式：
   - **From a template**（从模板）—— 浏览按类别（Hero、About、Services、Giving 等）组织的区块模板库，点击其中一个即可插入一个已设置好样式、预先填充内容的区块。添加之后，你可以自定义所有内容。
   - **Blank section**（空白区块）—— 选择列布局（单列、双列、三列等），然后从零开始构建。
3. 新区块会出现在预览中。点击它即可选中，并配置其背景颜色、内边距和其他样式选项。

### 切换区块布局

如果你已经搭建好某个区块，但想要不同的结构，可以使用该区块上的布局切换器，从库中选择另一种列排列方式，同时保留现有的内容和元素。

### 向区块添加元素

1. 在预览中点击区块内部，将其选中。
2. 点击 **Add Content**（添加内容），然后从列表中选择一种元素类型：
   - **Text**（文本）—— 标题、段落和富文本
   - **Image**（图片）—— 上传照片或链接到照片
   - **Button**（按钮）—— 可点击的行动号召链接
   - **Card**（卡片）—— 带有标题和描述的图片
   - **Form**（表单）—— 直接在页面上嵌入[表单](../forms/creating-forms)。如果表单设有[页眉照片](../forms/creating-forms.md#adding-a-header-photo)，它会显示在问题上方
   - **Calendar**（日历）—— 显示活动日历
   - **FAQ**（常见问题）—— 手风琴样式的问答模块
   - **Video**（视频）—— 通过网址嵌入视频
   - **Groups Browser**（小组浏览器）—— 所有教会小组的可筛选目录，可选择搜索、分类筛选和标签筛选
   - **Icon Feature**（图标特色）—— 带有标题和简短描述的图标，用于突出特色或事工
   - **Gallery**（图库）—— 多张照片的网格或瀑布流布局
   - **Testimonial**（见证）—— 一条或多条引文，附带作者姓名、角色和照片
   - **Social Icons**（社交图标）—— 指向教会社交媒体主页的链接图标：Facebook、Instagram、WhatsApp、YouTube、X、TikTok、Vimeo 和 Podcast。为每个要显示的图标填写链接；对于 **WhatsApp**，请使用 `https://wa.me/` 链接加上你的号码，或使用群组邀请链接
   - **Countdown**（倒计时）—— 距离某个日期或每周礼拜时间的计时器
   - **Stats**（统计）—— 一排带有标签的大号数字（会友人数、年数、校区数）
   - **Campaign Progress**（筹款进度）—— 奉献活动的实时进度条，显示为某个基金目标已筹集的总额
   - **Staff Grid**（员工网格）—— 小组成员的照片卡片；该小组必须开启**公开名单**选项
   - **Service Times**（礼拜时间）—— 你各校区的礼拜时间表，自动从出勤设置中提取
   - **Sermons**（讲道）—— 你的讲道库，可显示为完整浏览器，或以网格、列表或精选最新的布局显示
   - **Map**（地图）—— 以教会地址为中心的嵌入式地图
   - **Table**（表格）—— 用于表格内容的简单行列网格
   - **Text with Photo**（图文）—— 文本与图片并排显示
   - **Logo**（标志）—— 你的教会标志，取自[外观](appearance)
   - **Live Stream**（直播）—— 直接嵌入页面的直播播放器
   - **Podcast**（播客）—— 从你提供的外部播客 RSS 订阅源网址中提取的节目列表，可设置显示的节目数量，以及是否显示日期和描述。在线网站上的每个节目都有音频播放器和 **Download**（下载）链接，可将节目音频文件以节目标题保存。此功能用于在你的网站上推荐任何播客订阅源；若要将自己的讲道发布为播客，请参阅[管理讲道](../sermons/managing-sermons.md#your-podcast-feed)。
   - **Donation**（奉献）—— 奉献按钮或嵌入式奉献表单
   - **HTML** —— 你自己的原始 HTML，适用于高级用途，例如嵌入第三方小组件（参见[使用 HTML 元素](#using-the-html-element)）
   - **iFrame** —— 通过网址嵌入外部内容
3. 使用出现的设置面板配置该元素。

### 使用 HTML 元素 {#using-the-html-element}

**HTML** 元素有两个文本框：

- **HTML Content**（HTML 内容）—— 要在页面上显示的标记。你在此处包含的任何 `<script>` 标签都会在你的线上网站上运行。
- **JavaScript (exclude script tag)**（JavaScript（不包括 script 标签））—— 页面加载时运行的脚本代码。你也可以在此粘贴供应商的嵌入代码片段（包括其 `<script>` 标签），它同样会在线上网站运行。

如果你只在 JavaScript 框中粘贴了网址（例如图片链接），该框会变红，并显示警告 *"This is a web address, not JavaScript."*（这是网址，不是 JavaScript。）。在该框中只放置一个网址不会产生任何作用。若要显示图片，请使用 **Image** 元素，或在 **HTML Content** 中放置 `<img src="...">`。

### 使用日历元素 {#using-the-calendar-element}

**Calendar**（日历）元素会显示你某个日历中的活动：

1. 在 **Select**（选择）下，选择 **Group Calendar**（小组日历）（某个小组的活动——列表中显示你所属的小组）或 **Curated Calendar**（精选日历）（你在 **Calendars** 下创建的日历；参见[精选日历](../calendars/curated-calendar)）。
2. 在 **Select Calendar**（选择日历）下，选择小组或日历。
3. 在 **Display**（显示）下，选择显示方式：
   - **Month calendar**（月历）—— 访客可以翻页浏览的月份网格。
   - **Upcoming events**（即将举行的活动）—— 以网格形式显示接下来 12 个即将举行的活动的卡片，重复性活动只在其下一个日期显示一次。每张卡片显示活动照片（若无照片，则以主题深色显示其标题）、日期标记、星期和时间，以及描述的第一行。卡片上方的 **Subscribe**（订阅）按钮允许访客复制或下载该日历的 ICS 链接。此显示方式会提供 **Layout**（布局）设置：**Grid**（网格，默认）或 **Scrolling (automatic)**（滚动（自动）），后者会将卡片排成一行，并自动滚动播放。
4. 若只显示部分活动，请在 **Only events tagged**（仅显示带有以下标签的活动）中输入标签，例如 `youth`。只有 **Tags** 包含该词的活动才会显示。留空则显示所有活动。标签在每个活动上设置；参见[添加和编辑活动](../calendars/creating-calendars.md#adding-and-editing-events)。

无论哪种显示方式，点击某个活动都会打开其在你网站上的专属页面。活动页面会显示活动照片、标题、日期和时间以及描述，并有一个方框，内含 **When**（何时）（对于重复性活动，包括重复模式）和 **Where**（何地）（为其预订的房间）。当开启报名功能时，页面还会显示 **Register for this Event**（报名参加此活动）按钮，以及可将活动下载为日历文件的 **Add to my calendar**（添加到我的日历）链接。该页面经过设置，使搜索引擎能够在搜索结果中显示活动的日期和详情。在你的页面上显示的精选日历中，未来六个月内的活动页面也会列在网站的网站地图中，方便搜索引擎找到它们。

### 重新排序内容

拖动每个项目左侧的把手图标（六个点）即可重新排列区块或元素。你可以在区块内拖动元素，也可以将元素移动到其他区块。

## 设置页面样式

### 区块样式

点击任意区块，即可打开其样式面板。你可以设置：

- **Background**（背景）—— 纯色、渐变或图片。使用图片背景时，**Focal Point**（焦点）选择器允许你点击以设置在区块缩放时保持居中的图片部分；**Overlay**（遮罩）颜色选项则可在图片上添加半透明的色调，以提高文字的可读性。
- **Padding**（内边距）—— 区块内部的上下间距
- **Width**（宽度）—— 全宽，或居中/限定宽度
- **Dividers**（分隔线）—— 位于区块上边缘或下边缘的装饰性形状分隔线（波浪、斜线、曲线、三角形等），可设置颜色、高度和翻转选项

### 元素样式

点击任意元素，即可打开其样式面板。常见选项包括字体大小、颜色、对齐方式、外边距和内边距。对于图片，你可以设置替代文字和链接目标。

### 自定义 CSS

对于高级样式设置，每个区块和元素都有一个 **Custom CSS**（自定义 CSS）字段，你可以在其中编写自己的 CSS 规则。这些规则的作用范围仅限于该元素，因此不会无意中影响页面的其他部分。

:::tip
如果你需要在整个网站上应用样式——例如自定义字体或全局颜色——请使用[外观](appearance)设置，而不是在单个页面上使用自定义 CSS。
:::

## 预览页面

使用工具栏中的预览控件，检查页面在不同屏幕尺寸下的效果：

- **Desktop**（桌面）—— 全宽浏览器视图
- **Mobile**（移动端）—— 手机尺寸的窄视图

在手机上，除非你在行设置中为列设置了 **Mobile Width**（移动端宽度），否则一行中的各列会以全宽上下堆叠显示。讲道和播客列表在手机上也会将每集的文字堆叠在缩略图下方。

要以访客看到的方式查看线上页面，请返回页面列表，然后点击该页面的路径。它会在新的浏览器标签页中打开。

## 检查无障碍设计

点击工具栏中的 **Accessibility**（无障碍）图标，即可快速检查常见问题——例如缺少替代文字的图片、颜色对比度不足，或标题层级混乱。每个问题都会直接链接到需要注意的元素，方便你就地修复。

## 撤销更改

编辑器会自动记录你的编辑历史。使用工具栏按钮或键盘快捷键进行操作：

- **Undo**（撤销）（Ctrl+Z / Cmd+Z）—— 撤回你上一步的操作
- **Redo**（重做）（Ctrl+Shift+Z 或 Ctrl+Y / Cmd+Shift+Z）—— 重新应用已撤销的操作

你也可以将页面恢复到较早的快照。点击工具栏中的 **View history**（查看历史），即可看到带有描述的已保存快照列表，点击任意条目即可恢复到该时间点。

:::warning
恢复快照会用快照版本替换当前页面内容。标准的撤销按钮无法撤销此操作。如果你希望保留返回的选项，请在恢复旧快照之前，先保存当前状态的快照。
:::

## 保存与发布

你在编辑时，更改会自动保存。工具栏中的状态指示器会显示你的更改是否已保存。

### 草稿与已发布状态

页面可以设有**已发布**状态，用于控制访客何时看到你的更改。工具栏会显示一个状态标签，指示当前状态：

- **Live on save**（保存即上线）—— 页面不使用发布工作流。每次保存的更改都会立即上线。这是新页面的默认设置。
- **Unpublished changes**（未发布的更改）—— 该页面之前已经发布过，但自上次发布以来你又做了更改。访客仍会看到之前已发布的版本。
- **Published**（已发布）—— 页面已上线，你保存的内容与访客所看到的一致。

要发布更改，请点击工具栏中的 **Publish**（发布）按钮。页面会立即上线。

若要恢复到上次发布的版本，同时不影响访客所看到的内容，请打开溢出菜单（⋮），然后点击 **Discard unpublished changes**（放弃未发布的更改）。

若要停止使用发布工作流，请打开溢出菜单，然后点击 **Turn off publishing**（关闭发布功能）。之后，编辑内容将再次立即上线。

:::tip
当你希望提前准备好页面——例如为即将到来的活动准备——并只在恰当的时刻才让其上线时，请使用草稿/发布工作流。先构建并预览页面，准备就绪后再点击 Publish。
:::
