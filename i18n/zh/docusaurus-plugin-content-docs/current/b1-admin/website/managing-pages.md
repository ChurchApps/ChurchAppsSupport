# 管理页面

<div class="article-intro">

网站页面视图是您创建、编辑和组织教会网站所有页面的中心枢纽。您可以在这一个界面中同时管理页面内容和网站导航。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 完成[初始设置](initial-setup)以配置您的域名和基本网站设置
- 准备好内容和图片。请先使用[文件](files)管理器上传媒体资源。

</div>

:::info
如果您的教会拥有多个网站(例如各园区分别建站),可以使用网站页面视图顶部的站点切换器在不同网站之间切换。每个网站都有自己独立的页面、导航和[外观](appearance)设置。
:::

## 了解页面类型

**页面**表列出网站上的每一个页面及其状态:

- **自动生成**——由系统根据您教会的数据自动创建的页面(例如小组页面、讲道页面,或曲库中每篇讲道各自的页面)。这些页面会随着您数据的变化而自动更新。
- **自定义**——您自己创建、拥有独立内容和布局的页面。

如果您想完全掌控某个自动生成页面的内容和设计,可以将其转换为自定义页面。

## 添加和编辑页面

1. 点击"页面"表右上角的**添加页面**按钮。
2. 选择页面类型(空白页或模板)并为其命名。
3. 点击任意页面旁的**编辑**,打开[页面编辑器](page-editor),在其中添加区块、文字、图片等元素。
4. 点击**页面设置**以更新页面标题、URL 路径及其他元数据。
5. 使用**预览**按钮在新窗口中打开页面,查看访客将看到的实际效果。

:::tip
对于您的主页,请将 URL 路径设置为 `/`。对于其他所有页面,请使用有描述性的路径,例如 `/about` 或 `/contact`。
:::

### 页面设置

在任意页面上打开**页面设置**以配置:

- **标题与 URL 路径**——页面名称及其在网站上的地址。
- **可见性**——选择谁可以看到该页面:所有人、仅限成员、仅限员工,或特定小组成员。这是一种在不使用单独密码的情况下,快速限制访问私密页面(如员工资源页)的方式。
- **元描述**——在搜索引擎结果和社交媒体链接预览中显示的简短摘要。
- **重定向**——将旧的 URL 路径指向此页面,让指向已下线页面的链接和书签继续有效。

## 管理导航

网站页面视图的左侧边栏显示您的导航链接。这些链接控制访客在您网站上看到的菜单。

1. 点击**添加**创建新的导航链接。您可以将其指向网站上的任意页面,或指向外部网址。
2. 若要调整链接顺序,可将其拖放到您想要的位置。您也可以将链接嵌套在父级项目下,以创建下拉菜单。
3. 点击任意链接旁的**编辑**图标以更改其标签、URL 或位置。
4. 若要从导航中移除某个链接,点击**删除**图标。

:::info
移除导航链接并不会删除该页面本身。该页面依然存在,仍可通过其 URL 直接访问——只是不会再出现在菜单中。
:::

## 组织网站的技巧

- 将顶层导航控制在五到六项以内,方便访客快速找到内容。
- 对相关的子页面使用嵌套链接(例如,一个"关于我们"下拉菜单包含"我们的团队""信仰告白"和"历史沿革")。
- 点击**移动预览**在移动端查看您的导航,确保在小屏幕上也能正常工作。
- 为页面取清晰、有描述性的名称,帮助访客理解将会看到什么内容。

:::tip
您可以在页面上添加[表单](../forms/creating-forms.md),用于收集访客的报名信息、代祷请求或其他信息。
:::

## 从网站模板开始

如果您想从零开始搭建网站,可以使用**网站模板**来引导启动,而不必逐个创建页面。网站模板会创建一组预先构建好的页面——首页、关于我们、联系方式、奉献等等——并已配好占位内容和导航链接。

1. 在页面界面中,点击(**添加页面**按钮旁的)**网站模板**按钮。
2. 浏览可用的模板,点击某个模板可预览其页面结构。
3. 找到心仪的模板后,点击**应用模板**。
4. 尚不存在的页面会被创建并添加到您的导航中。已存在的页面则保持不变。

应用模板后,请在[页面编辑器](page-editor)中打开每个页面,将占位文字和图片替换为您教会的真实内容。

:::info
网站模板只创建页面结构和导航,不会覆盖网站的配色方案或字体——这些由[外观](appearance)控制。
:::

## 图片灯箱

当访客点击网站上的图片时,图片会在全屏灯箱叠层中打开。这样人们无需离开页面就能以更大尺寸查看照片。无需任何配置——灯箱功能会针对页面内容中的图片自动启用。
