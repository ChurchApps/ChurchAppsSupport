# 管理页面

<div class="article-intro">

网站页面视图是您创建、编辑和组织教会网站上所有页面的中心枢纽。您可以从这个单一屏幕管理您的页面内容和网站导航。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 完成[初始设置](initial-setup)以配置您的域和基本网站设置
- 准备好您的内容和图像。使用[文件](files)管理器先上传媒体资产。

</div>

:::info
如果您的教会有多个网站（例如，按校园分开的网站），请使用网站页面视图顶部的网站切换器在它们之间跳转。每个网站都有自己的页面、导航和[外观](appearance)设置。
:::

## 了解页面类型

**页面**表格列出您网站上的每个页面及其状态：

- **已生成** -- 由系统根据您的教会数据自动创建的页面（例如，小组页面、讲道页面或库中每个讲道的单独页面）。这些页面随着您的数据更改而自己更新。
- **自定义** -- 您使用自己的内容和布局创建的页面。

您可以将任何自动生成的页面转换为自定义页面，如果您想完全控制其内容和设计。

## 添加和编辑页面

1. 单击页面表格右上角的**添加页面**按钮。
2. 选择页面类型（空白或模板）并给它一个名称。
3. 单击任何页面旁的**编辑**以打开[页面编辑器](page-editor)，您可以在其中添加部分、文本、图像和其他元素。
4. 单击**页面设置**以更新页面标题、URL 路径和其他元数据。
5. 使用**预览**按钮在新窗口中打开您的页面，以准确查看访客将如何看到它。

:::tip
对于您的首页，将 URL 路径设置为仅 `/`。对于所有其他页面，使用描述性路径，如 `/about` 或 `/contact`。
:::

### 页面设置

在任何页面上打开**页面设置**以配置：

- **标题和 URL 路径** -- 页面名称和其在您网站上的地址。
- **可见性** -- 选择谁可以看到页面：所有人、仅成员、仅员工或特定小组的成员。这是不需要单独密码就能限制私人页面（如员工资源页面）的快速方式。
- **元描述** -- 搜索引擎结果和社交媒体链接预览中显示的简短摘要。
- **重定向** -- 将旧的 URL 路径指向此页面，以便指向已停用页面的链接和书签继续正常工作。

## 管理导航

网站页面视图显示您的导航链接。这些链接控制访客在您网站上看到的菜单。

1. 单击**添加**以创建新导航链接。您可以将其指向您网站上的任何页面或外部 URL。
2. 要重新排序链接，请拖放它们到您想要的顺序中。您也可以将链接嵌套在父项下以创建下拉菜单。
3. 单击任何链接旁的**编辑**图标以更改其标签、URL 或位置。
4. 要从导航中删除链接，请单击**删除**图标。

:::info
删除导航链接不会删除页面本身。该页面仍然存在并可以通过其 URL 直接访问 -- 它只是不会出现在菜单中。
:::

## 组织网站的提示

- 将您的顶级导航限制为五或六个项目，以便访客可以快速找到东西。
- 使用嵌套链接用于相关子页面（例如，带有 "我们的团队"、"信仰" 和 "历史" 的 "关于" 下拉菜单）。
- 通过单击**移动预览**在移动设备上查看您的导航，以确保它在较小屏幕上运行良好。
- 给页面清晰、描述性的名称，帮助访客理解他们将找到什么。

:::tip
您可以向您的页面添加[表单](../forms/creating-forms.md)以从访客收集注册、祈祷请求或其他信息。
:::

## 从网站模板开始

如果您正在从头开始构建网站，您可以使用**网站模板**来引导它，而不是一次创建一个页面。网站模板创建一组预构建页面 -- 首页、关于、连接、奉献等 -- 具有占位符内容和已连接的导航链接。

1. 在页面屏幕上，单击**网站模板**按钮（在**添加页面**按钮旁）。
2. 浏览可用的模板并单击其中一个以预览其页面结构。
3. 当您找到您喜欢的，单击**应用模板**。
4. 不存在的页面会被创建并添加到您的导航中。现有页面保持原样。

应用模板后，在[页面编辑器](page-editor)中打开每个页面，将占位符文本和图像替换为您教会的真实内容。

:::info
网站模板创建页面结构和导航。它们不会覆盖您网站的颜色方案或字体 -- 这些由[外观](appearance)控制。
:::

## 图像灯箱

当访客点击您网站上的图像时，它会在全屏灯箱覆盖中打开。这让人们可以在较大的尺寸下查看照片，而不会离开页面。不需要配置 -- 灯箱会自动为页面内容中的图像启用。
