# 管理页面

<div class="article-intro">

网站页面视图是创建、编辑和组织教会网站上所有页面的中央枢纽。您可以从这个单一屏幕管理页面内容和网站导航。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 完成[初始设置](initial-setup)以配置您的域和基本网站设置
- 准备好您的内容和图像。使用[文件](files)管理器先上传媒体资源。

</div>

:::info
如果您的教会有多个网站（例如，每个校区单独的网站），使用网站页面视图顶部的网站切换器在它们之间跳转。每个网站有自己的页面、导航和[外观](appearance)设置。
:::

## 理解页面类型

**页面**表格列出网站上每个页面及其状态：

- **生成的** -- 由系统根据教会数据自动创建的页面（例如，组页面、讲道页面或库中每个讲道的单独页面）。这些页面随数据变化而更新自己。
- **自定义** -- 您自己使用自己的内容和布局创建的页面。

您可以将任何自动生成的页面转换为自定义页面，如果您想要完全控制其内容和设计。

## 添加和编辑页面

1. 点击页面表格右上角的**添加页面**按钮。
2. 选择页面类型（空白或模板）并给它起个名字。
3. 点击任何页面旁的**编辑内容**打开[页面编辑器](page-editor)，在那里您可以添加部分、文本、图像和其他元素。
4. 点击**页面设置**（齿轮图标）更新页面标题、URL路径和其他元数据。
5. 使用**查看实时页面**按钮在新窗口中打开您的页面，看到它对访问者的确切样子。

:::tip
对于首页，设置URL路径为只是`/`。对于所有其他页面，使用描述性路径如`/about`或`/contact`。
:::

### 页面设置

在任何页面上打开**页面设置**以配置：

- **标题和URL路径** -- 页面名称和其在网站上的地址。
- **可见性** -- 选择谁可以看到页面：所有人、仅成员、仅员工或特定组的成员。这是一个快速的方式来控制私人页面（如员工资源页面），无需单独密码。
- **元描述** -- 搜索引擎结果和社交媒体链接预览中显示的简短摘要。
- **重定向** -- 将旧URL路径指向此页面，以便指向已停用页面的链接和书签继续工作。

## 管理导航

网站页面视图显示您的导航链接。这些链接控制访问者在您的网站上看到的菜单。

1. 点击**添加**创建新的导航链接。您可以将其指向网站上的任何页面或外部URL。
2. 要重新排序链接，拖放它们到您想要的顺序。您也可以将链接嵌套在父项下以创建下拉菜单。
3. 点击任何链接旁的**编辑**图标以更改其标签、URL或位置。
4. 要从导航中删除链接，点击**删除**图标。

:::info
删除导航链接不会删除页面本身。页面仍然存在，可以通过其URL直接访问 -- 它只是不会出现在菜单中。
:::

## 网站范围切换器

在网站页面视图左侧**主导航**上方有两个适用于整个教会网站的切换器：

- **显示登录** -- 在您网站的导航栏中显示**登录**按钮。
- **禁用公共网站** -- 关闭您的公共网站。如果您的教会仅使用B1进行成员门户、捐献和注册，而将其主网站放在其他地方，请使用它。

### 禁用公共网站的作用

当**禁用公共网站**打开时：

- 每个公共页面，包括首页和您的自定义页面，将未签入的访问者发送到登录屏幕。签入后，他们返回到他们要求的页面。
- 已签入的成员看到完整的网站，如往常一样，包括您的导航和内置的**生成的**页面（如组和讲道）。生成的页面不再出现在页面表格中。
- 搜索引擎被告知不要索引该网站。站点地图为空，`robots.txt`阻止所有爬虫。

这些链接保持工作，所以成员和访客仍然可以访问它们：

- 登录和登出
- 成员门户（`/mobile`下的所有内容）
- [活动注册](../guides/event-registration.md)链接和访客注册

当公共网站关闭时，交换机下方会出现警告。再次关闭交换机以恢复您的页面。网站禁用时不会删除任何内容。

:::info
此设置应用于整个教会。如果您有多个网站，它会关闭所有网站，而不仅仅是网站切换器中选定的网站。
:::

## 组织网站的提示

- 将顶级导航保持在五到六个项目，以便访问者可以快速找到内容。
- 对相关的子页面使用嵌套链接（例如，一个包含"我们的团队"、"信念"和"历史"的"关于"下拉菜单）。
- 通过点击**移动预览**在移动设备上检查导航，以确保它在小屏幕上运行良好。
- 为页面提供清晰、描述性的名称，帮助访问者理解他们将找到什么。

:::tip
您可以向页面添加[表单](../forms/creating-forms.md)以从访问者收集注册、祷告请求或其他信息。
:::

## 从网站模板开始

如果您从头开始构建网站，您可以使用**网站模板**而不是一次创建一个页面来引导它。网站模板创建一组预构建的页面 -- 首页、关于、连接、捐献等 -- 带有占位符内容和已连接的导航链接。

1. 在页面屏幕上，点击**网站模板**按钮（在**添加页面**按钮旁）。
2. 浏览可用的模板并点击一个来预览其页面结构。
3. 当您找到喜欢的时，点击**应用模板**。
4. 不存在的页面被创建并添加到导航。现有页面保持原样。

应用模板后，在[页面编辑器](page-editor)中打开每个页面，用您教会的真实内容替换占位符文本和图像。

:::info
网站模板创建页面结构和导航。它们不覆盖您网站的配色方案或字体 -- 那些由[外观](appearance)控制。
:::

## 图像灯箱

当访问者点击您网站上的图像时，它在全屏灯箱叠加中打开。这让人们可以以更大的尺寸查看照片，而无需离开页面。不需要配置 -- 灯箱自动为您页面内容中的图像启用。
