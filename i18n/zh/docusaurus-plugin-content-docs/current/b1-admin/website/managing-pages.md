# 管理页面

<div class="article-intro">

网站页面视图是您创建、编辑和组织教会网站上所有页面的中央枢纽。您可以从这个单一屏幕管理您的页面内容和网站导航。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 完成[初始设置](initial-setup)以配置域和基本网站设置
- 准备好您的内容和图像。首先使用[文件](files)管理器上传媒体资源。

</div>

:::info
如果您的教会有多个网站（例如，每个校园独立网站），请使用网站页面视图顶部的网站切换器在它们之间跳转。每个网站都有自己的页面、导航和[外观](appearance)设置。
:::

## 理解页面类型

**页面**表列出网站上的每一页及其状态：

- **生成** —— 由系统基于教会数据自动创建的页面（例如，小组页面、讲道页面或库中每次讲道的单个页面）。这些页面在数据更改时自动更新。
- **自定义** —— 您自己创建的具有自己内容和布局的页面。

您可以将任何自动生成的页面转换为自定义页面，以获得对其内容和设计的完全控制。

## 添加和编辑页面

1. 单击页面表右上角的**添加页面**按钮。
2. 选择页面类型（空白或模板）并给它一个名称。
3. 单击任何页面旁边的**编辑内容**以打开[页面编辑器](page-editor)，在那里您可以添加部分、文本、图像和其他元素。
4. 单击**页面设置**（齿轮图标）以更新页面标题、URL 路径和其他元数据。
5. 使用**查看实时页面**按钮在新窗口中打开您的页面，以查看访客如何看到的。

:::tip
对于首页，将 URL 路径设置为仅 `/`。对于所有其他页面，使用描述性路径，如 `/about` 或 `/contact`。
:::

### 页面设置

打开任何页面上的**页面设置**以配置：

- **标题和 URL 路径** —— 页面名称及其在网站上的地址。
- **可见性** —— 选择谁可以看到页面：所有人、仅成员、仅员工或特定小组的成员。这是在不需要单独密码的情况下门控私有页面（如员工资源页面）的快速方法。
- **元描述** —— 搜索引擎结果和社交媒体链接预览中显示的简短摘要。
- **重定向** —— 将旧 URL 路径指向此页面，以便到已退休页面的链接和书签继续有效。

## 管理导航

网站页面视图显示您的导航链接。这些链接控制访客在您的网站上看到的菜单。

1. 单击**添加**以创建新导航链接。您可以将其指向网站上的任何页面或外部 URL。
2. 要重新排序链接，请拖放它们到您想要的顺序。您也可以在父项下嵌套链接以创建下拉菜单。
3. 单击任何链接旁边的**编辑**图标以更改其标签、URL 或位置。
4. 要从导航中删除链接，请单击**删除**图标。

:::info
删除导航链接不会删除页面本身。页面仍然存在并可以通过其 URL 直接访问——它只是不会出现在菜单中。
:::

## 网站范围内的切换

在网站页面视图左侧的**主导航**上方有两个开关适用于整个教会网站：

- **显示登录** —— 在您的网站导航栏中显示**登录**按钮。
- **禁用公共网站** —— 关闭您的公共网站。如果您的教会仅在 B1 中使用献金和注册，并在其他地方保持主网站，请使用它。

### 禁用公共网站的作用

当**禁用公共网站**打开时：

- 每个公开页面，包括首页和您的自定义页面，都会向访客发送登录屏幕。
- 内置的**生成**页面（如小组和讲道）不再被提供，不再出现在页面表中。
- 网站标题仅显示**登录**按钮，没有导航链接。
- 搜索引擎被告知不要索引网站。网站地图为空，`robots.txt` 阻止所有爬取。

这些链接继续有效，所以成员和访客仍然可以访问它们：

- 登录和注销
- 成员门户（`/mobile` 下的所有内容）
- [事件注册](../guides/event-registration.md)链接和访客注册

一个警告显示在开关下，当公共网站关闭时。再次关闭开关以恢复您的页面。网站禁用时不会删除任何内容。

:::info
此设置适用于整个教会。如果您有多个网站，它关闭所有网站，不仅是网站切换器中选定的。
:::

## 组织网站的提示

- 将顶级导航限制在五到六个项目，以便访客能快速找到东西。
- 对相关子页面使用嵌套链接（例如，带有"我们的团队"、"信条"和"历史"的"关于"下拉菜单）。
- 通过单击**移动预览**在移动设备上查看您的导航，以确保它在较小屏幕上运行良好。
- 给页面清晰、描述性的名称，帮助访客理解他们将找到什么。

:::tip
您可以将[表单](../forms/creating-forms.md)添加到页面以收集来自访客的注册、祈祷请求或其他信息。
:::

## 从网站模板开始

如果您从头开始构建网站，您可以使用**网站模板**引导它，而不是逐个创建页面。网站模板创建一组预构建的页面——首页、关于、连接、献金等——具有占位符内容和已连接的导航链接。

1. 在页面屏幕上，单击**网站模板**按钮（在**添加页面**按钮旁边）。
2. 浏览可用的模板并单击一个以预览其页面结构。
3. 当您找到喜欢的，单击**应用模板**。
4. 不存在的页面被创建并添加到导航。现有页面保持原样。

应用模板后，在[页面编辑器](page-editor)中打开每一页，用教会的真实内容替换占位符文本和图像。

:::info
网站模板创建页面结构和导航。它们不会覆盖网站的配色方案或字体——这些由[外观](appearance)控制。
:::

## 图像灯箱

当访客单击您网站上的图像时，它在全屏灯箱覆盖中打开。这让人们以更大的尺寸查看照片，而不会离开页面。不需要配置——灯箱自动为页面内容中的图像启用。
