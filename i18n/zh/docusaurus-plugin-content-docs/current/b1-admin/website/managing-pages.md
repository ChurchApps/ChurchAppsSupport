# 管理页面

<div class="article-intro">

网站页面视图是你创建、编辑和组织教会网站上所有页面的中心。你可以在这一个界面中同时管理页面内容和网站导航。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 完成[初始设置](./initial-setup.md)，配置好域名和基本网站设置
- 准备好你的内容和图片。请先使用[文件](./files.md)管理器上传媒体资源。
- 请使用电脑或平板。网站页面视图和页面编辑器需要至少约 880 像素宽的屏幕；在手机上，你会看到提示，要求切换到更大的屏幕。

</div>

:::info
如果你的教会有多个网站（例如每个校区各有一个独立网站），请使用网站页面视图顶部的网站切换器在它们之间切换。每个网站都有各自的页面、导航和[外观](./appearance.md)设置。参见下文的[多个网站](#multiple-websites)。
:::

## 了解页面类型 {#understanding-page-types}

**Pages**（页面）表格按**路径**和**标题**列出你网站上的每个页面。页面分为两种类型：

- **Generated**（系统生成）-- 系统根据你教会的数据自动创建的页面（例如小组页面、讲道页面，或讲道库中每场讲道各自的页面）。这些页面带有 **Generated** 标记，并会随着你的数据变化而自动更新。
- **Custom**（自定义）-- 你自行创建、使用自己的内容和布局的页面。

如果你希望完全控制某个自动生成页面的内容和设计，可以将其转换为自定义页面。点击该系统生成页面旁边的 **Convert**（转换），然后点击 **Confirm**（确认）。随即打开 **New Page**（新建页面）对话框；为页面输入标题，然后点击 **Save**。你的新自定义页面会接管原系统生成页面的路径，之后你就可以在[页面编辑器](./page-editor.md)中进行构建。

## 添加和编辑页面 {#adding-and-editing-pages}

1. 点击网站页面视图右上角的 **Add Page**（添加页面）按钮。
2. 选择页面类型并输入 **Page Title**（页面标题），然后点击 **Save**。**Blank**（空白）会创建一个空页面；**Sermons**（讲道）、**About Us**（关于我们）、**Donate**（奉献）和 **Location**（地点）会为该类页面填入建议标题；**AI** 则会根据你输入的简短描述生成页面的初稿。页面路径由标题生成（例如 "Our Team"（我们的团队）会变为 `/our-team`），之后你可以在 **Page Settings**（页面设置）中更改。
3. 点击任意页面旁边的 **Edit Content**（编辑内容），打开[页面编辑器](./page-editor.md)，在其中添加版块、文字、图片和其他元素。
4. 点击页面旁边的 **Page Settings**（页面设置），更新页面标题、网址路径和其他元数据。
5. 点击 **Path**（路径）列中的页面路径，即可在新标签页中打开实时页面，查看访客将看到的确切效果。

:::tip
对于首页，请将网址路径设为 `/`。对于其他所有页面，请使用具有描述性的路径，例如 `/about` 或 `/contact`。
:::

### 页面设置 {#page-settings}

在任意页面上打开 **Page Settings**，即可配置：

- **Page Title**（页面标题）-- 页面名称。
- **Layout**（布局）-- **Header & Footer**（页眉和页脚）（默认，即在页面周围显示网站导航栏和页脚），或 **Clean Centered Content**（简洁居中内容）（仅显示页面内容，置于浅灰色背景上的居中卡片中，不显示导航栏或页脚 -- 适用于简单的报名页或落地页）。
- **URL Path**（网址路径）-- 页面在网站上的地址。点击铅笔图标进行更改，然后点击 **Check**（检查），确保路径有效且未被占用。
- **Visibility**（可见性）-- 选择谁可以看到该页面：**Everyone**（所有人）、**Logged-in Users**（已登录用户）、**Members & Staff**（会员和工作人员）、**Staff Only**（仅工作人员）、**Team Members**（团队成员）或 **Specific Groups**（特定小组）（然后勾选小组）。这是无需单独密码即可限制私密页面（例如工作人员资源页）访问的快捷方式。未登录的访客会看到 "This page is for church members"（此页面仅供教会会员访问）以及 **Login**（登录）按钮；已登录但未获分享该页面的人员会看到 "You don't have access to this page."（你无权访问此页面。）。受限页面不会包含在你的网站地图中。
- **Meta Description**（元描述）-- 在搜索引擎结果和社交媒体链接预览中显示的简短摘要。建议约 155 个字符，或点击 **Generate with AI**（使用 AI 生成），根据页面内容生成初稿。

该对话框还提供 **Duplicate**（复制）按钮（会复制页面及其全部内容），以及 **Delete**（删除）按钮（永久删除页面）。

:::tip
如果要将旧地址指向某个页面（例如将 `/about-us` 重命名为 `/about` 之后），请在[外观](./appearance.md#redirects--analytics)中的 **Redirects & analytics**（重定向与分析）下添加重定向。
:::

## 管理导航 {#managing-navigation}

网站页面视图右侧的 **Main Navigation**（主导航）面板显示你的导航链接。这些链接控制访客在你网站上看到的菜单。

1. 点击 **Add**（添加）以创建新的导航链接。你可以将其指向网站上的任意页面，或指向外部网址。
2. 若要重新排列链接，请将其拖放到所需的顺序。你也可以将链接嵌套在父级项目之下，以创建下拉菜单。
3. 点击任意链接即可打开其 **Link Settings**（链接设置），在其中更改文字、网址或父页面。
4. 若要将链接从导航中移除，请打开其 **Link Settings**，然后点击 **Delete**（删除）。

:::info
移除导航链接不会删除页面本身。页面依然存在，仍可通过其网址直接访问 -- 只是不会显示在菜单中。
:::

## 全站开关 {#site-wide-switches}

在 **Main Navigation** 面板中，链接下方有两个适用于整个教会网站的开关：

- **Show Login**（显示登录）-- 在网站导航栏中显示 **Login**（登录）按钮。
- **Disable Public Website**（禁用公开网站）-- 关闭你的公开网站。如果你的教会仅将 B1 用于会员门户、奉献和报名，而将主网站放在其他地方，可以使用此选项。

### 禁用公开网站的效果 {#what-disabling-the-public-website-does}

开启 **Disable Public Website** 后：

- 所有公开页面（包括首页和你的自定义页面）都会将未登录的访客引导至登录页面。登录后，他们会返回到原先请求的页面。
- 已登录的会员会照常看到完整的网站，包括导航和内置的 **Generated**（系统生成）页面（例如小组和讲道）。系统生成的页面不再显示在页面表格中。
- 搜索引擎会被告知不要索引该网站。网站地图为空，`robots.txt` 会阻止所有爬取。

以下链接仍可正常使用，因此会员和访客依然可以访问：

- 登录和登出
- 会员门户（`/mobile` 下的所有内容）
- [活动报名](../guides/event-registration.md)链接以及访客报名

开关下方会显示警告，提示公开网站已关闭。再次关闭该开关即可恢复你的页面。网站被禁用期间，不会删除任何内容。

:::info
此设置适用于你的整个教会。如果你有多个网站，它会关闭所有网站，而不仅仅是网站切换器中当前选中的那个。
:::

## 组织网站的小技巧 {#tips-for-organizing-your-site}

- 将顶级导航保持在五到六个项目以内，方便访客快速找到所需内容。
- 对于相关的子页面，请使用嵌套链接（例如 "About"（关于）下拉菜单中包含 "Our Team"（我们的团队）、"Beliefs"（信仰）和 "History"（历史））。
- 在手机上检查你的导航，确保它在较小的屏幕上也能良好运行。
- 为页面起一个清晰、具有描述性的名称，帮助访客了解他们将会找到什么。

:::tip
你可以在页面中添加[表单](../forms/creating-forms.md)，用于收集报名、代祷请求或访客的其他信息。
:::

## 从网站模板开始 {#starting-from-a-site-template}

如果你要从零开始构建网站，可以使用**网站模板**来快速搭建，而无需逐个创建页面。网站模板会创建一组预设页面 -- 首页、关于、联系、奉献等 -- 并已预先连接好占位内容和导航链接。

1. 在页面屏幕上，点击 **Start From a Template**（从模板开始）按钮（位于 **Add Page** 按钮旁边）。
2. 浏览可用的模板（例如 **Classic**（经典）、**Modern**（现代）、**Community**（社群）和 **Visitor Focused**（以访客为中心）），点击其中一个即可预览其页面以及它添加的导航链接。
3. 找到你喜欢的模板后，点击 **Create Site**（创建网站）。
4. 尚未存在的页面会被创建并添加到你的导航中。你已有的页面会标记为 **Already exists**（已存在）并保持不变。随后会打开第一个新创建的页面，方便你查看。

应用模板后，请在[页面编辑器](./page-editor.md)中打开每个页面，将占位文字和图片替换为你教会的真实内容。

:::info
模板只会在从未保存过配色方案的网站上设置颜色和字体。一旦你选择了自己的配色方案，应用模板时将保留你的颜色和字体 -- 这些设置仍在[外观](./appearance.md)中管理。
:::

## 多个网站 {#multiple-websites}

一个教会可以通过同一个账户运行多个网站 -- 例如每个校区一个网站，或为学校单独设立一个网站。

1. 在页面屏幕上，打开网站切换器（初始显示为 **Main Website**（主网站）），然后选择 **Manage websites…**（管理网站…）。
2. 在 **Websites**（网站）对话框中，输入 **Name**（名称）和 **Subdomain**（子域名）（仅限小写字母和数字 -- 它将成为 `{subdomain}.b1.church`），然后点击 **Add Website**（添加网站）。
3. 在网站切换器中选择新网站，即可构建其页面、导航、区块和外观。

若要删除某个网站，请打开 **Manage websites…**，并点击其旁边的 **Delete**（删除）。该网站的页面、导航和外观将被永久删除，其拥有的任何自定义域名会转移到主网站。

## 图片灯箱 {#image-lightbox}

当访客点击网站上的图片时，图片会在全屏灯箱浮层中打开，使人们无需离开当前页面即可以更大尺寸查看照片。无需任何配置 -- 灯箱会自动为页面内容中的图片启用。
