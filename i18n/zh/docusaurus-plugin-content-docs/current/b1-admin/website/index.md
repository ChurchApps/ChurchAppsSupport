# 网站

<div class="article-intro">

B1 Admin 中的网站版块为你的教会提供功能完备的网站构建器。你可以创建页面、自定义网站的外观和风格、管理媒体文件，并发布活动日历 -- 无需编写任何代码。

</div>

## 你可以做什么 {#what-you-can-do}

网站构建器分为以下几个主要区域：

### 页面 {#pages}

创建和管理教会网站上的所有页面。**Pages**（页面）表格列出每个页面 -- 由系统自动创建的页面带有 **Generated**（系统生成）标记，其余则为你创建的自定义页面。你可以添加新的自定义页面、编辑现有页面，或将自动生成的页面转换为自定义页面，以便完全控制其内容。

你的导航链接列在页面表格旁边的 **Main Navigation**（主导航）面板中。你可以通过拖放来重新排列和嵌套链接，从而设置访客所看到的确切层级和顺序。参见[页面管理](./managing-pages.md)。

### 博客 {#blog}

以博客文章的形式发布新闻、动态和灵修文章，显示在网站的 `/blog` 上，并提供 RSS 订阅源。参见[博客](./blog.md)指南。

### 区块 {#blocks}

构建可复用的内容组件，并将其放置到多个页面中。当你的行动号召、公告横幅或联系信息等内容需要在多处出现时，区块可以为你节省时间。只需更新一次区块，更改即会应用到所有使用它的地方。参见[可复用区块](./blocks.md)。

### 外观 {#appearance}

自定义网站的主题、颜色、字体、徽标和间距。你可以应用预设的样式主题快速开始，也可以使用配色方案编辑器、字体排版设置和自定义 CSS 微调每个细节。完整详情请参阅[外观](./appearance.md)指南。

### 文件 {#files}

在一个中央位置上传和管理所有媒体资源 -- 图片、文档和其他文件 -- 并复制文件链接，以便在网站的任何地方使用。详情请参阅[文件](./files.md)。

### 日历 {#calendars}

在你的网站上发布活动日历，让访客了解教会正在举行的活动。创建精选日历，将多个小组的活动汇集到同一视图中。日历在 B1 Admin 菜单中有自己的 **Calendars**（日历）项目，与 **Website**（网站）分开。

:::tip
如果你是首次配置网站，请从[初始设置](./initial-setup.md)开始。该指南会引导你完成域名设置、创建第一个页面以及配置网站外观。
:::
