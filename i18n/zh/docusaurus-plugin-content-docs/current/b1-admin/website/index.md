# 网站

<div class="article-intro">

B1 Admin 中的网站部分为您的教会提供功能齐全的网站生成器。您可以创建页面、自定义您网站的外观和风格、管理媒体文件并发布活动日历 -- 所有这些都无需编写任何代码。

</div>

## 您可以做什么

网站生成器分为五个主要区域：

### 页面

创建和管理教会网站上的所有页面。**页面**表格显示每个页面及其状态 -- 要么**已生成**（由系统自动创建）要么**自定义**（由您创建）。您可以添加新的自定义页面、编辑现有页面或将自动生成的页面转换为自定义页面以获得对其内容的完全控制。

您的导航链接显示在树形结构中。您可以使用拖放重新排序链接，以设置您希望访客看到的确切层次和顺序。

### 块

构建可重用的内容组件，您可以在多个页面上放置。块在您拥有出现在多个地方的内容（如行动号召、公告横幅或联系部分）时为您节省时间。更新一个块，更改就会应用到它被使用的任何地方。

### 外观

自定义您网站的主题、颜色、字体、徽标和间距。您可以应用预构建的样式主题以快速开始，或使用颜色调色板编辑器、排版设置和自定义 CSS 微调每个细节。有关详细信息，请参阅[外观](appearance)指南。

### 文件

在一个中心位置上传和组织所有媒体资产 -- 图像、文档和其他文件。使用文件夹来保持整洁，并复制文件 URL 以在您的网站上的任何地方使用。有关更多信息，请参阅[文件](files)。

### 日历

在您的网站上发布活动日历，以便访客可以看到教会发生了什么。创建策划的日历，将来自多个小组的活动拉入单一视图。

:::tip
如果您是第一次配置网站，请从[初始设置](initial-setup)开始。它会指导您完成域设置、创建第一个页面和配置网站外观。
:::
