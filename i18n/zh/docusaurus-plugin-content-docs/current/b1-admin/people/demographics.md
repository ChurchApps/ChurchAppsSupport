# 人口统计

<div class="article-intro">

**人口统计**仪表板让你以图表方式一览教会会众的概况——他们是谁、有多少人，以及会员在年龄层、性别、婚姻状况与校区之间的分布情况。每张图表都具有互动性：点击任何区块，即可直接跳转到经过筛选的人员搜索，显示恰好符合该条件的人员。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 人员必须已存在于你的通讯录中。如需入门，请参阅[新增人员](./adding-people.md)或[导入资料](./importing-data.md)。
- 若要依校区细分校区图表，你首先需要在[设置 → 校区](../settings/campuses.md)中设置校区。

</div>

## 打开人口统计 {#opening-demographics}

在 **People** 页面中，点击页面标题中的 **Demographics**。页面顶端会显示你的人员总数（**Total**），其后是下方所述的各张图表。每张环形图下方也会显示其总数。点击右上角的 **People**，即可返回通讯录。

## 图表 {#charts}

### 年龄 {#age}

堆叠条形图，显示各年龄段的人数：0–3、4–11、12–18、19–25、26–35、36–50、51–64 以及 65 岁以上。每个条形会依性别划分——**Female**（女）、**Male**（男），以及在该年龄段中若有人未记录性别，则会显示 **Unassigned**（未指定）——让你一眼就能看出每个年龄层内的性别比例。没有出生日期的人员不会计入此图表。

### 会员类型 {#membership-types}

环形图，依会员状态划分会众（例如 Member、Regular Attendee、Visitor 等）。没有状态的人员会显示为 **Unassigned**。

### 性别 {#gender}

环形图，显示通讯录中女性、男性及未指定记录的比例。

### 婚姻状况 {#marital-status}

环形图，显示各婚姻状况值的分布（例如 Married、Single、Widowed）。

### 校区 {#campus}

环形图，显示人员在教会各校区之间的分布。没有指定校区的人员会显示为 **Unassigned**，因此没有校区的教会只会看到一个 **Unassigned** 区块。

## 深入查看资料 {#drilling-into-the-data}

点击环形图的任何区块（或图例中的名称），或年龄图上的任何条形区段，即可前往 **People** 页面，该页面已预先套用筛选，只显示恰好符合条件的人员。页面载入完成后，筛选会保持生效，列表上方的数字会显示符合条件的住户与人员数量。你可以用此功能快速建立联络名单、执行批量操作，或汇出某个区段的资料——例如，点击会员状态中的 **Visitor** 区块，即可查看所有访客，然后将他们加入工作流程。

:::tip
深入查看筛选结果后，可在人员搜索中使用 **Save as List**，将该筛选条件保存起来以供日后使用。请参阅[已保存的名单](./lists.md)。
:::
