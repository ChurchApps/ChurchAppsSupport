# 人口统计

<div class="article-intro">

**Demographics**（人口统计）仪表板可直观展示您的会众概况：他们是谁、有多少人，以及会众在年龄段、性别、婚姻状况和校区之间的分布情况。每个图表都可以互动：点击任意部分，即可直接跳转到筛选后的人员搜索页面，显示该部分的确切人员。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 通讯录中必须已有人员。请参阅[添加人员](./adding-people.md)或[导入数据](./importing-data.md)开始操作。
- 要查看校区图表，您首先需要在[设置 → 校区](../settings/campuses.md)中配置校区。

</div>

## 打开人口统计

在 **People** 页面上，点击页眉中的 **Demographics**。页面顶部会显示您的总人数，之后是下文所述的各个图表。

## 图表

### 年龄分布

分组条形图，显示每个年龄段的人数（例如 0–9 岁、10–17 岁、18–24 岁，直至 65 岁以上）。每个条形分为三个系列：**Female**（女）、**Male**（男）和 **Unassigned**（未指定），让您一眼就能看出每个年龄段内的性别构成。

### 会员状态

环形图，按会员状态（例如 Member（会员）、Regular Attender（常规参加者）、Visitor（访客）等）划分您的会众。

### 性别

环形图，显示您通讯录中女性、男性和未指定记录的比例。

### 婚姻状况

环形图，显示各种婚姻状况值的分布情况（例如 Married（已婚）、Single（单身）、Widowed（丧偶））。

### 校区

环形图，显示人员在您教会各校区之间的分布情况。只有当您已配置校区并且至少有一人被分配到某个校区时，此图表才会显示。未分配校区的人员将显示为 **Unassigned**。

## 深入查看数据

点击环形图的任意切片，或年龄图表上的任意条形段，即可跳转到 **People** 页面，并自动筛选出这些人员。页面加载完成后，筛选条件仍会保留，列表上方的计数会显示匹配的家庭和人员数量。您可以利用这一功能快速建立联系人列表、执行批量操作或导出某个细分群体。例如，点击会员状态中的 **Visitor** 切片，即可查看所有访客，然后将他们加入工作流程。

:::tip
在深入查看筛选结果后，可在人员搜索中使用 **Save as List**（保存为列表），以便将该筛选条件保存下来供日后使用。请参阅[已保存列表](./lists.md)。
:::
