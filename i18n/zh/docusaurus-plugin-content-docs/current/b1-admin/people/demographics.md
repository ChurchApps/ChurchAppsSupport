# 人口统计

<div class="article-intro">

**人口统计**仪表板为您提供了您的会众的视觉快照 — 他们是谁、有多少人以及您的成员资格在年龄组、性别、婚姻状况和校区中的分布。每个图表都是交互式的：单击任何部分以直接跳转到显示确切这些人员的过滤的人员搜索。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 人员必须存在于您的目录中。参见[添加人员](./adding-people.md)或[导入数据](./importing-data.md)来开始。
- 要查看校区图表，您首先需要在[设置 > 校区](../settings/campuses.md)中配置校区。

</div>

## 打开人口统计

从**人员**页面，单击页面标题中的**人口统计**按钮（条形图图标）。页面在顶部显示您的总人数，然后是下面描述的图表。

## 图表

### 年龄分布

一个分组条形图，显示有多少人落入每个年龄范围（例如 0-9、10-17、18-24，依此类推至 65+）。每个条形分为三个系列 — **女性**、**男性**和**未分配** — 以便您可以一目了然地看到每个年龄组中的性别分解。

### 成员资格状态

一个甜甜圈图，按成员资格状态（例如成员、常规参加者、访客等）分解您的会众。

### 性别

一个甜甜圈图，显示目录中女性、男性和未分配记录的比例。

### 婚姻状况

一个甜甜圈图，显示跨婚姻状况值的分解（例如已婚、单身、丧偶）。

### 校区

一个甜甜圈图，显示人员如何分布在您的教会校区中。此图表仅在您配置了校区且至少有一个人分配到校区时出现。未分配校区的人员显示为**未分配**。

## 深入了解数据

单击任何甜甜圈图的任何切片或年龄图表上的任何条形段以导航到**人员**页面，预先过滤以显示确切这些人员。使用此功能快速构建联系人列表、运行批量操作或导出部分 — 例如，在成员资格状态中单击**访客**切片以查看所有访客，然后将他们发送到工作流。

:::tip
深入了解过滤结果后，在人员搜索中使用**另存为列表**以保存该过滤器供将来使用。参见[保存的列表](./lists.md)。
:::
