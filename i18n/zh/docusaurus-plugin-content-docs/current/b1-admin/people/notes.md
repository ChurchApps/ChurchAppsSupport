# 笔记

<div class="article-intro">

**Notes** 页面会将 B1 Admin 中各处的近期笔记汇集到一处，方便你无需逐一打开每条记录，就能跟进牧养关怀、后续跟进和规划事宜。它会按从新到旧的顺序列出你在成员、你所带领的小组、日历活动以及工作流卡片上写下的笔记，并链接回每条笔记的书写位置。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 如果你拥有 **Edit People** 权限，或你至少带领一个小组，**Notes** 页面就会出现在菜单中。参见[分配角色](./roles-permissions.md)。
- 该页面只显示你已获准阅读的笔记。每个标签页都遵循其所属记录的相同规则（参见[每个标签页显示的内容](#what-each-tab-shows)）。

</div>

## 打开笔记页面

1. 打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），并展开 **People**。
2. 点击 **Notes**。
3. 页面会在 **People** 标签页中打开。使用页眉中的标签在 **People**、**Groups**、**Events** 和 **Workflows** 之间切换。

## 查看列表

列表中的每条笔记会显示：

- **书写位置**——成员姓名、小组名称、活动标题或工作流卡片标题。点击名称即可打开该记录，阅读完整的讨论串或添加笔记。
- **保密**——一个徽章，标在来自成员“保密笔记”部分的成员笔记上。
- **作者与时间**——“By”后面是作者的姓名，再后面是发布的日期和时间。
- **笔记正文**——较长的笔记在列表中会被缩短。打开该记录即可阅读完整内容。

列表按最新的笔记优先显示。点击底部的 **Load more** 可查看更早的笔记。

笔记页面是只读的。若要添加、编辑或回复笔记，请点击该记录的名称以打开它。

## 每个标签页显示的内容 {#what-each-tab-shows}

| 标签 | 显示的笔记 | 谁可以查看 | 点击名称会打开 |
|-----|-------------|------------------|-------------------------|
| **People** | 成员记录上的笔记 | 拥有 **Edit People** 权限的人。保密笔记还需要 **View Confidential Notes** 权限 | 该成员的笔记 |
| **Groups** | 小组上的[带领者笔记](../groups/group-members.md#leader-notes) | 仅限每个小组的带领者，即使是管理员也是如此 | 该小组的笔记 |
| **Events** | [活动笔记](../calendars/creating-calendars.md#event-notes) | 有权编辑内容或管理日历的员工，以及活动的 **Who can view notes** 设置所允许的任何人 | 该活动所属小组的日历 |
| **Workflows** | [工作流卡片](../serving/workflows.md#working-the-board)上的笔记 | 任何能够打开该卡片的人，包括被分配到该卡片的成员或小组 | 该卡片的工作流看板 |

如果某个标签页中目前没有你可以查看的内容，页面会明确说明——例如：“暂无你所带领小组的笔记。”

:::tip
笔记讨论串带有一个用于接收通知的铃铛图标。点击它即可在该讨论串中有新笔记时收到通知（图标会立即改变），再次点击则可静音。这些开关设置永远不会以笔记的形式出现在笔记页面上。
:::
