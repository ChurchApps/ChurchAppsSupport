# 备注

<div class="article-intro">

**备注**页面将 B1 Admin 中的近期备注汇集到一处，方便你无需逐个打开记录，即可了解牧养关怀、后续跟进和事工规划的最新情况。它会列出人员、你所带领小组、日历活动以及工作流卡片上撰写的备注，按最新时间排序，并可链接回每条备注的撰写位置。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 如果你拥有 **Edit People** 权限，或你至少带领一个小组，菜单中就会出现 **Notes** 页面。参见[分配角色](./roles-permissions.md)。
- 该页面只显示你本就有权阅读的备注。每个标签页都遵循其所属记录的相同规则（参见[各标签页显示的内容](#what-each-tab-shows)）。

</div>

## 打开备注页面

1. 打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **People**。
2. 点击 **Notes**。
3. 页面会打开 **People** 标签页。使用页面顶部的标签页，可在 **People**、**Groups**、**Events** 和 **Workflows** 之间切换。

## 阅读列表

列表中的每条备注会显示：

- **撰写位置** —— 人员姓名、小组名称、活动标题或工作流卡片标题。点击名称即可打开该记录，阅读完整的讨论串或添加备注。
- **Confidential**（保密）—— 人员备注上的标识，表示该备注来自人员资料中的保密备注区域。
- **撰写人和时间** —— 显示 "By" 加上撰写人的姓名，之后是发布的日期和时间。
- **备注内容** —— 较长的备注在列表中会被缩短。打开记录即可阅读完整内容。

列表按最新备注在前的顺序显示。点击底部的 **Load more**（加载更多）即可查看较早的备注。

对于已被删除，或已合并到其他记录中的人员所撰写的备注，不会显示在 **People** 标签页中。

备注页面为只读。要添加、编辑或回复备注，请点击记录名称打开该记录。

## 各标签页显示的内容 {#what-each-tab-shows}

| 标签页 | 显示的备注 | 谁可以查看 | 点击名称打开 |
|-----|-------------|------------------|-------------------------|
| **People** | 人员记录上的备注 | 拥有 **Edit People** 权限的人员。保密备注还需要 **View Confidential Notes** 权限 | 该人员的备注 |
| **Groups** | 小组上的[负责人备注](../groups/group-members.md#leader-notes) | 仅每个小组的负责人，即使是管理员也不例外 | 该小组的备注 |
| **Events** | [活动备注](../calendars/creating-calendars.md#event-notes) | 有权编辑内容或管理日历的工作人员，以及活动的 **Who can view notes** 设置所允许的人员 | 该活动所属小组的日历 |
| **Workflows** | [工作流卡片](../serving/workflows.md#working-the-board)上的备注 | 任何可以打开该卡片的人，包括被分配到该卡片的人员或小组 | 该卡片所在的工作流看板 |

如果某个标签页中暂时没有你可以查看的内容，页面会提示——例如"你带领的小组暂无备注。"

:::tip
备注讨论串旁边有一个铃铛图标，用于接收通知。点击它即可在该讨论串有新备注时收到提醒（图标会立即变化）；再次点击则可静音。这些开关设置永远不会作为备注显示在备注页面上。
:::
