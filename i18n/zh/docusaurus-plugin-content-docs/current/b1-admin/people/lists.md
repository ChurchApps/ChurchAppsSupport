# 已保存列表

<div class="article-intro">

**已保存列表**让您可以将搜索查询以名称形式保存，并随时一键重新运行。只需构建一次列表——"北校区的活跃成员"、"过去 90 天内的访客"，或任何高级筛选——它就会保留在侧边栏中，您无需再次重新构建查询。

</div>

<div class="prereqs">
<h4>准备工作</h4>

- 在"人员"部分至少运行一次搜索，以便有结果可以保存。请参阅[搜索人员](./searching-people.md)或 [AI 搜索](./ai-search.md)。

</div>

## 将搜索保存为列表

1. 在**人员**页面运行一次搜索——快速搜索、AI 搜索，或高级筛选搜索均可。
2. 结果出现后，人员页面标题中会显示一个**保存为列表**按钮（书签图标）。
3. 点击**保存为列表**。
4. 输入列表的**名称**（必填）。
5. 您可以选择输入一个**类别**，将相关列表在侧边栏中归为一组（例如"外展"或"会员管理"）。
6. 点击**保存**。

该列表现已保存到您教会的账户中，并会出现在"人员"页面左侧的**已保存列表**面板中。

:::info
列表在您的教会内共享——任何拥有"人员"访问权限的人都可以查看和加载它们。只有具备相应权限的员工才能重命名或删除列表。
:::

## 加载已保存的列表

在"人员"页面左侧的**已保存列表**面板中，点击任意列表名称。搜索会立即使用保存的查询重新运行，并更新结果表格。

列表按类别分组（如果您指定了类别），未分类的列表排在最后。

:::tip
列表是**实时查询**，而非快照。每次加载列表时，搜索都会针对您当前的数据重新运行，因此新符合条件的人员也会出现在结果中。
:::

## 重命名和删除列表

拥有管理权限的员工可以直接在"已保存列表"面板中重命名或删除任何列表。

- 点击列表名称旁的**铅笔图标**进行重命名。
- 点击**垃圾桶图标**进行删除（系统会要求您确认）。

## 使用场景

| 场景 | 如何构建列表 |
|---|---|
| 所有访客 | 高级搜索：成员身份状态 = 访客 |
| 特定堂点的成员 | 高级搜索：堂点 = [您的堂点] |
| 没有邮箱地址的人员 | 高级搜索：邮箱为空 |
| 背景审查已过期的志愿者 | 高级搜索：[自定义字段](../settings/custom-fields.md)"背景审查到期日"早于今天 |
| 来自 AI 提问的结果 | 在 AI 搜索中提问，然后保存 |
