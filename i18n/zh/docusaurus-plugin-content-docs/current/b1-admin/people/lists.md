# 保存的列表

<div class="article-intro">

**保存的列表**让您在名称下存储搜索查询并随时一键重新运行。构建列表一次 — "校区北的活跃成员"、"过去 90 天的访客"或任何高级过滤 — 它保留在人员页面上的**保存的列表**面板中，因此您永远不必重建查询。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在人员部分运行至少一次搜索，以便您有结果要保存。参见[搜索人员](./searching-people.md)或 [AI 搜索](./ai-search.md)。

</div>

## 将搜索保存为列表

1. 在**人员**页面上运行搜索 — 快速搜索、AI 搜索或高级过滤搜索。
2. 出现结果时，人员页面标题中会显示**另存为列表**按钮（书签图标）。
3. 单击**另存为列表**。
4. 为列表输入**名称**（必需）。
5. 可选择输入**类别**以在**保存的列表**面板中将相关列表组合在一起（例如"外展"或"成员资格"）。
6. 点击**保存**。

列表现在保存到您的教会帐户，将出现在人员页面左侧的**保存的列表**面板中。

:::info
列表在您的教会中共享 — 任何拥有人员访问权限的人都可以查看和加载它们。只有具有适当权限的工作人员可以重命名或删除列表。
:::

## 加载保存的列表

在人员页面左侧的**保存的列表**面板中，单击任何列表名称。搜索立即以存储的查询重新运行，更新结果表。

列表按类别分组（如果您分配了一个），未分类的列表最后出现。

:::tip
列表是**实时查询**，而不是快照。每次加载列表时，搜索都会针对您当前的数据新鲜运行，因此现在符合条件的新人员将出现。
:::

## 重命名和删除列表

具有管理权限的工作人员可以直接从保存的列表面板重命名或删除任何列表。

- 单击列表名称旁边的**铅笔图标**以重命名它。
- 单击**垃圾桶图标**删除它（您会被要求确认）。

## 用例

| 场景 | 如何构建列表 |
|---|---|
| 所有访客 | 高级搜索：成员资格状态 = 访客 |
| 特定校区的成员 | 高级搜索：校区 = [您的校区] |
| 没有电子邮件地址的人员 | 高级搜索：电子邮件为空 |
| 背景检查已过期的志愿者 | 高级搜索：[自定义字段](../settings/custom-fields.md)"背景检查过期"在今天之前 |
| AI 问题的结果 | 在 AI 搜索中提出问题，然后保存 |
