# 批量编辑人员

<div class="article-intro">
批量编辑允许您一次更新多个人，在对许多个人进行相同更改时节省时间。您可以在单个操作中更新成员资格状态、婚姻状况、性别、选择退出首选项和小组成员资格。
</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要权限管理人员数据。有关详情，请参见[角色和权限](./roles-permissions.md)。
- 您应该已经添加或导入了您想要编辑的人员。如果需要，请参见[添加人员](./adding-people.md)。
</div>

## 为批量编辑选择人员

1. 在 B1Admin 中导航到**人员**
2. 使用搜索或过滤工具找到您想要更新的人员
3. 检查每个人名旁边的框以选择他们
   - 您可以单独选择人员
   - 或使用标题复选框选择当前页面上的所有可见人员
4. 选择至少一个人员后，**批量操作**按钮将出现

:::tip
如果您需要根据特定条件更新大量人员，请使用 [AI 搜索](./ai-search.md)功能或过滤器首先缩小列表，然后选择所有匹配的人员。
:::

## 可用的批量操作

**批量操作**菜单提供几个选项：

### 更新成员资格状态

为所有选定的人员更新成员资格状态：

1. 单击**批量操作** → **设置成员资格状态**
2. 选择新状态：
   - **访客** — 首次或偶尔的与会者
   - **常规参加者** — 不是成员的常见与会者
   - **成员** — 正式教会成员
   - **工作人员** — 教会工作人员
   - **不活跃** — 不再参加的人员
3. 选择更新模式：
   - **覆盖全部** — 替换所有选定人员的当前状态
   - **仅更新空** — 仅为没有状态的人员设置状态
4. 点击**更新**

### 更新婚姻状况

批量更新婚姻状况：

1. 单击**批量操作** → **设置婚姻状况**
2. 选择新状态：
   - **未知**
   - **单身**
   - **已婚**
   - **离婚**
   - **丧偶**
3. 选择是否覆盖现有值或仅更新空字段
4. 点击**更新**

### 更新性别

为多个人更新性别信息：

1. 单击**批量操作** → **设置性别**
2. 选择值：
   - **未指定**
   - **男性**
   - **女性**
3. 选择更新模式（覆盖全部或仅空）
4. 点击**更新**

### 更新选择退出状态

控制人员是否已选择退出通信：

1. 单击**批量操作** → **设置选择退出**
2. 选择：
   - **否** — 允许通信（删除选择退出）
   - **是** — 阻止通信（设置选择退出）
3. 选择更新模式
4. 点击**更新**

:::warning
更改选择退出状态时要小心。已明确选择退出的人员不应接收通信，除非他们给予了新的同意。
:::

### 设置自定义字段

为所有选定的人员一次性设置是/否[自定义字段](../settings/custom-fields.md)值：

1. 单击**批量操作** → **设置自定义字段**。
2. 选择您想要设置的是/否自定义字段。
3. 选择要应用的值（**是**或**否**）。
4. 点击**更新**。

:::info
只有是/否自定义字段适用于此批量操作。要设置其他字段类型，请单独编辑每个人。
:::

### 添加到小组

将所有选定的人员添加到一个或多个小组：

1. 单击**批量操作** → **添加到小组**
2. 搜索并选择要添加人员的小组
3. 您可以选择多个小组以将人员添加到所有小组
4. 单击**添加到小组**

每个人将被添加为所选小组的常规成员。如果需要，您可以稍后从[小组成员](../groups/group-members.md)页面将个人提升为小组领导者。

### 从小组中删除

从一个或多个小组中删除所有选定的人员：

1. 单击**批量操作** → **从小组中删除**
