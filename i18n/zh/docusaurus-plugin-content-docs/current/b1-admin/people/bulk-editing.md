# 批量编辑人员

<div class="article-intro">
批量编辑允许您一次更新多个人，在对许多个人进行相同更改时节省时间。您可以在单个操作中更新成员资格状态、婚姻状况、性别、选择退出首选项和小组成员资格。
</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要权限管理人员数据。有关详情，请参见[角色和权限](./roles-permissions.md)。
- 您应该已经添加或导入了您想要编辑的人员。如果需要，请参见[添加人员](./adding-people.md)。
</div>

## 为批量编辑选择人员

1. 在 B1 Admin 中导航到**人员**
2. 使用搜索或过滤工具找到您想要更新的人员
3. 勾选这些人员的复选框以选择他们
   - 在**家庭**视图中，勾选一个家庭会选中其中的所有人
   - 在**表格**视图中（通过**查看方式**切换按钮切换），您可以单独选择人员
   - 或使用列表上方的复选框选择所有可见人员
4. 选择至少一个人员后，列表上方的栏会显示所选人数，并提供**清除选择**和**操作**按钮

:::tip
如果您需要根据特定条件更新大量人员，请使用 [AI 搜索](./ai-search.md)功能或过滤器首先缩小列表，然后选择所有匹配的人员。
:::

## 可用的批量操作

**操作**菜单提供几个选项：

### 更新成员资格状态

为所有选定的人员更新成员资格状态：

1. 单击**操作** → **设置成员资格状态**
2. 选择新状态：
   - **访客** — 首次或偶尔的与会者
   - **来宾** — 来宾，例如在签到终端登记的家庭
   - **常规参加者** — 不是成员的常见与会者
   - **成员** — 正式教会成员
   - **工作人员** — 教会工作人员
   - **不活跃** — 不再参加的人员
   - **已故** — 已经去世的人员
3. 选择更新模式：
   - **覆盖全部** — 替换所有选定人员的当前状态
   - **仅更新空** — 仅为没有状态的人员设置状态
4. 点击**更新**

### 更新婚姻状况

批量更新婚姻状况：

1. 单击**操作** → **设置婚姻状况**
2. 选择新状态：
   - **未知**
   - **单身**
   - **已婚**
   - **离婚**
   - **丧偶**
3. 选择是否覆盖现有值或仅更新空字段
4. 点击**更新**

### 更新性别

为多个人更新性别信息：

1. 单击**操作** → **设置性别**
2. 选择值：
   - **未指定**
   - **男性**
   - **女性**
3. 选择更新模式（覆盖全部或仅空）
4. 点击**更新**

### 更新选择退出状态

控制人员是否已选择退出通信：

1. 单击**操作** → **设置目录选择退出**
2. 选择：
   - **否** — 允许通信（删除选择退出）
   - **是** — 阻止通信（设置选择退出）
3. 选择更新模式
4. 点击**更新**

:::warning
更改选择退出状态时要小心。已明确选择退出的人员不应接收通信，除非他们给予了新的同意。
:::

### 设置自定义字段

为所有选定的人员一次性设置是/否[自定义字段](../settings/custom-fields.md)值：

1. 单击**操作** → **设置自定义字段**。
2. 选择您想要设置的是/否自定义字段。
3. 选择要应用的值（**是**或**否**）。
4. 点击**更新**。

:::info
只有是/否自定义字段适用于此批量操作。要设置其他字段类型，请单独编辑每个人。
:::

### 添加到小组

将所有选定的人员添加到一个或多个小组：

1. 单击**操作** → **添加到小组**
2. 搜索并选择要添加人员的小组
3. 您可以选择多个小组以将人员添加到所有小组
4. 单击**添加到小组**

每个人将被添加为所选小组的常规成员。如果需要，您可以稍后从[小组成员](../groups/group-members.md)页面将个人提升为小组领导者。

### 从小组中删除

从一个或多个小组中删除所有选定的人员：

1. 单击**操作** → **从小组中删除**
2. 搜索并选择要移除人员的小组
3. 您可以选择多个小组
4. 单击**从小组中删除**

:::info
此操作仅将人员从指定小组中移除。它不会删除他们的人员记录。
:::

### 删除人员

从您的教会数据库中永久删除所选人员：

1. 单击**操作** → **删除**
2. **删除所选人员**对话框会要求您确认将删除的人数
3. 点击**删除**

:::danger
删除人员是永久性的，无法撤销。这将删除其所有数据，包括：
- 个人信息
- 小组成员资格
- 出席记录
- 捐赠历史
- 表单提交记录

只有在您完全确定要从系统中移除这些人员时，才使用此操作。
:::

## 批量编辑结果

完成批量操作后，您将看到一个摘要，显示：

- **选择总数** -- 本次操作包含的人员数量
- **成功更新** -- 已更改的记录数量
- **失败** -- 无法更新的记录（如适用）
- **未更改** -- 不需要更改的记录（例如，使用"仅更新空"模式时）

如果有任何更新失败，您将看到解释原因的错误详情。

## 最佳实践

- **从小处开始** -- 先在几条记录上测试批量操作，以确保您做出的是正确的更改
- **使用过滤器** -- 在选择人员之前，先使用过滤器或 AI 搜索缩小列表，以确保您只更新正确的个人
- **仔细检查选择** -- 在应用批量更改之前，检查所选人员
- **使用"仅更新空"模式** -- 当您想补充缺失的数据而不覆盖现有信息时
- **记录重大更改** -- 保留有关批量更新的备注，以便日后查阅
- **与团队协调** -- 在进行大规模批量更改时，告知其他管理员

## 常见用例

### 更新新成员

在成员班结束后，将所有参加者更新为成员状态：

1. 搜索参加该班的人员
2. 全部选中
3. 使用**操作** → **设置成员资格状态** → **成员**

### 组织小组

将多人添加到一个新的小组：

1. 搜索您想加入该小组的人员
2. 选择他们
3. 使用**操作** → **添加到小组**，然后选择该小组

### 清理数据

为已婚夫妇补充缺失的婚姻状况：

1. 过滤出已婚的人员（使用家庭信息）
2. 选择婚姻状况为空的人员
3. 使用**操作** → **设置婚姻状况** → **已婚** → **仅更新空**
