# 人员

<div class="article-intro">

**人员**区域是你在 B1 Admin 中进行教会管理的核心。在这里，你可以维护教会通讯录——搜索会员、新增人员、查看与编辑个人资料，以及追踪住户。无论你的会众规模大小，妥善整理人员记录都是支撑 B1 中所有其他功能的基础。

</div>

## 你可以做什么 {#what-you-can-do}

以下是人员区域中主要功能的概述：

1. **搜索通讯录**——使用快速搜索栏按姓名找人，或利用进阶筛选与 AI 驱动的自然语言搜索，找出你需要的确切人员。详情请参阅[搜索人员](./searching-people.md)与[AI 搜索](./ai-search.md)。

2. **将搜索条件保存为名单**——将任何搜索或筛选保存为具名的名单，之后只需点击一次即可重新载入。请参阅[已保存的名单](./lists.md)。

3. **查看人口统计**——以年龄、性别、婚姻状况、会员状态与校区，查看会众的图表分布，并点击任何图表区段深入查看相关人员。请参阅[人口统计](./demographics.md)。

4. **新增人员**——快速将个人加入通讯录，并填写其个人资料、联络信息与住户关系。逐步说明请参阅[新增人员](./adding-people.md)。

5. **批量编辑人员**——一次更改多位人员的会员状态、婚姻状况、性别、通讯录退出设置、校区或小组成员资格，或将他们加入工作流程。当你要对许多人做相同更改时，这样可以节省大量时间。请参阅[批量编辑](./bulk-editing.md)。

6. **打印通讯录**——按住户分组，生成格式完整、可打印的会员通讯录，并附有照片与联络信息。请参阅[打印通讯录](./print-directory.md)。

7. **导入与汇出资料**——从 CSV 文件导入会员资料，或从 Breeze 等其他教会管理系统迁移。你也可以随时将通讯录汇出为 CSV。请参阅[导入资料](./importing-data.md)与[汇出资料](./exporting-data.md)。

8. **管理个人资料**——查看并编辑每位人员的详细资料，包括联络信息、住户成员、[小组成员资格](../groups/group-members.md)、[出席历史](../attendance/tracking-attendance.md)、[奉献](../donations/recording-donations.md)以及[自定义表单](../forms/creating-forms.md)。人员的姓名、联络详细信息与住户位于资料页面左侧，其出席、奉献、小组、备注与表单的摘要则位于其旁边。将鼠标悬停在地址或住家／工作电话上，即可一键复制。

9. **查阅备注**——在一个列表中阅读人员、小组、活动与工作流程卡片上的最新备注。请参阅[备注](./notes.md)。

10. **指派角色与权限**——通过指派角色，控制团队中哪些人可以访问 B1 Admin 的不同部分。请参阅[指派角色](./roles-permissions.md)。

## 入门 {#getting-started}

若要进入人员区域，请打开[快速菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **People**，然后点击 **People**。你会看到依住户列出的教会通讯录，页面顶端则有搜索栏。使用 **View as** 切换开关，即可在**住户**列表与个人的**表格**之间切换。

:::tip
如果你是第一次设置 B1，请先[导入你现有的会员资料](./importing-data.md)，然后根据需要检查并整理个人资料。
:::
