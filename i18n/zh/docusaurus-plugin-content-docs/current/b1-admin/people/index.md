# 人员

<div class="article-intro">

**人员**部分是 B1 Admin 中教会管理的核心。您可以在这里维护教会名录——搜索成员、添加新人员、查看和编辑个人资料，以及跟踪家庭。无论您的会众规模大小，保持人员记录井然有序是支撑 B1 中每一项其他功能的基础。

</div>

## 您可以做什么

以下是"人员"部分中主要功能的概览：

1. **搜索名录** -- 使用快速搜索栏按姓名查找任何人，或利用高级筛选器和 AI 驱动的自然语言搜索精确定位所需人员。详情请参阅[搜索人员](./searching-people.md)和 [AI 搜索](./ai-search.md)。

2. **将搜索查询保存为列表** -- 将任何搜索或筛选保存为命名列表，以便一键重新加载。请参阅[已保存列表](./lists.md)。

3. **查看人口统计信息** -- 按年龄、性别、婚姻状况、成员身份状态和堂点查看会众的可视化分布——点击任意图表分段可深入查看这些人员。请参阅[人口统计](./demographics.md)。

4. **添加新人员** -- 快速将个人添加到名录中，并填写其个人资料详情、联系信息和家庭关系。有关分步说明，请参阅[添加人员](./adding-people.md)。

5. **批量编辑人员** -- 一次性更新多个人员，更改其成员身份状态、婚姻状况、性别、退出偏好或小组成员身份。这在对多个人进行相同更改时可节省时间。请参阅[批量编辑](./bulk-editing.md)。

6. **打印名录** -- 生成一份按家庭分组、附带照片和联系信息的格式化可打印成员名录。请参阅[打印名录](./print-directory.md)。

7. **导入和导出数据** -- 从 CSV 文件导入成员数据，或从 Breeze 等其他教会管理系统迁移。您也可以随时将名录导出为 CSV。请参阅[导入数据](./importing-data.md)和[导出数据](./exporting-data.md)。

8. **管理个人资料** -- 查看和编辑每个人员的详细资料，包括联系信息、家庭成员、[小组成员身份](../groups/group-members.md)、[考勤历史](../attendance/tracking-attendance.md)、[捐款](../donations/recording-donations.md)和[自定义表单](../forms/creating-forms.md)。将鼠标悬停在蓝色个人资料头部的邮箱、地址或电话号码上，可一键复制。

9. **分配角色和权限** -- 通过分配角色，控制团队中谁可以访问 B1 Admin 的不同部分。请参阅[分配角色](./roles-permissions.md)。

## 开始使用

要访问"人员"部分，请点击 B1 Admin 仪表板左侧边栏中的**人员**。您将看到完整的教会名录，顶部有搜索栏，下方是成员列表。

:::tip
如果您是第一次设置 B1，请先[导入现有成员数据](./importing-data.md)，然后根据需要检查并整理个人资料。
:::
