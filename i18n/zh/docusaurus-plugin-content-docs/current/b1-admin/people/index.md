# 人员

<div class="article-intro">

**人员**部分是你在B1 Admin中教会管理的中心。这是你维护教会目录的地方——搜索成员、添加新人、查看和编辑资料以及追踪家庭。无论你有一个小教会还是大教会,保持人员记录组织是为B1中所有其他功能赋予动力的基础。

</div>

## 你能做什么

以下是人员部分中可用的主要功能的概述：

1. **搜索你的目录** -- 使用快速搜索栏按名字查找任何人,或利用高级过滤器和AI驱动的自然语言搜索来定位你确切需要的人。见[搜索人员](./searching-people.md)和[AI搜索](./ai-search.md)以获取详情。

2. **将搜索查询保存为列表** -- 将任何搜索或过滤保存为命名列表,以便你可以单击一次重新加载它。见[已保存列表](./lists.md)。

3. **查看人口统计** -- 按年龄、性别、婚姻状况、成员身份状况和校园查看会众的直观分解——并点击任何图表片段钻取到这些人。见[人口统计](./demographics.md)。

4. **添加新人** -- 快速向目录添加个人并填写他们的资料详情、联系信息和家庭连接。见[添加人员](./adding-people.md)以获取逐步说明。

5. **批量编辑人员** -- 通过改变他们的成员身份状况、婚姻状况、性别、选择退出偏好或小组成员来一次更新多个人。当对许多个人进行相同更改时这可以节省时间。见[批量编辑](./bulk-editing.md)。

6. **打印你的目录** -- 生成格式化的、可打印的成员目录按家庭分组,包括照片和联系信息。见[打印目录](./print-directory.md)。

7. **导入和导出数据** -- 从CSV文件导入成员数据或从另一个教会管理系统(如Breeze)迁移。你也可以随时将目录导出到CSV。见[导入数据](./importing-data.md)和[导出数据](./exporting-data.md)。

8. **管理资料** -- 查看和编辑每个人的详细资料,包括联系信息、家庭成员、[小组成员](../groups/group-members.md)、[出席历史](../attendance/tracking-attendance.md)、[捐献](../donations/recording-donations.md)和[自定义表单](../forms/creating-forms.md)。悬停在蓝色资料标题中的电子邮件、地址或电话号码上以单击一次复制它。

9. **分配角色和权限** -- 通过分配角色来控制团队中谁可以访问B1 Admin的不同部分。见[分配角色](./roles-permissions.md)。

## 快速开始

要访问人员部分,打开[Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin左上角的搜索栏),展开**人员**,然后点击**人员**。你将看到完整的教会目录,顶部有搜索栏,下方有成员列表。

:::tip
如果你是首次设置B1,首先[导入你现有的成员数据](./importing-data.md)。然后根据需要查看和清理资料。
:::
