# 打印目录

<div class="article-intro">

打印目录功能为教会生成格式化、可打印的成员目录。它按家庭组织成员,包括联系信息和照片,设计用于在标准信纸大小的纸张上打印时看起来专业。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要一个有效的B1 Admin账户,有权查看人员。
- 目录中的人员应该填写了照片和联系信息以获得最佳效果。

</div>

## 打开打印目录

1. 导航到B1 Admin中的**人员**。
2. 点击人员结果卡顶部工具栏中的**打印图标**(打印机图标)。它显示在导出按钮旁边。
3. 打印目录在新浏览器标签中打开并开始加载你的目录数据。
4. 大约1.5秒后,你的浏览器打印对话框将自动出现。

:::tip
目录在单独的标签中打开,以便你可以打印它而无需离开人员页面。打印对话框出现后,标签会自动导航回。
:::

## 包含的内容

打印目录包括教会的所有**活跃成员**。具体来说：

- 具有**不活跃**或**访客**成员资格状态的人员会自动排除。
- 已**选择退出**目录的人员被排除。
- 所有其他人按**家庭**分组。

### 仅打印你的搜索结果

在人员页面上运行搜索后——快速搜索、[高级搜索](./searching-people.md#advanced-search)、[已保存列表](./lists.md)或[AI搜索](./ai-search.md)——打印图标更改为**打印结果**。点击它会打印仅你的结果中的人员的目录,而不是整个教会,使用相同的布局。

打印搜索结果时,上面的成员资格状态过滤器不适用:你搜索的每个人都被包括,即使是访客或不活跃的人。已选择退出目录的人员仍然被排除。要返回打印完整目录,首先清除你的搜索。

## 目录布局

打印目录有两部分:

### 封面

第一页包括:
- 教会名称
- 标题"成员目录"
- 当前年份
- 教会的位置
- 所包含总家庭的计数

### 成员名单

其余页面按姓氏字母顺序列出家庭。每个家庭卡片显示:

- **照片** -- 每个家庭成员的圆形缩略图,下面有他们的名字
- **家庭显示名称** -- 例如"Smith家族"、"John & Jane Doe"或仅是个人的名字
- **地址** -- 街道地址、城市、州和邮政编码
- **电话** -- 住家或手机号码
- **电子邮件** -- 主电子邮件地址
- **生日** -- 格式化为每个家庭成员的单个日期
- **周年纪念** -- 如果记录了

家庭被组织成**字母部分**(A、B、C等),每个字母组前有装饰性部分标题。每行并排出现两个家庭卡片。

## 打印设置

目录为**信纸大小**(8.5" × 11")格式化,边距为0.5英寸。当浏览器打印对话框出现时:

- 将纸张大小保留为**Letter**
- 在浏览器的打印设置中启用**背景图形**(有时称为"打印背景"),如果你想要部分标题以其颜色样式打印
- 建议纵向方向

:::info
目录遵守分页符——家庭卡片和部分标题不会跨页面分割。
:::
