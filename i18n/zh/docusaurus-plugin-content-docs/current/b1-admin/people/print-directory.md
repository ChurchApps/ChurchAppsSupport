# 打印通讯录

<div class="article-intro">

打印通讯录功能会为你的教会生成格式完整、可打印的会员通讯录。它以住户为单位进行整理，包含联络信息与照片，并以标准信纸尺寸打印，效果专业。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要一个有效的 B1 Admin 账户，并具有查看人员的权限。
- 通讯录中的人员最好已填写照片与联络信息，以获得最佳效果。

</div>

## 打开打印通讯录 {#opening-the-print-directory}

1. 在 B1 Admin 中前往 **People**。
2. 点击人员页面标题中的 **Print Directory**。
3. 打印通讯录会在新的浏览器分页中打开，并开始载入你的通讯录资料。
4. 约 1.5 秒后，浏览器的打印对话框会自动出现。

:::tip
通讯录会在独立的分页中打开，因此你无需离开人员页面即可打印。打印对话框关闭后，该分页会切换到人员页面，你可以将其关闭，或继续在该处工作。
:::

## 包含的内容 {#what-gets-included}

打印通讯录包含教会所有**活跃会员**。具体而言：

- 会员状态为 **Inactive**、**Visitor** 或 **Deceased** 的人员会被自动排除。
- 已**退出**通讯录的人员会被排除。
- 其他所有人员都会依**住户**分组。

### 仅打印搜索结果 {#printing-only-your-search-results}

在人员页面执行搜索之后——快速搜索、[进阶搜索](./searching-people.md#advanced-search)、[已保存的名单](./lists.md)，或 [AI 搜索](./ai-search.md)——**Print Directory** 按钮会变为 **Print Results**。点击它会以相同的版面，仅打印结果中的人员通讯录，而非整个教会的通讯录。

打印搜索结果时，上述会员状态的筛选不适用：你所搜索的所有人员都会包含在内，即使是访客或不活跃的人员也一样。已退出通讯录的人员仍会被排除在外。若要重新打印完整的通讯录，请先清除搜索条件。

## 通讯录版面 {#directory-layout}

打印出的通讯录分为两个部分：

### 封面 {#cover-page}

第一页包括：
- 你的教会标志（如果已设置）
- 你的教会名称
- 标题"Member Directory"（会员通讯录）
- 当前年份
- 你教会所在的城市与州
- 打印日期，以及所包含的住户数量

### 会员列表 {#member-listings}

其余各页会依姓氏字母顺序列出住户。每张住户卡片会显示：

- **照片**——每位住户成员的圆形缩图，姓名位于其下方
- **住户显示名称**——例如"The Smith Family"、"John & Jane Doe"，或个人的姓名
- **地址**——街道地址、城市、州与邮政编码
- **电话**——住家电话；若住户中没有人有住家电话，则显示手机号码
- **电子邮件**——主要电子邮件地址
- **生日**——每位成员的名字与生日（月与日）
- **结婚纪念日**——如果有记录

住户会依**字母分区**（A、B、C……）排列，每个字母组之前都有装饰性的分区标题。每一行会并排显示两张住户卡片。

## 打印设置 {#print-settings}

通讯录的格式为**信纸尺寸**（8.5" × 11"），页边距为 0.5 英寸。出现浏览器打印对话框时：

- 请将纸张尺寸保持为 **Letter**
- 如果希望分区标题以其配色样式打印，请在浏览器的打印设置中启用 **Background graphics**（有时称为 "Print backgrounds"）
- 建议使用直向（Portrait）方向

:::info
通讯录会遵守分页设置——住户卡片与分区标题不会被分割到不同的页面上。
:::
