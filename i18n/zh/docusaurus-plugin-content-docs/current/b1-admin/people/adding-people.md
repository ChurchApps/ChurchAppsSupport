# 添加人员

<div class="article-intro">

人员部分是 B1 Admin 的基础 — 这是你教会的成员数据库。其他所有功能（小组、出席、捐献、表单）都链接回人员记录。此指南向你介绍如何向你的数据库添加某人、编辑其详情以及将家庭成员链接到家庭。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要一个活跃的 B1 Admin 帐户，有权限管理人员。如果你不确定你的访问级别，见[角色和权限](roles-permissions.md)。
- 如果你要添加超过几个人，考虑改用[CSV 导入](importing-data.md)工具。

</div>

## 添加一个人

1. 导航到 B1.church Admin 仪表板。
2. 打开左上角的**部分菜单**并选择**人员**。
3. 在右上角点击**添加人**按钮。
4. 填入该人的名字、姓氏和电子邮件地址，然后点击**添加**。

该人的资料页面将打开，准备让你添加更多详情。

:::tip
如果你从另一个教会管理系统迁移，[导入数据](importing-data.md)功能让你从 CSV 文件导入整个目录 — 比逐个添加人员快得多。
:::

## 编辑详情

1. 在该人的资料页面上，点击他们名字旁的**编辑铅笔**。
2. 填入额外信息，例如中间名、成员身份状态、日期、地址、电话号码以及（对于儿童和学生）年级和学校。
3. 点击**保存**以存储个人信息。

资料还包括几个相关信息标签页：

- **笔记** — 添加关于该人的笔记（牧养关怀、跟进等）
- **小组** — 查看和管理[小组成员](../groups/group-members.md)
- **出席** — 查看[出席记录](../attendance/tracking-attendance.md)
- **捐献** — 查看[捐献历史](../donations/recording-donations.md)

## 使用表单

你可以直接从一个人的资料填写自定义表单。这些是你可以按照[创建表单](../forms/creating-forms.md)指南构建的用户定义表单。

1. 在该人的资料上，点击**表单**下拉菜单以选择表单。
2. 点击**添加表单**以打开它。
3. 填写表单详情并点击**保存**。

:::info
链接到一个人资料的表单使用**人员**表单类型。如果你需要一个独立表单（如事件注册），见表单指南中的[独立表单选项](../forms/creating-forms.md)。
:::

:::tip
如果你只需要在人员上追踪一个或两个额外的信息片段 — 一个日期、一个数字、一个是/否答案 — 使用[自定义字段](../settings/custom-fields.md)而不是表单。它们填写更快，并且在高级搜索中可直接搜索。
:::

## 管理家庭

家庭让你将家庭成员链接在一起。这对[签到](../attendance/check-in.md)特别有用，其中父母可以一次为所有儿童签到。

1. 在一个人的资料上，点击家庭名称旁的**编辑铅笔**。
2. 家庭编辑器将打开。为当前人选择**家庭角色**（例如，家长、配偶、儿童）。
3. 点击**添加**以添加另一个家庭成员。
4. 在搜索框中输入该人的名字并点击**搜索**。
5. 当该人出现在搜索结果中时，点击**选择**。
6. 选择他们的家庭角色并点击**保存**以完成家庭设置。
