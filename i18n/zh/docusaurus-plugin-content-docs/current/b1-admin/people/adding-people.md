# 添加人员

<div class="article-intro">

"人员"部分是 B1 Admin 的基础——它是您教会的成员数据库。其他所有功能（小组、考勤、捐款、表单）都与人员记录相关联。本指南将引导您完成添加人员、编辑其详细信息，以及将家庭成员关联到家庭单元的操作。

</div>

<div class="prereqs">
<h4>准备工作</h4>

- 您需要拥有具备人员管理权限的有效 B1 Admin 账户。如果不确定自己的访问权限级别，请参阅[角色与权限](roles-permissions.md)。
- 如果您要添加的人员超过几个，建议改用 [CSV 导入](importing-data.md)工具。

</div>

## 添加一个人员

1. 导航到 B1.church 管理仪表板。
2. 点击左侧边栏中的**人员**。
3. 点击右上角的**添加人员**按钮。
4. 填写该人员的名字、姓氏和电子邮箱，然后点击**添加**。

该人员的个人资料页面会打开，供您继续添加更多详细信息。

:::tip
如果您正在从其他教会管理系统迁移，[导入数据](importing-data.md)功能可以让您从 CSV 文件导入整个名录——比逐个添加人员快得多。
:::

## 编辑详细信息

1. 在该人员的个人资料页面，点击其姓名旁的**编辑铅笔**。
2. 填写更多信息，如中间名、成员身份状态、日期、地址、电话号码，以及（针对儿童和学生）年级和学校。
3. 点击**保存**以存储个人信息。

个人资料还包含几个用于相关信息的标签页：

- **备注** — 添加关于该人员的备注（牧养关怀、跟进事项等）
- **小组** — 查看和管理[小组成员身份](../groups/group-members.md)
- **考勤** — 查看[考勤记录](../attendance/tracking-attendance.md)
- **奉献** — 查看[捐款历史](../donations/recording-donations.md)

## 使用表单

您可以直接从人员的个人资料页面填写自定义表单。这些是您通过遵循[创建表单](../forms/creating-forms.md)指南自行构建的用户自定义表单。

1. 在该人员的个人资料页面，点击**表单**下拉菜单以选择一个表单。
2. 点击**添加表单**将其打开。
3. 填写表单详情并点击**保存**。

:::info
关联到人员个人资料的表单使用**人员**表单类型。如果您需要一个独立表单（例如活动注册），请参阅表单指南中的[独立表单选项](../forms/creating-forms.md)。
:::

:::tip
如果您只需要跟踪一两项额外的人员信息——一个日期、一个数字、一个是/否答案——请使用[自定义字段](../settings/custom-fields.md)而不是表单。填写起来更快，并且可以在高级搜索中直接搜索。
:::

## 管理家庭

家庭功能可以将家庭成员关联在一起。这对[签到](../attendance/check-in.md)特别有用，家长可以一次性为所有孩子签到。

1. 在人员的个人资料页面，点击家庭名称旁的**编辑铅笔**。
2. 家庭编辑器将会打开。为当前人员选择**家庭角色**（例如，户主、配偶、子女）。
3. 点击**添加**以添加另一位家庭成员。
4. 在搜索框中输入该人员的姓名并点击**搜索**。
5. 当该人员出现在搜索结果中时，点击**选择**。
6. 选择其家庭角色并点击**保存**以完成家庭设置。
