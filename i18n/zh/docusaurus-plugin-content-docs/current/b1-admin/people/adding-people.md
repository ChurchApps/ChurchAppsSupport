# 添加人员

<div class="article-intro">

“人员”板块是 B1 Admin 的基础——它是您教会的成员数据库。其他所有功能（群组、出席、奉献、表单）都与人员记录相关联。本指南将引导您将某人添加到数据库、编辑其详细信息，以及将家庭成员关联为家庭。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要一个有权管理人员的 B1 Admin 账户。如果您不确定自己的访问级别，请参见[角色与权限](roles-permissions.md)。
- 如果您要添加的人数超过几个，请考虑使用 [CSV 导入](importing-data.md)工具。

</div>

## 添加人员

1. 进入 B1.church Admin 仪表板。
2. 打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **人员**，然后点击 **人员**。
3. 点击页面标题中的 **添加人员** 按钮。页面将向下滚动到目录下方的 **添加新人员** 表单。
4. 填写人员的 **名字**、**姓氏** 和 **电子邮件**，然后点击 **添加**。

该人员的个人资料页面将会打开，您可以继续添加更多详细信息。

:::tip
如果您正在从其他教会管理系统迁移，[导入数据](importing-data.md)功能可让您从 CSV 文件导入整个通讯录——这比逐个添加人员快得多。
:::

### 重复警告

如果电子邮件地址（或者在使用完整的编辑表单创建人员时，电话号码，或名字 + 姓氏 + 出生日期的组合）与数据库中已有的某人匹配，则会在保存新记录之前弹出 **可能的重复项** 对话框。对话框会列出每位匹配人员及其电子邮件、电话和出生日期，方便您进行比较。

- 点击匹配项旁边的 **使用现有记录**，即可使用该人员的记录，而不创建新记录。
- 点击 **仍然创建**，即使发现了可能的匹配项，也仍然添加新人员。

只有在创建全新的人员时才会检查重复项——编辑现有记录永远不会触发此检查。它仅用于防止新增重复记录；不会合并已经存在的两条记录。

## 编辑详细信息 {#editing-details}

1. 在人员的个人资料页面，点击左侧联系方式下方的 **编辑** 按钮。
2. 在 **个人详细信息** 表单中，填写更多信息，例如中间名、会员状态（**访客**、**来宾**、**常规出席者**、**成员**、**员工**、**非活跃** 或 **已故**）、日期、地址、电话号码，以及（适用于儿童和学生）年级和学校。
3. 点击 **保存** 以存储个人信息。

个人资料的左侧显示人员的照片、姓名、会员状态、联系方式、任何[自定义字段](../settings/custom-fields.md)的值以及其所属家庭。点击照片即可更改。在 **编辑** 按钮下方还有一些其他操作：**工作流**（将该人员添加到某个[工作流](../serving/workflows.md)）、**合并**、**导出** 和 **导出数据**。

个人资料的其余部分显示每类相关信息的摘要部分：

- **出席** —— 显示该人员在最近几周中的出席情况以及最近的到访记录。点击 **所有年份** 可查看其完整的到访历史，包括校区、礼拜、礼拜时间、群组，以及 **已签到** 列（显示自助签到机的签到时间；没有自助签到记录的到访显示为破折号），或点击 **打印** 进行打印。若需了解全教会的趋势而非单个人员的历史，请参见[跟踪出席](../attendance/tracking-attendance.md)
- **奉献** —— 显示今年的奉献记录，包括对不可抵扣基金的捐款。点击 **所有年份** 查看其完整的[奉献历史](../donations/recording-donations.md)，或点击 **记录一笔奉献** 登记新的奉献。如果您的教会开启了[奉献隐私](../settings/church-settings.md#giving-privacy)，金额将保持隐藏，直到您点击 **显示奉献**
- **群组** —— 列出该人员的[群组成员资格](../groups/group-members.md)
- **备注** —— 显示关于该人员的最近备注（牧养关怀、跟进事项等）。点击 **所有备注** 以阅读和添加备注
- **表单** —— 列出该人员的表单以及每份表单是否已提交（参见下方的[使用表单](#working-with-forms)）

打开上述任一完整视图后，点击个人资料顶部带有该人员姓名的 **返回** 链接，即可返回个人资料页面。

## 向人员发送电子邮件

如果该人员已登记电子邮件地址，个人资料左侧的联系方式下方会出现 **电子邮件** 按钮。

1. 在人员的个人资料页面，点击 **电子邮件**。
2. 随即打开一个以该人员姓名为标题的 **电子邮件** 对话框，其中 **收件人** 显示该人员的地址。
3. 可选：从 **加载模板（可选）** 中选择已保存的模板。
4. 输入 **主题** 并撰写邮件内容。
5. 点击 **发送电子邮件**。

若要改为在您自己的邮件程序中撰写邮件，请点击 **在我的电子邮件应用中打开**。

:::info
通过 B1 发送邮件使用与群组电子邮件相同的审批和每日限额。如果您的教会尚未获得批准，对话框会要求您申请审核——在此期间，您仍可点击 **在我的电子邮件应用中打开**。请参见[为教会开启群组电子邮件](../groups/group-members.md#turning-on-group-email-for-your-church)。没有编辑群组成员权限的用户在点击 **电子邮件** 时将直接进入其电子邮件应用。
:::

## 使用表单 {#working-with-forms}

您可以直接从人员的个人资料中填写自定义表单。这些是用户自定义的表单，您可以按照[创建表单](../forms/creating-forms.md)指南进行构建。

1. 在人员的个人资料页面中找到 **表单** 部分。该部分列出每份表单，并显示其是否已 **提交** 或 **未提交**。
2. 点击表单名称以打开它（或点击 **所有表单** 查看完整列表）。
3. 点击表单上的 **编辑图标**（铅笔），填写详细信息，然后点击 **保存**。

表单提交后，点击其旁边的 **打印图标**，即可打印该人员填写的答案。

如果某份提交被错误地关联到了其他人员，请点击其旁边的 **更改人员** 图标（两个箭头），将其移给他人或取消关联。参见[更改提交的人员](../forms/managing-submissions.md#changing-the-person-on-a-submission)。

:::info
关联到人员个人资料的表单使用 **人员** 表单类型。如果您需要独立的表单（例如活动报名），请参见表单指南中的[独立表单选项](../forms/creating-forms.md)。
:::

:::tip
如果您只需要记录人员的一两项额外信息——例如日期、数字或是/否答案——请使用[自定义字段](../settings/custom-fields.md)，而不是表单。自定义字段填写更快，并且可以直接在高级搜索中搜索。
:::

## 管理家庭 {#managing-households}

家庭功能可让您将家庭成员关联在一起。这在[签到](../attendance/check-in.md)时特别有用，家长可以一次为所有子女办理签到。

1. 在人员的个人资料页面，点击左侧 **家庭** 标题旁的 **编辑**。
2. 家庭编辑器将打开。为当前人员选择 **家庭角色**（例如户主、配偶、子女、其他）。
3. 点击 **添加** 图标，添加另一位家庭成员。
4. 在 **添加家庭成员** 下，于搜索框中输入人员姓名，然后按 **Enter** 或点击搜索图标。（在您输入之前，会显示一份简短的 **最近的人员** 列表。）
5. 当该人员出现在搜索结果中时，点击其姓名或旁边的添加图标。
6. 选择其家庭角色，然后点击 **保存** 以完成家庭设置。
