# 添加人员

<div class="article-intro">

人员部分是B1 Admin的基础——这是您的教会成员数据库。每项其他功能（小组、出席、捐赠、表单）都与人员记录相关。本指南将引导您向数据库添加某人、编辑他们的详细信息并将家庭成员链接到家庭中。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 您需要具有管理人员权限的活跃B1 Admin账户。如果您不确定您的访问级别，请查看[角色和权限](roles-permissions.md)。
- 如果您添加超过少数人，请考虑使用[CSV导入](importing-data.md)工具代替。

</div>

## 添加人员

1. 导航到B1.church Admin仪表板。
2. 打开左上角的**部分菜单**并选择**人员**。
3. 点击右上角的**添加人员**按钮。
4. 填写人员的名字、姓氏和电子邮件地址，然后点击**添加**。

人员的个人资料页面将打开，准备好让您添加更多详细信息。

:::tip
如果您从另一个教会管理系统迁移，[导入数据](importing-data.md)功能让您从CSV文件将您的整个目录导入——比一次一个地添加人员快得多。
:::

### 重复警告

如果电子邮件地址（或在从完整编辑表单创建人员时，电话号码或匹配的名字+姓氏+出生日期）与已在数据库中的某人匹配，**可能重复**对话框会在保存新记录之前出现。它列出每个匹配的人员及其电子邮件、电话和出生日期，以便您可以比较。

- 点击匹配旁边的**使用现有**以使用该人员的记录而不是创建新记录。
- 点击**仍然创建**以添加新人员，即使找到了可能的匹配。

这仅在您创建全新人员时检查重复——编辑现有记录永远不会触发它。它仅防止新重复；它不会合并已存在的两条记录。

## 编辑详细信息

1. 在人员的个人资料页面上，点击他们名字旁边的**编辑铅笔**。
2. 填写其他信息，例如中间名、成员资格状态、日期、地址、电话号码以及（对于儿童和学生）年级和学校。
3. 点击**保存**以存储个人信息。

个人资料还包括几个用于相关信息的标签页：

- **笔记** ——添加有关人员的笔记（牧灵关怀、跟进等）
- **小组** ——查看和管理[小组成员](../groups/group-members.md)
- **出席** ——查看此人的个人访问历史记录，包括校园、服务、服务时间、小组和**签到**列，其中包含亭台签到时间（对于无亭台签到的记录访问显示为短划线）。对于教会范围的趋势而非一个人的历史记录，请查看[跟踪出席](../attendance/tracking-attendance.md)
- **捐赠** ——查看[捐赠历史](../donations/recording-donations.md)

## 使用表单

您可以直接从人员的个人资料中填出自定义表单。这些是用户定义的表单，您可以按照[创建表单](../forms/creating-forms.md)指南构建。

1. 在人员的个人资料上，点击**表单**下拉列表以选择表单。
2. 点击**添加表单**以打开它。
3. 填写表单详细信息并点击**保存**。

提交表单后，点击它旁边的**打印图标**以打印该人员的填入答案。

:::info
链接到人员个人资料的表单使用**人员**表单类型。如果您需要独立表单（如活动注册），请查看表单指南中的[独立表单选项](../forms/creating-forms.md)。
:::

:::tip
如果您只需要跟踪人员上的一两个额外信息——日期、数字、是/否答案——使用[自定义字段](../settings/custom-fields.md)而不是表单。它们填起来更快，并且可以在高级搜索中直接搜索。
:::

## 管理家庭

家庭让您将家庭成员链接在一起。这对于[签到](../attendance/check-in.md)特别有用，其中父母可以一次性签到他们的所有孩子。

1. 在人员的个人资料上，点击家庭名称旁边的**编辑铅笔**。
2. 家庭编辑器将打开。为当前人员选择**家庭角色**（例如，主人、配偶、孩子）。
3. 点击**添加**以添加另一个家庭成员。
4. 在搜索框中输入人员的名称并点击**搜索**。
5. 当人员出现在搜索结果中时，点击**选择**。
6. 选择他们的家庭角色并点击**保存**以完成家庭设置。
