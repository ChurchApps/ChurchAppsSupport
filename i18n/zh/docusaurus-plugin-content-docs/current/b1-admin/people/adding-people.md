# 添加人员

<div class="article-intro">

人员部分是B1 Admin的基础——这是教会的成员数据库。每项其他功能(小组、出席、捐赠、表单)都与人员记录相关。本指南将引导你向数据库添加某人、编辑他们的详细信息并将家庭成员链接到家庭中。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要具有管理人员权限的活跃B1 Admin账户。如果你不确定你的访问级别,请查看[角色和权限](roles-permissions.md)。
- 如果你添加超过少数人,请考虑使用[CSV导入](importing-data.md)工具代替。

</div>

## 添加人员

1. 导航到B1.church Admin仪表板。
2. 打开[Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)(左上角的搜索栏),展开**人员**,然后点击**人员**。
3. 点击页面标题中的**添加人员**按钮。页面会向下滚动到目录下方的**添加新人员**表单。
4. 填写人员的**名字**、**姓氏**和**电子邮件**,然后点击**添加**。

人员的个人资料页面将打开,准备好让你添加更多详细信息。

:::tip
如果你从另一个教会管理系统迁移,[导入数据](importing-data.md)功能让你从CSV文件将整个目录导入——比一次一个地添加人员快得多。
:::

### 重复警告

如果电子邮件地址(或在从完整编辑表单创建人员时,电话号码或匹配的名字+姓氏+出生日期)与已在数据库中的某人匹配,**可能重复**对话框会在保存新记录之前出现。它列出每个匹配的人员及其电子邮件、电话和出生日期,以便你可以比较。

- 点击匹配旁边的**使用现有**以使用该人员的记录而不是创建新记录。
- 点击**仍然创建**以添加新人员,即使找到了可能的匹配。

这仅在你创建全新人员时检查重复——编辑现有记录永远不会触发它。它仅防止新重复;它不会合并已存在的两条记录。

## 编辑详细信息

1. 在人员的个人资料页面上，点击其联系方式下方左侧的**编辑**按钮。
2. 在**个人详细信息**表单中填写其他信息，例如中间名、成员资格状态（**访客**、**来宾**、**常规出席者**、**成员**、**员工**、**不活跃**或**已故**）、日期、地址、电话号码以及（对于儿童和学生）年级和学校。
3. 点击**保存**以存储个人信息。

个人资料左侧显示人员的照片、姓名、成员资格状态、联系方式、任何[自定义字段](../settings/custom-fields.md)的值以及其家庭。点击照片可更改它。在**编辑**按钮下方还有几个操作：**工作流**（将人员添加到[工作流](../serving/workflows.md)）、**合并**、**导出**和**导出数据**。

个人资料的其余部分为每类相关信息显示摘要部分：

- **出席** — 显示此人在最近几周中参加了哪些周，以及其最近的访问。点击**所有年份**查看其完整访问历史记录，包括校园、敬拜、敬拜时间、小组和**签到**列（其中包含亭台签到时间，对于无亭台签到的记录访问显示为短划线），或点击**打印**进行打印。对于教会范围的趋势而非一个人的历史记录，请查看[追踪出席](../attendance/tracking-attendance.md)
- **捐赠** — 显示今年的捐款。点击**所有年份**查看其完整[捐赠历史](../donations/recording-donations.md)，或点击**记录捐款**来记录新的捐款
- **小组** — 列出此人的[小组成员资格](../groups/group-members.md)
- **笔记** — 显示关于此人的近期笔记（牧灵关怀、跟进等）。点击**所有笔记**以阅读和添加笔记
- **表单** — 列出此人的表单以及每个表单是否已提交（见下文[使用表单](#working-with-forms)）

打开这些完整视图之一时，点击页面顶部人员姓名的**返回到**链接即可返回个人资料。

## 给人员发送电子邮件

如果人员在文件中有电子邮件地址,其联系方式下方的左侧会出现**电子邮件**按钮。

1. 在人员的个人资料上,点击**电子邮件**。
2. 一个标有人员名字的**电子邮件**对话框打开,显示**发送至**和该人的地址。
3. 可选地从**加载模板(可选)**中选择一个保存的模板。
4. 输入**主题**并撰写消息。
5. 点击**发送电子邮件**。

要改为在你自己的邮件程序中编写消息,点击**在我的电子邮件应用中打开**。

:::info
从B1发送使用与小组电子邮件相同的批准和每日限制。如果你的教会还未被批准,对话框会要求你请求审查——与此同时,你仍然可以点击**在我的电子邮件应用中打开**。见[为教会开启小组电子邮件](../groups/group-members.md#turning-on-group-email-for-your-church)。没有权限编辑小组成员的用户在点击**电子邮件**时直接进入他们的电子邮件应用。
:::

## 使用表单 {#working-with-forms}

你可以直接从人员的个人资料中填出自定义表单。这些是用户定义的表单,你可以按照[创建表单](../forms/creating-forms.md)指南构建。

1. 在人员的个人资料上,找到**表单**部分。它列出每个表单,以及其是否已**提交**或**未提交**。
2. 点击表单名称以打开它(或点击**所有表单**查看完整列表)。
3. 点击表单上的**编辑图标**(铅笔),填写表单详细信息并点击**保存**。

提交表单后,点击它旁边的**打印图标**以打印该人员的填入答案。

如果提交最终出现在错误的人员上,点击它旁边的**更改人员**图标(两个箭头)以将其移动到其他人或取消链接。见[更改提交上的人员](../forms/managing-submissions.md#changing-the-person-on-a-submission)。

:::info
链接到人员个人资料的表单使用**人员**表单类型。如果你需要独立表单(如活动注册),见表单指南中的[独立表单选项](../forms/creating-forms.md)。
:::

:::tip
如果你只需要追踪人员上的一两个额外信息——日期、数字、是/否答案——使用[自定义字段](../settings/custom-fields.md)而不是表单。它们填起来更快,并且可以在高级搜索中直接搜索。
:::

## 管理家庭

家庭让你将家庭成员链接在一起。这对于[签到](../attendance/check-in.md)特别有用,其中父母可以一次性签到他们的所有孩子。

1. 在人员的个人资料上,点击左侧**家庭**标题旁边的**编辑**。
2. 家庭编辑器将打开。为当前人员选择**家庭角色**(例如,户主、配偶、孩子、其他)。
3. 点击**添加**图标以添加另一个家庭成员。
4. 在**添加家庭成员**下,在搜索框中输入人员的名称,然后按**回车**或点击搜索图标。(输入之前,会显示一个简短的**最近的人员**列表。)
5. 当人员出现在结果中时,点击其名称或其旁边的添加图标。
6. 选择他们的家庭角色并点击**保存**以完成家庭设置。
