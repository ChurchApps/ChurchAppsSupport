# 导出数据

<div class="article-intro">

B1 Admin 允许您导出教会数据，以便在电子表格中使用、与团队共享或保留备份。无论您需要的是快速获取姓名和电子邮件列表，还是完整的数据库导出，都有相应的选项可供选择。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要一个有效的 B1 Admin 账户，并拥有查看要导出数据的权限。如果您不确定自己的访问级别，请参阅[角色与权限](roles-permissions.md)。
- 要进行完整的数据库导出，您需要有权访问**设置**区域。

</div>

## 从人员页面导出

导出通讯录最快的方式是直接从**人员**页面进行：

1. 打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开**人员**，然后点击**人员**。
2. 使用搜索栏或筛选器缩小要导出的结果范围（或保持不筛选以导出所有人）。有关筛选的提示，请参阅[搜索人员](searching-people.md)。
3. 点击人员页面标题中的**导出**按钮。
4. 一个 CSV 文件会下载到您的电脑，其中包含当前结果中的人员，包括其姓名、联系信息、地址及其他标准字段。

:::tip
导出内容包括当前结果中的所有人。请先进行搜索、加载[已保存的列表](./lists.md)，或使用**高级**搜索，以便只导出您需要的人员。
:::

## 从设置中进行完整数据导出 {#full-data-export-from-settings}

若要完整导出您所有的 B1 数据（不仅仅是人员），请使用设置中的导出工具：

1. 在 Jump 菜单中，选择**设置 > 设置**。
2. 点击左侧设置菜单顶部、教会名称下方的**导入/导出**链接。
3. 从**数据源**下拉菜单中选择 **B1 数据库**。
4. 查看数据预览，然后点击**继续到目标**。
5. 选择 **B1 导出 Zip** 作为导出目标。
6. 监控导出进度，直到所有项目都显示绿色勾号。
7. 导出文件将自动下载。在您的下载文件夹中查找 `B1Export` 文件。
8. 解压该文件，即可访问各个 CSV 文件（例如 `people.csv`），并可在 Excel、Google Sheets 或 Numbers 中打开。

:::info
B1 导出 Zip 是您教会数据的完整备份。它包含：

- 人员（包括照片）和家庭，包括家庭接送联系人
- 分堂、服务和服务时间
- 小组和小组成员
- 奉献基金和捐款，包括分配到多个基金的奉献
- 考勤
- 表单、问题、提交内容和答案
- 自定义字段及其值
- 已保存的人员列表

如果在导出过程中无法下载或读取某人的照片，则会跳过该照片，导出将继续进行，不包含该照片。

若要还原数据，请选择 **B1 导入 Zip** 作为源，并选择 **B1 数据库**作为目标（参见[导入数据](./importing-data.md)）。家庭、接送联系人和已保存的列表会随人员一起重建。已保存列表的筛选条件会指向已还原的小组、基金、分堂和自定义字段。
:::

## 导出小组数据

您还可以导出各个小组的成员列表。在**小组**页面中，打开某个小组并点击**下载图标**，即可导出该小组的成员列表。更多详情请参阅[小组成员](../groups/group-members.md)。

:::info
导出的 CSV 文件可在所有主流电子表格应用中使用，包括 Microsoft Excel、Google Sheets 和 Apple Numbers。
:::
