# 导出数据

<div class="article-intro">

B1 Admin 允许您导出教会数据，以便在电子表格中使用、与团队共享或进行备份。无论您需要的是简单的姓名和邮箱列表，还是完整的数据库导出，都有相应的选项可以满足您的需求。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要一个拥有查看所需导出数据权限的 B1 Admin 账户。如果您不确定自己的访问权限级别，请参阅[角色与权限](roles-permissions.md)。
- 若要进行完整的数据库导出，您需要有权访问**设置**区域。

</div>

## 从人员页面导出

从**人员**页面导出名录是最快的方式：

1. 打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **People**，然后点击 **People**。
2. 使用搜索栏或筛选条件缩小您要导出的结果范围（或保持不筛选以导出所有人）。有关筛选技巧，请参阅[搜索人员](searching-people.md)。
3. 点击人员页面标题中的 **Export** 按钮。
4. 一个 CSV 文件会下载到您的电脑，其中包含当前结果中的人员，包括姓名、联系方式、地址和其他标准字段。

:::tip
导出内容包括当前结果中的所有人。请先进行搜索、加载[已保存列表](./lists.md)，或使用 **Advanced** 搜索，以便只导出您需要的人员。
:::

## 从设置中进行完整数据导出

如需完整导出您所有的 B1 数据（不仅限于人员），请使用设置中的导出工具：

1. 在快速跳转菜单中，选择 **Settings > Settings**。
2. 点击左侧设置菜单顶部教会名称下方的 **Import/Export** 链接。
3. 在 **Data Source** 下拉菜单中选择 **B1 Database**。
4. 查看数据预览，然后点击 **Continue to Destination**。
5. 选择 **B1 Export Zip** 作为导出目标。
6. 监控导出进度，直到所有项目都显示绿色对勾。
7. 导出文件会自动下载。请在下载文件夹中查找 `B1Export` 文件。
8. 解压文件，即可访问各个 CSV 文件（例如 `people.csv`），并在 Excel、Google Sheets 或 Numbers 中打开。

:::info
B1 导出 Zip 是您教会数据的完整备份。它包含：

- 人员（包括照片）和家庭，包括家庭接送联系人
- 校区、服事和礼拜时间
- 小组和小组成员
- 基金和奉献，包括分拆到多个基金的奉献
- 考勤
- 表单、问题、提交内容和答案
- 自定义字段及其值
- 已保存的人员列表

要恢复数据，请选择 **B1 Import Zip** 作为来源，并选择 **B1 Database** 作为目标（请参阅[导入数据](./importing-data.md)）。家庭、接送联系人和已保存的列表会与人员一同重建。已保存列表的筛选条件会指向已恢复的小组、基金、校区和自定义字段。
:::

## 导出小组数据

您也可以导出各个小组的成员名单。在**小组**页面中打开某个小组，然后点击**下载图标**即可导出该小组的成员名单。详情请参阅[小组成员](../groups/group-members.md)。

:::info
导出的 CSV 文件可在所有主流电子表格应用中使用，包括 Microsoft Excel、Google Sheets 和 Apple Numbers。
:::
