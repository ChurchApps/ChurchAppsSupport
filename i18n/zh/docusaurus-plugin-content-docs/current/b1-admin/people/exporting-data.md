# 导出数据

<div class="article-intro">

B1 Admin 让你导出你的教会数据，以便你可以在电子表格中使用它、与你的团队共享或保持备份。无论你是需要快速的名字和电子邮件列表还是完整的数据库导出，都有适合你需求的选项。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要一个活跃的 B1 Admin 帐户，有权限查看你想要导出的数据。如果你不确定你的访问级别，见[角色和权限](roles-permissions.md)。
- 对于完整的数据库导出，你需要访问**设置**区域。

</div>

## 从人员页面导出

从**人员**页面导出你的目录的最快方式：

1. 打开左上角的**部分菜单**并选择**人员**。
2. 使用搜索栏或过滤器缩小你想要导出的结果范围（或保留未过滤以导出所有人）。见[搜索人员](searching-people.md)以获取过滤提示。
3. 使用**列选择器**选择你想在导出中包含的列（例如，名字、电子邮件、电话、地址）。
4. 点击**导出**按钮。
5. CSV 文件会下载到你的计算机，包含表中当前显示的数据。

:::tip
在导出前自定义你的列。CSV 文件将包括你可见的确切列，所以你可以调整导出以满足你的需求而无需之后编辑文件。
:::

## 从设置进行完整数据导出

要导出所有 B1 数据（不仅仅是人员），使用设置中的导出工具：

1. 打开左上角的**部分菜单**并选择**设置**。
2. 在顶部导航中点击**导入/导出**。
3. 从**数据源**下拉菜单中选择**B1 数据库**。
4. 查看数据预览并点击**继续到目标**。
5. 选择**B1 导出 Zip** 作为导出目标。
6. 监视导出进度直到所有项目显示绿色复选标记。
7. 导出文件会自动下载。在你的下载文件夹中查找 `B1Export` 文件。
8. 解压文件以访问个人 CSV 文件（如 `people.csv`），你可以在 Excel、Google Sheets 或 Numbers 中打开。

:::info
完整数据导出包括人员、小组、捐献、出席等等 — 你 B1 数据库中的所有内容。这也是创建你的教会记录定期备份的很好方式。
:::

## 导出小组数据

你也可以为个人小组导出成员列表。从**小组**页面，打开小组并点击**下载图标**导出该小组的成员列表。见[小组成员](../groups/group-members.md)以获取更多详情。

:::info
导出的 CSV 文件适用于所有主要电子表格应用程序，包括 Microsoft Excel、Google Sheets 和 Apple Numbers。
:::
