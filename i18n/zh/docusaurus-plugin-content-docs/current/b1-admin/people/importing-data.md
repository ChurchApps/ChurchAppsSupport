# 导入数据

<div class="article-intro">

B1 转移工具使您可以轻松地将现有数据引入 B1，无论您是从电子表格开始新鲜、从另一个教会管理平台迁移还是导入捐赠记录。它也可以随时用于导出或备份您的数据。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要一个有效的 B1Admin 帐户，有权访问**设置**。
- 在开始之前，从您以前的系统准备好您的数据导出。
- 此工具适用于初始数据迁移。如果您已经使用 B1 一段时间，再次导入可能会创建重复记录。

</div>

## 访问转移工具

1. 登录**B1Admin**。
2. 打开左上角的**部分菜单**（带小箭头的部分名称）并选择**设置**。
3. 单击页面标题右上方的**导入/导出**按钮。
4. 这将在新标签中打开**B1 转移**工具，网址为 [transfer.b1.church](https://transfer.b1.church)。

转移工具通过四个步骤指导您：源、预览、目标和运行。

---

## 第 1 步 - 选择您的源

选择您的数据来自何处。有七个选项：

- **B1 数据库** — 直接从您现有的 B1 教会中提取数据。适用于进行备份或将数据转换为另一种格式。您必须登录才能使用此选项。
- **B1 导入 Zip** — B1 自己格式的 zip 文件。这主要用于恢复以前的 B1 导出。
- **Breeze 导入 Zip** — 包含来自 Breeze ChMS 的导出文件的 zip 文件。
- **Planning Center Zip** — 从 Planning Center 导出的 zip 或 CSV 文件。
- **自定义 CSV / Excel** — 任何包含人员数据的 CSV 或 Excel 文件。上传后，您将在导入继续之前将您的列映射到 B1 字段。
- **Tithe.ly CSV** — 来自 Tithe.ly 的人员或捐赠导出文件（接受 CSV 或 Excel 格式）。
- **CCB / Pushpay CSV** — 来自 Church Community Builder 或 Pushpay 的人员或捐赠导出 CSV。

您可以将文件拖放到上传区域，或单击浏览它。

---

## 第 1b 步 - 映射字段（仅限自定义 CSV / Excel）

如果您选择了**自定义 CSV / Excel**，上传文件后，工具将显示字段映射屏幕，然后再转移到预览。

您文件中的每一列都列在一个样本值旁边。对于每列，使用下拉菜单选择匹配的 B1 字段。该工具将自动检测常见列名，如"名字"、"电子邮件"或"邮政编码"，但您应该查看每一行并更正它遗漏的任何内容。

可用的 B1 字段包括：

- 名字、姓氏、中间名、昵称、显示名称、标题/前缀、后缀
- 电子邮件、住家电话、手机、工作电话
- 地址行 1、地址行 2、城市、州、邮政编码
- 出生日期、性别、婚姻状况、成员资格状况
- 家庭/家族名称
- 小组名称 — 按名称将人员分配给小组
- **表单答案（自定义字段）** — 将该列的值保存为附加到人员记录的自定义字段。如果您使用此选项，您将被要求给表单命名。

您不想导入的列可以设置为**(跳过)**。在继续之前，必须至少映射一个名称字段（名字或姓氏）。

单击**确认映射和导入**以进入预览。

---

## 第 2 步 - 预览您的数据

上传后，该工具显示所有将被导入的内容的预览。使用标签查看每种数据类型：

- **人员** — 按家庭列出，如包含则带有照片。
- **小组** — 按校区、服务、时间和类别组织。
- **出席** — 会议日期、小组和访问计数。
- **捐赠** — 批次、基金、捐赠者和金额。
- **表单** — 表单名称和内容类型。

在继续之前仔细查看此项。如果某些东西看起来不对，请单击**重新开始**并更正您的源文件。

---

## 第 3 步 - 选择您的目标

选择您想要数据去的位置：

- **B1 数据库** — 直接导入到您的教会的 B1 数据库。选择此后，该工具将显示要添加的记录的最终计数。单击**开始转移**确认。
- **B1 导出 Zip** — 将您的数据下载为 B1 格式的 zip 文件。适用于备份。
- **Breeze 导出 Zip** — 将您的数据转换为 Breeze 格式。
- **Planning Center Zip** — 将您的数据转换为 Planning Center 格式。

:::warning
源和目标不能是同一格式。如果它们匹配，该工具将警告您以防止意外重复。
:::
