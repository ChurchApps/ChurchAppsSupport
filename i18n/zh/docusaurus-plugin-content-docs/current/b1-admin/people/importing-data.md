# 导入数据

<div class="article-intro">

B1 Transfer 工具可以轻松地将您现有的数据导入 B1，无论您是从电子表格开始全新设置，还是从其他教会管理平台迁移，抑或是导入捐献记录。它也可以随时用于导出或备份您的数据。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要一个拥有**设置**访问权限的有效 B1 Admin 账户。
- 在开始之前，请先从之前的系统中导出数据并准备好。
- 此工具适用于初始数据迁移。如果您已经使用 B1 一段时间，再次导入可能会产生重复记录。

</div>

## 访问转移工具 {#accessing-the-transfer-tool}

1. 登录 **B1 Admin**。
2. 打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**设置**，然后点击**设置**。
3. 点击左侧设置菜单顶部、教会名称下方的**导入/导出**链接。
4. 这将在新标签页中打开 **B1 Transfer** 工具，网址为 [transfer.b1.church](https://transfer.b1.church)。

转移工具会引导您完成四个步骤：来源、预览、目标和运行。

---

## 第 1 步 - 选择来源 {#step-1---choose-your-source}

选择您的数据来源。共有七个选项：

- **B1 数据库** — 直接从您现有的 B1 教会中提取数据。适用于备份或将数据转换为其他格式。使用此选项必须已登录。
- **B1 导入 Zip** — B1 自有格式的 zip 文件。主要用于还原之前的 B1 导出。
- **Breeze 导入 Zip** — 包含从 Breeze ChMS 导出文件的 zip 文件。
- **Planning Center Zip** — 从 Planning Center 导出的 zip 或 CSV 文件。
- **自定义 CSV / Excel** — 任何包含人员数据的 CSV 或 Excel 文件。上传后，在导入继续之前，您需要将列映射到 B1 字段。
- **Tithe.ly CSV** — 从 Tithe.ly 导出的人员或捐献文件（接受 CSV 或 Excel 格式）。
- **CCB / Pushpay CSV** — 从 Church Community Builder 或 Pushpay 导出的人员或捐献 CSV 文件。

您可以将文件拖放到上传区域，也可以点击后浏览选择文件。

---

## 第 1b 步 - 映射字段（仅限自定义 CSV / Excel） {#step-1b---map-your-fields-custom-csv--excel-only}

如果您选择了**自定义 CSV / Excel**，上传文件后，工具会在进入预览之前显示字段映射界面。

文件中的每一列都会与一个示例值一同列出。对于每一列，请使用下拉菜单选择匹配的 B1 字段。工具会自动识别常见的列名，例如“First Name”“Email”或“Zip Code”，但您应检查每一行，并更正工具遗漏的内容。

可用的 B1 字段包括：

- 名字、姓氏、中间名、昵称、显示名称、称谓/前缀、后缀
- 电子邮件、家庭电话、手机、工作电话
- 地址第一行、地址第二行、城市、州/省、邮政编码
- 出生日期、结婚纪念日、性别、婚姻状况、会员状态
- 家庭/家族名称
- 组名称 — 按名称将人员分配到组
- **自定义字段（按名称匹配）** — 将该列保存到教会的[自定义人员字段](../settings/custom-fields.md)之一中。将出现一个 **B1 字段名称**框，并以列标题填充。请将其更改为 B1 中该字段的确切名称（大小写不影响匹配）。
- **表单回答（自定义字段）** — 将该列的值保存为附加在人员记录上的自定义字段。如果使用此选项，系统会要求您为表单命名。

日期可以是 `9/17/1994` 等常见格式，并会自动转换。对于自定义字段，是/否字段接受 Yes、No、Y、N、True、False、1 和 0 等值，多选字段则接受选项文本或其值。

:::info
请在导入前先在 B1 Admin 中创建自定义人员字段。导入完成后，**自定义字段**步骤会列出与任何 B1 字段都不匹配的列名，并统计不符合字段类型的值。这些值会被跳过，其余的导入仍会正常完成。
:::

不需要导入的列可以设置为**（跳过）**。在继续之前，必须至少映射一个姓名字段（名字或姓氏）。

点击**确认映射并导入**以进入预览。

---

## 第 2 步 - 预览数据 {#step-2---preview-your-data}

上传后，工具会显示将要导入的所有内容的预览。使用选项卡查看每种数据类型：

- **人员** — 按家庭列出，如包含照片则一并显示。
- **组** — 按校区、场次、时间和类别整理。
- **出勤** — 场次日期、组和到访次数。
- **捐献** — 批次、基金、捐赠人和金额。
- **表单** — 表单名称和内容类型。

请仔细检查。如果有什么不对，请点击**重新开始**，并更正您的源文件。

---

## 第 3 步 - 选择目标 {#step-3---choose-your-destination}

选择数据的去向：

- **B1 数据库** — 直接导入您教会的 B1 数据库。选择此项后，工具会显示将要添加的记录的最终数量。点击**开始转移**以确认。
- **B1 导出 Zip** — 将您的数据下载为 B1 格式的 zip 文件。适用于备份。
- **Breeze 导出 Zip** — 将您的数据转换为 Breeze 格式。
- **Planning Center Zip** — 将您的数据转换为 Planning Center 格式。

:::warning
来源和目标不能是相同的格式。如果两者相同，工具会发出警告，以防止意外重复。
:::

---

## 第 4 步 - 运行 {#step-4---run}

工具会处理转移，并显示每个步骤的进度：

- 校区、场次和时间
- 人员
- 照片
- 组和组成员
- 捐献
- 出勤
- 表单、问题、回答和表单提交
- 自定义字段（如果您映射了任何自定义字段列）
- 压缩（仅适用于 zip 文件目标）

当目标为 **B1 数据库**时，进度卡片标题为**导入进度**，完成时会显示**导入完成！**（或**导入已完成但有错误**）。对于 zip 文件目标，相同的消息会改为显示**导出**。

:::warning
转移进行期间请勿关闭浏览器。请等待所有步骤都显示为已完成。
:::

---

## 准备 Breeze 导入 Zip {#preparing-a-breeze-import-zip}

1. 在 Breeze 中，进入**设置**，然后点击左侧边栏中的**导出**。
2. 分别导出三个文件：**People**、**Tags** 和 **Contributions**。
3. 选中全部三个文件，右键单击，并将它们压缩为一个 zip 文件。
   - 在 Mac 上：选择文件，右键单击，然后选择**压缩**。
   - 在 PC 上：选择文件，右键单击，选择**发送到**，然后选择**压缩(zipped)文件夹**。
4. 在第 1 步中，使用 **Breeze 导入 Zip** 选项上传 zip 文件。

Breeze 导入会自动转移人员、组（标签）和捐赠记录。

---

## 准备 Planning Center 导出文件 {#preparing-a-planning-center-export}

1. 登录 Planning Center，并打开 **People** 产品。
2. 在左侧边栏中点击 **Lists**，并创建一个包含您想要导入的所有人员的列表。（如果您已经有一个包含整个会众的列表，请直接使用该列表。）
3. 打开列表，使用其**导出**选项将人员下载为 **CSV** 文件。请包含您想保留的字段——姓名、电子邮件、电话、地址、出生日期、性别和会员状态都会映射到 B1。
4. 如果 Planning Center 提供了多个文件，请全部选中，右键单击，并将它们压缩为一个 zip 文件。
   - 在 Mac 上：选择文件，右键单击，然后选择**压缩**。
   - 在 PC 上：选择文件，右键单击，选择**发送到**，然后选择**压缩(zipped)文件夹**。
5. 在第 1 步中，使用 **Planning Center Zip** 选项上传 CSV 或 zip 文件。

上传后，请继续进入预览，并在运行导入之前确认您的人员和家庭信息正确。

---

## 准备 Tithe.ly 导出文件 {#preparing-a-tithely-export}

1. 在 Tithe.ly 中，将您的**人员**数据导出为 CSV 或 Excel 文件。如果您还想导入捐献记录，可以另外导出一个**捐献**文件。
2. 工具会根据列名自动检测文件包含的是人员数据还是捐献数据。
3. 在第 1 步中，使用 **Tithe.ly CSV** 选项上传文件。

:::info
Tithe.ly 导出文件需要逐个导入。如果您需要分别导入人员和捐献记录，请运行该过程两次。
:::

---

## 准备 CCB 或 Pushpay 导出文件 {#preparing-a-ccb-or-pushpay-export}

1. 在 Church Community Builder 或 Pushpay 中，将您的**人员**数据导出为 CSV 文件。您也可以导出单独的捐赠/捐献文件。
2. 工具会根据列名自动检测文件包含的是人员数据还是捐献数据。
3. 在第 1 步中，使用 **CCB / Pushpay CSV** 选项上传文件。

---

## 导入之后 {#after-importing}

转移完成后，花几分钟验证您的数据：

1. 浏览[人员](../people/adding-people.md)页面，抽查几份个人资料。
2. 确认姓名、电子邮件、电话号码和地址都已正确导入。
3. 检查家庭关系是否完整。如果源数据中包含家庭角色，每个人的家庭角色（户主、配偶、子女或其他）会被保留：B1 导入 Zip 中的 **householdRole** 列、Breeze 或 Tithe.ly 中的 **Family Role**，以及 CCB / Pushpay 中的 **Family Position**。诸如“Head of Household”“Primary”“Wife”或“Son”之类的角色会被转换为对应的 B1 角色。Planning Center 和自定义 CSV / Excel 导入没有角色列，因此这些人员会被设置为**其他**；您可以在[人员](../people/adding-people.md#managing-households)页面中，通过该人员的家庭来更改其角色。
4. 检查导入的组和捐献记录。

如果您发现问题，可以从人员页面编辑个人资料。您也可以再次运行转移工具，以[导出数据](exporting-data.md)作为备份。
