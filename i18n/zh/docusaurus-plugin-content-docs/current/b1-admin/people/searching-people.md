# 搜索人员

<div class="article-intro">

**人员**页面以可搜索、可排序的表格形式显示您的教会名录。您可以快速找到会众中的任何人，自定义显示哪些信息，并导出结果。高效的搜索对于日常教会管理任务至关重要，例如跟进访客、准备联系人列表和管理成员记录。

</div>

<div class="prereqs">
<h4>准备工作</h4>

- 您需要拥有具备查看人员权限的有效 B1 Admin 账户。如果不确定自己的访问权限级别，请参阅[角色与权限](roles-permissions.md)。
- 您的教会名录中应已有人员数据。如果您还未添加任何人，请参阅[添加人员](adding-people.md)或[导入数据](importing-data.md)。

</div>

## 快速搜索

"人员"页面顶部的搜索栏可让您实时查找成员：

1. 点击"人员"页面顶部的**搜索框**。
2. 开始输入姓名、邮箱或其他关键词。
3. 结果会随着输入自动筛选（有大约半秒钟的短暂延迟，以避免每次按键都触发搜索）。
4. 下方的表格会更新，只显示匹配的结果。

:::tip
您无需按回车键。停止输入后搜索会自动运行。
:::

## 排序结果

您可以通过点击表格中的任意列标题来排序名录：

1. 点击某个**列标题**（例如**姓名**或**邮箱**）以按该列排序。
2. 再次点击同一标题可反转排序顺序。

这样可以轻松按字母顺序、年龄或任何其他可见列查找人员。

## 自定义列

并非所有信息都需要同时显示。您可以选择表格中显示哪些列：

1. 在表格顶部附近找到**列选择下拉菜单**。
2. 勾选或取消勾选列以显示或隐藏它们。可用列包括：
   - **照片**
   - **姓名**
   - **邮箱**
   - **电话**
   - **地址**
   - **出生日期**
   - **年龄**
   - **性别**
   - **成员身份状态**
   - **堂点**
3. 表格会立即更新以反映您的选择。

:::info
您的列选择会影响导出为 CSV 时包含的内容。请在导出前自定义列，以获取恰好所需的数据。
:::

## 分页

当名录记录较多时，结果会分布在多个页面上。使用表格底部的**分页控件**在各页之间切换。系统会显示当前页码和记录总数，让您始终清楚自己在列表中的位置。

:::tip
如果您想一次看到更多结果，建议缩小搜索范围，而不是在庞大的名录中逐页翻阅。
:::

## 导出搜索结果

您可以随时将当前搜索结果下载为 CSV 文件：

1. 应用您需要的任何搜索或筛选条件。
2. 自定义列以包含所需的数据。
3. 点击**导出**按钮。
4. CSV 文件会下载到您的计算机，可在 Excel、Google 表格或任何电子表格应用程序中打开。

有关导出的更多详情，请参阅[导出数据](./exporting-data.md)。

:::tip
对于更高级的查询——例如查找过去三个月未出席的所有人——可尝试 [AI 搜索](./ai-search.md)功能，让您使用自然语言问题进行搜索。
:::

## 高级搜索

高级搜索可让您通过组合条件构建精确的筛选器。从"人员"页面打开它，然后展开一个类别，勾选您想筛选的字段，并为每个字段选择运算符和值。类别包括**姓名**、**人口统计**、**联系方式**、**成员身份**、**活动**（捐款和考勤）以及**自定义字段**。

**自定义字段**类别列出了您教会的[自定义字段](../settings/custom-fields.md)——即您在"设置"中定义的、用于跟踪自有信息（例如背景审查到期日）的字段。提供的运算符与每个字段的类型相匹配：文本字段支持*包含/等于/以…开头/以…结尾*，数字字段支持比较运算符，日期字段支持*等于/晚于/早于*，是/否字段和多选字段则让您选择一个值。这里可筛选的任何字段都可以保存为实时[列表](./lists.md)。

## 将搜索保存为列表

运行搜索后，人员页面标题中会出现一个**保存为列表**按钮（书签图标）。点击它可将当前查询以名称和可选类别的形式保存，以便在未来的会话中立即重新加载。完整详情请参阅[已保存列表](./lists.md)。
