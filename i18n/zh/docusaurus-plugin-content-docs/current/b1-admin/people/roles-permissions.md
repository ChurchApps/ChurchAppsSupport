# 分配角色

<div class="article-intro">

B1 Admin 使用基于角色的权限系统来控制团队中每位用户可以查看和执行的操作。通过分配角色，您可以只向员工和志愿者开放其所需的区域——不多不少。妥善的角色管理既能保护教会数据的安全，又能帮助团队高效工作。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要 B1 Admin 中的 **域管理员** 权限，或拥有管理 **设置** 的角色权限。
- 您要分配角色的人员必须已存在于您的通讯录中。如果您需要先添加他们，请参见[添加人员](adding-people.md)。

</div>

## 了解角色

角色是一组权限，您可以将其分配给一个或多个用户。例如，您可以创建一个“财务团队”角色，授予其访问[奉献记录](../donations/recording-donations.md)的权限；或者创建一个“签到志愿者”角色，仅允许其访问[出席功能](../attendance/check-in.md)。

每个角色控制对 B1 Admin 特定区域的访问，包括：

- **人员** -- 查看和编辑成员资料。人员记录上的“备注”部分需要 **编辑人员** 权限，而单独的 **查看机密备注** 权限控制对“机密备注”部分的访问（用于牧养关怀、个人经历等敏感备注）。**仅查看人员姓名** 允许某人按姓名查找人员（仅能看到姓名、照片和会员状态），而无需访问完整通讯录。
- **奉献** -- 管理捐献和财务报告。**录入奉献** 是面向计款团队的较窄权限：它允许某人录入捐款，但仅限于仍处于开启状态的[批次](../donations/batches.md#who-can-change-a-batch)。
- **出席** -- 记录和查看出席数据
- **表单** -- 创建和管理[自定义表单](../forms/creating-forms.md)
- **群组** -- 管理[群组成员](../groups/group-members.md)和日历
- **设置** -- 配置全教会的设置

:::warning
**域管理员** 拥有 B1 Admin 每个区域的完全访问权限。其权限无法被编辑或限制。请仅将此角色分配给您的主要管理员。
:::

## 查看和管理角色

1. 打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **设置**。
2. 点击 **角色**。
3. 您将看到为您教会配置的所有角色列表。
4. 点击任意角色即可查看其成员和权限。

## 将用户添加到角色

1. 在跳转菜单中，选择 **设置 > 角色**。
2. 点击您要添加用户的角色。
3. 在 **成员** 部分，按姓名搜索该人员。
4. 点击 **添加**，将其分配到该角色。

该用户在下次登录时即可拥有该角色关联的所有权限。

## 编辑角色权限

1. 在跳转菜单中，选择 **设置 > 角色**。
2. 点击您要修改的角色。
3. 在 **权限** 部分，勾选或取消勾选您希望该角色访问的区域。
4. 点击 **保存** 以应用您的更改。

:::tip
遵循最小权限原则——只为每个角色授予其真正需要的权限。这样可以保护数据安全，并减少意外更改的可能性。
:::

## 常见角色示例

- **办公室员工** -- 可访问人员、奉献、出席和表单
- **群组领袖** -- 仅可访问[群组](../groups/creating-groups.md)
- **签到志愿者** -- 仅可访问[出席](../attendance/check-in.md)
- **财务团队** -- 可访问[奉献](../donations/recording-donations.md)和报告
- **计款团队** -- **录入奉献** 和 **查看奉献**，使志愿者可以将奉献金额录入开启的批次，而无需查看奉献汇总

有关人员和奉献权限的更详细说明，请参见[角色与权限](../settings/roles-permissions.md)。
