# 分配角色

<div class="article-intro">

B1 Admin 使用基于角色的权限系统来控制你团队中每个用户可以看到和做什么。通过分配角色，你可以给工作人员和志愿者访问他们确切需要的区域 — 仅此而已。适当的角色管理保持你的教会数据安全，同时赋予你的团队高效工作的能力。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要**域管理员**访问权限或具有权限管理 B1 Admin 中**设置**的角色。
- 你想要分配角色的人必须已经存在于你的目录中。如果你需要添加他们，见[添加人员](adding-people.md)。

</div>

## 理解角色

角色是你分配给一个或多个用户的一组权限。例如，你可能创建一个"财务团队"角色，授予[捐献记录](../donations/recording-donations.md)的访问权限，或一个"签到志愿者"角色，仅允许访问[出席功能](../attendance/check-in.md)。

每个角色控制对 B1 Admin 特定区域的访问，包括：

- **人员** — 查看和编辑成员资料。人员记录上的笔记标签页需要**编辑人员**，单独的**查看保密笔记**权限控制对保密笔记部分的访问权限（用于牧养关怀、个人历史和类似敏感笔记）。
- **捐献** — 管理贡献和财务报告
- **出席** — 记录和查看出席数据
- **表单** — 创建和管理[自定义表单](../forms/creating-forms.md)
- **小组** — 管理[小组成员](../groups/group-members.md)和日历
- **设置** — 配置教会范围的设置

:::warning
**域管理员**具有对 B1 Admin 每个区域的完全访问权限。他们的权限不能被编辑或限制。仅对你的主要管理员使用此角色。
:::

## 查看和管理角色

1. 打开左上角的**部分菜单**（部分名称和小箭头）并选择**设置**。
2. 在顶部导航中点击**角色**。
3. 你会看到为你的教会配置的所有角色的列表。
4. 点击任何角色以查看其成员和权限。

## 向角色添加用户

1. 导航到**设置**然后**角色**。
2. 点击你想添加用户的角色。
3. 在**成员**部分中，按名字搜索该人。
4. 点击**添加**以将其分配给角色。

该用户将在下次登录时拥有与该角色关联的所有权限。

## 编辑角色权限

1. 导航到**设置**然后**角色**。
2. 点击你想修改的角色。
3. 在**权限**部分中，勾选或取消勾选你想让该角色访问的区域。
4. 点击**保存**以应用你的更改。

:::tip
遵循最少权限原则 — 给每个角色仅它真正需要的权限。这保持你的数据安全并减少意外更改的机会。
:::

## 常见角色示例

- **办公工作人员** — 访问人员、捐献、出席和表单
- **小组领导** — 仅访问[小组](../groups/creating-groups.md)
- **签到志愿者** — 仅访问[出席](../attendance/check-in.md)
- **财务团队** — 访问[捐献](../donations/recording-donations.md)和报告
