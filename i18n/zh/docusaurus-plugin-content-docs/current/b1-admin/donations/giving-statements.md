# 捐赠声明

<div class="article-intro">

在每年年底，您的捐献者需要一份他们记录中可税收抵扣的给予摘要。B1 Admin使得一次为所有捐献者生成这些声明变得容易，为您节省数小时的手工工作。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 验证您的[基金](funds.md)被正确标记为**税收抵扣** -- 只有对税收抵扣基金的捐献才显示在声明中
- 确保所有捐献都已[记录](recording-donations.md)，任何在线交易都已[从Stripe导入](stripe-import.md)

</div>

## 访问捐赠声明

1. 在**B1 Admin**中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏）并展开**捐献**。
2. 点击**捐赠声明**。

## 生成声明

1. 从页面顶部的下拉菜单中选择**年份**。您可以选择当前年份或之前的任何五年。
2. 页面为该年显示摘要统计数据，包括：
   - **总捐献者** -- 给予的人数
   - **总捐献数** -- 单个捐献记录数
   - **总金额** -- 所有给予的合并金额

## 下载声明

您有两种选择来获取声明给您的捐献者：

### 以CSV文件下载

点击**下载ZIP**来下载包含每个捐献者的个个CSV文件的ZIP文件。这很有用，如果您想单独发送声明或将其导入另一个系统。

### 打印所有声明

点击**打印全部**来在浏览器中打开每个捐献者声明的可打印视图。从那里，使用浏览器的打印功能将它们发送到打印机。每个声明在新页面上开始，以便它们准备好折叠和邮寄。

:::tip
在您的记录新鲜时在一月初早期运行您的声明。在生成声明前双检查您的基金是否被正确标记为税收抵扣 -- 只有对税收抵扣基金的捐献才被包括。
:::

:::info
捐赠声明仅包括分配给已启用**税收抵扣**设置的基金的捐献。如果基金没有标记为税收抵扣，其捐献将不会显示在声明中。您可以在[基金](funds.md)页面上管理此设置。
:::

## 加拿大、澳大利亚和新西兰的收据格式

美国以外的教会可以将声明切换到其国家的官方收据布局。转到**设置**，打开**给予**部分，并将**声明格式**设置为**加拿大**、**澳大利亚**或**新西兰**，然后填入显示的字段：您的注册号（CRA注册号、ABN或新西兰慈善注册号）、您的组织地址、有权签署收据的人的名称，以及对于加拿大，签发收据的城市。

声明然后携带您的税务当局期望的措辞（对于加拿大，"所得税的官方收据"，CRA参考），收据号的形式`年份-捐献者ID`，仅从税收抵扣基金计算的合格金额，以及对任何对非可抵扣基金的礼物的单独行。捐献者在从B1.church打印他们自己的声明时看到相同的收据块。

## 后续步骤

如果您需要在生成声明前审查捐献详情，访问[捐献报告](donation-reports.md)页面或检查个别[批次](batches.md)。
