# 捐赠声明

<div class="article-intro">

在每年年底，您的捐赠者需要一份他们可税扣除捐赠的摘要以供他们的记录。B1Admin 可以轻松地为所有捐赠者一次性生成这些声明，为您节省数小时的手动工作。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 验证您的[基金](funds.md)已正确标记为**可税扣除** — 只有对可税扣除基金的捐赠才会出现在声明上
- 确保所有捐赠都已[记录](recording-donations.md)并且任何在线交易都已[从 Stripe 导入](stripe-import.md)

</div>

## 访问捐赠声明

1. 在 **B1Admin** 中，打开左上角的**部分菜单**并选择**捐赠**。
2. 点击**声明**。

## 生成声明

1. 从页面顶部的下拉菜单中选择**年份**。您可以选择当前年份或之前的五年中的任何一年。
2. 页面显示该年的摘要统计数据，包括：
   - **总捐赠者** — 进行捐赠的人数
   - **总捐赠** — 个人捐赠记录的数量
   - **总金额** — 所有捐赠的合并美元金额

## 下载声明

您有两个选项可以将声明发送给您的捐赠者：

### 下载为 CSV 文件

单击**下载 ZIP** 以下载包含每个捐赠者的个人 CSV 文件的 ZIP 文件。如果您想要单独发送声明电子邮件或将其导入另一个系统，这会很有用。

### 打印所有声明

单击**打印全部**以在您的浏览器中打开每个捐赠者声明的可打印视图。从那里，使用您的浏览器的打印功能将其发送到打印机。每个声明在新页面上开始，以便它们已准备好折叠和邮寄。

:::tip
在您的记录新鲜时在 1 月初早期运行您的声明。在生成声明之前，请再次检查您的基金是否已正确标记为可税扣除 — 只有对可税扣除基金的捐赠才会被包括在内。
:::

:::info
捐赠声明只包括分配给启用了**可税扣除**设置的基金的捐赠。如果基金未标记为可税扣除，其捐赠将不会出现在声明上。您可以在[基金](funds.md)页面管理此设置。
:::

## 下一步

如果您需要在生成声明之前查看捐赠详情，请访问[捐赠报告](donation-reports.md)页面或检查个别[批次](batches.md)。
