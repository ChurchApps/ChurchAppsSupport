# 捐赠声明

<div class="article-intro">

在每年年底,您的捐赠者需要获得其可扣税捐赠的汇总,供其记录之用。B1 Admin使您可以轻松一次性为所有捐赠者生成这些声明,节省您数小时的手动工作。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 验证您的[基金](funds.md)是否被正确标记为**可扣税** - 只有对可扣税基金的捐赠才会出现在声明中
- 确保所有捐赠都已[记录](recording-donations.md),并且任何在线交易都已[从Stripe导入](stripe-import.md)

</div>

## 访问捐赠声明

1. 在**B1 Admin**中,打开左上角的**部分菜单**,选择**捐赠**。
2. 单击**声明**。

## 生成声明

1. 从页面顶部的下拉菜单中选择**年份**。您可以选择当前年份或之前的任何五个年份。
2. 该页面显示该年份的汇总统计数据,包括:
   - **总捐赠者** - 捐赠的人数
   - **总捐赠数** - 个别捐赠记录的数量
   - **总金额** - 所有捐赠的合并美元金额

## 下载声明

您有两种选择方式获取捐赠者的声明:

### 下载为CSV文件

单击**下载ZIP**以下载包含每个捐赠者的单个CSV文件的ZIP文件。如果您想单独发送电子邮件声明或将其导入到另一个系统中,这很有用。

### 打印所有声明

单击**全部打印**在您的浏览器中打开每个捐赠者声明的可打印视图。从那里,使用浏览器的打印功能将其发送到打印机。每个声明从新页面开始,以便它们准备折叠和邮寄。

:::tip
在1月初趁您的记录还新鲜时运行您的声明。在生成声明之前,仔细检查您的基金是否被正确标记为可扣税 - 只有对可扣税基金的捐赠才会包含在内。
:::

:::info
捐赠声明只包括分配给启用了**可扣税**设置的基金的捐赠。如果基金未被标记为可扣税,其捐赠不会出现在声明上。您可以在[基金](funds.md)页面上管理此设置。
:::

## 加拿大、澳大利亚和新西兰的收据格式

美国以外的教会可以将声明切换到其国家的官方收据布局。去**设置**,打开**捐赠**部分,将**声明格式**设置为**加拿大**、**澳大利亚**或**新西兰**,然后填充出现的字段:您的注册号码(CRA注册号码、ABN或新西兰慈善注册号码)、您组织的地址、授权签署收据的人的姓名,以及加拿大的收据签发城市。

然后声明将携带您的税务机构期望的措辞(对于加拿大,"收入税目的官方收据"与CRA参考),收据号码的形式为`YEAR-DONORID`,仅从可扣税基金中计算的符合条件的金额,以及对任何非扣税基金捐赠的单独行。捐赠者在从B1.church打印他们自己的声明时会看到相同的收据块。

## 后续步骤

如果您需要在生成声明之前审查捐赠详细信息,请访问[捐赠报告](donation-reports.md)页面或检查个别[批次](batches.md)。
