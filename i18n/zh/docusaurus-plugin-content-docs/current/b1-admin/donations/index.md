# 捐赠

<div class="article-intro">

B1Admin 中的捐赠部分提供您管理教会捐赠所需的一切。从记录每周奉献到生成年底税务声明，您的所有捐赠工具都组织在一个地方，以便您可以掌握教会的财务。

</div>

## 子部分

您会在捐赠部分中找到以下页面：

### 摘要

**摘要**页面提供所有捐赠活动的视觉概览。它显示图表和过滤的报告，以便您可以快速查看整个教会的捐赠趋势。有关使用摘要和报告工具的更多详情，请参见[捐赠报告](donation-reports.md)。

### 批次

**[批次](batches.md)**让您将捐赠组合在一起 — 例如，在周日奉献期间收集的所有支票和现金。每个批次为便于核对而跟踪其捐赠计数和总金额。

### 基金

**[基金](funds.md)**按目的对您的捐赠进行分类。常见示例包括普通基金、建筑基金和使命。您可以将每个基金标记为可税扣除或不可税扣除。

### 声明

**[声明](giving-statements.md)**页面为您的捐赠者生成年底捐赠声明。您可以下载个人 CSV 文件或一次打印所有声明。

### Stripe 导入

如果您通过 Stripe 接受在线捐赠，**[Stripe 导入](stripe-import.md)**工具让您将这些交易导入 B1Admin，以便所有内容都在一个系统中。

## 在线捐赠

B1Admin 与 **Stripe** 和 **PayPal** 整合以接受在线捐赠。配置后，成员可以通过您的 B1.church 网站捐赠，这些捐赠会自动出现在您的记录中。参见[在线捐赠设置](online-giving-setup.md)来开始。

:::tip
如果您是 B1Admin 中捐赠的新手，请从[设置您的基金](funds.md)开始，然后[创建您的第一个批次](batches.md)并[记录捐赠](recording-donations.md)到其中。
:::
