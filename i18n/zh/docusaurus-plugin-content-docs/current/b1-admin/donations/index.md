# 奉献

<div class="article-intro">

B1 Admin 中的奉献板块为您提供管理教会奉献所需的一切工具。从记录每周的奉献，到生成年终税务报表，您所需的全部奉献工具都集中在一处，让您轻松掌握教会的财务状况。

</div>

## 子板块

奉献板块包含以下页面：

### 汇总

**汇总**页面可直观地展示所有奉献活动。它以图表和筛选报表的形式呈现，帮助您快速了解全教会的奉献趋势。有关使用汇总和报表工具的更多详情，请参阅[奉献报表](donation-reports.md)。

### 批次

**[批次](batches.md)**用于将奉献分组管理，例如将某个主日奉献期间收集的所有支票和现金归为一组。每个批次都会记录其奉献笔数和总金额，便于核对。批次点算完成后，拥有**编辑奉献**权限的人员可以将其关闭，使点算志愿者无法再对其进行更改。拥有**录入奉献**权限的志愿者可以向未关闭的批次添加奉献，而无需查看奉献板块的其他内容。

### 基金

**[基金](funds.md)**按用途对奉献进行分类。常见示例包括总基金、建筑基金和宣教基金。您可以将每个基金标记为可免税或不可免税。

### 税务报表

**[税务报表](giving-statements.md)**页面可为您的捐献人生成年终奉献报表。您可以逐个下载 CSV 文件，也可以一次性打印所有报表。

### Stripe 导入

如果您通过 Stripe 接受线上奉献，**[Stripe 导入](stripe-import.md)**工具可将这些交易导入 B1 Admin，使所有数据都保存在同一系统中。

## 线上奉献

B1 Admin 集成了 **Stripe** 和 **PayPal**，用于接受线上奉献。配置完成后，会众可以通过您的 B1.church 网站进行奉献，这些奉献会自动出现在您的记录中。请参阅[线上奉献设置](online-giving-setup.md)开始配置。

:::tip
如果您是首次在 B1 Admin 中处理奉献，请先[设置基金](funds.md)，然后[创建您的第一个批次](batches.md)，并[录入奉献](recording-donations.md)到该批次中。
:::
