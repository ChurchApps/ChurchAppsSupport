# 奉献

<div class="article-intro">

B1 Admin 中的奉献板块提供管理教会奉献所需的一切功能。从登记每周的奉献，到生成年终税务收据，你所有的奉献工具都集中在一处，方便你掌握教会的财务状况。

</div>

## 子板块 {#sub-sections}

你可以在奉献板块中找到以下页面：

### 概览 {#summary}

**概览**页面提供所有奉献活动的可视化总览。它显示图表和经过筛选的报表，让你快速了解教会的奉献趋势。有关使用概览和报表工具的更多详情，请参见[奉献报表](donation-reports.md)。

### 批次 {#batches}

**[批次](batches.md)** 让你将奉献归在一起——例如，将某次主日奉献中收集到的所有支票和现金归为一组。每个批次都会跟踪其奉献笔数和总金额，便于对账。一旦批次清点完毕，具有 **Edit Donations** 权限的人员即可将其关闭，使清点志愿者无法再更改。拥有 **Enter Donations** 权限的志愿者可以向开放的批次中添加奉献，而无需查看奉献板块中的其他内容。

### 基金 {#funds}

**[基金](funds.md)** 按用途对奉献进行分类。常见示例包括总基金、建堂基金和宣教基金。你可以将每个基金标记为可免税或不可免税。

### 筹款活动 {#campaigns}

**[筹款活动](campaigns.md)** 跟踪朝向某一目标的募款活动，同时显示成员的认捐以及该活动基金的实际奉献。

### 奉献收据 {#giving-statements}

**[奉献收据](giving-statements.md)** 页面为你的捐赠人生成年终奉献收据。你可以下载单独的 CSV 文件，也可以一次性打印所有收据。

### 失败的奉献 {#failed-gifts}

**Failed Gifts**（失败的奉献）列出支付网关无法扣款的定期在线奉献，并显示捐赠人、金额、日期、网关的提示信息，以及 **Retry**（重试）按钮。参见[失败的定期奉献](online-giving-setup.md#failed-recurring-gifts)。

### Stripe 导入 {#stripe-import}

如果你通过 Stripe 接受在线奉献，**[Stripe 导入](stripe-import.md)** 工具可以将这些交易导入 B1 Admin，使所有数据都在同一个系统中。

## 在线奉献 {#online-giving}

B1 Admin 与 **Stripe**、**Kingdom Funding** 和 **Paystack** 集成，用于接受在线奉献。配置完成后，成员可以通过你的 B1.church 网站进行奉献，这些奉献会自动出现在你的记录中。参见[在线奉献设置](online-giving-setup.md)开始配置。

:::tip
如果你是第一次在 B1 Admin 中处理奉献，请先[设置基金](funds.md)，然后[创建第一个批次](batches.md)，并将奉献[登记](recording-donations.md)到其中。
:::
