# 记录捐赠

<div class="article-intro">

在 B1Admin 中记录捐赠是通过批次系统完成的。您创建一个批次来代表一个收集（如周日奉献），然后将个人捐赠添加到该批次。这会保持您的捐赠记录有组织且易于核对。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置您的[基金](funds.md)以便您可以将捐赠分配给正确的类别
- 创建一个[批次](batches.md)来容纳您即将输入的捐赠
- 确保捐赠者在您的[人员目录](../people/adding-people.md)中，以便在输入礼物时可以查找他们

</div>

## 创建批次和添加捐赠

1. 在 **B1Admin** 中，打开左上角的**部分菜单**并选择**捐赠**，然后单击**批次**。
2. 点击**添加批次**。
3. 输入批次的名称（例如"周日奉献 - 1 月 5 日"）并选择日期。点击**保存**。
4. 您的新批次出现在列表中，显示零捐赠和 $0.00。
5. 单击**批次名称**打开它。

## 输入个人捐赠

1. 在批次详情页面中，在**搜索字段**中输入捐赠者的名称以找到他们。
2. 选择一个人后，捐赠输入表单会出现，其中包含**日期**、**付款方法**、**基金**、**金额**和**支票号码**字段。
3. 填入详情并单击**添加捐赠**。
4. 捐赠被添加到下面的表格中，表单重置以便您可以输入下一个。

:::tip
您可以在不离开批次页面的情况下快速连续输入多个捐赠。表单在每次输入后重置，以便您可以有效地通过一堆支票或信封。
:::

## 将捐赠分割到多个基金

有时单个捐赠者在一次交易中向多个基金捐赠。要处理这个：

1. 单击捐赠行上的**编辑**按钮。
2. 在编辑表单中，添加金额到不同的基金。总计会自动从个人基金金额计算。
3. 单击**保存**以更新捐赠。

:::info
当捐赠者写出为多个目的指定的单张支票时（如普通基金和使命），将捐赠分割到多个基金是常见的。
:::

## 编辑或删除捐赠

要编辑捐赠，请单击批次中其行上的**编辑**按钮。您可以更改日期、金额、基金、付款方法或任何其他详情。完成后单击**保存**。

:::tip
批次页面标题会自动更新，以显示捐赠总数和合并美元金额，当您添加或编辑条目时。使用它针对您的存款单进行核对。
:::
