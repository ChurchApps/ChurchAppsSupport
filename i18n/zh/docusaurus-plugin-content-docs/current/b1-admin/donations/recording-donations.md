# 记录捐献

<div class="article-intro">

在 B1 Admin 中记录捐献是通过批次系统完成的。您创建一个批次来代表一个收集（例如周日奉献），然后向该批次添加个人捐献。这样可以使您的捐献记录井然有序，易于核对。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置您的[基金](funds.md)，以便您可以将捐献分配到正确的类别
- 创建一个[批次](batches.md)来保存您即将输入的捐献
- 确保捐献者在您的[人员目录](../people/adding-people.md)中，以便您可以在输入捐献时查找他们

</div>

## 创建批次并添加捐献

1. 在 **B1 Admin** 中，打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**捐献**，然后点击**批次**。
2. 点击**添加批次**。
3. 输入批次的名称（例如，"周日奉献 - 1 月 5 日"）并选择日期。点击**保存**。
4. 您的新批次出现在列表中，显示零捐献和 $0.00。
5. 点击**批次名称**来打开它。

## 输入个人捐献

1. 在批次详情页面上，在**搜索字段**中输入捐献者的名称来查找他们。
2. 选择一个人后，捐献输入表单会显示，包括**日期**、**支付方式**、**基金**、**金额**和**支票号码**字段。
3. 填写详情并点击**添加捐献**。
4. 捐献被添加到下方的表格中，表单重置，以便您可以输入下一个。

:::tip
您可以快速连续输入多个捐献，而无需离开批次页面。每次输入后表单都会重置，以便您可以有效地处理一堆支票或信封。
:::

## 将捐献分拆到多个基金

有时单个捐献者在一笔交易中向多个基金捐献。要处理这种情况：

1. 点击捐献行上的**编辑**按钮。
2. 在编辑表单中，向不同的基金添加金额。总额将自动从各个基金金额中计算。
3. 点击**保存**来更新捐献。

:::info
将捐献分拆到基金是常见的，当捐献者开出一张支票用于多个目的时，例如总基金和宣教基金。
:::

## 编辑或删除捐献

要编辑捐献，请点击批次中其行上的**编辑**按钮。您可以更改日期、金额、基金、支付方式或任何其他细节。完成后点击**保存**。

:::tip
批次页面标题会自动更新，以显示捐献的总数和合并的美元金额，当您添加或编辑条目时。使用此来核对您的存款单据。
:::

## 退款捐献

如果捐献者因错误被收费或要求退款，您可以直接从其编辑屏幕退款已完成的捐献——无需转到您的支付网关的仪表板。

1. 打开捐献并点击**编辑**。
2. 点击表单底部删除旁边的**退款**按钮。
3. 确认对话框："通过支付网关完全退款这笔捐献？这不能撤销。"

捐献通过原始支付网关完全退款，并在您的捐献列表中标记为**已退款**。

:::warning
退款仅为全额退款——没有办法从 B1 Admin 退款部分金额。一旦确认，退款也无法撤销。
:::

:::info
**退款**按钮仅对通过在线支付（具有网关交易）且仍处于**完成**状态的捐献显示。手动输入的捐献（现金、支票）没有网关交易来退款——编辑或删除这些。
:::
