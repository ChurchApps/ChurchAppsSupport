# 记录捐款

<div class="article-intro">

在 B1 Admin 中记录捐款是通过批次（Batches）系统完成的。您可以创建一个批次来代表一次奉献（例如主日奉献），然后将单笔捐款添加到该批次中。这样可以让您的奉献记录井然有序，便于核对。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置您的[基金](funds.md)，以便将捐款分配到正确的类别
- 创建一个[批次](batches.md)，用于存放您即将录入的捐款
- 确保捐赠者已在您的[人员目录](../people/adding-people.md)中，以便录入奉献时可以查找他们
- 您需要拥有 **编辑捐款**（Edit Donations）权限，或者同时拥有 **录入捐款**（Enter Donations）和 **查看捐款**（View Donations）权限，才能向批次中录入奉献（参见[谁可以更改批次](batches.md#who-can-change-a-batch)）

</div>

## 创建批次并添加捐款

1. 在 **B1 Admin** 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **Donations（捐款）**，然后点击 **Batches（批次）**。
2. 点击页面顶部的 **Add Batch（添加批次）**。
3. 输入批次名称（例如“主日奉献 - 1月5日”），并选择日期。点击 **Save（保存）**。
4. 新批次会出现在列表中，显示捐款数量为零，金额为 $0.00。
5. 点击**批次名称**以打开该批次。

## 逐笔录入捐款

1. 在批次详情页上，捐款录入面板会显示在捐款列表旁边。在 **Select Person or Anonymous（选择人员或匿名）** 下，在搜索框中输入捐赠者的姓名以查找他们，或点击 **Anonymous（匿名）**。（点击页面顶部的 **Add Donation（添加捐款）** 会直接跳转到此面板。）
2. 选择人员后，录入表单会显示以下字段：**Date（日期）**、**Method（方式）**（Check 支票、Cash 现金、Card 银行卡或 In-Kind 实物）、**Fund（基金）**、**Notes（备注）**、**Amount（金额）**，以及 **Check #（支票号）**（银行卡奉献则为 **Last 4 digits（卡号后四位）**，实物奉献则为 **Item（物品）**，用于描述所捐物品）。点击捐赠者姓名旁边的 **Change（更改）** 可以选择其他人。
3. 填写详细信息，然后点击 **Add Donation（添加捐款）**（或按 Enter 键）。
4. 该笔捐款会添加到捐款列表中，表单会重置，以便您录入下一笔。

:::info
如果批次已被[关闭](batches.md#closing-and-reopening-a-batch)，没有 **编辑捐款** 权限的用户将看不到录入面板和 **Edit（编辑）** 链接，并且批次顶部会显示一条已关闭的提示。请让拥有 **编辑捐款** 权限的人员重新打开该批次。
:::

:::tip
您可以在批次页面中连续快速录入多笔捐款，无需离开该页面。每次录入后表单都会重置，因此您可以高效地处理一叠支票或信封。
:::

## 从 CSV 文件导入捐款 {#importing-donations-from-a-csv-file}

如果您的捐款数据已经在电子表格中——例如从其他奉献系统导出的数据，或计数团队的统计表——您可以将其导入批次，而无需逐笔输入。

1. 打开批次，然后点击页面顶部的 **Import CSV（导入 CSV）**。（当您可以更改该批次且教会至少有一个[基金](funds.md)时，此按钮才会显示。）
2. 点击 **Choose CSV File（选择 CSV 文件）**并选择您的文件。文件需要包含标题行，各列的顺序可以任意：
   - **Amount（金额）**（必填；`Total` 也可以）——货币符号和逗号会被忽略，因此 `$1,250.00` 是可以的。金额必须大于零。
   - **Date（日期）**——使用 `2026-10-25` 或 `10/25/2026` 等格式。如果留空，则使用批次日期。
   - **Fund（基金）**——基金名称，匹配时不区分大小写。如果留空，则使用您的第一个基金。
   - **Method（方式）**——**Check（支票）**、**Cash（现金）**、**Card（银行卡）**或 **In-Kind（实物）**。如果留空，则默认为 **Check（支票）**。
   - **Check Number（支票号）**——支票号码（或其他支付细节）。
   - **Notes（备注）**
   - **Email（邮箱）**、**Name（姓名）**，或 **First Name（名）** 和 **Last Name（姓）**——用于在您的数据库中匹配捐赠者。写成“Smith, John”的姓名会被识别为“John Smith”。
3. 查看预览。每一行会显示其行号、文件中的捐赠者、**Match（匹配结果）**、基金和金额：
   - 显示人员姓名表示已匹配到该捐赠者。B1 会先按邮箱匹配，然后按完全相同的姓名匹配，并且只有在恰好匹配到一个人时才会采用。
   - **Not found — anonymous（未找到 — 匿名）**表示未找到唯一匹配。该笔奉献将作为匿名捐款导入，并在其备注中添加“Imported as:”（导入为）及捐赠者姓名，以便您稍后分配。
   - 红色提示（例如 **Invalid amount（金额无效）**、**Unknown fund（未知基金）**、**Unknown method（未知方式）**或 **Invalid date（日期无效）**）表示该行将被跳过。请修正文件后重新选择，即可将其包含在内。
4. 点击 **Import（导入）**（按钮会显示将导入的行数）。捐款会被添加到批次中。

:::tip
导入后，对任何匿名捐款使用 **Edit（编辑）**，即可选择正确的人员。“Imported as:”备注会告诉您文件中记录的捐赠者是谁。
:::

## 从人员记录中登记一笔奉献

若要记录单笔奉献而无需打开批次，请在 **People（人员）** 中打开捐赠者的记录，然后点击 **Log a gift（登记奉献）**（位于奉献摘要中，或人员的奉献视图上）。

1. 设置 **Date（日期）**和 **Amount（金额）**。
2. 选择 **Fund（基金）**和 **Method（方式）**（Check 支票、Cash 现金、Card 银行卡或 In-Kind 实物），如有需要，填写 **Check #（支票号）**、**Last 4 digits（卡号后四位）**或 **Item（物品）**（用于实物奉献）。
3. 可选择填写 **Notes（备注）**，然后点击 **Save（保存）**。

该笔奉献会被保存到对应日期的批次中。如果该日期还没有批次，系统会自动为您创建一个，并以日期命名。

## 将一笔捐款拆分到多个基金

有时，同一位捐赠者在一次交易中会向多个基金捐款。要处理这种情况：

1. 在录入面板下方，点击 **full donation editor（完整捐款编辑器）**链接（或点击现有捐款行上的 **Edit（编辑）**）。
2. 在完整编辑器中，向不同的基金添加金额。总额会根据各基金的金额自动计算。
3. 点击 **Save（保存）**以更新该笔捐款。

:::info
当捐赠者在一张支票上注明了多个用途（例如普通基金和宣教基金）时，拆分捐款就很常见。
:::

## 编辑或删除捐款

要编辑捐款，请点击批次中该行上的 **Edit（编辑）**按钮。您可以更改日期、金额、基金、支付方式（Check 支票、Cash 现金、Card 银行卡或 In-Kind 实物）或其他任何细节。对于实物奉献，编辑器会将细节字段标注为 **Item（物品）**，以便您描述所捐的物品。完成后点击 **Save（保存）**。

:::tip
页面顶部批次名称下方的那一行会随着您添加或编辑条目而自动更新，显示批次日期、奉献笔数和合计金额。您可以用它来与存款单进行核对。
:::

## 退还捐款

如果捐赠者被误扣款或要求退款，您可以直接在捐款的编辑页面中退还已完成的捐款——无需前往支付网关的后台。

1. 打开该捐款并点击 **Edit（编辑）**。
2. 在表单底部，点击 Delete（删除）旁边的 **Refund（退款）**按钮。
3. 确认对话框中的提示：“通过支付网关全额退还此笔捐款？此操作无法撤销。”

该笔捐款将通过原支付网关全额退款，并在您的捐款列表中标记为 **Refunded（已退款）**。

:::warning
退款仅支持全额退款——无法在 B1 Admin 中部分退款。一旦确认，退款也无法撤销。
:::

:::info
**Refund（退款）**按钮仅对通过线上支付的捐款（它们有网关交易记录）且仍处于 **Complete（已完成）**状态的捐款显示。手动录入的捐款（现金、支票）没有可退款的网关交易——请改为编辑或删除这些捐款。
:::
