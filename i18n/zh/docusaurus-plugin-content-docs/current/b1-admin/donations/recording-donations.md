# 登记奉献 {#recording-donations}

<div class="article-intro">

在 B1 Admin 中登记奉献需通过批次系统完成。你需要创建一个批次来代表一次收款（例如主日奉献），然后将单笔奉献添加到该批次中。这样可以使你的奉献记录井井有条，并便于对账。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置好你的[基金](funds.md)，以便将奉献分配到正确的类别
- 创建一个[批次](batches.md)，用于存放你即将录入的奉献
- 确保捐赠人已在你的[人员名录](../people/adding-people.md)中，以便录入奉献时可以查找他们
- 你需要 **Edit Donations** 权限，或同时具备 **Enter Donations** 和 **View Donations** 权限，才能将奉献录入批次（参见[谁可以更改批次](batches.md#who-can-change-a-batch)）

</div>

## 创建批次并添加奉献 {#creating-a-batch-and-adding-donations}

1. 在 **B1 Admin** 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **Donations**，然后点击 **Batches**。
2. 点击页面顶部的 **Add Batch**。
3. 为批次输入名称（例如"1 月 5 日主日奉献"），并选择日期。点击 **Save**。
4. 新批次会出现在列表中，显示 0 笔奉献和 $0.00。
5. 点击**批次名称**将其打开。

## 逐笔录入奉献 {#entering-individual-donations}

1. 在批次详情页面，奉献录入面板会出现在奉献列表旁边。在 **Select Person or Anonymous**（选择人员或匿名）下，在搜索框中输入捐赠人的姓名以查找他们，或点击 **Anonymous**（匿名）。（点击页面顶部的 **Add Donation**（添加奉献）会直接跳转到此面板。）
2. 选择人员后，录入表单会显示以下字段：**Date**（日期，默认为批次日期）、**Method**（方式：Check（支票）、Cash（现金）、Card（银行卡）或 In-Kind（实物））、**Fund**（基金，教会设有多个基金时显示）、**Memo (prints on statement)**（备注，会打印在收据上）、**Notes (internal)**（内部备注）、**Amount**（金额），以及 **Check #**（支票号码；银行卡奉献则为 **Last 4 digits**（卡号后四位）；实物奉献则为 **Item**（物品，用于描述实物奉献）；现金奉献没有详情字段）。点击捐赠人姓名旁边的 **Change**（更改）即可选择其他人员。
3. 填写详细信息，然后点击 **Add Donation**（或按 Enter 键）。如果金额为空或为零，表单会提示你输入大于零的金额，而不会保存。
4. 奉献会被添加到奉献列表中，表单随即重置，方便你录入下一笔。日期、方式、基金、备注和内部备注会保持你所设置的内容，因此录入一叠相似的支票时，只需输入捐赠人、金额和支票号码即可。

打开批次时，**Date** 总会默认为批次日期。如果你更改了它，新日期会沿用到你在该批次中录入的下一笔奉献——无论是在录入面板还是完整的奉献编辑器中——直到你再次更改或离开该批次。

:::tip 备注（Memo）还是内部备注（Notes）？
**Memo** 会与奉献一同打印在捐赠人的奉献收据上。请用它填写捐赠人应当看到的内容，例如专款奉献的用途（"青年旅行"）。**Notes** 仅供工作人员查看，绝不会打印。当有人在线奉献时，他们在奉献表单备注框中输入的内容会被保存为该笔奉献的 Memo。
:::

:::info
如果批次已被[关闭](batches.md#closing-and-reopening-a-batch)，没有 **Edit Donations** 权限的人员将看不到录入面板和 **Edit** 链接，批次顶部也会显示关闭通知。请让具有 **Edit Donations** 权限的人员将其重新开放。
:::

:::tip
你无需离开批次页面，即可连续快速录入多笔奉献。每次录入后表单都会重置，因此你可以高效地处理一叠支票或信封。
:::

## 从 CSV 文件导入奉献 {#importing-donations-from-a-csv-file}

如果你的奉献已经在电子表格中——例如从其他奉献系统导出的数据，或清点团队的统计表——你可以将其导入批次，而无需逐笔输入。

1. 打开批次，然后点击页面顶部的 **Import CSV**。（当你有权更改该批次，且教会至少设有一个[基金](funds.md)时，此按钮才会出现。）
2. 点击 **Choose CSV File**（选择 CSV 文件）并选取你的文件。文件需包含标题行，各列的顺序可以任意：
   - **Amount**（金额，必填；`Total` 也可以）——货币符号和逗号会被忽略，因此 `$1,250.00` 也没有问题。金额必须大于零。
   - **Date**（日期）——使用如 `2026-10-25` 或 `10/25/2026` 的格式。若留空，则使用批次日期。
   - **Fund**（基金）——基金名称，匹配时不区分大小写。若留空，则使用你的第一个基金。
   - **Method**（方式）——**Check**、**Cash**、**Card** 或 **In-Kind**。若留空，则使用 **Check**。
   - **Check Number**（支票号码）——支票号码（或其他付款详情）。
   - **Notes**（备注）
   - **Email**（电子邮件）、**Name**（姓名），或 **First Name**（名字）和 **Last Name**（姓氏）——用于将捐赠人与数据库中的人员相匹配。如果姓名写为"Smith, John"，将被识别为"John Smith"。
3. 检查预览。每一行会显示其行号、文件中的捐赠人、**Match**（匹配结果）、基金和金额：
   - 显示人员姓名表示已匹配到该捐赠人。B1 会先按电子邮件匹配，然后按完全一致的姓名匹配，且仅当恰好只有一人符合时才会匹配。
   - **Not found — anonymous**（未找到——匿名）表示未找到唯一匹配。该奉献将以匿名方式导入，并且其备注中会添加"Imported as:"（导入为：）及捐赠人姓名，方便你稍后进行分配。
   - 红色提示信息（例如 **Invalid amount**（金额无效）、**Unknown fund**（基金未知）、**Unknown method**（方式未知）或 **Invalid date**（日期无效））表示该行将被跳过。请修正文件后重新选择，即可将其包含在内。
4. 点击 **Import**（导入）（按钮上会显示将导入的行数）。奉献将被添加到批次中。

:::tip
导入后，可以对任何匿名奉献使用 **Edit**，选择正确的人员。"Imported as:"备注会告诉你文件中记录的捐赠人是谁。
:::

## 从人员记录中记录奉献 {#logging-a-gift-from-a-persons-record}

若要在不打开批次的情况下记录单笔奉献，请在**人员**中打开捐赠人的记录，然后点击 **Log a gift**（记录奉献）（位于奉献摘要中，或人员的奉献视图中）。

1. 设置 **Date**（日期）和 **Amount**（金额）。
2. 选择 **Fund**（基金）和 **Method**（方式）（Check、Cash、Card 或 In-Kind），如有需要，输入 **Check #**（支票号码）、**Last 4 digits**（卡号后四位）或 **Item**（物品，适用于实物奉献）。
3. 可选择添加 **Notes**（备注），然后点击 **Save**。

该奉献会被保存到该日期的批次中。如果该日期尚无批次，系统会为你创建一个，并以该日期命名。

## 将一笔奉献拆分到多个基金 {#splitting-a-donation-across-multiple-funds}

有时，同一位捐赠人在一笔交易中会向多个基金奉献。处理方法如下：

1. 在录入面板下方，点击 **full donation editor**（完整奉献编辑器）链接（或点击现有奉献行上的 **Edit**）。新的奉献默认使用批次日期。
2. 在完整编辑器中，输入金额和基金，然后点击 **Add More**（添加更多）以添加另一个基金和金额。总额会根据各基金的金额自动计算。
3. 点击 **Save**。如果任何基金都没有金额，该奉献将不会被保存；编辑器会要求你输入大于零的金额。

:::info
当捐赠人开具一张支票，指定用于多个用途（例如总基金和宣教）时，将奉献拆分到多个基金的情况很常见。
:::

## 编辑或删除奉献 {#editing-or-removing-donations}

若要编辑奉献，请点击批次中该行上的 **Edit** 按钮。你可以更改日期、金额、基金、付款方式（Check、Cash、Card 或 In-Kind）或任何其他详细信息，包括 **Memo** 和 **Notes**。对于实物奉献，编辑器会将详情字段标注为 **Item**，以便你描述所奉献的物品。完成后点击 **Save**。

### 将奉献转移到其他批次 {#moving-a-gift-to-another-batch}

如果奉献被录入到了错误的批次，你可以直接将其移动，而无需删除后重新录入：

1. 点击该奉献所在行上的 **Edit**。
2. 在 **Batch** 下拉菜单中，选择它应当属于的批次。列表会显示每个批次的日期和名称，最新的排在最前。已关闭的批次不会列出，但该奉献当前所在的批次除外。
3. 点击 **Save**。

奉献会离开当前批次，并出现在你所选的批次中，两个批次的合计都会随之更新。移动奉献属于编辑操作，因此它不会像重新录入那样触发 **Donation · Created** [工作流](../serving/workflows.md#triggers)。

:::tip
页面顶部批次名称下方的那一行会随着你添加或编辑条目而自动更新，显示批次日期、奉献笔数和合计金额。你可以用它与存款单进行对账。
:::

## 退还奉献 {#refunding-a-donation}

如果捐赠人被错误扣款，或要求退还款项，你可以直接在已完成奉献的编辑界面中进行退款，无需前往支付网关的后台。

1. 打开该奉献，然后点击 **Edit**。
2. 在表单底部的 Delete 旁边，点击 **Refund**（退款）按钮。
3. 确认对话框："通过支付网关全额退还此奉献？此操作无法撤销。"

该奉献将通过原支付网关全额退款，并在你的奉献列表中标记为 **Refunded**（已退款）。

:::warning
退款仅支持全额退款——B1 Admin 无法退还部分金额。确认后，退款也无法撤销。
:::

:::info
**Refund** 按钮仅对通过线上付款（具有网关交易记录）且仍处于 **Complete**（已完成）状态的奉献显示。手动录入的奉献（现金、支票）没有可退款的网关交易——请改为编辑或删除这些奉献。
:::

## 为单笔奉献打印收据 {#printing-a-receipt-for-one-gift}

当有人递交支票、为活动或 T 恤付款，或来访的机构带来捐款时，你可以只为该笔奉献打印收据，而无需打印整个批次或年终收据。

1. 打开包含该奉献的批次。
2. 点击该奉献所在行上 **Edit** 旁边的 **Receipt**（收据）。你也可以点击"编辑奉献"表单底部的 **Receipt**。
3. 点击 **Print**（打印），或点击 **Close**（关闭）返回。

收据采用与奉献收据相同的版式：包括你的教会和捐赠人（或"Anonymous"（匿名））、奉献的日期和方式、每个基金及其金额、备注（如有）、你的奉献备注，以及若你已设置**收据格式**（**Statement format**）则会显示的官方收据信息栏（参见[奉献收据](giving-statements.md)）。该信息栏中的收据编号即为该奉献的 ID。

:::info
只有当奉献中的每个基金都标记为可免税时，才会打印"无商品或服务"的说明文字。如果奉献的任何部分用于不可免税的基金（例如活动费用或购买），收据将不会包含该说明，使其呈现为付款凭证而非慈善捐赠。
:::

:::tip
在线奉献本身已会自动发送感谢电子邮件，因此收据主要适用于你手动录入的奉献。
:::
