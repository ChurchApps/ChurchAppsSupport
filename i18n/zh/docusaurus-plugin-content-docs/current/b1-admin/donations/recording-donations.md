# 记录捐献

<div class="article-intro">

在 B1 Admin 中记录捐献是通过批次系统完成的。您可以创建一个批次来代表一次奉献（例如主日奉献），然后将各笔捐献添加到该批次中。这样可以使您的奉献记录井然有序，也便于核对。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置您的[基金](funds.md)，以便将捐献分配到正确的类别
- 创建一个[批次](batches.md)，用于存放您即将录入的捐献
- 确保捐献者已在您的[人员目录](../people/adding-people.md)中，以便录入奉献时可以查找他们
- 您需要拥有**编辑捐献**权限，或同时拥有**录入捐献**和**查看捐献**权限，才能将奉献录入批次（请参阅[谁可以更改批次](batches.md#who-can-change-a-batch)）

</div>

## 创建批次并添加捐献

1. 在 **B1 Admin** 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**捐献**，然后点击**批次**。
2. 点击页面顶部的**添加批次**。
3. 输入批次名称（例如"主日奉献 - 1月5日"），并选择日期。点击**保存**。
4. 新批次会出现在列表中，显示捐献数量为零，金额为 $0.00。
5. 点击**批次名称**以打开该批次。

## 录入单笔捐献

1. 在批次详情页上，捐献录入面板会显示在捐献列表旁边。在**选择人员或匿名**下，于搜索框中输入捐献者的姓名以查找其记录，或点击**匿名**。（点击页面顶部的**添加捐献**会直接跳转到此面板。）
2. 选择人员后，录入表单会显示以下字段：**日期**、**方式**（支票、现金、刷卡或实物）、**基金**、**备注**、**金额**，以及**支票号**（刷卡奉献则为**卡号末四位**，实物奉献则为描述所捐物品的**物品**）。如需选择其他人，请点击捐献者姓名旁的**更改**。
3. 填写详细信息，然后点击**添加捐献**（或按 Enter 键）。
4. 该笔捐献会被添加到捐献列表中，表单会重置，以便您录入下一笔。

:::info
如果批次已[关闭](batches.md#closing-and-reopening-a-batch)，则没有**编辑捐献**权限的用户将看不到录入面板和**编辑**链接，并且批次顶部会显示一条已关闭的提示。请让拥有**编辑捐献**权限的人员重新打开该批次。
:::

:::tip
您可以在批次页面中连续快速录入多笔捐献，无需离开页面。每次录入后表单都会重置，方便您高效地处理一叠支票或奉献袋。
:::

## 从个人记录中登记一笔奉献

如需记录单笔奉献而无需打开批次，请在**人员**中打开捐献者的记录，然后点击**登记奉献**（位于奉献摘要中，或人员的奉献视图中）。

1. 设置**日期**和**金额**。
2. 选择**基金**和**方式**（支票、现金、刷卡或实物），并在需要时填写**支票号**、**卡号末四位**或**物品**（用于实物奉献）。
3. 可选择填写**备注**，然后点击**保存**。

该笔奉献会保存到该日期对应的批次中。如果该日期尚无批次，系统会自动为您创建一个以该日期命名的批次。

## 将一笔捐献拆分到多个基金

有时，同一位捐献者在一次交易中会向多个基金捐款。处理方法如下：

1. 在录入面板下方，点击**完整捐献编辑器**链接（或点击现有捐献行上的**编辑**）。
2. 在完整编辑器中，为不同基金添加金额。总额将根据各基金金额自动计算。
3. 点击**保存**以更新该笔捐献。

:::info
当捐献者开出一张支票并指定用于多个用途时（例如普通基金和宣教基金），拆分捐献十分常见。
:::

## 编辑或删除捐献

如需编辑捐献，请点击批次中该笔捐献所在行上的**编辑**按钮。您可以更改日期、金额、基金、付款方式（支票、现金、刷卡或实物）或任何其他详细信息。对于实物奉献，编辑器会将明细字段标记为**物品**，以便您描述所捐的物品。完成后点击**保存**。

:::tip
随着您添加或编辑条目，页面顶部批次名称下方的那一行会自动更新，显示批次日期、奉献笔数和合计金额。您可以用它与存款单进行核对。
:::

## 退款

如果捐献者被误扣款，或要求退还款项，您可以直接在已完成捐献的编辑页面中办理退款，无需前往支付网关的后台。

1. 打开该笔捐献并点击**编辑**。
2. 点击表单底部删除按钮旁边的**退款**按钮。
3. 在对话框中确认："通过支付网关全额退还此笔捐献？此操作无法撤销。"

该笔捐献会通过原支付网关全额退款，并在您的捐献列表中标记为**已退款**。

:::warning
退款仅支持全额退款，B1 Admin 无法办理部分退款。确认后，退款同样无法撤销。
:::

:::info
**退款**按钮仅会出现在通过网上支付的捐献（即存在网关交易记录）且状态仍为**已完成**的捐献上。手动录入的捐献（现金、支票）没有可退款的网关交易，请改为编辑或删除这些记录。
:::
