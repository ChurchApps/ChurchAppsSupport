# 捐款批次

<div class="article-intro">

批次将您的捐款分组，便于跟踪和对账。一个典型的批次代表一次募捐，例如一次周日奉献或一次特别活动。使用批次有助于您保持井井有条，并能轻松核实您的记录是否与实际存款相符。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 请确保您已[设置基金](funds.md)，以便在录入捐款时可以使用
- 您需要拥有**查看捐款汇总**、**编辑捐款**或**录入捐款**权限，才能看到批次页面（参见[谁可以更改批次](#who-can-change-a-batch)）

</div>

## 批次页面

当您导航到**捐款 > 批次**时，您将看到您的批次列表。每一行显示：

- **名称** -- 您为批次设置的标签
- **日期** -- 募捐的日期
- **捐款** -- 批次中单独捐款的数量
- **总计** -- 合计金额
- **状态** -- **开放**或**已关闭**（参见[关闭和重新打开批次](#closing-and-reopening-a-batch)）

列表上方的年份按钮可让您只显示某一年的批次，或显示**全部**批次。一行摘要会显示所显示批次的数量、奉献笔数和总金额。

## 创建新批次

1. 点击页面顶部的**添加批次**。
2. 输入一个描述性名称（例如"2 月 9 日周日奉献"）。
3. 选择募捐的日期。
4. 点击**保存**。

您的新批次会出现在列表中，随时可以添加捐款。

## 使用批次

- **查看捐款** -- 点击批次名称，即可打开它并查看其中包含的所有单独捐款。在此处，您可以添加、编辑或移除捐款。
- **编辑批次详情** -- 点击批次行上的**编辑**按钮，即可更改其名称或日期。只有拥有**编辑捐款**权限的人员才能删除批次。
- **排序** -- 使用列标题按名称或日期对批次排序。
- **导出** -- 点击页面顶部的**导出**，即可将所显示的批次以电子表格（CSV）形式下载。
- **失败事件** -- 如果您的支付网关报告了问题，页面顶部会出现一个**失败事件**按钮（并显示未解决事件的数量）。点击它即可显示或隐藏批次下方的事件列表。
- **从 Stripe 导入** -- 点击页面顶部的**导入缺失的 Stripe 交易**，即可打开 [Stripe 导入](stripe-import.md)工具。

## 关闭和重新打开批次 {#closing-and-reopening-a-batch}

一旦批次已经清点并存入银行，请将其关闭，以确保其中的捐款与您关闭时保持完全一致。

1. 打开批次。
2. 点击页面顶部的**关闭批次**。

批次名称旁边的状态标签会从**开放**变为**已关闭**，批次页面的**状态**列中会显示**已关闭**，并且批次顶部会出现一条通知，说明该批次已关闭。批次关闭后，拥有**录入捐款**权限的人员仍可查看该批次，但无法添加、编辑或删除其中的捐款，也无法更改批次的名称或日期。

若要再次进行更改，请打开批次并点击**重新打开批次**。新建的批次始终从开放状态开始。

:::info
只有拥有**编辑捐款**权限的人员才能看到**关闭批次**和**重新打开批次**按钮。如果需要更正，他们也可以在不重新打开批次的情况下更改已关闭批次中的捐款。
:::

## 谁可以更改批次 {#who-can-change-a-batch}

有两项[角色权限](../settings/roles-permissions.md)允许某人处理批次：

- **编辑捐款** -- 完全访问权限：添加和删除批次、关闭和重新打开批次，以及无论批次是开放还是关闭，都可以添加、编辑或删除任何捐款。
- **录入捐款** -- 适用于负责计数的团队和录入奉献的志愿者。他们可以添加批次，并添加、编辑或删除捐款，但仅限于批次处于开放状态时。他们无法删除批次、关闭或重新打开批次，也无法更改通过在线奉献收到的捐款。

拥有**录入捐款**但没有**查看捐款汇总**权限的人员，会在 B1 Admin 菜单中看到**捐款**，点击后直接进入批次页面。他们看不到**汇总**、**基金**、**募捐活动**和**奉献证明**。要打开批次并查看其中的捐款，该角色还需要**查看捐款**权限。

:::tip
常见的设置是创建一个"计数团队"角色，授予**录入捐款**和**查看捐款**权限，同时由财务主管在存款核对完成后拥有**编辑捐款**权限并关闭每个批次。
:::

## 打印批次

打开批次并点击捐款列表上方的**打印**，即可打印一份纸质副本，供计数团队或存款记录使用。打印内容包括：

- 您教会的名称、批次名称和批次日期
- 批次中的每笔捐款，包括捐助者姓名、方式、备注、日期和金额（已退款的奉献会被划线并标记为已退款）
- **基金小计** -- 批次中捐给每个基金的合计金额
- **批次总计** -- 整个批次的合计金额

**打印**按钮只有在批次中至少有一笔捐款后才会出现。

### 一次打印多个批次

若要在一次操作中打印某一时期的所有批次（例如上个月的所有存款），请点击**批次**页面顶部、**导出**旁边的**打印**。**打印批次**页面会打开，其**开始日期**和**结束日期**默认为过去 30 天。更改任一日期即可选择不同的范围。

日期在该范围内（包括开始和结束日期）的每个批次都会按日期顺序打印，每页一个批次，使用与单个批次打印件相同的版式。没有捐款的批次将被省略；如果该范围内的所有批次都没有捐款，您将看到"此日期范围内没有包含捐款的批次。"。点击**打印**即可打开浏览器的打印对话框，或点击**关闭**返回批次列表。

## 导出批次到 QuickBooks Online

打开批次并点击**导出到 QuickBooks**，即可将该批次下载为日记账分录，供 QuickBooks Online 导入（**设置 > 导入数据 > 日记账分录**）。该文件包含一笔借记至**未存入资金**的分录（金额为批次总计），以及每个基金各一笔贷记分录，并以每个基金的名称作为账户名称。导入时，QuickBooks 会要求您将这些名称与您的会计科目表相匹配，因此请按照您的会计师为收入账户命名的方式为基金命名，或在导入时一次性进行映射。

:::tip
请始终如一地为批次命名，以便日后轻松查找。在名称中包含日期和募捐类型（例如"周日上午 - 2025-02-09"），可以在批次列表不断增长时保持其井然有序。
:::
