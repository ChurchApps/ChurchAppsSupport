# 管理基金

<div class="article-intro">

基金让你按用途对奉献进行分类，从而跟踪教会在每个事工领域获得的奉献金额。常见的基金包括总基金、建堂基金、宣教和青少年事工，但你可以根据需要创建任意数量的基金。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要有权访问 B1 Admin 中的**奉献**板块
- 确定教会需要哪些奉献类别，以及每个类别是否可以享受免税

</div>

## 基金页面 {#the-funds-page}

进入 **Donations > Funds**，即可查看所有基金的列表。每一行显示基金名称及其 **Tax Status**（税务状态）（可免税或不可免税），该状态决定发给该基金的奉献是否会出现在年终的[奉献收据](giving-statements.md)中。

## 创建新基金 {#creating-a-new-fund}

1. 点击页面顶部的 **Add Fund**。
2. 输入基金名称（例如"建堂基金"）。
3. 如果发给该基金的奉献应计入奉献收据，请勾选 **Tax Deductible**（可免税）。发给不可免税基金的奉献仍会列在捐赠人人员记录的奉献历史中。
4. 保持勾选 **Visible to Donors**（对捐赠人可见），即可在公开和成员的奉献表单中显示该基金；取消勾选则会对捐赠人隐藏该基金，但仍可用于手动登记的奉献。
5. 点击 **Save**。

新基金会立即出现在列表中，并可用于登记奉献。

## 编辑和删除基金 {#editing-and-deleting-funds}

- 若要编辑基金，请点击其所在行上的 **Edit**。你可以更改名称、切换免税设置，或切换 **Visible to Donors**，以在奉献表单中显示或隐藏该基金。
- 若要删除基金，请打开编辑表单，点击 **Delete**，然后确认。
- 若要分享一个打开奉献页面且已预先选定该基金的链接，请点击其所在行上的 **Giving Link**（奉献链接）（参见[预设基金和金额的链接](online-giving-setup.md#links-with-a-preset-fund-and-amount)）。

:::warning
删除基金不会移除先前分配到该基金的奉献。这些奉献记录仍保留在系统中，但该基金将不再可用于新的奉献。
:::

:::info
对捐赠人隐藏的基金，在本列表中名称旁边会显示 **Hidden**（已隐藏）标记。已隐藏的基金仍可用于在 B1 Admin 中手动登记的奉献——只是不会作为选项出现在公开或成员的奉献表单中。
:::

## 查看基金详情 {#viewing-fund-details}

点击**基金名称**即可打开其详情页面。该页面显示：

- **Summary**（摘要）——页面标题下方的一行信息，显示所选时段内的奉献笔数、奉献者人数和总金额
- **年份按钮**——页面默认打开当前年份；点击其他年份即可显示该日历年的数据
- **日期范围筛选器**——设置 **Start Date** 和 **End Date**，然后点击 **Filter**，即可将结果缩小到特定时段
- **奉献历史**——列出发给该基金的奉献，包括日期、批次、捐赠人和金额。点击列表上方的 **Export**，即可将其下载为 CSV。

当你需要就某项特定的奉献计划进行报告，或检查筹款目标的进展时，此视图非常有用。

## 排序和导出 {#sorting-and-exporting}

- 使用列标题可按名称对基金排序。
- 点击页面顶部的 **Export**，即可将基金列表下载为电子表格（CSV）。

:::tip
在开始[登记奉献](recording-donations.md)之前，请先设置好所有基金。事先备齐所有基金，可确保奉献从一开始就被正确分类。
:::

## 后续步骤 {#next-steps}

基金设置完成后，你可以在批次中[登记奉献](recording-donations.md)时将其分配给各笔奉献。在生成[奉献收据](giving-statements.md)之前，请务必将适当的基金标记为可免税。
