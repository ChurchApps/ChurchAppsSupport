# 管理基金

<div class="article-intro">

基金可以让您按用途对奉献进行分类，从而追踪教会在每个事工领域获得的奉献金额。常见的基金包括普通基金、建堂基金、宣教基金和青少年事工基金，但您可以根据需要创建任意数量的基金。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要有权访问 B1 Admin 中的 **Donations** 部分
- 确定教会需要哪些奉献类别，以及每个类别是否可以享受免税

</div>

## 基金页面

导航至 **Donations > Funds** 即可查看所有基金的列表。每一行显示基金名称及其 **Tax Status**（可免税或不可免税），这决定了捐给该基金的奉献是否会出现在年终[奉献报表](giving-statements.md)上。

## 创建新基金

1. 点击页面顶部的 **Add Fund**。
2. 输入基金名称（例如“建堂基金”）。
3. 如果捐给该基金的奉献应列入奉献报表，请勾选 **Tax Deductible**。捐给不可免税基金的奉献仍会列在捐献者个人档案的奉献记录中。
4. 保持勾选 **Visible to Donors**，即可在公开和成员奉献表单中显示该基金；取消勾选则会对捐献者隐藏该基金，但仍可用于手动记录的奉献。
5. 点击 **Save**。

新基金会立即出现在列表中，并可在录入奉献时使用。

## 编辑和删除基金

- 如需编辑基金，请点击该行的 **Edit**。您可以更改名称、切换免税设置，或切换 **Visible to Donors** 以在奉献表单中显示或隐藏该基金。
- 如需删除基金，请打开编辑表单并点击 **Delete**。

:::warning
删除基金不会移除之前分配给该基金的奉献记录。这些奉献记录仍保留在系统中，但该基金将不能再用于新的奉献。
:::

:::info
对捐献者隐藏的基金会在列表中名称旁显示 **Hidden** 标记。隐藏的基金仍可用于在 B1 Admin 中手动记录的奉献，只是不会出现在公开或成员奉献表单的选项中。
:::

## 查看基金详情

点击**基金名称**即可打开其详情页面。该页面显示：

- **Summary** -- 页面标题下方的一行摘要，包括奉献笔数、捐献人数以及总金额
- **Date range filter** -- 设置 **Start Date** 和 **End Date**，然后点击 **Filter**，即可将结果缩小到特定时间段
- **Donation history** -- 该基金的奉献列表，包括日期、批次、捐献人和金额。点击列表上方的 **Export** 即可将其下载为 CSV 文件

当您需要就某项特定的奉献计划进行汇报，或检查筹款目标的进度时，此页面非常有用。

## 排序和导出

- 使用列标题可按名称对基金排序。
- 点击页面顶部的 **Export**，即可将基金列表下载为电子表格（CSV）。

:::tip
在开始[录入奉献](recording-donations.md)之前，请先设置好您的基金。预先建立所有基金，可以确保奉献从一开始就被正确分类。
:::

## 后续步骤

基金设置完成后，您可以在批量[录入奉献](recording-donations.md)时将其分配给每笔奉献。在生成[奉献报表](giving-statements.md)之前，请确保已将相应基金标记为可免税。
