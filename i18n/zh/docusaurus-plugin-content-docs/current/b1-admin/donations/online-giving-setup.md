# 在线捐献设置

<div class="article-intro">

B1 Admin 与 **Stripe**、**PayPal**、**Kingdom Funding** 和 **Paystack**（用于非洲的教会）集成，使您的成员可以通过您的 B1.church 网站在线捐献。配置后，在线捐献会自动出现在您的捐献记录中，与手动输入的捐献一起保存，将一切保存在一个系统中。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置您的[捐献基金](funds.md)，以便捐献者可以指定他们的捐献
- 在 [stripe.com](https://stripe.com) 创建 Stripe 账户并激活它（退出测试模式）
- 准备好您的 B1 Admin 登录凭据

</div>

## 设置 Stripe

1. 如果您还没有 Stripe 账户，请在 [stripe.com](https://stripe.com) 创建一个账户。确保**激活您的账户**并退出测试模式。
2. 在 Stripe 中，转到**开发人员 > API 密钥**。
3. 复制您的**可发布密钥**。
4. 登录 [B1 Admin](https://admin.b1.church/)。
5. 转到**设置**并打开**捐献**部分。
6. 点击**捐献**部分上的编辑图标。
7. 将**提供商**设置为 **Stripe**。
8. 将您的可发布密钥粘贴到**公开密钥**字段中。
9. 回到 Stripe 并显示您的**密钥**（您只能查看一次，所以请保存备份）。
10. 将密钥粘贴到**密钥**字段中，然后点击**保存**。

:::warning
您的 Stripe 密钥只显示一次。在离开 Stripe 仪表板之前，请将其复制到安全位置。如果您丢失了它，您将需要生成新密钥。
:::

## 选择您的货币

选择 Stripe 作为您的提供商后，**货币**下拉菜单会在您的 API 密钥旁边显示。选择与您的 Stripe 账户结算货币相匹配的货币，以便正确收取捐献。

支持的货币包括美元、欧元、英镑、加元、澳元、印度卢比、日元、新加坡元、港元、瑞典克朗、挪威克朗、丹麦克朗、瑞士法郎、墨西哥比索和巴西雷亚尔。您可以在 [Stripe 仪表板](https://dashboard.stripe.com/settings/currencies) 中确认或更改您账户的默认货币。

:::info
您在此处选择的货币用于一次性捐献、定期订阅、费用计算和捐献报告。如果您稍后切换货币，只有新的捐献和订阅将使用新货币——现有的定期捐献将继续使用它们创建时的货币。
:::

:::warning
确保您的 Stripe 账户配置为接受您选择的货币。如果您的 Stripe 账户不支持所选货币，捐献将在结账时失败。
:::

## Apple Pay 和 Google Pay

使用 Stripe 的教会在公共捐献页面上自动获得 Apple Pay 和 Google Pay 按钮。这些按钮会在捐献者选择基金和金额后出现在卡片字段上方，仅当捐献者的浏览器或设备设置了钱包时才出现。定期捐献仍然使用卡片或银行字段。

Google Pay 无需设置。Apple Pay 需要将您的捐献页面域注册到 Stripe；B1 在捐献页面首次在您的域上加载时注册它。如果 Apple Pay 按钮在 iPhone 上未出现，请检查您 Stripe 仪表板中的**设置 > 支付方法域**，并确认您的 `yoursubdomain.b1.church`（或自定义）域已列出并验证。

## 匿名捐献

公共捐献页面上的捐献者可以选中**匿名捐献**。匿名捐献是在没有捐献者关联的情况下记录的，仍然会进入捐献者选择的基金，并在您的批次和报告中显示为**匿名**。捐献者的电子邮件仍然是必需的，以便可以发送收据，但不会创建任何人员记录。匿名捐献仅限一次性，不会出现在任何捐献声明中。

## 失败的定期捐献

当 Stripe 上的定期捐献失败时（例如，卡过期或被拒绝），失败的交费会在**捐献 > 失败的捐献**下显示，包括捐献者、金额、日期和网关给出的原因。点击**重试**以在捐献者更新其支付方式后再次尝试收费。

B1 也会在收费失败时向捐献者发送电子邮件，如果 3 天和 7 天后仍未成功，还会再次发送电子邮件，并提供在 B1.church 中更新其支付方式的链接。

:::info
如果您的教会在此功能存在之前设置了 Stripe，请打开**设置** > **捐献**，点击编辑，然后点击**保存**一次。这会刷新 Stripe webhook，以便向 B1 报告失败的交费。
:::

## 在您的 B1.church 网站上添加捐献页面

1. 转到 [b1.church](https://b1.church/) 并登录。
2. 点击**设置**图标。
3. 点击**添加选项卡**。
4. 选择**捐献**作为类型。
5. 输入选项卡的名称（例如，"捐献"）并点击**保存**。
6. 或者，更改选项卡图标——在图标搜索中输入"捐献"以找到与捐献相关的图标。

您的捐献页面现在已上线。成员可以在 `yoursubdomain.b1.church/donate` 访问它。

## 分享您的捐献链接

要找到您的捐献 URL，请转到 **B1 Admin** 并点击**设置**图标以查看您的子域。您的捐献链接遵循以下格式：

`https://yoursubdomain.b1.church/donate`

在您的网站、电子邮件或公告栏中分享此链接，以便成员知道在哪里进行在线捐献。

### 带有预设基金和金额的链接

要直接将捐献者发送到特定基金，请转到**捐献 > 基金**并点击基金上的**捐献链接**。或者输入一个金额，然后复制链接。当捐献者打开它时，基金和金额已在捐献页面上选定。该链接的格式如下：

`https://yoursubdomain.b1.church/donate?fundId=FUND_ID&amount=25`

相同的参数也适用于网站生成器的**捐献链接**元素。

## 捐献通知

每次收到捐献时，Stripe 都会发送电子邮件通知。要更改通知电子邮件地址，请转到 Stripe 仪表板，点击右上角的您的个人资料，选择**个人资料**，并更新您的电子邮件地址。

## 处理费选项

您可以配置您的捐献页面，让捐献者可以选择承担处理费，以便您的教会收到全额捐献。此设置在 B1 Admin 中的您的教会设置中进行管理。

:::tip
设置后，进行小额测试捐献以确认一切正常运行，然后再向您的会众宣布在线捐献。
:::

## 设置 Kingdom Funding

Kingdom Funding 是一个基督教支付处理器，支持信用卡/借记卡和 ACH 银行转账。如果您的教会与 Kingdom Funding 合作，您可以将其连接为您的捐献网关。

:::info
Kingdom Funding 集成目前处于测试阶段。请与您的 B1 账户代表联系以为您的教会启用它。
:::

1. 在 [kingdomfunding.org](https://kingdomfunding.org) 注册或登录。
2. 从 Kingdom Funding 商家门户获取您的**安全密钥**（公开）和**私密密钥**。
3. 在 B1 Admin 中，转到**设置**，打开**捐献**部分并点击编辑。
4. 将**提供商**设置为 **Kingdom Funding**。
5. 将您的安全密钥粘贴到**安全密钥**字段，将您的私密密钥粘贴到**私密密钥**字段。
6. 设置您从 Kingdom Funding 收到的 **Webhook 密钥**，并将显示的 webhook URL 复制到您的 Kingdom Funding 商家设置中，以便 Kingdom Funding 可以通知 B1 已完成的交易。
7. 保存。

连接后，成员将在捐献页面上看到卡片/银行切换，可以通过信用卡或 ACH 转账捐献。

## PayPal 和 Venmo 按钮

使用 **PayPal** 作为其提供商的教会在捐献页面上的卡片字段上方为一次性捐献获得 **PayPal** 和 **Venmo** 按钮。点击其中一个的捐献者在 PayPal 窗口中完成支付，捐献被记录为任何其他在线捐献。Venmo 仅对美国捐献者和 PayPal 认为符合条件的设备显示。定期捐献仍然使用卡片字段。

## 设置 Paystack（非洲）

Stripe 不为加纳、尼日利亚、肯尼亚、南非或科特迪瓦的教会开设账户。[Paystack](https://paystack.com) 可以，并且它接受本地卡、**移动钱包**（MTN MoMo、Vodafone Cash、AirtelTigo、M-PESA）、银行转账和 USSD——捐献者以您的当地货币支付（GHS、NGN、KES、ZAR、XOF）。

1. 使用您的教会的商业注册证书和当地银行账户在 [paystack.com](https://paystack.com) 注册，并完成 Paystack 的激活（上线）审核。
2. 在 Paystack 仪表板中打开**设置 → API 密钥和 Webhooks**，并复制**公开密钥**和**密钥**（使用实时密钥，而不是测试密钥）。
3. 在 B1 Admin 中，转到**设置**，打开**捐献**部分并点击编辑。
4. 将**提供商**设置为 **Paystack**，粘贴公开密钥和密钥，并选择您的**货币**。
5. 复制提供商下显示的 **webhook URL**，回到 Paystack 仪表板（**设置 → API 密钥和 Webhooks**）并将其粘贴到 **Webhook URL** 字段。这是定期捐献和移动钱包支付如何被记录的方式。
6. 保存。

捐献者在安全的 Paystack 窗口中完成其支付，可以在那里选择卡片、移动钱包或银行转账。注意事项：

- **定期捐献**需要卡片；移动钱包不能自动再次收费，所以 Paystack 仅允许一次性移动钱包捐献。
- Paystack 定期捐献可以从 B1 取消，但不能暂停或编辑——取消并创建新的捐献来更改金额。
- **处理费**默认反映 Paystack 对您货币的本地卡费率；如果您协商的费率不同，请编辑它们。
