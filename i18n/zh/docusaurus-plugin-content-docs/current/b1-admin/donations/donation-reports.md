# 捐赠报告

<div class="article-intro">

B1Admin 为您提供了多种方式来查看和分析您的教会的捐赠数据。捐赠摘要页面提供带有图表和过滤器的视觉概览，而报告部分提供更详细的捐赠摘要报告。使用这些工具来跟踪捐赠趋势、为董事会会议做准备或核对您的记录。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 确保捐赠已被[批量记录](recording-donations.md)或[从 Stripe 导入](stripe-import.md)
- 验证您的[基金](funds.md)已正确设置，以便捐赠被正确分类

</div>

## 捐赠仪表板

**捐赠仪表板**是您打开**捐赠**部分时看到的第一件事。它通过关键绩效指标提供捐赠活动的高级视图。

1. 打开左上角的**部分菜单**并选择**捐赠**以打开仪表板。
2. 在顶部，四个**KPI 卡片**一目了然地显示您的捐赠指标：
   - **总捐赠** — 所选期间的总捐赠金额。
   - **平均捐赠** — 平均捐赠金额。
   - **唯一捐赠者** — 进行捐赠的不同人数。
   - **总捐赠** — 个人捐赠的总数。
3. 使用**期间切换**在**每周**、**每月**和**每季度**视图之间切换。
4. 在 KPI 下方，图表显示所选期间的捐赠趋势。
5. 单击**下载**导出带有捐赠总计的 CSV 文件。

## 捐赠摘要页面

**摘要**页面提供更详细的汇总捐赠数据。

1. 打开左上角的**部分菜单**并选择**捐赠**以打开摘要页面。
2. 使用**日期范围过滤器**选择您想要审查的时间段。在顶部设置较早的日期，在底部设置较近的日期。
3. 页面显示周捐赠图表，以便您可以一目了然地看到趋势。
4. 单击**下载**导出带有捐赠总金额、捐赠周数和捐赠基金的 CSV 文件。

:::info
摘要页面显示汇总捐赠数据。它不包括个人捐赠者名称。对于捐赠者级别的详情，请使用[批次](batches.md)页面。
:::

## 查看捐赠者级别详情

对于谁捐赠、捐赠多少及捐赠哪个基金的分解：

1. 导航到**捐赠 > 批次**。
2. 单击**批次名称**以打开它。
3. 批次详情页面列出每笔捐赠，包括捐赠者的姓名、金额、基金、日期和付款方法。
4. 单击**捐赠者的姓名**以查看他们捐赠多少次以及每次捐赠多少的分解。
5. 单击**捐赠 ID** 以打开一个侧面板，显示该个人捐赠的完整详情。
6. 单击**下载**导出 CSV，其中包含该批次的所有捐赠者和捐赠信息。

## 捐赠摘要报告

捐赠报告直接构建在捐赠部分中 — 摘要页面充当您的捐赠摘要报告：

1. 打开左上角的**部分菜单**并选择**捐赠**以打开摘要页面。
2. 使用**日期范围过滤器**选择要报告的期间。
3. 单击**下载**导出报告为 CSV 文件。

## 导出数据

您可以从多个位置导出捐赠数据：

- **摘要页面** — 下载按基金分类的每周捐赠总计 CSV
- **批次详情页面** — 下载包含捐赠者详情的个人捐赠 CSV
- **基金详情页面** — 下载特定基金的捐赠历史

:::tip
对于年底报告，将摘要页面导出与[捐赠声明](giving-statements.md)工具结合使用，以获取汇总趋势和个人捐赠者声明。
:::
