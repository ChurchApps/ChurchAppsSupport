# 捐献报告

<div class="article-intro">

B1 Admin为您提供了查看和分析教会给予数据的多种方式。捐献**摘要**页面上的给予仪表板提供了带有图表和过滤器的可视化概览，而报告部分提供了更详细的捐献摘要报告。使用这些工具来跟踪给予趋势、为董事会会议做准备或对账您的记录。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 确保捐献已[记录在批次中](recording-donations.md)或[从Stripe导入](stripe-import.md)
- 验证您的[基金](funds.md)设置正确，以便捐献被正确分类

</div>

## 给予仪表板

给予仪表板是**摘要**页面的**仪表板**标签页，这是您打开**捐献**部分时看到的第一页。

1. 打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin左上角的搜索栏），展开**捐献**，然后点击**摘要**。**摘要**页面在**仪表板**标签页上打开。
2. 使用报告上方的**周**、**月**和**季度**切换来选择如何分组给予。
3. 在**过滤报告**面板中，设置**开始日期**和**结束日期**（默认为过去一年到昨天），可选地选择**基金**，然后点击**运行报告**。页面打开时报告会自动与默认值一起运行。
4. 四个**KPI卡片**显示选定范围的给予指标：
   - **总捐献** -- 捐献的总金额。
   - **平均礼物** -- 平均捐献金额。
   - **独特捐献者** -- 捐献的不同人数。
   - **总捐献数** -- 单个捐献的总数。
5. KPI下面，柱状图按周、月或季度显示给予，按基金分解。
6. 点击**下载选项**并选择**摘要**来导出按时期和基金的总数的CSV，或点击打印图标来打印报告。教会名称出现在打印报告的顶部。

如果期间的捐献以多种货币给出，KPI总数转换为教会货币，并在卡片下方显示**按当前汇率转换**注释。有关详细信息，请参见[多货币支持](./multi-currency.md#converted-totals)。

:::info
仪表板显示聚合给予数据。它不包括单个捐献者名称。对于捐献者级别的详情，使用[批次](batches.md)页面。
:::

## 流失捐献者

**仪表板**标签页旁边的**流失捐献者**标签页列出在一个时期内给予但之后没有给予的人。默认情况下，它将去年与今年迄今为止进行比较；更改任一日期范围来扩大或缩小搜索。每行显示人员、其最后礼物的日期和较早时期的总额，以及**下载选项 > 摘要**下载列表作为CSV进行后续邮件或通话列表。

## 查看捐献者级别详情

要了解谁给予、给予多少以及给予哪个基金的分解：

1. 导航到**捐献 > 批次**。
2. 点击**批次名称**来打开它。
3. 批次详情页面列出每项捐献，包括捐献者名称、金额、基金、日期和付款方法。
4. 点击**捐献者名称**来查看他们捐献了多少次及每次捐献多少的分解。
5. 点击**捐献ID**来打开一个显示该单个捐献的完整详情的侧面板。
6. 点击**下载**来导出CSV，包含该批次的所有捐献者和捐献信息。

## 捐献摘要报告

捐献报告直接构建到捐献部分 -- 摘要页面作为您的捐献摘要报告：

1. 在Jump菜单中，选择**捐献 > 摘要**。
2. 在**仪表板**标签页上，在**过滤报告**面板中设置**开始日期**和**结束日期**，然后点击**运行报告**。
3. 点击**下载选项**并选择**摘要**来将报告导出为CSV文件。

## 导出数据

您可以从多个地方导出捐献数据：

- **摘要页面** -- 下载按周、月或季度和基金的给予总数的CSV
- **批次详情页面** -- 下载包含捐献者详情的单个捐献的CSV
- **基金详情页面** -- 下载特定基金的捐献历史

:::tip
对于年终报告，结合摘要页面导出与[捐赠声明](giving-statements.md)工具来获得聚合趋势和单个捐献者声明。
:::
