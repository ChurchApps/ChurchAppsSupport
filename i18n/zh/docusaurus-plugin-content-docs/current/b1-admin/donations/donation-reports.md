# 捐赠报告

<div class="article-intro">

B1 Admin为您提供了多种方式来查看和分析教会的捐赠数据。捐赠摘要页面提供了一个带有图表和过滤器的可视概览,而报告部分提供了更详细的捐赠摘要报告。使用这些工具跟踪捐赠趋势、为董事会会议做准备或协调您的记录。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 确保捐赠已[按批次记录](recording-donations.md)或[从Stripe导入](stripe-import.md)
- 验证您的[基金](funds.md)设置正确,以便正确分类捐赠

</div>

## 捐赠仪表板

**捐赠仪表板**是打开**捐赠**部分时首先看到的内容。它通过关键绩效指标提供捐赠活动的高级视图。

1. 打开左上角的**部分菜单**,选择**捐赠**打开仪表板。
2. 在顶部,四个**KPI卡**一目了然地显示您的捐赠指标:
   - **总捐赠** - 在选定期间内捐赠的总金额。
   - **平均捐赠** - 平均捐赠金额。
   - **独特捐赠者** - 捐赠的不同人数。
   - **总捐赠数** - 个别捐赠的总数。
3. 使用**周期切换**在**周**、**月**和**季度**视图之间切换。
4. 在KPI下方,图表显示所选时期的捐赠趋势。
5. 单击**下载**以导出包含捐赠总额的CSV文件。

如果期间内的捐赠以多种货币进行,KPI总额将转换为您的教会货币,**以当前汇率转换**的注释将显示在卡下方。有关详细信息,请参阅[多货币支持](./multi-currency.md#converted-totals)。

## 停止捐赠者

**停止捐赠者**选项卡位于仪表板旁,列出在一个期间内捐赠但自那以后未捐赠的人。默认情况下,它比较去年日历与今年至今;更改任一日期范围以扩大或缩小搜索。每行显示人员、他们的最后一笔礼物的日期和早期时期的总额,**导出**将列表下载为CSV用于跟进邮寄或电话列表。

## 捐赠摘要页面

**摘要**页面提供了更详细的汇总捐赠数据。

1. 打开左上角的**部分菜单**,选择**捐赠**打开摘要页面。
2. 使用**日期范围过滤器**选择您想要审查的时间段。将较早的日期设置在顶部,将较近的日期设置在底部。
3. 该页面显示每周捐赠图表,以便您可以一目了然地看到趋势。
4. 单击**下载**以导出CSV文件,包括给定的总金额、给定的周和给定的基金。

:::info
摘要页面显示汇总捐赠数据。它不包括个别捐赠者的名称。有关捐赠者级别的详细信息,请使用[批次](batches.md)页面。
:::

## 查看捐赠者级别的详细信息

要查看谁捐赠了、捐赠了多少以及捐赠给哪个基金的分解:

1. 导航到**捐赠 > 批次**。
2. 单击**批次名称**以打开它。
3. 批次详细信息页面列出每笔捐赠,包括捐赠者的姓名、金额、基金、日期和付款方式。
4. 单击**捐赠者的姓名**查看他们捐赠了多少次和每次捐赠多少的分解。
5. 单击**捐赠ID**打开一个侧面板,其中显示该个别捐赠的完整详细信息。
6. 单击**下载**以导出CSV,其中包含该批次的所有捐赠者和捐赠信息。

## 捐赠摘要报告

捐赠报告直接内置在捐赠部分 - 摘要页面作为您的捐赠摘要报告:

1. 打开左上角的**部分菜单**,选择**捐赠**打开摘要页面。
2. 使用**日期范围过滤器**选择您想要报告的期间。
3. 单击**下载**以导出报告为CSV文件。

## 导出数据

您可以从多个地方导出捐赠数据:

- **摘要页面** - 下载按基金的每周捐赠总额的CSV
- **批次详细信息页面** - 下载个别捐赠的CSV,包括捐赠者详细信息
- **基金详细信息页面** - 下载特定基金的捐赠历史

:::tip
对于年终报告,将摘要页面导出与[捐赠声明](giving-statements.md)工具相结合,以获取汇总趋势和个别捐赠者声明。
:::
