# 多币种支持

<div class="article-intro">

B1 的多币种功能让教会能够接收并追踪不同币种的奉献。这对于拥有国际会员、宣教士或位于不同国家的多个校区的教会尤其有用。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要拥有管理奉献的权限。详情请参见[角色与权限](../people/roles-permissions.md)。
- 使用 Stripe 设置您的[在线奉献](./online-giving-setup.md)，Stripe 支持多币种交易。没有在线奉献的教会仍然可以选择手动录入奉献所用的币种。
- 了解教会在处理多种币种时的会计需求。

</div>

您教会的币种默认为教会注册时所在国家的币种（例如位于肯尼亚的教会默认为肯尼亚先令），在尚未保存任何币种时即使用该币种。您可以随时在 **Manage Church → Giving** 下更改。如果无法识别您的国家，则默认为美元。

## 启用多币种

B1 现已默认启用多币种支持。启用后：

- 会员在线奉献时可以使用当地币种
- 您可以手动以任何币种记录奉献
- 奉献报告会以原始币种显示金额
- 在线奉献由 Stripe 自动处理货币换算

## 支持的币种

系统支持所有主要世界货币，包括：

- **USD**——美元
- **EUR**——欧元
- **GBP**——英镑
- **CAD**——加拿大元
- **AUD**——澳大利亚元
- **MXN**——墨西哥比索
- **BRL**——巴西雷亚尔
- **INR**——印度卢比
- **CNY**——人民币
- **JPY**——日元
- 以及更多……

在线奉献可用的币种取决于您的 Stripe 账户支持的币种。

## 以不同币种记录奉献

### 在线奉献

当会员通过 Stripe 在线奉献时：

1. 他们在结账时选择偏好的币种
2. Stripe 以该币种处理付款
3. 奉献以原始币种金额记录在 B1 中
4. Stripe 自动将其换算为您账户的默认币种（如需换算）

### 手动录入

您手动录入的现金和支票奉献，会以教会的币种记录——即在 **Settings > Giving** 中设置的**币种**（参见[设置教会币种](./online-giving-setup.md#choosing-your-currency)）。每笔奉献不能单独选择币种。**Amount**（金额）输入框末尾会显示币种代码（例如 *PHP*），让您知道正在输入哪种币种的金额。

1. 在 B1 Admin 中前往 **Donations > Batches**，并打开该批次
2. 点击批次页面顶部的 **Add Donation**（添加奉献）
3. 以教会的币种输入金额
4. 填写其余的奉献详情
5. 点击 **Save**

编辑已有的奉献时，它会保留最初记录时的币种。

## 查看多币种奉献

### 奉献报告

奉献报告以原始币种显示金额：

- 单笔奉献记录会显示币种代码（例如“$100.00 USD”）
- 合计按币种分别计算
- 您可以按特定币种进行筛选

### 换算后的合计 {#converted-totals}

凡是 B1 显示单一合计金额的地方——奉献汇总的 KPI 卡片、奉献批次合计，以及基金合计——以非教会默认币种记录的奉献，都会按当前汇率换算为教会的币种，因此合计结果是一个有意义的单一数字，而不会将不同币种直接相加。只要进行了换算，合计金额下方就会显示 **Converted at current exchange rates**（按当前汇率换算）的说明。单笔奉献明细仍以原始币种显示。

### 奉献证明

生成奉献证明时：

- 每笔奉献都以其原始币种显示
- 合计按币种分别列出
- 会员可以清楚地看到自己在每种币种下的奉献金额

## Stripe 集成

对于在线奉献，Stripe 负责处理多币种交易：

- **自动换算**——Stripe 将各种币种换算为您账户的默认币种
- **汇率**——Stripe 使用当前的市场汇率
- **手续费**——货币换算可能会产生额外的 Stripe 费用
- **结算币种**——款项将以您账户的默认币种存入

:::info
请在 Stripe 后台查看当前的换算汇率，以及多币种交易可能产生的费用。
:::

## 会计注意事项

处理多种币种时：

- **记录保存**——保留奉献的原始金额和币种，以确保报告准确
- **汇率**——请注意 Stripe 的换算汇率可能与您银行的汇率不同
- **税务收据**——请咨询会计师，了解如何为税务目的报告不同币种的奉献
- **基金分配**——无论币种如何，您都可以将奉献分配到特定基金

## 最佳实践

- **默认币种**——在 **Settings > Giving** 中设置教会的主要币种，使手动录入的奉献和奉献合计都使用该币种
- **清晰沟通**——在结账过程中告知捐赠人他们以何种币种奉献
- **一致的报告**——合计金额始终会自动换算为教会的币种；需要查看原始金额时，请使用按奉献币种筛选的功能
- **定期对账**——将 Stripe 的结算款项与奉献记录进行核对，并考虑货币换算的影响

## 限制

- 在线奉献的付款处理货币换算仅由 Stripe 负责；手动奉献按录入金额记录，不会自动换算
- 历史报告和单笔奉献明细始终显示奉献记录时的原始币种
- 合计金额（KPI 卡片、批次合计、基金合计）均按当前汇率换算为教会的币种——这些汇率可能与款项结算时您银行或 Stripe 的汇率略有不同
