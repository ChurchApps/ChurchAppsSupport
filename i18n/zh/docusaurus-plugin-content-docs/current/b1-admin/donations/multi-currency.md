# 多币种支持

<div class="article-intro">

B1 的多币种功能让教会能够接受并跟踪不同货币的奉献。这对于拥有国际会员、宣教士或位于不同国家的多个堂区的教会尤其有用。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要具有管理奉献的权限。详情请参见[角色与权限](../people/roles-permissions.md)。
- 请使用 Stripe 设置你的[在线奉献](./online-giving-setup.md)，Stripe 支持多币种交易。未设置在线奉献的教会仍可选择手动录入奉献所使用的货币。
- 了解教会在处理多种货币方面的会计需求。

</div>

你的教会货币最初为教会注册时所填国家的货币（例如，肯尼亚的教会使用肯尼亚先令），若尚未保存任何货币，则使用该货币。你可以随时在 **Settings → Giving**（设置 → 奉献）下更改（**Currency** 下拉菜单）。如果系统无法识别你的国家，则默认为美元。

## 启用多币种 {#enabling-multi-currency}

B1 默认已启用多币种支持：

- 在线奉献按你在 **Giving** 设置中选择的货币收取
- 每笔奉献都保留其登记时所用的货币，单笔奉献明细会显示该货币
- 合计金额会换算为你的教会货币（参见[换算后的合计](#converted-totals)）
- 对于在线奉献，Stripe 会处理货币换算，将款项换算为你的收款货币

## 支持的货币 {#supported-currencies}

系统支持所有主要的世界货币，包括：

- **USD**——美元
- **EUR**——欧元
- **GBP**——英镑
- **CAD**——加拿大元
- **AUD**——澳大利亚元
- **MXN**——墨西哥比索
- **BRL**——巴西雷亚尔
- **INR**——印度卢比
- **CNY**——人民币
- **JPY**——日元
- 以及更多……

在线奉献可用的货币取决于你的 Stripe 账户所支持的货币。

## 以不同货币登记奉献 {#recording-donations-in-different-currencies}

### 在线奉献 {#online-donations}

当成员通过 Stripe 在线奉献时：

1. 奉献将按 **Settings → Giving** 中设置的货币收取；捐赠人在结账时无法选择货币
2. Stripe 以该货币处理付款
3. 奉献会以该货币和金额记录在 B1 中
4. Stripe 会自动处理所需的货币换算，将款项换算为你账户的收款货币

如果你之后更改 **Currency** 设置，新的奉献将使用新货币，而已登记的奉献仍保留原有货币，因此你的记录中可能同时包含多种货币。

### 手动录入 {#manual-entry}

你手动录入的奉献——无论是在批次中、使用 **Import CSV** 导入，还是在人员记录上使用 **Log a gift**（记录奉献）——始终以你的教会货币记录，该货币会显示在 **Amount**（金额）字段旁边。手动录入没有货币下拉菜单，因此如果奉献是以其他货币进行的，请在录入前将其换算为教会货币；如有需要，请在 **Notes**（备注）中记下原始金额。

## 查看多币种奉献 {#viewing-multi-currency-donations}

### 奉献报表 {#donation-reports}

单笔奉献明细——在批次中、基金页面上以及人员的奉献历史中——都会以其登记时所用的货币显示。合计金额则按下文所述进行换算。

### 换算后的合计 {#converted-totals}

凡是 B1 显示单一合计金额的地方——奉献概览的 KPI 卡片、奉献批次合计以及基金总额——以非教会默认货币登记的奉献，都会按当前汇率换算为教会货币，因此合计金额是一个有意义的单一数字，而不是将不同货币直接相加。只要进行了换算，合计金额下方就会显示 **Converted at current exchange rates**（按当前汇率换算）的说明。单笔奉献明细仍以原始货币显示。

### 奉献收据 {#giving-statements}

奉献收据会按登记时的金额列出每笔奉献，并直接相加而不进行换算，因此只有当该捐赠人当年的所有奉献都使用你的教会货币时，收据才准确。如果某位捐赠人使用了多种货币奉献，请在发送收据前仔细核对。

## Stripe 集成 {#stripe-integration}

对于在线奉献，Stripe 负责处理多币种交易：

- **自动换算**——Stripe 会将货币换算为你账户的默认货币
- **汇率**——Stripe 使用当前的市场汇率
- **费用**——货币换算可能产生额外的 Stripe 费用
- **收款货币**——款项将以你账户的默认货币存入

:::info
请查看你的 Stripe 后台，了解当前的换算汇率以及多币种交易可能产生的费用。
:::

## 会计注意事项 {#accounting-considerations}

处理多种货币时：

- **记录保存**——保留原始奉献金额和货币，以便进行准确的报告
- **汇率**——请注意，Stripe 的换算汇率可能与你银行的汇率不同
- **税务收据**——就如何为税务目的报告不同货币的奉献，请咨询你的会计师
- **基金分配**——无论使用何种货币，你都可以将奉献分配到特定基金

## 最佳实践 {#best-practices}

- **默认货币**——在 **Settings > Giving** 中设置你的主要教会货币，使手动录入的奉献和奉献合计均使用该货币
- **清晰沟通**——在结账过程中告知捐赠人他们将以何种货币奉献
- **报告一致性**——合计金额始终会自动换算为你的教会货币；打开批次或基金即可查看每笔奉献的原始金额和货币
- **定期对账**——将 Stripe 的付款与你的奉献记录进行核对，并考虑货币换算因素

## 限制 {#limitations}

- 付款处理中的货币换算仅针对在线奉献，由 Stripe 负责；手动奉献按录入时的教会货币记录
- 历史报表和单笔奉献明细始终显示奉献登记时的原始货币
- 合计金额（KPI 卡片、批次合计、基金总额）按当前汇率换算为教会货币——这些汇率可能与基金结算时你银行或 Stripe 的汇率略有不同
