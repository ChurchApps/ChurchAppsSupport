# 多货币支持

<div class="article-intro">

B1的多货币功能允许您的教会接受和跟踪不同货币的捐赠。这对于拥有国际成员、传教士或不同国家多个校园的教会特别有用。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要管理捐赠的权限。有关详细信息,请参阅[角色和权限](../people/roles-permissions.md)。
- 使用支持多货币交易的Stripe设置[在线捐赠](./online-giving-setup.md)。
- 了解您的教会处理多种货币的会计需求。

</div>

## 启用多货币

B1中现在默认启用了多货币支持。启用后:

- 成员在在线捐赠时可以用当地货币捐赠
- 您可以手动记录任何货币的捐赠
- 捐赠报告显示原始货币中的金额
- Stripe为在线捐赠自动处理货币转换

## 支持的货币

该系统支持所有主要的世界货币,包括:

- **USD** - 美元
- **EUR** - 欧元
- **GBP** - 英镑
- **CAD** - 加拿大元
- **AUD** - 澳大利亚元
- **MXN** - 墨西哥比索
- **BRL** - 巴西雷亚尔
- **INR** - 印度卢比
- **CNY** - 中国元
- **JPY** - 日元
- 以及更多...

在线捐赠的可用货币取决于您Stripe账户支持的货币。

## 记录不同货币的捐赠

### 在线捐赠

当成员通过Stripe在线捐赠时:

1. 他们在结账时选择他们的首选货币
2. Stripe以该货币处理付款
3. 捐赠以原始货币金额记录在B1中
4. Stripe自动处理任何必要的货币转换到您账户的默认货币

### 手动输入

要记录现金或支票捐赠以不同货币:

1. 导航到B1 Admin中的**捐赠**
2. 单击**添加捐赠**
3. 从货币下拉菜单中选择货币
4. 输入该货币中的金额
5. 完成其余捐赠详细信息
6. 单击**保存**

## 查看多货币捐赠

### 捐赠报告

捐赠报告以原始货币显示金额:

- 个别捐赠记录显示货币代码(例如,"$100.00 USD")
- 按货币计算总计
- 您可以按特定货币过滤

### 转换的总计

只要B1显示单个综合总计 - 捐赠摘要KPI卡、捐赠批次总计和基金的总计 - 以不同于您教会默认货币的货币记录的捐赠将使用当前汇率转换为您的教会货币,因此总计是一个单一的有意义数字,而不是将不同货币相加。**以当前汇率转换**的注释在应用转换时出现在总计下方。个别捐赠行项目仍以原始货币显示。

### 捐赠声明

生成捐赠声明时:

- 每笔捐赠以其原始货币出现
- 按货币分解总计
- 成员看到他们在每种货币中捐赠的金额

## Stripe集成

对于在线捐赠,Stripe处理多货币交易:

- **自动转换** - Stripe将货币转换为您账户的默认货币
- **汇率** - Stripe使用当前市场汇率
- **费用** - 货币转换可能会产生额外的Stripe费用
- **支付货币** - 资金以您账户的默认货币存入

:::info
检查您的Stripe仪表板以查看当前汇率和与多货币交易相关的任何费用。
:::

## 会计考虑因素

使用多种货币时:

- **记录保存** - 跟踪原始捐赠金额和货币以供准确报告
- **汇率** - 注意Stripe的转换率可能与您银行的汇率不同
- **税收收据** - 咨询您的会计师关于如何报告不同货币的捐赠用于税收目的
- **基金分配** - 无论货币如何,您都可以将捐赠分配给特定基金

## 最佳实践

- **默认货币** - 将您的主要教会货币设置为大多数交易的默认货币
- **清晰沟通** - 告诉捐赠者他们在结账过程中捐赠的货币
- **一致的报告** - 综合总计始终自动转换为您的教会货币;当您需要查看原始金额时,使用按捐赠货币过滤器
- **定期对帐** - 协调Stripe支付与您的捐赠记录,以解决货币转换

## 限制

- 支付处理的货币转换仅由Stripe为在线捐赠处理;手动捐赠以输入时的货币记录,没有自动转换
- 历史报告和个别捐赠行项目始终显示记录礼物的原始货币
- 综合总计(KPI卡、批次总计、基金总计)使用当前汇率转换为您的教会货币 - 这些汇率可能与您银行或Stripe的汇率在资金结算时略有不同
