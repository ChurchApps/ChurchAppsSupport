# Stripe 导入

<div class="article-intro">

如果你通过 Stripe 接受在线奉献，Stripe 导入工具可以将这些交易拉入 B1 Admin，使你的所有奉献数据集中在一处。这对于补录未被自动同步的交易尤其有用。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 完成[在线捐赠设置](online-giving-setup.md)，将你的 Stripe 账户连接到 B1 Admin。只有当教会的奉献网关为 Stripe 时，**Stripe Import** 菜单项和批次页面的按钮才会出现，并且仅对有权编辑奉献的人员可见
- 请确认你的 Stripe 控制台中，在你要导入的日期范围内确实有奉献记录

</div>

## 工作原理

导入过程分为两个步骤：首先预览将要导入的内容，然后确认导入。这种试运行方式可以让你在创建任何数据之前检查所有内容。

## 导入交易

1. 在 **B1 Admin** 中，进入 **Donations > Stripe Import**。（你也可以点击 **Batches** 页面顶部的 **Import missing Stripe transactions**。）
2. 打开 **Stripe Import** 页面。
3. 为你要导入的交易选择一个**日期范围**。
4. 点击 **Preview** 运行试运行检查。

## 查看预览

预览会显示 Stripe 中的每笔交易及其状态标识：

- **New** —— 该交易尚未导入，如果你继续操作，它将被包含在内。
- **Already Imported** —— 该交易已存在于 B1 Admin 中，将被跳过。
- **Skipped** —— 该交易因其他原因被排除（例如退款或失败的扣款）。

页面顶部的摘要部分会显示每个类别的交易总数以及涉及的金额。

:::info
预览步骤不会创建任何记录。它只是一个只读检查，方便你在正式提交之前核实将会发生的操作。
:::

## 完成导入

1. 查看预览结果和摘要合计。
2. 点击 **Import Missing**，导入所有标记为 **New** 的交易。
3. 导入完成后，每笔交易旁边的状态标记会更新，以显示结果。

## 使用 Stripe 导入的建议

- 定期（每周或每月）运行导入，使你的记录保持最新。
- 如果某笔交易显示为 **Already Imported**，表示 B1 Admin 中已有匹配的记录——无需任何操作。
- 如果你在查找特定交易，可使用日期范围筛选器聚焦于某一特定时段。

:::tip
导入后，请访问[批次](batches.md)页面，确认导入的奉献显示正确，并且合计金额与你在 Stripe 控制台中看到的一致。
:::

## 下一步

- 查看[奉献报表](donation-reports.md)，将导入的交易与其他奉献数据一并核对
- 确保导入的奉献已分配到正确的[基金](funds.md)，以便生成准确的[奉献报表（捐款证明）](giving-statements.md)
