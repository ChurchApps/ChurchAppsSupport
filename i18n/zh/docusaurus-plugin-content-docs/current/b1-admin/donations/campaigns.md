# 活动和承诺

<div class="article-intro">

活动让您运行针对特定目标的筹款活动 -- 建筑基金、宣教旅行、特殊项目 -- 并跟踪成员的承诺和实际捐献，以便您可以看到您的实时进度。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置您的[捐献基金](funds) -- 每个活动绑定到一个基金
- 您需要对B1 Admin的捐献部分拥有权限

</div>

## 打开活动

在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**捐献**，然后点击**活动**。您将看到所有活动及其目标金额、承诺总额和迄今为止给出的总额的列表。

## 创建活动

1. 点击**添加活动**。
2. 填入活动详情：
   - **名称** *(必需)* -- 此活动的显示名称（例如"建筑基金2026"）。
   - **基金** -- 此活动关联的捐献基金。
   - **开始日期** / **结束日期** -- 筹款窗口。
   - **目标** -- 活动的目标金额。
3. 点击**保存**。

## 跟踪进度

每个活动卡片显示：

- **目标** -- 您的目标金额
- **承诺** -- 成员承诺给予的总金额
- **给出** -- 在活动窗口期间实际捐献到此活动基金的总金额
- **进度条**显示您在目标上进展了多远

点击任何活动来打开详情视图，其中列出了单个承诺及其完成状态。

## 添加承诺

承诺是成员对活动贡献的承诺。要记录承诺：

1. 打开一个活动。
2. 点击**添加承诺**。
3. 选择做出承诺的**人**。
4. 输入承诺**金额**。
5. 可选地为承诺承诺设置**日期**。
6. 点击**保存**。

承诺出现在活动详情中，并对活动卡片上的**承诺**总数有贡献。

:::tip
承诺不同于实际捐献。承诺跟踪一个承诺；捐献记录实际的礼物。两者都显示在活动上，以便您可以看到承诺的履行情况如何。
:::

## 编辑或删除活动

点击任何活动卡片上的编辑图标来更新其名称、目标、日期或基金。点击**删除**来永久删除活动及其承诺。删除活动不会删除任何记录到其基金的捐献。
