# 募捐活动和承诺

<div class="article-intro">

募捐活动让你为特定目标进行募捐活动 — 建筑基金、宣教之旅、特殊项目 — 并跟踪成员的承诺和实际捐献，以便你可以看到你的实时进度。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 设置你的[捐献基金](funds) — 每个募捐活动都绑定到一个基金
- 你需要访问 B1 Admin 的捐献部分

</div>

## 打开募捐活动

在 B1 Admin 中，打开左上角的**部分菜单**（部分名称和小箭头）并选择**捐献**，然后选择**募捐活动**。你会看到所有募捐活动的列表，包括其目标金额、总承诺和迄今为止的总捐献。

## 创建募捐活动

1. 点击**添加募捐活动**。
2. 填写募捐活动详情：
   - **名字** *(必需)* — 此募捐活动的显示名称（例如，"2026 年建筑基金"）。
   - **基金** — 此募捐活动关联的捐献基金。
   - **开始日期** / **结束日期** — 募捐窗口。
   - **目标** — 募捐活动的目标金额。
3. 点击**保存**。

## 追踪进度

每个募捐活动卡显示：

- **目标** — 你的目标金额
- **承诺** — 成员承诺给予募捐活动的总金额
- **已给** — 募捐活动窗口期间实际捐献到此募捐活动基金的总金额
- **进度条** — 显示你完成目标的进度

点击任何募捐活动打开详情视图，其中列出个人承诺及其履行状态。

## 添加承诺

承诺是成员对募捐活动的给予承诺。要记录承诺：

1. 打开募捐活动。
2. 点击**添加承诺**。
3. 选择进行承诺的**人**。
4. 输入承诺**金额**。
5. 可选地为承诺承诺设置**日期**。
6. 点击**保存**。

承诺出现在募捐活动详情中并贡献到募捐活动卡上的**承诺**总数。

:::tip
承诺与实际捐献分开。承诺跟踪一个承诺；捐献记录实际礼物。两者都显示在募捐活动上，所以你可以看到承诺履行情况如何。
:::

## 编辑或删除募捐活动

点击任何募捐活动卡上的编辑图标以更新其名称、目标、日期或基金。点击**删除**永久删除募捐活动及其承诺。删除募捐活动不会删除任何记录到其基金的捐献。
