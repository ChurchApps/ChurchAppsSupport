# 活动筹款与认捐

<div class="article-intro">

筹款活动让你围绕特定目标开展募款——例如建堂基金、宣教短宣或特别项目——并将成员的认捐与实际奉献一并跟踪，从而实时掌握进展。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置好你的[奉献基金](./funds.md)——每个筹款活动都与一个基金相关联
- 你需要 **View Donation Summaries** 权限才能查看筹款活动，需要 **Edit Donations** 权限才能添加或更改筹款活动和认捐

</div>

## 打开筹款活动 {#opening-campaigns}

在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **Donations**，然后点击 **Campaigns**。你会看到一个表格，列出所有筹款活动及其基金、日期、目标金额、已认捐总额和目前已奉献总额。表格上方的摘要行会显示筹款活动的数量，以及认捐和奉献的合计金额。

## 创建筹款活动 {#creating-a-campaign}

1. 点击页面顶部的 **Add Campaign**。
2. 填写筹款活动的详细信息：
   - **Name**（*必填*）——该筹款活动的显示名称（例如"2026 建堂基金"）。
   - **Fund**（*必填*）——与该筹款活动相关联的奉献基金。
   - **Goal Amount**（*可选*）——筹款活动的目标金额。若未设置目标，该活动将不显示进度条。
   - **Start Date**（*必填，默认为今天*）和 **End Date**（*可选*）——募款的时间范围。若未设置结束日期，该活动将显示为 **Ongoing**（进行中）。
   - **Description**（说明）——对筹款活动的简短描述。
   - **Show progress on giving page**（在奉献页面显示进度）——向捐赠人在奉献页面上展示该筹款活动的进度。
   - **Allow donors to pledge**（允许捐赠人认捐）——允许捐赠人自行向该筹款活动认捐。
3. 点击 **Save**。如果缺少名称、基金或开始日期，表单会提示你需要填写哪一项。

## 跟踪进度 {#tracking-progress}

每个筹款活动的行会显示：

- **Goal**（目标）——你的目标金额
- **Pledged**（已认捐）——成员已认捐的总金额
- **Given**（已奉献）——在筹款期间实际捐给该活动基金的总金额
- **Progress**（进度）——以进度条和百分比显示距离目标的完成情况

点击筹款活动的名称即可打开详情视图。详情视图显示已达到目标的百分比，并列出每项认捐，包括每位捐赠人的认捐金额和已奉献金额，以及状态（**Not Started**（未开始）、**In Progress**（进行中）、**Fulfilled**（已履行）、**Beyond Pledged**（超额认捐），或对于未认捐而直接奉献的捐赠人显示的 **Non-Pledged**（未认捐））。捐赠人按姓氏、再按名字排序；点击列标题可改按该列排序。点击详情视图顶部的 **Export**，即可将认捐清单下载为 CSV。

## 添加认捐 {#adding-pledges}

认捐是成员承诺为某个筹款活动奉献的金额。记录认捐的步骤如下：

1. 打开一个筹款活动。
2. 点击页面顶部的 **Add Pledge**。
3. 搜索进行认捐的**人员**并将其添加。
4. 输入 **Pledge Amount**（认捐金额）。金额必须大于零。
5. 点击 **Save**。

认捐会出现在筹款活动详情中，并计入筹款活动列表中的 **Pledged** 总额。若要更改认捐金额，请点击该行的 **Edit**；若要删除认捐，请点击 **Edit**，然后点击 **Delete**。

:::tip
认捐与实际奉献是分开的。认捐记录的是一项承诺；奉献记录的是实际的捐款。两者都会显示在筹款活动中，方便你了解认捐的履行情况。
:::

## 编辑或删除筹款活动 {#editing-or-deleting-a-campaign}

点击任一筹款活动行上的 **Edit**（或点击筹款活动详情视图顶部的 **Edit Campaign**），即可更新其任何详细信息。在编辑表单中点击 **Delete**，可永久删除该筹款活动及其认捐记录；删除后会返回筹款活动列表。删除筹款活动不会删除已记录到其基金中的任何奉献。
