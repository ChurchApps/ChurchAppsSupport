# 募捐活动与认捐

<div class="article-intro">

募捐活动可让您为某个特定目标开展筹款活动，例如建筑基金、宣教短期服事或某个专项事工。您可以同时追踪会众的认捐和实际奉献，从而实时了解筹款进展。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置您的[捐献基金](funds)，因为每个募捐活动都与一个基金相关联
- 您需要有权访问 B1 Admin 中的捐献部分

</div>

## 打开募捐活动

在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（位于左上角的搜索栏），展开**捐献**，然后点击**募捐活动**。您将看到所有募捐活动的表格，其中包括每项活动的基金、日期、目标金额、认捐总额以及目前已奉献的总额。表格上方的摘要行会显示募捐活动的数量，以及认捐和奉献的合计金额。

## 创建募捐活动

1. 点击页面顶部的**添加募捐活动**。
2. 填写募捐活动的详细信息：
   - **名称** *（必填）* -- 该募捐活动的显示名称（例如"建筑基金 2026"）。
   - **基金** -- 与该募捐活动相关联的捐献基金。
   - **开始日期** / **结束日期** -- 筹款的时间范围。
   - **目标** -- 该募捐活动的目标金额。
3. 点击**保存**。

## 追踪进度

每个募捐活动行会显示：

- **目标** -- 您设定的目标金额
- **已认捐** -- 会众已认捐的总金额
- **已奉献** -- 在募捐活动期间实际捐给该活动基金的总金额
- **进度** -- 以进度条和百分比显示距离目标的完成情况

点击募捐活动的名称即可打开详情视图。该视图会显示目标的完成百分比，并列出每笔认捐，包括每位捐献者的认捐金额和奉献金额，以及状态（**未开始**、**进行中**、**已完成**、**超额认捐**，或对于未认捐而直接奉献的捐献者显示为**未认捐**）。捐献者按姓氏、名字排序；您也可以点击列标题，改为按该列排序。点击详情视图顶部的**导出**，即可将认捐列表下载为 CSV 文件。

## 添加认捐

认捐是会众承诺为募捐活动奉献的款项。要记录认捐，请按以下步骤操作：

1. 打开一个募捐活动。
2. 点击页面顶部的**添加认捐**。
3. 选择作出认捐的**人员**。
4. 输入认捐**金额**。
5. 可选择设定认捐承诺的**日期**。
6. 点击**保存**。

认捐会显示在募捐活动详情中，并计入募捐活动列表中的**已认捐**总额。如需修改认捐，请点击该行上的**编辑**。

:::tip
认捐与实际捐献是分开的。认捐记录的是一项承诺，而捐献记录的是实际奉献。两者都会显示在募捐活动中，方便您了解认捐的履行情况。
:::

## 编辑或删除募捐活动

点击任意募捐活动行上的**编辑**（或募捐活动详情视图顶部的**编辑募捐活动**），即可更新其名称、目标、日期或基金。点击**删除**将永久移除该募捐活动及其认捐记录。删除募捐活动不会删除已记入其基金的任何捐献。
