# 创建小组

<div class="article-intro">

在 B1 Admin 中创建小组十分简单。你需要设置一个类别，为小组命名，然后配置其各项设置。小组可以帮助你将教会组织成有意义的单元，例如小组、委员会和班级。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要一个拥有管理小组权限的有效 B1 Admin 账户。如果你不确定自己的访问级别，请参阅[角色与权限](../people/roles-permissions.md)。
- 请规划好小组的类别结构（例如"小组""事工""委员会"）。类别有助于让相关的小组保持井井有条。

</div>

## 添加新小组 {#adding-a-new-group}

1. 打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **People**，然后点击 **Groups**。
2. 点击页眉中的 **Add Group**（添加小组）。列表下方会打开 **New Group**（新建小组）表单。输入 **Category Name**（类别名称）。类别可帮助你将相关的小组归在一起（例如"小组""事工"或"委员会"）。如果类别已存在，你可以从列表中选择。
3. 输入小组的 **Name**（名称）。
4. 点击 **Add**（添加）（或点击 **Cancel**（取消）关闭表单）。新小组会出现在列表中，其类别显示在名称下方。

## 配置小组设置 {#configuring-group-settings}

小组创建后，你可以填写更多详细信息：

1. 点击列表中的**小组名称**将其打开。
2. 点击小组页面左侧、小组详情下方的 **Edit**（编辑）按钮。随即打开 **Group Details**（小组详情）表单。
3. 配置以下选项：
   - **Category Name**（类别名称）和 **Group Name**（小组名称）——更改小组的类别或重命名。
   - **Meeting Time**（聚会时间）和 **Meeting Location**（聚会地点）——小组通常的聚会时间和地点（例如"周三晚上 7 点，204 室"）。
   - **Description**（说明）——小组内容的简要概述，使用格式编辑器撰写。成员可以看到此内容。
   - **Photo**（照片）——点击照片框或 **Add Photo**（添加照片），为小组选择或上传图片。
   - **Slug**（短名）——在你的教会网站上用于小组网址的简短关键名称。
   - **Labels**（标签）——为小组分配一个或多个描述性标签（例如"线下""线上""欢迎新成员"）。标签是你自定义的自由格式标签；勾选所有适用的标签，或点击 **Add New Label**（添加新标签）创建新标签。标签可用于筛选"小组浏览器"网站组件中的小组，而"小组列表"网站组件也可以只显示带有某个标签的小组。
   - **Campus**（堂区）——小组所属的堂区（如果你的教会有多个堂区）。
   - **Enrollment**（报名方式）——选择谁可以加入该小组：
     - **Open (members can join immediately)**（开放，成员可立即加入）——任何人无需审批即可加入
     - **Request to Join (leader approval required)**（申请加入，需负责人批准）——人员必须提交需要审批的加入申请（参见[小组加入申请](./group-join-requests.md)）
     - **Closed (admin-add only)**（关闭，仅管理员可添加）——成员必须由负责人或管理员手动添加
   - **Discussions**（讨论）——开启或关闭小组的聊天信息流，任何成员都可以在其中发帖。默认为开启（**Yes**）。
   - **Announcements**（公告）——开启第二个仅负责人可发帖的聊天信息流——成员可以阅读和回应，但只有负责人可以发帖。默认为开启（**Yes**）。
   - **Show roster on website**（在网站上显示名单）——设为 **Yes**，即可在教会网站的小组页面上列出小组成员。
   - **Confidential group**（保密小组）——对公开页面、小组查找器及非成员隐藏该小组及其名单。适用于康复或辅导事工等敏感小组；只有小组成员和教会员工可以看到。
4. 对于班级和儿童教室，表单还包括以下板块：
   - **Age & Grade**（年龄与年级）——**Minimum Age**（最小年龄）和 **Maximum Age**（最大年龄）（以年和月为单位），以及 **Minimum Grade**（最低年级）和 **Maximum Grade**（最高年级），用于在签到时推荐合适的教室。留空（或选择 **No limit**（无限制））即表示不设限制。参见[签到安全](../attendance/checkin-safety.md#age-and-grade-room-guidance)。
   - **Check-In Capacity**（签到容量）——**Capacity**（容量）、**Guest Capacity**（访客容量）、**Children per Volunteer**（每位志愿者负责的儿童数）、**Minimum Volunteers**（最少志愿者人数）以及 **Closed for Check-In**（关闭签到）。参见[签到安全](../attendance/checkin-safety.md#room-capacity-and-closing-a-room)。
   - **Attendance**（考勤）——**Track Attendance**（跟踪考勤）（设为 **Yes** 即可为该小组记录[考勤](../attendance/tracking-attendance.md)）、**Attendance Reminder Emails**（考勤提醒邮件）（当小组的某个日历活动昨天举行但未记录考勤时，提醒小组负责人）、**Parent Pickup**（家长接送）和 **Print Nametag**（打印姓名牌）（适用于儿童小组的签到选项）。
   - **Service Times (optional)**（聚会时间（可选））——在 **Add Service Time**（添加聚会时间）中选择一个聚会时间，并点击加号按钮，将小组与之关联；若要取消，请点击聚会时间旁边的移除图标。有关聚会时间的详情，请参见[考勤设置](../attendance/setup.md)。
5. 点击 **Save**（保存）以应用更改，或点击 **Cancel**（取消）关闭表单而不保存。

小组页面左侧会显示小组的类别、聚会时间和地点、说明、标签和聚会时间，并以勾选标记显示 **Track Attendance**、**Print Nametag**、**Parent Pickup**、**Discussions** 和 **Announcements** 的开启状态，让你一目了然地看到哪些功能已开启。

:::tip
添加清晰的说明和聚会时间，有助于成员在加入小组时了解将会发生什么。
:::

:::info
如果同时关闭 Discussions 和 Announcements，成员门户中该小组的 Messages（消息）标签页将被完全移除。只关闭其中一项，则仅隐藏其对应的标签页，成员将被转到仍开启的信息流。无论哪种情况，现有消息都会被保留——这些开关只控制新的发帖。
:::

## 复制小组 {#duplicating-a-group}

如果要开设某个定期班级或事工的新一期，无需重新输入所有设置，可以复制现有的小组：

1. 打开该小组，然后点击 **Duplicate**（复制）（位于小组页面左侧 **Edit** 按钮的下方）。
2. 确认复制。

副本会沿用原小组的设置——类别、说明、照片、聚会时间/地点、报名方式、标签、堂区、聊天信息流、保密性、年龄和年级限制、签到容量以及考勤选项——但**不包括**其成员和聚会时间。新小组会立即打开；其名称为原名称加上 " (Copy)"，因此请在小组设置中将其重命名。

## 归档小组 {#archiving-a-group}

当某个小组不再活跃，但你希望保留其历史记录而非删除时：

1. 打开该小组，然后点击 **Edit**（编辑）以修改其设置。
2. 点击 **Archive**（归档）并确认。

已归档的小组会从主小组列表中消失。若要重新找到它，请点击小组页面顶部类别按钮旁边的 **Show archived**（显示已归档），然后点击该小组旁边的 **Restore**（恢复）并确认，即可将其恢复。

:::info
归档小组不会删除其成员、考勤历史或日历活动——它只是将小组从默认列表中隐藏，直到你将其恢复。
:::

## 删除小组 {#deleting-a-group}

若要永久删除小组，请打开它，点击 **Edit**，在 **Group Details** 表单底部点击 **Delete**（删除），然后确认。删除操作无法撤销——如果日后可能需要该小组的历史记录，请改为[归档](#archiving-a-group)。

## 后续步骤 {#next-steps}

创建并配置小组后，你可以：

- **添加成员**——搜索人员并将其添加到小组。使用星形图标（**Make Leader**（设为负责人））指定小组负责人。参见[小组成员](./group-members.md)。
- **设置日历**——为小组创建活动和定期聚会。参见[小组日历](./group-calendar.md)。
- **沟通**——在小组页面上向小组成员发送电子邮件、短信或推送通知。参见[小组成员](./group-members.md#emailing-group-members)。
- **导出数据**——点击小组成员名单上方的 **Export**（导出）即可下载。若要下载完整的小组列表，请点击小组页面页眉中的 **Export**。

:::info
每个小组都属于一个类别，小组主页面允许你按类别筛选列表。随着教会的发展，你随时可以重新排列或重命名类别。
:::
