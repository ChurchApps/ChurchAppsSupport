# 创建小组

<div class="article-intro">

在 B1 Admin 中创建小组很简单。你需要设置一个分类，为小组命名，然后配置其设置。小组可以帮助你将教会组织成有意义的单元，例如小组查经、委员会和班级。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要拥有一个可以管理小组的 B1 Admin 账号。如果你不确定自己的访问级别，请参阅[角色与权限](../people/roles-permissions.md)。
- 请先确定小组的分类结构（例如"小组查经""事工""委员会"）。分类有助于将相关小组整理在一起。

</div>

## 添加新小组

1. 打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **People**，然后点击 **Groups**。
2. 在页面标题中点击 **Add Group**。列表下方会打开 **New Group** 表单。输入 **Category Name**（分类名称）。分类可帮助你将相关小组归为一类（例如"小组查经""事工"或"委员会"）。如果分类已存在，可以从列表中选择。
3. 输入小组的 **Name**（名称）。
4. 点击 **Add**。新小组会出现在列表中，其分类显示在名称下方。

## 配置小组设置

小组创建完成后，你可以补充更多详细信息：

1. 点击列表中的**小组名称**将其打开。
2. 点击小组页面左侧、小组详情下方的 **Edit** 按钮。
3. 配置以下选项：
   - **Description**（描述）—— 对小组内容的简要概述。成员可以看到此内容。
   - **Meeting Times**（聚会时间）—— 小组通常的聚会时间（例如"周三晚上 7 点"）。
   - **Join Policy**（加入方式）—— 选择谁可以加入此小组：
     - **Open**（开放）—— 任何人无需审批即可立即加入
     - **Request**（申请）—— 人们必须提交加入申请，并需获得批准（参见[小组加入申请](./group-join-requests.md)）
     - **Closed**（关闭）—— 成员必须由负责人或管理员手动添加
   - **Labels**（标签）—— 为小组分配一个或多个描述性标签（例如"线下""线上""欢迎新成员"）。标签是你自定义的自由标记；选中所有适用的标签。标签可用于筛选 Groups Browser 网站元素中的小组。
   - **Confidential group**（保密小组）—— 对公开页面、小组查找功能以及非成员隐藏该小组及其名单。适用于康复或辅导事工等敏感小组；只有小组成员和教会工作人员可以看到。
   - **Discussions**（讨论）—— 开启或关闭小组的聊天信息流，任何成员都可以在其中发帖。默认开启。
   - **Announcements**（公告）—— 开启第二个仅负责人可发帖的聊天信息流——成员可以阅读和回应，但只有负责人可以发帖。默认开启。
   - **Attendance Tracking**（出勤追踪）—— 如果你想为该小组记录[出勤](../attendance/tracking-attendance.md)，请开启此选项。
   - **Service Times**（礼拜时间）—— 如适用，将小组与特定的教会礼拜时间相关联。有关礼拜时间的详细信息，请参阅[考勤设置](../attendance/setup.md)。
4. 点击 **Save** 应用你的更改。

:::tip
添加清晰的描述和聚会时间，有助于成员在加入小组时了解将会发生什么。
:::

:::info
同时关闭 Discussions 和 Announcements 会在成员门户中将 Messages（消息）标签页从小组中完全移除。只关闭其中一项会隐藏对应的标签页；成员会被引导至仍然开启的信息流。无论哪种情况，现有消息都会被保留——这些开关仅控制新的发帖功能。
:::

## 复制小组

正在开设一个定期班级或事工的新期次？无需重新输入所有设置，可以直接复制现有小组：

1. 打开该小组，点击 **Duplicate**（位于小组页面左侧 **Edit** 按钮的下方）。
2. 确认复制。

副本会保留原小组的设置——分类、描述、聚会时间/地点、加入方式、标签和校区——但**不会**包含其成员。新小组的名称为原名称加上 " (Copy)"；你可以在小组设置中重命名。

## 归档小组

当某个小组不再活跃，但你希望保留其历史记录而不是将其删除时：

1. 打开该小组，点击 **Edit** 编辑其设置。
2. 点击 **Archive** 并确认。

已归档的小组会从主小组列表中隐藏。要再次找到它，请点击小组页面顶部分类按钮旁边的 **Show archived** 按钮，然后点击该小组旁边的 **Restore** 将其恢复。

:::info
归档小组不会删除其成员、出勤记录或日历活动——它只是将该小组从默认列表中隐藏，直到你将其恢复。
:::

## 下一步

创建并配置小组后，你可以：

- **添加成员** —— 搜索人员并将其添加到小组中。使用星形图标（**Make Leader**，设为负责人）来指定小组负责人。参见[小组成员](./group-members.md)。
- **设置日历** —— 为小组创建活动和定期聚会。参见[小组日历](./group-calendar.md)。
- **沟通** —— 直接从小组页面向所有小组成员发送消息。
- **导出数据** —— 点击小组成员列表上方的 **Export** 即可下载。

:::info
每个小组都属于一个分类，主小组页面允许你按分类筛选列表。随着教会的成长，你随时可以重新调整或重命名分类。
:::
