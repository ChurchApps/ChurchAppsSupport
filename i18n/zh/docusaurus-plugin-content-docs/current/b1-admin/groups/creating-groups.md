# 创建小组

<div class="article-intro">

在 B1 Admin 中创建组很简单。您将设置一个类别，命名您的组，然后配置其设置。组帮助您将教会组织成有意义的单位，例如小组、委员会和班级。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要一个有权管理组的活跃 B1 Admin 账户。如果您不确定您的访问级别，请参阅[角色和权限](../people/roles-permissions.md)。
- 为您的组决定一个类别结构（例如，"小组"、"事工"、"委员会"）。类别帮助保持相关组的组织。

</div>

## 添加新组

1. 打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开**人员**，然后点击**组**。
2. 点击**添加组**并输入**类别名称**。类别帮助您将相关组组织在一起（例如，"小组"、"事工"或"委员会"）。如果类别已存在，您可以从列表中选择它。
3. 输入**组名称**。
4. 点击**添加**。您的新组将在所选类别下出现在列表中。

## 配置组设置

创建组后，您可以填写其他详情：

1. 在列表中点击**组名称**来打开它。
2. 点击**铅笔图标**来编辑组设置。
3. 配置以下选项：
   - **描述** -- 组的简要摘要。对成员可见。
   - **会议时间** -- 组通常会议的时间（例如，"周三晚上 7 点"）。
   - **加入政策** -- 选择谁可以加入此组：
     - **开放** -- 任何人都可以立即加入而无需批准
     - **请求** -- 人员必须提交需要批准的加入请求（请参阅[组加入请求](./group-join-requests.md)）
     - **关闭** -- 成员必须由领导者或管理员手动添加
   - **标签** -- 为组分配一个或多个描述性标签（例如，"亲身参与"、"在线"、"欢迎新成员"）。标签是自由形式的标签，您定义；检查所有适用的。标签可用于在组浏览器网站元素中过滤组。
   - **机密组** -- 从公共页面、组查找器和非成员隐藏此组及其名单。用于诸如恢复或辅导事工等敏感组；仅组的成员和教会员工可以看到它。
   - **讨论** -- 打开或关闭组的聊天源，任何成员都可以发布。默认打开。
   - **通知** -- 打开第二个仅供领导者的聊天源——成员可以阅读和反应，但仅领导者可以发布。默认打开。
   - **参加者追踪** -- 如果您想为此组记录[参加者](../attendance/tracking-attendance.md)，请启用此选项。
   - **服务时间** -- 将组与特定的教会服务时间关联（如果适用）。有关服务时间的详细信息，请参阅[参加者设置](../attendance/setup.md)。
4. 点击**保存**来应用您的更改。

:::tip
添加清晰的描述和会议时间帮助成员知道加入组时期望什么。
:::

:::info
关闭讨论和通知都会从成员门户中完全删除消息选项卡。关闭仅其中一个会隐藏其选项卡；成员会转移到仍然打开的任何源。现有消息保留在任何一种情况下——切换仅控制新发布。
:::

## 复制组

开始新一轮的定期班级或事工？而不是重新输入所有设置，复制现有组：

1. 打开组并点击组横幅中的**复制**图标（编辑旁边）。
2. 确认复制。

副本继承原始的设置——类别、描述、会议时间/位置、加入政策、标签和校区——但**不**其成员。新组以原始名称命名，后缀为"（副本）"；从组设置重命名它。

## 存档组

当组不再活跃但您想保留其历史而不是删除它时：

1. 打开组并点击**铅笔图标**来编辑其设置。
2. 点击**存档**并确认。

已存档的组从主要组列表中删除。要再次找到一个，打开**显示已存档**切换开关在组页面顶部，然后点击**恢复**组旁边来使其重新活跃。

:::info
存档组不会删除其成员、参加者历史或日历事件——它仅在您恢复它之前从默认列表中隐藏该组。
:::

## 后续步骤

创建和配置组后，您已准备好：

- **添加成员** -- 搜索人员并将其添加到组。使用绿色密钥图标来指定组领导者。请参阅[组成员](./group-members.md)。
- **设置日历** -- 为组创建事件和定期会议。请参阅[组日历](./group-calendar.md)。
- **沟通** -- 直接从组页面向所有组成员发送消息。
- **导出数据** -- 点击下载图标来导出您的组的成员列表。

:::info
您所有的教会组都按类别组织在主要组页面上。当您的教会增长时，您可以随时重新排列或重命名类别。
:::
