# 创建小组

<div class="article-intro">

在 B1 Admin 中创建小组非常简单。您需要设置一个类别，为小组命名，然后配置其设置。小组可以帮助您将教会组织成有意义的单元，如小组团契、委员会和班级。

</div>

<div class="prereqs">
<h4>准备工作</h4>

- 您需要拥有具备小组管理权限的有效 B1 Admin 账户。如果不确定自己的访问权限级别，请参阅[角色与权限](../people/roles-permissions.md)。
- 为小组确定一个类别结构（例如，"小组团契"、"事工"、"委员会"）。类别有助于将相关小组组织在一起。

</div>

## 添加新小组

1. 导航到 **B1 Admin 仪表板**。
2. 点击**小组**标签页。
3. 点击**添加小组**并输入**类别名称**。类别有助于将相关小组组织在一起（例如，"小组团契"、"事工"或"委员会"）。如果类别已存在，可以从列表中选择。
4. 输入**小组名称**。
5. 点击**添加**。新小组会出现在所选类别下的列表中。

## 配置小组设置

创建小组后，您可以填写更多详细信息：

1. 在列表中点击**小组名称**将其打开。
2. 点击**铅笔图标**编辑小组设置。
3. 配置以下选项：
   - **描述** -- 关于该小组的简要说明。成员可以看到此内容。
   - **聚会时间** -- 小组通常的聚会时间（例如，"周三晚上 7 点"）。
   - **加入政策** -- 选择谁可以加入此小组：
     - **开放** -- 任何人都可以立即加入，无需批准
     - **申请** -- 用户必须提交加入申请，需经批准（请参阅[小组加入申请](./group-join-requests.md)）
     - **封闭** -- 成员必须由负责人或管理员手动添加
   - **标签** -- 为小组分配一个或多个描述性标签（例如，"线下"、"线上"、"欢迎新成员"）。标签是您自定义的自由标记；勾选所有适用项。标签可用于在"小组浏览器"网站组件中筛选小组。
   - **保密小组** -- 在公开页面、小组查找器和非成员面前隐藏该小组及其名单。适用于康复或辅导事工等敏感小组；只有小组成员和教会员工可以看到。
   - **考勤跟踪** -- 如果您想为该小组记录[考勤](../attendance/tracking-attendance.md)，请启用此项。
   - **聚会时间关联** -- 如适用，将小组与特定的教会聚会时间关联。有关聚会时间的详细信息，请参阅[考勤设置](../attendance/setup.md)。
4. 点击**保存**以应用更改。

:::tip
添加清晰的描述和聚会时间有助于成员了解加入小组后可以期待什么。
:::

## 复制小组

要开始一个循环课程或事工的新一期？无需重新输入所有设置，直接复制现有小组即可：

1. 打开小组，点击小组横幅中的**复制**图标（位于"编辑"旁边）。
2. 确认复制操作。

副本会保留原小组的设置——类别、描述、聚会时间/地点、加入政策、标签和堂点——但**不会**保留其成员。新小组以原名称加上"（副本）"命名；可在小组设置中重新命名。

## 归档小组

当某个小组不再活跃，但您希望保留其历史记录而不是删除它时：

1. 打开小组，点击**铅笔图标**编辑其设置。
2. 点击**归档**并确认。

归档的小组会从主小组列表中移除。要重新找到它，请打开小组页面顶部的**显示已归档**开关，然后点击该小组旁边的**恢复**按钮将其找回。

:::info
归档小组不会删除其成员、考勤历史或日历活动——只是在您恢复之前将该小组从默认列表中隐藏。
:::

## 后续步骤

创建并配置好小组后，您可以：

- **添加成员** -- 搜索用户并将其添加到小组。使用绿色钥匙图标指定小组负责人。请参阅[小组成员](./group-members.md)。
- **设置日历** -- 为小组创建活动和定期聚会。请参阅[小组日历](./group-calendar.md)。
- **沟通** -- 直接从小组页面向所有小组成员发送消息。
- **导出数据** -- 点击下载图标导出小组成员列表。

:::info
教会的所有小组都按类别组织在主"小组"页面上。随着教会的发展，您可以随时重新排列或重命名类别。
:::
