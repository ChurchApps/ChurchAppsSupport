# 创建小组

<div class="article-intro">

在 B1 Admin 中创建小组非常简单。您需要设置一个类别，为小组命名，然后配置其各项设置。小组可以帮助您将教会组织成小组团契、委员会和班级等有意义的单位。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要拥有管理小组权限的有效 B1 Admin 账户。如果您不确定自己的访问级别，请参阅[角色与权限](../people/roles-permissions.md)。
- 规划好小组的类别结构（例如“小组团契”“事工”“委员会”）。类别有助于将相关的小组归类整理。

</div>

## 添加新小组

1. 打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **People**，然后点击 **Groups**。
2. 点击页面标题中的 **Add Group**（添加小组）。页面下方会打开 **New Group**（新小组）表单。输入 **Category Name**（类别名称）。类别可以帮助您将相关的小组组织在一起（例如“小组团契”“事工”或“委员会”）。如果类别已存在，您可以从列表中选择它。
3. 输入小组的**名称**。
4. 点击 **Add**。新小组会出现在列表中，其类别显示在名称下方。

## 配置小组设置

小组创建后，您可以补充更多详细信息：

1. 点击列表中的**小组名称**打开小组。
2. 点击小组页面左侧、小组详情下方的 **Edit** 按钮。
3. 配置以下选项：
   - **Description**（描述）——对小组用途的简要概述。会员可以看到此内容。
   - **Meeting Times**（聚会时间）——小组通常聚会的时间（例如“周三晚上 7 点”）。
   - **Join Policy**（加入政策）——选择谁可以加入此小组：
     - **Open**（开放）——任何人都可以立即加入，无需批准
     - **Request**（申请）——人们必须提交加入申请，并需要批准（参见[小组加入申请](./group-join-requests.md)）
     - **Closed**（关闭）——成员必须由负责人或管理员手动添加
   - **Labels**（标签）——为小组分配一个或多个描述性标签（例如“线下”“线上”“欢迎新成员”）。标签是您自定义的自由标签，勾选所有适用项即可。标签可用于筛选“Groups Browser”网站元素中的小组，而“Group List”网站元素则会显示带有某一标签的小组。
   - **Confidential group**（机密小组）——对公开页面、小组查找器和非成员隐藏此小组及其名单。适用于康复或辅导事工等敏感小组；只有小组成员和教会员工可以看到它。
   - **Discussions**（讨论）——开启或关闭小组的聊天消息流，任何成员都可以发帖。默认开启。
   - **Announcements**（公告）——开启第二个仅负责人可发帖的聊天消息流——成员可以阅读和回应，但只有负责人可以发帖。默认开启。
   - **Attendance Tracking**（出勤追踪）——如果您想为该小组记录[出勤](../attendance/tracking-attendance.md)，请启用此项。
   - **Service Times**（礼拜时间）——如适用，将小组与特定的教会礼拜时间关联。有关礼拜时间的详细信息，请参阅[出勤设置](../attendance/setup.md)。
4. 点击 **Save** 应用您的更改。

:::tip
添加清晰的描述和聚会时间，可以帮助成员在加入小组时了解会有哪些内容。
:::

:::info
同时关闭 Discussions 和 Announcements，会在成员门户中将 Messages（消息）标签页从小组中完全移除。只关闭其中一个，只会隐藏其对应的标签页，成员会被转到仍然开启的消息流。无论哪种情况，现有消息都会被保留——这些开关只控制新消息的发布。
:::

## 复制小组

要开始一个新的定期课程或事工周期吗？与其重新输入所有设置，不如复制现有的小组：

1. 打开小组并点击 **Duplicate**（复制）（位于小组页面左侧 **Edit** 按钮的下方）。
2. 确认复制。

副本会沿用原小组的设置——类别、描述、聚会时间/地点、加入政策、标签和校区——但**不会**复制其成员。新小组会以原小组名称加上“ (Copy)”（副本）命名；请在小组设置中将其重命名。

## 归档小组

当某个小组不再活跃，但您希望保留其历史记录而不是删除时：

1. 打开小组并点击 **Edit** 编辑其设置。
2. 点击 **Archive**（归档）并确认。

已归档的小组不再出现在主小组列表中。要找回它，请点击小组页面类别按钮旁边的 **Show archived**（显示已归档），然后点击小组旁的 **Restore**（恢复）即可将其恢复。

:::info
归档小组不会删除其成员、出勤记录或日历活动——它只会将小组从默认列表中隐藏，直到您将其恢复。
:::

## 后续步骤

创建并配置好小组后，您可以：

- **添加成员**——搜索人员并将其加入小组。使用星形图标（**Make Leader**，设为负责人）来指定小组负责人。参见[小组成员](./group-members.md)。
- **设置日历**——为小组创建活动和定期聚会。参见[小组日历](./group-calendar.md)。
- **沟通**——直接从小组页面向所有小组成员发送消息。
- **导出数据**——点击小组成员名单上方的 **Export**，即可下载名单。

:::info
每个小组都属于一个类别，主小组页面允许您按类别筛选列表。随着教会的发展，您可以随时重新整理或重命名类别。
:::
