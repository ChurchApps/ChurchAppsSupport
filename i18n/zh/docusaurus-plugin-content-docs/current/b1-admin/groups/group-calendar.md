# 小组日历

<div class="article-intro">

B1 中的每个小组都可以拥有自己的活动日历。小组负责人用它安排聚会、活动和定期事项，而所有小组成员都可以查看即将举行的活动，并参与相关讨论。日历让你的小组保持井然有序，并确保每位成员都了解即将发生的事情。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要在 B1 Admin 中创建一个小组，并至少有一名成员。参见[创建小组](creating-groups.md)和[小组成员](group-members.md)。
- 若要添加或编辑日历活动，你必须被指定为小组负责人。操作说明请参见[指定小组负责人](group-members.md#designating-group-leaders)。

</div>

## 访问小组日历 {#accessing-the-group-calendar}

小组日历可通过面向成员的 B1.church 应用访问：

1. 在 B1 Admin 中，点击屏幕右上角的**下拉菜单**。
2. 选择 **Switch App**（切换应用）。
3. 选择 **B1.church**。
4. 打开 **Groups**（小组）（在手机上位于底部标签栏，在电脑上位于顶部页眉）。
5. 从列表中选择你的小组。
6. 在 **Next event**（下一个活动）下，点击 **All events**（所有活动）打开小组的 **Events**（活动）视图。在该视图中使用 **Calendar**（日历）切换按钮可切换为月视图。

:::info
小组日历通过 B1.church（成员应用）管理，而非 B1 Admin。小组负责人可从管理后台切换应用以访问该日历。
:::

## 添加活动 {#adding-an-event}

1. 在小组日历中，点击 **Add Event**（添加活动）。
2. 输入活动的 **title**（标题）。
3. 简要撰写活动的 **description**（说明）。
4. 设置**开始时间**和**结束时间**。
5. 点击 **Save**（保存）将活动添加到日历中。

## 设置定期活动 {#setting-up-recurring-events}

如果你的小组定期聚会，可以将活动设置为自动重复：

1. 创建或编辑活动时，勾选 **Recurring**（定期）复选框。
2. 选择活动的重复方式：
   - **Interval**（间隔）——设置相隔的天数。例如输入"7"即表示每 7 天重复一次。
   - **Frequency**（频率）——选择按 **day**（天）、**week**（周）或 **month**（月）重复。
3. 保存活动。它现在会在每个预定的日期出现在日历上。

:::tip
如果你的小组每周六聚会，请将频率设为"week"，并选择星期六。之后活动便会自动出现在日历上。
:::

## 在 B1 Admin 中批量创建活动 {#bulk-creating-events-in-b1-admin}

B1 Admin 中的小组页面也设有 **Calendar**（日历）板块，工作人员可以在此一次性安排整个季度的聚会：

1. 在 B1 Admin 中打开该小组，在 **Calendar** 板块中点击 **All events**（所有活动）。
2. 点击 **+ Add Events**（添加活动）打开 **Add Recurring Events**（添加定期活动）对话框。
3. 检查 **Title**（标题）（默认为小组名称），并可选择添加 **Description**（说明）。
4. 选择 **First Meeting**（首次聚会）和 **Last Meeting**（最后一次聚会）日期、**Start**（开始）和 **End**（结束）时间，以及 **Repeats**（重复）频率——**Weekly**（每周）或 **Every 2 Weeks**（每两周），均在首次聚会所在的星期进行。若只有一次聚会，则两个日期填写相同即可。
5. 选择 **Visibility**（可见性）——**Public**（公开）或 **Private**（私密）。
6. **Skip holidays**（跳过节假日）默认为勾选状态，因此落在节假日的聚会日期会被取消勾选，并标注该节假日的名称。
7. 检查聚会日期列表，取消勾选要跳过的日期。
8. 如果希望成员能够回应这些活动（见下文），请保持 **Allow RSVPs**（允许回应）为勾选状态，然后点击 **Save**。

B1 Admin 的活动列表上方有 **Upcoming**（即将举行）和 **Past**（已过去）按钮。**Upcoming** 显示尚未结束的活动，以及仍在进行中的定期系列，最近的排在最前。**Past** 保留小组此前的所有活动，最新的排在最前。每一行显示活动标题、开始时间、重复方式、跳过的日期数量、可见性以及回应情况。点击某一行的 **Delete**（删除）并确认，即可移除该活动及其所有安排。

## 活动回应 {#event-rsvps}

小组活动可以收集回应——每次活动的每一场，都可以收到 **Yes**（参加）、**No**（不参加）或 **Maybe**（待定）的回应。

- **Allow RSVPs**（允许回应）默认为通过批量添加对话框创建的活动开启；取消勾选即可关闭这些活动的回应功能。关闭回应的活动在小组的活动列表中会显示为 **Disabled**（已禁用）。
- 在 B1 Admin 的小组活动列表中，每个活动都会显示回应摘要（例如"5 yes · 2 maybe · 1 no"）。点击该摘要即可打开 **RSVP Responses**（回应名单），其中按每一场活动列出了哪些人为 **Going**（参加）、**Maybe**（待定）或 **Not Going**（不参加）。

:::tip
回应功能让负责人无需正式的活动报名，即可掌握人数。如果是收费报名或需要管理名额的活动，请改用[活动报名](../calendars/creating-calendars.md#enabling-event-registration)。
:::

## 查看日历 {#viewing-the-calendar}

小组日历提供多种视图选项：

- **Month**（月）——一目了然地查看整月。
- **Week**（周）——聚焦于当前一周。
- **Day**（日）——详细查看单日。
- **Agenda**（议程）——按时间顺序列出即将举行的活动。

使用日历顶部的按钮即可在各视图之间切换。

## 活动详情与讨论 {#event-details-and-conversations}

点击任意活动即可查看其详情。在活动详情视图中：

- **成员和负责人**可以就该活动发起讨论并留言。
- **负责人**可以编辑活动详情、更改时间或删除活动。

:::warning
删除活动将永久移除该活动。编辑或删除定期活动时，系统会询问你要更改 **Just this date**（仅此日期）、**This and all following dates**（此日期及之后所有日期）还是 **All dates**（所有日期），因此你可以只取消某一次聚会，而不影响整个系列的其他安排。
:::

## 订阅日历 {#subscribing-to-the-calendar}

你可以将小组日历与个人日历同步：

1. 在小组日历页面上，点击 **Subscribe**（订阅）。
2. 按照提示将日历添加到 Google 日历、Apple 日历、Outlook 或任何其他支持订阅的日历应用中。

:::tip
订阅后，你的个人日程会与小组活动保持同步，无需另行查看 B1。小组负责人所做的任何更改都会自动出现在你同步的日历中。
:::
