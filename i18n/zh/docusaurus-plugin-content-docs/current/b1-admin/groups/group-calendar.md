# 小组日历

<div class="article-intro">

B1 中的每个小组都可以拥有自己的活动日历。小组负责人用它来安排聚会、活动和定期事件，而所有小组成员都可以查看即将到来的活动，并参与有关活动的讨论。日历可以让您的小组保持有序，并确保每个人都了解即将发生的事情。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要在 B1 Admin 中创建一个至少有一名成员的小组。参见[创建小组](creating-groups.md)和[小组成员](group-members.md)。
- 要添加或编辑日历活动，您必须被指定为小组负责人。参见[指定小组负责人](group-members.md)的说明。

</div>

## 访问小组日历

小组日历可通过面向成员的 B1.church 应用访问：

1. 在 B1 Admin 中，点击屏幕右上角的**下拉菜单**。
2. 选择 **Switch App（切换应用）**。
3. 选择 **B1.church**。
4. 打开 **Groups（小组）**（在手机上位于底部标签栏中，在电脑上位于顶部标题栏中）。
5. 从列表中选择您的小组。
6. 在 **Next event（下一个活动）**下，点击 **All events（全部活动）**以打开该小组的 **Events（活动）**视图。在该视图中使用 **Calendar（日历）**切换按钮即可查看月视图。

:::info
小组日历是通过 B1.church（成员应用）管理的，而不是通过 B1 Admin。小组负责人可以从管理仪表板切换应用来访问它。
:::

## 添加活动

1. 在小组日历中，点击 **Add Event（添加活动）**。
2. 输入活动的 **title（标题）**。
3. 简要撰写活动的 **description（描述）**。
4. 设置 **start time（开始时间）**和 **end time（结束时间）**。
5. 点击 **Save（保存）**，将活动添加到日历中。

## 设置定期活动

如果您的小组按固定时间聚会，可以将活动设置为自动重复：

1. 在创建或编辑活动时，勾选 **Recurring（定期）**复选框。
2. 选择活动的重复方式：
   - **Interval（间隔）**——设置每次之间相隔的天数。例如，输入“7”表示每 7 天重复一次。
   - **Frequency（频率）**——选择按 **day（天）**、**week（周）**或 **month（月）**重复。
3. 保存活动。它将按计划在每次出现时显示在日历上。

:::tip
如果您的小组每周六聚会，可将频率设置为“week（周）”并选择星期六。此后活动将自动出现在日历上。
:::

## 在 B1 Admin 中批量创建活动

小组在 B1 Admin 中的页面也有一个 **Calendar（日历）**部分，工作人员可以在其中一次性安排整个学期的聚会：

1. 在 B1 Admin 中打开小组，然后在 **Calendar（日历）**部分中点击 **All events（全部活动）**。
2. 点击 **+ Add Events（添加活动）**以打开 **Add Recurring Events（添加定期活动）**对话框。
3. 选择时间安排（每周、每两周、每月或仅一次）、**First Meeting（首次聚会）**和 **Last Meeting（最后一次聚会）**日期，并可选择 **Skip holidays（跳过节假日）**。
4. 查看聚会日期预览，并取消勾选任何需要跳过的日期。
5. 如果您希望成员能够回应这些活动（见下文），请保持 **Allow RSVPs（允许回复）**勾选，然后保存。

## 活动回复（RSVP）

小组活动可以收集回复——针对活动的每一次出现，成员可以回复 **Yes（参加）**、**No（不参加）**或 **Maybe（待定）**。

- 对于通过批量添加对话框创建的活动，**Allow RSVPs（允许回复）**默认开启；取消勾选即可为这些活动关闭回复。关闭回复的活动会在小组的活动列表中显示为 **Disabled（已禁用）**。
- 在 B1 Admin 的小组活动列表中，每个活动都会显示回复摘要（例如“5 yes · 2 maybe · 1 no”）。点击即可打开 **RSVP Responses（回复名单）**，其中列出了该次活动中回复参加、待定和不参加的人员。

:::tip
RSVP 可以让负责人在不需要完整活动报名的情况下统计人数。对于需要付费报名或有名额限制的活动，请改用[活动报名](../calendars/creating-calendars.md#enabling-event-registration)。
:::

## 查看日历

小组日历提供多种视图选项：

- **Month（月）**——一眼看清整个月。
- **Week（周）**——聚焦当前一周。
- **Day（日）**——详细查看单日。
- **Agenda（议程）**——按时间顺序查看即将到来的活动列表。

使用日历顶部的按钮在各视图之间切换。

## 活动详情与讨论

点击任意活动即可查看其详情。在活动详情视图中：

- **成员和负责人**可以就活动发起讨论并发表评论。
- **负责人**可以编辑活动详情、更改时间或删除活动。

:::warning
删除活动将永久移除该活动。如果您只需取消定期活动中的某一次，请考虑直接编辑该活动。
:::

## 订阅日历

您可以将小组日历与个人日历同步：

1. 在小组日历页面，点击 **Subscribe（订阅）**。
2. 按照提示将日历添加到 Google 日历、Apple 日历、Outlook 或任何支持订阅的其他日历应用中。

:::tip
订阅可以让您的个人日程与小组活动保持同步，无需再单独查看 B1。小组负责人所做的任何更改都会自动出现在您同步的日历中。
:::
