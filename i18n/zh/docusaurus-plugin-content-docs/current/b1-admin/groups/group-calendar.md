# 小组日历

<div class="article-intro">

B1 中的每个小组都可以拥有自己的活动日历。小组负责人用它来安排聚会、活动和定期事件，而所有小组成员都可以查看即将举行的活动并参与相关讨论。日历让您的小组保持有序，并确保每个人都了解即将发生的事情。

</div>

<div class="prereqs">
<h4>准备工作</h4>

- 您需要在 B1 Admin 中创建一个至少有一名成员的小组。请参阅[创建小组](creating-groups.md)和[小组成员](group-members.md)。
- 要添加或编辑日历活动，您必须被指定为小组负责人。有关说明，请参阅[指定小组负责人](group-members.md)。

</div>

## 访问小组日历

小组日历通过面向会员的 B1.church 应用程序访问：

1. 在 B1 Admin 中，点击屏幕右上角的**下拉菜单**。
2. 选择**切换应用**。
3. 选择 **B1.church**。
4. 点击左侧边栏中的**小组**。
5. 从列表中选择您的小组。
6. 点击屏幕左侧的**日历**。

:::info
小组日历通过 B1.church（会员应用）而非 B1 Admin 进行管理。小组负责人可以从管理仪表板切换应用来访问它。
:::

## 添加活动

1. 在小组日历中，点击**添加活动**。
2. 输入活动的**标题**。
3. 撰写一段简短的**描述**，说明该活动的内容。
4. 设置**开始时间**和**结束时间**。
5. 点击**保存**将活动添加到日历中。

## 设置定期活动

如果您的小组按固定日程聚会，可以设置活动自动重复：

1. 在创建或编辑活动时，勾选**重复**框。
2. 选择活动的重复方式：
   - **间隔** -- 设置各次发生之间的天数。例如，输入"7"表示每 7 天重复一次。
   - **频率** -- 选择按**天**、**周**或**月**重复。
3. 保存活动。此后它将在每个预定日期出现在日历上。

:::tip
对于每周六聚会的小组，将频率设置为"周"并选择星期六。活动将自动填充到未来的日历中。
:::

## 在 B1 Admin 中批量创建活动

小组在 B1 Admin 中的页面也有一个**日历**标签页，员工可以一次性安排整季的聚会：

1. 在 B1 Admin 中打开小组并选择**日历**标签页。
2. 点击**添加活动**打开**添加定期活动**对话框。
3. 选择日程安排（每周、每两周、每月或一次性），设置**首次聚会**和**末次聚会**日期，并可选择**跳过节假日**。
4. 查看聚会日期的预览，并取消勾选要跳过的日期。
5. 如果希望成员能够对这些活动做出回应（见下文），保持**允许 RSVP** 处于勾选状态，然后保存。

## 活动 RSVP

小组活动可以针对每次活动收集 RSVP——即**是**、**否**或**可能**。

- 通过批量添加对话框创建的活动默认开启**允许 RSVP**；取消勾选可关闭这些活动的响应功能。关闭 RSVP 的活动会在日历标签页中显示为**已禁用**。
- 在 B1 Admin 的小组日历标签页中，每个活动会显示一个响应汇总（例如，"5 是 · 2 可能 · 1 否"）。点击进入可打开**RSVP 响应**名单，列出该次活动中回答是、可能和否的人员。

:::tip
RSVP 让负责人无需正式的完整活动注册即可获得人数统计。对于付费报名或需要管理容量的活动，请改用[活动注册](../calendars/creating-calendars.md#enabling-event-registration)。
:::

## 查看日历

小组日历提供多种查看方式：

- **月** -- 一目了然地查看整月。
- **周** -- 聚焦当前一周。
- **日** -- 详细查看单独一天。
- **议程** -- 按时间顺序查看即将举行的活动列表。

使用日历顶部的按钮在不同视图之间切换。

## 活动详情与讨论

点击任意活动即可查看其详情。在活动详情视图中：

- **成员和负责人**可以就该活动发起讨论并留言。
- **负责人**可以编辑活动详情、更改时间或删除活动。

:::warning
删除活动会将其永久移除。如果您需要取消定期活动的某一次聚会，建议改为编辑该活动。
:::

## 订阅日历

您可以将小组日历与个人日历同步：

1. 在小组日历页面，点击**订阅**。
2. 按照提示将日历添加到 Google 日历、Apple 日历、Outlook 或任何其他支持订阅的日历应用程序。

:::tip
订阅可让您的个人日程与小组活动保持同步，无需单独查看 B1。小组负责人所做的任何更改都会自动出现在您同步的日历中。
:::
