# 小组日历

<div class="article-intro">

B1 中的每个小组都可以拥有自己的活动日历。小组负责人用它安排聚会、活动和定期事件，而所有小组成员都可以查看即将举行的活动，并就活动展开讨论。日历帮助您保持小组井然有序，确保每个人都清楚接下来会有什么安排。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要在 B1 Admin 中创建一个至少有一名成员的小组。参见[创建小组](creating-groups.md)和[小组成员](group-members.md)。
- 要添加或编辑日历活动，您必须被指定为小组负责人。参见[指定小组负责人](group-members.md)。

</div>

## 访问小组日历

小组日历通过面向会员的 B1.church 应用提供：

1. 在 B1 Admin 中，点击屏幕右上角的**下拉菜单**。
2. 选择 **Switch App**（切换应用）。
3. 选择 **B1.church**。
4. 打开 **Groups**（在手机上位于底部标签栏中，在电脑上位于顶部导航栏中）。
5. 从列表中选择您的小组。
6. 在 **Next event**（下一个活动）下，点击 **All events**（所有活动），打开该小组的 **Events** 视图。在此使用 **Calendar** 切换按钮可切换到月视图。

:::info
小组日历是通过 B1.church（会员应用）管理的，而不是在 B1 Admin 中。小组负责人可以从管理后台切换应用来访问它。
:::

## 添加活动

1. 在小组日历中，点击 **Add Event**（添加活动）。
2. 输入活动的**标题**。
3. 简要填写活动内容的**描述**。
4. 设置**开始时间**和**结束时间**。
5. 点击 **Save**，将活动添加到日历中。

## 设置定期活动

如果您的小组按固定时间聚会，可以让活动自动重复：

1. 在创建或编辑活动时，勾选 **Recurring**（重复）复选框。
2. 选择活动的重复方式：
   - **Interval**（间隔）——设置两次出现之间相隔的天数。例如，输入“7”即表示每 7 天重复一次。
   - **Frequency**（频率）——选择按 **day**（天）、**week**（周）或 **month**（月）重复。
3. 保存活动。它将出现在日历中每个预定的时间点。

:::tip
如果小组每周六聚会，请将频率设为“week”并选择周六。之后的活动会自动出现在日历上。
:::

## 在 B1 Admin 中批量创建活动

小组在 B1 Admin 中的页面也有一个 **Calendar**（日历）部分，工作人员可以在其中一次性排定整个学期的聚会：

1. 在 B1 Admin 中打开小组，在 **Calendar** 部分点击 **All events**。
2. 点击 **+ Add Events**（添加活动），打开 **Add Recurring Events**（添加定期活动）对话框。
3. 选择排期方式（每周、每两周、每月或单次），设置 **First Meeting**（首次聚会）和 **Last Meeting**（最后一次聚会）的日期，并可选择 **Skip holidays**（跳过节假日）。
4. 查看聚会日期的预览，取消勾选任何需要跳过的日期。
5. 如果希望成员能够对这些活动回复（见下文），请保持 **Allow RSVPs**（允许 RSVP）勾选，然后保存。

B1 Admin 的活动列表上方有 **Upcoming**（即将举行）和 **Past**（已结束）按钮。**Upcoming** 显示尚未结束的活动以及仍在进行中的定期系列，按最近日期排序。**Past** 则保留小组之前所有的活动，按最新日期排序。

## 活动 RSVP {#event-rsvps}

小组活动可以收集 RSVP 回复——每次活动都可以回复 **Yes**（参加）、**No**（不参加）或 **Maybe**（待定）。

- **Allow RSVPs** 在通过批量添加对话框创建的活动中默认开启；取消勾选即可关闭这些活动的回复功能。关闭了 RSVP 的活动在小组活动列表中显示为 **Disabled**（已禁用）。
- 在 B1 Admin 的小组活动列表中，每个活动都会显示回复摘要（例如“5 yes · 2 maybe · 1 no”）。点击即可打开 **RSVP Responses**（RSVP 回复）名单，查看该次活动中回答参加、待定和不参加的人员。

:::tip
RSVP 可以让负责人统计人数，而无需完整的活动报名流程。对于需要付费报名或限制名额的活动，请改用[活动报名](../calendars/creating-calendars.md#enabling-event-registration)。
:::

## 查看日历

小组日历提供多种视图：

- **Month**（月）——一目了然地查看整月安排。
- **Week**（周）——聚焦于当前一周。
- **Day**（日）——详细查看单日安排。
- **Agenda**（议程）——按时间顺序列出即将举行的活动。

使用日历顶部的按钮在各视图之间切换。

## 活动详情与讨论

点击任意活动即可查看其详情。在活动详情视图中：

- **成员和负责人**可以发起讨论并对活动发表评论。
- **负责人**可以编辑活动详情、更改时间或删除活动。

:::warning
删除活动会永久移除该活动。如果您只需取消定期活动中的某一次，请考虑编辑该活动而不是删除。
:::

## 订阅日历

您可以将小组日历与个人日历同步：

1. 在小组日历页面，点击 **Subscribe**（订阅）。
2. 按照提示将日历添加到 Google 日历、Apple 日历、Outlook 或任何支持订阅的其他日历应用中。

:::tip
订阅可以让您的个人日程与小组活动保持同步，无需单独查看 B1。小组负责人所做的任何更改都会自动出现在您同步的日历中。
:::
