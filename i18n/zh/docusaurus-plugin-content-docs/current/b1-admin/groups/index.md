# 小组

<div class="article-intro">

**小组**部分让你将教会成员组织成事工、小组、查经班、委员会等。小组是教会社区生活的基础,本部分为你提供了在一个地方创建、管理和与每个小组沟通的工具。请注意,**服侍团队**与小组是分开的——服侍团队用于服侍和志愿者调度。

</div>

## 概述

小组按**类别**组织。类别是一个顶级标签,如"小查经班"、"事工部门"或"委员会"。每个类别可以包含多个小组,使相关小组易于管理。

当你打开小组页面时,你会在顶部看到一个摘要,显示:

- **总小组数** -- 所有类别中的小组数量
- **类别数** -- 你创建的小组类别数量
- **总成员数** -- 所有小组中成员的总计数

摘要下方,你的小组按类别列出,每个小组的成员数显示在旁边。

## 你能做什么

以下是你可以在小组部分完成的事项:

1. **创建和组织小组** -- 在类别内添加新小组,以反映教会的结构。请参见[创建小组](./creating-groups.md)。

2. **管理小组成员** -- 添加和删除成员,指定领导者,以及与小组沟通。请参见[小组成员](./group-members.md)。

3. **安排事件** -- 每个小组都可以有自己的日历,用于会议、活动和重复性活动。请参见[小组日历](./group-calendar.md)。

4. **管理加入请求** -- 当小组使用**请求**加入政策时,审查和批准或拒绝来自想要加入的人的传入成员请求。请参见[小组加入请求](./group-join-requests.md)。

5. **导出小组数据** -- 下载任何小组的成员列表作为CSV文件,用于电子表格或邮件发送。请参见[小组成员](./group-members.md)以获取导出说明。

## 快速开始

要访问小组,打开[Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin左上角的搜索栏),展开**人员**,然后点击**小组**。你将看到所有按类别组织的现有小组。

:::tip
如果你刚刚开始,首先创建一些与教会结构相匹配的类别(例如,"事工部门"、"小查经班"、"委员会")。然后在每个类别内添加单个小组。请参见[创建小组](./creating-groups.md)了解分步说明。
:::

:::info
小组成员必须首先存在于你的[人员](../people/adding-people.md)目录中,才能被添加到小组。如果你是第一次设置B1,请在创建小组之前[导入你的成员数据](../people/importing-data.md)。
:::
