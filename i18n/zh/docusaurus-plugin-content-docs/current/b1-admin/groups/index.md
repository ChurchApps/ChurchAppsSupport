# 小组

<div class="article-intro">

**小组**部分让你将你的教会成员组织到事工、小组、查经、委员会等中。小组是你教会社区生活的支柱，此部分为你提供工具来创建、管理和与每个小组进行沟通。注意**团队**与小组分开 — 团队用于服侍和志愿者日程安排。

</div>

## 概述

小组按**类别**组织。类别是一个顶级标签，例如"小组"、"事工"或"委员会"。每个类别可以包含多个小组，使其易于将相关小组保持在一起。

当你打开小组页面时，你会看到顶部的一个摘要显示：

- **总小组** — 所有类别中的小组数
- **类别** — 你创建的小组类别数
- **总成员** — 所有小组中的成员的合并计数

在摘要下方，你的小组按类别列出，每个小组显示成员数。

## 你能做什么

以下是你在小组部分可以完成的事项：

1. **创建和组织小组** — 在类别中添加新小组以反映你的教会的结构方式。见[创建小组](./creating-groups.md)。

2. **管理小组成员** — 添加和删除成员、指定领导者并与你的小组进行沟通。见[小组成员](./group-members.md)。

3. **安排事件** — 每个小组可以有其自己的日历用于聚集、事件和重复活动。见[小组日历](./group-calendar.md)。

4. **管理加入请求** — 当小组使用**请求**加入策略时，审查并批准或拒绝想要加入的人员的传入成员请求。见[小组加入请求](./group-join-requests.md)。

5. **导出小组数据** — 将任何小组的成员列表下载为 CSV 文件，以在电子表格或邮件中使用。见[小组成员](./group-members.md)以获取导出说明。

## 入门

要访问小组，打开 B1 Admin 仪表板左上角的**部分菜单**并选择**人员**，然后在导航栏中点击**小组**标签页。你会看到所有按类别组织的现有小组。

:::tip
如果你刚刚入门，首先创建几个与你的教会结构相匹配的类别（例如，"事工"、"小组"、"委员会"）。然后在每个类别中添加个人小组。见[创建小组](./creating-groups.md)进行逐步演练。
:::

:::info
小组成员必须首先存在于你的[人员](../people/adding-people.md)目录中才能被添加到小组。如果你是首次设置 B1，在创建小组前[导入你的成员数据](../people/importing-data.md)。
:::
