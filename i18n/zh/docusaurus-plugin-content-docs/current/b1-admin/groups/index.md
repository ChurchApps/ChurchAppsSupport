# 小组

<div class="article-intro">

**小组**板块让你将教会成员组织成事工、小组、圣经研读班、委员会等。小组是教会群体生活的骨干，在此板块中，你可以在一处创建、管理并与每个小组沟通。请注意，**团队（Teams**）与小组是分开的——团队用于服事和志愿者排班。

</div>

## 概览 {#overview}

小组按**类别**组织。类别是顶层标签，例如"小组""事工"或"委员会"。每个类别可以包含多个小组，便于将相关的小组归在一起。

打开小组页面时，你会看到一个 **Search groups...**（搜索小组）框、一排类别按钮，以及你所有小组的表格。每个小组的名称下方会显示其类别和标签，并附有成员人数。在搜索框中输入即可按名称或类别查找小组；点击 **All**（全部）或某个类别名称即可筛选列表（其他类别位于 **More categories**（更多类别）下）；点击 **Name**（名称）或 **People**（人员）列标题即可排序。点击 **Clear filters**（清除筛选）即可重新显示所有小组。

页眉中的按钮用于访问本板块的其他功能：

- **Group Health**（小组健康状况）——比较所有小组的成员和出席情况。参见[小组健康状况](./groups-health.md)。
- **pending requests**（待处理申请）（例如"2 pending requests"）——当有人等待加入小组时出现。参见[小组加入申请](./group-join-requests.md#for-administrators)。
- **Export**（导出）——将小组列表下载为 CSV 文件。
- **Add Group**（添加小组）——创建小组。参见[创建小组](./creating-groups.md)。

## 你可以做什么 {#what-you-can-do}

在小组板块中，你可以完成以下操作：

1. **创建和组织小组**——在各个类别中添加新小组，以反映教会的组织结构。参见[创建小组](./creating-groups.md)。

2. **管理小组成员**——添加和移除成员、指定负责人，并与小组沟通。参见[小组成员](./group-members.md)。

3. **安排活动**——每个小组都可以拥有自己的日历，用于聚会、活动和定期事项。参见[小组日历](./group-calendar.md)。

4. **管理加入申请**——当小组采用 **Request**（申请）加入政策时，审阅并批准或拒绝想要加入的人员提交的入会申请。参见[小组加入申请](./group-join-requests.md)。

5. **导出小组数据**——将任何小组的成员名单下载为 CSV 文件，用于电子表格或邮寄。导出说明请参见[小组成员](./group-members.md#exporting-group-data)。

6. **查看小组健康状况**——在一张表格中查看每个小组的成员增长、流失和出席情况。参见[小组健康状况](./groups-health.md)。

## 入门 {#getting-started}

要访问小组，请打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **People**，然后点击 **Groups**。你会看到所有现有小组，并可按类别进行筛选。

:::tip
如果你刚刚开始，请先创建几个与教会结构相符的类别（例如"事工""小组""委员会"），然后在每个类别中添加具体的小组。参见[创建小组](./creating-groups.md)，了解逐步操作指南。
:::

:::info
小组成员必须先存在于你的[人员](../people/adding-people.md)名录中，才能被添加到小组。如果你是首次设置 B1，请在创建小组之前[导入你的成员数据](../people/importing-data.md)。
:::
