# 小组健康状况

<div class="article-intro">

组健康状况仪表板为您提供了所有组运行情况的鸟瞰图——成员趋势、参加平均数和过去 90 天的增长或流失——全部在一个可排序的表格中。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要至少几个有成员的组来看到有意义的数据。请参阅[创建组](creating-groups)。
- 参加数据从记录的会话中拉取。请参阅[参加](../attendance/)部分。

</div>

## 打开组健康状况

在 B1 Admin 中，打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**人员**，点击**组**，然后点击页面标题中的**组健康状况**按钮。仪表板加载一个表格，每行一个组。

## 列

| 列 | 显示什么 |
|--------|--------------|
| **名称** | 组名称，链接到组详情页面 |
| **类别** | 组的类别 |
| **成员** | 当前活跃成员数 |
| **加入（90d）** | 过去 90 天加入的成员 |
| **离开（90d）** | 过去 90 天离开的成员 |
| **流失（90d）** | 过去 90 天的净流失率百分比 |
| **平均参加** | 每个参加会话的平均人数 |

点击任何列标题来按该列对表格进行排序。再次点击来反转排序方向。

## 使用健康状况数据

- **高流失 + 低加入** — 一个正在萎缩且不替换失去成员的组。值得与组领导者进行对话。
- **高加入 + 低参加** — 人员在注册但不出现。考虑参与后续跟进。
- **高平均参加** — 一个健康的、活跃的组。其他组的潜在模型。

:::tip
点击组名称直接带您到组的详情页面，您可以在其中查看个人成员、参加记录和日历事件。
:::
