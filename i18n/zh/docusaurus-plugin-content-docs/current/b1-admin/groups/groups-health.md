# 小组健康状况

<div class="article-intro">

小组健康状况面板让你一目了然地了解所有小组的运作情况——成员趋势、出席率平均值，以及过去 90 天的增长或流失情况——全部呈现在一张可排序的表格中。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你至少需要有几个拥有成员的小组，才能看到有意义的数据。参见[创建小组](./creating-groups.md)。
- 出席数据来自已记录的聚会。参见[考勤](../attendance/index.md)板块。

</div>

## 打开小组健康状况 {#opening-groups-health}

在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **People**，点击 **Groups**，然后点击页眉中的 **Group Health**（小组健康状况）按钮。面板会加载一张表格，每个小组占一行。

## 列 {#columns}

| 列 | 显示内容 |
|--------|--------------|
| **Name**（名称） | 小组名称，链接到小组详情页面 |
| **Category**（类别） | 小组所属的类别 |
| **Members**（成员） | 当前活跃成员人数 |
| **Joined (90d)**（加入（90 天））| 过去 90 天内加入的成员 |
| **Left (90d)**（离开（90 天））| 过去 90 天内离开的成员 |
| **Churn (90d)**（流失率（90 天））| 90 天内的净流失率（百分比） |
| **Avg Attendance**（平均出席）| 每次出席聚会的平均人数；若未记录任何出席，则显示"-" |
| **Avg Age**（平均年龄）| 档案中有出生日期的成员的平均年龄 |
| **Female**（女）/ **Male**（男） | 女性和男性成员的人数 |

表格默认按名称排序。点击任一列标题即可按该列排序，再次点击则反转排序方向。点击页面顶部的 **Groups** 即可返回小组列表。

## 单个小组的健康状况 {#one-groups-health}

每个小组自己的页面都有一个 **Health**（健康状况）板块，其中有一行摘要（过去 90 天的成员、加入和离开人数）。点击 **See health**（查看健康状况）即可打开该小组的健康状况视图：包括 **Members**（成员）、**Joined (90d)**（加入（90 天））、**Left (90d)**（离开（90 天））和 **Churn (90d)**（流失率（90 天））的数字，**Membership Changes (12 months)**（成员变化（12 个月））图表，针对跟踪考勤的小组显示的 **Attendance Trend**（出席趋势）图表，以及该小组成员的 **Age**（年龄）和 **Gender**（性别）图表。

## 运用健康状况数据 {#using-health-data}

- **流失率高 + 加入人数少**——小组正在萎缩，且没有补充流失的成员。值得与小组负责人谈一谈。
- **加入人数多 + 出席率低**——人们在报名，却没有到场。可以考虑加强参与度的跟进。
- **平均出席率高**——小组健康、活跃。可作为其他小组的参考范例。

:::tip
点击小组名称即可直接进入该小组的详情页面，查看各个成员、出席记录和日历活动。
:::
