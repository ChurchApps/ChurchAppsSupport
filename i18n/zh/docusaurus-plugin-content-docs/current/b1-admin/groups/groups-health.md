# 小组健康状况

<div class="article-intro">

小组健康状况仪表板为您提供所有小组状况的俯瞰视图——成员趋势、出席平均数和过去90天的增长或流失——全部在一个可排序的表格中。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 您需要至少几个有成员的小组才能看到有意义的数据。查看[创建小组](creating-groups)。
- 出席数据从记录的会话中提取。查看[出席](../attendance/)部分。

</div>

## 打开小组健康状况

在B1 Admin中，打开左上角的**部分菜单**并选择**人员**，然后在导航栏中点击**小组**并点击页面标题中的**小组健康状况**按钮。仪表板加载一个表格，每个小组占一行。

## 列

| 列 | 显示内容 |
|--------|--------------|
| **名称** | 小组名称，链接到小组详细信息页面 |
| **类别** | 小组的类别 |
| **成员** | 当前活跃成员计数 |
| **加入（90天）** | 过去90天内加入的成员 |
| **离开（90天）** | 过去90天内离开的成员 |
| **流失（90天）** | 90天内的净流失率百分比 |
| **平均出席** | 每次出席会话的平均人数 |

点击任何列标题按该列对表格进行排序。再次点击以反转排序方向。

## 使用健康数据

- **高流失+低加入** ——一个正在缩小且未能替换流失成员的小组。值得与小组领导者进行对话。
- **高加入+低出席** ——人们注册但不出现。考虑进行参与度跟进。
- **高平均出席** ——一个健康、活跃的小组。其他小组的潜在模式。

:::tip
点击小组名称可直接转到小组的详细信息页面，您可以在其中查看各个成员、出席记录和日历活动。
:::
