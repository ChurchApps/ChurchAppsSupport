# 小组健康

<div class="article-intro">

小组健康仪表板让你可以从高层次了解所有小组的状况 — 成员趋势、出席平均值以及过去 90 天的增长或流失 — 全部在一个单一的可排序表中。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要至少几个有成员的小组来查看有意义的数据。见[创建小组](creating-groups)。
- 出席数据从记录的课程中提取。见[出席](../attendance/)部分。

</div>

## 打开小组健康

在 B1 Admin 中，打开左上角的**部分菜单**并选择**人员**，然后在导航栏中点击**小组**标签页并选择**健康**。仪表板加载一个表，每个小组一行。

## 列

| 列 | 显示内容 |
|--------|--------------|
| **名字** | 小组名称，链接到小组详情页面 |
| **类别** | 小组的类别 |
| **成员** | 当前活跃成员数 |
| **已加入 (90d)** | 过去 90 天加入的成员 |
| **已离开 (90d)** | 过去 90 天离开的成员 |
| **流失 (90d)** | 过去 90 天的净流失率（百分比） |
| **平均出席** | 每个出席课程的平均出席人数 |

点击任何列标题以按该列排序表。再次点击以反转排序方向。

## 使用健康数据

- **高流失 + 低加入** — 一个小组正在收缩且没有替换失去的成员。值得与小组领导进行交谈。
- **高加入 + 低出席** — 人们正在注册但没有出现。考虑进行参与跟进。
- **高平均出席** — 一个健康、活跃的小组。其他小组的潜在模型。

:::tip
点击小组名称会直接带你到小组的详情页面，在那里你可以查看个人成员、出席记录和日历事件。
:::
