# 小组成员

<div class="article-intro">

创建小组后，下一步就是添加成员。在小组的详情页面，您可以搜索人员、将其添加到小组、指定负责人、发送消息以及导出成员列表。管理小组成员资格对于协调小组、委员会和班级至关重要。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要在 B1 Admin 中至少设置一个小组。如果您还没有创建小组，请参阅[创建小组](creating-groups.md)。
- 您想要添加的人员应已在您的[人员](../people/adding-people.md)通讯录中。如果某人不在其中，您可以从成员搜索中创建该人员（见下文）。

</div>

## 将成员添加到小组

1. 在 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)中，选择**人员 > 小组**，然后点击您要管理的小组。
2. 在小组页面的**成员**部分，点击**所有成员**。（团队和事工会直接打开其成员列表。）
3. 在成员列表下方的**添加人员**框中，输入您要添加的人员姓名，然后按**回车**或点击搜索图标。
4. 在搜索结果中，点击该人员的姓名，或点击其旁边的添加图标。
5. 该人员现在会出现在小组成员列表中。

:::tip
在您输入任何内容之前，**添加人员**框会显示一份简短的**最近的人员**列表，您只需点击一下即可添加他们。
:::

完成后，点击带有小组名称的**返回**链接，即可返回小组页面。小组页面会显示小组的**成员**、**课程**、**日历**和**健康**摘要，每项都带有通往其完整视图的链接。如果您是该小组的负责人之一，页面还会显示**负责人备注**（见下方的[负责人备注](#leader-notes)）。

### 添加尚未在 B1 中的人员

如果您的搜索找不到任何人，搜索结果会显示**未找到记录**，并附带一个**添加新人员**链接。点击该链接，输入此人的名字、姓氏，以及（可选）电子邮件，然后点击**添加**。新人员会在您的人员通讯录中被创建，并在同一步骤中添加到小组中 -- 您无需再次搜索他们。

## 指定小组负责人 {#designating-group-leaders}

小组负责人拥有特殊权限 -- 他们可以编辑[小组日历](group-calendar.md)、管理活动，并协助协调小组工作。

1. 在小组成员列表中，找到您要将其设为负责人的人员。
2. 点击其姓名旁边的**星形图标**（**设为负责人**）。
3. 该人员即被指定为小组负责人，并显示**负责人**徽章。

若要取消负责人身份，请再次点击星形图标（**移除负责人权限**）。

:::info
任何小组成员都可以查看小组日历和活动，但只有负责人可以添加或编辑日历活动。
:::

## 负责人备注 {#leader-notes}

小组负责人可以为小组保留私人备注 -- 例如跟进事项、祷告需求或牧养关注 -- 其他小组成员永远看不到这些内容。

只有该小组的负责人才会在小组页面上看到**负责人备注**部分。该部分会显示最新的备注、撰写人及撰写时间，以及备注的总数。

1. 在小组页面上，点击**负责人备注**部分中的**所有备注**。
2. 在框中输入您的备注并发布。备注会附带作者的姓名和照片一同列出。
3. 点击带有小组名称的**返回**链接，即可返回小组页面。

:::info
负责人备注仅对该小组的负责人可见。其他成员看不到，员工或管理员即使拥有全部权限，除非他们同时也是该小组的负责人，否则同样看不到。若要让他人获得访问权限，请[将其设为负责人](#designating-group-leaders)。负责人还可以在 [B1.church](../../b1-church/groups/group-details.md#leader-notes) 上小组页面的**负责人备注**部分看到这些备注。
:::

## 向小组成员发送消息

您可以直接从 B1 Admin 与小组的所有成员沟通：

1. 在小组的成员列表中，点击列表上方的**向成员发送消息**图标。
2. 在文本框中输入您的消息（或从**模板**中选择一个）。
3. 点击**发送**。

您的消息将送达小组的所有成员。

## 向小组成员发送电子邮件

您可以向小组的所有成员发送格式化的电子邮件：

1. 在小组详情页面上，点击页面左侧的**电子邮件**按钮。
2. "发送电子邮件"对话框随即打开，显示将收到邮件的成员人数，以及没有登记电子邮件地址的人数。
3. 可选择从下拉菜单中选择一个**电子邮件模板**，或从头开始撰写消息。点击**管理模板**即可创建或编辑模板。
4. 输入**邮件主题**。您可以点击字段标签来插入合并字段：`{{firstName}}`、`{{lastName}}`、`{{displayName}}`、`{{email}}`、`{{churchName}}`。
5. 使用 HTML 编辑器撰写**邮件正文**。此处同样可以使用相同的合并字段。
6. 点击**发送**。
7. 摘要会显示成功发送的邮件数量，以及被跳过的成员数量（没有登记电子邮件地址）。

:::tip
为每周更新、活动通知或祷告请求等定期沟通创建可重复使用的电子邮件模板。模板可以节省时间，并确保信息传达的一致性。
:::

### 为您的教会开启小组电子邮件 {#turning-on-group-email-for-your-church}

在 B1 上的所有教会都从同一个地址发送电子邮件，因此它们共享同一个发送信誉。为确保每个人的电子邮件都不会被归入垃圾邮件文件夹，ChurchApps 团队会在每个教会首次发送小组电子邮件之前对其进行一次审核。

如果您的教会尚未通过审核，"发送电子邮件"对话框会显示**小组电子邮件需要快速审核**，而不是消息编辑器：

1. 点击**请求审核**。ChurchApps 支持团队会收到通知。
2. 对话框会变为**已请求审核**。您可以关闭它。
3. 小组电子邮件通常会在一个工作日内开启。之后再次打开"发送电子邮件"对话框，即可发送您的消息。

在您的教会获得批准之前，B1 也不会发送[表单后续电子邮件](../forms/creating-forms.md#sending-a-follow-up-email)，或[工作流](../serving/workflows.md)中的**发送电子邮件**步骤。

:::info 发送限制
获得批准后，每个教会每天最多可以发送 150 封教会撰写的电子邮件。随着您的教会积累良好的发送记录，该限制会逐步提高，最高可达每天 2,000 封。如果近期的邮件被退回或被标记为垃圾邮件，小组电子邮件将暂停发送，对话框会提示您联系支持人员。如果某次发送会超过每日限额，B1 将不会发送该邮件，并会显示错误信息。
:::

## 向小组成员发送短信

您的教会连接[短信服务提供商](../settings/church-settings.md#texting)后，小组页面上的**电子邮件**按钮旁边会出现一个**短信**按钮（**向本小组发送短信**）。

1. 在小组详情页面上，点击**短信**。
2. 对话框会显示将收到短信的成员人数。没有登记手机号码或已选择退订的成员将被跳过。
3. 输入您的消息。若要个性化内容，请点击消息框下方的占位符标签 -- **名字**、**姓氏**、**显示名称**或**教会名称** -- 将其插入光标处。发送短信时，每个占位符都会被替换为收件人自己的相应信息。
4. 点击**发送**。

有关更多详情，请参阅[使用合并字段个性化短信](../settings/church-settings.md#personalizing-texts-with-merge-fields)。

## 导出小组数据

若要将小组成员列表下载为文件：

1. 在小组的成员列表中，点击列表上方的**导出**。
2. 包含小组成员信息的 CSV 文件将下载到您的电脑。

CSV 导出适用于将数据导入其他工具，或保留离线记录。如需更多导出选项，请参阅[导出数据](../people/exporting-data.md)。

## 打印成员列表 {#printing-the-member-list}

在小组的成员列表中，点击列表上方的**打印点名册**（打印机）图标，并选择一种版式。页面会在新标签页中打开，并自动弹出浏览器的打印对话框。

- **考勤表** -- 一份不带日期的班级名单，其中带有**出席**和**缺席**方框，供教师手动标记。参见[打印点名册](../attendance/recording-attendance.md#printing-a-roll-sheet)。
- **联系人名册** -- 小组的联系名单，标注今天的日期，顶部显示您教会的徽标（如果您上传过，则为[网站 > 外观](../website/appearance.md)中的**浅色背景徽标**），其下方是教会名称，以及小组名称。每位成员占一行，包含其**姓名**、**电话**、**电子邮件**和**地址**。负责人会排在最前面并标注**负责人**，其他成员则按姓氏排列。显示的电话为成员的手机号码；如果没有手机号码，则显示其住宅或工作电话。对于已选择退订的成员，其联系方式将留空。

:::warning
联系人名册包含成员的个人联系信息。请仅与小组负责人以及其他需要该信息的人员分享打印副本。
:::

## 向小组成员发送推送通知

您可以直接向所有在设备上安装了 B1.church 应用并启用了推送通知的小组成员发送推送通知。

1. 在小组详情页面上，点击**通知**（位于**电子邮件**和**短信**按钮下方 -- 连接[短信服务提供商](../settings/church-settings.md#texting)后，**短信**按钮才会出现）。
2. 对话框会打开，显示您小组中已启用推送的成员人数。
3. 填写通知详情：
   - **标题**（*必填*）-- 简短的摘要，最多 80 个字符。
   - **消息**（*必填*）-- 通知正文，最多 240 个字符。
   - **打开链接或传单 URL**（*可选*）-- 相对应用路径（例如 `/mobile/groups`）或完整的 `https://` URL，点击通知时将打开该链接。
   - **图片 URL**（*可选*）-- 指向图片的 `https://` URL，在支持的设备上会与通知一同显示。
4. 实时预览会显示通知在设备上的呈现效果。
5. 点击**发送通知**。

:::info
推送通知仅会发送给已安装 B1.church PWA 且未禁用推送通知的小组成员。没有注册推送设备或已关闭推送的成员会被计为跳过，发送摘要会显示已送达与被跳过的人数。
:::

:::tip
发送后，对话框会显示成功排队的通知数量。如果大多数成员显示为被跳过，请提醒他们访问其 B1.church 站点，将其安装为主屏幕应用，并在提示时允许通知。
:::

## 移除成员

若要将某人从小组中移除，请在成员列表中找到其姓名，然后点击其条目旁边的**移除**按钮。

:::info
将某人从小组中移除不会将其从您的教会通讯录中删除。他们仍会出现在[人员](../people/adding-people.md)部分，并且随时可以重新添加到小组中。
:::
