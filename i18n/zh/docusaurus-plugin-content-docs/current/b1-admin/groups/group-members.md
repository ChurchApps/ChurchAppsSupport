# 小组成员 {#group-members}

<div class="article-intro">

创建小组后，下一步就是添加成员。在小组的详情页面，你可以搜索人员、将其添加到小组、指定负责人、发送消息以及导出成员名单。管理小组成员资格对于协调小组、委员会和班级至关重要。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要在 B1 Admin 中至少设置一个小组。如果你还没有创建小组，请参见[创建小组](creating-groups.md)。
- 你想添加的人员应已在你的[人员](../people/adding-people.md)名录中。如果某人不在其中，你可以通过成员搜索创建该人员（见下文）。

</div>

## 将成员添加到小组 {#adding-members-to-a-group}

1. 在[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)中，选择 **People > Groups**，然后点击你要管理的小组。
2. 在小组页面的 **Members**（成员）板块中，点击 **All members**（所有成员）。（团队和事工会直接打开其成员列表。）
3. 在成员列表下方的 **Add Person**（添加人员）框中，输入你想添加的人员姓名，然后按 **Enter** 或点击搜索图标。已在小组中的人员不会出现在搜索结果中。若要通过姓名以外的其他字段查找人员，请点击 **Advanced**（高级）。
4. 在搜索结果中点击该人员的姓名，或点击其旁边的添加图标。
5. 该人员现在会出现在小组成员列表中。如果其档案中有电子邮件地址，**Send Invite Email?**（发送邀请邮件？）对话框会询问是否向其发送邀请邮件；点击 **Send Invite**（发送邀请）或 **No Thanks**（不用了）。

:::tip
在你输入任何内容之前，**Add Person** 框会显示一份简短的 **Recent people**（最近的人员）列表，你只需点击一下即可添加：首先是你在任何人员搜索中最近选择过的人员（会记住在此浏览器中的选择），然后是最近加入 B1 的人员。
:::

完成后，点击带有小组名称的 **Back to** 链接即可返回小组页面。小组页面会显示小组的摘要：**Members**（成员，附有 **All members**（所有成员））、**Sessions**（聚会，附有 **All sessions**（所有聚会））、**Calendar**（日历，附有 **All events**（所有活动））以及 **Health**（健康状况，附有 **See health**（查看健康状况））。每个链接都会打开完整视图；**See health** 会显示小组的成员、加入、离开和流失人数，以及成员变化、考勤、年龄和性别的图表。如果你是该小组的负责人之一，页面还会显示 **Leader notes**（负责人笔记）（见下文[负责人笔记](#leader-notes)）。如果有表单关联到该小组，还会出现 **Linked forms**（关联表单）板块（见下文[关联表单](#linked-forms)）。

### 添加尚未在 B1 中的人员 {#adding-someone-who-isnt-in-b1-yet}

如果搜索未找到任何人，搜索结果会显示 **No records found**（未找到记录），并附有 **Add New Person**（添加新人员）链接。点击该链接，输入此人的名字和姓氏，可选填称谓、电子邮件和手机号码，然后点击 **Add**。新人员会在一个步骤中被创建到你的人员名录中，并加入该小组——无需再次搜索。

## 指定小组负责人 {#designating-group-leaders}

小组负责人拥有特殊权限——他们可以编辑[小组日历](group-calendar.md)、管理活动，并协助协调小组的工作。

1. 在小组成员列表中，找到你想设为负责人的人员。
2. 点击其姓名旁边的**星形图标**（**Make Leader**（设为负责人））。
3. 该人员即被指定为小组负责人，并显示 **Leader**（负责人）标记。

若要取消负责人身份，请再次点击星形图标（**Remove Leader Access**（移除负责人权限））。成员列表顶部会统计小组的成员和负责人数量。

:::info
任何小组成员都可以查看小组日历和活动，但只有负责人可以添加或编辑日历活动。
:::

## 关联表单 {#linked-forms}

当某个独立表单[关联到该小组](../forms/creating-forms.md#linking-a-form-to-a-group)后，小组页面会显示 **Linked forms**（关联表单）板块，列出每个表单的名称、其是 **Open**（开放）还是 **Closed**（已关闭），以及关联表单的数量。该板块仅对小组负责人和可以管理表单的人员显示，且只有在至少关联了一个表单时才会出现。表单管理员可以点击表单名称将其打开，或点击 **All forms**（所有表单）前往表单页面。

小组负责人可以在 [B1.church](../../b1-church/groups/group-details.md#linked-forms) 的小组页面上阅读和打印这些表单的回答。

## 负责人笔记 {#leader-notes}

小组负责人可以为小组保留私人笔记——例如跟进事项、代祷需要或牧养关注——其他小组成员都看不到。

**Leader notes** 板块仅对该小组的负责人显示在小组页面上。它会显示最新的一条笔记、撰写人及撰写时间，以及笔记总数。

1. 在小组页面上，点击 **Leader notes** 板块中的 **All notes**（所有笔记）。
2. 在框中输入笔记并发布。如需设置格式，请先选中文字，然后点击输入框下方在输入时出现的一排按钮 **Bold**（粗体）、**Italic**（斜体）、**Bulleted list**（项目符号列表）和 **Numbered list**（编号列表）中的相应按钮（也可以按 **Ctrl+B** / **Ctrl+I**）。在列表中，按 **Enter** 开始下一项，在空白项上按 **Enter** 则结束列表。笔记会显示撰写人的姓名和照片，以及每条笔记的发布日期和时间。
3. 点击带有小组名称的 **Back to** 链接即可返回小组页面。

:::info
负责人笔记仅对该小组的负责人可见。其他成员看不到，即使是拥有完整权限的工作人员或管理员也看不到，除非他们同时也是该小组的负责人。若要让他人获得访问权限，请[将其设为负责人](#designating-group-leaders)。负责人还可以在 [B1.church](../../b1-church/groups/group-details.md#leader-notes) 小组页面的 **Leader notes** 板块中，以及 B1 Admin 中 [笔记](../people/notes.md)页面的 **Groups** 标签上看到这些笔记。
:::

## 向小组成员发送消息 {#sending-messages-to-group-members}

你可以直接从 B1 Admin 向小组的所有成员发送消息：

1. 在小组的成员列表中，点击列表上方的 **Send a message to members**（向成员发送消息）图标。
2. 在文本框中输入消息，最多 140 个字符。若要从现成的消息开始，请点击 **Show Templates**（显示模板），然后从 **Templates**（模板）中选择一个。
3. 点击 **Send**（发送）。**Message sent.**（消息已发送。）的提示会确认发送成功。

你的消息会以应用通知的形式送达小组中的每位其他成员，内容以"Message from"（来自）和你的名字开头。

## 向小组成员发送电子邮件 {#emailing-group-members}

你可以向小组的所有成员发送格式化的电子邮件：

1. 在小组详情页面上，点击页面左侧的 **Email**（电子邮件）按钮。
2. **Send Email**（发送电子邮件）对话框会打开，显示将收到邮件的成员人数，以及档案中没有电子邮件地址的人数。
3. 可选择从 **Load Template (optional)**（加载模板（可选））中选择已保存的电子邮件，或从头撰写消息。点击 **Manage Templates**（管理模板）可创建或编辑模板。
4. 输入 **Subject**（主题）。你可以点击字段标签插入合并字段：**First Name**（名字）（`{{firstName}}`）、**Last Name**（姓氏）（`{{lastName}}`）、**Display Name**（显示名称）（`{{displayName}}`）、**Email**（电子邮件）（`{{email}}`）、**Church Name**（教会名称）（`{{churchName}}`），以及 **Group Name**（小组名称）（`{{groupName}}`），后者会自动填入小组的名称。
5. 使用格式编辑器撰写**邮件正文**。这里同样可以使用合并字段。发送前，点击 **Preview**（预览）标签检查消息。
6. 点击 **Send Email**（发送电子邮件）。
7. 摘要会显示成功发送的邮件数量，以及被跳过的成员数量（因为没有电子邮件地址）。

:::tip
为每周更新、活动公告或代祷请求等定期沟通创建可重复使用的电子邮件模板。模板既节省时间，又能确保信息表达一致。
:::

### 为教会开启小组电子邮件 {#turning-on-group-email-for-your-church}

B1 上的所有教会都从同一个地址发送电子邮件（教会名称显示为发件人名称），因此共享同一发信信誉。为了避免所有人的邮件被归入垃圾邮件，ChurchApps 团队会在教会首次发送小组电子邮件前进行一次审核。

如果你的教会尚未通过审核，**Send Email** 对话框会显示 **Group email needs a quick review**（小组电子邮件需要快速审核），而不是消息编辑器：

1. 点击 **Request review**（申请审核）。ChurchApps 支持团队会收到通知。
2. 对话框会变为 **Review requested**（已申请审核）。你可以关闭该对话框。
3. 小组电子邮件通常会在一个工作日内开通。届时再次打开 Send Email 对话框，即可发送你的消息。

在教会获得批准之前，B1 也不会发送[表单跟进电子邮件](../forms/creating-forms.md#sending-a-follow-up-email)，或[工作流](../serving/workflows.md)中的**发送电子邮件**步骤。

:::info 发送限制
获得批准后，教会每天最多可以发送 150 封由教会撰写的电子邮件。随着教会积累良好的发送记录，该上限会逐步提高，最高可达每天 2,000 封。如果近期的邮件被退回或被标记为垃圾邮件，小组电子邮件功能会暂停，对话框会提示你联系支持团队。如果某次发送会超出每日上限，B1 将不会发送，并显示错误提示。
:::

## 向小组成员发送短信 {#texting-group-members}

一旦你的教会连接了[短信服务提供商](../settings/church-settings.md#texting)，小组页面上的 **Email** 按钮旁边就会出现 **Text** 按钮（**Text this group**（向本小组发送短信））。

1. 在小组详情页面上，点击 **Text**。
2. 对话框会显示将收到短信的成员人数。没有手机号码或已选择退出的成员将被跳过。
3. 可选择从 **Load Template (optional)** 中选择已保存的短信以填充内容。当你的教会拥有[短信模板](../settings/email-templates.md#text-templates)后，选择器才会出现；可以编辑设置的人员还会看到 **Manage Templates**（管理模板）链接。
4. 输入或编辑你的消息。若要个性化内容，请点击消息框下方的占位符标签——**First Name**、**Last Name**、**Display Name**、**Church Name** 或 **Group Name**——将其插入光标位置。每个占位符在发送时都会被替换为收件人自己的信息；**Group Name** 会变为小组名称。
5. 点击 **Send**。

更多详情请参见[使用合并字段个性化短信](../settings/church-settings.md#personalizing-texts-with-merge-fields)。

## 导出小组数据 {#exporting-group-data}

若要将小组成员名单下载为文件：

1. 在小组的成员列表中，点击列表上方的 **Export**（导出）。
2. 包含小组成员信息的 CSV 文件将下载到你的电脑中。

CSV 导出适用于将数据导入其他工具，或保留离线记录。如需了解更多导出选项，请参见[导出数据](../people/exporting-data.md)。

## 打印成员名单 {#printing-the-member-list}

在小组的成员列表中，点击列表上方的**打印点名表**（**Print Roll Sheet**）（打印机）图标，然后选择版式。该图标对可以查看小组成员的人员以及小组负责人显示。页面会在新标签页中打开，并自动弹出浏览器的打印对话框。

- **Attendance Sheet**（考勤表）——一份不带日期的班级名单，附有 **Present**（出席）和 **Absent**（缺席）复选框，供教师手动标记。参见[打印点名表](../attendance/recording-attendance.md#printing-a-roll-sheet)。
- **Contact Roster**（联系人名册）——小组的联系人名单，标注当天日期，页眉为你的教会徽标（如果你已上传，则使用[网站 > 外观](../website/appearance.md)中的 **Light Background Logo**），其下方为教会名称，并显示小组名称。每位成员占一行，包括其 **Name**（姓名）、**Phone**（电话）、**Email**（电子邮件）和 **Address**（地址）。负责人排在最前并标注 **Leader**（负责人），其他人则按姓氏排序。显示的电话是成员的手机号码；若没有手机号码，则显示其住宅或工作电话。选择退出的人员，其联系方式将留空。

:::warning
联系人名册包含成员的个人联系信息。打印件仅应分发给小组负责人及其他有需要的人员。
:::

## 向小组成员发送推送通知 {#sending-push-notifications-to-group-members}

你可以直接向所有已在设备上安装 B1.church 应用并开启推送通知的小组成员发送推送通知。

1. 在小组详情页面上，点击 **Notify**（通知）（位于 **Email** 和 **Text** 按钮下方——一旦[短信服务提供商](../settings/church-settings.md#texting)连接后，**Text** 按钮才会出现）。
2. 对话框会打开，显示小组中开启了推送功能的成员人数。你本人不计入，因为你是发送者。
3. 在 **When**（何时）下，保持 **Send now**（立即发送），或选择 **Schedule for later**（稍后定时发送），然后选择 **Send at**（发送时间）的日期和时间。定时通知可以在 **Mobile > [Push Notifications](../settings/mobile-app.md#push-notifications)** 下查看、编辑或取消。
4. 填写通知详情：
   - **Title**（标题）*（必填）*——简短的摘要，最多 80 个字符。
   - **Message**（消息）*（必填）*——通知正文，最多 240 个字符。
   - **Open link or flyer URL**（打开的链接或传单网址）*（可选）*——相对的应用路径（例如 `/mobile/groups`）或完整的 `https://` 网址，点击通知时会打开该链接。
   - **Image URL**（图片网址）*（可选）*——一个 `https://` 图片网址，在支持的设备上会与通知一同显示。
5. 实时预览会显示该通知在设备上的呈现效果。
6. 点击 **Send Notification**（发送通知）（或 **Schedule Notification**（定时发送通知））。

:::info
推送通知仅会送达已安装 B1.church PWA 且未关闭推送通知的小组成员。没有注册推送设备或关闭了推送的成员会被计为已跳过，发送摘要会显示已送达与已跳过的人数。
:::

:::tip
发送后，对话框会显示成功加入发送队列的通知数量。如果大多数成员都显示为已跳过，请提醒他们访问 B1.church 网站，将其安装为主屏幕应用，并在提示时允许通知。
:::

## 移除成员 {#removing-members}

若要将某人移出小组，请在成员列表中找到其姓名，点击其条目旁边的**移除**图标，然后确认。

:::info
将某人移出小组不会将其从教会名录中删除。该人员仍会出现在[人员](../people/adding-people.md)板块中，并且可以随时重新添加到小组。
:::
