# 组成员

<div class="article-intro">

创建组之后，下一步就是添加成员。在组的详情页面中，您可以搜索人员、将他们添加到组、指定组长、发送消息以及导出成员列表。管理组成员对于协调小组、委员会和班级至关重要。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要在 B1 Admin 中至少设置一个组。如果您还没有创建组，请参阅[创建组](creating-groups.md)。
- 您要添加的人员应已在您的[人员](../people/adding-people.md)目录中。如果某人不在其中，您可以通过成员搜索创建该人员（见下文）。

</div>

## 向组中添加成员 {#adding-members-to-a-group}

1. 在 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)中，选择**人员 > 组**，然后点击您要管理的组。
2. 在组页面的**成员**部分，点击**所有成员**。（团队和事工会直接打开其成员列表。）
3. 在成员列表下方的**添加人员**框中，输入您要添加的人员姓名，然后按 **Enter** 或点击搜索图标。
4. 在搜索结果中，点击此人的姓名，或点击其旁边的添加图标。
5. 此人现在会出现在组成员列表中。

:::tip
在您输入任何内容之前，**添加人员**框会显示一个简短的**最近的人员**列表，您可以一键添加。
:::

完成后，点击带有组名的**返回至**链接，即可回到组页面。组页面会显示组的**成员**、**场次**、**日历**和**健康状况**摘要，每项都带有通往其完整视图的链接。

### 添加尚未在 B1 中的人员 {#adding-someone-who-isnt-in-b1-yet}

如果搜索结果中没有任何人，搜索会显示**未找到记录**以及**添加新人员**链接。点击该链接，输入此人的名字、姓氏，以及（可选）电子邮件，然后点击**添加**。新人员会被创建到您的人员目录中，并在一步之内添加到组中——您无需再次搜索。

## 指定组长 {#designating-group-leaders}

组长拥有特殊权限——他们可以编辑[组日历](group-calendar.md)、管理活动，并协助协调组的工作。

1. 在组成员列表中，找到您要设为组长的人员。
2. 点击其姓名旁边的**星形图标**（**设为组长**）。
3. 此人即被指定为组长，并会显示**组长**标记。

要取消组长身份，请再次点击星形图标（**移除组长权限**）。

:::info
任何组成员都可以查看组日历和活动，但只有组长可以添加或编辑日历活动。
:::

## 向组成员发送消息 {#sending-messages-to-group-members}

您可以直接从 B1 Admin 与组的所有成员沟通：

1. 在组的成员列表中，点击列表上方的**向成员发送消息**图标。
2. 在文本框中输入消息（或从**模板**中选择一条）。
3. 点击**发送**。

您的消息将送达组中的所有成员。

## 向组成员发送电子邮件 {#emailing-group-members}

您可以向组的所有成员发送格式化的电子邮件：

1. 在组详情页面中，点击页面左侧的**电子邮件**按钮。
2. 发送电子邮件对话框会打开，显示将收到邮件的成员人数，以及没有电子邮件地址的人数。
3. 可选择从下拉菜单中选择一个**电子邮件模板**，或从头撰写消息。点击**管理模板**可创建或编辑模板。
4. 输入**主题行**。点击字段标签即可插入合并字段：`{{firstName}}`、`{{lastName}}`、`{{displayName}}`、`{{email}}`、`{{churchName}}`。
5. 使用 HTML 编辑器撰写**邮件正文**。这里同样可以使用相同的合并字段。
6. 点击**发送**。
7. 摘要会显示成功发送的邮件数量，以及被跳过的成员数量（没有电子邮件地址）。

:::tip
为周更新、活动通知或代祷请求等定期沟通创建可重复使用的电子邮件模板。模板可以节省时间，并确保信息的一致性。
:::

### 为您的教会开启群组电子邮件 {#turning-on-group-email-for-your-church}

B1 上的所有教会都使用同一个地址发送电子邮件，因此它们共享同一个发送信誉。为了让所有人的电子邮件都不会被归入垃圾邮件文件夹，ChurchApps 团队会在每个教会首次发送群组电子邮件之前进行一次审核。

如果您的教会尚未通过审核，发送电子邮件对话框会显示**群组电子邮件需要快速审核**，而不是消息编辑器：

1. 点击**请求审核**。ChurchApps 支持团队会收到通知。
2. 对话框会变为**已请求审核**。您可以关闭它。
3. 群组电子邮件通常会在一个工作日内开启。之后再次打开发送电子邮件对话框，即可发送您的消息。

在您的教会获得批准之前，B1 也不会发送[表单后续电子邮件](../forms/creating-forms.md#sending-a-follow-up-email)，或[工作流](../serving/workflows.md)中的**发送电子邮件**步骤。

:::info 发送限制
获得批准后，教会每天最多可以发送 150 封由教会撰写的电子邮件。随着教会积累良好的发送记录，该上限会逐步提高，最高可达每天 2,000 封。如果近期的邮件被退回或被标记为垃圾邮件，群组电子邮件将暂停，对话框会要求您联系支持团队。如果某次发送会超过每日上限，B1 将不会发送该邮件，并显示错误提示。
:::

## 向组成员发送短信 {#texting-group-members}

一旦您的教会连接了[短信服务提供商](../settings/church-settings.md#texting)，组页面上的**电子邮件**按钮旁边就会出现**短信**按钮（**向此组发送短信**）。

1. 在组详情页面中，点击**短信**。
2. 对话框会显示将收到短信的成员人数。没有手机号码或已选择退订的成员将被跳过。
3. 输入您的消息。如需个性化，请点击消息框下方的占位符标签——**名字**、**姓氏**、**显示名称**或**教会名称**——将其插入光标处。发送短信时，每个占位符都会被替换为收件人自己的信息。
4. 点击**发送**。

有关更多详情，请参阅[使用合并字段个性化短信](../settings/church-settings.md#personalizing-texts-with-merge-fields)。

## 导出组数据 {#exporting-group-data}

要将组成员列表下载为文件：

1. 在组的成员列表中，点击列表上方的**导出**。
2. 包含组成员信息的 CSV 文件将下载到您的计算机。

CSV 导出适用于将数据导入其他工具，或保存离线记录。有关更多导出选项，请参阅[导出数据](../people/exporting-data.md)。

## 打印成员列表 {#printing-the-member-list}

在组的成员列表中，点击列表上方的**打印点名表**（打印机）图标，然后选择一种版式。页面将在新标签页中打开，并自动弹出浏览器的打印对话框。

- **考勤表** -- 一份未注明日期的班级名单，带有**出席**和**缺席**方框，供老师手动标记。参阅[打印点名表](../attendance/recording-attendance.md#printing-a-roll-sheet)。
- **联系人名册** -- 该组的联系人列表，注明今天的日期，顶部为您的教会标志（如果您上传过，则为来自[网站 > 外观](../website/appearance.md)的**浅色背景标志**），其下为教会名称，以及组名。每位成员占一行，包括其**姓名**、**电话**、**电子邮件**和**地址**。组长排在最前面并标注**组长**，其他成员则按姓氏排列。显示的电话为成员的手机号码；若没有手机号码，则显示家庭或工作电话。选择退订的人员，其联系方式将留空。

:::warning
联系人名册包含成员的个人联系信息。请仅将打印件分享给组长以及其他需要它的人。
:::

## 向组成员发送推送通知 {#sending-push-notifications-to-group-members}

您可以直接向所有在设备上安装了 B1.church 应用并开启了推送通知的组成员发送推送通知。

1. 在组详情页面中，点击**通知**（位于**电子邮件**和**短信**按钮下方——**短信**按钮在连接[短信服务提供商](../settings/church-settings.md#texting)后才会出现）。
2. 对话框会打开，显示已开启推送的组成员人数。
3. 填写通知详情：
   - **标题** *（必填）* -- 简短的摘要，最多 80 个字符。
   - **消息** *（必填）* -- 通知正文，最多 240 个字符。
   - **打开的链接或传单 URL** *（可选）* -- 相对的应用路径（例如 `/mobile/groups`），或完整的 `https://` URL，点击通知时会打开该地址。
   - **图片 URL** *（可选）* -- 指向图片的 `https://` URL，在支持的设备上会与通知一同显示。
4. 实时预览会显示通知在设备上的呈现效果。
5. 点击**发送通知**。

:::info
推送通知只会发送给已安装 B1.church PWA 且未关闭推送通知的组成员。没有注册推送设备或已关闭推送的成员会被计为已跳过，发送摘要会显示已送达和已跳过的人数。
:::

:::tip
发送后，对话框会显示成功加入队列的通知数量。如果大多数成员显示为已跳过，请提醒他们访问您的 B1.church 站点，将其安装为主屏幕应用，并在提示时允许通知。
:::

## 移除成员 {#removing-members}

要将某人从组中移除，请在成员列表中找到其姓名，然后点击其条目旁边的**移除**按钮。

:::info
将某人从组中移除，并不会将其从教会目录中删除。他们仍会出现在[人员](../people/adding-people.md)部分，并可随时重新添加到组中。
:::
