# 小组成员

<div class="article-intro">

创建小组后，下一步是添加成员。从小组的详细信息页面，您可以搜索人员、将他们添加到小组、分配领导者、发送消息和导出成员列表。管理小组成员对于协调小团体、委员会和班级至关重要。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 您需要在B1 Admin中至少设置一个小组。如果您尚未创建小组，请查看[创建小组](creating-groups.md)。
- 您想要添加的人员必须已存在于您的[人员](../people/adding-people.md)目录中。

</div>

## 将成员添加到小组

1. 导航到**小组**页面并点击您想要管理的小组。
2. 点击**成员**标签页。
3. 在搜索框中，输入您想要添加的人员的名称。
4. 在搜索结果中点击该人员名称旁边的**添加**。
5. 该人现在出现在小组成员列表中。

:::tip
将搜索框留空并点击**搜索**以浏览整个目录。如果您不确定某人姓名的确切拼写，这会很有帮助。
:::

## 指定小组领导者

小组领导者具有特殊权限——他们可以编辑[小组日历](group-calendar.md)、管理活动并帮助协调小组。

1. 在小组成员列表中，找到您想要设为领导者的人员。
2. 点击他们名字旁边的**绿色钥匙图标**。
3. 该人现在被指定为小组领导者。

要移除领导者身份，再次点击绿色钥匙图标。

:::info
任何小组成员都可以查看小组日历和活动，但只有领导者才能添加或编辑日历活动。
:::

## 向小组成员发送消息

您可以直接从B1 Admin与小组的所有成员进行交流：

1. 从小组详细信息页面，查找消息区域。
2. 在文本框中输入您的消息。
3. 点击**发送**。

您的消息将被发送到小组的所有成员。

## 向小组成员发送电子邮件

您可以向小组的所有成员发送格式化电子邮件：

1. 从小组详细信息页面，点击**电子邮件图标**。
2. "发送电子邮件"对话框打开，显示将接收电子邮件的成员数量以及没有电子邮件地址的成员数量。
3. 可选择从下拉菜单中选择**电子邮件模板**，或从头开始撰写消息。点击**管理模板**以创建或编辑模板。
4. 输入**主题行**。您可以通过点击字段芯片插入合并字段：`{{firstName}}`、`{{lastName}}`、`{{displayName}}`、`{{email}}`、`{{churchName}}`。
5. 使用HTML编辑器撰写**电子邮件正文**。相同的合并字段在此处也可用。
6. 点击**发送**。
7. 摘要显示成功发送了多少封电子邮件，以及跳过了多少成员（无电子邮件地址）。

:::tip
为定期沟通（如每周更新、活动公告或祷告请求）创建可重复使用的电子邮件模板。模板节省时间并确保信息一致。
:::

### 为您的教会打开小组电子邮件

B1上的所有教会都从同一地址发送电子邮件，因此他们共享一个发送信誉。为了防止每个人的电子邮件进入垃圾邮件文件夹，ChurchApps团队在每个教会能够发送小组电子邮件之前会对其进行一次审核。

如果您的教会尚未经过审核，"发送电子邮件"对话框会显示**小组电子邮件需要快速审核**而不是消息编辑器：

1. 点击**请求审核**。ChurchApps支持团队会收到通知。
2. 对话框更改为**已请求审核**。您可以关闭它。
3. 小组电子邮件通常在一个工作日内打开。之后再次打开"发送电子邮件"对话框以发送您的消息。

在您的教会获得批准之前，B1也不会发送[表单后续电子邮件](../forms/creating-forms.md#sending-a-follow-up-email)或[工作流](../serving/workflows.md)中的**发送电子邮件**步骤。

:::info 发送限制
获得批准后，教会每天可以发送最多150封教会撰写的电子邮件。随着您的教会建立清洁的发送历史，限制会增长到每天2,000封。如果最近的消息被退回或标记为垃圾邮件，小组电子邮件会暂停，对话框会要求您联系支持。如果发送会超过您的每日限制，B1不会发送，并显示错误。
:::

## 导出小组数据

要将小组成员列表下载为文件：

1. 从小组详细信息页面，点击**下载图标**。
2. 包含小组成员信息的CSV文件将下载到您的计算机。

要打印班级的签到表，请使用**打印点名表**——查看[打印点名表](../attendance/recording-attendance.md#printing-a-roll-sheet)。

CSV导出对于将数据导入其他工具或保留离线记录很有用。有关更多导出选项，请查看[导出数据](../people/exporting-data.md)。

## 向小组成员发送推送通知

您可以直接向安装了B1.church应用程序并启用了推送通知的所有小组成员发送推送通知。

1. 从小组详细信息页面，点击标题工具栏中的**钟形图标**（位于电子邮件和短信图标旁边）。
2. 一个对话框打开，显示您的小组中有多少成员启用了推送通知。
3. 填写通知详情：
   - **标题** *（必需）* ——简短摘要，最多80个字符。
   - **消息** *（必需）* ——通知正文，最多240个字符。
   - **打开链接或传单URL** *（可选）* ——相对应用路径（例如，`/mobile/groups`）或完整`https://`URL，点击时通知会打开。
   - **图像URL** *（可选）* ——`https://`URL到在支持的设备上与通知一起显示的图像。
4. 实时预览显示通知在设备上的显示方式。
5. 点击**发送通知**。

:::info
推送通知仅传送给安装了B1.church PWA并未禁用推送通知的小组成员。没有注册推送设备或推送已关闭的成员被计为已跳过，发送摘要显示有多少人被触及与跳过。
:::

:::tip
发送后，对话框显示有多少通知已成功排队。如果大多数成员显示为已跳过，请提醒他们访问他们的B1.church网站、将其安装为主屏幕应用程序，并在出现提示时允许通知。
:::

## 移除成员

要从小组中移除某人，请在成员列表中找到他们的名字，并点击他们条目旁边的**移除**按钮。

:::info
从小组中移除某人不会将他们从您的教会目录中删除。他们仍会在[人员](../people/adding-people.md)部分出现，并且可以随时重新添加到小组中。
:::
