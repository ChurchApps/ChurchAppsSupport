# 小组成员

<div class="article-intro">

创建小组后，下一步就是添加成员。在小组详情页面，你可以搜索人员、将其加入小组、指定负责人、发送消息以及导出成员名单。管理小组成员资格对于协调小组查经、委员会和班级至关重要。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要在 B1 Admin 中至少设置好一个小组。如果你还没有创建小组，请参阅[创建小组](creating-groups.md)。
- 你想要添加的人员应已在你的[人员](../people/adding-people.md)目录中。如果某人不在其中，你可以通过成员搜索创建该人员（见下文）。

</div>

## 将成员添加到小组

1. 在[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)中，选择 **People > Groups**，然后点击你要管理的小组。
2. 在小组页面的 **Members** 部分，点击 **All members**。（团队和事工会直接打开其成员列表。）
3. 在成员列表下方的 **Add Person** 框中，输入你要添加的人员姓名，然后按 **Enter** 或点击搜索图标。
4. 在搜索结果中，点击该人员的姓名或其旁边的添加图标。
5. 该人员现在会出现在小组成员列表中。

:::tip
在输入任何内容之前，**Add Person** 框会显示一个简短的**最近人员**列表，你只需点击一次即可添加。
:::

完成后，点击带有小组名称的**返回**链接，即可回到小组页面。小组页面会显示小组**成员（Members）**、**场次（Sessions）**、**日历（Calendar）**和**健康度（Health）**的摘要，每项都有通往完整视图的链接。如果你是该小组的负责人之一，还会显示**负责人备注（Leader notes）**（见下文[负责人备注](#leader-notes)）。当小组关联了表单时，还会出现**关联表单（Linked forms）**部分（见下文[关联表单](#linked-forms)）。

### 添加尚未在 B1 中的人员

如果搜索未找到任何人，搜索结果会显示 **No records found**（未找到记录），并附带一个 **Add New Person**（添加新人员）链接。点击该链接，输入此人的名字、姓氏和（可选）电子邮件，然后点击 **Add**。新人员会在你的人员目录中创建，并同时加入小组——无需再次搜索。

## 指定小组负责人 {#designating-group-leaders}

小组负责人拥有特殊权限——他们可以编辑[小组日历](group-calendar.md)、管理活动，并协助协调小组工作。

1. 在小组成员列表中，找到你想设为负责人的人员。
2. 点击其姓名旁边的**星形图标**（**Make Leader**，设为负责人）。
3. 该人员现在被指定为小组负责人，并显示 **Leader** 标识。

要取消负责人身份，请再次点击星形图标（**Remove Leader Access**，移除负责人权限）。

:::info
任何小组成员都可以查看小组日历和活动，但只有负责人可以添加或编辑日历活动。
:::

## 关联表单 {#linked-forms}

当独立表单[关联到该小组](../forms/creating-forms.md#linking-a-form-to-a-group)后，小组页面会显示**关联表单（Linked forms）**部分，列出每个表单的名称、其状态为**开放（Open）**还是**关闭（Closed）**，以及已关联的表单数量。该部分仅对小组负责人以及有权管理表单的人员可见，且只有在至少关联了一个表单时才会出现。表单管理员可以点击表单名称将其打开，或点击 **All forms** 前往表单页面。

小组负责人可以在 [B1.church](../../b1-church/groups/group-details.md#linked-forms) 上的小组页面中阅读并打印这些表单的答复。

## 负责人备注 {#leader-notes}

小组负责人可以为小组保留私人备注——例如后续跟进事项、代祷需求或牧养关注点——而小组中的其他成员永远看不到这些备注。

**负责人备注（Leader notes）**部分只会对该小组的负责人显示在小组页面上。它会显示最新的一条备注、撰写人及时间，以及备注的总条数。

1. 在小组页面的 **Leader notes** 部分，点击 **All notes**。
2. 在文本框中输入备注并发布。备注会按撰写人的姓名和照片、发布的日期和时间列出。
3. 点击带有小组名称的**返回**链接，回到小组页面。

:::info
负责人备注仅对该小组的负责人可见。其他成员看不到，即使是拥有全部权限的工作人员或管理员，除非他们也是该小组的负责人，否则同样看不到。若要让他人获得访问权限，请[将其设为负责人](#designating-group-leaders)。负责人还可以在 [B1.church](../../b1-church/groups/group-details.md#leader-notes) 小组页面的**负责人备注（Leader notes）**部分，以及 B1 Admin 中 [备注（Notes）](../people/notes.md)页面的 **Groups** 标签页中看到这些备注。
:::

## 向小组成员发送消息

你可以直接从 B1 Admin 与小组的所有成员沟通：

1. 在小组成员列表中，点击列表上方的 **Send a message to members**（向成员发送消息）图标。
2. 在文本框中输入消息（或从 **Templates**（模板）中选择一个）。
3. 点击 **Send**。

你的消息将发送给小组的所有成员。

## 向小组成员发送电子邮件

你可以向小组的所有成员发送格式化的电子邮件：

1. 在小组详情页面，点击页面左侧的 **Email** 按钮。
2. 发送电子邮件对话框会打开，显示将收到邮件的成员人数，以及没有登记电子邮件地址的人数。
3. 可选择从下拉菜单中选择**电子邮件模板**，或从头撰写消息。点击 **Manage Templates**（管理模板）可创建或编辑模板。
4. 输入**邮件主题**。你可以通过点击字段标签插入合并字段：`{{firstName}}`、`{{lastName}}`、`{{displayName}}`、`{{email}}`、`{{churchName}}`，以及 **Group Name**（`{{groupName}}`，会自动填入小组名称）。
5. 使用 HTML 编辑器撰写**邮件正文**。这里同样可以使用相同的合并字段。
6. 点击 **Send**。
7. 摘要会显示成功发送的邮件数量，以及被跳过的成员数量（没有登记电子邮件地址）。

:::tip
为定期的沟通创建可重复使用的电子邮件模板，例如每周更新、活动通知或代祷请求。模板可以节省时间，并确保信息的一致性。
:::

### 为教会开启小组邮件 {#turning-on-group-email-for-your-church}

所有使用 B1 的教会都从同一个地址发送电子邮件，因此共享同一个发信信誉。为了让每个教会的邮件都不被归入垃圾邮件，ChurchApps 团队会在教会首次发送小组邮件之前对其进行一次审核。

如果你的教会尚未通过审核，发送电子邮件对话框会显示 **Group email needs a quick review**（小组邮件需要快速审核），而不是消息编辑器：

1. 点击 **Request review**（请求审核）。ChurchApps 支持团队会收到通知。
2. 对话框会变为 **Review requested**（已请求审核）。你可以将其关闭。
3. 小组邮件通常会在一个工作日内开启。之后再次打开发送电子邮件对话框，即可发送你的消息。

在教会获得批准之前，B1 也不会发送[表单跟进邮件](../forms/creating-forms.md#sending-a-follow-up-email)，或[工作流](../serving/workflows.md)中的**发送电子邮件**步骤。

:::info 发送限制
获得批准后，每个教会每天最多可发送 150 封由教会撰写的电子邮件。随着教会积累良好的发送记录，该上限会逐步提高，最高可达每天 2,000 封。如果近期的邮件被退回或被标记为垃圾邮件，小组邮件将暂停，对话框会提示你联系支持团队。如果某次发送会超出每日上限，B1 将不会发送，并显示错误提示。
:::

## 向小组成员发送短信 {#texting-group-members}

一旦你的教会连接了[短信服务商](../settings/church-settings.md#texting)，小组页面上的 **Email** 按钮旁边就会出现 **Text** 按钮（**Text this group**，向本小组发送短信）。

1. 在小组详情页面，点击 **Text**。
2. 对话框会显示将收到短信的成员人数。没有登记手机号码或已选择退出的成员将被跳过。
3. 可选择从 **Load Template (optional)**（加载模板，可选）中选择一条已保存的短信来填充内容。当你的教会设置了[短信模板](../settings/email-templates.md#text-templates)后，该选择器才会出现；有权编辑设置的人员还会看到 **Manage Templates**（管理模板）链接。
4. 输入或编辑你的消息。若要个性化内容，请点击消息框下方的占位符标签——**First Name**（名字）、**Last Name**（姓氏）、**Display Name**（显示名称）、**Church Name**（教会名称）或 **Group Name**（小组名称）——将其插入光标处。发送短信时，每个占位符都会用收件人自己的信息填充；**Group Name** 则会替换为小组的名称。
5. 点击 **Send**。

更多细节请参阅[使用合并字段个性化短信](../settings/church-settings.md#personalizing-texts-with-merge-fields)。

## 导出小组数据

要将小组成员名单下载为文件：

1. 在小组成员列表中，点击列表上方的 **Export**。
2. 包含小组成员信息的 CSV 文件将下载到你的计算机上。

CSV 导出适用于将数据导入其他工具，或保留离线记录。更多导出选项，请参阅[导出数据](../people/exporting-data.md)。

## 打印成员名单 {#printing-the-member-list}

在小组成员列表中，点击列表上方的 **Print Roll Sheet**（打印机）图标，并选择一种版式。页面会在新标签页中打开，并自动弹出浏览器的打印对话框。

- **Attendance Sheet**（出勤表）—— 一份不含日期的班级名单，带有 **Present**（出席）和 **Absent**（缺席）复选框，供教师手工标记。参见[打印点名表](../attendance/recording-attendance.md#printing-a-roll-sheet)。
- **Contact Roster**（联系人名册）—— 小组的联系人名单，标注当天日期，顶部为你的教会标志（如果你已上传，则为来自[网站 > 外观](../website/appearance.md)的 **Light Background Logo**），标志下方是教会名称，以及小组名称。每位成员占一行，包含其**姓名（Name）**、**电话（Phone）**、**电子邮件（Email）**和**地址（Address）**。负责人会排在最前面并标注 **Leader**，其他成员则按姓氏排列。显示的电话为成员的手机号码；若没有手机号码，则显示其住宅或工作电话。选择退出的成员，其联系方式将留空。

:::warning
联系人名册包含成员的个人联系信息。打印的副本只应分享给小组负责人以及其他确有需要的人员。
:::

## 向小组成员发送推送通知

你可以直接向所有已在设备上安装 B1.church 应用并开启推送通知的小组成员发送推送通知。

1. 在小组详情页面，点击 **Notify**（位于 **Email** 和 **Text** 按钮下方——**Text** 按钮需在连接[短信服务商](../settings/church-settings.md#texting)后才会出现）。
2. 对话框会打开，显示你的小组成员中有多少人已开启推送。
3. 填写通知详情：
   - **Title**（标题）*（必填）* —— 简短的摘要，最多 80 个字符。
   - **Message**（消息）*（必填）* —— 通知正文，最多 240 个字符。
   - **Open link or flyer URL**（打开链接或传单网址）*（可选）* —— 相对的应用路径（例如 `/mobile/groups`），或完整的 `https://` 网址，点击通知时将打开该地址。
   - **Image URL**（图片网址）*（可选）* —— 指向图片的 `https://` 网址，在支持的设备上会与通知一同显示。
4. 实时预览会显示通知在设备上的呈现效果。
5. 点击 **Send Notification**（发送通知）。

:::info
推送通知仅会发送给已安装 B1.church PWA 且未关闭推送通知的小组成员。没有注册推送设备或已关闭推送的成员会被计为已跳过，发送摘要会显示已送达与已跳过的人数。
:::

:::tip
发送后，对话框会显示成功加入发送队列的通知数量。如果大多数成员显示为已跳过，请提醒他们访问其 B1.church 网站，将其安装为主屏幕应用，并在提示时允许通知。
:::

## 移除成员

要将某人移出小组，请在成员列表中找到其姓名，然后点击其条目旁边的**移除**按钮。

:::info
将某人移出小组并不会将其从教会目录中删除。他们仍会出现在[人员](../people/adding-people.md)部分中，并且可以随时重新加入小组。
:::
