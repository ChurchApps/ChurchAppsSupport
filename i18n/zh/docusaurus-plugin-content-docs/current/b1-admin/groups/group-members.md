# 小组成员

<div class="article-intro">

创建组后，下一步是添加成员。从组的详情页面，您可以搜索人员、将他们添加到组、分配领导者、发送消息和导出成员列表。管理组成员关系对于协调小组、委员会和班级至关重要。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要在 B1 Admin 中至少设置一个组。如果您还没有创建一个，请参阅[创建组](creating-groups.md)。
- 您想添加的人员应该已经在您的[人员](../people/adding-people.md)目录中。如果某人不在，您可以从成员搜索创建他们（见下文）。

</div>

## 将成员添加到组

1. 在 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)中，选择**人员 > 组**并点击您想管理的组。
2. 点击**成员**选项卡。
3. 在搜索框中，输入您想添加的人员的名称。
4. 在搜索结果中点击人员名称旁边的**添加**。
5. 该人员现在出现在组成员列表中。

:::tip
将搜索框留空并点击**搜索**来浏览您的整个目录。如果您不确定某人的确切拼写，这很有帮助。
:::

### 添加不在 B1 中的人

如果您的搜索找不到任何人，搜索显示**未找到记录**和一个**添加新人员**链接。点击它，输入人员的名字、姓氏和（可选）电子邮件，然后点击**添加**。新人员在您的人员目录中创建并在一个步骤中添加到组——您不需要再次搜索他们。

## 指定组领导者

组领导者有特殊权限——他们可以编辑[组日历](group-calendar.md)、管理事件并帮助协调组。

1. 在组成员列表中，找到您想成为领导者的人员。
2. 点击其名称旁边的**绿色密钥图标**。
3. 该人员现在被指定为组领导者。

要删除领导者状态，再次点击绿色密钥图标。

:::info
任何组成员都可以查看组日历和事件，但仅领导者可以添加或编辑日历事件。
:::

## 向组成员发送消息

您可以直接从 B1 Admin 与组的所有成员沟通：

1. 从组详情页面，查找消息区域。
2. 在文本框中输入您的消息。
3. 点击**发送**。

您的消息将被传递到组的所有成员。

## 向组成员发送电子邮件

您可以向组的所有成员发送格式化的电子邮件：

1. 从组详情页面，点击**电子邮件图标**。
2. 发送电子邮件对话框打开，显示将收到电子邮件的成员数量和有多少没有文件中的电子邮件地址。
3. 或者从下拉菜单中选择一个**电子邮件模板**，或从头开始撰写消息。点击**管理模板**来创建或编辑模板。
4. 输入一个**主题行**。您可以通过点击字段芯片插入合并字段：`{{firstName}}`、`{{lastName}}`、`{{displayName}}`、`{{email}}`、`{{churchName}}`。
5. 使用 HTML 编辑器撰写**电子邮件正文**。相同的合并字段在此处可用。
6. 点击**发送**。
7. 摘要显示成功发送的电子邮件数量和跳过的成员数量（文件中没有电子邮件）。

:::tip
为定期沟通创建可重复使用的电子邮件模板，例如每周更新、活动通知或祈祷请求。模板可节省时间并确保一致的消息传递。
:::

### 为您的教会打开组电子邮件

所有 B1 上的教会都从同一地址发送电子邮件，所以他们共享一个发送信誉。为了保持每个人的电子邮件不进入垃圾邮件文件夹，ChurchApps 团队在教会可以发送组电子邮件之前审查每个教会一次。

如果您的教会还未被审查，发送电子邮件对话框显示**组电子邮件需要快速审查**而不是消息编辑器：

1. 点击**请求审查**。ChurchApps 支持团队被通知。
2. 对话框改为**审查已请求**。您可以关闭它。
3. 组电子邮件通常在一个工作日内打开。在那之后再次打开发送电子邮件对话框来发送您的消息。

在您的教会被批准之前，B1 也不会发送[表单后续电子邮件](../forms/creating-forms.md#sending-a-follow-up-email)或[工作流](../serving/workflows.md)中的**发送电子邮件**步骤。

:::info Sending limits
批准后，教会每天可以发送最多 150 个教会编写的电子邮件。当您的教会建立清洁的发送历史时，限制增长到每天 2,000 个。如果最近的消息出现反弹或被标记为垃圾邮件，组电子邮件暂停，对话框要求您联系支持。如果发送会超过您的每日限制，B1 不会发送它并显示错误。
:::

## 向组成员发送短信

一旦您的教会连接了[短信提供商](../settings/church-settings.md#texting)，短信图标（**向此组发送短信**）出现在组的标题中。

1. 从组详情页面，点击**短信图标**。
2. 对话框显示有多少成员将获得短信。文件中没有手机号码或已退出的成员会被跳过。
3. 输入您的消息。要个性化它，点击消息框下方的占位符芯片——**名字**、**姓氏**、**显示名称**或**教会名称**——在您的光标处插入它。当短信被发送时，每个占位符都被填入接收者自己的详情。
4. 点击**发送**。

有关更多详细信息，请参阅[使用合并字段个性化短信](../settings/church-settings.md#personalizing-texts-with-merge-fields)。

## 导出组数据

要将组成员列表下载为文件：

1. 从组详情页面，点击**下载图标**。
2. 包含组的成员信息的 CSV 文件将下载到您的计算机。

要打印班级的签到表，请使用**打印名单** -- 请参阅[打印名单](../attendance/recording-attendance.md#printing-a-roll-sheet)。

CSV 导出对于将数据导入其他工具或保存离线记录很有用。有关更多导出选项，请参阅[导出数据](../people/exporting-data.md)。

## 向组成员发送推送通知

您可以将推送通知直接发送到所有在其设备上安装了 B1.church 应用并启用了推送通知的组成员。

1. 从组详情页面，点击标题工具栏中的**钟形图标**（在电子邮件和短信图标旁边——一旦[短信提供商](../settings/church-settings.md#texting)连接，短信图标就会显示）。
2. 一个对话框打开，显示您的组中有多少成员启用了推送。
3. 填写通知详情：
   - **标题** *(必需)* -- 简短摘要，最多 80 个字符。
   - **消息** *(必需)* -- 通知正文，最多 240 个字符。
   - **打开链接或传单 URL** *(可选)* -- 一个相对应用路径（例如，`/mobile/groups`）或一个完整 `https://` URL，当点击时通知会打开。
   - **图像 URL** *(可选)* -- 一个 `https://` URL 到出现在支持的设备上通知旁边的图像。
4. 实时预览显示通知在设备上的显示方式。
5. 点击**发送通知**。

:::info
推送通知仅传递给安装了 B1.church PWA 且未禁用推送通知的组成员。没有注册推送设备或推送关闭的成员被计为跳过，发送摘要显示有多少被到达与跳过。
:::

:::tip
发送后，对话框显示有多少通知已成功排队。如果大多数成员显示为已跳过，提醒他们访问他们的 B1.church 网站，将其安装为家庭屏幕应用，并在提示时允许通知。
:::

## 删除成员

要从组中删除某人，在成员列表中找到其名称并点击其条目旁边的**删除**按钮。

:::info
从组中删除人员不会将他们从您的教会目录中删除。他们仍将出现在[人员](../people/adding-people.md)部分，可以随时重新添加到组。
:::
