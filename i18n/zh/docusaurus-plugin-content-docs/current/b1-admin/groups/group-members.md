# 小组成员

<div class="article-intro">

创建小组后，下一步就是添加成员。在小组的详细信息页面，您可以搜索人员、将其添加到小组、指定负责人、发送消息以及导出成员名单。管理小组成员资格对于协调小组查经、委员会和班级至关重要。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您至少需要在 B1 Admin 中设置一个小组。如果您还没有创建小组，请参见[创建小组](creating-groups.md)。
- 您要添加的人员应已在您的[人员](../people/adding-people.md)目录中。如果某人不在其中，您可以通过成员搜索创建他们（见下文）。

</div>

## 向小组添加成员

1. 在[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)中，选择 **People > Groups（人员 > 小组）**，然后点击您要管理的小组。
2. 在小组页面的 **Members（成员）**部分，点击 **All members（全部成员）**。（团队和事工会直接打开其成员列表。）
3. 在成员列表下方的 **Add Person（添加人员）**框中，输入您要添加的人员姓名，然后按 **Enter** 或点击搜索图标。
4. 在搜索结果中，点击该人员的姓名，或点击其旁边的添加图标。
5. 该人员现在会出现在小组成员列表中。

:::tip
在您输入任何内容之前，**Add Person（添加人员）**框会显示一份简短的**最近人员（Recent people）**列表，您只需点击一下即可添加他们。
:::

完成后，点击带有小组名称的 **Back to（返回）**链接，即可返回小组页面。小组页面会显示小组的 **Members（成员）**、**Sessions（课程）**、**Calendar（日历）**和 **Health（健康状况）**摘要，每项都有通往完整视图的链接。如果您是该小组的负责人之一，页面还会显示 **Leader notes（负责人笔记）**（见下文[负责人笔记](#leader-notes)）。如果有表单关联到该小组，还会出现 **Linked forms（关联表单）**部分（见下文[关联表单](#linked-forms)）。

### 添加尚未在 B1 中的人员

如果搜索未找到任何人，搜索结果会显示 **No records found（未找到记录）**以及 **Add New Person（添加新人员）**链接。点击该链接，输入此人的名字、姓氏和（可选的）邮箱，然后点击 **Add（添加）**。新人员将被创建到您的 People（人员）目录中，并同时添加到小组中——您无需再次搜索。

## 指定小组负责人 {#designating-group-leaders}

小组负责人拥有特殊权限——他们可以编辑[小组日历](group-calendar.md)、管理活动，并协助协调小组工作。

1. 在小组成员列表中，找到您想设为负责人的人员。
2. 点击其姓名旁边的**星形图标**（**Make Leader（设为负责人）**）。
3. 该人员即被指定为小组负责人，并会显示 **Leader（负责人）**徽章。

若要取消负责人身份，请再次点击星形图标（**Remove Leader Access（移除负责人权限）**）。

:::info
任何小组成员都可以查看小组日历和活动，但只有负责人可以添加或编辑日历活动。
:::

## 关联表单 {#linked-forms}

当独立表单[关联到小组](../forms/creating-forms.md#linking-a-form-to-a-group)后，小组页面会显示 **Linked forms（关联表单）**部分，列出每个表单的名称、其为 **Open（开放）**还是 **Closed（已关闭）**，以及已关联的表单数量。该部分仅对小组负责人以及可以管理表单的人员显示，并且只有在至少关联了一个表单时才会出现。表单管理员可以点击表单名称打开该表单，也可以点击 **All forms（全部表单）**前往 Forms（表单）页面。

小组负责人可以在小组页面的 [B1.church](../../b1-church/groups/group-details.md#linked-forms) 上阅读和打印这些表单的答案。

## 负责人笔记 {#leader-notes}

小组负责人可以为小组保存私人笔记——例如跟进事项、代祷需求或牧养关切——而其他小组成员永远看不到这些内容。

**Leader notes（负责人笔记）**部分只会显示给该小组的负责人。它会显示最新的一条笔记、撰写人及撰写时间，以及笔记的总数。

1. 在小组页面的 **Leader notes（负责人笔记）**部分，点击 **All notes（全部笔记）**。
2. 在文本框中输入您的笔记并发布。笔记会按撰写人的姓名和照片列出，并显示发布的日期和时间。
3. 点击带有小组名称的 **Back to（返回）**链接，即可返回小组页面。

:::info
负责人笔记只对该小组的负责人可见。其他成员看不到，工作人员或管理员即使拥有完整权限，除非同时也是该小组的负责人，否则同样看不到。如需让其他人员获得访问权限，请[将其设为负责人](#designating-group-leaders)。负责人还可以在 [B1.church](../../b1-church/groups/group-details.md#leader-notes) 上小组页面的 **Leader notes（负责人笔记）**部分看到这些笔记，也可以在 B1 Admin 的 [Notes（笔记）](../people/notes.md)页面的 **Groups（小组）**选项卡中看到。
:::

## 向小组成员发送消息

您可以直接从 B1 Admin 与小组的所有成员沟通：

1. 在小组的成员列表中，点击列表上方的 **Send a message to members（向成员发送消息）**图标。
2. 在文本框中输入您的消息（或从 **Templates（模板）**中选择一个）。
3. 点击 **Send（发送）**。

您的消息将发送给小组的所有成员。

## 向小组成员发送电子邮件

您可以向小组的所有成员发送格式化的电子邮件：

1. 从小组详细信息页面，点击页面左侧的 **Email（邮件）**按钮。
2. 发送邮件对话框会打开，显示将收到邮件的成员人数，以及没有登记邮箱地址的成员人数。
3. 可选择从下拉菜单中选择一个**邮件模板**，或从头撰写消息。点击 **Manage Templates（管理模板）**可以创建或编辑模板。
4. 输入**邮件主题**。您可以通过点击字段标签插入合并字段：`{{firstName}}`、`{{lastName}}`、`{{displayName}}`、`{{email}}`、`{{churchName}}`。
5. 使用 HTML 编辑器撰写**邮件正文**。这里同样可以使用相同的合并字段。
6. 点击 **Send（发送）**。
7. 摘要会显示成功发送的邮件数量，以及被跳过的成员数量（未登记邮箱）。

:::tip
为定期的沟通创建可重复使用的邮件模板，例如每周更新、活动通知或代祷请求。模板可以节省时间，并确保消息的一致性。
:::

### 为您的教会开通小组邮件 {#turning-on-group-email-for-your-church}

在 B1 上，所有教会都从同一个地址发送邮件，因此它们共享同一个发送信誉。为了让每个人的邮件都不会进入垃圾邮件文件夹，ChurchApps 团队会在教会首次发送小组邮件之前进行一次审核。

如果您的教会尚未通过审核，发送邮件对话框会显示 **Group email needs a quick review（小组邮件需要快速审核）**，而不是消息编辑器：

1. 点击 **Request review（申请审核）**。ChurchApps 支持团队将收到通知。
2. 对话框会变为 **Review requested（已申请审核）**。您可以关闭它。
3. 小组邮件通常会在一个工作日内开通。此后再次打开发送邮件对话框即可发送您的消息。

在您的教会获准之前，B1 也不会发送[表单跟进邮件](../forms/creating-forms.md#sending-a-follow-up-email)或[工作流](../serving/workflows.md)中的**发送邮件**步骤。

:::info 发送限额
获准后，教会每天最多可以发送 150 封由教会撰写的邮件。随着教会积累良好的发送记录，该限额会逐步提高，最高可达每天 2,000 封。如果近期邮件被退回或被标记为垃圾邮件，小组邮件将暂停，并且对话框会要求您联系支持团队。如果某次发送将超出每日限额，B1 将不会发送该邮件，并会显示错误提示。
:::

## 向小组成员发送短信

一旦您的教会连接了[短信服务提供商](../settings/church-settings.md#texting)，小组页面上的 **Email（邮件）**按钮旁边就会出现 **Text（短信）**按钮（**Text this group（向本小组发短信）**）。

1. 从小组详细信息页面，点击 **Text（短信）**。
2. 对话框会显示将收到短信的成员人数。没有登记手机号码或已选择退订的成员将被跳过。
3. 输入您的消息。若要个性化消息，请点击消息框下方的占位符标签——**First Name（名）**、**Last Name（姓）**、**Display Name（显示名称）**或 **Church Name（教会名称）**——将其插入到光标处。发送短信时，每个占位符都会用收件人自己的信息填充。
4. 点击 **Send（发送）**。

更多详细信息请参见[使用合并字段个性化短信](../settings/church-settings.md#personalizing-texts-with-merge-fields)。

## 导出小组数据

若要将小组成员名单下载为文件：

1. 在小组的成员列表中，点击列表上方的 **Export（导出）**。
2. 包含小组成员信息的 CSV 文件将下载到您的电脑上。

CSV 导出对于将数据导入其他工具或保留离线记录非常有用。如需更多导出选项，请参见[导出数据](../people/exporting-data.md)。

## 打印成员名单

在小组的成员列表中，点击列表上方的 **Print Roll Sheet（打印点名表）**（打印机）图标，然后选择一种版式。页面会在新标签页中打开，并自动弹出浏览器的打印对话框。

- **Attendance Sheet（出勤表）**——一份不带日期的班级名单，附有 **Present（出席）**和 **Absent（缺席）**方框，供教师手动标记。参见[打印点名表](../attendance/recording-attendance.md#printing-a-roll-sheet)。
- **Contact Roster（联系名册）**——小组的联系名单，标注当天日期，顶部显示教会徽标（如果您上传过，则为[网站 > 外观](../website/appearance.md)中的 **Light Background Logo（浅色背景徽标）**），下方是教会名称，以及小组名称。每位成员占一行，包括其 **Name（姓名）**、**Phone（电话）**、**Email（邮箱）**和 **Address（地址）**。负责人会排在最前面并标注 **Leader（负责人）**，其他成员则按姓氏排序。显示的电话为成员的手机号码；如果没有手机，则显示其家庭或工作电话。对于已选择退订的成员，联系信息将留空。

:::warning
联系名册包含成员的个人联系信息。打印件只能分享给小组负责人以及其他需要使用的人员。
:::

## 向小组成员发送推送通知

您可以直接向所有在设备上安装了 B1.church 应用并启用了推送通知的小组成员发送推送通知。

1. 从小组详细信息页面，点击 **Notify（通知）**（位于 **Email（邮件）**和 **Text（短信）**按钮下方——**Text（短信）**按钮会在连接了[短信服务提供商](../settings/church-settings.md#texting)后出现）。
2. 对话框会打开，显示您小组中已启用推送的成员人数。
3. 填写通知详细信息：
   - **Title（标题）***（必填）*——简短的摘要，最多 80 个字符。
   - **Message（消息）***（必填）*——通知正文，最多 240 个字符。
   - **Open link or flyer URL（打开链接或传单网址）***（可选）*——相对应用路径（例如 `/mobile/groups`），或完整的 `https://` 网址，点击通知时将打开该地址。
   - **Image URL（图片网址）***（可选）*——一个 `https://` 网址，指向在支持的设备上随通知一同显示的图片。
4. 实时预览会显示通知在设备上的呈现效果。
5. 点击 **Send Notification（发送通知）**。

:::info
推送通知只会发送给已安装 B1.church PWA 且未关闭推送通知的小组成员。没有注册推送设备或已关闭推送的成员将被计为已跳过，发送摘要会显示成功送达与跳过的人数。
:::

:::tip
发送后，对话框会显示成功加入队列的通知数量。如果大多数成员显示为已跳过，请提醒他们访问您的 B1.church 网站，将其安装为主屏幕应用，并在提示时允许通知。
:::

## 移除成员

若要将某人从小组中移除，请在成员列表中找到其姓名，然后点击其条目旁边的**移除**按钮。

:::info
将某人从小组中移除不会将其从教会通讯录中删除。他们仍会出现在[人员](../people/adding-people.md)部分中，并可随时重新添加到小组。
:::
