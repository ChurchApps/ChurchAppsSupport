# 小组成员

<div class="article-intro">

创建小组后，下一步就是添加成员。在小组详情页面，您可以搜索人员、将其加入小组、指定负责人、发送消息以及导出成员名单。管理小组成员是协调小组团契、委员会和班级的关键。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您至少需要在 B1 Admin 中设置好一个小组。如果您还没有创建小组，请参见[创建小组](creating-groups.md)。
- 您想要添加的人员应当已经存在于[人员](../people/adding-people.md)目录中。如果某人不在其中，您可以通过成员搜索创建他（见下文）。

</div>

## 将成员添加到小组

1. 在[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)中，选择 **People > Groups**，然后点击要管理的小组。
2. 在小组页面的 **Members**（成员）部分，点击 **All members**（全部成员）。（团队和事工会直接打开其成员列表。）
3. 在成员列表下方的 **Add Person**（添加人员）框中，输入您要添加的人员姓名，然后按 **Enter** 或点击搜索图标。
4. 在搜索结果中，点击该人员的姓名或其旁边的添加图标。
5. 该人员现在会出现在小组成员列表中。

:::tip
在您输入任何内容之前，**Add Person** 框会显示一个简短的**最近人员**（Recent people）列表，您可以一键添加：先是您在任何人员搜索中最近选择过的人员（这些记录保存在当前浏览器中），然后是最近添加到 B1 的人员。
:::

完成后，点击带有小组名称的 **Back to**（返回）链接，即可返回小组页面。小组页面会显示小组的 **Members**（成员）、**Sessions**（场次）、**Calendar**（日历）和 **Health**（健康度）摘要，每项都有通往完整视图的链接。如果您是该小组的负责人之一，页面还会显示 **Leader notes**（负责人备注，见下文[负责人备注](#leader-notes)）。如果有表单关联到该小组，还会出现 **Linked forms**（关联表单）部分（见下文[关联表单](#linked-forms)）。

### 添加尚未在 B1 中的人员

如果搜索没有找到任何人，搜索结果会显示 **No records found**（未找到记录），并附带一个 **Add New Person**（添加新人员）链接。点击它，输入该人员的名字和姓氏，可选填称谓、电子邮件和手机号码，然后点击 **Add**。新人员会在您的人员目录中创建，并在同一步骤中加入小组——您无需再次搜索。

## 指定小组负责人 {#designating-group-leaders}

小组负责人拥有特殊权限——他们可以编辑[小组日历](group-calendar.md)、管理活动，并协助协调小组工作。

1. 在小组成员列表中，找到您要设为负责人的人员。
2. 点击其姓名旁边的**星形图标**（**Make Leader**，设为负责人）。
3. 该人员即被指定为小组负责人，并显示 **Leader**（负责人）标记。

要取消负责人身份，请再次点击星形图标（**Remove Leader Access**，取消负责人权限）。

:::info
任何小组成员都可以查看小组日历和活动，但只有负责人可以添加或编辑日历活动。
:::

## 关联表单 {#linked-forms}

当某个独立表单[关联到该小组](../forms/creating-forms.md#linking-a-form-to-a-group)后，小组页面会显示 **Linked forms** 部分，列出每个表单的名称、其为 **Open**（开放）还是 **Closed**（关闭）状态，以及已关联的表单数量。该部分仅对小组负责人以及有权管理表单的人员可见，并且只有在至少关联了一个表单时才会出现。表单管理员可以点击表单名称打开该表单，或点击 **All forms**（全部表单）前往表单页面。

小组负责人可以在 [B1.church](../../b1-church/groups/group-details.md#linked-forms) 的小组页面上阅读和打印这些表单的回答。

## 负责人备注 {#leader-notes}

小组负责人可以为小组保留私人备注——例如跟进事项、代祷需要或牧养关怀事项——这些备注其他成员永远看不到。

**Leader notes** 部分只对该小组的负责人显示在小组页面上。它会显示最新的一条备注、撰写人及时间，以及备注总数。

1. 在小组页面的 **Leader notes** 部分，点击 **All notes**（全部备注）。
2. 在输入框中输入备注并发布。若要设置格式，请选中文字，然后从弹出的菜单中选择 **Bold**（粗体）、**Italic**（斜体）、**Bulleted list**（项目符号列表）或 **Numbered list**（编号列表）（或按 **Ctrl+B** / **Ctrl+I**）。备注会显示撰写人的姓名和照片，以及每条备注的发布日期和时间。
3. 点击带有小组名称的 **Back to** 链接，返回小组页面。

:::info
负责人备注仅对该小组的负责人可见。其他成员看不到，即使拥有完整权限的工作人员和管理员也看不到，除非他们同时也是该小组的负责人。要让他人访问，请[将其设为负责人](#designating-group-leaders)。负责人还可以在 [B1.church](../../b1-church/groups/group-details.md#leader-notes) 小组页面的 **Leader notes** 部分，以及 B1 Admin 中[备注](../people/notes.md)页面的 **Groups** 标签页看到这些备注。
:::

## 向小组成员发送消息

您可以直接从 B1 Admin 向小组的所有成员发送消息：

1. 在小组的成员列表中，点击列表上方的 **Send a message to members**（向成员发送消息）图标。
2. 在文本框中输入消息（或从 **Templates**（模板）中选择一个）。
3. 点击 **Send**。

您的消息将送达小组的所有成员。

## 向小组成员发送电子邮件

您可以向小组的所有成员发送格式化的电子邮件：

1. 从小组详情页面，点击页面左侧的 **Email**（电子邮件）按钮。
2. **Send Email**（发送电子邮件）对话框会打开，显示将收到邮件的成员人数，以及没有电子邮件地址的人数。
3. 可选择从下拉菜单中选择一个**电子邮件模板**，或从头撰写消息。点击 **Manage Templates**（管理模板）可创建或编辑模板。
4. 输入**邮件主题**。点击字段标签可插入合并字段：`{{firstName}}`、`{{lastName}}`、`{{displayName}}`、`{{email}}`、`{{churchName}}`，以及 **Group Name**（小组名称，`{{groupName}}`），后者会被替换为小组名称。
5. 使用 HTML 编辑器撰写**邮件正文**。这里同样可以使用上述合并字段。
6. 点击 **Send**。
7. 发送后会显示摘要，说明成功发送了多少封邮件，以及跳过了多少名成员（因为没有电子邮件地址）。

:::tip
为周更新、活动通知或代祷请求等定期沟通创建可重复使用的电子邮件模板。模板可以节省时间，并确保消息的一致性。
:::

### 为教会开启小组邮件 {#turning-on-group-email-for-your-church}

B1 上的所有教会都从同一个地址发送电子邮件（您教会的名称会显示为发件人名称），因此它们共享同一个发送信誉。为了让每个教会的邮件都不会被归入垃圾邮件，ChurchApps 团队会在教会开始发送小组邮件之前对其进行一次审核。

如果您的教会尚未经过审核，**Send Email** 对话框会显示 **Group email needs a quick review**（小组邮件需要快速审核），而不是消息编辑器：

1. 点击 **Request review**（申请审核）。ChurchApps 支持团队会收到通知。
2. 对话框会变为 **Review requested**（已申请审核）。您可以关闭对话框。
3. 小组邮件通常会在一个工作日内开通。之后再次打开 Send Email 对话框，即可发送您的消息。

在教会获得批准之前，B1 也不会发送[表单跟进邮件](../forms/creating-forms.md#sending-a-follow-up-email)，或[工作流](../serving/workflows.md)中的**发送邮件**步骤。

:::info 发送限制
教会获得批准后，每天最多可以发送 150 封由教会撰写的邮件。随着教会积累良好的发送记录，该上限会逐步提高，最高可达每天 2,000 封。如果近期的邮件被退回或被标记为垃圾邮件，小组邮件会暂停，对话框会要求您联系支持团队。如果某次发送将超出每日上限，B1 不会发送该邮件，并会显示错误提示。
:::

## 向小组成员发送短信 {#texting-group-members}

一旦教会连接了[短信服务提供商](../settings/church-settings.md#texting)，小组页面上 **Email** 按钮旁边就会出现 **Text** 按钮（**Text this group**，向本小组发短信）。

1. 从小组详情页面，点击 **Text**。
2. 对话框会显示将收到短信的成员人数。没有登记手机号码或已退订的成员会被跳过。
3. 可选择从 **Load Template (optional)**（加载模板，可选）中选择一条已保存的短信来填充内容。只有教会设置了[短信模板](../settings/email-templates.md#text-templates)后，此选择器才会出现；有权编辑设置的人员还会看到 **Manage Templates** 链接。
4. 输入或编辑您的消息。若要个性化内容，请点击消息框下方的占位符标签——**First Name**（名字）、**Last Name**（姓氏）、**Display Name**（显示名称）、**Church Name**（教会名称）或 **Group Name**（小组名称）——将其插入光标位置。发送短信时，每个占位符都会被替换为收件人自己的信息；**Group Name** 会变成小组名称。
5. 点击 **Send**。

更多详情请参见[使用合并字段个性化短信](../settings/church-settings.md#personalizing-texts-with-merge-fields)。

## 导出小组数据

要将小组成员名单下载为文件：

1. 在小组的成员列表中，点击列表上方的 **Export**（导出）。
2. 包含小组成员信息的 CSV 文件会下载到您的电脑上。

CSV 导出适用于将数据导入其他工具，或保存离线记录。如需更多导出选项，请参见[导出数据](../people/exporting-data.md)。

## 打印成员名单 {#printing-the-member-list}

在小组的成员列表中，点击列表上方的 **Print Roll Sheet**（打印点名表）（打印机）图标，并选择一种版式。页面会在新标签页中打开，并自动弹出浏览器的打印对话框。

- **Attendance Sheet**（出勤表）——一份不带日期的班级名单，附有 **Present**（出席）和 **Absent**（缺席）方框，供教师手工标记。参见[打印点名表](../attendance/recording-attendance.md#printing-a-roll-sheet)。
- **Contact Roster**（联系名单）——小组的联系人名单，标注当天日期，顶部是教会徽标（如果您上传过[网站 > 外观](../website/appearance.md)中的**浅色背景徽标**），徽标下方是教会名称，再下方是小组名称。每位成员占一行，包含其**姓名**、**电话**、**电子邮件**和**地址**。负责人排在最前并标注 **Leader**，其他成员按姓氏排列。显示的电话为成员的手机号码；若没有手机号码，则显示家庭或工作电话。对于已退订的人员，联系信息将留空。

:::warning
联系名单包含成员的个人联系信息。请仅将打印件分发给小组负责人及其他有需要的人。
:::

## 向小组成员发送推送通知 {#sending-push-notifications-to-group-members}

您可以直接向所有已在设备上安装 B1.church 应用并开启推送通知的小组成员发送推送通知。

1. 从小组详情页面，点击 **Notify**（通知）（位于 **Email** 和 **Text** 按钮下方——**Text** 按钮需要在连接[短信服务提供商](../settings/church-settings.md#texting)后才会出现）。
2. 对话框会打开，显示您小组中开启了推送的成员人数。
3. 填写通知详情：
   - **Title**（标题）*（必填）*——简短的概要，最多 80 个字符。
   - **Message**（消息）*（必填）*——通知正文，最多 240 个字符。
   - **Open link or flyer URL**（打开链接或海报网址）*（可选）*——点击通知时要打开的应用相对路径（例如 `/mobile/groups`）或完整的 `https://` 网址。
   - **Image URL**（图片网址）*（可选）*——一个 `https://` 图片网址，在支持的设备上会与通知一同显示。
4. 实时预览会显示通知在设备上的呈现效果。
5. 在 **When**（何时）下，选择 **Send now**（立即发送），或选择 **Schedule for later**（稍后定时发送），然后选择未来的 **Send at**（发送时间）日期和时刻。
6. 点击 **Send Notification**（发送通知）（或 **Schedule Notification**（定时通知））。

定时通知，以及面向所有使用该应用的成员的全教会通知，都会在 **Mobile** 下的 [推送通知](../settings/push-notifications.md) 页面中管理。在发出之前，您可以在那里编辑、发送或取消它们。

:::info
推送通知只会送达已安装 B1.church PWA 且未关闭推送通知的小组成员。没有登记推送设备或关闭了推送的成员会被计为已跳过，发送摘要会显示有多少人已送达、多少人被跳过。
:::

:::tip
发送后，对话框会显示成功加入发送队列的通知数量。如果大多数成员显示为已跳过，请提醒他们访问 B1.church 网站，将其安装为主屏幕应用，并在提示时允许通知。
:::

## 移除成员

要将某人移出小组，请在成员列表中找到其姓名，然后点击其条目旁边的**移除**按钮。

:::info
将某人移出小组并不会将其从教会通讯录中删除。他/她仍会出现在[人员](../people/adding-people.md)板块中，并可随时重新加入小组。
:::
