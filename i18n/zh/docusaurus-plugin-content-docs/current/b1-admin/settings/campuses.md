# 校园

<div class="article-intro">

如果你的教会在多个地点开会，**校园**可让你追踪每个人和小组属于哪个网站。一旦配置好，校园就会在人员档案、出席设置和人口统计学仪表板中显示为一个选项。多点教会可以在整个 B1 Admin 中按校园进行过滤、搜索和报告。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要**编辑教会设置**权限来管理校园。参见[角色和权限](./roles-permissions.md)。

</div>

## 打开校园设置

在 B1 Admin 中，打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），选择**设置 > 设置**，然后选择**校园**卡。你也可以直接前往 **/settings/campuses**。你将看到所有已配置校园的列表，其中包含其名称、位置和时区。

## 添加校园

1. 单击**添加校园**（如果还没有校园，则点击**+**按钮）。
2. 填写校园详细信息：
   - **名称** *(必需)* -- 在 B1 Admin 中显示的显示名称（例如，"主校园"或"北校园"）。
   - **地址** -- 校园街道地址（用于信息显示；与你教会设置中的主教会地址不同）。
   - **城市 / 州 / 邮编** -- 校园位置。
   - **时区** -- 此校园的 IANA 时区（例如，*America/Chicago*）。当校园在不同时区时很有用。
   - **网站** -- 此校园自己网络形象的可选 URL。
3. 单击**保存**。

## 编辑校园

单击列表中的任何校园行以在右侧的面板中打开其编辑器。更新字段并单击**保存**。

## 删除校园

打开校园进行编辑并单击**删除**。系统会要求你确认。删除校园不会删除分配给它的人员 -- 他们的校园字段会变空。

## 将人员分配到校园

创建校园后，工作人员可以从其档案将一个人分配到校园：

1. 在**人员**中打开一个人的记录。
2. 单击**编辑**。
3. 从**校园**下拉列表中选择校园。
4. 单击**保存**。

你也可以从人员页面批量更新校园。选择多人，使用**批量编辑**，然后一次性为所有人设置校园字段。

## 按校园过滤

一旦校园设置好后，你可以在整个 B1 Admin 中按校园过滤：

- **人员搜索** -- 在高级搜索中添加校园条件，或加载范围限定于校园的[已保存列表](../people/lists.md)。
- **人口统计学** -- 当至少一个人被分配了校园时，[人口统计学仪表板](../people/demographics.md)会显示校园圆环图。
- **出席设置** -- 出席中的每个服务时间都可以绑定到一个校园。

:::tip
单点教会不需要配置校园。所有校园功能都是可选的 -- 如果不存在校园，校园字段和图表根本不会出现。
:::
