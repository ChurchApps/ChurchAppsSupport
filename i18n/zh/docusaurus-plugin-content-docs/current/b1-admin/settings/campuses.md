# 校园

<div class="article-intro">

如果你的教会在多个地点聚会，**校园**让你追踪每个人和小组属于哪个站点。配置后，校园显示为人员资料、出席设置和人口统计仪表板上的选项。多站点教会可以在整个 B1 Admin 中按校园过滤、搜索和报告。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要**编辑教会设置**权限来管理校园。见[角色和权限](./roles-permissions.md)。

</div>

## 打开校园设置

在 B1 Admin 中，打开左上角的**部分菜单**（部分名称和小箭头），选择**设置**，并从设置导航中选择**校园**。你会看到所有配置的校园的列表，带有他们的名称、位置和时区。

## 添加校园

1. 点击**添加校园**（或**+** 按钮，如果还不存在校园）。
2. 填写校园详情：
   - **名称** *(必需)* — 在整个 B1 Admin 中显示的显示名称（例如，"主校园"或"北校园"）。
   - **地址** — 校园街道地址（用于信息显示；与教会设置中的主教会地址不同）。
   - **城市 / 州 / 邮编** — 校园位置。
   - **时区** — 此校园的 IANA 时区（例如，*America/Chicago*）。在校园位于不同时区时很有用。
   - **网站** — 此校园自己网络存在的可选 URL。
3. 点击**保存**。

## 编辑校园

点击列表中的任何校园行以在右侧的面板中打开其编辑器。更新字段并点击**保存**。

## 删除校园

打开校园以编辑并点击**删除**。你将被要求确认。删除校园不会移除分配到它的人 — 他们的校园字段简单地变为空白。

## 将人员分配到校园

创建校园后，工作人员可以从他们的资料将一个人分配到校园：

1. 在**人员**中打开一个人的记录。
2. 点击**编辑**。
3. 从**校园**下拉菜单中选择校园。
4. 点击**保存**。

你也可以从人员页面批量更新校园。选择多个人，使用**批量编辑**，并一次为所有人设置校园字段。

## 按校园过滤

一旦校园被设置，你可以在 B1 Admin 中按校园过滤：

- **人员搜索** — 在高级搜索中添加校园条件，或加载一个[已保存列表](../people/lists.md)作用于校园。
- **人口统计** — [人口统计仪表板](../people/demographics.md)显示至少一个人分配了校园时的校园甜甜圈图表。
- **出席设置** — 出席中的每个服侍时间可以绑定到校园。

:::tip
单一位置的教会不需要配置校园。所有校园功能都是可选的 — 如果不存在校园，校园字段和图表简单地不会出现。
:::
