# 校区

<div class="article-intro">

如果您的教会在多个地点聚会，**校区**功能可以让您追踪每个人和每个小组所属的场地。配置完成后，校区会作为选项出现在人员资料、考勤设置和人口统计仪表板中。多场地教会可以在整个 B1 Admin 中按校区进行筛选、搜索和报告。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要 **编辑教会设置** 权限才能管理校区。参见[角色与权限](./roles-permissions.md)。

</div>

## 打开校区设置

在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），选择 **设置 > 设置**，然后在左侧列表中点击 **校区**，滚动到 **校区** 部分。您也可以直接前往 **/settings/campuses**。您将看到所有已配置校区的列表，包括其名称、位置和时区。

## 添加校区

1. 点击 **添加校区**。
2. 填写校区详细信息：
   - **名称** *（必填）* —— 在整个 B1 Admin 中显示的名称（例如"主校区"或"北校区"）。
   - **地址** —— 校区的街道地址（仅用于信息展示；与教会设置中的主教会地址不同）。
   - **城市 / 州 / 邮编** —— 校区所在位置。
   - **时区** —— 该校区的 IANA 时区（例如 *America/Chicago*）。该校区服务的[签到时间表](../attendance/setup.md#setting-a-check-in-schedule)将按此时区开始和结束。如果设为 **无**，则使用您教会的[时区](./church-settings.md#time-zone)。当校区位于不同时区时，此设置很有用。
   - **网站** —— 可选的网址，指向该校区自己的网络页面。
3. 点击 **保存**。

## 编辑校区

点击列表中的任意校区行，即可在右侧面板中打开其编辑器。更新字段后点击 **保存**。

## 删除校区

打开校区进行编辑，然后点击 **删除**。系统会要求您确认。删除校区不会移除分配到该校区的人员 —— 他们的校区字段会简单地变为空白。

## 将人员分配到校区

创建校区后，工作人员可以从人员资料中为某人分配校区：

1. 在 **人员** 中打开某人的记录。
2. 点击 **编辑**。
3. 从 **校区** 下拉菜单中选择校区。
4. 点击 **保存**。

您还可以在人员页面批量更新校区。选择多人，使用 **批量编辑**，并一次性为所有人设置校区字段。

## 按校区筛选

设置好校区后，您可以在整个 B1 Admin 中按校区进行筛选：

- **人员搜索** —— 在高级搜索中添加校区条件，或加载限定于某个校区的[已保存列表](../people/lists.md)。
- **人口统计** —— 当至少有一人分配了校区时，[人口统计仪表板](../people/demographics.md)会显示校区环形图。
- **考勤设置** —— 考勤中的每个礼拜时间都可以关联到某个校区。

:::tip
单一地点的教会无需配置校区。所有校区功能都是可选的 —— 如果不存在任何校区，校区字段和图表就不会显示。
:::
