# 角色与权限

<div class="article-intro">

角色让您可以控制不同用户在您的 ChurchApps 账户中能够访问的内容。您可以为工作人员、志愿者和其他团队成员创建自定义角色，每个角色拥有各自的访问级别，以确保数据安全。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要拥有域管理员权限，或拥有管理角色的权限
- 准备好团队成员名单以及他们需要访问的区域
- 查看下方可用的权限类别，以便规划您的角色

</div>

## 访问角色

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），并展开**设置**。
2. 点击**角色**。
3. 角色页面会显示您教会目前已定义的所有角色。**成员**列显示每个角色中的用户数量，**（所有人）**行显示**所有用户**。

## 了解角色页面

角色页面分为两个面板：

- **左侧** -- 显示分配给所选角色的成员列表。
- **右侧** -- 显示您可以为该角色配置的权限设置。

点击任意角色名称即可查看和管理其成员及权限。

## 将用户添加到角色

1. 选择您要添加成员的角色。
2. 使用左侧的**搜索框**查找您要添加的人员。
3. 从搜索结果中选择该人员。
4. 该人员将立即被添加到角色中。

## 从角色中移除用户

1. 选择包含您要移除的用户的角色。
2. 在左侧的成员列表中找到该人员。
3. 点击其姓名旁边的**移除按钮**。

## 配置权限

每个角色都可以被授予访问 B1 Admin 特定区域的权限。在**编辑权限**面板中，权限按部分分组，您可以展开这些部分，例如**考勤**、**内容**、**奉献**、**表单与计划**、**课程**、**消息**、**人员与小组**和**任务**。在**筛选权限**框中输入文字，即可仅显示匹配的权限。

勾选或取消勾选某项权限，即可为该角色授予或移除该权限。每个部分标题会显示该角色拥有其中多少项权限，例如 **2 of 5**，并且该数字会随着您勾选和取消勾选而更新。

### 奉献权限

**奉献**部分包含以下权限：

- **查看奉献摘要** -- 查看奉献部分，包括摘要、批次、基金、活动和奉献报表页面。
- **查看奉献** -- 查看单笔奉献，例如批次中的各项奉献。
- **编辑奉献** -- 完全控制：添加、编辑和删除奉献及批次，并[关闭和重新打开批次](../donations/batches.md#closing-and-reopening-a-batch)。
- **录入奉献** -- 添加批次并录入、编辑或删除奉献，但仅限于仍处于开放状态的批次。仅拥有此权限的人员无法删除批次、关闭或重新打开批次，也无法更改通过在线奉献收到的奉献。
- **编辑设置** -- 管理奉献设置。

拥有**录入奉献**但没有**查看奉献摘要**的人员只能看到**奉献**下的**批次**页面。请为点算团队角色同时授予**录入奉献**和**查看奉献**权限，以便他们打开批次并查看自己录入的奉献。详情请参阅[谁可以更改批次](../donations/batches.md#who-can-change-a-batch)。

### 仅人员姓名

**人员与小组**部分包含**查看人员姓名**权限。此权限适用于需要按姓名查找人员的志愿者——例如，在搜索框中选择某人——而无需访问完整目录。仅拥有此权限时，该人员：

- 可以按姓名搜索人员，并查看最近添加的人员列表，但只能看到每个人的姓名、照片和成员身份状态
- 无法通过电子邮件搜索、查看联系方式或打开**人员**目录

将**查看人员姓名**与**查看考勤**或**编辑考勤**搭配，适用于负责班级考勤的志愿者。他们菜单中的**人员**随后会打开**小组**，在那里他们可以打开**所有小组**列表，查看每个班级的成员姓名和课程。拥有**编辑考勤**权限的他们还可以[记录考勤](../attendance/recording-attendance.md)，并通过搜索姓名添加访客。姓名不会链接到人员记录，并且除非志愿者本身是成员，否则机密小组保持隐藏。

B1 Admin 会隐藏角色没有相应权限时无法使用的链接和按钮。例如，**所有小组**列表仅对可以编辑小组、查看小组成员或查看人员的人开放，或对同时拥有**查看人员姓名**和**查看考勤**或**编辑考勤**的人开放（其他人会被送回仪表板）；考勤设置仅在拥有**查看考勤**或**编辑服务**时才会出现；小组的**电子邮件**按钮仅对拥有**编辑小组成员**权限（发送小组电子邮件所需的权限）的人员显示；打印小组名册需要**查看小组成员**权限或是该小组的负责人；删除日历活动需要**编辑内容**权限（或撤回您自己待处理的请求）。

:::warning
**域管理员**拥有对您 ChurchApps 账户所有区域的完全访问权限。他们的权限无法被修改或限制。请仅将此角色分配给您最信任的管理员。
:::

:::tip
创建具体的角色，例如仅具有**奉献**访问权限的"财务主管"、具有**录入奉献**和**查看奉献**权限的"点算团队"，或仅具有**考勤**访问权限的"签到志愿者"。这遵循最小权限原则，有助于保障您的数据安全。有关 ChurchApps 如何保护您信息的更多内容，请参阅[数据安全](./data-security.md)。
:::
