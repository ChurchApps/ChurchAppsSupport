# 角色和权限

<div class="article-intro">

角色让你控制不同的用户在你的 ChurchApps 帐户中可以访问什么。你可以为工作人员、志愿者和其他团队成员创建自定义角色，每个都有自己的访问级别以保护你的数据安全。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要域管理员访问权限或有权限管理角色的角色
- 拥有团队成员和他们需要访问的区域的列表
- 查看下面的可用权限类别以规划你的角色

</div>

## 访问角色

1. 在 B1 Admin 中，打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），然后展开**设置**。
2. 单击**角色**。
3. 角色页面显示为你的教会定义的所有当前角色。

## 理解角色页面

角色页面分为两个面板：

- **左侧** -- 显示分配给所选角色的成员列表。
- **右侧** -- 显示你可以为该角色配置的权限设置。

单击任何角色名称来查看和管理其成员和权限。

## 将用户添加到角色

1. 选择要添加成员的角色。
2. 使用左侧的**搜索字段**找到要添加的人。
3. 从搜索结果中选择该人。
4. 他们将立即被添加到角色中。

## 从角色中删除用户

1. 选择包含要删除的用户的角色。
2. 在左侧的成员列表中找到该人。
3. 单击他们名称旁边的**删除按钮**。

## 配置权限

每个角色都可以被授予对 B1 Admin 特定区域的访问权限。权限按部分组织：

- **人员** -- 访问成员目录和人员记录。
- **捐赠** -- 访问捐赠记录和基金管理。
- **出席** -- 访问出席跟踪和报告。
- **内容** -- 访问网站和内容管理。
- 以及其他可用的区域。

使用角色页面右侧的复选框为每个区域启用或禁用访问。

:::warning
**域管理员**对你的 ChurchApps 帐户的所有区域都有完全访问权限。他们的权限不能被修改或限制。仅为你最信任的管理员使用此角色。
:::

:::tip
创建特定的角色，如"财务主管"，仅具有**捐赠**访问权限，或"检查入场志愿者"，仅具有**出席**访问权限。这遵循最低权限原则并保持你的数据安全。参见[数据安全](./data-security.md)以了解更多关于 ChurchApps 如何保护你的信息。
:::
