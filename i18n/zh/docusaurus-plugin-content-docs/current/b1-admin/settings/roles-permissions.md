# 角色和权限

<div class="article-intro">

角色让您控制不同用户在 ChurchApps 帐户中可以访问的内容。您可以为员工、志愿者和其他团队成员创建自定义角色，每个角色都有自己的访问级别以保持数据安全。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 您需要域管理员访问或具有管理角色权限的角色
- 拥有团队成员列表和他们需要访问的区域
- 查看下面的可用权限类别以规划您的角色

</div>

## 访问角色

1. 在 B1 Admin 中，打开左上角的**部分菜单**（带有小箭头的部分名称）并选择**设置**。
2. 单击设置导航栏中的**角色**。
3. 角色页面显示为教会当前定义的所有角色。

## 理解角色页面

角色页面分为两个面板：

- **左侧** —— 显示分配到选定角色的成员列表。
- **右侧** —— 显示您可以为该角色配置的权限设置。

单击任何角色名称以查看和管理其成员和权限。

## 向角色添加用户

1. 选择您想添加成员的角色。
2. 使用左侧的**搜索字段**找到您想添加的人员。
3. 从搜索结果中选择该人员。
4. 他们将立即被添加到该角色。

## 从角色删除用户

1. 选择包含您想删除的用户的角色。
2. 在左侧的成员列表中找到该人员。
3. 单击他们名称旁边的**删除按钮**。

## 配置权限

每个角色都可以被授予 B1 Admin 特定区域的访问权限。权限按部分组织：

- **人员** —— 访问成员目录和人员记录。
- **献金** —— 访问献金记录和基金管理。
- **出席** —— 访问出席追踪和报告。
- **内容** —— 访问网站和内容管理。
- 以及可用时的其他区域。

使用角色页面右侧的复选框为每个区域启用或禁用访问。

:::warning
**域管理员**对 ChurchApps 帐户的所有区域都有完全访问权限。他们的权限不能被修改或限制。仅对最值得信任的管理员使用此角色。
:::

:::tip
创建特定角色，如"财务主管"仅具有**献金**访问权限，或"签到志愿者"仅具有**出席**访问权限。这遵循最小权限原则并保持数据安全。有关 ChurchApps 如何保护信息的更多信息，请参阅[数据安全](./data-security.md)。
:::
