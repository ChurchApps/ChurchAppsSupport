# 角色和权限

<div class="article-intro">

角色让您控制不同用户在您的 ChurchApps 帐户中可以访问的内容。您可以为员工、志愿者和其他团队成员创建自定义角色，每个角色都有自己的访问级别来保护您的数据。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要域管理员访问权限或有权管理角色的角色
- 准备团队成员列表和他们需要访问的区域
- 查看以下可用权限类别来规划您的角色

</div>

## 访问角色

1. 在 B1 Admin 中，打开左上角的**菜单**（带小箭头的菜单名称）并选择**设置**。
2. 单击标头中的**角色**按钮。
3. 角色页面显示为您的教会定义的所有当前角色。

## 理解角色页面

角色页面分为两个面板：

- **左侧** -- 显示分配给选定角色的成员列表。
- **右侧** -- 显示您可以为该角色配置的权限设置。

单击任何角色名称以查看和管理其成员和权限。

## 将用户添加到角色

1. 选择您想要添加成员的角色。
2. 使用左侧的**搜索字段**找到您想要添加的人。
3. 从搜索结果中选择人员。
4. 他们将立即被添加到角色中。

## 从角色中删除用户

1. 选择包含您想要删除的用户的角色。
2. 在左侧的成员列表中找到该人。
3. 单击其名称旁边的**删除按钮**。

## 配置权限

每个角色可以被授予对 B1 Admin 特定区域的访问权限。权限按部分组织：

- **人员** -- 访问成员目录和人员记录。
- **捐赠** -- 访问捐赠记录和资金管理。
- **出席** -- 访问出席跟踪和报告。
- **内容** -- 访问网站和内容管理。
- 以及其他可用的区域。

使用角色页面右侧的复选框来为每个区域启用或禁用访问。

:::warning
**域管理员**对您的 ChurchApps 帐户的所有区域拥有完全访问权限。他们的权限无法修改或限制。仅为您最受信任的管理员使用此角色。
:::

:::tip
创建特定角色，例如"财务主管"，仅拥有**捐赠**访问权限，或"签到志愿者"，仅拥有**出席**访问权限。这遵循最小权限原则并保持您的数据安全。请参阅[数据安全](./data-security.md)了解更多关于 ChurchApps 如何保护您的信息。
:::
