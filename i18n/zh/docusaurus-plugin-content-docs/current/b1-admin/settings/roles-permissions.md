# 角色与权限

<div class="article-intro">

角色让您能够控制不同用户在您的 ChurchApps 账户中可以访问的内容。您可以为员工、志愿者和其他团队成员创建自定义角色，每个角色拥有各自的访问级别，从而确保您的数据安全。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要拥有域管理员权限，或拥有管理角色的权限
- 准备好团队成员名单以及他们需要访问的区域
- 请先查看下方可用的权限类别，以规划您的角色

</div>

## 访问角色

1. 在 B1 Admin 中，打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），并展开**设置**。
2. 点击**角色**。
3. 角色页面会显示您教会当前已定义的所有角色。

## 了解角色页面

角色页面分为两个面板：

- **左侧** -- 显示分配给所选角色的成员列表。
- **右侧** -- 显示您可以为该角色配置的权限设置。

点击任意角色名称，即可查看和管理其成员及权限。

## 将用户添加到角色

1. 选择您要添加成员的角色。
2. 使用左侧的**搜索框**查找您要添加的人员。
3. 从搜索结果中选择该人员。
4. 该人员会立即被添加到此角色中。

## 将用户从角色中移除

1. 选择包含您要移除的用户的角色。
2. 在左侧的成员列表中找到该人员。
3. 点击其姓名旁边的**移除按钮**。

## 配置权限

每个角色都可以被授予访问 B1 Admin 特定区域的权限。在**编辑权限**面板中，权限被分组到您可以展开的各个部分中，例如**考勤**、**内容**、**捐款**、**表单与计划**、**课程**、**消息**、**人员与小组**和**任务**。在**筛选权限**框中输入文字，即可仅显示与之匹配的权限。

勾选或取消勾选某项权限，即可为该角色授予或移除该权限。

### 捐款权限

**捐款**部分包含以下权限：

- **查看捐款汇总** -- 查看捐款部分，包括汇总、批次、基金、募捐活动和奉献证明页面。
- **查看捐款** -- 查看单独的捐款记录，例如批次中的奉献。
- **编辑捐款** -- 完全控制：添加、编辑和删除捐款及批次，并[关闭和重新打开批次](../donations/batches.md#closing-and-reopening-a-batch)。
- **录入捐款** -- 添加批次并录入、编辑或删除捐款，但仅限于仍处于开放状态的批次。仅拥有此权限的人员无法删除批次、关闭或重新打开批次，也无法更改通过在线奉献收到的捐款。
- **编辑设置** -- 管理捐款设置。

拥有**录入捐款**权限但没有**查看捐款汇总**权限的人员，在**捐款**下只能看到**批次**页面。请为计数团队角色同时授予**录入捐款**和**查看捐款**权限，以便他们能够打开批次并查看自己录入的奉献。详情请参阅[谁可以更改批次](../donations/batches.md#who-can-change-a-batch)。

### 仅查看人员姓名

**人员与小组**部分包含**仅查看人员姓名**权限。此权限适用于需要按姓名查找人员的志愿者，例如在搜索框中选择某人，而无需访问完整通讯录。仅拥有此权限的人员：

- 可以按姓名搜索人员，并查看最近添加的人员列表，但只能看到每个人的姓名、照片和会员状态
- 无法按电子邮件搜索、查看联系方式或打开**人员**通讯录

B1 Admin 会隐藏角色没有相应权限的链接和按钮。例如，**所有小组**列表仅对可以编辑小组、查看小组成员或查看人员的用户开放（其他人会被送回仪表板）；考勤设置仅在拥有**查看考勤**或**编辑服务**权限时才会显示；小组的**电子邮件**按钮仅对拥有**编辑小组成员**权限的人员显示（发送小组电子邮件所需的权限）；打印小组名册需要**查看小组成员**权限，或者您是该小组的负责人；删除日历活动需要**编辑内容**权限（或撤回您自己待处理的请求）。

:::warning
**域管理员**拥有您 ChurchApps 账户中所有区域的完全访问权限。其权限无法被修改或限制。请仅将此角色用于您最信任的管理员。
:::

:::tip
可以创建特定的角色，例如仅拥有**捐款**访问权限的"财务主管"、拥有**录入捐款**和**查看捐款**权限的"计数团队"，或仅拥有**考勤**访问权限的"签到志愿者"。这遵循了最小权限原则，有助于保障您的数据安全。有关 ChurchApps 如何保护您信息的更多内容，请参阅[数据安全](./data-security.md)。
:::
