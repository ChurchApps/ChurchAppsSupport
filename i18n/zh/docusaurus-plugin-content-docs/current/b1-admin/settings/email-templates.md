# 电子邮件模板

<div class="article-intro">

电子邮件模板让您保存可重用的电子邮件内容 -- 欢迎消息、活动提醒、捐赠感谢 -- 以便您（或[工作流](../serving/workflows.md)）可以一键发送它，而不是每次都从头编写。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要访问 B1 Admin 中的设置区域。

</div>

## 访问电子邮件模板

1. 在 B1 Admin 中，打开左上角的**菜单**（带小箭头的菜单名称）并选择**设置**。
2. 单击**电子邮件模板**。
3. 您将看到现有模板的列表，其中包含其主题、类别和最后修改日期。

## 创建模板

1. 单击**新建模板**。
2. 输入**模板名称**来在列表中标识它，并选择一个**类别**（常规、活动、小组、捐赠或欢迎）来帮助组织您的模板。
3. 输入**主题**行。
4. 使用富文本编辑器编写**正文**。
5. 单击**保存**。

## 合并字段

单击主题或正文上方的合并字段芯片将其插入到您的光标处。发送电子邮件时，每个合并字段都被替换为收件人的实际信息：

- `{{firstName}}`、`{{lastName}}`、`{{displayName}}` -- 收件人的名字
- `{{email}}` -- 收件人的电子邮件地址
- `{{churchName}}` -- 您的教会名称

## 预览模板

单击**预览**以了解主题和正文在保存或发送之前如何使用合并字段中填入的示例数据。

## 使用模板

保存的模板在编写电子邮件给人员或小组时可供选择，以及作为[工作流](../serving/workflows.md)中的操作。

## 编辑和删除

单击模板旁边的**编辑**图标来更新它，或单击**删除**图标来永久删除它。
