# 电子邮件模板

<div class="article-intro">

电子邮件模板让您保存可重复使用的电子邮件内容——欢迎消息、事件提醒、献金感谢——所以您（或[工作流](../serving/workflows.md)）可以一键发送它，而不是每次从头开始写。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 您需要访问 B1 Admin 中的设置区域。

</div>

## 访问电子邮件模板

1. 在 B1 Admin 中，打开左上角的**部分菜单**（带有小箭头的部分名称）并选择**设置**。
2. 单击**电子邮件模板**。
3. 您将看到现有模板的列表及其主题、类别和最后修改日期。

## 创建模板

1. 单击**新模板**。
2. 输入**模板名称**以在列表中标识它，并选择**类别**（常规、事件、小组、献金或欢迎）以帮助组织您的模板。
3. 输入**主题**行。
4. 使用富文本编辑器编写**正文**。
5. 单击**保存**。

## 合并字段

单击主题或正文上方的合并字段芯片以在光标位置插入它。发送电子邮件时，每个合并字段都被收件人的实际信息替换：

- `{{firstName}}`、`{{lastName}}`、`{{displayName}}` —— 收件人的名称
- `{{email}}` —— 收件人的电子邮件地址
- `{{churchName}}` —— 您教会的名称

## 预览模板

单击**预览**以查看主题和正文在为合并字段填充示例数据时的外观，然后再保存或发送。

## 使用模板

保存的模板在撰写电子邮件给人员或小组时可供选择，以及作为[工作流](../serving/workflows.md)中的操作。在您的教会可以发送它们之前，ChurchApps 团队需要为组电子邮件批准一次。请参阅[为您的教会启用组电子邮件](../groups/group-members.md#为您的教会打开小组电子邮件)。

## 编辑和删除

单击模板旁边的**编辑**图标来更新它，或单击**删除**图标来永久删除它。
