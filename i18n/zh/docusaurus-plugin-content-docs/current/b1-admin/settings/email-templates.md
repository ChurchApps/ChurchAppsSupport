# 电子邮件模板

<div class="article-intro">

电子邮件模板让你保存可重复使用的电子邮件内容 -- 欢迎消息、事件提醒、捐赠感谢 -- 所以你（或[工作流](../serving/workflows.md)）可以一键发送，而不是每次都从头开始编写。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要在 B1 Admin 中访问设置区域。

</div>

## 访问电子邮件模板

1. 在 B1 Admin 中，打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），然后展开**设置**。
2. 单击**电子邮件模板**。
3. 你会看到现有模板的列表，其中包括主题、类别和最后修改日期。

## 创建模板

1. 单击**新建模板**。
2. 输入**模板名称**以在列表中标识它，并选择一个**类别**（常规、事件、小组、捐赠或欢迎）来帮助组织你的模板。
3. 输入**主题**行。
4. 使用富文本编辑器编写**正文**。
5. 单击**保存**。

## 合并字段

单击主题或正文上方的合并字段芯片将其插入到你的光标处 -- 首先单击文本中你想要该字段的位置，然后单击芯片。你的光标保留在位置，所以你可以在插入的字段之后继续输入。如果你不首先单击进入正文就单击一个正文芯片，该字段会被添加到正文的末尾。发送电子邮件时，每个合并字段都会被替换为收件人的实际信息：

- `{{firstName}}`、`{{lastName}}`、`{{displayName}}` -- 收件人的名称
- `{{email}}` -- 收件人的电子邮件地址
- `{{churchName}}` -- 你的教会的名称

## 预览模板

单击**预览**以查看主题和正文在为合并字段填充样本数据后的外观，然后再保存或发送。

## 使用模板

已保存的模板可在编写发送给人员或小组的电子邮件时选择，也可作为[工作流](../serving/workflows.md)中的操作。在你的教会可以发送它们之前，ChurchApps 团队需要为群组电子邮件批准它一次。参见[为你的教会打开群组电子邮件](../groups/group-members.md#turning-on-group-email-for-your-church)。

## 编辑和删除

单击模板旁边的**编辑**图标来更新它，或**删除**图标来永久删除它。
