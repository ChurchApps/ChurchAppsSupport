# 电子邮件模板

<div class="article-intro">

电子邮件模板让你可以保存可重复使用的电子邮件内容——欢迎信息、活动提醒、捐献感谢信——这样你（或[工作流](../serving/workflows.md)）就可以一键发送，而不必每次都从头编写。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要访问 B1 Admin 中的设置区域。

</div>

## 访问电子邮件模板

1. 前往左侧边栏的**设置**。
2. 点击**电子邮件模板**。
3. 你会看到现有模板的列表，包括主题、类别和最后修改日期。

## 创建模板

1. 点击**新建模板**。
2. 输入**模板名称**以便在列表中识别，并选择一个**类别**（常规、活动、小组、捐献或欢迎）以帮助整理模板。
3. 输入**主题**行。
4. 使用富文本编辑器撰写**正文**。
5. 点击**保存**。

## 合并字段

点击主题或正文上方的合并字段芯片，将其插入到光标位置。发送邮件时，每个合并字段都会被替换为收件人的实际信息：

- `{{firstName}}`、`{{lastName}}`、`{{displayName}}` -- 收件人的姓名
- `{{email}}` -- 收件人的电子邮件地址
- `{{churchName}}` -- 你的教会名称

## 预览模板

点击**预览**，在保存或发送之前查看填入示例数据后主题和正文的效果。

## 使用模板

已保存的模板可以在给个人或小组撰写邮件时选择使用，也可以作为[工作流](../serving/workflows.md)中的一个操作使用。

## 编辑和删除

点击模板旁的**编辑**图标进行更新，或点击**删除**图标将其永久移除。
