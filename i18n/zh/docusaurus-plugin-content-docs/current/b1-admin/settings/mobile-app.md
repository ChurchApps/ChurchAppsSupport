# 移动应用设置

<div class="article-intro">

移动应用设置页面让您配置在您教会的 **B1.church 移动体验（PWA）** 中显示的导航选项卡。您可以控制哪些选项卡可见、它们链接到的内容以及它们的显示方式。

</div>

:::info 本地 B1 Mobile 应用已弃用
此处配置的选项卡通过已替代本地 B1 Mobile 应用的[B1.church 渐进式网络应用（PWA）](/docs/b1-church/getting-started/installing-pwa)提供。与您的教会成员分享您教会的安装页面 -- `https://yourchurchname.b1.church/mobile/install` -- 它会指导他们在他们的设备上安装应用，无需从 App Store 或 Google Play 下载。
:::

<div class="prereqs">
<h4>开始之前</h4>

- 您需要"编辑教会设置"权限。如果您没有访问权限，请参阅[角色和权限](./roles-permissions.md)。
- 首先配置您的[教会设置](./church-settings.md)，包括您的教会名称和品牌形象

</div>

## 访问移动应用设置

1. 在 B1 Admin 中，打开左上角的**菜单**（带小箭头的菜单名称）并选择**设置**。
2. 单击标头中的**移动应用**按钮。
3. 移动应用设置页面显示您当前的应用选项卡。

## 添加新选项卡

1. 单击页面顶部的**添加选项卡**按钮。
2. 填写选项卡详情：
   - **名称** -- 在选项卡上显示的标签（例如 "讲道" 或 "奉献"）。
   - **图标** -- 单击图标选择器以为您的选项卡选择一个图标。您也可以上传自定义图像。
   - **选项卡类型** -- 从《圣经》、直播流、捐赠、网站等选项中选择。
   - **URL** -- 输入选项卡应链接到的网址。
   - **可见性** -- 控制谁可以看到此选项卡（所有人、仅成员等）。
3. 单击**保存选项卡**将其添加到您的应用。

## 编辑现有选项卡

1. 单击**应用选项卡**列表中的任何现有选项卡。
2. 更新选项卡的名称、图标、URL、类型或可见性设置。
3. 单击**保存选项卡**以应用您的更改。

## 重新排序选项卡

您可以更改选项卡在移动应用中显示的顺序。在列表中拖放选项卡以重新排列它们。此页面上显示的顺序与您的成员在应用中看到的顺序相匹配。

:::info
某些选项卡可能会在满足某些条件时自动显示 -- 例如，当流处于活动状态时，直播流选项卡可能会显示。手动添加的选项卡让您可以完全控制您的成员在所有时间看到的内容。
:::

:::tip
保持您的选项卡数量易于管理。三到五个选项卡对大多数教会都有效。太多选项卡会使您的成员的导航变得混乱。
:::

## 成员目录和消息设置

相同移动部分中的 **B1 Mobile** 选项卡持有在 B1.church 体验中管理成员目录和私人消息的设置：

- **目录批准组** -- 审查成员目录更新后再应用的小组。
- **显示在目录中** -- 谁可以出现在成员目录中（仅员工到所有人）。
- **可见性偏好** -- 成员地址、电话号码和电子邮件地址的默认可见性。
- **私人消息的最低年龄** -- 儿童安全控制。当任一方根据其出生日期在此年龄以下时，B1 不会打开**新的**私人消息对话（在没有出生日期的情况下，家庭角色用作后备）。年龄以下的人在目录中完全可见 -- 仅直接消息对于所有人包括员工在**两个方向**都被阻止。小组对话和给孩子的父母发消息仍然有效。选项为关闭、13、16 或 18；默认为**18**。现有对话不受影响。

:::tip
因为最低年龄检查依赖于出生日期，请确保您的教会中的儿童的出生日期被填写。此设置属于与[签到安全控制](../attendance/checkin-safety.md)相同的儿童安全家族。
:::

## 这些选项卡出现在哪里

您在此处配置的选项卡在您的成员从 `https://yourchurchname.b1.church` 上的任何页面安装的 **B1.church PWA** 中显示。您在此页面上所做的更改会在成员下次打开应用时反映。（选项卡也由已弃用的[B1 Mobile 本地应用](/docs/b1-mobile/)为仍在运行它的任何成员呈现，但该应用已弃用，不再更新。）
