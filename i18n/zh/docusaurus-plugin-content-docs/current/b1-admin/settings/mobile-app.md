# 移动应用设置

<div class="article-intro">

移动应用设置页面让您可以配置在**B1.church 移动体验(PWA)**中为您的教会成员显示的导航标签。您可以控制哪些标签可见、它们链接到哪里,以及它们的显示方式。

</div>

:::info 原生 B1 Mobile 应用已被弃用
此处配置的标签通过 [B1.church 渐进式网页应用(PWA)](/docs/b1-church/getting-started/installing-pwa) 提供,该应用已取代原生 B1 Mobile 应用。请将您教会的安装页面——`https://yourchurchname.b1.church/mobile/install`——分享给成员;它会引导他们在自己的设备上安装该应用,无需通过 App Store 或 Google Play 下载。
:::

<div class="prereqs">
<h4>开始之前</h4>

- 您需要拥有"编辑教会设置"权限。如果您没有访问权限,请参阅[角色与权限](./roles-permissions.md)。
- 请先配置好您的[教会设置](./church-settings.md),包括教会名称和品牌形象

</div>

## 访问移动应用设置

1. 导航到左侧边栏的**设置**页面。
2. 点击页头中的**移动应用**按钮。
3. 移动应用设置页面会显示您当前的应用标签。

## 添加新标签

1. 点击页面顶部的**添加标签**按钮。
2. 填写标签详情:
   - **名称**——标签上显示的标题(例如"讲道"或"奉献")。
   - **图标**——点击图标选择器为您的标签选择图标。您也可以上传自定义图片。
   - **标签类型**——从圣经、直播、捐赠、网站等选项中选择。
   - **URL**——输入该标签应链接到的网址。
   - **可见性**——控制谁可以看到此标签(所有人、仅成员等)。
3. 点击**保存标签**将其添加到您的应用中。

## 编辑现有标签

1. 在**应用标签**列表中点击任意现有标签。
2. 更新该标签的名称、图标、URL、类型或可见性设置。
3. 点击**保存标签**以应用您的更改。

## 重新排序标签

您可以更改标签在移动应用中出现的顺序。在列表中拖放标签即可重新排列。此页面上显示的顺序即为成员在应用中看到的顺序。

:::info
某些标签在满足特定条件时可能会自动出现——例如,当有直播正在进行时,直播标签可能会自动显示。手动添加的标签让您可以完全掌控成员始终能看到的内容。
:::

:::tip
请保持标签数量适中。三到五个标签对大多数教会来说效果最佳。标签过多会让成员的导航体验变得混乱。
:::

## 这些标签会显示在哪里

您在此处配置的标签会显示在成员从 `https://yourchurchname.b1.church` 的任意页面安装的 **B1.church PWA** 中。您在此页面所做的更改会在成员下次打开应用时生效。(这些标签也会在旧版 [B1 Mobile 原生应用](/docs/b1-mobile/) 中,为仍在使用该应用的成员呈现,但该应用已被弃用,不再更新。)
