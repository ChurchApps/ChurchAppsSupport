# 移动应用设置

<div class="article-intro">

移动应用设置页面让你配置在**B1.church 移动体验 (PWA)**中为你的教会成员出现的导航选项卡。你控制哪些选项卡可见、它们链接到什么以及它们的显示方式。

</div>

:::info 本机 B1 移动应用已弃用
此处配置的选项卡通过[B1.church Progressive Web App (PWA)](/docs/b1-church/getting-started/installing-pwa)交付，已取代本机 B1 移动应用。与你的成员分享你的教会的安装页面 -- `https://yourchurchname.b1.church/mobile/install` -- 它会在他们的设备上引导他们安装应用，不需要从应用商店或 Google Play 下载。
:::

<div class="prereqs">
<h4>开始前</h4>

- 你需要"编辑教会设置"权限。如果你没有访问权限，参见[角色和权限](./roles-permissions.md)。
- 首先配置你的[教会设置](./church-settings.md)，包括你的教会名称和品牌

</div>

## 访问导航设置

1. 在 B1 Admin 中，打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），然后展开**移动**。
2. 单击**导航** (`/mobile/navigation`)。
3. 导航页面显示你当前的应用选项卡。

## 添加新选项卡

1. 单击页面顶部的**添加选项卡**按钮。
2. 填写选项卡详细信息：
   - **名称** -- 在选项卡上出现的标签（例如，"讲道"或"捐赠"）。
   - **图标** -- 单击图标选择器选择选项卡的图标。你也可以上传自定义图像。
   - **选项卡类型** -- 从圣经、直播、捐赠、网站等选项中选择。
   - **URL** -- 输入选项卡应链接到的网址。
   - **可见性** -- 控制谁可以看到此选项卡（所有人、仅成员等）。
3. 单击**保存选项卡**将其添加到你的应用。

## 编辑现有选项卡

1. 在**应用选项卡**列表中单击任何现有选项卡。
2. 更新选项卡的名称、图标、URL、类型或可见性设置。
3. 单击**保存选项卡**以应用你的更改。

## 重新排列选项卡

你可以更改选项卡在移动应用中出现的顺序。在列表中拖放选项卡来重新排列它们。此页面上显示的顺序与你的成员在应用中看到的顺序相匹配。

:::info
某些选项卡可能在满足某些条件时自动出现 -- 例如，当流是活跃时，直播选项卡可能会显示。手动添加的选项卡让你完全控制你的成员何时看到的内容。
:::

:::tip
保持选项卡数量可控。三到五个选项卡适用于大多数教会。太多选项卡会让你的成员的导航变得混乱。
:::

## 成员目录和消息设置

同一移动部分中的**成员门户**项目包含管理 B1.church 体验中成员目录和私人消息的设置：

- **目录批准小组** -- 在成员目录更新以及[帐户删除请求](../profile/account-deletion.md)生效之前审查它们的小组。
- **在目录中显示** -- 谁可以在成员目录中出现（仅工作人员到所有人）。
- **可见性偏好** -- 为还没有选择自己设置的成员设置教会范围的默认值。**地址**、**电话号码**和**电子邮件**每个都有自己的下拉列表，在配置可见性的地方有相同的五个级别可用：
  - **所有人** -- 对任何人可见，包括匿名访客
  - **成员** -- 仅对拥有成员或工作人员记录的人可见
  - **仅小组** -- 仅对与此人共享小组的人可见
  - **我的小组领导者和工作人员** -- 仅对此人所属小组的领导者和工作人员可见
  - **仅工作人员** -- 仅对拥有人员 > 查看权限的工作人员以及该人自己可见

  成员可以从 B1.church PWA 中他们档案的**隐私**选项卡为他们自己的记录覆盖这些默认值 -- 参见[编辑你的档案](/docs/b1-church/getting-started/me-page)。
- **私人消息的最低年龄** -- 儿童安全控制。当任一方基于其出生日期（当档案上没有出生日期时使用家庭角色作为后备）未满此年龄时，B1 将不会打开**新**的私人消息对话。未满年龄的人在目录中仍然完全可见 -- 仅直接消息被阻止，在**两个方向**，对包括工作人员的所有人。小组对话和向儿童的父母发送消息仍然有效。选项是关闭、13、16 或 18；默认是**18**。现有对话不受影响。

:::tip
因为最低年龄检查依赖于出生日期，请确保填写你的教会中儿童的出生日期。此设置属于同一儿童安全系列，如同[检查入场安全控制](../attendance/checkin-safety.md)。
:::

### 主屏幕登录提示

在登录前打开应用的[主屏幕](/docs/b1-church/getting-started/navigating#home)的访客看到一个简短的提示 -- 默认情况下，*"登录以查看你的小组、捐赠等。"* -- 旁边是**登录**按钮。同一成员门户页面 (`/mobile/b1-mobile`) 上的**主屏幕登录提示**设置让你更改它：

- **在应用主屏幕上显示登录提示** -- 关闭此选项以从主屏幕隐藏提示和**登录**按钮。访客仍然可以从应用菜单登录。
- **登录提示文本** -- 用你自己的消息（最多 150 个字符）替换默认措辞。留空以使用默认值。当提示关闭时，此框被禁用。

单击**保存**来应用。保存会刷新应用的缓存设置，所以更改会在主屏幕下次加载时显示。

## 这些选项卡出现的地方

你在这里配置的选项卡显示在**B1.church PWA**中，你的成员从 `https://yourchurchname.b1.church` 上的任何页面安装。你在此页面上进行的更改会在成员下次打开应用时反映。（选项卡也由旧的[B1 移动本机应用](/docs/b1-mobile/)呈现，用于任何仍然运行它的成员，但该应用已弃用，不再更新。）
