# 自定义字段

<div class="article-intro">

**自定义字段**让您可以在每个人员记录上跟踪您自己的信息——例如 B1 没有内置字段的内容，如背景调查到期日、T 恤尺码或洗礼班状态。您只需在设置中定义一次字段，然后在每位人员的个人资料中填写其值，并基于该字段进行搜索或建立列表。这取代了过去为存储单项自定义数据而创建人员表单的变通做法。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要拥有 **People** 的编辑权限才能定义字段并填写值，并且需要有权访问 **Settings** 区域。拥有人员查看权限的人可以看到这些值。参见[角色与权限](./roles-permissions.md)。
- 在开始之前，请确定您想要跟踪的内容，并选择最合适的类型（文本、数字、日期、是/否或下拉选项）。

## 打开自定义字段

在 B1 Admin 中，打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），选择 **Settings > Settings**，然后点击左侧列表中的 **Custom Fields**，滚动到 **Custom Fields** 部分。您也可以直接访问 **/settings/custom-fields**。页面会列出您已定义的每个字段，显示其**名称**和**字段类型**。如果您还没有创建任何字段，面板会显示 *"No custom fields have been added yet."*（尚未添加任何自定义字段。）

## 称谓

自定义字段部分顶部的 **Titles**（称谓）卡片列出了在 B1 Admin 以及 B1 应用（个人资料编辑器和访客注册表单）中添加或编辑人员时，**Title** 框中提供的称谓。默认列表为 Mr、Mrs、Miss、Ms、Dr、Prof、Rev 和 Pastor。

1. 在 **New title**（新称谓）中输入一个称谓（最多 10 个字符），例如 *Deacon*（执事）或 *Elder*（长老），然后点击 **Add Title**（添加称谓）。
2. 若要从列表中移除某个称谓，请点击其标签上的 **×**。
3. 点击 **Save**。

:::tip
**Title** 框仍然允许输入，因此工作人员和会员可以输入列表中没有的称谓。从列表中移除某个称谓，并不会更改已经使用该称谓的人员。
:::

## 添加字段

1. 点击 **Add Field**（添加字段）。
2. 在右侧打开的编辑器中，输入**名称**——这是工作人员在人员个人资料和搜索中看到的标签（例如 *Background check expires*（背景调查到期））。
3. 选择**字段类型**：
   - **Textbox**（文本框）——自由格式的短文本。
   - **Whole Number**（整数）——不带小数的数字（例如数量）。
   - **Decimal**（小数）——可以包含小数的数字。
   - **Date**（日期）——日历日期。
   - **Yes/No**（是/否）——简单的是或否答案。
   - **Multiple Choice**（多项选择）——下拉选项列表。选择此类型后，会出现 **choices editor**（选项编辑器），让您添加人们可以选择的每个选项。
4. 点击 **Save**。

该字段现在可以在每位人员的个人资料中使用。

:::info
自定义字段的类型与[表单问题](../forms/creating-forms.md)所用的类型相同，因此各处的值表现一致。
:::

## 编辑字段

点击列表中的任意字段行，即可在编辑器中重新打开它。更改名称、类型或选项后，点击 **Save**。

:::warning
如果某个字段已经有数据，再更改其**字段类型**（例如从文本框改为日期），之前录入的值可能会保持与新类型不匹配的格式。工作人员开始填写该字段后，请谨慎更改类型。
:::

## 删除字段

打开字段进行编辑，然后点击 **Delete**（删除）。系统会要求您确认：*"Are you sure you wish to delete this custom field? Its stored values will also be removed."*（您确定要删除此自定义字段吗？其已保存的值也将被一并删除。）删除字段会永久移除该字段**以及所有人员上为其保存的每个值**——此操作无法撤销。

## 为人员填写值

当至少存在一个自定义字段后，它的值会与每位人员记录上的内置详细信息并排显示——您可以在个人资料的左侧，与其联系方式一同查看这些值，并在编辑人员其他信息的同一表单中进行编辑。在您定义第一个字段之前，不会出现任何额外内容。

1. 在 **People** 中打开某人的记录。
2. 点击个人资料左侧、联系方式下方的 **Edit** 按钮。
3. 滚动到编辑表单底部的 **Custom Fields**（自定义字段）区域，为每个字段填写值。每个字段都会显示与其类型相匹配的输入控件——日期字段为日期选择器，是/否字段为下拉菜单，多项选择字段为下拉列表，依此类推。
4. 点击 **Save**。您的自定义字段值会与该人员的其他信息一同保存。

回到个人资料，任何已有值的字段都会在人员联系方式下方以 *字段名称：值* 的形式显示（是/否的答案显示为 *Yes* 或 *No*，多项选择则显示选项的标签）。留空的字段会被隐藏。若要删除某个值，请编辑该人员，清空该字段，然后保存——空值会从记录中删除，而不会被存储为空白。

:::tip
典型的用途是志愿者安全管理：创建一个名为 *Background check expires*（背景调查到期）的**日期**字段，为每位志愿者录入日期，然后建立一个[已保存列表](../people/lists.md)，标记出日期已过的人员。
:::

## 搜索并基于自定义字段建立列表

自定义字段完全支持搜索：

1. 在 **People** 页面，打开[高级搜索](../people/searching-people.md)。
2. 展开 **Custom Fields** 类别。
3. 勾选您要筛选的字段，选择运算符，并输入一个值。可用的运算符与字段类型相匹配：
   - **Textbox**——包含、等于、以……开头、以……结尾。
   - **Whole Number / Decimal**——等于、大于、大于或等于、小于、小于或等于。
   - **Date**——等于、晚于（大于）、早于（小于）。
   - **Yes/No**——等于 Yes 或 No。
   - **Multiple Choice**——等于或包含其中一个选项。

您可以将任何自定义字段搜索保存为[列表](../people/lists.md)。列表是实时查询，因此基于 *Background check expires is before today*（背景调查到期日早于今天）建立的列表，每次打开时都会重新检查每位人员——无需手动维护。

## 将自定义字段显示为列

若要一次查看所有人的某个字段值，可以将其添加为 **People** 页面上的一列。将 **View as** 切换为 **Table**（表格），点击页眉中的 **Select columns**（选择列）图标，切换到 **Custom**（自定义）标签页，然后勾选该字段。每位人员的值都会显示在内置列旁边自己的列中。参见[将自定义字段显示为列](../people/searching-people.md#showing-custom-fields-as-columns)。

## 合并时的处理

当您[合并两条人员记录](../people/adding-people.md)时，自定义字段的值会自动保留。保留下来的人员会保留其自己的值；对于仅被删除的人员拥有值的字段，该值会被复制过来，因此不会丢失任何内容。
