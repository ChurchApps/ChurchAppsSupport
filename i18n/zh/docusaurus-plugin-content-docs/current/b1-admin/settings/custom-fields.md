# 自定义字段

<div class="article-intro">

**自定义字段**让您在每个人员记录上跟踪自己的信息——例如 B1 没有内置字段的内容，如背景调查到期日、T恤尺码或洗礼班状态。您只需在设置中定义一次字段，然后在每位成员的资料中填写数值，并可根据该字段进行搜索或建立列表。这取代了以前为存储单项自定义数据而创建人员表单的变通做法。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要拥有**人员**的编辑权限才能定义字段和填写数值，并且需要有权访问**设置**区域。拥有人员查看权限的人可以查看这些数值。请参阅[角色与权限](./roles-permissions.md)。
- 在开始之前，请确定您要跟踪的内容以及最合适的类型（文本、数字、日期、是/否回答或下拉列表）。

## 打开自定义字段

在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），选择 **Settings > Settings**，然后点击左侧列表中的**自定义字段**，即可滚动到**自定义字段**部分。您也可以直接访问 **/settings/custom-fields**。您将看到所有已定义字段的列表，显示其**名称**和**字段类型**。如果您还没有创建任何字段，面板会显示*"尚未添加自定义字段。"*

## 添加字段

1. 点击**添加字段**。
2. 在右侧打开的编辑器中，输入**名称**——这是工作人员在人员资料和搜索中看到的标签（例如，*背景调查到期*）。
3. 选择**字段类型**：
   - **文本框** — 自由格式的短文本。
   - **整数** — 不含小数的数字（例如计数）。
   - **小数** — 可包含小数的数字。
   - **日期** — 日历日期。
   - **是/否** — 简单的是或否回答。
   - **多项选择** — 下拉列表。选择此类型时，会出现**选项编辑器**，供您添加人们可以选择的每个选项。
4. 点击**保存**。

此字段现在可在每位成员的资料中使用。

:::info
字段类型与[表单问题](../forms/creating-forms.md)使用的类型相同，因此在整个 B1 中的数值表现保持一致。
:::

## 编辑字段

点击列表中的任意字段行，即可在编辑器中重新打开。更改名称、类型或选项，然后点击**保存**。

:::warning
更改已有数值的字段的**字段类型**（例如从文本框改为日期）可能会使之前输入的数值与新类型的格式不匹配。在工作人员已开始填写该字段后，请谨慎更改类型。
:::

## 删除字段

打开字段进行编辑，然后点击**删除**。系统会要求您确认：*"您确定要删除此自定义字段吗？其存储的数值也将一并删除。"* 删除字段会永久移除该字段以及**所有成员上为其存储的每个数值**，且此操作无法撤销。

## 在成员上填写数值

一旦至少存在一个自定义字段，其数值就会与每位成员记录上的内置信息并列显示——您可以在资料左侧的联系信息旁查看，并在您用于编辑成员其他信息的同一表单中进行编辑。在您定义第一个字段之前，不会出现任何额外内容。

1. 在**人员**中打开成员的记录。
2. 点击资料左侧、成员联系信息下方的**编辑**按钮。
3. 滚动到编辑表单底部的**自定义字段**区域，并为每个字段填写数值。每个字段都会显示与其类型匹配的输入控件——日期字段显示日期选择器，是/否字段显示是/否下拉菜单，多项选择显示下拉列表，依此类推。
4. 点击**保存**。您的自定义字段数值将与该成员的其他信息一同保存。

回到资料页面，任何有数值的字段现在都会以 *字段名称: 数值* 的形式显示在成员联系信息下方（是/否回答显示为*是*或*否*，多项选择显示选项的标签）。留空的字段会被直接隐藏。要删除某个数值，请编辑该成员，清空该字段并保存——空值会从记录中删除，而不是存储为空白。

:::tip
经典用例是志愿者安全：创建一个名为*背景调查到期*的**日期**字段，为每位志愿者记录其日期，然后建立一个[已保存列表](../people/lists.md)，标记出日期已过的人员。
:::

## 基于自定义字段进行搜索和建立列表

自定义字段完全支持搜索：

1. 在**人员**页面，打开[高级搜索](../people/searching-people.md)。
2. 展开**自定义字段**类别。
3. 勾选您要筛选的字段，选择运算符，并输入数值。提供的运算符与字段类型相匹配：
   - **文本框** — 包含、等于、开头为、结尾为。
   - **整数 / 小数** — 等于、大于、大于或等于、小于、小于或等于。
   - **日期** — 等于、晚于（大于）、早于（小于）。
   - **是/否** — 等于是或否。
   - **多项选择** — 等于或包含其中一个选项。

您可以将任何自定义字段搜索保存为[列表](../people/lists.md)。列表是实时查询，因此基于*背景调查到期早于今天*建立的列表会在您每次打开时重新检查每位成员——无需手动维护。

## 将自定义字段显示为列

要一次查看所有人的字段数值，可将其添加为**人员**页面上的一列。将**查看方式**切换为**表格**，点击页眉中的**选择列**图标，切换到**自定义**选项卡，然后勾选该字段。每位成员的数值会显示在其自己的列中，与内置列并列。请参阅[将自定义字段显示为列](../people/searching-people.md#showing-custom-fields-as-columns)。

## 合并时的处理

当您[合并两个成员记录](../people/adding-people.md)时，自定义字段的数值会自动保留。您保留的成员保留其自身的数值；对于只有被移除成员有数值的字段，该数值会被复制过来，因此不会丢失任何信息。
