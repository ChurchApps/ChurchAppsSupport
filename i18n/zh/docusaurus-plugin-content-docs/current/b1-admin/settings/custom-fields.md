# 自定义字段

<div class="article-intro">

**自定义字段**让你可以在每个人员记录上跟踪自己的信息——那些 B1 没有内置字段的内容，例如背景调查到期日期、T 恤尺码或洗礼班状态。你在设置中定义一次字段，然后在每个人的资料上填写值，并可以据此搜索或构建名单。这取代了以前为了存储单一自定义数据而创建人员表单的变通做法。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要**人员**编辑权限才能定义字段和填写值，并需要访问**设置**区域。拥有人员查看权限的任何人都可以看到这些值。参见[角色与权限](./roles-permissions.md)。
- 在开始之前，先确定你想跟踪什么内容以及哪种类型最合适（文本、数字、日期、是/否答案或选择列表）。

</div>

## 打开自定义字段

在 B1 Admin 中，前往左侧边栏的**设置**并选择**自定义字段**卡片。你也可以直接访问 **/settings/custom-fields**。你会看到你定义过的每个字段的列表，显示其**名称**和**字段类型**。如果尚未创建任何字段，面板会显示"*尚未添加任何自定义字段。*"

## 添加字段

1. 点击**添加字段**。
2. 在右侧打开的编辑器中，输入**名称**——这是工作人员在人员资料和搜索中看到的标签（例如*背景调查到期日*）。
3. 选择**字段类型**：
   - **文本框** — 自由格式的短文本。
   - **整数** — 不含小数的数字（例如计数）。
   - **小数** — 可包含小数的数字。
   - **日期** — 日历日期。
   - **是/否** — 简单的是或否答案。
   - **多选** — 选择列表。选择此类型时，会出现一个**选项编辑器**，供你添加人们可以选择的每个选项。
4. 点击**保存**。

该字段现已在每个人的资料上可用。

:::info
字段类型与[表单问题](../forms/creating-forms.md)使用的是同一套类型，因此各处的值表现一致。
:::

## 编辑字段

点击列表中的任意字段行即可在编辑器中重新打开它。修改名称、类型或选项，然后点击**保存**。

:::warning
更改已经存有值的字段的**字段类型**（例如从文本框改为日期）可能会导致此前输入的值变成与新类型不匹配的格式。工作人员已开始填写该字段后，请谨慎更改类型。
:::

## 删除字段

打开字段进行编辑并点击**删除**。系统会要求你确认："*你确定要删除此自定义字段吗？其存储的值也将被删除。*"删除字段会永久移除该字段**以及所有人员存储的相关值**——此操作无法撤销。

## 为某人填写值

一旦存在至少一个自定义字段，其值就会与每个人记录上的内置详情一起显示——你在**个人详情**中查看它们，并在用于该人其余信息的同一表单上编辑。在你定义第一个字段之前，不会出现任何额外内容。

1. 在**人员**中打开某人的记录。
2. 在**个人详情**部分，点击**编辑**（铅笔）按钮。
3. 滚动到编辑表单底部的**自定义字段**区域，为每个字段填写值。每个字段会显示与其类型匹配的输入控件——日期字段是日期选择器，是/否字段是是/否下拉菜单，多选字段是选择列表，依此类推。
4. 点击**保存**。你的自定义字段值会与此人的其余详情一起保存。

回到资料页面，任何有值的字段现在都会显示在**个人详情**部分（是/否答案读作*是*或*否*，多选显示所选选项的标签）。留空的字段则被隐藏。要移除某个值，编辑此人、清空该字段并保存——空值会从记录中删除，而不是以空白形式存储。

:::tip
经典的使用场景是志愿者安全管理：创建一个名为*背景调查到期日*的**日期**字段，记录每位志愿者的日期，然后构建一个[已保存名单](../people/lists.md)，标记出日期已过的所有人。
:::

## 在自定义字段上搜索和构建名单

自定义字段完全可搜索：

1. 在**人员**页面上，打开[高级搜索](../people/searching-people.md)。
2. 展开**自定义字段**类别。
3. 勾选要筛选的字段，选择一个运算符，然后输入一个值。可用的运算符与字段类型相匹配：
   - **文本框** — 包含、等于、开头是、结尾是。
   - **整数/小数** — 等于、大于、大于等于、小于、小于等于。
   - **日期** — 等于、晚于（大于）、早于（小于）。
   - **是/否** — 等于是或否。
   - **多选** — 等于或包含某个选项。

将任何自定义字段搜索保存为[名单](../people/lists.md)。名单是实时查询，因此基于*背景调查到期日早于今天*构建的名单每次打开都会重新检查所有人——无需手动维护。

## 合并时会发生什么

当你[合并两个人员记录](../people/adding-people.md)时，自定义字段的值会自动带过来。你保留的那个人会保留自己的值；对于只有被移除的人有值的字段，该值会被复制过来，确保不会丢失任何信息。
