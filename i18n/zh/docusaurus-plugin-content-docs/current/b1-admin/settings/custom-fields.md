# 自定义字段

<div class="article-intro">

**自定义字段**让你在每条人员记录上追踪你自己的信息 -- B1 没有内置字段的东西，比如背景检查过期日期、T 恤尺码或洗礼课程状态。你在设置中定义一次字段，然后在每个人的档案上填入一个值，并在其上搜索或构建列表。这取代了创建人员表单来存储单个自定义数据的较旧的解决方法。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要**人员**编辑权限来定义字段并填充值，并可以访问**设置**区域。任何拥有人员查看权限的人都可以看到这些值。参见[角色和权限](./roles-permissions.md)。
- 在你开始之前，决定你想追踪什么以及哪种类型最适合（文本、数字、日期、是/否答案或选项列表）。

</div>

## 打开自定义字段

在 B1 Admin 中，打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），选择**设置 > 设置**，然后选择**自定义字段**卡。你也可以直接前往 **/settings/custom-fields**。你会看到你定义的每个字段的列表，显示其**名称**和**字段类型**。如果你还没有创建任何字段，面板会显示*"还没有添加自定义字段。"*

## 添加字段

1. 单击**添加字段**。
2. 在右侧打开的编辑器中，输入**名称** -- 这是工作人员将在人员档案和搜索中看到的标签（例如，*背景检查过期*）。
3. 选择**字段类型**：
   - **文本框** -- 自由格式的短文本。
   - **整数** -- 没有小数的数字（例如，计数）。
   - **小数** -- 可以包含小数的数字。
   - **日期** -- 日历日期。
   - **是/否** -- 简单的是或否答案。
   - **多个选择** -- 选项列表。当你选择这种类型时，会出现**选择编辑器**，以便你可以添加人们可以从中选择的每个选项。
4. 单击**保存**。

该字段现在在每个人的档案上可用。

:::info
字段类型与[表单问题](../forms/creating-forms.md)使用的集合相同，因此值在 B1 中的行为是一致的。
:::

## 编辑字段

单击列表中的任何字段行来重新在编辑器中打开它。更改名称、类型或选择并单击**保存**。

:::warning
更改已经有值的字段的**字段类型**（例如，从文本框到日期）可能会使以前输入的值保留在不再与新类型匹配的格式中。一旦工作人员开始填写该字段，请小心更改类型。
:::

## 删除字段

打开字段进行编辑并单击**删除**。系统会要求你确认：*"你确定要删除此自定义字段吗?它的存储值也将被删除。"* 删除字段会永久删除它**以及为其存储的每个值**在所有人中 -- 这无法撤销。

## 在一个人上填充值

一旦至少存在一个自定义字段，其值就会在每条人员记录上与内置详细信息一起出现 -- 你在**个人详细信息**中查看它们，并在你使用的同一表单上编辑它们来编辑其余人员的信息。在你定义了第一个字段之前，不会出现任何额外的东西。

1. 在**人员**中打开一个人的记录。
2. 在**个人详细信息**部分中，单击**编辑**（铅笔）按钮。
3. 滚动到编辑表单底部的**自定义字段**区域，并为每个字段填充值。每个字段都显示与其类型匹配的输入 -- 日期字段的日期选择器、是/否字段的是/否下拉列表、多个选择的选项列表等。
4. 单击**保存**。你的自定义字段值与其余人员的详细信息一起保存。

回到档案上，任何有值的字段现在都会在**个人详细信息**部分中显示（是/否答案读作*是*或*否*，多个选择显示选项的标签）。留空的字段只是被隐藏了。要删除值，请编辑该人，清除字段，然后保存 -- 空值从记录中删除，而不是存储为空白。

:::tip
经典的用例是志愿者安全：创建一个**日期**字段，称为*背景检查过期*，记录每个志愿者的日期，然后构建一个[已保存列表](../people/lists.md)，标记任何日期已过的人。
:::

## 搜索并在自定义字段上构建列表

自定义字段是完全可搜索的：

1. 在**人员**页面上，打开[高级搜索](../people/searching-people.md)。
2. 展开**自定义字段**类别。
3. 检查你想要过滤的字段，选择一个操作符，并输入一个值。提供的操作符与字段的类型匹配：
   - **文本框** -- 包含、等于、开始于、结束于。
   - **整数 / 小数** -- 等于、大于、大于或等于、小于、小于或等于。
   - **日期** -- 等于、之后（大于）、之前（小于）。
   - **是/否** -- 等于是或否。
   - **多个选择** -- 等于或包含其中一个选择。

将任何自定义字段搜索保存为[列表](../people/lists.md)。列表是实时查询，所以*背景检查过期在今天之前*构建的列表每次你打开它时都会重新检查每个人 -- 无需手动维护。

## 将自定义字段显示为列

要一次查看所有人的字段值，请将其添加为**人员**页面上的列。打开列选择器，切换到**自定义**选项卡，然后检查该字段。每个人的值与内置字段一起显示在其自己的列中。参见[将自定义字段显示为列](../people/searching-people.md#showing-custom-fields-as-columns)。

## 合并时会发生什么

当你[合并两条人员记录](../people/adding-people.md)时，自定义字段值会自动转移。你保留的人员坚持他们自己的值；对于任何只有被删除人员有值的字段，该值会被复制，因此不会丢失任何东西。
