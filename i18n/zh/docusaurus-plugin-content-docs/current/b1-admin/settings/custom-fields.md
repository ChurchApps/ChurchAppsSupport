# 自定义字段

<div class="article-intro">

**自定义字段**让您在每个人的档案上追踪您自己的信息 -- 这些是 B1 没有内置字段的内容，比如背景检查过期日期、T 恤尺码或洗礼班状态。您在设置中定义一次字段，然后在每个人的档案中填入值，并搜索或基于它构建列表。这替代了创建人员表单仅用于存储单个数据片段的旧解决方法。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要**人员**编辑权限来定义字段和填入值，以及访问**设置**区域。任何拥有人员查看权限的人都可以看到值。请参阅[角色和权限](./roles-permissions.md)。
- 在开始之前，决定您想追踪什么以及哪种类型最适合（文本、数字、日期、是/否答案或选择列表）。

</div>

## 打开自定义字段

在 B1 Admin 中，打开左上角的**菜单**（带小箭头的菜单名称），选择**设置**，然后选择**自定义字段**卡片。您也可以直接转到 **/settings/custom-fields**。您将看到您已定义的每个字段的列表，显示其**名称**和**字段类型**。如果您还没有创建任何字段，面板会显示*"还没有添加自定义字段。"*

## 添加字段

1. 单击**添加字段**。
2. 在右侧打开的编辑器中，输入**名称** -- 这是员工在人员档案和搜索中看到的标签（例如，*背景检查过期*）。
3. 选择**字段类型**：
   - **文本框** -- 自由格式的短文本。
   - **整数** -- 没有小数的数字（例如，计数）。
   - **小数** -- 可以包括小数的数字。
   - **日期** -- 日历日期。
   - **是/否** -- 简单的是或否答案。
   - **多选** -- 选择列表。当您选择此类型时，会显示**选择编辑器**，以便您可以添加人们可以选择的每个选项。
4. 单击**保存**。

该字段现在可以在每个人的档案上使用。

:::info
字段类型与[表单问题](../forms/creating-forms.md)使用的集合相同，因此值在 B1 中的行为是一致的。
:::

## 编辑字段

单击列表中的任何字段行以在编辑器中重新打开它。更改名称、类型或选择，然后单击**保存**。

:::warning
更改已有值的字段的**字段类型**（例如，从文本框更改为日期）可能会使之前输入的值处于不再匹配新类型的格式中。一旦员工开始填写字段，请谨慎更改类型。
:::

## 删除字段

打开字段进行编辑并单击**删除**。系统会要求您确认：*"您确定要删除此自定义字段吗？其存储的值也将被删除。"* 删除字段会永久删除它**和存储在所有人上的每个值** -- 这无法撤销。

## 填写人员的值

一旦至少存在一个自定义字段，其值就会与人员记录上的内置详细信息一起显示 -- 您可以在**个人详情**中查看它们，并在用于其余人员信息的相同表单上编辑它们。在您定义第一个字段之前，不会显示任何内容。

1. 在**人员**中打开一个人的记录。
2. 在**个人详情**部分，单击**编辑**（铅笔）按钮。
3. 滚动到编辑表单底部的**自定义字段**区域，并为每个字段填入一个值。每个字段显示与其类型匹配的输入 -- 日期字段的日期选择器、是/否字段的是/否下拉菜单、多选的选择列表等。
4. 单击**保存**。您的自定义字段值与其余人员详情一起保存。

回到档案上，任何有值的字段现在都显示在**个人详情**部分（是/否答案读作*是*或*否*，多选显示选项的标签）。留白的字段只是隐藏。要删除一个值，编辑人员，清除字段，然后保存 -- 空值被从记录中删除而不是存储为空白。

:::tip
经典用例是志愿者安全：创建一个名为*背景检查过期*的**日期**字段，记录每个志愿者的日期，然后构建一个[已保存列表](../people/lists.md)，标记日期已过的任何人。
:::

## 搜索并基于自定义字段构建列表

自定义字段完全可搜索：

1. 在**人员**页面上，打开[高级搜索](../people/searching-people.md)。
2. 展开**自定义字段**类别。
3. 检查您想筛选的字段，选择一个运算符，然后输入一个值。提供的运算符与字段的类型匹配：
   - **文本框** -- 包含、等于、开头为、结尾为。
   - **整数 / 小数** -- 等于、大于、大于或等于、小于、小于或等于。
   - **日期** -- 等于、之后（大于）、之前（小于）。
   - **是/否** -- 等于是或否。
   - **多选** -- 等于或包含其中一个选择。

将任何自定义字段搜索保存为[列表](../people/lists.md)。列表是实时查询，因此基于*背景检查过期在今天之前*的列表每次打开时都会重新检查每个人 -- 无需手动维护。

## 合并时会发生什么

当您[合并两个人员记录](../people/adding-people.md)时，自定义字段值会自动进行。您保留的人员持有他们自己的值；对于只有被删除人员有值的任何字段，该值会被复制过来，所以不会丢失任何东西。
