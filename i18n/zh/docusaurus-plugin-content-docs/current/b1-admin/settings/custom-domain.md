# 自定义域

<div class="article-intro">

你可以指向你自己的域（例如，**www.yourchurch.org**）到你的 B1 网站，以便访客在你教会的真实网址访问它，而不是默认的 yourchurch.1.church 地址。

</div>

## 步骤 1 -- 首先添加 DNS 记录

在 B1 中添加你的域之前，你需要在你的域注册商（GoDaddy、Namecheap、Cloudflare 等）处将其指向 B1 的服务器。

添加这些记录之一 -- CNAME 是首选：

| 类型 | 主机 | 值 |
|------|------|-------|
| CNAME | `www` | `proxy.b1.church` |
| A | `yourchurch.org` | `3.23.251.61` |

对你的 `www` 地址使用 **CNAME**。如果你的注册商不支持根/顶点域上的 CNAME（不带 www），或者如果你想让根域也起作用，请使用 **A 记录**。

DNS 更改可能需要几分钟到几小时才能生效。

## 步骤 2 -- 在 B1 中添加域

DNS 指向 B1 后：

1. 转到 B1 Admin 中的**设置**。
2. 单击**域**。
3. 在字段中键入你的域并单击**保存**。

你不需要首先单击**+**按钮 -- 字段中留下的已输入域在你保存时会被添加。当你想在保存之前向列表添加多个域时，使用**+**（或按**Enter**）。

B1 自动处理 SSL -- 不需要证书购买。

:::warning
如果在 DNS 记录到位之前在 B1 中添加域，它将不会保存。始终首先设置 DNS。
:::

## 检查它是否正常工作

保存后，在浏览器中访问你的域。如果它加载你的 B1 网站，你就完成了。如果你看到错误，DNS 可能仍在传播 -- 等待几分钟并再试一次。

你也可以在 [dnschecker.org](https://dnschecker.org) 检查 DNS 传播 -- 搜索你的域并查看 CNAME 或 A 记录是否显示。
