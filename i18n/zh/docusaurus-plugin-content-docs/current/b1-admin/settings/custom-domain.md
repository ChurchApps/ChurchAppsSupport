# 自定义域名

<div class="article-intro">

您可以将自己的域名（例如 **www.yourchurch.org**）指向您的 B1 网站，这样访客就可以通过教会真实的网址访问网站，而无需使用默认的 yourchurch.b1.church 地址。

</div>

## 第 1 步 —— 先添加 DNS 记录

在 B1 中添加您的域名之前，您需要在域名注册商（GoDaddy、Namecheap、Cloudflare 等）处将其指向 B1 的服务器。

添加以下记录之一——推荐使用 CNAME：

| 类型 | 主机 | 值 |
|------|------|-----|
| CNAME | `www` | `proxy.b1.church` |
| A | `yourchurch.org` | `3.23.251.61` |

对于 `www` 地址，请使用 **CNAME**。如果您的注册商不支持根域名（不带 www 的顶级域名）使用 CNAME，或者您希望根域名也能正常访问，则请使用 **A 记录**。

DNS 更改可能需要几分钟到几小时才能生效。

## 第 2 步 —— 在 B1 中添加域名

DNS 指向 B1 之后：

1. 在 B1 Admin 中前往**设置**。
2. 点击左侧列表中的**域名**，然后点击**域名**板块中的**编辑**。
3. 在输入框中输入您的域名，然后点击**保存**。

您无需先点击 **+** 按钮——只需将域名留在输入框中并保存即可添加。当您希望在保存前添加多个域名到列表中时，请使用 **+**（或按 **Enter** 键）。

B1 会自动处理 SSL——无需购买证书。

:::warning
如果您在 DNS 记录设置好之前就在 B1 中添加域名，该域名将无法保存。请务必先设置 DNS。
:::

## 检查是否生效

保存后，在浏览器中访问您的域名。如果能加载您的 B1 网站，即表示设置完成。如果出现错误，则 DNS 可能仍在传播中——请等待几分钟后再试一次。

您也可以在 [dnschecker.org](https://dnschecker.org) 上检查 DNS 传播情况——搜索您的域名，并查看您的 CNAME 或 A 记录是否已显示出来。
