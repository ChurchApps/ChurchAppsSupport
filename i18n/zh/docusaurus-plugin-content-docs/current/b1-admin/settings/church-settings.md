# 教会设置

<div class="article-intro">

教会设置页面是您配置教会基本信息、联系方式和品牌的地方。这些详细信息在所有 ChurchApps 工具中使用，包括您的 B1.church 网站和 B1 移动应用。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 您需要"编辑教会设置"权限。如果您没有访问权限，请参阅[角色和权限](./roles-permissions.md)。
- 准备好您教会的地址、联系信息和徽标

</div>

## 编辑您的教会信息

1. 在 B1 Admin 中，打开左上角的**部分菜单**（带有小箭头的部分名称）并选择**设置**。
2. 打开**教会信息**部分并单击其编辑（铅笔）图标。
3. 更新以下任何字段：
   - **教会名称** —— 在所有 ChurchApps 产品中显示的名称。
   - **地址** —— 您教会的物理地址。
   - **联系信息** —— 电话号码、电子邮件和其他联系方式。
4. 单击**保存**以应用您的更改。

## 设置您的子域

您的教会在 **yourchurch.1.church** 获得一个免费子域。这是教会成员和访客可以访问教会在线形象的网址。

1. 在设置页面上，找到**子域**字段。
2. 输入您首选的子域（例如，"gracechurch"用于 gracechurch.1.church）。
3. 保存您的更改。

:::info
您的子域在所有 ChurchApps 教会中必须是唯一的。如果您首选的名称已被占用，请尝试添加您的城市或州（例如，"gracechurch-dallas"）。
:::

如果您想让访客在您自己的域（例如，**www.gracechurch.org**）访问您的网站，请参阅[自定义域](./custom-domain.md)。

## 配置品牌

自定义您的教会如何在所有 ChurchApps 工具中出现：

1. 通过单击徽标区域并选择图像文件来上传您的**教会徽标**。
2. 添加在您的网站和[移动应用](./mobile-app.md)上使用的任何额外**教会图像**。

:::tip
为了获得最佳效果，使用 PNG 格式具有透明背景的徽标。这确保它在浅色和深色背景上看起来都很好。
:::

## 周开始日期

选择您的日历在哪一天开始。教会信息部分上的**周开始日期**下拉菜单默认为**周日**，但可以设置为任何一天。一旦更改，它就被应用于 B1 Admin 和 B1.church 成员门户中的日历网格——小组日历、策展日历和事件编辑器都从您选择的日期开始布置周。

## 文件存储

默认情况下，您上传到您的网站（通过[文件](../website/files.md)）和其他内容区域的文件使用 B1 的免费托管存储，最多 100MB。如果您需要更多空间，您可以改为连接您自己的云存储——新上传然后直接进入您的帐户，无平台限制。

1. 在设置页面上，找到**文件存储**卡片并单击以编辑它。
2. 选择提供商：**Google Drive**、**Dropbox**、**OneDrive** 或 **S3 兼容存储桶**（AWS S3、Cloudflare R2、Backblaze B2 等）。
3. 对于 Google Drive、Dropbox 或 OneDrive，单击**连接**并登录以授权访问。对于 S3 兼容存储桶，输入您的访问密钥、密码、存储桶名称和公共 URL 基础。
4. 单击**保存**。

:::info
这仅影响新上传到您的网站文件和类似内容区域。图库图像、缩略图、徽标和人员照片始终停留在 B1 的默认存储上。
:::

## 等级晋升

如果您在儿童和学生上跟踪**等级**，B1 可以在您选择的日期（例如 8 月 1 日）自动将所有人升级一级，而不是要求您手动编辑每个配置文件。

1. 在设置页面上，找到**等级晋升**选项。
2. 打开它并选择每年晋升等级的**月和日**。
3. 保存您的更改。

## 导入和导出

设置标题中的**导入/导出**按钮在新浏览器窗口中打开专用工具。使用此来：

- 从另一个教会管理系统导入成员数据。
- 导出您的 ChurchApps 数据以备份或迁移。

当您首次设置教会并需要将现有记录转移到 ChurchApps 时，这特别有帮助。

:::warning
导入数据时，始终先备份您现有的记录。导入操作向您的系统添加数据，如果运行多次可能会创建重复条目。
:::
