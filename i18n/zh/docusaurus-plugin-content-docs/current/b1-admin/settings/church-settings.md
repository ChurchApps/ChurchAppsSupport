# 教会设置

<div class="article-intro">

教会设置页面用于配置教会的基本信息、联系方式和品牌形象。这些信息会应用于所有 ChurchApps 工具，包括您的 B1.church 网站和 B1 App。

</div>

## 编辑教会信息

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（位于左上角的搜索栏），展开**设置**，然后点击**设置**。
2. 在**教会信息**部分（页面顶部），点击**编辑**。
3. 更新以下任意字段：
   - **教会名称** —— 将显示在所有 ChurchApps 产品中的名称。
   - **地址** —— 教会的实际地址。
   - **联系信息** —— 电话号码、电子邮件和其他联系方式。
   - **时区** —— 教会所在的时区。请参阅下方的[时区](#time-zone)。
4. 点击**保存**以应用更改。

## 设置子域名

您的教会将获得一个免费的子域名 **yourchurch.1.church**。这是会众和访客访问教会线上主页的网址。

1. 在设置页面中，点击**教会信息**部分的**编辑**，然后找到**子域名**字段。
2. 输入您希望使用的子域名（例如，输入 "gracechurch" 即可得到 gracechurch.1.church）。
3. 保存更改。

:::info
您的子域名必须在所有 ChurchApps 教会中唯一。如果您想要的名称已被占用，可以尝试添加城市或州名（例如 "gracechurch-dallas"）。
:::

如果您希望访客通过您自己的域名访问网站（例如 **`www.gracechurch.org`**），请参阅[自定义域名](./custom-domain.md)。

## 配置品牌形象

自定义教会在所有 ChurchApps 工具中的展示方式：

1. 点击标志区域并选择图片文件，上传您的**教会标志**。
2. 添加网站和[移动应用](./mobile-app.md)中使用的其他**教会图片**。

:::tip
为获得最佳效果，建议使用背景透明的 PNG 格式标志。这样无论在浅色还是深色背景上都能清晰显示。
:::

## 一周的第一天

选择日历的起始日。教会信息部分中的**一周的第一天**下拉菜单默认为**星期日**，但可以设置为任意一天。更改后，B1 Admin 和 B1.church 会员门户中的日历网格都会遵循此设置——小组日历、策划日历和活动编辑器都将以您选择的那一天作为每周的起始。

## 时区

**教会信息**部分中的**时区**下拉菜单用于设置教会所在的时区（例如 *America/Chicago*）。选择**无**则留空。保存后，该时区会显示在教会信息摘要中。

B1 将此时区用于全教会范围的时间设置，例如活动提醒以及您的 [FreePlay](../../freeplay/scheduled-mode/scheduling-the-calendar.md) 电视上的日程安排。[签到时间表](../attendance/setup.md#setting-a-check-in-schedule)首先以该礼拜所属[堂点](./campuses.md)的时区计算；只有当该堂点未设置时区时，才会使用教会的时区。如果您的所有堂点都位于同一时区，请同时在教会和每个堂点上进行设置。

## 地区（日期和电话格式）

**地区**设置用于控制 B1 中日期和时间的显示方式。默认情况下，日期采用美国格式（例如 "Sep 28, 2026" 和 "9/28/2026"）。美国以外的教会可以切换为本地格式——例如，选择 English (United Kingdom) 后将显示 "28 Sept 2026" 和 "28/09/2026"。

1. 在设置页面中，点击左侧列表中的**地区**，然后点击**地区**部分中的**编辑**。
2. 从**地区**下拉菜单中选择您所在的地区。每个选项都会显示一个示例日期，方便您查看日期的具体显示效果。
3. 点击**保存**。

保存后，地区部分会显示您所选的地区、**日期格式**示例以及您的**电话号码**格式。

### 电话号码格式

同一地区部分中的**电话号码**设置用于控制在个人档案中输入电话号码的方式：

- **国际（含国家代码）** —— 默认选项。电话字段会显示国旗选择器，并以国家代码保存号码（例如 +1 918 555 1234）。
- **本地（按输入方式）** —— 电话字段变为普通文本框，号码将按您的输入原样保存，不会添加国家代码（例如 0701 234 5678）。如果您的教会习惯使用本地格式书写号码，并且不希望 B1 自动添加国家代码，请选择此项。

选择**本地**后，地区部分还会在您所选地区旁边显示"本地电话号码"。

:::tip
当号码包含国家代码时，短信功能效果最佳。如果您通过 B1 发送短信，请保留**国际**格式，或确保在本地模式下输入的号码包含国家代码。
:::

您所选的地区会应用于 B1 Admin 以及您的 B1.church 网站和会员门户中的日期和时间，包括讲道、博客文章、小组日历和服事计划，使会众看到的日期格式与教职员工一致。

## 短信 {#texting}

连接短信服务提供商，即可通过 B1 Admin 向个人或整个小组发送短信。短信通过您在服务提供商处的自有账户发送，因此将适用其定价和限制。

1. 在设置页面中，点击左侧列表中的**短信**，然后点击**短信**部分中的**编辑**。
2. 选择**提供商**：
   - **Clearstream** —— 输入 **API 密钥**。请在您的 Clearstream 账户设置的 API Keys 下创建密钥。
   - **Text In Church** —— 输入 **API 密钥**。请先向 Text In Church 支持团队申请开发者 API 访问权限，然后在账户设置 > Developer API 部分中创建密钥。
   - **Nalo Solutions**（加纳）—— 输入您 Nalo Solutions 账户中的授权密钥作为 **API 密钥**，并输入 Nalo 已为您批准的**发件人 ID**（最多 11 个字符）。
   - **Twilio** —— 使用教会自己的 Twilio 账户；费用由 Twilio 直接向您收取。从 [Twilio Console](https://console.twilio.com) 复制 **Account SID** 和 **Auth Token**，并输入**发送号码**——即已在 A2P 10DLC 上注册的 Twilio 电话号码，格式如 `+15551234567`。保存后，将下方的入站 Webhook 网址粘贴到 Twilio 中该号码的 **A message comes in** Webhook 设置里，这样 STOP 回复也会记录到 B1 中。
3. 点击**保存**。

如需停止发送短信，请将**提供商**设置为**无**并保存。这将删除已保存的提供商。

### 对回复 STOP 的人员取消订阅

保存提供商后，请点击**编辑**重新打开短信部分。在提供商设置下方，会显示一个只读的**入站（STOP）Webhook 网址**字段，其中包含教会专属的网址。点击该字段即可选中网址，复制后粘贴到您的短信服务提供商的入站消息（回复）Webhook 设置中。上述任一可以将收到的回复转发至 Webhook 的提供商都适用此方法。

此后，当有人回复您的短信并发送 **STOP**（或 STOPALL、UNSUBSCRIBE、CANCEL、END、QUIT、OPTOUT 或 REVOKE）时，B1 会找到所有手机号码匹配的人员，将其标记为已取消订阅，并关闭其短信提醒。之后，他们将不会收到小组短信。其他回复将被忽略。

:::info
此功能与**对会员目录隐藏我**使用相同的订阅设置，因此回复 STOP 的人员在其个人资料中也会显示为**已对目录隐藏**。只有在选中已保存的提供商时，该字段才会显示——如果您将下拉菜单切换为其他提供商，请先保存，才能再次看到该网址。
:::

连接提供商后，有权发送短信的员工可以在小组页面上看到**短信**按钮（**给该小组发短信**），在拥有手机号码的个人页面上也能看到（**发送短信**）。输入消息内容后点击**发送**。对话框会统计字符数和短信条数。对于小组，发送前它会显示将收到短信的成员人数：

- 没有手机号码记录的成员将被跳过。
- 选择了**对会员目录隐藏我**的成员将被视为已取消订阅，同样会被跳过。
- 共用同一手机号码的家庭成员只会收到一条短信。

### 使用合并字段个性化短信 {#personalizing-texts-with-merge-fields}

在消息框下方，短信对话框会显示占位符标签：**名字**、**姓氏**、**显示名称**和**教会名称**。点击某个标签，即可在光标处插入对应的占位符（`{{firstName}}`、`{{lastName}}`、`{{displayName}}` 或 `{{churchName}}`）。发送短信时，每个占位符都会被替换为该收件人的对应信息，因此像 `Hi {{firstName}}, see you Sunday!` 这样的小组短信，会以每位成员自己的名字送达。占位符同时适用于小组短信和发给单个人的短信。发给小组的短信还提供**小组名称**标签（`{{groupName}}`），它会被替换为小组的名称。

如需重复使用某条消息，可将其保存为[短信模板](./email-templates.md#text-templates)（属于**短信**类别的电子邮件模板），然后在短信窗口顶部的**加载模板（可选）**中选择它。

:::info
1,600 个字符的限制针对的是您输入时的消息内容。占位符填充完成后，任何超过 1,600 个字符的文本都会在该长度处被截断。
:::

短信还可以通过[工作流](../serving/workflows.md#sending-a-text)中的**发送短信**步骤自动发出，该步骤使用相同的提供商和占位符。

## 文件存储

默认情况下，您通过[文件](../website/files.md)上传到网站以及其他内容区域的文件，将使用 B1 提供的免费托管存储空间，最多 100MB。如果您需要更多空间，可以改为连接自己的云存储——此后新上传的文件将直接保存到您的账户中，不受平台限制。

1. 在设置页面中，点击左侧列表中的**文件存储**，然后点击**文件存储**部分中的**编辑**。
2. 选择提供商：**Google Drive**、**Dropbox**、**OneDrive**，或 **S3 兼容存储桶**（AWS S3、Cloudflare R2、Backblaze B2 等）。
3. 对于 Google Drive、Dropbox 或 OneDrive，请点击**连接**并登录以授权访问。对于 S3 兼容存储桶，请输入访问密钥、密钥、存储桶名称和公共 URL 基础地址。
4. 点击**保存**。

:::info
此设置仅影响新上传到网站文件及类似内容区域的文件。图库图片、缩略图、标志和人员照片始终保存在 B1 的默认存储中。
:::

## 年级升级

如果您在儿童和学生信息中记录了**年级**，B1 可以在您指定的日期（例如 8 月 1 日）自动将所有人升一个年级，无需您逐个手动编辑个人资料。

1. 在设置页面中，点击左侧列表中的**年级升级**，然后点击**年级升级**部分中的**编辑**。
2. 打开开关（显示为**已启用**），并选择每年进行年级升级的**月份**和**日期**。在该日期，所有有年级记录的人员都将升一个年级，而 12 年级的学生将变为**已毕业**。
3. 保存更改。

如需停止自动升级，请关闭开关使其显示为**已禁用**并保存。升级日期将被删除，年级将不再自动变化。

## 志愿者报名 {#volunteer-signup}

默认情况下，浏览[志愿者报名](../../b1-church/serving/volunteer-signup.md)的会员会看到所有有空缺职位的即将到来的周次。如果列表较长，您可以改为只显示每种计划类型的下一周。

1. 在设置页面中，点击左侧列表中的**志愿者报名**，然后点击**志愿者报名**部分中的**编辑**。
2. 打开**仅显示每种计划类型的下一周**。
3. 保存更改。

开启此选项后，每种计划类型将只显示其下一个即将到来的计划。下一周的计划会在当前日期过去后才会出现。该部分的**显示周次**一行会显示**仅每种计划类型的下一周**或**所有即将到来的周次**。

## 奉献隐私 {#giving-privacy}

拥有奉献访问权限的人通常可以在人员档案上看到该人的奉献总额（[人员档案](../people/adding-people.md#editing-details)）。如果您不希望每次打开档案时都显示金额，可以将其隐藏，直到有人主动请求查看。

1. 在设置页面中，点击左侧列表中的**奉献隐私**，然后点击**奉献隐私**部分中的**编辑**。
2. 打开**在点击前隐藏人员档案上的奉献信息**。
3. 保存更改。

开启此选项后，人员档案上的奉献卡片会显示"人员档案上的奉献信息已隐藏"。点击**显示奉献**即可加载并显示该人员的奉献信息。打开其他人员的档案时，信息会再次隐藏。谁可以查看奉献信息不会改变：只有拥有奉献访问权限的人员才能看到该卡片。

## 导入和导出

设置页面中教会名称下方的 **导入/导出** 链接会在新的浏览器窗口中打开一个专用工具。您可以使用它来：

- 从其他教会管理系统导入会员数据。
- 导出您的 ChurchApps 数据，用于备份或迁移。

在您首次设置教会、需要将现有记录迁移到 ChurchApps 时，此功能尤其有用。

:::warning
导入数据前，请务必先备份现有记录。导入操作会向系统添加数据，如果多次运行，可能会产生重复记录。
:::
