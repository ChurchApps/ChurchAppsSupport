# 教会设置

<div class="article-intro">

教会设置页面是你配置教会的基本信息、联系方式和品牌的地方。这些详细信息在所有 ChurchApps 工具中使用，包括你的 B1.church 网站和 B1 移动应用。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要"编辑教会设置"权限。如果你没有访问权限，参见[角色和权限](./roles-permissions.md)。
- 准备好你的教会的地址、联系信息和徽标

</div>

## 编辑你的教会信息

1. 在 B1 Admin 中，打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**设置**，然后单击**设置**。
2. 打开**教会信息**部分，然后单击其编辑（铅笔）图标。
3. 更新以下任何字段：
   - **教会名称** -- 在所有 ChurchApps 产品中显示的名称。
   - **地址** -- 你的教会的物理地址。
   - **联系信息** -- 电话号码、电子邮件和其他联系方式。
4. 单击**保存**以应用你的更改。

## 设置你的子域

你的教会在 **yourchurch.1.church** 获得一个免费子域。这是你的教会成员和访客可以访问你教会在线形象的网址。

1. 在设置页面上，找到**子域**字段。
2. 输入你首选的子域（例如，"gracechurch"代表 gracechurch.1.church）。
3. 保存你的更改。

:::info
你的子域必须在所有 ChurchApps 教会中是唯一的。如果你首选的名称已被使用，请尝试添加你的城市或州（例如，"gracechurch-dallas"）。
:::

如果你想让访客在你自己的域（例如，**www.gracechurch.org**）访问你的网站，请参见[自定义域](./custom-domain.md)。

## 配置品牌

在所有 ChurchApps 工具中自定义你的教会的外观：

1. 通过单击徽标区域并选择图像文件来上传你的**教会徽标**。
2. 添加你的网站和[移动应用](./mobile-app.md)使用的任何其他**教会图像**。

:::tip
为了获得最佳效果，请使用 PNG 格式中具有透明背景的徽标。这确保它在浅色和深色背景上看起来都很好。
:::

## 周的第一天

选择你的日历从哪一天开始。**周的第一天**下拉列表默认为**星期日**，但可以设置为任何一天。一旦更改，它在 B1 Admin 和 B1.church 成员门户中的日历网格上都会得到遵守 -- 小组日历、策划日历和事件编辑器都按你选择的日期开始周。

## 区域（日期和电话格式）

**区域**设置控制日期和时间在整个 B1 中的写法。默认情况下，日期使用美国格式（例如，"Sep 28, 2026"和"9/28/2026"）。美国外的教会可以切换到自己的格式 -- 例如，选择英语（英国）显示"28 Sept 2026"和"28/09/2026"。

1. 在设置页面上，找到**区域**卡并单击进行编辑。
2. 从**区域**下拉列表中选择你的区域。每个选项都显示一个样本日期，所以你可以准确看到日期的显示方式。
3. 单击**保存**。

区域卡随后显示你选择的区域、**日期格式**的样本以及你的**电话号码**格式。

### 电话号码格式

同一个区域卡上有一个**电话号码**设置，用于控制在个人记录中如何输入电话号码：

- **国际（带国家/地区代码）** -- 默认选项。电话字段显示国旗选择器，并连同国家/地区代码一起保存号码（例如 +1 918 555 1234）。
- **本地（按输入保存）** -- 电话字段变为普通文本框，号码完全按你输入的内容保存，不会添加国家/地区代码（例如 0701 234 5678）。如果你的教会使用本地格式书写号码，并且不希望 B1 添加国家/地区代码，请选择此项。

选择**本地**后，区域卡还会在你的区域旁边显示“本地电话号码”。

:::tip
号码包含国家/地区代码时短信效果最佳。如果你从 B1 发送短信，请保持**国际**格式，或确保你在本地模式下输入的号码包含国家/地区代码。
:::

你的区域应用于整个 B1 Admin 和你的 B1.church 网站和成员门户中的日期和时间，包括讲道、博客文章、小组日历和服侍计划，所以成员看到的日期格式与你的工作人员相同。

## 短信

连接短信提供商以从 B1 Admin 向一个人或整个小组发送 SMS 消息。短信通过你自己的提供商帐户发送，所以他们的定价和限制适用。

1. 在设置页面上，找到**短信**卡并单击进行编辑。
2. 选择**提供商**：
   - **Clearstream** -- 输入**API 密钥**。在你的 Clearstream 帐户设置中的 API 密钥下创建一个。
   - **Text In Church** -- 输入**API 密钥**。首先向 Text In Church 支持请求开发者 API 访问权限，然后在你的帐户设置 > 开发者 API 部分创建密钥。
   - **Nalo Solutions**（加纳）-- 输入来自你的 Nalo Solutions 帐户的身份验证密钥作为**API 密钥**，以及**发件人 ID**（最多 11 个字符），Nalo 已为你批准。
3. 单击**保存**。

要停止发短信，请将**提供商**设置为**无**并保存。这会删除已保存的提供商。

一旦连接了提供商，有权限发送文本的工作人员会在小组的标题中看到一个文本图标（**给这个小组发短信**）和一个具有手机的人（**发送短信消息**）。键入你的消息并单击**发送**。对话框计数字符和 SMS 段。对于一个小组，它显示在你发送之前有多少成员会获得短信：

- 档案上没有手机的成员会被跳过。
- 选择**从成员目录中隐藏我**的成员被计为选择退出，并被跳过。
- 共享手机号码的家庭成员只获得一次短信。

### 使用合并字段个性化短信

在消息框下方，短信对话框显示占位符芯片：**名字**、**姓氏**、**显示名称**和**教会名称**。单击一个芯片将其占位符（`{{firstName}}`、`{{lastName}}`、`{{displayName}}`或 `{{churchName}}`）插入到你的光标处。发送短信时，每个占位符都会被替换为该收件人的详细信息，所以一条小组短信，如 `Hi {{firstName}}, see you Sunday!` 会以每个成员自己的名字送达。占位符适用于小组短信和发送给一个人的短信。

:::info
1,600 个字符的限制适用于你键入的消息。填充占位符后，任何长于 1,600 个字符的文本都会在该长度处被截断。
:::

短信也可以从[工作流](../serving/workflows.md#sending-a-text)步骤的**发送短信**操作自动发出，该操作使用相同的提供商和占位符。

## 文件存储

默认情况下，你上传到你的网站的文件（通过[文件](../website/files.md)）和其他内容区域使用 B1 的免费托管存储，最多 100MB。如果你需要更多空间，你可以改为连接你自己的云存储 -- 新上传然后直接转到你的帐户，没有平台限制。

1. 在设置页面上，找到**文件存储**卡并单击进行编辑。
2. 选择提供商：**Google Drive**、**Dropbox**、**OneDrive**或 **S3 兼容的存储桶**（AWS S3、Cloudflare R2、Backblaze B2 等）。
3. 对于 Google Drive、Dropbox 或 OneDrive，单击**连接**并登录以授权访问。对于 S3 兼容的存储桶，输入你的访问密钥、秘密、存储桶名称和公共 URL 基数。
4. 单击**保存**。

:::info
这仅影响你的网站文件和类似内容区域的新上传。图库图像、缩略图、徽标和人员照片始终保留在 B1 的默认存储上。
:::

## 年级晋升

如果你追踪儿童和学生的**年级**，B1 可以在你选择的日期（例如，8 月 1 日）自动将每个人提升一个年级，而不需要你手动编辑每个档案。

1. 在设置页面上，找到**年级晋升**选项。
2. 打开开关（它显示**已启用**），然后选择每年提升年级的**月份**和**日期**。在那个日期，每个有年级的人都会提升一个年级，12 年级学生变成**已毕业**。
3. 保存你的更改。

要停止自动晋升，请关闭开关使其显示**已禁用**并保存。晋升日期被删除，年级将不再自动更改。

## 导入和导出

设置标题中的**导入/导出**按钮在新浏览器窗口中打开专用工具。使用它来：

- 从另一个教会管理系统导入成员数据。
- 导出你的 ChurchApps 数据以进行备份或迁移。

当你首次设置你的教会并需要将现有记录转移到 ChurchApps 时，这特别有帮助。

:::warning
导入数据时，始终先备份现有记录。导入操作会向你的系统添加数据，如果多次运行，可能会创建重复条目。
:::
