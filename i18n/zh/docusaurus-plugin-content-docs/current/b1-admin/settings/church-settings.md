# 教会设置

<div class="article-intro">

教会设置页面是您配置教会基本信息、联系方式和品牌形象的地方。这些详细信息在所有 ChurchApps 工具中使用，包括您的 B1.church 网站和 B1 Mobile 应用。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要"编辑教会设置"权限。如果您没有访问权限，请参阅[角色和权限](./roles-permissions.md)。
- 准备好您的教会地址、联系信息和徽标

</div>

## 编辑您的教会信息

1. 在 B1 Admin 中，打开左上角的**菜单**（带小箭头的菜单名称）并选择**设置**。
2. 单击标头中的**编辑设置**按钮。
3. 更新以下任何字段：
   - **教会名称** -- 在所有 ChurchApps 产品中显示的名称。
   - **地址** -- 您教会的物理地址。
   - **联系信息** -- 电话号码、电子邮件和其他联系方式。
4. 单击**保存**以应用您的更改。

## 设置您的子域

您的教会获得一个免费子域 **yourchurch.b1.church**。这是您的成员和访客可以访问教会在线存在的网址。

1. 在设置页面上，找到**子域**字段。
2. 输入您偏好的子域（例如 "gracechurch" 用于 gracechurch.b1.church）。
3. 保存您的更改。

:::info
您的子域必须在所有 ChurchApps 教会中唯一。如果您的首选名称已被占用，请尝试添加您的城市或州（例如 "gracechurch-dallas"）。
:::

## 配置品牌

自定义您的教会在所有 ChurchApps 工具中的显示方式：

1. 单击徽标区域并选择图像文件来上传您的**教会徽标**。
2. 添加您网站和[移动应用](./mobile-app.md)上使用的任何其他**教会图像**。

:::tip
为了获得最佳效果，请使用具有透明背景的 PNG 格式徽标。这确保它在浅色和深色背景上都看起来很棒。
:::

## 年级晋升

如果您在儿童和学生中追踪**年级**，B1 可以自动在您选择的日期（例如 8 月 1 日）将所有人的年级上调，而不需要手动编辑每个档案。

1. 在设置页面上，找到**年级晋升**选项。
2. 打开它并选择**月份和日期**以每年晋升年级。
3. 保存您的更改。

## 导入和导出

设置标头中的**导入/导出**按钮在新浏览器窗口中打开专门的工具。使用它来：

- 从另一个教会管理系统导入成员数据。
- 导出您的 ChurchApps 数据以进行备份或迁移。

当您首次设置教会并需要将现有记录转移到 ChurchApps 时，这特别有用。

:::warning
导入数据时，始终首先备份您的现有记录。导入操作会向您的系统添加数据，如果多次运行，可能会创建重复项。
:::
