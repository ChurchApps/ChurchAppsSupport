# 教会设置

<div class="article-intro">

教会设置页面用于配置您教会的基本信息、联系方式和品牌形象。这些信息会在所有 ChurchApps 工具中使用，包括您的 B1.church 网站和 B1 Mobile 应用。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要拥有"编辑教会设置"权限。如果您没有访问权限，请参阅[角色与权限](./roles-permissions.md)。
- 准备好教会的地址、联系信息和标志。

</div>

## 编辑教会信息

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **设置**，然后点击 **设置**。
2. 在 **教会信息** 部分（页面顶部），点击 **编辑**。
3. 更新以下任一字段：
   - **教会名称** -- 在所有 ChurchApps 产品中显示的名称。
   - **地址** -- 教会的实际地址。
   - **联系信息** -- 电话号码、电子邮件和其他联系方式。
   - **时区** -- 教会所在的时区。参见下方的[时区](#time-zone)。
4. 点击 **保存** 以应用更改。

## 设置子域名

您的教会可获得一个免费的子域名 **yourchurch.1.church**。这是会众和访客访问教会在线内容的网址。

1. 在设置页面，点击 **教会信息** 部分中的 **编辑**，并找到 **子域名** 字段。
2. 输入您偏好的子域名（例如，"gracechurch" 对应 gracechurch.1.church）。
3. 保存更改。

:::info
您的子域名在所有 ChurchApps 教会中必须是唯一的。如果您偏好的名称已被占用，可以尝试添加您所在的城市或州（例如"gracechurch-dallas"）。
:::

如果您希望访客通过您自己的域名（例如 **`www.gracechurch.org`**）访问您的网站，请参阅[自定义域名](./custom-domain.md)。

## 配置品牌形象

自定义您的教会在所有 ChurchApps 工具中的呈现方式：

1. 点击教会标志区域并选择图片文件，即可上传您的**教会标志**。
2. 添加其他用于您的网站和[移动应用](./mobile-app.md)的**教会图片**。

:::tip
为获得最佳效果，请使用 PNG 格式、背景透明的标志。这样可以确保它在浅色和深色背景上都显示良好。
:::

## 每周第一天

选择您的日历从哪一天开始。教会信息部分的 **每周第一天** 下拉菜单默认为 **星期日**，但可以设置为任意一天。更改后，它会在 B1 Admin 和 B1.church 会员门户的日历视图中生效 -- 小组日历、策划日历以及活动编辑器都会以您选择的那一天作为每周的开始。

## 时区

教会信息部分中的 **时区** 下拉菜单用于设置教会所在的时区（例如 *America/Chicago*）。选择 **无** 可将其留空。保存后，该时区会显示在教会信息摘要中。

B1 将此时区用于全教会范围的时间，例如活动提醒以及您的 [FreePlay](../../freeplay/scheduled-mode/scheduling-the-calendar.md) 电视上的日程安排。[签到时间表](../attendance/setup.md#setting-a-check-in-schedule)首先以礼拜所在[校区](./campuses.md)的时区计算；只有当该校区未设置时区时，才会使用教会时区。如果您的所有校区都位于同一时区，请同时在教会和每个校区上进行设置。

## 地区（日期和电话格式）

**地区** 设置用于控制整个 B1 中日期和时间的书写方式。默认情况下，日期采用美国格式（例如"Sep 28, 2026"和"9/28/2026"）。美国以外的教会可以切换为其本国格式 —— 例如，选择英语（英国）后，日期会显示为"28 Sept 2026"和"28/09/2026"。

1. 在设置页面，点击左侧列表中的 **地区**，然后点击 **地区** 部分中的 **编辑**。
2. 从 **地区** 下拉菜单中选择您的地区。每个选项都会显示一个示例日期，方便您确认日期的显示效果。
3. 点击 **保存**。

保存后，地区部分会显示您所选的地区、**日期格式**示例以及您的**电话号码**格式。

### 电话号码格式

同一地区部分中的 **电话号码** 设置用于控制人员记录中电话号码的输入方式：

- **国际（含国家代码）** -- 默认选项。电话字段会显示国旗选择器，并以国家代码保存号码（例如 +1 918 555 1234）。
- **本地（按输入保存）** -- 电话字段变为普通文本框，并完全按照您输入的方式保存号码，不会添加国家代码（例如 0701 234 5678）。如果您的教会以本地格式书写号码，且不希望 B1 添加国家代码，请选择此项。

选择 **本地** 后，地区部分还会在您的地区旁边显示"本地电话号码"。

:::tip
当号码包含国家代码时，短信功能效果最佳。如果您通过 B1 发送短信，请保留 **国际** 格式，或确保在本地模式下输入的号码包含国家代码。
:::

您所选的地区会应用于整个 B1 Admin 以及您的 B1.church 网站和会员门户中的日期和时间，包括讲道、博客文章、小组日历和服侍计划，因此会员看到的日期格式与工作人员一致。

## 短信 {#texting}

连接短信服务提供方，即可从 B1 Admin 向个人或整个小组发送短信。短信通过您自己在服务提供方处的账户发送，因此适用其定价和限制。

1. 在设置页面，点击左侧列表中的 **短信**，然后点击 **短信** 部分中的 **编辑**。
2. 选择 **提供方**：
   - **Clearstream** -- 输入 **API 密钥**。请在您的 Clearstream 账户设置的 API Keys 下创建密钥。
   - **Text In Church** -- 输入 **API 密钥**。请先向 Text In Church 支持团队申请开发者 API 访问权限，然后在您账户设置的 Developer API 部分创建密钥。
   - **Nalo Solutions**（加纳）-- 将 Nalo Solutions 账户中的授权密钥作为 **API 密钥** 输入，并输入 Nalo 为您批准的 **发送方 ID**（最多 11 个字符）。
   - **Twilio** -- 使用您教会自己的 Twilio 账户；Twilio 将直接向您收费。从 [Twilio 控制台](https://console.twilio.com)复制 **Account SID** 和 **Auth Token**，并输入 **发送号码** —— 一个已为 A2P 10DLC 注册的 Twilio 电话号码，格式如 `+15551234567`。保存后，请将入站 Webhook 网址（见下文）粘贴到 Twilio 中该号码的 **收到消息时** Webhook 中，以便 STOP 回复也能在 B1 中被记录。
3. 点击 **保存**。

若要停止发送短信，请将 **提供方** 设置为 **无** 并保存。这会移除已保存的提供方。

### 对回复 STOP 的人员退订

保存提供方后，请再次点击 **编辑** 打开短信部分。在提供方设置下方，有一个只读的 **入站（STOP）Webhook 网址** 字段，其中显示一个专属于您教会的网址。点击该字段即可选中网址，复制后粘贴到您的短信服务提供方的入站消息（回复）Webhook 设置中。上述任一服务提供方只要能将收到的回复转发到 Webhook，即可使用此功能。

此后，当有人回复您短信中的 **STOP**（或 STOPALL、UNSUBSCRIBE、CANCEL、END、QUIT、OPTOUT 或 REVOKE）时，B1 会找到所有手机号码匹配的人员，将他们标记为已退订，并关闭其短信提醒。之后，他们会在小组短信中被跳过。其他回复会被忽略。

:::info
此功能使用的退订设置与 **在会员目录中隐藏我** 相同，因此回复 STOP 的人在其个人资料中也会显示为**已从目录中隐藏**。该字段仅在选中已保存的提供方时显示 —— 如果您将下拉菜单切换到其他提供方，请先保存，才能再次看到该网址。
:::

连接提供方后，有权发送短信的工作人员可以在小组页面（**给此小组发送短信**）以及拥有手机号码的个人页面（**发送短信**）上看到 **短信** 按钮。输入您的消息并点击 **发送**。对话框会统计字符数和短信段数。对于小组，它会在发送前显示将收到短信的成员人数：

- 没有登记手机号码的成员会被跳过。
- 选择了**在会员目录中隐藏我**的成员会被视为已退订并跳过。
- 共享同一手机号码的家庭成员只会收到一条短信。

### 使用合并字段个性化短信 {#personalizing-texts-with-merge-fields}

在消息框下方，短信对话框会显示占位符标签：**名字**、**姓氏**、**显示名称** 和 **教会名称**。点击某个标签即可在光标处插入其占位符（`{{firstName}}`、`{{lastName}}`、`{{displayName}}` 或 `{{churchName}}`）。发送短信时，每个占位符都会被替换为该接收人的相应信息，因此像 `Hi {{firstName}}, see you Sunday!` 这样的小组短信会以每位成员各自的姓名送达。占位符既适用于小组短信，也适用于发给单个人的短信。

:::info
1,600 个字符的限制适用于您输入时的消息内容。填入占位符后，任何超过 1,600 个字符的短信都会在该长度处被截断。
:::

短信也可以通过[工作流](../serving/workflows.md#sending-a-text)中的 **发送短信** 步骤自动发出，它使用相同的提供方和占位符。

## 文件存储

默认情况下，您通过[文件](../website/files.md)上传到网站的文件以及其他内容区域的文件，都使用 B1 免费托管存储，最多 100MB。如果您需要更多空间，可以改为连接您自己的云存储 —— 此后新上传的文件将直接保存到您的账户中，不受平台限制。

1. 在设置页面，点击左侧列表中的 **文件存储**，然后点击 **文件存储** 部分中的 **编辑**。
2. 选择提供方：**Google Drive**、**Dropbox**、**OneDrive**，或 **兼容 S3 的存储桶**（AWS S3、Cloudflare R2、Backblaze B2 等）。
3. 对于 Google Drive、Dropbox 或 OneDrive，请点击 **连接** 并登录以授权访问。对于兼容 S3 的存储桶，请输入您的访问密钥、密钥、存储桶名称和公共网址基础路径。
4. 点击 **保存**。

:::info
此设置仅影响您网站文件及类似内容区域中的新上传文件。图库图片、缩略图、标志和人员照片始终保存在 B1 的默认存储中。
:::

## 年级升级

如果您为儿童和学生记录了**年级**，B1 可以在您选择的日期（例如 8 月 1 日）自动将所有人升一个年级，而无需您逐一手动编辑个人资料。

1. 在设置页面，点击左侧列表中的 **年级升级**，然后点击 **年级升级** 部分中的 **编辑**。
2. 打开开关（显示为 **已启用**），并选择每年升级年级的**月份**和**日期**。在该日期，所有有年级的人都会升一个年级，而 12 年级的学生会变为**已毕业**。
3. 保存更改。

要停止自动升级，请关闭开关，使其显示为 **已禁用**，然后保存。升级日期会被移除，年级将不再自动变更。

## 志愿者报名 {#volunteer-signup}

默认情况下，浏览[志愿者报名](../../b1-church/serving/volunteer-signup.md)的会员会看到所有有空缺职位的即将到来的每一周。如果该列表过长，您可以改为仅显示每种计划类型的下一周。

1. 在设置页面，点击左侧列表中的 **志愿者报名**，然后点击 **志愿者报名** 部分中的 **编辑**。
2. 开启 **仅显示每种计划类型的下一周**。
3. 保存更改。

开启后，每种计划类型只会显示其下一个即将到来的计划。下一周的计划会在当前日期过去后出现。该部分的 **显示周数** 一行会显示 **仅每种计划类型的下一周** 或 **所有即将到来的周**。

## 奉献隐私 {#giving-privacy}

拥有奉献访问权限的人通常可以在其[人员记录](../people/adding-people.md#editing-details)上看到该人员的奉献总额。如果您不希望每次打开记录时都显示金额，可以将其隐藏，直到有人主动请求查看。

1. 在设置页面，点击左侧列表中的 **奉献隐私**，然后点击 **奉献隐私** 部分中的 **编辑**。
2. 开启 **在人员记录上隐藏奉献，直到点击查看**。
3. 保存更改。

开启后，人员记录上的奉献卡片会显示"奉献在人员记录中已隐藏"。点击 **显示奉献** 即可加载并显示该人员的奉献。切换到其他人员时，它会再次隐藏。谁可以查看奉献不会改变：只有拥有奉献访问权限的人才能看到该卡片。

## 导入和导出

教会名称下方设置页面中的 **导入/导出** 链接会在新的浏览器窗口中打开一个专门的工具。您可以用它来：

- 从其他教会管理系统导入会员数据。
- 为备份或迁移目的导出您的 ChurchApps 数据。

当您首次设置教会，需要将现有记录转移到 ChurchApps 中时，此功能尤其有用。

:::warning
导入数据时，请务必先备份现有记录。导入操作会向系统添加数据，如果多次运行，可能会产生重复条目。
:::
