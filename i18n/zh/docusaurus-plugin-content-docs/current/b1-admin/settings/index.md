# 设置

<div class="article-intro">

设置部分是您在 B1 Admin 中配置教会帐户、品牌和管理选项的地方。从这里您可以管理从教会名称和子域到用户权限和移动应用配置的所有内容。

</div>

## 您将在这里找到什么

设置区域分为以下子部分：

1. **设置** —— 配置您教会的基本信息、品牌和子域。有关详细信息，请参阅[教会设置](./church-settings.md)。要使用您自己的域名（例如 yourchurch.org），请参阅[自定义域](./custom-domain.md)。
2. **校园** —— 添加和管理教会的多个物理位置。创建后，校园会出现在人员档案上、出席设置中和人口统计学仪表板中。作为主设置页面上的卡片而不是单独的导航项到达。有关详细信息，请参阅[校园](./campuses.md)。
3. **自定义字段** —— 定义您自己的字段以在人员上追踪（日期、数字、是/否答案或选择列表），然后在档案上填充它们并搜索它们。也作为主设置页面上的卡片到达。有关详细信息，请参阅[自定义字段](./custom-fields.md)。
4. **电子邮件模板** —— 保存可重复使用的电子邮件内容以手动或从工作流发送。有关详细信息，请参阅[电子邮件模板](./email-templates.md)。
5. **服务器管理** —— 访问高级管理工具以管理教会的服务器级设置。

:::info
**移动应用**配置和**表单**现在有其自己的顶级导航项——**移动**和**表单**（在**人员**下找到）——而不是存在于设置中。有关详细信息，请参阅[移动应用设置](./mobile-app.md)和[创建表单](/docs/b1-admin/forms/creating-forms)。
:::

## 主设置页面

当您首次打开设置页面时，您将在顶部看到您的**教会名称**和**子域**显示。标题提供常见任务的快速访问按钮：

- **电子邮件模板** —— 直接跳转到电子邮件模板管理。
- **审计日志** —— 查看整个教会帐户所做更改的日志。
- **批次** —— 直接跳转到献金批次。
- **导入/导出** —— 使用导入/导出工具在系统之间传输数据。

在标题下方，打开**教会信息**部分以编辑教会的名称、地址、联系信息和品牌——请参阅[教会设置](./church-settings.md)。要管理用户角色，请单击设置导航栏中的**角色**——请参阅[角色和权限](./roles-permissions.md)。

:::tip
首先在**教会信息**下配置教会名称和品牌，然后设置[角色](./roles-permissions.md)以邀请具有正确访问级别的团队成员。
:::

:::info
有关如何保护您的数据的信息，请参阅[数据安全](./data-security.md)。
:::
