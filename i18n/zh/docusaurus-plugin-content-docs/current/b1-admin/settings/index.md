# 设置

<div class="article-intro">

设置区域是您在 B1 Admin 中配置教会账户、品牌形象和管理选项的地方。从这里,您可以管理从教会名称、子域名到用户权限和移动应用配置的一切内容。

</div>

## 您会在这里找到什么

设置区域从侧边栏可访问,组织为以下几个子部分:

1. **设置**——配置您教会的基本信息、品牌形象和子域名。详见[教会设置](./church-settings.md)。
2. **园区**——为您的教会添加和管理多个实体地点。创建后,园区会出现在个人档案、出勤设置和人口统计仪表盘中。详见[园区](./campuses.md)。
3. **自定义字段**——为人员定义您自己的跟踪字段(日期、数字、是/否问题或选择列表),然后在档案中填写并按其搜索。详见[自定义字段](./custom-fields.md)。
3. **移动应用**——设置并自定义出现在 [B1.church PWA](/docs/b1-church/getting-started/installing-pwa) 中面向您成员的导航标签(相同的标签也会在已弃用的 B1 Mobile 原生应用中呈现)。详见[移动应用设置](./mobile-app.md)。
4. **服务器管理**——访问高级管理工具,管理您教会的服务器级设置。
5. **表单**——创建和管理自定义表单,用于从会众中收集信息。

## 主设置页面

首次打开设置页面时,您会在顶部看到您的**教会名称**和**子域名**。页头提供了常见任务的快捷访问按钮:

- **编辑设置**——更新您教会的名称、地址、联系信息和品牌形象。
- **移动应用**——直接跳转到移动应用配置。
- **角色**——为您的团队管理用户角色和权限。
- **导入/导出**——使用导入/导出工具在系统之间迁移数据。

:::tip
建议先在**编辑设置**下配置好您教会的名称和品牌形象,然后设置[角色](./roles-permissions.md),以合适的访问级别邀请您的团队成员。
:::

:::info
关于您的数据如何受到保护,详见[数据安全](./data-security.md)。
:::
