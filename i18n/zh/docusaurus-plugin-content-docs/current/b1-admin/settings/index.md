# 设置

<div class="article-intro">

设置板块用于在 B1 Admin 中配置教会的账户、品牌和管理选项。在这里，您可以管理从教会名称和子域名，到用户权限和移动应用配置的一切内容。

</div>

## 这里包含的内容

设置区域分为以下几个子部分：

1. **Settings**（设置）——配置教会的基本信息、品牌、子域名、地区（日期和电话格式）、短信服务提供商和文件存储。详情请参见[教会设置](./church-settings.md)。若要使用您自己的域名（例如 yourchurch.org），请参见[自定义域名](./custom-domain.md)。
2. **Campuses**（校区）——添加和管理教会的多个实体地点。创建后，校区会出现在人员个人资料、出勤设置和人口统计仪表板中。它是主设置页面上的一个部分，而不是单独的导航项。详情请参见[校区](./campuses.md)。
3. **Custom Fields**（自定义字段）——定义您想为人员跟踪的自定义字段（日期、数字、是/否答案或下拉列表），然后在个人资料中填写并基于它们进行搜索。它同样是主设置页面上的一个部分。详情请参见[自定义字段](./custom-fields.md)。
4. **Email Templates**（邮件模板）——保存可重复使用的邮件内容，用于手动发送或从工作流发送。详情请参见[邮件模板](./email-templates.md)。
5. **Audit Log**（审计日志）和 **Batches**（批次）——查看您账户中所做的变更（[审计日志](../reports/audit-log.md)），以及查看或撤销批量导入和操作（**Batches**）。
6. **Server Admin**（服务器管理）——访问用于管理教会服务器级设置的高级管理工具。

:::info
**Mobile Apps**（移动应用）配置和**表单**现在拥有各自的顶级导航项——**Mobile**（移动端）和 **Forms**（表单，位于 **People** 下）——而不再位于设置中。详情请参见[移动应用设置](./mobile-app.md)和[创建表单](/docs/b1-admin/forms/creating-forms)。
:::

## 主设置页面

打开设置页面时，左侧面板会显示您的**教会名称**、**子域名**和地址，并附有 **Import/Export**（导入/导出）链接，可打开用于在不同系统之间迁移数据的导入导出工具。

在此之下，**Configuration**（配置）列表会链接到每个设置部分：**Church Information**（教会信息）、**General**（常规）、**Region**（地区）、**Giving**（奉献）、**Texting**（短信）、**File Storage**（文件存储）、**Domains**（域名）、**Grade Promotion**（升级）、**Check-In**（签到）、**Campuses**（校区）、**Custom Fields**（自定义字段）和 **Developer**（开发者）。仍需设置的部分（例如 Giving、Texting 或 Domains）会以一个小圆点标记。所有部分都位于同一页面上——点击列表中的名称即可滚动到对应位置，或直接向下滚动。每个部分都会显示当前的设置；点击某个部分中的 **Edit** 即可进行更改。

**Email Templates**、**Audit Log** 和 **Batches** 是独立的页面——请通过[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)中 **Settings** 下的入口打开。

请从 **Church Information** 部分开始，编辑您教会的名称、地址和联系信息——参见[教会设置](./church-settings.md)。若要管理用户角色，请打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)并选择 **Settings > Roles**——参见[角色与权限](./roles-permissions.md)。

:::tip
首先在 **Church Information** 下配置您的教会名称和品牌，然后设置[角色](./roles-permissions.md)，以适当的访问权限邀请您的团队成员。
:::

:::info
关于您的数据如何受到保护，请参见[数据安全](./data-security.md)。
:::
