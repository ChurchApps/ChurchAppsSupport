# 设置

<div class="article-intro">

设置部分是你在 B1 Admin 中配置教会帐户、品牌和管理选项的地方。从这里你可以管理从你的教会名称和子域到用户权限和移动应用配置的所有内容。

</div>

## 你会在这里找到什么

设置区域组织为以下子部分：

1. **设置** -- 配置你的教会的基本信息、品牌、子域、区域（日期和电话格式）、短信提供商和文件存储。详见[教会设置](./church-settings.md)。要使用你自己的域名（例如 yourchurch.org），参见[自定义域](./custom-domain.md)。
2. **校园** -- 为你的教会添加并管理多个物理位置。创建后，校园出现在人员档案、出席设置和人口统计学仪表板中。作为主设置页面上的卡片而不是单独的导航项目到达。详见[校园](./campuses.md)。
3. **自定义字段** -- 定义你自己的字段来在人员上追踪（日期、数字、是/否答案或选项列表），然后在档案上填补它们并在其上搜索。也作为主设置页面上的卡片到达。详见[自定义字段](./custom-fields.md)。
4. **电子邮件模板** -- 保存可重复使用的电子邮件内容以手动或从工作流发送。详见[电子邮件模板](./email-templates.md)。
5. **服务器管理员** -- 访问高级管理工具以管理你的教会的服务器级设置。

:::info
**移动应用**配置和**表单**现在有自己的顶级导航项 -- **移动**和**表单**（在**人员**下找到）-- 而不是住在设置内。详见[移动应用设置](./mobile-app.md)和[创建表单](/docs/b1-admin/forms/creating-forms)。
:::

## 主设置页面

当你首次打开设置页面时，你会看到你的**教会名称**和**子域**显示在顶部。标题提供常见任务的快速访问按钮：

- **电子邮件模板** -- 直接跳转到电子邮件模板管理。
- **审计日志** -- 查看跨你的教会帐户进行的更改的日志。
- **批次** -- 直接跳转到捐赠批次。
- **导入/导出** -- 使用导入/导出工具在系统之间传输数据。

在标题下方，打开**教会信息**部分以编辑你的教会的名称、地址、联系信息和品牌 -- 参见[教会设置](./church-settings.md)。要管理用户角色，打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)并选择**设置 > 角色** -- 参见[角色和权限](./roles-permissions.md)。

:::tip
从**教会信息**下配置你的教会名称和品牌开始，然后设置[角色](./roles-permissions.md)以邀请你的团队成员获得正确的访问级别。
:::

:::info
有关你的数据如何被保护，参见[数据安全](./data-security.md)。
:::
