# 崇拜流程

<div class="article-intro">

崇拜流程定义了您崇拜服事中各元素的顺序。使用它来安排从开场歌曲到闭会祷告的每一项内容,让您的整个团队都能提前了解服事的流程。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 为您要构建崇拜流程的日期[创建一个服事计划](./plans.md)
- (可选)将[歌曲](./songs.md)添加到您的曲库中,以便直接链接到崇拜流程中

</div>

## 访问崇拜流程

1. 导航到**事工服事**并选择您的事工。
2. 点击一种**计划类型**,然后打开某个具体的**计划**。
3. 点击计划详情页面上的**崇拜流程**标签页。

## 构建您的崇拜流程

崇拜流程是按服事期间发生顺序排列的项目列表。常见的元素包括:

- 敬拜歌曲
- 祷告
- 经文诵读
- 公告
- 讲道或信息
- 奉献
- 结束

## 向崇拜流程添加项目

1. 在**崇拜流程**标签页,点击**添加项目**。
2. 选择您想添加的元素类型(例如,来自曲库的歌曲、自定义项目或标题)。
3. 输入该项目的详细信息,如标题和任何备注。
4. 点击**保存**。

:::tip
您可以直接从[歌曲](./songs.md)曲库添加歌曲。这会将歌曲详情(包括歌词和编配)链接到您的服事计划,让您的敬拜团队掌握所需的一切信息。
:::

## 重新排序项目

拖动每一行左侧的手柄以重新排列顺序——将其放到您想让项目落地的蓝线上,或放到某个分区标题上以将其移入该分区。屏幕上显示的顺序就是您的团队在服事期间将遵循的顺序。

## 时长与媒体

每个项目和分区都会显示它运行多长时间以及何时开始:

- 如果计划选定了单一服事时间,左侧栏会显示每个项目开始的实际**时钟时间**(例如上午 9:14)。否则会显示相对于服事开始的经过时间。
- 分区标题会汇总其内部所有项目的运行时长。
- 歌曲和自定义项目只有在项目编辑界面中填入**分钟**/**秒**后才会计入此时间表。
- 您从媒体库(图片或视频片段)添加的项目会显示**缩略图**并自动计时——视频的时长是根据文件本身测量的,而图片则贡献约 5:00 的规划估计时长(以斜体显示),因为它会一直停留在屏幕上,直到操作员手动切换。您仍然可以将两者都编辑为特定的时长。

## 编辑与删除项目

- 点击崇拜流程中的任意项目以**编辑**其详情。
- 使用**删除**选项从流程中移除某个项目。

:::info
崇拜流程是针对每个计划单独设置的。您在此处所做的更改只影响所选计划,不会改动其他计划或您的歌曲曲库。
:::

## 让项目仅出现在特定服事时间

如果您的计划有多个服事时间(例如上午 8 点和上午 10 点两场),您可以选择每个项目应出现在哪些场次中。这在某条公告只与某一场服事相关,或某首歌只在一场唱而另一场不唱时非常有用。

1. 打开一个在**时间**标签页中定义了两个或以上服事时间的计划。
2. 在**崇拜流程**标签页,点击某个项目进行编辑。
3. 在**包含在以下服事场次**下,您会看到每个服事时间对应一个复选框,并标注了时间。
4. 取消勾选该项目应跳过的场次。
5. 点击**保存**。

默认情况下,每个项目都会包含在每一场服事中。当您按某一场服事筛选并打印计划时,被排除的服事场次会被隐藏,这样每场服事都能拿到一份只包含相关项目的干净流程单。

:::tip
只有当计划包含多个服事时间时,**包含在以下服事场次**部分才会出现。如果您只看到一个服事场次,请先在计划的**时间**标签页中添加更多场次。
:::

## 分享崇拜流程

崇拜流程完成后,您可以从计划详情页面打印完整的计划(包括崇拜流程)。这能让您的团队获得一份完整的服事概览。

## 后续步骤

- 为与该服事相关的后续事项创建[任务](./tasks.md)
