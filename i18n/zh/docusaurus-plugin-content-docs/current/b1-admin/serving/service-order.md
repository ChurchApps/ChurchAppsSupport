# 服务顺序

<div class="article-intro">

服务顺序定义了你的敬拜服务中元素的序列。使用它来排列从开场歌曲到结束祷告的一切，以便你的整个团队提前知道服务的流程。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [为你想构建服务顺序的日期创建服务计划](./plans.md)
- 可选地，向你的库添加[歌曲](./songs.md)，以便你可以将它们直接链接到服务顺序中

</div>

## 访问服务顺序

1. 导航到**服侍**并选择你的事工。
2. 点击**计划类型**，然后打开特定的**计划**。
3. 点击计划详细页面上的**服务顺序**标签。

## 构建你的服务顺序

服务顺序是按照他们在服务期间发生的序列排列的项目列表。常见元素包括：

- 敬拜歌曲
- 祷告
- 经文阅读
- 公告
- 讲道或信息
- 奉献
- 结束

## 向服务顺序添加项目

1. 在**服务顺序**标签上，点击**添加项目**。
2. 选择你想添加的元素类型（例如，来自你的库的歌曲、自定义项目、标题或**外部项目**）。
3. 输入项目的详细信息，例如标题和任何注释。
4. 点击**保存**。

:::tip
你可以直接从你的[歌曲](./songs.md)库中添加歌曲。这将歌曲详细信息（包括歌词和编排）链接到你的服务计划，以便你的敬拜团队拥有他们所需的一切。
:::

### 从外部提供商导入多个项目

选择**外部项目**会打开你的链接课程提供商的浏览器，而不是单项表单。浏览（或搜索）进入提供商的内容，并检查你想要的每个部分或操作旁边的框。对话框追踪你已选择的数量（例如，"已选择3个"）-- 点击**导入(3)**一次将所有内容添加到服务顺序，而不是对每个内容重复添加项目流程。

:::tip
这是在一次通过中将整个课程的部分和提示拉入服务顺序的最快方式，而不是逐个添加每个项目。
:::

## 重新排列项目

通过每行左侧的手柄拖动项目来重新排列顺序 — 放在你想要项目着陆的蓝线上，或放在部分标题上以将其移入该部分。屏幕上显示的序列是你的团队在服务期间将遵循的顺序。

## 编辑课程部分

课程和课程部分（例如，"大组"或"参与1"）持有他们自己的脚本行、幻灯片和视频。要改变其中的内容，点击服务顺序中的部分。该部分打开显示其中的一切：讲话和指示行显示为标记为**说**、**做**或**注意**的完整文本，幻灯片或视频显示带有缩略图。

- 点击任何行旁边的**x**将其从你的计划中移除。它停留在列表中，被删除，带有一个箭头将其放回。
- 点击任何文本以改变措辞。改写的行提供**恢复原始措辞**。
- 点击**保存**。该部分在你的服务顺序中保持为单行，带有小标签如**8个项目中的6个**，表明你已自定义它，其运行时间更新。

在任何时间再次打开该部分以查看你的更改，放回行，或选择**恢复原始部分**以撤销所有更改。你的编辑仅影响你的计划 -- 原始课程永远不会被改变 -- 并且它们贯穿到打印计划和你的志愿者看到的内容。

如果你需要该部分中的项目作为其自己的行（例如，在两行之间放置一首歌），点击部分行右端的箭头以将其内容显示为单独的行。点击这些行中第一行的箭头以将它们折叠回一个。这对来自任何连接提供商的内容都以相同方式工作。

分配给一个项目的志愿者会在服务顺序中显示在它旁边，所以任何审查计划的人都可以一目了然地看到谁覆盖每个部分。

## 计时和媒体

每个项目和部分显示它运行多长时间以及何时开始：

- 如果计划选择了单个服务时间，左边栏显示每个项目开始的实际**时钟时间**（例如，上午9:14）。否则它显示从服务开始的经过时间。
- 部分标题汇总它们内部所有内容的运行时间。
- 歌曲和自定义项目在你在项目的编辑屏幕上输入**分钟**/**秒**后计入此时间表。
- 你从你的媒体库添加的项目（图像或视频剪辑）显示**缩略图**并自动计时 — 视频的持续时间是从文件本身测量的，而图像贡献约5:00规划估计（以斜体显示）因为它保留在屏幕上直到操作员推进它。你仍然可以将任一编辑为特定持续时间。

## 编辑和删除项目

- 点击服务顺序中的任何项目以**编辑**其详细信息。
- 使用**删除**选项从顺序中删除项目。

:::info
服务顺序是特定于每个计划的。你在这里做的更改仅影响选定的计划，不会改变其他计划或你的歌曲库。
:::

### 批量选择和删除项目

要一次清除一个部分中的多个项目，而不是逐个删除它们：

1. 点击部分标题上的**选择项目**。
2. 检查你想删除的项目，或检查**选择部分中的全部**以直接获取该部分下的所有内容。
3. 点击**删除选定项**并确认。
4. 点击**完成选择**以退出选择模式。

:::info
批量选择仅应用于部分的直接子项，不是嵌套在子部分文件夹内的项目。
:::

## 在特定服务时间中包括项目

如果你的计划有多个服务时间（例如，上午8点和上午10点服务），你可以选择每个项目应出现在哪些服务中。这在公告仅与一项服务相关，或歌曲在一项服务中唱但不在另一项服务中唱的情况下很有用。

1. 打开一个计划，该计划在**时间**标签上定义了两个或多个服务时间。
2. 在**服务顺序**标签上，点击一个项目来编辑它。
3. 在**在服务中包括**下，你会看到每个服务时间的复选框，标记有时间。
4. 取消检查该项目应被跳过的任何服务。
5. 点击**保存**。

默认情况下，每个项目都包括在每项服务中。排除的服务时间在你打印过滤到该服务的计划时被隐藏，所以每项服务会收到一个仅包含相关项目的干净运行表。

:::tip
**在服务中包括**部分仅在计划有多个服务时间时出现。如果你只看到一项服务，编辑计划的**时间**标签首先添加额外的服务。
:::

### 为每项服务显示不同的职位

如果一个项目设置了**职位**，**在服务中包括**中的每个选中服务时间也会获得自己的**此服务的职位**下拉列表。当同一部分在每项服务中由不同的志愿者覆盖时使用它 -- 将其保留为**与上面相同**以保持项目的默认职位，或选择不同的职位仅为该服务时间覆盖它。

## 共享服务顺序

一旦你的服务顺序完成，你可以从计划详细页面打印完整计划（包括服务顺序）。这给你的团队完整的服务说明。当**显示志愿者姓名**在打印中打开时，每个部分标题也会打印，旁边是分配的志愿者的职位，以便你的团队可以看到谁覆盖该部分，而无需打开应用。如果标题的职位在特定服务中被覆盖，打印会显示它在该计划上的服务中解析到的每个不同的职位名称（例如，"敬拜团队/青年团队"）。
