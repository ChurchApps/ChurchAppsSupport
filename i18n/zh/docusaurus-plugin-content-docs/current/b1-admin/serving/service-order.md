# 服务流程

<div class="article-intro">

服务流程定义了敬拜服务中各个环节的顺序。您可以用它规划从开场诗歌到结束祷告的每个环节，让整个团队提前了解服务的流程。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [为您想要制定服务流程的日期创建服务计划](./plans.md)
- （可选）将[诗歌](./songs.md)添加到您的曲库中，以便将其直接链接到服务流程中

</div>

## 访问服务流程

1. 前往**服侍**，并选择您的事工。
2. 点击某个**计划类型**，然后打开特定的**计划**。
3. **服务流程**部分位于计划页面的顶部，在**服侍团队安排**上方。

## 制定您的服务流程

服务流程是一个按照服务中将要发生的先后顺序排列的项目列表。常见的环节包括：

- 敬拜诗歌
- 祷告
- 经文朗读
- 公告
- 讲道或信息
- 奉献
- 结束

## 向服务流程添加项目

1. 在**服务流程**部分，点击**添加**并选择要添加的内容：**添加章节**（用于对项目进行分组的标题）、**项目**（自定义项目）、**诗歌**（来自您的曲库）或**从课程添加**。您也可以直接点击**添加章节**。
2. 若要在某个章节内添加内容，请使用该章节标题上的添加菜单，并选择**诗歌**、**项目**或**外部项目**。
3. 输入项目的详细信息，例如标题和任何备注。
4. 点击**保存**。

:::tip
您可以直接从您的[诗歌](./songs.md)曲库中添加诗歌。这会将诗歌的详细信息（包括歌词和编曲）链接到您的服务计划中，让您的敬拜团队拥有所需的一切。
:::

### 从外部提供方批量导入多个项目

选择**外部项目**（或**从课程添加**）会打开您已连接的课程提供方的浏览器，而不是单个项目的表单。浏览（或搜索）提供方的内容，并勾选您想要添加的每个章节或操作旁边的复选框。对话框会统计您已选择的数量（例如"已选 3 项"）-- 点击**导入（3）**即可一次性将所有项目添加到服务流程中，而无需对每个项目重复添加流程。

一些提供方（例如 GO! Curriculum、Dropbox、Google Drive 和 OneDrive）会将课程作为一组文件（视频、幻灯片、图片）提供，而不是按章节划分。在**从课程添加**中浏览这些提供方时，文件会与文件夹一并显示 -- 点击某个文件，即可将其作为独立项目添加到服务流程中。

:::tip
这是一次性将整节课的章节和提示全部导入服务流程的最快方式，无需逐个添加项目。
:::

### 自定义已链接的课程

当计划中链接了课程时，服务流程会首先显示该课程的**课程预览**。点击**自定义**（或添加章节、项目或诗歌），即可将课程的章节复制到计划中，以便进行编辑。对于仅包含文件列表的课程（例如 GO! Curriculum 课程），这些文件会归入一个以该课程命名的章节下，因此您仍然有一个章节栏可用于添加自己的项目。

## 调整项目顺序

拖动每一行左侧的把手即可重新排列顺序 -- 将其放到您希望项目落入位置的蓝色线上，或放到章节标题上，即可将其移入该章节。屏幕上显示的顺序，就是您的团队在服务期间将遵循的顺序。

## 编辑课程章节

课程和课程教材章节（例如"大组"或"Engage 1"）包含其自己的讲解台词、幻灯片和视频。若要更改其中的内容，请在服务流程中点击该章节。章节会打开并显示其中的全部内容：口头和指导性台词以完整文本显示，并标有**说**、**做**或**备注**，幻灯片或视频则以缩略图显示。

- 点击任意台词旁边的 **x**，即可将其从您的计划中移除。该台词会保留在列表中，并带有删除线，同时附有一个可将其恢复的箭头。
- 点击任意文字即可改写。改写过的台词会提供**恢复原文**选项。
- 点击**保存**。该章节在服务流程中仍保持为单行，并会显示一个小标签（例如 **6 / 8 项**），表示您已自定义该章节，其运行时间也会随之更新。

您可以随时重新打开该章节，以查看您的更改、恢复台词，或选择**恢复原始章节**以撤销所有更改。您的编辑只影响您的计划 -- 原始课程永远不会被更改 -- 并且这些编辑会延续到打印的计划以及志愿者所看到的内容中。

如果您需要将该章节中的某个项目作为独立的行（例如，将一首诗歌放在两句台词之间），请点击章节行右端的箭头，以将其内容显示为独立的行。点击其中第一行的箭头，即可将它们重新折叠为一行。此操作对任何已连接提供方的内容同样适用。

分配给某个项目的志愿者会显示在服务流程中该项目的旁边，因此任何查看计划的人都能一目了然地看到每个部分由谁负责。

## 时间与媒体

每个项目和章节都会显示其运行时长及开始时间：

- 如果计划中只选择了一个服务时间，左侧栏会显示每个项目开始的实际**钟点时间**（例如上午 9:14）。否则，显示的是从服务开始算起的已过时间。
- 章节标题会汇总其中所有内容的运行时间。
- 诗歌和自定义项目在您于该项目的编辑界面中输入**分钟**/**秒**后，才会计入此日程。
- 您从媒体库中添加的项目（图片或视频片段）会显示**缩略图**，并自动计时 -- 视频的时长从文件本身测量，而图片则计为约 5:00 的计划估时（以斜体显示），因为图片会一直显示直到操作员切换。您仍然可以将这两者编辑为指定的时长。

## 编辑和移除项目

- 点击服务流程中的任意项目，即可**编辑**其详细信息。
- 使用**删除**选项，即可从流程中移除项目。

:::info
服务流程仅针对每个计划。您在此处所做的更改只会影响所选的计划，不会改变其他计划或您的诗歌曲库。
:::

### 批量选择并删除项目

若要一次清除某个章节中的多个项目，而不必逐个删除：

1. 点击章节标题上的**选择项目**。
2. 勾选您要移除的项目，或勾选**选择本章节全部**，以选中该章节直接包含的所有内容。
3. 点击**删除所选**并确认。
4. 点击**完成选择**以退出选择模式。

:::info
批量选择仅适用于章节的直接子项，不包括嵌套在子章节文件夹中的项目。
:::

## 将项目包含在特定服务时间中

如果您的计划有多个服务时间（例如上午 8 点和上午 10 点的服务），您可以选择每个项目应出现在哪些服务中。当某则通知只与一个服务相关，或某首诗歌只在一个服务中演唱而不在另一个服务中演唱时，这一功能非常有用。

1. 打开一个有两个或更多服务时间的计划。点击**服侍团队安排**部分中的**时间**，即可查看或添加服务时间。
2. 在**服务流程**部分，点击某个项目进行编辑。
3. 在**包含于服务**下，您会看到每个服务时间对应的一个复选框，并标有该时间。
4. 取消勾选应跳过的服务。
5. 点击**保存**。

默认情况下，每个项目都包含在每个服务中。当您按某个服务筛选打印计划时，会隐藏未包含该服务的项目，从而使每个服务都能拿到只包含相关项目的干净流程单。

:::tip
只有当计划有多个服务时间时，才会显示**包含于服务**部分。如果您只看到一个服务，请先点击计划的**服侍团队安排**部分中的**时间**，添加其他服务。
:::

### 为每个服务设置不同的职位

如果某个项目设置了**职位**，那么在**包含于服务**中每个被勾选的服务时间，还会各自显示一个**该服务的职位**下拉菜单。当同一章节在每个服务中由不同的志愿者负责时，可使用此功能 -- 保持**同上**即可沿用项目的默认职位，或选择其他职位，仅针对该服务时间进行覆盖。

## 分享服务流程

服务流程完成后，您可以点击计划页面顶部的**打印**按钮，打印完整计划（包括服务流程）。这会为您的团队提供一份完整的服务概览，标题处显示您教会的名称和计划名称。打印时如果开启了**显示志愿者姓名**，每个章节标题也会打印出分配的志愿者职位，这样团队无需打开应用即可看出谁负责该章节。如果某个标题的职位在特定服务中被覆盖，打印内容会列出该计划中各服务所解析出的每个不同职位名称（例如"敬拜团队 / 青年团队"）。
