# 服务顺序

<div class="article-intro">

服务顺序定义了您敬拜服务中的元素序列。使用它来列出从开场歌曲到闭幕祷告的所有内容，以便您的整个团队提前知道服务的流程。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [创建服务计划](./plans.md)来为您想建立服务顺序的日期创建
- 可选择将[歌曲](./songs.md)添加到您的库中，以便您可以直接将它们链接到服务顺序

</div>

## 访问服务顺序

1. 导航到**服侍**并选择您的事工。
2. 点击**计划类型**，然后打开特定的**计划**。
3. 点击计划详情页面上的**服务顺序**选项卡。

## 建立您的服务顺序

服务顺序是按照它们在服务期间出现的顺序排列的项目列表。常见的元素包括：

- 敬拜歌曲
- 祷告
- 经文阅读
- 公告
- 讲道或信息
- 奉献
- 闭幕

## 向服务顺序添加项目

1. 在**服务顺序**选项卡上，点击**添加项目**。
2. 选择要添加的元素类型（例如，来自库的歌曲、自定义项目、标题或**外部项目**）。
3. 输入项目的详细信息，例如标题和任何说明。
4. 点击**保存**。

:::tip
您可以直接从[歌曲](./songs.md)库添加歌曲。这将歌曲详细信息（包括歌词和编排）链接到您的服务计划，以便您的敬拜团队拥有他们需要的所有内容。
:::

### 从外部提供商导入多个项目

选择**外部项目**会打开一个用于您链接的课程提供商的浏览器，而不是单个项目表单。浏览（或搜索）提供商的内容，并在您想要的每个部分或操作旁边勾选框。对话框跟踪您选择了多少个（例如，"3个已选择"）-- 点击**导入（3）**来一次性将所有这些添加到服务顺序，而不是对每个重复添加项目流程。

:::tip
这是将整个课程的部分和提示拉入服务顺序的最快方法，一次通过，而不是逐个添加每个项目。
:::

## 重新排序项目

通过每行左侧的句柄拖动项目来重新排列顺序 -- 将其放到您想要项目落地的蓝线上，或放到部分标题上以将其移动到该部分。屏幕上显示的序列是您的团队在服务期间将遵循的顺序。

## 编辑课程部分

课程和课程部分（例如，"大组"或"参与1"）拥有自己的脚本行、幻灯片和视频。要更改其中内容，请点击服务顺序中的部分。该部分打开显示其中的所有内容：口头和指令行显示为标记为**说**、**做**或**注意**的完整文本，幻灯片或视频出现时带有缩略图。

- 点击任何行旁边的**x**将其从您的计划中移除。它保持在列表中，被划掉，带有箭头可以将其放回。
- 点击任何文本来改写它。改写的行提供**恢复原始措辞**。
- 点击**保存**。该部分在您的服务顺序中保持为单行，带有小标签如**8个项目中的6个**显示您已自定义它，其运行时间会更新。

随时再次打开部分以查看您的更改、放回行，或选择**恢复原始部分**来撤销所有更改。您的编辑仅影响您的计划 -- 原始课程永远不会改变 -- 并且它们会传递到打印的计划和您的志愿者看到的内容。

如果您需要一个项目作为自己的行（例如，在两行之间放一首歌曲），请点击部分行右端的箭头来将其内容显示为单独的行。点击这些行中第一行的箭头将它们折叠回一个。这对来自任何连接的提供商的内容也适用。

分配给项目的志愿者会显示在服务顺序中它的旁边，所以任何审查计划的人都可以看到谁在一目了然的每个部分。

## 时间和媒体

每个项目和部分显示它运行多长时间以及何时开始：

- 如果计划选择了单个服务时间，左边栏显示每个项目开始的实际**时钟时间**（例如，上午9:14）。否则它显示从服务开始的经过时间。
- 部分标题合计其中所有内容的运行时间。
- 歌曲和自定义项目在您在项目编辑屏幕上输入**分钟**/**秒**后计入此时间表。
- 您从媒体库添加的项目（图像或视频剪辑）显示**缩略图**并自动计时 -- 视频的时长从文件本身测量，而图像贡献约5:00规划估计（以斜体显示）因为它保持在屏幕上直到操作员推进它。您仍然可以将任何一个编辑为特定持续时间。

## 编辑和移除项目

- 点击服务顺序中的任何项目来**编辑**其详细信息。
- 使用**删除**选项来从顺序中移除项目。

:::info
服务顺序特定于每个计划。您在此所做的更改仅影响所选计划，不会改变其他计划或您的歌曲库。
:::

### 批量选择和删除项目

要一次清除部分中的多个项目，而不是逐个删除它们：

1. 点击部分标题上的**选择项目**。
2. 检查要移除的项目，或检查**选择部分中的全部**来直接抓住该部分下的所有内容。
3. 点击**删除已选择的**并确认。
4. 点击**完成选择**来退出选择模式。

:::info
批量选择仅适用于部分的直接子项，不适用于嵌套在子部分文件夹中的项目。
:::

## 在特定服务时间中包含项目

如果您的计划有多个服务时间（例如，上午8点和上午10点的服务），您可以选择每个项目应该出现在哪些服务中。当公告仅与一项服务相关时，或在一项服务中唱歌但在另一项服务中不唱歌时，这很有用。

1. 打开一个在**分配**选项卡的**时间**卡中定义了两个或多个服务时间的计划。
2. 在**服务顺序**选项卡上，点击一个项目来编辑它。
3. 在**包含在服务中**下，您将看到每个服务时间的复选框，标记为时间。
4. 取消选中应跳过项目的任何服务。
5. 点击**保存**。

默认情况下，每个项目都包含在每项服务中。排除的服务时间在您打印过滤到该服务的计划时被隐藏，因此每项服务都会收到仅包含相关项目的干净运行表。

:::tip
**包含在服务中**部分仅在计划有多个服务时间时出现。如果您只看到一项服务，请使用计划**分配**选项卡上的**时间**卡来首先添加其他服务。
:::

### 为每项服务显示不同的位置

如果项目设置了**位置**，**包含在服务中**中的每个选定的服务时间也会获得其自己的**此服务的位置**下拉菜单。当同一部分由每项服务的不同志愿者覆盖时使用它 -- 将其设置为**与上面相同**来保持项目的默认位置，或选择不同的位置来仅对该服务时间覆盖它。

## 分享服务顺序

一旦您的服务顺序完成，您可以从计划详情页面打印完整计划（包括服务顺序）。这为您的团队提供了完整的服务摘要，由您教会的名称和计划的名称标题。当**显示志愿者名称**打开时进行打印，每个部分标题也打印时会在其旁边显示分配的志愿者的位置，以便您的团队可以看到谁在该部分而无需打开应用程序。如果标题的位置对于特定服务被覆盖，打印会显示它在该计划上的服务中解析到的每个不同位置名称（例如，"敬拜团队 / 青年团队"）。
