# 从 Lessons.church 安排课程

<div class="article-intro">

B1 Admin 与 [Lessons.church](https://lessons.church) 直接集成，因此您可以直接在服务计划中为教室安排课程。这样，志愿者、分配安排和课程内容都能集中在一个地方。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在服事区域中设置您的事工
- 拥有一个有效的 [Lessons.church](https://lessons.church) 账户——如果您的教会还没有账户，请先在该网站注册

</div>

:::tip 跟随分步指南操作
想从头到尾了解完整的设置流程吗？我们的 **<a href="/guides/freeplay-b1admin" target="_blank">分步指南</a>** 涵盖了连接提供商、安排课程，以及将 FreePlay 连接到您的教室电视——附有简短视频和书面步骤，您可以边做边勾选。
:::

## 第 1 步 —— 关联您的 Lessons.church 账户

每个事工只需进行一次此设置。在浏览和安排内容之前，您需要先连接您的 Lessons.church 账户。

1. 登录 [B1 Admin](https://admin.b1.church/)，进入 **Serving（服事）**
2. 打开您想要连接的事工（例如儿童事工）
3. 向下滚动到 **Content Providers（内容提供商）** 部分
4. 点击 **Link New Provider（关联新提供商）**
5. 从列表中选择 **Lessons.church**
6. 屏幕上会出现一个带有代码的设备授权页面
7. 前往 [lessons.church](https://lessons.church)，登录并输入代码以授权连接
8. 获得批准后，您将在 B1 Admin 中看到 Lessons.church 下方显示 **Linked（已关联）**

:::info
内容提供商部分按事工划分。如果您有多个事工（例如儿童和青少年），则需要为每个事工分别关联 Lessons.church。
:::

Lessons.church 并不是唯一的选择。同一个 **Link New Provider** 列表还提供其他课程和文件来源，包括 SignPresenter、The Bible Project、Jesus Film Project、Go Curriculum、Dropbox、Google Drive 和 OneDrive。关联方式都相同，关联后它们会作为提供商出现，供您在选择课程时切换使用。

## 第 2 步 —— 安排课程

关联完成后，您可以直接从计划中安排课程。

1. 在 B1 Admin 中，进入 **Serving → Plans（服事 → 计划）**
2. 选择您事工的标签，然后点击 **Add Plan Type（添加计划类型）**（如果该事工还没有计划类型，则点击 **Create Plan Type（创建计划类型）**）——为计划类型命名，例如"儿童主日学"或"主日学校"
3. 点击您刚创建的计划类型，然后点击 **Schedule Lesson（安排课程）**。在此菜单中，您可以安排单节课程、批量安排一个系列，或者选择 **Apply Year Plan（应用年度计划）**，从 Lessons.church 载入一个已发布的年度课程序列。
4. 选择课程的**日期**（默认为即将到来的主日）
5. 点击 **Select Lesson（选择课程）**——会打开一个内容浏览对话框
6. 对话框会默认选择 **Lessons.church** 作为提供商（或此计划类型之前课程所使用的提供商）。如果您关联了其他提供商，可以在对话框顶部切换
7. 浏览内容：
   - 选择一个 **Program（课程项目）**（例如"Bible Stories for Kids（儿童圣经故事）"）
   - 在该课程项目中选择一个 **Study（学习单元）**（例如"Creation and Early Stories（创世与早期故事）"）
   - 选择具体的 **Lesson（课程）**
   - 选择 **Venue（教室版本）**——即适合该年龄段的课程版本

   其他提供商的内容组织方式有所不同。例如，**Go Curriculum** 先选择 **Elementary（小学）** 或 **Preschool（学前）**，然后是系列，最后才是课程本身——没有教室版本可选。
8. 点击 **Associate Lesson（关联课程）** 确认
9. 为志愿者选择**复制选项**：
   - **Nothing（不复制）** —— 全新计划，不带入任何志愿者
   - **Positions Only（仅职位）** —— 从上一个计划复制志愿者职位，但不复制具体的分配人员
   - **Positions and Assignments（职位和分配）** —— 同时复制职位和已分配的志愿者 *（最常用）*
10. 点击 **Save（保存）**

计划会自动创建并命名（例如"Feb 23 - Elementary"）。志愿者可以打开计划查看自己的分配，并在主日之前浏览课程内容。

:::warning
请务必为您教室的年龄段选择正确的 **Venue（教室版本）**。选错教室版本意味着您的志愿者会看到为其他年龄段设计的内容。
:::

## 批量安排系列课程

若要一次安排同一系列中的多节课程，请点击 **Schedule Lesson → Bulk Schedule（批量安排）**：

1. 在 **Starting Lesson（起始课程）** 下，点击 **Select Lesson（选择课程）**，选择您想要安排的第一节课
2. 设置 **Start Date（开始日期）**，并选择 **Interval（间隔）**（**Weekly（每周）** 或 **Bi-Weekly（每两周）**）
3. 选择要从上一个计划复制的内容（**Nothing（不复制）**、**Positions Only（仅职位）** 或 **Positions and Assignments（职位和分配）**）
4. 检查列表——起始课程及该系列的其余课程，每节都带有日期。取消勾选您想跳过的课程
5. 点击 **Save（保存）**，为每节课创建一个计划

对于 Lessons.church，列表还会显示每节课将使用的 **Venue（教室版本）**，系统会根据名称与您为起始课程选择的教室版本进行匹配（如果某节课没有该版本，则会使用其他版本，并标记为 **substituted（已替换）**）。没有教室版本层级的提供商（例如 Go Curriculum）会直接安排课程，此时 Venue 列会被隐藏。

## 应用年度计划

如果某个课程出版商已在 Lessons.church 上发布了年度计划，您可以一步将整个序列载入此计划类型：

1. 点击 **Schedule Lesson → Apply Year Plan（应用年度计划）**
2. 选择已发布的年度计划
3. 如果该计划与日历挂钩（例如 Ark Kids），请选择**目标年份**。复活节和圣诞节的学习单元会对应该年份的日期。如果您只安排一年中的部分课程，请调整第一个和最后一个上课日期。
4. 如果该计划不与日历挂钩，请设置第一节课的日期（第 1 周落在该日期；之后各周间隔七天），并选择要生成的周数（12、24、44 或 52）
5. 可选择从上一个计划复制志愿者职位
6. 预览列表。取消勾选您不想要的周次——该段落中后续的课程会顺延到下一个空闲的主日，而不会留下空缺。对于与日历挂钩的计划，已有计划的日期同样会被跳过。
7. 保存。每一周都会成为一个可照常编辑的服事计划——您可以更改课程、志愿者或日期——而 FreePlay 会播放该周计划中的任何内容。

:::tip
**提前规划** —— 您可以一次安排多周的课程，让团队提前做好准备。使用计划视图中的过往课程列表，避免无意中重复内容。
:::

## 自定义课程内容

课程安排完成后，您可以为您的具体教室进行调整——删除不适用的部分、隐藏教室不使用的角色，或重新排列内容以符合您偏好的流程。自定义内容可以仅保存给某一间教室使用，也可以应用于教会的所有教室。

有关分步说明，请参阅[自定义课程](/docs/lessons-church/customization/customizing-lessons)指南。

## 使用 FreePlay 在教室电视上播放课程

在 B1 Admin 中安排课程与 **[FreePlay](/docs/freeplay/)** 完美搭配——FreePlay 是 ChurchApps 为教室电视和 Fire Stick 提供的免费媒体播放器。计划设置完成后，FreePlay 可以直接从 Lessons.church 拉取课程内容，并在教室中全屏播放。教师可以使用电视遥控器控制进度，逐步播放视频和幻灯片，配合课程的节奏。

这意味着您的志愿者可以在手机上查看计划，而内容则在教室电视上播放——无需额外设置、无需 U 盘，也不会在最后一刻手忙脚乱。

[了解如何将 FreePlay 连接到内容提供商 →](/docs/freeplay/content-providers/connecting-providers)

## 没有找到您的课程提供商？

可用提供商的列表还在不断增加。如果您的教会使用的课程提供商尚未出现在 B1 Admin 中，请与我们联系，我们会努力为其添加支持。

您可以直接复制下面的消息并发送给您的课程提供商——一旦他们与我们取得联系，我们就会着手完成集成：

---

> **主题：ChurchApps 集成请求**
>
> 您好，[课程提供商团队]：
>
> 我们非常喜欢贵方的课程，每周都在孩子们身上使用。我们也使用 ChurchApps 来管理志愿者和服事计划，并使用 FreePlay（freeplay.church）在教室电视上直接播放课程内容。这对我们的教师来说是一次革命性的改变。
>
> 目前我们需要单独管理贵方的课程，但如果贵方能与 ChurchApps 集成，我们就可以直接在服事计划中安排贵方的课程，并通过 FreePlay 在教室屏幕上播放——无需离开我们已经在使用的工具。
>
> ChurchApps 已经与多家课程提供商合作，他们的团队也乐于与贵方合作。能否请您联系 **support@churchapps.org**，以便开始洽谈？我们非常希望看到这件事成为现实！
>
> 谢谢！
