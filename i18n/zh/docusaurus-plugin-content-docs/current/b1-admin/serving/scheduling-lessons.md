# 从Lessons.church安排课程

<div class="article-intro">

B1 Admin直接与[Lessons.church](https://lessons.church)集成，因此您可以在服务计划中直接为教室安排课程。这将一切 -- 志愿者、分配和课程内容 -- 保持在一个地方。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在服侍区域设置您的事工
- 拥有有效的[Lessons.church](https://lessons.church)账户 -- 如果您的教会还没有，请先在那里注册

</div>

:::tip 按照指导演练
想从头到尾看到完整的设置？我们的**<a href="/guides/freeplay-b1admin" target="_blank">逐步指南</a>**涵盖了链接提供商、安排课程和将FreePlay连接到教室电视 -- 包含您可以逐项检查的短视频和书面步骤。
:::

## 第1步 -- 链接您的Lessons.church账户

这是每个事工的一次性设置。您需要在浏览和安排内容之前连接您的Lessons.church账户。

1. 登录[B1 Admin](https://admin.b1.church/)并转到**服侍**
2. 打开您想要连接的事工（例如儿童事工）
3. 向下滚动到**内容提供商账户**部分
4. 点击**链接新提供商**
5. 从列表中选择**Lessons.church**
6. 设备授权屏幕将出现并带有代码
7. 转到[lessons.church](https://lessons.church)，登录，然后输入代码以授权连接
8. 批准后，您将在B1 Admin中的Lessons.church下看到**"账户已链接"**

:::info
内容提供商账户部分按事工划分。如果您运行多个事工（例如儿童和青年），您需要分别为每个链接Lessons.church。
:::

## 第2步 -- 安排课程

链接后，您可以直接从计划中安排课程。

1. 在B1 Admin中，转到**服侍 → 计划**
2. 选择您的事工选项卡并点击**添加计划类型** -- 给计划类型一个名称，如儿童教会或主日学校
3. 点击您刚刚创建的计划类型，然后点击**安排课程**。从该菜单，您可以安排一堂课程、批量安排一个系列，或**应用年计划**来从Lessons.church放入已发布的年序列。
4. 选择课程的**日期**（默认为即将到来的周日）
5. 点击**选择课程** -- 内容浏览器对话框打开
6. 对话框打开时**Lessons.church**被选中作为提供商（或用于此计划类型的早期课程的提供商）。如果您已链接其他提供商，可以在对话框顶部的它们之间切换
7. 浏览内容：
   - 选择**节目**（例如，"儿童圣经故事"）
   - 选择该节目内的**学习**（例如，"创造和早期故事"）
   - 选择特定**课程**
   - 选择**会场** -- 这是课程的年龄组版本
8. 点击**关联课程**来确认
9. 为志愿者选择您的**复制选项**：
   - **无** -- 新计划，不携带志愿者
   - **仅位置** -- 从之前的计划复制志愿者角色，但不复制分配的人
   - **位置和分配** -- 复制角色和分配的志愿者 *(最常见)*
10. 点击**保存**

计划会自动创建并命名（例如"2月23日 - 小学"）。志愿者可以打开计划来查看他们的分配并在周日前审查课程内容。

:::warning
确保为您教室的年龄组选择正确的**会场**。选择错误的会场意味着您的志愿者会看到为不同年龄级别设计的内容。
:::

## 应用年计划

如果课程发行商已在Lessons.church上发布了年计划，您可以在一个步骤中将整个序列加载到此计划类型上：

1. 点击**安排课程 → 应用年计划**
2. 选择已发布的年计划
3. 如果计划是日历锚定的（例如Ark Kids），选择**目标年份**。复活节和圣诞节研究落在该年份的日期上。如果您只安排年份的一部分，调整第一个和最后一个班级日期。
4. 如果计划不是日历锚定的，设置第一个班级日期（第1周落在该日期；之后的周是七天间隔）以及要写多少周（12、24、44或52）
5. 可选择从之前的计划复制志愿者位置
6. 预览列表。取消选中您不想要的任何周 -- 该拉伸中的后期课程转到下一个打开的周日，而不是留下空洞。对于日历锚定计划，已有计划的日期以相同的方式被跳过。
7. 保存。每周都会成为一个服务计划，您可以像往常一样编辑 -- 更改课程、志愿者或日期 -- FreePlay将播放该周计划上的内容。

:::tip
**提前计划** -- 您可以一次安排多周的课程，以便您的团队提前准备。使用计划视图中的过去课程列表来避免意外重复内容。
:::

## 自定义课程内容

一旦课程被安排，您可以为您的特定教室定制它 -- 删除不适用的部分、隐藏您的房间不使用的角色，或重新排列内容以匹配您偏好的流程。自定义可以保存为仅一个教室或应用到教会的所有教室。

有关逐步说明，请参阅[自定义课程](/docs/lessons-church/customization/customizing-lessons)指南。

## 用FreePlay在教室电视上播放课程

在B1 Admin中安排课程与**[FreePlay](/docs/freeplay/)**完美配合 -- ChurchApps用于教室电视和Fire Sticks的免费媒体播放器。当您的计划设置好后，FreePlay可以直接从Lessons.church拉取课程内容并在教室中全屏播放。您的教师用电视遥控器控制步调，在课程流动时推进视频和幻灯片。

这意味着您的志愿者在手机上看到计划，同时内容在房间的电视上播放 -- 无需单独设置、无需USB驱动器、无需最后一刻的匆忙。

[了解如何将FreePlay连接到内容提供商 →](/docs/freeplay/content-providers/connecting-providers)

## 看不到您的课程提供商？

可用提供商的列表在不断增长。如果您的教会使用的课程提供商在B1 Admin中尚未显示，请联系我们，我们将努力添加它们。

随时复制并直接发送下面的消息给您的课程提供商 -- 一旦他们联系我们，我们就会设置集成：

---

> **主题：ChurchApps集成请求**
>
> 亲爱的[课程提供商团队]，
>
> 我们喜欢您的课程，每周都在孩子们身上使用。我们也使用ChurchApps来管理我们的志愿者和服务计划，并使用FreePlay (freeplay.church) 来直接在我们的教室电视上播放课程内容。这对我们的教师来说改变了游戏规则。
>
> 现在我们必须单独管理您的课程，但如果您与ChurchApps集成，我们可以直接在我们的服务计划中安排您的课程，并通过FreePlay在我们的教室屏幕上播放它们 -- 所有这些都无需离开我们已经使用的工具。
>
> ChurchApps已经与多个课程提供商合作，他们的团队也准备与您合作。您能联系他们吗？**support@churchapps.org** 来开始对话？我们很想看到这一切发生！
>
> 谢谢！
