# 数字标牌

<div class="article-intro">

使用数字标牌馈送将你的课程内容发送到大厅或走廊的电视。每个计划类型都有一个馈送URL，始终播放当前计划的内容，所以每周无需更新。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 使用[Lessons.church](../../b1-church/content/lessons.md)或其他课程内容设置一个[计划类型](./plans.md)
- 拥有[SignPresenter](https://www.signpresenter.com)账户和一个设置好的设备来显示它

</div>

## 获取馈送URL

1. 导航到**服侍**并打开包含你的计划类型的事工。
2. 在计划类型页面上点击**数字标牌**按钮（RSS图标）。
3. 复制对话框中显示的馈送URL。

:::info
馈送URL与计划类型相关联，而不是单个计划。它自动跟踪为该计划类型安排为当前的任何计划，所以你只需设置一次。
:::

## 连接到SignPresenter

馈送是为与[SignPresenter](https://www.signpresenter.com)配合使用而构建的，SignPresenter是一个第三方数字标牌应用。将复制的URL粘贴到SignPresenter中作为外部馈送，以在连接的屏幕上显示你当前的课程内容。

有关SignPresenter内的分步设置，请查看[SignPresenter的Lessons.church指南](https://support.signpresenter.com/topics/lessons-dot-church.html)。

## 下一步

- 在[计划](./plans.md)页面上管理为此标牌显示提供内容的计划
- 使用[Lessons.church](./scheduling-lessons.md)安排内容
