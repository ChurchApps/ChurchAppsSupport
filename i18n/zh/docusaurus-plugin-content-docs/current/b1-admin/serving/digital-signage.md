# 数字标牌

<div class="article-intro">

通过数字标牌信息源，将您的课程内容发送到大厅或走廊的电视上。每种计划类型都有一个信息源网址，它始终播放当前计划的内容，因此无需每周更新。如果您的电视运行 FreePlay，也可以改为在 FreePlay Admin 中为这些电视安排该计划类型。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 使用 [Lessons.church](../../b1-church/content/lessons.md) 或其他课程内容，设置一个[计划类型](./plans.md)并安排好内容
- 拥有 [SignPresenter](https://www.signpresenter.com) 账户，并设置一台用于显示它的设备，或一台运行 [FreePlay](../../freeplay/) 的电视

</div>

## 获取信息源网址

1. 前往 **服侍**，选择包含您计划类型的事工，然后点击该计划类型以打开它。
2. 在计划类型页面顶部，点击 **数字标牌**（电视图标）。
3. 在 **数字标牌信息源** 对话框中，点击 **信息源网址** 旁边的复制按钮。

:::info
信息源网址绑定的是计划类型，而不是某一个计划。它会自动跟踪该计划类型当前被设为当前计划的那一个，因此您只需设置一次。
:::

## 连接 SignPresenter

该信息源专为 [SignPresenter](https://www.signpresenter.com) 设计，这是一款第三方数字标牌应用。将复制的网址粘贴到 SignPresenter 中作为外部信息源，即可在已连接的屏幕上显示您当前的课程内容。

有关在 SignPresenter 中的分步设置说明，请参阅 [SignPresenter 的 Lessons.church 指南](https://support.signpresenter.com/topics/lessons-dot-church.html)。该对话框中也有此说明的链接。

## 改用 FreePlay 电视

如果您的屏幕运行 [FreePlay](../../freeplay/)，则无需使用信息源网址。**数字标牌信息源** 对话框中有一个 **admin.freeplay.church/calendar** 链接，您可以在那里为您的 FreePlay 电视安排此计划类型：

1. 点击对话框中的 **admin.freeplay.church/calendar** 链接。FreePlay Admin 使用与 B1 Admin 相同的登录账户。
2. 选择您电视所在的屏幕组，然后点击 **添加日程**。
3. 在 **播放** 下，从 **服侍计划** 中选择您的计划类型。它会标有 **（当前计划）**。
4. 设置日期和时间，然后点击 **保存**。

电视会在您设定的时间播放该计划类型每周的当前计划。这同样适用于 Go Curriculum 课程，包括您自定义过的计划。FreePlay 使用在 **内容提供方** 下关联到该事工的 Go Curriculum 账户登录（参见[安排课程](./scheduling-lessons.md)），如果该事工没有关联账户，则使用教会的 Go Curriculum 连接。有关所有选项，请参阅[安排日历](../../freeplay/scheduled-mode/scheduling-the-calendar)；要添加电视，请参阅[配对屏幕](../../freeplay/scheduled-mode/pairing-a-screen)。

:::note
信息源网址不包含 Go Curriculum 媒体，因为该内容需要您教会的 Go Curriculum 登录。要在大厅或教室的电视上显示 Go Curriculum 课程，请使用 FreePlay。
:::

## 后续步骤

- 使用 [Lessons.church](./scheduling-lessons.md) 安排内容
- 使用[定时模式](../../freeplay/scheduled-mode/)为 FreePlay 电视安排日历
