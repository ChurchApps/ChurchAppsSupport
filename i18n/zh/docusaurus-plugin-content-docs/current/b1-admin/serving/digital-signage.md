# 数字标牌

<div class="article-intro">

使用数字标牌订阅源，将您的课程内容发送到大厅或走廊的电视上。每种计划类型都有一个订阅源网址，它会始终播放当前计划的内容，因此每周无需进行任何更新。如果您的电视运行 FreePlay，也可以改为在 FreePlay Admin 中为该计划类型安排播放时间。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置一个[计划类型](./plans.md)，并已在 [Lessons.church](../../b1-church/content/lessons.md) 或其他课程内容中安排好内容
- 拥有一个 [SignPresenter](https://www.signpresenter.com) 账户，以及一台已设置好用于显示它的设备，或一台运行 [FreePlay](../../freeplay/) 的电视

</div>

## 获取订阅源网址

1. 前往**服事**，选择包含您计划类型的事工，然后点击该计划类型将其打开。
2. 在计划类型页面顶部，点击**数字标牌**（电视图标）。
3. 在**数字标牌订阅源**对话框中，点击 **Feed Url** 旁边的复制按钮。

:::info
订阅源网址绑定的是计划类型，而不是某一个具体计划。它会自动跟踪该计划类型当前被设为“当前计划”的那一项，因此您只需设置一次即可。
:::

## 连接 SignPresenter

该订阅源专为 [SignPresenter](https://www.signpresenter.com) 设计，这是一款第三方数字标牌应用。将复制的网址作为外部订阅源粘贴到 SignPresenter 中，即可在已连接的屏幕上显示您当前的课程内容。

有关在 SignPresenter 中的分步设置，请参阅 [SignPresenter 的 Lessons.church 指南](https://support.signpresenter.com/topics/lessons-dot-church.html)。该对话框中也附有这些说明的链接。

## 改用 FreePlay 电视

如果您的屏幕运行 [FreePlay](../../freeplay/)，则无需使用订阅源网址。**数字标牌订阅源**对话框中会链接到 **admin.freeplay.church/calendar**，您可以在该页面为 FreePlay 电视安排此计划类型：

1. 点击对话框中的 **admin.freeplay.church/calendar** 链接。FreePlay Admin 使用与 B1 Admin 相同的登录账户。
2. 选择您电视所在的屏幕组，然后点击**添加日程**。
3. 在**播放**下，从**服事计划**中选择您的计划类型。它会标注为 **(current plan)**（当前计划）。
4. 设置日期和时间，然后点击**保存**。

电视会在您设定的时间，每周播放该计划类型当前的计划内容。有关所有选项，请参阅[安排日历](../../freeplay/scheduled-mode/scheduling-the-calendar)；如需添加电视，请参阅[配对屏幕](../../freeplay/scheduled-mode/pairing-a-screen)。

## 后续步骤

- 在[计划](./plans.md)页面管理为此数字标牌提供内容的计划
- 使用 [Lessons.church](./scheduling-lessons.md) 安排内容
- 使用[定时模式](../../freeplay/scheduled-mode/)为 FreePlay 电视安排日历
