# 数字标牌

<div class="article-intro">

使用数字标牌提要将您的课程内容发送到大厅或走廊电视。每个计划类型都会获得一个 Feed URL，该 URL 始终播放当前计划的内容，因此一周内无需更新任何内容。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 使用[Lessons.church](../content/lessons.md)或其他已安排的课程内容设置[计划类型](./plans.md)
- 拥有[SignPresenter](https://www.signpresenter.com)帐户和已设置的设备来显示它

</div>

## 获取 Feed URL

1. 导航到**服务**并打开包含您的计划类型的事工。
2. 在计划类型页面上单击**数字标牌**按钮（RSS 图标）。
3. 复制对话框中显示的 Feed URL。

:::info
Feed URL 与计划类型相关联，而不是单个计划。它会自动跟踪为该计划类型安排的当前计划，因此您只需设置一次。
:::

## 连接到 SignPresenter

该 Feed 旨在与[SignPresenter](https://www.signpresenter.com)（第三方数字标牌应用）配合使用。将复制的 URL 粘贴到 SignPresenter 中作为外部 Feed，以在连接的屏幕上显示您当前的课程内容。

有关在 SignPresenter 中的分步设置，请参阅[SignPresenter 的 Lessons.church 指南](https://support.signpresenter.com/topics/lessons-dot-church.html)。

## 后续步骤

- 在[计划](./plans.md)页面上管理为该标牌显示供电的计划
- 使用[Lessons.church](./scheduling-lessons.md)安排内容
