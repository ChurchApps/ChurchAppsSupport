# 服务计划

<div class="article-intro">

服务计划组织谁在服侍以及何时服侍。每个计划与特定日期和事工相关联，使您可以逐周协调志愿者团队，并确保每项服务都有充足的人员。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在服侍区域设置您的事工和团队
- 确保志愿者已添加到您的[人员目录](../people/adding-people.md)并分配给团队

</div>

## 访问计划

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**服侍**，然后点击**计划**。
2. 在页面顶部选择一个**事工选项卡**。
3. 点击一个**计划类型**来查看该类型的计划列表。
4. 点击特定计划来打开它。

:::info
管理计划不需要完全的管理员访问权限。任何是事工成员的人都可以导航到服侍并为自己的事工创建、编辑和安排计划，而无需计划编辑权限。拥有计划编辑角色的编辑可以管理每个事工的计划。
:::

## 创建计划

1. 从计划类型视图中，点击**新建计划**。
2. 给计划一个名称或使用日期作为名称。选择服务的**日期**。
3. 如果您想从之前的计划复制，选择仅位置或位置和分配。如果您不想复制，就选择什么都不做。您也可以从我之前的计划复制服务顺序。
4. 保存计划。您现在可以开始分配团队成员并建立[服务顺序](./service-order.md)。

## 计划详情页面

打开计划时，您会看到两个选项卡：

- **分配** -- 管理哪些团队成员被分配到此计划。您可以从现有团队添加人员，并查看谁已确认或仍在待处理中。
- **[服务顺序](./service-order.md)** -- 用敬拜歌曲、祷告、宣布和讲道等元素建立服务顺序。

## 分配团队成员

1. 打开计划并转到**分配**选项卡。
2. 点击**添加位置**来展开它。在添加位置表单中填充信息。对于类别名称，添加任何您喜欢的类别。要让教会中的任何人填充该位置（不仅仅是一个团队的成员），请将**志愿者组**设置为**无**。
3. 点击**所需人数**并选择志愿者来填充该位置。如果该位置有**志愿者组**，您从该组的成员中选择。如果其志愿者组设置为**无**，您可以搜索教会中的任何人。
4. 通过点击**添加**从您的团队花名册添加成员。
5. 分配的成员将与他们的分配状态一起出现在他们的团队下。
6. 点击通知志愿者来通知他们在B1应用程序中或通过电子邮件通知。

每个位置显示一个计数芯片（例如，"2/3"），以便您一目了然地看到有多少个位置被填充。在分配选项卡的顶部，一个进度条和摘要芯片（"Y个位置中的X个已填充"）显示您的计划整体人员配置，一旦每个位置都被覆盖，就切换到**人员充足**。

:::tip
在创建计划之前在事工设置中设置您的团队。这样，您将拥有一个现成的志愿者池来分配。
:::

## 计划设置

每个计划都有额外的设置，您可以通过点击计划上的编辑（铅笔）图标来配置。这些包括：

- **报名截止日期** -- 服务开始前志愿者报名关闭的小时数。输入负数以保持报名在服务开始时间后开放。
- **在报名页面上显示志愿者名称** -- 当选中时，志愿者可以看到谁已经为每个位置报名。
- **暂定** -- 隐藏分配，直到您准备好发布时间表。
- **当志愿者拒绝时自动安排替代人员** -- 当选中时，如果分配的志愿者拒绝他们的位置，B1将自动联系团队名册上的下一个可用人员，并询问他们是否可以服侍。这会沿着列表继续下去，直到某人接受，保持您的位置被填充，而无需手动跟进。

## 志愿者提醒

B1可以自动提醒志愿者他们被安排服侍的服务，这样您就不必每周追赶您的团队。提醒发送给**所有被安排的人** -- 那些已确认的和尚未回应的 -- 通过电子邮件和应用程序内/推送通知。每个提醒包括志愿者的位置、服务日期、计划说明和您的自定义消息。

提醒时间和内容按**计划类型**设置，因此每种类型的服务都可以保持自己的时间表。

1. 从**服侍**区域，选择包含计划类型的事工。
2. 点击计划类型旁边的**编辑（铅笔）图标**。
3. 在**提醒**部分，设置：
   - **服务前提醒日期** -- 以逗号分隔的提前发送多少天的列表，例如`7,1,0`。使用`0`在服务当天发送提醒。将此字段留空以关闭此计划类型的提醒。
   - **自定义提醒消息** *(可选)* -- 添加到提醒的额外文本，例如"提前30分钟到达以进行排练。"
4. 保存计划类型。

新计划类型默认在每次服务前**2天**提醒志愿者，直到您更改此设置。

:::tip
尚未确认的志愿者在提醒电子邮件中直接获得**接受**和**拒绝**按钮，因此他们可以在不登录的情况下回应。
:::

:::info
每个提醒只发送一次。仍然暂定的计划（尚未发送给团队）不会触发提醒。
:::

## 将组与计划类型相关联

在计划类型页面的计划列表下方，**组**部分让您决定哪些组可以从其成员门户中查看此计划类型的计划。这是一种快速方式，可以将即将进行的服务显示给正确的团队，而无需给予他们管理员访问权限。

1. 在计划类型页面上，向下滚动到**组**部分。
2. 点击**添加组**并从下拉菜单中选择一个组。
3. 在**显示**列中，选择该组的成员应该看到此计划类型的**过去**、**未来**还是**两者**计划。
4. 重复以关联其他组，或点击垃圾图标来删除组。

:::info
只有标记为**标准**的组才会出现在选择器中。关联组的成员会自动在B1成员门户中的组页面上看到此计划类型的计划 -- 仅限于您选择的过去/未来/两者窗口。
:::

如果计划是Lessons.church课程，关联组的成员也会在组页面上看到**本周的课程**卡片（底行、经文和家长问题）。在这里关联一个家长组并将过滤器设置为**过去**，以便包含今天的课程。志愿者团队通常使用**未来**或**两者**。

## 打印计划

您可以打印计划来分发给您的团队。打开计划，打开服务顺序选项卡，并使用**打印**选项生成可打印版本，其中包括分配和服务顺序。打印件的顶部显示您教会的名称和计划的名称，因此松散的页面很容易识别。这对于在排练时分发或在公共区域张贴很有用。

:::info
计划按事工组织。在创建或查看计划之前，请确保您在正确的事工选项卡上。
:::
