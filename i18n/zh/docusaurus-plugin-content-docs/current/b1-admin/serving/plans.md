# 服事计划

<div class="article-intro">

服事计划用于组织谁在什么时候服事。每个计划都关联到特定的日期和事工,让您能够逐周协调志愿者团队,确保每场服事都配备充足人员。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在事工服事区域设置您的事工和团队
- 确保志愿者已被添加到您的[人员目录](../people/adding-people.md)并分配到团队

</div>

## 访问计划

1. 从主菜单导航到**事工服事**。
2. 在页面顶部选择一个**事工标签**。
3. 点击一种**计划类型**以查看该类型的计划列表。
4. 点击某个具体计划将其打开。

:::info
管理计划并不需要完整的管理员权限。任何事工成员都可以进入事工服事区域,为自己所属的事工创建、编辑和排定计划,无需拥有"计划编辑"权限。拥有"计划编辑"角色的编辑者可以跨所有事工管理计划。
:::

## 创建计划

1. 在计划类型视图中,点击**新建计划**。
2. 为计划命名,或直接使用日期作为名称。选择服事的**日期**。
3. 如果您想从之前的计划中复制内容,可以选择只复制职位,或同时复制职位和分配。如果不想复制,则什么都不选。您也可以从上一个计划复制崇拜流程。
4. 保存计划。现在您可以开始分配团队成员并构建[崇拜流程](./service-order.md)。

## 计划详情页面

打开一个计划后,您会看到两个标签页:

- **分配**——管理哪些团队成员被分配到此计划。您可以从现有团队中添加人员,查看谁已确认、谁仍待确认。
- **[崇拜流程](./service-order.md)**——使用敬拜歌曲、祷告、公告和讲道等元素构建崇拜的顺序。

## 分配团队成员

1. 打开一个计划,进入**分配**标签页。
2. 点击**添加职位**将其展开。在添加职位表单中填写信息。类别名称可以填写您喜欢的任何名称。
3. 点击**所需人数**并选择志愿者来填补该职位。
4. 点击**添加**,从您的团队名单中添加成员。
5. 被分配的成员会连同其分配状态一起显示在其所属团队下。
6. 点击通知志愿者,可以通过 B1 应用内消息或电子邮件通知他们。

每个职位都会显示一个计数标记(例如"2/3"),让您一眼看出该职位已填补了多少个名额。在分配标签页顶部,一个进度条和汇总标记("已填补 X/Y 个职位")显示该计划的整体人员配备情况,当所有职位都填满时会切换为**已满员**。

:::tip
在创建计划之前,先在事工设置中建立好您的团队。这样一来,您在分配时就有一个现成的志愿者库可供选择。
:::

## 志愿者提醒

B1 可以在服事前自动提醒志愿者,免去您每周追人的麻烦。提醒会发送给**所有已排班的人**——无论是已确认还是尚未回应的人——通过电子邮件和应用内/推送通知发送。每条提醒都包含志愿者的职位、服事日期、计划备注以及您的自定义留言。

提醒的时间和内容是按**计划类型**设置的,因此每种服事类型都可以拥有自己的提醒安排。

1. 在**事工服事**区域,选择包含该计划类型的事工。
2. 点击该计划类型旁边的**编辑(铅笔)图标**。
3. 在**提醒**部分,设置:
   - **服事前提醒天数**——用逗号分隔的天数列表,表示提前多少天发送,例如 `7,1,0`。使用 `0` 表示在服事当天发送提醒。留空此字段可关闭该计划类型的提醒。
   - **自定义提醒消息***(可选)*——添加到提醒中的额外文字,例如"请提前 30 分钟到场排练"。
4. 保存该计划类型。

新建的计划类型默认会在每场服事前**2 天**提醒志愿者,直到您修改此设置。

:::tip
尚未确认的志愿者会在提醒邮件中直接看到**接受**和**拒绝**按钮,无需登录即可回应。
:::

:::info
每条提醒只会发送一次。仍处于草拟状态(尚未发布给团队)的计划不会触发提醒。
:::

## 将小组与计划类型关联

在计划类型页面的计划列表下方,**小组**部分让您决定哪些小组的成员可以在其成员门户中看到这一计划类型的计划。这是一种快速的方式,可以让正确的团队看到即将到来的服事,而无需授予其管理员权限。

1. 在计划类型页面上,向下滚动到**小组**部分。
2. 点击**添加小组**,并从下拉列表中选择一个小组。
3. 在**显示**列中,选择该小组成员应看到此计划类型的**过去**、**未来**还是**两者**的计划。
4. 重复以上步骤关联更多小组,或点击垃圾桶图标移除某个小组。

:::info
只有被标记为**标准**的小组才会出现在选择器中。关联小组的成员会自动在 B1 成员门户的[计划](/docs/b1-church/plans/)标签页中看到该计划类型的计划——范围限定于您所选择的过去/未来/两者的时间窗口。
:::

## 打印计划

您可以打印计划,分发给您的团队。打开计划,进入崇拜流程标签页,使用**打印**选项生成包含分配和崇拜流程的可打印版本。这对于在排练时分发或张贴在公共区域很有用。

:::info
计划按事工组织。在创建或查看计划之前,请确保您位于正确的事工标签页上。
:::

## 后续步骤

- 使用[计划总览](./plans-overview.md)在一个网格中查看多周的所有安排,发现未填补的职位——并直接从网格中分配志愿者
- 将计划的结构保存为[计划模板](./plan-templates.md),以便一键套用到未来的计划中
- 使用歌曲、诵读和其他元素构建您的[崇拜流程](./service-order.md)
- 将您曲库中的[歌曲](./songs.md)直接添加到崇拜流程中
- 使用[任务](./tasks.md)为团队成员分配后续跟进事项
