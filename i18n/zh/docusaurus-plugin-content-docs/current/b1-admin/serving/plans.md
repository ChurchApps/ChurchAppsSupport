# 服务计划

<div class="article-intro">

服务计划用于组织谁在服侍以及何时服侍。每个计划都关联到特定的日期和事工，使您可以逐周协调志愿者团队，确保每次服务都有足够的人手。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在服侍区域设置您的事工和团队
- 确保志愿者已添加到您的[人员目录](../people/adding-people.md)并分配到团队

</div>

## 访问计划 {#accessing-plans}

1. 在 B1 Admin 中，打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**服侍**，然后点击**计划**。
2. 在页面顶部选择一个**事工选项卡**。
3. 点击一个**计划类型**，查看该类型的计划列表。使用列表上方的**即将到来**和**过去**在未来计划与过去计划之间切换。
4. 点击特定计划以将其打开。

每个计划页面都包含返回其计划类型和**计划**的链接，因此您无需使用浏览器的后退按钮即可返回上一级。

:::info
管理计划不需要完全的管理员权限。任何事工成员都可以进入服侍区域，为自己的事工创建、编辑和安排计划，而无需计划编辑权限。拥有计划编辑角色的编辑者可以管理所有事工的计划。
:::

## 创建计划 {#creating-a-plan}

1. 在计划类型页面上，点击页面顶部的**新建计划**。
2. 为计划起一个名称，或直接使用日期作为名称。选择服务的**日期**。
3. 如果您的事工有[模板](./plan-templates.md)，可以在**从模板开始**下选择一个模板，一步填充服务顺序、位置和备注。
4. 否则，如果您想从之前的计划复制，请使用**复制自之前的计划**选择**仅复制位置**或**位置和分配**。如果不想复制，请选择**不复制**。您还可以勾选**复制服务顺序**。从之前的计划复制时，新计划还会保留该计划的**备注**、**报名截止时间**、**在报名页面上显示志愿者姓名**以及自动替换设置，因此您无需每周重新输入。您可以在新计划的设置中更改其中任何一项。
5. 若要在复制时一次设置多周，请在**每周重复此次数**中输入一个数字（最多 12）。B1 会为每一周创建一个计划，每个计划都从前一个计划复制而来。如果计划以日期命名，每个新计划都会以其各自的日期命名。
6. 可选地设置**报名截止时间（服务前小时数）**。新计划会沿用上一个计划的截止时间，您可以在此更改。留空则表示没有截止时间。
7. 保存计划。现在您可以开始分配团队成员，并编排[服务顺序](./service-order.md)。

:::tip
**每周重复此次数**仅在您复制上一个计划的内容（位置、分配或服务顺序）时可用。
:::

## 计划详情页面 {#the-plan-detail-page}

打开计划时，计划名称、事工、计划类型和服务日期会显示在顶部，并带有**编辑**和**打印**按钮。其下方，所有内容都在同一页面上：

- **[服务顺序](./service-order.md)** -- 通过敬拜歌曲、祷告、公告和讲道等元素编排服务顺序。
- **服侍团队分配** -- 管理分配到此计划的团队成员。您可以从现有团队中添加人员，并查看谁已确认、谁仍在等待。位置上方的链接可让您打开该计划的**备注**和**时间**。

## 分配团队成员 {#assigning-team-members}

1. 打开计划，并滚动到**服侍团队分配**。
2. 点击**添加位置**。在添加位置表单中填写信息。类别名称可以填写您喜欢的任何类别。若要让教会中的任何人都能担任该位置（而不仅限于某个团队的成员），请将**志愿者组**保持为**无**。
3. 点击**所需人员**，选择志愿者来填补该位置。如果该位置设有**志愿者组**，您可以从该组的成员中选择。如果其志愿者组设为**无**，您可以搜索教会中的任何人。
4. 点击**添加**，从您的团队名册中添加成员。
5. 被分配的成员会显示在其所属团队下，并带有其分配状态。
6. 点击**通知志愿者**，通过 B1 应用或电子邮件通知他们。

每个位置都会显示一个计数标签（例如“2/3”），让您一眼看出有多少名额已经填满。在**服侍团队分配**标题下，一条摘要（“已填补 X / Y 个位置”）会显示该计划的整体人手情况，以及仍需多少人。所有位置都填满后，它会切换为**人员已配齐**。

:::tip
在创建计划之前，请先在事工设置中设置好您的团队。这样您就有了现成的志愿者池可供分配。
:::

### 将位置复制到空计划中 {#copying-positions-into-an-empty-plan}

如果某个计划还没有任何位置，而且存在同类型的较早计划，则**服侍团队分配**中会出现**复制自之前的计划**链接。选择**仅复制位置**或**位置和分配**，即可用之前计划的位置（以及志愿者）填充您当前打开的计划。复制的内容会进入当前计划；它不会为同一日期创建第二个计划。

## 计划设置 {#plan-settings}

每个计划都有其他可以配置的设置。您可以在计划类型列表中点击计划旁边的**编辑**，或在计划页面顶部点击**编辑**按钮进行配置。点击**完成**（或计划名称）即可返回计划。这些设置包括：

- **报名截止时间（服务前小时数）** — 服务开始前多少小时志愿者报名截止。输入负数可使报名在服务开始时间之后仍保持开放。留空则表示没有截止时间。
- **在报名页面上显示志愿者姓名** — 勾选后，已登录的志愿者可以在 B1.church 报名页面上看到每个位置已有哪些人报名。未登录的访客永远看不到姓名。
- **暂定安排** — 在您准备发布排班表之前，对志愿者隐藏分配。
- **志愿者拒绝时自动安排替补** — 勾选后，如果被分配的志愿者拒绝其位置，B1 会自动联系团队名册上的下一位可用人员，询问其是否可以服侍。此过程会依次进行，直到有人接受，从而无需手动跟进即可保持位置有人填补。

## 志愿者提醒 {#volunteer-reminders}

B1 可以在志愿者被安排服侍的服务之前自动提醒他们，这样您每周就不必逐一联系团队成员。提醒会发送给**所有已被安排的人**——包括已确认的和尚未回复的。每封提醒邮件都包含志愿者的位置、服务日期、计划备注以及您的自定义消息。

提醒的时间和内容按**计划类型**设置，因此每种服务都可以拥有自己的时间安排。

1. 在**服侍**区域中，选择包含该计划类型的事工。
2. 在**计划类型**列表中，点击该计划类型旁边的**编辑**。
3. 展开**提醒**部分，并开启**为此类型的计划发送提醒**。
4. 在**提醒应在何时发出？**下，最多选择三个时间点：**提前 7 天**、**提前 3 天**、**提前 2 天**、**提前 1 天**或**当天**。
5. 设置提醒发出的**时间**。
6. 可选地添加**消息**。留空则使用默认的提醒措辞。
7. 在**发送方式**下，选择**推送**、**电子邮件**，以及（如果您的教会已连接[短信服务提供商](../settings/church-settings.md#texting)）**短信**。
8. 点击**保存提醒**。

在您开启之前，计划类型的提醒默认处于关闭状态。

:::tip
尚未确认的志愿者会在提醒邮件中直接看到**接受**和**拒绝**按钮，无需登录即可回复。
:::

### 短信提醒 {#text-reminders}

只有当您的教会连接了短信服务提供商时，**短信**选项才会出现。短信通过您教会的短信服务提供商发送，每条短信都可能产生费用。只有在志愿者的[通知偏好](../../b1-church/getting-started/notification-preferences.md)中开启了**短信**，并且其个人资料中有手机号码时，才会收到短信提醒。每条短信都以您教会的名称开头，并限制为单条短信，末尾附有“Reply STOP to opt out.”。回复 STOP 的人将不再收到您教会的短信。要让 STOP 回复能够到达 B1，请将您[短信设置](../settings/church-settings.md#texting)中的**入站（STOP）Webhook URL**粘贴到您的服务提供商的入站消息 webhook 中。

若要立即向某个日期范围内所有已安排的人员发送短信，请使用[计划概览](./plans-overview.md#texting-everyone-scheduled)中的**向志愿者发送短信**。

:::info
每条提醒只发送一次。短信提醒是在推送和电子邮件之外额外发送的，而不是替代它们。
:::

## 将组与计划类型关联 {#associating-groups-with-a-plan-type}

在计划类型页面的计划列表下方，**关联的组**部分可让您决定哪些组可以从其成员门户查看该计划类型的计划。这是一种快速的方式，可以将即将到来的服务展示给相关团队，而无需授予其管理员权限。

1. 在计划类型页面上，点击页面顶部的**关联的组**（或向下滚动到该部分）。
2. 点击**添加组**，并从下拉菜单中选择一个组。
3. 在**显示**列中，选择该组的成员应看到此计划类型的**仅过去的计划**、**仅即将到来的计划**，还是**过去和即将到来的计划**。
4. 重复此操作以关联更多组，或点击垃圾桶图标移除某个组。

:::info
只有标记为**标准**的组才会出现在选择器中。关联组的成员会自动在 B1 成员门户中该组的页面上看到此计划类型的计划——仅限于您所选的时间范围内。
:::

如果计划是 Lessons.church 课程，关联组的成员还会在组页面上看到**本周课程**卡片（包含底线、经文以及给家长的一个问题）。请在此关联家长组，并将筛选条件设置为**仅过去的计划**，以便包含今天的课程。服侍团队通常使用**仅即将到来的计划**或**过去和即将到来的计划**。

## 打印计划 {#printing-plans}

您可以打印计划以分发给团队。打开计划，点击页面顶部的**打印**，即可生成包含分配和服务顺序的可打印版本。打印件顶部会显示您的教会标志（如果您上传过，则为来自[网站 > 外观](../website/appearance.md)的**浅色背景标志**），其下为教会名称和计划名称，方便识别散页。这适用于在排练时分发，或张贴在公共区域。

:::info
计划按事工组织。在创建或查看计划之前，请确保您位于正确的事工选项卡上。
:::

- 将计划的结构保存为[计划模板](./plan-templates.md)，以便一键将其应用到未来的计划中

- 直接从您的曲库中将[歌曲](./songs.md)添加到服务顺序中
