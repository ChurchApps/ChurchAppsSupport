# 服侍计划

<div class="article-intro">

服侍计划组织谁在服侍以及何时服侍。每个计划都绑定到特定的日期和事工，使它易于协调你的志愿者团队周复一周，并确保每个服侍都充分配备。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 在服侍区域中设置你的事工和团队
- 确保志愿者已添加到你的[人员目录](../people/adding-people.md)并分配到团队

</div>

## 访问计划

1. 从主菜单导航到**服侍**。
2. 选择顶部的**事工标签页**。
3. 点击**计划类型**以查看该类型的计划列表。
4. 点击特定计划以打开它。

:::info
完整的管理员访问权限不需要来管理计划。任何是事工成员的人都可以导航到服侍并为他们自己的事工创建、编辑和排定计划，而无需计划编辑权限。具有计划编辑角色的编辑可以管理每个事工的计划。
:::

## 创建计划

1. 从计划类型视图中，点击**新计划**。
2. 给计划一个名称或使用日期作为名称。选择服侍的**日期**。
3. 如果你想从之前的计划复制，选择仅职位或职位和分配。如果你不想复制，就选择无。你也可以从我的之前的计划复制服侍的顺序。
4. 保存计划。你现在可以开始分配团队成员并构建[服侍顺序](./service-order.md)。

## 计划详情页面

当你打开计划时，你会看到两个标签页：

- **分配** — 管理哪些团队成员被分配到此计划。你可以从现有团队添加人并查看谁已确认或仍待处理。
- **[服侍顺序](./service-order.md)** — 使用敬拜歌曲、祷告、公告和讲道等元素构建服侍顺序。

## 分配团队成员

1. 打开计划并转到**分配**标签页。
2. 点击**添加职位**以展开它。在添加职位表单中填写信息。对于类别名称，添加任何你喜欢的类别。
3. 点击**需要的人**并选择志愿者来填补该职位。
4. 通过点击**添加**从你的团队花名册添加成员。
5. 分配的成员将显示在他们的团队下，带有他们的分配状态。
6. 点击通知志愿者以通过 B1 应用或电子邮件通知他们。

每个职位显示计数芯片（例如，"2/3"）以便你可以一目了然地看到有多少个职位被填充。在分配标签页的顶部，进度条和摘要芯片（"X of Y 职位已填充"）显示你的计划总体人员配置，一旦每个职位都被覆盖，切换到**完全配备**。

:::tip
在创建计划前在事工设置中设置你的团队。这样你会有一个现成的志愿者池可以分配。
:::

## 计划设置

每个计划都有额外的设置你可以通过点击计划上的编辑（铅笔）图标来配置。这些包括：

- **注册截止时间** — 服侍前志愿者注册关闭的小时数。输入负数以在服侍开始时间后保持注册开放。
- **在注册页面上显示志愿者名称** — 选中时，志愿者可以看到谁已经为每个职位注册。
- **暂定** — 隐藏来自志愿者的分配，直到你准备好发布日程。
- **当志愿者拒绝时自动排定替代品** — 选中时，如果分配的志愿者拒绝他们的职位，B1 将自动联系团队花名册中的下一个可用人员并询问他们是否可以服侍。这在列表中继续向下进行，直到有人接受，保持你的职位被填充而无需手动跟进。

## 志愿者提醒

B1 可以自动提醒志愿者他们被排定服侍的服侍，所以你不必每周追赶你的团队。提醒发送给**所有被排定的人** — 那些已确认和那些尚未回应的人 — 通过电子邮件和应用内/推送通知。每条提醒包括志愿者的职位、服侍日期、计划笔记和你的自定义消息。

提醒时间和内容按**计划类型**设置，所以每种类型的服侍可以保持自己的日程。

1. 从**服侍**区域，选择包含计划类型的事工。
2. 点击计划类型旁的**编辑（铅笔）图标**。
3. 在**提醒**部分中，设置：
   - **服侍前提醒天数** — 逗号分隔的多少天前发送列表，例如 `7,1,0`。使用 `0` 在服侍当天发送提醒。将此字段留空以关闭此计划类型的提醒。
   - **自定义提醒消息** *(可选)* — 添加到提醒的额外文本，例如"提前 30 分钟到达以排练。"
4. 保存计划类型。

新计划类型默认在每个服侍前 **2 天** 提醒志愿者，直到你改变这个。

:::tip
尚未确认的志愿者可以在提醒电子邮件中直接获得**接受**和**拒绝**按钮，所以他们可以回应而无需登录。
:::

:::info
每条提醒只被发送一次。仍然暂定（尚未发送给团队）的计划不会触发提醒。
:::

## 将小组与计划类型关联

在计划类型页面上的计划列表下方，**小组**部分让你决定哪些小组可以从他们的成员门户看到此计划类型的计划。这是将即将来临的服侍表面到正确的团队而无需给他们管理员访问权限的快速方式。

1. 在计划类型页面上，向下滚动到**小组**部分。
2. 点击**添加小组**并从下拉菜单中选择小组。
3. 在**显示**列中，选择该小组的成员是否应该看到**过去**、**未来**或**两者**计划类型的计划。
4. 重复以关联其他小组，或点击垃圾图标来移除小组。

:::info
只有标记为**标准**的小组出现在选择器中。关联小组的成员自动在 B1 成员门户中的[计划](/docs/b1-church/plans/)标签页中看到此计划类型的计划 — 限制到你选择的过去/未来/两者窗口。
:::

## 打印计划

你可以打印计划以分发给你的团队。打开计划，打开服侍顺序标签页并使用**打印**选项生成包括分配和服侍顺序的可打印版本。这适合在排练中发放或在公共区域张贴。

:::info
计划按事工组织。在创建或查看计划前确保你在正确的事工标签页上。
:::
