# 服务计划

<div class="article-intro">

服务计划组织谁在服侍以及何时服侍。每个计划都与特定日期和事工相关联，使你可以轻松按周协调志愿者团队，并确保每项服务都有充分的人员配置。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在服侍区域中设置你的事工和团队
- 确保志愿者已添加到你的[人员目录](../people/adding-people.md)并分配给团队

</div>

## 访问计划

1. 从主菜单导航到**服侍**。
2. 选择页面顶部的**事工标签**。
3. 点击**计划类型**以查看该类型的计划列表。
4. 点击特定计划以打开它。

:::info
完整的管理员访问权限不是管理计划所需的。任何事工成员都可以导航到服侍并为他们自己的事工创建、编辑和安排计划，而无需计划编辑权限。具有计划编辑角色的编辑可以管理所有事工的计划。
:::

## 创建计划

1. 从计划类型视图中，点击**新建计划**。
2. 为计划指定名称或使用日期作为名称。选择服务的**日期**。
3. 如果你想从之前的计划复制，选择仅职位或职位和分配。如果你不想复制，只需选择无。你也可以从我的前一个计划复制服务顺序。
4. 保存计划。你现在可以开始分配团队成员并构建[服务顺序](./service-order.md)。

## 计划详细页面

当你打开计划时，你会看到两个标签：

- **分配** -- 管理哪些团队成员被分配到此计划。你可以从现有团队添加人员，并查看谁已确认或仍未响应。
- **[服务顺序](./service-order.md)** -- 使用敬拜歌曲、祷告、公告和讲道等元素构建服务顺序。

## 分配团队成员

1. 打开计划并进入**分配**标签。
2. 点击**添加职位**来扩展它。填出添加职位表单中的信息。对于类别名称，添加你喜欢的任何类别。
3. 点击**需要的人数**并选择志愿者来填补该职位。如果职位有**志愿者小组**，你从该小组的成员中选择。如果其志愿者小组设置为**无**，你可以搜索教会中的任何人。
4. 通过点击**添加**从你的团队名单中添加成员。
5. 分配的成员会在他们的团队下显示，带有他们的分配状态。
6. 点击通知志愿者在B1应用或通过电子邮件通知他们。

每个职位显示一个计数芯片（例如，"2/3"），所以你可以一目了然地看到有多少个职位已填充。在分配标签的顶部，进度条和摘要芯片（"Y个职位中有X个已填"）显示你的整体计划人员配置，一旦每个职位都被覆盖，就切换到**配置完整**。

:::tip
在创建计划之前在事工设置中设置你的团队。这样，你将拥有一个随时可用的志愿者池来分配。
:::

## 计划设置

每个计划都有额外的设置，你可以通过点击计划上的编辑（铅笔）图标来配置。这些包括：

- **报名截止日期** — 在志愿者报名关闭的服务前的小时数。输入负数以在服务开始时间后保持报名开放。
- **在报名页面上显示志愿者姓名** — 选中时，志愿者可以看到谁已经为每个职位报名。
- **铅笔草稿** — 隐藏分配给志愿者，直到你准备好发布日程。
- **当志愿者拒绝时自动安排替换** — 选中时，如果分配的志愿者拒绝他们的职位，B1将自动联系团队名单上下一个可用的人，并询问他们是否可以服侍。这会继续下去，直到有人接受，保持你的职位已填充，而无需手动跟进。

## 志愿者提醒

B1可以自动提醒志愿者他们被安排服务的日期之前，所以你不必每周追逐你的团队。提醒发送给**所有被安排的人** — 那些已确认的和那些尚未响应的 — 通过电子邮件和应用内/推送通知。每个提醒包括志愿者的职位、服务日期、计划笔记和你的自定义消息。

提醒时间和内容是按**计划类型**设置的，所以每种服务都可以保持自己的日程。

1. 从**服侍**区域，选择包含计划类型的事工。
2. 点击计划类型旁边的**编辑（铅笔）图标**。
3. 在**提醒**部分，设置：
   - **服务前提醒天数** — 提前多少天发送的逗号分隔列表，例如`7,1,0`。使用`0`在服务当天发送提醒。将此字段留空以关闭此计划类型的提醒。
   - **自定义提醒消息** *（可选）* — 添加到提醒的额外文本，例如"提早30分钟到达进行排练。"
4. 保存计划类型。

新计划类型默认在服务前**2天**提醒志愿者，直到你更改这个。

:::tip
尚未确认的志愿者会在提醒电子邮件中获得**接受**和**拒绝**按钮，所以他们可以在不登录的情况下响应。
:::

:::info
每个提醒只发送一次。仍然处于草稿状态的计划（尚未发送给团队）不会触发提醒。
:::

## 将小组与计划类型关联

在计划类型页面上的计划列表下方，**小组**部分让你决定哪些小组可以从他们的成员门户查看此计划类型的计划。这是一种快速方式，可以将即将来临的服务表面给正确的团队，而无需向他们提供管理员访问权限。

1. 在计划类型页面上，向下滚动到**小组**部分。
2. 点击**添加小组**并从下拉列表中选择一个小组。
3. 在**显示**列中，选择该小组的成员是否应该看到此计划类型的**过去**、**未来**或**两者**计划。
4. 重复以关联其他小组，或点击垃圾桶图标来删除小组。

:::info
只有标记为**标准**的小组才会出现在选择器中。关联小组的成员会自动在B1成员门户中看到该计划类型的计划 — 限制在你选择的过去/未来/两者窗口。
:::

如果计划是Lessons.church课程，关联小组的成员也会在小组页面上看到**本周课程**卡片（底行、经节和给父母的问题）。在此处关联一个家长小组，并将过滤器设置为**过去**，以便包含今天的课程。志愿者团队通常使用**未来**或**两者**。

## 打印计划

你可以打印计划以分发给你的团队。打开计划，打开服务顺序标签并使用**打印**选项生成一个可打印版本，包括分配和服务顺序。这对于在排练时分发或在公共区域发布很有用。

:::info
计划按事工组织。在创建或查看计划之前，请确保你在正确的事工标签上。
:::
