# 服事计划

<div class="article-intro">

服事计划用于安排谁在何时服事。每个计划都与特定的日期和事工相关联，使你可以逐周协调志愿者团队，确保每场礼拜都有足够的人手。

</div>

## 访问计划

1. 在 B1 Admin 中，打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **Serving**，然后点击 **Plans**。
2. 选择页面顶部的**事工标签页**。
3. 点击某个**计划类型**，查看该类型的计划列表。使用列表上方的 **Upcoming**（即将到来）和 **Past**（过去）可在未来和较早的计划之间切换。**Upcoming** 列出从今天起的计划，最近的排在最前，没有日期的计划排在最后。**Past** 只列出较早的计划，最新的排在最前。
4. 点击某个具体计划即可将其打开。

每个计划页面都会显示返回其计划类型和 **Plans** 的链接，因此你无需使用浏览器的后退按钮即可返回上一级。

:::info
管理计划无需完整的管理员权限。任何事工的成员都可以进入服事区域，为自己的事工创建、编辑和安排计划，而无需拥有 Plans Edit 权限。拥有 Plans Edit 角色的编辑者可以管理所有事工的计划。
:::

## 创建计划

1. 在计划类型页面，点击页面顶部的 **New Plan**（新建计划）。
2. 为计划命名，或直接使用日期作为名称。选择服事的**日期**。
3. 如果你的事工有[模板](./plan-templates.md)，可以在 **Start from template**（从模板开始）下选择一个模板，一步完成礼拜程序、岗位和备注的填写。
4. 否则，如果你希望从之前的计划复制，请使用 **Copy from Previous Plan**（从上一计划复制），选择 **Positions Only**（仅岗位）或 **Positions and Assignments**（岗位和分配）。如果不想复制，请选择 **Nothing**（无）。你也可以勾选 **Copy Order of Service**（复制礼拜程序）。从上一计划复制时，新计划还会保留该计划的 **Notes**（备注）、**Signup Deadline**（报名截止时间）、**Show volunteer names on signup page**（在报名页面显示志愿者姓名）以及自动替换设置，因此你无需每周重新填写。你可以在新计划的设置中更改其中任何一项。
5. 若要在复制的同时一次设置多个计划，请选择 **Repeat every**（重复周期）和 **Frequency**（频率）（Day（日）、Week（周）或 Month（月）），然后输入 **Number of plans**（计划数量）（最多 12 个）。对于按月重复，**On**（于）选项可让你保持在每月的同一天，或同一个星期几，例如每月第二个星期六。B1 会在保存前列出日期，并为每个日期创建一个计划，每个计划都从前一个计划复制而来。如果计划以日期命名，则每个新计划都会以其自身的日期命名。
6. 可选设置 **Signup Deadline (hours before service)**（报名截止时间，礼拜前的小时数）。新计划会沿用上一计划的截止时间，你可以在此更改。留空则没有截止时间。有关截止时间的计算方式，请参阅[计划设置](#plan-settings)。
7. 保存计划。现在你可以开始分配团队成员，并编排[礼拜程序](./service-order.md)。

:::tip
只有在从上一计划复制内容（岗位、分配或礼拜程序）时，重复设置才可用。
:::

## 计划详情页面

打开一个计划后，计划名称、事工、计划类型和服事日期会显示在页面顶部，并附有 **Edit**（编辑）和 **Print**（打印）按钮。其下的所有内容都在同一页面中：

- **[礼拜程序](./service-order.md)** —— 使用敬拜歌曲、祷告、公告和讲道等元素编排礼拜程序。
- **Serving Team Assignments**（服事团队安排）—— 管理分配到该计划的团队成员。你可以从现有团队中添加人员，并查看哪些人已确认或仍在待定。岗位上方的链接可让你打开计划的 **Notes**（备注）和 **Times**（时间）。

## 分配团队成员 {#assigning-team-members}

1. 打开一个计划，滚动到 **Serving Team Assignments**。
2. 点击 **Add Position**（添加岗位）。填写添加岗位表单中的信息。分类名称可自行填写。如果希望任何教会成员都能担任该岗位（而不仅限于某一团队的成员），请将 **Volunteer Group**（志愿者小组）保持为 **None**（无）。
3. 点击 **People Needed**（所需人员），选择志愿者来担任该岗位。如果该岗位设有 **Volunteer Group**，你将从该小组的成员中选择。如果其 Volunteer Group 设为 **None**，则可以搜索教会中的任何人。
4. 点击 **Add**，从你的团队名单中添加成员。
5. 被分配的成员会显示在其团队下，并附有其分配状态。
6. 点击 notify volunteers（通知志愿者），通过 B1 应用或电子邮件通知他们。如果该计划使用了[确认工作流](#plan-settings)，通知操作还会启动一个工作流卡片，持续跟进每个请求，直到志愿者作出回应。

每个岗位都会显示一个计数标签（例如"2/3"），让你一眼看出已有多少个名额已填满。在 **Serving Team Assignments** 标题下方，会显示一行摘要（"X 个岗位中已填 Y 个"），说明该计划的整体人手情况以及仍需多少人，一旦所有岗位都已安排，则会切换为 **Fully staffed**（人手已满）。

:::tip
在创建计划之前，先在事工设置中配置好你的团队。这样你就有现成的志愿者人选可供分配。
:::

### 将岗位复制到空计划中

如果某个计划尚无岗位，而且存在同类型的较早计划，则在 **Serving Team Assignments** 中会出现一个 **Copy from Previous Plan** 链接。选择 **Positions Only** 或 **Positions and Assignments**，即可用上一计划的岗位（以及志愿者）填充你当前打开的计划。复制的内容会进入当前计划；它不会为同一日期创建第二个计划。

## 计划设置 {#plan-settings}

每个计划都有额外的设置，你可以点击计划类型列表中计划旁边的 **Edit**，或计划页面顶部的 **Edit** 按钮进行配置。点击 **Done**（完成）或计划名称即可返回计划。这些设置包括：

- **Signup Deadline (hours before service)**（报名截止时间，礼拜前的小时数）—— 礼拜前多少小时截止志愿者报名。该时间从计划的第一个**礼拜**时间倒推计算（排练和其他时间会被跳过，除非计划中没有其他时间）。因此，如果一场 10:00 AM 的礼拜设置了 2 小时的截止时间，那么报名会在当天上午 8:00 截止。如果计划没有设置任何时间，则截止时间从服事日期当天教会时区的上午 9:00 开始计算。截止时间一过，志愿者既不能报名，也不能取消自己的报名。输入负数可让报名在礼拜开始后仍保持开放。留空或清除该字段，则表示没有截止时间。
- **Confirmation workflow**（确认工作流）—— 选择一个[服事安排确认工作流](./workflows.md#serving-assignment-confirmations)，通过电子邮件和短信跟进该计划的服事请求，直到每位志愿者接受或婉拒为止。当你在已发布的计划上**通知**志愿者时，每个新请求都会在该工作流的看板上获得自己的卡片，并且通知链接上方会显示一条备注："新请求将使用确认工作流。"如果希望保留常规通知，请保持选择 **Use existing assignment notifications**（使用现有的安排通知）。列表中只会显示处于活动状态的确认工作流；请先在 **Serving > Workflows** 下创建一个。
- **Show volunteer names on signup page**（在报名页面显示志愿者姓名）—— 勾选后，已登录的志愿者可以在 B1.church 报名页面上看到每个岗位已有哪些人报名。对于未登录的访客，永远不会显示姓名。
- **Penciled in**（暂定）—— 在你准备发布排班表之前，对志愿者隐藏安排。
- **Automatically schedule a replacement when a volunteer declines**（志愿者婉拒时自动安排替补）—— 勾选后，如果被分配的志愿者婉拒了其岗位，B1 会自动联系团队名单中的下一位可用人员，询问其是否可以服事。这一过程会沿名单依次进行，直到有人接受为止，无需人工跟进即可保持岗位有人。

:::tip
在成员报名页面上，每个计划的开放岗位会先按分类、再按名称列出。除非你在[设置 > 志愿者报名](../settings/church-settings.md#volunteer-signup)中开启了 **Show only the next week of each plan type**（仅显示每种计划类型的下一周），否则成员会看到所有有开放岗位的未来周次。
:::

## 志愿者提醒 {#volunteer-reminders}

B1 可以在志愿者被安排的礼拜之前自动提醒他们，因此你无需每周逐一催促团队。提醒会发送给**所有已被安排的人员**——包括已确认的和尚未回复的。例外情况是通过[确认工作流](./workflows.md#serving-assignment-confirmations)发出的请求：该志愿者只会在接受之后才收到提醒，因为在此之前，工作流会负责跟进。每封提醒邮件都包含志愿者的岗位、服事日期、计划备注以及你自定义的消息。

提醒的时间和内容按**计划类型**设置，因此每类礼拜都可以拥有自己的时间表。

1. 在**服事**区域中，选择包含该计划类型的事工。
2. 在 **Plan Types**（计划类型）列表中，点击该计划类型旁边的 **Edit**。
3. 展开 **Reminders**（提醒）部分，并开启 **Send reminders for plans of this type**（为此类型的计划发送提醒）。
4. 在 **When should reminders go out?**（何时发送提醒？）下，最多选择三个时间点：**7 days before**（提前 7 天）、**3 days before**（提前 3 天）、**2 days before**（提前 2 天）、**1 day before**（提前 1 天）或 **Day of**（当天）。
5. 设置提醒发送的 **Time of Day**（具体时间）。
6. 可选添加 **Message**（消息）。留空则使用默认的提醒文字。
7. 在 **Send By**（发送方式）下，选择 **Push**（推送）、**Email**（电子邮件），以及如果你的教会已连接[短信服务商](../settings/church-settings.md#texting)，还可以选择 **Text**（短信）。
8. 点击 **Save Reminders**（保存提醒）。

在你开启之前，计划类型的提醒默认为关闭状态。

:::tip
尚未确认的志愿者会在提醒邮件中直接看到 **Accept**（接受）和 **Decline**（婉拒）按钮，无需登录即可回复。
:::

### 短信提醒 {#text-reminders}

只有当你的教会已连接短信服务商时，才会出现 **Text**（短信）选项。短信通过你教会的短信服务商发送，每条短信都可能产生费用。只有当志愿者在其[通知偏好设置](../../b1-church/getting-started/notification-preferences.md)中开启了**短信**，并且个人资料中有手机号码时，才会收到短信提醒。每条短信开头都会注明你教会的名称，内容限制在一条短信之内，并以"回复 STOP 即可退订"结尾。回复 STOP 的人将不再收到你教会的短信。为了让 STOP 回复能够送达 B1，请将你的[短信设置](../settings/church-settings.md#texting)中的 **Inbound (STOP) webhook URL**（入站（STOP）webhook 网址）粘贴到服务商的入站消息 webhook 中。

若要立即向某个日期范围内的所有已排班人员发送短信，请使用[计划概览](./plans-overview.md#texting-everyone-scheduled)中的 **Text Volunteers**（向志愿者发送短信）。

:::info
每条提醒只会发送一次。短信提醒是在推送和电子邮件之外额外发送的，而不是替代它们。
:::

## 将小组与计划类型关联

在计划类型页面的计划列表下方，**Associated Groups**（关联小组）部分可让你决定哪些小组可以在其成员门户中查看该计划类型的计划。这是一种快速的方式，可在不给予管理员权限的情况下，将即将到来的礼拜告知相关团队。

1. 在计划类型页面，点击页面顶部的 **Associated Groups**（或向下滚动到该部分）。
2. 点击 **Add Group**（添加小组），并从下拉菜单中选择一个小组。
3. 在 **Shows**（显示）列中，选择该小组的成员应查看该计划类型的 **Past plans only**（仅过去的计划）、**Upcoming plans only**（仅即将到来的计划）还是 **Past and upcoming plans**（过去和即将到来的计划）。
4. 如需关联更多小组，请重复上述步骤；如需移除某个小组，请点击垃圾桶图标。

:::info
只有标记为 **Standard**（标准）的小组才会出现在选择器中。关联小组的成员会自动在 B1 成员门户的小组页面上看到该计划类型的计划——仅限于你所选的时间范围。
:::

如果这些计划是 Lessons.church 课程，关联小组的成员还会在小组页面上看到一张 **This week's lesson**（本周课程）卡片（包括底部的经文、经节以及给家长的问题）。在此关联一个家长小组，并将筛选条件设为 **Past plans only**（仅过去的计划），这样今天的课程就会包含在内。服事团队通常会使用 **Upcoming plans only** 或 **Past and upcoming plans**。

## 打印计划 {#printing-plans}

你可以打印计划分发给团队。打开计划后，点击页面顶部的 **Print**（打印），即可生成包含分配信息和礼拜程序的可打印版本。打印件顶部会显示你的教会标志（如果你已上传，则为来自[网站 > 外观](../website/appearance.md)的 **Light Background Logo**），标志下方是教会名称，然后是计划名称，以便散页也容易辨认。这对于在排练时分发，或张贴在公共区域都很有用。

打印件会省略任何空白内容。如果没有分配志愿者，则不会出现团队方框，礼拜程序将使用整个页面宽度。如果没有任何项目设置了长度，则会省略 **Length**（长度）列；如果计划既没有礼拜时间也没有长度，则同样会省略 **Time**（时间）列。若要去掉带有服事日期的黑色 **Service Order**（礼拜程序）标题栏，请取消勾选打印页面顶部的 **Show Service Order heading**（显示礼拜程序标题）；B1 Admin 会在该浏览器中记住你的选择。

:::info
计划按事工进行组织。在创建或查看计划之前，请确保你位于正确的事工标签页。
:::
