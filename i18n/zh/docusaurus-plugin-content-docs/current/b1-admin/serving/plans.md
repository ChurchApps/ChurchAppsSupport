# 服务计划

<div class="article-intro">

服务计划组织谁在服侍以及何时服侍。每个计划与特定日期和事工相关联，使您可以逐周协调志愿者团队，并确保每项服务都有充足的人员。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在服侍区域设置您的事工和团队
- 确保志愿者已添加到您的[人员目录](../people/adding-people.md)并分配给团队

</div>

## 访问计划

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**服侍**，然后点击**计划**。
2. 在页面顶部选择一个**事工选项卡**。
3. 点击一个**计划类型**来查看该类型的计划列表。使用列表上方的**Upcoming**和**Past**在未来计划和较早的计划之间切换。
4. 点击特定计划来打开它。

每个计划页面都包含返回其计划类型和**Plans**的链接，因此您无需使用浏览器的后退按钮即可返回上一级。

:::info
管理计划不需要完全的管理员访问权限。任何是事工成员的人都可以导航到服侍并为自己的事工创建、编辑和安排计划，而无需计划编辑权限。拥有计划编辑角色的编辑可以管理每个事工的计划。
:::

## 创建计划

1. 在计划类型页面上，点击页面顶部的**新建计划**。
2. 给计划一个名称或使用日期作为名称。选择服务的**日期**。
3. 如果您的事工有[模板](./plan-templates.md)，可以在**Start from template**下选择一个模板，一步填充服务顺序、位置和备注。
4. 否则，如果您想从之前的计划复制，请使用**Copy from Previous Plan**选择**Positions Only**（仅位置）或**Positions and Assignments**（位置和分配）。如果您不想复制，请选择**Nothing**（不复制）。您也可以勾选**Copy Order of Service**（复制服务顺序）。从上一个计划复制时，新计划还会保留该计划的**备注**、**报名截止时间**、**在报名页面上显示志愿者名称**以及自动替换设置，因此您不必每周重新输入。您可以在新计划的设置中更改其中任何一项。
5. 要在复制时一次设置多周，请在**Repeat weekly for this many weeks**中输入一个数字（最多12）。B1会每周创建一个计划，每个计划都从前一个计划复制而来。如果计划以日期命名，每个新计划都会以其自己的日期命名。
6. 可选地设置**Signup Deadline (hours before service)**（服务前报名截止小时数）。新计划会沿用上一个计划的截止时间，您可以在此更改。留空表示没有截止时间。
7. 保存计划。您现在可以开始分配团队成员并建立[服务顺序](./service-order.md)。

:::tip
**Repeat weekly for this many weeks**仅在您从上一个计划复制内容（位置、分配或服务顺序）时可用。
:::

## 计划详情页面

打开计划时，计划名称、事工、计划类型和服务日期会显示在顶部，并带有**编辑**和**打印**按钮。在其下方，所有内容都在同一页面上：

- **[服务顺序](./service-order.md)** -- 用敬拜歌曲、祷告、宣布和讲道等元素建立服务顺序。
- **服侍团队分配** -- 管理哪些团队成员被分配到此计划。您可以从现有团队添加人员，并查看谁已确认或仍在待处理中。位置上方的链接可让您打开计划的**备注**和**时间**。

## 分配团队成员 {#assigning-team-members}

1. 打开计划并滚动到**服侍团队分配**。
2. 点击**添加位置**。在添加位置表单中填充信息。对于类别名称，添加任何您喜欢的类别。要让教会中的任何人填充该位置（不仅仅是一个团队的成员），请将**志愿者组**设置为**无**。
3. 点击**所需人数**并选择志愿者来填充该位置。如果该位置有**志愿者组**，您从该组的成员中选择。如果其志愿者组设置为**无**，您可以搜索教会中的任何人。
4. 通过点击**添加**从您的团队花名册添加成员。
5. 分配的成员将与他们的分配状态一起出现在他们的团队下。
6. 点击通知志愿者来通知他们在B1应用程序中或通过电子邮件通知。

每个位置显示一个计数芯片（例如，"2/3"），以便您一目了然地看到有多少个位置被填充。在**服侍团队分配**标题下，一个摘要（"Y个位置中的X个已填充"）显示您的计划整体人员配置以及仍需要的人数，一旦每个位置都被覆盖，就切换到**人员充足**。

:::tip
在创建计划之前在事工设置中设置您的团队。这样，您将拥有一个现成的志愿者池来分配。
:::

### 将位置从之前的计划复制到空计划中 {#copying-positions-into-an-empty-plan}

如果计划还没有位置，并且存在同一类型的更早计划，**服侍团队分配**中会出现**Copy from Previous Plan**链接。选择**Positions Only**（仅位置）或**Positions and Assignments**（位置和分配），即可用之前计划的位置（以及志愿者）填充您打开的计划。复制内容进入当前计划；不会为同一日期创建第二个计划。

## 计划设置

每个计划都有额外的设置，您可以通过点击计划类型列表中计划旁边的**编辑**，或计划页面顶部的**编辑**按钮来配置。点击**完成**（或计划名称）即可返回计划。这些包括：

- **报名截止时间（服务前小时数）** -- 服务开始前志愿者报名关闭的小时数。输入负数以保持报名在服务开始时间后开放。留空表示没有截止时间。
- **在报名页面上显示志愿者名称** -- 当选中时，已登录的志愿者可以在 B1.church 报名页面上看到谁已经为每个位置报名。未登录的访客永远看不到名称。
- **暂定** -- 隐藏分配，直到您准备好发布时间表。
- **当志愿者拒绝时自动安排替代人员** -- 当选中时，如果分配的志愿者拒绝他们的位置，B1将自动联系团队名册上的下一个可用人员，并询问他们是否可以服侍。这会沿着列表继续下去，直到某人接受，保持您的位置被填充，而无需手动跟进。

## 志愿者提醒 {#volunteer-reminders}

B1可以自动提醒志愿者他们被安排服侍的服务，这样您就不必每周追赶您的团队。提醒发送给**所有被安排的人** -- 那些已确认的和尚未回应的。每封提醒电子邮件包括志愿者的位置、服务日期、计划说明和您的自定义消息。

提醒时间和内容按**计划类型**设置，因此每种类型的服务都可以保持自己的时间表。

1. 从**服侍**区域，选择包含计划类型的事工。
2. 在**计划类型**列表中，点击计划类型旁边的**编辑**。
3. 展开**提醒**部分并打开**Send reminders for plans of this type**（为此类型的计划发送提醒）。
4. 在**When should reminders go out?**（何时发送提醒？）下，最多选择三个时间：**7 days before**（提前7天）、**3 days before**（提前3天）、**2 days before**（提前2天）、**1 day before**（提前1天）或**Day of**（当天）。
5. 设置提醒发送的**Time of Day**（时间）。
6. 可选地添加**Message**（消息）。留空则使用默认的提醒措辞。
7. 在**Send By**（发送方式）下，选择**Push**（推送）、**Email**（电子邮件），如果您的教会已连接[短信提供商](../settings/church-settings.md#texting)，还可以选择**Text**（短信）。
8. 点击**Save Reminders**（保存提醒）。

在您打开提醒之前，计划类型的提醒处于关闭状态。

:::tip
尚未确认的志愿者在提醒电子邮件中直接获得**接受**和**拒绝**按钮，因此他们可以在不登录的情况下回应。
:::

### 短信提醒 {#text-reminders}

只有当您的教会连接了短信提供商时，**短信**选项才会出现。短信通过您教会的短信提供商发送，每条短信可能会产生费用。只有在志愿者于其[通知首选项](../../b1-church/getting-started/notification-preferences.md)中开启了**Text messages**，并且其资料中有手机号码时，才会收到短信提醒。每条短信都以您教会的名称开头，保持为单条短信，并以"Reply STOP to opt out."结尾。回复 STOP 的人将不再收到您教会的短信。为使 STOP 回复能够到达 B1，请将[短信设置](../settings/church-settings.md#texting)中的**Inbound (STOP) webhook URL**粘贴到您提供商的入站消息 webhook 中。

要立即向一段日期范围内的所有被安排者发送短信，请使用[计划概览](./plans-overview.md#texting-everyone-scheduled)上的**给志愿者发送短信**。

:::info
每个提醒只发送一次。短信提醒是在推送和电子邮件之外另外发送的，而不是替代它们。
:::

## 将组与计划类型相关联

在计划类型页面的计划列表下方，**关联组**部分让您决定哪些组可以从其成员门户中查看此计划类型的计划。这是一种快速方式，可以将即将进行的服务显示给正确的团队，而无需给予他们管理员访问权限。

1. 在计划类型页面上，点击页面顶部的**Associated Groups**（或向下滚动到该部分）。
2. 点击**添加组**并从下拉菜单中选择一个组。
3. 在**显示**列中，选择该组的成员应该看到此计划类型的**仅过去的计划**、**仅即将到来的计划**还是**过去和即将到来的计划**。
4. 重复以关联其他组，或点击垃圾图标来删除组。

:::info
只有标记为**标准**的组才会出现在选择器中。关联组的成员会自动在B1成员门户中的组页面上看到此计划类型的计划 -- 仅限于您选择的时间范围。
:::

如果计划是Lessons.church课程，关联组的成员也会在组页面上看到**本周的课程**卡片（底行、经文和家长问题）。在这里关联一个家长组并将过滤器设置为**仅过去的计划**，以便包含今天的课程。志愿者团队通常使用**仅即将到来的计划**或**过去和即将到来的计划**。

## 打印计划

您可以打印计划来分发给您的团队。打开计划，并点击页面顶部的**打印**按钮生成可打印版本，其中包括分配和服务顺序。打印件的顶部显示您教会的名称和计划的名称，因此松散的页面很容易识别。这对于在排练时分发或在公共区域张贴很有用。

:::info
计划按事工组织。在创建或查看计划之前，请确保您在正确的事工选项卡上。
:::
