# 服侍计划

<div class="article-intro">

服侍计划用于组织谁在服侍以及何时服侍。每个计划都关联到特定的日期和事工，便于您逐周协调志愿者团队，确保每场礼拜都配备齐全。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在服侍区域中设置您的事工和团队
- 确保志愿者已添加到您的[人员目录](../people/adding-people.md)中并分配到团队

</div>

## 访问计划

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **服侍**，然后点击 **计划**。
2. 选择页面顶部的**事工标签**。
3. 点击某个**计划类型**，查看该类型的计划列表。使用列表上方的 **即将到来** 和 **过去** 在未来与较早的计划之间切换。**即将到来** 列出从今天起的计划，最近的排在最前，未设置日期的计划排在最后。**过去** 只列出较早的计划，最新的排在最前。
4. 点击某个具体计划以打开它。

每个计划页面都会提供返回其计划类型和 **计划** 页面的链接，因此您无需使用浏览器的后退按钮即可返回上一级。

:::info
管理计划不需要完整的管理员权限。任何事工成员都可以前往服侍区域，为自己的事工创建、编辑和安排计划，而无需计划编辑权限。拥有计划编辑角色的编辑者可以管理所有事工的计划。
:::

## 创建计划

1. 在计划类型页面顶部，点击 **新建计划**。
2. 为计划命名，或直接使用日期作为名称。选择礼拜的**日期**。
3. 如果您的事工有[模板](./plan-templates.md)，可以在 **从模板开始** 下选择一个，一步填入礼拜程序、职位和备注。
4. 否则，如果您想复制上一个计划，请使用 **复制上一个计划**，选择 **仅职位** 或 **职位和分配**。如果不想复制，请选择 **无**。您还可以勾选 **复制礼拜程序**。从上一个计划复制时，新计划还会保留该计划的 **备注**、**报名截止时间**、**在报名页面显示志愿者姓名** 以及自动替补设置，因此您无需每周重新输入。您可以在新计划的设置中更改其中任何一项。
5. 如果要在复制时一次设置多周，请在 **重复每周此次数** 中输入数字（最多 12）。B1 会为每周创建一个计划，每个计划都复制自前一个。如果计划以日期命名，则每个新计划都会以其各自的日期命名。
6. 可选择设置 **报名截止时间（礼拜前小时数）**。新计划会沿用上一个计划的截止时间，您可以在此更改。留空则表示没有截止时间。有关截止时间的计算方式，请参阅[计划设置](#plan-settings)。
7. 保存计划。现在您可以开始分配团队成员，并编排[礼拜程序](./service-order.md)。

:::tip
**重复每周此次数** 仅在您复制上一个计划的内容（职位、分配或礼拜程序）时可用。
:::

## 计划详情页面

打开计划时，计划的名称、事工、计划类型和服侍日期会显示在顶部，并带有 **编辑** 和 **打印** 按钮。其下所有内容都在同一页面中：

- **[礼拜程序](./service-order.md)** -- 使用敬拜诗歌、祷告、公告和讲道等元素编排礼拜程序。
- **服侍团队分配** -- 管理分配到此计划的团队成员。您可以从现有团队中添加人员，并查看谁已确认、谁仍待定。职位上方的链接可让您打开计划的 **备注** 和 **时间**。

## 分配团队成员

1. 打开计划，滚动到 **服侍团队分配**。
2. 点击 **添加职位**。填写添加职位表单中的信息。类别名称可自行填写任何类别。如果希望教会中的任何人都能担任该职位（而不仅限于某一个团队的成员），请将 **志愿者组** 保持为 **无**。
3. 点击 **所需人员** 并选择志愿者来填补该职位。如果该职位设有 **志愿者组**，您可以从该组的成员中选择。如果其志愿者组设置为 **无**，则可以搜索教会中的任何人。
4. 点击 **添加**，从团队名册中添加成员。
5. 已分配的成员会显示在其团队下，并附有其分配状态。
6. 点击通知志愿者，即可通过 B1 应用或电子邮件通知他们。如果计划使用[确认工作流](#plan-settings)，通知操作还会启动一张工作流卡片，持续跟进每个请求，直到志愿者回复为止。

每个职位都会显示一个计数标签（例如 "2/3"），让您一眼看出有多少名额已经填满。在 **服侍团队分配** 标题下方，会显示汇总信息（"已填补 X / 共 Y 个职位"），反映计划的整体人员配备情况，以及仍需要的人数；当所有职位都已覆盖后，会切换为 **已完全配备**。

:::tip
在创建计划之前，先在事工设置中设置好您的团队。这样您就有现成的志愿者人选池可供分配。
:::

### 将职位复制到空计划中

如果计划还没有任何职位，而且存在同一类型的更早计划，则 **服侍团队分配** 中会出现 **复制上一个计划** 链接。选择 **仅职位** 或 **职位和分配**，即可用上一个计划的职位（以及志愿者）填充您当前打开的计划。内容会复制到当前计划中；不会为同一日期创建第二个计划。

## 计划设置

每个计划都有一些额外设置，您可以点击计划类型列表中该计划旁的 **编辑**，或计划页面顶部的 **编辑** 按钮进行配置。点击 **完成**（或计划名称）即可返回计划。这些设置包括：

- **报名截止时间（礼拜前小时数）** -- 礼拜前多少小时停止志愿者报名。时间从计划的第一个**礼拜**时间往前计算（排练和其他时间会被跳过，除非计划中没有其他时间），因此，上午 10:00 礼拜的 2 小时截止时间会在当天上午 8:00 关闭报名。如果计划没有时间，则截止时间从教会所在时区服侍日期的上午 9:00 开始计算。截止时间过后，志愿者既不能报名，也不能自行取消。输入负数可让报名在礼拜开始后仍保持开放。留空或清除该项，则表示没有截止时间。
- **确认工作流** -- 选择一个[服侍分配确认工作流](./workflows.md#serving-assignment-confirmations)，通过电子邮件和短信跟进此计划的服侍请求，直到每位志愿者接受或拒绝为止。在已发布的计划上点击 **通知** 志愿者时，每个新请求都会在该工作流的看板上获得自己的卡片，并且通知链接上方会显示提示 *"新请求将使用确认工作流。"* 若要保留常规通知，请选择 **使用现有分配通知**。只有已启用的确认工作流会出现在列表中；请先在 **服侍 > 工作流** 下创建一个。
- **在报名页面显示志愿者姓名** -- 勾选后，已登录的志愿者可以在 B1.church 报名页面上看到每个职位已有哪些人报名。未登录的访客永远看不到姓名。
- **暂存** -- 在您准备发布排班表之前，对志愿者隐藏分配。
- **志愿者拒绝时自动安排替补** -- 勾选后，如果已分配的志愿者拒绝其职位，B1 会自动联系团队名册上的下一位可用人员，询问其是否愿意服侍。此过程会按名单依次进行，直到有人接受，无需手动跟进即可保持职位填满。

:::tip
在会员报名页面上，每个计划的空缺职位会先按类别、再按名称列出。除非您在[设置 > 志愿者报名](../settings/church-settings.md#volunteer-signup)中开启 **仅显示每种计划类型的下一周**，否则会员会看到所有有空缺职位的即将到来的每一周。
:::

## 志愿者提醒 {#volunteer-reminders}

B1 可以在志愿者被排班的礼拜前自动提醒他们，这样您每周就不必一一追着团队成员跑。提醒会发送给 **所有被排班的人** -- 包括已确认的人和尚未回复的人。例外的情况是通过[确认工作流](./workflows.md#serving-assignment-confirmations)发送的请求：该志愿者只有在接受后才会收到提醒，因为在此之前工作流会负责跟进。每封提醒邮件都包含志愿者的职位、服侍日期、计划备注以及您自定义的消息。

提醒的时间和内容按**计划类型**设置，因此每种礼拜都可以有自己的时间表。

1. 在 **服侍** 区域中，选择包含该计划类型的事工。
2. 在 **计划类型** 列表中，点击该计划类型旁的 **编辑**。
3. 展开 **提醒** 部分，并开启 **为此类型的计划发送提醒**。
4. 在 **何时发送提醒？** 下，最多选择三个时间点：**提前 7 天**、**提前 3 天**、**提前 2 天**、**提前 1 天** 或 **当天**。
5. 设置提醒发送的 **时间**。
6. 可选择添加 **消息**。留空则使用默认的提醒措辞。
7. 在 **发送方式** 下，选择 **推送**、**电子邮件**，以及（如果您的教会已连接[短信服务商](../settings/church-settings.md#texting)）**短信**。
8. 点击 **保存提醒**。

在您开启之前，计划类型的提醒是关闭的。

:::tip
尚未确认的志愿者会在提醒邮件中直接看到 **接受** 和 **拒绝** 按钮，因此无需登录即可回复。
:::

### 短信提醒

只有当您的教会已连接短信服务商时，才会出现 **短信** 选项。短信通过教会的短信服务商发送，每条短信可能会产生费用。只有当志愿者在其[通知偏好设置](../../b1-church/getting-started/notification-preferences.md)中开启了 **短信**，并且个人资料中有手机号码时，才会收到短信提醒。每条短信都以教会名称开头，控制在一条短信之内，并以"回复 STOP 退订"结尾。回复 STOP 的人将不再收到您教会的短信。要让 STOP 回复传到 B1，请将[短信设置](../settings/church-settings.md#texting)中的 **入站（STOP）Webhook 网址** 粘贴到您服务商的入站消息 Webhook 中。

若要立即向某个日期范围内所有被排班的人发送短信，请使用[计划概览](./plans-overview.md#texting-everyone-scheduled)中的 **给志愿者发短信**。

:::info
每条提醒只发送一次。短信提醒是在推送和电子邮件之外额外发送的，而不是替代它们。
:::

## 将小组与计划类型关联

在计划类型页面的计划列表下方，**关联小组** 部分可让您决定哪些小组可以在其成员门户中查看此计划类型的计划。这是一种快速方式，可将即将到来的礼拜展示给合适的团队，而无需授予他们管理员权限。

1. 在计划类型页面上，点击页面顶部的 **关联小组**（或向下滚动到该部分）。
2. 点击 **添加小组**，然后从下拉列表中选择一个小组。
3. 在 **显示** 列中，选择该小组的成员应查看此计划类型的 **仅过去的计划**、**仅即将到来的计划**，还是 **过去和即将到来的计划**。
4. 重复此操作以关联更多小组，或点击垃圾桶图标移除某个小组。

:::info
只有标记为**标准**的小组才会出现在选择器中。关联小组的成员会自动在 B1 会员门户的小组页面上看到此计划类型的计划，且仅限于您所选的时间范围。
:::

如果这些计划是 Lessons.church 课程，关联小组的成员还会在小组页面上看到一张**本周课程**卡片（包括底线、经文以及给家长的问题）。在此将一个家长小组关联过来，并将筛选条件设为**仅过去的计划**，这样今天的课程就会被包括在内。服侍团队通常使用**仅即将到来的计划**或**过去和即将到来的计划**。

## 打印计划

您可以打印计划分发给团队。打开计划，点击页面顶部的 **打印**，即可生成包含分配和礼拜程序的可打印版本。打印件顶部会显示教会标志（如果您上传过，则为 [网站 > 外观](../website/appearance.md) 中的 **浅色背景标志**），标志下方是教会名称，并附有计划名称，方便区分散页。这在排练时分发或张贴在公共区域时很有用。

:::info
计划按事工组织。在创建或查看计划之前，请确保您位于正确的事工标签中。
:::
