# 服事

<div class="article-intro">

服事版块是协调志愿者和规划教会崇拜的中心。无论你是在组织主日崇拜、周中聚会还是特别活动，都可以在这里统筹一切，让各个团队清楚地知道谁在何时服事。

</div>

## 服事页面的运作方式 {#how-the-serving-page-works}

打开 **Serving**（服事）页面时，你会在顶部看到以标签页形式显示的各个事工。每个事工都有自己的计划类型和团队，因此你可以独立管理多个事工。例如，你可能有敬拜、儿童事工和接待等不同的标签页。

作为事工成员的非管理员工作人员也可以访问服事页面。他们只会看到自己所属的事工，并且无需完整的管理员权限，即可为其事工创建和编辑计划、分派、计划类型以及崇拜程序。

:::tip
如果你是管理员，标签页将显示你所属的事工，以及尚无成员的所有事工（**Mine**，我的）。选择 **All**（全部）可查看每个事工。当你需要核对多个团队的分派情况时，这一功能非常有用。如果你的教会有很多事工，页面会出现 **Find a ministry**（查找事工）输入框，方便你按名称筛选标签页。
:::

## 子版块 {#sub-sections}

服事版块包括以下主要功能：

- **[计划](./plans.md)** -- 为特定日期创建服事计划，并将志愿者分派到各个团队。计划可帮助你安排谁在何时服事，让每个人提前知道自己的职责。你可以通过推送、电子邮件或短信设置自动[志愿者提醒](./plans.md#volunteer-reminders)，让团队在每次礼拜前收到通知；并使用[计划总览](./plans-overview.md)，在一个网格中查看多周内的所有即将到来的分派。
- **[诗歌](./songs.md)** -- 管理你的敬拜诗歌库，包括歌词、编排和外部链接。敬拜团队可借此为即将到来的礼拜做准备。
- **[任务](./tasks.md)** -- 从 **My Work**（我的工作）中为团队成员分配和跟踪任务。
- **[工作流](./workflows.md)** -- 通过可视化的看板（Kanban）引导人员完成一系列步骤，例如新访客跟进或入会流程。步骤可以执行自动化操作（发送电子邮件、等待几天、加入小组），卡片可通过结果按钮、条件分流，或事件与定时触发器推进，并内置报表功能。

## 入门指南 {#getting-started}

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **Serving**（服事），然后点击 **Plans**（计划）。
2. 点击 **Add Ministry**（添加事工）以创建新事工，或选择 **All** 查看所有现有事工。选择某个**事工标签页**，即可查看其计划类型和服事团队。
3. 点击 **Create Plan Type**（创建计划类型）（或 **Add Plan Type**（添加计划类型）），或选择现有的计划类型，开始[创建服事计划](./plans.md)；也可以浏览[诗歌](./songs.md)和[任务](./tasks.md)子版块。

:::info
在创建计划之前，你需要先在服事区创建事工，并在每个事工下创建团队。选择某个事工标签页，然后在 **Serving Teams**（服事团队）列表中点击 **Create Serving Team**（创建服事团队）（或 **New Serving Team**（新建服事团队））即可添加团队。
:::
