# 服侍

<div class="article-intro">

服侍部分是您协调志愿者和计划教会服务的中心。无论您是组织周日敬拜、周中聚集还是特殊活动，这是您汇集所有内容的地方，以便您的团队确切知道谁在服侍以及何时服侍。

</div>

## 服侍页面如何工作

当您打开**服侍**页面时，您会看到您的事工显示为顶部的选项卡。每个事工都有自己的计划类型和团队，因此您可以独立管理多个事工。例如，您可能为敬拜、儿童事工和好客分别设置选项卡。

不是管理员但是事工成员的员工也可以访问服侍页面。他们只会看到他们所属的事工，并且可以创建和编辑计划、分配、计划类型以及他们事工的服务顺序，而无需完整的管理员权限。

:::tip
如果您是管理员，可以切换**显示全部**来一次查看所有事工。当您需要检查多个团队之间的分配时，这很有帮助。
:::

## 子章节

服侍部分包括这些关键领域：

- **[计划](./plans.md)** -- 为特定日期创建服务计划并将志愿者分配给团队。计划可帮助您组织谁在何时服侍，因此每个人都提前知道他们的角色。设置自动[志愿者提醒](./plans.md#volunteer-reminders)，以便在每次服务前通知您的团队，并使用**[计划概览](./plans-overview.md)**在一个网格中查看多周的所有即将进行的分配。
- **[歌曲](./songs.md)** -- 用歌词、编排和外部链接管理您的敬拜歌曲库。您的敬拜团队可以使用这个来为即将进行的服务做准备。
- **[任务](./tasks.md)** -- 从**我的工作**分配和跟踪您的团队成员的任务。
- **[工作流](./workflows.md)** -- 在视觉看板上将人员移动通过一系列步骤，例如新访问者跟进或会员过程。步骤可以运行自动化操作（发送电子邮件、等待几天、添加到群组），卡片可以通过结果按钮、条件路由或事件和日程触发器前进 -- 带有内置报告。

## 入门

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**服侍**，然后点击**计划**。
2. 点击添加事工按钮来创建新事工或切换"显示全部"来查看现有事工选项卡。选择一个**事工选项卡**来查看其计划类型和团队。
3. 选择"创建计划类型"或选择现有计划类型来开始[创建服务计划](./plans.md)，或探索[歌曲](./songs.md)和[任务](./tasks.md)子章节。

:::info
在创建计划之前，您需要在服侍区域中创建您的事工，以及在每个事工中创建团队。
:::
