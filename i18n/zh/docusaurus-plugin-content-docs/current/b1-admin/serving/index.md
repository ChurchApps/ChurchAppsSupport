# 服侍

<div class="article-intro">

服侍部分是你协调志愿者和规划教会服务的中心。无论你是组织周日敬拜、周中集会还是特殊活动，这是你汇聚一切的地方，使你的团队确切知道谁在服侍以及何时服侍。

</div>

## 服侍页面如何工作

当你打开**服侍**页面时，你会看到你的事工显示为顶部的标签。每个事工都有自己的计划类型和团队，所以你可以独立管理多个事工。例如，你可能有单独的敬拜、儿童事工和热情款待标签。

不是管理员的工作人员如果是事工的成员也可以访问服侍页面。他们只会看到他们所属的事工，并可以为他们的事工创建和编辑计划、分配、计划类型和服务顺序，无需完整的管理员权限。

:::tip
如果你是管理员，切换**显示全部**以一次查看所有事工。当你需要检查多个团队的分配时，这很有帮助。
:::

## 子部分

服侍部分包括这些关键区域：

- **[计划](./plans.md)** -- 为特定日期创建服务计划并将志愿者分配给团队。计划帮助你组织谁在何时服侍，所以每个人都提前知道他们的角色。设置自动[志愿者提醒](./plans.md#volunteer-reminders)使你的团队在每场服务前收到通知，并使用**[计划概览](./plans-overview.md)**在一个网格中查看多周的所有即将来临的分配。
- **[歌曲](./songs.md)** -- 使用歌词、编排和外部链接管理你的敬拜歌曲库。你的敬拜团队可以使用这个来为即将到来的服务做准备。
- **[任务](./tasks.md)** -- 从**我的工作**为你的团队成员分配和追踪任务。
- **[工作流](./workflows.md)** -- 在可视化看板上将人员通过一系列步骤移动，例如新访客后续跟进或成员资格流程。步骤可以运行自动化操作（发送电子邮件、等待几天、添加到小组），卡片通过结果按钮、条件路由或事件和日程触发器前进 -- 具有内置报告。

## 开始使用

1. 从B1 Admin中的主菜单导航到**服侍**。
2. 点击添加事工按钮以创建新事工或切换"显示全部"以查看现有事工标签。选择**事工标签**以查看其计划类型和团队。
3. 选择"创建计划类型"或选择现有计划类型以开始[创建服务计划](./plans.md)，或探索[歌曲](./songs.md)和[任务](./tasks.md)子部分。

:::info
在你能创建计划之前，你需要在服侍区域中创建你的事工和每个事工内的团队。
:::
