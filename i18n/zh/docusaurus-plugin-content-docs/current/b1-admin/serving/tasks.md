# 任务

<div class="article-intro">

任务让你为教会中的人或小组分配行动项目。无论是一次性待办事项还是重复性责任，任务都可以帮助你追踪需要做的事情和谁负责，以便没有遗漏任何事情。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 确保你想分配任务的人或[小组](../groups/creating-groups.md)存在于B1 Admin中
- 导航到**服侍**部分并打开**我的工作**以查看任务

</div>

## 查看任务

导航到**服侍**并打开**我的工作**。你会看到你的开放任务列表。每个任务显示其标题、被分配人和状态。

:::tip
默认情况下，只显示开放任务。切换**显示已关闭**以查看完成的任务。
:::

## 创建任务

1. 在任务页面上，点击**添加任务**。
2. 为任务输入**标题**。
3. 点击**分配给**框并输入一个人的名字，或切换到**小组**并输入小组名称。
4. 点击**搜索**并从结果中选择人或小组。
5. 添加**笔记**，其中包含被分配人的任何详细信息或说明。
6. 点击**保存**。

任务现在将出现在任务列表中，并在被分配人的仪表板和移动应用中可见。

## 管理任务

点击任何任务以打开其详细页面。从这里你可以：

- **改变状态** -- 使用状态下拉菜单在**开放**和**已关闭**之间切换。
- **重新分配任务** -- 将被分配人更新到不同的人或小组。
- **添加笔记** -- 为被分配人包含额外信息或更新。
- **编辑标题** -- 根据需要更新任务标题。

## 任务生命周期

1. 新任务从**开放**状态开始。
2. 被分配人收到通知，可以从他们的仪表板、**服侍 > 我的工作**或移动应用查看任务。
3. 工作完成后，被分配人（或管理员）将状态改为**已关闭**。
4. 已关闭的任务从默认视图中删除，但仍然可以通过启用**显示已关闭**访问。

:::info
B1 Admin不再按计划创建重复任务。对于与人的重复跟进，使用带有[日程触发器](./workflows.md#schedule-triggers)的[工作流](./workflows.md)。
:::

:::tip
当你需要通过同一组阶段移动许多人时 — 例如新访客后续跟进或成员资格流程 — 使用[工作流](./workflows.md)。工作流将任务转变为拖放板上的卡片，具有步骤、截止日期和路由。
:::

:::info
某些任务由B1的其他部分自动创建，并打开到特殊审查卡而不是标准笔记/重新分配视图 — [小组加入请求](../groups/group-join-requests.md#approving-from-the-tasks-page)、[个人资料更改请求](../profile/approving-profile-changes.md)和[账户删除请求](../profile/account-deletion.md)都以这种方式工作。
:::
