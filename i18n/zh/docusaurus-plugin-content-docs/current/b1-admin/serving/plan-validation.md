# 计划验证和志愿者通知

<div class="article-intro">

B1 Admin会在周日前自动检查你的计划是否存在问题 — 未填充的职位、日程冲突和在该日期已被阻止的志愿者。当一切看起来都很好时，你可以通过单击通知整个团队。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 创建一个[服务计划](./plans.md)并将志愿者分配给职位
- 向计划添加[服务时间](./plans.md)，以便冲突检测可以检查重叠
- 确保志愿者安装了B1 Mobile应用以接收推送通知

</div>

## 验证面板

每个计划都有一个**验证**面板，在你构建它时自动运行。它检查三件事：

### 未填充的职位
如果一个职位需要的人数多于当前分配的人数，验证面板会准确列出仍然需要的内容 — 例如，*"音响技师：还需要1人。"* 你可以一目了然地看到你的计划在周到来之前是否已满员。

### 日程冲突
如果一个志愿者被分配到两个在同一计划内时间重叠的职位，验证面板会标记冲突 — 例如，*"简·史密斯：周日服务期间敬拜领导者和儿童签到之间的时间冲突。"* 这会在双重预订成为周日早上的问题之前就抓住它。

### 封锁日期
志愿者可以在B1 Mobile中设置他们无法使用的日期。如果有人被分配到属于他们的封锁日期之一的计划中，验证面板会自动显示冲突，以便你可以找到替换者。

### 跨计划冲突
验证也检查所有计划的重叠。如果同一志愿者被分配到两个不同的计划中，这两个计划的时间重叠 — 例如，一个上午9点的服务和一个上午10点的服务，都运行到上午10:30 — B1 Admin会将该人标记为在计划之间双重预订。

:::tip
你不需要做任何事情来运行验证 — 每次你添加或更改分配时它都会自动更新。当你构建计划时只需留意面板即可。
:::

## 通知志愿者

计划确定后，你可以直接从验证面板一次通知所有分配的志愿者。

1. 打开计划并滚动到**验证**面板
2. 如果有未通知的志愿者，你会看到一个链接，显示有多少人需要被通知（例如，*"通知8名志愿者"*）
3. 点击链接向所有尚未被通知的人发送推送通知
4. 志愿者会在他们的手机上收到一条通知，让他们知道他们已被安排并提示他们确认他们的分配

:::info
只有尚未被通知的志愿者才会被包括。如果你稍后向计划中添加某人，该链接会重新出现，以便你可以通知新增加的人而不重新通知其他团队成员。
:::

:::warning
志愿者必须安装了B1.church移动体验（PWA在他们的主屏幕上，或仍然拥有它的用户的已弃用B1 Mobile原生应用），并启用了通知以接收推送通知。有关设置说明，请查看[安装为应用（PWA）](/docs/b1-church/getting-started/installing-pwa)。
:::
