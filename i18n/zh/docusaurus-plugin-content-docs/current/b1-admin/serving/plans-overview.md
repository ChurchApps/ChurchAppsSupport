# 计划概览

<div class="article-intro">

计划概览提供了您所有志愿者分配在多个服务日期上的全景视图。不必逐个打开每个计划，您可以在单个网格中看到谁在每个位置为接下来的几周服侍 -- 并快速发现还需要填补的任何空缺。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在服侍区域中创建至少一个事工和计划类型
- 创建[服务计划](./plans.md)和日期以及志愿者分配
- 确保您的志愿者已添加到您的[人员目录](../people/adding-people.md)

</div>

## 访问概览

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**服侍**，然后点击**计划**。
2. 在页面顶部选择一个**事工选项卡**。
3. 点击一个**计划类型**来打开其计划列表。
4. 点击页面顶部附近的**概览**按钮。

## 阅读概览网格

概览显示一个网格，其中：

- **行**代表每个位置（例如，"音乐：吉他"、"技术：投影"），按类别分组
- **列**代表即将进行的服务日期（例如，"4月14日"、"4月21日"）
- **单元格**显示分配到该日期该位置的志愿者的名称

以**红色**突出显示的单元格是未填充的 -- 尚未分配志愿者。这使您可以一目了然地看到人员配置空缺，而无需逐个打开每个计划。

:::tip
志愿者名称以简短格式显示（名字和姓氏首字母，例如"John D."），以便在您有许多位置时保持网格紧凑。
:::

## 从概览直接分配志愿者

您不需要打开单个计划来填补空位。点击网格中的任何单元格以打开该位置和日期的分配面板。从那里您可以：

- 从您的团队中选择一个人来分配到该位置
- 点击已分配的任何人旁边的**删除**来将其从该槽中移除
- 保存更改而不离开概览

这使得在一次通过中为整个时间表安排人员成为可能 -- 跨周和位置进行工作，而无需在单个计划中导航。

## 从概览自动安排

点击**自动安排**让B1一次填充当前网格中的每个打开的、未填充的槽。对于视图中的每个计划，它从链接到每个位置的群组中提取候选人，并自动填充空槽，报告它能够填充多少个可见计划。计划一次填充一个，所以同一志愿者不会在同一通过中跨两个日期被重复预订。

:::info
自动安排只填充已经为空的槽位 -- 它从不替换现有分配。
:::

## 给所有安排的人发送电子邮件

点击**给志愿者发送电子邮件**来一次性向在当前过滤日期范围和事工中的任何地方分配的每个志愿者发送通知，而不是逐个计划发送电子邮件。B1报告发送了多少封电子邮件以及有多少封失败了。

## 突出显示志愿者的日程表

使用**突出显示**下拉菜单来选择您的团队中的一个人 -- 网格中分配他们的每个单元格都会被强调，因此在将他们添加到另一个槽之前，您可以看到他们已经在哪里服侍。选择**全部**来关闭突出显示。

## 过滤概览

您可以使用顶部的过滤控件调整概览显示的内容：

- **开始日期 / 结束日期** -- 默认情况下，概览显示未来12周。输入自定义日期来扩展或缩小范围。
- **事工** -- 切换到不同事工而不离开概览。
- **计划类型** -- 在选定的事工中过滤到特定的计划类型。
- **仅未填充** -- 打开此选项来隐藏每个日期都已填充的行，这样您可以只专注于仍需要志愿者的位置。

进行更改后点击**过滤**来更新网格。

## 导出为CSV

点击**导出CSV**来将当前网格下载为电子表格。导出包含过滤日期范围的所有位置和志愿者分配，使其易于与事工领导人分享或打印用于计划会议。

:::info
CSV导出反映当前应用的任何过滤 -- 只有网格中显示的日期和计划类型包含在下载中。
:::
