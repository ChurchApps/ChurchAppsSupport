# 计划总览

<div class="article-intro">

计划总览让您可以一目了然地查看多个服事日期上的所有志愿者安排。您无需逐个打开每个计划,而是可以在一个网格中查看未来几周内每个职位的服事人员——并快速发现仍需填补的空缺。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在事工服事区域中至少创建一个事工和一种计划类型
- 创建带有日期和志愿者安排的[服事计划](./plans.md)
- 确保您的志愿者已被添加到[人员目录](../people/adding-people.md)中

</div>

## 访问总览

1. 从 B1 Admin 主菜单导航到**事工服事**。
2. 在页面顶部选择一个**事工标签**。
3. 点击一种**计划类型**以打开其计划列表。
4. 点击页面顶部附近的**总览**按钮。

## 阅读总览网格

总览显示一个网格,其中:

- **行**代表按类别分组的每个职位(例如"音乐:吉他"、"技术:投影")
- **列**代表即将到来的服事日期(例如"4月14日"、"4月21日")
- **单元格**显示分配到该日期该职位的志愿者姓名

标记为**红色**的单元格表示未填补——尚未指定志愿者。这样您无需逐个打开计划,就能一目了然地看到人手空缺。

:::tip
志愿者姓名以简短格式显示(名字加姓氏首字母,例如"John D."),以便在职位较多时保持网格紧凑。
:::

## 直接从总览中安排志愿者

您无需打开各个计划来填补空缺。点击网格中的任意单元格,即可打开该职位和日期的分配面板。在那里您可以:

- 从您的团队中选择一个人分配到该职位
- 点击已分配人员旁边的**移除**将其从该岗位撤下
- 无需离开总览即可保存更改

这使得您可以一次性为整个日程安排人员——无需在各个计划之间来回切换,即可跨周次和职位进行操作。

## 从总览中自动排班

点击**自动排班**,让 B1 一次性填补当前网格中所有开放且未填补的空缺。对于视图中的每个计划,它会从与每个职位关联的小组中提取候选人并自动填补空缺,并报告它成功填补了多少个可见计划。计划是逐个填补的,因此同一个志愿者不会在同一轮次中被安排到两个日期而造成冲突。

:::info
自动排班只会填补已经空缺的岗位——它绝不会替换现有的安排。
:::

## 给所有已安排的人发送邮件

点击**发送邮件给志愿者**,一次性向当前筛选日期范围和事工中所有已被安排的志愿者发送通知,而无需逐个计划发送邮件。B1 会报告成功发送和失败的邮件数量。

## 高亮显示某位志愿者的日程

使用**高亮**下拉菜单从您的团队中选择一个人——网格中他们被分配到的每个单元格都会被标出,这样您在将他们加入另一个岗位之前,就能看到他们已经在哪些地方服事。选择**所有人**可关闭高亮显示。

## 筛选总览

您可以使用顶部的筛选控件调整总览显示的内容:

- **开始日期/结束日期**——默认情况下,总览显示未来 12 周的内容。输入自定义日期以扩大或缩小范围。
- **事工**——无需离开总览即可切换到其他事工。
- **计划类型**——筛选所选事工中的特定计划类型。
- **仅显示未填补**——开启此选项可隐藏所有日期都已填满的行,以便您只关注仍需志愿者的职位。

更改后点击**筛选**以更新网格。

## 导出为 CSV

点击**导出 CSV**,将当前网格下载为电子表格。导出内容包括筛选日期范围内的所有职位和志愿者安排,方便与事工负责人分享或在策划会议中打印。

:::info
CSV 导出反映当前应用的所有筛选条件——下载内容仅包含网格中显示的日期和计划类型。
:::
