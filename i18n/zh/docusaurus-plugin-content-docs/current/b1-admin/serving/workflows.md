# 工作流

<div class="article-intro">

工作流可让人们通过可视化面板上的一系列步骤移动。每个人都变成一张卡片，从一个步骤移动到下一个步骤 -- 从首次访客跟进、成员身份流程、首次捐赠感谢，到任何需要追踪许多人经过相同阶段的其他情况。一个步骤可以要求志愿者执行某些操作（打电话、进行对话）**并且**自动执行操作 -- 发送电子邮件或短信、等待几天、将人员添加到小组 -- 所以工作流处理人员跟进和围绕它的日常工作。工作流扩展了[任务](./tasks.md)到拖放式看板，因此没有任何东西或任何人会被遗漏。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 确保你想追踪的人员存在于 B1 Admin
- 熟悉[任务](./tasks.md)的工作方式，因为面板上的每张卡片都是一个任务
- 要使用**发送电子邮件**操作，请先创建要发送的电子邮件模板（在**消息传递 → 管理模板**下管理）
- 要使用**发送短信**操作，请先连接[短信提供商](../settings/church-settings.md#texting)
- 你需要适当的任务权限。查看、编辑卡片和管理工作流是单独的权限级别（参见[角色和权限](../settings/roles-permissions.md)）

</div>

## 查看工作流

打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开**服侍**，然后单击**工作流**。你将看到你的工作流列出并按类别分组，并突出显示活跃的工作流。单击任何工作流以打开其面板。

## 创建工作流

1. 在工作流页面上，单击**添加工作流**。
2. 选择开始方式：
   - **空白工作流** -- 从头开始，构建你自己的步骤。
   - **从模板** -- 从一组可以编辑的现成步骤开始。内置模板包括：
     - **新访客跟进** -- 发送欢迎电子邮件 → 个人电话 → 邀请到下一步 → 已连接
     - **成员身份课程** -- 表达兴趣 → 注册课程 → 参加课程 → 完成成员身份
     - **首次捐赠感谢** -- 发送感谢信 → 分享捐赠影响 → 已管理
3. 给工作流命名**名称**。
4. 可选地分配**类别**以将相关工作流分组在一起。你可以直接从下拉列表创建新类别。
5. 保留工作流**活跃**，以便人员可以添加到其中，或将其设置为**非活跃**以将其隐藏在添加到工作流列表中。
6. 单击**保存**。

:::tip
使用工作流列表上的**复制**按钮复制现有工作流 -- 包括其步骤、自动化操作和路由 -- 作为新工作流的起点。
:::

## 使用步骤构建面板

每个工作流面板由**步骤**组成，从左到右显示为列。打开工作流并使用**添加步骤**创建过程的每个阶段。

添加或编辑步骤时，你可以配置：

- **步骤名称** -- 列标题（例如，"欢迎电话"或"等待注册"）。
- **截止日期（天数）** -- 当卡片进入该步骤时自动设置截止日期。逾期的卡片被标记为**逾期**。
- **默认受让人** -- 此步骤上的新卡片自动分配给的人或小组。
- **自动化操作** -- 当卡片到达时系统自动执行的操作（见下文）。
- **路由** -- 卡片离开该步骤时的去向（参见[使用结果和条件路由卡片](#routing-cards-with-outcomes-and-conditions)）。

拖动步骤列以符合你的过程顺序。该顺序还定义了当没有其他路由适用时卡片采取的默认路径。

:::info
首先保存新步骤。自动化操作和路由附加到该步骤，因此一旦该步骤存在，编辑器就会解锁这些部分。
:::

## 自动化操作

每个步骤都可以带有一个**自动化操作**列表，当卡片**进入**步骤时立即自动执行 -- 在任何人触及之前。这是步骤如何既提示志愿者*又*处理跟进周围的日常工作的方式。

在步骤编辑器中，打开**自动化操作**，单击**添加操作**，选择一个类型，填写其设置，然后单击该操作上的保存图标。根据需要添加尽可能多；它们**从上到下按顺序**运行。

| 操作 | 功能 |
|---|---|
| **发送电子邮件** | 向该人发送你选择的电子邮件模板。你可以覆盖主题行。 |
| **发送短信** | 通过你教会的[短信提供商](../settings/church-settings.md#texting)向该人发送你写的消息。 |
| **等待** | 在继续之前将卡片暂停一定天数（见下文）。 |
| **添加到小组** | 将该人添加到你选择的[小组](../groups/index.md)。 |
| **从小组中删除** | 从你选择的小组中删除该人。 |
| **添加到工作流** | 在另一个工作流上启动该人 -- 用于在流程之间进行交接。 |
| **添加备注** | 在卡片的历史记录中记录备注。 |
| **设置字段** | 更新人员记录上的字段：成员身份状态、婚姻状况、性别、城市、州或邮编。 |
| **Webhook** | 将卡片的详细信息发送到你提供的外部网址 (URL)，用于连接到其他系统。 |
| **创建任务** | 创建[任务](./tasks.md)，输入标题和描述，分配给你选择的任何人。 |

步骤的所有操作完成后，卡片**停留在该步骤**上，以便人员可以处理它 -- 除非该步骤具有自动将其向前移动的自动路由（参见[完全自动化步骤](#fully-automated-steps)）。

:::info
自动化操作仅在卡片通过正常流程到达时运行 -- 当首次添加卡片、当结果或自动路由将其带入时，或在等待完成后。当工作人员手动将卡片拖到步骤上或将其发送回去时，它们**不会**重新运行，因此人员不会获得相同的电子邮件两次。
:::

### 发送电子邮件

选择**发送电子邮件**，选择你的电子邮件模板之一，并可选地键入自定义主题。当卡片进入步骤时，该人自动收到该电子邮件。（如果该人的档案上没有电子邮件地址，该步骤只是跳过此操作。）模板中的[合并字段](../settings/email-templates.md#merge-fields)（如 `{{firstName}}`）会填充该人自己的详细信息。

:::info
工作流电子邮件仅在你的教会被批准发送群组电子邮件后才会发出，并且计入你的教会每日电子邮件限额。参见[为你的教会打开群组电子邮件](../groups/group-members.md#turning-on-group-email-for-your-church)。
:::

### 发送短信

选择**发送短信**并键入**短信消息**（最多 1,600 个字符）。当卡片进入步骤时，该人会在其手机上收到该短信。你可以使用 `{{firstName}}`、`{{lastName}}`、`{{displayName}}` 或 `{{churchName}}` 将消息个性化，这些会在发送短信时填充该人的详细信息。

- 如果该人的档案上没有手机，该操作会被跳过。
- 如果该人已选择退出，不会发送任何文本，卡片的历史记录会记录**已跳过的短信：已选择退出**。
- 发送短信时，卡片的历史记录会记录**已发送短信**。如果发送失败 -- 例如，因为没有连接短信提供商或你的教会没有短信配额 -- 失败会被记录在卡片的历史记录中，步骤的其余操作仍然运行。

:::warning
短信通过你的教会自己的[短信提供商](../settings/church-settings.md#texting)发送。如果没有连接提供商，操作编辑器会警告*"未设置短信提供商"*，短信将不会发送。
:::

### 等待几天（滴灌序列）

**等待**操作会将卡片保留设置的天数。等待时，卡片显示为**已推迟**。等待结束时：

1. 同一步骤上的任何**剩余操作**运行 -- 所以你可以构建滴灌，如**发送电子邮件 → 等待 3 天 → 发送提醒电子邮件**。
2. 然后，如果该步骤有自动路由，卡片会向前移动；否则它停留在步骤上供人员提取。

:::tip
步骤开始处的**等待**是"保持"卡片的简单方法，然后再将其显示给志愿者 -- 例如，*等待 7 天，然后教练联系*。
:::

## 将人员添加为卡片

有几种方法可以将人员添加到面板：

- **从面板** -- 单击步骤列底部的**添加卡片**并选择人员。你也可以选择小组，该小组的每个成员都被添加为卡片。
- **从人员的记录** -- 使用人员页面上的**添加到工作流**将其放在工作流上。
- **从人员搜索** -- 选择多人并使用批量**添加到工作流**操作一次性添加所有人。
- **使用触发器自动添加** -- 当发生某些事情时添加人员，如表单提交或首次捐赠（参见下面的[触发器](#triggers)）。

## 处理面板

打开工作流以查看其面板。每张卡片显示该人的名字、分配对象，以及截止日期或状态芯片（**逾期**或**已推迟**）。步骤列也会显示其运行的任何自动化操作的小标记和其路由的注释，为你提供卡片流动方式的一目了然的地图。

- **移动卡片** -- 当人员进度时将卡片从一列拖到下一列。
- **打开卡片** -- 双击卡片（或单击它）打开其详细抽屉，你可以在其中更改步骤、重新分配它、添加备注和查看已发生的事情。

从卡片抽屉中，你可以：

- **分配**卡片给不同的人或小组。
- **推迟**卡片 1 天、3 天或 1 周，以暂时隐藏其截止日期。
- **发送回**上一步或**跳过**到下一步。
- **固定分配** -- 当卡片在步骤之间移动时保持同一所有者。默认情况下，将卡片移到新步骤会将其重新分配给该步骤的默认受让人；固定保持当前人员在整个过程中负责。
- **完成**卡片以完成它，或选择**结果**按钮（如果步骤已配置结果）（参见[路由](#routing-cards-with-outcomes-and-conditions)）。
- **添加备注**和查看卡片的**历史记录** -- 包括已运行的自动化操作的日志（发送的电子邮件、等待等）。

### 批量操作

选中多张卡片上的复选框以一起对其进行操作。出现工具栏，让你**完成**、**推迟**、**重新分配**或**移动**所有选定的卡片到另一个步骤。

## 使用结果和条件路由卡片

路由控制卡片离开步骤时的去向。打开步骤的编辑器以配置两种路由。

### 结果按钮

结果是完成该步骤上的卡片时显示在卡片抽屉中的按钮。你可以提供选择，如"加入小组"或"不感兴趣"，而不是单个**完成**按钮。每个结果可以：

- 将卡片发送到**此工作流中的另一个步骤**，
- **将卡片交接**到完全不同的工作流，或
- **关闭**卡片。

这让一个决定可以让该人走不同的路径。

### 自动路由（条件）

自动路由**在卡片进入步骤的那一刻**移动卡片（以及自动化操作完成后），无需任何人点击，如果该人与一组条件匹配。添加一条路由，选择目标步骤，并定义一个或多个**条件**（例如，一个人的校园、年龄或成员身份状态）。没有条件的路由与每个人匹配。

:::info
在面板上，每个步骤列显示描述其路由的小注释 -- 例如，结果标签或"如果匹配"，然后是到目标步骤或工作流的箭头。
:::

## 完全自动化步骤

你可以让步骤完全自动运行，无需任何人处理。给该步骤其**自动化操作**并添加**自动路由**（没有条件）指向下一步。当卡片进入时，操作运行，然后路由立即推进它 -- 卡片直接通过。

:::tip
将此与**等待**结合：*发送欢迎电子邮件 → 等待 3 天 → 自动进入"个人电话"步骤。* 电子邮件和时间为你处理，志愿者只在需要人工接触时看到卡片。
:::

## 触发器

触发器在发生某些事情时自动将人员添加到工作流中，因此你永远不必手动添加卡片。在工作流面板上，单击**触发器**选项卡，然后**添加触发器**。有两种类型：

### 事件触发器

当 B1 中的记录更改时立即触发。选择事件，然后可选地添加**条件**，以便仅添加匹配的人员：

- **人员 · 创建 / 更新** -- 例如，添加任何状态变为*访客*的人。
- **捐赠 · 已创建** -- 例如，将首次或大额捐赠添加到感谢工作流（按金额、资金或方式进行匹配）。
- **小组 · 成员加入** / **小组 · 已创建**。
- **表单 · 已提交** -- 添加提交选定表单的任何人（非常适合"我是新人"或"连接"卡片）。

### 计划触发器

定期运行 -- 每天、每周、每月或每年 -- 针对一组条件。使用这些进行基于时间的外展，如*所有成员身份周年纪念日为今天的人*或*月度*检查。

对于任何触发器，你也可以设置：

- 新卡片启动的**入口步骤**（默认为第一步）。
- **每人一次** -- 所以同一个人不会被触发器两次添加到工作流。
- **活跃** -- 打开或关闭触发器而不删除它。

:::tip
将**表单 · 已提交**触发器与**新访客跟进**模板配对，将你的"连接卡"或"我是新人"表单转换为自动跟进管道。
:::

## 我的卡片

志愿者和工作人员无需挖掘每个面板即可找到他们的工作。**我的卡片**页面（从工作流页面链接）列出分配给当前用户的所有工作流上的每张卡片。单击卡片打开它所属的面板。

## 报告

打开工作流并单击**报告**以查看该工作流的分析：

- **逾期** -- 逾期卡片数。
- **每步卡片数** -- 当前每个步骤上有多少张卡片，显示为柱状图。
- **已完成（30 天）** -- 过去 30 天的吞吐量，显示为折线图。

使用这些来发现瓶颈 -- 例如，卡片堆积并永不推进的步骤。
