# 工作流

<div class="article-intro">

工作流通过可视化看板将人员逐步推进。每个人成为一张卡片，从一个阶段移动到下一个阶段——从首访者跟进，到成员加入流程，到首次献金感谢，以及任何您需要追踪多个人通过相同阶段的场景。一个步骤可以要求志愿者执行某个操作（进行通话、进行交谈）**并且**自动运行操作——发送电子邮件、等待几天、将该人添加到小组——因此工作流既处理人工跟进，也处理围绕它的繁琐工作。工作流将[任务](./tasks.md)扩展为拖放式看板，确保没有任何人或事项遗漏。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 确保您要追踪的人员存在于 B1 Admin
- 熟悉[任务](./tasks.md)的工作方式，因为看板上的每张卡片都是一项任务
- 要使用**发送电子邮件**操作，请先创建您想发送的电子邮件模板（在**消息 → 管理模板**下管理）
- 您需要具有适当的任务权限。查看、编辑卡片和管理工作流是分开的权限级别（请参阅[角色和权限](../settings/roles-permissions.md)）

</div>

## 查看工作流

导航到**服务**，然后从菜单中选择**工作流**。您将看到您的工作流按类别列出并分组，活跃工作流突出显示。单击任何工作流以打开其看板。

## 创建工作流

1. 在工作流页面上，单击**添加工作流**。
2. 选择如何开始：
   - **空白工作流** —— 从头开始并构建您自己的步骤。
   - **从模板开始** —— 从现成的步骤集开始，您可以编辑。内置模板包括：
     - **新访客跟进** —— 发送欢迎电子邮件 → 个人通话 → 邀请下一步 → 已连接
     - **成员课程** —— 表示兴趣 → 课程注册 → 参加课程 → 完成成员加入
     - **首次献金感谢** —— 发送感谢便条 → 分享献金影响 → 已管理
3. 给工作流一个**名称**。
4. 可选择为工作流分配**类别**以将相关工作流分组在一起。您可以直接从下拉列表创建新类别。
5. 保持工作流**活跃**以便人员可以添加到其中，或将其设置为**无效**以从添加到工作流列表中隐藏它。
6. 单击**保存**。

:::tip
使用工作流列表上的**复制**按钮复制现有工作流——包括其步骤、自动操作和路由——作为新工作流的起点。
:::

## 使用步骤构建看板

每个工作流看板由从左到右显示为列的**步骤**组成。打开工作流并使用**添加步骤**来创建流程的每个阶段。

当您添加或编辑步骤时，您可以配置：

- **步骤名称** —— 列标题（例如，"欢迎通话"或"等待注册"）。
- **到期日期（天数）** —— 当卡片进入此步骤时自动设置到期日期。逾期的卡片被标记为**逾期**。
- **默认分配人** —— 新卡片在此步骤上自动分配给的人员或小组。
- **自动操作** —— 系统在卡片到达时自动执行的操作（请见下文）。
- **路由** —— 卡片离开步骤时的去向（请参阅[使用结果和条件路由卡片](#使用结果和条件路由卡片)）。

将步骤列拖动到与您的流程匹配的顺序。顺序还定义了当没有其他路由适用时卡片采取的默认路径。

:::info
首先保存新步骤。自动操作和路由附加到步骤，因此编辑器在步骤存在后才解锁这些部分。
:::

## 自动操作

每个步骤可以进行一系列**自动操作**，这些操作在卡片**进入**步骤时由自己运行——在任何人触及它之前。这就是一个步骤如何既提示志愿者**又**照顾跟进周围的常规工作的方式。

在步骤编辑器中，打开**自动操作**，单击**添加操作**，选择一个类型，填充其设置，然后单击该操作上的保存图标。根据需要添加尽可能多的操作；它们从**上到下按顺序**运行。

| 操作 | 它做什么 |
|---|---|
| **发送电子邮件** | 发送您选择的电子邮件模板给该人。您可以覆盖主题行。 |
| **等待** | 在继续之前暂停卡片指定天数（请见下文）。 |
| **添加到小组** | 将该人添加到您选择的[小组](../groups/index.md)。 |
| **添加到工作流** | 在另一个工作流上启动该人——对于在流程之间移交很有用。 |
| **添加备注** | 在卡片历史中记录备注。 |
| **设置字段** | 更新人员记录上的字段：成员状态、婚姻状态、性别、城市、州或邮编。 |
| **网络钩子** | 将卡片的详细信息发送到您提供的外部网址 (URL)，用于连接到其他系统。 |

步骤的所有操作完成后，卡片**停留在该步骤**以便一个人可以处理它——除非该步骤具有将其向前移动的自动路由（请参阅[完全自动化步骤](#完全自动化步骤)）。

:::info
自动操作仅在卡片通过正常流程到达时运行——当它首次被添加、当结果或自动路由将其带入时，或在等待完成后。当员工手动将卡片拖到步骤或将其发送回去时，它们**不会**重新运行，因此一个人不会收到相同电子邮件两次。
:::

### 发送电子邮件

选择**发送电子邮件**，选择您的一个电子邮件模板之一，并可选择键入自定义主题。当卡片进入步骤时，该人自动收到该电子邮件。（如果该人的文件中没有电子邮件地址，该步骤只是跳过此操作。）

:::info
工作流电子邮件仅在您的教会获得批准发送组电子邮件后才会发出，它们计入您教会的每日电子邮件限制。请参阅[为您的教会启用组电子邮件](../groups/group-members.md#为您的教会打开小组电子邮件)。
:::

### 等待几天（滴灌序列）

**等待**操作将卡片保留您设置的天数。当它等待时，卡片显示为**已暂停**。等待结束后：

1. 同一步骤上的任何**剩余操作**运行——所以您可以构建一个类似**发送电子邮件 → 等待 3 天 → 发送提醒电子邮件**的滴灌。
2. 然后，如果该步骤有自动路由，卡片会向前移动；否则它停留在步骤上以供人员处理。

:::tip
步骤开始处的**等待**是"保留"卡片然后才将其显示给志愿者的简单方法——例如，*等待 7 天，然后教练会联系*。
:::

## 添加人员作为卡片

有几种方法可以将人员放在看板上：

- **从看板** —— 单击步骤列底部的**添加卡片**并选择一个人。您也可以选择一个小组，该小组的每个成员都被添加为卡片。
- **从人员记录** —— 在人员页面上使用**添加到工作流**将其放到工作流上。
- **从人员搜索** —— 选择多个人员并使用批量**添加到工作流**操作一次性添加他们所有人。
- **使用触发器自动** —— 在发生某些事情时添加人员，如表单提交或首次献金（请参阅下面的[触发器](#触发器)）。

## 处理看板

打开工作流以查看其看板。每张卡片显示人员的名字、分配给谁，以及到期日期或状态芯片（**逾期**或**已暂停**）。步骤列也显示其运行的任何自动操作的小徽章和其路由的注释，为您提供卡片如何流动的一眼了解。

- **移动卡片** —— 当人员进展时，将卡片从一列拖到下一列。
- **打开卡片** —— 双击卡片（或点击它）以打开其详细信息抽屉，您可以在其中更改步骤、重新分配它、添加备注并查看已发生的情况。

从卡片抽屉您可以：

- **分配**卡片给不同的人员或小组。
- **暂停**卡片 1 天、3 天或 1 周以暂时隐藏其到期日期。
- **发送回**上一步或**跳过**到下一步。
- **固定分配** —— 即使卡片在步骤之间移动，也要保持相同的所有者在卡片上。默认情况下，将卡片移动到新步骤会将其重新分配到该步骤的默认分配人；固定会在整个过程中保持当前人员负责。
- **完成**卡片以完成它，或选择**结果**按钮（如果步骤配置了结果）（请参阅[路由](#使用结果和条件路由卡片)）。
- **添加备注**并查看卡片的**历史** —— 包括已运行的自动操作的日志（已发送的电子邮件、等待等）。

### 批量操作

在多张卡片上选择复选框以一起处理它们。工具栏出现让您**完成**、**暂停**、**重新分配**或**移动**所有选定的卡片到另一步骤一次。

## 使用结果和条件路由卡片

路由控制卡片离开步骤时的去向。打开步骤的编辑器以配置两种路由。

### 结果按钮

结果是在您完成该步骤上的卡片时显示在卡片抽屉中的按钮。您可以提供选择，而不是单一的**完成**按钮，例如"加入小组"或"不感兴趣"。每个结果可以：

- 将卡片发送到**此工作流中的另一步骤**，
- **将卡片移交**给完全不同的工作流，或
- **关闭**卡片。

这让一个决定可以将人员分支到不同的路径。

### 自动路由（条件）

自动路由在卡片**进入步骤时的瞬间**（在其自动操作完成后）将卡片向前移动，如果人员匹配一组条件，则无需任何人点击。添加路由，选择目标步骤，并定义一个或多个**条件**（例如，人员的校园、年龄或成员状态）。没有条件的路由匹配所有人。

:::info
在看板上，每个步骤列都显示描述其路由的小注释——例如，结果标签或"如果匹配"，然后是指向目标步骤或工作流的箭头。
:::

## 完全自动化步骤

您可以使一个步骤完全自动运行，没有人处理它。给该步骤其**自动操作**并添加一个**自动路由**（没有条件）指向下一步骤。当卡片进入时，操作运行，然后路由立即推进它——卡片直接通过。

:::tip
将其与**等待**结合：*发送欢迎电子邮件 → 等待 3 天 → 自动推进到"个人通话"步骤。* 电子邮件和时间由您处理，志愿者只有在需要人工接触时才看到卡片。
:::

## 触发器

触发器在发生某些事情时自动将人员添加到工作流中，因此您永远不必手动添加卡片。在工作流看板上，单击**触发器**标签，然后**添加触发器**。有两种类型：

### 事件触发器

在 B1 中的记录更改时立即触发。选择事件，然后可选择添加**条件**以便仅添加匹配的人员：

- **人员 · 创建 / 更新** —— 例如，添加任何状态变为*访客*的人员。
- **献金 · 创建** —— 例如，将首次或大笔献金添加到感谢工作流（按金额、基金或方法匹配）。
- **小组 · 成员加入** / **小组 · 创建**。
- **表单 · 已提交** —— 添加任何提交选定表单的人员（适合"我是新的"或"连接"卡片）。

### 计划触发器

基于重复计划——每天、每周、每月或每年——针对一组条件运行。将这些用于基于时间的推广，例如*所有成员周年纪念日是今天的人*或*每月*检查。

对于任何触发器，您也可以设置：

- 新卡片启动的**入场步骤**（默认为第一步）。
- **每个人一次** —— 所以同一个人不会被触发器添加到工作流两次。
- **活跃** —— 打开或关闭触发器，而不删除它。

:::tip
将**表单 · 已提交**触发器与**新访客跟进**模板配对，将您的"连接卡片"或"我是新的"表单变成自动跟进管道。
:::

## 我的卡片

志愿者和员工不需要挖掘每个看板来寻找他们的工作。**我的卡片**页面（从工作流页面链接）列出分配给当前用户的每张卡片，跨所有工作流。单击卡片打开它所属的看板。

## 报告

打开工作流并单击**报告**以查看该工作流的分析：

- **逾期** —— 逾期的卡片数。
- **每步卡片** —— 当前在每个步骤上坐着多少张卡片，显示为列图。
- **已完成（30 天）** —— 过去 30 天的吞吐量，显示为折线图。

使用这些来发现瓶颈——例如，一个步骤堆积了卡片并且永不推进。
