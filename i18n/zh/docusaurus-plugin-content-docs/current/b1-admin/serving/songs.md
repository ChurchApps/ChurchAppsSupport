# 歌曲

<div class="article-intro">

歌曲页面用于管理你的敬拜歌曲曲库。将所有歌曲详细信息、歌词和编曲保存在一处，使敬拜团队能够轻松为即将到来的礼拜做好准备，并保持曲目的一致性。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在 B1 Admin 的[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)中，选择 **Serving > Songs** 即可访问歌曲页面
- 可选：先设置好你的[服事计划](./plans.md)，以便将歌曲直接链接到[礼拜程序](./service-order.md)中

</div>

## 浏览你的歌曲曲库

打开 **Songs** 页面时，你的歌曲会以表格形式列出。每一行显示歌曲的缩略图、标题、演唱者和时长。使用列表下方的页面控件可以翻阅大型曲库，或通过搜索查找所需的歌曲。

## 搜索歌曲

1. 点击歌曲页面顶部的 **Search Songs**（搜索歌曲）搜索框。
2. 输入歌曲的**标题**或**演唱者**姓名。
3. 列表会随着你的输入进行筛选，显示曲库中匹配的歌曲以及匹配的数量。点击 **Clear**（清除）即可再次显示所有歌曲。

## 添加歌曲

1. 点击歌曲页面顶部的 **Add Song**（添加歌曲）。
2. 在 **Search for a Song**（搜索歌曲）中，按**标题或演唱者**搜索外部歌曲数据库。
3. 选择你要添加的歌曲；如果找不到，请点击 **Create Manually**（手动创建）。
4. 歌曲将被添加到你的曲库中，其基本信息已预先填写。

:::tip
添加歌曲后，点击它即可查看并更新详细信息、添加编曲，或附加外部链接，例如 YouTube 视频或和弦谱。
:::

### 来自 WorshipCommons 的免费歌曲 {#free-songs-from-worshipcommons}

你的搜索结果中，除了常规结果外，还可能包含一个 **WorshipCommons — free**（WorshipCommons — 免费）部分。这些是来自 [WorshipCommons](https://worshipcommons.org) 的、适合主日使用的歌曲，并已通过审核、获得用于敬拜的授权。每个结果都会显示一个许可标识——**Free for worship**（免费用于敬拜）或 **Public domain**（公有领域）——以便你在添加之前了解其使用条款。

- 点击 WorshipCommons 的结果，即可将其添加到你的曲库中，操作与常规搜索结果相同。
- 点击 **View on WorshipCommons**（在 WorshipCommons 上查看），即可在新标签页中打开原始列表。

只有通过 WorshipCommons 审核流程的歌曲才会出现在此处，因此可选范围可能比主歌曲数据库小。

## 删除歌曲

勾选一首或多首歌曲旁边的复选框（或勾选标题栏中的复选框以选中所有显示的歌曲），然后点击出现的操作栏中的 **Delete Selected**（删除所选）并确认。点击 **Clear** 可取消选择。

## 查看和编辑歌曲

点击歌曲的标题即可打开其详情页面。歌曲的标题、演唱者，以及专辑、调性、时长、BPM 和拍号等详细信息会显示在左侧，同时还会列出其编曲和外部链接。在此页面，你可以：

- **编辑歌曲详情** —— 点击 **Edit** 更新标题、演唱者、时长和其他元数据。完成后点击 **Done**。若要将歌曲从曲库中移除，请点击 **Edit**，然后点击 **Delete song**（删除歌曲）。
- **管理编曲** —— 每首歌曲可以有多个编曲（例如不同的调性或版本）。点击 **Add Arrangement**（添加编曲）即可创建一个，点击 **Arrangements**（编曲）下方的编曲名称即可将其打开。
- **添加歌词** —— 使用 ChordPro 记谱法（例如 `[G]Amazing grace`）为每个编曲输入或更新歌词。编辑器旁边的实时预览会在你输入时渲染格式化的和弦谱，让你准确看到团队将看到的内容。
- **设置调性** —— 使用歌词旁边的调性选择器为每个编曲指定音乐调性。选择器列出的调性按音乐人通常的书写方式排列（C、Db、D、Eb、E、F、F#、G、Ab、A、Bb、B）。更改调性会立即转调所显示的和弦，无论是在编曲页面上，还是从服事计划中打开歌曲时都会如此，因此团队始终看到的是他们实际演奏的调性所对应的和弦。和弦的拼写会与调性相匹配：降号调如 Bb 或 Eb 会显示降号和弦名（Bb、Eb、Ab），而不是升号。
- **添加外部链接** —— 附加指向其他地方托管的资源的链接，例如 YouTube 视频、和弦谱或乐谱。

## 编曲

编曲代表歌曲的一个不同版本——例如，较快的现代版与较慢的原声版，或同一首歌为不同团队所用的不同调性。同一首歌的每个编曲都共享歌曲标题和演唱者，但拥有各自独立的设置：

- **Key（调性）** —— 编曲演奏所用的音乐调性
- **BPM** —— 每分钟节拍数，即速度
- **Length（长度）** —— 以秒计的时长
- **Meter（拍号）** —— 拍号（例如 4/4、3/4、6/8）
- **Sequence（顺序）** —— 和弦/段落结构（例如 前奏 → 主歌 → 副歌 → 桥段）
- **Lyrics（歌词）** —— 用于显示或投影
- **External links（外部链接）** —— 和弦谱、YouTube 录音、乐谱或其他资源

将歌曲添加到[礼拜程序](./service-order.md)时，你可以为该特定礼拜选择使用哪个编曲，这样团队总能排练和演奏正确的版本。

### 排练音频

敬拜负责人可以为编曲附加排练音频，以便团队在练习前提前聆听：

1. 打开歌曲并选择编曲。
2. 点击 **Upload Audio**（上传音频）。
3. 选择 MP3、M4A 或 AAC 文件（最大 25 MB——为控制存储用量，不接受 WAV 格式）。
4. 保存。该音轨会在该编曲出现的任何地方内嵌播放——包括 B1 Admin 中的编曲页面，以及团队成员在 B1.church 成员门户中打开的服事计划。带有音频的计划环节会显示音符图标，而不是缩略图。

删除编曲也会同时删除其上传的音频文件。

:::info
你曲库中的歌曲可以直接添加到计划中的[礼拜程序](./service-order.md)，将歌曲详情和所选编曲链接到该特定礼拜。
:::
