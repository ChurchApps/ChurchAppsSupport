# 歌曲

<div class="article-intro">

歌曲页面用于管理您的敬拜歌曲曲库。将所有歌曲详情、歌词和编配集中保存在一处,让您的敬拜团队能够轻松为即将到来的服事做准备,并维持一致的曲目库。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在 B1 Admin 中导航到**事工服事**部分以访问歌曲页面
- (可选)先设置好您的[服事计划](./plans.md),以便将歌曲直接链接到[崇拜流程](./service-order.md)中

</div>

## 浏览您的歌曲曲库

打开**歌曲**页面时,您的歌曲会以卡片形式展示。每张卡片显示歌曲的缩略图、标题、艺人和时长。您可以滚动浏览曲库,或使用搜索功能查找所需内容。

## 搜索歌曲

1. 点击歌曲页面上的**搜索**按钮。
2. 输入歌曲**标题**或**艺人**名称。
3. 随着您的输入,结果会实时筛选,显示曲库中匹配的歌曲。

## 添加歌曲

1. 在歌曲页面点击**添加歌曲**。
2. 按标题或艺人名称搜索外部歌曲数据库。
3. 选择您想添加的歌曲。
4. 该歌曲会被添加到您的曲库中,基本详情已预先填好。

:::tip
添加歌曲后,点击它可以查看并更新其详情、添加编配,或附加外部链接,例如 YouTube 视频或和弦谱。
:::

## 查看和编辑歌曲

点击任意歌曲卡片打开其详情页面。在这里您可以:

- **编辑歌曲详情**——更新标题、艺人、时长和其他元数据。
- **管理编配**——每首歌曲可以有多个编配版本(例如,不同的调性或版本)。根据需要添加、编辑或删除编配。
- **添加歌词**——为每个编配输入或更新歌词。
- **设置调性**——使用歌词旁边的调性选择器为每个编配指定音乐调性。更改调性会立即转调显示的和弦——无论是在编配页面上,还是在从服事计划中打开歌曲时都是如此,让您的团队始终看到实际演奏调性下的和弦。
- **添加外部链接**——附加指向外部资源的链接,如 YouTube 视频、和弦谱,或托管在其他地方的乐谱。

## 编配

编配代表一首歌的不同演绎版本——例如,更快的现代版本相对于较慢的原声版本,或同一首歌用不同调性给不同团队使用。同一首歌的每个编配共享歌曲标题和艺人信息,但拥有各自独立的设置:

- **调性**——该编配所使用的音乐调性
- **BPM**——每分钟节拍数的速度
- **时长**——以秒为单位的持续时间
- **拍号**——节拍单位(例如 4/4、3/4、6/8)
- **段落结构**——和弦/段落顺序(例如前奏 → 主歌 → 副歌 → 桥段)
- **歌词**——用于显示或投影
- **外部链接**——和弦谱、YouTube 录音、乐谱或其他资源

当您将一首歌添加到[崇拜流程](./service-order.md)时,可以为该场特定服事选择要使用哪个编配,确保您的团队始终排练并演奏正确的版本。

:::info
您曲库中的歌曲可以直接添加到计划内的[崇拜流程](./service-order.md)中,将歌曲详情及所选编配链接到该场特定服事。
:::

## 后续步骤
