# 歌曲

<div class="article-intro">

歌曲页面管理您的敬拜歌曲库。将所有歌曲详情、歌词和编排保存在一个地方，这样您的敬拜团队可以轻松为即将到来的服务做准备，并保持一致的曲库。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 导航到 B1 Admin 中的**服务**部分以访问歌曲页面
- 可选择，设置您的[服务计划](./plans.md)以便您可以直接将歌曲链接到[服务顺序](./service-order.md)

</div>

## 浏览歌曲库

当您打开**歌曲**页面时，您的歌曲显示为卡片。每张卡片显示歌曲的缩略图、标题、艺术家和时长。滚动浏览库或使用搜索找到您需要的内容。

## 搜索歌曲

1. 单击歌曲页面上的**搜索**按钮。
2. 输入歌曲**标题**或**艺术家**名称。
3. 结果会随着您的输入而筛选，显示库中的匹配歌曲。

## 添加歌曲

1. 单击歌曲页面上的**添加歌曲**。
2. 按标题或艺术家在外部歌曲数据库中搜索。
3. 选择您想要添加的歌曲。
4. 歌曲将添加到您的库中，其基本详情已预填。

:::tip
添加歌曲后，单击它以查看和更新其详情、添加编排或附加外部链接，如 YouTube 视频或和弦谱。
:::

## 查看和编辑歌曲

单击任何歌曲卡片以打开其详情页面。从这里您可以：

- **编辑歌曲详情**——更新标题、艺术家、时长和其他元数据。
- **管理编排**——每首歌曲可以有多个编排（例如，不同的调式或版本）。根据需要添加、编辑或移除编排。
- **添加歌词**——输入或更新每个编排的歌词。
- **设置调式**——使用歌词旁边的调式选择器为每个编排指定音乐调式。改变调式会立即转移显示的和弦，无论是在编排页面上还是从服务计划打开歌曲时，所以您的团队总是看到他们实际演奏的调式中的和弦。
- **添加外部链接**——附加到资源的链接，如在其他地方托管的 YouTube 视频、和弦谱或乐谱。

## 编排

编排代表歌曲的一个不同版本——例如，更快的现代版本与更慢的原声版本，或同一首歌用不同的调式为不同的团队。同一首歌的每个编排共享歌曲标题和艺术家，但有其自己的独立设置：

- **调式**——演奏编排的音乐调式
- **BPM**——每分钟拍数的节奏
- **长度**——秒数的时长
- **拍号**——时间签名（例如，4/4、3/4、6/8）
- **序列**——和弦/部分结构（例如，引入 → 诗节 → 副歌 → 桥接）
- **歌词**——用于显示或投影
- **外部链接**——和弦谱、YouTube 录音、乐谱或其他资源

当您将歌曲添加到[服务顺序](./service-order.md)时，您可以为该特定服务选择使用哪个编排，所以您的团队总是排练和演奏正确的版本。

### 排练音频

敬拜管理员可以为编排附加排练音频轨道，以便团队可以在实践前听取：

1. 打开歌曲并选择编排。
2. 单击**上传音频**。
3. 选择 MP3、M4A 或 AAC 文件（最大 25 MB——不接受 WAV，以保持存储使用量易于管理）。
4. 保存。轨道在该编排出现的任何地方内联播放——在 B1 Admin 的编排页面上和当团队成员在 B1.church 成员门户中打开它时在服务计划中。带有音频的计划项目显示音乐音符图标而不是缩略图。

删除编排也会移除其上传的音频文件。

:::info
来自您库的歌曲可以直接添加到计划内的[服务顺序](./service-order.md)，将歌曲详情和所选编排链接到该特定服务。
:::
