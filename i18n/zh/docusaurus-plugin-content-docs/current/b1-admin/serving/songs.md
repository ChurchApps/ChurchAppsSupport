# 歌曲

<div class="article-intro">

歌曲页面管理您的敬拜歌曲库。将所有歌曲详细信息、歌词和编排保留在一个地方，以便您的敬拜团队可以轻松为即将进行的服务做准备并保持一致的曲目。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在B1 Admin的[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)中，选择**服侍 > 歌曲**来访问歌曲页面
- 可选择，让您的[服务计划](./plans.md)设置好，以便您可以直接将歌曲链接到[服务顺序](./service-order.md)

</div>

## 浏览您的歌曲库

打开**歌曲**页面时，您的歌曲显示为卡片。每张卡片显示歌曲的缩略图、标题、艺术家和时长。滚动浏览库或使用搜索来查找您需要的内容。

## 搜索歌曲

1. 点击歌曲页面上的**搜索**按钮。
2. 输入歌曲**标题**或**艺术家**名称。
3. 结果将在您输入时过滤，显示库中的匹配歌曲。

## 添加歌曲

1. 点击歌曲页面上的**添加歌曲**。
2. 按标题或艺术家搜索外部歌曲数据库。
3. 选择要添加的歌曲。
4. 歌曲将被添加到您的库中，基本详细信息已预先填充。

:::tip
添加歌曲后，点击它来审查和更新其详细信息、添加编排或附加外部链接，如YouTube视频或和弦表。
:::

### 来自WorshipCommons的免费歌曲

您的搜索结果可能还包括**WorshipCommons -- 免费**部分，与常规结果一起。这些是来自[WorshipCommons](https://worshipcommons.org)的周日现成歌曲，已被审查并获得敬拜使用的许可。每个结果显示许可证徽章 -- **免费敬拜**或**公共领域** -- 所以您在添加前知道条款。

- 点击WorshipCommons结果来将其添加到您的库，就像常规搜索结果一样。
- 点击**在WorshipCommons上查看**在新选项卡中打开原始列表。

只有通过WorshipCommons审查流程的歌曲才会出现在这里，因此选择可能小于主歌曲数据库。

## 查看和编辑歌曲

点击任何歌曲卡来打开其详情页面。从这里您可以：

- **编辑歌曲详细信息** -- 更新标题、艺术家、时长和其他元数据。
- **管理编排** -- 每首歌曲可以有多个编排（例如，不同的调或版本）。根据需要添加、编辑或删除编排。
- **添加歌词** -- 使用ChordPro符号输入或更新每个编排的歌词（例如，`[G]Amazing grace`）。编辑器旁边的实时预览在您输入时呈现格式化的和弦表，因此您可以看到您的团队将看到的确切内容。
- **设置调** -- 使用歌词旁边的调选择器为每个编排指定音乐调。更改调会立即转置显示的和弦，既在编排页面上又在从服务计划打开歌曲时，因此您的团队始终看到他们实际演奏的调的和弦。
- **添加外部链接** -- 附加到资源的链接，如YouTube视频、和弦表或其他地方托管的乐谱。

## 编排

编排代表歌曲的不同版本 -- 例如，更快的现代版本对比较慢的原声版本，或相同歌曲以不同调为不同团队。同一首歌的每个编排共享歌曲标题和艺术家，但有自己的独立设置：

- **调** -- 编排表演的音乐调
- **BPM** -- 每分钟节拍的速度
- **长度** -- 持续时间（秒）
- **拍号** -- 时间签名（例如，4/4、3/4、6/8）
- **顺序** -- 和弦/部分结构（例如，前奏 → 诗句 → 合唱 → 桥接）
- **歌词** -- 用于显示或投影
- **外部链接** -- 和弦表、YouTube录音、乐谱或其他资源

将歌曲添加到[服务顺序](./service-order.md)时，您可以选择为该特定服务使用哪个编排，以便您的团队始终排练和演奏正确的版本。

### 排练音频

敬拜管理员可以将排练音频轨道附加到编排，以便团队可以在练习前提前听：

1. 打开歌曲并选择编排。
2. 点击**上传音频**。
3. 选择MP3、M4A或AAC文件（最多25 MB -- 不接受WAV，以保持存储使用可管理）。
4. 保存。曲目在该编排出现的任何地方内联播放 -- 在B1 Admin中的编排页面上，以及当团队成员在B1.church成员门户中打开它时在服务计划中。带有音频的计划项目显示音乐音符图标而不是缩略图。

删除编排也会删除其上传的音频文件。

:::info
您的库中的歌曲可以直接添加到计划中的[服务顺序](./service-order.md)，将歌曲详细信息和所选编排链接到该特定服务。
:::
