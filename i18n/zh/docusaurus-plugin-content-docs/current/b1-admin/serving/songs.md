# 诗歌

<div class="article-intro">

诗歌页面用于管理你的敬拜诗歌库。将所有诗歌详情、歌词和编曲集中保存在一处，让敬拜团队能够轻松为即将到来的礼拜做准备，并保持曲目的一致性。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在 B1 Admin 的[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)中，选择 **Serving > Songs**（服事 > 诗歌）即可进入诗歌页面
- 可选：设置好[服事计划](./plans.md)，以便将诗歌直接链接到[崇拜程序](./service-order.md)中

</div>

## 浏览你的诗歌库 {#browsing-your-song-library}

打开 **Songs**（诗歌）页面时，你的诗歌会以表格形式列出。每一行显示诗歌的缩略图、标题、演唱者和时长。若诗歌库较大，可使用列表下方的页面控件翻页浏览，或通过搜索找到所需内容。

## 搜索诗歌 {#searching-for-songs}

1. 点击诗歌页面顶部的 **Search Songs**（搜索诗歌）输入框。
2. 输入诗歌的**标题**或**演唱者**名称。
3. 列表会在你输入时实时筛选，显示诗歌库中匹配的诗歌及匹配数量。点击 **Clear**（清除）即可重新显示所有诗歌。

## 添加诗歌 {#adding-a-song}

1. 点击诗歌页面顶部的 **Add Song**（添加诗歌）。
2. 在 **Search for a Song**（搜索诗歌）中，按**标题或演唱者**搜索外部诗歌数据库。
3. 选择你想添加的诗歌；如果找不到，请点击 **Create Manually**（手动创建）。
4. 该诗歌会被添加到你的诗歌库中，其基本详情已预先填好。

:::tip
添加诗歌后，点击该诗歌即可查看并更新其详情、添加编曲，或附加 YouTube 视频、和弦谱等外部链接。
:::

### 来自 WorshipCommons 的免费诗歌 {#free-songs-from-worshipcommons}

搜索结果中，除常规结果外，还可能出现 **WorshipCommons — free**（WorshipCommons — 免费）部分。这些是来自 [WorshipCommons](https://worshipcommons.org) 的、可直接用于主日礼拜的诗歌，已经过审核并获准用于敬拜。每个结果都会显示一个授权标识 -- **Free for worship**（免费用于敬拜）或 **Public domain**（公有领域），让你在添加之前就了解使用条款。

- 点击某个 WorshipCommons 结果即可将其添加到你的诗歌库，操作与常规搜索结果相同。
- 点击 **View on WorshipCommons**（在 WorshipCommons 上查看）可在新标签页中打开原始页面。

只有通过 WorshipCommons 审核流程的诗歌才会显示在此处，因此其数量可能少于主诗歌数据库。

如需浏览完整的 WorshipCommons 库、打印和弦谱或导出幻灯片，请参阅 [WorshipCommons 文档](../../worship-commons/index.md)。

## 删除诗歌 {#deleting-songs}

勾选一首或多首诗歌旁边的复选框（或勾选表头中的复选框以选中当前显示的所有诗歌），然后点击出现的操作栏中的 **Delete Selected**（删除所选项），并确认。点击 **Clear** 可取消选择。

## 查看和编辑诗歌 {#viewing-and-editing-a-song}

点击诗歌标题即可打开其详情页。诗歌的标题、演唱者，以及专辑、调式、时长、BPM 和拍号等详细信息显示在左侧，并附有其编曲和外部链接。所选编曲的歌词和调式则占据页面其余部分。在此你可以：

- **编辑诗歌详情** -- 点击 **Edit**（编辑）以更新标题、演唱者、时长及其他元数据。完成后点击 **Done**（完成）。若要将该诗歌从诗歌库中移除，请点击 **Edit**，然后点击 **Delete song**（删除诗歌）。
- **管理编曲** -- 每首诗歌可以有多个编曲（例如不同的调式或版本）。点击 **Add Arrangement**（添加编曲）即可创建一个，点击 **Arrangements**（编曲）下的编曲名称即可打开它。
- **添加歌词** -- 点击编曲名称旁边的 **Edit**，即可更改其名称、BPM、拍号、时长、段落顺序和歌词。歌词请使用 ChordPro 记法输入（例如 `[G]Amazing grace`）。编辑器旁边的实时预览会在你输入时渲染出格式化的和弦谱，让你准确看到团队将看到的内容。
- **设置调式** -- 使用歌词上方的 **Key**（调式）选择器为每个编曲指定音乐调式。选择器按音乐家通常的写法列出调式（C、Db、D、Eb、E、F、F#、G、Ab、A、Bb、B）。更改调式会立即转调所显示的和弦，无论是在编曲页面上，还是从服事计划中打开该诗歌时，因此团队始终能看到他们实际演奏调式下的和弦。和弦的拼写会与调式相符：降号调如 Bb 或 Eb 会显示降号和弦名（Bb、Eb、Ab），而不是升号写法。
- **添加外部链接** -- 点击左侧 **External Links**（外部链接）旁边的 **Edit**，即可链接 YouTube、Spotify、Apple、CCLI 或 Hymnary 等平台上的诗歌。链接到其他地方托管的和弦谱或乐谱时，请将其添加到某个调式下（参见 **Manage keys**（管理调式））。
- **管理调式** -- 在 **Keys**（调式）下，点击 **Add key**（添加调式），添加编曲所使用的一个调式（包括 **Key Signature**（调号）和可选的标签，例如 "John's Key"（John 的调式））。选择一个调式后，点击 **Add Files**（添加文件），即可选择 **Import from PraiseCharts**（从 PraiseCharts 导入）、为该调式添加 **Add External Link**（外部链接，例如该调式的和弦谱），或选择 **Upload Audio**（上传音频）。

## 编曲 {#arrangements}

编曲代表诗歌的一个独立版本，例如一个节奏较快的现代版与一个较慢的原声版，或为不同团队准备的不同调式版本。同一首诗歌的每个编曲都共享标题和演唱者，但拥有各自独立的设置：

- **Key**（调式）-- 编曲演奏所用的音乐调式
- **BPM** -- 每分钟节拍数，即速度
- **Length**（时长）-- 以秒为单位的时长
- **Meter**（拍号）-- 拍号（例如 4/4、3/4、6/8）
- **Sequence**（段落顺序）-- 和弦/段落结构（例如 前奏 → 主歌 → 副歌 → 桥段）
- **Lyrics**（歌词）-- 用于显示或投影
- **External links**（外部链接）-- 和弦谱、YouTube 录音、乐谱或其他资源

将诗歌添加到[崇拜程序](./service-order.md)时，你可以为该场礼拜选择使用哪个编曲，确保团队始终排练和演奏正确的版本。

### 排练音频 {#rehearsal-audio}

敬拜负责人可以为编曲附加排练音频轨道，让团队在排练前提前聆听：

1. 打开该诗歌并选择相应的编曲。
2. 在 **Keys**（调式）下选择一个调式（如果该编曲尚无调式，请先点击 **Add key**），点击 **Add Files**（添加文件），然后选择 **Upload Audio**（上传音频）。
3. 选择 MP3、M4A 或 AAC 文件（最大 25 MB -- 不接受 WAV 格式，以控制存储空间的使用）。
4. 点击 **Save**（保存）。只要该编曲出现的地方，音轨都会内嵌播放 -- 包括 B1 Admin 中的编曲页面，以及团队成员在 B1.church 会员门户中打开服事计划时。带有音频的计划项目会显示音符图标，而不是缩略图。

删除编曲时，其上传的音频文件也会一并删除。

:::info
诗歌库中的诗歌可以直接添加到计划中的[崇拜程序](./service-order.md)，从而将诗歌详情和所选编曲关联到该场特定礼拜。
:::
