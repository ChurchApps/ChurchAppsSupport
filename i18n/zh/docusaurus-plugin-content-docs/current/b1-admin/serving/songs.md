# 歌曲

<div class="article-intro">

"歌曲"页面用于管理您的敬拜歌曲库。将所有歌曲的详细信息、歌词和编曲集中保存在一处，让敬拜团队能够轻松为即将到来的礼拜做准备，并保持曲目的一致性。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在 B1 Admin 中，通过[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)选择**服务 > 歌曲**，即可进入"歌曲"页面
- 可选：提前设置好[礼拜计划](./plans.md)，以便将歌曲直接添加到[礼拜流程](./service-order.md)中

</div>

## 浏览歌曲库

打开**歌曲**页面时，您的歌曲会以表格形式列出。每一行显示歌曲的缩略图、标题、演唱者和时长。如果曲库较大，可以使用列表下方的分页控件翻页，也可以通过搜索快速找到所需歌曲。

## 搜索歌曲

1. 点击"歌曲"页面顶部的**搜索歌曲**框。
2. 输入歌曲**标题**或**演唱者**名称。
3. 列表会在您输入时实时筛选，显示曲库中匹配的歌曲及匹配数量。点击**清除**即可再次显示所有歌曲。

## 添加歌曲

1. 点击"歌曲"页面顶部的**添加歌曲**。
2. 在**搜索歌曲**中，按**标题或演唱者**搜索外部歌曲数据库。
3. 选择要添加的歌曲；如果找不到，可点击**手动创建**。
4. 歌曲会以预先填好的基本信息添加到您的曲库中。

:::tip
添加歌曲后，点击该歌曲即可查看并更新其详细信息、添加编曲，或附加 YouTube 视频、和弦谱等外部链接。
:::

### 来自 WorshipCommons 的免费歌曲

您的搜索结果中，除常规结果外，还可能出现**WorshipCommons — 免费**分区。这些是来自 [WorshipCommons](https://worshipcommons.org) 的歌曲，已经过审核并获得用于敬拜的授权，可直接用于主日礼拜。每个结果都会显示授权标签——**免费用于敬拜**或**公有领域**——方便您在添加前了解使用条款。

- 点击 WorshipCommons 的结果即可将其添加到您的曲库，操作与常规搜索结果相同。
- 点击**在 WorshipCommons 上查看**，可在新标签页中打开原始页面。

只有通过 WorshipCommons 审核流程的歌曲才会出现在这里，因此数量可能少于主要歌曲数据库。

如需浏览完整的 WorshipCommons 曲库、打印乐谱或导出幻灯片，请参阅 [WorshipCommons 文档](../../worship-commons/index.md)。

## 删除歌曲

勾选一首或多首歌曲前的复选框（或勾选表头中的复选框以选中当前显示的所有歌曲），然后点击出现在下方栏中的**删除所选**并确认。点击**清除**即可取消选择。

## 查看和编辑歌曲

点击歌曲标题即可打开其详情页。歌曲的标题、演唱者，以及专辑、调性、长度、BPM 和节拍等详细信息会显示在左侧，同时还会列出其编曲和外部链接。在此页面，您可以：

- **编辑歌曲详情**——点击**编辑**，可更新标题、演唱者、时长及其他元数据。完成后点击**完成**。如需将歌曲从曲库中移除，请点击**编辑**，然后点击**删除歌曲**。
- **管理编曲**——每首歌曲可以有多个编曲（例如不同的调性或版本）。点击**添加编曲**即可创建新编曲，点击**编曲**下方的编曲名称即可打开该编曲。
- **添加歌词**——使用 ChordPro 标记法为每个编曲输入或更新歌词（例如 `[G]Amazing grace`）。编辑器旁边的实时预览会在您输入时渲染格式化的和弦谱，让您准确看到敬拜团队将看到的内容。
- **设置调性**——使用歌词旁的调性选择器为每个编曲指定音乐调性。选择器按照音乐人通常的书写方式列出调性（C、Db、D、Eb、E、F、F#、G、Ab、A、Bb、B）。更改调性后，编曲页面以及从礼拜计划中打开歌曲时，显示的和弦都会立即转调，因此敬拜团队看到的和弦始终与实际演奏的调性一致。和弦的拼写也会与调性匹配：Bb、Eb 等降号调会显示降号和弦名（Bb、Eb、Ab），而不是升号。
- **添加外部链接**——附加指向其他地方托管的资源链接，例如 YouTube 视频、和弦谱或乐谱。

## 编曲

编曲代表歌曲的一个独立版本，例如节奏较快的现代版与节奏较慢的原声版本，或同一首歌为不同团队准备的不同调性版本。同一首歌的每个编曲都共享歌曲标题和演唱者，但拥有各自独立的设置：

- **调性**——编曲演奏所用的音乐调性
- **BPM**——每分钟节拍数（速度）
- **长度**——以秒为单位的时长
- **节拍**——拍号（例如 4/4、3/4、6/8）
- **段落顺序**——和弦与段落结构（例如 前奏 → 主歌 → 副歌 → 桥段）
- **歌词**——用于显示或投影
- **外部链接**——和弦谱、YouTube 录音、乐谱或其他资源

将歌曲添加到[礼拜流程](./service-order.md)时，您可以为该次礼拜选择使用哪个编曲，确保团队始终排练和演奏正确的版本。

### 排练音频

敬拜管理员可以为编曲附加排练音频，方便团队在排练前提前聆听：

1. 打开歌曲并选择相应的编曲。
2. 点击**上传音频**。
3. 选择 MP3、M4A 或 AAC 文件（最大 25 MB——为控制存储用量，不接受 WAV 格式）。
4. 保存。只要该编曲出现，音轨就会以内嵌方式播放——包括 B1 Admin 中的编曲页面，以及团队成员在 B1.church 成员门户中打开的礼拜计划。带有音频的计划项目会显示音符图标，而不是缩略图。

删除编曲时，其上传的音频文件也会一并删除。

:::info
您曲库中的歌曲可以直接添加到计划中的[礼拜流程](./service-order.md)，从而将歌曲详情和所选编曲关联到该次特定礼拜。
:::
