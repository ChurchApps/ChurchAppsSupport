# 计划模板

<div class="article-intro">

计划模板让您保存计划的服务顺序或职位的可重复使用快照，并一键应用到未来的计划中。您无需每周重新搭建相同的结构，只需保存一次，然后将其套用到所需的任意数量的即将到来的计划中。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 创建至少一个已定义服务顺序或职位的[服务计划](plans.md)
- 您需要访问 B1 Admin 中的服侍区域

</div>

## 将计划保存为模板

1. 从**服侍**区域打开一个现有计划。
2. 在计划的**服务顺序**部分中，点击**Save as Template**。
3. 为模板命名（例如"标准主日"或"敬拜 + 讲道"）。
4. 保存。模板会捕获计划在当时的服务顺序、职位和备注。

## 管理模板

在任何计划类型页面上，点击计划列表上方的**Templates**以打开**Plan Templates**。在那里您可以：

- **Rename** — 更改模板的显示名称
- **Update from plan** — 用计划的当前状态替换模板内容（在您完善标准结构后很有用）
- **Apply** — 将模板套用到一个或多个即将到来的计划
- **Delete** — 删除您不再需要的模板

## 将模板应用到计划

1. 在计划类型页面上，点击计划列表上方的**Templates**。
2. 点击您要使用的模板旁边的**Apply**图标（复制图标）。
3. 通过勾选复选框选择要应用到的即将到来的计划。
4. 选择要复制的内容：
   - **Order of Service** — 用模板的项目替换所选计划的服务顺序项目
   - **Positions** — 用模板的职位替换所选计划的职位（及其分配）
5. 点击**Apply**。

如果模板包含备注，应用模板时也会用模板的备注替换所选计划的备注。

:::warning
应用职位会替换所选计划上所有现有的职位和分配。在应用之前，请确保您尚未为这些职位安排志愿者。
:::

:::tip
当您希望保持一致的歌曲/讲道结构，但志愿者每周的分配都不同时，请应用服务顺序而不应用职位。
:::

## 从模板开始新计划

模板在事工内的计划类型之间共享。点击**New Plan**且该事工有模板时，新计划表单会包含一个**Start from template**列表。选择一个模板并保存，新计划将使用该模板的服务顺序、职位和备注创建。为该计划选择模板会替换**Copy from Previous Plan**选项。

## 保持模板最新

如果您的标准服务结构发生变化，请打开模板管理器，使用**Update from plan**从您最新的计划同步模板，而无需从头重新搭建。
