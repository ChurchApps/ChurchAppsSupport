# 计划模板

<div class="article-intro">

计划模板让你将计划的崇拜程序或岗位保存为可重复使用的快照，并一键应用到未来的计划中。无需每周重新搭建相同的结构，你只需保存一次，便可将其应用到任意数量的即将到来的计划中。

</div>

## 将计划保存为模板 {#saving-a-plan-as-a-template}

1. 从**服事**区中打开一份现有计划。
2. 点击 **Edit order of service**（编辑崇拜程序）以打开该计划的崇拜程序，然后点击其上方的 **Save as Template**（保存为模板）。
3. 为模板命名（例如 "Standard Sunday"（标准主日）或 "Worship + Sermon"（敬拜 + 讲道））。默认名称为该计划的名称。
4. 点击 **Save**（保存）。模板会记录保存时该计划当前的崇拜程序、岗位和备注。

## 管理模板 {#managing-templates}

在任意计划类型页面上，点击计划列表上方的 **Templates**（模板），即可打开 **Plan Templates**（计划模板）。每个模板都有以下图标：

- **Edit**（编辑，铅笔图标）-- 重命名模板
- **Update from plan**（从计划更新，循环箭头图标）-- 用某份计划的当前状态替换模板内容（在你完善标准结构后很有用）
- **Apply**（应用，复制图标）-- 将模板应用到一份或多份即将到来的计划中
- **Delete**（删除，垃圾桶图标）-- 删除你不再需要的模板

## 将模板应用到计划 {#applying-a-template-to-plans}

1. 在计划类型页面上，点击计划列表上方的 **Templates**。
2. 点击你要使用的模板旁边的 **Apply**（应用）图标（复制图标）。
3. 勾选复选框，选择要应用到的即将到来的计划。今天之前的计划不会列出。
4. 选择要复制的内容：
   - **Order of Service**（崇拜程序）-- 用模板中的项目替换所选计划的崇拜程序项目
   - **Positions**（岗位）-- 用模板中的岗位替换所选计划的岗位（及其分派）
5. 点击 **Apply**。**Order of Service** 默认已勾选；两项中至少须勾选一项。

如果模板包含备注，应用模板时也会用模板的备注替换所选计划的备注。

:::warning
应用岗位会替换所选计划上所有现有的岗位和分派。在应用之前，请确保你尚未为这些岗位安排志愿者。
:::

:::tip
如果你希望保持统一的诗歌/讲道结构，但志愿者每周的分派各不相同，请只应用崇拜程序而不应用岗位。
:::

## 从模板开始新计划 {#starting-a-new-plan-from-a-template}

模板在事工内的各计划类型之间共享。当你点击 **New Plan**（新建计划），且该事工存在模板时，新计划表单会包含 **Start from template**（从模板开始）列表。选择一个模板并保存，新计划就会带着该模板的崇拜程序、岗位和备注一起创建。选择模板会替代该计划的 **Copy from Previous Plan**（从上一份计划复制）选项。

## 保持模板为最新 {#keeping-templates-up-to-date}

如果你的标准礼拜结构有所变化，请打开模板管理器，点击 **Update from plan**（从计划更新），选择要复制的计划，然后点击 **Save**，即可用你最新的计划同步模板，而无需从头重建。列表会提供该计划类型的所有计划，包括过去和即将到来的计划。
