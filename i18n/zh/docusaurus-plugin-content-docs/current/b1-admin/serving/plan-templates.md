# 计划模板

<div class="article-intro">

计划模板允许你将计划的礼拜程序或岗位保存为可重复使用的快照，并一键应用到之后的计划中。你无需每周重新搭建相同的结构，只需保存一次，即可将其应用到任意数量的未来计划上。

</div>

## 将计划保存为模板

1. 从**服事**区域打开一个现有计划。
2. 在计划的 **Order of Service**（礼拜程序）部分，点击 **Save as Template**（保存为模板）。
3. 为模板命名（例如"标准主日"或"敬拜 + 讲道"）。
4. 保存。模板会记录保存那一刻计划的礼拜程序、岗位和备注。

## 管理模板

在任意计划类型页面的计划列表上方点击 **Templates**（模板），即可打开 **Plan Templates**（计划模板）。在这里你可以：

- **Rename**（重命名）—— 更改模板的显示名称
- **Update from plan**（从计划更新）—— 用某个计划的当前状态替换模板内容（在你完善了标准结构之后很有用）
- **Apply**（应用）—— 将模板应用到一个或多个未来计划上
- **Delete**（删除）—— 删除你不再需要的模板

## 将模板应用到计划

1. 在计划类型页面的计划列表上方点击 **Templates**。
2. 点击你要使用的模板旁边的 **Apply** 图标（复制图标）。
3. 勾选复选框，选择要应用的未来计划。
4. 选择要复制的内容：
   - **Order of Service**（礼拜程序）—— 用模板中的项目替换所选计划的礼拜程序项目
   - **Positions**（岗位）—— 用模板中的岗位替换所选计划的岗位（及其分配的人员）
5. 点击 **Apply**。

如果模板包含备注，应用时也会用模板的备注替换所选计划的备注。

:::warning
应用岗位会替换所选计划上所有现有的岗位和分配。应用之前，请确保你尚未为这些岗位安排志愿者。
:::

:::tip
当你希望保持一致的歌曲/讲道结构，而志愿者每周的分配各不相同时，请只应用礼拜程序，而不应用岗位。
:::

## 从模板开始新计划

模板在同一事工的各计划类型之间共享。当你点击 **New Plan**（新建计划），且该事工已有模板时，新计划表单会包含一个 **Start from template**（从模板开始）列表。选择一个模板并保存，新计划便会以该模板的礼拜程序、岗位和备注创建。选择模板后，该计划将不再使用 **Copy from Previous Plan**（从上一计划复制）选项。

## 保持模板为最新

如果你的标准礼拜结构有所变化，请打开模板管理器，使用 **Update from plan**，从你最新的计划同步模板，而不必从头重新建立。
