# 创建日历

<div class="article-intro">

在 B1 Admin 中创建日历，可以通过关联一个或多个小组来构建一个精选的活动视图。活动由小组负责人在各自的小组中管理，而你的日历会将这些活动集中显示在一处。拥有编辑权限的管理员可以为任何小组添加或编辑活动。非管理员的小组负责人只能管理自己所带领小组的活动。

## 创建新日历

1. 在 B1 Admin 中，打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **Calendars**，然后点击 **Calendars**。
2. 点击页面顶部的 **Add Calendar**。新日历表单会在日历列表下方打开。
3. 输入日历的**名称**（例如"青年事工活动"或"主教会日历"）。
4. 可选填写**描述**，帮助团队了解该日历的用途。
5. 点击 **Create** 保存新日历。

## 日历详情页

创建日历后，在其所在行点击 **Manage Events**，即可打开详情页。该页面分为两个主要区域：

- **左栏** —— 日历名称及其操作按钮（**New Event**、**Edit**、**Import .ics** 和 **Print**），随后是 **Groups in Calendar** 列表，显示已包含在该日历中的小组。点击某个小组旁边的 **Remove**，即可将其从日历中移除。
- **主区域** —— **Calendar Events** 视图，显示从已关联小组中汇集的活动，其上方有 **Subscribe** 和 **Add Group** 按钮。

## 关联小组

在日历中有活动的小组会自动出现在详情页左侧的 **Groups in Calendar** 列表中。

1. 点击日历上方的 **Add Group**，将某个小组与你的日历关联。
2. 从下拉菜单中选择该小组。列表中包含教会中的每个小组，而不仅仅是你所属的小组。
3. 选择是包含该小组的**所有活动**，还是仅包含**特定活动**。
4. 点击 **Save**。

每个活动在日历中只会出现一次。如果你添加了整个小组，之前已逐个添加的该小组活动会被合并到小组条目中；而从已在日历中的小组里挑选特定活动，则不会新增任何内容。只有作为整体添加的小组才会列在 **Groups in Calendar** 下。

### 导入 .ics 文件

点击 **Import .ics**，可从其他日历导入活动。选择活动所属的 **Group**，然后点击 **Choose .ics file** 或粘贴文件内容，再点击 **Import**。活动会在该小组中创建，并且该小组会被添加到你导入时所用的日历中，因此活动会立即显示在那里。

### 从日历中移除活动

点击日历上的某个活动，然后点击 **Remove from Calendar**。这只会将该活动从此日历中移除——活动本身仍保留在其所属小组中。如果该活动是因为整个小组被添加而出现在日历中，那么移除操作会将该小组的所有活动都从此日历中移除（活动仍保留在小组中）。要永久删除某个活动，请在[小组日历](../groups/group-calendar.md)中将其删除。

:::tip
将小组关联到日历是自动汇集活动的有效方式。当小组负责人在其[小组](../groups/creating-groups.md)中添加活动时，该活动无需你额外操作即可流入全教会的日历。
:::

:::info
如果你希望创建一个从全教会多个小组汇集活动的单一日历，请参阅[精选日历](curated-calendar)，了解更简便的方法。
:::

## 添加和编辑活动 {#adding-and-editing-events}

在日历详情页点击 **New Event** 即可添加活动；或点击日历上的某个活动，然后点击 **Edit** 进行修改。**New Event** / **Edit Event** 表单包含以下字段：

- **Group** —— 活动所属的小组。如果你的教会设有活动模板，还可以选择 **Template** 来自动填充表单。
- **Title**（标题）
- **Event photo**（活动照片）—— 点击 **Add Photo**（或空白的照片框）选择或上传图片，图片会裁剪为宽幅 16:9 的比例。点击 **Change Photo** 可替换照片。该照片会显示在你网站上活动页面的顶部；当日历元素显示 **Upcoming events** 时，它也会作为活动的卡片图片出现（参见[在网站上展示活动](#showing-events-on-your-website)）。
- **Description**（描述）—— 显示在你网站的活动页面上。支持粗体文字、列表和链接。
- **Start** 和 **End**（开始和结束）、**Repeats**（重复）以及 **Visibility**（可见性）（**Public**（公开）或 **Private**（私密））。
- **Tags**（标签）—— 以逗号分隔的标签，例如 `youth, students`。网站上的日历元素可以设置为只显示带有特定标签的活动。这与活动报名设置中显示的 **Tags** 字段相同。
- **Who can view notes**（谁可以查看备注）和 **Who can post notes**（谁可以发布备注）—— 决定哪些人可以阅读和添加活动备注（参见[活动备注](#event-notes)）。可选择 **Staff only**（仅工作人员）（默认）、**Group leaders**（小组负责人，即活动所属小组的负责人）或 **Group members**（小组成员，即活动所属小组中的所有人，包括负责人）。
- **Rooms**（房间）和 **Resources**（资源）—— 为活动预留空间和设备。参见[房间、资源与排期](rooms-resources)。

点击 **Save**。如果活动是重复性的，B1 会要求你确认，因为保存时会更新该系列中的每一次发生。

### 活动备注 {#event-notes}

每个活动都有自己的备注讨论串，用于规划和跟进。在日历详情页点击某个活动；对话框会显示该活动的详情、提醒，以及下方的 **Notes**。输入备注并发布，即可将其添加到讨论串中。

拥有编辑内容或管理日历权限的工作人员始终可以阅读和发布活动备注。活动上的 **Who can view notes** 和 **Who can post notes** 设置则决定活动所属小组的负责人或成员是否也可以这样做。

### 在网站上展示活动 {#showing-events-on-your-website}

要在你的网站上展示日历，请在页面中添加一个 **Calendar** 元素，并选择此日历。该元素可以显示月历，也可以显示即将举行活动的卡片网格，并可限定只显示带有某个标签的活动。访客点击某个活动即可打开其专属的活动页面。参见[使用日历元素](../website/page-editor.md#using-the-calendar-element)。

## 开启活动报名 {#enabling-event-registration}

你可以为任何日历活动开启报名功能，使成员能够通过 B1 网站或移动应用报名。

1. 点击现有活动，或创建新活动。
2. 在活动编辑器中，将 **Registration** 切换为开启。
3. 配置报名设置：
   - **Capacity**（名额）（可选）—— 设置最大报名人数。留空表示不限。
   - **Registration Opens**（报名开始）—— 报名开放的日期和时间。
   - **Registration Closes**（报名截止）—— 报名结束的日期和时间。
   - **Tags**（标签）—— 以逗号分隔的标签（例如"youth, retreat, vbs"），用于对可报名的活动进行分类。
   - **Registration Questions**（报名问题）—— 可选择附加一个[表单](../forms/creating-forms.md)，使报名者在报名时回答额外的问题（饮食限制、T恤尺码、紧急联系人等）。选择 **None** 则跳过问题。
   - **Enable Waitlist**（启用候补名单）—— 当活动名额已满时，允许更多报名者加入候补名单，而不是被拒绝。参见[付费报名](paid-registrations#waitlist)。
4. 保存活动。

对于付费活动，同一设置页面还允许你定义带价格的 **Attendee Types**（参与者类型）、可选的 **Selections**（附加选项）以及 **Discount Codes**（折扣码），付款通过教会的捐赠服务商收取。完整说明请参见[付费报名](paid-registrations)。

开启报名后，成员在 [B1 网站](../../b1-church/events/registering)或 [B1 移动应用](../../b1-mobile/events/registering)上查看活动时，会看到 **Register for this Event** 按钮。如果你附加了表单，报名者在报名过程中会看到 **Questions** 步骤，他们的回答会与报名信息一同保存。

:::info
报名问题仅适用于**未**标记为受限（Restricted）的表单。受限表单在报名过程中会被自动跳过而不显示，因此在为活动附加问题时，请使用未受限的表单。
:::

### 管理报名

要查看和管理活动的报名情况：

1. 在快速跳转菜单中，选择 **Calendars > Registrations**。
2. 你会看到一个表格，列出所有已开启报名的活动，显示活动名称、日期、当前报名人数与名额的对比，以及标签。
3. 点击某个活动，即可查看完整的报名列表，包括姓名、人数、参与者类型、付款状态和报名日期。
4. 在详情页中，你可以：
   - **Add Attendee**（添加参与者）—— 手动为通过线下或电话报名的人员办理登记。
   - **Cancel**（取消）个别报名
   - **Delete**（删除）报名（永久删除）
   - 当名额空出时，**Promote**（转正）候补中的报名
   - **Export CSV**（导出 CSV）—— 下载所有报名信息，包括参与者类型、附加选项、付款金额和问题回答

如果活动附加了报名问题，详情页还会显示 **Unanswered questions only**（仅显示未回答问题）筛选器，便于快速找到尚未提交回答的报名者；每条已回答的报名记录上还会有 **View Answers**（查看回答）按钮，用于查看其答复。付费活动会增加 **Type**（类型）列、**Paid / Total**（已付 / 总额）列、各类型的人数统计，以及付款详情对话框——参见[付费报名](paid-registrations#the-registration-roster)。

:::tip
使用名额进度条可以监控活动报名的满员速度。当活动达到或超过名额时，进度条会变为红色。
:::
