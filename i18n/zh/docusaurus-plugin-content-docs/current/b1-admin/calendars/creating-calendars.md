# 创建日历

<div class="article-intro">

在 B1 Admin 中创建日历，可以通过连接一个或多个小组来构建精选的活动视图。活动由小组负责人在各自的小组内管理，而您的日历会将这些活动集中显示在一处。拥有编辑权限的管理员可以为任何小组添加或编辑活动。非管理员的小组负责人只能管理自己所领导小组的活动。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置您希望纳入日历的[小组](../groups/creating-groups.md)
- 您需要拥有 B1 Admin 中日历板块的管理权限

</div>

## 创建新日历

1. 在 B1 Admin 中，打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**日历**，然后点击**日历**。
2. 点击页面顶部的**添加日历**。新日历表单会在日历列表下方打开。
3. 为您的日历输入**名称**（例如“青年事工活动”或“主教会日历”）。
4. 可选：添加**描述**，帮助您的团队了解该日历的用途。
5. 点击**创建**以保存新日历。

## 日历详情页

创建日历后，点击其所在行上的**管理活动**即可打开详情页。该页面包含两个主要区域：

- **左侧栏** —— 日历名称及其操作按钮（**新建活动**、**编辑**、**导入 .ics** 和**打印**），下方是**日历中的小组**列表，显示包含在该日历中的小组。点击某个小组旁边的**移除**，即可将其从日历中删除。
- **主区域** —— **日历活动**视图，显示从已连接小组中汇集的活动，上方有**订阅**和**添加小组**按钮。

## 连接小组

已在日历中拥有活动的小组会自动出现在详情页左侧的**日历中的小组**列表中。

1. 点击日历上方的**添加小组**，将一个小组关联到您的日历。
2. 从下拉菜单中选择该小组。
3. 选择要包含该小组的**全部活动**，还是仅包含**特定活动**。
4. 点击**保存**。

:::tip
将小组连接到日历，是自动汇总活动的有效方式。当小组负责人将活动添加到其[小组](../groups/creating-groups.md)中时，该活动就能无需您额外操作，自动显示在全教会的日历中。
:::

:::info
如果您希望创建一个从全教会众多小组中汇集活动的日历，请参阅[精选日历](curated-calendar)，了解更简便的做法。
:::

## 添加和编辑活动 {#adding-and-editing-events}

在日历详情页点击**新建活动**即可添加活动，或在日历中点击某个活动，然后点击**编辑**进行修改。**新建活动** / **编辑活动**表单包含以下字段：

- **小组** —— 活动所属的小组。如果您的教会设有活动模板，您还可以选择一个**模板**来预先填写表单。
- **标题**
- **活动照片** —— 点击**添加照片**（或空白的照片框）即可选择或上传图片，图片会被裁剪为宽幅 16:9 比例。点击**更改照片**可替换图片。该照片会显示在您网站上活动页面的顶部，并在日历元素显示**即将举行的活动**时作为其卡片图片（参见[在网站上显示活动](#showing-events-on-your-website)）。
- **描述** —— 显示在您网站上的活动页面中。支持粗体文本、列表和链接。
- **开始**和**结束**、**重复**以及**可见性**（**公开**或**私人**）。
- **标签** —— 以逗号分隔的标签，例如 `youth, students`。网站上的日历元素可以设置为只显示带有特定标签的活动。这与活动报名设置中显示的**标签**字段相同。
- **谁可以查看备注**和**谁可以发布备注** —— 决定谁可以阅读和添加活动备注（参见[活动备注](#event-notes)）。可选择**仅限员工**（默认）、**小组负责人**（活动所属小组的负责人）或**小组成员**（活动所属小组的所有成员，包括负责人）。
- **房间**和**资源** —— 为活动预订场地和设备。参见[房间、资源与排期](rooms-resources)。

点击**保存**。如果活动是重复的，B1 会要求您确认，因为保存时会更新该系列的每一次出现。

### 活动备注 {#event-notes}

每个活动都有自己的备注讨论串，用于规划和跟进。在日历详情页点击某个活动；对话框会显示该活动的详情、提醒，以及下方的**备注**。输入备注并发布，即可将其添加到讨论串中。

拥有编辑内容或管理日历权限的员工始终可以阅读和发布活动备注。活动上的**谁可以查看备注**和**谁可以发布备注**设置，决定该活动所属小组的负责人或成员是否也可以这样做。

### 在网站上显示活动 {#showing-events-on-your-website}

要在网站上显示日历，请在页面中添加一个**日历**元素，并选择此日历。该元素可以显示月历，也可以显示即将举行活动卡片的网格，并且可以限制为仅显示带有某个标签的活动。访客点击某个活动即可打开其专属活动页面。参见[使用日历元素](../website/page-editor.md#using-the-calendar-element)。

## 启用活动报名 {#enabling-event-registration}

您可以为任何日历活动启用报名，让会众通过 B1 网站或移动应用报名。

1. 点击现有活动，或新建一个活动。
2. 在活动编辑器中，切换**报名**开关以启用。
3. 配置报名设置：
   - **名额**（可选）—— 设置最大报名人数。留空表示不限。
   - **报名开始** —— 报名开放的日期和时间。
   - **报名截止** —— 报名结束的日期和时间。
   - **标签** —— 以逗号分隔的标签（例如 “youth, retreat, vbs”），用于帮助对可报名活动进行分类。
   - **报名问题** —— 可选择附加一个[表单](../forms/creating-forms.md)，使报名者在报名过程中回答额外问题（如饮食限制、T 恤尺码、紧急联系人等）。选择**无**即可跳过问题。
   - **启用候补名单** —— 当活动报名满员时，允许更多报名者加入候补名单，而不是被拒绝。参见[付费报名](paid-registrations#waitlist)。
4. 保存活动。

对于付费活动，同一设置页面还可以让您定义带价格的**参与者类型**、可选的**选项**（附加项目）以及**折扣码**，付款通过您教会的奉献服务商收取。完整说明请参见[付费报名](paid-registrations)。

启用报名后，会众在[B1 网站](../../b1-church/events/registering)或 [B1 移动应用](../../b1-mobile/events/registering)上查看该活动时，将会看到**报名参加此活动**按钮。如果您附加了表单，报名者在报名时会看到**问题**步骤，他们的回答将与报名信息一并保存。

:::info
报名问题仅适用于**未**标记为受限的表单。受限表单在报名过程中会被自动跳过而不显示，因此在为活动附加问题时，请使用非受限表单。
:::

### 管理报名

要查看和管理活动报名：

1. 在 Jump 菜单中，选择**日历 > 报名**。
2. 您将看到一个表格，列出所有已启用报名的活动，显示活动标题、日期、当前报名人数与名额、以及标签。
3. 点击某个活动，即可查看完整的报名列表，包括姓名、成员人数、参与者类型、付款状态和报名日期。
4. 在详情页中，您可以：
   - **添加参与者** —— 手动为通过线下或电话报名的人员办理报名。
   - **取消**单个报名
   - **删除**报名（永久删除）
   - 当有名额空出时，**升级**候补名单中的报名
   - **导出 CSV** —— 下载所有报名信息，包括参与者类型、选项、付款金额和问题回答

如果活动附加了报名问题，详情页还会显示**仅显示未回答的问题**筛选器，用于快速找出尚未提交回答的报名者；每条已回答的报名记录上还会有**查看回答**按钮，用于查看其回答内容。付费活动会增加**类型**列、**已付 / 总计**列、各类型的人数统计，以及付款详情对话框——参见[付费报名](paid-registrations#the-registration-roster)。

:::tip
使用名额进度条来监控活动报名的满员速度。当活动达到或超过名额时，进度条会变为红色。
:::
