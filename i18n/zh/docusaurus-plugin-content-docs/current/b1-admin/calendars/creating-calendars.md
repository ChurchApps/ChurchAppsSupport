# 创建日历

<div class="article-intro">

在 B1Admin 中创建日历可让您通过连接一个或多个小组来构建精选的事件视图。事件由小组领导者在其小组中管理，您的日历在一个位置显示这些事件。拥有编辑访问权限的管理员可以为任何小组添加或编辑事件。非管理员小组领导者只能管理他们领导的小组的事件。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置[小组](../groups/creating-groups.md)，其事件您想要包含在日历中
- 您需要对 B1Admin 中的日历部分拥有管理访问权限

</div>

## 创建新日历

1. 在 B1Admin 中，导航到**网站**，然后转到**日历**部分。
2. 点击**添加日历**。
3. 为您的日历输入**名称**（例如，"青年事工事件"或"主要教会日历"）。
4. 添加可选**描述**以帮助您的团队了解此日历的用途。
5. 点击**创建**保存您的新日历。

## 日历详情页面

创建日历后，单击它以打开详情页面。此页面有两个主要区域：

- **左列** — 日历的视图，显示从连接的小组中提取的事件。
- **右列** — 关联的小组列表。这是您管理此日历包含哪些小组的位置。

## 连接小组

在日历中具有事件的小组会自动出现在详情页面右侧的小组列表中。

1. 在小组部分点击**添加**以将小组与您的日历关联。
2. 从下拉菜单中选择小组。
3. 选择是包含该小组的**所有事件**还是仅**特定事件**。
4. 点击**保存**。

:::tip
将小组连接到您的日历是自动聚合事件的强大方式。当小组领导者向他们的[小组](../groups/creating-groups.md)添加事件时，它可以流入您的教会范围日历，无需您的任何额外工作。
:::

:::info
如果您想创建一个从教会各个小组提取事件的单一日历，请参阅[精选日历](curated-calendar)了解简化方法。
:::

## 启用事件注册

您可以为任何日历事件启用注册，以便成员可以通过 B1 网站或移动应用注册。

1. 单击现有事件或创建新事件。
2. 在事件编辑器中，切换**注册**以启用它。
3. 配置注册设置：
   - **容量**（可选）— 设置最大注册数量。留空表示无限制。
   - **注册打开** — 注册变得可用的日期和时间。
   - **注册关闭** — 注册关闭的日期和时间。
   - **标签** — 以逗号分隔的标签（例如"青年、撤退、VBS"），以帮助分类可注册事件。
   - **注册问题** — 可选择附加[表单](../forms/creating-forms.md)，以便注册者在注册时回答额外问题（饮食限制、T 恤尺寸、紧急联系人等）。选择**无**以跳过问题。
   - **启用候补名单** — 当事件填满时，让额外注册者加入候补名单，而不是被拒绝。参见[付费注册](paid-registrations#waitlist)。
4. 保存事件。

对于付费事件，同一设置页面允许您定义带价格的**参加者类型**、可选**选择**（附加项）和**折扣代码**，付款通过您的教会捐赠提供商收集。有关完整的演练，请参见[付费注册](paid-registrations)。

启用注册后，成员在[B1 网站](../../b1-church/events/registering)或[B1 移动应用](../../b1-mobile/events/registering)上查看事件时会看到**注册此事件**按钮。如果您附加了表单，注册者在注册期间会看到**问题**步骤，他们的答案会与其注册一起保存。

:::info
注册问题仅适用于**未**标记为受限的表单。受限表单在注册期间会自动跳过，而不是显示，因此在将问题附加到事件时请使用不受限的表单。
:::

### 管理注册

要查看和管理您事件的注册：

1. 导航到 B1Admin 中的**注册**页面。
2. 您会看到所有启用了注册的事件表，显示事件标题、日期、当前注册计数对容量和标签。
3. 单击事件以查看完整的注册列表，包括姓名、成员计数、参加者类型、付款状态和注册日期。
4. 从详情页面，您可以：
   - **添加参加者** — 手动注册离线或通过电话注册的人。
   - **取消**个人注册
   - **删除**注册永久
   - **晋升**候补名单注册当有空位时
   - **导出 CSV** — 下载所有注册，包括参加者类型、选择、付款金额和问题答案

如果事件附加了注册问题，详情页面还会显示**仅未回答的问题**过滤器以快速找到未提交答案的注册者，以及每个已回答注册上的**查看答案**按钮以查看他们的回应。付费事件添加**类型**列、**已付款/总计**列、每种类型的计数和付款详情对话框 — 参见[付费注册](paid-registrations#the-registration-roster)。

:::tip
使用容量进度条监控事件填满的速度。当事件处于或超过容量时，该条会变红。
:::
