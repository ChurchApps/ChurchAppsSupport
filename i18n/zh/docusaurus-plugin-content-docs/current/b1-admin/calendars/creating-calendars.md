# 创建日历

<div class="article-intro">

在 B1 Admin 中创建日历，可以通过关联一个或多个小组来构建一个精心整理的活动视图。活动由小组负责人在其小组内进行管理，而您的日历会将这些活动集中显示在一个地方。即使是域管理员，如果不是活动所属小组的负责人，也无法在日历部分直接添加或编辑活动。

</div>

<div class="prereqs">
<h4>准备工作</h4>

- 设置好您希望纳入日历的[小组](../groups/creating-groups.md)的活动
- 您需要拥有 B1 Admin 中"日历"部分的管理权限

</div>

## 创建新日历

1. 在 B1 Admin 中，导航到**网站**，然后进入**日历**部分。
2. 点击**添加日历**。
3. 为您的日历输入一个**名称**（例如，"青年事工活动"或"教会主日历"）。
4. 添加可选的**描述**，帮助团队了解此日历的用途。
5. 点击**创建**以保存新日历。

## 日历详情页

创建日历后，点击进入详情页。此页面有两个主要区域：

- **左栏** -- 日历视图，显示从关联小组中导入的活动。
- **右栏** -- 关联小组列表。您可以在这里管理哪些小组被纳入此日历。

## 关联小组

在日历中有活动的小组会自动出现在详情页右侧的小组列表中。

1. 在小组区域点击**添加**，将某个小组与您的日历关联。
2. 从下拉菜单中选择该小组。
3. 选择是纳入该小组的**所有活动**，还是仅纳入**特定活动**。
4. 点击**保存**。

:::tip
将小组关联到日历是自动汇总活动的强大方式。当小组负责人在其[小组](../groups/creating-groups.md)中添加活动时，该活动可以自动汇入您的全教会日历，无需额外操作。
:::

:::info
如果您想创建一个从教会内多个小组汇总活动的单一日历，请参阅[精选日历](curated-calendar)，了解更精简的方法。
:::

## 启用活动注册

您可以为任何日历活动启用注册功能，让成员通过 B1 网站或移动应用报名。

1. 点击现有活动，或创建一个新活动。
2. 在活动编辑器中，打开**注册**开关以启用该功能。
3. 配置注册设置：
   - **容量**（可选）-- 设置最大注册人数。留空表示不限。
   - **注册开始时间** -- 注册开放的日期和时间。
   - **注册截止时间** -- 注册关闭的日期和时间。
   - **标签** -- 以逗号分隔的标签（例如，"青年、退修会、暑期圣经学校"），用于帮助分类可注册的活动。
   - **注册问题** -- 您可以选择关联一个[表单](../forms/creating-forms.md)，让注册者在报名时回答额外问题（饮食限制、T 恤尺码、紧急联系人等）。选择**无**可跳过问题。
   - **启用候补名单** -- 当活动名额已满时，允许额外的注册者加入候补名单，而不是被拒绝。请参阅[付费注册](paid-registrations#waitlist)。
4. 保存活动。

对于付费活动，同一设置页面还可让您定义带价格的**参加者类型**、可选的**附加项**（增值选项）以及**折扣码**，付款通过教会的奉献服务商收取。有关完整说明，请参阅[付费注册](paid-registrations)。

启用注册后，成员在[B1 网站](../../b1-church/events/registering)或 [B1 移动应用](../../b1-mobile/events/registering)中查看活动时会看到**报名参加此活动**按钮。如果您关联了表单，注册者会在注册过程中看到**问题**步骤，其答案会与注册信息一同保存。

:::info
注册问题功能仅适用于**未**标记为受限的表单。受限表单会在注册过程中被自动跳过而不会显示，因此在为活动关联问题时请使用非受限表单。
:::

### 管理注册

要查看和管理活动的注册情况：

1. 导航到 B1 Admin 中的**注册**页面。
2. 您会看到一个表格，列出所有已启用注册的活动，显示活动标题、日期、当前注册人数与容量的对比，以及标签。
3. 点击某个活动可查看完整的注册列表，包括姓名、成员人数、参加者类型、付款状态和注册日期。
4. 在详情页中，您可以：
   - **添加参加者** -- 手动为线下或电话报名的人登记。
   - **取消**单条注册
   - **永久删除**注册
   - 名额空出时**提升**候补名单上的注册
   - **导出 CSV** -- 下载所有注册信息，包括参加者类型、附加项、付款金额和问题答案

如果活动附有注册问题，详情页还会显示一个**仅显示未回答问题**的筛选器，方便快速找到尚未提交答案的注册者；每条已回答的注册记录旁还有**查看答案**按钮，可查看其回复内容。付费活动会额外显示**类型**列、**已付/总额**列、各类型的人数统计，以及付款详情对话框——请参阅[付费注册](paid-registrations#the-registration-roster)。

:::tip
使用容量进度条监控活动报名的速度。当活动达到或超过容量时，进度条会变为红色。
:::
