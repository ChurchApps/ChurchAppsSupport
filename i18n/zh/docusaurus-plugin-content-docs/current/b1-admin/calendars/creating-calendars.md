# 创建日历

<div class="article-intro">

在 B1 Admin 中创建日历，可以通过关联一个或多个小组来构建一个精选的活动视图。活动由小组负责人在各自的小组内管理，而你的日历会将这些活动集中显示在一处。具有编辑权限的管理员可以为任何小组添加或编辑活动。非管理员的小组负责人只能管理自己所带领小组的活动。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置好你希望纳入日历的[小组](../groups/creating-groups.md)
- 你需要拥有 B1 Admin 中日历板块的管理访问权限

</div>

## 创建新日历

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **Calendars**，然后点击 **Calendars**。
2. 点击页面顶部的 **Add Calendar**。新的日历表单会在日历列表下方打开。
3. 为你的日历输入**名称**（例如“青年事工活动”或“主教会日历”）。
4. 可选填写**描述**，帮助你的团队了解该日历的用途。
5. 点击 **Create** 保存新日历。

## 日历详情页

创建日历后，点击其所在行的 **Manage Events** 即可打开详情页。该页面分为两个主要区域：

- **左侧栏** —— 日历名称及其操作按钮（**New Event**、**Edit**、**Import .ics** 和 **Print**），下方是 **Groups in Calendar** 列表，显示已包含在该日历中的小组。点击某个小组旁的 **Remove**，即可将其移出日历。
- **主区域** —— **Calendar Events** 视图，显示从已关联小组中汇集的活动，上方有 **Subscribe** 和 **Add Group** 按钮。

## 关联小组

在日历中有活动的小组会自动出现在详情页左侧的 **Groups in Calendar** 列表中。

1. 点击日历上方的 **Add Group**，将小组与你的日历关联。
2. 从下拉菜单中选择小组。列表包含教会中的每个小组，而不仅仅是你所属的小组。
3. 选择是纳入该小组的**所有活动**，还是仅纳入**特定活动**。
4. 点击 **Save**。

每个活动在日历中只会出现一次。如果你添加了整个小组，那么之前已逐个添加的该小组活动会合并到小组条目中；如果你从已在日历中的小组中选择特定活动，则不会新增任何内容。只有以整体方式添加的小组才会列在 **Groups in Calendar** 下。

### 导入 .ics 文件

点击 **Import .ics**，从其他日历导入活动。选择活动应归属的**小组**，然后点击 **Choose .ics file** 或粘贴文件内容，再点击 **Import**。活动会在该小组中创建，并且该小组会被添加到你导入所用的日历中，因此活动会立即显示在那里。

### 从日历中移除活动

点击日历上的某个活动，然后点击 **Remove from Calendar**。这只会将该活动从此日历中移除——活动本身仍保留在其小组中。如果该活动是因整个小组被添加而出现在日历上的，那么移除时会将该小组的所有活动都从此日历中移除（活动仍保留在小组中）。要永久删除某个活动，请在[小组日历](../groups/group-calendar.md)中将其删除。

:::tip
将小组关联到你的日历，是自动汇总活动的有效方式。当小组负责人将活动添加到其[小组](../groups/creating-groups.md)中时，该活动就能自动汇入你的全教会日历，无需你额外操作。
:::

:::info
如果你想创建一个汇集全教会多个小组活动的日历，请参见[精选日历](curated-calendar)，了解更简便的做法。
:::

## 添加和编辑活动 {#adding-and-editing-events}

在日历详情页点击 **New Event** 即可添加活动，或在日历上点击某个活动后再点击 **Edit** 进行修改。**New Event** / **Edit Event** 表单包含以下字段：

- **Group** —— 活动所属的小组。如果你的教会设有活动模板，你还可以选择一个**Template**来自动填充表单。
- **Title**（标题）
- **Event photo**（活动照片）—— 点击 **Add Photo**（或空白的照片框）选择或上传图片，图片将被裁剪为宽幅 16:9 比例。点击 **Change Photo** 可替换图片。该照片会显示在你网站上活动页面的顶部，并在日历元素显示**Upcoming events**时作为其缩略图（参见[在网站上展示活动](#showing-events-on-your-website)）。
- **Description**（描述）—— 显示在你网站上的活动页面中。支持粗体文字、列表和链接。
- **Start** 和 **End**、**Repeats**（重复）以及 **Visibility**（可见性，**Public** 公开或 **Private** 私密）。
- **Tags**（标签）—— 以逗号分隔的标签，例如 `youth, students`。网站上的日历元素可设置为仅显示带有特定标签的活动。这与活动报名设置中显示的**Tags**字段相同。
- **Who can view notes** 和 **Who can post notes** —— 谁可以阅读和添加活动备注（参见[活动备注](#event-notes)）。可选择 **Staff only**（仅员工，默认）、**Group leaders**（活动所属小组的负责人）或 **Group members**（活动所属小组的所有成员，包括负责人）。
- **Rooms** 和 **Resources**（房间和资源）—— 为活动预留空间和设备。参见[房间、资源与排期](rooms-resources)。

点击 **Save**。如果活动是重复的，B1 会要求你确认，因为保存时会更新该系列中的每一次出现。

### 活动备注 {#event-notes}

每个活动都有自己的备注讨论串，用于计划和跟进。在日历详情页上点击某个活动，对话框会显示活动详情、提醒以及下方的**备注（Notes）**。输入备注并发布，即可将其添加到讨论串中。

具有编辑内容或管理日历权限的员工始终可以阅读和发布活动备注。活动上的 **Who can view notes** 和 **Who can post notes** 设置则决定该活动所属小组的负责人或成员是否也能阅读或发布。

### 在网站上展示活动 {#showing-events-on-your-website}

要在你的网站上展示日历，请在页面中添加一个**日历（Calendar）**元素，并选择该日历。该元素可以显示月历视图，也可以显示即将举行活动的网格磁贴，并且可以限定为仅显示带有某个标签的活动。访客点击某个活动即可打开其专属的活动页面。参见[使用日历元素](../website/page-editor.md#using-the-calendar-element)。

## 开启活动报名 {#enabling-event-registration}

你可以为任何日历活动开启报名，使成员能够通过 B1 网站或移动应用进行报名。

1. 点击已有活动，或创建新活动。
2. 在活动编辑器中，将 **Registration** 切换为开启。
3. 配置报名设置：
   - **Capacity**（名额，可选）—— 设置最大报名人数。留空表示不限。
   - **Registration Opens**（报名开始）—— 报名开放的日期和时间。
   - **Registration Closes**（报名截止）—— 报名结束的日期和时间。
   - **Tags**（标签）—— 以逗号分隔的标签（例如“youth, retreat, vbs”），用于帮助对可报名活动进行分类。
   - **Registration Questions**（报名问题，可选）—— 可附加一个[表单](../forms/creating-forms.md)，使报名者在报名时回答额外的问题（例如饮食限制、T 恤尺码、紧急联系人等）。选择 **None** 可跳过问题。
   - **Enable Waitlist**（启用候补名单）—— 当活动名额已满时，允许额外的报名者加入候补名单，而不是被拒绝。参见[付费报名](paid-registrations#waitlist)。
4. 保存活动。

对于付费活动，同一设置页面还可以让你定义有价格的**参加者类型（Attendee Types）**、可选的**附加项（Selections）**以及**折扣码（Discount Codes）**，付款通过你教会的捐款服务提供商收取。完整说明请参见[付费报名](paid-registrations)。

开启报名后，成员在 [B1 网站](../../b1-church/events/registering)或 [B1 移动应用](../../b1-mobile/events/registering)上查看该活动时，将看到 **Register for this Event** 按钮。如果你附加了表单，报名者在报名过程中会看到**Questions**步骤，他们的回答会与报名信息一同保存。

:::info
报名问题仅适用于**未**标记为受限（Restricted）的表单。受限表单在报名过程中会被自动跳过而不会显示，因此在为活动附加问题时，请使用未受限的表单。
:::

### 管理报名

要查看和管理活动的报名情况：

1. 在跳转菜单中，选择 **Calendars > Registrations**。
2. 你会看到一个表格，列出所有已开启报名的活动，显示活动标题、日期、当前报名人数与名额的对比，以及标签。
3. 点击某个活动，即可查看完整的报名列表，包括姓名、人数、参加者类型、付款状态以及报名日期。
4. 在详情页中，你可以：
   - **Add Attendee** —— 手动为通过线下或电话报名的人员办理报名。
   - **Cancel** 单个报名
   - **Delete** 永久删除报名
   - 名额出现空缺时，**Promote** 候补名单中的报名
   - **Export CSV** —— 下载所有报名信息，包括参加者类型、附加项、付款金额和问题回答

如果活动附加了报名问题，详情页还会显示 **Unanswered questions only** 筛选器，用于快速找出尚未提交回答的报名者，并且每条已回答的报名旁都有 **View Answers** 按钮，可查看其回答内容。付费活动会增加 **Type** 列、**Paid / Total** 列、各类型人数统计以及付款详情对话框——参见[付费报名](paid-registrations#the-registration-roster)。

:::tip
使用名额进度条来监控活动报名的满员速度。当活动达到或超过名额上限时，进度条会变为红色。
:::
