# 创建日历

<div class="article-intro">

在 B1 Admin 中创建日历，可以通过关联一个或多个小组，打造一个精选的活动视图。活动由小组负责人在各自小组内管理，而你的日历会在一处集中显示这些活动。拥有编辑权限的管理员可以为任何小组添加或编辑活动。非管理员的小组负责人只能管理自己负责的小组的活动。

</div>

## 创建新日历

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（位于左上角的搜索栏），展开 **日历**，然后点击 **日历**。
2. 点击页面顶部的 **添加日历**。新日历表单会在日历列表下方打开。
3. 为你的日历输入一个**名称**（例如"青年事工活动"或"主堂日历"）。
4. 可选择填写**描述**，帮助团队了解这个日历的用途。
5. 点击 **创建** 保存新日历。

## 日历详情页

创建日历后，点击其所在行的 **管理活动**，即可打开详情页。该页面主要分为两个区域：

- **左侧栏**：显示日历名称及其操作按钮（**新建活动**、**编辑**、**导入 .ics** 和 **打印**），下方是 **日历中的小组** 列表，显示哪些小组已包含在此日历中。点击某个小组旁边的 **移除**，即可将其从日历中删除。
- **主区域**：**日历活动** 视图，显示从已关联小组汇入的活动，上方有 **订阅** 和 **添加小组** 按钮。

## 关联小组

在日历中有活动的小组，会自动出现在详情页左侧的 **日历中的小组** 列表里。

1. 点击日历上方的 **添加小组**，将一个小组关联到你的日历。
2. 从下拉菜单中选择小组。列表包含教会中的所有小组，而不仅限于你所属的小组。
3. 选择是纳入该小组的**全部活动**，还是仅纳入**特定活动**。
4. 点击 **保存**。

每个活动在日历中只会出现一次。如果你添加了整个小组，之前已逐个添加的该小组活动会被归入小组条目中；而从已在日历中的小组里再选择特定活动，则不会新增任何内容。只有以整体方式添加的小组，才会列在 **日历中的小组** 下。

### 导入 .ics 文件

点击 **导入 .ics**，即可从其他日历导入活动。选择活动应归属的 **小组**，然后点击 **选择 .ics 文件**或粘贴文件内容，再点击 **导入**。活动会被创建在该小组中，并且该小组会被添加到你导入时所用的日历中，因此活动会立即显示在那里。

### 从日历中移除活动

点击日历上的某个活动，然后点击 **从日历中移除**。这只会将活动从此日历中撤下，活动本身仍保留在其所属小组中。如果该活动是因为整个小组被添加而出现在日历中的，那么移除操作会把该小组的所有活动都从此日历中撤下（活动仍保留在小组中）。若要永久删除某个活动，请前往[小组日历](../groups/group-calendar.md)将其删除。

:::tip
将小组关联到日历，是自动汇总活动的高效方式。当小组负责人在其[小组](../groups/creating-groups.md)中添加活动时，该活动便能自动流入全教会的日历，无需你额外操作。
:::

:::info
如果你希望创建一个能汇集教会内多个小组活动的日历，请参阅[精选日历](./curated-calendar.md)，了解更简便的做法。
:::

## 添加和编辑活动 {#adding-and-editing-events}

在日历详情页点击 **新建活动** 即可添加活动；若要修改，请在日历上点击某个活动，然后点击 **编辑**。**新建活动** / **编辑活动** 表单包含以下字段：

- **小组**：活动所属的小组。如果你的教会设有活动模板，你还可以选择一个**模板**来预先填充表单。
- **标题**
- **活动照片**：点击 **添加照片**（或空白的照片框）选择或上传图片，图片会被裁剪为宽幅的 16:9 比例。点击 **更换照片** 可以替换。该照片会显示在你网站上活动页面的顶部；当日历组件显示**即将举行的活动**时，它也会作为活动的卡片图片出现（参见[在网站上展示活动](#showing-events-on-your-website)）。
- **描述**：显示在你网站上的活动页面中。支持粗体文字、列表和链接。
- **开始**和**结束**、**重复**，以及**可见性**（**公开**或**私密**）。
- **标签**：以逗号分隔的标签，例如 `youth, students`。你可以将网站上的日历组件设置为仅显示带有特定标签的活动。这与活动报名设置中显示的**标签**字段相同。
- **谁可以查看备注**和**谁可以发布备注**：决定哪些人可以阅读和添加活动备注（参见[活动备注](#event-notes)）。可选择**仅限员工**（默认）、**小组负责人**（活动所属小组的负责人）或**小组成员**（活动所属小组的所有成员，包括负责人）。
- **场地**和**资源**：为活动预留空间和设备。请参阅[场地、资源与排期](./rooms-resources.md)。

点击 **保存**。如果活动是重复的，B1 会要求你确认，因为保存操作会更新该系列中的每一次安排。

### 活动备注 {#event-notes}

每个活动都有自己的备注讨论串，用于规划和跟进。在日历详情页点击某个活动，对话框会显示该活动的详情、提醒，以及下方的 **备注**。输入备注后点击发布，即可将其添加到讨论串中。

拥有编辑内容或管理日历权限的员工，始终可以阅读和发布活动备注。活动上的**谁可以查看备注**和**谁可以发布备注**设置，决定该活动所属小组的负责人或成员是否同样拥有这些权限。

### 在你的网站上展示活动 {#showing-events-on-your-website}

若要在网站上展示日历，请在页面中添加一个**日历**组件，并选择此日历。该组件可以显示月历，或以网格形式展示即将举行的活动卡片，还可以限制为仅显示带有某个标签的活动。访客点击某个活动后，会打开该活动自己的页面。请参阅[使用日历组件](../website/page-editor.md#using-the-calendar-element)。

## 启用活动报名 {#enabling-event-registration}

你可以为任何日历活动启用报名，让成员通过 B1 网站或移动应用报名。

1. 点击现有活动，或新建一个活动。
2. 在活动编辑器中，将**报名**开关打开。
3. 配置报名设置：
   - **名额上限**（可选）：设置最多可报名的人数。留空则不限人数。
   - **报名开始时间**：报名开始可用的日期和时间。
   - **报名截止时间**：报名结束的日期和时间。
   - **标签**：以逗号分隔的标签（例如"青少年, 退修会, vbs"），用于帮助对可报名活动进行分类。
   - **报名问题**：可选择附加一个[表单](../forms/creating-forms.md)，让报名者在报名时回答额外问题（如饮食限制、T 恤尺码、紧急联系人等）。选择**无**即可跳过问题。
   - **启用候补名单**：当活动名额已满时，允许其他报名者加入候补名单，而不是直接被拒绝。请参阅[付费报名](./paid-registrations.md#waitlist)。
4. 保存活动。

对于付费活动，同一设置页面还可以让你定义带价格的**参加者类型**、可选的**附加选项**（加购项目），以及**优惠码**，付款通过教会的奉献服务提供商收取。完整说明请参阅[付费报名](./paid-registrations.md)。

启用报名后，成员在[B1.church 或 B1 App](../../b1-church/events/registering.md)中查看该活动时，会看到一个**报名此活动**按钮。如果你附加了表单，报名者在报名过程中会看到**问题**步骤，他们的回答会与报名信息一同保存。

:::info
报名问题仅适用于**未**标记为受限的表单。受限表单在报名过程中会被自动跳过而不予显示，因此在为活动附加问题时，请使用未受限的表单。
:::

### 管理报名

若要查看和管理活动的报名情况：

1. 在跳转菜单中，选择 **日历 > 报名**。
2. 你会看到一个表格，列出所有已启用报名的活动，包括活动标题、日期、当前报名人数与名额上限，以及标签。
3. 点击某个活动，即可查看完整的报名名单，包括姓名、成员人数、参加者类型、付款状态和报名日期。
4. 在详情页中，你可以：
   - **添加参加者**：手动为通过线下或电话报名的人登记。
   - **取消**单个报名
   - **永久删除**报名记录
   - 当名额空出时，**转正**候补名单中的报名
   - **导出 CSV**：下载所有报名记录，包括参加者类型、附加选项、付款金额和问题回答

如果活动附加了报名问题，详情页还会显示一个**仅显示未回答问题**的筛选器，方便快速找到尚未提交回答的报名者；每条已回答的报名记录上还会有一个**查看回答**按钮，用于查看他们的回复。付费活动会额外增加**类型**列、**已付/总数**列、每种类型的人数统计，以及付款详情对话框，请参阅[付费报名](./paid-registrations.md#the-registration-roster)。

:::tip
利用名额进度条，可以了解活动报名的填满速度。当活动达到或超过名额上限时，进度条会变为红色。
:::
