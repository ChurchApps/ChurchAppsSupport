# 创建日历

<div class="article-intro">

在B1 Admin中创建日历可以让您通过连接一个或多个小组来构建策划好的事件视图。事件由小组领导者在他们的小组内管理，您的日历在一个地方显示这些事件。具有编辑权限的管理员可以为任何小组添加或编辑事件。非管理员组领导者只能管理他们领导的小组的事件。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置您想在日历中包含事件的[小组](../groups/creating-groups.md)
- 您需要对B1 Admin中的日历部分拥有管理权限

</div>

## 创建新日历

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**日历**，然后点击**日历**。
2. 点击**添加日历**。
3. 为您的日历输入**名称**（例如"青年事工事件"或"主教会日历"）。
4. 添加可选的**描述**以帮助您的团队理解此日历的用途。
5. 点击**创建**来保存您的新日历。

## 日历详情页面

创建日历后，单击它以打开详情页面。此页面有两个主要区域：

- **左列** -- 显示从连接的小组拉取的事件的日历视图。
- **右列** -- 相关小组列表。这是您管理此日历中包含哪些小组的地方。

## 连接小组

具有日历事件的小组会自动出现在详情页面右侧的小组列表中。

1. 在小组部分中单击**添加**以将小组与您的日历关联。
2. 从下拉菜单中选择小组。
3. 选择是包含该小组的**所有事件**还是仅**特定事件**。
4. 点击**保存**。

:::tip
将小组连接到您的日历是自动聚合事件的强大方法。当小组领导者向他们的[小组](../groups/creating-groups.md)添加事件时，它可以流入您的教会范围内的日历，而无需您的任何额外工作。
:::

:::info
如果您想创建从教会内许多小组拉取事件的单个日历，请参阅[策划日历](curated-calendar)了解简化的方法。
:::

## 启用事件注册

您可以为任何日历事件启用注册，以便成员可以通过B1网站或移动应用程序注册。

1. 单击现有事件或创建新事件。
2. 在事件编辑器中，切换**注册**来启用它。
3. 配置注册设置：
   - **容量**（可选）-- 设置最大注册数。留空表示无限制。
   - **注册打开** -- 注册可用的日期和时间。
   - **注册关闭** -- 注册关闭的日期和时间。
   - **标签** -- 逗号分隔的标签（例如"青年、务工会、VBS"）以帮助分类可注册事件。
   - **注册问题** -- 可选择附加一个[表单](../forms/creating-forms.md)，以便申请人在注册时回答额外问题（饮食限制、T恤尺寸、紧急联系人等）。选择**无**来跳过问题。
   - **启用等待列表** -- 当事件满满时，让其他申请人加入等待列表而不是被拒绝。参见[付费注册](paid-registrations#waitlist)。
4. 保存事件。

对于付费活动，同一设置页面让您定义定价的**参与者类型**，可选的**选择**（附加功能），和**折扣代码**，付款通过您教会的捐献提供商收集。有关完整的演练，请参见[付费注册](paid-registrations)。

一旦启用注册，成员在查看[B1网站](../../b1-church/events/registering)或[B1移动应用](../../b1-mobile/events/registering)上的事件时会看到**为此事件注册**按钮。如果您附加了表单，申请人在注册期间会看到**问题**步骤，他们的答案会随他们的注册一起保存。

:::info
注册问题仅适用于**未**标记为受限的表单。受限表单在注册期间会被自动跳过而不会显示，因此在将问题附加到事件时使用不受限的表单。
:::

### 管理注册

要查看和管理您的事件注册：

1. 在Jump菜单中，选择**日历 > 注册**。
2. 您将看到一个表格，显示所有启用注册的事件，包括事件标题、日期、当前注册数与容量、和标签。
3. 单击事件以查看完整的注册列表，包括名称、成员数、参与者类型、付款状态和注册日期。
4. 从详情页面，您可以：
   - **添加参与者** -- 手动注册在线下或电话上注册的人员。
   - **取消**单个注册
   - **删除**永久注册
   - **提升**等待列表注册当位置开放时
   - **导出CSV** -- 下载所有注册，包括参与者类型、选择、付款金额和问题答案

如果事件有附加的注册问题，详情页面还显示**仅未回答的问题**筛选器以快速查找尚未提交答案的申请人，和一个**查看答案**按钮在每个已回答的注册上查看他们的回复。付费活动添加**类型**列、**已付/总计**列、按类型计数和付款详情对话框 -- 参见[付费注册](paid-registrations#the-registration-roster)。

:::tip
使用容量进度条来监控事件填充的速度。当事件达到或超过容量时，栏变为红色。
:::
