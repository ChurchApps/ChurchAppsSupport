# 房间、资源和日程

<div class="article-intro">

房间和资源让您跟踪您的教会的可预订空间和设备。当小组或团队想要为事件使用房间或借用资源时，他们可以通过 B1 请求 — 您可以批准或拒绝这些请求以防止重复预订。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要对 B1Admin 中的日历部分拥有管理访问权限
- 设置[小组](../groups/creating-groups)，其成员将提交预订请求

</div>

## 打开房间和资源

在 B1Admin 中，转到**日历**并选择**房间和资源**。页面有四个标签：**房间**、**资源**、**封闭**和**模板**。

## 房间

房间是可以与日历事件一起预留的物理空间 — 圣殿、联谊厅、教室等。

### 添加房间

1. 在**房间**标签上，单击**添加房间**。
2. 输入房间的**名称**。
3. 可选择设置**容量**（最大人数）。
4. 设置**批准组** — 当小组请求此房间时，选择的小组的领导者会收到通知并必须批准预订。如果不需要批准，留空。
5. 点击**保存**。

### 编辑或删除房间

单击任何房间旁边的编辑图标，进行更改，然后单击**保存**。使用**删除**永久删除房间。

## 资源

资源是可以与事件一起预订的项目 — AV 设备、投影仪、椅子、面包车等。

### 添加资源

1. 单击**资源**标签，然后**添加资源**。
2. 输入**名称**和可选**描述**。
3. 如果有人需要签署资源贷款，请设置**批准组**。
4. 点击**保存**。

## 封闭

封闭防止房间或资源在特定时间段内被预订 — 用于装修、预留期限或维护。

### 添加封闭

1. 单击**封闭**标签，然后**添加封闭**。
2. 选择是否要封闭**房间**、**资源**或所有房间和资源。
3. 设置封闭的**开始**和**结束**日期/时间。
4. 可选地添加**原因**备注。
5. 点击**保存**。

## 事件模板

模板让您保存可重复使用的事件配置 — 标题、描述和关联的小组 — 以便定期事件可以一致地创建。

### 添加模板

1. 单击**模板**标签，然后**添加模板**。
2. 为模板输入**名称**。
3. 可选择链接**小组**，以便从模板创建时事件自动连接到该小组。
4. 点击**保存**。

创建新事件时，工作人员可以选择现有模板以预填事件详情。
