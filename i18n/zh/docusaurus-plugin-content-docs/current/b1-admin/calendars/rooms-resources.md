# 房间、资源和日程

<div class="article-intro">

房间和资源让您跟踪教会的可预订空间和设备。当小组或团队想为事件使用房间或借用资源时，他们可以通过B1请求 -- 您可以批准或拒绝这些请求以防止双重预订。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要对B1 Admin中的日历部分拥有管理权限
- 设置[小组](../groups/creating-groups)，其成员将提交预订请求

</div>

## 打开房间和资源

在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**日历**，然后点击**房间和资源**。该页面有四个标签页：**房间**、**资源**、**停用**和**模板**。

## 房间

房间是可以与日历事件一起预留的物理空间 -- 礼拜堂、团契厅、教室等。

### 添加房间

1. 在**房间**标签页上，点击**添加房间**。
2. 为房间输入**名称**。
3. 可选地设置**容量**（最大人数）。
4. 设置**批准小组** -- 当小组请求此房间时，所选小组的领导者会收到通知并必须批准预订。如果不需要批准，留空。
5. 点击**保存**。

### 编辑或删除房间

点击任何房间旁边的编辑图标，做出您的更改，然后点击**保存**。使用**删除**来永久删除房间。

## 资源

资源是可以与事件一起预订的项目 -- 音视频设备、投影仪、椅子、货车等。

### 添加资源

1. 点击**资源**标签页，然后**添加资源**。
2. 输入**名称**和可选的**描述**。
3. 如果需要有人签字批准资源贷款，设置**批准小组**。
4. 点击**保存**。

## 停用

停用防止房间或资源在某些时间被预订 -- 用于翻新、保留期或维护。

### 添加停用

1. 点击**停用**标签页，然后**添加停用**。
2. 选择是否阻止**房间**、**资源**或所有房间和资源。
3. 为停用设置**开始**和**结束**日期/时间。
4. 可选地添加**原因**备注。
5. 点击**保存**。

## 事件模板

模板让您保存可重复使用的事件配置 -- 标题、描述和相关小组 -- 这样定期事件可以一致地创建。

### 添加模板

1. 点击**模板**标签页，然后**添加模板**。
2. 为模板输入**名称**。
3. 可选地链接**小组**，以便从模板创建事件时自动将事件连接到该小组。
4. 点击**保存**。

在创建新事件时，员工可以选择现有模板来预填事件详情。
