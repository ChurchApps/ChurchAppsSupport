# 付费报名

<div class="article-intro">

活动报名可以不仅仅是简单的人数统计。你可以定义带价格的参加者类型（如成人和儿童）、提供带各自价格和数量的可选附加项、创建折扣码，并通过教会现有的捐献服务提供商在报名时收取付款。当活动名额已满时，可选的候补名单会让感兴趣的成员排队等候，并在名额空出时自动晋升。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 先在活动上启用报名功能——参见[创建日历](creating-calendars#enabling-event-registration)
- 若要收取付款，你的教会需要[配置在线捐献](../donations/online-giving-setup.md)（Stripe、PayPal 或 Kingdom Funding）。免费活动无需配置捐献。

</div>

## 打开报名设置

1. 在 B1 Admin 中，前往**报名**页面并打开你的活动（或从其日历中打开该活动）。
2. **报名设置**卡片显示基本信息——**启用报名**、**容量**、**报名开始/结束时间**、**标签**和**报名问题**。
3. 基本信息下方是三个手风琴面板：**参加者类型**、**选项**和**折扣码**。

## 参加者类型

参加者类型让你可以对不同类型的参加者收取不同的价格——并分别设置各自的名额上限。

1. 展开**参加者类型**面板并点击**添加类型**。
2. 输入**名称**（例如"成人"、"儿童"、"学生"）。
3. 设置**价格**。使用 0 表示免费类型。
4. （可选）仅为此类型设置**容量**（例如仅 20 个儿童名额）。留空则该类型无单独限制。
5. 点击**保存**。

报名时，每位参加者选择一个类型；已售罄的类型会显示为**已售罄**且无法选择。名单会显示每位参加者的类型以及各类型的实时统计。

## 选项

选项是可选的收费附加项——T 恤、餐饮计划、活动升级等。

1. 展开**选项**面板并点击**添加选项**。
2. 输入**名称**、可选的**描述**和**价格**（0 显示为"免费"）。
3. （可选）设置**容量**（所有报名的总可用数量）和**最大数量**（单次报名最多可订购的数量）。
4. 点击**保存**。

报名者在注册时选择数量，总数会计入容量，因此你不会超卖。

## 折扣码

1. 展开**折扣码**面板并点击**添加折扣码**。
2. 输入报名者将输入的**代码**。
3. 选择**类型**——**百分比**或**金额**——以及其**数值**。
4. （可选）通过**开始日期**/**结束日期**、**最少成员数**（该报名中最少参加者数量）和**最大使用次数**来限制该代码。
5. 点击**保存**。

每个代码都会显示**使用次数**统计，方便你查看其被兑换的频率。报名者应用代码时会立即收到反馈——包括代码已过期、尚未开始或需要更多参加者时的明确提示。

## 候补名单

在报名设置卡片中打开**启用候补名单**。当活动名额已满时：

- 新报名者会被提供候补名单名额，而不是被拒之门外。他们完成与正常报名相同的流程（候补状态下会跳过付款环节）。
- 有人取消时，候补名单中最早的一条记录会**自动晋升**，并收到一封通知名额已空出的邮件。如果仍有欠款，邮件会附带链接以完成付款。
- 你也可以随时对候补名单中的某一行使用**晋升**操作手动晋升——在提高活动容量后尤其有用。

:::info
被晋升的报名在余款结清前会保持*待处理*状态；结清余款（或无需支付）后即会被确认。
:::

## 报名名单

从报名页面打开某个活动可以查看所有报名。表格显示**姓名**、**成员**、**类型**（每位参加者的类型）、**已付/总计**（有欠款时显示余额提醒）、**状态**和**日期**，表格上方还有各类型的数量芯片。

- 点击某行的详情图标可打开**报名详情**对话框——包含成员、选项、已付/余额，以及列出每笔费用（金额、方式、日期）的**付款**表格。
- **导出 CSV** 会下载完整名单，列包括成员、参加者类型、选项、已付/总计/余额、状态，以及每个报名问题各一列。
- **添加参加者**仍可用于手动记录线下报名。

:::info
退款不在 B1 内处理。如果需要为已取消的付费报名退款，请在你的捐献服务提供商的控制台中（例如 Stripe）办理退款。
:::

## 付款如何运作

付款通过教会已用于捐献的同一个捐献网关处理——卡片信息直接发送给该提供商，绝不会经过 B1 的服务器。价格始终在服务器端根据你配置的类型、选项和折扣码计算，因此报名者无法篡改总额。已登录的成员可以使用已保存的卡片付款；访客则在结账时输入卡片信息。
