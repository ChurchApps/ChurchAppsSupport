# 付费报名

<div class="article-intro">

活动报名可以不只是简单的人数统计。您可以定义带价格的参与者类型（例如成人和儿童），提供带有各自价格和数量的可选附加项目，创建折扣码，并通过教会现有的奉献服务提供商在报名时收取付款。当活动报满时，可选的候补名单会让感兴趣的成员排队等候，并在有名额空出时自动递补。

</div>

<h4>开始之前</h4>

- 先在活动上启用报名——参见[创建日历](./creating-calendars.md#enabling-event-registration)
- 要在线收款，教会需要[配置在线奉献](../donations/online-giving-setup.md)（Stripe、PayPal 或 Kingdom Funding）。免费活动无需设置奉献。如果没有在线奉献，付费报名依然可用，但参与者需要直接向教会付款——参见[没有在线奉献的教会](#churches-without-online-giving)。

## 打开报名设置

1. 在 B1 Admin 中，打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），选择 **Calendars > Registrations**，然后打开您的活动（或从其所属日历中打开该活动）。
2. **Registration Settings** 卡片显示基本设置——**Enable Registration**（启用报名）、**Capacity**（名额）、**Registration Opens/Closes**（报名开始/截止）、**Tags**（标签）和 **Registration Questions**（报名问题）。
3. 基本设置下方有三个折叠面板：**Attendee Types**（参与者类型）、**Selections**（附加选项）和 **Discount Codes**（折扣码）。

## 参与者类型

参与者类型让您可以针对不同类别的参与者收取不同的费用，并分别设置各自的人数上限。

1. 展开 **Attendee Types** 面板，点击 **Add Type**。
2. 输入**名称**（例如“成人”“儿童”“学生”）。
3. 设置**价格**。免费类型请填 0。
4. 可选地为该类型单独设置**名额**（例如只开放 20 个儿童名额）。留空表示该类型不设人数限制。
5. 点击 **Save**。

报名时，每位参与者需选择一种类型；已售罄的类型会显示为 **Sold out**（已售罄），无法选择。报名列表会显示每位参与者的类型以及各类型的实时人数。

## 附加选项

附加选项是可选的收费项目，例如 T 恤、餐食套餐、活动升级等。

1. 展开 **Selections** 面板，点击 **Add Selection**。
2. 输入**名称**、可选的**描述**以及**价格**（填 0 时显示为“Free”，即免费）。
3. 可选地设置**名额**（所有报名共享的总数量）以及**最大数量**（单次报名最多可订购的数量）。
4. 点击 **Save**。

报名者在报名时选择数量，所选数量会计入名额，因此您不会超售。

## 折扣码

1. 展开 **Discount Codes** 面板，点击 **Add Discount Code**。
2. 输入报名者需要输入的**折扣码**。
3. 选择**类型**——**Percent**（百分比）或 **Amount**（固定金额）——并填写其**数值**。
4. 可选地为折扣码设置限制：**Start Date** / **End Date**（起止日期）、**Min Members**（最少人数，即报名中的最少参与人数）以及 **Max Uses**（最多使用次数）。
5. 点击 **Save**。

每个折扣码都会显示 **Uses**（使用次数），方便您了解其被兑换的频率。报名者在应用折扣码时会立即获得反馈，包括折扣码已过期、尚未生效或需要更多参与人数等明确提示。

## 候补名单 {#waitlist}

在 **Registration Settings** 卡片中打开 **Enable Waitlist**（开启候补名单）。当活动达到名额上限时：

- 新的报名者会被提供候补名额，而不是被拒绝。他们需完成同样的报名步骤（候补期间跳过付款）。
- 当有人取消报名时，最早的候补报名会**自动递补**，并收到一封邮件，告知有名额空出。如果他们有未付款项，邮件会链接到教会 B1 网站上的[我的报名](../../b1-church/events/my-registrations.md)，他们可以在那里完成付款。
- 您可以随时对候补中的报名点击 **Promote**（递补）手动递补某人——例如在提高活动名额之后很有用。

:::info
递补的报名在付清所有欠款之前会保持*待处理*状态；付款（或无需付款）后即会确认报名。
:::

## 报名名单 {#the-registration-roster}

从 Registrations 页面打开某个活动，即可查看所有报名。卡片标题会显示占用名额的报名数与名额上限（例如 *Registrations (18 / 20)*）。只有待处理和已确认的报名计入名额；存在候补时，标题会附加候补人数（例如 *· 3 waitlisted*），名额进度条下方也会显示相同的候补人数。名额进度条上方较大的数字统计的是**人数**而非报名数——即每个待处理或已确认报名中的全部人员，因此一个四口之家计为四人。但名额上限本身仍按报名数计算。表格显示 **Name**（姓名）、**Members**（成员）、**Type**（类型，即每位参与者的类型）、**Paid / Total**（已付 / 总额，如仍有欠款会显示余额警告）、**Status**（状态）和 **Date**（日期），表格上方还有各类型的人数标签。

- 点击某行的详情图标，可打开 **Registration Details**（报名详情）对话框——包括成员、附加选项、已付/余额，以及列出每笔收费（金额、方式、日期）的 **Payments**（付款）表格。
- **Export CSV** 会下载完整的报名名单，其中包括成员、参与者类型、附加选项、已付/总额/余额、状态，以及每个报名问题一列。
- **Add Attendee**（添加参与者）为教会内任何人记录线下或电话报名。选择该人员，在付费活动中还需选择其参与者类型。系统不会向其收费：付费报名会以**待处理**状态保存，并将全部金额记为待付余额。如果教会已开通在线奉献，该人员可以在[我的报名](../../b1-church/events/my-registrations.md)中付款；否则请当面收取。您需要拥有报名的编辑权限才能添加参与者。

:::info
B1 内无法处理退款。如需为已取消的付费报名退款，请在奉献服务提供商的后台（例如 Stripe）中办理退款。
:::

## 付款方式

付款通过教会已在使用的捐款支付网关完成——银行卡信息直接发送给服务提供商，从不经过 B1 的服务器。价格始终由服务器根据您配置的类型、附加选项和折扣码计算，因此报名者无法篡改总价。已登录的成员可以使用已保存的银行卡付款。访客则需在结账时输入银行卡信息，并在付款前勾选 **I'm not a robot**（我不是机器人）验证。

### 没有在线奉献的教会 {#churches-without-online-giving}

如果教会没有设置奉献服务提供商，付费活动仍然可以接受报名。付款步骤会告知报名者当前无法在线付款，他们可以直接向教会付款，并且 **Register and Pay Later**（先报名后付款）按钮会保存该报名。该报名会以**待处理**状态保存，并将全部金额记为待付余额，同时在报名列表中以余额警告的形式显示。请按教会平常的方式收取款项。

:::info
B1 无法将线下付款标记为已收到。收取款项后，待付余额仍会保留在报名列表和报名者的[我的报名](../../b1-church/events/my-registrations.md)卡片上，因此请自行记录谁已付款。
:::
