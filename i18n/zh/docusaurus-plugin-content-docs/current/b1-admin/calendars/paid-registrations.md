# 付费注册

<div class="article-intro">

事件注册可以超越简单的人数统计。您可以定义带价格的参加者类型（如成人和儿童）、提供带自己价格和数量的可选附加项、创建折扣代码，并通过您的教会现有捐赠提供商在注册时收取付款。当事件满员时，可选的候补名单会让感兴趣的成员排队，并在空位打开时自动晋升他们。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 首先在事件上启用注册 — 参见[创建日历](creating-calendars#enabling-event-registration)
- 要收取付款，您的教会需要[配置在线捐赠](../donations/online-giving-setup.md)（Stripe、PayPal 或 Kingdom Funding）。免费事件不需要捐赠设置。

</div>

## 打开注册设置

1. 在 B1Admin 中，转到**注册**页面并打开您的事件（或从其日历打开事件）。
2. **注册设置**卡片显示基础 — **启用注册**、**容量**、**注册打开/关闭**、**标签**和**注册问题**。
3. 在基础下方是三个手风琴：**参加者类型**、**选择**和**折扣代码**。

## 参加者类型

参加者类型让您为不同类型的参加者收取不同的价格 — 并分别限制每个类型。

1. 展开**参加者类型**手风琴并单击**添加类型**。
2. 输入**名称**（例如"成人"、"儿童"、"学生"）。
3. 设置**价格**。对于免费类型使用 0。
4. 可选地为仅此类型设置**容量**（例如只有 20 个儿童位置）。留空表示无每种类型限制。
5. 点击**保存**。

在注册期间，每个参加者选择一个类型；售罄的类型显示为**已售罄**且无法选择。名单显示每个参加者的类型和运行的每种类型计数。

## 选择

选择是可选的带价格的附加项 — T 恤、膳食计划、活动升级。

1. 展开**选择**手风琴并单击**添加选择**。
2. 输入**名称**、可选**描述**和**价格**（0 显示为"免费"）。
3. 可选地设置**容量**（跨所有注册的总可用）和**最大数量**（一个注册可以订购的最多）。
4. 点击**保存**。

注册人在注册期间选择数量，总数计入容量，这样您永远不会超额销售。

## 折扣代码

1. 展开**折扣代码**手风琴并单击**添加折扣代码**。
2. 输入注册人将输入的**代码**。
3. 选择**类型** — **百分比**或**金额** — 及其**值**。
4. 可选地使用**开始日期**/**结束日期**、**最少成员数**（注册上的最少参加者数）和**最大使用次数**限制代码。
5. 点击**保存**。

每个代码显示一个**使用**计数，以便您可以看到它被兑换的频率。注册人在应用代码时获得即时反馈 — 包括当代码已过期、尚未开始或需要更多参加者时的清晰消息。

## 候补名单

在注册设置卡片中打开**启用候补名单**。当事件达到容量时：

- 新注册人被提供候补名单位置，而不是被拒绝。他们完成相同的注册（候补名单时支付被跳过）。
- 当某人取消时，最老的候补名单注册会**自动晋升**并收到一封电子邮件，表示一个位置打开了。如果他们欠余额，电子邮件会链接他们以完成付款。
- 您可以随时使用候补名单行上的**晋升**操作手动晋升某人 — 在提高事件容量后很有用。

:::info
晋升的注册在支付任何余额之前保持*待处理*；支付（或没有支付）确认他们。
:::

## 注册名单

从注册页面打开一个事件以查看每个注册。表格显示**姓名**、**成员**、**类型**（每个参加者的类型）、**已付款/总计**（当仍欠款时有余额警告）、**状态**和**日期**，加上表格上方的每种类型计数芯片。

- 单击行的详情图标以打开**注册详情**对话框 — 成员、选择、已付款/余额和**付款**表格，列出每笔费用（金额、方法、日期）。
- **导出 CSV** 下载完整名单，其中包含成员、参加者类型、选择、已付款/总计/余额、状态和每个注册问题一列。
- **添加参加者**仍然让您手动记录离线注册。

:::info
退款不在 B1 中处理。如果您需要退款已取消的付费注册，请从您的捐赠提供商的仪表板（例如 Stripe）发出退款。
:::

## 付款如何工作

付款通过您的教会已经用于捐赠的相同捐赠网关运行 — 卡片详情直接去提供商，永远不会接触 B1 的服务器。价格始终从您配置的类型、选择和折扣代码从服务器计算，因此注册人无法篡改总计。已登录的成员可以用保存的卡片支付；访客在结账时输入卡片。
