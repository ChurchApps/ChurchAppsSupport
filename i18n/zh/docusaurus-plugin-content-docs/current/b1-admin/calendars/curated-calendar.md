# 策划日历

<div class="article-intro">

策划日历将来自多个小组的事件聚合到一个统一的日历视图中。这非常适合创建显示教会范围内所有事件的教会级日历，在一个地方显示您所有事工和小组中发生的一切。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置您想要包含的[小组](../groups/creating-groups.md)
- 确保小组领导者已向其各自的小组添加事件
- 熟悉[创建日历](creating-calendars)的基础知识

</div>

## 创建策划日历

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**日历**，然后点击**日历**。
2. 点击**添加日历**以创建新的策划日历。
3. 给您的日历命名**名称**（例如"教会事件"或"本周在我们教会"）。
4. 点击**创建**来保存它。

## 将小组添加到您的日历

1. 单击您的新日历以打开它。
2. 在右侧的**日历中的小组**部分中，点击**添加**。
3. 从下拉菜单中选择一个小组。
4. 选择是添加该小组的**所有事件**还是仅**特定事件**。
5. 点击**保存**。
6. 重复此过程以添加您想要包含的尽可能多的小组。

:::tip
添加您所有活跃的事工小组以创建综合日历，为您的教众提供教会每周发生的事情的完整图景。
:::

## 分享您的日历

一旦您的策划日历设置完成，您可以通过以下几种方式分享它：

- **在网站上嵌入** -- 日历可以直接显示在您的B1.church网站页面上供访问者浏览。
- **通过ICS订阅** -- 点击**订阅**来复制ICS链接。您的教众可以将此链接粘贴到Google Calendar、Apple Calendar、Outlook或任何其他日历应用中以保持同步。
- **下载ICS文件** -- 下载日历文件以将其导入到日历应用程序中。

:::info
当小组领导者向他们的[小组](../groups/creating-groups.md)添加新事件时，这些事件会自动出现在您的策划日历中。每次添加新事件时，您都无需手动更新策划日历。
:::

:::note 私人活动
只有**公开**活动才会显示在您网站上的策划日历及其 ICS 订阅中。在 B1 Admin 中，可以编辑内容的工作人员还会在策划日历上看到小组的**私人**活动，这样您在整理日历时就可以查看完整的日程安排。
:::
