# 精选日历

<div class="article-intro">

精选日历将多个小组的活动汇集到一个统一的日历视图中。这非常适合创建一个全教会的日历，在一处展示所有事工和小组的全部活动。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置好你希望纳入的[小组](../groups/creating-groups.md)
- 确保小组负责人已将活动添加到各自的小组中
- 请先熟悉[创建日历](./creating-calendars.md)的基本操作

</div>

## 创建精选日历 {#creating-a-curated-calendar}

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **Calendars**，然后点击 **Calendars**。
2. 点击 **Add Calendar**，创建一个新的精选日历。
3. 为日历设置 **Calendar Name**（例如"教会活动"或"本周教会动态"）。
4. 点击 **Create** 保存。

## 向日历添加小组 {#adding-groups-to-your-calendar}

1. 点击新日历的名称（或点击其所在行上的 **Manage Events**）将其打开。
2. 点击日历上方的 **Add Group**。你添加的小组会出现在页面左侧的 **Groups in Calendar** 列表中。
3. 在 **Select a Group** 中选择一个小组。教会中的每个小组都会列出，包括你并非其成员的小组。
4. 选择 **Add all the events of the group**（添加该小组的所有活动），或选择 **Add specific events**，然后点击你想要的活动。
5. 点击 **Save**。
6. 重复以上步骤，添加你希望纳入的任意数量的小组。

即使你单独添加了某个活动，又添加了其所属的整个小组，该活动也只会列出一次。**Groups in Calendar** 列表仅显示以其全部活动被添加的小组。

若要将某项内容从日历中移除，请点击该活动并选择 **Remove from Calendar**。活动仍保留在其小组中。如果该活动来自整个小组，移除它则会将该小组的所有活动都从本日历中移除。

:::tip
添加你所有活跃的事工小组，即可创建一个全面的日历，让会众每周都能完整了解教会正在进行的活动。
:::

## 分享你的日历 {#sharing-your-calendar}

精选日历设置完成后，你可以通过以下几种方式进行分享：

- **嵌入你的网站**——在页面中添加一个 **Calendar** 组件，以月历网格或即将举行的活动卡片形式展示日历，并可选择仅显示带有某个标签的活动。每个活动都会链接到你网站上的专属页面。参见[使用日历组件](../website/page-editor.md#using-the-calendar-element)。
- **通过 ICS 订阅**——点击日历上方的 **Subscribe**，然后选择 **Copy ICS Link**。会众可以将此链接粘贴到 Google 日历、Apple 日历、Outlook 或其他任何日历应用中，保持同步。
- **下载 ICS 文件**——点击 **Subscribe**，然后选择 **Download ICS File**，即可将日历导入日历应用。
- **打印**——在日历页面上点击 **Print**，即可获得可打印的视图。

:::info
当小组负责人将新活动添加到其[小组](../groups/creating-groups.md)中时，这些活动会自动出现在你的精选日历中。每次添加新活动时，你无需手动更新精选日历。
:::

:::note 私密活动
只有**公开**活动才会显示在你网站上的精选日历及其 ICS 订阅中。在 B1 Admin 中，具有编辑内容权限的工作人员还可以在精选日历上看到小组的**私密**活动，以便在整理日历时查看完整的安排。
:::
