# 精选日历

<div class="article-intro">

精选日历会将多个小组的活动汇集到一个统一的日历视图中。这非常适合创建全教会的日历，在一个地方显示您所有事工和小组的全部活动。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置您希望纳入的[小组](../groups/creating-groups.md)
- 确保小组负责人已在各自的小组中添加活动
- 熟悉[创建日历](creating-calendars)的基本操作

</div>

## 创建精选日历

1. 在 B1 Admin 中，打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**日历**，然后点击**日历**。
2. 点击**添加日历**，创建一个新的精选日历。
3. 为您的日历输入**名称**（例如“教会活动”或“本周我们的教会”）。
4. 点击**创建**进行保存。

## 将小组添加到日历

1. 在您的新日历上点击**管理活动**，打开该日历。
2. 点击日历上方的**添加小组**。您添加的小组会出现在页面左侧的**日历中的小组**列表中。
3. 从下拉菜单中选择一个小组。
4. 选择要添加该小组的**全部活动**，还是仅添加**特定活动**。
5. 点击**保存**。
6. 重复此过程，添加您想要包含的任意数量的小组。

:::tip
将所有活跃的事工小组都添加进来，即可创建一个全面的日历，让您的会众每周都能完整了解教会正在发生的一切。
:::

## 分享您的日历

设置好精选日历后，您可以通过多种方式分享：

- **嵌入您的网站** —— 在页面中添加**日历**元素，以月历网格或即将举行活动的卡片形式显示日历，也可以限制为仅显示带有某个标签的活动。每个活动都会链接到您网站上的专属页面。参见[使用日历元素](../website/page-editor.md#using-the-calendar-element)。
- **通过 ICS 订阅** —— 点击**订阅**即可复制 ICS 链接。您的会众可以将此链接粘贴到 Google 日历、Apple 日历、Outlook 或其他任何日历应用中，以保持同步。
- **下载 ICS 文件** —— 下载日历文件，并将其导入到日历应用中。

:::info
当小组负责人将新活动添加到其[小组](../groups/creating-groups.md)中时，这些活动会自动出现在您的精选日历中。您无需每次有新活动时都手动更新精选日历。
:::

:::note 私人活动
只有**公开**活动才会出现在您网站上的精选日历及其 ICS 订阅中。在 B1 Admin 中，有权编辑内容的员工还可以在精选日历上看到小组的**私人**活动，以便您在整理日历时检查完整的日程安排。
:::
