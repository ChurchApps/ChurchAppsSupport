# 精选日历

<div class="article-intro">

精选日历会将多个小组的活动汇集到一个统一的日历视图中。这非常适合创建全教会的日历，在一处展示你所有事工和小组的全部活动。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 设置好你希望纳入的[小组](../groups/creating-groups.md)
- 确保小组负责人已将活动添加到各自的小组中
- 熟悉[创建日历](creating-calendars)的基本操作

</div>

## 创建精选日历

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **Calendars**，然后点击 **Calendars**。
2. 点击 **Add Calendar**，创建一个新的精选日历。
3. 为你的日历设置**名称**（例如“教会活动”或“本周我们的教会”）。
4. 点击 **Create** 保存。

## 向日历中添加小组

1. 点击新日历上的 **Manage Events**，打开该日历。
2. 点击日历上方的 **Add Group**。你添加的小组会出现在页面左侧的 **Groups in Calendar** 列表中。
3. 从下拉菜单中选择一个小组。教会中的每个小组都会列出，包括你不是其成员的小组。
4. 选择是添加该小组的**所有活动**，还是仅添加**特定活动**。
5. 点击 **Save**。
6. 重复此过程，添加你想纳入的所有小组。

每个活动只会列出一次，即使你既单独添加了某个活动，又添加了它所属的整个小组。**Groups in Calendar** 列表仅显示以全部活动方式添加的小组。

要将某项内容从日历中移除，请点击该活动并选择 **Remove from Calendar**。活动仍保留在其小组中。如果活动是来自整个小组的，移除时会将该小组的所有活动从此日历中移除。

:::tip
添加你所有活跃的事工小组，即可打造一个全面的日历，让会众每周都能全面了解教会正在发生的事情。
:::

## 分享你的日历

精选日历设置完成后，你可以通过多种方式分享：

- **嵌入到你的网站** —— 在页面中添加**日历（Calendar）**元素，以月历网格或即将举行活动的磁贴形式展示日历，并可选择仅显示带有某个标签的活动。每个活动都会链接到你网站上的专属页面。参见[使用日历元素](../website/page-editor.md#using-the-calendar-element)。
- **通过 ICS 订阅** —— 点击 **Subscribe** 复制 ICS 链接。你的会众可以将此链接粘贴到 Google 日历、Apple 日历、Outlook 或任何其他日历应用中，以保持同步。
- **下载 ICS 文件** —— 下载日历文件，并将其导入到日历应用中。

:::info
当小组负责人将新活动添加到其[小组](../groups/creating-groups.md)中时，这些活动会自动出现在你的精选日历中。每次新增活动时，你无需手动更新精选日历。
:::

:::note 私密活动
只有**公开（public）**活动会出现在你网站上的精选日历及其 ICS 订阅中。在 B1 Admin 中，有权编辑内容的员工还能在精选日历上看到小组的**私密（private）**活动，以便在整理日历时检查完整的日程安排。
:::
