# 日历

<div class="article-intro">

B1 Admin 中的日历板块让你通过汇集各小组的活动，为教会创建精选日历。小组负责人管理各自小组的活动，而作为管理员，你可以构建日历，将这些活动显示在 B1.church 网站上，供会众查看。

</div>

## 查看你的日历 {#viewing-your-calendars}

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **Calendars**，然后点击 **Calendars**。
2. 日历页面会以表格形式列出你所有的日历，包括名称和状态。使用 **Find a calendar** 框可筛选列表。如果有待处理的预订或活动申请，页面顶部的 **pending approvals** 链接会打开[审批](./approvals.md)页面。
3. 将鼠标悬停在某一行上，会显示 **Manage Events** 链接（用于打开日历）和 **Edit** 链接（用于重命名或删除日历）。

日历板块及其中的每个页面都需要 **Edit Content** 权限。**Calendars** 菜单包含 **Calendars**、**Availability**、**Rooms & Resources**、**Approvals** 和 **Registrations**。

## 你可以做什么 {#what-you-can-do}

- **添加新日历**——点击页面顶部的 **Add Calendar**，为特定事工、活动类型或用途创建日历。分步说明请参见[创建日历](./creating-calendars.md)。
- **编辑日历**——在任意日历上点击 **Manage Events** 将其打开，并管理其中包含的小组。
- **发布日历**——日历可以显示在你的 B1.church 网站上，供访客查看教会即将举行的活动。
- **创建精选日历**——将多个小组的活动汇集到一个日历视图中，全面了解教会正在进行的所有活动。详情请参见[精选日历](./curated-calendar.md)。
- **管理房间和资源**——跟踪可预订的场地和设备，并处理审批申请。详情请参见[房间与资源](./rooms-resources.md)。
- **查看可用性**——在一个日历上查看所有房间和资源的预订情况，并为即将举行的活动预订场地。详情请参见[可用性日历](./availability.md)。
- **审批申请**——批准或拒绝房间、资源和活动申请。请参见[日历审批](./approvals.md)。
- **管理报名**——开启活动报名，查看报名人员。请参见[开启活动报名](./creating-calendars.md#enabling-event-registration)和[付费报名](./paid-registrations.md)。

:::info
日历与[小组](../groups/creating-groups.md)密切相关。当小组安排了活动时，这些活动可以被汇入你的日历。请参阅[创建日历](./creating-calendars.md)页面，了解如何将小组关联到日历。
:::
