# 日历

<div class="article-intro">

B1 Admin中的日历部分让您通过集合来自小组的事件来为教会创建策划日历。小组领导者管理他们自己小组的事件，作为管理员，您可以构建日历，将这些事件显示在您的B1.church网站上供教众查看。

</div>

## 查看您的日历

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**日历**，然后点击**日历**。
2. 日历页面列出您所有的日历及其名称和状态。
3. 每个日历还显示与之相关联的小组。

## 您可以做什么

- **添加新日历** -- 点击添加按钮来为特定事工、事件类型或目的创建日历。有关分步说明，请参见[创建日历](creating-calendars)。
- **编辑日历** -- 点击任何日历来打开它并管理其中包含的小组。
- **发布日历** -- 日历可以显示在您的B1.church网站上，以便访问者可以看到教会中即将发生的事件。
- **创建策划日历** -- 将来自多个小组的事件拉取到单个日历视图中，以全面了解教会中发生的一切。有关详细信息，请参见[策划日历](curated-calendar)。
- **管理房间和资源** -- 跟踪可预订的空间和设备，并处理批准请求。有关详细信息，请参见[房间和资源](rooms-resources)。
- **查看可用性** -- 在单个日历上查看所有房间和资源预订，并为即将来临的事件预订空间。有关详细信息，请参见[可用性日历](availability)。

:::info
日历与[小组](../groups/creating-groups.md)密切配合。当小组有事件计划时，这些事件可以拉取到您的日历中。查看[创建日历](creating-calendars)页面以了解如何将小组连接到日历。
:::
