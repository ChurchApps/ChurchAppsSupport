# 可用性日历

<div class="article-intro">

可用性日历让您可以全面了解您的教会中所有房间和资源的预订。从这里您可以看到已安排的内容，在冲突发生之前发现它们，并直接为任何事件预订房间或资源。

</div>

<div class="prereqs">
<h4>在开始之前</h4>

- 在房间与资源部分中设置至少一个[房间或资源](rooms-resources)
- 您需要有权编辑 B1 Admin 中的日历部分

</div>

## 打开可用性日历

在 B1 Admin 中，打开[Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**日历**，然后单击**可用性**。

## 阅读日历

日历默认显示当前月份。您可以使用顶部的箭头向前和向后导航，或在月、周和日视图之间切换。

每个事件都按预订状态进行颜色编码：

| 颜色 | 含义 |
|-------|---------|
| 绿色 | 已批准 |
| 橙色 | 待批准 |
| 灰色 | 已阻止（不可用）|

将鼠标悬停在事件上会显示事件标题和附加到其的房间或资源。

## 按房间或资源过滤

使用页面左上角的**过滤**下拉菜单将日历缩小到单个房间或资源。选择**所有房间与资源**以返回完整视图。

## 预订房间或资源

1. 单击页面右上角的**预订**按钮。
2. 在打开的对话框中，填写事件详细信息：
   - **标题** — 事件的名称
   - **开始**和**结束**日期/时间
   - **可见性** — 公开或私密
   - **房间** — 选择一个或多个房间进行预订
   - **资源** — 选择一个或多个资源进行预订
3. 可选择设置**设置**和**拆卸**时间（以分钟为单位）。这些在两端都会填充预订，以便为设置和清理保留空间，即使事件开始/结束时间保持相同。
4. 要重复预订，请选中**重复**并配置重复出现：
   - **重复每** -- 设置间隔（例如，每 2 周）。
   - **频率** -- 每日、每周或每月。每周让您选择一周的特定日期；每月让您选择一个月的固定日期或相对模式，如"第二个星期二"。
   - **结束** -- 从不、特定日期或设定次数后。
5. 要指定自定义预订窗口（与事件开始/结束不同），切换**自定义预订窗口**并输入窗口开始和结束时间。当房间需要在事件的规定时间之外可访问时，请使用此功能。
6. 单击**保存**以提交预订。

:::info
如果房间或资源配置了**批准小组**，预订将显示为**待处理**，直到该小组的领导者批准。有关批准工作流程，请参阅[日历批准](approvals)。
:::

:::tip
日历将在您保存之前突出显示任何冲突。如果您看到冲突警告，请调整您的时间或选择不同的房间。
:::
