# 可用性日历

<div class="article-intro">

可用性日历为您提供教会所有房间和资源预订的鸟瞰视图。从这里您可以看到计划的内容、在冲突发生之前发现冲突，并直接为任何事件预订房间或资源。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在房间和资源部分至少设置一个[房间或资源](rooms-resources)
- 您需要在 B1Admin 中对日历部分拥有编辑访问权限

</div>

## 打开可用性日历

在 B1Admin 中，打开左上角的**部分菜单**并选择**日历**，然后选择**可用性**。

## 读取日历

日历默认显示当前月份。您可以用顶部的箭头向前和向后导航，或在月、周和日视图之间切换。

每个事件都按预订状态进行颜色编码：

| 颜色 | 含义 |
|-------|---------|
| 绿色 | 已批准 |
| 橙色 | 等待批准 |
| 灰色 | 被封闭（不可用） |

将鼠标悬停在事件上会显示事件标题和附加到它的房间或资源。

## 按房间或资源过滤

使用左上角的**过滤器**下拉菜单将日历缩小到单个房间或资源。选择**所有房间和资源**以返回到完整视图。

## 预订房间或资源

1. 单击页面右上角的**预订**按钮。
2. 在打开的对话框中，填入事件详情：
   - **标题** — 事件的名称
   - **开始**和**结束**日期/时间
   - **可见性** — 公开或私密
   - **房间** — 选择一个或多个房间以预留
   - **资源** — 选择一个或多个资源以预留
3. 可选择设置**设置**和**拆卸**时间（以分钟为单位）。这会在两端垫住预订，以便为设置和清理预留空间，尽管事件开始/结束时间保持不变。
4. 要重复预订，请检查**重复**并配置重复：
   - **重复频率** — 设置间隔（例如，每 2 周）。
   - **频率** — 每天、每周或每月。每周让您选择周中的特定日期；每月让您选择每月的固定日期或相对模式，如"第二个星期二"。
   - **结束** — 永不、在特定日期上或在一定次数后。
5. 要指定自定义预订窗口（与事件开始/结束不同），切换**自定义预订窗口**并输入窗口开始和结束时间。当房间需要在事件列出的时间之外可访问时，请使用此选项。
6. 点击**保存**提交预订。

:::info
如果房间或资源已配置**批准组**，预订将显示为**待处理**，直到该组的领导者批准。有关批准工作流，请参见[日历批准](approvals)。
:::

:::tip
日历会在您保存前突出显示任何冲突。如果您看到冲突警告，请调整时间或选择不同的房间。
:::
