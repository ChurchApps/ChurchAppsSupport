# 可用性日历

<div class="article-intro">

可用性日历让您一目了然地查看教会所有房间和资源的预订情况。在这里，您可以查看已安排的日程、提前发现冲突，并直接为任何活动预订房间或资源。

</div>

<div class="prereqs">
<h4>准备工作</h4>

- 在"房间与资源"部分设置至少一个[房间或资源](rooms-resources)
- 您需要拥有 B1 Admin 中"日历"部分的编辑权限

</div>

## 打开可用性日历

在 B1 Admin 中，前往**日历**，然后在侧边栏中选择**可用性**。

## 读取日历

日历默认显示当前月份。您可以使用顶部的箭头前后导航，或在月、周、日视图之间切换。

每个活动会根据预订状态进行颜色编码：

| 颜色 | 含义 |
|-------|---------|
| 绿色 | 已批准 |
| 橙色 | 待批准 |
| 灰色 | 已封锁（不可用） |

将鼠标悬停在活动上会显示活动标题及其关联的房间或资源。

## 按房间或资源筛选

使用左上角的**筛选**下拉菜单，将日历缩小到单个房间或资源。选择**所有房间与资源**可返回完整视图。

## 预订房间或资源

1. 点击页面右上角的**预订**按钮。
2. 在打开的对话框中填写活动详情：
   - **标题** — 活动的名称
   - **开始**和**结束**日期/时间
   - **可见性** — 公开或私密
   - **房间** — 选择一个或多个要预订的房间
   - **资源** — 选择一个或多个要预订的资源
3. 您可以选择设置**布置**和**撤场**时间（以分钟为单位）。这会在预订的两端增加缓冲时间，以便为布置和清理预留空间，同时活动的开始/结束时间保持不变。
4. 要重复预订，请勾选**重复**并配置重复规则：
   - **重复间隔** -- 设置间隔（例如，每 2 周一次）。
   - **频率** -- 每天、每周或每月。每周可让您选择一周中的特定日期；每月可让您选择固定的某天或相对模式，如"每月第二个星期二"。
   - **结束** -- 永不结束、在特定日期结束，或在发生一定次数后结束。
5. 要指定与活动开始/结束时间不同的自定义预订时段，请打开**自定义预订时段**开关并输入时段的开始和结束时间。当房间需要在活动列出的时间之外也可使用时，请使用此选项。
6. 点击**保存**提交预订。

:::info
如果房间或资源配置了**批准小组**，该预订在该小组的负责人批准之前将显示为**待批准**状态。有关批准流程，请参阅[日历批准](approvals)。
:::

:::tip
日历会在您保存之前高亮显示任何冲突。如果看到冲突警告，请调整时间或选择其他房间。
:::
