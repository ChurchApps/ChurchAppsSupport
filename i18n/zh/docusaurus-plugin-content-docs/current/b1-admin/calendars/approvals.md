# 日历批准

<div class="article-intro">

批准页面是管理员审查和处理待处理房间和资源预订请求，以及需要在发布前获得批准的日历事件的地方。

</div>

<div class="prereqs">
<h4>在开始之前</h4>

- 在[房间与资源](rooms-resources)中使用**批准小组**配置房间或资源
- 您需要**日历管理员**权限或**content.edit**权限

</div>

## 打开批准

在 B1 Admin 中，打开[Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**日历**，然后单击**批准**。待处理的预订请求和等待审查的事件列在此处。

## 预订请求

当小组创建事件并请求房间或资源时，请求出现在**房间与资源请求**面板中。每一行显示：

- 被请求的房间或资源
- 事件名称和日期/时间
- 请求小组

### 冲突指示器

如果两个请求对同一房间或资源重叠，会出现冲突警告图标。在批准任何一个之前，请仔细审查冲突请求。

### 批准或拒绝

单击任何预订请求上的**✓**（批准）或**✗**（拒绝）图标。请求小组会收到决定通知。批准的预订锁定到该事件的房间或资源；拒绝的预订释放该插槽供其他人使用。

单击批准时，会打开**批准预订**对话框，以便您也可以在同一步骤中发布事件：

1. 选中**发布到公共日历**以在其小组的日历上公开此事件。取消选中以批准预订而不更改事件的可见性。
2. 一旦**发布到公共日历**被选中，您可以从**也添加到日历**中选择一个精选日历，将事件也添加到您的[精选日历](curated-calendar)之一。将其设置为**无**以跳过此操作。（此选项仅在您拥有**content.edit**权限时显示。）
3. 单击**批准**。

## 待处理事件

如果您的日历工作流程需要在事件对公众可见之前获得事件批准，待处理的事件会出现在**事件请求**面板中。批准一个事件以将其发布到日历，或拒绝它以通知提交者需要进行更改。

:::tip
在[房间与资源](rooms-resources)中为房间设置批准小组，以要求该房间的批准。有权限的小组可以在创建事件时请求房间，这些请求会流入此页面。
:::
