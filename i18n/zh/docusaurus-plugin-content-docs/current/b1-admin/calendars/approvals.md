# 日历批准

<div class="article-intro">

批准页面是管理员审查并处理未决房间和资源预订请求，以及在发布前需要批准的日历事件的地方。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在[房间和资源](rooms-resources)中使用**批准组**配置房间或资源
- 您需要**日历管理**权限或**content.edit**权限

</div>

## 打开批准

在 B1Admin 中，转到**日历**并选择**批准**。未决预订请求和等待审查的事件列在这里。

## 预订请求

当小组创建事件并请求房间或资源时，请求出现在**预订请求**面板中。每行显示：

- 被请求的房间或资源
- 事件名称和日期/时间
- 请求的小组

### 冲突指示

如果两个请求重叠相同的房间或资源，会出现冲突警告图标。在批准任何一个之前，请仔细查看冲突的请求。

### 批准或拒绝

点击任何预订请求上的**✓**（批准）或**✗**（拒绝）图标。请求的小组会收到决定通知。批准的预订会锁定到该事件的房间或资源；拒绝的预订会释放该时段供其他人使用。

## 未决事件

如果您的日历工作流需要在事件对公众可见之前进行事件批准，未决事件会出现在**未决事件**面板中。批准事件以将其发布到日历，或拒绝事件以通知提交者需要更改。

:::tip
在[房间和资源](rooms-resources)中的房间上设置批准组，以要求对该房间进行批准。拥有访问权限的小组可以在创建事件时请求房间，这些请求会进入本页面。
:::
