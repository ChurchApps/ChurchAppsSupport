# 直播

<div class="article-intro">

直播时间页面让你配置你的教会的直播日程、管理服侍时间以及自定义观众体验。设置周期性的周间服侍或一次性事件，配置聊天和视频设置，以及控制你的流何时开始直播。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要 **contentApi.streamingServices.edit** 权限。如果你没有访问权限，见[角色和权限](../settings/roles-permissions.md)。
- 如果你计划使用自动直播，准备好你的 YouTube 频道 ID
- 添加至少一个[讲道](managing-sermons)或永久直播 URL 以用作你的流源

</div>

该页面有两个主要标签页：**服侍**用于管理你的直播日程，**设置**用于配置你的直播页面。

## 管理服侍

### 添加服侍

1. 在 B1 Admin 中，打开左上角的**部分菜单**（部分名称和小箭头）并选择**讲道**，然后点击**直播时间**标签页。
2. 点击**添加服侍**按钮以创建新的排定服侍。
3. 输入**服侍名称**（例如，"主日早间"）。
4. 设置**服侍时间** — 选择你的服侍开始的日期和时间。
5. 将**每周重复**设置为**是**用于常规周间服侍，或**否**用于一次性事件。

### 配置聊天和视频设置

6. 在**聊天设置**下，设置聊天应该在服侍前后多少分钟启用。这让访客在服侍开始前开始聊天，并在之后继续。
7. 在**视频设置**下，设置多早开始视频流以进行倒计时或服前内容。
8. 从下拉菜单中选择播放哪个讲道：
   - **最新讲道** — 自动播放你最近添加的视频。
   - **当前直播服侍** — 使用你的频道 ID 从 YouTube 播放你的当前直播流。
   - 你也可以选择你已经保存的任何特定讲道。
9. 点击**保存**以排定你的服侍。

:::info
如果设置为周期，你的服侍将每周自动更新。你可以添加尽可能多的服侍。访客在访问你的直播页面时将看到下一个排定的服侍时间。
:::

## 直播页面设置

点击**设置**标签页以自定义显示在你的直播旁边的标签页和链接。

### 添加标签页

1. 点击**添加**按钮向你的直播页面添加新标签页。
2. 选择预设计的**聊天**标签页或添加带有外部 URL 的自定义标签页。
3. 对于聊天标签页，只需在**标签页文本**框中给它一个名称，设置就完成了。
4. 对于链接标签页，输入标签页名称，通过点击图标按钮选择图标，并输入 URL。
5. 你配置的标签页将出现在直播页面上，供观众访问额外资源和交互功能。

### 预览你的流

点击**查看你的流**按钮以精确查看你的直播页面对访客的样子，包括你的徽标、服侍时间和配置的标签页。

## 设置你的 YouTube 直播流

要连接你的 YouTube 频道以进行自动直播：

1. 转到**讲道**并点击**添加讲道**，然后选择**添加永久直播 URL**。
2. 视频提供商默认为**当前 YouTube 直播流**。输入你的 **YouTube 频道 ID**。
3. 添加标题和描述，然后点击**保存**。
4. 在**直播时间**中，创建服侍并从讲道下拉菜单中选择你的永久直播 URL。

:::tip
要找到你的 YouTube 频道 ID，转到你的 YouTube 频道的高级设置并复制频道 ID 值。
:::

## 自定义颜色和徽标

你的直播页面使用你的网站的[外观](../website/appearance)设置：

- **浅色强调色**带深色文本用于标题。
- **深色强调色**带浅色文本用于侧栏。
- 你的**浅色背景徽标**出现在直播页面上。使用透明背景的图像和 4:1 的宽高比。

要更改这些，转到**网站**然后**外观**并更新你的[颜色调色板](../website/appearance#color-palette)和[徽标](../website/appearance#logo-and-branding)设置。

## 添加直播主持人

要给团队成员访问权限与公共聊天一起的仅主持人聊天：

1. 打开左上角的**部分菜单**（部分名称和小箭头），选择**设置**，并点击**角色**。
2. 点击加号按钮并选择**添加自定义角色**。
3. 将角色命名为"流主持人"并点击**保存**。
4. 点击新角色，然后在成员部分中点击**添加**以添加人。
5. 向下滚动到**编辑权限**，展开**内容**部分，并勾选**主持人聊天**。

当主持人登录直播页面时，除了公共聊天外，还会出现一个私有**主持人聊天**标签页，供工作人员在广播期间进行工作人员专用对话。

:::info
有关创建角色和管理权限的更多详情，见[角色和权限](../settings/roles-permissions.md)。
:::

## 故障排除

如果使用"当前 YouTube 直播流"选项和你的频道 ID 时，你的自动 YouTube 直播流显示不正确，尝试以下操作：

**症状：**
- 直播嵌入显示"视频不可用"
- 页面加载但没有视频出现
- 直接 YouTube 嵌入有效，但自动频道直播流无效

**解决方案：**
检查你的 YouTube 频道中的旧的或即将到来的排定的直播并删除它们：

1. 转到你的 YouTube Studio。
2. 导航到**内容**然后**直播**。
3. 查找任何旧排定的直播或即将到来的排定的流。
4. 删除这些旧的或排定的直播条目。
5. 再次测试你的直播页面。

:::warning
当你的频道中有多个排定或过去的直播条目时，YouTube 的自动频道直播嵌入可能被阻止。删除这些允许 YouTube 正确识别和提供你的当前直播流。
:::

**额外要求：**
- 你的直播流必须设置为**公开**（不是不可见或私有）。
- 你的 YouTube 流设置中必须允许嵌入。
- 确保你使用的是**当前 YouTube 直播流**提供商（带频道 ID），而不是 **YouTube** 提供商（带视频 ID）。
