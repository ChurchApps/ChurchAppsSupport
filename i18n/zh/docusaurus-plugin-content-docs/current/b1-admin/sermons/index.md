# 讲道

<div class="article-intro">

B1 Admin 中的讲道版块让你管理教会的讲道库和直播。你可以添加单独的讲道、将其整理到播放列表中、配置直播时间表，并从 YouTube 或 Vimeo 批量导入现有内容。

</div>

:::info
要访问讲道版块，你需要在角色的 **Content**（内容）部分拥有 **Edit Services**（编辑礼拜）权限。没有此权限时，菜单中将不显示讲道，其页面也会显示权限提示。如果你在菜单中看不到讲道，请联系教会管理员为你分配适当的角色。有关管理权限的详情，请参阅[角色与权限](../settings/roles-permissions.md)。
:::

## 你可以做什么 {#what-you-can-do}

在[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)中，**Sermons**（讲道）包含三个页面：**Sermons**（你的讲道库、播放列表和播客订阅源）、**Live Stream Times**（直播时间）和 **Settings**（设置）。批量导入可通过 **Add Sermon**（添加讲道）按钮进入。本版块涵盖以下功能：

### 讲道 {#sermons}

添加和管理讲道库中的单个讲道条目。每场讲道可包含标题、讲员、日期、描述、缩略图，以及视频或音频内容的链接。你可以将讲道链接到 YouTube、Vimeo、Facebook 或自定义视频网址。完整详情请参阅[管理讲道](./managing-sermons.md)。

### 播放列表 {#playlists}

将讲道整理为系列或合集。播放列表便于会众按顺序浏览某个讲道系列。每个播放列表都有自己的名称、描述和缩略图。更多信息请参阅[播放列表](./playlists.md)。

### 直播时间 {#live-stream-times}

配置教会的直播时间表。设置每周重复的礼拜或一次性活动，管理聊天和视频设置，并控制直播的开始时间。访客将在你的直播页面上看到下一场预定礼拜的时间。设置说明请参阅[直播](./live-streaming.md)。

### 直播设置 {#stream-settings}

**Sermons** 下的 **Settings** 页面（标题为 **Stream Settings**（直播设置））用于控制直播旁边显示的 **Content Tabs**（内容标签页）-- 即聊天、祷告和自定义链接。请参阅[直播页面设置](./live-streaming.md#streaming-page-settings)。

### 批量导入 {#bulk-import}

通过从 YouTube 或 Vimeo 批量导入视频，快速填充你的讲道库。这是将现有讲道内容迁移到 B1 最快的方式。请参阅[批量导入](./bulk-import.md)开始使用。

:::tip
如果你是首次设置讲道，请先创建一个[播放列表](./playlists.md)，然后[逐个添加讲道](./managing-sermons.md)，或从 YouTube 或 Vimeo [批量导入](./bulk-import.md)。
:::
