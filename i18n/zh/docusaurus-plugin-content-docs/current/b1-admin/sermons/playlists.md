# 播放列表

<div class="article-intro">

播放列表让你将讲道整理为系列或合集。当访客在你的 B1.church 网站上浏览讲道库时，播放列表可帮助他们找到并按正确顺序跟随完整的讲道系列。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要在角色的 **Content**（内容）部分拥有 **Edit Services**（编辑礼拜）权限。如果你没有访问权限，请参阅[角色与权限](../settings/roles-permissions.md)。
- 准备好播放列表的名称、描述和缩略图

</div>

## 查看播放列表 {#viewing-playlists}

1. 在 B1 Admin 中，打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开 **Sermons**（讲道），然后点击 **Sermons**。
2. 在 **Sermons** 页面上找到 **Playlists**（播放列表）面板（位于讲道列表旁边）。
3. 你会看到所有现有播放列表的名称列表，**Playlists** 标题旁显示数量。当播放列表超过五个时，列表上方会出现 **Search playlists...**（搜索播放列表...）输入框。

## 创建播放列表 {#creating-a-playlist}

1. 如果你还没有任何播放列表，请点击 **Create First Playlist**（创建第一个播放列表）按钮；否则，请点击 **Playlists** 面板中的 **Add playlist**（添加播放列表）按钮。面板上方会打开 **Create New Playlist**（创建新播放列表）表单。
2. 输入 **Playlist Title**（播放列表标题）-- 例如讲道系列的名称，如 "Faith Foundations"（信仰根基）或 "Summer in the Psalms"（夏季诗篇）。
3. 添加 **Description**（描述），向访客简要介绍该系列。
4. 设置 **Publish Date**（发布日期），以控制播放列表何时对访客可见。
5. 点击 **Add Thumbnail**（添加缩略图），上传并裁剪 **Thumbnail Image**（缩略图），以直观地代表该系列（建议尺寸为 1280x720 像素，即 16:9）。
6. 点击 **Save**（保存）以创建播放列表。

## 编辑或删除播放列表 {#editing-or-deleting-a-playlist}

将鼠标悬停在 **Playlists** 面板中的某个播放列表上，然后点击 **Edit**（编辑）。修改任意字段（如需更换图片，请使用 **Change Thumbnail**（更换缩略图）），然后点击 **Save**；或者点击 **Delete**（删除）并确认，以删除该播放列表。

:::tip
请先创建播放列表，再添加讲道。这样你在添加讲道时就可以直接将其分配到正确的播放列表，而无需事后重新整理。
:::

## 将讲道添加到播放列表 {#adding-sermons-to-a-playlist}

当你[添加或编辑讲道](./managing-sermons.md)时，可使用 **Playlist**（播放列表）下拉菜单将其分配到播放列表。分配到同一播放列表的所有讲道会归为一组，并按顺序显示在你的网站上。

:::info
你也可以在[批量导入](./bulk-import.md)过程中将讲道分配到播放列表。从 YouTube 或 Vimeo 导入时，请在点击 **Import** 之前，从 **Import Into Playlist**（导入到播放列表）下拉菜单中选择播放列表。
:::

## 播放列表在网站上的显示方式 {#how-playlists-appear-on-your-website}

播放列表会以可浏览合集的形式显示在你的 B1.church 网站上。访客可以：

- 一览所有可用的讲道系列
- 点击进入某个播放列表，查看该系列中的所有讲道
- 按顺序观看或收听讲道
