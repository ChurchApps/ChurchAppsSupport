# 播放列表

<div class="article-intro">

播放列表让你将你的讲道组织成系列或集合。当访客在你的 B1.church 网站上浏览你的讲道库时，播放列表帮助他们找到并跟随完整的讲道系列的正确顺序。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要 **contentApi.streamingServices.edit** 权限。如果你没有访问权限，见[角色和权限](../settings/roles-permissions.md)。
- 准备好你的播放列表的名称、描述和缩略图图像

</div>

## 查看播放列表

1. 在 B1 Admin 中，打开左上角的**部分菜单**（部分名称和小箭头）并选择**讲道**。
2. 点击页面顶部的**播放列表**标签页。
3. 你会看到所有现有播放列表的列表，包括其名称和描述。

## 创建播放列表

1. 点击**创建首个播放列表**按钮（如果你没有播放列表）或点击**添加播放列表**。
2. 为播放列表输入**名称** — 例如，讲道系列标题，如"信仰基础"或"诗篇之夏"。
3. 添加**描述**以给访客系列的简要概述。
4. 设置**发布日期**以控制播放列表何时变为可见。
5. 上传**缩略图图像**以直观地代表系列。
6. 点击**保存**以创建你的播放列表。

:::tip
在添加讲道前首先创建你的播放列表。这样你可以在你进行时将每个讲道分配给正确的播放列表，而不是之后重新组织。
:::

## 向播放列表添加讲道

当你[添加或编辑讲道](managing-sermons)时，你使用**播放列表**下拉菜单将其分配给播放列表。分配给相同播放列表的所有讲道被分组在一起并按顺序显示在你的网站上。

:::info
你也可以在[批量导入](bulk-import)期间将讲道分配给播放列表。从 YouTube 或 Vimeo 导入时，在点击**导入**前从**导入到播放列表**下拉菜单中选择播放列表。
:::

## 播放列表如何在你的网站上显示

播放列表在你的 B1.church 网站上显示为可浏览的集合。访客可以：

- 一目了然地查看所有可用的讲道系列
- 点击播放列表以查看该系列中的所有讲道
- 按顺序观看或收听讲道

- [批量导入](bulk-import) — 导入多个讲道并将其分配给播放列表
