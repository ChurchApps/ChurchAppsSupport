# 播放列表

<div class="article-intro">

播放列表让您将讲道组织成系列或集合。当访问者在您的B1.church网站上浏览讲道库时，播放列表可帮助他们以正确的顺序查找并跟随完整的讲道系列。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要**contentApi.streamingServices.edit**权限。如果您没有访问权限，请参阅[角色和权限](../settings/roles-permissions.md)。
- 为播放列表准备好名称、描述和缩略图

</div>

## 查看播放列表

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**讲道**，然后点击**讲道**。
2. 在**讲道**页面上找到**播放列表**面板（与讲道列表一起）。
3. 您将看到所有现有播放列表及其名称和描述的列表。

## 创建播放列表

1. 点击**创建第一个播放列表**按钮（如果您还没有播放列表）或点击**播放列表**面板标头中的**添加**（+）按钮。
2. 输入播放列表的**名称** -- 例如，讲道系列的标题，如"信仰基础"或"诗篇夏季"。
3. 添加**描述**为访问者提供系列的简要概述。
4. 设置**发布日期**来控制播放列表何时可见。
5. 上传**缩略图**来直观地代表该系列。
6. 点击**保存**来创建您的播放列表。

:::tip
在添加讲道之前先创建播放列表。这样，当您添加每个讲道时，可以将其分配到正确的播放列表，而不是稍后重新组织。
:::

## 向播放列表添加讲道

当您[添加或编辑讲道](managing-sermons)时，您可以使用**播放列表**下拉菜单将其分配给播放列表。分配给同一播放列表的所有讲道都被分组在一起，并按顺序在您的网站上显示。

:::info
您也可以在[批量导入](bulk-import)期间将讲道分配到播放列表。从YouTube或Vimeo导入时，在点击**导入**之前从**导入到播放列表**下拉菜单中选择播放列表。
:::

## 播放列表如何在您的网站上显示

播放列表在您的B1.church网站上显示为可浏览的集合。访问者可以：

- 一目了然地看到所有可用的讲道系列
- 点击播放列表来查看该系列中的所有讲道
- 按顺序观看或收听讲道
