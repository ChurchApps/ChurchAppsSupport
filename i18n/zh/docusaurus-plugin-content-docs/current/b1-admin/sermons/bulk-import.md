# 批量导入

<div class="article-intro">

批量导入页面让你通过从 YouTube 或 Vimeo 导入视频来快速填充你的讲道库。这是导入你现有讲道内容的最快方式，而不是逐个添加每个视频。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要 **contentApi.streamingServices.edit** 权限。如果你没有访问权限，见[角色和权限](../settings/roles-permissions.md)。
- 创建至少一个[播放列表](playlists)来导入你的讲道
- 准备好你的 YouTube 频道 ID 或 Vimeo 帐户信息

</div>

## 选择你的源

1. 在 B1 Admin 中，打开左上角的**部分菜单**（部分名称和小箭头）并选择**讲道**，然后点击**批量导入**标签页。
2. 你会看到两个可点击的卡片：
   - **YouTube**（红色）— 从 YouTube 频道导入视频
   - **Vimeo**（蓝色）— 从 Vimeo 帐户导入视频
3. 点击你的讲道所在平台的卡片。

:::tip
如果你在两个平台上都有视频，你可以随时回去切换源。
:::

## 导入前

在导入视频前，你至少需要一个播放列表来组织它们。如果你还没有创建任何播放列表：

1. 点击**播放列表**标签页。
2. 点击**创建首个播放列表**并填写名称、描述、发布日期和缩略图。
3. 点击**保存**，然后返回**批量导入**标签页。

见[播放列表](playlists)以获取创建和管理播放列表的详细说明。

## 导入视频

1. 选择 YouTube 或 Vimeo 后，在提供的字段中输入你的 **YouTube 频道 ID** 或 **Vimeo 帐户信息**。
2. 点击**获取**按钮以从你的频道或帐户检索所有可用视频。
3. 获取后，你会看到所有视频的列表和复选框。
4. 选中你想导入的视频旁边的复选框。你可以选择全部或选择特定的。
5. 可选地，启用**自动导入新视频**以自动将未来上传添加到你的库。
6. 点击**导入到播放列表**下拉菜单选择这些视频应该添加到哪个播放列表。
7. 点击**导入**按钮以完成批量导入。

你的视频将被导入，包括所有其详情，包括标题、描述、日期和缩略图。

:::info
批量导入适合在你从另一个平台迁移时开始。对于今后添加个人讲道，改用[管理讲道](managing-sermons)页面。
:::
