# 批量导入

<div class="article-intro">

批量导入页面允许你通过从YouTube或Vimeo导入视频来快速填充你的讲道库。这是引入现有讲道内容的最快方式，而不是一次添加一个视频。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你需要**contentApi.streamingServices.edit**权限。如果你没有访问权限，请查看[角色和权限](../settings/roles-permissions.md)。
- 至少创建一个[播放列表](playlists)来导入你的讲道
- 准备好你的YouTube频道ID或Vimeo账户信息

</div>

## 选择你的来源

1. 在B1 Admin中，打开左上角的**部分菜单**（部分名称带有小箭头）并选择**讲道**。点击**添加讲道**并从菜单中选择**批量导入**。
2. 你会看到两个可点击的卡片：
   - **YouTube**（红色）-- 从YouTube频道导入视频
   - **Vimeo**（蓝色）-- 从Vimeo账户导入视频
3. 点击你的讲道托管的平台的卡片。

:::tip
如果你在两个平台上都有视频，你随时可以返回并切换来源。
:::

## 导入之前

在导入视频之前，你需要至少一个播放列表来组织它们。如果你还没有创建任何播放列表：

1. 点击**播放列表**标签。
2. 点击**创建第一个播放列表**并填入名称、描述、发布日期和缩略图。
3. 点击**保存**，然后返回**批量导入**标签。

有关创建和管理播放列表的详细说明，请查看[播放列表](playlists)。

## 导入视频

1. 选择YouTube或Vimeo后，在提供的字段中输入你的**YouTube频道ID**或**Vimeo账户信息**。
2. 点击**获取**按钮以从你的频道或账户检索所有可用视频。
3. 获取后，你会看到所有视频的列表，带有复选框。
4. 检查你想导入的视频旁边的框。你可以选择全部或选择特定的。
5. 可选地，启用**自动导入新视频**以自动将未来上传的内容添加到你的库。
6. 点击**导入到播放列表**下拉菜单以选择这些视频应添加到哪个播放列表。
7. 点击**导入**按钮以完成批量导入。

你的视频将通过所有详细信息导入，包括标题、描述、日期和缩略图。

:::info
批量导入非常适合在你从另一个平台迁移时入门。要继续添加单个讲道，请改用[管理讲道](managing-sermons)页面。
:::
