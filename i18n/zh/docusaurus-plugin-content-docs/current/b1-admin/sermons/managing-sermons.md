# 管理讲道

<div class="article-intro">

讲道页面显示你的整个讲道库。从这里你可以添加新讲道、编辑现有条目并按播放列表组织你的内容。每个讲道可以链接到托管在 YouTube、Vimeo、Facebook 或自定义 URL 上的视频或音频。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 你需要 **contentApi.streamingServices.edit** 权限。如果你没有访问权限，见[角色和权限](../settings/roles-permissions.md)。
- 创建至少一个[播放列表](playlists)来组织你的讲道
- 从 YouTube、Vimeo 或 Facebook 准备好你的视频 ID 或 URL

</div>

## 查看你的讲道库

1. 在 B1 Admin 中，打开左上角的**部分菜单**（部分名称和小箭头）并选择**讲道**。
2. 讲道页面显示所有你的讲道条目，按播放列表组织。每个讲道显示其缩略图、标题和日期。
3. 点击任何讲道以查看或编辑其详情。

## 添加讲道

1. 点击右上角的**添加讲道**按钮并从下拉菜单中选择**添加讲道**。
2. 选择一个**播放列表**以将讲道分配给。
3. 选择你的**视频提供商** — YouTube、Vimeo、Facebook 或自定义 URL。我们推荐 YouTube，因为它与 B1 系统配合最好。
4. 输入视频 ID 或 URL 并点击**获取**。对于 YouTube，视频 ID 是 YouTube URL 中 `v=` 后的字符串。
5. 当你点击**获取**时，讲道详情被自动导入，包括发布日期、时长、标题、描述和缩略图。
6. 做你想要的任何更改并点击**保存**。

:::tip
你也可以通过从**添加讲道**下拉菜单中选择**添加永久直播 URL** 来添加永久直播流 URL。这使用你的频道 ID 创建与你的 YouTube 频道直播流的持久连接。见[直播](live-streaming)以获取更多详情。
:::

## 编辑讲道

1. 点击你的库中的任何讲道以打开其详情。
2. 根据需要更新标题、讲员、日期、描述、缩略图或媒体链接。
3. 点击**保存**以应用你的更改。

## 讲道详情

每个讲道条目可以包括：

- **标题** — 显示给访客的讲道名称
- **讲员** — 谁传讲讲道
- **日期** — 发布或传讲日期
- **描述** — 讲道内容摘要
- **缩略图** — 在你的讲道库中显示的预览图像
- **视频/音频链接** — 讲道媒体在 YouTube、Vimeo、Facebook 或自定义主机上的 URL

## 排定讲道以进行直播

添加讲道后，你可以在你的直播页面上将其排定以进行广播：

1. 转到**直播时间**标签页。
2. 编辑服侍并在**视频设置**下，从下拉菜单中选择你的讲道。
3. 讲道将在排定的服侍时间播放。

:::info
对于一次导入多个讲道而不是逐个添加，使用[批量导入](bulk-import)工具直接从你的 YouTube 或 Vimeo 帐户拉取视频。
:::
