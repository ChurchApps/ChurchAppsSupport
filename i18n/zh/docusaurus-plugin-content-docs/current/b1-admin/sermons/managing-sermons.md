# 管理讲道

<div class="article-intro">

讲道页面显示您的整个讲道库。从这里，您可以添加新讲道、编辑现有条目并按播放列表组织您的内容。每场讲道都可以链接到托管在YouTube、Vimeo、Facebook或自定义URL上的视频或音频。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要**contentApi.streamingServices.edit**权限。如果您没有访问权限，请参阅[角色和权限](../settings/roles-permissions.md)。
- 至少创建一个[播放列表](playlists)来组织您的讲道
- 从YouTube、Vimeo或Facebook准备好您的视频ID或URL

</div>

## 查看您的讲道库

1. 在B1 Admin中，打开[Jump菜单](../introduction.md#getting-around-with-the-jump-menu)（左上角的搜索栏），展开**讲道**，然后点击**讲道**。
2. 讲道页面显示所有讲道条目，按播放列表组织。每个讲道都显示其缩略图、标题和日期。
3. 点击任何讲道以查看或编辑其详细信息。

## 添加讲道

1. 点击右上角的**添加讲道**按钮，从下拉菜单中选择**添加讲道**。
2. 选择一个**播放列表**来分配讲道。
3. 选择您的**视频提供商** -- YouTube、Vimeo、Facebook或自定义URL。我们建议使用YouTube，因为它最适合B1系统。
4. 输入视频ID或URL，然后点击**获取**。对于YouTube，视频ID是YouTube URL中`v=`之后的字符串。
5. 点击**获取**后，讲道详细信息会自动导入，包括发布日期、时长、标题、描述和缩略图。
6. 进行任何您想要的更改，然后点击**保存**。

:::tip
您还可以通过从**添加讲道**下拉菜单中选择**添加永久直播URL**来添加永久直播URL。这会使用您的频道ID创建与您的YouTube频道直播流的持久连接。有关更多详细信息，请参阅[直播](live-streaming)。
:::

## 编辑讲道

1. 点击库中的任何讲道以打开其详细信息。
2. 根据需要更新标题、讲者、日期、描述、缩略图或媒体链接。
3. 点击**保存**以应用您的更改。

## 讲道详细信息

每个讲道条目可以包括：

- **标题** -- 向访问者显示的讲道名称
- **讲者** -- 谁传递了讲道
- **日期** -- 发布或传递日期
- **描述** -- 讲道内容的摘要
- **缩略图** -- 讲道库中显示的预览图像
- **视频/音频链接** -- YouTube、Vimeo、Facebook或自定义主机上讲道媒体的URL
- **音频文件URL（用于播客）** -- 这次讲道的MP3/M4A文件的直接链接。您可以粘贴URL或点击**上传音频**来上传文件并自动填充。只有设置了此字段（或直接视频文件链接）的讲道才会包含在您的播客源中。

## 您的播客源

一旦至少一个讲道附加了音频或视频文件，B1 Admin就会自动为您的教会生成播客RSS源 -- 无需打开任何内容。在讲道列表下方的**播客源**面板中找到它：点击复制图标复制源URL，然后将该URL提交给Apple Podcasts、Spotify或任何其他播客目录。

:::info
仅链接到嵌入式播放器（如YouTube或Vimeo视频ID）的讲道不会出现在播客源中 -- 播客应用需要可直接下载的媒体文件。添加**音频文件URL**来包含讲道。
:::

## 为直播安排讲道

添加讲道后，您可以在您的直播页面上安排其广播：

1. 在Jump菜单中，选择**讲道 > 直播时间**。
2. 编辑服务，在**视频设置**下，从下拉菜单中选择您的讲道。
3. 讲道将在计划的服务时间播放。

:::info
要一次导入多个讲道而不是逐个添加，请使用[批量导入](bulk-import)工具直接从您的YouTube或Vimeo账户拉取视频。
:::
