# 奉献汇总

<div class="article-intro">

奉献汇总报表让你清楚地了解教会的奉献活动情况。你可以用它追踪奉献总额、监测奉献趋势，并为领导团队准备财务报告。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 确保奉献记录在系统中[被持续录入](../donations/recording-donations.md)
- 你需要具备 **View Donation Summaries**（查看奉献汇总）[权限](../settings/roles-permissions.md)

</div>

## 运行报表 {#running-the-report}

1. 打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **Donations**（奉献），然后点击 **Summary**（汇总）。报表会立即运行，默认显示过去一年的数据。
2. 选择 **Weekly**（每周）、**Monthly**（每月）或 **Quarterly**（每季度），设置奉献的分组方式。
3. 在 **Filter Report**（筛选报表）面板中，设置 **Start Date**（开始日期）和 **End Date**（结束日期），可选择一个 **Fund**（基金），然后点击 **Run Report**（运行报表）。
4. 点击 **Download Options**（下载选项）并选择 **Summary**，即可将总计数据下载为 CSV 文件；或点击打印图标打印报表。

有关此页面的更多信息，请参阅[奉献报表](../donations/donation-reports.md#giving-dashboard)。

## 报表内容 {#what-the-report-shows}

奉献汇总包括：

- **Total Giving**（奉献总额）-- 所选时段内的奉献总金额。
- **Average Gift**（平均奉献）和 **Total Donations**（奉献总笔数）-- 典型的奉献金额和奉献笔数。
- **Unique Donors**（不重复捐助者）-- 参与奉献的不同捐助者人数。
- **Amounts by fund**（按基金的金额）-- 按周、月或季度显示各基金奉献情况的柱状图。

## 实际用途 {#practical-uses}

- **财务规划** -- 查看奉献趋势，预测未来收入并规划预算。
- **董事会报告** -- 为定期的董事会或领导层会议生成清晰的奉献数据摘要。
- **年终回顾** -- 运行全年的报表，以准备年度财务总结。
- **活动追踪** -- 按基金筛选，追踪特别奉献活动或建筑项目的进展。
- **季节性分析** -- 比较不同时段的奉献情况，了解季节性规律。

:::tip
建议每月运行一次此报表，以便及时了解教会的财务状况。比较月与月之间的数据，有助于及早发现趋势。
:::

:::warning
奉献数据来源于系统中记录的奉献。请确保奉献始终如一地录入，无论是通过网上奉献、支票处理还是手动录入，这样报表才最准确。详情请参阅[录入奉献](../donations/recording-donations.md)。
:::
