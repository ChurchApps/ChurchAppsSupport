# 捐赠汇总

<div class="article-intro">

捐赠汇总报告清楚地显示您教会的捐赠活动。使用它来追踪捐赠总额、监控捐赠趋势，并为您的领导团队准备财务报告。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 确保在您的系统中[一致地记录捐赠](../donations/recording-donations.md)
- 您需要适当的[权限](../settings/roles-permissions.md)来访问财务报告

</div>

## 运行报告

1. 直接在浏览器中转到 **admin.b1.church/reports/donationSummary**（报告在导航菜单中没有条目——将地址加入书签是返回的最简单方式）。
2. 设置**日期范围**以定义报告期间。
3. 应用其他筛选器，如**基金**或其他条件以缩小结果。
4. 报告将显示所选期间的捐赠汇总。

## 报告显示内容

捐赠汇总报告包括：

- **总捐赠**——所选期间的总体捐赠金额。
- **捐赠者数量**——贡献的独特捐赠者的数量。
- **按基金划分的金额**——跨不同基金的捐赠细分（如果适用）。

## 实际用途

- **财务规划**——查看捐赠趋势以预测未来收入并规划您的预算。
- **董事会报告**——为定期董事会或领导会议生成具有清晰捐赠数据的汇总。
- **年终回顾**——为整年运行报告以准备年度财务汇总。
- **活动追踪**——按基金筛选以追踪特殊捐赠活动或建筑项目的进度。
- **季节性分析**——比较不同时期的捐赠以了解季节性模式。

:::tip
每月运行此报告以了解您教会的财务健康状况。比较逐月数据有助于您尽早发现趋势。
:::

:::warning
捐赠数据来自您系统中记录的贡献。确保一致地输入捐赠——无论是通过在线捐赠、支票处理还是手动输入——以获得最准确的报告。有关详细信息，请查看[记录捐赠](../donations/recording-donations.md)。
:::
