# 出勤报告

<div class="article-intro">

B1 Admin 提供三份出勤报告，帮助您了解人员如何与您的服务和小组互动。每份报告都提供了对您的出勤数据的不同视角，从高层次趋势到每日细节。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 确保为您的服务和小组 [一致地跟踪出勤](../attendance/tracking-attendance.md)
- 确保您的 [小组](../groups/creating-groups.md) 和服务已在 B1 Admin 中配置
- 您需要适当的 [权限](../settings/roles-permissions.md) 才能访问报告

</div>

## 出勤趋势

出勤趋势报告显示您的服务出勤如何随时间变化。

1. 直接在浏览器中转到 **admin.b1.church/reports/attendanceTrend**（报告在导航菜单中没有条目 -- 将地址加入书签是返回的最简单方法）。同样的报告也在出勤页面的 **Attendance Trend** 标签页上。
2. 可选地选择 **Campus**、**Service**、**Service Time** 或 **Group** 以过滤结果。
3. 设置 **Start Date** 和 **End Date**。默认情况下，报告涵盖过去一年，从一年前到今天，包括结束日期。点击 **Run Report**。
4. 报告显示一张柱状图和每周总访问量表。每周标记为该周日期的日期，表格的 **Session Dates** 列列出该周有出勤的实际日期（例如"9/27, 9/30"）。

此报告对于发现季节性下降、增长趋势或特殊事件的影响等模式很有用。

## 小组出勤

小组出勤报告显示谁在一个日期范围内参加了每个小组会议。

1. 直接在浏览器中转到 **admin.b1.church/reports/groupAttendance**，或打开出勤页面的 **Group Attendance** 标签页。
2. 可选地选择 **Campus** 和 **Service**。
3. 设置 **Start Date** 和 **End Date**。默认情况下，报告涵盖上周日到今天，包括结束日期。
4. 点击 **Run Report**。

结果按会议日期、服务时间、小组分组，每个小组下方列出参加的人。服务时间、小组和名称按字母顺序排序。在每个人的名称旁边，**Checked In** 列显示记录出勤的时间（如果没有时间则为空白），**Membership Status** 列显示他们的状态，如成员或访客。

要下载电子表格，点击 **Download Options** 并选择 **Summary**。CSV 包含：

- 日期范围内召开的每个小组每个成员一行，按小组然后按名称排序。
- 人员名称和小组名称在前几列。
- 每个日期会议一列，命名为服务、服务时间和日期（例如"Sunday - 9:00 AM (2026-09-27)"），每个人标记为 **present** 或 **absent**。

使用此报告比较各小组的出勤并确定哪些小组正在增长或需要关注。

## 每日小组出勤

每日小组出勤报告提供您的小组出勤数据的逐日细分。

1. 直接在浏览器中转到 **admin.b1.church/reports/dailyGroupAttendance**。
2. 为报告设置 **日期范围**。
3. 选择您想要查看的 **小组**。
4. 报告显示范围内每个单独日期的出勤数字。

此报告提供精细细节，有助于理解周间差异或确定具有异常高或低出席率的特定日期。

:::tip
使用出勤趋势报告获得高层次概览，使用每日小组出勤报告当您需要深入特定日期时。
:::

## 实际用途

- **计划** -- 使用出勤趋势来计划即将到来的服务的座位、人员配备和资源。
- **外联** -- 尽早识别出席率下降的模式，以便您可以跟进成员。
- **董事会报告** -- 在您的定期领导力报告中包含出勤数据以显示事工健康。
- **活动评估** -- 比较特殊活动前后的出勤以衡量其影响。

:::warning
出勤数据通过您的小组和服务签到流程记录。如果没有一致地跟踪出勤，您的报告将无法准确反映实际参与。请参见 [跟踪出勤](../attendance/tracking-attendance.md) 以获取设置说明。
:::
