# 出席报告

<div class="article-intro">

B1 Admin 提供三份出席报告，帮助您了解人员如何参与您的服务和团体。每份报告提供不同的出席数据视角，从高层趋势到每日细分。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 确保为您的服务和团体[一致地追踪出席情况](../attendance/tracking-attendance.md)
- 确保您的[团体](../groups/creating-groups.md)和服务在 B1 Admin 中配置
- 您需要适当的[权限](../settings/roles-permissions.md)来访问报告

</div>

## 出席趋势

出席趋势报告显示您的服务在一段时间内出席情况如何变化。

1. 直接在浏览器中转到 **admin.b1.church/reports/attendanceTrend**（报告在导航菜单中没有条目——将地址加入书签是返回的最简单方式）。
2. 设置**日期范围**以定义时间段。
3. 选择**服务**或**团体**来筛选结果。
4. 报告显示在所选期间内出席计数的趋势线。

此报告对于发现季节性下降、增长趋势或特殊活动的影响等模式很有用。

## 团体出席

团体出席报告显示所选日期范围内按团体划分的出席总数。

1. 直接在浏览器中转到 **admin.b1.church/reports/groupAttendance**。
2. 为报告设置**日期范围**。
3. 选择您想要查看的**团体**。
4. 报告显示每个团体的总出席数字。

使用此报告比较各团体间的出席情况，并确定哪些团体正在增长或需要关注。

## 每日团体出席

每日团体出席报告提供您团体出席数据的逐日细分。

1. 直接在浏览器中转到 **admin.b1.church/reports/dailyGroupAttendance**。
2. 为报告设置**日期范围**。
3. 选择您想要查看的**团体**。
4. 报告显示范围内每个单独日期的出席人数。

此报告提供详细的粒度，有助于理解周与周的变化或识别出席异常高或低的特定日期。

:::tip
使用出席趋势报告获得高层概述，在需要深入特定日期时使用每日团体出席报告。
:::

## 实际用途

- **规划**——使用出席趋势来规划即将到来的服务的座位、人员配备和资源。
- **外联**——尽早识别出席下降的模式，以便您可以跟进成员。
- **董事会报告**——在定期领导报告中包括出席数据，以显示事工健康。
- **活动评估**——比较特殊活动前后的出席情况，以衡量其影响。

:::warning
出席数据通过您的团体和服务签到流程记录。如果不一致地追踪出席情况，您的报告将无法准确反映实际参与。查看 [追踪出席情况](../attendance/tracking-attendance.md) 了解设置说明。
:::
