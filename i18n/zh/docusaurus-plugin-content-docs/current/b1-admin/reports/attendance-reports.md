# 考勤报告

<div class="article-intro">

B1 Admin 提供三种考勤报告，帮助您了解人们如何参与您的礼拜和小组。每份报告都从不同角度呈现您的考勤数据，从高层次的趋势到每日的详细分析。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 请确保您的礼拜和小组[持续跟踪考勤](../attendance/tracking-attendance.md)
- 请确保您的[小组](../groups/creating-groups.md)和礼拜已在 B1 Admin 中配置完成
- 您需要具有访问报告的相应[权限](../settings/roles-permissions.md)

</div>

## 考勤趋势

考勤趋势报告显示您的礼拜考勤随时间的变化情况。

1. 在浏览器中直接前往 **admin.b1.church/reports/attendanceTrend**（报告不在导航菜单中，因此收藏该地址是返回报告的最简便方法）。同一报告也位于考勤页面中：点击 **All years**，然后选择 **Attendance Trend** 标签页。
2. 可选择 **Campus**（校区）、**Service**（礼拜）、**Service Time**（礼拜时间）或 **Group**（小组）来筛选结果。
3. 设置 **Start Date**（开始日期）和 **End Date**（结束日期）。默认情况下，报告涵盖过去一年，即从一年前到今天，并且结束日期会被完整包含。点击 **Run Report**（运行报告）。
4. 报告会以条形图和表格的形式显示每周的总到访次数。每周都会标注该周周日的日期，表格中的 **Session Dates**（礼拜日期）列会列出该周实际有考勤的日期（例如 "9/27, 9/30"）。

此报告有助于发现季节性下降、增长趋势或特殊活动的影响等规律。

## 小组考勤

小组考勤报告显示在指定日期范围内，每次小组聚会都有哪些人参加。

1. 在浏览器中直接前往 **admin.b1.church/reports/groupAttendance**，或在考勤页面中点击 **All years**，然后选择 **Group Attendance** 标签页。
2. 可选择 **Campus**（校区）和 **Service**（礼拜）。
3. 设置 **Start Date**（开始日期）和 **End Date**（结束日期）。默认情况下，报告涵盖从上一个周日到今天的时间，并且结束日期会被完整包含。
4. 点击 **Run Report**（运行报告）。

结果按礼拜日期、礼拜时间、小组分组，每个小组下列出参加的人员。礼拜时间、小组和姓名均按字母顺序排列。在每个人的姓名旁边，**Checked In**（签到时间）列显示其考勤记录的时间（如果没有记录时间则为空白），**Membership Status**（会员状态）列则显示其状态，例如 Member（会员）或 Visitor（访客）。

若要下载电子表格，请点击 **Download Options**（下载选项）并选择 **Summary**（摘要）。该 CSV 文件包含：

- 每位在日期范围内参加过小组聚会的小组成员各占一行，按小组排序，然后按姓名排序。
- 前几列为该人员的姓名和小组名称。
- 每个有日期的礼拜各占一列，列名包含礼拜、礼拜时间和日期（例如 "Sunday - 9:00 AM (2026-09-27)"），每位人员分别标记为 **present**（出席）或 **absent**（缺席）。

使用此报告可以比较各小组之间的考勤情况，并找出哪些小组正在增长或需要关注。

## 每日小组考勤

每日小组考勤报告（标题为 **Group attendance by day**，即按日统计的小组考勤）按日统计某一个小组的参加人数。

1. 在浏览器中直接前往 **admin.b1.church/reports/dailyGroupAttendance**。
2. 使用 **Campus**（校区）、**Service**（礼拜）和 **Service Time**（礼拜时间）下拉菜单缩小列表范围，然后选择您要查看的 **Group**（小组）。
3. 运行报告。报告会按时间从早到晚列出该小组聚会的每一天，并显示 **Date**（日期）以及当天记录的 **Attendees**（参加人数）。

此报告提供细粒度的详细信息，有助于了解每周的波动情况，或找出人数异常高或低的特定日期。

:::tip
如需高层次的概览，请使用考勤趋势报告；如需深入查看特定日期，请使用每日小组考勤报告。
:::

## 实际用途

- **规划**：利用考勤趋势规划即将到来的礼拜的座位、人员安排和资源。
- **外展**：及早发现考勤下降的情况，以便跟进会员。
- **董事会报告**：在定期的领导层报告中包含考勤数据，以展示事工的健康状况。
- **活动评估**：比较特殊活动前后的考勤，以衡量其影响。

:::warning
考勤数据通过您的小组和礼拜签到流程记录。如果考勤未被持续跟踪，您的报告将无法准确反映实际参与情况。有关设置说明，请参阅[跟踪考勤](../attendance/tracking-attendance.md)。
:::
