# 出勤报表

<div class="article-intro">

B1 Admin 提供三种出勤报表，帮助你了解人们如何参与你的礼拜和小组。每种报表都从不同角度展示你的出勤数据，从宏观趋势到每日明细，应有尽有。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 请确保你的礼拜和小组都在[持续追踪出勤](../attendance/tracking-attendance.md)
- 确保你的[小组](../groups/creating-groups.md)和礼拜已在 B1 Admin 中配置完成
- 你需要具备访问报表的相应[权限](../settings/roles-permissions.md)

</div>

## 出勤趋势

出勤趋势报表显示你的礼拜出勤随时间的变化情况。

1. 直接在浏览器中访问 **admin.b1.church/reports/attendanceTrend**（报表在导航菜单中没有入口——将该地址加入书签是最便捷的返回方式）。同一报表也位于出勤页面中：点击 **All years**，然后选择 **Attendance Trend** 标签页。
2. 可选择 **Campus**（校区）、**Service**（礼拜）、**Service Time**（礼拜时间）或 **Group**（小组）来筛选结果。
3. 设置 **Start Date**（开始日期）和 **End Date**（结束日期）。默认情况下，报表涵盖过去一年，即从一年前到今天，且结束日期会完整包含在内。点击 **Run Report**（运行报表）。
4. 报表会以柱状图和表格的形式显示每周的总到访人次。每周会以该周星期日的日期作为标签，表格中的 **Session Dates**（场次日期）列会列出该周内实际有出勤记录的日期（例如"9/27、9/30"）。

该报表有助于发现季节性下降、增长趋势或特别活动的影响等规律。

## 小组出勤 {#group-attendance}

小组出勤报表显示在某一日期范围内，每场小组聚会的出席人员。

1. 直接在浏览器中访问 **admin.b1.church/reports/groupAttendance**；或在出勤页面点击 **All years**，然后选择 **Group Attendance** 标签页。
2. 可选择 **Campus** 和 **Service**。
3. 设置 **Start Date** 和 **End Date**。默认情况下，报表涵盖上一个星期日到今天，且结束日期会完整包含在内。
4. 点击 **Run Report**。

结果会按场次日期分组，然后按礼拜时间、再按小组排列，每个小组下方列出出席的人员。礼拜时间、小组和姓名均按字母顺序排序。在每位人员的姓名旁边，**Checked In**（签到时间）列会显示其出勤被记录的时间（若没有记录时间则留空），**Membership Status**（会籍状态）列则显示其状态，例如 Member（会员）或 Visitor（访客）。对于不在礼拜时间聚会的小组的场次，同样会包括在内；它们会显示为没有礼拜时间。

若要下载电子表格，请点击 **Download Options**（下载选项），然后选择 **Summary**（摘要）。该 CSV 文件包含：

- 每个在该日期范围内聚会的小组中，每位成员占一行，按小组、再按姓名排序。
- 前几列为人员姓名和小组名称。
- 每个有日期的场次占一列，列名由礼拜、礼拜时间和日期组成（例如"Sunday - 9:00 AM (2026-09-27)"），每位人员标记为 **present**（出席）或 **absent**（缺席）。没有礼拜时间的场次，仅以日期命名。

使用此报表可以比较各小组的出勤情况，并找出哪些小组正在成长或需要关注。

## 每日小组出勤

每日小组出勤报表（标题为 **Group attendance by day**，即按天统计的小组出勤）会按天统计某一个小组的出席人数。

1. 直接在浏览器中访问 **admin.b1.church/reports/dailyGroupAttendance**。
2. 使用 **Campus**、**Service** 和 **Service Time** 下拉菜单缩小列表范围，然后选择你要查看的 **Group**（小组）。
3. 运行报表。它会列出该小组聚会的每一天（最早的日期排在最前），并显示 **Date**（日期）以及当天记录的 **Attendees**（出席人数）。

该报表提供精细的明细，有助于了解每周的波动，或找出出勤人数异常高或低的特定日期。

:::tip
需要宏观概览时，请使用出勤趋势报表；需要深入到特定日期时，请使用每日小组出勤报表。
:::

## 实际用途

- **规划** —— 利用出勤趋势为即将到来的礼拜规划座位、人员安排和资源。
- **外展** —— 及早发现出勤下降的模式，以便跟进会员。
- **董事会报告** —— 将出勤数据纳入定期的领导层报告，以展示事工的健康状况。
- **活动评估** —— 比较特别活动前后的出勤情况，以衡量其影响。

:::warning
出勤数据是通过小组和礼拜的签到流程记录的。如果出勤没有被持续追踪，你的报表将无法准确反映实际参与情况。设置说明请参阅[追踪出勤](../attendance/tracking-attendance.md)。
:::
