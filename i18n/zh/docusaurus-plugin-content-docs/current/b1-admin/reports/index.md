# 报告

<div class="article-intro">

报告页面让您快速访问预构建的报告，帮助您了解您的教会数据。使用这些报告来追踪出席趋势、监控捐赠活动，并通过生日庆祝与您的会众保持联系。

</div>

## 可用报告

报告在 B1 Admin 导航菜单中没有条目——直接转到您想要的报告的 URL（将其加入书签是返回的最简单方式）。每份报告直接打开其筛选器。

- **[生日报告](./birthday-report)**（`admin.b1.church/reports/birthdays`）——查看您会众成员的即将到来的生日。
- **[周年纪念报告](./anniversary-report)**（`admin.b1.church/reports/anniversaries`）——查看您会众成员的即将到来的婚姻周年纪念。
- **[出席趋势](./attendance-reports)**（`admin.b1.church/reports/attendanceTrend`）——查看您服务中出席模式如何随时间变化。
- **[团体出席](./attendance-reports)**（`admin.b1.church/reports/groupAttendance`）——查看所选日期范围内按团体划分的出席总数。
- **[每日团体出席](./attendance-reports)**（`admin.b1.church/reports/dailyGroupAttendance`）——获取团体出席数据的逐日细分。
- **[捐赠汇总](./donation-summary)**（`admin.b1.church/reports/donationSummary`）——查看捐赠总额和趋势以进行财务规划。
- **[审计日志](./audit-log)**——追踪您的教会管理系统中的所有变更和操作（位于设置 > 审计日志下）。

## 使用报告

1. 直接转到报告的 URL，例如 **admin.b1.church/reports/birthdays**。
2. 使用报告顶部的**筛选器**按日期范围、团体、服务或其他条件缩小数据。
3. 查看报告中显示的结果。

:::tip
定期运行报告以了解最新的出席趋势、即将到来的生日和捐赠模式。这些数据帮助您更有效地规划事工和外联。
:::

:::info
报告数据取决于一致的数据输入。确保您的团队[追踪出席情况](../attendance/tracking-attendance.md)、[记录捐赠](../donations/recording-donations.md)和保持[人员记录](../people/adding-people.md)最新以获得最准确的结果。
:::
