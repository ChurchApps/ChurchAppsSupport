# 报告

<div class="article-intro">

B1 Admin 提供多种方式来获取有关会众、出勤和奉献的数据。报告功能内置于应用的相关板块中，而不是集中在单独的报告页面。

</div>

## 在哪里找到报告

### 人员
- **[生日与纪念日列表](./birthday-report.md)**——在 **People → Advanced Search**（人员 → 高级搜索）中按 Birth Month（出生月份）或 Anniversary Month（纪念日月份）筛选，即可获得即将到来的生日或纪念日列表。

### 出勤
- **[出勤报告](./attendance-reports.md)**——出勤趋势和小组出勤数据位于 **Attendance**（出勤）板块中。

### 奉献
- **[奉献汇总](./donation-summary.md)**——奉献合计和基金明细位于 **Donations**（奉献）板块中。

### 设置
- **[审计日志](./audit-log.md)**——追踪教会管理系统中的所有变更和操作（位于 **Settings → Audit Log**（设置 → 审计日志）下）。

:::info
报告数据依赖于一致的数据录入。请确保您的团队在[追踪出勤](../attendance/tracking-attendance.md)、[记录奉献](../donations/recording-donations.md)，并及时更新[人员记录](../people/adding-people.md)，以获得最准确的结果。
:::
