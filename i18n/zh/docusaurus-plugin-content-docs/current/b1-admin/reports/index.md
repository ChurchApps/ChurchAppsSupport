# 报告

<div class="article-intro">

B1 Admin 提供多种方式让您获取有关会众、考勤和奉献的数据。报告功能内置于应用的相关板块中，而非集中在单独的报告页面中。

</div>

## 报告位置

### 人员
- **[生日与纪念日列表](./birthday-report)**：在 **People → Advanced Search** 中按 Birth Month（出生月份）或 Anniversary Month（纪念日月份）筛选，即可获得即将到来的生日或纪念日列表。

### 考勤
- **[考勤报告](./attendance-reports)**：考勤趋势和小组考勤数据位于 **Attendance**（考勤）板块中。

### 奉献
- **[奉献摘要](./donation-summary)**：奉献总额和基金明细位于 **Donations**（奉献）板块中。

### 设置
- **[审计日志](./audit-log)**：跟踪您教会管理系统中的所有更改和操作（位于 **Settings → Audit Log** 下）。

:::info
报告数据依赖于一致的数据录入。请确保您的团队[跟踪考勤](../attendance/tracking-attendance.md)、[记录奉献](../donations/recording-donations.md)，并保持[人员记录](../people/adding-people.md)的更新，以获得最准确的结果。
:::
