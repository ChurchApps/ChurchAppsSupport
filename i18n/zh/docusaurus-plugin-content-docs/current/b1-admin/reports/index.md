# 报告

<div class="article-intro">

B1Admin 为您提供了多种方式来提取有关您的会众、出席和捐赠的数据。报告内置于应用的相关部分中，而不是单个报告页面。

</div>

## 在哪里查找报告

### 人员
- **[生日和周年纪念名单](./birthday-report)** — 在**人员 > 高级搜索**中按出生月份或周年纪念月份过滤以获取即将到来的生日或周年纪念的名单。

### 出席
- **[出席报告](./attendance-reports)** — 出席趋势和小组出席数据可在**出席**部分找到。

### 捐赠
- **[捐赠摘要](./donation-summary)** — 捐赠总计和基金分解可在**捐赠**部分找到。

### 设置
- **[审计日志](./audit-log)** — 跟踪您的教会管理系统中的所有更改和操作（位于**设置 > 审计日志**下）。

:::info
报告数据取决于一致的数据输入。确保您的团队[跟踪出席](../attendance/tracking-attendance.md)、[记录捐赠](../donations/recording-donations.md)，并保持[人员记录](../people/adding-people.md)最新以获得最准确的结果。
:::
