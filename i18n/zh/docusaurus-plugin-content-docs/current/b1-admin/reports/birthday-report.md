# 生日和周年纪念名单

<div class="article-intro">

需要给定月份内有生日或周年纪念的所有人的名单 — 用于公告、宣布或贺卡？人员搜索可以按**出生月份**和**周年纪念月份**过滤您的会众并直接在结果中显示日期。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 确保在每个人的资料上输入了出生日期（和周年纪念）。参见[添加人员](../people/adding-people.md)。
- 您需要权限查看人员。参见[角色和权限](../settings/roles-permissions.md)。

</div>

## 获取一个月的生日名单

1. 打开左上角的**部分菜单**并选择**人员**。
2. 在搜索框下，单击**高级**。
3. 展开**人口统计**部分并检查**出生月份**，然后选择月份。
4. 运行搜索 — 该月有生日的所有人出现在结果中。
5. 要查看日期，单击结果右上方的**列图标**并启用**生日**列。如果您更喜欢在那里排序或打印，请使用**导出**将列表下载为电子表格。

## 获取周年纪念名单

相同的步骤 — 在**人口统计**部分中，改为检查**周年纪念月份**（或也是），选择月份，并在结果中启用**周年纪念**列。

## 实际用途

- **每周公告** — 运行当前月份的列表并直接将名称读入公告。
- **生日和周年纪念贺卡** — 导出月份列表并将其交给您的贺卡写作团队。
- **里程碑** — 与**年龄**过滤器结合使用以查找里程碑生日。

:::tip
两个列表都来自每个人资料上的出生日期和周年纪念字段 — 如果某人缺失，他们的资料只需添加日期。
:::

:::info
B1Admin 的早期版本有一个生日的单独报告页面。该页面已停用 — 上面的人员搜索过滤器是当前方式，也涵盖周年纪念。
:::
