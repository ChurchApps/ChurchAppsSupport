# 生日和周年纪念列表

<div class="article-intro">

需要一份列表，列出特定月份有生日或周年纪念的所有人员 -- 用于教会公报、公告或卡片？People 搜索可以按 **Birth Month** 和 **Anniversary Month** 过滤您的会众，并在结果中显示日期。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 确保出生日期（和周年纪念日）已在每个人员的资料中输入。参见 [添加人员](../people/adding-people.md)。
- 您需要有权查看人员。参见 [角色和权限](../settings/roles-permissions.md)。

</div>

## 获取某月的生日列表

1. 打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **People**，然后点击 **People**。
2. 在搜索框下，点击 **Advanced**。
3. 展开 **Demographics** 部分并勾选 **Birth Month**，然后选择月份。
4. 运行搜索 -- 在该月有生日的所有人都会出现在结果中。
5. 要查看日期，点击结果右上角的 **列图标** 并启用 **Birthday** 列。如果您更喜欢在其中排序或打印，请使用 **Export** 将列表下载为电子表格。

## 获取周年纪念列表

相同的步骤 -- 在 **Demographics** 部分中，改为勾选 **Anniversary Month**（或同时勾选两个），选择月份，并在结果中启用 **Anniversary** 列。

## 实际用途

- **每周教会公报** -- 运行当前月份的列表并将名称直接读入公报。
- **生日和周年纪念卡** -- 导出本月的列表并将其交给您的卡片制作团队。
- **里程碑** -- 与 **Age** 过滤器相结合以找到里程碑生日。

:::tip
两个列表都来自每个人员资料中的出生日期和周年纪念字段 -- 如果某人缺失，他们的资料只需添加日期。
:::

:::info
早期版本的 B1 Admin 有一个单独的生日报告页面。该页面已停用 -- People 搜索过滤器是目前的方式，它们也涵盖周年纪念。
:::
