# 生日报告

<div class="article-intro">

生日报告帮助您与您的会众保持联系，显示即将到来生日的成员。使用它来规划庆祝活动、发送贺卡或在服务中进行公告。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 确保在每个人的个人资料上输入了出生日期。有关详细信息，请查看[添加人员](../people/adding-people.md)。
- 您需要适当的[权限](../settings/roles-permissions.md)来访问报告

</div>

## 运行报告

1. 直接在浏览器中转到 **admin.b1.church/reports/birthdays**（报告在导航菜单中没有条目——将地址加入书签是返回的最简单方式）。
2. 从下拉菜单中选择您想要的**月份**。您可以选择将结果限制在单个**团体**。
3. 单击**运行报告**。报告列出该月有生日的所有人，包括他们的出生日期——可以直接读入公告或公告列表。

## 报告显示内容

生日报告显示：

- **生日**——他们生日的日期。
- **姓名**——您的教会数据库中该人的姓名。

结果涵盖您选择的月份，使您可以轻松查看谁即将庆祝生日。

## 实际用途

- **周公告**——为即将到来的一周运行报告，并将生日包括在您的公告中。
- **生日卡**——为该月生成列表，让您的团队发送个人生日贺卡。
- **小组领导**——团体领导可以运行报告以记住他们团体中成员的生日。
- **里程碑庆祝**——针对特定日期范围进行筛选以规划里程碑生日庆祝。

:::tip
在每个月初运行此报告以提前规划。您可以设置日期范围以覆盖整个月份，以便有时间准备卡片或公告。
:::

:::info
生日数据来自每个人个人资料上的出生日期字段。确保您的[成员记录](../people/adding-people.md)是最新的，以获得准确的结果。
:::
