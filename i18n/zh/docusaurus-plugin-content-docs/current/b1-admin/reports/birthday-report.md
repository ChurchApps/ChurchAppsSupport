# 生日和周年纪念列表

<div class="article-intro">

需要列出某个月份内所有过生日或有结婚纪念日的人员，用于周报、公告或祝福卡片吗？人员搜索可以按 **Birth Month**（出生月份）和 **Anniversary Month**（纪念日月份）筛选你的会众，并直接在结果中显示日期。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 确保每位人员的个人资料中已录入出生日期（以及纪念日）。参见[添加人员](../people/adding-people.md)。
- 你需要具备查看人员信息的权限。参见[角色与权限](../settings/roles-permissions.md)。

</div>

## 获取某月的生日列表 {#getting-a-birthday-list-for-a-month}

1. 打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **People**，然后点击 **People**。
2. 在搜索框下方点击 **Advanced**。
3. 展开 **Demographics**（人口统计）部分，勾选 **Birth Month**，然后选择月份。
4. 勾选筛选条件后，结果会立即更新，显示该月过生日的所有人员。
5. 要查看具体日期，请将 **View as** 切换为 **Table**（表格），然后点击页面标题中的 **Select columns**（选择列）图标，启用 **Birth Date**（出生日期）列（若不想显示年份，可选择 **Birthday (No Year)**（生日，不含年份））。如果你更习惯在电子表格中排序或打印，可使用 **Export** 将列表下载为电子表格。

## 获取纪念日列表 {#getting-an-anniversary-list}

操作步骤相同：在 **Demographics** 部分改为勾选（或同时勾选）**Anniversary Month**（纪念日月份），选择月份，然后在结果中启用 **Anniversary**（纪念日）列。

## 实际用途 {#practical-uses}

- **每周周报** -- 运行当月的列表，直接将姓名写入周报。
- **生日和纪念日卡片** -- 导出当月列表，交给负责写卡片的团队。
- **里程碑** -- 结合 **Age**（年龄）筛选条件，找出具有里程碑意义的生日。

:::tip
这两份列表均来自每位人员个人资料中的出生日期和纪念日字段。如果某人没有出现在列表中，只需在其个人资料中补充日期即可。
:::

:::info
早期版本的 B1 Admin 在菜单中提供了一个单独的生日报表链接。该链接现已移除，上述人员搜索筛选条件是目前的使用方式，并且同样支持纪念日。
:::
