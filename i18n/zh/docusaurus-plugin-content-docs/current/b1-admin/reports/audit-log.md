# 审计日志

<div class="article-intro">

审计日志跟踪整个教会管理系统中的所有重要操作和更改。使用它来查看登录活动、跟踪谁对人员记录进行了更改、监控权限更新并在您的团队中保持问责制。

</div>

<div class="prereqs">
<h4>开始前</h4>

- B1 Admin 账户具有服务器管理员访问权限
- 导航到 **Settings** 以查找审计日志

</div>

## 查看审计日志

1. 打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏）并展开 **Settings**。
2. 点击 **Audit Log**。
3. 日志在表格中显示最近的条目，包含以下列：
   - **Date** -- 操作发生的时间。
   - **Category** -- 操作的类型（为快速扫描进行颜色编码）。
   - **Action** -- 执行的操作（例如 create、update、delete、login_success）。
   - **Entity** -- 受影响的记录的类型和 ID。
   - **IP Address** -- 执行操作的用户的 IP 地址。
   - **Details** -- 所做具体更改的摘要。

## 过滤日志

使用页面顶部的过滤器来缩小结果范围：

- **Category** -- 按操作类型过滤：
  - **All Categories** -- 显示所有内容。
  - **Login** -- 登录成功和失败。
  - **People** -- 创建、更新或删除人员记录。
  - **Permissions** -- 权限授予和撤销。
  - **Donations** -- 捐赠记录更改。
  - **Groups** -- 小组管理操作。
  - **Forms** -- 表单提交活动。
  - **Settings** -- 配置更改。
- **Start Date** -- 显示从此日期开始的条目。
- **End Date** -- 显示到此日期的条目。

设置过滤器后点击 **Search** 以更新结果。

## 了解类别

每个类别都用颜色编码以快速识别：

- **Login** -- 蓝色标记。跟踪成功和失败的登录尝试。
- **People** -- 紫色标记。跟踪人员记录创建、更新和删除。
- **Permissions** -- 红色标记。跟踪授予或撤销访问权限的时间。
- **Donations** -- 绿色标记。跟踪捐赠记录更改。
- **Groups** -- 灰色标记。跟踪小组管理操作。
- **Forms** -- 橙色标记。跟踪表单提交活动。
- **Settings** -- 黄色标记。跟踪配置更改。

## 导出日志

当显示日志条目时，会出现 **CSV 下载** 按钮。点击它将当前过滤的结果导出到电子表格以进行离线审查或记录保留。

## 分页

使用表格底部的分页控件浏览结果。您可以每页显示 25、50 或 100 条条目。

:::info
审计日志条目会自动保留一年。365 天以上的条目会被删除以保持系统性能。
:::

:::tip
定期审查审计日志，尤其是在入职新团队成员或进行重大配置更改后。它有助于及早识别意外活动。
:::
