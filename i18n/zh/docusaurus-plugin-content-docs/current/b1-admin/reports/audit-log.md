# 审计日志

<div class="article-intro">

审计日志会记录教会管理系统中所有重要的操作和变更。您可以用它来查看登录活动、追踪谁对人员记录做出了修改、监控权限更新，并确保团队中每个人都有责任意识。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 拥有服务器管理员权限的 B1 Admin 账户
- 前往 **Settings** 找到审计日志

</div>

## 查看审计日志

1. 打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），并展开 **Settings**。
2. 点击 **Audit Log**。
3. 日志会以表格形式显示最近的条目，包含以下列：
   - **Date**（日期）——操作发生的时间。
   - **Category**（类别）——操作的类型（颜色编码，便于快速浏览）。
   - **Action**（操作）——执行的动作（例如 create、update、delete、login_success）。
   - **Entity**（实体）——受影响记录的类型和 ID。
   - **IP Address**（IP 地址）——执行该操作的用户的 IP 地址。
   - **Details**（详情）——所做具体变更的摘要。

## 筛选日志

使用页面顶部的筛选器缩小结果范围：

- **Category**（类别）——按操作类型筛选：
  - **All Categories**（所有类别）——显示全部内容。
  - **Login**（登录）——登录成功与失败。
  - **People**（人员）——创建、更新或删除人员记录。
  - **Permissions**（权限）——授予或撤销权限。
  - **Donations**（奉献）——奉献记录的变更。
  - **Groups**（小组）——小组管理操作。
  - **Forms**（表单）——表单提交活动。
  - **Settings**（设置）——配置变更。
- **Start Date**（开始日期）——显示此日期之后的条目。
- **End Date**（结束日期）——显示截至此日期的条目。

设置好筛选条件后，点击 **Search**（搜索）以更新结果。

## 了解类别

每个类别都有颜色标识，便于快速识别：

- **Login**（登录）——蓝色标签。记录成功和失败的登录尝试。
- **People**（人员）——紫色标签。记录人员记录的创建、更新和删除。
- **Permissions**（权限）——红色标签。记录访问权限的授予或撤销。
- **Donations**（奉献）——绿色标签。记录奉献记录的变更。
- **Groups**（小组）——灰色标签。记录小组管理操作。
- **Forms**（表单）——橙色标签。记录表单提交活动。
- **Settings**（设置）——黄色标签。记录配置变更。

## 人员和小组的备注历史

如果您可以打开审计日志，那么在人员或小组的 **Notes**（备注）标签页上，也能直接看到备注的变更记录：

1. 被编辑过的备注会在其日期旁显示 **(edited · view history)**（已编辑 · 查看历史）。点击它即可打开审计日志，并自动筛选出该人员或小组的备注历史。
2. 被删除的备注会在原位置留下一个灰色的 **Deleted note**（已删除的备注）标记，显示撰写人、发布时间和删除时间。点击 **View history**（查看历史）即可打开同样筛选后的日志。
3. 在筛选后的日志中，展开 **Note Updated**（备注已更新）或 **Note Deleted**（备注已删除）条目，即可查看旧文本以及进行变更的账户。点击 **Show all**（显示全部）可清除筛选。
4. 在 **Entity** 列中，人员或小组备注的 ID 会链接回该人员或小组的备注页面。

无法打开审计日志的工作人员只会看到备注列表，而看不到这些标记。

## 导出日志

当显示日志条目时，会出现 **CSV download**（下载 CSV）按钮。点击即可将当前筛选后的结果导出为电子表格，用于离线审查或记录保存。

## 分页

使用表格底部的分页控件浏览结果。每页可显示 25、50 或 100 条条目。

:::info
审计日志条目会自动保留一年。超过 365 天的条目将被删除，以保持系统性能。
:::

:::tip
请定期查看审计日志，尤其是在新团队成员加入或进行重大配置变更之后。这有助于及早发现异常活动。
:::
