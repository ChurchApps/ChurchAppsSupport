# 结婚纪念日名单

<div class="article-intro">

需要某个月份所有有结婚纪念日的人员名单，用于周报、卡片或公告吗？人员搜索可让你依**Anniversary Month**进行筛选，并直接在结果中显示日期。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 请确保每位人员的个人资料中已输入结婚纪念日。详情请参阅[新增人员](../people/adding-people.md)。
- 你需要具有查看人员的权限。请参阅[角色与权限](../settings/roles-permissions.md)。

</div>

## 取得某个月份的结婚纪念日名单 {#getting-an-anniversary-list-for-a-month}

1. 打开[快速菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **People**，然后点击 **People**。
2. 在搜索框下方，点击 **Advanced**。
3. 展开 **Demographics** 区块，勾选 **Anniversary Month**，然后选择月份。
4. 勾选筛选条件后，结果会立即更新——该月份所有有结婚纪念日的人员都会出现。
5. 若要查看日期，请将 **View as** 切换为 **Table**，然后点击页面标题中的**选择栏位**图标，并启用 **Anniversary** 栏位。如果你想排序或打印名单，请使用 **Export** 将名单下载为试算表。

## 实际用途 {#practical-uses}

- **每周周报**——执行当月的名单，并将结婚纪念日列入周报或公告。
- **纪念日卡片**——汇出当月名单，交给负责撰写卡片的团队。
- **里程碑庆祝**——搭配 **Years Married** 筛选，找出具有里程碑意义的结婚纪念日。

:::tip
请在每个月初执行此名单，以便在纪念日到来之前，有充足的时间准备卡片或公告。
:::

:::info
结婚纪念日的资料来自每位人员个人资料中的纪念日栏位。如果有人遗漏，只需在其个人资料中补上日期即可。请参阅[新增人员](../people/adding-people.md)。
:::
