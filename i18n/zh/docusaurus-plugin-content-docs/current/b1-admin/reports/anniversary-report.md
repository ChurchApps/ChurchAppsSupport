# 周年纪念名单

<div class="article-intro">

需要给定月份内有婚纱摄影周年纪念的所有人的名单 — 用于公告、贺卡或宣布？人员搜索让您按**周年纪念月份**过滤并直接在结果中显示日期。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 确保在每个人的资料上输入了周年纪念日期。详情请参见[添加人员](../people/adding-people.md)。
- 您需要权限查看人员。参见[角色和权限](../settings/roles-permissions.md)。

</div>

## 获取一个月的周年纪念名单

1. 打开左上角的**部分菜单**并选择**人员**。
2. 在搜索框下，单击**高级**。
3. 展开**人口统计**部分并检查**周年纪念月份**，然后选择月份。
4. 运行搜索 — 该月有周年纪念的所有人出现在结果中。
5. 要查看日期，单击结果右上方的**列图标**并启用**周年纪念**列。如果您更喜欢排序或打印，请使用**导出**将列表下载为电子表格。

## 实际用途

- **每周公告** — 运行当前月份的列表并在您的公告或宣布中包括周年纪念。
- **周年纪念贺卡** — 导出月份列表并将其交给您的贺卡写作团队。
- **里程碑庆祝** — 与**结婚年限**过滤器结合使用以查找里程碑周年纪念。

:::tip
在每个月开始时运行此项，以便您在周年纪念到来前有时间准备贺卡或宣布。
:::

:::info
周年纪念数据来自每个人资料上的周年纪念字段。如果某人缺失，他们的资料只需添加日期。参见[添加人员](../people/adding-people.md)。
:::
