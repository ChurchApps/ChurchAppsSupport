# 周年纪念报告

<div class="article-intro">

周年纪念报告帮助您与您的会众保持联系，显示即将到来的婚姻周年纪念的成员。使用它来规划庆祝活动、发送贺卡或在服务中进行公告。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 确保在每个人的个人资料上输入了周年纪念日期。有关详细信息，请查看[添加人员](../people/adding-people.md)。
- 您需要适当的[权限](../settings/roles-permissions.md)来访问报告

</div>

## 运行报告

1. 直接在浏览器中转到 **admin.b1.church/reports/anniversaries**（报告在导航菜单中没有条目——将地址加入书签是返回的最简单方式）。
2. 从下拉菜单中选择您想要的**月份**。您可以选择将结果限制在单个**团体**。
3. 单击**运行报告**。报告列出该月有周年纪念的所有人，包括日期——可以直接读入公告或公告列表。

## 报告显示内容

周年纪念报告显示：

- **周年纪念**——他们的婚姻周年纪念日期。
- **姓名**——您的教会数据库中该人的姓名。

结果涵盖您选择的月份，使您可以轻松查看谁即将庆祝周年纪念。

## 实际用途

- **周公告**——为即将到来的一周运行报告，并将周年纪念包括在您的公告中。
- **周年纪念卡**——为该月生成列表，让您的团队发送个人周年纪念贺卡。
- **小组领导**——团体领导可以运行报告以记住他们团体中成员的周年纪念。
- **里程碑庆祝**——针对特定日期范围进行筛选以规划里程碑周年纪念庆祝。

:::tip
在每个月初运行此报告以提前规划。您可以设置日期范围以覆盖整个月份，以便有时间准备卡片或公告。
:::

:::info
周年纪念数据来自每个人个人资料上的周年纪念字段。确保您的[成员记录](../people/adding-people.md)是最新的，以获得准确的结果。
:::
