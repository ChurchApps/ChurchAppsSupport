# 周年纪念列表

<div class="article-intro">

需要一份列表，列出特定月份有婚礼周年纪念的所有人员 -- 用于教会公报、卡片或公告？People 搜索允许您按 **Anniversary Month** 过滤并在结果中显示日期。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 确保周年纪念日期已在每个人员的资料中输入。有关详情，请参见 [添加人员](../people/adding-people.md)。
- 您需要有权查看人员。参见 [角色和权限](../settings/roles-permissions.md)。

</div>

## 获取某月的周年纪念列表

1. 打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **People**，然后点击 **People**。
2. 在搜索框下，点击 **Advanced**。
3. 展开 **Demographics** 部分并勾选 **Anniversary Month**，然后选择月份。
4. 运行搜索 -- 在该月有周年纪念的所有人都会出现在结果中。
5. 要查看日期，点击结果右上角的 **列图标** 并启用 **Anniversary** 列。如果您更喜欢在电子表格中排序或打印，请使用 **Export** 将列表下载为电子表格。

## 实际用途

- **每周教会公报** -- 运行当前月份的列表并在您的公报或公告中包含周年纪念。
- **周年纪念卡** -- 导出本月的列表并将其交给您的卡片制作团队。
- **里程碑庆祝** -- 与 **Years Married** 过滤器相结合以查找里程碑周年纪念。

:::tip
在每个月初运行此操作，这样您有时间在周年纪念到来前准备卡片或公告。
:::

:::info
周年纪念数据来自每个人员资料中的周年纪念字段。如果某人缺失，他们的资料只需添加日期。参见 [添加人员](../people/adding-people.md)。
:::
