# B1 Admin 概览

<div class="article-intro">

B1 Admin 是您的教会管理仪表板。它提供工具来管理教会运营的各个方面——从会员目录、奉献到网站建设和直播——都集中在一个地方。

</div>

## 入门

1. 打开浏览器并访问 [admin.b1.church](https://admin.b1.church)
2. 使用您的用户名和密码登录
3. 您会进入 **Dashboard**（仪表板），即您的主页。它会显示本周的礼拜流程、实时的签到和服事人员、需要您关注的事项（例如待审批或加入申请），以及您的未完成任务和小组

:::tip
初次使用 B1 Admin？请先阅读[介绍](./introduction.md)，观看视频导览，然后访问[设置](./settings/index.md)以配置教会信息并邀请您的团队。
:::

## 您的仪表板

Dashboard 是您的 B1 Admin 主页（`/`）。它围绕教会的每周礼拜而构建：

- **This week's service**（本周礼拜）——当前或即将到来的计划名称和礼拜流程，并附有通往完整计划的链接
- **Live status**（实时状态）——当人们在主日开始签到后，页面会显示目前在场的人数、此时段正在服事的人员、首次到访的新人，以及按房间列出的、带容量条的逐室统计
- **Needs Attention**（需要关注）——需要处理的待审批事项和小组加入申请
- **My tasks**（我的任务）和 **My Groups**（我的小组）——您未完成的任务（点击 **Add Task** 添加，或点击 **All tasks** 查看完整列表）以及您所属的小组

仪表板显示的内容取决于您的[角色](./settings/roles-permissions.md)。例如，只有当您可以打开该计划（您可以编辑计划、属于计划所属的事工，或正在为该计划服事）时，才会出现通往完整计划的链接；只有当您有权管理小组、查看小组成员或查看人员时，才会出现 **All groups**（全部小组）链接。

:::tip
包括 Sermons（讲道）、Calendars（日历）、Mobile（移动）和 Settings（设置）在内的每个板块，都可以在 B1 Admin 左上角的[快速跳转菜单](./introduction.md#getting-around-with-the-jump-menu)中找到。点击它或按 **Ctrl+K**（或 **Cmd+K**），然后浏览或开始输入。
:::

## 主要功能

- **[人员](./people/index.md)**——管理教会通讯录、添加成员、批量编辑数据，并可按家庭浏览或以可排序的表格浏览。每个人都有一个记录页面，左侧是其详细信息，旁边是出勤、奉献、小组、备注和表单的摘要。使用 **Date Added**（添加日期）搜索可以找到最近添加的人员。[备注](./people/notes.md)页面会列出人员、小组、活动和工作流卡片上的最新备注
- **[小组](./groups/index.md)**——创建和组织教会小组，支持加入申请、成员管理、小组邮件、个性化的小组短信（配有可重复使用的短信模板和小组名称占位符），以及可打印的联系名单。每个小组都有一个页面，左侧是其操作，旁边是成员、场次、日历和健康度摘要
- **[出勤](./attendance/index.md)**——设置校区和礼拜时间，记录具名出勤并打印班级点名表，查看哪些班级仍需录入出勤，使用趋势报告记录简单的人数统计，为每个礼拜时间设置签到时间表，使自助签到能在各校区所在时区自动开启和关闭，并允许首次到访的新人通过[二维码](./attendance/check-in.md#guest-registration-via-qr-code)登记，登记的字段由您选择
- **[奉献](./donations/index.md)**——以多种币种记录奉献（或在没有在线奉献的情况下以教会自己的币种记录），管理基金，从人员记录中登记单笔奉献，打印批次（一次一个或按日期范围打印全部批次），将基金小计打印在教会信头上，在批次清点完毕后关闭批次，从 CSV 文件导入批次，让清点小组凭借 **Enter Donations**（录入奉献）权限录入奉献，并生成印有教会徽标的奉献证明
- **[服事](./serving/index.md)**——协调志愿者，创建服事计划（或将计划每周复制，最多 12 周），通过推送、电子邮件或短信发送提醒，使用 **Text Volunteers**（短信通知志愿者）给所有已排班的人发短信，管理任务，并通过可以发送电子邮件和短信、通知工作人员、记录出勤以及跟踪志愿者是否确认服事安排的分步工作流来推进工作。定时的工作流规则可以找出已经停止奉献的定期捐赠人，打印的计划会省略空白列
- **[表单](./forms/index.md)**——为报名和数据收集创建自定义表单，添加页眉照片，通过二维码分享独立表单，并将表单关联到小组，让小组负责人阅读和打印回答
- **[报告](./reports/index.md)**——查看生日、出勤和奉献报告
- **[网站](./website/index.md)**——使用自定义导航样式建设和管理教会网站，通过 GA4 ID 追踪网站和 B1 应用的访问情况，或关闭公开网站，仅保留会员门户
- **[讲道](./sermons/index.md)**——管理讲道库、直播以及自动生成的播客订阅源
- **[日历](./calendars/index.md)**——创建按小组着色的策划日历，将其打印在教会信头上，管理房间/资源预订并查看可用情况。接受带价格参与者类型的[活动报名](./calendars/paid-registrations.md)，可手动添加参与者而不向其收费，并且在教会没有在线奉献时，允许人们先报名、后付款
- **[推送通知](./settings/push-notifications.md)**——向教会应用的所有用户或某个小组发送或定时发送推送通知，并可在发出前编辑、发送或取消，也可清理列表中的旧通知
- **[设置](./settings/index.md)**——在一个可滚动的页面上配置所有内容，并提供快速跳转列表：教会信息、地区、日期和电话号码格式、短信（包括您自己的 Twilio 账户）、带成员人数的角色、权限以及自定义人员字段

:::info
点击任意页面右上角的问号图标，即可快速访问帮助和文档。要更改颜色主题（**Default**、**Classic** 或 **Custom**）或在浅色和深色模式之间切换，请打开用户菜单并使用 **Theme Preferences**（主题偏好设置）。要使用身份验证器应用中的验证码保护您的账户，请在个人资料中开启[双重登录验证](./profile/managing-profile.md#two-factor-sign-in)。
:::
