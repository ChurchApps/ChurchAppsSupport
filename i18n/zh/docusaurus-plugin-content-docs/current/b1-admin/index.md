# B1 Admin概览

<div class="article-intro">

B1 Admin是您的教会管理仪表板。它提供工具来管理您的教会运营的各个方面——从成员目录和捐赠到网站建设和直播——所有这些都在一个地方。

</div>

## 开始使用

1. 打开您的浏览器并转到[admin.b1.church](https://admin.b1.church)
2. 使用您的用户名和密码登录
3. 您将落在**仪表板**上，这是您的主页。它显示本周的服务顺序、谁在实时签到和服务中、任何需要您注意的任务（如待批准的批准或加入请求）、您的小组和您的打开的任务

:::tip
初次接触B1 Admin？从[简介](./introduction)开始观看视频演练，然后访问[设置](./settings/)以配置您的教会信息并邀请您的团队。
:::

## 您的仪表板

仪表板是您的B1 Admin主页（`/`）。它围绕您的教会的每周服务构建：

- **本周的服务** ——当前或即将到来的计划的名称和服务顺序，带有进入完整计划的链接
- **实时状态** ——一旦人们周日开始签到，页面显示房间中有多少人、谁在这个小时服务、第一次来访的客人以及带有容量栏的按房间分类
- **需要注意** ——待批准的批准和需要采取行动的小组加入请求
- **您的小组**和**打开的任务** ——您属于的小组和分配给您或您的小组的任务

:::tip
讲道、日历、移动和设置仍然在顶部导航中只需单击一下。对于任何其他内容，按**Ctrl+K**（或**Cmd+K**）打开[命令面板](./introduction#finding-anything-quickly-with-the-command-palette)。
:::

## 主要功能

- **[人员](./people/)** - 管理您的教会目录、添加成员、批量编辑数据、跟踪家庭
- **[小组](./groups/)** - 创建和组织教会小组，包括加入请求、成员管理和小组电子邮件
- **[出席](./attendance/)** - 设置校园、服务时间、追踪命名出席并提供可打印的班级点名表，以及用趋势报告记录简单的人数
- **[捐赠](./donations/)** - 以多种货币记录捐赠、管理基金、生成报表
- **[服务](./serving/)** - 协调志愿者、创建服务计划、管理任务并通过分步工作流移动人员
- **[表单](./forms/)** - 为注册和数据收集构建自定义表单
- **[报告](./reports/)** - 查看生日、出席和捐赠报告
- **[网站](./website/)** - 构建和管理您的教会网站，支持自定义导航样式，或关闭公共网站并仅保留成员门户
- **[讲道](./sermons/)** - 管理您的讲道库、直播和自动播客提要
- **[日历](./calendars/)** - 创建策划日历、管理房间/资源预订并查看可用性
- **[设置](./settings/)** - 配置教会信息、角色、权限和自定义人员字段
