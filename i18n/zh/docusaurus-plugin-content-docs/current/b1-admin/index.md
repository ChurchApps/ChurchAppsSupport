# B1 Admin 概览

<div class="article-intro">

B1 Admin 是你的教会管理仪表板。它提供了管理教会各项运营的工具——从会员通讯录、奉献，到网站建设和在线直播——都集中在一处完成。

</div>

## 入门

1. 打开浏览器，访问 [admin.b1.church](https://admin.b1.church)
2. 使用你的用户名和密码登录
3. 你会进入 **Dashboard**（仪表板），即你的首页。它会显示本周的礼拜程序、实时签到和服事的人员、需要你关注的事项（例如待审批或加入申请），以及你待办的任务和所在的小组

:::tip
初次使用 B1 Admin？请先阅读[介绍](./introduction.md)，观看视频导览，然后访问[设置](./settings/index.md)来配置教会信息并邀请你的团队。
:::

## 你的仪表板

仪表板是你的 B1 Admin 首页（`/`），围绕教会每周的礼拜而设计：

- **本周礼拜** —— 当前或即将到来的计划名称和礼拜程序，并可链接至完整计划
- **实时状态** —— 星期日人们开始签到后，页面会显示厅内人数、本时段在服事的人员、首次到访的访客，以及带有容量进度条的逐房间明细
- **需要关注** —— 需要处理的待审批事项和小组加入申请
- **我的任务**和**我的小组** —— 你待办的任务（点击 **Add Task** 添加，或点击 **All tasks** 查看完整列表）以及你所属的小组

仪表板显示的内容取决于你的[角色](./settings/roles-permissions.md)。例如，只有当你有权打开该计划（即你可以编辑计划、属于该计划的事工，或正在为其服事）时，才会出现通往完整计划的链接；只有当你有权管理小组、查看小组成员或查看人员时，才会出现 **All groups** 链接。

:::tip
所有板块（包括讲道、日历、移动端和设置）都可以通过 B1 Admin 左上角的[快速跳转菜单](./introduction.md#getting-around-with-the-jump-menu)找到。点击它或按下 **Ctrl+K**（或 **Cmd+K**），然后浏览或直接输入即可。
:::

## 主要功能

- **[人员](./people/index.md)** —— 管理教会通讯录、添加成员、批量编辑数据，并可按家庭浏览或以可排序的表格查看。每位人员都有一个统一的资料页，左侧为详细信息，右侧为出勤、奉献、小组、备注和表单的摘要。可通过 **Date Added** 搜索查找最近添加的人员。[备注](./people/notes.md)页面会列出人员、小组、活动和工作流卡片的近期备注
- **[小组](./groups/index.md)** —— 创建并组织教会小组，支持加入申请、成员管理、小组电子邮件、使用可重复使用的短信模板并带有小组名称占位符的个性化小组短信，以及可打印的联系人名册。每个小组都有一个统一的页面，左侧为操作按钮，右侧为成员、场次、日历和健康度摘要
- **[出勤](./attendance/index.md)** —— 设置校区和礼拜时间，追踪具名出勤并可打印班级点名表，查看哪些班级仍需录入出勤，记录简单的人数统计并生成趋势报表；为每个礼拜时间设置签到计划，使自助签到能够按各校区所在时区自动开放和关闭；并允许首次到访的访客通过[二维码](./attendance/check-in.md#guest-registration-via-qr-code)进行登记，登记字段可由你自行选择
- **[奉献](./donations/index.md)** —— 以多种货币记录奉献，管理基金，从人员资料中记录单笔奉献，在教会信纸上打印批次（一次一个，或打印某日期范围内的所有批次）并附带基金小计，清点后关闭批次，从 CSV 文件导入批次，让清点团队使用 **Enter Donations** 权限录入奉献，并生成印有教会标志的奉献报表
- **[服事](./serving/index.md)** —— 协调志愿者，创建礼拜计划（或每周向前复制一份，最多 12 周），通过推送、电子邮件或短信发送提醒，使用 **Text Volunteers** 向所有已排班人员发送短信，管理任务，并通过分步工作流推进人员流程——工作流可以发送电子邮件和短信、通知工作人员、记录出勤，并追踪志愿者是否确认了其服事安排。定时工作流规则可以找出已停止奉献的定期奉献者，打印的计划也会省略空白列
- **[表单](./forms/index.md)** —— 创建用于报名和收集数据的自定义表单，添加页眉照片，通过二维码分享独立表单，并将表单关联到小组，使小组负责人可以阅读和打印答复
- **[报表](./reports/index.md)** —— 查看生日、出勤和奉献报表
- **[网站](./website/index.md)** —— 建设和管理教会网站，可自定义导航样式，使用 GA4 ID 追踪网站和 B1 应用的访问情况，也可关闭公开网站，仅保留成员门户
- **[讲道](./sermons/index.md)** —— 管理讲道资料库、在线直播，以及自动生成的播客订阅源
- **[日历](./calendars/index.md)** —— 创建精选日历，管理房间/资源预订，并查看可用时间。开展带有定价参与者类型的[活动报名](./calendars/paid-registrations.md)，可手动添加参与者而不收费，并且当教会没有在线奉献时，允许人们先报名、稍后付款
- **[设置](./settings/index.md)** —— 在一个可滚动的页面中完成所有配置，并提供快速跳转列表：教会信息、地区、日期和电话号码格式、短信（包括你自己的 Twilio 账户）、带有成员人数的角色、权限，以及自定义人员字段

:::info
点击页面右上角的问号图标，可快速访问帮助和文档。若要更改颜色主题（**Default**、**Classic** 或 **Custom**）或在浅色和深色模式之间切换，请打开用户菜单并使用 **Theme Preferences**（主题偏好设置）。若要通过身份验证器应用中的验证码保护你的账号，请在个人资料中开启[两步验证登录](./profile/managing-profile.md#two-factor-sign-in)。
:::
