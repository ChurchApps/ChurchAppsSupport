# B1 Admin概览

<div class="article-intro">

B1 Admin是你的教会管理仪表板。它提供工具来管理教会运营的各个方面——从成员目录和捐赠到网站建设和直播——所有这些都在一个地方。

</div>

## 快速开始

1. 打开你的浏览器并转到[admin.b1.church](https://admin.b1.church)
2. 用你的用户名和密码登录
3. 你将进入**仪表板**,这是你的主页。它显示本周的敬拜顺序,谁在实时签到和服侍中,任何需要你注意的事项(如待批准的请求或加入请求),你的待办任务,以及你的小组

:::tip
初次接触B1 Admin?从[简介](./introduction)开始观看视频演练,然后访问[设置](./settings/)以配置你的教会信息并邀请你的团队。
:::

## 你的仪表板

仪表板是你的B1 Admin主页(`/`)。它围绕教会的每周敬拜构建:

- **本周的敬拜** -- 当前或即将到来的计划的名称和敬拜顺序,带有进入完整计划的链接
- **实时状态** -- 一旦人们在周日开始签到,页面显示房间中有多少人、谁在这个小时服侍、第一次来访的客人以及按房间分类的容量条
- **需要注意** -- 待批准的请求和需要采取行动的小组加入请求
- **我的任务**和**我的小组** -- 你的待办任务（点击**添加任务**可新增一个，或点击**所有任务**查看完整列表）和你属于的小组

:::tip
讲道、日历、移动和设置都在左上角的[Jump 菜单](./introduction.md#getting-around-with-the-jump-menu)中。点击它或按**Ctrl+K**(或**Cmd+K**),然后浏览或开始输入。
:::

## 主要功能

- **[人员](./people/)** - 管理教会目录、添加成员、批量编辑数据，并可按家庭浏览或以可排序表格查看。每位人员的页面左侧显示其详细信息，右侧显示出席、奉献、小组、备注和表单的摘要
- **[小组](./groups/)** - 创建和组织教会小组,包括加入请求、成员管理、小组电子邮件、个性化小组短信和可打印的联系人名册。每个小组的页面左侧为操作，右侧显示成员、场景、日历和健康摘要
- **[出席](./attendance/)** - 设置校园、敬拜时间、追踪命名出席和可打印的班级点名表,用趋势报告记录简单的人数，查看哪些班级仍需录入出席，并为每个敬拜时间设置签到时间表，使自助签到自动开放和关闭
- **[捐赠](./donations/)** - 以多种货币记录捐赠、管理基金、在个人记录中记录单笔捐款、打印带有基金小计的批次（一次一个，或日期范围内的所有批次）、生成印有教会标志的报表
- **[服侍](./serving/)** - 协调志愿者、创建敬拜计划（或每周复制一个计划，最多 12 周）、通过推送、电子邮件或短信发送提醒、使用**向志愿者发送短信**向所有已排班人员发送短信、管理任务和通过分步工作流移动人员,这些可以自动发送电子邮件和短信
- **[表单](./forms/)** - 为注册和数据收集构建自定义表单
- **[报告](./reports/)** - 查看生日、出席和捐赠报告
- **[网站](./website/)** - 构建和管理教会网站,支持自定义导航样式，使用 GA4 ID 追踪网站和 B1 应用的访问情况，或关闭公共网站并仅保留成员门户
- **[讲道](./sermons/)** - 管理讲道库、直播和自动播客提要
- **[日历](./calendars/)** - 创建策划日历、管理房间/资源预订并查看可用性
- **[设置](./settings/)** - 在一个可滚动页面中配置所有内容（配有快速跳转列表）：教会信息、地区、日期和电话号码格式、短信、角色、权限和自定义人员字段

:::info
点击任何页面右上角的问号图标可快速访问帮助和文档。要在浅色和深色模式之间切换，请打开用户菜单并选择**主题偏好**。
:::
