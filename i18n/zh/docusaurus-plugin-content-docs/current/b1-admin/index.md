# B1 Admin 概览

<div class="article-intro">

B1 Admin 是您的教会管理仪表板。它提供了管理教会运营各个方面的工具——从会众名录、奉献到网站建设和直播——都可以在一个地方完成。

</div>

## 入门

1. 打开浏览器，访问 [admin.b1.church](https://admin.b1.church)
2. 使用您的用户名和密码登录
3. 您会进入**仪表板**，即您的首页。它会显示本周的礼拜程序、实时签到和服事人员情况、需要您关注的事项（例如待审批事项或入组申请）、您的待办任务以及您所在的小组

:::tip
初次使用 B1 Admin？请先阅读[介绍](./introduction)，观看视频教程，然后访问[设置](./settings/)以配置教会信息并邀请您的团队。
:::

## 您的仪表板

仪表板是您的 B1 Admin 首页（`/`）。它围绕教会的每周礼拜进行设计：

- **本周礼拜** -- 当前或即将到来的服事计划名称和礼拜程序，并附有进入完整计划的链接
- **实时状态** -- 周日人们开始签到后，页面会显示当前在场人数、此时段的服事人员、首次到访的访客，以及带有容量进度条的各房间明细
- **需要关注** -- 需要处理的待审批事项和小组入组申请
- **我的任务**和**我的小组** -- 您未完成的任务（点击 **Add Task** 添加，或点击 **All tasks** 查看完整列表）以及您所属的小组

:::tip
包括 Sermons、Calendars、Mobile 和 Settings 在内的所有板块，都可以在 B1 Admin 左上角的[快速跳转菜单](./introduction.md#getting-around-with-the-jump-menu)中找到。点击它或按 **Ctrl+K**（或 **Cmd+K**），然后浏览或直接输入即可。
:::

## 主要功能

- **[人员（People）](./people/)** -- 管理教会名录、添加成员、批量编辑数据，并可按家庭或以可排序的表格浏览。每位人员都有一个独立的档案页面，左侧显示其详细信息，右侧显示考勤、奉献、小组、备注和表单的摘要
- **[小组（Groups）](./groups/)** -- 创建和组织教会小组，支持入组申请、成员管理、小组邮件、个性化小组短信以及可打印的联系名单。每个小组都有一个页面，左侧为操作区，右侧为成员、课次、日程和健康状况的摘要
- **[考勤（Attendance）](./attendance/)** -- 设置校区、礼拜时间，记录实名考勤并打印班级点名表，查看哪些班级仍需录入考勤，记录简单的人数统计并查看趋势报告，还可为每个礼拜时间设置签到时间表，使自助签到自动开放和关闭
- **[奉献（Donations）](./donations/)** -- 支持多种货币录入奉献，管理基金，在人员档案中单独记录一笔奉献，打印批次（逐个打印或打印某日期范围内的所有批次）并附带基金小计，生成印有教会标志的奉献报表
- **[服事（Serving）](./serving/)** -- 协调志愿者，创建服事计划（或每周向前复制最多 12 周），通过推送、电子邮件或短信发送提醒，使用**Text Volunteers**群发短信给所有已排班的人员，管理任务，并通过可自动发送电子邮件和短信的分步工作流推进事务
- **[表单（Forms）](./forms/)** -- 创建用于报名和数据收集的自定义表单
- **[报告（Reports）](./reports/)** -- 查看生日、考勤和奉献报告
- **[网站（Website）](./website/)** -- 搭建和管理教会网站，自定义导航样式，使用 GA4 ID 追踪网站和 B1 应用的访问情况，或关闭公开网站，仅保留会员门户
- **[讲道（Sermons）](./sermons/)** -- 管理讲道库、直播以及自动生成的播客订阅源
- **[日历（Calendars）](./calendars/)** -- 创建精选日历，管理房间/资源预订，并查看可用情况
- **[设置（Settings）](./settings/)** -- 在一个可滚动的页面中完成所有配置，并提供快速跳转列表：教会信息、地区、日期和电话号码格式、短信、角色、权限以及自定义人员字段

:::info
点击任意页面右上角的问号图标，即可快速访问帮助和文档。要更改颜色主题（**Default**、**Classic** 或 **Custom**）或在浅色和深色模式之间切换，请打开用户菜单并使用 **Theme Preferences**。
:::
