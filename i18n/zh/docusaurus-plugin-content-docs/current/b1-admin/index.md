# B1 Admin 概览

<div class="article-intro">

B1 Admin 是您的教会管理仪表板，提供管理教会运营各个方面的工具——从会员名录、奉献，到网站搭建和直播——一切都在同一个地方完成。

</div>

## 开始使用

1. 打开浏览器并访问 [admin.b1.church](https://admin.b1.church)
2. 使用您的用户名和密码登录
3. 您将进入**仪表板**，其中概览了教会数据，并提供**快速操作**，方便完成添加人员、创建小组、记录捐款等常见任务

:::tip
初次使用 B1 Admin？先阅读[简介](./introduction)观看视频演示，然后访问[设置](./settings/)配置教会信息并邀请团队成员。
:::

## 主要功能

- **[人员](./people/)** - 管理教会名录、添加成员、批量编辑数据、跟踪家庭
- **[小组](./groups/)** - 创建和组织教会小组，处理加入申请和成员管理
- **[考勤](./attendance/)** - 设置堂点、聚会时间，并跟踪考勤
- **[奉献](./donations/)** - 以多种货币记录捐款、管理基金、生成报表
- **[服事](./serving/)** - 协调志愿者、创建服事计划、管理任务，并通过分步流程引导人员
- **[表单](./forms/)** - 为注册和数据收集构建自定义表单
- **[报表](./reports/)** - 查看生日、考勤和捐款报表
- **[网站](./website/)** - 使用自定义导航样式构建和管理教会网站
- **[讲道](./sermons/)** - 管理讲道库和直播
- **[日历](./calendars/)** - 创建精选日历、管理房间/资源预订，并查看可用性
- **[设置](./settings/)** - 配置教会信息、角色、权限和自定义人员字段
