# B1 Admin 概览

<div class="article-intro">

B1 Admin 是您的教会管理仪表板。它提供各种工具，用于管理教会运营的方方面面——从会众通讯录和奉献到网站搭建和直播——所有功能都集中在一个地方。

</div>

## 入门

1. 打开浏览器，访问 [admin.b1.church](https://admin.b1.church)
2. 使用您的用户名和密码登录
3. 您将进入 **Dashboard（仪表板）**，即您的首页。它会显示本周的礼拜程序、实时签到和服事人员、需要您关注的事项（例如待审批事项或加入申请）、您的待办任务，以及您的小组

:::tip
初次使用 B1 Admin？请先阅读[简介](./introduction)观看视频教程，然后访问[设置](./settings/)以配置您的教会信息并邀请团队成员。
:::

## 您的仪表板

仪表板是您的 B1 Admin 首页（`/`）。它围绕教会的每周礼拜构建：

- **本周礼拜（This week's service）**——当前或即将到来的计划名称和礼拜程序，并附有进入完整计划的链接
- **实时状态（Live status）**——主日开始签到后，页面会显示现场人数、当前时段的服事人员、初次到访的访客，以及各房间的容量进度条明细
- **需要关注（Needs Attention）**——需要处理的待审批事项和小组加入申请
- **我的任务（My tasks）**和**我的小组（My Groups）**——您的未完成任务（可点击 **Add Task（添加任务）**添加新任务，或点击 **All tasks（全部任务）**查看完整列表）以及您所属的小组

仪表板显示的内容取决于您的[角色](./settings/roles-permissions.md)。例如，只有当您有权打开该计划（您可以编辑计划、属于该计划的事工，或正在参与该计划的服事）时，才会显示进入完整计划的链接；只有当您有权管理小组、查看小组成员或查看人员时，才会显示 **All groups（全部小组）**链接。

:::tip
包括讲道、日历、移动端和设置在内的每个板块，都可以在 B1 Admin 左上角的[跳转菜单](./introduction.md#getting-around-with-the-jump-menu)中找到。点击它或按 **Ctrl+K**（或 **Cmd+K**），然后浏览或直接输入以搜索。
:::

## 主要功能

- **[人员（People）](./people/)**——管理您的教会通讯录、添加成员、批量编辑数据，并可按家庭或以可排序的表格浏览。每个人都有一个个人记录页面，左侧显示其详细信息，右侧显示出勤、奉献、小组、笔记和表单的摘要。[笔记（Notes）](./people/notes)页面会列出人员、小组、活动和工作流卡片的近期笔记
- **[小组（Groups）](./groups/)**——创建和组织教会小组，支持加入申请、成员管理、小组邮件、个性化小组短信以及可打印的联系名册。每个小组都有一个页面，左侧是其操作，右侧是成员、课程、日历和健康状况的摘要
- **[出勤（Attendance）](./attendance/)**——设置校区和礼拜时间，记录具名出勤并打印班级点名表，查看哪些班级仍需录入出勤，记录简单的人数统计并生成趋势报告，为每个礼拜时间设置签到时段，使自助签到能够根据各校区所在时区自动开启和关闭，并允许初次到访的访客通过[二维码](./attendance/check-in#guest-registration-via-qr-code)登记，登记字段由您自行选择
- **[奉献（Donations）](./donations/)**——以多种货币记录奉献，管理基金，记录个人的单笔奉献，打印批次（一次一个，或某一日期范围内的所有批次）并附基金小计，在清点完成后关闭批次，从 CSV 文件导入批次，允许计数团队使用**录入奉献（Enter Donations）**权限录入奉献，并生成印有教会徽标的奉献证明
- **[服事（Serving）](./serving/)**——协调志愿者，创建服事计划（或每周向前复制最多 12 周），通过推送、电子邮件或短信发送提醒，使用**短信志愿者（Text Volunteers）**向所有已排班人员发送短信，管理任务，并通过分步工作流推动人员完成流程，工作流可以发送电子邮件和短信、通知工作人员、记录出勤，以及跟踪志愿者是否确认了其服事安排
- **[表单（Forms）](./forms/)**——构建用于报名和数据收集的自定义表单，添加页眉图片，通过二维码分享独立表单，并将表单关联到小组，使其负责人能够阅读和打印答案
- **[报告（Reports）](./reports/)**——查看生日、出勤和奉献报告
- **[网站（Website）](./website/)**——搭建和管理您的教会网站，自定义导航样式，使用您的 GA4 ID 跟踪网站和 B1 应用的访问情况，或关闭公开网站，仅保留成员门户
- **[讲道（Sermons）](./sermons/)**——管理您的讲道库、直播以及自动生成的播客订阅源
- **[日历（Calendars）](./calendars/)**——创建精选日历，管理房间/资源预订，并查看可用情况
- **[设置（Settings）](./settings/)**——在一个可滚动的页面中完成所有配置，并提供快速跳转列表：教会信息、地区、日期和电话号码格式、短信（包括您自己的 Twilio 账户）、带成员人数的角色、权限，以及自定义人员字段

:::info
点击任意页面右上角的问号图标，即可快速访问帮助和文档。若要更改颜色主题（**Default（默认）**、**Classic（经典）**或 **Custom（自定义）**）或在浅色与深色模式之间切换，请打开用户菜单并使用 **Theme Preferences（主题偏好设置）**。
:::
