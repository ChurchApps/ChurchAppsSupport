# B1 Admin 概览

<div class="article-intro">

B1 Admin 是你的教会管理仪表板。它提供各种工具，管理教会运作的每一个环节——从通讯录、奉献到网站建设与直播——全部集中在一个地方。

</div>

## 入门 {#getting-started}

1. 打开浏览器，前往 [admin.b1.church](https://admin.b1.church)
2. 使用你的用户名和密码登录
3. 你会进入你的首页**仪表板**。它会显示本周的礼拜程序、实时的报到与服事人员、需要你处理的事项（例如待审批的项目或入会申请）、你未完成的任务，以及你所在的小组

:::tip
初次使用 B1 Admin？请先阅读[简介](./introduction.md)观看视频导览，然后前往[设置](./settings/index.md)配置教会资料并邀请你的团队。
:::

## 你的仪表板 {#your-dashboard}

[仪表板](./dashboard.md)是你的 B1 Admin 首页（`/`），主要围绕教会的每周礼拜设计：

- **本周礼拜**——当前或即将到来的计划名称与礼拜程序，并附有前往完整计划的链接
- **实时状态**——当人们在主日开始报到后，页面会显示目前在场的人数、此时段的服事人员、初次到访的访客，以及各场地的人数与容量条
- **需要处理**——需要你采取行动的待审批日历项目和小组入会申请
- **我的任务**与**我的小组**——你未完成的任务（点击 **Add Task** 新增，或点击 **All tasks** 查看完整列表）以及你所属的小组

仪表板显示的内容取决于你的[角色](./settings/roles-permissions.md)。详情请参阅[仪表板](./dashboard.md)。你的通知与私人消息位于右上角的用户菜单中，请参阅[通知与消息](./notifications.md)。

:::tip
所有区域（包括讲道、日历、手机应用和设置）都位于 B1 Admin 左上角的[快速菜单](./introduction.md#getting-around-with-the-jump-menu)中。点击它或按下 **Ctrl+K**（或 **Cmd+K**），即可浏览或直接开始输入。
:::

## 主要功能 {#key-features}

- **[人员](./people/index.md)**——管理教会通讯录、新增会员、批量编辑数据，并可按家庭或以可排序的表格浏览。每位人员都有一个个人资料页，左侧为详细资料，右侧则是出席、奉献、小组、备注与表格的摘要。使用 **Date Added** 搜索可找到最近新增的人员。[备注](./people/notes.md)页面会列出人员、小组、活动与工作流程卡片上的最新备注
- **[小组](./groups/index.md)**——建立并管理教会小组，支持入会申请、成员管理、小组电子邮件、使用可重复使用的短信模板及 Group Name 占位符发送个性化小组短信，并可打印联络名册。每个小组都有一个页面，左侧为操作项目，右侧则是成员、聚会、日历与健康状况的摘要
- **[出席](./attendance/index.md)**——设置堂会与礼拜时间，记录具名出席并可打印班级点名表，查看哪些班级仍待登记出席，记录简单的人数并查看趋势报表；为每个礼拜时间设置报到时段，让自助报到能依各堂会所在时区自动开启与关闭；并让初次到访的访客通过[二维码](./attendance/check-in.md#guest-registration-via-qr-code)报名，所填写的栏位由你自行选择
- **[奉献](./donations/index.md)**——以多种货币记录奉献（或在未使用线上奉献时以教会自己的货币记录），管理基金，从人员的个人资料中记录单笔奉献，打印批次（逐一或按日期范围打印全部批次），并以教会信头打印并附有基金小计，计数完成后关闭批次，从 CSV 文件导入批次，允许计数团队凭 **Enter Donations** 权限输入奉献，并生成印有教会标志的奉献证明
- **[服事](./serving/index.md)**——协调志愿者、建立服事计划（或复制一份计划，一次设置多达 12 个，并可按日、周或月重复），通过推送通知、电子邮件或短信发送提醒，使用 **Text Volunteers** 向所有已排班的人员发送短信，管理任务，并以逐步的工作流程推动人员完成各项流程，工作流程可发送电子邮件与短信、通知工作人员、记录出席，并追踪志愿者是否确认其服事安排。排程的工作流程规则可找出已停止奉献的定期奉献者，打印的计划也会省略空白栏位
- **[表格](./forms/index.md)**——建立用于报名与资料收集的自定义表格，添加标题图片，以二维码分享独立表格，并将表格连接到小组，使其负责人能阅读与打印回复内容
- **[报表](./reports/index.md)**——查看生日、出席与奉献报表，这些报表位于人员、出席与奉献区域之中，另外设置中还有审计日志
- **[网站](./website/index.md)**——建立并管理教会网站，可自定义导航样式，并以你的 GA4 ID 追踪网站与 B1 应用程序的访问情况，或关闭公开网站，仅保留会员门户
- **[讲道](./sermons/index.md)**——管理讲道资料库、直播，以及自动生成的播客订阅源
- **[日历](./calendars/index.md)**——建立精选日历，活动依小组以颜色区分，[更改或取消重复活动的某一天](./calendars/creating-calendars.md#changing-one-date-of-a-recurring-event)，可印在教会信头上，管理场地与资源预订，并查看可用时间。开放[活动报名](./calendars/paid-registrations.md)并设置收费的参与者类型，可手动添加不收费的参与者，并在教会未提供线上奉献时，让人们先报名、稍后再付款
- **[手机](./settings/mobile-app.md)**——设置教会 B1 应用程序的导航标签、主题与主画面，设置 B1 Checkin 应用程序及其标签，并向所有使用应用程序的人员或某个小组发送或排程[推送通知](./settings/mobile-app.md#push-notifications)
- **[设置](./settings/index.md)**——在一个可滚动的页面中完成所有配置，并附有快速跳转列表：教会资料、地区、日期与电话号码格式、短信功能（包括你自己的 Twilio 账户）、附有会员人数的角色、权限，以及自定义的人员栏位
- **[整合](./integrations/index.md)**——将活动发布到 Slack 或 Discord，同步 Mailchimp 受众名单，连接 Zapier，并使用 **Settings > Developer** 下的 API 密钥与 webhook，向 Claude 或 ChatGPT 查询你的教会资料

:::info
点击任何页面右上角的问号图标，即可快速查看帮助与文档。若要更改颜色主题（**Default**、**Classic** 或 **Custom**）或在浅色与深色模式之间切换，请打开用户菜单并使用 **Theme Preferences**。若要用身份验证应用程序产生的验证码保护你的账户，请在个人资料中开启[双重验证登录](./profile/managing-profile.md#two-factor-sign-in)。
:::
