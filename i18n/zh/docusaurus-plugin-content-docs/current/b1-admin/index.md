# B1 Admin 概览

<div class="article-intro">

B1 Admin 是您的教会管理仪表板。它提供了管理教会运营各个方面的工具——从会众名录、奉献到网站建设和直播——都可以在一个地方完成。

</div>

## 入门

1. 打开浏览器，访问 [admin.b1.church](https://admin.b1.church)
2. 使用您的用户名和密码登录
3. 您将进入**仪表板**，即您的主页。它会显示本周的服事程序、实时的签到和服事人员、需要您关注的事项（例如待审批或加入申请），以及您的待办任务和小组

:::tip
初次使用 B1 Admin？请先阅读[入门介绍](./introduction)，观看视频导览，然后访问[设置](./settings/)来配置教会信息并邀请您的团队。
:::

## 您的仪表板

仪表板是您的 B1 Admin 主页（`/`）。它围绕教会的每周服事构建：

- **本周服事** —— 当前或即将到来的计划名称和服事程序，并附有进入完整计划的链接
- **实时状态** —— 周日人们开始签到后，页面会显示现场人数、此时段的服事人员、首次到访的访客，以及带有容量进度条的逐房间明细
- **需要关注** —— 需要处理的待审批事项和小组加入申请
- **我的任务**和**我的小组** —— 您的待办任务（点击**添加任务**即可新增，或点击**全部任务**查看完整列表）以及您所属的小组

仪表板显示的内容取决于您的[角色](./settings/roles-permissions.md)。例如，只有当您有权打开该计划（您可以编辑计划、属于该计划所属的事工，或正在为该计划服事）时，才会出现进入完整计划的链接；只有当您有权管理小组、查看小组成员或查看人员时，才会出现**全部小组**链接。

:::tip
包括讲道、日历、移动端和设置在内的每个板块，都可以通过 B1 Admin 左上角的 [Jump 菜单](./introduction.md#getting-around-with-the-jump-menu)找到。点击它或按 **Ctrl+K**（或 **Cmd+K**），然后浏览或直接开始输入。
:::

## 主要功能

- **[人员](./people/)** - 管理教会名录、添加成员、批量编辑数据，并可按家庭或以可排序的表格浏览。每个人都有一个个人记录页面，左侧显示其详细信息，右侧汇总了出勤、奉献、小组、备注和表单
- **[小组](./groups/)** - 创建和组织教会小组，支持加入申请、成员管理、小组电子邮件、个性化小组短信，以及可打印的联系人名册。每个小组都有一个页面，左侧为其操作，右侧汇总了成员、聚会、日历和健康状况
- **[出勤](./attendance/)** - 设置校区和服事时间，记录具名出勤并可打印班级点名表，查看哪些班级仍需录入出勤，使用趋势报告记录简单的人数统计，并为每个服事时间设置签到时间表，使自助签到能够自动开放和关闭
- **[奉献](./donations/)** - 以多种货币记录奉献、管理基金，从人员记录中记录单笔奉献，逐批或按日期范围打印批次（含各基金小计），在清点完成后关闭批次，使用**录入奉献**权限让计数团队录入奉献，并生成印有教会 Logo 的对账单
- **[服事](./serving/)** - 协调志愿者、创建服事计划（或将计划每周复制，最多 12 周）、通过推送、电子邮件或短信发送提醒，使用**短信联系志愿者**向所有已排班人员发送短信，管理任务，并通过可自动发送电子邮件和短信的分步工作流推进事项
- **[表单](./forms/)** - 构建用于报名和数据收集的自定义表单
- **[报告](./reports/)** - 查看生日、出勤和奉献报告
- **[网站](./website/)** - 构建和管理教会网站，自定义导航样式，使用 GA4 ID 跟踪网站和 B1 应用的访问情况，或关闭公开网站、仅保留会员门户
- **[讲道](./sermons/)** - 管理讲道库、直播，以及自动生成的播客订阅源
- **[日历](./calendars/)** - 创建精选日历、管理房间/资源预订，并查看可用情况
- **[设置](./settings/)** - 在一个可滚动页面中配置所有内容，并提供快速跳转列表：教会信息、地区、日期和电话号码格式、短信、角色、权限以及自定义人员字段

:::info
点击任意页面右上角的问号图标，即可快速访问帮助和文档。要更改颜色主题（**默认**、**经典**或**自定义**）或在浅色和深色模式之间切换，请打开用户菜单，然后使用**主题偏好设置**。
:::
