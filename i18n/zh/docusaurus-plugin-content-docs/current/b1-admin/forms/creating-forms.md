# 创建表单

<div class="article-intro">

创建自定义表单，以便从您的会众中收集信息。您可以创建活动注册、调查、访客卡、会员申请等表单。表单可以关联到您数据库中的人员，也可以作为拥有独立公开 URL 的独立页面使用。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 对于**人员**表单（关联到人员记录），您需要先[在数据库中添加人员](../people/adding-people.md)。
- 对于收取**付款**的表单，您必须先[为在线捐献配置 Stripe](../donations/online-giving-setup.md)。

</div>

## 创建新表单 {#creating-a-new-form}

1. 打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开**人员**，然后点击**表单**。
2. 点击**添加表单**。
3. 输入表单的**名称**。
4. 从下拉菜单中选择表单类型：
   - **人员** — 将提交内容关联到数据库中的[人员记录](../people/adding-people.md)。
   - **独立** — 创建一个拥有自己公开 URL 的独立表单，适用于外部注册。
5. 点击**保存**以创建表单。

新表单将出现在列表中。点击它即可开始添加问题。

## 打印空白表单 {#printing-a-blank-form}

需要一份纸质副本来分发——例如欢迎台使用的访客卡，或者供没有网络的人手写填写的表单？请在表单主列表中点击表单旁边的**打印**以打开预览，然后点击**打印**。空白字段会为每个问题打印下划线或复选框，方便人们手写填写；必填问题会标有星号。页面顶部会显示您的教会标志（如果您上传过，则为来自[网站 > 外观](../website/appearance.md)的**浅色背景标志**），其下是教会名称，再下面是表单名称。没有其他打印选项——只能打印整个表单，或者不打印。

## 添加问题 {#adding-questions}

1. 打开您的表单，并进入**问题**选项卡。
2. 点击**添加问题**。
3. 从提供商下拉菜单中选择**字段类型**。可用类型包括：
   - **文本框** — 用于简短的文字回答
   - **日期** — 用于日期选择
   - **电子邮件** — 用于电子邮件地址
   - **电话号码** — 用于电话号码输入
   - **多选** — 用于从预设选项中选择
   - **付款** — 用于收取付款
4. 输入问题的**标题**和可选的**描述**。
5. 如果该字段为必填项，请勾选**需要回答**。
6. 点击**保存**。
7. 重复以上步骤添加更多问题。

:::warning
**付款**字段类型需要配置 Stripe。如果您尚未设置在线捐献，请在添加付款字段之前参阅[在线捐献设置](../donations/online-giving-setup.md)。
:::

## 管理表单成员 {#managing-form-members}

1. 打开您的表单，并进入**表单成员**选项卡。
2. 搜索某人，并以角色身份添加：
   - **管理员** — 可以编辑表单并查看所有提交内容。
   - **仅查看** — 可以查看提交内容，但不能编辑表单。

## 自动将提交者添加到组 {#automatically-adding-submitters-to-a-group}

启用**从提交创建人员记录**后，您还可以将表单关联到某个组，使每位提交者都自动添加到该组的名单中：

1. 打开表单的**详情**，并开启**从提交创建人员记录**。
2. 在**将提交者添加到组**下，选择要添加提交者的组，或保持为**无**。
3. 点击**保存**。

每当有人提交表单时，匹配到的或新创建的人员都会被添加到该组（已在组中的成员会被跳过）。这对于营地报名表之类的情况很有用，可以自动建立营地的名单组。

### 发送后续电子邮件 {#sending-a-follow-up-email}

启用**从提交创建人员记录**后，您还可以向每位提交表单的人发送电子邮件。在表单的**详情**中填写**后续电子邮件主题**和**后续电子邮件正文**。两处都可以使用 `{firstName}` 和 `{churchName}` 令牌。只有两个字段都已填写时才会发送电子邮件。

:::info
后续电子邮件只有在您的教会获准发送群组电子邮件后才会发出，并且会计入教会的每日电子邮件上限。参阅[为您的教会开启群组电子邮件](../groups/group-members.md#turning-on-group-email-for-your-church)。
:::

## 复制表单 {#duplicating-a-form}

若要以某个表单为起点创建新表单，请在表单列表中点击该表单旁边的**复制**并确认。B1 会创建一份完全相同的表单副本（包括所有问题），之后您可以独立地重命名和编辑它。

:::tip
复制功能适用于定期举办的活动，且每年的注册问题基本保持不变。复制去年的表单，更新名称和日期，即可开始使用。
:::

## 配置表单属性 {#configuring-form-properties}

您可以随时更新表单的名称和设置。对于独立表单，您还会看到一个唯一的**公开 URL**，可以分享给任何人，同时还有**描述**字段——即显示在公开表单页面问题上方的文字，用于在人们开始填写前说明表单的用途。

使用**感谢信息**字段可设置人们提交表单后看到的内容，包括在表单的公开 URL 页面上。如果留空，他们将看到“Thank you for submitting the form!”。

:::tip
独立表单非常适合活动注册。您可以通过电子邮件或社交媒体分享公开 URL，也可以直接将表单嵌入您的教会网站。
:::

:::info
要在您的 B1 网站上嵌入表单，请进入网站编辑器，添加新板块，并选择**表单**元素。然后选择要显示的表单。有关编辑网站的详细信息，请参阅[管理页面](../website/managing-pages.md)。
:::
