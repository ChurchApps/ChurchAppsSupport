# 创建表单

<div class="article-intro">

构建自定义表单以从您的会众中收集信息。您可以为事件注册、调查、访客卡、成员申请等创建表单。表单可以链接到数据库中的人员或用作具有自己公共 URL 的独立页面。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 对于**人员**表单（链接到人员记录），您首先需要[数据库中的人员](../people/adding-people.md)。
- 对于收集**付款**的表单，您必须[配置 Stripe 用于在线捐赠](../donations/online-giving-setup.md)。

</div>

## 创建新表单

1. 从主菜单导航到**表单**。
2. 点击**添加表单**。
3. 为您的表单输入**名称**。
4. 从下拉菜单中选择表单类型：
   - **人员** — 将提交与数据库中的[人员记录](../people/adding-people.md)关联。
   - **独立** — 创建独立表单，有自己的公共 URL，非常适合外部注册。
5. 点击**保存**以创建表单。

您的新表单会出现在列表中。单击它以开始添加问题。

## 添加问题

1. 打开您的表单并转到**问题**标签。
2. 点击**添加问题**。
3. 从提供商下拉菜单中选择**字段类型**。可用类型包括：
   - **文本框** — 用于简短文本答案
   - **日期** — 用于日期选择
   - **电子邮件** — 用于电子邮件地址
   - **电话号码** — 用于电话输入
   - **多项选择** — 用于从预定义选项中选择
   - **付款** — 用于收取付款
4. 输入问题的**标题**和可选**描述**。
5. 如果字段是必需的，请选中**需要答案**。
6. 点击**保存**。
7. 重复以添加更多问题。

:::warning
**付款**字段类型需要配置 Stripe。如果您还没有设置在线捐赠，请在添加付款字段之前参见[在线捐赠设置](../donations/online-giving-setup.md)。
:::

## 管理表单成员

1. 打开您的表单并转到**成员**标签。
2. 搜索一个人并添加他们与一个角色：
   - **管理员** — 可以编辑表单并查看所有提交。
   - **仅查看** — 可以查看提交但无法编辑表单。

## 自动将提交者添加到小组

启用**从提交中创建人员记录**时，您也可以将表单链接到小组，以便每个提交者都自动添加到该小组的名单中：

1. 打开您的表单的**详情**，并打开**从提交中创建人员记录**。
2. 在**将提交者添加到小组**下，选择要添加提交者的小组，或将其保留为**无**。
3. 点击**保存**。

每次有人提交表单时，匹配或新创建的人员会被添加到小组（现有小组成员会被跳过）。这对于应该自动构建营地名单小组的营地注册表单等很有用。

## 复制表单

要重用表单作为新表单的起点，请单击表单列表中表单旁边的**复制**图标（复制图标）。B1 创建表单的精确副本 — 包括所有问题 — 您可以独立重命名和编辑。

:::tip
对于注册问题每年保持相同的定期事件，复制很方便。复制去年的表单，更新名称和日期，您已经准备好了。
:::

## 配置表单属性

您可以随时更新表单的名称和设置。对于独立表单，您还会看到可以与任何人分享的唯一**公共 URL**。

:::tip
独立表单非常适合事件注册。通过电子邮件、社交媒体分享公共 URL，或直接在教会网站上嵌入表单。
:::

:::info
要在您的 B1 网站上嵌入表单，请转到您的网站编辑器，添加新部分，然后选择**表单**元素。然后选择要显示的表单。有关编辑网站的详情，请参见[管理页面](../website/managing-pages.md)。
:::
