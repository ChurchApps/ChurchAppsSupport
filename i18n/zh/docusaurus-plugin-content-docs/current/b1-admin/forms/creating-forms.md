# 创建表单

<div class="article-intro">

构建自定义表单来从您的会众中收集信息。您可以创建活动注册、调查、访客卡、成员申请等表单。表单可以链接到您数据库中的人员或用作具有自己公开 URL 的独立页面。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 对于**人员**表单（链接到人员记录），您首先需要[数据库中的人员](../people/adding-people.md)。
- 对于收集**付款**的表单，您必须[为在线捐献配置 Stripe](../donations/online-giving-setup.md)。

</div>

## 创建新表单

1. 打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开**人员**，然后点击**表单**。
2. 点击**添加表单**。
3. 输入您的表单的**名称**。
4. 从下拉菜单中选择表单类型：
   - **人员** — 将提交与您数据库中的[人员记录](../people/adding-people.md)关联。
   - **独立** — 创建一个具有自己公开 URL 的独立表单，非常适合外部注册。
5. 点击**保存**来创建表单。

您的新表单将出现在列表中。点击它以开始添加问题。

## 打印空白表单

需要一份纸质副本来分发——用于欢迎台的访客卡，或者没有网络接入的人可以手工填写的表单？点击表单列表上表单旁边的**打印图标**以打开预览，然后点击**打印**。空白字段使用下划线或每个问题的复选框打印，以便人们可以手工填写；必需的问题用星号标记。您的教会名称打印在表单名称上方的顶部。没有其他打印选项——打印整个表单或不打印。

## 添加问题

1. 打开您的表单并转到**问题**选项卡。
2. 点击**添加问题**。
3. 从提供商下拉菜单中选择**字段类型**。可用的类型包括：
   - **文本框** — 用于短文本答案
   - **日期** — 用于日期选择
   - **电子邮件** — 用于电子邮件地址
   - **电话号码** — 用于电话输入
   - **多选** — 用于从预定义选项中选择
   - **付款** — 用于收集付款
4. 输入问题的**标题**和可选的**描述**。
5. 如果字段是必需的，请检查**需要回答**。
6. 点击**保存**。
7. 重复以添加更多问题。

:::warning
**付款**字段类型需要配置 Stripe。如果您尚未设置在线捐献，请在添加付款字段之前参阅[在线捐献设置](../donations/online-giving-setup.md)。
:::

## 管理表单成员

1. 打开您的表单并转到**表单成员**选项卡。
2. 搜索一个人并通过角色添加他们：
   - **管理员** — 可以编辑表单并查看所有提交。
   - **仅查看** — 可以查看提交但无法编辑表单。

## 自动将提交者添加到组

启用**从提交创建人员记录**后，您还可以将表单链接到一个组，以便每个提交者自动添加到该组的名单中：

1. 打开您的表单的**详情**，并打开**从提交创建人员记录**。
2. 在**将提交者添加到组**下，选择要将提交者添加到的组，或将其设置为**无**。
3. 点击**保存**。

每次有人提交表单时，匹配或新创建的人员都会添加到组中（跳过现有组成员）。这对于营地注册表等事项很有用，应该自动构建营地的名单组。

### 发送后续电子邮件

启用**从提交创建人员记录**后，您还可以向提交表单的每个人发送电子邮件。在表单的详情中填写**后续电子邮件主题**和**后续电子邮件正文**。您可以在两者中使用 `{firstName}` 和 `{churchName}` 令牌。仅当两个字段都填写时才发送电子邮件。

:::info
后续电子邮件仅在您的教会获得批准以发送群组电子邮件后才会发出，并且它们计入您的教会的每日电子邮件限制。参阅[为您的教会打开群组电子邮件](../groups/group-members.md#turning-on-group-email-for-your-church)。
:::

## 复制表单

要将表单重复用作新表单的起点，请点击表单列表中表单旁边的**复制**图标（复制图标）。B1 创建表单的精确副本——包括所有问题——然后您可以独立重命名和编辑。

:::tip
对于每年问题保持不变的定期活动，复制很方便。复制去年的表单，更新名称和日期，您就可以开始了。
:::

## 配置表单属性

您可以随时更新表单的名称和设置。对于独立表单，您还将看到一个唯一的**公开 URL**，您可以与任何人分享，以及一个**描述**字段——在人们开始填写前显示在公共表单页面上方的文本，对于告诉人们表单的用途很有用。

使用**感谢消息**字段来设置人们在提交表单后看到的内容，包括在表单的公开 URL 页面上。如果您将其留空，他们会看到"感谢您提交表单！"

:::tip
独立表单非常适合活动注册。通过电子邮件、社交媒体分享公开 URL 或直接在您的教会网站上嵌入表单。
:::

:::info
要在您的 B1 网站上嵌入表单，请转到您的网站编辑器，添加新部分，然后选择**表单**元素。然后选择您想要显示的表单。有关编辑网站的详细信息，请参阅[管理页面](../website/managing-pages.md)。
:::
