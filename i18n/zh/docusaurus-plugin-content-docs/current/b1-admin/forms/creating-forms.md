# 创建表单

<div class="article-intro">

创建自定义表单，以收集您会众的信息。您可以为活动报名、问卷调查、访客卡、会员申请等创建表单。表单可以关联到您数据库中的人员，也可以作为独立页面使用，并拥有各自的公开网址。

</div>

## 创建新表单

1. 打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **People（人员）**，然后点击 **Forms（表单）**。
2. 点击 **Add Form（添加表单）**。
3. 输入表单的**名称**。
4. 在 **Associate With（关联对象）**下拉菜单中选择表单类型：
   - **People（人员）**——将提交内容与您数据库中的[人员记录](../people/adding-people.md)关联。人员表单是从人员记录中填写的，因此不会生成可分享的链接。
   - **Stand Alone（独立）**——创建一个拥有独立公开网址的表单，非常适合外部报名。只有独立表单才能使用[页眉图片](#adding-a-header-photo)、[二维码](#sharing-a-form-with-a-qr-code)、[关联小组](#linking-a-form-to-a-group)以及 **Create a person record from submissions（根据提交内容创建人员记录）**功能。
5. 点击 **Save（保存）**以创建表单。

您的新表单会出现在列表中。点击它即可开始添加问题。

## 打印空白表单 {#printing-a-blank-form}

需要纸质版表单发给别人吗？例如用于欢迎台的访客卡，或供没有网络的人手写填写的表单？在表单主列表中，点击表单旁边的 **Print（打印）**以打开预览，然后点击 **Print（打印）**。空白字段会为每个问题打印下划线或复选框，方便人们手写填写；必填问题会标注星号。页面顶部会显示您的教会徽标（如果您上传过，则为[网站 > 外观](../website/appearance.md)中的 **Light Background Logo（浅色背景徽标）**），下方是教会名称，然后是表单名称。没有其他打印选项——只能打印整个表单。

## 使用二维码分享表单 {#sharing-a-form-with-a-qr-code}

独立表单在主表单列表中旁边都有一个 **QR Code（二维码）**链接（已归档的表单没有此链接）。点击它即可打开表单公开网址的二维码，下方会显示该链接。点击 **Download PNG（下载 PNG）**即可将二维码保存为图片，以便印在主日程序单上或在幻灯片上展示。扫描二维码的人会在手机上打开该表单。

## 添加问题 {#adding-questions}

1. 打开您的表单，进入 **Questions（问题）**选项卡。
2. 点击 **Add Question（添加问题）**。
3. 从 Provider（提供方）下拉菜单中选择**字段类型**。可用类型包括：
   - **Textbox（文本框）**——用于简短的文字回答
   - **Date（日期）**——用于选择日期
   - **Email（邮箱）**——用于邮箱地址
   - **Phone Number（电话号码）**——用于输入电话
   - **Multiple Choice（多项选择）**——用于从预设选项中选择
   - **Payment（付款）**——用于收取款项
4. 输入问题的 **Title（标题）**，以及可选的 **Description（描述）**。描述会在人们填写表单时显示在问题下方，因此可用于提供提示，例如“请填写需要我们知道的任何过敏信息”。
5. 如果该字段为必填项，请勾选 **Require an answer（必须回答）**。
6. 点击 **Save（保存）**。
7. 重复上述步骤以添加更多问题。

:::warning
**Payment（付款）**字段类型需要配置 Stripe。如果您尚未设置线上奉献，请在添加付款字段之前参阅[线上奉献设置](../donations/online-giving-setup.md)。
:::

## 管理表单成员 {#managing-form-members}

1. 打开您的表单，进入 **Form Members（表单成员）**选项卡。
2. 搜索某人并为其添加角色：
   - **Admin（管理员）**——可以编辑表单并查看所有提交内容。
   - **View Only（仅查看）**——可以查看提交内容，但不能编辑表单。

## 将表单关联到小组 {#linking-a-form-to-a-group}

您可以将任何独立表单关联到小组——例如，为小组提供的代祷请求表，或为青年旅行提供的医疗同意书：

1. 打开您表单的 **Details（详细信息）**。
2. 在 **Linked group（关联小组）**下，选择小组，或保持为 **None（无）**。
3. 点击 **Save（保存）**。

表单关联后：

- **小组成员**会在 B1.church 上小组页面的 **Forms（表单）**部分看到该表单（只要表单处于开放状态），并可点击 **Fill out（填写）**按钮打开它（参见[小组详情](../../b1-church/groups/group-details.md#linked-forms)）。
- **小组负责人**也可以看到已关闭的表单，并能阅读每份提交内容的答案，还可以打印（单份提交或 **Print all（全部打印）**）。负责人只能查看答案——除非他们同时也是[表单成员](#managing-form-members)，否则无法编辑表单。
- **在 B1 Admin 中**，小组页面会显示 **Linked forms（关联表单）**部分，列出每个关联表单，并标明为 **Open（开放）**或 **Closed（已关闭）**。该部分仅对小组负责人以及可以管理表单的人员显示。参见[小组成员](../groups/group-members.md#linked-forms)。

当表单超出其可用时间范围时，即为已关闭。已归档的表单不会显示在小组页面上。

### 自动将提交者添加到小组 {#automatically-adding-submitters-to-a-group}

仅将表单关联到小组并不会自动将任何人添加到小组中。若要将每位提交者都添加到关联小组的名单中，请在表单详细信息中同时开启 **Create a person record from submissions（根据提交内容创建人员记录）**，然后点击 **Save（保存）**。

每当有人提交表单时，匹配到的或新创建的人员都会被添加到该小组中（已在小组中的成员会被跳过）。这对于诸如营会报名表之类的场景非常有用，它可以自动为营会建立名单小组。

### 发送跟进邮件

开启 **Create a person record from submissions（根据提交内容创建人员记录）**后，您还可以向每位提交表单的人发送邮件。在表单详细信息中填写 **Follow-up Email Subject（跟进邮件主题）**和 **Follow-up Email Body（跟进邮件正文）**。两者中都可以使用 `{firstName}` 和 `{churchName}` 标记。只有当两个字段都填写完整时，才会发送邮件。

:::info
只有在您的教会获准发送小组邮件后，跟进邮件才会发出，并且它们会计入您教会的每日邮件限额。参见[为您的教会开通小组邮件](../groups/group-members.md#turning-on-group-email-for-your-church)。
:::

## 复制表单

若要以现有表单为起点创建新表单，请在表单列表中点击表单旁边的 **Duplicate（复制）**，然后确认。B1 会创建该表单的完全副本——包括所有问题——之后您可以独立地重命名和编辑它。

:::tip
复制功能非常适合每年报名问题基本不变的定期活动。复制去年的表单，更新名称和日期，即可开始使用。
:::

## 配置表单属性

您随时可以更新表单的名称和设置。对于独立表单，您还会看到一个唯一的**公开网址**，可与任何人分享，同时还有一个 **Description（描述）**字段——即显示在公开表单页面问题上方的文字，用于在人们开始填写之前说明表单的用途。

### 添加页眉图片 {#adding-a-header-photo}

独立表单可以在表单顶部显示**页眉图片（Header Photo）**。在表单详细信息中，点击图片框或 **Add Photo（添加图片）**，然后选择或上传图片（图片会被裁剪为 16:9 的比例）。点击 **Save（保存）**。图片会显示在表单名称下方、描述上方，出现在表单的公开网址页面上，以及通过网站 **Form（表单）**元素嵌入表单的任何位置。使用 **Change Photo（更换图片）**可以替换图片，使用 **Remove（移除）**可以删除图片。

使用 **Thank You Message（感谢信息）**字段可以设置人们提交表单后看到的内容，包括在表单的公开网址页面上。如果留空，他们将看到“感谢您提交表单！”。

:::tip
独立表单非常适合活动报名。您可以通过电子邮件、社交媒体分享公开网址，或直接将表单嵌入您的教会网站。
:::

:::info
要在您的 B1 网站上嵌入表单，请进入网站编辑器，添加新的板块，然后选择 **Form（表单）**元素。接着选择您要显示的表单。有关编辑网站的详细信息，请参阅[管理页面](../website/managing-pages.md)。
:::
