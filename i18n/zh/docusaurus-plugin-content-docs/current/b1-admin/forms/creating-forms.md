# 创建表单

<div class="article-intro">

构建自定义表单来收集来自您的会众的信息。您可以创建表单用于事件注册、调查、访客卡、成员申请等。表单可以链接到您数据库中的人员或用作具有自己公共URL的独立页面。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 对于**人员**表单(链接到人员记录),您需要[首先在数据库中有人员](../people/adding-people.md)。
- 对于收集**付款**的表单,您必须有[为在线捐赠配置的Stripe](../donations/online-giving-setup.md)。

</div>

## 创建新表单

1. 从部分菜单打开**人员**,然后单击导航栏中的**表单**。
2. 单击**添加表单**。
3. 为您的表单输入**名称**。
4. 从下拉菜单中选择表单类型:
   - **人员** - 将提交与您的数据库中的[人员记录](../people/adding-people.md)关联。
   - **独立** - 创建具有自己公共URL的独立表单,非常适合外部注册。
5. 单击**保存**创建表单。

您的新表单将出现在列表中。单击它以开始添加问题。

## 打印空白表单

需要纸质副本用于分发 - 用于欢迎台的访客卡,或某人无法访问互联网可以手工填写的表单?单击表单主表单列表中表单旁的**打印图标**以打开预览,然后单击**打印**。空白字段以下划线或复选框打印用于每个问题,以便人们可以手工填写;必需问题用星号标记。没有其他打印选项 - 打印整个表单或不打印。

## 添加问题

1. 打开您的表单并转到**问题**选项卡。
2. 单击**添加问题**。
3. 从提供者下拉菜单中选择**字段类型**。可用类型包括:
   - **文本框** - 用于简短文本答案
   - **日期** - 用于日期选择
   - **电子邮件** - 用于电子邮件地址
   - **电话号码** - 用于电话输入
   - **多项选择** - 用于从预定义选项中选择
   - **付款** - 用于收集付款
4. 为问题输入**标题**和可选的**描述**。
5. 如果字段是必需的,检查**需要答案**。
6. 单击**保存**。
7. 重复添加更多问题。

:::warning
**付款**字段类型需要配置Stripe。如果您还未设置在线捐赠,请在添加付款字段之前查看[在线捐赠设置](../donations/online-giving-setup.md)。
:::

## 管理表单成员

1. 打开您的表单并转到**成员**选项卡。
2. 搜索一个人并以角色添加他们:
   - **管理员** - 可以编辑表单并查看所有提交。
   - **仅查看** - 可以查看提交但无法编辑表单。

## 自动将提交者添加到团队

当启用**从提交中创建人员记录**时,您也可以将表单链接到团队,这样每个提交者都会自动添加到该团队的名单中:

1. 打开您的表单的**详细信息**,打开**从提交中创建人员记录**。
2. 在**添加提交者到团队**下,选择要添加提交者的团队,或将其设置为**无**。
3. 单击**保存**。

每当有人提交表单时,匹配或新创建的人员就会被添加到该团队中(现有团队成员将被跳过)。这对于应该自动构建营地名单团队的营地报名表等内容很有用。

### 发送跟进电子邮件

启用**从提交中创建人员记录**后,您也可以向每个提交表单的人发送电子邮件。填写表单详细信息中的**跟进电子邮件主题**和**跟进电子邮件正文**。您可以在两者中使用`{firstName}`和`{churchName}`令牌。仅当两个字段都填充时才发送电子邮件。

:::info
跟进电子邮件仅在您的教会被批准发送群组电子邮件后才会发出,并且它们计入您的教会每日电子邮件限制。请参阅[为您的教会打开群组电子邮件](../groups/group-members.md#turning-on-group-email-for-your-church)。
:::

## 复制表单

要重新使用表单作为新表单的起点,请单击表单列表中表单旁的**复制**图标(复制图标)。B1创建表单的精确副本 - 包括所有问题 - 然后您可以独立重命名和编辑它。

:::tip
复制对于问题每年都保持相同的定期活动很方便。复制去年的表单,更新名称和日期,您就可以开始了。
:::

## 配置表单属性

您可以随时更新表单的名称和设置。对于独立表单,您还会看到唯一的**公共URL**,您可以与任何人分享,以及**描述**字段 - 在公共表单页面的问题上方显示的文本,用于告诉人们表单是什么用途在他们开始填写之前。

:::tip
独立表单非常适合事件注册。通过电子邮件、社交媒体共享公共URL或直接在教会网站上嵌入表单。
:::

:::info
要在您的B1网站上嵌入表单,请转到您的网站编辑器,添加新部分,然后选择**表单**元素。然后选择您想要显示的表单。有关编辑网站的详细信息,请参阅[管理页面](../website/managing-pages.md)。
:::
