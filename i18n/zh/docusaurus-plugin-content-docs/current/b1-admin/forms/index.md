# 表单

<div class="article-intro">

表单部分允许您为注册、调查、数据收集等创建自定义表单。无论您需要访客卡、活动注册或祈祷请求表单，您都可以在此构建它，并通过公开链接或您的 B1.church 网站与您的会众分享。

</div>

## 表单页面

当您打开**表单**时，您将看到这些选项卡：

- **表单** -- 显示所有您的活动表单。
- **已存档表单** -- 显示已存档的表单。您可以随时恢复已存档的表单。此选项卡仅在至少已存档一个表单后显示。

列表中的每个表单都显示其名称，如果配置了，还显示您可以外部分享的公开 URL。

## 您可以做什么

从表单页面，您可以：

- **添加表单** -- 点击**添加表单**以创建新的自定义表单。
- **编辑表单** -- 点击表单名称来打开它并修改其问题、成员或设置。
- **存档表单** -- 将您不再需要的表单移到**已存档表单**选项卡以保持列表整洁。
- **恢复表单** -- 切换到**已存档表单**选项卡并恢复您想要再次激活的任何表单。

## 使用表单

点击任何表单名称来打开它。表单编辑器最多有三个选项卡：

- **问题** -- 通过添加不同类型的字段来构建表单结构。有关详细信息，请参阅[创建表单](./creating-forms.md)。
- **表单成员** -- 控制谁可以访问和管理表单（仅限独立表单）。
- **表单提交** -- 查看已提交的响应。有关详细信息，请参阅[管理提交](./managing-submissions.md)。

:::tip
具有公开 URL 的表单可以通过链接分享、嵌入到您的网站上或包含在电子邮件中。这使从可能没有教会账户的人收集信息变得容易。
:::

:::info
您可以使用**表单成员**选项卡控制每个表单的访问权限。分配**管理员**或**仅查看**角色，以为您的团队提供正确的访问级别。
:::
