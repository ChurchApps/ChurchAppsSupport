# 表单

<div class="article-intro">

表单板块让你为报名、问卷调查、数据收集等用途创建自定义表单。无论你需要访客卡、活动报名表还是代祷请求表，都可以在此处创建，并通过公开链接或你的 B1.church 网站与会众分享。

</div>

## 表单页面 {#the-forms-page}

打开**表单**时，你会看到以下标签：

- **Forms**（表单）——显示所有启用中的表单。
- **Archived Forms**（已归档表单）——显示已归档的表单。你可以随时恢复已归档的表单。只有在至少归档过一个表单后，此标签才会出现。

列表上方会显示表单的数量。列表中的每个表单都会显示其名称；对于独立表单，还会显示可对外分享的公开网址（人员表单则显示 **Person profile form**（人员资料表单））。将鼠标悬停在某一行上（在手机上，链接始终显示）即可看到其操作：**Edit**（编辑）、**Print**（打印）、**QR Code**（二维码，仅限独立表单）、**Duplicate**（复制）和 **Archive**（归档）。已归档的表单显示 **Print**（打印）和 **Restore**（恢复）。

## 你可以做什么 {#what-you-can-do}

在表单页面，你可以：

- **添加表单**——点击 **Add Form**（添加表单）创建新的自定义表单。
- **查找表单**——在 **Find a form**（查找表单）框中输入内容，按名称筛选列表。
- **编辑表单**——点击表单名称打开它，修改其问题、成员或设置；或点击该行上的 **Edit**，直接在表单页面上更改设置。
- **打印、分享或复制表单**——参见[打印空白表单](./creating-forms.md#printing-a-blank-form)、[使用二维码分享表单](./creating-forms.md#sharing-a-form-with-a-qr-code)和[复制表单](./creating-forms.md#duplicating-a-form)。
- **归档表单**——点击 **Archive**（归档）并确认，即可将不再需要的表单移至 **Archived Forms** 标签，保持列表整洁。其提交内容会被保留。
- **恢复表单**——切换到 **Archived Forms** 标签，点击 **Restore**（恢复）并确认，即可使表单重新启用。

## 处理表单 {#working-with-a-form}

点击任一表单名称即可打开它。页面左侧显示表单的名称、类型和公开链接，并附有用于设置[属性](./creating-forms.md#configuring-form-properties)的 **Edit Form** 按钮，以及返回列表的 **Forms** 链接。根据你的访问权限，表单最多包含三个标签：

- **Questions**（问题）——通过添加不同类型的字段来构建表单结构。详情请参见[创建表单](./creating-forms.md)。
- **Form Members**（表单成员）——控制谁可以访问和管理该表单（仅限独立表单）。
- **Form Submissions**（表单提交）——查看已提交的回复。详情请参见[管理提交内容](./managing-submissions.md)。

:::tip
带有公开网址的表单可以通过链接分享、嵌入你的网站或加入电子邮件中。这使你可以更轻松地从那些可能没有教会账户的人那里收集信息。
:::

:::info
你可以使用 **Form Members** 标签控制谁有权访问每个表单。为团队成员分配 **Admin** 或 **View Only** 角色，即可赋予他们合适的访问级别。
:::
