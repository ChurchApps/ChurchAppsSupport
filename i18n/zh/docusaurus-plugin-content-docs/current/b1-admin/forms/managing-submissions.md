# 管理提交内容

<div class="article-intro">

表单上线后，提交内容就会陆续到达。**Form Submissions（表单提交）**选项卡可让您查看每一份回复、跟踪谁已提交，并利用这些数据及时跟进会众。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [创建一个表单](./creating-forms.md)，并至少添加一个问题
- 通过其公开网址分享表单，或将其嵌入您的[网站](../website/managing-pages.md)

</div>

## 查看提交内容

1. 打开[跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **People（人员）**，然后点击 **Forms（表单）**。
2. 点击您想查看的表单。
3. 进入 **Form Submissions（表单提交）**选项卡。

您将看到该表单收到的所有回复列表。每条提交内容都会显示填写人的信息和提交日期，并随后为表单上的每个问题提供一列。如果您的表单问题很多，可以左右滚动表格以查看其余列。

## 查看单条提交内容

点击任意提交内容即可查看完整详情。您将看到该人员对表单上每个问题给出的所有答案。

点击提交内容旁边的**打印图标**，即可打印该人员填写的答案——这对于纸质存档或需要留存的已签名同意书非常有用。打印件会在顶部居中显示您的教会徽标（如果您上传过，则为[网站 > 外观](../website/appearance.md)中的 **Light Background Logo（浅色背景徽标）**），下方是教会名称。即使您在深色模式下使用 B1 Admin，打印件始终使用白纸黑字。这与[打印空白表单](./creating-forms.md#printing-a-blank-form)不同；它打印的是某一个人已提交的答案，而不是空白副本。只要显示提交内容的地方，都会出现这个打印图标，包括在[人员个人资料](../people/adding-people.md#working-with-forms)上。

## 更改提交内容所属的人员

如果某份提交内容关联到了错误的人员——例如，两位家庭成员共用同一个邮箱地址——您可以将其移动到正确的人员名下，或取消关联。

1. 在 **Form Submissions（表单提交）**选项卡上，点击人员姓名旁边的 **Change person（更改人员）**图标（两个箭头）。同样的图标也会出现在[人员个人资料](../people/adding-people.md#working-with-forms)中提交内容的旁边。
2. 在 **Change person（更改人员）**对话框中，搜索正确的人员，然后点击 **Move to this person（移至此人员）**。
3. 或者点击 **Unlink (Anonymous)（取消关联（匿名））**，将该提交内容与任何人员分离。之后它将显示为 **Anonymous（匿名）**。

只有关联关系会改变。答案保持不变，也不会再次发送跟进邮件。

:::info
对于设置为创建人员记录的表单，当有人在您教会的网站上登录的同时提交表单时，该提交内容会关联到他们自己的记录，即使数据库中有其他人与其共用同一个邮箱地址。当您[合并两条人员记录](../people/adding-people.md)时，被删除人员的表单提交内容会转移到您保留的那位人员名下。
:::

## 收集提交内容的方式

提交内容可以通过多种渠道收集：

- **公开网址**——如果您的表单有公开网址（独立表单），任何拥有该链接的人都可以提交回复。通过电子邮件、社交媒体或短信分享网址即可。
- **嵌入您的网站**——嵌入在 B1 网站上的表单会在访客填写时自动收集提交内容。
- **内部使用**——工作人员和志愿者也可以直接在 B1 Admin 中代他人提交表单。

:::tip
对于访客卡或代祷请求等表单，请定期查看 **Form Submissions（表单提交）**选项卡，以便及时跟进。
:::

## 使用提交数据

通过表单收集的数据可以帮助您：

- 跟踪活动报名情况并据此做好安排
- 跟进访客或新会员
- 收集调查反馈，用于事工规划
- 处理活动或项目的付款

:::info
拥有 **Admin（管理员）**或 **View Only（仅查看）**角色的表单成员可以访问 **Form Submissions（表单提交）**选项卡。请通过 **Form Members（表单成员）**选项卡管理角色，确保团队中的合适人员拥有他们所需表单的访问权限。
:::

:::info
如果独立表单[已关联到某个小组](./creating-forms.md#linking-a-form-to-a-group)，该小组的负责人无需是表单成员，即可在 B1.church 的小组页面上阅读并打印其提交内容。负责人还可以在那里查看其小组活动的报名问题答案。参见[小组详情](../../b1-church/groups/group-details.md#linked-forms)。
:::

:::tip
如果一个**独立（Stand Alone）**表单设置为创建人员记录，那么任何与现有人员匹配的提交内容，都会同时显示在该人员在 People（人员）中页面的**表单（Forms）**部分——而不仅限于人员类型的表单。
:::
