# 管理提交

<div class="article-intro">

表单上线后，提交内容就会陆续到达。**表单提交**选项卡可让您查看每一份回复、跟踪谁已提交，并利用这些数据及时跟进您的会众。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [创建一个表单](./creating-forms.md)，并至少添加一个问题
- 通过表单的公开 URL 分享表单，或将其嵌入您的[网站](../website/managing-pages.md)

</div>

## 查看提交内容 {#viewing-submissions}

1. 打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开**人员**，然后点击**表单**。
2. 点击您要查看的表单。
3. 进入**表单提交**选项卡。

您将看到该表单收到的所有回复列表。每条提交内容都会显示提交人的信息和提交日期，之后是表单上每个问题对应的一列。如果表单问题较多，请左右滚动表格以查看其余列。

## 查看单条提交内容 {#reviewing-individual-submissions}

点击任意提交内容即可查看完整详情。您将看到此人对表单上每个问题的全部回答。

点击提交内容旁边的**打印图标**，即可打印此人填写的答案——适用于纸质存档或需要留存备查的签署授权书。打印件顶部会显示您的教会标志（如果您上传过，则为来自[网站 > 外观](../website/appearance.md)的**浅色背景标志**），其下是教会名称。这与[打印空白表单](./creating-forms.md#printing-a-blank-form)不同；它打印的是某一个人已提交的答案，而不是空白副本。凡是显示提交内容的地方都会出现该打印图标，包括[人员个人资料](../people/adding-people.md#working-with-forms)页面。

## 更改提交内容对应的人员 {#changing-the-person-on-a-submission}

如果提交内容关联到了错误的人——例如两位家庭成员共用一个电子邮件地址——您可以将其移动到正确的人员名下，或取消关联。

1. 在**表单提交**选项卡中，点击人员姓名旁边的**更改人员**图标（两个箭头）。同样的图标也会出现在[人员个人资料](../people/adding-people.md#working-with-forms)中提交内容的旁边。
2. 在**更改人员**对话框中，搜索正确的人员，然后点击**移至此人**。
3. 或者，点击**取消关联（匿名）**，将提交内容与任何人员分离。之后它将显示为**匿名**。

只有关联关系会发生变化。回答内容保持不变，也不会重新发送后续电子邮件。

:::info
对于设置为创建人员记录的表单，如果某人在提交时已登录您教会的网站，该提交内容将关联到他自己的记录，即使数据库中有另一个人与其共用同一电子邮件地址。当您[合并两条人员记录](../people/adding-people.md)时，被移除人员的表单提交内容会转移到您保留的那位人员名下。
:::

## 提交内容的收集方式 {#how-submissions-are-collected}

提交内容可以通过以下几种渠道收到：

- **公开 URL** -- 如果表单拥有公开 URL（独立表单），任何拥有该链接的人都可以提交回复。您可以通过电子邮件、社交媒体或短信分享该 URL。
- **嵌入您的网站** -- 嵌入在 B1 网站上的表单会在访客填写时自动收集提交内容。
- **内部使用** -- 工作人员和志愿者也可以直接在 B1 Admin 中代他人提交表单。

:::tip
请定期查看**表单提交**选项卡，尤其是访客卡或代祷请求等表单，以便及时跟进。
:::

## 使用提交数据 {#using-submission-data}

通过表单收集的数据可以帮助您：

- 跟踪活动报名情况，并据此做好安排
- 跟进访客或新会员
- 收集调查反馈，用于事工规划
- 处理活动或项目的付款

:::info
拥有**管理员**或**仅查看**角色的表单成员可以访问**表单提交**选项卡。请通过**表单成员**选项卡管理角色，确保团队中合适的人员有权访问他们所需的表单。
:::

:::tip
如果一个**独立**表单设置为创建人员记录，那么匹配到现有人员的提交内容也会显示在该人员页面的**表单**部分中，而不仅限于人员类型的表单。
:::
