# 管理提交

<div class="article-intro">

您的表单上线后,提交将开始出现。提交选项卡允许您审查每个响应、跟踪谁已提交,并使用数据及时跟进您的会众。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [创建表单](./creating-forms.md)至少有一个问题
- 通过其公共URL共享表单或在您的[网站](../website/managing-pages.md)上嵌入它

</div>

## 查看提交

1. 从部分菜单打开**人员**,然后单击导航栏中的**表单**。
2. 单击要审查的表单。
3. 转到**提交**选项卡。

您将看到为该表单收到的所有响应的列表。每个提交显示响应者的信息和提交的日期。

## 审查个别提交

单击任何提交以查看完整详细信息。您将看到人员为表单上每个问题提供的所有答案。

单击提交旁的**打印图标**以打印该人的已填入答案 - 用于纸质文件或您需要保留的签署的发布。这与[打印空白表单](./creating-forms.md#printing-a-blank-form)不同;它打印一个人已提交的答案,而不是空副本。相同的打印图标出现在显示提交的任何地方,包括在[人员的个人资料](../people/adding-people.md#working-with-forms)。

## 提交如何被收集

提交可以通过多个渠道进来:

- **公共URL** - 如果您的表单有公共URL(独立表单),任何拥有链接的人都可以提交响应。通过电子邮件、社交媒体或文本消息分享URL。
- **嵌入您的网站** - 嵌入在您的B1网站上的表单在访问者填写时自动收集提交。
- **内部使用** - 员工和志愿者也可以直接在B1 Admin中代表他人提交表单。

:::tip
定期检查访客卡或祷告请求等表单的**提交**选项卡,以便您可以及时跟进。
:::

## 使用提交数据

通过表单收集的数据可以帮助您:

- 跟踪事件注册并相应规划
- 跟进访客或新成员
- 为事工规划收集调查反馈
- 处理活动或计划的付款

:::info
拥有**管理员**或**仅查看**角色的表单成员可以访问提交选项卡。通过在**成员**选项卡中管理角色,确保您的团队中合适的人员可以访问他们需要的表单。
:::

:::tip
如果**独立**表单设置为创建人员记录,任何与现有人员匹配的提交也会显示在该人员在人员部分中自己的**表单**选项卡上 - 而不仅仅是人员类型的表单。
:::
