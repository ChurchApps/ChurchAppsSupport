# 管理提交

<div class="article-intro">

一旦您的表单上线，提交就会开始进入。**表单提交**选项卡让您查看每个响应、追踪谁已提交，并使用数据及时与您的会众进行后续跟进。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [创建一个表单](./creating-forms.md)，至少有一个问题
- 通过其公开 URL 分享表单或将其嵌入到您的[网站](../website/managing-pages.md)上

</div>

## 查看提交

1. 打开 [Jump 菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开**人员**，然后点击**表单**。
2. 点击您想要查看的表单。
3. 转到**表单提交**选项卡。

您将看到为该表单收到的所有响应的列表。每个提交都显示响应者的信息和提交日期，随后是表单上每个问题的一列。如果您的表单有许多问题，请向左滚动表格以查看其余列。

## 查看个人提交

点击任何提交以查看完整详情。您将看到该人为表单上的每个问题提供的所有答案。

点击提交旁边的**打印图标**以打印该人的已填入答案——对于纸质文件或您需要保存的签署版本很有用。打印件在顶部显示您的教会名称。这与[打印空白表单](./creating-forms.md#printing-a-blank-form)分开；它打印一个人已提交的答案，而不是空副本。相同的打印图标出现在显示提交的任何地方，包括在[人员的个人资料](../people/adding-people.md#working-with-forms)上。

## 更改提交上的人员

如果提交链接到错误的人——例如，两个家庭成员共享一个电子邮件地址——您可以将其移到正确的人或取消链接。

1. 在**表单提交**选项卡上，点击人员名称旁边的**更改人员**图标（两个箭头）。相同的图标出现在[人员的个人资料](../people/adding-people.md#working-with-forms)上提交的旁边。
2. 在**更改人员**对话框中，搜索正确的人员并点击**移到此人**。
3. 或点击**取消链接（匿名）**来从任何人分离提交。然后它显示为**匿名**。

仅链接改变。答案保持不变，不会再次发送后续电子邮件。

:::info
在设置为创建人员记录的表单上，当有人在提交时登录到您的教会网站时，提交会链接到他们自己的记录，即使您的数据库中的另一个人共享他们的电子邮件地址。当您[合并两个人员记录](../people/adding-people.md)时，被删除人员的表单提交会移到您保留的人员。
:::

## 如何收集提交

提交可以通过几个渠道进入：

- **公开 URL** -- 如果您的表单有公开 URL（独立表单），任何具有链接的人都可以提交响应。通过电子邮件、社交媒体或短信分享 URL。
- **嵌入在您的网站上** -- 嵌入在您的 B1 网站上的表单在访问者填写它们时自动收集提交。
- **内部使用** -- 员工和志愿者也可以在 B1 Admin 中代表他人直接提交表单。

:::tip
定期检查**表单提交**选项卡以了解访客卡或祈祷请求等表单，以便您可以及时进行后续跟进。
:::

## 使用提交数据

通过表单收集的数据可以帮助您：

- 追踪活动注册并相应地计划
- 与访客或新成员进行后续跟进
- 为事工规划收集调查反馈
- 为活动或项目处理付款

:::info
具有**管理员**或**仅查看**角色的表单成员可以访问**表单提交**选项卡。通过在**表单成员**选项卡中管理角色，确保您团队中的正确的人有权访问他们需要的表单。
:::

:::tip
如果**独立**表单设置为创建人员记录，任何匹配到现有人员的提交也会显示在该人员在人员部分中自己的**表单**选项卡上——不仅仅是人员类型表单。
:::
