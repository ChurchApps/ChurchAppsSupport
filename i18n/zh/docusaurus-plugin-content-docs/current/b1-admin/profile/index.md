# 个人资料

<div class="article-intro">

个人资料板块可让你管理自己在 ChurchApps 中的个人账号设置。你的个人资料在所有 ChurchApps 工具之间共享，因此你在此所做的更改将应用于所有地方——从 B1 Admin 到 B1 移动应用。

</div>

## 你可以做什么

在个人资料板块中，你可以：

- **更新姓名和电子邮件** —— 保持联系信息为最新。
- **更改密码** —— 为你的账号设置新密码。
- **开启两步登录** —— 登录时需要输入身份验证器应用中的验证码。参见[两步登录](./managing-profile.md#two-factor-sign-in)。
- **切换主题** —— 从用户菜单（点击右上角的个人头像）在浅色和深色模式之间切换。
- **管理已连接的设备** —— 查看并控制哪些 ChurchAppsPlayer 设备已关联到你的账号。
- **查看已关联的账号** —— 查看并管理与你的 ChurchApps 账号相连的任何外部服务。
- **批准个人资料变更请求** —— 审核并应用成员提交的更新。

## 个人资料子页面

个人资料区域包含以下页面：

1. **[管理你的个人资料](./managing-profile.md)** —— 编辑你的个人信息、更改密码、管理已关联的账号、开启两步登录、调整主题偏好，以及处理账号删除。
2. **[批准个人资料变更](./approving-profile-changes.md)** —— 审核并批准成员通过 B1 移动应用提交的个人资料更新请求。
3. **[管理设备](./devices.md)** —— 查看、添加并管理与你的账号配对的 ChurchAppsPlayer 设备。

:::tip
请保持你的电子邮件地址为最新。它用于账号找回以及教会发出的重要通知。
:::
