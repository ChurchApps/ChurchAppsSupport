# 个人资料

<div class="article-intro">

个人资料区域让你管理 ChurchApps 中的个人账户设置。点击 B1 Admin 右上角的个人头像，然后选择**Edit Profile**，即可打开它。你的个人资料会在所有 ChurchApps 工具中共享，因此你在此所做的更改，会套用到所有地方——从 B1 Admin 到 B1 应用程序。

</div>

## 你可以做什么 {#what-you-can-do}

在个人资料区域中，你可以：

- **更新你的姓名与电子邮件**——保持你的联络信息为最新。
- **更改密码**——为你的账户设置新密码。
- **开启双重验证登录**——登录时需要输入来自身份验证应用程序的验证码。请参阅[双重验证登录](./managing-profile.md#two-factor-sign-in)。
- **切换主题**——从用户菜单（点击右上角的个人头像）在浅色与深色模式之间切换。
- **管理已连接的设备**——检视、配对、重新命名并移除与你的账户相连的 ChurchAppsPlayer 与 FreePlay 屏幕。
- **检视已连接的账户**——查看并管理与你的 ChurchApps 账户相连的任何外部服务。
- **批准个人资料变更请求**——审查并套用会员提交的更新。
- **审查账户删除请求**——批准或拒绝会员删除其账户的请求。

## 个人资料的子区域 {#profile-sub-sections}

个人资料区域包含以下页面：

1. **[管理你的个人资料](./managing-profile.md)**——编辑你的个人信息、更改密码、管理已连接的账户、开启双重验证登录、调整主题偏好设置，以及处理账户删除。
2. **[审批个人资料变更](./approving-profile-changes.md)**——审查并批准会员通过 B1 应用程序提交的个人资料更新请求。
3. **[审查账户删除请求](./account-deletion.md)**——批准或拒绝会员删除其账户的请求。
4. **[管理设备](./devices.md)**——检视、新增、重新命名并移除与你的账户配对的 ChurchAppsPlayer 与 FreePlay 屏幕。

:::tip
请保持你的电子邮件地址为最新。它用于账户恢复，以及教会发出的重要通知。
:::
