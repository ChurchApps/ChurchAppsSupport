# 个人资料

<div class="article-intro">

个人资料部分可让您管理个人账户设置。您的个人资料在所有 ChurchApps 工具中通用，因此您在此处所做的更改将应用于所有地方——从 B1 Admin 到 B1 App。

</div>

## 您可以做什么

在个人资料部分，您可以：

- **更新姓名和电子邮件** -- 保持您的联系信息为最新。
- **更改密码** -- 为您的账户设置新密码。
- **开启双重验证登录** -- 登录时要求输入来自身份验证应用的验证码。请参阅[双重验证登录](./managing-profile.md#two-factor-sign-in)。
- **切换主题** -- 从用户菜单（点击右上角的个人头像）在浅色和深色模式之间切换。
- **管理已连接的设备** -- 查看并控制哪些 ChurchAppsPlayer 设备已链接到您的账户。
- **查看已链接的账户** -- 查看并管理已连接到您的 ChurchApps 账户的任何外部服务。
- **批准个人资料更改请求** -- 审查并应用成员提交的更新。

## 个人资料子部分

个人资料区域包含以下页面：

1. **[管理您的个人资料](./managing-profile.md)** -- 编辑您的个人信息、更改密码、管理已链接的账户、开启双重验证登录、调整主题偏好设置以及处理账户删除。
2. **[批准个人资料更改](./approving-profile-changes.md)** -- 审查并批准成员通过 B1 App 提交的个人资料更新请求。
3. **[管理设备](./devices.md)** -- 查看、添加并管理与您的账户配对的 ChurchAppsPlayer 设备。

:::tip
请保持您的电子邮件地址为最新。它用于账户恢复以及您所在教会发送的重要通知。
:::
