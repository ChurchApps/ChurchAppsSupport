# 资料

<div class="article-intro">

资料部分让您管理在 ChurchApps 中的个人帐户设置。您的资料在所有 ChurchApps 工具之间共享，因此您在此处所做的更改适用于所有地方 — 从 B1Admin 到 B1 移动应用。

</div>

## 您可以做什么

从资料部分，您可以：

- **更新您的姓名和电子邮件** — 保持您的联系信息是最新的。
- **更改您的密码** — 为您的帐户设置新密码。
- **切换主题** — 在亮和暗模式之间切换以匹配您的偏好。
- **管理连接的设备** — 查看和控制哪些 ChurchAppsPlayer 设备链接到您的帐户。
- **查看链接的帐户** — 查看和管理连接到您的 ChurchApps 帐户的任何外部服务。
- **批准资料变更请求** — 审查和应用成员提交的更新。

## 资料子部分

资料区域有以下页面：

1. **[管理您的资料](./managing-profile.md)** — 编辑您的个人信息、更改您的密码、管理链接的帐户、调整主题首选项并处理帐户删除。
2. **[批准资料变更](./approving-profile-changes.md)** — 审查和批准成员通过 B1 移动提交的资料更新请求。
3. **[管理设备](./devices.md)** — 查看、添加和管理与您的帐户配对的 ChurchAppsPlayer 设备。

:::tip
保持您的电子邮件地址最新。它用于帐户恢复和来自您的教会的重要通知。
:::
