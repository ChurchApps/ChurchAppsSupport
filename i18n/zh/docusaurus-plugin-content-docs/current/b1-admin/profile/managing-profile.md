# 管理您的个人资料

<div class="article-intro">

个人资料页面可让您编辑个人账户设置。您的个人资料在所有 ChurchApps 产品中共享，因此您在此处所做的任何更改都会在您使用 ChurchApps 的各处生效。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须已登录您的 ChurchApps 账户
- 如果您计划更新电子邮件地址或密码，请提前准备好新的电子邮件地址或密码

</div>

## 个人资料信息

个人资料页面在左侧显示您的姓名和电子邮件地址，其下方有一个 **Edit** 按钮。点击 **Edit** 即可打开 **Edit Account** 表单，其中包含您的基本账户信息：

1. **Email** -- 用于登录和接收通知的电子邮件地址。
2. **First Name** 和 **Last Name** -- 您在 ChurchApps 中的显示名称。
3. **Password** -- 更新您的账户密码。

如需更新信息，请编辑相应字段，然后点击 **Save Changes** 按钮。如果您不想保存，请点击 **Cancel**（或带有您姓名的 **Back to** 链接）返回个人资料页面。

## 更改密码

1. 在个人资料页面上，点击 **Edit**。
2. 输入您的 **Current password**（当前密码）。
3. 在 **New password** 字段中输入新密码。
4. 在 **Verify password** 字段中再次输入新密码。
5. 点击 **Save Changes**。

:::info
密码长度至少为 8 个字符。请确保密码和确认密码字段的内容完全一致。您必须确认当前密码才能更改密码——如果您不记得当前密码，请改用登录页面上的 **Forgot Password** 链接。
:::

## 关联账户

**Linked Accounts** 部分显示与您的 ChurchApps 账户相关联的所有外部服务。您可以在此部分查看已关联的账户，并管理这些连接。

## 主题偏好设置

B1 Admin 允许您选择颜色主题以及浅色或深色显示模式：

1. 点击 B1 Admin 右上角的个人头像，打开用户菜单。
2. 在 **Theme Preferences** 下，选择一个主题：
   - **Default** -- 当前的 B1 Admin 外观：在简洁的画布上使用带边框的面板。
   - **Classic** -- 早期的 B1 Admin 外观，带有彩色页面横幅、带阴影的卡片和灰色背景。在您选择主题之前，您看到的就是此外观。
   - **Custom** -- 基于您教会自身颜色的 Default 外观。它使用 **Mobile > App Theme** 中的浅色模式主色；如果未设置应用颜色，则使用您网站的主色，以便 B1 Admin 与您的会员应用保持一致。
3. 在主题下方，选择 **Light Mode**（浅色模式）或 **Dark Mode**（深色模式）。
4. 界面会立即更新以反映您的选择。

您的选择会记录在该设备和浏览器上。

## 删除账户

在个人资料页面的 **Account Deletion** 部分，您可以找到删除账户的选项。

- 如果您的教会**尚未**配置目录审批小组，点击 **Delete my account** 会立即删除您的账户及相关数据，且此操作无法撤销。
- 如果您的教会**已**配置目录审批小组，您的请求会改为提交给该小组进行审核。请求待处理期间，该按钮会被禁用，教会批准或拒绝后您会收到通知。有关后续流程，请参阅[审核账户删除请求](./account-deletion.md)。

:::warning
无论是立即删除还是经教会批准后删除，账户删除都是永久性的，无法撤销。
:::

:::info
如果您是 **Domain Admin**（域管理员），请在删除账户之前，将管理职责转移给其他用户。有关管理管理员角色的详情，请参阅[角色与权限](../settings/roles-permissions.md)。
:::

:::info
演示模式下无法编辑个人资料。如果您使用的是演示账户，将无法更改个人资料设置。
:::
