# 管理个人资料

<div class="article-intro">

个人资料页面允许您编辑个人账户设置。您的个人资料在所有 ChurchApps 产品之间共享，因此您在此处所做的任何更改，都会在您使用 ChurchApps 的所有地方生效。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须已登录您的 ChurchApps 账户
- 如果您计划更新电子邮件地址或密码，请提前准备好新的电子邮件地址或密码

</div>

## 个人资料信息

个人资料页面的左侧显示您的姓名和电子邮件地址，其下方有一个 **Edit** 按钮。点击 **Edit** 即可打开 **Edit Account**（编辑账户）表单，其中包含您的基本账户信息：

1. **Email**（电子邮件）：用于登录和接收通知的电子邮件地址。
2. **First Name**（名字）和 **Last Name**（姓氏）：您在 ChurchApps 中显示的名称。
3. **Password**（密码）：更新您的账户密码。

要更新您的信息，请编辑相应字段，然后点击 **Save Changes**（保存更改）按钮。若要在不保存的情况下返回个人资料，请点击 **Cancel**（取消）或带有您姓名的 **Back to** 链接。

## 更改密码

1. 在个人资料页面上，点击 **Edit**。
2. 输入您的 **Current password**（当前密码）。
3. 在 **New password**（新密码）字段中输入新密码。
4. 在 **Verify password**（确认密码）字段中再次输入。
5. 点击 **Save Changes**。

:::info
密码长度必须至少为 8 个字符。请确保密码和确认密码字段完全一致。您必须确认当前密码才能更改密码；如果您不记得当前密码，请改用登录页面上的 **Forgot Password**（忘记密码）链接。
:::

## 关联账户

**Linked Accounts**（关联账户）部分显示与您的 ChurchApps 账户关联的所有外部服务。您可以在此部分查看哪些账户已关联，并管理这些连接。

## 主题偏好设置

B1 Admin 允许您选择配色主题，以及浅色或深色显示模式：

1. 点击 B1 Admin 右上角的个人头像，打开用户菜单。
2. 在 **Theme Preferences**（主题偏好设置）下，选择一个主题：
   - **Default**（默认）：当前的 B1 Admin 外观：在干净的画布上使用带边框的面板。新用户默认看到此主题，直到他们选择其他主题。
   - **Classic**（经典）：B1 Admin 早期的外观，包含彩色页面横幅、带阴影的卡片以及灰色背景。如果您在新外观推出之前已在此设备上使用过 B1 Admin，并且从未选择过主题，您将继续使用经典主题。
   - **Custom**（自定义）：基于您教会自身颜色构建的默认外观。它使用 **Mobile > App Theme**（移动端 > 应用主题）中设置的浅色模式主色；如果未设置应用颜色，则使用您网站的主色，使 B1 Admin 与您的会员应用保持一致。
3. 在主题下方，选择 **Light Mode**（浅色模式）或 **Dark Mode**（深色模式）。
4. 界面会立即更新以反映您的选择。

您的选择会记录在该设备和浏览器上。

## 删除账户

在个人资料页面的 **Account Deletion**（删除账户）部分，您可以找到删除账户的选项。

- 如果您的教会**尚未**配置目录审批小组，点击 **Delete my account**（删除我的账户）将立即删除您的账户及相关数据，且此操作无法撤销。
- 如果您的教会**已**配置目录审批小组，您的请求将改为发送给该小组进行审核。在请求待处理期间，该按钮将被禁用，您的教会批准或拒绝后，您将收到通知。有关后续流程，请参阅[审核删除账户请求](./account-deletion.md)。

:::warning
无论是立即删除还是经教会批准后删除，账户删除都是永久性的，且无法撤销。
:::

:::info
如果您是 **Domain Admin**（域管理员），请在删除账户之前，先将管理职责转交给其他用户。有关管理员角色的详细信息，请参阅[角色与权限](../settings/roles-permissions.md)。
:::

:::info
在演示模式下，个人资料编辑功能已禁用。如果您正在使用演示账户，将无法更改个人资料设置。
:::
