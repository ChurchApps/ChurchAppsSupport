# 管理你的个人资料

<div class="article-intro">

个人资料页面可让你编辑个人账号设置。你的个人资料在所有 ChurchApps 产品之间共享，因此你在此处所做的任何更改，都会在你使用 ChurchApps 的所有地方生效。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你必须已登录你的 ChurchApps 账号
- 如果你打算更新电子邮件地址或密码，请提前准备好新的电子邮件地址或密码

</div>

## 个人资料信息

个人资料页面左侧显示你的姓名和电子邮件地址，其下方有一个 **Edit**（编辑）按钮。点击 **Edit** 即可打开 **Edit Account**（编辑账号）表单，其中包含你的基本账号信息：

1. **Email**（电子邮件）—— 用于登录和接收通知的电子邮件地址。
2. **First Name**（名字）和 **Last Name**（姓氏）—— 你在 ChurchApps 中显示的名称。
3. **Password**（密码）—— 更新你的账号密码。

要更新信息，请编辑相应字段，然后点击 **Save Changes**（保存更改）按钮。若要在不保存的情况下返回个人资料，请点击 **Cancel**（取消），或点击带有你姓名的**返回**链接。

## 更改密码

1. 在个人资料页面，点击 **Edit**。
2. 输入你的 **Current password**（当前密码）。
3. 在 **New password**（新密码）字段中输入新密码。
4. 在 **Verify password**（确认密码）字段中再次输入。
5. 点击 **Save Changes**。

:::info
密码长度至少为 8 个字符。请确保密码和确认密码字段完全一致。更改密码前必须确认当前密码——如果你忘记了当前密码，请改用登录页面上的 **Forgot Password**（忘记密码）链接。
:::

## 已关联账号

**Linked Accounts**（已关联账号）部分会显示与你的 ChurchApps 账号相连的任何外部服务。你可以在此查看已关联的账号，并管理这些连接。

## 两步登录 {#two-factor-sign-in}

两步登录会在登录时增加第二步验证：输入密码（或使用 Google、Microsoft 或电子邮件登录链接）之后，你还需输入身份验证器应用（例如 Google Authenticator、Microsoft Authenticator、1Password 或 Authy）中显示的 6 位数字验证码。此功能为可选项，默认关闭。开启后，它将适用于所有使用你账号的 ChurchApps 登录——包括 B1 Admin、你教会的 B1.church 网站和应用、B1 Church Checkin、Lessons.church、FreePlay 以及其他产品。

### 开启两步登录

1. 在个人资料页面，找到 **Two-Factor Sign-In**（两步登录）部分，并点击 **Turn on**（开启）。
2. 用你的身份验证器应用扫描二维码。如果无法扫描，请将 **Can't scan? Enter this key:**（无法扫描？请输入此密钥：）下方显示的密钥手动输入到应用中。
3. 输入应用显示的 **6 位验证码**，然后点击 **Verify**（验证）。
4. B1 Admin 会显示十个**备用代码**。每个代码可在你丢失手机时用于登录一次。点击 **Copy**（复制）或将其写下来，妥善保存，然后点击 **I saved them**（我已保存）。

:::warning
备用代码仅显示一次。如果你丢失了手机，且没有剩余的备用代码，ChurchApps 服务器管理员需要在确认你的身份后，为你关闭两步登录。
:::

两步登录开启后，该部分会显示 **On**（已开启），并显示你剩余的备用代码数量。

### 使用验证码登录

输入密码后，登录界面会要求输入验证码。请输入身份验证器应用中的 6 位验证码，或其中一个备用代码，然后提交。每个备用代码只能使用一次。如果验证码错误，你会看到"验证码无效，请重试。"如果错误次数过多，你的账号登录将被暂停一段时间。

在你已登录过的设备上保持登录状态时，不会再次要求输入验证码；只有在重新登录时才会要求输入。

### 关闭两步登录

1. 在 **Two-Factor Sign-In** 部分，点击 **Turn off**（关闭）。
2. 输入身份验证器应用中当前的验证码，或一个备用代码。
3. 点击 **Verify**。

:::info
无法为演示账号设置两步登录，因此在演示账号中该部分会被隐藏。
:::

## 主题偏好设置

B1 Admin 允许你选择颜色主题以及浅色或深色显示模式：

1. 点击 B1 Admin 右上角的个人头像，打开用户菜单。
2. 在 **Theme Preferences**（主题偏好设置）下，选择一个主题：
   - **Default**（默认）—— 当前的 B1 Admin 外观：干净背景上带边框的面板。新用户在选择其他主题之前都会看到此主题。
   - **Classic**（经典）—— 早期的 B1 Admin 外观，带有彩色页面横幅、带阴影的卡片以及灰色背景。如果你在新外观推出之前已在此设备上使用过 B1 Admin，且从未选择过主题，则你将保持使用 Classic。
   - **Custom**（自定义）—— 基于你教会自身主题色构建的默认外观。它使用 **Mobile > App Theme** 中的浅色模式主色；如果未设置应用颜色，则使用你网站的主色，从而使 B1 Admin 与你的会员应用保持一致。
3. 在主题下方，选择 **Light Mode**（浅色模式）或 **Dark Mode**（深色模式）。
4. 界面会立即更新以反映你的选择。

你的选择会记录在该设备和浏览器上。

## 账号删除

在个人资料页面的 **Account Deletion**（账号删除）部分，你可以找到删除账号的选项。

- 如果你的教会**未**配置目录审批小组（Directory Approval Group），点击 **Delete my account**（删除我的账号）将立即删除你的账号及相关数据，且无法撤销。
- 如果你的教会**已**配置目录审批小组，你的请求将改为发送给该小组进行审核。在请求待处理期间，该按钮将被禁用，教会批准或拒绝后，你将收到通知。有关后续流程，请参阅[审核账号删除请求](./account-deletion.md)。

:::warning
无论是立即删除还是经教会批准后删除，账号删除都是永久性的，无法撤销。
:::

:::info
如果你是**域名管理员（Domain Admin）**，请在删除账号之前，先将管理职责转交给其他用户。有关管理员角色的详细信息，请参阅[角色与权限](../settings/roles-permissions.md)。
:::

:::info
在演示模式下无法编辑个人资料。如果你使用的是演示账号，将无法更改个人资料设置。
:::
