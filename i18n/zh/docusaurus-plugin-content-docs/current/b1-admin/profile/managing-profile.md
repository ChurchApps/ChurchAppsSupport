# 管理您的资料

<div class="article-intro">

资料页面让您编辑您的个人帐户设置。您的资料在所有 ChurchApps 产品中共享，因此您在此处所做的任何更改都会在您使用 ChurchApps 的所有地方反映出来。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须登录您的 ChurchApps 帐户
- 如果您计划更新新电子邮件地址或密码，请准备好

</div>

## 资料信息

资料页面左侧显示您的姓名和电子邮件地址，其下方有一个**编辑**按钮。点击**编辑**打开**编辑帐户**表单，其中包含您的基本帐户详情：

1. **电子邮件** — 用于登录和接收通知的电子邮件地址。
2. **名字**和**姓氏** — 您在 ChurchApps 中的显示名称。
3. **密码** — 更新您的帐户密码。

要更新您的信息，编辑字段并单击**保存更改**按钮。单击**取消**（或带有您姓名的**返回**链接）即可返回您的资料页面而不保存。

## 更改您的密码

1. 在资料页面上，点击**编辑**。
2. 输入您的**当前密码**。
3. 在**新密码**字段中输入您的新密码。
4. 在**验证密码**字段中重新输入。
5. 点击**保存更改**。

:::info
您的密码必须至少 8 个字符长。确保密码和确认字段完全匹配。您必须确认当前密码才能更改它 — 如果您不知道它，请改用登录页面上的**忘记密码**链接。
:::

## 链接的帐户

**链接的帐户**部分显示连接到您的 ChurchApps 帐户的任何外部服务。您可以从此部分查看链接的帐户并管理这些连接。

## 主题首选项

B1 Admin 支持亮色和暗色显示模式：

1. 点击 B1 Admin 右上角的个人头像，打开用户菜单。
2. 在**主题首选项**下，选择**亮色模式**或**暗色模式**。
3. 界面将立即更新以反映您的选择。

您的选择会记录在该设备和浏览器上。

## 帐户删除

在资料页面的**帐户删除**部分，您会找到永久删除您的帐户的选项。此操作删除您的帐户和关联数据，无法撤销。

:::warning
帐户删除是永久的，无法反转。在继续之前，请确保您真的想要删除您的帐户。
:::

:::info
如果您是**域管理员**，请确保在删除您的帐户前将管理责任转移给另一个用户。有关管理管理员角色的详情，请参见[角色和权限](../settings/roles-permissions.md)。
:::

:::info
在演示模式中禁用资料编辑。如果您使用演示帐户，您将无法更改您的资料设置。
:::
