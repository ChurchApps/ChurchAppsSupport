# 审批个人资料变更 {#approving-profile-changes}

<div class="article-intro">

当你的教会要求个人资料更新须经管理员批准时，会员会通过 B1 应用程序提交变更，而这些请求会以任务的形式出现在 B1 Admin 中。本指南说明如何审查并批准这些请求。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你必须是在 **Mobile &rarr; Member portal** 中被指定为**通讯录审批小组**的小组成员
- 如果尚未设置审批小组，个人资料变更将会立即套用，而无需审查

</div>

## 在哪里找到待处理的请求 {#where-to-find-pending-requests}

当会员提交个人资料变更时，它会以任务的形式分派给你的审批小组。你可以在两个地方找到它：

**从仪表板（你的首页）**：
1. 登录 B1 Admin——仪表板会自动载入。
2. 在 **My tasks** 区块中，点击 **All tasks**。（My tasks 只列出分派给你个人的未完成任务。）
3. 点击 **Assigned to My Groups** 标签。所有待处理的个人资料变更请求都会列在该处。

**从 Serving &rarr; My Work**：
1. 打开[快速菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），并展开 **Serving**。
2. 点击 **My Work**。
3. 在 Tasks 下点击 **Assigned to My Groups** 标签。

## 审查并批准请求 {#reviewing-and-approving-a-request}

1. 点击 **Profile Update** 任务将其打开。
2. 在 **Requested Changes** 下，你会看到会员想要更新的每个栏位，以及他们提交的新值。
3. 检查这些变更。
4. 点击 **Apply**，批准并将变更储存到其个人资料中。

新增家庭成员的请求，会在一行中显示该新人员的称谓、姓名、住户角色、手机号码与电子邮件（例如 *Mr John Smith · Child · 555-0100 · john@example.com*），如果会员有添加照片，照片会显示在其旁边。套用后，系统会在该会员的住户中，以这些资料和照片建立该人员。

变更套用后，任务会自动关闭。

## 设置审批小组 {#setting-up-the-approval-group}

如果你的教会希望个人资料变更须经审批，必须先设置通讯录审批小组。

1. 打开快速菜单，并展开 **Mobile**。
2. 点击 **Member portal**（"Portal settings"页面）。
3. 在 **Directory Approval Group** 下，选择应审查个人资料变更请求的小组。
4. 点击 **Save**。

该小组的任何成员，都会在仪表板的 **Assigned to My Groups** 下看到新进来的个人资料变更请求。

同一个通讯录审批小组也会审查**账户删除请求**——请参阅[审查账户删除请求](./account-deletion.md)。

:::tip
请确认你的审批人确实是已设置小组的成员——只有小组成员才会看到这些请求。
:::
