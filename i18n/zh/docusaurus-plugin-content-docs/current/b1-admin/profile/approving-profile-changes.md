# 批准个人资料更改

<div class="article-intro">

当您的教会要求管理员批准个人资料更新时，成员通过 B1 Mobile 应用提交他们的更改，这些请求在 B1 Admin 中显示为任务。本指南说明如何查看和批准它们。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须是在**移动 → B1 Mobile** 中指定为**目录批准组**的组的成员
- 如果未配置批准组，个人资料更改会立即应用，无需审核

</div>

## 查找待处理请求的位置

当成员提交个人资料更改时，它会显示为分配给您的批准组的任务。您可以在两个地方找到它：

**从仪表板：**
1. 登录 B1 Admin — 仪表板会自动加载。
2. 在右侧的**任务**部分，单击**分配给我的组**选项卡。
3. 任何待处理的个人资料更改请求都将列在那里。

**从服务 → 我的工作：**
1. 在顶部导航中，单击**服务**。
2. 单击**我的工作**。
3. 在任务下方单击**分配给我的组**选项卡。

## 审核并批准请求

1. 单击**个人资料更新**任务以打开它。
2. 在**请求的更改**下，您将看到成员想要更新的每个字段以及他们提交的新值。
3. 审核更改。
4. 单击**应用**以批准并保存对其个人资料的更改。

任务在应用更改后会自动关闭。

## 设置批准组

如果您的教会希望个人资料更改需要批准，必须先配置目录批准组。

1. 在顶部导航中，单击**移动**。
2. 单击**B1 Mobile**。
3. 在**目录批准组**下，选择其成员应审核个人资料更改请求的组。
4. 单击**保存**。

该组的任何成员都将在其仪表板上的**分配给我的组**下看到传入的个人资料更改请求。

:::tip
确保您的批准者实际上是配置的组的成员 — 只有组成员才能看到请求。
:::
