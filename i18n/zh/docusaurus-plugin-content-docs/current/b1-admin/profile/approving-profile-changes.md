# 批准个人资料更改

<div class="article-intro">

当你的教会要求管理员批准个人资料更新时，成员通过B1 Mobile应用提交他们的更改，这些请求在B1 Admin中显示为任务。本指南解释如何审查和批准它们。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你必须是在**移动应用 → 成员门户**中指定为**目录批准小组**的小组成员
- 如果没有配置批准小组，个人资料更改会立即应用而无需审查

</div>

## 在哪里找到待处理的请求

当成员提交个人资料更改时，它会作为分配给你的批准小组的任务出现。你可以在两个地方找到它：

**从仪表板（你的主页）：**
1. 登录到B1 Admin — 仪表板会自动加载。
2. 在右侧的**任务**部分，点击**分配给我的小组**标签。
3. 任何待处理的个人资料更改请求都将列在那里。

**从服侍 → 我的工作：**
1. 在顶部导航中，点击**服侍**。
2. 点击**我的工作**。
3. 在任务下点击**分配给我的小组**标签。

## 审查和批准请求

1. 点击**个人资料更新**任务以打开它。
2. 在**请求的更改**下，你会看到成员想要更新的每个字段以及他们提交的新值。
3. 审查更改。
4. 点击**应用**以批准并保存更改到他们的个人资料。

应用更改后，任务会自动关闭。

## 设置批准小组

如果你的教会想要个人资料更改需要批准，必须先配置目录批准小组。

1. 在顶部导航中，点击**移动应用**。
2. 点击**成员门户**（"门户设置"页面）。
3. 在**目录批准小组**下，选择其成员应审查个人资料更改请求的小组。
4. 点击**保存**。

该小组的任何成员都会在他们的仪表板上的**分配给我的小组**下看到传入的个人资料更改请求。

同一目录批准小组也审查**账户删除请求** — 查看[审查账户删除请求](./account-deletion.md)。

:::tip
确保你的批准者实际上是配置的小组的成员 — 只有小组成员才会看到请求。
:::
