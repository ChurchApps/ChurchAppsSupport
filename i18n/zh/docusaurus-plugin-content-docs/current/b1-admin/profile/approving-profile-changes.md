# 审批个人资料变更

<div class="article-intro">

当您的教会要求管理员审批个人资料更新时，会员会通过 B1 应用提交变更，这些申请会以任务的形式出现在 B1 Admin 中。本指南说明如何审核和批准这些申请。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须是在 **Mobile &rarr; Member portal**（移动端 > 会员门户）中被指定为 **Directory Approval Group**（目录审批小组）的小组成员
- 如果尚未配置审批小组，个人资料变更将立即生效，无需审核

</div>

## 在哪里找到待处理的申请

当会员提交个人资料变更时，它会以任务的形式分配给您的审批小组。您可以在以下两个地方找到它：

**从仪表板（您的主页）：**
1. 登录 B1 Admin——仪表板会自动加载。
2. 在 **My tasks**（我的任务）部分，点击 **All tasks**（全部任务）。（My tasks 只列出分配给您个人的未完成任务。）
3. 点击 **Assigned to My Groups**（分配给我的小组）标签页。任何待处理的个人资料变更申请都会列在这里。

**从 Serving &rarr; My Work（服事 > 我的工作）：**
1. 打开[快速跳转菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **Serving**。
2. 点击 **My Work**。
3. 点击任务下的 **Assigned to My Groups** 标签页。

## 审核并批准申请

1. 点击 **Profile Update**（个人资料更新）任务将其打开。
2. 在 **Requested Changes**（请求的变更）下，您会看到会员希望更新的每个字段，以及其提交的新值。
3. 审查这些变更。
4. 点击 **Apply**（应用），批准并保存对其个人资料的变更。

添加家庭成员的申请会在一行中显示新人员的称谓、姓名、家庭角色和手机号码（例如 *Mr John Smith · Child · 555-0100*）。应用该申请后，系统会在该会员的家庭中按这些信息创建此人。

变更应用后，任务会自动关闭。

## 设置审批小组

如果您的教会希望个人资料变更需要经过审批，必须先配置目录审批小组。

1. 打开快速跳转菜单，展开 **Mobile**（移动端）。
2. 点击 **Member portal**（会员门户，即“Portal settings”页面）。
3. 在 **Directory Approval Group**（目录审批小组）下，选择应负责审核个人资料变更申请的小组。
4. 点击 **Save**。

该审批小组的任何成员都会在仪表板的 **Assigned to My Groups** 下看到收到的个人资料变更申请。

同一个目录审批小组也会审核**账户删除申请**——参见[审核账户删除申请](./account-deletion.md)。

:::tip
请确保您的审批人确实是已配置小组的成员——只有小组成员才能看到这些申请。
:::
