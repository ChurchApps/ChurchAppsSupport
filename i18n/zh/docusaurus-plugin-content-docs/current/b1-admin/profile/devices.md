# 管理设备

<div class="article-intro">

设备页面让你管理连接到你账户的 ChurchAppsPlayer 与 FreePlay 设备。这些设备用于串流内容，并在你所在场地的屏幕上显示教会的媒体。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 请确保 ChurchAppsPlayer 或 FreePlay 设备已开机并连接到互联网
- 记下设备屏幕上显示的配对码
- 如果你尚未检视过，请先查看你的[个人资料设置](./managing-profile.md)

</div>

## 打开设备页面 {#opening-the-devices-page}

打开[快速菜单](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），输入 **Devices**，然后选择它。当你位于个人资料页面时，快速菜单也会并列显示 **Profile** 与 **Devices**。

## 检视你的设备 {#viewing-your-devices}

打开设备页面时，你会看到一个表格，列出与你账户配对的 ChurchAppsPlayer 与 FreePlay 屏幕，并包含以下信息：

- **Label**——你为设备指定的名称（在你为其命名之前，显示为 **Device**）。
- **Registration Date**——该设备首次与你的账户配对的时间。
- **Last Active Date**——该设备最近一次连接到你账户的时间。

## 新增设备 {#adding-a-new-device}

1. 点击设备页面顶端的 **Add Screen** 按钮。
2. 找到你要连接的 ChurchAppsPlayer 或 FreePlay 设备上显示的配对码。
3. 将其输入 **Pairing Code** 栏位。
4. 如果你的教会已设置[计划类型](../serving/plans.md)，**Show Plans For** 下拉菜单可让你为 FreePlay 屏幕选择其应遵循的计划类型——若只希望将设备用于浏览与通知，请保持为 **None (notifications only)**。
5. 点击 **Save**。设备配对完成后会出现在你的设备表格中。如果配对码有误或已过期，你会看到 *"Invalid pairing code"*。

:::tip
在尝试配对之前，请确保设备已开机并连接到互联网。配对码会显示在设备的屏幕上。
:::

## 编辑设备标签 {#editing-a-device-label}

1. 点击设备表格中该设备旁边的 **Edit**。
2. 将 **Label** 更新为具描述性的名称（例如"Sanctuary Main Screen"或"Lobby Display"）。
3. 点击 **Save**。

**Edit Device** 表单还包含 **Associated Content** 列表，列出你教会的 Lessons.church 班级。勾选某个班级，即可将其与该屏幕关联；每个方框在你点击后会立即储存。

:::tip
使用清楚、具描述性的标签，能让你轻松辨识每台设备，尤其是在你的教会设置了多个屏幕的情况下。
:::

## 管理设备访问 {#managing-device-access}

使用设备页面来追踪哪些设备可以访问你教会的串流与内容。如果某台设备已不再使用，请将它从你的账户中移除：

1. 点击该设备旁边的 **Edit**。
2. 点击 **Remove**，然后再次点击 **Remove** 以确认。

该屏幕需要新的配对码才能再次连接。

:::warning
请定期检查你已连接的设备，确保只有使用中且获得授权的设备与你的账户相连。为维护安全，请移除所有不再使用的设备。
:::
