# 管理设备

<div class="article-intro">

"设备"页面让您管理连接到您账户的 ChurchAppsPlayer 和 FreePlay 设备。这些设备用于在您所在地点的屏幕上流式播放内容和展示教会媒体。

</div>

<div class="prereqs">
<h4>准备工作</h4>

- 已开启并连接到互联网的 ChurchAppsPlayer 设备
- 记下设备屏幕上显示的配对码
- 如果您还未查看过，请先查看[个人资料设置](./managing-profile.md)

</div>

## 查看您的设备

打开"设备"页面后，您会看到一个表格，列出所有已注册的设备及以下信息：

- **标签** -- 您为该设备指定的名称。
- **注册日期** -- 该设备首次与您的账户配对的时间。
- **最近活跃日期** -- 该设备最近一次连接到您账户的时间。

## 添加新设备

1. 点击"设备"页面顶部的**添加设备**按钮。
2. 系统会提示您输入**配对码**。
3. 在您想要连接的 ChurchAppsPlayer 或 FreePlay 设备上找到显示的配对码。
4. 输入该配对码。如果是 FreePlay 电视，会有一个**显示计划来源**下拉菜单，让您选择该屏幕要跟随的计划类型——如果只想将设备用于浏览和通知，请保持在**无**。
5. 确认。配对成功后，该设备会出现在您的设备表格中。

:::tip
在尝试配对之前，请确保设备已开启并连接到互联网。配对码会显示在设备屏幕上。
:::

## 编辑设备标签

1. 在设备表格中点击**设备名称**。
2. 将标签更新为更具描述性的内容（例如"主堂主屏幕"或"大厅显示屏"）。
3. 保存您的更改。

:::tip
使用清晰、描述性的标签可以更容易地识别各个设备，尤其是在教会设置了多个屏幕的情况下。
:::

## 管理设备访问权限

使用"设备"页面来跟踪哪些设备可以访问教会的流媒体和内容。如果某个设备不再使用，您可以将其从账户中移除，以保持设备列表的整洁和安全。

:::warning
定期检查已连接的设备，确保只有活跃、经过授权的设备与您的账户关联。移除不再使用的设备以维护安全。
:::
