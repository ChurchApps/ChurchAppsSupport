# 审查账户删除请求

<div class="article-intro">

当教会配置了目录批准组时，账户删除不再立即进行 —— 成员的请求变成一个任务，你的批准组在删除任何内容前审查它。本页面解释了请求如何进行、如何批准或拒绝它，以及在各种情况下会发生什么。

</div>

<div class="prereqs">
<h4>开始前</h4>

- **目录批准组**必须在**移动应用 → 成员门户**下配置。没有它的话，在"个人资料"页面上单击**删除我的账户**仍然会立即删除账户，没有审查步骤。请参阅[移动应用设置](../settings/mobile-app.md)。
- 批准或拒绝请求需要**人员 > 编辑**权限。

</div>

## 成员如何请求删除

账户删除从**我的个人资料**页面请求 —— 在[管理你的个人资料](./managing-profile.md)中介绍的相同共享账户页面 —— 在其**账户删除**部分下。当配置了批准组时，确认请求不会立即删除任何内容。相反，它：

1. 创建一个题为**"账户删除请求"**的开放任务，分配给目录批准组，在**服务 → 任务**下。
2. 为该人禁用**删除我的账户**按钮，并显示一条通知表示请求正在等待审查。

在一个请求已经打开时提交第二个请求只是重新打开相同的任务 —— 一个人一次只能有一个待处理的删除请求。

## 审查请求

1. 转到**服务 → 任务**（或你的仪表板上的**分配给我的小组**，与[个人资料更改请求](./approving-profile-changes.md)出现的位置相同）。
2. 打开题为**"来自*姓名*的账户删除请求"**的任务。
3. 你将看到两个操作：**批准删除**和**拒绝**。

### 批准

确认**"永久匿名此人的记录并删除他们的登录？这无法撤销。"** 这用通用值替换该人的个人信息（与人记录上的**数据管理 > 匿名**操作使用的匿名化相同 —— 请参阅[数据安全](../settings/data-security.md)），并删除他们的登录。任务自动关闭，成员会收到通知他们的请求已被批准。

### 拒绝

拒绝需要一个原因，因为GDPR仅允许因法律例外而拒绝删除请求：

- **法律保留**（捐赠、税务或就业记录）
- **法律主张所需**
- **其他** —— 在文本框中解释（至少10个字符）

成员会收到关于决定以及你提供的原因的通知，如果他们不同意，可能会重新提交他们的请求或升级到监管机构。

:::info
教会有30天的时间来回应删除请求。任务在28天内到期，如果批准组在21天和27天后仍然打开，会收到自动提醒。
:::

:::tip
删除和个人资料更改请求使用相同的目录批准组和基于任务的审查流程 —— 如果你还需要审查目录更新请求，请参阅[批准个人资料更改](./approving-profile-changes.md)。
:::
