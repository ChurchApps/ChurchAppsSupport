# 审查账户删除请求

<div class="article-intro">

当教会配置了目录批准小组时，账户删除不再立即发生 — 成员的请求变成一个任务，由你的批准小组在删除任何内容之前审查。此页面解释如何进行请求，如何批准或拒绝，以及每种情况下会发生什么。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- **目录批准小组**必须在**移动应用 → 成员门户**下配置。没有配置的情况下，在个人资料页面上点击**删除我的账户**仍会立即删除账户，没有审查步骤。查看[移动应用设置](../settings/mobile-app.md)。
- 批准或拒绝请求需要**人员 > 编辑**权限。

</div>

## 成员如何请求删除

账户删除是从**我的个人资料**页面请求的 — 同一个在[管理您的个人资料](./managing-profile.md)中涵盖的共享账户页面 — 在其**账户删除**部分下。配置批准小组后，确认请求不会立即删除任何内容。相反，它：

1. 创建标题为**"账户删除请求"**的开放任务，分配给目录批准小组，在**服侍 → 我的工作**下。
2. 为该人禁用**删除我的账户**按钮，并显示请求正在等待审查的通知。

在已有一个开放请求的情况下提交第二个请求只会重新打开相同的任务 — 一个人一次只能有一个待处理删除请求。

## 审查请求

1. 转到**服侍 → 我的工作**（或仪表板上的**分配给我的小组**，与[个人资料更改请求](./approving-profile-changes.md)出现的位置相同）。
2. 打开标题为**"来自 *姓名* 的账户删除请求"**的任务。
3. 你会看到两个操作：**批准删除**和**拒绝**。

### 批准

确认**"永久匿名化此人的记录并删除其登录？这无法撤销。"** 这将用通用值替换该人的个人信息（与**数据管理 > 匿名化**操作使用的相同匿名化 — 查看[数据安全](../settings/data-security.md)）并删除其登录。任务自动关闭，成员收到通知，他们的请求已获批。

### 拒绝

拒绝需要理由，因为GDPR仅允许因法律例外拒绝删除请求：

- **法律保留**（捐款、税收或雇用记录）
- **需要以提出法律主张**
- **其他** — 在文本框中解释（至少10个字符）

成员会收到决定通知以及你提供的理由，可能会重新提交请求或向监督当局上报，如果他们不同意。

:::info
教会有30天时间回应删除请求。任务将在28天内完成，如果仍然开放，批准小组会在21天和27天后收到自动提醒。
:::

:::tip
删除和个人资料更改请求使用相同的目录批准小组和相同的基于任务的审查流程 — 如果你还需要审查目录更新请求，请查看[批准个人资料更改](./approving-profile-changes.md)。
:::
