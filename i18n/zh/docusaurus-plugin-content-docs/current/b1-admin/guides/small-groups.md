# 管理小组

<div class="article-intro">

设置小组、查经班或事工团队，并管理成员、小组日历和讨论。在网站上发布全教会的活动日历，让访客了解教会的动态，也让会员通过网络门户和手机应用程序保持联系。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 具有管理员权限的 B1 Admin 账户
- [已添加到通讯录的人员](../people/adding-people.md)（小组成员须先存在于系统中）

</div>

## 步骤 1：建立小组类别与小组 {#step-1-create-group-categories--groups}

将小组归类，方便会员轻松找到他们需要的小组。

请按照[建立小组](../groups/creating-groups.md)指南完成以下操作：

1. 在[快速菜单](../introduction.md#getting-around-with-the-jump-menu)中，选择 **People > Groups**，然后点击 **Add Group**
2. 输入用于分类的 **Category Name**（例如「小组」、「查经班」、「事工团队」、「委员会」）以及小组的 **Name**（例如「周二晚男士小组」、「女士查经班」），然后点击 **Add**
3. 打开小组，点击 **Edit**，填写 **Meeting Time**、**Meeting Location** 和 **Description**。在 **Enrollment** 中设置人员是可以立即加入、需要申请加入，还是只能由负责人添加

## 步骤 2：添加成员与负责人 {#step-2-add-members--leaders}

为小组加入成员，并指定可以管理各自团队的负责人。

请按照[小组成员](../groups/group-members.md)指南完成以下操作：

1. 在小组页面点击 **All members**，并在 **Add Person** 框中搜索人员以将其添加
2. 点击星形图标（**Make Leader**）指定小组负责人。负责人将获得额外的权限

:::tip
小组负责人无需完整的管理员权限，即可管理自己小组的日历、发布讨论并协调活动。
:::

## 步骤 3：设置小组日历 {#step-3-set-up-group-calendars}

为每个小组设置专属日历，用于安排聚会和活动。

请按照[小组日历](../groups/group-calendar.md)指南完成以下操作：

1. 添加定期聚会（例如「每周二晚上 7 点」）以及一次性活动（例如「小组烧烤 - 3 月 15 日」）
2. 小组负责人可以在 B1.church 上为自己的小组添加和管理活动
3. 在 B1 Admin 中，你可以一次安排整个季度的聚会：打开小组，在 **Calendar** 区块中点击 **All events**，然后点击 **+ Add Events**

## 步骤 4：建立全教会日历 {#step-4-create-a-church-wide-calendar}

将所有小组的活动汇集到一个统一的全教会日历中。

请按照[建立日历](../calendars/creating-calendars.md)和[精选日历](../calendars/curated-calendar.md)指南完成以下操作：

1. 在快速菜单中，选择 **Calendars > Calendars**，点击 **Add Calendar**，输入 **Calendar Name**，然后点击 **Create**
2. 打开日历，点击 **Add Group**，选择一个小组，并选择 **Add all the events of the group**（或仅选择特定活动）。每个小组都需重复此步骤
3. 点击 **Subscribe** 分享 ICS 订阅链接，让会员可以将活动添加到他们个人的日历应用程序（Google 日历、Apple 日历、Outlook）中

:::info
当你添加某个小组的所有活动后，精选日历会自动加入新活动——当小组负责人添加活动时，活动也会同步显示在全教会日历上。
:::

## 步骤 5：发布到你的网站 {#step-5-publish-to-your-website}

让访客和会员在你的 B1 网站上看到小组和日历。

请按照[页面编辑器](../website/page-editor.md)指南完成以下操作：

1. 在 B1 网站的页面中添加 **Calendar** 元素，以显示精选日历
2. 添加 **Groups Browser**（或 **Group List**）元素，让访客可以浏览可加入的小组，并了解如何参与

## 步骤 6：会员体验 {#step-6-member-experience}

会员可以通过手机或电脑发现、加入并参与小组。

1. 会员可以在 [B1.church](../../b1-church/groups/browsing-groups.md) 上浏览并加入小组
2. 小组成员可以查看详情和日历，并在[讨论](../../b1-church/groups/conversations.md)中发帖
3. 所有小组功能也可在 [B1 App](../../b1-church/groups/index.md) 中使用

:::info
会员无论在网页还是手机上，都能看到自己的小组、即将举行的活动和小组讨论——所有内容保持同步。
:::

## 完成！ {#youre-done}

你的小组已设置完成并相互连接。会员可以发现小组、查看活动，并通过讨论保持联系——全部都在你的网站和手机应用程序上。小组负责人也可以独立管理自己的团队。
