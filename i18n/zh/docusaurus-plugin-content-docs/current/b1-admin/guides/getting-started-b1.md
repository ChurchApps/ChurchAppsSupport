# 使用 B1 快速设置您的教会

<div class="article-intro">

这是一份面向新教会的完整入门指南，涵盖从创建账户到导入成员通讯录、配置首批功能的全过程。请按顺序完成以下步骤，让您的教会在 B1 上顺利启动。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 一个有效的电子邮箱地址
- 您的教会徽标和品牌素材（颜色、图片）——建议准备，但开始使用并非必需

</div>

## 第 1 步：创建您的账户

注册您的教会，并成为第一位管理员。

请按照 [创建账户](../../getting-started/create-account.md) 指南完成以下操作：

1. 访问 b1.church，使用您的电子邮箱注册
2. 验证您的电子邮箱地址
3. 选择"创建新教会"，并输入教会名称
4. 您将自动成为域管理员，拥有全部功能的完整权限

## 第 2 步：配置教会设置

填写教会的基本信息并设置品牌形象。

请按照 [教会设置](../settings/church-settings.md) 指南完成以下操作：

1. 填写教会名称、地址、电话号码和电子邮箱
2. 设置您的子域名（将成为 yourchurch.b1.church）
3. 上传教会徽标和图片

:::tip
您的子域名会出现在网站网址和奉献页面网址中，因此请选择简短且易于识别的名称（例如，"grace"代表 Grace Community Church）。
:::

## 第 3 步：设置角色并邀请团队

控制每个人可以访问的内容，并让您的团队参与进来。

请按照 [角色与权限](../settings/roles-permissions.md) 指南完成以下操作：

1. 为您的团队创建角色（例如"牧师"、"办公室管理员"、"财务团队"、"敬拜领袖"）
2. 为每个角色分配特定权限，确保人们只能看到其所需的内容
3. 通过添加成员并分配角色来邀请团队成员

:::info
您不必独自完成所有工作。尽早邀请办公室职员、牧师和事工负责人，他们可以协助设置各自负责的领域。
:::

## 第 4 步：导入您的会众信息

将现有的成员通讯录导入 B1。

请参阅 [导入数据](../people/importing-data.md) 指南。您有两种选择：

1. **CSV 上传**——从当前系统或电子表格中导出，整理为 CSV 格式，然后上传至 B1
2. **Breeze 迁移**——一键导入，可同时转入人员、照片、小组、奉献和考勤记录

:::tip
从 Breeze 迁移？导入工具可一步完成所有数据的转移，包括人员、照片、小组、奉献和考勤历史记录。这是最快速的入门方式。
:::

## 第 5 步：配置移动应用

为您的会众定制 B1 应用体验。

请按照 [移动应用设置](../settings/mobile-app.md) 指南完成以下操作：

1. 自定义会众在 B1 应用中看到的标签页
2. 设置标签页的名称、图标和类型（圣经、直播、奉献、网站等）
3. 控制会众可以看到的功能

## 第 6 步：开始设置各项功能

基础设置已经就绪，请按照以下指南设置具体功能：

- [设置在线奉献](./online-giving.md)——通过网站和应用接受奉献
- [启动您的教会网站](./launch-website.md)——建立您的教会网站
- [开展小组事工](./small-groups.md)——组织小组、查经班和各类事工
- [设置儿童签到](./childrens-checkin.md)——为儿童事工提供自助签到服务
- [管理主日志愿者](./sunday-volunteers.md)——协调您的服事团队
- [建立您的讲道资料库](./sermon-library.md)——将讲道上线并设置直播
- [记录考勤](./track-attendance.md)——监控参加礼拜和小组的人员

## 完成！

您的教会已在 B1 上设置完成。团队已获得访问权限，人员信息已导入，您可以开始使用对事工最为重要的功能了。请浏览上方的功能指南，逐一设置各个领域。
