# 追踪教会出席人数

<div class="article-intro">

为你的主日敬拜和小组设置出席追踪——从配置校园和敬拜时间,到手动记录出席人数或通过自助签到应用记录,再到在报告中查看趋势。完成后,你将全面了解谁在参加以及何时参加。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 拥有管理员权限的B1 Admin账户
- [已将人员添加到你的通讯录](../people/adding-people.md)
- [为你要追踪的事工创建了小组](../groups/creating-groups.md)

</div>

## 步骤1:配置校园和敬拜时间

定义你的教会在哪里以及何时聚集。

按照[出席设置](../attendance/setup.md)指南进行:

1. 添加你的校园(例如,"主校园")
2. 添加敬拜时间(例如,"周日上午9:00"、"周日上午11:00"、"周三晚上7:00")
3. 为每个敬拜时间分配小组,以定义在该敬拜期间哪些班级/事工在聚集

## 步骤2:启用小组出席追踪

为你要监控的小组开启出席追踪。

按照[创建小组](../groups/creating-groups.md)指南进行:

1. 编辑你要追踪的每个小组并开启"追踪出席人数"
2. 将小组与敬拜时间关联,以便出席人数记录对应到正确的敬拜

:::info
并非每个小组都需要出席追踪。只为你想监控参与情况的小组启用它——儿童班级、小组、主日学等。
:::

## 步骤3:手动记录出席人数

勾选每场敬拜和小组的出席人员。

按照[记录出席人数](../attendance/recording-attendance.md)指南进行:

1. 打开小组的**场景**标签并添加一个场景,记录日期和敬拜时间。勾选**也为其他小组添加**以同时为该敬拜时间的每个班级创建场景。
2. 勾选每个小组的出席人员

:::tip
手动追踪非常适合成人敬拜、小组以及不便使用签到终端的任何场景。
:::

## 步骤4:设置自助签到(可选)

让成员使用平板终端自行签到。

按照[签到](../attendance/check-in.md)指南进行:

1. 在平板电脑上安装B1 Checkin应用,用于自助签到
2. 成员搜索自己的姓名并为自己及家人签到
3. 签到出席人数记录与手动输入的记录一起显示——数据没有区别

:::info
如需完整的儿童事工签到设置(包括硬件和打印机配置),请参阅[儿童签到指南](./childrens-checkin.md)。
:::

## 步骤5:查看出席人数报告

全面了解你的教会的参与情况。

按照[出席人数报告](../reports/attendance-reports.md)指南进行。有三种报告视图可用:

1. **出席趋势** -- 查看一段时间内的出席人数变化,发现增长或下降趋势
2. **小组出席人数** -- 查看每个小组在日期范围内的出席人员及其CSV下载
3. **每日小组出席人数** -- 按天列出明细,用于详细分析

:::info
报告同时包含手动记录和自助签到的出席人数数据。数据显示方式没有区别——两种方法的数据汇入同一报告。
:::

## 完成!

你的出席追踪已设置完成。无论你是手动记录出席人数、使用签到应用,还是两者兼用——所有数据都汇入相同的报告,让你清晰了解教会各项活动的参与情况。
