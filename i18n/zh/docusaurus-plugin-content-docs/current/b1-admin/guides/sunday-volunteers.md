# 管理主日志愿者

<div class="article-intro">

设置您的志愿者团队，创建每周的服事计划，分配岗位，使用赞美诗构建礼拜程序，并分配主日任务。完成后，您的志愿者即可在 B1 网站和移动应用上看到自己的任务，并可直接接受或拒绝。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 拥有管理员权限的 B1 Admin 账户
- 已[将志愿者添加到您的人员目录](../people/adding-people.md)

</div>

## 第 1 步：创建志愿者团队

将您的志愿者组织成团队，以便按事工领域管理服事安排。

按照[创建小组](../groups/creating-groups.md)和[小组成员](../groups/group-members.md)指南完成以下操作：

1. 创建一个类别（例如“主日早上团队”）
2. 创建小组，例如“敬拜团”“音响与媒体”“迎宾”“儿童事工志愿者”
3. 通过搜索每位志愿者的姓名并点击添加，将他们加入各个小组

:::tip
在小组的成员列表中（在小组页面上点击 **All members（全部成员）**），使用星形图标（**Make Leader（设为负责人）**）指定团队负责人。负责人可以管理自己小组的日历并协调团队工作。
:::

## 第 2 步：建立您的赞美诗库

添加敬拜赞美诗，以便每周将其纳入服事计划。

按照[赞美诗](../serving/songs.md)指南完成以下操作：

1. 添加敬拜赞美诗，包括标题、作者和时长
2. 对于每首赞美诗，添加编曲版本，包括歌词和调式标注
3. 添加外部链接，例如 YouTube 演唱视频、和弦谱或乐谱

:::info
在这里添加的赞美诗，之后可以纳入任何服事计划。建立一次曲库，每周重复使用。
:::

## 第 3 步：创建服事计划

计划是每周的安排，用于告诉志愿者他们需要在哪里服事。

按照[计划](../serving/plans.md)指南完成以下操作：

1. 进入“服事”，选择您的事工选项卡，然后打开您的计划类型
2. 点击 **New Plan（新建计划）**，并选择服事日期。若要一次设置多个主日，请从上一个计划复制，并在 **Repeat weekly for this many weeks（每周重复的周数）**中输入周数
3. 在计划的 **Serving Team Assignments（服事团队安排）**部分，添加岗位并为其分配志愿者
4. 志愿者会看到其服事状态（Requested 已请求、Confirmed 已确认、Pending 待定）
5. 为计划类型开启[志愿者提醒](../serving/plans.md#volunteer-reminders)，以便在每次礼拜前通过推送、电子邮件或短信提醒志愿者

## 第 4 步：编排礼拜程序

规划好礼拜从头到尾的流程。

按照[礼拜程序](../serving/service-order.md)指南完成以下操作：

1. 打开您的计划，在顶部找到 **Order of Service（礼拜程序）**部分
2. 点击 **Add（添加）**以添加环节：敬拜赞美诗（来自您的曲库）、祷告、经文诵读、报告、讲道、奉献、祝福
3. 拖放各项以重新排列礼拜流程

:::info
礼拜程序是针对特定计划的。这里的更改不会影响其他计划或主赞美诗库。
:::

## 第 5 步：分配主日任务

跟踪一次性的主日职责，确保没有任何事项遗漏。

按照[任务](../serving/tasks.md)指南完成以下操作：

1. 为“准备圣餐饼杯”“印制周报”或“布置音响设备”等职责创建任务
2. 将每项任务分配给负责的人员或小组
3. 任务会出现在 **服事 > 我的工作（Serving > My Work）**中、受托人的仪表板上，以及移动应用中

:::info
B1 Admin 不再按重复计划创建任务。对于需要让人员逐步完成的重复流程，请使用带有计划触发器的[工作流](../serving/workflows.md)。
:::

## 第 6 步：启用自助报名（可选）

让志愿者自行报名岗位，而不必等待管理员分配。

1. 在创建或编辑计划时，设置 **Signup Deadline（报名截止时间）**（礼拜前的小时数），以控制自助报名何时截止。截止时间从计划的第一场礼拜时间往前计算。留空则没有截止时间。新计划默认沿用上一个计划的截止时间。
2. 可选择开启 **Show volunteer names on signup page（在报名页面显示志愿者姓名）**，让志愿者看到还有哪些人已报名。
3. 对于每个岗位，勾选 **Allow Self-Signup（允许自助报名）**复选框，使其可供自助报名。
4. 为每个岗位添加**描述**，让志愿者了解该角色的职责。

自助报名岗位创建后，它们会自动出现在 [B1.church](../../b1-church/serving/volunteer-signup) 和 [B1 移动应用](../../b1-mobile/serving/volunteer-signup)的志愿者报名页面上。成员可以浏览开放的岗位，查看剩余名额，并一键报名。

:::tip
在同一个计划中混合使用管理员分配岗位和自助报名岗位。例如，直接指派敬拜带领者，但让迎宾和咖啡服务人员自行选择。
:::

## 第 7 步：通知志愿者

被分配了服事任务的志愿者会自动看到他们的计划，并可以作出回应。

1. 志愿者可以在 [B1.church](../../b1-church/plans/viewing-plans.md) 和 [B1 移动应用](../../b1-mobile/serving/viewing-plans.md)上看到他们的计划
2. 他们可以直接在任一平台上接受或拒绝安排
3. 他们可以为无法服事的周次设置不可服事日期
4. 计划可以打印出来用于排练，或张贴在后台
5. 志愿者可以通过[志愿者报名页面](../../b1-church/serving/volunteer-signup)浏览并报名开放的岗位

:::tip
移动应用的推送通知会在志愿者收到新安排或计划有变动时提醒他们。
:::

## 大功告成！

您的志愿者管理系统已经设置完成。每周创建一个新计划、分配岗位，您的团队就能在手机或电脑上看到一切。
