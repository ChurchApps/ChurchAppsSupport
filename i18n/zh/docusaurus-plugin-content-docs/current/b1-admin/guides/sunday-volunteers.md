# 管理周日志愿者

<div class="article-intro">

设置志愿者团队，创建每周的服事计划，分配岗位，使用敬拜诗歌编排服事流程，并分配周日任务。完成后，志愿者可以在 B1 网站和移动应用上看到自己的任务，并直接接受或拒绝。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 拥有管理员权限的 B1 Admin 账户
- 已将志愿者[添加到您的人员名录](../people/adding-people.md)

</div>

## 第 1 步：创建志愿者团队

将志愿者分组编入团队，便于按事工领域管理服事安排。

请参考[创建小组](../groups/creating-groups.md)和[小组成员](../groups/group-members.md)指南，完成以下操作：

1. 创建一个分类（例如“周日早间团队”）
2. 创建小组，例如“敬拜团队”“音响与媒体”“迎宾”“儿童事工志愿者”
3. 搜索志愿者姓名并点击添加，将其加入各个小组

:::tip
在小组的成员列表中（在小组页面点击**所有成员**），使用星形图标（**设为负责人**）指定团队负责人。负责人可以管理本小组的日历并协调团队工作。
:::

## 第 2 步：建立诗歌库

添加敬拜诗歌，以便每周将其加入服事计划。

请参考[诗歌](../serving/songs.md)指南，完成以下操作：

1. 添加敬拜诗歌，填写名称、作者和时长
2. 为每首诗歌添加编曲版本，并填写歌词和调式
3. 添加外部链接，例如 YouTube 演唱视频、和弦谱或乐谱

:::info
在此添加的诗歌之后可以加入任何服事计划。只需建立一次诗歌库，即可每周重复使用。
:::

## 第 3 步：创建服事计划

计划是每周的任务安排，用于告诉志愿者他们需要在哪里服事。

请参考[计划](../serving/plans.md)指南，完成以下操作：

1. 进入“服事”，选择您的事工标签，然后打开相应的计划类型
2. 点击**新建计划**并选择服事日期。若要一次设置多个主日，请从上一个计划复制，并在**计划数量**中输入数量
3. 在计划的**服事团队安排**部分，添加岗位并为其分配志愿者
4. 志愿者可以看到自己的安排状态（已请求、已确认、待定）
5. 为计划类型开启[志愿者提醒](../serving/plans.md#volunteer-reminders)，使志愿者在每次服事前通过推送、电子邮件或短信收到提醒

## 第 4 步：编排服事流程

规划从头到尾的服事流程。

请参考[服事流程](../serving/service-order.md)指南，完成以下操作：

1. 打开您的计划，在顶部找到**服事流程**部分
2. 点击**添加**，加入各个环节：敬拜诗歌（来自您的诗歌库）、祷告、经文诵读、报告、讲道、奉献、结束祷告
3. 拖放各项以调整服事流程的顺序

:::info
服事流程只针对单个计划。此处的更改不会影响其他计划或主诗歌库。
:::

## 第 5 步：分配周日任务

跟踪一次性的周日职责，确保没有遗漏。

请参考[任务](../serving/tasks.md)指南，完成以下操作：

1. 为“准备圣餐用品”“印刷主日周报”或“设置音响设备”等职责创建任务
2. 将每项任务分配给负责的个人或小组
3. 任务会显示在**服事 > 我的工作**中，也会出现在负责人的仪表板和移动应用上

:::info
B1 Admin 不再按重复计划创建任务。对于需要让人员逐步完成的重复流程，请使用带有定时触发器的[工作流](../serving/workflows.md)。
:::

## 第 6 步：开启自助报名（可选）

让志愿者自行报名岗位，无需等待管理员分配。

1. 创建或编辑计划时，设置**报名截止时间**（服事前的小时数），以控制自助报名的截止时间。时间从计划的第一个服事时间向前计算。留空则没有截止时间。新计划会沿用上一个计划的截止设置。
2. 可选：开启**在报名页面显示志愿者姓名**，让志愿者看到其他已报名的人。
3. 对于每个岗位，勾选**允许自助报名**复选框，使其可供自助报名。
4. 为每个岗位添加**描述**，让志愿者了解该角色的工作内容。

自助报名岗位创建后，会自动显示在 [B1.church 和 B1 App 上的志愿者报名页面](../../b1-church/serving/volunteer-signup.md)中。会众可以浏览开放的岗位，查看剩余名额，并一键报名。

:::tip
在同一计划中混合使用管理员分配和自助报名的岗位。例如，直接指定领诗者，同时让迎宾和咖啡服务人员自行选择。
:::

## 第 7 步：通知志愿者

被分配的志愿者会自动看到自己的计划，并可以回复。

1. 志愿者可以在 [B1.church 和 B1 App](../../b1-church/plans/viewing-plans.md) 上查看自己的计划
2. 他们可以直接在手机或电脑上接受或拒绝安排
3. 他们可以为无法参加服事的日期设置不可服事日期
4. 计划可以打印出来用于排练，或张贴在后台
5. 志愿者可以通过[志愿者报名页面](../../b1-church/serving/volunteer-signup.md)浏览并报名开放的岗位

:::tip
当志愿者获得新的安排或计划有所变动时，B1 App 中的推送通知会提醒他们。
:::

## 完成！

您的志愿者管理系统已设置完毕。每周创建新计划、分配岗位，您的团队即可在手机或电脑上查看所有信息。
