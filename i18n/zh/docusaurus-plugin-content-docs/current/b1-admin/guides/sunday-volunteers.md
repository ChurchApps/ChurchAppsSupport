# 管理周日志愿者

<div class="article-intro">

设置您的志愿者团队、创建每周服务计划、分配职位、使用敬拜歌曲构建服务顺序并分配周日任务。最后，您的志愿者将在B1网站和移动应用上看到他们的分配，并可以直接接受或拒绝。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 具有管理员访问权限的B1 Admin账户
- 志愿者[添加到您的人员目录](../people/adding-people.md)

</div>

## 第1步：创建志愿者团队

将您的志愿者组织成团队，以便您可以按事工领域管理分配。

按照[创建小组](../groups/creating-groups.md)和[小组成员](../groups/group-members.md)指南：

1. 创建一个类别（例如，"周日早间团队"）
2. 创建小组，如"敬拜团队"、"音声与媒体"、"迎宾员"、"儿童事工志愿者"
3. 通过搜索他们的名字并点击"添加"将志愿者添加到每个小组

:::tip
使用"成员"标签页中的绿色钥匙图标指定团队领导者。领导者可以管理他们自己的小组日历并协调他们的团队。
:::

## 第2步：构建您的歌曲库

添加敬拜歌曲，以便您每周可以将其拉入服务计划。

按照[歌曲](../serving/songs.md)指南：

1. 添加具有标题、艺术家和时长的敬拜歌曲
2. 对于每首歌曲，添加包含歌词和关键指定的编排
3. 添加指向YouTube表演、和弦图表或乐谱的外部链接

:::info
在这里添加的歌曲可以在以后的任何服务计划中使用。构建一次您的库，每周重复使用。
:::

## 第3步：创建服务计划

计划是告诉志愿者他们在哪里需要的每周分配。

按照[计划](../serving/plans.md)指南：

1. 导航到"服务"，选择您的事工标签页
2. 点击"添加计划"并选择服务日期
3. 在"分配"标签页上，展开每个团队并将志愿者分配到他们的职位
4. 志愿者将看到他们的分配状态（已请求、已确认、待定）

## 第4步：构建服务顺序

规划您的服务从开始到结束的流程。

按照[服务顺序](../serving/service-order.md)指南：

1. 在您的计划中切换到"服务顺序"标签页
2. 点击"添加项目"以添加元素：敬拜歌曲（来自您的库）、祷告、圣经阅读、公告、讲道、奉献、闭幕
3. 拖放项目以重新排列服务流程

:::info
服务顺序是特定于计划的。这里的更改不会影响其他计划或主歌曲库。
:::

## 第5步：分配周日任务

跟踪一次性周日责任，以确保没有任何事情遗漏。

按照[任务](../serving/tasks.md)指南：

1. 创建责任任务，例如"准备圣餐元素"、"打印公报"或"设置音声设备"
2. 将每个任务分配给负责人或小组
3. 任务显示在**服务 > 我的工作**下、分配人的仪表板上以及移动应用中

:::info
B1 Admin不再在重复时间表上创建任务。对于移动人员完成步骤的重复流程，使用带有计划触发器的[工作流](../serving/workflows.md)。
:::

## 第6步：启用自助注册（可选）

让志愿者自己注册职位，而不是等待管理员分配。

1. 编辑计划时，设置**注册截止日期**（服务前的小时数）以控制自助注册何时关闭。留空表示无截止日期。
2. 可选地切换**在注册页面上显示志愿者名称**以让志愿者看到谁还注册了。
3. 对于每个职位，勾选**允许自助注册**复选框以使其可用于自助服务。
4. 为每个职位添加**描述**，以便志愿者了解该角色涉及什么。

创建自助注册职位后，它们会自动出现在[B1.church](../../b1-church/serving/volunteer-signup)和[B1移动应用](../../b1-mobile/serving/volunteer-signup)上的志愿者注册页面。成员可以浏览开放职位、查看还剩多少个名额，并一键注册。

:::tip
在同一个计划中混合管理员分配和自助注册职位。例如，直接分配您的敬拜领导但让迎宾员和咖啡服务员自行选择。
:::

## 第7步：让志愿者了解

分配的志愿者会自动看到他们的计划并可以回应。

1. 志愿者在[B1.church](../../b1-church/plans/viewing-plans.md)和[B1移动应用](../../b1-mobile/serving/viewing-plans.md)上看到他们的计划
2. 他们可以直接从任一平台接受或拒绝分配
3. 他们可以为他们不可用的周设置禁止日期
4. 计划可以打印用于排练或张贴在后台
5. 志愿者可以通过[志愿者注册页面](../../b1-church/serving/volunteer-signup)浏览和注册开放职位

:::tip
移动应用上的推送通知会在志愿者接收新分配或计划更改时提醒他们。
:::

## 完成！

您的志愿者管理系统已设置。每周创建一个新计划、分配职位，您的团队会在他们的手机或电脑上看到所有内容。
