# 管理星期日志愿者

<div class="article-intro">

设置你的志愿者团队，创建每周的礼拜计划，分配岗位，使用敬拜歌曲编排礼拜程序，并分派星期日的任务。完成后，你的志愿者可以在 B1 网站和移动应用上看到自己的安排，并可直接接受或婉拒。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 拥有管理员权限的 B1 Admin 账号
- 志愿者已[添加到你的人员目录](../people/adding-people.md)中

</div>

## 第一步：创建志愿者团队

将志愿者组织成团队，以便按事工领域管理安排。

请按照[创建小组](../groups/creating-groups.md)和[小组成员](../groups/group-members.md)指南完成以下操作：

1. 创建一个分类（例如"星期日早间团队"）
2. 创建小组，例如"敬拜团队""音响与媒体""迎宾""儿童事工志愿者"
3. 通过搜索志愿者姓名并点击添加，将其加入各个小组

:::tip
在小组的成员列表中（在小组页面点击 **All members**），使用星形图标（**Make Leader**，设为负责人）指定团队负责人。负责人可以管理自己小组的日历，并协调团队工作。
:::

## 第二步：建立敬拜歌曲库

添加敬拜歌曲，以便每周将其加入礼拜计划中。

请按照[歌曲](../serving/songs.md)指南完成以下操作：

1. 添加敬拜歌曲，填写歌名、演唱者和时长
2. 为每首歌添加编曲版本，包括歌词和调号
3. 添加外部链接，例如 YouTube 演唱视频、和弦谱或乐谱

:::info
在此添加的歌曲之后都可以加入任何礼拜计划中。只需建立一次曲库，每周即可重复使用。
:::

## 第三步：创建礼拜计划

计划是每周的安排，用于告知志愿者他们需要在哪里服事。

请按照[计划](../serving/plans.md)指南完成以下操作：

1. 进入"服事（Serving）"，选择你的事工标签页，然后打开你的计划类型
2. 点击 **New Plan**，并选择礼拜日期。若要一次设置多个星期日，可以从上一个计划复制，并在 **Number of plans** 中填写数量
3. 在计划的 **Serving Team Assignments**（服事团队安排）部分，添加岗位并为其分配志愿者
4. 志愿者将看到自己的安排状态（Requested（已申请）、Confirmed（已确认）、Pending（待定））
5. 为该计划类型开启[志愿者提醒](../serving/plans.md#volunteer-reminders)，使志愿者在每场礼拜前通过推送、电子邮件或短信收到提醒

## 第四步：编排礼拜程序

规划从头到尾的礼拜流程。

请按照[礼拜程序](../serving/service-order.md)指南完成以下操作：

1. 打开你的计划，找到顶部的 **Order of Service**（礼拜程序）部分
2. 点击 **Add** 添加环节：敬拜歌曲（来自你的曲库）、祷告、经文诵读、公告、讲道、奉献、结束祷告
3. 通过拖放调整环节顺序

:::info
礼拜程序是针对每个计划单独设置的。这里的更改不会影响其他计划或主歌曲库。
:::

## 第五步：分派星期日任务

追踪一次性的星期日职责，确保没有任何事项被遗漏。

请按照[任务](../serving/tasks.md)指南完成以下操作：

1. 为"准备圣餐用品""打印周报""布置音响设备"等职责创建任务
2. 将每项任务分配给负责的人员或小组
3. 任务会显示在 **Serving > My Work** 下、受托人的仪表板上，以及移动应用中

:::info
B1 Admin 不再按重复周期自动创建任务。对于需要让人员按步骤推进的重复性流程，请使用带有定时触发器的[工作流](../serving/workflows.md)。
:::

## 第六步：开启自助报名（可选）

让志愿者自行报名岗位，而不必等待管理员分配。

1. 在创建或编辑计划时，设置**报名截止时间**（Signup Deadline，即礼拜前的小时数），以控制自助报名何时截止。该时间从计划的首场礼拜时间倒推计算。留空则没有截止时间。新计划会沿用上一个计划的截止时间。
2. 可选开启 **Show volunteer names on signup page**（在报名页面显示志愿者姓名），让志愿者看到其他已报名的人员。
3. 对于每个岗位，勾选 **Allow Self-Signup**（允许自助报名），使其可供自助报名。
4. 为每个岗位添加**描述**，使志愿者了解该职责的内容。

自助报名岗位创建后，会自动显示在 [B1.church](../../b1-church/serving/volunteer-signup.md) 和 [B1 移动应用](../../b1-mobile/serving/volunteer-signup.md)的志愿者报名页面上。成员可以浏览开放的岗位、查看剩余名额，并一键报名。

:::tip
在同一个计划中混合使用管理员分配和自助报名的岗位。例如，直接分配敬拜带领人，同时让迎宾和咖啡服务人员自行选择。
:::

## 第七步：通知志愿者

被分配的志愿者会自动看到自己的计划，并可以作出回应。

1. 志愿者可以在 [B1.church](../../b1-church/plans/viewing-plans.md) 和 [B1 移动应用](../../b1-mobile/serving/viewing-plans.md)上查看自己的计划
2. 他们可以直接在任一平台上接受或婉拒安排
3. 对于无法服事的周次，他们可以设置不可服事日期
4. 计划可以打印出来用于排练，或张贴在后台
5. 志愿者可以通过[志愿者报名页面](../../b1-church/serving/volunteer-signup.md)浏览并报名开放的岗位

:::tip
移动应用上的推送通知会在志愿者收到新安排或计划有变动时提醒他们。
:::

## 完成！

你的志愿者管理系统已设置完毕。每周创建一个新计划、分配岗位，你的团队就可以在手机或电脑上看到一切。
