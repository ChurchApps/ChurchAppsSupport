# 设置活动报名

<div class="article-intro">

创建活动报名表，收集参与者信息和可选付款，将其嵌入教会网站，并随时管理提交的报名信息。完成后，您将为任何教会活动拥有一个可分享的报名页面。

</div>

:::info
**处理活动报名的两种方式：** 本指南介绍**基于表单的报名**，它让您完全掌控自定义字段和付款收集。如果活动较简单，只需记录谁会参加，可以使用日历内置的**原生活动报名**功能。设置说明请参阅[创建日历](../calendars/creating-calendars.md#enabling-event-registration)。原生报名允许成员直接通过 [B1.church 或 B1 App](../../b1-church/events/registering.md) 报名，并提供名额跟踪、报名时间段和电子邮件确认。
:::

<div class="prereqs">
<h4>开始之前</h4>

- 具有管理员权限的 B1 Admin 账户
- 如需收集付款：请先[配置 Stripe](../donations/online-giving-setup.md)

</div>

## 第 1 步：创建独立表单

独立表单拥有自己的公开网址，任何人都可以访问，非常适合用于活动报名。

请按照[创建表单](../forms/creating-forms.md)指南进行以下操作：

1. 进入“表单”，点击“添加表单”
2. 选择“独立”类型，这将为您的表单提供独立的公开网址
3. 以活动命名（例如“男士退修会报名”“儿童假期圣经学校报名”）

## 第 2 步：添加问题

设置您需要向报名者收集的字段。

请按照[创建表单](../forms/creating-forms.md#adding-questions)指南添加问题：

1. 转到“问题”选项卡，添加您所需信息的字段，例如姓名、电子邮件、电话、饮食限制、T 恤尺码、紧急联系人等
2. 对于餐食偏好或场次选择等选项，使用“多项选择”

:::warning
付款字段类型需要先配置 Stripe。如果您尚未设置在线奉献，请在添加付款字段之前参阅[在线奉献设置](../donations/online-giving-setup.md)。
:::

## 第 3 步：配置表单设置

控制您的报名表何时以及如何可用。

1. 如果报名仅在有限时间内开放，请设置可用日期
2. 复制公开网址，您可以直接分享此链接
3. 添加具有“管理员”或“仅查看”角色的表单成员，以协助管理提交的报名信息

## 第 4 步：嵌入您的网站

将报名表添加到教会网站上，让人们更容易找到。

请按照[管理页面](../website/managing-pages.md)指南进行以下操作：

1. 在 B1 网站编辑器中，为页面添加新区块，并选择“表单”元素
2. 从列表中选择您的报名表

:::tip
也可以通过电子邮件、社交媒体和教会周报分享独立网址。可见的渠道越多，获得的报名就越多。
:::

## 第 5 步：管理提交的报名

随着报名的进行跟踪登记情况，并在需要时导出数据。

请按照[管理提交内容](../forms/managing-submissions.md)指南进行以下操作：

1. 在“提交”选项卡中查看陆续提交的回复
2. 导出为 CSV 格式，用于电子表格、人数统计或与活动协调员共享

## 完成！

您的活动报名已上线。分享链接，将其嵌入您的网站，并在 B1 Admin 中跟踪报名情况。活动结束后，导出最终名单以作存档。
