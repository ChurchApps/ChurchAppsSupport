# 建立你的讲道资料库并进行直播

<div class="article-intro">

让你的讲道存档上线，并设置直播。从导入现有的 YouTube 或 Vimeo 资料库，到安排定期的直播礼拜与互动聊天，全部都在这里完成。完成后，你的会众便可以在网站和手机应用程序上观看过去的讲道，也能加入现场礼拜。

</div>

## 培训视频

<YouTube id="b3B3A25g2Sk" title="在 B1 中建立你的讲道资料库" next="在 B1 中设置直播" nextUrl="/docs/b1-admin/sermons/live-streaming" />

<div class="prereqs">
<h4>开始之前</h4>

- 具备内容管理权限的 B1 Admin 账户
- 含有讲道视频的 YouTube 或 Vimeo 频道（用于导入你的存档）
- YouTube 频道 ID（用于直播，可在 YouTube Studio 的设置中找到）

</div>

## 步骤 1：建立讲道播放列表

播放列表可将你的讲道整理成系列或合集，方便浏览。

请依照[播放列表](../sermons/playlists.md)指南进行以下操作：

1. 建立系列或合集，例如「2024 主日信息」、「婚姻系列」、「圣诞礼拜」
2. 为每个播放列表添加名称、描述、发布日期和缩略图

:::tip
在添加讲道之前先建立播放列表。这样在新增讲道时，更容易将它们归入正确的系列。
:::

## 步骤 2：导入现有的讲道

如果你已经在 YouTube 或 Vimeo 上有讲道视频，可以一次全部导入。

请依照[批量导入](../sermons/bulk-import.md)指南进行以下操作：

1. 输入你的 YouTube 或 Vimeo 频道网址
2. 预览导入结果，查看将会导入哪些视频
3. 点击导入，一次添加全部视频

## 步骤 3：逐一添加讲道

如果只是偶尔新增，或是讲道不属于批量导入的范围，可以逐一添加。

请依照[管理讲道](../sermons/managing-sermons.md)指南进行以下操作：

1. 粘贴视频网址（YouTube、Vimeo 或 Facebook）
2. 标题、描述、缩略图和时长会从视频元数据自动填入
3. 将讲道指定到某个播放列表

## 步骤 4：设置直播

连接你的 YouTube 频道，让你的 B1 网站自动获取你的直播内容。

请依照[直播](../sermons/live-streaming.md)指南进行以下操作：

1. 在直播设置中输入你的 YouTube 频道 ID
2. 设置定期的礼拜时间表（例如每周日上午 10:00）
3. 在 **Sermons > Settings** 页面自定义直播页面的标签（聊天、代祷请求，以及自定义链接）

:::info
当你在 YouTube 上开始直播时，B1 直播页面会自动获取该直播内容。主日早上无需额外操作。
:::

## 步骤 5：在网站上显示

让访客能轻松找到你的讲道资料库与直播。

请依照[管理页面](../website/managing-pages.md)指南进行以下操作：

1. 在你的 B1 网站上添加「讲道」区块，让访客可以浏览资料库
2. 添加「直播」区块，提供现场观看的体验

## 步骤 6：手机访问

会员可以通过任何设备观看讲道和参加现场礼拜。

1. 会员可以在 [B1.church 以及 B1 App](../../b1-church/content/sermons.md) 上观看讲道
2. 带有聊天功能的直播在手机和电脑上都能使用

:::info
现场聊天功能让线上会众能够即时参与，感觉就像身在现场一样。
:::

## 完成了！

你的讲道资料库已经上线，直播也已设置完成。会员随时都能补看过去的讲道，并从任何地方加入现场礼拜。新上传的讲道也可以自动同步。
