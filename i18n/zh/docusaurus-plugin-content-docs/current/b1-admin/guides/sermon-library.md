# 搭建您的讲道库和直播

<div class="article-intro">

将您的讲道存档上线，并设置直播——从导入现有的 YouTube 或 Vimeo 资料库，到安排带有互动聊天的定期直播礼拜。完成后，您的会众即可在网站和移动应用上观看过往讲道并加入直播礼拜。

</div>

## 培训视频

<YouTube id="b3B3A25g2Sk" title="Building Your Sermon Library in B1" />

<div class="prereqs">
<h4>开始之前</h4>

- 拥有内容管理权限的 B1 Admin 账户
- 包含讲道视频的 YouTube 或 Vimeo 频道（用于导入您的存档）
- YouTube 频道 ID（用于直播——可在您的 YouTube Studio 设置中找到）

</div>

## 第 1 步：创建讲道播放列表

播放列表可以将您的讲道组织成系列和合集，便于浏览。

按照[播放列表](../sermons/playlists.md)指南完成以下操作：

1. 创建系列或合集，例如“2024 年主日讲道”“婚姻系列”“圣诞礼拜”
2. 为每个播放列表添加名称、描述、发布日期和缩略图

:::tip
在添加讲道之前先创建播放列表。这样在添加讲道时，更容易将其归入正确的系列。
:::

## 第 2 步：导入现有讲道

如果您已经在 YouTube 或 Vimeo 上有讲道视频，可以一次性全部导入。

按照[批量导入](../sermons/bulk-import.md)指南完成以下操作：

1. 输入您的 YouTube 或 Vimeo 频道网址
2. 预览导入结果，查看将导入哪些视频
3. 点击导入，一次性全部添加

## 第 3 步：添加单独的讲道

对于一次性添加或不属于批量导入的讲道，请逐个添加。

按照[管理讲道](../sermons/managing-sermons.md)指南完成以下操作：

1. 粘贴视频网址（YouTube、Vimeo 或 Facebook）
2. 标题、描述、缩略图和时长会根据视频元数据自动填充
3. 将讲道分配到播放列表

## 第 4 步：设置直播

连接您的 YouTube 频道，使您的 B1 网站能够自动获取您的直播。

按照[直播](../sermons/live-streaming.md)指南完成以下操作：

1. 在直播设置中输入您的 YouTube 频道 ID
2. 配置您的定期礼拜时间表（例如每周日上午 10:00）
3. 在 **Sermons > Settings（讲道 > 设置）**页面中自定义直播页面的选项卡（聊天、代祷请求以及自定义链接）

:::info
当您在 YouTube 上开始直播时，B1 直播页面会自动获取该直播。主日早上无需任何额外操作。
:::

## 第 5 步：在您的网站上展示

让访客可以轻松访问您的讲道库和直播。

按照[管理页面](../website/managing-pages.md)指南完成以下操作：

1. 在您的 B1 网站中添加“讲道”板块，供访客浏览您的讲道库
2. 添加“直播”板块，用于直播观看体验

## 第 6 步：移动端访问

会众可以在任何设备上观看讲道和直播礼拜。

1. 会众可以在 [B1 移动应用](../../b1-mobile/content/sermons.md)和 [B1.church](../../b1-church/content/sermons.md)上观看讲道
2. 带聊天功能的直播在两个平台上均可使用

:::info
直播聊天功能让您的线上会众能够实时参与，就像身临其境一样。
:::

## 大功告成！

您的讲道库已经上线，直播也已配置完成。会众可以随时补看过往讲道，并在任何地方加入直播礼拜。新的讲道上传可以自动同步。
