# 创建您的账户

<div class="article-intro">

开始使用 ChurchApps 始于创建您的账户。该过程仅需几分钟，并为您提供对所有 ChurchApps 工具的访问权限，包括 B1 Admin、B1.church 和 Lessons.church。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 准备好有效的电子邮件地址用于账户验证
- 查看[快速入门概览](./index.md)了解 ChurchApps 提供的内容

</div>

## 逐步注册

1. 在您的网络浏览器中转到 [B1.church](https://b1.church)。
2. 点击**注册**按钮。
3. 输入您的**名字**、**姓氏**和**电子邮件地址**——或者，如果您的教会启用了单点登录，点击**使用 Google 继续**或**使用 Microsoft 继续**使用您现有的账户直接跳到第 5 步。
4. 为您的账户创建密码。
5. 提交注册表单。

:::info
一个 ChurchApps 账户可在 B1、Lessons.church 和其他 ChurchApps 应用中使用。如果您看到**您已经有一个 ChurchApps 账户。请改用它登录。**，点击**登录**并使用该电子邮件登录。如果您不记得密码，请使用**忘记密码**。
:::

## 确认您的电子邮件

注册后，您将在提供的地址收到确认电子邮件。

1. 在您的收件箱中检查来自 ChurchApps 的确认电子邮件。
2. 点击电子邮件中的确认链接。
3. 您的账户现在已验证并可以使用。

:::tip
如果您看不到确认电子邮件，请检查您的垃圾或废件文件夹。电子邮件来自 ChurchApps，可能需要一两分钟才能到达。
:::

## 设置您的教会

确认您的电子邮件并登录后，您将有选择创建新教会或加入现有教会的选项。

**要创建新教会：**

1. 选择**创建新教会**的选项。
2. 输入您的**教会名称**和基本信息。如果找到匹配项，注册表将自动填充您的教会详细信息。
3. 完成设置过程。
4. 您将被带往**仪表板**，这是 B1 Admin 的主页，您可以在此处开始配置您的教会。

**要加入现有教会：**

1. 选择**加入现有教会**的选项。
2. 按名称搜索您的教会。
3. 请求加入。您教会的管理员需要批准您的请求。

:::info
如果您尝试使用尚未注册的电子邮件登录，您将自动被定向到注册流程，以便您可以创建账户。
:::

:::info
创建新教会的人被自动分配**域管理员**角色，该角色授予对所有设置和功能的完全访问权限。您稍后可以从**角色**页面添加其他管理员。
:::

## 接下来做什么

一旦您的教会设置完毕，请转到[初始设置](./initial-setup.md)指南以配置您的教会设置、品牌和团队访问。
