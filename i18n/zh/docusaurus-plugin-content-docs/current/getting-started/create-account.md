# 创建你的账号

<div class="article-intro">

开始使用 ChurchApps 的第一步是创建你的账号。整个过程只需几分钟，之后你即可访问所有 ChurchApps 工具，包括 B1 Admin、B1.church 和 Lessons.church。

## 分步注册

1. 在网页浏览器中访问 [B1.church](https://b1.church)。
2. 点击 **Register**（注册）按钮。
3. 输入你的 **名字**、**姓氏** 和 **电子邮件地址**——或者，如果你的教会已启用单点登录，可点击 **Continue with Google**（使用 Google 继续）或 **Continue with Microsoft**（使用 Microsoft 继续），直接使用你现有的账号跳至第 5 步。
4. 为你的账号设置密码。
5. 提交注册表单。

:::info
同一个 ChurchApps 账号可以在 B1、Lessons.church 以及其他 ChurchApps 应用中通用。如果你看到 **You already have a ChurchApps account. Please sign in with it instead.**（你已有 ChurchApps 账号，请直接登录。），请点击 **Login**（登录），并使用该电子邮件登录。如果你忘记了密码，请使用 **Forgot Password**（忘记密码）。
:::

## 确认你的电子邮件

注册之后，你会收到一封发送到你所提供地址的确认邮件。

1. 在收件箱中查找来自 ChurchApps 的确认邮件。
2. 点击邮件中的确认链接。
3. 你的账号即已验证，可以正常使用。

:::tip
如果没有看到确认邮件，请检查垃圾邮件或广告邮件文件夹。该邮件来自 ChurchApps，可能需要一两分钟才会送达。
:::

## 设置你的教会

确认电子邮件并登录之后，你可以选择创建新教会，或加入已有的教会。

**创建新教会：**

1. 选择 **create a new church**（创建新教会）选项。
2. 输入你的 **教会名称** 和基本信息。如果找到匹配项，注册表单会自动填入你的教会详细信息。
3. 完成设置流程。
4. 系统会带你进入 **Dashboard**（仪表板），即 B1 Admin 的首页，你可以在那里开始配置你的教会。

**加入已有的教会：**

1. 选择 **join an existing church**（加入已有教会）选项。
2. 按名称搜索你的教会。
3. 提交加入申请。你所在教会的管理员需要批准你的申请。

:::info
如果你尝试使用尚未注册的电子邮件登录，系统会自动引导你进入注册流程，以便你创建账号。
:::

:::info
创建新教会的人会自动被分配 **Domain Admin**（域名管理员）角色，该角色可完全访问所有设置和功能。之后，你可以在 **Roles**（角色）页面添加其他管理员。
:::
