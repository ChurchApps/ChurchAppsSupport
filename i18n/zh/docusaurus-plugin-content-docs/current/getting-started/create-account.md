# 创建你的账户

<div class="article-intro">

开始使用 ChurchApps 的第一步是创建账户。整个过程只需几分钟，即可让你使用所有 ChurchApps 工具，包括 B1 Admin、B1.church 和 Lessons.church。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 准备好一个有效的电子邮件地址用于账户验证
- 阅读[新手入门概览](./index.md)以了解 ChurchApps 提供的功能

</div>

## 分步注册

1. 在浏览器中打开 [B1.church](https://b1.church)。
2. 点击**注册**按钮。
3. 输入你的**名字**、**姓氏**和**电子邮件地址**——如果你的教会启用了单点登录，也可以点击**使用 Google 继续**或**使用 Microsoft 继续**，直接使用现有账户跳到第 5 步。
4. 为你的账户设置密码。
5. 提交注册表单。

## 确认你的电子邮件

注册后，你会在提供的地址收到一封确认电子邮件。

1. 检查收件箱中来自 ChurchApps 的确认邮件。
2. 点击邮件中的确认链接。
3. 你的账户现已通过验证，可以使用了。

:::tip
如果没有看到确认邮件，请检查垃圾邮件或杂件文件夹。该邮件来自 ChurchApps，可能需要一两分钟才能送达。
:::

## 设置你的教会

确认电子邮件并登录后，你可以选择创建一个新教会或加入一个已有的教会。

**创建新教会：**

1. 选择**创建新教会**选项。
2. 输入你的**教会名称**和基本信息。如果找到匹配项，注册表单会自动填充你的教会详细信息。
3. 完成设置流程。
4. 你将被带到 **B1 Admin 控制台**，在那里可以开始配置你的教会。

**加入已有教会：**

1. 选择**加入已有教会**选项。
2. 按名称搜索你的教会。
3. 提交加入申请。你教会的管理员需要批准你的申请。

:::info
如果你尝试使用尚未注册的电子邮件登录，系统会自动引导你进入注册流程，以便创建账户。
:::

:::info
创建新教会的人会自动获得**域管理员**角色，拥有对所有设置和功能的完全访问权限。你可以稍后在**角色**页面添加其他管理员。
:::

## 接下来做什么

教会设置完成后，前往[初始设置](./initial-setup.md)指南，配置你教会的设置、品牌和团队访问权限。
