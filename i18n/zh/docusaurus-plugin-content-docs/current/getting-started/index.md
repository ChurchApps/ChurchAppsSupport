## 已经注册？从这里开始

你的前 15 分钟：

1. **打造专属于你的内容。** 添加教会名称、地址和标志，让 B1、你的网站和你的应用看起来就是你的教会。参见[初始设置，第 1 和第 2 步](./initial-setup.md#step-1-configure-your-church-information)。
2. **添加你的成员。** 手动添加几位成员，或从电子表格或旧的教会软件中导入你的完整名单。参见[导入你的成员](../b1-admin/people/importing-data.md)（附视频）。
3. **邀请你的团队。** 为你的员工和核心志愿者授予相应权限的访问权。参见[角色与权限](../b1-admin/settings/roles-permissions.md)。

### 然后选择你的第一个项目

- **儿童教室：** 免费安排 [Lessons.church](../lessons-church/index.md) 课程，并通过 [FreePlay](../freeplay/index.md) 在教室电视上播放。
- **小组：** [开展小组活动](../b1-admin/guides/small-groups.md)
- **教会网站：** [上线你的网站](../b1-admin/guides/launch-website.md)
- **在线奉献：** [设置在线奉献](../b1-admin/guides/online-giving.md)
- **儿童签到：** [设置签到](../b1-admin/guides/childrens-checkin.md)
- **主日志愿者：** [管理主日志愿者](../b1-admin/guides/sunday-volunteers.md)
- **考勤：** [记录考勤](../b1-admin/guides/track-attendance.md)
- **讲道与直播：** [建立你的讲道资料库](../b1-admin/guides/sermon-library.md)

如果你是新用户且还没有账号，请从[创建你的账号](./create-account.md)开始。

## ChurchApps 产品

ChurchApps 包含多款可协同工作的产品：

- **B1 Admin**——你的教会管理仪表板。在一个中央位置管理成员、小组、考勤、捐赠、网站内容等。[B1 Admin 指南](/docs/b1-admin/)
- **B1.church**——你的公开教会网站和成员门户。成员可以观看讲道、查阅通讯录、在线奉献，并保持联系。[B1.church 指南](/docs/b1-church/)
- **Lessons.church**——适用于主日学、小组和查经的免费教会课程。免费访问不断增长的课程库。[Lessons.church 指南](/docs/lessons-church/)
- **FreePlay**——一款免费的电视应用，可在教室和走廊的电视（Fire TV、Android TV 和 Apple TV）上播放你的课程、敬拜视频和公告，还可以按排程播放。[设置 FreePlay](/docs/freeplay/)
- **FreeShow**——适用于主日敬拜的免费演示软件。在聚会期间显示歌词、幻灯片和媒体。[freeshow.app](https://freeshow.app)
- **WorshipCommons**——一个开放的敬拜音乐库，你的教会可以免费演唱：包括公有领域的赞美诗和作者分享的歌曲，附有和弦谱、歌词、移调和音频。[worshipcommons.org](https://worshipcommons.org)

:::info
所有 ChurchApps 工具都是**100% 免费**的，没有任何限制、高级版本或隐藏费用。ChurchApps 是一个非营利组织，依靠捐赠和志愿者的支持运作。
:::

## 本文档涵盖的内容

本文档将带你了解开始使用 ChurchApps 所需的一切。你将学习如何：

1. 创建你的账号并注册你的教会。
2. 配置你教会的基本设置和品牌形象。
3. 为你的团队设置合适的角色与权限。
4. 开始使用各项工具来管理你的会众。
