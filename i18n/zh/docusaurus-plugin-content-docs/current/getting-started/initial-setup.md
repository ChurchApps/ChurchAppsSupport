# 初始设置

<div class="article-intro">

在创建帐户和教会后，有几个重要步骤要在邀请团队之前配置。本指南将指导您完成建议的设置顺序，以便您的教会从第一天就准备就绪。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [创建您的帐户](./create-account.md)并注册您的教会
- 准备好您的教会徽标和品牌资产（可选但推荐）

</div>

## 步骤 1：配置您的教会信息

1. 打开左上角的**菜单**（带小箭头的菜单名称）并选择**设置**。
2. 单击**编辑设置**。
3. 输入您的教会的**名称**、**地址**和**联系方式**。
4. 单击**保存**以应用您的更改。

## 步骤 2：设置您的品牌

1. 从**仪表板**，导航到**网站**，然后选择**外观**。
2. 上传您的**教会徽标**。
3. 配置任何其他品牌选项，如颜色和图像。
4. 您的品牌将显示在 B1.church 网站和 B1 Mobile 应用上。

:::tip
在邀请团队成员之前准备好徽标和品牌会在他们登录时留下打磨的第一印象。
:::

## 步骤 3：配置角色并邀请您的团队

1. 从**设置**页面单击**角色**。
2. 为您的团队创建角色（例如 "牧师"、"秘书"、"财务主管"）。
3. 为每个角色分配适当的权限。
4. 通过搜索他们的帐户并将他们分配给角色来添加团队成员。

## 步骤 4：设置您的关键区域

有了团队，开始在 B1 Admin 中构建核心区域：

1. **人员** -- 向您的教会目录添加成员。这是其他所有东西的基础，所以从这里开始。您可以手动添加人或使用**设置**中的**导入**工具。
2. **小组** -- 为小组、事工团队、班级和其他聚集创建小组。
3. **出席** -- 为追踪出席配置您的校园、服务和服务时间。
4. **捐赠** -- 设置捐赠资金并连接您的支付网关（Stripe）以接受在线捐赠。
5. **网站** -- 使用 B1.church 网站生成器构建您的公开教会网站。

:::info
您不需要一次设置每个区域。许多教会从**人员**和**小组**开始，然后在舒服时添加**出席**和**捐赠**。
:::

## 建议顺序

为获得最平稳的设置体验，我们建议这个顺序：

1. **人员** -- 首先添加您的成员和常规与会者。
2. **小组** -- 将人组织成有意义的小组。
3. **出席** -- 开始追踪每周谁出席。
4. **捐赠** -- 一旦您的人在系统中，设置捐赠。
5. **网站** -- 在您的数据就位后构建您的公开网站。

完成这些步骤后，您的教会已准备好。探索[B1 Admin](/docs/b1-admin/)文档以了解每个区域的详细指南。
