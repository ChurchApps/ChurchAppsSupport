# 初始设置

<div class="article-intro">

创建您的账户和教会后，邀请您的团队之前有一些重要步骤需要配置。本指南会引导您按照推荐的设置顺序进行，以便您的教会从第一天就准备就绪。

</div>

<div class="prereqs">
<h4>开始前</h4>

- [创建您的账户](./create-account.md)并注册您的教会
- 准备好您的教会标志和品牌资产（可选但推荐）

</div>

## 第 1 步：配置您的教会信息

1. 打开 [Jump 菜单](../b1-admin/introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开**设置**，然后点击**设置**。
2. 点击**编辑设置**。
3. 输入您的教会的**名称**、**地址**和**联系方式**。
4. 点击**保存**以应用您的更改。

## 第 2 步：设置您的品牌

1. 在 Jump 菜单中，选择**网站 > 外观**。
2. 上传您的**教会标志**。
3. 配置任何其他品牌选项，例如颜色和图像。
4. 您的品牌将显示在您的 B1.church 网站和 B1 Mobile 应用程序中。

:::tip
在邀请团队成员之前准备好您的标志和品牌，当他们登录时会给人留下精美的第一印象。
:::

## 第 3 步：配置角色并邀请您的团队

1. 在 Jump 菜单中，选择**设置 > 角色**。
2. 为您的团队创建角色（例如，"牧师"、"秘书"、"财务"）。
3. 为每个角色分配适当的权限。
4. 通过搜索其账户并将其分配给角色来添加团队成员。

## 第 4 步：设置您的关键区域

有了您的团队，开始构建 B1 Admin 的核心区域：

1. **人员** -- 将成员添加到您的教会目录。这是一切的基础，所以从这里开始。您可以手动添加人员或使用**设置**中的**导入**工具。
2. **小组** -- 为小组、事工团队、课程和其他聚集创建小组。
3. **出勤** -- 配置您的校园、服务和服务时间以跟踪出勤。
4. **捐赠** -- 设置捐赠基金并连接您的支付网关 (Stripe) 以接受在线捐赠。
5. **网站** -- 使用 B1.church 网站构建器构建您的公共教会网站。

:::info
您无需一次性设置每个区域。许多教会从**人员**和**小组**开始，然后随着对该平台的熟悉，添加**出勤**和**捐赠**。
:::

## 推荐顺序

为了获得最顺利的设置体验，我们建议按以下顺序进行：

1. **人员** -- 首先添加您的成员和常规参与者。
2. **小组** -- 将人员组织成有意义的小组。
3. **出勤** -- 开始跟踪每周有多少人参加。
4. **捐赠** -- 一旦您的人员在系统中，设置捐赠。
5. **网站** -- 在您的数据就位后，最后构建您面向公众的网站。

完成这些步骤后，您的教会就可以准备就绪了。浏览[B1 Admin](/docs/b1-admin/)文档以了解每个区域的详细指南。
