# 初始设置

<div class="article-intro">

创建您的账户和教会后，在邀请您的团队之前，需要进行一些重要的配置步骤。本指南将指导您完成推荐的设置顺序，使您的教会从第一天开始就准备就绪。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [创建您的账户](./create-account.md)并注册您的教会
- 准备好您的教会徽标和品牌资产（可选但推荐）

</div>

## 步骤 1：配置您的教会信息

1. 打开左上角的**部分菜单**（带有小箭头的部分名称），选择**设置**。
2. 点击**编辑设置**。
3. 输入您的教会**名称**、**地址**和**联系详情**。
4. 点击**保存**以应用您的更改。

## 步骤 2：设置您的品牌

1. 从**仪表板**（您的主页），导航至**网站**，然后选择**外观**。
2. 上传您的**教会徽标**。
3. 配置任何其他品牌选项，例如颜色和图像。
4. 您的品牌将出现在您的 B1.church 网站和 B1 移动应用中。

:::tip
在邀请团队成员之前准备好您的徽标和品牌可以在他们登录时给出专业的第一印象。
:::

## 步骤 3：配置角色并邀请您的团队

1. 从**设置**页面点击**角色**。
2. 为您的团队创建角色（例如，"牧师"、"秘书"、"财务"）。
3. 为每个角色分配适当的权限。
4. 通过搜索他们的账户并将其分配给角色来添加团队成员。

## 步骤 4：设置您的关键区域

有了您的团队到位，开始构建 B1 Admin 的核心区域：

1. **人员** — 将成员添加到您的教会目录。这是其他一切的基础，所以从这里开始。您可以手动添加人员或使用**设置**中的**导入**工具。
2. **小组** — 为小组、事工团队、课程和其他聚会创建小组。
3. **出席** — 为跟踪出席配置您的校园、服务和服务时间。
4. **捐款** — 设置捐款基金并连接您的支付网关（Stripe）以接受在线捐赠。
5. **网站** — 使用 B1.church 网站构建器构建您的公共教会网站。

:::info
您不需要一次设置每个区域。许多教会从**人员**和**小组**开始，然后在适应平台时添加**出席**和**捐款**。
:::

## 推荐顺序

为了最顺利的设置体验，我们建议按此顺序进行：

1. **人员** — 首先添加您的成员和定期参加者。
2. **小组** — 将人员组织成有意义的小组。
3. **出席** — 开始跟踪每周谁出现。
4. **捐款** — 一旦您的人员在系统中，就设置捐赠。
5. **网站** — 在您的数据到位后最后构建您的面向公众的网站。

完成这些步骤后，您的教会已准备就绪。查看[B1 Admin](/docs/b1-admin/)文档，了解每个区域的详细指南。
