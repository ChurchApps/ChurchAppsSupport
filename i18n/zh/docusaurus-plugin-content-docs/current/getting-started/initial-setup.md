# 初始设置

<div class="article-intro">

创建账户和教会之后，在邀请团队成员之前，还有几个重要的配置步骤。本指南将引导您按照推荐的设置顺序操作，让您的教会从第一天起就能顺利运作。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [创建您的账户](./create-account.md)并注册您的教会
- 准备好教会的标志和品牌素材（可选，但建议准备）

</div>

## 第 1 步：配置教会信息

1. 打开[快速跳转菜单](../b1-admin/introduction.md#getting-around-with-the-jump-menu)（B1 Admin 左上角的搜索栏），展开 **设置**，然后点击 **设置**。
2. 在 **教会信息** 部分，点击 **编辑**。
3. 输入教会的**名称**、**子域名**和**地址**。
4. 点击 **保存** 以应用您的更改。

## 第 2 步：设置品牌形象

1. 在快速跳转菜单中，选择 **网站 > 外观**。
2. 上传您的**教会标志**。
3. 配置其他品牌选项，例如颜色和图片。
4. 您的品牌形象将显示在您的 B1.church 网站和 B1 App 中。

:::tip
在邀请团队成员之前准备好标志和品牌素材，他们登录时会获得更专业的第一印象。
:::

## 第 3 步：配置角色并邀请团队

1. 在快速跳转菜单中，选择 **设置 > 角色**。
2. 为您的团队创建角色（例如"牧师"、"秘书"、"财务"）。
3. 为每个角色分配适当的权限。
4. 通过搜索成员账户并将其分配到相应角色来添加团队成员。

## 第 4 步：设置您的核心功能区域

团队组建完成后，开始搭建 B1 Admin 的核心功能区域：

1. **人员** —— 将成员添加到教会通讯录中。这是其他所有功能的基础，因此建议从这里开始。您可以手动添加人员，也可以使用 **设置** 中的 **导入/导出** 工具。
2. **小组** —— 为小组、事工团队、课程及其他聚会创建小组。
3. **考勤** —— 配置您的堂点、崇拜聚会及聚会时间，以便记录考勤。
4. **奉献** —— 设置奉献基金，并连接您的支付网关（Stripe），以接受在线奉献。
5. **网站** —— 使用 B1.church 网站构建工具搭建您的公开教会网站。

:::info
您无需一次设置所有功能区域。许多教会会先从 **人员** 和 **小组** 开始，待熟悉平台后再添加 **考勤** 和 **奉献**。
:::

## 推荐顺序

为了获得最顺畅的设置体验，我们建议按以下顺序进行：

1. **人员** —— 首先添加您的成员和经常参加聚会的人。
2. **小组** —— 将人员组织成有意义的小组。
3. **考勤** —— 开始记录每周的出席情况。
4. **奉献** —— 在人员信息录入系统后设置奉献功能。
5. **网站** —— 最后构建面向公众的网站，此时数据已经就位。

完成以上步骤后，您的教会就可以正式运作了。请参阅 [B1 Admin](/docs/b1-admin/) 文档，了解每个功能区域的详细指南。
