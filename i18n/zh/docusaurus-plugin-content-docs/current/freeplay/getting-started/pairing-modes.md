# 选择配对模式

<div class="article-intro">

FreePlay 提供两种配对模式来将您的电视连接到教会，另外还可以直接浏览内容提供者。**选择配对模式**屏幕将这些选项呈现为可使用您的电视遥控器进行导航的大卡片。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 安装 FreePlay 并首次启动它 -- 请参阅[入门](./index.md)
- 准备好您的电视遥控器用于导航

</div>

## 配对到教室

当您希望特定的电视始终显示为特定房间安排的课程时，选择**配对到教室**。这是儿童事工教室的最佳选择，其中课程按每周日程分配。

**它的工作原理：**您按名称搜索您的教会，选择一个教室，FreePlay 会自动获取为该房间今天安排的任何课程。每个星期天上午，您只需打开电视，正确的课程就准备好了。

**最适合：**应始终显示该房间计划内容的专用教室电视。

:::tip
在配对您的电视之前，在 [freeplay.church](https://freeplay.church) 设置您的教室。这确保了当您搜索您的教会时，您的房间会出现。
:::

## 配对到计划

当您想跟随教会服务计划时，选择**配对到计划**。此模式生成一个配对代码，您在**B1 Admin**中输入该代码以将电视链接到特定的计划类型。电视随后下载并播放分配给当前计划的内容。

**它的工作原理：** FreePlay 在屏幕上显示一个配对代码和二维码。管理员在**B1 Admin**中打开链接的页面，输入代码，并从**显示计划**下拉列表中选择屏幕应遵循的计划类型。批准后，电视会自动加载当前计划的内容。

**最适合：** 显示与您的周服务计划相关联的内容的电视，例如敬拜歌词或公告幻灯片。

## 内容提供者

如果您不需要配对到教室或计划，可以直接浏览内容提供者。提供者如 [Lessons.church](../../lessons-church/) 和 Bible Project 提供您可以下载并在电视上按需播放的内容。

**最适合：**志愿者每周手动选择播放内容的电视，或当您想探索可用内容时。

:::info
您可以随时从边栏底部的**设置**中访问**提供者**屏幕。您无需使用配对模式来浏览和播放内容。
:::
