# 选择配对模式

<div class="article-intro">

FreePlay 提供两种将电视与教会连接的配对模式，此外还可以直接浏览内容提供商。**选择配对模式**屏幕会将这些选项显示为大卡片，你可以用电视遥控器进行导航。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 安装 FreePlay 并首次启动 -- 参见[新手入门](./index.md)
- 准备好电视遥控器以便导航

</div>

## 配对到教室

当你希望某台特定电视始终显示分配给某个教室的课程时，请选择**配对到教室**。这是儿童事工教室的最佳选择，因为课程是按每周计划分配的。

**工作原理：**你按名称搜索你的教会，选择一个教室，FreePlay 会自动获取该教室今天安排的课程。每个周日早上，你只需打开电视，正确的课程就已准备就绪。

**适用于：**应始终显示该教室已安排内容的专用教室电视。

:::tip
在配对电视之前，请先在 [freeplay.church](https://freeplay.church) 上设置好你的教室。这样可以确保你搜索教会时能看到你的教室。
:::

## 配对到计划

当你希望跟随教会的崇拜计划时，请选择**配对到计划**。此模式会生成一个配对代码，你需要在 **B1 Admin** 中输入该代码，将电视与特定的计划类型关联。之后电视会下载并播放分配给当前计划的内容。

**工作原理：**FreePlay 会在屏幕上显示一个配对代码和一个二维码。管理员在 **B1 Admin** 中打开相关联的页面，输入代码，并从**显示哪些计划**下拉菜单中选择该屏幕应跟随的计划类型。批准后，电视会自动加载当前计划的内容。

**适用于：**显示与每周崇拜计划相关内容的电视，例如敬拜歌词或通知幻灯片。

## 内容提供商

如果你不需要配对到教室或计划，可以直接浏览内容提供商。像 [Lessons.church](../../lessons-church/) 和 Bible Project 这样的提供商提供可供下载并按需播放的内容。

**适用于：**由志愿者每周手动选择播放内容的电视，或者你想探索可用内容时。

:::info
你可以随时从导航底部的侧边栏访问**提供商**屏幕。浏览和播放内容并不需要使用配对模式。
:::
