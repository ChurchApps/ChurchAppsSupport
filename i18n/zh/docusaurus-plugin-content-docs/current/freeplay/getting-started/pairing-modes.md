# 选择配对模式

<div class="article-intro">

FreePlay 可以通过三种方式运行电视：按照您在 FreePlay Admin 中设置的日历播放、按照 B1 Admin 中的礼拜计划播放，或由志愿者使用遥控器选择播放内容。两种配对方式都从电视上的同一个屏幕开始。您在哪里输入配对码，决定了电视使用哪种模式。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 安装 FreePlay 并首次启动。参见[入门指南](./index.md)
- 准备好电视遥控器以便导航

</div>

## 获取配对码

1. 在电视上，打开侧边栏底部的 **设置**。
2. 选择 **配对到日历**。
3. FreePlay 会显示一个四个字母的配对码和一个二维码。配对码有效期为 15 分钟，到期后 FreePlay 会自动显示新的配对码。

## 定时模式（FreePlay Admin）

当您希望电视自动运行时，请在 [admin.freeplay.church](https://admin.freeplay.church) 的 **FreePlay Admin** 中输入配对码。您可以制作播放列表，将其放入某组屏幕的日历中，电视将按照设定的时间播放。无需有人按下开始。

**工作方式：** 扫描电视上的二维码，或访问 **freeplay.church/pair**。然后选择电视应当遵循其日历的屏幕组，并点击 **配对**。电视会下载未来一周的内容，并按时钟播放，即使离线也可以。

**最适合：** 大堂和走廊的标识牌、通知循环，以及希望人们走进教室时课程已经开始播放的教室。

完整指南请参见 **[定时模式](../scheduled-mode/)**。

## 礼拜计划模式（B1 Admin）

当您希望电视跟随某个礼拜计划类型时，请在 **B1 Admin** 中输入配对码。电视会下载当前计划的内容，由志愿者按下 **开始计划** 来播放。

**工作方式：** 在 B1 Admin 中，使用电视上显示的配对码添加屏幕，并在 **显示以下计划** 下选择计划类型。每周，电视都会获取该计划类型的最新计划。

**最适合：** 显示与每周礼拜计划相关内容的电视，由专人在时间到时开始播放。

完整指南请参见 **[礼拜计划模式](../plan-mode/)**。

:::tip
您也可以按计划定时播放当前的礼拜计划。在 FreePlay Admin 中，添加一个日历条目，并在 **礼拜计划** 下选择计划类型。
:::

## 内容提供方（无需配对）

如果您完全不需要配对电视，可以直接浏览内容提供方。[Lessons.church](../../lessons-church/) 和 Bible Project 等提供方提供可以下载并随时播放的内容。

**最适合：** 志愿者每周自行选择播放内容的电视，或您希望了解有哪些可用内容的情况。

:::info
您可以随时从侧边栏底部的 **设置** 打开 **提供方** 页面。浏览和播放内容无需配对电视。
:::
