# 下载课程内容

<div class="article-intro">

选择教会和教室后，FreePlay 会自动获取今天安排的课程并开始下载其所有媒体文件。这个屏幕是您在开始课程前等待内容准备好的地方。

</div>

<div class="prereqs">
<h4>在您开始之前</h4>

- 选择您的教会和教室 -- 见[选择您的教会和房间](./selecting-room)
- 确保您的电视已连接到互联网以进行初始下载

</div>

## 下载的工作方式

1. FreePlay 检查您的教室的时间表并加载分配的课程
2. 课程名称、标题和描述出现在屏幕上，覆盖在课程的封面图像上
3. 进度指示器显示**下载项目 X 之 Y**，因为每个文件被保存到设备
4. 当所有文件下载完毕后，**开始课程**按钮与播放图标一起出现

您在下载期间无需做任何事情。FreePlay 会自动处理一切。

## 分辨率

FreePlay 默认以 720p 下载内容。分辨率设置（720p 或 1080p）决定了下载的视频和图像文件的质量。较高的分辨率在大电视上看起来更清晰，但下载时间更长，使用更多存储空间。

:::info
分辨率默认设置为 720p。内容以为您的设备配置的分辨率下载。
:::

## 开始课程

下载完毕后，**开始课程**按钮在屏幕底部逐渐出现。使用您的电视遥控器突出显示它并按**选择**开始播放。

## 自动刷新

FreePlay 每小时检查更新的内容。如果日程表在白天更改，应用会自动选择新课程。您也可以按遥控器上的**返回**以返回到房间选择屏幕，然后重新进入下载屏幕以强制刷新。

:::tip
在您的建筑物有强大的互联网连接时在星期天上午之前下载课程。下载后，内容离线播放，无任何网络依赖。
:::

## 下载屏幕

FreePlay 包括一个**下载**屏幕，您可以在其中查看和管理已下载到设备的所有内容。打开侧边栏底部的**设置**，然后选择**下载**。这让您可以看到本地存储和准备离线播放的内容。使用下载屏幕在星期天上午之前验证课程已完全下载，或通过删除旧内容释放存储空间。

## 如果计划为空

如果为所选的教室安排了没有课程，您将看到消息"无法加载计划。请确保为此班级安排了课程。"检查您的计划在 [freeplay.church](https://freeplay.church) 并确保正确的课程被分配到此房间。
