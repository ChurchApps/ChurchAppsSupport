# 连接到提供商

<div class="article-intro">

在您能够浏览来自提供商的内容之前，您需要连接到它。一些提供商通过 QR 代码或电子邮件登录需要认证，而其他提供商可以通过单击进行连接。

</div>

<div class="prereqs">
<h4>在您开始之前</h4>

- 安装和启动 FreePlay -- 见[入门](../getting-started/)
- 为导航准备好您的电视遥控器
- 对于需要登录的提供商，您的账户凭证可用

</div>

:::tip 一起设置 B1 Admin + FreePlay？
我们的**<a href="/guides/freeplay-b1admin" target="_blank">循序渐进指南</a>**演练链接 B1 Admin、调度课程和连接 FreePlay — 所有在一个地方。在新标签页中打开它以跟随。
:::

## 浏览可用的提供商

1. 打开侧边栏底部的**设置**，然后选择**提供商**以打开**内容提供商**屏幕
2. 您将看到提供商卡片的网格，每一个显示提供商的徽标和名称
3. 连接的提供商在他们的名称下显示绿色**已连接**徽章
4. 还未可用的提供商显示**即将推出**标签

## 不需要认证的连接

一些提供商不需要登录。当您选择这些提供商之一时，FreePlay 立即连接并打开内容浏览器。不需要凭证。

## 设备流认证（QR 代码）

某些提供商使用设备流，类似于您在电视上登录流应用的方式：

1. 在**内容提供商**屏幕上选择提供商卡片
2. FreePlay 显示 QR 代码和验证 URL
3. 用您的电话扫描 QR 代码，或在任何设备上访问显示的 URL
4. 输入屏幕上显示的用户代码
5. 在您的电话或计算机上完成登录过程
6. FreePlay 检测成功的登录并显示**已连接！**
7. 内容浏览器自动打开

:::info
脉动**等待授权**指示器显示 FreePlay 正在检查您的登录。代码在几分钟后过期，所以及时完成流程。
:::

**Go Curriculum** 使用相同的 QR 代码登录模式 -- 扫描代码并使用您的 gocurriculum.com 账户登录以连接。

## 表单登录

其他提供商使用传统电子邮件和密码登录：

1. 选择提供商卡片
2. 使用屏幕上的键盘输入您的**电子邮件**和**密码**
3. 选择**登录**按钮
4. 如果您的凭证正确，FreePlay 显示**已连接！**并打开内容浏览器

:::tip
使用遥控器上的方向盘在电子邮件字段、密码字段和登录按钮之间移动。在文本字段上按**选择**以打开屏幕上的键盘。
:::

## 在您的网络上查找提供商

**FreeShow** 是在您的本地网络上找到的，而不是通过登录：FreePlay 搜索网络，列出每台运行 FreeShow 的计算机它找到的，并连接到您选择的（如果没有显示，选择**再次扫描**）。

## 提供商设置

选择显示**已连接**徽章的提供商卡片会打开其**提供商设置**屏幕：

- **浏览库** -- 在侧边栏中显示或隐藏此提供商的内容库
- **自动下载今天的课程** -- 使用此提供商作为今天课程的来源并预下载其文件（仅对提供当前课程的提供商显示）
- **用于公告** -- 从此提供商选择一个文件夹以从侧边栏中的**公告**项目循环。见[公告](./announcements)
- **检查公告更新** -- 一旦选择了公告文件夹后显示；下载新幻灯片并删除已删除的幻灯片
- **断开连接** -- 删除连接

## 断开提供商

要从您已连接的提供商断开连接：

1. 转到**内容提供商**屏幕（**设置** > **提供商**）
2. 选择显示**已连接**徽章的提供商卡片
3. 在**提供商设置**屏幕上，选择**断开连接**

断开连接后，提供商的内容将不再出现在您的侧边栏中。如果您将其中一个文件夹用于公告，这些幻灯片也会被删除。

:::warning
断开连接会从您的设备中删除保存的认证。如果您想稍后重新连接，您需要再次登录。
:::
