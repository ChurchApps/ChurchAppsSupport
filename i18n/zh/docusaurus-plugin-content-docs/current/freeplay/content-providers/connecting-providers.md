# 连接内容提供方

<div class="article-intro">

在浏览提供方的内容之前，您需要先连接到该提供方。有些提供方需要通过二维码或电子邮件登录进行身份验证，而其他提供方只需点击一次即可连接。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 安装并启动 FreePlay -- 参见[入门指南](../getting-started/)
- 准备好电视遥控器以便导航
- 对于需要登录的提供方，请准备好您的账户凭据

</div>

:::tip 同时设置 B1 Admin 和 FreePlay？
我们的**<a href="/guides/freeplay-b1admin" target="_blank">分步指南</a>**将在一处介绍如何关联 B1 Admin、排定课程并连接 FreePlay。请在新标签页中打开，以便边看边操作。
:::

## 浏览可用的提供方

1. 在屏幕底部的侧边栏中打开**设置**，然后选择**提供方**，进入**内容提供方**屏幕
2. 您将看到一个提供方卡片网格，每张卡片显示该提供方的标志和名称
3. 已连接的提供方会在其名称下方显示绿色的**已连接**标记
4. 尚未开放的提供方会显示**即将推出**标签

## 无需身份验证的连接

有些提供方不需要登录。选择这类提供方后，FreePlay 会立即连接并打开内容浏览器。无需任何凭据。

## 设备流身份验证（二维码）

某些提供方使用设备流，类似于您在电视上登录流媒体应用的方式：

1. 在**内容提供方**屏幕上选择提供方卡片
2. FreePlay 会显示**连接到**屏幕，其中包含提供方名称、二维码和验证网址
3. 用手机扫描二维码，或在任意设备上访问显示的网址
4. 输入电视屏幕上显示的代码
5. 在手机或电脑上完成登录流程
6. FreePlay 检测到登录成功后，会显示**连接成功！**
7. 内容浏览器会自动打开

:::info
闪烁的**等待确认**指示器表示 FreePlay 正在检查您的登录状态。屏幕会显示代码过期前剩余的分钟数，因此请尽快完成操作。如果代码已过期，请选择**生成新代码**。
:::

## 手机登录（仅二维码）

**Dropbox**、**OneDrive** 和 **Go Curriculum** 使用略有不同的二维码登录方式，无需输入代码：

1. 在**内容提供方**屏幕上选择提供方卡片
2. FreePlay 会显示**连接到**屏幕，其中包含提供方名称和二维码
3. 用手机扫描二维码，并使用该提供方的账户登录（OneDrive 使用您的 Microsoft 账户，Go Curriculum 使用您的 gocurriculum.com 账户）
4. 批准访问权限。电视会自动连接并显示**连接成功！**

屏幕会显示您完成登录还剩的分钟数。

## 表单登录

其他提供方使用传统的电子邮件和密码登录：

1. 选择提供方卡片
2. 使用屏幕键盘输入您的**电子邮件**和**密码**
3. 选择**登录**按钮
4. 如果凭据正确，FreePlay 会显示**连接成功！**并打开内容浏览器

:::tip
使用遥控器的方向键在电子邮件字段、密码字段和登录按钮之间移动。在文本字段上按下**确认**即可打开屏幕键盘。
:::

## 提供方设置

选择显示**已连接**标记的提供方卡片，会打开其**提供方设置**屏幕：

- **浏览资料库** -- 在侧边栏中显示或隐藏此提供方的内容资料库
- **自动下载今日课程** -- 将此提供方作为今日课程的来源，并预先下载其文件（仅对提供当前课程的提供方显示）
- **用于公告** -- 从此提供方中选择一个文件夹，在侧边栏的**公告**项目中循环播放。参见[公告](./announcements)
- **检查公告更新** -- 选择公告文件夹后显示；下载新幻灯片并删除已移除的幻灯片
- **断开连接** -- 移除此连接

## 断开提供方连接

要断开您已连接的提供方：

1. 进入**内容提供方**屏幕（**设置** > **提供方**）
2. 选择显示**已连接**标记的提供方卡片
3. 在**提供方设置**屏幕上，选择**断开连接**

断开连接后，该提供方的内容将不再出现在侧边栏中。如果您曾将其某个文件夹用于公告，这些幻灯片也会被一并删除。

:::warning
断开连接会从您的设备中移除已保存的身份验证信息。如果日后想重新连接，您需要再次登录。
:::
