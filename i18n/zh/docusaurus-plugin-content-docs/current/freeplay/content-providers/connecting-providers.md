# 连接内容提供商

<div class="article-intro">

在浏览提供商的内容之前，你需要先连接到它。有些提供商需要通过二维码或电子邮件登录进行身份验证，而另一些只需单击即可连接。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 安装并启动 FreePlay -- 参见[新手入门](../getting-started/)
- 准备好电视遥控器以便导航
- 对于需要登录的提供商，请准备好你的账号凭据

</div>

:::tip 要一起设置 B1 Admin 和 FreePlay 吗？
我们的**<a href="/guides/freeplay-b1admin" target="_blank">分步指南</a>**详细介绍了如何关联 B1 Admin、安排课程以及连接 FreePlay——所有步骤都在一个地方完成。请在新标签页中打开以便跟随操作。
:::

## 浏览可用的提供商

1. 从侧边栏打开**内容提供商**屏幕（选择底部的**提供商**图标）
2. 你会看到一个提供商卡片网格，每张卡片显示提供商的徽标和名称
3. 已连接的提供商会在名称下方显示绿色的**已连接**徽章
4. 尚未可用的提供商会显示**即将推出**标签

## 无需身份验证即可连接

有些提供商不需要登录。当你选择这些提供商之一时，FreePlay 会立即连接并打开内容浏览器。无需任何凭据。

## 设备流身份验证（二维码）

某些提供商使用设备流方式，与在电视上登录流媒体应用的方式类似：

1. 在**内容提供商**屏幕上选择提供商卡片
2. FreePlay 会显示一个二维码和一个验证网址
3. 用手机扫描二维码，或在任意设备上访问显示的网址
4. 输入电视屏幕上显示的用户代码
5. 在手机或电脑上完成登录流程
6. FreePlay 检测到登录成功后会显示**已连接！**
7. 内容浏览器会自动打开

:::info
一个脉动的**等待授权**指示器表示 FreePlay 正在检查你的登录状态。代码会在几分钟后过期，所以请及时完成流程。
:::

**Go Curriculum** 使用相同的二维码登录方式——扫描代码并使用你的 gocurriculum.com 账号登录即可连接。

## 表单登录

其他提供商使用传统的电子邮件和密码登录：

1. 选择提供商卡片
2. 使用屏幕键盘输入你的**电子邮件**和**密码**
3. 选择**登录**按钮
4. 如果凭据正确，FreePlay 会显示**已连接！**并打开内容浏览器

:::tip
使用遥控器上的方向键在电子邮件字段、密码字段和登录按钮之间移动。在文本字段上按**选择**键即可打开屏幕键盘。
:::

## 断开提供商连接

要断开已连接的提供商：

1. 前往**内容提供商**屏幕
2. 选择显示**已连接**徽章的提供商卡片
3. 会出现一个确认提示，询问你是否要断开连接
4. 选择**断开连接**以移除该连接

断开连接后，该提供商的内容将不再出现在你的侧边栏中。

:::warning
断开连接会移除设备上保存的身份验证信息。如果以后想重新连接，你需要重新登录。
:::
