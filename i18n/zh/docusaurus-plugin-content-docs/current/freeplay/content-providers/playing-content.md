# 播放内容

<div class="article-intro">

FreePlay 播放器会全屏显示，专为电视遥控器设计。它可以播放来自内容提供方、已下载的课程、计划或您的公告文件夹中的视频和图片幻灯片，并可自动或按您的节奏切换内容。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 选择要播放的内容。请参阅[浏览和下载内容](./browsing-content)、[计划模式](../plan-mode/)或[公告](./announcements)
- 按下**开始**以打开播放器

</div>

:::info
与日历配对的屏幕会使用单独的定时播放器，其控件略有不同。请参阅[电视上的定时播放](../scheduled-mode/scheduled-playback)。
:::

## 播放器控件

使用电视遥控器控制播放：

| 遥控器按钮 | 功能 |
|---|---|
| **确定 / 播放-暂停** | 暂停或继续播放 |
| **右方向键** | 跳到下一张幻灯片或下一个视频 |
| **左方向键** | 返回上一张幻灯片或上一个视频 |
| **快进** | 在视频中前进 10 秒。在幻灯片上，则跳到下一项 |
| **快退** | 在视频中后退 10 秒。在幻灯片上，则跳到上一项 |
| **上方向键** | 打开**选择消息**，跳转到特定项目 |
| **下 / 返回** | 退出播放器 |

:::tip
在支持触控的遥控器上，您还可以使用滑动操作。向左滑动前进，向右滑动后退，向下滑动打开**选择消息**，向上滑动退出播放器。
:::

## 视频与幻灯片

暂停时，内容上方会出现暂停图标。再次按下**确定**或**播放-暂停**即可继续播放。

视频播放完毕后会自动切换到下一项。设置为循环的视频会一直重复播放，直到您跳到下一项为止。

图片幻灯片会在几秒钟后自动切换（除非内容提供方设置了其他时长，否则为 5 秒）。如需提前切换，请按**右方向键**；如需让幻灯片保持在屏幕上，请暂停播放。

## 选择消息

在播放过程中按下**上**键，即可打开**选择消息**。它会显示所有项目的缩略图和标题，并将正在播放的项目标记为**正在播放**。移动到任意项目并按下**确定**，即可直接跳转到该项目。按**返回**可关闭列表，且不会更改任何内容。

## 退出播放器

在遥控器上按下**下**或**返回**即可离开播放器。您最终返回的位置取决于您正在播放的内容：

- **内容提供方的内容** -- 返回内容浏览器
- **计划** -- 返回计划下载页面。请参阅[计划模式](../plan-mode/)
- **下载的内容** -- 返回**下载**页面

:::info
播放器打开期间屏幕会保持唤醒状态，因此电视不会在课程进行中进入睡眠。
:::
