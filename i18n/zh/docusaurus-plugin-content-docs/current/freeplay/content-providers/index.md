# 内容提供商

<div class="article-intro">

内容提供商是为您的电视提供课程资料、视频和图片的外部服务。FreePlay 支持多个提供商，让您可以在同一个应用中浏览并下载来自不同来源的内容。

</div>

## 可用的提供商

FreePlay 目前包含以下提供商：

- **[Lessons.church](../../lessons-church/index.md)** - 免费的开源儿童事工课程
- **Bible Project** - 探索圣经的视频和资源
- **SignPresenter** - 为教会提供的演示文稿和标识内容
- **B1.church** - 来自您自己 B1 教会设置的内容
- **Go Curriculum** - 来自 gocurriculum.com 的课程，按年龄组（**Elementary** 和 **Preschool**）分类，然后是系列和课程。您只能看到您的 Go 会员资格所包含的年龄组和视频
- **Dropbox** - 浏览并播放您自己 Dropbox 中的图片和视频
- **Jesus Film Project** - 来自 Jesus Film Project 的电影和视频片段
- **OneDrive** - 浏览并播放您自己 Microsoft OneDrive 中的图片、视频和音频

:::note
Google Drive 和 FreeShow 不再显示在 FreePlay 电视应用中。要在电视上使用 Google Drive 内容，请在 [FreePlay Admin](../scheduled-mode/building-playlists.md#connecting-providers) 中进行连接，将文件添加到播放列表，然后安排该播放列表。
:::

:::info
部分提供商仍在陆续添加中。如果某个提供商卡片显示"Coming Soon"（即将推出），则表示该提供商尚无法连接。
:::

## 提供商的工作方式

每个提供商都有自己的内容库，按文件夹和文件进行组织。连接提供商后，其内容会显示在文件夹浏览器中，您可以在其中进入分类、选择项目并下载以供播放。

已连接的提供商会显示在屏幕左侧边栏的 **Browse** 标题下。您只需在侧边栏中选择即可在不同提供商之间切换，便于在设置过程中轻松切换内容来源。

您还可以从任一已连接的提供商中选择一个文件夹，将其作为[公告](./announcements.md)在电视上循环播放。

:::tip
您在电视上连接的提供商仅适用于该电视。如果您使用[定时模式](../scheduled-mode/index.md)，请改为在 FreePlay Admin 中连接一次提供商，之后每个定时屏幕都可以播放来自这些提供商的内容。
:::
