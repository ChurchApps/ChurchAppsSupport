# 内容提供商

<div class="article-intro">

内容提供商是为电视播放提供课程材料、视频和图片的外部服务。FreePlay 支持多个提供商，让你可以在一个应用中浏览并下载来自不同来源的内容。

</div>

## 可用的提供商

FreePlay 目前包含以下提供商：

- **[Lessons.church](../../lessons-church/)** - 免费、开源的儿童事工课程
- **Bible Project** - 探索圣经的视频和资源
- **SignPresenter** - 面向教会的演示和标牌内容
- **B1.church** - 来自你自己 B1 教会设置的内容
- **Go Curriculum** - 来自 gocurriculum.com 的课程，按合集和课时组织

:::info
部分提供商仍在陆续接入中。如果提供商卡片显示"即将推出"，则表示该提供商目前尚不能连接。
:::

## 提供商的工作方式

每个提供商都有自己的内容库，按文件夹和文件组织。连接到某个提供商后，其内容会显示在文件夹浏览器中，你可以深入浏览类别、选择项目并下载以供播放。

已连接的提供商会显示在屏幕左侧的侧边栏中。你可以在侧边栏中选择不同的提供商进行切换，方便在设置过程中在各内容来源之间跳转。
