# 内容提供商

<div class="article-intro">

内容提供商是为您的电视提供课程材料、视频和图片的外部服务。FreePlay 支持多个提供商，让您可以在同一个应用中浏览并下载来自不同来源的内容。

</div>

## 可用的提供商

FreePlay 目前包含以下提供商：

- **[Lessons.church](../../lessons-church/)** —— 免费的开源儿童事工课程
- **Bible Project** —— 探索圣经的视频和资源
- **SignPresenter** —— 面向教会的演示文稿和标牌内容
- **B1.church** —— 来自您自己 B1 教会系统的内容
- **Go Curriculum** —— 来自 gocurriculum.com 的课程，按系列和课程组织
- **Dropbox** —— 浏览并播放您自己 Dropbox 中的图片和视频
- **Jesus Film Project** —— 来自 Jesus Film Project 的电影和视频片段
- **OneDrive** —— 浏览并播放您自己 Microsoft OneDrive 中的图片、视频和音频

:::note
Google Drive 和 FreeShow 不再显示在 FreePlay 电视应用中。若要在电视上使用 Google Drive 的内容，请在 [FreePlay Admin](../scheduled-mode/building-playlists#connecting-providers) 中将其连接，将文件添加到播放列表，然后安排该播放列表。
:::

:::info
部分提供商仍在陆续添加中。如果某个提供商卡片显示"Coming Soon（即将推出）"，则表示该提供商目前尚不可连接。
:::

## 提供商的工作方式

每个提供商都有自己的内容库，内容按文件夹和文件组织。连接提供商后，其内容会出现在文件夹浏览器中，您可以进入各个分类、选择项目并下载用于播放。

已连接的提供商会显示在屏幕左侧的边栏中，位于 **Browse（浏览）** 标题下。您可以在边栏中选择不同的提供商进行切换，便于在设置过程中轻松地在各个内容来源之间跳转。

您也可以从任何已连接的提供商中选择一个文件夹，将其作为[公告](./announcements)在电视上循环播放。

:::tip
您在电视上连接的提供商仅适用于该台电视。如果您使用[定时模式](../scheduled-mode/)，请改为在 FreePlay Admin 中一次性连接提供商，这样每个定时屏幕都可以播放这些提供商的内容。
:::
