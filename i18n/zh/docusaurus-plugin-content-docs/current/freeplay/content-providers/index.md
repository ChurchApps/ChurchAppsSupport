# 内容提供商

<div class="article-intro">

内容提供商是提供课程材料、视频和图像以在您的电视上播放的外部服务。FreePlay 支持多个提供商，让您在一个应用中浏览和下载来自不同来源的内容。

</div>

## 可用的提供商

FreePlay 目前包括以下提供商：

- **[Lessons.church](../../lessons-church/)** - 免费、开源的儿童事工课程
- **Bible Project** - 探索圣经的视频和资源
- **SignPresenter** - 教会的演示和标志内容
- **B1.church** - 来自您自己的 B1 教会设置的内容
- **Go Curriculum** - 来自 gocurriculum.com 的课程，按收集和课程组织
- **Google Drive** - 从您自己的 Google Drive 浏览和播放视频和音频文件
- **FreeShow** - FreePlay 找到 FreeShow 在同一网络上的计算机上运行并连接到它

:::info
一些提供商仍在添加中。如果提供商卡片显示"即将推出"，它尚不可用于连接。
:::

## 提供商如何工作

每个提供商都有自己的内容库，组织成文件夹和文件。连接到提供商后，其内容出现在文件夹浏览器中，您可以在其中钻取类别、选择项目并下载它们以供播放。

连接的提供商在屏幕左侧的侧边栏中出现，在**浏览**标题下。您可以在侧边栏中选择它们来在提供商之间切换，轻松在设置期间在内容来源之间跳转。

您还可以从任何连接的提供商选择一个文件夹以循环为[公告](./announcements)在您的电视上。
