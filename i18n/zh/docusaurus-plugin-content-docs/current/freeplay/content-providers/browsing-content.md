# 浏览和下载内容

<div class="article-intro">

连接到内容提供方后，您可以浏览其资料库、下载文件，并在电视上播放。内容浏览器以可视化网格的形式展示文件夹和文件，您可以使用电视遥控器进行导航。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 至少连接一个内容提供方 -- 参见[连接提供方](./connecting-providers)
- 准备好电视遥控器以便导航

</div>

## 内容浏览器

内容浏览器以 3 列卡片网格显示项目。每张卡片都会显示缩略图和标题。项目分为两种类型：

- **文件夹** - 以缩略图或文件夹图标表示。选择文件夹即可查看其内容
- **文件** - 单个媒体项目（视频或图片）。视频文件的缩略图上会显示播放图标

屏幕顶部的标题栏会显示当前文件夹的名称；如果您位于根目录，则显示提供方名称。

## 浏览文件夹

1. 使用遥控器的方向键高亮选中一个文件夹
2. 按下**确认**打开它
3. 浏览器会加载该文件夹的内容，其中可能是更多文件夹或可播放的文件
4. 在遥控器上按下**返回**，即可返回上一级

您可以深入浏览，深度取决于提供方的内容结构。浏览器会记录您的文件夹路径，方便您逐级返回。

## 浏览 Lessons.church

[Lessons.church](../../lessons-church/) 资料库的组织方式与其网站相同。在顶层，您会看到两个文件夹：

- **Lessons（课程）** - 依次按**项目**、**研习**和**课程**进入。每节课会列出其**版本**，即针对特定年龄段或场景（例如学前班或小学）的课程版本。选择某个版本即可打开该课程版本的下载屏幕
- **Add-Ons（附加内容）** - 按类别分组的额外视频和资源

在任一层级按下**返回**即可回到上一级。

## 下载和播放内容

当您选择包含可播放文件的文件夹（或选择单个文件）时，FreePlay 会显示内容标题、封面图片以及两个选项：

- **下载** - 先将所有文件保存到电视上，播放时便不依赖 Wi-Fi。每保存一个文件，进度条都会随之填充。完成后，会出现带有播放图标的**开始**按钮。按下**确认**即可开始播放
- **流式播放** - 不保存文件，直接通过互联网开始播放

:::tip
请在主日早晨之前，趁教堂网络连接良好时下载课程。下载完成后，内容可离线播放；如果之后再次播放，将立即加载，无需重新下载。
:::

## 管理下载

在侧边栏底部打开**设置**，然后选择**下载**，即可查看此电视上保存的所有内容：

- 选择某个下载项即可播放
- 高亮选中某个下载项，然后选择其角落的删除图标，即可将其移除并释放存储空间

如果屏幕显示**暂无下载**，说明此电视上尚未保存任何内容。

## 播放提供方内容

播放期间可使用以下控制：

- **右方向键** - 下一项
- **左方向键** - 上一项
- **确认 / 播放-暂停** - 暂停或继续播放视频
- **上方向键** - 打开信息选择器，跳转到特定项目
- **返回** - 退出到内容浏览器

退出播放器后，您将返回当前提供方根目录下的内容浏览器。

:::info
有关所有播放器控制的完整说明，请参阅[播放内容](./playing-content)。
:::

## 在提供方之间切换

已连接的提供方会显示在左侧边栏的**浏览**标题下。要切换到其他提供方：

1. 按下遥控器上的**左**方向键展开侧边栏
2. 选择您要浏览的提供方
3. 内容浏览器会刷新，显示该提供方的资料库

:::warning
如果某个文件夹显示"无可用内容"，说明该提供方在此层级没有任何项目。请尝试浏览其他文件夹，或稍后再查看。
:::
