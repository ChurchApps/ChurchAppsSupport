# 浏览和下载内容

<div class="article-intro">

连接到内容提供商后，您可以浏览其库、下载文件并在电视上播放它们。内容浏览器提供了文件夹和文件的可视网格，您使用电视遥控器进行导航。

</div>

<div class="prereqs">
<h4>在您开始之前</h4>

- 至少连接到一个内容提供商 -- 见[连接到提供商](./connecting-providers)
- 为导航准备好您的电视遥控器

</div>

## 内容浏览器

内容浏览器在 3 列卡片网格中显示项目。每张卡片显示一个缩略图和标题。有两种项目类型：

- **文件夹** - 由缩略图或文件夹图标表示。选择一个文件夹以查看其内容。
- **文件** - 个别媒体项目（视频或图像）。视频文件在其缩略图上显示播放图标覆盖。

屏幕顶部的头显示当前文件夹的名称，或如果您在根级别上，则为提供商名称。

## 导航文件夹

1. 使用遥控器上的方向盘突出显示一个文件夹
2. 按**选择**打开它
3. 浏览器加载文件夹的内容，这可能是更多文件夹或可播放文件
4. 在遥控器上按**返回**以上升一个级别

您可以钻取提供商内容结构允许的深度。浏览器跟踪您的文件夹路径，所以您可以通过每个级别导航返回。

## 下载和播放内容

当您选择包含可播放文件的文件夹（或选择单个文件）时，FreePlay 移动到下载屏幕：

1. 内容标题与所选文件夹的封面图像一起出现在屏幕上
2. 进度条显示**下载项目 X 之 Y**，因为文件被保存到您的设备
3. 一旦下载完毕，**开始**按钮与播放图标一起出现
4. 按**选择**开始播放

:::tip
下载的内容缓存在您的电视上。如果您稍后再次播放相同内容，它会立即加载而不重新下载。
:::

## 播放提供商内容

播放的工作方式与课程播放相同。使用这些控制：

- **右箭头** - 下一项
- **左箭头** - 上一项
- **选择 / 播放-暂停** - 暂停或恢复视频
- **向上箭头** - 打开消息选择器以跳转到特定项目
- **返回** - 退出到内容浏览器

当您退出播放器时，您在当前提供商的根级别返回到内容浏览器。

:::info
有关所有播放器控件的完整参考，请见[播放课程](../classroom-mode/playing-lessons)。
:::

## 在提供商之间切换

连接的提供商在左侧侧边栏的**浏览**标题下显示为项目。要切换到不同的提供商：

1. 在遥控器上按**左**箭头以展开侧边栏
2. 选择您想要浏览的提供商
3. 内容浏览器用该提供商的库刷新

:::warning
如果文件夹显示"没有可用内容"，提供商在该级别没有任何项目。尝试导航到不同的文件夹或稍后检查。
:::
