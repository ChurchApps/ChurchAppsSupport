# 浏览和下载内容

<div class="article-intro">

连接内容提供方后，您可以浏览其资料库、下载文件，并在电视上播放。内容浏览器以可视化网格的形式显示文件夹和文件，您可以使用电视遥控器进行导航。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 至少连接一个内容提供方——参见 [连接提供方](./connecting-providers.md)
- 准备好电视遥控器

</div>

## 内容浏览器

内容浏览器以每行 3 列的卡片网格显示项目。每张卡片显示一张缩略图和一个标题。项目分为两种类型：

- **文件夹**——以缩略图或文件夹图标表示。选择文件夹即可查看其内容。
- **文件**——单个媒体项目（视频或图片）。视频文件的缩略图上会显示播放图标。

屏幕顶部的标题栏显示当前文件夹的名称；如果您位于根目录，则显示提供方名称。

## 浏览文件夹

1. 使用遥控器上的方向键高亮选中一个文件夹
2. 按下**确认**键打开该文件夹
3. 浏览器会加载文件夹内容，内容可能是更多文件夹或可播放的文件
4. 按遥控器上的**返回**键返回上一级

您可以根据提供方的内容结构逐层深入。浏览器会记录您的文件夹路径，方便您逐级返回。

## 浏览 Lessons.church

[Lessons.church](../../lessons-church/index.md) 资料库的组织方式与其网站相同。在顶层，您会看到两个文件夹：

- **Lessons**——按**项目（program）**、**研经（study）**、**课程（lesson）**逐级进入。每节课程会列出其**场景（venue）**，即适用于特定年龄段或场合的课程版本，例如学龄前或小学。选择一个场景即可打开该版本课程的下载界面。
- **Add-Ons**——额外的视频和资源，按类别分组。

在任何一级按**返回**键即可返回上一级。

## 浏览 Go Curriculum

在您[使用 gocurriculum.com 账户登录](./connecting-providers.md#phone-sign-in-qr-code-only)后，Go Curriculum 会显示其年龄组：**Elementary**（小学）和 **Preschool**（学龄前）。依次选择年龄组、合集和课程，然后选择一节课程即可打开其下载界面。

您看到的内容取决于您的 Go 会员资格：

- 仅列出您的会员资格所涵盖的年龄组。如果您的登录账户没有 Go 会员资格，资料库将为空。
- 某些视频仅面向特定会员级别。您的会员资格不包括的视频将不会显示在课程中。

## 下载和播放内容

选择包含可播放文件的文件夹（或选择单个文件）时，FreePlay 会显示内容标题和封面图片，并提供两个选项：

- **下载**——先将所有文件保存到电视上，这样播放就不依赖 Wi-Fi。每个文件保存时，进度条都会随之填充。完成后，会出现带有播放图标的**开始**按钮。按**确认**键开始播放。
- **流式播放**——直接通过互联网开始播放，不保存文件。

:::tip
在周日上午之前、教堂网络连接良好时下载课程。下载完成后，内容可离线播放；之后再次播放时会立即加载，无需重新下载。
:::

## 管理下载内容

打开侧边栏底部的**设置**，然后选择**下载**，即可查看保存在此电视上的所有内容：

- 选择某个下载项即可播放
- 高亮某个下载项，然后选择其角落的删除图标，即可将其移除并释放存储空间

如果屏幕显示**暂无下载**，则说明此电视上尚未保存任何内容。

## 播放提供方内容

播放时可使用以下控制：

- **右方向键**——下一项
- **左方向键**——上一项
- **确认 / 播放-暂停**——暂停或继续播放视频
- **上方向键**——打开消息选择器，跳转到特定项目
- **返回**——退出到内容浏览器

退出播放器后，您将返回当前提供方根目录下的内容浏览器。

:::info
如需查看所有播放器控制的完整说明，请参阅[播放内容](./playing-content.md)。
:::

## 在提供方之间切换

已连接的提供方会显示在左侧边栏的**浏览**标题下。要切换到其他提供方：

1. 按遥控器上的**左**方向键展开侧边栏
2. 选择您要浏览的提供方
3. 内容浏览器会刷新，显示该提供方的资料库

:::warning
如果某个文件夹显示“没有可用内容”，则说明该提供方在此级别没有任何项目。请尝试浏览其他文件夹，或稍后再查看。
:::
