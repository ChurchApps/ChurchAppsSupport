# FreePlay 概览

<div class="article-intro">

FreePlay 是一款面向教会的电视应用，可在教室电视上显示课程内容。它可在 Android TV、Amazon Fire TV 和 Apple TV 上运行，设计目标是在周日早晨无需互联网连接即可使用。志愿者可以在平时预先下载课程材料，待课程开始时只需按下播放即可。

</div>

:::tip 第一次使用 FreePlay？从这里开始
观看我们的**<a href="/guides/freeplay-quickstart" target="_blank">快速入门视频</a>**，几分钟内即可安装 FreePlay 并开始播放内容。无需任何技术技能。
:::

:::tip 想进一步了解？
我们的**<a href="/guides/freeplay-b1admin" target="_blank">完整设置指南</a>**将引导您关联 B1 Admin，使每周的正确课程自动下载到您的教室电视上。包含视频和文字步骤。
:::

## 主要功能

- **离线播放** - 提前下载视频和图片幻灯片，使您在礼拜期间无需依赖 Wi-Fi
- **下载管理** - 通过**设置** > **下载**查看和管理所有已下载的内容
- **定时模式** - 在 [admin.freeplay.church](https://admin.freeplay.church) 构建播放列表并将其安排到日历中，已配对的电视会在正确的时间自动播放，无需任何人按下开始 -- 参见[定时模式](./scheduled-mode/)
- **计划配对** - 将您的设备关联到教会的服务计划，以便在各个房间协调播放内容
- **内容提供方** - 从外部来源浏览和下载内容，例如 [Lessons.church](/docs/lessons-church/)、Bible Project、Dropbox 和 OneDrive
- **公告** - 循环播放已连接提供方中某个文件夹里的幻灯片 -- 参见[公告](./content-providers/announcements)
- **适用电视遥控器** - 使用方向键和确认键，即可用标准电视遥控器操作整个应用
- **可折叠侧边栏** - 纤细的侧边栏让导航随时可用，同时不会占用过多屏幕空间

## 工作原理

启动 FreePlay 时，它会连接到您的内容提供方并检查可用内容。之后，您可以浏览文件夹、下载媒体并播放课程，所有操作都针对大屏幕电视进行了优化。
