# FreePlay 概述

<div class="article-intro">

FreePlay 是为教会设计的电视应用程序，可在教室电视上显示课程内容。它可在 Android TV、Amazon Fire TV 和 Apple TV 上运行，旨在周日早上不需要互联网连接的情况下工作。志愿者可以在整个星期预先下载课程材料，然后在课程开始时按播放键。

</div>

## 关键特性

- **离线播放** - 提前下载视频和图像幻灯片，这样您在服务期间永远不会依赖 Wi-Fi
- **下载管理** - 从**设置** > **下载**查看和管理所有下载的内容
- **教室配对** - 将您的电视连接到特定房间并自动接收计划的课程内容
- **计划配对** - 将您的设备链接到教会服务计划，以实现房间之间的协调内容
- **内容提供者** - 从 [Lessons.church](/docs/lessons-church/) 和 Bible Project 等外部来源浏览和下载内容
- **公告** - 从连接的提供者循环播放一个幻灯片文件夹 -- 请参阅[公告](./content-providers/announcements)
- **电视遥控器友好** - 使用标准电视遥控器和方向按钮及选择按钮导航整个应用程序
- **可折叠边栏** - 一个细长的边栏使导航易于访问，不会使屏幕混乱

## 它的工作原理

当您启动 FreePlay 时，它会连接到您的内容提供者并检查可用内容。从那里，您可以浏览文件夹、下载媒体和播放课程 -- 所有内容都针对大屏幕电视体验进行了优化。
