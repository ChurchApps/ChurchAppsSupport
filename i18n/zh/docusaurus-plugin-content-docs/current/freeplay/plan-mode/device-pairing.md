# 配对你的设备

<div class="article-intro">

要使用计划模式，你需要在 B1 Admin 中将电视与某个计划类型配对。FreePlay 会生成一个唯一的配对代码，将设备与你教会的计划关联起来，从而实现每周自动内容分发。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 安装并启动 FreePlay -- 参见[新手入门](../getting-started/)
- 在[配对模式屏幕](../getting-started/pairing-modes.md)中选择**配对到计划**
- 可通过电脑或手机访问 **B1 Admin** 以完成配对

</div>

## 生成配对代码

1. 在**选择配对模式**屏幕上，选择**配对到计划**
2. FreePlay 会联系服务器并生成一个简短的配对代码
3. 代码会以大字符显示在屏幕中央
4. 代码下方会有一个脉动指示器，显示**等待连接**

代码以单个字符的形式显示，方便在房间对面阅读。

## 在 B1 Admin 中输入代码

1. 在电脑或手机上，访问电视上代码下方显示的地址（或扫描屏幕上的二维码）——这会打开 B1 Admin 中的**授权设备**页面
2. 如果代码没有通过二维码自动填入，请输入配对代码
3. 在**显示哪些计划**下，选择你希望该屏幕跟随的计划类型（例如"主日崇拜"）。如果你只想让屏幕用于浏览内容或通知而不关联任何计划，请保持设置为**无**
4. 批准该设备

FreePlay 会每隔几秒轮询服务器，检查配对是否完成。一旦 **B1 Admin** 确认连接，电视就会自动进入计划下载屏幕。

:::tip
也可以使用同一个代码在 B1 Admin 的**个人资料 → 设备 → 添加设备**中配对设备——该处提供同样的**显示哪些计划**类型选择器。
:::

## 下载计划内容

配对完成后，FreePlay 会加载该计划类型的当前计划。它会显示：

- 计划名称和崇拜日期
- 关联的课程名称（如果计划包含课程内容）
- 显示**正在下载第 X 项，共 Y 项**的进度指示器

当所有媒体文件下载完成后，会出现**开始计划**按钮。按遥控器上的**选择**键即可开始播放。

:::tip
计划每小时自动刷新一次。如果计划在当天有更新，FreePlay 会自动获取变更，无需任何手动操作。
:::

## 备选方案：按教会名称搜索

如果你不想使用配对代码流程，可以在配对屏幕底部选择**或按教会名称搜索**。这会带你进入教会搜索屏幕，你可以在那里找到你的教会并改为连接到教室。

## 如果配对失败

如果无法生成配对代码（例如由于网络问题），你会看到一条错误消息以及一个**重试**按钮。请确保你的电视已连接到互联网，然后重试。

:::warning
配对代码会在一段时间后过期。如果等待时间过长，请返回配对屏幕生成新代码。
:::
