# 配对您的设备

<div class="article-intro">

要使用礼拜计划模式，您需要将电视与 B1 Admin 中的计划类型进行配对。FreePlay 会在电视上显示一个简短的配对码。您在 B1 Admin 中输入该配对码，并选择要跟随的计划类型，电视便会每周自动获取该计划的内容。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 安装并启动 FreePlay。参见[入门指南](../getting-started/)
- 需要使用电脑或手机访问 **B1 Admin** 以完成配对

</div>

## 生成配对码

1. 在电视上，打开侧边栏底部的 **设置**。
2. 选择 **配对到日历**。
3. FreePlay 会以大字显示一个四个字母的配对码，旁边是一个二维码。
4. 在配对码下方，一个闪烁的 **等待确认** 指示器表示 FreePlay 正在等待您完成配对。

同一配对码既可用于 FreePlay Admin 中的[定时模式](../scheduled-mode/)，也可用于 B1 Admin 中的礼拜计划模式。屏幕上的二维码和 **freeplay.church/pair** 地址会打开 FreePlay Admin。若使用礼拜计划模式，请忽略它们，并按下文所述在 B1 Admin 中输入配对码。

## 在 B1 Admin 中输入配对码

1. 在 B1 Admin 中，进入 **个人资料** > **设备**，然后点击 **添加屏幕**。
2. 在 **配对码** 中输入电视上显示的四个字母。
3. 在 **显示以下计划** 下，选择您希望此屏幕跟随的计划类型，例如“主日礼拜”。
4. 保存。

FreePlay 每隔几秒钟检查一次配对是否完成。B1 Admin 确认配对后，电视会显示 **已连接！**，并进入计划下载界面。

## 下载计划内容

配对完成后，FreePlay 会加载该计划类型的当前计划。它会显示：

- 计划名称和礼拜日期
- 如果计划包含课程内容，则显示课程名称
- 显示 **正在下载第 X 项，共 Y 项** 的进度指示器

当所有媒体文件下载完成后，会出现 **开始计划** 按钮。在遥控器上按下 **确认** 键即可开始播放。

:::tip
计划每小时自动刷新一次。如果有人在白天更新了计划，FreePlay 会自动获取这些更改。
:::

## 如果配对失败

如果 FreePlay 无法生成配对码（例如由于网络问题），您会看到一条错误消息，并附有 **重试** 按钮。请确保电视已连接到互联网，然后重试。

:::warning
配对码在 15 分钟后失效。旧的配对码到期时，FreePlay 会自动显示新的配对码，您也可以随时选择 **生成新配对码**。如果您输入的配对码无效，请使用电视当前显示的配对码。
:::
