# 计划模式

<div class="article-intro">

计划模式可将您的电视与教会的服事计划连接起来。它不再根据课堂时间表提取内容，而是遵循教会领导层在 B1 Admin 中配置的计划。当您希望电视准确显示本周计划中安排的内容时，这种模式尤为理想。

</div>

## 与其他模式的区别

- **[定时模式](../scheduled-mode/)**会在您设定的时间播放 FreePlay Admin 中日历里的播放列表，无需有人按下开始
- **计划模式**会获取与某个计划类型相关联的内容，其中可能包括课程、内容提供方的演示、附加内容以及其他按自定义顺序排列的媒体

当您的服事计划包含来自不同来源、并组织在同一序列中的多种内容时，计划模式尤其有用。

:::tip
希望当前计划在设定的时间自动播放吗？在 FreePlay Admin 中添加日历条目，并在**服事计划**下选择计划类型即可。请参阅[安排日历](../scheduled-mode/scheduling-the-calendar)。
:::

## 工作原理

1. 在电视上，打开**设置** > **配对到日历**，以显示配对码
2. 管理员在 **B1 Admin** 中输入该配对码，并在**显示以下计划**下选择计划类型
3. 配对完成后，FreePlay 会加载当前计划并下载所有相关媒体
4. 按下**开始计划**即可开始播放

电视会保持与该计划类型的配对。每周，它都会自动获取最新的计划及其内容。
