# 安排日历

<div class="article-intro">

FreePlay 管理后台中的**日历**页面用于控制每个屏幕组播放什么内容以及何时播放。您可以为播放列表、礼拜计划或提供商文件夹添加计划，并将其设置为每周重复或仅播放一次。当没有安排任何内容时，该组的默认循环会播放。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 至少创建一个屏幕组。请参阅[管理屏幕与分组](./managing-screens.md#screen-groups)
- [创建播放列表](./building-playlists.md)，或在 B1 管理后台中设置好计划类型

</div>

## 查看日历 {#reading-the-calendar}

1. 进入**日历**。
2. 从顶部的标签页中选择一个屏幕组。每个标签页都会显示该组拥有的计划数量。
3. 周视图从周一到周日，时间为上午 6 点至晚上 10 点。红线标示当前时间。
4. 使用箭头切换到上一周或下一周，或点击**今天**回到本周。

页面副标题会显示日历所使用的时区。计划遵循教会的时区，该时区可在 B1 管理后台的[教会信息](../../b1-admin/settings/church-settings.md#time-zone)中设置。如果教会未设置时区，FreePlay 将使用您所在校区的时区。日历与电视使用相同的时区，因此在日历上放置于上午 9:00 的时段，将会在屏幕上于上午 9:00 播放，即使您的电脑设置为其他时区。

计划按类型进行颜色编码。图例说明了各种颜色的含义：

- **默认循环** -- 斜线背景，当该组设有默认循环时，显示在所有内容的底层
- **播放列表**
- **礼拜计划**
- **提供商文件夹**

每个时段都会显示其名称；较高的时段还会显示时间、是否重复（**每周**或**单次**），以及提前结束时的处理方式。

## 设置默认循环 {#setting-the-default-loop}

当没有安排任何内容时，默认循环会在该组的屏幕上播放。

1. 在**日历**页面，点击页眉中的**默认循环…**。如果已设置默认循环，按钮会显示**默认循环：**，后接播放列表的名称。
2. 选择一个**播放列表**，或选择**无 — 屏幕变黑**。
3. 点击**保存**。

## 添加计划 {#adding-a-schedule}

有三种方式可以新建计划：

- 点击日历上的空白处。表单将打开，并已填入该日期和半小时时段。
- 点击页眉中的**添加计划**。
- 从命令面板中选择**添加计划**（**Ctrl+K** 或 **⌘K**）。

然后填写表单：

1. **播放** -- 选择要播放的内容：
   - **播放列表** -- 您已创建的任何播放列表
   - **礼拜计划** -- 来自 B1 管理后台的计划类型，标记为**（当前计划）**。屏幕每周都会播放该计划类型当前的计划，包括 Go Curriculum 课程（也包括自定义课程），这些课程使用与该计划类型的事工相关联的 Go 账户登录
   - **提供商文件夹…** -- 打开**选择提供商文件夹**。浏览到某个文件夹并点击**使用此文件夹**。若稍后要选择其他文件夹，请点击**更改**
2. **重复** -- 选择该计划播放的星期。若要改为单个日期，请开启**单次**并选择**日期**。
3. **开始**和**结束** -- 计划开始和停止的时间。
4. **如果提前结束** -- 当内容在结束时间之前已播放完毕时的处理方式：
   - **循环至结束时间** -- 从头重新开始。适用于标牌循环、公告和倒计时
   - **教师控制节奏** -- 幻灯片等待教师的遥控器操作。课程画面会一直保持到结束时间之后，直至最后一张幻灯片
   - **播放一次，然后返回默认循环**
5. 对于重复计划，将**开始于**设置为首个日期。在**结束于**下，选择**从不**，或选择**指定日期**并输入**结束日期**。
6. 点击**保存**。

:::info
**教师控制节奏**取代了较早的"停留在最后一张幻灯片"选项。使用该选项保存的计划现在将以教师控制节奏播放。
:::

## 编辑或删除计划 {#editing-or-deleting-a-schedule}

1. 点击日历上该计划的时段。
2. 更改任意字段并点击**保存**，或点击**删除**以移除该计划。

## 重叠的计划 {#overlapping-schedules}

如果两个计划相互重叠，表单会显示警告：**与另一计划重叠。开始较晚的计划优先**。在较晚的计划运行期间，屏幕会播放该计划。当其结束后，如果较早的计划仍在运行，屏幕将切换回较早的计划。

## 屏幕如何获取更改 {#how-screens-pick-up-changes}

已配对的屏幕会下载未来 7 天内安排的全部内容，并自行检查是否有更改。您在编辑日历后无需再去操作电视。若要查看某个屏幕是否已获得所需的全部内容，请查看[屏幕页面](./managing-screens.md)上的**就绪至**。
