# 安排日历

<div class="article-intro">

FreePlay Admin 中的 **日历** 页面用于控制每个屏幕组播放什么内容以及何时播放。您可以为播放列表、礼拜计划或提供方文件夹添加安排，并设置为每周重复或仅播放一次。未安排任何内容时，将播放该屏幕组的默认循环。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 至少创建一个屏幕组。参见[管理屏幕和组](./managing-screens#screen-groups)
- [制作播放列表](./building-playlists)，或在 B1 Admin 中设置好计划类型

</div>

## 查看日历

1. 进入 **日历**。
2. 从顶部的标签页中选择一个屏幕组。每个标签页都会显示该组拥有的安排数量。
3. 周视图从周一到周日，时间范围为上午 6 点至晚上 10 点。红线标示当前时间。
4. 使用箭头切换到上一周或下一周，或点击 **今天** 返回本周。

页面副标题会显示日历所使用的时区。安排遵循您教会的时区。如果您的教会未设置时区，FreePlay 将使用您所在校区的时区。

安排按类型以颜色区分。图例会说明各颜色的含义：

- **默认循环** - 斜线背景，当该组设置了默认循环时，显示在所有内容的下层
- **播放列表**
- **礼拜计划**
- **提供方文件夹**

每个色块都会显示其名称；较高的色块还会显示时间、是否重复（**每周** 或 **单次**），以及内容提前结束时的处理方式。

## 设置默认循环

默认循环会在该组的屏幕上播放，只要没有安排其他内容。

1. 在 **日历** 页面中，点击页眉中的 **默认循环…**。如果已经设置了默认循环，按钮会显示 **默认循环：** 加上播放列表的名称。
2. 选择 **播放列表**，或选择 **无 — 屏幕变暗**。
3. 点击 **保存**。

## 添加安排

有三种方式可以新建安排：

- 点击日历上的空白处。表单将打开，并已填入该日和对应的半小时时段。
- 点击页眉中的 **添加安排**。
- 从命令面板（**Ctrl+K** 或 **⌘K**）中选择 **添加安排**。

然后填写表单：

1. **播放** - 选择播放的内容：
   - **播放列表** - 您制作的任何播放列表
   - **礼拜计划** - 来自 B1 Admin 的计划类型，标有 **（当前计划）**。屏幕每周都会播放该计划类型当前的计划
   - **提供方文件夹…** - 打开 **选择提供方文件夹**。浏览到某个文件夹并点击 **使用此文件夹**。若稍后要选择其他文件夹，请点击 **更改**
2. **重复** - 选择此安排播放的星期几。若要改为单个日期，请开启 **单次**，然后选择 **日期**。
3. **开始** 和 **结束** - 安排开始和停止播放的时间。
4. **提前结束时** - 内容在结束时间之前播完时的处理方式：
   - **循环至结束时间** - 从头开始重新播放。适用于标识循环、通知和倒计时
   - **教师控制节奏** - 幻灯片会等待教师的遥控器操作。课程画面会在结束时间之后保持显示，直到最后一张幻灯片
   - **播放一次，然后返回默认循环**
5. 对于重复性安排，将 **开始日期** 设为第一个日期。在 **结束** 下，选择 **从不**，或选择 **指定日期**，然后输入 **结束日期**。
6. 点击 **保存**。

:::info
**教师控制节奏** 取代了较早的“停留在最后一张幻灯片”选项。使用该选项保存的安排现在将以教师控制节奏播放。
:::

## 编辑或删除安排

1. 点击日历上该安排的色块。
2. 更改任意字段并点击 **保存**，或点击 **删除** 以移除该安排。

## 重叠的安排

如果两个安排重叠，表单会显示警告：**与另一个安排重叠。开始时间较晚的安排优先。** 在较晚的安排运行期间，屏幕会播放该安排。它结束后，如果较早的安排仍在运行，屏幕将切换回较早的安排。

## 屏幕如何获取更改

已配对的屏幕会下载未来 7 天内安排的所有内容，并自行检查更改。您在编辑日历后无需操作电视。若要查看屏幕是否已具备所需的全部内容，请查看[屏幕页面](./managing-screens)上的 **就绪至**。
