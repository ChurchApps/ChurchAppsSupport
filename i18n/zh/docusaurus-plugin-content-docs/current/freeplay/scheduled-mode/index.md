# 定时模式

<div class="article-intro">

定时模式让 FreePlay 电视可以自动运行。您可以在 [admin.freeplay.church](https://admin.freeplay.church) 的 **FreePlay Admin** 中创建播放列表并将其排入日历。每台与该日历配对的电视都会下载未来一周的内容，并按照时钟准时播放已排定的内容，无需有人按下开始按钮。由于文件已预先下载，即使 Wi-Fi 断开，播放也会继续进行。

</div>

:::tip
FreePlay Admin 使用您的 ChurchApps 登录账户，即您用于 B1 Admin 的同一账户。无需另外创建账户。
:::

## 整体结构

FreePlay Admin 有四个主要页面，列在网站顶部：

- **[屏幕](./managing-screens)** - 您已配对的电视、其状态，以及它们所属的**屏幕组**。同一屏幕组中的屏幕共用一个日历和一个默认循环
- **[播放列表](./building-playlists)** - 您从内容提供方中选择的图片和视频循环
- **[日历](./scheduling-the-calendar)** - 每个屏幕组播放什么内容以及何时播放
- **[提供方](./building-playlists#connecting-providers)** - 您的播放列表所使用的内容来源。每个来源只需为整个教会连接一次

当没有排定任何内容时，屏幕组中的屏幕会播放其**默认循环**。如果该组没有默认循环，屏幕将保持黑屏。

## 与计划模式的区别

- **[计划模式](../plan-mode/)**从 B1 Admin 中跟随某一种服务计划类型。有人在电视上按下**开始计划**，课程才会开始播放
- **定时模式**则跟随日历。内容会在您设定的时间开始和停止，因此非常适合大厅标识、公告循环，以及需要在人员进入前就播放课程的教室

日历条目仍然可以播放服务计划。添加排程时，在**服务计划**下选择计划类型，屏幕就会播放 B1 Admin 中该周的当前计划。

## 入门

在您完成以下每一步之前，**屏幕**页面会显示一个带有每个步骤链接的**开始使用**清单：

1. **连接提供方** - 在**提供方**页面中链接 Dropbox、OneDrive、Lessons.church 或其他来源
2. **创建播放列表** - 从提供方中选择图片和视频
3. **排入日历** - 选择何时播放什么内容，或为该组设置默认循环
4. **配对屏幕** - 输入电视上显示的四位代码

点击**隐藏**可关闭该清单。

:::tip
按下 **Ctrl+K**（Mac 上为 **⌘K**），或点击页眉中的搜索框，即可打开命令面板。在这里您可以跳转到任意页面，或执行**配对屏幕**、**添加播放列表**或**添加排程**等操作。
:::
