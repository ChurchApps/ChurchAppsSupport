# 管理屏幕与群组

<div class="article-intro">

FreePlay Admin 中的**屏幕**页面会列出与您教会配对的每台电视，显示它当前正在播放的内容以及是否已为主日做好准备。您也可以在此管理**屏幕群组**。同一群组中的屏幕共享同一个日历和同一个默认循环播放列表。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 登录 FreePlay Admin：[admin.freeplay.church](https://admin.freeplay.church)
- [至少配对一台屏幕](./pairing-a-screen)

</div>

## 屏幕页面

页面顶部的三个数字可以让您快速了解整体状况：

- **当前在线** -- 在过去 15 分钟内有签到记录的屏幕
- **主日已就绪** -- 已预定的屏幕中，所有内容已下载至本周日的数量
- **需要关注** -- 离线或缺少文件的屏幕

在此下方，您可以使用**搜索屏幕**，按名称、群组或正在播放的内容查找屏幕。筛选标签可将列表缩小为**全部**、**已预定**、**手动**、**需要关注**或某个特定群组。通过右侧的切换开关，可以在**表格**和**网格**视图之间切换。

每台屏幕会显示以下信息：

- **名称**和设备型号
- **群组**
- **模式** -- **已预定**或**手动**
- **正在播放** -- 屏幕上当前正在播放的内容。手动屏幕会显示**课堂 · 教师按下开始**
- **就绪至** -- 屏幕已下载至的日期。如果文件未能下载完成，则会改为显示**N 个文件缺失**。新屏幕会显示**等待首次同步**
- **最后在线** -- 屏幕最后一次签到的时间。长时间未签到的屏幕会显示**离线**，从未连接过的屏幕则显示**从未在线**

使用**演示**可在浏览器中播放该屏幕的日历，使用**编辑**则可更改其设置。

## 查看屏幕

点击屏幕名称即可打开其页面。页面左侧有以下选项：

- **在浏览器中演示** -- 在浏览器中全屏播放该屏幕的日历，效果与电视上的显示一致。请参阅[从浏览器演示](./scheduled-playback#presenting-from-a-browser)
- **编辑** -- 更改名称、群组或模式
- **更多** > **取消配对** -- 断开电视连接，电视将重新显示配对码

页面其余部分包含以下区域：

- **当前与接下来** -- 当前正在播放的内容及其播放时间段，随后列出未来 7 天内预定的所有内容。点击**打开日历**可跳转到该群组的日历
- **下载** -- 所有内容均已下载完成时显示**就绪至**某日期，否则列出缺失的文件
- **设备** -- 设备 ID、平台、型号、FreePlay 应用版本、IP 地址、已用和可用存储空间、最后在线时间以及模式
- **最近** -- 该屏幕最近报告的活动记录

:::tip
如果屏幕显示缺少文件，请确认它处于在线状态且有可用存储空间。电视会在下次签到时自动下载缺失的文件。
:::

## 编辑屏幕

1. 点击屏幕旁的**编辑**，或在其页面上点击**编辑**。
2. 更改**名称**、**群组**或**模式**（**已预定**或**手动**）。
3. 点击**保存**。

将屏幕移动到其他群组后，它会切换为该群组的日历。

## 屏幕群组 {#screen-groups}

屏幕群组是一组同时播放相同内容的屏幕，例如"大厅"或"儿童区"。每个群组都有自己的日历，并可以设置**默认循环**，在没有预定内容时自动播放。

如需管理群组，请点击**屏幕**页面顶部的**群组**。**屏幕群组**列表会显示每个群组的名称、包含的屏幕数量以及默认循环播放列表。点击**屏幕**即可返回。

### 添加群组

1. 在**屏幕群组**视图中，点击**添加群组**。
2. 输入**名称**，例如"大厅"。
3. 选择**默认循环**播放列表，或保留为**无 -- 屏幕熄灭**。
4. 点击**保存**。

您也可以在配对屏幕时，通过在**群组**字段中选择**＋ 新建群组…**来创建群组。

### 编辑或删除群组

1. 点击群组旁的**编辑**。
2. 更改名称或默认循环，然后点击**保存**。
3. 如需删除群组，请点击**删除**并确认。

:::warning
删除群组也会删除其日程安排。该群组中的屏幕会熄灭，直到您将其移至其他群组为止。
:::
