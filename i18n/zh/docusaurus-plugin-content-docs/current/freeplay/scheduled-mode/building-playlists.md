# 连接提供商与构建播放列表

<div class="article-intro">

播放列表是一组循环播放的图片和视频，您可以将其放到日程表上。在 FreePlay Admin 中，您只需为整个教会连接一次内容提供商。然后，通过从这些提供商中选择文件来构建播放列表。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 登录 [admin.freeplay.church](https://admin.freeplay.church) 上的 FreePlay Admin
- 准备好您要关联的任何提供商账户的登录信息，例如 Dropbox 或 OneDrive

</div>

## 连接提供商 {#connecting-providers}

**Providers（提供商）** 页面将您的内容来源分为两个部分：

- **Connected（已连接）** —— 您可以立即使用的提供商。无需登录的公共提供商（例如 Lessons.church 和 Bible Project）始终显示在此处，并标注为 **Public · no sign-in needed（公共 · 无需登录）**。已关联的账户会显示 **Account linked（账户已关联）** 以及链接的到期时间。
- **Available（可用）** —— 需要您先登录才能使用的提供商。

连接提供商的步骤：

1. 进入 **Providers（提供商）**。
2. 在 **Available（可用）** 下找到该提供商，然后点击 **Connect（连接）**。
3. 使用该提供商的账户登录：
   - 部分提供商（例如 Dropbox、Google Drive 和 OneDrive）会打开登录弹窗。如果没有出现任何内容，请允许 admin.freeplay.church 弹出窗口。
   - 其他提供商会显示一个链接和一个代码。访问该链接，输入代码，然后批准访问。完成后，对话框会自动更新。
4. 当您看到 **Account linked successfully!（账户关联成功！）** 时，该提供商就会移至 **Connected（已连接）**。

已连接的提供商有三项操作：

- **Browse（浏览）** —— 浏览该提供商的文件夹
- **Refresh（刷新）** —— 续期该提供商的登录状态
- **Unlink（取消关联）** —— 断开账户连接

:::info
FreePlay Admin 中的提供商连接属于整个教会，而不属于某个人或某台电视。定时播放的屏幕通过这些连接获取文件，因此您无需在每台电视上分别登录各个提供商。
:::

**FreeShow** 显示为 **On your church network · each TV finds it itself（在教会网络中 · 每台电视自行查找）**。在 FreePlay Admin 中无需为它进行任何连接设置。

## 播放列表页面

**Playlists（播放列表）** 页面会列出每个播放列表，包括其项目数量、总时长、使用位置（小组的 **Default loop（默认循环）**，或日程数量），以及最后更新时间。每一行都有以下操作：

- **Present（演示）** —— 在浏览器中全屏播放该播放列表
- **Edit（编辑）** —— 打开播放列表编辑器
- **Duplicate（复制）** —— 创建一个名为"(copy)"的副本

## 创建播放列表

1. 进入 **Playlists（播放列表）**，然后点击 **Add playlist（添加播放列表）**。
2. 输入 **Name（名称）**，例如"欢迎循环"。
3. 点击 **Add playlist（添加播放列表）**。播放列表编辑器随即打开。

## 添加项目

播放列表编辑器的左侧显示播放列表的 **Items（项目）**，右侧为 **Add from provider（从提供商添加）**。

1. 在右侧选择一个提供商标签。若要添加其他来源，请点击 **Connect another（连接其他）**，这会打开 **Providers（提供商）** 页面。
2. 点击文件夹即可逐级进入。使用面包屑导航可返回上一级。
3. 点击某个文件，即可将其添加到播放列表末尾。已在播放列表中的文件会标记为已选中。
4. 若要一次性添加当前文件夹中的所有内容，请点击 **Add all（全部添加）**。该按钮会显示尚未加入播放列表的文件数量。
5. 点击编辑器顶部的 **Save（保存）**。

:::warning
只有点击 **Save（保存）** 后更改才会生效。若要不保存直接离开，请点击 **Cancel（取消）**。
:::

## 整理项目

在左侧的 **Items（项目）** 列表中：

- **重新排序** —— 通过左侧的拖动手柄拖动项目
- **图片时长** —— 图片默认显示 10 秒。您可以更改图片旁边的秒数
- **视频** —— 视频显示为 **Plays to end（播放至结束）**，并完整播放其全部时长
- **移除** —— 将项目从播放列表中移除

顶部的摘要会显示项目数量以及播放列表的总时长。

## 重命名、复制和删除

编辑器左侧的面板会显示该播放列表的使用位置。它还提供以下操作：

- **Present（演示）** —— 在浏览器中播放该播放列表
- **Rename（重命名）** —— 更改播放列表的名称
- **Duplicate（复制）** —— 创建一个副本，以便单独编辑
- **Delete（删除）** —— 删除该播放列表。播放它的日程将回退到小组的默认循环

## 在浏览器中演示播放列表

点击 **Present（演示）**，即可在浏览器中全屏播放该播放列表。这便于预览播放列表，或从连接到投影仪的笔记本电脑上运行。移动鼠标即可显示控制栏，然后使用以下按键：

| 按键 | 操作 |
|---|---|
| **空格** | 暂停或继续 |
| **←** / **→** | 上一项或下一项 |
| **F** | 切换全屏 |
| **Esc** | 退出 |
