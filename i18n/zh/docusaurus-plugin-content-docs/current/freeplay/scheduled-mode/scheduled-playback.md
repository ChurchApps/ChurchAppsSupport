# 电视上的定时播放

<div class="article-intro">

一旦电视与日历配对，FreePlay 就会为您运行它。它会下载未来一周的内容，在已排定的时间切换内容，并在网络中断时继续从自身存储中播放。教师或志愿者仍然可以使用电视遥控器暂停、跳过和跳转。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [将电视与日历配对](./pairing-a-screen)
- [在日历中添加内容](./scheduling-the-calendar)，或为该屏幕所在的组设置默认循环

</div>

## 电视自动执行的操作

- **直接打开日程** - 已配对的电视启动 FreePlay 时，会直接进入定时播放器
- **提前下载** - FreePlay 会下载未来 7 天内排定的所有文件以及默认循环，并从这些下载文件中播放
- **按时钟播放** - 在每个排定的开始时间，屏幕会切换到对应内容。没有排定内容时，则播放该组的默认循环
- **检查变更** - FreePlay 会定期检查 FreePlay Admin 中的日历变更，并下载任何新内容
- **修复损坏文件** - 如果某个已下载的文件无法播放，FreePlay 会跳过它并重新下载

在首批文件到达之前，屏幕会显示**正在加载日程...**或**正在下载 X / Y 个文件**。如果没有排定任何内容且该组没有默认循环，则会显示**当前没有排定内容**。

## 信息面板

在遥控器上按下**确认**即可打开信息面板。面板会在几秒钟后自动关闭。面板显示以下内容：

- **右上角** - 当截至某一日期的所有内容都已下载完成时，显示**已下载至**及该日期；文件仍在传输中时显示**下载中**。其下方为已下载的文件数量和进度条
- **左下角** - 正在播放的内容名称（或**默认循环**）、当前屏幕上的项目，以及接下来要播放的内容及其时间
- **上次检查** - FreePlay 上次检查日历变更的时间

该面板还包含三个按钮：

- **固定此播放列表** - 循环播放当前内容并忽略日历。选择**取消固定播放列表**即可恢复按日程播放
- **浏览内容** - 离开定时播放器，浏览您已连接的提供方
- **设置** - 打开 FreePlay 设置，您可以在其中[取消配对或与其他日历配对](./pairing-a-screen#changing-or-unpairing-from-the-tv)

:::tip
浏览内容后如需返回日程，请关闭并重新打开 FreePlay。已配对的电视始终会打开定时播放器。
:::

## 遥控器按键

| 遥控器按键 | 操作 |
|---|---|
| **确认** | 打开信息面板 |
| **播放/暂停** | 暂停或继续播放。暂停时会显示播放图标 |
| **右方向键** | 下一张幻灯片或视频 |
| **左方向键** | 上一张幻灯片或视频 |
| **上方向键** | 打开幻灯片概览，跳转到任意幻灯片 |
| **快进** | 视频快进 10 秒 |
| **快退** | 视频快退 10 秒 |
| **返回** | 关闭幻灯片概览或信息面板，或打开信息面板 |

下一项和上一项仅在当前正在播放的内容中切换。只有当日程设置为循环时，才会从最后一项回到第一项。快进和快退仅在播放视频时有效，在幻灯片上无效。

### 跳转到某张幻灯片

按下**上**键打开幻灯片概览。它会显示当前播放列表或课程中的每个项目。移动到您想要的项目，然后按下**确认**即可直接跳转。

## 教师控制的课程

当日程设置为**教师控制节奏**时，图片幻灯片不会自动切换。教师使用**右方向键**前进。视频会播放至结束，然后继续下一个项目。

教师控制节奏的课程会在排定的结束时间之后仍保持在屏幕上，直到教师翻到最后一张幻灯片且课程结束。然后屏幕才会切换到下一个排定内容。这样可以避免课程超时时，课堂内容被突然中断。

## 在浏览器中播放 {#presenting-from-a-browser}

您也可以在网页浏览器中播放屏幕的日历。在 FreePlay Admin 中，从**屏幕**页面打开该屏幕，然后点击**在浏览器中播放**。浏览器会与电视一样跟随该屏幕的日历，控制栏会显示接下来要播放的内容。使用**空格键**暂停，**←** / **→** 跳过，**F** 进入全屏，**Esc** 退出。
