# 电视上的定时播放

<div class="article-intro">

电视与日历配对后，FreePlay 会为你自动运行。它会提前下载未来一周的内容，在排定的时间切换播放内容；如果网络中断，它会从自身存储中继续播放。教师或志愿者仍可以用电视遥控器暂停、跳过和跳转。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [将电视与日历配对](./pairing-a-screen.md)
- [在日历中安排内容](./scheduling-the-calendar.md)，或为该屏幕所在的组设置默认循环播放

</div>

## 电视自动完成的工作

- **直接进入日程** —— 已配对的电视启动 FreePlay 时，会直接进入定时播放器
- **提前下载** —— FreePlay 会下载未来 7 天内所有已排期的文件，以及默认循环内容，并从这些下载的文件中播放
- **按时钟播放** —— 到达每个排定的开始时间时，屏幕会切换到该内容。若没有排期内容，则播放该组的默认循环内容
- **检查变更** —— FreePlay 会定期检查 FreePlay Admin 中的日历变更，并下载任何新内容
- **修复损坏文件** —— 如果某个已下载的文件无法播放，FreePlay 会跳过它并重新下载

在首批文件到达之前，屏幕会显示**正在加载日程…**或**正在下载 X / Y 个文件**。如果没有任何排期内容，且该组也没有默认循环内容，则会显示**当前没有排期内容**。

## 信息面板

按遥控器上的**确认**键即可打开信息面板。面板会在几秒后自动关闭。面板显示以下内容：

- **右上角** —— **Ready through**（已就绪至），后面跟着一个日期，表示截至该日期的所有内容均已下载；如果文件仍在下载中，则显示**正在下载**。其下方是已下载的文件数量以及进度条
- **左下角** —— 正在播放的内容名称（或**默认循环**）、当前屏幕上显示的项目，以及即将播放的下一项内容及其时间
- **Last checked**（上次检查）—— FreePlay 上次检查日程变更的时间

面板上还有三个按钮：

- **Pin This Playlist**（固定此播放列表）—— 让当前内容循环播放，并忽略日历。选择 **Unpin Playlist**（取消固定播放列表）即可恢复按日程播放
- **Browse Content**（浏览内容）—— 离开定时播放器，去浏览已连接的内容服务商
- **Settings**（设置）—— 打开 FreePlay 设置，你可以在那里[取消配对或与其他日历配对](./pairing-a-screen.md#changing-or-unpairing-from-the-tv)

:::tip
浏览内容之后，若要返回日程，可在 **Content Providers**（内容服务商）屏幕上按遥控器的**返回**键；或打开**设置**，选择**配对到日历**，然后选择**返回日程**。已配对的电视在 FreePlay 回到前台时也会返回定时播放器，而且每次启动都会直接进入定时播放器。
:::

## 遥控器操作

| 遥控器按钮 | 操作 |
|---|---|
| **确认** | 打开信息面板 |
| **播放/暂停** | 暂停或继续播放。暂停时会显示播放图标 |
| **右箭头** | 下一张幻灯片或下一个视频 |
| **左箭头** | 上一张幻灯片或上一个视频 |
| **上箭头** | 打开幻灯片总览，跳转到任意幻灯片 |
| **快进** | 在视频中前进 10 秒 |
| **快退** | 在视频中后退 10 秒 |
| **返回** | 关闭幻灯片总览或信息面板，或打开信息面板 |

"下一项"和"上一项"只会在当前正在播放的内容范围内切换。只有当日程设置为循环播放时，才会从最后一项回到第一项。快进和快退仅在播放视频时有效；在幻灯片上它们不起任何作用。

### 跳转到某张幻灯片

按**上**键打开幻灯片总览。它会显示当前播放列表或课程中的每一项内容。移动到你想要的项目，然后按**确认**键即可直接跳转到该项。

## 教师控制节奏的课程

当日程设置为**教师控制节奏**时，图片幻灯片不会自动翻页。教师通过**右箭头**向前推进。视频会播放到结束，然后转到下一项内容。

教师控制节奏的课程即使超过了排定的结束时间，也会保持在屏幕上，直到教师翻到最后一张幻灯片并完成播放。之后，屏幕才会切换到下一项排定内容。这样可以避免课程时间较长的班级在讲课中途被切断。

## 通过浏览器播放 {#presenting-from-a-browser}

你也可以在网页浏览器中播放屏幕的日历。在 FreePlay Admin 中，从**屏幕**页面打开该屏幕，然后点击**在浏览器中播放**。浏览器会以与电视相同的方式跟随该屏幕的日历，并且控制栏会显示即将播放的下一项内容。使用**空格键**暂停，**←** / **→** 切换内容，**F** 键进入全屏，**Esc** 键退出。
