# 在 WorshipCommons 上分享诗歌

<div class="article-intro">

如果您创作了一首诗歌，并希望教会可以自由地演唱它，您可以将它分享到 WorshipCommons。您也可以分享资料库中已有诗歌的译本或编曲。每首诗歌在上线前都会由工作人员人工审阅，通常在几天之内完成。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 登录 WorshipCommons。请参阅[您的账户和词曲作者页面](./your-account.md)。
- 您必须年满 18 岁，并且必须是该诗歌的创作者或拥有其版权。每位合作词曲作者都必须以书面形式同意。
- 请准备好歌词，并至少准备一种让教会学习旋律的方式：示范录音（手机录音即可）、乐谱、MIDI 文件或视频链接。

</div>

## 开始提交

1. 点击顶部菜单中的**词曲作者专区**。
2. 按照页面上的四个步骤操作：**诗歌**、**文件**、**授权**和**您的声明**。点击顶部的步骤名称可直接跳转到对应步骤。

诗歌一旦有了标题，您的内容就会自动保存为草稿，请留意表单顶部的**草稿已保存**提示。您之后可以从**我的提交**中点击**继续**，返回编辑。

:::info
如果词曲作者希望在不上传诗歌的情况下发布它，可以从**征集诗歌**页面复制发布声明（该链接位于每个页面的底部）。
:::

## 第一步：诗歌

1. 在**您要添加的是什么？**下，选择**新诗歌**、**现有诗歌的译本**或**现有诗歌的编曲**。
2. 输入**标题**。
3. 在**词曲作者**中，请按照和弦谱上应显示的方式，逐一输入每位合作词曲作者的名字。
4. 填写**创作年份**、**原始调性**和**速度（BPM）**。在您自行选择之前，系统会根据您输入的第一个和弦判断调性。
5. 点击符合的**主题**。若要查看完整列表，请点击**更多主题**。
6. 选择诗歌的**语言**；如果诗歌基于某段经文，请添加**经文出处**（例如：以赛亚书 40:4）。教会会在诗歌页面上看到该经文。
7. 如果教会已向 CCLI 申报过此诗歌，请填写**CCLI 编号（可选）**，这样对教会而言不会有任何变化。
8. 将歌词粘贴到**歌词与和弦**中，每次一个段落，每段以其名称开头（如：第一段、副歌等）。和弦是可选的，请将其放在音节之前的方括号中，例如 `[G]Holy, holy`。您也可以点击**从 ChordPro 或文本文件载入**。

**谱面预览**会显示教会看到您诗歌的确切样式，任何问题都会列在下方。

:::warning
如果您的诗歌看起来与资料库中已有的诗歌相同，您会看到一条附有链接的警告。如果确实是同一首诗歌，请打开它并提出编辑建议，而不是上传副本。
:::

### 分享译本或编曲

当您选择**现有诗歌的译本**或**现有诗歌的编曲**时：

1. 在**原始诗歌**下，按标题搜索资料库，并从列表中选择原作。
2. 若为译本，请填写**译者**，并选择诗歌的新**语言**（必须与原作不同）。若为编曲，请填写**编曲者**。
3. 照常完成该步骤的其余部分。编曲会自动带入原作的标题、词曲作者和调性。

WorshipCommons 会将两个诗歌页面双向互相链接。由于原作已包含曲调，因此文件为可选项。

:::info
某些授权不允许制作译本或编曲。这些诗歌在列表中会显示为不可用，并标明需要词曲作者的许可。如果您自行发布了原作，仍可以新增其译本。
:::

## 第二步：文件

将文件拖放到方框中，或点击方框选择文件。每个方框都会列出可接受的文件类型及其大小限制。

- **示范录音** -- MP3、WAV 或 M4A
- **伴奏音轨** -- 不含主唱的音乐
- **乐谱** -- 以 PDF 或 MusicXML 格式提供的主旋律谱或声乐谱
- **MIDI 旋律** -- 教会可在浏览器中以钢琴音色预听
- **分轨** -- 包含各声部音轨的 ZIP 压缩包，每个声部一个文件，且均从第 1 小节开始
- **封面图片** -- JPG、PNG 或 WebP
- **视频链接** -- YouTube（或其他平台）的网址，供教会聆听该诗歌

如果您上传了录音，请勾选**此录音为我本人所有（或我已获得拥有者的许可进行分享）。**

## 第三步：授权

首先选择您要授予的内容：仅**词曲**，还是**词曲及母带录音**。

接着选择**词曲授权**。每个选项都会让该诗歌永久免费供敬拜使用，差别在于您保留哪些权利：

- **免费供敬拜使用**（建议）-- 教会可以演唱、投影、印刷、串流、转调、编曲和翻译该诗歌。您保留录音与乐谱销售、影音同步、音乐会、广播以及诗歌的所有权。
- **CC BY 4.0** -- 任何人均可将其用于任何用途（包括商业用途），但须注明您的署名。
- **公共领域** -- 任何人均可将其用于任何用途。您不保留任何权利（为永久的 CC0 献予公众声明）。

若要完整阅读授权条款，请点击某选项下方的**阅读授权条款。**

如果您同时提供母带录音，会出现**母带录音**步骤。请上传完成的混音版本并选择其专属授权，该授权可以与词曲的授权不同。

## 第四步：您的声明

请阅读摘要，然后勾选每个方框，以确认：您年满 18 岁；您是该诗歌的创作者（或拥有其版权）；每位合作词曲作者都已同意；没有任何出版商或版权协会剥夺您作出此授权的权利；您了解供敬拜使用的授权是永久的；以及歌词和旋律均由人类创作，并非由 AI 生成。

:::warning
即使您日后要求下架该诗歌，教会仍可能保留每一份副本。请只分享您已准备好永久交给教会的诗歌。
:::

## 提交审核

1. 点击**加入公共资源库**。如果有任何缺失项目，按钮上方会出现一份列表，点击其中任一项目即可跳转至该处。
2. 等待出现**感谢您，已进入审核阶段**。

您可以在**我的提交**中追踪该诗歌。如果审核人员要求修改，其状态会变为**需要修改**，您点击**继续**时，审核人员的备注会显示在表单顶部。获准后，状态会显示为**已上线**。
