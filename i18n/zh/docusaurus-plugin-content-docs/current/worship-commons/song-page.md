# WorshipCommons 歌曲页面

<div class="article-intro">

WorshipCommons 上的每首歌曲都有自己的页面，其中包括歌词和和弦、试听旋律的方式、练习工具、可打印的乐谱以及下载内容。除了将歌曲保存到您的账户外，本页面上的所有功能都无需登录即可使用。

</div>

## 页面顶部

页面顶部显示歌曲的封面、标题、第一句歌词、词曲作者和年份，如果有赞美诗曲调名称，也会显示在这里。在此之下，您会看到：

- **授权标签** -- 例如 **公有领域**、**WC**（可免费用于敬拜）或知识共享标签，如 **CC BY**。
- **主题和格律** -- 点击主题或格律标签，即可找到具有相同标签的其他歌曲。
- **调性、BPM、拍号和预计演唱时长**，如果歌曲有推荐调性，还会显示**推荐调性**。

页面右侧是主要操作按钮：

- **带领敬拜** -- 打开全屏的跟唱歌词视图，并伴有音乐。请参阅[展示与导出歌曲](./presenting-and-exporting.md)。
- **+ 添加到事工计划** -- 将歌曲以当前屏幕上显示的调性添加到您的某个[事工计划](./service-plans.md)中。
- **心形图标（收藏歌曲）** -- 将歌曲保存到您的账户。系统会先要求您登录。
- **词曲作者页面** -- 当作者添加了教会可借以支持其创作的链接时显示。

点击作者姓名即可打开其[作者页面](./your-account.md#writer-pages)，其中列出了该作者在曲库中的所有歌曲。

## 试听歌曲

当歌曲有音频时，标题下方会出现播放条。点击播放按钮即可收听。

- 如果作者分享了录音，您将听到**示范录音**或**母带录音**。
- 否则，您将听到**钢琴预览** -- 由钢琴演奏旋律文件。钢琴预览会跟随您在页面上选择的调性，让您听到的就是您演唱时的调性。

## 和弦与歌词

**和弦与歌词**标签页显示乐谱。使用其上方的工具栏为您的团队进行设置：

1. **调性** -- 选择新的调性，所有和弦都会随之转调。原始调性会标记为**（原调）**。
2. **变调夹** -- 选择变调夹的品位。乐谱会显示需要弹奏的和弦指法（例如 **2 — C 指法**），而歌曲仍以您选择的调性发声。
3. **移调** -- 点击 **−** 或 **+**，每次将调性降低或升高半音。
4. **显示** -- 关闭**和弦**，仅显示歌词；或开启**纳什维尔数字谱**，以数字显示和弦。
5. **字号**和**分栏** -- 放大文字，或将乐谱以两栏显示。

将鼠标悬停在任何和弦上或点击和弦，即可查看在吉他和钢琴上的弹奏方法。对于较长的歌曲，可使用**跳转至**按钮，直接滚动到某段主歌或副歌。

:::info
只有歌词的歌曲不会显示调性、变调夹或和弦控件，因为没有和弦可供更改。
:::

在乐谱下方，您会找到：

- **打印 / PDF** -- 以您选择的调性、变调夹和和弦设置打开可打印的乐谱。在该页面上，选择**字号**（包括**大字体**），选择**两栏**或**显示和弦**，然后点击**打印**。使用浏览器的打印对话框即可将其保存为 PDF。
- **ChordPro** 和 **歌词（TXT）** -- 将歌曲下载为 ChordPro 文件或纯文本。
- **复制歌词** -- 将歌词（不含和弦）复制到剪贴板。
- **乐谱 PDF** -- 当歌曲有现成的乐谱 PDF 时显示。

页面底部的一行文字会告诉您该歌曲是否需要向 CCLI 报告。WorshipCommons 上的大多数歌曲都不需要。

## 五线谱

有乐谱的歌曲会显示**五线谱**标签页。其中以您选择的调性显示旋律。点击**完整乐谱（所有声部）→**即可打开完整乐谱，您可以在其中选择**调性**和**声部**，然后点击**打印**。如果作者上传了五线谱 PDF，也会显示在此处，并附有**打开全尺寸 →**和**下载 PDF**链接。

## 关于与版权

**关于与版权**标签页回答“这首歌从哪里来，我们可以使用吗？”它显示：

- 作者、歌曲的经文出处、主题和格律
- **用其他曲调演唱** -- 同一格律的其他赞美诗曲调
- **贡献者与修改** -- 参与该歌曲创作的人员以及已获批准的修改
- **版权** -- 授权允许您做什么、不允许做什么以及您必须做什么，并提供**复制署名**按钮，用于复制可用于周报或幻灯片的署名文字

## 练习工具

**练习**面板可帮助您的团队排练：

- **速度** -- 使用滑块或 **−** 和 **+** 按钮，将音乐放慢或加快（50%–150%）。
- **练习声部** -- 当音乐有多个声部（例如女高音、女中音、男高音和男低音）时，点击某个声部可单独听它，或点击**全部**一起听。
- **节拍器** -- 点击**▶ 节拍器**，以当前速度听到节拍声。
- **播放音符** -- 播放页面所选调性的起始音，方便您为全场定音。

## 下载与投影

**下载**面板始终提供当前调性和变调夹下的**和弦谱（打印版）**。根据作者分享的内容，您还可能看到**创作素材包**、**音频素材包**或**多轨音频（ZIP）**。

**投影**面板会打开歌词投影器并导出幻灯片。请参阅[展示与导出歌曲](./presenting-and-exporting.md)。

## 经文、相关歌曲与译本

在页面底部：

- **经文关联** -- 显示歌曲的经文出处，并附上世界英文圣经（World English Bible）中的经文内容。如果歌曲尚未有出处，请点击**提议一个 →**来建议出处。
- **相关歌曲** -- 同一语言的其他版本，以及标题相似的歌曲。
- **译本** -- 该歌曲的其他语言版本。点击**添加一个 →**即可分享译本（请参阅[分享歌曲](./sharing-a-song.md)）。如果歌曲的授权不允许翻译，您将看到**翻译需要作者许可。**
