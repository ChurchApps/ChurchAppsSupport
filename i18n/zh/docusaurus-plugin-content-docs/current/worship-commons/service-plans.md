# WorshipCommons 服务单

<div class="article-intro">

WorshipCommons 上的服务单就是周日的歌单。按顺序排列歌曲，为每首歌选择调式、变调夹和分段，然后与乐队共享同一个链接。在服务单中，您可以打开适合乐谱架的舞台视图、打印小册子，或将整套歌曲导出到演示软件。

</div>

:::info
服务单保存在您的网页浏览器中，而不是您的账户里，使用时无需登录。共享链接包含整套歌曲，因此如果您要换设备，请保存好该链接。如果您的教会在 B1 Admin 中规划服务，请改为参阅[计划](../b1-admin/serving/plans.md)。
:::

## 创建服务单

1. 点击顶部菜单中的**服务单**。
2. 输入名称，例如「9 月 14 日主日」或「青年夜」，然后点击**创建服务单**。

您也可以从任意歌曲开始创建服务单。在歌曲页面上，点击**+ 添加到服务单**，在列表下方输入名称，然后点击**创建**。

## 添加歌曲

1. 打开歌曲页面。请先设定所需的调式，因为歌曲会以屏幕上显示的调式加入服务单。
2. 点击**+ 添加到服务单**。
3. 点击服务单的名称。出现对勾表示该歌曲已在此服务单中。再次点击即可将其移除。

此时按钮会显示**✓ 已加入**，后面接服务单的名称。在弹出窗口中点击带有服务单名称的**打开**链接，即可前往该服务单。

## 编排歌单

从**服务单**页面打开服务单。对于每首歌曲，您可以：

- **调整顺序**——使用 **↑** 和 **↓** 按钮，或将歌曲拖动到新位置。点击**移除**即可将其删除。
- **调式**——从歌曲的**已发布**调式中选择，或选择其他任意调式（列于**预览（任意调式）**下）。
- **变调夹**——选择变调夹的品位。服务单会显示应使用的和弦指法。
- **分段**——设定主歌与副歌的顺序。使用箭头移动某个分段，点击 **×** 删除，点击 **+ 添加分段** 增加分段（例如重复的副歌）。点击**恢复默认**即可回到歌曲原本的顺序。
- **编曲**——为乐队输入简短的备注，例如「结尾副歌唱两遍，最后一段主歌清唱」。

服务单顶部会显示歌曲数量和整套歌曲的大约时长。所有更改都会自动保存。

## 与团队共享

1. 点击**共享链接**，链接会被复制到剪贴板。
2. 通过短信或电子邮件发送给乐队。

任何打开该链接的人都能看到包含所有调式、变调夹、分段和备注的服务单，无需账户。他们也可以点击**保存副本**，在自己的浏览器中保留一份可编辑的副本。

在**服务单**页面上，您还可以对服务单进行**共享**、**重命名**、**复制**或**删除**操作。

## 周日使用服务单

- **舞台模式**——每个屏幕显示一份乐谱，适合放在乐谱架上的平板电脑。使用箭头（或 **←** 和 **→** 键）在歌曲之间切换，并使用字号按钮放大乐谱。舞台模式会尽量防止屏幕自动休眠；状态栏会显示是否处于**保持屏幕常亮**状态。
- **打印小册子**——按顺序打印每份乐谱，每页一首，封面列出歌曲和调式。选择**大字体**或**显示和弦**，然后点击**打印**。
- **复制到 OnSong / Planning Center**——按您选择的调式和分段复制每份乐谱，可直接粘贴使用。

## 导出歌单

点击 **FreeShow**、**OpenLP**、**ProPresenter** 或 **PowerPoint**，即可按您选择的调式和分段，下载适用于该工具的整套歌曲。

点击**家庭教会合集**，即可下载一个 ZIP 文件，其中包含每首歌以您的调式呈现的乐谱、歌词、幻灯片、版权署名、歌单，以及一个 LICENSE.txt 文件。

:::warning
除非您勾选**相同方式共享合集（包含 CC BY-SA 歌曲）**，否则采用 CC BY-SA 授权的歌曲不会包含在家庭教会合集中。如果您选择包含这些歌曲，则由该合集制作的任何作品都必须以相同的授权条款共享。乐谱、舞台模式和小册子始终包含这些歌曲。
:::
