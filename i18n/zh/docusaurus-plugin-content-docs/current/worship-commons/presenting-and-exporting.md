# 展示与导出 WorshipCommons 歌曲

<div class="article-intro">

WorshipCommons 无需安装任何软件，就能直接在浏览器中把歌曲歌词显示在屏幕上。如果您的教会已经在使用演示软件，可以改为下载歌曲的幻灯片，用于 FreeShow、OpenLP、ProPresenter 或 PowerPoint，或者将歌曲添加到您的 B1 Admin 歌曲库中。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在 [worshipcommons.org](https://worshipcommons.org) 打开歌曲页面。请参阅[查找歌曲](./finding-songs.md)。
- 如要在电视或投影仪上显示歌词，请用 HDMI 线将电脑连接到显示设备（或使用投屏功能）。

</div>

## 在浏览器中带领敬拜

**带领敬拜**是一种全屏视图，会播放音乐，并逐行显示歌词，演唱到哪个字就高亮哪个字。它适用于小组、课堂或没有乐队的家庭教会。

1. 在歌曲页面上，点击 **带领敬拜**。（只有当歌曲带有可供伴奏的音乐时，此按钮才会出现。）
2. 选择 **调性**和**速度**。如果歌曲提供钢琴试听，您可以选择 **钢琴**或**风琴**。
3. 点击 **段落**，选择要演唱的段落，并使用箭头按钮调整段落顺序。
4. 如果希望音乐开始前有一个预备拍，请打开 **预备拍**。
5. 点击 **▶ 播放**。

使用 **空白**可隐藏歌词，使用 **高对比**切换为高对比度屏幕，使用 **全屏**填满整个屏幕。点击 **投放到电视**可查看在电视上显示的快速步骤。

:::tip
键盘快捷键：**空格键**播放/暂停，**← →**移动一行，**↑ ↓**切换段落，**B**空白，**H**高对比，**F**全屏，**Esc**返回歌曲页面。点击屏幕底部的**显示快捷键**即可查看全部快捷键。
:::

## 投影歌词

**打开投影**每屏显示一段歌词，您需要手动翻页。如果有现场乐手演奏，请使用此功能。

1. 在歌曲页面上找到 **投影**面板，然后点击 **打开投影**。
2. 按 **F** 或点击 **全屏**，使画面填满屏幕。
3. 点击屏幕，或按**空格键**或 **→** 键，进入下一张幻灯片。按 **←** 返回上一张。点击底部的段落名称，即可直接跳转到该段落。
4. 按 **B** 使屏幕空白，按 **H** 切换为高对比。
5. 完成后，按 **Esc**（或点击 **← 返回歌曲**）。

底部栏会显示当前段落、幻灯片总数以及下一张内容。歌曲的署名信息也会显示在屏幕上。

## 导出幻灯片

歌曲页面上的**投影**面板为每种工具提供了一个按钮。点击某个按钮即可下载该歌曲：

| 按钮 | 您将获得 |
| --- | --- |
| **FreeShow** | 可导入 [FreeShow](https://freeshow.app) 的演示文件 |
| **PowerPoint** | PPTX 幻灯片文件 |
| **OpenLP** | 可导入 OpenLP 的 OpenLyrics 文件 |
| **ProPresenter** | 可导入 ProPresenter 的文本文件 |
| **OnSong / PCO** | 将歌曲复制到剪贴板，以便粘贴到 OnSong 或 Planning Center 中 |

按钮下方的说明会告诉您幻灯片的分页方式。如果歌曲有已批准的段落结构图，幻灯片会按照该结构分页；否则，幻灯片会按照歌词原有的段落分页。每次导出都会包含歌曲的署名和授权信息。

:::tip
如要一次导出整套歌曲（采用您所选的调性和段落），请先创建一份[服事计划](./service-plans.md)，然后在其中使用导出按钮。
:::

## 将 WorshipCommons 歌曲添加到 B1

如果您的教会在 B1 Admin 中安排礼拜，就无需下载任何文件。WorshipCommons 中适合主日使用的歌曲会出现在 B1 Admin 的歌曲搜索结果中，位于 **WorshipCommons — 免费**分类下。点击某首歌曲，即可将其添加到您的歌曲库中，并链接回它在 WorshipCommons 上的页面。

具体步骤请参阅 [B1 Admin 中的歌曲](../b1-admin/serving/songs.md#free-songs-from-worshipcommons)。
