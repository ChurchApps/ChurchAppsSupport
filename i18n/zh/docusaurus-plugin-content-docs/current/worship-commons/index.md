# WorshipCommons 概览

<div class="article-intro">

WorshipCommons 是一个为教会提供的免费开放敬拜歌曲库。其中收录了公有领域的赞美诗和歌曲，以及作者选择公开分享的作品。每首歌曲都附有歌词、可转换到任意调的和弦谱，以及用于主日崇拜的幻灯片。访问 [worshipcommons.org](https://worshipcommons.org)，即可查找歌曲、更改调性、打印和弦谱，并将歌词投放到屏幕上。

</div>

WorshipCommons 面向需要无额外费用即可使用歌曲的敬拜领袖、音乐人和技术志愿者，也面向希望将作品赠予教会的词曲作者。浏览、演奏、打印和投影歌曲都无需账户。免费的 ChurchApps 账户则让你可以保存歌曲，并分享自己的作品。

:::info
教会可以如何使用某首歌曲，取决于该曲的授权条款。公有领域的赞美诗在美国可用于任何用途（尽力确保准确，其他国家的情况可能有所不同）。根据 WorshipCommons 授权条款分享的歌曲可免费用于敬拜，作者保留商业使用权。打开歌曲的 **About & rights** 标签页，即可查看其允许的具体用途。对于你在敬拜中演唱的其他歌曲，WorshipCommons 并不能替代你的 CCLI 授权。
:::

## 主要功能

- **搜索与筛选** -- 可按标题、首行歌词、曲调、主题、经文或作者搜索，并可按调性、速度、语言、授权方式等进行筛选。请参阅[查找歌曲](./finding-songs.md)。
- **任意调的和弦谱** -- 可转调、设置变调夹、切换为纳什维尔数字谱，点击和弦即可查看吉他和钢琴的指法。请参阅[歌曲页面](./song-page.md)。
- **聆听歌曲** -- 播放示范录音或钢琴预览，放慢速度，并配合节拍器练习。
- **打印与下载** -- 打印符合你调性的和弦谱，或在歌曲提供时下载 ChordPro、歌词、乐谱和音频包。
- **领唱与投影** -- 在浏览器标签页中领唱，歌词会随音乐同步滚动，也可以打开简易的歌词投影器。请参阅[演示与导出歌曲](./presenting-and-exporting.md)。
- **导出** -- 下载适用于 FreeShow、OpenLP、ProPresenter 或 PowerPoint 的幻灯片，或复制歌曲以用于 OnSong 或 Planning Center。B1 Admin 可以直接将 WorshipCommons 歌曲添加到你的歌曲库中。
- **崇拜流程安排** -- 为主日规划一组歌曲，为每首歌选择调性和段落，并与乐队分享一个链接。请参阅[崇拜流程](./service-plans.md)。
- **分享你的歌曲** -- 上传你创作、翻译或编曲的歌曲，并选择授权方式。请参阅[分享歌曲](./sharing-a-song.md)。
- **社区编辑** -- 任何登录用户都可以提出修改建议，由审核人员决定是否采纳。请参阅[提出编辑建议与举报歌曲](./proposing-edits.md)。
- **作者页面** -- 每位作者都会获得一个页面，列出其作品，并可选择添加简介和链接。请参阅[你的账户与作者页面](./your-account.md)。
