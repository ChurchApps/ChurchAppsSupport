# 你的 WorshipCommons 账户与作者页面

<div class="article-intro">

无需账户，你也可以在 WorshipCommons 上浏览、播放、打印和投影歌曲。免费账户可以让你保存歌曲、分享自己的歌曲、提出编辑建议，并追踪你提交过的所有内容。如果你是词曲作者，账户还可以让你编辑教会看到的作者页面。

</div>

## 登录或创建账户

WorshipCommons 使用 ChurchApps 账户。如果你已有账户（例如来自 B1），可以使用相同的电子邮件和密码登录。

1. 点击顶部菜单中的 **Sign in**（登录）。
2. 输入你的 **Email**（电子邮件）和 **Password**（密码），然后点击 **Sign in**（登录）。

**创建账户：**

1. 在登录页面，点击 **Create an account**（创建账户）。
2. 输入你的 **First name**（名字）、**Last name**（姓氏）和 **Email**（电子邮件），然后点击 **Create account**（创建账户）。
3. 查看你的电子邮件，找到 6 位验证码，输入后点击 **Verify code**（验证验证码）。
4. 选择至少 8 个字符的密码，在 **Verify password**（确认密码）下再次输入，然后点击 **Set password & sign in**（设置密码并登录）。

**忘记密码？** 在登录页面点击 **Forgot password?**（忘记密码？），输入你的电子邮件，然后点击 **Send code**（发送验证码）。接着输入邮件中的验证码，并设置新密码。

登录后，你的名字会显示在顶部菜单中。点击它可以打开 **My submissions**（我的提交）或 **Report**（报告），也可以 **Sign out**（退出登录）。

## 已保存的歌曲

在任何歌曲页面点击心形图标即可保存该歌曲。点击顶部菜单中的 **Saved songs**（已保存的歌曲），可以查看你保存的所有歌曲。已保存的歌曲存储在你的账户中，因此在你登录的每台设备上都能看到。点击 **Remove**（移除）可将歌曲从列表中删除。

:::tip
已保存的歌曲只是一个简单的收藏列表。如果要为某个特定的主日规划诗歌单，包括调性和段落，请使用[服事计划](./service-plans.md)。
:::

## 我的提交

点击顶部菜单中的你的名字，然后选择 **My submissions**（我的提交），即可查看你开始或发送过的所有歌曲和修改，以及每项内容目前的状态。使用顶部的标签——**All**（全部）、**Drafts**（草稿）、**In review**（审核中）、**Live**（已上线）和 **Not accepted**（未通过）——来筛选列表。

每个条目都会显示其类型（例如 **New song**（新歌）、**Translation**（翻译）、**Arrangement**（编曲）、**Correction**（更正）或 **Removal request**（下架申请））以及状态：

| 状态 | 含义 |
| --- | --- |
| **Draft**（草稿） | 已开始但尚未发送。点击 **Continue**（继续）完成它，或点击 **Delete draft**（删除草稿）将其移除。 |
| **Changes requested**（需要修改） | 审核人员要求修改。点击 **Continue**（继续），完成修改后重新发送。 |
| **In review**（审核中） | 每首歌曲在上线前都会由专人审阅，通常在几天内完成。点击 **Withdraw**（撤回）可将其退回草稿。 |
| **Live**（已上线） | 已收录在曲库中，教会可以免费使用。你可以看到它的下载次数和链接。 |
| **Not accepted**（未通过） | 未能收录进曲库。会显示审核人员的原因。 |
| **Withdrawn**（已撤回） | 你在审核前将其撤回。 |
| **Taken down**（已下架） | 应你的要求，该歌曲已从曲库中移除。 |

对于已上线的歌曲，点击 **Copy link**（复制链接）可分享其页面，点击 **Propose a change**（提议修改）可提交编辑，或点击 **Request removal**（申请下架）请求将其下架。请参阅[提议编辑与举报歌曲](./proposing-edits.md)。

:::info
如果 WorshipCommons 团队将你添加为某首歌曲的共同发布者（例如，你与他人共同创作、但由别人上传的歌曲），该歌曲会以 **Live**（已上线）的状态出现在你的 **My submissions**（我的提交）中，即使你并未亲自提交。作为该歌曲的发布者，即使其授权设置为不接受公开编辑，你仍可以进行修改。
:::

## 作者页面

曲库中的每位作者都有一个作者页面，列出其所有歌曲，并显示每首歌曲的年份、调性、主题和授权方式。教会可以点击歌曲页面上的作者姓名进入该页面。当一首歌曲有多位作者时，每个名字都会链接到各自的页面。

作者页面还可以显示肖像、简短简介、链接，以及支持链接，让教会可以支持作者的其他事工。

### 编辑你的作者页面

当你的一首歌曲上线，并且署名为你本人时，你就会拥有一个作者页面。

1. 点击顶部菜单中的你的名字，然后选择 **My submissions**（我的提交）。
2. 点击 **Writer profile**（作者资料）。
3. 在 **About you**（关于你）下，写几句话介绍你是谁以及你创作的歌曲（最多 2,000 个字符）。
4. 在 **Links**（链接）下，最多添加五个链接，例如你的网站。为每个链接填写 **Label**（标签）及其网址。点击 **Add a link**（添加链接）可增加一行。
5. 在 **Support links**（支持链接）下，添加教会可以支持你工作的地方，例如商店或事工页面。点击 **Add a support link**（添加支持链接）可增加一行。
6. 点击 **Save profile**（保存资料）。

点击 **View your writer page**（查看你的作者页面）即可以教会看到的方式预览。你的支持链接也会以 **Songwriter's page**（词曲作者页面）按钮的形式出现在你每首歌曲的页面上。

:::tip
你与他人共同创作了歌曲，或者已有一个未关联到你账户的作者页面？请发送电子邮件至 [support@churchapps.org](mailto:support@churchapps.org)，并请求将其关联到你的账户。
:::
