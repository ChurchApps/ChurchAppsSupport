# B1 Church Checkin 概览

<div class="article-intro">

B1 Church Checkin 是 iPad 和 Android 平板的自助服务亭应用。它让教会成员可以查找他们的家庭、为孩子分配小组或班级以及打印名牌和家长接送单 -- 所有这些都无需大堂的志愿者。

</div>

## 它的工作方式

将 iPad 或 Android 平板放在您的大堂或欢迎区。成员走上前，通过电话号码或姓氏搜索他们的家庭，查看他们的家人，选择每个人应该参加哪些小组，然后点击**签到**。应用会自动打印名牌和接送单，然后为下一个家庭重置。

## 关键功能

- **自助成员查找** -- 通过电话号码或姓氏搜索来快速找到您的家庭。
- **家庭查看** -- 一目了然地看到所有家庭成员及其照片和当前小组分配。
- **小组分配** -- 为每个家庭成员分配到为选定服务时间选择的正确班级或小组。
- **访客签到** -- 在签到时将访客添加到您的家庭，仅需名字和姓氏。
- **QR 访客注册** -- 显示一个 QR 码，访客可以扫描以在签到前在自己的手机上[自己注册](../b1-church/checkin/guest-registration)。
- **标签打印** -- 为儿童打印名牌，为家长打印带有唯一安全代码的接送单。
- **网络打印机支持** -- 直接从应用发现并配置网络打印机。
- **自动登录** -- 首次登录后，应用记住您的凭据，未来启动时直接转到服务屏幕。
- **多教会支持** -- 如果您的帐户链接到多个教会，您可以选择要签到哪个。
- **教会品牌** -- 选择教会后，应用在标头中显示您的教会徽标。
