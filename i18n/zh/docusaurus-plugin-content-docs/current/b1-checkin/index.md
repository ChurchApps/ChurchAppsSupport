# B1 Church Checkin 概览

<div class="article-intro">

B1 Church Checkin 是一款适用于 iPad 和 Android 平板电脑的自助服务终端应用。它让教会成员可以查找其家庭信息、为儿童分配小组或班级，并打印姓名标签和家长接送单 -- 全程无需志愿者在服务台协助。

</div>

## 工作原理

将 iPad 或 Android 平板电脑放置在教会大厅或迎宾区。成员走上前，通过电话号码或姓氏搜索其家庭，查看家人信息，为每个人选择应参加的小组，然后点击**签到**。应用会自动打印姓名标签和接送单，然后为下一个家庭重置。

## 主要功能

- **自助成员查询** -- 通过电话号码或姓氏快速查找您的家庭。
- **家庭检查** -- 一目了然地查看所有家庭成员的照片和当前小组分配。
- **小组分配** -- 为所选礼拜时间为每位家庭成员分配合适的班级或小组。
- **访客签到** -- 现场为访客添加名字和姓氏，将其加入您的家庭。
- **二维码访客登记** -- 显示一个二维码，访客可扫描后在自己的手机上[完成登记](../b1-church/checkin/guest-registration)，然后再签到；或让他们点击**在此登记**，在自助终端上填写相同的表单。
- **标签打印** -- 为儿童打印带有唯一安全码的姓名标签和家长接送单。
- **网络打印机支持** -- 直接从应用中发现并配置网络打印机。
- **自动登录** -- 首次登录后，应用会记住您的凭据，并在之后的启动中直接进入服务屏幕。
- **多教会支持** -- 如果您的账户关联了多个教会，您可以选择要签到的教会。
- **教会品牌** -- 选择教会后，应用会在页眉中显示您教会的标志。
