# B1 Church 签到概览

<div class="article-intro">

B1 Church 签到是一个自助式自助服务亭应用，适用于 iPad 和 Android 平板电脑。它让教会成员查询他们的家庭、将儿童分配给小组或班级、打印姓名标签和家长接送单 -- 所有这些都无需在服务台需要志愿者。

</div>

## 工作原理

在您的大厅或欢迎区放置一台 iPad 或 Android 平板电脑。成员走过来，按电话号码或姓氏搜索他们的家庭，审查他们的家人，选择每个人应该参加哪些小组，然后点击 **签到**。该应用会自动打印姓名标签和接送单，然后为下一个家庭重置。

## 主要功能

- **自助式会员查询** -- 按电话号码或姓氏搜索快速查找您的家庭。
- **家庭审查** -- 一目了然地看到所有家庭成员的照片和当前小组分配。
- **小组分配** -- 将每个家庭成员分配给所选服务时间的正确班级或小组。
- **访客签到** -- 使用名字和姓氏临时将访客添加到您的家庭。
- **二维码访客注册** -- 显示一个二维码，访客可以扫描以 [自行注册](../b1-church/checkin/guest-registration) 在他们自己的手机上签到前，或让他们点击 **在此注册** 在自助服务亭上填写相同的表单。
- **标签打印** -- 为儿童打印姓名标签和带有唯一安全代码的家长接送单。
- **网络打印机支持** -- 直接从应用中发现和配置网络打印机。
- **自动登录** -- 首次登录后，该应用会记住您的凭据，并在将来启动时直接进入服务屏幕。
- **多教会支持** -- 如果您的账户链接到多个教会，您可以选择登录哪一个。
- **教会品牌** -- 选择教会后，应用会在标题中显示您的教会徽标。

:::
