# 添加访客 {#adding-guests}

<div class="article-intro">

如果有人正在拜访你的家庭并需要与你的家庭一起签到，你可以直接在登记机上将他们添加为访客。这对于来访的儿童、亲戚或尚未加入教会系统的朋友非常有用。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [查找你的家庭](./looking-up-members.md)，并从搜索结果中选择一位成员
- 进入[家庭查看界面](./household-review.md)，你可以在那里看到你的家庭成员

</div>

## 如何添加访客 {#how-to-add-a-guest}

1. 在**家庭查看界面**上，点击位于家庭成员列表下方的**添加访客**按钮。
2. 添加访客表单会出现，包含以下字段：
   - **名字** -- 输入访客的名字。
   - **姓氏** -- 输入访客的姓氏。
   - **电子邮件** -- 可选。输入访客的电子邮件，以便教会在其来访后进行跟进。
3. 点击**添加访客**按钮保存。

访客会被添加到你的家庭中，并且你会返回家庭查看界面。新访客会与你的其他家庭成员一起出现在成员列表中。

:::info
如果访客的姓名与系统中已有的非成员人员相符，应用会关联到该现有记录，而不会创建重复记录。这有助于保持教会数据库的整洁。在这种情况下，你输入的电子邮件不会被保存；它只会添加到新创建的访客记录中。
:::

## 添加访客后 {#after-adding-a-guest}

访客出现在你的家庭列表中后，你可以：

- **展开他们的卡片**，并[将他们分配到小组](./group-assignment.md)，与其他家庭成员一样。
- **[签到](./completing-checkin.md)**整个家庭，包括访客。

## 取消 {#canceling}

如果你改变主意，请点击添加访客表单底部的**取消**按钮，返回家庭查看界面，而不添加任何人。

:::tip
在登记机上添加访客会在教会数据库中创建一条人员记录。教会管理员之后可以在 B1 Admin 的[人员](../../b1-admin/people/adding-people.md)中更新访客的完整详细信息。
:::

## 下一步 {#next-step}

添加访客并根据需要[分配小组](./group-assignment.md)后，你就可以[完成签到](./completing-checkin.md)了。
