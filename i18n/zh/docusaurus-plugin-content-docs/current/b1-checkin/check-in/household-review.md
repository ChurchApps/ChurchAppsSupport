# 审核您的家庭成员

<div class="article-intro">

在您从搜索结果中选择一个人之后,应用会加载您的整个家庭,并在家庭审核界面中显示出来。这是签到流程的中枢环节,您可以在这里看到家庭中的每一位成员,并在签到之前管理他们的小组分配。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在服事场次界面[选择一个服事场次](./selecting-service)
- [查找一位成员](./looking-up-members)并从搜索结果中选择该成员

</div>

## 查看家庭成员

每位家庭成员都会以卡片形式显示,包含:

- 该成员的**照片**(如果档案中没有照片,则显示占位图标)
- 该成员的**显示名称**
- **当前小组分配情况的摘要**(卡片折叠时,以小标签的形式显示在姓名下方)
- 卡片右侧的**展开/折叠箭头**

## 展开某位成员

轻点某位成员的卡片将其展开。展开后,您会看到该服事场次下每个**服事时间**对应的一行。每一行显示:

- **服事时间名称**(例如"上午 9:00"或"上午 11:00")
- 一个显示当前所分配小组的**按钮**,若尚未分配小组则显示"选择小组"

轻点小组按钮可进入[小组选择界面](./group-assignment),在那里您可以为该成员和服事时间选择或更改小组。

展开后的卡片还会显示**成员**、**访客**和**志愿者**标签。轻点其中之一可设置该人员的签到身份类型——默认为"成员"。这一类型对儿童房间尤为重要:志愿者会计入该房间的志愿者与儿童比例,访客则计入您教会所设定的访客容量限制。

再次轻点该成员的卡片即可将其折叠。

:::tip
您不必为每位家庭成员都分配小组。参加主崇拜服事的成人可以不做小组分配。只需为需要签到进入特定班级或项目的成员分配小组即可。
:::

## 从此界面可进行的操作

在家庭审核界面,您有三种操作选择:

- **展开某位成员**并轻点服事时间按钮,以[分配或更改小组](./group-assignment)。
- **轻点成员列表下方的"添加访客"按钮**,为您的家庭[添加一位访客](./adding-guests)。
- **轻点屏幕底部的签到按钮**,为家庭中的每一位成员[完成签到](./completing-checkin)。

:::info
上一次签到同一服事场次时产生的小组分配会自动预加载。如果您的孩子每周参加相同的小组,可能无需做任何更改——只需审核后签到即可。
:::

## 后续步骤

- 为需要签到进入特定班级或项目的家庭成员[分配小组](./group-assignment)。
- 如果有人与您的家庭同行,[添加一位访客](./adding-guests)。
- 当每个人的分配情况看起来都正确无误时,[完成签到](./completing-checkin)。
