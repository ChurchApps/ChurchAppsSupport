# 分配小组

<div class="article-intro">

当您在家庭审核界面轻点某个服事时间按钮时,应用会打开小组选择界面。在这里,您可以为该家庭成员选择在该特定服事时间应该参加的小组或班级。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在家庭审核界面[审核您的家庭成员](./household-review)
- 展开您要分配的成员,并轻点某个服事时间按钮
- 请确保您教会的管理员已在 B1 Admin 中[创建了小组](../../b1-admin/groups/creating-groups.md),并将其与服事时间关联

</div>

## 小组是如何组织的

小组以**类别**的形式展示。每个类别都显示为一张卡片,内容包括:

- **类别名称**(例如"儿童""青年""成人")
- 该类别下的**小组数量**

轻点某个类别卡片可将其展开,查看其中的各个小组。再次轻点即可折叠。

## 选择小组

1. 轻点某个**类别**将其展开。
2. 查看该类别下的小组列表。每个小组会显示名称,右侧带有一个选择图标。
3. 轻点您想要分配的**小组名称**。

应用会保存您的选择,并返回到[家庭审核界面](./household-review)。该成员对应的服事时间按钮此时会显示您所选小组的名称。

## 年龄与年级引导

如果您教会为各房间设置了年龄或年级范围,列表会引导您找到合适的房间:该成员符合条件的房间会被**高亮显示**,超出其年龄或年级范围的房间则会被**淡化显示**。淡化的房间仍可被选择,但需要工作人员确认该选择。年龄和年级是根据您教会设定的年级晋升日期计算的,因此房间信息在学年交替时仍能保持准确。

## 选择"无"

如果您认为某位家庭成员在这一服事时间不需要分配到任何小组,请轻点屏幕底部的**无**按钮。这会清除该服事时间的现有小组分配,并返回家庭审核界面。

:::tip
对于参加主崇拜服事、无需签到进入特定小组或班级的成人,请使用**无**选项。
:::

## 更改小组分配

如需更改已完成的小组分配:

1. 返回[家庭审核界面](./household-review)。
2. 展开您要更改小组的成员。
3. 轻点服事时间按钮(此时会显示当前已分配的小组名称)。
4. 选择其他小组,或轻点**无**。

:::info
小组和类别是由您教会的管理员在 B1 Admin 中配置的。如果某个小组缺失或归错了类别,请让您的管理员更新[小组设置](../../b1-admin/groups/creating-groups.md)。
:::

## 后续步骤

完成小组分配后,返回[家庭审核界面](./household-review)以便:

- 为其他家庭成员分配小组
- 如果有人与您的家庭同行,[添加访客](./adding-guests)
- 在所有分配都准备就绪后,[完成签到](./completing-checkin)
