# 签出和儿童安全 {#checking-out--child-safety}

<div class="article-intro">

签出是儿童签入流程的最后一环：家长出示接送标签上的安全码，自助终端核实由谁前来接送，然后为儿童办理签出。有人值守的站点还提供安全工具，包括受信任接送人验证、给家长发送短信、安全标签重新打印以及紧急广播。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 签出功能仅在自助终端管理设置中设为**有人值守**模式的站点上可用
- 儿童必须已通过[签入](./completing-checkin.md)，并打印了带有安全码的接送标签
- 分页和紧急广播要求教会已在 B1 Admin 中连接短信服务提供商

</div>

## 开始签出 {#starting-a-check-out}

1. 在有人值守的站点，在查询屏幕上点击**签出**。
2. 输入家庭接送标签上 4 个字符的**安全码**。你可以直接键入、使用屏幕键盘，或使用 USB 或蓝牙扫描仪扫描标签上的条形码 -- 输入全部 4 个字符后，安全码会自动提交。
   - 没有扫描仪？点击安全码输入框下方的**扫描**，改用平板电脑的摄像头。将接送标签上的二维码或条形码对准**扫描接送码**窗口中的摄像头，安全码会自动输入。默认使用后置摄像头；点击翻转按钮可切换摄像头，或点击**取消**返回键入模式。
3. 自助终端会显示在该安全码下签入的儿童。

### 在没有安全码时查找家庭 {#finding-a-family-without-the-code}

如果家长遗失了接送标签，请改为查找该家庭：

1. 在**签出**屏幕上，点击**按姓名搜索**（位于**扫描**旁边）。
2. 输入该家庭的姓氏并点击**搜索**，或点击**使用电话号码**，然后在键盘上输入电话号码（至少后 4 位）。
3. 点击结果中的该人。自助终端会找到该家庭中今天已签入且尚未签出的所有人，并像输入安全码时一样显示他们。

如果该家庭中没有人签入，自助终端会显示 "No one in this household is checked in right now."（此家庭中目前没有人签入。）。点击**重新搜索**可再次搜索，或点击**改为输入安全码**，返回安全码输入框。

下文的接送核查依然适用：该家庭受信任的接送人和成年人会被列出，被标记为**不被授权**的人员仍会被阻止。

## 验证谁来接送 {#verifying-who-is-picking-up}

签出屏幕会询问由谁来接送儿童：

- 该家庭中**受信任的接送人**会以可点击的卡片显示，并带有其照片和关系 -- 点击站在你面前的人即可。
- **家庭成年人**也会以照片网格的形式显示。
- **其他**选项允许你为不在列表中的人输入姓名。

如果输入的姓名与该家庭中标记为**不被授权**的人员相匹配，自助终端会以警告阻止签出。工作人员可以选择**覆盖**以继续签出 -- 覆盖操作会连同该人的姓名记录在出勤记录中。

确认接送人后，点击签出。接送人的姓名会与出勤记录一同保存。

:::info
受信任和不被授权的接送人由教会工作人员在 B1 Admin 中每个人的页面上管理 -- 请参阅[签入安全](../../b1-admin/attendance/checkin-safety.md#trusted-and-not-authorized-pickup-people)。
:::

## 给家长分页 {#paging-a-parent}

礼拜期间需要找家长 -- 比如需要更换尿布，或孩子在哭？在有人值守站点的签出屏幕上，工作人员可以发送**分页**：通过教会的短信服务提供商，向儿童的父母或监护人发送一条短信。已选择退出短信或没有手机号码的家长会被跳过，自助终端会显示已发送的短信数量。

## 重新打印标签 {#reprinting-labels}

如果名牌或接送标签遗失或损坏，有人值守站点的工作人员可以在输入安全码后，从签出屏幕**重新打印**该家庭的标签。重新打印使用与原始签入相同的打印机和标签模板。

## 紧急广播 {#emergency-broadcast}

发生紧急情况时，工作人员可以一次性向当前礼拜中**每位已签入儿童**的监护人发送短信：

1. 打开自助终端的**管理员设置**（在页眉标志上快速点击 7 次，如果设置了 PIN 码，还需输入 PIN 码）。
2. 点击**紧急广播**。
3. 输入消息，然后在确认字段中输入 **EMERGENCY** -- 在你这样做之前，**发送广播**按钮将保持禁用状态。
4. 自助终端会报告有多少部手机收到了消息，以及有多少人被跳过（已选择退出或没有手机号码）。

:::warning
广播会发送给所选礼拜中每个已签入的家庭。仅用于真正的紧急情况，例如疏散、封锁或恶劣天气。
:::
