# 签出和儿童安全

<div class="article-intro">

签出结束了儿童签入的循环：家长出示来自其接送标签的安全代码，自助终端验证谁来接送，儿童被签出。有人值守的站点也获得安全工具 -- 受信任的接送人验证、给家长发送短信、安全标签重新打印和紧急广播。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 签出在自助终端管理员设置中设置为**有人值守**模式的站点上可用
- 儿童必须已与[签入](./completing-checkin)和打印接送标签上的安全代码
- 分页和紧急广播需要您的教会在B1 Admin中连接了短信提供商

</div>

## 开始签出

1. 在有人值守的站点，在查询屏幕上点击**签出**。
2. 从家庭接送标签输入4字符**安全代码**。您可以输入它、使用屏幕上的键盘或用USB或蓝牙扫描仪扫描标签的条形码 -- 一旦输入所有4个字符，代码自动提交。
   - 没有扫描仪？点击代码字段下方的**扫描**以改用平板电脑的摄像头。将接送标签的二维码或条形码对着**扫描接送代码**窗口中的摄像头，代码会为您输入。默认使用后置摄像头；点击翻转按钮切换摄像头，或点击**取消**返回输入。
3. 自助终端显示在该代码下签入的儿童。

## 验证谁来接送

签出屏幕询问谁来接送儿童：

- **受信任的接送人**对于家庭显示为可点击卡片，带有他们的照片和关系 -- 点击站在您面前的人。
- **家庭成年人**也显示在照片网格中。
- **其他**让您为不在列表上的人输入名字。

如果输入的名字与某人标记为该家庭**不被授权**的名字匹配，自助终端会用警告阻止签出。员工可以选择**覆盖**继续 -- 覆盖在出勤记录上记录，带有该人的名字。

一旦接送人被确认，点击签出。接送人的名字存储在出勤记录中。

:::info
受信任和未被授权的接送人由教会员工在B1 Admin中每个人的页面上管理 -- 请参阅[签入安全](../../b1-admin/attendance/checkin-safety#trusted-and-not-authorized-pickup-people)。
:::

## 给家长分页

需要在服务期间要求家长 -- 尿布更换、哭泣的孩子？从有人值守站点的签出屏幕，员工可以发送**分页**：通过教会的短信提供商向孩子的家长或监护人发送短信。选择退出短信或没有手机号码的家长被跳过，自助终端显示发送了多少条消息。

## 重新打印标签

如果名牌或接送标签丢失或损坏，有人值守站点的员工可以在输入安全代码后从签出屏幕**重新打印**家庭的标签。重新打印使用与原始签入相同的打印机和标签模板。

## 紧急广播

在紧急情况下，员工可以一次性向当前服务的**每个签入儿童**的监护人发短信：

1. 打开自助终端**管理员设置**（在标题logo上快速点击7次，加上PIN（如果设置了））。
2. 点击**紧急广播**。
3. 输入消息，然后在确认字段中输入**紧急情况** -- **发送广播**按钮保持禁用，直到您这样做。
4. 自助终端报告有多少部手机收到了消息以及有多少人被跳过（选择退出或没有手机号码）。

:::warning
广播发送到所选服务的每个签入家庭。仅在真正的紧急情况下使用 -- 疏散、封锁、恶劣天气。
:::
