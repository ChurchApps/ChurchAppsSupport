# 签退与儿童安全

<div class="article-intro">

签退是儿童签到流程的收尾环节：家长出示接送标签上的安全码，签到亭核实接送人身份，随后儿童被签退。有人值守的站点还提供安全工具——可信接送核实、寻呼家长短信、安全标签补打，以及紧急广播。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 签退功能仅在签到亭管理设置中设为**有人值守**模式的站点上可用
- 儿童必须已经[签到](./completing-checkin)并打印了带有安全码的接送标签
- 寻呼和紧急广播功能需要教会已在 B1 Admin 中连接短信服务提供商

</div>

## 开始签退

1. 在有人值守的站点上，在查询屏幕点击**签退**。
2. 输入家庭接送标签上的 4 位**安全码**。你可以输入、使用屏幕小键盘，或用 USB 或蓝牙扫描器扫描标签上的条形码——输入完所有 4 位字符后代码会自动提交。
3. 签到亭会显示在该代码下签到的儿童。

## 核实接送人身份

签退屏幕会询问是谁来接送儿童：

- 该家庭的**可信接送人**会以可点击卡片的形式显示，带有照片和关系——点击站在你面前的人。
- **家庭成年人**同样会显示在照片网格中。
- **其他**选项让你输入不在名单上的人的姓名。

如果输入的姓名与该家庭中标记为**未授权**的人匹配，签到亭会阻止签退并显示警告。工作人员可以选择**覆盖**以继续进行——该覆盖操作会连同此人的姓名一起记录在签到记录中。

确认接送人后，点击签退。接送人的姓名会与签到记录一起存储。

:::info
可信和未授权的接送人由教会工作人员在 B1 Admin 中各个人员的页面上进行管理——参见[签到安全](../../b1-admin/attendance/checkin-safety#trusted-and-not-authorized-pickup-people)。
:::

## 寻呼家长

在服务过程中需要联系家长——例如换尿布或孩子哭闹？在有人值守站点的签退屏幕上，工作人员可以通过教会的短信服务提供商向孩子的家长或监护人发送**寻呼**短信。已选择不接收短信或没有登记手机号码的家长会被跳过，签到亭会显示发送了多少条消息。

## 补打标签

如果姓名牌或接送标签丢失或损坏，有人值守站点的工作人员可以在输入安全码后从签退屏幕**补打**该家庭的标签。补打使用与原始签到相同的打印机和标签模板。

## 紧急广播

在紧急情况下，工作人员可以一次性给当前服务中**所有已签到儿童**的监护人发送短信：

1. 打开签到亭的**管理设置**（快速点击标题徽标 7 次，如果设置了 PIN 码还需输入 PIN）。
2. 点击**紧急广播**。
3. 输入消息内容，然后在确认字段中输入**EMERGENCY**——在此之前**发送广播**按钮保持禁用状态。
4. 签到亭会报告有多少部手机收到了消息，以及有多少人被跳过（选择不接收短信或没有手机号码）。

:::warning
该广播会发送给所选服务中所有已签到家庭。请仅在真正的紧急情况下使用——如疏散、封锁、恶劣天气。
:::
