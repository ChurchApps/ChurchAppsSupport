# 完成签到

<div class="article-intro">

一旦您审查了您的家庭并做了任何需要的小组分配，您就准备好完成签到。这是信息亭工作流中的最后一步——应用程序提交出席情况、打印标签并为下一个家庭重置。

</div>

<div class="prereqs">
<h4>开始前</h4>

- [查看您的家庭](./household-review)在家庭查看屏幕上
- [分配小组](./group-assignment)给任何需要签到特定课程或程序的家庭成员
- 可选择[添加任何访客](./adding-guests)与您的家庭一起访问

</div>

## 如何签到

1. 从**家庭查看屏幕**，点击屏幕底部的**签到**按钮。
2. 应用程序将出席数据提交到服务器，并显示带有绿色复选标记和欢迎消息的**成功屏幕**。

这就是全部。您的家庭出席已被记录。

## 客满和志愿者比例

如果您的教会在其房间上配置了[安全限制](../../b1-admin/attendance/checkin-safety)，服务器在保存之前检查它们：

- 如果选定的房间**已满或关闭**，签到不会继续，应用程序会命名房间以便您选择不同的。
- 如果儿童房间**缺少志愿者**其比例，应用程序要么显示员工可以确认继续的警告，要么完全阻止签到——取决于您的教会配置比例执行的方式。

## 标签打印

如果配置了网络打印机，应用程序在签到后自动打印标签：

- **姓名标签**为分配到启用了**打印姓名牌**设置的小组的每个人打印。姓名标签包括人员的名字、他们的小组分配以及如果有的过敏症/备注信息。
- **家长接送单据**在任何签到的人员在启用了**家长接送**设置的小组中时打印。被签到为**志愿者**的人被跳过，所以在家长接送房间中服务的护理工人不会获得接送单据。接送单据列出儿童、他们的小组分配和唯一**4 字符安全代码**。

:::info
相同的安全代码出现在儿童的姓名标签和家长的接送单据上。在接送时间，志愿者匹配代码以验证正确的成人正在接送每个儿童。
:::

安全代码为每次签到生成新代码，仅使用辅音和数字（排除元音以避免形成不适当的单词）。

:::warning
如果标签不打印，通过点击**教会徽标** 7 次打开管理员设置，然后点击**更改打印机**以验证打印机连接。有关故障排除步骤，请参阅[打印机设置](../getting-started/printer-setup)。
:::

## 签到后发生什么

- 如果配置了打印机，应用程序打印所有标签，然后自动返回到**查找屏幕**，准备下一个家庭。
- 如果未配置打印机，成功屏幕显示几秒钟，然后自动返回到**查找屏幕**。

您不需要点击任何东西返回查找屏幕——应用程序处理转换自动。

:::tip
应用程序在每次签到后完全重置，所以没有一个家庭看到另一个家庭信息的风险。
:::

## 记录什么

当您点击**签到**时，应用程序为具有小组分配的每个家庭成员发送以下到服务器：

- **人员**被签到
- **服务**他们正在参加
- **服务时间**和他们分配给的**小组**

此数据显示在 B1 Admin 中的出席部分，您的教会管理员可以在那里查看和管理出席记录。有关详细信息，请参阅[签到管理指南](../../b1-admin/attendance/check-in.md)。
