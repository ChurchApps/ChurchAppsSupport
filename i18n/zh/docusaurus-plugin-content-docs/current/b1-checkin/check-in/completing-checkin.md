# 完成签到

<div class="article-intro">

在您核对完家庭信息并完成所有需要的小组分配后，即可完成签到。这是自助机流程的最后一步——应用会提交出勤数据、打印标签，并为下一个家庭重置。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [核对您的家庭信息](./household-review)，位于家庭核对屏幕
- [为需要参加特定班级或项目的家庭成员分配小组](./group-assignment)
- 可选：[添加随您家人一同到访的访客](./adding-guests)

</div>

## 如何签到

1. 在**家庭核对屏幕**上，点击屏幕底部的 **Check-in（签到）** 按钮。
2. 应用会将出勤数据提交到服务器，并显示一个带有绿色对勾和欢迎信息的**成功屏幕**。

这就是全部操作。您家人的出勤已经记录下来了。

## 房间已满与志愿者配比

如果您的教会已为其房间配置了[安全限制](../../b1-admin/attendance/checkin-safety)，服务器会在保存前进行检查：

- 如果所选房间**已满或已关闭**，签到将不会成功，应用会指出该房间，以便您选择其他房间。
- 如果服务时间设有[签到时间表](../../b1-admin/attendance/setup#setting-a-check-in-schedule)，且当前签到窗口未开放，则同样会拒绝为该服务时间下的房间签到。**无法签到** 屏幕会列出该房间，并注明原因"现在不可签到"；点击 **Change Rooms（更换房间）** 即可选择其他服务时间或小组。（在[选择服务](./selecting-service#when-check-in-isnt-open)时，已经关闭的服务时间会被隐藏，因此您通常只会在签到窗口于签到过程中途关闭时才会看到此情况。）
- 如果儿童房间的**志愿者人手不足**（未达到配比要求），应用会显示一条警告，由工作人员确认后方可继续，或直接阻止签到——具体取决于您教会对配比的执行方式。

## 标签打印

如果已配置网络打印机，应用会在签到后自动打印标签：

- **姓名标签** 会为每个被分配到已启用 **Print Nametag（打印名牌）** 设置的小组的人员打印。姓名标签包括此人的姓名、小组分配，以及（如有记录）过敏或备注信息。
- **家长接送单** 会在任何已签到人员所在的小组启用了 **Parent Pickup（家长接送）** 设置时打印。以**志愿者**身份签到的人员会被跳过，因此在家长接送房间服务的托儿人员不会获得接送单。接送单会列出儿童、其小组分配，以及一个唯一的 **4 位安全码**。

:::info
同一个安全码会同时出现在儿童的姓名标签和家长的接送单上。接送时，志愿者会核对这些安全码，以确认每个孩子是由正确的成年人接走的。
:::

安全码在每次签到时都会重新生成，并且只使用辅音字母和数字（为避免组成不当词语，元音字母已被排除）。

:::warning
如果标签没有打印，请点击**教会徽标**七次以打开管理员设置，然后点击 **Change Printer（更换打印机）** 检查打印机连接。故障排除步骤请参阅[打印机设置](../getting-started/printer-setup)。
:::

## 签到后会发生什么

- 如果已配置打印机，应用会打印所有标签，然后自动返回**查找屏幕**，准备迎接下一个家庭。
- 如果未配置打印机，成功屏幕会显示几秒钟，然后自动返回**查找屏幕**。

您无需点击任何按钮即可返回查找屏幕——应用会自动完成切换。

:::tip
每次签到后，应用都会完全重置，因此不存在一个家庭看到另一个家庭信息的风险。
:::

## 记录内容

当您点击 **Check-in（签到）** 时，应用会为每位已分配小组的家庭成员向服务器发送以下信息：

- 被签到的**人员**
- 他们所参加的**服务**
- 他们被分配到的**服务时间**和**小组**

这些数据会显示在 B1 Admin 的出勤部分中，教会管理员可以在那里查看和管理出勤记录。详情请参阅[签到管理指南](../../b1-admin/attendance/check-in.md)。
