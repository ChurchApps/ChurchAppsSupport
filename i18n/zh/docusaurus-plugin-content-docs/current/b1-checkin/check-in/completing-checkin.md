# 完成签到

<div class="article-intro">

在您审核完家庭成员并完成所需的小组分配后,就可以最终完成签到了。这是自助签到亭流程的最后一步——应用会提交出勤记录、打印标签,并为下一个家庭重置界面。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在家庭审核界面[审核您的家庭成员](./household-review)
- 为需要签到进入特定班级或项目的家庭成员[分配小组](./group-assignment)
- (可选)[添加与您家庭同行的任何访客](./adding-guests)

</div>

## 如何签到

1. 在**家庭审核界面**,轻点屏幕底部的**签到**按钮。
2. 应用会将出勤数据提交至服务器,并显示一个带有绿色对勾和欢迎信息的**成功界面**。

就是这么简单。您家庭的出勤已被记录。

## 房间已满与志愿者比例

如果您的教会为其房间配置了[安全限制](../../b1-admin/attendance/checkin-safety),服务器在保存前会先检查这些限制:

- 如果所选房间**已满或已关闭**,签到无法完成,应用会指出该房间名称,以便您选择其他房间。
- 如果某个儿童房间的**志愿者比例不足**,应用会视教会对比例执行方式的配置,要么显示一条警告,由工作人员确认后继续,要么直接完全阻止此次签到。

## 标签打印

如果配置了网络打印机,应用会在签到后自动打印标签:

- 系统会为每个被分配到已启用**打印姓名牌**设置的小组的成员打印**姓名标签**。姓名标签包含该人的姓名、其小组分配情况,以及档案中记录的任何过敏或备注信息。
- 只要有任何签到人员所属小组启用了**家长接送**设置,系统就会打印**家长接送单**。接送单列出了孩子姓名、他们的小组分配,以及一个唯一的**4位安全码**。

:::info
同一个安全码会同时出现在孩子的姓名标签和家长的接送单上。接送时,志愿者通过核对安全码来确认前来接送的确实是该孩子的正确监护人。
:::

安全码为每次签到重新生成,且只使用辅音字母和数字(排除元音字母,以避免拼出不雅词语)。

:::warning
如果标签无法打印,请连续轻点**教会标志**七次以打开管理员设置,然后轻点**更换打印机**以检查打印机连接。故障排查步骤请参阅[打印机设置](../getting-started/printer-setup)。
:::

## 签到后会发生什么

- 如果配置了打印机,应用会打印所有标签,然后自动返回**查找界面**,准备迎接下一个家庭。
- 如果没有配置打印机,成功界面会显示几秒钟,然后自动返回**查找界面**。

您无需进行任何操作即可返回查找界面——应用会自动完成这一切换。

:::tip
应用在每次签到后都会完全重置,因此不存在一个家庭看到另一个家庭信息的风险。
:::

## 系统会记录哪些内容

当您轻点**签到**时,应用会为每个有小组分配的家庭成员向服务器发送以下信息:

- 被签到的**本人**
- 他们参加的**服事场次**
- 他们所分配的**服事时间**和**小组**

这些数据会出现在 B1 Admin 的出勤部分,您教会的管理员可以在那里查看和管理出勤记录。详情请参阅[签到管理指南](../../b1-admin/attendance/check-in.md)。
