# 选择服务

<div class="article-intro">

每次签到的第一步都是选择您要参加的服务。应用加载完成后会立即显示服务屏幕，它决定了签到流程其余部分中可用的礼拜时间和小组。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [登录](../getting-started/logging-in)到 B1 Church Checkin 应用并选择您的教会
- 确保您的教会管理员已在 B1 Admin 中[配置服务和礼拜时间](../../b1-admin/attendance/setup.md)

</div>

## 工作原理

1. 登录后（或在再次访问时自动登录后），应用会显示**服务屏幕**。
2. 您会看到为您的教会配置的所有服务列表。每个服务都以卡片形式显示，卡片上有服务名称（例如"周日早晨"或"周三晚间"）。
3. 点击您要参加的服务。

应用会加载与该服务关联的礼拜时间和小组，然后带您进入[成员查询屏幕](./looking-up-members)。

## 签到未开放时

如果您的管理员为某个礼拜时间设置了[签到时间表](../../b1-admin/attendance/setup#setting-a-check-in-schedule)，应用仅允许家庭在该礼拜时间的签到时段开放时选择它。当前签到时段已关闭的礼拜时间仍会显示在[家庭屏幕](./household-review)上，但会标记为**已关闭**（例如 **已关闭 · 周日 9:30 AM 开放**），而不会提供小组按钮。

如果您点击的服务的所有礼拜时间都已关闭，应用会告诉您签到何时开放 -- 例如 **"该服务的签到将于周日 9:30 AM 开放。"**（如果无法显示开放时间，则会显示 **"该服务当前未开放签到。"**）点击**返回**即可回到服务列表并选择其他服务，或等待签到时段开放后再重试。

:::info
签到时段遵循服务所在校区的时区。如果该校区未设置时区，则使用您教会的时区。如果某个礼拜时间的开放时间看起来不对，请让您的管理员检查校区或教会设置中的时区。在家庭屏幕上，自助服务终端还会使用平板电脑自身的时钟来开启和关闭礼拜时间，因此请确保平板电脑设置了正确的时间和时区。
:::

:::info
服务由您的教会管理员在 B1 Admin 的考勤部分中配置。如果您没有看到预期的服务，请让管理员在[考勤设置](../../b1-admin/attendance/setup.md)中确认该服务已创建。
:::

## 幕后发生的事情

当您选择一个服务时，应用会从服务器获取三项内容：

- 该服务的**礼拜时间**（例如，一个服务可能有上午 9:00 和上午 11:00 两个时段）。
- 每个礼拜时间可用的**小组**（例如幼儿园、学前班、小学）。
- **小组与礼拜时间的关联**，用于确定哪些小组在哪些时间可用。

这些数据会在本地缓存，因此签到流程的其余部分快速且响应灵敏。

:::tip
如果您的教会只配置了一个服务，您仍需点击它才能继续。应用不会自动选择单个服务。
:::

## 下一步

选择服务后，您将通过电话号码或姓名[查找您的家庭](./looking-up-members)。
