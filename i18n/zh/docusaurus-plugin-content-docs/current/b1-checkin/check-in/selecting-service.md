# 选择服务

<div class="article-intro">

每次签到的第一步是选择您要参加的服务。应用加载完成后会立即显示服务选择界面，它决定了接下来整个签到流程中可用的服务时间和小组。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- [登录](../getting-started/logging-in)到 B1 Church Checkin 应用并选择您的教会
- 确保您的教会管理员已在 B1 Admin 中[配置服务和服务时间](../../b1-admin/attendance/setup.md)

</div>

## 工作原理

1. 登录后（或在之后的回访中自动登录后），应用会显示**服务界面**。
2. 您将看到为您的教会配置的所有服务列表。每个服务都显示为一张卡片，其中包含服务名称（例如"周日早晨"或"周三晚上"）。
3. 点击您要参加的服务。

应用会加载与该服务关联的服务时间和小组，然后带您进入[成员查找界面](./looking-up-members)。

## 签到未开放时 {#when-check-in-isnt-open}

如果您的管理员为某个服务时间设置了[签到时段](../../b1-admin/attendance/setup#setting-a-check-in-schedule)，应用只会在其签到窗口开放期间提供该服务时间。签到窗口当前已关闭的服务时间会被隐藏，以免家庭成员在后续流程中选择它们。

如果您点击的服务下的所有服务时间都已关闭，应用会显示 **"此服务目前不开放签到。"**。点击**返回**即可回到服务列表并选择其他服务，或等待签到窗口开放后再重试。

:::info
签到窗口遵循您教会的时区。如果您的教会未设置时区，则使用您所在分堂的时区。如果服务时间的开放时间看起来不对，请让管理员在教会或分堂设置中检查时区。
:::

:::info
服务由您的教会管理员在 B1 Admin 的"考勤"部分中配置。如果您没有看到您期望的服务，请让管理员在[考勤设置](../../b1-admin/attendance/setup.md)中确认该服务已创建。
:::

## 幕后发生的事情

当您选择服务时，应用会从服务器获取三类数据：

- 该服务的**服务时间**（例如，一个服务可能有上午 9:00 和上午 11:00 两个时间段）。
- 每个服务时间可用的**小组**（例如，婴儿房、学龄前、小学）。
- 决定哪些小组在哪些服务时间可用的**小组与服务时间关联**。

这些数据会被缓存在本地，使签到过程的其余部分快速且响应灵敏。

:::tip
如果您的教会只配置了一个服务，您仍需点击它才能继续。应用不会自动选择唯一的服务。
:::

## 下一步

选择服务后，您将通过电话号码或姓名[查找您的家庭](./looking-up-members)。
