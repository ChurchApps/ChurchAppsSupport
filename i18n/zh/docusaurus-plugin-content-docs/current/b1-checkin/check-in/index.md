# 签到流程

<div class="article-intro">

B1 Church Checkin 中的签到流程遵循一套简单的分步流程。教会成员走到自助签到亭前,找到自己的家庭,确认小组分配,然后完成签到——整个过程不到一分钟。本节将介绍自助签到亭体验的每一个步骤。

</div>

## 签到流程一览

1. **[选择服事场次](./selecting-service)**——选择您要参加的服事场次(例如主日上午、主日下午、周中聚会)。
2. **[查找您的家庭](./looking-up-members)**——通过电话号码或姓氏搜索,在系统中找到自己。
3. **[审核您的家庭成员](./household-review)**——查看所有家庭成员及其当前的小组分配情况。
4. **[分配小组](./group-assignment)**——为每位家庭成员在每个服事时间选择应参加的班级或小组。
5. **[添加访客](./adding-guests)**(可选)——如果有访客与您同行,将其添加到您的家庭中。
6. **[完成签到](./completing-checkin)**——轻点签到按钮以提交出勤记录并打印标签。
7. **[签退](./checking-out)**(有人值守的接送点)——接送时核对安全码和接送人身份,支持信任接送人名单、寻呼家长和标签重印。

签到完成后,应用会显示成功界面,并自动返回查找界面,准备迎接下一个家庭。

:::tip
整个流程都是为教会成员独立操作而设计的。志愿者无需操作自助签到亭,不过安排人手在旁协助首次到访的访客始终是个不错的主意。
:::

## 开始之前

在使用签到自助亭之前,请确保 B1 Admin 中已完成以下配置:

- 已在出勤设置下设置好**服事场次和服事时间**。请参阅[出勤设置指南](../../b1-admin/attendance/setup.md)。
- 已创建**小组**并将其与相应的服事时间关联。请参阅[创建小组](../../b1-admin/groups/creating-groups.md)。
- 已针对标签打印配置好**小组设置**:为需要姓名标签的小组启用**打印姓名牌**,为需要接送单的儿童小组启用**家长接送**。
- 已将**人员**添加到系统中并设置好家庭关联。请参阅[添加人员](../../b1-admin/people/adding-people.md)。

:::info
如果您还未设置好签到亭本身,请参阅[入门指南](../getting-started/)以了解安装、登录和打印机配置说明。
:::
