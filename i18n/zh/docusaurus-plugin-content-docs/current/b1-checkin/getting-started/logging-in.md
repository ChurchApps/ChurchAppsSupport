# 登录

<div class="article-intro">

在自助机用于签到之前，你需要使用一个有权访问你教会的 ChurchApps 账号登录。本页介绍首次登录流程、教会选择、自动登录行为以及如何退出登录。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在你的 Android 平板上安装 B1 Church Checkin（参见[入门指南](./index.md)）
- 准备好你的 ChurchApps 账号邮箱和密码
- 该账号需要在你的教会中拥有 **Checkin**（签到）权限（或 **Edit Attendance**（编辑出勤））。管理员可以在 B1 Admin 中通过 **Settings > Roles**（设置 > 角色）添加该权限——参见[签到自助机账号](../../b1-admin/settings/roles-permissions.md#check-in-kiosk-accounts)

</div>

## 首次登录

1. 打开 B1 Church Checkin 应用。启动画面结束后，你会看到带有 B1 Church Checkin 标志的登录屏幕。
2. 在第一个字段中输入你的**电子邮件地址**。
3. 在第二个字段中输入你的**密码**。
4. 点击 **Login**（登录）按钮。

应用会验证你的凭据并让你登录。如果邮箱或密码不正确，屏幕底部会显示错误信息。

如果该账号已开启[两步登录](../../b1-admin/profile/managing-profile.md#two-factor-sign-in)，应用随后会要求输入验证码。请输入账号所有者身份验证器应用中显示的 6 位验证码，或其中一个备用代码，然后再次点击 **Login**。你只需在首次登录时输入验证码；之后自助机将保持登录状态。

:::info
这与你用于 B1 Admin 或其他任何 ChurchApps 产品的邮箱和密码相同。签到自助机不需要单独的账号。
:::

## 选择你的教会

登录成功后，应用会加载你的账号拥有 **Checkin** 或 **Edit Attendance** 权限的教会。仅拥有其他权限的教会会被排除在外。如果没有任何符合条件的教会，应用会显示 **No check-in access**（没有签到权限），并提示你请教会管理员将 Checkin 权限添加到你所属的某个角色中。每个教会都以卡片形式显示，包括教会名称和标志（如果已在 B1 Admin 中配置）。

- 如果你的账号只关联了**一个教会**，你仍然会看到选择界面。点击你的教会即可继续。
- 如果你的账号关联了**多个教会**，请点击你希望此自助机为其服务的教会。

选择教会后，应用会加载该教会的品牌和外观设置。此后的所有屏幕页眉都会显示你的教会标志。

## 再次访问时自动登录

首次成功登录后，应用会在平板上保存一个安全的登录令牌以及你所选的教会。它不会保存你的密码。之后每次启动时：

- 应用会使用已保存的令牌自动为你登录。
- 如果你之前已选择过教会，应用会恢复该选择，并直接进入**礼拜选择屏幕**。
- 如果已保存的登录信息已失效，应用会返回登录屏幕，以便你重新登录。

:::tip
由于自助机会自动登录，你只需在初始设置时输入一次凭据。之后，平板开机即可直接使用。
:::

## 管理员设置

管理员设置被刻意隐藏，以防使用自助机的教会成员意外更改配置。访问方法如下：

1. 在 **2 秒钟内**快速连续点击页眉中的**教会标志** **七次**。
2. 如果设置了自助机 PIN 码，系统提示时请输入 PIN 码。
3. **Admin Settings**（管理员设置）屏幕会打开，并提供以下选项：
   - **Change Service**（更改礼拜）—— 切换所选的礼拜时间
   - **Change Printer**（更改打印机）—— 打开[打印机设置](./printer-setup.md)，搜索并选择打印机
   - **Set/Change PIN**（设置/更改 PIN）—— 设置或更新用于保护管理员访问的自助机 PIN 码
   - **Logout**（退出登录）—— 退出登录并返回登录屏幕

:::warning
退出登录会清除所有已保存的凭据和教会选择。你需要重新输入邮箱和密码才能再次使用自助机。仅在需要切换账号或重新配置自助机时才退出登录。
:::

## 下一步
