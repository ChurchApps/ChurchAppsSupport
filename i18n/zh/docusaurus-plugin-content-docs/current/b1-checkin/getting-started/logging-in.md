# 登录

<div class="article-intro">

在自助签到终端用于签到之前，您需要使用一个有权访问贵教会的 ChurchApps 账户登录。本页介绍首次登录流程、教会选择、自动登录行为以及如何退出登录。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 在您的 Android 平板上安装 B1 Church Checkin（参见[入门指南](./index.md)）
- 准备好您的 ChurchApps 账户邮箱和密码
- 该账户需要在贵教会拥有 **Checkin** 权限（或 **Edit Attendance**）。管理员可以在 B1 Admin 中通过 **Settings > Roles**（设置 > 角色）添加该权限，参见[签到终端账户](../../b1-admin/settings/roles-permissions.md#check-in-kiosk-accounts)

</div>

## 首次登录

1. 打开 B1 Church Checkin 应用。启动画面结束后，您将看到带有 B1 Church Checkin 标志的登录界面。
2. 在第一个输入框中输入您的**电子邮件地址**。
3. 在第二个输入框中输入您的**密码**。
4. 点击 **Login**（登录）按钮。

应用会验证您的凭据并让您登录。如果邮箱或密码不正确，屏幕底部会显示错误消息。

如果该账户开启了[两步登录](../../b1-admin/profile/managing-profile.md#two-factor-sign-in)，应用会接着要求输入验证码。请输入账户所有者验证器应用中显示的 6 位数字验证码，或其中一个备用代码，然后再次点击 **Login**（登录）。仅首次登录需要验证码，之后签到终端会保持登录状态。

:::info
这与您用于 B1 Admin 或其他任何 ChurchApps 产品的邮箱和密码相同。您无需为签到终端单独申请账户。
:::

## 选择您的教会

登录成功后，应用会加载您的账户拥有 **Checkin** 或 **Edit Attendance** 权限的教会。仅拥有其他权限的教会将不会显示。如果没有符合条件的教会，应用会显示 **No check-in access**（无签到权限），并提示您请教会管理员将 Checkin 权限添加到您的某个角色中。每个教会以卡片形式显示，包含教会名称和标志（如果已在 B1 Admin 中设置）。

- 如果您的账户只关联了**一个教会**，您仍会看到选择界面。点击您的教会即可继续。
- 如果您的账户关联了**多个教会**，请点击您希望此签到终端服务的教会。

选择教会后，应用会加载该教会的品牌和外观设置。此后所有界面的页眉都会显示您教会的标志。

## 再次使用时自动登录

首次成功登录后，应用会在平板上保存安全的登录令牌和您选择的教会。它不会保存您的密码。之后每次启动时：

- 应用会使用已保存的令牌自动为您登录。
- 如果您之前选择过教会，应用会恢复该选择并直接进入**服务界面**。
- 如果已保存的登录信息已失效，应用会返回登录界面，以便您重新登录。

:::tip
由于签到终端会自动登录，您只需在初始设置时输入一次凭据。之后只要开启平板电源，即可直接使用。
:::

## 管理员设置

管理员设置被刻意隐藏，以防止使用签到终端的教会成员意外更改配置。要访问这些设置：

1. 在页眉中快速连续点击**教会标志**七次（需在两秒内完成）。
2. 如果已设置签到终端 PIN 码，请在提示时输入该 PIN 码。
3. **Admin Settings**（管理员设置）界面将打开，其中包含以下选项：
   - **Change Service**（更改服务）——切换所选的服务时间
   - **Change Printer**（更改打印机）——打开[打印机设置](./printer-setup.md)，搜索并选择打印机
   - **Set Admin PIN**（设置管理员 PIN）（若已设置则显示为 **Change Admin PIN**（更改管理员 PIN））——设置或更新用于保护管理员访问的签到终端 PIN 码
   - **Emergency broadcast**（紧急广播）——向每个已签到家庭的监护人发送短信（参见[紧急广播](../check-in/checking-out.md#emergency-broadcast)）
   - **Manned station mode**（有人值守模式）——一个开关，可为此站点添加签出、呼叫、补打和个人资料编辑功能（参见[签出](../check-in/checking-out.md)）
   - **Logout**（退出登录）——退出账户并返回登录界面

   点击 **Back to Kiosk**（返回签到）即可返回签到界面。

:::warning
退出登录会清除所有已保存的凭据和教会选择。若要再次使用签到终端，您需要重新输入邮箱和密码。请仅在需要切换账户或重新配置签到终端时退出登录。
:::

## 后续步骤

登录后，您可以[设置打印机](./printer-setup.md)，或直接前往[签到流程](../check-in/index.md)。
