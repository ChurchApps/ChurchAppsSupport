# 服事

<div class="article-intro">

B1.church 中的服事板块可让您浏览志愿服事的机会，并报名参加教会的各个职位。除了查看被分配给您的计划和礼拜程序，您现在还可以自主选择需要填补的职位。

</div>

## 您可以做什么

- **浏览志愿服事机会** -- 查看即将举行的、有空缺职位需要志愿者的服事计划。
- **报名职位** -- 选择一个职位，一键为自己报名。
- **查看您的计划** -- 查看您即将进行和过去的[服事安排](../plans/viewing-plans)。
- **回复安排** -- 在计划页面或首页的 **You're serving**（您的服事）部分，接受或婉拒您被排定的职位。如果您在接受后计划有变，可以在礼拜结束前[婉拒已接受的安排](../plans/viewing-plans#declining-an-accepted-assignment)。
- **取消报名** -- 如果您的计划有变，可在截止时间之前取消自主报名。

## 工作原理

教会管理员会创建服事计划，并将某些职位标记为可自主报名。这些职位会显示在志愿者报名页面上，并按类别（例如“Band”（乐队）、“Hospitality”（接待）或“Kids Ministry”（儿童事工））进行组织。您可以查看每个职位还有多少名额，并为您有空参加的职位报名。

:::info
只有教会管理员已开放自主报名的职位才会出现在志愿者页面上。某些职位可能只能通过直接指派来填补。
:::
