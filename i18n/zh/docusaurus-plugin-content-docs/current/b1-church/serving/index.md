# 服事

<div class="article-intro">

B1.church 的服事板块让您可以浏览志愿服事机会，并报名教会的各个职位。除了查看您被分配的计划和礼拜流程外，您现在还可以自行选择需要人手的职位。

</div>

## 您可以做什么 {#what-you-can-do}

- **浏览志愿服事机会** -- 查看即将举行的礼拜计划中需要志愿者的空缺职位。
- **报名职位** -- 选择一个职位，一键即可为自己报名。
- **查看您的计划** -- 查看您即将进行和过往的[服事安排](../plans/viewing-plans.md)。
- **回复安排** -- 在计划页面或主页的**您正在服事**板块中接受或拒绝您被排班的职位。如果您接受后计划有变，可以在礼拜结束前[拒绝已接受的安排](../plans/viewing-plans.md#declining-an-accepted-assignment)。
- **取消报名** -- 如果您的计划有变，可以在截止日期前取消自行报名的职位。

## 运作方式 {#how-it-works}

教会管理员会创建礼拜计划，并将某些职位标记为可供自行报名。这些计划会显示在教会网站的**志愿服事机会**页面上，以及成员门户中的**志愿者**页面上（在计划页面点击**报名服事**即可进入）。打开某个计划，即可查看其职位（按类别组织，例如"乐队"、"接待"或"儿童事工"），以及每个职位还剩多少空缺，然后为您有空的职位报名。

:::info
只有教会管理员开放了自行报名的职位才会出现在志愿者页面上。某些职位可能只能通过直接分配来填补。
:::
