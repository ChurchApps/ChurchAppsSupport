# 志愿者报名

<div class="article-intro">

浏览可报名的志愿岗位，并直接在 B1.church 上为即将举行的聚会报名。岗位按类别分组，方便您快速找到需要帮助的地方并加入团队。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 一个 B1.church 账户——您必须登录才能报名
- 您的教会管理员必须至少为一个岗位开启了自助报名

</div>

## 浏览可报名的岗位

1. 进入您教会 B1.church 网站上的**志愿者**页面。
2. 您将看到一份列表，其中包含有开放志愿岗位的即将举行的服事计划。每个计划内，岗位按类别排列，然后按名称排序。如果您的教会只显示每种计划类型的下一周，则后续几周会在本周结束后才会出现。
3. 每个计划都会显示**计划名称**、**服事日期**和**服事时间**。服事日期是计划的实际日历日期，与您所在的时区无关。

岗位按类别分组（例如"乐队"、"接待"、"儿童事工"）。每个岗位显示：

- **岗位名称** -- 您将担任的角色（例如"鼓手"、"迎宾员"、"咖啡服务员"）。
- **描述** -- 如果管理员提供了岗位的详细信息，将在此显示。
- **可用名额** -- 进度条，显示已填补和剩余的名额数量。
- **已报名人员** -- 如果您的教会为某计划开启了报名页面的**显示志愿者姓名**，则会显示"已报名："一行，列出已在该岗位服事的人员姓名。仅当您登录后才会显示姓名。

## 报名

1. 找到您想要参与服事的岗位。
2. 点击该岗位旁边的**报名**按钮。
3. 会出现确认消息："您已报名！感谢您的志愿服事。"
4. 该岗位将显示绿色标识，确认您已报名。

:::info
您必须登录才能报名。如果您未登录，系统会先提示您登录。
:::

## 取消报名

如果您的计划有变，无法继续服事：

1. 找到您已报名的岗位——它会显示绿色的"您已报名"标识。
2. 点击**移除**按钮。
3. 确认您要将自己从该岗位移除。
4. 会出现消息确认："您已从此岗位移除。"

## 截止时间

您的教会管理员可能会为每个计划设置报名截止时间。截止时间是在计划第一个服事时间之前的固定小时数——例如，对于上午10:00的聚会，设置2小时的截止时间，则报名将于当天上午8:00关闭。截止时间过后：

- 您无法报名新的岗位。
- 您无法取消已有的报名。
- 计划顶部会显示一条消息，表明报名截止时间已过。

## 岗位名额

每个岗位的名额都是有限的。当所有名额都已满时：

- 该岗位会显示为**已满**。
- 报名按钮将被禁用。
- 如果有人取消报名，名额将重新空出。

:::tip
请定期查看志愿者页面，尤其是在本周初。热门岗位很快就会报满，因此尽早报名可以让您有更多选择。
:::
