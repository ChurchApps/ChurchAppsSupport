# 志愿者报名

<div class="article-intro">

浏览可用的志愿者职位，并直接在 B1.church 上为自己报名即将举行的礼拜。职位按类别组织，方便您快速找到需要帮助的地方并加入团队。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 需要一个 B1.church 账户 -- 您必须登录才能报名
- 教会管理员必须已至少为一个职位开放自行报名

</div>

## 浏览可报名的职位 {#browsing-available-positions}

1. 进入您教会 B1.church 网站上的**志愿者机会**页面（`/volunteer`）。在成员门户中，请在**计划**页面点击**报名服事**，以打开**志愿者**页面。
2. 您将看到一份列表，其中包括有开放志愿者职位的即将举行的礼拜计划。如果您的教会只显示每种计划类型的下一周，那么当前一周过去后，之后的几周才会出现。
3. 每个计划都会显示**计划名称**、**礼拜日期**和**礼拜时间**、还有多少空缺（或**已满**），以及已填补职位的进度条。礼拜日期是计划的实际日历日期，无论您在哪个时区查看。在网站上，每个开放的职位都会列出其剩余空缺数；在成员门户中，点击**有空缺**可隐藏已满的计划。
4. 在网站上点击**查看并报名**（或在成员门户中点击计划）即可查看其职位。

在一个计划内，职位会按类别分组（例如"乐队"、"接待"、"儿童事工"），然后按名称排列。每个职位会显示：

- **职位名称** -- 您将担任的角色（例如"鼓手"、"迎宾"、"咖啡服务员"）。
- **说明** -- 如果管理员提供了角色的详细信息。
- **可用名额** -- 已填补和剩余的名额数（例如网站上的"剩余 2 / 2 个名额"，或成员门户中的"已填补 0 / 2"）。
- **已报名人员** -- 如果您的教会为该计划开启了**在报名页面显示志愿者姓名**，则会显示一行"已报名："，列出已在该职位服事的人员姓名。只有在您登录后才会显示姓名。

## 报名 {#signing-up}

1. 找到您想服事的职位。
2. 点击该职位旁边的**报名**按钮。
3. 会出现确认信息："您已报名成功！感谢您的志愿服事。"（在成员门户中为："您已报名成功！"）。
4. 该职位会显示一个绿色的**您已报名**标签（在成员门户中为**已报名**）以及一个**移除**按钮。

:::info
您必须登录才能报名。如果您未登录，页面会显示"请登录以报名职位。"并附带登录链接，**报名**按钮也将被禁用。
:::

## 取消报名 {#removing-a-signup}

如果您的计划有变，无法再继续服事：

1. 找到您已报名的职位 -- 它会显示一个绿色的"您已报名"标签。
2. 点击**移除**按钮。
3. 在**要移除自己吗**？对话框中（在成员门户中为**取消报名？**），点击**移除**确认。
4. 系统会显示确认信息："您已从此职位中移除。"（在成员门户中为："您的报名已取消。"）。

## 截止日期 {#deadlines}

教会管理员可以为每个计划设置报名截止日期。截止日期为计划第一场礼拜时间之前的固定小时数 -- 例如，对于上午 10:00 的礼拜设置 2 小时截止，则当天上午 8:00 报名即告截止。截止日期过后：

- 您无法报名新的职位。
- 您无法取消现有的报名。
- 计划顶部会显示提示"此计划的报名截止日期已过。"（在成员门户中为："报名截止日期已过。"）。

## 职位名额 {#position-capacity}

每个职位的名额都是有限的。当所有名额都已填满时：

- 该职位的按钮会显示**已满**并被禁用。
- 在网站上，该职位会显示"全部 2 个名额已满"（并标明名额数）。
- 如果有人取消报名，名额会重新开放。

:::tip
请定期查看志愿者页面，尤其是在每周初。热门职位很快就会被报满，因此越早报名，选择的余地就越大。
:::
