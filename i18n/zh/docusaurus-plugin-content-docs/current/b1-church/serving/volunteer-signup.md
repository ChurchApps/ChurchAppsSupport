# 志愿者报名

<div class="article-intro">

浏览可用的志愿者职位，并直接通过 B1.church 为即将举行的礼拜报名。职位按类别组织，方便您快速找到需要帮助的地方并加入团队。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 需要一个 B1.church 账户——报名前必须登录
- 教会管理员必须至少为一个职位开启自主报名

</div>

## 浏览可报名的职位

1. 进入您教会 B1.church 网站上的**志愿者（Volunteer）**页面。
2. 您将看到一份即将举行的服事计划列表，这些计划都有空缺的志愿者职位。在每个计划中，职位按类别排列，同类别内再按名称排序。如果您的教会只显示每种计划类型的下一周，那么当前一周过去后，之后的周次才会出现。
3. 每个计划都会显示**计划名称**、**礼拜日期**和**礼拜时间**。

职位按类别分组（例如“Band”（乐队）、“Hospitality”（接待）、“Kids Ministry”（儿童事工））。每个职位会显示：

- **职位名称** -- 您将担任的角色（例如“Drummer”（鼓手）、“Greeter”（迎宾）、“Coffee Server”（咖啡服务员））。
- **描述** -- 如果管理员提供了相关信息，这里会显示该角色的详情。
- **可报名名额** -- 进度条，显示已填补和剩余的名额数量。
- **已报名人员** -- 如果您的教会为该计划开启了**在报名页面显示志愿者姓名**，则会显示“Signed up:”（已报名：）一行，列出已在该职位服事的人员姓名。只有在您登录后才会显示姓名。

## 报名

1. 找到您想要参与服事的职位。
2. 点击该职位旁边的 **Sign Up**（报名）按钮。
3. 系统会显示确认信息：“You're signed up! Thank you for volunteering.”（您已报名成功！感谢您的志愿服事。）
4. 该职位会显示绿色标记，确认您已报名。

:::info
您必须登录才能报名。如果您未登录，系统会先提示您登录。
:::

## 取消报名

如果您的计划有变，无法继续服事：

1. 找到您已报名的职位——它会显示绿色的“You're signed up”（您已报名）标记。
2. 点击 **Remove**（移除）按钮。
3. 确认您要将自己从该职位中移除。
4. 系统会提示：“You have been removed from this position.”（您已从该职位中移除。）

## 截止时间

您的教会管理员可能会为每个计划设置报名截止时间。截止时间为礼拜日期之前的若干小时。截止时间过后：

- 您无法再报名新的职位。
- 您无法取消已有的报名。
- 计划顶部会显示提示，说明报名截止时间已过。

## 职位名额

每个职位的名额都是有限的。当所有名额都已满时：

- 该职位会显示为 **Full**（已满）。
- 报名按钮会被禁用。
- 如果有人取消报名，名额会重新开放。

:::tip
请定期查看志愿者页面，尤其是每周初。热门职位很快就会报满，因此尽早报名可以获得更多选择。
:::
