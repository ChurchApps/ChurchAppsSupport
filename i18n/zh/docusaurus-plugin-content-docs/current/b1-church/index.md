# B1.church

<div class="article-intro">

B1.church 是面向教会成员的门户网站。会众可以在这里保持联系、使用教会工具，并在一周之中与教会社群保持互动。每个教会都拥有专属网址 `https://yourchurchname.b1.church`。

</div>

会员访问您的 B1.church 网站时，会看到带有教会品牌形象、导航链接和内容页面的公开网站。登录后，他们可以进入**会员门户（Member Portal）**，所有个人教会工具都集中在此处。

## 主要功能

- **首页和我的** -- 会员门户会打开[首页仪表板](./getting-started/navigating.md)，预览您即将进行的服事安排、小组以及今年的奉献情况；[“我的”页面](./getting-started/me-page.md)则列出您即将参与的内容——服事安排、活动报名、小组活动——以及您最近的通知。
- **小组** -- 查看您所属的小组，查看小组成员，参与对话，并记录考勤。
- **奉献** -- 在线向教会奉献，并查看您的奉献历史。
- **活动** -- 浏览即将举行的活动，并为您自己和家人报名。
- **服事** -- 查看服事计划、您的志愿者职位，并报名参加开放的志愿服事机会。您可以在[通知偏好设置](./getting-started/notification-preferences.md)中选择通过短信接收服事和活动提醒（随时回复 STOP 即可取消）。
- **计划** -- 查看即将举行的服事计划，接受或婉拒您被分配的职位，并查看诗歌详情和礼拜程序。
- **签到** -- 为您自己和家庭成员办理礼拜和活动签到。访客可以通过二维码完成登记。
- **社区名录** -- 浏览教会的会员名录、查看个人资料，并发送私信。您可以在[个人资料的隐私部分](./getting-started/editing-your-profile.md#privacy)中控制谁能看到您自己的联系信息。
- **内容** -- 在教会网站上观看讲道、阅读圣经、收看直播，并查看每日经文。（课程播放现已转移至 [FreePlay](/docs/freeplay/)——会员门户中的“课程”标签页已停用。）
