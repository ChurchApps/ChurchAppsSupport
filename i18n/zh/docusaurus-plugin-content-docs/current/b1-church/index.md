# B1.church

<div class="article-intro">

B1.church 是您教会面向成员的门户网站。会众可以在这里保持联系、使用教会的各项工具，并在一周中与社区互动。每个教会都拥有自己的网址，格式为 `https://yourchurchname.b1.church`。

</div>

当成员访问您的 B1.church 网站时，他们会看到带有您教会品牌标识、导航链接和内容页面的公开网站。登录后，他们可以进入**成员门户**，在这里集中使用所有个人的教会工具。

## 主要功能

- **主页和我的** -- 成员门户会打开[主页仪表板](./getting-started/navigating.md)，展示您即将进行的服事安排、您所在的小组以及您今年的奉献情况；[我的页面](./getting-started/me-page.md)则列出您即将参与的事项——服事安排、活动报名、小组活动——以及您最近的通知、您提交的表单和出勤历史。
- **小组** -- 查看您所属的小组，查看小组成员，参与对话，记录出勤，并填写与您小组关联的表单（负责人可以阅读和打印答复内容）。
- **奉献** -- 在线向教会捐款，并查看您的奉献历史和证明，即使您的教会不接受在线奉献也可以使用。
- **活动** -- 浏览即将举行的活动，为您自己和家人报名。
- **服事** -- 查看服事计划、您的志愿岗位，并报名参加开放的志愿者机会。您可以在[通知偏好设置](./getting-started/notification-preferences.md)中选择通过短信接收服事和活动提醒（随时回复 STOP 即可取消）。
- **计划** -- 查看即将举行的服事计划，接受或拒绝您被分配的岗位，并查看歌曲详情和礼拜流程。
- **签到** -- 为您自己和家庭成员办理服事或活动的签到。访客可以通过二维码进行登记。
- **社区通讯录** -- 浏览教会的成员通讯录，查看个人资料，并发送私信。在您个人资料的[隐私部分](./getting-started/editing-your-profile.md#privacy)中，可控制谁能看到您的联系信息。
- **内容** -- 从教会网站访问讲道、阅读圣经、观看直播，并查看、分享或下载每日经文（以及往期经文）。（课程播放功能现已转移至 [FreePlay](/docs/freeplay/)——门户内的课程标签页已弃用。）
