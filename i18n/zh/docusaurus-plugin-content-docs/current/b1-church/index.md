# B1.church

<div class="article-intro">

B1.church 是您教会的面向成员的门户。这是您的会众去保持联系、访问教会工具并在整周参与您的社区的地方。每个教会都获得自己的 URL：`https://yourchurchname.b1.church`。

</div>

当成员访问您的 B1.church 网站时，他们会看到您教会的公开网站，包括您的品牌、导航链接和内容页面。登录后，他们可以访问**成员门户**，其中所有个人教会工具都集中在一个地方。

## 主要功能

- **首页和我的** -- 成员门户在[首页仪表板](./getting-started/navigating.md)上打开，[我的页面](./getting-started/me-page.md)列出您即将发生的事情 -- 服侍分配、事件注册、小组事件 -- 以及您最近的通知。
- **小组** -- 查看您所属的小组、查看小组成员、参与对话并跟踪参与。
- **奉献** -- 在线向您的教会捐款并查看您的奉献历史。
- **事件** -- 浏览即将举行的事件并注册您自己和您的家人。
- **服侍** -- 查看服侍计划、您的志愿者职位并注册开放的志愿者机会。
- **计划** -- 查看即将举行的服侍计划、查看您指派的职位并访问歌曲详情和服侍顺序。
- **签到** -- 为服务和事件签到您自己和您的家庭成员。访客可以通过二维码注册。
- **社区目录** -- 浏览您教会的成员目录、查看资料并发送直接消息。从您的[档案隐私选项卡](./getting-started/editing-your-profile.md#privacy-tab)控制谁可以看到您自己的联系信息。
- **内容** -- 从您教会的网站访问讲道、阅读圣经、观看直播和查看每日经文。（课程播放现在位于[FreePlay](/docs/freeplay/) -- 门户内的课程选项卡已弃用。）
