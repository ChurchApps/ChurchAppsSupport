# 编辑您的个人资料

<div class="article-intro">

您在成员门户中的个人资料页面可用于更新联系信息、管理家庭成员、更改账户邮箱和密码，并控制谁可以查看您的地址、电话号码和电子邮箱。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要[登录](./logging-in.md)——编辑个人资料需要账户

</div>

## 打开个人资料

点击顶部应用栏中的个人头像，或在**更多**页面或您的[我的页面](./me-page.md)顶部点击**编辑个人资料**，即可打开位于 `/mobile/profileEdit` 的**您的个人资料**。该页面由多个部分组成——**照片和姓名**、**联系方式**、**家庭**、**账户**和**隐私**——每个部分都显示您的当前信息，并带有**编辑**链接（或**添加家庭成员** / **更改**），点击后可打开面板进行修改。

## 照片和姓名以及联系方式

这些部分包含您的教会在您的个人记录中看到的信息：

- **照片和姓名** —— 点击**更改照片**上传新图片，并编辑您的名、中间名和姓。
- **联系方式** —— 电子邮箱、手机、家庭电话、工作电话、出生日期以及您的地址（街道、城市、省/州和邮编）。如果您在[通知偏好设置](./notification-preferences.md)中开启了短信提醒，提醒将发送至您的手机号码。

在面板中进行修改后，点击**保存更改**。

:::info
如果您所在的教会要求审批通讯录更改，页面将显示"对个人资料的更改将提交教会工作人员审批。"，按钮显示为**提交审批**——您的修改将作为请求提交，而不会立即生效。有关教会如何审核这些更改，请参阅[审批个人资料更改](/docs/b1-admin/profile/approving-profile-changes)。
:::

## 家庭

"家庭"部分显示与您的家庭相关联的其他成员，每位成员都带有其家庭角色（户主、配偶、子女等）。点击某位家庭成员即可查看其详细信息。

如需添加尚未在系统中的家庭成员，请点击**添加家庭成员**，输入其名字，然后点击**添加**。新添加的家庭成员将进入待处理列表，并与您的其他个人资料更改一起提交，由教会进行审核。

## 账户

"账户"部分管理的是您的登录信息，而非教会个人资料。点击**编辑**即可打开：

- **显示名称** —— 登录时显示的名和姓（与教会个人资料中的姓名分开）。
- **更改邮箱** —— 更新您用于登录的邮箱地址。
- **更改密码** —— 输入当前密码，然后两次输入新密码。新密码长度必须至少为8个字符。

每个部分都有各自的**保存**按钮。

## 隐私

"隐私"部分显示谁可以查看您在 ChurchApps 中的联系信息。点击**更改**打开**可见性偏好设置**：

- **对成员通讯录隐藏我** —— 一个开关，可将您从[成员通讯录](../community/member-directory.md)中完全移除。
- **地址可见性**、**电话可见性**和**邮箱可见性** —— 每项都有各自的下拉菜单，例如，您可以让全体教会成员看到您的邮箱，同时对地址保持更私密的设置。可选项如下：

| 级别 | 可查看的人 |
|---|---|
| **所有人** | 任何可以查看通讯录的人。 |
| **仅限会员** | 其他已登录的教会成员。 |
| **仅限我的小组** | 仅您所属小组的成员。 |
| **仅限我的小组负责人和工作人员** | 仅教会工作人员以及您所属小组的负责人。 |
| **仅限工作人员** | 仅教会工作人员（具有"工作人员"会员身份状态或"人员"查看权限的人）。 |

点击**保存**以应用您的选择。您的教会会为这三个字段设置默认值——请参阅[移动应用设置](/docs/b1-admin/settings/mobile-app)——但您在此处的任何选择都会覆盖您个人记录的默认值。

:::tip
无论这些设置如何，您始终可以看到自己的信息，具有"人员"查看权限的工作人员也始终可以看到。
:::
