# 编辑您的个人资料

<div class="article-intro">

会员门户中的个人资料页面可让您更新联系信息、管理家庭成员、更改账户邮箱和密码，并控制哪些人可以查看您的地址、电话号码和电子邮件地址。

## 打开您的个人资料

点击顶部应用栏中的个人资料照片，或点击**更多**页面顶部或[我的页面](./me-page.md)上的**编辑个人资料**，即可打开位于 `/mobile/profileEdit` 的**您的个人资料**。该页面是由多个分区组成的单页，分别为**照片和姓名**、**联系方式**、**家庭**、**账户**和**隐私**。每个分区都显示您的当前信息，并带有**编辑**链接（或**添加家庭成员**/**更改**），点击后会打开一个面板，您可以在其中进行更改。

## 照片、姓名与联系方式

这些分区包含您的教会在您的个人记录中看到的信息：

- **照片和姓名** — 点击**更改照片**上传新图片，并编辑您的**称谓**以及名字、中间名和姓氏。对于**称谓**，可以从建议项中选择（Mr、Mrs、Miss、Ms、Dr、Prof、Rev 或 Pastor），也可以自行输入，最多 10 个字符。
- **联系方式** — 电子邮件、手机号码、家庭电话、工作电话、出生日期，以及您的地址（街道、城市、州/省和邮政编码）。如果您在[通知偏好设置](./notification-preferences.md)中开启了短信提醒，提醒将发送到您的手机号码。

在面板中进行更改后，点击**保存更改**。

:::info
如果您所在的教会要求目录更改需经批准，页面会显示“对您个人资料的更改将提交给教会工作人员审批。”，按钮则显示为**提交审批**。此时您的编辑内容将作为请求提交，而不会立即生效。有关教会如何审核这些更改，请参阅[批准个人资料更改](/docs/b1-admin/profile/approving-profile-changes)。
:::

## 家庭

家庭分区显示与您的家庭相关联的其他人员，并标明每人的家庭角色（户主、配偶、子女等）。点击某位家庭成员即可查看其详细信息。

要添加系统中尚不存在的家庭成员：

1. 点击**添加家庭成员**。
2. 输入其**名字**。**姓氏**默认填入您的姓氏；如果对方的姓氏不同，请加以更改。
3. 可选择填写其**称谓**和**手机号码**。
4. 选择其**家庭角色**：**户主**、**配偶**、**子女**或**其他**（默认选项）。
5. 点击**添加**。该成员会出现在**待添加的家庭成员**下，并显示其角色；如需将某人从列表中移除，请点击**移除**。如需添加其他人员，请重复上述步骤。
6. 点击**保存更改**（或**提交审批**）。

如果您所在的教会需要审核目录更改，新添加的家庭成员将与您的其他更改一并提交，等待教会批准。否则，家庭成员会在您保存后立即添加到您的家庭中。

## 账户

账户分区用于管理您的登录信息，而非教会个人资料。点击**编辑**即可打开该分区：

- **显示名称** — 登录时显示的名字和姓氏（与教会个人资料上的姓名分开设置）。
- **更改邮箱** — 更新您用于登录的电子邮件地址。
- **更改密码** — 输入当前密码，然后两次输入新密码。新密码长度至少为 8 个字符。

每个部分都有各自的**保存**按钮。

## 隐私

隐私分区显示谁可以查看您在 ChurchApps 中的联系信息。点击**更改**即可打开**可见性偏好设置**：

- **对会员目录隐藏我** — 一个开关，开启后会将您从[会员目录](../community/member-directory.md)中完全移除。
- **地址可见性**、**电话可见性**和**电子邮件可见性** — 每项都有独立的下拉菜单，例如，您可以让全体教会成员都能看到您的电子邮件，同时将地址设置得更加私密。可选项如下：

| 级别 | 可见范围 |
|---|---|
| **所有人** | 任何可以查看目录的人都可以看到。 |
| **仅限会员** | 其他已登录的教会会员可以看到。 |
| **仅限我的小组** | 仅您所属小组的成员可以看到。 |
| **仅限我的小组负责人和工作人员** | 仅教会工作人员以及您所属小组的负责人可以看到。 |
| **仅限工作人员** | 仅教会工作人员可以看到（即具有“工作人员”会员身份或“人员”查看权限的人员）。 |

点击**保存**以应用您的选择。教会会为这三个字段各设定一个默认值，请参阅[移动应用设置](/docs/b1-admin/settings/mobile-app)；但您在此处所做的选择将覆盖您个人记录上的默认值。

:::tip
无论这些设置如何，您始终可以查看自己的信息；具有“人员”查看权限的工作人员也始终可以查看。
:::
