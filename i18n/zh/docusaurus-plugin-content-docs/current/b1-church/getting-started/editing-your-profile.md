# 编辑您的个人资料 {#editing-your-profile}

<div class="article-intro">

成员门户中的个人资料页面可让您更新联系信息、管理家庭成员、更改账户邮箱和密码，并控制谁可以查看您的地址、电话号码和电子邮件地址。

## 打开您的个人资料 {#opening-your-profile}

点击顶部应用栏中的个人头像，或点击**更多**页面或[我的页面](./me-page.md)顶部的**编辑个人资料**，即可打开位于 `/mobile/profileEdit` 的**您的个人资料**。该页面由多个板块组成 -- **照片与姓名**、**联系方式**、**家庭**、**账户**和**隐私** -- 每个板块都显示您当前的信息，并带有**编辑**链接（或**添加家庭成员**/**更改**），点击后会打开一个面板供您进行修改。

## 照片与姓名及联系方式 {#photo--name-and-contact}

这些板块包含教会在您的个人记录中看到的信息：

- **照片与姓名** -- 点击**更改照片**上传新图片，并编辑您的**称谓**、名字、中间名和姓氏。**称谓**可从建议项中选择（先生、太太、小姐、女士、博士、教授、牧师或牧者），也可以自行输入，最多 10 个字符。
- **联系方式** -- 电子邮件、手机、家庭电话、工作电话、出生日期，以及您的地址（街道、城市、州/省和邮编）。如果您在[通知偏好设置](./notification-preferences.md)中开启了短信提醒，提醒将发送至您的手机号码。

在面板中完成修改后，点击**保存更改**。

:::info
如果您的教会要求对名录信息的更改进行审批，页面会显示"您的个人资料更改将提交给教会工作人员审批。"，按钮会显示为**提交审批** -- 您的修改将作为请求提交，而不是立即生效。关于教会如何审核这些更改，请参阅[审批个人资料更改](/docs/b1-admin/profile/approving-profile-changes)。
:::

## 家庭 {#household}

家庭板块显示与您的家庭相关联的其他人，每人都带有其家庭角色（户主、配偶、子女等）。点击某位家庭成员即可查看其详细信息。

若要添加尚未在系统中的家庭成员：

1. 点击**添加家庭成员**。
2. 输入其**名字**。**姓氏**默认填入您的姓氏；如果对方的姓氏不同，请予以更改。
3. 可选择填写其**称谓**、**电子邮件**和**手机**。
4. 选择其**家庭角色**：**户主**、**配偶**、**子女**或**其他**（默认）。
5. 可选择点击**添加照片**，选择其照片（点击**更改照片**可选择其他照片）。
6. 点击**添加**。该成员会显示在**待处理的家庭成员**下，并带有其角色和电子邮件；点击**删除**可将其从列表中移除。如需添加其他人，请重复此操作。
7. 点击**保存更改**（或**提交审批**）。

如果您的教会审核名录更改，新增的家庭成员会与您的其他更改一同提交，等待教会审批。否则，他们会在您保存后立即添加到您的家庭中。

## 账户 {#account}

账户板块管理您的登录信息，而非教会个人资料。点击**编辑**即可打开：

- **显示名称** -- 登录时显示的名字和姓氏（与您教会个人资料中的姓名分开）。
- **更改邮箱** -- 更新您用于登录的电子邮件地址。
- **更改密码** -- 输入当前密码，然后两次输入新密码。新密码必须至少为 8 个字符。

每个部分都有各自的**保存**按钮。

## 隐私 {#privacy}

隐私板块显示谁可以在整个 ChurchApps 中查看您的联系信息。点击**更改**打开**可见性偏好设置**：

- **对成员名录隐藏我** -- 一个开关，可将您从[成员名录](../community/member-directory.md)中完全移除。
- **地址可见性**、**电话可见性**和**电子邮件可见性** -- 每项都有各自的下拉菜单，例如，您可以让整个教会看到您的电子邮件，同时将地址设置得更为私密。可选项如下：

| 级别 | 可见对象 |
|---|---|
| **所有人** | 任何可以查看名录的人。 |
| **仅成员** | 其他已登录的教会成员。 |
| **仅我的小组** | 仅您所在小组的成员。 |
| **仅我的小组领袖与员工** | 仅教会员工及您所在小组的领袖。 |
| **仅员工** | 仅教会员工（具有员工会员身份或人员查看权限的人）。 |

点击**保存**以应用您的选择。教会会为这三个字段各自设定默认值 -- 请参阅[移动应用设置](/docs/b1-admin/settings/mobile-app)；但您在此处的选择将覆盖您个人记录的默认值。

:::tip
无论这些设置如何，您始终可以看到自己的信息；拥有人员查看权限的员工也始终可以看到。
:::
