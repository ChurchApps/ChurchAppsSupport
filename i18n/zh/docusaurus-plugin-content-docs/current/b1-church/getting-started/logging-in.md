# 登录

<div class="article-intro">

登录 B1.church 让您可以访问成员门户，您可以在其中看到对您的期望、管理小组、在线捐献以及使用您的教会设置的所有工具。本文介绍如何登录、导航您的用户菜单和登出。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 您需要一个 ChurchApps 账户。详见 [入门](../getting-started/) 创建一个。
- 您需要您的教会的 B1.church URL（例如，`https://yourchurchname.b1.church`）。

</div>

## 如何登录

1. 转到您的教会的 B1.church URL（例如，`https://yourchurchname.b1.church`）。
2. 点击标题右上角的 **登录** 按钮。
3. 输入您的 **电子邮件地址** 和 **密码**，或点击 **使用 Google 继续** 或 **使用 Microsoft 继续**（如果您的教会启用了单点登录）。
4. 点击 **登录**。

登录后，您将被带回到您点击登录前的页面。如果您在未登录时直接导航到成员门户页面，您将在登录后自动返回到该页面。

## 保持登录状态

您在同一浏览器或已安装应用上保持登录状态，直到您登出，即使您有一段时间没有访问 -- 您的会话最多保留约 30 天的非活动时间。登录一次也会在您在教会网站和成员门户 (`/mobile`) 之间移动时保持登录状态，因此您不必在每个地方都登录。

## 访问成员门户

登录后，您可以通过点击页面右上角的您的 **名字** 并从菜单中选择 **成员门户** 来访问成员门户。成员门户是所有个人教会工具的所在地，包括您的 [主页仪表板](./navigating.md)、[我的页面](./me-page.md)、[小组](../groups/)、[捐献](../giving/) 等。

## 您的用户菜单

登录后，您的名字显示为右上角的芯片。点击它打开一个菜单，选项如下：

- **成员门户** -- 转到您的个人成员门户仪表板。
- **编辑档案** -- 更新您的账户设置或编辑您的教会档案。
- **登出** -- 登出您的账户。

## 管理员访问权限

如果您是具有适当权限的教会管理员，您也会在您的用户菜单中看到 **管理员门户** 选项。点击它会将您带到 B1 Admin，您可以在其中管理教会的设置、人员、小组和内容。

## 忘记密码

如果您忘记了您的密码：

1. 点击登录页面上的 **忘记密码**。
2. 输入与您的 ChurchApps 账户相关联的电子邮件地址并提交。
3. 检查您的电子邮件以获取包含 **6 位验证码** 的消息。该代码有效期为 15 分钟。
4. 在验证屏幕上输入代码以登录。
5. 登录后，访问您的档案选择新密码。

:::tip
如果代码在几分钟内没有到达，请检查您的垃圾邮件文件夹。在五次错误尝试后，代码被锁定 -- 如果发生这种情况，请从忘记密码页面请求新代码。
:::

## 登出

要登出，点击右上角的您的 **名字** 并选择 **登出**。您将被登出并返回到公开网站。
