# 登录

<div class="article-intro">

登录 B1.church 后，您就可以使用会员门户，查看您的动态、管理小组、在线奉献，并使用教会设置的所有工具。本文介绍如何登录、使用用户菜单，以及如何退出登录。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要一个 ChurchApps 账户。请参见[新手入门](../getting-started/)进行创建。
- 您需要知道教会的 B1.church 网址（例如 `https://yourchurchname.b1.church`）。

</div>

## 如何登录

1. 前往您教会的 B1.church 网址（例如 `https://yourchurchname.b1.church`）。
2. 点击页头右上角的**登录**按钮。
3. 输入您的**邮箱地址**和**密码**，或者如果您的教会启用了单点登录，可以点击**使用 Google 继续**或**使用 Microsoft 继续**。
4. 点击**登录**。

登录成功后，系统会将您带回点击登录前所在的页面。如果您在未登录状态下直接访问了会员门户的某个页面，登录后会自动返回该页面。

## 进入会员门户

登录后，点击页面右上角的**姓名**，从菜单中选择**会员门户**，即可进入会员门户。会员门户是您所有个人教会工具的集中地，包括[动态](../community/timeline.md)、[小组](../groups/)、[奉献](../giving/)等。

## 您的用户菜单

登录后，您的姓名会以标签形式显示在右上角。点击它可打开一个包含以下选项的菜单：

- **会员门户** -- 前往您的个人会员门户仪表盘。
- **编辑资料** -- 更新您的账户设置或编辑您的教会档案。
- **退出登录** -- 退出您的账户。

## 管理员权限

如果您是拥有相应权限的教会管理员，您的用户菜单中还会看到**管理员门户**选项。点击该选项会带您进入 B1 Admin，您可以在其中管理教会的设置、人员、小组和内容。

## 忘记密码

如果您忘记了密码：

1. 在登录页面点击**忘记密码**。
2. 输入与您的 ChurchApps 账户关联的邮箱地址并提交。
3. 查收您的邮箱，寻找包含**六位数验证码**的邮件。该验证码 15 分钟内有效。
4. 在验证界面输入验证码即可登录。
5. 登录成功后，前往个人资料页面设置新密码。

:::tip
如果几分钟内没有收到验证码，请检查垃圾邮件文件夹。连续输入五次错误验证码后，验证码将被锁定——如遇此情况，请在忘记密码页面重新申请。
:::

## 退出登录

要退出登录，请点击右上角的**姓名**，然后选择**退出登录**。系统会将您退出账户，并返回公开网站。
