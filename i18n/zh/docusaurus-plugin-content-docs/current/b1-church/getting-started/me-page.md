# 我的页面

<div class="article-intro">

**我**页面是会员门户中的个人仪表板——您的一切即将发生的事情的一个按时间顺序的视图：服务分配、事件注册和您的小组即将举行的事件，加上您最近的通知。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要[登录](./logging-in.md)——"我"页面仅对已登录的会员显示

</div>

## 打开"我"页面

打开门户菜单并点击**我**。页面加载时您的个人信息会被组织成多个部分。

## 即将到来

**即将到来**部分按日期顺序列出您面前的所有内容，每个项目都用类型标记标记：

- **服务** -- 您即将举行的服务计划上的志愿者职位。点击一个以打开计划。
- **注册** -- 您已[注册](../events/registering)的事件。点击进入您的[注册](../events/my-registrations)。
- **事件** -- 来自您所属小组的即将举行的事件。点击一个以打开该小组的事件。

如果没有安排任何事项，您将看到"没有即将到来的事项"——当安排您的服务时间、事件和注册时，它们将出现在此处。

## 最近通知

在"即将到来"下方，**最近通知**部分显示您最新的通知，以便您可以赶上而无需打开门户的每个区域。

## 快捷方式

**我**页面顶部的**快捷方式**部分链接到您最常访问的地方：

- **编辑个人资料** -- 见[编辑您的个人资料](./editing-your-profile.md)。
- **通知偏好设置** -- 见[通知偏好设置](./notification-preferences.md)。
- **消息** -- 您的私人对话。
- **捐赠** -- 在线捐赠并查看您的捐赠历史记录。
- **注册** -- 您已注册的事件。

如果您的教堂有可预订的房间或资源，会出现两个额外的快捷方式：

- **申请活动** -- 要求举办需要您需要的房间和设备的活动。见[申请活动和房间](../events/requesting-events)。
- **我的申请** -- 跟踪您的申请状态并取消待处理的申请。

如果您的教堂还没有设置房间或资源，这些快捷方式将被隐藏。
