# 我的页面

<div class="article-intro">

**我的**页面是您在成员门户中的个人仪表板——一个页面即可查看您即将参与的所有事项（服事安排、活动报名以及您所在小组的近期活动），同时还包括您的家庭、小组、奉献、已提交的表单、出勤记录、报名情况以及最近的通知。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要[登录](./logging-in.md)——"我的"页面仅对已登录的成员显示

</div>

## 打开"我的"页面

点击底部标签栏中的**更多**，然后在**账户**下点击**我的**。页面会显示您的照片、姓名和会员状态，以及两个按钮：

- **编辑个人资料** -- 参见[编辑您的个人资料](./editing-your-profile.md)。
- **设置** -- 打开您的[通知偏好设置](./notification-preferences.md)。

如果您已退出登录，将看到"登录以查看您的一周安排"以及一个**登录**按钮。

## 即将到来

**即将到来**部分按日期顺序列出您接下来的三项内容，每项都带有类型标签。如果还有更多，请点击**全部即将到来**查看完整列表，点击**返回我的**即可回到"我的"页面。

- **服事** -- 您在即将举行的服事计划中的志愿岗位，并显示您所服事的那场聚会的日期和开始时间（如果计划有多个时段，则显示您的团队需要到场的时间；如果计划没有时间，则仅显示日期）。点击可打开该计划。
- **报名** -- 您已[报名参加](../events/registering)的活动。点击可进入您的[报名记录](../events/my-registrations)。
- **活动** -- 您所在小组即将举行的活动。点击可查看该小组的活动。

如果某个活动或报名项目有照片，该行的开头会显示一张小缩略图。

如果没有任何安排，您将看到"近期无安排"——您的服事时间、活动和报名记录在安排好后会显示在此处。

## 家庭、小组和奉献

- **家庭** -- 您家庭中的其他成员。点击某个姓名可查看其个人资料，或点击**管理**从您的个人资料中编辑家庭信息。如果没有其他人与您的家庭相关联，则此部分隐藏。
- **我的小组** -- 您所属的小组。点击某个小组即可打开，或点击**全部小组**查看完整列表。
- **奉献** -- 您今年的奉献总额和奉献次数。点击**历史**打开奉献页面。如果您的教会不接受在线捐款，或教会已将成员的奉献历史限制为较早的年份或将其隐藏（参见[奉献历史](../giving/donation-history.md#if-your-church-limits-giving-history)），则此部分隐藏。

## 我的表单

**我的表单**部分列出您最近提交的表单及每份表单的提交日期。如果您尚未提交任何表单，将看到"您还没有提交任何表单。"

点击某个表单或**全部表单**即可打开**我的表单**页面，该页面按提交时间从新到旧列出您提交的表单。点击某个表单可展开查看您的答案；再次点击即可收起。您的答案在此仅供查看——如需更改，请联系您的教会。

:::info
"我的表单"会显示您自行填写的独立表单，以及与您的个人记录相关联的独立表单提交——例如，通过您的邮箱地址匹配到您的表单，或教会工作人员[转移给您](../../b1-admin/forms/managing-submissions.md#changing-the-person-on-a-submission)的表单。教会工作人员在 B1 Admin 中为您的记录填写的表单不会列出。
:::

## 我的出勤

**我的出勤**部分显示您在过去90天内的出勤次数，以及您最近的签到记录。每一行都显示小组名称（如果您签到的是某次聚会，则显示聚会名称）和日期。

点击某一行或**历史**即可打开**我的出勤**页面，该页面列出您在过去12个月内签到过的聚会和小组，并按月份分组。如果没有任何记录，您将看到"过去12个月内没有出勤记录。"

## 请求与报名

**请求与报名**部分显示您的活动报名数量，并附有**报名**链接，可用于管理报名。

如果您的教会设有可预订的房间或资源，还会显示另外两个链接：

- **申请活动** -- 申请借用您所需的房间和设备来举办活动。参见[申请活动与房间](../events/requesting-events)。
- **我的申请** -- 跟踪您的申请状态，并可取消待处理的申请。

如果您的教会尚未设置房间或资源，这些链接将隐藏。

## 收件箱

**收件箱**部分显示您最近的两条通知，方便您无需逐个打开门户的各个区域即可快速了解最新情况。点击**打开收件箱**可查看您的所有通知和消息，或点击**消息**进入您的私人对话。
