# 导航B1App

<div class="article-intro">

B1.church中的会员门户是一个优先为手机设计的网络应用，位于`/mobile`下。它适用于任何浏览器，可以安装到您的主屏幕。此页面解释了主页仪表板、底部选项卡栏、更多菜单和"我"页面。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要[登录](./logging-in.md)才能看到您的个人信息。登出的访客仍然可以浏览公开内容，如果功能需要账户，会看到**登录**按钮。

</div>

## 主页

打开`https://yourchurchname.b1.church/mobile`会将您带到**主页**仪表板`/mobile/dashboard`。主页是会员门户的登陆页面，显示：

- 带有您名字的问候
- 每日经文
- 您的教堂突出显示的任何内容的特色卡片
- **探索**工具网格，您的教堂已打开的工具——小组、捐赠、报到、讲道、计划等

点击探索中的卡片会打开该工具。如果您的教堂拥有超过仪表板上显示的工具，最后一张卡片是**更多**，它在`/mobile/more`处打开完整列表。

## 底部选项卡栏

在手机上，选项卡栏固定在屏幕底部：

- **主页** -- 始终是第一个选项卡
- 最多三个您的教堂配置的选项卡
- **更多** -- 打开导航菜单

如果您的教堂配置了超过三个选项卡，其余的不会丢失：它们出现在**更多**菜单和仪表板的探索网格中。教堂管理员在B1 Admin的**移动应用 → 导航**下设置选项卡顺序。

## 菜单

点击**更多**会打开导航菜单。在平板电脑或桌面上，同一菜单始终沿屏幕左侧可见。它包含：

- 您的名字和照片，带有**编辑个人资料**快捷方式——见[编辑您的个人资料](./editing-your-profile.md)
- **主页**和**我**
- **管理员门户** -- 仅在您在教堂有管理员权限时显示；它打开B1 Admin
- 您的教堂配置的每个选项卡，按顺序
- **安装应用** -- 在`/mobile/install`处打开[安装说明](./installing-pwa.md)
- 浅色/深色模式切换
- **登录**或**登出**
- 您的教堂名称和隐私政策链接

## 应用栏

每个屏幕顶部的栏显示：

- 屏幕标题，或主页上的教堂名称
- 当您钻进详情屏幕时的返回箭头
- 一个**钟**图标用于通知和消息，带有未读项目的徽章
- 您的**个人资料照片**，打开您在`/mobile/profileEdit`的个人资料——见[编辑您的个人资料](./editing-your-profile.md)

## 我的页面

**我**（`/mobile/me`）是您的个人中心。它列出了指向您的个人资料、[通知偏好设置](./notification-preferences.md)、消息、[捐赠](../giving/)和[注册](../events/my-registrations.md)的快捷方式，然后是您面前的内容——服务分配、事件注册和小组事件——以及您最近的通知。见[我的页面](./me-page)以获取详细信息。

如果您登出，我的页面会显示一个**登录**按钮。

## 安装到您的主屏幕

会员门户是一个渐进式网络应用。访问`/mobile/install`（或在菜单中选择**安装应用**）以获取您的设备的分步说明。安装后，它从您的主屏幕全屏打开而不需要浏览器边框。见[以应用形式安装（PWA）](./installing-pwa.md)。

## 您的教堂的公共网站

在会员门户之外，您的教堂的公共网站有自己的标题导航，带有您的管理员配置的链接——页面如[讲道](../content/sermons.md)、[圣经](../content/bible.md)、[直播](../content/live-streaming.md)和公共小组列表。在手机上，这些链接位于标题右上角的汉堡包图标后面。

:::info
您看到的选项卡和工具因教堂而异。管理员通过B1 Admin控制对会员可见的部分，因此如果您看不到此处描述的功能，您的教堂可能还没有打开它。
:::
