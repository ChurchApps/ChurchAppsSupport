# 浏览 B1App

<div class="article-intro">

B1.church 的会员门户采用侧边栏导航布局，方便您在各项工具之间切换。本页说明该导航方式在桌面端和移动端设备上的使用方法。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要先[登录](./logging-in.md)才能访问会员门户。

</div>

## 侧边栏导航

进入会员门户后，您会在屏幕左侧看到一个纵向侧边栏。该侧边栏包含门户各部分对应的标签页：

- **动态** -- 展示来自您所属小组和教会的个性化更新与讨论信息流。这是打开会员门户时默认加载的标签页。
- **我** -- 您的个人仪表盘，展示即将到来的服事安排、报名情况、小组活动以及最近的通知。请参见[我的页面](./me-page)。
- **小组** -- 查看并参与您所属的[小组](../groups/)。
- **社区** -- 浏览教会的[会员通讯录](../community/member-directory.md)。
- **计划** -- 查看即将到来的[服事计划](../plans/)以及您被分配的服事岗位。
- **签到** -- 为聚会和活动为您自己及家人[签到](../checkin/)。
- **课程**（*已弃用*） -- 门户内的课程标签页已被 [FreePlay](/docs/freeplay/) 取代，用于课堂播放。您可以直接在 [Lessons.church](https://lessons.church) 上浏览课程，或参见[课程参考页面](../content/lessons.md)了解详情。
- **奉献** -- 进行在线[捐款](../giving/)并查看您的奉献历史记录。

点击任意标签页即可切换到相应功能区。当前所在的标签页会高亮显示，让您始终清楚自己所在的位置。

:::info
您看到的标签页可能因教会启用的功能而有所不同。教会管理员通过 B1 Admin 控制会员可见的功能区。如果您没有看到某个特定的标签页，可能是您的教会尚未启用该功能。
:::

## 移动端导航

在手机、平板等较小屏幕的设备上，侧边栏会收起以节省空间。取而代之的是会员门户顶部的**菜单**按钮。点击它可打开包含所有可用标签页的列表。选择某个标签页即可导航到相应功能区，选择后菜单会自动关闭。

## 管理标签页

如果您在教会拥有管理员权限，侧边栏底部还会显示一个额外的**管理**标签页。点击它会带您进入 B1 Admin，您可以在其中管理教会的设置和数据。

## 顶部页头导航

在会员门户之外，网站主页头包含教会自定义的导航链接。这些链接由教会管理员配置，可能包括指向[讲道](../content/sermons.md)、[圣经](../content/bible.md)、[直播](../content/live-streaming.md)等内容页面的链接。在移动端，这些链接可通过页头右上角的汉堡菜单图标访问。
