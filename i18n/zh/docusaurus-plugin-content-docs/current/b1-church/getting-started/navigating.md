# 导航 B1App

<div class="article-intro">

B1.church 中的成员门户是一个位于 `/mobile` 下的手机优先网络应用。它在任何浏览器中运行，可以安装在您的主屏幕上。此页面解释了主页仪表板、底部选项卡栏、更多菜单和我的页面。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 您需要 [登录](./logging-in.md) 才能查看您的个人信息。已登出的访客仍然可以浏览公开内容，并在功能需要账户时获得 **登录** 按钮。

</div>

## 主页

打开 `https://yourchurchname.b1.church/mobile` 会将您带到 `/mobile/dashboard` 的 **主页** 仪表板。主页是成员门户的登录页面，显示：

- 带有您的名字的问候
- 每日经文
- 您的教会突出显示的内容的特色卡片
- 一个 **浏览** 网格，显示您的教会已打开的工具 -- 小组、捐献、签到、讲道、计划等

点击浏览中的卡片会打开该工具。如果您的教会拥有超过仪表板容纳的工具，最后一张卡片是 **更多**，它会在 `/mobile/more` 打开完整列表。

如果您已登出，主页显示一个 **欢迎** 标题代替问候，带有简短提示（"登录以查看您的小组、捐献等"）和一个 **登录** 按钮。您的教会可以改写此提示或隐藏它 -- 详见 [移动应用设置](../../b1-admin/settings/mobile-app.md#home-screen-sign-in-prompt)。隐藏时，您仍然可以从菜单或我的标签中登录。

## 底部选项卡栏

在手机上，一个选项卡栏固定在屏幕底部：

- **主页** -- 始终是第一个选项卡
- 您的教会配置的最多三个选项卡
- **更多** -- 打开导航菜单

如果您的教会配置了超过三个选项卡，其余的不会丢失：它们会在 **更多** 菜单和仪表板的浏览网格中出现。教会管理员在 B1 Admin 中的 **移动 → 导航** 下设置选项卡顺序。

## 菜单

点击 **更多** 打开导航菜单。在平板电脑或桌面上，同一菜单始终沿屏幕左侧可见。它包含：

- 您的名字和照片，带有 **编辑档案** 快捷方式 -- 详见 [编辑您的档案](./editing-your-profile.md)
- **主页** 和 **我的**
- **管理员门户** -- 仅在您在教会拥有管理员权限时显示；它打开 B1 Admin
- 您的教会配置的每个选项卡，按顺序
- **安装应用** -- 在 `/mobile/install` 打开 [安装说明](./installing-pwa.md)
- 一个亮/暗模式切换
- **登录** 或 **登出**
- 您的教会名称和隐私政策链接

## 应用栏

每个屏幕顶部的栏显示：

- 屏幕标题，或主页上的教会名称
- 当您深入到详细屏幕时的后退箭头
- 一个 **铃** 图标，用于通知和消息，带有未读项目的徽章
- 您的 **档案照片**，打开您的档案 `/mobile/profileEdit` -- 详见 [编辑您的档案](./editing-your-profile.md)

## 我的页面

**我的** (`/mobile/me`) 是您的个人中心。它列出了到您的档案、[通知偏好](./notification-preferences.md)、消息、[捐献](../giving/) 和 [注册](../events/my-registrations.md) 的快捷方式，后面跟随对您的期望 -- 服务分配、事件注册和小组事件 -- 以及您最近的通知。详见 [我的页面](./me-page) 了解详情。

如果您已登出，我的页面显示一个 **登录** 按钮。

## 安装到您的主屏幕

成员门户是一个渐进式网络应用。访问 `/mobile/install`（或在菜单中选择 **安装应用**）获取您的设备的分步说明。安装后，它从您的主屏幕以全屏打开，没有浏览器框架。详见 [安装为应用 (PWA)](./installing-pwa.md)。

## 您的教会的公开网站

在成员门户之外，您的教会的公开网站拥有自己的标题导航，包含您的管理员配置的链接 -- 页面如 [讲道](../content/sermons.md)、[圣经](../content/bible.md)、[直播](../content/live-streaming.md) 和公开小组列表。在手机上，这些链接位于标题右上角的汉堡包图标后面。

:::info
您看到的选项卡和工具因教会而异。管理员通过 B1 Admin 控制哪些部分对成员可见，因此如果您看不到此处描述的功能，您的教会可能没有打开它。
:::
