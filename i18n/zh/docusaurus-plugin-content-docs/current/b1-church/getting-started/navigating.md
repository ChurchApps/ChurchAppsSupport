# 导航 B1App

<div class="article-intro">

B1.church 会员门户是一个以手机为主的网页应用，位于 `/mobile` 路径下。它可以在任何浏览器中使用，也可以安装到主屏幕上。本页将介绍首页仪表板、底部标签栏、“更多”页面和“我的”页面。

## 首页 {#home}

打开 `https://yourchurchname.b1.church/mobile` 即可进入 `/mobile/dashboard` 的**首页**仪表板。首页是会员门户的着陆页。它以问候语开头（“早上好”“下午好”或“晚上好”，后面跟着您的名字）和今天的日期，之后是仅在适用时才会出现的各个区块：

- **新闻**——如果教会开启了此功能，会以照片卡片的形式显示教会最新的博客文章，并自动滑动。点击卡片即可在应用内阅读完整文章，或点击 **All news**（全部新闻）查看完整列表。每篇文章都有一个 **View on website**（在网站上查看）链接，指向教会网站上的同一篇文章——参见[主屏幕区块](../../b1-admin/settings/mobile-app.md#home-screen-sections)。
- **照片卡片**——教会为其设置了照片的标签（包括每日经文）会显示在教会名称下方的照片卡片中。根据教会的选择，它们可能以两列网格、可左右滑动的一排（也可以自动滚动）、每个名称旁带有小缩略图的列表，或三张精选卡片（网格或自动滚动的一排）的形式排列，其余的列在下方，并带有通往完整列表的 **All** 链接——参见[主屏幕卡片](../../b1-admin/settings/mobile-app.md#home-screen-tiles)。当左右滑动的一排卡片超过屏幕宽度时，其下方会出现一排圆点，指示您所在的位置；点击圆点即可跳转到对应的卡片。该排卡片会持续向前滚动，滚动到最后一张后会从第一张重新开始。每个带照片的标签都会显示在这里，即使它也占用了标签栏中的一个位置。
- **您的待办事项**——登录后，显示您最新的两项未完成任务和工作流卡片（卡片优先），并附有通往完整**My tasks**（我的任务）列表的 **All** 链接。任务和卡片在那里以及在您的[“我的”页面](./me-page.md)上都按最新排序。
- **最新讲道**——教会最新的讲道，并附有 **All sermons**（全部讲道）链接
- **每日经文**——今天的经文；点击即可打开完整的[每日经文](../content/verse-of-the-day.md)页面
- **您正在服事**——您即将到来的服事安排，并附有 **All plans**（全部计划）链接。如果有任何安排仍需您的回复，这些安排会优先显示，并附带 **Needs reply**（需要回复）标记以及 **Accept**（接受）/**Decline**（拒绝）按钮，您可以直接在首页作出回应（**Decline** 会先要求您确认）；否则，您的下一次安排会显示 **Accepted**（已接受）或 **Confirmed**（已确认）标记。点击某项安排即可打开其计划。
- **您的小组**——最多三个您所在的小组，显示其聚会时间和地点，并附有 **All groups**（全部小组）链接
- **即将举行的活动**——登录后，显示您接下来的三个小组活动和活动报名，按日期顺序合并显示，每项都带有日期和时间（如果活动有照片，还会显示缩略图）。每一行都带有 **Event**（活动，来自您所在小组的活动）或 **Registration**（报名，您已[报名参加](../events/registering.md)的活动）标签；您已报名的活动只会显示一次，即作为报名显示。点击活动即可打开其小组的活动列表，点击报名则会打开您的[报名记录](../events/my-registrations.md)。点击 **All upcoming events**（全部即将举行的活动）即可在您的[“我的”页面](./me-page.md#upcoming)上打开完整的即将举行列表，其中还包括您的服事安排和报名。
- **我的出勤**和**我的表单**——如果教会开启了这些功能，会显示您在过去 90 天内的出勤次数及最近两次到访，以及您最近两次的表单提交，并附有通往完整列表的链接。无论如何，这些内容都会显示在您的[“我的”页面](./me-page.md)上——参见[主屏幕区块](../../b1-admin/settings/mobile-app.md#home-screen-sections)。
- **奉献**——您今年的奉献总额（“Given in”加当前年份）、**Give**（奉献）按钮（仅在教会提供在线奉献时显示），以及通往您[奉献历史](../giving/donation-history.md)的 **History**（历史）链接。如果教会将会员的奉献历史限制在较早的年份，或将其隐藏，则此区块会被隐藏；在这种情况下，教会的奉献工具会以按钮的形式出现在 **More from**（更多来自）下方。
- **更多来自**（*您的教会*）——教会已开启、但尚未出现在标签栏或上方区块中的其他工具的按钮。您最常用的工具会排在前面。

服事、小组、出勤、表单和奉献区块仅在您已登录、教会已开启相应工具，并且有内容可显示（例如即将到来的安排或至少一个小组）时才会出现。在电脑上，首页以两栏布局显示。

如果您未登录，首页会以 **Welcome**（欢迎）标题代替问候语，并附有一段简短的提示（“Sign in to see your groups, giving, and more.”（登录后即可查看您的小组、奉献等内容。））以及 **Sign In**（登录）按钮。即使教会尚未为首页设置任何其他内容，该提示也会显示。教会可以更改此提示文字或将其隐藏——参见[移动应用设置](../../b1-admin/settings/mobile-app.md#home-screen-sign-in-prompt)。隐藏后，您仍可以从**更多**页面或**我的**页面登录。

## 底部标签栏

在手机上，标签栏固定在屏幕底部：

- **首页**——始终是第一个标签
- 教会配置的最多三个标签
- **更多**——打开“更多”页面

内置屏幕（例如小组、奉献或计划）会优先占用标签栏位置；剩余的位置则留给教会的自定义页面。只有指向外部网站的链接和每日经文永远不会获得标签位置。如果教会配置的标签超过了可容纳的数量，多余的标签也不会丢失：它们会显示在**更多**页面和首页的**更多来自**区块中。教会管理员在 B1 Admin 的 **Mobile → Navigation**（移动端 → 导航）中设置标签顺序。

### 文件夹标签 {#folder-tabs}

教会可以将多个标签组合到一个**文件夹**中。文件夹与其他标签一样显示——在标签栏、“更多”页面或首页的照片卡片中——点击它会打开一个以文件夹名称为标题的屏幕，列出其中的标签。如果文件夹中的每个标签都有照片，则会以照片卡片的形式显示；否则会以列表形式显示。文件夹中指向外部网站的链接会在新的浏览器标签页中打开。文件夹中的标签只会出现在文件夹自己的屏幕上，不会出现在标签栏或“更多”页面上。如果文件夹中没有您可以看到的内容，该文件夹会被隐藏。

## 在电脑上

在较宽的屏幕上（例如电脑或大屏平板），底部标签栏会被替换为屏幕顶部的一条标题栏，颜色与教会主题色一致。它会显示教会的徽标（如果没有设置徽标，则显示教会名称；点击即可返回首页）、**Home**（首页）、教会配置的最多五个标签，以及 **More**（更多），右侧是通知铃铛和您的头像。当您打开详情页面时，页面内容上方会出现 **Back**（返回）链接。

## “更多”页面 {#the-more-page}

点击**更多**即可打开位于 `/mobile/more` 的“更多”页面。它包含：

- 您的姓名和照片，以及 **Edit Profile**（编辑个人资料）链接——参见[编辑您的个人资料](./editing-your-profile.md)
- 教会配置的所有标签，按顺序列在教会名称下方。指向外部网站的链接会在新的浏览器标签页中打开。
- **Account**（账户）部分，包括：
  - **Me**（我的）——您的个人页面（仅限已登录用户）
  - **Appearance**（外观）——在 **Light Mode**（浅色模式）和 **Dark Mode**（深色模式）之间切换
  - **Admin Portal**（管理门户）——仅在您在教会拥有管理员权限时显示；它会在新标签页中打开 B1 Admin
  - **Install App**（安装应用）——打开位于 `/mobile/install` 的[安装说明](./installing-pwa.md)（应用安装后隐藏）
- **Sign out**（退出登录），或在您未登录时显示 **Sign In**（登录）按钮
- 教会名称以及隐私政策链接

## 应用栏

在手机上，每个屏幕顶部的栏会显示：

- 首页和其他主要屏幕上的教会徽标（如果教会未上传徽标，则显示教会名称），或在您进入某个详情屏幕时显示返回箭头。屏幕标题显示在页面本身的顶部。
- 用于通知和消息的**铃铛**图标，并带有未读项目的徽章——参见下文[通知与消息](#notifications-and-messages)
- 您的**头像**，点击即可在 `/mobile/profileEdit` 打开您的个人资料——参见[编辑您的个人资料](./editing-your-profile.md)

只有在您登录时，铃铛和头像才会显示。

## 通知与消息 {#notifications-and-messages}

点击铃铛会打开一个面板，包含两个部分：

- **Messages**（消息）——您最近的私人对话，并附有用于发起新对话的 **New message**（新消息）链接
- **Notifications**（通知）——您最近的通知，未读的通知带有 **New**（新）标记。点击通知即可前往其所对应的小组、计划或对话。

每个部分都会显示其中的未读项目数量。点击底部的 **See all**（查看全部），即可打开位于 `/mobile/notifications` 的完整收件箱。

## 包含分区的页面

详情页面——例如小组、计划、您的“我的”页面，以及计划和奉献屏幕——都以分区的形式排列，而不是标签页。每个分区都会显示简短的预览，分区标题中的链接（例如 **All members**（全部成员）、**All events**（全部活动）或 **Full service order**（完整服事流程））会打开完整列表。该视图顶部的 **Back to**（返回）链接会带您回到来源页面。

## “我的”页面

**Me**（我的，`/mobile/me`）是您的个人中心。它会显示您的姓名和照片，并附有 **Edit Profile**（编辑个人资料）和 **Settings**（设置）（[通知偏好](./notification-preferences.md)）按钮，然后显示即将到来的内容——服事安排、活动报名和小组活动——接着是您的家庭、您的小组、您今年的[奉献](../giving/index.md)、您提交过的表单、您的出勤历史、您的[报名记录](../events/my-registrations.md)，以及您最近的通知和消息。详情请参见[“我的”页面](./me-page.md)。

如果您未登录，“我的”页面会显示 **Sign In**（登录）按钮。

## 安装到主屏幕

会员门户是一个渐进式 Web 应用（PWA）。访问 `/mobile/install`（或在“更多”页面选择 **Install App**（安装应用）），即可获取适用于您设备的分步说明。安装后，它会从主屏幕以全屏方式打开，不带浏览器界面。参见[将应用安装为 PWA](./installing-pwa.md)。

## 教会的公开网站

在会员门户之外，您教会的公开网站有自己的顶部导航，其中的链接由管理员配置——例如[讲道](../content/sermons.md)、[圣经](../content/bible.md)、[直播](../content/live-streaming.md)页面，以及公开的小组列表。在手机上，这些链接位于页眉右上角的汉堡菜单图标后面。

:::info
不同教会可见的标签和工具各不相同。管理员通过 B1 Admin 控制会员可以看到哪些板块，因此如果您没有看到此处描述的某项功能，可能是您的教会未开启该功能。
:::
