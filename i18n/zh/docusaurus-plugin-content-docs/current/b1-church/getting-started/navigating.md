# 浏览 B1App

<div class="article-intro">

B1.church 的会员门户是一个以手机为主的网页应用，位于 `/mobile` 路径下。它可以在任何浏览器中使用，也可以安装到主屏幕上。本页介绍首页仪表盘、底部标签栏、更多页面和我的页面。

</div>

## 首页 {#home}

打开 `https://yourchurchname.b1.church/mobile` 会进入 `/mobile/dashboard` 的 **首页** 仪表盘。首页是会员门户的落地页。页面顶部是问候语（"早上好"、"下午好"或"晚上好"，后面跟您的名字）和今天的日期，之后是仅在适用时才会出现的各个板块：

- **照片卡片** -- 教会为某个标签页设置的照片（包括每日经文）会以照片卡片的形式显示在教会名称下方。根据教会的设置，它们可能排列为两列的网格、可左右滑动的一行（也可能自动滚动），或是每个名称旁带小缩略图的列表。请参阅[首页屏幕卡片](../../b1-admin/settings/mobile-app.md#home-screen-tiles)。当左右滑动的一行卡片超出屏幕宽度时，其下方会出现一排圆点，指示您所在的位置；点击圆点即可跳转到对应卡片。滚动到最后一张后会从第一张重新开始。即使某个照片标签页同时也占用了标签栏的位置，它仍会显示在这里。
- **最新讲道** -- 教会最新的讲道内容，并附有 **所有讲道** 链接
- **每日经文** -- 今天的经文；点击即可打开完整的[每日经文](../content/verse-of-the-day.md)页面
- **您正在服事** -- 您即将到来的服事安排，并附有 **所有计划** 链接。如果有任何安排仍需您回复，这些安排会优先显示，并带有 **需要回复** 标记以及 **接受** / **拒绝** 按钮，方便您直接在首页作出回应（点击 **拒绝** 前会要求您确认）。否则，您的下一个安排会显示 **已接受** 或 **已确认** 标记。点击某个安排即可打开对应的计划。
- **您的小组** -- 最多三个小组，显示其聚会时间和地点，并附有 **所有小组** 链接
- **即将举行的活动** -- 登录后，这里会按日期顺序列出您接下来三项小组活动和活动报名，每项都显示日期和时间（如果活动有照片，还会显示缩略图）。每一行都标有 **活动**（您所属小组的活动）或 **报名**（您已[报名](../events/registering.md)的活动）；您已报名的活动只显示一次，并以报名形式呈现。点击活动可打开其所属小组的活动页面，点击报名项目则可打开您的[报名记录](../events/my-registrations.md)。点击 **所有即将举行的活动** 可在您的[我的页面](./me-page.md#upcoming)上打开完整的即将举行列表，其中还包括您的服事安排和报名。
- **我的出席** 和 **我的表格** -- 如果教会开启了这些功能，这里会显示您在过去 90 天内的出席次数、最近两次的到访记录，以及最近两次的表格提交记录，并附有完整列表的链接。无论教会是否开启，这些内容都会显示在您的[我的页面](./me-page.md)上，请参阅[首页屏幕板块](../../b1-admin/settings/mobile-app.md#home-screen-sections)。
- **奉献** -- 您今年的奉献总额（"今年奉献"，显示当前年份），附有 **奉献** 按钮（仅当教会提供在线奉献时显示）以及通往您[奉献历史](../giving/donation-history.md)的 **历史** 链接。如果教会将会员的奉献历史限制在更早的年份或已将其隐藏，则此板块会被隐藏，教会的奉献工具会改为以按钮形式显示在 **更多来自** 之下
- **更多来自** *您的教会* -- 教会已开启、但未出现在标签栏或上方板块中的其他工具按钮。您最常使用的工具会排在最前面。

只有在您已登录、教会已开启该工具、且有内容可显示时，服事、小组、出席、表格和奉献板块才会出现。例如，您有即将到来的服事安排，或至少加入了一个小组。在电脑上，首页以两栏布局显示。

如果您未登录，首页会以 **欢迎** 标题取代问候语，并显示一段简短提示（"登录即可查看您的小组、奉献等内容。"）以及 **登录** 按钮。即使教会尚未为首页设置其他内容，该提示也会显示。教会可以修改或隐藏此提示，请参阅[移动应用设置](../../b1-admin/settings/mobile-app.md#home-screen-sign-in-prompt)。隐藏后，您仍可从 **更多** 页面或 **我的** 页面登录。

## 底部标签栏

在手机上，标签栏固定在屏幕底部：

- **首页** -- 始终是第一个标签
- 教会设置的最多三个标签
- **更多** -- 打开更多页面

内置页面（例如小组、奉献或计划）会优先占用标签位置；剩余的位置会分配给教会的自定义页面。只有指向外部网站的链接和每日经文永远不会获得标签位置。如果教会设置的标签超过了可容纳的数量，多出的标签并不会丢失：它们会显示在 **更多** 页面以及首页的 **更多来自** 板块中。教会管理员可以在 B1 Admin 中的 **移动端 → 导航** 下设置标签顺序。

### 文件夹标签 {#folder-tabs}

教会可以将多个标签归入一个 **文件夹**。文件夹与其他标签一样显示在标签栏、更多页面或首页的照片卡片中。点击文件夹会打开一个以文件夹名称为标题的页面，列出其中的标签。如果文件夹中的每个标签都有照片，它们会以照片卡片的形式显示；否则以列表形式显示。文件夹中指向外部网站的链接会在新的浏览器标签页中打开。文件夹内的标签只会出现在该文件夹的页面中，不会出现在标签栏或更多页面上。如果文件夹中没有您可以看到的内容，该文件夹将被隐藏。

## 在电脑上

在电脑或大尺寸平板等较宽的屏幕上，底部标签栏会被替换为屏幕顶部的标题栏，其颜色与教会的主题色一致。标题栏会显示教会的标志（若未设置标志，则显示教会名称；点击即可返回首页）、**首页**、教会设置的最多五个标签，以及 **更多**，右侧还有铃铛图标和您的头像。打开详情页面时，页面内容上方会出现 **返回** 链接。

## 更多页面

点击 **更多** 会打开位于 `/mobile/more` 的更多页面。该页面包含：

- 您的姓名和照片，以及 **编辑个人资料** 链接 — 请参阅[编辑您的个人资料](./editing-your-profile.md)
- 教会设置的所有标签，按顺序显示在教会名称之下。指向外部网站的链接会在新的浏览器标签页中打开。
- **账户** 板块，包括：
  - **我的** -- 您的个人页面（仅限已登录用户）
  - **外观** -- 在 **浅色模式** 和 **深色模式** 之间切换
  - **管理门户** -- 仅当您在教会拥有管理员权限时显示；点击后会在新的标签页中打开 B1 Admin
  - **安装应用** -- 打开位于 `/mobile/install` 的[安装说明](./installing-pwa.md)（应用安装后隐藏）
- **退出登录**；如果您未登录，则显示 **登录** 按钮
- 教会名称以及隐私政策链接

## 应用栏

在手机上，每个屏幕顶部的横栏会显示：

- 在首页和其他主要页面上显示教会的标志（如果教会未上传标志，则显示其名称）；当您进入详情页面时，则显示返回箭头。页面标题会显示在页面本身的顶部。
- **铃铛**图标，用于通知和消息，未读项目会显示角标 — 请参阅下方的[通知与消息](#notifications-and-messages)
- 您的**头像**，点击后会打开位于 `/mobile/profileEdit` 的个人资料页面 — 请参阅[编辑您的个人资料](./editing-your-profile.md)

铃铛和头像仅在您登录后显示。

## 通知与消息

点击铃铛会打开一个包含两个板块的面板：

- **消息** -- 您最近的私人对话，并附有 **新消息** 链接，用于发起新对话
- **通知** -- 您最近的通知，未读通知会带有 **新** 标记。点击通知即可前往其相关的小组、计划或对话。

每个板块都会显示其中未读项目的数量。点击底部的 **查看全部** 即可在 `/mobile/notifications` 打开完整的收件箱。

## 带板块的页面

详情页面 —— 例如小组、计划、我的页面，以及计划和奉献页面 —— 采用由多个板块组成的单页布局，而不是标签页。每个板块都会显示简短预览，板块标题中的链接（例如 **所有成员**、**所有活动** 或 **完整服事流程**）会打开完整列表。该视图顶部的 **返回** 链接可带您回到之前的页面。

## 我的页面

**我的**（`/mobile/me`）是您的个人中心。页面顶部显示您的姓名和照片，并附有 **编辑个人资料** 和 **设置**（[通知偏好](./notification-preferences.md)）按钮。之后依次显示您即将进行的事项，包括服事安排、活动报名和小组活动，然后是您的家庭成员、小组、今年的[奉献](../giving/index.md)、您提交过的表格、出席记录、您的[报名记录](../events/my-registrations.md)，以及最近的通知和消息。详情请参阅[我的页面](./me-page.md)。

如果您未登录，我的页面会显示 **登录** 按钮。

## 安装到主屏幕

会员门户是一个渐进式网页应用（PWA）。访问 `/mobile/install`（或在更多页面中选择 **安装应用**），即可获取适合您设备的分步说明。安装后，应用会从主屏幕全屏打开，不显示浏览器界面。请参阅[以应用形式安装（PWA）](./installing-pwa.md)。

## 教会的公开网站

在会员门户之外，教会的公开网站拥有自己的顶部导航栏，其中的链接由管理员设置，例如[讲道](../content/sermons.md)、[圣经](../content/bible.md)、[直播](../content/live-streaming.md)页面以及公开的小组列表。在手机上，这些链接位于页眉右上角的汉堡菜单图标之后。

:::info
不同教会看到的标签和工具各不相同。管理员通过 B1 Admin 控制会员可见的板块，因此如果您没有看到本文所述的某项功能，可能是您的教会尚未开启该功能。
:::
