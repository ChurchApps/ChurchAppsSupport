# 浏览 B1App

<div class="article-intro">

B1.church 的成员门户是一个以手机为主的网页应用，位于 `/mobile` 路径下。它可以在任何浏览器中使用，也可以安装到主屏幕上。本页介绍主页仪表板、底部标签栏、"更多"页面和"我的"页面。

## 主页 {#home}

打开 `https://yourchurchname.b1.church/mobile` 将进入位于 `/mobile/dashboard` 的**主页**仪表板。主页是成员门户的首页。它以问候语（"早上好"、"下午好"或"晚上好"，并附上您的名字）和今天的日期开始，随后是仅在适用时才会出现的各个部分：

- **照片图块** -- 教会为其配置了照片的标签页（包括每日经文）会以照片图块的形式显示在教会名称下方。根据教会的设置，它们会以两列网格、可左右滑动的一行（也可自动移动），或带有小缩略图的列表形式排列——参见[主页图块](../../b1-admin/settings/mobile-app.md#home-screen-tiles)。每个照片标签页都会出现在这里，即使它在标签栏中也有一个位置。
- **最新讲道** -- 教会最新的讲道，并附有**全部讲道**链接
- **每日经文** -- 今天的经文；点击即可打开完整的[每日经文](../content/verse-of-the-day.md)页面
- **您正在服事** -- 您接下来的服事安排，并附有**全部计划**链接。如果有任何安排仍需您回复，这些安排会优先显示，并带有**需要回复**标签以及**接受** / **拒绝**按钮，方便您直接在主页上回应（点击**拒绝**需要先确认）；否则，您接下来的安排会显示**已接受**或**已确认**标签。点击某个安排即可打开其计划。
- **您的小组** -- 最多三个您所在的小组，显示其聚会时间和地点，并附有**全部小组**链接
- **即将举行的活动** -- 登录后，显示您所属小组中接下来的三项活动，每项都带有日期和时间（如果活动有照片，还会显示缩略图）。点击某项活动即可打开该小组的活动。点击**全部即将举行的活动**可在您的[我的页面](./me-page.md#upcoming)上查看完整的即将举行活动列表，其中还包括您的服事安排和报名记录。
- **我的出勤**和**我的表单** -- 如果教会开启了这些功能，将显示您在过去90天内的聚会次数以及最近的两次到访，以及您最近的两份表单提交记录，并附有查看完整列表的链接。无论如何，这些内容始终会显示在您的[我的页面](./me-page.md)上——参见[主页部分](../../b1-admin/settings/mobile-app.md#home-screen-sections)。
- **奉献** -- 您今年的奉献总额（"今年已奉献"），以及**奉献**按钮（仅当教会提供在线奉献时显示）和通往您的[奉献历史](../giving/donation-history.md)的**历史**链接。如果教会已将成员的奉献历史限制为较早的年份或将其隐藏，则此部分隐藏，教会的奉献工具将以按钮形式显示在**更多来自**下方。
- **更多来自** *您的教会* -- 教会已开启但未在标签栏或上方显示的其他工具的按钮。您最常使用的工具会排在前面。

服事、小组、出勤、表单和奉献部分仅在您已登录、教会已开启该工具且您有内容可显示时才会出现——例如，有即将到来的服事安排，或至少有一个小组。在计算机上，主页以两列布局显示。

如果您未登录，主页将显示**欢迎**标题以代替问候语，并附有简短提示（"登录以查看您的小组、奉献等内容。"）和**登录**按钮。即使教会尚未为主页设置其他内容，该提示也会显示。教会可以更改此提示的措辞或将其隐藏——参见[移动应用设置](../../b1-admin/settings/mobile-app.md#home-screen-sign-in-prompt)。当提示被隐藏时，您仍可通过**更多**页面或**我的**页面登录。

## 底部标签栏

在手机上，标签栏固定在屏幕底部：

- **主页** -- 始终是第一个标签
- 教会配置的最多三个标签
- **更多** -- 打开"更多"页面

内置页面（如小组、奉献或计划）优先获得标签位置；剩余的位置则分配给教会的自定义页面。只有外部网站链接和每日经文永远不会获得标签位置。如果教会配置的标签超过了可显示的数量，多出的标签并不会丢失：它们会出现在**更多**页面以及主页的**更多来自**部分中。教会管理员可以在 B1 Admin 的**移动端 → 导航**下设置标签顺序。

## 在计算机上

在计算机或大屏平板等较宽的屏幕上，底部标签栏会被替换为屏幕顶部的标题栏，并采用您所在教会的主题色。标题栏显示教会的标志（若未设置标志，则显示教会名称；点击即可返回主页）、**主页**、教会配置的最多五个标签以及**更多**，右侧还有铃铛图标和您的头像。打开详情页面时，页面内容上方会出现**返回**链接。

## "更多"页面

点击**更多**即可打开位于 `/mobile/more` 的"更多"页面。其中包含：

- 您的姓名和照片，以及**编辑个人资料**链接——参见[编辑您的个人资料](./editing-your-profile.md)
- 教会配置的所有标签，按顺序排列在教会名称下方。指向外部网站的链接会在新的浏览器标签页中打开。
- **账户**部分，包括：
  - **我的** -- 您的个人页面（仅限登录后）
  - **外观** -- 在**浅色模式**和**深色模式**之间切换
  - **管理门户** -- 仅当您在教会拥有管理员权限时显示；点击后会在新标签页中打开 B1 Admin
  - **安装应用** -- 打开位于 `/mobile/install` 的[安装说明](./installing-pwa.md)（应用安装后隐藏）
- **退出登录**，或者在您未登录时显示**登录**按钮
- 您所在教会的名称以及隐私政策链接

## 应用栏

在手机上，每个屏幕顶部的栏显示以下内容：

- 在主页和其他主要屏幕上显示教会的标志（若教会未上传标志，则显示教会名称）；当您进入某个详情页面时，则显示返回箭头。屏幕标题会显示在页面顶部。
- **铃铛**图标，用于查看通知和消息，未读项目会显示角标——参见下方的[通知和消息](#notifications-and-messages)
- 您的**个人头像**，点击即可打开位于 `/mobile/profileEdit` 的个人资料——参见[编辑您的个人资料](./editing-your-profile.md)

铃铛和个人头像仅在您登录后显示。

## 通知和消息

点击铃铛即可打开包含两个部分的面板：

- **消息** -- 您最近的私人对话，并附有**新消息**链接以发起新对话
- **通知** -- 您最近的通知，未读通知会显示**新**标签。点击某条通知即可跳转到其来源的小组、计划或对话。

每个部分都会显示其未读项目的数量。点击底部的**查看全部**即可打开位于 `/mobile/notifications` 的完整收件箱。

## 带有分区的页面

详情页面——小组、计划、您的"我的"页面，以及计划和奉献屏幕——采用分区式的单页布局，而非标签页。每个分区都会显示简短预览，分区标题中的链接（如**全部成员**、**全部活动**或**完整服事流程**）可打开完整列表。该视图顶部的**返回**链接会带您回到之前的页面。

## "我的"页面

**我的**（`/mobile/me`）是您的个人中心。它显示您的姓名和照片，并附有**编辑个人资料**和**设置**（[通知偏好设置](./notification-preferences.md)）按钮；随后是您即将参与的事项——服事安排、活动报名和小组活动——接着是您的家庭、小组、您今年的[奉献](../giving/)、您提交的表单、出勤历史、您的[报名记录](../events/my-registrations.md)，以及最近的通知和消息。详情请参见[我的页面](./me-page)。

如果您已退出登录，"我的"页面将显示**登录**按钮。

## 安装到主屏幕

成员门户是一个渐进式网页应用（PWA）。访问 `/mobile/install`（或在"更多"页面中选择**安装应用**），即可获取适用于您设备的分步说明。安装后，应用将从主屏幕全屏打开，不显示浏览器界面。参见[将其安装为应用（PWA）](./installing-pwa.md)。

## 您教会的公开网站

在成员门户之外，您教会的公开网站有其自己的顶部导航栏，其中包含管理员配置的链接——例如[讲道](../content/sermons.md)、[圣经](../content/bible.md)、[直播](../content/live-streaming.md)页面，以及公开的小组列表。在手机上，这些链接位于页眉右上角的汉堡图标之后。

:::info
您看到的标签和工具因教会而异。管理员通过 B1 Admin 控制成员可见的部分，因此如果您没有看到本文描述的某项功能，可能是您的教会尚未开启该功能。
:::
