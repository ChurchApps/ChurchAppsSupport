# 浏览 B1App

<div class="article-intro">

B1.church 的会员门户是一个以手机为主的网页应用，位于 `/mobile` 路径下。它可以在任何浏览器中使用，也可以安装到主屏幕上。本页将介绍首页仪表板、底部标签栏、更多页面和我的页面。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要[登录](./logging-in.md)才能查看个人信息。未登录的访客仍可浏览公开内容，并且在需要账户的功能处会看到**登录**按钮。

</div>

## 首页 {#home}

打开 `https://yourchurchname.b1.church/mobile` 即可进入 `/mobile/dashboard` 的**首页**仪表板。首页是会员门户的起始页面。它首先显示问候语（"早上好"、"下午好"或"晚上好"，并附上您的名字）以及今天的日期，随后是仅在适用时才会出现的以下部分：

- **最新讲道** -- 教会最新的讲道，附有**全部讲道**链接
- **每日经文** -- 今日经文；点击即可打开完整的[每日经文](../content/verse-of-the-day.md)页面
- **您正在服事** -- 您即将到来的服事安排，附有**全部计划**链接。如果有任何安排仍需您回复，这些安排会优先显示，并带有**待回复**标记以及**接受**和**拒绝**按钮，方便您直接在首页上作出回应（点击**拒绝**前需要先确认）；否则，您接下来的安排会显示**已接受**或**已确认**标记。点击某项安排即可打开其计划。
- **您的群组** -- 最多三个您所在群组，显示其聚会时间和地点，并附有**全部群组**链接
- **奉献** -- 您今年的奉献总额（当前年份的"已奉献"），以及**奉献**按钮和指向您[奉献历史](../giving/donation-history.md)的**历史**链接
- **更多来自** *您的教会* -- 您教会已开启、但未显示在标签栏或上方区域中的其他工具的按钮。您最常使用的工具会排在最前面。

服事、群组和奉献部分仅在您已登录、教会已开启该工具，并且有内容可显示时才会出现，例如有即将到来的服事安排或至少加入了一个群组。在电脑上，首页会以两栏布局显示。

如果您未登录，首页会以**欢迎**标题代替问候语，并附有简短提示（"登录以查看您的群组、奉献等内容。"）以及**登录**按钮。即使教会尚未为首页设置其他内容，该提示也会显示。您的教会可以修改此提示的措辞或将其隐藏 -- 请参阅[移动应用设置](../../b1-admin/settings/mobile-app.md#home-screen-sign-in-prompt)。隐藏后，您仍可从**更多**页面或**我的**页面登录。

## 底部标签栏

在手机上，标签栏会固定在屏幕底部：

- **首页** -- 始终位于第一个标签
- 教会配置的最多三个标签
- **更多** -- 打开更多页面

指向外部网站、自定义页面和每日经文的链接永远不会获得独立的标签。如果教会配置的标签超过了可显示的数量，多出的标签并不会丢失：它们会显示在**更多**页面以及首页的**更多来自**部分中。教会管理员可在 B1 Admin 的**移动端 → 导航**中设置标签顺序。

## 在电脑上

在电脑或大屏平板等较宽的屏幕上，底部标签栏会被屏幕顶部的一个标题栏取代，并采用教会的主题色。标题栏会显示教会名称（点击即可返回首页）、**首页**、教会配置的最多五个标签以及**更多**，右侧则为铃铛图标和您的头像。打开详情页面时，页面内容上方会出现**返回**链接。

## 更多页面 {#the-more-page}

点击**更多**即可打开位于 `/mobile/more` 的更多页面。该页面包含：

- 您的姓名和照片，以及**编辑个人资料**链接 -- 请参阅[编辑您的个人资料](./editing-your-profile.md)
- 教会配置的全部标签，按顺序列在教会名称下方。指向外部网站的链接会在新的浏览器标签页中打开。
- **账户**部分，包括：
  - **我的** -- 您的个人页面（仅限登录用户）
  - **外观** -- 在**浅色模式**和**深色模式**之间切换
  - **管理门户** -- 仅当您在教会拥有管理员权限时显示；点击后会在新标签页中打开 B1 Admin
  - **安装应用** -- 打开位于 `/mobile/install` 的[安装说明](./installing-pwa.md)（应用安装后将隐藏）
- **退出登录**；如果您未登录，则显示**登录**按钮
- 您教会的名称以及隐私政策链接

## 应用栏

在手机上，每个屏幕顶部的栏会显示：

- 在首页和其他主要屏幕上显示教会名称；当您进入某个详情页面时，则显示返回箭头。屏幕标题会显示在页面内容顶部。
- **铃铛**图标，用于查看通知和消息，未读项目会显示数字标记 -- 请参阅下方的[通知与消息](#notifications-and-messages)
- 您的**头像**，点击后会打开位于 `/mobile/profileEdit` 的个人资料 -- 请参阅[编辑您的个人资料](./editing-your-profile.md)

铃铛和头像仅在您登录后显示。

## 通知与消息 {#notifications-and-messages}

点击铃铛会打开一个包含两个部分的面板：

- **消息** -- 您最近的私人对话，并附有用于发起新对话的**新消息**链接
- **通知** -- 您最近的通知，未读通知会带有**新**标记。点击某条通知即可前往其来源的群组、计划或对话。

每个部分都会显示其中未读项目的数量。点击底部的**查看全部**即可打开位于 `/mobile/notifications` 的完整收件箱。

## 包含分区的页面

详情页面（例如群组、计划、我的页面，以及计划和奉献页面）采用分区布局，而非标签页。每个分区都会显示简短预览，分区标题中的链接（例如**全部成员**、**全部活动**或**完整服事顺序**）可打开完整列表。该视图顶部的**返回至**链接可让您返回到之前的页面。

## 我的页面

**我的**（`/mobile/me`）是您的个人中心。页面顶部显示您的姓名和照片，并附有**编辑个人资料**和**设置**（[通知偏好](./notification-preferences.md)）按钮；随后显示您即将到来的事项，包括服事安排、活动报名和群组活动；再往下是您的家庭、您的群组、您今年的[奉献](../giving/)、您的[报名记录](../events/my-registrations.md)，以及最近的通知和消息。详情请参阅[我的页面](./me-page)。

如果您未登录，我的页面将显示**登录**按钮。

## 安装到主屏幕

会员门户是一个渐进式 Web 应用（PWA）。访问 `/mobile/install`（或在更多页面中选择**安装应用**），即可查看适用于您设备的分步说明。安装后，它将从主屏幕全屏打开，不显示浏览器界面。请参阅[以应用形式安装（PWA）](./installing-pwa.md)。

## 教会的公开网站

在会员门户之外，您教会的公开网站有自己的顶部导航，其中包含管理员配置的链接，例如[讲道](../content/sermons.md)、[圣经](../content/bible.md)、[直播](../content/live-streaming.md)以及公开的群组列表等页面。在手机上，这些链接位于页眉右上角的汉堡菜单图标之后。

:::info
您看到的标签和工具因教会而异。管理员通过 B1 Admin 控制会员可见的部分，因此如果您没有看到本文描述的某项功能，可能是您的教会尚未开启该功能。
:::
