# 安装为应用（PWA）

<div class="article-intro">

B1.church 支持安装为渐进式网页应用（PWA），让您可以像安装原生应用一样，将教会的会员门户添加到手机主屏幕。这为您带来全屏、类似原生应用的体验，且无需通过 App Store 或 Google Play。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要教会的 B1.church 网址：`https://yourchurchname.b1.church`
- 请使用受支持的浏览器：iOS 上的 **Safari** 或 Android 上的 **Chrome**

</div>

## 什么是 PWA？

渐进式网页应用（PWA）是一种可以安装在您设备上、并像原生应用一样运行的网站。当您将 B1.church 安装为 PWA 后，它会：

- 以全屏方式打开，没有浏览器导航栏
- 以教会的图标和名称出现在主屏幕上
- 完美呈现教会的品牌风格和主题色

:::tip
如果您不想从 App Store 或 Google Play 单独安装一个应用，PWA 是很好的选择。它以更便捷的形式，提供与浏览器中相同的会员门户体验。
:::

## 安装页面

最简单的安装方式是使用教会专属的安装页面：

```
https://yourchurchname.b1.church/mobile/install
```

该页面会自动检测您的设备，并显示相应的操作说明：

- **iPhone** —— 分步的 Safari"添加到主屏幕"操作说明
- **Android** —— Chrome 中一键式的**安装到主屏幕**按钮
- **桌面端** —— 一个二维码，您可以用手机扫描以在手机端打开安装页面

您可以通过以下几种方式进入安装页面：

- 在会员门户中打开菜单（☰），点击**安装应用**（应用安装完成后此选项会自动隐藏）
- 点击教会通过短信、邮件或主日大屏分享的链接
- 直接在浏览器中输入网址

:::tip 面向教会工作人员
将安装页面链接分享给会众——可以放在周报、通讯或投影片中。它会为每位会员逐步演示适用于其设备的具体操作步骤。您也可以从 B1Admin 仪表盘的**下载应用**快捷操作进入该页面。
:::

您也可以在教会 B1.church 网站的**任意页面**上，通过下方的浏览器操作步骤手动安装 PWA——安装页面只是一种引导式的便捷方式。

启动已安装的应用后，它会直接打开您的会员仪表盘，随时可供登录。

## 在 iPhone 上安装（iOS —— Safari）

1. 在 iPhone 上打开 **Safari**，前往 `https://yourchurchname.b1.church/mobile/install`（将 `yourchurchname` 替换为您教会的网址标识）。
2. 点击屏幕底部的**分享**按钮（带向上箭头的方框图标）。
3. 在分享面板中向下滚动，点击**添加到主屏幕**。
4. 名称会默认使用您教会的名称。点击右上角的**添加**。

应用图标会出现在您的主屏幕上。点击图标即可以全屏模式打开会员门户。

:::info
在 iOS 上安装 PWA 需要使用 Safari。如果您在 iPhone 上使用的是 Chrome 或其他浏览器，请先切换到 Safari。
:::

## 在 Android 上安装（Chrome）

1. 在 Android 设备上打开 **Chrome**，前往 `https://yourchurchname.b1.church/mobile/install`。
2. 点击**安装到主屏幕**按钮。（如果没有此按钮，请点击右上角的三点菜单（⋮），选择**添加到主屏幕**。）
3. 出现提示时点击**添加**。

应用图标会出现在您的主屏幕上。点击图标即可打开会员门户。

## 安装完成后

安装完成后，PWA 会在专属的全屏窗口中直接打开会员门户。您可以：

- 使用现有的 ChurchApps 账户登录
- 使用教会已启用的所有会员功能——小组、奉献、签到、服事计划等等
- 随时点击主屏幕上的图标返回该应用

当您有未读消息时，应用图标会显示**通知徽章**（一个小数字标记），让您一目了然地知道是否有新内容等待查看。

:::info
PWA 需要联网使用。与部分原生应用不同，它不会缓存全部内容以供离线使用。
:::

## 旧版 B1 Mobile 应用怎么办？

iOS 和 Android 上的旧版原生 **B1 Mobile** 应用已停止维护，不再更新。今后 PWA 是访问 B1.church 会员门户的官方支持方式，并且涵盖了原生应用提供的所有面向会员的功能。如果您之前安装过原生应用，请在方便时切换到 PWA。

关于已停用应用的历史文档，请参见 [B1 Mobile 参考页面](/docs/b1-mobile/)。
