# 安装为应用（PWA）

<div class="article-intro">

B1.church 支持安装为渐进式网页应用（PWA），让您可以像原生应用一样，将教会的会员门户添加到手机主屏幕上。无需通过 App Store 或 Google Play，即可获得全屏的类应用体验。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要教会的 B1.church 网址：`https://yourchurchname.b1.church`
- 请使用受支持的浏览器：iOS 上的 **Safari**，或 Android 上的 **Chrome**

</div>

## 什么是 PWA？

渐进式网页应用（PWA）是一种可以安装到设备上、行为与原生应用相似的网站。将 B1.church 安装为 PWA 后，它会：

- 以全屏方式打开，不显示浏览器导航栏
- 以您教会的图标和名称显示在主屏幕上
- 与您教会的品牌形象和主题颜色完美契合

:::tip
如果您不想从 App Store 或 Google Play 安装单独的应用，PWA 是很好的选择。它提供与浏览器中相同的会员门户体验，但使用更加便捷。
:::

## 安装页面

最简单的安装方式是访问您教会专用的安装页面：

```
https://yourchurchname.b1.church/mobile/install
```

该页面会自动检测您的设备，并显示相应的说明：

- **iPhone** —— 逐步的 Safari“添加到主屏幕”说明
- **Android** —— 在 Chrome 中点击一次即可使用的 **Install on Home Screen**（安装到主屏幕）按钮
- **桌面端** —— 一个二维码，您可以用手机扫描，在手机上打开安装页面

您可以通过以下几种方式进入安装页面：

- 在会员门户中点击 **More**（更多），然后在 **Account**（账户）下点击 **Install App**（安装应用）（应用一旦安装，此选项会隐藏）
- 点击教会通过短信、电子邮件或在主日屏幕上分享的链接
- 直接在浏览器中输入网址

:::tip 致教会工作人员
请将安装页面的链接分享给会众——可以放在主日程序、通讯或幻灯片上。该页面会为每位成员指导其设备的具体操作步骤。您也可以通过 B1 Admin 仪表板上的 **Download the App**（下载应用）快捷操作进入该页面。
:::

您也可以使用下面的浏览器步骤，从教会 B1.church 网站的**任意页面**手动安装 PWA——安装页面只是引导式的安装方式。

启动已安装的应用时，它会直接打开您的会员仪表板，等待您登录。

## 在 iPhone 上安装（iOS —— Safari）

1. 在 iPhone 上打开 **Safari**，访问 `https://yourchurchname.b1.church/mobile/install`（将 `yourchurchname` 替换为您教会的网址标识）。
2. 点击屏幕底部的**分享**按钮（带有向上箭头的方框）。
3. 在分享面板中向下滚动，然后点击 **Add to Home Screen**（添加到主屏幕）。
4. 名称默认为您教会的名称。点击右上角的 **Add**（添加）。

应用图标将出现在您的主屏幕上。点击它即可全屏打开会员门户。

:::info
在 iOS 上安装 PWA 需要使用 Safari。如果您在 iPhone 上使用 Chrome 或其他浏览器，请先切换到 Safari。
:::

## 在 Android 上安装（Chrome）

1. 在 Android 设备上打开 **Chrome**，访问 `https://yourchurchname.b1.church/mobile/install`。
2. 点击 **Install on Home Screen**（安装到主屏幕）按钮。（如果该按钮不可用，请点击右上角的三点菜单（⋮），然后选择 **Add to Home screen**（添加到主屏幕）。）
3. 出现提示时，点击 **Add**（添加）。

应用图标将出现在您的主屏幕上。点击它即可打开会员门户。

## 安装之后

安装完成后，PWA 会在专用的全屏窗口中直接打开会员门户。您可以：

- 使用您现有的 ChurchApps 账户登录
- 访问教会已启用的所有会员功能——小组、奉献、签到、服事计划等
- 随时点击主屏幕上的图标返回

当您有未读消息时，应用图标会显示**通知角标**（一个小数字徽章），让您一眼就能看出是否有新内容等待查看。

:::info
PWA 需要网络连接。与某些原生应用不同，它不会缓存全部内容以供离线使用。
:::

## 旧版 B1 Mobile 应用怎么办？

iOS 和 Android 上的旧版原生 **B1 Mobile** 应用已停止支持，不再更新。今后，PWA 是访问 B1.church 会员门户的受支持方式，并涵盖原生应用提供的所有面向会员的功能。如果您之前安装过原生应用，请在方便时切换到 PWA。

有关已停止支持应用的历史文档，请参阅 [B1 Mobile 参考页面](/docs/b1-mobile/)。
