# 安装为应用（PWA）

<div class="article-intro">

B1.church 支持安装为渐进式网页应用（PWA），让您可以像原生应用一样，将教会的成员门户添加到手机主屏幕。这样您无需通过 App Store 或 Google Play，即可获得全屏、接近应用的体验。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要教会的 B1.church 网址：`https://yourchurchname.b1.church`
- 请使用受支持的浏览器：iOS 上的 **Safari** 或 Android 上的 **Chrome**

</div>

## 什么是 PWA？ {#what-is-a-pwa}

渐进式网页应用（PWA）是一种可以安装到设备上、行为类似原生应用的网站。当您将 B1.church 安装为 PWA 后，它将：

- 以全屏方式打开，不显示浏览器导航栏
- 在主屏幕上显示教会的图标和名称
- 与教会的品牌和主题颜色完美契合

:::tip
如果您不想从 App Store 或 Google Play 安装单独的应用，PWA 是一个很好的选择。它为您提供与浏览器中相同的成员门户体验，使用起来更加便捷。
:::

## 安装页面 {#the-install-page}

最简单的安装方式是访问教会专门的安装页面：

```
https://yourchurchname.b1.church/mobile/install
```

该页面会自动检测您的设备，并显示相应的说明：

- **iPhone** -- 分步的 Safari "添加到主屏幕"说明
- **Android** -- 在 Chrome 中点击一次即可的**安装到主屏幕**按钮
- **电脑** -- 一个可用手机扫描的二维码，用于在手机上打开安装页面；如果您的浏览器支持安装网页应用，还会显示**安装到此电脑**按钮

您可以通过以下几种方式进入安装页面：

- 在成员门户中点击**更多**，然后在**账户**下点击**安装应用**（应用一旦安装，该项会隐藏）
- 点击教会通过短信、电子邮件或周日屏幕分享的链接
- 直接在浏览器中输入网址

:::tip 面向教会工作人员
请将安装页面的链接分享给会众 -- 可将其放在周报、通讯或幻灯片中。该页面会为每位成员提供针对其设备的具体步骤。您也可以从 B1Admin 仪表板上的**下载应用**快捷操作进入该页面。
:::

您也可以使用下面的浏览器步骤，从教会 B1.church 网站的**任意页面**手动安装 PWA -- 安装页面只是引导式的操作方式。

启动已安装的应用后，它会直接打开您的成员仪表板，等待您登录。

## 在 iPhone 上安装（iOS -- Safari） {#installing-on-iphone-ios--safari}

1. 在您的 iPhone 上打开 **Safari**，访问 `https://yourchurchname.b1.church/mobile/install`（将 `yourchurchname` 替换为您教会网址的标识）。
2. 点击屏幕底部的**分享**按钮（带有向上箭头的方框图标）。
3. 在分享面板中向下滚动，然后点击**添加到主屏幕**。
4. 名称默认为您教会的名称。点击右上角的**添加**。

应用图标将出现在您的主屏幕上。点击即可全屏打开成员门户。

:::info
在 iOS 上安装 PWA 需要使用 Safari。如果您在 iPhone 上使用 Chrome 或其他浏览器，请先切换到 Safari。
:::

## 在 Android 上安装（Chrome） {#installing-on-android-chrome}

1. 在您的 Android 设备上打开 **Chrome**，访问 `https://yourchurchname.b1.church/mobile/install`。
2. 点击**安装到主屏幕**按钮。（如果 Chrome 尚未弹出安装提示，页面会告知您 -- 请点击右上角的三点菜单（⋮），然后选择**安装应用**。）
3. 出现提示时，点击**安装**。

应用图标将出现在您的主屏幕上。点击即可打开成员门户。

## 安装之后 {#after-installing}

安装完成后，PWA 会直接在专用的全屏窗口中打开成员门户。如果您从已安装的应用中打开安装页面，页面会显示"一切就绪！"，而不是安装步骤。您可以：

- 使用您现有的 ChurchApps 账户登录
- 访问教会已开启的所有成员功能 -- 小组、奉献、签到、服事计划等
- 随时点击主屏幕上的图标返回

当您有未读通知或消息时，应用图标会显示**通知角标**（一个小数字徽章），让您一眼就能看出是否有新内容等待查看。

:::info
PWA 需要网络连接。与某些原生应用不同，它不会缓存全部内容以供离线使用。
:::
