# 以应用形式安装（PWA）

<div class="article-intro">

B1.church 支持安装为渐进式 Web 应用（PWA），让您可以像原生应用一样，把教会的成员门户添加到手机主屏幕。无需通过 App Store 或 Google Play，即可获得全屏、类似应用的体验。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您需要教会的 B1.church 网址：`https://yourchurchname.b1.church`
- 请使用受支持的浏览器：iOS 上使用 **Safari**，Android 上使用 **Chrome**

</div>

## 什么是 PWA？

渐进式 Web 应用（PWA）是一种可以安装到设备上、表现得像原生应用的网站。将 B1.church 安装为 PWA 后，它会：

- 全屏打开，没有浏览器导航栏
- 以您教会的图标和名称出现在主屏幕上
- 与教会的品牌标识和主题颜色保持一致

:::tip
如果您不想从 App Store 或 Google Play 另行安装应用，PWA 是很好的选择。它提供与浏览器中相同的成员门户体验，使用起来更加便捷。
:::

## 安装页面

最简单的安装方式是访问教会专属的安装页面：

```
https://yourchurchname.b1.church/mobile/install
```

该页面会自动识别您的设备，并显示相应的操作说明：

- **iPhone**：分步显示 Safari 中“添加到主屏幕”的操作说明
- **Android**：在 Chrome 中提供一键式 **安装到主屏幕** 按钮
- **桌面设备**：显示一个二维码，您可以用手机扫描，在手机上打开安装页面

您可以通过以下几种方式进入安装页面：

- 在成员门户中点击 **更多**，然后在 **账户** 下点击 **安装应用**（应用安装后，该选项会隐藏）
- 点击教会通过短信、电子邮件或主日屏幕分享的链接
- 直接在浏览器中输入网址

:::tip 教会工作人员
请将安装页面链接分享给会众，可以放在主日周报、教会通讯或幻灯片中。页面会引导每位成员针对其设备完成具体步骤。您也可以从 B1Admin 仪表板上的 **下载应用** 快捷操作进入该页面。
:::

您也可以使用下面的浏览器步骤，从教会 B1.church 网站的**任意页面**手动安装 PWA。安装页面只是提供引导式操作的一种方式。

启动已安装的应用后，它会直接打开成员仪表板，等待您登录。

## 在 iPhone（iOS，Safari）上安装

1. 在 iPhone 上打开 **Safari**，访问 `https://yourchurchname.b1.church/mobile/install`（将 `yourchurchname` 替换为教会网址中的标识符）。
2. 点击屏幕底部的 **分享** 按钮（一个向上箭头的方框图标）。
3. 在分享菜单中向下滚动，然后点击 **添加到主屏幕**。
4. 名称默认为教会名称。点击右上角的 **添加**。

应用图标将出现在主屏幕上。点击图标即可全屏打开成员门户。

:::info
iOS 上的 PWA 安装需要使用 Safari。如果您在 iPhone 上使用 Chrome 或其他浏览器，请先切换到 Safari。
:::

## 在 Android（Chrome）上安装

1. 在 Android 设备上打开 **Chrome**，访问 `https://yourchurchname.b1.church/mobile/install`。
2. 点击 **安装到主屏幕** 按钮。（如果没有该按钮，请点击右上角的三点菜单（⋮），然后选择 **添加到主屏幕**。）
3. 出现提示时，点击 **添加**。

应用图标将出现在主屏幕上。点击图标即可打开成员门户。

## 安装之后

安装完成后，PWA 会在专属的全屏窗口中直接打开成员门户。您可以：

- 使用现有的 ChurchApps 账户登录
- 使用教会已启用的所有成员功能，例如小组、奉献、签到、服事安排等
- 随时点击主屏幕上的图标返回应用

当您有未读消息时，应用图标会显示**通知标记**（一个小数字徽章），让您一眼就能看出是否有新内容等待查看。

:::info
PWA 需要联网才能使用。与某些原生应用不同，它不会缓存所有内容以供离线使用。
:::
