# 通知偏好设置

<div class="article-intro">

通知偏好设置让您决定从教堂接收哪些通知以及如何接收——推送通知、电子邮件或应用内钟。您可以调整每种通知类型、设置安静时间或一次静音所有内容，所有这些都从一个屏幕完成。

</div>

## 打开您的偏好设置

1. 进入**我**页面并点击**快捷方式**下的**通知偏好设置**。

您也可以点击钟形图标，打开**通知**选项卡，点击**查看所有通知**，然后在该页面上点击**通知偏好设置**。

## 全局控制

在屏幕顶部，您会找到适用于所有内容的设置：

- **静音所有** -- 临时暂停所有非必要通知。
- **推送通知** -- 为您的设备打开或关闭推送通知。
- **电子邮件频率** -- 选择电子邮件通知的到达方式：
  - **按通知** -- 当事情发生时发送电子邮件。
  - **每日摘要** -- 将它们捆绑成一封每日电子邮件。
  - **从不** -- 不要发送通知电子邮件。
- **安静时间** -- 设置开始和结束时间（和您的时区），当您不希望被打扰时。非紧急通知会等待安静时间结束。

## 按类型选择通知

在全局控制下方是通知类型网格。对于每一个，您可以打开或关闭您想要的渠道：

- **推送** -- 您设备上的通知。
- **电子邮件** -- 发送到您收件箱的消息。
- **应用内** -- 应用内的钟/徽章。

常见类型包括**事件提醒**、**服务和日程**、**直接消息**、**小组聊天**、**祷告请求**和**教堂公告**。例如，您可能为直接消息启用推送通知，但为公告关闭它们。

:::info
一些通知类型**始终开启**，无法关闭——**账户和安全**、**捐赠收据和声明**和**报到安全警报**。这些是您的安全和法律原因所必需的，因此它们显示一个小锁定图标。其他一切都由您控制。
:::

某些类型**默认关闭**（例如促销或筹款消息），仅在您选择退出时才会到达您。

## 保存您的更改

调整偏好设置后，点击**保存偏好设置**。您的更改立即生效，并适用于您使用B1的任何地方。

:::tip
时间敏感通知——如安全警报或儿童报到安全消息——即使在安静时间也会到达您。日常更新会等待安静时间结束。
:::
