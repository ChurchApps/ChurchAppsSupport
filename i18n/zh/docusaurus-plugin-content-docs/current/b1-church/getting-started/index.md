# B1.church 入门指南

<div class="article-intro">

B1.church 是您教会的线上家园。您可以通过它与教会保持联系、查看最新动态、在线奉献、办理服务签到，还能做更多事情。本节将带您了解访问和使用会员门户的基本方法。

</div>

## 访问您教会的网站

您教会的 B1.church 网址通常采用 `https://yourchurchname.b1.church` 的格式。您可以在电脑、平板或手机上的任何网页浏览器中访问此网址。教会的领导层或迎新团队可以为您提供准确的地址。

首次访问网站时，您会看到教会的公开网站，其中包含该教会的定制品牌标识、导航菜单和内容页面。

## 创建账户

要访问会员门户及其各项功能，您需要一个 ChurchApps 账户。

1. 访问您教会的 B1.church 网址。
2. 点击页面右上角的 **登录** 按钮。
3. 在登录界面，选择 **注册** 新账户的选项。
4. 输入您的 **名字**、**姓氏**、**电子邮件地址**，并设置 **密码**。
5. 完成注册表格。

注册完成后，您即可登录并使用会员门户的全部工具。

:::tip
如果您的教会已将您添加到其系统中，请使用他们登记在案的电子邮件地址。这样您的账户将与现有的教会个人资料关联起来。
:::

## 您可以做什么

登录后，会员门户将为您提供以下功能：

- **首页**仪表盘，可预览您的服事、小组和奉献情况；**我的**页面则显示您即将参与的事项
- 您所属的**小组**，包括对话和活动
- 在线**奉献**，进行捐款
- **服事计划**，显示您的志愿者排班和服事详情
- **签到**，用于服事和活动
- **社群**通讯录，用于查找并结识其他会员

## 在手机上访问

B1.church 可在任何移动端浏览器中使用。如果您希望获得更接近应用程序的体验，可以将教会的会员门户安装为**渐进式网页应用（PWA）**。访问 `https://yourchurchname.b1.church/mobile/install`，即可获取针对您设备的分步指导；您也可以直接通过 Safari 或 Chrome 将其添加到主屏幕。无需应用商店。有关说明，请参阅 [安装为应用（PWA）](./installing-pwa.md)。
