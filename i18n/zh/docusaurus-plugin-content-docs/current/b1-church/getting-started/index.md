# B1.church 入门指南

<div class="article-intro">

B1.church 是您教会的线上家园。您可以在这里与会众保持联系、查看最新动态、在线奉献、办理礼拜签到等。本节将带您了解访问和使用成员门户的基础知识。

</div>

## 访问您教会的网站 {#accessing-your-churchs-site}

您的教会拥有专属的 B1.church 网址，通常采用 `https://yourchurchname.b1.church` 的格式。您可以在电脑、平板或手机上的任何网页浏览器中访问该网址。教会领导或接待团队可以为您提供准确的地址。

您首次访问网站时，将看到教会的公开网站，其中包含定制的品牌标识、导航菜单和内容页面。

## 创建账户 {#creating-an-account}

要访问成员门户及其功能，您需要一个 ChurchApps 账户。

1. 访问您教会的 B1.church 网址。
2. 点击页面右上角的**登录**按钮（如果您教会的网站没有显示该按钮，请前往 `/login`）。在成员门户中，请改为点击**登录**。
3. 在登录页面，选择**注册**（成员门户中为**创建账户**）。
4. 输入您的**名字**、**姓氏**和**电子邮件地址**，然后提交表单。
5. 检查您的电子邮件，找到**6 位验证码**并输入。
6. 设置一个**密码**（至少 8 个字符），并再次输入以确认。

此后您即已登录，可以使用成员门户的全部工具。

:::tip
如果您的教会已将您添加到其系统中，请使用他们存档的相同电子邮件地址。这样您的账户将与现有的教会个人资料关联起来。
:::

## 您可以做什么 {#what-you-can-do}

登录后，成员门户将为您提供以下功能：

- **主页**仪表板，展示您的服事、小组和奉献的预览，以及**我的**页面，展示您即将参与的事项
- 您所属的**小组**，包括对话和活动
- 在线**奉献**
- **计划**，展示您的志愿者安排和礼拜详情
- 礼拜和活动的**签到**
- **社区**名录，用于查找并联系其他成员

## 在手机上访问 {#accessing-on-your-phone}

B1.church 可在任何手机浏览器中使用。若想获得更接近应用的体验，您可以将教会的成员门户安装为**渐进式网页应用（PWA）** -- 访问 `https://yourchurchname.b1.church/mobile/install`，即可获得针对您设备的分步指引；或直接通过 Safari 或 Chrome 将其添加到主屏幕。无需应用商店。请参阅[安装为应用（PWA）](./installing-pwa.md)了解详细说明。
