# B1.church 入门指南

<div class="article-intro">

B1.church 是您教会的线上家园。您可以通过它与会众保持联系、查看最新动态、在线奉献、办理礼拜签到等等。本节将带您了解访问和使用会员门户的基础知识。

</div>

## 访问您教会的网站

您的教会拥有专属的 B1.church 网址，通常采用 `https://yourchurchname.b1.church` 的格式。您可以在电脑、平板电脑或手机上的任何网页浏览器中访问此网址。您的教会领导或迎宾团队可以为您提供准确的地址。

您第一次访问网站时，会看到教会的公开网站，其中包含教会定制的品牌形象、导航菜单和内容页面。

## 创建账户

要访问会员门户及其各项功能，您需要一个 ChurchApps 账户。

1. 访问您教会的 B1.church 网址。
2. 点击页面右上角的 **Login**（登录）按钮。
3. 在登录界面中，选择 **Register**（注册）新账户的选项。
4. 输入您的**名字**、**姓氏**、**电子邮件地址**，并设置**密码**。
5. 完成注册表单。

注册完成后，您即可登录并使用会员门户的全部工具。

:::tip
如果您的教会已将您添加到其系统中，请使用他们记录在案的同一电子邮件地址。这样您的账户就会与现有的教会个人资料关联。
:::

## 您可以做什么

登录后，会员门户将为您提供以下功能：

- **首页（Home）**仪表板，可预览您的服事、小组和奉献情况，以及显示您即将参与的活动的**我的（Me）**页面
- 您所属的**小组（Groups）**，包括对话和活动
- 在线**奉献（Giving）**
- 显示您的志愿者排班和礼拜详情的**计划（Plans）**
- 礼拜和活动的**签到（Check-In）**
- **社区（Community）**名录，用于查找并联系其他成员

## 在手机上访问

B1.church 可在任何移动浏览器中使用。如需更接近应用的体验，您可以将教会的会员门户安装为**渐进式网页应用（PWA）**——访问 `https://yourchurchname.b1.church/mobile/install`，即可获取针对您设备的分步指引；也可以直接从 Safari 或 Chrome 将其添加到主屏幕。无需应用商店。详细说明请参阅[安装为应用（PWA）](./installing-pwa.md)。

:::info
旧版原生 B1 Mobile 应用已停止支持。今后在手机上使用 B1.church 的受支持方式是 PWA——历史文档请参阅 [B1 Mobile 参考页面](/docs/b1-mobile/)。
:::
