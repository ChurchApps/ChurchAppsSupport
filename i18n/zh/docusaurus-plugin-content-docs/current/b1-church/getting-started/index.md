# B1.church 新手入门

<div class="article-intro">

B1.church 是您教会的线上家园。您可以在这里与会众保持联系、查看最新动态、在线奉献、为聚会签到，以及更多功能。本节将引导您了解访问和使用会员门户的基本操作。

</div>

## 访问您教会的网站

您的教会拥有专属的 B1.church 网址，通常格式为 `https://yourchurchname.b1.church`。您可以在电脑、平板或手机的任意网页浏览器中访问此网址。您的教会领导层或接待团队可以为您提供确切的网址。

首次访问该网站时，您会看到教会的公开网站，包含教会自定义的品牌形象、导航菜单和内容页面。

## 创建账户

要访问会员门户及其功能，您需要一个 ChurchApps 账户。

1. 访问您教会的 B1.church 网址。
2. 点击页面右上角的**登录**按钮。
3. 在登录界面上，选择**注册**新账户的选项。
4. 输入您的**名**、**姓**、**邮箱地址**，并设置**密码**。
5. 完成注册表单。

注册完成后，您就可以登录并使用会员门户的所有工具。

:::tip
如果您的教会已经在其系统中添加了您的信息，请使用他们存档中相同的邮箱地址注册。这样可以将您的账户与现有的教会档案关联起来。
:::

## 您可以做什么

登录后，会员门户可让您使用以下功能：

- 您的个人**动态**，展示来自所属小组和教会的最新消息
- 您所属的**小组**，包括其中的交流讨论和活动
- 用于捐款的在线**奉献**功能
- 展示您的服事安排和服事详情的**计划**
- 用于聚会和活动的**签到**功能
- **社区**通讯录，用于查找并联系其他会员

## 在手机上访问

B1.church 可在任意手机浏览器中使用。为获得更接近原生应用的体验，您可以将教会的会员门户安装为**渐进式网页应用（PWA）**——访问 `https://yourchurchname.b1.church/mobile/install` 获取针对您设备的分步指导，或直接从 Safari 或 Chrome 将其添加到主屏幕。无需应用商店。有关说明，请参见[安装为应用（PWA）](./installing-pwa.md)。

:::info
旧版原生 B1 Mobile 应用已停止维护。今后 PWA 是在手机上使用 B1.church 的官方支持方式——历史文档请参见 [B1 Mobile 参考页面](/docs/b1-mobile/)。
:::
