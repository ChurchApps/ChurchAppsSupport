# 计划

<div class="article-intro">

B1.church 中的**计划**板块可让您查看被分配给您的服事计划。无论您是在敬拜团队、协助儿童事工，还是在其他领域服事，都可以在这里了解您的排班时间、所担任的职位，以及礼拜的整体安排。

</div>

## 您将在这里找到的内容

根据教会的设置方式，计划可能包含以下几类内容：

- **您的安排** -- 查看您被分配的职位以及需要您服事的时间。每项安排都会显示您的职位名称、礼拜日期以及当前状态（例如 Accepted（已接受）、Declined（已婉拒）或 Needs reply（待回复））。您可以接受或婉拒新的安排；如果您的计划有变，也可以婉拒已接受的安排。
- **礼拜程序** -- 查看礼拜程序，包括时间安排、诗歌信息和各环节的描述，以便您提前了解礼拜的流程。
- **课程内容** -- 部分计划包含来自 [Lessons.church](../content/lessons.md) 等供应商的相关课程或课程内容。您可以直接在计划中预览这些内容。
- **不可服事日期** -- 通过管理您的不可服事日期，告知团队负责人您无法参加的时间。
- **首页预览** -- 您接下来的安排也会显示在[首页仪表板](../getting-started/navigating.md#home)的 **You're serving**（您的服事）部分，您可以在那里接受或婉拒需要回复的安排。

## 入门

如需访问您的计划，请点击会员门户标签栏中或**更多（More）**页面上的 **Plans**（计划）。您必须[登录](../getting-started/logging-in.md)才能查看计划——如果您未登录，系统会先提示您登录。

:::info
您只能看到分配给您的计划。如果您没有看到任何计划，则说明您尚未被加入任何服事团队。请联系教会管理员或事工负责人，以参与服事。
:::
