# 礼拜程序

<div class="article-intro">

打开计划时，**礼拜程序（Service Order）**部分会显示该礼拜的前几个环节——点击 **Full service order**（完整礼拜程序）即可查看完整流程。这让您和团队都能看到统一的礼拜流程，包括每个环节的时间、诗歌详情和描述。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 从您的[计划列表](./viewing-plans.md)中打开一个计划，即可查看其礼拜程序。

</div>

## 礼拜程序显示的内容

礼拜程序以列表形式显示，项目按照礼拜中的实际顺序排列。每个项目包括：

- **累计时间** -- 从礼拜开始计算的运行时间，让您知道每个环节预计何时开始。
- **项目名称和描述** -- 环节的名称（例如诗歌名称、祷告或公告），以及任何备注或描述。
- **时长** -- 该项目预计需要的时间。

项目会归入**标题（headers）**之下，标题将相关的环节归为一组（例如“Worship Set”（敬拜时段）或“Message”（讲道））。这使您可以轻松浏览礼拜的整体结构。

课程和教材部分还可以展开，显示其下嵌套的单独活动文件夹——点击该部分即可展开或收起其活动，查看团队将逐步进行的每个步骤。

## 查看诗歌歌词和和弦

在礼拜程序中点击某首诗歌，即可打开其歌词和和弦。使用顶部的 **Key Signature**（调号）下拉菜单即可即时转调——如果您的乐器或音域需要与敬拜领导所定的调不同，这一功能会很方便。

## 课程和教材内容

如果计划中关联了来自 [Lessons.church](../content/lessons.md) 等供应商的课程或教材内容，您将在礼拜程序中看到该内容的预览。这可能包括课程环节、演示材料，以及团队在礼拜中需要的其他资源。

## 打印礼拜程序

B1.church 会员应用没有计划的打印选项。如果您需要包含团队名单和完整礼拜程序的打印版本，请请工作人员从 B1 Admin 中打印。请参阅[打印计划](../../b1-admin/serving/plans.md#printing-plans)。
