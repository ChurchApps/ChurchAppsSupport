# 礼拜流程

<div class="article-intro">

打开计划时，**礼拜流程**板块会显示该礼拜的前几个环节 -- 点击**完整礼拜流程**即可查看整个流程。这让您和您的团队可以共同查看礼拜的进行流程，包括每个环节的时间、歌曲详情和说明。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 从您的[计划列表](./viewing-plans.md)打开一个计划，即可查看其礼拜流程。

</div>

## 礼拜流程显示的内容 {#what-the-service-order-shows}

礼拜流程以列表形式显示，按照礼拜中的实际顺序排列。每个环节包括：

- **累计时间** -- 从礼拜开始计算的运行时间，让您知道每个环节预计何时开始。
- **环节标签和说明** -- 环节的名称（例如歌曲名称、祷告或公告）以及任何备注或说明。
- **时长** -- 该环节预计所需的时间。

环节会归入**标题**之下，标题会将相关的环节归为一组（例如"敬拜时间"或"信息"）。每个标题都会显示其下环节的总时间，便于您快速浏览礼拜的整体结构。

歌曲会显示音乐符号以及演奏的调性（例如"G 调"）。附有链接的环节会以链接形式显示其名称 -- 点击即可打开链接（音频链接会直接在页面中播放）。

课程和课程内容板块也可以展开为嵌套其下的一组具体行动 -- 点击该板块即可展开或收起其中的行动，并查看您的团队将依次经历的每个步骤。

## 查看歌词和和弦 {#viewing-song-lyrics-and-chords}

在礼拜流程中点击某首歌曲即可打开其详情：演唱者、**调号**按钮、**歌词**（如果歌曲有和弦，则会一并显示），以及专辑、BPM、调性、拍号和时长等歌曲信息，还有通往 Spotify、YouTube 或 PraiseCharts 等平台上该歌曲的**链接**。点击**调号**下的某个调性即可即时转调 -- 如果您的乐器或音域需要与敬拜领袖计划的调性不同，这一功能非常实用。完成后点击**关闭**。

## 课程与课程内容 {#curriculum-and-lesson-content}

如果计划关联了来自 [Lessons.church](../content/lessons.md) 等提供商的课程或课程内容，您将在礼拜流程中看到该内容的预览。其中可能包括课程板块、演示材料，以及您的团队在礼拜中所需的其他资源。

## 打印礼拜流程 {#printing-the-service-order}

B1.church 成员应用不提供计划的打印功能。如果您需要带有团队名单和完整礼拜流程的纸质版，请让工作人员从 B1 管理后台打印。请参阅[打印计划](../../b1-admin/serving/plans.md#printing-plans)。
