# 崇拜流程

<div class="article-intro">

打开计划后，**崇拜流程**部分会显示该场聚会的项目顺序。这为您和团队提供了聚会流程的共同视图，包括每个环节的时间安排、诗歌详情和说明。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须已[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 从您的[计划列表](./viewing-plans.md)中打开一个计划，即可查看其崇拜流程。

</div>

## 崇拜流程显示的内容

崇拜流程会按照聚会中出现的顺序，以列表形式展示各个项目。每个项目包括：

- **累计时间** -- 从聚会开始计算的累计时长，让您知道每个环节预计何时开始。
- **项目名称和描述** -- 该环节的名称（例如诗歌标题、祷告或通告），以及任何备注或说明。
- **时长** -- 该项目预计所需的时间。

项目会按**分组标题**组织，将相关环节归为一组（例如"敬拜环节"或"信息"）。这样便于快速浏览聚会的整体结构。

## 查看诗歌歌词与和弦

点击崇拜流程中的某首诗歌，即可打开其歌词和和弦。使用页面顶部的**调号**下拉菜单可即时转调——如果您的乐器或音域需要与敬拜带领者原定不同的调，这个功能会很有用。

## 课程和教材内容

如果该计划关联了来自 [Lessons.church](../content/lessons.md) 等平台的课程或教材内容，您会在崇拜流程中看到该内容的预览。这可能包括课程章节、演示材料以及团队在聚会中所需的其他资源。

## 打印崇拜流程

您可以打印一份格式化的崇拜流程，方便在聚会当天携带。

1. 从**计划**列表中打开该计划。
2. 在**崇拜流程**部分，点击右上角的**打印**图标。
3. 系统会打开一个新窗口，显示可打印的版式，其中包括：
   - 顶部的**聚会日期**。
   - 左侧按分类分组的**团队分工**，显示每个岗位及负责该岗位的人员。
   - 右侧的**完整崇拜流程**，包含时间、项目详情和时长列。
4. 您浏览器的打印对话框会自动打开，您可以直接打印或另存为 PDF。

:::tip
打印出的崇拜流程非常适合在排练或聚会当天随身携带参考。它将团队名单和完整崇拜流程整合在同一页面上。
:::
