# 查看计划

<div class="article-intro">

计划页面给您清楚地看到您被分配的所有服务计划。它使用主详细布局，以便您可以快速浏览您的计划并深入了解任何一个的详情。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)您的 B1.church 帐户。
- 您必须被分配到至少一个服务计划。如果您看不到任何计划，请联系您的教会管理员或事工领导者。

</div>

## 访问您的计划

1. 在[侧边栏导航](../getting-started/navigating.md)中单击**计划**。
2. 您将在页面左侧看到您的计划列表。

## 计划列表

您的计划在左侧面板中的**我的计划**下列出。每个条目显示：

- **计划名称**（例如 "主日礼拜" 或 "儿童事工"）
- **服务日期**
- 您的**位置**（您担任的角色）
- 您的**状态** -- 色彩编码，以便您一目了然地查看您是否已接受、拒绝或尚未回复

在列表的顶部，您还会看到**禁止日期**选项。单击它以管理您无法为服务提供的日期。您可以添加、编辑和删除禁止日期范围，以便您的团队领导者知道何时需要围绕您安排。

:::info
您的教会可能会在您安排的服务前发送**提醒**，通过电子邮件和应用通知。如果您尚未回复，您可以直接从提醒电子邮件中**接受**或**拒绝** -- 无需登录。
:::

## 查看计划详情

单击列表中的任何计划以在右侧面板中打开其详情。详情视图包括：

- **位置详情** -- 您分配的位置，包含所需时间和当前状态。如果您尚未回复，您可以直接从此视图单击**接受**或**拒绝**。
- **笔记** -- 计划创建者为团队添加的任何笔记。
- **服务顺序** -- 完整的服务顺序，包含时间、项目和描述。有关更多详情，请参阅[服务顺序](./service-order.md)。
- **团队分配** -- 所有团队成员和他们的位置摘要，以便您可以看到与您一起服务的其他人。

:::tip
如果您在不同计划中有多个任务，列表按日期排序，以便您即将到来的承诺首先出现。定期检查以关注您的日程。
:::

## 教师查看课程

如果您的计划包括关联的课程来自内容提供商（如 Lessons.church），您将在**服务顺序**选项卡中看到一个切换按钮，让您在**摘要**和**教导**视图之间切换。

- **摘要视图** -- 显示服务顺序，带有时间和基本课程部分，非常适合快速查看何时会发生什么
- **教导视图** -- 打开为教师设计的沉浸式全屏课程演示，具有格式化说明、嵌入媒体、笔记和分步指导

教导视图将课程内容组织成在顶部显示为选项卡的可导航部分。您可以：

- 点击部分选项卡直接跳到课程的那一部分
- 滚动浏览课程内容，活动选项卡将自动更新以匹配您的位置
- 单击媒体项目（视频、图像、活动）在模态对话中查看它们；音频链接（歌曲录音、讲道片段）使用内置音频播放器内联播放
- 看到动作类型的不同格式化：**说**显示在对话气泡中，**做**以粗体文本显示，**笔记**以突出显示的标注显示

:::tip
教导视图在领导教室或小组时特别有帮助，因为它以清晰、无干扰的格式呈现所有课程内容，针对移动和平板使用进行了优化。
:::
