# 查看计划

<div class="article-intro">

计划页面为您提供了您被分配的所有服务计划的清晰视图。它使用主详情布局，因此您可以快速浏览您的计划并深入查看任何一个的详情。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)您的B1.church账户。
- 您必须被分配到至少一个服务计划。如果您看不到任何计划，请联系您的教堂管理员或事工领导者。

</div>

## 访问您的计划

1. 在[侧边栏导航](../getting-started/navigating.md)中单击**计划**。
2. 您将看到您被安排在其上的计划列表。

## 计划列表

您的计划分为两个选项卡：**即将到来**和**过去**。每个条目显示：

- **计划名称**（例如，"星期日敬拜"或"儿童事工"）
- **服务日期**
- 您的**职位**（您填充的角色）
- 您的**状态** -- 使用颜色编码，以便您一眼就能看到您是否已接受、拒绝或尚未回应

在列表下方是**封闭日期**部分。使用它来管理您不可用于服务的日期。您可以添加、编辑和移除封闭日期范围，以便您的团队领导者知道何时应避免围绕您安排。

:::info
您的教堂可能在您被安排的服务之前通过电子邮件和应用通知发送**提醒**。如果您还没有回应，您可以直接从提醒电子邮件**接受**或**拒绝**——无需登录。
:::

## 查看计划详情

单击列表中的任何计划以打开它。计划页面有三个选项卡：

- **概览** -- 您的分配职位及所需时间和您的当前状态，加上计划创建者为团队添加的任何笔记。如果您还没有回应，您可以直接从此视图单击**接受**或**拒绝**。
- **服务顺序** -- 带有时间、项目和描述的完整服务顺序。见[服务顺序](./service-order.md)以获取更多详细信息。
- **服务团队** -- 所有团队成员及其职位，以便您可以看到还有谁与您一起服务。

:::tip
如果您有多个跨不同计划的分配，列表按日期排序，因此您即将到来的承诺首先出现。定期检查以保持您的日程安排的顶部。
:::

## 课程的教师视图

如果您的计划包括来自内容提供商（例如Lessons.church）的相关课程，**服务顺序**选项卡显示课程的部分以供快速审查，以及**讲授**按钮。

单击**讲授**以打开为教师设计的沉浸式全屏课程演示，带有格式化说明、嵌入式媒体、笔记和分步指导。关闭它以返回服务顺序。

讲授视图将课程内容组织成显示为顶部标签页的可导航部分。您可以：

- 点击部分标签页以直接跳转到课程的该部分
- 滚动浏览课程内容，活动标签页将自动更新以匹配您的位置
- 单击媒体项目（视频、图像、活动）以在模态对话框中查看它们；音频链接（歌曲录音、讲道片段）使用内置音频播放器内联播放
- 查看格式不同的操作类型：**说**以会话气泡出现，**做**以粗体文本出现，**笔记**以突出显示的标注出现

:::tip
讲授视图在领导课堂或小组时特别有帮助，因为它以为移动设备和平板电脑使用优化的干净、不分心的格式呈现所有课程内容。
:::
