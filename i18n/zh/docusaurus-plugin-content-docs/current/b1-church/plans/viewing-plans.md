# 查看计划

<div class="article-intro">

计划页面让您清楚地查看所有分配给您的礼拜计划。它会显示哪些事项需要您回复、哪些即将到来，以及您已服事过哪些，并让您打开任何计划查看详情。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 您必须被分配到至少一个礼拜计划。如果您看不到任何计划，请联系教会管理员或事工负责人。

</div>

## 进入您的计划 {#accessing-your-plans}

1. 点击标签栏中的**计划**、[更多页面](../getting-started/navigating.md#the-more-page)中的**计划**，或主页上**您正在服事**板块中的**全部计划**。
2. 您将看到您已排班的计划。

## 计划页面 {#the-plans-page}

页面顶部会显示您即将到来的安排中有多少已确认、有多少仍需回复，并提供**报名服事**按钮，可打开[志愿者报名](../serving/volunteer-signup.md)页面。页面下方按以下板块组织：

- **需要您回复** -- 您尚未回复的安排，每项都带有**接受**和**拒绝**按钮，方便您无需打开计划即可回复。点击**拒绝**时会先要求您确认。仅在有待您回复的事项时显示。
- **即将到来** -- 您接下来的三项安排。点击**全部即将到来**可查看其余安排。
- **不可服事日期** -- 您无法服事的日期。点击**添加日期**，选择**开始日期**和**结束日期**，然后点击**保存**。点击某个不可服事日期旁边的**删除**即可将其移除。您的团队负责人会看到这些日期，以便在安排时避开您。
- **过往** -- 您今年服事过的次数以及您最近一次服事的时间（如果您尚未服事过，则显示"暂无过往安排。"）。点击**过往安排**可查看完整列表，并可按年份筛选。

每项安排都会显示**礼拜日期**、**计划名称**、您的**职位**，以及一个状态标记 -- **已接受**、**已确认**、**已拒绝**、**待回复**，或者如果您尚未回复，则显示**需要回复**。

:::info
教会可能会在您排班的礼拜前通过电子邮件和应用通知发送**提醒**。如果教会发送短信，您也可以在[通知偏好设置](../getting-started/notification-preferences.md)中开启**短信**，以接收短信提醒。如果您尚未回复，可以直接在提醒电子邮件中点击**接受**或**拒绝** -- 无需登录。
:::

## 查看计划详情 {#viewing-plan-details}

点击任意计划即可打开。计划页面顶部会显示计划名称和礼拜日期，随后是以下板块：

- **您的安排** -- 您在该计划中被分配的每个职位，包括所属团队、您的状态，以及您需要到场的**礼拜时间**。如果您尚未回复，可以直接在此点击**接受**或**拒绝**。点击**拒绝**时会先要求您确认。
- **礼拜流程** -- 礼拜的前几个环节，并显示环节总数。点击**完整礼拜流程**可查看全部内容。更多详情请参阅[礼拜流程](./service-order.md)。
- **服事团队** -- 与您一同服事的人员及其职位，并显示人数和团队数（例如"10 人服事 · 3 个团队"）。拒绝其职位的人员不会被列出。点击**全部团队**可查看每个团队及其成员。
- **计划备注** -- 计划创建者为团队添加的任何备注。
- **下载** -- 附加在计划课程内容中的文件（如有）。

在完整礼拜流程或团队列表顶部点击**返回**，*计划名称*即可返回计划页面。

## 拒绝已接受的安排 {#declining-an-accepted-assignment}

如果您接受后出现了变化，仍可以在计划页面上退出：

1. 打开计划，在**您的安排**下找到您的职位。该职位会显示**已接受**标记。
2. 点击该职位下方红色的**拒绝**链接。
3. 系统会要求确认**拒绝此安排？** -- "您的团队负责人将收到通知，告知您无法再服事此职位。"
4. 点击**拒绝**确认，或点击**取消**保留该安排。

您的状态将变为**已拒绝**。无论您在计划页面、计划页面的**需要您回复**板块，还是主页的**您正在服事**板块中点击**拒绝**，都会出现相同的确认提示 -- 因此误触不会导致安排被拒绝。

## 接受已拒绝的安排 {#accepting-a-declined-assignment}

拒绝后改变了主意？打开计划，在显示**已拒绝**标记的职位下，点击**接受**。您的状态将恢复为**已接受**。

**拒绝**和**接受**链接仅在您的礼拜时间结束之前可用 -- 此后，您无法再从计划页面更改该安排。

如果您从未回复某项安排，且其礼拜时间已经过去，计划页面会显示**回复已关闭**标记，取代**接受**和**拒绝**按钮，并附有说明*"此服事时间已过，因此您无法再回复。"*

:::tip
如果您在不同计划中有多项安排，列表会按日期排序，因此您即将承担的事项会排在最前面。请定期查看，以便掌握您的排班情况。
:::

## 课程的教师视图 {#teacher-view-for-lessons}

如果您的计划包含来自内容提供商（例如 Lessons.church）的相关课程，**礼拜流程**板块会显示该课程的板块以供快速浏览，计划页面顶部还会出现**教学**按钮。

点击**教学**即可打开专为教师设计的沉浸式全屏课程演示，其中包含格式化的说明、嵌入的媒体、备注以及分步指导。关闭后即可返回计划。

教学视图将课程内容组织为多个板块。您可以：

- 点击顶部的**板块**，查看板块列表并直接跳转到课程的任何部分
- 滚动浏览课程内容 -- 标题会显示您当前所在的板块（例如"第 2 个板块，共 5 个"）
- 点击媒体项目（视频、图片、活动）即可在弹窗中查看；音频链接（歌曲录音、讲道片段）则会通过内置的音频播放器直接播放
- 查看以不同样式呈现的行动类型：**说**会以对话气泡显示，**做**以粗体文字显示，**备注**则以高亮提示框显示

:::tip
在带领教室或小组时，教学视图尤为有用，它以简洁、不分散注意力的格式呈现您的全部课程内容，并针对手机和平板电脑进行了优化。
:::
