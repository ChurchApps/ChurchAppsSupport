# 奉献

<div class="article-intro">

B1App 让您可以轻松通过在线捐款支持您的教会。无论您想进行一次性的快速奉献，还是管理定期奉献，您所需要的一切都可以在您教会的 B1.church 网站上找到。

</div>

## 概述

B1App 支持两种奉献方式：

- **公开捐款** -- 任何人无需登录即可进行捐款。访问您教会的捐款页面，选择基金并输入付款信息即可。无需账户。
- **已登录奉献** -- 在捐款前[登录](../getting-started/logging-in.md)，您的奉献将关联到您的账户。这让您可以查看完整的奉献历史、打印奉献证明、管理定期奉献以及使用已保存的付款方式。

## 您可以做什么

以下是奉献部分提供的功能：

- **向特定基金奉献** -- 您的教会可能设有多个基金，例如普通基金、建堂基金或宣教基金。您可以选择将奉献指定到哪个基金。
- **使用信用卡或银行账户付款** -- 奉献通过 Stripe 安全处理。您可以使用信用卡或借记卡付款，也提供 ACH 银行转账的付款说明。
- **设置定期奉献** -- 登录的成员可以安排自动定期奉献，确保您不会错过任何一次奉献。
- **查看奉献历史** -- 查看您过往奉献的完整列表，包括日期、方式、基金和金额。
- **打印奉献证明** -- 生成当年或往年的可打印奉献证明，用于您的报税记录。
- **管理付款方式** -- 保存并管理您的付款方式，以便将来更快速地奉献。

您的教会可以限制成员可以查看哪些年份的奉献历史，也可以将其隐藏，并可以添加显示在您的奉献页面和证明上的奉献说明。参见[奉献历史](./donation-history.md#if-your-church-limits-giving-history)。

:::info
奉献通过 **Stripe** 安全处理。您的付款信息绝不会存储在 B1.church 的服务器上。
:::
