# 奉献

<div class="article-intro">

B1App 让您可以轻松地通过在线捐赠支持教会。无论您想进行一次性的快速奉献，还是管理定期奉献，您所需的一切都可以在教会的 B1.church 网站上找到。

</div>

## 概览 {#overview}

B1App 支持两种奉献方式：

- **公开捐赠** -- 任何人都可以无需登录，进行一次性或定期捐赠。访问教会的捐赠页面，选择基金，然后输入您的付款信息即可。无需账户，您也可以选择匿名奉献。
- **已认证奉献** -- 如果您在捐赠前[登录](../getting-started/logging-in.md)，您的奉献将与您的账户关联。这样您就可以查看完整的奉献历史、打印奉献对账单、管理定期奉献，并使用已保存的付款方式。

## 您可以做什么 {#what-you-can-do}

奉献板块提供以下功能：

- **向特定基金奉献** -- 您的教会可能设有多个基金，例如普通基金、建筑基金或宣教基金。您可以选择将奉献用于哪个基金。
- **使用信用卡或银行账户付款** -- 奉献由教会的支付服务商安全处理（大多数教会使用 Stripe）。您可以使用信用卡或借记卡付款，并且根据服务商的不同，还可以使用银行账户、移动支付或 PayPal 和 Venmo。也提供 ACH 银行转账的付款说明。
- **设置定期奉献** -- 登录的成员可以安排自动定期奉献，确保您不会错过任何一次奉献。
- **查看奉献历史** -- 查看您过往奉献的完整列表，包括日期、方式、基金和金额。
- **打印奉献对账单** -- 生成当年或上一年的可打印奉献对账单，用于您的税务记录。
- **管理付款方式** -- 保存并管理您的付款方式，以便将来更快地完成奉献。

您的教会可以限制成员可以查看的奉献历史年份，也可以将其隐藏，并可以添加显示在您的奉献页面和对账单上的奉献说明。请参阅[奉献历史](./donation-history.md#if-your-church-limits-giving-history)。

:::info
奉献由教会的支付服务商（例如 **Stripe**）安全处理。您的银行卡和银行账户信息绝不会存储在 B1.church 的服务器上。
:::
