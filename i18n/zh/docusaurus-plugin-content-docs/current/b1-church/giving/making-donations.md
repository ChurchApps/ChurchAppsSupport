# 进行奉献

<div class="article-intro">

您可以通过教会的 B1.church 网站以两种方式进行奉献：公开捐赠页面（无需登录）和成员捐赠页面（需要登录）。两者都使用教会支付服务商提供的安全奉献表单（大多数教会使用 Stripe）。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 公开捐赠无需账户 -- 只需访问教会的**捐赠**页面即可。
- 若要使用成员捐赠（可追踪历史并保存付款方式），请先[登录](../getting-started/logging-in.md)您的账户。

</div>

## 公开捐赠页面（无需登录） {#public-donation-page-no-login-required}

任何人都可以在不创建账户的情况下进行奉献：

1. 进入教会的**捐赠**页面。
2. 奉献表单显示在页面左侧。选择**进行奉献**以进行一次性奉献，或选择**设置定期奉献**以按计划奉献（选择频率和开始日期）。
3. 输入您的**名字**、**姓氏**和**电子邮件**，然后输入银行卡信息。
4. 在**基金**下，输入**金额**并选择**基金**。点击**添加更多**可将奉献分配到多个基金。
5. 可选填写**备注**。如果教会允许，您可以勾选该选项以承担交易手续费。
6. 点击**捐赠**完成奉献。

若您希望奉献时不显示您的姓名，请勾选**匿名奉献（仅限一次性奉献）**。此时姓名字段和定期奉献选项将被隐藏。

在页面右侧的**管理奉献**下，如果您希望通过银行转账奉献，可以看到**ACH 付款说明**的链接。如果您想登录以使用奉献历史等附加功能，还可以点击**登录**按钮（表单下方也有**登录以管理现有奉献**的链接）。

在您未登录时，成员门户中的**奉献**页面（`/mobile/donate`）会显示相同的表单，其下方带有**登录以管理定期奉献并查看历史**的链接。

:::tip
如果您在访问公开捐赠页面时已经登录，系统会自动将您重定向到成员捐赠页面，您可以在那里查看完整的奉献历史并使用已保存的付款方式。
:::

## 成员捐赠页面（已登录） {#member-donation-page-logged-in}

登录后，成员门户中的**奉献**页面顶部会显示**奉献**按钮和**打印对账单**按钮，随后是以下板块：

- **今年**（以当前年份为标题）-- 您的年初至今奉献总额及奉献笔数，并附有**全部历史**链接。详情请参阅[奉献历史](./donation-history.md)。
- **定期** -- 您预定的奉献，并附有**管理**链接。
- **近期活动** -- 您最近的三笔奉献，并附有**重复上次奉献**链接，点击后将打开奉献表单。
- **付款方式** -- 您已保存的银行卡和银行账户，并附有**管理**链接，可用于添加银行卡或银行账户，以及编辑或删除已保存的付款方式。
- 如果教会正在进行募捐活动，还会显示募捐进度卡片。

进行奉献的步骤：

1. 从教会的**捐赠**标签页、[主页仪表板](../getting-started/navigating.md#home)的**奉献**板块中的**奉献**按钮，或[我的页面](../getting-started/me-page.md)的**奉献**板块中的**历史**进入奉献页面。在奉献页面中，点击**奉献**打开奉献表单。
2. 选择**进行奉献**或**设置定期奉献**。
3. 选择已保存的付款方式，或输入新的银行卡信息。输入新卡时，若希望下次继续使用，请勾选**保存此卡用于未来奉献**（前提是教会的服务商支持保存银行卡）。
4. 选择您想奉献的**基金**并输入**金额**；点击**添加更多**可向多个基金奉献。列表仅显示教会向捐赠者提供的基金，即使您是可以在 B1 管理后台中查看其他基金的工作人员，也是如此。
5. 点击**预览奉献**以核对您的奉献，然后点击**捐赠**完成。点击**取消**即可返回奉献页面。

奉献处理完成后，将出现成功提示，您的奉献也会显示在您的[奉献历史](./donation-history.md)中。

:::info
如果您的奉献记录使用了多种货币，您的年初至今总额和历史总额将按教会的货币换算，并在下方显示**按当前汇率换算**的说明。奉献历史中的每笔单独奉献仍会显示其原始货币。
:::

## 付款方式 {#payment-methods}

奉献由您的教会所连接的支付服务商安全处理。您可以使用的付款方式取决于该服务商：

- **Stripe** -- 信用卡或借记卡，或银行账户（ACH）。
- **Kingdom Funding** -- 信用卡或借记卡，或银行账户（ACH）。
- **Paystack**（非洲的教会）-- 当地银行卡和移动支付，以当地货币结算。
- **PayPal 和 Venmo** -- 已设置 PayPal 的教会会在一次性奉献的银行卡输入框上方显示 **PayPal** 和 **Venmo** 按钮。定期奉献则使用银行卡输入框。

登录后，您的付款方式可以保存以供将来使用，下次奉献时会更加快捷。

:::info 未登录时通过银行账户奉献
如果您以访客身份（未登录）通过银行账户奉献，该账户必须通过登录您的银行即时验证。如果无法即时验证，您会看到"无法即时验证此银行账户。请使用银行卡奉献，或登录后在您的奉献个人资料中添加该银行账户。"需要数日验证的银行账户只能在您登录后添加。
:::

:::warning
如果您的奉献未能成功完成，请仔细检查您的付款信息并重试。如果问题仍然存在，请联系教会办公室寻求帮助。
:::
