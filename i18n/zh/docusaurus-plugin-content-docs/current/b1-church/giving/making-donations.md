# 进行捐赠

<div class="article-intro">

通过教堂的B1.church站点进行捐赠有两种方法：公开捐赠页面（不需要登录）和会员捐赠页面（需要登录）。两者都使用由Stripe驱动的安全捐赠表单。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 对于公开捐赠，无需账户——只需访问您的教堂的**捐赠**页面。
- 对于带有历史记录跟踪和已保存付款方式的会员捐赠，首先[登录](../getting-started/logging-in.md)您的账户。

</div>

## 公开捐赠页面（无需登录）

任何人都可以在不创建账户的情况下进行捐赠：

1. 导航到您的教堂的**捐赠**页面。
2. 捐赠表单显示在页面的左侧。选择您想要捐赠的**基金**。
3. 输入您的付款详细信息和您想要捐赠的金额。
4. 提交表单以完成您的捐赠。

在页面的右侧，如果您更喜欢通过银行转账捐赠，您会看到一个**ACH付款说明**的链接。如果您想要登录以访问捐赠历史等附加功能，还有一个**登录**按钮。

:::tip
如果您在访问公开捐赠页面时已经登录，您将自动重定向到会员捐赠页面，您可以在那里访问您的完整捐赠历史和已保存的付款方式。
:::

## 会员捐赠页面（已登录）

当您登录时，捐赠体验包括额外的功能，组织为四个选项卡：

- **概览** -- 您年初至今的捐赠总额、活动进度卡片（如果教堂有有效活动）以及您最近的赠予，带有一键**重复**按钮。
- **捐赠** -- 捐赠表单。
- **管理** -- 您的已保存付款方式（添加、移除或设置默认卡或银行账户）。
- **历史记录** -- 您过去的捐赠、按期间的捐赠总额、定期赠予和声明导出。见[捐赠历史记录](./donation-history.md)以获取详细信息。

要捐赠：

1. 从您的教堂的**捐赠**选项卡或从您[我的页面](../getting-started/me-page.md)上**快捷方式**中的**捐赠**打开捐赠页面。如果您进入**概览**，选择**捐赠**选项卡。
2. 选择您想要捐赠的**基金**并输入您的捐赠金额。
3. 选择现有已保存的付款方式或输入新的付款详细信息。
4. 提交表单以完成您的捐赠。

捐赠处理后，会出现成功消息，您的捐赠将出现在您的[捐赠历史记录](./donation-history.md)中。

:::info
如果您给予的捐赠以多个币种记录，您的概览年初至今总额和历史记录期间总额转换为您的教堂币种，下面有**以当前汇率转换**说明。您历史记录中的个人捐赠仍然显示其原始币种。
:::

## 付款方式

捐赠通过**Stripe**安全处理。您可以用信用卡、借记卡支付或设置ACH银行付款。当您登录时，您的付款方式可以保存供将来使用，使下次捐赠更快。

:::warning
如果您的捐赠未通过，请仔细检查您的付款详细信息并重试。如果问题持续，请联系您的教堂办公室以获取帮助。
:::
