# 进行捐赠

<div class="article-intro">

您可以通过教会的 B1.church 网站进行捐赠，共有两种方式：公开捐赠页面（无需登录）和会员捐赠页面（需要登录）。两者都使用由 Stripe 提供支持的安全捐赠表单。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 进行公开捐赠无需账户，只需访问教会的**捐赠**页面即可。
- 如需进行会员捐赠并记录捐赠历史、保存付款方式，请先[登录](../getting-started/logging-in.md)您的账户。

</div>

## 公开捐赠页面（无需登录）

任何人都可以在不创建账户的情况下进行捐赠：

1. 前往教会的**捐赠**页面。
2. 捐赠表单显示在页面左侧。选择您想要奉献的**基金**。
3. 输入您的付款信息以及您希望奉献的金额。
4. 提交表单，完成捐赠。

在页面右侧，如果您希望通过银行转账捐赠，可以看到**ACH 付款说明**链接。如果您想登录以使用捐赠历史等额外功能，还可以点击**登录**按钮。

:::tip
如果您在访问公开捐赠页面时已经登录，系统会自动将您重定向到会员捐赠页面，在那里您可以查看完整的奉献记录并使用已保存的付款方式。
:::

## 会员捐赠页面（已登录）

登录后，会员门户中的**奉献**页面顶部会显示**捐赠**按钮和**打印对账单**按钮，其下方为以下几个部分：

- **今年**（标题为当前年份）——您本年度至今的奉献总额和捐赠笔数，并附有**全部历史**链接。详情请参阅[捐赠历史](./donation-history.md)。
- **定期**——您的定期捐赠安排，并附有**管理**链接。
- **最近活动**——您最近三次的捐赠，并附有**重复上次捐赠**链接，点击后将打开捐赠表单。
- **付款方式**——您已保存的银行卡和银行账户，并附有**管理**链接，可用于添加、删除或设置默认付款方式。
- 如果您的教会正在进行募捐活动，还会显示募捐进度卡片。

进行捐赠的步骤：

1. 通过以下任一方式打开奉献页面：教会的**捐赠**标签页、[首页仪表盘](../getting-started/navigating.md#home)中**奉献**部分的**捐赠**按钮，或[我的页面](../getting-started/me-page.md)中**奉献**部分的**历史**。在奉献页面上，点击**捐赠**打开捐赠表单。
2. 选择您想要奉献的**基金**，并输入捐赠金额。即使您是可以在 B1 Admin 中查看其他基金的工作人员，列表中也只会显示教会向捐赠者开放的基金。
3. 选择一种已保存的付款方式，或输入新的付款信息。
4. 提交表单，完成捐赠。

捐赠处理完成后，将出现成功提示，您的捐赠也会显示在[捐赠历史](./donation-history.md)中。

:::info
如果您的捐赠记录使用了多种货币，您的本年度总额和历史总额将换算为教会所用的货币，并在下方附注**按当前汇率换算**。捐赠历史中的各笔捐赠仍会显示其原始货币。
:::

## 付款方式

捐赠通过 **Stripe** 安全处理。您可以使用信用卡、借记卡付款，或设置 ACH 银行付款。登录后，您的付款方式可以保存以供将来使用，下次捐赠时会更加便捷。

:::info 未登录时通过银行账户捐赠
如果您以访客身份（未登录）通过银行账户捐赠，该账户必须通过登录您的银行即时验证。如果无法即时验证，您将看到提示：“此银行账户无法即时验证。请使用银行卡捐赠，或登录后在您的奉献资料下添加该银行账户。”需要数天时间验证的银行账户，只能在登录后添加。
:::

:::warning
如果您的捐赠未能成功，请仔细检查付款信息并重试。如果问题仍然存在，请联系教会办公室寻求协助。
:::
