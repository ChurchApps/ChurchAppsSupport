# 奉献历史

<div class="article-intro">

登录后，您可以查看完整的历史捐款记录，并生成用于报税的奉献报表。您的奉献历史可在 B1.church 账户的**奉献**部分查看。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须已[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 您需要至少完成过一次捐款。请参见[进行捐款](./making-donations.md)开始操作。

</div>

## 查看历史记录

1. 登录您的 B1.church 账户。
2. 进入**奉献**部分。
3. 点击左侧面板中的**历史**，查看您的历史捐款记录。

您的奉献历史会以表格形式展示，包含以下列：

- **日期** -- 捐款发生的时间。
- **方式** -- 您的付款方式（例如"银行卡 - Visa"或"银行 - ACH"）。
- **基金** -- 捐款所指向的基金（例如常规基金、建堂基金）。
- **金额** -- 捐款的金额。

:::info
仍在处理中的捐款会在基金名称旁显示"待处理"标签，且金额会以不同颜色显示。
:::

## 导出和打印报表

点击奉献历史页头中的**下载**按钮，即可访问导出选项：

- **本年度（CSV）** -- 下载包含本年度所有捐款记录的 CSV 文件。您可以在电子表格应用程序中打开该文件。
- **本年度（打印）** -- 打开本年度的可打印奉献报表。
- **上一年度（CSV）** -- 下载包含上一年度所有捐款记录的 CSV 文件。
- **上一年度（打印）** -- 打开上一年度的可打印奉献报表。

:::tip
建议在新的一年伊始尽早打印上一年度的奉献报表，以便为报税季做好准备。可打印的报表包含您留存记录所需的全部详细信息。
:::

## 定期捐款

在**奉献**部分，您还可以点击**定期捐款**来管理您设置的任何定期奉献计划。此部分让您可以查看、更新或取消定期捐款，并管理您已保存的付款方式。

如果某笔定期捐款是通过 **Stripe** 扣款，您也可以选择**暂停**而不是取消——点击该笔捐款旁的暂停图标并确认即可。奉献会暂停，直到您再次点击该图标以**恢复**；已暂停的捐款会在列表中标记为**已暂停**。通过其他支付服务商的定期捐款仍可编辑或取消，但无法暂停。
