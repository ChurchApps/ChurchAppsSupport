# 捐赠历史记录

<div class="article-intro">

当您登录时，您可以查看您过去捐赠的完整记录并生成用于税务目的的捐赠声明。您的捐赠历史记录可从您B1.church账户的**捐赠**部分获得。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)您的B1.church账户。
- 您需要至少进行过一次捐赠。见[进行捐赠](./making-donations.md)以开始。

</div>

## 查看您的历史记录

1. 登录您的B1.church账户。
2. 导航到**捐赠**部分。
3. 单击**历史记录**选项卡以查看您过去的捐赠。

在顶部，**捐赠**卡片显示可选时期的总额——**年初至今**、**过去30天**、**过去90天**或**所有时间**——从下拉菜单中选择一个。如果该期间的捐赠以多个币种进行，总额转换为您的教堂币种，且**以当前汇率转换**说明出现在下方。

在总额下方，您的最近活动与以下内容一起列出：

- **日期** -- 捐赠的进行时间。
- **方式** -- 您如何支付（例如"卡 - Visa"或"银行 - ACH"）。
- **基金** -- 捐赠指向的基金（例如，常规基金、建筑基金）。
- **金额** -- 捐赠的金额，以其给出的币种。

:::info
仍在处理中的捐赠在基金名称旁边显示"待处理"标签，金额以不同的颜色显示。
:::

## 导出和打印声明

单击最近活动列表上方的**打印声明**以在新选项卡中打开可打印的捐赠声明，涵盖当前日历年。

:::tip
在新年初打印您的声明，在您需要税务申报前，而去年的捐赠仍然新鲜在您的历史记录中。
:::

## 定期捐赠

如果您有任何计划赠予，历史记录选项卡上的**定期**部分列出每一个及其金额、间隔和付款方式。

如果定期捐赠通过**Stripe**收费，您可以**暂停**它而不是取消——单击捐赠旁边的暂停图标并确认。捐赠停止，直到您单击同一图标**恢复**；暂停的捐赠在列表中标记为**已暂停**。来自其他付款提供商的定期捐赠仍然可以编辑或取消，但不能暂停。

要添加、移除或更改您的已保存付款方式，请使用**管理**选项卡。
