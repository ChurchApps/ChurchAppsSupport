# 我的报名

<div class="article-intro">

成员门户中的**报名**页面是您所有已报名活动的主页。您可以在这里查看报名状态、支付未结清的余额、编辑参加人员和所订购的项目，或完全取消报名。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md) -- 访客报名不会显示在这里
- 您需要至少有一次活动报名。请参阅[报名参加活动](./registering.md)。

</div>

## 查看您的报名 {#viewing-your-registrations}

打开成员门户中的**我的**页面，点击**请求与报名**板块中的**报名**。您家庭的报名会分为**即将举行**和**已结束**两类（显示最近的三场已结束活动；点击**全部已结束**可查看其余活动）。每项报名会显示：

- **活动标题和日期**，后面是您报名的**成员**
- **状态**标签 -- **已报名**、**待处理**、**候补中**或**已取消**；如果仍有欠款，则显示**待付余额**
- 付款信息行 -- 已付金额与总额（例如"总计：$25.00 / $25.00"），或"待付余额 $25.00，共 $25.00"并附带**完成付款**按钮

如果您还没有报名任何活动，您会看到"您尚未报名任何活动。请稍后再来查看即将举行的活动。"

## 完成付款 {#completing-a-payment}

对于有未结清余额的报名，都会出现**完成付款**按钮 -- 最常见的情况是您从候补名单中转为正式报名后，或员工修改报名后您的总额发生了变化。

1. 点击**完成付款**。
2. 核对订单摘要，选择已保存的银行卡或输入新卡信息，然后付款。
3. 余额付清后，该报名将显示为**已报名**。

:::tip
当候补名额为您空出时，教会发送的电子邮件中包含一个直接前往此付款步骤的链接。
:::

## 编辑报名 {#editing-a-registration}

计划可能会有变化。点击报名上的**编辑**，即可打开**编辑报名**对话框，您可以：

- 修改每位成员的**名字**、**姓氏**和**参加者类型**
- 调整**选择数量**（如 T 恤或餐食等附加项目）

点击**保存**以保留修改，或点击**返回**在不保存的情况下关闭。若要更改您的联系方式，请联系教会办公室。

编辑时仍受名额限制 -- 如果某个参加者类型或选项此后已售罄，系统会要求您选择其他选项。保存后会重新计算您的总额；如果修改后仍有待付余额，卡片上会出现**完成付款**按钮。

:::info
编辑报名不会自动扣除您的银行卡。如果新总额更高，请使用**完成付款**支付差额；如果新总额更低，请联系教会办理退款 -- 退款由教会工作人员通过其支付服务商处理。
:::

## 取消报名 {#canceling-a-registration}

1. 点击卡片上的**取消报名**。
2. 在**取消报名**？对话框中，点击**取消报名**确认 -- 取消后无法撤销。点击**保留**则维持现状。

该报名会保留在您的列表中，并标记为**已取消**。

您的名额会立即释放。如果活动设有候补名单，队列中的下一位会自动转为正式报名。您此前支付的任何款项不会自动退还 -- 如需退款，请联系教会办公室。
