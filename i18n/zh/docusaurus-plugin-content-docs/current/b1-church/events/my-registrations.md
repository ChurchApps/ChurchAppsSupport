# 我的报名

<div class="article-intro">

会员门户中的**报名**页面是你查看所有已报名活动的主页。在这里你可以查看状态、支付未结余款、编辑参加人员和已订购的内容，或直接取消报名。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你必须已[登录](../getting-started/logging-in.md)——访客报名不会显示在这里
- 你需要至少有一条活动报名记录。参见[活动报名](./registering)。

</div>

## 查看你的报名

在会员门户中打开**报名**。每条报名会显示为一张卡片，包含：

- **活动标题和日期**
- 一个**状态**标签——**已确认**、**待处理**、**候补中**或**已取消**
- 你报名的**成员**
- 付款信息行——已付总额，或如果仍有欠款则显示**待付余额**

如果你还没有任何报名，会看到"暂无报名。"

## 完成付款

任何有未结余款的报名上都会出现**完成付款**按钮——最常见的情况是在你从候补名单晋升后，或工作人员编辑更改了你的总额之后。

1. 点击**完成付款**。
2. 查看订单摘要，选择已保存的卡片或输入新卡片，然后付款。
3. 余款结清后，报名状态会变为**已确认**。

:::tip
当候补名额为你空出时，教会发送的邮件会包含一个直接跳转到该付款步骤的链接。
:::

## 编辑报名

计划有时会变。点击报名上的**编辑**打开**编辑报名**对话框，你可以在其中：

- 更新你的**联系方式**
- 更改每位成员的**姓名**和**参加者类型**
- 调整**选项数量**（如 T 恤或餐饮等附加项）

编辑时容量限制仍然适用——如果某个参加者类型或选项已经售罄，系统会要求你选择其他选项。保存后系统会重新计算总额；如果变更后仍有欠款，卡片上会出现**完成付款**按钮。

:::info
编辑操作绝不会自动扣款。如果新总额更高，请用**完成付款**支付差额；如果更低，请联系你的教会咨询退款事宜——退款由教会工作人员通过其支付服务提供商处理。
:::

## 取消报名

1. 点击卡片上的**取消报名**。
2. 在对话框中确认——取消操作无法撤销。

你的名额会立即释放。如果该活动有候补名单，排在最前的人会自动晋升。你已支付的任何款项不会自动退还——请联系教会办公室咨询退款事宜。
