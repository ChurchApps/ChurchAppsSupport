# 活动

<div class="article-intro">

B1.church 上的"活动"部分让您可以浏览教会即将举行的活动，并直接从网站进行报名。当您的教会为某个活动启用了报名功能后，您只需几个简单步骤即可为自己和家人报名——对于收费活动，您还可以选择参加者类型和附加选项、使用折扣码，并在报名过程中安全完成付款。

</div>

## 浏览活动

活动会显示在教会日历上。当您打开一个已启用报名功能的活动时，活动详情旁会显示一个**报名参加此活动**按钮。

已启用报名的活动会显示：

- **活动标题和描述** -- 说明活动的内容。
- **日期和时间** -- 活动举行的时间。
- **报名按钮** -- 一个蓝色按钮，点击后会带您进入报名表单。

## 报名状态

根据时间和名额情况，活动可能会显示不同的状态：

- **开放中** -- 报名已开放，您可以进行报名。
- **尚未开放** -- 报名窗口尚未开始。请在开放日期之后再来查看。
- **已截止** -- 报名截止日期已过。
- **已满** -- 所有可用名额均已被占满。

:::tip
如果某个活动已满，只要您的教会已启用**候补名单**功能，您仍可以加入候补——一旦有名额空出，系统会自动发邮件通知您。否则，请稍后再来查看；如果有人取消报名，名额可能会重新开放。
:::

## 您需要准备什么

- 一个 B1.church 账户（也可以以访客身份报名）
- 访问您教会 B1.church 网站的权限
