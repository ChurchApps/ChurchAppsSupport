# 活动

<div class="article-intro">

B1.church 上的活动板块让你可以浏览即将举行的教会活动，并直接在网站上报名。当教会为某活动开放报名时，你可以自行报名，并为家庭成员报名，只需几个简单的步骤即可完成。对于收费活动，你还可以在报名过程中选择参加者类型和选项、使用折扣码，并安全地完成付款。

</div>

## 浏览活动

活动会显示在教会网站上，可以是月历形式，也可以是即将举行活动的卡片形式。点击某个活动即可打开其专属页面，其中显示：

- **活动照片** -- 如果教会添加了照片。
- **活动标题和描述** -- 活动的内容介绍。
- **时间** -- 下一次活动的日期和时间，或定期活动的重复规律。
- **地点** -- 活动预订的房间（如有）。
- **Register for this Event** -- 一个按钮，点击后会进入报名表单。仅在为该活动开启报名时显示。
- **Add to my calendar** -- 下载该活动的日历文件，可在 Google 日历、Apple 日历、Outlook 或其他日历应用中打开。

点击页面顶部的 **All events** 即可返回。在即将举行的活动卡片上方，**Subscribe** 按钮可让你复制整个日历的 ICS 链接或下载该链接，这样新活动就会出现在你自己的日历应用中。

## 报名状态

根据时间和名额的不同，活动可能显示不同的状态：

- **Open** -- 可以报名。
- **Not Yet Open** -- 报名时间尚未开始。请在开放日期之后再来查看。
- **Closed** -- 报名截止日期已过。
- **Full** -- 所有名额均已满。

:::tip
如果活动已满，当教会开启候补名单功能时，你仍可能加入 **waitlist**（候补名单）——如果有名额空出，系统会自动通过电子邮件通知你。否则，请稍后再来查看；如果有人取消报名，名额可能会释放出来。
:::

## 你需要准备

- 一个 B1.church 账户（或者你可以以访客身份报名）
- 能够访问你教会的 B1.church 网站
