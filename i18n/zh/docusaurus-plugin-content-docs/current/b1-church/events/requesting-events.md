# 申请活动与房间

<div class="article-intro">

如果您的教会管理可预订的房间和资源，您可以直接在会员门户中申请一场活动，并选择所需的房间和设备。您在选择时会看到与现有预订的冲突提示，您的申请将提交给教会审批，您也可以在“我的申请”中跟踪或取消申请。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)会员门户
- 您的教会必须已在 B1 Admin 中设置好房间或资源——只有在设置后，申请链接才会出现

</div>

## 提交申请

1. 打开会员门户中的**我的**页面，在 **Requests & registrations**（申请与报名）部分点击 **Request an Event**（申请活动）。
2. 填写活动的基本信息：**Event title**（活动标题）、可选的**描述（Description）**、**Start**（开始）和 **End**（结束）时间（或选择 **All day**（全天）），以及是否**重复（Repeats）**。
3. 选择您需要的**房间（Rooms）**和**资源（Resources）**。对于资源，您可以设置**数量（Qty）**。
4. 注意冲突提示——如果您的时间与某个房间或资源的现有预订重叠，您会看到“*This time conflicts with an existing booking.*”（此时间与现有预订冲突。）您可以调整时间或选择其他选项。
5. 点击 **Submit Request**（提交申请）。

提交后，**Request submitted**（申请已提交）摘要会显示您所申请的每个房间和资源的状态：

- **Approved**（已批准）-- 立即预订成功（该房间或资源没有审批小组）。
- **Pending approval**（待批准）-- 需要教会相关人员先行审核。

## 跟踪您的申请

从“我的”页面打开 **My Requests**（我的申请）。每项申请都会显示活动、您提交申请的时间以及状态标签：

- **Pending**（待处理）-- 等待审批结果
- **Approved**（已批准）-- 您的预订已确认
- **Rejected**（已拒绝）-- 申请已被拒绝

在申请仍处于待处理状态时，您可以点击 **Cancel request**（取消申请）撤回申请（系统会要求您确认——取消后无法撤销）。

:::info
申请由教会工作人员在 B1 Admin 的[审批页面](../../b1-admin/calendars/approvals)中审核。哪些房间和资源需要审批由您的教会决定——请参阅[房间与资源](../../b1-admin/calendars/rooms-resources)。
:::
