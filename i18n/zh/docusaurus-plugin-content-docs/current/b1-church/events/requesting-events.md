# 申请活动与房间

<div class="article-intro">

如果你的教会跟踪可预订的房间和资源，你可以直接从会员门户申请一个活动——包括所需的房间和设备。在你选择的过程中，与现有预订的冲突会被标记出来，你的申请会提交给教会审批，你也可以在"我的申请"中跟踪或取消它。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 你必须已[登录](../getting-started/logging-in.md)会员门户
- 你的教会必须已在 B1 Admin 中设置房间或资源——申请快捷方式只有在设置完成后才会出现

</div>

## 提交申请

1. 在会员门户中打开**我**页面，点击快捷方式下的**申请活动**。
2. 填写活动基本信息：**活动标题**、可选的**描述**、**开始**和**结束**时间（或**全天**），以及是否**重复**。
3. 选择你需要的**房间**和**资源**。对于资源，你可以设置**数量**。
4. 留意冲突警告——如果你的时间与某个房间或资源的现有预订重叠，你会看到"*此时间与现有预订冲突。*"你可以调整时间或选择其他内容。
5. 点击**提交申请**。

提交后，**申请已提交**摘要会显示你申请的每个房间和资源的状态：

- **已批准** -- 立即预订成功（该房间或资源没有设置审批组）。
- **待批准** -- 需要教会中的某人先行批准。

## 跟踪你的申请

从"我"页面打开**我的申请**。每条申请都会显示活动信息、申请时间和一个状态标签：

- **待处理** -- 等待决定
- **已批准** -- 你的预订已确认
- **已拒绝** -- 申请被拒绝

在申请仍处于待处理状态时，你可以使用**取消申请**撤回它（系统会要求你确认——取消操作无法撤销）。

:::info
申请由教会工作人员在 B1 Admin 的[审批页面](../../b1-admin/calendars/approvals)上审核。哪些房间和资源需要审批由你的教会决定——参见[房间与资源](../../b1-admin/calendars/rooms-resources)。
:::
