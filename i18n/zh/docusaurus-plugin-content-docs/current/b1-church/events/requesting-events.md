# 申请活动与房间 {#requesting-events--rooms}

<div class="article-intro">

如果您的教会管理可预订的房间和资源，您可以直接在成员门户中申请活动，并选择所需的房间和设备。在您选择时，系统会标出与现有预订的冲突，您的申请将提交给教会审批，您也可以在"我的申请"中跟踪或取消申请。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)成员门户
- 您的教会必须已在 B1 Admin 中设置房间或资源 -- 只有这样，申请链接才会出现

</div>

## 提交申请 {#submitting-a-request}

1. 打开成员门户中的**我的**页面，点击**请求与报名**板块中的**申请活动**。
   除非教会已撰写了自己的说明（例如预订指南或需要提前多久申请），否则页面顶部会显示 *"Staff will approve each room and item."*（工作人员会审批每个房间和项目。）；如果有教会说明，则会显示该说明（请参阅[活动申请页面](../../b1-admin/settings/mobile-app.md#event-request-page)）。
2. 填写活动基本信息：**活动标题**、可选的**描述**，以及**开始**和**结束**时间。如果只需选择日期，请开启**全天**。
3. 选择您需要的**房间**和**资源**（每类可以选择多个）。选择后，您可以设置**准备时间（之前分钟数）**和**收尾时间（之后分钟数）**，或开启**自定义预订时段**，自行设置**预订开始**和**预订结束**时间。
4. 注意冲突提示 -- 如果您的时间与房间或资源的现有预订重叠，您会看到 *"Some selections may already be booked at this time."*（部分所选项目在此时间可能已被预订。）您可以调整时间或选择其他项目。
5. 如果活动会多次举行，请开启**重复**并设置重复规律。
6. 点击**提交申请**。在您输入活动标题之前，该按钮将保持灰色不可点击。点击**取消**可离开而不提交。

提交后，会显示**申请已提交**摘要，列出您所申请的每个房间和资源的状态（点击**我的申请**可前往您的列表）：

- **已批准** -- 立即完成预订（该房间或资源无需审批小组）。
- **待审批** -- 需要教会的某人先进行审核。

## 跟踪您的申请 {#tracking-your-requests}

从"我的"页面打开**我的申请**。申请会根据活动日期分为**即将举行**和**已结束**两类（点击**全部已结束**可查看较早的申请）。每项申请会显示活动标题及开始时间、您输入的描述、您所申请的每个房间和资源的状态，以及一个状态标签：

- **待处理** -- 等待审批结果
- **已批准** -- 您的预订已确认
- **已拒绝** -- 申请已被驳回

如果工作人员在驳回申请或申请中的某个房间或资源时给出了原因，该原因会以红色显示在申请下方，例如 *Rejected: The gym is booked that weekend.*（已拒绝：该周末体育馆已被预订。）。同样的原因也会包含在您收到的有关此决定的通知中。

申请仍在待处理时，您可以点击**取消申请**来撤回它。系统会弹出确认提示："取消此申请？此操作无法撤销。" -- 点击**取消申请**确认，或点击**保留**则维持现状。

您也可以点击"我的申请"顶部的**申请活动**按钮发起新的申请。

:::info
申请由教会工作人员在 B1 Admin 的[审批页面](../../b1-admin/calendars/approvals.md)中审核。哪些房间和资源需要审批由教会决定 -- 请参阅[房间与资源](../../b1-admin/calendars/rooms-resources.md)。
:::
