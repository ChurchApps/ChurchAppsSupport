# 小组详情

<div class="article-intro">

当您从小组页面点击某个小组时，将进入小组详情页面。您看到的内容取决于您是否已登录，已登录的成员还可以看到更多部分和功能。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 通过[浏览小组](./browsing-groups.md)找到要查看的小组。
- 如需完整访问所有部分，请[登录](../getting-started/logging-in.md)您的账户。

</div>

## 访客视图（未登录）

如果您未登录，将看到以下内容：

- **标题** -- 小组名称及其聚会时间和地点。在计算机上，小组照片会显示在其上方。
- **登录以加入** -- 小组名称下方的按钮。登录（或创建账户）后即可加入小组或申请加入。登录后，您将返回该小组，并直接进入加入步骤。
- **关于** -- 小组的完整描述，说明其目的和参与内容。
- **负责人** -- 小组负责人的姓名。点击负责人的姓名即可查看其个人资料。
- **即将举行的活动** -- 小组最多三项即将举行的活动，每项显示日期、时间和活动标题；如果活动开放报名，还会显示**报名**链接。如果小组没有即将举行的活动，则隐藏此部分。

## 成员视图（已登录）

如果您已登录但不是该小组的成员，您将看到小组的标题和**关于**部分，以及该小组的加入选项（参见下方的[加入小组](#joining-a-group)）。成为成员后，将显示接下来描述的各个部分。

成为成员后，小组标题会显示其名称、聚会日期、时间和地点；如果您的教会开启了小组聊天，还会显示**打开聊天**按钮。如果您是该小组的负责人，名称下方会显示**您 · 负责人**标签。在计算机上，标题位于左侧一栏，小组照片位于其中，各个部分则显示在其右侧。

该页面是一个分区式的单页。每个分区都显示简短预览，点击分区标题中的链接即可打开完整视图；点击**返回**，*小组名称*即可返回。可用的分区如下：

- **下一次活动** -- 小组的下一次即将举行的活动，并提供**参加** / **可能参加** / **无法参加**按钮（参见[活动回复](./event-rsvps.md)）。点击**全部活动**可打开小组日历：使用箭头切换月份，并在**日历**（月视图，点击某一天即可查看当天的活动）和**列表**（按日期顺序列出当月活动，并按天分组）之间切换。如果您正在查看当前月份，列表将从今天开始，因此只显示尚未发生的活动。如果小组的活动设有标签，您可以按标签进行筛选。
- **本周课程** -- 如果您的小组关联了 Lessons.church 的计划类型，且本周课程包含供家长带回家的内容，该内容将显示在**下一次活动**下方（仅限成员）。
- **聚会** -- 小组最近的聚会记录，按时间从新到旧排列。每条记录显示日期、出席人数（例如"12人中8人到场"），未来日期则显示**即将举行**，以及负责人对该次聚会的备注（保留粗体文字、列表和链接）。点击**全部聚会**可查看全部记录。只有当聚会有备注或出勤记录时才会显示。参见下方的[聚会备注和出勤](#meeting-notes-and-attendance)。
- **负责人备注** -- 仅对小组负责人可见。显示最新的两条负责人备注；点击**打开备注**可阅读全部备注并发布新备注。参见下方的[负责人备注](#leader-notes)。
- **表单** -- 教会已关联到小组的表单，每次最多显示三份。成员可以看到开放的表单，每份都带有**填写**按钮。负责人还可以看到已关闭的表单（标记为**已关闭**）、每份表单的回复数量，以及小组活动的报名表单（标记为**活动报名**）。点击**全部表单**可查看全部表单。仅当小组关联了表单时才会显示。参见下方的[关联表单](#linked-forms)。
- **消息** -- 小组聊天中的最新消息。点击**打开聊天**即可阅读和发布消息。仅对成员显示，且仅当教会为该小组开启了小组聊天时才会显示。更多详情请参见[小组对话](./conversations.md)。
- **成员** -- 小组成员的预览（负责人排在前面），以及成员和负责人的人数。点击**全部成员**可查看完整列表，并可使用**搜索成员**进行搜索。点击成员姓名可在[成员通讯录](../community/member-directory.md)中访问其个人资料。
- **资源** -- 为小组分享的前几个文件和链接。点击**全部资源**可查看全部资源；您可以下载已上传的文件，或打开已链接的资源。
- **计划** -- 小组的下一个服事计划。点击**全部计划**可查看全部计划。仅当小组有计划时显示。
- **关于** -- 小组的完整描述，以富文本格式呈现。仅当小组设有描述时显示。

成员还可以在页面底部看到**退出小组**链接。

## 负责人权限

如果您是小组的负责人，您还拥有额外的编辑权限：

- **创建和编辑活动** -- 点击**全部活动**，然后点击**添加活动**，即可将活动添加到小组日历中。创建活动时，您可以同时预订房间和资源——从可用的房间和资源中进行选择，设置可选的布置和收拾时间，预订申请会自动提交等待审批。
- **编辑重复活动** -- 打开重复活动进行编辑时，B1 会先询问您要更改哪些日期：**仅此日期**、**此日期及之后的所有日期**或**所有日期**。选择其中一项并点击**保存**即可打开活动。如果您选择了**仅此日期**，**重复**开关将隐藏，您的更改（或删除操作）仅适用于该日期。
- **删除活动** -- 点击活动旁的铅笔图标，然后点击**删除活动**并确认。对于重复活动，删除操作将遵循您打开活动时选择的日期——仅此日期、此日期及之后的所有日期，或整个系列。已删除的日期将不再出现在小组日历或成员的即将举行活动中。
- **设置活动提醒** -- 编辑现有活动时，开启**发送提醒**即可在活动开始前提醒参与者。选择提醒的发送时间、**每日时间**、**谁应该收到提醒？**，以及可选的**消息**，然后在**发送方式**下选择**推送**、**电子邮件**，或者（如果您的教会已设置短信功能）**短信**。短信仅发送给在[通知偏好设置](../getting-started/notification-preferences.md)中开启了短信提醒的人。
- **管理资源** -- 上传文件（最多100 MB存储空间）、添加链接或删除现有资源。
- **撰写聚会备注和记录出勤** -- 在**聚会**部分使用**添加备注**和**记录出勤**。参见[聚会备注和出勤](#meeting-notes-and-attendance)。
- **记录私人负责人备注** -- 使用**负责人备注**部分。参见[负责人备注](#leader-notes)。
- **阅读和打印表单答复** -- 使用**表单**部分。参见[关联表单](#linked-forms)。

如需更改小组的名称、描述或成员列表，请使用 B1 Admin。参见[小组成员](../../b1-admin/groups/group-members.md)。

### 聚会备注和出勤 {#meeting-notes-and-attendance}

小组负责人以及有权记录出勤的工作人员，会在**聚会**部分的标题中看到**添加备注**和**记录出勤**。成员则可以看到相同的聚会列表和备注，因此错过某周聚会的人也能跟上进度。

要撰写某次聚会的总结：

1. 点击**添加备注**。
2. 选择聚会**日期**。默认为过去一周内您最近的一次聚会，或今天。您也可以选择未来的日期，提前为聚会发布备注。
3. 在**备注**框中撰写备注——例如讨论的内容、通知事项或代祷请求。工具栏可用于添加粗体文字、列表和链接。
4. 点击**保存**。

如果该日期已有备注，则会打开该备注供您编辑。**记录出勤**页面在日期下方同样有**备注**框，因此您可以在记录出勤的同时撰写聚会总结。负责人也可以点击列表中的某次聚会，打开其出勤和备注。聚会备注与工作人员在 B1 Admin 中查看的小组**场次**备注相同——参见[记录出勤](../../b1-admin/attendance/recording-attendance.md#session-notes)。

### 负责人备注 {#leader-notes}

**负责人备注**是小组负责人专用的私人动态，例如用于记录跟进事项或牧养关怀事项。只有小组负责人可以查看或发布其中的内容。其他成员永远无法看到，除非教会工作人员同时也是该小组的负责人，否则他们也无法看到。

1. 在**负责人备注**部分，点击**打开备注**（或点击任意一条备注）。
2. 在底部的输入框中输入您的备注并发送。

在有人发布内容之前，动态会显示"暂无备注"，并附有提醒"只有本小组的负责人可以查看这些备注。"负责人可以在 B1 Admin 的小组页面上看到相同的备注——参见[小组成员](../../b1-admin/groups/group-members.md#leader-notes)。

### 关联表单 {#linked-forms}

教会工作人员可以在 B1 Admin 中将表单关联到您的小组——例如代祷请求卡或外出活动的许可表（参见[将表单关联到小组](../../b1-admin/forms/creating-forms.md#linking-a-form-to-a-group)）。关联的表单会出现在小组的**表单**部分。成员点击**填写**即可打开表单并提交。

负责人还可以阅读和打印答复内容：

1. 在**表单**部分，点击某份表单（或点击**全部表单**并选择一份）。小组活动中包含报名问题的报名记录也会列在此处。
2. 列表会显示每位答复者及其提交日期。未登录的人员的答复将显示为**匿名**。
3. 点击某人即可查看其答复，每个问题都显示在对应答案的上方。
4. 点击**打印**可打印该人的答复，或点击列表上方的**全部打印**以打印该表单的所有答复。

打印件顶部居中处会显示教会的标志（如果在 B1 Admin 中上传了**浅色背景标志**，则显示该标志）和名称，然后是表单名称，再然后是每个人的答复，并以其姓名和提交日期作为标题。负责人可以阅读答复，但不能更改答复或编辑表单。点击**全部表单**即可返回列表。

## 加入小组

当您登录后尚未成为成员时，小组详情页面上会出现加入按钮。按钮的文字取决于小组的加入政策：

- **加入小组** -- 小组是开放的。点击后您将立即成为成员。
- **申请加入** -- 小组需要审批。点击后会打开一个对话框，您可以在其中选择性地向小组负责人留言，然后提交申请。有关管理您的申请的详情，请参见[申请加入小组](./join-requests.md)。

发送申请后，该按钮将被**申请待处理**提示替代："您的加入申请已发送。小组负责人将进行审核。"

如果您未登录并点击了**登录以加入**，登录后将返回该小组，加入步骤会自动开始：开放的小组会立即将您添加为成员；需要审批的小组则会打开**申请加入**对话框。

如果两个按钮都没有出现，则表示该小组已关闭，成员只能由负责人或管理员手动添加。

:::info
您必须登录才能加入小组或申请加入小组。如果小组已关闭而您想加入，请联系您的教会办公室或该小组的某位负责人。
:::
