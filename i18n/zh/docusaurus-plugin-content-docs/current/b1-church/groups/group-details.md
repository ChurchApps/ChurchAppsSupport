# 小组详情

<div class="article-intro">

当您从小组页面点击某个小组时，会进入小组详情页面。您看到的内容取决于您是否已登录：已登录的成员可以看到更多板块和功能。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 通过[浏览小组](./browsing-groups.md)找到您想查看的小组。
- 如需完整访问所有板块，请[登录](../getting-started/logging-in.md)您的账户。

</div>

## 访客视图（未登录）

如果您未登录，将看到以下内容：

- **页眉** -- 小组的名称，以及其聚会时间和地点。在电脑上，小组的照片会显示在名称上方。
- **登录以加入** -- 位于小组名称下方的按钮。登录（或创建账户）即可加入小组或申请加入。登录后，您将返回该小组，并直接进入加入步骤。
- **关于** -- 完整的小组介绍，说明小组的宗旨和参与内容。
- **负责人** -- 小组负责人的姓名。您可以点击负责人的姓名查看其个人资料。
- **即将举行的活动** -- 小组最近的最多三场活动，每场显示日期、时间和活动标题；如果活动开放报名，还会显示**报名**链接。如果小组没有即将举行的活动，则隐藏此板块。

## 成员视图（已登录）

如果您已登录但不是该小组的成员，您会看到小组的页眉和**关于**板块，以及该小组的加入选项（参见下文的[加入小组](#joining-a-group)）。成为成员后，才会显示接下来介绍的各个板块。

成为成员后，小组页眉会显示小组名称、聚会日期、时间和地点；如果您所在的教会开启了小组聊天，还会显示**打开聊天**按钮。如果您是该小组的负责人，名称下方会出现**您 · 负责人**标签。在电脑上，页眉位于左侧一栏，包含小组照片，各个板块则显示在其右侧。

页面由多个板块组成。每个板块都会显示简短预览，板块标题中的链接可打开完整视图；点击**返回**加上*小组名称*即可回到此页。可用的板块如下：

- **下次活动** -- 小组的下一场即将举行的活动，并带有**参加** / **可能参加** / **无法参加**按钮（参见[活动报名](./event-rsvps.md)）。点击**所有活动**即可打开小组日历：使用箭头切换月份，并在**日历**（月历网格，点击某一天即可查看当天活动）和**列表**（按日期顺序列出当月活动，并按天分组）之间切换。当您查看的是当前月份时，列表将从今天开始，因此只显示尚未发生的活动。如果小组活动设有标签，您可以按标签进行筛选。
- **本周课程** -- 如果您的小组关联了 Lessons.church 计划类型，并且本周课程包含家长带回家的内容，该内容会显示在**下次活动**下方（仅限成员）。
- **聚会** -- 小组最近的聚会记录，按最新在前排列。每条记录显示日期、出席人数（例如"12 人中 8 人出席"），或未来日期的**即将举行**，以及该次聚会的负责人笔记，并保留其中的粗体文字、列表和链接。点击**所有聚会**查看全部记录。只有当聚会有笔记或出席记录时才会显示。参见下文的[聚会笔记和出席记录](#meeting-notes-and-attendance)。
- **负责人笔记** -- 仅对小组负责人可见。显示最新的两条负责人笔记；点击**打开笔记**即可阅读全部笔记并发布新笔记。参见下文的[负责人笔记](#leader-notes)。
- **消息** -- 小组聊天中的最新消息。点击**打开聊天**即可阅读和发布消息。仅对成员显示，并且仅当您所在的教会为该小组开启了小组聊天时才会显示。更多详情请参阅[小组对话](./conversations.md)。
- **成员** -- 小组成员的预览（负责人排在前面），以及成员和负责人的人数。点击**所有成员**查看完整名单，并可使用**搜索成员**进行搜索。点击成员姓名可访问其在[成员目录](../community/member-directory.md)中的个人资料。
- **资源** -- 为小组发布的前几个共享文件和链接。点击**所有资源**查看全部；您可以下载已上传的文件，或打开已链接的资源。
- **计划** -- 小组的下一个服务计划。点击**所有计划**查看全部。仅当小组有计划时才会显示。
- **关于** -- 小组的完整介绍，以富文本格式呈现。仅当小组设有描述时才会显示。

成员还可以在页面底部看到**退出小组**链接。

## 负责人权限

如果您是小组的负责人，您还拥有额外的编辑功能：

- **创建和编辑活动** -- 点击**所有活动**，然后点击**添加活动**，即可将活动添加到小组日历中。创建活动时，您可以同时预订房间和资源：从可用的房间和资源中进行选择，设置可选的布置和收场时间，预订申请将自动提交以等待批准。
- **编辑重复活动** -- 打开重复活动进行编辑时，B1 会先询问要更改哪些日期：**仅此日期**、**此日期及之后所有日期**或**所有日期**。选择后点击**保存**即可打开该活动。如果您选择了**仅此日期**，则会隐藏**重复**开关，您的更改（或删除操作）将仅应用于该日期。
- **设置活动提醒** -- 编辑现有活动时，开启**发送提醒**即可在活动开始前提醒参加者。选择提醒的发送时间、**每日时间**、**提醒对象**以及可选的**消息**，然后在**发送方式**下选择**推送**、**电子邮件**，或者，如果您的教会已设置短信功能，则选择**短信**。短信仅发送给在[通知偏好设置](../getting-started/notification-preferences.md)中开启了短信提醒的人员。
- **管理资源** -- 上传文件（最多 100 MB 存储空间）、添加链接，或删除现有资源。
- **记录聚会笔记和出席情况** -- 在**聚会**板块中使用**添加笔记**和**记录出席**。参见[聚会笔记和出席记录](#meeting-notes-and-attendance)。
- **记录私密负责人笔记** -- 使用**负责人笔记**板块。参见[负责人笔记](#leader-notes)。

要更改小组的名称、描述或成员名单，请使用 B1 Admin。参见[小组成员](../../b1-admin/groups/group-members.md)。

### 聚会笔记和出席记录 {#meeting-notes-and-attendance}

小组负责人以及有权记录出席情况的工作人员，会在**聚会**板块标题中看到**添加笔记**和**记录出席**。成员可以看到相同的聚会列表和笔记，因此错过某次聚会的人也能及时了解内容。

要撰写聚会总结：

1. 点击**添加笔记**。
2. 选择聚会**日期**。默认为过去一周内您最近的一次聚会，或今天。您也可以选择未来的日期，提前为聚会发布笔记。
3. 在**笔记**框中写下笔记，例如讨论的内容、通知事项或代祷请求。工具栏可用于添加粗体文字、列表和链接。
4. 点击**保存**。

如果该日期已有笔记，则会打开该笔记以便编辑。**记录出席**屏幕在日期下方也有相同的**笔记**框，因此您可以在记录出席的同时撰写聚会总结。负责人也可以点击列表中的某次聚会，打开其出席记录和笔记。聚会笔记与工作人员在 B1 Admin 中小组的**课程**中看到的课程笔记相同 -- 参见[记录出席](../../b1-admin/attendance/recording-attendance.md#session-notes)。

### 负责人笔记 {#leader-notes}

**负责人笔记**是专供小组负责人使用的私密动态，例如用于跟进事项或牧养关怀事宜。只有小组负责人可以查看和发布。其他成员无法看到，除非教会工作人员同时也是该小组的负责人，否则他们也无法看到。

1. 在**负责人笔记**板块中，点击**打开笔记**（或点击任意一条笔记）。
2. 在底部的输入框中输入笔记并发送。

在有人发布之前，动态会显示"暂无笔记"，并附带提示"只有该小组的负责人可以查看这些笔记。"负责人可以在 B1 Admin 中该小组的页面上看到相同的笔记 -- 参见[小组成员](../../b1-admin/groups/group-members.md#leader-notes)。

## 加入小组 {#joining-a-group}

当您已登录但尚未成为成员时，小组详情页面会出现加入按钮。按钮的文字取决于小组的加入政策：

- **加入小组** -- 小组开放加入。点击后您会立即成为成员。
- **申请加入** -- 小组需要批准。点击后会打开一个对话框，您可以在其中附上给小组负责人的可选留言，然后提交申请。有关管理您的申请，请参见[申请加入小组](./join-requests.md)。

提交申请后，该按钮会被**申请待处理**提示取代："您的加入申请已发送。小组负责人将会审核。"

如果您在未登录时点击了**登录以加入**，登录后您将返回该小组，加入步骤会自动开始：开放的小组会立即将您加入，需要批准的小组则会打开**申请加入**对话框。

如果这两个按钮都没有出现，说明该小组已关闭，成员只能由负责人或管理员手动添加。

:::info
您必须登录后才能加入或申请加入小组。如果小组已关闭而您希望加入，请联系教会办公室或小组负责人。
:::
