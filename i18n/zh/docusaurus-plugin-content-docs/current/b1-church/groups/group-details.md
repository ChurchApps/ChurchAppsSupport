# 小组详情

<div class="article-intro">

当您从小组页面点击某个小组时，会进入小组详情页面。您看到的内容取决于您是否已登录：已登录的成员可以看到更多板块和功能。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 请先[浏览小组](./browsing-groups.md)，找到您想查看的小组。
- 若要访问所有板块，请[登录](../getting-started/logging-in.md)您的账户。

</div>

## 访客视图（未登录） {#visitor-view-not-logged-in}

如果您未登录，将看到以下内容：

- **页眉** -- 小组名称，以及聚会时间和地点。在电脑上，小组照片会显示在其上方。
- **登录以加入** -- 位于小组名称下方的按钮。登录（或创建账户）即可加入小组或申请加入。登录后，您会返回该小组，并直接进入加入步骤。
- **关于** -- 小组的完整简介，说明其宗旨和可期待的内容；如果小组没有简介，则显示"暂无详情。"
- **领袖** -- 小组领袖的姓名。点击领袖的姓名即可查看其个人资料。
- **即将举行的活动** -- 该小组最多三场即将举行的活动，每场显示活动标题、日期、时间和简介；如果活动接受报名，还会显示**报名**链接。如果小组没有即将举行的活动，此板块会被隐藏。

## 成员视图（已登录） {#member-view-logged-in}

如果您已登录但不是该小组的成员，您会看到小组的页眉和**关于**板块，以及该小组的加入选项（参见下方的[加入小组](#joining-a-group)）。下面介绍的板块会在您成为成员后出现。

成为成员后，小组页眉会显示小组名称、聚会的星期、时间和地点；如果教会已开启小组聊天，还会显示**打开聊天**按钮。如果您是该小组的领袖，名称下方会显示**您 · 领袖**标签。在电脑上，页眉位于左侧一栏，内含小组照片，各板块则显示在其右侧。

页面为一页多个板块的布局。每个板块都显示简短预览，板块标题中的链接会打开完整视图；点击**返回**，然后点击*小组名称*即可返回。可用的板块包括：

- **下一场活动** -- 小组的下一场即将举行的活动，附带**会参加** / **可能参加** / **不能参加**按钮（参见[活动回复（RSVP）](./event-rsvps.md)）。接受报名的活动会有**报名**链接；您报名后，您的状态（**已报名**、**待处理**或**候补中**）会显示在该位置（此卡片和完整活动列表中均会显示），点击即可进入您的[报名记录](../events/my-registrations.md)。点击**全部活动**即可打开小组日历：使用箭头切换月份，并可在**日历**（月视图，点击某天即可查看当天活动）和**列表**（按日期顺序列出当月活动，并按天分组）之间切换。查看当前月份时，列表从今天开始，因此只显示仍即将举行的活动。如果小组活动带有标签，您可以按标签筛选。点击底部的**订阅**，即可将小组日历添加到您自己的日历应用中，新活动将自动显示在那里。
- **本周课程** -- 如果您的小组关联了 Lessons.church 计划类型，并且本周课程包含家长带回家的内容，则会显示在**下一场活动**下方（仅对成员可见）。
- **聚会** -- 小组最近的聚会，按最新优先排列。每次聚会都会显示日期、出席人数（例如"12 人中有 8 人到场"），如果是今天或未来的日期且尚无出勤记录，则显示**即将举行**；同时显示该次聚会的领袖备注，其中的粗体文字、列表和链接都会保留。点击**全部聚会**可查看全部记录。只有当某次聚会有备注或出勤记录时，该聚会才会显示。参见下方的[聚会备注与出勤](#meeting-notes-and-attendance)。
- **领袖备注** -- 仅对小组领袖可见。显示最新的两条领袖备注；点击**打开备注**即可阅读全部备注并发布新备注。参见下方的[领袖备注](#leader-notes)。
- **表单** -- 教会与该小组关联的表单，每次最多显示三个。成员可以看到开放中的表单，每个都带有**填写**按钮。领袖还可以看到已关闭的表单（标记为**已关闭**）、每个表单的回答数量，以及该小组活动的报名表单（标记为**活动报名**）。点击**全部表单**即可查看全部表单。仅当小组关联了表单时才会显示。参见下方的[关联表单](#linked-forms)。
- **消息** -- 小组聊天中的最新消息。点击**打开聊天**即可阅读和发布消息。仅对成员显示，并且仅当教会为该小组开启了小组聊天时才会显示。更多详情请参阅[小组对话](./conversations.md)。
- **成员** -- 小组成员的预览（领袖排在前面），以及成员和领袖的人数。点击**全部成员**查看完整列表，并可通过**搜索成员**进行搜索。点击成员姓名即可在[成员名录](../community/member-directory.md)中查看其个人资料。
- **资源** -- 为小组发布的前几个共享文件和链接。点击**全部资源**可查看全部资源；您可以下载上传的文件或打开链接的资源。
- **计划** -- 小组的下一个服事计划。点击**全部计划**可查看全部计划。仅当小组有计划时才会显示。
- **关于** -- 小组的完整简介，以富文本格式呈现。仅当小组有简介时才会显示。

成员还会在页面底部看到**离开小组**链接。点击后会先询问"离开此小组？"，因为您将失去对小组消息、活动和资源的访问权限；再次点击**离开小组**即可确认。

## 领袖权限 {#leader-capabilities}

如果您是小组领袖，您拥有以下额外的编辑功能：

- **创建和编辑活动** -- 点击**全部活动**，然后点击**添加活动**即可将活动添加到小组日历中。创建活动时，您可以同时预订房间和资源 -- 从可用的房间和资源中选择，设置可选的准备和收尾时间，预订申请会自动提交审批。
- **编辑重复活动** -- 打开重复活动进行编辑时，B1 会先询问要修改哪些日期：**仅此日期**、**此日期及之后所有日期**或**所有日期**。选择后点击**保存**即可打开该活动。如果您选择了**仅此日期**，**重复**开关将被隐藏，您的修改（或删除）仅适用于该单一日期。
- **删除活动** -- 点击活动旁边的铅笔图标，然后点击**删除活动**并确认。对于重复活动，删除操作将遵循您打开活动时所选的日期范围 -- 仅此日期、此日期及之后所有日期，或整个系列。已删除的日期将不再显示在小组日历或成员的即将举行活动中。
- **设置活动提醒** -- 编辑现有活动时，开启**发送提醒**，可在活动开始前提醒相关人员。选择提醒的发送时间、**一天中的时间**、**应提醒哪些人？**，以及可选的**消息**，然后在**发送方式**下选择**推送**、**电子邮件**，或（如果教会已设置短信功能）**短信**。短信仅发送给在其[通知偏好设置](../getting-started/notification-preferences.md)中开启了短信提醒的人。
- **管理资源** -- 上传文件（存储空间上限为 100 MB）、添加链接，或删除现有资源。
- **撰写聚会备注并记录出勤** -- 使用**聚会**板块中的**添加备注**和**记录出勤**。参见[聚会备注与出勤](#meeting-notes-and-attendance)。
- **撰写仅领袖可见的备注** -- 使用**领袖备注**板块。参见[领袖备注](#leader-notes)。
- **阅读和打印表单回答** -- 使用**表单**板块。参见[关联表单](#linked-forms)。

若要更改小组的名称、简介或成员名单，请使用 B1 管理后台。请参阅[小组成员](../../b1-admin/groups/group-members.md)。

### 聚会备注与出勤 {#meeting-notes-and-attendance}

小组领袖以及有权记录出勤的工作人员，会在**聚会**板块标题中看到**添加备注**和**记录出勤**。成员则可以看到相同的聚会列表和备注，因此错过某一周的人也可以随时了解情况。

若要撰写聚会总结：

1. 点击**添加备注**。
2. 选择聚会**日期**。默认为过去一周内您最近的一次聚会，或今天。您也可以选择未来的日期，以便在聚会前发布备注。
3. 在**备注**框中撰写备注，例如所讨论的内容、公告或代祷事项。工具栏可用于添加粗体文字、列表和链接。
4. 点击**保存**。

如果该日期已有备注，则会打开该备注供您编辑。**记录出勤**页面在日期下方同样有**备注**框，因此您可以在记录出勤的同时撰写总结。领袖也可以点击列表中的某次聚会，打开其出勤和备注。聚会备注与工作人员在 B1 管理后台小组的**课程**中看到的课程备注相同 -- 请参阅[记录出勤](../../b1-admin/attendance/recording-attendance.md#session-notes)。

### 领袖备注 {#leader-notes}

**领袖备注**是仅供小组领袖使用的私人信息流 -- 例如，用于记录后续跟进或牧养关怀事项。只有小组领袖可以查看或发布备注。其他成员看不到，除非工作人员同时也是该小组的领袖，否则工作人员也看不到。

1. 在**领袖备注**板块中，点击**打开备注**（或点击任意一条备注）。
2. 在底部的输入框中输入备注并发送。选中文字即可将其设为粗体或斜体，或转为列表 -- 参见[设置消息格式](./conversations.md#formatting-your-message)。

在有人发布备注之前，信息流会显示"暂无备注"，并附有提醒"只有此小组的领袖可以查看这些备注。"领袖可在 B1 管理后台的小组页面中看到相同的备注 -- 请参阅[小组成员](../../b1-admin/groups/group-members.md#leader-notes)。

### 关联表单 {#linked-forms}

教会工作人员可以在 B1 管理后台中将表单与您的小组关联 -- 例如代祷卡或外出活动的许可表（参见[将表单关联到小组](../../b1-admin/forms/creating-forms.md#linking-a-form-to-a-group)）。关联的表单会出现在小组的**表单**板块中。成员点击**填写**即可打开表单并提交。

领袖还可以阅读和打印回答：

1. 在**表单**板块中，点击某个表单（或点击**全部表单**后选择一个）。小组活动中包含报名问题的报名记录也会列在此处。
2. 列表会显示每位回答者及其提交日期。未登录者的回答将显示为**匿名**。
3. 点击某人即可查看其回答，每个问题都显示在其答案上方。
4. 点击**打印**即可打印该人的回答；或点击列表上方的**全部打印**，打印该表单的所有回答。

打印件顶部居中显示教会的标志（如果在 B1 管理后台中上传了**浅色背景标志**）和名称，随后是表单名称，再之后是每个人的回答，并以其姓名和提交日期作为标题。领袖可以阅读回答，但不能更改回答或编辑表单。点击**全部表单**即可返回列表。

## 加入小组 {#joining-a-group}

当您已登录但尚未成为成员时，小组详情页面上会出现加入按钮。按钮文字取决于该小组的加入政策：

- **加入小组** -- 小组开放。点击后您将立即成为成员。
- **申请加入** -- 小组需要审批。点击后会打开一个对话框，您可以附上可选的留言给小组领袖，然后提交申请。有关管理申请的详情，请参阅[申请加入小组](./join-requests.md)。

提交申请后，该按钮会被**申请待处理**提示取代："您的加入申请已发送。小组领袖将进行审核。"

如果您未登录，并点击了**登录以加入**，登录后您将返回该小组，加入步骤会自动开始：开放的小组会立即将您加入，需要审批的小组则会打开**申请加入**对话框。

如果两个按钮都未出现，说明该小组已关闭，必须由领袖或管理员手动添加成员。

:::info
您必须登录才能加入或申请加入小组。如果小组已关闭而您想加入，请联系教会办公室或该小组的某位领袖。
:::
