# 小组详情

<div class="article-intro">

当您从小组页面点击某个小组时，就会进入小组详情页面。您所看到的内容取决于您是否已登录，已登录的会员还能看到更多板块和功能。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 先[浏览小组](./browsing-groups.md)，找到要查看的小组。
- 如需完整访问所有板块，请[登录](../getting-started/logging-in.md)您的账户。

</div>

## 访客视图（未登录）

如果您未登录，将看到以下内容：

- **标题区**——小组名称，以及其聚会时间和地点。在电脑上，小组照片会显示在标题上方。
- **Sign in to join**（登录后加入）——位于小组名称下方的按钮。登录（或创建账户）后即可加入小组或申请加入。登录后，您会被带回该小组，并直接进入加入步骤。
- **About**（关于）——小组的完整描述，说明其目的以及期望的内容。
- **Leaders**（负责人）——小组负责人的姓名。您可以点击负责人的姓名查看其个人资料。
- **Upcoming Events**（即将举行的活动）——该小组最多三个即将举行的活动，每个都显示日期、时间和活动标题；如果该活动接受报名，还会显示 **Register**（报名）链接。您报名后，该链接会被您的状态取代——**Registered**（已报名）、**Pending**（待处理）或 **Waitlisted**（候补中）——点击即可打开您的报名记录。如果小组没有即将举行的活动，此部分会被隐藏。

## 会员视图（已登录）

如果您已登录但不是该小组的成员，您将看到小组的标题区和 **About** 部分，以及该小组的加入选项（参见下文[加入小组](#joining-a-group)）。成为会员之后，才会显示下面描述的各个部分。

当您是会员时，小组的标题区会显示小组名称、聚会日期、时间和地点；如果教会开启了小组聊天，还会显示 **Open chat**（打开聊天）按钮。如果您是该小组的负责人，名称下方会出现 **You · Leader**（您 · 负责人）标签。在电脑上，标题区位于左侧一栏，包含小组照片，各个部分则显示在其右侧。

该页面是一张由多个部分组成的页面。每个部分都会显示简短的预览，点击分区标题中的链接即可打开完整视图；点击 **Back to**（返回）*小组名称* 即可返回。可用的部分如下：

- **Next event**（下一个活动）——小组的下一个即将举行的活动，带有 **Going**（参加）/**Maybe**（待定）/**Can't go**（无法参加）按钮（参见 [活动 RSVP](./event-rsvps.md)）。接受报名的活动会有 **Register** 链接；您报名后，您的状态——**Registered**、**Pending** 或 **Waitlisted**——会显示在其位置（在此卡片上以及完整的活动列表中），点击即可打开您的[报名记录](../events/my-registrations.md)。点击 **All events**（全部活动）可打开小组日历：使用箭头切换月份，并可在 **Calendar**（日历，点击某一天即可查看当天的活动）和 **List**（列表，按日期分组显示当月的活动）之间切换。当您查看的是当前月份时，列表会从今天开始，只显示尚未发生的活动。如果小组的活动设有标签，您可以按标签进行筛选。
- **This week's lesson**（本周课程）——如果您的小组关联了 Lessons.church 计划类型，且本周课程有家长带回家的内容，则会显示在 **Next event** 下方（仅限会员）。
- **Meetings**（聚会）——小组最近的聚会，按最新排序。每次聚会都会显示日期、出席人数（例如“8 of 12 there”（12 人中 8 人到场）），或未来日期的 **Upcoming**（即将举行），以及负责人为该次聚会所写的备注，其中的粗体文字、列表和链接都会保留。点击 **All meetings**（全部聚会）可查看全部。只有在聚会有备注或出勤记录后，它才会出现在此处。参见下文[聚会备注与出勤](#meeting-notes-and-attendance)。
- **Leader notes**（负责人备注）——仅对小组负责人可见。显示最新的两条负责人备注；点击 **Open notes**（打开备注）可阅读全部备注并发布新备注。参见下文[负责人备注](#leader-notes)。
- **Forms**（表单）——教会为小组关联的表单，每次最多显示三个。会员可以看到开放中的表单，每个表单都有 **Fill out**（填写）按钮。负责人还会看到已关闭的表单（标记为 **Closed**（已关闭））、每个表单的回答数，以及该小组活动的报名表（标记为 **Event registration**（活动报名））。点击 **All forms**（全部表单）可查看全部。仅当小组已关联表单时才会显示。参见下文[关联表单](#linked-forms)。
- **Messages**（消息）——小组聊天中的最新消息。点击 **Open chat** 即可阅读和发布。仅对会员显示，且仅当教会为该小组开启了小组聊天时才会显示。更多详情请参见[小组对话](./conversations.md)。
- **Members**（成员）——小组成员的预览（负责人排在最前），以及成员和负责人的人数。点击 **All members**（全部成员）可查看完整列表，并可使用 **Search Members**（搜索成员）进行搜索。点击成员的姓名即可访问其在[成员目录](../community/member-directory.md)中的个人资料。
- **Resources**（资源）——为小组分享的前几个文件和链接。点击 **All resources**（全部资源）可查看全部；您可以下载已上传的文件，或打开已链接的资源。
- **Plans**（计划）——小组的下一份服事计划。点击 **All plans**（全部计划）可查看全部。仅当小组有计划时才会显示。
- **About**（关于）——小组的完整描述，以富文本格式呈现。仅当小组有描述时才会显示。

会员还可以在页面底部看到 **Leave Group**（退出小组）链接。

## 负责人权限

如果您是该小组的负责人，您还拥有额外的编辑权限：

- **创建和编辑活动**——点击 **All events**，然后点击 **Add Event**（添加活动），即可将活动添加到小组日历中。创建活动时，您可以同时预订房间和资源——从可用的房间和资源中选择，设置可选的布置和收场时间，预订申请会自动提交以供审批。
- **编辑重复活动**——打开重复活动进行编辑时，B1 会先询问您要更改哪些日期：**Just this date**（仅此日期）、**This and all following dates**（此日期及之后所有日期）或 **All dates**（所有日期）。选择一项并点击 **Save** 即可打开该活动。如果您选择了 **Just this date**，**Recurring**（重复）开关会被隐藏，您的更改（或删除操作）只会应用于该单个日期。
- **删除活动**——点击活动旁边的铅笔图标，然后点击 **Delete event**（删除活动）并确认。对于重复活动，删除操作会遵循您打开活动时所选的日期——仅此日期、此日期及之后所有日期，或整个系列。被删除的日期将不再出现在小组日历或会员的即将举行活动中。
- **设置活动提醒**——编辑现有活动时，打开 **Send reminders**（发送提醒），以便在活动开始前提醒人们。选择提醒的发送时间、**Time of Day**（时间点）、**Who should be reminded?**（提醒谁？）以及可选的**消息**，然后在 **Send By**（发送方式）下选择 **Push**（推送）、**Email**（电子邮件），或（如果教会已设置短信）**Text**（短信）。短信仅发送给在其[通知偏好](../getting-started/notification-preferences.md)中开启了短信提醒的人。
- **管理资源**——上传文件（最多 100 MB 存储空间）、添加链接，或删除现有资源。
- **撰写聚会备注并记录出勤**——在 **Meetings** 部分使用 **Add note**（添加备注）和 **Take attendance**（记录出勤）。参见[聚会备注与出勤](#meeting-notes-and-attendance)。
- **保存私人负责人备注**——使用 **Leader notes** 部分。参见[负责人备注](#leader-notes)。
- **阅读并打印表单回答**——使用 **Forms** 部分。参见[关联表单](#linked-forms)。

若要更改小组的名称、描述或成员名单，请使用 B1 Admin。参见[小组成员](../../b1-admin/groups/group-members.md)。

### 聚会备注与出勤 {#meeting-notes-and-attendance}

小组负责人以及有权记录出勤的工作人员，会在 **Meetings** 部分的标题中看到 **Add note**（添加备注）和 **Take attendance**（记录出勤）。会员则可以看到同样的聚会列表和备注，因此错过某一周的人也能补上进度。

要撰写某次聚会的总结：

1. 点击 **Add note**（添加备注）。
2. 选择聚会**日期**。默认为过去一周内您最近的一次聚会，或今天。您也可以选择未来的日期，提前为聚会发布备注。
3. 在 **Notes**（备注）框中撰写备注——例如讲授的内容、公告或代祷事项。工具栏可以添加粗体文字、列表和链接。
4. 点击 **Save**（保存）。

如果该日期已有备注，则会打开备注供您编辑。**Take attendance**（记录出勤）页面在日期下方同样有 **Notes**（备注）框，因此您可以在记录出勤的同时撰写聚会总结。负责人也可以点击列表中的某次聚会，打开其出勤和备注。聚会备注与工作人员在 B1 Admin 中小组的 **Sessions**（场次）中看到的场次备注相同——参见[记录出勤](../../b1-admin/attendance/recording-attendance.md#session-notes)。

### 负责人备注 {#leader-notes}

**Leader notes**（负责人备注）是供小组负责人使用的私人动态——例如用于跟进事项或牧养关怀事项的记录。只有小组负责人可以看到或发布其中的内容。其他会员永远看不到，除非工作人员同时也是该小组的负责人，否则他们也看不到。

1. 在 **Leader notes** 部分，点击 **Open notes**（打开备注）（或点击任意一条备注）。
2. 在底部的输入框中输入备注并发送。选中文字即可设为粗体或斜体，或将其设为列表——参见[设置消息格式](./conversations.md#formatting-your-message)。

在有人发布之前，该动态会显示 "No notes yet"（暂无备注），并提示 "Only this group's leaders can see these notes."（只有该小组的负责人可以看到这些备注。）负责人可以在 B1 Admin 的小组页面上看到相同的备注——参见[小组成员](../../b1-admin/groups/group-members.md#leader-notes)。

### 关联表单 {#linked-forms}

教会工作人员可以在 B1 Admin 中将表单关联到您的小组——例如代祷请求卡或外出活动的家长同意书（参见[将表单关联到小组](../../b1-admin/forms/creating-forms.md#linking-a-form-to-a-group)）。关联的表单会显示在小组的 **Forms**（表单）部分。会员点击 **Fill out**（填写）即可打开表单并提交。

负责人还可以阅读并打印回答：

1. 在 **Forms** 部分，点击某个表单（或点击 **All forms**（全部表单）并选择一个）。小组活动中设有报名问题的报名也会列在这里。
2. 列表会显示每位作答者以及他们的提交日期。未登录的人员的回答会显示为 **Anonymous**（匿名）。
3. 点击某人即可查看其回答，每个问题都显示在其答案上方。
4. 点击 **Print**（打印）即可打印该人员的回答，或点击列表上方的 **Print all**（全部打印）打印该表单的所有回答。

打印件顶部居中显示教会的徽标（如果已在 B1 Admin 中上传**浅色背景徽标**）和名称，然后是表单名称，再然后是每位作答者的回答，每份回答都带有其姓名和提交日期。负责人可以阅读回答，但不能更改回答或编辑表单。点击 **All forms** 可返回列表。

## 加入小组 {#joining-a-group}

当您已登录且尚未成为会员时，小组详情页面上会出现加入按钮。按钮的文字取决于小组的加入政策：

- **Join Group**（加入小组）——小组是开放的。点击后您会立即被添加为会员。
- **Request to Join**（申请加入）——小组需要批准。点击后会打开一个对话框，您可以附上可选的消息给小组负责人，然后提交申请。参见[申请加入小组](./join-requests.md)了解如何管理您的申请。

您发送申请后，该按钮会被 **Request Pending**（申请待处理）提示取代："Your request to join has been sent. A group leader will review it."（您的加入申请已发送。小组负责人将进行审核。）

如果您未登录，并点击了 **Sign in to join**（登录后加入），登录后您会返回该小组，加入步骤会自动开始：开放的小组会立即将您添加进来，需要批准的小组则会打开 **Request to Join** 对话框。

如果两个按钮都没有出现，说明该小组已关闭，成员必须由负责人或管理员手动添加。

:::info
您必须登录才能加入小组或申请加入小组。如果某个小组已关闭，而您想加入，请联系教会办公室或该小组的某位负责人。
:::
