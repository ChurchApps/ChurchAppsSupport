# 小组详情

<div class="article-intro">

当您点击小组页面上的小组时，您会被带到小组详情页面。您看到的内容取决于您是否已登录，已登录的成员可以访问额外的选项卡和功能。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 通过[浏览小组](./browsing-groups.md)找到要查看的小组。
- 要完全访问所有选项卡，请[登录](../getting-started/logging-in.md)您的账户。

</div>

## 访客视图（未登录）

如果您未登录，您将看到以下内容：

- **主题区域** -- 显示小组照片、名称、会议时间和会议地点的大型横幅区域。
- **描述** -- 小组的完整描述，解释其目的和期望。
- **领导者** -- 小组领导者的头像和名称。您可以点击领导者的名称查看其个人资料。
- **日历事件** -- 显示小组最多三个即将举行的事件，每个事件显示日期和事件标题。如果小组没有即将举行的事件，此部分将被隐藏。
- **登录以加入** -- 页面底部的按钮。登录（或创建账户）加入小组或请求加入。登录后，您将返回小组并直接进入加入步骤。

## 成员视图（已登录）

如果您已登录但不是小组的成员，您会看到小组的主题区域和描述以及小组的加入选项（请参阅下面的[加入小组](#加入小组)）。一旦您成为成员，接下来描述的选项卡将出现。

当您是成员时，小组详情页面显示主题区域以及一个选项卡边栏。如果您的小组与 Lessons.church 计划类型相关联，且本周的课程有家庭带回内容，**本周的课程**卡片会出现在主题和选项卡之间（仅限成员）。

可用的选项卡包括：

- **关于** -- 小组的完整描述，使用富文本格式呈现。仅在小组有描述时显示。
- **计划** -- 小组的服侍计划。仅在小组有计划时显示。
- **消息** -- 小组成员发布消息并相互互动的空间。仅显示给成员，且仅在您的教会为此小组启用了小组聊天时显示。有关详细信息，请参阅[小组对话](./conversations.md)。
- **成员** -- 小组中所有成员的列表，显示其照片和名称。您可以点击成员的名称访问[成员目录](../community/member-directory.md)中的个人资料。
- **参与** -- 仅对小组领导者（及具有参与权限的员工）可见。允许跟踪谁参加了小组会议。
- **事件** -- 显示小组的日历，包括会议和事件。您可以浏览即将举行和过去的事件。
- **资源** -- 为小组发布的共享文件和链接。您可以下载上传的文件或打开链接的资源。

## 领导者功能

如果您是小组的领导者，您拥有额外的编辑功能：

- **创建和编辑事件** -- 从**事件**选项卡中为小组日历添加事件。创建事件时，您可以在旁边预留房间和资源 -- 从可用房间和资源中选择，设置可选的设置和拆卸时间，预订请求会自动提交以供批准。
- **管理资源** -- 上传文件（最多 100 MB 存储空间）、添加链接或删除现有资源。
- **跟踪参与** -- 从**参与**选项卡记录小组会议的参与情况。

要更改小组的名称、描述或成员列表，请使用 B1 Admin。请参阅[小组成员](../../b1-admin/groups/group-members.md)。

## 加入小组

当您已登录且尚未成为成员时，小组详情页面上会出现一个加入按钮。按钮标签取决于小组的加入政策：

- **加入小组** -- 小组是公开的。点击此按钮会立即将您添加为成员。
- **请求加入** -- 小组需要批准。点击此按钮会打开一个对话框，您可以在其中向小组领导者包含一条可选消息，然后提交您的请求。有关管理您的请求的详细信息，请参阅[请求加入小组](./join-requests.md)。

发送请求后，该按钮被替换为**请求待审**通知："您的加入请求已发送。小组领导者将审核它。"

如果您未登录并点击了**登录以加入**，您会在登录后返回小组，加入步骤会自动启动：公开小组会立即将您添加进去，需要批准的小组会打开**请求加入**对话框。

如果两个按钮都没有出现，小组是关闭的，成员必须由领导者或管理员手动添加。

:::info
您必须登录才能加入或请求加入小组。如果小组已关闭，您想加入，请联系您的教会办公室或小组的领导者之一。
:::
