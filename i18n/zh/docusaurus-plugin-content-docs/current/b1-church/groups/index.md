# 群组

<div class="article-intro">

群组是与教会其他成员建立联系的好方法。无论您是在寻找小组、事工团队、查经班还是志愿服务机会，都可以直接从您教会的 B1.church 网站浏览并加入群组。

</div>

## 您可以做什么

在 B1App 中，您可以对群组进行以下操作：

- **浏览公开群组** -- 查看按类别整理的所有可用群组。每个群组都会显示照片、名称、聚会时间、地点和简短描述。
- **查看群组详情** -- 点击任意群组，查看完整描述、带领人以及即将举行的日历活动。
- **加入群组** -- 与群组建立联系，成为其成员。开放群组可立即加入；需要审批的群组则允许您提交入组申请。请参阅[申请加入群组](./join-requests.md)。
- **参与交流** -- 成为群组成员后，您可以在群组聊天中发布消息，并与其他成员互动。在群组页面点击**打开聊天**即可。
- **查看活动和资源** -- 查看群组的下一次活动（点击**全部活动**可查看完整日历），并在**资源**部分下载共享文件或链接。

## 公开访问与登录后的体验

任何人都可以访问您教会的群组页面并浏览可用群组。未登录的访客可以查看群组描述、了解带领人是谁，并查看即将举行的日历活动。要加入群组，访客需点击**登录以加入**，然后登录或创建账户。

当您[登录](../getting-started/logging-in.md)并且是某个群组的成员时，群组详情页会显示更多部分：**下一次活动**、**聚会**、**消息**、**成员**、**资源**、**计划**和**关于**。部分内容仅在适用时显示。例如，**关于**需要群组描述，**计划**需要服事计划，**消息**需要开启群组聊天。每个部分都会显示预览，并附有**全部成员**或**全部活动**等链接，用于打开完整列表。群组带领人在这些视图中拥有额外的编辑功能。

**聚会**部分列出群组最近的聚会，最新的排在最前，并显示每次聚会带领人的备注以及出席人数。错过某周聚会的成员可以在此补看。群组带领人以及有权记录考勤的工作人员，会在该部分标题处看到**添加备注**和**记录考勤**。**添加备注**可为任意日期添加简短备注，包括未来的聚会；备注中可以包含粗体文字、列表和链接。**考勤**页面在日期下方也有相同的**备注**框，因此您可以在记录考勤的同时撰写聚会总结。点击某次聚会即可打开其考勤页面。请参阅[聚会备注与考勤](./group-details.md#meeting-notes-and-attendance)。

群组带领人还会看到**带领人备注**部分。这是一个私密的信息流，群组带领人可以在此记录成员和教会工作人员看不到的备注。请参阅[带领人备注](./group-details.md#leader-notes)。

:::tip
群组对话位于每个群组的聊天中。您的群组会显示在[首页](../getting-started/navigating.md#home)的**您的群组**部分，群组的即将举行的活动则会显示在[我的页面](../getting-started/me-page.md)上。需要您关注的新动态会以通知的形式出现在铃铛菜单中。
:::
