# 小组

<div class="article-intro">

小组是与教会中其他人建立联系的绝佳方式。无论您在寻找小型团契、事工团队、查经小组，还是志愿服事机会，都可以直接从教会的 B1.church 网站浏览并加入小组。

</div>

## 您可以做什么

以下是您在 B1App 中可以对小组进行的操作：

- **浏览公开小组** -- 按分类查看所有可加入的小组。每个小组都会显示照片、名称、聚会时间、地点和简要描述。
- **查看小组详情** -- 点击任意小组即可查看其完整描述、负责人、即将举行的日历活动，以及可联系小组负责人的联系表单。
- **加入小组** -- 与小组建立联系，成为其成员。开放式小组可立即加入；需要审批的小组可以提交加入申请。请参见[申请加入小组](./join-requests.md)。
- **参与交流讨论** -- 成为小组成员后，您可以通过"交流"标签页发布消息，与其他小组成员互动。
- **访问日历和资源** -- 在小组日历上查看即将举行的活动，并从"资源"标签页下载共享的文件或链接。

## 公开体验与登录体验

任何人都可以访问教会的小组页面并浏览可用小组。未登录的访客可以查看小组描述、了解负责人是谁、查看即将举行的日历活动，并使用联系表单向负责人发送消息。

[登录](../getting-started/logging-in.md)后，您将解锁小组详情页面上的更多标签页，包括**小组详情**、**日历**、**交流**、**资源**、**成员**和**出席**。小组负责人在这些标签页中还拥有额外的编辑权限。

:::tip
小组内容也会出现在您的[动态](../community/timeline.md)中——来自您所属小组的交流和更新会自动显示在您的活动信息流中。
:::
