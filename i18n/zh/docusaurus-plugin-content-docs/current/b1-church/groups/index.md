# 小组

<div class="article-intro">

小组是与教会其他成员建立联系的绝佳途径。无论您想找的是小组团契、事工团队、圣经研读，还是志愿服务的机会，您都可以直接在教会的 B1.church 网站上浏览并加入小组。

</div>

## 您可以做什么 {#what-you-can-do}

以下是您在 B1App 中可以对小组进行的操作：

- **浏览公开小组** -- 搜索所有可用的小组，并按类别或校区进行筛选。每个小组都会显示照片、名称、聚会时间、地点和简短简介。
- **查看小组详情** -- 点击任意小组，即可查看其完整简介、领袖和即将举行的日历活动。
- **加入小组** -- 与小组建立联系，成为其成员。开放的小组可立即加入；需要审批的小组则可以提交加入申请。请参阅[申请加入小组](./join-requests.md)。
- **参与对话** -- 成为小组成员后，您可以在小组聊天中发布消息，并与其他小组成员互动 -- 在小组页面点击**打开聊天**即可。
- **查看活动和资源** -- 查看小组的下一场活动（点击**全部活动**可查看完整日历），并从**资源**板块下载共享的文件或链接。

## 公开体验与登录后的体验 {#public-vs-logged-in-experience}

任何人都可以访问教会的小组页面并浏览可用的小组。未登录的访客可以查看小组简介、了解领袖是谁，并查看即将举行的日历活动。若要加入小组，访客需点击**登录以加入**，然后登录或创建账户。

当您[登录](../getting-started/logging-in.md)并且是该小组的成员后，小组详情页面会显示更多板块：**下一场活动**、**聚会**、**消息**、**成员**、**资源**、**计划**和**关于**。某些板块仅在相关时才会显示 -- 例如，**关于**需要小组简介，**计划**需要服事计划，**消息**需要开启小组聊天。每个板块都会显示预览，并附有**全部成员**或**全部活动**等链接，用于打开完整列表。小组领袖在这些视图中拥有额外的编辑功能。

**聚会**板块列出小组最近的聚会，按最新优先排列，显示每次聚会的领袖备注以及到场人数。错过某一周的成员可以在此处补上进度。小组领袖以及有权记录出勤的工作人员，会在板块标题中看到**添加备注**和**记录出勤**。**添加备注**可为任何日期添加简短备注，包括未来的聚会；备注中可以包含粗体文字、列表和链接。**出勤**页面在日期下方同样有**备注**框，因此可以在记录出勤的同时撰写聚会总结。点击某次聚会即可打开其出勤记录。请参阅[聚会备注与出勤](./group-details.md#meeting-notes-and-attendance)。

小组领袖还会看到**领袖备注**板块：这是一个私人信息流，小组领袖可以在其中记录成员和教会工作人员看不到的备注。请参阅[领袖备注](./group-details.md#leader-notes)。

:::tip
小组对话存在于每个小组的聊天中，您所在的小组会显示在[主页仪表板](../getting-started/navigating.md#home)的**您的小组**板块中，小组的即将举行活动则会显示在[我的页面](../getting-started/me-page.md)上。需要您关注的新动态会以通知的形式出现在铃铛菜单中。
:::
