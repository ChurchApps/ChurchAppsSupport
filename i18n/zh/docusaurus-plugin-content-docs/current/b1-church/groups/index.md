# 小组

<div class="article-intro">

小组是与教会中其他人联系的好方式。无论您是在寻找小型小组、事工团队、圣经研究还是志愿者机会，您都可以直接从教会的 B1.church 网站浏览和加入小组。

</div>

## 您可以做什么

以下是您在 B1App 中可以对小组执行的操作：

- **浏览公开小组** -- 查看按类别组织的所有可用小组。每个小组显示照片、名称、会议时间、地点和简要描述。
- **查看小组详情** -- 点击任何小组查看其完整描述、领导者和即将举行的日历事件。
- **加入小组** -- 与小组联系以成为成员。公开小组让您立即加入；需要批准的小组让您提交加入请求。请参阅[请求加入小组](./join-requests.md)。
- **参与对话** -- 成为小组的成员后，您可以通过**消息**选项卡发布消息并与其他小组成员互动。
- **访问事件和资源** -- 在小组的**事件**选项卡上查看即将举行的事件，从**资源**选项卡下载共享文件或链接。

## 公开与已登录体验

任何人都可以访问您教会的小组页面并浏览可用的小组。未登录的访客可以查看小组描述、查看领导者，并查看即将举行的日历事件。要加入小组，访客点击**登录以加入**并登录或创建账户。

当您[登录](../getting-started/logging-in.md)并是小组的成员时，您将解锁小组详情页面上的额外选项卡：**关于**、**计划**、**消息**、**成员**、**参与**、**事件**和**资源**。某些选项卡仅在适用时出现 -- 例如，**关于**需要小组描述，**计划**需要服侍计划，**消息**需要启用小组聊天，**参与**显示给小组领导者和可以参与的人。小组领导者在这些选项卡上拥有额外的编辑功能。

:::tip
小组对话存在于每个小组的**消息**选项卡上，您的小组的即将举行的事件显示在[我的页面](../getting-started/me-page.md)上。需要您注意的新活动作为通知在铃铛菜单中到达。
:::
