# 小组

<div class="article-intro">

小组是与教会其他成员建立联系的好方式。无论您是在寻找小组团契、事工团队、圣经学习还是志愿服事的机会，都可以直接在教会的 B1.church 网站上浏览并加入小组。

</div>

## 您可以做什么

在 B1App 中，您可以通过小组完成以下操作：

- **浏览公开小组** -- 查看按类别组织的所有可参加的小组。每个小组都会显示照片、名称、聚会时间、地点和简短描述。
- **查看小组详情** -- 点击任意小组，查看其完整描述、负责人以及即将举行的日历活动。
- **加入小组** -- 与小组建立联系，成为其成员。开放的小组可以立即加入；需要审批的小组则可以提交加入申请。请参阅[申请加入小组](./join-requests.md)。
- **参与对话** -- 成为小组成员后，您可以在小组聊天中发布消息，并与其他成员互动——在小组页面上点击 **Open chat** 即可。
- **访问活动和资源** -- 查看小组的下一个活动（点击 **All events** 查看完整日历），并从**资源（Resources）**部分下载共享文件或链接。

## 访客与已登录用户的体验

任何人都可以访问教会的小组页面并浏览可参加的小组。未登录的访客可以查看小组描述、了解负责人是谁，并查看即将举行的日历活动。要加入小组，访客需点击 **Sign in to join**（登录以加入），然后登录或创建账户。

当您[登录](../getting-started/logging-in.md)并成为小组成员后，小组详情页面会显示更多部分：**Next event**（下一个活动）、**Messages**（消息）、**Members**（成员）、**Resources**（资源）、**Plans**（计划）、**Attendance**（考勤）和 **About**（关于）。部分内容仅在符合条件时才会显示——例如，**About** 需要小组有描述，**Plans** 需要有服事计划，**Messages** 需要开启小组聊天，**Attendance** 则只对小组负责人和有权记录考勤的人员显示。每个部分都会显示预览，并附有 **All members**（全部成员）或 **All events**（全部活动）等链接，用于打开完整列表。小组负责人在这些视图中拥有额外的编辑功能。

:::tip
小组对话位于每个小组的聊天中，您的小组会显示在[首页仪表板](../getting-started/navigating.md#home)的 **Your groups**（您的小组）部分中，您小组的即将举行的活动则会显示在[“我的”页面](../getting-started/me-page.md)上。需要您关注的新动态会以通知的形式出现在铃铛菜单中。
:::
