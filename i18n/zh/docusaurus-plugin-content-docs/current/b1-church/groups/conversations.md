# 小组对话

<div class="article-intro">

您小组页面上的消息选项卡是小组成员可以发布消息并相互交互的空间。使用对话来讨论主题、分享更新并在会议间隙与您的小组保持联系。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)您的B1.church账户。
- 您必须是小组的成员才能访问消息选项卡。见[小组详情](./group-details.md)以了解如何加入小组。

</div>

## 访问对话

1. 通过从[小组页面](./browsing-groups.md)单击小组来导航到小组详情页面。
2. 确保您已登录。
3. 单击侧边栏中的**消息**选项卡。

## 讨论和公告

消息选项卡可能会显示两个子选项卡，取决于您的教堂为此小组打开了哪些源：

- **讨论** -- 任何小组成员都可以发布消息并回复他人的空间。
- **公告** -- 小组领导者发布的对所有成员都很重要的消息。常规成员可以阅读公告并做出反应，但只有领导者可以发布。如果您尝试作为常规成员发布，您会看到一条说只有领导者可以发布公告并通过直接消息回复的说明。

如果您的教堂只为此小组打开了两个源之一，您只会看到该源而没有选项卡栏。如果两者都关闭，小组根本没有消息选项卡。

## 发布消息

1. 在您的小组页面上打开**消息**选项卡。
2. 确保您在**讨论**子选项卡上（如果选项卡栏可见）。
3. 在文本字段中输入您的消息。
4. 提交您的消息以与小组共享。

您的消息将对小组的所有成员可见。

## 编辑或删除您的消息

您可以编辑或删除您发布的任何消息：

1. 将鼠标悬停在您的消息上（或在移动设备上点击它）以显示**更多选项**按钮（⋮）。
2. 单击该按钮以打开消息菜单。
3. 选择**编辑**以修改消息文本，或**删除**以移除它。
   - 编辑时，消息文本加载回输入字段。进行您的更改并提交以保存它们。
   - 删除时，出现确认对话框。单击**确认**以永久移除消息。

:::info
您只能编辑或删除您自己的消息。其他成员发布的消息不显示编辑/删除选项。
:::

## 对消息做出反应

在小组聊天中，您可以用表情符号对任何消息做出反应：

1. 点击或将鼠标悬停在消息上并选择**添加反应**。
2. 从六个表情符号中选择一个：👍 ❤️ 😂 🎉 🙏 😮。

反应在消息下方显示为小卡片，显示有多少人使用了每一个的计数。您自己的反应突出显示——点击卡片（或再次选择相同的表情符号）以移除它，或选择不同的表情符号以添加另一个。反应实时为聊天中的每个人显示。

:::tip
小组对话也出现在您的[时间线](../community/timeline.md)上，因此您可以不用访问每个小组就可以跟上讨论。
:::

## 领导者功能

如果您是小组领导者，您在消息选项卡中有额外的功能：

- **发布公告** -- 切换到**公告**子选项卡并发布所有小组成员可以阅读的消息。
- **发布讨论** -- 您也可以像任何其他成员一样参与常规讨论。

:::info
对话特定于每个小组。您在一个小组中发布的消息不会出现在另一个小组的对话中。
:::
