# 群组对话

<div class="article-intro">

群组聊天是群组成员发布消息并彼此互动的空间。您可以使用对话讨论话题、分享最新动态，并在聚会之间与群组保持联系。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须已[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 您必须是群组成员才能访问群组聊天。有关如何加入群组，请参阅[群组详情](./group-details.md)。

</div>

## 访问对话

1. 从[群组页面](./browsing-groups.md)点击某个群组，进入群组详情页。
2. 确保您已登录。
3. 点击群组名称下方的**打开聊天**，或点击**消息**部分（该部分会预览最新消息）。聊天会全屏打开；点击返回箭头即可回到群组页面。

## 讨论与公告

群组聊天可以包含两个信息流，具体取决于您所在教会为该群组启用了哪些功能。聊天顶部群组名称上方的标签会显示您当前所在的信息流：

- **聊天** —— 讨论区，任何群组成员都可以发布消息并回复他人。
- **公告** —— 由群组负责人发布的、所有成员都应看到的重要消息。普通成员可以阅读公告并做出回应，但只有负责人可以发布；普通成员看到的不是消息输入框，而是提示"只有群组负责人可以发布公告。"

当两个信息流都已开启时，聊天顶部的**公告**横条会显示最新一条公告。点击**全部公告**可打开公告信息流，点击**返回聊天**则回到讨论区。（只有当群组至少有一条公告时，成员才会看到该横条。）

如果您所在教会只为该群组开启了其中一个信息流，聊天会直接打开该信息流。如果两者都已关闭，则该群组没有聊天功能，也不会显示**消息**部分。

## 发布消息

1. 在群组页面点击**打开聊天**。
2. 确保您位于**聊天**信息流中（如果您正在阅读公告，请点击**返回聊天**）。
3. 在**发送消息…**输入框中输入您的消息。
4. 点击发送按钮，将消息分享给群组。在手机或平板上，回车键会开始新的一行；在电脑上，**Enter** 键发送消息，**Shift+Enter** 开始新的一行。

您的消息对群组所有成员可见。每条消息都会显示发送时间：当天的消息显示时间，前一天的消息显示"昨天"及时间，更早的消息则显示日期和时间。

## 设置消息格式 {#formatting-your-message}

您可以为消息添加粗体、斜体和列表：

1. 输入消息，然后选中您想要设置格式的文字或段落。
2. 消息输入框上方会出现一个小工具栏，包含**粗体**、**斜体**、**项目符号列表**和**编号列表**按钮。点击其中一个即可应用格式。在文字仍处于选中状态时再次点击同一按钮，即可取消格式。
3. 像平常一样发送消息。

在电脑上，您还可以按 **Ctrl+B**（Mac 上为 **Cmd+B**）设置粗体，按 **Ctrl+I**（**Cmd+I**）设置斜体。

该工具栏会为您的文字添加简单的 Markdown 语法：`**粗体**`、`_斜体_`、行首的 `- ` 表示项目符号列表，以及 `1. ` 表示编号列表。您也可以自己直接输入这些符号。聊天中的所有人都能看到格式化后的消息，网页链接仍可点击，换行也会被保留。同样的格式也适用于公告、[负责人笔记](./group-details.md#leader-notes)和私信。

## 编辑或删除您的消息

您可以编辑或删除自己发布的任何消息：

1. 点击消息下方的**更多选项**按钮（⋮），打开消息菜单。
2. 选择**编辑**以修改消息内容，或选择**删除**以移除该消息。
   - 编辑时，消息文字会重新载入输入框，上方会显示**正在编辑消息**的提示（点击**取消**可停止编辑）。修改内容后发送即可保存。
   - 删除时，会出现**删除消息？**的确认提示。点击**删除**即可为对话中的所有人永久移除该消息。

:::info
您只能编辑自己的消息。群组负责人还可以删除其他成员的消息；普通成员只能看到自己消息的选项。
:::

## 回应消息

在群组聊天中，您可以用表情符号回应任何消息：

1. 点击消息下方的**添加回应**按钮。
2. 从六个表情符号中选择一个：👍 ❤️ 😂 🎉 🙏 😮。

回应会以小标签的形式显示在消息下方，并标注使用每个表情的人数。您自己的回应会高亮显示——点击该标签（或再次选择同一个表情）即可取消回应，选择其他表情则可添加新的回应。回应会实时显示给聊天中的所有人。

:::tip
群组对话现在统一放在各群组的聊天中——原先合并显示的[时间线](../community/timeline.md)信息流已经停用。需要您关注的动态会以通知的形式出现在应用栏的**铃铛**图标下方。
:::

## 负责人功能

如果您是群组负责人，在群组聊天中还拥有以下额外功能：

- **发布公告** —— 点击**全部公告**（或者当群组只开启了公告时，直接打开聊天），然后发布所有群组成员都可以阅读的消息。
- **删除消息** —— 通过消息菜单（⋮）删除任何成员的消息。
- **发布讨论** —— 您也可以像其他成员一样参与常规讨论。

:::info
对话是按群组划分的。您在一个群组中发布的消息，不会出现在其他群组的对话中。
:::
