# 小组对话

<div class="article-intro">

您小组页面上的消息标签是小组成员可以发布消息和彼此互动的空间。使用对话来讨论主题、分享更新并在聚会之间与您的小组保持联系。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 您必须 [登录](../getting-started/logging-in.md) 您的 B1.church 账户。
- 您必须是小组的成员才能访问消息标签。详见 [小组详情](./group-details.md) 了解如何加入小组。

</div>

## 访问对话

1. 通过点击 [小组页面](./browsing-groups.md) 中的小组导航到小组详情页面。
2. 确保您已登录。
3. 点击侧栏中的 **消息** 标签。

## 讨论和公告

消息标签可能显示两个子标签，具体取决于您的教会为该小组打开了哪些源：

- **讨论** -- 任何小组成员都可以发布消息并回复他人的空间。
- **公告** -- 小组领导发布的对所有成员都很重要的消息。普通成员可以阅读公告并对其做出反应，但只有领导可以发布。如果您尝试作为普通成员发布，您会看到一条注意，仅领导可以发布公告，请改为通过直接消息回复。

如果您的教会仅为该小组打开了这两个源之一，您会看到只有该源，没有选项卡栏。如果两者都关闭，该小组根本没有消息标签。

## 发布消息

1. 打开您的小组页面上的 **消息** 标签。
2. 确保您在 **讨论** 子标签上（如果选项卡栏可见）。
3. 在文本字段中输入您的消息。
4. 提交您的消息以与小组分享。

您的消息将对小组的所有成员可见。

## 编辑或删除您的消息

您可以编辑或删除您发布的任何消息：

1. 将鼠标悬停在您的消息上（或在移动设备上点击它）以显示 **更多选项** 按钮（⋮）。
2. 点击按钮打开消息菜单。
3. 选择 **编辑** 来修改消息文本，或 **删除** 来删除它。
   - 编辑时，消息文本加载回输入字段。做出更改并提交以保存。
   - 删除时，出现确认对话。点击 **确认** 以永久删除消息。

:::info
您只能编辑或删除您自己的消息。其他成员发布的消息不显示编辑/删除选项。
:::

## 对消息做出反应

在小组聊天中，您可以用表情符号对任何消息做出反应：

1. 点击或悬停在消息上并选择 **添加反应**。
2. 从六个表情符号中选择一个：👍 ❤️ 😂 🎉 🙏 😮。

反应显示为消息下的小芯片，带有使用每个芯片的人数计数。您自己的反应被突出显示 -- 点击芯片（或再次选择相同的表情符号）以删除它，或选择不同的表情符号以添加另一个。反应对聊天中的每个人都实时显示。

:::tip
小组对话位于每个小组的 **消息** 标签上 -- 旧的组合 [时间表](../community/timeline.md) 源已被停用。需要您注意的活动作为应用栏中 **铃** 图标下的通知到达。
:::

## 领导功能

如果您是小组领导，您在消息标签中拥有额外的功能：

- **发布公告** -- 切换到 **公告** 子标签并发布所有小组成员可以阅读的消息。
- **发布讨论** -- 您也可以像任何其他成员一样参与常规讨论。

:::info
对话特定于每个小组。您在一个小组中发布的消息不会出现在另一个小组的对话中。
:::
