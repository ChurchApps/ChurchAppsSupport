# 小组交流

<div class="article-intro">

小组页面上的"交流"标签页是小组成员发布消息、互相交流的空间。您可以通过交流讨论话题、分享动态，并在聚会之间与小组保持联系。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须已[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 您必须是该小组的成员才能访问"交流"标签页。有关如何加入小组，请参见[小组详情](./group-details.md)。

</div>

## 进入交流页面

1. 从[小组页面](./browsing-groups.md)点击某个小组，进入小组详情页面。
2. 确保您已登录。
3. 点击侧边栏中的**交流**标签页。

## 讨论和公告

"交流"标签页可能会显示两个子标签页：

- **讨论** -- 任何小组成员都可以在此发布消息并回复他人的空间。这是默认视图，始终可用。
- **公告** -- 由小组负责人发布、所有成员都应查看的重要消息。普通成员可以阅读公告，但只有负责人可以发布公告。

如果没有公告且您不是负责人，您将只会看到"讨论"视图，不会显示标签栏。

## 发布消息

1. 打开小组页面上的**交流**标签页。
2. 确保您位于**讨论**子标签页（如果标签栏可见）。
3. 在文本框中输入您的消息。
4. 提交消息，与小组分享。

您的消息将对小组的所有成员可见。

## 编辑或删除您的消息

您可以编辑或删除自己发布的任何消息：

1. 将鼠标悬停在您的消息上（在移动端则点击消息），显示**更多选项**按钮（⋮）。
2. 点击该按钮打开消息菜单。
3. 选择**编辑**修改消息文本，或选择**删除**将其移除。
   - 编辑时，消息文本会重新加载到输入框中。修改后提交即可保存更改。
   - 删除时，会弹出确认对话框。点击**确认**即可永久删除该消息。

:::info
您只能编辑或删除自己发布的消息。其他成员发布的消息不会显示编辑/删除选项。
:::

## 对消息作出回应

在小组聊天中，您可以使用表情符号对任意消息作出回应：

1. 点击或悬停在某条消息上，选择**添加反应**。
2. 从六种表情中选择一种：👍 ❤️ 😂 🎉 🙏 😮。

反应会以小标签的形式显示在消息下方，并标明使用每种表情的人数。您自己的反应会被高亮显示——点击该标签（或再次选择同一表情）即可移除，或选择其他表情添加新反应。反应会实时显示给聊天中的所有人。

:::tip
小组交流内容也会出现在您的[动态](../community/timeline.md)中，因此您无需逐一访问每个小组即可了解讨论情况。
:::

## 负责人功能

如果您是小组负责人，您在"交流"标签页中拥有额外的功能：

- **发布公告** -- 切换到**公告**子标签页，发布所有小组成员都能看到的消息。
- **发布讨论** -- 您也可以像其他成员一样参与常规讨论。

:::info
交流内容仅限于各自小组内部。您在某个小组中发布的消息不会出现在其他小组的交流中。
:::
