# 小组对话

<div class="article-intro">

小组聊天是小组成员发布消息并相互交流的空间。您可以利用对话讨论话题、分享动态，并在聚会之间与小组保持联系。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 您必须是该小组的成员才能访问小组聊天。请参阅[小组详情](./group-details.md)了解如何加入小组。

</div>

## 访问对话 {#accessing-conversations}

1. 从[小组页面](./browsing-groups.md)点击某个小组，进入小组详情页面。
2. 确认您已登录。
3. 点击小组名称下方的**打开聊天**，或点击**消息**板块（该板块会预览最新消息）。聊天会以全屏方式打开；点击返回箭头即可回到小组页面。

## 讨论与公告 {#discussions-and-announcements}

根据教会为该小组开启的功能，小组聊天可以包含两个消息流。聊天顶部小组名称上方的标签会显示您当前所在的消息流：

- **聊天** -- 讨论区，任何小组成员都可以发布消息并回复他人。
- **公告** -- 由小组领袖发布的、所有成员都应看到的重要消息。普通成员可以阅读公告并对其做出回应，但只有领袖可以发布；普通成员看到的不是消息框，而是"只有小组领袖可以发布公告。"

当两个消息流都已开启时，聊天顶部的**公告**栏会显示最新公告。点击**全部公告**可打开公告消息流，点击**返回聊天**则可回到讨论区。（只有当小组至少有一条公告时，成员才会看到该公告栏。）

如果教会只为该小组开启了其中一个消息流，聊天会直接打开该消息流。如果两者都未开启，则该小组没有聊天功能，也不会显示**消息**板块。

## 发布消息 {#posting-a-message}

1. 在您的小组页面点击**打开聊天**。
2. 确认您位于**聊天**消息流中（如果您正在阅读公告，请点击**返回聊天**）。
3. 在**发送消息**…框中输入您的消息。
4. 点击发送按钮即可与小组分享。在手机或平板电脑上，回车键用于换行；在电脑上，**Enter** 键用于发送，**Shift+Enter** 用于换行。

您的消息将对小组所有成员可见。每条消息都会显示发送时间：今天的消息显示时间，昨天的消息显示"昨天"及时间，更早的消息则显示日期和时间。

## 设置消息格式 {#formatting-your-message}

您可以为消息添加粗体、斜体和列表：

1. 点击消息框。选中后，其下方会显示一排按钮：**粗体**、**斜体**、**项目符号列表**和**编号列表**。
2. 输入您的消息，选中您想设置格式的文字或行，然后点击相应按钮即可应用。在文字仍处于选中状态时再次点击同一按钮即可取消格式。如果没有选中任何内容，列表按钮会对您当前所在的行进行格式设置。
3. 照常发送消息。

在电脑上，您还可以按 **Ctrl+B**（Mac 上为 **Cmd+B**）设置粗体，按 **Ctrl+I**（**Cmd+I**）设置斜体。

工具栏会为您的文字添加简单的 Markdown 格式：`**bold**`、`_italic_`，行首的 `- ` 表示项目符号列表，`1. ` 表示编号列表。您也可以自行输入这些符号。聊天中的所有人都能看到格式化后的消息；网页链接仍可点击（在新标签页中打开）；指向图片（.jpg、.png、.gif 等）的链接会在消息下方显示图片；换行也会被保留。相同的格式设置同样适用于公告、[领袖备注](./group-details.md#leader-notes)和私信。

## 编辑或删除您的消息 {#editing-or-deleting-your-messages}

您可以编辑或删除您发布的任何消息：

1. 点击消息下方的**更多选项**按钮（⋮）以打开消息菜单。
2. 选择**编辑**以修改消息内容，或选择**删除**将其移除。
   - 编辑时，消息内容会重新载入输入框，其上方会显示**正在编辑消息**的提示（点击**取消**即可停止编辑）。进行修改后发送即可保存。
   - 删除时，会出现**删除消息**？的确认提示。点击**删除**即可对对话中的所有人永久移除该消息。

:::info
您只能编辑自己的消息。小组领袖还可以删除其他成员的消息；普通成员只能在自己的消息上看到相应选项。
:::

## 回应消息 {#reacting-to-messages}

在小组聊天中，您可以用表情符号回应任何消息：

1. 点击消息下方的**添加回应**按钮。
2. 从六个表情符号中选择一个：👍 ❤️ 😂 🎉 🙏 😮。

回应会以小标签的形式显示在消息下方，并标注每种回应的人数。您自己的回应会被高亮显示 -- 点击该标签（或再次选择相同的表情符号）即可取消，选择其他表情符号则可添加另一个回应。回应会实时显示给聊天中的所有人。

:::tip
小组对话存在于每个小组的聊天中 -- 原先综合性的[时间线](../community/timeline.md)信息流已停用。需要您关注的动态会以通知的形式出现在应用栏中的**铃铛**图标下方。
:::

## 领袖功能 {#leader-features}

如果您是小组领袖，在小组聊天中您还拥有以下额外功能：

- **发布公告** -- 点击**全部公告**（或在仅开启公告时打开聊天），然后发布所有小组成员都可以阅读的消息。
- **删除消息** -- 通过消息菜单（⋮）删除任何成员的消息。
- **发布讨论** -- 您也可以像其他成员一样参与常规讨论。

:::info
对话以小组为单位独立存在。您在一个小组中发布的消息不会出现在其他小组的对话中。
:::
