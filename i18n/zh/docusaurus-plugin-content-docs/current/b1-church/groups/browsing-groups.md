# 浏览小组

<div class="article-intro">

教会的公开小组页面让您可以轻松发现感兴趣的小组。您可以按名称搜索，或按类别或校区缩小列表范围，找到最适合您的小组。

## 找到小组页面 {#finding-the-groups-page}

进入教会 B1.church 网站上的**查找小组**页面（`/groups`）。该页面可公开访问，因此您无需登录即可浏览。在成员门户中，**小组**页面上的**查找小组**按钮会打开同一页面。

## 搜索与筛选 {#searching-and-filtering}

教会所有的公开小组会一并显示。使用列表上方的控件可以缩小范围：

- **按名称或简介搜索小组** -- 输入一个词，即可只显示名称、简介或类别中包含该词的小组。
- **类别** -- 选择一个类别（例如"小组团契"、"青少年"或"音乐"），即可只显示该类别下的小组。选择**所有类别**可再次查看全部小组。类别由教会管理员设置，且只有在类别数量超过一个时才会显示此筛选器。
- **校区** -- 如果您的教会有多个校区，选择一个校区即可只查看分配给该校区的小组，或选择**所有校区**查看全部小组。

如果没有符合条件的小组，页面会显示"没有符合筛选条件的小组。"

教会还可以链接到某个小组标签的页面，例如 `/groups/youth`，该页面只列出带有该标签的小组。

## 阅读小组卡片 {#reading-group-cards}

每个小组都以卡片形式显示，包含以下信息：

- **小组照片** -- 代表该小组的封面图片。如果未设置照片，则显示默认图片。
- **小组名称** -- 醒目地显示在照片上方。
- **聚会时间** -- 小组通常的聚会时间（例如"周三晚上 7 点"）。如果未设置时间，则显示"--"。
- **聚会地点** -- 小组的聚会地点，位于右侧。如果未设置地点，则显示"--"。
- **简介** -- 对小组内容的简短预览，限制在几行以内。如果小组没有简介，卡片会显示"未提供简介"。点击小组即可阅读完整简介。

## 查看小组 {#viewing-a-group}

点击任何小组卡片即可在成员门户中打开完整的小组详情页面。在那里，您可以看到完整的简介、小组领袖、即将举行的活动，以及加入小组的方式。

:::tip
如果您在寻找某一类型的小组，请先使用**类别**筛选器进行选择。这样可以省去逐个浏览所有小组的时间。
:::

## 成员门户中的我的小组 {#your-groups-in-the-member-portal}

成员门户中的**小组**页面会列出您所属的小组。标题会显示您加入了多少个小组（以及有多少个加入申请待处理）。

- **搜索我的小组** -- 按名称筛选您的小组。
- **我的小组** -- 您最常打开的小组，最多五个，每个都显示其聚会时间和地点。点击即可打开。
- **其他小组** -- 您的其余小组。
- **待处理的申请** -- 您申请加入、正在等待小组领袖审批的小组。请参阅[申请加入小组](./join-requests.md)。
- **即将举行的活动** -- 接受报名的教会活动，每项都带有**报名**链接。请参阅[报名参加活动](../events/registering.md)。

点击**查找小组**即可浏览教会的所有小组。如果您尚未加入任何小组，页面会显示"还没有小组"以及**浏览小组**按钮；如果您未登录，页面会提示您登录以查看您的小组。
