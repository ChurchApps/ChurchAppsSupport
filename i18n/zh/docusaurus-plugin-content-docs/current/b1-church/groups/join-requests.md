# 请求加入小组

<div class="article-intro">

某些小组在您成为成员之前需要批准。当小组有此设置时，您提交加入请求 -- 可选地向小组领导者包含一条消息 -- 并等待领导者批准或拒绝。您可以查看待处理请求的状态并随时取消它们。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)到您的 B1.church 账户才能请求加入小组。

</div>

## 加入与请求加入

小组可以由其管理员设置不同的加入政策：

- **公开** -- 在小组的详情页面上点击**加入小组**，您将立即被添加为成员。
- **需要请求** -- 点击**请求加入**以提交小组领导者必须批准的请求，您才能成为成员。
- **关闭** -- 没有加入按钮出现。成员必须由领导者手动添加。

## 如何提交加入请求

1. 浏览到您想加入的小组。如果您需要帮助找到它，请参阅[浏览小组](./browsing-groups.md)。
2. 打开小组的详情页面。
3. 点击**请求加入**。
4. 会出现一个对话框，您可以选择向小组领导者写一条消息，说明为什么您想加入。
5. 点击**提交**发送您的请求。

小组的页面现在显示**请求待审**通知代替按钮。小组的领导者将收到有关您的请求的通知。一旦他们审核了它，您将收到一个包含结果的通知。

:::tip
包含一条简短消息 -- 例如您是如何听说这个小组的，或者您希望从中获得什么 -- 可以帮助领导者更快做出决定。
:::

## 检查您的请求状态

提交请求后，您可以从**小组**页面查看其状态：

1. 导航到您教会的 B1.church 网站上的**小组**页面。
2. 向下滚动到**待审请求**部分。
3. 每个待审请求显示小组名称和您提交的日期。

如果请求已被批准或拒绝，您将收到一个通知 -- 批准的请求会将您作为成员移入小组。

## 取消请求

如果您在领导者审核您的请求之前改变主意：

1. 转到**小组**页面。
2. 在**待审请求**部分找到您的请求。
3. 点击请求旁边的**取消**。

请求立即被撤回，领导者将不再看到它。
