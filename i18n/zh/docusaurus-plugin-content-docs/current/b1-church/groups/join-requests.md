# 申请加入小组

<div class="article-intro">

部分小组在您成为成员之前需要审批。当小组设有此项设置时，您需要提交加入申请 -- 可选择附上给小组领袖的留言 -- 然后等待领袖批准或拒绝。您可以随时查看待处理申请的状态，并将其取消。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)您的 B1.church 账户，才能申请加入小组。

</div>

## 加入与申请加入 {#joining-vs-requesting-to-join}

小组的管理员可以设置不同的加入政策：

- **开放** -- 在小组详情页面点击**加入小组**，您将立即成为成员。
- **需要申请** -- 点击**申请加入**，提交申请，待小组领袖批准后您才能成为成员。
- **关闭** -- 不会出现加入按钮。成员只能由领袖手动添加。

## 如何提交加入申请 {#how-to-submit-a-join-request}

1. 浏览您想加入的小组。如果您需要帮助查找，请参阅[浏览小组](./browsing-groups.md)。
2. 打开该小组的详情页面。
3. 点击**申请加入**。
4. 此时会弹出**申请加入**对话框，您可以选择在**留言（可选**）中向小组领袖说明您希望加入的原因。
5. 点击**发送申请**提交您的申请。

此时，小组页面上会显示**申请待处理**提示，取代原来的按钮。小组领袖将收到关于您申请的通知。领袖审核后，您会收到一条包含结果的通知。

:::tip
附上简短的留言 -- 例如您是如何得知这个小组的，或您希望从中获得什么 -- 有助于领袖更快做出决定。
:::

## 查看申请状态 {#checking-the-status-of-your-requests}

提交申请后，您可以在成员门户的**小组**页面（即列出您自己小组的页面，而非公开的**查找小组**页面）中查看其状态：

1. 在成员门户中打开**小组**。
2. 向下滚动到**待处理的申请**板块。只有当您有等待处理的申请时，此板块才会出现。
3. 每个待处理的申请都会显示小组名称以及您提交申请的日期（例如"申请于 11/10/2026"）。

如果申请已被批准或拒绝，您将收到通知 -- 获批的申请会将您转为小组成员。

## 取消申请 {#cancelling-a-request}

如果您在领袖审核之前改变主意：

1. 在成员门户中打开**小组**。
2. 在**待处理的申请**板块中找到您的申请。
3. 点击该申请旁边的**取消申请**。

申请会立即被撤回，领袖将不再看到该申请。
