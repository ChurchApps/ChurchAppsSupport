# 活动回复（RSVP）

<div class="article-intro">

小组活动可以收集回复，以便领袖了解谁会参加。在您小组的页面和日历上，每个即将举行的活动都有**会参加**、**可能参加**和**不能参加**按钮 -- 轻点即可作答，随时可以改变主意，并一目了然地看到还有多少人会参加。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)并且是该小组的成员
- 该活动必须允许回复（默认开启；领袖可以针对每项活动将其关闭）

</div>

## 回复活动 {#responding-to-an-event}

1. 在成员门户中打开您的小组。小组的下一场活动会显示在**下一场活动**板块中。如需查看其他活动，请点击**全部活动**：在**日历**视图中点击某一天即可查看当天的活动，或切换到**列表**视图，一次查看本月所有即将举行的活动。
2. 每个即将举行的活动都会显示三个按钮：**会参加**、**可能参加**和**不能参加**。
3. 点击您的回答。您的选择会被高亮显示，每个按钮都会实时显示给出该回复的人数。
4. 再次点击已高亮的回答即可清除，或点击其他按钮更改您的回复。

您的回复仅适用于该特定场次 -- 对于每周一次的聚会，您需要分别回复每周的活动。活动结束后，其按钮会消失；您的回答仍会以标记的形式显示在活动旁边。

## 面向小组领袖 {#for-group-leaders}

- **查看回复** -- 领袖可以在小组日历（**全部活动**）中看到每个活动上的**查看回复**链接，包括已结束的活动。点击后会打开**回复**面板，按回答类别列出所有人 -- 会参加、可能参加和不能参加。如果尚无人回复，则会显示"暂无回复。"
- **开启或关闭活动回复** -- 在创建或编辑活动时，使用**允许回复**开关。关闭回复的活动将不显示回复按钮。通过 B1 管理后台批量创建活动的工作人员也有相同的选项 -- 请参阅[小组日历](../../b1-admin/groups/group-calendar.md#event-rsvps)。

:::tip
回复只是一个轻量级的人数统计。如果您的活动需要报名信息、人数管理或付款，请改用[活动报名](../events/registering.md)。
:::
