# 活动出席回复（RSVP）

<div class="article-intro">

小组活动可以收集出席回复（RSVP），让组长了解谁会参加。在您小组的日历上，每个即将到来的活动都会询问“您会参加吗？”——点击一下即可作答，随时可以改变主意，并能一目了然地看到有多少人将会参加。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须已[登录](../getting-started/logging-in.md)并且是该小组的成员
- 该活动必须已启用 RSVP 功能（默认开启；组长可以针对每个活动单独关闭）

</div>

## 回应活动

1. 在会员门户中打开您的小组，进入其**活动**/日历视图。
2. 每个即将到来的活动卡片都会显示**您会参加吗？**，并附带三个按钮：**参加**、**可能**和**不参加**。
3. 点击您的回答。您的选择会高亮显示，每个按钮上会实时显示做出该回应的人数。
4. 再次点击已高亮的回答可清除它，或点击其他按钮更改您的回应。

您的 RSVP 仅适用于该次具体的活动——例如每周例会，您需要为每周的活动分别作答。

## 面向小组组长

- **查看回应** —— 组长会在每个活动卡片上看到**查看回应**按钮。点击后会打开**回应**面板，按回答类型列出所有人——参加、可能和不参加。如果还没有人回应，会显示“暂无回应”。
- **开启或关闭 RSVP** —— 在创建或编辑活动时，使用**允许 RSVP**开关。关闭 RSVP 的活动不会显示回应按钮。工作人员在 B1 Admin 中批量创建活动时也有相同选项——参见[小组日历](../../b1-admin/groups/group-calendar#event-rsvps)。

:::tip
RSVP 是一种轻量级的人数统计方式。如果您的活动需要报名详情、容量管理或付款，请改用[活动报名](../events/registering)功能。
:::
