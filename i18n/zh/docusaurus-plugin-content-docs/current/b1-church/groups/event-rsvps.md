# 活动回复（RSVP）

<div class="article-intro">

小组活动可以收集回复，以便负责人了解谁会参加。在您小组的页面和日历上，每个即将举行的活动都有 **Going**（会参加）、**Maybe**（待定）和 **Can't go**（不能参加）按钮——轻点即可回复，随时可以改变主意，并能一目了然地看到还有多少人会参加。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)并且是该小组的成员
- 该活动必须允许回复（默认开启；负责人可以为每个活动单独关闭）

</div>

## 回复活动

1. 在会员门户中打开您的小组。小组的下一个活动会显示在 **Next event**（下一个活动）部分。如需查看其他活动，请点击 **All events**（全部活动）：在 **Calendar**（日历）视图中，点击某一天即可查看当天的活动；或切换到 **List**（列表）视图，一次性查看本月所有即将举行的活动。
2. 每个即将举行的活动都会显示三个按钮：**Going**、**Maybe** 和 **Can't go**。
3. 点击您的回复。您的选择会被高亮显示，每个按钮都会实时显示选择该回复的人数。
4. 再次点击已高亮的回复即可取消，或点击其他按钮更改您的回复。

您的回复仅适用于该特定的活动场次——对于每周一次的聚会，您需要分别回复每周的活动。

## 面向小组负责人

- **查看回复** -- 负责人可以在小组日历（**All events**）中每个活动上看到 **View responses**（查看回复）链接。点击后会打开 **Responses**（回复）面板，按回复类型列出所有人——Going、Maybe 和 Can't go。如果还没有人回复，则显示“No responses yet”（暂无回复）。
- **开启或关闭活动回复** -- 在创建或编辑活动时，使用 **Allow RSVPs**（允许回复）开关。关闭回复的活动不会显示回复按钮。在 B1 Admin 中批量创建活动的工作人员也有同样的选项——请参阅[小组日历](../../b1-admin/groups/group-calendar#event-rsvps)。

:::tip
活动回复是一种轻量级的人数统计方式。如果您的活动需要报名信息、人数上限管理或付款，请改用[活动报名](../events/registering)。
:::
