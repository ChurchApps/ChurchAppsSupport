# 自助报到

<div class="article-intro">

自助报到流程让您仅需几个步骤即可为自己和家人记录出席情况。这是在教堂使用实体自助服务终端的快速替代方案。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)您的B1.church账户。
- 您的家庭成员必须关联到您的账户。如果缺少家庭成员，请要求教堂管理员将其添加到您的家户。

</div>

## 报到流程

报到遵循一个简单的三步流程。导航到[侧边栏](../getting-started/navigating.md)中的**报到**选项卡以开始。

### 第1步：选择服务

打开报到页面时，您将看到可用服务列表（例如"星期日上午"或"星期三晚上"）。每个服务卡片显示服务名称和校园地点（如果您的教堂有多个地点）。

单击服务卡片以选择它并继续下一步。

### 第2步：选择家庭成员和小组

选择服务后，您将看到您的家庭成员列表。对于每个参加的人：

1. 点击家庭成员以展开其条目。
2. 您将看到所选服务的可用**服务时间**。
3. 在服务时间旁边单击**选择小组**以选择该人应被报到到的小组（例如"主礼拜堂"、"儿童室1"或"青年小组"）。
4. 为每个参加的家庭成员重复此操作。

您不需要报到每个家庭成员——仅展开并为实际到场的人员分配小组。

### 第3步：确认

为所有参加的人员选择小组后，单击页面底部的**完成报到**按钮。

您将看到确认您的报到已完成且出席情况已保存的消息。片刻后，页面返回到服务列表，准备进行下一次报到。

如果您的教堂在报到站点处打印名牌，您会看到**您已报到！**以及一个二维码和安全代码。在报到站点显示该代码以打印您的名牌，然后点击**完成**。

:::tip
如果您需要在完成报到前更改小组选择，请点击任何服务时间旁边的**更改**按钮以选择不同的小组。
:::

## 需要了解的事项

- 您只能报到关联到您账户的家庭成员。如果缺少家庭成员，请要求教堂管理员将其添加到您的家户。
- 如果报到页面上没有显示服务，您的教堂可能目前还没有配置任何报到服务。

:::warning
报到仅在您的教堂配置了有效服务时可用。如果您看不到任何列出的服务，请与教堂办公室确认是否启用了自助报到。
:::
