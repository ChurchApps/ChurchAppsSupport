# 自助签到

<div class="article-intro">

自助签到流程让您只需几个步骤就能为自己和您的家庭记录出勤情况。这是使用教会的物理自助服务亭的快速替代方案。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 您必须 [登录](../getting-started/logging-in.md) 您的 B1.church 账户。
- 您的家庭成员必须链接到您的账户。如果缺少家庭成员，请要求您的教会管理员将他们添加到您的家庭。

</div>

## 签到流程

签到遵循一个简单的三步流程。导航到 [侧栏](../getting-started/navigating.md) 中的 **签到** 标签开始。

### 步骤 1：选择服务

当您打开签到页面时，您会看到可用服务列表（例如"周日早晨"或"周三晚上"）。每张服务卡片显示服务名称和校园（如果您的教会有多个位置）。

点击服务来选择它并进行下一步。

### 步骤 2：选择家庭成员和小组

选择服务后，您会看到您的家庭成员列表。对于每个参加的人：

1. 点击一个家庭成员来扩展他们的条目。
2. 您会看到您选择的服务的可用 **服务时间**。
3. 点击服务时间旁边的 **选择小组** 选择该人应该签到的小组（如"主礼拜"、"儿童室 1"或"青年团"）。
4. 对每个参加的家庭成员重复。

您不需要签到每个家庭成员 -- 只扩展并为实际参加的人分配小组。

### 步骤 3：确认

为所有参加的人选择小组后，点击页面底部的 **完成签到** 按钮。

您会看到一个确认，表示您的签到已完成，您的出勤已保存。片刻后，页面返回到服务列表，准备好下一次签到。

如果您的教会在签到站点打印名牌，您会看到 **您已签到！** 带有二维码和安全代码。在签到站点显示代码以打印您的名牌，然后点击 **完成**。在 B1 签到自助服务亭，点击 **扫描代码** 并将二维码拿到摄像头前 -- 详见 [为电话签到打印标签](../../b1-checkin/check-in/looking-up-members#printing-labels-for-a-phone-check-in)。

如果您的家庭已经为您选择的服务签到，一个 **显示签到代码** 按钮出现在您的家庭列表上方。点击它以再次显示二维码和安全代码 -- 例如，如果您在到达签到站点前关闭了页面。

:::tip
如果您需要在完成签到前更改小组选择，点击任何服务时间旁边的 **更改** 按钮来选择不同的小组。
:::

## 注意事项

- 您只能签到链接到您账户的家庭成员。如果缺少家庭成员，请要求您的教会管理员将他们添加到您的家庭。
- 如果签到页面上没有出现服务，您的教会可能目前没有任何配置用于签到的服务。

:::warning
签到仅在您的教会配置了有效服务时可用。如果您看不到列出的任何服务，请与您的教会办公室联系以确认自助签到是否已启用。
:::
