# 自助签到

<div class="article-intro">

自助签到流程让您只需几个步骤，就能为自己和家人记录出席情况。它是使用教会实体签到机的快捷替代方式。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须已[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 您的家庭成员必须已关联到您的账户。如果缺少某位家人，请让教会管理员将其添加到您的家庭中。

</div>

## 签到流程

签到分为简单的三个步骤。从[标签栏或“更多”页面](../getting-started/navigating.md)打开**签到**即可开始。

### 第 1 步：选择服事

打开签到页面后，您会看到一份可用服事的列表（例如“主日早上”或“周三晚上”）。每张服事卡片会显示服事名称；如果您的教会有多个堂点，还会显示所在堂点。

点击某项服事即可将其选中，并进入下一步。

### 第 2 步：选择家庭成员和小组

选择服事后，您会在**谁在这里**下看到您的家庭成员。对于每位出席的人：

1. 点击一位家庭成员，展开其条目。
2. 您会看到所选服事可用的**服事时间**。如果教会为某个服事时间设定了签到时段，则只有在该时段开放时才能选择（例如，从服事开始前 30 分钟到结束后不久）。在该时段之外，该服事时间会显示为**已关闭**；如已知开放时间，还会一并显示，例如 **已关闭 · 周日 9:30 AM 开放**。
3. 点击某个服事时间旁的**选择小组**，为此人选择签到的小组（例如“主日崇拜”“儿童室 1”或“青年团契”）。
4. 对每位出席的家庭成员重复上述操作。

您无需为每位家庭成员都办理签到，只需展开并为实际在场的人分配小组即可。

今天已在此服事中签到的人，其姓名旁会显示**已签到**标记。

### 第 3 步：确认

为所有出席的人选好小组后，点击页面底部的按钮。该按钮会统计您所选的人数，例如 **签到 1 人** 或 **签到 3 人**。

如果您选中的某人今天已在此服事中签到，将弹出**已签到**窗口并列出其姓名。点击**再次签到**可更新其小组，或点击**取消**返回。

随后您会看到签到完成的确认信息，表示您的出席记录已保存。片刻之后，页面会返回服事列表，方便您进行下一次签到。

如果您的教会在签到站打印姓名牌，您看到的将是**您已签到！**，并附有二维码和安全码。请在签到站出示该代码以打印姓名牌，然后点击**完成**。若在 B1 Checkin 签到机上，请点击**扫描代码**，并将二维码举到摄像头前，详见[为手机签到打印标签](../../b1-checkin/check-in/looking-up-members.md#printing-labels-for-a-phone-check-in)。

如果您所选的服事中您的家庭已完成签到，“谁在这里”标题旁会出现**显示签到码**链接。点击它即可重新显示二维码和安全码，例如在您关闭页面之前还未到达签到站时使用。

:::tip
如果在完成签到前需要更改小组选择，请点击任一服事时间旁的**更改**按钮，选择其他小组。
:::

## 注意事项

- 您只能为已关联到您账户的家庭成员办理签到。如果缺少某位家人，请让教会管理员将其添加到您的家庭中。
- 如果签到页面上没有显示任何服事，可能是您的教会目前尚未配置可供签到的服事。
- 如果您选择了某项服事，并看到类似“签到将于周日 9:30 AM 开放。”（或“此服事目前尚未开放签到。”）的提示，表示该服事的所有时间目前都不在签到时段内。请等签到开放后再试。
- 如果您的家庭已为较早的服事时间签到，在较晚的服事时间开放后，即使较早的时间已经结束，您仍可返回为较晚的时间办理签到。
- 如果您选择的房间已满或已关闭，您会看到提示：“您选择的房间已满或已关闭签到。请联系志愿者。”
- 如果儿童房内没有足够的志愿者为另一名儿童签到，您会看到一条指明房间名称的提示，例如：“儿童室 1 目前没有足够的志愿者再照看一名儿童。请选择其他房间或联系志愿者。”

:::warning
只有在教会配置了有效服事的情况下才能使用签到功能。如果您看不到任何服事列表，请与教会办公室确认是否已开通自助签到。
:::
