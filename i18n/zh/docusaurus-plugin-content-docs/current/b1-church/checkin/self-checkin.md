# 自助签到

<div class="article-intro">

自助签到流程让您只需几个步骤即可为自己和家人记录出勤。这是使用教会实体自助终端的快捷替代方式。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须已[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 您的家庭成员必须已关联到您的账户。如果缺少某位家庭成员，请让教会管理员将其添加到您的家庭中。

</div>

## 签到流程

签到遵循简单的三步流程。从[标签栏或"更多"页面](../getting-started/navigating.md)打开**签到**即可开始。

### 第一步：选择服务

打开签到页面时，您会看到可用服务的列表（例如"周日早晨"或"周三晚间"）。每个服务卡片显示服务名称，如果教会有多个地点，还会显示校区。

点击某个服务即可选择它并进入下一步。

### 第二步：选择家庭成员和小组

选择服务后，您会在**谁在这里**下看到您的家庭成员。对于每位出席的人员：

1. 点击某位家庭成员以展开其条目。
2. 您会看到所选服务的可用**礼拜时间**。如果您的教会为某个礼拜时间设置了签到时间表，则只能在该礼拜时间的签到时段开放时选择它（例如，从礼拜开始前 30 分钟到结束后不久）。在该时段之外，该礼拜时间会列为**已关闭**，并在已知时显示开放时间 -- 例如 **已关闭 · 周日 9:30 AM 开放**。
3. 点击某个礼拜时间旁边的**选择小组**，以选择该人员应签到的小组（例如"主日崇拜"、"儿童室 1"或"青年团契"）。
4. 对每位出席的家庭成员重复此操作。

您无需为每位家庭成员签到 -- 只需展开并为实际在场的人员分配小组。

### 第三步：确认

为所有出席人员选择小组后，点击页面底部的按钮。它会统计您所选的人数 -- 例如 **签到 1 人**或**签到 3 人**。

您会看到确认信息，表明您的签到已完成且出勤已保存。片刻之后，页面将返回服务列表，准备下一次签到。

如果您的教会在签到站打印姓名牌，您会看到 **您已签到！**，并附有二维码和安全码。请在签到站出示该代码以打印姓名牌，然后点击**完成**。在 B1 Checkin 自助终端上，点击**扫描代码**，并将二维码举到摄像头前 -- 请参阅[为手机签到打印标签](../../b1-checkin/check-in/looking-up-members#printing-labels-for-a-phone-check-in)。

如果您选择的服务中，您的家庭已经签到，**谁在这里**标题旁会出现**显示签到代码**链接。点击它即可重新调出二维码和安全码 -- 例如，如果您在到达签到站之前已关闭页面。

:::tip
如果您需要在完成签到之前更改小组选择，请点击任意礼拜时间旁边的**更改**按钮，以选择其他小组。
:::

## 注意事项

- 您只能为关联到您账户的家庭成员签到。如果缺少某位家庭成员，请让教会管理员将其添加到您的家庭中。
- 如果签到页面上没有显示任何服务，可能是您的教会目前没有配置任何可供签到的服务。
- 如果您选择了某个服务，并看到类似"签到将于周日 9:30 AM 开放。"（或"该服务当前未开放签到。"）的消息，说明该服务的所有礼拜时间目前都不在其签到时段内。请在签到开放后再试。
- 如果您的家庭已在较早的礼拜时间签到，即使较早的时段已经结束，您也可以在较晚的礼拜时间开放后返回并为其签到。
- 如果您选择的会议室已满或已关闭，您会看到"您选择的会议室已满或已关闭，无法签到。请联系志愿者。"

:::warning
只有当您的教会配置了有效的服务时，才能进行签到。如果您看不到任何列出的服务，请与教会办公室确认是否已启用自助签到。
:::
