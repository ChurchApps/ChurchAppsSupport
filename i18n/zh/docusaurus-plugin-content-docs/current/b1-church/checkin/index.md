# 签到

<div class="article-intro">

B1.church 中的**签到**功能允许您直接通过会员门户为自己和家庭成员办理礼拜签到。这是一种方便的方式，无需前往实体签到机，即可记录您的出席情况。

</div>

## 工作原理

使用自助签到时，您需要选择礼拜、选择哪些家庭成员参加，并为每位参加者分配每个礼拜时间对应的小组。确认后，您的出席记录会自动保存。

## 入门

如需访问签到功能，请在会员门户的[标签栏或“更多”页面](../getting-started/navigating.md)中点击 **Check-In**。您必须[登录](../getting-started/logging-in.md)才能使用此功能——如果您未登录，系统会提示您先登录。

:::info
签到功能要求您的教会已在管理设置中设置好礼拜和出席小组。如果您打开签到页面时没有可用的礼拜，可能是您的教会尚未配置此功能。请联系教会管理员寻求帮助。
:::
