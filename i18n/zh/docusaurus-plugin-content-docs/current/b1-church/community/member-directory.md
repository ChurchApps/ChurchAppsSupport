# 成员目录

<div class="article-intro">

成员目录让您可以浏览和搜索教会中的人员。无论您是想查找某位同小组的成员,还是想认识新朋友,目录都能让您轻松地与教会大家庭建立联系。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须先[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 该目录仅对**成员和员工**开放。访客和尚未成为成员的常来者会看到"仅限成员"的提示信息。

</div>

## 访问目录

1. 在[侧边栏导航](../getting-started/navigating.md)中点击**社区**。
2. 目录加载后,页面左侧会显示所有可见教会成员的列表。

## 搜索成员

该页面采用主从式布局。在左侧,您有两种查找人员的方式:

### 按姓名搜索

1. 确保搜索区域顶部选中了**人员**筛选项。
2. 在搜索框中输入姓名。
3. 点击**搜索**或按 **Enter** 键查看结果。

如果您将搜索框留空并点击**搜索**,系统会显示完整的目录列表。

### 按小组搜索

1. 点击搜索区域顶部的**小组**筛选项。
2. 从下拉列表中选择一个小组。
3. 点击**搜索**以查看该小组的所有成员。

:::tip
按小组搜索是一种快捷方式,适合用来查找您在[小组聚会](../groups/browsing-groups.md)中认识、但记不清姓名的人。
:::

## 浏览目录

成员按姓氏字母顺序排列,并按字母标题分组(A、B、C 等)。每条记录都显示成员的照片、显示名称和家庭名称,方便您快速浏览列表。

## 查看成员资料

点击列表中的任意成员,即可在右侧详情面板中打开其个人资料。资料中显示的信息由您的教会配置,可能包括联系方式、家庭成员和小组成员身份。

您也可以点击资料中的家庭成员,跳转到他们各自的资料页面。

:::info
每份资料中可见的信息取决于您教会的隐私和目录设置。并非每个字段都会对每位成员显示。
:::
