# 成员名录

<div class="article-intro">

成员名录让您浏览和搜索教会中的成员。无论您需要查找同一小组的成员，还是结识新朋友，名录都能让您轻松与教会大家庭建立联系。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 谁可以打开名录，取决于教会的**在名录中显示**设置：**仅管理员**、**成员及以上**（默认）、**常规参加者及以上**，或**访客及以上**。低于该级别的人会看到"仅限成员"的提示，未登录的访客会看到"需要登录"并附带**登录**按钮。拥有"人员 > 查看"权限的员工始终可以打开名录；若设置为**仅管理员**，则只有他们可以打开，即使是员工身份的人也不行。身份为访客或非活跃状态的人始终无法打开。请参阅[成员名录与消息设置](../../b1-admin/settings/mobile-app.md#member-directory--messaging-settings)。

</div>

## 访问名录 {#accessing-the-directory}

1. 点击[标签栏或"更多"页面中的](../getting-started/navigating.md)** 社区**（您的教会可能为其使用了其他名称）。
2. **名录**会打开，显示人数以及所有可见教会成员的列表。

## 搜索成员 {#searching-for-members}

在列表顶部的**搜索成员**框中输入姓名。列表会随您输入而筛选，每个姓名中匹配的部分会被高亮显示。清空搜索框即可再次查看完整名录。

## 浏览名录 {#browsing-the-directory}

成员会按姓氏首字母归入字母标题（A、B、C 等），同一字母下再按姓氏和名字排序。不以字母开头的姓名会列在末尾的**其他**下。每个条目会显示成员的照片、显示名称和会员状态，方便您快速浏览列表。如果没有符合搜索条件的成员，您会看到"未找到成员"。

## 查看成员资料 {#viewing-a-member-profile}

点击列表中的任一成员即可打开其资料。资料页会显示成员的姓名、照片和会员状态，并提供**发消息**、**致电**（其手机号码，若无手机号则为家庭电话）或**发短信**（仅限手机）按钮（前提是有相关信息）。下方的**联系信息**部分会显示教会和该成员选择共享的详情，例如电子邮件、电话和地址；**家庭成员**部分会列出同一家庭中的其他人。点击电子邮件地址即可给对方写邮件，点击地址即可在谷歌地图中打开。如果对方尚未与您共享任何联系方式，您会看到"联系信息不可用"。

**发消息**会与该人开启一段私人对话，详见[消息与通知](./messages.md)。您可以通过选中文字并使用消息框下方的按钮行，将文字设为粗体或斜体，或添加列表，操作方式与[小组聊天](../groups/conversations.md#formatting-your-message)相同。

在个人资料中点击家庭成员，也可以前往对方的资料页。在您自己的资料页上，**编辑资料**按钮会取代**发消息**、**致电**和**发短信**按钮，点击后可前往[编辑您的个人资料](../getting-started/editing-your-profile.md)。

:::info
每份资料中可见的信息取决于教会的隐私和名录设置。并非每位成员的所有字段都会显示。
:::

:::info
低于教会[私信最低年龄要求](/docs/b1-admin/settings/mobile-app#member-directory--messaging-settings)的成员仍会显示在名录中，但无法向其发送私信。
:::
