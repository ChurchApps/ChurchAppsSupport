# 成员目录

<div class="article-intro">

成员目录让您浏览和搜索您教会中的人。无论您是需要查找小组成员还是找新人，该目录都可以轻松与您的教会家族联系。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)您的 B1.church 帐户。
- 该目录仅对**成员和员工**可用。还未成为成员的访客和与会者将看到 "仅限成员" 消息。

</div>

## 访问目录

1. 在[侧边栏导航](../getting-started/navigating.md)中单击**社区**。
2. 目录加载，在页面左侧显示所有可见教会成员的列表。

## 搜索成员

该页面使用主详细布局。在左侧，您有两种方式来找到人：

### 按名称搜索

1. 确保在搜索区域的顶部选择了**人员**过滤器。
2. 在搜索框中键入名称。
3. 单击**搜索**或按**Enter**以查看结果。

如果您留下搜索框为空并单击**搜索**，会显示完整目录列表。

### 按小组搜索

1. 单击搜索区域顶部的**小组**过滤器。
2. 从下拉列表中选择一个小组。
3. 单击**搜索**以查看该小组的所有成员。

:::tip
按小组搜索是快速找到您在[小组会议](../groups/browsing-groups.md)上遇到的人的方式，但您记不住他们的名字。
:::

## 浏览目录

成员按姓氏按字母顺序列出，并按字母标题（A、B、C 等）分组。每个条目显示成员的照片、显示名称和家庭名称，使您可以轻松浏览列表。

## 查看成员档案

单击列表中的任何成员以在右侧的详细面板中打开他们的档案。该档案显示成员的信息，如您的教会配置所示，可能包括联系方式、家庭成员和小组成员资格。

您可以在档案中单击家庭成员以导航到他们的档案。

:::info
每个档案中可见的信息取决于您的教会的隐私和目录设置。并非所有字段都可能对每个成员显示。
:::

:::info
年龄在您教会的[私人消息最低年龄](/docs/b1-admin/settings/mobile-app#member-directory--messaging-settings)以下的成员在目录中保持可见，但向他们发送私人消息的选项不可用。
:::
