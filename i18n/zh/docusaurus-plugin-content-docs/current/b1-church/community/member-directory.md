# 会员通讯录

<div class="article-intro">

会员通讯录让您可以浏览和搜索教会中的成员。无论您是要查找同一小组的成员，还是要认识新朋友，通讯录都能帮助您轻松与教会大家庭保持联系。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须先[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 谁可以打开通讯录，取决于您教会的**在通讯录中显示**设置：**仅管理员**、**会员及以上**（默认）、**常规参与者及以上**或**访客及以上**。低于该级别的人会看到“仅限会员”的提示。拥有“人员 > 查看”权限的工作人员始终可以打开通讯录；在设置为**仅管理员**时，只有他们可以打开，即使是会员身份为“员工”的人也不行。会员身份为“访客”或“未激活”的人则始终无法打开。请参阅[通讯录与消息设置](../../b1-admin/settings/mobile-app.md#member-directory--messaging-settings)。

</div>

## 进入通讯录

1. 点击[底部标签栏或“更多”页面](../getting-started/navigating.md)中的**社区**（您的教会可能使用了不同的名称）。
2. **通讯录**会打开，显示人数以及所有可见教会会员的列表。

## 搜索会员

在列表顶部的**搜索会员**框中输入姓名。列表会随您输入而即时筛选，每个姓名中匹配的部分会高亮显示。清空搜索框即可再次查看完整通讯录。

## 浏览通讯录

会员会按名字的首字母分组在字母标题下（A、B、C 等），每组内按姓氏排序。每个条目显示会员的照片、显示名称和会员身份，方便您快速浏览列表。

## 查看会员资料

点击列表中的任一会员即可打开其资料。资料页会显示该会员的姓名、照片和会员身份，并在有相关信息时提供**发消息**、**打电话**或发送**短信**的按钮。其下方的**联系信息**部分会显示教会和该会员选择分享的详细信息，例如电子邮件、电话和地址；**家庭成员**则列出该会员家庭中的其他人。

点击**发消息**会与该人开启一段私人对话。您可以先选中文字，再使用弹出的工具栏将文字设为粗体或斜体，或添加列表，操作方式与[小组聊天](../groups/conversations.md#formatting-your-message)相同。

您也可以在资料页中点击家庭成员，进入他们的资料页。在您自己的资料页上，**编辑资料**按钮会带您前往[编辑您的资料](../getting-started/editing-your-profile.md)。

:::info
每份资料可见的信息取决于教会的隐私和通讯录设置。并非每位会员的所有字段都会显示。
:::

:::info
低于教会[私人消息最低年龄](/docs/b1-admin/settings/mobile-app#member-directory--messaging-settings)的会员仍会显示在通讯录中，但无法向其发送私人消息。
:::
