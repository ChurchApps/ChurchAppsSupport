# 会员名录

<div class="article-intro">

会员名录可让您浏览和搜索教会中的成员。无论您是想查找同一小组的成员，还是想认识新朋友，名录都能帮您轻松与教会大家庭保持联系。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 名录仅对**会员和教职员工**开放。尚未成为会员的访客和参加者会看到“Members Only”（仅限会员）的提示。

</div>

## 访问名录

1. 在[标签栏或“更多”页面](../getting-started/navigating.md)中点击 **Community**（您的教会可能为其取了其他名称）。
2. **Directory**（名录）会打开，并显示人数以及所有可见的教会成员列表。

## 搜索成员

在列表顶部的 **Search Members** 框中输入姓名。列表会随您输入而筛选，每个姓名中匹配的部分会被高亮显示。清空搜索框即可再次查看完整名录。

## 浏览名录

成员会按其名字的首字母归入字母标题下（A、B、C 等），每个字母下按姓氏排序。每条记录都会显示成员的照片、显示名称和会籍状态，方便您快速浏览列表。

## 查看成员档案

点击列表中的任意成员即可打开其档案。档案会显示该成员的姓名、照片和会籍状态，并在相关信息可用时提供 **Message**（发消息）、**Call**（致电）或 **Text**（发短信）按钮。其下方的 **Contact Information**（联系信息）部分会显示教会和该成员选择分享的详细信息，例如电子邮件、电话和地址；**Household Members**（家庭成员）部分则列出其家庭中的其他人。

在档案中点击家庭成员，即可跳转到其个人档案。在您自己的档案中，**Edit profile**（编辑个人资料）按钮会带您进入[编辑您的个人资料](../getting-started/editing-your-profile.md)页面。

:::info
每份档案中可见的信息取决于您教会的隐私和名录设置。并非每位成员的所有字段都会显示。
:::

:::info
在您教会的[私信最低年龄](/docs/b1-admin/settings/mobile-app#member-directory--messaging-settings)以下的成员仍会显示在名录中，但无法向其发送私信。
:::
