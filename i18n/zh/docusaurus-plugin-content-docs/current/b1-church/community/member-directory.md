# 成员目录

<div class="article-intro">

成员目录让您可以浏览和搜索教会中的人员。无论您需要查找同一小组的成员，还是寻找新认识的人，目录都能让您轻松与教会大家庭建立联系。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您必须已[登录](../getting-started/logging-in.md)您的 B1.church 账户。
- 谁可以打开目录取决于您教会的**在目录中显示**设置：**仅管理员**、**成员及以上**（默认）、**常规出席者及以上**或**访客及以上**。低于该级别的人员会看到"仅限成员"的提示。拥有"人员 > 查看"权限的工作人员始终可以打开目录；如果设置为**仅管理员**，则只有他们可以打开 -- 即使是成员身份状态为工作人员的人也不行。访客或非活跃身份状态的人员则永远无法打开。请参阅[成员目录与消息设置](../../b1-admin/settings/mobile-app.md#member-directory--messaging-settings)。

</div>

## 访问目录

1. 在[标签栏或"更多"页面](../getting-started/navigating.md)上点击**社区**（您的教会可能为其取了其他名称）。
2. **目录**会打开，显示人数以及所有可见教会成员的列表。

## 搜索成员

在列表顶部的**搜索成员**框中输入姓名。列表会随您输入而筛选，每个姓名中匹配的部分会被高亮显示。清空搜索框即可再次查看完整目录。

## 浏览目录

成员按其名字的首字母归类在字母标题下（A、B、C 等），每个字母内部按姓氏排序。每个条目显示成员的照片、显示名称和成员身份状态，便于快速浏览列表。

## 查看成员资料

点击列表中的任意成员即可打开其资料。资料会显示成员的姓名、照片和成员身份状态，并提供**发消息**、**致电**或在有相关信息时发送**短信**的按钮。其下方的**联系信息**部分会显示教会和成员选择分享的详细信息，例如电子邮件、电话和地址；**家庭成员**则列出该成员家庭中的其他人。

您可以在资料中点击家庭成员，以跳转到他们的资料。在您自己的资料上，**编辑资料**按钮会带您前往[编辑您的资料](../getting-started/editing-your-profile.md)。

:::info
每份资料中可见的信息取决于您教会的隐私和目录设置。并非每位成员都会显示所有字段。
:::

:::info
您教会[私信最低年龄](/docs/b1-admin/settings/mobile-app#member-directory--messaging-settings)以下的成员仍会在目录中可见，但向他们发送私信的选项不可用。
:::
