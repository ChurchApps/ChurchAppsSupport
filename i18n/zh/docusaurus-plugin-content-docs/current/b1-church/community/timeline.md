# 动态

<div class="article-intro">

独立的 **Timeline**（动态）标签页已经停用。会员门户现在会打开[首页仪表板](../getting-started/navigating.md)，而以前汇集在一个综合信息流中的内容，现在会显示在相应的位置——即“我的”页面、通知以及各个小组内。

</div>

## 动态内容的新位置

| 您以前在动态中看到的内容 | 现在的查看位置 |
| --- | --- |
| 小组对话和公告 | 每个[小组](../groups/conversations.md)内的聊天（**Open chat**） |
| 您和您所在小组即将举行的活动 | **我的**页面（`/mobile/me`）以及每个小组的 **Next event** 部分 |
| 任务和服事安排 | **我的**页面以及[计划](../plans/) |
| 新讲道 | 首页的 **Latest sermon** 部分以及[讲道](../content/sermons.md)标签页 |
| 所有提醒您的内容 | 应用栏中的**铃铛**图标，或 `/mobile/notifications` |

## “我的”页面

[“我的”页面](../getting-started/me-page)是旧信息流最接近的替代品。它会列出您即将参与的内容——服事安排、活动报名和小组活动——以及您最近的通知，并可直接链接到您的个人资料、通知偏好设置、消息、奉献和报名记录。

## 通知

以前会以动态条目形式出现、需要您关注的内容，现在会以通知的形式送达。点击应用栏中的铃铛即可查看最新通知，或点击 **See all**（查看全部）（或打开 `/mobile/notifications`）查看完整列表。点击通知会带您进入其来源的小组、计划或对话。您可以在[通知偏好设置](../getting-started/notification-preferences.md)中控制接收哪些通知以及接收方式。

:::tip
如果您的“我的”页面看起来是空的，可能是因为您还没有加入任何小组。请访问[小组](../groups/browsing-groups.md)页面查找可以加入的小组，或请教会管理员或小组负责人将您添加进去。
:::
