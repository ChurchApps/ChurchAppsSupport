# 时间线

<div class="article-intro">

独立的**时间线**标签已被停用。成员门户现在会打开[主页仪表板](../getting-started/navigating.md)，原本汇集在一个综合信息流中的活动，现在显示在各自合适的位置 -- 在"我的"页面、通知中以及每个小组内。

</div>

## 时间线内容现在的位置

| 您以前在时间线上看到的内容 | 现在在哪里找到 |
| --- | --- |
| 小组对话和公告 | 每个[小组](../groups/conversations.md)内的聊天（**打开聊天**） |
| 您和您小组即将举行的活动 | **我的**页面（`/mobile/me`）以及每个小组的**下一场活动**部分 |
| 任务和服事分配 | **我的**页面以及[计划](../plans/) |
| 新讲道 | 主页上的**最新讲道**部分以及[讲道](../content/sermons.md)标签 |
| 任何提醒您的内容 | 应用栏中的**铃铛**图标，或 `/mobile/notifications` |

## 我的页面

[我的页面](../getting-started/me-page)是旧信息流最接近的替代品。它列出了您即将参加的活动 -- 服事分配、活动报名以及小组活动 -- 同时还列出您提交的表单、出勤记录以及最新通知，并可直接链接到您的资料、通知偏好、消息、奉献和报名记录。

## 通知

以前会作为时间线项目出现、需要您关注的任何内容，现在都会以通知的形式送达。点击应用栏中的铃铛即可查看最新通知，或点击**查看全部**（或打开 `/mobile/notifications`）查看完整列表。点击通知会带您前往其来源的小组、计划或对话。您可以在[通知偏好](../getting-started/notification-preferences.md)下控制您收到哪些通知以及接收方式。

:::tip
如果您的"我的"页面看起来是空的，您可能还没有加入任何小组。请访问[小组](../groups/browsing-groups.md)页面查找可加入的小组，或请您的教会管理员或小组领袖将您添加进去。
:::
