# 社区

<div class="article-intro">

B1.church 中的**社区**板块帮助您与教会大家庭保持联系。它提供成员名录，方便您查找并了解其他教会成员。

</div>

## 您将找到的内容 {#what-you-will-find}

- **[成员名录](./member-directory.md)** -- 浏览并搜索教会的成员名录。按姓名查找您要找的人。点击某位成员即可查看其个人资料详情。
- **[消息与通知](./messages.md)** -- 向其他成员发送私信，并在收件箱中查看您的通知。
- **[时间线](./timeline.md)** -- 旧的综合动态信息流，现已停用。本页说明如今每类更新分别位于何处。

## 入门指南 {#getting-started}

您必须[登录](../getting-started/logging-in.md)才能使用社区功能。如果您未登录，**社区**标签页会显示登录提示，而不是成员名录。

成员门户会打开[主页仪表板](../getting-started/navigating.md)。**社区**标签页可让您访问成员名录，应用顶栏中的**铃铛**图标可打开您的消息和通知。

:::info
您在名录中可见的成员和信息取决于教会的隐私设置。您可能无法查看每位成员的完整资料。如果您对共享的内容有疑问，请联系教会管理员。
:::

:::tip
可结合[小组](../groups/index.md)使用社区功能，让自己在一周中都与教会保持紧密联系。
:::
