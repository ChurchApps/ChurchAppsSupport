# 直播

<div class="article-intro">

直播页面让您可以直接在 B1.church 中观看教会礼拜的实时画面。教会开始直播时，您可以收看，并在观看视频的同时使用互动功能参与其中。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 观看直播无需登录。直播页面可供公开访问。
- 教会必须已配置直播时间表。请查看教会的礼拜时间，了解何时提供现场直播。

</div>

## 观看直播 {#watching-a-live-stream}

1. 从教会网站导航中进入**直播**页面。
2. 如果礼拜正在进行，视频会自动在页面上播放。
3. 直接在页面上观看直播。

当没有礼拜正在直播时，播放器会显示以下内容之一：

- **礼拜开始前** -- 显示礼拜标题（或**下一场礼拜时间**）及倒计时。如果距离礼拜还有一天以上，则会显示其日期和时间。倒计时结束后，视频会自动开始播放，您无需刷新页面。
- **礼拜结束后** -- 显示"本次礼拜已结束。"
- **未安排礼拜** -- 显示教会的标志，或教会在离线时选择展示的其他内容。

## 互动功能 {#interactive-features}

根据教会的配置，直播页面可能会在视频旁边提供互动标签页。这些可能包括：

- **聊天** -- 在直播期间发送消息，并与其他观众互动。聊天顶部会显示正在观看的人数；点击即可查看他们的姓名。在**消息**框中输入内容，然后点击**发送**（笑脸按钮可添加表情符号）。聊天会在礼拜开始前一段设定时间开放，并在礼拜结束后保持开放一段时间；在此之前，消息框会被"聊天将于"及对应时间所取代。
- **主持人聊天** -- 如果您已登录，并且教会已将您设为聊天主持人，则会出现一个单独的**主持人聊天**标签页，供您与其他主持人私下交流。
- **其他标签页** -- 教会可能会添加自定义标签页，链接到周报、讲道笔记、[奉献页面](../giving/making-donations.md)或其他资源。

观看时，点击标签页图标或标签名称即可在可用功能之间切换。

### 您在聊天中的名称 {#your-name-in-chat}

您无需登录即可聊天。您将以**匿名**加一个数字的身份加入；点击该名称旁边的铅笔图标，即可设置您自己的显示名称，然后点击**更新**。如果您已登录，您的聊天消息将使用您账户中的名称。

## 在成员门户中观看 {#watching-in-the-member-portal}

成员门户中的**直播**页面（`/mobile/stream`）会在标题旁显示**直播中**或**离线**标记；当没有直播时，还会显示下一场直播的开始时间。播放器下方，每个聊天都有一个区域显示其最新消息；点击**打开聊天**即可阅读和发送消息。教会的其他直播标签页会列在下方，点击即可打开。

## 礼拜前后 {#before-and-after-the-service}

教会会设定直播和互动功能开放的具体时间。您可能可以在礼拜正式开始前加入聊天，有时间与其他人打招呼。礼拜结束后，聊天可能会短暂保持开放，以便继续交流。

:::info
如果直播页面显示离线内容或倒计时，说明下一场预定礼拜尚未开始。请在列出的礼拜时间再回来查看。
:::

:::tip
想找您错过的录制讲道？请访问[讲道](./sermons.md)页面，浏览教会的往期信息。
:::

## 可用性 {#availability}

当教会已配置直播时间表时，直播页面即可使用。如果您在导航中看不到**直播**链接，可能是教会尚未设置现场直播。如需详情，请联系教会管理员。
