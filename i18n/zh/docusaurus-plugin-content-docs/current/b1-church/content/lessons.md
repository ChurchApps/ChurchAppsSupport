# 课程（已弃用）

:::danger 课程标签已被 FreePlay 替代
B1.church 上的嵌入式 **课程** 标签已被弃用。来自 Lessons.church 的课程播放现在通过 **[FreePlay](/docs/freeplay/)** 提供 -- ChurchApps 为教室屏幕、Fire TV、Apple TV 和 Android TV 提供的免费电视应用 -- 它提供嵌入式标签无法提供的离线播放、教室配对和电视遥控器体验。

要浏览、安排或直接编辑课程，请在浏览器中登录 [Lessons.church](https://lessons.church)。要在教室电视上播放课程，请在您的电视设备上安装 [FreePlay](/docs/freeplay/getting-started/)。

与在 B1Admin 中关联到课程计划类型的小组相关联的家长在 [小组详情](/docs/b1-church/groups/group-details.md) 页面上看到 **本周的课程** -- 不在这个已弃用的标签上。
:::

<div class="article-intro">

**课程** 标签让您可以访问您的教会的课程和学习材料。内容通过 Lessons.church 平台提供，直接嵌入 B1.church 中，所以您无需导航到单独的网站。

</div>

<div class="prereqs">
<h4>开始前</h4>

- 您必须 [登录](../getting-started/logging-in.md) 您的 B1.church 账户。课程标签位于成员区域，需要身份验证。
- 您的教会必须通过 Lessons.church 配置课程。

</div>

## 访问课程

1. 登录您的 B1.church 成员门户。
2. 点击 [成员导航](../getting-started/navigating.md) 中的 **课程** 标签。
3. Lessons.church 内容直接加载到页面中。

当您打开课程标签时，您的登录会自动进行。您无需单独再次登录 Lessons.church。

## 您可以做什么

进入课程标签后，您可以浏览您的教会提供的课程。根据您的教会设置，您可能会找到：

- **课程计划** -- 结构化的大纲，带有部分和活动
- **演示和媒体** -- 伴随课程的幻灯片、视频和图像
- **可下载的资源** -- 供进一步研究的文件和附加内容

您可以点击课程中的各个部分来在对话框窗口中查看其内容。使用 **返回** 按钮返回到部分列表，或 **关闭** 以退出对话框。

:::tip
为您的小组安排的课程在 [小组详情](../groups/group-details.md) 页面上显示为 **本周的课程**，使得无需直接导航到课程标签就可以轻松查找分配的课程。
:::

## 可用性

当您的教会通过 Lessons.church 配置课程时，课程标签会出现。如果您在成员导航中看不到 **课程** 标签，您的教会可能没有设置课程内容。有关更多信息，请联系您的教会管理员。
