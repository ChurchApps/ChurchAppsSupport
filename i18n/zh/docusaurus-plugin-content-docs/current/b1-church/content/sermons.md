# 讲道

<div class="article-intro">

讲道页面让您浏览并观看教会录制的讲道。教会的讲道库会按照教会配置的外观和布局展示，因此其风格将与教会的品牌形象保持一致。

</div>

<div class="prereqs">
<h4>开始之前</h4>

- 观看讲道无需登录。讲道页面可供公开访问。
- 教会必须已通过其管理门户添加讲道内容。

</div>

## 在网站上浏览讲道 {#browsing-sermons-on-the-website}

1. 从教会网站导航中进入**讲道**页面。
2. 页面会默认打开**播放列表**：每个教会讲道系列都有一张卡片，显示其图片和标题。
3. 点击某个播放列表，即可查看其中的讲道，每篇都带有图片和标题。
4. 点击某篇讲道即可在页面上播放。

列表上方的按钮（**播放列表**、播放列表名称、讲道标题）可让您逐级返回。讲道视频可能托管在 YouTube、Vimeo 或 Facebook 等平台上。

每篇讲道还有自己的页面，地址为 `/sermons/` 加上该讲道的 ID，您可以分享或加入书签。页面会显示视频、系列名称、标题、日期和简介。

:::info 播客订阅源
教会的讲道也会以播客（RSS）订阅源的形式发布。播客应用和订阅阅读器可以从任何一篇讲道的页面找到该订阅源。
:::

## 成员门户中的讲道 {#sermons-in-the-member-portal}

成员门户中的**讲道**页面（`/mobile/sermons`）以一页多个板块的形式布局：

- 页面顶部的**观看最新**会打开最新的讲道。教会直播期间，它会变为**观看直播**，并打开[直播](./live-streaming.md)。
- **最新** -- 最新的讲道，显示其图片、系列、日期和时长。
- **直播** -- 当直播正在进行或将在 24 小时内开始时显示，并附上下一场礼拜时间。点击即可打开直播。
- **近期** -- 接下来的三篇讲道。点击**所有讲道**可查看全部讲道、按年份筛选，或搜索所有年份的标题和简介。
- **系列** -- 教会最新的三个系列，以及每个系列包含的讲道数量。点击**所有系列**查看完整列表，或点击某个系列查看其中的讲道。

点击某篇讲道即可打开。点击图片或**观看讲道**即可播放，点击**分享**可发送链接，点击**打开链接**可在其原始网站上打开视频。下方还有**关于**板块（包含简介）和**本系列中的讲道**列表，并附带**本系列全部**链接。

:::tip
如果您想找的是现场直播而非录制讲道，请查看[直播](./live-streaming.md)页面。
:::

## 可用性 {#availability}

当教会已通过其管理门户添加讲道内容时，讲道页面即可使用。如果您在教会导航中看不到**讲道**链接，可能是教会尚未配置此功能。如需更多信息，请联系教会管理员。
