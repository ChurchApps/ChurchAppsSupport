# 内容

<div class="article-intro">

B1.church 为您的会众提供一个集中访问教会所分享内容的地方。根据教会的配置，您可以在成员门户中访问讲道、直播、圣经阅读、每日经文以及课程材料。

</div>

## 可用内容功能

### 讲道

浏览和观看教会录制的讲道。您教会的讲道库按播放列表和系列组织，便于查找过去的信息。

### 直播

直接在 B1.church 中观看教会的现场直播。当礼拜正在直播时，您可以加入直播，并通过聊天与其他观众互动。

### 圣经

使用内置的圣经阅读器阅读经文。您无需离开网站即可浏览书卷、章节和经节。

### 每日经文

查看每天更换的精美圣经经文图片。图片会自动调整以适应您的屏幕。您还可以分享或下载任何一天的经文，并浏览往日的经文。

### 课程

查看教会计划中已安排的课程。如果您是教师或领袖，可以使用**教师视图**以全屏、易于导航的格式查看课程，非常适合教学或演示。

### 课程（已弃用 - 嵌入式标签）

嵌入式**课程**标签已被弃用。课程播放现已转移至 **[FreePlay](/docs/freeplay/)**，这是 ChurchApps 面向教室屏幕的免费电视应用。如需在手机、平板或电脑上浏览课程，请直接登录 [Lessons.church](https://lessons.church)。详情请参阅[课程参考页面](./lessons.md)。

## 查找内容

内容页面可通过您教会的网站导航找到。您的教会管理员决定启用哪些内容功能以及它们在菜单中的显示方式。如果您没有看到上面列出的某项内容功能，则可能是您的教会未配置该功能。

:::info
[讲道](./sermons.md)和[圣经](./bible.md)是公开提供的。其他功能可能需要您先[登录](../getting-started/logging-in.md)。
:::
