# 课程教师视图

<div class="article-intro">
教师视图提供了一个扩展的全屏界面，以结构化的章节显示课程内容，便于教师和带领者在授课期间浏览课程材料。
</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您的教会必须已在某个计划中安排好课程。详情请参阅 B1 Admin 指南中的[安排课程](../../b1-admin/serving/scheduling-lessons.md)。
- 您需要被分配到该计划，或在您的 B1.church 网站上拥有查看该计划的权限。
</div>

## 打开教师视图

要访问某个课程的扩展教师视图：

1. 在 B1.church 会员门户中打开**计划（Plans）**
2. 打开包含您要讲授的课程的计划
3. 点击计划页面顶部的 **Teach** 按钮

课程将在专为授课优化的全屏界面中打开。

:::tip
当需要将课程内容投影到屏幕或电视上供全班观看，或使用平板电脑授课时，教师视图尤其有用。
:::

## 教师视图功能

### 章节导航

教师视图将课程内容组织为多个章节：

- 课程的每个主要章节都会显示为独立的带标题区块
- 点击顶部的 **Sections**（章节）即可打开章节列表，然后选择某一章节直接跳转
- 标题会显示您当前所在的章节，例如“Section 2 of 5”（第 2 章，共 5 章）
- 章节列表可以方便您跳转到课程的不同部分

### 可滚动内容

主内容区域会显示完整的课程材料：

- 自然地滚动浏览课程内容
- 滚动时，标题会自动更新为您正在查看的章节
- 所有格式化的文字、图片和说明都会清晰地显示

### 媒体播放

当课程包含视频、图片或其他媒体时：

- 点击任意媒体项目即可在弹出播放器中打开
- 视频会在带有标准控件的专用视频播放器中播放
- 图片会在灯箱中全屏查看
- 关闭媒体播放器即可返回课程内容

### 可下载资源

如果课程包含可下载的文件（活动单、涂色页等）：

- 每个资源旁都会出现下载按钮
- 点击即可将文件直接下载到您的设备
- 文件可以是内容创作者提供的 PDF、图片或其他材料

## 在课堂中使用教师视图

### 课前

1. 在上课前打开教师视图中的课程
2. 浏览所有章节，熟悉课程内容
3. 下载您需要的任何可打印资源
4. 测试所有视频或媒体，确保其能正常播放

### 课中

1. 在您的设备上保持教师视图打开，或将其投影到屏幕上
2. 随着课程进展，使用 **Sections** 在各章节之间跳转
3. 在适当的时候播放视频或展示图片
4. 根据需要滚动浏览说明，同时不会丢失您的位置

### 投影屏幕上

为全班投影时：

- 全屏布局可以减少干扰
- 大号、清晰的文字即使在教室另一端也清晰可见
- 点击媒体项目即可向全班展示视频或图片
- 可使用无线鼠标或触控板进行导航

## 关闭教师视图

要退出教师视图：

- 点击右上角的 **Close**（关闭）按钮（X）
- 或按键盘上的 **Esc** 键
- 您将返回计划详情视图

## 移动设备和平板电脑使用

教师视图可在平板电脑和移动设备上使用：

- **平板电脑** -- 非常适合希望携带课程指南的教师
- **手机** -- 同样支持，但较小的屏幕可能不太适合授课
- **横屏模式** -- 在移动设备上可获得最佳观看体验

## 与普通课程视图的区别

| 功能 | 普通视图 | 教师视图 |
|---------|--------------|--------------|
| **布局** | 紧凑，与计划内嵌显示 | 全屏，专用视图 |
| **导航** | 仅滚动 | 章节列表 + 带当前章节标题的滚动 |
| **媒体** | 嵌入页面中 | 弹出播放器，便于专注观看 |
| **屏幕空间** | 显示计划中的其他项目 | 最大化用于课程内容 |
| **最适合** | 浏览和规划 | 授课和演示 |

## 最佳实践

- **提前准备** -- 课前在教师视图中复习课程，熟悉其布局
- **标记章节** -- 记下哪些章节包含关键活动或讨论
- **测试媒体** -- 在上课前确保视频和图片能正常加载
- **提早下载资源** -- 不要等到上课时才下载可打印材料
- **使用更大的屏幕** -- 通过投影或使用平板电脑，获得最佳授课体验

## 故障排除

### 课程无法在教师视图中打开

- 确认该课程已在计划中正确安排
- 检查您是否有查看该计划的权限
- 刷新页面后重试

### 视频无法播放

- 检查您的网络连接
- 确认您的设备允许媒体播放
- 尝试在单独的标签页中打开视频
- 某些内容提供商可能对视频播放有限制

### 移动设备上内容显示不全

- 将设备旋转至横屏模式
- 如有需要，稍微缩小页面
- 考虑使用平板电脑或更大的设备以获得更好的可视效果
