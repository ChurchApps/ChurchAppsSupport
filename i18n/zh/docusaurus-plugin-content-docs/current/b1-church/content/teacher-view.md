# 课程的教师视图

<div class="article-intro">
教师视图为查看具有结构化部分的课程内容提供了展开的全屏界面，使教师和领导者更容易在课堂时间内浏览课程材料。
</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您的教堂必须在计划中安排课程。有关详细信息，请参阅B1 Admin指南中的[安排课程](../../b1-admin/serving/scheduling-lessons.md)。
- 您需要被分配到计划或有权在您的B1.church站点上查看它。
</div>

## 打开教师视图

要访问课程的展开教师视图：

1. 导航到B1.church的**计划**部分
2. 打开包含您要教授的课程的计划
3. 打开**服务顺序**选项卡
4. 单击**讲授**按钮

该课程将在针对教学优化的全屏界面中打开。

:::tip
当在屏幕或电视上为课堂投影课程内容，或从平板电脑教授时，教师视图特别有用。
:::

## 教师视图功能

### 标签页导航

教师视图使用顶部的标签页将课程内容组织到各个部分中：

- 课程的每个主要部分显示为单独的标签页
- 单击任何标签页以直接跳转到该部分
- 活动部分在标签页栏中突出显示
- 标签页使得轻松跳转到课程的不同部分

### 可滚动内容

主要内容区域显示完整的课程材料：

- 自然地滚动浏览课程
- 当您滚动时，活动标签页自动更新以匹配您正在查看的部分
- 所有格式化文本、图像和说明都清晰显示

### 媒体播放

当课程包含视频、图像或其他媒体时：

- 单击任何媒体项目以在弹出播放器中打开它
- 视频在带有标准控件的专用视频播放器中播放
- 图像在灯箱中打开以供全屏查看
- 关闭媒体播放器以返回课程内容

### 可下载的资源

如果课程包含可下载文件（活动表、着色页等）：

- 为每个资源显示下载按钮
- 单击以直接将文件下载到您的设备
- 文件可包含由内容创建者提供的PDF、图像或其他材料

## 在课堂中使用教师视图

### 课前

1. 在课程开始前在教师视图中打开课程
2. 查看所有部分并熟悉内容
3. 下载任何您需要的可打印资源
4. 测试任何视频或媒体以确保它们正确播放

### 课中

1. 在您的设备上保持教师视图打开或将其投影到屏幕上
2. 使用标签页在您进行课程时在各部分之间跳转
3. 在适当的时间播放视频或显示图像
4. 根据需要滚动浏览说明，不会丢失您的位置

### 在投影屏幕上

在为课堂投影时：

- 全屏布局消除干扰
- 大型、易读的文本使内容从房间各处可见
- 单击媒体项目以向整个班级显示视频或图像
- 使用无线鼠标或触控板进行导航

## 关闭教师视图

要退出教师视图：

- 单击顶部角落的**关闭**按钮（X）
- 或按键盘上的**Esc**键
- 您将返回到计划详情视图

## 移动设备和平板电脑使用

教师视图在平板电脑和移动设备上工作：

- **平板电脑** -- 对于想要便携式课程指南的教师来说很完美
- **手机** -- 也支持，尽管较小的屏幕可能不太理想用于教学
- **横向模式** -- 在移动设备上提供最佳查看体验

## 与常规课程视图的区别

| 功能 | 常规视图 | 教师视图 |
|---------|--------------|--------------|
| **布局** | 紧凑，内联计划 | 全屏，专用视图 |
| **导航** | 仅滚动 | 标签页 + 带自动突出显示的滚动 |
| **媒体** | 嵌入在页面中 | 用于专注查看的弹出播放器 |
| **屏幕空间** | 显示其他计划项目 | 为课程内容最大化 |
| **最适合** | 浏览和计划 | 教学和演示 |

## 最佳实践

- **提前准备** -- 课程前在教师视图中查看课程以熟悉布局
- **标记部分** -- 记下哪些标签页包含关键活动或讨论
- **测试媒体** -- 确保视频和图像在课堂前正确加载
- **尽早下载资源** -- 不要等到课堂时间才下载可打印材料
- **使用更大的屏幕** -- 投影或使用平板电脑以获得最佳教学体验

## 故障排除

### 课程未在教师视图中打开

- 确保课程已在计划中正确安排
- 检查您是否有权查看计划
- 刷新页面并重试

### 视频不播放

- 检查您的网络连接
- 确保您的设备允许媒体播放
- 尝试在单独的选项卡中打开视频
- 某些内容提供商可能对视频播放有限制

### 内容在移动设备上显示被切割

- 将您的设备旋转到横向模式
- 如果需要，稍微缩小缩放
- 考虑使用平板电脑或更大的设备以获得更好的可见性
