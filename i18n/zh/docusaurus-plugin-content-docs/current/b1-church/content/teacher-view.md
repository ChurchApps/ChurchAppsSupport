# 课程的教师视图

<div class="article-intro">
教师视图提供一个扩展的全屏界面，以结构化的板块查看课程内容，让教师和领袖在上课期间更轻松地浏览课程材料。
</div>

<div class="prereqs">
<h4>开始之前</h4>

- 您的教会必须已在计划中安排课程。详情请参阅 B1 管理指南中的[安排课程](../../b1-admin/serving/scheduling-lessons.md)。
- 您需要被分配到该计划，或有权在您的 B1.church 网站上查看该计划。
</div>

## 打开教师视图 {#opening-teacher-view}

若要访问课程的扩展教师视图：

1. 在 B1.church 成员门户中打开**计划**
2. 打开包含您要教授的课程的计划
3. 点击计划页面顶部的**教学**按钮

课程将在为教学优化的全屏界面中打开。

只有当计划的礼拜顺序直接来自已安排的课程时，才会出现**教学**按钮。如果您的教会自定义了计划的礼拜顺序，则不会显示该按钮，但课程的可打印文件仍会出现在计划的**下载**板块中。

:::tip
教师视图在将课程内容投影到屏幕或电视上供全班观看，或使用平板电脑授课时特别有用。
:::

## 教师视图功能 {#teacher-view-features}

### 板块导航 {#section-navigation}

教师视图将课程内容组织为多个板块：

- 课程的每个主要板块都以独立的标题区块显示
- 点击顶部的**板块**打开板块列表，然后选择一个即可直接跳转到该板块
- 标题会显示您当前所在的板块，例如"第 2 个板块，共 5 个"
- 板块列表让您可以方便地跳到课程的不同部分
- 当课程有多个板块时，上一个和下一个按钮（标注相邻板块的名称）会在您滚动时固定在屏幕底部

### 可滚动内容 {#scrollable-content}

主内容区域显示完整的课程材料：

- 自然地滚动浏览课程
- 滚动时，标题会自动更新为您正在查看的板块
- 所有格式化的文字、图片和说明都会清晰显示

### 媒体播放 {#media-playback}

当课程包含视频、图片或其他媒体时：

- 点击任意媒体项目即可在弹出播放器中打开
- 视频会在带有标准控件的专用视频播放器中播放
- 图片会在灯箱中全屏查看
- 关闭媒体播放器即可返回课程内容

### 可下载资源 {#downloadable-resources}

如果课程包含可下载的文件（活动单、涂色页等）：

- 每个资源的下载按钮会出现在课程最后一个板块之后
- 点击即可将文件直接下载到您的设备
- 文件可包括 PDF、图片或内容创作者提供的其他材料

## 在课堂中使用教师视图 {#using-teacher-view-in-the-classroom}

### 上课前 {#before-class}

1. 上课前在教师视图中打开课程
2. 浏览所有板块，熟悉其内容
3. 下载您需要的任何可打印资源
4. 测试所有视频或媒体，确保它们能正常播放

### 上课期间 {#during-class}

1. 在您的设备上保持教师视图打开，或将其投影到屏幕上
2. 随着课程进行，使用**板块**在各个板块之间跳转
3. 在适当的时机播放视频或展示图片
4. 根据需要滚动查看说明，同时不会丢失您的位置

### 投影到屏幕上 {#on-a-projected-screen}

为全班投影时：

- 全屏布局可减少干扰
- 大号、清晰的文字让房间另一端的人也能看清内容
- 点击媒体项目即可向全班展示视频或图片
- 使用无线鼠标或触控板进行导航

## 关闭教师视图 {#closing-teacher-view}

若要退出教师视图：

- 点击右上角的**关闭**按钮（X）
- 或按键盘上的 **Esc** 键
- 您将返回计划详情视图

## 移动设备和平板电脑使用 {#mobile-and-tablet-use}

教师视图适用于平板电脑和移动设备：

- **平板电脑** -- 非常适合希望随身携带课程指南的教师
- **手机** -- 同样支持，不过较小的屏幕可能不太适合授课
- **横屏模式** -- 在移动设备上提供最佳的观看体验

## 与常规课程视图的区别 {#differences-from-regular-lesson-view}

| 功能 | 常规视图 | 教师视图 |
|---------|--------------|--------------|
| **布局** | 紧凑，与计划内联显示 | 全屏，专用视图 |
| **导航** | 仅滚动 | 板块列表 + 带当前板块标题的滚动 |
| **媒体** | 嵌入页面中 | 弹出播放器，便于专注观看 |
| **屏幕空间** | 显示计划中的其他项目 | 最大化用于课程内容 |
| **最适合** | 浏览和规划 | 授课和演示 |

## 最佳实践 {#best-practices}

- **提前准备** -- 上课前在教师视图中浏览课程，熟悉其布局
- **标记板块** -- 记下哪些板块包含关键活动或讨论
- **测试媒体** -- 上课前确保视频和图片能正常加载
- **提早下载资源** -- 不要等到上课时才下载可打印材料
- **使用更大的屏幕** -- 通过投影或平板电脑获得最佳的授课体验

## 故障排除 {#troubleshooting}

### 课程无法在教师视图中打开 {#lesson-doesnt-open-in-teacher-view}

- 确保该课程已在计划中正确安排
- 如果计划的礼拜顺序经过自定义，**教学**按钮会被隐藏 -- 参见[打开教师视图](#opening-teacher-view)
- 检查您是否有权查看该计划
- 刷新页面后重试

### 视频无法播放 {#videos-wont-play}

- 检查您的网络连接
- 确保您的设备允许媒体播放
- 尝试在单独的标签页中打开视频
- 某些内容提供商可能对视频播放有所限制

### 移动设备上内容显示不全 {#content-appears-cut-off-on-mobile}

- 将设备旋转至横屏模式
- 如有需要，请稍微缩小页面
- 考虑使用平板电脑或更大的设备以获得更好的可视性
