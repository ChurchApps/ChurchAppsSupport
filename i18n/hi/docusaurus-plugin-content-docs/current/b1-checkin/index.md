# B1 Church Checkin अवलोकन

<div class="article-intro">

B1 Church Checkin एक iPad और Android tablets के लिए एक self-service kiosk app है। यह चर्च members को अपने परिवार को look up करने, बच्चों को groups या classes के लिए assign करने, और name labels और parent pickup slips print करने देता है -- सब कुछ एक desk पर volunteer की आवश्यकता के बिना।

</div>

## यह कैसे काम करता है

अपनी lobby या welcome area में एक iPad या Android tablet रखें। Members walk up करते हैं, अपने household को phone number या last name से search करते हैं, अपने family को review करते हैं, चुनते हैं कि प्रत्येक व्यक्ति किस groups को attend करना चाहिए, और **Check-in** पर tap करते हैं। App automatically name labels और pickup slips print करता है, फिर अगले family के लिए reset होता है।

## मुख्य सुविधाएं

- **Self-service member lookup** -- Phone number या last name से अपने household को quickly खोजें।
- **Household review** -- सभी family members को photos और current group assignments के साथ एक नज़र में देखें।
- **Group assignment** -- प्रत्येक family member को selected service time के लिए सही class या group में assign करें।
- **Guest check-in** -- spot पर अपने household में एक guest add करें first और last name के साथ।
- **QR guest registration** -- एक QR code display करें जिसे visitors अपने phone पर scan कर सकते हैं [register themselves](../b1-church/checkin/guest-registration) check-in करने से पहले।
- **Label printing** -- बच्चों के लिए name labels print करें और unique security codes के साथ parent pickup slips।
- **Network printer support** -- Network printers को directly app से discover और configure करें।
- **Auto-login** -- पहली login के बाद, app आपके credentials को याद रखता है और future launches पर सीधे services screen पर जाता है।
- **Multi-church support** -- यदि आपका account एक से अधिक churches को linked है, तो आप चुन सकते हैं कि कौन सी church में check-in करना है।
- **Church branding** -- एक church select किए जाने के बाद app header में आपकी church logo display होता है।
