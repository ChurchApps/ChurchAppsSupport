# पाठ सामग्री डाउनलोड करना

<div class="article-intro">

एक बार जब आप चर्च और classroom को select कर लेते हैं, FreePlay automatically आज के लिए schedule किए गए पाठ को fetch करता है और इसकी सभी media files को download करना शुरू करता है। यह screen वह जगह है जहां आप lesson को शुरू करने से पहले सामग्री के ready होने की प्रतीक्षा करते हैं।

</div>

<div class="prereqs">
<h4>शुरू करने से पहले</h4>

- अपने चर्च और classroom को select करें — [Selecting Your Church and Room](./selecting-room) देखें
- अपने TV को initial download के लिए internet से connected होना सुनिश्चित करें

</div>

## Download कैसे काम करता है

1. FreePlay आपके classroom के schedule को check करता है और assigned पाठ को load करता है
2. पाठ का name, title, और description screen पर appear होते हैं, पाठ के cover image पर overlay किए गए
3. एक progress indicator **Downloading item X of Y** दिखाता है जब हर file device में save होता है
4. जब सभी files download हो जाती हैं, **Start Lesson** button appear होता है

Download के दौरान आपको कुछ नहीं करना है। FreePlay सब कुछ automatically handle करता है।

## Resolution

FreePlay default रूप से content को 720p पर download करता है। resolution setting (720p या 1080p) downloaded video और image files की quality को determine करता है। बड़े TVs पर higher resolution sharper दिखता है लेकिन download में अधिक समय लेता है और अधिक storage use करता है।

:::info
Resolution default से 720p पर set है। Content आपके device के लिए configured resolution पर download होता है।
:::

## Lesson को शुरू करना

Download complete होने के बाद, **Start Lesson** button screen के नीचे fade in होता है। अपने TV remote का use करके इसे highlight करें और **Select** को press करें playback शुरू करने के लिए।

## Automatic Refresh

FreePlay हर घंटे updated content को check करता है। यदि दिन के दौरान schedule change होता है, app automatically नया पाठ pick up करता है। आप अपने remote पर **Back** को भी press कर सकते हैं room selection screen पर return करने के लिए और refresh को force करने के लिए download screen को फिर से enter करें।

:::tip
अपने building में strong internet connection होने पर पहले से lessons को download करें। एक बार download हो जाने के बाद, सामग्री बिना किसी network dependency के offline खेलता है।
:::

## Downloads Screen

FreePlay एक **Downloads** screen include करता है जहां आप device पर download की गई सभी content को view और manage कर सकते हैं। **Settings** को bottom of the sidebar से खोलें, फिर **Downloads** को select करें। यह आपको visibility देता है कि locally क्या store है।

## यदि Schedule खाली है

यदि selected classroom के लिए कोई पाठ schedule नहीं है, आप देखेंगे "The schedule could not be loaded. Make sure a lesson is scheduled for this class." अपने schedule को [freeplay.church](https://freeplay.church) पर check करें।
