# डेवलपर दस्तावेज़

<div class="article-intro">

ChurchApps लगभग 20 ओपन-सोर्स प्रोजेक्ट्स का एक संग्रह है, जो मिलकर एक पूर्ण चर्च प्रबंधन प्लेटफ़ॉर्म प्रदान करते हैं। इन प्रोजेक्ट्स में बैकएंड APIs, वेब एप्लिकेशन, मोबाइल ऐप्स, एक डेस्कटॉप एप्लिकेशन और साझा लाइब्रेरी शामिल हैं -- ये सभी TypeScript में लिखे गए हैं। यह अनुभाग आपको स्थानीय डेवलपमेंट एनवायरनमेंट सेट करने और योगदान देना शुरू करने के लिए आवश्यक सब कुछ देता है।

</div>

## एक नज़र में आर्किटेक्चर

ये प्रोजेक्ट्स **स्वतंत्र रिपॉज़िटरी** हैं (मोनोरेपो नहीं)। साझा कोड `@churchapps/*` स्कोप के अंतर्गत npm पर प्रकाशित होता है और सामान्य डिपेंडेंसी के रूप में उपयोग होता है। इसका अर्थ है कि आप पूरे ईकोसिस्टम को क्लोन किए बिना भी किसी एक प्रोजेक्ट पर काम कर सकते हैं।

मुख्य विशेषताएँ:

- **भाषा:** पूरे प्रोजेक्ट में TypeScript
- **बैकएंड:** Node.js / Express APIs, जो Serverless Framework के माध्यम से AWS Lambda पर डिप्लॉय होते हैं
- **वेब:** React 19 (Vite और Next.js), Material-UI 7
- **मोबाइल:** Expo के साथ React Native
- **डेटाबेस:** MySQL 8.0, प्रति API मॉड्यूल एक डेटाबेस

## इस अनुभाग में क्या है

- **[सेटअप](setup/)** -- स्थानीय डेवलपमेंट एनवायरनमेंट, पूर्वापेक्षाएँ और कॉन्फ़िगरेशन
  - [पूर्वापेक्षाएँ](setup/prerequisites) -- आवश्यक टूल और सॉफ़्टवेयर
  - [प्रोजेक्ट का अवलोकन](setup/project-overview) -- सभी प्रोजेक्ट्स एक नज़र में
  - [एनवायरनमेंट वेरिएबल्स](setup/environment-variables) -- `.env` फ़ाइलों को कॉन्फ़िगर करना
- **[API](api/)** -- कोर API का स्थानीय सेटअप, डेटाबेस इनिशियलाइज़ेशन और मॉड्यूल संरचना
- **[वेब ऐप्स](web-apps/)** -- B1Admin, B1App और LessonsApp को स्थानीय रूप से चलाना
- **[मोबाइल ऐप्स](mobile/)** -- B1Mobile और अन्य Expo ऐप्स बनाना
- **[साझा लाइब्रेरी](shared-libraries/)** -- Helpers, ApiHelper और AppHelper के साथ काम करना
- **[डिप्लॉयमेंट](deployment/)** -- APIs, वेब ऐप्स और मोबाइल ऐप्स को डिप्लॉय करना
- **[FreePlay कंटेंट प्रोवाइडर](freeplay-content-provider)** -- अपनी लेसन लाइब्रेरी को FreePlay से जोड़ना
