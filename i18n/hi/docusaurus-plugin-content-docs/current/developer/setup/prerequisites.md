# पूर्वापेक्षाएँ

<div class="article-intro">

आपको किन उपकरणों की ज़रूरत होगी, यह इस पर निर्भर करता है कि आप किन परियोजनाओं पर काम करना चाहते हैं। यह पृष्ठ सभी आवश्यक सॉफ़्टवेयर को विकास क्षेत्र के अनुसार सूचीबद्ध करता है, सार्वभौमिक आवश्यकताओं से लेकर प्लेटफ़ॉर्म-विशिष्ट टूलचेन तक।

</div>

<div class="prereqs">
<h4>शुरू करने से पहले</h4>

- यह तय करने के लिए [परियोजना अवलोकन](./project-overview.md) देखें कि आप किन परियोजनाओं पर काम करना चाहते हैं
- सॉफ़्टवेयर इंस्टॉल करने के लिए अपनी विकास मशीन पर व्यवस्थापक (administrator) पहुँच होनी चाहिए

</div>

## सभी परियोजनाएँ

ये आपकी परियोजना चाहे जो भी हो, हर स्थिति में आवश्यक हैं:

| उपकरण | संस्करण | टिप्पणियाँ |
|------|---------|-------|
| **Node.js** | 20+ | B1App और LessonsApp (Next.js 16) के लिए संस्करण 22+ आवश्यक है; Api के लिए 24+ आवश्यक है |
| **npm** | Node.js के साथ आता है | सभी परियोजनाओं में पैकेज मैनेजर के रूप में उपयोग किया जाता है |
| **Git** | नवीनतम | प्रत्येक परियोजना एक अलग रिपॉज़िटरी है |

:::tip
Node के संस्करणों के बीच आसानी से स्विच करने के लिए [nvm](https://github.com/nvm-sh/nvm) (macOS/Linux) या [nvm-windows](https://github.com/coreybutler/nvm-windows) (Windows) जैसे Node संस्करण मैनेजर का उपयोग करें।
:::

## बैकएंड API विकास

यदि आप API को स्थानीय रूप से चलाने की योजना बना रहे हैं (डेमो APIs की ओर इशारा करने के बजाय):

| उपकरण | संस्करण | टिप्पणियाँ |
|------|---------|-------|
| **MySQL** | 8.0+ | हर API मॉड्यूल अपना स्वयं का डेटाबेस उपयोग करता है |

मुख्य API के लिए आपको छह डेटाबेस की आवश्यकता होगी: `membership`, `attendance`, `content`, `giving`, `messaging`, और `doing`। API में स्कीमा शुरू करने के लिए स्क्रिप्ट शामिल हैं -- देखें [API स्थानीय सेटअप](../api/local-setup.md) मार्गदर्शिका।

## मोबाइल ऐप विकास

B1Checkin, LessonsScreen, या अन्य React Native / Expo ऐप्स के लिए:

| उपकरण | संस्करण | टिप्पणियाँ |
|------|---------|-------|
| **Expo CLI** | नवीनतम | ग्लोबली इंस्टॉल करें: `npm install -g expo-cli` |
| **Android Studio** | नवीनतम | Android विकास के लिए आवश्यक (इसमें Android SDK शामिल है) |
| **Xcode** | नवीनतम | iOS विकास के लिए आवश्यक (केवल macOS) |

:::info
Android Studio या Xcode के बिना त्वरित परीक्षण के लिए आप भौतिक डिवाइस पर Expo Go ऐप का उपयोग कर सकते हैं। हालाँकि, प्रोडक्शन बाइनरी बनाने के लिए नेटिव टूलचेन आवश्यक हैं।
:::

## FreeShow (डेस्कटॉप ऐप) विकास

FreeShow को अतिरिक्त नेटिव बिल्ड निर्भरताओं की आवश्यकता होती है क्योंकि यह नेटिव Node मॉड्यूल (जैसे `canvas`) कंपाइल करता है:

### सभी प्लेटफ़ॉर्म

| उपकरण | संस्करण | टिप्पणियाँ |
|------|---------|-------|
| **Python** | 3.12 | नेटिव मॉड्यूल कंपाइलेशन के लिए `node-gyp` द्वारा आवश्यक |
| **setuptools** | नवीनतम | `pip install setuptools` के माध्यम से इंस्टॉल करें |

### Windows

| उपकरण | टिप्पणियाँ |
|------|-------|
| **Visual Studio** | Community संस्करण पर्याप्त है |
| **"Desktop development with C++" वर्कलोड** | Visual Studio इंस्टॉलेशन के दौरान चुनें |
| **Windows 10 SDK** | C++ वर्कलोड में शामिल; सुनिश्चित करें कि यह चेक किया गया हो |

आप कमांड लाइन के माध्यम से Visual Studio बिल्ड टूल इंस्टॉल कर सकते हैं:

```bash
npm install --global windows-build-tools
```

या Visual Studio Community इंस्टॉल करें और इंस्टॉलेशन के दौरान "Desktop development with C++" वर्कलोड चुनें।

### Linux

```bash
sudo apt-get install libfontconfig1-dev
```

### macOS

आमतौर पर Xcode Command Line Tools पर्याप्त होते हैं:

```bash
xcode-select --install
```

## अपना इंस्टॉलेशन सत्यापित करें

पुष्टि करने के लिए ये कमांड चलाएँ कि सब कुछ इंस्टॉल है:

```bash
node --version    # v20.x.x या उससे अधिक प्रिंट होना चाहिए
npm --version     # 10.x.x या उससे अधिक प्रिंट होना चाहिए
git --version     # git version 2.x.x प्रिंट होना चाहिए
mysql --version   # केवल स्थानीय API विकास के लिए आवश्यक
```
