# आर्किटेक्चर

<div class="article-intro">

ये पेज क्रॉस-रिपो सिस्टम मैप हैं: ये दिखाते हैं कि कोई मुख्य ChurchApps सिस्टम शुरू से अंत तक कैसे काम करता है, ऐप्स, API मॉड्यूल और साझा लाइब्रेरी में फैला हुआ। ये यह नहीं बताते कि कोई एक प्रोजेक्ट कैसे सेट अप होता है। किसी सिस्टम का व्यवहार बदलने से पहले इन्हें पढ़ें। कोई प्रोजेक्ट चालू करने के लिए [सेटअप](../setup/index.md) पढ़ें और एंडपॉइंट-स्तर की जानकारी के लिए [API सेक्शन](../api/index.md) देखें।

</div>

## इकोसिस्टम एक नज़र में

ChurchApps लगभग 20 स्वतंत्र रिपॉज़िटरी है (यह मोनोरेपो नहीं है)। क्लाइंट ऐप्स HTTPS और WebSocket के ज़रिए बैकएंड APIs के एक छोटे सेट से बात करते हैं, और `@churchapps` स्कोप के तहत प्रकाशित npm पैकेज के ज़रिए कोड साझा करते हैं।

```
┌────────────────────────────────┐            ┌──────────────────────────────────────────────┐
│  Clients                       │            │  Api — core modular monolith (AWS Lambda)    │
│                                │            │                                              │
│  B1Admin    staff dashboard    │   HTTPS    │   membership    attendance    content        │
│  B1App      member portal +    │ ─────────▶ │   giving        messaging     doing          │
│             church websites    │            │                                              │
│  B1Checkin  check-in kiosk     │ ◀───WS───▶ │   one MySQL database per module (6 total)    │
│                                │            └──────────────────────────────────────────────┘
│  FreePlay   TV content player  │            ┌──────────────────────────────────────────────┐
└───────────────┬────────────────┘            │  LessonsApi — Lessons.church backend         │
                │                             └──────────────────────────────────────────────┘
                │  shared code via npm (@churchapps/*)
                ▼
   helpers (cross-app interfaces) · apphelper (React components) · apihelper (Express/server utilities)
```

इस सेक्शन में दस्तावेज़ीकृत हर चीज़ को आकार देने वाले दो संरचनात्मक नियम:

1. **मॉड्यूल अलग-थलग हैं।** हर Api मॉड्यूल अपना डेटाबेस और अपनी टेबल रखता है। अन्य मॉड्यूल और ऐप्स उसके डेटा तक केवल उसके REST एंडपॉइंट्स के ज़रिए पहुँचते हैं। देखें [मॉड्यूल संरचना](../api/module-structure.md)।
2. **साझा कोड npm पैकेज के रूप में आता है।** ऐप्स एक-दूसरे का सोर्स कोड इम्पोर्ट नहीं करते। जो भी दोबारा उपयोग होता है, वह `@churchapps/helpers`, `@churchapps/apphelper` या `@churchapps/apihelper` के ज़रिए रिपो की सीमाएँ पार करता है। देखें [साझा लाइब्रेरी](../shared-libraries/index.md)।
