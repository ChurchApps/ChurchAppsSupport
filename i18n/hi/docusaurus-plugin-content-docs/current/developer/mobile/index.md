# मोबाइल ऐप्स

<div class="article-intro">

ChurchApps के मोबाइल ऐप्स **React Native** और **Expo** से बनाए गए हैं, जो Android, iOS और Android TV पर नेटिव अनुभव देते हैं। सभी मोबाइल ऐप्स एक ही Expo-आधारित टूलचेन साझा करते हैं, इसलिए अगर आप एक ऐप बना सकते हैं, तो आप सभी बना सकते हैं।

</div>

## ऐप्स

| ऐप | उद्देश्य | प्लेटफ़ॉर्म |
|-----|---------|----------|
| B1 Checkin | चेक-इन स्टेशनों के लिए किओस्क ऐप | Android, iOS |
| LessonsScreen | कक्षाओं में पाठ दिखाने के लिए Android TV ऐप | Android TV |

:::info
सदस्यों के लिए बना ऐप B1 App है, यानी B1App का `/mobile` खंड, जिसे सदस्य Progressive Web App (PWA) के रूप में इंस्टॉल करते हैं। यह एक वेब ऐप है, Expo प्रोजेक्ट नहीं; इसे स्थानीय रूप से चलाने के लिए [वेब ऐप्स](../web-apps/index.md) देखें।
:::

### B1 Checkin

यह चर्चों के चेक-इन स्टेशनों के लिए विशेष रूप से बना किओस्क ऐप है। यह एक सरल, स्पर्श-अनुकूल इंटरफ़ेस देता है, जिससे सदस्य बच्चों का चेक-इन कर सकते हैं और सेवाओं व कार्यक्रमों में उपस्थिति दर्ज कर सकते हैं।

### LessonsScreen

यह एक Android TV ऐप है जो कक्षाओं में पाठ की सामग्री दिखाता है। शिक्षक पाठ की स्लाइड, वीडियो और गतिविधियाँ TV स्क्रीन पर भेज सकते हैं, जिससे कक्षाओं के दौरान पाठ्यक्रम की सामग्री प्रस्तुत करना आसान हो जाता है।

## स्थानीय सेटअप

सभी मोबाइल ऐप्स एक ही Expo-आधारित टूलचेन साझा करते हैं और लगभग एक जैसे सेटअप पैटर्न का पालन करते हैं। उदाहरण के रूप में B1 Checkin का उपयोग करते हुए:

1. **Node.js**, Android Studio (Android एमुलेटर के लिए) और Xcode (iOS सिम्युलेटर के लिए, केवल macOS पर) इंस्टॉल करें — देखें [पूर्वापेक्षाएँ](../setup/prerequisites.md)।
2. रिपॉज़िटरी क्लोन करें और डिपेंडेंसी इंस्टॉल करें (B1 Checkin Yarn का उपयोग करता है):

   ```bash
   git clone https://github.com/ChurchApps/B1Checkin.git
   cd B1Checkin && yarn install
   ```

3. `dotenv.sample.txt` को `.env` में कॉपी करें और वह स्टेज सेट करें जिससे ऐप कनेक्ट हो (स्थानीय API के लिए `dev`) — देखें [पर्यावरण चर](../setup/environment-variables.md#b1checkin-react-native--expo)।
4. `yarn start` से Expo डेव सर्वर शुरू करें, फिर एमुलेटर या डिवाइस पर ऐप लॉन्च करने के लिए `yarn android` या `yarn ios` चलाएँ।

रिलीज़ बिल्ड और ओवर-द-एयर अपडेट के लिए [मोबाइल डिप्लॉयमेंट](../deployment/mobile.md) देखें।
