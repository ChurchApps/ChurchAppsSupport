# सदस्य निर्देशिका

<div class="article-intro">

Member directory आपको अपनी चर्च में लोगों को browse और search करने देता है। चाहे आपको एक fellow group member को look up करना हो या किसी नए को खोजना हो, directory आपकी चर्च family के साथ connect करना आसान बनाता है।

</div>

<div class="prereqs">
<h4>शुरुआत करने से पहले</h4>

- आपको अपने B1.church account के लिए [logged in](../getting-started/logging-in.md) होना चाहिए।
- Directory केवल **members और staff** के लिए उपलब्ध है। Visitors और attendees जो अभी तक members नहीं बने हैं एक "Members Only" message देखेंगे।

</div>

## Directory को Access करना

1. [sidebar navigation](../getting-started/navigating.md) में **Community** पर क्लिक करें।
2. Directory loads होता है page के left side पर सभी visible church members की एक सूची के साथ।

## Members को Search करना

Page एक master-detail layout का उपयोग करता है। Left side पर, आपके पास लोगों को खोजने के दो तरीके हैं:

### नाम से Search करना

1. सुनिश्चित करें कि search area के top पर **People** filter select है।
2. Search box में एक नाम type करें।
3. Results को देखने के लिए **Search** पर क्लिक करें या **Enter** दबाएं।

यदि आप search box को empty छोड़ते हैं और **Search** पर क्लिक करते हैं, तो पूरी directory listing दिखाई देती है।

### Group द्वारा Search करना

1. Search area के top पर **Groups** filter पर क्लिक करें।
2. Dropdown list से एक group select करें।
3. उस group के सभी members को देखने के लिए **Search** पर क्लिक करें।

:::tip
Group द्वारा search करना किसी को quickly खोजने का एक तरीका है जिससे आप एक [group meeting](../groups/browsing-groups.md) में मिले थे लेकिन जिनका नाम आप बिल्कुल याद नहीं कर सकते।
:::

## Directory को Browse करना

Members को alphabetically list किया जाता है last name द्वारा और letter headings के तहत grouped किया जाता है (A, B, C, आदि)। प्रत्येक entry member का photo, display name, और household name दिखाता है, जिससे list के through scan करना आसान होता है।

## एक Member Profile को देखना

List में किसी भी member पर क्लिक करें उनके profile को right पर detail panel में खोलने के लिए। Profile वह member की information display करता है जैसा कि आपकी चर्च द्वारा configured है, जिसमें contact details, household members, और group memberships शामिल हो सकते हैं।

आप profile के अंदर household members पर क्लिक कर सकते हैं उनके profiles को navigate करने के लिए।

:::info
प्रत्येक profile में दृश्यमान information आपकी चर्च की privacy और directory settings पर निर्भर करता है। हर member के लिए सभी fields show नहीं किए जा सकते।
:::

:::info
आपकी चर्च के [minimum age for private messages](/docs/b1-admin/settings/mobile-app#member-directory--messaging-settings) के अंतर्गत Members directory में दिखाई देते हैं, लेकिन उन्हें एक private message भेजने का विकल्प unavailable है।
:::
