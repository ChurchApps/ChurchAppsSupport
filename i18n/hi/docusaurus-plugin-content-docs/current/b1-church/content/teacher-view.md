# Lessons के लिए Teacher View

<div class="article-intro">
Teacher View lesson content देखने के लिए एक विस्तृत, full-screen interface देता है जिसमें संरचित sections होते हैं। इससे शिक्षकों और leaders को कक्षा के समय lesson materials में आसानी से आगे-पीछे जाने में मदद मिलती है।
</div>

<div class="prereqs">
<h4>शुरू करने से पहले</h4>

- आपके church के plan में lessons schedule होने चाहिए। विवरण के लिए B1 Admin guide देखें: [Scheduling Lessons](../../b1-admin/serving/scheduling-lessons.md)।
- आपको plan में assign होना चाहिए या अपनी B1.church site पर उसे देखने की access होनी चाहिए।
</div>

## Teacher View खोलना

किसी lesson के लिए विस्तृत teacher view तक पहुंचने के लिए:

1. B1.church member portal में **Plans** खोलें
2. वह plan खोलें जिसमें वह lesson है जिसे आप पढ़ाना चाहते हैं
3. plan page के ऊपर **Teach** button पर click करें

lesson पढ़ाने के लिए अनुकूलित full-screen interface में खुलेगा।

:::tip
Teacher View विशेष रूप से उपयोगी है जब कक्षा के देखने के लिए lesson content को screen या TV पर project करना हो, या tablet से पढ़ाना हो।
:::

## Teacher View की विशेषताएं

### Section Navigation

teacher view lesson content को sections में व्यवस्थित करता है:

- lesson का हर मुख्य section अपने शीर्षक वाले block के रूप में दिखता है
- sections की सूची खोलने के लिए ऊपर **Sections** पर click करें, फिर सीधे किसी एक पर जाने के लिए उसे चुनें
- heading दिखाता है कि आप किस section में हैं, जैसे "Section 2 of 5"
- section सूची lesson के अलग-अलग हिस्सों में आसानी से जाने देती है

### Scrollable Content

मुख्य content area पूरी lesson materials दिखाता है:

- lesson में स्वाभाविक रूप से scroll करें
- scroll करते समय heading अपने-आप उस section से मेल खाने के लिए update होता है जिसे आप देख रहे हैं
- सभी formatted text, images, और instructions साफ़ तौर पर दिखाए जाते हैं

### Media Playback

जब lessons में videos, images, या अन्य media होते हैं:

- किसी भी media item पर click करें ताकि वह popup player में खुले
- videos standard controls वाले एक समर्पित video player में चलते हैं
- images full-screen देखने के लिए lightbox में खुलते हैं
- lesson content पर लौटने के लिए media player बंद करें

### Downloadable Resources

यदि lesson में downloadable files हैं (activity sheets, coloring pages, आदि):

- हर resource के लिए download buttons दिखते हैं
- files सीधे अपने device पर download करने के लिए click करें
- files में PDFs, images, या content creator द्वारा दी गई अन्य materials हो सकती हैं

## Classroom में Teacher View का उपयोग

### Class से पहले

1. class शुरू होने से पहले Teacher View में lesson खोलें
2. सभी sections की समीक्षा करें और content से परिचित हों
3. जो printable resources चाहिए उन्हें download करें
4. सुनिश्चित करने के लिए कि वे सही चलें, कोई भी videos या media जांचें

### Class के दौरान

1. अपने device पर Teacher View खुला रखें या उसे screen पर project करें
2. lesson में आगे बढ़ते हुए sections के बीच जाने के लिए **Sections** का उपयोग करें
3. उचित समय पर videos चलाएं या images दिखाएं
4. अपनी जगह खोए बिना ज़रूरत के अनुसार instructions में scroll करें

### Projected Screen पर

class के लिए project करते समय:

- full-screen layout ध्यान भटकाने वाली चीज़ें हटा देता है
- बड़ा, पढ़ने योग्य text पूरे कमरे से content दिखाई देने देता है
- पूरी class को videos या images दिखाने के लिए media items पर click करें
- wireless mouse या trackpad से navigate करें

## Teacher View बंद करना

teacher view से बाहर निकलने के लिए:

- ऊपरी कोने में **Close** button (X) पर click करें
- या अपने keyboard पर **Esc** key दबाएं
- आप plan details view पर लौट आएंगे

## Mobile और Tablet पर उपयोग

Teacher View tablets और mobile devices पर काम करता है:

- **Tablets** -- उन शिक्षकों के लिए बेहतरीन जो एक portable lesson guide चाहते हैं
- **Phones** -- समर्थित भी है, हालांकि छोटी screen पढ़ाने के लिए कम आदर्श हो सकती है
- **Landscape mode** -- mobile devices पर सबसे अच्छा देखने का अनुभव देता है

## Regular Lesson View से अंतर

| Feature | Regular View | Teacher View |
|---------|--------------|--------------|
| **Layout** | Compact, plan के साथ inline | Full-screen, समर्पित view |
| **Navigation** | केवल scroll | Section सूची + वर्तमान section heading के साथ scroll |
| **Media** | पेज में embedded | केंद्रित देखने के लिए popup player |
| **Screen space** | Plan के अन्य items दिखाता है | Lesson content के लिए अधिकतम |
| **Best for** | ब्राउज़ करना और योजना बनाना | पढ़ाना और प्रस्तुत करना |

## सर्वोत्तम अभ्यास

- **पहले से तैयारी करें** -- layout से परिचित होने के लिए class से पहले Teacher View में lessons की समीक्षा करें
- **Sections चिह्नित करें** -- नोट करें कि कौन-से sections में मुख्य गतिविधियां या चर्चाएं हैं
- **Media जांचें** -- class के समय से पहले सुनिश्चित करें कि videos और images ठीक से load होते हैं
- **Resources जल्दी download करें** -- printables download करने के लिए class के समय तक इंतज़ार न करें
- **बड़ी screen का उपयोग करें** -- सबसे अच्छे पढ़ाने के अनुभव के लिए project करें या tablet का उपयोग करें

## समस्या निवारण

### Lesson Teacher View में नहीं खुलता

- सुनिश्चित करें कि lesson plan में ठीक से schedule हुआ है
- जांचें कि आपके पास plan देखने की अनुमति है
- पेज refresh करें और फिर से प्रयास करें

### Videos नहीं चलते

- अपना internet connection जांचें
- सुनिश्चित करें कि आपका device media playback की अनुमति देता है
- video को अलग tab में खोलने का प्रयास करें
- कुछ content providers के video playback पर प्रतिबंध हो सकते हैं

### Mobile पर content कटा हुआ दिखता है

- अपने device को landscape mode में घुमाएं
- ज़रूरत हो तो थोड़ा zoom out करें
- बेहतर दृश्यता के लिए tablet या बड़े device का उपयोग करने पर विचार करें
