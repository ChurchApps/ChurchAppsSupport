# समूह कैलेंडर

<div class="article-intro">

B1 में हर समूह का अपना event calendar हो सकता है। समूह leaders इसका उपयोग meetings, गतिविधियों और आवर्ती events को schedule करने के लिए करते हैं, जबकि सभी समूह सदस्य आगामी events देख सकते हैं और उनके बारे में बातचीत में शामिल हो सकते हैं। कैलेंडर आपके समूह को व्यवस्थित रखता है और यह सुनिश्चित करता है कि सभी को आने वाली चीज़ों की जानकारी रहे।

</div>

<div class="prereqs">
<h4>शुरुआत से पहले</h4>

- आपको B1 Admin में एक समूह बनाना होगा जिसमें कम से कम एक सदस्य हो। [Creating Groups](creating-groups.md) और [Group Members](group-members.md) देखें।
- calendar events जोड़ने या संपादित करने के लिए, आपको समूह leader के रूप में नियुक्त होना चाहिए। निर्देशों के लिए [Designating Group Leaders](group-members.md) देखें।

</div>

## समूह कैलेंडर तक पहुंचना

समूह कैलेंडर B1.church सदस्य ऐप के माध्यम से उपलब्ध है:

1. B1 Admin से, अपनी स्क्रीन के ऊपरी दाएं कोने में **dropdown menu** पर क्लिक करें।
2. **Switch App** चुनें।
3. **B1.church** चुनें।
4. बाईं साइडबार में **Groups** पर क्लिक करें।
5. सूची से अपना समूह चुनें।
6. स्क्रीन के बाईं ओर **Calendar** पर क्लिक करें।

:::info
समूह कैलेंडर B1 Admin के बजाय B1.church (सदस्य ऐप) के माध्यम से प्रबंधित होता है। समूह leaders एडमिन डैशबोर्ड से ऐप बदलकर इसे एक्सेस करते हैं।
:::

## एक Event जोड़ना

1. समूह कैलेंडर से, **Add an Event** पर क्लिक करें।
2. event के लिए एक **title** दर्ज करें।
3. event किस बारे में है, इसका एक संक्षिप्त **description** लिखें।
4. **start time** और **end time** सेट करें।
5. event को कैलेंडर में जोड़ने के लिए **Save** पर क्लिक करें।

## आवर्ती Events सेट करना

यदि आपका समूह नियमित समय पर मिलता है, तो आप events को अपने आप दोहराने के लिए सेट कर सकते हैं:

1. event बनाते या संपादित करते समय, **Recurring** बॉक्स को चेक करें।
2. चुनें कि event कैसे दोहराया जाए:
   - **Interval** -- हर बार के बीच दिनों की संख्या सेट करें। उदाहरण के लिए, "7" दर्ज करने पर event हर 7 दिन में दोहराया जाएगा।
   - **Frequency** -- **day**, **week**, या **month** के अनुसार दोहराने के लिए चुनें।
3. event सेव करें। यह अब कैलेंडर पर हर निर्धारित occurrence में दिखाई देगा।

:::tip
जो समूह हर शनिवार को मिलता है, उसके लिए frequency "week" सेट करें और शनिवार चुनें। event आगे के लिए कैलेंडर पर अपने आप भर जाएगा।
:::

## B1 Admin में एक साथ कई Events बनाना

B1 Admin में समूह के पेज पर एक **Calendar** सेक्शन भी है, जहां staff एक पूरे सीज़न की meetings एक साथ schedule कर सकते हैं:

1. B1 Admin में समूह खोलें और **Calendar** सेक्शन में **All events** पर क्लिक करें।
2. **Add Recurring Events** dialog खोलने के लिए **+ Add Events** पर क्लिक करें।
3. schedule चुनें (weekly, every 2 weeks, monthly, या one time), **First Meeting** और **Last Meeting** की तारीखें, और वैकल्पिक रूप से **Skip holidays** चुनें।
4. meeting की तारीखों का preview देखें और छोड़ने के लिए किसी भी तारीख को अनचेक करें।
5. यदि आप चाहते हैं कि सदस्य इन events का जवाब दे सकें, तो **Allow RSVPs** को चेक रखें (नीचे देखें), फिर सेव करें।

## Event RSVPs

समूह events में RSVPs लिए जा सकते हैं -- event की हर occurrence के लिए **Yes**, **No**, या **Maybe**।

- **Allow RSVPs** bulk-add dialog के माध्यम से बनाए गए events के लिए डिफ़ॉल्ट रूप से चालू होता है; उन events के लिए responses बंद करने के लिए इसे अनचेक करें। जिन events में RSVPs बंद हैं, वे समूह की event सूची में **Disabled** के रूप में दिखते हैं।
- B1 Admin में समूह की event सूची में, हर event एक response summary दिखाता है (उदाहरण के लिए, "5 yes · 2 maybe · 1 no")। **RSVP Responses** roster खोलने के लिए उस पर क्लिक करें, जिसमें उस occurrence के लिए yes, maybe और no जवाब देने वालों की सूची होती है।

:::tip
RSVPs पूरे event registration की औपचारिकता के बिना leaders को उपस्थिति की संख्या देते हैं। paid signups या capacity-managed events के लिए, इसके बजाय [event registration](../calendars/creating-calendars.md#enabling-event-registration) का उपयोग करें।
:::

## कैलेंडर देखना

समूह कैलेंडर कई view विकल्प देता है:

- **Month** -- पूरा महीना एक नज़र में देखें।
- **Week** -- वर्तमान सप्ताह पर ध्यान दें।
- **Day** -- एक दिन को विस्तार से देखें।
- **Agenda** -- आगामी events की सूची समय क्रम में देखें।

कैलेंडर के शीर्ष पर बटनों का उपयोग करके views के बीच स्विच करें।

## Event विवरण और बातचीत

किसी भी event पर क्लिक करके उसका विवरण देखें। event detail view से:

- **Members और leaders** event के बारे में बातचीत शुरू कर सकते हैं और comments छोड़ सकते हैं।
- **Leaders** event विवरण संपादित कर सकते हैं, समय बदल सकते हैं, या event हटा सकते हैं।

:::warning
event हटाने से वह स्थायी रूप से हट जाता है। यदि आपको किसी आवर्ती event की केवल एक occurrence रद्द करनी है, तो इसके बजाय उसे संपादित करने पर विचार करें।
:::

## कैलेंडर की सदस्यता लेना

आप समूह कैलेंडर को अपने व्यक्तिगत कैलेंडर के साथ sync कर सकते हैं:

1. समूह कैलेंडर पेज से, **Subscribe** पर क्लिक करें।
2. कैलेंडर को Google Calendar, Apple Calendar, Outlook, या subscriptions का समर्थन करने वाले किसी अन्य calendar application में जोड़ने के लिए निर्देशों का पालन करें।

:::tip
subscribe करने से आपका व्यक्तिगत schedule B1 को अलग से देखे बिना समूह के events के साथ sync रहता है। समूह leaders द्वारा किए गए किसी भी बदलाव आपके sync किए गए कैलेंडर में अपने आप दिखाई देंगे।
:::
