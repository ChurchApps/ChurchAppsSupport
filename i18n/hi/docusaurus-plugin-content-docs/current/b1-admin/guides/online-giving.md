# ऑनलाइन दान सेट अप करें

<div class="article-intro">

दान फंड बनाने से लेकर भुगतान प्रोसेसिंग के लिए Stripe जोड़ने और अपनी मंडली के साथ दान पृष्ठ साझा करने तक, अपने चर्च में ऑनलाइन दान स्वीकार करने के लिए ज़रूरी सब कुछ चरण-दर-चरण देखें। अंत तक, सदस्य आपकी वेबसाइट और मोबाइल ऐप के ज़रिए ऑनलाइन दान कर पाएँगे।

</div>

<div class="prereqs">
<h4>शुरू करने से पहले</h4>

- एडमिन पहुँच वाला B1 Admin खाता — देखें [भूमिकाएँ और अनुमतियाँ](../people/roles-permissions.md)
- एक Stripe खाता (ज़रूरत हो तो [stripe.com](https://stripe.com) पर मुफ़्त में बनाएँ)

</div>

## चरण 1: दान फंड बनाएँ

फंड वे श्रेणियाँ हैं जिनमें दानदाता दान कर सकते हैं। दान स्वीकार करने से पहले आपको कम से कम एक फंड की ज़रूरत होगी।

अपनी दान श्रेणियाँ सेट करने के लिए [फंड](../donations/funds.md) गाइड का पालन करें:

1. अपने सबसे सामान्य फंड बनाएँ (जैसे, "General Fund", "Building Fund", "Missions")
2. कर-कटौती योग्य (tax-deductible) फंड को उचित रूप से चिह्नित करें — इसका असर वर्ष-अंत के दान विवरणों पर पड़ता है

:::tip
आप कभी भी और फंड जोड़ सकते हैं। अपनी सबसे सामान्य दान श्रेणियों से शुरुआत करें।
:::

## चरण 2: Stripe कनेक्ट करें

Stripe सभी भुगतान प्रोसेसिंग संभालता है। आप अपना Stripe खाता B1 Admin से जोड़ेंगे ताकि दान सीधे आपके बैंक खाते में पहुँचें।

Stripe कनेक्ट करने के लिए [ऑनलाइन दान सेटअप](../donations/online-giving-setup.md) गाइड का पालन करें:

1. अपने Stripe डैशबोर्ड में लॉग इन करें और अपनी Publishable Key और Secret Key प्राप्त करें
2. B1 Admin में, Settings पर जाएँ और दोनों कुंजियाँ दर्ज करें

:::warning
Stripe आपकी Secret Key केवल एक बार दिखाता है। Stripe डैशबोर्ड छोड़ने से पहले उसे कॉपी करके सहेज लें। यदि यह खो जाए, तो आपको नई Key बनानी होगी।
:::

## चरण 3: अपनी वेबसाइट पर दान पृष्ठ जोड़ें

एक दान पृष्ठ जोड़कर दान को सुलभ बनाएँ।

अपनी B1 वेबसाइट पर दान पृष्ठ जोड़ने के लिए [ऑनलाइन दान सेटअप](../donations/online-giving-setup.md) और [पृष्ठ प्रबंधन](../website/managing-pages.md) गाइड का पालन करें:

1. अपनी B1.church साइट पर एक "Donate" टैब जोड़ें
2. आपका दान URL होगा: `https://yoursubdomain.b1.church/donate`
3. सदस्य बिना लॉग इन किए दान कर सकते हैं (सार्वजनिक पृष्ठ), या सहेजे गए भुगतान तरीकों और दान इतिहास के लिए लॉग इन कर सकते हैं

## चरण 4: एक परीक्षण दान करें

अपनी मंडली को घोषणा करने से पहले, जाँच लें कि सब कुछ काम करता है।

1. प्रक्रिया शुरू से अंत तक काम करती है या नहीं, यह जाँचने के लिए एक छोटा परीक्षण दान करें
2. जाँचें कि दान B1 Admin में Donations के अंतर्गत दिखाई देता है

:::tip
यदि आप असली शुल्क लगाए बिना जाँचना चाहते हैं, तो पहले Stripe का test mode उपयोग करें, फिर अपनी मंडली को घोषणा करने से पहले live mode पर स्विच करें।
:::

## चरण 5: अपनी मंडली को सूचित करें

बात फैलाएँ ताकि सदस्य जानें कि वे ऑनलाइन दान कर सकते हैं।

1. अपनी वेबसाइट, ईमेल न्यूज़लेटर, बुलेटिन और सोशल मीडिया के ज़रिए दान URL साझा करें
2. सदस्य [B1 Mobile ऐप](../../b1-mobile/giving/index.md) के ज़रिए भी दान कर सकते हैं — दान की सुविधा उसमें पहले से शामिल है

:::info
लॉग इन करने वाले सदस्य भुगतान तरीके सहेज सकते हैं, आवर्ती दान सेट कर सकते हैं, और अपना दान इतिहास देख सकते हैं। गुमनाम दान भी संभव है — इसके लिए लॉग इन की ज़रूरत नहीं।
:::

## चरण 6: निरंतर प्रबंधन

अपने दान रिकॉर्ड अद्यतन रखें और पूरे वर्ष रिपोर्ट बनाएँ।

1. नियमित रूप से (साप्ताहिक या मासिक) [Stripe लेन-देन आयात करें](../donations/stripe-import.md) ताकि आपके रिकॉर्ड अद्यतन रहें
2. फंड के अनुसार दान के रुझान और कुल राशि देखने के लिए [दान रिपोर्ट देखें](../donations/donation-reports.md)
3. अपने दानदाताओं के कर रिकॉर्ड के लिए [वर्ष-अंत दान विवरण बनाएँ](../donations/giving-statements.md)

:::tip
Stripe आयात कम से कम मासिक चलाएँ ताकि आपके रिकॉर्ड अद्यतन रहें। पूरी वर्ष-अंत प्रक्रिया के लिए [वर्ष-अंत रिपोर्ट गाइड](./year-end-reports.md) देखें।
:::

## सब हो गया!

आपका चर्च अब ऑनलाइन दान स्वीकार कर रहा है। सदस्य आपकी वेबसाइट, B1 Mobile ऐप, या किसी भी वेब ब्राउज़र वाले डिवाइस से दान कर सकते हैं। सभी दान B1 Admin में स्वचालित रूप से दर्ज होते हैं।
