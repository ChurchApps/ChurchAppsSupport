# ऑनलाइन दान सेट अप करें

<div class="article-intro">

दान निधियाँ बनाने से लेकर भुगतान प्रोसेसिंग के लिए Stripe जोड़ने और अपनी मंडली के साथ दान पेज साझा करने तक, अपने चर्च में ऑनलाइन दान स्वीकार करने के लिए आवश्यक सब कुछ यहाँ समझें। इसके बाद सदस्य आपकी वेबसाइट और मोबाइल ऐप के माध्यम से ऑनलाइन दान कर सकेंगे।

</div>

<div class="prereqs">
<h4>शुरू करने से पहले</h4>

- व्यवस्थापक पहुँच वाला B1 Admin खाता — देखें [Roles & Permissions](../people/roles-permissions.md)
- एक Stripe खाता (यदि आवश्यक हो तो [stripe.com](https://stripe.com) पर मुफ़्त में बनाएँ)

</div>

## चरण 1: दान निधियाँ बनाएँ

निधियाँ वे श्रेणियाँ हैं जिनमें दाता दान कर सकते हैं। दान स्वीकार करने से पहले आपको कम से कम एक निधि की आवश्यकता है।

अपनी दान श्रेणियाँ सेट करने के लिए [Funds](../donations/funds.md) गाइड का पालन करें:

1. अपनी सबसे आम निधियाँ बनाएँ (जैसे, "General Fund", "Building Fund", "Missions")
2. कर-कटौती योग्य निधियों को उचित रूप से चिह्नित करें — इसका असर वार्षिक दान विवरण पर पड़ता है

:::tip
आप कभी भी और निधियाँ जोड़ सकते हैं। अपनी सबसे आम दान श्रेणियों से शुरुआत करें।
:::

## चरण 2: Stripe जोड़ें

सभी भुगतान प्रोसेसिंग Stripe द्वारा संभाली जाती है। आप अपना Stripe खाता B1 Admin से जोड़ेंगे ताकि दान सीधे आपके बैंक खाते में पहुँचें।

Stripe जोड़ने के लिए [Online Giving Setup](../donations/online-giving-setup.md) गाइड का पालन करें:

1. अपने Stripe डैशबोर्ड में लॉग इन करें और अपनी Publishable Key और Secret Key प्राप्त करें
2. B1 Admin में, Settings पर जाएँ और दोनों कुंजियाँ दर्ज करें

:::warning
Stripe आपकी Secret Key केवल एक बार दिखाता है। Stripe डैशबोर्ड छोड़ने से पहले उसे कॉपी करके सहेज लें। यदि यह खो जाए, तो आपको नई कुंजी बनानी होगी।
:::

## चरण 3: अपनी वेबसाइट पर दान पेज जोड़ें

अपनी B1 वेबसाइट पर दान पेज जोड़कर दान को सुलभ बनाएँ।

दान पेज जोड़ने और इन कार्यों के लिए [Online Giving Setup](../donations/online-giving-setup.md) और [Managing Pages](../website/managing-pages.md) गाइड का पालन करें:

1. अपनी B1.church साइट में एक "Donate" टैब जोड़ें
2. आपका दान URL होगा: `https://yoursubdomain.b1.church/donate`
3. सदस्य बिना लॉग इन किए दान कर सकते हैं (सार्वजनिक पेज) या सहेजी गई भुगतान विधियों और दान इतिहास के लिए लॉग इन कर सकते हैं

## चरण 4: एक परीक्षण दान करें

अपनी मंडली को सूचित करने से पहले, सब कुछ सही काम कर रहा है यह सत्यापित करें।

1. प्रवाह को शुरू से अंत तक जाँचने के लिए एक छोटा परीक्षण दान करें
2. जाँचें कि दान B1 Admin में Donations के अंतर्गत दिखाई दे रहा है

:::tip
यदि आप बिना वास्तविक शुल्क के सत्यापित करना चाहते हैं, तो पहले Stripe का test mode उपयोग करें, फिर अपनी मंडली को सूचित करने से पहले live mode पर स्विच करें।
:::

## चरण 5: अपनी मंडली को सूचित करें

सदस्यों को बताएँ कि वे ऑनलाइन दान कर सकते हैं।

1. अपनी वेबसाइट, ईमेल न्यूज़लेटर, बुलेटिन और सोशल मीडिया के माध्यम से दान URL साझा करें
2. सदस्य [B1 App](../../b1-church/giving/index.md) के माध्यम से भी दान कर सकते हैं — दान सुविधा उसमें पहले से शामिल है

:::info
जो सदस्य लॉग इन करते हैं वे भुगतान विधियाँ सहेज सकते हैं, आवर्ती दान सेट कर सकते हैं और अपना दान इतिहास देख सकते हैं। गुमनाम दान भी संभव है — इसके लिए लॉग इन करने की आवश्यकता नहीं है।
:::

## चरण 6: निरंतर प्रबंधन

अपने दान रिकॉर्ड अद्यतन रखें और पूरे वर्ष रिपोर्ट तैयार करें।

1. अपने रिकॉर्ड अद्यतन रखने के लिए नियमित रूप से (साप्ताहिक या मासिक) [Stripe लेनदेन आयात करें](../donations/stripe-import.md)
2. निधि के अनुसार दान के रुझान और कुल राशि देखने के लिए [दान रिपोर्ट देखें](../donations/donation-reports.md)
3. अपने दाताओं के कर रिकॉर्ड के लिए [वार्षिक दान विवरण तैयार करें](../donations/giving-statements.md)

:::tip
यह सुनिश्चित करने के लिए कि आपके रिकॉर्ड अद्यतन रहें, Stripe आयात कम से कम मासिक चलाएँ। पूरी वार्षिक प्रक्रिया के लिए [Year-End Reports Guide](./year-end-reports.md) देखें।
:::

## आप तैयार हैं!

आपका चर्च अब ऑनलाइन दान स्वीकार कर रहा है। सदस्य आपकी वेबसाइट, B1 App, या किसी भी वेब ब्राउज़र वाले उपकरण के माध्यम से दान कर सकते हैं। सभी दान अपने आप B1 Admin में दर्ज होते हैं।
