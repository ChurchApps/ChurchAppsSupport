# जन्मदिन और वर्षगांठ सूचियाँ

<div class="article-intro">

किसी दिए गए महीने में birthday या anniversary वाले सभी लोगों की एक सूची चाहिए — bulletin, announcements, या cards के लिए? People search आपकी congregation को **Birth Month** और **Anniversary Month** के अनुसार filter कर सकता है और dates को सीधे results में दिखाता है।

</div>

<div class="prereqs">
<h4>शुरुआत करने से पहले</h4>

- सुनिश्चित करें कि birth dates (और anniversaries) हर व्यक्ति के profile पर enter किए गए हैं। [लोगों को जोड़ना](../people/adding-people.md) देखें।
- आपको People को देखने की अनुमति चाहिए। [Roles & Permissions](../settings/roles-permissions.md) देखें।

</div>

## एक महीने के लिए जन्मदिन सूची प्राप्त करना

1. [Jump menu](../introduction.md#getting-around-with-the-jump-menu) खोलें (B1 Admin के ऊपरी-बाएं में खोज बार), **People** को expand करें, और **People** पर क्लिक करें।
2. Search box के नीचे, **Advanced** पर क्लिक करें।
3. **Demographics** section को expand करें और **Birth Month** को check करें, फिर महीने को चुनें।
4. Search को run करें — जिन सभी लोगों का जन्मदिन उस महीने में है वे results में दिखाई देते हैं।
5. Dates को देखने के लिए, results के शीर्ष दाईं ओर **columns icon** पर क्लिक करें और **Birthday** column को enable करें। यदि आप वहां sort या print करना पसंद करते हैं तो list को spreadsheet के रूप में download करने के लिए **Export** का उपयोग करें।

## एक वर्षगांठ सूची प्राप्त करना

समान steps — **Demographics** section में, **Anniversary Month** को instead (या साथ ही) check करें, महीने को चुनें, और results में **Anniversary** column को enable करें।

## व्यावहारिक उपयोग

- **Weekly bulletins** -- Current महीने की सूची को run करें और names को सीधे bulletin में पढ़ें।
- **Birthday और anniversary cards** -- महीने की सूची को export करें और इसे अपनी card-writing team को दें।
- **Milestones** -- Milestone birthdays को खोजने के लिए **Age** filter के साथ combine करें।

:::tip
दोनों lists हर व्यक्ति के profile पर birth date और anniversary fields से आते हैं — अगर कोई missing है, तो उनके profile को केवल date को add करने की आवश्यकता है।
:::

:::info
B1 Admin के पहले versions में birthdays के लिए एक अलग Reports page था। वह page retire किया गया है — ऊपर दिए गए People search filters current तरीका है, और वे anniversaries को भी cover करते हैं।
:::
