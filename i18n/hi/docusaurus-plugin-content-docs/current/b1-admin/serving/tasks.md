# कार्य

<div class="article-intro">

कार्य आपको आपके चर्च में लोगों या समूहों को action items असाइन करने देता है। चाहे यह एक one-time to-do हो या एक recurring responsibility, कार्य आपको ट्रैक करने में मदद करते हैं कि क्या किया जाना चाहिए और कौन responsible है ताकि कुछ भी overlooked न हो।

</div>

<div class="prereqs">
<h4>शुरुआत से पहले</h4>

- सुनिश्चित करें कि जिन लोगों या [समूहों](../groups/creating-groups.md) को आप कार्य असाइन करना चाहते हैं वे B1 Admin में मौजूद हैं
- **Serving** अनुभाग पर नेविगेट करें और कार्य देखने के लिए **My Work** खोलें

</div>

## कार्य देखना

**Serving** पर नेविगेट करें और **My Work** खोलें। आप अपने खुले कार्यों की एक सूची देखेंगे। प्रत्येक कार्य अपना शीर्षक, assignee, और status दिखाता है।

:::tip
Default रूप से, केवल खुले कार्य दिखाई देते हैं। **Show Closed** को toggle करें पूर्ण किए गए कार्यों को भी देखने के लिए।
:::

## कार्य बनाना

1. कार्य पृष्ठ पर, **Add Task** पर क्लिक करें।
2. कार्य के लिए एक **title** दर्ज करें।
3. **Assign To** बॉक्स पर क्लिक करें और किसी व्यक्ति का नाम type करें, या **Group** पर switch करें और एक समूह का नाम type करें।
4. **Search** पर क्लिक करें और परिणामों से व्यक्ति या समूह को चुनें।
5. असाइनी के लिए किसी भी विवरण या निर्देशों के साथ एक **note** जोड़ें।
6. **Save** पर क्लिक करें।

कार्य अब कार्य सूची में दिखाई देगा और assignee के dashboard और mobile app पर दिखाई देगा।

## कार्य का प्रबंधन

किसी भी कार्य पर क्लिक करें इसके detail page को खोलने के लिए। यहां से आप:

- **स्थिति बदलें** -- status dropdown का उपयोग करके **Open** और **Closed** के बीच switch करें।
- **कार्य को पुनः असाइन करें** -- assignee को एक अलग व्यक्ति या समूह में update करें।
- **नोट्स जोड़ें** -- assignee के लिए अतिरिक्त जानकारी या updates शामिल करें।
- **शीर्षक को संपादित करें** -- आवश्यकतानुसार कार्य शीर्षक को update करें।

## कार्य जीवन चक्र

1. एक नया कार्य **Open** की स्थिति के साथ शुरू होता है।
2. assignee को एक notification मिलता है और वह अपने dashboard, **Serving > My Work**, या mobile app से कार्य को देख सकता है।
3. एक बार जब काम complete हो जाता है, तो assignee (या एक admin) स्थिति को **Closed** में बदल देता है।
4. बंद किए गए कार्य default view से removed हो जाते हैं लेकिन **Show Closed** को enable करके अभी भी access किए जा सकते हैं।

:::info
B1 Admin अब एक schedule पर recurring कार्य create नहीं करता है। लोगों के साथ repeating follow-up के लिए, एक [workflow](./workflows.md) का उपयोग करें एक [schedule trigger](./workflows.md#schedule-triggers) के साथ।
:::

:::tip
जब आपको कई लोगों को same set of stages के माध्यम से move करना होता है -- जैसे new-visitor follow-up या एक membership process -- [Workflows](./workflows.md) का उपयोग करें। Workflows कार्यों को एक drag-and-drop board पर कार्ड में बदल देते हैं steps, due dates, और routing के साथ।
:::

:::info
कुछ कार्य B1 के अन्य भागों द्वारा स्वचालित रूप से बनाए जाते हैं और एक special review card को खोलते हैं standard note/reassign view के बजाय -- [group join requests](../groups/group-join-requests.md#approving-from-the-tasks-page), [profile change requests](../profile/approving-profile-changes.md), और [account deletion requests](../profile/account-deletion.md) सभी इसी तरीके से काम करते हैं।
:::

## अगले कदम

- लोगों को एक multi-step process के माध्यम से [Workflows](./workflows.md) के साथ move करें
- लोगों को repeatable processes के माध्यम से स्वचालित रूप से move करने के लिए [Workflows](./workflows.md) का उपयोग करें
- service preparation action items को ट्रैक करने के लिए [Service Plans](./plans.md) के साथ कार्यों का उपयोग करें
