# चेक-इन लेबल डिज़ाइनर

<div class="article-intro">

Label Designer आपको नाम टैग और पिकअप स्लिप टेम्पलेट बनाने और कस्टमाइज़ करने देता है जो परिवारों के अपने बच्चों को चेक-इन करते समय प्रिंट होते हैं। आप नियंत्रित कर सकते हैं कि प्रत्येक लेबल पर कौन सी जानकारी दिखाई देती है, यह कहां स्थित है, और यह कैसा दिखता है।

</div>

<div class="prereqs">
<h4>शुरू करने से पहले</h4>

- [Attendance](setup) को सेट अप करें और कम से कम एक सेवा समय को चेक-इन सक्षम के साथ कॉन्फ़िगर करें
- [Check-In](check-in) को सेट अप करें ताकि लेबल प्रिंट हो रहे हों
- आपको Attendance अनुभाग तक प्रशासनिक पहुंच की आवश्यकता है

</div>

## Label Designer खोलना

B1 Admin में, [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (शीर्ष-बाएं खोज बार) खोलें, **Mobile** विस्तृत करें, और **B1 CheckIn** पर क्लिक करें। फिर Check-in Labels कार्ड पर **Design Labels** बटन पर क्लिक करें। आप अपने सहेजे गए लेबल टेम्पलेट की एक सूची देखेंगे, प्रकार द्वारा अलग: **Nametag** और **Pickup Slip**।

## लेबल प्रकार

- **Nametag** — बच्चे पर प्रिंट और संलग्न किया जाता है। आमतौर पर बच्चे का नाम, उनकी classroom/session, और एक सुरक्षा कोड शामिल होता है।
- **Pickup Slip** — माता-पिता या अभिभावक को दिया जाता है। आमतौर पर सुरक्षा कोड और उन बच्चों की सूची शामिल होती है जिन्हें उन्होंने चेक-इन किया।

B1 आपको एक डिफ़ॉल्ट nametag और एक डिफ़ॉल्ट pickup slip टेम्पलेट से शुरू करता है जो मानक 3.5 × 1.1 इंच थर्मल लेबल के लिए आकार में है।

## एक लेबल टेम्पलेट बनाना

1. **Add** पर क्लिक करें और मेनू से एक शुरुआती बिंदु चुनें: **Nametag 3.5" x 1.1"**, **Pickup Slip 3.5" x 1.1"**, या **Blank**।
2. एक नया टेम्पलेट लेबल editor में खुल जाता है।

### लेबल Editor

editor लेबल का एक scaled preview दिखाता है कॉन्फ़िगर किए गए आकार पर। बाईं ओर के पैनल पर आप कॉन्फ़िगर कर सकते हैं:

- **Name** — टेम्पलेट नाम (केवल आपके संदर्भ के लिए)
- **Label Type** — Nametag या Pickup Slip
- **Width / Height** — लेबल आकार इंच में

### Blocks जोड़ना

एक लेबल blocks से बनाया जाता है — लेबल कैनवास पर स्थित content के अलग-अलग टुकड़े। एक नया block सम्मिलित करने के लिए **Add Block** पर क्लिक करें और इसके प्रकार को चुनें:

- **Field** — print time पर एक डेटा value को खींचता है:
  - `person.displayName` — व्यक्ति का पूरा नाम
  - `sessions` — सेवा/classroom जिसे वे चेक-इन करते हैं
  - `securityCode` — यादृच्छिक रूप से उत्पन्न pickup सुरक्षा कोड
  - `children` — बच्चों की सूची (pickup slips के लिए)
  - `person.nametagNotes` — व्यक्ति के रिकॉर्ड पर कोई विशेष नोट
  - `person.isBirthdayWeek` — true यदि व्यक्ति का जन्मदिन (महीना और दिन) चेक-इन के आस-पास 3 दिनों के भीतर है
  - `campus` — कैंपस का नाम
- **Text** — static text जिसे आप type करते हैं (headings, labels, या instructions के लिए)
- **Barcode** — एक barcode जो सुरक्षा कोड को एन्कोड करता है

### Blocks को स्थापित करना

प्रत्येक block में **X**, **Y**, **Width**, और **Height** फ़ील्ड हैं जो लेबल कैनवास के प्रतिशत के रूप में व्यक्त किए जाते हैं (0–100)। content को precisely स्थापित करने के लिए इन्हें समायोजित करें। आप निम्नलिखित भी सेट कर सकते हैं:

- **Font Size** — पाठ आकार points में
- **Bold** — bold text को toggle करें
- **Align** — बाएं, केंद्र, या दाएं पाठ alignment
- **Condition** — यदि एक field खाली है तो block को optionally hide करें (उदाहरण के लिए, केवल nametagNotes दिखाएं यदि इसका कोई value है)। यह `person.isBirthdayWeek` के साथ भी काम करता है ताकि एक birthday graphic या text केवल nametags पर दिखाई दे जिनका जन्मदिन चेक-इन के कुछ दिन के भीतर है।

### सहेजना

टेम्पलेट को save करने के लिए **Save** पर क्लिक करें। अपडेट किया गया टेम्पलेट अगली बार B1 Checkin में labels प्रिंट किए जाते समय उपयोग किया जाएगा।

## टेम्पलेट को Reorder करना

यदि आपके पास कई nametag या pickup slip टेम्पलेट हैं, तो B1 Checkin डिफ़ॉल्ट रूप से सूची में पहले टेम्पलेट का उपयोग करेगा। उन्हें reorder करने के लिए टेम्पलेट को ड्रैग करें।

## एक टेम्पलेट को हटाना

किसी भी टेम्पलेट पंक्ति पर delete icon पर क्लिक करें और confirm करें। प्रकार का अंतिम टेम्पलेट हटाने से डिफ़ॉल्ट built-in टेम्पलेट restore होता है।

:::tip
अपने अगली सेवा से पहले टेम्पलेट को edit करने के बाद एक test print करें ताकि यह सुनिश्चित हो सके कि layout सही दिखता है।
:::
