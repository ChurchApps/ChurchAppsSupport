# Curated Calendar

<div class="article-intro">

Curated calendar कई groups के events को एक एकीकृत calendar view में इकट्ठा करता है। यह पूरे church के लिए एक calendar बनाने के लिए आदर्श है, जो आपकी सभी ministries और groups में होने वाली हर चीज़ एक ही जगह दिखाता है।

</div>

<div class="prereqs">
<h4>शुरू करने से पहले</h4>

- उन [groups](../groups/creating-groups.md) को सेट करें जिनके events आप शामिल करना चाहते हैं
- सुनिश्चित करें कि group leaders ने अपने-अपने groups में events जोड़े हैं
- [Creating Calendars](creating-calendars) की मूल बातों से परिचित हो जाएं

</div>

## Curated Calendar बनाना

1. B1 Admin में, [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ऊपर-बाएं कोने का search bar) खोलें, **Calendars** को विस्तृत करें, और **Calendars** पर क्लिक करें।
2. नया curated calendar बनाने के लिए **Add Calendar** पर क्लिक करें।
3. अपने calendar को एक **नाम** दें (उदाहरण के लिए, "Church Events" या "This Week at Our Church")।
4. सहेजने के लिए **Create** पर क्लिक करें।

## अपने Calendar में Groups जोड़ना

1. अपने नए calendar को खोलने के लिए उस पर **Manage Events** पर क्लिक करें।
2. calendar के ऊपर **Add Group** पर क्लिक करें। आपके जोड़े गए groups पेज के बाईं ओर **Groups in Calendar** सूची में दिखते हैं।
3. ड्रॉपडाउन मेनू से एक group चुनें।
4. चुनें कि उस group से **सभी events** जोड़ने हैं या केवल **विशिष्ट events**।
5. **Save** पर क्लिक करें।
6. जितने भी groups शामिल करना चाहते हैं, इस प्रक्रिया को दोहराएं।

:::tip
अपने सभी सक्रिय ministry groups जोड़ें ताकि एक व्यापक calendar बने, जो आपकी congregation को हर हफ्ते church में क्या हो रहा है, इसकी पूरी तस्वीर दे।
:::

## अपना Calendar साझा करना

एक बार आपका curated calendar सेट हो जाए, तो आप उसे कई तरीकों से साझा कर सकते हैं:

- **अपनी website पर embed करें** -- किसी page में **Calendar** element जोड़ें, ताकि calendar month grid के रूप में या आने वाले events की tiles के रूप में दिखे, वैकल्पिक रूप से केवल एक tag वाले events तक सीमित। हर event आपकी site पर अपने page से लिंक होता है। देखें [Using the Calendar element](../website/page-editor.md#using-the-calendar-element).
- **ICS के रूप में subscribe करें** -- ICS लिंक कॉपी करने के लिए **Subscribe** पर क्लिक करें। आपकी congregation इस लिंक को Google Calendar, Apple Calendar, Outlook, या किसी अन्य calendar app में पेस्ट करके सिंक में रह सकती है।
- **ICS file download करें** -- calendar file download करें ताकि उसे किसी calendar application में import किया जा सके।

:::info
जब group leaders अपने [groups](../groups/creating-groups.md) में नए events जोड़ते हैं, तो वे events अपने-आप आपके curated calendar में दिखते हैं। हर नया event जुड़ने पर आपको curated calendar मैन्युअली अपडेट करने की ज़रूरत नहीं है।
:::

:::note निजी events
आपकी website पर curated calendar और उसकी ICS subscription में केवल **सार्वजनिक** events दिखते हैं। B1 Admin में, जो staff content edit कर सकते हैं, वे group के **निजी** events भी curated calendar पर देखते हैं, ताकि calendar बनाते समय आप पूरा schedule देख सकें।
:::
