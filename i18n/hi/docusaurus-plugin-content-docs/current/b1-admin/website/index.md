# वेबसाइट

<div class="article-intro">

B1 Admin में Website अनुभाग आपके चर्च के लिए एक पूर्ण-विशेषताओं वाला वेबसाइट बिल्डर देता है। आप पृष्ठ बना सकते हैं, अपनी साइट का रूप और अनुभव अनुकूलित कर सकते हैं, मीडिया फ़ाइलें प्रबंधित कर सकते हैं, और इवेंट कैलेंडर प्रकाशित कर सकते हैं -- और यह सब बिना कोई कोड लिखे।

</div>

## आप क्या कर सकते हैं

Website बिल्डर इन मुख्य क्षेत्रों में व्यवस्थित है:

### Pages

अपनी चर्च वेबसाइट के सभी पृष्ठ बनाएं और प्रबंधित करें। **Pages** तालिका हर पृष्ठ को सूचीबद्ध करती है -- सिस्टम द्वारा स्वतः बनाए गए पृष्ठों पर **Generated** बैज होता है, और बाकी आपके बनाए कस्टम पृष्ठ हैं। आप नए कस्टम पृष्ठ जोड़ सकते हैं, मौजूदा पृष्ठ संपादित कर सकते हैं, या स्वतः-जनित पृष्ठों को कस्टम पृष्ठों में बदल सकते हैं ताकि उनकी सामग्री पर पूरा नियंत्रण मिले।

आपके नेविगेशन लिंक एक ट्री संरचना में दिखाए जाते हैं। आगंतुकों को जिस सटीक क्रम और पदानुक्रम में दिखाना चाहते हैं, उसके लिए आप ड्रैग-एंड-ड्रॉप से लिंक का क्रम बदल सकते हैं।

### Blog

अपनी साइट पर `/blog` पर समाचार, अपडेट और भक्ति-संदेश ब्लॉग पोस्ट के रूप में प्रकाशित करें, RSS फ़ीड के साथ। [Blog](blog) गाइड देखें।

### Blocks

पुन: उपयोग किए जा सकने वाले सामग्री घटक बनाएं जिन्हें आप कई पृष्ठों पर रख सकें। जब आपके पास कॉल-टू-एक्शन, घोषणा बैनर, या संपर्क अनुभाग जैसी सामग्री हो जो एक से अधिक जगह दिखती है, तो Blocks समय बचाते हैं। किसी block को एक बार अपडेट करें और परिवर्तन हर उस जगह लागू हो जाता है जहाँ वह उपयोग हुआ है।

### Appearance

अपनी वेबसाइट की थीम, रंग, फ़ॉन्ट, लोगो और स्पेसिंग अनुकूलित करें। त्वरित शुरुआत के लिए पूर्व-निर्मित स्टाइल थीम लागू करें, या कलर पैलेट एडिटर, टाइपोग्राफ़ी सेटिंग्स और कस्टम CSS से हर विवरण बारीकी से समायोजित करें। पूरे विवरण के लिए [Appearance](appearance) गाइड देखें।

### Files

अपनी सभी मीडिया संपत्तियाँ -- छवियाँ, दस्तावेज़ और अन्य फ़ाइलें -- एक केंद्रीय स्थान पर अपलोड और प्रबंधित करें, और अपनी साइट पर कहीं भी उपयोग के लिए फ़ाइल लिंक कॉपी करें। अधिक जानकारी के लिए [Files](files) देखें।

### Calendars

अपनी वेबसाइट पर इवेंट कैलेंडर प्रकाशित करें ताकि आगंतुक देख सकें कि आपके चर्च में क्या हो रहा है। चुने हुए कैलेंडर बनाएं जो कई समूहों के इवेंट को एक ही दृश्य में लाते हैं। Calendars का B1 Admin मेनू में अपना **Calendars** आइटम है, जो **Website** से अलग है।

:::tip
यदि आप पहली बार अपनी वेबसाइट सेट कर रहे हैं तो [Initial Setup](initial-setup) से शुरू करें। यह आपको डोमेन सेटअप, पहला पृष्ठ बनाने, और साइट की दिखावट कॉन्फ़िगर करने में मार्गदर्शन करता है।
:::
