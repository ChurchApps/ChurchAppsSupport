# वेबसाइट

<div class="article-intro">

B1 Admin में website सेक्शन आपको अपनी चर्च के लिए एक full-featured website builder देता है। आप पृष्ठ बना सकते हैं, अपनी site के look और feel को customize कर सकते हैं, media files को manage कर सकते हैं, और event calendars को publish कर सकते हैं -- सब कुछ बिना कोई code लिखे।

</div>

## आप क्या कर सकते हैं

Website builder पांच मुख्य क्षेत्रों में organized है:

### Pages

अपनी चर्च वेबसाइट पर सभी पृष्ठों को create और manage करें। **Pages** table हर पृष्ठ को अपनी status के साथ दिखाता है -- **Generated** (system द्वारा स्वचालित रूप से बनाया गया) या **Custom** (आपके द्वारा बनाया गया)। आप नए custom pages जोड़ सकते हैं, existing ones को edit कर सकते हैं, या auto-generated pages को custom pages में convert कर सकते हैं full control के लिए।

आपके navigation links एक tree structure में displayed होते हैं। आप drag-and-drop का उपयोग करके links को reorder कर सकते हैं वह exact hierarchy और order set करने के लिए जो visitors देखेंगे।

### Blocks

Reusable content components बनाएं जिन्हें आप कई pages पर रख सकते हैं। Blocks आपके समय को बचाते हैं जब आपके पास content होता है जैसे एक call-to-action, announcement banner, या contact section जो एक से अधिक जगहों पर दिखाई देता है। एक block को एक बार update करें और परिवर्तन हर जगह जहां इसका उपयोग किया जाता है लागू होता है।

### Appearance

अपनी वेबसाइट के theme, colors, fonts, logo, और spacing को customize करें। आप quick start के लिए pre-built style themes apply कर सकते हैं या color palette editor, typography settings, और custom CSS के साथ हर विवरण को fine-tune कर सकते हैं। पूरे विवरण के लिए [Appearance](appearance) guide देखें।

### Files

सभी media assets को upload और organize करें -- images, documents, और अन्य files -- एक central location में। चीजों को tidy रखने के लिए folders का उपयोग करें और अपनी site पर कहीं भी उपयोग के लिए file URLs को copy करें। अधिक जानकारी के लिए [Files](files) देखें।

### Calendars

अपनी वेबसाइट पर event calendars publish करें ताकि visitors देख सकें कि आपकी चर्च में क्या हो रहा है। Curated calendars बनाएं जो कई groups से events को एक single view में pull करते हैं।

:::tip
यदि आप पहली बार अपनी वेबसाइट को configure कर रहे हैं तो [Initial Setup](initial-setup) के साथ शुरुआत करें। यह आपको domain setup, अपने पहले पृष्ठ को बनाने, और अपनी site के appearance को configuring के through चलाता है।
:::
