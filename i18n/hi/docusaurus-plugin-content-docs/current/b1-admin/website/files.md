# फाइलें

<div class="article-intro">

Files पृष्ठ आपकी चर्च वेबसाइट पर उपयोग की जाने वाली सभी मीडिया और दस्तावेजों के लिए केंद्रीय भंडार है। यहाँ से आप हर छवि, दस्तावेज़ और मीडिया फ़ाइल को अपलोड, व्यवस्थित, ब्राउज़ और प्रबंधित कर सकते हैं जिसकी आपकी साइट को आवश्यकता है।

</div>

<div class="prereqs">
<h4>शुरू करने से पहले</h4>

- अपनी वेबसाइट के लिए [प्रारंभिक सेटअप](initial-setup) पूरा करें
- तेज़ पृष्ठ लोड समय के लिए अपलोड करने से पहले छवियों को अनुकूलित करें
- अपनी फ़ाइलों को सामान्य वेब प्रारूपों में तैयार करें (PNG, JPG, PDF, आदि)

</div>

## फाइलें अपलोड करना

1. B1 Admin में, [Jump menu](../introduction.md#getting-around-with-the-jump-menu) खोलें (ऊपर-बाएं में खोज बार), **Website** को विस्तृत करें, और **Files** पर क्लिक करें।
2. अपलोड क्षेत्र पर सीधे फ़ाइलों को ड्रैग और ड्रॉप करें, या अपने कंप्यूटर को ब्राउज़ करने के लिए अपलोड बटन पर क्लिक करें।
3. आपकी फ़ाइलें अपलोड होंगी और तुरंत फ़ाइल लाइब्रेरी में दिखाई देंगी।

:::tip
सर्वोत्तम परिणामों के लिए, अपलोड करने से पहले छवियों को अनुकूलित करें। छोटी फ़ाइल आकार आपकी वेबसाइट को आगंतुकों के लिए तेज़ी से लोड करने में मदद करती है। TinyPNG या Squoosh जैसे उपकरण ध्यान देने योग्य गुणवत्ता हानि के बिना छवियों को संपीड़ित कर सकते हैं।
:::

## फोल्डरों के साथ व्यवस्थित करना

1. संबंधित फ़ाइलों को एक साथ समूहित करने के लिए फ़ोल्डर बनाएं -- उदाहरण के लिए, "Sermon Graphics," "Event Banners," या "Staff Photos."
2. फ़ोल्डरों के बीच फ़ाइलों को स्थानांतरित करें अपनी लाइब्रेरी को जैसे-जैसे बढ़ता है, साफ़ रखने के लिए।
3. स्पष्ट, वर्णनात्मक फ़ोल्डर नाम का उपयोग करें ताकि आपकी टीम फ़ाइलें जल्दी से खोज सके।

## ब्राउज़िंग और खोज

- अपनी अपलोड की गई सभी फ़ाइलों के थंबनेल देखने के लिए फ़ाइल लाइब्रेरी के माध्यम से स्क्रॉल करें।
- जब आपकी लाइब्रेरी बड़ी हो जाए तो नाम के आधार पर फ़ाइलें खोजने के लिए **search** फ़ंक्शन का उपयोग करें।
- किसी भी फ़ाइल पर क्लिक करें इसके विवरण देखने के लिए, फ़ाइल नाम, आकार और URL सहित।

## अपनी वेबसाइट पर फाइलें का उपयोग करना

1. किसी फ़ाइल पर क्लिक करें इसके विवरण देखने के लिए।
2. **Copy the file URL** इसे अपनी वेबसाइट पृष्ठों में उपयोग करने के लिए। आप इस URL को छवि तत्वों, डाउनलोड लिंक, या किसी अन्य जगह पेस्ट कर सकते हैं जो एक फ़ाइल URL को स्वीकार करता है।
3. आप यहाँ अपलोड की गई फ़ाइलें आपकी सभी वेबसाइट पृष्ठों और सामग्री ब्लॉक्स में उपलोध्य हैं।

:::info
[Pages प्रबंधित करें](managing-pages) में पृष्ठ बनाते समय, आप यहाँ अपलोड की गई किसी भी फ़ाइल को इसके URL के द्वारा संदर्भित कर सकते हैं। यह सभी आपकी मीडिया को एक केंद्रीय स्थान में संगठित रखता है।
:::

## फाइलें हटाना

1. वह फ़ाइल चुनें जिसे आप हटाना चाहते हैं।
2. इसे अपनी लाइब्रेरी से स्थायी रूप से हटाने के लिए **Delete** बटन पर क्लिक करें।
3. सुनिश्चित करें कि फ़ाइल किसी पृष्ठ पर वर्तमान में उपयोग में नहीं है इसे हटाने से पहले, क्योंकि यह किसी भी लिंक या छवि को तोड़ेगा जो इसे संदर्भित करते हैं।

:::warning
हटाई गई फ़ाइलें पुनः प्राप्त नहीं की जा सकती। कोई फ़ाइल हटाने से पहले दोहराई जाँच करें कि वह किसी पृष्ठ पर अब उपयोग में नहीं है।
:::
