# ईमेल टेम्पलेट्स

<div class="article-intro">

ईमेल टेम्पलेट्स आपको पुन: उपयोग योग्य ईमेल सामग्री सहेजने देते हैं -- एक स्वागत संदेश, एक घटना reminder, एक दान धन्यवाद -- ताकि आप (या एक [workflow](../serving/workflows.md)) इसे एक क्लिक में भेज सकें बजाय हर बार इसे शुरू से लिखने के।

</div>

<div class="prereqs">
<h4>शुरुआत करने से पहले</h4>

- आपको B1 Admin में सेटिंग्स क्षेत्र तक पहुंच की आवश्यकता है।

</div>

## ईमेल टेम्पलेट्स तक पहुंचना

1. B1 Admin में, शीर्ष-बाएं कोने में **section menu** खोलें (छोटे तीर के साथ section का नाम) और **Settings** चुनें।
2. **Email Templates** पर क्लिक करें।
3. आप मौजूदा टेम्पलेट्स की एक सूची देखेंगे जिनमें उनका विषय, श्रेणी और अंतिम संशोधित तारीख दिखाई देगी।

## एक टेम्पलेट बनाना

1. **New Template** पर क्लिक करें।
2. एक **Template Name** दर्ज करें इसे सूची में पहचानने के लिए, और एक **Category** चुनें (General, Events, Groups, Giving, या Welcome) अपने टेम्पलेट्स को संगठित करने में मदद के लिए।
3. **Subject** लाइन दर्ज करें।
4. **Body** को rich text editor का उपयोग करके लिखें।
5. **Save** पर क्लिक करें।

## Merge फील्ड्स

विषय या Body के ऊपर एक merge field chip पर क्लिक करें इसे अपने cursor पर insert करने के लिए। जब ईमेल भेजा जाता है, तो प्रत्येक merge field को प्राप्तकर्ता की वास्तविक जानकारी से प्रतिस्थापित किया जाता है:

- `{{firstName}}`, `{{lastName}}`, `{{displayName}}` -- प्राप्तकर्ता का नाम
- `{{email}}` -- प्राप्तकर्ता का ईमेल पता
- `{{churchName}}` -- आपकी चर्च का नाम

## एक टेम्पलेट का preview करना

**Preview** पर क्लिक करें देखने के लिए कि विषय और body कैसे दिखेंगे merge फील्ड्स के लिए नमूना डेटा भरे हुए, save या send करने से पहले।

## एक टेम्पलेट का उपयोग करना

Saved टेम्पलेट्स लोगों या एक समूह को ईमेल लिखते समय select करने के लिए उपलब्ध हैं, और [Workflows](../serving/workflows.md) में एक action के रूप में।

## संपादित करना और हटाना

टेम्पलेट को अपडेट करने के लिए इसके आगे **Edit** icon पर क्लिक करें, या इसे स्थायी रूप से हटाने के लिए **Delete** icon पर क्लिक करें।
