# कनेक्टेड सेवाएँ

<div class="article-intro">

B1 को किसी अन्य चर्च-तकनीक टूल से जोड़ने का सबसे तेज़ तरीका आम तौर पर Zapier या Make की एक रेसिपी होता है। इसके लिए B1 में नए इंफ़्रास्ट्रक्चर की ज़रूरत नहीं होती, और वर्कफ़्लो तीसरा पक्ष होस्ट करता है। यह पेज उन सेवाओं की चुनी हुई सूची है जिनकी वायरिंग आज संभव होने की हमने पुष्टि की है, और हर एक के लिए एक छोटी, कॉपी-पेस्ट करने योग्य सेटअप गाइड है।

</div>

## इन सभी में क्या समान है

1. **B1 की ओर की वायरिंग एक जैसी है** — **B1Admin → Settings → Developer → API Keys** में सही स्कोप के साथ एक API key बनाएँ, फिर या तो ब्रिज को ट्रिगर के लिए webhook रजिस्टर करने दें (Zapier / Make यह अपने-आप करते हैं, इसके लिए `settings:write` चाहिए) या किसी डाउनस्ट्रीम एक्शन से B1 के REST endpoints कॉल करें।
2. **ब्रिज का बिल आपको आता है, हमें नहीं।** ChurchApps मुफ़्त है; Zapier और Make दोनों में मुफ़्त टियर हैं जो कुछ रेसिपी को कवर करते हैं।
3. **आप बिना लाइव गए वायरिंग का परीक्षण कर सकते हैं।** दोनों ब्रिज में एक "Test step" बटन है जो B1 के विरुद्ध ट्रिगर एक बार चलाता है और रेसिपी चालू करने से पहले आपको डेटा का स्वरूप दिखाता है।

## ब्रिज चुनना

- **Zapier** अधिक सुविधाजनक है और इसका ऐप कैटलॉग बड़ा है। लागत कोई समस्या न हो तो इसे डिफ़ॉल्ट के रूप में उपयोग करें।
- **Make** बड़े पैमाने पर सस्ता है और इसमें अधिक लचीला रूटिंग/फ़िल्टर लॉजिक है। जब किसी एक वर्कफ़्लो में फ़ैन-आउट, शर्तें, या कई चरण हों तो इसका उपयोग करें।
- **Webhooks by Zapier** (Mobile Message दस्तावेज़ में उपयोग) एक सामान्य एडैप्टर है, जो Zap से किसी भी HTTP endpoint पर POST करने देता है, जब गंतव्य कोई प्रथम-श्रेणी Zapier ऐप न हो।

यदि इस सूची में न दिखने वाली कोई चीज़ चाहिए, तो B1 का [REST API](/docs/developer/api) और [webhooks](/docs/developer/api/webhooks) खुले हैं। आप [`@churchapps/integration-sdk`](https://www.npmjs.com/package/@churchapps/integration-sdk) से कुछ घंटों में एक-बार का ब्रिज बना सकते हैं।

## यहाँ क्या नहीं है (और क्यों)

Tithe.ly, Pushpay, Vanco, PastorsLine, Gloo, Notebird, KidCheck, MinistrySafe जैसे कई लोकप्रिय चर्च-तकनीक टूल के पास आज कोई प्रकाशित Zapier ऐप या Make मॉड्यूल नहीं है। उनके अपने API हैं, लेकिन उन्हें B1 से जोड़ना एक कस्टम-कोड का काम है, रेसिपी का नहीं, इसलिए वे इस सूची में फ़िट नहीं होते। यदि कोई विक्रेता Zapier ऐप या Make मॉड्यूल जोड़ता है, तो हम दस्तावेज़ जोड़ देंगे।

हमने जानबूझकर Planning Center-Services-विशिष्ट टूल (संगीत, प्रस्तुति), प्रतिस्पर्धी चर्च प्रबंधन सॉफ़्टवेयर (ChMS) उत्पाद, माइग्रेशन सलाहकार, और केवल PCO-विशिष्ट डेटा साफ़ करने वाले टूल को छोड़ा है। इनमें से किसी का भी B1 में उपयोगी वायरिंग मार्ग नहीं है।
