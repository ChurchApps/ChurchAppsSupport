# Claude

<div class="article-intro">

Claude से अपने चर्च के बारे में सादी भाषा में पूछें, और वह आपके B1 डेटा से जवाब देगा -- जिसमें आपके FreePlay पाठ और कक्षाएँ भी शामिल हैं। *"रविवार को कितने पहली बार आने वाले आगंतुक आए?"* या *"इस महीने कौन किसी छोटे समूह में शामिल हुआ?"* जैसे सवाल पूछें -- या उसे कुछ करने को कहें, जैसे *"हमारी वेबसाइट पर Events नामक एक नया पृष्ठ जोड़ें।"* सेटअप में 3 मिनट से कम लगते हैं और इंस्टॉल करने के लिए किसी तकनीकी कौशल या सॉफ़्टवेयर की ज़रूरत नहीं है।

</div>

<div class="prereqs">
<h4>आपको क्या चाहिए</h4>

- **एक Claude खाता।** **मुफ़्त योजना चलती है** -- इसे आज़माने का अच्छा तरीका है। हालाँकि, मुफ़्त खातों की दैनिक संदेश सीमा होती है, और B1 में जानकारी खोजने में संदेश जल्दी खर्च होते हैं, इसलिए यदि आप इसे नियमित रूप से उपयोग करते हैं, तो हम **Claude Pro** (लगभग $20/माह) की सलाह देते हैं।
- **आपका B1 लॉगिन** -- वही जो आप B1 Admin के लिए उपयोग करते हैं।

</div>

:::tip अनुशंसित -- आज़माने के लिए मुफ़्त
Claude B1 को AI से जोड़ने का सबसे आसान तरीका है, और यह Claude की **मुफ़्त योजना** पर काम करता है -- किसी भी चीज़ के लिए भुगतान करने से पहले आपके चर्च के इसे आज़माने का एक बेहतरीन तरीका।
:::

जोड़ने के दो तरीके हैं। **विकल्प 1 सबसे आसान है** -- कोई key नहीं और कुछ भी इंस्टॉल नहीं करना।

## विकल्प 1 -- B1 से साइन इन करें (सबसे आसान)

Claude वेबसाइट, Claude डेस्कटॉप ऐप और Claude फ़ोन ऐप पर काम करता है -- एक बार सेट करें और यह सब पर चालू हो जाता है।

### चरण 1 -- Claude का connector सेटिंग्स खोलें

1. [claude.ai](https://claude.ai) पर जाएँ और साइन इन करें (या एक मुफ़्त खाता बनाएँ)।
2. नीचे-बाईं ओर अपने नाम पर क्लिक करें, फिर **Settings** → **Connectors**।

### चरण 2 -- B1 जोड़ें

1. **Add** पर क्लिक करें, फिर **Add custom connector**।
2. **Name:** में `B1` टाइप करें।
3. **URL:** में `https://api.churchapps.org/mcp` चिपकाएँ।
4. बाकी विकल्पों को जैसे हैं वैसे छोड़ दें और **Add** पर क्लिक करें।

### चरण 3 -- B1 में साइन इन करें

1. **Connect** पर क्लिक करें। एक B1 साइन-इन पृष्ठ खुलता है।
2. अपने B1 खाते से लॉग इन करें। यदि आप एक से अधिक चर्च से जुड़े हैं, तो जाँच लें कि सबसे ऊपर सही चर्च दिख रहा है।
3. B1 बताता है कि Claude क्या करने के लिए कह रहा है और पुष्टि करता है कि आपको **claude.ai** पर वापस भेजा जाएगा। **Allow** पर क्लिक करें।

आप Claude में वापस आ जाते हैं, और B1 जुड़ा हुआ दिखता है।

### चरण 4 -- कुछ पूछें

एक **नई चैट** शुरू करें और आज़माएँ:

- *"हमारे चर्च में कितने लोग हैं?"*
- *"हमारे सक्रिय समूहों की सूची बनाओ।"*
- *"इस महीने के दान का फंड-वार सारांश दो।"*
- *"पिछले 30 दिनों में चर्च में कौन शामिल हुआ?"*

पहली बार, Claude B1 का उपयोग करने की अनुमति माँगता है -- **Allow** पर क्लिक करें।

## विकल्प 2 -- B1 key के साथ डेस्कटॉप एक्सटेंशन

यदि आप Claude को सीमित अनुमतियों वाली key देना चाहते हैं (उदाहरण के लिए, केवल देखने की अनुमति), तो इसका उपयोग करें। यह Mac या Windows के लिए Claude डेस्कटॉप ऐप में काम करता है, और key बनाने के लिए आपको B1 में चर्च सेटिंग्स प्रबंधित करने की अनुमति चाहिए।

### चरण 1 -- Claude ऐप प्राप्त करें

[claude.com/download](https://claude.com/download) से Claude ऐप डाउनलोड करें, इंस्टॉल करें, खोलें, और साइन इन करें।

### चरण 2 -- अपनी B1 key बनाएँ

key वह चीज़ है जो Claude को *आपके* चर्च के B1 में प्रवेश देती है -- इसे केवल Claude के लिए एक पासवर्ड समझें।

1. [B1 Admin](https://admin.b1.church) में लॉग इन करें और [Settings → Developer](https://admin.b1.church/settings/developer) पर जाएँ।
2. **API Keys** टैब पर, **New API Key** पर क्लिक करें।
3. **Name:** में `Claude` टाइप करें।
4. **Scopes:** चुनें कि Claude क्या कर सकता है। हर क्षेत्र में एक **read** बॉक्स (केवल देखना) और एक **write** बॉक्स (बदलाव करना) है। निश्चित नहीं? शुरुआत के लिए केवल **read** बॉक्स चेक करें -- आप बाद में अधिक अनुमतियों वाली नई key बना सकते हैं।
5. **Save** पर क्लिक करें, फिर key को **Copy** करें। यह केवल एक बार दिखाई जाती है, इसलिए सीधे चरण 3 पर जाएँ।

### चरण 3 -- Claude में B1 जोड़ें

1. [B1 एक्सटेंशन डाउनलोड करें](https://github.com/mbyrdLCS/b1-claude-connect/releases/latest/download/b1-churchapps.mcpb)।
2. डाउनलोड की गई फ़ाइल (`b1-churchapps.mcpb`) पर **डबल-क्लिक** करें। Claude खुलता है और **B1 (ChurchApps)** दिखाता है।
3. **Install** पर क्लिक करें।
4. जब यह आपकी **B1 API key** माँगे, तो चरण 2 की key चिपकाएँ और सहेजें।
5. **Claude को पूरी तरह बंद करें** (Mac: **Cmd+Q** · Windows: टास्कबार में Claude आइकन पर राइट-क्लिक करें → **Quit**) और उसे फिर से खोलें।

यदि डबल-क्लिक करने से Claude नहीं खुलता, तो Claude में **Settings → Extensions → Advanced settings → Install Extension…** पर जाएँ और डाउनलोड की गई फ़ाइल चुनें। फिर एक नई चैट शुरू करें और कुछ पूछें।

:::tip एक्सटेंशन पहले से इंस्टॉल है?
कुछ करने की ज़रूरत नहीं है -- FreePlay उसी कनेक्शन के माध्यम से काम करता है। एक अपवाद है: संस्करण 1.1.0 ने B1 ईमेल और पासवर्ड माँगा था; उसे अपडेट करने के लिए एक्सटेंशन फिर से डाउनलोड और इंस्टॉल करें। आपकी key सुरक्षित रहती है।
:::

## क्या यह सुरक्षित है?

- Claude केवल **आपके चर्च** का डेटा देख सकता है।
- **साइन इन करके (विकल्प 1):** Claude आपके अपने B1 लॉगिन से अधिक कुछ नहीं कर सकता। आपके **Allow** पर क्लिक करने से पहले B1 साइन-इन पृष्ठ सूचीबद्ध करता है कि Claude क्या-क्या कर सकता है।
- **key के साथ (विकल्प 2):** Claude केवल वही कर सकता है जो key B1 में अनुमति देती है -- केवल **read** बॉक्स चेक वाली key देख सकती है, लेकिन कभी कुछ बदल नहीं सकती। FreePlay उसी key के तहत उसी तरह काम करता है।
- **इसे बंद करने के लिए:** B1 Admin में **Settings → Developer** पर जाएँ और **Connected Apps** के अंतर्गत ऐप को रद्द करें (विकल्प 1), या **API Keys** के अंतर्गत key हटाएँ (विकल्प 2)। पहुँच तुरंत बंद हो जाती है। आप Claude में B1 connector पर **Disconnect** पर भी क्लिक कर सकते हैं।

## इसकी लागत कितनी है?

B1 कनेक्शन मुफ़्त है -- यह ChurchApps का हिस्सा है। Claude की अपनी मुफ़्त योजना है; Claude Pro (लगभग $20/माह) आपको काफ़ी अधिक उपयोग देता है। देखें [claude.com/pricing](https://claude.com/pricing)।

## तकनीकी विवरण

इस पृष्ठ का बाकी हिस्सा तकनीकी उपयोगकर्ताओं और AI सहायकों के लिए है: scopes, जुड़ने के अन्य तरीके, और यह कैसे काम करता है।

### Scopes {#scopes}

Claude B1 API में बने **Model Context Protocol (MCP) server** (`https://api.churchapps.org/mcp`) के माध्यम से B1 से बात करता है। हर कॉल उसी auth, अनुमति और चर्च-स्कोपिंग नियमों से गुज़रती है जो B1 Admin के अनुरोध पर लागू होते हैं। Claude API key की **अनुमतियों और scopes** तक सीमित है, और webhooks, OAuth admin endpoints, या अन्य केवल-ऑपरेटर पथों तक नहीं पहुँच सकता।

सामान्य शुरुआती scope सेट:

- **केवल-पढ़ने वाला सहायक:** `people:read`, `groups:read`, `attendance:read`, `donations:read`, `content:read`
- **पढ़ना + नोट्स / कार्य जोड़ना:** `people:write` जोड़ें
- **पूर्ण परिचालन सहायक:** जिन `:write` scopes की आपको ज़रूरत है उन्हें जोड़ें

`donations:read` key वाला Claude दान का सारांश दे सकता है, लेकिन कोई उपहार दर्ज नहीं कर सकता। `people:write` key वाला Claude किसी व्यक्ति को जोड़ सकता है, लेकिन दान नहीं देख सकता। हर scope क्या अनुमति देता है, इसके लिए [API Keys](/docs/developer/api/api-keys) देखें।

### जुड़ने के अन्य तरीके

#### Claude Code (CLI)

एक टर्मिनल में:

```bash
claude mcp add --scope user --transport http b1 https://api.churchapps.org/mcp \
  --header "Authorization: Bearer cak_<prefix>.<secret>"
```

बस इतना ही। किसी भी Claude Code सत्र में `/mcp` टाइप करें यह पुष्टि करने के लिए कि `b1` सर्वर जुड़ा है, फिर अपने चर्च के बारे में Claude से कोई भी सवाल पूछें।

#### Claude Desktop -- मैन्युअल कॉन्फ़िग (उन्नत)

यदि आप एक्सटेंशन का उपयोग नहीं करना चाहते, तो Claude Desktop की कॉन्फ़िग फ़ाइल संपादित करें:

- **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`

एक `b1` सर्वर प्रविष्टि जोड़ें जो `mcp-remote` के माध्यम से B1 से जुड़ती है ([Node.js](https://nodejs.org) आवश्यक है):

```json
{
  "mcpServers": {
    "b1": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://api.churchapps.org/mcp",
        "--header", "Authorization:Bearer cak_<prefix>.<secret>"
      ]
    }
  }
}
```

Claude Desktop को पुनः आरंभ करें। चैट कंपोज़र में connector मेनू अपने टूल्स के साथ `b1` दिखाएगा।

#### Claude.ai (वेब) -- Custom Connector

ऊपर **विकल्प 1** देखें। connector OAuth 2.1 का उपयोग करता है: Claude `https://api.churchapps.org/.well-known/oauth-protected-resource` से B1 के authorization server को खोजता है, Dynamic Client Registration के साथ स्वयं को पंजीकृत करता है, और PKCE के साथ साइन इन करता है। Team और Enterprise योजनाओं पर, किसी owner को पहले संगठन के लिए connector जोड़ना पड़ सकता है। Claude कोई विशिष्ट scopes नहीं माँगता, इसलिए सहमति पृष्ठ वह सब कुछ दिखाता है जो साइन इन किया हुआ B1 खाता एक्सेस कर सकता है। B1 Admin में **Settings → Developer → Connected Apps** के अंतर्गत इसे रद्द करें।

### यह कैसे काम करता है

B1 API एक एकल MCP endpoint `/mcp` पर उपलब्ध कराता है। Claude उससे जुड़ता है, आपकी `cak_…` key से प्रमाणीकरण करता है, और चार टूल्स तक पहुँच पाता है:

| टूल | यह क्या करता है |
|---|---|
| `list_endpoints` | उन REST endpoints की सूची देता है जिन्हें Claude कॉल कर सकता है, path के अनुसार फ़िल्टर करने योग्य। खोज के लिए उपयोग होता है। |
| `describe_endpoint` | किसी विशिष्ट endpoint के लिए संक्षिप्त सारांश और एक उदाहरण अनुरोध/प्रतिक्रिया देता है। |
| `api_call` | प्रमाणीकृत उपयोगकर्ता के रूप में वास्तव में एक REST endpoint को चलाता है। |
| `describe_page_builder` | आपकी चर्च वेबसाइट के पृष्ठ बनाने और संपादित करने की गाइड, जिसे Claude वेबसाइट सामग्री पर काम करने से पहले पढ़ता है। |

यह वही `/membership/people`, `/giving/donations`, `/attendance/visits` आदि सतह है जिसका आपका B1Admin उपयोग करता है -- हर प्राधिकरण नियम समान रूप से लागू होता है। FreePlay (lessons.church) endpoints `/lessons/*` के अंतर्गत सूचीबद्ध हैं; FreePlay के लिए Claude के कॉल उसी उपयोगकर्ता के रूप में, उन्हीं अनुमतियों के साथ आगे भेजे जाते हैं।

### सुरक्षा और सीमाएँ

- **प्रति-चर्च अलगाव।** API key एक ही चर्च से जुड़ती है। Claude के पास दूसरे चर्चों का डेटा देखने का कोई तरीका नहीं है।
- **अनुमति-सीमित।** यदि आप B1Admin में key बनाने वाले व्यक्ति से कोई अनुमति हटाते हैं, तो Claude अगले कॉल पर तुरंत उसे खो देता है।
- **रद्द करने योग्य।** **Settings → Developer → API Keys** में key हटाएँ और Claude की पहुँच तुरंत समाप्त हो जाती है।
- **ब्लॉकलिस्ट।** Provider webhooks, OAuth client admin endpoints, और केवल-ऑपरेटर `apiEmails` route MCP के माध्यम से कॉल नहीं किए जा सकते।
- **प्रतिक्रिया आकार सीमा।** एक एकल टूल प्रतिक्रिया 64 KB तक सीमित है ताकि लंबी सूचियाँ Claude के संदर्भ को न भर दें -- ऐसा होने पर Claude फ़िल्टर से क्वेरी को संकुचित करेगा।
- **ऑडिट ट्रेल।** बदलाव (mutations) B1Admin क्रियाओं के समान ऑडिट लॉग से गुज़रते हैं; आप इन्हें **Settings → Audit Log** के अंतर्गत देख सकते हैं।

### समस्या निवारण

**Claude FreePlay के लिए B1 ईमेल और पासवर्ड माँगता है:** आपके पास डेस्कटॉप एक्सटेंशन का संस्करण 1.1.0 है। अपडेट करने के लिए इसे फिर से डाउनलोड और इंस्टॉल करें -- नए संस्करण केवल आपकी key का उपयोग करते हैं।

**Claude "Unauthorized" या 401 रिपोर्ट करता है:** bearer token गायब है, गलत है, या key रद्द की जा चुकी है। यदि आपने एक्सटेंशन का उपयोग किया है, तो Claude में **Settings → Extensions → B1 (ChurchApps)** खोलें और key फिर से चिपकाएँ। अन्यथा `Authorization: Bearer cak_…` हेडर को दोबारा जाँचें (स्पेस और शाब्दिक `Bearer` पर ध्यान दें)।

**एक टूल कॉल 403 लौटाता है:** API key के पास उस endpoint के लिए scope नहीं है। **Settings → Developer → API Keys** में scope जोड़ें (आपको एक नई key बनानी होगी -- scopes को मौके पर नहीं बदला जा सकता) और नई key को एक्सटेंशन की सेटिंग्स या Claude की कॉन्फ़िग में चिपकाएँ।

**Claude को कोई endpoint नहीं मिलता:** उससे फ़िल्टर के साथ `list_endpoints` कॉल करने को कहें, जैसे *"use list_endpoints with filter 'donations' to find the right path"*। रूट सूची लाइव API से बनाई जाती है, इसलिए आप जो भी `curl` से पहुँच सकते हैं, वह उसमें है।

**स्थानीय विकास:** `https://api.churchapps.org/mcp` को `http://localhost:8084/mcp` से बदलें -- वही auth, वही टूल्स।
