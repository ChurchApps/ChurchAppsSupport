# Zapier

<div class="article-intro">

Zapier पर आधिकारिक B1.church ऐप आपको एक Zap को आपके चर्च की घटनाओं पर प्रतिक्रिया देने देता है (नया व्यक्ति, नया दान, नया समूह सदस्य, …) और रिकॉर्ड वापस B1 में लिखने देता है। कोई कोडिंग नहीं, कोई इंफ़्रास्ट्रक्चर नहीं -- आप इसे Zapier के ड्रैग-एंड-ड्रॉप एडिटर में जोड़ते हैं, एक API key चिपकाते हैं, और Zap चालू कर देते हैं।

</div>

:::caution Zapier की स्वीकृति की प्रतीक्षा
B1.church ऐप बन चुका है और काम कर रहा है, लेकिन यह Zap एडिटर की ऐप डायरेक्टरी में सार्वजनिक रूप से दिखने से पहले अब भी Zapier की समीक्षा की प्रतीक्षा कर रहा है। स्वीकृति मिलने तक, केवल आमंत्रित खाते ही इसका उपयोग कर सकते हैं। नीचे सब कुछ बताता है कि स्वीकृति के बाद यह कैसे काम करेगा।
:::

<div class="prereqs">
<h4>शुरू करने से पहले</h4>

- एक [Zapier](https://zapier.com) खाता (कुछ Zaps के लिए मुफ़्त योजना पर्याप्त है)
- B1Admin में **Edit Settings** अनुमति वाला एक चर्च एडमिन (आप एक API key बनाएँगे)
- इस बारे में एक विचार कि आप क्या करना चाहते हैं -- जैसे "जब B1 में कोई व्यक्ति जुड़े, तो उसे मेरी Mailchimp सूची में जोड़ें"

</div>

## ट्रिगर और क्रियाएँ

| प्रकार | क्या | B1 इवेंट / endpoint |
|---|---|---|
| **Trigger** | New Person | `person.created` |
| **Trigger** | Updated Person | `person.updated` |
| **Trigger** | New Donation | `donation.created` |
| **Trigger** | New Group Member | `group.member.added` |
| **Trigger** | New Form Submission | `form.submission.created` |
| **Action** | Create Person | एक नया व्यक्ति जोड़ता है |
| **Action** | Add Donation | एक दान दर्ज करता है |
| **Action** | Add Group Member | किसी व्यक्ति को समूह में जोड़ता है |
| **Action** | Find Person | id, ईमेल, या नाम से किसी व्यक्ति को खोजता है; यदि कोई मेल नहीं खाता तो कार्य विफल कर देता है |

इन्हें Zapier के 7,000+ समर्थित ऐप्स में से किसी के भी साथ स्वतंत्र रूप से जोड़ें।

## सेटअप

### 1. B1 API key बनाएँ

1. B1Admin में **Settings → Developer → API Keys** पर जाएँ।
2. **New API Key** पर क्लिक करें, उसे "Zapier" जैसा नाम दें, और वे scopes चुनें जिनकी Zap को ज़रूरत है।
3. **महत्वपूर्ण:** Zap चालू होने पर Zapier आपकी ओर से एक webhook पंजीकृत करता है, जिसके लिए **`settings:write`** scope आवश्यक है। यदि आपके किसी भी Zap में B1 ट्रिगर है, तो हमेशा `settings:write` शामिल करें।
4. क्रियाओं के लिए आवश्यक scopes भी दें -- उदाहरण के लिए "Add Donation" क्रिया को `donations:write` चाहिए, "Create Person" को `people:write`।
5. सहेजें। पूरी `cak_…` key **एक बार** दिखाई जाती है -- उसे कॉपी करें।

### 2. Zapier को B1 से जोड़ें

1. Zapier में एक नया Zap बनाएँ।
2. जब आप पहली बार कोई B1 ट्रिगर या क्रिया चुनते हैं, तो Zapier आपसे **Sign in to B1.church** करने को कहता है।
3. चरण 1 की key चिपकाएँ और **Yes, Continue** पर क्लिक करें। Zapier उसे आपके चर्च के विरुद्ध सत्यापित करता है।

यह कनेक्शन Zapier में सहेजा जाता है और आपके खाते के हर Zap द्वारा पुन: उपयोग होता है।

### 3. Zap बनाएँ

एक ट्रिगर चुनें, फिर एक या अधिक क्रिया चरण जोड़ें। नीचे उदाहरण हैं।

## सामान्य रेसिपी

### नए B1 लोगों को Mailchimp में जोड़ें

- **Trigger** — B1: New Person
- **Action** — Mailchimp: Add/Update Subscriber। B1 के `name__first`, `name__last`, `contactInfo__email` को Mailchimp के First Name / Last Name / Email फ़ील्ड में मैप करें।

### दान को Slack चैनल पर एक समृद्ध कार्ड के साथ पोस्ट करें

- **Trigger** — B1: New Donation
- **Action** — Slack: Send Channel Message। कोई भी लेआउट बनाएँ -- बटन, अटैचमेंट, आदि -- जो [Slack कनेक्टर](./slack-discord) नहीं बना सकता।

### नए समूह सदस्यों को Google Group में जोड़ें

- **Trigger** — B1: New Group Member (किसी विशिष्ट `groupId` तक फ़िल्टर किया गया)
- **Action** — Filter by Zapier: केवल तभी आगे बढ़ें जब B1 समूह वही हो जिसकी आपको परवाह है
- **Action** — B1: Find Person (ईमेल प्राप्त करने के लिए ट्रिगर के `personId` का उपयोग करें)
- **Action** — Google Groups: Add Member

### फ़ॉर्म प्रस्तुतियों को प्रोजेक्ट ट्रैकर पर भेजें

- **Trigger** — B1: New Form Submission
- **Action** — Notion / Linear / Asana / Trello: Create page / issue / task

## ट्रिगर अंदर से कैसे काम करते हैं

ट्रिगर **REST hooks** हैं, polling नहीं -- Zapier हर 15 मिनट में B1 को नहीं पूछता। जब आप Zap चालू करते हैं, तो Zapier B1 से एक निजी Zapier URL की ओर इशारा करने वाला webhook पंजीकृत करने को कहता है; जब इवेंट होता है, तो B1 लिफ़ाफ़ा Zapier को POST करता है और आपका Zap **कुछ ही सेकंड में** शुरू हो जाता है। Zap बंद करें और Zapier B1 से webhook हटाने को कहता है -- कोई अनाथ सदस्यता नहीं रहती।

इसका अर्थ है कि ट्रिगर केवल उन इवेंट्स पर फ़ायर होता है जो Zap चालू होने **के बाद** होते हैं। कोई बैकफ़िल नहीं है -- Zap चालू करने से कल के दान दोबारा नहीं चलते।

## सीमाएँ और नोट्स

- **एक ही ट्रिगर वाले कई Zaps** हर एक अपना B1 webhook पंजीकृत करते हैं -- कोई टकराव नहीं है, लेकिन यदि आप **Settings → Developer → Webhooks** देख रहे हैं और सोच रहे हैं कि तीन एक जैसी `Zapier — donation.created` पंक्तियाँ क्यों हैं, तो यह जानना उपयोगी है।
- **Zap सेटअप में टेस्ट डेटा** -- जब आप एक Zap बनाते हैं, तो Zapier फ़ील्ड मैप करने के लिए नमूना डेटा माँगता है। यदि B1 में हाल का कोई मेल खाता इवेंट है, तो यह उसे खींचता है; अन्यथा यह ऐप परिभाषा से एक कृत्रिम नमूना उपयोग करता है।
- **क्रिया विफलताएँ Zap त्रुटियों के रूप में** Zapier के कार्य इतिहास में दिखती हैं। एक सामान्य कारण: गलत scope वाली API key (जैसे "Add Donation" क्रिया को `donations:write` चाहिए)। सही scopes के साथ key फिर से बनाएँ और Zapier में फिर से कनेक्ट करें।
- **बाहरी API कॉल कोटा** -- किसी क्रिया से हर B1 API कॉल आपके Zapier कार्य कोटा में गिना जाता है, B1 की ओर की किसी चीज़ में नहीं।

## समस्या निवारण

- कनेक्ट करते समय **"Authentication failed"** -- API key गलत है, रद्द कर दी गई है, या Zap को चाहिए scopes उसमें नहीं हैं। B1Admin में कम से कम `settings:write` और Zap जिन संसाधन scopes को छूता है उन्हें जोड़कर उसे फिर से बनाएँ, फिर कनेक्शन अपडेट करें।
- **ट्रिगर कभी फ़ायर नहीं होता** -- पुष्टि करें कि webhook वास्तव में पंजीकृत हुआ है: B1Admin में **Settings → Developer → Webhooks** पर अब "Zapier — &lt;event&gt;" नाम की एक पंक्ति दिखनी चाहिए। यदि वह नहीं है, तो Zap चालू करते समय API key में `settings:write` नहीं रहा होगा। key ठीक करें, Zap को बंद करके फिर चालू करें।
- **ट्रिगर दो बार फ़ायर होता है** -- यदि उसकी स्वीकृति खो गई हो तो Zapier कभी-कभी फिर से डिलीवर करता है। यदि आपको सख्त डुप्लिकेट-हटाने की ज़रूरत है, तो किसी अनूठे id (जैसे व्यक्ति का `id`) पर "Filter by Zapier" चरण का उपयोग करें।
