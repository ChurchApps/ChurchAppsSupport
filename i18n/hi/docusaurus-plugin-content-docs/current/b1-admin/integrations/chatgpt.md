# ChatGPT

<div class="article-intro">

अपने चर्च के B1 डेटा के साथ OpenAI के ChatGPT को कनेक्ट करें और इसे भारी उठाने दें। कनेक्ट होने के बाद, ChatGPT आपकी लाइव चर्च रिकॉर्ड देख सकता है और आपको ऐसी चीजें करने में मदद कर सकता है जो अन्यथा B1 Admin में कई चरण लेंगे — या जो आप पता भी नहीं लगा सकते हैं कि कैसे करें।

**कुछ चीजें जो आप इसे करने के लिए कह सकते हैं:**
- *"रविवार स्कूल कक्षा सेट अप करें और प्रत्येक शिक्षक को उनके समूह के आधार पर सही कमरे में रखें"*
- *"मुझे वह सब दिखाएं जो पिछले हफ्ते आए लेकिन किसी छोटे समूह को असाइन नहीं किया गया है"*
- *"इस महीने की दान राशि निधि द्वारा सारांशित करें"*
- *"हमारे नए सदस्य कौन हैं और क्या हमने उनके साथ अनुवर्ती कार्रवाई की है?"*
- *"मैं B1 में X कैसे करें यह पता नहीं लगा सकता — क्या आप मुझे इसके माध्यम से चल सकते हैं या मेरे लिए इसे कर सकते हैं?"*

ChatGPT सीधे आपके B1 डेटा से उत्तर खींचता है और कार्य करता है, केवल आपके चर्च के लिए सीमित।

:::tip अनुशंसित: Claude Code
सबसे सुगम MCP अनुभव के लिए, [Claude Code](./claude) अनुशंसित क्लाइंट है — सेटअप एक कमांड लेता है और यह बॉक्स से बाहर काम करता है। ChatGPT भी काम करता है और एक बढ़िया विकल्प है यदि आपकी टीम पहले से इसका उपयोग कर रही है।
:::

दो पथ समर्थित हैं: **MCP कनेक्टर** (ChatGPT में निर्मित) और एक **कस्टम GPT** उन टीमों के लिए जो एक साझा सहायक चाहते हैं।

</div>

<div class="prereqs">
<h4>शुरू करने से पहले</h4>

- एक OpenAI खाता सेट अप करें। ChatGPT तक पहुंच और कम से कम मूल कार्यक्षमता के लिए।
- B1 Admin तक पहुंच और किसी भी कार्यक्षमता के लिए ChatGPT का उपयोग करने के लिए सहमति। समझ लें कि ChatGPT चर्च डेटा को शामिल कर सकता है।

</div>

## MCP कनेक्टर (अनुशंसित)

सेटअप सबसे आसान तरीका एक समर्पित MCP क्लाइंट है।

1. **Claude Code** इंस्टॉल करें (या कोई अन्य समर्थित MCP क्लाइंट)।
2. आपके ChurchApps खाते से API कुंजी जनरेट करें।
3. कुंजी को अपने क्लाइंट कॉन्फ़िगरेशन में पेस्ट करें।
4. आप तुरंत शुरू कर सकते हैं!
