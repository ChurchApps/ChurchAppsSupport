# अपना Profile प्रबंधित करना

<div class="article-intro">

Profile पेज आपको अपनी व्यक्तिगत खाता सेटिंग्स संपादित करने देता है। आपकी profile सभी ChurchApps उत्पादों में साझा है, इसलिए यहाँ किए गए बदलाव हर उस जगह दिखेंगे जहाँ आप ChurchApps उपयोग करते हैं।

</div>

<div class="prereqs">
<h4>शुरू करने से पहले</h4>

- आपको अपने ChurchApps खाते में लॉग इन होना चाहिए
- अगर आप उन्हें अपडेट करने की योजना बनाते हैं, तो अपना नया email पता या password तैयार रखें

</div>

## अपनी Profile खोलना {#opening-your-profile}

B1 Admin में ऊपर-दाईं ओर अपनी प्रोफ़ाइल फ़ोटो पर क्लिक करें और **Edit Profile** चुनें। Profile पेज पर बाईं ओर आपका नाम और email होता है, और दाईं ओर **Linked Accounts**, **Two-Factor Sign-In**, और **Account Deletion** सेक्शन होते हैं।

## Profile की जानकारी {#profile-information}

Profile पेज बाईं ओर आपका नाम और email पता दिखाता है, उनके नीचे एक **Edit** बटन के साथ। **Edit Account** फ़ॉर्म खोलने के लिए **Edit** पर क्लिक करें, जिसमें आपके मूल खाता विवरण होते हैं:

1. **Email** -- आपका email पता, जो लॉग इन करने और सूचनाएँ पाने के लिए उपयोग होता है।
2. **First Name** और **Last Name** -- ChurchApps में आपका प्रदर्शन नाम।
3. **Current password**, **New password**, और **Verify password** -- केवल अपना password बदलने के लिए भरें; मौजूदा password रखने के लिए इन्हें खाली छोड़ें।

अपनी जानकारी अपडेट करने के लिए फ़ील्ड संपादित करें और **Save Changes** बटन पर क्लिक करें। **Changes saved.** संदेश अपडेट की पुष्टि करता है। बिना सेव किए profile पर लौटने के लिए **Cancel** (या अपने नाम वाले **Back to** link) पर क्लिक करें। password फ़ील्ड में आँख के आइकन पर क्लिक करके आपके द्वारा टाइप किया गया दिखाएँ या छिपाएँ।

## अपना Password बदलना {#changing-your-password}

1. Profile पेज पर **Edit** पर क्लिक करें।
2. अपना **Current password** दर्ज करें।
3. **New password** फ़ील्ड में नया password दर्ज करें।
4. **Verify password** फ़ील्ड में उसे फिर से दर्ज करें।
5. **Save Changes** पर क्लिक करें।

:::info
आपका password कम से कम 8 अक्षरों का होना चाहिए। सुनिश्चित करें कि password और पुष्टि दोनों फ़ील्ड बिल्कुल मेल खाते हों। इसे बदलने के लिए आपको अपना मौजूदा password पुष्ट करना होगा -- अगर आपको वह नहीं पता, तो लॉगिन पेज पर **Forgot Password** link का उपयोग करें।
:::

## Linked Accounts {#linked-accounts}

**Linked Accounts** सेक्शन उन बाहरी सेवाओं को दिखाता है जिन्हें आप अपने ChurchApps खाते से जोड़ सकते हैं। आज यह **PraiseCharts** है, जिसका उपयोग Serving में [songs](../serving/songs.md) के लिए गाने ढूँढने और chords व sheet music डाउनलोड करने हेतु होता है। यह **Linked** या **Not linked** दिखाता है:

- अपना खाता जोड़ने के लिए **Link** पर क्लिक करें और खुलने वाली विंडो में PraiseCharts में साइन इन करें।
- पहले PraiseCharts खाता बनाने के लिए **Sign Up** पर क्लिक करें।
- इसे अलग करने के लिए **Unlink** पर क्लिक करें।

## Two-Factor Sign-In {#two-factor-sign-in}

Two-factor sign-in लॉग इन करने में एक दूसरा चरण जोड़ता है: आपके password के बाद (या Google, Microsoft, या email sign-in link के बाद), आपको अपने फ़ोन के authenticator ऐप से 6-अंकों का कोड भी दर्ज करना होता है, जैसे Google Authenticator, Microsoft Authenticator, 1Password, या Authy। यह वैकल्पिक है और डिफ़ॉल्ट रूप से बंद रहता है। एक बार चालू होने पर, यह आपके खाते का उपयोग करने वाले हर ChurchApps लॉगिन पर लागू होता है -- B1 Admin, आपके चर्च की B1.church साइट और ऐप, B1 Church Checkin, Lessons.church, FreePlay, और बाकी सब।

### इसे चालू करना {#turning-it-on}

1. Profile पेज पर **Two-Factor Sign-In** सेक्शन ढूँढें और **Turn on** पर क्लिक करें।
2. अपने authenticator ऐप से QR कोड स्कैन करें। अगर आप उसे स्कैन नहीं कर सकते, तो **Can't scan? Enter this key:** के अंतर्गत दिखाई गई key ऐप में टाइप करें।
3. ऐप द्वारा दिखाया गया **6-अंकों का कोड** दर्ज करें और **Verify** पर क्लिक करें।
4. B1 Admin दस **backup codes** दिखाता है। हर एक अगर आपका फ़ोन खो जाए तो एक बार आपको साइन इन करवाता है। **Copy** पर क्लिक करें या उन्हें लिख लें, किसी सुरक्षित जगह रखें, और **I saved them** पर क्लिक करें।

:::warning
backup codes केवल एक बार दिखाए जाते हैं। अगर आप अपना फ़ोन खो दें और कोई backup code न बचे, तो आपकी पहचान की पुष्टि के बाद एक ChurchApps सर्वर administrator को आपके लिए two-factor sign-in बंद करना होगा।
:::

जब two-factor sign-in चालू होता है, तो सेक्शन **On** दिखाता है और बताता है कि आपके पास कितने backup codes बचे हैं।

### कोड से साइन इन करना {#signing-in-with-a-code}

अपना password दर्ज करने के बाद, लॉगिन स्क्रीन एक कोड माँगती है। अपने authenticator ऐप से 6-अंकों का कोड, या अपने backup codes में से एक दर्ज करें, और सबमिट करें। हर backup code केवल एक बार काम करता है। अगर कोड गलत है, तो आपको "That code didn't work. Please try again." दिखेगा। बहुत सारे गलत कोड के बाद, आपके खाते के लॉगिन कुछ समय के लिए रोक दिए जाते हैं।

ऐसे डिवाइस पर साइन इन रहना जिस पर आप पहले लॉग इन कर चुके हैं, फिर से कोड नहीं माँगता; यह केवल तब आता है जब आप नए सिरे से लॉग इन करते हैं।

### इसे बंद करना {#turning-it-off}

1. **Two-Factor Sign-In** सेक्शन में **Turn off** पर क्लिक करें।
2. अपने authenticator ऐप से वर्तमान कोड, या कोई backup code दर्ज करें।
3. **Verify** पर क्लिक करें।

:::info
demo खातों पर two-factor sign-in सेट नहीं किया जा सकता, इसलिए वहाँ सेक्शन छिपा रहता है।
:::

## Theme Preferences {#theme-preferences}

B1 Admin आपको एक रंग theme और light या dark display mode चुनने देता है:

1. अपना user menu खोलने के लिए B1 Admin में ऊपर-दाईं ओर अपनी प्रोफ़ाइल फ़ोटो पर क्लिक करें।
2. **Theme Preferences** के अंतर्गत एक theme चुनें:
   - **Default** -- वर्तमान B1 Admin रूप: एक साफ़ कैनवास पर बॉर्डर वाले panels। नए उपयोगकर्ता किसी दूसरे theme को चुनने तक यही देखते हैं।
   - **Classic** -- पहले वाला B1 Admin रूप, जिसमें रंगीन पेज banner, छायादार cards, और ग्रे पृष्ठभूमि होती है। अगर आपने नया रूप आने से पहले इस डिवाइस पर B1 Admin उपयोग किया था और कभी कोई theme नहीं चुना, तो आप Classic पर ही रहेंगे।
   - **Custom** -- आपके चर्च के अपने रंग से बना Default रूप। यह **Mobile > App Theme** से light-mode primary color का उपयोग करता है, या अगर कोई ऐप रंग सेट नहीं है तो आपकी वेबसाइट का primary color, ताकि B1 Admin आपके सदस्य ऐप से मेल खाए।
3. themes के नीचे **Light Mode** या **Dark Mode** चुनें।
4. इंटरफ़ेस आपके चुनाव को तुरंत दर्शाने के लिए अपडेट होता है।

आपके चुनाव उस डिवाइस और ब्राउज़र पर याद रखे जाते हैं।

## खाता हटाना {#account-deletion}

Profile पेज के **Account Deletion** सेक्शन में आपको अपना खाता हटाने का विकल्प मिलेगा।

- अगर आपके चर्च ने Directory Approval Group **कॉन्फ़िगर नहीं** किया है, तो सेक्शन चेतावनी देता है *"Careful, these actions are permanent"*। **Delete my account** पर क्लिक करें और पुष्टि करें, और आपका खाता व संबंधित डेटा तुरंत हटा दिए जाते हैं और आप साइन आउट हो जाते हैं। इसे वापस नहीं किया जा सकता।
- अगर आपके चर्च ने Directory Approval Group **कॉन्फ़िगर किया है**, तो सेक्शन बताता है कि आपका चर्च हटाने के अनुरोधों की समीक्षा करता है। **Delete my account** पर क्लिक करें, फिर **Send request**, और अनुरोध उसके बजाय समीक्षा के लिए उस group को जाता है। जब तक अनुरोध लंबित है, बटन निष्क्रिय रहता है, और जब आपका चर्च उसे स्वीकृत या अस्वीकृत करेगा तो आपको सूचना मिलेगी। आगे क्या होता है, इसके लिए देखें [Reviewing Account Deletion Requests](./account-deletion.md)।

:::warning
खाता हटाना -- चाहे तुरंत हो या आपके चर्च द्वारा स्वीकृत -- स्थायी है और इसे उलटा नहीं जा सकता।
:::

:::info
अगर आप अपने चर्च के एकमात्र **Domain Admin** हैं, तो B1 आपका खाता नहीं हटाएगा। वह दिखाता है "You are the only Domain Admin for *church*. Make someone else a Domain Admin before deleting your account." **Domain Admins** में पहले किसी और उपयोगकर्ता को जोड़ें। admin भूमिकाएँ प्रबंधित करने के विवरण के लिए [Roles & Permissions](../settings/roles-permissions.md) देखें।
:::

:::info
demo मोड में profile संपादन अक्षम है। अगर आप demo खाते का उपयोग कर रहे हैं, तो आप अपनी profile सेटिंग्स में बदलाव नहीं कर पाएँगे।
:::
