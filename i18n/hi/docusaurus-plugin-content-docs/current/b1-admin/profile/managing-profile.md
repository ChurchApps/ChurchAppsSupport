# अपनी प्रोफ़ाइल प्रबंधित करना

<div class="article-intro">

प्रोफ़ाइल पृष्ठ आपको अपनी व्यक्तिगत खाता सेटिंग्स संपादित करने देता है। आपकी प्रोफ़ाइल सभी ChurchApps उत्पादों में साझा है, इसलिए यहाँ किए गए बदलाव हर उस जगह दिखेंगे जहाँ आप ChurchApps उपयोग करते हैं।

</div>

<div class="prereqs">
<h4>शुरू करने से पहले</h4>

- आपको अपने ChurchApps खाते में लॉग इन होना चाहिए
- यदि आप ईमेल या पासवर्ड अपडेट करने की योजना बना रहे हैं, तो अपना नया ईमेल पता या पासवर्ड तैयार रखें

</div>

## प्रोफ़ाइल जानकारी

प्रोफ़ाइल पृष्ठ बाईं ओर आपका नाम और ईमेल पता दिखाता है, उनके नीचे **Edit** बटन के साथ। अपने बुनियादी खाता विवरण वाला **Edit Account** फ़ॉर्म खोलने के लिए **Edit** पर क्लिक करें:

1. **Email** -- आपका ईमेल पता, जो लॉग इन करने और सूचनाएँ प्राप्त करने के लिए उपयोग होता है।
2. **First Name** और **Last Name** -- ChurchApps में आपका प्रदर्शित नाम।
3. **Password** -- अपना खाता पासवर्ड अपडेट करें।

अपनी जानकारी अपडेट करने के लिए, फ़ील्ड संपादित करें और **Save Changes** बटन पर क्लिक करें। बिना सहेजे प्रोफ़ाइल पर लौटने के लिए **Cancel** (या अपने नाम वाले **Back to** लिंक) पर क्लिक करें।

## अपना पासवर्ड बदलना

1. प्रोफ़ाइल पृष्ठ पर, **Edit** पर क्लिक करें।
2. अपना **Current password** दर्ज करें।
3. **New password** फ़ील्ड में अपना नया पासवर्ड दर्ज करें।
4. **Verify password** फ़ील्ड में उसे फिर से दर्ज करें।
5. **Save Changes** पर क्लिक करें।

:::info
आपका पासवर्ड कम से कम 8 अक्षरों का होना चाहिए। सुनिश्चित करें कि पासवर्ड और पुष्टि फ़ील्ड बिल्कुल मेल खाते हों। इसे बदलने के लिए आपको अपना वर्तमान पासवर्ड पुष्ट करना होगा -- यदि आपको वह याद नहीं है, तो इसके बजाय लॉगिन पृष्ठ पर **Forgot Password** लिंक का उपयोग करें।
:::

## जुड़े हुए खाते

**Linked Accounts** अनुभाग दिखाता है कि आपके ChurchApps खाते से कौन सी बाहरी सेवाएँ जुड़ी हैं। आप इस अनुभाग से देख सकते हैं कि कौन से खाते जुड़े हैं और उन कनेक्शनों को प्रबंधित कर सकते हैं।

## दो-चरणीय साइन-इन {#two-factor-sign-in}

दो-चरणीय साइन-इन लॉग इन करने में एक दूसरा चरण जोड़ता है: आपके पासवर्ड (या Google, Microsoft, या ईमेल साइन-इन लिंक) के बाद, आप अपने फ़ोन पर किसी ऑथेंटिकेटर ऐप से 6 अंकों का कोड भी दर्ज करते हैं, जैसे Google Authenticator, Microsoft Authenticator, 1Password, या Authy। यह वैकल्पिक है और डिफ़ॉल्ट रूप से बंद है। एक बार चालू होने पर, यह आपके खाते का उपयोग करने वाले हर ChurchApps लॉगिन पर लागू होता है -- B1 Admin, आपके चर्च की B1.church साइट और ऐप, B1 Church Checkin, Lessons.church, FreePlay, और बाकी सब।

### इसे चालू करना

1. प्रोफ़ाइल पृष्ठ पर, **Two-Factor Sign-In** अनुभाग खोजें और **Turn on** पर क्लिक करें।
2. QR कोड को अपने ऑथेंटिकेटर ऐप से स्कैन करें। यदि आप उसे स्कैन नहीं कर सकते, तो **Can't scan? Enter this key:** के नीचे दिखाई गई key को ऐप में टाइप करें।
3. ऐप द्वारा दिखाया गया **6-digit code** दर्ज करें और **Verify** पर क्लिक करें।
4. B1 Admin दस **backup codes** दिखाता है। यदि आप अपना फ़ोन खो दें, तो उनमें से हर एक आपको एक बार साइन इन करवा सकता है। **Copy** पर क्लिक करें या उन्हें लिख लें, किसी सुरक्षित जगह रखें, और **I saved them** पर क्लिक करें।

:::warning
Backup codes केवल एक बार दिखाए जाते हैं। यदि आप अपना फ़ोन खो देते हैं और आपके पास कोई backup code नहीं बचा है, तो आपकी पहचान की पुष्टि होने के बाद एक ChurchApps सर्वर एडमिनिस्ट्रेटर को आपके लिए दो-चरणीय साइन-इन बंद करना होगा।
:::

जब दो-चरणीय साइन-इन चालू होता है, तो अनुभाग **On** पढ़ता है और दिखाता है कि आपके पास कितने backup codes बचे हैं।

### कोड से साइन इन करना

अपना पासवर्ड दर्ज करने के बाद, लॉगिन स्क्रीन एक कोड माँगती है। अपने ऑथेंटिकेटर ऐप से 6 अंकों का कोड, या अपने एक backup code को दर्ज करें, और सबमिट करें। हर backup code केवल एक बार काम करता है। यदि कोड गलत है, तो आपको "That code didn't work. Please try again." दिखेगा। बहुत अधिक गलत कोड के बाद, आपके खाते के लिए कुछ समय के लिए लॉगिन रोक दिए जाते हैं।

जिस डिवाइस पर आप पहले से लॉग इन हैं, उस पर साइन इन बने रहने पर फिर से कोड नहीं माँगा जाता; यह केवल तब आता है जब आप नए सिरे से लॉग इन करते हैं।

### इसे बंद करना

1. **Two-Factor Sign-In** अनुभाग में, **Turn off** पर क्लिक करें।
2. अपने ऑथेंटिकेटर ऐप से वर्तमान कोड, या एक backup code दर्ज करें।
3. **Verify** पर क्लिक करें।

:::info
डेमो खातों पर दो-चरणीय साइन-इन सेट नहीं किया जा सकता, इसलिए वहाँ यह अनुभाग छिपा होता है।
:::

## थीम प्राथमिकताएँ

B1 Admin आपको एक रंग थीम और लाइट या डार्क डिस्प्ले मोड चुनने देता है:

1. B1 Admin में ऊपर-दाईं ओर अपनी प्रोफ़ाइल फ़ोटो पर क्लिक करके अपना उपयोगकर्ता मेनू खोलें।
2. **Theme Preferences** के अंतर्गत एक थीम चुनें:
   - **Default** -- वर्तमान B1 Admin रूप: एक साफ़ कैनवास पर बॉर्डर वाले पैनल। नए उपयोगकर्ता दूसरी थीम चुनने तक यही देखते हैं।
   - **Classic** -- पहले का B1 Admin रूप, जिसमें रंगीन पृष्ठ बैनर, छायादार कार्ड, और ग्रे पृष्ठभूमि है। यदि आपने नया रूप आने से पहले इस डिवाइस पर B1 Admin उपयोग किया था और कोई थीम नहीं चुनी, तो आप Classic पर ही रहेंगे।
   - **Custom** -- आपके चर्च के अपने रंग से बना Default रूप। यह **Mobile > App Theme** से लाइट-मोड प्राथमिक रंग उपयोग करता है, या यदि कोई ऐप रंग सेट नहीं है तो आपकी वेबसाइट का प्राथमिक रंग, ताकि B1 Admin आपके सदस्य ऐप से मेल खाए।
3. थीम्स के नीचे, **Light Mode** या **Dark Mode** चुनें।
4. इंटरफ़ेस आपकी पसंद को दर्शाने के लिए तुरंत अपडेट होता है।

आपकी पसंद उस डिवाइस और ब्राउज़र पर याद रखी जाती है।

## खाता हटाना

प्रोफ़ाइल पृष्ठ के **Account Deletion** अनुभाग में, आपको अपना खाता हटाने का विकल्प मिलेगा।

- यदि आपके चर्च ने Directory Approval Group **कॉन्फ़िगर नहीं** किया है, तो **Delete my account** पर क्लिक करने से आपका खाता और संबंधित डेटा तुरंत हट जाता है, और इसे पूर्ववत नहीं किया जा सकता।
- यदि आपके चर्च ने Directory Approval Group **कॉन्फ़िगर** किया है, तो आपका अनुरोध समीक्षा के लिए उस समूह को भेजा जाता है। अनुरोध लंबित रहने तक बटन निष्क्रिय रहता है, और आपके चर्च द्वारा स्वीकृत या अस्वीकृत करने पर आपको सूचित किया जाएगा। आगे क्या होता है, इसके लिए [Reviewing Account Deletion Requests](./account-deletion.md) देखें।

:::warning
खाता हटाना -- चाहे तुरंत हो या आपके चर्च द्वारा स्वीकृत -- स्थायी है और इसे पलटा नहीं जा सकता।
:::

:::info
यदि आप **Domain Admin** हैं, तो अपना खाता हटाने से पहले प्रशासनिक ज़िम्मेदारियाँ किसी दूसरे उपयोगकर्ता को सौंप दें। एडमिन भूमिकाएँ प्रबंधित करने के विवरण के लिए [Roles & Permissions](../settings/roles-permissions.md) देखें।
:::

:::info
डेमो मोड में प्रोफ़ाइल संपादन अक्षम है। यदि आप डेमो खाते का उपयोग कर रहे हैं, तो आप अपनी प्रोफ़ाइल सेटिंग्स में बदलाव नहीं कर पाएँगे।
:::
