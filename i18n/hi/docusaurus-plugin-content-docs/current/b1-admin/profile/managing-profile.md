# अपनी प्रोफ़ाइल प्रबंधित करना

<div class="article-intro">

Profile पेज आपको अपनी व्यक्तिगत खाता सेटिंग्स संपादित करने देता है। आपकी प्रोफ़ाइल सभी ChurchApps उत्पादों में साझा होती है, इसलिए आप यहाँ जो भी बदलाव करेंगे, वह उन सभी जगहों पर दिखेगा जहाँ आप ChurchApps का उपयोग करते हैं।

</div>

<div class="prereqs">
<h4>शुरू करने से पहले</h4>

- आपका ChurchApps खाते में लॉग इन होना ज़रूरी है
- अगर आप ईमेल या पासवर्ड बदलने की योजना बना रहे हैं, तो नया ईमेल पता या पासवर्ड तैयार रखें

</div>

## प्रोफ़ाइल जानकारी

Profile पेज बाईं ओर आपका नाम और ईमेल पता दिखाता है, उनके नीचे **Edit** बटन के साथ। **Edit Account** फ़ॉर्म खोलने के लिए **Edit** पर क्लिक करें, जिसमें आपके बुनियादी खाता विवरण हैं:

1. **Email** -- आपका ईमेल पता, जो लॉग इन करने और सूचनाएँ प्राप्त करने के लिए उपयोग होता है।
2. **First Name** और **Last Name** -- ChurchApps में आपका प्रदर्शित नाम।
3. **Password** -- अपना खाता पासवर्ड अपडेट करें।

अपनी जानकारी अपडेट करने के लिए फ़ील्ड संपादित करें और **Save Changes** बटन पर क्लिक करें। बिना सेव किए अपनी प्रोफ़ाइल पर लौटने के लिए **Cancel** (या अपने नाम वाले **Back to** लिंक) पर क्लिक करें।

## अपना पासवर्ड बदलना

1. Profile पेज पर, **Edit** पर क्लिक करें।
2. अपना **Current password** दर्ज करें।
3. **New password** फ़ील्ड में अपना नया पासवर्ड दर्ज करें।
4. **Verify password** फ़ील्ड में उसे फिर से दर्ज करें।
5. **Save Changes** पर क्लिक करें।

:::info
आपका पासवर्ड कम से कम 8 अक्षरों का होना चाहिए। सुनिश्चित करें कि पासवर्ड और पुष्टि फ़ील्ड बिल्कुल मेल खाते हों। पासवर्ड बदलने के लिए आपको अपने वर्तमान पासवर्ड की पुष्टि करनी होगी -- अगर आपको वह याद नहीं है, तो इसके बजाय लॉगिन पेज पर **Forgot Password** लिंक का उपयोग करें।
:::

## Linked Accounts

**Linked Accounts** सेक्शन उन बाहरी सेवाओं को दिखाता है जो आपके ChurchApps खाते से जुड़ी हैं। आप देख सकते हैं कि कौन-से खाते लिंक हैं और इस सेक्शन से उन कनेक्शनों को प्रबंधित कर सकते हैं।

## थीम प्राथमिकताएँ

B1 Admin आपको एक रंग थीम और लाइट या डार्क डिस्प्ले मोड चुनने देता है:

1. B1 Admin के ऊपर-दाईं ओर अपनी प्रोफ़ाइल फ़ोटो पर क्लिक करके अपना उपयोगकर्ता मेनू खोलें।
2. **Theme Preferences** के अंतर्गत एक थीम चुनें:
   - **Default** -- वर्तमान B1 Admin रूप: साफ़ कैनवास पर बॉर्डर वाले पैनल। नए उपयोगकर्ता दूसरी थीम चुनने तक इसी थीम को देखते हैं।
   - **Classic** -- B1 Admin का पिछला रूप, जिसमें रंगीन पेज बैनर, छायादार कार्ड और धूसर पृष्ठभूमि है। अगर आपने नया रूप आने से पहले इस डिवाइस पर B1 Admin इस्तेमाल किया था और कभी कोई थीम नहीं चुनी, तो आप Classic पर ही रहते हैं।
   - **Custom** -- आपके चर्च के अपने रंग से बना Default रूप। यह **Mobile > App Theme** से लाइट-मोड primary रंग का उपयोग करता है, या अगर कोई ऐप रंग सेट नहीं है तो आपकी वेबसाइट का primary रंग, ताकि B1 Admin आपके सदस्य ऐप से मेल खाए।
3. थीम के नीचे **Light Mode** या **Dark Mode** चुनें।
4. आपकी पसंद के अनुसार इंटरफ़ेस तुरंत अपडेट हो जाता है।

आपकी पसंद इस डिवाइस और ब्राउज़र पर याद रखी जाती है।

## खाता हटाना

Profile पेज के **Account Deletion** सेक्शन में आपको अपना खाता हटाने का विकल्प मिलेगा।

- अगर आपके चर्च ने Directory Approval Group कॉन्फ़िगर **नहीं** किया है, तो **Delete my account** पर क्लिक करने से आपका खाता और संबंधित डेटा तुरंत हट जाता है, और इसे पलटा नहीं जा सकता।
- अगर आपके चर्च ने Directory Approval Group **कॉन्फ़िगर** किया है, तो आपका अनुरोध समीक्षा के लिए उस ग्रुप को भेजा जाता है। जब तक अनुरोध लंबित है, बटन निष्क्रिय रहता है, और चर्च के स्वीकृत या अस्वीकृत करने पर आपको सूचना मिलेगी। आगे क्या होता है, यह जानने के लिए [खाता हटाने के अनुरोधों की समीक्षा](./account-deletion.md) देखें।

:::warning
खाता हटाना -- चाहे तुरंत हो या चर्च द्वारा स्वीकृत -- स्थायी है और इसे पलटा नहीं जा सकता।
:::

:::info
अगर आप **Domain Admin** हैं, तो खाता हटाने से पहले प्रशासनिक ज़िम्मेदारियाँ किसी और उपयोगकर्ता को सौंपना सुनिश्चित करें। admin भूमिकाएँ प्रबंधित करने के विवरण के लिए [Roles & Permissions](../settings/roles-permissions.md) देखें।
:::

:::info
प्रोफ़ाइल संपादन डेमो मोड में बंद है। अगर आप डेमो खाते का उपयोग कर रहे हैं, तो आप अपनी प्रोफ़ाइल सेटिंग्स में बदलाव नहीं कर पाएँगे।
:::
