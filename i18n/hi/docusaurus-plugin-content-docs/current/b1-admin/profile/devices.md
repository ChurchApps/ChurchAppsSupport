# डिवाइस प्रबंधित करना

<div class="article-intro">

Devices पृष्ठ आपको अपने खाते से जुड़े ChurchAppsPlayer और FreePlay डिवाइसों को प्रबंधित करने देता है। इन डिवाइसों का उपयोग आपके स्थान पर स्क्रीन पर सामग्री स्ट्रीम करने और चर्च मीडिया प्रदर्शित करने के लिए किया जाता है।

</div>

<div class="prereqs">
<h4>शुरू करने से पहले</h4>

- एक ChurchAppsPlayer डिवाइस चालू और इंटरनेट से जुड़ा होना चाहिए
- डिवाइस की स्क्रीन पर दिखाए गए pairing code को नोट करें
- यदि आपने पहले से नहीं किया है तो अपनी [प्रोफ़ाइल सेटिंग्स](./managing-profile.md) देखें

</div>

## अपने डिवाइस देखना

जब आप Devices पृष्ठ खोलते हैं, तो आपको सभी पंजीकृत डिवाइसों की एक तालिका दिखाई देगी जिसमें निम्नलिखित जानकारी होगी:

- **Label** -- डिवाइस को आपके द्वारा दिया गया नाम।
- **Registration Date** -- जब डिवाइस को पहली बार आपके खाते से पेयर किया गया था।
- **Last Active Date** -- डिवाइस के आपके खाते से जुड़ने का सबसे हालिया समय।

## नया डिवाइस जोड़ना

1. Devices पृष्ठ के शीर्ष पर **Add Screen** बटन पर क्लिक करें।
2. आपसे एक **pairing code** दर्ज करने के लिए कहा जाएगा।
3. जिस ChurchAppsPlayer या FreePlay डिवाइस को आप जोड़ना चाहते हैं, उस पर दिखाया गया pairing code खोजें।
4. कोड दर्ज करें। यदि यह FreePlay TV है, तो एक **Show Plans For** ड्रॉपडाउन आपको वह plan type चुनने देता है जिसका स्क्रीन अनुसरण करे -- डिवाइस को केवल ब्राउज़िंग और सूचनाओं के लिए उपयोग करने हेतु इसे **None** पर रहने दें।
5. पुष्टि करें। सफलतापूर्वक पेयर होने पर डिवाइस आपकी डिवाइस तालिका में दिखाई देगा।

:::tip
पेयर करने का प्रयास करने से पहले सुनिश्चित करें कि डिवाइस चालू है और इंटरनेट से जुड़ा है। pairing code डिवाइस की स्क्रीन पर दिखाया जाता है।
:::

## डिवाइस Label संपादित करना

1. डिवाइस तालिका में डिवाइस के आगे **Edit** पर क्लिक करें।
2. label को किसी वर्णनात्मक नाम में अपडेट करें (उदाहरण के लिए, "Sanctuary Main Screen" या "Lobby Display")।
3. अपने बदलाव सहेजें।

:::tip
स्पष्ट, वर्णनात्मक labels का उपयोग करने से यह पहचानना आसान होता है कि कौन सा डिवाइस कौन सा है, विशेष रूप से जब आपके चर्च में कई स्क्रीन सेट अप हों।
:::

## डिवाइस एक्सेस प्रबंधित करना

Devices पृष्ठ का उपयोग यह ट्रैक करने के लिए करें कि कौन से डिवाइसों की आपके चर्च की स्ट्रीमिंग और सामग्री तक पहुंच है। यदि कोई डिवाइस अब उपयोग में नहीं है, तो अपनी डिवाइस सूची को साफ़ और सुरक्षित रखने के लिए आप उसे अपने खाते से हटा सकते हैं।

:::warning
नियमित रूप से अपने जुड़े हुए डिवाइसों की समीक्षा करें ताकि सुनिश्चित हो कि केवल सक्रिय, अधिकृत डिवाइस आपके खाते से जुड़े हैं। सुरक्षा बनाए रखने के लिए उन डिवाइसों को हटाएं जो अब उपयोग में नहीं हैं।
:::
