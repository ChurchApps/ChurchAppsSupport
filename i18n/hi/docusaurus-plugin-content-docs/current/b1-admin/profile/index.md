# Profile

<div class="article-intro">

Profile सेक्शन आपको ChurchApps में अपनी व्यक्तिगत खाता सेटिंग्स प्रबंधित करने देता है। B1 Admin के ऊपर-दाईं ओर अपनी प्रोफ़ाइल फ़ोटो पर क्लिक करके और **Edit Profile** चुनकर इसे खोलें। आपकी profile सभी ChurchApps उपकरणों में साझा है, इसलिए यहाँ किए गए बदलाव हर जगह लागू होते हैं -- B1 Admin से लेकर B1 App तक।

</div>

## आप क्या कर सकते हैं {#what-you-can-do}

Profile सेक्शन से, आप:

- **अपना नाम और email अपडेट करें** -- अपनी संपर्क जानकारी को अद्यतन रखें।
- **अपना password बदलें** -- अपने खाते के लिए नया password सेट करें।
- **Two-factor sign-in चालू करें** -- लॉग इन करते समय authenticator ऐप से कोड माँगें। देखें [Two-Factor Sign-In](./managing-profile.md#two-factor-sign-in)।
- **Themes बदलें** -- user menu (ऊपर-दाईं ओर अपनी प्रोफ़ाइल फ़ोटो पर क्लिक करें) से light और dark mode के बीच स्विच करें।
- **जुड़े हुए devices प्रबंधित करें** -- अपने खाते से जुड़ी ChurchAppsPlayer और FreePlay स्क्रीन देखें, जोड़ें, नाम बदलें, और हटाएँ।
- **जुड़े हुए खाते देखें** -- अपने ChurchApps खाते से जुड़ी किसी भी बाहरी सेवा को देखें और प्रबंधित करें।
- **प्रोफ़ाइल बदलाव अनुरोध स्वीकृत करें** -- सदस्यों द्वारा भेजे गए अपडेट की समीक्षा करें और उन्हें लागू करें।
- **खाता हटाने के अनुरोधों की समीक्षा करें** -- सदस्यों के अपने खाते हटाने के अनुरोधों को स्वीकृत या अस्वीकृत करें।

## Profile उप-सेक्शन {#profile-sub-sections}

Profile क्षेत्र में ये पेज हैं:

1. **[अपना Profile प्रबंधित करना](./managing-profile.md)** -- अपनी व्यक्तिगत जानकारी संपादित करें, password बदलें, जुड़े हुए खाते प्रबंधित करें, two-factor sign-in चालू करें, theme प्राथमिकताएँ समायोजित करें, और खाता हटाने को सँभालें।
2. **[प्रोफ़ाइल बदलावों को स्वीकृत करना](./approving-profile-changes.md)** -- B1 App के माध्यम से सदस्यों द्वारा भेजे गए प्रोफ़ाइल अपडेट अनुरोधों की समीक्षा और स्वीकृति करें।
3. **[खाता हटाने के अनुरोधों की समीक्षा](./account-deletion.md)** -- सदस्यों के अपने खाते हटाने के अनुरोधों को स्वीकृत या अस्वीकृत करें।
4. **[Devices प्रबंधित करना](./devices.md)** -- अपने खाते से जुड़ी ChurchAppsPlayer और FreePlay स्क्रीन देखें, जोड़ें, नाम बदलें, और हटाएँ।

:::tip
अपना email पता अद्यतन रखें। इसका उपयोग खाता पुनर्प्राप्ति और आपके चर्च की महत्वपूर्ण सूचनाओं के लिए होता है।
:::
