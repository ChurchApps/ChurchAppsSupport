# प्रारंभिक सेटअप

<div class="article-intro">

अपने account को create करने और अपनी चर्च को register करने के बाद, अपनी team को invite करने से पहले कुछ महत्वपूर्ण steps को configure करने हैं। यह guide आपको recommended setup order के through चलाता है ताकि आपकी चर्च पहले दिन से ready हो।

</div>

<div class="prereqs">
<h4>शुरुआत करने से पहले</h4>

- [Create your account](./create-account.md) और अपनी चर्च को register करें
- अपनी चर्च logo और branding assets को तैयार करें (optional लेकिन recommended)

</div>

## Step 1: अपनी चर्च की जानकारी को Configure करें

1. शीर्ष-बाएं कोने में **section menu** खोलें (छोटे तीर के साथ section का नाम) और **Settings** चुनें।
2. **Edit Settings** पर क्लिक करें।
3. अपनी चर्च का **नाम**, **पता**, और **संपर्क विवरण** दर्ज करें।
4. अपने परिवर्तनों को लागू करने के लिए **Save** पर क्लिक करें।

## Step 2: अपनी Branding को Set Up करें

1. **Dashboard** से, **Website** को navigate करें, फिर **Appearance** को select करें।
2. अपनी **church logo** को upload करें।
3. Colors और images जैसे कोई भी अतिरिक्त branding options को configure करें।
4. आपकी branding आपकी B1.church website और B1 Mobile app पर दिखाई देगी।

:::tip
अपनी logo और branding को तैयार करना team members को invite करने से पहले एक polished first impression देता है जब वे login करते हैं।
:::

## Step 3: भूमिकाओं को Configure करें और अपनी Team को Invite करें

1. **Settings** page से **Roles** पर क्लिक करें।
2. अपनी team के लिए भूमिकाएं create करें (उदाहरण के लिए, "Pastor", "Secretary", "Treasurer")।
3. प्रत्येक भूमिका को appropriate permissions assign करें।
4. उन्हें search करके और भूमिकाओं के लिए assign करके team members को जोड़ें।

## Step 4: अपने Key क्षेत्रों को Set Up करें

अपनी team के साथ, B1 Admin के core areas को building शुरू करें:

1. **People** -- अपनी चर्च directory में members को add करें। यह सब के लिए foundation है, तो यहाँ शुरू करें। आप manually लोगों को add कर सकते हैं या **Settings** से **Import** tool का उपयोग कर सकते हैं।
2. **Groups** -- Small groups, ministry teams, classes, और अन्य gatherings के लिए groups create करें।
3. **Attendance** -- Attendance track करने के लिए अपने campuses, services, और service times को configure करें।
4. **Donations** -- Donation funds को set up करें और online giving को accept करने के लिए अपने payment gateway (Stripe) को connect करें।
5. **Website** -- B1.church website builder का उपयोग करके अपनी public church website को build करें।

:::info
आपको एक बार सब कुछ set up करने की आवश्यकता नहीं है। कई churches **People** और **Groups** के साथ शुरू करते हैं, फिर platform के साथ comfortable होने के बाद **Attendance** और **Donations** को add करते हैं।
:::

## Recommended Order

सबसे smooth setup experience के लिए, हम इस order को suggest करते हैं:

1. **People** -- पहले अपने members और regular attendees को add करें।
2. **Groups** -- लोगों को meaningful groups में organize करें।
3. **Attendance** -- Track करना शुरू करें कौन हर week show up करता है।
4. **Donations** -- अपने लोग system में होने के बाद giving को set up करें।
5. **Website** -- अपनी data के साथ ready होने के बाद अपनी public-facing site को build करें last में।

एक बार जब आप ये steps complete कर लें, आपकी चर्च जाने के लिए ready है। प्रत्येक area में detailed guides के लिए [B1 Admin](/docs/b1-admin/) documentation को explore करें।
