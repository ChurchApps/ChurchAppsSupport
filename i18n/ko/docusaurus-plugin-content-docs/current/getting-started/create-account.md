# 계정 만들기

<div class="article-intro">

ChurchApps 시작하기는 계정을 만드는 것부터 시작합니다. 과정은 몇 분밖에 걸리지 않으며, B1 Admin, B1.church, Lessons.church를 포함한 모든 ChurchApps 도구에 접근할 수 있게 됩니다.

## 단계별 등록

1. 웹 브라우저에서 [B1.church](https://b1.church)로 이동합니다.
2. **Register** 버튼을 클릭합니다.
3. **이름**, **성**, **이메일 주소**를 입력합니다. 또는 교회가 단일 로그인을 켜 두었다면 **Continue with Google** 또는 **Continue with Microsoft**를 클릭하여 기존 계정으로 5단계로 바로 넘어갑니다.
4. 계정의 비밀번호를 만듭니다.
5. 등록 양식을 제출합니다.

:::info
하나의 ChurchApps 계정으로 B1, Lessons.church, 그 밖의 ChurchApps 앱을 모두 사용할 수 있습니다. **You already have a ChurchApps account. Please sign in with it instead.**가 보이면 **Login**을 클릭하고 그 이메일로 로그인하세요. 비밀번호가 기억나지 않으면 **Forgot Password**를 사용하세요.
:::

## 이메일 확인하기

등록한 뒤에는 입력한 주소로 확인 이메일을 받게 됩니다.

1. 받은 편지함에서 ChurchApps가 보낸 확인 이메일을 찾습니다.
2. 이메일의 확인 링크를 클릭합니다.
3. 계정이 인증되었으며 이제 사용할 준비가 되었습니다.

:::tip
확인 이메일이 보이지 않으면 스팸 또는 정크 메일 폴더를 확인하세요. 이메일은 ChurchApps에서 오며 도착하는 데 1~2분 걸릴 수 있습니다.
:::

## 교회 설정하기

이메일을 확인하고 로그인한 뒤에는 새 교회를 만들거나 기존 교회에 합류하는 옵션이 나타납니다.

**새 교회를 만들려면:**

1. **create a new church**(새 교회 만들기) 옵션을 선택합니다.
2. **church name**(교회 이름)과 기본 정보를 입력합니다. 일치하는 항목이 발견되면 등록 양식이 교회 정보를 자동으로 채웁니다.
3. 설정 과정을 완료합니다.
4. B1 Admin의 홈 페이지인 **Dashboard**로 이동하며, 거기에서 교회를 구성하기 시작할 수 있습니다.

**기존 교회에 합류하려면:**

1. **join an existing church**(기존 교회에 합류하기) 옵션을 선택합니다.
2. 이름으로 교회를 검색합니다.
3. 합류를 요청합니다. 교회의 관리자가 요청을 승인해야 합니다.

:::info
아직 등록되지 않은 이메일로 로그인하려고 하면, 계정을 만들 수 있도록 등록 절차로 자동 안내됩니다.
:::

:::info
새 교회를 만든 사람은 자동으로 **Domain Admin** 역할을 받으며, 모든 설정과 기능에 대한 전체 접근 권한이 부여됩니다. 나중에 **Roles** 페이지에서 관리자를 추가할 수 있습니다.
:::
