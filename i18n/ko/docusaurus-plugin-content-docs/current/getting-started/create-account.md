# 계정 만들기

<div class="article-intro">

ChurchApps로 시작하는 것은 계정을 만드는 것으로 시작합니다. 프로세스는 몇 분만에 완료되며 B1 Admin, B1.church 및 Lessons.church를 포함한 모든 ChurchApps 도구에 대한 액세스를 제공합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 계정 확인을 위해 유효한 이메일 주소가 준비되어 있음
- [시작하기 개요](./index.md)를 검토하여 ChurchApps가 제공하는 것을 이해함

</div>

## 단계별 등록

1. 웹 브라우저에서 [B1.church](https://b1.church)로 이동합니다.
2. **등록** 버튼을 클릭합니다.
3. **이름**, **성** 및 **이메일 주소**를 입력합니다. 또는 교회에서 single sign-on을 활성화한 경우 **Google로 계속** 또는 **Microsoft로 계속**을 클릭하여 기존 계정을 사용하여 5단계로 바로 이동합니다.
4. 계정의 비밀번호를 만듭니다.
5. 등록 양식을 제출합니다.

:::info
하나의 ChurchApps 계정이 B1, Lessons.church 및 다른 ChurchApps 앱에서 작동합니다. **ChurchApps 계정이 이미 있습니다. 대신 그것으로 로그인하세요.**가 표시되면 **로그인**을 클릭하고 해당 이메일로 로그인합니다. 비밀번호가 생각나지 않으면 **비밀번호 찾기**를 사용합니다.
:::

## 이메일 확인

등록 후 제공한 주소로 확인 이메일을 받게 됩니다.

1. ChurchApps의 확인 이메일을 받은 편지함에서 확인합니다.
2. 이메일의 확인 링크를 클릭합니다.
3. 계정이 이제 확인되었고 사용 준비가 되었습니다.

:::tip
확인 이메일이 보이지 않으면 스팸 또는 정크 폴더를 확인합니다. 이메일은 ChurchApps에서 보내며 도착하는 데 1~2분이 걸릴 수 있습니다.
:::

## 교회 설정

이메일을 확인하고 로그인한 후 새 교회를 만들거나 기존 교회에 참여할 수 있는 옵션이 제공됩니다.

**새 교회를 만들려면:**

1. **새 교회 만들기** 옵션을 선택합니다.
2. **교회 이름** 및 기본 정보를 입력합니다. 등록 양식은 일치하는 항목이 찾아지면 교회 세부 정보를 자동으로 채웁니다.
3. 설정 프로세스를 완료합니다.
4. 교회 구성을 시작할 수 있는 B1 Admin 홈 페이지인 **대시보드**로 이동합니다.

**기존 교회에 참여하려면:**

1. **기존 교회에 참여** 옵션을 선택합니다.
2. 이름으로 교회를 검색합니다.
3. 참여를 요청합니다. 교회의 관리자가 요청을 승인해야 합니다.

:::info
아직 등록되지 않은 이메일로 로그인하려고 하면 계정을 만들 수 있도록 자동으로 등록 흐름으로 이동합니다.
:::

:::info
새 교회를 만드는 사람은 자동으로 모든 설정 및 기능에 대한 전체 액세스 권한을 부여하는 **Domain Admin** 역할이 할당됩니다. 나중에 **역할** 페이지에서 추가 관리자를 추가할 수 있습니다.
:::
