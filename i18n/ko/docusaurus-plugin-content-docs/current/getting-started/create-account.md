# 계정 만들기

<div class="article-intro">

ChurchApps를 시작하려면 먼저 계정을 만들어야 합니다. 이 과정은 몇 분밖에 걸리지 않으며, B1 Admin, B1.church, Lessons.church를 포함한 모든 ChurchApps 도구에 대한 접근 권한을 제공합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 계정 인증을 위해 유효한 이메일 주소를 준비하세요
- ChurchApps가 제공하는 기능을 이해하기 위해 [시작하기 개요](./index.md)를 검토하세요

</div>

## 단계별 등록

1. 웹 브라우저에서 [B1.church](https://b1.church)로 이동하세요.
2. **등록** 버튼을 클릭하세요.
3. **이름**, **성**, **이메일 주소**를 입력하세요 -- 또는 교회에서 싱글 사인온을 사용하는 경우, **Google로 계속하기** 또는 **Microsoft로 계속하기**를 클릭하여 기존 계정으로 5단계까지 바로 건너뛸 수 있습니다.
4. 계정 비밀번호를 만드세요.
5. 등록 양식을 제출하세요.

## 이메일 확인하기

등록 후 입력한 주소로 확인 이메일을 받게 됩니다.

1. ChurchApps에서 보낸 확인 이메일이 있는지 받은편지함을 확인하세요.
2. 이메일에 포함된 확인 링크를 클릭하세요.
3. 이제 계정이 인증되어 사용할 준비가 되었습니다.

:::tip
확인 이메일이 보이지 않으면 스팸 또는 정크 폴더를 확인하세요. 이메일은 ChurchApps에서 발송되며 도착까지 1~2분이 걸릴 수 있습니다.
:::

## 교회 설정하기

이메일을 확인하고 로그인한 후에는 새 교회를 만들거나 기존 교회에 가입할 수 있는 옵션이 나타납니다.

**새 교회를 만들려면:**

1. **새 교회 만들기** 옵션을 선택하세요.
2. **교회 이름**과 기본 정보를 입력하세요. 일치하는 항목이 발견되면 등록 양식이 교회 정보를 자동으로 채워줍니다.
3. 설정 절차를 완료하세요.
4. **B1 Admin 대시보드**로 이동하여 교회 구성을 시작할 수 있습니다.

**기존 교회에 가입하려면:**

1. **기존 교회에 가입하기** 옵션을 선택하세요.
2. 이름으로 교회를 검색하세요.
3. 가입을 요청하세요. 교회 관리자가 요청을 승인해야 합니다.

:::info
아직 등록되지 않은 이메일로 로그인을 시도하면 계정을 만들 수 있도록 등록 절차로 자동 이동됩니다.
:::

:::info
새 교회를 만든 사람에게는 자동으로 **도메인 관리자** 역할이 부여되며, 이는 모든 설정과 기능에 대한 전체 접근 권한을 제공합니다. 나중에 **역할** 페이지에서 추가 관리자를 등록할 수 있습니다.
:::
