# 계정 만들기

<div class="article-intro">

ChurchApps 시작은 계정을 만드는 것부터입니다. 과정은 몇 분이면 끝나며, B1 Admin, B1.church, Lessons.church를 비롯한 모든 ChurchApps 도구를 사용할 수 있습니다.

</div>

## 단계별 가입 방법

1. 웹 브라우저에서 [B1.church](https://b1.church)에 접속하세요.
2. **Register** 버튼을 클릭하세요.
3. **이름**, **성**, **이메일 주소**를 입력하세요. 교회에서 단일 로그인(SSO)을 사용한다면 **Continue with Google** 또는 **Continue with Microsoft**를 클릭해 기존 계정으로 5단계로 바로 넘어갈 수 있습니다.
4. 계정의 비밀번호를 만드세요.
5. 가입 양식을 제출하세요.

:::info
하나의 ChurchApps 계정으로 B1, Lessons.church 및 다른 ChurchApps 앱을 모두 사용할 수 있습니다. **You already have a ChurchApps account. Please sign in with it instead.** 메시지가 보이면 **Login**을 클릭하고 해당 이메일로 로그인하세요. 비밀번호가 기억나지 않으면 **Forgot Password**를 사용하세요.
:::

## 이메일 인증하기

가입한 후에는 입력한 주소로 인증 이메일이 발송됩니다.

1. 받은편지함에서 ChurchApps가 보낸 인증 이메일을 확인하세요.
2. 이메일의 인증 링크를 클릭하세요.
3. 계정 인증이 완료되어 사용할 준비가 되었습니다.

:::tip
인증 이메일이 보이지 않으면 스팸 또는 정크 메일함을 확인하세요. 이메일은 ChurchApps에서 보내며 도착하는 데 1~2분 정도 걸릴 수 있습니다.
:::

## 교회 설정하기

이메일 인증을 마치고 로그인하면 새 교회를 만들거나 기존 교회에 참여하는 옵션이 나타납니다.

**새 교회를 만들려면:**

1. **새 교회 만들기** 옵션을 선택하세요.
2. **교회 이름**과 기본 정보를 입력하세요. 일치하는 교회가 있으면 가입 양식에 교회 정보가 자동으로 채워집니다.
3. 설정 과정을 마치세요.
4. B1 Admin의 홈 페이지인 **대시보드**로 이동하며, 여기서 교회 설정을 시작할 수 있습니다.

**기존 교회에 참여하려면:**

1. **기존 교회에 참여하기** 옵션을 선택하세요.
2. 교회 이름으로 검색하세요.
3. 참여를 요청하세요. 요청은 교회의 관리자가 승인해야 합니다.

:::info
아직 등록되지 않은 이메일로 로그인하면 가입 절차로 자동 이동하여 계정을 만들 수 있습니다.
:::

:::info
새 교회를 만든 사람에게는 모든 설정과 기능에 대한 전체 접근 권한을 부여하는 **Domain Admin** 역할이 자동으로 지정됩니다. 나중에 **역할** 페이지에서 관리자를 추가할 수 있습니다.
:::
