# 시작하기

<div class="article-intro">

ChurchApps에 오신 것을 환영합니다. 교회가 번성하도록 돕기 위해 만들어진 무료 오픈소스 도구입니다. 작은 교회든 여러 캠퍼스를 운영하는 큰 조직이든, ChurchApps는 교회 공동체를 관리하고 성장시키는 데 필요한 모든 것을 제공합니다.

## 이미 가입하셨나요? 여기서 시작하세요

처음 15분 동안 할 일입니다.

1. **나만의 교회로 꾸미기.** 교회 이름, 주소, 로고를 추가하면 B1, 웹사이트, 앱이 교회의 모습으로 보입니다. [초기 설정 1단계와 2단계](./initial-setup.md#step-1-configure-your-church-information)를 참고하세요.
2. **교인 추가하기.** 몇 명을 직접 추가하거나, 스프레드시트나 기존 교회 소프트웨어에서 전체 명단을 가져오세요. [교인 가져오기](../b1-admin/people/importing-data.md)(동영상 포함)를 참고하세요.
3. **팀 초대하기.** 직원과 주요 봉사자에게 알맞은 권한을 주고 접근을 허용하세요. [역할 및 권한](../b1-admin/settings/roles-permissions.md)을 참고하세요.

### 그다음 첫 번째 프로젝트 고르기

- **주일학교 교실:** 무료 [Lessons.church](../lessons-church/index.md) 커리큘럼을 일정에 맞춰 예약하고, [FreePlay](../freeplay/index.md)로 교실 TV에서 재생하세요.
- **소그룹:** [소그룹 운영하기](../b1-admin/guides/small-groups.md)
- **교회 웹사이트:** [웹사이트 공개하기](../b1-admin/guides/launch-website.md)
- **온라인 헌금:** [온라인 헌금 설정하기](../b1-admin/guides/online-giving.md)
- **어린이 체크인:** [체크인 설정하기](../b1-admin/guides/childrens-checkin.md)
- **주일 봉사자:** [주일 봉사자 관리하기](../b1-admin/guides/sunday-volunteers.md)
- **출석:** [출석 기록하기](../b1-admin/guides/track-attendance.md)
- **설교와 라이브 스트림:** [설교 라이브러리 만들기](../b1-admin/guides/sermon-library.md)

아직 계정이 없다면 [계정 만들기](./create-account.md)부터 시작하세요.

## ChurchApps 제품

ChurchApps에는 서로 함께 작동하는 여러 제품이 있습니다.

- **B1 Admin** -- 교회 관리 대시보드입니다. 교인, 그룹, 출석, 헌금, 웹사이트 콘텐츠 등을 한곳에서 관리합니다. [B1 Admin 가이드](/docs/b1-admin/)
- **B1.church** -- 공개 교회 웹사이트이자 교인 포털입니다. 교인은 설교를 보고, 명부에 접근하고, 온라인으로 헌금하고, 교회와 계속 연결될 수 있습니다. [B1.church 가이드](/docs/b1-church/)
- **Lessons.church** -- 주일학교, 소그룹, 성경 공부를 위한 무료 교회 커리큘럼입니다. 계속 늘어나는 수업 라이브러리를 무료로 이용할 수 있습니다. [Lessons.church 가이드](/docs/lessons-church/)
- **FreePlay** -- 수업, 예배 영상, 공지를 교실과 복도의 TV(Fire TV, Android TV, Apple TV)에서 재생하는 무료 TV 앱입니다. 일정에 맞춰 재생할 수도 있습니다. [FreePlay 설정하기](/docs/freeplay/)
- **FreeShow** -- 예배를 위한 무료 프레젠테이션 소프트웨어입니다. 모임 중에 가사, 슬라이드, 미디어를 표시합니다. [freeshow.app](https://freeshow.app)
- **WorshipCommons** -- 교회가 무료로 부를 수 있는 열린 찬양 라이브러리입니다. 퍼블릭 도메인 찬송가와 작가들이 공유한 찬양을 코드 차트, 가사, 조옮김, 오디오와 함께 제공합니다. [worshipcommons.org](https://worshipcommons.org)

:::info
모든 ChurchApps 도구는 **100% 무료**이며 사용 제한, 유료 등급, 숨은 비용이 없습니다. ChurchApps는 기부와 자원봉사자의 도움으로 운영되는 비영리 단체입니다.
:::

## 이 문서가 다루는 내용

이 문서는 ChurchApps를 시작하고 사용하는 데 필요한 모든 것을 안내합니다. 다음을 배우게 됩니다.

1. 계정을 만들고 교회를 등록하기
2. 교회의 기본 설정과 브랜딩 구성하기
3. 올바른 역할과 권한으로 팀 구성하기
4. 도구를 사용해 교인을 관리하기 시작하기
