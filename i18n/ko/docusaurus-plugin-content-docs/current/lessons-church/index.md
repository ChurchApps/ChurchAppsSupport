# Lessons.church

<div class="article-intro">

Lessons.church는 교회를 위한 완전히 무료인 교과 과정 플랫폼입니다. 구독, 수수료, 사용 제한이 없습니다. 12개 이상의 제공업체에서 189개 이상의 연구를 통해 미취학부터 성인까지 모든 연령대를 포함하는 1,100개 이상의 동영상 기반 수업을 제공합니다.

</div>

## 할 수 있는 것

Lessons.church를 사용하여 교회는 다음을 수행할 수 있습니다:

- **콘텐츠 탐색** - 여러 제공업체의 성장하는 프로그램 및 연구 라이브러리를 탐색합니다. 연령대 및 주제별로 구성됩니다.
- **교실 설정** - 사역 구조와 일치하는 교실을 만듭니다 (예: 미취학부, 초등학교, 청소년 또는 성인).
- **수업 일정** - 필요한 날짜에 교실에 특정 수업을 할당합니다.
- **필요에 맞게 사용자 정의** - 수업 콘텐츠를 교회의 교수 스타일과 선호도에 맞게 조정합니다.
- **반 수업** - 기본 제공 발표자 모드를 사용하여 수업 중에 수업을 단계별로 진행합니다.

## 콘텐츠 구성 방법

Lessons.church는 명확한 계층에서 교과 과정을 구성합니다:

1. **프로그램** - 제공업체의 최상위 교과 과정 시리즈 (예: 어린이 사역 프로그램).
2. **연구** - 프로그램 내의 관련 수업 그룹 (예: 특정 주제의 4주 시리즈).
3. **수업** - 연구 내의 개별 교수 세션, 일반적으로 한 반 모임에 사용됩니다.
4. **장소** - 특정 연령대 또는 설정을 위해 맞춤화된 다양한 버전의 수업 (예: 미취학부 버전 및 초등학교 버전).

## 통합

Lessons.church는 콘텐츠 전달을 도우려면 다른 ChurchApps 도구와 함께 작동합니다:

- **B1.church** - 자원 봉사자와 부모는 B1 앱을 통해 예정된 수업 및 최근 수업에 액세스할 수 있습니다.
- **FreeShow** - FreeShow 프레젠테이션 소프트웨어를 사용하여 화면에 수업 콘텐츠를 표시합니다.
- **[FreePlay](https://freeplay.church)** - FreePlay 앱을 사용하여 Android TV, Fire TV 또는 Apple TV에서 TV에 수업을 직접 표시합니다.
