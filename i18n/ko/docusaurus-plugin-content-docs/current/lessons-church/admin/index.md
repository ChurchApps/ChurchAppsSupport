# 관리

<div class="article-intro">

Lessons.church의 관리 영역은 콘텐츠 작성자와 관리자가 레슨 라이브러리를 관리하는 곳입니다. 이곳에서 커리큘럼 구조를 구성하고, 리소스를 업로드하고, 사용 통계를 확인하며, 타사 콘텐츠 제공업체를 연결할 수 있습니다.

</div>

:::warning
관리 기능에 접근하려면 적절한 권한이 필요합니다. 관리 옵션이 보이지 않는다면 교회 관리자에게 문의하여 접근 권한을 요청하세요.
:::

## 할 수 있는 작업

관리 영역에서는 콘텐츠를 완전히 제어할 수 있습니다:

- **프로그램 만들기 및 편집** -- 이름, 설명, 이미지, 슬러그를 포함한 최상위 커리큘럼 시리즈를 설정합니다.
- **연구 관리** -- 각 프로그램 안에서 관련 레슨을 묶은 그룹을 구성합니다.
- **레슨 작성** -- 장소, 섹션, 역할, 작업을 포함한 개별 레슨을 추가합니다.
- **리소스 업로드** -- 프로그램, 연구 또는 레슨 단위에 다운로드 가능한 파일(PDF, 활동지, 이미지)을 첨부합니다.
- **통계 보기** -- 어떤 콘텐츠가, 누구에 의해, 어디에서 다운로드되었는지 확인합니다.
- **제공업체 구성** -- Open Lesson Format을 사용하는 외부 커리큘럼 제공업체를 연결합니다. 이 작업은 관리 영역이 아닌 **외부 제공업체** 페이지에서 진행합니다.
- **연간 계획** -- 모든 커리큘럼에 대해 1주차, 2주차, 3주차… 순서를 게시합니다. 교회는 B1 Admin에서 이를 적용합니다.

## 콘텐츠 구조

관리자라면 콘텐츠가 어떻게 구성되는지 이해해 두면 도움이 됩니다:

1. **프로그램**에는 하나 이상의 연구가 포함됩니다.
2. **연구**에는 하나 이상의 레슨이 포함됩니다.
3. **레슨**에는 하나 이상의 장소(연령대별 변형)가 포함됩니다.
4. **장소**에는 섹션이 포함되며, 섹션에는 역할 기반 작업이 포함됩니다.

각 단계마다 자체 다운로드 가능 리소스를 첨부할 수 있습니다.
