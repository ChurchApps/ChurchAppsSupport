# 관리
<div class="article-intro">
Lessons.church의 관리 영역은 콘텐츠 제작자와 관리자가 수업 라이브러리를 관리하는 곳입니다. 여기에서 교육 과정 구조를 만들고, 자료를 업로드하고, 사용 통계를 검토할 수 있습니다.
</div>

:::warning
관리 액세스에는 적절한 권한이 필요합니다. 관리 옵션이 보이지 않으면, 교회 관리자에게 액세스를 요청하세요.
:::

## 할 수 있는 것들

관리 영역은 콘텐츠에 대한 완전한 제어를 제공합니다:

- **프로그램 생성 및 편집** — 이름, 설명, 이미지, 슬러그가 있는 최상위 교육 과정 시리즈를 설정합니다
- **스터디 관리** — 각 프로그램 내에서 관련 수업 그룹을 구성합니다
- **수업 구축** — 장소, 섹션, 역할, 행동이 있는 개별 수업을 추가합니다
- **자료 업로드** — 프로그램, 스터디 또는 수업 수준에서 다운로드 가능한 파일을 첨부합니다
- **통계 보기** — 콘텐츠가 다운로드되는 내용과 위치를 확인합니다
- **제공자 구성** — Open Lesson Format을 사용하는 외부 교육 과정 제공자를 연결합니다
- **연간 계획** — 모든 교육 과정에 대해 주 1, 2, 3... 순서를 게시합니다

## 콘텐츠 계층 구조

콘텐츠는 다음과 같이 구조화됩니다:

1. **프로그램** — 하나 이상의 스터디를 포함합니다
2. **스터디** — 하나 이상의 수업을 포함합니다
3. **수업** — 하나 이상의 장소 (연령대 변형)를 포함합니다
4. **장소** — 섹션을 포함하고, 섹션은 역할 기반 행동을 포함합니다

각 수준은 자신의 다운로드 가능한 자료를 가질 수 있습니다.
