# 외부 제공자

<div class="article-intro">

Lessons.church는 Open Lesson Format을 통해 외부 커리큘럼 제공자를 지원합니다. 즉, 교회에서 다른 기관의 커리큘럼을 연결하여 기본 제공 라이브러리 바로 옆에서 교실별로 예약할 수 있습니다. 이를 통해 팀은 여러 출처의 커리큘럼을 한곳에서 활용할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 교회 교실 일정을 관리할 수 있는 계정으로 Lessons.church에 로그인하세요
- 연결하려는 외부 제공자에게서 피드 URL을 받으세요. 이 URL은 [Open Lesson Format](./open-lesson-format.md)으로 레슨을 반환해야 합니다

</div>

## 제공자 추가하기

1. Lessons.church 탐색 메뉴에서 **외부 제공자**를 클릭하세요. **외부 레슨 제공자** 페이지가 열립니다.
2. **제공자 추가**를 클릭하세요. 아직 추가한 제공자가 없다면 대신 **첫 번째 제공자 추가**를 클릭하세요.
3. **제공자 이름**을 입력하세요. 팀원이 제공자를 선택할 때 보게 되는 이름입니다.
4. **API URL**을 입력하세요. 제공자가 Open Lesson Format으로 커리큘럼을 게시하는 주소입니다.
5. **저장**을 클릭하세요.

제공자는 귀교회에만 추가됩니다. 이후 교실에 대해 [레슨 예약](../classrooms/scheduling-lessons.md)을 할 때 **제공자** 선택 항목에 나타나며, [연간 계획](./managing-year-plans.md)을 작성할 때는 **출처** 선택 항목에 나타납니다.

## 제공자 관리하기

**외부 레슨 제공자** 페이지에는 귀교회가 추가한 모든 제공자가 나열됩니다. 제공자를 변경하려면 다음을 따르세요.

- **수정** -- **제공자 수정**(연필) 아이콘을 클릭하고, **제공자 이름** 또는 **API URL**을 변경한 뒤 **저장**을 클릭하세요.
- **삭제** -- **제공자 수정** 아이콘을 클릭한 다음, 삭제(휴지통) 아이콘을 클릭하고 확인하세요.

## Open Lesson Format이란 무엇인가요?

Open Lesson Format은 프로그램, 연구, 레슨, 장소, 섹션, 활동 등 커리큘럼 콘텐츠를 구조화된 방식으로 설명하는 표준화된 스키마입니다. 이 형식을 사용해 콘텐츠를 게시하는 모든 기관은 Lessons.church에 제공자로 추가될 수 있습니다.

콘텐츠 제공자로서 Lessons.church를 통해 커리큘럼을 제공하는 데 관심이 있다면, 전체 스키마 문서는 [Open Lesson Format](./open-lesson-format.md) 가이드에서 확인할 수 있습니다.

## 외부 제공자를 사용하는 이유

- **교회를 위한 더 많은 선택지** -- 교회는 플랫폼을 벗어나지 않고도 더 다양한 커리큘럼을 살펴볼 수 있습니다.
- **모든 것을 한곳에서** -- 봉사자와 코디네이터는 레슨을 찾고 예약하기 위해 여러 웹사이트를 방문할 필요가 없습니다.
- **간편한 설정** -- 제공자 추가에는 이름과 피드 URL만 있으면 됩니다. 수동 데이터 입력이나 파일 업로드가 필요하지 않습니다.

:::info
외부 콘텐츠는 외부 제공자가 관리합니다. 제공자의 콘텐츠가 누락되었거나 오래된 것을 발견하면, 문제는 제공자 측에서 해결해야 할 수 있습니다.
:::

:::tip
외부 제공자의 레슨이 예약된 후 어떻게 보이는지 알아보려면, 브라우징 섹션의 [외부 제공자](../browsing/external-providers.md)를 참고하세요.
:::
