# 수업 관리
<div class="article-intro">
수업은 스터디 내의 개별 교육 세션입니다. 각 수업은 한 클래스 모임 동안 일어나는 일을 나타냅니다. 여기에서 자원봉사자가 가르칠 때 사용할 세부 콘텐츠를 구축합니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- [프로그램 생성](./managing-programs.md)하고 [스터디 추가](./managing-studies.md)합니다
- Lessons.church에 대한 관리자 권한이 필요합니다
</div>

## 수업 생성

1. **관리** 영역으로 이동합니다
2. 프로그램을 확장하고 스터디를 찾습니다
3. **수업 추가**를 클릭합니다
4. 수업의 **이름**과 기타 세부 정보를 입력합니다
5. 수업을 저장합니다

## 부모 가져가기

각 수업에는 선택적인 **부모 가져가기** 섹션이 있습니다. 이러한 필드는 부모가 B1 그룹에서 클래스 후에 보는 내용입니다:

| 필드 | 목적 |
|---|---|
| **요점** | 한 문장. "하나님은 그의 약속을 지킵니다." |
| **구절** | 암송 구절 참고 및 짧은 텍스트 |
| **질문** | 부모가 어떤 PDF 없이 묻을 수 있는 한 질문 |
| **선택적 주** | 추가 (기도 신청, 가족 활동). 마크다운 |

## 수업 구조 이해

각 수업은 여러 계층으로 구조화됩니다:

- **장소** — 서로 다른 연령대 또는 설정을 위한 다른 버전
- **섹션** — "환영", "비디오", "성경 이야기", "활동" 등의 세그먼트
- **역할과 행동** — 각 섹션에서 역할 (예: "리드 교사" 또는 "소그룹 리더)을 할당하고 특정 행동을 제공합니다

## 행동 유형

네 가지 유형의 행동을 역할에 할당할 수 있습니다:

- **말하기** — 자원봉사자가 말하거나 바꿔 말할 텍스트
- **하기** — 물리적 활동 또는 실행 지침
- **주의** — 배경 정보 또는 자원봉사자를 위한 알림 (큰 목소리로 읽지 않음)
- **재생** — 섹션 중에 재생할 비디오 또는 오디오 클립

## 장소 추가

1. 관리 보기에서 수업을 엽니다
2. **장소 추가**를 클릭합니다
3. 장소의 이름을 입력합니다 (예: "미취학", "초등학교")
4. 저장합니다. 이제 이 장소에 섹션을 추가할 수 있습니다

## 섹션 및 행동 추가

1. 장소를 확장하여 섹션을 봅니다
2. **섹션 추가**를 클릭하고 이름을 입력합니다
3. 섹션 내에서 **행동 추가**를 클릭합니다
4. **역할**, **행동 유형**, 콘텐츠를 선택합니다
5. 저장합니다
