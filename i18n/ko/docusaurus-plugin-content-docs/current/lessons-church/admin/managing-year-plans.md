# 연간 계획 관리

<div class="article-intro">

Lessons.church에서 연간 교육 계획을 관리합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- Lessons.church 계정 필요
- 관리자 권한 필요

</div>

## 연간 계획 생성

1. Lessons.church에 로그인합니다
2. **계획** 섹션으로 이동합니다
3. **새 연간 계획**을 클릭합니다
4. 연도를 선택합니다
5. 수업을 추가합니다
6. **저장**을 클릭합니다

## 계획 편집

1. 기존 계획을 선택합니다
2. 수업을 추가하거나 편집합니다
3. 변경사항을 **저장**합니다
