# 클래스룸 설정하기

<div class="article-intro">

레슨 일정을 잡으려면 먼저 교육 공간을 나타내는 클래스룸을 만들어야 합니다. 이 가이드는 Lessons.church 포털에서 클래스룸을 만들고, 이름을 짓고, 관리하는 방법을 안내합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [계정 만들기](../getting-started/creating-account.md)를 하고 교회와 연결하기
- [포털 개요](../getting-started/portal-overview.md)를 살펴보기

</div>

## 클래스룸 만들기

1. [Lessons.church](https://lessons.church)에서 계정에 로그인합니다.
2. **포털**로 이동합니다. 이곳은 교회의 클래스룸과 일정을 관리하는 중앙 허브입니다.
3. **클래스룸** 상자에서 **추가**를 클릭합니다. 아직 클래스룸이 하나도 없다면 대신 **첫 클래스룸 추가**를 클릭합니다.
4. **클래스룸 이름**을 입력합니다. 봉사자들이 쉽게 알아볼 수 있는 설명적인 이름을 고르세요. 예를 들어 "유치부", "초등 1~2학년", "중등부" 같은 이름이 좋습니다.
5. **저장**을 클릭합니다. 새 클래스룸이 바로 **클래스룸** 목록에 나타납니다.

교회의 각 교실이나 연령별 그룹마다 이 단계를 반복하세요. 필요한 만큼 클래스룸을 얼마든지 만들 수 있습니다.

## 처음 설정하기

아직 클래스룸을 설정하지 않았다면 포털에 설정 과정을 안내하는 설정 동영상이 표시됩니다. 이 동영상은 클래스룸을 만드는 기본 방법과 첫 레슨 일정을 잡는 방법을 다룹니다. Lessons.church를 처음 사용하신다면 좋은 출발점이 됩니다.

:::tip
봉사자들이 이미 교실을 부르는 방식에 맞춰 클래스룸 이름을 지으세요. 모두가 "유아실"이라고 부른다면 "영유아 교육 101호실"처럼 formal한 이름보다 "유아실"이라고 이름 짓는 것이 좋습니다.
:::

## 클래스룸 관리하기

클래스룸은 포털 대시보드에 표시되며, 언제든지 여기에서 관리할 수 있습니다. 대시보드에서 다음과 같은 작업을 할 수 있습니다.

- **클래스룸 이름 바꾸기** -- 해당 클래스룸 옆의 **클래스룸 편집**(연필) 아이콘을 클릭하고, **클래스룸 이름**을 변경한 뒤 **저장**을 클릭합니다.
- **클래스룸 삭제하기** -- **클래스룸 편집**을 클릭한 다음, **클래스룸 삭제**(휴지통) 아이콘을 클릭하고 확인합니다.
- **일정 보기** -- 클래스룸을 클릭하면 해당 클래스룸의 레슨 일정을 볼 수 있습니다.

## 다음 단계

클래스룸 설정이 끝나면 봉사자들이 매주 무엇을 가르쳐야 할지 알 수 있도록 [레슨 일정 잡기](./scheduling-lessons.md)를 시작할 준비가 된 것입니다.
