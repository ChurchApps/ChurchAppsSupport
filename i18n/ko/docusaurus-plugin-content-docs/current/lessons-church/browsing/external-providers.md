# 외부 제공자

<div class="article-intro">

Lessons.church는 자체 교육과정에만 국한되지 않습니다. 타사 교육과정 제공자는 **개방형 레슨 형식(Open Lesson Format)**을 통해 콘텐츠를 게시할 수 있습니다. 교회가 제공자를 추가하면, Lessons.church 라이브러리 바로 옆에서 해당 제공자의 레슨을 교실용으로 예약할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [프로그램과 학습 과정](./programs-and-studies.md)을 읽고 콘텐츠가 어떻게 구성되는지 이해하세요.
- 제공자 연결을 추가하려면 교회의 교실 일정에 접근할 수 있는 [Lessons.church 계정](../getting-started/creating-account.md)이 필요합니다.

</div>

## 외부 제공자란?

외부 제공자는 개방형 레슨 형식(Open Lesson Format)을 사용해 교회 교육과정을 게시하는 모든 단체를 말합니다. 개방형 레슨 형식은 레슨 콘텐츠를 여러 플랫폼에서 공유할 수 있도록 하는 표준입니다. 제공자가 이 형식으로 콘텐츠를 제공하면, Lessons.church는 이를 읽어 자체 레슨과 동일한 레이아웃으로 표시할 수 있습니다.

이를 통해 여러 웹사이트를 방문하지 않고도 더 다양한 교육과정을 이용할 수 있습니다.

## 제공자 연결 추가하기

교회에서 개방형 레슨 형식을 지원하는 교육과정 제공자를 사용하는 경우:

1. Lessons.church 계정에 로그인합니다.
2. 내비게이션에서 **External Providers**를 클릭합니다.
3. **Add Provider**를 클릭하고, **Provider Name**과 제공자의 **API URL**을 입력한 뒤 **Save**를 클릭합니다.

전체 절차는 [타사 제공자](../admin/third-party-providers.md)를 참고하세요.

:::info
외부 제공자는 교회에만 추가됩니다. 해당 제공자의 프로그램은 Lessons.church 공개 홈페이지나 검색 결과에 표시되지 않습니다.
:::

## 외부 콘텐츠 사용하기

제공자가 추가되면, 일정을 잡을 때 해당 제공자의 프로그램, 학습 과정, 레슨을 사용할 수 있습니다.

1. [교실 일정에 레슨 추가](../classrooms/scheduling-lessons.md)를 할 때 **Provider**에서 제공자를 선택합니다.
2. Lessons.church 레슨과 같은 방식으로 **Program**, **Study**, **Lesson**, **Venue**를 선택합니다.
3. 교실 일정에서 예약된 외부 레슨 아래의 **View Lesson**을 클릭하면 레슨이 열립니다. 기본 제공 레슨과 동일한 레이아웃(섹션, 역할, 작업, 영상, 다운로드 가능한 자료)을 사용합니다.

:::note
외부 제공자의 레슨은 [사용자 지정](../customization/customizing-lessons.md)할 수 없습니다. **Customize** 링크는 Lessons.church 레슨에만 표시됩니다.
:::

## 콘텐츠 제작자를 위한 안내

Lessons.church에 콘텐츠를 제공하는 데 관심이 있는 교육과정 게시자라면, 개방형 레슨 형식을 통해 프로그램, 학습 과정, 레슨을 표준화된 방식으로 공유할 수 있습니다. 연동에 대한 자세한 내용은 Lessons.church 팀에 문의하거나 개발자 문서를 참고하세요.

:::tip
제공자를 추가, 수정, 삭제하는 단계별 안내는 [타사 제공자](../admin/third-party-providers.md)를 참고하세요.
:::
