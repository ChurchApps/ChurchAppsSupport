# 검색

<div class="article-intro">

가르치고 싶은 주제는 알고 있지만 어떤 프로그램이나 학습 과정에 포함되어 있는지 확실하지 않을 때, 검색 기능을 사용하면 적합한 콘텐츠를 빠르게 찾을 수 있습니다. 검색은 Lessons.church 라이브러리의 프로그램, 학습 과정 및 공과 전반에서 작동합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 이용 가능한 모든 탐색 옵션을 이해하기 위해 [콘텐츠 탐색](./index.md) 개요를 숙지하십시오

</div>

## 검색하는 방법

1. Lessons.church 사이트 상단의 **검색** 아이콘을 클릭하여 검색 상자를 엽니다.
2. 키워드나 구문을 입력합니다(예: "용서", "다윗과 골리앗", "기도"). 입력하는 동안 일치하는 결과가 상자 아래 목록에 나타나며, 하나를 클릭하면 바로 이동합니다.
3. **Enter** 키를 누르면 전체 검색 결과 페이지가 열립니다.

## 검색 작동 방식

검색은 Lessons.church 라이브러리의 모든 프로그램, 학습 과정, 공과의 이름, 설명, 카테고리 및 연령대를 검색합니다. 단어의 시작 부분도 일치하므로 "bapt"는 "baptism"을 찾습니다. 이름에서의 일치가 가장 중요하며, 프로그램과 학습 과정은 개별 공과보다 약간 앞에 순위가 매겨집니다. 외부 공급자의 콘텐츠는 검색 결과에 포함되지 않습니다.

## 결과 탐색하기

각 결과에는 **프로그램**, **학습 과정** 또는 **공과** 표시가 있으며, 연령대가 설정된 경우 함께 표시됩니다. 학습 과정은 속한 프로그램을, 공과는 학습 과정과 프로그램을 보여 줍니다. 결과를 클릭하면 해당 페이지로 바로 이동합니다. 공과 페이지에는 전체 콘텐츠, 섹션, 역할, 다운로드 가능한 자료가 표시됩니다.

## 검색을 사용할 때

검색은 다음과 같은 경우에 가장 유용합니다:

- 특정 성경 이야기나 주제를 염두에 두고 있으며 이를 다루는 모든 이용 가능한 커리큘럼을 보고 싶을 때.
- 특별 시리즈를 계획하고 있으며 특정 주제에 대한 공과를 찾아야 할 때.
- 아직 이용 가능한 프로그램에 익숙하지 않으며 제공되는 내용을 빠르게 탐색하고 싶을 때.

:::tip
단어를 더 많이 포함하는 결과가 상위에 옵니다. 원하는 결과가 아래쪽에 있다면 구체적인 단어를 하나 더 추가해 보십시오. 예를 들어 "선한 사마리아인"을 검색하면 그 비유에 관한 공과가 맨 위로 올라옵니다.
:::

이미 원하는 프로그램을 알고 있다면 프로그램별 탐색이 보통 더 빠릅니다. 콘텐츠 계층 구조 탐색에 대한 자세한 내용은 [프로그램과 학습 과정](./programs-and-studies.md)을 참조하십시오.
