# 포털 개요

<div class="article-intro">

Lessons.church에 로그인하면 **Portal**(포털)으로 이동합니다. 포털은 교회의 교실과 수업 일정을 관리하는 대시보드입니다. 교회의 커리큘럼을 준비할 때 대부분의 시간을 이곳에서 보내게 됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [계정을 만들고](./creating-account.md) 교회에 연결하세요
- [Lessons.church](https://lessons.church)에 로그인하세요

</div>

## 화면 구성

포털은 **Classroom Management** 페이지로 열리며, 두 개의 주요 영역으로 구성되어 있습니다:

- **Classrooms** (오른쪽) — 교회의 교실 목록입니다. 교실 이름을 클릭하면 예정된 수업을 볼 수 있습니다. 여기에서 새 교실을 추가하거나 기존 교실을 수정할 수도 있습니다.
- **Lesson Schedule** (왼쪽) — 교실을 선택하면 해당 교실에 예정된 수업이 이 영역에 표시됩니다. 아직 교실을 설정하지 않았다면, 시작하는 데 도움이 되는 설정 안내 동영상이 나타납니다.

## 포털에서 할 수 있는 작업

포털에서 다음 작업을 할 수 있습니다:

1. **교실 관리** — 교실을 추가, 수정 또는 삭제합니다. 각 교실은 봉사자 팀(B1 앱에서 다가오는 수업을 확인할 수 있도록)과 학부모/학생 그룹(최근 수업에 접근할 수 있도록)에 연결할 수 있습니다. 여전히 이 교실 일정 방식을 사용하는 교회의 경우, 학부모는 교실 페이지를 `?upcoming=1` 없이 열어 가정으로 가져갈 콘텐츠를 볼 수 있습니다. B1Admin 플랜 유형을 사용하는 교회는 B1에서 연결된 그룹 페이지에서 가정용 콘텐츠 카드를 확인합니다.
2. **예정된 수업 보기 및 관리** — 각 교실에 앞으로 어떤 수업이 예정되어 있는지 확인하고, 필요에 따라 변경합니다.
3. **교실 피드 구독** — 교실 옆의 피드 아이콘을 클릭하면, 호환되는 앱에서 사용할 수 있는 재생목록 피드 URL을 받을 수 있습니다.
4. **External Providers 접근** — **External Providers** 페이지에서 Open Lesson Format을 지원하는 외부 콘텐츠 제공처를 설정합니다. 이를 통해 Lessons.church 기본 라이브러리 외의 다른 제공처에서도 수업을 가져올 수 있습니다.
5. **Admin 영역 접근** — 관리자 권한이 있다면 내비게이션에 **Admin** 옵션이 표시됩니다. Admin 영역에서는 콘텐츠 수준에서 프로그램, 스터디, 수업을 관리할 수 있습니다.

## 내비게이션

포털 내비게이션에는 다음 항목이 있습니다:

- **Home** — 공개 Lessons.church 홈페이지로 돌아가 콘텐츠를 둘러볼 수 있습니다.
- **Schedules** — 교실과 수업 일정을 관리하는 포털의 기본 화면입니다.
- **External Providers** — 외부 수업 제공처를 설정합니다.
- **Admin** — 프로그램, 스터디, 수업 콘텐츠를 관리합니다(콘텐츠 편집 권한이 있는 경우에만 표시됩니다).

:::info
**Admin** 옵션은 계정에 콘텐츠 편집 권한이 부여된 경우에만 나타납니다. 대부분의 교회 직원은 일상적인 관리를 위해 **Schedules** 및 **External Providers** 페이지를 사용하게 됩니다.
:::

## 시작하기

포털을 처음 방문했고 아직 교실을 만들지 않았다면, 교실 패널에서 **Add First Classroom**을 클릭하는 것부터 시작하세요. 교실 이름(예: "유치부" 또는 "3~5학년")을 입력하고 저장합니다. 그다음 [수업 예약하기](../classrooms/scheduling-lessons.md)를 진행할 수 있습니다.
