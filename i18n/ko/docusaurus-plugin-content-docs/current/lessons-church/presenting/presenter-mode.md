# 발표자 모드

<div class="article-intro">

발표자 모드는 수업을 전체 화면, 프로젝션 친화적 디스플레이로 변환합니다. 교실 화면, 프로젝터 또는 TV에서 수업 콘텐츠를 보여주도록 설계되어 있어서 모든 사람이 수업 중에 따라올 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [수업을 교실에 일정 지정](../classrooms/scheduling-lessons.md)하거나 [콘텐츠 라이브러리](../browsing/index.md)를 통해 수업으로 이동합니다
- 디스플레이 (프로젝터, TV 또는 모니터)가 연결되고 구성되었는지 확인합니다

</div>

## 발표자 모드에 진입

1. 제공할 수업을 엽니다.
2. 수업 페이지의 **발표** 버튼을 클릭합니다.
3. 수업이 검은색 배경과 크고 읽기 쉬운 텍스트가 있는 전체 화면 보기로 전환됩니다.

발표자 모드에 있으면 화면 탐색 컨트롤을 사용하여 수업 섹션별로 이동할 수 있습니다.

## 모양

발표자 모드는 깨끗한 어두운 배경을 사용하므로 콘텐츠가 투사 화면에서 두드러집니다. 수업의 각 섹션이 한 번에 표시되어 현재 활동에 집중합니다. 텍스트, 이미지 및 동영상 포함은 모두 방의 전체에서 읽을 수 있도록 형식화됩니다.

## FreeShow와 함께 사용

Lessons.church는 [FreeShow](https://freeshow.app)라는 무료 프레젠테이션 애플리케이션과 통합됩니다. FreeShow는 Lessons.church에서 수업 콘텐츠를 직접 가져와 수업 슬라이드를 기존 프레젠테이션 워크플로우에 통합할 수 있습니다. 이미 경배 가사나 공지사항에 FreeShow를 사용하는 경우 특히 유용합니다.

## FreePlay와 함께 사용

**[FreePlay](https://freeplay.church)**를 사용하면 별도의 컴퓨터 없이 TV에서 수업을 표시할 수 있습니다. Android TV, Fire TV 또는 Apple TV 장치에 앱을 설치하고, Lessons.church 교실에 연결하면 예정된 수업이 자동으로 나타납니다. 이것은 전용 화면이 있는 교실을 위한 훌륭한 핸즈프리 옵션입니다. [FreePlay 문서](/docs/freeplay/)에서 설정을 참조합니다.

:::tip
프로젝터를 사용 중인 경우 발표자 모드에 진입하기 전에 프로젝터로 미러 또는 확장되도록 설정되었는지 확인합니다. 이것은 전체 화면 보기가 올바른 화면에 나타나도록 합니다.
:::

## 발표자 모드 종료

발표자 모드를 종료하려면 **Escape** 키를 누르거나 화면 모서리의 종료 버튼을 클릭합니다. 일반 수업 보기로 돌아갑니다.
