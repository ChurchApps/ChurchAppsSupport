# 레슨 맞춤 설정

<div class="article-intro">

이 가이드에서는 교실에 맞게 레슨을 맞춤 설정하는 방법을 안내합니다. 맞춤 설정을 사용하면 콘텐츠를 제거하거나 순서를 바꿔 자원봉사자가 필요한 내용만 정확히 볼 수 있습니다. 더 많지도, 더 적지도 않게 말입니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 포털에서 [교실을 최소 하나 설정](../classrooms/setting-up-classrooms.md)하세요
- 맞춤 설정하려는 교실에 [레슨을 예약](../classrooms/scheduling-lessons.md)하세요
- [맞춤 설정 개요](./index.md)를 읽고 어떤 항목을 맞춤 설정할 수 있는지 확인하세요

</div>

## 맞춤 설정 화면 열기

1. 로그인한 후 **포털**로 이동합니다.
2. 맞춤 설정하려는 레슨이 있는 **교실**을 선택합니다.
3. 교실 일정에서 레슨을 찾아 레슨 이름 아래의 **맞춤 설정**을 클릭합니다.

**레슨 맞춤 설정** 페이지에는 레슨의 섹션 목록이 표시되며, 각 섹션 아래에는 역할과 각 역할의 작업이 나열됩니다. 각 행의 오른쪽에는 다음 버튼이 있습니다.

- **위쪽 화살표**와 **아래쪽 화살표** -- 항목을 이웃 항목과 한 칸씩 위 또는 아래로 이동합니다
- **삭제**(휴지통) -- 항목을 제거합니다

:::info
**맞춤 설정**은 Lessons.church 레슨에만 표시됩니다. 외부 제공업체에서 예약한 레슨에는 대신 **레슨 보기**가 표시되며 맞춤 설정할 수 없습니다.
:::

## 변경 사항의 적용 범위 선택하기

화살표나 휴지통 아이콘을 클릭하면 **선택한 맞춤 설정 적용 대상:** 메뉴가 나타납니다.

- **이 교실** -- 변경 사항이 현재 교실에만 적용됩니다. 다른 교실에는 영향을 주지 않습니다.
- **모든 교실** -- 변경 사항이 교회의 모든 교실에 적용됩니다.

하나를 선택하면 변경 사항이 바로 저장됩니다. 별도의 저장 단계는 없습니다.

## 섹션 제거하기

섹션이 교실에 맞지 않는다면 전체를 제거할 수 있습니다. 레슨에 여러 연령대를 위한 콘텐츠가 포함되어 있고 그중 하나만 필요할 때 유용합니다. 예를 들어 레슨에 “유아 활동” 섹션과 “초등 활동” 섹션이 모두 있다면, 교실에 맞지 않는 쪽을 제거할 수 있습니다.

1. 제거하려는 섹션을 찾습니다.
2. 해당 섹션의 **삭제**(휴지통) 버튼을 클릭합니다.
3. **이 교실** 또는 **모든 교실**을 선택합니다.

섹션은 제거된 상태로 표시되며, 그 안의 모든 역할과 작업도 함께 제거됩니다. 자원봉사자는 이 레슨에서 해당 섹션을 더 이상 보지 않습니다.

## 역할이나 작업 제거하기

섹션 안에서 특정 역할이나 작업만 제거할 수도 있습니다. 예를 들어 섹션에 “예배 인도자” 역할이 있지만 교실에 그 역할이 없다면, 섹션 전체를 제거하지 않고 해당 역할만 제거할 수 있습니다.

1. 섹션 아래 목록에서 역할이나 작업을 찾습니다.
2. 해당 항목의 **삭제**(휴지통) 버튼을 클릭하고 변경 사항의 적용 범위를 선택합니다.

## 콘텐츠 순서 바꾸기

섹션, 역할, 작업의 순서를 원하는 흐름에 맞게 바꿀 수 있습니다.

1. 이동하려는 항목의 **위쪽 화살표** 또는 **아래쪽 화살표**를 클릭합니다.
2. 변경 사항의 적용 범위를 선택합니다. 항목이 이웃 항목과 자리를 바꿉니다.

원하는 순서가 될 때까지 반복합니다. 새 순서는 자원봉사자가 레슨을 볼 때 보이는 순서입니다.

## 제거 취소하기

제거한 항목을 다시 표시하려면 해당 항목의 **삭제** 버튼을 다시 클릭합니다. 이제 메뉴에 **없음** 옵션이 추가로 표시됩니다. **없음**을 선택하면 제거가 해제되고 항목이 다시 표시되며, 다른 옵션을 선택하면 제거의 적용 범위를 바꿀 수 있습니다.

:::tip
먼저 한 교실의 레슨 하나를 맞춤 설정해 보세요. 과정에 익숙해지면 모든 교실에 맞춤 설정을 더 넓게 적용할 수 있습니다.
:::

## 맞춤 설정이 유용한 경우

맞춤 설정은 다음과 같은 경우에 가장 유용합니다.

- 레슨에 여러 연령대를 위한 콘텐츠가 있고 관련 부분만 보여주고 싶을 때
- 교실에서 특정 역할(예: 전담 예배 인도자나 기술 자원봉사자)을 사용하지 않을 때
- 기본 제공 순서와 다른 순서로 레슨 흐름을 구성하고 싶을 때

:::info
모든 레슨을 맞춤 설정할 필요는 없습니다. 콘텐츠가 교실에 그대로 맞는다면 이 단계를 건너뛰고 바로 [발표하기](../presenting/index.md)로 넘어가면 됩니다.
:::
