# 커스터마이징

<div class="article-intro">

Lessons.church는 바로 사용할 수 있는 레슨 콘텐츠 라이브러리를 제공하지만, 교회마다 상황은 다릅니다. 커스터마이징 기능을 사용하면 특정 교실, 가르치는 방식, 연령대에 맞게 레슨 콘텐츠를 조정할 수 있으므로 봉사자들은 자신에게 관련 있는 내용만 보게 됩니다.

</div>

## 커스터마이징이 필요한 이유

Lessons.church의 레슨 콘텐츠는 유연하게 사용할 수 있도록 설계되었습니다. 하나의 레슨에는 여러 연령대를 위한 섹션, 선택 활동, 또는 모든 교실에 해당하지 않는 역할이 포함될 수 있습니다. 봉사자들에게 해당하지 않는 부분을 일일이 건너뛰도록 하는 대신, 레슨을 커스터마이징하여 자신에게 관련 있는 내용만 보이도록 할 수 있습니다.

예를 들어, 레슨에 미취학 아동에게는 잘 맞지만 5학년 교실에는 적합하지 않은 공예 활동이 포함되어 있을 수 있습니다. 커스터마이징을 사용하면 나이가 많은 그룹에서는 해당 섹션을 숨기고, 어린 그룹에서는 그대로 유지할 수 있습니다.

## 커스터마이징할 수 있는 항목

- **섹션 제거** -- 특정 교실이나 연령대에 해당하지 않는 레슨의 섹션 전체를 제거합니다.
- **역할 또는 활동 제거** -- 필요하지 않은 섹션 내의 개별 역할이나 활동을 제거합니다.
- **콘텐츠 순서 변경** -- 교실에서 원하는 흐름에 맞게 섹션과 활동의 순서를 재배치합니다.

## 교실별 또는 전체 적용

변경할 때마다 적용 범위를 선택할 수 있습니다.

- **이 교실만** -- 변경 사항은 현재 교실에만 적용됩니다. 다른 교실에서는 원래 콘텐츠가 표시됩니다.
- **모든 교실** -- 변경 사항이 교회의 모든 교실에 적용됩니다.

이러한 유연성 덕분에 같은 레슨을 연령대별로 다르게 설정하거나, 모든 교실에 한 번에 적용되는 변경을 할 수 있습니다.

:::tip
커스터마이징이 처음이라면, 모든 교실에 변경 사항을 적용하기 전에 한 교실에서 먼저 사용해 보며 작동 방식을 익혀 보시기 바랍니다.
:::
