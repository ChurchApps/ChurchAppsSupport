# 프린터 설정
<div class="article-intro">
B1 Church Checkin은 네트워크 라벨 프린터에 이름표와 부모 픽업 슬립을 인쇄할 수 있습니다. 프린터 설정은 선택사항입니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- [로그인](./logging-in)하여 B1 Church Checkin 앱에서 교회를 선택합니다
- 호환되는 네트워크 라벨 프린터를 태블릿과 동일한 Wi-Fi 네트워크에 연결합니다
</div>
## 추천 라벨
B1 Checkin의 기본 라벨 템플릿은 **1.1" × 3.5"** 라벨용입니다.
**Brother QL 프린터**를 사용하는 경우, **Brother DK-1201** 라벨(1.1" × 3.5")을 사용해야 합니다.
## 프린터 설정 접근
프린터 설정 화면에는 언제든지 **관리자 설정** 메뉴를 통해 접근할 수 있습니다:
1. **교회 로고**를 빠르게 7번 탭합니다 (2초 이내)
2. 키오스크 PIN이 설정된 경우 PIN을 입력합니다
3. 관리자 설정 화면에서 **프린터 변경**을 탭합니다
## 프린터 검색
프린터 설정 화면이 열리면, 앱이 자동으로 로컬 네트워크에서 호환되는 프린터를 검색합니다.
## 테스트 인쇄
프린터를 선택한 후, 연결을 확인할 수 있습니다:
1. 원하는 프린터를 선택합니다
2. 화면 아래 **테스트 인쇄** 버튼을 탭합니다
3. 앱이 테스트 라벨을 프린터로 보냅니다
## 선택 저장
만족하면:
1. 화면 아래 **저장 및 재시작** 버튼을 탭합니다
2. 앱이 프린터 선택을 저장하고 재시작합니다
## 다음 단계
프린터를 구성하면, [체크인 워크플로우](../check-in/)를 시작할 준비가 됩니다.
