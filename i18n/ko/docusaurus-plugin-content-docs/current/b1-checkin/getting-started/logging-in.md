# 로그인

<div class="article-intro">

키오스크를 체크인에 사용하려면 먼저 교회에 접근 권한이 있는 ChurchApps 계정으로 로그인해야 합니다. 이 페이지에서는 처음 로그인하는 절차, 교회 선택, 자동 로그인 동작, 그리고 로그아웃 방법을 다룹니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- Android 태블릿에 B1 Church Checkin을 설치하세요([시작하기](./index.md) 참고).
- ChurchApps 계정의 이메일과 비밀번호를 준비하세요.

</div>

## 처음 로그인하기

1. B1 Church Checkin 앱을 엽니다. 스플래시 화면이 지나면 B1 Church Checkin 로고가 있는 로그인 화면이 나타납니다.
2. 첫 번째 필드에 **이메일 주소**를 입력합니다.
3. 두 번째 필드에 **비밀번호**를 입력합니다.
4. **Login** 버튼을 탭합니다.

앱이 자격 증명을 확인하고 로그인시킵니다. 이메일이나 비밀번호가 틀리면 화면 하단에 오류 메시지가 나타납니다.

계정에 [이중 인증 로그인](../../b1-admin/profile/managing-profile.md#two-factor-sign-in)이 켜져 있다면, 앱은 이어서 코드를 요청합니다. 계정 소유자의 인증 앱에 표시된 6자리 코드나 백업 코드 중 하나를 입력하고, **Login**을 다시 탭하세요. 이 코드는 처음 로그인할 때만 필요하며, 그 후에는 키오스크가 로그인 상태를 유지합니다.

:::info
B1 Admin이나 다른 ChurchApps 제품에 사용하는 이메일과 비밀번호와 같습니다. 체크인 키오스크를 위해 별도의 계정을 만들 필요는 없습니다.
:::

## 교회 선택하기

로그인에 성공하면 앱은 계정에 연결된 교회 목록을 불러옵니다. 각 교회는 교회 이름과 로고(B1 Admin에서 설정한 경우)가 표시된 카드로 나타납니다.

- 계정이 **교회 하나에만** 연결되어 있더라도 선택 화면이 나타납니다. 교회를 탭하여 계속 진행하세요.
- 계정이 **여러 교회에** 연결되어 있다면, 이 키오스크가 서비스할 교회를 탭하세요.

교회를 선택하면 앱은 그 교회의 브랜딩과 외관 설정을 불러옵니다. 이후 모든 화면의 머리글에 교회 로고가 표시됩니다.

## 다음번 방문 시 자동 로그인

처음 로그인에 성공한 후, 앱은 안전한 로그인 토큰과 선택한 교회를 태블릿에 저장합니다. 비밀번호는 저장하지 않습니다. 다음번 실행부터는 다음과 같이 동작합니다.

- 앱이 저장된 토큰으로 자동 로그인합니다.
- 이전에 교회를 선택했다면 그 선택을 복원하고 **services screen**(예배 화면)으로 바로 이동합니다.
- 저장된 로그인이 더 이상 유효하지 않으면, 앱은 다시 로그인할 수 있도록 로그인 화면으로 돌아갑니다.

:::tip
키오스크는 자동으로 로그인하므로, 자격 증명은 초기 설정 때 한 번만 입력하면 됩니다. 그 후에는 태블릿을 켜기만 하면 바로 사용할 준비가 됩니다.
:::

## 관리자 설정

키오스크를 사용하는 교인이 실수로 설정을 바꾸지 않도록, 관리자 설정은 의도적으로 숨겨져 있습니다. 접근하려면 다음과 같이 하세요.

1. 머리글의 **교회 로고**를 빠르게 **7번** 연속으로 탭합니다(2초 이내).
2. 키오스크 PIN이 설정되어 있다면, 요청이 나타날 때 PIN을 입력합니다.
3. **Admin Settings** 화면이 열리며 다음 옵션이 표시됩니다.
   - **Change Service** -- 선택한 예배 시간을 바꿉니다.
   - **Change Printer** -- [프린터 설정](./printer-setup)을 열어 프린터를 검색하고 선택합니다.
   - **Set/Change PIN** -- 관리자 접근을 보호하는 키오스크 PIN을 설정하거나 변경합니다.
   - **Logout** -- 로그아웃하고 로그인 화면으로 돌아갑니다.

:::warning
로그아웃하면 저장된 모든 자격 증명과 교회 선택이 지워집니다. 키오스크를 다시 사용하려면 이메일과 비밀번호를 다시 입력해야 합니다. 계정을 바꾸거나 키오스크를 다시 설정해야 할 때만 로그아웃하세요.
:::
