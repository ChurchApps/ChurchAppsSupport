# 로그인하기

<div class="article-intro">

키오스크로 체크인하려면 먼저 교회에 접근 권한이 있는 ChurchApps 계정으로 로그인해야 합니다. 이 페이지에서는 처음 로그인하는 방법, 교회 선택, 자동 로그인 동작, 로그아웃 방법을 다룹니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- Android 태블릿에 B1 Church Checkin을 설치하세요([시작하기](./index.md) 참고).
- ChurchApps 계정의 이메일과 비밀번호를 준비하세요.
- 계정에 교회에서 **Checkin** 권한(또는 **Edit Attendance**)이 있어야 합니다. 관리자가 B1 Admin의 **설정 > 역할**에서 추가합니다. [체크인 키오스크 계정](../../b1-admin/settings/roles-permissions.md#check-in-kiosk-accounts)을 참고하세요.

</div>

## 처음 로그인하기

1. B1 Church Checkin 앱을 여세요. 시작 화면이 지나면 B1 Church Checkin 로고가 있는 로그인 화면이 나타납니다.
2. 첫 번째 칸에 **이메일 주소**를 입력하세요.
3. 두 번째 칸에 **비밀번호**를 입력하세요.
4. **Login** 버튼을 누르세요.

앱이 자격 증명을 확인하고 로그인합니다. 이메일이나 비밀번호가 맞지 않으면 화면 하단에 오류 메시지가 나타납니다.

계정에 [2단계 로그인](../../b1-admin/profile/managing-profile.md#two-factor-sign-in)이 켜져 있다면, 앱이 이어서 코드를 요청합니다. 계정 소유자의 인증 앱에 표시된 6자리 코드나 백업 코드 중 하나를 입력하고 **Login**을 다시 누르세요. 이 코드는 처음 로그인할 때만 필요하며, 그 뒤로는 키오스크가 로그인 상태를 유지합니다.

:::info
B1 Admin이나 다른 ChurchApps 제품에서 사용하는 이메일과 비밀번호와 같습니다. 체크인 키오스크를 위해 별도의 계정을 만들 필요는 없습니다.
:::

## 교회 선택하기

로그인에 성공하면 앱은 계정에 **Checkin** 또는 **Edit Attendance** 권한이 있는 교회를 불러옵니다. 다른 권한만 있는 교회는 목록에서 제외됩니다. 남은 교회가 하나도 없으면 앱에 **No check-in access**가 표시되며, 교회 관리자에게 역할 중 하나에 Checkin 권한을 추가해 달라고 요청하라는 안내가 나옵니다. 각 교회는 교회 이름과 로고(B1 Admin에서 설정한 경우)가 있는 카드로 표시됩니다.

- 계정이 **교회 하나**에만 연결되어 있어도 교회 선택 화면이 나타납니다. 교회를 누르면 계속 진행합니다.
- 계정이 **여러 교회**에 연결되어 있다면, 이 키오스크가 체크인을 담당할 교회를 누르세요.

교회를 선택하면 앱이 해당 교회의 브랜딩과 화면 설정을 불러옵니다. 이후 모든 화면의 상단에 교회 로고가 표시됩니다.

## 다음번 실행 시 자동 로그인

처음 로그인에 성공하면 앱은 태블릿에 보안 로그인 토큰과 선택한 교회를 저장합니다. 비밀번호는 저장하지 않습니다. 다음번 실행부터는 다음과 같이 동작합니다.

- 앱이 저장된 토큰으로 자동 로그인합니다.
- 이전에 교회를 선택했다면 그 선택을 복원하고 **예배 화면**으로 바로 이동합니다.
- 저장된 로그인 정보가 더 이상 유효하지 않으면 로그인 화면으로 돌아가 다시 로그인할 수 있게 합니다.

:::tip
키오스크는 자동으로 로그인하므로, 자격 증명은 초기 설정 때 한 번만 입력하면 됩니다. 그 뒤로는 태블릿의 전원만 켜면 바로 사용할 수 있습니다.
:::

## 관리자 설정

키오스크를 사용하는 교인이 실수로 설정을 바꾸지 않도록 관리자 설정은 숨겨져 있습니다. 관리자 설정에 들어가려면 다음과 같이 하세요.

1. 상단의 **교회 로고**를 빠르게(2초 이내에) **일곱 번** 누르세요.
2. 키오스크 PIN이 설정되어 있다면 요청이 나타날 때 PIN을 입력하세요.
3. 다음 옵션이 있는 **Admin Settings** 화면이 열립니다.
   - **Change Service** -- 선택한 예배 시간 변경
   - **Change Printer** -- [프린터 설정](./printer-setup)을 열어 프린터를 찾고 선택
   - **Set/Change PIN** -- 관리자 접근을 보호하는 키오스크 PIN 설정 또는 변경
   - **Logout** -- 로그아웃하고 로그인 화면으로 돌아가기

:::warning
로그아웃하면 저장된 모든 자격 증명과 교회 선택이 지워집니다. 키오스크를 다시 사용하려면 이메일과 비밀번호를 다시 입력해야 합니다. 계정을 바꾸거나 키오스크를 다시 설정해야 할 때만 로그아웃하세요.
:::
