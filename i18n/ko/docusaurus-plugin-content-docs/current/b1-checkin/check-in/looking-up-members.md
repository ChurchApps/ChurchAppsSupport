# 회원 찾기

<div class="article-intro">

서비스를 선택하면 회원 조회 화면이 나타납니다. 여기서 가족을 검색하여 체크인 할 수 있습니다. 앱은 전화번호 또는 이름으로 검색을 지원합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 서비스 화면에서 [서비스 선택](./selecting-service)
- 귀하의 가정이 교회 관리자에 의해 [시스템에 추가되었는지 확인](../../b1-admin/people/adding-people.md)

</div>

## 검색 모드

조회 화면에서는 두 가지 검색 모드를 제공합니다. 화면 상단의 토글을 탭하여 전환할 수 있습니다:

- **전화번호** -- 전화번호로 검색합니다. 이것이 기본 모드입니다.
- **이름** -- 이름으로 검색합니다.

## 전화번호로 검색

1. 화면 상단에서 **전화번호**가 활성 검색 모드인지 확인합니다(강조 표시됨).
2. 검색 필드를 탭하고 화면 키패드를 사용하여 전화번호의 최소 **4자리**를 입력합니다.
3. **검색** 버튼을 탭하거나 키보드의 검색 키를 누릅니다.

앱은 입력하신 숫자와 일치하는 전화번호를 가진 회원을 검색합니다. 4자리 이상 입력하면 전체 번호를 사용합니다. 정확히 4자리만 입력하면 저장된 전화번호의 마지막 4자리와 일치시킵니다.

## 이름으로 검색

1. 화면 상단의 **이름** 토글을 탭하여 이름 검색 모드로 전환합니다.
2. 검색 필드에 사람의 이름 최소 **2자**를 입력합니다.
3. **검색** 버튼을 탭합니다.

앱은 입력하신 텍스트와 일치하는 이름을 가진 회원을 검색합니다.

## 사람 선택

검색 결과는 검색 필드 아래 카드로 나타납니다. 각 카드는 사람의 **이름**과 **사진**을 표시합니다(사진이 저장된 경우).

사람의 카드를 탭하여 선택합니다. 앱은 해당 사람의 가정의 모든 구성원을 로드하고 [가정 검토 화면](./household-review)으로 이동합니다.

:::tip
전화번호의 마지막 4자리로 검색하는 것이 가족을 찾는 가장 빠른 방법입니다. 더 빠른 체크인 경험을 위해 회원들에게 이 방법을 사용하도록 권장하세요.
:::

:::warning
결과를 찾을 수 없으면 앱에 메시지가 표시됩니다. 입력한 숫자나 이름을 다시 확인하거나 다른 검색 모드를 시도해보세요. 처음 방문하는 분이면 자원봉사자에게 [시스템에 추가](../../b1-admin/people/adding-people.md) 되도록 도움을 요청하세요.
:::

## 손님으로 등록

교회에서 QR 손님 등록을 활성화한 경우 조회 화면의 검색 아래에 **손님으로 등록** 링크가 나타납니다. 처음 방문한 손님은 이것을 사용하여 체크인하기 전에 교회 시스템에 가족을 추가할 수 있습니다.

1. **손님으로 등록**을 탭합니다. "손님으로 등록하려면 스캔하세요."라는 메시지와 함께 QR 코드가 있는 창이 열립니다.
2. [손님 등록 양식](../../b1-church/checkin/guest-registration)을 작성하는 방법을 선택합니다:
   - **휴대폰에서** -- QR 코드를 스캔하고 휴대폰에서 양식을 작성한 후 **확인**을 탭하여 창을 닫습니다.
   - **키오스크에서** -- **여기에 등록**을 탭하여 태블릿에서 같은 양식을 엽니다. 양식을 작성하고 **등록**을 탭한 다음 **완료**(또는 뒤로 화살표)를 탭하여 조회 화면으로 돌아갑니다.
3. 등록 후 이름이나 전화번호로 가족을 검색하여 체크인합니다.

:::info
**여기에 등록**으로 열린 양식은 손님 등록 페이지에 유지됩니다. 손님들은 키오스크에서 교회 웹사이트의 다른 부분을 탐색할 수 없습니다. 2분 동안 양식을 터치하거나 입력하지 않으면 키오스크가 이를 닫고 조회 화면으로 돌아갑니다. 양식이 닫힐 때마다 입력한 내용이 지워지므로 다음 가족이 빈 양식으로 시작합니다.
:::

## 휴대폰 체크인을 위한 레이블 인쇄

[B1 Church 셀프 체크인](../../b1-church/checkin/self-checkin)을 통해 휴대폰에서 이미 체크인한 가족은 자신을 찾지 않고도 키오스크에서 이름표를 인쇄할 수 있습니다.

1. 조회 화면에서 **코드 스캔** 버튼(QR 코드 아이콘)을 탭합니다.
2. 휴대폰의 QR 코드를 카메라 앞에 가져갑니다. 앱이 카메라 액세스를 요청하면 **카메라 허용**을 탭합니다. 기본적으로 전면 카메라가 사용되며, 플립 버튼을 탭하여 전환할 수 있습니다.
3. 키오스크가 체크인을 찾아 레이블을 인쇄한 후 조회 화면으로 돌아갑니다.

스캔하면 레이블만 인쇄됩니다. 가족이 휴대폰에서 체크인할 때 이미 출석이 기록되었습니다. 코드가 활성 체크인과 일치하지 않으면 키오스크에 메시지가 표시되고 조회 화면으로 돌아갑니다.
