# 구성원 찾기

<div class="article-intro">

예배를 선택하면 구성원 찾기 화면으로 이동합니다. 여기에서 체크인할 가족을 검색합니다. 이 앱은 전화번호 또는 이름으로 검색할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 예배 화면에서 [예배를 선택](./selecting-service.md)하세요
- 교회 관리자가 가족을 [시스템에 추가](../../b1-admin/people/adding-people.md)했는지 확인하세요

</div>

## 검색 모드 {#search-modes}

찾기 화면에는 두 가지 검색 모드가 있습니다. 화면 상단의 토글을 눌러 전환할 수 있습니다.

- **Phone**(전화번호) -- 전화번호로 검색합니다. 기본 모드입니다.
- **Name**(이름) -- 이름으로 검색합니다.

## 전화번호로 검색하기 {#searching-by-phone-number}

1. **Phone**이 활성 검색 모드인지 확인하세요(상단에 강조 표시됩니다).
2. 검색 칸을 누르고 화면 키패드로 전화번호를 최소 **4자리** 입력하세요.
3. **Search**(검색) 버튼을 누르거나 키보드의 검색 키를 누르세요.

앱은 입력한 숫자와 일치하는 전화번호를 가진 구성원을 찾습니다. 4자리보다 많이 입력하면 전체 번호를 사용합니다. 정확히 4자리를 입력하면 등록된 전화번호의 마지막 4자리와 비교합니다.

## 이름으로 검색하기 {#searching-by-name}

1. 화면 상단의 **Name** 토글을 눌러 이름 검색 모드로 바꾸세요.
2. 검색 칸에 사람의 이름을 최소 **2글자** 입력하세요.
3. **Search** 버튼을 누르세요.

앱은 입력한 이름과 일치하는 구성원을 찾습니다.

## 사람 선택하기 {#selecting-a-person}

검색 결과는 검색 칸 아래에 카드로 나타납니다. 각 카드에는 사람의 **이름**과 **사진**(등록된 경우)이 표시됩니다.

사람의 카드를 누르면 선택됩니다. 앱은 그 사람의 가족 구성원 전체를 불러온 다음 [가족 확인 화면](./household-review.md)으로 이동합니다.

:::tip
전화번호 뒷자리 4자리로 검색하는 것이 가족을 찾는 가장 빠른 방법입니다. 더 빠른 체크인을 위해 구성원들에게 이 방법을 안내하세요.
:::

:::warning
결과가 없으면 앱이 그 사실을 알려 줍니다. 입력한 숫자나 이름을 다시 확인하거나, 다른 검색 모드를 시도하세요. 처음 방문하셨다면 자원봉사자에게 [시스템에 등록](../../b1-admin/people/adding-people.md)하는 도움을 요청하세요.
:::

## 손님으로 등록하기 {#registering-as-a-guest}

교회에서 QR 손님 등록을 켜 두었다면, 찾기 화면의 검색 아래에 **Register as guest**(손님으로 등록) 링크가 나타납니다. 처음 방문하는 분은 이것을 사용하여 체크인하기 전에 가족을 교회 시스템에 추가할 수 있습니다.

1. **Register as guest**를 누르세요. "Scan to register as a guest."(손님으로 등록하려면 스캔하세요.)라는 메시지와 QR 코드가 있는 창이 열립니다.
2. [손님 등록 양식](../../b1-church/checkin/guest-registration.md)을 작성하는 방법을 고르세요.
   - **휴대폰에서** -- QR 코드를 스캔하고 휴대폰에서 양식을 작성한 다음 **OK**를 눌러 창을 닫으세요.
   - **키오스크에서** -- **Register here**(여기에서 등록)를 누르면 같은 양식이 태블릿에서 바로 열립니다. 작성한 다음 **Register**(등록)를 누르고, **Done**(완료)(또는 뒤로 화살표)을 눌러 찾기 화면으로 돌아가세요.
3. 등록이 끝나면 이름이나 전화번호로 가족을 검색하여 체크인하세요.

:::info
**Register here**로 연 양식은 손님 등록 페이지에 머무릅니다. 방문자는 키오스크에서 교회 웹사이트의 다른 부분으로 이동할 수 없습니다. 2분 동안 양식을 누르거나 입력하지 않으면 키오스크가 양식을 닫고 찾기 화면으로 돌아갑니다. 양식이 닫힐 때마다 입력된 내용은 지워지므로, 다음 가족은 빈 양식으로 시작합니다.
:::

## 휴대폰 체크인용 라벨 인쇄하기 {#printing-labels-for-a-phone-check-in}

[B1 Church 셀프 체크인](../../b1-church/checkin/self-checkin.md)으로 휴대폰에서 이미 체크인한 가족은, 직접 찾지 않고도 키오스크에서 이름표를 인쇄할 수 있습니다.

1. 찾기 화면에서 **Scan code**(코드 스캔) 버튼(QR 코드 아이콘)을 누르세요.
2. 휴대폰의 QR 코드를 카메라에 대세요. 앱이 카메라 접근을 요청하면 **Allow Camera**(카메라 허용)를 누르세요. 기본적으로 전면 카메라가 사용되며, 전환 버튼을 누르면 바꿀 수 있습니다.
3. 키오스크가 체크인을 찾아 라벨을 인쇄한 다음, 찾기 화면으로 돌아갑니다.

스캔은 라벨만 인쇄합니다. 출석은 가족이 휴대폰에서 체크인할 때 이미 기록되었습니다. 코드가 활성 체크인과 일치하지 않으면, 키오스크가 메시지를 표시하고 찾기 화면으로 돌아갑니다.

## 다음 단계 {#next-step}

사람을 선택한 후에는 [가족을 확인](./household-review.md)하고 그룹 배정을 관리하게 됩니다.
