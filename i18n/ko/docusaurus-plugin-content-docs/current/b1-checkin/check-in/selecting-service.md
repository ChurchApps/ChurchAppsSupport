# 서비스 선택

<div class="article-intro">

모든 체크인의 첫 단계는 참석할 서비스를 고르는 것입니다. 서비스 화면은 앱 로딩이 끝나자마자 나타나며, 이후 체크인 과정에서 어떤 예배 시간과 그룹을 사용할 수 있는지를 결정합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Church Checkin 앱에 [로그인](../getting-started/logging-in)하고 교회를 선택합니다
- 교회 관리자가 B1 Admin에서 [서비스와 예배 시간을 설정](../../b1-admin/attendance/setup.md)했는지 확인합니다

</div>

## 작동 방식

1. 로그인한 후(또는 재방문 시 자동 로그인한 후) 앱에 **서비스 화면**이 표시됩니다.
2. 교회에 설정된 모든 서비스 목록이 나타납니다. 각 서비스는 서비스 이름(예: "일요일 아침" 또는 "수요일 저녁")이 적힌 카드로 표시됩니다.
3. 참석하는 서비스를 탭합니다.

앱은 해당 서비스와 연결된 예배 시간과 그룹을 불러온 다음, [구성원 조회 화면](./looking-up-members)으로 이동합니다.

## 체크인이 열려 있지 않을 때 {#when-check-in-isnt-open}

관리자가 예배 시간에 [체크인 일정](../../b1-admin/attendance/setup#setting-a-check-in-schedule)을 지정했다면, 앱은 체크인 기간이 열려 있는 동안에만 해당 예배 시간을 제공합니다. 지금 체크인 기간이 닫혀 있는 예배 시간은 숨겨지므로, 가족들이 체크인 과정 뒤에서 그 시간을 선택할 수 없습니다.

선택한 서비스의 모든 예배 시간이 닫혀 있다면, 앱에 **"이 서비스의 체크인이 지금은 열려 있지 않습니다."**라고 표시됩니다. **뒤로**를 탭하여 서비스 목록으로 돌아가 다른 서비스를 선택하거나, 체크인 기간이 열릴 때까지 기다렸다가 다시 시도하세요.

:::info
체크인 기간은 교회의 시간대를 따릅니다. 교회에 시간대가 설정되어 있지 않다면 대신 캠퍼스의 시간대가 사용됩니다. 예배 시간이 잘못된 시각에 열리는 것 같다면, 관리자에게 교회 또는 캠퍼스 설정의 시간대를 확인해 달라고 요청하세요.
:::

:::info
서비스는 교회 관리자가 B1 Admin의 출석(Attendance) 섹션에서 설정합니다. 기대했던 서비스가 보이지 않는다면, 관리자에게 [출석 설정](../../b1-admin/attendance/setup.md)에서 해당 서비스가 만들어졌는지 확인해 달라고 요청하세요.
:::

## 내부에서 일어나는 일

서비스를 선택하면 앱은 서버에서 세 가지 정보를 가져옵니다.

- 해당 서비스의 **예배 시간**(예: 한 서비스에 오전 9시와 오전 11시 예배 시간 슬롯이 있을 수 있습니다).
- 각 예배 시간에 사용할 수 있는 **그룹**(예: 영아부, 유치부, 초등부).
- 어떤 그룹을 어떤 예배 시간에 사용할 수 있는지 정하는 **그룹과 예배 시간의 연결 정보**.

이 데이터는 로컬에 캐시되어, 이후 체크인 과정이 빠르고 반응이 좋게 동작합니다.

:::tip
교회에 서비스가 하나만 설정되어 있더라도 진행하려면 탭해야 합니다. 앱은 서비스를 자동으로 선택하지 않습니다.
:::
