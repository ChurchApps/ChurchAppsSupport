# 체크인 완료하기

<div class="article-intro">

가족을 검토하고 필요한 그룹 배정을 마쳤다면 이제 체크인을 마무리할 준비가 된 것입니다. 이는 키오스크 워크플로우의 마지막 단계로, 앱이 출석을 제출하고 라벨을 인쇄한 다음 다음 가족을 위해 초기화됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 가족 검토 화면에서 [가족을 검토](./household-review)하세요
- 특정 클래스나 프로그램에 체크인해야 하는 가족 구성원에게 [그룹을 배정](./group-assignment)하세요
- 선택적으로, 가족과 함께 방문한 [손님을 추가](./adding-guests)하세요

</div>

## 체크인하는 방법

1. **가족 검토 화면**에서 화면 하단의 **체크인(Check-in)** 버튼을 탭합니다.
2. 앱이 출석 데이터를 서버에 제출하고, 녹색 체크 표시와 환영 메시지가 담긴 **성공 화면**을 표시합니다.

이것으로 끝입니다. 가족의 출석이 기록되었습니다.

## 정원 초과 방과 자원봉사자 비율

교회가 방에 [안전 제한](../../b1-admin/attendance/checkin-safety)을 설정해 두었다면, 서버는 저장하기 전에 이를 확인합니다.

- 선택한 방이 **정원 초과이거나 마감**된 경우, 체크인이 진행되지 않으며 앱은 해당 방의 이름을 알려주어 다른 방을 선택할 수 있게 합니다.
- 어린이 방이 비율 기준에 비해 **자원봉사자가 부족한** 경우, 앱은 교회의 비율 적용 방식 설정에 따라 스태프가 확인해 진행할 수 있는 경고를 표시하거나, 체크인 자체를 완전히 막습니다.

## 라벨 인쇄

네트워크 프린터가 설정되어 있으면, 앱은 체크인 후 자동으로 라벨을 인쇄합니다.

- **이름표(Name labels)**는 **이름표 인쇄(Print Nametag)** 설정이 활성화된 그룹에 배정된 각 사람에 대해 인쇄됩니다. 이름표에는 이름, 그룹 배정, 그리고 기록되어 있는 경우 알레르기/메모 정보가 포함됩니다.
- **부모 픽업 확인증(Parent pickup slips)**은 체크인한 사람 중 누구든 **부모 픽업(Parent Pickup)** 설정이 활성화된 그룹에 속해 있으면 인쇄됩니다. 픽업 확인증에는 자녀 목록, 그룹 배정, 그리고 고유한 **4자리 보안 코드**가 표시됩니다.

:::info
동일한 보안 코드가 자녀의 이름표와 부모의 픽업 확인증 모두에 표시됩니다. 픽업 시간에 자원봉사자는 이 코드를 대조해 올바른 보호자가 각 자녀를 데려가는지 확인합니다.
:::

보안 코드는 체크인할 때마다 새로 생성되며, 자음과 숫자만 사용합니다(부적절한 단어가 만들어지지 않도록 모음은 제외됩니다).

:::warning
라벨이 인쇄되지 않으면 **교회 로고**를 일곱 번 탭해 관리자 설정을 열고, **프린터 변경(Change Printer)**을 탭해 프린터 연결을 확인하세요. 문제 해결 단계는 [프린터 설정](../getting-started/printer-setup)을 참고하세요.
:::

## 체크인 후 일어나는 일

- 프린터가 설정되어 있으면 앱이 모든 라벨을 인쇄한 뒤 자동으로 **조회 화면**으로 돌아가 다음 가족을 맞을 준비를 합니다.
- 프린터가 설정되어 있지 않으면 성공 화면이 몇 초간 표시된 뒤 자동으로 **조회 화면**으로 돌아갑니다.

조회 화면으로 돌아가기 위해 따로 무언가를 탭할 필요는 없습니다 -- 앱이 전환을 자동으로 처리합니다.

:::tip
앱은 체크인이 끝날 때마다 완전히 초기화되므로, 한 가족이 다른 가족의 정보를 볼 위험이 없습니다.
:::

## 기록되는 내용

**체크인(Check-in)**을 탭하면, 앱은 그룹이 배정된 각 가족 구성원에 대해 다음 정보를 서버로 전송합니다.

- 체크인되는 **사람**
- 참석하는 **예배**
- 배정된 **예배 시간**과 **그룹**

이 데이터는 B1 Admin의 출석(Attendance) 섹션에 표시되며, 교회 관리자가 출석 기록을 확인하고 관리할 수 있습니다. 자세한 내용은 [체크인 관리 안내서](../../b1-admin/attendance/check-in.md)를 참고하세요.
