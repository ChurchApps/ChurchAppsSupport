# 체크아웃 및 아동 안전

<div class="article-intro">

체크아웃은 아동 체크인의 마지막 단계입니다: 부모가 픽업 라벨의 보안 코드를 제시하면 키오스크가 픽업하는 사람이 누구인지 확인하고 아동을 체크아웃시킵니다. 유인 스테이션에는 신뢰할 수 있는 픽업 확인, 부모 호출 문자, 보안 라벨 재인쇄, 긴급 방송 등 추가 안전 도구도 제공됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 체크아웃은 키오스크 관리 설정에서 **유인** 모드로 설정된 스테이션에서 사용할 수 있습니다
- 아동은 보안 코드가 있는 픽업 라벨이 인쇄된 상태로 [체크인](./completing-checkin)되어 있어야 합니다
- 호출 및 긴급 방송을 사용하려면 교회가 B1 Admin에 문자 발송 제공업체를 연결해야 합니다

</div>

## 체크아웃 시작하기

1. 유인 스테이션에서 조회 화면의 **체크아웃**을 탭하세요.
2. 가족의 픽업 라벨에 적힌 4자리 **보안 코드**를 입력하세요. 직접 입력하거나, 화면 키패드를 사용하거나, USB 또는 블루투스 스캐너로 라벨의 바코드를 스캔할 수 있습니다 -- 4자리가 모두 입력되면 자동으로 제출됩니다.
3. 키오스크에 해당 코드로 체크인된 아동들이 표시됩니다.

## 픽업하는 사람 확인하기

체크아웃 화면은 아동을 픽업할 사람이 누구인지 묻습니다:

- 해당 가구의 **신뢰할 수 있는 픽업 담당자**는 사진과 관계가 표시된 탭 가능한 카드로 나타납니다 -- 눈앞에 있는 사람을 탭하세요.
- **가구 성인**도 사진 그리드에 표시됩니다.
- **기타**를 사용하면 목록에 없는 사람의 이름을 입력할 수 있습니다.

입력한 이름이 해당 가구에서 **승인되지 않음**으로 표시된 사람과 일치하면 키오스크가 경고와 함께 체크아웃을 차단합니다. 직원은 **재정의**를 선택하여 진행할 수 있으며, 재정의는 해당 사람의 이름과 함께 출석 기록에 남습니다.

픽업 담당자가 확인되면 체크아웃을 탭하세요. 픽업 담당자의 이름이 출석 기록에 저장됩니다.

:::info
신뢰할 수 있는 픽업 담당자와 승인되지 않은 픽업 담당자는 B1 Admin의 각 인물 페이지에서 교회 직원이 관리합니다 -- [체크인 안전](../../b1-admin/attendance/checkin-safety#trusted-and-not-authorized-pickup-people)을 참조하세요.
:::

## 부모 호출하기

예배 중 부모가 필요한 경우가 있습니다 -- 기저귀 교체, 우는 아이 등. 유인 스테이션의 체크아웃 화면에서 직원은 교회의 문자 발송 제공업체를 통해 아동의 부모나 보호자에게 **호출** 문자 메시지를 보낼 수 있습니다. 문자 수신을 거부했거나 휴대폰 번호가 없는 부모는 제외되며, 키오스크는 몇 개의 메시지가 발송되었는지 표시합니다.

## 라벨 재인쇄하기

이름표나 픽업 라벨을 분실하거나 손상된 경우, 유인 스테이션의 직원은 보안 코드를 입력한 후 체크아웃 화면에서 가족의 라벨을 **재인쇄**할 수 있습니다. 재인쇄는 원래 체크인과 동일한 프린터와 라벨 템플릿을 사용합니다.

## 긴급 방송

긴급 상황이 발생하면 직원은 현재 예배에 **체크인된 모든 아동**의 보호자에게 한 번에 문자를 보낼 수 있습니다:

1. 키오스크 **관리 설정**을 여세요(헤더 로고를 빠르게 7번 탭, 핀이 설정된 경우 핀 입력).
2. **긴급 방송**을 탭하세요.
3. 메시지를 입력한 후 확인 필드에 **EMERGENCY**를 입력하세요 -- 입력하기 전까지는 **방송 보내기** 버튼이 비활성화되어 있습니다.
4. 키오스크는 몇 대의 휴대폰이 메시지를 수신했는지, 몇 명이 제외되었는지(수신 거부 또는 휴대폰 번호 없음) 보고합니다.

:::warning
방송은 선택한 예배에 체크인된 모든 가구로 발송됩니다. 대피, 봉쇄, 심각한 기상 상황과 같은 진정한 긴급 상황에만 사용하세요.
:::
