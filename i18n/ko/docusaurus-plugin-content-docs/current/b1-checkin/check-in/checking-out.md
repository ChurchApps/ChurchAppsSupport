# 체크아웃 및 어린이 안전

<div class="article-intro">

체크아웃은 어린이 체크인 루프를 닫습니다. 부모가 픽업 라벨의 보안 코드를 제시하고 키오스크가 누가 픽업하는지 확인한 다음 어린이를 체크아웃합니다. 관리되는 스테이션에는 또한 안전 도구(신뢰할 수 있는 픽업 확인, 부모에게 페이징 문자, 보안 라벨 재인쇄, 긴급 방송)가 포함됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 체크아웃은 키오스크 관리 설정에서 **관리됨** 모드로 설정된 스테이션에서 사용 가능합니다
- 어린이는 보안 코드가 있는 인쇄된 픽업 라벨을 가지고 [체크인](./completing-checkin)되어야 합니다
- 페이징 및 긴급 방송을 위해서는 교회가 B1 Admin에서 문자 공급자와 연결되어 있어야 합니다

</div>

## 체크아웃 시작

1. 관리되는 스테이션에서 조회 화면의 **체크아웃**을 탭합니다.
2. 가족의 픽업 라벨에서 4자 **보안 코드**를 입력합니다. 입력하거나 화면의 키패드를 사용하거나 USB 또는 Bluetooth 스캐너로 라벨의 바코드를 스캔할 수 있습니다. 모든 4개 문자가 입력되면 코드가 자동으로 제출됩니다.
   - 스캐너가 없으신가요? 코드 필드 아래의 **스캔**을 탭하여 대신 태블릿의 카메라를 사용합니다. **픽업 코드 스캔** 창의 카메라에 픽업 라벨의 QR 코드 또는 바코드를 들고 있으면 코드가 자동으로 입력됩니다. 기본적으로 후면 카메라가 사용됩니다. 카메라를 전환하려면 뒤집기 버튼을 탭하거나 입력으로 돌아가려면 **취소**를 탭합니다.
3. 키오스크는 해당 코드로 체크인된 어린이를 표시합니다.

## 누가 픽업하는지 확인

체크아웃 화면에서는 누가 어린이를 픽업하는지 묻습니다:

- **신뢰할 수 있는 픽업 사람들**은 사진과 관계가 있는 탭 가능한 카드로 나타납니다. 당신 앞에 있는 사람을 탭합니다.
- **가구 성인**도 사진 그리드에 나타납니다.
- **기타**를 사용하면 목록에 없는 사람의 이름을 입력할 수 있습니다.

입력한 이름이 해당 가구에 대해 **권한 없음**으로 표시된 사람과 일치하면 키오스크는 경고와 함께 체크아웃을 차단합니다. 직원이 어쨌든 진행하기 위해 **재정의**를 선택할 수 있습니다. 재정의는 출석 기록에 사람의 이름과 함께 기록됩니다.

픽업 사람이 확인되면 체크아웃을 탭합니다. 픽업 사람의 이름이 출석 기록과 함께 저장됩니다.

:::info
신뢰할 수 있는 픽업 사람과 권한이 없는 픽업 사람은 B1 Admin의 각 사람 페이지에서 교회 직원이 관리합니다. [체크인 안전](../../b1-admin/attendance/checkin-safety#trusted-and-not-authorized-pickup-people)을 참조하세요.
:::

## 부모에게 페이징

예배 중에 부모가 필요하신가요? 기저귀 교체, 우는 아이? 관리되는 스테이션의 체크아웃 화면에서 직원은 **페이징**을 보낼 수 있습니다. 교회의 문자 공급자를 통해 어린이의 부모 또는 보호자에게 보내는 문자 메시지입니다. 문자를 거부했거나 휴대폰 번호가 없는 부모는 건너뛰고 키오스크는 얼마나 많은 메시지가 전송되었는지 표시합니다.

## 라벨 재인쇄

이름표 또는 픽업 라벨이 손실되거나 손상된 경우 관리되는 스테이션의 직원이 보안 코드를 입력한 후 체크아웃 화면에서 가족의 라벨을 **재인쇄**할 수 있습니다. 재인쇄는 원래 체크인과 동일한 프린터 및 라벨 템플릿을 사용합니다.

## 긴급 방송

긴급 상황에서 직원은 현재 예배를 위해 **체크인된 모든 어린이**의 보호자에게 한 번에 문자를 보낼 수 있습니다:

1. 키오스크 **관리 설정**(헤더 로고에서 7번의 빠른 탭, 설정되어 있으면 PIN 추가)을 엽니다.
2. **긴급 방송**을 탭합니다.
3. 메시지를 입력한 다음 확인 필드에 **EMERGENCY**를 입력합니다. **방송 전송** 버튼은 입력할 때까지 비활성화되어 있습니다.
4. 키오스크는 메시지를 받은 휴대폰의 수와 건너뛴 사람의 수(거부했거나 휴대폰 번호 없음)를 보고합니다.

:::warning
방송은 선택한 예배를 위해 체크인된 모든 가구로 전송됩니다. 진정한 긴급 상황(대피, 폐쇄, 악천후)에 사용합니다.
:::
