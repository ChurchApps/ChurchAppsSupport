# 체크아웃 및 어린이 안전 {#checking-out--child-safety}

<div class="article-intro">

체크아웃은 어린이 체크인 과정을 마무리합니다. 부모가 픽업 라벨의 보안 코드를 제시하면, 키오스크가 누가 픽업하는지 확인한 다음 어린이를 체크아웃합니다. 관리되는 스테이션에는 안전 도구도 제공됩니다. 신뢰할 수 있는 픽업 확인, 부모에게 보내는 페이지 문자, 보안 라벨 재인쇄, 긴급 방송이 그것입니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 체크아웃은 키오스크 관리 설정에서 **관리됨(manned)** 모드로 설정된 스테이션에서 사용할 수 있습니다
- 어린이는 보안 코드가 적힌 인쇄된 픽업 라벨을 받고 [체크인](./completing-checkin.md)되어 있어야 합니다
- 페이징과 긴급 방송을 사용하려면 교회가 B1 Admin에서 문자 메시지 공급자를 연결해 두어야 합니다

</div>

## 체크아웃 시작하기 {#starting-a-check-out}

1. 관리되는 스테이션에서 조회 화면의 **Check Out**(체크아웃)을 탭합니다.
2. 가족의 픽업 라벨에 있는 4자리 **보안 코드**를 입력합니다. 직접 입력하거나 화면 키패드를 쓰거나, USB 또는 Bluetooth 스캐너로 라벨의 바코드를 스캔할 수 있습니다. 4자리를 모두 입력하면 코드가 자동으로 제출됩니다.
   - 스캐너가 없나요? 코드 입력란 아래의 **Scan**(스캔)을 탭하면 태블릿 카메라를 사용합니다. **Scan pickup code**(픽업 코드 스캔) 창에서 픽업 라벨의 QR 코드나 바코드를 카메라에 비추면 코드가 자동으로 입력됩니다. 기본적으로 후면 카메라가 사용됩니다. 카메라를 전환하려면 뒤집기 버튼을 탭하고, 입력으로 돌아가려면 **Cancel**(취소)을 탭하세요.
3. 키오스크에 그 코드로 체크인된 어린이들이 표시됩니다.

### 보안 코드 없이 가족 찾기 {#finding-a-family-without-the-code}

부모가 픽업 라벨을 잃어버렸다면 가족을 조회하세요.

1. **Check Out** 화면에서 (**Scan** 옆의) **Search by name**(이름으로 검색)을 탭합니다.
2. 가족의 성을 입력하고 **Search**(검색)를 탭하거나, **Use phone number**(전화번호 사용)를 탭하여 키패드에 전화번호(끝 4자리 이상)를 입력합니다.
3. 결과에서 해당 사람을 탭합니다. 키오스크는 오늘 체크인되었고 아직 체크아웃되지 않은 그 가정의 모든 사람을 찾아, 코드를 입력한 것과 똑같이 보여줍니다.

가정의 누구도 체크인되어 있지 않다면 키오스크에 "No one in this household is checked in right now."(현재 이 가정에서 체크인된 사람이 없습니다.)라고 표시됩니다. 다시 검색하려면 **New search**(새로 검색)를, 코드 입력란으로 돌아가려면 **Enter code instead**(대신 코드 입력)를 탭하세요.

아래의 픽업 확인 절차는 여전히 적용됩니다. 가정의 신뢰할 수 있는 픽업 사람과 성인이 목록에 나타나며, 권한 없음으로 지정된 이름은 여전히 차단됩니다.

## 누가 픽업하는지 확인하기 {#verifying-who-is-picking-up}

체크아웃 화면에서는 누가 어린이를 데려가는지 묻습니다.

- 가정의 **신뢰할 수 있는 픽업 사람**은 사진과 관계가 함께 표시된 탭 가능한 카드로 나타납니다. 지금 앞에 서 있는 사람을 탭하세요.
- **가정의 성인**도 사진 격자에 나타납니다.
- **Other**(기타)를 선택하면 목록에 없는 사람의 이름을 입력할 수 있습니다.

입력한 이름이 그 가정에서 **Not Authorized**(권한 없음)로 표시된 사람과 일치하면 키오스크는 경고와 함께 체크아웃을 차단합니다. 직원은 **Override**(무시하고 진행)를 선택하여 그대로 진행할 수 있습니다. 이 무시 기록은 사람 이름과 함께 출석 기록에 남습니다.

픽업하는 사람이 확인되면 체크아웃을 탭하세요. 픽업 사람의 이름은 출석 기록과 함께 저장됩니다.

:::info
신뢰할 수 있는 픽업 사람과 권한 없는 픽업 사람은 교회 직원이 B1 Admin의 각 사람 페이지에서 관리합니다. [체크인 안전](../../b1-admin/attendance/checkin-safety.md#trusted-and-not-authorized-pickup-people)을 참고하세요.
:::

## 부모에게 페이징하기 {#paging-a-parent}

예배 중에 부모가 필요하신가요? 기저귀를 갈아야 하거나 아이가 울고 있나요? 관리되는 스테이션의 체크아웃 화면에서 직원은 **페이지(page)**를 보낼 수 있습니다. 교회의 문자 메시지 공급자를 통해 어린이의 부모나 보호자에게 보내는 문자 메시지입니다. 문자 수신을 거부했거나 휴대폰 번호가 없는 부모는 건너뛰며, 키오스크에 전송된 메시지 수가 표시됩니다.

## 라벨 재인쇄하기 {#reprinting-labels}

이름표나 픽업 라벨을 잃어버리거나 손상되었다면, 관리되는 스테이션의 직원은 보안 코드를 입력한 뒤 체크아웃 화면에서 가족의 라벨을 **재인쇄**할 수 있습니다. 재인쇄는 원래 체크인 때와 같은 프린터와 라벨 템플릿을 사용합니다.

## 긴급 방송 {#emergency-broadcast}

긴급 상황에서 직원은 현재 예배에 **체크인된 모든 어린이**의 보호자에게 한 번에 문자를 보낼 수 있습니다.

1. 키오스크 **관리자 설정**을 엽니다(헤더 로고를 7번 빠르게 탭한 뒤, PIN이 설정되어 있으면 PIN을 입력합니다).
2. **Emergency broadcast**(긴급 방송)를 탭합니다.
3. 메시지를 입력한 다음 확인 입력란에 **EMERGENCY**를 입력합니다. 그 전까지 **Send broadcast**(방송 보내기) 버튼은 비활성화된 상태로 있습니다.
4. 키오스크는 메시지를 받은 휴대폰 수와 건너뛴 사람 수(수신 거부 또는 휴대폰 번호 없음)를 알려 줍니다.

:::warning
방송은 선택한 예배에 체크인된 모든 가정에 전송됩니다. 대피, 봉쇄, 악천후처럼 실제 긴급 상황에서만 사용하세요.
:::
