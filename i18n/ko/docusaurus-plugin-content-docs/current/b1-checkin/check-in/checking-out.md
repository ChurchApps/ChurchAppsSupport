# 체크아웃 및 아동 안전

<div class="article-intro">

체크아웃은 체크인의 반대: 부모가 자녀를 픽업하고 키오스크가 픽업 사람을 확인하고 필요한 경우 부모에게 알립니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [체크인 안전](../attendance/checkin-safety.md) 설정 완료

</div>

## 체크아웃 흐름

1. 키오스크의 **체크아웃** 탭으로 이동합니다.
2. 픽업 사람을 확인합니다.
3. **체크아웃** 확인을 누릅니다.
