# 가족 검토하기

<div class="article-intro">

검색 결과에서 사람을 선택하면, 앱은 전체 가족을 불러와 가족 검토 화면에 표시합니다. 이곳이 체크인 과정의 중심 허브로, 가족 구성원 전체를 확인하고 체크인 전에 그룹 배정을 관리할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 예배 화면에서 [예배를 선택](./selecting-service)하세요
- [구성원을 조회](./looking-up-members)하고 검색 결과에서 선택하세요

</div>

## 가족 구성원 보기

각 가족 구성원은 다음 정보가 담긴 카드로 표시됩니다.

- **사진**(등록된 사진이 없으면 자리 표시 아이콘)
- **표시 이름**
- **현재 그룹 배정 요약**(카드가 접혀 있을 때 이름 아래에 작은 칩으로 표시됨)
- 오른쪽의 **펼치기/접기 화살표**

## 구성원 펼치기

구성원의 카드를 탭하면 펼쳐집니다. 펼쳐지면 선택한 예배 안의 각 **예배 시간**마다 하나씩 행이 표시됩니다. 각 행에는 다음이 표시됩니다.

- **예배 시간 이름**(예: "오전 9:00" 또는 "오전 11:00")
- 현재 배정된 그룹을 보여주는 **버튼**, 또는 아직 그룹이 배정되지 않았다면 "그룹 선택"

그룹 버튼을 탭하면 [그룹 선택 화면](./group-assignment)으로 이동해 해당 사람과 예배 시간의 그룹을 선택하거나 변경할 수 있습니다.

펼쳐진 카드에는 **교인(Member)**, **손님(Guest)**, **자원봉사자(Volunteer)** 칩도 표시됩니다. 하나를 탭해 이 사람이 어떻게 체크인하는지 설정하세요 -- 기본값은 교인입니다. 이 구분은 어린이 방에서 중요합니다. 자원봉사자는 방의 자원봉사자 대 어린이 비율에 포함되고, 손님은 교회가 설정한 손님 정원에 포함됩니다.

구성원의 카드를 다시 탭하면 접힙니다.

:::tip
모든 가족 구성원을 그룹에 배정할 필요는 없습니다. 본예배에 참석하는 성인은 그룹 배정 없이 남겨둘 수 있습니다. 특정 클래스나 프로그램에 체크인해야 하는 구성원에게만 그룹을 배정하세요.
:::

## 이 화면에서 이동하기

가족 검토 화면에서는 세 가지를 할 수 있습니다.

- **구성원을 펼치고** 예배 시간 버튼을 탭해 [그룹을 배정하거나 변경](./group-assignment)합니다.
- 구성원 목록 아래의 **손님 추가 버튼을 탭해** 가족에 [손님을 추가](./adding-guests)합니다.
- 화면 하단의 **체크인 버튼을 탭해** 가족 전체의 [체크인을 완료](./completing-checkin)합니다.

:::info
같은 예배에 대한 이전 체크인의 그룹 배정은 자동으로 미리 불러와집니다. 자녀가 매주 같은 그룹에 참석한다면 아무것도 바꿀 필요 없이 확인만 하고 체크인하면 될 수도 있습니다.
:::

## 다음 단계

- 특정 클래스나 프로그램에 체크인해야 하는 가족 구성원에게 [그룹을 배정](./group-assignment)하세요.
- 가족과 함께 방문한 사람이 있다면 [손님을 추가](./adding-guests)하세요.
- 모든 구성원의 배정이 올바르면 [체크인을 완료](./completing-checkin)하세요.
