# 그룹 배정하기

<div class="article-intro">

가족 검토 화면에서 예배 시간 버튼을 탭하면, 앱은 그룹 선택 화면을 엽니다. 여기에서 가족 구성원이 해당 예배 시간에 참석할 그룹이나 클래스를 선택합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 가족 검토 화면에서 [가족을 검토](./household-review)하세요
- 배정하려는 구성원을 펼치고 예배 시간 버튼을 탭하세요
- 교회 관리자가 B1 Admin에서 [그룹을 만들고](../../b1-admin/groups/creating-groups.md) 예배 시간에 연결해 두었는지 확인하세요

</div>

## 그룹이 구성되는 방식

그룹은 **카테고리**별로 표시됩니다. 각 카테고리는 다음을 보여주는 카드 형태로 나타납니다.

- **카테고리 이름**(예: "어린이", "청소년", "성인")
- 해당 카테고리에 속한 **그룹 수**

카테고리 카드를 탭하면 펼쳐지면서 그 안의 개별 그룹을 볼 수 있습니다. 다시 탭하면 접힙니다.

## 그룹 선택하기

1. **카테고리**를 탭해 펼칩니다.
2. 해당 카테고리 안의 그룹 목록을 확인합니다. 각 그룹은 오른쪽에 선택 아이콘과 함께 이름이 표시됩니다.
3. 배정하려는 **그룹 이름**을 탭합니다.

앱이 선택 내용을 저장하고 [가족 검토 화면](./household-review)으로 돌아갑니다. 해당 구성원의 예배 시간 버튼에는 이제 선택한 그룹의 이름이 표시됩니다.

## 연령 및 학년 안내

교회가 방마다 연령이나 학년 범위를 설정해 두었다면, 목록이 알맞은 방을 안내해 줍니다. 해당 사람이 조건에 맞는 방은 **강조 표시**되고, 연령이나 학년 범위를 벗어난 방은 **흐리게** 표시됩니다. 흐리게 표시된 방도 선택할 수는 있지만, 스태프가 그 선택을 확인해야 합니다. 연령과 학년은 교회의 학년 승급 날짜를 기준으로 계산되므로, 학년도가 바뀌더라도 방 정보는 정확하게 유지됩니다.

## "없음" 선택하기

가족 구성원을 이번 예배 시간에 어떤 그룹에도 배정하지 않기로 했다면, 화면 하단의 **없음(None)** 버튼을 탭하세요. 이렇게 하면 해당 예배 시간에 대한 기존 그룹 배정이 지워지고 가족 검토 화면으로 돌아갑니다.

:::tip
본예배에 참석하며 특정 그룹이나 클래스에 체크인할 필요가 없는 성인의 경우 **없음(None)** 옵션을 사용하세요.
:::

## 그룹 배정 변경하기

이미 완료된 그룹 배정을 변경하려면 다음과 같이 하세요.

1. [가족 검토 화면](./household-review)으로 돌아갑니다.
2. 그룹을 변경하려는 구성원을 펼칩니다.
3. (현재 배정된 그룹 이름이 표시된) 예배 시간 버튼을 탭합니다.
4. 다른 그룹을 선택하거나 **없음(None)**을 탭합니다.

:::info
그룹과 카테고리는 교회 관리자가 B1 Admin에서 설정합니다. 그룹이 보이지 않거나 잘못된 카테고리에 있다면, 관리자에게 [그룹 설정](../../b1-admin/groups/creating-groups.md)을 업데이트해 달라고 요청하세요.
:::

## 다음 단계

- 다른 가족 구성원에게도 그룹을 배정합니다
- 가족과 함께 방문한 사람이 있다면 [손님을 추가](./adding-guests)합니다
- 모든 배정이 준비되면 [체크인을 완료](./completing-checkin)합니다
