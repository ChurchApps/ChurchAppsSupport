# B1 Admin 개요

<div class="article-intro">

B1 Admin은 교회 관리 대시보드입니다. 회원 명부와 헌금부터 웹사이트 제작과 실시간 스트리밍까지, 교회 운영의 모든 측면을 관리할 수 있는 도구를 한곳에서 제공합니다.

</div>

## 시작하기

1. 브라우저를 열고 [admin.b1.church](https://admin.b1.church)로 이동합니다
2. 사용자 이름과 비밀번호로 로그인합니다
3. **대시보드**로 이동하면 교회 데이터의 전체 개요와 함께, 사람 추가, 그룹 생성, 헌금 기록 등 자주 하는 작업을 위한 **빠른 작업** 메뉴가 표시됩니다

:::tip
B1 Admin이 처음이신가요? 영상으로 안내를 받으려면 [소개](./introduction)부터 시작한 다음, [설정](./settings/)에서 교회 정보를 구성하고 팀원을 초대하세요.
:::

## 주요 기능

- **[교인](./people/)** - 교회 명부 관리, 회원 추가, 데이터 일괄 편집, 가구 추적
- **[그룹](./groups/)** - 가입 신청과 회원 관리를 포함한 교회 그룹 생성 및 조직
- **[출석](./attendance/)** - 캠퍼스와 예배 시간 설정 및 출석 추적
- **[헌금](./donations/)** - 여러 통화로 헌금 기록, 펀드 관리, 명세서 생성
- **[섬김](./serving/)** - 자원봉사자 조율, 섬김 계획 수립, 작업 관리, 단계별 워크플로우를 통한 인원 배치
- **[양식](./forms/)** - 등록 및 데이터 수집을 위한 사용자 지정 양식 제작
- **[보고서](./reports/)** - 생일, 출석, 헌금 보고서 확인
- **[웹사이트](./website/)** - 맞춤형 내비게이션 스타일로 교회 웹사이트 제작 및 관리
- **[설교](./sermons/)** - 설교 라이브러리 및 실시간 스트리밍 관리
- **[캘린더](./calendars/)** - 큐레이션 캘린더 생성, 회의실/자원 예약 관리, 예약 현황 확인
- **[설정](./settings/)** - 교회 정보, 역할, 권한, 사용자 지정 인물 필드 구성

:::info
모든 페이지 오른쪽 상단의 물음표 아이콘을 클릭하면 도움말과 설명서에 빠르게 접근할 수 있습니다.
:::

지원이 필요하면 [support@churchapps.org](mailto:support@churchapps.org)로 이메일을 보내세요.
