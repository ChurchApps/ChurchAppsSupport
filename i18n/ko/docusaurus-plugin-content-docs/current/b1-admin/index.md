# B1 Admin 개요

<div class="article-intro">

B1 Admin은 교회 관리 대시보드입니다. 회원 디렉토리와 기부금부터 웹사이트 구축 및 라이브 스트리밍까지 교회 운영의 모든 측면을 관리하는 도구를 제공하며, 모두 한 곳에서 관리할 수 있습니다.

</div>

## 시작하기

1. 브라우저를 열고 [admin.b1.church](https://admin.b1.church)로 이동합니다.
2. 사용자 이름과 비밀번호로 로그인합니다.
3. 홈 페이지인 **Dashboard**가 열립니다. 이번 주 서비스 순서, 실시간으로 체크인하고 섬기고 있는 사람, 주의가 필요한 항목(보류 중인 승인이나 가입 요청 등), 열린 작업, 그룹을 보여줍니다.

:::tip
B1 Admin이 처음이라면 [소개](./introduction)에서 동영상 둘러보기를 본 다음, [설정](./settings/)에서 교회 정보를 구성하고 팀원을 초대하세요.
:::

## 대시보드

대시보드는 B1 Admin의 홈 페이지(`/`)입니다. 교회의 주간 서비스를 중심으로 구성되어 있습니다.

- **이번 주 서비스** -- 현재 또는 예정된 계획의 이름과 서비스 순서, 전체 계획으로 연결되는 링크
- **실시간 상태** -- 일요일에 사람들이 체크인하기 시작하면, 방 안에 있는 인원, 이번 시간에 섬기는 사람, 첫 방문자 수, 수용 인원 막대가 있는 방별 현황이 표시됩니다.
- **Needs Attention** -- 조치가 필요한 보류 중인 승인과 그룹 가입 요청
- **My tasks**와 **My Groups** -- 열린 작업(**Add Task**로 추가하거나 **All tasks**를 클릭하여 전체 목록 보기)과 내가 속한 그룹

:::tip
설교, Calendars, Mobile, Settings를 포함한 모든 섹션은 B1 Admin 왼쪽 상단의 [Jump 메뉴](./introduction.md#getting-around-with-the-jump-menu)에 있습니다. 메뉴를 클릭하거나 **Ctrl+K**(또는 **Cmd+K**)를 누른 다음 찾아보거나 입력을 시작하세요.
:::

## 주요 기능

- **[사람](./people/)** - 교회 디렉토리를 관리하고, 회원을 추가하고, 데이터를 일괄 편집하며, 가구별 또는 정렬 가능한 표 형식으로 살펴봅니다. 각 사람을 열면 왼쪽에 세부 정보가 있고 오른쪽에 출석, 헌금, 그룹, 메모, 양식 요약이 있는 하나의 기록 페이지가 열립니다.
- **[그룹](./groups/)** - 가입 요청, 회원 관리, 그룹 이메일, 개인화된 그룹 문자, 인쇄 가능한 연락처 명단을 갖춘 교회 그룹을 만들고 구성합니다. 각 그룹을 열면 왼쪽에 작업이 있고 오른쪽에 회원, 세션, 캘린더, 상태 요약이 있는 하나의 페이지가 열립니다.
- **[출석](./attendance/)** - 캠퍼스와 서비스 시간을 설정하고, 인쇄 가능한 반 출석부로 이름별 출석을 추적하고, 아직 입력하지 않은 반을 확인하고, 추세 보고서와 함께 간단한 인원 집계를 기록합니다. 또한 각 서비스 시간에 체크인 일정을 설정하여 셀프 체크인이 자동으로 열리고 닫히도록 할 수 있습니다.
- **[헌금](./donations/)** - 여러 통화로 헌금을 기록하고, 기금을 관리하고, 한 사람의 기록에서 단건 헌금을 입력하고, 배치를 인쇄(한 번에 하나 또는 날짜 범위의 모든 배치)하며 기금별 소계를 포함하고, 교회 로고가 찍힌 명세서를 생성합니다.
- **[봉사](./serving/)** - 봉사자를 조직하고, 서비스 계획을 만들고(또는 최대 12주까지 주간 복사), 푸시, 이메일 또는 문자로 알림을 보내고, **Text Volunteers**로 배정된 모든 사람에게 문자를 보내고, 작업을 관리하며, 이메일과 문자를 자동으로 보낼 수 있는 단계별 워크플로를 진행합니다.
- **[양식](./forms/)** - 등록 및 데이터 수집을 위한 맞춤 양식을 만듭니다.
- **[보고서](./reports/)** - 생일, 출석, 헌금 보고서를 확인합니다.
- **[웹사이트](./website/)** - 맞춤 탐색 스타일로 교회 웹사이트를 만들고 관리하며, GA4 ID로 웹사이트와 B1 앱의 방문을 추적하고, 공개 사이트를 끄고 회원 포털만 남길 수 있습니다.
- **[설교](./sermons/)** - 설교 라이브러리, 라이브 스트리밍, 자동 팟캐스트 피드를 관리합니다.
- **[캘린더](./calendars/)** - 큐레이션된 캘린더를 만들고, 방이나 자원 예약을 관리하며, 사용 가능 여부를 확인합니다.
- **[설정](./settings/)** - 빠른 이동 목록이 있는 하나의 스크롤 페이지에서 모든 것을 설정합니다. 교회 정보, 지역, 날짜 및 전화번호 형식, 문자 메시지, 역할, 권한, 맞춤 사람 필드를 포함합니다.

:::info
모든 페이지의 오른쪽 상단에 있는 물음표 아이콘을 클릭하면 도움말과 문서에 빠르게 접근할 수 있습니다. 색상 테마(**Default**, **Classic**, **Custom**)를 변경하거나 라이트 모드와 다크 모드를 전환하려면 사용자 메뉴를 열고 **Theme Preferences**를 사용하세요.
:::

지원이 필요하면 [support@churchapps.org](mailto:support@churchapps.org)로 이메일을 보내 주세요.
