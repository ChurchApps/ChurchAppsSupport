# B1 Admin 개요

<div class="article-intro">

B1 Admin은 교회 관리 대시보드입니다. 교인 디렉터리와 헌금부터 웹사이트 구축과 라이브 스트리밍까지, 교회 운영의 모든 측면을 관리하는 도구를 한곳에서 제공합니다.

</div>

## 시작하기

1. 브라우저를 열고 [admin.b1.church](https://admin.b1.church)로 이동합니다.
2. 사용자 이름과 비밀번호로 로그인합니다.
3. 홈 페이지인 **Dashboard**가 열립니다. 이번 주 예배 순서, 실시간으로 체크인하고 봉사 중인 사람, 승인 대기나 가입 요청처럼 확인이 필요한 항목, 미완료 작업, 그리고 소속 그룹을 보여 줍니다.

:::tip
B1 Admin이 처음이라면 먼저 [소개](./introduction) 페이지에서 동영상 안내를 확인한 다음, [설정](./settings/)에서 교회 정보를 구성하고 팀을 초대하세요.
:::

## 나의 대시보드

Dashboard는 B1 Admin의 홈 페이지(`/`)입니다. 교회의 주간 예배를 중심으로 구성되어 있습니다:

- **This week's service** -- 현재 또는 다가오는 계획의 이름과 예배 순서이며, 전체 계획으로 이동하는 링크가 있습니다.
- **Live status** -- 주일에 사람들이 체크인하기 시작하면, 현재 예배실에 있는 인원, 이 시간에 봉사하는 사람, 첫 방문자, 수용 인원 막대가 포함된 방별 현황을 보여 줍니다.
- **Needs Attention** -- 조치가 필요한 승인 대기 항목과 그룹 가입 요청입니다.
- **My tasks**와 **My Groups** -- 미완료 작업(**Add Task**로 추가하거나, **All tasks**를 클릭하여 전체 목록을 확인)과 내가 속한 그룹입니다.

Dashboard에 표시되는 내용은 [역할](./settings/roles-permissions.md)에 따라 달라집니다. 예를 들어 전체 계획 링크는 계획을 열 수 있는 경우에만 나타납니다(계획을 편집할 수 있거나, 계획의 사역에 속해 있거나, 해당 계획에서 봉사하는 경우). **All groups** 링크는 그룹을 관리하거나, 그룹 구성원을 보거나, 교인을 볼 수 있는 경우에만 나타납니다.

:::tip
Sermons, Calendars, Mobile, Settings를 포함한 모든 섹션은 B1 Admin 왼쪽 상단의 [Jump 메뉴](./introduction.md#getting-around-with-the-jump-menu)에 있습니다. 메뉴를 클릭하거나 **Ctrl+K**(또는 **Cmd+K**)를 누른 다음, 찾아보거나 입력을 시작하세요.
:::

## 주요 기능

- **[People](./people/)** - 교회 디렉터리를 관리하고, 교인을 추가하며, 데이터를 일괄 편집하고, 가구별 또는 정렬 가능한 표 형태로 탐색합니다. 각 교인은 하나의 레코드 페이지로 열리며, 왼쪽에는 상세 정보가, 옆에는 출석, 헌금, 그룹, 메모, 양식 요약이 표시됩니다.
- **[Groups](./groups/)** - 가입 요청, 구성원 관리, 그룹 이메일, 맞춤형 그룹 문자, 인쇄 가능한 연락처 명단을 갖춘 교회 그룹을 만들고 정리합니다. 각 그룹은 하나의 페이지로 열리며, 왼쪽에는 작업 버튼이, 옆에는 구성원, 세션, 달력, 상태 요약이 표시됩니다.
- **[Attendance](./attendance/)** - 캠퍼스와 예배 시간을 설정하고, 이름 단위 출석을 기록하며 인쇄 가능한 반 출석부를 제공합니다. 아직 출석이 입력되지 않은 반을 확인하고, 추세 보고서와 함께 간단한 인원 집계를 기록하며, 각 예배 시간에 체크인 일정을 설정하여 셀프 체크인이 자동으로 열리고 닫히도록 할 수 있습니다.
- **[Donations](./donations/)** - 여러 통화로 헌금을 기록하고, 펀드를 관리하며, 교인의 레코드에서 헌금 한 건을 기록하고, 묶음을 펀드별 소계와 함께 인쇄하며(한 번에 하나씩 또는 날짜 범위의 모든 묶음), 집계가 끝난 묶음을 마감하고, **Enter Donations** 권한으로 계수 팀이 헌금을 입력하도록 하며, 교회 로고가 인쇄된 명세서를 생성합니다.
- **[Serving](./serving/)** - 봉사자를 조직하고, 예배 계획을 만들거나(주 단위로 최대 12주까지 복사 가능), 푸시, 이메일, 문자로 알림을 보내고, **Text Volunteers**로 배정된 모든 사람에게 문자를 보내고, 작업을 관리하며, 이메일과 문자를 자동으로 보낼 수 있는 단계별 워크플로를 운영합니다.
- **[Forms](./forms/)** - 등록 및 데이터 수집을 위한 맞춤형 양식을 만듭니다.
- **[Reports](./reports/)** - 생일, 출석, 헌금 보고서를 확인합니다.
- **[Website](./website/)** - 맞춤형 내비게이션 스타일로 교회 웹사이트를 구축하고 관리합니다. GA4 ID로 웹사이트와 B1 앱 방문을 추적하거나, 공개 사이트를 끄고 교인 포털만 유지할 수 있습니다.
- **[Sermons](./sermons/)** - 설교 라이브러리, 라이브 스트리밍, 자동 팟캐스트 피드를 관리합니다.
- **[Calendars](./calendars/)** - 큐레이션된 달력을 만들고, 방과 리소스 예약을 관리하며, 가용성을 확인합니다.
- **[Settings](./settings/)** - 빠른 이동 목록이 있는 하나의 스크롤 페이지에서 모든 것을 설정합니다. 교회 정보, 지역, 날짜 및 전화번호 형식, 문자 메시지, 역할, 권한, 사용자 지정 교인 필드가 포함됩니다.

:::info
페이지 오른쪽 위의 물음표 아이콘을 클릭하면 언제든지 도움말과 문서에 빠르게 접근할 수 있습니다. 색상 테마(**Default**, **Classic**, **Custom**)를 변경하거나 라이트 모드와 다크 모드를 전환하려면 사용자 메뉴를 열고 **Theme Preferences**를 사용하세요.
:::

도움이 필요하면 [support@churchapps.org](mailto:support@churchapps.org)로 이메일을 보내세요.
