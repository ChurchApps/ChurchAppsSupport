# 페이지 편집기 사용하기

<div class="article-intro">

B1 페이지 편집기는 코드를 작성하지 않고도 교회 웹사이트 페이지를 디자인할 수 있는 시각적 드래그 앤 드롭 빌더입니다. 섹션과 콘텐츠 블록을 추가하고, 스타일을 조정하고, 미리 보고, 변경 사항을 되돌릴 수 있습니다. 모든 작업을 브라우저 안에서 할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [초기 설정](initial-setup)을 완료하여 웹사이트를 구성하세요
- [페이지 관리](managing-pages)에서 페이지를 하나 이상 만드세요
- 편집기에 접근하려면 **content.edit** 권한이 필요합니다

</div>

## 편집기 열기

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Website**를 펼친 다음 **Pages**를 클릭합니다.
2. 페이지 표에서 편집할 페이지를 찾아 **Edit Content**를 클릭합니다.

편집기가 전체 화면 모드로 열립니다. 왼쪽 패널에는 페이지 구조와 사용 가능한 콘텐츠 요소가 표시되고, 가운데 영역에는 페이지의 실시간 미리 보기가 표시됩니다.

:::info
편집기는 B1 Admin의 테마 설정과 관계없이 항상 밝은 모드로 표시되며, [모양](appearance)에서 선택한 제목 및 본문 글꼴을 사용합니다. 이렇게 해야 미리 보기가 웹사이트 방문자에게 보이는 실제 모습과 정확히 일치합니다.
:::

## 페이지 구조: 섹션과 요소

모든 페이지는 두 단계로 구성됩니다.

- **섹션** -- 페이지를 가로 띠로 나누는 최상위 컨테이너입니다(예: 히어로 섹션, 콘텐츠 블록, 푸터 띠). 콘텐츠를 추가하려면 모든 페이지에 섹션이 최소 하나 있어야 합니다.
- **요소** -- 섹션 안에 배치하는 개별 콘텐츠 조각으로, 텍스트, 이미지, 버튼, 카드, 양식, 캘린더 등이 있습니다.

### 섹션 추가하기

1. **Add Section**을 클릭합니다(또는 왼쪽 패널 상단의 **+** 버튼을 클릭합니다).
2. 시작 방식을 선택합니다.
   - **템플릿에서 시작** -- 카테고리(Hero, About, Services, Giving 등)별로 정리된 섹션 템플릿 갤러리를 둘러보고, 하나를 클릭하면 스타일이 완성되고 내용이 채워진 섹션이 삽입됩니다. 추가한 뒤 모든 항목을 수정할 수 있습니다.
   - **빈 섹션** -- 열 레이아웃(단일, 2열, 3열 등)을 선택하고 처음부터 만듭니다.
3. 새 섹션이 미리 보기에 나타납니다. 섹션을 클릭하여 선택한 다음 배경색, 여백 및 기타 스타일 옵션을 설정합니다.

### 섹션 레이아웃 전환하기

섹션을 이미 만들었지만 다른 구조를 원한다면 해당 섹션의 레이아웃 전환기를 사용하세요. 기존 콘텐츠와 요소를 그대로 유지하면서 열 배치를 갤러리의 다른 배치로 바꿀 수 있습니다.

### 섹션에 요소 추가하기

1. 미리 보기에서 섹션 안을 클릭하여 선택합니다.
2. **Add Content**를 클릭하고 목록에서 요소 유형을 선택합니다.
   - **Text** -- 제목, 단락, 서식 있는 텍스트
   - **Image** -- 사진을 업로드하거나 링크로 연결
   - **Button** -- 클릭 가능한 행동 유도(CTA) 링크
   - **Card** -- 제목과 설명이 있는 이미지
   - **Form** -- 페이지에 [양식](../forms/creating-forms)을 직접 삽입
   - **Calendar** -- 이벤트 캘린더 표시
   - **FAQ** -- 아코디언 형식의 질문과 답변 블록
   - **Video** -- URL로 동영상 삽입
   - **Groups Browser** -- 선택적 검색, 카테고리 필터, 라벨 필터가 있는 모든 교회 그룹의 필터링 가능한 디렉터리
   - **Icon Feature** -- 기능이나 사역 소개를 위한 아이콘, 제목, 짧은 설명
   - **Gallery** -- 여러 사진을 격자 또는 메이슨리 레이아웃으로 표시
   - **Testimonial** -- 작성자 이름, 역할, 사진이 포함된 한 개 이상의 인용문
   - **Social Icons** -- 교회의 소셜 미디어 프로필로 연결되는 아이콘
   - **Countdown** -- 특정 날짜 또는 주간 예배 시간까지의 타이머
   - **Stats** -- 큰 숫자와 라벨의 행(구성원 수, 연수, 캠퍼스 등)
   - **Campaign Progress** -- 헌금 캠페인의 실시간 진행률 막대로, 기금 목표에 대해 모금된 총액을 보여줌
   - **Staff Grid** -- 그룹 구성원의 사진 카드. 그룹의 **공개 명단** 옵션이 켜져 있어야 합니다
   - **Service Times** -- 출석 설정에서 자동으로 가져온 캠퍼스별 예배 일정
   - **Sermons** -- 전체 브라우저 또는 격자, 목록, 최신 강조 레이아웃으로 보여주는 설교 라이브러리
   - **Map** -- 교회 주소를 중심으로 한 내장 지도
   - **Table** -- 표 형식의 콘텐츠를 위한 간단한 행과 열의 격자
   - **Text with Photo** -- 텍스트와 이미지를 나란히 배치
   - **Logo** -- [모양](appearance)에서 가져온 교회 로고
   - **Live Stream** -- 라이브 스트림 플레이어를 페이지에 직접 삽입
   - **Podcast** -- 직접 입력한 외부 팟캐스트 RSS 피드 URL에서 가져온 에피소드 목록이며, 표시할 에피소드 수와 날짜 및 설명 표시 여부를 설정할 수 있습니다. 이는 사이트에 다른 팟캐스트 피드를 소개하기 위한 기능입니다. 자신의 설교를 팟캐스트로 게시하려면 대신 [설교 관리](../sermons/managing-sermons.md#your-podcast-feed)를 참조하세요.
   - **Donation** -- 헌금 버튼 또는 내장 헌금 양식
   - **HTML** -- 직접 작성한 원시 HTML로, 타사 위젯 삽입 같은 고급 용도에 사용합니다([HTML 요소 사용하기](#using-the-html-element) 참조)
   - **iFrame** -- URL로 외부 콘텐츠를 삽입
3. 나타나는 설정 패널에서 요소를 구성합니다.

### HTML 요소 사용하기 {#using-the-html-element}

**HTML** 요소에는 두 개의 입력 상자가 있습니다.

- **HTML Content** -- 페이지에 표시할 마크업입니다. 여기에 포함한 `<script>` 태그는 실제 사이트에서 실행됩니다.
- **JavaScript (exclude script tag)** -- 페이지가 로드될 때 실행되는 스크립트 코드입니다. 여기에 `<script>` 태그를 포함한 채로 외부 업체의 임베드 코드를 붙여넣을 수도 있으며, 실제 사이트에서 실행됩니다.

JavaScript 상자에 웹 주소만 붙여넣으면(예: 이미지 링크) 상자가 빨간색으로 바뀌고 *"This is a web address, not JavaScript."*(이것은 웹 주소이며 JavaScript가 아닙니다.)라는 경고가 표시됩니다. 이 상자에 있는 주소는 아무 작업도 하지 않습니다. 그림을 표시하려면 **Image** 요소를 사용하거나 **HTML Content**에 `<img src="...">`를 입력하세요.

### 캘린더 요소 사용하기 {#using-the-calendar-element}

**Calendar** 요소는 캘린더 중 하나의 이벤트를 보여줍니다.

1. **Select**에서 **Group Calendar**(한 그룹의 이벤트이며, 목록에는 내가 속한 그룹이 표시됨) 또는 **Curated Calendar**(**Calendars**에서 직접 만든 캘린더, [큐레이션 캘린더](../calendars/curated-calendar) 참조)를 선택합니다.
2. **Select Calendar**에서 그룹 또는 캘린더를 고릅니다.
3. **Display**에서 표시 방식을 고릅니다.
   - **Month calendar** -- 방문자가 넘겨볼 수 있는 월간 격자입니다.
   - **Upcoming events** -- 다가오는 이벤트 12개를 타일 격자로 보여주며, 반복 이벤트는 다음 날짜에 한 번 표시됩니다. 각 타일에는 이벤트 사진(사진이 없으면 테마의 어두운 색상 위에 제목이 표시됨), 날짜 배지, 요일과 시간, 설명의 첫 줄이 표시됩니다. 타일 위의 **Subscribe** 버튼을 누르면 방문자가 캘린더의 ICS 링크를 복사하거나 파일을 내려받을 수 있습니다.
4. 일부 이벤트만 보여주려면 **Only events tagged**에 태그를 입력합니다(예: `youth`). **Tags**에 해당 단어가 포함된 이벤트만 나타납니다. 비워 두면 모든 이벤트가 표시됩니다. 태그는 각 이벤트에서 설정합니다. [이벤트 추가 및 편집](../calendars/creating-calendars.md#adding-and-editing-events)을 참조하세요.

두 표시 방식 모두에서 이벤트를 클릭하면 교회 웹사이트의 해당 이벤트 페이지가 열립니다. 이벤트 페이지에는 이벤트 사진, 제목, 날짜와 시간, 설명이 표시되며, **When**(반복 이벤트의 경우 반복 패턴 포함)과 **Where**(이벤트에 예약된 방)가 담긴 상자가 함께 있습니다. 등록이 켜져 있으면 **Register for this Event** 버튼이 나타나고, **Add to my calendar** 링크를 누르면 이벤트를 캘린더 파일로 내려받을 수 있습니다. 검색 엔진이 검색 결과에 이벤트의 날짜와 세부 정보를 표시할 수 있도록 페이지가 구성되어 있습니다.

### 콘텐츠 순서 바꾸기

각 항목 왼쪽의 손잡이 아이콘(점 여섯 개)을 드래그하여 섹션이나 요소의 순서를 바꿉니다. 섹션 안에서 요소를 드래그하거나 요소를 다른 섹션으로 옮길 수 있습니다.

## 페이지 꾸미기

### 섹션 스타일

섹션을 클릭하면 스타일 패널이 열립니다. 다음을 설정할 수 있습니다.

- **Background** -- 단색, 그라데이션 또는 이미지. 이미지 배경을 사용하면 **Focal Point** 선택기로 섹션 크기가 조정될 때 가운데에 유지될 이미지 부분을 클릭하여 정할 수 있고, **Overlay** 색상 옵션으로 이미지 위에 반투명 색조를 입혀 글자를 더 잘 읽히게 할 수 있습니다.
- **Padding** -- 섹션 내부의 위쪽 및 아래쪽 간격
- **Width** -- 전체 너비 또는 가운데 정렬/제한 너비
- **Dividers** -- 섹션의 위쪽 또는 아래쪽 가장자리에 놓는 장식용 모양 구분선(물결, 기울임, 곡선, 삼각형 등). 색상, 높이, 뒤집기 옵션을 설정할 수 있습니다

### 요소 스타일

요소를 클릭하면 스타일 패널이 열립니다. 일반적인 옵션으로는 글꼴 크기, 색상, 정렬, 바깥 여백, 안쪽 여백이 있습니다. 이미지의 경우 대체 텍스트와 링크 대상을 설정할 수 있습니다.

### 사용자 지정 CSS

고급 스타일링을 위해 각 섹션과 요소에는 **Custom CSS** 필드가 있으며, 여기에 직접 CSS 규칙을 작성할 수 있습니다. 이 규칙은 해당 요소에만 적용되므로 페이지의 다른 부분에 의도치 않게 영향을 주지 않습니다.

:::tip
사용자 지정 글꼴이나 전역 색상처럼 사이트 전체에 적용할 스타일이 필요하다면, 개별 페이지의 사용자 지정 CSS 대신 [모양](appearance) 설정을 사용하세요.
:::

## 페이지 미리 보기

도구 모음의 미리 보기 컨트롤로 여러 화면 크기에서 페이지가 어떻게 보이는지 확인하세요.

- **Desktop** -- 전체 너비의 브라우저 화면
- **Mobile** -- 좁은 휴대폰 크기 화면

방문자가 보는 그대로 실제 페이지를 보려면 페이지 목록으로 돌아가 페이지의 경로를 클릭하세요. 새 브라우저 탭에서 열립니다.

## 접근성 확인하기

도구 모음의 **Accessibility** 아이콘을 클릭하면 흔한 문제를 빠르게 확인할 수 있습니다. 대체 텍스트가 없는 이미지, 낮은 색상 대비, 순서가 맞지 않는 제목 등을 점검합니다. 각 문제는 해당 요소로 바로 연결되므로 그 자리에서 수정할 수 있습니다.

## 변경 사항 되돌리기

편집기는 편집 기록을 자동으로 저장합니다. 도구 모음 버튼이나 키보드 단축키를 사용하세요.

- **Undo** (Ctrl+Z / Cmd+Z) -- 마지막 작업을 되돌립니다
- **Redo** (Ctrl+Shift+Z 또는 Ctrl+Y / Cmd+Shift+Z) -- 되돌린 작업을 다시 적용합니다

저장된 이전 스냅샷으로 페이지를 복원할 수도 있습니다. 도구 모음의 **View history**를 클릭하면 설명이 붙은 저장된 스냅샷 목록이 표시되며, 항목을 클릭하면 해당 시점으로 복원됩니다.

:::warning
스냅샷을 복원하면 현재 페이지 콘텐츠가 스냅샷 버전으로 바뀝니다. 이 작업은 표준 실행 취소 버튼으로 되돌릴 수 없습니다. 이전 스냅샷으로 되돌리는 선택지를 남기고 싶다면, 복원하기 전에 현재 상태의 스냅샷을 먼저 저장하세요.
:::

## 저장 및 게시

작업하는 동안 변경 사항은 자동으로 저장됩니다. 도구 모음의 상태 표시기에서 변경 사항이 저장되었는지 확인할 수 있습니다.

### 임시 저장 및 게시 상태

페이지에는 **게시됨** 상태가 있으며, 이 상태에 따라 방문자가 변경 사항을 언제 보는지가 결정됩니다. 도구 모음에는 현재 상태를 보여주는 상태 칩이 표시됩니다.

- **Live on save** -- 페이지가 게시 워크플로를 사용하지 않습니다. 저장하는 모든 변경 사항이 즉시 공개됩니다. 새 페이지의 기본값입니다.
- **Unpublished changes** -- 페이지가 이전에 게시된 적이 있지만, 마지막 게시 이후 변경 사항이 있습니다. 방문자에게는 여전히 이전에 게시된 버전이 표시됩니다.
- **Published** -- 페이지가 공개되어 있으며, 저장된 콘텐츠가 방문자가 보는 내용과 일치합니다.

변경 사항을 게시하려면 도구 모음의 **Publish** 버튼을 클릭하세요. 페이지는 즉시 공개됩니다.

방문자가 보는 내용에 영향을 주지 않고 마지막으로 게시된 버전으로 되돌리려면, 더보기 메뉴(⋮)를 열고 **Discard unpublished changes**를 클릭하세요.

게시 워크플로 사용을 중단하려면 더보기 메뉴를 열고 **Turn off publishing**을 클릭하세요. 그러면 편집 내용이 다시 즉시 공개됩니다.

:::tip
페이지를 미리 준비해 두었다가 적절한 시점에만 공개하고 싶을 때 임시 저장/게시 워크플로를 사용하세요. 예를 들어 다가오는 행사를 위한 페이지라면, 페이지를 만들고 미리 본 다음 준비가 되었을 때 **Publish**를 클릭하세요.
:::
