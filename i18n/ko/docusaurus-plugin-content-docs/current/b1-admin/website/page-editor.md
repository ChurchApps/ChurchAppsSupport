# 페이지 편집기 사용하기

<div class="article-intro">

B1 페이지 편집기는 코드를 쓰지 않고도 교회 웹사이트 페이지를 디자인할 수 있는 시각적 드래그 앤 드롭 빌더입니다. 섹션과 콘텐츠 블록을 추가하고, 스타일을 맞춤 설정하고, 작업을 미리 보고, 변경 사항을 실행 취소할 수 있으며, 모두 브라우저 안에서 가능합니다.

</div>

## 편집기 열기 {#opening-the-editor}

1. B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Website**(웹사이트)를 펼친 다음 **Pages**(페이지)를 클릭하세요.
2. 페이지 표에서 편집할 페이지를 찾아 **Edit Content**(콘텐츠 편집)를 클릭하세요.

편집기는 페이지의 실시간 미리 보기와 함께 전체 화면으로 열립니다. 상단 도구 모음에는 **Exit**(나가기), 페이지의 게시 상태, **Undo**(실행 취소)와 **Redo**(다시 실행), 저장 상태, **Publish**(게시), 데스크톱 및 모바일 미리 보기 버튼, **Add Content**(콘텐츠 추가), 접근성 검사, **More**(더보기)(⋮) 메뉴가 있습니다. **Add Content**를 클릭하면 왼쪽에 **Add Elements**(요소 추가) 패널이 열리며, 섹션이나 요소를 클릭하면 오른쪽에 설정이 열립니다.

편집기에는 최소 약 880픽셀 너비의 화면이 필요합니다. 휴대폰에서는 태블릿이나 컴퓨터로 페이지를 열라는 메시지가 표시됩니다.

:::info
편집기는 B1 Admin의 테마 설정과 관계없이 항상 밝은 모드로 표시되며, [모양](./appearance.md)에서 선택한 제목 및 본문 글꼴을 사용합니다. 이렇게 해야 미리 보기가 웹사이트 방문자에게 보이는 페이지와 정확히 일치합니다.
:::

## 페이지 구조: 섹션과 요소 {#page-structure-sections-and-elements}

모든 페이지는 두 단계로 만들어집니다.

- **섹션** -- 페이지를 가로 띠로 나누는 최상위 컨테이너입니다(예: 히어로 섹션, 콘텐츠 블록, 바닥글 띠). 콘텐츠를 추가하려면 모든 페이지에 섹션이 최소 하나 있어야 합니다.
- **요소** -- 섹션 안에 놓이는 개별 콘텐츠 조각입니다. 텍스트, 이미지, 버튼, 카드, 양식, 달력 등이 있습니다.

### 섹션 추가하기 {#adding-a-section}

1. **Add Content**를 클릭하고 **Section**(섹션)을 페이지로 드래그하세요. 두 섹션 사이에 마우스를 올리면 나타나는 **+**(**Add section**(섹션 추가)) 버튼을 클릭해도 됩니다.
2. **Choose a Section Layout**(섹션 레이아웃 선택) 대화 상자에서 시작 방법을 고르세요.
   - **From a template**(템플릿에서) — 카테고리(Hero(히어로), About(소개), Services(예배), People(사람), Media(미디어), Giving(헌금), Call to Action(행동 유도))별로 섹션 템플릿을 둘러보고 하나를 클릭하면 완전히 스타일이 지정되고 내용이 채워진 섹션이 삽입됩니다. 추가한 후에는 무엇이든 맞춤 설정할 수 있습니다.
   - **Blank Section**(빈 섹션) — 처음부터 만들 수 있는 빈 섹션입니다. 열로 나누려면 그 안에 **Row**(행) 요소를 추가하세요.
3. 새 섹션이 미리 보기에 나타납니다. 섹션을 클릭하여 선택하면 배경, 색상, 기타 스타일 옵션을 설정할 수 있습니다.

섹션 위에 마우스를 올리면 도구 모음이 나타납니다. 여기에는 드래그 손잡이, **Section settings**(섹션 설정), **Move section up**(섹션 위로 이동), **Move section down**(섹션 아래로 이동), **Duplicate section**(섹션 복제), **Try another layout**(다른 레이아웃 시도), **Delete section**(섹션 삭제)이 있습니다.

### 섹션 레이아웃 바꾸기 {#switching-a-sections-layout}

이미 섹션을 만들었지만 다른 구조를 원한다면, 섹션의 도구 모음에서 **Try another layout**을 클릭하세요. 기존 내용과 요소는 그대로 둔 채, 갤러리에서 다른 배치로 바꿀 수 있습니다.

### 섹션에 요소 추가하기 {#adding-elements-to-a-section}

1. **Add Content**를 클릭하여 **Add Elements** 패널을 여세요. **Search Elements**(요소 검색) 또는 탭(**All**(전체), **Common**(일반), **Media**(미디어), **Church**(교회), **Advanced**(고급), 그리고 [재사용 블록](./blocks.md)을 만든 후에는 **Blocks**(블록))을 사용하여 요소를 찾으세요.
2. 요소를 미리 보기의 섹션으로 드래그하거나, 페이지에서 요소를 선택한 다음 카드를 클릭하면 그 바로 뒤에 새 요소가 추가됩니다. 요소의 종류는 다음과 같습니다.
   - **Row**(행) -- 섹션을 나란히 놓인 열로 나눕니다
   - **Box**(상자) -- 스타일이 지정된 컨테이너 안에 요소를 묶습니다
   - **Carousel**(캐러셀) -- 전체 너비 슬라이드를 차례로 보여줍니다
   - **White Space**(여백) -- 빈 세로 공간을 추가합니다
   - **Text**(텍스트) -- 제목, 단락, 리치 텍스트입니다
   - **Image**(이미지) -- 사진을 업로드하거나 링크합니다
   - **Button Link**(버튼 링크) -- 클릭할 수 있는 행동 유도 버튼입니다
   - **Card**(카드) -- 제목과 설명이 있는 이미지입니다
   - **Form**(양식) -- [양식](../forms/creating-forms.md)을 페이지에 직접 넣습니다. 양식에 [헤더 사진](../forms/creating-forms.md#adding-a-header-photo)이 있으면 질문 위에 표시됩니다
   - **Calendar**(달력) -- 행사 달력을 표시합니다
   - **Expandable**(펼치기) -- 아코디언 방식의 질문과 답변 블록입니다
   - **Video**(영상) -- URL로 영상을 삽입합니다
   - **Groups Browser**(그룹 탐색기) -- 모든 교회 그룹의 필터링 가능한 디렉터리입니다. 선택적으로 검색, 분류 필터, 라벨 필터를 제공합니다. **Layout**(레이아웃)은 **Grid**(격자)(기본값) 또는 **Scrolling (automatic)**(자동 스크롤)일 수 있습니다. [스크롤 레이아웃](#scrolling-layouts)을 참고하세요
   - **Group List**(그룹 목록) -- 공개 그룹의 타일입니다. 선택적으로 특정 라벨이 붙은 그룹만 표시할 수 있습니다. **Layout**은 **Grid**(기본값으로, 한 줄에 최대 세 개의 타일) 또는 **Scrolling (automatic**)일 수 있습니다. [스크롤 레이아웃](#scrolling-layouts)을 참고하세요
   - **Icon Feature**(아이콘 강조) -- 아이콘, 제목, 짧은 설명이 있으며, 특징이나 사역 소개에 사용합니다
   - **Gallery**(갤러리) -- 여러 사진을 격자나 메이슨리 레이아웃으로 보여줍니다
   - **Testimonial**(간증) -- 작성자 이름, 역할, 사진과 함께 하나 이상의 인용문을 보여줍니다
   - **Social Icons**(소셜 아이콘) -- 교회의 소셜 미디어 프로필로 연결되는 아이콘입니다. Facebook, Instagram, WhatsApp, YouTube, X, TikTok, Vimeo, Podcast가 있습니다. 보여 줄 각 프로필에 링크를 입력하세요. **WhatsApp**의 경우 전화번호가 담긴 `https://wa.me/` 링크나 그룹 초대 링크를 사용하세요
   - **Countdown**(카운트다운) -- 날짜나 주간 예배 시간까지 줄어드는 타이머입니다
   - **Stats**(통계) -- 큰 숫자와 레이블(구성원, 연수, 캠퍼스 등)이 나열된 줄입니다
   - **Campaign Progress**(캠페인 진행 상황) -- 헌금 캠페인의 실시간 진행 막대로, 헌금 항목의 목표액을 향해 모인 금액을 보여줍니다
   - **Staff Grid**(직원 격자) -- 그룹 구성원의 사진 카드입니다. 그룹의 **public roster**(공개 명단) 옵션이 켜져 있어야 합니다
   - **Service Times**(예배 시간) -- 캠퍼스의 예배 일정으로, 출석 설정에서 자동으로 가져옵니다
   - **Sermons**(설교) -- 설교 라이브러리를 전체 탐색기나 격자, 목록, 최신 추천 레이아웃으로 보여줍니다
   - **Location**(위치) -- 교회 주소를 중심으로 한 지도를 삽입합니다
   - **Table**(표) -- 표 형태의 내용을 위한 간단한 행과 열 격자입니다
   - **Text with Photo**(사진이 있는 텍스트) -- 텍스트와 이미지를 나란히 배치합니다
   - **Logo**(로고) -- [모양](./appearance.md)에서 가져온 교회 로고입니다
   - **Stream**(스트림) -- 실시간 스트림 플레이어를 페이지에 직접 삽입합니다
   - **Podcast**(팟캐스트) -- 입력한 외부 팟캐스트 RSS 피드 URL에서 가져온 에피소드 목록입니다. 보여 줄 에피소드 수와 날짜 및 설명 표시 여부를 설정할 수 있습니다. 실제 사이트의 각 에피소드에는 오디오 플레이어와 에피소드 제목 아래에 오디오 파일을 저장하는 **Download**(다운로드) 링크가 있습니다. 이는 사이트에 어떤 팟캐스트 피드든 소개하기 위한 것입니다. 자신의 설교를 팟캐스트로 게시하려면 [설교 관리](../sermons/managing-sermons.md#your-podcast-feed)를 참고하세요.
   - **Donation**(헌금) -- 페이지에 삽입하는 전체 헌금 양식입니다
   - **Donate Link**(헌금 링크) -- 헌금 페이지를 여는 버튼입니다
   - **HTML** -- 고급 사용을 위한 직접 작성한 HTML입니다. 예를 들어 타사 위젯을 삽입할 때 사용합니다([HTML 요소 사용하기](#using-the-html-element) 참고)
   - **Embedded Page**(삽입된 페이지) -- URL로 지정한 다른 웹 페이지를 프레임 안에 삽입합니다
3. 나타나는 설정 패널에서 요소를 구성하세요.

### HTML 요소 사용하기 {#using-the-html-element}

**HTML** 요소에는 두 개의 상자가 있습니다.

- **HTML Content**(HTML 내용) -- 페이지에 표시할 마크업입니다. 여기에 포함한 `<script>` 태그는 실제 사이트에서 실행됩니다.
- **JavaScript (exclude script tag)**(JavaScript(script 태그 제외)) -- 페이지가 로드될 때 실행되는 스크립트 코드입니다. 공급업체의 임베드 코드를 `<script>` 태그를 포함한 채로 여기에 붙여 넣을 수도 있으며, 실제 사이트에서 실행됩니다.

JavaScript 상자에 웹 주소(예: 이미지 링크)만 붙여 넣으면, 상자가 빨간색으로 바뀌고 *"This is a web address, not JavaScript."*(이것은 웹 주소이며 JavaScript가 아닙니다.)라는 경고가 표시됩니다. 이 상자에 주소만 넣으면 아무 일도 일어나지 않습니다. 사진을 보여주려면 **Image** 요소를 사용하거나, **HTML Content**에 `<img src="...">`를 넣으세요.

### 달력 요소 사용하기 {#using-the-calendar-element}

**Calendar**(달력) 요소는 교회의 달력 중 하나에서 행사를 보여줍니다.

1. **Select**(선택) 아래에서 **Group Calendar**(그룹 달력)(한 그룹의 행사이며, 목록에는 여러분이 속한 그룹이 나타납니다) 또는 **Curated Calendar**(큐레이션 달력)(**Calendars**에서 만든 달력입니다. [큐레이션 달력](../calendars/curated-calendar.md)을 참고하세요) 중 하나를 고르세요.
2. **Select Calendar**(달력 선택) 아래에서 그룹이나 달력을 고르세요.
3. **Display**(표시) 아래에서 보여주는 방식을 고르세요.
   - **Month calendar**(월간 달력) -- 방문자가 넘겨 볼 수 있는 월 단위 격자입니다. 각 행사는 속한 그룹의 색으로 표시되므로, 그룹의 행사는 모든 달력에서 같은 색을 가집니다. B1이 색을 자동으로 고르므로 따로 설정할 것이 없습니다.
   - **Upcoming events**(다가오는 행사) -- 다음 12개 행사의 타일 격자입니다. 반복되는 행사는 다음 날짜에 한 번 표시됩니다. 각 타일에는 행사 사진(사진이 없으면 테마의 어두운 색 위에 제목), 날짜 배지, 요일과 시간, 설명의 첫 줄이 표시됩니다. 타일 위의 **Subscribe**(구독) 버튼을 누르면 방문자가 달력의 ICS 링크를 복사하거나 다운로드할 수 있습니다. 이 표시 방식에는 **Layout**(레이아웃) 설정이 나타납니다. **Grid**(격자)(기본값) 또는 **Scrolling (automatic)**(자동 스크롤) 중 하나이며, 자동 스크롤은 타일을 한 줄에 놓고 스스로 움직이게 합니다([스크롤 레이아웃](#scrolling-layouts) 참고). **Curated Calendar**의 경우 **Group badge**(그룹 배지) 설정을 켜면, 각 행사의 그룹 이름이 타일 오른쪽 위 모서리에 그 그룹의 달력 색으로 표시됩니다. 보관되었거나 비공개인 그룹의 행사에는 배지가 붙지 않습니다.
4. 일부 행사만 보여주려면 **Only events tagged**(다음 태그가 있는 행사만) 상자에 태그를 입력하세요. 예를 들어 `youth`입니다. **Tags**(태그)에 그 단어가 포함된 행사만 나타납니다. 모든 행사를 보여주려면 비워 두세요. 태그는 각 행사에서 설정합니다. [행사 추가 및 편집하기](../calendars/creating-calendars.md#adding-and-editing-events)를 참고하세요.

어느 표시 방식이든 행사를 클릭하면 웹사이트의 행사 자체 페이지가 열립니다. 행사 페이지에는 행사 사진, 제목, 날짜와 시간, 설명과 함께 **When**(언제)(반복 행사의 경우 반복 패턴 포함)과 **Where**(어디서)(예약된 공간)가 담긴 상자가 있습니다. 등록이 켜져 있으면 **Register for this Event**(이 행사에 등록) 버튼도 있으며, **Add to my calendar**(내 달력에 추가) 링크를 누르면 행사를 달력 파일로 다운로드할 수 있습니다. 이 페이지는 검색 엔진이 검색 결과에 행사의 날짜와 세부 정보를 표시할 수 있도록 구성되어 있습니다. 페이지에 표시된 큐레이션 달력의 행사 페이지(향후 6개월 행사)도 사이트맵에 나열되므로, 검색 엔진이 찾을 수 있습니다.

### 스크롤 레이아웃 {#scrolling-layouts}

**Groups Browser**, **Group List**, Calendar 요소의 **Upcoming events** 표시 방식에 있는 **Scrolling (automatic)**(자동 스크롤) 레이아웃은, 타일을 격자 대신 한 줄에 놓습니다. 휴대폰에서는 각 타일이 줄의 전체 너비를 채우고, 컴퓨터에서는 두 개의 타일이 나란히 들어갑니다. 한 번에 들어갈 수 있는 것보다 타일이 많으면 이 줄은 다음과 같이 작동합니다.

- 약 4초마다 타일 하나씩 앞으로 움직이며, 마지막 타일 다음에는 다시 첫 타일로 돌아갑니다.
- 방문자가 그 위에 마우스를 올리거나, 터치하거나, 탭으로 이동하면 일시 정지되며, 몇 초 후 다시 시작합니다.
- 아래에 점들이 줄지어 나타나며, 타일마다 점이 하나씩 있고 현재 타일의 점이 채워져 있습니다. 방문자는 점을 클릭하여 해당 타일로 바로 이동할 수 있습니다.

동작 줄이기가 설정된 기기에서는 줄이 움직이지 않으며, 방문자가 직접 밀거나 스크롤하여 볼 수 있습니다. 타일이 모두 들어가면 줄은 움직이지 않고 점도 나타나지 않습니다.

### 내용 순서 바꾸기 {#reordering-content}

각 항목 왼쪽의 손잡이 아이콘(점 여섯 개)을 드래그하여 섹션이나 요소의 순서를 바꾸세요. 섹션 안에서 요소를 드래그하거나 섹션 사이로 옮길 수 있습니다.

## 페이지 스타일 지정하기 {#styling-your-page}

### 섹션 스타일 {#section-styles}

섹션을 클릭하면 스타일 패널이 열립니다. 다음을 설정할 수 있습니다.

- **Colors**(색상) -- **Suggested**(추천) 탭에서 팔레트의 색상 조합 중 하나를 클릭하세요. **Custom**(사용자 지정) 탭에서는 **Background Type**(배경 유형)(**Color**(색), **Image**(이미지), **YouTube Video**(YouTube 영상))과 제목, 텍스트, 링크 색을 설정하세요. 이미지 배경을 사용할 때는 이미지를 클릭하여 초점(이미지를 자를 때 보이는 부분)을 설정하고, **Overlay Color**(오버레이 색)와 **Background Opacity**(배경 불투명도)를 사용하여 이미지에 색조를 입혀 텍스트가 잘 읽히도록 하세요.
- **Visibility**(표시 여부) -- **Hide on desktop**(데스크톱에서 숨기기) 또는 **Hide on mobile**(모바일에서 숨기기)
- **Styles**(스타일) -- 위아래 여백 같은 개별 스타일 설정을 모든 기기, 데스크톱만, 또는 모바일만 적용하도록 추가하세요
- **Animations**(애니메이션) -- 섹션이 화면에 스크롤되어 들어올 때의 효과와 속도입니다
- **Shape Dividers**(모양 구분선) -- 섹션의 위쪽이나 아래쪽 가장자리에 놓이는 장식 모양(wave(물결), waves(여러 물결), slant(기울기), curve(곡선), peaks(봉우리), triangle(삼각형))으로, 색, 높이, 뒤집기 옵션이 있습니다

섹션 설정에는 **Duplicate**(복제)와 **Convert To Block**(블록으로 변환)도 있습니다. 후자는 섹션을 새 [재사용 블록](./blocks.md)으로 복사합니다.

### 요소 스타일 {#element-styles}

요소를 클릭하면 스타일 패널이 열립니다. 일반적인 옵션은 글꼴 크기, 색, 정렬, 여백, 안쪽 여백입니다. 이미지의 경우 대체 텍스트와 링크 대상을 설정할 수 있습니다.

### 하나의 섹션이나 요소에만 적용하는 스타일 {#styles-for-one-section-or-element}

더 세밀하게 제어하려면, 섹션이나 요소의 설정에서 **Styles** 패널을 열고 **All**(전체), **Desktop Only**(데스크톱 전용), **Mobile Only**(모바일 전용) 아래의 **Add a style**(스타일 추가)을 클릭하세요. 각 스타일은 그 섹션이나 요소에만 적용되므로, 페이지의 나머지 부분에는 영향을 주지 않습니다.

:::tip
사용자 지정 글꼴이나 전역 색상처럼 사이트 전체에 스타일을 적용해야 한다면, 개별 페이지의 사용자 지정 CSS 대신 [모양](./appearance.md) 설정을 사용하세요.
:::

## 페이지 미리 보기 {#previewing-your-page}

도구 모음의 미리 보기 컨트롤을 사용하여 여러 화면 크기에서 페이지가 어떻게 보이는지 확인하세요.

- **Desktop**(데스크톱) -- 전체 너비 브라우저 보기
- **Mobile**(모바일) -- 휴대폰 크기의 좁은 보기

휴대폰에서는, 행의 설정에서 **Mobile Width**(모바일 너비)를 지정하지 않는 한 행의 열들이 전체 너비로 한 줄씩 쌓입니다. 설교와 팟캐스트 목록도 휴대폰에서는 각 에피소드의 텍스트를 썸네일 아래에 쌓아 보여줍니다.

방문자가 보는 것과 정확히 같은 실제 페이지를 보려면 페이지 목록으로 돌아가 페이지의 경로를 클릭하세요. 새 브라우저 탭에서 열립니다.

## 접근성 확인하기 {#checking-accessibility}

도구 모음의 **Check accessibility**(접근성 확인) 아이콘을 클릭하세요(문제가 발견되면 개수가 표시됩니다). 대체 텍스트가 없는 이미지, 낮은 색 대비, 순서가 맞지 않는 제목 같은 흔한 문제를 빠르게 검사합니다. 각 문제는 해당 요소로 바로 연결되므로, 그 자리에서 고칠 수 있습니다.

## 변경 사항 실행 취소하기 {#undoing-changes}

편집기는 편집 기록을 자동으로 추적합니다. 도구 모음 버튼이나 키보드 단축키로 이동하세요.

- **Undo**(실행 취소)(Ctrl+Z / Cmd+Z) -- 마지막 작업을 되돌립니다
- **Redo**(다시 실행)(Ctrl+Shift+Z 또는 Ctrl+Y / Cmd+Shift+Z) -- 되돌린 작업을 다시 적용합니다

더 이전 시점으로 이동할 수도 있습니다. 도구 모음의 **More**(⋮) 메뉴를 열고 **View history**(기록 보기)를 클릭하세요. **Edit History**(편집 기록) 대화 상자에는 각 변경 사항이 시간과 함께 나열되며, 현재 위치는 **(current)**(현재)로 표시됩니다. 항목(또는 그 **Restore to this point**(이 시점으로 복원) 버튼)을 클릭하면 페이지가 그 시점의 모습으로 돌아갑니다.

:::info
복원한 시점 이후의 변경 사항은 기록에 남아 있으므로, **Redo**를 사용하거나 나중의 항목을 선택하여 다시 앞으로 갈 수 있습니다. 새로운 편집을 하면 그 이후의 항목은 새 편집으로 대체됩니다.
:::

## 저장 및 게시하기 {#saving-and-publishing}

작업하는 동안 변경 사항은 자동으로 저장됩니다. 도구 모음의 상태 표시기는 변경 사항이 저장되었는지 보여줍니다.

### 초안과 게시 상태 {#draft-and-published-state}

페이지에는 **게시됨** 상태가 있으며, 이는 방문자가 변경 사항을 언제 볼 수 있는지 제어합니다. 도구 모음에는 현재 상태를 보여주는 상태 칩이 표시됩니다.

- **Live on save**(저장 시 바로 공개) -- 페이지가 게시 워크플로를 사용하지 않습니다. 저장한 모든 변경 사항은 즉시 공개됩니다. 새 페이지의 기본값입니다.
- **Unpublished changes**(게시되지 않은 변경 사항) -- 페이지를 이전에 게시한 적이 있지만, 마지막 게시 이후 변경했습니다. 방문자는 여전히 이전에 게시된 버전을 봅니다.
- **Published**(게시됨) -- 페이지가 공개되어 있으며, 저장된 내용이 방문자가 보는 내용과 일치합니다.

변경 사항을 게시하려면 도구 모음의 **Publish**(게시) 버튼을 클릭하세요. 페이지가 즉시 공개됩니다.

방문자가 보는 내용에 영향을 주지 않고 마지막으로 게시된 버전으로 되돌리려면, 더보기 메뉴(⋮)를 열고 **Discard unpublished changes**(게시되지 않은 변경 사항 취소)를 클릭하세요.

게시 워크플로 사용을 중단하려면, 더보기 메뉴를 열고 **Turn off publishing**(게시 끄기)을 클릭하세요. 그러면 이후 편집은 다시 즉시 공개됩니다.

:::tip
페이지를 미리 준비하고 적절한 순간에만 공개하고 싶을 때, 예를 들어 다가오는 행사를 위해 초안/게시 워크플로를 사용하세요. 페이지를 만들고 미리 본 다음, 준비가 되면 Publish를 클릭하세요.
:::
