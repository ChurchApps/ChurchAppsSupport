# 페이지 편집기 사용하기 {#using-the-page-editor}

<div class="article-intro">

B1 페이지 편집기는 코드를 작성하지 않고도 교회 웹사이트 페이지를 디자인할 수 있는 시각적 드래그 앤 드롭 빌더입니다. 섹션과 콘텐츠 블록을 추가하고, 스타일을 사용자 지정하고, 작업 결과를 미리 보고, 변경 사항을 되돌릴 수 있습니다. 모든 작업은 브라우저 안에서 이루어집니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [초기 설정](initial-setup)을 완료하여 웹사이트를 구성하세요.
- [페이지 관리](managing-pages)에서 페이지를 하나 이상 만드세요.
- 편집기에 접근하려면 **content.edit** 권한이 필요합니다.

</div>

## 편집기 열기 {#opening-the-editor}

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **웹사이트**를 펼친 다음 **페이지**를 클릭합니다.
2. 페이지 표에서 편집하려는 페이지를 찾아 **콘텐츠 편집**을 클릭합니다.

편집기는 전체 화면 모드로 열립니다. 왼쪽 패널에는 페이지 구조와 사용 가능한 콘텐츠 요소가 표시되고, 가운데 영역에는 페이지의 실시간 미리 보기가 표시됩니다.

:::info
편집기는 B1 Admin의 테마 설정과 관계없이 항상 밝은 모드로 표시되며, [모양](appearance)에서 선택한 제목 및 본문 글꼴을 사용합니다. 이렇게 해야 미리 보기가 웹사이트 방문자에게 보일 실제 모습과 정확히 일치합니다.
:::

## 페이지 구조: 섹션과 요소 {#page-structure-sections-and-elements}

모든 페이지는 두 단계로 구성됩니다.

- **섹션** -- 페이지를 가로 띠로 나누는 최상위 컨테이너입니다(예: 히어로 섹션, 콘텐츠 블록, 바닥글 띠). 콘텐츠를 추가하기 전에 모든 페이지에는 섹션이 하나 이상 있어야 합니다.
- **요소** -- 섹션 안에 놓이는 개별 콘텐츠로, 텍스트, 이미지, 버튼, 카드, 양식, 달력 등이 있습니다.

### 섹션 추가하기 {#adding-a-section}

1. **섹션 추가**(또는 왼쪽 패널 상단의 **+** 버튼)를 클릭합니다.
2. 시작 방법을 선택합니다.
   - **템플릿에서** — 카테고리(히어로, 소개, 섬김, 헌금 등)별로 정리된 섹션 템플릿 갤러리를 둘러보고 하나를 클릭하면, 스타일이 완전히 적용되고 내용이 미리 채워진 섹션이 삽입됩니다. 추가한 뒤에는 모든 것을 사용자 지정할 수 있습니다.
   - **빈 섹션** — 열 배치(단일, 2열, 3열 등)를 고르고 처음부터 만듭니다.
3. 새 섹션이 미리 보기에 나타납니다. 섹션을 클릭하여 선택한 다음 배경색, 안쪽 여백, 기타 스타일 옵션을 설정합니다.

### 섹션 배치 바꾸기 {#switching-a-sections-layout}

이미 만든 섹션의 구조를 바꾸고 싶다면, 그 섹션의 배치 전환 도구를 사용하여 기존 콘텐츠와 요소는 그대로 둔 채 갤러리의 다른 열 배치로 바꿀 수 있습니다.

### 섹션에 요소 추가하기 {#adding-elements-to-a-section}

1. 미리 보기에서 섹션 안을 클릭하여 선택합니다.
2. **콘텐츠 추가**를 클릭하고 목록에서 요소 유형을 선택합니다.
   - **텍스트** -- 제목, 단락, 서식 있는 텍스트
   - **이미지** -- 사진을 업로드하거나 링크로 연결
   - **버튼** -- 클릭 가능한 행동 유도 링크
   - **카드** -- 제목과 설명이 있는 이미지
   - **양식** -- [양식](../forms/creating-forms)을 페이지에 직접 삽입
   - **달력** -- 이벤트 달력 표시
   - **FAQ** -- 아코디언 형식의 질문과 답변 블록
   - **동영상** -- URL로 동영상 삽입
   - **그룹 찾아보기** -- 검색, 분류 필터, 라벨 필터를 선택적으로 갖춘 모든 교회 그룹의 필터링 가능한 목록
   - **아이콘 기능** -- 기능이나 사역을 강조하기 위한 아이콘, 제목, 짧은 설명
   - **갤러리** -- 여러 사진을 격자 또는 메이슨리 배치로 표시
   - **추천사** -- 작성자 이름, 역할, 사진과 함께 하나 이상의 인용문
   - **소셜 아이콘** -- 교회의 소셜 미디어 프로필로 연결되는 아이콘
   - **카운트다운** -- 날짜나 주간 예배 시간까지 남은 시간을 세는 타이머
   - **통계** -- 라벨(구성원, 연도, 캠퍼스)이 있는 큰 숫자의 행
   - **캠페인 진행 상황** -- 헌금 캠페인의 실시간 진행 막대로, 재정 항목 목표를 향해 모인 금액을 보여 줌
   - **직원 격자** -- 그룹 구성원을 위한 사진 카드. 그룹의 **공개 명단** 옵션이 켜져 있어야 합니다.
   - **예배 시간** -- 출석 설정에서 자동으로 가져오는 캠퍼스별 예배 일정
   - **설교** -- 설교 자료실을 전체 찾아보기 화면이나 격자, 목록, 최신 강조 배치로 표시
   - **지도** -- 교회 주소를 중심으로 한 지도
   - **표** -- 표 형식의 내용을 위한 행과 열의 단순한 격자
   - **사진이 있는 텍스트** -- 텍스트와 이미지를 나란히 배치
   - **로고** -- [모양](appearance)에서 가져오는 교회 로고
   - **라이브 스트림** -- 라이브 스트림 플레이어를 페이지에 직접 삽입
   - **팟캐스트** -- 제공한 외부 팟캐스트 RSS 피드 URL에서 가져온 에피소드 목록. 표시할 에피소드 수와 날짜 및 설명 표시 여부를 설정할 수 있습니다. 실제 사이트의 각 에피소드에는 오디오 플레이어와 에피소드 제목으로 오디오 파일을 저장하는 **다운로드** 링크가 있습니다. 사이트에 임의의 팟캐스트 피드를 소개하는 용도이며, 자신의 설교를 팟캐스트로 게시하려면 [설교 관리하기](../sermons/managing-sermons.md#your-podcast-feed)를 참조하세요.
   - **헌금** -- 헌금 버튼 또는 삽입된 헌금 양식
   - **HTML** -- 타사 위젯 삽입 같은 고급 사용을 위한 원시 HTML 직접 입력(자세한 내용은 [HTML 요소 사용하기](#using-the-html-element) 참조)
   - **iFrame** -- URL로 외부 콘텐츠 삽입
3. 나타나는 설정 패널에서 요소를 구성합니다.

### HTML 요소 사용하기 {#using-the-html-element}

**HTML** 요소에는 두 개의 상자가 있습니다.

- **HTML 콘텐츠** -- 페이지에 표시할 마크업입니다. 여기에 포함한 `<script>` 태그는 실제 사이트에서 실행됩니다.
- **JavaScript(script 태그 제외)** -- 페이지가 로드될 때 실행되는 스크립트 코드입니다. 제공업체의 삽입 코드 조각을 `<script>` 태그와 함께 여기에 붙여 넣으면 실제 사이트에서 실행됩니다.

JavaScript 상자에 웹 주소(예: 이미지 링크)만 붙여 넣으면, 상자가 빨간색으로 바뀌고 *"이것은 JavaScript가 아니라 웹 주소입니다."*라는 경고가 표시됩니다. 그 상자에 있는 단순한 주소는 아무 일도 하지 않습니다. 그림을 표시하려면 **이미지** 요소를 사용하거나 **HTML 콘텐츠**에 `<img src="...">`를 넣으세요.

### 달력 요소 사용하기 {#using-the-calendar-element}

**달력** 요소는 교회의 달력 중 하나에서 이벤트를 보여 줍니다.

1. **선택** 아래에서 **그룹 달력**(한 그룹의 이벤트, 목록에는 내가 속한 그룹이 표시됨) 또는 **큐레이션 달력**(**달력**에서 만든 달력, [큐레이션 달력](../calendars/curated-calendar) 참조)을 선택합니다.
2. **달력 선택** 아래에서 그룹이나 달력을 고릅니다.
3. **표시** 아래에서 표시 방법을 고릅니다.
   - **월별 달력** -- 방문자가 페이지를 넘기며 볼 수 있는 한 달 격자입니다.
   - **다가오는 이벤트** -- 다음 12개 이벤트의 타일 격자입니다. 반복 이벤트는 다음 날짜에 한 번만 표시됩니다. 각 타일에는 이벤트 사진(사진이 없으면 테마의 어두운 색상 위에 제목), 날짜 배지, 요일과 시간, 설명의 첫 줄이 표시됩니다. 타일 위의 **구독** 버튼으로 방문자는 달력의 ICS 링크를 복사하거나 내려받을 수 있습니다.
4. 일부 이벤트만 표시하려면 **다음 태그가 있는 이벤트만**에 태그를 입력합니다(예: `youth`). **태그**에 해당 단어가 포함된 이벤트만 나타납니다. 비워 두면 모든 이벤트를 표시합니다. 태그는 각 이벤트에서 설정합니다. [이벤트 추가 및 편집](../calendars/creating-calendars.md#adding-and-editing-events)을 참조하세요.

두 표시 방식 모두에서 이벤트를 클릭하면 교회 웹사이트의 해당 이벤트 페이지가 열립니다. 이벤트 페이지에는 이벤트 사진, 제목, 날짜와 시간, 설명이 표시되며, **언제**(반복 이벤트라면 반복 패턴 포함)와 **어디서**(예약된 방)가 적힌 상자도 있습니다. 등록이 켜져 있다면 **이 이벤트에 등록하기** 버튼이 있고, 이벤트를 달력 파일로 내려받는 **내 달력에 추가** 링크도 있습니다. 검색 엔진이 검색 결과에 이벤트의 날짜와 세부 정보를 보여 줄 수 있도록 페이지가 구성되어 있습니다.

### 콘텐츠 순서 바꾸기 {#reordering-content}

각 항목 왼쪽의 손잡이 아이콘(점 여섯 개)을 사용하여 섹션이나 요소를 끌어서 순서를 바꿉니다. 요소는 섹션 안에서 끌거나 섹션 사이로 옮길 수 있습니다.

## 페이지 스타일링하기 {#styling-your-page}

### 섹션 스타일 {#section-styles}

섹션을 클릭하면 스타일 패널이 열립니다. 다음을 설정할 수 있습니다.

- **배경** -- 단색, 그라데이션, 또는 이미지. 이미지 배경을 사용할 때는 **초점** 선택기에서 클릭하여 섹션 크기가 조절될 때 이미지의 어느 부분이 가운데에 남을지 정할 수 있고, **오버레이** 색상 옵션으로 이미지 위에 반투명한 색을 입혀 글자 가독성을 높일 수 있습니다.
- **여백** -- 섹션 안의 위쪽과 아래쪽 간격
- **너비** -- 전체 너비 또는 가운데 정렬/포함
- **구분선** -- 섹션의 위쪽 또는 아래쪽 가장자리에 놓는 장식용 모양 구분선(물결, 기울기, 곡선, 삼각형 등)으로, 색상, 높이, 뒤집기 옵션이 있습니다.

### 요소 스타일 {#element-styles}

요소를 클릭하면 스타일 패널이 열립니다. 글꼴 크기, 색상, 정렬, 바깥 여백, 안쪽 여백 등의 옵션이 일반적으로 제공됩니다. 이미지의 경우 대체 텍스트와 링크 대상을 설정할 수 있습니다.

### 사용자 지정 CSS {#custom-css}

고급 스타일링이 필요하다면, 각 섹션과 요소에 있는 **사용자 지정 CSS** 필드에 직접 CSS 규칙을 작성할 수 있습니다. 이 규칙은 해당 요소에만 적용되므로, 페이지의 다른 부분에 의도치 않게 영향을 주지 않습니다.

:::tip
사용자 정의 글꼴이나 전역 색상처럼 사이트 전체에 스타일을 적용해야 한다면, 개별 페이지의 사용자 지정 CSS 대신 [모양](appearance) 설정을 사용하세요.
:::

## 페이지 미리 보기 {#previewing-your-page}

도구 모음의 미리 보기 컨트롤을 사용하여 다양한 화면 크기에서 페이지가 어떻게 보이는지 확인하세요.

- **데스크톱** -- 전체 너비 브라우저 보기
- **모바일** -- 좁은 휴대폰 크기 보기

방문자가 보게 될 그대로의 실제 페이지를 보려면 페이지 목록으로 돌아가 페이지의 경로를 클릭하세요. 새 브라우저 탭에서 열립니다.

## 접근성 확인하기 {#checking-accessibility}

도구 모음의 **접근성** 아이콘을 클릭하면 대체 텍스트가 없는 이미지, 낮은 색상 대비, 순서가 어긋난 제목 같은 흔한 문제를 빠르게 확인합니다. 각 문제는 수정이 필요한 요소로 바로 연결되므로, 그 자리에서 고칠 수 있습니다.

## 변경 사항 되돌리기 {#undoing-changes}

편집기는 편집 기록을 자동으로 추적합니다. 도구 모음 버튼이나 단축키를 사용하여 이동하세요.

- **실행 취소**(Ctrl+Z / Cmd+Z) -- 마지막 작업을 되돌립니다
- **다시 실행**(Ctrl+Shift+Z 또는 Ctrl+Y / Cmd+Shift+Z) -- 취소한 작업을 다시 적용합니다

페이지를 이전 스냅숏으로 복원할 수도 있습니다. 도구 모음의 **기록 보기**를 클릭하면 설명이 있는 저장된 스냅숏 목록이 나타나며, 항목을 클릭하면 그 시점으로 복원됩니다.

:::warning
스냅숏을 복원하면 현재 페이지 내용이 스냅숏 버전으로 바뀝니다. 이 작업은 표준 실행 취소 버튼으로 되돌릴 수 없습니다. 나중에 돌아갈 수 있는 선택지를 남기고 싶다면, 오래된 스냅숏을 복원하기 전에 현재 상태의 스냅숏을 먼저 저장하세요.
:::

## 저장과 게시 {#saving-and-publishing}

작업하는 동안 변경 사항은 자동으로 저장됩니다. 도구 모음의 상태 표시기가 변경 사항이 저장되었는지 보여 줍니다.

### 초안과 게시 상태 {#draft-and-published-state}

페이지에는 **게시됨** 상태가 있을 수 있으며, 이는 방문자가 변경 사항을 언제 보게 될지를 제어합니다. 도구 모음에는 현재 상태를 보여 주는 상태 칩이 표시됩니다.

- **저장 시 바로 공개** -- 페이지가 게시 워크플로를 사용하지 않습니다. 저장된 모든 변경 사항이 즉시 공개됩니다. 새 페이지의 기본값입니다.
- **게시되지 않은 변경 사항** -- 페이지를 이전에 게시한 적이 있지만, 마지막 게시 이후 변경했습니다. 방문자에게는 여전히 이전에 게시된 버전이 보입니다.
- **게시됨** -- 페이지가 공개되어 있으며, 저장된 내용이 방문자가 보는 내용과 일치합니다.

변경 사항을 게시하려면 도구 모음의 **게시** 버튼을 클릭합니다. 페이지가 즉시 공개됩니다.

방문자가 보는 내용에 영향을 주지 않고 마지막으로 게시된 버전으로 되돌리려면, 더보기 메뉴(⋮)를 열고 **게시되지 않은 변경 사항 취소**를 클릭합니다.

게시 워크플로 사용을 중단하려면 더보기 메뉴를 열고 **게시 끄기**를 클릭합니다. 그러면 편집 내용이 다시 즉시 공개됩니다.

:::tip
예정된 행사처럼 페이지를 미리 준비해 두고 적절한 시점에만 공개하고 싶을 때 초안/게시 워크플로를 사용하세요. 페이지를 만들고 미리 본 다음, 준비가 되면 게시를 클릭하세요.
:::
