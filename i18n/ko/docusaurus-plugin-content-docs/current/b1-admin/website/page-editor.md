# 페이지 편집기 사용하기

<div class="article-intro">

B1 페이지 편집기는 코드를 작성하지 않고도 교회 웹사이트 페이지를 디자인할 수 있는 시각적 드래그 앤 드롭 빌더입니다. 섹션과 콘텐츠 블록을 추가하고, 스타일을 맞추고, 작업 내용을 미리 보고, 변경 사항을 실행 취소할 수 있습니다. 모든 작업은 브라우저 안에서 이루어집니다.

## 편집기 열기

1. B1 관리자에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Website**를 펼친 다음 **Pages**를 클릭하세요.
2. 페이지 표에서 편집할 페이지를 찾아 **Edit Content**를 클릭하세요.

편집기는 전체 화면으로 열립니다. 왼쪽 패널에는 페이지 구조와 사용 가능한 콘텐츠 요소가 표시되고, 가운데 영역에는 페이지의 실시간 미리 보기가 나타납니다.

:::info
편집기는 B1 관리자의 테마 설정과 관계없이 항상 밝은 모드로 표시되며, [모양](./appearance.md)에서 선택한 제목 및 본문 글꼴을 사용합니다. 이렇게 해야 미리 보기가 방문자에게 보이는 실제 페이지와 정확히 일치합니다.
:::

## 페이지 구조: 섹션과 요소

모든 페이지는 두 단계로 구성됩니다.

- **섹션** -- 페이지를 가로 띠 모양으로 나누는 최상위 컨테이너입니다(예: 히어로 섹션, 콘텐츠 블록, 푸터 띠). 콘텐츠를 추가하려면 페이지에 섹션이 최소 하나 있어야 합니다.
- **요소** -- 섹션 안에 배치되는 개별 콘텐츠로, 텍스트, 이미지, 버튼, 카드, 양식, 캘린더 등이 있습니다.

### 섹션 추가하기

1. **섹션 추가**를 클릭하거나 왼쪽 패널 상단의 **+** 버튼을 클릭하세요.
2. 시작 방법을 선택하세요.
   - **템플릿에서 선택** — 카테고리(히어로, 소개, 서비스, 헌금 등)별로 정리된 섹션 템플릿 갤러리에서 하나를 골라 클릭하면, 스타일이 완전히 적용되고 내용이 미리 채워진 섹션이 삽입됩니다. 추가한 후에는 모든 항목을 자유롭게 수정할 수 있습니다.
   - **빈 섹션** — 열 배치(단일 열, 두 열, 세 열 등)를 고른 다음 처음부터 직접 만드세요.
3. 새 섹션이 미리 보기에 나타납니다. 섹션을 클릭해 선택하고 배경색, 여백 및 기타 스타일 옵션을 설정하세요.

### 섹션 레이아웃 바꾸기

이미 만든 섹션의 구조를 바꾸고 싶으신가요? 해당 섹션의 레이아웃 전환기를 사용하면 기존 콘텐츠와 요소를 그대로 둔 채 갤러리에서 다른 열 배치로 바꿀 수 있습니다.

### 섹션에 요소 추가하기

1. 미리 보기에서 섹션 안을 클릭해 선택하세요.
2. **콘텐츠 추가**를 클릭하고 목록에서 요소 유형을 선택하세요.
   - **텍스트** -- 제목, 단락, 서식 있는 텍스트
   - **이미지** -- 사진을 업로드하거나 사진 링크를 연결
   - **버튼** -- 클릭할 수 있는 행동 유도 링크
   - **카드** -- 제목과 설명이 있는 이미지
   - **양식** -- 페이지에 [양식](../forms/creating-forms.md)을 직접 삽입합니다. 양식에 [머리글 사진](../forms/creating-forms.md#adding-a-header-photo)이 있으면 질문 위에 표시됩니다
   - **캘린더** -- 행사 캘린더 표시
   - **FAQ** -- 아코디언 형식의 질문과 답변 블록
   - **동영상** -- URL로 동영상 삽입
   - **그룹 찾아보기** -- 모든 교회 그룹을 검색, 카테고리 필터, 레이블 필터로 찾아볼 수 있는 목록입니다. **레이아웃**은 **그리드**(기본값) 또는 **스크롤(자동)** 중에서 선택할 수 있습니다 -- [스크롤 레이아웃](#scrolling-layouts)을 참조하세요
   - **그룹 목록** -- 공개 그룹의 타일을 표시하며, 특정 레이블이 붙은 그룹만 표시할 수도 있습니다. **레이아웃**은 **그리드**(기본값, 한 줄에 최대 타일 3개) 또는 **스크롤(자동)** 중에서 선택할 수 있습니다 -- [스크롤 레이아웃](#scrolling-layouts)을 참조하세요
   - **아이콘 기능** -- 기능이나 사역을 강조하기 위한 아이콘, 제목, 짧은 설명
   - **갤러리** -- 여러 장의 사진을 격자 또는 메이슨리 레이아웃으로 표시
   - **추천의 글** -- 작성자 이름, 직함, 사진과 함께 하나 이상의 인용문 표시
   - **소셜 아이콘** -- 교회의 소셜 미디어 프로필로 연결되는 아이콘: Facebook, Instagram, WhatsApp, YouTube, X, TikTok, Vimeo, Podcast. 표시하려는 항목마다 링크를 입력하세요. **WhatsApp**의 경우 전화번호가 포함된 `https://wa.me/` 링크나 그룹 초대 링크를 사용하세요
   - **카운트다운** -- 특정 날짜나 주간 예배 시간까지 남은 시간을 표시하는 타이머
   - **통계** -- 큰 숫자와 설명 라벨을 한 줄로 표시(교인 수, 설립 연수, 캠퍼스 수 등)
   - **헌금 캠페인 진행률** -- 헌금 캠페인의 실시간 진행 막대로, 기금 목표를 향해 모인 총액을 보여 줍니다
   - **사역팀 그리드** -- 그룹 구성원의 사진 카드를 표시합니다. 해당 그룹의 **공개 명단** 옵션이 켜져 있어야 합니다
   - **예배 시간** -- 출석 설정에서 자동으로 가져온 캠퍼스별 예배 일정
   - **설교** -- 설교 라이브러리를 전체 목록 브라우저로 표시하거나, 그리드, 목록, 또는 최신 설교 강조 레이아웃으로 표시
   - **지도** -- 교회 주소를 중심으로 한 내장 지도
   - **표** -- 표 형식 콘텐츠를 위한 행과 열의 간단한 격자
   - **사진이 있는 텍스트** -- 텍스트와 이미지를 나란히 배치
   - **로고** -- [모양](./appearance.md)에서 가져온 교회 로고
   - **라이브 스트림** -- 페이지에 직접 삽입되는 라이브 스트림 플레이어
   - **팟캐스트** -- 입력한 외부 팟캐스트 RSS 피드 URL에서 가져온 에피소드 목록이며, 표시할 에피소드 수와 날짜 및 설명 표시 여부를 설정할 수 있습니다. 실제 웹사이트의 각 에피소드에는 오디오 플레이어와 **다운로드** 링크가 있어, 에피소드 제목으로 된 오디오 파일을 저장할 수 있습니다. 이 요소는 어떤 팟캐스트 피드든 웹사이트에 소개하기 위한 것입니다. 자신의 설교를 팟캐스트로 게시하려면 대신 [설교 관리](../sermons/managing-sermons.md#your-podcast-feed)를 참조하세요
   - **헌금** -- 헌금 버튼 또는 삽입된 헌금 양식
   - **HTML** -- 타사 위젯 삽입 등 고급 용도를 위한 직접 작성한 HTML(자세한 내용은 [HTML 요소 사용하기](#using-the-html-element)를 참조하세요)
   - **iFrame** -- URL로 외부 콘텐츠 삽입
3. 나타나는 설정 패널에서 요소를 구성하세요.

### HTML 요소 사용하기

**HTML** 요소에는 두 개의 입력 상자가 있습니다.

- **HTML 콘텐츠** -- 페이지에 표시할 마크업입니다. 여기에 포함한 `<script>` 태그는 실제 웹사이트에서 실행됩니다.
- **JavaScript(script 태그 제외)** -- 페이지가 로드될 때 실행되는 스크립트 코드입니다. 공급업체가 제공한 삽입 코드를 `<script>` 태그와 함께 여기에 붙여 넣을 수도 있으며, 실제 웹사이트에서 실행됩니다.

JavaScript 상자에 웹 주소(예: 이미지 링크)만 붙여 넣으면 상자가 빨간색으로 바뀌고 *"이것은 JavaScript가 아니라 웹 주소입니다."*라는 경고가 표시됩니다. 이 상자에 주소만 입력하면 아무 일도 일어나지 않습니다. 사진을 표시하려면 **이미지** 요소를 사용하거나 **HTML 콘텐츠**에 `<img src="...">`를 입력하세요.

### 캘린더 요소 사용하기 {#using-the-calendar-element}

**캘린더** 요소는 여러 캘린더 중 하나의 행사를 표시합니다.

1. **선택** 항목에서 **그룹 캘린더**(한 그룹의 행사 -- 목록에는 내가 속한 그룹이 표시됨) 또는 **큐레이션 캘린더**(**캘린더** 메뉴에서 직접 만든 캘린더, [큐레이션 캘린더](../calendars/curated-calendar.md) 참조) 중에서 고르세요.
2. **캘린더 선택** 항목에서 그룹 또는 캘린더를 고르세요.
3. **표시 방식**에서 보여 줄 방식을 고르세요.
   - **월별 캘린더** -- 방문자가 월을 넘겨 볼 수 있는 월간 격자입니다. 각 행사는 소속 그룹의 색으로 표시되므로, 그룹의 행사는 모든 캘린더에서 같은 색을 가집니다. 색은 B1이 자동으로 정하므로 따로 설정할 것은 없습니다.
   - **다가오는 행사** -- 다음 행사 12개를 타일 격자로 보여 주며, 반복되는 행사는 다음 날짜에 한 번만 표시됩니다. 각 타일에는 행사 사진(사진이 없으면 테마의 어두운 색 바탕에 제목이 표시됨), 날짜 배지, 요일과 시간, 설명의 첫 줄이 표시됩니다. 타일 위의 **구독** 버튼을 누르면 방문자가 캘린더의 ICS 링크를 복사하거나 파일을 내려받을 수 있습니다. 이 표시 방식에는 **레이아웃** 설정이 나타나며, **그리드**(기본값) 또는 **스크롤(자동)** 중에서 고를 수 있습니다. 스크롤(자동)을 고르면 타일이 한 줄로 배치되어 저절로 가로로 넘어갑니다([스크롤 레이아웃](#scrolling-layouts) 참조). **큐레이션 캘린더**인 경우 **그룹 배지** 설정을 켜면 각 타일의 오른쪽 위 모서리에 행사가 속한 그룹 이름이 해당 그룹의 캘린더 색으로 표시됩니다. 보관되었거나 비공개인 그룹의 행사에는 배지가 표시되지 않습니다.
4. 일부 행사만 표시하려면 **다음 태그가 붙은 행사만**에 태그를 입력하세요. 예를 들어 `youth`를 입력합니다. **태그**에 해당 단어가 포함된 행사만 나타납니다. 비워 두면 모든 행사가 표시됩니다. 태그는 각 행사에 설정하며, 자세한 내용은 [행사 추가 및 편집](../calendars/creating-calendars.md#adding-and-editing-events)을 참조하세요.

두 가지 표시 방식 모두에서 행사를 클릭하면 웹사이트에 있는 해당 행사의 전용 페이지가 열립니다. 행사 페이지에는 행사 사진, 제목, 날짜와 시간, 설명이 표시되며, **언제**(반복 행사의 경우 반복 패턴 포함)와 **어디서**(행사를 위해 예약된 시설)가 적힌 상자도 있습니다. 등록 기능이 켜져 있으면 **이 행사에 등록하기** 버튼이 표시되고, **내 캘린더에 추가** 링크를 누르면 행사가 캘린더 파일로 내려받아집니다. 이 페이지는 검색 엔진이 검색 결과에 행사의 날짜와 세부 정보를 표시할 수 있도록 구성되어 있습니다. 페이지에 표시되는 큐레이션 캘린더의 행사 페이지(향후 6개월 이내의 행사)도 웹사이트 사이트맵에 포함되므로 검색 엔진이 찾을 수 있습니다.

### 스크롤 레이아웃 {#scrolling-layouts}

**그룹 찾아보기**, **그룹 목록**, 그리고 캘린더 요소의 **다가오는 행사** 표시 방식에서 **스크롤(자동)** 레이아웃을 선택하면, 타일이 격자 대신 한 줄로 배치됩니다. 휴대폰에서는 각 타일이 줄 전체를 차지하고, 컴퓨터에서는 타일 두 개가 나란히 들어갑니다. 한 화면에 들어가지 않을 만큼 타일이 많으면 줄은 다음과 같이 동작합니다.

- 약 4초마다 타일 하나씩 앞으로 넘어가며, 마지막 타일 다음에는 다시 첫 번째 타일로 돌아갑니다.
- 방문자가 타일 위에 마우스를 올리거나, 터치하거나, 탭으로 포커스를 옮기면 일시 정지하고, 몇 초 후에 다시 넘어가기 시작합니다.
- 줄 아래에 타일 개수만큼의 점이 표시되며, 현재 타일에 해당하는 점이 채워져 나타납니다. 방문자는 점을 클릭해 해당 타일로 바로 이동할 수 있습니다.

동작 줄이기 설정을 사용하는 기기에서는 줄이 움직이지 않으며, 방문자가 직접 스와이프하거나 스크롤해야 합니다. 모든 타일이 한 화면에 들어가면 줄은 움직이지 않고 점도 나타나지 않습니다.

### 콘텐츠 순서 바꾸기

각 항목의 왼쪽에 있는 손잡이 아이콘(점 여섯 개)을 드래그하여 섹션이나 요소의 순서를 바꿀 수 있습니다. 섹션 안에서 요소를 옮기거나 다른 섹션으로 옮길 수도 있습니다.

## 페이지 스타일 지정하기

### 섹션 스타일

섹션을 클릭하면 스타일 패널이 열립니다. 다음 항목을 설정할 수 있습니다.

- **배경** -- 단색, 그라데이션, 또는 이미지. 이미지 배경을 사용할 때는 **초점** 선택기를 클릭해 섹션 크기가 조정될 때 가운데에 남을 이미지 부분을 정할 수 있고, **오버레이** 색상 옵션으로 이미지 위에 반투명한 색을 덧입혀 글자를 더 잘 읽히게 할 수 있습니다.
- **여백** -- 섹션 안쪽의 위쪽과 아래쪽 간격
- **너비** -- 전체 너비 또는 가운데 정렬/제한된 너비
- **구분선** -- 섹션의 위쪽이나 아래쪽 가장자리에 넣는 장식용 도형 구분선(물결, 기울임, 곡선, 삼각형 등). 색, 높이, 뒤집기 옵션을 설정할 수 있습니다

### 요소 스타일

요소를 클릭하면 스타일 패널이 열립니다. 일반적인 옵션으로는 글꼴 크기, 색, 정렬, 바깥 여백, 안쪽 여백이 있습니다. 이미지의 경우 대체 텍스트와 링크 대상을 설정할 수 있습니다.

### 사용자 지정 CSS

고급 스타일링이 필요하면 각 섹션과 요소에 있는 **사용자 지정 CSS** 항목에 직접 CSS 규칙을 작성할 수 있습니다. 이 규칙은 해당 요소에만 적용되므로 페이지의 나머지 부분에 의도치 않게 영향을 주지 않습니다.

:::tip
사용자 지정 글꼴이나 전역 색상처럼 웹사이트 전체에 스타일을 적용해야 한다면, 개별 페이지의 사용자 지정 CSS 대신 [모양](./appearance.md) 설정을 사용하세요.
:::

## 페이지 미리 보기

도구 모음의 미리 보기 컨트롤을 사용하면 여러 화면 크기에서 페이지가 어떻게 보이는지 확인할 수 있습니다.

- **데스크톱** -- 전체 너비의 브라우저 보기
- **모바일** -- 좁은 휴대폰 크기 보기

휴대폰에서는 행의 열들이 전체 너비로 위아래로 쌓입니다. 단, 행 설정에서 열마다 **모바일 너비**를 지정했다면 그렇지 않습니다. 설교 및 팟캐스트 목록은 휴대폰에서 각 에피소드의 텍스트가 썸네일 아래에 배치됩니다.

방문자가 보는 것과 똑같은 실제 페이지를 확인하려면 페이지 목록으로 돌아가 해당 페이지의 경로를 클릭하세요. 새 브라우저 탭에서 열립니다.

## 접근성 확인하기

도구 모음의 **접근성** 아이콘을 클릭하면 대체 텍스트가 없는 이미지, 낮은 색 대비, 순서가 맞지 않는 제목 등 흔한 문제를 빠르게 점검합니다. 각 문제는 수정이 필요한 요소로 바로 연결되므로 그 자리에서 고칠 수 있습니다.

## 변경 사항 실행 취소하기

편집기는 편집 기록을 자동으로 저장합니다. 도구 모음 버튼이나 키보드 단축키를 사용해 이동하세요.

- **실행 취소** (Ctrl+Z / Cmd+Z) -- 마지막 작업을 되돌립니다
- **다시 실행** (Ctrl+Shift+Z 또는 Ctrl+Y / Cmd+Shift+Z) -- 실행 취소한 작업을 다시 적용합니다

페이지를 이전 스냅샷으로 되돌릴 수도 있습니다. 도구 모음의 **기록 보기**를 클릭하면 설명이 붙은 저장된 스냅샷 목록이 나타나며, 항목을 클릭하면 그 시점으로 복원됩니다.

:::warning
스냅샷을 복원하면 현재 페이지 콘텐츠가 스냅샷 버전으로 대체됩니다. 이 작업은 표준 실행 취소 버튼으로 되돌릴 수 없습니다. 이전 스냅샷으로 되돌리기 전에 현재 상태의 스냅샷을 먼저 저장해 두면 다시 돌아갈 수 있습니다.
:::

## 저장 및 게시하기

변경 사항은 작업하는 동안 자동으로 저장됩니다. 도구 모음의 상태 표시기에서 변경 사항이 저장되었는지 확인할 수 있습니다.

### 임시 저장 및 게시 상태

페이지에는 **게시됨** 상태가 있으며, 이 상태에 따라 방문자가 변경 사항을 언제 보는지가 결정됩니다. 도구 모음에는 현재 상태를 보여 주는 상태 칩이 표시됩니다.

- **저장 시 바로 공개** -- 페이지가 게시 절차를 사용하지 않습니다. 저장한 모든 변경 사항이 즉시 공개됩니다. 새 페이지의 기본값입니다.
- **게시되지 않은 변경 사항** -- 페이지가 이전에 게시된 적이 있지만 마지막 게시 이후에 변경했습니다. 방문자는 여전히 이전에 게시된 버전을 봅니다.
- **게시됨** -- 페이지가 공개되어 있으며, 저장된 콘텐츠가 방문자가 보는 내용과 일치합니다.

변경 사항을 게시하려면 도구 모음의 **게시** 버튼을 클릭하세요. 페이지가 즉시 공개됩니다.

방문자가 보는 내용에 영향을 주지 않고 마지막으로 게시된 버전으로 되돌리려면 더보기 메뉴(⋮)를 열고 **게시되지 않은 변경 사항 취소**를 클릭하세요.

게시 절차 사용을 중단하려면 더보기 메뉴를 열고 **게시 기능 끄기**를 클릭하세요. 이후 편집 내용은 다시 즉시 공개됩니다.

:::tip
예를 들어 다가오는 행사를 위해 페이지를 미리 준비해 두고 적절한 시점에만 공개하고 싶을 때 임시 저장/게시 절차를 사용하세요. 페이지를 만들고 미리 본 다음, 준비가 되었을 때 게시를 클릭하면 됩니다.
:::
