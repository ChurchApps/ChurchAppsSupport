# 페이지 편집기 사용

<div class="article-intro">

B1 페이지 편집기는 코드를 작성하지 않고 교회 웹사이트 페이지를 디자인할 수 있는 시각적 드래그 앤 드롭 빌더입니다. 섹션 및 콘텐츠 블록을 추가하고, 스타일을 사용자 정의하고, 작업을 미리 보고, 변경사항을 실행 취소할 수 있습니다. 모두 브라우저 내에서 가능합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 웹사이트를 구성하려면 [초기 설정](initial-setup)을 완료하세요
- [페이지 관리](managing-pages)에서 최소한 하나의 페이지를 만드세요
- 편집기에 액세스하려면 **content.edit** 권한이 필요합니다

</div>

## 편집기 열기

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 위의 검색 표시줄)를 열고 **웹사이트**를 확장한 다음 **페이지**를 클릭합니다.
2. 페이지 테이블에서 편집할 페이지를 찾고 **편집**을 클릭합니다.

편집기가 전체 화면 모드로 열립니다. 왼쪽 패널에는 페이지 구조와 사용 가능한 콘텐츠 요소가 표시되고 중앙 영역에는 페이지의 실시간 미리보기가 표시됩니다.

:::info
편집기는 B1 Admin 테마 설정에 관계없이 항상 밝은 모드로 표시됩니다. 이렇게 하면 미리보기가 웹사이트 방문자에게 페이지가 어떻게 보일지 정확하게 일치합니다.
:::

## 페이지 구조: 섹션 및 요소

모든 페이지는 두 수준으로 구성됩니다:

- **섹션** - 페이지를 가로 띠로 나누는 최상위 컨테이너(예: 영웅 섹션, 콘텐츠 블록 또는 바닥글 스트립). 콘텐츠를 추가하기 전에 모든 페이지에는 최소한 하나의 섹션이 있어야 합니다.
- **요소** - 텍스트, 이미지, 버튼, 카드, 양식, 달력 등 섹션 내에 배치된 개별 콘텐츠 조각입니다.

### 섹션 추가

1. **섹션 추가**를 클릭합니다(또는 왼쪽 패널 상단의 **+** 버튼).
2. 시작 방법을 선택합니다:
   - **템플릿에서** - 카테고리(영웅, 정보, 서비스, 기부 등)별로 구성된 섹션 템플릿 갤러리를 탐색하고 하나를 클릭하여 완전히 스타일이 지정되고 미리 채워진 섹션으로 삽입합니다. 추가된 후 모든 항목을 사용자 정의할 수 있습니다.
   - **빈 섹션** - 열 레이아웃(단일, 2열, 3열 등)을 선택하고 처음부터 빌드합니다.
3. 새 섹션이 미리보기에 나타납니다. 이를 클릭하여 선택하고 배경색, 패딩 및 기타 스타일 옵션을 구성합니다.

### 섹션의 레이아웃 전환

이미 섹션을 빌드했지만 다른 구조를 원하십니까? 해당 섹션의 레이아웃 전환기를 사용하여 기존 콘텐츠와 요소를 제자리에 유지하면서 갤러리에서 다른 열 배열로 교체합니다.

### 섹션에 요소 추가

1. 미리보기에서 섹션 내부를 클릭하여 선택합니다.
2. **콘텐츠 추가**를 클릭하고 목록에서 요소 유형을 선택합니다:
   - **텍스트** - 제목, 단락 및 서식 있는 텍스트
   - **이미지** - 사진 업로드 또는 링크
   - **버튼** - 클릭 가능한 행동 요청 링크
   - **카드** - 제목과 설명이 있는 이미지
   - **양식** - [양식](../forms/creating-forms)을 페이지에 직접 임베드합니다
   - **달력** - 이벤트 달력 표시
   - **FAQ** - 아코디언 스타일의 질문 및 답변 블록
   - **비디오** - URL로 비디오를 임베드합니다
   - **그룹 브라우저** - 선택적 검색, 카테고리 필터 및 레이블 필터가 있는 모든 교회 그룹의 필터링 가능한 디렉토리
   - **아이콘 기능** - 기능 또는 사역 강조를 위한 아이콘, 제목 및 짧은 설명
   - **갤러리** - 다중 사진 그리드 또는 벽돌 레이아웃
   - **증언** - 저자 이름, 역할 및 사진이 있는 하나 이상의 인용구
   - **소셜 아이콘** - 교회의 소셜 미디어 프로필에 연결된 아이콘
   - **카운트다운** - 날짜 또는 주간 예배 시간까지 카운트다운하는 타이머
   - **통계** - 레이블이 있는 큰 숫자 행(구성원, 연도, 캠퍼스)
   - **캠페인 진행률** - 기부 캠페인의 실시간 진행 표시줄, 기금 목표에 대해 모금된 총액 표시
   - **직원 그리드** - 그룹의 구성원에 대한 사진 카드. 그룹에는 **공개 명단** 옵션이 켜져 있어야 합니다
   - **예배 시간** - 캠퍼스의 예배 일정, 출석 설정에서 자동으로 가져옴
   - **설교** - 전체 브라우저 또는 그리드, 목록 또는 특가 최신 레이아웃으로 설교 라이브러리
   - **지도** - 교회 주소를 중심으로 한 임베드 지도
   - **테이블** - 표형 콘텐츠를 위한 행과 열의 간단한 그리드
   - **텍스트와 사진** - 텍스트 및 이미지가 나란히 배치됨
   - **로고** - [외형](appearance)에서 가져온 교회 로고
   - **라이브 스트림** - 페이지에 직접 임베드된 라이브 스트림 플레이어
   - **팟캐스트** - 제공한 외부 팟캐스트 RSS 피드 URL에서 가져온 에피소드 목록, 표시할 에피소드 수 및 날짜와 설명 표시 여부에 대한 설정이 있습니다. 이는 사이트에서 팟캐스트 피드를 featuring하기 위한 것입니다. 자신의 설교를 팟캐스트로 게시하려면 [설교 관리](../sermons/managing-sermons.md#your-podcast-feed)를 참조하세요.
   - **기부** - 기부 버튼 또는 임베드된 기부 양식
   - **원시 HTML** - 고급 사용 사례를 위한 사용자 정의 HTML 마크업
   - **iFrame** - URL로 외부 콘텐츠를 임베드합니다
3. 나타나는 설정 패널을 사용하여 요소를 구성합니다.

### 콘텐츠 순서 변경

각 항목의 왼쪽에 있는 핸들 아이콘(6개의 점)을 사용하여 섹션 또는 요소를 드래그하여 순서를 변경합니다. 섹션 내에서 요소를 드래그하거나 섹션 간에 이동할 수 있습니다.

## 페이지 스타일 지정

### 섹션 스타일

섹션을 클릭하여 스타일 패널을 엽니다. 다음을 설정할 수 있습니다:

- **배경** - 단색, 그래디언트 또는 이미지입니다. 이미지 배경을 사용할 때 **초점** 선택기를 사용하면 섹션이 확장될 때 이미지의 어느 부분이 중앙에 유지될지 클릭하여 설정할 수 있으며 **오버레이** 색상 옵션을 사용하면 이미지 위에 반투명 틴트를 추가하여 텍스트 가독성을 개선할 수 있습니다.
- **패딩** - 섹션 내부의 상단 및 하단 간격
- **너비** - 전체 너비 또는 중앙/포함된 너비
- **구분선** - 색상, 높이 및 뒤집기 옵션을 포함한 섹션의 상단 또는 하단 가장자리의 장식 도형 구분선(파도, 기울기, 곡선, 삼각형 등)

### 요소 스타일

요소를 클릭하여 스타일 패널을 엽니다. 일반적인 옵션에는 글꼴 크기, 색상, 정렬, 여백 및 패딩이 포함됩니다. 이미지의 경우 대체 텍스트 및 링크 대상을 설정할 수 있습니다.

### 사용자 정의 CSS

고급 스타일링을 위해 각 섹션 및 요소에는 자신의 CSS 규칙을 작성할 수 있는 **사용자 정의 CSS** 필드가 있습니다. 이들은 해당 요소로 범위가 지정되므로 실수로 페이지의 나머지 부분에 영향을 미치지 않습니다.

:::tip
전체 사이트에 스타일을 적용해야 하는 경우(예: 사용자 정의 글꼴 또는 전역 색상) 개별 페이지의 사용자 정의 CSS 대신 [외형](appearance) 설정을 사용합니다.
:::

## 페이지 미리보기

툴바의 미리보기 컨트롤을 사용하여 다양한 화면 크기에서 페이지가 어떻게 보이는지 확인합니다:

- **데스크톱** - 전체 너비 브라우저 보기
- **모바일** - 좁은 휴대폰 크기 보기

**미리보기**를 클릭하여 새 브라우저 탭에서 페이지의 실시간 버전을 열고 방문자가 보는 것과 정확히 동일하게 확인합니다.

## 접근성 확인

툴바의 **접근성** 아이콘을 클릭하여 일반적인 문제(대체 텍스트가 없는 이미지, 낮은 색상 대비 또는 순서가 잘못된 제목)에 대한 빠른 점검을 실행합니다. 각 문제는 주의가 필요한 요소로 직접 연결되므로 그 자리에서 수정할 수 있습니다.

## 변경사항 실행 취소

편집기는 편집 기록을 자동으로 추적합니다. 툴바 버튼 또는 키보드 바로가기를 사용하여 탐색합니다:

- **실행 취소**(Ctrl+Z / Cmd+Z) - 마지막 작업을 되돌립니다
- **재실행**(Ctrl+Y / Cmd+Y) - 실행 취소된 작업을 다시 적용합니다

페이지를 이전 스냅샷으로 복원할 수도 있습니다. 툴바의 **기록**을 클릭하여 설명이 있는 저장된 스냅샷 목록을 보고 항목을 클릭하여 해당 지점으로 복원합니다.

:::warning
스냅샷을 복원하면 현재 페이지 콘텐츠가 스냅샷 버전으로 바뀝니다. 이는 표준 실행 취소 버튼으로 실행 취소할 수 없습니다. 돌아갈 수 있는 옵션을 유지하려면 이전 스냅샷을 복원하기 전에 현재 상태의 스냅샷을 저장합니다.
:::

## 저장 및 게시

변경사항은 작업할 때 자동으로 저장됩니다. 툴바의 상태 표시기는 변경사항이 저장되었는지 여부를 표시합니다.

### 초안 및 게시됨 상태

페이지는 방문자가 변경사항을 보는 시기를 제어하는 **게시됨** 상태를 가질 수 있습니다. 툴바는 현재 상태를 보여주는 상태 칩을 표시합니다:

- **저장 시 실시간** - 페이지는 게시 워크플로우를 사용하지 않습니다. 저장된 모든 변경사항은 즉시 실시간으로 전환됩니다. 이는 새 페이지의 기본값입니다.
- **게시되지 않은 변경사항** - 페이지는 이전에 게시되었지만 마지막 게시 이후로 변경사항을 만들었습니다. 방문자는 여전히 이전에 게시된 버전을 봅니다.
- **게시됨** - 페이지가 실시간이며 저장된 콘텐츠가 방문자가 보는 것과 일치합니다.

변경사항을 게시하려면 툴바의 **게시** 버튼을 클릭합니다. 페이지는 즉시 실시간으로 전환됩니다.

방문자가 보는 것에 영향을 주지 않고 마지막 게시된 버전으로 되돌리려면 오버플로우 메뉴(⋮)를 열고 **변경사항 버리기**를 클릭합니다.

페이지를 완전히 오프라인으로 전환하려면 오버플로우 메뉴를 열고 **게시 취소**를 클릭합니다. 방문자는 다시 게시할 때까지 해당 페이지를 더 이상 볼 수 없습니다.

:::tip
예정된 이벤트와 같이 페이지를 준비하고 적절한 시점에만 실시간으로 전환하려면 초안/게시 워크플로우를 사용합니다. 페이지를 빌드하고 미리 보기한 다음 준비가 되면 게시를 클릭합니다.
:::
