# 페이지 편집기 사용하기

<div class="article-intro">

B1 페이지 편집기는 코드를 쓰지 않고도 교회 웹사이트 페이지를 디자인할 수 있는 시각적 드래그 앤 드롭 빌더입니다. 섹션과 콘텐츠 블록을 추가하고, 스타일을 꾸미고, 작업을 미리 보고, 변경을 되돌릴 수 있습니다. 모든 작업은 브라우저 안에서 이루어집니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 웹사이트를 설정하려면 [초기 설정](initial-setup)을 완료하세요.
- [페이지 관리하기](managing-pages)에서 페이지를 최소한 하나 만드세요.
- 편집기에 접근하려면 **content.edit** 권한이 필요합니다.

</div>

## 편집기 열기

1. B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 위의 검색창)를 열고 **Website**를 펼친 다음 **Pages**를 클릭하세요.
2. 페이지 표에서 편집할 페이지를 찾아 **Edit Content**를 클릭하세요.

편집기는 전체 화면으로 열립니다. 왼쪽 패널에는 페이지 구조와 사용할 수 있는 콘텐츠 요소가 나타나며, 가운데 영역에는 페이지의 실시간 미리 보기가 나타납니다.

:::info
편집기는 B1 Admin의 테마 설정과 관계없이 항상 밝은 모드로 표시되며, [외관](appearance)에서 고른 제목 글꼴과 본문 글꼴을 사용합니다. 이렇게 해야 미리 보기가 웹사이트 방문자에게 보일 페이지와 정확히 맞습니다.
:::

## 페이지 구조: 섹션과 요소

모든 페이지는 두 단계로 만들어집니다.

- **섹션** -- 페이지를 가로 띠로 나누는 최상위 컨테이너입니다(예: 히어로 섹션, 콘텐츠 블록, 푸터 띠). 콘텐츠를 추가하려면 모든 페이지에 섹션이 최소한 하나는 있어야 합니다.
- **요소** -- 섹션 안에 놓이는 개별 콘텐츠 조각입니다. 텍스트, 이미지, 버튼, 카드, 양식, 캘린더 등이 있습니다.

### 섹션 추가하기

1. **Add Section**(또는 왼쪽 패널 위의 **+** 버튼)을 클릭하세요.
2. 시작 방법을 고르세요.
   - **From a template**(템플릿에서) -- 카테고리(Hero, About, Services, Giving 등)별로 정리된 섹션 템플릿 갤러리를 둘러보고, 하나를 클릭하면 스타일이 완성되고 내용이 채워진 섹션이 들어갑니다. 추가된 뒤에는 무엇이든 바꿀 수 있습니다.
   - **Blank section**(빈 섹션) -- 열 배치(한 열, 두 열, 세 열 등)를 고르고 처음부터 만듭니다.
3. 새 섹션이 미리 보기에 나타납니다. 섹션을 클릭해 선택하고 배경색, 여백, 기타 스타일 옵션을 설정하세요.

### 섹션 배치 바꾸기

섹션을 이미 만들었지만 다른 구조를 원한다면, 그 섹션의 레이아웃 전환기를 사용하세요. 갤러리에서 다른 열 배치로 바꾸면서, 기존 콘텐츠와 요소는 그대로 유지됩니다.

### 섹션에 요소 추가하기

1. 미리 보기에서 섹션 안을 클릭해 선택하세요.
2. **Add Content**를 클릭하고 목록에서 요소 유형을 고르세요.
   - **Text**(텍스트) -- 제목, 단락, 리치 텍스트
   - **Image**(이미지) -- 사진을 업로드하거나 사진에 링크
   - **Button**(버튼) -- 클릭할 수 있는 행동 유도 링크
   - **Card**(카드) -- 제목과 설명이 있는 이미지
   - **Form**(양식) -- [양식](../forms/creating-forms)을 페이지에 직접 넣기. 양식에 [머리글 사진](../forms/creating-forms.md#adding-a-header-photo)이 있다면 질문 위에 표시됩니다.
   - **Calendar**(캘린더) -- 행사 캘린더 표시
   - **FAQ** -- 아코디언 형식의 질문과 답변 블록
   - **Video**(영상) -- URL로 영상 삽입
   - **Groups Browser**(그룹 찾아보기) -- 교회의 모든 그룹을 검색, 카테고리 필터, 라벨 필터로 거를 수 있는 목록(선택 사항)
   - **Icon Feature**(아이콘 기능) -- 아이콘과 제목, 짧은 설명. 기능이나 사역을 강조할 때 씁니다.
   - **Gallery**(갤러리) -- 여러 사진을 격자 또는 벽돌 배치로 표시
   - **Testimonial**(추천글) -- 작성자 이름, 역할, 사진이 있는 하나 이상의 인용문
   - **Social Icons**(소셜 아이콘) -- 교회의 소셜 미디어 프로필로 연결되는 아이콘. Facebook, Instagram, WhatsApp, YouTube, X, TikTok, Vimeo, Podcast가 있습니다. 보여 주고 싶은 것마다 링크를 입력하세요. **WhatsApp**은 전화번호가 들어간 `https://wa.me/` 링크나 그룹 초대 링크를 쓰세요.
   - **Countdown**(카운트다운) -- 특정 날짜나 주간 예배 시간까지 세는 타이머
   - **Stats**(통계) -- 라벨이 붙은 큰 숫자 줄(교인 수, 연수, 캠퍼스 수)
   - **Campaign Progress**(캠페인 진행) -- 헌금 캠페인의 실시간 진행 막대. 펀드 목표를 향해 모인 총액을 보여 줍니다.
   - **Staff Grid**(직원 격자) -- 그룹 구성원의 사진 카드. 그룹의 **public roster**(공개 명단) 옵션이 켜져 있어야 합니다.
   - **Service Times**(예배 시간) -- 출석 설정에서 자동으로 가져온 캠퍼스별 예배 일정
   - **Sermons**(설교) -- 설교 자료실을 전체 탐색기로, 또는 격자, 목록, 최신 추천 레이아웃으로 표시
   - **Map**(지도) -- 교회 주소를 중심으로 한 지도 삽입
   - **Table**(표) -- 표 형식 내용을 위한 행과 열의 간단한 격자
   - **Text with Photo**(사진과 텍스트) -- 텍스트와 이미지를 나란히 배치
   - **Logo**(로고) -- [외관](appearance)에서 가져온 교회 로고
   - **Live Stream**(생방송) -- 생방송 플레이어를 페이지에 직접 삽입
   - **Podcast**(팟캐스트) -- 여러분이 입력한 외부 팟캐스트 RSS 피드 URL에서 가져온 에피소드 목록. 보여 줄 에피소드 수와 날짜 및 설명 표시 여부를 설정할 수 있습니다. 실제 사이트의 각 에피소드에는 오디오 플레이어와 **Download** 링크가 있어, 에피소드 제목으로 오디오 파일을 저장할 수 있습니다. 이것은 어떤 팟캐스트 피드든 사이트에서 소개하기 위한 것입니다. 자신의 설교를 팟캐스트로 게시하려면 대신 [설교 관리하기](../sermons/managing-sermons.md#your-podcast-feed)를 참고하세요.
   - **Donation**(헌금) -- 헌금 버튼이나 삽입된 헌금 양식
   - **HTML** -- 직접 작성한 원시 HTML. 제3자 위젯을 삽입하는 등 고급 용도에 씁니다([HTML 요소 사용하기](#using-the-html-element) 참고).
   - **iFrame** -- URL로 외부 콘텐츠 삽입
3. 나타나는 설정 패널에서 요소를 구성하세요.

### HTML 요소 사용하기 {#using-the-html-element}

**HTML** 요소에는 상자가 두 개 있습니다.

- **HTML Content**(HTML 콘텐츠) -- 페이지에 보여 줄 마크업. 여기에 넣은 `<script>` 태그는 실제 사이트에서 실행됩니다.
- **JavaScript (exclude script tag)**(자바스크립트(script 태그 제외)) -- 페이지가 로드될 때 실행되는 스크립트 코드. 여기에 벤더가 제공한 `<script>` 태그가 포함된 임베드 코드를 붙여 넣어도, 실제 사이트에서 실행됩니다.

자바스크립트 상자에 웹 주소(예: 이미지 링크)만 붙여 넣으면, 상자가 빨간색으로 바뀌며 *"This is a web address, not JavaScript."*(이것은 자바스크립트가 아니라 웹 주소입니다.)라는 경고가 표시됩니다. 그 상자에 있는 주소만으로는 아무 일도 일어나지 않습니다. 사진을 보여 주려면 **Image** 요소를 쓰거나, **HTML Content**에 `<img src="...">`를 넣으세요.

### 캘린더 요소 사용하기 {#using-the-calendar-element}

**Calendar** 요소는 여러분의 캘린더 중 하나에서 행사를 보여 줍니다.

1. **Select**(선택) 아래에서 **Group Calendar**(그룹 캘린더, 한 그룹의 행사이며 목록에는 내가 속한 그룹이 나타남) 또는 **Curated Calendar**(큐레이션 캘린더, **Calendars** 아래에서 만든 캘린더. [큐레이션 캘린더](../calendars/curated-calendar)를 참고하세요)를 고르세요.
2. **Select Calendar**(캘린더 선택) 아래에서 그룹이나 캘린더를 고르세요.
3. **Display**(표시) 아래에서 보여 주는 방식을 고르세요.
   - **Month calendar**(월간 캘린더) -- 방문자가 넘겨 볼 수 있는 한 달 격자
   - **Upcoming events**(다가오는 행사) -- 다음 12개 행사의 타일 격자. 반복되는 행사는 다음 날짜에 한 번만 보입니다. 각 타일에는 행사 사진(사진이 없다면 테마의 어두운 색 위에 제목), 날짜 배지, 요일과 시간, 설명의 첫 줄이 표시됩니다. 타일 위의 **Subscribe** 버튼으로 방문자가 캘린더의 ICS 링크를 복사하거나 내려받을 수 있습니다. 이 표시 방식에는 **Layout**(레이아웃) 설정도 나타납니다. **Grid**(격자, 기본값) 또는 **Scrolling (automatic)**(스크롤(자동))이며, 후자는 타일을 한 줄에 놓고 스스로 천천히 넘어가게 합니다.
4. 일부 행사만 보이게 하려면 **Only events tagged**(이 태그가 붙은 행사만)에 태그를 입력하세요. 예를 들어 `youth`. **Tags**에 그 단어가 포함된 행사만 나타납니다. 비워 두면 모든 행사가 보입니다. 태그는 행사마다 설정합니다. [행사 추가 및 편집](../calendars/creating-calendars.md#adding-and-editing-events)을 참고하세요.

두 표시 방식 모두에서, 행사를 클릭하면 웹사이트의 행사 페이지가 열립니다. 행사 페이지에는 행사 사진, 제목, 날짜와 시간, 설명이 나오며, **When**(반복 행사라면 반복 패턴 포함)과 **Where**(행사를 위해 예약된 방)가 있는 상자도 있습니다. 등록을 켜 두었다면 **Register for this Event** 버튼이 있고, **Add to my calendar** 링크로 행사를 캘린더 파일로 내려받을 수 있습니다. 이 페이지는 검색 엔진이 검색 결과에 행사의 날짜와 세부 정보를 표시할 수 있도록 설정되어 있습니다. 여러분의 페이지에 표시된 큐레이션 캘린더의 행사 페이지(향후 6개월 안의 행사)도 사이트맵에 나열되므로, 검색 엔진이 찾을 수 있습니다.

### 내용 순서 바꾸기

섹션이나 요소를 드래그해 순서를 바꾸세요. 각 항목 왼쪽의 손잡이 아이콘(점 여섯 개)을 끌면 됩니다. 요소는 섹션 안에서 끌거나 섹션 사이로 옮길 수 있습니다.

## 페이지 꾸미기

### 섹션 스타일

섹션을 클릭하면 스타일 패널이 열립니다. 다음을 설정할 수 있습니다.

- **Background**(배경) -- 단색, 그라데이션, 또는 이미지. 이미지 배경을 쓸 때 **Focal Point**(초점) 선택기로 섹션이 크기에 맞춰 조정될 때 가운데에 남을 부분을 클릭해 정할 수 있습니다. **Overlay**(오버레이) 색 옵션으로 이미지 위에 반투명한 색 막을 씌워 글자를 더 잘 읽히게 할 수 있습니다.
- **Padding**(여백) -- 섹션 안쪽의 위아래 간격
- **Width**(너비) -- 전체 너비 또는 가운데 정렬/제한된 너비
- **Dividers**(구분선) -- 섹션의 위쪽이나 아래쪽 가장자리에 놓는 장식용 모양 구분선(웨이브, 슬랜트, 곡선, 삼각형 등). 색, 높이, 뒤집기 옵션이 있습니다.

### 요소 스타일

요소를 클릭하면 스타일 패널이 열립니다. 일반적인 옵션은 글꼴 크기, 색, 정렬, 바깥 여백, 안쪽 여백입니다. 이미지라면 대체 텍스트와 링크 대상을 설정할 수 있습니다.

### 사용자 지정 CSS

고급 스타일링을 위해, 각 섹션과 요소에는 **Custom CSS** 필드가 있어 직접 CSS 규칙을 쓸 수 있습니다. 이 규칙은 해당 요소에만 적용되므로, 페이지의 나머지 부분에 의도치 않게 영향을 주지 않습니다.

:::tip
사용자 지정 글꼴이나 전역 색처럼 사이트 전체에 스타일을 적용해야 한다면, 개별 페이지의 사용자 지정 CSS 대신 [외관](appearance) 설정을 사용하세요.
:::

## 페이지 미리 보기

도구 모음의 미리 보기 컨트롤로 여러 화면 크기에서 페이지가 어떻게 보이는지 확인하세요.

- **Desktop**(데스크톱) -- 전체 너비의 브라우저 화면
- **Mobile**(모바일) -- 좁은 휴대폰 크기 화면

휴대폰에서는 행의 열들이 행의 설정에서 **Mobile Width**(모바일 너비)를 따로 지정하지 않는 한, 전체 너비로 위아래로 쌓입니다. 설교와 팟캐스트 목록도 휴대폰에서는 각 에피소드의 텍스트를 썸네일 아래에 쌓아 보여 줍니다.

방문자가 보게 될 실제 페이지를 정확히 보려면, 페이지 목록으로 돌아가 페이지의 경로를 클릭하세요. 새 브라우저 탭에서 열립니다.

## 접근성 확인하기

도구 모음의 **Accessibility**(접근성) 아이콘을 클릭하면 흔한 문제(대체 텍스트가 없는 이미지, 낮은 색 대비, 순서가 맞지 않는 제목)를 빠르게 점검합니다. 각 문제는 주의가 필요한 요소로 바로 연결되므로, 그 자리에서 고칠 수 있습니다.

## 변경 되돌리기

편집기는 편집 이력을 자동으로 기록합니다. 도구 모음 버튼이나 키보드 단축키로 이동하세요.

- **Undo**(실행 취소, Ctrl+Z / Cmd+Z) -- 마지막 작업을 되돌림
- **Redo**(다시 실행, Ctrl+Shift+Z 또는 Ctrl+Y / Cmd+Shift+Z) -- 되돌린 작업을 다시 적용

페이지를 이전 스냅샷으로 복원할 수도 있습니다. 도구 모음의 **View history**(기록 보기)를 클릭하면 설명과 함께 저장된 스냅샷 목록이 나타나며, 항목을 클릭하면 그 시점으로 되돌아갑니다.

:::warning
스냅샷을 복원하면 현재 페이지 내용이 스냅샷 버전으로 바뀝니다. 이것은 표준 실행 취소 버튼으로 되돌릴 수 없습니다. 나중에 돌아갈 수 있는 선택지를 남기고 싶다면, 오래된 스냅샷을 복원하기 전에 현재 상태의 스냅샷을 저장하세요.
:::

## 저장과 게시

작업하는 동안 변경 사항은 자동으로 저장됩니다. 도구 모음의 상태 표시기에서 변경 사항이 저장되었는지 확인할 수 있습니다.

### 임시 저장과 게시 상태

페이지에는 **published**(게시됨) 상태가 있어, 방문자가 변경 사항을 언제 볼지를 제어합니다. 도구 모음에는 현재 상태를 보여 주는 상태 칩이 표시됩니다.

- **Live on save**(저장하면 바로 공개) -- 페이지는 게시 워크플로를 쓰지 않습니다. 저장한 모든 변경 사항이 즉시 공개됩니다. 새 페이지의 기본값입니다.
- **Unpublished changes**(게시되지 않은 변경 사항) -- 이 페이지는 전에 게시된 적이 있지만, 마지막 게시 이후 변경한 내용이 있습니다. 방문자에게는 여전히 이전에 게시된 버전이 보입니다.
- **Published**(게시됨) -- 페이지가 공개되어 있으며, 저장된 내용과 방문자가 보는 내용이 일치합니다.

변경 사항을 게시하려면 도구 모음의 **Publish** 버튼을 클릭하세요. 페이지가 즉시 공개됩니다.

방문자가 보는 내용에 영향을 주지 않으면서 마지막으로 게시된 버전으로 되돌리려면, 더보기 메뉴(⋮)를 열고 **Discard unpublished changes**(게시되지 않은 변경 사항 취소)를 클릭하세요.

게시 워크플로를 쓰지 않으려면, 더보기 메뉴를 열고 **Turn off publishing**(게시 끄기)을 클릭하세요. 그러면 편집 내용이 다시 즉시 공개됩니다.

:::tip
페이지를 미리 준비하고 정확한 순간에만 공개하고 싶을 때, 예를 들어 다가오는 행사를 위해서라면 임시 저장/게시 워크플로를 쓰세요. 페이지를 만들고 미리 본 다음, 준비가 되면 Publish를 클릭하세요.
:::
