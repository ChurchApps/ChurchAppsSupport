# 웹사이트

<div class="article-intro">

B1 Admin의 웹사이트 섹션은 교회를 위한 완전한 기능의 웹사이트 빌더를 제공합니다. 코드를 작성할 필요 없이 페이지를 만들고, 사이트의 모양과 느낌을 사용자 정의하고, 미디어 파일을 관리하고, 이벤트 캘린더를 게시할 수 있습니다.

</div>

## 할 수 있는 일

웹사이트 빌더는 다음 주요 영역으로 구성되어 있습니다:

### 페이지

교회 웹사이트의 모든 페이지를 만들고 관리합니다. **페이지** 테이블에는 각 페이지가 나열됩니다. 시스템이 자동으로 만든 페이지에는 **생성** 배지가 표시되며, 나머지는 직접 만든 사용자 정의 페이지입니다. 새 사용자 정의 페이지를 추가하거나, 기존 페이지를 편집하거나, 자동 생성 페이지를 사용자 정의 페이지로 변환하여 콘텐츠를 완전히 제어할 수 있습니다.

네비게이션 링크는 트리 구조로 표시됩니다. 드래그 앤 드롭을 사용하여 링크를 순서를 바꿔서 방문객이 보게 될 정확한 계층 구조와 순서를 설정할 수 있습니다.

### 블로그 {#blog}

뉴스, 업데이트 및 묵상 글을 사이트의 `/blog`에 블로그 게시물로 게시하며 RSS 피드도 제공됩니다. [블로그](blog) 가이드를 참조하세요.

### 블록

여러 페이지에 배치할 수 있는 재사용 가능한 콘텐츠 구성 요소를 만듭니다. 블록은 행동 호출, 공지 배너 또는 연락처 섹션과 같이 한 곳 이상에 나타나는 콘텐츠가 있을 때 시간을 절약합니다. 블록을 한 번 업데이트하면 사용되는 모든 곳에 변경 사항이 적용됩니다.

### 모양

웹사이트의 테마, 색상, 글꼴, 로고 및 간격을 사용자 정의합니다. 빠른 시작을 위해 사전 구축된 스타일 테마를 적용하거나 색상 팔레트 편집기, 타이포그래피 설정 및 사용자 정의 CSS를 사용하여 모든 세부 정보를 미세 조정할 수 있습니다. 전체 세부 정보는 [모양](appearance) 가이드를 참조하세요.

### 파일

모든 미디어 자산(이미지, 문서 및 기타 파일)을 한 중앙 위치에 업로드하고 관리하며, 사이트 어디에서든 사용할 파일 링크를 복사합니다. 자세한 정보는 [파일](files)을 참조하세요.

### 캘린더

방문객들이 교회에서 일어나는 일을 볼 수 있도록 웹사이트에 이벤트 캘린더를 게시합니다. 여러 그룹의 이벤트를 하나의 보기로 선별된 캘린더를 만듭니다. 캘린더는 **웹사이트**와 별도로 B1 Admin 메뉴의 **캘린더** 항목에 있습니다.

:::tip
처음으로 웹사이트를 구성하는 경우 [초기 설정](initial-setup)을 시작하세요. 도메인 설정, 첫 페이지 만들기 및 사이트의 모양 구성 단계를 안내합니다.
:::
