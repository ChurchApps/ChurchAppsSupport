# 웹사이트

<div class="article-intro">

B1 Admin의 웹사이트 섹션은 교회를 위한 기능이 풍부한 웹사이트 빌더를 제공합니다. 코드를 전혀 쓰지 않고도 페이지를 만들고, 사이트의 모양과 느낌을 맞춤 설정하고, 미디어 파일을 관리하고, 행사 달력을 게시할 수 있습니다.

</div>

## 할 수 있는 작업 {#what-you-can-do}

웹사이트 빌더는 다음 주요 영역으로 구성되어 있습니다.

### 페이지 {#pages}

교회 웹사이트의 모든 페이지를 만들고 관리하세요. **Pages**(페이지) 표에는 각 페이지가 나열됩니다. 시스템이 자동으로 만든 페이지에는 **Generated**(자동 생성) 배지가 붙으며, 나머지는 직접 만든 사용자 지정 페이지입니다. 새 사용자 지정 페이지를 추가하거나, 기존 페이지를 편집하거나, 자동 생성된 페이지를 사용자 지정 페이지로 전환하여 내용을 완전히 제어할 수 있습니다.

탐색 링크는 Pages 표 옆의 **Main Navigation**(주 탐색) 패널에 나열됩니다. 드래그 앤 드롭으로 링크의 순서를 바꾸고 하위 항목으로 중첩하여, 방문자가 보게 될 정확한 계층과 순서를 설정할 수 있습니다. [페이지 관리](./managing-pages.md)를 참고하세요.

### 블로그 {#blog}

`/blog`에 소식, 업데이트, 묵상 글을 블로그 글로 게시하세요. RSS 피드도 제공됩니다. [블로그](./blog.md) 가이드를 참고하세요.

### 블록 {#blocks}

여러 페이지에 배치할 수 있는 재사용 가능한 콘텐츠 구성 요소를 만드세요. 행동 유도 문구, 공지 배너, 연락처 섹션처럼 여러 곳에 나타나는 콘텐츠가 있을 때 시간을 절약할 수 있습니다. 블록을 한 번 업데이트하면 그 블록이 쓰이는 모든 곳에 변경 사항이 적용됩니다. [재사용 블록](./blocks.md)을 참고하세요.

### 모양 {#appearance}

웹사이트의 테마, 색상, 글꼴, 로고, 간격을 맞춤 설정하세요. 미리 만들어진 스타일 테마로 빠르게 시작하거나, 색상 팔레트 편집기, 타이포그래피 설정, 사용자 지정 CSS로 모든 세부 사항을 미세하게 조정할 수 있습니다. 자세한 내용은 [모양](./appearance.md) 가이드를 참고하세요.

### 파일 {#files}

이미지, 문서, 기타 파일 등 모든 미디어 자산을 한 중앙 위치에서 업로드하고 관리하세요. 파일 링크를 복사하여 사이트의 어느 곳에서든 사용할 수 있습니다. 자세한 내용은 [파일](./files.md)을 참고하세요.

### 달력 {#calendars}

방문자가 교회에서 무슨 일이 일어나는지 볼 수 있도록 웹사이트에 행사 달력을 게시하세요. 여러 그룹의 행사를 하나의 보기로 모으는 큐레이션 달력을 만들 수 있습니다. 달력은 **Website**와 별도로, B1 Admin 메뉴에 자체 **Calendars**(달력) 항목이 있습니다.

:::tip
웹사이트를 처음 설정한다면 [초기 설정](./initial-setup.md)부터 시작하세요. 도메인 설정, 첫 페이지 만들기, 사이트 모양 구성을 차례로 안내합니다.
:::
