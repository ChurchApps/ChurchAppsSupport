# 페이지 관리

<div class="article-intro">

웹사이트 페이지 화면은 교회 웹사이트의 모든 페이지를 만들고, 편집하고, 정리하는 중심 허브입니다. 이 하나의 화면에서 페이지 콘텐츠와 사이트 내비게이션을 모두 관리할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 도메인과 기본 사이트 설정을 구성하려면 [초기 설정](initial-setup)을 완료하세요
- 콘텐츠와 이미지를 준비하세요. 먼저 [파일](files) 관리자를 사용해 미디어 자산을 업로드하세요.

</div>

:::info
교회에 웹사이트가 여러 개 있다면(예: 캠퍼스별로 별도 사이트), 웹사이트 페이지 화면 상단의 사이트 전환기를 사용해 사이트 간에 이동할 수 있습니다. 각 사이트는 고유한 페이지, 내비게이션, [외관](appearance) 설정을 가집니다.
:::

## 페이지 유형 이해하기

**페이지(Pages)** 표에는 사이트의 모든 페이지와 각 페이지의 상태가 나열됩니다.

- **자동 생성됨(Generated)** -- 교회 데이터를 기반으로 시스템이 자동으로 만든 페이지입니다(예: 그룹 페이지, 설교 페이지, 라이브러리 내 각 설교마다 만들어지는 개별 페이지). 이런 페이지는 데이터가 바뀌면 스스로 업데이트됩니다.
- **사용자 지정(Custom)** -- 직접 콘텐츠와 레이아웃을 만든 페이지입니다.

콘텐츠와 디자인을 완전히 제어하고 싶다면 자동 생성된 페이지를 사용자 지정 페이지로 전환할 수 있습니다.

## 페이지 추가 및 편집하기

1. 페이지 표 오른쪽 상단의 **페이지 추가(Add Page)** 버튼을 클릭합니다.
2. 페이지 유형(빈 페이지 또는 템플릿)을 선택하고 이름을 붙입니다.
3. 페이지 옆의 **편집(Edit)**을 클릭하면 [페이지 편집기](page-editor)가 열리며, 여기서 섹션, 텍스트, 이미지 및 기타 요소를 추가할 수 있습니다.
4. **페이지 설정(Page Settings)**을 클릭해 페이지 제목, URL 경로, 기타 메타데이터를 업데이트합니다.
5. **미리보기(Preview)** 버튼을 사용해 새 창에서 페이지를 열고, 방문자에게 실제로 어떻게 보일지 정확히 확인하세요.

:::tip
홈페이지의 경우 URL 경로를 그냥 `/`로 설정하세요. 다른 모든 페이지에는 `/about`이나 `/contact`처럼 설명적인 경로를 사용하세요.
:::

### 페이지 설정

어느 페이지에서든 **페이지 설정(Page Settings)**을 열면 다음을 구성할 수 있습니다.

- **제목과 URL 경로** -- 페이지 이름과 사이트 내 주소입니다.
- **표시 여부(Visibility)** -- 이 페이지를 볼 수 있는 사람을 선택합니다: 전체, 교인만, 스태프만, 또는 특정 그룹의 구성원. 별도의 비밀번호 없이 (스태프 자료 페이지 같은) 비공개 페이지를 빠르게 제한하는 방법입니다.
- **메타 설명(Meta Description)** -- 검색 엔진 결과와 소셜 미디어 링크 미리보기에 표시되는 짧은 요약입니다.
- **리다이렉트(Redirects)** -- 이전 URL 경로를 이 페이지로 연결해서, 폐지된 페이지에 대한 링크와 북마크가 계속 작동하도록 합니다.

## 내비게이션 관리하기

웹사이트 페이지 화면의 왼쪽 사이드바에는 내비게이션 링크가 표시됩니다. 이 링크들이 방문자가 웹사이트에서 보게 되는 메뉴를 제어합니다.

1. **추가(Add)**를 클릭해 새 내비게이션 링크를 만듭니다. 사이트 내 어느 페이지로든, 또는 외부 URL로 연결할 수 있습니다.
2. 링크 순서를 바꾸려면 원하는 순서로 드래그 앤 드롭하세요. 상위 항목 아래에 링크를 중첩시켜 드롭다운 메뉴를 만들 수도 있습니다.
3. 링크 옆의 **편집(Edit)** 아이콘을 클릭해 레이블, URL, 위치를 변경합니다.
4. 내비게이션에서 링크를 제거하려면 **삭제(Delete)** 아이콘을 클릭합니다.

:::info
내비게이션 링크를 제거해도 페이지 자체는 삭제되지 않습니다. 페이지는 여전히 존재하며 URL로 직접 접근할 수 있습니다 -- 다만 메뉴에는 더 이상 표시되지 않습니다.
:::

## 사이트 구성 팁

- 방문자가 원하는 것을 빠르게 찾을 수 있도록 최상위 내비게이션은 5~6개 항목으로 유지하세요.
- 관련된 하위 페이지에는 중첩 링크를 사용하세요(예: "소개" 드롭다운 아래에 "우리 팀", "신앙", "역사").
- **모바일 미리보기(Mobile Preview)**를 클릭해 작은 화면에서도 내비게이션이 잘 작동하는지 확인하세요.
- 방문자가 무엇을 찾을 수 있는지 이해할 수 있도록 페이지 이름은 명확하고 설명적으로 지어주세요.

:::tip
[양식](../forms/creating-forms.md)을 페이지에 추가해서 방문자로부터 등록 정보, 기도 요청, 기타 정보를 수집할 수 있습니다.
:::

## 사이트 템플릿으로 시작하기

처음부터 사이트를 구축하는 경우, 페이지를 하나씩 만드는 대신 **사이트 템플릿(Site Template)**을 이용해 빠르게 시작할 수 있습니다. 사이트 템플릿은 홈, 소개, 커넥트, 헌금 등 미리 만들어진 페이지들을 생성하며, 자리 표시자 콘텐츠와 내비게이션 링크가 이미 연결되어 있습니다.

1. 페이지 화면에서 (**페이지 추가** 버튼 옆에 있는) **사이트 템플릿(Site Templates)** 버튼을 클릭합니다.
2. 사용 가능한 템플릿을 둘러보고, 하나를 클릭해 페이지 구조를 미리 봅니다.
3. 마음에 드는 템플릿을 찾으면 **템플릿 적용(Apply Template)**을 클릭합니다.
4. 아직 존재하지 않는 페이지들이 생성되어 내비게이션에 추가됩니다. 기존 페이지는 그대로 유지됩니다.

템플릿을 적용한 뒤에는 [페이지 편집기](page-editor)에서 각 페이지를 열어 자리 표시자 텍스트와 이미지를 교회의 실제 콘텐츠로 바꾸세요.

:::info
사이트 템플릿은 페이지 구조와 내비게이션을 만들어 줄 뿐입니다. 사이트의 색상 구성이나 글꼴을 재정의하지는 않습니다 -- 이는 [외관](appearance)에서 제어됩니다.
:::

## 이미지 라이트박스

방문자가 웹사이트의 이미지를 클릭하면 전체 화면 라이트박스 오버레이로 열립니다. 이를 통해 페이지를 벗어나지 않고도 사진을 더 크게 볼 수 있습니다. 별도의 설정이 필요 없습니다 -- 페이지 콘텐츠의 이미지에는 라이트박스가 자동으로 활성화됩니다.
