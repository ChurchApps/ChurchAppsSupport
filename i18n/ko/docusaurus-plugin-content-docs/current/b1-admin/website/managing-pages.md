# 페이지 관리

<div class="article-intro">

웹사이트 페이지 보기는 교회 웹사이트의 모든 페이지를 만들고, 편집하고, 구성하기 위한 중앙 허브입니다. 이 단일 화면에서 페이지 콘텐츠와 사이트의 네비게이션을 모두 관리할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [초기 설정](initial-setup)을 완료하여 도메인 및 기본 사이트 설정 구성
- 콘텐츠 및 이미지 준비. 먼저 [파일](files) 관리자를 사용하여 미디어 자산 업로드

</div>

:::info
교회에 둘 이상의 웹사이트가 있는 경우(예: 캠퍼스별 별도 사이트), 웹사이트 페이지 보기의 상단에 있는 사이트 전환기를 사용하여 페이지 간에 이동합니다. 각 사이트에는 고유한 페이지, 네비게이션 및 [모양](appearance) 설정이 있습니다.
:::

## 페이지 유형 이해

**페이지** 테이블은 사이트의 모든 페이지와 함께 상태를 나열합니다:

- **생성** -- 교회의 데이터를 기반으로 시스템이 자동으로 만든 페이지(예: 그룹 페이지, 설교 페이지 또는 라이브러리의 각 설교에 대한 개별 페이지). 이러한 페이지는 데이터가 변경되면 자동으로 업데이트됩니다.
- **사용자 정의** -- 고유한 콘텐츠 및 레이아웃으로 직접 만든 페이지입니다.

자동 생성 페이지를 사용자 정의 페이지로 변환하여 콘텐츠 및 디자인을 완전히 제어할 수 있습니다.

## 페이지 추가 및 편집

1. 페이지 테이블의 오른쪽 위 모서리의 **페이지 추가** 버튼을 클릭합니다.
2. 페이지 유형(비어 있음 또는 템플릿)을 선택하고 이름을 지정합니다.
3. 모든 페이지 옆의 **편집**을 클릭하여 [페이지 편집기](page-editor)를 열어서 섹션, 텍스트, 이미지 및 기타 요소를 추가할 수 있습니다.
4. **페이지 설정**을 클릭하여 페이지 제목, URL 경로 및 기타 메타데이터를 업데이트합니다.
5. **미리보기** 버튼을 사용하여 새 창에서 페이지를 열고 방문객에게 정확히 어떻게 보이는지 확인합니다.

:::tip
홈 페이지의 경우 URL 경로를 `/`로 설정합니다. 다른 모든 페이지의 경우 `/about` 또는 `/contact`와 같은 설명적인 경로를 사용합니다.
:::

### 페이지 설정

모든 페이지에서 **페이지 설정**을 열어서 다음을 구성합니다:

- **제목 및 URL 경로** -- 페이지 이름 및 사이트의 주소입니다.
- **표시 설정** -- 페이지를 볼 수 있는 사람 선택: 모두, 회원만, 직원만 또는 특정 그룹의 회원. 이것은 비밀번호 없이 개인 페이지(직원 리소스 페이지 같은)를 빠르게 제한하는 방법입니다.
- **메타 설명** -- 검색 엔진 결과 및 소셜 미디어 링크 미리보기에 표시되는 짧은 요약입니다.
- **리디렉션** -- 이전 URL 경로를 이 페이지로 지정하여 폐기된 페이지의 링크 및 북마크가 계속 작동합니다.

## 네비게이션 관리

웹사이트 페이지 보기에는 네비게이션 링크가 표시됩니다. 이러한 링크는 방문객이 웹사이트에서 보는 메뉴를 제어합니다.

1. **추가**를 클릭하여 새 네비게이션 링크를 만듭니다. 사이트의 모든 페이지 또는 외부 URL을 가리킬 수 있습니다.
2. 링크를 드래그 앤 드롭하여 원하는 순서로 순서를 바꿉니다. 상위 항목 아래에 링크를 중첩하여 드롭다운 메뉴를 만들 수도 있습니다.
3. 모든 링크 옆의 **편집** 아이콘을 클릭하여 레이블, URL 또는 위치를 변경합니다.
4. 네비게이션에서 링크를 제거하려면 **삭제** 아이콘을 클릭합니다.

:::info
네비게이션 링크를 제거해도 페이지 자체는 삭제되지 않습니다. 페이지는 계속 존재하며 직접 URL로 접근할 수 있습니다 -- 메뉴에만 표시되지 않습니다.
:::

## 사이트 구성 팁

- 방문객이 빠르게 찾을 수 있도록 최상위 네비게이션을 5~6개 항목으로 유지합니다.
- 관련 하위 페이지의 경우 중첩된 링크를 사용합니다(예: "팀", "신념" 및 "역사"를 포함한 "정보" 드롭다운).
- **모바일 미리보기**를 클릭하여 모바일에서 네비게이션이 잘 작동하는지 확인합니다.
- 방문객이 찾을 내용을 이해하는 데 도움이 되는 명확한 설명적 이름을 페이지에 지정합니다.

:::tip
[양식](../forms/creating-forms.md)을 페이지에 추가하여 방문객의 등록, 기도 요청 또는 기타 정보를 수집할 수 있습니다.
:::

## 사이트 템플릿에서 시작

처음부터 사이트를 빌드하는 경우, 한 번에 하나의 페이지를 만드는 대신 **사이트 템플릿**을 사용하여 부트스트랩할 수 있습니다. 사이트 템플릿은 자리 표시자 콘텐츠 및 이미 연결된 네비게이션 링크가 있는 홈, 정보, 연결, 기부금 등의 사전 구축된 페이지 세트를 만듭니다.

1. 페이지 화면에서 **사이트 템플릿** 버튼(**페이지 추가** 버튼 옆)을 클릭합니다.
2. 사용 가능한 템플릿을 찾아보고 하나를 클릭하여 페이지 구조를 미리 봅니다.
3. 마음에 드는 것을 찾으면 **템플릿 적용**을 클릭합니다.
4. 아직 존재하지 않는 페이지가 만들어지고 네비게이션에 추가됩니다. 기존 페이지는 그대로 유지됩니다.

템플릿을 적용한 후, [페이지 편집기](page-editor)에서 각 페이지를 열어서 자리 표시자 텍스트 및 이미지를 교회의 실제 콘텐츠로 바꾸세요.

:::info
사이트 템플릿은 페이지 구조 및 네비게이션을 만듭니다. 사이트의 색 구성표 또는 글꼴은 재정의하지 않습니다 -- 이는 [모양](appearance)에서 제어됩니다.
:::

## 이미지 라이트박스

방문객이 웹사이트의 이미지를 클릭하면 전체 화면 라이트박스 오버레이에서 열립니다. 이렇게 하면 사람들이 페이지를 떠나지 않고 더 큰 크기로 사진을 볼 수 있습니다. 구성이 필요하지 않습니다 -- 라이트박스는 페이지 콘텐츠의 이미지에 대해 자동으로 활성화됩니다.
