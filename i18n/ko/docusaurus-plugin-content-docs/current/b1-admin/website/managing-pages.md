# 페이지 관리

<div class="article-intro">

웹사이트 페이지 보기는 교회 웹사이트의 모든 페이지를 생성, 편집 및 구성하기 위한 중앙 허브입니다. 단일 화면에서 페이지 콘텐츠와 사이트의 네비게이션을 모두 관리할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 도메인 및 기본 사이트 설정을 구성하려면 [초기 설정](initial-setup)을 완료하세요
- 콘텐츠 및 이미지를 준비하세요. [파일](files) 관리자를 사용하여 미디어 자산을 먼저 업로드합니다.

</div>

:::info
교회에 웹사이트가 2개 이상인 경우(예: 캠퍼스당 별도 사이트) 웹사이트 페이지 보기의 상단에 있는 사이트 전환기를 사용하여 사이트 간을 이동합니다. 각 사이트에는 자신의 페이지, 네비게이션 및 [외형](appearance) 설정이 있습니다.
:::

## 페이지 유형 이해

**페이지** 테이블은 사이트의 모든 페이지를 상태와 함께 나열합니다:

- **생성됨** - 교회의 데이터를 기반으로 시스템에서 자동으로 생성된 페이지(예: 그룹 페이지, 설교 페이지 또는 라이브러리의 각 설교에 대한 개별 페이지). 이 페이지는 데이터가 변경됨에 따라 스스로 업데이트됩니다.
- **사용자 정의** - 자신의 콘텐츠와 레이아웃으로 직접 생성한 페이지입니다.

콘텐츠 및 디자인을 완전히 제어하려면 자동으로 생성된 페이지를 사용자 정의 페이지로 변환할 수 있습니다.

## 페이지 추가 및 편집

1. 페이지 테이블의 오른쪽 위 모서리에서 **페이지 추가** 버튼을 클릭합니다.
2. 페이지 유형(빈 페이지 또는 템플릿)을 선택하고 이름을 지정합니다.
3. 모든 페이지 옆의 **콘텐츠 편집**을 클릭하여 [페이지 편집기](page-editor)를 열고 섹션, 텍스트, 이미지 및 기타 요소를 추가할 수 있습니다.
4. **페이지 설정**(톱니바퀴 아이콘)을 클릭하여 페이지 제목, URL 경로 및 기타 메타데이터를 업데이트합니다.
5. **라이브 페이지 보기** 버튼을 사용하여 새 창에서 페이지를 열고 방문자에게 정확히 어떻게 보일지 확인합니다.

:::tip
홈 페이지의 경우 URL 경로를 `/`로만 설정합니다. 다른 모든 페이지의 경우 `/about` 또는 `/contact`와 같은 설명적인 경로를 사용합니다.
:::

### 페이지 설정

모든 페이지에서 **페이지 설정**을 열어 구성합니다:

- **제목 및 URL 경로** - 페이지 이름 및 사이트의 주소입니다.
- **표시 여부** - 페이지를 볼 수 있는 사람을 선택합니다: 모두, 구성원만, 직원만 또는 특정 그룹의 구성원입니다. 이는 별도의 비밀번호 없이 비공개 페이지(예: 직원 리소스 페이지)를 보호하는 빠른 방법입니다.
- **메타 설명** - 검색 엔진 결과 및 소셜 미디어 링크 미리보기에 표시되는 짧은 요약입니다.
- **리디렉션** - 이전 URL 경로를 이 페이지로 지정하여 은퇴한 페이지에 대한 링크 및 북마크가 계속 작동하도록 합니다.

## 네비게이션 관리

웹사이트 페이지 보기는 네비게이션 링크를 표시합니다. 이 링크는 방문자가 웹사이트에서 보는 메뉴를 제어합니다.

1. **추가**를 클릭하여 새 네비게이션 링크를 만듭니다. 사이트의 모든 페이지 또는 외부 URL을 지정할 수 있습니다.
2. 링크의 순서를 변경하려면 원하는 순서로 끌어다 놓습니다. 상위 항목 아래에 링크를 중첩하여 드롭다운 메뉴를 만들 수도 있습니다.
3. 링크 옆의 **편집** 아이콘을 클릭하여 레이블, URL 또는 위치를 변경합니다.
4. 네비게이션에서 링크를 제거하려면 **삭제** 아이콘을 클릭합니다.

:::info
네비게이션 링크를 제거하면 페이지 자체가 삭제되지 않습니다. 페이지는 계속 존재하며 URL로 직접 액세스할 수 있습니다. 단순히 메뉴에 나타나지 않을 뿐입니다.
:::

## 사이트 전체 스위치

웹사이트 페이지 보기의 왼쪽에 있는 **주 네비게이션** 위에는 전체 교회 웹사이트에 적용되는 두 개의 스위치가 있습니다:

- **로그인 표시** - 웹사이트의 네비게이션 표시줄에 **로그인** 버튼을 표시합니다.
- **공개 웹사이트 비활성화** - 공개 웹사이트를 끕니다. 교회가 B1을 구성원 포털, 기부, 등록에만 사용하고 주요 웹사이트를 다른 곳에 유지하는 경우 사용합니다.

### 공개 웹사이트 비활성화의 효과

**공개 웹사이트 비활성화**가 켜져 있을 때:

- 홈 페이지 및 사용자 정의 페이지를 포함한 모든 공개 페이지는 로그인하지 않은 방문자를 로그인 화면으로 보냅니다. 로그인한 후 요청한 페이지로 돌아갑니다.
- 로그인한 구성원은 네비게이션 및 기본 제공 **생성된** 페이지(예: 그룹 및 설교)를 포함하여 전체 웹사이트를 평소대로 볼 수 있습니다. 생성된 페이지는 더 이상 페이지 테이블에 나타나지 않습니다.
- 검색 엔진에 사이트를 인덱싱하지 않도록 지시합니다. 사이트맵은 비어 있고 `robots.txt`는 모든 크롤링을 차단합니다.

이 링크는 계속 작동하므로 구성원과 게스트는 여전히 액세스할 수 있습니다:

- 로그인 및 로그아웃
- 구성원 포털(`/mobile` 아래의 모든 항목)
- [이벤트 등록](../guides/event-registration.md) 링크 및 게스트 등록

공개 웹사이트가 꺼져 있는 동안 스위치 아래에 경고가 표시됩니다. 스위치를 다시 끄면 페이지가 돌아옵니다. 사이트가 비활성화되는 동안 아무것도 삭제되지 않습니다.

:::info
이 설정은 전체 교회에 적용됩니다. 2개 이상의 사이트가 있는 경우 사이트 전환기에서 선택한 사이트만이 아니라 모두 끕니다.
:::

## 사이트 구성 팁

- 상위 수준 네비게이션을 5개 또는 6개 항목으로 유지하여 방문자가 빠르게 찾을 수 있습니다.
- 관련 하위 페이지에 중첩된 링크를 사용합니다(예: "우리 팀", "신념" 및 "역사"가 있는 "정보" 드롭다운).
- **모바일 미리보기**를 클릭하여 모바일에서 네비게이션을 검토하여 작은 화면에서 제대로 작동하는지 확인합니다.
- 방문자가 찾을 것을 이해할 수 있도록 명확하고 설명적인 페이지 이름을 지정합니다.

:::tip
페이지에 [양식](../forms/creating-forms.md)을 추가하여 방문자의 등록, 기도 요청 또는 기타 정보를 수집할 수 있습니다.
:::

## 사이트 템플릿에서 시작

사이트를 처음부터 빌드하는 경우 한 번에 하나씩 페이지를 만드는 대신 **사이트 템플릿**을 사용하여 부트스트랩할 수 있습니다. 사이트 템플릿은 홈, 정보, 연결, 기부 등 일련의 사전 구축된 페이지를 만들고 플레이스홀더 콘텐츠 및 네비게이션 링크가 이미 연결되어 있습니다.

1. 페이지 화면에서 **사이트 템플릿** 버튼(**페이지 추가** 버튼 옆)을 클릭합니다.
2. 사용 가능한 템플릿을 탐색하고 하나를 클릭하여 페이지 구조를 미리 봅니다.
3. 마음에 드는 것을 찾으면 **템플릿 적용**을 클릭합니다.
4. 아직 없는 페이지가 생성되고 네비게이션에 추가됩니다. 기존 페이지는 그대로 유지됩니다.

템플릿을 적용한 후 [페이지 편집기](page-editor)에서 각 페이지를 열어 플레이스홀더 텍스트 및 이미지를 교회의 실제 콘텐츠로 바꿉니다.

:::info
사이트 템플릿은 페이지 구조 및 네비게이션을 만듭니다. 사이트의 색상 구성 또는 글꼴을 재정의하지 않습니다. 이들은 [외형](appearance)으로 제어됩니다.
:::

## 이미지 라이트박스

방문자가 웹사이트의 이미지를 클릭하면 전체 화면 라이트박스 오버레이로 열립니다. 이를 통해 사람들이 페이지를 떠나지 않고 더 큰 크기로 사진을 볼 수 있습니다. 구성이 필요하지 않습니다. 라이트박스는 페이지 콘텐츠의 이미지에 대해 자동으로 활성화됩니다.
