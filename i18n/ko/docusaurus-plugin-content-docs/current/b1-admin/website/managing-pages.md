# 페이지 관리

<div class="article-intro">

웹사이트 페이지 보기는 교회 웹사이트의 모든 페이지를 만들고, 편집하고, 정리하는 중심 공간입니다. 이 한 화면에서 페이지 내용과 사이트 탐색을 모두 관리할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 도메인과 기본 사이트 설정을 구성하려면 [초기 설정](./initial-setup.md)을 마치세요
- 콘텐츠와 이미지를 준비하세요. 먼저 [파일](./files.md) 관리자를 사용하여 미디어 자산을 업로드하세요.
- 컴퓨터나 태블릿을 사용하세요. 웹사이트 페이지 보기와 페이지 편집기는 최소 약 880픽셀 너비의 화면이 필요합니다. 휴대폰에서는 더 큰 화면으로 바꾸라는 메시지가 표시됩니다.

</div>

:::info
교회에 웹사이트가 둘 이상 있다면(예: 캠퍼스별로 따로 사이트), 웹사이트 페이지 보기 상단의 사이트 전환기를 사용하여 사이트 사이를 이동하세요. 각 사이트는 자체 페이지, 탐색, [모양](./appearance.md) 설정을 가집니다. 아래의 [여러 웹사이트](#multiple-websites)를 참고하세요.
:::

## 페이지 유형 이해하기 {#understanding-page-types}

**Pages**(페이지) 표에는 사이트의 모든 페이지가 **Path**(경로)와 **Title**(제목)로 나열됩니다. 페이지에는 두 가지 종류가 있습니다.

- **Generated**(자동 생성) -- 교회의 데이터를 바탕으로 시스템이 자동으로 만든 페이지입니다(예: 그룹 페이지, 설교 페이지, 라이브러리의 설교마다 있는 개별 페이지). 이 페이지에는 **Generated** 배지가 표시되며, 데이터가 바뀌면 스스로 업데이트됩니다.
- **Custom**(사용자 지정) -- 직접 내용과 레이아웃을 만든 페이지입니다.

내용과 디자인을 완전히 제어하고 싶다면 자동 생성된 페이지를 사용자 지정 페이지로 바꿀 수 있습니다. 자동 생성된 페이지 옆의 **Convert**(변환)를 클릭하고 **Confirm**(확인)을 클릭하세요. **New Page**(새 페이지) 대화 상자가 열리면 페이지 제목을 입력하고 **Save**를 클릭하세요. 새 사용자 지정 페이지가 자동 생성된 페이지의 경로를 이어받으며, 이후 [페이지 편집기](./page-editor.md)에서 만들 수 있습니다.

## 페이지 추가 및 편집하기 {#adding-and-editing-pages}

1. 웹사이트 페이지 보기 오른쪽 상단의 **Add Page**(페이지 추가) 버튼을 클릭하세요.
2. 페이지 유형을 선택하고 **Page Title**(페이지 제목)을 입력한 다음 **Save**를 클릭하세요. **Blank**(빈 페이지)는 빈 페이지를 시작하고, **Sermons**(설교), **About Us**(교회 소개), **Donate**(헌금), **Location**(위치)은 그 종류의 페이지에 맞는 제목을 미리 채워 줍니다. **AI**는 입력한 짧은 설명으로 페이지의 초안을 만듭니다. 페이지의 경로는 제목에서 만들어집니다(예: "Our Team"은 `/our-team`이 됩니다). 나중에 **Page Settings**(페이지 설정)에서 바꿀 수 있습니다.
3. 아무 페이지 옆의 **Edit Content**(콘텐츠 편집)를 클릭하면 [페이지 편집기](./page-editor.md)가 열리며, 여기에서 섹션, 텍스트, 이미지, 기타 요소를 추가할 수 있습니다.
4. 페이지 옆의 **Page Settings**를 클릭하면 페이지 제목, URL 경로, 기타 메타데이터를 업데이트할 수 있습니다.
5. **Path**(경로) 열에서 페이지의 경로를 클릭하면 실제 페이지가 새 탭에서 열리므로, 방문자에게 정확히 어떻게 보일지 확인할 수 있습니다.

:::tip
홈 페이지는 URL 경로를 `/`로만 설정하세요. 다른 모든 페이지는 `/about`이나 `/contact`처럼 설명이 분명한 경로를 사용하세요.
:::

### 페이지 설정 {#page-settings}

아무 페이지에서나 **Page Settings**를 열어 다음을 설정할 수 있습니다.

- **Page Title**(페이지 제목) -- 페이지 이름입니다.
- **Layout**(레이아웃) -- **Header & Footer**(머리글과 바닥글)(기본값으로, 페이지를 감싸는 사이트 탐색 모음과 바닥글이 있습니다) 또는 **Clean Centered Content**(깔끔한 가운데 정렬 콘텐츠)(밝은 회색 배경 위의 가운데 정렬 카드에 페이지 내용만 표시하며, 탐색 모음과 바닥글이 없습니다. 간단한 신청 페이지나 랜딩 페이지에 편리합니다).
- **URL Path**(URL 경로) -- 사이트에서 페이지의 주소입니다. 연필 아이콘을 클릭하여 바꾼 다음 **Check**(확인)를 클릭하여 경로가 유효하고 이미 사용 중이지 않은지 확인하세요.
- **Visibility**(표시 대상) -- 페이지를 볼 수 있는 사람을 선택합니다. **Everyone**(모두), **Logged-in Users**(로그인한 사용자), **Members & Staff**(구성원과 직원), **Staff Only**(직원만), **Team Members**(팀 구성원), **Specific Groups**(특정 그룹)(그다음 그룹을 체크) 중 하나입니다. 별도의 암호 없이 비공개 페이지(예: 직원 자료 페이지)를 제한하는 간편한 방법입니다. 로그인하지 않은 방문자에게는 **Login**(로그인) 버튼과 함께 "This page is for church members."(이 페이지는 교회 구성원을 위한 것입니다.)가 표시됩니다. 페이지가 공유되지 않은 로그인한 사람에게는 "You don't have access to this page."(이 페이지에 접근 권한이 없습니다.)가 표시됩니다. 제한된 페이지는 사이트맵에서 제외됩니다.
- **Meta Description**(메타 설명) -- 검색 엔진 결과와 소셜 미디어 링크 미리 보기에 표시되는 짧은 요약입니다. 약 155자를 목표로 하거나, **Generate with AI**(AI로 생성)를 클릭하여 페이지 내용에서 초안을 만드세요.

대화 상자에는 페이지와 모든 내용을 복사하는 **Duplicate**(복제) 버튼과, 페이지를 영구적으로 삭제하는 **Delete**(삭제) 버튼도 있습니다.

:::tip
오래된 주소를 페이지로 보내려면(예: `/about-us`의 이름을 `/about`으로 바꾼 후), [모양](./appearance.md#redirects--analytics)의 **Redirects & analytics**(리디렉션 및 분석)에서 리디렉션을 추가하세요.
:::

## 탐색 관리하기 {#managing-navigation}

웹사이트 페이지 보기 오른쪽의 **Main Navigation**(주 탐색) 패널에는 탐색 링크가 표시됩니다. 이 링크들은 방문자가 웹사이트에서 보는 메뉴를 제어합니다.

1. **Add**(추가)를 클릭하여 새 탐색 링크를 만드세요. 사이트의 아무 페이지나 외부 URL을 가리킬 수 있습니다.
2. 링크의 순서를 바꾸려면 원하는 순서로 드래그 앤 드롭하세요. 상위 항목 아래에 링크를 중첩하여 드롭다운 메뉴를 만들 수도 있습니다.
3. 링크를 클릭하면 **Link Settings**(링크 설정)가 열립니다. 여기에서 텍스트, URL, 상위 페이지를 바꿀 수 있습니다.
4. 탐색에서 링크를 제거하려면, **Link Settings**를 열고 **Delete**를 클릭하세요.

:::info
탐색 링크를 제거해도 페이지 자체는 삭제되지 않습니다. 페이지는 여전히 존재하며 URL로 직접 접근할 수 있습니다. 단지 메뉴에 나타나지 않을 뿐입니다.
:::

## 사이트 전체 스위치 {#site-wide-switches}

**Main Navigation** 패널의 링크 아래에는 교회 웹사이트 전체에 적용되는 두 개의 스위치가 있습니다.

- **Show Login**(로그인 표시) -- 웹사이트 탐색 모음에 **Login**(로그인) 버튼을 표시합니다.
- **Disable Public Website**(공개 웹사이트 끄기) -- 공개 웹사이트를 끕니다. 교회가 B1을 회원 포털, 헌금, 등록에만 사용하고 주 웹사이트는 다른 곳에 둘 때 사용하세요.

### 공개 웹사이트를 끄면 일어나는 일 {#what-disabling-the-public-website-does}

**Disable Public Website**를 켜면:

- 홈 페이지와 사용자 지정 페이지를 포함한 모든 공개 페이지가, 로그인하지 않은 방문자를 로그인 화면으로 보냅니다. 로그인한 후에는 요청했던 페이지로 돌아갑니다.
- 로그인한 구성원은 평소처럼 탐색과 자동 생성된 기본 페이지(그룹, 설교 등)를 포함한 전체 웹사이트를 봅니다. 자동 생성된 페이지는 더 이상 Pages 표에 나타나지 않습니다.
- 검색 엔진에는 사이트를 색인하지 말라고 알립니다. 사이트맵은 비어 있고 `robots.txt`는 모든 크롤링을 차단합니다.

다음 링크는 계속 작동하므로, 구성원과 손님은 여전히 접근할 수 있습니다.

- 로그인과 로그아웃
- 회원 포털(`/mobile` 아래의 모든 것)
- [행사 등록](../guides/event-registration.md) 링크와 손님 등록

공개 웹사이트가 꺼져 있는 동안에는 스위치 아래에 경고가 표시됩니다. 페이지를 되돌리려면 스위치를 다시 끄세요. 사이트가 꺼져 있는 동안 아무것도 삭제되지 않습니다.

:::info
이 설정은 교회 전체에 적용됩니다. 사이트가 둘 이상이라면, 사이트 전환기에서 선택한 사이트뿐 아니라 모든 사이트가 꺼집니다.
:::

## 사이트 정리 팁 {#tips-for-organizing-your-site}

- 방문자가 빠르게 찾을 수 있도록 최상위 탐색은 다섯 또는 여섯 개 항목으로 유지하세요.
- 관련된 하위 페이지에는 중첩 링크를 사용하세요(예: "About"(교회 소개) 드롭다운에 "Our Team"(우리 팀), "Beliefs"(신앙), "History"(역사)를 넣기).
- 작은 화면에서도 잘 작동하는지 휴대폰에서 탐색을 검토하세요.
- 방문자가 무엇을 찾게 될지 이해할 수 있도록 페이지에 명확하고 설명적인 이름을 붙이세요.

:::tip
페이지에 [양식](../forms/creating-forms.md)을 추가하면 등록, 기도 요청, 기타 정보를 방문자에게서 받을 수 있습니다.
:::

## 사이트 템플릿에서 시작하기 {#starting-from-a-site-template}

사이트를 처음부터 만든다면, 페이지를 하나씩 만드는 대신 **Site Template**(사이트 템플릿)으로 시작할 수 있습니다. 사이트 템플릿은 자리 표시자 내용과 탐색 링크가 이미 연결된, 미리 만들어진 페이지 세트(홈, 교회 소개, 연결, 헌금 등)를 만듭니다.

1. 페이지 화면에서 **Start From a Template**(템플릿에서 시작) 버튼을 클릭하세요(**Add Page** 버튼 옆에 있습니다).
2. 사용 가능한 템플릿(**Classic**(클래식), **Modern**(모던), **Community**(커뮤니티), **Visitor Focused**(방문자 중심) 등)을 둘러보고, 하나를 클릭하여 그 페이지와 추가되는 탐색 링크를 미리 보세요.
3. 마음에 드는 템플릿을 찾으면 **Create Site**(사이트 만들기)를 클릭하세요.
4. 아직 없는 페이지는 만들어져 탐색에 추가됩니다. 이미 있는 페이지는 **Already exists**(이미 있음)로 표시되며 그대로 둡니다. 그다음 새로 만들어진 첫 페이지가 열려 살펴볼 수 있습니다.

템플릿을 적용한 후에는 각 페이지를 [페이지 편집기](./page-editor.md)에서 열어 자리 표시자 텍스트와 이미지를 교회의 실제 내용으로 바꾸세요.

:::info
템플릿은 색상 팔레트를 한 번도 저장하지 않은 사이트에서만 색상과 글꼴을 설정합니다. 직접 팔레트를 고른 후에는 템플릿을 적용해도 색상과 글꼴은 바뀌지 않으며, 계속 [모양](./appearance.md)에서 관리됩니다.
:::

## 여러 웹사이트 {#multiple-websites}

교회는 같은 계정에서 웹사이트를 둘 이상 운영할 수 있습니다. 예를 들어 캠퍼스마다 하나씩, 또는 학교를 위한 별도의 사이트를 둘 수 있습니다.

1. 페이지 화면에서 사이트 전환기를 여세요(처음에는 **Main Website**(기본 웹사이트)가 표시됩니다). 그리고 **Manage websites…**(웹사이트 관리…)를 선택하세요.
2. **Websites**(웹사이트) 대화 상자에서 **Name**(이름)과 **Subdomain**(하위 도메인)(소문자와 숫자만 사용. `{subdomain}.b1.church`가 됩니다)을 입력하고 **Add Website**(웹사이트 추가)를 클릭하세요.
3. 사이트 전환기에서 새 사이트를 선택하면 그 사이트의 페이지, 탐색, 블록, 모양을 만들 수 있습니다.

사이트를 제거하려면 **Manage websites**…를 열고 그 옆의 **Delete**(삭제)를 클릭하세요. 사이트의 페이지, 탐색, 모양은 영구적으로 삭제되며, 사이트가 가지고 있던 사용자 지정 도메인은 기본 웹사이트로 옮겨집니다.

## 이미지 라이트박스 {#image-lightbox}

방문자가 웹사이트의 이미지를 클릭하면 전체 화면 라이트박스 오버레이에서 열립니다. 페이지를 벗어나지 않고도 사진을 더 크게 볼 수 있습니다. 별도의 설정은 필요하지 않습니다. 페이지 내용의 이미지에는 라이트박스가 자동으로 켜집니다.
