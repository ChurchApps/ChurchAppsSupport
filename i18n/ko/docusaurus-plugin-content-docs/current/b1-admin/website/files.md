# 파일

<div class="article-intro">

파일 페이지는 교회 웹사이트에서 사용하는 모든 미디어와 문서를 모아 두는 중앙 저장소입니다. 여기에서 사이트에 필요한 모든 이미지, 문서, 미디어 파일을 업로드하고, 찾아보고, 관리할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 웹사이트의 [초기 설정](./initial-setup.md)을 마치세요
- 페이지 로딩 속도를 높이기 위해 업로드 전에 이미지를 최적화하세요
- 파일을 일반적인 웹 형식(PNG, JPG, PDF 등)으로 준비하세요

</div>

## 파일 업로드하기 {#uploading-files}

1. B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Website**(웹사이트)를 펼친 다음 **Files**(파일)를 클릭하세요.
2. 페이지 상단의 **Upload Files**(파일 업로드)를 클릭하거나, 오른쪽의 **Upload Files** 패널에서 **Choose File**(파일 선택)을 클릭한 다음 컴퓨터에서 파일을 고르세요.
3. 파일은 선택하는 즉시 업로드되며 파일 표에 나타납니다.

Upload Files 패널에는 사용 중인 저장 공간도 표시됩니다. 100MB는 무료로 제공됩니다. 가득 차면 파일을 삭제하거나 공간을 추가할 때까지 업로드 버튼이 숨겨집니다. 더 많은 공간을 얻으려면 **Settings**(설정)의 **File Storage**(파일 저장소) 섹션에서 자체 Google Drive, Dropbox, OneDrive, 또는 S3 버킷을 연결하세요. 그러면 파일은 연결된 계정에 저장되고, 패널에는 **Stored in your linked account**(연결된 계정에 저장됨)가 표시됩니다.

:::tip
가장 좋은 결과를 얻으려면 업로드 전에 이미지를 최적화하세요. 파일 크기가 작을수록 방문자에게 웹사이트가 빨리 로드됩니다. TinyPNG나 Squoosh 같은 도구는 눈에 띄는 화질 저하 없이 이미지를 압축할 수 있습니다.
:::

## 파일 찾아보기 {#browsing-files}

파일 표에는 업로드된 모든 파일이 **Name**(이름)과 **Size**(크기)와 함께 나열됩니다. 파일 이름을 클릭하면 새 탭에서 열립니다. 팀이 빠르게 찾을 수 있도록, 업로드하기 전에 파일에 명확하고 설명적인 이름을 붙이세요.

## 웹사이트에서 파일 사용하기 {#using-files-on-your-website}

1. 파일 표에서 파일을 찾으세요.
2. **Copy link**(링크 복사)를 클릭하여 파일의 URL을 복사하세요(버튼이 **Copied**(복사됨)로 바뀝니다). 이 URL은 이미지 요소, 다운로드 링크, 또는 파일 URL을 받는 어느 곳에든 붙여 넣을 수 있습니다.
3. 여기에서 업로드한 파일은 웹사이트의 모든 페이지와 콘텐츠 블록에서 사용할 수 있습니다.

:::info
[페이지 관리](./managing-pages.md)에서 페이지를 만들 때, 여기에 업로드한 파일을 URL로 참조할 수 있습니다. 이렇게 하면 모든 미디어를 한 중앙 위치에서 정리할 수 있습니다.
:::

## 파일 삭제하기 {#deleting-files}

1. 파일 표에서 제거하려는 파일을 찾으세요.
2. 파일 옆의 **Delete**(삭제)를 클릭하고 확인하면 라이브러리에서 영구적으로 제거됩니다.
3. 삭제하기 전에 어떤 페이지에서도 그 파일을 사용하고 있지 않은지 확인하세요. 사용 중이면 그 파일을 참조하는 링크나 이미지가 깨집니다.

:::warning
삭제된 파일은 복구할 수 없습니다. 제거하기 전에 어느 페이지에서도 그 파일을 사용하지 않는지 다시 확인하세요.
:::
