# 파일

<div class="article-intro">

파일 페이지는 교회 웹사이트에서 사용되는 모든 미디어 및 문서의 중앙 저장소입니다. 여기에서 사이트에 필요한 모든 이미지, 문서 및 미디어 파일을 업로드, 구성, 탐색 및 관리할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 웹사이트의 [초기 설정](initial-setup)을 완료하세요
- 빠른 페이지 로드 시간을 위해 업로드하기 전에 이미지를 최적화하세요
- 일반적인 웹 형식(PNG, JPG, PDF 등)으로 파일을 준비하세요

</div>

## 파일 업로드

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 위의 검색 표시줄)를 열고 **웹사이트**를 확장한 다음 **파일**을 클릭합니다.
2. 파일을 업로드 영역으로 직접 끌어다 놓거나 업로드 버튼을 클릭하여 컴퓨터를 찾아봅니다.
3. 파일이 업로드되고 파일 라이브러리에 즉시 나타납니다.

:::tip
최상의 결과를 위해 업로드하기 전에 이미지를 최적화합니다. 더 작은 파일 크기는 웹사이트가 방문자를 위해 더 빠르게 로드되도록 합니다. TinyPNG 또는 Squoosh와 같은 도구는 눈에 띄는 품질 손실 없이 이미지를 압축할 수 있습니다.
:::

## 폴더로 구성

1. 폴더를 만들어 관련 파일을 함께 그룹화합니다. 예를 들어 "설교 그래픽", "이벤트 배너" 또는 "직원 사진"입니다.
2. 라이브러리가 증가함에 따라 파일을 폴더 간에 이동하여 라이브러리를 정리 상태로 유지합니다.
3. 팀이 파일을 빠르게 찾을 수 있도록 명확하고 설명적인 폴더 이름을 사용합니다.

## 탐색 및 검색

- 파일 라이브러리를 스크롤하여 업로드된 모든 파일의 썸네일을 확인합니다.
- 라이브러리가 커지면 **검색** 기능을 사용하여 이름으로 파일을 찾습니다.
- 파일명, 크기 및 URL을 포함한 세부정보를 보려면 파일을 클릭합니다.

## 웹사이트에서 파일 사용

1. 파일을 클릭하여 세부정보를 확인합니다.
2. **파일 URL을 복사**하여 웹사이트 페이지에서 사용합니다. 이 URL을 이미지 요소, 다운로드 링크 또는 파일 URL을 허용하는 다른 곳에 붙여넣을 수 있습니다.
3. 여기에 업로드한 파일은 모든 웹사이트 페이지 및 콘텐츠 블록에서 사용할 수 있습니다.

:::info
[페이지 관리](managing-pages)에서 페이지를 빌드할 때 URL로 여기에 업로드된 모든 파일을 참조할 수 있습니다. 이는 모든 미디어를 한 중앙 위치에 구성된 상태로 유지합니다.
:::

## 파일 삭제

1. 제거할 파일을 선택합니다.
2. **삭제** 버튼을 클릭하여 라이브러리에서 영구적으로 제거합니다.
3. 파일을 삭제하기 전에 파일이 현재 어떤 페이지에서도 사용되지 않고 있는지 확인합니다. 이것은 이를 참조하는 모든 링크 또는 이미지를 깨뜨릴 것이기 때문입니다.

:::warning
삭제된 파일은 복구할 수 없습니다. 제거하기 전에 파일이 더 이상 어떤 페이지에서도 사용되지 않는지 다시 한 번 확인합니다.
:::
