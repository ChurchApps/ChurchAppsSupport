# 파일

<div class="article-intro">

파일 페이지는 교회 웹사이트에서 사용되는 모든 미디어 및 문서의 중앙 저장소입니다. 여기에서 사이트에 필요한 모든 이미지, 문서 및 미디어 파일을 업로드, 탐색 및 관리할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 웹사이트의 [초기 설정](initial-setup)을 완료하세요
- 빠른 페이지 로드 시간을 위해 업로드하기 전에 이미지를 최적화하세요
- 일반적인 웹 형식(PNG, JPG, PDF 등)으로 파일을 준비하세요

</div>

## 파일 업로드

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 위의 검색 표시줄)를 열고 **웹사이트**를 확장한 다음 **파일**을 클릭합니다.
2. 오른쪽의 **파일 업로드** 패널에서 **파일 선택**을 클릭하고 컴퓨터에서 파일을 선택합니다. (페이지 상단의 **파일 업로드** 버튼을 누르면 같은 패널로 이동합니다.)
3. 파일이 업로드되어 파일 테이블에 나타납니다.

파일 업로드 패널에는 사용 중인 저장 공간도 표시됩니다. 100MB가 무료로 제공되며, 더 많은 공간이 필요하면 **설정**의 **파일 저장소** 섹션에서 직접 소유한 Google Drive, Dropbox, OneDrive 또는 S3 버킷을 연결하세요.

:::tip
최상의 결과를 위해 업로드하기 전에 이미지를 최적화합니다. 더 작은 파일 크기는 웹사이트가 방문자를 위해 더 빠르게 로드되도록 합니다. TinyPNG 또는 Squoosh와 같은 도구는 눈에 띄는 품질 손실 없이 이미지를 압축할 수 있습니다.
:::

## 파일 탐색 {#browsing-files}

파일 테이블에는 업로드된 모든 파일이 **이름**과 **크기**와 함께 나열됩니다. 파일 이름을 클릭하면 새 탭에서 열립니다. 팀이 파일을 쉽게 찾을 수 있도록 업로드하기 전에 명확하고 설명적인 이름을 지정하세요.

## 웹사이트에서 파일 사용

1. 파일 테이블에서 파일을 찾습니다.
2. **링크 복사**를 클릭하여 파일 URL을 복사합니다. 이 URL을 이미지 요소, 다운로드 링크 또는 파일 URL을 허용하는 다른 곳에 붙여넣을 수 있습니다. 이 URL을 이미지 요소, 다운로드 링크 또는 파일 URL을 허용하는 다른 곳에 붙여넣을 수 있습니다.
3. 여기에 업로드한 파일은 모든 웹사이트 페이지 및 콘텐츠 블록에서 사용할 수 있습니다.

:::info
[페이지 관리](managing-pages)에서 페이지를 빌드할 때 URL로 여기에 업로드된 모든 파일을 참조할 수 있습니다. 이는 모든 미디어를 한 중앙 위치에 구성된 상태로 유지합니다.
:::

## 파일 삭제

1. 파일 테이블에서 제거할 파일을 찾습니다.
2. 파일 옆의 **삭제**를 클릭하고 확인하여 라이브러리에서 영구적으로 제거합니다.
3. 파일을 삭제하기 전에 파일이 현재 어떤 페이지에서도 사용되지 않고 있는지 확인합니다. 이것은 이를 참조하는 모든 링크 또는 이미지를 깨뜨릴 것이기 때문입니다.

:::warning
삭제된 파일은 복구할 수 없습니다. 제거하기 전에 파일이 더 이상 어떤 페이지에서도 사용되지 않는지 다시 한 번 확인합니다.
:::
