# 블로그

<div class="article-intro">

블로그 페이지를 사용하면 교회 웹사이트에 뉴스, 업데이트, 영적 명상을 게시할 수 있습니다. 게시물은 `/blog`의 카드 목록, 자체 URL 및 Zapier와 같은 다른 도구가 새 게시물을 감시할 수 있는 RSS 피드에 나타납니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 웹사이트의 [초기 설정](initial-setup)을 완료하세요
- 방문자가 메뉴에서 블로그를 찾을 수 있도록 하려면 [페이지 관리](managing-pages)에서 `/blog`로의 네비게이션 링크를 추가하세요

</div>

## 블로그 액세스

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 위의 검색 표시줄)를 열고 **웹사이트**를 확장합니다.
2. **블로그**를 클릭합니다.
3. 블로그 페이지에는 모든 게시물과 그 상태 및 게시 날짜가 나열됩니다.

## 게시물 추가

1. 오른쪽 위 모서리에서 **게시물 추가**를 클릭합니다.
2. **제목**을 입력합니다. URL 친화적인 슬러그는 입력하는 동안 자동으로 생성되므로 다른 주소를 원하면 직접 편집할 수 있습니다.
3. **발췌**를 추가합니다. 게시물 목록, 메타 설명, RSS 피드에 표시된 짧은 요약입니다. 비워두면 게시물 콘텐츠의 시작 부분에서 자동으로 생성됩니다.
4. **콘텐츠** 편집기에서 Markdown을 사용하여 게시물 본문을 작성합니다. **미리보기**를 클릭하여 형식이 지정된 게시물이 어떻게 보일지 확인합니다.
5. **카테고리**(기존 항목을 선택하거나 새로운 항목 입력)와 선택적 쉼표로 구분된 **태그**를 선택합니다.
6. **이미지 선택**을 클릭하여 [파일](files) 갤러리에서 사진을 선택하거나 새로운 사진을 업로드합니다. 업로드된 사진은 16:9 비율로 고정된 기본 제공 자르기 도구에서 열려 모든 사진을 게시물 헤더 및 목록 카드에 맞게 조정할 수 있습니다.
7. **저자**를 설정합니다. 기본값은 본인이지만 데이터베이스에서 누구든 검색하고 선택할 수 있습니다.
8. **게시됨**을 켜고 게시물을 공개할 준비가 되면 **게시 날짜**를 설정합니다. 게시물을 초안으로 저장하려면 꺼둡니다.

:::tip
향후 **게시 날짜**를 설정하여 게시물을 예약합니다. 방문자에게서 숨겨져 있으며 해당 날짜가 도래할 때까지 블로그 목록에 **예약됨** 칩을 표시합니다.
:::

## 게시물 상태

목록의 각 게시물은 세 가지 상태 중 하나를 표시합니다:

- **초안** - 게시되지 않음. 관리자에게만 표시됩니다.
- **예약됨** - 게시됨이 켜져 있지만 게시 날짜는 미래입니다.
- **게시됨** - 웹사이트에 실시간으로 게재되며 RSS 피드에 포함됩니다.

## 게시물 편집, 미리보기 및 삭제

- 게시물 옆의 **편집** 아이콘을 클릭하여 변경사항을 적용합니다.
- **보기** 아이콘(게시된 게시물에 표시됨)을 클릭하여 웹사이트의 실시간 게시물을 새 탭에서 엽니다.
- **삭제** 아이콘을 클릭하여 게시물을 영구적으로 제거합니다.

## 방문자가 블로그를 보는 방법

게시된 게시물은 `{yoursite}/blog`에 나타나며 페이지당 10개이고 아카이브를 통해 페이징하기 위한 **이전**/**다음** 링크가 있으며 카테고리 필터와 각 게시물의 저자 정보 및 사진이 있습니다. 태그는 클릭 가능한 칩으로도 렌더링되므로 방문자가 동일한 방식으로 태그별로 목록을 필터링할 수 있습니다. 개별 게시물은 `{yoursite}/blog/{slug}`에 있으며 동일한 카테고리의 관련 게시물이 포함됩니다. 블로그 페이지는 또한 RSS 피드를 게시하며 이는 피드 리더 및 Zapier와 같은 자동화 도구에서 자동으로 검색됩니다.

:::info
블로그 게시물은 일반 웹사이트 페이지와 별개의 콘텐츠 유형입니다. [페이지 편집기](page-editor)에서 빌드되지 않으며 페이지 목록에 나타나지 않습니다. 이는 블로그 작성을 빠르고 작성에 집중하게 유지합니다.
:::
