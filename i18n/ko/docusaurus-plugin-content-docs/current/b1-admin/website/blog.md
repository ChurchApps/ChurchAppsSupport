# 블로그

<div class="article-intro">

블로그 페이지에서는 교회 웹사이트에 소식, 업데이트, 묵상 글을 게시할 수 있습니다. 글은 `/blog`의 카드 목록, 각 글의 고유 주소, 그리고 Zapier 같은 다른 도구가 새 글을 감시할 수 있는 RSS 피드에 나타납니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 웹사이트의 [초기 설정](./initial-setup.md)을 완료하세요.
- 방문자가 메뉴에서 블로그를 찾을 수 있도록 하려면 [페이지 관리](./managing-pages.md)에서 `/blog`로 가는 내비게이션 링크를 추가하세요.

</div>

## 블로그 열기

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **웹사이트**를 펼칩니다.
2. **블로그**를 클릭합니다.
3. 블로그 페이지에는 모든 글이 상태 및 게시일과 함께 나열됩니다.

## 글 추가하기

1. 오른쪽 위의 **글 추가**를 클릭합니다.
2. **제목**을 입력합니다. URL에 쓸 수 있는 **웹 주소**(슬러그)가 입력하는 동안 자동으로 만들어집니다. 다른 주소를 원하면 직접 편집하세요.
3. **요약문**을 추가합니다. 글 목록, 메타 설명, RSS 피드에 보이는 짧은 요약입니다. 비워 두면 글 내용의 앞부분에서 자동으로 만들어집니다.
4. **내용** 편집기에서 마크다운으로 글 본문을 씁니다. **미리 보기**를 클릭하면 서식이 적용된 글이 어떻게 보일지 확인할 수 있습니다.
5. **분류**를 고릅니다(기존 분류를 고르거나 새 분류를 입력). 선택 사항으로 쉼표로 구분한 **태그**를 입력합니다.
6. **이미지 선택**을 클릭해 [파일](./files.md) 갤러리에서 사진을 고르거나 새 사진을 업로드합니다. 업로드한 사진은 16:9 비율에 고정된 내장 자르기 도구에서 열리므로, 글 머리글과 목록 카드에 맞게 어떤 사진이든 구도를 잡을 수 있습니다.
7. **작성자**를 설정합니다. 기본값은 나이지만, 데이터베이스의 누구든지 검색해서 고를 수 있습니다.
8. 글을 공개할 준비가 되면 **게시됨**을 켜고 **게시일**을 설정합니다. 임시 저장하려면 끕니다.

:::tip
**게시일**을 미래로 설정하면 글을 예약할 수 있습니다. 그 날짜가 올 때까지 방문자에게는 숨겨지고, 블로그 목록에는 **예약됨** 칩이 표시됩니다.
:::

## 글 상태

목록의 각 글은 세 가지 상태 중 하나를 보여 줍니다:

- **초안** -- 게시되지 않았습니다. 관리자에게만 보입니다.
- **예약됨** -- 게시됨이 켜져 있지만 게시일이 미래입니다.
- **게시됨** -- 웹사이트에 공개되어 있고 RSS 피드에 포함됩니다.

## 글 편집, 미리 보기, 삭제하기

- 글 옆의 **편집**을 클릭해 수정합니다.
- 게시된 글에 나타나는 **사이트에서 보기**를 클릭하면 웹사이트의 실제 글이 새 탭에서 열립니다.
- **삭제**를 클릭하면 글이 영구적으로 제거됩니다.

## 방문자가 블로그를 보는 방식

게시된 글은 `{yoursite}/blog`에 한 페이지에 10개씩 나타나며, **이전**/**다음** 링크로 보관된 글을 넘겨 볼 수 있습니다. 분류 필터와 각 글의 작성자 정보 및 사진도 함께 보입니다. 태그도 클릭할 수 있는 칩으로 나타나, 방문자가 같은 방식으로 태그별 목록을 걸러 볼 수 있습니다. 각 글은 `{yoursite}/blog/{slug}`에 있으며, 같은 분류의 관련 글을 함께 보여 줍니다. 블로그 페이지는 RSS 피드도 제공하므로, 피드 리더나 Zapier 같은 자동화 도구가 자동으로 찾을 수 있습니다.

켜 두었다면 게시된 글은 교회 앱의 홈 화면 **소식** 섹션에도 나타날 수 있습니다. [홈 화면 섹션](../settings/mobile-app.md#home-screen-sections)을 참고하세요.

:::info
블로그 글은 일반 웹사이트 페이지와 다른 콘텐츠 유형입니다. [페이지 편집기](./page-editor.md)로 만들지 않으며 페이지 목록에도 나타나지 않습니다. 이렇게 해서 블로그 작성은 빠르게 글쓰기에만 집중할 수 있습니다.
:::

## 글 아래에 댓글 추가하기

B1은 블로그 댓글을 직접 호스팅하지 않지만, 댓글 서비스를 추가할 수 있습니다. 모든 글 아래에 뉴스레터 신청이나 헌금 버튼처럼 다른 것을 넣을 수도 있습니다.

1. [Hyvor Talk](https://talk.hyvor.com), [FastComments](https://fastcomments.com), [Disqus](https://disqus.com) 같은 댓글 서비스에 가입하고 임베드 코드를 복사합니다.
2. 블로그 페이지에서 **모든 글 아래**까지 스크롤합니다.
3. 임베드 코드를 붙여 넣고 **저장**을 클릭합니다.

이 코드는 게시된 모든 글의 내용 아래에 나타납니다. 댓글 서비스가 검토와 스팸 필터링을 담당하므로, 대시보드를 정기적으로 확인하세요.

:::tip
상자를 비우고 **저장**을 클릭하면 모든 글에서 코드가 제거됩니다. 교회 설정을 편집할 수 있는 사람만 이 상자를 볼 수 있습니다.
:::
