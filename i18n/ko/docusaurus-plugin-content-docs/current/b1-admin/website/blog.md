# 블로그

<div class="article-intro">

블로그 페이지를 사용하면 뉴스, 업데이트, 묵상글을 교회 웹사이트에 게시할 수 있습니다. 게시물은 `/blog`의 카드 목록, 자체 URL, 그리고 Zapier 같은 다른 도구가 새 게시물을 감시할 수 있는 RSS 피드에 표시됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 웹사이트의 [초기 설정](initial-setup)을 완료하세요
- 방문자가 메뉴에서 블로그를 찾을 수 있도록 하려면 [페이지 관리](managing-pages)에서 `/blog`로의 내비게이션 링크를 추가하세요

</div>

## 블로그 접근하기

1. B1 Admin에서 왼쪽 메뉴의 **웹사이트**를 클릭하세요.
2. 웹사이트 페이지 보기 상단의 **블로그** 탭을 클릭하세요.
3. 블로그 페이지에는 상태와 게시일과 함께 모든 게시물이 나열됩니다.

## 게시물 추가하기

1. 오른쪽 상단의 **게시물 추가**를 클릭하세요.
2. **제목**을 입력하세요. 입력하는 동안 URL 친화적인 슬러그가 자동으로 생성됩니다 -- 다른 주소를 원한다면 직접 편집할 수 있습니다.
3. **요약**을 추가하세요 -- 게시물 목록, 메타 설명, RSS 피드에 표시되는 짧은 요약입니다. 비워 두면 게시물 내용의 시작 부분에서 자동으로 생성됩니다.
4. **콘텐츠** 편집기에서 마크다운을 사용하여 게시물 본문을 작성하세요. **미리보기**를 클릭하면 서식이 적용된 게시물이 어떻게 보일지 확인할 수 있습니다.
5. **카테고리**를 선택하고(기존 항목을 선택하거나 새로 입력) 선택적으로 쉼표로 구분된 **태그**를 입력하세요.
6. **이미지 선택**을 클릭하여 [파일](files) 갤러리에서 사진을 선택하거나 새로 업로드하세요. 업로드된 사진은 16:9 비율로 고정된 내장 자르기 도구에서 열리므로, 게시물 헤더와 목록 카드에 맞게 어떤 사진이든 프레이밍할 수 있습니다.
7. **작성자**를 설정하세요 -- 기본값은 본인이지만, 데이터베이스의 다른 사람을 검색하여 선택할 수도 있습니다.
8. 게시물을 공개할 준비가 되면 **게시됨**을 켜고 **게시일**을 설정하세요. 초안으로 저장하려면 꺼진 상태로 두세요.

:::tip
**게시일**을 미래로 설정하면 게시물을 예약할 수 있습니다. 해당 날짜가 될 때까지 방문자에게는 숨겨져 있으며 블로그 목록에는 **예약됨** 칩이 표시됩니다.
:::

## 게시물 상태

목록의 각 게시물은 다음 세 가지 상태 중 하나로 표시됩니다:

- **초안** -- 게시되지 않음. 관리자에게만 표시됩니다.
- **예약됨** -- 게시됨이 켜져 있지만 게시일이 미래입니다.
- **게시됨** -- 웹사이트에 공개되어 있으며 RSS 피드에 포함됩니다.

## 게시물 편집, 미리보기, 삭제

- 게시물 옆의 **편집** 아이콘을 클릭하여 변경하세요.
- **보기** 아이콘(게시된 게시물에서 표시)을 클릭하면 새 탭에서 웹사이트의 실제 게시물이 열립니다.
- **삭제** 아이콘을 클릭하면 게시물을 영구적으로 제거합니다.

## 방문자에게 블로그가 보이는 방식

게시된 게시물은 `{yoursite}/blog`에 페이지당 10개씩 표시되며, 아카이브를 넘겨볼 수 있는 **이전**/**다음** 링크, 카테고리 필터, 각 게시물의 작성자 정보와 사진이 함께 제공됩니다. 태그도 클릭 가능한 칩으로 렌더링되어 방문자가 같은 방식으로 태그별로 목록을 필터링할 수 있습니다. 개별 게시물은 `{yoursite}/blog/{slug}`에 위치하며 동일한 카테고리의 관련 게시물을 포함합니다. 블로그 페이지는 피드 리더와 Zapier 같은 자동화 도구가 자동으로 발견할 수 있는 RSS 피드도 게시합니다.

:::info
블로그 게시물은 일반 웹사이트 페이지와는 별개의 콘텐츠 유형입니다 -- [페이지 편집기](page-editor)에서 만들어지지 않으며 페이지 목록에 나타나지 않습니다. 이는 블로그 작성을 빠르고 글쓰기에 집중할 수 있게 해줍니다.
:::
