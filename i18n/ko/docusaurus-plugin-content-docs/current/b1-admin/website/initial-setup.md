# 초기 설정

<div class="article-intro">

모든 B1 계정에는 준비된 웹사이트가 함께 제공됩니다. 이 가이드는 교회 도메인 설정, 사이트의 모양 구성, 첫 페이지 생성, 네비게이션 구성 단계를 안내합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1.church 계정 및 관리자 액세스 필요
- 사용자 정의 도메인을 사용하는 경우 DNS 공급자 로그인 자격 증명을 준비하세요 (예: GoDaddy, Cloudflare 또는 AWS)
- 최상의 결과를 위해 투명한 배경이 있는 PNG 형식의 교회 로고를 준비하세요

</div>

## 도메인 설정

교회는 자동으로 B1.church에서 서브도메인을 받습니다 (예: `yourchurch.b1.church`). 또한 자신의 사용자 정의 도메인을 B1 사이트로 가리킬 수 있습니다.

1. admin.b1.church를 방문하거나 프로필 드롭다운을 클릭하고 **앱 전환**을 선택하여 **B1.church Admin**으로 이동하세요.
2. 왼쪽 상단의 **섹션 메뉴** (작은 화살표가 있는 섹션 이름)를 열고 **설정**을 선택하세요.
3. **교회 정보** 섹션을 열어 서브도메인을 확인합니다. 공백이 없는 짧고 인식할 수 있는 것으로 설정하세요.
4. 사용자 정의 도메인을 사용하려면 DNS 공급자 (예: GoDaddy, Cloudflare 또는 AWS)에 로그인하고 두 개의 레코드를 추가하세요:
   - `3.23.251.61`을 가리키는 루트 도메인의 **A 레코드**
   - `proxy.b1.church`를 가리키는 `www`의 **CNAME 레코드**
5. B1.church Admin으로 돌아가서 사용자 정의 도메인을 목록에 추가하고 **추가** 후 **저장**을 클릭하세요. 사이트는 사용자 정의 도메인에서 몇 분 내에 액세스할 수 있습니다.

:::tip
설정 옵션이 표시되지 않으면 교회 계정을 설정한 사람에게 "교회 설정 편집" 권한을 부여하도록 요청하세요. 자세한 내용은 [역할 및 권한](../settings/roles-permissions.md)을 참조하세요.
:::

## 첫 페이지 만들기

1. B1 Admin에서 왼쪽 메뉴의 **웹사이트**를 클릭하여 웹사이트 페이지 보기를 엽니다.
2. 오른쪽 상단의 **페이지 추가**를 클릭하세요.
3. 페이지 유형으로 **빈 페이지**를 선택하고 "홈"으로 이름을 지정하세요.
4. **페이지 설정**을 클릭하고 URL 경로를 `/` (텍스트 없는 슬래시)로 홈 페이지로 설정합니다. 다른 페이지는 `/page-name`을 사용합니다.
5. **콘텐츠 편집**을 클릭하여 구축을 시작합니다. 모든 페이지는 **섹션**으로 시작해야 합니다 -- 이것은 다른 모든 요소의 컨테이너입니다.
6. 섹션을 추가한 후 **콘텐츠 추가**를 다시 클릭하여 텍스트, 이미지, 비디오, 카드, 양식 등을 섹션으로 드래그하여 삽입합니다.

:::info
페이지 및 네비게이션 작업에 대한 자세한 지침은 [페이지 관리](managing-pages)를 참조하세요. 시각 편집기에 대한 전체 가이드는 [페이지 편집기 사용](page-editor)을 참조하세요.
:::

## 사이트 모양 구성

1. 웹사이트 페이지 보기에서 상단의 **모양** 탭을 클릭하세요.
2. **색상 팔레트**를 사용하여 기본, 보조 및 악센트 톤에 대한 브랜드 색상을 설정합니다.
3. **타이포그래피 설정** 아래에서 글꼴 브라우저에서 제목 및 본문 글꼴을 선택합니다.
4. 스타일 설정의 **로고** 아래에 교회 로고를 업로드합니다. 밝은 배경 및 어두운 배경 버전을 모두 제공하세요.
5. **사이트 바닥글**을 교회의 연락처 정보 및 링크로 구성하세요.

:::info
모양에서 변경한 사항은 전체 웹사이트에 적용됩니다. 각 설정에 대한 자세한 지침은 [모양](appearance) 페이지를 참조하세요.
:::

## 네비게이션 설정

네비게이션 링크는 웹사이트 페이지 보기에 나타납니다. 이를 구성하려면:

1. **추가**를 클릭하여 새 네비게이션 링크를 만들고 페이지 중 하나를 가리킵니다.
2. 링크를 드래그 앤 드롭하여 순서를 변경하거나 상위 항목 아래에 중첩합니다.
3. 사이트를 미리 보기하여 네비게이션이 올바르게 보이는지 확인합니다.
