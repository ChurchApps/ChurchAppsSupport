# 재사용 블록

<div class="article-intro">

블록은 한 번 만들어 원하는 만큼 여러 페이지에서 재사용할 수 있는 웹사이트 콘텐츠 조각입니다. 행동 유도 배너, 연락처 띠, 예배 시간 패널 등이 해당됩니다. 블록을 편집하면, 그 블록을 사용하는 모든 페이지에 변경 사항이 반영됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 웹사이트 콘텐츠를 편집할 권한이 필요합니다
- 컴퓨터나 태블릿을 사용하세요. 블록 편집기는 페이지에 쓰는 것과 같은 전체 화면 편집기입니다

</div>

## 블록 열기 {#opening-blocks}

1. B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Website**(웹사이트)를 펼치세요.
2. **Blocks**(블록)를 클릭하세요. **Reusable Blocks**(재사용 블록) 페이지에는 각 블록의 **Name**(이름)과 **Type**(유형)이 나열됩니다.

교회에 웹사이트가 둘 이상 있다면, 페이지 상단의 사이트 전환기를 사용하여 사이트별 블록을 확인하세요. 사이트 바닥글도 블록이지만, 여기 나열되지 않고 [모양](./appearance.md)의 **Site Footer**(사이트 바닥글)에서 편집합니다.

## 블록 추가하기 {#adding-a-block}

1. **Add Block**(블록 추가)을 클릭하세요.
2. 팀이 알아볼 수 있는 **Name**(이름)을 입력하세요.
3. **Block Type**(블록 유형)을 선택하세요.
   - **Element(s)**(요소) -- 페이지의 섹션 안에 넣는 하나 이상의 요소(텍스트, 이미지, 버튼 등)입니다.
   - **Section(s)**(섹션) -- 페이지의 다른 섹션 사이에 넣는 하나 이상의 전체 섹션입니다.
4. **Save**를 클릭하세요. 블록이 목록에 나타납니다.

## 블록 내용 만들기 {#building-a-blocks-content}

1. 블록의 이름을 클릭하거나, 해당 행의 **Edit**(편집)를 클릭하세요. 블록이 [페이지 편집기](./page-editor.md)에서 열립니다.
2. 섹션부터 시작하여 페이지에서 하는 것과 같은 방식으로 콘텐츠를 추가하고 꾸미세요.
3. 변경 사항은 자동으로 저장됩니다. 도구 모음의 **Exit**(나가기)을 클릭하면 블록 목록으로 돌아갑니다.

## 페이지에서 블록 사용하기 {#using-a-block-on-a-page}

1. [페이지 편집기](./page-editor.md)에서 페이지를 열고 **Add Content**(콘텐츠 추가)를 클릭하세요.
2. **Add Elements**(요소 추가) 패널에서 **Blocks**(블록) 탭을 선택하세요. (이 탭은 블록이 하나 이상 있을 때만 나타납니다.)
3. 블록을 페이지로 드래그하세요. 요소 블록은 섹션 안에, 섹션 블록은 섹션 사이에 놓입니다.

페이지에는 블록의 현재 내용이 표시됩니다. 내용을 바꾸려면 **Blocks** 페이지에서 블록 자체를 편집하세요. 그 블록을 사용하는 모든 페이지가 업데이트됩니다.

## 블록 이름 바꾸기 또는 삭제하기 {#renaming-or-deleting-a-block}

1. 블록의 행에서 **Rename**(이름 바꾸기)을 클릭하세요.
2. **Name**(이름) 또는 **Block Type**(블록 유형)을 변경하고 **Save**를 클릭하거나, **Delete**(삭제)를 클릭한 다음 확인하여 블록을 영구적으로 제거하세요.

:::warning
삭제된 블록을 사용하던 페이지에는 더 이상 그 내용이 표시되지 않습니다. 사용 중인 블록을 삭제하기 전에 페이지를 확인하세요.
:::
