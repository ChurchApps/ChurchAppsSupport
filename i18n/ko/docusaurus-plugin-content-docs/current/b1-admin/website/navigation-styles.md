# 탐색 스타일

<div class="article-intro">

교회 웹사이트의 탐색 모음 색상을 브랜드에 맞게 맞춤 설정하세요. 고정 배경과 투명 오버레이 모두에 대해 색상을 설정할 수 있으므로, 페이지마다 탐색이 어떻게 보일지 완전히 제어할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 웹사이트 콘텐츠를 편집할 권한이 필요합니다. 자세한 내용은 [역할 및 권한](../settings/roles-permissions.md)을 참고하세요.
- 16진수 색상 코드(예: #03A9F4)를 포함한 브랜드 색상을 준비하세요.
- 웹사이트의 고정 탐색과 투명 탐색 스타일의 차이를 이해하세요.

</div>

## 탐색 모드 이해하기 {#understanding-navigation-modes}

웹사이트 탐색은 페이지에 따라 두 가지 다른 스타일로 나타날 수 있습니다.

- **고정 탐색** -- 배경 색이 있는 탐색 모음으로, 보통 내용 페이지에 사용합니다
- **투명 탐색** -- 페이지 내용 위에 겹쳐지는 탐색으로, 보통 히어로 이미지나 전체 화면 배경이 있는 페이지에 사용합니다

두 모드의 색상은 각각 독립적으로 맞춤 설정할 수 있습니다.

## 탐색 스타일 접근하기 {#accessing-navigation-styles}

1. B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Website**(웹사이트)를 펼치세요.
2. **Appearance**(모양)를 클릭하세요.
3. **Style Settings**(스타일 설정) 목록에서 **Navigation**(탐색)을 클릭하세요.

**Navigation Styling**(탐색 스타일) 편집기에는 두 개의 카드가 있습니다. **Header (solid)**(머리글(고정))과 **Header over hero (transparent)**(히어로 위 머리글(투명))입니다.

## 고정 탐색 설정하기 {#configuring-solid-navigation}

고정 탐색은 탐색 모음 뒤에 배경 색이 있는 형태로 나타납니다. 이 설정은 **Header (solid)** 카드에 있습니다. 각 색상은 선택 사항입니다. **Override**(재정의) 스위치가 꺼져 있는 동안에는 탐색이 사이트의 기본 색상을 그대로 사용합니다. 다음을 맞춤 설정할 수 있습니다.

### 배경 색 {#background-color}

1. **Background color**(배경 색)의 **Override** 스위치를 켜세요.
2. 색상 선택기를 클릭하세요.
3. 원하는 배경 색을 고르세요(선택기는 흰색 #FFFFFF에서 시작합니다).

### 링크 색 {#link-color}

1. **Link color**(링크 색)의 **Override** 스위치를 켜세요.
2. 탐색 링크 텍스트의 색을 고르세요.
3. 기본 상태의 링크에 적용됩니다(선택기는 어두운 회색 #555555에서 시작합니다).

### 링크 마우스 오버 색 {#link-hover-color}

1. **Link hover color**(링크 마우스 오버 색)의 **Override** 스위치를 켜세요.
2. 사용자가 링크 위에 마우스를 올렸을 때 링크가 바뀔 색을 고르세요.
3. 클릭할 수 있는 링크에 시각적 피드백을 제공합니다(선택기는 연한 파란색 #03A9F4에서 시작합니다).

### 활성 색 {#active-color}

1. **Active link color**(활성 링크 색)의 **Override** 스위치를 켜세요.
2. 현재 활성 페이지 링크의 색을 고르세요.
3. 사용자가 자신이 어느 페이지에 있는지 알 수 있게 도와줍니다(선택기는 연한 파란색 #03A9F4에서 시작합니다).

## 투명 탐색 설정하기 {#configuring-transparent-navigation}

투명 탐색은 배경 없이 페이지 내용 위에 겹쳐집니다. 이 설정은 **Header over hero (transparent)** 카드에 있습니다. **Override** 스위치가 꺼져 있는 동안에는 해당 색이 히어로 섹션의 텍스트 색과 자동으로 맞춰집니다. 다음을 맞춤 설정할 수 있습니다.

### 링크 색 {#link-color-1}

1. **Link color**의 **Override** 스위치를 켜세요.
2. 페이지 배경과 대비가 잘 되는 색을 고르세요.
3. 어두운 배경 위에서는 흰색이나 밝은 색이 보통 가장 잘 보입니다.

### 링크 마우스 오버 색 {#link-hover-color-1}

1. **Link hover color**의 **Override** 스위치를 켜세요.
2. 마우스 오버 상태의 색을 고르세요.
3. 페이지 배경 위에서 잘 보이는지 확인하세요.

### 활성 색 {#active-color-1}

1. **Active link color**의 **Override** 스위치를 켜세요.
2. 활성 페이지 표시 색을 고르세요.
3. 눈에 띄면서도 디자인에 어울려야 합니다.

:::info
투명 탐색은 페이지 내용 위에 직접 겹쳐지므로 배경 색 설정이 없습니다.
:::

## 변경 사항 저장하기 {#saving-your-changes}

1. 색상을 설정한 후 **Save Navigation**(탐색 저장)을 클릭하세요.
2. 변경 사항은 실제 웹사이트에 즉시 적용됩니다.
3. 웹사이트를 방문하여 두 모드의 탐색을 모두 확인하세요.

## 기본값으로 되돌리기 {#resetting-to-defaults}

기본 색상으로 돌아가고 싶다면:

1. 사용자 지정 색상의 **Override** 스위치를 모두 끄세요.
2. **Save Navigation**을 클릭하세요.
3. 탐색은 사이트의 기본 색상으로 돌아갑니다(히어로 위에서는 히어로의 텍스트 색으로 돌아갑니다).

또는 **Cancel**(취소)을 클릭하면 저장하지 않고 모든 변경을 버립니다.

## 권장 사항 {#best-practices}

### 색 대비 {#color-contrast}

- **가독성** -- 링크 색이 배경과 충분히 대비되는지 확인하세요
- **WCAG 준수** -- 접근성을 위해 최소 4.5:1의 대비율을 목표로 하세요
- **두 모드 모두 테스트** -- 고정 탐색과 투명 탐색 모두로 사이트를 미리 보세요

### 브랜드 일관성 {#brand-consistency}

- **브랜드 색 사용** -- 로고와 웹사이트 테마에 맞추세요
- **색 수 제한** -- 응집력 있는 모습을 위해 2~3가지 색만 사용하세요
- **이미지 고려** -- 투명 탐색을 사용한다면, 일반적인 페이지 배경에서 테스트하세요

### 마우스 오버 및 활성 상태 {#hover-and-active-states}

- **명확한 피드백** -- 마우스 오버 상태가 기본 링크와 확실히 달라 보이게 하세요
- **활성 페이지 구분** -- 사용자가 자신의 위치를 알 수 있도록 뚜렷한 색을 사용하세요
- **부드러운 전환** -- 시스템이 색 변화를 자동으로 애니메이션 처리합니다

## 문제 해결 {#troubleshooting}

### 색이 올바르게 보이지 않을 때 {#colors-dont-look-right}

- **캐시 지우기** -- 브라우저 캐시 때문에 이전 색이 보일 수 있습니다
- **16진수 코드 확인** -- 올바른 16진수 색상 코드를 입력했는지 확인하세요
- **다른 배경에서 테스트** -- 페이지에 따라 색이 다르게 보일 수 있습니다

### 탐색이 보이지 않을 때 {#navigation-not-visible}

- **투명 모드** -- 밝은 이미지 위에 투명 탐색을 사용하면 어두운 텍스트는 잘 보이지 않을 수 있습니다
- **해결 방법** -- 링크 색을 조정하거나 더 어두운 페이지 배경을 사용하세요
- **대안** -- 탐색 영역에 은은한 그림자나 배경 오버레이를 추가하세요

## 기술 세부 정보 {#technical-details}

탐색 스타일은 JSON으로 저장되며 CSS 변수를 사용하여 적용됩니다.

- 변경 사항은 사이트를 다시 빌드하지 않고도 즉시 적용됩니다
- 색상은 모든 탐색 요소에 전파됩니다
- 재정의는 선택 사항이며, 설정하지 않은 색은 테마 기본값을 사용합니다
