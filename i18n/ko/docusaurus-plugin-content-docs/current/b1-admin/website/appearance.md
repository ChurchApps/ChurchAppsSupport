# 외관
<div class="article-intro">
외관 페이지는 교회 웹사이트의 전체 모양과 느낌을 커스터마이즈합니다. 색상과 글꼴부터 간격과 커스텀 CSS까지, 한 곳에서 모든 시각적 측면을 제어할 수 있습니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- [초기 설정](initial-setup)을 완료합니다
- 교회 로고가 준비되어 있어야 합니다 (PNG 형식, 투명 배경)
- 교회의 브랜드 색상(16진수 값)을 알고 있어야 합니다
</div>
## 외관 설정 접근
1. B1 Admin에서 **웹사이트**를 클릭합니다
2. **외관** 탭을 클릭합니다
3. 왼쪽에는 웹사이트의 라이브 미리보기가, 오른쪽에는 **스타일 설정** 옵션이 로드됩니다
## 색상 팔레트
1. 스타일 설정 패널에서 **색상 팔레트**를 클릭합니다
2. **기본 색상** (밝음, 강조, 어두움)과 **의미론적 색상** (기본, 보조, 성공, 경고, 오류)을 봅니다
3. 색상 견본을 클릭하여 색상 선택기를 엽니다
4. **색상 조합 미리보기**는 선택한 색상들이 함께 어떻게 작동하는지 보여줍니다
5. **제안된 팔레트**를 사용하여 빠르게 사전 설계된 색 구성표를 적용합니다
## 타이포그래피
1. **타이포그래피 설정**을 클릭합니다
2. **글꼴 선택**을 클릭하여 글꼴 브라우저를 엽니다
3. 제목과 본문 텍스트에 대한 글꼴을 설정합니다
4. **타이포그래피 스케일**을 클릭하여 제목 크기 계층을 조정합니다
## 간격
1. **간격 스케일**을 클릭합니다
2. 매우 작음부터 매우 큼까지 간격 값을 조정합니다
3. **간격 저장**을 클릭하여 전체 사이트에 적용합니다
## 로고 및 브랜딩
1. **로고**를 클릭합니다
2. **밝은 배경 로고**와 **어두운 배경 로고**를 업로드합니다
3. **소셜 미디어 이미지**를 업로드합니다
## 네비게이션 스타일
1. **네비게이션 스타일** 섹션으로 스크롤합니다
2. **네비게이션 스타일 편집**을 클릭합니다
3. 자신의 색상을 구성합니다
4. **저장**을 클릭합니다
