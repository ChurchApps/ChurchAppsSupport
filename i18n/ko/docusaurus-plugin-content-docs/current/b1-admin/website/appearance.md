# 외형

<div class="article-intro">

외형 페이지를 사용하면 교회 웹사이트의 전체적인 모양과 느낌을 사용자 정의할 수 있습니다. 색상, 글꼴, 간격, 사용자 정의 CSS에 이르기까지 한 곳에서 사이트의 모든 시각적 측면을 제어할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 웹사이트의 [초기 설정](initial-setup)을 완료하세요
- PNG 형식의 투명 배경과 4:1 종횡비를 가진 교회 로고를 준비하세요
- 기존 스타일 가이드가 있는 경우 교회의 브랜드 색상(16진수 값)을 알아두세요

</div>

## 외형 설정 액세스

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 위의 검색 표시줄)를 열고 **웹사이트**를 확장합니다.
2. **외형**을 클릭합니다.
3. 사이트 스타일 페이지가 로드되고 왼쪽에는 웹사이트의 실시간 미리보기가 표시되고 오른쪽에는 **스타일 설정** 옵션이 표시됩니다.

## 색상 팔레트

1. 스타일 설정 패널에서 **색상 팔레트**를 클릭합니다.
2. **기본 색상**(밝은 색, 강조 색, 어두운 색)과 **의미론적 색상**(기본, 보조, 성공, 경고, 오류)을 볼 수 있습니다.
3. 색상 견본을 클릭하여 색상 선택기를 엽니다. 선택기를 드래그하거나 16진수 값을 입력하여 색상을 선택합니다.
4. **색상 조합 미리보기**에는 선택한 색상이 어떻게 함께 작동하는지 표시됩니다.
5. **제안된 팔레트**를 사용하여 사전 설계된 색상 체계를 빠르게 적용합니다.
6. 만족하면 **저장**을 클릭합니다.

## 타이포그래피

1. 스타일 설정 패널에서 **타이포그래피 설정**을 클릭합니다.
2. **글꼴 선택**을 클릭하여 글꼴 브라우저를 엽니다. 이름으로 검색하거나 Serif, Sans Serif, Display, Handwriting, Monospace 등의 카테고리를 탐색할 수 있습니다.
3. 제목과 본문 텍스트 모두에 대해 글꼴을 설정합니다.
4. **타이포그래피 스케일**을 클릭하여 제목 1부터 제목 4까지의 크기 계층 구조를 조정합니다. 스케일 배수와 기본 크기 필드를 사용하여 미세 조정합니다.
5. **저장**을 클릭하여 글꼴 선택을 적용합니다.

## 간격

1. 스타일 설정 패널에서 **간격 스케일**을 클릭합니다.
2. 매우 작음부터 매우 큼까지 간격 값을 조정합니다. 실제 예제는 각 값이 레이아웃에 어떻게 영향을 미치는지 보여줍니다.
3. **간격 저장**을 클릭하여 값을 전체 사이트에 적용합니다.

## 로고 및 브랜딩

1. 스타일 설정 패널에서 **로고**를 클릭합니다.
2. **밝은 배경 로고**와 **어두운 배경 로고**를 업로드합니다. 최상의 결과를 위해 투명 배경과 4:1 종횡비를 가진 이미지를 사용합니다.
3. 링크 미리보기를 위한 **소셜 미디어 이미지**와 브라우저 탭 아이콘을 위한 **Favicon**을 업로드합니다.

:::tip
최상의 결과를 위해 PNG 형식의 투명 배경이 있는 로고를 사용합니다. 이렇게 하면 웹사이트 및 [모바일 앱](../settings/mobile-app.md)의 밝은 배경과 어두운 배경 모두에서 멋져 보입니다.
:::

## 네비게이션 스타일

고정 및 투명 모드 모두에서 웹사이트의 네비게이션 표시줄 색상을 사용자 정의합니다:

1. **네비게이션 스타일** 섹션으로 스크롤합니다
2. **네비게이션 스타일 편집**을 클릭합니다
3. 고정 네비게이션(배경 포함) 및 투명 네비게이션(오버레이 모드)에 대한 색상을 구성합니다
4. **저장**을 클릭하여 네비게이션 색상을 적용합니다

자세한 지침은 [네비게이션 스타일](./navigation-styles.md)을 참조하세요.

## 공지사항 및 위젯

사이트 위젯은 사이트의 모든 페이지에 나타나며 페이지 콘텐츠 위에 떠 있습니다:

- **공지사항 배너** - 예정된 이벤트 또는 서비스 변경과 같이 시간이 민감한 메시지를 위해 사이트 상단에 있는 해제 가능한 표시줄입니다.
- **런처** - 예를 들어 기부, 체크인 또는 공지사항 보기 링크와 같은 빠른 액세스 메뉴를 여는 떠 있는 버튼입니다.

1. 스타일 설정 패널에서 **공지사항 및 위젯**을 클릭합니다.
2. 원하는 위젯을 켜고 텍스트, 링크 및 색상을 구성합니다.
3. **저장**을 클릭합니다.

## 리디렉션 및 분석

스타일 설정의 **리디렉션 및 분석** 패널에는 관련 없지만 일반적으로 필요한 두 가지 설정이 있습니다:

- **분석** - **Google Analytics 4 측정 ID**를 추가하여 웹사이트의 방문자 트래픽을 추적합니다.
- **리디렉션** - 이전 URL 경로를 새 경로로 매핑하여 이동하거나 이름을 바꾼 페이지의 링크가 404 오류 대신 계속 작동하도록 합니다. 이전 **From** 경로와 새 **To** 경로를 입력한 다음 **저장**을 클릭합니다.

## 사용자 정의 CSS 및 JavaScript

1. 스타일 설정 패널에서 **CSS 및 Javascript**를 클릭합니다.
2. **사용자 정의 CSS**를 추가하여 고급 사용자 정의를 위한 기본 스타일을 재정의합니다.
3. 추적 코드 또는 기타 스크립트를 위해 **사용자 정의 HTML**을 추가합니다.
4. Google Analytics 통합과 같은 코드 조각을 위해 **일반 Javascript 예제** 섹션을 사용합니다.

:::warning
사용자 정의 CSS는 강력하지만 잘못 사용하면 사이트의 레이아웃을 깨뜨릴 수 있습니다. 대부분의 교회는 기본 제공 색상, 글꼴 및 간격 컨트롤을 사용하여 원하는 모양을 구현할 수 있습니다. 웹 개발에 익숙한 경우에만 사용자 정의 CSS를 사용하세요.
:::

:::info
사이트는 다른 소스의 인라인 스크립트를 차단하는 콘텐츠 보안 정책을 시행합니다. **사용자 정의 JavaScript** 필드는 유일한 신뢰할 수 있는 예외입니다. 여기에 저장하는 코드는 그대로 실행되므로 신뢰할 수 있는 소스의 스크립트만 붙여넣으세요(분석 태그, 채팅 위젯, 유사한 임베드).
:::

## 스타일 테마

빠른 시작점을 원하면 색상 팔레트 섹션의 **제안된 팔레트**는 한 번의 클릭으로 조정된 색상을 설정하는 사전 구축된 테마를 제공합니다. 테마를 적용한 후 항상 개별 설정을 미세 조정할 수 있습니다.
