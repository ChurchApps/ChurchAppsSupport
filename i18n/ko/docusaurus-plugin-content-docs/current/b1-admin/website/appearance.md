# 모양 {#appearance}

<div class="article-intro">

모양 페이지에서는 교회 웹사이트의 전반적인 외관과 느낌을 맞춤 설정할 수 있습니다. 색상과 글꼴에서 간격과 사용자 지정 CSS까지, 사이트의 모든 시각적 요소를 한곳에서 제어하세요.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 웹사이트의 [초기 설정](./initial-setup.md)을 마치세요
- 교회 로고를 투명한 배경과 4:1 가로세로 비율의 PNG 형식으로 준비하세요
- 기존 스타일 가이드가 있다면 교회의 브랜드 색상(16진수 값)을 알고 계세요

</div>

## 모양 설정 접근하기 {#accessing-appearance-settings}

1. B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Website**(웹사이트)를 펼치세요.
2. **Appearance**(모양)를 클릭하세요.
3. **Site Styles**(사이트 스타일) 페이지가 열립니다. **Theme, fonts & footer**(테마, 글꼴, 바닥글) 카드에는 왼쪽에 **Style Settings**(스타일 설정) 목록이, 오른쪽에 샘플 사이트 미리 보기가 표시됩니다. 그 아래에는 **Announcement & widgets**(공지 및 위젯)와 **Redirects & analytics**(리디렉션 및 분석) 카드가 있습니다.

## 색상 팔레트 {#color-palette}

1. Style Settings 패널에서 **Color Palette**(색상 팔레트)를 클릭하세요.
2. **Base Colors**(기본 색상)(밝은 색, 강조 색, 어두운 색 음영)과 **Semantic Colors**(의미 색상)(Primary(기본), Secondary(보조), Success(성공), Warning(경고), Error(오류))가 표시됩니다.
3. 색상 견본을 클릭하여 색상 선택기를 여세요. 선택기를 드래그하거나 16진수 값을 입력하여 색을 고르세요.
4. **Color Combinations Preview**(색상 조합 미리 보기)에서 선택한 색상이 어떻게 어울리는지 볼 수 있습니다.
5. **Suggested Palettes**(추천 팔레트)를 사용하면 미리 디자인된 색상 구성에서 시작할 수 있습니다. 팔레트를 클릭하면 편집기에 색상만 불러와집니다.
6. 사이트에 색상을 적용하려면 **Save Palette**(팔레트 저장)를, 버리려면 **Cancel**(취소)을 클릭하세요.

## 글꼴 {#typography}

1. Style Settings 패널에서 **Fonts**(글꼴)를 클릭하세요.
2. **Heading Font**(제목 글꼴) 또는 **Body Font**(본문 글꼴) 버튼을 클릭하면 **Select a Font**(글꼴 선택) 창이 열립니다. 이 창에는 인기순으로 정렬된 Google 글꼴이 페이지당 10개씩 나열됩니다. **Search**(검색)에 입력하여 이름으로 글꼴을 찾거나, **Category Filter**(분류 필터)(Serif(세리프), Sans Serif(산세리프), Display(디스플레이), Handwriting(손글씨), Monospace(고정폭))를 사용하세요. 글꼴을 클릭하면 선택됩니다. **Popular Font Combinations**(인기 글꼴 조합) 중 하나를 클릭하면 두 글꼴을 한 번에 설정할 수도 있습니다.
3. **Save Fonts**(글꼴 저장)를 클릭하여 글꼴 선택을 적용하세요.
4. 제목 1부터 제목 4까지의 크기 계층을 조정하려면 Style Settings 패널에서 **Typography Scale**(타이포그래피 배율)을 클릭하세요. **Type Scale**(타입 배율), **Base Size**(기본 크기), **Line Height**(줄 높이) 항목으로 세부 조정한 다음 **Save Typography**(타이포그래피 저장)를 클릭하세요.

## 간격 {#spacing}

1. Style Settings 패널에서 **Spacing Scale**(간격 배율)을 클릭하세요.
2. Extra Small(매우 작음)부터 Extra Large(매우 큼)까지 간격 값을 조정하세요. 실제 예시를 통해 각 값이 레이아웃에 어떤 영향을 주는지 보여줍니다.
3. **Save Spacing**(간격 저장)을 클릭하면 값이 사이트 전체에 적용됩니다.

## 로고와 브랜딩 {#logo-and-branding}

1. Style Settings 패널에서 **Logo**(로고)를 클릭하세요.
2. **Light Background Logo**(밝은 배경 로고)와 **Dark Background Logo**(어두운 배경 로고)를 업로드하세요. 가장 좋은 결과를 얻으려면 투명한 배경과 4:1 가로세로 비율의 이미지를 사용하세요.
3. 링크 미리 보기용 **Social Media Image**(소셜 미디어 이미지)와 브라우저 탭 아이콘용 **Favicon**(파비콘)을 업로드하세요.
4. 선택 사항으로 **PWA Short Name**(PWA 짧은 이름)(최대 12자)을 입력하세요. 누군가 휴대폰 홈 화면에 앱을 추가할 때 교회 앱 아이콘 아래에 표시되는 이름입니다.
5. **Save Changes**(변경 사항 저장)를 클릭하세요. 업로드한 이미지는 저장하기 전까지 보관되지 않으므로, 저장하기 전에 브라우저 탭을 닫거나 새로 고치려고 하면 브라우저가 저장되지 않은 변경 사항이 있다고 경고합니다.

로고는 교회의 모든 웹사이트에서 공유되며, 앱과 출석부 같은 인쇄물에도 사용됩니다.

:::tip
가장 좋은 결과를 얻으려면 투명한 배경의 PNG 로고를 사용하세요. 그래야 웹사이트와 [모바일 앱](../settings/mobile-app.md)의 밝은 배경과 어두운 배경 모두에서 잘 보입니다.
:::

## 탐색 스타일 {#navigation-styles}

고정 모드와 투명 모드 모두에서 웹사이트 탐색 모음의 색상을 맞춤 설정하세요:

1. Style Settings 패널에서 **Navigation**(탐색)을 클릭하세요
2. **Header (solid)**(머리글(고정))과 **Header over hero (transparent)**(히어로 위 머리글(투명))의 색상을 설정하세요
3. **Save Navigation**(탐색 저장)을 클릭하여 탐색 색상을 적용하세요

자세한 방법은 [탐색 스타일](./navigation-styles.md)을 참고하세요.

## 사이트 바닥글 {#site-footer}

Style Settings 패널에서 **Site Footer**(사이트 바닥글)를 클릭하면 블록 편집기에서 바닥글이 열립니다. 다른 페이지 섹션과 마찬가지로 구성하세요. 예를 들어 주소, 예배 시간, 소셜 링크를 넣을 수 있습니다. 끝나면 **Exit**(나가기)을 클릭하세요. 바닥글은 **Header & Footer**(머리글과 바닥글) 레이아웃을 사용하는 모든 페이지의 맨 아래에 나타납니다. 웹사이트마다 각자의 바닥글이 있습니다.

## 공지 및 위젯 {#announcement--widgets}

사이트 위젯은 사이트의 모든 페이지에 나타나며, 페이지 내용 위에 떠 있습니다:

- **Announcement Banner**(공지 배너) -- 사이트 상단에 있는 닫을 수 있는 바로, 행사나 예배 변경처럼 시간에 민감한 메시지를 표시합니다.
- **Launcher**(런처) -- 빠른 메뉴를 여는 떠 있는 버튼으로, 예를 들어 헌금, 체크인, 주보 보기 링크를 제공합니다.

1. Style Settings 아래의 **Announcement & widgets**(공지 및 위젯) 카드를 찾으세요.
2. **Announcement Bar**(공지 배너)에서 **Enabled**(사용)를 체크하고 **Text**(텍스트), 선택 사항인 **Link URL**(링크 URL)과 **Link Text**(링크 텍스트), **Background Color**(배경 색상)와 **Text Color**(텍스트 색상)를 입력하세요. **Start Date**(시작일)와 **End Date**(종료일)를 설정하면 그 기간에만 배너가 표시됩니다.
3. **Launcher**에서 **Enabled**를 체크한 다음, 링크마다 **Add Action**(작업 추가)을 클릭하고(최대 다섯 개) **Label**(레이블), **URL**, **Icon**(아이콘)을 입력하세요. **Position**(위치)(오른쪽 아래 또는 왼쪽 아래)과 **Color**(색상)를 선택하세요.
4. **Save**를 클릭하세요.

위젯을 끄려면 **Enabled**를 해제하고 **Save**를 클릭하세요. 이 위젯은 교회의 모든 웹사이트에 적용됩니다.

공지 배너는 교회 B1 앱(`/mobile`의 회원 포털, 설치된 앱 포함)의 홈 화면 상단, 인사말 위에도 같은 텍스트, 링크, 색상, 날짜로 표시됩니다. 앱에서는 자신의 페이지(예: `/food`)를 가리키는 **Link URL**이 웹사이트를 다시 불러오는 대신 앱 안에서 그 페이지를 엽니다. [B1App 탐색하기](../../b1-church/getting-started/navigating.md#home)를 참고하세요.

배너의 동작에 대한 몇 가지 세부 사항은 다음과 같습니다:

- 휴대폰에서는 긴 텍스트가 여러 줄로 나뉘며, 맞지 않으면 링크가 별도의 줄로 내려갑니다.
- 웹사이트에서는 메뉴 모음이 공지 배너 바로 아래에 놓여 메뉴 버튼이 계속 보입니다. 메뉴와 팝업 창은 배너 위에 열립니다.
- 누군가 배너의 **×** 버튼으로 배너를 닫으면, 그 기기에서는 하루 동안 숨겨졌다가 다시 나타납니다. **Text**를 바꾸면 이전 공지를 닫은 사람에게도 새 공지가 바로 표시됩니다.

## 리디렉션 및 분석 {#redirects--analytics}

**Redirects & analytics**(리디렉션 및 분석) 카드(Style Settings 아래)에는 서로 관련은 없지만 자주 필요한 두 가지 설정이 있습니다:

- **Analytics**(분석) -- **GA4 Measurement ID**(GA4 측정 ID)(형식 `G-XXXXXXXXXX`)를 입력하고 **Save**를 클릭하면 웹사이트 방문자 트래픽을 추적합니다. 같은 ID로 교회의 B1 앱(`/mobile`의 회원 포털, 설치된 앱 포함)에서의 페이지 조회도 추적하며, `display_mode` 값이 `installed`(설치됨) 또는 `browser`(브라우저)로 태그되므로 Google Analytics에서 설치된 앱의 방문과 브라우저 방문을 구분할 수 있습니다.
- **Redirects**(리디렉션) -- 예전 URL 경로를 새 경로로 연결하여, 이동하거나 이름을 바꾼 페이지로 가는 링크가 404 오류 대신 계속 작동하게 합니다. 이전 **From Path**(시작 경로)와 새 **To Path**(대상 경로)를 입력한 다음 **Add**(추가)를 클릭하세요. 리디렉션은 즉시 저장되며 입력란 위에 나열됩니다. 제거하려면 삭제 아이콘을 클릭하세요. 경로는 소문자로, 앞에는 슬래시를 붙이고 뒤에는 슬래시를 붙이지 않은 형태로 저장됩니다. 리디렉션은 B1의 기본 제공 페이지(`/sermons`, `/stream`, `/donate`, `/bible`, `/votd`)보다 우선하므로, 그 주소를 다른 곳(예: 자체 설교 페이지나 YouTube 채널)으로 보낼 수 있습니다. 같은 주소에 직접 만든 페이지가 있다면 리디렉션이 그 페이지를 덮어쓰지는 않습니다. 리디렉션을 적용하려면 먼저 그 페이지를 삭제하세요.

## 사용자 지정 CSS와 JavaScript {#custom-css-and-javascript}

1. Style Settings 패널에서 **CSS & Javascript**(CSS 및 자바스크립트)를 클릭하세요.
2. 고급 맞춤 설정을 위해 기본 스타일을 덮어쓰는 **Custom CSS**(사용자 지정 CSS)를 추가하세요.
3. 추적 코드나 기타 스크립트를 위해 **Custom HTML**(사용자 지정 HTML)을 추가하세요.
4. 바로 쓸 수 있는 코드 조각은 **Common CSS Examples**(일반 CSS 예시)와 **Common JavaScript Examples**(일반 자바스크립트 예시) 섹션을 활용한 다음 **Save Changes**(변경 사항 저장)를 클릭하세요.

:::warning
사용자 지정 CSS는 강력하지만 잘못 사용하면 사이트 레이아웃이 깨질 수 있습니다. 대부분의 교회는 내장된 색상, 글꼴, 간격 설정만으로 원하는 모습을 만들 수 있습니다. 웹 개발에 익숙한 경우에만 사용자 지정 CSS를 쓰세요.
:::

:::info
사이트에는 다른 출처의 인라인 스크립트를 차단하는 콘텐츠 보안 정책(Content Security Policy)이 적용되어 있습니다. 여기의 **Custom HTML** 필드와 개별 페이지의 [HTML 요소](./page-editor.md#using-the-html-element)는 예외로 허용된 부분입니다. 그곳에 저장한 코드는 그대로 실행되므로, 신뢰할 수 있는 출처의 스크립트(분석 태그, 채팅 위젯 등 비슷한 임베드)만 붙여 넣으세요.
:::

## 스타일 테마 {#style-themes}

빠르게 시작하고 싶다면, 색상 팔레트 섹션의 **Suggested Palettes**(추천 팔레트)에 조화로운 색상의 미리 만들어진 테마가 있습니다. 하나를 클릭하여 불러온 다음 원하는 색상을 조정하고 **Save Palette**를 클릭하세요.
