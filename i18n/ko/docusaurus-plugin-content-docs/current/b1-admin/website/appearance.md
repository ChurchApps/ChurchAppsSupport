# 외관

<div class="article-intro">

외관 페이지에서는 교회 웹사이트의 전반적인 모습과 느낌을 맞춤 설정할 수 있습니다. 색상과 글꼴부터 간격과 사용자 지정 CSS까지, 한 곳에서 사이트의 시각적 요소를 모두 제어할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 웹사이트의 [초기 설정](initial-setup)을 완료하세요.
- 교회 로고를 투명 배경과 4:1 가로세로 비율의 PNG 형식으로 준비하세요.
- 기존 스타일 가이드가 있다면 교회의 브랜드 색상(16진수 값)을 확인하세요.

</div>

## 외관 설정 열기

1. B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Website**를 펼칩니다.
2. **Appearance**를 클릭합니다.
3. **Site Styles** 페이지가 열립니다. **Theme, fonts & footer** 카드에는 왼쪽에 **Style Settings** 목록이, 오른쪽에 샘플 사이트 미리 보기가 표시됩니다. 그 아래에는 **Announcement & widgets**와 **Redirects & analytics** 카드가 있습니다.

## 색상 팔레트 {#color-palette}

1. Style Settings 패널에서 **Color Palette**를 클릭합니다.
2. **Base Colors**(밝은 색, 강조 색, 어두운 색)와 **Semantic Colors**(Primary, Secondary, Success, Warning, Error)가 표시됩니다.
3. 색상 견본을 클릭하여 색상 선택기를 엽니다. 선택기를 드래그하거나 16진수 값을 입력하여 색상을 고릅니다.
4. **Color Combinations Preview**에서 선택한 색상들이 함께 어떻게 어울리는지 확인할 수 있습니다.
5. **Suggested Palettes**를 사용하면 미리 디자인된 색상 조합을 빠르게 적용할 수 있습니다.
6. 만족스러우면 **Save Palette**를 클릭합니다.

## 글꼴(타이포그래피)

1. Style Settings 패널에서 **Fonts**를 클릭합니다.
2. **Heading Font** 또는 **Body Font** 버튼을 클릭하여 글꼴 브라우저를 엽니다. 이름으로 검색하거나 Serif, Sans Serif, Display, Handwriting, Monospace 같은 범주를 둘러볼 수 있습니다. **Popular Font Combinations** 중 하나를 고를 수도 있습니다.
3. **Save Fonts**를 클릭하여 글꼴 선택을 적용합니다.
4. 제목 1~4(Heading 1~4)의 크기 체계를 조정하려면 Style Settings 패널에서 **Typography Scale**을 클릭합니다. **Type Scale** 배율, **Base Size**, **Line Height** 값을 세부적으로 조정한 다음 **Save Typography**를 클릭합니다.

## 간격

1. Style Settings 패널에서 **Spacing Scale**을 클릭합니다.
2. Extra Small부터 Extra Large까지 간격 값을 조정합니다. 실제 예시를 통해 각 값이 레이아웃에 어떤 영향을 주는지 확인할 수 있습니다.
3. **Save Spacing**을 클릭하여 값을 사이트 전체에 적용합니다.

## 로고와 브랜딩 {#logo-and-branding}

1. Style Settings 패널에서 **Logo**를 클릭합니다.
2. **Light Background Logo**와 **Dark Background Logo**를 업로드합니다. 최상의 결과를 위해 투명 배경과 4:1 가로세로 비율의 이미지를 사용하세요.
3. 링크 미리 보기용 **Social Media Image**와 브라우저 탭 아이콘용 **Favicon**을 업로드합니다.
4. **Save Changes**를 클릭합니다. 업로드한 이미지는 저장하기 전까지 보관되지 않으므로, 저장하기 전에 브라우저 탭을 닫거나 새로 고치려고 하면 저장되지 않은 변경 사항이 있다는 경고가 표시됩니다.

:::tip
최상의 결과를 위해 투명 배경의 PNG 형식 로고를 사용하세요. 그래야 웹사이트와 [모바일 앱](../settings/mobile-app.md)의 밝은 배경과 어두운 배경 모두에서 잘 보입니다.
:::

## 내비게이션 스타일

웹사이트 내비게이션 바의 색상을 단색 모드와 투명 모드에 맞게 각각 맞춤 설정할 수 있습니다.

1. Style Settings 패널에서 **Navigation**을 클릭합니다.
2. **Header (solid)**와 **Header over hero (transparent)**의 색상을 설정합니다.
3. **Save Navigation**을 클릭하여 내비게이션 색상을 적용합니다.

자세한 내용은 [내비게이션 스타일](./navigation-styles.md)을 참고하세요.

## 공지 및 위젯

사이트 위젯은 사이트의 모든 페이지에 표시되며, 페이지 내용 위에 떠 있습니다.

- **Announcement Banner** -- 사이트 상단에 표시되는 닫을 수 있는 막대로, 행사나 예배 변경 같은 시급한 메시지에 사용합니다.
- **Launcher** -- 빠른 접근 메뉴를 여는 플로팅 버튼입니다. 예를 들어 헌금, 체크인, 주보 페이지로 연결되는 링크를 둘 수 있습니다.

1. Style Settings 아래의 **Announcement & widgets** 카드를 찾습니다.
2. 사용할 위젯을 켜고 텍스트, 링크, 색상을 설정합니다.
3. **Save**를 클릭합니다.

## 리디렉션 및 분석

Style Settings 아래의 **Redirects & analytics** 카드에는 서로 관련은 없지만 자주 필요한 두 가지 설정이 있습니다.

- **Analytics** -- **GA4 Measurement ID**(형식: `G-XXXXXXXXXX`)를 추가하면 웹사이트 방문자 트래픽을 추적할 수 있습니다. 같은 ID로 교회의 B1 앱(설치된 앱을 포함하여 `/mobile`에 있는 구성원 포털)의 페이지 조회도 추적되며, `display_mode` 값이 `installed` 또는 `browser`로 태그되어 Google Analytics에서 설치된 앱 방문과 브라우저 방문을 구분할 수 있습니다.
- **Redirects** -- 기존 URL 경로를 새 경로로 연결하여, 이동하거나 이름을 바꾼 페이지의 링크가 404 오류 없이 계속 작동하게 합니다. 기존 **From** 경로와 새 **To** 경로를 입력한 다음 **Save**를 클릭하세요. 리디렉션은 B1의 기본 제공 페이지(`/sermons`, `/stream`, `/donate`, `/bible`, `/votd`)보다 우선 적용되므로, 해당 주소를 다른 곳(예: 교회의 설교 페이지나 YouTube 채널)으로 보낼 수 있습니다. 같은 주소에 직접 만든 페이지가 있으면 리디렉션은 이를 대체하지 않습니다. 리디렉션을 적용하려면 먼저 그 페이지를 삭제하세요.

## 사용자 지정 CSS와 JavaScript

1. Style Settings 패널에서 **CSS & Javascript**를 클릭합니다.
2. 고급 맞춤 설정을 위해 **Custom CSS**를 추가하여 기본 스타일을 덮어씁니다.
3. 추적 코드나 기타 스크립트를 위해 **Custom HTML**을 추가합니다.
4. Google Analytics 연동 같은 예제 코드는 **Common JavaScript Examples** 섹션을 이용하세요.

:::warning
사용자 지정 CSS는 강력하지만, 잘못 사용하면 사이트 레이아웃이 깨질 수 있습니다. 대부분의 교회는 기본 제공 색상, 글꼴, 간격 설정만으로도 원하는 모습을 만들 수 있습니다. 웹 개발에 익숙한 경우에만 사용자 지정 CSS를 사용하세요.
:::

:::info
이 사이트는 다른 출처의 인라인 스크립트를 차단하는 콘텐츠 보안 정책(Content Security Policy)을 적용합니다. 여기의 **Custom HTML** 입력란과 개별 페이지의 [HTML 요소](page-editor#using-the-html-element)는 예외입니다. 여기에 저장한 코드는 그대로 실행되므로, 신뢰할 수 있는 출처의 스크립트(분석 태그, 채팅 위젯 등 비슷한 삽입 코드)만 붙여 넣으세요.
:::

## 스타일 테마

빠르게 시작하려면 색상 팔레트 섹션의 **Suggested Palettes**를 사용하세요. 한 번의 클릭으로 조화로운 색상이 한꺼번에 설정되는 미리 만들어진 테마를 제공합니다. 테마를 적용한 뒤에도 개별 설정을 언제든지 세부적으로 조정할 수 있습니다.
