# 설교 라이브러리 구축 및 라이브 스트림

<div class="article-intro">

설교 아카이브를 온라인에 공개하고 라이브 스트리밍을 설정하세요. 기존 YouTube 또는 Vimeo 라이브러리를 가져오는 것부터 채팅 기능이 포함된 정기 라이브 예배 일정 설정까지 다룹니다. 완료하면 성도들이 웹사이트와 모바일 앱에서 지난 설교를 시청하고 라이브 예배에 참여할 수 있습니다.

</div>

## 교육 영상

<div class="prereqs">
<h4>시작하기 전에</h4>

- 콘텐츠 관리 권한이 있는 B1 Admin 계정
- 설교 영상이 있는 YouTube 또는 Vimeo 채널 (기존 아카이브 가져오기용)
- YouTube 채널 ID (라이브 스트리밍용 — YouTube 스튜디오 설정에서 확인할 수 있습니다)

</div>

## 1단계: 설교 재생목록 만들기

재생목록은 설교를 시리즈와 모음별로 정리하여 쉽게 찾아볼 수 있도록 합니다.

[재생목록](../sermons/playlists.md) 가이드를 따라 다음을 진행하세요:

1. "2024 주일 설교", "결혼 시리즈", "성탄절 예배"와 같은 시리즈/모음 만들기
2. 각 재생목록에 이름, 설명, 게시일, 썸네일 추가하기

:::tip
설교를 추가하기 전에 재생목록을 먼저 만드세요. 설교를 추가할 때 올바른 시리즈로 쉽게 정리할 수 있습니다.
:::

## 2단계: 기존 설교 가져오기

이미 YouTube 또는 Vimeo에 설교 영상이 있다면 한 번에 모두 가져올 수 있습니다.

[일괄 가져오기](../sermons/bulk-import.md) 가이드를 따라 다음을 진행하세요:

1. YouTube 또는 Vimeo 채널 URL 입력하기
2. 가져올 영상을 확인하려면 미리 보기 실행하기
3. 가져오기를 클릭하여 모든 영상을 한 번에 추가하기

## 3단계: 개별 설교 추가하기

일회성 추가나 일괄 가져오기에 포함되지 않은 설교는 개별적으로 추가하세요.

[설교 관리](../sermons/managing-sermons.md) 가이드를 따라 다음을 진행하세요:

1. 영상 URL 붙여넣기 (YouTube, Vimeo 또는 Facebook)
2. 제목, 설명, 썸네일, 길이는 영상 메타데이터에서 자동으로 채워집니다
3. 설교를 재생목록에 할당하기

## 4단계: 라이브 스트리밍 설정하기

YouTube 채널을 연결하면 B1 사이트가 라이브 스트림을 자동으로 가져옵니다.

[라이브 스트리밍](../sermons/live-streaming.md) 가이드를 따라 다음을 진행하세요:

1. 스트리밍 설정에 YouTube 채널 ID 입력하기
2. 정기 예배 일정 구성하기 (예: 주일 오전 10:00)
3. **Sermons > Settings** 페이지에서 스트리밍 페이지 탭(채팅, 기도 제목, 사용자 지정 링크) 맞춤 설정하기

:::info
YouTube에서 라이브를 시작하면 B1 스트리밍 페이지가 자동으로 스트림을 가져옵니다. 주일 아침에 별도의 작업이 필요하지 않습니다.
:::

## 5단계: 웹사이트에 표시하기

방문자가 설교 라이브러리와 라이브 스트림에 쉽게 접근할 수 있도록 하세요.

[페이지 관리](../website/managing-pages.md) 가이드를 따라 다음을 진행하세요:

1. 방문자가 라이브러리를 둘러볼 수 있도록 B1 웹사이트에 설교 섹션 추가하기
2. 라이브 시청 경험을 위한 라이브 스트림 섹션 추가하기

## 6단계: 모바일 접근

성도들은 어떤 기기에서든 설교와 라이브 예배에 접근할 수 있습니다.

1. 성도들은 [B1.church 및 B1 App](../../b1-church/content/sermons.md)에서 설교를 시청할 수 있습니다
2. 채팅이 포함된 라이브 스트리밍은 휴대폰과 컴퓨터 모두에서 작동합니다

:::info
라이브 채팅 기능을 통해 온라인 성도들도 실시간으로 참여할 수 있어, 마치 현장에 있는 것처럼 함께할 수 있습니다.
:::

## 완료되었습니다!

설교 라이브러리가 온라인에 공개되었고 라이브 스트림이 설정되었습니다. 성도들은 언제든지 지난 설교를 다시 볼 수 있고, 어디에서나 라이브 예배에 참여할 수 있습니다. 새로운 설교 업로드는 자동으로 동기화될 수 있습니다.
