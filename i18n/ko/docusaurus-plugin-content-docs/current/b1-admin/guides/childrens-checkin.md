# 어린이 사역 체크인 설정하기

<div class="article-intro">

이 가이드는 교회에서 어린이 체크인 시스템을 운영하는 데 필요한 모든 과정을 안내합니다. 데이터베이스에 가족을 등록하고, 연령에 맞는 그룹을 구성하고, 주일 아침에 이름표를 출력하는 것까지 다룹니다. 가이드를 마치면 부모가 키오스크 태블릿에서 자녀를 체크인하고 일치하는 보안 태그를 받을 수 있게 됩니다.

</div>

- 선택 사항: 다른 시스템에서 옮겨 오는 경우 가족 목록을 CSV 파일로 준비하세요.

## 1단계: 데이터베이스에 가족 추가하기

체크인이 작동하려면 시스템이 가족을 알고 있어야 합니다. 각 자녀는 가구 기능을 통해 부모와 연결되어야 합니다.

적어도 한 가족을 추가하려면 [사람 추가하기](../people/adding-people.md) 가이드를 따르세요. 다음 사항을 꼭 지켜 주세요.

- 부모를 먼저 추가합니다.
- 각 자녀를 추가합니다.
- [가구 편집기](../people/adding-people.md#managing-households)를 사용하여 모두를 같은 가구로 연결합니다.

:::tip
가족이 몇 가구를 넘는다면 한 가족씩 추가하지 말고 [CSV 가져오기](../people/importing-data.md) 도구를 사용하세요. 전체 디렉터리를 몇 분 안에 가져올 수 있습니다.
:::

## 2단계: 어린이 그룹 만들기

그룹은 아이들이 체크인하는 반을 정의합니다. 보통 연령대마다 그룹을 하나씩 두는 것이 좋습니다.

다음과 같은 그룹을 만들려면 [그룹 만들기](../groups/creating-groups.md) 가이드를 따르세요.

- **Nursery** (0~2세)
- **Preschool** (3~5세)
- **Elementary** (6~10세)

교회의 사역 구조에 맞게 이름과 연령 범위를 조정할 수 있습니다.

## 3단계: 캠퍼스와 예배 구성하기

체크인은 특정 예배 시간에 연결됩니다. 최소한 캠퍼스 하나와 예배 하나가 구성되어 있어야 합니다.

[출석 설정](../attendance/setup.md) 가이드를 따라 다음을 진행하세요.

1. 캠퍼스를 추가합니다(예: "Main Campus").
2. 예배를 추가합니다(예: "Sunday Morning").
3. 예배 시간을 설정합니다(예: "9:00 AM"). 선택 사항으로 예배 전에 체크인이 자동으로 열리고 예배 후에 닫히도록 [체크인 일정](../attendance/setup.md#setting-a-check-in-schedule)을 설정할 수 있습니다.
4. 어린이 그룹을 예배에 배정합니다.

## 4단계: 체크인 앱 설정하기

이제 태블릿에 체크인 앱을 설치하여 모든 것을 연결합니다.

1. **B1 Checkin 앱**을 설치합니다. 다운로드 링크는 [체크인](../attendance/check-in.md) 문서를 참고하세요.
2. B1 Admin 계정으로 로그인합니다.
3. 캠퍼스와 예배 시간을 선택합니다.

자세한 설정 단계는 [체크인](../attendance/check-in.md) 문서 전체를 참고하세요.

## 5단계: 하드웨어 준비하기

키오스크용 태블릿이 필요하며, 이름표를 출력하려면 선택 사항으로 Brother 라벨 프린터가 필요합니다.

최소 구성은 다음과 같습니다.

- **Android 또는 Amazon Fire 태블릿 한 대** -- [추천 태블릿](../attendance/check-in.md#recommended-hardware)을 참고하세요.
- **Brother 라벨 프린터 한 대** -- Bluetooth와 WiFi를 지원하므로 QL-1110NWB를 추천합니다.
- **Brother DK-1201 라벨** (1-1/7" x 3-1/2")

:::warning
B1 Checkin 앱과 호환되는 프린터는 Brother 라벨 프린터뿐입니다. 다른 브랜드의 프린터는 작동하지 않습니다.
:::

## 6단계: 테스트 체크인 실행하기

주일 아침 전에 미리 테스트해 보세요.

1. 태블릿에서 B1 Checkin 앱을 엽니다.
2. 캠퍼스와 올바른 예배 시간을 선택합니다.
3. 추가해 둔 가족 중 한 가족을 검색합니다.
4. 자녀 한 명을 체크인하고 다음을 확인합니다.
   - B1 Admin의 **Attendance**에 출석이 나타나는지 확인합니다.
   - 프린터를 사용한다면 이름표가 올바르게 출력되는지 확인합니다.

:::tip
출시 전에 환영팀 봉사자들에게 체크인 절차를 교육하세요. 보통 5분 정도의 간단한 안내면 충분합니다.
:::

## 완료되었습니다!

이제 어린이 사역 체크인 준비가 끝났습니다. 부모는 가족을 검색하고, 자녀를 선택한 뒤 키오스크에서 체크인할 수 있습니다. 출석은 B1 Admin에 자동으로 기록됩니다.
