# 교회 웹사이트 출시

<div class="article-intro">

B1.church는 추가 비용 없이 완전한 웹사이트 빌더를 포함합니다. 이 가이드는 처음부터 교회 웹사이트를 만드는 방법을 안내합니다 — 홈페이지 설정, 모양 및 느낌 구성, 주요 페이지 추가 및 선택적으로 온라인 기부 및 이벤트 등록 양식 연결.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 교회 로고를 준비합니다(투명한 배경이 있는 PNG이 최적임).
- 사이트에 대해 2~3가지 브랜드 색상을 선택합니다.
- 사용자 정의 도메인(예: yourchurch.com)을 사용하는 경우, DNS 제공자(GoDaddy, Cloudflare 등)에 대한 접근 권한이 있습니다.
- 사이트에서 온라인 기부를 원하는 경우, 먼저 [온라인 기부 설정](../donations/online-giving-setup.md)(Stripe)을 완료합니다.

</div>

## 단계 1: 초기 웹사이트 설정

홈페이지와 기본 사이트 구조를 만들어 시작합니다.

[웹사이트 초기 설정](../website/initial-setup.md) 가이드를 따릅니다:

1. B1 Admin에서 **웹사이트**로 이동합니다.
2. 영웅 섹션, 환영 메시지 및 주요 정보로 홈페이지를 만듭니다.
3. 교회 이름과 태그라인을 추가합니다.

## 단계 2: 모양 구성

사이트의 시각적 정체성 — 색상, 글꼴, 로고 및 바닥글을 설정합니다.

[모양](../website/appearance.md) 가이드를 따릅니다:

1. 교회 로고를 업로드합니다.
2. 기본 및 강조 색상을 설정합니다.
3. 네비게이션 바 및 바닥글을 구성합니다.
4. 변경 사항을 미리봅니다.

:::tip
색상 팔레트를 단순하게 유지합니다 — 기본 색상 + 강조 색상 하나로 보통 충분합니다. 웹사이트 빌더가 나머지를 처리할 것입니다.
:::

## 단계 3: 콘텐츠 페이지 추가

방문자가 가장 필요한 페이지를 만들어냅니다.

[페이지 관리](../website/managing-pages.md) 가이드를 따라 다음과 같은 페이지를 만듭니다:

- **소개** — 교회의 이야기, 신념 및 지도자
- **설교** — [설교 라이브러리](../sermons/managing-sermons.md)로 연결
- **이벤트** — 예정된 이벤트 및 등록
- **기부** — 온라인 기부 페이지(Stripe [설정](../donations/online-giving-setup.md)이 필요)
- **연락처** — 위치, 서비스 시간 및 연락처 정보

## 단계 4: 도메인 연결

기본 B1 URL 대신 사용자 정의 도메인 이름(예: yourchurch.com)을 사용하려는 경우:

1. B1 Admin에서 **설정**으로 이동하고 **도메인** 섹션을 엽니다.
2. 사용자 정의 도메인을 입력합니다.
3. 도메인 공급자에서 DNS 레코드를 업데이트하여 B1을 가리킵니다.

:::info
DNS 변경은 전파되는 데 최대 48시간이 걸릴 수 있습니다. 사이트는 사용자 정의 도메인에서 즉시 접근할 수 없을 수 있습니다. 이 시간 동안 기본 B1 URL은 계속 작동합니다.
:::

## 단계 5: 기부 및 양식 추가

상호 작용하는 요소로 사이트를 향상시킵니다:

- **온라인 기부** — 멤버가 웹사이트에서 직접 기부할 수 있도록 기부 섹션을 추가합니다. Stripe을 먼저 구성하려면 [온라인 기부 설정](../donations/online-giving-setup.md)을 참조합니다.
- **등록 양식** — 이벤트 등록, 방문자 카드 또는 자원 신청용 [독립 실행형 양식](../forms/creating-forms.md)을 포함합니다. 페이지에 양식 요소를 추가하는 방법은 [페이지 관리](../website/managing-pages.md)를 참조하십시오.

## 완료했습니다!

교회 웹사이트가 공개되었습니다. URL을 회중 및 소셜 미디어와 공유합니다. B1 Admin 대시보드에서 언제든지 콘텐츠를 업데이트하고, 새 페이지를 추가하고, 모양을 조정할 수 있습니다.
