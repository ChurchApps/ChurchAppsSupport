# 연말 기부 보고서 생성

<div class="article-intro">

기부 기록을 최종화하고, 기금 설정을 검증하고, 모든 기부자를 위해 세금 공제 기부 명세서를 생성하는 연말 프로세스를 거칩니다. 이는 보통 이전 달력 연도에 대해 1월 초에 수행됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin 계정(재정 접근 포함)
- 연중 기록된 기부(Stripe를 통한 온라인 및/또는 수동 입력)
- 온라인 기부를 수락하는 경우 Stripe 계정에 대한 접근

</div>

## 단계 1: 최종 Stripe 거래 가져오기

연말의 모든 온라인 기부가 시스템에 있는지 확인합니다.

[Stripe 가져오기](../donations/stripe-import.md) 가이드를 따릅니다:

1. 기부 > 배치 > Stripe 가져오기로 이동합니다.
2. 연말을 포함하는 날짜 범위를 선택합니다(예: 12월 1일 - 12월 31일).
3. 먼저 미리보기를 클릭하여 검토한 후, 누락된 것을 가져오기로 최종 확정합니다.

:::warning
명세서를 생성하기 전에 이 가져오기를 실행합니다. 가져오지 않은 거래는 기부자 명세서에 나타나지 않습니다.
:::

## 단계 2: 기부 보고서 검토

명세서를 생성하기 전에 기록이 정확한지 확인합니다.

[기부 보고서](../donations/donation-reports.md) 가이드를 따릅니다:

1. 전체 연도에 대한 기부 요약 페이지를 확인합니다.
2. 기금별 합계를 검토하고 은행 명세서와 비교하여 불일치를 찾습니다.
3. 필요하면 개별 배치를 클릭하여 기부자 수준의 세부사항을 확인합니다.

## 단계 3: 기금 세금 상태 확인

각 기금의 세금 공제 설정이 명세서가 정확하도록 올바른지 확인합니다.

[기금](../donations/funds.md) 가이드를 따릅니다:

1. 각 기금을 열고 세금 공제 설정이 올바른지 확인합니다.

:::info
세금 공제로 표시된 기금에 대한 기부만 기부 명세서에 나타납니다. 기금이 세금 공제되어야 하지만 그렇게 표시되지 않은 경우, 명세서를 생성하기 전에 업데이트합니다.
:::

## 단계 4: 기부 명세서 생성

기부자를 위한 공식 기부 명세서를 만듭니다.

[기부 명세서](../donations/giving-statements.md) 가이드를 따릅니다:

1. **기부 > 기부 명세서**로 이동합니다.
2. 드롭다운에서 연도를 선택하고 요약 통계를 검토합니다.
3. 다운로드 방법을 선택합니다:
   - **ZIP 다운로드** — 개별 CSV 파일, 기부자당 하나
   - **모두 인쇄** — 각 명세서가 새 페이지에 있는 인쇄 가능한 보기

:::tip
1월 초에 기록이 신선할 때 명세서를 생성합니다. 이것은 발송하기 전에 문제를 찾을 시간을 줍니다.
:::

## 단계 5: 기부자에게 배포

명세서를 기부자의 손에 넘깁니다.

1. 명세서를 인쇄하고 우편으로 보내거나, 개별 CSV를 기부자에게 이메일로 보냅니다.
2. 멤버는 [B1.church](../../b1-church/giving/donation-history.md) 및 [B1 모바일 앱](../../b1-mobile/giving/donation-history.md)에서 자신의 기부 기록을 보고 명세서를 인쇄할 수 있습니다.

## 완료했습니다!

연말 기부 보고서가 완료되었습니다. 기부자는 세금 공제 명세서를 가지고 있고, 재정 기록은 연도에 대해 최종화됩니다.
