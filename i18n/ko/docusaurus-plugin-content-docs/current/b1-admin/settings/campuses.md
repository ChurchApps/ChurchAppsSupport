# 캠퍼스

<div class="article-intro">

교회가 한 곳 이상의 장소에서 모인다면, **캠퍼스**를 사용하여 각 사람과 그룹이 어느 장소에 속하는지 추적할 수 있습니다. 설정하면 캠퍼스가 사람 프로필, 출석 설정, 인구통계 대시보드에서 선택 항목으로 나타납니다. 여러 장소를 운영하는 교회는 B1 Admin 전반에서 캠퍼스별로 필터링, 검색, 보고를 할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 캠퍼스를 관리하려면 **Edit Church Settings**(교회 설정 편집) 권한이 필요합니다. [역할 및 권한](./roles-permissions.md)을 참고하세요.

</div>

## 캠퍼스 설정 열기 {#opening-campus-settings}

B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Settings > Settings**(설정 > 설정)를 선택한 다음, 왼쪽 목록에서 **Campuses**(캠퍼스)를 클릭하여 **Campuses** 섹션으로 스크롤하세요. **/settings/campuses** 주소로 바로 이동할 수도 있습니다. 설정된 모든 캠퍼스가 이름, 위치, 시간대와 함께 목록으로 표시됩니다.

## 캠퍼스 추가하기 {#adding-a-campus}

1. **Add Campus**(캠퍼스 추가)를 클릭하세요.
2. 캠퍼스 세부 정보를 입력하세요.
   - **Name**(이름) *(필수)* — B1 Admin 전체에 표시되는 이름입니다(예: "Main Campus"(본 캠퍼스) 또는 "North Campus"(북부 캠퍼스)).
   - **Address**(주소)와 **Address Line 2**(주소 2) — 캠퍼스의 도로명 주소입니다(참고용으로 표시되며, 교회 설정의 본 교회 주소와는 별개입니다).
   - **City / State / Zip**(도시 / 주 / 우편번호) — 캠퍼스의 위치입니다.
   - **Time Zone**(시간대) — 이 캠퍼스의 IANA 시간대입니다(예: *America/Chicago*). 이 캠퍼스 예배의 [체크인 일정](../attendance/setup.md#setting-a-check-in-schedule)은 이 시간대를 기준으로 열리고 닫힙니다. **None**(없음)으로 설정하면 교회의 [시간대](./church-settings.md#time-zone)가 대신 사용됩니다. 캠퍼스가 서로 다른 시간대에 있을 때 유용합니다.
   - **Website**(웹사이트) — 이 캠퍼스만의 웹 페이지 주소(선택 사항)입니다.
3. **Save**(저장)를 클릭하세요.

목록에는 각 캠퍼스의 **Name**(이름), **Location**(위치)(도시와 주), **Time Zone**(시간대)이 표시되며, 왼쪽 목록의 **Campuses**(캠퍼스) 항목에는 등록된 장소 수가 나타납니다.

## 캠퍼스 편집하기 {#editing-a-campus}

목록에서 캠퍼스 행을 클릭하면 오른쪽 패널에서 편집기가 열립니다. 필드를 수정한 다음 **Save**를 클릭하거나, 저장하지 않고 편집기를 닫으려면 **Cancel**(취소)을 클릭하세요.

## 캠퍼스 삭제하기 {#deleting-a-campus}

캠퍼스를 편집용으로 열고 **Delete**(삭제)를 클릭하세요. 확인을 요청합니다. 캠퍼스를 삭제해도 그 캠퍼스에 배정된 사람은 삭제되지 않으며, 그 사람의 캠퍼스 필드만 비게 됩니다.

## 사람을 캠퍼스에 배정하기 {#assigning-people-to-a-campus}

캠퍼스를 만든 후, 직원은 사람의 프로필에서 캠퍼스를 배정할 수 있습니다.

1. **People**(사람)에서 사람의 기록을 여세요.
2. **Edit**(편집)를 클릭하세요.
3. **Campus**(캠퍼스) 드롭다운에서 캠퍼스를 선택하세요.
4. **Save**를 클릭하세요.

사람 페이지에서 일괄로 캠퍼스를 업데이트할 수도 있습니다. 여러 사람을 선택하고 **Bulk Edit**(일괄 편집)을 사용하여 모든 사람의 Campus 필드를 한 번에 설정하세요.

## 캠퍼스로 필터링하기 {#filtering-by-campus}

캠퍼스를 설정하면 B1 Admin 전반에서 캠퍼스별로 필터링할 수 있습니다.

- **사람 검색** — 고급 검색에서 Campus 조건을 추가하거나, 캠퍼스 범위가 지정된 [저장된 목록](../people/lists.md)을 불러오세요.
- **인구통계** — 최소 한 사람에게 캠퍼스가 배정되어 있으면 [인구통계 대시보드](../people/demographics.md)에 Campus 도넛 차트가 표시됩니다.
- **출석 설정** — 출석의 각 예배 시간을 캠퍼스에 연결할 수 있습니다.

:::tip
장소가 하나뿐인 교회는 캠퍼스를 설정할 필요가 없습니다. 모든 캠퍼스 기능은 선택 사항이며, 캠퍼스가 없으면 캠퍼스 필드와 차트가 그냥 나타나지 않습니다.
:::
