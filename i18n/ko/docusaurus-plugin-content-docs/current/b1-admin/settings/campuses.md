# 캠퍼스

<div class="article-intro">

교회가 한 곳 이상의 장소에서 모인다면 **Campuses**를 사용하여 각 사람과 그룹이 어느 사이트에 속하는지 관리할 수 있습니다. 설정하면 캠퍼스가 사람 프로필, 출석 설정, 인구 통계 대시보드의 옵션으로 나타납니다. 여러 사이트를 운영하는 교회는 B1 Admin 전체에서 캠퍼스별로 필터링, 검색, 보고할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 캠퍼스를 관리하려면 **Edit Church Settings** 권한이 필요합니다. [역할 및 권한](./roles-permissions.md)을 참고하세요.

</div>

## 캠퍼스 설정 열기

B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Settings > Settings**를 선택한 다음, 왼쪽 목록에서 **Campuses**를 클릭하여 **Campuses** 섹션으로 이동합니다. **/settings/campuses** 주소로 바로 이동할 수도 있습니다. 설정된 모든 캠퍼스가 이름, 위치, 시간대와 함께 목록으로 표시됩니다.

## 캠퍼스 추가하기

1. **Add Campus**를 클릭합니다.
2. 캠퍼스 세부 정보를 입력합니다.
   - **Name** *(필수)* -- B1 Admin 전체에 표시되는 이름입니다(예: "Main Campus" 또는 "North Campus").
   - **Address** -- 캠퍼스의 도로명 주소입니다(정보 표시용이며, 교회 설정의 교회 주소와는 다릅니다).
   - **City / State / Zip** -- 캠퍼스의 위치입니다.
   - **Time Zone** -- 이 캠퍼스의 IANA 시간대입니다(예: *America/Chicago*). 이 캠퍼스에서 진행하는 예배의 [체크인 일정](../attendance/setup.md#setting-a-check-in-schedule)은 이 시간대를 기준으로 열리고 닫힙니다. **None**으로 설정하면 교회의 [시간대](./church-settings.md#time-zone)가 대신 사용됩니다. 캠퍼스가 서로 다른 시간대에 있을 때 유용합니다.
   - **Website** -- 이 캠퍼스 자체의 웹 존재를 나타내는 URL입니다(선택 사항).
3. **Save**를 클릭합니다.

## 캠퍼스 편집하기

목록에서 캠퍼스 행을 클릭하면 오른쪽 패널에서 편집기가 열립니다. 필드를 수정하고 **Save**를 클릭하세요.

## 캠퍼스 삭제하기

캠퍼스를 편집하기 위해 열고 **Delete**를 클릭합니다. 확인을 요청하는 메시지가 표시됩니다. 캠퍼스를 삭제해도 그 캠퍼스에 배정된 사람은 제거되지 않으며, 해당 사람의 캠퍼스 필드만 비게 됩니다.

## 사람을 캠퍼스에 배정하기

캠퍼스를 만든 후 직원은 사람의 프로필에서 캠퍼스를 배정할 수 있습니다.

1. **People**에서 사람의 기록을 엽니다.
2. **Edit**를 클릭합니다.
3. **Campus** 드롭다운에서 캠퍼스를 선택합니다.
4. **Save**를 클릭합니다.

People 페이지에서 여러 사람의 캠퍼스를 한꺼번에 바꿀 수도 있습니다. 여러 사람을 선택하고 **Bulk Edit**를 사용하여 모든 사람의 Campus 필드를 한 번에 설정하세요.

## 캠퍼스별 필터링

캠퍼스를 설정하면 B1 Admin 전체에서 캠퍼스별로 필터링할 수 있습니다.

- **People 검색** -- 고급 검색에 Campus 조건을 추가하거나, 캠퍼스에 맞춰 범위를 설정한 [저장된 목록](../people/lists.md)을 불러옵니다.
- **Demographics** -- 한 명 이상에게 캠퍼스가 배정되어 있으면 [인구 통계 대시보드](../people/demographics.md)에 Campus 도넛 차트가 표시됩니다.
- **Attendance Setup** -- 출석의 각 예배 시간을 캠퍼스와 연결할 수 있습니다.

:::tip
단일 장소 교회는 캠퍼스를 설정할 필요가 없습니다. 모든 캠퍼스 기능은 선택 사항입니다. 캠퍼스가 없으면 캠퍼스 필드와 차트가 그냥 표시되지 않습니다.
:::
