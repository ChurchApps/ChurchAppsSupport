# 캠퍼스 {#campuses}

<div class="article-intro">

교회가 두 곳 이상의 장소에서 모인다면, **캠퍼스** 기능으로 각 사람과 그룹이 어느 장소에 속하는지 추적할 수 있습니다. 설정하면 캠퍼스가 사람 프로필, 출석 설정, 인구통계 대시보드의 선택 항목으로 나타납니다. 여러 장소를 운영하는 교회는 B1 Admin 전체에서 캠퍼스별로 필터링, 검색, 보고를 할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 캠퍼스를 관리하려면 **교회 설정 편집** 권한이 필요합니다. [역할 및 권한](./roles-permissions.md)을 참조하세요.

</div>

## 캠퍼스 설정 열기 {#opening-campus-settings}

B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **설정 > 설정**을 선택한 다음, 왼쪽 목록에서 **캠퍼스**를 클릭하여 **캠퍼스** 섹션으로 스크롤합니다. **/settings/campuses** 주소로 바로 갈 수도 있습니다. 설정된 모든 캠퍼스가 이름, 위치, 시간대와 함께 목록으로 표시됩니다.

## 캠퍼스 추가하기 {#adding-a-campus}

1. **캠퍼스 추가**를 클릭합니다.
2. 캠퍼스 세부 정보를 입력합니다.
   - **이름** *(필수)* — B1 Admin 전체에 표시되는 이름입니다(예: "본당 캠퍼스" 또는 "북부 캠퍼스").
   - **주소** — 캠퍼스의 도로명 주소입니다(참고용으로 표시되며, 교회 설정의 교회 본 주소와는 다릅니다).
   - **도시 / 주(도) / 우편번호** — 캠퍼스의 위치입니다.
   - **시간대** — 이 캠퍼스의 IANA 시간대입니다(예: *America/Chicago*). 이 캠퍼스의 예배에 대한 [체크인 일정](../attendance/setup.md#setting-a-check-in-schedule)은 이 시간대를 기준으로 열리고 닫힙니다. **없음**으로 설정하면 교회의 [시간대](./church-settings.md#time-zone)를 대신 사용합니다. 캠퍼스가 서로 다른 시간대에 있을 때 유용합니다.
   - **웹사이트** — 이 캠퍼스 자체의 웹 사이트 주소(선택 사항)입니다.
3. **저장**을 클릭합니다.

## 캠퍼스 편집하기 {#editing-a-campus}

목록에서 캠퍼스 행을 클릭하면 오른쪽 패널에 편집기가 열립니다. 필드를 수정하고 **저장**을 클릭하세요.

## 캠퍼스 삭제하기 {#deleting-a-campus}

캠퍼스를 편집용으로 열고 **삭제**를 클릭합니다. 확인을 요청받게 됩니다. 캠퍼스를 삭제해도 그 캠퍼스에 배정된 사람은 제거되지 않으며, 그 사람의 캠퍼스 필드만 비어 있게 됩니다.

## 사람을 캠퍼스에 배정하기 {#assigning-people-to-a-campus}

캠퍼스를 만든 뒤에는, 직원이 사람의 프로필에서 그 사람을 캠퍼스에 배정할 수 있습니다.

1. **사람**에서 사람의 기록을 엽니다.
2. **편집**을 클릭합니다.
3. **캠퍼스** 드롭다운에서 캠퍼스를 선택합니다.
4. **저장**을 클릭합니다.

사람 페이지에서 여러 사람의 캠퍼스를 한꺼번에 바꿀 수도 있습니다. 여러 사람을 선택하고 **일괄 편집**을 사용하여 모든 사람의 캠퍼스 필드를 한 번에 설정하세요.

## 캠퍼스별로 필터링하기 {#filtering-by-campus}

캠퍼스를 설정하면 B1 Admin 전체에서 캠퍼스별로 필터링할 수 있습니다.

- **사람 검색** — 고급 검색에 캠퍼스 조건을 추가하거나, 캠퍼스로 범위를 정한 [저장된 목록](../people/lists.md)을 불러옵니다.
- **인구통계** — 한 명 이상의 사람에게 캠퍼스가 배정되어 있으면 [인구통계 대시보드](../people/demographics.md)에 캠퍼스 도넛 차트가 표시됩니다.
- **출석 설정** — 출석의 각 예배 시간은 캠퍼스에 연결할 수 있습니다.

:::tip
장소가 하나인 교회라면 캠퍼스를 설정할 필요가 없습니다. 캠퍼스 기능은 모두 선택 사항이며, 캠퍼스가 하나도 없다면 캠퍼스 필드와 차트는 그냥 나타나지 않습니다.
:::
