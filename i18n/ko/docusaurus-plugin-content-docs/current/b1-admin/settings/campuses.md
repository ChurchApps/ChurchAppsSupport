# 캠퍼스

<div class="article-intro">

교회가 한 개 이상의 위치에서 모이면 **캠퍼스**를 통해 각 사람 및 그룹이 어느 캠퍼스에 속하는지 추적할 수 있습니다. 구성되면 캠퍼스는 사람 프로필, 출석 설정 및 인구통계 대시보드에서 옵션으로 나타납니다. 다중 사이트 교회는 B1 Admin 전체의 캠퍼스별로 필터링, 검색 및 보고할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 캠퍼스를 관리하려면 **교회 설정 편집** 권한이 필요합니다. [역할 및 권한](./roles-permissions.md) 참조.

</div>

## 캠퍼스 설정 열기

B1 Admin에서 왼쪽 위 모서리의 **섹션 메뉴**(섹션 이름과 작은 화살표)를 열고 **설정**을 선택한 후 설정 탐색에서 **캠퍼스**를 선택합니다. 이름, 위치 및 시간대가 있는 구성된 모든 캠퍼스의 목록이 표시됩니다.

## 캠퍼스 추가

1. **캠퍼스 추가**(또는 캠퍼스가 아직 없는 경우 **+** 버튼)를 클릭합니다.
2. 캠퍼스 세부 정보를 입력합니다:
   - **이름** *(필수)* -- B1 Admin 전체에 표시되는 이름(예: "메인 캠퍼스" 또는 "북쪽 캠퍼스").
   - **주소** — 캠퍼스 거리 주소(정보 표시에 사용됨, 교회 설정의 주 주소와는 다름).
   - **도시 / 주 / 우편 번호** — 캠퍼스 위치입니다.
   - **시간대** — 이 캠퍼스의 IANA 시간대(예: *America/Chicago*). 캠퍼스가 다른 시간대에 있을 때 유용합니다.
   - **웹사이트** — 이 캠퍼스 자신의 웹 존재를 위한 선택적 URL입니다.
3. **저장**을 클릭합니다.

## 캠퍼스 편집

목록의 캠퍼스 행을 클릭하여 오른쪽의 패널에서 편집기를 엽니다. 필드를 업데이트하고 **저장**을 클릭합니다.

## 캠퍼스 삭제

편집을 위해 캠퍼스를 열고 **삭제**를 클릭합니다. 확인하라는 메시지가 표시됩니다. 캠퍼스를 삭제해도 할당된 사람이 제거되지 않습니다. 캠퍼스 필드가 단순히 비어있게 됩니다.

## 사람을 캠퍼스에 할당

캠퍼스를 만든 후 직원이 프로필에서 사람을 캠퍼스에 할당할 수 있습니다:

1. **사람**에서 사람의 기록을 엽니다.
2. **편집**을 클릭합니다.
3. **캠퍼스** 드롭다운에서 캠퍼스를 선택합니다.
4. **저장**을 클릭합니다.

사람 페이지에서 **일괄 편집**을 사용하여 캠퍼스를 일괄 업데이트할 수도 있습니다. 여러 사람을 선택하고 한 번에 모두에 대한 캠퍼스 필드를 설정합니다.

## 캠퍼스별 필터링

캠퍼스를 설정한 후 B1 Admin 전체에서 캠퍼스별로 필터링할 수 있습니다:

- **사람 검색** -- 고급 검색에서 캠퍼스 조건을 추가하거나 캠퍼스 범위의 [저장된 목록](../people/lists.md)을 로드합니다.
- **인구통계** — [인구통계 대시보드](../people/demographics.md)는 최소 한 사람이 캠퍼스에 할당되면 캠퍼스 도넛 차트를 표시합니다.
- **출석 설정** — 출석 설정의 각 예배 시간이 캠퍼스에 연결될 수 있습니다.

:::tip
단일 위치 교회는 캠퍼스를 구성할 필요가 없습니다. 모든 캠퍼스 기능은 선택 사항입니다. 캠퍼스가 없으면 캠퍼스 필드 및 차트가 단순히 표시되지 않습니다.
:::
