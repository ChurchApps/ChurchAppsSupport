# 캠퍼스

<div class="article-intro">

여러 위치에서 봉사하는 교회의 경우 캠퍼스를 설정하여 사람, 서비스, 그룹 및 이벤트를 캠퍼스별로 구성할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 설정 편집 권한 필요

</div>

## 캠퍼스 추가

1. B1 Admin에서 **설정 > 캠퍼스**로 이동합니다.
2. **캠퍼스 추가**를 클릭합니다.
3. 캠퍼스 **이름**을 입력합니다.
4. **저장**을 클릭합니다.

## 사람에게 캠퍼스 할당

사람의 프로필에서 **캠퍼스** 필드를 설정합니다.
