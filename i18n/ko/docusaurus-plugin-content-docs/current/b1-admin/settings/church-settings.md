# 교회 설정

<div class="article-intro">

교회 설정 페이지에서는 교회의 기본 정보, 연락처, 브랜딩을 구성합니다. 이 정보는 B1.church 웹사이트와 B1 Mobile 앱을 포함해 모든 ChurchApps 도구 전반에서 사용됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- "교회 설정 편집" 권한이 필요합니다. 접근 권한이 없다면 [역할 및 권한](./roles-permissions.md)을 참고하세요.
- 교회의 주소, 연락처 정보, 로고를 미리 준비해 두세요

</div>

## 교회 정보 편집하기

1. 왼쪽 사이드바에서 **설정(Settings)** 페이지로 이동합니다.
2. 헤더의 **설정 편집(Edit Settings)** 버튼을 클릭합니다.
3. 다음 필드 중 원하는 항목을 업데이트합니다.
   - **교회 이름** -- 모든 ChurchApps 제품에 표시되는 이름입니다.
   - **주소** -- 교회의 실제 주소입니다.
   - **연락처 정보** -- 전화번호, 이메일, 기타 연락처 정보입니다.
4. **저장(Save)**을 클릭해 변경 사항을 적용합니다.

## 서브도메인 설정하기

교회는 **yourchurch.b1.church** 형태의 무료 서브도메인을 받습니다. 이는 교인과 방문자가 교회의 온라인 공간에 접속할 수 있는 웹 주소입니다.

1. 설정 페이지에서 **서브도메인(Subdomain)** 필드를 찾습니다.
2. 원하는 서브도메인을 입력합니다(예: gracechurch.b1.church를 원한다면 "gracechurch").
3. 변경 사항을 저장합니다.

:::info
서브도메인은 모든 ChurchApps 소속 교회 중에서 고유해야 합니다. 원하는 이름이 이미 사용 중이라면, 도시나 주 이름을 덧붙여 보세요(예: "gracechurch-dallas").
:::

## 브랜딩 구성하기

모든 ChurchApps 도구에서 교회가 어떻게 표시되는지 사용자 지정할 수 있습니다.

1. 로고 영역을 클릭하고 이미지 파일을 선택해 **교회 로고**를 업로드합니다.
2. 웹사이트와 [모바일 앱](./mobile-app.md)에서 사용할 추가 **교회 이미지**를 추가합니다.

:::tip
가장 좋은 결과를 위해 투명 배경의 PNG 형식 로고를 사용하세요. 이렇게 하면 밝은 배경과 어두운 배경 모두에서 멋지게 보입니다.
:::

## 학년 승급

자녀와 학생의 **학년**을 관리하고 있다면, B1은 각 프로필을 일일이 수정할 필요 없이 선택한 날짜(예: 8월 1일)에 모든 사람의 학년을 자동으로 한 단계 올려줄 수 있습니다.

1. 설정 페이지에서 **학년 승급(Grade Promotion)** 옵션을 찾습니다.
2. 이를 켜고 매년 학년을 승급할 **월과 일**을 선택합니다.
3. 변경 사항을 저장합니다.

## 가져오기 및 내보내기

설정 헤더의 **가져오기/내보내기(Import/Export)** 버튼을 클릭하면 새 브라우저 창에서 전용 도구가 열립니다. 이 도구로 다음을 할 수 있습니다.

- 다른 교회 관리 시스템에서 교인 데이터를 가져옵니다.
- 백업이나 이전을 위해 ChurchApps 데이터를 내보냅니다.

교회를 처음 설정하면서 기존 기록을 ChurchApps로 옮겨야 할 때 특히 유용합니다.

:::warning
데이터를 가져오기 전에는 항상 기존 기록을 먼저 백업하세요. 가져오기 작업은 시스템에 데이터를 추가하는 방식이므로, 여러 번 실행하면 중복 항목이 생길 수 있습니다.
:::
