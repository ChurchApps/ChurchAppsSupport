# 교회 설정

<div class="article-intro">

교회 설정 페이지는 교회의 기본 정보, 연락처 세부 정보 및 브랜딩을 구성하는 곳입니다. 이러한 세부 정보는 B1.church 웹사이트 및 B1 모바일 앱을 포함한 모든 ChurchApps 도구에서 사용됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- "교회 설정 편집" 권한이 필요합니다. 접근 권한이 없는 경우 [역할 및 권한](./roles-permissions.md)을 참조하세요.
- 교회의 주소, 연락처 정보 및 로고를 준비하세요.

</div>

## 교회 정보 편집

1. B1 Admin에서 **섹션 메뉴**(왼쪽 위 모서리의 섹션 이름 옆 작은 화살표)를 열고 **설정**을 선택합니다.
2. 헤더에서 **설정 편집** 버튼을 클릭합니다.
3. 다음 필드 중 하나를 업데이트합니다:
   - **교회 이름** -- 모든 ChurchApps 제품에 표시되는 이름입니다.
   - **주소** -- 교회의 실제 주소입니다.
   - **연락처 정보** -- 전화번호, 이메일 및 기타 연락처 세부 정보입니다.
4. **저장**을 클릭하여 변경 사항을 적용합니다.

## 하위 도메인 설정

교회는 **yourchurch.b1.church**에서 무료 하위 도메인을 받습니다. 이것은 교인들과 방문객들이 교회의 온라인 활동에 접근할 수 있는 웹 주소입니다.

1. 설정 페이지에서 **하위 도메인** 필드를 찾습니다.
2. 선호하는 하위 도메인을 입력합니다(예: "gracechurch"는 gracechurch.b1.church의 경우).
3. 변경 사항을 저장합니다.

:::info
하위 도메인은 모든 ChurchApps 교회에서 고유해야 합니다. 원하는 이름이 이미 사용 중인 경우, 도시 또는 주를 추가해 보세요(예: "gracechurch-dallas").
:::

## 브랜딩 구성

교회가 모든 ChurchApps 도구에서 어떻게 표시되는지 사용자 정의하세요:

1. 로고 영역을 클릭하고 이미지 파일을 선택하여 **교회 로고**를 업로드합니다.
2. 웹사이트 및 [모바일 앱](./mobile-app.md)에서 사용할 **추가 교회 이미지**를 추가합니다.

:::tip
최상의 결과를 위해, 투명한 배경의 PNG 형식 로고를 사용하세요. 이렇게 하면 밝은 배경과 어두운 배경 모두에서 멋지게 보입니다.
:::

## 학년 승격

어린이 및 학생에 대해 **학년**을 추적하는 경우, B1은 선택한 날짜(예: 8월 1일)에 모든 사람의 학년을 자동으로 올릴 수 있으므로 각 프로필을 수동으로 편집할 필요가 없습니다.

1. 설정 페이지에서 **학년 승격** 옵션을 찾습니다.
2. 이를 켜고 매년 학년을 승격할 **월과 일**을 선택합니다.
3. 변경 사항을 저장합니다.

## 가져오기 및 내보내기

설정 헤더의 **가져오기/내보내기** 버튼은 새 브라우저 창에서 전용 도구를 열어줍니다. 이를 사용하여:

- 다른 교회 관리 시스템에서 회원 데이터를 가져옵니다.
- 백업 또는 마이그레이션 목적으로 ChurchApps 데이터를 내보냅니다.

이는 교회 설정을 처음 시작하고 기존 기록을 ChurchApps로 전송해야 할 때 특히 도움이 됩니다.

:::warning
데이터를 가져올 때는 항상 기존 기록을 먼저 백업하세요. 가져오기 작업은 시스템에 데이터를 추가하며, 여러 번 실행되면 중복 항목을 생성할 수 있습니다.
:::
