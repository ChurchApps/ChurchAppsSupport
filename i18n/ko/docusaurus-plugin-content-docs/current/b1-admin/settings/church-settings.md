# 교회 설정

<div class="article-intro">

교회 설정 페이지는 교회의 기본 정보, 연락처 세부 정보 및 브랜딩을 구성하는 곳입니다. 이 세부 정보는 B1.church 웹 사이트 및 B1 Mobile 앱을 포함한 모든 ChurchApps 도구에 사용됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- "교회 설정 편집" 권한이 필요합니다. 액세스 권한이 없으면 [역할 및 권한](./roles-permissions.md)을 참조합니다.
- 교회의 주소, 연락처 정보 및 로고를 준비합니다

</div>

## 교회 정보 편집

1. B1 Admin에서 왼쪽 상단의 **섹션 메뉴** (작은 화살표가 있는 섹션 이름)를 열고 **설정**을 선택합니다.
2. 헤더의 **설정 편집** 버튼을 클릭합니다.
3. 다음 필드 중 하나를 업데이트합니다:
   - **교회 이름** - 모든 ChurchApps 제품에 표시되는 이름입니다.
   - **주소** - 교회의 물리적 주소입니다.
   - **연락처 정보** - 전화번호, 이메일 및 기타 연락처 세부 정보입니다.
4. **저장**을 클릭하여 변경사항을 적용합니다.

## 서브도메인 설정

교회는 **yourchurch.b1.church**에서 무료 서브도메인을 받습니다. 이것이 회원과 방문자가 교회의 온라인 환경에 액세스할 수 있는 웹 주소입니다.

1. 설정 페이지에서 **서브도메인** 필드를 찾습니다.
2. 선호하는 서브도메인을 입력합니다 (예: "gracechurch"는 gracechurch.b1.church).
3. 변경사항을 저장합니다.

:::info
서브도메인은 모든 ChurchApps 교회에 걸쳐 고유해야 합니다. 선호하는 이름이 사용 중이면 도시나 주를 추가해 봅니다 (예: "gracechurch-dallas").
:::

## 브랜딩 구성

모든 ChurchApps 도구에 교회가 표시되는 방식을 사용자 정의합니다:

1. 로고 영역을 클릭하고 이미지 파일을 선택하여 **교회 로고**를 업로드합니다.
2. [모바일 앱](./mobile-app.md)에 사용되는 추가 **교회 이미지**를 추가합니다.

:::tip
최상의 결과를 위해 PNG 형식의 투명 배경이 있는 로고를 사용합니다. 밝은 배경과 어두운 배경 모두에서 멋지게 보입니다.
:::

## 주의 첫날

달력이 시작되는 요일을 선택합니다. 교회 정보 섹션의 **주의 첫날** 드롭다운은 기본값으로 **일요일**로 설정되지만 어떤 요일로든 설정할 수 있습니다. 변경하면 B1 Admin과 B1.church 회원 포털의 달력 그리드 전체에 적용됩니다. 그룹 달력, 큐레이션된 달력, 이벤트 편집기는 모두 선택한 요일부터 시작하여 주를 표시합니다.

## 학년 진급

어린이 및 학생의 **학년**을 추적하면 B1이 모든 프로필을 수동으로 편집하도록 요구하지 않고 선택한 날짜 (예: 8월 1일)에 모두를 자동으로 진급시킬 수 있습니다.

1. 설정 페이지에서 **학년 진급** 옵션을 찾습니다.
2. 켜고 매년 학년을 진급할 **월과 날짜**를 선택합니다.
3. 변경사항을 저장합니다.

## 가져오기 및 내보내기

설정 헤더의 **가져오기/내보내기** 버튼은 새로운 브라우저 창에서 전용 도구를 엽니다. 다음을 수행하는 데 사용합니다:

- 다른 교회 관리 시스템에서 회원 데이터를 가져옵니다.
- 백업 또는 마이그레이션 목적으로 ChurchApps 데이터를 내보냅니다.

이것은 교회 설정 초기 단계에서 기존 기록을 ChurchApps로 전송해야 할 때 특히 유용합니다.

:::warning
데이터를 가져올 때 항상 먼저 기존 기록을 백업합니다. 가져오기 작업은 시스템에 데이터를 추가하며 여러 번 실행되면 중복 항목이 생성될 수 있습니다.
:::
