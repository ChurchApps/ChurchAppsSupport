# 교회 설정

<div class="article-intro">

교회 설정 페이지에서 교회의 기본 정보, 연락처, 브랜딩을 구성할 수 있습니다. 이 정보는 B1.church 웹사이트와 B1 App을 포함한 모든 ChurchApps 도구에서 사용됩니다.

## 교회 정보 편집하기

1. B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **설정**을 펼친 뒤 **설정**을 클릭합니다.
2. 페이지 상단의 **교회 정보** 섹션에서 **편집**을 클릭합니다.
3. 다음 항목 중 원하는 내용을 수정합니다.
   - **교회 이름** -- 모든 ChurchApps 제품에 표시되는 이름입니다.
   - **주소** -- 교회의 실제 주소입니다.
   - **연락처 정보** -- 전화번호, 이메일 등 기타 연락처 정보입니다.
   - **시간대** -- 교회의 시간대입니다. 아래 [시간대](#time-zone)를 참고하세요.
4. **저장**을 클릭하여 변경 사항을 적용합니다.

## 서브도메인 설정하기

교회에는 **yourchurch.1.church** 형식의 무료 서브도메인이 제공됩니다. 이 주소는 성도와 방문자가 교회의 온라인 공간에 접속하는 웹 주소입니다.

1. 설정 페이지에서 **교회 정보** 섹션의 **편집**을 클릭하고 **서브도메인** 항목을 찾습니다.
2. 원하는 서브도메인을 입력합니다(예: gracechurch.1.church를 원하면 "gracechurch").
3. 변경 사항을 저장합니다.

:::info
서브도메인은 모든 ChurchApps 교회 중에서 고유해야 합니다. 원하는 이름이 이미 사용 중이라면 도시나 주 이름을 덧붙여 보세요(예: "gracechurch-dallas").
:::

방문자가 **`www.gracechurch.org`**처럼 교회 고유의 도메인으로 사이트에 접속하도록 하려면 [사용자 지정 도메인](./custom-domain.md)을 참고하세요.

## 브랜딩 설정하기

모든 ChurchApps 도구에서 교회가 표시되는 방식을 사용자 지정할 수 있습니다.

1. 로고 영역을 클릭하고 이미지 파일을 선택하여 **교회 로고**를 업로드합니다.
2. 웹사이트와 [모바일 앱](./mobile-app.md)에서 사용할 **교회 이미지**를 추가로 업로드합니다.

:::tip
최상의 결과를 위해 배경이 투명한 PNG 형식의 로고를 사용하세요. 밝은 배경과 어두운 배경 모두에서 선명하게 보입니다.
:::

## 주의 첫날

달력이 시작되는 요일을 선택합니다. 교회 정보 섹션의 **주의 첫날** 드롭다운은 기본값이 **일요일**이지만 원하는 요일로 변경할 수 있습니다. 변경하면 B1 Admin과 B1.church 성도 포털의 달력 화면에 반영됩니다. 그룹 달력, 큐레이션 달력, 이벤트 편집기 모두 선택한 요일을 주의 시작일로 표시합니다.

## 시간대

**교회 정보** 섹션의 **시간대** 드롭다운에서 교회의 시간대를 설정합니다(예: *America/Chicago*). 비워 두려면 **없음**을 선택하세요. 저장하면 교회 정보 요약에 해당 시간대가 표시됩니다.

B1은 이벤트 알림이나 [FreePlay](../../freeplay/scheduled-mode/scheduling-the-calendar.md) TV의 일정처럼 교회 전체에 적용되는 시간에 이 시간대를 사용합니다. [출석 체크인 일정](../attendance/setup.md#setting-a-check-in-schedule)은 먼저 예배가 열리는 [캠퍼스](./campuses.md)의 시간대를 기준으로 하며, 캠퍼스에 시간대가 없을 때만 교회 시간대를 사용합니다. 모든 캠퍼스가 같은 시간대에 있다면 교회와 각 캠퍼스 모두에 시간대를 설정하세요.

## 지역(날짜 및 전화번호 형식)

**지역** 설정은 B1 전체에서 날짜와 시간을 표기하는 방식을 결정합니다. 기본값은 미국 형식입니다(예: "Sep 28, 2026" 및 "9/28/2026"). 미국 외 지역의 교회는 해당 지역의 형식으로 변경할 수 있습니다. 예를 들어 영어(영국)를 선택하면 "28 Sept 2026" 및 "28/09/2026"으로 표시됩니다.

1. 설정 페이지의 왼쪽 목록에서 **지역**을 클릭한 다음 **지역** 섹션의 **편집**을 클릭합니다.
2. **지역** 드롭다운에서 지역을 선택합니다. 각 옵션에는 예시 날짜가 표시되어 날짜가 어떻게 보일지 미리 확인할 수 있습니다.
3. **저장**을 클릭합니다.

그러면 지역 섹션에 선택한 지역, **날짜 형식** 예시, **전화번호** 형식이 표시됩니다.

### 전화번호 형식

같은 지역 섹션에 있는 **전화번호** 설정은 성도 기록에서 전화번호를 입력하는 방식을 결정합니다.

- **국제(국가 번호 포함)** -- 기본값입니다. 전화번호 입력란에 국기 선택기가 표시되며, 번호를 국가 번호와 함께 저장합니다(예: +1 918 555 1234).
- **지역(입력한 그대로)** -- 전화번호 입력란이 일반 텍스트 상자로 바뀌며, 국가 번호를 추가하지 않고 입력한 그대로 저장합니다(예: 0701 234 5678). 교회에서 번호를 현지 형식으로 적고 B1이 국가 번호를 자동으로 추가하지 않기를 원한다면 이 옵션을 선택하세요.

**지역**을 선택하면 지역 섹션에 지역 이름 옆에 "지역 전화번호"도 표시됩니다.

:::tip
문자 메시지는 번호에 국가 번호가 포함되어 있을 때 가장 잘 작동합니다. B1에서 문자를 보낸다면 **국제** 형식을 유지하거나, 지역 모드에서 입력하는 번호에 국가 번호가 포함되어 있는지 확인하세요.
:::

지역 설정은 B1 Admin뿐만 아니라 B1.church 웹사이트와 성도 포털에 있는 날짜와 시간에도 적용됩니다. 설교, 블로그 게시물, 그룹 달력, 봉사 계획 등이 포함되므로 성도들도 교직원과 같은 형식으로 날짜를 보게 됩니다.

## 문자 메시지 {#texting}

문자 메시지 제공업체를 연결하면 B1 Admin에서 개인이나 그룹 전체에 SMS를 보낼 수 있습니다. 문자는 교회가 제공업체와 맺은 자체 계정을 통해 발송되므로 해당 제공업체의 요금과 제한이 적용됩니다.

1. 설정 페이지의 왼쪽 목록에서 **문자 메시지**를 클릭한 다음 **문자 메시지** 섹션의 **편집**을 클릭합니다.
2. **제공업체**를 선택합니다.
   - **Clearstream** -- **API 키**를 입력합니다. Clearstream 계정 설정의 API Keys에서 생성할 수 있습니다.
   - **Text In Church** -- **API 키**를 입력합니다. 먼저 Text In Church 지원팀에 개발자 API 접근을 요청한 다음, 계정 설정의 Developer API 섹션에서 키를 생성하세요.
   - **Nalo Solutions**(가나) -- Nalo Solutions 계정의 인증 키를 **API 키**로 입력하고, Nalo에서 승인받은 **발신자 ID**(최대 11자)를 입력합니다.
   - **Twilio** -- 교회의 Twilio 계정을 사용합니다. Twilio 요금은 교회에 직접 청구됩니다. [Twilio 콘솔](https://console.twilio.com)에서 **Account SID**와 **Auth Token**을 복사하고, **발신 번호**를 입력합니다. 발신 번호는 A2P 10DLC에 등록된 Twilio 전화번호여야 하며, `+15551234567`과 같은 형식이어야 합니다. 저장한 후에는 아래 수신 웹후크 URL을 Twilio 번호의 **A message comes in** 웹후크에 붙여 넣어야 STOP 응답이 B1에도 기록됩니다.
3. **저장**을 클릭합니다.

문자 메시지 발송을 중단하려면 **제공업체**를 **없음**으로 설정하고 저장하세요. 그러면 저장된 제공업체가 제거됩니다.

### STOP으로 응답한 사람 수신 거부 처리하기

제공업체를 저장한 후에는 **편집**을 눌러 문자 메시지 섹션을 다시 엽니다. 제공업체 설정 아래에는 교회 고유의 주소를 보여 주는 읽기 전용 **수신(STOP) 웹후크 URL** 필드가 있습니다. 필드를 클릭하여 주소를 선택하고 복사한 다음, 문자 제공업체의 수신 메시지(답장) 웹후크 설정에 붙여 넣으세요. 수신 답장을 웹후크로 전달할 수 있는 위의 제공업체라면 모두 이 방식을 사용할 수 있습니다.

이후 누군가 보낸 문자에 **STOP**(또는 STOPALL, UNSUBSCRIBE, CANCEL, END, QUIT, OPTOUT, REVOKE)으로 답장하면, B1은 휴대폰 번호가 일치하는 모든 사람을 찾아 수신 거부로 표시하고 문자 알림을 끕니다. 이후 그룹 문자에서도 제외됩니다. 그 밖의 답장은 무시됩니다.

:::info
이 기능은 **성도 디렉터리에서 숨기기**와 같은 수신 거부 설정을 사용하므로, STOP으로 답장한 사람은 프로필에 **디렉터리에서 숨김**으로도 표시됩니다. 이 필드는 저장된 제공업체가 선택되어 있을 때만 나타납니다. 드롭다운을 다른 제공업체로 바꾼 경우에는 URL을 다시 보려면 먼저 저장해야 합니다.
:::

제공업체를 연결하면, 문자 발송 권한이 있는 교직원은 그룹 페이지(**이 그룹에 문자 보내기**)와 휴대폰 번호가 있는 개인 페이지(**문자 메시지 보내기**)에서 **문자** 버튼을 볼 수 있습니다. 메시지를 입력하고 **보내기**를 클릭하세요. 문자 창에서는 글자 수와 SMS 세그먼트 수가 표시됩니다. 그룹에 보내는 경우에는 발송 전에 문자를 받을 구성원 수가 표시됩니다.

- 휴대폰 번호가 등록되어 있지 않은 구성원은 제외됩니다.
- **성도 디렉터리에서 숨기기**를 선택한 구성원은 수신 거부된 것으로 간주되어 제외됩니다.
- 같은 휴대폰 번호를 공유하는 가족 구성원에게는 문자가 한 번만 전송됩니다.

### 병합 필드로 문자 개인화하기 {#personalizing-texts-with-merge-fields}

메시지 입력란 아래의 문자 창에는 **이름**, **성**, **표시 이름**, **교회 이름** 자리 표시자 칩이 나타납니다. 칩을 클릭하면 커서 위치에 해당 자리 표시자(`{{firstName}}`, `{{lastName}}`, `{{displayName}}`, `{{churchName}}`)가 삽입됩니다. 문자가 발송되면 각 자리 표시자는 수신자의 정보로 바뀌므로, `Hi {{firstName}}, see you Sunday!`와 같은 그룹 문자는 구성원마다 각자의 이름으로 전달됩니다. 자리 표시자는 그룹 문자와 개인 문자 모두에서 사용할 수 있습니다. 그룹에 보내는 문자에는 **그룹 이름** 칩(`{{groupName}}`)도 있으며, 이 칩은 그룹 이름으로 바뀝니다.

메시지를 재사용하려면 [문자 템플릿](./email-templates.md#text-templates)(**문자** 카테고리의 이메일 템플릿)으로 저장한 다음, 문자 창 상단의 **템플릿 불러오기(선택 사항)**에서 선택하세요.

:::info
1,600자 제한은 입력하는 메시지 자체에 적용됩니다. 자리 표시자가 채워진 후 1,600자를 넘는 텍스트는 그 길이에서 잘립니다.
:::

문자는 [워크플로](../serving/workflows.md#sending-a-text)의 **문자 보내기** 단계를 통해 자동으로 발송될 수도 있습니다. 이 방식도 같은 제공업체와 자리 표시자를 사용합니다.

## 파일 저장소

기본적으로 웹사이트에 [파일](../website/files.md)을 통해 업로드하는 파일과 기타 콘텐츠 영역의 파일은 최대 100MB까지 B1의 무료 호스팅 저장소를 사용합니다. 더 많은 공간이 필요하다면 대신 자체 클라우드 저장소를 연결할 수 있습니다. 이후 새로 업로드하는 파일은 플랫폼 제한 없이 교회의 계정으로 바로 저장됩니다.

1. 설정 페이지의 왼쪽 목록에서 **파일 저장소**를 클릭한 다음 **파일 저장소** 섹션의 **편집**을 클릭합니다.
2. 제공업체를 선택합니다: **Google Drive**, **Dropbox**, **OneDrive**, 또는 **S3 호환 버킷**(AWS S3, Cloudflare R2, Backblaze B2 등).
3. Google Drive, Dropbox, OneDrive는 **연결**을 클릭하고 로그인하여 접근을 승인합니다. S3 호환 버킷은 액세스 키, 시크릿, 버킷 이름, 공개 URL 기본 경로를 입력합니다.
4. **저장**을 클릭합니다.

:::info
이 설정은 웹사이트 파일 및 이와 유사한 콘텐츠 영역에 새로 업로드하는 파일에만 영향을 줍니다. 갤러리 이미지, 썸네일, 로고, 성도 사진은 항상 B1의 기본 저장소에 보관됩니다.
:::

## 학년 진급

어린이와 학생의 **학년**을 기록한다면, B1은 각 프로필을 일일이 수정하지 않아도 선택한 날짜(예: 8월 1일)에 모든 사람의 학년을 자동으로 한 단계씩 올릴 수 있습니다.

1. 설정 페이지의 왼쪽 목록에서 **학년 진급**을 클릭한 다음 **학년 진급** 섹션의 **편집**을 클릭합니다.
2. 스위치를 켜고(**사용**으로 표시됨), 매년 학년을 올릴 **월**과 **일**을 선택합니다. 그 날짜가 되면 학년이 있는 모든 사람이 한 학년 올라가며, 12학년은 **졸업**으로 바뀝니다.
3. 변경 사항을 저장합니다.

자동 진급을 중단하려면 스위치를 꺼서 **사용 안 함**으로 표시되게 하고 저장하세요. 그러면 진급 날짜가 삭제되며 학년은 더 이상 자동으로 바뀌지 않습니다.

## 봉사 신청 {#volunteer-signup}

기본적으로 [봉사 신청](../../b1-church/serving/volunteer-signup.md)을 살펴보는 성도에게는 자리가 남아 있는 모든 예정 주차가 표시됩니다. 목록이 길어진다면 각 계획 유형의 다음 한 주만 표시하도록 설정할 수 있습니다.

1. 설정 페이지의 왼쪽 목록에서 **봉사 신청**을 클릭한 다음 **봉사 신청** 섹션의 **편집**을 클릭합니다.
2. **계획 유형별로 다음 한 주만 표시**를 켭니다.
3. 변경 사항을 저장합니다.

이 설정을 켜면 각 계획 유형은 다음 예정 계획만 표시합니다. 다음 주 계획은 해당 날짜가 지난 후에 나타납니다. 섹션의 **표시되는 주** 항목에는 **계획 유형별 다음 한 주만** 또는 **예정된 모든 주**가 표시됩니다.

## 헌금 개인정보 보호 {#giving-privacy}

헌금 권한이 있는 사람은 보통 [성도 기록](../people/adding-people.md#editing-details)에서 성도의 헌금 총액을 볼 수 있습니다. 기록을 열 때마다 금액이 화면에 나타나는 것을 원하지 않는다면, 누군가 요청할 때까지 금액을 숨길 수 있습니다.

1. 설정 페이지의 왼쪽 목록에서 **헌금 개인정보 보호**를 클릭한 다음 **헌금 개인정보 보호** 섹션의 **편집**을 클릭합니다.
2. **성도 기록에서 클릭할 때까지 헌금 숨기기**를 켭니다.
3. 변경 사항을 저장합니다.

이 설정을 켜면 성도 기록의 헌금 카드에 "성도 기록에서 헌금이 숨겨져 있습니다."라고 표시됩니다. **헌금 보기**를 클릭하면 해당 성도의 헌금이 불러와져 표시됩니다. 다른 성도의 기록을 열면 다시 숨겨집니다. 헌금을 볼 수 있는 사람은 바뀌지 않습니다. 헌금 권한이 있는 사람만 이 카드를 볼 수 있습니다.

## 가져오기 및 내보내기

설정 페이지에서 교회 이름 아래에 있는 **가져오기/내보내기** 링크는 새 브라우저 창에서 전용 도구를 엽니다. 이 도구를 사용하여 다음을 할 수 있습니다.

- 다른 교회 관리 시스템에서 성도 데이터를 가져오기
- 백업이나 이전 목적으로 ChurchApps 데이터 내보내기

이 기능은 교회를 처음 설정하면서 기존 기록을 ChurchApps로 옮겨야 할 때 특히 유용합니다.

:::warning
데이터를 가져오기 전에 반드시 기존 기록을 먼저 백업하세요. 가져오기 작업은 시스템에 데이터를 추가하며, 여러 번 실행하면 중복 항목이 생길 수 있습니다.
:::
