# 교회 설정

<div class="article-intro">

교회 설정 페이지에서는 교회의 기본 정보, 연락처 세부사항 및 브랜딩을 구성합니다. 이러한 세부사항은 B1.church 웹사이트 및 B1 모바일 앱을 포함한 모든 ChurchApps 도구에서 사용됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- "교회 설정 편집" 권한이 필요합니다. 액세스 권한이 없으면 [역할 및 권한](./roles-permissions.md)을 참조하세요.
- 교회의 주소, 연락처 정보 및 로고를 준비하세요

</div>

## 교회 정보 편집

1. B1 Admin에서 왼쪽 상단의 **섹션 메뉴** (작은 화살표가 있는 섹션 이름)를 열고 **설정**을 선택하세요.
2. **교회 정보** 섹션을 열고 편집 (연필) 아이콘을 클릭하세요.
3. 다음 필드 중 하나를 업데이트하세요:
   - **교회 이름** -- 모든 ChurchApps 제품에 표시되는 이름.
   - **주소** -- 교회의 실제 주소.
   - **연락처 정보** -- 전화번호, 이메일 및 기타 연락처 세부사항.
4. **저장**을 클릭하여 변경사항을 적용하세요.

## 서브도메인 설정

교회는 **yourchurch.1.church**에서 무료 서브도메인을 받습니다. 이것은 멤버와 방문자가 교회의 온라인 존재에 액세스할 수 있는 웹 주소입니다.

1. 설정 페이지에서 **서브도메인** 필드를 찾으세요.
2. 원하는 서브도메인을 입력하세요 (예: "gracechurch"은 gracechurch.1.church의 경우).
3. 변경사항을 저장하세요.

:::info
서브도메인은 모든 ChurchApps 교회에서 고유해야 합니다. 원하는 이름이 사용되고 있으면 도시나 주를 추가하세요 (예: "gracechurch-dallas").
:::

방문자가 자신의 도메인 (예: **www.gracechurch.org**)에서 사이트에 도달하도록 하려면 [사용자 정의 도메인](./custom-domain.md)을 참조하세요.

## 브랜딩 구성

모든 ChurchApps 도구에서 교회가 어떻게 표시되는지 사용자 정의하세요:

1. 로고 영역을 클릭하여 이미지 파일을 선택하여 **교회 로고**를 업로드하세요.
2. 웹사이트와 [모바일 앱](./mobile-app.md)에서 사용되는 추가 **교회 이미지**를 추가하세요.

:::tip
최상의 결과를 위해 PNG 형식의 투명 배경이 있는 로고를 사용하세요. 이렇게 하면 밝은 배경과 어두운 배경 모두에서 훌륭하게 보입니다.
:::

## 주 시작 요일

캘린더가 시작하는 요일을 선택하세요. 교회 정보 섹션의 **주 시작 요일** 드롭다운은 기본값이 **일요일**이지만 어느 요일로든 설정할 수 있습니다. 변경되면 B1 Admin과 B1.church 멤버 포털의 캘린더 그리드 전체에서 인정됩니다 -- 그룹 캘린더, 선별된 캘린더 및 이벤트 편집기는 모두 선택한 요일부터 시작하는 주를 배치합니다.

## 파일 저장

기본적으로 웹사이트에 업로드하는 파일 ([파일](../website/files.md)을 통해)과 기타 콘텐츠 영역은 B1의 무료 호스팅 저장소를 사용하며 최대 100MB입니다. 더 많은 공간이 필요하면 대신 자신의 클라우드 저장소를 연결할 수 있습니다 -- 새 업로드는 플랫폼 제한이 없는 계정으로 직접 이동합니다.

1. 설정 페이지에서 **파일 저장** 카드를 찾고 편집을 클릭하세요.
2. 공급자를 선택하세요: **Google Drive**, **Dropbox**, **OneDrive** 또는 **S3 호환 버킷** (AWS S3, Cloudflare R2, Backblaze B2 등).
3. Google Drive, Dropbox 또는 OneDrive의 경우 **연결**을 클릭하여 액세스를 권한부여하려면 로그인하세요. S3 호환 버킷의 경우 액세스 키, 암호, 버킷 이름 및 공개 URL 기준을 입력하세요.
4. **저장**을 클릭하세요.

:::info
이것은 웹사이트 파일과 유사한 콘텐츠 영역으로의 새 업로드에만 영향을 줍니다. 갤러리 이미지, 축소판, 로고 및 사람 사진은 항상 B1의 기본 저장소에 유지됩니다.
:::

## 학년 진급

자녀 및 학생에게 **학년**을 추적하는 경우 B1은 각 프로필을 손으로 편집하도록 요구하지 않고 선택한 날짜 (예: 8월 1일)에 모든 사람을 자동으로 학년을 올릴 수 있습니다.

1. 설정 페이지에서 **학년 진급** 옵션을 찾으세요.
2. 켜기를 선택하고 매년 학년을 진급할 **월 및 일**을 선택하세요.
3. 변경사항을 저장하세요.

## 가져오기 및 내보내기

설정 헤더의 **가져오기/내보내기** 단추는 새 브라우저 창에서 전용 도구를 엽니다. 다음에 사용하세요:

- 다른 교회 관리 시스템에서 멤버 데이터를 가져옵니다.
- 백업 또는 마이그레이션 목적으로 ChurchApps 데이터를 내보냅니다.

이것은 특히 교회를 처음 설정할 때 기존 레코드를 ChurchApps로 전송해야 할 때 도움이 됩니다.

:::warning
데이터를 가져올 때는 항상 먼저 기존 레코드를 백업하세요. 가져오기 작업은 시스템에 데이터를 추가하며 여러 번 실행하면 중복 항목이 생성될 수 있습니다.
:::
