# 교회 설정 {#church-settings}

<div class="article-intro">

교회 설정 페이지에서는 교회의 기본 정보, 연락처, 브랜드를 구성합니다. 이 정보는 B1.church 웹사이트와 B1 Mobile 앱을 포함하여 모든 ChurchApps 도구에서 사용됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- "교회 설정 편집" 권한이 필요합니다. 접근 권한이 없다면 [역할 및 권한](./roles-permissions.md)을 참조하세요.
- 교회의 주소, 연락처 정보, 로고를 준비해 두세요.

</div>

## 교회 정보 편집하기 {#editing-your-church-information}

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **설정**을 펼친 다음 **설정**을 클릭합니다.
2. 페이지 상단의 **교회 정보** 섹션에서 **편집**을 클릭합니다.
3. 다음 항목 중 원하는 것을 업데이트합니다.
   - **교회 이름** -- 모든 ChurchApps 제품에 표시되는 이름입니다.
   - **주소** -- 교회의 실제 주소입니다.
   - **연락처 정보** -- 전화번호, 이메일 및 기타 연락처 세부 정보입니다.
   - **시간대** -- 교회의 시간대입니다. 아래의 [시간대](#time-zone)를 참조하세요.
4. **저장**을 클릭하여 변경 사항을 적용합니다.

## 하위 도메인 설정하기 {#setting-up-your-subdomain}

교회는 **yourchurch.1.church**에서 무료 하위 도메인을 받습니다. 회원과 방문자가 교회의 온라인 공간에 접속할 수 있는 웹 주소입니다.

1. 설정 페이지에서 **교회 정보** 섹션의 **편집**을 클릭하고 **하위 도메인** 필드를 찾습니다.
2. 원하는 하위 도메인을 입력합니다(예: gracechurch.1.church라면 "gracechurch").
3. 변경 사항을 저장합니다.

:::info
하위 도메인은 모든 ChurchApps 교회에서 고유해야 합니다. 원하는 이름이 이미 사용 중이라면 도시나 주 이름을 추가해 보세요(예: "gracechurch-dallas").
:::

방문자가 자체 도메인(예: **www.gracechurch.org**)으로 사이트에 접속하기를 원한다면 [사용자 지정 도메인](./custom-domain.md)을 참조하세요.

## 브랜딩 구성하기 {#configuring-branding}

모든 ChurchApps 도구에서 교회가 보이는 방식을 설정할 수 있습니다.

1. 로고 영역을 클릭하고 이미지 파일을 선택하여 **교회 로고**를 업로드합니다.
2. 웹사이트와 [모바일 앱](./mobile-app.md)에 사용할 추가 **교회 이미지**를 추가합니다.

:::tip
가장 좋은 결과를 얻으려면 투명 배경의 PNG 형식 로고를 사용하세요. 밝은 배경과 어두운 배경 모두에서 잘 보입니다.
:::

## 주의 첫 요일 {#first-day-of-week}

달력이 시작되는 요일을 선택하세요. 교회 정보 섹션의 **주의 첫 요일** 드롭다운은 기본값이 **일요일**이지만, 어떤 요일로든 설정할 수 있습니다. 변경하면 B1 Admin과 B1.church 회원 포털의 달력 격자 전체에 적용됩니다. 그룹 달력, 큐레이션 달력, 이벤트 편집기 모두 선택한 요일로 주를 시작합니다.

## 시간대 {#time-zone}

교회 정보 섹션의 **시간대** 드롭다운은 교회의 시간대(예: *America/Chicago*)를 설정합니다. 비워 두려면 **없음**을 선택하세요. 저장하면 시간대가 교회 정보 요약에 나타납니다.

B1은 이 시간대를 이벤트 알림과 [FreePlay](../../freeplay/scheduled-mode/scheduling-the-calendar.md) TV의 일정처럼 교회 전체에서 사용하는 시각에 사용합니다. [체크인 일정](../attendance/setup.md#setting-a-check-in-schedule)은 먼저 예배가 열리는 [캠퍼스](./campuses.md)의 시간대를 기준으로 하며, 캠퍼스에 시간대가 없을 때만 교회 시간대를 사용합니다. 캠퍼스가 모두 같은 시간대에 있다면 교회와 각 캠퍼스 모두에 설정하세요.

## 지역(날짜 및 전화번호 형식) {#region-date-and-phone-format}

**지역** 설정은 B1 전체에서 날짜와 시각을 표시하는 방식을 제어합니다. 기본적으로 날짜는 미국 형식을 사용합니다(예: "Sep 28, 2026" 및 "9/28/2026"). 미국 밖의 교회는 자국의 형식으로 바꿀 수 있습니다. 예를 들어 영어(영국)를 선택하면 "28 Sept 2026" 및 "28/09/2026"으로 표시됩니다.

1. 설정 페이지에서 왼쪽 목록의 **지역**을 클릭한 다음, **지역** 섹션에서 **편집**을 클릭합니다.
2. **지역** 드롭다운에서 지역을 선택합니다. 각 옵션에는 예시 날짜가 표시되므로 날짜가 어떻게 보일지 정확히 확인할 수 있습니다.
3. **저장**을 클릭합니다.

그러면 지역 섹션에 선택한 지역, **날짜 형식**의 예시, 그리고 **전화번호** 형식이 표시됩니다.

### 전화번호 형식 {#phone-number-format}

같은 지역 섹션에는 사람의 기록에서 전화번호를 어떻게 입력하는지 제어하는 **전화번호** 설정이 있습니다.

- **국제(국가 코드 포함)** -- 기본값입니다. 전화번호 필드에 국기 선택기가 표시되며, 번호를 국가 코드와 함께 저장합니다(예: +1 918 555 1234).
- **지역(입력한 그대로)** -- 전화번호 필드가 일반 텍스트 상자가 되며, 국가 코드를 추가하지 않고 입력한 그대로 번호를 저장합니다(예: 0701 234 5678). 교회가 번호를 지역 형식으로 적고, B1이 국가 코드를 추가하지 않기를 원한다면 이것을 선택하세요.

**지역**을 선택하면 지역 섹션에 지역 옆에 "지역 전화번호"도 표시됩니다.

:::tip
문자 메시지는 번호에 국가 코드가 포함될 때 가장 잘 작동합니다. B1에서 문자를 보낸다면 **국제** 형식을 유지하거나, 지역 모드에서 입력하는 번호에 국가 코드가 포함되도록 하세요.
:::

지역 설정은 B1 Admin 전체와 B1.church 웹사이트 및 회원 포털의 날짜와 시각에 적용됩니다. 설교, 블로그 글, 그룹 달력, 섬김 일정도 포함되므로, 회원도 직원과 같은 형식으로 날짜를 봅니다.

## 문자 메시지 {#texting}

문자 메시지 제공업체를 연결하면 B1 Admin에서 한 사람이나 그룹 전체에 SMS를 보낼 수 있습니다. 문자는 귀하가 제공업체와 맺은 계정을 통해 발송되므로, 해당 제공업체의 요금과 한도가 적용됩니다.

1. 설정 페이지에서 왼쪽 목록의 **문자 메시지**를 클릭한 다음, **문자 메시지** 섹션에서 **편집**을 클릭합니다.
2. **제공업체**를 선택합니다.
   - **Clearstream** -- **API 키**를 입력합니다. Clearstream 계정 설정의 API Keys에서 만들 수 있습니다.
   - **Text In Church** -- **API 키**를 입력합니다. 먼저 Text In Church 지원팀에 개발자 API 접근을 요청한 다음, 계정 설정의 Developer API 섹션에서 키를 만드세요.
   - **Nalo Solutions**(가나) -- Nalo Solutions 계정의 인증 키를 **API 키**로 입력하고, Nalo가 승인한 **발신자 ID**(최대 11자)를 입력합니다.
3. **저장**을 클릭합니다.

문자 발송을 중단하려면 **제공업체**를 **없음**으로 설정하고 저장하세요. 저장된 제공업체가 제거됩니다.

### STOP으로 답장한 사람 수신 거부 처리하기 {#opting-out-people-who-reply-stop}

제공업체를 저장한 뒤에는 **편집**으로 문자 메시지 섹션을 다시 엽니다. 제공업체 설정 아래에 읽기 전용 **수신(STOP) 웹훅 URL** 필드가 있으며, 이 필드에는 교회 고유의 웹 주소가 표시됩니다. 필드를 클릭하여 주소를 선택하고 복사한 다음, 문자 제공업체의 수신 메시지(답장) 웹훅 설정에 붙여 넣으세요. 들어오는 답장을 웹훅으로 전달할 수 있는 위의 제공업체라면 모두 작동합니다.

이후 누군가 보낸 문자에 **STOP**(또는 STOPALL, UNSUBSCRIBE, CANCEL, END, QUIT, OPTOUT, REVOKE)으로 답장하면, B1은 휴대폰 번호가 일치하는 모든 사람을 찾아 수신 거부 상태로 표시하고 문자 알림을 끕니다. 이후 이들은 그룹 문자에서 건너뛰어집니다. 그 밖의 답장은 무시됩니다.

:::info
이 기능은 **디렉터리에서 나를 숨기기**와 같은 수신 거부 설정을 사용하므로, STOP으로 답장한 사람은 프로필에도 **디렉터리에서 숨겨짐**으로 표시됩니다. 이 필드는 저장된 제공업체가 선택되어 있을 때만 나타납니다. 드롭다운을 다른 제공업체로 바꾼다면, URL을 다시 보려면 먼저 저장하세요.
:::

제공업체가 연결되면, 문자 발송 권한이 있는 직원은 그룹 페이지(**이 그룹에 문자 보내기**)와 휴대폰 번호가 있는 사람의 페이지(**문자 메시지 보내기**)에서 **문자** 버튼을 볼 수 있습니다. 메시지를 입력하고 **보내기**를 클릭하세요. 대화상자는 글자 수와 SMS 세그먼트 수를 셉니다. 그룹의 경우, 보내기 전에 문자를 받을 구성원이 몇 명인지 보여 줍니다.

- 휴대폰 번호가 등록되어 있지 않은 구성원은 건너뜁니다.
- **디렉터리에서 나를 숨기기**를 선택한 구성원은 수신 거부로 계산되어 건너뜁니다.
- 같은 휴대폰 번호를 공유하는 가족 구성원은 문자를 한 번만 받습니다.

### 병합 필드로 문자 개인화하기 {#personalizing-texts-with-merge-fields}

메시지 상자 아래에 있는 문자 대화상자에는 자리 표시자 칩이 있습니다. **이름**, **성**, **표시 이름**, **교회 이름**입니다. 칩을 클릭하면 커서 위치에 자리 표시자(`{{firstName}}`, `{{lastName}}`, `{{displayName}}`, `{{churchName}}`)가 삽입됩니다. 문자가 발송되면 각 자리 표시자는 그 수신자의 세부 정보로 바뀌므로, `Hi {{firstName}}, see you Sunday!` 같은 그룹 문자가 구성원마다 각자의 이름으로 전달됩니다. 자리 표시자는 그룹 문자와 한 사람에게 보내는 문자 모두에서 작동합니다.

:::info
1,600자 제한은 입력한 그대로의 메시지에 적용됩니다. 자리 표시자가 채워진 뒤 1,600자를 넘는 문자는 그 길이에서 잘립니다.
:::

문자는 [워크플로](../serving/workflows.md#sending-a-text) 단계의 **문자 보내기** 작업으로도 자동 발송할 수 있으며, 이 경우 같은 제공업체와 자리 표시자를 사용합니다.

## 파일 저장소 {#file-storage}

기본적으로 웹사이트 [파일](../website/files.md)(및 기타 콘텐츠 영역)을 통해 업로드하는 파일은 최대 100MB까지 B1의 무료 호스팅 저장소를 사용합니다. 더 많은 공간이 필요하다면 대신 자체 클라우드 저장소를 연결할 수 있습니다. 그러면 새 업로드가 플랫폼 제한 없이 귀하의 계정으로 바로 저장됩니다.

1. 설정 페이지에서 왼쪽 목록의 **파일 저장소**를 클릭한 다음, **파일 저장소** 섹션에서 **편집**을 클릭합니다.
2. 제공업체를 선택합니다. **Google Drive**, **Dropbox**, **OneDrive**, 또는 **S3 호환 버킷**(AWS S3, Cloudflare R2, Backblaze B2 등)입니다.
3. Google Drive, Dropbox, 또는 OneDrive의 경우 **연결**을 클릭하고 로그인하여 접근을 승인합니다. S3 호환 버킷의 경우 액세스 키, 비밀 키, 버킷 이름, 공개 URL 기본 주소를 입력합니다.
4. **저장**을 클릭합니다.

:::info
이 설정은 웹사이트 파일과 유사한 콘텐츠 영역에 대한 새 업로드에만 영향을 줍니다. 갤러리 이미지, 썸네일, 로고, 사람 사진은 항상 B1의 기본 저장소에 남습니다.
:::

## 학년 진급 {#grade-promotion}

어린이와 학생의 **학년**을 기록한다면, B1은 선택한 날짜(예: 8월 1일)에 모든 사람을 자동으로 한 학년씩 올릴 수 있습니다. 프로필을 하나씩 손으로 편집할 필요가 없습니다.

1. 설정 페이지에서 왼쪽 목록의 **학년 진급**을 클릭한 다음, **학년 진급** 섹션에서 **편집**을 클릭합니다.
2. 스위치를 켜서 **사용**으로 표시되게 하고, 매년 학년을 올릴 **월**과 **일**을 선택합니다. 그 날짜가 되면 학년이 있는 모든 사람이 한 학년씩 올라가며, 12학년은 **졸업**으로 바뀝니다.
3. 변경 사항을 저장합니다.

자동 진급을 중단하려면 스위치를 꺼서 **사용 안 함**으로 표시되게 하고 저장하세요. 진급 날짜가 제거되며 학년은 더 이상 스스로 바뀌지 않습니다.

## 봉사자 등록 {#volunteer-signup}

기본적으로 [봉사자 등록](../../b1-church/serving/volunteer-signup.md)을 살펴보는 회원에게는 자리가 남아 있는 다가오는 모든 주가 표시됩니다. 목록이 길어지면 각 일정 유형의 다음 한 주만 대신 표시할 수 있습니다.

1. 설정 페이지에서 왼쪽 목록의 **봉사자 등록**을 클릭한 다음, **봉사자 등록** 섹션에서 **편집**을 클릭합니다.
2. **각 일정 유형의 다음 한 주만 표시**를 켭니다.
3. 변경 사항을 저장합니다.

이 설정을 켜면 각 일정 유형은 다음에 다가오는 일정만 표시합니다. 다음 주 일정은 그 날짜가 지나야 나타납니다. 섹션의 **표시되는 주** 행에는 **각 일정 유형의 다음 한 주만** 또는 **다가오는 모든 주**가 표시됩니다.

## 헌금 개인정보 보호 {#giving-privacy}

헌금 접근 권한이 있는 사람은 보통 [사람 기록](../people/adding-people.md#editing-details)에서 그 사람의 헌금 합계를 볼 수 있습니다. 기록을 열 때마다 금액이 화면에 보이지 않도록 하고 싶다면, 누군가 요청할 때까지 숨길 수 있습니다.

1. 설정 페이지에서 왼쪽 목록의 **헌금 개인정보 보호**를 클릭한 다음, **헌금 개인정보 보호** 섹션에서 **편집**을 클릭합니다.
2. **사람 기록에서 클릭할 때까지 헌금 숨기기**를 켭니다.
3. 변경 사항을 저장합니다.

이 설정을 켜면 사람 기록의 헌금 카드에 "사람 기록에서 헌금이 숨겨져 있습니다."라고 표시됩니다. **헌금 보기**를 클릭하면 그 사람의 헌금을 불러와 표시합니다. 다른 사람을 열면 다시 숨겨집니다. 헌금을 볼 수 있는 사람이 바뀌지는 않습니다. 헌금 접근 권한이 있는 사람만 이 카드를 봅니다.

## 가져오기 및 내보내기 {#import-and-export}

설정 페이지에서 교회 이름 아래의 **가져오기/내보내기** 링크를 열면 새 브라우저 창에서 전용 도구가 열립니다. 이 도구는 다음 용도로 사용합니다.

- 다른 교회 관리 시스템에서 회원 데이터 가져오기
- 백업이나 이전을 위해 ChurchApps 데이터 내보내기

교회를 처음 설정하면서 기존 기록을 ChurchApps로 옮겨야 할 때 특히 유용합니다.

:::warning
데이터를 가져올 때는 항상 먼저 기존 기록을 백업하세요. 가져오기 작업은 시스템에 데이터를 추가하며, 여러 번 실행하면 중복 항목이 만들어질 수 있습니다.
:::
