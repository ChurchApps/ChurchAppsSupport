# 교회 설정

<div class="article-intro">

교회 설정 페이지는 교회의 기본 정보, 연락처 세부 정보 및 브랜딩을 구성하는 곳입니다. 이 세부 정보는 B1.church 웹사이트 및 B1 모바일 앱을 포함한 모든 ChurchApps 도구에서 사용됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- "교회 설정 편집" 권한이 필요합니다. 접근 권한이 없으면 [역할 및 권한](./roles-permissions.md)을 참조하세요.
- 교회의 주소, 연락처 정보 및 로고가 준비되어 있어야 합니다

</div>

## 교회 정보 편집하기

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)를 열고 (왼쪽 위의 검색 바), **설정**을 확장하고 **설정**을 클릭하세요.
2. **교회 정보** 섹션을 열고 편집 (연필) 아이콘을 클릭하세요.
3. 다음 필드 중 하나를 업데이트하세요:
   - **교회 이름** -- 모든 ChurchApps 제품에서 표시되는 이름.
   - **주소** -- 교회의 물리적 주소.
   - **연락처 정보** -- 전화번호, 이메일 및 기타 연락처 세부 정보.
4. **저장**을 클릭하여 변경 사항을 적용하세요.

## 서브도메인 설정하기

교회는 **yourchurch.1.church**에서 무료 서브도메인을 얻습니다. 이것은 교인과 방문객이 교회의 온라인 존재에 접속할 수 있는 웹 주소입니다.

1. 설정 페이지에서 **서브도메인** 필드를 찾으세요.
2. 선호하는 서브도메인을 입력하세요 (예: "gracechurch"는 gracechurch.1.church에 해당).
3. 변경 사항을 저장하세요.

:::info
서브도메인은 모든 ChurchApps 교회 전체에서 고유해야 합니다. 선호하는 이름이 사용 중이면, 도시 또는 주를 추가해 보세요 (예: "gracechurch-dallas").
:::

방문객이 자신의 도메인 (예: **www.gracechurch.org**)에서 사이트에 접속하도록 하려면 [사용자 정의 도메인](./custom-domain.md)을 참조하세요.

## 브랜딩 구성하기

ChurchApps 도구 전체에서 교회가 나타나는 방식을 사용자 정의하세요:

1. 로고 영역을 클릭하고 이미지 파일을 선택하여 **교회 로고**를 업로드하세요.
2. 웹사이트 및 [모바일 앱](./mobile-app.md)에서 사용하는 모든 추가 **교회 이미지**를 추가하세요.

:::tip
최상의 결과를 위해 PNG 형식의 투명한 배경이 있는 로고를 사용하세요. 이렇게 하면 밝은 배경과 어두운 배경 모두에서 멋지게 보입니다.
:::

## 주의 첫 번째 날

캘린더가 어느 날부터 시작되는지 선택하세요. 교회 정보 섹션의 **주의 첫 번째 날** 드롭다운은 기본적으로 **일요일**이지만, 어느 날로든 설정할 수 있습니다. 변경되면, B1 Admin 및 B1.church 회원 포털의 캘린더 그리드 전체에서 적용됩니다 -- 그룹 캘린더, 엄선된 캘린더, 이벤트 편집기는 모두 당신이 선택한 날부터 시작하는 주를 배열합니다.

## 지역 (날짜 형식)

**지역** 설정은 B1 전체에서 날짜와 시간이 작성되는 방식을 제어합니다. 기본적으로 날짜는 미국 형식을 사용합니다 (예: "Sep 28, 2026" 및 "9/28/2026"). 미국 외 교회는 자신의 형식으로 전환할 수 있습니다 -- 예를 들어, 영어 (영국)을 선택하면 대신 "28 Sept 2026" 및 "28/09/2026"을 표시합니다.

1. 설정 페이지에서 **지역** 카드를 찾고 클릭하여 편집하세요.
2. **지역** 드롭다운에서 지역을 선택하세요. 각 옵션은 날짜가 정확히 어떻게 보일 것인지 볼 수 있도록 샘플 날짜를 표시합니다.
3. **저장**을 클릭하세요.

지역 카드는 선택한 지역과 **날짜 형식**의 샘플을 표시합니다.

지역은 B1 Admin과 B1.church 웹사이트 및 회원 포털의 날짜 및 시간 전체에 적용되며, 설교, 블로그 게시물, 그룹 캘린더 및 사역 계획을 포함하므로, 회원은 직원이 하는 것과 같은 형식으로 날짜를 봅니다.

## 문자 메시지

문자 제공자를 연결하여 B1 Admin에서 개인 또는 전체 그룹에 SMS 메시지를 보내세요. 텍스트는 제공자와의 자신의 계정을 통해 전송되므로, 그들의 가격 책정 및 제한이 적용됩니다.

1. 설정 페이지에서 **문자 메시지** 카드를 찾고 클릭하여 편집하세요.
2. **제공자**를 선택하세요:
   - **Clearstream** -- **API 키**를 입력하세요. Clearstream 계정 설정에서 API 키 아래에 하나를 만드세요.
   - **Text In Church** -- **API 키**를 입력하세요. 먼저 Text In Church 지원팀에 개발자 API 접근을 요청한 다음, 계정 설정 > 개발자 API 섹션에서 키를 만드세요.
   - **Nalo Solutions** (가나) -- Nalo Solutions 계정의 인증 키를 **API 키**로 입력하고, Nalo가 당신을 위해 승인한 **발신자 ID** (최대 11자)를 입력하세요.
3. **저장**을 클릭하세요.

텍스트 메시지를 중지하려면, **제공자**를 **없음**으로 설정하고 저장하세요. 이렇게 하면 저장된 제공자가 제거됩니다.

제공자가 연결되면, 텍스트를 보낼 권한이 있는 직원은 그룹의 헤더에서 텍스트 아이콘 (**이 그룹에 문자 보내기**)과 휴대폰이 있는 사람의 헤더에서 (**문자 메시지 보내기**)를 봅니다. 메시지를 입력하고 **보내기**를 클릭하세요. 대화 상자는 문자 및 SMS 세그먼트를 계산합니다. 그룹의 경우, 전송하기 전에 몇 명의 멤버가 문자를 받을지 표시합니다:

- 파일에 휴대폰이 없는 멤버는 건너뜁니다.
- **회원 디렉토리에서 나를 숨기기**를 선택한 멤버는 옵트아웃으로 계산되고 건너뜁니다.
- 휴대폰 번호를 공유하는 가족 멤버는 한 번만 문자를 받습니다.

### 병합 필드를 사용하여 텍스트 개인화하기

메시지 상자 아래, 텍스트 대화는 플레이스홀더 칩을 표시합니다: **이름**, **성**, **표시 이름** 및 **교회 이름**. 칩을 클릭하여 자신의 커서에 플레이스홀더 (`{{firstName}}`, `{{lastName}}`, `{{displayName}}` 또는 `{{churchName}}`)를 삽입하세요. 텍스트가 전송될 때, 각 플레이스홀더는 그 수신자의 세부 정보로 바뀌므로, `Hi {{firstName}}, see you Sunday!`와 같은 그룹 텍스트는 각 멤버의 자신의 이름으로 도달합니다. 플레이스홀더는 그룹 텍스트 및 개인 텍스트 모두에 대해 작동합니다.

:::info
1,600자 제한은 입력한 대로 메시지에 적용됩니다. 플레이스홀더가 채워진 후, 1,600자보다 긴 텍스트는 그 길이에서 잘립니다.
:::

텍스트는 또한 같은 제공자 및 플레이스홀더를 사용하는 **텍스트 보내기** 작업으로 [워크플로우](../serving/workflows.md#sending-a-text) 단계에서 자동으로 나갈 수 있습니다.

## 파일 저장

기본적으로 웹사이트 ([파일](../website/files.md)을 통해)와 다른 콘텐츠 영역에 업로드하는 파일은 B1의 무료 호스팅 저장소를 사용하며, 최대 100MB입니다. 더 많은 공간이 필요하면, 대신 자신의 클라우드 저장소를 연결할 수 있습니다 -- 새 업로드는 플랫폼 제한 없이 자신의 계정으로 바로 이동합니다.

1. 설정 페이지에서 **파일 저장** 카드를 찾고 클릭하여 편집하세요.
2. 제공자를 선택하세요: **Google Drive**, **Dropbox**, **OneDrive** 또는 **S3 호환 버킷** (AWS S3, Cloudflare R2, Backblaze B2 등).
3. Google Drive, Dropbox 또는 OneDrive의 경우, **연결**을 클릭하고 접근 권한을 부여하도록 로그인하세요. S3 호환 버킷의 경우, 접근 키, 비밀, 버킷 이름 및 공개 URL 베이스를 입력하세요.
4. **저장**을 클릭하세요.

:::info
이것은 웹사이트 파일 및 유사한 콘텐츠 영역에 대한 새 업로드에만 영향을 줍니다. 갤러리 이미지, 썸네일, 로고 및 사람 사진은 항상 B1의 기본 저장소에 남아 있습니다.
:::

## 학년 승격

자녀 및 학생에 대해 **학년**을 추적하는 경우, B1은 자동으로 당신이 선택한 날짜 (예: 8월 1일)에 모두를 한 학년씩 올릴 수 있습니다, 각 프로필을 수동으로 편집해야 하는 것 대신.

1. 설정 페이지에서 **학년 승격** 옵션을 찾으세요.
2. 스위치를 켜세요 (**활성화됨**을 표시) 그리고 매년 학년을 승격할 **월** 및 **일**을 선택하세요. 그 날, 학년이 있는 모든 사람은 한 학년씩 올라가고, 12학년은 **졸업**이 됩니다.
3. 변경 사항을 저장하세요.

자동 승격을 중지하려면, 스위치를 끄세요 (**비활성화됨**을 표시) 그리고 저장하세요. 승격 날짜가 제거되고 학년은 더 이상 자체적으로 변경되지 않습니다.

## 가져오기 및 내보내기

설정 헤더의 **가져오기/내보내기** 버튼은 새 브라우저 창에서 전용 도구를 엽니다. 이를 사용하여:

- 다른 교회 관리 시스템에서 멤버 데이터를 가져오세요.
- 백업 또는 마이그레이션 목적으로 ChurchApps 데이터를 내보내세요.

이는 처음 교회를 설정할 때와 기존 기록을 ChurchApps로 전송해야 할 때 특히 도움이 됩니다.

:::warning
데이터를 가져올 때는, 항상 먼저 기존 기록을 백업하세요. 가져오기 작업은 데이터를 시스템에 추가하고 여러 번 실행되는 경우 중복 항목을 만들 수 있습니다.
:::
