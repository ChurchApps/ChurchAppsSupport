# 교회 설정

<div class="article-intro">

교회 설정 페이지에서 교회의 기본 정보, 연락처 세부 정보, 브랜딩을 구성합니다. 이 정보는 B1.church 웹사이트와 B1 Mobile 앱을 포함하여 모든 ChurchApps 도구에서 사용됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- "Edit Church Settings" 권한이 필요합니다. 접근 권한이 없다면 [역할 및 권한](./roles-permissions.md)을 참조하세요.
- 교회의 주소, 연락처 정보, 로고를 미리 준비하세요.

</div>

## 교회 정보 편집하기

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Settings**를 펼친 다음 **Settings**를 클릭합니다.
2. (페이지 상단의) **Church Information** 섹션에서 **Edit**를 클릭합니다.
3. 다음 필드 중 원하는 항목을 수정합니다.
   - **Church Name** -- 모든 ChurchApps 제품에 표시되는 이름입니다.
   - **Address** -- 교회의 실제 주소입니다.
   - **Contact Information** -- 전화번호, 이메일 및 기타 연락처 세부 정보입니다.
4. **Save**를 클릭하여 변경 사항을 적용합니다.

## 서브도메인 설정하기

교회에는 **yourchurch.1.church** 형식의 무료 서브도메인이 제공됩니다. 이는 성도와 방문자가 교회의 온라인 페이지에 접속하는 웹 주소입니다.

1. 설정 페이지에서 **Church Information** 섹션의 **Edit**를 클릭하고 **Subdomain** 필드를 찾습니다.
2. 원하는 서브도메인을 입력합니다(예: gracechurch.1.church라면 "gracechurch").
3. 변경 사항을 저장합니다.

:::info
서브도메인은 모든 ChurchApps 교회에서 고유해야 합니다. 원하는 이름이 이미 사용 중이라면 도시나 주 이름을 추가해 보세요(예: "gracechurch-dallas").
:::

방문자가 자체 도메인(예: **`www.gracechurch.org`**)으로 사이트에 접속하기를 원한다면 [커스텀 도메인](./custom-domain.md)을 참조하세요.

## 브랜딩 설정하기

모든 ChurchApps 도구에서 교회가 보이는 방식을 맞춤 설정합니다.

1. 로고 영역을 클릭하고 이미지 파일을 선택하여 **church logo**(교회 로고)를 업로드합니다.
2. 웹사이트와 [모바일 앱](./mobile-app.md)에서 사용할 추가 **church images**(교회 이미지)를 추가합니다.

:::tip
가장 좋은 결과를 얻으려면 배경이 투명한 PNG 형식의 로고를 사용하세요. 밝은 배경과 어두운 배경 모두에서 잘 보입니다.
:::

## 한 주의 첫날

달력이 시작되는 요일을 선택합니다. Church Info 섹션의 **First Day of Week** 드롭다운 기본값은 **Sunday**이지만 어떤 요일로든 설정할 수 있습니다. 변경하면 B1 Admin과 B1.church 회원 포털의 달력 격자에 반영됩니다. 그룹 달력, 큐레이션 달력, 이벤트 편집기 모두 선택한 요일로 시작하는 주를 표시합니다.

## 지역(날짜 및 전화번호 형식)

**Region** 설정은 B1 전체에서 날짜와 시간이 표시되는 방식을 결정합니다. 기본값은 미국 형식이며(예: "Sep 28, 2026" 및 "9/28/2026"), 미국 외의 교회는 자국 형식으로 바꿀 수 있습니다. 예를 들어 English (United Kingdom)을 선택하면 "28 Sept 2026"과 "28/09/2026"으로 표시됩니다.

1. 설정 페이지에서 왼쪽 목록의 **Region**을 클릭한 다음 **Region** 섹션의 **Edit**를 클릭합니다.
2. **Region** 드롭다운에서 지역을 선택합니다. 각 옵션에는 샘플 날짜가 표시되어 날짜가 어떻게 보일지 정확히 확인할 수 있습니다.
3. **Save**를 클릭합니다.

그러면 Region 섹션에 선택한 지역, **Date format** 샘플, **Phone numbers** 형식이 표시됩니다.

### 전화번호 형식

같은 Region 섹션에는 사람의 기록에 전화번호를 입력하는 방식을 결정하는 **Phone numbers** 설정이 있습니다.

- **International (with country code)** -- 기본값입니다. 전화번호 필드에 국가 선택 도구가 표시되며, 번호를 국가 코드와 함께 저장합니다(예: +1 918 555 1234).
- **Local (as typed)** -- 전화번호 필드가 일반 텍스트 상자로 바뀌며, 입력한 그대로 국가 코드를 추가하지 않고 저장합니다(예: 0701 234 5678). 교회가 번호를 현지 형식으로 적고 B1이 국가 코드를 추가하지 않기를 원한다면 이 옵션을 선택하세요.

**Local**을 선택하면 Region 섹션에 지역 옆으로 "Local phone numbers"도 표시됩니다.

:::tip
문자 메시지는 번호에 국가 코드가 포함될 때 가장 잘 작동합니다. B1에서 문자를 보낸다면 **International** 형식을 유지하거나, Local 모드에서 입력하는 번호에 국가 코드가 포함되어 있는지 확인하세요.
:::

지역 설정은 B1 Admin과 B1.church 웹사이트 및 회원 포털 전체에서 날짜와 시간에 적용됩니다. 설교, 블로그 게시물, 그룹 달력, 서비스 계획이 포함되므로 성도도 직원과 같은 형식으로 날짜를 보게 됩니다.

## 문자 메시지 {#texting}

문자 서비스 제공업체를 연결하면 B1 Admin에서 한 사람이나 그룹 전체에 SMS를 보낼 수 있습니다. 문자는 제공업체와 맺은 자신의 계정을 통해 발송되므로 그 제공업체의 요금과 한도가 적용됩니다.

1. 설정 페이지에서 왼쪽 목록의 **Texting**을 클릭한 다음 **Texting** 섹션의 **Edit**를 클릭합니다.
2. **Provider**를 선택합니다.
   - **Clearstream** -- **API Key**를 입력합니다. Clearstream 계정 설정의 API Keys에서 만들 수 있습니다.
   - **Text In Church** -- **API Key**를 입력합니다. 먼저 Text In Church 지원팀에 개발자 API 접근을 요청한 다음, 계정 설정 > Developer API 섹션에서 키를 만드세요.
   - **Nalo Solutions** (가나) -- Nalo Solutions 계정의 인증 키를 **API Key**로, Nalo에서 승인받은 **Sender ID**(최대 11자)를 입력합니다.
3. **Save**를 클릭합니다.

문자 발송을 중지하려면 **Provider**를 **None**으로 설정하고 저장합니다. 저장된 제공업체가 제거됩니다.

### STOP으로 답장한 사람 수신 거부 처리하기

제공업체를 저장한 후에는 **Edit**로 Texting 섹션을 다시 엽니다. 제공업체 설정 아래에는 교회 고유의 웹 주소를 보여주는 읽기 전용 **Inbound (STOP) webhook URL** 필드가 있습니다. 필드를 클릭하여 주소를 선택하고 복사한 다음, 문자 제공업체의 수신 메시지(답장) webhook 설정에 붙여 넣으세요. 들어오는 답장을 webhook으로 전달할 수 있는 위의 모든 제공업체에서 작동합니다.

이후 누군가 교회의 문자에 **STOP**(또는 STOPALL, UNSUBSCRIBE, CANCEL, END, QUIT, OPTOUT, REVOKE)로 답장하면, B1은 휴대폰 번호가 일치하는 모든 사람을 찾아 수신 거부 상태로 표시하고 그들의 문자 알림을 끕니다. 이후 그룹 문자에서는 이들이 제외됩니다. 다른 답장은 무시됩니다.

:::info
이 기능은 **Hide me from the member directory**와 같은 수신 거부 설정을 사용하므로, STOP으로 답장한 사람은 프로필에 **Hidden from directory**로도 표시됩니다. 이 필드는 저장된 제공업체가 선택되어 있을 때만 나타납니다. 드롭다운을 다른 제공업체로 바꾸면 URL을 다시 보기 전에 먼저 저장하세요.
:::

제공업체가 연결되면 문자 발송 권한이 있는 직원은 그룹 페이지(**Text this group**)와 휴대폰 번호가 있는 사람의 페이지(**Send text message**)에서 **Text** 버튼을 보게 됩니다. 메시지를 입력하고 **Send**를 클릭하세요. 대화상자에서 글자 수와 SMS 세그먼트 수를 계산합니다. 그룹의 경우 보내기 전에 문자를 받을 회원 수를 보여줍니다.

- 휴대폰 번호가 등록되어 있지 않은 회원은 건너뜁니다.
- **Hide me from the member directory**를 선택한 회원은 수신 거부된 것으로 계산되어 건너뜁니다.
- 같은 휴대폰 번호를 공유하는 가족 구성원에게는 문자가 한 번만 전송됩니다.

### 병합 필드로 문자 개인화하기 {#personalizing-texts-with-merge-fields}

메시지 상자 아래의 Text 대화상자에는 자리 표시자 칩이 있습니다. **First Name**, **Last Name**, **Display Name**, **Church Name**입니다. 칩을 클릭하면 커서 위치에 자리 표시자(`{{firstName}}`, `{{lastName}}`, `{{displayName}}`, `{{churchName}}`)가 삽입됩니다. 문자가 발송되면 각 자리 표시자는 수신자의 정보로 바뀌므로, `Hi {{firstName}}, see you Sunday!`와 같은 그룹 문자가 각 회원에게 그 사람의 이름으로 전달됩니다. 자리 표시자는 그룹 문자와 개인 문자 모두에서 작동합니다.

:::info
1,600자 제한은 입력한 메시지에 적용됩니다. 자리 표시자가 채워진 후 1,600자를 넘는 문자는 그 길이에서 잘립니다.
:::

문자는 [워크플로](../serving/workflows.md#sending-a-text) 단계의 **Send Text** 동작으로도 자동 발송할 수 있으며, 이때 같은 제공업체와 자리 표시자를 사용합니다.

## 파일 저장소

기본적으로 웹사이트 [파일](../website/files.md) 및 기타 콘텐츠 영역에 업로드하는 파일은 최대 100MB까지 B1의 무료 호스팅 저장소를 사용합니다. 더 많은 공간이 필요하다면 대신 자신의 클라우드 저장소를 연결할 수 있습니다. 그러면 새 업로드가 플랫폼 제한 없이 계정으로 바로 저장됩니다.

1. 설정 페이지에서 왼쪽 목록의 **File Storage**를 클릭한 다음 **File Storage** 섹션의 **Edit**를 클릭합니다.
2. 제공업체를 선택합니다. **Google Drive**, **Dropbox**, **OneDrive**, 또는 **S3 호환 버킷**(AWS S3, Cloudflare R2, Backblaze B2 등)입니다.
3. Google Drive, Dropbox, OneDrive의 경우 **Connect**를 클릭하고 로그인하여 접근을 승인합니다. S3 호환 버킷의 경우 액세스 키, 시크릿, 버킷 이름, 공개 URL 기본 경로를 입력합니다.
4. **Save**를 클릭합니다.

:::info
이 설정은 웹사이트 파일과 유사한 콘텐츠 영역에 대한 새 업로드에만 영향을 줍니다. 갤러리 이미지, 썸네일, 로고, 사람 사진은 항상 B1의 기본 저장소에 남습니다.
:::

## 학년 진급

어린이와 학생의 **Grade**(학년)를 추적한다면, B1은 각 프로필을 일일이 수정하지 않아도 선택한 날짜(예: 8월 1일)에 모든 사람을 한 학년씩 자동으로 올릴 수 있습니다.

1. 설정 페이지에서 왼쪽 목록의 **Grade Promotion**을 클릭한 다음 **Grade Promotion** 섹션의 **Edit**를 클릭합니다.
2. 스위치를 켜고(**Enabled**로 표시됨) 매년 학년을 올릴 **Month**와 **Day**를 선택합니다. 그 날짜에 학년이 있는 모든 사람은 한 학년 올라가며, 12학년은 **Graduated**가 됩니다.
3. 변경 사항을 저장합니다.

자동 진급을 중지하려면 스위치를 꺼서 **Disabled**로 표시되게 한 후 저장합니다. 진급 날짜가 제거되며 학년은 더 이상 자동으로 바뀌지 않습니다.

## 봉사자 신청 {#volunteer-signup}

기본적으로 [봉사자 신청](../../b1-church/serving/volunteer-signup.md)을 둘러보는 회원은 빈 포지션이 있는 앞으로의 모든 주를 봅니다. 목록이 길어지면 대신 계획 유형별로 다음 한 주만 표시할 수 있습니다.

1. 설정 페이지에서 왼쪽 목록의 **Volunteer Signup**을 클릭한 다음 **Volunteer Signup** 섹션의 **Edit**를 클릭합니다.
2. **Show only the next week of each plan type**을 켭니다.
3. 변경 사항을 저장합니다.

이 설정을 켜면 각 계획 유형은 다음에 다가오는 계획 하나만 표시합니다. 그 날짜가 지나면 다음 주가 나타납니다. 섹션의 **Weeks shown** 행에는 **Only the next week of each plan type** 또는 **All upcoming weeks**가 표시됩니다.

## 헌금 개인정보 보호 {#giving-privacy}

헌금 접근 권한이 있는 사람은 보통 [사람 기록](../people/adding-people.md#editing-details)에서 그 사람의 헌금 합계를 볼 수 있습니다. 기록을 열 때마다 금액이 화면에 표시되는 것을 원치 않는다면, 누군가 요청하기 전까지 금액을 숨길 수 있습니다.

1. 설정 페이지에서 왼쪽 목록의 **Giving privacy**를 클릭한 다음 **Giving privacy** 섹션의 **Edit**를 클릭합니다.
2. **Hide giving on person records until clicked**를 켭니다.
3. 변경 사항을 저장합니다.

이 설정을 켜면 사람 기록의 헌금 카드에 "Giving is hidden on person records."(사람 기록에서 헌금이 숨겨져 있습니다.)가 표시됩니다. **Show giving**을 클릭하면 그 사람의 헌금이 불러와져 표시됩니다. 다른 사람의 기록을 열면 다시 숨겨집니다. 헌금을 볼 수 있는 사람이 바뀌지는 않습니다. 헌금 접근 권한이 있는 사람만 카드를 볼 수 있습니다.

## 가져오기 및 내보내기

설정 페이지에서 교회 이름 아래의 **Import/Export** 링크를 클릭하면 새 브라우저 창에서 전용 도구가 열립니다. 이 도구로 다음을 할 수 있습니다.

- 다른 교회 관리 시스템에서 회원 데이터를 가져오기
- 백업이나 이전 목적으로 ChurchApps 데이터 내보내기

교회를 처음 설정하면서 기존 기록을 ChurchApps로 옮겨야 할 때 특히 유용합니다.

:::warning
데이터를 가져오기 전에 반드시 기존 기록을 먼저 백업하세요. 가져오기 작업은 시스템에 데이터를 추가하며, 여러 번 실행하면 중복 항목이 생길 수 있습니다.
:::
