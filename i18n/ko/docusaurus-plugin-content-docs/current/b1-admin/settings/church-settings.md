# 교회 설정
<div class="article-intro">
교회 설정 페이지는 교회의 기본 정보, 연락처, 브랜딩을 구성하는 곳입니다. 이 세부 정보는 모든 ChurchApps 도구에서 사용됩니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- "교회 설정 편집" 권한이 필요합니다
- 교회의 주소, 연락처 정보, 로고를 준비합니다
</div>
## 교회 정보 편집
1. B1 Admin에서 **섹션 메뉴**를 열고 **설정**을 선택합니다
2. 헤더에서 **설정 편집** 버튼을 클릭합니다
3. 다음 필드를 업데이트합니다:
   - **교회 이름** — 모든 ChurchApps 제품에서 표시되는 이름
   - **주소** — 교회의 물리적 주소
   - **연락처 정보** — 전화 번호, 이메일, 기타 세부 정보
4. **저장**을 클릭하여 변경 사항을 적용합니다
## 서브도메인 설정
교회는 **yourchurch.b1.church**에서 무료 서브도메인을 받습니다.
1. 설정 페이지에서 **서브도메인** 필드를 찾습니다
2. 원하는 서브도메인을 입력합니다 (예: "gracechurch")
3. 변경 사항을 저장합니다
## 브랜딩 구성
1. **교회 로고**를 업로드합니다
2. 추가 **교회 이미지**를 추가합니다
:::tip
최상의 결과를 위해 투명 배경이 있는 PNG 로고를 사용합니다.
:::
## 파일 저장소
기본적으로 100MB 무료 저장소를 사용합니다. 더 많은 공간이 필요한 경우, 자신의 클라우드 저장소를 연결할 수 있습니다.
