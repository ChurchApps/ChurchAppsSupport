# 데이터 보안

<div class="article-intro">

완벽하게 안전한 시스템은 없지만, ChurchApps는 데이터 보안을 진지하게 생각합니다. 이 페이지는 B1.church Admin과 기타 ChurchApps 제품에 입력된 모든 데이터를 보호하기 위해 취하는 조치를 설명합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 이 페이지를 읽고 교회의 데이터가 어떻게 보호되는지 이해하세요
- 민감한 정보에 누가 접근할 수 있는지 제어하기 위해 [역할 및 권한](./roles-permissions.md)을 설정하세요
- [개인정보 처리방침](https://churchapps.org/privacy)을 익혀 두세요

</div>

## 민감한 데이터의 저장 최소화 {#limiting-sensitive-data-stored}

우리의 첫 번째 접근 방식은 필요 이상으로 민감한 데이터를 저장하지 않는 것입니다. 즉, 헌금에 사용된 신용카드나 은행 계좌 정보는 절대 저장하지 않습니다. 사용자가 B1.church Admin이나 B1에서 헌금을 할 때, 신용카드 정보는 저희 서버로 전송되지 않고 결제 게이트웨이(Stripe)로만 전송됩니다. 따라서 데이터 유출 사고가 나더라도 신용카드나 은행 정보는 노출되지 않습니다.

또한 저희 시스템에는 비밀번호를 저장하지 않습니다. 모든 비밀번호는 일부 데이터를 파기하는 단방향 해시 알고리즘으로 처리되므로, 저희를 포함한 누구도 데이터베이스에서 비밀번호를 되찾을 수 없습니다. 비밀번호를 확인하려면 입력된 값을 같은 단방향 해시에 통과시켜 같은 결과가 나와야 합니다.

이 두 가지 출처를 제외하면 남는 민감한 데이터는 이름과 연락처 정보 목록뿐입니다.

:::tip
ChurchApps는 신용카드나 은행 정보를 저장하지 않으므로, 최악의 데이터 유출 사고가 나더라도 금융 계좌 정보는 노출되지 않습니다. 위험에 놓이는 것은 이름과 연락처 정보뿐입니다.
:::

## 표준 모범 사례 사용 {#using-standard-best-practices}

저희는 업계 표준 보안 모범 사례를 사용합니다. 여기에는 HTTPS를 사용하여 서버로 주고받는 모든 데이터를 암호화하는 것이 포함됩니다. 모든 서버는 Amazon Web Services의 안전한 물리적 데이터센터에서 호스팅됩니다. 모든 데이터베이스 서버는 방화벽 뒤에 있어 인터넷에서 접근할 수 없습니다.

## 데이터 분리 {#data-segregation}

데이터는 범위에 따라 서로 다른 데이터베이스로 분리됩니다. 각 모듈(Membership(회원), Giving(헌금), Attendance(출석), Messaging(메시지), Doing(실행), Content(콘텐츠))은 자체 데이터베이스를 가진 독립된 데이터 사일로입니다. 한 모듈이 침해되더라도, 다른 모듈까지 침해되지 않으면 데이터의 활용 가치는 제한됩니다. 예를 들어 Giving API/데이터베이스가 침해되면, 악의적인 사용자는 헌금 목록과 날짜에 접근할 수 있지만(카드나 계좌 정보는 절대 없습니다), 누가 헌금했는지나 어느 교회를 위한 헌금인지는 알 수 없습니다. 그 정보는 별도의 Membership 데이터베이스에 저장되어 있기 때문입니다.

:::info
데이터 분리란 한 시스템이 침해되어도 모든 교회 데이터에 접근할 수 없다는 뜻입니다. 각 API는 자체 데이터베이스를 가지고 독립적으로 작동하므로, 잠재적인 침해의 영향이 제한됩니다.
:::

## 제한된 접근 {#limited-access}

운영 서버에 대한 접근은 접근이 필요한 서버 관리자로만 엄격하게 제한됩니다. 현재 이 권한을 가진 사람은 이사회 구성원인 두 명입니다. 개발자, 자원봉사자, 그 밖의 이사회 구성원은 운영 서버에 접근할 수 없습니다.

## 개인정보 처리방침 {#privacy-policy}

여러분의 데이터는 여러분의 것이며, 제3자에게 절대 판매되지 않습니다. 전체 개인정보 처리방침은 [여기](https://churchapps.org/privacy)에서 읽을 수 있습니다.

## GDPR 준수 {#gdpr-compliance}

ChurchApps는 영국이나 유럽연합에 구성원이 있는 교회를 위해 GDPR 준수를 지원합니다. 주요 요구 사항을 다루는 방법은 다음과 같습니다.

### 정보 주체의 권리 {#data-subject-rights}

ChurchApps는 교회가 정보 주체의 요청에 응답할 수 있도록 도구를 제공합니다.

- **열람권(제15조)** — 구성원은 교회에 연락하여 자신의 개인 데이터 사본을 요청할 수 있습니다. 관리자는 B1.church Admin에서 사람의 기록에 있는 **Export Data**(데이터 내보내기)나, 사람의 편집 양식의 **Data Management**(데이터 관리) 섹션을 통해 누구의 데이터든 내보낼 수 있습니다.
- **삭제권(제17조)** — 구성원은 프로필 페이지에서 직접 계정 삭제를 요청하거나([계정 삭제 요청 검토](../profile/account-deletion.md) 참고), 교회에 직접 연락하여 요청할 수 있습니다. 관리자는 사람 상세 페이지의 **Data Management** 섹션에서 모든 모듈에 걸쳐 사람의 데이터를 익명화할 수도 있습니다. 익명화는 개인 정보를 일반적인 값으로 바꾸되, 교회의 재정 보고에 필요한 집계 기록(헌금 합계, 출석 횟수)은 보존합니다.
- **처리 제한권(제18조)** — 구성원은 교회에 연락하여, 통신 수신 거부를 포함한 처리 제한을 요청할 수 있습니다.
- **데이터 이동권(제20조)** — 관리자는 요청한 구성원을 대신하여 개인 데이터를 구조화되고 기계가 읽을 수 있는 JSON 형식으로 내보낼 수 있습니다.

### 데이터 관리 도구 사용하기 {#using-the-data-management-tools}

개인의 GDPR 데이터 도구에 접근하려면:

1. B1 Admin에서 **People**(사람)로 이동하여 사람의 기록을 여세요.
2. **Edit**(편집)를 클릭하여 편집 모드로 들어가세요.
3. 기본적으로 접혀 있는 **Data Management**(데이터 관리) 섹션까지 아래로 스크롤하고, 클릭하여 펼치세요.
4. **Export Data**(데이터 내보내기)를 사용하여 그 사람에 대해 저장된 모든 데이터가 담긴 JSON 파일을 다운로드하세요. (편집 양식을 열지 않고도, 사람의 이름 아래 작업 목록에서 같은 **Export Data** 링크를 사용할 수 있습니다.)
5. **Anonymize**(익명화)를 사용하여 개인 정보를 일반적인 값으로 바꾸세요. 확인하려면 `ANONYMIZE`를 입력해야 합니다. 이 작업은 되돌릴 수 없습니다.

:::warning
익명화는 영구적입니다. 재정 보고를 위해 헌금 합계와 출석 횟수는 보존되지만, 모든 개인 식별 정보(이름, 이메일, 주소 등)는 제거되며 복구할 수 없습니다.
:::

### 데이터 처리 {#data-processing}

ChurchApps는 교회(**데이터 관리자**)를 대신하여 **데이터 처리자**의 역할을 합니다. [데이터 처리 계약](https://churchapps.org/terms)은 하위 처리자 사용, 침해 통지 절차, 계약 종료 시 데이터 처리 등 각 당사자의 책임을 설명합니다.

### 국제 데이터 이전 {#international-data-transfers}

ChurchApps 데이터는 미국의 Amazon Web Services(AWS)에서 호스팅됩니다. 영국/EU에서의 국제 데이터 이전은 [AWS 데이터 처리 부록](https://aws.amazon.com/compliance/data-processing-addendum/)에 따라 AWS의 표준 계약 조항(SCC)으로 보호됩니다. AWS DPA는 모든 고객의 AWS 서비스 약관에 자동으로 포함됩니다. SCC와 같은 적절한 이전 메커니즘이 있다면 EU 기반 호스팅은 필요하지 않습니다.

이전 위험을 어떻게 평가했는지에 대한 자세한 내용은 [이전 위험 평가](./transfer-risk-assessment.md)를 참고하세요.

### 하위 처리자 {#sub-processors}

- **Amazon Web Services (AWS)** — 인프라 호스팅, 데이터 저장, 콘텐츠 전달
- **Stripe** — 헌금 결제 처리(ChurchApps는 카드 데이터를 저장하지 않습니다)

:::info
개인 데이터 처리에 대한 자세한 내용은 [개인정보 처리방침](https://churchapps.org/privacy)과 [서비스 약관](https://churchapps.org/terms)을 참고하세요. GDPR 준수에 대해 질문이 있다면 support@churchapps.org로 연락하세요.
:::
