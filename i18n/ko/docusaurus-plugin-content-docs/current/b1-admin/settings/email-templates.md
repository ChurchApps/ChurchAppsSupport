# 이메일 템플릿

<div class="article-intro">

이메일 템플릿을 사용하면 환영 메시지, 이벤트 알림, 기부금 감사 등의 재사용 가능한 이메일 콘텐츠를 저장할 수 있으므로 매번 처음부터 작성하는 대신 한 번의 클릭으로 보낼 수 있습니다([워크플로우](../serving/workflows.md) 또는 직접).

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin의 설정 영역에 접근해야 합니다.

</div>

## 이메일 템플릿 접근

1. B1 Admin에서 **섹션 메뉴**(왼쪽 위 모서리의 섹션 이름 옆 작은 화살표)를 열고 **설정**을 선택합니다.
2. **이메일 템플릿**을 클릭합니다.
3. 주제, 카테고리 및 마지막 수정 날짜와 함께 기존 템플릿 목록이 표시됩니다.

## 템플릿 만들기

1. **새 템플릿**을 클릭합니다.
2. **템플릿 이름**을 입력하여 목록에서 식별하고, **카테고리**(일반, 이벤트, 그룹, 기부금 또는 환영)를 선택하여 템플릿을 구성합니다.
3. **제목** 줄을 입력합니다.
4. 리치 텍스트 편집기를 사용하여 **본문**을 작성합니다.
5. **저장**을 클릭합니다.

## 병합 필드

제목 또는 본문 위의 병합 필드 칩을 클릭하여 커서의 위치에 삽입합니다. 이메일을 보낼 때 각 병합 필드는 수신자의 실제 정보로 대체됩니다:

- `{{firstName}}`, `{{lastName}}`, `{{displayName}}` -- 수신자의 이름
- `{{email}}` -- 수신자의 이메일 주소
- `{{churchName}}` -- 교회 이름

## 템플릿 미리보기

**미리보기**를 클릭하여 저장하거나 보내기 전에 제목과 본문이 병합 필드에 샘플 데이터가 어떻게 표시되는지 확인합니다.

## 템플릿 사용

저장된 템플릿은 사람 또는 그룹에 이메일을 작성할 때 선택할 수 있으며, [워크플로우](../serving/workflows.md)의 작업으로도 사용할 수 있습니다.

## 편집 및 삭제

템플릿 옆의 **편집** 아이콘을 클릭하여 업데이트하거나 **삭제** 아이콘을 클릭하여 영구적으로 제거합니다.
