# 이메일 템플릿

<div class="article-intro">

이메일 템플릿을 사용하면 환영 메시지, 이벤트 알림, 후원 감사 인사 등 재사용 가능한 이메일 내용을 저장할 수 있어, 매번 처음부터 작성하는 대신 (당신 또는 [워크플로우](../serving/workflows.md)가) 클릭 한 번으로 보낼 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin의 설정 영역에 대한 접근 권한이 필요합니다.

</div>

## 이메일 템플릿에 접근하기

1. 왼쪽 사이드바에서 **설정**으로 이동하세요.
2. **이메일 템플릿**을 클릭하세요.
3. 제목, 카테고리, 마지막 수정일이 함께 표시된 기존 템플릿 목록이 보입니다.

## 템플릿 만들기

1. **새 템플릿**을 클릭하세요.
2. 목록에서 식별할 수 있도록 **템플릿 이름**을 입력하고, 템플릿을 정리하는 데 도움이 되는 **카테고리**(일반, 이벤트, 그룹, 후원, 또는 환영)를 선택하세요.
3. **제목** 줄을 입력하세요.
4. 서식 있는 텍스트 편집기를 사용하여 **본문**을 작성하세요.
5. **저장**을 클릭하세요.

## 병합 필드

제목이나 본문 위의 병합 필드 칩을 클릭하면 커서 위치에 삽입됩니다. 이메일이 발송되면 각 병합 필드는 수신자의 실제 정보로 대체됩니다:

- `{{firstName}}`, `{{lastName}}`, `{{displayName}}` -- 수신자의 이름
- `{{email}}` -- 수신자의 이메일 주소
- `{{churchName}}` -- 교회의 이름

## 템플릿 미리보기

**미리보기**를 클릭하면 저장하거나 발송하기 전에 병합 필드에 샘플 데이터가 채워진 제목과 본문이 어떻게 보일지 확인할 수 있습니다.

## 템플릿 사용하기

저장된 템플릿은 사람이나 그룹에게 이메일을 작성할 때 선택할 수 있으며, [워크플로우](../serving/workflows.md)의 작업으로도 사용할 수 있습니다.

## 편집 및 삭제

템플릿 옆의 **편집** 아이콘을 클릭하여 업데이트하거나, **삭제** 아이콘을 클릭하여 영구적으로 제거하세요.
