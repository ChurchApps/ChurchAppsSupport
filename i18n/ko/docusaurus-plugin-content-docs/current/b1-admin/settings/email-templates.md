# 이메일 템플릿

<div class="article-intro">

이메일 템플릿은 재사용 가능한 이메일 콘텐츠를 저장합니다 -- 환영 메시지, 이벤트 미리 알림, 헌금 감사 -- 따라서 당신 (또는 [워크플로우](../serving/workflows.md))이 매번 처음부터 작성하는 대신 한 번의 클릭으로 보낼 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin의 설정 영역에 액세스해야 합니다.

</div>

## 이메일 템플릿 액세스

1. B1 Admin에서 왼쪽 상단의 **섹션 메뉴** (작은 화살표가 있는 섹션 이름)를 열고 **설정**을 선택하세요.
2. **이메일 템플릿**을 클릭하세요.
3. 제목, 카테고리 및 마지막 수정 날짜가 있는 기존 템플릿 목록을 볼 수 있습니다.

## 템플릿 만들기

1. **새 템플릿**을 클릭하세요.
2. **템플릿 이름**을 입력하여 목록에서 식별하고, **카테고리** (일반, 이벤트, 그룹, 헌금 또는 환영)를 선택하여 템플릿을 구성합니다.
3. **제목** 줄을 입력하세요.
4. 리치 텍스트 편집기를 사용하여 **본문**을 작성하세요.
5. **저장**을 클릭하세요.

## 병합 필드

제목 또는 본문 위의 병합 필드 칩을 클릭하여 커서에 삽입합니다. 이메일이 전송될 때 각 병합 필드는 수신자의 실제 정보로 바뀝니다:

- `{{firstName}}`, `{{lastName}}`, `{{displayName}}` -- 수신자의 이름
- `{{email}}` -- 수신자의 이메일 주소
- `{{churchName}}` -- 교회의 이름

## 템플릿 미리 보기

**미리 보기**를 클릭하여 저장 또는 전송하기 전에 병합 필드에 샘플 데이터가 입력된 상태에서 제목과 본문이 어떻게 보이는지 확인하세요.

## 템플릿 사용

저장된 템플릿은 사람 또는 그룹에 이메일을 작성할 때 선택할 수 있으며 [워크플로우](../serving/workflows.md)의 작업으로도 사용 가능합니다. 교회가 이들을 보낼 수 있기 전에 ChurchApps 팀은 그룹 이메일에 대해 한 번 이를 승인해야 합니다. [교회용 그룹 이메일 켜기](../groups/group-members.md#turning-on-group-email-for-your-church)를 참조하세요.

## 편집 및 삭제

템플릿 옆의 **편집** 아이콘을 클릭하여 업데이트하거나 **삭제** 아이콘을 클릭하여 영구적으로 제거하세요.
