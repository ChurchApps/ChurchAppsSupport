# 모바일 앱 설정 {#mobile-app-settings}

<div class="article-intro">

모바일 앱 설정 페이지에서는 교회 회원이 **B1.church 모바일 환경(PWA)**에서 보게 될 탐색 탭을 구성할 수 있습니다. 어떤 탭이 보일지, 어디로 연결될지, 어떻게 표시될지를 직접 제어합니다.

</div>

:::info 기본 B1 Mobile 앱은 더 이상 권장되지 않습니다
여기서 설정한 탭은 기본 B1 Mobile 앱을 대체한 [B1.church 프로그레시브 웹 앱(PWA)](/docs/b1-church/getting-started/installing-pwa)을 통해 전달됩니다. 교회의 설치 페이지 — `https://yourchurchname.b1.church/mobile/install` — 를 회원과 공유하세요. 이 페이지는 App Store나 Google Play에서 내려받을 필요 없이 기기에 앱을 설치하는 방법을 안내합니다.
:::

<div class="prereqs">
<h4>시작하기 전에</h4>

- "교회 설정 편집" 권한이 필요합니다. 접근 권한이 없다면 [역할 및 권한](./roles-permissions.md)을 참조하세요.
- 먼저 교회 이름과 브랜딩을 포함하여 [교회 설정](./church-settings.md)을 구성하세요.

</div>

## 탐색 설정 열기 {#accessing-navigation-settings}

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **모바일**을 펼칩니다.
2. **탐색**(`/mobile/navigation`)을 클릭합니다.
3. 탐색 페이지에 현재 앱 탭이 표시됩니다.

## 새 탭 추가하기 {#adding-a-new-tab}

1. 페이지 상단의 **탭 추가** 버튼을 클릭합니다.
2. 탭 세부 정보를 입력합니다.
   - **이름** -- 탭에 표시되는 이름입니다(예: "설교" 또는 "헌금하기").
   - **아이콘** -- 아이콘 선택기를 클릭하여 탭의 아이콘을 고릅니다.
   - **이미지** -- **이미지 선택**(또는 **이미지 변경**)을 클릭하여 탭에 사진을 넣습니다. 사진이 있는 탭은 앱의 홈 화면에 사진 타일로 나타납니다. [홈 화면 타일](#home-screen-tiles)을 참조하세요.
   - **탭 유형** -- 성경, 라이브 스트림, 헌금, 웹사이트 등 옵션 중에서 선택합니다.
   - **URL** -- 탭이 연결할 웹 주소를 입력합니다.
   - **표시 여부** -- 누가 이 탭을 볼 수 있는지 제어합니다(모든 사람, 회원만 등). **회원 디렉터리** 탭의 경우, 이 설정은 탭 자체를 누가 보는지만 제어합니다. 디렉터리를 누가 열 수 있는지는 회원 포털 페이지의 **디렉터리에 표시**로 설정합니다([회원 디렉터리 및 메시지 설정](#member-directory--messaging-settings) 참조).
3. **탭 저장**을 클릭하여 앱에 추가합니다.

## 기존 탭 편집하기 {#editing-an-existing-tab}

1. **앱 탭** 목록에서 기존 탭을 클릭합니다.
2. 탭의 이름, 아이콘, URL, 유형 또는 표시 설정을 업데이트합니다.
3. **탭 저장**을 클릭하여 변경 사항을 적용합니다.

## 탭 순서 바꾸기 {#reordering-tabs}

모바일 앱에서 탭이 나타나는 순서를 바꿀 수 있습니다. 목록에서 탭을 끌어다 놓아 재배열하세요. 이 페이지에 표시되는 순서가 회원이 앱에서 보는 순서와 같습니다.

:::info
특정 조건이 충족되면 일부 탭이 자동으로 나타날 수 있습니다. 예를 들어 라이브 스트림이 활성화되면 라이브 스트림 탭이 나타날 수 있습니다. 직접 추가한 탭은 회원이 항상 보는 내용을 완전히 제어할 수 있게 해 줍니다.
:::

:::tip
탭 개수는 관리하기 쉬운 수로 유지하세요. 대부분의 교회에는 3~5개가 잘 맞습니다. 탭이 너무 많으면 회원이 탐색하기 혼란스러울 수 있습니다.
:::

## 회원 디렉터리 및 메시지 설정 {#member-directory--messaging-settings}

같은 모바일 섹션의 **회원 포털** 항목에는 B1.church 환경에서 회원 디렉터리와 개인 메시지를 관리하는 설정이 있습니다.

- **디렉터리 승인 그룹** -- 회원 디렉터리 업데이트와 [계정 삭제 요청](../profile/account-deletion.md)을 적용되기 전에 검토하는 그룹입니다.
- **디렉터리에 표시** -- 누가 회원 디렉터리를 열고, 누가 그 안에 나열되는지를 정합니다. **직원만**, **회원 및 직원**(기본값), **정기 참석자 이상**, **모든 사람(방문자 포함)** 중에서 선택할 수 있습니다. 교인 상태가 선택한 수준보다 낮은 사람은 디렉터리를 볼 수 없으며 목록에도 나타나지 않습니다. 사람 &gt; 보기 권한이 있는 직원은 이 설정과 상관없이 항상 디렉터리를 열고 모든 사람을 볼 수 있습니다.
- **공개 설정** -- 아직 자신의 설정을 고르지 않은 회원에 대한 교회 전체 기본값을 정합니다. **주소**, **전화번호**, **이메일**은 각각 드롭다운이 있으며, 공개 설정이 적용되는 모든 곳에서 같은 다섯 단계를 사용할 수 있습니다.
  - **모든 사람** -- 익명 방문자를 포함하여 누구에게나 보입니다
  - **회원** -- 회원 또는 직원 기록이 있는 사람에게만 보입니다
  - **그룹 구성원만** -- 이 사람과 같은 그룹에 속한 사람에게만 보입니다
  - **내 그룹 리더 및 직원** -- 이 사람이 속한 그룹의 리더와 직원에게만 보입니다
  - **직원만** -- 사람 &gt; 보기 권한이 있는 직원과 본인에게만 보입니다

  회원은 B1.church PWA의 프로필 **개인정보 보호** 탭에서 자신의 기록에 대해 이 기본값을 재정의할 수 있습니다. [프로필 편집하기](/docs/b1-church/getting-started/me-page)를 참조하세요.
- **개인 메시지 최소 연령** -- 아동 보호 설정입니다. 두 사람 중 한 명이라도 생년월일 기준으로 이 나이 미만이면, B1은 **새로운** 개인 메시지 대화를 열지 않습니다(생년월일이 없는 경우 가구 역할을 대신 사용합니다). 해당 연령 미만의 사람도 디렉터리에는 완전히 보이며, 차단되는 것은 **양방향**의 직접 메시지뿐입니다. 직원을 포함한 모든 사람에게 해당합니다. 그룹 대화와 자녀의 부모에게 보내는 메시지는 여전히 가능합니다. 선택지는 끄기, 13, 16, 18이며 기본값은 **18**입니다. 기존 대화에는 영향을 주지 않습니다.

:::tip
최소 연령 검사는 생년월일에 의존하므로, 교회의 자녀에 대한 생년월일이 입력되어 있는지 확인하세요. 이 설정은 [체크인 안전 설정](../attendance/checkin-safety.md)과 같은 아동 보호 설정 계열에 속합니다.
:::

### 홈 화면 로그인 안내 {#home-screen-sign-in-prompt}

로그인하지 않은 채 앱의 [홈 화면](/docs/b1-church/getting-started/navigating#home)을 여는 방문자는 **로그인** 버튼 옆에 짧은 안내를 보게 됩니다. 기본 문구는 *"그룹, 헌금 등을 보려면 로그인하세요."*입니다. 같은 회원 포털 페이지(`/mobile/b1-mobile`)의 **홈 화면 로그인 안내** 설정으로 이를 바꿀 수 있습니다.

- **앱 홈 화면에 로그인 안내 표시** -- 끄면 홈 화면에서 안내와 **로그인** 버튼이 모두 사라집니다. 방문자는 여전히 앱 메뉴에서 로그인할 수 있습니다.
- **로그인 안내 문구** -- 기본 문구를 직접 작성한 메시지로 바꿉니다(최대 150자). 비워 두면 기본 문구를 사용합니다. 안내를 끄면 이 상자는 비활성화됩니다.

**저장**을 클릭하여 적용합니다. 저장하면 앱의 캐시된 설정이 새로 고쳐지므로, 변경 사항은 홈 화면이 다음에 로드될 때 나타납니다.

### 홈 화면 타일 {#home-screen-tiles}

사진이 있는 탭([새 탭 추가하기](#adding-a-new-tab)의 **이미지** 참조)은 앱의 [홈 화면](/docs/b1-church/getting-started/navigating#home)에 교회 이름이 머리글인 섹션 안에 사진 타일로 나타납니다. 사진을 넣은 "오늘의 말씀" 탭도 여기에 포함됩니다. 사진이 있는 탭은 탭 바에도 함께 나타납니다.

같은 회원 포털 페이지(`/mobile/b1-mobile`)의 **홈 화면 타일** 설정은 이 타일이 배치되는 방식을 제어합니다. **레이아웃**을 고르세요.

- **격자** -- 한 줄에 두 개의 타일(기본값)입니다. 타일 개수가 홀수이면 첫 타일이 전체 너비를 차지합니다.
- **가로 스크롤 줄** -- 회원이 옆으로 밀어 넘기는 한 줄의 타일입니다.
- **목록** -- 각 탭 이름 옆에 작은 사진 썸네일이 있는 목록입니다.

**저장**을 클릭하여 적용합니다.

## 이 탭이 나타나는 곳 {#where-these-tabs-appear}

여기서 설정한 탭은 회원이 `https://yourchurchname.b1.church`의 어떤 페이지에서든 설치하는 **B1.church PWA**에 표시됩니다. 이 페이지에서 바꾼 내용은 회원이 앱을 다음에 열 때 반영됩니다.

휴대폰에서는 하단 탭 바에 **홈**, 탭 최대 3개, **더보기**가 표시되며, 컴퓨터에서는 머리글에 최대 5개가 표시됩니다. 기본 제공 화면(설교, 헌금, 그룹 등)이 먼저 자리를 차지하고, 남는 자리는 **내부 페이지** 탭이 채웁니다. **외부 URL**과 **오늘의 말씀** 탭은 자리를 차지하지 못합니다. 자리에 들어가지 못한 탭을 포함한 모든 탭은 앱의 **더보기** 페이지에 나열됩니다. 회원에게 보이는 모습은 [B1App 둘러보기](/docs/b1-church/getting-started/navigating)를 참조하세요. (탭은 아직 기본 B1 Mobile 네이티브 앱을 사용하는 회원을 위해 기존 [B1 Mobile 네이티브 앱](/docs/b1-mobile/)에도 표시되지만, 해당 앱은 더 이상 권장되지 않으며 업데이트되지 않습니다.)
