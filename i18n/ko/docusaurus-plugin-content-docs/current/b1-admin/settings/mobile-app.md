# 모바일 앱 설정

<div class="article-intro">

모바일 앱 설정 페이지는 교회 멤버를 위해 **B1.church 모바일 환경 (PWA)**에 나타나는 네비게이션 탭을 구성할 수 있도록 합니다. 어떤 탭이 보이는지, 어디로 연결되는지, 그리고 어떻게 표시되는지를 제어합니다.

</div>

:::info 네이티브 B1 모바일 앱이 더 이상 제공됩니다
여기에서 구성된 탭은 네이티브 B1 모바일 앱을 대체한 [B1.church Progressive Web App (PWA)](/docs/b1-church/getting-started/installing-pwa)를 통해 전달됩니다. 교회 설치 페이지를 멤버와 공유하세요 -- `https://yourchurchname.b1.church/mobile/install` -- 이는 앱 스토어 또는 Google Play 다운로드 없이 장치에 앱을 설치하는 과정을 안내합니다.
:::

<div class="prereqs">
<h4>시작하기 전에</h4>

- "교회 설정 편집" 권한이 필요합니다. 접근 권한이 없으면 [역할 및 권한](./roles-permissions.md)을 참조하세요.
- 교회 이름 및 브랜딩을 포함하여 먼저 [교회 설정](./church-settings.md)을 구성하세요

</div>

## 네비게이션 설정 접근하기

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)를 열고 (왼쪽 위의 검색 바) **모바일**을 확장하세요.
2. **네비게이션**을 클릭하세요 (`/mobile/navigation`).
3. 네비게이션 페이지는 현재 앱 탭을 표시합니다.

## 새 탭 추가하기

1. 페이지 상단의 **탭 추가** 버튼을 클릭하세요.
2. 탭 세부 정보를 입력하세요:
   - **이름** -- 탭에 나타나는 레이블 (예: "설교" 또는 "기부").
   - **아이콘** -- 아이콘 선택기를 클릭하여 탭의 아이콘을 선택하세요. 사용자 정의 이미지를 업로드할 수도 있습니다.
   - **탭 유형** -- 성경, 라이브 스트림, 기부, 웹사이트 등과 같은 옵션에서 선택하세요.
   - **URL** -- 탭이 연결되어야 하는 웹 주소를 입력하세요.
   - **보이기** -- 이 탭을 볼 수 있는 사람을 제어하세요 (모두, 멤버만 등).
3. **탭 저장**을 클릭하여 앱에 추가하세요.

## 기존 탭 편집하기

1. **앱 탭** 목록의 기존 탭을 클릭하세요.
2. 탭의 이름, 아이콘, URL, 유형 또는 보이기 설정을 업데이트하세요.
3. **탭 저장**을 클릭하여 변경 사항을 적용하세요.

## 탭 재정렬하기

모바일 앱에 탭이 나타나는 순서를 변경할 수 있습니다. 목록에서 탭을 드래그 앤 드롭하여 재정렬하세요. 이 페이지에 표시된 순서는 멤버가 앱에서 볼 순서와 일치합니다.

:::info
특정 조건이 충족될 때 일부 탭이 자동으로 나타날 수 있습니다 -- 예를 들어, 스트림이 활성화되어 있을 때 라이브 스트림 탭이 나타날 수 있습니다. 수동으로 추가된 탭은 멤버가 항상 볼 수 있는 것을 완전히 제어합니다.
:::

:::tip
탭 개수를 관리 가능하게 유지하세요. 3개에서 5개의 탭이 대부분의 교회에 잘 작동합니다. 탭이 너무 많으면 멤버의 네비게이션을 혼란스럽게 할 수 있습니다.
:::

## 회원 디렉토리 및 메시징 설정

같은 모바일 섹션의 **회원 포털** 항목은 B1.church 환경에서 회원 디렉토리 및 개인 메시징을 관리하는 설정을 보유합니다:

- **디렉토리 승인 그룹** -- 회원 디렉토리 업데이트 및 [계정 삭제 요청](../profile/account-deletion.md)을 검토하고 적용 전에 검토하는 그룹.
- **디렉토리에 표시** -- 회원 디렉토리에 나타날 수 있는 사람 (직원만부터 모두까지).
- **보이기 기본값** -- 아직 자신의 설정을 선택하지 않은 멤버를 위한 교회 전체 기본값을 설정합니다. **주소**, **전화 번호** 및 **이메일**은 각각 자신의 드롭다운을 가지며, 보이기가 구성되는 모든 곳에서 사용 가능한 5가지 수준:
  - **모두** -- 익명 방문객을 포함한 모두가 볼 수 있음
  - **멤버** -- 멤버 또는 직원 기록이 있는 사람만 볼 수 있음
  - **그룹만** -- 이 사람과 그룹을 공유하는 사람만 볼 수 있음
  - **내 그룹 리더 및 직원** -- 이 사람이 속한 그룹의 리더 및 직원만 볼 수 있음
  - **직원만** -- 사람 > 보기 권한이 있는 직원 및 사람 자신만 볼 수 있음

  멤버는 B1.church PWA의 프로필의 **개인정보** 탭에서 자신의 기록을 위해 이러한 기본값을 재정의할 수 있습니다 -- [프로필 편집](/docs/b1-church/getting-started/me-page) 참조.
- **개인 메시지의 최소 나이** -- 아동 안전 제어. 두 사람 중 하나가 생일을 기반으로 이 나이 미만일 때 B1은 **새로운** 개인 메시지 대화를 열지 않습니다 (파일에 생일이 없을 때 가정 역할이 대체로 사용됨). 나이 미만인 사람은 디렉토리에서 완전히 보이지만 -- 모두를 포함한 모두 방향에서 직원을 포함하여 직접 메시징만 차단됩니다. 그룹 대화 및 아동의 부모에게 메시징은 계속 작동합니다. 옵션은 꺼짐, 13, 16 또는 18입니다; 기본값은 **18**입니다. 기존 대화는 영향을 받지 않습니다.

:::tip
최소 나이 확인이 생일에 의존하기 때문에, 회중의 자녀에 대해 생일이 입력되어 있는지 확인하세요. 이 설정은 [체크인 안전 제어](../attendance/checkin-safety.md)와 같은 아동 안전 가족에 속합니다.
:::

### 홈 화면 로그인 프롬프트

로그인하지 않고 앱의 [홈 화면](/docs/b1-church/getting-started/navigating#home)을 열어 방문객은 짧은 프롬프트를 봅니다 -- 기본적으로, *"로그인하여 그룹, 기부 등을 보세요."* -- **로그인** 버튼 옆에. 같은 회원 포털 페이지 (`/mobile/b1-mobile`)의 **홈 화면 로그인 프롬프트** 설정을 사용하면 변경할 수 있습니다:

- **앱 홈 화면에 로그인 프롬프트 표시** -- 이를 끄면 프롬프트 및 **로그인** 버튼을 홈 화면에서 숨깁니다. 방문객은 여전히 앱 메뉴에서 로그인할 수 있습니다.
- **로그인 프롬프트 텍스트** -- 기본 문구를 자신의 메시지로 바꾸세요 (최대 150자). 기본값을 사용하려면 공백으로 두세요. 이 상자는 프롬프트가 꺼져 있을 때 비활성화됩니다.

적용하려면 **저장**을 클릭하세요. 저장하면 앱의 캐시된 설정을 새로 고치므로, 홈 화면이 다음에 로드될 때 변경 사항이 나타납니다.

## 이 탭이 나타나는 곳

여기에서 구성한 탭은 `https://yourchurchname.b1.church`의 모든 페이지에서 설치한 멤버의 **B1.church PWA**에 표시됩니다. 이 페이지에서 수행한 변경 사항은 멤버가 다음에 앱을 열 때 반영됩니다. (탭은 아직 이를 실행 중인 멤버를 위해 레거시 [B1 모바일 네이티브 앱](/docs/b1-mobile/)에 의해서도 렌더링되지만, 그 앱은 더 이상 제공되고 더 이상 업데이트되지 않습니다.)
