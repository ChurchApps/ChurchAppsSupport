# 모바일 앱 설정

<div class="article-intro">

모바일 앱 설정 페이지를 사용하면 교회 회원을 위한 **B1.church 모바일 환경(PWA)**에 표시되는 네비게이션 탭을 구성할 수 있습니다. 표시할 탭, 연결 대상 및 표시 방식을 제어합니다.

</div>

:::info 네이티브 B1 모바일 앱이 중단됨
여기서 구성한 탭은 네이티브 B1 모바일 앱을 대체한 [B1.church Progressive Web App(PWA)](/docs/b1-church/getting-started/installing-pwa)를 통해 전달됩니다. 교회의 설치 페이지(`https://yourchurchname.b1.church/mobile/install`)를 회원과 공유하세요. 앱 스토어나 Google Play 다운로드 없이 기기에 앱을 설치하는 방법을 안내합니다.
:::

<div class="prereqs">
<h4>시작하기 전에</h4>

- "교회 설정 편집" 권한이 필요합니다. 접근 권한이 없는 경우 [역할 및 권한](./roles-permissions.md)을 참조하세요.
- 먼저 [교회 설정](./church-settings.md)을 구성하세요. 교회 이름 및 브랜딩 포함

</div>

## 모바일 앱 설정 접근

1. B1 Admin에서 **섹션 메뉴**(왼쪽 위 모서리의 섹션 이름 옆 작은 화살표)를 열고 **설정**을 선택합니다.
2. 헤더에서 **모바일 앱** 버튼을 클릭합니다.
3. 모바일 앱 설정 페이지에 현재 앱 탭이 표시됩니다.

## 새 탭 추가

1. 페이지 상단의 **탭 추가** 버튼을 클릭합니다.
2. 탭 세부 정보를 입력합니다:
   - **이름** -- 탭에 표시되는 레이블(예: "설교" 또는 "기부금").
   - **아이콘** -- 아이콘 선택기를 클릭하여 탭의 아이콘을 선택합니다. 사용자 정의 이미지를 업로드할 수도 있습니다.
   - **탭 유형** -- 성경, 라이브 스트림, 기부금, 웹사이트 등의 옵션에서 선택합니다.
   - **URL** -- 탭이 연결할 웹 주소를 입력합니다.
   - **표시 설정** -- 이 탭을 볼 수 있는 사람을 제어합니다(모두, 회원만 등).
3. **탭 저장**을 클릭하여 앱에 추가합니다.

## 기존 탭 편집

1. **앱 탭** 목록의 모든 기존 탭을 클릭합니다.
2. 탭의 이름, 아이콘, URL, 유형 또는 표시 설정을 업데이트합니다.
3. **탭 저장**을 클릭하여 변경 사항을 적용합니다.

## 탭 순서 변경

모바일 앱에 탭이 표시되는 순서를 변경할 수 있습니다. 목록에서 탭을 드래그 앤 드롭하여 순서를 변경합니다. 이 페이지에 표시된 순서는 회원이 앱에서 보게 될 순서와 일치합니다.

:::info
특정 조건이 충족되면 일부 탭이 자동으로 표시될 수 있습니다(예: 스트림이 활성화되면 라이브 스트림 탭이 나타날 수 있습니다). 수동으로 추가된 탭은 모든 시간에 회원이 무엇을 보는지에 대해 완전한 제어를 제공합니다.
:::

:::tip
탭 수를 관리하기 좋게 유지하세요. 대부분의 교회에는 3~5개의 탭이 잘 작동합니다. 탭이 너무 많으면 회원에게 네비게이션이 혼란스러울 수 있습니다.
:::

## 회원 디렉토리 및 메시징 설정

동일한 모바일 섹션의 **B1 모바일** 탭에는 B1.church 환경의 회원 디렉토리 및 개인 메시징을 관리하는 설정이 있습니다:

- **디렉토리 승인 그룹** -- 회원 디렉토리 업데이트가 적용되기 전에 검토하는 그룹입니다.
- **디렉토리에 표시** -- 회원 디렉토리에 표시될 수 있는 사람(직원만부터 모두까지).
- **표시 설정** -- 회원 주소, 전화번호 및 이메일 주소의 기본 표시 여부입니다.
- **개인 메시지의 최소 나이** -- 자녀 안전 제어입니다. B1은 어느 한 사람이 이 나이 미만인 경우 **새로운** 개인 메시지 대화를 열지 않으며, 생년월일을 기반으로 합니다(생년월일이 기록에 없을 때는 가구 역할을 대체로 사용). 나이 미만의 사람들은 디렉토리에 완전히 표시됩니다 -- 직원을 포함한 **양쪽 방향**에서 모든 사람에 대해 직접 메시징만 차단됩니다. 그룹 대화 및 자녀의 부모에게 메시징은 계속 작동합니다. 옵션은 끄기, 13, 16 또는 18이며, 기본값은 **18**입니다. 기존 대화는 영향을 받지 않습니다.

:::tip
최소 나이 확인은 생년월일에 의존하므로 교회의 어린이에 대해 생년월일이 채워져 있는지 확인하세요. 이 설정은 [체크인 안전 제어](../attendance/checkin-safety.md)와 동일한 자녀 안전 범주에 속합니다.
:::

## 이 탭이 표시되는 위치

여기서 구성한 탭은 회원이 `https://yourchurchname.b1.church`의 모든 페이지에서 설치하는 **B1.church PWA**에 표시됩니다. 이 페이지에서 변경한 내용은 회원이 다음에 앱을 열 때 반영됩니다. (탭은 아직 실행 중인 회원을 위해 레거시 [B1 모바일 네이티브 앱](/docs/b1-mobile/)에서도 렌더링되지만, 해당 앱은 더 이상 업데이트되지 않으므로 중단됩니다.)
