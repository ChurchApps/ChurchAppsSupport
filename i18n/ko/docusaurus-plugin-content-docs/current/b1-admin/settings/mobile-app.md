# 모바일 앱 설정

<div class="article-intro">

모바일 앱 설정 페이지에서는 교인들을 위한 **B1.church 모바일 경험(PWA)**에 표시되는 내비게이션 탭을 구성할 수 있습니다. 어떤 탭을 표시할지, 각 탭이 무엇에 연결될지, 어떻게 보일지를 직접 제어합니다.

</div>

:::info 네이티브 B1 Mobile 앱은 단종되었습니다
여기서 구성한 탭은 네이티브 B1 Mobile 앱을 대체한 [B1.church Progressive Web App(PWA)](/docs/b1-church/getting-started/installing-pwa)를 통해 전달됩니다. 교회의 설치 페이지인 `https://yourchurchname.b1.church/mobile/install`을 교인들과 공유하세요. App Store나 Google Play에서 다운로드할 필요 없이, 기기에 앱을 설치하는 방법을 안내해 줍니다.
:::

<div class="prereqs">
<h4>시작하기 전에</h4>

- "교회 설정 편집" 권한이 필요합니다. 접근 권한이 없다면 [역할 및 권한](./roles-permissions.md)을 참고하세요.
- 먼저 교회 이름과 브랜딩을 포함해 [교회 설정](./church-settings.md)을 구성하세요

</div>

## 모바일 앱 설정에 접근하기

1. 왼쪽 사이드바에서 **설정(Settings)** 페이지로 이동합니다.
2. 헤더의 **모바일 앱(Mobile Apps)** 버튼을 클릭합니다.
3. 모바일 앱 설정 페이지에 현재 앱 탭들이 표시됩니다.

## 새 탭 추가하기

1. 페이지 상단의 **탭 추가(Add Tab)** 버튼을 클릭합니다.
2. 탭 세부 정보를 입력합니다.
   - **이름(Name)** -- 탭에 표시되는 레이블입니다(예: "설교" 또는 "헌금").
   - **아이콘(Icon)** -- 아이콘 선택기를 클릭해 탭 아이콘을 고릅니다. 사용자 지정 이미지를 업로드할 수도 있습니다.
   - **탭 유형(Tab Type)** -- 성경, 라이브 스트림, 헌금, 웹사이트 등의 옵션 중에서 선택합니다.
   - **URL** -- 탭이 연결될 웹 주소를 입력합니다.
   - **표시 여부(Visibility)** -- 이 탭을 볼 수 있는 대상을 제어합니다(전체, 교인만 등).
3. **탭 저장(Save Tab)**을 클릭해 앱에 추가합니다.

## 기존 탭 편집하기

1. **앱 탭(App Tabs)** 목록에서 기존 탭을 클릭합니다.
2. 탭의 이름, 아이콘, URL, 유형, 표시 설정을 업데이트합니다.
3. **탭 저장(Save Tab)**을 클릭해 변경 사항을 적용합니다.

## 탭 순서 바꾸기

모바일 앱에서 탭이 나타나는 순서를 변경할 수 있습니다. 목록에서 탭을 드래그 앤 드롭해 재배열하세요. 이 페이지에 표시되는 순서가 교인들이 앱에서 보게 될 순서와 일치합니다.

:::info
특정 조건이 충족되면 일부 탭이 자동으로 나타날 수 있습니다 -- 예를 들어, 스트리밍이 진행 중일 때 라이브 스트림 탭이 표시될 수 있습니다. 직접 추가한 탭은 교인들에게 항상 보이는 내용을 완전히 통제할 수 있게 해줍니다.
:::

:::tip
탭 개수는 관리하기 쉬운 수준으로 유지하세요. 대부분의 교회에서는 3~5개의 탭이 적당합니다. 탭이 너무 많으면 교인들이 내비게이션을 헷갈려 할 수 있습니다.
:::

## 이 탭들이 표시되는 위치

여기서 구성한 탭은 `https://yourchurchname.b1.church`의 어느 페이지에서든 설치할 수 있는 **B1.church PWA**에 표시됩니다. 이 페이지에서 변경한 내용은 교인이 다음번에 앱을 열 때 반영됩니다. (레거시 [B1 Mobile 네이티브 앱](/docs/b1-mobile/)을 아직 사용 중인 교인에게도 동일한 탭이 표시되지만, 해당 앱은 단종되었으며 더 이상 업데이트되지 않습니다.)
