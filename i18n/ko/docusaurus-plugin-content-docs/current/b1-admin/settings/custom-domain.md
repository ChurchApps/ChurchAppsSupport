# 사용자 지정 도메인

<div class="article-intro">

자신의 도메인(예: **`www.yourchurch.org`**)을 B1 사이트에 연결하면, 방문자가 기본 yourchurch.b1.church 주소 대신 교회의 실제 웹 주소로 사이트에 접속할 수 있습니다.

</div>

## 1단계 -- 먼저 DNS 레코드 추가하기

B1에 도메인을 추가하기 전에, 도메인 등록 기관(GoDaddy, Namecheap, Cloudflare 등)에서 도메인이 B1 서버를 가리키도록 설정해야 합니다.

다음 레코드 중 하나를 추가하세요. CNAME을 권장합니다.

| 유형 | 호스트 | 값 |
|------|------|-------|
| CNAME | `www` | `proxy.b1.church` |
| A | `yourchurch.org` | `3.23.251.61` |

`www` 주소에는 **CNAME**을 사용하세요. 루트 또는 apex 도메인(www가 없는 도메인)에 CNAME을 지원하지 않는 등록 기관이거나, 루트 도메인도 함께 작동하게 하려면 **A 레코드**를 사용하세요.

DNS 변경이 적용되기까지 몇 분에서 몇 시간이 걸릴 수 있습니다.

## 2단계 -- B1에서 도메인 추가하기

DNS가 B1을 가리키면 다음과 같이 하세요.

1. B1 Admin에서 **Settings**로 이동하세요.
2. 왼쪽 목록에서 **Domains**를 클릭한 다음 **Domains** 섹션의 **Edit**를 클릭하세요.
3. 입력란에 도메인을 입력하고 **Save**를 클릭하세요.

**+** 버튼을 먼저 누를 필요는 없습니다. 입력란에 적힌 도메인은 저장할 때 추가됩니다. 저장하기 전에 여러 도메인을 목록에 추가하려면 **+**(또는 **Enter** 키)를 사용하세요.

B1이 SSL을 자동으로 처리하므로 인증서를 구입할 필요가 없습니다.

:::warning
DNS 레코드를 설정하기 전에 B1에 도메인을 추가하면 저장되지 않습니다. 반드시 DNS를 먼저 설정하세요.
:::

## 작동 확인하기

저장한 뒤 브라우저에서 도메인에 접속해 보세요. B1 사이트가 열리면 완료된 것입니다. 오류가 나타나면 DNS가 아직 전파되는 중일 수 있으니 몇 분 기다린 뒤 다시 시도하세요.

[dnschecker.org](https://dnschecker.org)에서도 DNS 전파 상태를 확인할 수 있습니다. 도메인을 검색한 다음, 등록한 CNAME 또는 A 레코드가 표시되는지 살펴보세요.
