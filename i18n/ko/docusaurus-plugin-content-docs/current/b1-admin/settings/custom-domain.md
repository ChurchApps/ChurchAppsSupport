# 사용자 지정 도메인

<div class="article-intro">

자신의 도메인(예: **`www.yourchurch.org`**)을 B1 사이트에 연결하면, 방문자는 기본 yourchurch.b1.church 주소 대신 교회의 실제 웹 주소로 사이트에 접속할 수 있습니다.

</div>

## 1단계 -- 먼저 DNS 레코드 추가하기

B1에 도메인을 추가하기 전에, 도메인 등록 업체(GoDaddy, Namecheap, Cloudflare 등)에서 도메인이 B1 서버를 가리키도록 설정해야 합니다.

다음 레코드 중 하나를 추가하세요. CNAME이 권장됩니다.

| 유형 | 호스트 | 값 |
|------|------|-------|
| CNAME | `www` | `proxy.b1.church` |
| A | `yourchurch.org` | `3.23.251.61` |

`www` 주소에는 **CNAME**을 사용하세요. 등록 업체가 루트(www 없는 apex) 도메인에 대한 CNAME을 지원하지 않는 경우, 또는 루트 도메인도 작동하게 하고 싶다면 **A 레코드**를 사용하세요.

DNS 변경이 적용되는 데는 몇 분에서 몇 시간이 걸릴 수 있습니다.

## 2단계 -- B1에서 도메인 추가하기

DNS가 B1을 가리키게 되었다면:

1. B1 Admin에서 **Settings**로 이동하세요.
2. 왼쪽 목록에서 **Domains**를 클릭한 다음, **Domains** 섹션의 **Edit**를 클릭하세요.
3. 입력란에 도메인을 입력하고 **Save**를 클릭하세요.

먼저 **+** 버튼을 누를 필요는 없습니다. 입력란에 입력된 도메인은 저장할 때 추가됩니다. 저장하기 전에 여러 도메인을 목록에 추가하고 싶다면 **+**(또는 **Enter**)를 사용하세요.

B1이 SSL을 자동으로 처리하므로, 인증서를 따로 구매할 필요가 없습니다.

:::warning
DNS 레코드가 준비되기 전에 B1에서 도메인을 추가하면 저장되지 않습니다. 항상 DNS를 먼저 설정하세요.
:::

## 작동 확인하기

저장한 뒤 브라우저에서 도메인에 접속하세요. B1 사이트가 열리면 끝입니다. 오류가 나타나면 DNS가 아직 반영되는 중일 수 있으니, 몇 분 기다린 뒤 다시 시도하세요.

[dnschecker.org](https://dnschecker.org)에서 DNS 반영 상태도 확인할 수 있습니다. 도메인을 검색하고 CNAME 또는 A 레코드가 나타나는지 확인하세요.
