# 사용자 정의 도메인

<div class="article-intro">

자신의 도메인 (예: **www.yourchurch.org**)을 B1 사이트로 가리킬 수 있으므로, 방문객이 기본 yourchurch.1.church 주소 대신 교회의 실제 웹 주소에서 이를 접근할 수 있습니다.

</div>

## 단계 1 -- 먼저 DNS 레코드 추가하기

B1에서 도메인을 추가하기 전에, 도메인 등록자 (GoDaddy, Namecheap, Cloudflare 등)에서 B1의 서버로 가리켜야 합니다.

이 레코드 중 하나를 추가하세요 -- CNAME이 선호됩니다:

| 유형 | 호스트 | 값 |
|------|------|-------|
| CNAME | `www` | `proxy.b1.church` |
| A | `yourchurch.org` | `3.23.251.61` |

자신의 `www` 주소에 **CNAME**을 사용하세요. 등록자가 루트/최상위 도메인 (www 없음)에서 CNAME을 지원하지 않거나, 루트 도메인도 작동하도록 하려면 **A 레코드**를 사용하세요.

DNS 변경은 적용되기까지 몇 분에서 몇 시간이 걸릴 수 있습니다.

## 단계 2 -- B1에서 도메인 추가하기

DNS가 B1을 가리키면:

1. B1 Admin에서 **설정**으로 이동하세요.
2. **도메인**을 클릭하세요.
3. 필드에 도메인을 입력하고 **저장**을 클릭하세요.

먼저 **+** 버튼을 클릭할 필요가 없습니다 -- 필드에 입력된 도메인은 저장할 때 추가됩니다. 저장하기 전에 목록에 여러 도메인을 추가하려고 할 때 **+** (또는 **Enter** 누르기)를 사용하세요.

B1은 SSL을 자동으로 처리합니다 -- 인증서 구매가 필요하지 않습니다.

:::warning
DNS 레코드가 없기 전에 B1에서 도메인을 추가하면, 저장되지 않습니다. 항상 먼저 DNS를 설정하세요.
:::

## 작동 여부 확인하기

저장 후 브라우저에서 도메인을 방문하세요. B1 사이트가 로드되면, 완료입니다. 오류가 표시되면, DNS가 아직 전파 중일 수 있습니다 -- 몇 분 기다렸다가 다시 시도하세요.

[dnschecker.org](https://dnschecker.org)에서 DNS 전파를 확인할 수도 있습니다 -- 도메인을 검색하고 자신의 CNAME 또는 A 레코드가 나타나는 것을 찾으세요.
