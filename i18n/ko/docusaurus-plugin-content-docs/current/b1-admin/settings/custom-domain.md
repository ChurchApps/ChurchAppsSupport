# 사용자 정의 도메인

<div class="article-intro">

자신의 도메인 (예: **www.yourchurch.org**)을 B1 사이트로 가리켜서 방문자가 기본 yourchurch.1.church 주소 대신 교회의 실제 웹 주소에서 이에 도달하도록 할 수 있습니다.

</div>

## 1단계 -- 먼저 DNS 레코드 추가

B1에서 도메인을 추가하기 전에 도메인 레지스트라 (GoDaddy, Namecheap, Cloudflare 등)에서 B1의 서버로 가리켜야 합니다.

이러한 레코드 중 하나를 추가하세요 -- CNAME이 선호됩니다:

| 유형 | 호스트 | 값 |
|------|------|-------|
| CNAME | `www` | `proxy.b1.church` |
| A | `yourchurch.org` | `3.23.251.61` |

`www` 주소에 **CNAME**을 사용하세요. 레지스트라가 루트/apex 도메인 (www 없이)에서 CNAME을 지원하지 않거나 루트 도메인도 작동하도록 하려면 **A 레코드**를 사용하세요.

DNS 변경이 적용되는 데 몇 분에서 몇 시간이 걸릴 수 있습니다.

## 2단계 -- B1에서 도메인 추가

DNS가 B1을 가리키고 있으면:

1. B1 Admin의 **설정**으로 이동하세요.
2. **도메인**을 클릭하세요.
3. 필드에 도메인을 입력하고 **저장**을 클릭하세요.

B1은 SSL을 자동으로 처리합니다 -- 인증서 구매가 필요하지 않습니다.

:::warning
DNS 레코드를 배치하기 전에 B1에 도메인을 추가하면 저장되지 않습니다. 항상 먼저 DNS를 설정하세요.
:::

## 작동하는지 확인

저장 후 브라우저에서 도메인을 방문하세요. B1 사이트를 로드하면 완료입니다. 오류가 표시되면 DNS가 여전히 전파 중일 수 있습니다 -- 몇 분 기다린 후 다시 시도하세요.

[dnschecker.org](https://dnschecker.org)에서 DNS 전파를 확인할 수도 있습니다 -- 도메인을 검색하고 CNAME 또는 A 레코드가 표시되는지 확인하세요.
