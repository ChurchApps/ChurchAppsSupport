# 설정
<div class="article-intro">
설정 섹션은 B1 Admin에서 교회의 계정, 브랜딩, 관리 옵션을 구성하는 곳입니다. 교회 이름과 서브도메인부터 사용자 권한과 모바일 앱 구성까지 모든 것을 관리할 수 있습니다.
</div>
## 찾을 수 있는 것
설정 영역은 다음 하위 섹션으로 구성되어 있습니다:
1. **설정** — 교회의 기본 정보, 브랜딩, 서브도메인을 구성합니다
2. **캠퍼스** — 교회의 여러 물리적 위치를 추가하고 관리합니다
3. **커스텀 필드** — 사람들을 추적하기 위해 자신의 필드를 정의합니다
4. **모바일 앱** — B1.church PWA에 나타나는 네비게이션 탭을 커스터마이즈합니다
5. **이메일 템플릿** — 재사용 가능한 이메일 콘텐츠를 저장합니다
6. **서버 관리** — 고급 관리 도구에 접근합니다
