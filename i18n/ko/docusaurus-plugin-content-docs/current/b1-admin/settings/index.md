# 설정

<div class="article-intro">

설정 영역은 B1 Admin에서 교회의 계정, 브랜딩, 관리 옵션을 구성하는 곳입니다. 교회 이름과 서브도메인에서 사용자 권한과 모바일 앱 구성까지 여기서 관리할 수 있습니다.

</div>

## 이곳에서 찾을 수 있는 것

설정 영역은 다음 하위 섹션으로 구성되어 있습니다:

1. **설정** -- 교회의 기본 정보, 브랜딩, 서브도메인, 지역(날짜 및 전화번호 형식), 문자 제공업체, 파일 저장소를 구성합니다. 자세한 내용은 [교회 설정](./church-settings.md)을 참고하세요. 교회 고유의 도메인 이름(예: yourchurch.org)을 쓰려면 [사용자 지정 도메인](./custom-domain.md)을 참고하세요.
2. **캠퍼스** -- 교회의 여러 실제 장소를 추가하고 관리합니다. 캠퍼스를 만들면 사람 프로필, 출석 설정, 인구 통계 대시보드에 나타납니다. 별도의 탐색 항목이 아니라 기본 설정 페이지의 섹션으로 들어갑니다. 자세한 내용은 [캠퍼스](./campuses.md)를 참고하세요.
3. **맞춤 항목** -- 사람에 대해 추적할 항목(날짜, 숫자, 예/아니요 답변, 목록 선택)을 직접 정의한 다음, 프로필에서 값을 입력하고 그 값으로 검색합니다. 이것도 기본 설정 페이지의 섹션으로 들어갑니다. 자세한 내용은 [맞춤 항목](./custom-fields.md)을 참고하세요.
4. **이메일 템플릿** -- 수동으로 보내거나 워크플로에서 보낼 재사용 가능한 이메일 내용을 저장합니다. 자세한 내용은 [이메일 템플릿](./email-templates.md)을 참고하세요.
5. **감사 로그**와 **일괄 처리** -- 계정 전반에 걸친 변경 사항을 검토합니다([감사 로그](../reports/audit-log.md)). 대량 가져오기와 작업을 검토하거나 되돌립니다(**일괄 처리**).
6. **서버 관리** -- 교회의 서버 수준 설정을 관리하는 고급 관리 도구에 접근합니다.

:::info
**모바일 앱** 설정과 **양식**은 이제 설정 안에 있지 않고, 자체 최상위 탐색 항목으로 있습니다. **모바일**과 **양식**(**사람** 아래에 있습니다)입니다. 자세한 내용은 [모바일 앱 설정](./mobile-app.md)과 [양식 만들기](/docs/b1-admin/forms/creating-forms)를 참고하세요.
:::

## 기본 설정 페이지

설정 페이지를 처음 열면 왼쪽 패널에 **교회 이름**, **서브도메인**, 주소가 표시됩니다. 그 아래에는 **가져오기/내보내기** 링크가 있어, 시스템 간 데이터를 옮기는 가져오기/내보내기 도구를 열 수 있습니다.

그 아래의 **구성** 목록에는 각 설정 섹션으로 가는 링크가 있습니다. **교회 정보**, **일반**, **지역**, **헌금**, **문자**, **파일 저장소**, **도메인**, **학년 진급**, **체크인**, **캠퍼스**, **맞춤 항목**, **개발자**입니다. 아직 설정이 필요한 섹션(예: 헌금, 문자, 도메인)에는 작은 점이 표시됩니다. 모든 섹션은 한 페이지에 있으며, 목록의 이름을 클릭하면 그 섹션으로 스크롤되고, 그냥 아래로 스크롤해도 됩니다. 각 섹션에는 현재 설정이 보이며, 바꾸려면 섹션의 **편집**을 클릭합니다.

**이메일 템플릿**, **감사 로그**, **일괄 처리**는 별도의 페이지입니다. [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)에서 **설정** 아래에 있는 항목을 열어 이동하세요.

**교회 정보** 섹션부터 시작해 교회 이름, 주소, 연락처를 편집하세요. 자세한 내용은 [교회 설정](./church-settings.md)을 참고하세요. 사용자 역할을 관리하려면 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)를 열고 **설정 > 역할**을 선택하세요. 자세한 내용은 [역할 및 권한](./roles-permissions.md)을 참고하세요.

:::tip
먼저 **교회 정보**에서 교회 이름과 브랜딩을 설정한 다음, [역할](./roles-permissions.md)을 설정해 팀원을 적절한 접근 권한으로 초대하세요.
:::

:::info
데이터가 어떻게 보호되는지는 [데이터 보안](./data-security.md)을 참고하세요.
:::
