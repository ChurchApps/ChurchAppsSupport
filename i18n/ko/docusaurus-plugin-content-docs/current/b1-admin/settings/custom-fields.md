# 사용자 정의 필드

<div class="article-intro">

**사용자 정의 필드**를 사용하면 모든 사람 기록에서 고유한 정보를 추적할 수 있습니다 -- B1에 기본 제공 필드가 없는 것들(예: 신원조회 만료일, 티셔츠 크기 또는 세례 수업 상태). 필드를 설정에서 한 번 정의한 다음, 각 사람의 프로필에서 값을 채우고 검색하거나 목록을 작성합니다. 이렇게 하면 하나의 사용자 정의 데이터를 저장하기 위해 사람 양식을 생성하는 이전의 해결 방법을 대체합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 필드를 정의하고 값을 채우려면 **사람** 편집 권한이 필요하며, **설정** 영역에 접근해야 합니다. 사람 보기 권한이 있는 사람은 누구든지 값을 볼 수 있습니다. [역할 및 권한](./roles-permissions.md)을 참조하세요.
- 추적하려는 항목과 가장 적합한 유형(텍스트, 숫자, 날짜, 예/아니오 또는 선택 목록)을 시작하기 전에 결정하세요.

</div>

## 사용자 정의 필드 열기

B1 Admin에서 **섹션 메뉴**(왼쪽 위 모서리의 섹션 이름 옆 작은 화살표)를 열고 **설정**을 선택한 다음 **사용자 정의 필드** 카드를 선택합니다. **/settings/custom-fields**에서 바로 이동할 수도 있습니다. 정의한 모든 필드의 목록이 표시되며, **이름** 및 **필드 유형**이 표시됩니다. 아직 생성하지 않은 경우 패널에는 *"아직 사용자 정의 필드가 추가되지 않았습니다."*가 표시됩니다.

## 필드 추가

1. **필드 추가**를 클릭합니다.
2. 오른쪽에 열리는 편집기에서 **이름**을 입력합니다 -- 이것은 사람 프로필과 검색에서 직원이 보게 될 레이블입니다(예: *신원조회 만료 날짜*).
3. **필드 유형**을 선택합니다:
   - **텍스트박스** -- 자유 형식 짧은 텍스트입니다.
   - **정수** -- 소수점 없는 숫자(예: 카운트).
   - **소수** -- 소수점을 포함할 수 있는 숫자입니다.
   - **날짜** -- 달력 날짜입니다.
   - **예/아니오** -- 단순 예 또는 아니오 답변입니다.
   - **다중 선택** -- 선택 목록입니다. 이 유형을 선택하면 **선택 편집기**가 나타나므로 사람이 선택할 수 있는 각 옵션을 추가할 수 있습니다.
4. **저장**을 클릭합니다.

이제 필드는 모든 사람의 프로필에서 사용할 수 있습니다.

:::info
필드 유형은 [양식 질문](../forms/creating-forms.md)에 사용되는 것과 같으므로 값은 B1 전체에서 일관되게 동작합니다.
:::

## 필드 편집

목록의 모든 필드 행을 클릭하여 편집기에서 다시 열 수 있습니다. 이름, 유형 또는 선택 항목을 변경한 후 **저장**을 클릭합니다.

:::warning
이미 값이 있는 필드의 **필드 유형**을 변경하면(예: 텍스트박스에서 날짜로) 이전에 입력한 값이 더 이상 새 유형과 일치하지 않는 형식으로 남을 수 있습니다. 직원이 필드를 채우기 시작한 후에는 주의해서 유형을 변경하세요.
:::

## 필드 삭제

편집을 위해 필드를 열고 **삭제**를 클릭합니다. 확인 메시지가 표시됩니다: *"이 사용자 정의 필드를 삭제하시겠습니까? 저장된 값도 제거됩니다."* 필드를 삭제하면 모든 사람에 대해 저장된 모든 값과 함께 **영구적으로 제거**됩니다 -- 이는 실행 취소할 수 없습니다.

## 사람의 값 채우기

최소 하나의 사용자 정의 필드가 존재하면 해당 값은 각 사람 기록의 기본 제공 세부 정보 옆에 나타납니다 -- 값을 **개인 세부 정보**에서 보고 나머지 사람 정보에 사용하는 동일한 양식에서 편집할 수 있습니다. 첫 번째 필드를 정의할 때까지 아무것도 표시되지 않습니다.

1. **사람** 섹션에서 사람의 기록을 엽니다.
2. **개인 세부 정보** 섹션에서 **편집**(연필) 버튼을 클릭합니다.
3. 편집 양식 하단의 **사용자 정의 필드** 영역으로 스크롤하여 각 필드에 대한 값을 채웁니다. 각 필드는 해당 유형과 일치하는 입력을 보여줍니다 -- 날짜 필드의 경우 날짜 선택기, 예/아니오 필드의 경우 예/아니오 드롭다운, 다중 선택의 경우 선택 목록 등.
4. **저장**을 클릭합니다. 사용자 정의 필드 값은 나머지 사람 세부 정보와 함께 저장됩니다.

프로필에서 돌아가면 값이 있는 모든 필드가 이제 **개인 세부 정보** 섹션에 표시됩니다(예/아니오 답변은 *예* 또는 *아니오*로 표시되고, 다중 선택은 옵션의 레이블을 표시합니다). 비어 있는 필드는 숨겨집니다. 값을 제거하려면 사람을 편집하고 필드를 지운 후 저장하세요 -- 빈 값은 공백으로 저장되지 않고 기록에서 삭제됩니다.

:::tip
전형적인 사용 사례는 자원봉사자 안전입니다: *신원조회 만료* 이름의 **날짜** 필드를 생성하고, 각 자원봉사자의 날짜를 기록한 다음, 날짜가 지난 모든 사람을 표시하는 [저장된 목록](../people/lists.md)을 작성합니다.
:::

## 사용자 정의 필드에서 검색 및 목록 작성

사용자 정의 필드는 완전히 검색 가능합니다:

1. **사람** 페이지에서 [고급 검색](../people/searching-people.md)을 엽니다.
2. **사용자 정의 필드** 카테고리를 확장합니다.
3. 필터링할 필드를 확인하고, 연산자를 선택하고, 값을 입력합니다. 제공되는 연산자는 필드의 유형과 일치합니다:
   - **텍스트박스** -- 포함, 같음, 시작함, 끝남.
   - **정수 / 소수** -- 같음, 보다 큼, 보다 크거나 같음, 보다 작음, 보다 작거나 같음.
   - **날짜** -- 같음, 이후(보다 큼), 이전(보다 작음).
   - **예/아니오** -- 예 또는 아니오와 같음.
   - **다중 선택** -- 선택 항목 중 하나와 같거나 포함.

모든 사용자 정의 필드 검색을 [목록](../people/lists.md)으로 저장하세요. 목록은 라이브 쿼리이므로, *신원조회 만료가 오늘 이전*에 구축된 목록은 열 때마다 모든 사람을 다시 확인합니다 -- 수동 업데이트가 없습니다.

## 병합 시 발생하는 일

두 개의 사람 기록을 [병합](../people/adding-people.md)할 때, 사용자 정의 필드 값은 자동으로 전달됩니다. 유지하는 사람은 자신의 값을 보유합니다. 제거된 사람만 값을 가진 필드의 경우 해당 값이 복사되므로 아무것도 손실되지 않습니다.

## 관련 기사

- [사람 검색](../people/searching-people.md) -- 사용자 정의 필드 카테고리를 포함한 고급 검색
- [저장된 목록](../people/lists.md) -- 사용자 정의 필드 검색을 저장하고 라이브로 다시 실행
- [역할 및 권한](./roles-permissions.md) -- 필드를 정의하고 값을 편집할 수 있는 사람
- [양식 만들기](../forms/creating-forms.md) -- 단일 필드보다 전체 양식이 더 적합한 다중 질문 데이터 수집의 경우
