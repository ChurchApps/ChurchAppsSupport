# 사용자 정의 필드

<div class="article-intro">

사용자 정의 필드를 통해 교회에 고유한 정보를 사람 기록에 추가할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 설정 편집 권한 필요

</div>

## 사용자 정의 필드 추가

1. B1 Admin에서 **설정 > 사용자 정의 필드**로 이동합니다.
2. **필드 추가**를 클릭합니다.
3. 필드 **이름**을 입력합니다.
4. **필드 유형** 선택 (텍스트, 숫자, 날짜, 선택)
5. **저장**을 클릭합니다.
