# 사용자 정의 필드

<div class="article-intro">

**사용자 정의 필드**는 모든 사람 기록에 자신의 정보를 추적할 수 있도록 합니다 -- 배경 검사 만료 날짜, T셔츠 크기 또는 세례식 클래스 상태와 같이 B1이 기본 제공 필드가 없는 것들. 설정에서 한 번 필드를 정의한 다음, 각 사람의 프로필에 값을 입력하고 검색하거나 목록을 구축합니다. 이것은 단일 맞춤 데이터를 저장하기 위해 사람 양식을 만드는 이전 해결 방법을 대체합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 필드를 정의하고 값을 입력할 **사람** 편집 권한과 **설정** 영역에 접근이 필요합니다. 사람 보기 권한이 있는 모든 사람이 값을 볼 수 있습니다. [역할 및 권한](./roles-permissions.md) 참조.
- 추적하려는 것을 결정하고 시작하기 전에 가장 잘 맞는 유형 (텍스트, 숫자, 날짜, 예/아니오 답변 또는 선택 목록)을 결정하세요.

</div>

## 사용자 정의 필드 열기

B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)를 열고 (왼쪽 위의 검색 바), **설정 > 설정**을 선택하고, **사용자 정의 필드** 카드를 선택하세요. **/settings/custom-fields**에서 직접 갈 수도 있습니다. 정의한 모든 필드의 목록을 볼 수 있으며, **이름** 및 **필드 유형**을 표시합니다. 아직 만든 것이 없으면, 패널은 *"아직 사용자 정의 필드가 추가되지 않았습니다."*를 읽습니다.

## 필드 추가하기

1. **필드 추가**를 클릭하세요.
2. 오른쪽에 열리는 편집기에서 **이름**을 입력하세요 -- 이것은 직원이 사람 프로필 및 검색에서 볼 레이블입니다 (예: *배경 검사 만료*).
3. **필드 유형**을 선택하세요:
   - **텍스트박스** -- 자유 형식의 짧은 텍스트.
   - **정수** -- 소수 없는 숫자 (예: 개수).
   - **소수** -- 소수를 포함할 수 있는 숫자.
   - **날짜** -- 달력 날짜.
   - **예/아니오** -- 간단한 예 또는 아니오 답변.
   - **다중 선택** -- 선택 목록. 이 유형을 선택하면, **선택 편집기**가 나타나므로 사람이 선택할 수 있는 각 옵션을 추가할 수 있습니다.
4. **저장**을 클릭하세요.

필드는 이제 모든 사람의 프로필에서 사용할 수 있습니다.

:::info
필드 유형은 [양식 질문](../forms/creating-forms.md)에 사용되는 동일한 집합이므로, 값은 B1 전체에서 일관되게 작동합니다.
:::

## 필드 편집하기

목록의 필드 행을 클릭하여 편집기에서 다시 열세요. 이름, 유형 또는 선택을 변경하고 **저장**을 클릭하세요.

:::warning
이미 값이 있는 필드의 **필드 유형**을 변경하면 (예: 텍스트박스에서 날짜로), 이전에 입력한 값을 더 이상 새 유형과 일치하지 않는 형식으로 남길 수 있습니다. 직원이 필드를 입력하기 시작한 후 유형을 주의해서 변경하세요.
:::

## 필드 삭제하기

편집을 위해 필드를 열고 **삭제**를 클릭하세요. 확인을 묻게 됩니다: *"이 사용자 정의 필드를 삭제하시겠습니까? 저장된 값도 제거됩니다."* 필드를 삭제하면 모든 사람의 **그리고 그것을 위해 저장된 모든 값**을 영구적으로 제거합니다 -- 이것은 실행 취소할 수 없습니다.

## 사람에 값 입력하기

최소한 하나의 사용자 정의 필드가 존재하면, 그 값은 각 사람의 기록에 기본 세부 정보 옆에 살고 있습니다 -- **개인 세부 정보**에서 보고 사람의 정보의 나머지 부분에 사용하는 동일한 양식에서 편집합니다. 첫 번째 필드를 정의할 때까지 특별한 것은 나타나지 않습니다.

1. **사람**에서 사람의 기록을 열세요.
2. **개인 세부 정보** 섹션에서 **편집** (연필) 버튼을 클릭하세요.
3. 편집 양식 하단의 **사용자 정의 필드** 영역으로 스크롤하고 각 필드의 값을 입력하세요. 각 필드는 유형과 일치하는 입력을 표시합니다 -- 날짜 필드용 날짜 선택기, 예/아니오 필드용 예/아니오 드롭다운, 다중 선택용 선택 목록 등.
4. **저장**을 클릭하세요. 사용자 정의 필드 값은 사람의 정보의 나머지 부분과 함께 저장됩니다.

프로필로 돌아가면, 값이 있는 모든 필드는 이제 **개인 세부 정보** 섹션에 표시됩니다 (예/아니오 답변은 *예* 또는 *아니오*로 읽고, 다중 선택은 옵션의 레이블을 표시합니다). 공백으로 남겨진 필드는 단순히 숨겨집니다. 값을 제거하려면, 사람을 편집하고, 필드를 지우고, 저장하세요 -- 빈 값은 공백으로 저장되지 않고 기록에서 삭제됩니다.

:::tip
고전적인 사용 사례는 자원봉사자 안전입니다: *배경 검사 만료*라는 **날짜** 필드를 만들고, 각 자원봉사자의 날짜를 기록한 다음, 날짜가 지난 모든 사람에게 플래그를 지정하는 [저장된 목록](../people/lists.md)을 구축하세요.
:::

## 사용자 정의 필드에서 검색 및 목록 구축하기

사용자 정의 필드는 완전히 검색 가능합니다:

1. **사람** 페이지에서 [고급 검색](../people/searching-people.md)을 열세요.
2. **사용자 정의 필드** 카테고리를 확장하세요.
3. 필터링할 필드를 확인하고, 연산자를 선택하고, 값을 입력하세요. 제공되는 연산자는 필드의 유형과 일치합니다:
   - **텍스트박스** -- 포함, 같음, 시작, 끝.
   - **정수 / 소수** -- 같음, 초과, 이상, 미만, 이하.
   - **날짜** -- 같음, 이후 (초과), 이전 (미만).
   - **예/아니오** -- 예 또는 아니오와 같음.
   - **다중 선택** -- 선택지 중 하나와 같음 또는 포함.

사용자 정의 필드 검색을 [목록](../people/lists.md)으로 저장하세요. 목록은 라이브 쿼리이므로, *배경 검사 만료가 오늘 이전*에 구축된 목록은 열 때마다 모든 사람을 다시 확인합니다 -- 수동 유지 보수 없음.

## 사용자 정의 필드를 열로 표시하기

모든 사람의 필드 값을 한 번에 보려면, **사람** 페이지의 열로 추가하세요. 열 선택기를 열고, **사용자 정의** 탭으로 전환하고, 필드를 확인하세요. 각 사람의 값은 기본 제공 옆에 자신의 열에 나타납니다. [사용자 정의 필드를 열로 표시하기](../people/searching-people.md#showing-custom-fields-as-columns) 참조.

## 병합에서 어떤 일이 발생하는가

[두 사람 기록을 병합](../people/adding-people.md)할 때, 사용자 정의 필드 값은 자동으로 옮겨집니다. 유지하는 사람은 자신의 값을 유지합니다; 제거된 사람만 값이 있는 모든 필드에 대해, 그 값은 복사되므로 아무것도 손실되지 않습니다.
