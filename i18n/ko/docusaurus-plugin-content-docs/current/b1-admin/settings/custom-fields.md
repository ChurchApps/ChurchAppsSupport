# 사용자 지정 필드

<div class="article-intro">

**사용자 지정 필드**를 사용하면 모든 인물 레코드에서 자체 정보를 추적할 수 있습니다 — 신원 조회 만료일, 티셔츠 사이즈, 세례 수업 상태처럼 B1에 내장된 필드가 없는 정보입니다. 설정에서 필드를 한 번 정의한 다음, 각 인물의 프로필에서 값을 입력하고 이를 기준으로 검색하거나 목록을 만들 수 있습니다. 이는 단일 사용자 지정 데이터를 저장하기 위해 People 양식을 만들던 이전의 우회 방법을 대체합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 필드를 정의하고 값을 입력하려면 **People** 편집 권한과 **설정** 영역에 대한 접근 권한이 필요합니다. People 보기 권한이 있는 사람은 누구나 값을 볼 수 있습니다. [역할 및 권한](./roles-permissions.md)을 참조하세요.
- 시작하기 전에 무엇을 추적할지, 어떤 유형(텍스트, 숫자, 날짜, 예/아니오 답변, 또는 선택 목록)이 가장 적합한지 결정하세요.

</div>

## 사용자 지정 필드 열기

B1 Admin에서 왼쪽 사이드바의 **설정**으로 이동하여 **사용자 지정 필드** 카드를 선택하세요. **/settings/custom-fields**로 바로 이동할 수도 있습니다. 정의한 모든 필드의 목록이 **이름**과 **필드 유형**과 함께 표시됩니다. 아직 만든 필드가 없다면 패널에 *"아직 추가된 사용자 지정 필드가 없습니다."*라고 표시됩니다.

## 필드 추가하기

1. **필드 추가**를 클릭하세요.
2. 오른쪽에 열리는 편집기에서 **이름**을 입력하세요 — 이는 직원이 인물 프로필과 검색에서 보게 될 라벨입니다(예: *신원 조회 만료일*).
3. **필드 유형**을 선택하세요:
   - **텍스트 상자** — 자유 형식의 짧은 텍스트.
   - **정수** — 소수점이 없는 숫자(예: 개수).
   - **소수** — 소수점을 포함할 수 있는 숫자.
   - **날짜** — 달력 날짜.
   - **예/아니오** — 간단한 예/아니오 답변.
   - **다중 선택** — 선택 목록. 이 유형을 선택하면 사람들이 선택할 수 있는 각 옵션을 추가할 수 있는 **선택 항목 편집기**가 나타납니다.
4. **저장**을 클릭하세요.

이제 이 필드는 모든 인물의 프로필에서 사용할 수 있습니다.

:::info
필드 유형은 [양식 질문](../forms/creating-forms.md)에 사용되는 것과 동일한 세트이므로 값이 B1 전반에서 일관되게 동작합니다.
:::

## 필드 편집하기

목록에서 필드 행을 클릭하면 편집기가 다시 열립니다. 이름, 유형, 또는 선택 항목을 변경한 후 **저장**을 클릭하세요.

:::warning
이미 값이 있는 필드의 **필드 유형**을 변경하면(예: 텍스트 상자에서 날짜로) 이전에 입력된 값이 새 유형과 더 이상 일치하지 않는 형식으로 남을 수 있습니다. 직원이 필드에 값을 입력하기 시작한 후에는 유형을 신중하게 변경하세요.
:::

## 필드 삭제하기

편집을 위해 필드를 열고 **삭제**를 클릭하세요. 확인 메시지가 표시됩니다: *"이 사용자 지정 필드를 삭제하시겠습니까? 저장된 값도 함께 제거됩니다."* 필드를 삭제하면 해당 필드와 **모든 사람에 대해 저장된 모든 값**이 영구적으로 제거되며, 이는 되돌릴 수 없습니다.

## 인물에 값 입력하기

사용자 지정 필드가 하나 이상 존재하면, 그 값은 각 인물 레코드의 내장 세부 정보와 나란히 표시됩니다 — **개인 정보**에서 확인하고, 인물의 나머지 정보와 동일한 양식에서 편집합니다. 첫 필드를 정의하기 전에는 추가로 표시되는 항목이 없습니다.

1. **People**에서 인물 레코드를 여세요.
2. **개인 정보** 섹션에서 **편집**(연필) 버튼을 클릭하세요.
3. 편집 양식 하단의 **사용자 지정 필드** 영역으로 스크롤하여 각 필드의 값을 입력하세요. 각 필드는 해당 유형에 맞는 입력 방식을 표시합니다 — 날짜 필드는 날짜 선택기, 예/아니오 필드는 예/아니오 드롭다운, 다중 선택은 선택 목록 등입니다.
4. **저장**을 클릭하세요. 사용자 지정 필드 값이 인물의 나머지 정보와 함께 저장됩니다.

프로필로 돌아가면 값이 있는 필드는 **개인 정보** 섹션에 표시됩니다(예/아니오 답변은 *예* 또는 *아니오*로, 다중 선택은 옵션의 라벨로 표시됩니다). 비워 둔 필드는 단순히 숨겨집니다. 값을 제거하려면 인물을 편집하고 필드를 비운 후 저장하세요 — 빈 값은 저장되는 대신 레코드에서 삭제됩니다.

:::tip
대표적인 사용 사례는 자원봉사자 안전입니다: *신원 조회 만료일*이라는 **날짜** 필드를 만들고 각 자원봉사자의 날짜를 기록한 다음, 날짜가 지난 사람을 표시하는 [저장된 목록](../people/lists.md)을 만드세요.
:::

## 사용자 지정 필드로 검색 및 목록 만들기

사용자 지정 필드는 완전히 검색 가능합니다:

1. **People** 페이지에서 [고급 검색](../people/searching-people.md)을 여세요.
2. **사용자 지정 필드** 카테고리를 펼치세요.
3. 필터링할 필드를 선택하고, 연산자를 선택한 후, 값을 입력하세요. 제공되는 연산자는 필드 유형에 따라 다릅니다:
   - **텍스트 상자** — 포함, 같음, ~로 시작, ~로 끝남.
   - **정수 / 소수** — 같음, 초과, 이상, 미만, 이하.
   - **날짜** — 같음, 이후(초과), 이전(미만).
   - **예/아니오** — 예 또는 아니오와 같음.
   - **다중 선택** — 선택 항목 중 하나와 같음 또는 포함.

사용자 지정 필드 검색은 [목록](../people/lists.md)으로 저장할 수 있습니다. 목록은 실시간 쿼리이므로, *신원 조회 만료일이 오늘 이전*을 기준으로 만든 목록은 열 때마다 모든 사람을 다시 확인합니다 — 수동 관리가 필요 없습니다.

## 병합 시 발생하는 일

[두 인물 레코드를 병합](../people/adding-people.md)하면 사용자 지정 필드 값이 자동으로 이전됩니다. 유지되는 인물은 자신의 값을 그대로 유지하며, 제거되는 인물에게만 값이 있던 필드는 해당 값이 복사되어 손실되지 않습니다.
