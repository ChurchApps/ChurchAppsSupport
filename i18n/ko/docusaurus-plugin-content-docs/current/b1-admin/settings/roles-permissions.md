# 역할 및 권한

<div class="article-intro">

역할을 사용하면 ChurchApps 계정 내에서 다양한 사용자가 접근할 수 있는 내용을 제어할 수 있습니다. 직원, 자원봉사자 및 기타 팀원을 위한 사용자 정의 역할을 만들 수 있으며, 각각 고유한 접근 수준으로 데이터를 안전하게 유지할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 도메인 관리자 접근 또는 역할을 관리할 수 있는 권한이 필요합니다.
- 팀 구성원 목록과 접근이 필요한 영역 준비
- 아래의 사용 가능한 권한 카테고리를 검토하여 역할 계획

</div>

## 역할 접근

1. B1 Admin에서 **섹션 메뉴**(왼쪽 위 모서리의 섹션 이름 옆 작은 화살표)를 열고 **설정**을 선택합니다.
2. 헤더에서 **역할** 버튼을 클릭합니다.
3. 역할 페이지에는 교회를 위해 현재 정의된 모든 역할이 표시됩니다.

## 역할 페이지 이해

역할 페이지는 두 개의 패널로 나뉩니다:

- **왼쪽** -- 선택된 역할에 할당된 구성원 목록을 표시합니다.
- **오른쪽** -- 해당 역할에 대해 구성할 수 있는 권한 설정을 표시합니다.

모든 역할 이름을 클릭하여 회원 및 권한을 보고 관리합니다.

## 역할에 사용자 추가

1. 구성원을 추가할 역할을 선택합니다.
2. 왼쪽의 **검색 필드**를 사용하여 추가할 사람을 찾습니다.
3. 검색 결과에서 해당 사람을 선택합니다.
4. 즉시 역할에 추가됩니다.

## 역할에서 사용자 제거

1. 제거할 사용자가 포함된 역할을 선택합니다.
2. 왼쪽의 구성원 목록에서 해당 사람을 찾습니다.
3. 해당 이름 옆의 **제거 버튼**을 클릭합니다.

## 권한 구성

각 역할에는 B1 Admin의 특정 영역에 대한 접근 권한을 부여할 수 있습니다. 권한은 섹션별로 구성됩니다:

- **사람** -- 회원 디렉토리 및 사람 기록에 접근합니다.
- **기부금** -- 기부금 기록 및 자금 관리에 접근합니다.
- **참석** -- 참석 추적 및 보고서에 접근합니다.
- **콘텐츠** -- 웹사이트 및 콘텐츠 관리에 접근합니다.
- 기타 사용 가능한 영역.

역할 페이지의 오른쪽 확인란을 사용하여 각 영역에 대한 접근을 활성화하거나 비활성화합니다.

:::warning
**도메인 관리자**는 ChurchApps 계정의 모든 영역에 대해 전체 접근 권한을 가집니다. 해당 권한을 수정하거나 제한할 수 없습니다. 이 역할을 가장 신뢰할 수 있는 관리자에게만 사용하세요.
:::

:::tip
"재무" 역할을 만들어 **기부금** 접근만 제공하거나, "체크인 자원봉사자" 역할을 만들어 **참석** 접근만 제공하는 등 구체적인 역할을 만드세요. 이것은 최소 권한 원칙을 따르며 데이터를 안전하게 유지합니다. 자세한 내용은 [데이터 보안](./data-security.md)을 참조하세요.
:::
