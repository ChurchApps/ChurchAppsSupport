# 체크인 라벨 디자이너

<div class="article-intro">

라벨 디자이너를 사용하면 가족이 자녀를 체크인할 때 인쇄되는 이름표 및 픽업 슬립 템플릿을 만들고 사용자 정의할 수 있습니다. 각 라벨에 나타나는 정보, 위치 및 모양을 정확히 제어할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [출석](setup)을 설정하고 체크인을 사용하도록 설정한 서비스 시간을 하나 이상 구성합니다
- [체크인](check-in)을 설정하여 라벨이 인쇄되는지 확인합니다
- 출석 섹션에 대한 관리 액세스가 필요합니다

</div>

## 라벨 디자이너 열기

B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **모바일**을 확장하여 **B1 CheckIn**을 클릭합니다. 그런 다음 체크인 라벨 카드에서 **라벨 디자인** 버튼을 클릭합니다. 유형별로 분리된 저장된 라벨 템플릿 목록이 표시됩니다: **이름표** 및 **픽업 슬립**.

## 라벨 유형

- **이름표** — 인쇄되어 어린이에게 부착됩니다. 일반적으로 어린이 이름, 교실/세션 및 보안 코드를 포함합니다.
- **픽업 슬립** — 부모 또는 보호자에게 제공됩니다. 일반적으로 보안 코드와 체크인한 어린이 목록을 포함합니다.

B1은 표준 3.5 × 1.1인치 열감지 라벨 크기의 기본 이름표 및 기본 픽업 슬립 템플릿으로 시작합니다.

## 라벨 템플릿 만들기

1. **추가**를 클릭하고 메뉴에서 시작점을 선택하세요: **이름표 3.5" x 1.1"**, **픽업 슬립 3.5" x 1.1"** 또는 **공백**.
2. 라벨 편집기에서 새 템플릿이 열립니다.

### 라벨 편집기

편집기는 구성된 크기의 라벨 축소 미리보기를 표시합니다. 왼쪽 패널을 따라 다음을 구성할 수 있습니다:

- **이름** — 템플릿 이름(참조 목적으로만)
- **라벨 유형** — 이름표 또는 픽업 슬립
- **너비 / 높이** — 인치 단위의 라벨 크기

### 블록 추가

라벨은 블록 — 라벨 캔버스에 배치된 개별 콘텐츠 조각으로 만들어집니다. **블록 추가**를 클릭하여 새 블록을 삽입하고 유형을 선택합니다:

- **필드** — 인쇄 시간에 데이터 값을 가져옵니다:
  - `person.displayName` — 사람의 전체 이름
  - `sessions` — 체크인한 서비스/교실
  - `securityCode` — 무작위로 생성된 픽업 보안 코드
  - `children` — 어린이 목록(픽업 슬립의 경우)
  - `person.nametagNotes` — 사람의 기록에 있는 특수 참고사항
  - `person.isBirthdayWeek` — 사람의 생일(월 및 일)이 체크인 날짜 전후 3일 이내인 경우 참
  - `campus` — 캠퍼스 이름
- **텍스트** — 입력한 정적 텍스트(제목, 레이블 또는 지침의 경우)
- **바코드** — 보안 코드를 인코딩하는 바코드

### 블록 배치

각 블록에는 라벨 캔버스의 백분율(0-100)로 표현되는 **X**, **Y**, **너비** 및 **높이** 필드가 있습니다. 이를 조정하여 콘텐츠를 정확히 배치하세요. 다음을 설정할 수도 있습니다:

- **글꼴 크기** — 포인트 단위의 텍스트 크기
- **굵게** — 굵은 텍스트 토글
- **정렬** — 왼쪽, 중앙 또는 오른쪽 텍스트 정렬
- **조건** — 필드가 비어있으면 선택적으로 블록을 숨깁니다(예: nametagNotes에 값이 있는 경우에만 표시). 이는 `person.isBirthdayWeek`로도 작동하여 생일이 체크인의 며칠 이내인 어린이의 이름표에만 생일 그래픽 또는 텍스트를 표시합니다.

### 저장

**저장**을 클릭하여 템플릿을 저장합니다. 업데이트된 템플릿은 B1 Checkin에서 라벨을 인쇄할 때 다음에 사용됩니다.

## 템플릿 순서 변경

여러 이름표 또는 픽업 슬립 템플릿이 있는 경우 B1 Checkin은 기본적으로 목록의 첫 번째 템플릿을 사용합니다. 템플릿을 끌어서 순서를 변경하세요.

## 템플릿 삭제

템플릿 행의 삭제 아이콘을 클릭하고 확인하세요. 유형의 마지막 템플릿을 삭제하면 기본 내장 템플릿이 복원됩니다.

:::tip
템플릿을 편집한 후 테스트 인쇄를 하여 다음 서비스 전에 레이아웃이 올바르게 보이는지 확인합니다.
:::
