# 체크인 레이블 디자이너

<div class="article-intro">

레이블 디자이너를 사용하면 가족이 아동을 체크인할 때 인쇄되는 이름표 및 픽업 전표 템플릿을 만들고 사용자 정의할 수 있습니다. 각 레이블에 표시되는 정보, 위치 및 모양을 정확히 제어할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [출석](setup)을 설정하고 체크인이 활성화된 최소 하나의 서비스 시간 구성
- [체크인](check-in)을 설정하여 레이블이 인쇄되는지 확인
- 출석 섹션에 대한 관리자 액세스 필요

</div>

## 레이블 디자이너 열기

B1 Admin에서 왼쪽 상단의 **섹션 메뉴**(현재 섹션 이름과 옆의 작은 화살표)를 클릭하고 **모바일**을 선택합니다. 탐색 모음에서 **B1 CheckIn**을 선택한 후 체크인 레이블 카드의 **레이블 디자인** 버튼을 클릭합니다. 저장된 레이블 템플릿 목록이 유형별로 분리되어 표시됩니다: **이름표** 및 **픽업 전표**.

## 레이블 유형

- **이름표** — 인쇄되어 아동에게 부착됩니다. 일반적으로 아동의 이름, 교실/세션 및 보안 코드를 포함합니다.
- **픽업 전표** -- 부모 또는 보호자에게 제공됩니다. 일반적으로 보안 코드와 체크인한 아동 목록을 포함합니다.

B1은 표준 3.5 × 1.1인치 열전사 레이블용으로 크기 지정된 기본 이름표 및 기본 픽업 전표 템플릿으로 시작합니다.

## 레이블 템플릿 생성

1. **이름표 추가** 또는 **픽업 전표 추가**(또는 드롭다운을 사용하여 선택)를 클릭합니다.
2. 새 템플릿이 레이블 편집기에서 열립니다.

### 레이블 편집기

편집기는 구성된 크기로 레이블의 축소된 미리보기를 보여줍니다. 왼쪽 패널에서 다음을 구성할 수 있습니다:

- **이름** — 템플릿 이름(참조용)
- **레이블 유형** — 이름표 또는 픽업 전표
- **너비 / 높이** -- 인치 단위의 레이블 크기

### 블록 추가

레이블은 블록(레이블 캔버스에 배치된 개별 콘텐츠)으로 구성됩니다. **블록 추가**를 클릭하여 새 블록을 삽입하고 해당 유형을 선택합니다:

- **필드** — 인쇄 시 데이터 값을 가져옵니다:
  - `person.displayName` — 사람의 전체 이름
  - `sessions` — 체크인한 서비스/교실
  - `securityCode` — 무작위로 생성된 픽업 보안 코드
  - `children` — 아동 목록(픽업 전표용)
  - `person.nametagNotes` — 사람의 기록에 있는 특별 메모
  - `campus` — 캠퍼스 이름
- **텍스트** -- 입력하는 정적 텍스트(제목, 레이블 또는 지침용)
- **바코드** — 보안 코드를 인코딩하는 바코드

### 블록 배치

각 블록에는 레이블 캔버스의 백분율로 표현된 **X**, **Y**, **너비** 및 **높이** 필드가 있습니다(0-100). 이를 조정하여 콘텐츠를 정확히 배치합니다. 다음을 설정할 수도 있습니다:

- **글꼴 크기** — 포인트 단위의 텍스트 크기
- **굵음** — 굵은 텍스트 토글
- **정렬** -- 왼쪽, 중앙 또는 오른쪽 텍스트 정렬
- **조건** -- 필드가 비어 있으면 선택적으로 블록 숨기기(예: 값이 있는 경우에만 nametagNotes 표시)

### 저장

**저장**을 클릭하여 템플릿을 저장합니다. 업데이트된 템플릿은 B1 Checkin에서 다음에 레이블이 인쇄될 때 사용됩니다.

## 템플릿 재정렬

여러 개의 이름표 또는 픽업 전표 템플릿이 있는 경우 B1 Checkin은 기본적으로 목록의 첫 번째 템플릿을 사용합니다. 템플릿을 끌어서 재정렬하세요.

## 템플릿 삭제

템플릿 행의 삭제 아이콘을 클릭하고 확인합니다. 유형의 마지막 템플릿을 삭제하면 기본 제공 템플릿이 복원됩니다.

:::tip
템플릿을 편집한 후 테스트 인쇄를 수행하여 다음 서비스 전에 레이아웃이 올바르게 보이는지 확인하세요.
:::
