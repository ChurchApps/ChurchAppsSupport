# 출석 기록

<div class="article-intro">

캠퍼스, 예배 시간 및 그룹을 설정한 후에는 각 모임 후에 출석을 수동으로 기록할 수 있습니다. B1 Admin은 **세션** 주위에 출석을 정렬합니다 -- 그룹당 모임 날짜당 하나의 세션. 세션을 생성하고, 참석자를 표시하면, 데이터가 출석 보고서에 직접 연결됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 캠퍼스, 예배 시간 및 그룹을 설정해야 합니다. 아직 설정하지 않았다면 [출석 설정](setup.md)을 참조하세요.
- 추적하려는 그룹에 **출석 추적** 활성화되어 있어야 합니다. 자세한 내용은 [출석 설정](setup.md)을 참조하세요.

</div>

## 세션 생성

세션은 그룹 모임의 한 번의 발생을 나타냅니다 -- 예를 들어, 특정 일요일의 K-3학년 클래스입니다.

1. **B1 Admin**을 열고, 왼쪽 상단의 **섹션 메뉴**를 열어 **사람**을 선택한 후, **그룹** 탭을 클릭합니다.
2. 출석을 기록하려는 그룹을 선택합니다.
3. **세션** 탭을 클릭합니다.
4. **새로 만들기**를 클릭하여 새 세션을 만듭니다.
5. 그룹이 예배 시간에 할당되었으면 **예배 시간**을 선택합니다. 스케줄되지 않은 그룹인 경우 이 필드가 나타나지 않습니다.
6. **세션 날짜**를 선택합니다 -- 오늘, 과거 날짜 또는 미래 날짜가 될 수 있습니다.
7. **저장**을 클릭합니다.

:::tip
과거 날짜의 세션을 만들어 아직 기록하지 않은 출석을 보완할 수도 있고, 미리 만들어서 그룹이 모일 때 준비할 수도 있습니다.
:::

## 출석 표시

세션을 선택하여 출석 목록을 확인합니다. 모든 그룹 구성원이 체크박스와 함께 표시되며, 성을 기준으로 정렬되고, 이미 참석으로 기록된 사람은 선택되어 있습니다.

1. 참석한 각 사람 옆의 상자를 선택합니다. **모두 선택** 또는 **없음 선택**을 사용하여 모든 사람을 한 번에 변경할 수 있습니다.
2. 목록 위의 개수(예: "15명 중 12명 출석")는 상자를 선택하면서 업데이트됩니다.
3. **출석 저장**을 클릭합니다. 저장할 때까지는 아무것도 기록되지 않으며, 저장이 완료되면 메시지가 확인됩니다.

이미 참석으로 기록된 사람의 선택을 해제한 후 저장하면 해당 사람이 세션에서 제거됩니다.

### 방문객 추가

그룹의 구성원이 아닌 사람을 기록하려면 출석 목록 옆의 사람 검색에서 검색합니다. 데이터베이스에 없으면 검색에서 만들 수 있습니다. 그들은 이미 선택된 상태로 목록에 추가됩니다. **출석 저장**을 클릭하여 기록합니다.

키오스크에서 체크인한 사람은 **자원봉사자** 또는 **손님** 칩을 표시합니다. 그룹 구성원이 아닌 사람은 **손님** 칩을 표시합니다.

## 롤 시트 인쇄

롤 시트는 교사가 손으로 표시하고 나중에 입력하도록 돌려줄 수 있는 인쇄 가능한 클래스 목록입니다. 각 시트는 교회 이름, 클래스, 예배 시간 및 날짜 줄을 보여줍니다. 모든 구성원에는 **참석** 및 **부재중** 상자가 있으며, 방문객을 위한 빈 줄과 **교사 / 메모** 영역이 있습니다.

- **세션에서** -- 세션의 출석 목록 위에서 **롤 시트 인쇄**(프린터) 아이콘을 클릭합니다. 시트는 세션의 날짜로 표시됩니다.
- **예배를 위한 모든 클래스** -- 세션에 예배 시간이 있으면 **모든 클래스 인쇄**를 클릭하여 해당 예배 시간에 할당된 클래스당 하나의 시트를 인쇄합니다. 각 클래스는 자체 페이지에 인쇄됩니다.
- **멤버 탭에서** -- 그룹의 구성원 목록 위의 **롤 시트 인쇄** 아이콘을 클릭하여 날짜가 없는 시트를 인쇄합니다.

시트는 새 탭에서 열리고 브라우저의 인쇄 대화상자가 자동으로 나타납니다.

## 출석을 스프레드시트로 내보내기

세션의 기록을 CSV 파일로 다운로드하여 Excel, Numbers 또는 Google Sheets에서 사용할 수 있습니다.

1. 내보내려는 세션을 엽니다.
2. 출석 목록 위의 **내보내기** 버튼을 클릭합니다.
3. 다운로드한 파일을 스프레드시트 응용 프로그램에서 엽니다.

## 기록된 출석 보기

세션을 기록한 후 데이터가 출석 보고서에 표시됩니다.

- **출석 동향 탭** -- 시간에 따른 교회 전체 동향을 보여줍니다. [출석 추적](tracking-attendance.md)을 참조하세요.
- **그룹 출석 탭** -- 개별 그룹별로 분류된 출석을 보여줍니다.

:::tip
방금 생성한 세션이 보고서에 바로 나타나지 않으면 세션 날짜가 보고서 필터에서 선택한 날짜 범위 내에 있는지 확인하세요.
:::
