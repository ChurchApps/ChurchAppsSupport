# 출석 기록

<div class="article-intro">

캠퍼스, 서비스 시간, 그룹이 설정되었다면, 모임이 끝난 후 출석을 수동으로 기록할 수 있습니다. B1 Admin은 **세션** 중심으로 출석을 관리합니다. 각 세션은 한 그룹이 한 번 만난 것을 나타냅니다. 세션을 생성하고, 참석자를 표시하면 데이터가 출석 보고서에 직접 반영됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 캠퍼스, 서비스 시간, 그룹이 구성되어야 합니다. [출석 설정](setup.md)을 참고하세요.
- 추적하려는 그룹에 **출석 추적**이 활성화되어 있어야 합니다. [출석 설정](setup.md)의 세부 정보를 참고하세요.

</div>

## 세션 생성

세션은 그룹의 모임이 한 번 열리는 것을 나타냅니다. 예를 들어 특정 일요일의 K~3학년 반 수업입니다.

1. **B1 Admin**을 열고, **섹션 메뉴**를 열고 **사람들**을 선택한 후 **그룹** 탭을 클릭합니다.
2. 출석을 기록할 그룹을 선택합니다.
3. **세션** 탭을 클릭합니다.
4. **새로 만들기**를 클릭하여 새 세션을 생성합니다.
5. 그룹이 서비스 시간에 할당되어 있으면 **서비스 시간**을 선택합니다. 정해진 시간이 없는 그룹인 경우 이 필드가 표시되지 않습니다.
6. **세션 날짜**를 선택합니다. 과거 날짜, 오늘, 또는 미래 날짜일 수 있습니다.
7. **저장**을 클릭합니다.

:::tip
아직 기록하지 않은 과거 날짜의 세션을 생성하거나, 그룹이 모이기 전에 미리 세션을 생성할 수 있습니다.
:::

## 출석 표시

세션을 저장하면, 그룹의 구성원이 페이지 오른쪽에 나타납니다.

1. 참석한 각 사람 옆의 체크박스를 선택합니다.
2. 변경 사항은 자동으로 저장됩니다. 출석 표시에는 추가 저장 버튼이 없습니다.

:::info
현재 그룹 구성원만 세션 목록에 나타납니다. 누군가 참석했지만 아직 그룹에 없으면 먼저 [그룹에 추가](../groups/group-members.md)한 후 출석을 기록합니다.
:::

## 출석 정보를 스프레드시트로 내보내기

세션 기록을 CSV 파일로 다운로드하여 Excel, Numbers 또는 Google Sheets에서 사용할 수 있습니다.

1. 내보낼 세션을 엽니다.
2. **CSV 다운로드** 버튼을 클릭합니다.
3. 다운로드한 파일을 스프레드시트 애플리케이션에서 엽니다.

## 기록된 출석 보기

세션을 기록한 후 데이터가 출석 보고서에 나타납니다.

- **출석 탭** — 시간에 따른 교회 전체의 추세를 보여줍니다. [출석 추적](tracking-attendance.md)을 참고하세요.
- **그룹 탭** — 개별 그룹별로 세분화된 출석을 표시합니다.

:::tip
방금 생성한 세션이 보고서에 즉시 나타나지 않으면, 세션 날짜가 보고서 필터에서 선택한 날짜 범위 내에 있는지 확인하세요.
:::
