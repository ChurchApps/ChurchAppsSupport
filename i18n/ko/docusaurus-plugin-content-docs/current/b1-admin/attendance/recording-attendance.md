# 출석 기록

<div class="article-intro">

캠퍼스, 서비스 시간 및 그룹이 설정되면 각 모임 후에 출석을 수동으로 기록할 수 있습니다. B1 Admin은 **세션** 주위에 출석을 구성합니다 -- 모임 날짜당 그룹당 하나의 세션. 세션을 만들고, 누가 보였는지 표시하고, 데이터가 직접 출석 보고서에 공급됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 캠퍼스, 서비스 시간 및 그룹이 구성되어 있어야 합니다. 아직 하지 않았다면 [출석 설정](setup.md)을 참조하세요.
- 추적하려는 그룹에서 **출석 추적**을 활성화해야 합니다. 자세한 내용은 [출석 설정](setup.md)을 참조하세요.

</div>

## 세션 만들기

세션은 그룹 모임의 한 번 발생을 나타냅니다 — 예를 들어, 특정 일요일의 유아반-3학년 수업입니다.

1. **B1 Admin**을 열고 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **사람**을 확장하여 **그룹**을 클릭하세요.
2. 출석을 기록하려는 그룹을 선택하세요.
3. **세션** 탭을 클릭하세요.
4. **새로 만들기**를 클릭하여 새 세션을 만듭니다.
5. 그룹이 서비스 시간에 할당된 경우 **서비스 시간**을 선택합니다. 예정되지 않은 그룹인 경우 이 필드는 나타나지 않습니다.
6. **세션 날짜**를 선택합니다 — 이는 오늘, 과거 날짜 또는 미래 날짜일 수 있습니다.
7. **저장**을 클릭하세요.

### 서비스 시간에서 모든 수업에 대한 세션 추가

다른 그룹이 동일한 서비스 시간에 모이는 경우(예: 일요일 오전 9:00의 모든 어린이 수업), 각 그룹을 방문하는 대신 한 단계에서 세션을 만들 수 있습니다.

1. 위 단계를 따르고 **서비스 시간**을 선택합니다.
2. **또한 _service time_의 다른 _N_ 그룹에 대해 추가**를 확인합니다. 확인란은 해당 서비스 시간에 할당된 다른 그룹의 수를 보여줍니다. 새 세션을 추가할 때 그리고 최소 하나의 다른 그룹이 해당 시간에 모일 때만 나타납니다.
3. **저장**을 클릭하세요.

세션은 현재 그룹과 동일한 날짜 및 서비스 시간의 각 다른 그룹에 대해 만들어집니다. 해당 날짜 및 서비스 시간에 대해 이미 세션이 있는 그룹은 건너뛰므로 중복이 발생하지 않습니다.

:::tip
아직 기록하지 않은 출석을 따라잡기 위해 과거 날짜에 대한 세션을 만들거나 그룹이 모일 때 준비되도록 미리 만들 수 있습니다.
:::

## 출석 표시

세션을 선택하여 출석 목록을 봅니다. 모든 그룹 회원이 확인란으로 나열되고 성 이름순으로 정렬되며 이미 출석으로 기록된 사람은 확인됩니다.

1. 참석한 각 사람 옆의 상자를 선택합니다. **모두 선택** 또는 **없음 선택**을 사용하여 한 번에 모두를 변경합니다.
2. 목록 위의 수(예: "15명 중 12명 출석")는 확인란을 선택하면서 업데이트됩니다.
3. **출석 저장**을 클릭합니다. 저장할 때까지 아무것도 기록되지 않으며 메시지는 저장이 완료되면 확인합니다.

이미 출석으로 기록된 사람을 선택 해제한 다음 저장하면 세션에서 제거됩니다.

### 방문자 추가

그룹의 회원이 아닌 사람의 출석을 기록하려면 출석 목록 옆의 사람 검색에서 그들을 검색합니다. 아직 데이터베이스에 없는 경우 검색에서 만들 수 있습니다. 그들은 이미 확인된 목록에 추가됩니다. **출석 저장**을 클릭하여 기록합니다.

키오스크에서 체크인한 사람은 **자원봉사자** 또는 **손님** 칩을 표시합니다. 그룹 회원이 아닌 사람은 **손님** 칩을 표시합니다.

## 여전히 출석이 필요한 그룹 확인

여러 수업이 동일한 서비스 시간에 모일 때 해당 날짜에 대해 출석을 입력해야 하는 그룹을 한 눈에 볼 수 있습니다.

1. 서비스 시간이 있는 세션을 엽니다.
2. 출석 목록 맨 위의 **여전히 출석이 필요한 사람**을 클릭합니다.
3. 대화가 해당 서비스 시간에 할당된 모든 그룹을 나열하며 맨 위에 "8개 그룹 중 5개 입력됨"과 같은 요약을 표시합니다.

해당 날짜에 출석으로 표시된 사람이 없는 그룹은 **입력되지 않음** 칩을 표시하고 먼저 나열됩니다. 출석이 있는 그룹은 예를 들어 "입력됨(12)"과 같이 표시된 사람 수와 함께 **입력됨**을 표시합니다. 그룹 이름을 클릭하여 해당 그룹으로 이동하고 출석을 기록합니다.

:::tip
이를 **모든 수업 인쇄**와 [서비스 시간의 모든 수업에 대한 세션 추가](#adding-sessions-for-every-class-in-a-service-time)로 쌍을 이룹니다: 세션을 만들고, 출석부를 배포한 다음 **여전히 출석이 필요한 사람**을 사용하여 어떤 시트가 아직 입력되지 않았는지 확인합니다.
:::

## 출석부 인쇄

출석부는 교사가 손으로 표시할 수 있는 인쇄 가능한 수업 목록이며 나중에 입력하기 위해 반환할 수 있습니다. 각 시트는 교회 이름, 수업, 수업 이름 아래의 큰 **날짜** 줄 및 서비스 시간을 보여줍니다. 회원은 2개의 열에 나열되므로(왼쪽 열을 읽은 다음 오른쪽) 더 많은 이름이 페이지에 맞습니다. 모든 회원은 **출석** 및 **부재** 상자를 가지고 있습니다. 방문자를 위한 빈 줄과 **교사 / 참고** 영역이 있습니다.

- **세션에서** -- 세션의 출석 목록 맨 위의 **출석부 인쇄**(프린터) 아이콘을 클릭합니다. 시트는 세션의 날짜로 표시됩니다.
- **서비스의 모든 수업** -- 세션에 서비스 시간이 있는 경우 **모든 수업 인쇄**를 클릭하여 해당 서비스 시간에 할당된 각 수업당 한 장씩 인쇄합니다. 각 수업이 자신의 페이지에 인쇄됩니다.
- **회원 탭에서** -- 그룹의 회원 목록 위의 **출석부 인쇄** 아이콘을 클릭한 다음 **출석 시트**를 선택하여 날짜가 없는 시트를 인쇄합니다. 같은 메뉴에는 각 회원의 전화번호, 이메일, 주소가 포함된 **연락처 명부** 레이아웃도 있습니다. [회원 목록 인쇄하기](../groups/group-members.md#printing-the-member-list)를 참조하세요.

시트가 새 탭에서 열리고 브라우저의 인쇄 대화가 자동으로 나타납니다.

## 출석을 스프레드시트로 내보내기

세션의 기록을 CSV 파일로 다운로드하여 Excel, Numbers 또는 Google Sheets에서 사용할 수 있습니다.

1. 내보내려는 세션을 엽니다.
2. 출석 목록 맨 위의 **내보내기** 버튼을 클릭합니다.
3. 스프레드시트 응용 프로그램에서 다운로드한 파일을 엽니다.

## 기록된 출석 보기

세션을 기록한 후 데이터가 출석 보고서에 나타납니다.

- **출석 추세 탭** -- 시간 경과에 따른 교회 전체 추세를 표시합니다. [출석 추적](tracking-attendance.md)을 참조하세요.
- **그룹 출석 탭** -- 개별 그룹별로 분류된 출석을 표시합니다. [출석 보고서](../reports/attendance-reports.md#group-attendance)를 참조하세요.

:::tip
방금 만든 세션이 보고서에 바로 나타나지 않으면 세션 날짜가 보고서 필터에서 선택한 날짜 범위에 포함되는지 확인합니다.
:::
