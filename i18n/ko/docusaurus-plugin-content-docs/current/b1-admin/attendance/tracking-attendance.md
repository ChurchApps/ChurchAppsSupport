# 출석 추적

<div class="article-intro">

캠퍼스, 서비스 시간 및 그룹이 구성되면 B1 Admin은 출석 데이터를 검토하고 추세를 파악하기 쉽게 합니다. 출석 페이지는 두 가지 보고 보기 — 교회 전체 추세를 위한 **출석 추세** 탭과 그룹 수준의 세부 정보를 위한 **그룹 출석** 탭을 제공합니다. 이러한 도구를 사용하여 성장 패턴을 이해하고, 감소하는 참여를 식별하고, 교회를 위해 데이터 기반 결정을 내립니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 출석 구조는 최소 하나의 캠퍼스 및 서비스 시간으로 설정되어야 합니다. 아직 하지 않았다면 [출석 설정](setup.md)을 참조하세요.
- 보고서에 결과를 표시하려면 출석 데이터를 기록해야 합니다. 데이터는 [수동 입력](recording-attendance.md) 또는 [자동 체크인](check-in.md)에서 올 수 있습니다.

</div>

## 출석 추세 보기

1. **B1 Admin**을 열고 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **사람**을 확장하여 **출석**을 클릭합니다.
2. **출석 추세** 탭을 클릭합니다.
3. 보고서는 탭이 열릴 때 자동으로 실행되어 각 주의 총 출석을 표시합니다.

## 데이터 필터링

**보고서 필터** 상자의 필터를 사용하여 결과를 좁히고 **보고서 실행**을 클릭합니다:

- **캠퍼스** -- 캠퍼스를 선택하여 해당 위치만의 출석을 확인합니다.
- **서비스** -- 보고서를 하나의 서비스로 제한합니다.
- **서비스 시간** -- 특정 모임으로 드릴 인하기 위해 서비스 시간을 선택합니다.
- **그룹** -- 단일 그룹의 출석을 표시합니다.
- **시작 날짜** 및 **종료 날짜** -- 포함할 날짜 범위입니다. 기본적으로 보고서는 지난 1년간, 1년 전부터 오늘까지 범위하며 종료 날짜는 완전히 포함됩니다.

보고서는 주당 총 방문의 막대 차트 및 표를 표시합니다. 각 주는 그 주의 일요일 날짜로 표시됩니다. 표에는 해당 주에 출석이 있었던 실제 날짜를 나열하는 **세션 날짜** 열(예: "9/27, 9/30")도 있으므로 주중 모임이 일요일과 같은 주에 계산되는 시기를 볼 수 있습니다.

:::info
보고서는 출석 추세 탭을 열 때마다 자동으로 실행되므로 새로 고침 버튼을 클릭할 필요 없이 항상 최신 숫자를 볼 수 있습니다.
:::

## 그룹 출석

**그룹 출석** 탭은 각 그룹 세션에 참석한 사람을 표시합니다. 전체 서비스 번호를 보기보다는 특정 수업, 사역 팀 또는 소그룹을 모니터링하려고 할 때 유용합니다.

1. **그룹 출석** 탭을 선택합니다.
2. 선택적으로 **캠퍼스** 및 **서비스**를 선택합니다.
3. **시작 날짜** 및 **종료 날짜**를 설정합니다. 기본적으로 보고서는 지난 일요일부터 오늘까지 범위합니다.
4. **보고서 실행**을 클릭합니다.

결과는 세션 날짜별로 그룹화되고 서비스 시간 및 그룹별로 그룹화되며 각 그룹 아래에 참석한 사람이 나열됩니다. 서비스 시간, 그룹 및 이름이 알파벳순으로 정렬되므로 각 제목이 한 번 나타납니다. 각 사람의 행은 출석이 기록된 시간을 포함하는 **체크인** 열(파일에 시간이 없으면 공백) 및 **회원 자격 상태** 열(예: 회원 또는 방문자)도 표시하므로 한 눈에 손님을 찾을 수 있습니다.

데이터를 다운로드하려면 **다운로드 옵션**을 클릭하고 **요약**을 선택합니다. CSV는 그룹별로 정렬되고 이름별로 정렬되는 그룹 회원당 한 행을 가지며 범위의 각 날짜 세션에 대한 열(예: "일요일 - 오전 9:00 (2026-09-27)")을 **출석** 또는 **부재**로 표시합니다.

:::tip
그룹 출석은 시간 경과에 따라 자신의 그룹 내 참여를 추적하려는 [소그룹](../groups/creating-groups.md) 리더에게 특히 유용합니다.
:::

## 출석 데이터 사용 팁

- 월별로 추세를 검토하여 계절 패턴을 조기에 포착합니다.
- 캠퍼스 수준의 데이터를 비교하여 어느 위치가 성장하고 있는지 파악합니다.
- 그룹 수준의 보고서를 사용하여 출석 감소를 보이는 [그룹](../groups/group-members.md)을 팔로우업합니다.
- 출석 통찰력을 [AI 검색](../people/ai-search.md) 도구와 결합하여 최근에 참석하지 않은 사람을 찾습니다.
