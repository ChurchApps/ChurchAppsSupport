# 출석 추적
<div class="article-intro">
캠퍼스, 서비스 시간, 그룹이 구성되면 B1 Admin은 출석 데이터를 쉽게 검토하고 추세를 발견할 수 있게 해줍니다. 출석 페이지는 두 가지 보고 보기를 제공합니다. 이 도구들을 사용하여 성장 패턴을 파악하고, 참여도 저하를 식별하고, 교회를 위한 데이터 기반 결정을 내릴 수 있습니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- 출석 구조가 최소 한 캠퍼스와 서비스 시간으로 설정되어야 합니다.
- 보고서가 결과를 표시하기 전에 출석 데이터를 기록해야 합니다.
</div>
## 출석 추세 보기
1. **B1 Admin**을 열고, 왼쪽 위 **섹션 메뉴**를 열고 **사람들**을 선택합니다.
2. **출석** 탭을 클릭합니다.
3. 탭이 열리면 보고서가 자동으로 실행됩니다.
## 데이터 필터링
페이지 위쪽의 필터를 사용하여 결과를 좁힙니다:
- **날짜 범위** — 특정 기간에 초점을 맞춥니다.
- **캠퍼스** — 특정 위치의 출석만 봅니다.
- **서비스 시간** — 특정 모임을 선택합니다.
## 그룹 출석
**그룹** 탭은 개별 그룹별로 세분화된 출석을 표시합니다.
1. **그룹** 탭을 선택합니다.
2. 목록에서 그룹을 선택합니다.
3. 날짜 범위 필터를 사용하여 보고 기간을 조정합니다.
