# 출석 설정

<div class="article-intro">

출석을 기록하려면 먼저 B1 Admin에 교회의 실제 장소, 예배 시간, 각 예배에 모이는 그룹을 알려 주어야 합니다. 이 한 번의 설정으로 교회 전체의 출석 추적과 보고의 기반이 되는 구조가 만들어집니다.

</div>

<h4>시작하기 전에</h4>

- **Edit Services** 출석 권한이 있는 활성 B1 Admin 계정이 필요합니다. **Setup** 옵션은 이 권한이 있는 사람에게만 보입니다. 출석 보기 권한만으로는 충분하지 않습니다. 접근 수준이 확실하지 않다면 [역할 및 권한](../people/roles-permissions.md)을 참고하세요.
- 예배 시간에 그룹을 배정할 계획이라면, 먼저 [그룹을 만들어](../groups/creating-groups.md) 두세요.

## 핵심 개념

- **캠퍼스** -- 교회가 모이는 실제 장소입니다(예: "Main Campus", "North Campus"). 캠퍼스는 **설정**에서 관리합니다.
- **예배** -- 캠퍼스에서 반복적으로 열리는 모임입니다(예: "Sunday Service", "Midweek").
- **예배 시간** -- 예배가 열리는 특정 시간입니다(예: "9:00 AM", "11:00 AM").
- **예배 배정 그룹** -- 특정 예배 시간에 배정된 그룹입니다. 출석은 그 예배의 맥락 안에서 추적됩니다.
- **예배 미배정 그룹** -- 예배 시간과 연결되지 않고 자체적으로 출석을 추적하는 그룹입니다.

## 출석 구조 설정하기

1. **B1 Admin**을 열고, [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 위의 검색창)를 연 다음 **People**을 펼치세요.
2. **Attendance**를 클릭한 뒤 왼쪽 열에서 **Setup**을 클릭하세요. **Service structure** 표가 열리며, 위쪽에 캠퍼스, 예배 시간, 예배 배정 그룹과 예배 미배정 그룹의 개수가 표시됩니다. 표에서 무언가를 추가, 수정, 삭제하면 개수가 바로 갱신됩니다.
3. **Service structure** 패널 오른쪽 위의 **Manage Campuses**를 클릭하세요. **Settings → Campuses**로 이동합니다. **Add Campus**를 클릭하고, 장소 이름을 입력하세요(주소와 시간대는 선택 사항입니다). 그다음 **Save**를 클릭하세요.
4. **People → Attendance**로 돌아가 **Setup**을 클릭하세요. 방금 만든 캠퍼스가 설정 표에 나타납니다.
5. 캠퍼스 아래 **Service** 열의 **+ 버튼**을 클릭하세요. "Sunday Service" 같은 예배 이름을 입력하고 **Save**를 클릭하세요.
6. 예배 아래 **Time** 열의 **+ 버튼**을 클릭하세요. **Service Time** 이름(예: "9:00 AM")을 입력하고, 원하면 [체크인 일정](#setting-a-check-in-schedule)을 입력한 뒤 **Save**를 클릭하세요. 예배 시간마다 반복하세요.
7. 그룹을 예배 시간에 연결하려면 **People > Groups**에서 그룹을 열고 **Edit**를 클릭한 뒤 **Add Service Time**을 사용하세요. 다음 절을 참고하세요.

### 그룹에서 Track Attendance 켜기

그룹의 출석을 기록하려면 먼저 해당 그룹의 Track Attendance를 켜야 합니다.

1. 점프 메뉴에서 **People > Groups**를 선택하고 그룹을 여세요.
2. 그룹 이름 아래의 **Edit** 버튼을 클릭하세요.
3. **Track Attendance**를 **Yes**로 설정하세요.
4. **Save**를 클릭하세요.

:::tip
앞 단계에서 그룹을 예배 시간에 배정했다면, 그룹의 편집 화면에서 **Add Service Time** 옵션도 사용해 올바른 예배에 연결하세요. 그래야 출석 세션이 올바른 캠퍼스와 시간에 연결됩니다.
:::

:::tip
정규 예배 밖에서 모이는 그룹(자체적으로 출석을 추적하는 수요일 소그룹 등)이라면 예배 미배정 그룹으로 두면 됩니다. 그래도 출석 보고를 위해 **Group Attendance** 보고서에는 나타납니다.
:::

## 체크인 일정 설정하기 {#setting-a-check-in-schedule}

예배 시간마다 선택 사항인 체크인 일정을 둘 수 있습니다. 이렇게 하면 [셀프 체크인](check-in.md)이 매주 스스로 열리고 닫힙니다. 일정이 없으면 그 예배 시간의 체크인은 언제든지 가능합니다(방이 가득 찼거나 다른 이유로 닫히지 않은 경우에 한해).

1. **Setup** 화면에서 **Time** 열의 예배 시간 이름을 클릭하세요(또는 새로 추가하세요).
2. **Check-in Schedule** 아래에서 예배 시간이 열리는 요일인 **Day**를 고르세요.
3. **Start Time**과 필요하다면 **End Time**을 설정하세요.
4. **Open check-in (minutes before start)**를 입력하세요. 예를 들어 `30`이면 예배 시작 30분 전에 체크인이 열립니다.
5. **Close check-in (minutes after end)**를 입력하세요. 예를 들어 `15`이면 종료 시간 이후 15분 동안 체크인이 열려 있습니다. 종료 시간을 설정하지 않았다면 시작 시간부터 계산합니다.
6. **Save**를 클릭하세요.

일정은 매주 반복되며, 예배가 있는 캠퍼스의 시간대를 기준으로 합니다. 그 캠퍼스에 시간대가 없으면 교회의 [시간대](../settings/church-settings.md#time-zone)를 사용하고, 그것도 없으면 시간대가 설정된 첫 번째 캠퍼스의 시간대를, 마지막으로 동부 시간(America/New_York)을 사용합니다. 체크인이 잘못된 시간에 열린다면 [캠퍼스](../settings/campuses.md)에서 해당 캠퍼스의 **Time Zone**을 확인하세요. 일정을 지우려면 **Day**를 **No schedule**로 되돌리고 **Save**를 클릭하세요. 일정은 **Day**와 **Start Time**이 모두 설정되어 있을 때만 적용됩니다.

예배 시간의 체크인 창이 닫혀 있는 동안에는 다음과 같습니다.

- **B1.church의 셀프 체크인**은 그 예배 시간을 **Closed**(또는 예: **Closed · opens Sun 9:30 AM**)로 표시하며, 선택할 수 없습니다. 어떤 예배의 모든 시간이 닫혀 있으면, 가족들에게는 "Check-in opens Sun 9:30 AM."처럼 체크인이 열리는 시간이 보입니다.
- **B1 Checkin 키오스크 앱**도 그 예배 시간을 **Closed**와 함께 열리는 시간을 표시합니다. 한 예배의 모든 시간이 닫혀 있으면, 키오스크는 그 예배의 체크인이 언제 열리는지 알려 줍니다. 이미 닫힌 예배 시간에 체크인한 사람은 그룹 옆에 **Checked in**이 표시됩니다. 체크인 도중에 창이 닫히면, 키오스크는 체크인을 완료하지 않고 영향을 받은 방을 보여 주는 **Can't check in yet** 화면을 띄웁니다. 그러면 가족은 다른 방을 고를 수 있습니다.

이전 예배 시간에 이미 체크인한 가구는, 이전 창이 닫힌 뒤에도 다시 와서 열려 있는 나중 예배 시간을 추가할 수 있습니다. 기존 체크인은 그대로 유지됩니다.

:::tip
시작 45분 전처럼 넉넉한 열림 시간을 설정하면, 일찍 도착한 가족과 봉사자가 체크인할 수 있습니다. 닫힘 시간은 짧게 설정하면, 예배가 시작된 뒤에 늦게 온 사람은 체크인하기 어려워집니다.
:::

## 설정 편집하기

언제든지 설정을 바꿀 수 있습니다. 캠퍼스, 예배 시간, 그룹을 선택하고 **Edit**를 클릭하면 세부 정보를 바꿀 수 있으며, **Delete**를 클릭하면 삭제됩니다.

:::info
예배 시간을 삭제해도 지난 출석 기록은 삭제되지 않습니다. 일정을 바꾸더라도 과거 데이터는 그대로 보존됩니다.
:::
