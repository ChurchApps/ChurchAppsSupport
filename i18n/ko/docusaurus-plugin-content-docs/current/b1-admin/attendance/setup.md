# 출석 설정 {#attendance-setup}

<div class="article-intro">

출석을 추적하려면 먼저 B1 Admin에 교회의 실제 위치, 예배 시간, 각 예배에 모이는 그룹을 알려 주어야 합니다. 이 한 번의 설정으로 교회 전체의 모든 출석 추적과 보고의 기반 구조가 만들어집니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 출석을 관리할 권한이 있는 활성 B1 Admin 계정이 필요합니다. 접근 권한 수준이 확실하지 않다면 [역할 및 권한](../people/roles-permissions.md)을 참조하세요.
- 그룹을 예배 시간에 배정할 계획이라면, 먼저 [그룹을 만들어](../groups/creating-groups.md) 두어야 합니다.

</div>

## 핵심 개념 {#key-concepts}

- **캠퍼스** -- 교회가 모이는 실제 장소(예: "본당 캠퍼스", "북부 캠퍼스"). 캠퍼스는 **설정** 아래에서 관리합니다.
- **예배** -- 캠퍼스에서 정기적으로 열리는 모임(예: "주일 예배", "수요 모임").
- **예배 시간** -- 예배가 열리는 구체적인 시각(예: "오전 9:00", "오전 11:00").
- **예배 배정 그룹** -- 특정 예배 시간에 배정된 그룹입니다. 출석은 그 예배의 맥락에서 추적됩니다.
- **예배 미배정 그룹** -- 예배 시간에 묶이지 않고 자체적으로 출석을 추적하는 그룹입니다.

## 출석 구조 설정하기 {#setting-up-your-attendance-structure}

1. **B1 Admin**을 열고, [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 연 다음 **사람**을 펼칩니다.
2. **출석**을 클릭한 다음 왼쪽 열의 **설정**을 클릭합니다. **서비스 구조** 표가 열리며, 상단에 캠퍼스, 예배 시간, 예배 배정 그룹과 예배 미배정 그룹의 수가 표시됩니다.
3. **캠퍼스 관리**(**서비스 구조** 패널 오른쪽 상단)를 클릭합니다. **설정 → 캠퍼스**로 이동합니다. **캠퍼스 추가**를 클릭하고, 장소의 이름을 입력한 다음(주소와 시간대는 선택 사항입니다) **저장**을 클릭합니다.
4. **사람 → 출석**으로 돌아가 **설정**을 클릭합니다. 설정 표에 방금 만든 캠퍼스가 나타납니다.
5. 캠퍼스 아래의 **서비스** 열에 있는 **+ 버튼**을 클릭합니다. "주일 예배"와 같은 예배 이름을 입력하고 **저장**을 클릭합니다.
6. 예배 아래의 **시간** 열에 있는 **+ 버튼**을 클릭합니다. "오전 9:00"과 같은 **예배 시간** 이름을 입력하고, 원하면 [체크인 일정](#setting-a-check-in-schedule)을 채운 다음 **저장**을 클릭합니다. 예배 시간마다 반복합니다.
7. 그룹을 예배 시간에 연결하려면 **사람 > 그룹**에서 그룹을 열고 **편집**을 클릭한 다음 **예배 시간 추가**를 사용합니다. 다음 섹션을 참조하세요.

### 그룹에서 출석 추적 활성화하기 {#enabling-track-attendance-on-a-group}

그룹의 출석을 기록하려면 먼저 그 그룹에서 출석 추적을 켜야 합니다.

1. Jump 메뉴에서 **사람 > 그룹**을 선택하고 그룹을 선택합니다.
2. 그룹 이름 아래의 **편집** 버튼을 클릭합니다.
3. **출석 추적**을 **예**로 설정합니다.
4. **저장**을 클릭합니다.

:::tip
앞 단계에서 그룹을 예배 시간에 배정했다면, 그룹 편집 화면의 **예배 시간 추가** 옵션을 사용하여 올바른 예배에 연결하세요. 이렇게 해야 세션이 올바른 캠퍼스와 시간에 연결됩니다.
:::

:::tip
그룹이 정규 예배 밖에서 모이는 경우(예: 자체적으로 출석을 추적하는 수요일 소그룹), 예배 미배정 그룹으로 두면 됩니다. 이 그룹도 출석 보고를 위해 **그룹 출석** 보고서에 계속 나타납니다.
:::

## 체크인 일정 설정하기 {#setting-a-check-in-schedule}

각 예배 시간에는 선택적으로 체크인 일정을 지정할 수 있습니다. 그러면 [셀프 체크인](check-in.md)이 매주 스스로 열리고 닫힙니다. 일정을 지정하지 않으면 해당 예배 시간의 체크인은 언제든지 이용할 수 있습니다(방이 가득 차는 등 다른 이유로 닫히지 않는 한).

1. **설정** 보기에서 **시간** 열의 예배 시간 이름을 클릭합니다(또는 새로 추가합니다).
2. **체크인 일정**에서 예배 시간이 모이는 요일인 **요일**을 선택합니다.
3. **시작 시간**과, 원하면 **종료 시간**을 설정합니다.
4. **체크인 열기(시작 전 분)**를 입력합니다. 예를 들어 `30`을 입력하면 예배 시작 30분 전에 체크인이 열립니다.
5. **체크인 닫기(종료 후 분)**를 입력합니다. 예를 들어 `15`를 입력하면 종료 시간 이후 15분 동안 체크인이 열려 있습니다. 종료 시간을 설정하지 않았다면 시작 시간을 기준으로 계산합니다.
6. **저장**을 클릭합니다.

일정은 매주 반복되며, 예배가 열리는 캠퍼스의 시간대를 기준으로 합니다. 그 캠퍼스에 시간대가 없다면 교회의 [시간대](../settings/church-settings.md#time-zone)를 사용하고, 그것도 없으면 시간대가 설정된 첫 번째 캠퍼스의 시간대를 사용하며, 마지막으로 동부 시간(America/New_York)을 사용합니다. 체크인이 잘못된 시각에 열린다면 [캠퍼스](../settings/campuses.md)에서 해당 캠퍼스의 **시간대**를 확인하세요. 일정을 제거하려면 **요일**을 **일정 없음**으로 되돌리고 **저장**을 클릭합니다. 일정은 **요일**과 **시작 시간**이 모두 설정되어 있을 때만 적용됩니다.

예배 시간의 체크인 기간이 닫혀 있을 때는 다음과 같이 동작합니다.

- **B1.church의 셀프 체크인**은 해당 예배 시간을 **닫힘**으로 표시하며(또는 예를 들어 **닫힘 · 일요일 오전 9:30 열림**으로 표시하며), 선택할 수 없습니다. 예배의 모든 시간이 닫혀 있다면 가족에게 "체크인은 일요일 오전 9:30에 열립니다."와 같이 체크인이 언제 열리는지 보여 줍니다.
- **B1 Checkin 키오스크 앱**도 해당 예배 시간을 **닫힘**으로 표시하고, 언제 열리는지 함께 보여 줍니다. 예배의 모든 시간이 닫혀 있다면 키오스크는 그 예배의 체크인이 언제 열리는지 알려 줍니다. 닫힌 예배 시간에 이미 체크인된 사람은 그룹이 **체크인됨**으로 표시됩니다. 체크인 도중에 기간이 끝나면 키오스크는 체크인을 완료하지 않고, 영향을 받은 방을 나열하는 **아직 체크인할 수 없습니다** 화면을 표시하여 가족이 다른 방을 선택할 수 있게 합니다.

이전 예배 시간에 이미 체크인한 가구는, 이전 예배의 체크인 기간이 끝난 뒤에도 다시 와서 열려 있는 이후 예배 시간을 추가할 수 있습니다. 기존 체크인 기록은 유지됩니다.

:::tip
넉넉한 체크인 열기 시간(예: 시작 45분 전)을 설정하면 일찍 도착한 가족과 봉사자가 체크인할 수 있습니다. 체크인 닫기 시간은 짧게 설정하면 예배가 시작된 뒤에 늦게 도착한 사람도 체크인할 수 있습니다.
:::

## 설정 편집하기 {#editing-your-setup}

설정은 언제든지 수정할 수 있습니다. 캠퍼스, 예배 시간 또는 그룹을 선택하고 **편집**을 클릭하면 세부 정보를 바꿀 수 있으며, **삭제**를 클릭하면 제거할 수 있습니다.

:::info
예배 시간을 제거해도 과거의 출석 기록은 삭제되지 않습니다. 일정을 바꾸더라도 과거 데이터는 그대로 보존됩니다.
:::
