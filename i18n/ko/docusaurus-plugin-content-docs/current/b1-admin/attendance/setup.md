# 출석 설정

<div class="article-intro">

출석을 추적할 수 있기 전에 교회의 물리적 위치, 예배가 발생하는 시간 및 각 예배에서 만나는 그룹을 B1 Admin에 알려야 합니다. 이 일회성 설정은 교회 전체 출석 추적 및 보고를 제공하는 구조를 만듭니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 출석을 관리할 권한이 있는 활성 B1 Admin 계정이 필요합니다. 액세스 수준이 확실하지 않으면 [역할 및 권한](../people/roles-permissions.md) 참조하세요.
- 그룹을 예배 시간에 할당할 계획이라면 먼저 [그룹이 생성](../groups/creating-groups.md)되어 있는지 확인하세요.

</div>

## 주요 개념

- **캠퍼스** -- 교회가 만나는 물리적 위치(예: "메인 캠퍼스", "북쪽 캠퍼스"). 캠퍼스는 **설정** 아래에서 관리됩니다.
- **예배** -- 캠퍼스의 정기적인 모임(예: "일요일 예배", "주중).
- **예배 시간** -- 예배가 발생하는 구체적인 시간(예: "오전 9:00", "오전 11:00").
- **예정된 그룹** -- 특정 예배 시간에 할당된 그룹입니다. 출석은 해당 예배의 맥락에서 추적됩니다.
- **예정되지 않은 그룹** -- 예배 시간과 연결되지 않고 자체적으로 출석을 추적하는 그룹입니다.

## 출석 구조 설정

1. **B1 Admin**을 열고 왼쪽 위 모서리의 **섹션 메뉴**(섹션 이름과 작은 화살표)를 클릭한 후 **사람**을 선택합니다.
2. 탐색 표시줄에서 **출석** 탭을 클릭합니다. **설정** 탭이 기본적으로 선택됩니다.
3. **캠퍼스 관리**(설정 패널 오른쪽 상단)를 클릭합니다. **설정 → 캠퍼스**로 이동합니다. **캠퍼스 추가**를 클릭하고 위치 이름을 입력합니다(주소 및 시간대는 선택 사항). **저장**을 클릭합니다.
4. **사람 → 출석 → 설정**으로 돌아갑니다. 캠퍼스가 설정 테이블에 나타납니다.
5. **캠퍼스 아래의 예배 열의 + 버튼**을 클릭합니다. "일요일 예배"와 같은 예배 이름을 입력하고 **저장**을 클릭합니다.
6. **예배 아래의 시간 열의 + 버튼**을 클릭합니다. "오전 9:00"과 같은 시간을 입력하고 **저장**을 클릭합니다. 각 예배 시간에 대해 반복합니다.
7. 그룹을 예배 시간에 연결하려면 **그룹** 탭에서 그룹을 열고 **편집** 연필을 클릭한 후 **예배 시간 추가** 사용 — 다음 섹션 참조.

### 그룹에서 출석 추적 활성화

그룹이 출석을 기록하려면 먼저 해당 그룹에 대해 출석 추적을 켜야 합니다.

1. 사이드바에서 **그룹**을 클릭하고 그룹을 선택합니다.
2. **편집** 연필 아이콘을 클릭합니다.
3. **출석 추적**을 **예**로 설정합니다.
4. **저장**을 클릭합니다.

:::tip
이전 단계에서 그룹을 예배 시간에 할당한 경우 그룹의 편집 화면에서 **예배 시간 추가** 옵션을 사용하여 올바른 예배에 연결합니다. 이를 통해 세션이 올바른 캠퍼스 및 시간에 연결됩니다.
:::

:::tip
정기적인 예배 외에 만나는 그룹(예: 자체 출석을 추적하는 주중 소그룹)이 있으면 예정되지 않은 그룹으로 두면 됩니다. 여전히 그룹 탭에 출석 보고를 위해 나타납니다.
:::

## 설정 편집

언제든지 설정을 업데이트할 수 있습니다. 캠퍼스, 예배 시간 또는 그룹을 선택하고 **편집**을 클릭하여 세부 정보를 변경하거나 **삭제**를 클릭하여 제거합니다.

:::info
예배 시간을 제거해도 과거 출석 기록이 삭제되지 않습니다. 일정을 변경하더라도 과거 데이터가 유지됩니다.
:::
