# 출석 설정

<div class="article-intro">

출석을 추적하기 전에 교회의 실제 장소, 예배 시간, 각 예배에서 모이는 그룹을 B1 Admin에 알려 주어야 합니다. 이 일회성 설정은 교회 전체의 모든 출석 추적과 보고의 기반이 되는 구조를 만듭니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 출석을 관리할 권한이 있는 B1 Admin 계정이 활성화되어 있어야 합니다. 접근 수준이 확실하지 않다면 [역할 및 권한](../people/roles-permissions.md)을 참고하세요.
- 그룹을 예배 시간에 배정할 계획이라면 먼저 [그룹을 만들어](../groups/creating-groups.md) 두어야 합니다.

</div>

## 핵심 개념

- **캠퍼스** -- 교회가 모이는 실제 장소(예: "본당 캠퍼스", "북부 캠퍼스"). 캠퍼스는 **Settings** 아래에서 관리합니다.
- **예배(Service)** -- 캠퍼스에서 정기적으로 열리는 모임(예: "주일 예배", "수요 모임").
- **예배 시간(Service Time)** -- 예배가 열리는 특정 시각(예: "오전 9:00", "오전 11:00").
- **예정 그룹(Scheduled Group)** -- 특정 예배 시간에 배정된 그룹. 출석은 그 예배의 맥락에서 추적합니다.
- **비예정 그룹(Unscheduled Group)** -- 예배 시간과 연결되지 않고 자체적으로 출석을 추적하는 그룹.

## 출석 구조 설정하기

1. **B1 Admin**을 열고 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 연 뒤 **People**을 펼칩니다.
2. **Attendance**를 클릭한 다음 왼쪽 열의 **Setup**을 클릭합니다. **Service structure** 표가 열리며, 상단에 캠퍼스, 예배 시간, 예정 그룹과 비예정 그룹의 개수가 표시됩니다. 표에서 항목을 추가, 수정, 삭제하면 개수가 바로 갱신됩니다.
3. **Service structure** 패널 오른쪽 위의 **Manage Campuses**를 클릭합니다. **Settings → Campuses**로 이동합니다. **Add Campus**를 클릭하고 장소 이름을 입력한 뒤(주소와 시간대는 선택 사항) **Save**를 클릭합니다.
4. **People → Attendance**로 돌아가 **Setup**을 클릭합니다. 방금 만든 캠퍼스가 설정 표에 나타납니다.
5. 캠퍼스 아래 **Service** 열의 **+ 버튼**을 클릭합니다. "주일 예배"와 같은 예배 이름을 입력하고 **Save**를 클릭합니다.
6. 예배 아래 **Time** 열의 **+ 버튼**을 클릭합니다. "오전 9:00"과 같은 **Service Time** 이름을 입력하고, 원하면 [체크인 일정](#setting-a-check-in-schedule)을 채운 뒤 **Save**를 클릭합니다. 예배 시간마다 이 과정을 반복합니다.
7. 그룹을 예배 시간에 연결하려면 **People > Groups**에서 그룹을 열고 **Edit**을 클릭한 뒤 **Add Service Time**을 사용합니다. 아래 섹션을 참고하세요.

### 그룹에서 Track Attendance 켜기

그룹의 출석을 기록하려면 먼저 그 그룹에서 Track Attendance를 켜야 합니다.

1. Jump 메뉴에서 **People > Groups**를 선택하고 그룹을 선택합니다.
2. 그룹 이름 아래의 **Edit** 버튼을 클릭합니다.
3. **Track Attendance**를 **Yes**로 설정합니다.
4. **Save**를 클릭합니다.

:::tip
앞 단계에서 그룹을 예배 시간에 배정했다면, 그룹의 편집 화면에서 **Add Service Time** 옵션을 사용해 올바른 예배에 연결하세요. 그래야 세션이 올바른 캠퍼스와 시간에 연결됩니다.
:::

:::tip
그룹이 정기 예배 외에 모이는 경우라면 -- 예를 들어 자체적으로 출석을 추적하는 수요 소그룹 -- 비예정 그룹으로 두면 됩니다. 이 그룹도 출석 보고서의 **Group Attendance** 보고서에 계속 나타납니다.
:::

## 체크인 일정 설정하기

예배 시간마다 선택 사항으로 체크인 일정을 지정하면, [셀프 체크인](check-in.md)이 매주 자동으로 열리고 닫힙니다. 일정을 지정하지 않으면, 공간이 가득 차는 등 다른 이유로 닫혀 있지 않은 한 그 예배 시간의 체크인은 언제든 가능합니다.

1. **Setup** 화면에서 예배 시간의 이름을 **Time** 열에서 클릭합니다(또는 새로 추가합니다).
2. **Check-in Schedule** 아래에서 예배 시간이 열리는 **Day**(요일)를 고릅니다.
3. **Start Time**을 설정하고, 원하면 **End Time**도 설정합니다.
4. **Open check-in (minutes before start)**를 입력합니다. 예를 들어 `30`을 입력하면 예배 시작 30분 전에 체크인이 열립니다.
5. **Close check-in (minutes after end)**를 입력합니다. 예를 들어 `15`를 입력하면 예배 종료 후 15분 동안 체크인이 계속 열려 있습니다. 종료 시간을 설정하지 않았다면 시작 시간부터 계산합니다.
6. **Save**를 클릭합니다.

일정은 매주 반복되며, 예배가 열리는 캠퍼스의 시간대를 기준으로 합니다. 캠퍼스에 시간대가 없다면 교회의 [시간대](../settings/church-settings.md#time-zone)를 사용하고, 그것도 없으면 시간대가 설정된 첫 번째 캠퍼스의 시간대를, 마지막으로 동부 시간(America/New_York)을 사용합니다. 체크인이 엉뚱한 시각에 열린다면 [캠퍼스](../settings/campuses.md)에서 해당 캠퍼스의 **Time Zone**을 확인하세요. 일정을 제거하려면 **Day**를 **No schedule**로 되돌리고 **Save**를 클릭합니다. 일정은 **Day**와 **Start Time**이 모두 설정되어 있을 때만 적용됩니다.

예배 시간의 체크인 기간이 닫혀 있는 동안:

- **B1.church의 셀프 체크인**은 해당 예배 시간을 **Closed**로 표시하며(예: **Closed · opens Sun 9:30 AM**), 선택할 수 없습니다. 예배의 모든 시간이 닫혀 있다면 가족에게 체크인이 언제 열리는지 보여 줍니다. 예를 들어 "체크인은 주일 오전 9:30에 열립니다."와 같이 표시합니다.
- **B1 Checkin 키오스크 앱**도 해당 예배 시간을 **Closed**로 표시하며 언제 열리는지 알려 줍니다. 예배의 모든 시간이 닫혀 있다면 키오스크가 그 예배의 체크인이 언제 열리는지 알려 줍니다. 이미 닫힌 예배 시간에 체크인한 사람은 해당 그룹이 **Checked in**으로 표시됩니다. 체크인 도중에 기간이 닫히면 키오스크는 체크인을 완료하지 않고 **Can't check in yet** 화면을 보여 주며, 영향을 받는 공간을 표시하여 가족이 다른 공간을 고를 수 있게 합니다.

이전 예배 시간에 이미 체크인한 가구는 이전 예배 시간의 기간이 닫힌 뒤에도 다시 와서 아직 열려 있는 이후 예배 시간을 추가할 수 있습니다. 기존 체크인 기록은 그대로 유지됩니다.

:::tip
넉넉한 열림 기간(예: 시작 45분 전)을 설정하면 일찍 도착한 가족과 봉사자가 체크인할 수 있습니다. 닫힘 기간은 짧게 설정하면 예배가 시작된 뒤 늦게 온 사람은 여전히 체크인할 수 있습니다.
:::

## 설정 편집하기

언제든지 설정을 수정할 수 있습니다. 캠퍼스, 예배 시간, 또는 그룹을 선택하고 **Edit**을 클릭하면 세부 정보를 바꿀 수 있습니다. **Delete**를 클릭하면 삭제됩니다.

:::info
예배 시간을 삭제해도 과거의 출석 기록은 삭제되지 않습니다. 일정을 바꾸더라도 과거 데이터는 그대로 보존됩니다.
:::
