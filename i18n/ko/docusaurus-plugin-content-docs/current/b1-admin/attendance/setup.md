# 출석 설정

<div class="article-intro">

출석을 추적하기 전에 B1 Admin에 교회의 물리적 위치, 서비스가 발생하는 시간 및 각 서비스에서 만나는 그룹에 대해 알려야 합니다. 이 일회성 설정은 교회 전체의 모든 출석 추적 및 보고를 제공하는 구조를 만듭니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 출석을 관리할 권한이 있는 활성 B1 Admin 계정이 필요합니다. 액세스 수준이 확실하지 않으면 [역할 및 권한](../people/roles-permissions.md)을 참조하세요.
- 그룹을 서비스 시간에 할당하려는 경우 먼저 [그룹이 생성](../groups/creating-groups.md)되었는지 확인하세요.

</div>

## 핵심 개념

- **캠퍼스** -- 교회가 모이는 물리적 위치(예: "주 캠퍼스", "북쪽 캠퍼스"). 캠퍼스는 **설정** 아래에서 관리됩니다.
- **서비스** -- 캠퍼스에서의 반복되는 모임(예: "일요일 예배", "주중").
- **서비스 시간** -- 서비스가 발생하는 특정 시간(예: "오전 9:00", "오전 11:00").
- **예약된 그룹** -- 특정 서비스 시간에 할당된 그룹. 출석은 해당 서비스의 맥락에서 추적됩니다.
- **예약되지 않은 그룹** -- 서비스 시간에 연결되지 않고 자체적으로 출석을 추적하는 그룹.

## 출석 구조 설정

1. **B1 Admin**을 열고 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **사람**을 확장합니다.
2. **출석**을 클릭한 다음 왼쪽 열에서 **설정**을 클릭합니다. **서비스 구조** 표가 열리며, 상단에 캠퍼스, 서비스 시간, 예약된 그룹과 예약되지 않은 그룹의 수가 표시됩니다.
3. **캠퍼스 관리**(**서비스 구조** 패널의 오른쪽 상단)를 클릭합니다. 이는 **설정 → 캠퍼스**로 이동합니다. **캠퍼스 추가**를 클릭하고 위치 이름을 입력하고(주소 및 시간대는 선택사항) **저장**을 클릭합니다.
4. **사람 → 출석**으로 돌아가 **설정**을 클릭합니다. 캠퍼스가 이제 설정 표에 나타납니다.
5. 캠퍼스 아래의 **서비스 열의 + 버튼**을 클릭합니다. "일요일 예배"와 같은 서비스 이름을 입력하고 **저장**을 클릭합니다.
6. 서비스 아래의 **시간 열의 + 버튼**을 클릭합니다. **서비스 시간** 이름(예: "오전 9:00")을 입력하고, 원하면 [체크인 일정](#setting-a-check-in-schedule)을 입력한 다음 **저장**을 클릭합니다. 각 서비스 시간마다 반복합니다.
7. 그룹을 서비스 시간에 연결하려면 **사람 > 그룹**에서 그룹을 열고 **편집**을 클릭한 다음 **서비스 시간 추가**를 사용합니다 — 다음 섹션을 참조합니다.

### 그룹에서 출석 추적 활성화

그룹에 출석을 기록하기 전에 해당 그룹에 대해 출석 추적을 켜야 합니다.

1. Jump 메뉴에서 **사람 > 그룹**을 선택하고 그룹을 선택합니다.
2. 그룹 이름 아래의 **편집** 버튼을 클릭합니다.
3. **출석 추적**을 **예**로 설정합니다.
4. **저장**을 클릭합니다.

:::tip
이전 단계에서 그룹을 서비스 시간에 할당한 경우 그룹의 편집 화면에서 **서비스 시간 추가** 옵션을 사용하여 올바른 서비스에 연결합니다. 이렇게 하면 세션이 올바른 캠퍼스 및 시간에 연결됩니다.
:::

:::tip
그룹이 정규 서비스 외에 만날 경우 — 자신의 출석을 추적하는 주중 소그룹처럼 — 예약되지 않은 그룹으로 둡니다. 출석 보고를 위해 **그룹 출석** 보고서에 여전히 나타납니다.
:::

## 체크인 일정 설정 {#setting-a-check-in-schedule}

각 서비스 시간에는 선택적으로 체크인 일정을 설정할 수 있으며, 이렇게 하면 [셀프 체크인](check-in.md)이 매주 자동으로 열리고 닫힙니다. 일정이 없으면 해당 서비스 시간의 체크인은 (객실이 가득 차는 등 다른 이유로 닫히지 않는 한) 언제든지 이용할 수 있습니다.

1. **설정** 보기에서 **시간** 열의 서비스 시간 이름을 클릭합니다(또는 새로 추가합니다).
2. **체크인 일정**에서 서비스 시간이 모이는 요일을 선택합니다.
3. **시작 시간**과 선택적으로 **종료 시간**을 설정합니다.
4. **체크인 열기(시작 전 분)**에 입력합니다 -- 예: `30`을 입력하면 서비스 시작 30분 전에 체크인이 열립니다.
5. **체크인 닫기(종료 후 분)**에 입력합니다 -- 예: `15`를 입력하면 종료 시간 후 15분 동안 체크인이 열려 있습니다. 종료 시간을 설정하지 않았다면 시작 시간을 기준으로 계산합니다.
6. **저장**을 클릭합니다.

일정은 교회의 현지 시간을 사용하며 매주 반복됩니다. 일정을 제거하려면 **요일**을 **일정 없음**으로 되돌리고 **저장**을 클릭합니다. 일정은 **요일**과 **시작 시간**이 모두 설정된 경우에만 적용됩니다.

서비스 시간의 체크인 기간이 닫혀 있는 동안:

- **B1.church의 셀프 체크인**에서 해당 서비스 시간이 숨겨집니다. 서비스의 시간이 모두 닫혀 있으면 가족에게 "지금은 이 서비스의 체크인이 열려 있지 않습니다."라고 표시됩니다.
- **B1 Checkin 키오스크 앱**은 해당 서비스 시간의 그룹에 대한 체크인을 완료하지 않습니다. 키오스크는 영향을 받는 객실을 나열하는 **아직 체크인할 수 없음** 화면을 표시하여 가족이 다른 객실을 선택할 수 있도록 합니다.

:::tip
시작 45분 전과 같이 넉넉한 열기 기간을 설정하여 일찍 도착하는 가족과 자원봉사자가 체크인할 수 있게 하고, 짧은 닫기 기간을 설정하여 서비스가 시작된 후에도 늦은 사람이 체크인할 수 있도록 하세요.
:::

## 설정 편집

설정을 언제든지 업데이트할 수 있습니다. 캠퍼스, 서비스 시간 또는 그룹을 선택하고 **편집**을 클릭하여 세부 정보를 변경하거나 **삭제**를 클릭하여 제거합니다.

:::info
서비스 시간을 제거해도 과거 출석 기록은 삭제되지 않습니다. 일정을 변경하더라도 과거 데이터는 보존됩니다.
:::

## 다음은?
