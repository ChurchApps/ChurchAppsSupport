# 출석 설정
<div class="article-intro">
출석을 추적하기 전에 B1 Admin에 교회의 물리적 위치, 서비스 시간, 각 서비스에서 모이는 그룹을 알려야 합니다. 이 일회성 설정은 교회 전체의 모든 출석 추적 및 보고의 기반을 만듭니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- 출석을 관리할 수 있는 권한이 있는 활성 B1 Admin 계정이 필요합니다. [역할 & 권한](../people/roles-permissions.md)을 참고하여 접근 권한을 확인하세요.
- 그룹을 서비스 시간에 할당할 계획이라면 먼저 [그룹이 생성](../groups/creating-groups.md)되어 있어야 합니다.
</div>
## 주요 개념
- **캠퍼스** — 교회가 만나는 물리적 위치 (예: "본 캠퍼스", "북부 캠퍼스"). 캠퍼스는 **설정**에서 관리됩니다.
- **서비스** — 캠퍼스에서 반복되는 모임 (예: "주일 예배", "주중 모임").
- **서비스 시간** — 서비스가 열리는 특정 시간 (예: "오전 9:00", "오전 11:00").
- **예정된 그룹** — 특정 서비스 시간에 할당된 그룹. 출석은 그 서비스의 맥락에서 추적됩니다.
- **예정되지 않은 그룹** — 서비스 시간과 관계없이 자체적으로 출석을 추적하는 그룹.
## 출석 구조 설정
1. **B1 Admin**을 열고, **섹션 메뉴**(섹션 이름과 작은 화살표)를 클릭하고 **사람들**을 선택합니다.
2. 네비게이션 바에서 **출석** 탭을 클릭합니다. **설정** 탭이 기본으로 선택되어 있습니다.
3. **캠퍼스 관리**를 클릭합니다. 이것은 **설정 → 캠퍼스**로 이동합니다. **캠퍼스 추가**를 클릭하고, 위치의 이름을 입력한 후 **저장**을 클릭합니다.
4. **사람들 → 출석 → 설정**으로 돌아갑니다. 캠퍼스가 이제 설정 테이블에 나타납니다.
5. 캠퍼스 아래 **서비스 열의 + 버튼**을 클릭합니다. 서비스 이름을 입력하고 **저장**을 클릭합니다.
6. 서비스 아래 **시간 열의 + 버튼**을 클릭합니다. 시간을 입력하고 **저장**을 클릭합니다.
7. 그룹을 서비스 시간에 연결하려면, **그룹** 탭에서 그룹을 열고, **편집** 연필 아이콘을 클릭하고, **서비스 시간 추가**를 사용합니다.
### 그룹에서 출석 추적 활성화
1. 왼쪽 위의 **섹션 메뉴**를 열고 **사람들**을 선택한 후 **그룹** 탭을 클릭하고 그룹을 선택합니다.
2. **편집** 연필 아이콘을 클릭합니다.
3. **출석 추적**을 **예**로 설정합니다.
4. **저장**을 클릭합니다.
:::tip
그룹을 서비스 시간에 할당했으면, 그룹의 편집 화면에서 **서비스 시간 추가** 옵션을 사용하여 올바른 서비스에 연결합니다.
:::
## 설정 편집
언제든지 설정을 업데이트할 수 있습니다. 캠퍼스, 서비스 시간 또는 그룹을 선택하고 **편집**을 클릭하여 세부 정보를 변경하거나 **삭제**를 클릭하여 제거합니다.
:::info
서비스 시간을 제거해도 과거 출석 기록은 삭제되지 않습니다.
:::
