# 사람 검색

<div class="article-intro">

**People** 페이지는 교회 디렉터리를 가구 단위의 검색 가능한 목록 또는 개인별 정렬 가능한 표로 보여 줍니다. 교회의 누구든 빠르게 찾을 수 있고, 표시할 정보를 원하는 대로 선택하며, 검색 결과를 내보낼 수 있습니다. 효율적인 검색은 방문자 후속 조치, 연락처 목록 준비, 교인 기록 관리와 같은 일상적인 교회 행정 업무에 필수적입니다.

## 가구 보기와 표 보기

People 페이지는 디렉터리를 **가구** 단위로 알파벳순으로 묶어 보여 줍니다. 각 행에는 가구의 사진, 가구 이름(예: "The Smith Family"), 그리고 구성원 모두의 이름이 표시됩니다. 가구를 클릭하면 대표 가구원(head of household)의 프로필이 열리고, 구성원 이름을 클릭하면 해당 사람이 열립니다. 목록 위의 개수는 표시된 가구와 사람의 수를 보여 줍니다.

목록 위의 **View as** 토글을 사용하면 **Households**와 **Table** 사이를 전환할 수 있습니다. **Table** 보기는 한 행에 한 사람씩 나열하며, 정렬하고 열을 선택할 수 있는 보기입니다(아래 참고). B1은 이 기기에서 선택한 보기를 기억합니다.

기본적으로 페이지에는 디렉터리의 일부만 불러옵니다. 더 많은 사람이 있다면 목록 아래의 **Show All Members**를 클릭하여 전체를 불러오세요.

## 빠른 검색

People 페이지 상단의 **Find a household or person** 상자를 사용하면 구성원을 실시간으로 찾을 수 있습니다.

1. People 페이지 상단의 **검색 상자**를 클릭합니다.
2. 이름을 입력하기 시작합니다.
3. 입력하는 동안 결과가 자동으로 필터링됩니다(키 입력마다 검색이 실행되지 않도록 약 0.5초의 짧은 지연이 있습니다).
4. 아래 목록이 일치하는 결과만 보여 주도록 업데이트됩니다.

검색을 초기화하고 전체 디렉터리를 다시 보려면 검색 상자 아래의 **Clear**를 클릭하세요.

:::tip
Enter 키를 누를 필요가 없습니다. 입력을 멈추면 검색이 자동으로 실행됩니다.
:::

## 결과 정렬하기

**Table** 보기에서 사람은 성, 이름 순서로 나열됩니다. 열 머리글을 클릭하면 다른 방식으로 디렉터리를 정렬할 수 있습니다.

1. **열 머리글**(예: **Name** 또는 **Email**)을 클릭하면 그 열을 기준으로 정렬됩니다.
2. 같은 머리글을 다시 클릭하면 정렬 순서가 반대로 바뀝니다.

이렇게 하면 알파벳순, 나이순, 또는 표시된 다른 열 기준으로 사람을 쉽게 찾을 수 있습니다.

## 열 설정하기

모든 정보를 한 번에 볼 필요는 없습니다. 표에 표시할 열을 선택할 수 있습니다.

1. People 페이지 헤더에서 **Select columns** 아이콘을 클릭합니다. (열 설정은 **Table** 보기에 적용됩니다.)
2. 열을 체크하거나 체크 해제하여 표시하거나 숨깁니다. 사용할 수 있는 열은 다음과 같습니다.
   - **Photo**
   - **Name**
   - **Email**
   - **Phone**
   - **Address**
   - **Birth Date**
   - **Age**
   - **Gender**
   - **Membership Status**
   - **Campus**
3. 선택 사항이 즉시 표에 반영됩니다. **Done**을 클릭하면 **Select Columns** 대화 상자가 닫힙니다.

### 사용자 지정 필드를 열로 표시하기

열 선택기에는 두 개의 탭이 있습니다. **Standard**에는 위에 나열된 기본 열이 있고, **Custom**에는 교회의 [사용자 지정 필드](../settings/custom-fields.md)와 사람 양식의 질문들이 있습니다. **Custom** 탭에서 필드를 체크하면 열로 추가되며, 각 사람의 해당 필드 값이 표에 나타납니다. 값은 사람의 프로필에서와 같은 방식으로 표시됩니다. 예/아니요 필드는 *Yes* 또는 *No*로, 객관식 필드는 선택지의 레이블로, 날짜는 짧은 날짜 형식으로 표시됩니다. 필드 값이 없는 사람의 칸은 비어 있습니다.


## 검색 결과 내보내기

현재 검색 결과를 언제든지 CSV 파일로 다운로드할 수 있습니다.

1. 원하는 검색이나 필터를 적용합니다.
2. People 페이지 헤더의 **Export** 버튼을 클릭합니다.
3. CSV 파일이 컴퓨터로 다운로드되며, Excel, Google Sheets 또는 다른 스프레드시트 앱에서 바로 열 수 있습니다.

내보내기에 대한 자세한 내용은 [데이터 내보내기](./exporting-data.md)를 참고하세요.

:::tip
"지난 3개월 동안 출석하지 않은 모든 사람" 같은 더 고급 질의를 하려면 [AI 검색](./ai-search.md) 기능을 사용해 보세요. 일상 언어로 질문하여 검색할 수 있습니다.
:::

## 고급 검색

고급 검색(Advanced Search)을 사용하면 여러 조건을 조합하여 정밀한 필터를 만들 수 있습니다. People 페이지의 검색 상자 아래에 있는 **Advanced**를 클릭하여 열고, 카테고리를 펼친 후 필터링할 필드를 체크합니다(필드 이름이나 체크박스 중 아무거나 클릭할 수 있습니다). 각 필드마다 연산자와 값을 선택합니다. 카테고리에는 **Names**, **Demographics**, **Contact**, **Membership**, **Activity**(헌금 및 출석), **Custom Fields**가 있습니다.

**Custom Fields** 카테고리에는 교회의 [사용자 지정 필드](../settings/custom-fields.md)가 나열됩니다. 이는 설정에서 여러분이 정의한, 교회 고유 정보를 추적하는 필드입니다(예: 신원 조회 만료일). 제공되는 연산자는 각 필드 유형에 맞춰집니다. 텍스트 필드는 *contains / equals / starts with / ends with*(포함 / 같음 / 다음으로 시작 / 다음으로 끝남)를 지원하고, 숫자 필드는 비교 연산자를 지원하며, 날짜 필드는 *equals / after / before*(같음 / 이후 / 이전)를 지원합니다. 예/아니요 필드와 객관식 필드는 값을 선택할 수 있습니다. 여기서 필터링할 수 있는 모든 필드는 실시간 [목록](./lists.md)으로 저장할 수 있습니다.

## 검색을 목록으로 저장하기

검색을 실행하면 People 페이지 헤더에 **Save as List** 버튼이 나타납니다. 이를 클릭하면 현재 질의를 이름과 선택적 분류와 함께 저장하여, 나중에 언제든지 바로 다시 불러올 수 있습니다. 자세한 내용은 [저장된 목록](./lists.md)을 참고하세요.
