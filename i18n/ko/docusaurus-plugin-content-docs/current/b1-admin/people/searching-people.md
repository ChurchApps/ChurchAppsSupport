# 사람 검색하기

<div class="article-intro">

**사람** 페이지는 교회 명부를 가구 단위의 검색 가능한 목록으로, 또는 개인별로 정렬할 수 있는 표로 보여 줍니다. 교회 구성원을 빠르게 찾고, 표시할 정보를 원하는 대로 설정하며, 검색 결과를 내보낼 수 있습니다. 방문자 후속 조치, 연락처 목록 준비, 구성원 기록 관리와 같은 일상적인 교회 행정 업무에서 효율적인 검색은 필수입니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 사람을 볼 수 있는 권한이 있는 활성 B1 Admin 계정이 필요합니다. 본인의 접근 수준이 확실하지 않다면 [역할 및 권한](roles-permissions.md)을 참조하세요.
- 교회 명부에 사람이 등록되어 있어야 합니다. 아직 아무도 추가하지 않았다면 [사람 추가하기](adding-people.md) 또는 [데이터 가져오기](importing-data.md)를 참조하세요.

</div>

## 가구 보기와 표 보기

사람 페이지는 명부를 **가구** 단위로 알파벳 순으로 묶어 보여 줍니다. 각 행에는 가구의 사진, 가구 이름(예: "The Smith Family"), 그리고 가구 구성원의 이름이 표시됩니다. 가구를 클릭하면 가구주의 프로필이 열리고, 구성원의 이름을 클릭하면 해당 사람이 열립니다. 목록 위의 개수는 표시 중인 가구와 사람 수를 보여 줍니다.

목록 위의 **보기 방식** 토글을 사용하여 **가구**와 **표** 사이를 전환할 수 있습니다. **표** 보기는 한 행에 한 사람씩 나열하며, 아래에서 설명하는 정렬과 열 선택은 여기서 할 수 있습니다. B1은 이 기기에서 선택한 보기를 기억합니다.

기본적으로 페이지는 명부의 처음 일부만 불러옵니다. 더 많은 사람이 있다면 목록 아래의 **모든 구성원 표시**를 클릭하여 모든 사람을 불러옵니다.

## 빠른 검색

사람 페이지 상단의 **가구 또는 사람 찾기** 상자에서 실시간으로 구성원을 찾을 수 있습니다.

1. 사람 페이지 상단의 **검색 상자**를 클릭합니다.
2. 이름을 입력하기 시작합니다.
3. 입력하는 동안 결과가 자동으로 필터링됩니다(키를 누를 때마다 검색이 실행되지 않도록 약 0.5초의 짧은 지연이 있습니다).
4. 아래 목록이 일치하는 결과만 보여 주도록 갱신됩니다.

검색 상자 아래의 **지우기**를 클릭하면 검색이 초기화되고 전체 명부가 다시 표시됩니다.

:::tip
Enter 키를 누를 필요가 없습니다. 입력을 멈추면 검색이 자동으로 실행됩니다.
:::

## 결과 정렬하기

**표** 보기에서 사람들은 성, 그다음 이름 순으로 나열됩니다. 어떤 열 머리글이든 클릭하면 명부를 다른 방식으로 정렬할 수 있습니다.

1. **열 머리글**(예: **이름** 또는 **이메일**)을 클릭하면 해당 열 기준으로 정렬됩니다.
2. 같은 머리글을 다시 클릭하면 정렬 순서가 반대로 바뀝니다.

이렇게 하면 알파벳 순, 나이 순 또는 표시 중인 다른 열 기준으로 쉽게 사람을 찾을 수 있습니다.

## 열 설정하기

모든 정보를 한꺼번에 볼 필요는 없습니다. 표에 표시할 열을 선택할 수 있습니다.

1. 사람 페이지 머리글의 **열 선택** 아이콘을 클릭합니다. (열은 **표** 보기에 적용됩니다.)
2. 열을 체크하거나 체크를 해제하여 표시하거나 숨깁니다. 사용 가능한 열은 다음과 같습니다.
   - **사진**
   - **이름**
   - **이메일**
   - **전화**
   - **주소**
   - **생년월일**
   - **나이**
   - **성별**
   - **구성원 상태**
   - **캠퍼스**
3. 선택 내용이 즉시 표에 반영됩니다.

### 사용자 지정 필드를 열로 표시하기 {#showing-custom-fields-as-columns}

열 선택 창에는 두 개의 탭이 있습니다. **기본** 탭에는 위에 나열된 기본 제공 열이 있고, **사용자 지정** 탭에는 교회의 [사용자 지정 필드](../settings/custom-fields.md)와 사람 양식의 질문들이 있습니다. **사용자 지정** 탭에서 필드를 체크하면 열로 추가되며, 각 사람의 해당 필드 값이 표에 표시됩니다. 값은 사람의 프로필과 같은 방식으로 표시됩니다. 예/아니요 필드는 *예* 또는 *아니요*로 표시되고, 객관식 필드는 옵션의 라벨이 표시되며, 날짜는 짧은 날짜 형식으로 표시됩니다. 해당 필드의 값이 없는 사람은 빈 칸으로 표시됩니다.


## 검색 결과 내보내기

현재 검색 결과를 언제든지 CSV 파일로 다운로드할 수 있습니다.

1. 원하는 검색어나 필터를 적용합니다.
2. 사람 페이지 머리글의 **내보내기** 버튼을 클릭합니다.
3. CSV 파일이 컴퓨터로 다운로드되며, Excel, Google Sheets 또는 다른 스프레드시트 앱에서 바로 열 수 있습니다.

내보내기에 대한 자세한 내용은 [데이터 내보내기](./exporting-data.md)를 참조하세요.

:::tip
최근 3개월 동안 출석하지 않은 모든 사람을 찾는 것처럼 더 고급 조회가 필요하다면, 일상 언어로 질문하여 검색할 수 있는 [AI 검색](./ai-search.md) 기능을 사용해 보세요.
:::

## 고급 검색 {#advanced-search}

고급 검색을 사용하면 여러 조건을 조합하여 정밀한 필터를 만들 수 있습니다. 사람 페이지의 검색 상자 아래에 있는 **고급**을 클릭하여 열고, 범주를 펼쳐 필터링할 필드를 체크한 다음 각 필드에 대해 연산자와 값을 선택하세요. 범주에는 **이름**, **인구통계**, **연락처**, **구성원 자격**, **활동**(헌금 및 출석), **사용자 지정 필드**가 있습니다.

**사용자 지정 필드** 범주에는 교회의 [사용자 지정 필드](../settings/custom-fields.md) 목록이 나열됩니다. 이는 설정에서 본인이 정의한 필드로, 예를 들어 신원 조사 만료일과 같이 교회의 고유한 정보를 추적하는 데 사용됩니다. 제공되는 연산자는 각 필드의 유형에 맞춰집니다. 텍스트 필드는 *포함 / 같음 / 다음으로 시작 / 다음으로 끝남*을, 숫자 필드는 비교 연산자를, 날짜 필드는 *같음 / 이후 / 이전*을 지원하며, 예/아니요 및 객관식 필드에서는 값을 선택할 수 있습니다. 여기서 필터링할 수 있는 모든 필드는 라이브 [목록](./lists.md)으로 저장할 수 있습니다.

## 검색을 목록으로 저장하기

검색을 실행한 후 사람 페이지 머리글에 **목록으로 저장** 버튼이 나타납니다. 이를 클릭하면 현재 조건을 이름과 선택적 범주와 함께 저장하여, 나중에 세션에서 즉시 다시 불러올 수 있습니다. 자세한 내용은 [저장된 목록](./lists.md)을 참조하세요.
