# 사람 검색

<div class="article-intro">

**People** 페이지는 교회 디렉토리를 검색 가능하고 정렬 가능한 표로 표시합니다. 교회 공동체의 누구든 빠르게 찾을 수 있으며, 표시되는 정보를 사용자 지정하고, 결과를 내보낼 수 있습니다. 효율적인 검색은 방문자 추적, 연락처 목록 준비, 회원 기록 관리 같은 일상적인 교회 행정 업무에 필수적입니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 사람을 볼 수 있는 권한이 있는 활성 B1 Admin 계정이 필요합니다. 접근 수준이 확실하지 않으면 [Roles & Permissions](roles-permissions.md)을 참고하세요.
- 교회 디렉토리에 사람들이 있어야 합니다. 아직 아무도 추가하지 않았다면 [Adding People](adding-people.md) 또는 [Importing Data](importing-data.md)을 참고하세요.

</div>

## 빠른 검색

People 페이지 상단의 검색 모음을 사용하여 실시간으로 회원을 찾을 수 있습니다:

1. People 페이지 상단의 **검색 상자**를 클릭하세요.
2. 이름, 이메일 또는 다른 키워드를 입력하세요.
3. 입력하면서 결과가 자동으로 필터링됩니다(검색이 모든 키입력에서 실행되지 않도록 약 0.5초의 짧은 지연이 있습니다).
4. 아래의 표가 일치하는 결과만 표시하도록 업데이트됩니다.

:::tip
Enter를 누를 필요가 없습니다. 입력을 멈추면 검색이 자동으로 실행됩니다.
:::

## 결과 정렬

표의 임의의 열 제목을 클릭하여 디렉토리를 정렬할 수 있습니다:

1. **열 제목**(예: **Name** 또는 **Email**)을 클릭하여 해당 열로 정렬하세요.
2. 같은 제목을 다시 클릭하면 정렬 순서가 반대가 됩니다.

이를 통해 사람들을 알파벳 순, 나이별 또는 다른 표시 열로 쉽게 찾을 수 있습니다.

## 열 사용자 지정

모든 정보가 한 번에 표시될 필요는 없습니다. 표에 나타나는 열을 선택할 수 있습니다:

1. 표 상단 근처의 **열 선택 드롭다운**을 찾으세요.
2. 열을 선택하거나 해제하여 표시하거나 숨기세요. 사용 가능한 열은:
   - **Photo**
   - **Name**
   - **Email**
   - **Phone**
   - **Address**
   - **Birth Date**
   - **Age**
   - **Gender**
   - **Membership Status**
   - **Campus**
3. 표가 즉시 업데이트되어 선택사항을 반영합니다.

### 사용자 지정 필드를 열로 표시

열 선택기에는 두 개의 탭이 있습니다: **Standard**는 위에 나열된 기본 제공 열을 가지고 있으며, **Custom**은 교회의 [Custom Fields](../settings/custom-fields.md)와 모든 People 양식의 질문을 가지고 있습니다. **Custom** 탭에서 사용자 지정 필드를 선택하여 열로 추가하면, 각 사람의 해당 필드 값이 표에 나타납니다. 값은 사람의 프로필에 표시된 것과 동일한 방식으로 표시됩니다 -- Yes/No 필드는 *Yes* 또는 *No*를 읽고, 다중 선택 필드는 옵션의 레이블을 표시하며, 날짜는 간단한 날짜로 표시됩니다. 필드 값이 없는 사람은 빈 셀을 표시합니다.

:::info
열 선택사항은 CSV로 내보낼 때 포함되는 내용에 영향을 줍니다. 내보내기 전에 열을 사용자 지정하여 필요한 정확한 데이터를 얻으세요.
:::

## 페이지 나누기

디렉토리에 많은 기록이 있을 때 결과는 여러 페이지로 나뉩니다. 표 하단의 **페이지 나누기 컨트롤**을 사용하여 페이지 사이를 이동하세요. 현재 페이지와 총 기록 수가 표시되므로 목록의 어디에 있는지 항상 알 수 있습니다.

:::tip
큰 디렉토리를 페이지로 넘기기보다는 검색을 정제하여 목록을 좁히는 것을 선호하면, 한 번에 더 많은 결과를 보고 싶다면 검색을 정제하여 목록을 좁히세요.
:::

## 검색 결과 내보내기

현재 검색 결과를 언제든지 CSV 파일로 다운로드할 수 있습니다:

1. 원하는 검색이나 필터를 적용하세요.
2. 필요한 데이터를 포함하도록 열을 사용자 지정하세요.
3. **Export** 버튼을 클릭하세요.
4. CSV 파일이 컴퓨터로 다운로드되어 Excel, Google Sheets 또는 다른 스프레드시트 애플리케이션에서 열 수 있습니다.

내보내기에 대한 자세한 정보는 [Exporting Data](./exporting-data.md)를 참고하세요.

:::tip
모두가 지난 3개월 동안 참석하지 않은 경우 찾기 같은 고급 쿼리의 경우 일반 언어 질문을 사용하여 검색할 수 있는 [AI Search](./ai-search.md) 기능을 시도하세요.
:::

## 고급 검색

Advanced Search를 사용하면 조건을 조합하여 정확한 필터를 작성할 수 있습니다. People 페이지에서 열고 카테고리를 확장한 다음 각각에 대해 필터링할 필드를 확인하여 연산자와 값을 선택하세요. 카테고리에는 **Names**, **Demographics**, **Contact**, **Membership**, **Activity**(기부금 및 출석) 및 **Custom Fields**가 포함됩니다.

**Custom Fields** 카테고리는 교회의 [Custom Fields](../settings/custom-fields.md) -- 배경 확인 만료 날짜 같은 자신의 정보를 추적하기 위해 Settings에서 정의하는 필드를 나열합니다. 제공되는 연산자는 각 필드의 유형과 일치합니다: 텍스트 필드는 *contains / equals / starts with / ends with*를 지원하고, 숫자 필드는 비교 연산자를 지원하며, 날짜 필드는 *equals / after / before*를 지원하고, Yes/No 및 다중 선택 필드는 값을 선택하게 합니다. 여기서 필터링할 수 있는 모든 필드는 라이브 [List](./lists.md)로 저장될 수 있습니다.

## 검색을 목록으로 저장

검색을 실행한 후, **Save as List** 버튼(책갈피 아이콘)이 People 페이지 헤더에 나타납니다. 현재 쿼리를 이름과 선택적 카테고리 아래에 저장하려면 클릭하면 이후 세션에서 즉시 다시 로드할 수 있습니다. 전체 세부사항은 [Saved Lists](./lists.md)를 참고하세요.
