# 교인 검색

<div class="article-intro">

**교인** 페이지는 교회 명부를 검색 및 정렬이 가능한 표 형태로 보여줍니다. 회중 내 누구든 빠르게 찾고, 표시되는 정보를 원하는 대로 조정하고, 결과를 내보낼 수 있습니다. 효율적인 검색은 방문자 후속 조치, 연락처 목록 준비, 회원 기록 관리와 같은 일상적인 교회 관리 업무에 필수적입니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 교인을 조회할 수 있는 권한을 가진 활성 B1 Admin 계정이 필요합니다. 자신의 접근 수준이 확실하지 않다면 [역할 및 권한](roles-permissions.md)을 참고하세요.
- 교회 명부에 사람이 등록되어 있어야 합니다. 아직 아무도 추가하지 않았다면 [교인 추가](adding-people.md) 또는 [데이터 가져오기](importing-data.md)를 참고하세요.

</div>

## 빠른 검색

교인 페이지 상단의 검색창을 사용하면 실시간으로 회원을 찾을 수 있습니다.

1. 교인 페이지 상단의 **검색창**을 클릭합니다.
2. 이름, 이메일, 또는 다른 키워드를 입력하기 시작합니다.
3. 입력하는 동안 결과가 자동으로 필터링됩니다(입력할 때마다 검색이 실행되지 않도록 약 0.5초의 짧은 지연이 있습니다).
4. 아래 표가 일치하는 결과만 표시하도록 업데이트됩니다.

:::tip
Enter 키를 누를 필요는 없습니다. 입력을 멈추면 검색이 자동으로 실행됩니다.
:::

## 결과 정렬하기

표의 열 머리글을 클릭해 명부를 정렬할 수 있습니다.

1. **열 머리글**(예: **이름** 또는 **이메일**)을 클릭해 해당 열 기준으로 정렬합니다.
2. 같은 머리글을 다시 클릭하면 정렬 순서가 반전됩니다.

이를 통해 알파벳순, 연령순, 또는 다른 표시된 열을 기준으로 손쉽게 사람을 찾을 수 있습니다.

## 열 사용자 지정하기

모든 정보를 한꺼번에 표시할 필요는 없습니다. 표에 표시할 열을 직접 선택할 수 있습니다.

1. 표 상단 근처의 **열 선택 드롭다운**을 찾습니다.
2. 열을 체크하거나 해제해 표시하거나 숨깁니다. 선택 가능한 열은 다음과 같습니다.
   - **사진**
   - **이름**
   - **이메일**
   - **전화번호**
   - **주소**
   - **생년월일**
   - **나이**
   - **성별**
   - **회원 상태**
   - **캠퍼스**
3. 표가 즉시 업데이트되어 선택 사항이 반영됩니다.

:::info
선택한 열은 CSV로 내보낼 때 포함되는 항목에도 영향을 줍니다. 원하는 데이터를 정확히 얻으려면 내보내기 전에 열을 사용자 지정하세요.
:::

## 페이지 나누기

명부에 기록이 많을 경우 결과가 여러 페이지로 나뉩니다. 표 하단의 **페이지 이동 컨트롤**을 사용해 페이지 사이를 이동하세요. 현재 페이지와 전체 기록 수가 표시되므로 목록 내 위치를 항상 파악할 수 있습니다.

:::tip
한 번에 더 많은 결과를 보고 싶다면, 큰 명부를 여러 페이지로 넘기는 대신 검색 조건을 좁혀서 목록을 줄이세요.
:::

## 검색 결과 내보내기

현재 검색 결과를 언제든지 CSV 파일로 다운로드할 수 있습니다.

1. 원하는 검색이나 필터를 적용합니다.
2. 필요한 데이터가 포함되도록 열을 사용자 지정합니다.
3. **내보내기** 버튼을 클릭합니다.
4. CSV 파일이 컴퓨터에 다운로드되며, Excel, Google 시트, 또는 다른 스프레드시트 프로그램에서 바로 열 수 있습니다.

내보내기에 대한 자세한 내용은 [데이터 내보내기](./exporting-data.md)를 참고하세요.

:::tip
최근 3개월간 출석하지 않은 사람을 모두 찾는 것과 같은 더 복잡한 조회에는, 자연어 질문으로 검색할 수 있는 [AI 검색](./ai-search.md) 기능을 사용해 보세요.
:::

## 고급 검색

고급 검색을 사용하면 여러 조건을 조합해 정밀한 필터를 만들 수 있습니다. 교인 페이지에서 열고, 카테고리를 펼친 다음 필터링할 필드를 체크하여 각 필드에 대한 연산자와 값을 선택합니다. 카테고리에는 **이름**, **인구통계**, **연락처**, **회원 정보**, **활동**(헌금 및 출석), **사용자 지정 필드**가 있습니다.

**사용자 지정 필드** 카테고리에는 교회가 정의한 [사용자 지정 필드](../settings/custom-fields.md)가 나열됩니다. 이는 설정에서 직접 정의해 (예: 신원조회 만료일 같은) 자체 정보를 추적하는 필드입니다. 제공되는 연산자는 각 필드 유형에 맞게 달라집니다. 텍스트 필드는 *포함 / 같음 / 시작 문자 / 끝 문자*를, 숫자 필드는 비교 연산자를, 날짜 필드는 *같음 / 이후 / 이전*을 지원하며, 예/아니오 및 객관식 필드는 값을 선택하는 방식입니다. 여기서 필터링할 수 있는 모든 필드는 실시간 [목록](./lists.md)으로 저장할 수 있습니다.

## 검색을 목록으로 저장하기

검색을 실행한 후에는 교인 페이지 헤더에 **목록으로 저장** 버튼(책갈피 아이콘)이 나타납니다. 이를 클릭하면 현재 쿼리를 이름과 선택적인 카테고리로 저장해, 이후 세션에서 즉시 다시 불러올 수 있습니다. 자세한 내용은 [저장된 목록](./lists.md)을 참고하세요.
