# 인쇄 디렉토리

<div class="article-intro">

인쇄 디렉토리 기능은 교회용 형식이 지정되고 인쇄 가능한 구성원 디렉토리를 생성합니다. 가정별로 구성원을 구성하고, 연락처 정보와 사진을 포함하고, 표준 편지 크기 용지에 인쇄할 때 전문적으로 보이도록 설계되었습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 사람을 볼 수 있는 권한이 있는 활성 B1 Admin 계정 필요
- 최상의 결과를 위해 디렉토리의 사람이 사진과 연락처 정보를 입력해야 합니다.

</div>

## 인쇄 디렉토리 열기

1. B1 Admin에서 **사람**으로 이동합니다.
2. 사람 결과 카드 상단의 도구 모음에서 **인쇄 아이콘**(프린터 아이콘)을 클릭합니다. 내보내기 버튼 옆에 나타납니다.
3. 인쇄 디렉토리가 새 브라우저 탭에서 열리고 디렉토리 데이터를 로드하기 시작합니다.
4. 약 1.5초 후 브라우저의 인쇄 대화가 자동으로 나타납니다.

:::tip
디렉토리는 별도의 탭에서 열리므로 사람 페이지를 떠나지 않고 인쇄할 수 있습니다. 인쇄 대화가 나타난 후 탭이 자동으로 다시 이동합니다.
:::

## 포함된 항목

인쇄 디렉토리에는 교회의 모든 **활성 구성원**이 포함됩니다. 특히:

- **비활성** 또는 **방문자** 구성원 상태를 가진 사람은 자동으로 제외됩니다.
- 디렉토리에서 **옵트아웃**한 사람은 제외됩니다.
- 다른 모든 사람은 **가정별**로 그룹화됩니다.

## 디렉토리 레이아웃

인쇄된 디렉토리는 두 부분으로 구성됩니다:

### 표지

첫 페이지에는 다음이 포함됩니다:
- 교회 이름
- "구성원 디렉토리" 제목
- 현재 연도
- 교회의 위치
- 포함된 총 가정 개수

### 구성원 목록

남은 페이지는 성씨별로 알파벳순으로 가정을 나열합니다. 각 가정 카드에는 다음이 표시됩니다:

- **사진** -- 각 가정 구성원의 원형 썸네일, 아래에 이름
- **가정 표시 이름** -- 예: "Smith 가족", "John & Jane Doe" 또는 개인의 경우 이름만
- **주소** -- 거리 주소, 도시, 주 및 우편번호
- **전화** -- 집 또는 휴대폰 번호
- **이메일** -- 기본 이메일 주소
- **생일** -- 각 가정 구성원에 대해 개별 날짜로 형식화됨
- **기념일** -- 기록된 경우

가정은 **알파벳 섹션**(A, B, C, ...)으로 구성되며 각 문자 그룹 앞에 장식 섹션 헤더가 있습니다. 두 개의 가정 카드가 각 행에 나란히 나타납니다.

## 인쇄 설정

디렉토리는 0.5인치 여백이 있는 **편지 크기 용지**(8.5" × 11")용으로 형식이 지정됩니다. 브라우저 인쇄 대화가 나타나면:

- 용지 크기를 **편지**로 설정된 대로 두세요
- 섹션 헤더가 색상 스타일과 함께 인쇄되기를 원하면 브라우저의 인쇄 설정에서 **배경 그래픽** 활성화(때로는 "배경 인쇄")
- 세로 방향이 권장됩니다

:::info
디렉토리는 페이지 나누기를 존중합니다 — 가정 카드 및 섹션 헤더는 페이지 전체에 분할되지 않습니다.
:::
