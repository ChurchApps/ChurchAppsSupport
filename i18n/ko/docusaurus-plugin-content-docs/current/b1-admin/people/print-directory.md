# 디렉터리 인쇄

<div class="article-intro">

디렉터리 인쇄 기능은 교회를 위한 형식이 갖춰진 인쇄용 성도 디렉터리를 만듭니다. 성도를 가구별로 정리하고, 연락처와 사진을 포함하며, 표준 레터 용지에 인쇄했을 때 전문적으로 보이도록 설계되었습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 사람을 볼 수 있는 권한이 있는 활성 B1 Admin 계정이 필요합니다.
- 최상의 결과를 위해 디렉터리의 사람들에게 사진과 연락처가 입력되어 있어야 합니다.

</div>

## 디렉터리 인쇄 열기 {#opening-the-print-directory}

1. B1 Admin에서 **People**로 이동하세요.
2. People 페이지 머리글의 **Print Directory**를 클릭하세요.
3. 디렉터리 인쇄 페이지가 새 브라우저 탭에서 열리고 디렉터리 데이터를 불러오기 시작합니다.
4. 약 1.5초 후, 브라우저의 인쇄 대화상자가 자동으로 나타납니다.

:::tip
디렉터리는 별도의 탭에서 열리므로 People 페이지를 떠나지 않고도 인쇄할 수 있습니다. 인쇄 대화상자가 닫히면 그 탭은 People 페이지로 바뀌므로, 닫거나 그대로 작업을 계속할 수 있습니다.
:::

## 포함되는 내용 {#what-gets-included}

인쇄 디렉터리에는 교회의 모든 **활동 중인 회원**이 포함됩니다. 구체적으로는 다음과 같습니다:

- 교인 상태가 **Inactive**, **Visitor**, **Deceased**인 사람은 자동으로 제외됩니다.
- 디렉터리에서 **제외 설정(opt out**)을 한 사람은 제외됩니다.
- 나머지 모든 사람은 **가구**별로 묶입니다.

### 검색 결과만 인쇄하기 {#printing-only-your-search-results}

People 페이지에서 검색을 실행하면 -- 빠른 검색, [고급 검색](./searching-people.md#advanced-search), [저장된 목록](./lists.md), [AI 검색](./ai-search.md) 중 무엇이든 -- **Print Directory** 버튼이 **Print Results**로 바뀝니다. 이것을 클릭하면 전체 교회 대신 검색 결과에 있는 사람만 같은 레이아웃으로 디렉터리를 인쇄합니다.

검색 결과를 인쇄할 때는 위의 교인 상태 필터가 적용되지 않습니다. 검색한 모든 사람이 포함되며, 방문자나 비활성 사람도 예외가 아닙니다. 디렉터리에서 제외 설정을 한 사람은 여전히 빠집니다. 전체 디렉터리 인쇄로 돌아가려면 먼저 검색을 지우세요.

## 디렉터리 레이아웃 {#directory-layout}

인쇄된 디렉터리는 두 부분으로 구성됩니다:

### 표지 {#cover-page}

첫 페이지에는 다음이 포함됩니다:
- 설정되어 있다면 교회 로고
- 교회 이름
- "Member Directory"라는 제목
- 현재 연도
- 교회의 도시와 주
- 인쇄한 날짜와 포함된 가구 수

### 성도 목록 {#member-listings}

나머지 페이지에는 가구가 성을 기준으로 알파벳순으로 나열됩니다. 각 가구 카드에는 다음이 표시됩니다:

- **사진** -- 각 가구 구성원의 원형 썸네일과 그 아래의 이름
- **가구 표시 이름** -- 예를 들어 "The Smith Family", "John & Jane Doe", 또는 개인의 경우 그 사람의 이름
- **주소** -- 도로 주소, 도시, 주, 우편번호
- **전화** -- 집 전화번호, 가구 중 아무도 집 전화번호가 없다면 휴대폰 번호
- **이메일** -- 기본 이메일 주소
- **생일** -- 각 구성원의 이름과 생일(월과 일)
- **결혼기념일** -- 기록되어 있는 경우

가구는 **알파벳 구역**(A, B, C, ...)으로 나뉘며, 각 글자 묶음 앞에 장식된 구역 머리글이 있습니다. 각 행에는 가구 카드 두 개가 나란히 나타납니다.

## 인쇄 설정 {#print-settings}

디렉터리는 0.5인치 여백이 있는 **레터 용지 크기**(8.5" × 11")에 맞춰져 있습니다. 브라우저 인쇄 대화상자가 나타나면:

- 용지 크기를 **Letter**로 그대로 두세요.
- 구역 머리글을 색상 스타일과 함께 인쇄하려면 브라우저의 인쇄 설정에서 **Background graphics**("Print backgrounds"라고도 함)를 켜세요.
- 세로 방향을 권장합니다.

:::info
디렉터리는 페이지 나누기를 존중합니다. 가구 카드와 구역 머리글은 페이지 사이에서 잘리지 않습니다.
:::
