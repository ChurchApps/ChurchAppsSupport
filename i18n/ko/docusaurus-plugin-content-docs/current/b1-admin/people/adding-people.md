# 교인 추가

<div class="article-intro">

교인 섹션은 B1 Admin의 기초이며, 교회의 회원 데이터베이스입니다. 다른 모든 기능(그룹, 출석, 헌금, 양식)은 결국 인물 기록과 연결됩니다. 이 가이드는 데이터베이스에 사람을 추가하고, 세부 정보를 편집하고, 가족 구성원을 가구로 연결하는 방법을 안내합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 교인을 관리할 수 있는 권한을 가진 활성 B1 Admin 계정이 필요합니다. 자신의 접근 수준이 확실하지 않다면 [역할 및 권한](roles-permissions.md)을 참고하세요.
- 몇 명 이상을 한꺼번에 추가한다면 [CSV 가져오기](importing-data.md) 도구를 사용하는 것을 고려하세요.

</div>

## 교인 추가하기

1. B1.church Admin 대시보드로 이동합니다.
2. 왼쪽 사이드바에서 **교인**을 클릭합니다.
3. 오른쪽 상단의 **교인 추가** 버튼을 클릭합니다.
4. 이름, 성, 이메일 주소를 입력한 다음 **추가**를 클릭합니다.

해당 인물의 프로필 페이지가 열리며, 여기서 더 많은 세부 정보를 추가할 수 있습니다.

:::tip
다른 교회 관리 시스템에서 마이그레이션하는 경우, [데이터 가져오기](importing-data.md) 기능을 사용하면 CSV 파일에서 전체 명부를 한 번에 가져올 수 있습니다 — 한 명씩 추가하는 것보다 훨씬 빠릅니다.
:::

## 세부 정보 편집하기

1. 인물의 프로필 페이지에서 이름 옆의 **편집 연필 아이콘**을 클릭합니다.
2. 중간 이름, 회원 상태, 날짜, 주소, 전화번호, (자녀와 학생의 경우) 학년과 학교 등 추가 정보를 입력합니다.
3. **저장**을 클릭해 개인 정보를 저장합니다.

프로필에는 관련 정보를 위한 여러 탭도 포함되어 있습니다.

- **노트** — 해당 인물에 대한 노트를 추가합니다(목회적 돌봄, 후속 조치 등)
- **그룹** — [그룹 소속](../groups/group-members.md)을 조회하고 관리합니다
- **출석** — [출석 기록](../attendance/tracking-attendance.md)을 조회합니다
- **헌금** — [헌금 내역](../donations/recording-donations.md)을 조회합니다

## 양식 작업하기

인물의 프로필에서 직접 사용자 지정 양식을 작성할 수 있습니다. 이는 [양식 만들기](../forms/creating-forms.md) 가이드를 따라 직접 만들 수 있는 사용자 정의 양식입니다.

1. 인물의 프로필에서 **양식** 드롭다운을 클릭해 양식을 선택합니다.
2. **양식 추가**를 클릭해 엽니다.
3. 양식 정보를 입력하고 **저장**을 클릭합니다.

:::info
인물의 프로필에 연결된 양식은 **교인** 양식 유형을 사용합니다. 행사 등록과 같은 독립형 양식이 필요하다면, 양식 가이드의 [독립형 양식 옵션](../forms/creating-forms.md)을 참고하세요.
:::

:::tip
날짜, 숫자, 예/아니오 답변처럼 한두 가지 추가 정보만 교인별로 추적하면 된다면, 양식 대신 [사용자 지정 필드](../settings/custom-fields.md)를 사용하세요. 입력이 더 빠르고, 고급 검색에서 직접 검색할 수 있습니다.
:::

## 가구 관리하기

가구를 사용하면 가족 구성원을 서로 연결할 수 있습니다. 특히 [체크인](../attendance/check-in.md)에 유용해서, 부모가 자녀 전체를 한 번에 체크인할 수 있습니다.

1. 인물의 프로필에서 가구 이름 옆의 **편집 연필 아이콘**을 클릭합니다.
2. 가구 편집기가 열립니다. 현재 인물의 **가구 내 역할**을 선택합니다(예: 가장, 배우자, 자녀).
3. **추가**를 클릭해 다른 가구 구성원을 추가합니다.
4. 검색 상자에 이름을 입력하고 **검색**을 클릭합니다.
5. 검색 결과에 해당 인물이 나타나면 **선택**을 클릭합니다.
6. 가구 내 역할을 선택하고 **저장**을 클릭해 가구 설정을 완료합니다.
