# 신도 추가

<div class="article-intro">

사람 섹션은 B1 Admin의 기초입니다. 교회의 신도 데이터베이스입니다. 다른 모든 기능(그룹, 출석, 기부, 양식)은 사람 기록에 연결됩니다. 이 가이드는 누군가를 데이터베이스에 추가하고, 세부 정보를 편집하고, 가족 구성원을 가계에 연결하는 방법을 안내합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 사람을 관리할 권한이 있는 활성 B1 Admin 계정이 필요합니다. 액세스 수준이 확실하지 않으면 [역할 및 권한](roles-permissions.md) 참조하세요.
- 한 번에 여러 사람을 추가하는 경우 [CSV 가져오기](importing-data.md) 도구 사용을 고려하세요.

</div>

## 사람 추가

1. B1.church Admin 대시보드로 이동합니다.
2. 왼쪽 위 모서리의 **섹션 메뉴**를 열고 **사람**을 선택합니다.
3. 오른쪽 위 모서리의 **사람 추가** 버튼을 클릭합니다.
4. 사람의 이름, 성과 이메일 주소를 입력한 후 **추가**를 클릭합니다.

사람의 프로필 페이지가 열리며 더 많은 세부 정보를 추가할 준비가 됩니다.

:::tip
다른 교회 관리 시스템에서 마이그레이션하는 경우 [데이터 가져오기](importing-data.md) 기능을 통해 CSV 파일에서 전체 디렉토리를 가져올 수 있습니다. 한 번에 하나씩 사람을 추가하는 것보다 훨씬 빠릅니다.
:::

## 세부 정보 편집

1. 사람의 프로필 페이지에서 이름 옆의 **편집 연필**을 클릭합니다.
2. 중간 이름, 회원 상태, 날짜, 주소, 전화 번호 및 (어린이와 학생의 경우) 학년 및 학교와 같은 추가 정보를 입력합니다.
3. **저장**을 클릭하여 개인 정보를 저장합니다.

프로필에는 또한 관련 정보를 위한 여러 탭이 포함되어 있습니다:

- **노트** — 사람에 대한 노트 추가(목회적 돌봄, 후속 조치 등)
- **그룹** — [그룹 회원 관리](../groups/group-members.md) 보기 및 관리
- **출석** — [출석 기록](../attendance/tracking-attendance.md) 보기
- **기부** — [기부 내역](../donations/recording-donations.md) 보기

## 양식으로 작업

사람의 프로필에서 직접 사용자 정의 양식을 작성할 수 있습니다. 이는 [양식 생성](../forms/creating-forms.md) 가이드를 따라 빌드할 수 있는 사용자 정의 양식입니다.

1. 사람의 프로필에서 **양식** 드롭다운을 클릭하여 양식을 선택합니다.
2. **양식 추가**를 클릭하여 엽니다.
3. 양식 세부 정보를 입력하고 **저장**을 클릭합니다.

:::info
사람의 프로필에 연결된 양식은 **사람** 양식 유형을 사용합니다. 독립형 양식(예: 이벤트 등록)이 필요한 경우 양식 가이드의 [독립형 양식 옵션](../forms/creating-forms.md)을 참조.
:::

:::tip
신도에게 하나 또는 두 개의 추가 정보만 추적하면 되는 경우(날짜, 숫자, 예/아니오 답변), 양식 대신 [사용자 정의 필드](../settings/custom-fields.md)를 사용합니다. 작성 속도가 빠르고 고급 검색에서 직접 검색 가능합니다.
:::

## 가계 관리

가계는 가족 구성원을 함께 연결합니다. 이는 [체크인](../attendance/check-in.md)에서 부모가 모든 자녀를 한 번에 체크인할 수 있는 경우에 특히 유용합니다.

1. 사람의 프로필에서 가계 이름 옆의 **편집 연필**을 클릭합니다.
2. 가계 편집기가 열립니다. 현재 사람의 **가계 역할** 선택(예: 가장, 배우자, 자녀).
3. **추가**를 클릭하여 다른 가계 구성원을 추가합니다.
4. 검색 상자에 사람의 이름을 입력하고 **검색**을 클릭합니다.
5. 사람이 검색 결과에 나타나면 **선택**을 클릭합니다.
6. 그들의 가계 역할을 선택하고 **저장**을 클릭하여 가계 설정을 완료합니다.
