# 사람 추가

<div class="article-intro">

사람 섹션은 B1 Admin의 기초입니다 — 교회의 회원 데이터베이스입니다. 다른 모든 기능(그룹, 참석, 기부금, 양식)은 사람 기록에 연결됩니다. 이 가이드는 누군가를 데이터베이스에 추가하고, 세부 정보를 편집하고, 가족 구성원을 가구로 연결하는 방법을 안내합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 사람을 관리할 수 있는 권한이 있는 활성 B1 Admin 계정이 필요합니다. 액세스 수준이 확실하지 않은 경우 [역할 및 권한](roles-permissions.md)을 참조하세요.
- 한 번에 여러 사람을 추가하는 경우 [CSV 가져오기](importing-data.md) 도구 사용을 고려하세요.

</div>

## 사람 추가하기

1. B1.church Admin 대시보드로 이동합니다.
2. [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu) (왼쪽 상단의 검색창)를 열고, **사람**을 확장한 후 **사람**을 클릭합니다.
3. 오른쪽 상단 모서리의 **사람 추가** 버튼을 클릭합니다.
4. 사람의 이름, 성 및 이메일 주소를 입력한 후 **추가**를 클릭합니다.

사람의 프로필 페이지가 열리고 더 많은 세부 정보를 추가할 준비가 됩니다.

:::tip
다른 교회 관리 시스템에서 마이그레이션하는 경우, [데이터 가져오기](importing-data.md) 기능을 사용하면 전체 디렉토리를 한 번에 한 명씩 추가하는 것보다 훨씬 빠르게 가져올 수 있습니다.
:::

### 중복 경고

이메일 주소(또는 전체 편집 양식에서 사람을 만들 때 전화번호 또는 이름 + 성 + 생일 일치)가 데이터베이스의 누군가와 일치하면, 새 기록이 저장되기 전에 **가능한 중복** 대화 상자가 나타납니다. 이메일, 전화 및 생일과 함께 일치하는 각 사람이 나열되므로 비교할 수 있습니다.

- 일치 옆의 **기존 항목 사용**을 클릭하여 새 항목을 만드는 대신 해당 사람의 기록을 사용합니다.
- 가능한 일치가 발견되었지만 어쨌든 새 사람을 추가하려면 **어쨌든 만들기**를 클릭합니다.

이것은 새로운 사람을 만들 때만 중복을 확인합니다 — 기존 기록을 편집하면 트리거되지 않습니다. 새로운 중복을 방지하지만 이미 존재하는 두 기록을 병합하지는 않습니다.

## 세부 정보 편집

1. 사람의 프로필 페이지에서 이름 옆의 **편집 연필**을 클릭합니다.
2. 중간 이름, 회원 상태, 날짜, 주소, 전화번호 및 (어린이 및 학생의 경우) 학년 및 학교와 같은 추가 정보를 입력합니다.
3. **저장**을 클릭하여 개인 정보를 저장합니다.

프로필에는 관련 정보에 대한 여러 탭도 포함됩니다:

- **노트** -- 사람에 대한 노트를 추가합니다 (목회 돌봄, 추적 등).
- **그룹** -- [그룹 회원](../groups/group-members.md)을 보고 관리합니다.
- **참석** -- 이 사람의 개별 방문 기록을 봅니다 (캠퍼스, 서비스, 서비스 시간, 그룹 및 키오스크 체크인 시간이 표시된 **체크인됨** 열 포함, 키오스크 체크인 없이 기록된 방문의 경우 대시로 표시됨). 한 사람의 기록이 아닌 교회 전체 추세를 보려면 [참석 추적](../attendance/tracking-attendance.md)을 참조하세요.
- **기부금** -- [기부금 기록](../donations/recording-donations.md)을 봅니다.

## 사람에게 이메일 보내기

사람이 파일에 이메일 주소를 가지고 있으면, 프로필 헤더에 **이 사람에게 이메일 보내기** 버튼 (봉투 아이콘)이 나타납니다.

1. 사람의 프로필에서 **봉투 아이콘**을 클릭합니다.
2. 사람의 이름으로 제목이 지정된 **이메일** 대화 상자가 열려 **보내는 대상**에 사람의 주소가 표시됩니다.
3. 선택적으로 **템플릿 로드 (선택 사항)**에서 저장된 템플릿을 선택합니다.
4. **제목**을 입력하고 메시지를 작성합니다.
5. **이메일 보내기**를 클릭합니다.

대신 자신의 메일 프로그램에서 메시지를 작성하려면 **내 이메일 앱에서 열기**를 클릭합니다.

:::info
B1에서 보내기는 그룹 이메일과 동일한 승인 및 일일 한도를 사용합니다. 교회가 아직 승인되지 않았다면 대화 상자에서 검토를 요청하도록 요청합니다 -- 그 동안 **내 이메일 앱에서 열기**를 클릭할 수 있습니다. [교회를 위해 그룹 이메일 켜기](../groups/group-members.md#turning-on-group-email-for-your-church)를 참조하세요. 그룹 회원을 편집할 수 있는 권한이 없는 사용자는 봉투 아이콘을 클릭할 때 바로 이메일 앱으로 이동합니다.
:::

## 양식 작업

사람의 프로필에서 직접 사용자 정의 양식을 작성할 수 있습니다. 이러한 양식은 [양식 만들기](../forms/creating-forms.md) 가이드를 따라 구축할 수 있는 사용자 정의 양식입니다.

1. 사람의 프로필에서 **양식** 드롭다운을 클릭하여 양식을 선택합니다.
2. **양식 추가**를 클릭하여 엽니다.
3. 양식 세부 정보를 입력하고 **저장**을 클릭합니다.

양식이 제출되면 옆의 **인쇄 아이콘**을 클릭하여 해당 사람의 작성된 답변을 인쇄합니다.

제출 항목이 잘못된 사람에게 연결된 경우, 옆의 **사람 변경** 아이콘 (두 개의 화살표)을 클릭하여 다른 사람으로 이동하거나 연결을 해제합니다. [제출 항목의 사람 변경](../forms/managing-submissions.md#changing-the-person-on-a-submission)을 참조하세요.

:::info
사람의 프로필에 연결된 양식은 **사람** 양식 유형을 사용합니다. 이벤트 등록과 같은 독립 실행형 양식이 필요한 경우, 양식 가이드의 [독립 실행형 양식 옵션](../forms/creating-forms.md)을 참조하세요.
:::

:::tip
사람에 대해 하나 또는 두 개의 추가 정보만 추적하면 되는 경우 -- 날짜, 숫자, 예/아니오 답변 -- 양식 대신 [사용자 정의 필드](../settings/custom-fields.md)를 사용합니다. 입력하기가 더 빠르고 고급 검색에서 직접 검색 가능합니다.
:::

## 가구 관리

가구를 사용하면 가족 구성원을 함께 연결할 수 있습니다. 이는 부모가 모든 자녀를 한 번에 체크인할 수 있는 [체크인](../attendance/check-in.md)에 특히 유용합니다.

1. 사람의 프로필에서 가구 이름 옆의 **편집 연필**을 클릭합니다.
2. 가구 편집기가 열립니다. 현재 사람의 **가구 역할**을 선택합니다 (예: 대표, 배우자, 자녀).
3. **추가**를 클릭하여 다른 가구 구성원을 추가합니다.
4. 검색 상자에 사람의 이름을 입력하고 **검색**을 클릭합니다.
5. 검색 결과에 그 사람이 나타나면 **선택**을 클릭합니다.
6. 해당 사람의 가구 역할을 선택하고 **저장**을 클릭하여 가구 설정을 완료합니다.
