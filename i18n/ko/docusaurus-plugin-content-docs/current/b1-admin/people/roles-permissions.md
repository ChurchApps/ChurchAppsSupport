# 역할 할당

<div class="article-intro">

B1 Admin은 역할 기반 권한 시스템을 사용하여 팀의 각 사용자가 보고 수행할 수 있는 작업을 제어합니다. 역할을 할당하면 직원 및 자원봉사자에게 필요한 정확한 영역에만 액세스할 수 있으며, 이 이상은 없습니다. 적절한 역할 관리는 교회 데이터를 안전하게 유지하면서 팀이 효율적으로 작업하도록 권한을 부여합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- **도메인 관리자** 액세스 또는 B1 Admin에서 **설정**을 관리할 권한이 있는 역할이 필요합니다.
- 역할을 할당하려는 사람들이 이미 디렉토리에 있어야 합니다. 먼저 추가해야 하는 경우 [신도 추가](adding-people.md) 참조.

</div>

## 역할 이해

역할은 하나 이상의 사용자에게 할당하는 권한 집합입니다. 예를 들어 [기부 기록](../donations/recording-donations.md)에 액세스할 수 있도록 하는 "재정 팀" 역할을 만들거나 [출석 기능](../attendance/check-in.md)에만 액세스할 수 있게 하는 "체크인 자원봉사자" 역할을 만들 수 있습니다.

각 역할은 다음을 포함한 B1 Admin의 특정 영역에 대한 액세스를 제어합니다:

- **사람** -- 신도 프로필 보기 및 편집. 사람 기록의 노트 탭에는 **사람 편집**이 필요하고 별도의 **기밀 노트 보기** 권한이 기밀 노트 섹션(목회적 돌봄, 개인 기록 및 유사한 민감한 노트)에 대한 액세스를 제어합니다.
- **기부** -- 기여 및 재정 보고서 관리
- **출석** -- 출석 데이터 기록 및 보기
- **양식** -- [사용자 정의 양식](../forms/creating-forms.md) 생성 및 관리
- **그룹** -- [그룹 회원](../groups/group-members.md) 및 달력 관리
- **설정** -- 교회 전체 설정 구성

:::warning
**도메인 관리자**는 B1 Admin의 모든 영역에 전체 액세스할 수 있습니다. 권한을 편집하거나 제한할 수 없습니다. 이 역할은 주요 관리자에게만 사용합니다.
:::

## 역할 보기 및 관리

1. 왼쪽 위 모서리의 **섹션 메뉴**(섹션 이름과 작은 화살표)를 열고 **설정**을 선택합니다.
2. 상단 탐색에서 **역할**을 클릭합니다.
3. 교회에 대해 구성된 모든 역할의 목록이 표시됩니다.
4. 아무 역할을 클릭하여 해당 구성원 및 권한을 봅니다.

## 역할에 사용자 추가

1. **설정**으로 이동한 후 **역할**을 클릭합니다.
2. 사용자를 추가하려는 역할을 클릭합니다.
3. **회원** 섹션에서 이름으로 사람을 검색합니다.
4. **추가**를 클릭하여 역할에 할당합니다.

사용자는 다음 로그인 시 해당 역할과 관련된 모든 권한을 갖게 됩니다.

## 역할 권한 편집

1. **설정**으로 이동한 후 **역할**을 클릭합니다.
2. 수정하려는 역할을 클릭합니다.
3. **권한** 섹션에서 역할이 액세스할 영역을 선택 또는 선택 해제합니다.
4. **저장**을 클릭하여 변경 사항을 적용합니다.

:::tip
최소 권한 원칙을 따르세요. 각 역할에 정말 필요한 권한만 부여하세요. 이는 데이터를 안전하게 유지하고 실수로 인한 변경 가능성을 줄입니다.
:::

## 일반적인 역할 예

- **사무실 직원** -- 사람, 기부, 출석 및 양식에 대한 액세스
- **그룹 리더** -- [그룹](../groups/creating-groups.md)에만 액세스
- **체크인 자원봉사자** -- [출석](../attendance/check-in.md)에만 액세스
- **재정 팀** -- [기부](../donations/recording-donations.md) 및 보고서에 대한 액세스
