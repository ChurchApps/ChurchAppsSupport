# 저장된 목록

<div class="article-intro">

**저장된 목록**을 사용하면 검색 쿼리를 이름을 붙여 저장하고 언제든지 클릭 한 번으로 다시 실행할 수 있습니다. "캠퍼스 노스 지역 활성 회원", "최근 90일 방문자"처럼 목록을 한 번만 만들어 두면, 사이드바에 계속 남아 있으므로 매번 쿼리를 새로 작성할 필요가 없습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 저장할 결과를 얻으려면 교인 섹션에서 최소 한 번은 검색을 실행하세요. [교인 검색](./searching-people.md) 또는 [AI 검색](./ai-search.md)을 참고하세요.

</div>

## 검색을 목록으로 저장하기

1. **교인** 페이지에서 검색을 실행합니다 — 빠른 검색, AI 검색, 또는 고급 필터 검색 모두 가능합니다.
2. 결과가 나타나면 교인 페이지 헤더에 **목록으로 저장** 버튼(책갈피 아이콘)이 표시됩니다.
3. **목록으로 저장**을 클릭합니다.
4. 목록의 **이름**을 입력합니다(필수 항목).
5. 사이드바에서 관련 목록을 함께 묶고 싶다면 선택적으로 **카테고리**를 입력합니다(예: "아웃리치" 또는 "회원").
6. **저장**을 클릭합니다.

이제 목록이 교회 계정에 저장되며, 교인 페이지 왼쪽의 **저장된 목록** 패널에 나타납니다.

:::info
목록은 교회 전체에 공유됩니다 — 교인 접근 권한이 있는 사람이라면 누구든 볼 수 있고 불러올 수 있습니다. 목록의 이름 변경이나 삭제는 적절한 권한을 가진 직원만 할 수 있습니다.
:::

## 저장된 목록 불러오기

교인 페이지 왼쪽의 **저장된 목록** 패널에서 목록 이름을 클릭하세요. 저장된 쿼리로 검색이 즉시 다시 실행되며 결과 표가 업데이트됩니다.

목록은 (카테고리를 지정한 경우) 카테고리별로 그룹화되며, 카테고리가 없는 목록은 마지막에 표시됩니다.

:::tip
목록은 스냅샷이 아니라 **실시간 쿼리**입니다. 목록을 불러올 때마다 현재 데이터를 기준으로 검색이 새로 실행되므로, 이제 막 조건을 충족한 새로운 사람도 결과에 나타납니다.
:::

## 목록 이름 변경 및 삭제

관리 권한이 있는 직원은 저장된 목록 패널에서 직접 목록의 이름을 변경하거나 삭제할 수 있습니다.

- 목록 이름 옆의 **연필 아이콘**을 클릭해 이름을 변경합니다.
- **휴지통 아이콘**을 클릭해 삭제합니다(확인 절차가 표시됩니다).

## 사용 사례

| 시나리오 | 목록 만드는 방법 |
|---|---|
| 모든 방문자 | 고급 검색: 회원 상태 = 방문자 |
| 특정 캠퍼스의 회원 | 고급 검색: 캠퍼스 = [해당 캠퍼스] |
| 이메일 주소가 없는 사람 | 고급 검색: 이메일이 비어 있음 |
| 신원조회 기한이 만료된 자원봉사자 | 고급 검색: [사용자 지정 필드](../settings/custom-fields.md) "신원조회 만료일"이 오늘 이전 |
| AI 질문의 결과 | AI 검색에서 질문을 한 다음 저장 |
