# 저장된 목록

<div class="article-intro">

**저장된 목록**은 검색 쿼리를 이름 아래에 저장하고 언제든 한 번의 클릭으로 다시 실행할 수 있습니다. 목록을 한 번 작성합니다 — "캠퍼스 북쪽의 활성 구성원", "지난 90일 동안의 방문자" 또는 고급 필터입니다 — 그리고 사람 페이지의 **저장된 목록** 패널에 유지되므로 쿼리를 다시 작성할 필요가 없습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 사람 섹션에서 최소 하나의 검색을 실행하여 저장할 결과가 있습니다. [사람 검색](./searching-people.md) 또는 [AI 검색](./ai-search.md) 참조.

</div>

## 검색을 목록으로 저장

1. **사람** 페이지에서 검색을 실행합니다 — 빠른 검색, AI 검색 또는 고급 필터 검색입니다.
2. 결과가 나타나면 **목록으로 저장** 버튼(책갈피 아이콘)이 사람 페이지 헤더에 표시됩니다.
3. **목록으로 저장**을 클릭합니다.
4. 목록의 **이름**을 입력합니다(필수).
5. 선택적으로 **범주**를 입력하여 **저장된 목록** 패널에서 관련 목록을 함께 그룹화합니다(예: "봉사활동" 또는 "구성원").
6. **저장**을 클릭합니다.

목록은 이제 교회 계정에 저장되고 사람 페이지의 왼쪽 **저장된 목록** 패널에 나타납니다.

:::info
목록은 교회 전체에서 공유됩니다 — 사람에게 액세스할 수 있는 모든 사람이 볼 수 있고 로드할 수 있습니다. 적절한 권한이 있는 직원만 목록의 이름을 바꾸거나 삭제할 수 있습니다.
:::

## 저장된 목록 로드

사람 페이지의 왼쪽 **저장된 목록** 패널에서 목록 이름을 클릭합니다. 저장된 쿼리로 검색이 즉시 다시 실행되고 결과 표가 업데이트됩니다.

목록은 범주별로 그룹화됩니다(할당한 경우) 분류되지 않은 목록이 마지막에 나타납니다.

:::tip
목록은 **라이브 쿼리**이지만 스냅샷이 아닙니다. 목록을 로드할 때마다 검색은 현재 데이터에 대해 신선하게 실행되므로 조건과 일치하는 새 사람이 나타납니다.
:::

## 목록 이름 변경 및 삭제

관리 권한이 있는 직원은 저장된 목록 패널에서 직접 목록의 이름을 바꾸거나 삭제할 수 있습니다.

- 목록 이름 옆의 **연필 아이콘**을 클릭하여 이름을 바꿉니다.
- **휴지통 아이콘**을 클릭하여 삭제합니다(확인을 요청합니다).

## 사용 사례

| 시나리오 | 목록을 작성하는 방법 |
|---|---|
| 모든 방문자 | 고급 검색: 구성원 상태 = 방문자 |
| 특정 캠퍼스의 구성원 | 고급 검색: 캠퍼스 = [귀 캠퍼스] |
| 이메일 주소가 없는 사람 | 고급 검색: 이메일이 비어 있음 |
| 만료된 신원조회가 있는 자원봉사자 | 고급 검색: [사용자 정의 필드](../settings/custom-fields.md) "신원조회 만료" 오늘 이전 |
| AI 질문의 결과 | AI 검색에서 질문을 하고 저장합니다 |
