# 저장된 목록
<div class="article-intro">
**저장된 목록**은 검색 쿼리를 이름 아래에 저장하고 언제든지 다시 실행할 수 있게 해줍니다. 목록을 한 번 만들면, 사람 페이지의 **저장된 목록** 패널에 저장되어 다시 구축할 필요가 없습니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- 사람 섹션에서 최소 하나의 검색을 실행해야 합니다
</div>
## 검색을 목록으로 저장
1. **사람** 페이지에서 검색을 실행합니다
2. 결과가 나타나면 **목록으로 저장** 버튼을 클릭합니다
3. 목록의 **이름**을 입력합니다
4. 선택적으로 **카테고리**를 입력합니다
5. **저장**을 클릭합니다
## 저장된 목록 로드
**저장된 목록** 패널에서 목록 이름을 클릭하면 검색이 실행되고 결과가 업데이트됩니다.
