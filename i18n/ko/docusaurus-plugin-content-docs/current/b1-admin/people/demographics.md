# 인구 통계

<div class="article-intro">

**Demographics** 대시보드는 교회 성도의 시각적 요약을 보여 줍니다. 성도가 누구인지, 몇 명인지, 그리고 연령대, 성별, 혼인 상태, 캠퍼스별로 교인이 어떻게 분포되어 있는지 확인할 수 있습니다. 모든 차트는 대화형입니다. 어떤 조각을 클릭하면 정확히 그 사람들만 보여 주는 필터링된 People 검색으로 바로 이동합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 디렉터리에 사람이 있어야 합니다. 시작하려면 [사람 추가하기](./adding-people.md) 또는 [데이터 가져오기](./importing-data.md)를 참고하세요.
- 캠퍼스 차트를 캠퍼스별로 나누려면, 먼저 [설정 → 캠퍼스](../settings/campuses.md)에서 캠퍼스를 설정해야 합니다.

</div>

## Demographics 열기 {#opening-demographics}

**People** 페이지에서 페이지 머리글의 **Demographics**를 클릭하세요. 페이지 상단에는 전체 인원 수(**Total**)가 표시되고, 그 아래에 아래 설명하는 차트들이 나옵니다. 각 도넛 차트 아래에도 해당 차트의 합계가 표시됩니다. 오른쪽 위의 **People**을 클릭하면 디렉터리로 돌아갑니다.

## 차트 {#charts}

### 연령 {#age}

각 연령대에 속하는 사람 수를 보여 주는 누적 막대 차트입니다. 연령대는 0–3, 4–11, 12–18, 19–25, 26–35, 36–50, 51–64, 65 이상입니다. 각 막대는 성별로 나뉘며 — **Female**, **Male**, 그리고 해당 연령대에 성별이 기록되지 않은 사람이 있으면 **Unassigned** — 각 연령대 안의 성별 분포를 한눈에 볼 수 있습니다. 생년월일이 없는 사람은 이 차트에 포함되지 않습니다.

### 교인 유형 {#membership-types}

교인 상태(예: Member, Regular Attendee, Visitor 등)별로 교회를 나눈 도넛 차트입니다. 상태가 없는 사람은 **Unassigned**로 표시됩니다.

### 성별 {#gender}

디렉터리의 여성, 남성, 미지정 기록 비율을 보여 주는 도넛 차트입니다.

### 혼인 상태 {#marital-status}

혼인 상태 값(예: Married, Single, Widowed)별 분포를 보여 주는 도넛 차트입니다.

### 캠퍼스 {#campus}

교회의 캠퍼스별로 사람이 어떻게 분포되어 있는지 보여 주는 도넛 차트입니다. 캠퍼스가 지정되지 않은 사람은 **Unassigned**로 표시되므로, 캠퍼스가 없는 교회는 **Unassigned** 조각 하나만 보게 됩니다.

## 데이터 세부 탐색하기 {#drilling-into-the-data}

도넛 차트의 조각(또는 범례의 이름)이나 연령 차트의 막대 구간을 클릭하면 정확히 그 사람들만 필터가 적용된 **People** 페이지로 이동합니다. 페이지 로딩이 끝나도 필터는 유지되며, 목록 위의 개수는 일치하는 가구와 사람의 수를 보여 줍니다. 이 기능으로 연락처 목록을 빠르게 만들거나, 일괄 작업을 실행하거나, 특정 구간을 내보낼 수 있습니다. 예를 들어 교인 상태 차트의 **Visitor** 조각을 클릭하면 모든 방문자를 보고, 그들을 워크플로로 보낼 수 있습니다.

:::tip
필터가 적용된 결과로 이동한 후에는 People 검색의 **Save as List**를 사용하여 해당 필터를 나중에 쓸 수 있도록 저장하세요. [저장된 목록](./lists.md)을 참고하세요.
:::
