# 인구통계

<div class="article-intro">

**Demographics** 대시보드는 교인 현황을 한눈에 보여 줍니다. 교인이 누구인지, 몇 명인지, 그리고 연령대, 성별, 혼인 상태, 캠퍼스별로 어떻게 분포하는지 알 수 있습니다. 모든 차트는 상호작용이 가능합니다. 원하는 부분을 클릭하면 해당 사람들만 보여 주는 필터링된 People 검색 페이지로 바로 이동합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 디렉터리에 사람이 등록되어 있어야 합니다. 시작하려면 [사람 추가](./adding-people.md) 또는 [데이터 가져오기](./importing-data.md)를 참고하세요.
- 캠퍼스 차트를 보려면 먼저 [설정 → 캠퍼스](../settings/campuses.md)에서 캠퍼스를 설정해야 합니다.

</div>

## Demographics 열기

**People** 페이지에서 페이지 헤더의 **Demographics**를 클릭합니다. 페이지 상단에는 전체 인원수가 표시되고, 그 아래에 아래 설명된 차트가 나타납니다.

## 차트

### 연령 분포

각 연령대(예: 0–9, 10–17, 18–24 등 65세 이상까지)에 속한 사람 수를 보여 주는 묶음 막대 차트입니다. 각 막대는 **Female**(여성), **Male**(남성), **Unassigned**(미지정) 세 개의 계열로 나뉘어 있어, 각 연령대 안에서 성별 분포를 한눈에 볼 수 있습니다.

### 교인 상태

교인을 교인 상태(예: Member, Regular Attender, Visitor 등)별로 나눈 도넛 차트입니다.

### 성별

디렉터리에 있는 여성, 남성, 미지정 기록의 비율을 보여 주는 도넛 차트입니다.

### 혼인 상태

혼인 상태 값(예: Married, Single, Widowed)별 분포를 보여 주는 도넛 차트입니다.

### 캠퍼스

교회의 캠퍼스별로 사람이 어떻게 분포하는지 보여 주는 도넛 차트입니다. 이 차트는 캠퍼스가 설정되어 있고, 캠퍼스에 배정된 사람이 한 명 이상 있을 때만 나타납니다. 캠퍼스가 지정되지 않은 사람은 **Unassigned**로 표시됩니다.

## 데이터 자세히 보기

도넛 차트의 조각이나 연령 차트의 막대 구간을 클릭하면 해당 사람들만 표시하도록 미리 필터링된 **People** 페이지로 이동합니다. 페이지 로딩이 끝나도 필터가 유지되며, 목록 위의 개수는 일치한 가구와 사람 수를 보여 줍니다. 이 기능을 사용하면 연락처 목록을 빠르게 만들거나, 일괄 작업을 실행하거나, 특정 구간을 내보낼 수 있습니다. 예를 들어 Membership Status에서 **Visitor** 조각을 클릭하여 모든 방문자를 보고, 그들을 워크플로로 보낼 수 있습니다.

:::tip
필터링된 결과를 확인한 후, People 검색에서 **Save as List**를 사용하면 나중에 다시 사용할 수 있도록 필터를 저장할 수 있습니다. 자세한 내용은 [저장된 목록](./lists.md)을 참고하세요.
:::
