# 데이터 가져오기

<div class="article-intro">

B1 전송 도구를 사용하면 기존 데이터를 B1로 쉽게 가져올 수 있습니다. 스프레드시트에서 새로 시작하거나, 다른 교회 관리 플랫폼에서 마이그레이션하거나, 기부 기록을 가져오든 상관없습니다. 언제든지 데이터를 내보내거나 백업하는 데도 사용할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- **설정**에 액세스할 수 있는 활성 B1 Admin 계정이 필요합니다.
- 시작하기 전에 이전 시스템에서 데이터를 내보내고 준비하세요.
- 이 도구는 초기 데이터 마이그레이션을 목적으로 합니다. B1을 이미 사용 중인 경우 다시 가져오기 시 중복 기록이 생성될 수 있습니다.

</div>

## 전송 도구 액세스

1. **B1 Admin**에 로그인합니다.
2. 왼쪽 위 모서리의 **섹션 메뉴**(섹션 이름과 작은 화살표)를 열고 **설정**을 선택합니다.
3. 페이지 헤더의 오른쪽 위에서 **가져오기/내보내기** 버튼을 클릭합니다.
4. 새 탭에서 **B1 전송** 도구가 [transfer.b1.church](https://transfer.b1.church)에서 열립니다.

전송 도구는 4단계를 안내합니다: 원본, 미리보기, 대상 및 실행.

---

## 1단계 - 원본 선택

데이터가 어디에서 오는지 선택합니다. 7가지 옵션이 있습니다:

- **B1 데이터베이스** — 기존 B1 교회에서 직접 데이터를 가져옵니다. 백업을 만들거나 데이터를 다른 형식으로 변환하는 데 유용합니다. 이 옵션을 사용하려면 로그인해야 합니다.
- **B1 가져오기 Zip** -- B1 자체 형식의 zip 파일입니다. 주로 이전 B1 내보내기를 복원하는 데 사용됩니다.
- **Breeze 가져오기 Zip** -- Breeze ChMS에서 내보낸 파일을 포함하는 zip 파일입니다.
- **Planning Center Zip** -- Planning Center에서 내보낸 zip 또는 CSV 파일입니다.
- **사용자 정의 CSV / Excel** -- 사람 데이터를 포함하는 모든 CSV 또는 Excel 파일입니다. 업로드 후 가져오기가 진행되기 전에 열을 B1 필드로 매핑합니다.
- **Tithe.ly CSV** — Tithe.ly의 사람 또는 기부 내보내기 파일(CSV 또는 Excel 형식 허용).
- **CCB / Pushpay CSV** — Church Community Builder 또는 Pushpay의 사람 또는 기부 내보내기 CSV입니다.

파일을 업로드 영역으로 끌어서 놓거나 클릭하여 찾아보세요.

---

## 1단계b - 필드 매핑(사용자 정의 CSV / Excel만)

**사용자 정의 CSV / Excel**을 선택한 경우 파일을 업로드한 후 미리보기로 이동하기 전에 필드 매핑 화면이 표시됩니다.

파일의 각 열이 샘플 값과 함께 나열됩니다. 각 열에 대해 드롭다운을 사용하여 일치하는 B1 필드를 선택합니다. 도구는 "이름", "이메일" 또는 "우편 번호"와 같은 일반적인 열 이름을 자동 감지하지만 모든 행을 검토하고 놓친 항목을 수정해야 합니다.

사용 가능한 B1 필드에는:

- 이름, 성, 중간 이름, 별명, 표시 이름, 제목/접두사, 접미사
- 이메일, 집 전화, 휴대 전화, 직장 전화
- 주소 1줄, 주소 2줄, 도시, 주, 우편 번호
- 생년월일, 성별, 결혼 상태, 회원 상태
- 가계/가족 이름
- 그룹 이름 — 사람을 이름으로 그룹에 할당합니다.
- **양식 답변(사용자 정의 필드)** — 해당 열의 값을 사람의 기록에 첨부된 사용자 정의 필드로 저장합니다. 이 옵션을 사용하면 양식에 이름을 지정하라는 메시지가 표시됩니다.

가져오지 않으려는 열은 **(건너뛰기)**로 설정할 수 있습니다. 계속하기 전에 최소 하나의 이름 필드(이름 또는 성)를 매핑해야 합니다.

**매핑 확인 및 가져오기**를 클릭하여 미리보기로 이동합니다.

---

## 2단계 - 데이터 미리보기

업로드 후 도구는 가져올 모든 항목의 미리보기를 표시합니다. 탭을 사용하여 각 데이터 유형을 검토합니다:

- **사람** — 가계별로 나열되며 포함된 경우 사진입니다.
- **그룹** — 캠퍼스, 예배, 시간 및 범주별로 조직됩니다.
- **출석** — 세션 날짜, 그룹 및 방문 수입니다.
- **기부** — 배치, 기금, 기부자 및 금액입니다.
- **양식** — 양식 이름 및 콘텐츠 유형입니다.

진행하기 전에 이를 주의 깊게 검토하세요. 뭔가 잘못된 것처럼 보이면 **처음부터 시작**을 클릭하고 원본 파일을 수정합니다.

---

## 3단계 - 대상 선택

데이터를 가져올 위치를 선택합니다:

- **B1 데이터베이스** — 교회의 B1 데이터베이스로 직접 가져옵니다. 이를 선택한 후 도구는 추가할 기록의 최종 수를 표시합니다. **전송 시작**을 클릭하여 확인합니다.
- **B1 내보내기 Zip** — B1 형식 zip 파일로 데이터를 다운로드합니다. 백업에 좋습니다.
- **Breeze 내보내기 Zip** — Breeze 형식으로 데이터를 변환합니다.
- **Planning Center Zip** — Planning Center 형식으로 데이터를 변환합니다.

:::warning
원본과 대상은 동일한 형식일 수 없습니다. 일치하는 경우 도구는 실수로 중복을 방지하도록 경고합니다.
:::

---

## 4단계 - 실행

도구는 전송을 처리하고 각 단계의 진행 상황을 표시합니다:

- 캠퍼스, 예배 및 시간
- 사람
- 사진
- 그룹 및 그룹 회원
- 기부
- 출석
- 양식, 질문, 답변 및 양식 제출
- 압축(zip 파일 대상만)

:::warning
전송이 실행되는 동안 브라우저를 닫지 마세요. 모든 단계가 완료될 때까지 기다립니다.
:::

---

## Breeze 가져오기 Zip 준비

1. Breeze에서 **설정**으로 이동하고 왼쪽 사이드바에서 **내보내기**를 클릭합니다.
2. 3개의 별도 파일을 내보냅니다: **사람**, **태그** 및 **기여**.
3. 3개 파일을 모두 선택하고 마우스 오른쪽 버튼을 클릭한 후 단일 zip 파일로 압축합니다.
   - Mac의 경우: 파일을 선택하고 마우스 오른쪽 버튼을 클릭한 후 **압축**을 선택합니다.
   - PC의 경우: 파일을 선택하고 마우스 오른쪽 버튼을 클릭한 후 **다음으로 보내기**를 선택한 후 **압축(zipped) 폴더**를 선택합니다.
4. 1단계에서 **Breeze 가져오기 Zip** 옵션을 사용하여 zip 파일을 업로드합니다.

Breeze 가져오기는 사람, 그룹(태그) 및 기부 기록을 자동으로 전송합니다.

---

## Planning Center 내보내기 준비

1. Planning Center에서 사람 데이터를 CSV 또는 zip 파일로 내보냅니다.
2. 1단계에서 **Planning Center Zip** 옵션을 사용하여 업로드합니다.

---

## Tithe.ly 내보내기 준비

1. Tithe.ly에서 **사람** 데이터를 CSV 또는 Excel 파일로 내보냅니다. 기부 기록을 가져오려는 경우 별도의 **기부** 파일을 내보낼 수도 있습니다.
2. 도구는 열 이름을 기반으로 파일에 사람 또는 기부 데이터가 포함되어 있는지 자동으로 감지합니다.
3. 1단계에서 **Tithe.ly CSV** 옵션을 사용하여 파일을 업로드합니다.

:::info
Tithe.ly 내보내기는 한 번에 하나의 파일로 가져올 수 있습니다. 사람과 기부 기록을 모두 가져와야 하는 경우 프로세스를 두 번 실행합니다.
:::

---

## CCB 또는 Pushpay 내보내기 준비

1. Church Community Builder 또는 Pushpay에서 **사람** 데이터를 CSV 파일로 내보냅니다. 별도의 기부/기여 파일을 내보낼 수도 있습니다.
2. 도구는 열 이름을 기반으로 파일에 사람 또는 기부 데이터가 포함되어 있는지 자동으로 감지합니다.
3. 1단계에서 **CCB / Pushpay CSV** 옵션을 사용하여 파일을 업로드합니다.

---

## 가져오기 후

전송이 완료되면 시간을 내어 데이터를 확인하세요:

1. [사람](../people/adding-people.md) 페이지를 열어보고 몇 개의 프로필을 샘플링합니다.
2. 이름, 이메일, 전화 번호 및 주소가 올바르게 전송되었는지 확인합니다.
3. 가계 연결이 그대로 유지되는지 확인합니다.
4. 가져온 그룹 및 기부 기록을 검토합니다.

문제를 발견하면 사람 페이지에서 개별 프로필을 편집할 수 있습니다. [데이터 내보내기](exporting-data.md)를 위해 다시 전송 도구를 실행하여 데이터의 백업을 만들 수도 있습니다.
