# 데이터 가져오기
<div class="article-intro">
B1 Transfer 도구를 사용하면 기존 데이터를 B1로 쉽게 가져올 수 있습니다. 스프레드시트에서 시작하거나 다른 교회 관리 플랫폼에서 마이그레이션하거나 기부금 기록을 가져올 수 있습니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- B1 Admin 계정이 필요합니다
- 기존 시스템에서 데이터를 내보낼 준비가 되어 있어야 합니다
</div>
## 전송 도구 접근
1. **B1 Admin**에 로그인합니다
2. **섹션 메뉴**를 열고 **설정**을 선택합니다
3. **가져오기/내보내기** 버튼을 클릭합니다
4. **B1 Transfer** 도구가 새 탭에서 열립니다
## 다음 단계
- [B1 Transfer](https://transfer.b1.church)를 방문합니다
