# 데이터 가져오기

<div class="article-intro">

B1 전송 도구는 기존 데이터를 B1로 가져오기를 쉽게 만듭니다. 스프레드시트에서 처음부터 시작하든, 다른 교회 관리 플랫폼에서 마이그레이션하든, 기부 기록을 가져오든 간에. 또한 언제든지 데이터를 내보내거나 백업하는 데 사용할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- **설정**에 접근할 수 있는 활성 B1 Admin 계정이 필요합니다.
- 시작하기 전에 이전 시스템에서 데이터를 내보내고 준비해둡니다.
- 이 도구는 초기 데이터 마이그레이션을 위한 것입니다. B1을 이미 한동안 사용 중이었다면, 다시 가져오기를 하면 중복 기록이 생길 수 있습니다.

</div>

## 전송 도구 접근하기

1. **B1 Admin**에 로그인합니다.
2. 왼쪽 상단의 **섹션 메뉴**(섹션 이름과 작은 화살표)를 열고 **설정**을 선택합니다.
3. 페이지 헤더의 오른쪽 상단에서 **가져오기/내보내기** 버튼을 클릭합니다.
4. 이것은 **B1 전송** 도구를 새 탭으로 [transfer.b1.church](https://transfer.b1.church)에서 엽니다.

전송 도구는 네 단계를 거칩니다: 소스, 미리보기, 대상 및 실행.

---

## 단계 1 - 소스 선택

데이터가 어디에서 오는지 선택합니다. 일곱 가지 옵션이 있습니다:

- **B1 데이터베이스** — 기존 B1 교회에서 직접 데이터를 가져옵니다. 백업을 만들거나 데이터를 다른 형식으로 변환할 때 유용합니다. 이 옵션을 사용하려면 로그인해야 합니다.
- **B1 가져오기 Zip** — B1의 자체 형식의 zip 파일. 이는 주로 이전 B1 내보내기를 복원하는 데 사용됩니다.
- **Breeze 가져오기 Zip** — Breeze ChMS에서 내보낸 파일이 포함된 zip 파일.
- **Planning Center Zip** — Planning Center에서 내보낸 zip 또는 CSV 파일.
- **사용자 정의 CSV / Excel** — 사람 데이터를 포함하는 모든 CSV 또는 Excel 파일. 업로드 후, 가져오기를 진행하기 전에 열을 B1 필드로 매핑합니다.
- **Tithe.ly CSV** — Tithe.ly의 사람 또는 기부 내보내기 파일(CSV 또는 Excel 형식 허용).
- **CCB / Pushpay CSV** — Church Community Builder 또는 Pushpay의 사람 또는 기부 내보내기 CSV.

파일을 업로드 영역으로 끌어다놓거나, 클릭하여 찾아볼 수 있습니다.

---

## 단계 1b - 필드 매핑(사용자 정의 CSV / Excel만)

**사용자 정의 CSV / Excel**을 선택한 경우, 파일을 업로드한 후 미리보기로 이동하기 전에 필드 매핑 화면이 표시됩니다.

파일의 각 열은 샘플 값과 함께 나열됩니다. 각 열에 대해, 드롭다운을 사용하여 일치하는 B1 필드를 선택합니다. 도구는 "이름", "이메일" 또는 "우편번호" 같은 일반적인 열 이름을 자동 감지하지만, 모든 행을 검토하고 놓친 것을 수정해야 합니다.

사용 가능한 B1 필드는 다음을 포함합니다:

- 이름, 성, 중간 이름, 별명, 표시 이름, 직책/접두사, 접미사
- 이메일, 집 전화, 휴대 전화, 직장 전화
- 주소 1번 줄, 주소 2번 줄, 도시, 주, 우편번호
- 생일, 기념일, 성별, 결혼 상태, 멤버십 상태
- 가족/가족 이름
- 그룹 이름 — 사람을 그룹 이름으로 지정
- **사용자 정의 필드(이름으로 일치)** — 열을 교회의 [사용자 정의 사람 필드](../settings/custom-fields.md) 중 하나에 저장합니다. **B1 필드 이름** 상자가 나타나고 열 헤더로 채워집니다. B1에 표시되는 대로 정확히 필드의 이름으로 변경합니다(대소문자는 중요하지 않음).
- **양식 답변(사용자 정의 필드)** — 그 열의 값을 사람의 기록에 첨부된 사용자 정의 필드로 저장합니다. 이 옵션을 사용하면, 양식의 이름을 지정하도록 요청됩니다.

날짜는 `9/17/1994` 같은 일반적인 형식으로 되어 있으며 자동으로 변환됩니다. 사용자 정의 필드의 경우, 예/아니오 필드는 예, 아니오, Y, N, 참, 거짓, 1 및 0 같은 값을 허용하고, 다중선택 필드는 선택 텍스트 또는 그 값을 허용합니다.

:::info
가져오기 전에 B1 Admin에서 사용자 정의 사람 필드를 만듭니다. 가져오기가 끝나면, **사용자 정의 필드** 단계는 B1 필드와 일치하지 않는 열 이름을 나열하고 필드의 유형에 맞지 않는 값을 계산합니다. 이 값들은 건너뛰어지고, 나머지 가져오기는 여전히 완료됩니다.
:::

가져오지 않으려는 열은 **(건너뛰기)**로 설정할 수 있습니다. 계속하기 전에 최소 하나의 이름 필드(이름 또는 성)가 매핑되어야 합니다.

**매핑 확인 & 가져오기**를 클릭하여 미리보기로 진행합니다.

---

## 단계 2 - 데이터 미리보기

업로드 후, 도구는 가져올 모든 것의 미리보기를 표시합니다. 탭을 사용하여 각 데이터 유형을 검토합니다:

- **사람** — 가족별로 나열되고, 포함된 경우 사진.
- **그룹** — 캠퍼스, 서비스, 시간 및 카테고리별로 구성.
- **출석** — 세션 날짜, 그룹 및 방문 수.
- **기부** — 배치, 기금, 기부자 및 금액.
- **양식** — 양식 이름 및 콘텐츠 유형.

진행하기 전에 이것을 주의 깊게 검토합니다. 뭔가 잘못되었으면, **처음부터 시작**을 클릭하고 소스 파일을 수정합니다.

---

## 단계 3 - 대상 선택

데이터가 어디로 가는지 선택합니다:

- **B1 데이터베이스** — 교회의 B1 데이터베이스로 직접 가져옵니다. 이를 선택한 후, 도구는 추가될 기록의 최종 수를 표시합니다. **전송 시작**을 클릭하여 확인합니다.
- **B1 내보내기 Zip** — 데이터를 B1 형식의 zip 파일로 다운로드합니다. 백업에 좋습니다.
- **Breeze 내보내기 Zip** — 데이터를 Breeze 형식으로 변환합니다.
- **Planning Center Zip** — 데이터를 Planning Center 형식으로 변환합니다.

:::warning
소스와 대상은 같은 형식이 될 수 없습니다. 일치하면, 도구는 실수로 중복을 방지하기 위해 경고합니다.
:::

---

## 단계 4 - 실행

도구는 전송을 처리하고 각 단계에 대한 진행률을 표시합니다:

- 캠퍼스, 서비스 및 시간
- 사람
- 사진
- 그룹 및 그룹 멤버
- 기부
- 출석
- 양식, 질문, 답변 및 양식 제출
- 사용자 정의 필드(사용자 정의 필드 열을 매핑한 경우)
- 압축 중(zip 파일 대상의 경우만)

:::warning
전송이 실행되는 동안 브라우저를 닫지 마십시오. 모든 단계가 완료로 표시될 때까지 대기합니다.
:::

---

## Breeze 가져오기 Zip 준비

1. Breeze에서, **설정**으로 이동하고 왼쪽 사이드바에서 **내보내기**를 클릭합니다.
2. 세 개의 개별 파일을 내보냅니다: **사람**, **태그** 및 **기부**.
3. 세 개의 파일 모두를 선택하고, 마우스 오른쪽 버튼을 클릭하고, 단일 zip 파일로 압축합니다.
   - Mac: 파일을 선택하고, 마우스 오른쪽 버튼을 클릭하고, **압축**을 선택합니다.
   - PC: 파일을 선택하고, 마우스 오른쪽 버튼을 클릭하고, **보내기**를 선택한 후 **압축(지퍼) 폴더**를 선택합니다.
4. 단계 1의 **Breeze 가져오기 Zip** 옵션을 사용하여 zip 파일을 업로드합니다.

Breeze 가져오기는 자동으로 사람, 그룹(태그) 및 기부 기록을 전송합니다.

---

## Planning Center 내보내기 준비

1. Planning Center에 로그인하고 **사람** 제품을 엽니다.
2. 왼쪽 사이드바에서, **목록**을 클릭하고 가져오려는 모든 사람을 포함하는 목록을 만듭니다. (이미 전체 회중 목록이 있으면, 그것을 사용합니다.)
3. 목록을 열고 **내보내기** 옵션을 사용하여 **CSV** 파일로 사람을 다운로드합니다. 유지하려는 필드를 포함합니다 — 이름, 이메일, 전화, 주소, 생일, 성별 및 멤버십 상태는 모두 B1으로 매핑됩니다.
4. Planning Center가 하나 이상의 파일을 제공하면, 모두 선택하고, 마우스 오른쪽 버튼을 클릭하고, 단일 zip으로 압축합니다.
   - Mac: 파일을 선택하고, 마우스 오른쪽 버튼을 클릭하고, **압축**을 선택합니다.
   - PC: 파일을 선택하고, 마우스 오른쪽 버튼을 클릭하고, **보내기**를 선택한 후 **압축(지퍼) 폴더**를 선택합니다.
5. 단계 1의 **Planning Center Zip** 옵션을 사용하여 CSV 또는 zip을 업로드합니다.

업로드 후, 미리보기로 계속하고 가져오기를 실행하기 전에 사람 및 가족이 올바른지 확인합니다.

---

## Tithe.ly 내보내기 준비

1. Tithe.ly에서, **사람** 데이터를 CSV 또는 Excel 파일로 내보냅니다. 기부 기록을 가져오려면 별도의 **기부** 파일을 내보낼 수도 있습니다.
2. 도구는 열 이름에 따라 파일이 사람 데이터를 포함하는지 기부 데이터를 포함하는지 자동으로 감지합니다.
3. 단계 1의 **Tithe.ly CSV** 옵션을 사용하여 파일을 업로드합니다.

:::info
Tithe.ly 내보내기는 한 번에 하나의 파일씩 가져올 수 있습니다. 사람 및 기부 기록을 모두 가져오려면 프로세스를 두 번 실행합니다.
:::

---

## CCB 또는 Pushpay 내보내기 준비

1. Church Community Builder 또는 Pushpay에서, **사람** 데이터를 CSV 파일로 내보냅니다. 별도의 기부/기여 파일을 내보낼 수도 있습니다.
2. 도구는 열 이름에 따라 파일이 사람 데이터를 포함하는지 기부 데이터를 포함하는지 자동으로 감지합니다.
3. 단계 1의 **CCB / Pushpay CSV** 옵션을 사용하여 파일을 업로드합니다.

---

## 가져온 후

전송이 완료되면, 몇 분이 걸립니다 데이터를 검증합니다:

1. [사람](../people/adding-people.md) 페이지를 탐색하고 몇 개의 프로필을 현장 점검합니다.
2. 이름, 이메일, 전화번호 및 주소가 올바르게 전달되었는지 확인합니다.
3. 가족 연결이 그대로 유지되었는지 확인합니다.
4. 가져온 그룹 및 기부 기록을 검토합니다.

문제를 발견하면, 사람 페이지에서 개별 프로필을 편집할 수 있습니다. 또한 전송 도구를 다시 실행하여 [데이터를 내보낼](exporting-data.md) 수 있습니다.
