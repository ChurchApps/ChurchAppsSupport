# 데이터 내보내기

<div class="article-intro">

B1 Admin에서는 교회 데이터를 내보내서 스프레드시트에서 사용하거나, 팀과 공유하거나, 백업용으로 보관할 수 있습니다. 이름과 이메일의 간단한 목록이 필요하든 전체 데이터베이스 내보내기가 필요하든, 필요에 맞는 옵션이 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 내보낼 데이터를 볼 수 있는 권한이 있는 활성 B1 Admin 계정이 필요합니다. 접근 수준이 확실하지 않다면 [역할 및 권한](roles-permissions.md)을 참조하세요.
- 전체 데이터베이스를 내보내려면 **Settings** 영역에 접근할 수 있어야 합니다.

</div>

## People 페이지에서 내보내기

디렉토리를 내보내는 가장 빠른 방법은 **People** 페이지에서 직접 하는 것입니다.

1. [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 상단의 검색창)를 열고 **People**을 펼친 다음 **People**을 클릭합니다.
2. 검색창이나 필터를 사용하여 내보낼 결과를 좁힙니다(전체를 내보내려면 필터 없이 둡니다). 필터링 팁은 [사람 검색하기](searching-people.md)를 참조하세요.
3. People 페이지 헤더의 **Export** 버튼을 클릭합니다.
4. 현재 결과에 있는 사람들의 이름, 연락처 정보, 주소 및 기타 표준 필드가 포함된 CSV 파일이 컴퓨터에 다운로드됩니다.

:::tip
내보내기에는 현재 결과에 있는 모든 사람이 포함됩니다. 필요한 사람만 내보내려면 먼저 검색을 실행하거나, [저장된 목록](./lists.md)을 불러오거나, **Advanced** 검색을 사용하세요.
:::

## 설정에서 전체 데이터 내보내기

B1 데이터 전체(사람만이 아님)를 내보내려면 설정의 내보내기 도구를 사용합니다.

1. Jump 메뉴에서 **Settings > Settings**를 선택합니다.
2. 왼쪽 설정 메뉴 상단의 교회 이름 아래에 있는 **Import/Export** 링크를 클릭합니다.
3. **Data Source** 드롭다운에서 **B1 Database**를 선택합니다.
4. 데이터 미리보기를 검토한 다음 **Continue to Destination**을 클릭합니다.
5. 내보내기 대상으로 **B1 Export Zip**을 선택합니다.
6. 모든 항목에 녹색 체크 표시가 나타날 때까지 내보내기 진행 상황을 확인합니다.
7. 내보내기 파일이 자동으로 다운로드됩니다. 다운로드 폴더에서 `B1Export` 파일을 찾으세요.
8. 파일의 압축을 풀면 Excel, Google Sheets 또는 Numbers에서 열 수 있는 개별 CSV 파일(예: `people.csv`)에 접근할 수 있습니다.

:::info
B1 Export Zip은 교회 데이터의 전체 백업입니다. 다음이 포함됩니다.

- 사진이 포함된 사람과 가구(가구 픽업 연락처 포함)
- 캠퍼스, 서비스, 서비스 시간
- 그룹과 그룹 회원
- 기금과 헌금(여러 기금에 나뉜 헌금 포함)
- 출석
- 양식, 질문, 제출 내용, 답변
- 맞춤 필드와 그 값
- 저장된 사람 목록

복원하려면 원본으로 **B1 Import Zip**을, 대상으로 **B1 Database**를 선택합니다([데이터 가져오기](./importing-data.md) 참조). 가구, 픽업 연락처, 저장된 목록은 사람과 함께 다시 만들어집니다. 저장된 목록의 필터는 복원된 그룹, 기금, 캠퍼스, 맞춤 필드를 가리키도록 설정됩니다.
:::

## 그룹 데이터 내보내기

개별 그룹의 회원 목록도 내보낼 수 있습니다. **Groups** 페이지에서 그룹을 열고 **다운로드 아이콘**을 클릭하면 그 그룹의 회원 목록을 내보낼 수 있습니다. 자세한 내용은 [그룹 회원](../groups/group-members.md)을 참조하세요.

:::info
내보낸 CSV 파일은 Microsoft Excel, Google Sheets, Apple Numbers를 포함한 주요 스프레드시트 프로그램에서 모두 사용할 수 있습니다.
:::
