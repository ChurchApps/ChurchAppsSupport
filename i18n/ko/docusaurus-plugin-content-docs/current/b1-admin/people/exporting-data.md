# 데이터 내보내기

<div class="article-intro">

B1 Admin을 통해 교회 데이터를 내보낼 수 있으므로 스프레드시트에서 사용하거나, 팀과 공유하거나, 백업을 유지할 수 있습니다. 빠른 이름 및 이메일 목록이 필요하거나 완전한 데이터베이스 내보내기가 필요하든 필요에 맞는 옵션이 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 내보내려는 데이터를 볼 권한이 있는 활성 B1 Admin 계정이 필요합니다. 액세스 수준이 확실하지 않으면 [역할 및 권한](roles-permissions.md) 참조하세요.
- 전체 데이터베이스 내보내기의 경우 **설정** 영역에 액세스해야 합니다.

</div>

## 사람 페이지에서 내보내기

디렉토리를 내보내는 가장 빠른 방법은 **사람** 페이지에서 직접 내보내기입니다:

1. 왼쪽 위 모서리의 **섹션 메뉴**를 열고 **사람**을 선택합니다.
2. 검색 표시줄 또는 필터를 사용하여 내보내려는 결과를 좁힙니다(또는 필터링하지 않으면 모두 내보냅니다). 필터링 팁은 [사람 검색](searching-people.md) 참조.
3. **열 선택기**를 사용하여 내보내기에 포함할 열을 선택합니다(예: 이름, 이메일, 휴대폰, 주소).
4. **내보내기** 버튼을 클릭합니다.
5. CSV 파일이 현재 테이블에 표시된 데이터와 함께 컴퓨터로 다운로드됩니다.

:::tip
내보내기 전에 열을 사용자 정의합니다. CSV 파일은 표시하는 정확한 열을 포함하므로 나중에 파일을 편집하지 않고도 필요에 맞게 내보내기를 조정할 수 있습니다.
:::

## 설정에서 전체 데이터 내보내기

B1 데이터 전체(사람뿐만 아니라)를 완전히 내보내려면 설정의 내보내기 도구를 사용합니다:

1. 왼쪽 위 모서리의 **섹션 메뉴**를 열고 **설정**을 선택합니다.
2. 상단 탐색에서 **가져오기/내보내기**를 클릭합니다.
3. **데이터 원본** 드롭다운에서 **B1 데이터베이스**를 선택합니다.
4. 데이터 미리보기를 검토하고 **대상으로 계속**을 클릭합니다.
5. 내보내기 대상으로 **B1 내보내기 Zip**을 선택합니다.
6. 모든 항목이 녹색 확인 표시를 표시할 때까지 내보내기 진행 상황을 모니터링합니다.
7. 내보내기 파일이 자동으로 다운로드됩니다. 다운로드 폴더에서 `B1Export` 파일을 찾으세요.
8. 파일의 압축을 풀어 Excel, Google Sheets 또는 Numbers에서 열 수 있는 개별 CSV 파일(예: `people.csv`)에 액세스합니다.

:::info
전체 데이터 내보내기에는 사람, 그룹, 기부, 출석 등이 포함됩니다. B1 데이터베이스의 모든 항목입니다. 이는 또한 교회 기록의 정기적인 백업을 만드는 좋은 방법입니다.
:::

## 그룹 데이터 내보내기

개별 그룹의 회원 목록을 내보낼 수도 있습니다. **그룹** 페이지에서 그룹을 열고 **다운로드 아이콘**을 클릭하여 해당 그룹의 회원 목록을 내보냅니다. 자세한 내용은 [그룹 회원](../groups/group-members.md) 참조.

:::info
내보낸 CSV 파일은 Microsoft Excel, Google Sheets 및 Apple Numbers를 포함한 모든 주요 스프레드시트 애플리케이션과 함께 작동합니다.
:::
