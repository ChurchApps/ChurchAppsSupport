# 데이터 내보내기

<div class="article-intro">

B1 Admin을 사용하면 교회 데이터를 내보낼 수 있으므로 스프레드시트에서 사용하거나, 팀과 공유하거나, 백업을 유지할 수 있습니다. 이름과 이메일의 빠른 목록이 필요하든 완전한 데이터베이스 내보내기가 필요하든 필요에 맞는 옵션이 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 내보내려는 데이터를 볼 수 있는 권한이 있는 활성 B1 Admin 계정이 필요합니다. 액세스 수준이 확실하지 않은 경우 [역할 및 권한](roles-permissions.md)을 참조하세요.
- 전체 데이터베이스 내보내기의 경우 **설정** 영역에 액세스해야 합니다.

</div>

## 사람 페이지에서 내보내기

디렉토리를 내보내는 가장 빠른 방법은 **사람** 페이지에서 직접 내보내기입니다:

1. [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu) (B1 Admin의 왼쪽 상단의 검색창)를 열고, **사람**을 확장한 후 **사람**을 클릭합니다.
2. 검색창이나 필터를 사용하여 내보내려는 결과를 좁히거나 (또는 필터링하지 않은 상태로 두어 모두 내보내기). 필터링 팁은 [사람 검색](searching-people.md)을 참조하세요.
3. 사람 페이지 헤더의 **내보내기** 버튼을 클릭합니다.
4. 현재 결과의 사람들(이름, 연락처 정보, 주소 및 기타 표준 필드 포함)이 포함된 CSV 파일이 컴퓨터로 다운로드됩니다.

:::tip
내보내기에는 현재 결과의 모든 사람이 포함됩니다. 먼저 검색을 실행하거나, [저장된 목록](./lists.md)을 불러오거나, **고급** 검색을 사용하여 필요한 사람만 내보내세요.
:::

## 설정에서 전체 데이터 내보내기

B1 데이터 전체 (사람뿐만 아니라)를 완전히 내보내려면 설정의 내보내기 도구를 사용합니다:

1. Jump 메뉴에서 **설정 > 설정**을 선택합니다.
2. 왼쪽 설정 메뉴의 교회 이름 아래에 있는 **가져오기/내보내기** 링크를 클릭합니다.
3. **데이터 소스** 드롭다운에서 **B1 데이터베이스**를 선택합니다.
4. 데이터 미리보기를 검토하고 **대상으로 계속**을 클릭합니다.
5. 내보내기 대상으로 **B1 내보내기 Zip**을 선택합니다.
6. 모든 항목이 녹색 확인 표시를 표시할 때까지 내보내기 진행을 모니터링합니다.
7. 내보내기 파일이 자동으로 다운로드됩니다. 다운로드 폴더에서 `B1Export` 파일을 찾으세요.
8. 파일의 압축을 풀어 Excel, Google Sheets 또는 Numbers에서 열 수 있는 개별 CSV 파일 (예: `people.csv`)에 액세스합니다.

:::info
전체 데이터 내보내기에는 사람, 그룹, 기부금, 참석 등이 포함됩니다 -- B1 데이터베이스의 모든 항목입니다. 이는 또한 교회 기록의 정기적 백업을 만드는 좋은 방법입니다.
:::

## 그룹 데이터 내보내기

개별 그룹의 회원 목록을 내보낼 수도 있습니다. **그룹** 페이지에서 그룹을 열고 **다운로드 아이콘**을 클릭하여 해당 그룹의 회원 목록을 내보냅니다. 자세한 내용은 [그룹 회원](../groups/group-members.md)을 참조하세요.

:::info
내보낸 CSV 파일은 Microsoft Excel, Google Sheets 및 Apple Numbers를 포함한 모든 주요 스프레드시트 애플리케이션과 함께 작동합니다.
:::
