# 캠페인 및 서약

<div class="article-intro">

캠페인을 통해 특정 목표를 향한 기금 모금 활동을 진행할 수 있습니다 — 건물 기금, 선교 여행, 특별 프로젝트 — 그리고 실제 기부와 함께 구성원의 서약을 추적하여 실시간 진행 상황을 볼 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [기부 기금](funds) 설정 — 각 캠페인이 기금에 연결됩니다
- B1 Admin의 기부 섹션에 액세스 필요

</div>

## 캠페인 열기

B1 Admin에서 왼쪽 상단의 **섹션 메뉴**(섹션 이름과 작은 화살표)를 열고 **기부**를 선택한 후 **캠페인**을 선택합니다. 각 캠페인의 목표 금액, 총 서약 및 지금까지의 총 기부를 포함한 모든 캠페인 목록을 볼 수 있습니다.

## 캠페인 생성

1. **캠페인 추가**를 클릭합니다.
2. 캠페인 세부 정보를 입력합니다:
   - **이름** *(필수)* — 이 캠페인의 표시 이름(예: "건물 기금 2026").
   - **기금** — 이 캠페인과 관련된 기부 기금입니다.
   - **시작 날짜** / **종료 날짜** — 기금 모금 기간입니다.
   - **목표** — 캠페인의 목표 금액입니다.
3. **저장**을 클릭합니다.

## 진행 상황 추적

각 캠페인 카드는 다음을 표시합니다:

- **목표** — 목표 금액
- **서약됨** — 구성원이 기부하기로 서약한 총액
- **기부됨** — 캠페인 기간 동안 이 캠페인의 기금에 실제로 기부된 총액
- **진행 표시줄** — 목표를 향해 얼마나 진행했는지 표시

캠페인을 클릭하여 상세 보기를 열면 개별 서약 및 이행 상태가 나열됩니다.

## 서약 추가

서약은 캠페인에 기부하기로 구성원이 약속하는 것입니다. 서약을 기록하려면:

1. 캠페인을 엽니다.
2. **서약 추가**를 클릭합니다.
3. 서약하는 **사람**을 선택합니다.
4. 서약 **금액**을 입력합니다.
5. 선택적으로 서약 약속의 **날짜**를 설정합니다.
6. **저장**을 클릭합니다.

서약은 캠페인 세부 정보에 나타나고 캠페인 카드의 **서약됨** 총액에 기여합니다.

:::tip
서약은 실제 기부와 별개입니다. 서약은 약속을 추적합니다. 기부는 실제 선물을 기록합니다. 캠페인에서 둘 다 표시되므로 서약이 얼마나 잘 이행되는지 볼 수 있습니다.
:::

## 캠페인 편집 또는 삭제

캠페인 카드의 편집 아이콘을 클릭하여 이름, 목표, 날짜 또는 기금을 업데이트합니다. **삭제**를 클릭하여 캠페인과 서약을 영구적으로 제거합니다. 캠페인을 삭제해도 기금에 기록된 기부는 삭제되지 않습니다.
