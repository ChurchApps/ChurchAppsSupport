# 캠페인 및 서약

<div class="article-intro">

캠페인을 사용하면 특정 목표(건설 기금, 선교 여행, 특별 프로젝트)를 향한 기금 모금 드라이브를 실행하고 회원의 서약을 실제 기부와 함께 추적하여 실시간 진행 상황을 볼 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [기부 기금](funds)을 설정하세요 -- 각 캠페인은 기금과 연결됩니다
- B1 Admin의 기부 섹션에 액세스해야 합니다

</div>

## 캠페인 열기

B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **기부**를 확장한 후 **캠페인**을 클릭합니다. 목표 금액, 총 서약 금액 및 지금까지 기부한 금액과 함께 모든 캠페인의 목록이 표시됩니다.

## 캠페인 생성하기

1. **캠페인 추가**를 클릭합니다.
2. 캠페인 상세를 입력합니다:
   - **이름** *(필수)* -- 이 캠페인의 표시 이름(예: "건설 기금 2026").
   - **기금** -- 이 캠페인과 연결된 기부 기금입니다.
   - **시작 날짜** / **종료 날짜** -- 기금 모금 기간입니다.
   - **목표** -- 캠페인의 목표 금액입니다.
3. **저장**을 클릭합니다.

## 진행 상황 추적하기

각 캠페인 카드에는 다음이 표시됩니다:

- **목표** -- 목표 금액
- **약속** -- 회원이 기부하기로 약속한 총 금액
- **기부됨** -- 캠페인 기간 중 이 캠페인의 기금에 실제로 기부한 총 금액
- **진행률 표시줄** -- 목표를 향해 얼마나 진행했는지를 보여줍니다

캠페인을 클릭하여 개별 서약과 이행 상태를 나열하는 상세 보기를 엽니다.

## 서약 추가하기

서약은 캠페인을 향해 기부하기로 약속한 회원의 약속입니다. 서약을 기록하려면:

1. 캠페인을 엽니다.
2. **서약 추가**를 클릭합니다.
3. 서약을 할 **사람**을 선택합니다.
4. 서약 **금액**을 입력합니다.
5. 선택 사항으로 서약 약속의 **날짜**를 설정합니다.
6. **저장**을 클릭합니다.

서약이 캠페인 상세에 나타나고 캠페인 카드의 **약속** 합계에 기여합니다.

:::tip
서약은 실제 기부와 별개입니다. 서약은 약속을 추적하고, 기부는 실제 선물을 기록합니다. 둘 다 캠페인에 표시되므로 서약이 얼마나 잘 이행되고 있는지 볼 수 있습니다.
:::

## 캠페인 편집 또는 삭제하기

모든 캠페인 카드의 편집 아이콘을 클릭하여 이름, 목표, 날짜 또는 기금을 업데이트합니다. **삭제**를 클릭하여 캠페인과 서약을 영구적으로 제거합니다. 캠페인을 삭제해도 기금에 기록된 기부는 삭제되지 않습니다.
