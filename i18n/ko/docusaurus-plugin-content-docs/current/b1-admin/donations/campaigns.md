# 캠페인 및 약정

<div class="article-intro">

캠페인을 사용하면 건축 기금, 선교 여행, 특별 프로젝트처럼 특정 목표를 향한 모금 운동을 진행하고, 구성원의 약정을 실제 헌금과 함께 추적하여 실시간 진행 상황을 확인할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [헌금 기금](funds)을 설정하십시오 -- 각 캠페인은 하나의 기금에 연결됩니다
- B1 Admin의 Donations 섹션에 접근할 수 있어야 합니다

</div>

## 캠페인 열기

B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **Donations**를 펼친 뒤 **Campaigns**를 클릭합니다. 모든 캠페인이 기금, 날짜, 목표 금액, 총 약정액, 지금까지 받은 총 헌금과 함께 표로 나타납니다. 표 위의 요약 줄에는 캠페인 수와 약정 및 헌금의 합계 금액이 표시됩니다.

## 캠페인 만들기

1. 페이지 상단의 **Add Campaign**을 클릭합니다.
2. 캠페인 세부 정보를 입력합니다:
   - **Name**(이름) *(필수)* -- 이 캠페인의 표시 이름(예: "Building Fund 2026").
   - **Fund**(기금) -- 이 캠페인과 연결된 헌금 기금.
   - **Start Date**(시작일) / **End Date**(종료일) -- 모금 기간.
   - **Goal**(목표) -- 캠페인의 목표 금액.
3. **Save**를 클릭합니다.

## 진행 상황 추적하기

각 캠페인 행에는 다음이 표시됩니다:

- **Goal**(목표) -- 목표 금액
- **Pledged**(약정액) -- 구성원이 약정한 총액
- **Given**(헌금액) -- 캠페인 기간 동안 이 캠페인의 기금으로 실제 헌금된 총액
- **Progress**(진행률) -- 목표에 얼마나 가까워졌는지 보여주는 막대와 백분율

캠페인 이름을 클릭하면 상세 보기가 열립니다. 목표 달성 백분율을 보여주며, 각 헌금자의 약정액과 헌금액, 상태(**Not Started**(시작 전), **In Progress**(진행 중), **Fulfilled**(이행 완료), **Beyond Pledged**(약정 초과), 약정 없이 헌금한 사람을 위한 **Non-Pledged**(비약정))가 포함된 개별 약정 목록을 보여줍니다. 헌금자는 성, 그다음 이름 순으로 나열됩니다. 열 머리글을 클릭하면 해당 열 기준으로 정렬할 수 있습니다. 상세 보기 상단의 **Export**를 클릭하면 약정 목록을 CSV로 내려받습니다.

## 약정 추가하기

약정은 구성원이 캠페인에 헌금하겠다고 한 약속입니다. 약정을 기록하려면:

1. 캠페인을 엽니다.
2. 페이지 상단의 **Add Pledge**를 클릭합니다.
3. 약정하는 **사람**을 선택합니다.
4. 약정 **금액**을 입력합니다.
5. 필요하면 약정 약속의 **날짜**를 설정합니다.
6. **Save**를 클릭합니다.

약정은 캠페인 상세 보기에 나타나며, 캠페인 목록의 **Pledged** 합계에 반영됩니다. 약정을 변경하려면 해당 행의 **Edit**를 클릭합니다.

:::tip
약정은 실제 헌금과 별개입니다. 약정은 약속을 기록하고, 헌금은 실제 헌금을 기록합니다. 두 가지 모두 캠페인에 표시되므로 약정이 얼마나 이행되고 있는지 확인할 수 있습니다.
:::

## 캠페인 편집 및 삭제하기

캠페인 행의 **Edit**(또는 캠페인 상세 보기 상단의 **Edit Campaign**)을 클릭하여 이름, 목표, 날짜, 기금을 수정합니다. **Delete**를 클릭하면 캠페인과 그 약정이 영구적으로 삭제됩니다. 캠페인을 삭제해도 그 기금에 기록된 헌금은 삭제되지 않습니다.

- [헌금 보고서](donation-reports) -- 기금별 헌금 보고
