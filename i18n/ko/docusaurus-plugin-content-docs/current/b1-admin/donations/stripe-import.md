# Stripe 가져오기

<div class="article-intro">

Stripe로 온라인 헌금을 받는다면, Stripe 가져오기 도구를 사용해 그 거래를 B1 Admin으로 가져올 수 있으므로 모든 헌금 데이터를 한곳에 모을 수 있습니다. 자동으로 동기화되지 않은 거래를 찾아내는 데 특히 유용합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [온라인 헌금 설정](online-giving-setup.md)을 완료해 Stripe 계정을 B1 Admin에 연결하세요. **Stripe Import** 메뉴 항목과 Batches 페이지의 버튼은 교회의 헌금 게이트웨이가 Stripe이고, 헌금을 편집할 수 있는 사람에게만 나타납니다.
- 가져오려는 기간에 Stripe 대시보드에 헌금이 있는지 확인하세요.

</div>

## 작동 방식

가져오기는 두 단계로 진행됩니다. 먼저 무엇이 가져와질지 미리 보고, 그다음 가져오기를 확인합니다. 이렇게 시험 실행(dry run)으로 진행하면 데이터가 만들어지기 전에 모든 내용을 검토할 수 있습니다.

## 거래 가져오기

1. **B1 Admin**에서 **Donations > Stripe Import**로 이동하세요. (**Batches** 페이지 위의 **Import missing Stripe transactions**를 클릭해도 됩니다.)
2. **Stripe Import** 페이지가 열립니다.
3. 가져올 거래의 **날짜 범위**를 고르세요.
4. **Preview**를 클릭해 시험 실행을 하세요.

## 미리 보기 검토

미리 보기에는 Stripe의 각 거래와 상태 표시가 함께 나타납니다.

- **New** -- 아직 가져오지 않은 거래입니다. 계속 진행하면 포함됩니다.
- **Already Imported** -- 이 거래는 B1 Admin에 이미 있으며 건너뜁니다.
- **Skipped** -- 다른 이유(예: 환불 또는 실패한 청구)로 제외된 거래입니다.

맨 위의 요약 섹션에는 각 분류의 거래 총 건수와 관련된 금액이 표시됩니다.

:::info
미리 보기 단계는 어떤 기록도 만들지 않습니다. 실제로 반영하기 전에 무엇이 일어날지 확인하기 위한 읽기 전용 검사입니다.
:::

## 가져오기 완료

1. 미리 보기 결과와 요약 합계를 검토하세요.
2. **Import Missing**을 클릭하면 **New**로 표시된 모든 거래를 가져옵니다.
3. 가져오기가 끝나면 각 거래 옆의 상태 배지가 결과에 맞게 갱신됩니다.

## Stripe 가져오기 사용 팁

- 기록을 최신으로 유지하려면 주간이나 월간으로 정기적으로 가져오세요.
- 거래가 **Already Imported**로 표시되면 B1 Admin에 이미 일치하는 기록이 있다는 뜻이므로 별도 조치가 필요하지 않습니다.
- 특정 거래를 찾고 있다면 날짜 범위 필터로 특정 기간에 집중하세요.

:::tip
가져온 뒤에는 [Batches](batches.md) 페이지를 방문해 가져온 헌금이 올바르게 나타나는지, 그리고 합계가 Stripe 대시보드에서 보이는 것과 일치하는지 확인하세요.
:::
