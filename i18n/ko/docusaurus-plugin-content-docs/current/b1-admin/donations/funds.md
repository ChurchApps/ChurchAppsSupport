# 펀드 관리

<div class="article-intro">

펀드를 사용하면 목적별로 헌금을 분류해서 각 사역 영역별로 얼마나 헌금이 들어오는지 추적할 수 있습니다. 일반 헌금, 건축 헌금, 선교, 청소년 사역 등이 흔히 쓰이는 펀드지만, 필요한 만큼 얼마든지 만들 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin의 **헌금** 섹션에 대한 접근 권한이 필요합니다
- 교회에 필요한 헌금 항목과 각 항목의 세금 공제 대상 여부를 결정하세요

</div>

## 펀드 페이지

**헌금 > 펀드**로 이동하면 모든 펀드의 목록을 볼 수 있습니다. 각 행에는 펀드 이름과 **세금 상태**(세금 공제 대상 또는 비공제 대상)가 표시되며, 이는 해당 펀드로의 헌금이 연말 [헌금 명세서](giving-statements.md)에 표시될지를 결정합니다.

## 새 펀드 만들기

1. 페이지 상단의 **펀드 추가**를 클릭합니다.
2. 펀드 이름을 입력합니다(예: "건축 헌금").
3. 이 펀드로의 헌금이 헌금 명세서에 포함되어야 한다면 **세금 공제 대상** 체크박스를 선택합니다.
4. 펀드를 공개 및 회원용 헌금 양식에 표시하려면 **기부자에게 표시**를 체크된 상태로 두고, 수동으로 기록되는 헌금에는 계속 사용하면서 기부자에게는 펀드를 숨기고 싶다면 체크를 해제하세요.
5. **저장**을 클릭합니다.

새 펀드는 즉시 목록에 나타나며 헌금을 입력할 때 바로 사용할 수 있습니다.

## 펀드 편집 및 삭제

- 펀드를 편집하려면 해당 행의 **편집**을 클릭합니다. 이름을 변경하거나, 세금 공제 대상 설정을 전환하거나, **기부자에게 표시** 설정을 전환해 헌금 양식에서 표시하거나 숨길 수 있습니다.
- 펀드를 삭제하려면 편집 양식을 열고 **삭제**를 클릭합니다.

:::warning
펀드를 삭제해도 이전에 해당 펀드로 지정된 헌금은 삭제되지 않습니다. 해당 헌금 기록은 시스템에 그대로 남지만, 이후 새 헌금에는 그 펀드를 사용할 수 없습니다.
:::

:::info
기부자에게 숨겨진 펀드는 이 목록에서 이름 옆에 **숨김** 배지가 표시됩니다. 숨겨진 펀드도 B1 Admin에서 수동으로 기록하는 헌금에는 계속 사용할 수 있으며, 다만 공개 또는 회원용 헌금 양식에는 옵션으로 나타나지 않습니다.
:::

## 펀드 상세 정보 보기

**펀드 이름**을 클릭하면 상세 페이지가 열립니다. 이 페이지에는 다음이 표시됩니다.

- **요약** -- 페이지 제목 아래의 한 줄로, 헌금 건수, 기부자 수, 총 금액을 보여줍니다
- **날짜 범위 필터** -- **시작 날짜**와 **종료 날짜**를 설정하고 **필터**를 클릭하여 특정 기간으로 결과를 좁힙니다
- **헌금 내역** -- 날짜, 배치, 기부자, 금액을 포함하여 이 펀드로 들어온 헌금 목록입니다. 목록 위의 **내보내기**를 클릭하면 CSV로 다운로드할 수 있습니다.

이 화면은 특정 헌금 캠페인에 대해 보고하거나 모금 목표에 대한 진행 상황을 확인할 때 유용합니다.

## 정렬 및 내보내기

- 열 머리글을 사용해 펀드를 이름순으로 정렬할 수 있습니다.
- 페이지 상단의 **내보내기**를 클릭하면 펀드 목록을 스프레드시트(CSV)로 다운로드할 수 있습니다.

:::tip
[헌금 기록](recording-donations.md)을 시작하기 전에 펀드를 먼저 설정해 두세요. 모든 펀드가 준비되어 있으면 처음부터 헌금이 정확하게 분류됩니다.
:::

## 다음 단계

펀드 설정이 끝나면, 배치 단위로 [헌금을 기록](recording-donations.md)할 때 해당 펀드를 헌금에 지정할 수 있습니다. [헌금 명세서](giving-statements.md)를 생성하기 전에 해당하는 펀드가 세금 공제 대상으로 표시되어 있는지 반드시 확인하세요.
