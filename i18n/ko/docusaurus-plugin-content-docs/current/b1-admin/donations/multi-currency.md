# 다중 통화 지원

<div class="article-intro">

B1의 다중 통화 기능을 사용하면 교회가 여러 통화로 헌금을 받고 추적할 수 있습니다. 해외 구성원, 선교사, 여러 나라에 있는 캠퍼스가 있는 교회에 특히 유용합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 헌금을 관리할 권한이 있어야 합니다. 자세한 내용은 [역할 및 권한](../people/roles-permissions.md)을 참고하세요.
- 다중 통화 거래를 지원하는 Stripe로 [온라인 헌금](./online-giving-setup.md)을 설정하세요. 온라인 헌금이 없는 교회도 직접 입력한 헌금이 기록될 통화는 선택할 수 있습니다.
- 교회의 회계상 다중 통화 처리 요건을 이해해 두세요.

</div>

교회의 통화는 처음에 교회를 등록할 때 입력한 국가의 통화로 시작합니다(예: 케냐에 있는 교회라면 케냐 실링). 아직 저장된 통화가 없을 때 이 통화를 사용합니다. **관리 → 헌금**에서 언제든지 바꿀 수 있습니다. 국가를 인식하지 못하면 미국 달러로 시작합니다.

## 다중 통화 켜기

다중 통화 지원은 이제 B1에서 기본으로 켜져 있습니다. 켜져 있으면 다음과 같습니다:

- 구성원은 온라인으로 헌금할 때 자신의 현지 통화로 낼 수 있습니다.
- 어떤 통화로든 헌금을 직접 기록할 수 있습니다.
- 헌금 보고서는 원래 통화로 금액을 표시합니다.
- 온라인 헌금에 대한 통화 환산은 Stripe가 자동으로 처리합니다.

## 지원되는 통화

시스템은 주요 세계 통화를 모두 지원하며, 여기에는 다음이 포함됩니다:

- **USD** -- 미국 달러
- **EUR** -- 유로
- **GBP** -- 영국 파운드
- **CAD** -- 캐나다 달러
- **AUD** -- 호주 달러
- **MXN** -- 멕시코 페소
- **BRL** -- 브라질 헤알
- **INR** -- 인도 루피
- **CNY** -- 중국 위안
- **JPY** -- 일본 엔
- 그 밖에도 많습니다...

온라인 헌금에서 사용할 수 있는 통화는 Stripe 계정이 지원하는 통화에 따라 달라집니다.

## 여러 통화로 헌금 기록하기

### 온라인 헌금

구성원이 Stripe로 온라인 헌금을 할 때:

1. 결제 시 선호하는 통화를 선택합니다.
2. Stripe가 그 통화로 결제를 처리합니다.
3. 헌금은 원래 통화의 금액 그대로 B1에 기록됩니다.
4. Stripe가 필요한 통화 환산을 자동으로 처리하여 교회 계정의 기본 통화로 바꿉니다.

### 직접 입력

직접 입력한 현금과 수표 헌금은 교회의 통화로 기록됩니다. 이는 **설정 > 헌금**에서 설정한 **통화**입니다([교회 통화 선택하기](./online-giving-setup.md#choosing-your-currency) 참고). 헌금마다 통화를 따로 고를 수 없습니다. **금액** 입력란 끝에는 통화 코드가 표시되어(예: *PHP*), 어떤 통화로 입력하는지 알 수 있습니다.

1. B1 Admin에서 **헌금 > 일괄 처리**로 이동해 해당 일괄 처리를 엽니다.
2. 일괄 처리 페이지 상단의 **헌금 추가**를 클릭합니다.
3. 교회의 통화로 금액을 입력합니다.
4. 나머지 헌금 세부 정보를 입력합니다.
5. **저장**을 클릭합니다.

이미 있는 헌금을 편집하면 처음 기록될 때의 통화가 그대로 유지됩니다.

## 다중 통화 헌금 보기

### 헌금 보고서

헌금 보고서는 금액을 원래 통화로 표시합니다.

- 개별 헌금 기록에는 통화 코드가 표시됩니다(예: "$100.00 USD").
- 합계는 통화별로 계산됩니다.
- 특정 통화로 필터링할 수 있습니다.

### 환산된 합계 {#converted-totals}

B1이 하나로 합쳐진 합계를 보여 주는 곳(헌금 요약의 KPI 카드, 헌금 일괄 처리 합계, 펀드 합계)에서는, 교회의 기본 통화가 아닌 통화로 기록된 헌금을 현재 환율로 교회 통화로 환산합니다. 그래서 서로 다른 통화를 더하지 않고 의미 있는 하나의 숫자로 합계가 나타납니다. 환산이 적용되면 합계 아래에 **현재 환율로 환산됨** 안내가 표시됩니다. 개별 헌금 항목은 여전히 원래 통화로 표시됩니다.

### 헌금 명세서

헌금 명세서를 만들 때:

- 각 헌금은 원래 통화로 표시됩니다.
- 합계는 통화별로 나뉩니다.
- 구성원은 각 통화로 자신이 낸 금액을 정확히 볼 수 있습니다.

## Stripe 연동

온라인 헌금의 경우 다중 통화 거래는 Stripe가 처리합니다.

- **자동 환산** -- Stripe가 통화를 교회 계정의 기본 통화로 환산합니다.
- **환율** -- Stripe는 현재 시장 환율을 사용합니다.
- **수수료** -- 통화 환산에는 Stripe의 추가 수수료가 붙을 수 있습니다.
- **정산 통화** -- 헌금은 교회 계정의 기본 통화로 입금됩니다.

:::info
Stripe 대시보드에서 현재 환율과 다중 통화 거래에 붙는 수수료를 확인하세요.
:::

## 회계 고려 사항

여러 통화를 다룰 때는 다음을 유의하세요:

- **기록 관리** -- 정확한 보고를 위해 헌금의 원래 금액과 통화를 추적하세요.
- **환율** -- Stripe의 환율은 은행의 환율과 다를 수 있습니다.
- **세금 영수증** -- 세금 목적으로 여러 통화의 헌금을 어떻게 보고할지는 회계사와 상의하세요.
- **펀드 배분** -- 통화와 관계없이 헌금을 특정 펀드에 배분할 수 있습니다.

## 권장 사항

- **기본 통화** -- 직접 입력한 헌금과 헌금 합계가 그 통화를 사용하도록 **설정 > 헌금**에서 주된 교회 통화를 설정하세요.
- **명확한 안내** -- 결제 과정에서 헌금자에게 어떤 통화로 헌금하는지 알려 주세요.
- **일관된 보고** -- 합계는 항상 교회 통화로 자동 환산됩니다. 원래 금액을 보고 싶을 때는 헌금별 통화 필터를 사용하세요.
- **정기 대사** -- 환산을 고려해 Stripe 정산금과 헌금 기록을 맞춰 보세요.

## 제한 사항

- 온라인 헌금의 결제 처리를 위한 통화 환산은 Stripe가 담당합니다. 직접 입력한 헌금은 입력한 그대로 기록되며 자동 환산되지 않습니다.
- 과거 보고서와 개별 헌금 항목은 항상 헌금이 기록된 원래 통화로 표시됩니다.
- 합계(KPI 카드, 일괄 처리 합계, 펀드 합계)는 현재 환율을 사용해 교회 통화로 환산됩니다. 이 환율은 자금이 정산되는 시점의 은행 또는 Stripe 환율과 약간 다를 수 있습니다.
