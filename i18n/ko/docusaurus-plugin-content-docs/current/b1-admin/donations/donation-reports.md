# 기부 보고서

<div class="article-intro">

B1 Admin은 교회의 기부 데이터를 보고 분석할 수 있는 여러 방법을 제공합니다. 기부 요약 페이지는 차트와 필터로 시각적 개요를 제공하며, 보고서 섹션은 더 자세한 기부 요약 보고서를 제공합니다. 이 도구를 사용하여 기부 동향을 추적하고, 이사회 회의를 준비하거나, 기록을 조정하세요.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 기부가 [배치로 기록](recording-donations.md)되었거나 [Stripe에서 가져왔는지](stripe-import.md) 확인하세요.
- [기금](funds.md)이 올바르게 설정되어 기부가 올바르게 분류되는지 확인하세요.

</div>

## 기부 대시보드

**기부 대시보드**는 **기부** 섹션을 열 때 처음 나타나는 것입니다. 주요 성과 지표로 기부 활동의 높은 수준의 개요를 제공합니다.

1. 왼쪽 상단의 **섹션 메뉴**를 열고 **기부**를 선택하여 대시보드를 엽니다.
2. 맨 위에 4개의 **KPI 카드**가 기부 지표를 한눈에 표시합니다:
   - **총 기부** -- 선택한 기간의 총 기부 금액입니다.
   - **평균 기부** -- 평균 기부 금액입니다.
   - **고유 기부자** -- 기부한 서로 다른 사람의 수입니다.
   - **총 기부** -- 개별 기부의 총 수입니다.
3. **기간 토글**을 사용하여 **주간**, **월간** 및 **분기별** 보기를 전환합니다.
4. KPI 아래에는 선택한 기간의 기부 동향을 표시하는 차트가 있습니다.
5. **다운로드**를 클릭하여 기부 합계가 있는 CSV 파일을 내보냅니다.

기간 동안의 기부가 둘 이상의 통화로 주어진 경우 KPI 합계가 교회 통화로 변환되고 카드 아래에 **현재 환율로 변환됨** 메모가 나타납니다. 자세한 내용은 [다중 통화 지원](./multi-currency.md#converted-totals)을 참조하세요.

## 기부를 중단한 기부자

대시보드 옆의 **기부를 중단한 기부자** 탭은 한 기간 동안 기부했지만 이후로 기부하지 않은 사람들을 나열합니다. 기본적으로 작년을 올해까지와 비교합니다. 어느 한 날짜 범위를 변경하여 검색을 넓히거나 좁혀서 정렬합니다. 각 행은 사람, 마지막 기부 날짜 및 이전 기간의 합계를 표시하며, **내보내기**는 후속 메일링 또는 전화 목록용 CSV 목록을 다운로드합니다.

## 기부 요약 페이지

**요약** 페이지는 더 자세한 집계 기부 데이터를 제공합니다.

1. 왼쪽 상단의 **섹션 메뉴**를 열고 **기부**를 선택하여 요약 페이지를 엽니다.
2. **날짜 범위 필터**를 사용하여 검토하려는 시간 기간을 선택합니다. 위에 더 빠른 날짜를 설정하고 아래에 더 최근 날짜를 설정합니다.
3. 페이지는 주별 기부 차트를 표시하므로 한눈에 동향을 볼 수 있습니다.
4. **다운로드**를 클릭하여 주어진 총 금액, 주어진 주 및 주어진 기금이 포함된 CSV 파일을 내보냅니다.

:::info
요약 페이지는 집계 기부 데이터를 보여줍니다. 개별 기부자 이름을 포함하지 않습니다. 기부자 수준 세부사항은 [배치](batches.md) 페이지를 사용하세요.
:::

## 기부자 수준 세부사항 보기

기부자, 금액 및 기금 분류:

1. **기부 > 배치**로 이동합니다.
2. **배치 이름**을 클릭하여 엽니다.
3. 배치 세부사항 페이지는 기부자 이름, 금액, 기금, 날짜 및 결제 방법이 있는 각 기부를 나열합니다.
4. **기부자 이름**을 클릭하여 기부 횟수 및 매번 금액의 분류를 확인합니다.
5. **기부 ID**를 클릭하여 해당 개별 기부의 전체 세부사항이 있는 사이드 패널을 엽니다.
6. **다운로드**를 클릭하여 해당 배치의 모든 기부자 및 기부 정보가 있는 CSV를 내보냅니다.

## 기부 요약 보고서

기부 보고서는 기부 섹션에 직접 내장되어 있습니다 -- 요약 페이지가 기부 요약 보고서로 제공됩니다:

1. 왼쪽 상단의 **섹션 메뉴**를 열고 **기부**를 선택하여 요약 페이지를 엽니다.
2. **날짜 범위 필터**를 사용하여 보고하려는 기간을 선택합니다.
3. **다운로드**를 클릭하여 보고서를 CSV 파일로 내보냅니다.

## 데이터 내보내기

여러 위치에서 기부 데이터를 내보낼 수 있습니다:

- **요약 페이지** -- 기금별 주간 기부 합계의 CSV 다운로드
- **배치 세부사항 페이지** -- 기부자 세부사항이 있는 개별 기부의 CSV 다운로드
- **기금 세부사항 페이지** -- 특정 기금에 대한 기부 기록 다운로드

:::tip
연말 보고를 위해 요약 페이지 내보내기를 [기부 명세서](giving-statements.md) 도구와 결합하여 집계 동향과 개별 기부자 명세서를 모두 얻으세요.
:::
