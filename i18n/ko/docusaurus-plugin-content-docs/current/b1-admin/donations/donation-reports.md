# 기부금 보고서
<div class="article-intro">
B1 Admin은 교회의 기부금 데이터를 보고 분석하는 여러 방법을 제공합니다. 기부금 대시보드는 차트와 필터를 통한 고수준의 보기를 제공하며, 보고서 섹션은 더 자세한 기부금 요약 보고서를 제공합니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- 기부금이 [배치로 기록](recording-donations.md)되거나 [Stripe에서 가져오기](stripe-import.md)되어야 합니다
- [펀드](funds.md)가 올바르게 설정되어 있는지 확인합니다
</div>
## 기부금 대시보드
**기부금 대시보드**는 기부 활동의 고수준 보기를 제공합니다.
1. **섹션 메뉴**를 열고 **기부금**을 선택합니다.
2. 위쪽의 4개 **KPI 카드**가 기부금 지표를 표시합니다.
3. **기간 전환**을 사용하여 주, 월, 분기 보기 사이에 전환합니다.
4. 차트는 선택한 기간의 기부금 추세를 표시합니다.
5. **다운로드**를 클릭하여 CSV 파일을 내보냅니다.
