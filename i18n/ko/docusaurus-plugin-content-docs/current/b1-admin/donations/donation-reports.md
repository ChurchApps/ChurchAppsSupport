# 기부 보고

<div class="article-intro">

B1 Admin은 교회의 기부 데이터를 보고 분석할 수 있는 여러 방법을 제공합니다. 기부 **요약** 페이지의 기부 대시보드는 차트와 필터로 시각적 개요를 제공하는 반면, 보고 섹션은 더 자세한 기부 요약 보고를 제공합니다. 이러한 도구를 사용하여 기부 추세를 추적하고, 이사회 회의를 준비하거나, 기록을 조정하세요.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 기부가 [배치에 기록](recording-donations.md)되거나 [Stripe에서 가져오기](stripe-import.md)되었는지 확인하세요
- [기금](funds.md)이 올바르게 설정되어 있는지 확인하여 기부가 올바르게 분류됩니다

</div>

## 기부 대시보드

기부 대시보드는 **요약** 페이지의 **대시보드** 탭이며, **기부** 섹션을 열 때 보는 첫 번째 페이지입니다.

1. [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 상단의 검색 표시줄)를 열고 **기부**를 확장한 후 **요약**을 클릭합니다. **요약** 페이지가 **대시보드** 탭에서 열립니다.
2. 보고서 위의 **주간**, **월간**, **분기별** 토글을 사용하여 기부를 그룹화하는 방식을 선택합니다.
3. **보고서 필터** 패널에서 **시작 날짜**와 **종료 날짜**(기본값은 지난 1년부터 어제까지)를 설정하고 선택 사항으로 **기금**을 선택한 후 **보고서 실행**을 클릭합니다. 페이지가 열릴 때 기본값으로 보고서가 자동으로 실행됩니다.
4. 네 개의 **KPI 카드**에 선택한 범위에 대한 기부 지표가 표시됩니다:
   - **총 기부** -- 기부한 총 금액.
   - **평균 선물** -- 평균 기부 금액.
   - **고유 기부자** -- 기부한 뚜렷한 사람의 수.
   - **총 기부** -- 개별 기부의 총 수.
5. KPI 아래에는 기금별로 분류된 주간, 월간 또는 분기별 기부를 보여주는 막대 차트가 표시됩니다.
6. **다운로드 옵션**을 클릭하고 **요약**을 선택하여 기금별 기간별 합계의 CSV를 내보내거나, 프린터 아이콘을 클릭하여 보고서를 인쇄합니다. 인쇄된 보고서의 맨 위에 교회 이름이 표시됩니다.

기간의 기부가 둘 이상의 통화로 제공된 경우 KPI 합계가 교회 통화로 변환되고 카드 아래에 **현재 환율로 변환됨** 메모가 나타납니다. 자세한 내용은 [다중 통화 지원](./multi-currency.md#converted-totals)을 참조하세요.

:::info
대시보드는 집계된 기부 데이터를 표시합니다. 개별 기부자 이름을 포함하지 않습니다. 기부자 수준 세부 정보는 [배치](batches.md) 페이지를 사용합니다.
:::

## 기부하지 않은 기부자

**대시보드** 탭 옆의 **기부하지 않은 기부자** 탭에는 한 기간 중에 기부했지만 그 이후로는 기부하지 않은 사람이 나열됩니다. 기본값으로 지난 역년과 올해 현재까지 비교합니다. 검색 범위를 넓히거나 좁히려면 날짜 범위를 변경하세요. 각 행에는 사람, 마지막 선물의 날짜 및 이전 기간의 합계가 표시되며, **다운로드 옵션 > 요약**은 후속 메일링 또는 전화 목록용 CSV로 목록을 다운로드합니다.

## 기부자 수준 세부 정보 보기

기부자, 기부 금액 및 기금에 대한 분류:

1. **기부 > 배치**로 이동합니다.
2. **배치 이름**을 클릭하여 엽니다.
3. 배치 상세 페이지에는 각 기부 목록이 기부자 이름, 금액, 기금, 날짜 및 결제 방법과 함께 표시됩니다.
4. **기부자 이름**을 클릭하여 기부 횟수와 각 기부 금액의 분류를 봅니다.
5. **기부 ID**를 클릭하여 개별 기부에 대한 전체 세부 정보가 있는 측면 패널을 엽니다.
6. **다운로드**를 클릭하여 해당 배치의 모든 기부자 및 기부 정보를 포함한 CSV를 내보냅니다.

## 기부 요약 보고

기부 보고는 기부 섹션에 직접 구축됩니다 -- 요약 페이지는 기부 요약 보고로 사용됩니다:

1. Jump 메뉴에서 **기부 > 요약**을 선택합니다.
2. **대시보드** 탭에서 **필터 보고서** 패널의 **시작 날짜**와 **종료 날짜**를 설정하고 **보고서 실행**을 클릭합니다.
3. **다운로드 옵션**을 클릭하고 **요약**을 선택하여 보고서를 CSV 파일로 내보냅니다.

## 데이터 내보내기

여러 위치에서 기부 데이터를 내보낼 수 있습니다:

- **요약 페이지** -- 주간, 월간 또는 분기별 기금별 기부 합계의 CSV 다운로드
- **배치 상세 페이지** -- 기부자 세부 정보가 있는 개별 기부의 CSV 다운로드
- **기금 상세 페이지** -- 특정 기금에 대한 기부 기록 다운로드

:::tip
연말 보고를 위해 요약 페이지 내보내기를 [기부 명세서](giving-statements.md) 도구와 결합하여 집계 추세와 개별 기부자 명세서를 모두 얻으세요.
:::
