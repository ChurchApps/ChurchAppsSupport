# 기부 명세서

<div class="article-intro">

연도 말에 기부자는 기록용 세금 공제 기부의 요약이 필요합니다. B1 Admin을 사용하면 한 번에 모든 기부자에 대한 이 명세서를 쉽게 생성하여 수시간의 수동 작업을 절약할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [기금](funds.md)이 **세금 공제 가능**으로 올바르게 표시되어 있는지 확인하세요 -- 세금 공제 가능 기금으로의 기부만 명세서에 나타납니다.
- 모든 기부가 [기록](recording-donations.md)되었고 온라인 거래가 [Stripe에서 가져와졌는지](stripe-import.md) 확인하세요.

</div>

## 기부 명세서 액세스

1. **B1 Admin**에서 왼쪽 상단의 **섹션 메뉴**를 열고 **기부**를 선택합니다.
2. **명세서**를 클릭합니다.

## 명세서 생성

1. 페이지 위의 드롭다운에서 **연도**를 선택합니다. 현재 연도 또는 이전 5년 중 아무 연도나 선택할 수 있습니다.
2. 페이지는 다음을 포함한 해당 연도의 요약 통계를 표시합니다:
   - **총 기부자** -- 기부한 사람의 수
   - **총 기부** -- 개별 기부 기록의 수
   - **총 금액** -- 모든 기부의 합계 금액

## 명세서 다운로드

기부자에게 명세서를 얻는 두 가지 옵션이 있습니다:

### CSV 파일로 다운로드

**ZIP 다운로드**를 클릭하여 각 기부자의 개별 CSV 파일이 포함된 ZIP 파일을 다운로드합니다. 명세서를 개별적으로 이메일로 보내거나 다른 시스템으로 가져오려면 유용합니다.

### 모든 명세서 인쇄

**모두 인쇄**를 클릭하여 브라우저에서 모든 기부자의 명세서의 인쇄 가능한 보기를 엽니다. 여기서 브라우저의 인쇄 기능을 사용하여 프린터로 보냅니다. 각 명세서는 새 페이지에서 시작하므로 접어서 우송할 준비가 되어 있습니다.

:::tip
1월 초에 기록이 신선할 때 명세서를 실행하세요. 명세서를 생성하기 전에 기금이 세금 공제 가능으로 올바르게 표시되어 있는지 다시 확인하세요 -- 세금 공제 가능 기금으로의 기부만 포함됩니다.
:::

:::info
기부 명세서는 **세금 공제 가능** 설정이 활성화된 기금에 할당된 기부만 포함합니다. 기금이 세금 공제 불가능으로 표시되지 않으면 기부가 명세서에 나타나지 않습니다. 이 설정은 [기금](funds.md) 페이지에서 관리할 수 있습니다.
:::

## 캐나다, 호주 및 뉴질랜드를 위한 영수증 형식

미국 이외의 교회는 명세서를 해당 국가의 공식 영수증 레이아웃으로 전환할 수 있습니다. **설정**으로 이동하고, **기부** 섹션을 열고, **명세서 형식**을 **캐나다**, **호주** 또는 **뉴질랜드**로 설정한 후 나타나는 필드를 채우세요: 등록 번호(CRA 등록 번호, ABN 또는 NZ 자선 등록 번호), 조직의 주소, 영수증에 서명 권한이 있는 사람의 이름 및 캐나다의 경우 영수증이 발급되는 도시입니다.

그러면 명세서는 세금 당국이 예상하는 표현(캐나다의 경우, CRA 참조가 있는 "소득세 목적의 공식 영수증"), 형식 `YEAR-DONORID`의 영수증 번호, 세금 공제 기금만에서 계산된 적격 금액, 공제 불가능 기금에 대한 별도의 줄을 전달합니다. 기부자는 B1.church에서 자신의 명세서를 인쇄할 때 동일한 영수증 블록을 봅니다.
