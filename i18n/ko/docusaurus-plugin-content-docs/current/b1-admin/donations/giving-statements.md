# 기부 명세서

<div class="article-intro">

연말에 기부자는 세금 공제 가능한 기부의 요약이 필요합니다. B1 Admin은 모든 기부자에 대한 이러한 명세서를 한 번에 생성하여 수동 작업 시간을 절약하는 것을 쉽게 만듭니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [기금](funds.md)이 **세금 공제 가능**으로 올바르게 표시되어 있는지 확인하세요 -- 세금 공제 가능 기금에 대한 기부만 명세서에 나타납니다
- 모든 기부가 [기록되었으며](recording-donations.md) 온라인 거래가 [Stripe에서 가져오기](stripe-import.md)되었는지 확인하세요

</div>

## 기부 명세서 액세스하기

1. **B1 Admin**에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **기부**를 확장합니다.
2. **기부 명세서**를 클릭합니다.

## 명세서 생성하기

1. 페이지 상단의 드롭다운에서 **연도**를 선택합니다. 현재 연도 또는 이전 5년 중 하나를 선택할 수 있습니다.
2. 페이지에는 해당 연도의 요약 통계가 표시됩니다:
   - **총 기부자** -- 기부한 사람의 수
   - **총 기부** -- 개별 기부 기록의 수
   - **총 금액** -- 모든 기부의 합계 금액

## 명세서 다운로드하기

기부자에게 명세서를 전달하는 두 가지 옵션이 있습니다:

### CSV 파일로 다운로드하기

**ZIP 다운로드**를 클릭하여 각 기부자에 대한 개별 CSV 파일이 포함된 ZIP 파일을 다운로드합니다. 이는 명세서를 개별적으로 이메일로 보내거나 다른 시스템에 가져오려는 경우에 유용합니다.

### 모든 명세서 인쇄하기

**모두 인쇄**를 클릭하여 브라우저에서 모든 기부자의 명세서를 인쇄 가능한 보기로 엽니다. 거기서 브라우저의 인쇄 기능을 사용하여 프린터로 보냅니다. 각 명세서는 새 페이지에서 시작하므로 접어서 우편으로 보낼 준비가 되었습니다.

:::tip
기록이 신선할 때 1월 초에 명세서를 실행하세요. 명세서를 생성하기 전에 기금이 세금 공제 가능으로 올바르게 표시되어 있는지 확인하세요 -- 세금 공제 가능 기금에 대한 기부만 포함됩니다.
:::

:::info
기부 명세서는 **세금 공제 가능** 설정이 활성화된 기금에 할당된 기부만 포함합니다. 기금이 세금 공제 가능으로 표시되지 않으면 해당 기부는 명세서에 나타나지 않습니다. [기금](funds.md) 페이지에서 이 설정을 관리할 수 있습니다.
:::

## 캐나다, 호주 및 뉴질랜드를 위한 영수증 형식

미국 외의 교회는 명세서를 해당 국가의 공식 영수증 레이아웃으로 전환할 수 있습니다. **설정**으로 가서 **기부** 섹션을 열고 **명세서 형식**을 **캐나다**, **호주** 또는 **뉴질랜드**로 설정한 후 나타나는 필드를 입력합니다: 등록 번호(CRA 등록 번호, ABN 또는 뉴질랜드 자선 등록 번호), 조직의 주소, 영수증에 서명할 권한이 있는 사람의 이름, 캐나다의 경우 영수증이 발급되는 도시입니다.

명세서에는 해당 세금 당국이 예상하는 용어(캐나다의 경우 CRA 참조와 함께 "소득세 목적의 공식 영수증")가 포함되고, YEAR-DONORID 형식의 영수증 번호가 있으며, 세금 공제 가능 기금에서만 계산된 적격 금액, 비공제 가능 기금에 대한 별도 행입니다. 기부자는 B1.church에서 자신의 명세서를 인쇄할 때 동일한 영수증 블록을 봅니다.
