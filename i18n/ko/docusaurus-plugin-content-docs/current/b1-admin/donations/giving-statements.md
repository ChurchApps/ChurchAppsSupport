# 기부금 명세서
<div class="article-intro">
연말에 기부자들은 세금 공제 기부금 요약이 필요합니다. B1 Admin은 모든 기부자를 위해 이 명세서를 한 번에 생성하여 시간을 절약합니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- [펀드](funds.md)가 **세금 공제 대상**으로 올바르게 표시되어야 합니다
- 모든 기부금이 [기록](recording-donations.md)되어야 합니다
</div>
## 명세서 접근
1. **B1 Admin**에서 **섹션 메뉴**를 열고 **기부금**을 선택합니다.
2. **명세서**를 클릭합니다.
## 명세서 생성
1. 위쪽의 드롭다운에서 **연도**를 선택합니다.
2. 페이지는 해당 연도의 요약 통계를 표시합니다.
## 다음 단계
명세서가 필요하기 전에 [기부금 보고서](donation-reports.md) 페이지를 검토하거나 [배치](batches.md)를 확인합니다.
