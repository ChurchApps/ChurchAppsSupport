# 기부 배치

<div class="article-intro">

배치는 더 쉬운 추적 및 조정을 위해 기부를 함께 그룹화합니다. 일반적인 배치는 주일 오헌금이나 특별 행사와 같은 단일 수집을 나타냅니다. 배치를 사용하면 조직을 유지하고 기록이 실제 입금과 일치하는지 확인하기가 간단합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [기금을 설정](funds.md)하여 기부를 기록할 때 사용 가능하도록 하세요
- B1 Admin의 **기부** 섹션에 액세스해야 합니다

</div>

## 배치 페이지

**기부 > 배치**로 이동하면 모든 배치 목록이 표시됩니다. 각 행에는 다음이 표시됩니다:

- **이름** -- 배치에 지정한 레이블
- **날짜** -- 수집 날짜
- **기부** -- 배치의 개별 기부 수
- **합계** -- 합계 금액

상단 헤더에는 배치의 총 수, 모든 배치에 걸친 기부의 총 수 및 전체 금액을 포함한 요약 통계가 표시됩니다.

## 새 배치 생성하기

1. 페이지 상단의 **배치 추가**를 클릭합니다.
2. 설명적인 이름을 입력합니다(예: "주일 오헌금 - 2월 9일").
3. 수집 날짜를 선택합니다.
4. **저장**을 클릭합니다.

새 배치가 목록에 나타나고 기부를 추가할 준비가 됩니다.

## 배치 작업하기

- **기부 보기** -- 배치 이름을 클릭하여 열고 포함된 모든 개별 기부를 봅니다. 여기서 기부를 추가, 편집 또는 제거할 수 있습니다.
- **배치 상세 편집** -- 배치 행의 **편집** 버튼을 클릭하여 이름 또는 날짜를 변경합니다.
- **정렬** -- 열 헤더를 사용하여 배치를 이름 또는 날짜로 정렬합니다.
- **내보내기** -- **내보내기**를 클릭하여 배치 목록을 스프레드시트(CSV)로 다운로드합니다.

## 배치 인쇄하기

배치를 열고 기부 목록 상단의 **인쇄**(프린터) 아이콘을 클릭하여 계산 팀이나 입금 기록용 종이 사본을 인쇄합니다. 인쇄본에는 다음이 포함됩니다:

- 교회 이름, 배치 이름 및 배치 날짜
- 배치의 모든 기부(기부자 이름, 방법, 메모, 날짜 및 금액 포함)(환불된 선물은 취소 선이 그어지고 환불됨으로 표시됨)
- **기금 소계** -- 배치의 각 기금에 주어진 합계
- **배치 합계** -- 전체 배치의 합계 금액

인쇄 아이콘은 배치에 최소 하나의 기부가 있는 경우에만 나타납니다.

### 여러 배치를 한 번에 인쇄하기

특정 기간의 모든 배치(예: 지난달의 모든 입금)를 한 번에 인쇄하려면 **배치** 목록 헤더에서 **내보내기** 옆에 있는 **인쇄**(프린터) 아이콘을 클릭합니다. **배치 인쇄** 페이지가 열리며 **시작 날짜**와 **종료 날짜**의 기본값은 최근 30일입니다. 다른 기간을 선택하려면 두 날짜 중 하나를 변경합니다.

해당 기간(시작 날짜와 종료 날짜 포함)에 날짜가 속한 모든 배치가 날짜순으로 배치당 한 페이지씩, 단일 배치 인쇄본과 같은 레이아웃으로 인쇄됩니다. 기부가 없는 배치는 제외되며, 해당 기간의 어떤 배치에도 기부가 없으면 "이 날짜 범위에 기부가 있는 배치가 없습니다."라고 표시됩니다. **인쇄**를 클릭하면 브라우저의 인쇄 대화상자가 열리고, **닫기**를 클릭하면 배치 목록으로 돌아갑니다.

## 배치를 QuickBooks Online으로 내보내기

배치를 열고 **QuickBooks용으로 내보내기**를 클릭하여 QuickBooks Online이 가져올 수 있는 분개로 배치를 다운로드합니다(**설정 > 데이터 가져오기 > 분개**). 파일에는 배치 합계에 대한 **미입금 기금** 하나의 차변과 각 기금의 이름을 계정 이름으로 사용하여 기금당 하나의 대변이 포함됩니다. QuickBooks는 가져오기 중에 해당 이름을 계정도표에 일치시키도록 요청하므로 기금 이름을 부기기사가 수입 계정의 이름을 지정하는 방식으로 지정하거나 가져오기 시 한 번 매핑합니다.

:::tip
나중에 찾기 쉽도록 배치 이름을 일관되게 지정하세요. 날짜와 수집 유형을 포함하면(예: "일요일 오전 - 2025-02-09") 목록이 증가할 때 조직을 유지합니다.
:::
