# 헌금 배치

<div class="article-intro">

배치(batch)는 헌금을 묶어 추적하고 대조하기 쉽게 해 줍니다. 보통 배치 하나는 주일 헌금이나 특별 행사 헌금처럼 한 번의 헌금 시간을 나타냅니다. 배치를 사용하면 기록을 체계적으로 관리할 수 있고, 장부가 실제 입금 내역과 맞는지 간단히 확인할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 헌금을 기록할 때 쓸 수 있도록 [헌금 기금(fund)을 먼저 설정](funds.md)하세요.
- 배치 페이지를 보려면 **View Donation Summaries**, **Edit Donations**, 또는 **Enter Donations** 권한이 필요합니다([배치를 변경할 수 있는 사람](#who-can-change-a-batch) 참고).

</div>

## 배치 페이지

**Donations > Batches**로 이동하면 배치 목록이 나타납니다. 각 행에는 다음이 표시됩니다.

- **Name** -- 배치에 붙인 이름
- **Date** -- 헌금 시간의 날짜
- **Donations** -- 배치에 포함된 개별 헌금의 수
- **Total** -- 합계 금액
- **Status** -- **Open**(열림) 또는 **Closed**(닫힘)([배치 닫기와 다시 열기](#closing-and-reopening-a-batch) 참고)

목록 위에 있는 연도 버튼으로 특정 연도의 배치만 보거나, **All**을 눌러 모든 배치를 볼 수 있습니다. 한 줄 요약에는 표시된 배치의 개수, 헌금 건수, 합계 금액이 나타납니다.

## 새 배치 만들기

1. 페이지 상단의 **Add Batch**를 클릭합니다.
2. 알아보기 쉬운 이름을 입력합니다(예: "주일 헌금 - 2월 9일").
3. 헌금 날짜를 선택합니다.
4. **Save**를 클릭합니다.

새 배치가 목록에 나타나며, 이제 헌금을 추가할 수 있습니다.

## 배치 작업하기

- **헌금 보기** -- 배치 이름을 클릭하면 그 배치에 포함된 개별 헌금을 볼 수 있습니다. 여기서 헌금을 추가, 수정, 삭제하거나, **Import CSV**를 클릭하여 스프레드시트에서 많은 헌금을 한 번에 가져올 수 있습니다([CSV 파일에서 헌금 가져오기](recording-donations.md#importing-donations-from-a-csv-file) 참고).
- **배치 세부 정보 수정** -- 배치 행의 **Edit** 버튼을 클릭하면 이름이나 날짜를 바꿀 수 있습니다. 배치를 삭제할 수 있는 사람은 **Edit Donations** 권한이 있는 사람뿐입니다.
- **정렬** -- 열 머리글을 사용하면 이름이나 날짜로 배치를 정렬할 수 있습니다.
- **내보내기** -- 페이지 상단의 **Export**를 클릭하면 표시된 배치를 스프레드시트(CSV)로 내려받을 수 있습니다.
- **실패한 이벤트** -- 결제 게이트웨이에서 문제를 보고한 경우, 페이지 상단에 해결되지 않은 이벤트 수가 적힌 **Failed events** 버튼이 나타납니다. 이를 클릭하면 아래 이벤트 목록을 보이거나 숨길 수 있습니다.
- **Stripe에서 가져오기** -- 페이지 상단의 **Import missing Stripe transactions**를 클릭하면 [Stripe 가져오기](stripe-import.md) 도구가 열립니다.

## 배치 닫기와 다시 열기

배치의 헌금을 세고 입금한 뒤에는 배치를 닫아서 닫을 때의 상태 그대로 헌금이 유지되도록 하세요.

1. 배치를 엽니다.
2. 페이지 상단의 **Close Batch**를 클릭합니다.

배치 이름 옆의 상태 표시가 **Open**에서 **Closed**로 바뀌고, 배치 페이지의 **Status** 열에도 **Closed**가 표시되며, 배치 상단에는 배치가 닫혔다는 안내가 나타납니다. 배치가 닫혀 있는 동안 **Enter Donations** 권한이 있는 사람은 배치를 볼 수 있지만, 헌금을 추가, 수정, 삭제하거나 배치의 이름이나 날짜를 바꿀 수는 없습니다.

다시 변경하려면 배치를 열고 **Reopen Batch**를 클릭합니다. 새 배치는 항상 열린 상태로 시작합니다.

:::info
**Edit Donations** 권한이 있는 사람만 **Close Batch**와 **Reopen Batch** 버튼을 볼 수 있습니다. 이들은 수정이 필요할 때 배치를 다시 열지 않고도 닫힌 배치의 헌금을 바꿀 수 있습니다.
:::

## 배치를 변경할 수 있는 사람

[역할 권한](../settings/roles-permissions.md) 중 두 가지가 배치 작업을 가능하게 합니다.

- **Edit Donations** -- 전체 권한입니다. 배치를 추가하고 삭제하며, 닫고 다시 열고, 배치가 열려 있든 닫혀 있든 모든 헌금을 추가, 수정, 삭제할 수 있습니다.
- **Enter Donations** -- 헌금을 세고 기록하는 팀이나 봉사자를 위한 권한입니다. 배치를 추가하고 헌금을 추가, 수정, 삭제할 수 있지만, 배치가 열려 있을 때만 가능합니다. 배치를 삭제하거나 닫고 다시 열 수 없으며, 온라인 헌금으로 들어온 헌금도 바꿀 수 없습니다.

**Enter Donations**는 있지만 **View Donation Summaries**는 없는 사람에게는 B1 Admin 메뉴에 **Donations**가 보이며, 이를 누르면 바로 배치 페이지로 이동합니다. **Summary**, **Funds**, **Campaigns**, **Giving Statements**는 숨겨집니다. 배치를 열어 그 안의 헌금을 보려면 역할에 **View Donations** 권한도 있어야 합니다.

:::tip
흔한 구성은 **Enter Donations**와 **View Donations**가 있는 "헌금 계수팀" 역할을 만들고, 입금을 대조한 뒤 각 배치를 닫는 재정 담당자에게 **Edit Donations**를 주는 것입니다.
:::

## 배치 인쇄하기

배치를 열고 헌금 목록 위의 **Print**를 클릭하면 헌금 계수팀이나 입금 기록을 위해 종이 사본을 인쇄할 수 있습니다. 인쇄물에는 다음이 포함됩니다.

- 교회 이름, 배치 이름, 배치 날짜
- 배치에 있는 모든 헌금(헌금자 이름, 방법, 메모, 날짜, 금액 포함. 환불된 헌금은 취소선이 그어지고 환불로 표시됩니다)
- **Fund Subtotals**(기금별 소계) -- 배치에서 각 기금에 헌금된 합계
- **Batch Total**(배치 합계) -- 배치 전체의 합산 금액

**Print** 버튼은 배치에 헌금이 하나 이상 있을 때만 나타납니다.

### 여러 배치 한꺼번에 인쇄하기

특정 기간의 모든 배치를 한 번에 인쇄하려면(예: 지난달의 모든 입금 내역) **Batches** 페이지 상단에서 **Export** 옆의 **Print**를 클릭합니다. **Print Batches** 페이지가 열리며, **Start Date**와 **End Date**가 기본적으로 지난 30일로 설정되어 있습니다. 두 날짜를 바꾸면 다른 기간을 고를 수 있습니다.

범위 안(시작일과 종료일 포함)의 모든 배치가 날짜순으로, 배치마다 한 페이지씩 단일 배치 인쇄물과 같은 양식으로 인쇄됩니다. 헌금이 없는 배치는 제외되며, 범위 안의 배치에 헌금이 하나도 없다면 "이 날짜 범위에는 헌금이 있는 배치가 없습니다."라는 메시지가 나타납니다. **Print**를 클릭하면 브라우저의 인쇄 대화상자가 열리고, **Close**를 클릭하면 배치 목록으로 돌아갑니다.

## QuickBooks Online으로 배치 내보내기

배치를 열고 **Export for QuickBooks**를 클릭하면 배치를 QuickBooks Online에서 가져올 수 있는 분개 전표로 내려받습니다(**Settings > Import Data > Journal Entries**). 파일에는 배치 합계에 대한 **Undeposited Funds** 차변 한 줄과, 기금마다 하나씩 대변 한 줄이 들어 있으며, 각 기금의 이름이 계정 이름으로 사용됩니다. QuickBooks는 가져올 때 이 이름을 계정 과목표와 맞추도록 요청하므로, 회계 담당자가 수입 계정을 부르는 방식에 맞추어 기금 이름을 정하거나 가져올 때 한 번 매핑해 두세요.

:::tip
나중에 쉽게 찾을 수 있도록 배치 이름을 일관되게 지으세요. 날짜와 헌금 종류를 넣으면(예: "주일 오전 - 2025-02-09") 배치가 늘어나도 목록이 정리됩니다.
:::
