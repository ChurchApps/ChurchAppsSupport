# 기부 기록

<div class="article-intro">

B1 Admin에서 기부를 기록하는 것은 배치 시스템을 통해 수행됩니다. 배치를 만들어 수금(예: 주일 헌금)을 나타낸 다음 해당 배치에 개별 기부를 추가합니다. 이렇게 하면 기부 기록을 정리하고 조정하기 쉽게 유지할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 기부를 올바른 범주에 할당할 수 있도록 [기금](funds.md)을 설정합니다
- 입력하려는 기부를 보관할 [배치](batches.md)를 만듭니다
- 기부자들이 기부자 디렉토리에 있는지 확인하십시오([사람 추가](../people/adding-people.md)), 그래서 당신은 헌금을 입력할 때 그들을 찾을 수 있습니다

</div>

## 배치 만들기 및 기부 추가

1. **B1 Admin**에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **Donations**를 확장한 후 **Batches**를 클릭합니다.
2. **Add Batch**를 클릭합니다.
3. 배치의 이름(예: "Sunday Offering - Jan 5")을 입력하고 날짜를 선택합니다. **Save**를 클릭합니다.
4. 새 배치가 목록에 나타나 기부 0개와 $0.00을 표시합니다.
5. **배치 이름**을 클릭하여 열습니다.

## 개별 기부 입력

1. 배치 세부 정보 페이지에서 **search field**에 기부자의 이름을 입력하여 찾습니다.
2. 사람을 선택한 후 기부 입력 양식이 **Date**, **Payment Method**, **Fund**, **Amount** 및 **Check Number** 필드와 함께 나타납니다.
3. 세부 정보를 입력하고 **Add Donation**을 클릭합니다.
4. 기부가 아래 표에 추가되고 양식이 초기화되어 다음 기부를 입력할 수 있습니다.

:::tip
배치 페이지를 떠나지 않고 여러 기부를 한 번에 빠르게 입력할 수 있습니다. 각 항목 후에 양식이 초기화되므로 수표 또는 봉투 더미를 효율적으로 진행할 수 있습니다.
:::

## 여러 기금에 걸쳐 기부 분할

때때로 단일 기부자가 한 거래에서 둘 이상의 기금에 기부합니다. 이를 처리하려면:

1. 기부 행의 **Edit** 버튼을 클릭합니다.
2. 편집 양식에서 다른 기금에 금액을 추가합니다. 합계는 개별 기금 금액에서 자동으로 계산됩니다.
3. **Save**를 클릭하여 기부를 업데이트합니다.

:::info
기금을 통해 기부를 분할하는 것은 기부자가 일반 기금과 선교활동과 같은 여러 목적으로 지정된 수표를 작성할 때 일반적입니다.
:::

## 기부 편집 또는 제거

기부를 편집하려면 배치의 행에서 **Edit** 버튼을 클릭합니다. 날짜, 금액, 기금, 결제 방법 또는 기타 세부 정보를 변경할 수 있습니다. 완료되면 **Save**를 클릭합니다.

:::tip
배치 페이지 헤더는 기부를 추가하거나 편집할 때 기부 총 수와 합산 금액을 자동으로 업데이트합니다. 이를 사용하여 입금 전표에 대해 조정합니다.
:::

## 기부 환불

기부자가 실수로 청구되었거나 환불을 요청한 경우 편집 화면에서 직접 완료된 기부를 환불할 수 있습니다. 지불 게이트웨이의 대시보드로 이동할 필요가 없습니다.

1. 기부를 열고 **Edit**를 클릭합니다.
2. 양식의 아래쪽 삭제 옆에서 **Refund** 버튼을 클릭합니다.
3. 대화를 확인합니다: "이 기부를 지불 게이트웨이를 통해 전체적으로 환불하시겠습니까? 이것은 실행 취소할 수 없습니다."

기부는 원래 지불 게이트웨이를 통해 전체 환불되며 기부 목록에서 **Refunded**로 표시됩니다.

:::warning
환불은 전체 환불만 가능합니다. B1 Admin에서 부분 금액을 환불할 수 있는 방법이 없습니다. 또한 환불은 확인 후 실행 취소할 수 없습니다.
:::

:::info
**Refund** 버튼은 온라인으로 결제된 기부(게이트웨이 거래가 있음)이고 여전히 **Complete** 상태인 기부에만 나타납니다. 수동으로 입력한 기부(현금, 수표)는 환불할 게이트웨이 거래가 없으므로 대신 편집하거나 삭제하십시오.
:::
