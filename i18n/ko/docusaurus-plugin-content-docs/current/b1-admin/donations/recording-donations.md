# 기부금 기록
<div class="article-intro">
B1 Admin에서 기부금 기록은 배치 시스템을 통해 이루어집니다. 배치를 생성하여 수집을 나타내고, 개별 기부금을 추가합니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- [펀드](funds.md)가 설정되어 있어야 합니다
- [배치](batches.md)가 생성되어 있어야 합니다
- 기부자가 [사람 디렉토리](../people/adding-people.md)에 있어야 합니다
</div>
## 배치 생성 및 기부금 추가
1. **B1 Admin**에서 **섹션 메뉴**를 열고 **기부금**을 선택한 후 **배치**를 클릭합니다.
2. **배치 추가**를 클릭합니다.
3. 배치의 이름을 입력하고 날짜를 선택한 후 **저장**을 클릭합니다.
4. 새로운 배치가 목록에 나타납니다.
5. **배치 이름**을 클릭하여 엽니다.
## 개별 기부금 입력
1. 배치 세부 정보 페이지에서 **검색 필드**에 기부자의 이름을 입력합니다.
2. 사람을 선택하면 기부금 항목 양식이 나타납니다.
3. 세부 정보를 입력하고 **기부금 추가**를 클릭합니다.
