# 헌금 기록하기

<div class="article-intro">

B1 Admin에서 헌금을 기록하는 작업은 배치(Batches) 시스템을 통해 이루어집니다. 주일 헌금 같은 한 번의 헌금 모음을 나타내는 배치를 만든 다음, 그 배치에 개별 헌금을 추가합니다. 이렇게 하면 헌금 기록을 체계적으로 정리하고 대조하기 쉽습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 헌금을 올바른 범주에 배정할 수 있도록 [기금](funds.md)을 설정하십시오
- 입력할 헌금을 담을 [배치](batches.md)를 만드십시오
- 헌금자가 [사람 디렉터리](../people/adding-people.md)에 있어야 헌금 입력 시 찾을 수 있습니다
- 배치에 헌금을 입력하려면 **헌금 수정**, 또는 **헌금 입력**과 **헌금 보기**가 함께 필요합니다([배치를 변경할 수 있는 사람](batches.md#who-can-change-a-batch) 참조)

</div>

## 배치 만들기와 헌금 추가하기

1. **B1 Admin**에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **Donations**를 펼친 뒤 **Batches**를 클릭합니다.
2. 페이지 상단의 **Add Batch**를 클릭합니다.
3. 배치 이름(예: "Sunday Offering - Jan 5")을 입력하고 날짜를 선택합니다. **Save**를 클릭합니다.
4. 새 배치가 목록에 헌금 0건, $0.00으로 표시됩니다.
5. **배치 이름**을 클릭하여 배치를 엽니다.

## 개별 헌금 입력하기

1. 배치 상세 페이지에서는 헌금 목록 옆에 헌금 입력 패널이 나타납니다. **Select Person or Anonymous** 아래의 검색 필드에 헌금자의 이름을 입력하여 찾거나, **Anonymous**를 클릭합니다. (페이지 상단의 **Add Donation**을 클릭하면 이 패널로 이동합니다.)
2. 사람을 선택하면 입력 양식에 **Date**, **Method**(Check, Cash, Card, In-Kind), **Fund**, **Notes**, **Amount**, **Check #**(카드 헌금의 경우 **Last 4 digits**, 현물 헌금을 설명하려면 **Item**) 필드가 나타납니다. 다른 사람을 선택하려면 헌금자 이름 옆의 **Change**를 클릭합니다.
3. 세부 정보를 입력하고 **Add Donation**을 클릭합니다(또는 Enter 키를 누릅니다).
4. 헌금이 헌금 목록에 추가되고, 양식이 초기화되어 다음 헌금을 입력할 수 있습니다.

:::info
배치가 [마감](batches.md#closing-and-reopening-a-batch)된 경우, **헌금 수정** 권한이 없는 사람에게는 입력 패널과 **Edit** 링크가 보이지 않으며, 배치 상단에 마감되었다는 안내가 표시됩니다. **헌금 수정** 권한이 있는 사람에게 배치를 다시 열어 달라고 요청하십시오.
:::

:::tip
배치 페이지를 떠나지 않고도 헌금을 연속으로 빠르게 입력할 수 있습니다. 입력할 때마다 양식이 초기화되므로 수표나 헌금 봉투 묶음을 효율적으로 처리할 수 있습니다.
:::

## 개인 기록에서 헌금 하나 기록하기

배치를 열지 않고 헌금 하나만 기록하려면, **People**에서 헌금자의 기록을 열고 (헌금 요약 또는 해당 사람의 헌금 보기에서) **Log a gift**를 클릭합니다.

1. **Date**와 **Amount**를 설정합니다.
2. **Fund**와 **Method**(Check, Cash, Card, In-Kind)를 선택하고, 필요하면 **Check #**, **Last 4 digits**, 또는 현물 헌금의 경우 **Item**을 입력합니다.
3. 필요하면 **Notes**를 추가한 뒤 **Save**를 클릭합니다.

헌금은 해당 날짜의 배치에 저장됩니다. 그 날짜의 배치가 아직 없으면 날짜를 이름으로 한 배치가 자동으로 만들어집니다.

## 헌금 하나를 여러 기금으로 나누기

한 번의 거래에서 헌금자가 둘 이상의 기금에 헌금하는 경우가 있습니다. 이를 처리하려면:

1. 입력 패널 아래의 **full donation editor** 링크를 클릭합니다(또는 기존 헌금 행의 **Edit**를 클릭합니다).
2. 전체 편집기에서 여러 기금에 금액을 나누어 입력합니다. 총액은 각 기금 금액에서 자동으로 계산됩니다.
3. **Save**를 클릭하여 헌금을 업데이트합니다.

:::info
한 명의 헌금자가 일반 기금과 선교 기금처럼 여러 목적을 지정한 수표 한 장을 쓰는 경우 헌금을 여러 기금으로 나누는 일은 흔합니다.
:::

## 헌금 수정 및 삭제하기

헌금을 수정하려면 배치에서 해당 행의 **Edit** 버튼을 클릭합니다. 날짜, 금액, 기금, 결제 방법(Check, Cash, Card, In-Kind) 또는 그 밖의 세부 정보를 변경할 수 있습니다. 현물 헌금의 경우 편집기는 세부 필드의 이름을 **Item**으로 표시하여 무엇을 드렸는지 설명할 수 있도록 합니다. 끝나면 **Save**를 클릭합니다.

:::tip
배치 이름 아래의 줄은 항목을 추가하거나 수정할 때마다 배치 날짜, 헌금 건수, 합계 금액을 자동으로 업데이트합니다. 이를 입금 전표와 대조하는 데 사용하십시오.
:::

## 헌금 환불하기

헌금자가 잘못 결제되었거나 돈을 돌려받기를 원하는 경우, 결제 게이트웨이 대시보드에 갈 필요 없이 완료된 헌금을 편집 화면에서 직접 환불할 수 있습니다.

1. 헌금을 열고 **Edit**를 클릭합니다.
2. 양식 하단의 Delete 옆에 있는 **Refund** 버튼을 클릭합니다.
3. 대화상자에서 확인합니다: "이 헌금을 결제 게이트웨이를 통해 전액 환불하시겠습니까? 이 작업은 취소할 수 없습니다."

헌금은 원래 결제 게이트웨이를 통해 전액 환불되며, 헌금 목록에서 **Refunded**로 표시됩니다.

:::warning
환불은 전액 환불만 가능합니다 -- B1 Admin에서는 일부 금액만 환불할 수 없습니다. 또한 한번 확인하면 환불을 취소할 수 없습니다.
:::

:::info
**Refund** 버튼은 온라인으로 결제된 헌금(게이트웨이 거래가 있는)이고 아직 **Complete** 상태인 헌금에만 나타납니다. 직접 입력한 헌금(현금, 수표)에는 환불할 게이트웨이 거래가 없으므로, 대신 편집하거나 삭제하십시오.
:::
