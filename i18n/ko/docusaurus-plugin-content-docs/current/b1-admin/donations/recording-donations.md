# 헌금 기록하기

<div class="article-intro">

B1 Admin에서 헌금을 기록하려면 Batches(배치) 시스템을 사용합니다. 주일 헌금처럼 하나의 헌금 시간을 나타내는 배치를 만든 다음, 그 배치에 개별 헌금을 추가합니다. 이렇게 하면 헌금 기록을 체계적으로 관리하고 쉽게 대조할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 올바른 항목에 헌금을 배정할 수 있도록 [funds(헌금 항목)](funds.md)를 먼저 설정하세요
- 입력할 헌금을 담을 [batch(배치)](batches.md)를 만드세요
- 헌금 기록 시 헌금자를 검색할 수 있도록 헌금자가 [people directory(교인 명부)](../people/adding-people.md)에 등록되어 있어야 합니다
- 배치에 헌금을 입력하려면 **Edit Donations** 권한이 있거나, **Enter Donations**와 **View Donations** 권한을 함께 가지고 있어야 합니다 ([Who Can Change a Batch(누가 배치를 변경할 수 있는지)](batches.md#who-can-change-a-batch) 참고)

</div>

## 배치 만들기 및 헌금 추가하기

1. **B1 Admin**에서 [Jump menu(점프 메뉴)](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Donations**를 펼친 다음 **Batches**를 클릭합니다.
2. 페이지 상단의 **Add Batch**를 클릭합니다.
3. 배치 이름(예: "Sunday Offering - Jan 5")을 입력하고 날짜를 선택합니다. **Save**를 클릭합니다.
4. 새 배치가 목록에 나타나며, 헌금 건수는 0건, 금액은 $0.00으로 표시됩니다.
5. **배치 이름**을 클릭하여 배치를 엽니다.

## 개별 헌금 입력하기

1. 배치 상세 페이지에서 헌금 목록 옆에 헌금 입력 패널이 나타납니다. **Select Person or Anonymous** 아래의 검색창에 헌금자 이름을 입력하여 찾거나 **Anonymous**를 클릭합니다. (페이지 상단의 **Add Donation**을 클릭하면 이 패널로 이동합니다.)
2. 사람을 선택하면 입력 양식에 **Date**, **Method**(Check, Cash, Card, In-Kind 중 선택), **Fund**, **Notes**, **Amount**, **Check #**(카드 헌금의 경우 **Last 4 digits**, 현물 헌금의 경우 **Item**) 필드가 표시됩니다. 다른 사람을 선택하려면 헌금자 이름 옆의 **Change**를 클릭합니다.
3. 세부 정보를 입력하고 **Add Donation**을 클릭합니다(또는 Enter 키를 누릅니다).
4. 헌금이 헌금 목록에 추가되고, 양식이 초기화되어 다음 헌금을 입력할 수 있습니다.

:::info
배치가 [closed(마감)](batches.md#closing-and-reopening-a-batch)된 경우, **Edit Donations** 권한이 없는 사용자에게는 입력 패널과 **Edit** 링크가 표시되지 않으며, 배치 상단에 마감되었다는 안내가 나타납니다. **Edit Donations** 권한이 있는 사용자에게 배치를 다시 열어 달라고 요청하세요.
:::

:::tip
배치 페이지를 벗어나지 않고도 여러 헌금을 연속으로 빠르게 입력할 수 있습니다. 헌금 한 건을 입력할 때마다 양식이 초기화되므로 수표나 봉투 묶음을 효율적으로 처리할 수 있습니다.
:::

## CSV 파일에서 헌금 가져오기 {#importing-donations-from-a-csv-file}

다른 헌금 시스템에서 내보낸 파일이나 집계팀의 집계표처럼 헌금 내역이 이미 스프레드시트에 있다면, 하나씩 입력하는 대신 배치로 가져올 수 있습니다.

1. 배치를 열고 페이지 상단의 **Import CSV**를 클릭합니다. (배치를 변경할 수 있고 교회에 [fund(헌금 항목)](funds.md)이 하나 이상 있을 때 이 버튼이 표시됩니다.)
2. **Choose CSV File**을 클릭하고 파일을 선택합니다. 파일에는 머리글 행이 있어야 하며, 열의 순서는 자유롭습니다.
   - **Amount**(필수, `Total`도 사용 가능) -- 통화 기호와 쉼표는 무시되므로 `$1,250.00`처럼 입력해도 됩니다. 금액은 0보다 커야 합니다.
   - **Date** -- `2026-10-25` 또는 `10/25/2026`과 같은 형식을 사용합니다. 비워 두면 배치 날짜가 사용됩니다.
   - **Fund** -- 헌금 항목의 이름이며, 대소문자를 구분하지 않고 일치시킵니다. 비워 두면 첫 번째 헌금 항목이 사용됩니다.
   - **Method** -- **Check**, **Cash**, **Card**, **In-Kind** 중 하나입니다. 비워 두면 **Check**가 사용됩니다.
   - **Check Number** -- 수표 번호(또는 기타 결제 세부 정보)입니다.
   - **Notes**
   - **Email**, **Name**, 또는 **First Name**과 **Last Name** -- 헌금자를 데이터베이스의 교인과 일치시키는 데 사용됩니다. "Smith, John"과 같이 적힌 이름은 "John Smith"로 인식됩니다.
3. 미리보기를 확인합니다. 각 행에는 줄 번호, 파일에 적힌 헌금자, **Match**, 헌금 항목, 금액이 표시됩니다.
   - 사람의 이름이 표시되면 헌금자가 일치한 것입니다. B1은 먼저 이메일로, 다음으로 정확한 이름으로 일치를 찾으며, 조건에 맞는 사람이 한 명일 때만 일치로 봅니다.
   - **Not found — anonymous**는 일치하는 사람을 찾지 못했다는 뜻입니다. 해당 헌금은 익명으로 가져오며, 나중에 배정할 수 있도록 헌금자의 이름이 담긴 "Imported as:" 메모가 비고란에 추가됩니다.
   - **Invalid amount**, **Unknown fund**, **Unknown method**, **Invalid date**와 같은 빨간색 메시지는 해당 행을 건너뛴다는 뜻입니다. 파일을 수정한 다음 다시 선택하면 해당 행이 포함됩니다.
4. **Import**를 클릭합니다(버튼에 가져올 행의 수가 표시됩니다). 헌금이 배치에 추가됩니다.

:::tip
가져온 후에는 익명 헌금에서 **Edit**를 사용하여 알맞은 사람을 선택할 수 있습니다. "Imported as:" 메모에 파일에 적힌 헌금자 정보가 나와 있습니다.
:::

## 사람의 기록에서 헌금 기록하기

배치를 열지 않고 헌금 한 건을 기록하려면 **People**에서 헌금자의 기록을 열고 (헌금 요약 또는 사람의 헌금 보기에서) **Log a gift**를 클릭합니다.

1. **Date**와 **Amount**를 설정합니다.
2. **Fund**와 **Method**(Check, Cash, Card, In-Kind 중 선택)를 선택하고, 필요한 경우 **Check #**, **Last 4 digits**, 또는 **Item**(현물 헌금의 경우)을 입력합니다.
3. 필요하면 **Notes**를 추가한 다음 **Save**를 클릭합니다.

헌금은 해당 날짜의 배치에 저장됩니다. 그 날짜의 배치가 아직 없으면 날짜를 이름으로 한 배치가 자동으로 만들어집니다.

## 한 헌금을 여러 헌금 항목에 나누기

한 명의 헌금자가 한 번의 거래로 여러 헌금 항목에 헌금하는 경우가 있습니다. 이때는 다음과 같이 처리합니다.

1. 입력 패널 아래의 **full donation editor** 링크를 클릭하거나 기존 헌금 행에서 **Edit**를 클릭합니다.
2. 전체 편집기에서 서로 다른 헌금 항목에 금액을 추가합니다. 전체 금액은 각 헌금 항목의 금액을 바탕으로 자동 계산됩니다.
3. **Save**를 클릭하여 헌금을 업데이트합니다.

:::info
헌금자가 General Fund와 Missions처럼 여러 용도를 지정한 수표 한 장을 낸 경우, 헌금을 여러 항목에 나누는 일이 흔합니다.
:::

## 헌금 수정 및 삭제하기

헌금을 수정하려면 배치에서 해당 행의 **Edit** 버튼을 클릭합니다. 날짜, 금액, 헌금 항목, 결제 방법(Check, Cash, Card, In-Kind 중 선택) 또는 기타 세부 정보를 변경할 수 있습니다. 현물 헌금의 경우 편집기에서 세부 정보 필드의 이름이 **Item**으로 표시되어 어떤 물건을 헌금했는지 적을 수 있습니다. 작업이 끝나면 **Save**를 클릭합니다.

:::tip
페이지 상단의 배치 이름 아래 줄에는 헌금을 추가하거나 수정할 때마다 배치 날짜, 헌금 건수, 헌금 합계 금액이 자동으로 업데이트되어 표시됩니다. 이를 활용하여 입금 전표와 대조해 보세요.
:::

## 헌금 환불하기

헌금자가 잘못 결제되었거나 환불을 요청하는 경우, 결제 게이트웨이의 대시보드에 들어가지 않고도 완료된 헌금을 편집 화면에서 바로 환불할 수 있습니다.

1. 헌금을 열고 **Edit**를 클릭합니다.
2. 양식 하단의 Delete 옆에 있는 **Refund** 버튼을 클릭합니다.
3. 대화상자에서 "Refund this donation in full through the payment gateway? This cannot be undone."(이 헌금을 결제 게이트웨이를 통해 전액 환불하시겠습니까? 이 작업은 취소할 수 없습니다.) 메시지를 확인합니다.

헌금은 원래 결제 게이트웨이를 통해 전액 환불되며, 헌금 목록에서 **Refunded**(환불됨)로 표시됩니다.

:::warning
환불은 전액만 가능합니다. B1 Admin에서는 일부 금액만 환불할 방법이 없습니다. 또한 한 번 확인한 환불은 취소할 수 없습니다.
:::

:::info
**Refund** 버튼은 온라인으로 결제된 헌금(게이트웨이 거래 기록이 있는 헌금)이면서 상태가 여전히 **Complete**(완료)인 경우에만 표시됩니다. 직접 입력한 헌금(현금, 수표)에는 환불할 게이트웨이 거래가 없으므로, 이러한 헌금은 편집하거나 삭제해야 합니다.
:::
