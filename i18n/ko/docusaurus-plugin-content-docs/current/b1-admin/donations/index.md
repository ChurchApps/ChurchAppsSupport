# 기부금
<div class="article-intro">
B1 Admin의 기부금 섹션은 교회의 기부금을 관리하는 데 필요한 모든 것을 제공합니다. 주간 헌금 기록부터 연말 세금 명세서 생성까지, 모든 기부금 도구가 한 곳에 구성되어 있습니다.
</div>
## 하위 섹션
기부금 섹션에서 다음 페이지를 찾을 수 있습니다:
- **요약** — 모든 기부 활동의 시각적 개요
- **배치** — 기부금을 그룹화합니다
- **펀드** — 기부금을 목적별로 분류합니다
- **명세서** — 기부자를 위한 연말 명세서 생성
- **Stripe 가져오기** — 온라인 거래 가져오기
## 온라인 기부
B1 Admin은 **Stripe**와 **PayPal**과 통합되어 온라인 기부를 받습니다.

:::
