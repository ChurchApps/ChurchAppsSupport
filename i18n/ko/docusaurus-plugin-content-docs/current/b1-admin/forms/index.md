# 양식

<div class="article-intro">

양식 섹션을 사용하면 등록, 설문 조사, 데이터 수집 등을 위한 사용자 정의 양식을 만들 수 있습니다. 방문자 카드, 행사 등록 또는 기도 요청 양식이 필요한지 여부를 불문하고 여기에서 만들어 공개 링크 또는 B1.church 웹사이트를 통해 교중과 공유할 수 있습니다.

</div>

## 양식 페이지

**Forms**를 열면 다음 탭이 표시됩니다:

- **Forms** -- 모든 활성 양식을 표시합니다.
- **Archived Forms** -- 보관된 양식을 표시합니다. 언제든지 보관된 양식을 복원할 수 있습니다. 이 탭은 최소 하나의 양식이 보관된 후에만 나타납니다.

목록의 각 양식은 이름과 구성된 경우 외부에서 공유할 수 있는 공개 URL을 표시합니다.

## 할 수 있는 것

양식 페이지에서 다음을 수행할 수 있습니다:

- **양식 추가** -- **Add Form**을 클릭하여 새 사용자 정의 양식을 만듭니다.
- **양식 편집** -- 양식 이름을 클릭하여 열고 질문, 멤버 또는 설정을 수정합니다.
- **양식 보관** -- 더 이상 필요하지 않은 양식을 **Archived Forms** 탭으로 이동하여 목록을 깔끔하게 유지합니다.
- **양식 복원** -- **Archived Forms** 탭으로 전환하고 다시 활성화하려는 양식을 복원합니다.

## 양식으로 작업

양식 이름을 클릭하여 엽니다. 양식 편집기에는 최대 3개의 탭이 있습니다:

- **Questions** -- 다양한 유형의 필드를 추가하여 양식 구조를 만듭니다. 세부 정보는 [Creating Forms](./creating-forms.md)를 참조합니다.
- **Form Members** -- 양식에 접근하고 관리할 수 있는 사람을 제어합니다(독립형 양식만 해당).
- **Form Submissions** -- 제출된 응답을 봅니다. 세부 정보는 [Managing Submissions](./managing-submissions.md)를 참조합니다.

:::tip
공개 URL이 있는 양식은 링크를 통해 공유하거나 웹사이트에 포함하거나 이메일에 포함할 수 있습니다. 이렇게 하면 교회 계정을 가지지 않은 사람으로부터 정보를 수집하기가 쉬워집니다.
:::

:::info
**Form Members** 탭을 사용하여 각 양식에 접근할 수 있는 사람을 제어할 수 있습니다. 팀에 올바른 수준의 접근 권한을 제공하려면 **Admin** 또는 **View Only** 역할을 할당합니다.
:::
