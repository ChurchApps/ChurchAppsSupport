# 제출물 관리

<div class="article-intro">

양식이 라이브 상태가 되면 제출물이 들어오기 시작합니다. **Form Submissions** 탭을 사용하면 모든 응답을 검토하고 누가 제출했는지 추적하고 데이터를 사용하여 적절한 시간에 교중을 팔로우업할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 최소 하나의 질문이 포함된 [양식을 만듭니다](./creating-forms.md)
- 양식을 공개 URL을 통해 공유하거나 [웹사이트](../website/managing-pages.md)에 포함합니다

</div>

## 제출물 보기

1. [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin의 왼쪽 상단 검색 표시줄)를 열고 **People**을 확장한 후 **Forms**를 클릭합니다.
2. 검토할 양식을 클릭합니다.
3. **Form Submissions** 탭으로 이동합니다.

해당 양식에 대해 받은 모든 응답 목록이 표시됩니다. 각 제출물은 응답자의 정보 및 제출 날짜를 표시한 후 양식의 모든 질문에 대해 하나의 열을 표시합니다. 양식에 많은 질문이 있으면 표를 옆으로 스크롤하여 나머지 열을 봅니다.

## 개별 제출물 검토

제출물을 클릭하여 전체 세부 정보를 봅니다. 사람이 양식의 각 질문에 대해 제공한 모든 답변이 표시됩니다.

제출물 옆에 있는 **print icon**을 클릭하여 해당 사람이 작성한 답변을 인쇄합니다. 종이 파일 또는 보유해야 하는 서명된 릴리스에 유용합니다. 인쇄본은 교회의 이름을 상단에 표시합니다. 이것은 [공백 양식 인쇄](./creating-forms.md#printing-a-blank-form)와는 별개입니다. 빈 복사본이 아닌 한 사람이 이미 제출한 답변을 인쇄합니다. 동일한 인쇄 아이콘은 [개인 프로필](../people/adding-people.md#working-with-forms)을 포함하여 제출물이 표시되는 모든 곳에 나타납니다.

## 제출물의 개인 변경

제출물이 잘못된 사람과 연결된 경우(예: 두 가족 구성원이 이메일 주소를 공유하는 경우) 올바른 사람으로 이동하거나 연결을 해제할 수 있습니다.

1. **Form Submissions** 탭에서 개인의 이름 옆에 있는 **Change person** 아이콘(두 개의 화살표)을 클릭합니다. 동일한 아이콘은 [개인 프로필](../people/adding-people.md#working-with-forms)의 제출물 옆에도 나타납니다.
2. **Change person** 대화에서 올바른 사람을 검색하고 **Move to this person**을 클릭합니다.
3. 또는 **Unlink (Anonymous)**를 클릭하여 모든 사람의 제출물을 분리합니다. 그러면 **Anonymous**로 표시됩니다.

링크만 변경됩니다. 답변은 동일하게 유지되고 추가 이메일은 다시 전송되지 않습니다.

:::info
사람 기록을 만들도록 설정된 양식에서 누군가가 제출하는 동안 교회 사이트에 로그인한 경우 제출물은 데이터베이스의 다른 사람이 이메일 주소를 공유하더라도 자신의 기록에 연결됩니다. [두 개의 사람 기록을 병합](../people/adding-people.md)하면 제거된 사람의 양식 제출물이 유지하는 사람으로 이동합니다.
:::

## 제출물 수집 방법

제출물은 여러 채널을 통해 들어올 수 있습니다:

- **공개 URL** -- 양식에 공개 URL(Stand Alone 양식)이 있으면 링크를 가진 누구나 응답을 제출할 수 있습니다. 이메일, 소셜 미디어 또는 문자 메시지를 통해 URL을 공유합니다.
- **웹사이트에 포함됨** -- B1 웹사이트에 포함된 양식은 방문자가 작성할 때 제출물을 자동으로 수집합니다.
- **내부 사용** -- 직원 및 자원 봉사자는 B1 Admin 내에서 다른 사람을 대신하여 양식을 제출할 수도 있습니다.

:::tip
방문자 카드 또는 기도 요청과 같은 양식의 **Form Submissions** 탭을 정기적으로 확인하여 시기 적절하게 팔로우업할 수 있도록 합니다.
:::

## 제출 데이터 사용

양식을 통해 수집한 데이터는 다음에 도움이 될 수 있습니다:

- 행사 등록 추적 및 그에 따라 계획
- 방문자 또는 새 멤버 팔로우업
- 목회 계획을 위한 설문 조사 피드백 수집
- 행사 또는 프로그램에 대한 결제 처리

:::info
**Admin** 또는 **View Only** 역할을 가진 양식 멤버는 **Form Submissions** 탭에 접근할 수 있습니다. **Form Members** 탭에서 역할을 관리하여 팀의 올바른 사람이 필요한 양식에 접근할 수 있는지 확인합니다.
:::

:::tip
**Stand Alone** 양식이 사람 기록을 만들도록 설정된 경우 기존 사람과 일치하는 모든 제출물이 사람 섹션의 해당 사람의 자신의 **Forms** 탭에도 나타납니다. 사람 유형 양식만이 아닙니다.
:::
