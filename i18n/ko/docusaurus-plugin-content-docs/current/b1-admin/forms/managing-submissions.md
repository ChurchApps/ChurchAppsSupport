# 제출 관리

<div class="article-intro">

양식이 실시간으로 전환되면 제출이 들어오기 시작합니다. 제출 탭을 사용하면 모든 응답을 검토하고, 제출한 사람을 추적하고, 데이터를 사용하여 시간에 맞춰 신도를 후속 조치할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [최소한 하나의 질문으로 양식을 생성합니다](./creating-forms.md).
- 공개 URL을 통해 또는 [웹사이트에 포함](../website/managing-pages.md)하여 양식을 공유합니다.

</div>

## 제출 보기

1. 섹션 메뉴에서 **사람**을 열고, 탐색 모음에서 **양식**을 클릭합니다.
2. 검토하려는 양식을 클릭합니다.
3. **제출** 탭으로 이동합니다.

해당 양식에 대해 수신된 모든 응답의 목록이 표시됩니다. 각 제출은 응답자의 정보와 제출된 날짜를 표시합니다.

## 개별 제출 검토

제출을 클릭하여 전체 세부사항을 봅니다. 양식의 각 질문에 대해 사람이 제공한 모든 답변이 표시됩니다.

제출 옆의 **인쇄 아이콘**을 클릭하여 그 사람의 작성된 답변을 인쇄합니다 -- 종이 파일이나 보관해야 할 서명된 양식에 유용합니다. 이는 [빈 양식 인쇄](./creating-forms.md#printing-a-blank-form)와 별개입니다. 빈 사본이 아닌 한 사람이 이미 제출한 답변을 인쇄합니다. 동일한 인쇄 아이콘은 제출이 표시되는 곳 어디든지 나타납니다([사람의 프로필](../people/adding-people.md#working-with-forms)포함).

## 제출이 수집되는 방식

제출은 여러 채널을 통해 들어올 수 있습니다:

- **공개 URL** -- 양식에 공개 URL이 있는 경우(독립 실행형 양식), 링크가 있는 누구나 응답을 제출할 수 있습니다. 이메일, 소셜 미디어 또는 문자 메시지를 통해 URL을 공유합니다.
- **웹사이트에 포함** -- B1 웹사이트에 포함된 양식은 방문자가 작성할 때 자동으로 제출을 수집합니다.
- **내부 사용** -- 직원 및 자원봉사자는 B1 Admin 내에서 다른 사람 대신 양식을 제출할 수도 있습니다.

:::tip
방문객 카드 또는 기도 요청과 같은 양식의 경우 **제출** 탭을 정기적으로 확인하여 신속하게 후속 조치할 수 있습니다.
:::

## 제출 데이터 사용

양식을 통해 수집한 데이터는 다음을 도와줄 수 있습니다:

- 행사 등록을 추적하고 적절히 계획합니다.
- 방문객 또는 신규 구성원을 후속 조치합니다.
- 사역 계획을 위해 설문조사 피드백을 수집합니다.
- 행사 또는 프로그램에 대한 결제를 처리합니다.

:::info
**관리자** 또는 **보기만** 역할이 있는 양식 구성원은 제출 탭에 액세스할 수 있습니다. **구성원** 탭에서 역할을 관리하여 팀의 올바른 사람이 필요한 양식에 액세스할 수 있도록 하세요.
:::

:::tip
**독립 실행형** 양식이 사람 기록을 만들도록 설정된 경우, 기존 사람과 일치하는 제출도 해당 사람의 자신의 **양식** 탭에 표시됩니다 -- 사람 유형 양식뿐만 아니라.
:::
