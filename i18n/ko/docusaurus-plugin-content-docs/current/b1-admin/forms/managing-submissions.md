# 제출 내용 관리하기

<div class="article-intro">

양식이 공개되면 제출 내용이 들어오기 시작합니다. **Form Submissions** 탭에서는 모든 응답을 검토하고, 누가 제출했는지 확인하며, 그 데이터를 활용해 교인들에게 시기적절하게 후속 조치를 할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 질문이 하나 이상 포함된 [양식을 만드세요](./creating-forms.md)
- 공개 URL로 양식을 공유하거나 [웹사이트](../website/managing-pages.md)에 삽입하세요

</div>

## 제출 내용 보기

1. [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 상단의 검색창)를 열고 **People**을 펼친 다음 **Forms**를 클릭합니다.
2. 검토하려는 양식을 클릭합니다.
3. **Form Submissions** 탭으로 이동합니다.

해당 양식으로 받은 모든 응답 목록이 표시됩니다. 각 제출 내용에는 응답자 정보와 제출 날짜가 표시되며, 양식의 질문마다 열이 하나씩 이어서 나타납니다. 질문이 많은 경우 표를 좌우로 스크롤하여 나머지 열을 확인하세요.

## 개별 제출 내용 검토하기

제출 내용을 클릭하면 전체 세부 정보를 볼 수 있습니다. 양식의 각 질문에 대해 응답자가 작성한 모든 답변이 표시됩니다.

제출 내용 옆의 **인쇄 아이콘**을 클릭하면 해당 응답자가 작성한 답변을 인쇄할 수 있습니다. 종이 파일이나 보관해야 하는 서명된 동의서가 필요할 때 유용합니다. 인쇄물 상단에는 교회 로고([Website > Appearance](../website/appearance.md)에서 업로드한 **Light Background Logo**가 있는 경우)와 그 아래 교회 이름이 표시됩니다. 이는 [빈 양식 인쇄하기](./creating-forms.md#printing-a-blank-form)와는 별개의 기능으로, 빈 양식이 아니라 한 사람이 이미 제출한 답변을 인쇄합니다. 제출 내용이 표시되는 곳이라면 [사람의 프로필](../people/adding-people.md#working-with-forms)에서도 같은 인쇄 아이콘을 볼 수 있습니다.

## 제출 내용의 사람 변경하기 {#changing-the-person-on-a-submission}

제출 내용이 잘못된 사람과 연결된 경우, 예를 들어 두 가족 구성원이 같은 이메일 주소를 쓰는 경우에는 올바른 사람에게 옮기거나 연결을 해제할 수 있습니다.

1. **Form Submissions** 탭에서 사람 이름 옆의 **Change person** 아이콘(화살표 두 개)을 클릭합니다. 같은 아이콘이 [사람의 프로필](../people/adding-people.md#working-with-forms)에 있는 제출 내용 옆에도 나타납니다.
2. **Change person** 대화상자에서 올바른 사람을 검색한 다음 **Move to this person**을 클릭합니다.
3. 또는 **Unlink (Anonymous)**를 클릭하여 제출 내용을 모든 사람으로부터 분리합니다. 이후 제출 내용은 **Anonymous**로 표시됩니다.

연결만 변경되며 답변 내용은 그대로 유지됩니다. 후속 이메일이 다시 발송되지도 않습니다.

:::info
사람 기록을 만들도록 설정된 양식에서, 제출 시 교회 웹사이트에 로그인한 상태라면 같은 이메일 주소를 가진 다른 사람이 데이터베이스에 있더라도 제출 내용이 그 사람 본인의 기록에 연결됩니다. [사람 기록 두 개를 병합](../people/adding-people.md)하면, 삭제된 사람의 양식 제출 내용은 남는 사람에게 이전됩니다.
:::

## 제출 내용이 수집되는 경로

제출 내용은 여러 경로를 통해 들어올 수 있습니다.

- **공개 URL** -- 양식에 공개 URL이 있는 경우(독립형 양식) 링크를 가진 누구나 응답을 제출할 수 있습니다. 이메일, 소셜 미디어, 문자 메시지로 URL을 공유하세요.
- **웹사이트 삽입** -- B1 웹사이트에 삽입된 양식은 방문자가 작성할 때 제출 내용이 자동으로 수집됩니다.
- **내부 사용** -- 직원과 봉사자도 B1 Admin 안에서 다른 사람을 대신하여 양식을 제출할 수 있습니다.

:::tip
방문자 카드나 기도 요청과 같은 양식은 **Form Submissions** 탭을 자주 확인하여 신속하게 후속 조치를 취하세요.
:::

## 제출 데이터 활용하기

양식을 통해 수집된 데이터는 다음과 같은 일에 도움이 됩니다.

- 행사 등록 현황을 파악하고 그에 맞춰 계획 세우기
- 방문자나 새 교인에게 후속 연락하기
- 사역 계획을 위해 설문조사 의견 수집하기
- 행사나 프로그램의 결제 처리하기

:::info
**Admin** 또는 **View Only** 역할을 가진 양식 구성원은 **Form Submissions** 탭에 접근할 수 있습니다. **Form Members** 탭에서 역할을 관리하여 팀에 필요한 양식에 올바른 사람이 접근할 수 있도록 하세요.
:::

:::tip
**Stand Alone** 양식이 사람 기록을 만들도록 설정되어 있으면, 기존 사람과 일치하는 제출 내용은 People에서 해당 사람의 페이지 **Forms** 섹션에도 표시됩니다. People 유형 양식에만 표시되는 것이 아닙니다.
:::
