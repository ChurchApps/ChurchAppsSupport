# 양식 생성

<div class="article-intro">

교회 신도로부터 정보를 수집할 사용자 정의 양식을 만드세요. 행사 등록, 설문조사, 방문객 카드, 회원 신청 등을 위한 양식을 만들 수 있습니다. 양식은 데이터베이스의 사람에게 연결되거나 자신의 공개 URL이 있는 독립 실행형 페이지로 사용될 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- **사람** 양식(사람 기록에 연결됨)의 경우 먼저 [데이터베이스에 사람을 추가](../people/adding-people.md)하세요.
- **결제**를 수집하는 양식의 경우 [온라인 기부를 위해 Stripe를 구성](../donations/online-giving-setup.md)해야 합니다.

</div>

## 새 양식 만들기

1. 섹션 메뉴에서 **사람**을 열고, 탐색 모음에서 **양식**을 클릭합니다.
2. **양식 추가**를 클릭합니다.
3. 양식에 대한 **이름**을 입력합니다.
4. 드롭다운에서 양식 유형을 선택합니다:
   - **사람** — 제출을 데이터베이스의 [사람 기록](../people/adding-people.md)과 연결합니다.
   - **독립 실행형** -- 자신의 공개 URL이 있는 독립 양식을 만듭니다. 외부 등록에 이상적입니다.
5. **저장**을 클릭하여 양식을 만듭니다.

새 양식이 목록에 나타납니다. 클릭하여 질문 추가를 시작하세요.

## 빈 양식 인쇄

환영 책상의 방문객 카드나 인터넷 접근 없이 손으로 작성할 수 있는 양식처럼 선착순 종이 사본이 필요하신가요? 주 양식 목록의 양식 옆에 있는 **인쇄 아이콘**을 클릭하여 미리보기를 연 다음 **인쇄**를 클릭합니다. 빈 필드는 각 질문에 대해 밑줄 또는 확인란으로 인쇄되므로 사람들이 손으로 작성할 수 있습니다. 필수 질문은 별표로 표시됩니다. 다른 인쇄 옵션은 없습니다 -- 전체 양식을 인쇄하거나 아무것도 인쇄하지 마세요.

## 질문 추가

1. 양식을 열고 **질문** 탭으로 이동합니다.
2. **질문 추가**를 클릭합니다.
3. 공급자 드롭다운에서 **필드 유형**을 선택합니다. 사용 가능한 유형은 다음을 포함합니다:
   - **텍스트상자** — 짧은 텍스트 답변용
   - **날짜** -- 날짜 선택용
   - **이메일** -- 이메일 주소용
   - **전화 번호** -- 전화 입력용
   - **객관식** -- 미리 정의된 옵션에서 선택용
   - **결제** -- 결제 수집용
4. 질문에 대한 **제목**과 선택적 **설명**을 입력합니다.
5. 필드가 필수인 경우 **답변 필요**를 확인합니다.
6. **저장**을 클릭합니다.
7. 더 많은 질문을 추가하려면 반복하세요.

:::warning
**결제** 필드 유형을 사용하려면 Stripe가 구성되어야 합니다. 아직 온라인 기부를 설정하지 않았다면 결제 필드를 추가하기 전에 [온라인 기부 설정](../donations/online-giving-setup.md)을 참조하세요.
:::

## 양식 구성원 관리

1. 양식을 열고 **구성원** 탭으로 이동합니다.
2. 사람을 검색하고 역할로 추가합니다:
   - **관리자** -- 양식을 편집하고 모든 제출을 볼 수 있습니다.
   - **보기만** -- 제출을 볼 수 있지만 양식을 편집할 수 없습니다.

## 자동으로 제출자를 그룹에 추가

**제출에서 사람 기록 생성**이 활성화되면 양식을 그룹에 연결하여 모든 제출자가 자동으로 해당 그룹의 명단에 추가될 수 있습니다:

1. 양식의 **세부사항**을 열고 **제출에서 사람 기록 생성**을 켭니다.
2. **제출자를 그룹에 추가**에서 제출자를 추가할 그룹을 선택하거나 **없음**으로 설정된 상태로 두십시오.
3. **저장**을 클릭합니다.

누군가 양식을 제출할 때마다 일치하거나 새로 만든 사람이 그룹에 추가됩니다(기존 그룹 구성원은 건너뜁니다). 이는 캠프 등록 양식과 같이 캠프의 명단을 자동으로 작성해야 하는 경우에 유용합니다.

### 후속 이메일 전송

**제출에서 사람 기록 생성**이 켜져 있으면 양식을 제출한 각 사람에게 이메일을 보낼 수도 있습니다. 양식의 세부사항에서 **후속 이메일 제목** 및 **후속 이메일 본문**을 입력합니다. `{firstName}` 및 `{churchName}` 토큰을 둘 다에서 사용할 수 있습니다. 이메일은 두 필드가 모두 채워져 있을 때만 전송됩니다.

:::info
후속 이메일은 교회가 그룹 이메일 전송 승인을 받은 후에만 나가며, 교회의 일일 이메일 한도에 포함됩니다. [교회를 위해 그룹 이메일 켜기](../groups/group-members.md#turning-on-group-email-for-your-church)를 참조하세요.
:::

## 양식 복제

양식을 새 양식의 시작점으로 다시 사용하려면 양식 목록의 양식 옆에 있는 **복제** 아이콘(복사 아이콘)을 클릭합니다. B1은 모든 질문을 포함하여 양식의 정확한 사본을 만들어서 독립적으로 이름을 바꾸고 편집할 수 있습니다.

:::tip
복제는 등록 질문이 해년 동안 동일하게 유지되는 반복되는 행사에 유용합니다. 작년 양식을 복제하고, 이름과 날짜를 업데이트하면 준비가 됩니다.
:::

## 양식 속성 구성

언제든지 양식의 이름과 설정을 업데이트할 수 있습니다. 독립 실행형 양식의 경우 누구와도 공유할 수 있는 고유한 **공개 URL**과 공개 양식 페이지 위에 표시되는 텍스트인 **설명** 필드도 표시됩니다 -- 사람들이 작성을 시작하기 전에 양식의 목적을 알려주는 데 유용합니다.

:::tip
독립 실행형 양식은 행사 등록에 좋습니다. 이메일, 소셜 미디어 또는 교회 웹사이트에 직접 포함하여 공개 URL을 공유하세요.
:::

:::info
양식을 B1 웹사이트에 포함하려면 웹사이트 편집기로 이동하여 새 섹션을 추가하고 **양식** 요소를 선택합니다. 그런 다음 표시하려는 양식을 선택합니다. 웹사이트 편집에 대한 자세한 내용은 [페이지 관리](../website/managing-pages.md)를 참조하세요.
:::
