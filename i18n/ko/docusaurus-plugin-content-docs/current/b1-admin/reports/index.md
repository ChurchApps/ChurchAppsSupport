# 보고서

<div class="article-intro">

B1 Admin은 교인, 출석, 헌금에 관한 데이터를 가져올 수 있는 여러 방법을 제공합니다. 보고 기능은 하나의 보고서 페이지가 아니라 앱의 관련 섹션에 포함되어 있습니다.

</div>

## 보고서 찾는 곳 {#where-to-find-reports}

### 사람 {#people}
- **[생일 및 기념일 목록](./birthday-report.md)** -- **People → Advanced Search**(사람 → 고급 검색)에서 Birth Month(생일 월) 또는 Anniversary Month(기념일 월)로 필터링하여 다가오는 생일이나 기념일 목록을 확인하세요.

### 출석 {#attendance}
- **[출석 보고서](./attendance-reports.md)** -- 출석 추이와 그룹 출석 데이터는 **Attendance**(출석) 섹션에서 찾을 수 있습니다.

### 헌금 {#donations}
- **[헌금 요약](./donation-summary.md)** -- 헌금 총액과 헌금 항목별 내역은 **Donations**(헌금) 섹션에서 찾을 수 있습니다.

### 설정 {#settings}
- **[감사 로그](./audit-log.md)** -- 교회 관리 시스템 전반의 모든 변경 사항과 작업을 추적하세요(**Settings → Audit Log**(설정 → 감사 로그)에서 찾을 수 있습니다).

:::info
보고서 데이터는 일관된 데이터 입력에 달려 있습니다. 가장 정확한 결과를 얻으려면 팀이 [출석을 기록](../attendance/tracking-attendance.md)하고, [헌금을 기록](../donations/recording-donations.md)하며, [사람 기록](../people/adding-people.md)을 최신 상태로 유지하고 있는지 확인하세요.
:::
