# 보고서

<div class="article-intro">

B1 Admin에서는 교인, 출석, 헌금에 관한 데이터를 여러 방법으로 조회할 수 있습니다. 보고는 하나의 보고서 페이지가 아니라 앱의 관련 섹션 안에 들어 있습니다.

</div>

## 교육 영상

<YouTube id="vn5SonVe94Q" title="Running Reports in B1" />

## 보고서 찾는 곳

### 사람
- **[생일 및 기념일 목록](./birthday-report.md)** -- **사람 → 고급 검색**에서 생월 또는 기념일 월로 걸러서 다가오는 생일이나 기념일 목록을 봅니다.

### 출석
- **[출석 보고서](./attendance-reports.md)** -- 출석 추세와 그룹별 출석 데이터는 **출석** 섹션에 있습니다.

### 헌금
- **[헌금 요약](./donation-summary.md)** -- 헌금 합계와 펀드별 내역은 **헌금** 섹션에 있습니다.

### 설정
- **[감사 로그](./audit-log.md)** -- 교회 관리 시스템 전반의 모든 변경과 작업을 추적합니다(**설정 → 감사 로그**에서 찾을 수 있습니다).

:::info
보고서의 데이터는 일관된 데이터 입력에 달려 있습니다. 가장 정확한 결과를 얻으려면 팀이 [출석을 기록하고](../attendance/tracking-attendance.md), [헌금을 기록하며](../donations/recording-donations.md), [사람 기록](../people/adding-people.md)을 최신 상태로 유지하도록 하세요.
:::
