# 생일 및 기념일 목록

<div class="article-intro">

주어진 달에 생일 또는 기념일이 있는 모든 사람의 목록이 필요하신가요 -- 주보, 공지사항 또는 카드용? People 검색으로 **Birth Month**와 **Anniversary Month**로 교회를 필터링하고 결과에 날짜를 바로 표시할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 각 사람의 프로필에 생년월일(및 기념일)이 입력되어 있는지 확인하세요. [Adding People](../people/adding-people.md)을 참고하세요.
- People을 볼 수 있는 권한이 필요합니다. [Roles & Permissions](../settings/roles-permissions.md)을 참고하세요.

</div>

## 한 달의 생일 목록 가져오기

1. B1 Admin의 왼쪽 상단에 있는 검색 모음인 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)를 열고 **People**을 확장한 다음 **People**을 클릭하세요.
2. 검색 상자 아래에서 **Advanced**를 클릭하세요.
3. **Demographics** 섹션을 확장하고 **Birth Month**를 선택한 다음 달을 선택하세요.
4. 검색을 실행하세요 -- 그 달에 생일이 있는 모든 사람이 결과에 나타납니다.
5. 날짜를 보려면, 결과의 오른쪽 상단에서 **열 아이콘**을 클릭하고 **Birthday** 열을 활성화하세요. 스프레드시트에서 정렬하거나 인쇄하는 것을 선호하면 **Export**를 사용하여 목록을 다운로드하세요.

## 기념일 목록 가져오기

같은 단계입니다 -- **Demographics** 섹션에서 **Anniversary Month**를 대신 선택하고(또는 추가로), 달을 선택한 다음, 결과에서 **Anniversary** 열을 활성화하세요.

## 실질적인 사용

- **주간 주보** -- 현재 달의 목록을 실행하고 이름을 바로 주보에 읽으세요.
- **생일 및 기념일 카드** -- 달의 목록을 내보내고 카드 작성 팀에 넘기세요.
- **마일스톤** -- **Age** 필터와 결합하여 마일스톤 생일을 찾으세요.

:::tip
둘 다의 목록은 각 사람의 프로필의 생년월일 및 기념일 필드에서 옵니다 -- 누군가가 없다면, 해당 프로필에 날짜만 추가하면 됩니다.
:::

:::info
B1 Admin의 이전 버전은 생일용 별도의 Reports 페이지를 가지고 있었습니다. 해당 페이지는 폐지되었으며 -- People 검색 필터 위는 현재 방식이며, 기념일도 다룹니다.
:::
