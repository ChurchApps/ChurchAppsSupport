# 생일 보고서

<div class="article-intro">

생일 보고서는 예정된 생일을 가진 회원을 보여주어 회중과의 연결을 유지하는 데 도움이 됩니다. 축하 행사를 계획하거나 카드를 보내거나 예배 중에 공지사항을 하는 데 사용합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 각 사람의 프로필에 생년월일이 입력되어 있는지 확인합니다. 자세한 내용은 [사람 추가](../people/adding-people.md)를 참조합니다.
- 보고서에 액세스할 적절한 [권한](../settings/roles-permissions.md)이 필요합니다

</div>

## 보고서 실행

1. 브라우저에서 **admin.b1.church/reports/birthdays**로 직접 이동합니다 (보고서는 탐색 메뉴에 항목이 없습니다. 주소를 북마크하는 것이 가장 쉬운 방법입니다).
2. 드롭다운에서 원하는 **월**을 선택합니다. 선택적으로 결과를 단일 **그룹**으로 제한할 수 있습니다.
3. **보고서 실행**을 클릭합니다. 보고서는 그 달의 생일을 가진 모든 사람을 생년월일과 함께 나열합니다. 게시판이나 공지 목록에 직접 읽을 준비가 된 상태입니다.

## 보고서 내용

생일 보고서는 다음을 표시합니다:

- **생일** - 생일 날짜입니다.
- **이름** - 교회 데이터베이스의 사람 이름입니다.

결과는 선택한 월을 다루므로 누가 곧 생일이 있는지 쉽게 볼 수 있습니다.

## 실용적인 사용

- **주간 공지사항** - 다가오는 주의 보고서를 실행하고 생일을 게시판이나 공지사항에 포함시킵니다.
- **생일 카드** - 해당 월의 목록을 생성하고 팀에서 개인 생일 카드를 보내도록 합니다.
- **소그룹 리더** - 그룹 리더는 보고서를 실행하여 그룹 구성원의 생일을 기억할 수 있습니다.
- **이정표 축하** - 특정 날짜 범위를 필터링하여 이정표 생일 축하를 계획합니다.

:::tip
각 월 초에 이 보고서를 실행하여 미리 계획합니다. 카드나 공지사항을 준비할 시간을 갖기 위해 전체 월을 포함하도록 날짜 범위를 설정할 수 있습니다.
:::

:::info
생일 데이터는 각 사람의 프로필에 있는 생년월일 필드에서 나옵니다. 정확한 결과를 위해 [회원 기록](../people/adding-people.md)이 최신 상태인지 확인합니다.
:::
