# 생일 및 기념일 목록

<div class="article-intro">

주어진 달에 생일이나 기념일이 있는 모든 사람의 목록이 필요합니까 — 게시판, 공지 또는 카드를 위해? 사람 검색은 **출생월** 및 **기념일 월**로 교회를 필터링하고 결과에서 직접 날짜를 표시할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 각 사람의 프로필에 생년월일(및 기념일)이 입력되어 있는지 확인합니다. [사람 추가](../people/adding-people.md)를 참조하세요.
- 사람을 볼 수 있는 권한이 필요합니다. [역할 및 권한](../settings/roles-permissions.md)을 참조하세요.

</div>

## 월간 생일 목록 받기

1. 왼쪽 상단의 **섹션 메뉴**를 열고 **사람**을 선택합니다.
2. 검색 상자 아래에서 **고급**을 클릭합니다.
3. **인구통계** 섹션을 확장하고 **출생월**을 확인한 후 월을 선택합니다.
4. 검색을 실행합니다 — 그 달에 생일이 있는 모든 사람이 결과에 나타납니다.
5. 날짜를 보려면 결과 오른쪽 상단의 **열 아이콘**을 클릭하고 **생일** 열을 활성화합니다. 스프레드시트에서 정렬하거나 인쇄하려면 **내보내기**를 사용하여 목록을 다운로드합니다.

## 기념일 목록 받기

동일한 단계입니다 — **인구통계** 섹션에서 대신 **기념일 월**을 확인(또는 함께)하고, 월을 선택한 후 결과에서 **기념일** 열을 활성화합니다.

## 실제 용도

- **주간 게시판** -- 현재 달의 목록을 실행하고 게시판이나 공지에 이름을 바로 읽으세요.
- **생일 및 기념일 카드** -- 달의 목록을 내보내고 카드 쓰기 팀에 전달합니다.
- **이정표** -- **나이** 필터와 결합하여 이정표 생일을 찾습니다.

:::tip
두 목록 모두 각 사람의 프로필의 생년월일 및 기념일 필드에서 나옵니다 — 누군가 누락된 경우 프로필에 날짜를 추가하면 됩니다.
:::

:::info
이전 버전의 B1 Admin에는 생일을 위한 별도의 보고서 페이지가 있었습니다. 해당 페이지는 폐기되었습니다 — 현재 방법은 위의 사람 검색 필터이며 기념일도 포함합니다.
:::
