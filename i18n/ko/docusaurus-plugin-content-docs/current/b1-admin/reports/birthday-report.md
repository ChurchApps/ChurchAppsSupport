# 생일 및 기념일 목록

<div class="article-intro">

주보, 공지, 카드에 쓰기 위해 특정 월에 생일이나 기념일이 있는 모든 사람의 목록이 필요하신가요? 사람 검색에서 **Birth Month**(생일 월)와 **Anniversary Month**(기념일 월)로 교인을 필터링하고, 결과에서 바로 날짜를 확인할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 각 사람의 프로필에 생년월일(및 기념일)이 입력되어 있는지 확인하세요. [사람 추가하기](../people/adding-people.md)를 참고하세요.
- 사람 정보를 볼 수 있는 권한이 필요합니다. [역할 및 권한](../settings/roles-permissions.md)을 참고하세요.

</div>

## 월별 생일 목록 만들기 {#getting-a-birthday-list-for-a-month}

1. [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 상단의 검색창)를 열고 **People**(사람)을 펼친 다음 **People**을 클릭하세요.
2. 검색창 아래에서 **Advanced**(고급)를 클릭하세요.
3. **Demographics**(인구통계) 섹션을 펼치고 **Birth Month**(생일 월)를 체크한 다음 월을 선택하세요.
4. 필터를 체크하는 즉시 결과가 업데이트되며, 해당 월에 생일인 모든 사람이 나타납니다.
5. 날짜를 보려면 **View as**(보기 방식)를 **Table**(표)로 바꾸고, 페이지 상단의 **Select columns**(열 선택) 아이콘을 클릭한 다음 **Birth Date**(생년월일) 열을 켜세요(연도를 빼려면 **Birthday (No Year)**(생일(연도 제외))를 선택하세요). 스프레드시트에서 정렬하거나 인쇄하고 싶다면 **Export**(내보내기)를 사용해 목록을 스프레드시트로 다운로드하세요.

## 기념일 목록 만들기 {#getting-an-anniversary-list}

같은 단계를 따르되, **Demographics** 섹션에서 **Anniversary Month**(기념일 월)를 대신(또는 추가로) 체크하고, 월을 선택한 다음 결과에서 **Anniversary**(기념일) 열을 켜세요.

## 실제 활용 방법 {#practical-uses}

- **주간 주보** -- 이번 달 목록을 실행해 이름을 주보에 바로 옮기세요.
- **생일 및 기념일 카드** -- 해당 월의 목록을 내보내 카드 작성 팀에 전달하세요.
- **기념일 축하** -- **Age**(나이) 필터와 함께 사용하면 특별한 나이를 맞이하는 생일을 찾을 수 있습니다.

:::tip
두 목록 모두 각 사람의 프로필에 있는 생년월일과 기념일 필드에서 가져옵니다. 누군가 목록에 없다면 프로필에 날짜를 추가하기만 하면 됩니다.
:::

:::info
이전 버전의 B1 Admin에서는 메뉴에서 별도의 생일 보고서로 연결되었습니다. 해당 링크는 제거되었습니다. 위의 사람 검색 필터가 현재 방식이며, 기념일도 포함합니다.
:::
