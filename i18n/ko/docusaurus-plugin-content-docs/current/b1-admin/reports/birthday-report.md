# 생일 & 기념일 목록
<div class="article-intro">
특정 월의 생일이나 기념일이 있는 모든 사람의 목록이 필요하신가요? 사람 검색은 **생일 월** 및 **기념일 월**로 필터링하고 결과에 날짜를 표시할 수 있습니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- 각 사람의 프로필에 생일(및 기념일)이 입력되어야 합니다
- 사람을 볼 수 있는 권한이 필요합니다
</div>
## 월별 생일 목록 가져오기
1. **섹션 메뉴**를 열고 **사람들**을 선택합니다
2. 검색 상자 아래 **고급**을 클릭합니다
3. **인구통계** 섹션을 펼치고 **생일 월**을 선택한 후 월을 선택합니다
4. 검색을 실행합니다
5. 결과에서 **생일** 열을 활성화하려면 위의 **열 아이콘**을 클릭합니다
## 기념일 목록 가져오기
동일한 단계를 따르되, **기념일 월**을 선택합니다.
