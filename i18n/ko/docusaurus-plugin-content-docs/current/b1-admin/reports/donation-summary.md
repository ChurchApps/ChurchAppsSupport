# 기부금 요약

<div class="article-intro">

기부금 요약 보고서는 교회의 기부 활동을 명확하게 보여줍니다. 기부금 합계를 추적하고, 기부 추세를 모니터링하며, 리더십 팀을 위한 재무 보고서를 준비하는 데 사용합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 기부금이 시스템에서 [일관되게 기록](../donations/recording-donations.md)되는지 확인합니다
- 재무 보고서에 액세스할 적절한 [권한](../settings/roles-permissions.md)이 필요합니다

</div>

## 보고서 실행

1. 브라우저에서 **admin.b1.church/reports/donationSummary**로 직접 이동합니다 (보고서는 탐색 메뉴에 항목이 없습니다. 주소를 북마크하는 것이 가장 쉬운 방법입니다).
2. 보고 기간을 정의할 **날짜 범위**를 설정합니다.
3. **기금** 또는 기타 기준과 같은 추가 필터를 적용하여 결과를 좁힙니다.
4. 보고서는 선택한 기간의 기부 요약을 표시합니다.

## 보고서 내용

기부금 요약 보고서에는 다음이 포함됩니다:

- **총 기부금** - 선택한 기간의 전체 기부 금액입니다.
- **기부자 수** - 기여한 고유 기부자의 수입니다.
- **기금별 금액** - 해당되는 경우 다양한 기금 전반의 기부 분석입니다.

## 실용적인 사용

- **재무 계획** - 기부 추세를 검토하여 향후 소득을 예측하고 예산을 계획합니다.
- **이사회 보고서** - 정기적인 이사회 또는 리더십 회의를 위한 명확한 기부 데이터가 포함된 요약을 생성합니다.
- **연말 검토** - 전체 연도에 대한 보고서를 실행하여 연간 재무 요약을 준비합니다.
- **캠페인 추적** - 기금별로 필터링하여 특별 기부 캠페인 또는 건축 프로젝트의 진행 상황을 추적합니다.
- **계절 분석** - 다양한 기간에 걸쳐 기부를 비교하여 계절 패턴을 이해합니다.

:::tip
월별로 이 보고서를 실행하여 교회의 재무 건강에 대해 알 수 있습니다. 월별 데이터를 비교하면 추세를 조기에 발견하는 데 도움이 됩니다.
:::

:::warning
기부금 데이터는 시스템에 기록된 기여에서 나옵니다. 온라인 기부, 수표 처리 또는 수동 입력 여부를 불문하고 기부금이 일관되게 입력되는지 확인합니다. 정확한 보고서를 위해 [기부금 기록](../donations/recording-donations.md)을 참조합니다.
:::
