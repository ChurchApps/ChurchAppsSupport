# 헌금 요약

<div class="article-intro">

헌금 요약 보고서는 교회의 헌금 활동을 한눈에 보여줍니다. 헌금 총액을 추적하고, 헌금 추세를 모니터링하며, 리더십 팀을 위한 재정 보고서를 준비하는 데 사용하세요.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 시스템에 헌금이 [일관되게 기록](../donations/recording-donations.md)되고 있는지 확인하세요
- **View Donation Summaries**(헌금 요약 보기) [권한](../settings/roles-permissions.md)이 필요합니다

</div>

## 보고서 실행하기 {#running-the-report}

1. [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 상단의 검색창)를 열고 **Donations**(헌금)를 펼친 다음 **Summary**(요약)를 클릭하세요. 보고서는 지난 1년 기준으로 바로 실행됩니다.
2. **Weekly**(주간), **Monthly**(월간), **Quarterly**(분기) 중 하나를 선택하여 헌금을 묶는 단위를 설정하세요.
3. **Filter Report**(보고서 필터) 패널에서 **Start Date**(시작일)와 **End Date**(종료일)를 설정하고, 필요하면 **Fund**(헌금 항목)를 선택한 다음 **Run Report**(보고서 실행)를 클릭하세요.
4. **Download Options**(다운로드 옵션)를 클릭하고 **Summary**(요약)를 선택하면 총계를 CSV로 다운로드할 수 있습니다. 보고서를 인쇄하려면 프린터 아이콘을 클릭하세요.

이 페이지에 대한 자세한 내용은 [헌금 보고서](../donations/donation-reports.md#giving-dashboard)를 참고하세요.

## 보고서 내용 {#what-the-report-shows}

헌금 요약에는 다음 항목이 포함됩니다.

- **Total Giving**(총 헌금) -- 선택한 기간의 전체 헌금액입니다.
- **Average Gift**(평균 헌금)과 **Total Donations**(총 헌금 건수) -- 일반적인 헌금 금액과 헌금 건수입니다.
- **Unique Donors**(고유 헌금자) -- 헌금에 참여한 고유한 사람의 수입니다.
- **Amounts by fund**(헌금 항목별 금액) -- 주, 월 또는 분기별 헌금을 헌금 항목별로 나눈 막대 그래프입니다.

## 실제 활용 방법 {#practical-uses}

- **재정 계획** -- 헌금 추세를 검토하여 향후 수입을 예측하고 예산을 계획하세요.
- **이사회 보고** -- 명확한 헌금 데이터를 바탕으로 정기 이사회나 리더십 회의에 필요한 요약을 만드세요.
- **연말 검토** -- 전체 연도 기준으로 보고서를 실행하여 연간 재정 요약을 준비하세요.
- **캠페인 추적** -- 헌금 항목으로 필터링하여 특별 헌금 캠페인이나 건축 프로젝트의 진행 상황을 추적하세요.
- **계절별 분석** -- 여러 기간의 헌금을 비교하여 계절적 패턴을 파악하세요.

:::tip
교회의 재정 상태를 계속 파악할 수 있도록 이 보고서를 매월 실행하세요. 전월 대비 데이터를 비교하면 추세를 조기에 발견하는 데 도움이 됩니다.
:::

:::warning
헌금 데이터는 시스템에 기록된 헌금에서 가져옵니다. 가장 정확한 보고서를 얻으려면 온라인 헌금, 수표 처리, 수동 입력 등 어떤 방식이든 헌금이 일관되게 입력되고 있는지 확인하세요. 자세한 내용은 [헌금 기록하기](../donations/recording-donations.md)를 참고하세요.
:::
