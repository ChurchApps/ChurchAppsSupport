# 감사 로그

<div class="article-intro">

감사 로그는 교회 관리 시스템에서 이루어진 중요한 모든 작업과 변경 사항을 기록합니다. 로그인 활동을 검토하고, 사람 기록을 누가 바꾸었는지 추적하며, 권한 변경을 모니터링하고, 팀 전체의 책임성을 유지하는 데 사용하세요.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 서버 관리자 권한이 있는 B1 Admin 계정이 필요합니다.
- **설정**으로 이동하여 감사 로그를 찾으세요.

</div>

## 감사 로그 보기

1. [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 상단의 검색 표시줄)를 열고 **설정**을 펼칩니다.
2. **감사 로그**를 클릭합니다.
3. 로그에는 최근 항목이 다음 열을 가진 표로 나타납니다:
   - **날짜** -- 작업이 일어난 시각입니다.
   - **분류** -- 작업의 종류입니다(빠르게 훑어볼 수 있도록 색으로 구분됩니다).
   - **작업** -- 무엇을 했는지입니다(예: create, update, delete, login_success).
   - **대상** -- 영향을 받은 기록의 종류와 ID입니다.
   - **IP 주소** -- 작업을 수행한 사용자의 IP 주소입니다.
   - **세부 정보** -- 구체적으로 바뀐 내용의 요약입니다.

## 로그 필터링하기

페이지 상단의 필터를 사용해 결과를 좁힐 수 있습니다:

- **분류** -- 작업 종류별로 걸러 보기:
  - **모든 분류** -- 전부 표시합니다.
  - **로그인** -- 로그인 성공과 실패입니다.
  - **사람** -- 사람 기록의 생성, 수정, 삭제입니다.
  - **권한** -- 권한 부여와 회수입니다.
  - **헌금** -- 헌금 기록의 변경입니다.
  - **그룹** -- 그룹 관리 작업입니다.
  - **양식** -- 양식 제출 활동입니다.
  - **설정** -- 구성 변경입니다.
- **시작일** -- 이 날짜 이후의 항목을 보여 줍니다.
- **종료일** -- 이 날짜까지의 항목을 보여 줍니다.

필터를 설정한 뒤 **검색**을 클릭하면 결과가 갱신됩니다.

## 분류 이해하기

각 분류는 쉽게 구별할 수 있도록 색으로 표시됩니다:

- **로그인** -- 파란색 칩. 성공과 실패한 로그인 시도를 추적합니다.
- **사람** -- 보라색 칩. 사람 기록의 생성, 수정, 삭제를 추적합니다.
- **권한** -- 빨간색 칩. 접근 권한이 부여되거나 회수될 때를 추적합니다.
- **헌금** -- 초록색 칩. 헌금 기록의 변경을 추적합니다.
- **그룹** -- 회색 칩. 그룹 관리 작업을 추적합니다.
- **양식** -- 주황색 칩. 양식 제출 활동을 추적합니다.
- **설정** -- 노란색 칩. 구성 변경을 추적합니다.

## 사람과 그룹의 메모 이력

감사 로그를 열 수 있다면, 변경된 메모의 기록도 메모가 있는 곳, 즉 사람이나 그룹의 **메모** 탭에서 바로 볼 수 있습니다:

1. 수정된 메모는 날짜 옆에 **(수정됨 · 이력 보기)**가 표시됩니다. 이를 클릭하면 그 사람이나 그룹의 메모 이력으로 필터링된 감사 로그가 열립니다.
2. 삭제된 메모는 자리에 회색 **삭제된 메모** 표시를 남기며, 누가 작성했는지, 언제 게시되었는지, 언제 삭제되었는지를 보여 줍니다. **이력 보기**를 클릭하면 같은 필터가 적용된 로그가 열립니다.
3. 필터링된 로그에서 **메모 수정됨** 또는 **메모 삭제됨** 항목을 펼치면 이전 텍스트와 변경을 한 계정을 볼 수 있습니다. 필터를 지우려면 **모두 보기**를 클릭하세요.
4. **대상** 열에서 사람이나 그룹 메모의 ID는 그 사람이나 그룹의 메모로 연결됩니다.

감사 로그를 열 수 없는 직원은 이러한 표시 없이 메모 목록을 봅니다.

## 로그 내보내기

로그 항목이 표시되면 **CSV 다운로드** 버튼이 나타납니다. 이를 클릭하면 현재 필터가 적용된 결과를 스프레드시트로 내보내 오프라인 검토나 기록 보관에 쓸 수 있습니다.

## 페이지 나누기

표 아래의 페이지 나누기 컨트롤로 결과 사이를 이동할 수 있습니다. 한 페이지에 25, 50, 100개 항목을 표시할 수 있습니다.

:::info
감사 로그 항목은 자동으로 1년 동안 보관됩니다. 365일이 지난 항목은 시스템 성능을 위해 삭제됩니다.
:::

:::tip
특히 새 팀원을 맞이했거나 중요한 구성 변경을 한 뒤에는 감사 로그를 정기적으로 검토하세요. 예상치 못한 활동을 일찍 찾아내는 데 도움이 됩니다.
:::
