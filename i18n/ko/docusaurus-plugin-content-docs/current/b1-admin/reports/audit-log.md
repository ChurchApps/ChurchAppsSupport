# 감사 로그

<div class="article-intro">

감사 로그는 교회 관리 시스템 전반의 주요 작업과 변경 사항을 기록합니다. 로그인 활동을 검토하고, 사람 기록을 누가 변경했는지 추적하고, 권한 업데이트를 모니터링하여 팀 전체의 책임성을 유지하는 데 사용하세요.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- **Edit Church Settings**(교회 설정 편집) 권한이 있는 역할이 필요합니다(역할 권한의 **Content**(콘텐츠) 섹션에 있으며, **Settings**(설정)를 여는 것과 같은 권한입니다). [역할 및 권한](../settings/roles-permissions.md)을 참고하세요.

</div>

## 감사 로그 보기 {#viewing-the-audit-log}

1. [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 상단의 검색창)를 열고 **Settings**(설정)를 펼치세요.
2. **Audit Log**(감사 로그)를 클릭하세요.
3. 로그에는 최근 항목이 다음 열이 있는 표로 표시됩니다.
   - **Date**(날짜) -- 작업이 발생한 시점입니다.
   - **Module**(모듈) -- 변경이 이루어진 B1의 영역입니다(예: 멤버십 또는 헌금).
   - **Category**(분류) -- 기록 또는 작업의 유형입니다(빠르게 훑어볼 수 있도록 색으로 구분됩니다).
   - **Action**(작업) -- 수행된 작업입니다(예: Donation Saved, Login Success, Note Updated).
   - **Entity**(개체) -- 영향을 받은 기록의 유형과 ID입니다.
   - **IP Address**(IP 주소) -- 작업을 수행한 사용자의 IP 주소입니다.
4. 행 시작 부분의 화살표를 클릭하면 세부 정보를 볼 수 있습니다. 변경된 각 필드의 **Old Value**(이전 값)와 **New Value**(새 값)가 표로 표시되며, 삭제 작업의 경우 **Deleted Record**(삭제된 기록)가 표시됩니다.

## 로그 필터링 {#filtering-the-log}

페이지 상단의 필터를 사용해 결과를 좁힐 수 있습니다.

- **Module**(모듈) -- 영역별로 필터링합니다: **All Modules**(전체 모듈), **People**(사람), **Giving**(헌금), **Attendance**(출석), **Messaging**(메시지), **Content**(콘텐츠), **Serving**(봉사), 또는 **Lessons**(수업).
- **Category**(분류) -- 작업 유형별로 필터링합니다.
  - **All Categories**(전체 분류) -- 모든 항목을 표시합니다.
  - **Login**(로그인) -- 로그인 성공 및 실패입니다.
  - **People**(사람) -- 사람 기록의 생성, 수정, 삭제입니다.
  - **Permissions**(권한) -- 권한 부여 및 취소입니다.
  - **Donations**(헌금) -- 헌금 기록 변경입니다.
  - **Groups**(그룹) -- 그룹 관리 작업입니다.
  - **Forms**(양식) -- 양식 제출 활동입니다.
  - **Settings**(설정) -- 구성 변경입니다.
- **Start Date**(시작일) -- 이 날짜 이후의 항목을 표시합니다.
- **End Date**(종료일) -- 이 날짜까지의 항목을 표시합니다.

필터를 설정한 다음 **Search**(검색)를 클릭하면 결과가 업데이트됩니다.

## 분류 이해하기 {#understanding-categories}

각 항목의 분류는 색으로 구분된 칩으로 표시되어 빠르게 식별할 수 있습니다.

- **login**(로그인) -- 파란색 칩. 로그인 성공과 실패 시도를 추적합니다.
- **person**(사람) -- 파란색 칩. 사람 기록의 생성, 수정, 삭제를 추적합니다.
- **permission**(권한) -- 빨간색 칩. 접근 권한이 부여되거나 취소되는 시점을 추적합니다.
- **donation**(헌금) -- 초록색 칩. 헌금 기록 변경을 추적합니다.
- **form**(양식) -- 주황색 칩. 양식 제출 활동을 추적합니다.
- **group**(그룹), **settings**(설정), 그리고 **userchurch**(사용자 교회) 같은 기타 분류 -- 회색 칩.

## 사람과 그룹의 메모 기록 {#note-history-on-people-and-groups}

감사 로그를 열 수 있는 경우, 사람 또는 그룹의 **Notes**(메모) 탭에서 메모가 있는 위치에 바로 변경된 메모의 기록도 볼 수 있습니다.

1. 수정된 메모는 날짜 옆에 **(edited · view history)**((수정됨 · 기록 보기))로 표시됩니다. 이를 클릭하면 해당 사람이나 그룹의 메모 기록으로 필터링된 감사 로그가 열립니다.
2. 삭제된 메모는 회색으로 표시된 **Deleted note**(삭제된 메모) 표시로 대체되며, 누가 작성했는지, 언제 게시되었는지, 언제 삭제되었는지가 보입니다. **View history**(기록 보기)를 클릭하면 같은 필터가 적용된 로그가 열립니다.
3. 필터가 적용된 로그에서 **Note Updated**(메모 수정됨) 또는 **Note Deleted**(메모 삭제됨) 항목을 펼치면 이전 텍스트와 변경을 수행한 계정을 확인할 수 있습니다. 필터를 해제하려면 **Show all**(모두 보기)을 클릭하세요.
4. **Entity**(개체) 열에서 사람 또는 그룹 메모의 ID를 클릭하면 해당 사람이나 그룹의 메모로 돌아갑니다.

감사 로그를 열 수 없는 직원에게는 이러한 표시 없이 메모 목록만 보입니다.

## 로그 내보내기 {#exporting-the-log}

로그 항목이 표시되면 페이지 상단에 **Export CSV**(CSV 내보내기) 버튼이 나타납니다. 이를 클릭하면 현재 필터링된 결과를 스프레드시트로 내보내 오프라인에서 검토하거나 기록을 보관할 수 있습니다.

## 페이지 나누기 {#pagination}

표 하단의 페이지 나누기 컨트롤을 사용해 결과를 이동할 수 있습니다. 페이지당 25개, 50개(기본값), 또는 100개의 항목을 표시할 수 있습니다.

:::info
감사 로그 항목은 자동으로 1년 동안 보관됩니다. 365일이 지난 항목은 시스템 성능을 유지하기 위해 삭제됩니다.
:::

:::tip
특히 새로운 팀원을 온보딩하거나 중요한 설정을 변경한 후에는 감사 로그를 정기적으로 검토하세요. 예상치 못한 활동을 조기에 발견하는 데 도움이 됩니다.
:::
