# 감사 로그

<div class="article-intro">

감사 로그는 교회 관리 시스템 전체에서 모든 중요한 작업과 변경사항을 추적합니다. 로그인 활동을 검토하고, 누가 사람 기록을 변경했는지 추적하고, 권한 업데이트를 모니터링하며, 팀 전체의 책임을 유지하려면 사용하세요.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 서버 관리자 접근권이 있는 B1 Admin 계정
- **Settings**으로 이동하여 감사 로그 찾기

</div>

## 감사 로그 보기

1. B1 Admin의 왼쪽 상단에 있는 검색 모음인 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)를 열고 **Settings**을 확장하세요.
2. **Audit Log**를 클릭하세요.
3. 로그는 다음 열이 있는 표에 최근 항목을 표시합니다:
   - **Date** -- 작업이 발생한 시간.
   - **Category** -- 작업의 유형(빠른 스캔을 위해 색상 코드됨).
   - **Action** -- 수행된 작업(예: create, update, delete, login_success).
   - **Entity** -- 영향을 받은 기록의 유형 및 ID.
   - **IP Address** -- 작업을 수행한 사용자의 IP 주소.
   - **Details** -- 수행된 특정 변경사항의 요약.

## 로그 필터링

페이지 상단의 필터를 사용하여 결과를 좁히세요:

- **Category** -- 작업 유형별 필터:
  - **All Categories** -- 모든 것을 표시.
  - **Login** -- 로그인 성공 및 실패.
  - **People** -- 사람 기록 생성, 업데이트 또는 삭제.
  - **Permissions** -- 권한 부여 및 취소.
  - **Donations** -- 기부금 기록 변경.
  - **Groups** -- 그룹 관리 작업.
  - **Forms** -- 양식 제출 활동.
  - **Settings** -- 구성 변경.
- **Start Date** -- 이 날짜부터의 항목을 표시.
- **End Date** -- 이 날짜까지의 항목을 표시.

필터를 설정한 후 **Search**를 클릭하여 결과를 업데이트하세요.

## 카테고리 이해

각 카테고리는 빠른 식별을 위해 색상 코드됩니다:

- **Login** -- 파란색 칩. 성공 및 실패한 로그인 시도를 추적.
- **People** -- 보라색 칩. 사람 기록의 생성, 업데이트, 삭제를 추적.
- **Permissions** -- 빨간색 칩. 접근 권한의 부여 또는 취소를 추적.
- **Donations** -- 초록색 칩. 기부금 기록 변경을 추적.
- **Groups** -- 회색 칩. 그룹 관리 작업을 추적.
- **Forms** -- 주황색 칩. 양식 제출 활동을 추적.
- **Settings** -- 노란색 칩. 구성 변경을 추적.

## 로그 내보내기

로그 항목이 표시될 때, **CSV 다운로드** 버튼이 나타납니다. 오프라인 검토 또는 기록 유지를 위해 현재 필터링된 결과를 스프레드시트로 내보내려면 클릭하세요.

## 페이지 나누기

표 하단의 페이지 나누기 컨트롤을 사용하여 결과를 탐색하세요. 한 페이지당 25, 50 또는 100개 항목을 표시할 수 있습니다.

:::info
감사 로그 항목은 자동으로 1년 동안 유지됩니다. 365일보다 오래된 항목은 시스템을 성능 있게 유지하기 위해 제거됩니다.
:::

:::tip
특히 새 팀 멤버를 온보딩한 후 또는 중요한 구성 변경을 한 후 감사 로그를 정기적으로 검토하세요. 예상치 못한 활동을 조기에 식별하는 데 도움이 됩니다.
:::
