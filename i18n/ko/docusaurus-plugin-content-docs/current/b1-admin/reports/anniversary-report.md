# 기념일 목록

<div class="article-intro">

주어진 달에 결혼기념일이 있는 모든 사람의 목록이 필요하신가요 -- 주보, 카드 또는 공지사항용? People 검색을 사용하면 **Anniversary Month**로 필터링하고 결과에 날짜를 바로 표시할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 각 사람의 프로필에 결혼기념일 날짜가 입력되어 있는지 확인하세요. 자세한 내용은 [Adding People](../people/adding-people.md)를 참고하세요.
- People을 볼 수 있는 권한이 필요합니다. [Roles & Permissions](../settings/roles-permissions.md)을 참고하세요.

</div>

## 한 달의 기념일 목록 가져오기

1. B1 Admin의 왼쪽 상단에 있는 검색 모음인 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)를 열고 **People**을 확장한 다음 **People**을 클릭하세요.
2. 검색 상자 아래에서 **Advanced**를 클릭하세요.
3. **Demographics** 섹션을 확장하고 **Anniversary Month**를 선택한 다음 달을 선택하세요.
4. 검색을 실행하세요 -- 그 달에 기념일이 있는 모든 사람이 결과에 나타납니다.
5. 날짜를 보려면, 결과의 오른쪽 상단에서 **열 아이콘**을 클릭하고 **Anniversary** 열을 활성화하세요. 스프레드시트로 정렬하거나 인쇄하는 것을 선호하면 **Export**를 사용하여 목록을 다운로드하세요.

## 실질적인 사용

- **주간 주보** -- 현재 달의 목록을 실행하고 기념일을 주보나 공지사항에 포함시키세요.
- **기념일 카드** -- 달의 목록을 내보내고 카드 작성 팀에 넘기세요.
- **마일스톤 축하** -- **Years Married** 필터와 결합하여 마일스톤 기념일을 찾으세요.

:::tip
각 달이 시작될 때 실행하면 기념일이 도래하기 전에 카드나 공지사항을 준비할 시간이 있습니다.
:::

:::info
기념일 데이터는 각 사람의 프로필의 기념일 필드에서 옵니다. 누군가가 없다면, 해당 프로필에 날짜만 추가하면 됩니다. [Adding People](../people/adding-people.md)를 참고하세요.
:::
