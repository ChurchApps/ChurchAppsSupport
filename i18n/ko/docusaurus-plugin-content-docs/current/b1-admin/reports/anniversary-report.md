# 기념일 목록

<div class="article-intro">

주어진 달에 결혼 기념일이 있는 모든 사람의 목록이 필요합니까 — 게시판, 카드 또는 공지를 위해? 사람 검색을 통해 **기념일 월**로 필터링하고 결과에서 직접 날짜를 표시할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 각 사람의 프로필에 기념일 날짜가 입력되어 있는지 확인합니다. 세부 정보는 [사람 추가](../people/adding-people.md)를 참조하세요.
- 사람을 볼 수 있는 권한이 필요합니다. [역할 및 권한](../settings/roles-permissions.md)을 참조하세요.

</div>

## 월간 기념일 목록 받기

1. 왼쪽 상단의 **섹션 메뉴**를 열고 **사람**을 선택합니다.
2. 검색 상자 아래에서 **고급**을 클릭합니다.
3. **인구통계** 섹션을 확장하고 **기념일 월**을 확인한 후 월을 선택합니다.
4. 검색을 실행합니다 — 그 달에 기념일이 있는 모든 사람이 결과에 나타납니다.
5. 날짜를 보려면 결과 오른쪽 상단의 **열 아이콘**을 클릭하고 **기념일** 열을 활성화합니다. 스프레드시트로 정렬하거나 인쇄하려면 **내보내기**를 사용하여 목록을 다운로드합니다.

## 실제 용도

- **주간 게시판** -- 현재 달의 목록을 실행하고 게시판이나 공지에 기념일을 포함합니다.
- **기념일 카드** -- 달의 목록을 내보내고 카드 쓰기 팀에 전달합니다.
- **이정표 축하** -- **혼인 연수** 필터와 결합하여 이정표 기념일을 찾습니다.

:::tip
기념일이 도착하기 전에 카드나 공지를 준비할 시간을 가질 수 있도록 매달 초에 이를 실행합니다.
:::

:::info
기념일 데이터는 각 사람의 프로필의 기념일 필드에서 나옵니다. 누군가 누락된 경우 프로필에 날짜를 추가하면 됩니다. [사람 추가](../people/adding-people.md)를 참조하세요.
:::
