# 결혼기념일 목록

<div class="article-intro">

주보, 카드 또는 공지를 위해 특정 달에 결혼기념일이 있는 모든 사람의 목록이 필요하신가요? People 검색에서 **Anniversary Month**로 필터링하고, 결과에서 바로 날짜를 표시할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 각 사람의 프로필에 결혼기념일이 입력되어 있는지 확인하세요. 자세한 내용은 [사람 추가하기](../people/adding-people.md)를 참고하세요.
- People을 볼 수 있는 권한이 필요합니다. [역할 및 권한](../settings/roles-permissions.md)을 참고하세요.

</div>

## 한 달의 결혼기념일 목록 만들기 {#getting-an-anniversary-list-for-a-month}

1. [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 위의 검색창)를 열고 **People**을 펼친 다음 **People**을 클릭하세요.
2. 검색창 아래에서 **Advanced**를 클릭하세요.
3. **Demographics** 섹션을 펼치고 **Anniversary Month**를 체크한 다음 달을 고르세요.
4. 필터를 체크하는 즉시 결과가 업데이트됩니다. 그 달에 결혼기념일이 있는 모든 사람이 나타납니다.
5. 날짜를 보려면 **View as**를 **Table**로 전환한 다음, 페이지 머리글의 **Select columns** 아이콘을 클릭하고 **Anniversary** 열을 켜세요. 목록을 정렬하거나 인쇄하고 싶다면 **Export**를 사용하여 스프레드시트로 내려받으세요.

## 실제 활용 {#practical-uses}

- **주간 주보** -- 이번 달 목록을 실행하여 주보나 공지에 결혼기념일을 포함하세요.
- **결혼기념일 카드** -- 이번 달 목록을 내보내 카드를 쓰는 팀에 전달하세요.
- **기념일 축하** -- **Years Married** 필터와 함께 사용하여 의미 있는 기념일(마일스톤)을 찾으세요.

:::tip
매달 초에 이 목록을 실행하면, 기념일이 오기 전에 카드나 공지를 준비할 시간이 있습니다.
:::

:::info
결혼기념일 데이터는 각 사람의 프로필에 있는 기념일 필드에서 가져옵니다. 누군가 빠져 있다면, 그 사람의 프로필에 날짜를 추가하기만 하면 됩니다. [사람 추가하기](../people/adding-people.md)를 참고하세요.
:::
