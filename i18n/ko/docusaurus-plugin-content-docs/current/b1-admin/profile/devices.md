# 기기 관리하기

<div class="article-intro">

기기 페이지에서는 계정에 연결된 ChurchAppsPlayer 및 FreePlay 기기를 관리할 수 있습니다. 이 기기들은 교회 장소의 화면에 콘텐츠를 스트리밍하고 미디어를 표시하는 데 사용됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- ChurchAppsPlayer 또는 FreePlay 기기가 켜져 있고 인터넷에 연결되어 있어야 합니다.
- 기기 화면에 표시된 페어링 코드를 확인하세요.
- 아직 확인하지 않았다면 [프로필 설정](./managing-profile.md)을 검토하세요.

</div>

## 기기 페이지 열기 {#opening-the-devices-page}

[점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 위의 검색창)를 열고 **Devices**를 입력한 다음 선택하세요. 프로필 페이지에 있을 때는 점프 메뉴에 **Profile**과 **Devices**가 나란히 표시됩니다.

## 기기 확인하기 {#viewing-your-devices}

기기 페이지를 열면, 계정에 페어링된 ChurchAppsPlayer 및 FreePlay 화면을 나열한 표가 나타나며 다음 정보가 표시됩니다:

- **Label** -- 기기에 지정한 이름(이름을 붙이기 전에는 **Device**).
- **Registration Date** -- 기기가 처음 계정에 페어링된 날짜.
- **Last Active Date** -- 기기가 계정에 마지막으로 연결된 시각.

## 새 기기 추가하기 {#adding-a-new-device}

1. 기기 페이지 상단의 **Add Screen** 버튼을 클릭하세요.
2. 연결하려는 ChurchAppsPlayer 또는 FreePlay 기기에 표시된 페어링 코드를 찾으세요.
3. **Pairing Code** 필드에 입력하세요.
4. 교회에 [계획 유형](../serving/plans.md)이 설정되어 있다면, **Show Plans For** 드롭다운에서 FreePlay 화면이 따라갈 계획 유형을 고를 수 있습니다. 기기를 탐색과 알림 용도로만 쓰려면 **None (notifications only**)로 두세요.
5. **Save**를 클릭하세요. 페어링되면 기기가 기기 표에 나타납니다. 코드가 잘못되었거나 만료되었다면 *"Invalid pairing code"*가 표시됩니다.

:::tip
페어링을 시도하기 전에 기기가 켜져 있고 인터넷에 연결되어 있는지 확인하세요. 페어링 코드는 기기 화면에 표시됩니다.
:::

## 기기 레이블 편집하기 {#editing-a-device-label}

1. 기기 표에서 기기 옆의 **Edit**를 클릭하세요.
2. **Label**을 설명이 잘 드러나는 이름으로 바꾸세요(예: "Sanctuary Main Screen" 또는 "Lobby Display").
3. **Save**를 클릭하세요.

**Edit Device** 양식에는 교회의 Lessons.church 교실 목록인 **Associated Content**도 있습니다. 교실을 체크하면 화면과 연결되며, 각 체크 상자는 클릭하는 즉시 저장됩니다.

:::tip
명확하고 설명이 잘 드러나는 레이블을 쓰면, 특히 교회에 화면이 여러 개 설정되어 있을 때 어떤 기기가 어느 것인지 쉽게 알 수 있습니다.
:::

## 기기 접근 관리하기 {#managing-device-access}

기기 페이지를 사용하여 어떤 기기가 교회의 스트리밍과 콘텐츠에 접근할 수 있는지 파악하세요. 더 이상 사용하지 않는 기기는 계정에서 제거하세요.

1. 기기 옆의 **Edit**를 클릭하세요.
2. **Remove**를 클릭한 다음, 확인을 위해 다시 **Remove**를 클릭하세요.

화면이 다시 연결되려면 새 페어링 코드가 필요합니다.

:::warning
연결된 기기를 정기적으로 검토하여 활성 상태이고 승인된 기기만 계정에 연결되어 있는지 확인하세요. 보안을 유지하려면 더 이상 사용하지 않는 기기는 모두 제거하세요.
:::
