# 기기 관리

<div class="article-intro">

기기 페이지에서는 계정에 연결된 ChurchAppsPlayer 및 FreePlay 기기를 관리할 수 있습니다. 이 기기들은 콘텐츠 스트리밍과 교회 현장 화면에 미디어를 표시하는 데 사용됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- ChurchAppsPlayer 기기의 전원을 켜고 인터넷에 연결해 두세요
- 기기 화면에 표시되는 페어링 코드를 확인해 두세요
- 아직 확인하지 않았다면 [프로필 설정](./managing-profile.md)을 검토하세요

</div>

## 등록된 기기 보기

기기 페이지를 열면 등록된 모든 기기의 목록이 다음 정보와 함께 표시됩니다.

- **라벨** -- 기기에 지정한 이름입니다.
- **등록 날짜** -- 기기가 계정과 처음 페어링된 시점입니다.
- **최근 활동 날짜** -- 기기가 계정에 가장 최근에 연결된 시점입니다.

## 새 기기 추가하기

1. 기기 페이지 상단의 **기기 추가** 버튼을 클릭합니다.
2. **페어링 코드**를 입력하라는 메시지가 표시됩니다.
3. 연결하려는 ChurchAppsPlayer 또는 FreePlay 기기 화면에 표시된 페어링 코드를 확인합니다.
4. 코드를 입력합니다. FreePlay TV라면, **표시할 계획** 드롭다운에서 화면이 따라야 할 계획 유형을 선택할 수 있습니다 — 탐색과 알림 용도로만 사용하려면 **없음**으로 두세요.
5. 확인합니다. 페어링이 성공적으로 완료되면 기기가 기기 목록에 나타납니다.

:::tip
페어링을 시도하기 전에 기기의 전원이 켜져 있고 인터넷에 연결되어 있는지 확인하세요. 페어링 코드는 기기 화면에 표시됩니다.
:::

## 기기 라벨 편집하기

1. 기기 목록에서 **기기 이름**을 클릭합니다.
2. 라벨을 알아보기 쉬운 이름으로 업데이트합니다(예: "본당 메인 스크린" 또는 "로비 디스플레이").
3. 변경 사항을 저장합니다.

:::tip
명확하고 알아보기 쉬운 라벨을 사용하면 특히 교회에 여러 대의 화면이 설치되어 있을 때 어떤 기기가 어떤 것인지 쉽게 구분할 수 있습니다.
:::

## 기기 접근 관리하기

기기 페이지를 사용해 교회의 스트리밍 및 콘텐츠에 접근할 수 있는 기기를 파악하세요. 더 이상 사용하지 않는 기기가 있다면 계정에서 제거해 기기 목록을 깔끔하고 안전하게 유지할 수 있습니다.

:::warning
연결된 기기를 정기적으로 검토해 활성화되어 있고 승인된 기기만 계정에 연결되어 있는지 확인하세요. 더 이상 사용하지 않는 기기는 보안을 위해 제거하세요.
:::
