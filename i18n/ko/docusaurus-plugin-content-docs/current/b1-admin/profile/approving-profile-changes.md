# 프로필 변경 승인
<div class="article-intro">
교회에서 프로필 업데이트에 대한 관리자 승인이 필요한 경우, 회원은 B1 모바일 앱을 통해 변경을 제출하고 해당 요청이 B1 Admin의 작업으로 나타납니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- **모바일 → B1 모바일**에서 **디렉토리 승인 그룹**으로 지정된 그룹의 회원이어야 합니다
- 승인 그룹이 구성되지 않은 경우, 프로필 변경이 즉시 적용됩니다
</div>

## 보류 중인 요청 찾기

회원이 프로필 변경을 제출하면, 승인 그룹에 할당된 작업으로 나타납니다. 두 곳에서 찾을 수 있습니다:

**대시보드에서:**
1. B1 Admin에 로그인합니다
2. 오른쪽의 **작업** 섹션에서 **내 그룹에 할당** 탭을 클릭합니다
3. 보류 중인 프로필 변경 요청이 나열됩니다

**섬김 → 내 작업에서:**
1. 위의 네비게이션에서 **섬김**을 클릭합니다
2. **내 작업**을 클릭합니다
3. 작업 아래 **내 그룹에 할당** 탭을 클릭합니다

## 요청 검토 및 승인

1. **프로필 업데이트** 작업을 클릭하여 엽니다
2. **요청된 변경** 아래에서 회원이 업데이트하려는 각 필드를 볼 수 있습니다
3. 변경 사항을 검토합니다
4. **적용**을 클릭하여 승인하고 프로필에 변경 사항을 저장합니다

작업이 변경 사항이 적용되면 자동으로 닫힙니다.

## 승인 그룹 설정

교회에서 프로필 변경에 승인이 필요한 경우, 먼저 디렉토리 승인 그룹을 구성해야 합니다.

1. 위의 네비게이션에서 **모바일**을 클릭합니다
2. **B1 모바일**을 클릭합니다
3. **디렉토리 승인 그룹** 아래에서 프로필 변경 요청을 검토해야 하는 그룹의 회원을 선택합니다
4. **저장**을 클릭합니다

그 그룹의 모든 회원이 대시보드의 **내 그룹에 할당** 아래에서 들어오는 프로필 변경 요청을 볼 수 있습니다.

:::tip
승인자가 실제로 구성된 그룹의 회원인지 확인합니다 — 그룹 회원만 요청을 볼 수 있습니다.
:::
