# 프로필 변경 승인

<div class="article-intro">

교회에서 프로필 업데이트에 대한 관리자 승인이 필요한 경우 구성원은 B1 모바일 앱을 통해 변경사항을 제출하고 이러한 요청은 B1 Admin에서 작업으로 표시됩니다. 이 가이드에서는 이를 검토하고 승인하는 방법을 설명합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- **Mobile → B1 Mobile**에서 **디렉토리 승인 그룹**으로 지정된 그룹의 구성원이어야 합니다
- 승인 그룹이 구성되지 않은 경우 프로필 변경이 검토 없이 즉시 적용됩니다

</div>

## 보류 중인 요청 찾기

구성원이 프로필 변경을 제출할 때 승인 그룹에 할당된 작업으로 표시됩니다. 두 위치에서 찾을 수 있습니다:

**대시보드에서:**
1. B1 Admin에 로그인합니다 — 대시보드가 자동으로 로드됩니다.
2. 오른쪽 **작업** 섹션에서 **내 그룹에 할당됨** 탭을 클릭합니다.
3. 보류 중인 프로필 변경 요청이 여기에 나열됩니다.

**Serving → 내 작업에서:**
1. 상단 탐색에서 **Serving**을 클릭합니다.
2. **내 작업**을 클릭합니다.
3. 작업 아래 **내 그룹에 할당됨** 탭을 클릭합니다.

## 요청 검토 및 승인

1. **프로필 업데이트** 작업을 클릭하여 엽니다.
2. **요청된 변경 사항**에서 구성원이 업데이트하려는 각 필드와 제출한 새 값을 볼 수 있습니다.
3. 변경사항을 검토합니다.
4. **적용**을 클릭하여 변경사항을 승인하고 프로필에 저장합니다.

변경사항이 적용되면 작업이 자동으로 닫힙니다.

## 승인 그룹 설정

교회에서 프로필 변경에 승인이 필요한 경우 디렉토리 승인 그룹을 먼저 구성해야 합니다.

1. 상단 탐색에서 **Mobile**을 클릭합니다.
2. **B1 Mobile**을 클릭합니다.
3. **디렉토리 승인 그룹**에서 프로필 변경 요청을 검토해야 하는 그룹 구성원의 그룹을 선택합니다.
4. **저장**을 클릭합니다.

해당 그룹의 모든 구성원은 대시보드의 **내 그룹에 할당됨**에서 들어오는 프로필 변경 요청을 볼 수 있습니다.

:::tip
승인자가 실제로 구성된 그룹의 구성원인지 확인하세요 — 그룹 구성원만 요청을 볼 수 있습니다.
:::
