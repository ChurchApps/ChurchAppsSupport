# 프로필 변경 승인하기

<div class="article-intro">

교회가 프로필 업데이트에 관리자 승인을 요구한다면, 구성원은 B1 앱을 통해 변경 사항을 제출하고 그 요청은 B1 Admin에 할 일로 나타납니다. 이 안내서는 그 요청을 검토하고 승인하는 방법을 설명합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- **모바일 → 구성원 포털**에서 **디렉터리 승인 그룹**으로 지정된 그룹의 구성원이어야 합니다.
- 승인 그룹이 설정되지 않았다면, 프로필 변경은 검토 없이 바로 적용됩니다.

</div>

## 대기 중인 요청 찾기

구성원이 프로필을 변경하여 제출하면, 그 요청은 승인 그룹에 배정된 할 일로 나타납니다. 다음 두 곳에서 찾을 수 있습니다:

**대시보드(홈 페이지)에서:**
1. B1 Admin에 로그인합니다. 대시보드가 자동으로 열립니다.
2. **나의 할 일** 섹션에서 **모든 할 일**을 클릭합니다. (나의 할 일에는 나에게 개인적으로 배정된 진행 중인 할 일만 나열됩니다.)
3. **내 그룹에 배정됨** 탭을 클릭합니다. 대기 중인 프로필 변경 요청이 여기에 나열됩니다.

**섬김 → 내 업무에서:**
1. [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 상단의 검색 표시줄)를 열고 **섬김**을 펼칩니다.
2. **내 업무**를 클릭합니다.
3. 할 일 아래의 **내 그룹에 배정됨** 탭을 클릭합니다.

## 요청 검토 및 승인하기

1. **프로필 업데이트** 할 일을 클릭해 엽니다.
2. **요청된 변경 사항** 아래에서 구성원이 업데이트하려는 각 항목과 제출한 새 값을 볼 수 있습니다.
3. 변경 사항을 검토합니다.
4. **적용**을 클릭해 승인하고 그 구성원의 프로필에 변경 사항을 저장합니다.

가족 구성원을 추가하는 요청은 새 사람의 직함, 이름, 가구 역할, 휴대폰 번호를 한 줄에 보여 줍니다(예: *Mr John Smith · 자녀 · 555-0100*). 이를 적용하면 그 구성원의 가구에 해당 세부 정보를 가진 사람이 만들어집니다.

변경 사항이 적용되면 할 일은 자동으로 닫힙니다.

## 승인 그룹 설정하기

교회가 프로필 변경에 승인을 요구하려면 먼저 디렉터리 승인 그룹을 설정해야 합니다.

1. Jump 메뉴를 열고 **모바일**을 펼칩니다.
2. **구성원 포털**("포털 설정" 페이지)을 클릭합니다.
3. **디렉터리 승인 그룹**에서 프로필 변경 요청을 검토할 구성원이 속한 그룹을 고릅니다.
4. **저장**을 클릭합니다.

그 승인 그룹의 구성원이라면 누구나 대시보드의 **내 그룹에 배정됨** 아래에서 들어오는 프로필 변경 요청을 볼 수 있습니다.

같은 디렉터리 승인 그룹은 **계정 삭제 요청**도 검토합니다. [계정 삭제 요청 검토하기](./account-deletion.md)를 참고하세요.

:::tip
승인자가 실제로 설정된 그룹의 구성원인지 확인하세요. 그룹 구성원만 요청을 볼 수 있습니다.
:::
