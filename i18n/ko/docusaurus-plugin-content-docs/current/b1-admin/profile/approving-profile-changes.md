# 프로필 변경 승인하기

<div class="article-intro">

교회가 프로필 업데이트에 관리자 승인을 요구하는 경우, 성도는 B1 App을 통해 변경 사항을 제출하며 그 요청은 B1 Admin에 업무로 나타납니다. 이 가이드는 요청을 검토하고 승인하는 방법을 설명합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- **Mobile &rarr; Member portal**에서 **Directory Approval Group**으로 지정된 그룹의 구성원이어야 합니다.
- 승인 그룹이 설정되어 있지 않다면, 프로필 변경은 검토 없이 즉시 적용됩니다.

</div>

## 대기 중인 요청 찾기 {#where-to-find-pending-requests}

성도가 프로필 변경을 제출하면 승인 그룹에 배정된 업무로 나타납니다. 다음 두 곳에서 찾을 수 있습니다:

**대시보드(홈 페이지)에서:**
1. B1 Admin에 로그인하세요. 대시보드가 자동으로 열립니다.
2. **My tasks** 섹션에서 **All tasks**를 클릭하세요. (My tasks에는 나에게 개별적으로 배정된 진행 중인 업무만 나열됩니다.)
3. **Assigned to My Groups** 탭을 클릭하세요. 대기 중인 프로필 변경 요청이 그곳에 나열됩니다.

**Serving &rarr; My Work에서:**
1. [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 위의 검색창)를 열고 **Serving**을 펼치세요.
2. **My Work**를 클릭하세요.
3. Tasks 아래의 **Assigned to My Groups** 탭을 클릭하세요.

## 요청 검토 및 승인하기 {#reviewing-and-approving-a-request}

1. **Profile Update** 업무를 클릭하여 여세요.
2. **Requested Changes** 아래에서 성도가 업데이트하려는 각 필드와 제출한 새 값을 볼 수 있습니다.
3. 변경 사항을 검토하세요.
4. **Apply**를 클릭하여 승인하고 프로필에 변경 사항을 저장하세요.

가족 구성원을 추가하는 요청은 새 사람의 호칭, 이름, 가구 역할, 휴대폰 번호를 한 줄로 보여 줍니다(예: *Mr John Smith · Child · 555-0100*). 적용하면 그 세부 정보로 성도의 가구에 그 사람이 생성됩니다.

변경 사항이 적용되면 업무는 자동으로 닫힙니다.

## 승인 그룹 설정하기 {#setting-up-the-approval-group}

교회가 프로필 변경에 승인을 요구하려면, 먼저 디렉터리 승인 그룹을 설정해야 합니다.

1. 점프 메뉴를 열고 **Mobile**을 펼치세요.
2. **Member portal**("Portal settings" 페이지)을 클릭하세요.
3. **Directory Approval Group** 아래에서 프로필 변경 요청을 검토할 구성원이 속한 그룹을 고르세요.
4. **Save**를 클릭하세요.

그 그룹의 구성원은 누구나 대시보드의 **Assigned to My Groups** 아래에서 들어오는 프로필 변경 요청을 볼 수 있습니다.

같은 디렉터리 승인 그룹이 **계정 삭제 요청**도 검토합니다. [계정 삭제 요청 검토하기](./account-deletion.md)를 참고하세요.

:::tip
승인자가 실제로 설정된 그룹의 구성원인지 확인하세요. 그룹 구성원만 요청을 볼 수 있습니다.
:::
