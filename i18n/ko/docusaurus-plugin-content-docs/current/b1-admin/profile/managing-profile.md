# 프로필 관리하기 {#managing-your-profile}

<div class="article-intro">

프로필 페이지에서는 개인 계정 설정을 편집할 수 있습니다. 프로필은 모든 ChurchApps 제품에서 공유되므로, 여기서 바꾼 내용은 ChurchApps를 사용하는 모든 곳에 반영됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- ChurchApps 계정에 로그인되어 있어야 합니다
- 이메일 주소나 비밀번호를 바꿀 계획이라면 새 이메일 주소나 비밀번호를 준비하세요

</div>

## 프로필 정보 {#profile-information}

프로필 페이지 왼쪽에는 이름과 이메일 주소가 표시되며, 그 아래에 **편집** 버튼이 있습니다. **편집**을 클릭하면 기본 계정 정보가 담긴 **계정 편집** 양식이 열립니다.

1. **이메일** -- 로그인과 알림 수신에 사용하는 이메일 주소입니다.
2. **이름**과 **성** -- ChurchApps 전체에서 표시되는 이름입니다.
3. **비밀번호** -- 계정 비밀번호를 업데이트합니다.

정보를 업데이트하려면 필드를 편집하고 **변경 사항 저장**을 클릭합니다. 저장하지 않고 프로필로 돌아가려면 **취소**(또는 이름이 있는 **돌아가기** 링크)를 클릭하세요.

## 비밀번호 변경하기 {#changing-your-password}

1. 프로필 페이지에서 **편집**을 클릭합니다.
2. **현재 비밀번호**를 입력합니다.
3. **새 비밀번호** 필드에 새 비밀번호를 입력합니다.
4. **비밀번호 확인** 필드에 다시 입력합니다.
5. **변경 사항 저장**을 클릭합니다.

:::info
비밀번호는 최소 8자 이상이어야 합니다. 비밀번호와 확인 필드가 정확히 일치하는지 확인하세요. 비밀번호를 바꾸려면 현재 비밀번호를 확인해야 합니다. 현재 비밀번호를 모른다면 로그인 페이지의 **비밀번호 찾기** 링크를 사용하세요.
:::

## 연결된 계정 {#linked-accounts}

**연결된 계정** 섹션에는 ChurchApps 계정에 연결된 외부 서비스가 표시됩니다. 이 섹션에서 어떤 계정이 연결되어 있는지 보고 그 연결을 관리할 수 있습니다.

## 테마 설정 {#theme-preferences}

B1 Admin에서는 색상 테마와 밝은 화면 또는 어두운 화면 모드를 고를 수 있습니다.

1. B1 Admin 오른쪽 상단의 프로필 사진을 클릭하여 사용자 메뉴를 엽니다.
2. **테마 설정**에서 테마를 선택합니다.
   - **기본** -- 현재 B1 Admin 모습입니다. 깔끔한 바탕 위에 테두리가 있는 패널로 구성됩니다. 새 사용자는 다른 테마를 고르기 전까지 이 테마를 봅니다.
   - **클래식** -- 이전 B1 Admin 모습입니다. 색이 있는 페이지 배너, 그림자가 있는 카드, 회색 배경을 사용합니다. 새 모습이 나오기 전에 이 기기에서 B1 Admin을 사용했고 테마를 한 번도 고르지 않았다면, 계속 클래식 테마를 보게 됩니다.
   - **사용자 지정** -- 교회 고유의 색상으로 만든 기본 모습입니다. **모바일 > 앱 테마**의 밝은 모드 기본 색상을 쓰며, 앱 색상이 설정되지 않았다면 웹사이트의 기본 색상을 씁니다. 그래서 B1 Admin이 회원 앱과 맞춰집니다.
3. 테마 아래에서 **밝은 모드** 또는 **어두운 모드**를 선택합니다.
4. 화면이 바로 선택을 반영하여 업데이트됩니다.

선택한 내용은 그 기기와 브라우저에 기억됩니다.

## 계정 삭제 {#account-deletion}

프로필 페이지의 **계정 삭제** 섹션에서 계정을 삭제할 수 있습니다.

- 교회에서 **디렉터리 승인 그룹**을 설정하지 **않았다면**, **내 계정 삭제**를 클릭하면 계정과 관련 데이터가 즉시 제거되며, 이 작업은 되돌릴 수 없습니다.
- 교회에서 **디렉터리 승인 그룹을 설정했다면**, 요청은 대신 그 그룹에 보내져 검토됩니다. 요청이 처리되는 동안 버튼은 비활성화되며, 교회가 승인하거나 거절하면 알림을 받습니다. 다음 단계는 [계정 삭제 요청 검토하기](./account-deletion.md)를 참조하세요.

:::warning
계정 삭제는 즉시 이루어지든 교회의 승인을 받아 이루어지든 영구적이며 되돌릴 수 없습니다.
:::

:::info
**도메인 관리자**라면, 계정을 삭제하기 전에 관리 책임을 다른 사용자에게 넘겨 두세요. 관리자 역할 관리에 대한 자세한 내용은 [역할 및 권한](../settings/roles-permissions.md)을 참조하세요.
:::

:::info
데모 모드에서는 프로필 편집이 비활성화되어 있습니다. 데모 계정을 사용하고 있다면 프로필 설정을 변경할 수 없습니다.
:::
