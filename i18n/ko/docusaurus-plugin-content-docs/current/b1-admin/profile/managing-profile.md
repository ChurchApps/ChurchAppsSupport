# 프로필 관리하기

<div class="article-intro">

프로필 페이지에서는 개인 계정 설정을 편집할 수 있습니다. 프로필은 모든 ChurchApps 제품에서 공유되므로, 여기서 바꾼 내용은 ChurchApps를 사용하는 모든 곳에 반영됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- ChurchApps 계정에 로그인되어 있어야 합니다.
- 이메일 주소나 비밀번호를 바꿀 계획이라면 새 값을 미리 준비하세요.

</div>

## 프로필 정보

프로필 페이지 왼쪽에는 이름과 이메일 주소가 나오며, 그 아래에 **Edit** 버튼이 있습니다. **Edit**를 클릭하면 기본 계정 정보가 담긴 **Edit Account** 양식이 열립니다.

1. **Email** -- 로그인하고 알림을 받을 때 쓰는 이메일 주소.
2. **First Name**과 **Last Name** -- ChurchApps 전체에 표시되는 이름.
3. **Password** -- 계정 비밀번호 업데이트.

정보를 수정하려면 필드를 편집한 뒤 **Save Changes** 버튼을 클릭하세요. 저장하지 않고 프로필로 돌아가려면 **Cancel**(또는 이름이 적힌 **Back to** 링크)을 클릭하세요.

## 비밀번호 변경하기

1. 프로필 페이지에서 **Edit**를 클릭하세요.
2. **Current password**(현재 비밀번호)를 입력하세요.
3. **New password** 필드에 새 비밀번호를 입력하세요.
4. **Verify password** 필드에 다시 입력하세요.
5. **Save Changes**를 클릭하세요.

:::info
비밀번호는 최소 8자 이상이어야 합니다. 비밀번호와 확인 필드가 정확히 일치하는지 확인하세요. 비밀번호를 바꾸려면 현재 비밀번호를 확인해야 합니다. 현재 비밀번호를 모르겠다면 로그인 페이지의 **Forgot Password** 링크를 대신 사용하세요.
:::

## 연결된 계정

**Linked Accounts**(연결된 계정) 섹션에는 ChurchApps 계정에 연결된 외부 서비스가 표시됩니다. 이 섹션에서 어떤 계정이 연결되어 있는지 보고, 그 연결을 관리할 수 있습니다.

## 2단계 로그인 {#two-factor-sign-in}

2단계 로그인은 로그인에 두 번째 단계를 추가합니다. 비밀번호(또는 Google, Microsoft, 이메일 로그인 링크) 다음에, 휴대폰의 인증 앱(Google Authenticator, Microsoft Authenticator, 1Password, Authy 등)에 나오는 6자리 코드도 입력합니다. 선택 사항이며 기본값은 꺼짐입니다. 켜면 내 계정을 사용하는 모든 ChurchApps 로그인에 적용됩니다. B1 Admin, 교회의 B1.church 사이트와 앱, B1 Church Checkin, Lessons.church, FreePlay 등이 모두 포함됩니다.

### 켜는 방법

1. 프로필 페이지에서 **Two-Factor Sign-In** 섹션을 찾아 **Turn on**을 클릭하세요.
2. 인증 앱으로 QR 코드를 스캔하세요. 스캔할 수 없다면 **Can't scan? Enter this key:** 아래에 표시된 키를 앱에 직접 입력하세요.
3. 앱에 표시된 **6자리 코드**를 입력하고 **Verify**를 클릭하세요.
4. B1 Admin이 **백업 코드** 열 개를 보여 줍니다. 각 코드는 휴대폰을 잃어버렸을 때 한 번씩 로그인할 수 있게 해 줍니다. **Copy**를 클릭하거나 적어 두고, 안전한 곳에 보관한 뒤 **I saved them**을 클릭하세요.

:::warning
백업 코드는 한 번만 표시됩니다. 휴대폰을 잃어버렸고 남은 백업 코드도 없다면, ChurchApps 서버 관리자가 본인 확인을 거친 뒤 대신 2단계 로그인을 꺼 주어야 합니다.
:::

2단계 로그인이 켜져 있으면 섹션에 **On**이 표시되며, 남은 백업 코드 수도 함께 나타납니다.

### 코드로 로그인하기

비밀번호를 입력하면 로그인 화면이 코드를 요구합니다. 인증 앱의 6자리 코드 또는 백업 코드 중 하나를 입력하고 제출하세요. 백업 코드는 각각 한 번만 사용할 수 있습니다. 코드가 틀리면 "That code didn't work. Please try again."이 표시됩니다. 잘못된 코드를 너무 많이 입력하면 계정의 로그인이 잠시 중단됩니다.

이미 로그인한 기기에서 계속 로그인 상태로 있다면 코드를 다시 묻지 않습니다. 새로 로그인할 때에만 나타납니다.

### 끄는 방법

1. **Two-Factor Sign-In** 섹션에서 **Turn off**를 클릭하세요.
2. 인증 앱의 현재 코드 또는 백업 코드를 입력하세요.
3. **Verify**를 클릭하세요.

:::info
데모 계정에서는 2단계 로그인을 설정할 수 없으므로, 그곳에서는 이 섹션이 숨겨져 있습니다.
:::

## 테마 설정

B1 Admin에서는 색상 테마와 밝은 또는 어두운 화면 모드를 고를 수 있습니다.

1. B1 Admin 오른쪽 위의 프로필 사진을 클릭해 사용자 메뉴를 여세요.
2. **Theme Preferences**에서 테마를 고르세요.
   - **Default** -- 현재의 B1 Admin 화면. 깔끔한 바탕에 테두리가 있는 패널 형태입니다. 새 사용자는 다른 테마를 고르기 전까지 이 테마를 봅니다.
   - **Classic** -- 이전 B1 Admin 화면으로, 색이 있는 페이지 배너, 그림자가 있는 카드, 회색 바탕이 특징입니다. 새 화면이 나오기 전에 이 기기에서 B1 Admin을 썼고 테마를 고른 적이 없다면 계속 Classic을 보게 됩니다.
   - **Custom** -- 교회 고유의 색으로 만든 Default 화면입니다. **Mobile > App Theme**의 밝은 모드 기본 색을 쓰며, 앱 색이 없으면 웹사이트의 기본 색을 씁니다. 그래서 B1 Admin이 교인용 앱과 맞춰집니다.
3. 테마 아래에서 **Light Mode** 또는 **Dark Mode**를 고르세요.
4. 화면이 선택을 즉시 반영합니다.

선택 내용은 이 기기와 브라우저에 기억됩니다.

## 계정 삭제

프로필 페이지의 **Account Deletion** 섹션에서 계정을 삭제할 수 있습니다.

- 교회가 디렉터리 승인 그룹(Directory Approval Group)을 설정**하지 않았다면**, **Delete my account**를 클릭하면 계정과 관련 데이터가 즉시 삭제되며, 이는 되돌릴 수 없습니다.
- 교회가 디렉터리 승인 그룹을 설정**했다면**, 요청이 대신 그 그룹에 검토를 위해 보내집니다. 요청이 대기 중인 동안에는 버튼이 비활성화되며, 교회가 승인하거나 거절하면 알림을 받습니다. 그다음 진행 과정은 [계정 삭제 요청 검토하기](./account-deletion.md)를 참고하세요.

:::warning
계정 삭제는 즉시 이루어지든 교회의 승인을 받든 영구적이며 되돌릴 수 없습니다.
:::

:::info
**Domain Admin**이라면 계정을 삭제하기 전에 관리자 역할을 다른 사용자에게 넘겨주세요. 관리자 역할을 관리하는 방법은 [역할 및 권한](../settings/roles-permissions.md)을 참고하세요.
:::

:::info
데모 모드에서는 프로필 편집이 비활성화되어 있습니다. 데모 계정을 사용하는 경우 프로필 설정을 바꿀 수 없습니다.
:::
