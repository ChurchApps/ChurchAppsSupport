# 프로필 관리하기

<div class="article-intro">

프로필 페이지에서 개인 계정 설정을 편집할 수 있습니다. 프로필은 모든 ChurchApps 제품에서 공유되므로, 여기서 변경한 내용은 ChurchApps를 사용하는 모든 곳에 반영됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- ChurchApps 계정에 로그인되어 있어야 합니다.
- 이메일 주소나 비밀번호를 변경하려면 새 값을 미리 준비해 두세요.

</div>

## 프로필 정보

프로필 페이지에는 왼쪽에 이름과 이메일 주소가 표시되며, 그 아래에 **Edit** 버튼이 있습니다. **Edit**를 클릭하면 기본 계정 세부 정보가 들어 있는 **Edit Account** 양식이 열립니다.

1. **Email** -- 로그인에 사용하고 알림을 받는 이메일 주소입니다.
2. **First Name**과 **Last Name** -- ChurchApps 전체에서 표시되는 이름입니다.
3. **Password** -- 계정 비밀번호를 변경합니다.

정보를 수정하려면 필드를 편집하고 **Save Changes** 버튼을 클릭합니다. 저장하지 않고 프로필로 돌아가려면 **Cancel**(또는 이름이 있는 **Back to** 링크)을 클릭합니다.

## 비밀번호 변경하기

1. 프로필 페이지에서 **Edit**를 클릭합니다.
2. **Current password**에 현재 비밀번호를 입력합니다.
3. **New password** 필드에 새 비밀번호를 입력합니다.
4. **Verify password** 필드에 다시 입력합니다.
5. **Save Changes**를 클릭합니다.

:::info
비밀번호는 8자 이상이어야 합니다. 비밀번호와 확인 필드가 정확히 일치하는지 확인하세요. 비밀번호를 변경하려면 현재 비밀번호를 확인해야 합니다. 현재 비밀번호를 모른다면 로그인 페이지의 **Forgot Password** 링크를 사용하세요.
:::

## 연결된 계정

**Linked Accounts** 섹션에는 ChurchApps 계정에 연결된 외부 서비스가 표시됩니다. 이 섹션에서 어떤 계정이 연결되어 있는지 보고 그 연결을 관리할 수 있습니다.

## 테마 설정

B1 Admin에서는 색상 테마와 라이트 또는 다크 표시 모드를 선택할 수 있습니다.

1. B1 Admin 오른쪽 상단의 프로필 사진을 클릭하여 사용자 메뉴를 엽니다.
2. **Theme Preferences** 아래에서 테마를 선택합니다.
   - **Default** -- 현재 B1 Admin 디자인입니다. 깔끔한 바탕 위에 테두리가 있는 패널이 표시됩니다.
   - **Classic** -- 이전 B1 Admin 디자인입니다. 색이 있는 페이지 배너, 그림자가 있는 카드, 회색 배경이 특징입니다. 테마를 선택하기 전까지 보이는 화면입니다.
   - **Custom** -- 교회 고유의 색상으로 만든 Default 디자인입니다. **Mobile > App Theme**의 라이트 모드 기본 색상을 사용하며, 앱 색상이 설정되지 않았다면 웹사이트의 기본 색상을 사용하므로 B1 Admin이 회원용 앱과 어울립니다.
3. 테마 아래에서 **Light Mode** 또는 **Dark Mode**를 선택합니다.
4. 선택한 내용이 바로 인터페이스에 반영됩니다.

선택한 설정은 해당 기기와 브라우저에 저장됩니다.

## 계정 삭제

프로필 페이지의 **Account Deletion** 섹션에서 계정을 삭제할 수 있습니다.

- 교회가 디렉토리 승인 그룹을 설정하지 **않았다면**, **Delete my account**를 클릭하면 계정과 관련 데이터가 즉시 삭제되며 이 작업은 되돌릴 수 없습니다.
- 교회가 디렉토리 승인 그룹을 설정**했다면**, 요청이 대신 그 그룹에 검토용으로 전송됩니다. 요청이 보류 중인 동안에는 버튼이 비활성화되며, 교회가 승인하거나 거절하면 알림을 받습니다. 이후 절차는 [계정 삭제 요청 검토하기](./account-deletion.md)를 참조하세요.

:::warning
계정 삭제는 즉시 진행되든 교회의 승인을 받아 진행되든 영구적이며 되돌릴 수 없습니다.
:::

:::info
**Domain Admin**이라면 계정을 삭제하기 전에 관리 책임을 다른 사용자에게 넘기세요. 관리자 역할 관리에 대한 자세한 내용은 [역할 및 권한](../settings/roles-permissions.md)을 참조하세요.
:::

:::info
데모 모드에서는 프로필 편집이 비활성화됩니다. 데모 계정을 사용 중이라면 프로필 설정을 변경할 수 없습니다.
:::
