# 프로필 관리하기

<div class="article-intro">

프로필 페이지에서는 개인 계정 설정을 편집할 수 있습니다. 프로필은 모든 ChurchApps 제품이 공유하므로, 여기에서 변경한 내용은 ChurchApps를 사용하는 모든 곳에 반영됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- ChurchApps 계정에 로그인되어 있어야 합니다.
- 이메일 주소나 비밀번호를 변경할 계획이라면 새 이메일 주소나 비밀번호를 미리 준비하세요.

</div>

## 프로필 정보

프로필 페이지에는 왼쪽에 이름과 이메일 주소가 표시되며, 그 아래에 **Edit** 버튼이 있습니다. **Edit**을 클릭하면 기본 계정 세부 정보가 있는 **Edit Account** 양식이 열립니다.

1. **Email** -- 로그인과 알림 수신에 사용하는 이메일 주소입니다.
2. **First Name**과 **Last Name** -- ChurchApps 전반에서 표시되는 이름입니다.
3. **Password** -- 계정 비밀번호를 업데이트합니다.

정보를 업데이트하려면 필드를 편집하고 **Save Changes** 버튼을 클릭합니다. 저장하지 않고 프로필로 돌아가려면 **Cancel**(또는 이름이 적힌 **Back to** 링크)을 클릭하세요.

## 비밀번호 변경하기

1. 프로필 페이지에서 **Edit**을 클릭합니다.
2. **Current password**에 현재 비밀번호를 입력합니다.
3. **New password** 필드에 새 비밀번호를 입력합니다.
4. **Verify password** 필드에 다시 입력합니다.
5. **Save Changes**를 클릭합니다.

:::info
비밀번호는 최소 8자 이상이어야 합니다. 비밀번호와 확인 필드가 정확히 일치하는지 확인하세요. 비밀번호를 변경하려면 현재 비밀번호를 확인해야 합니다. 현재 비밀번호를 모른다면 로그인 페이지의 **Forgot Password** 링크를 사용하세요.
:::

## 연결된 계정

**Linked Accounts** 섹션에는 ChurchApps 계정에 연결된 외부 서비스가 표시됩니다. 이 섹션에서 어떤 계정이 연결되어 있는지 확인하고 연결을 관리할 수 있습니다.

## 이중 인증 로그인

이중 인증 로그인은 로그인에 두 번째 단계를 추가합니다. 비밀번호(또는 Google, Microsoft, 이메일 로그인 링크)를 입력한 뒤, 휴대폰의 인증 앱(Google Authenticator, Microsoft Authenticator, 1Password, Authy 등)에 표시되는 6자리 코드도 입력해야 합니다. 이 기능은 선택 사항이며 기본적으로 꺼져 있습니다. 한번 켜면 여러분의 계정을 사용하는 모든 ChurchApps 로그인에 적용됩니다 -- B1 Admin, 교회의 B1.church 사이트와 앱, B1 Church Checkin, Lessons.church, FreePlay 등입니다.

### 켜는 방법

1. 프로필 페이지에서 **Two-Factor Sign-In** 섹션을 찾아 **Turn on**을 클릭합니다.
2. 인증 앱으로 QR 코드를 스캔합니다. 스캔할 수 없다면 **Can't scan? Enter this key:** 아래에 표시된 키를 앱에 직접 입력하세요.
3. 앱에 표시된 **6자리 코드**를 입력하고 **Verify**를 클릭합니다.
4. B1 Admin에 **백업 코드** 10개가 표시됩니다. 각 코드는 휴대폰을 분실했을 때 한 번씩 로그인할 수 있게 해 줍니다. **Copy**를 클릭하거나 적어 둔 다음 안전한 곳에 보관하고, **I saved them**을 클릭하세요.

:::warning
백업 코드는 한 번만 표시됩니다. 휴대폰을 분실했고 남은 백업 코드도 없다면, ChurchApps 서버 관리자가 본인 확인을 마친 후에야 이중 인증 로그인을 꺼 줄 수 있습니다.
:::

이중 인증 로그인이 켜져 있으면 **Two-Factor Sign-In** 섹션에 **On**이 표시되며, 남은 백업 코드 수도 함께 나타납니다.

### 코드로 로그인하기

비밀번호를 입력하면 로그인 화면에서 코드를 요구합니다. 인증 앱의 6자리 코드 또는 백업 코드 중 하나를 입력하고 제출하세요. 각 백업 코드는 한 번만 사용할 수 있습니다. 코드가 틀리면 "That code didn't work. Please try again." 메시지가 나타납니다. 잘못된 코드를 너무 많이 입력하면 한동안 계정의 로그인이 일시 중지됩니다.

이미 로그인한 적이 있는 기기에 계속 로그인된 상태라면 코드를 다시 요구하지 않습니다. 새로 로그인할 때만 코드가 필요합니다.

### 끄는 방법

1. **Two-Factor Sign-In** 섹션에서 **Turn off**를 클릭합니다.
2. 인증 앱의 현재 코드 또는 백업 코드를 입력합니다.
3. **Verify**를 클릭합니다.

:::info
데모 계정에서는 이중 인증 로그인을 설정할 수 없으므로 해당 섹션이 숨겨집니다.
:::

## 테마 환경설정

B1 Admin에서는 색상 테마와 라이트 또는 다크 표시 모드를 선택할 수 있습니다.

1. B1 Admin 오른쪽 상단의 프로필 사진을 클릭하여 사용자 메뉴를 엽니다.
2. **Theme Preferences** 아래에서 테마를 선택합니다.
   - **Default** -- 현재 B1 Admin의 모습으로, 깔끔한 바탕 위에 테두리가 있는 패널이 특징입니다. 새 사용자는 다른 테마를 선택하기 전까지 이 테마를 봅니다.
   - **Classic** -- 이전 B1 Admin의 모습으로, 색이 있는 페이지 배너, 그림자가 있는 카드, 회색 배경이 특징입니다. 새 모습이 나오기 전에 이 기기에서 B1 Admin을 사용했고 테마를 선택한 적이 없다면 계속 Classic을 사용합니다.
   - **Custom** -- 교회 고유의 색상으로 만든 Default 모습입니다. **Mobile > App Theme**에서 설정한 라이트 모드의 기본 색상을 사용하며, 앱 색상이 설정되지 않았다면 웹사이트의 기본 색상을 사용합니다. 따라서 B1 Admin이 교인 앱과 맞춰집니다.
3. 테마 아래에서 **Light Mode** 또는 **Dark Mode**를 선택합니다.
4. 인터페이스가 선택 내용을 즉시 반영합니다.

선택한 내용은 해당 기기와 브라우저에 기억됩니다.

## 계정 삭제

프로필 페이지의 **Account Deletion** 섹션에서 계정을 삭제하는 옵션을 찾을 수 있습니다.

- 교회가 디렉터리 승인 그룹을 설정하지 **않았다면**, **Delete my account**를 클릭하면 계정과 관련 데이터가 즉시 삭제되며, 이 작업은 되돌릴 수 없습니다.
- 교회가 디렉터리 승인 그룹을 설정**했다면**, 요청이 검토를 위해 그 그룹으로 전송됩니다. 요청이 처리되는 동안 버튼은 비활성화되며, 교회가 승인하거나 거절하면 알림을 받게 됩니다. 이후 절차는 [계정 삭제 요청 검토하기](./account-deletion.md)를 참고하세요.

:::warning
계정 삭제는 즉시 이루어지든 교회의 승인을 받아 이루어지든 영구적이며 되돌릴 수 없습니다.
:::

:::info
**Domain Admin**이라면 계정을 삭제하기 전에 관리 책임을 다른 사용자에게 넘기세요. 관리자 역할 관리에 대한 자세한 내용은 [역할과 권한](../settings/roles-permissions.md)을 참고하세요.
:::

:::info
데모 모드에서는 프로필 편집이 비활성화됩니다. 데모 계정을 사용 중이라면 프로필 설정을 변경할 수 없습니다.
:::
