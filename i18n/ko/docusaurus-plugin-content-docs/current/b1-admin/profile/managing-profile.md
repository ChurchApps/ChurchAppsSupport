# 프로필 관리

<div class="article-intro">

프로필 페이지에서는 개인 계정 설정을 편집할 수 있습니다. 프로필은 모든 ChurchApps 제품에서 공유되므로, 여기서 변경한 내용은 ChurchApps를 사용하는 모든 곳에 반영됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- ChurchApps 계정에 로그인되어 있어야 합니다
- 이메일 주소나 비밀번호를 변경하려면 새 값을 미리 준비해 두세요

</div>

## 프로필 정보

프로필 페이지에는 왼쪽에 이름과 이메일 주소가 표시되며, 그 아래에 **편집** 버튼이 있습니다. **편집**을 클릭하면 기본 계정 정보가 들어 있는 **계정 편집** 양식이 열립니다:

1. **이메일** -- 로그인과 알림 수신에 사용되는 이메일 주소입니다.
2. **이름**과 **성** -- ChurchApps 전체에서 표시되는 이름입니다.
3. **비밀번호** -- 계정 비밀번호를 변경합니다.

정보를 수정하려면 필드를 편집한 후 **변경 사항 저장** 버튼을 클릭하세요. 저장하지 않고 프로필로 돌아가려면 **취소**(또는 이름이 적힌 **뒤로** 링크)를 클릭하세요.

## 비밀번호 변경

1. 프로필 페이지에서 **편집**을 클릭합니다.
2. **현재 비밀번호**를 입력합니다.
3. **새 비밀번호** 필드에 새 비밀번호를 입력합니다.
4. **비밀번호 확인** 필드에 같은 비밀번호를 다시 입력합니다.
5. **변경 사항 저장**을 클릭합니다.

:::info
비밀번호는 8자 이상이어야 합니다. 비밀번호와 확인 필드의 내용이 정확히 일치하는지 확인하세요. 비밀번호를 변경하려면 현재 비밀번호를 입력해야 합니다. 현재 비밀번호를 모르는 경우 로그인 페이지의 **비밀번호 찾기** 링크를 이용하세요.
:::

## 연결된 계정

**연결된 계정** 섹션에는 ChurchApps 계정에 연결된 외부 서비스가 표시됩니다. 이 섹션에서 연결된 계정을 확인하고 연결을 관리할 수 있습니다.

## 테마 설정

B1 Admin은 밝은 모드와 어두운 모드를 모두 지원합니다:

1. B1 Admin 오른쪽 상단의 프로필 사진을 클릭하여 사용자 메뉴를 엽니다.
2. **테마 설정**에서 **밝은 모드** 또는 **어두운 모드**를 선택합니다.
3. 선택한 모드가 즉시 인터페이스에 반영됩니다.

선택한 설정은 해당 기기와 브라우저에 저장됩니다.

## 계정 삭제

프로필 페이지의 **계정 삭제** 섹션에서 계정을 삭제할 수 있습니다.

- 교회에서 **디렉터리 승인 그룹**을 설정하지 않은 경우, **내 계정 삭제**를 클릭하면 계정과 관련 데이터가 즉시 삭제되며 이 작업은 되돌릴 수 없습니다.
- 교회에서 **디렉터리 승인 그룹**을 설정한 경우, 삭제 요청은 대신 해당 그룹에 검토용으로 전송됩니다. 요청이 처리되는 동안 버튼은 비활성화되며, 교회에서 요청을 승인하거나 거부하면 알림을 받게 됩니다. 이후 절차는 [계정 삭제 요청 검토](./account-deletion.md)를 참조하세요.

:::warning
계정 삭제는 즉시 삭제되든 교회의 승인을 받아 삭제되든 영구적이며 되돌릴 수 없습니다.
:::

:::info
**도메인 관리자**라면 계정을 삭제하기 전에 관리자 권한을 다른 사용자에게 넘겨야 합니다. 관리자 역할 관리에 대한 자세한 내용은 [역할 및 권한](../settings/roles-permissions.md)을 참조하세요.
:::

:::info
데모 모드에서는 프로필 편집이 비활성화되어 있습니다. 데모 계정을 사용하는 경우 프로필 설정을 변경할 수 없습니다.
:::
