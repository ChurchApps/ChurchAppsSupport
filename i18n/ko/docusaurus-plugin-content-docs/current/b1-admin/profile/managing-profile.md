# 프로필 관리
<div class="article-intro">
프로필 페이지에서는 개인 계정 설정을 편집할 수 있습니다. 프로필은 모든 ChurchApps 제품에서 공유되므로, 여기서 변경한 내용이 모든 곳에 반영됩니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- ChurchApps 계정에 로그인해야 합니다
- 새 이메일 주소 또는 비밀번호가 준비되어 있어야 합니다
</div>
## 프로필 정보
프로필 페이지의 위쪽 섹션에는 기본 계정 세부 정보가 있습니다:
1. **이메일** — 로그인 및 알림용 이메일
2. **이름** — ChurchApps 전체에서의 표시 이름
3. **비밀번호** — 계정 비밀번호
## 비밀번호 변경
1. 프로필 페이지의 비밀번호 필드로 스크롤합니다
2. **현재 비밀번호**를 입력합니다
3. 새 비밀번호를 입력합니다
4. 비밀번호를 다시 입력합니다
5. **변경 사항 저장**을 클릭합니다
## 테마 선택
1. 프로필 페이지에서 **테마** 전환을 찾습니다
2. **밝은 색** 또는 **어두운 색** 모드를 선택합니다
3. 인터페이스가 즉시 업데이트됩니다
