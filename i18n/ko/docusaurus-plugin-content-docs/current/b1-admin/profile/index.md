# 프로필
<div class="article-intro">
프로필 섹션에서는 ChurchApps의 개인 계정 설정을 관리할 수 있습니다. 프로필은 모든 ChurchApps 도구에서 공유되므로, 여기서 변경한 내용은 모든 곳에 적용됩니다.
</div>
## 할 수 있는 것들
프로필 섹션에서:
- **이름과 이메일 업데이트** — 연락처 정보를 최신 상태로 유지합니다
- **비밀번호 변경** — 새 비밀번호를 설정합니다
- **테마 전환** — 밝은 색 또는 어두운 색 모드를 선택합니다
- **연결된 기기 관리** — 계정과 연결된 기기를 보고 관리합니다
- **연결된 계정 보기** — 외부 서비스 연결을 관리합니다
- **프로필 변경 요청 승인** — 회원이 제출한 업데이트를 검토합니다
