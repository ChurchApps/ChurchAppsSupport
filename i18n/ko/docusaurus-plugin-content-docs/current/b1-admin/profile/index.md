# 프로필

<div class="article-intro">

프로필 섹션에서는 ChurchApps의 개인 계정 설정을 관리할 수 있습니다. 프로필은 모든 ChurchApps 도구에서 공유되므로, 여기서 바꾼 내용은 B1 Admin에서 B1 모바일 앱까지 어디에서나 적용됩니다.

</div>

## 할 수 있는 일

프로필 섹션에서 다음을 할 수 있습니다.

- **이름과 이메일 업데이트** -- 연락처 정보를 최신으로 유지하세요.
- **비밀번호 변경** -- 계정의 새 비밀번호를 설정하세요.
- **2단계 로그인 켜기** -- 로그인할 때 인증 앱의 코드를 요구하도록 설정하세요. [2단계 로그인](./managing-profile.md#two-factor-sign-in)을 참고하세요.
- **테마 전환** -- 사용자 메뉴(오른쪽 위의 프로필 사진을 클릭)에서 밝은 모드와 어두운 모드를 전환하세요.
- **연결된 기기 관리** -- 내 계정에 연결된 ChurchAppsPlayer 기기를 보고 관리하세요.
- **연결된 계정 보기** -- ChurchApps 계정에 연결된 외부 서비스를 보고 관리하세요.
- **프로필 변경 요청 승인** -- 교인이 제출한 업데이트를 검토하고 적용하세요.

## 프로필 하위 섹션

프로필 영역에는 다음 페이지가 있습니다.

1. **[프로필 관리하기](./managing-profile.md)** -- 개인 정보를 편집하고, 비밀번호를 바꾸고, 연결된 계정을 관리하고, 2단계 로그인을 켜고, 테마 설정을 조정하고, 계정 삭제를 처리합니다.
2. **[프로필 변경 승인하기](./approving-profile-changes.md)** -- B1 모바일을 통해 교인이 제출한 프로필 업데이트 요청을 검토하고 승인합니다.
3. **[기기 관리하기](./devices.md)** -- 내 계정과 짝지어진 ChurchAppsPlayer 기기를 보고, 추가하고, 관리합니다.

:::tip
이메일 주소를 최신으로 유지하세요. 계정 복구와 교회에서 보내는 중요한 알림에 사용됩니다.
:::
