# 프로필

<div class="article-intro">

프로필 섹션에서는 ChurchApps의 개인 계정 설정을 관리할 수 있습니다. 프로필은 모든 ChurchApps 도구에서 공유되므로, 여기서 변경한 내용은 B1 Admin부터 B1 Mobile 앱까지 모든 곳에 적용됩니다.

</div>

## 할 수 있는 것들

프로필 섹션에서 다음을 할 수 있습니다:

- **이름과 이메일 업데이트** -- 연락처 정보를 최신 상태로 유지합니다.
- **비밀번호 변경** -- 계정의 새 비밀번호를 설정합니다.
- **테마 전환** -- 사용자 메뉴(오른쪽 상단의 프로필 사진 클릭)에서 밝은 모드와 어두운 모드를 전환합니다.
- **연결된 기기 관리** -- 계정에 연결된 ChurchAppsPlayer 기기를 확인하고 관리합니다.
- **연결된 계정 보기** -- ChurchApps 계정에 연결된 외부 서비스를 확인하고 관리합니다.
- **프로필 변경 요청 승인** -- 회원이 제출한 정보 업데이트를 검토하고 적용합니다.

## 프로필 하위 섹션

프로필 영역에는 다음 페이지가 있습니다:

1. **[프로필 관리](./managing-profile.md)** -- 개인 정보를 편집하고, 비밀번호를 변경하고, 연결된 계정을 관리하고, 테마 설정을 조정하고, 계정 삭제를 처리합니다.
2. **[프로필 변경 승인](./approving-profile-changes.md)** -- B1 Mobile을 통해 회원이 제출한 프로필 업데이트 요청을 검토하고 승인합니다.
3. **[기기 관리](./devices.md)** -- 계정과 페어링된 ChurchAppsPlayer 기기를 보고, 추가하고, 관리합니다.

:::tip

:::
