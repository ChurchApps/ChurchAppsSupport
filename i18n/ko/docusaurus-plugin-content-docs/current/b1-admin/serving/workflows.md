# 워크플로우

<div class="article-intro">

워크플로우는 사람들을 시각적 보드의 일련의 단계를 통해 이동시킵니다. 각 사람은 한 단계에서 다음 단계로 이동하는 카드가 됩니다 -- 처음 방문한 손님의 팔로우업에서 회원가입 절차로, 처음 헌금한 사람에 대한 감사 인사로, 많은 사람들을 같은 단계의 집합을 통해 추적해야 하는 다른 모든 경우로. 한 단계는 자원봉사자에게 무언가를 할 것을 요청할 수 있으며 **그리고** 자동화된 작업을 자체적으로 실행할 수 있습니다 -- 이메일 보내기, 며칠 기다리기, 그룹에 사람 추가하기 -- 따라서 워크플로우는 인간 팔로우업과 그 주변의 번거로운 작업을 모두 처리합니다. 워크플로우는 [작업](./tasks.md)을 드래그 앤 드롭 칸반 보드로 확장하므로 아무도 놓치지 않습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 추적하려는 사람들이 B1 Admin에 있는지 확인하세요
- [작업](./tasks.md)이 어떻게 작동하는지 숙지하세요. 각 보드의 카드는 작업이기 때문입니다
- **이메일 보내기** 작업을 사용하려면 먼저 보내려는 이메일 템플릿을 만드세요 (**메시징 → 템플릿 관리** 아래에서 관리됨)
- 적절한 작업 권한이 필요합니다. 카드 보기, 편집 및 워크플로우 관리는 별도의 권한 수준입니다 ([역할 및 권한](../settings/roles-permissions.md) 참조)

</div>

## 워크플로우 보기

**서빙**으로 이동하고 메뉴에서 **워크플로우**를 선택하세요. 워크플로우가 카테고리별로 그룹화되어 나열되고 활성 워크플로우가 강조 표시됩니다. 임의의 워크플로우를 클릭하여 보드를 엽니다.

## 워크플로우 만들기

1. 워크플로우 페이지에서 **워크플로우 추가**를 클릭하세요.
2. 시작하는 방법을 선택하세요:
   - **빈 워크플로우** -- 처음부터 시작하여 자신의 단계를 만드세요.
   - **템플릿에서** -- 편집할 수 있는 미리 만들어진 단계 세트로 시작하세요. 내장 템플릿에는 다음이 포함됩니다:
     - **새 방문자 팔로우업** -- 환영 이메일 보내기 → 개인 전화 통화 → 다음 단계로 초대 → 연결됨
     - **회원가입 클래스** -- 관심 표현 → 클래스 등록 → 클래스 참석 → 회원가입 완료
     - **처음 헌금 감사** -- 감사 메모 보내기 → 헌금 영향 공유 → 관리됨
3. 워크플로우에 **이름**을 지정하세요.
4. 선택적으로 관련 워크플로우를 그룹화하려면 **카테고리**를 할당하세요. 드롭다운에서 직접 새 카테고리를 만들 수 있습니다.
5. 워크플로우를 **활성**으로 두어 사람들이 추가될 수 있도록 하거나, **비활성**으로 설정하여 워크플로우 추가 목록에서 숨길 수 있습니다.
6. **저장**을 클릭하세요.

:::tip
워크플로우 목록의 **복제** 단추를 사용하여 기존 워크플로우를 복사하세요 -- 단계, 자동화된 작업 및 라우팅을 포함한 -- 새 워크플로우의 시작점으로.
:::

## 단계로 보드 만들기

각 워크플로우 보드는 **단계**로 구성되며, 왼쪽에서 오른쪽으로 열로 표시됩니다. 워크플로우를 열고 **단계 추가**를 사용하여 프로세스의 각 단계를 만드세요.

단계를 추가하거나 편집할 때 다음을 구성할 수 있습니다:

- **단계 이름** -- 열 제목 (예: "환영 전화" 또는 "등록 대기 중").
- **다음에서 만료** (일) -- 카드가 이 단계에 들어올 때 만료 날짜를 자동으로 설정합니다. 만료 날짜가 지난 카드는 **기한 초과**로 표시됩니다.
- **기본 담당자** -- 이 단계의 새 카드가 자동으로 할당되는 사람 또는 그룹.
- **자동화된 작업** -- 카드가 도착했을 때 시스템이 자체적으로 수행하는 작업 (아래 참조).
- **라우팅** -- 카드가 단계를 떠날 때 어디로 가는지 ([라우팅](#routing-cards-with-outcomes-and-conditions) 참조).

단계 열을 프로세스와 일치하는 순서로 드래그하세요. 순서는 다른 라우팅이 적용되지 않을 때 카드가 취하는 기본 경로를 정의합니다.

:::info
새 단계를 먼저 저장하세요. 자동화된 작업과 라우팅은 단계에 첨부되므로 편집기는 단계가 존재하면 해당 섹션을 잠금 해제합니다.
:::

## 자동화된 작업

모든 단계는 카드가 단계에 **들어가는** 순간 자신들에 의해 실행되는 **자동화된 작업** 목록을 수행할 수 있습니다 -- 아무도 건드리기 전에. 이것은 한 단계가 자원봉사자에게 프롬프트를 주고 **그리고** 팔로우업 주변의 일상적인 작업을 처리하는 방법입니다.

단계 편집기에서 **자동화된 작업**을 열고, **작업 추가**를 클릭하고, 유형을 선택하고, 설정을 채운 후, 해당 작업에서 저장 아이콘을 클릭하세요. 필요한 만큼 추가하세요; 그들은 **위에서 아래로 순서대로** 실행됩니다.

| 작업 | 하는 일 |
|---|---|
| **이메일 보내기** | 선택한 이메일 템플릿을 사람에게 이메일로 보냅니다. 제목 줄을 재정의할 수 있습니다. |
| **대기** | 계속하기 전에 카드를 여러 날 동안 일시 중지합니다 (아래 참조). |
| **그룹에 추가** | 선택한 [그룹](../groups/index.md)에 사람을 추가합니다. |
| **워크플로우에 추가** | 사람을 다른 워크플로우에 시작합니다 -- 프로세스 간에 넘길 때 유용합니다. |
| **메모 추가** | 카드의 히스토리에 메모를 기록합니다. |
| **필드 설정** | 사람의 레코드에서 필드를 업데이트합니다: 회원가입 상태, 결혼 상태, 성별, 도시, 주 또는 우편번호. |
| **웹훅** | 다른 시스템에 연결하기 위해 제공한 외부 웹 주소 (URL)로 카드의 세부정보를 보냅니다. |

단계의 모든 작업이 완료되면 카드는 **해당 단계에서 휴식을 취합니다** 사람이 작업할 수 있도록 -- 단계에 카드를 계속 이동시키는 자동 경로가 없는 한 ([완전히 자동화된 단계](#fully-automated-steps) 참조).

:::info
자동화된 작업은 카드가 정상적인 흐름으로 도착할 때만 실행됩니다 -- 처음 추가될 때, 결과 또는 자동 경로가 이를 가져올 때, 또는 대기가 완료된 후. 직원이 카드를 수동으로 단계로 드래그하거나 되돌릴 때는 **재실행되지 않으므로** 사람이 같은 이메일을 두 번 받지 않습니다.
:::

### 이메일 보내기

**이메일 보내기**를 선택하고, 이메일 템플릿 중 하나를 선택하고, 선택적으로 사용자 정의 제목을 입력하세요. 카드가 단계에 들어가면 사람이 해당 이메일을 자동으로 받습니다. (사람의 파일에 이메일 주소가 없는 경우 단계는 단순히 이 작업을 건너뜁니다.)

:::info
워크플로우 이메일은 교회가 그룹 이메일을 보낼 승인을 받은 후에만 나가고 교회의 일일 이메일 한도에 포함됩니다. [교회용 그룹 이메일 켜기](../groups/group-members.md#turning-on-group-email-for-your-church) 참조.
:::

### 며칠 대기 (드립 시퀀스)

**대기** 작업은 카드를 설정한 일수 동안 보유합니다. 기다리는 동안 카드는 **일시 중지됨**으로 표시됩니다. 대기가 끝나면:

1. **같은 단계의 나머지 작업** 실행 -- 드립처럼 구축할 수 있습니다 **이메일 보내기 → 3일 대기 → 상기 이메일 보내기**.
2. 그러면 단계에 자동 경로가 있는 경우 카드가 계속 이동됩니다; 그렇지 않으면 사람이 선택할 수 있도록 단계에서 휴식합니다.

:::tip
단계의 매우 시작 부분에 **대기**는 카드를 자원봉사자에게 표시하기 전에 "보유"하는 간단한 방법입니다 -- 예를 들어, *7일 대기, 그러면 코치가 도달합니다*.
:::

## 사람을 카드로 추가

보드에 사람을 올려놓는 몇 가지 방법이 있습니다:

- **보드에서** -- 단계 열 하단의 **카드 추가**를 클릭하고 사람을 선택하세요. 그룹을 선택할 수도 있으며 그 그룹의 모든 멤버가 카드로 추가됩니다.
- **사람의 기록에서** -- 사람의 페이지에서 **워크플로우에 추가**를 사용하여 워크플로우에 드롭하세요.
- **사람 검색에서** -- 여러 사람을 선택하고 대량 **워크플로우에 추가** 작업을 사용하여 모두 한 번에 추가하세요.
- **트리거를 사용한 자동으로** -- 양식 제출 또는 첫 번째 선물 같은 것이 발생할 때 사람을 추가하세요 ([트리거](#triggers) 아래 참조).

## 보드 작업

워크플로우를 열어 보드를 확인하세요. 각 카드는 사람의 이름, 할당된 사람, 만료 날짜 또는 상태 칩 (**기한 초과** 또는 **일시 중지됨**)을 표시합니다. 단계 열은 또한 실행하는 자동화된 작업에 대한 작은 배지와 라우팅에 대한 주석을 표시하여 카드가 어떻게 흐르는지 한 눈에 볼 수 있습니다.

- **카드 이동** -- 카드를 한 열에서 다음 열로 드래그하여 사람이 진행합니다.
- **카드 열기** -- 카드를 두 번 클릭 (또는 클릭)하여 세부 서랍을 열고, 여기서 단계를 변경하고, 재할당하고, 메모를 추가하고, 이미 발생한 일을 검토할 수 있습니다.

카드 서랍에서 다음을 할 수 있습니다:

- **할당** 카드를 다른 사람 또는 그룹에 할당하세요.
- **일시 중지** 카드를 1일, 3일 또는 1주일 동안 일시 중지하여 만료 날짜를 임시로 숨길 수 있습니다.
- **이전 단계로 돌아가기** 또는 **다음 단계로 건너뛰기**.
- **할당 고정** -- 단계 간에 이동할 때에도 같은 소유자를 카드에 보관하세요. 기본적으로 카드를 새 단계로 이동하면 해당 단계의 기본 담당자에게 재할당됩니다; 고정하면 현재 사람이 전체 기간을 통해 책임을 유지합니다.
- **완료** 카드를 완료하거나 단계에 결과가 구성된 경우 **결과** 단추를 선택하세요 ([라우팅](#routing-cards-with-outcomes-and-conditions) 참조).
- **메모 추가** 그리고 카드의 **히스토리** 검토 -- 실행된 자동화된 작업 로그를 포함합니다 (이메일 보낸, 대기 등).

### 대량 작업

여러 카드의 확인란을 선택하여 함께 작업하세요. 선택한 모든 카드를 **완료**, **일시 중지**, **재할당** 또는 **이동**할 수 있는 도구 모음이 나타납니다.

## 결과 및 조건을 사용한 카드 라우팅

라우팅은 카드가 단계를 떠날 때 어디로 가는지 제어합니다. 단계의 편집기를 열어 두 가지 라우팅을 구성하세요.

### 결과 단추

결과는 해당 단계의 카드를 완료할 때 카드 서랍에 표시되는 단추입니다. 단일 **완료** 단추 대신 "그룹 가입" 또는 "관심 없음"과 같은 선택지를 제공할 수 있습니다. 각 결과는 다음을 수행할 수 있습니다:

- 카드를 이 워크플로우의 **다른 단계**로 보내기,
- **카드를 완전히 다른 워크플로우로 넘기거나,** 또는
- **카드를 닫기**.

이는 한 가지 결정이 사람을 다양한 경로로 나뉠 수 있도록 합니다.

### 자동 라우팅 (조건부)

자동 경로는 카드가 단계에 **들어가는 순간** 카드를 계속 이동시킵니다 (자동화된 작업 완료 후), 아무도 클릭하지 않으면, 사람이 조건의 집합과 일치할 경우. 경로를 추가하고, 대상 단계를 선택하고, 하나 이상의 **조건**을 정의하세요 (예: 사람의 캠퍼스, 나이 또는 회원가입 상태). 조건이 없는 경로는 모든 사람과 일치합니다.

:::info
보드에서 각 단계 열은 라우팅을 설명하는 작은 주석을 표시합니다 -- 예를 들어, 결과 레이블 또는 "일치하면" 대상 단계 또는 워크플로우로의 화살표입니다.
:::

## 완전히 자동화된 단계

단계를 완전히 자신의 방법으로 실행할 수 있으므로 아무도 작업하지 않습니다. 단계에 **자동화된 작업**과 다음 단계를 가리키는 **자동 경로** (조건 없이)를 추가하세요. 카드가 들어가면 작업이 실행되고 경로가 즉시 이동합니다 -- 카드는 직접 통과합니다.

:::tip
이것을 **대기**와 함께 결합하세요: *환영 이메일 보내기 → 3일 대기 → "개인 전화" 단계로 자동으로 진행*. 이메일과 시간은 자동으로 처리되고 자원봉사자는 인간의 손길이 필요할 때만 카드를 봅니다.
:::

## 트리거

트리거는 뭔가가 발생할 때 자동으로 사람을 워크플로우에 추가하므로 카드를 손으로 추가할 필요가 없습니다. 워크플로우 보드에서 **트리거** 탭을 클릭한 후 **트리거 추가**를 클릭하세요. 두 가지 종류가 있습니다:

### 이벤트 트리거

B1의 기록이 변경되자마자 실행됩니다. 이벤트를 선택한 후 선택적으로 **조건**을 추가하여 일치하는 사람만 추가하세요:

- **사람 · 생성 / 업데이트** -- 예: 상태가 *방문자*가 되는 사람을 추가하세요.
- **기부금 · 생성** -- 예: 첫 번째 또는 큰 선물을 감사 워크플로우에 추가하세요 (금액, 펀드 또는 방법으로 일치).
- **그룹 · 멤버 가입** / **그룹 · 생성**.
- **양식 · 제출** -- 선택한 양식을 제출하는 사람을 추가하세요 ("나 신규" 또는 "연결" 카드에 적합함).

### 일정 트리거

반복 기준 -- 일일, 주간, 월간 또는 연간 -- 조건 세트에 대해 실행합니다. 이러한 것들을 *회원가입 기념일이 오늘인 모든 사람* 또는 *월간* 체크인과 같은 시간 기반 아웃리치에 사용하세요.

모든 트리거에 대해 다음을 설정할 수도 있습니다:

- **입력 단계** 새 카드가 시작되는 곳 (기본값은 첫 번째 단계).
- **사람당 한 번** -- 따라서 같은 사람이 트리거에 의해 워크플로우에 두 번 추가되지 않습니다.
- **활성** -- 삭제하지 않고 트리거를 켜거나 끕니다.

:::tip
**양식 · 제출** 트리거를 **새 방문자 팔로우업** 템플릿과 쌍으로 하여 "연결 카드" 또는 "나 신규" 양식을 자동 팔로우업 파이프라인으로 바꾸세요.
:::

## 내 카드

자원봉사자와 직원이 모든 보드를 파고 자신의 업무를 찾을 필요가 없습니다. **내 카드** 페이지 (워크플로우 페이지에서 링크됨)는 모든 워크플로우에서 현재 사용자에게 할당된 모든 카드를 나열합니다. 카드를 클릭하면 카드가 속한 보드를 엽니다.

## 보고서

워크플로우를 열고 **보고서**를 클릭하여 해당 워크플로우의 분석을 확인하세요:

- **기한 초과** -- 만료 날짜가 지난 카드의 수.
- **단계별 카드** -- 현재 각 단계에 얼마나 많은 카드가 있는지, 열 차트로 표시됩니다.
- **완료됨 (30일)** -- 지난 30일 동안의 처리량, 꺾은선형 차트로 표시됩니다.

이를 사용하여 병목 현상을 감지하세요 -- 예를 들어, 카드가 축적되고 절대 진행하지 않는 단계입니다.
