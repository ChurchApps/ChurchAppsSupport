# 워크플로우

<div class="article-intro">

워크플로우는 사람들을 시각적 보드 위의 일련의 단계를 통해 이동시킵니다. 각 사람은 한 단계에서 다음 단계로 이동하는 카드가 됩니다 -- 초대 손님 팔로우업부터 회원 과정, 초대 기부자 감사 인사 등 같은 단계의 집합을 통해 많은 사람을 추적해야 할 때마다 가능합니다. 한 단계는 자원봉사자에게 무언가를 하도록 요청할 수 있습니다 (전화 걸기, 대화하기) **그리고** 자동 작업을 자체적으로 실행할 수 있습니다 -- 이메일 또는 문자 보내기, 며칠 기다리기, 그룹에 사람 추가하기 -- 따라서 워크플로우는 인적 팔로우업과 그 주변의 일상 업무를 모두 처리합니다. 워크플로우는 [작업](./tasks.md)을 드래그 앤 드롭 칸반 보드로 확장하므로 아무도 빠지지 않습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 추적하려는 사람이 B1 Admin에 존재하는지 확인하세요
- [작업](./tasks.md)이 어떻게 작동하는지 숙지하세요. 보드의 각 카드는 작업이기 때문입니다
- **이메일 보내기** 작업을 사용하려면 먼저 보내려는 이메일 템플릿을 만드세요 (**메시징 → 템플릿 관리** 아래에서 관리됨)
- **문자 보내기** 작업을 사용하려면 먼저 [문자 제공자](../settings/church-settings.md#texting)를 연결하세요
- 적절한 작업 권한이 필요합니다. 카드 보기, 편집, 워크플로우 관리는 별도의 권한 수준입니다 ([역할 및 권한](../settings/roles-permissions.md) 참조)

</div>

## 워크플로우 보기

[Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)를 열고 (B1 Admin의 왼쪽 위에 있는 검색 바), **사역**을 펼치고 **워크플로우**를 클릭하세요. 워크플로우가 카테고리별로 나열되고 그룹화되어 있으며, 활성 워크플로우가 강조되어 있습니다. 워크플로우를 클릭하면 보드가 열립니다.

## 워크플로우 만들기

1. 워크플로우 페이지에서 **워크플로우 추가**를 클릭하세요.
2. 시작 방법을 선택하세요:
   - **빈 워크플로우** -- 처음부터 시작하여 자신만의 단계를 구축하세요.
   - **템플릿에서** -- 편집할 수 있는 미리 만들어진 단계 집합으로 시작하세요. 기본 제공 템플릿은 다음을 포함합니다:
     - **새 방문객 팔로우업** -- 환영 이메일 보내기 → 개인 전화 → 다음 단계 초대 → 연결됨
     - **회원 수업** -- 관심 표현 → 수업 등록 → 수업 참석 → 회원 완료
     - **첫 기부자 감사 인사** -- 감사 편지 보내기 → 기부 영향력 공유 → 관리됨
3. 워크플로우에 **이름**을 지정하세요.
4. 선택적으로 **카테고리**를 할당하여 관련 워크플로우를 함께 그룹화하세요. 드롭다운에서 바로 새 카테고리를 만들 수 있습니다.
5. 워크플로우를 **활성**으로 유지하여 사람을 추가할 수 있도록 하거나, **비활성**으로 설정하여 워크플로우 추가 목록에서 숨기세요.
6. **저장**을 클릭하세요.

:::tip
워크플로우 목록의 **복제** 버튼을 사용하여 기존 워크플로우를 복사하세요 -- 단계, 자동 작업 및 라우팅을 포함합니다 -- 새로운 것의 시작점으로.
:::

## 단계를 사용하여 보드 구축하기

각 워크플로우 보드는 왼쪽에서 오른쪽으로 표시되는 **단계**로 구성됩니다. 워크플로우를 열고 **단계 추가**를 사용하여 프로세스의 각 단계를 만드세요.

단계를 추가하거나 편집할 때 다음을 구성할 수 있습니다:

- **단계 이름** -- 열 제목 (예: "환영 전화" 또는 "등록 대기중").
- **기한 (일)** -- 카드가 이 단계에 들어올 때 자동으로 기한을 설정합니다. 기한이 지난 카드는 **기한 초과**로 표시됩니다.
- **기본 담당자** -- 이 단계의 새 카드가 자동으로 할당되는 사람 또는 그룹.
- **자동 작업** -- 카드가 도착할 때 시스템이 자체적으로 수행하는 작업 (아래 참조).
- **라우팅** -- 카드가 단계를 떠날 때 가는 위치 ([결과 및 조건으로 카드 라우팅](#routing-cards-with-outcomes-and-conditions) 참조).

단계 열을 프로세스와 일치하는 순서로 드래그하세요. 순서는 또한 다른 라우팅이 적용되지 않을 때 카드가 취하는 기본 경로를 정의합니다.

:::info
새 단계를 먼저 저장하세요. 자동 작업 및 라우팅은 단계에 첨부되므로, 단계가 존재한 후 편집기가 해당 섹션을 잠금 해제합니다.
:::

## 자동 작업

모든 단계는 카드가 단계에 **진입**하는 순간 자체적으로 실행되는 **자동 작업** 목록을 수행할 수 있습니다 -- 아무도 만지기 전에. 이것이 단계가 자원봉사자를 **그리고** 팔로우업 주변의 일상 업무를 처리하는 방법입니다.

단계 편집기에서 **자동 작업**을 열고, **작업 추가**를 클릭하고, 유형을 선택하고, 설정을 입력하고, 해당 작업의 저장 아이콘을 클릭하세요. 필요한 만큼 추가하세요; 이들은 **위에서 아래로 순서대로** 실행됩니다.

| 작업 | 하는 일 |
|---|---|
| **이메일 보내기** | 사람에게 당신이 선택한 이메일 템플릿을 이메일합니다. 제목 줄을 재정의할 수 있습니다. |
| **문자 보내기** | 교회의 [문자 제공자](../settings/church-settings.md#texting)를 통해 당신이 작성한 메시지를 사람에게 문자합니다. |
| **대기** | 카드를 일정 일 동안 일시 중지한 후 계속됩니다 (아래 참조). |
| **그룹에 추가** | 사람을 당신이 선택한 [그룹](../groups/index.md)에 추가합니다. |
| **그룹에서 제거** | 사람을 당신이 선택한 그룹에서 제거합니다. |
| **워크플로우에 추가** | 사람을 다른 워크플로우에서 시작합니다 -- 프로세스 간 인계에 유용합니다. |
| **메모 추가** | 카드의 기록에 메모를 기록합니다. |
| **필드 설정** | 사람의 기록에서 필드를 업데이트합니다: 회원 상태, 결혼 상태, 성별, 도시, 주 또는 우편번호. |
| **웹훅** | 카드의 세부 정보를 당신이 제공한 외부 웹 주소 (URL)로 보냅니다 (다른 시스템 연결용). |
| **작업 만들기** | 당신이 입력한 제목과 설명으로 [작업](./tasks.md)을 만들고, 당신이 선택한 사람에게 할당합니다. |

단계의 모든 작업이 완료된 후 카드는 **해당 단계에서 휴식**하므로 사람이 작업할 수 있습니다 -- 단계에 카드를 앞으로 이동하는 자동 경로가 있지 않은 한 ([완전히 자동화된 단계](#fully-automated-steps) 참조).

:::info
자동 작업은 카드가 정상 흐름을 통해 도착할 때만 실행됩니다 -- 처음 추가될 때, 결과 또는 자동 경로가 나타날 때, 또는 대기가 끝난 후. 직원이 수동으로 카드를 단계로 드래그하거나 되돌릴 때는 다시 실행되지 않으므로, 사람이 같은 이메일을 두 번 받지 않습니다.
:::

### 이메일 보내기

**이메일 보내기**를 선택하고, 이메일 템플릿 중 하나를 선택하고, 선택적으로 사용자 정의 제목을 입력하세요. 카드가 단계에 들어가면, 사람이 그 이메일을 자동으로 받습니다. (사람이 파일에 이메일 주소가 없으면, 단계는 이 작업을 단순히 건너뜁니다.) 템플릿의 `{{firstName}}`과 같은 [병합 필드](../settings/email-templates.md#merge-fields)는 사람의 자신의 세부 정보로 채워집니다.

:::info
워크플로우 이메일은 교회가 그룹 이메일을 보낼 수 있도록 승인된 후에만 나갑니다, 그리고 교회의 일일 이메일 제한에 포함됩니다. [교회를 위해 그룹 이메일 켜기](../groups/group-members.md#turning-on-group-email-for-your-church) 참조.
:::

### 문자 보내기

**문자 보내기**를 선택하고 **텍스트 메시지**를 입력하세요 (최대 1,600자). 카드가 단계에 들어가면, 사람이 자신의 휴대폰에서 그 텍스트를 받습니다. `{{firstName}}`, `{{lastName}}`, `{{displayName}}`, 또는 `{{churchName}}`를 사용하여 메시지를 개인화할 수 있습니다. 이는 텍스트가 전송될 때 사람의 세부 정보로 채워집니다.

- 사람이 파일에 휴대폰이 없으면, 작업은 건너뜁니다.
- 사람이 옵트아웃했으면, 텍스트가 전송되지 않고 카드의 기록은 **문자 건너뜀: 옵트아웃**으로 표시합니다.
- 텍스트가 나가면, 카드의 기록은 **문자 전송됨**으로 표시합니다. 전송이 실패하면 -- 예를 들어, 문자 제공자가 연결되지 않았거나 교회가 문자 크레딧이 부족하기 때문에 -- 실패는 카드의 기록에 로깅되고 단계의 나머지 작업은 계속 실행됩니다.

:::warning
텍스트는 교회의 자신의 [문자 제공자](../settings/church-settings.md#texting)를 통해 전송됩니다. 제공자가 연결되지 않으면, 작업 편집기는 *"문자 제공자가 설정되지 않았습니다"*라고 경고하고 텍스트는 전송되지 않습니다.
:::

### 며칠 기다리기 (점적 수열)

**대기** 작업은 당신이 설정한 일 수 동안 카드를 보류합니다. 기다리는 동안, 카드는 **일시중지됨**으로 표시됩니다. 대기가 끝나면:

1. 같은 단계의 모든 **남은 작업**이 실행됩니다 -- 따라서 **이메일 보내기 → 3일 대기 → 상기 이메일 보내기**와 같은 점적을 구축할 수 있습니다.
2. 그러면, 단계에 자동 경로가 있으면 카드는 이동합니다; 그렇지 않으면 사람이 선택할 수 있도록 단계에서 휴식합니다.

:::tip
단계의 맨 처음의 **대기**는 카드를 자원봉사자 앞에 표시하기 전에 "보류"하는 간단한 방법입니다 -- 예를 들어, *7일 대기, 그러면 코치가 연락합니다*.
:::

## 카드로 사람 추가하기

사람을 보드에 추가하는 여러 가지 방법이 있습니다:

- **보드에서** -- 단계 열의 하단에서 **카드 추가**를 클릭하고 사람을 선택하세요. 그룹을 선택할 수도 있으며, 그 그룹의 모든 멤버가 카드로 추가됩니다.
- **사람의 기록에서** -- 사람의 페이지에서 **워크플로우에 추가**를 사용하여 그들을 워크플로우에 드롭하세요.
- **사람 검색에서** -- 여러 사람을 선택하고 일괄 **워크플로우에 추가** 작업을 사용하여 모두 한 번에 추가하세요.
- **트리거로 자동** -- 양식 제출 또는 첫 기부와 같이 무언가가 발생할 때 사람을 추가합니다 (아래 [트리거](#triggers) 참조).

## 보드 작업

워크플로우를 열어 보드를 보세요. 각 카드는 사람의 이름, 할당된 사람, 기한 또는 상태 칩 (**기한 초과** 또는 **일시중지됨**)을 표시합니다. 단계 열은 또한 실행하는 자동 작업의 작은 배지와 라우팅의 주석을 표시하여, 카드가 어떻게 흐르는지의 한눈에 보는 지도를 제공합니다.

- **카드 이동** -- 사람이 진행하면서 카드를 한 열에서 다음으로 드래그하세요.
- **카드 열기** -- 카드를 더블클릭하거나 (또는 클릭) 세부 정보 드로어를 열어, 단계를 변경하고, 다시 할당하고, 메모를 추가하고, 이미 발생한 일을 검토할 수 있습니다.

카드 드로어에서 당신은 다음을 할 수 있습니다:

- **할당** 카드를 다른 사람 또는 그룹에 지정하세요.
- **일시중지** 카드를 1일, 3일, 또는 1주 동안 일시중지하여 기한을 일시적으로 숨기세요.
- **뒤로 보내기** 이전 단계로 또는 **건너뛰기** 다음 단계로.
- **할당 고정** -- 카드가 단계 간 이동하더라도 같은 소유자를 카드에 유지합니다. 기본적으로, 카드를 새 단계로 이동하면 해당 단계의 기본 담당자에게 다시 할당됩니다; 고정은 전체 책임을 유지합니다.
- **완료** 카드를 완료하거나, 단계에 결과가 구성된 경우 **결과** 버튼을 선택합니다 ([라우팅](#routing-cards-with-outcomes-and-conditions) 참조).
- **메모 추가** 및 카드의 **기록** 검토 -- 실행된 자동 작업의 로그 포함 (보낸 이메일, 대기 등).

### 일괄 작업

여러 카드의 확인란을 선택하여 함께 작업하세요. 도구 모음이 나타나 모든 선택한 카드를 **완료**, **일시중지**, **다시 할당**, 또는 한 번에 다른 단계로 **이동**할 수 있습니다.

## 결과 및 조건으로 카드 라우팅

라우팅은 카드가 단계를 떠날 때 가는 위치를 제어합니다. 단계의 편집기를 열어 두 가지 라우팅을 구성하세요.

### 결과 버튼

결과는 해당 단계의 카드를 완료할 때 카드 드로어에 표시되는 버튼입니다. 단일 **완료** 버튼 대신, "그룹에 참여" 또는 "관심 없음"과 같은 선택을 제공할 수 있습니다. 각 결과는 다음을 할 수 있습니다:

- 카드를 이 워크플로우의 **다른 단계**로 보내기,
- **카드를 완전히 다른 워크플로우**로 인계하기, 또는
- 카드를 **닫기**.

이것은 한 결정이 사람을 다른 경로로 분기할 수 있도록 합니다.

### 자동 라우팅 (조건부)

자동 라우팅은 카드가 단계에 **진입하는 순간** 카드를 이동시킵니다 (그리고 자동 작업이 완료된 후), 아무도 클릭하지 않고, 사람이 조건 집합과 일치하는 경우. 경로를 추가하고, 대상 단계를 선택하고, 하나 이상의 **조건**을 정의합니다 (예를 들어, 사람의 캠퍼스, 나이, 또는 회원 상태). 조건이 없는 경로는 모두와 일치합니다.

:::info
보드에서, 각 단계 열은 라우팅을 설명하는 작은 주석을 표시합니다 -- 예를 들어, 결과 레이블 또는 "일치하면" 이어서 목적지 단계 또는 워크플로우로의 화살표.
:::

## 완전히 자동화된 단계

단계가 완전히 자체적으로 실행되도록 할 수 있습니다, 아무도 작동하지 않고. 단계에 **자동 작업**을 제공하고 다음 단계를 가리키는 **자동 경로** (조건 없음)를 추가합니다. 카드가 들어가면, 작업이 실행되고, 경로가 즉시 이를 진행합니다 -- 카드는 통과합니다.

:::tip
이를 **대기**와 결합하세요: *환영 이메일 보내기 → 3일 대기 → "개인 전화" 단계로 자동 진행합니다.* 이메일과 타이밍은 처리되고, 자원봉사자는 인적 접촉이 시간일 때만 카드를 봅니다.
:::

## 트리거

트리거는 무언가가 발생할 때 사람을 워크플로우에 자동으로 추가하므로, 카드를 수동으로 추가할 필요가 없습니다. 워크플로우 보드에서 **트리거** 탭을 클릭하고, **트리거 추가**를 하세요. 두 가지 종류가 있습니다:

### 이벤트 트리거

B1의 기록이 변경되는 순간 실행됩니다. 이벤트를 선택한 다음, 선택적으로 **조건**을 추가하여 일치하는 사람만 추가됩니다:

- **사람 · 생성됨 / 업데이트됨** -- 예: 상태가 *방문객*이 되는 모든 사람을 추가합니다.
- **기부 · 생성됨** -- 예: 첫 번째 또는 큰 기부를 감사 워크플로우에 추가합니다 (금액, 기금 또는 방법으로 일치).
- **그룹 · 멤버 참여** / **그룹 · 생성됨**.
- **양식 · 제출됨** -- 선택한 양식을 제출하는 모든 사람을 추가합니다 ("새로운", "연결" 카드에 좋음).

### 일정 트리거

반복적으로 실행됩니다 -- 매일, 매주, 매월, 또는 매년 -- 조건 집합에 대해. *회원 기념일이 오늘인 모든 사람* 또는 *월간* 체크인과 같은 시간 기반 아웃리치에 사용합니다.

모든 트리거에 대해 당신은 또한 설정할 수 있습니다:

- 새 카드가 시작하는 **진입 단계** (첫 번째 단계로 기본값).
- **사람당 한 번** -- 같은 사람이 트리거에 의해 워크플로우에 두 번 추가되지 않도록.
- **활성** -- 삭제하지 않고 트리거를 켜거나 끕니다.

:::tip
**양식 · 제출됨** 트리거를 **새 방문객 팔로우업** 템플릿과 짝지어 "연결 카드" 또는 "새로운" 양식을 자동 팔로우업 파이프라인으로 변환합니다.
:::

## 내 카드

자원봉사자 및 직원은 모든 보드를 파고 자신의 업무를 찾을 필요가 없습니다. **내 카드** 페이지 (워크플로우 페이지에서 연결됨)는 모든 워크플로우에 걸쳐 현재 사용자에게 할당된 모든 카드를 나열합니다. 카드를 클릭하면 그것이 속한 보드가 열립니다.

## 보고서

워크플로우를 열고 **보고서**를 클릭하여 해당 워크플로우의 분석을 보세요:

- **기한 초과** -- 기한이 지난 카드의 수.
- **단계당 카드** -- 현재 각 단계에 앉아 있는 카드 수, 열 차트로 표시.
- **완료됨 (30일)** -- 지난 30일에 걸친 처리량, 라인 차트로 표시.

이를 사용하여 병목 현상을 발견하세요 -- 예를 들어, 카드가 축적되고 절대 진행하지 않는 단계.
