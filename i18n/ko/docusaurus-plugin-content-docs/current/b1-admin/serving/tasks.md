# 작업

<div class="article-intro">

작업을 사용하면 교회의 사람이나 그룹에 작업 항목을 할당할 수 있습니다. 일회성 작업이든 반복되는 책임이든 작업은 무엇을 해야 하는지 그리고 누가 책임이 있는지 추적하는 데 도움이 되므로 아무것도 간과되지 않습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 작업을 할당하려는 사람 또는 [그룹](../groups/creating-groups.md)이 B1 Admin에 존재하는지 확인합니다
- **봉사** 섹션으로 이동하고 **내 작업**을 열어 작업을 봅니다

</div>

## 작업 보기

**봉사**로 이동하고 **내 작업**을 엽니다. 공개 작업 목록이 표시됩니다. 각 작업은 제목, 할당 담당자 및 상태를 표시합니다.

:::tip
기본적으로 공개 작업만 표시됩니다. **종료된 작업 표시**를 전환하여 완료된 작업도 봅니다.
:::

## 작업 만들기

1. 작업 페이지에서 **작업 추가**를 클릭합니다.
2. 작업의 **제목**을 입력합니다.
3. **할당 대상** 상자를 클릭하고 사람의 이름을 입력하거나 **그룹**으로 전환하고 그룹 이름을 입력합니다.
4. **검색**을 클릭하고 결과에서 사람이나 그룹을 선택합니다.
5. 할당 담당자에 대한 세부 정보 또는 지침이 있는 **메모**를 추가합니다.
6. **저장**을 클릭합니다.

작업이 이제 작업 목록에 나타나고 할당 담당자의 대시보드 및 모바일 앱에서 볼 수 있습니다.

## 작업 관리

모든 작업을 클릭하여 세부 정보 페이지를 엽니다. 여기에서 다음을 할 수 있습니다:

- **상태 변경** -- 상태 드롭다운을 사용하여 **공개**와 **종료** 사이를 전환합니다.
- **작업 재할당** -- 할당 담당자를 다른 사람이나 그룹으로 업데이트합니다.
- **메모 추가** -- 할당 담당자에 대한 추가 정보 또는 업데이트를 포함합니다.
- **제목 편집** -- 필요에 따라 작업 제목을 업데이트합니다.

## 작업 수명 주기

1. 새 작업은 **공개** 상태로 시작합니다.
2. 할당 담당자는 알림을 받고 대시보드, **봉사 > 내 작업** 또는 모바일 앱에서 작업을 볼 수 있습니다.
3. 작업이 완료되면 할당 담당자(또는 관리자)가 상태를 **종료**로 변경합니다.
4. 종료된 작업은 기본 보기에서 제거되지만 **종료된 작업 표시**를 활성화하여 여전히 액세스할 수 있습니다.

:::info
B1 Admin은 더 이상 일정에 따라 반복 작업을 만들지 않습니다. 사람과의 반복적인 후속을 위해 [일정 트리거](./workflows.md#schedule-triggers)가 있는 [워크플로우](./workflows.md)를 사용하세요.
:::

:::tip
새 방문자 추적 또는 회원십 프로세스와 같이 많은 사람들을 동일한 단계 집합을 통해 이동해야 할 때 [워크플로우](./workflows.md)를 사용하세요. 워크플로우는 단계, 기한 및 라우팅이 있는 드래그 앤 드롭 보드의 작업을 카드로 변환합니다.
:::

:::info
일부 작업은 B1의 다른 부분에서 자동으로 생성되며 표준 메모/재할당 보기 대신 특별한 검토 카드로 열립니다. [그룹 참여 요청](../groups/group-join-requests.md#approving-from-the-tasks-page), [프로필 변경 요청](../profile/approving-profile-changes.md) 및 [계정 삭제 요청](../profile/account-deletion.md)은 모두 이런 식으로 작동합니다.
:::
