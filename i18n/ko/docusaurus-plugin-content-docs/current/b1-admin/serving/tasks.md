# 작업

<div class="article-intro">

작업을 사용하면 교회의 사람 또는 그룹에 작업 항목을 할당할 수 있습니다. 일회성 할 일이든 반복되는 책임이든 작업은 무엇을 해야 하고 누가 책임인지 추적하여 아무것도 간과되지 않도록 도와줍니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 작업을 할당하려는 사람 또는 [그룹](../groups/creating-groups.md)이 B1 Admin에 존재하는지 확인하세요
- [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)에서 **섬김 > 내 작업**을 선택하여 작업을 보세요

</div>

## 작업 보기

Jump 메뉴에서 **섬김 > 내 작업**을 선택하세요(또는 "내 작업"을 검색하세요). **작업** 목록에는 각 작업의 제목, 연관된 사람, 할당된 사람, 열린 날짜 및 상태가 표시됩니다. 목록과 함께 **My Cards** 아래에 [워크플로우](./workflows.md) 카드가 나타납니다.

목록 위의 탭을 사용하여 **Assigned to Me**(내게 할당됨), **Assigned to My Groups**(내 그룹에 할당됨), **Requested by Me**(내가 요청함) 작업 간에 전환하세요. 각 탭에는 보유한 작업 수가 표시됩니다.

:::tip
기본적으로 열려있는 작업만 표시됩니다. 완료된 작업을 보려면 목록 위에서 **Closed**를 선택하세요.
:::

## 작업 만들기

1. **내 작업** 페이지에서 **작업 추가**를 클릭하세요. **New Task** 양식이 열립니다.
2. **Associate with** 상자를 클릭하고 작업과 관련된 사람을 선택하세요.
3. **Assign to** 상자를 클릭하세요. **Select a Person or Group** 창에서 **Person** 탭으로 검색하거나 **Group** 탭으로 전환하여 그룹을 검색한 다음 결과를 선택하세요.
4. 작업의 **제목**을 입력하세요.
5. 담당자를 위한 세부 정보 또는 지침이 있는 **메모**를 추가하세요.
6. **저장**을 클릭하세요.

작업이 이제 작업 목록에 나타나고 담당자의 대시보드 및 모바일 앱에 표시됩니다.

## 작업 관리

모든 작업을 클릭하여 상세 페이지를 열어보세요. 여기서 다음을 할 수 있습니다:

- **작업 종료 또는 다시 열기** -- 작업이 끝나면 **Close task**를 클릭하세요. 다시 열려면 **Reopen task**를 클릭하세요.
- **작업 재할당** -- **Assign**을 클릭하여 다른 사람 또는 그룹을 선택하세요.
- **관련 대상 변경** -- **Associate**를 클릭하여 다른 사람을 선택하세요.
- **메모 추가** -- 작업의 메모에 담당자를 위한 업데이트 또는 세부 정보를 게시하세요.
- **알림 설정** -- 아래의 [작업 알림](#task-reminders)을 참조하세요.

## 작업 알림 {#task-reminders}

마감일이 있는 작업은 마감 전에 담당자에게 알림을 보낼 수 있습니다.

1. 작업 페이지에서 **Reminders** 옆의 **편집**을 클릭하세요.
2. **Send reminders for this task**를 켜세요.
3. **When should reminders go out?**에서 최대 세 가지 시점을 선택하세요: **7 days before**, **3 days before**, **1 day before**, 또는 **Day of**.
4. **Time of Day**를 설정하고 선택 사항으로 **Message**를 입력하세요.
5. **Send By**에서 **Push**, **Email** 및, 교회에 [문자 제공자](../settings/church-settings.md#texting)가 연결되어 있다면 **Text**를 선택하세요.
6. **Save Reminders**를 클릭하세요.

작업에 마감일이 없으면 B1은 마감일을 설정하기 전까지 알림이 전송되지 않는다고 경고합니다. 문자 알림은 [알림 설정](../../b1-church/getting-started/notification-preferences.md)에서 **문자 메시지**를 켠 사람에게만 전달되며, 각 문자는 교회에 비용이 발생할 수 있습니다.

## 작업 수명 주기

1. 새 작업은 **열기** 상태로 시작합니다.
2. 담당자는 알림을 받고 대시보드, **섬김 > 내 작업** 또는 모바일 앱에서 작업을 볼 수 있습니다.
3. 작업이 완료되면 담당자(또는 관리자)가 **Close task**를 클릭합니다.
4. 종료된 작업은 기본 보기에서 제거되지만 작업 목록 위의 **Closed**를 선택하여 찾을 수 있습니다.

:::info
B1 Admin은 더 이상 일정에 따라 반복되는 작업을 만들지 않습니다. 사람과의 반복 팔로우업의 경우 [일정 트리거](./workflows.md#schedule-triggers)를 사용하여 [워크플로우](./workflows.md)를 사용하세요.
:::

:::tip
새 방문자 팔로우업 또는 멤버십 프로세스와 같이 많은 사람을 동일한 단계를 거쳐 이동시켜야 할 때 [워크플로우](./workflows.md)를 사용하세요. 워크플로우는 작업을 단계, 기한 및 라우팅이 있는 끌어서 놓기 보드의 카드로 변환합니다.
:::

:::info
일부 작업은 B1의 다른 부분에서 자동으로 생성되고 표준 메모/재할당 보기 대신 특별한 검토 카드로 열립니다 -- [그룹 가입 요청](../groups/group-join-requests.md#approving-from-the-tasks-page), [프로필 변경 요청](../profile/approving-profile-changes.md) 및 [계정 삭제 요청](../profile/account-deletion.md)이 모두 이런 식으로 작동합니다.
:::

- [워크플로우](./workflows.md)를 사용하여 사람을 반복 가능한 프로세스를 거쳐 자동으로 이동시키세요
