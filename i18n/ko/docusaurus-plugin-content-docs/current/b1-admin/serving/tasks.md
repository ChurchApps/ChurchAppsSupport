# 작업

<div class="article-intro">

작업을 사용하면 교회의 사람 또는 그룹에 작업 항목을 할당할 수 있습니다. 일회성 할 일이든 반복되는 책임이든 작업은 무엇을 해야 하고 누가 책임인지 추적하여 아무것도 간과되지 않도록 도와줍니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 작업을 할당하려는 사람 또는 [그룹](../groups/creating-groups.md)이 B1 Admin에 존재하는지 확인하세요
- [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)에서 **섬김 > 내 작업**을 선택하여 작업을 보세요

</div>

## 작업 보기

Jump 메뉴에서 **섬김 > 내 작업**을 선택하세요(또는 "내 작업"을 검색하세요). 열려있는 작업 목록이 표시됩니다. 각 작업은 제목, 담당자 및 상태를 표시합니다.

:::tip
기본적으로 열려있는 작업만 표시됩니다. **종료된 항목 표시**를 토글하여 완료된 작업도 보세요.
:::

## 작업 만들기

1. 작업 페이지에서 **작업 추가**를 클릭하세요.
2. 작업의 **제목**을 입력하세요.
3. **할당 대상** 상자를 클릭하고 사람의 이름을 입력하거나 **그룹**으로 전환하고 그룹 이름을 입력하세요.
4. **검색**을 클릭하고 결과에서 사람 또는 그룹을 선택하세요.
5. 담당자를 위한 세부 정보 또는 지침이 있는 **메모**를 추가하세요.
6. **저장**을 클릭하세요.

작업이 이제 작업 목록에 나타나고 담당자의 대시보드 및 모바일 앱에 표시됩니다.

## 작업 관리

모든 작업을 클릭하여 상세 페이지를 열어보세요. 여기서 다음을 할 수 있습니다:

- **상태 변경** -- 상태 드롭다운을 사용하여 **열기** 및 **종료** 사이를 전환합니다.
- **작업 재할당** -- 담당자를 다른 사람 또는 그룹으로 업데이트합니다.
- **메모 추가** -- 담당자를 위한 추가 정보 또는 업데이트를 포함합니다.
- **제목 편집** -- 필요에 따라 작업 제목을 업데이트합니다.

## 작업 수명 주기

1. 새 작업은 **열기** 상태로 시작합니다.
2. 담당자는 알림을 받고 대시보드, **섬김 > 내 작업** 또는 모바일 앱에서 작업을 볼 수 있습니다.
3. 작업이 완료되면 담당자(또는 관리자)가 상태를 **종료**로 변경합니다.
4. 종료된 작업은 기본 보기에서 제거되지만 **종료된 항목 표시**를 사용하여 액세스할 수 있습니다.

:::info
B1 Admin은 더 이상 일정에 따라 반복되는 작업을 만들지 않습니다. 사람과의 반복 팔로우업의 경우 [일정 트리거](./workflows.md#schedule-triggers)를 사용하여 [워크플로우](./workflows.md)를 사용하세요.
:::

:::tip
새 방문자 팔로우업 또는 멤버십 프로세스와 같이 많은 사람을 동일한 단계를 거쳐 이동시켜야 할 때 [워크플로우](./workflows.md)를 사용하세요. 워크플로우는 작업을 단계, 기한 및 라우팅이 있는 끌어서 놓기 보드의 카드로 변환합니다.
:::

:::info
일부 작업은 B1의 다른 부분에서 자동으로 생성되고 표준 메모/재할당 보기 대신 특별한 검토 카드로 열립니다 -- [그룹 가입 요청](../groups/group-join-requests.md#approving-from-the-tasks-page), [프로필 변경 요청](../profile/approving-profile-changes.md) 및 [계정 삭제 요청](../profile/account-deletion.md)이 모두 이런 식으로 작동합니다.
:::

- [워크플로우](./workflows.md)를 사용하여 사람을 반복 가능한 프로세스를 거쳐 자동으로 이동시키세요
