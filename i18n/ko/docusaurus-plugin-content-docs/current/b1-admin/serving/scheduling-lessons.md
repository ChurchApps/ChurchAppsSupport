# Lessons.church에서 수업 일정 잡기
<div class="article-intro">
B1 Admin은 [Lessons.church](https://lessons.church)와 직접 통합되어 서비스 계획 내에서 교실용 교육 과정을 일정할 수 있습니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- 섬김 영역에서 사역을 설정합니다
- 활성 [Lessons.church](https://lessons.church) 계정이 있어야 합니다
</div>
## Step 1 — Lessons.church 계정 연결
1. B1 Admin으로 로그인하고 **섬김**으로 이동합니다
2. 연결할 사역을 엽니다
3. **콘텐츠 제공자 계정** 섹션으로 스크롤합니다
4. **새 제공자 연결**을 클릭합니다
5. **Lessons.church**를 선택합니다
6. 디바이스 인증 코드가 표시됩니다
7. [lessons.church](https://lessons.church)로 가서 로그인하고 코드를 입력합니다
## Step 2 — 수업 일정 잡기
1. B1 Admin에서 **섬김 → 계획**으로 이동합니다
2. 사역 탭을 선택하고 **계획 유형 추가**를 클릭합니다
3. 계획 유형 이름을 입력합니다
4. 계획 유형을 클릭하고 **수업 일정**을 선택합니다
5. **날짜**를 선택합니다 (기본값: 다음 주일)
6. **수업 선택**을 클릭합니다
7. **Lessons.church**가 제공자로 선택되어 있는지 확인합니다
8. 콘텐츠를 탐색합니다:
   - **프로그램** 선택 (예: "성경 이야기")
   - **공부** 선택
   - **수업** 선택
   - **장소** 선택 (연령대)
9. **수업 연결**을 클릭합니다
10. 자원봉사자 복사 옵션을 선택합니다
11. **저장**을 클릭합니다
