# 디지털 사이니지

<div class="article-intro">

디지털 사이니지 피드를 사용하여 로비나 복도 TV로 수업 콘텐츠를 보냅니다. 각 계획 유형은 현재 계획의 콘텐츠를 항상 재생하는 피드 URL을 가져오므로 주마다 업데이트할 내용이 없습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [Lessons.church](../content/lessons.md) 또는 기타 수업 콘텐츠가 예약된 [계획 유형](./plans.md) 설정
- [SignPresenter](https://www.signpresenter.com) 계정 및 표시하도록 설정된 기기 필요

</div>

## 피드 URL 받기

1. **Serving**으로 이동한 후 계획 유형이 포함된 사역을 엽니다.
2. 계획 유형 페이지의 **디지털 사이니지** 버튼(RSS 아이콘)을 클릭합니다.
3. 대화에 표시된 피드 URL을 복사합니다.

:::info
피드 URL은 단일 계획이 아닌 계획 유형과 연결됩니다. 자동으로 해당 계획 유형에 대해 현재로 예약된 계획을 추적하므로 한 번만 설정하면 됩니다.
:::

## SignPresenter에 연결

피드는 [SignPresenter](https://www.signpresenter.com)(타사 디지털 사이니지 앱)와 함께 작동하도록 구축되었습니다. 복사한 URL을 SignPresenter에 외부 피드로 붙여 넣어 연결된 화면에 현재 수업 콘텐츠를 표시합니다.

SignPresenter 내 단계별 설정은 [SignPresenter의 Lessons.church 가이드](https://support.signpresenter.com/topics/lessons-dot-church.html)를 참조하세요.
