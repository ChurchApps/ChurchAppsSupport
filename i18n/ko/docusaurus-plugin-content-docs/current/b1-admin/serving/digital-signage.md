# 디지털 사이니지
<div class="article-intro">
디지털 사이니지 피드를 사용하여 로비 또는 복도 TV에 수업 콘텐츠를 보냅니다. 각 계획 유형은 피드를 받으므로, 매주 업데이트할 필요가 없습니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- [계획 유형](./plans.md)이 [Lessons.church](../content/lessons.md) 또는 다른 수업 콘텐츠로 설정되어야 합니다
- [SignPresenter](https://www.signpresenter.com) 계정과 디스플레이할 디바이스가 있어야 합니다
</div>

## 피드 URL 가져오기

1. **섬김**으로 이동하고 계획 유형이 있는 사역을 엽니다
2. 계획 유형 페이지에서 **디지털 사이니지** 버튼 (RSS 아이콘)을 클릭합니다
3. 대화에 표시된 피드 URL을 복사합니다

:::info
피드 URL은 계획 유형과 연결되어 있습니다. 자동으로 그 계획 유형의 현재 계획을 추적하므로, 한 번만 설정하면 됩니다.
:::

## SignPresenter에 연결

피드는 [SignPresenter](https://www.signpresenter.com)와 함께 작동하도록 만들어졌습니다. 복사한 URL을 SignPresenter에 외부 피드로 붙여넣어 연결된 화면에 현재 수업 콘텐츠를 표시합니다.

SignPresenter 내에서 단계별 설정은 [SignPresenter의 Lessons.church 가이드](https://support.signpresenter.com/topics/lessons-dot-church.html)를 참고합니다.
