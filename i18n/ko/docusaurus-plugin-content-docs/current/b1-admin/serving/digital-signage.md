# 디지털 사이니지

<div class="article-intro">

디지털 사이니지 피드를 사용하여 로비 또는 복도 TV로 레슨 콘텐츠를 보냅니다. 각 계획 유형은 항상 현재 계획의 콘텐츠를 재생하는 피드 URL을 가져오므로 매주 업데이트할 필요가 없습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [Lessons.church](../../b1-church/content/lessons.md) 또는 기타 레슨 콘텐츠가 예약된 [계획 유형](./plans.md)을 설정합니다
- [SignPresenter](https://www.signpresenter.com) 계정과 이를 표시하기 위해 설정된 장치가 있습니다

</div>

## 피드 URL 가져오기

1. **봉사**로 이동하여 계획 유형이 포함된 사역을 엽니다.
2. 계획 유형 페이지에서 **디지털 사이니지** 버튼(RSS 아이콘)을 클릭합니다.
3. 대화 상자에 표시된 피드 URL을 복사합니다.

:::info
피드 URL은 단일 계획이 아닌 계획 유형에 연결됩니다. 해당 계획 유형에 대해 현재로 예약된 계획을 자동으로 추적하므로 한 번만 설정하면 됩니다.
:::

## SignPresenter에 연결

피드는 타사 디지털 사이니지 앱인 [SignPresenter](https://www.signpresenter.com)와 함께 작동하도록 구축되었습니다. 복사한 URL을 SignPresenter에 외부 피드로 붙여넣어 연결된 화면에 현재 레슨 콘텐츠를 표시합니다.

SignPresenter 내에서 단계별 설정은 [SignPresenter의 Lessons.church 가이드](https://support.signpresenter.com/topics/lessons-dot-church.html)를 참조하세요.
