# 디지털 사이니지

<div class="article-intro">

디지털 사이니지 피드를 사용하면 로비나 복도의 TV에 수업 콘텐츠를 보낼 수 있습니다. 계획 유형마다 피드 URL이 생성되며, 이 URL은 항상 현재 계획의 콘텐츠를 재생하므로 매주 업데이트할 필요가 없습니다. TV가 FreePlay를 실행한다면, 대신 FreePlay Admin에서 해당 계획 유형을 TV에 예약할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [Lessons.church](../../b1-church/content/lessons.md) 또는 다른 수업 콘텐츠가 예약된 [계획 유형](./plans.md)을 설정하세요
- [SignPresenter](https://www.signpresenter.com) 계정과 이를 표시할 기기를 준비하거나, [FreePlay](../../freeplay/)를 실행하는 TV를 준비하세요

</div>

## 피드 URL 가져오기

1. **Serving**으로 이동하여 계획 유형이 포함된 사역을 선택하고, 계획 유형을 클릭하여 엽니다.
2. 계획 유형 페이지 상단의 **Digital Signage**(TV 아이콘)를 클릭합니다.
3. **Digital Signage Feed** 대화 상자에서 **Feed Url** 옆의 복사 버튼을 클릭합니다.

:::info
피드 URL은 단일 계획이 아니라 계획 유형에 연결되어 있습니다. 해당 계획 유형의 현재 계획으로 지정된 계획을 자동으로 따라가므로, 한 번만 설정하면 됩니다.
:::

## SignPresenter에 연결하기

이 피드는 타사 디지털 사이니지 앱인 [SignPresenter](https://www.signpresenter.com)와 함께 작동하도록 만들어졌습니다. 복사한 URL을 SignPresenter에 외부 피드로 붙여넣으면, 연결된 화면에 현재 수업 콘텐츠를 표시할 수 있습니다.

SignPresenter 안에서의 단계별 설정은 [SignPresenter의 Lessons.church 가이드](https://support.signpresenter.com/topics/lessons-dot-church.html)를 참고하세요. 대화 상자에도 이 안내로 연결되는 링크가 있습니다.

## 대신 FreePlay TV 사용하기

화면이 [FreePlay](../../freeplay/)를 실행한다면 피드 URL이 필요하지 않습니다. **Digital Signage Feed** 대화 상자에는 **admin.freeplay.church/calendar**로 연결되는 링크가 있으며, 여기서 FreePlay TV에 이 계획 유형을 예약할 수 있습니다:

1. 대화 상자의 **admin.freeplay.church/calendar** 링크를 클릭합니다. FreePlay Admin은 B1 Admin과 같은 로그인 정보를 사용합니다.
2. TV용 화면 그룹을 선택하고 **Add schedule**을 클릭합니다.
3. **Play**에서 **Service plans** 중 원하는 계획 유형을 선택합니다. 현재 계획이라는 표시인 **(current plan)**이 붙어 있습니다.
4. 요일과 시간을 설정한 후 **Save**를 클릭합니다.

TV는 설정한 시간에 매주 해당 계획 유형의 현재 계획을 재생합니다. 모든 옵션은 [캘린더 예약하기](../../freeplay/scheduled-mode/scheduling-the-calendar)를, TV를 추가하는 방법은 [화면 페어링하기](../../freeplay/scheduled-mode/pairing-a-screen)를 참고하세요.
