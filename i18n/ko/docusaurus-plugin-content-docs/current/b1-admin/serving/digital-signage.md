# 디지털 사이니지 {#digital-signage}

<div class="article-intro">

디지털 사이니지 피드를 사용하여 공과 자료 내용을 로비나 복도의 TV에 보내세요. 일정 유형마다 피드 URL이 생성되며, 이 URL은 항상 현재 일정의 내용을 재생하므로 매주 업데이트할 것이 없습니다. TV에서 FreePlay를 실행하고 있다면, 대신 FreePlay 관리자에서 해당 기기에 일정 유형을 예약할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [Lessons.church](../../b1-church/content/lessons.md) 또는 다른 공과 자료가 예약된 [일정 유형](./plans.md)을 설정하세요
- [SignPresenter](https://www.signpresenter.com) 계정과 이를 표시할 기기를 준비하거나, [FreePlay](../../freeplay/)를 실행하는 TV를 준비하세요

</div>

## 피드 URL 얻기 {#getting-the-feed-url}

1. **섬김**으로 이동하여 일정 유형이 포함된 사역을 선택하고, 일정 유형을 클릭하여 엽니다.
2. 일정 유형 페이지 상단의 **디지털 사이니지**(TV 아이콘)를 클릭합니다.
3. **디지털 사이니지 피드** 대화상자에서 **피드 URL** 옆의 복사 버튼을 클릭합니다.

:::info
피드 URL은 단일 일정이 아니라 일정 유형에 연결되어 있습니다. 그 일정 유형에 대해 현재로 예약된 일정을 자동으로 따라가므로, 한 번만 설정하면 됩니다.
:::

## SignPresenter에 연결하기 {#connecting-to-signpresenter}

이 피드는 타사 디지털 사이니지 앱인 [SignPresenter](https://www.signpresenter.com)와 함께 작동하도록 만들어졌습니다. 복사한 URL을 SignPresenter에 외부 피드로 붙여 넣으면, 연결된 화면에 현재 공과 자료 내용이 표시됩니다.

SignPresenter 안에서 단계별 설정 방법은 [SignPresenter의 Lessons.church 가이드](https://support.signpresenter.com/topics/lessons-dot-church.html)를 참조하세요. 대화상자에도 이 안내 링크가 있습니다.

## 대신 FreePlay TV 사용하기 {#using-freeplay-tvs-instead}

화면에서 [FreePlay](../../freeplay/)를 실행한다면 피드 URL이 필요하지 않습니다. **디지털 사이니지 피드** 대화상자에는 **admin.freeplay.church/calendar** 링크가 있으며, 여기서 FreePlay TV에 이 일정 유형을 예약할 수 있습니다.

1. 대화상자의 **admin.freeplay.church/calendar** 링크를 클릭합니다. FreePlay 관리자는 B1 Admin과 같은 로그인을 사용합니다.
2. TV에 해당하는 화면 그룹을 선택하고 **일정 추가**를 클릭합니다.
3. **재생**에서 **섬김 일정**의 일정 유형을 선택합니다. 현재 일정은 **(현재 일정)**으로 표시됩니다.
4. 요일과 시간을 설정한 다음 **저장**을 클릭합니다.

TV는 설정한 시간에 맞춰 매주 그 일정 유형의 현재 일정을 재생합니다. 사용자 지정한 일정을 포함하여 Go Curriculum 자료에도 이 방법이 작동합니다. FreePlay는 **콘텐츠 제공자** 아래에서 사역에 연결된 Go Curriculum 계정으로 로그인하며(자세한 내용은 [공과 자료 예약하기](./scheduling-lessons.md) 참조), 사역에 연결된 계정이 없다면 교회의 Go Curriculum 연결을 사용합니다. 모든 옵션은 [달력 예약하기](../../freeplay/scheduled-mode/scheduling-the-calendar)를, TV를 추가하려면 [화면 페어링하기](../../freeplay/scheduled-mode/pairing-a-screen)를 참조하세요.

:::note
피드 URL에는 Go Curriculum 미디어가 포함되지 않습니다. 이 자료에는 교회의 Go Curriculum 로그인이 필요하기 때문입니다. 로비나 교실 TV에 Go Curriculum 공과 자료를 표시하려면 FreePlay를 사용하세요.
:::
