# 계획 템플릿

<div class="article-intro">

계획 템플릿을 사용하면 계획의 예배 순서나 위치의 재사용 가능한 스냅샷을 저장하고 한 번의 클릭으로 향후 계획에 적용할 수 있습니다. 매주 동일한 구조를 다시 작성하는 대신 한 번 저장하고 필요한 만큼 많은 향후 계획에 스탬프합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 예배 순서 또는 위치가 정의된 최소 하나의 [서비스 계획](plans.md) 생성
- Serving 영역의 액세스 필요

</div>

## 계획을 템플릿으로 저장

1. **Serving** 영역에서 기존 계획을 엽니다.
2. **템플릿** 버튼(계획 페이지 상단)을 클릭합니다.
3. **템플릿으로 저장**을 선택합니다.
4. 템플릿에 이름을 지정합니다(예: "표준 주일" 또는 "예배 + 설교").
5. 저장합니다. 템플릿은 그 순간 계획의 현재 예배 순서와 위치를 캡처합니다.

## 템플릿 관리

모든 계획 유형 페이지의 **템플릿** 버튼에서 다음을 수행할 수 있습니다:

- **이름 변경** — 템플릿의 표시 이름 변경
- **계획에서 업데이트** — 템플릿의 콘텐츠를 계획의 현재 상태로 바꾸기(표준 구조를 개선한 후 유용)
- **적용** — 하나 이상의 향후 계획에 템플릿 스탬프
- **삭제** — 더 이상 필요하지 않은 템플릿 제거

## 계획에 템플릿 적용

1. 계획 유형 페이지의 **템플릿** 버튼을 클릭합니다.
2. 사용하려는 템플릿 옆의 **적용** 아이콘(복사 아이콘)을 클릭합니다.
3. 상자를 확인하여 적용할 향후 계획을 선택합니다.
4. 복사할 항목을 선택합니다:
   - **예배 순서** — 선택한 계획의 서비스 순서 항목을 템플릿의 항목으로 바꿉니다
   - **위치** — 선택한 계획의 위치(및 해당 할당)를 템플릿의 위치로 바꿉니다
5. **적용**을 클릭합니다.

:::warning
위치 적용은 선택한 계획의 모든 기존 위치 및 할당을 바꿉니다. 위치를 적용하기 전에 자원봉사자를 이미 해당 위치에 예약하지 않았는지 확인하세요.
:::

:::tip
위치 없이 예배 순서를 적용하여 일관된 노래/설교 구조를 원하지만 자원봉사자가 각 주에 다르게 할당된 경우.
:::

## 템플릿을 최신 상태로 유지

표준 서비스 구조가 변경되면 템플릿 관리자를 열고 **계획에서 업데이트**를 사용하여 최신 계획에서 템플릿을 동기화합니다.
