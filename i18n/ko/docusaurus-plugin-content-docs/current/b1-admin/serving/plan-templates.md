# 계획 템플릿

<div class="article-intro">

계획 템플릿을 사용하면 계획의 예배 순서나 자리 구성을 재사용할 수 있는 스냅샷으로 저장하고, 한 번의 클릭으로 앞으로의 계획에 적용할 수 있습니다. 매주 같은 구조를 다시 만드는 대신, 한 번 저장해 두고 필요한 만큼 다가오는 계획에 찍어 쓰세요.

</div>

## 계획을 템플릿으로 저장하기

1. **Serving** 영역에서 기존 계획을 여세요.
2. 계획의 **Order of Service**(예배 순서) 섹션에서 **Save as Template**을 클릭하세요.
3. 템플릿 이름을 정하세요(예: "Standard Sunday" 또는 "Worship + Sermon").
4. 저장하세요. 템플릿에는 저장하는 시점의 예배 순서, 자리, 메모가 담깁니다.

## 템플릿 관리하기

계획 유형 페이지에서 계획 목록 위의 **Templates**를 클릭하면 **Plan Templates**가 열립니다. 여기서 다음을 할 수 있습니다.

- **Rename**(이름 바꾸기) -- 템플릿의 표시 이름을 바꿉니다.
- **Update from plan**(계획에서 업데이트) -- 템플릿의 내용을 계획의 현재 상태로 바꿉니다. 표준 구조를 다듬은 뒤에 유용합니다.
- **Apply**(적용) -- 템플릿을 다가오는 계획 하나 이상에 찍어 넣습니다.
- **Delete**(삭제) -- 더 이상 필요 없는 템플릿을 제거합니다.

## 템플릿을 계획에 적용하기

1. 계획 유형 페이지에서 계획 목록 위의 **Templates**를 클릭하세요.
2. 사용할 템플릿 옆의 **Apply** 아이콘(복사 아이콘)을 클릭하세요.
3. 적용할 다가오는 계획을 체크박스로 고르세요.
4. 무엇을 복사할지 고르세요.
   - **Order of Service** -- 선택한 계획의 예배 순서 항목을 템플릿의 항목으로 바꿉니다.
   - **Positions** -- 선택한 계획의 자리(와 그 배정)를 템플릿의 자리로 바꿉니다.
5. **Apply**를 클릭하세요.

템플릿에 메모가 있다면, 적용할 때 선택한 계획의 메모도 템플릿의 메모로 바뀝니다.

:::warning
자리를 적용하면 선택한 계획의 기존 자리와 배정이 모두 바뀝니다. 적용하기 전에 그 자리에 이미 봉사자를 배정하지 않았는지 확인하세요.
:::

:::tip
찬양과 설교의 구조는 일관되게 두고 싶은데 봉사자는 매주 다르게 배정되어 있다면, 자리 없이 예배 순서만 적용하세요.
:::

## 템플릿으로 새 계획 시작하기

템플릿은 사역 안의 계획 유형들끼리 공유됩니다. **New Plan**을 클릭했을 때 사역에 템플릿이 있다면, 새 계획 양식에 **Start from template**(템플릿에서 시작) 목록이 나타납니다. 템플릿을 고르고 저장하면, 새 계획은 그 템플릿의 예배 순서, 자리, 메모와 함께 만들어집니다. 템플릿을 고르면 그 계획에 대한 **Copy from Previous Plan**(이전 계획에서 복사) 옵션은 대체됩니다.

## 템플릿을 최신으로 유지하기

표준 예배 구조가 바뀌었다면, 템플릿 관리 화면을 열고 **Update from plan**을 사용해 가장 최근의 계획으로 템플릿을 동기화하세요. 처음부터 다시 만들 필요가 없습니다.
