# 계획 개요

<div class="article-intro">

계획 개요는 한 번에 여러 서비스 날짜에 걸친 모든 자원봉사자 과제의 조감도를 제공합니다. 각 계획을 개별적으로 열지 않고도 한눈에 예정된 주에 걸친 모든 위치에 누가 봉사하고 있는지 볼 수 있으며 여전히 채워야 할 격차를 빠르게 식별할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 섬김 영역에서 최소한 하나의 사역 및 계획 유형을 만드세요
- 날짜 및 자원봉사자 과제가 있는 [서비스 계획](./plans.md)을 만드세요
- 자원봉사자가 [사람 디렉토리](../people/adding-people.md)에 추가되었는지 확인하세요

</div>

## 개요 액세스

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(좌상단의 검색 표시줄)를 열고 **섬김**을 확장한 다음 **계획**을 클릭하세요.
2. 페이지 상단의 **사역 탭**을 선택하세요.
3. **계획 유형**을 클릭하여 계획 목록을 열어보세요.
4. 페이지 상단의 **개요** 버튼을 클릭하세요.

## 개요 그리드 읽기

개요는 다음과 같이 그리드를 표시합니다:

- **행**은 카테고리별로 그룹화된 각 위치(예: "음악: 기타", "기술: 프로젝션")를 나타냅니다
- **열**은 예정된 서비스 날짜(예: "Apr 14", "Apr 21")를 나타냅니다
- **셀**은 해당 날짜의 해당 위치에 할당된 자원봉사자의 이름을 표시합니다

**빨간색**으로 강조 표시된 셀은 채워지지 않았습니다 -- 자원봉사자가 아직 할당되지 않았습니다. 이렇게 하면 각 계획을 개별적으로 열지 않고도 한눈에 직원 공백을 볼 수 있습니다.

:::tip
자원봉사자 이름은 단축된 형식(이름 및 성의 이니셜, 예: "John D.")으로 표시되어 많은 위치가 있을 때 그리드를 간결하게 유지합니다.
:::

## 개요에서 자원봉사자 직접 할당

빈 슬롯을 채우기 위해 개별 계획을 열 필요가 없습니다. 그리드의 셀을 클릭하여 해당 위치 및 날짜에 대한 과제 패널을 열어보세요. 여기서 다음을 할 수 있습니다:

- 팀에서 사람을 선택하여 위치에 할당하세요
- 이미 할당된 사람 옆의 **제거**를 클릭하여 해당 슬롯에서 제거하세요
- 개요를 떠나지 않고 변경 사항을 저장하세요

이를 통해 한 번에 전체 일정을 직원으로 만들 수 있습니다. -- 개별 계획에서 들어오고 나가지 않고도 주 및 위치 전체에서 작업하세요.

## 개요에서 자동 일정 계획

**자동 일정**을 클릭하여 B1이 현재 그리드의 모든 열려 있고 채워지지 않은 슬롯을 한 번에 채우도록 하세요. 보기의 각 계획에 대해 각 위치에 연결된 그룹에서 후보를 가져오고 빈 슬롯을 자동으로 채우며 채울 수 있었던 보이는 계획의 개수를 보고합니다. 계획은 한 번에 하나씩 채워지므로 동일한 자원봉사자가 동일한 경로에서 두 날짜에 이중 예약되지 않습니다.

:::info
자동 일정은 이미 비어 있는 슬롯만 채웁니다 -- 기존 과제를 절대 대체하지 않습니다.
:::

## 예정된 모든 사람에게 이메일 보내기

**이메일 자원봉사자**를 클릭하여 계획별로 이메일을 보내지 않고 현재 필터링된 날짜 범위 및 사역의 어디에든 할당된 모든 자원봉사자에게 한 번의 작업으로 알림을 보내세요. B1은 전송된 이메일 수와 실패한 이메일 수를 보고합니다.

## 자원봉사자 일정 강조

**강조** 드롭다운을 사용하여 팀에서 사람을 선택하세요 -- 할당된 모든 셀이 그리드에서 불리어집니다. 따라서 다른 슬롯에 추가하기 전에 이미 봉사하고 있는 모든 위치를 볼 수 있습니다. **모두**를 선택하여 강조를 해제하세요.

## 개요 필터링

상단의 필터 컨트롤을 사용하여 개요가 표시하는 내용을 조정할 수 있습니다:

- **시작 날짜 / 종료 날짜** -- 기본적으로 개요는 미래로 12주를 표시합니다. 범위를 확장하거나 좁히려면 사용자 정의 날짜를 입력하세요.
- **사역** -- 개요를 떠나지 않고 다른 사역으로 전환하세요.
- **계획 유형** -- 선택된 사역 내에서 특정 계획 유형으로 필터링하세요.
- **채워지지 않은 것만** -- 이를 켜서 모든 날짜가 이미 채워진 행을 숨기세요. 따라서 여전히 자원봉사자가 필요한 위치에만 초점을 맞출 수 있습니다.

변경한 후 **필터**를 클릭하여 그리드를 업데이트하세요.

## CSV로 내보내기

**CSV 내보내기**를 클릭하여 현재 그리드를 스프레드시트로 다운로드하세요. 내보내기에는 필터링된 날짜 범위에 대한 모든 위치 및 자원봉사자 과제가 포함되어 있으므로 사역 리더와 공유하거나 계획 회의를 위해 인쇄하기가 쉬워집니다.

:::info
CSV 내보내기는 현재 적용된 필터를 반영합니다 -- 그리드에 표시된 날짜 및 계획 유형만 다운로드에 포함됩니다.
:::
