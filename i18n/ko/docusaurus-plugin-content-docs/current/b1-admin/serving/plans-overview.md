# 사역 일정 개요

<div class="article-intro">

사역 일정 개요는 여러 예배 날짜에 걸친 모든 자원봉사 배정을 한눈에 볼 수 있게 해줍니다. 각 일정을 하나씩 열어보는 대신, 다가오는 몇 주 동안 모든 직책에 누가 섬기고 있는지를 하나의 표에서 확인하고, 아직 채워야 할 빈자리를 빠르게 찾아낼 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 섬김(Serving) 영역에서 사역(Ministry)과 일정 유형(Plan Type)을 최소 하나 이상 만드세요
- 날짜와 자원봉사 배정이 포함된 [예배 일정](./plans.md)을 만드세요
- 자원봉사자가 [인물 디렉터리](../people/adding-people.md)에 등록되어 있는지 확인하세요

</div>

## 개요 화면 접근하기

1. B1 Admin의 메인 메뉴에서 **섬김(Serving)**으로 이동합니다.
2. 페이지 상단의 **사역 탭**을 선택합니다.
3. **일정 유형**을 클릭하여 해당 일정 목록을 엽니다.
4. 페이지 상단 근처의 **개요(Overview)** 버튼을 클릭합니다.

## 개요 표 읽는 방법

개요 화면에는 다음과 같은 표가 표시됩니다.

- **행(Rows)**은 카테고리별로 그룹화된 각 직책(예: "음악: 기타", "기술: 프로젝션")을 나타냅니다
- **열(Columns)**은 다가오는 예배 날짜(예: "4월 14일", "4월 21일")를 나타냅니다
- **셀(Cells)**은 해당 날짜의 해당 직책에 배정된 자원봉사자의 이름을 보여줍니다

**빨간색**으로 표시된 셀은 아직 채워지지 않은 자리입니다 -- 아직 자원봉사자가 배정되지 않았습니다. 이를 통해 각 일정을 일일이 열어보지 않고도 인력 공백을 한눈에 파악할 수 있습니다.

:::tip
직책이 많을 때 표를 간결하게 유지하기 위해 자원봉사자 이름은 축약된 형식(이름과 성의 첫 글자, 예: "John D.")으로 표시됩니다.
:::

## 개요 화면에서 바로 자원봉사자 배정하기

빈자리를 채우기 위해 개별 일정을 열 필요가 없습니다. 표에서 아무 셀이나 클릭하면 해당 직책과 날짜에 대한 배정 패널이 열립니다. 여기에서 다음을 할 수 있습니다.

- 팀에서 해당 직책에 배정할 사람을 선택
- 이미 배정된 사람 옆의 **제거(Remove)**를 클릭하여 해당 자리에서 빼기
- 개요 화면을 벗어나지 않고 변경 사항 저장

이를 통해 여러 주와 직책을 오가며 개별 일정을 드나들지 않고도 한 번에 전체 일정의 인력을 배치할 수 있습니다.

## 개요 화면에서 자동 배정하기

**자동 배정(Auto-Schedule)**을 클릭하면 B1이 현재 표에 있는 비어 있는 모든 자리를 한 번에 채워줍니다. 화면에 보이는 각 일정에 대해, 각 직책에 연결된 그룹에서 후보자를 가져와 빈자리를 자동으로 채우고, 화면에 보이는 일정 중 몇 개를 채울 수 있었는지 보고합니다. 일정은 한 번에 하나씩 채워지므로, 같은 자원봉사자가 한 번의 실행에서 같은 날짜의 두 자리에 중복 배정되지 않습니다.

:::info
자동 배정은 이미 비어 있는 자리만 채웁니다 -- 기존 배정을 대체하는 일은 절대 없습니다.
:::

## 배정된 모든 사람에게 이메일 보내기

**자원봉사자에게 이메일 보내기(Email Volunteers)**를 클릭하면, 일정별로 각각 이메일을 보내는 대신 현재 필터링된 날짜 범위와 사역 내에서 어딘가에 배정된 모든 자원봉사자에게 한 번의 작업으로 알림을 보낼 수 있습니다. B1은 발송된 이메일 수와 실패한 이메일 수를 알려줍니다.

## 자원봉사자의 일정 강조 표시하기

**강조 표시(Highlight)** 드롭다운을 사용해 팀에서 사람을 선택하세요 -- 해당 사람이 배정된 모든 셀이 표에서 강조 표시되므로, 다른 자리에 추가로 배정하기 전에 이미 어디에서 섬기고 있는지 확인할 수 있습니다. 강조 표시를 끄려면 **전체(Everyone)**를 선택하세요.

## 개요 화면 필터링하기

상단의 필터 컨트롤을 사용해 개요 화면에 표시되는 내용을 조정할 수 있습니다.

- **시작일 / 종료일** -- 기본적으로 개요 화면은 향후 12주를 표시합니다. 사용자 지정 날짜를 입력하여 범위를 넓히거나 좁힐 수 있습니다.
- **사역(Ministry)** -- 개요 화면을 벗어나지 않고 다른 사역으로 전환합니다.
- **일정 유형(Plan Type)** -- 선택한 사역 내의 특정 일정 유형으로 필터링합니다.
- **미채용만 표시(Unfilled only)** -- 모든 날짜가 이미 채워진 행을 숨기려면 이 옵션을 켜서, 아직 자원봉사자가 필요한 직책에만 집중할 수 있습니다.

변경한 후 **필터(Filter)**를 클릭하면 표가 업데이트됩니다.

## CSV로 내보내기

**CSV 내보내기(Export CSV)**를 클릭하면 현재 표를 스프레드시트로 다운로드할 수 있습니다. 내보내기 파일에는 필터링된 날짜 범위의 모든 직책과 자원봉사자 배정이 포함되어 있어, 사역 리더와 공유하거나 기획 회의를 위해 인쇄하기 쉽습니다.

:::info
CSV 내보내기는 현재 적용된 필터를 그대로 반영합니다 -- 표에 표시된 날짜와 일정 유형만 다운로드에 포함됩니다.
:::
