# 찬양

<div class="article-intro">

찬양 페이지는 예배 찬양 라이브러리를 관리합니다. 모든 찬양의 세부 정보, 가사, 편곡을 한곳에 보관하면, 찬양 팀이 다가오는 예배를 쉽게 준비하고 일관된 레퍼토리를 유지할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin의 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)에서 **Serving > Songs**를 선택하여 찬양 페이지에 접근합니다.
- 선택 사항으로 [예배 계획](./plans.md)을 설정해 두면, 찬양을 [예배 순서](./service-order.md)에 바로 연결할 수 있습니다.

</div>

## 찬양 라이브러리 둘러보기

**Songs** 페이지를 열면 찬양이 표로 나열됩니다. 각 행에는 찬양의 미리 보기 이미지, 제목, 아티스트, 길이가 표시됩니다. 목록 아래의 페이지 컨트롤을 사용하여 큰 라이브러리를 넘겨 보거나, 검색하여 원하는 찬양을 찾을 수 있습니다.

## 찬양 검색하기

1. 찬양 페이지 상단의 **Search Songs** 상자를 클릭합니다.
2. 찬양의 **제목** 또는 **아티스트** 이름을 입력합니다.
3. 입력하는 동안 목록이 필터링되어 라이브러리에서 일치하는 찬양과 일치한 개수가 표시됩니다. 모든 찬양을 다시 보려면 **Clear**를 클릭합니다.

## 찬양 추가하기

1. 찬양 페이지 상단의 **Add Song**을 클릭합니다.
2. **Search for a Song**에서 외부 찬양 데이터베이스를 **Title or Artist**로 검색합니다.
3. 추가할 찬양을 선택하거나, 찾을 수 없다면 **Create Manually**를 클릭합니다.
4. 기본 세부 정보가 미리 채워진 상태로 찬양이 라이브러리에 추가됩니다.

:::tip
찬양을 추가한 뒤 찬양을 클릭하면 세부 정보를 검토하고 수정하거나, 편곡을 추가하거나, 유튜브 동영상이나 코드 악보 같은 외부 링크를 첨부할 수 있습니다.
:::

### WorshipCommons의 무료 찬양

검색 결과에는 일반 결과와 함께 **WorshipCommons — free** 섹션이 나타날 수도 있습니다. 이 찬양들은 [WorshipCommons](https://worshipcommons.org)에서 제공하는 것으로, 예배에서 바로 사용할 수 있도록 검토되고 라이선스가 부여된 찬양입니다. 각 결과에는 라이선스 배지 -- **Free for worship**(예배용 무료) 또는 **Public domain**(퍼블릭 도메인) -- 가 표시되므로, 추가하기 전에 이용 조건을 확인할 수 있습니다.

- WorshipCommons 결과를 클릭하면, 일반 검색 결과와 마찬가지로 라이브러리에 추가됩니다.
- **View on WorshipCommons**를 클릭하면 원래 목록을 새 탭에서 엽니다.

WorshipCommons의 검토 과정을 통과한 찬양만 여기에 나타나므로, 선택 범위는 주요 찬양 데이터베이스보다 작을 수 있습니다.

## 찬양 삭제하기

한 곡 이상의 찬양 옆 체크박스를 체크합니다(또는 머리글의 체크박스를 눌러 표시된 모든 찬양을 선택합니다). 그런 다음 나타나는 막대에서 **Delete Selected**를 클릭하고 확인합니다. 선택을 해제하려면 **Clear**를 클릭하세요.

## 찬양 보기 및 편집하기

찬양의 제목을 클릭하면 상세 페이지가 열립니다. 제목, 아티스트, 앨범, 키, 길이, BPM, 박자 같은 세부 정보가 왼쪽에 표시되며, 편곡과 외부 링크도 함께 나타납니다. 여기에서 다음을 할 수 있습니다.

- **찬양 세부 정보 편집** -- **Edit**을 클릭하여 제목, 아티스트, 길이, 기타 메타데이터를 업데이트합니다. 끝나면 **Done**을 클릭하세요. 찬양을 라이브러리에서 제거하려면 **Edit**을 클릭한 다음 **Delete song**을 클릭합니다.
- **편곡 관리** -- 찬양마다 여러 편곡(예: 다른 키나 버전)을 둘 수 있습니다. **Add Arrangement**를 클릭하여 편곡을 만들고, **Arrangements** 아래에서 편곡 이름을 클릭하여 엽니다.
- **가사 추가** -- ChordPro 표기법(예: `[G]Amazing grace`)으로 각 편곡의 가사를 입력하거나 업데이트합니다. 편집기 옆의 실시간 미리 보기가 입력하는 동안 서식이 적용된 코드 악보를 보여 주므로, 팀이 보게 될 모습을 정확히 확인할 수 있습니다.
- **키 설정** -- 가사 옆의 키 선택기를 사용하여 각 편곡의 음악적 키를 지정합니다. 선택기는 음악가들이 보통 적는 방식으로 키를 나열합니다(C, Db, D, Eb, E, F, F#, G, Ab, A, Bb, B). 키를 바꾸면 편곡 페이지에서든 예배 계획에서 찬양을 열 때든 표시되는 코드가 즉시 조옮김되므로, 팀은 실제로 연주하는 키의 코드를 항상 보게 됩니다. 코드 표기는 키에 맞춰집니다. Bb나 Eb 같은 플랫 키는 샵이 아니라 플랫 코드 이름(Bb, Eb, Ab)으로 표시됩니다.
- **외부 링크 추가** -- 유튜브 동영상, 코드 악보, 다른 곳에 있는 악보 같은 자료로 연결되는 링크를 첨부합니다.

## 편곡

편곡은 찬양의 고유한 버전을 나타냅니다. 예를 들어 더 빠른 현대적 버전과 느린 어쿠스틱 버전, 또는 다른 팀을 위해 다른 키로 바꾼 같은 찬양일 수 있습니다. 같은 찬양의 각 편곡은 찬양 제목과 아티스트를 공유하지만, 자체적인 독립 설정을 가집니다.

- **키** -- 편곡을 연주하는 음악적 키
- **BPM** -- 분당 박자 수로 나타낸 템포
- **Length** -- 초 단위의 길이
- **Meter** -- 박자표(예: 4/4, 3/4, 6/8)
- **Sequence** -- 코드와 구간의 구조(예: 인트로 → 벌스 → 코러스 → 브리지)
- **Lyrics** -- 화면 표시나 영사용 가사
- **External links** -- 코드 악보, 유튜브 녹음, 악보, 또는 기타 자료

찬양을 [예배 순서](./service-order.md)에 추가할 때, 그 예배에 사용할 편곡을 선택할 수 있으므로 팀은 항상 올바른 버전을 연습하고 연주합니다.

### 리허설 오디오

예배 관리자는 팀이 연습 전에 미리 들을 수 있도록 편곡에 리허설 오디오 트랙을 첨부할 수 있습니다.

1. 찬양을 열고 편곡을 선택합니다.
2. **Upload Audio**를 클릭합니다.
3. MP3, M4A, 또는 AAC 파일을 선택합니다(최대 25MB -- 저장 공간 사용량을 관리하기 위해 WAV는 허용되지 않습니다).
4. 저장합니다. 이 트랙은 편곡이 나타나는 곳이면 어디에서든 인라인으로 재생됩니다. B1 Admin의 편곡 페이지, 그리고 팀 구성원이 B1.church 멤버 포털에서 열어 보는 예배 계획에서 재생됩니다. 오디오가 있는 계획 항목에는 미리 보기 이미지 대신 음표 아이콘이 표시됩니다.

편곡을 삭제하면 업로드된 오디오 파일도 함께 삭제됩니다.

:::info
라이브러리의 찬양은 계획 안의 [예배 순서](./service-order.md)에 바로 추가할 수 있으며, 찬양의 세부 정보와 선택한 편곡을 그 특정 예배에 연결합니다.
:::
