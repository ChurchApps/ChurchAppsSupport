# 곡

<div class="article-intro">

곡 페이지는 예배 찬양 라이브러리를 관리합니다. 모든 곡의 세부 정보, 가사, 편곡을 한곳에 모아 두면 예배팀이 다가오는 예배를 쉽게 준비하고 일관된 레퍼토리를 유지할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin의 **섬김(Serving)** 섹션으로 이동해 곡 페이지에 접근하세요
- 선택적으로, [예배 일정](./plans.md)을 미리 준비해 두면 곡을 [예배 순서](./service-order.md)에 바로 연결할 수 있습니다

</div>

## 곡 라이브러리 둘러보기

**곡(Songs)** 페이지를 열면 곡들이 카드 형태로 표시됩니다. 각 카드에는 곡의 썸네일 이미지, 제목, 아티스트, 재생 시간이 표시됩니다. 라이브러리를 스크롤하거나 검색을 사용해 원하는 곡을 찾으세요.

## 곡 검색하기

1. 곡 페이지에서 **검색(Search)** 버튼을 클릭합니다.
2. 곡 **제목** 또는 **아티스트** 이름을 입력합니다.
3. 입력하는 동안 결과가 필터링되며, 라이브러리에서 일치하는 곡이 표시됩니다.

## 곡 추가하기

1. 곡 페이지에서 **곡 추가(Add Song)**를 클릭합니다.
2. 제목이나 아티스트로 외부 곡 데이터베이스를 검색합니다.
3. 추가하려는 곡을 선택합니다.
4. 기본 정보가 미리 채워진 상태로 곡이 라이브러리에 추가됩니다.

:::tip
곡을 추가한 뒤 클릭해서 세부 정보를 검토·수정하거나, 편곡을 추가하거나, YouTube 영상이나 코드 차트 같은 외부 링크를 첨부하세요.
:::

## 곡 보기 및 편집하기

곡 카드를 클릭하면 상세 페이지가 열립니다. 여기서 다음을 할 수 있습니다.

- **곡 세부 정보 편집** -- 제목, 아티스트, 재생 시간 및 기타 메타데이터를 업데이트합니다.
- **편곡 관리** -- 각 곡은 여러 편곡(예: 다른 키나 다른 버전)을 가질 수 있습니다. 필요에 따라 편곡을 추가, 편집, 삭제하세요.
- **가사 추가** -- 각 편곡의 가사를 입력하거나 수정합니다.
- **키 설정** -- 가사 옆의 키 선택기를 사용해 각 편곡의 음악적 키를 지정합니다. 키를 변경하면 표시된 코드가 즉시 이조되며, 편곡 페이지에서든 예배 일정에서 곡을 열 때든 팀은 항상 실제로 연주하는 키의 코드를 보게 됩니다.
- **외부 링크 추가** -- YouTube 영상, 코드 차트, 다른 곳에 호스팅된 악보 같은 자료에 대한 링크를 첨부합니다.

## 편곡

편곡은 한 곡의 서로 다른 버전을 나타냅니다 -- 예를 들어 빠른 현대적 버전과 느린 어쿠스틱 버전, 또는 다른 팀을 위한 다른 키의 같은 곡 등입니다. 같은 곡의 각 편곡은 곡 제목과 아티스트는 공유하지만, 다음과 같은 독립적인 설정을 각각 갖습니다.

- **키(Key)** -- 편곡이 연주되는 음악적 키
- **BPM** -- 분당 박자 수로 나타낸 템포
- **길이(Length)** -- 초 단위 재생 시간
- **박자(Meter)** -- 박자표(예: 4/4, 3/4, 6/8)
- **순서(Sequence)** -- 코드/구간 구조(예: 인트로 → 절 → 후렴 → 브리지)
- **가사(Lyrics)** -- 화면 표시 또는 프로젝션용
- **외부 링크(External links)** -- 코드 차트, YouTube 녹화, 악보, 기타 자료

곡을 [예배 순서](./service-order.md)에 추가할 때, 해당 예배에서 사용할 편곡을 선택할 수 있어서 팀은 항상 올바른 버전을 연습하고 연주하게 됩니다.

:::info
라이브러리의 곡은 일정 안의 [예배 순서](./service-order.md)에 바로 추가할 수 있으며, 그 특정 예배에 곡의 세부 정보와 선택한 편곡이 연결됩니다.
:::
