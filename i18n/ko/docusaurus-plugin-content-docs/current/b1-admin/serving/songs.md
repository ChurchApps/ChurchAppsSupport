# 노래

<div class="article-intro">

노래 페이지에서는 찬양 곡 라이브러리를 관리합니다. 곡의 세부 정보, 가사, 편곡을 한곳에 모아 두면 찬양팀이 다가오는 예배를 쉽게 준비하고 일관된 레퍼토리를 유지할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin의 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)에서 **Serving > Songs**를 선택하여 노래 페이지로 이동합니다.
- 필요하다면 [예배 계획](./plans.md)을 미리 설정해 두면 노래를 [예배 순서](./service-order.md)에 바로 연결할 수 있습니다.

</div>

## 찬양 곡 라이브러리 둘러보기

**노래** 페이지를 열면 곡들이 표 형태로 나열됩니다. 각 행에는 곡의 썸네일 이미지, 제목, 아티스트, 길이가 표시됩니다. 목록 아래의 페이지 컨트롤로 많은 곡을 넘겨 보거나, 검색으로 원하는 곡을 찾을 수 있습니다.

## 곡 검색하기

1. 노래 페이지 상단의 **Search Songs** 상자를 클릭합니다.
2. 곡 **제목** 또는 **아티스트** 이름을 입력합니다.
3. 입력하는 대로 목록이 필터링되어, 라이브러리에서 일치하는 곡과 일치한 곡의 개수가 표시됩니다. 모든 곡을 다시 보려면 **Clear**를 클릭합니다.

## 곡 추가하기

1. 노래 페이지 상단의 **Add Song**을 클릭합니다.
2. **Search for a Song**에서 **Title or Artist**로 외부 곡 데이터베이스를 검색합니다.
3. 추가할 곡을 선택합니다. 원하는 곡이 없다면 **Create Manually**를 클릭합니다.
4. 기본 정보가 미리 채워진 상태로 곡이 라이브러리에 추가됩니다.

:::tip
곡을 추가한 뒤에는 곡을 클릭하여 세부 정보를 검토하고 수정하거나, 편곡을 추가하거나, YouTube 영상이나 코드 악보 같은 외부 링크를 첨부할 수 있습니다.
:::

### WorshipCommons의 무료 곡

검색 결과에는 일반 결과와 함께 **WorshipCommons — free** 섹션이 나타날 수도 있습니다. 이 곡들은 [WorshipCommons](https://worshipcommons.org)에서 제공하며, 검토를 거쳐 예배에 사용할 수 있도록 라이선스가 부여된 주일 예배용 곡입니다. 각 결과에는 라이선스 배지인 **Free for worship** 또는 **Public domain**이 표시되어, 추가하기 전에 이용 조건을 확인할 수 있습니다.

- WorshipCommons 결과를 클릭하면 일반 검색 결과와 마찬가지로 라이브러리에 추가됩니다.
- **View on WorshipCommons**를 클릭하면 원본 목록이 새 탭에서 열립니다.

WorshipCommons의 심사 과정을 통과한 곡만 여기에 표시되므로, 주요 곡 데이터베이스보다 선택지가 적을 수 있습니다.

WorshipCommons 전체 라이브러리를 둘러보거나, 악보를 인쇄하거나, 슬라이드를 내보내려면 [WorshipCommons 문서](../../worship-commons/index.md)를 참고하세요.

## 곡 삭제하기

하나 이상의 곡 옆 체크박스를 선택하거나(화면에 보이는 모든 곡을 선택하려면 머리글의 체크박스를 선택합니다), 나타나는 표시줄에서 **Delete Selected**를 클릭한 뒤 확인합니다. 선택을 해제하려면 **Clear**를 클릭합니다.

## 곡 보기 및 편집하기

곡의 제목을 클릭하면 상세 페이지가 열립니다. 곡의 제목, 아티스트, 앨범, 조성, 길이, BPM, 박자표 같은 세부 정보가 왼쪽에 표시되며, 편곡과 외부 링크도 함께 나타납니다. 이 페이지에서 다음을 할 수 있습니다.

- **곡 세부 정보 편집** -- **Edit**를 클릭하여 제목, 아티스트, 길이 등 메타데이터를 수정합니다. 완료되면 **Done**을 클릭합니다. 곡을 라이브러리에서 제거하려면 **Edit**를 클릭한 뒤 **Delete song**을 클릭합니다.
- **편곡 관리** -- 각 곡에는 여러 편곡(예: 다른 조성이나 다른 버전)을 둘 수 있습니다. **Add Arrangement**를 클릭하여 새 편곡을 만들고, **Arrangements** 아래의 편곡 이름을 클릭하여 엽니다.
- **가사 추가** -- ChordPro 표기법(예: `[G]Amazing grace`)을 사용하여 각 편곡의 가사를 입력하거나 수정합니다. 편집기 옆의 실시간 미리보기에서 입력하는 동안 서식이 적용된 코드 악보가 표시되므로, 찬양팀이 보게 될 화면을 정확히 확인할 수 있습니다.
- **조성 설정** -- 가사 옆의 조성 선택기를 사용하여 각 편곡의 조성을 지정합니다. 선택기에는 음악가들이 보통 표기하는 방식대로 조성이 나열됩니다(C, Db, D, Eb, E, F, F#, G, Ab, A, Bb, B). 조성을 바꾸면 편곡 페이지에서든 예배 계획에서 곡을 열 때든 표시되는 코드가 즉시 전조되므로, 찬양팀은 실제로 연주하는 조성의 코드를 항상 볼 수 있습니다. 코드 표기는 조성에 맞춰 적용됩니다. Bb나 Eb 같은 플랫 조성에서는 샤프 대신 플랫 코드명(Bb, Eb, Ab)이 표시됩니다.
- **외부 링크 추가** -- YouTube 영상, 코드 악보, 다른 곳에 호스팅된 악보 같은 자료에 링크를 첨부합니다.

## 편곡

편곡은 같은 곡의 서로 다른 버전을 뜻합니다. 예를 들어 더 빠른 현대적 버전과 느린 어쿠스틱 버전, 또는 다른 팀을 위해 다른 조성으로 편곡한 같은 곡이 있을 수 있습니다. 같은 곡의 편곡들은 곡 제목과 아티스트를 공유하지만, 각자 독립된 설정을 가집니다.

- **조성** -- 편곡을 연주하는 음악적 조성
- **BPM** -- 분당 박자 수로 나타내는 템포
- **길이** -- 초 단위의 재생 시간
- **박자표** -- 박자 기호(예: 4/4, 3/4, 6/8)
- **진행 구조** -- 코드와 섹션의 구성(예: 인트로 → 벌스 → 코러스 → 브리지)
- **가사** -- 화면 표시나 프로젝션용
- **외부 링크** -- 코드 악보, YouTube 녹음, 악보, 기타 자료

[예배 순서](./service-order.md)에 곡을 추가할 때, 해당 예배에서 사용할 편곡을 고를 수 있으므로 찬양팀이 항상 올바른 버전으로 리허설하고 연주할 수 있습니다.

### 리허설 오디오

찬양 관리자는 편곡에 리허설 오디오 트랙을 첨부하여, 팀원들이 연습 전에 미리 들을 수 있도록 할 수 있습니다.

1. 곡을 열고 편곡을 선택합니다.
2. **Upload Audio**를 클릭합니다.
3. MP3, M4A 또는 AAC 파일을 선택합니다(최대 25MB입니다. 저장 용량을 적정하게 유지하기 위해 WAV 파일은 허용되지 않습니다).
4. 저장합니다. 트랙은 해당 편곡이 나타나는 모든 곳에서 바로 재생됩니다. B1 Admin의 편곡 페이지에서도, 팀원이 B1.church 멤버 포털에서 예배 계획을 열 때도 재생됩니다. 오디오가 있는 계획 항목에는 썸네일 대신 음표 아이콘이 표시됩니다.

편곡을 삭제하면 업로드된 오디오 파일도 함께 삭제됩니다.

:::info
라이브러리의 곡은 계획 안의 [예배 순서](./service-order.md)에 바로 추가할 수 있습니다. 이때 곡 세부 정보와 선택한 편곡이 해당 예배에 연결됩니다.
:::
