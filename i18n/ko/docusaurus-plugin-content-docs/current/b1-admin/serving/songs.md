# 찬양

<div class="article-intro">

찬양 페이지에서는 교회의 찬양 목록을 관리합니다. 모든 찬양의 세부 정보, 가사, 편곡을 한곳에 보관하여 찬양팀이 다가오는 예배를 쉽게 준비하고 일관된 찬양 목록을 유지할 수 있도록 합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin의 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)에서 **Serving > Songs**를 선택하면 찬양 페이지에 들어갈 수 있습니다.
- 선택 사항으로, 찬양을 [예배 순서](./service-order.md)에 바로 넣을 수 있도록 [예배 계획](./plans.md)을 미리 설정해 두세요.

</div>

## 찬양 목록 둘러보기

**Songs** 페이지를 열면 찬양이 표로 나열됩니다. 각 행에는 찬양의 썸네일 이미지, 제목, 아티스트, 길이가 표시됩니다. 목록 아래의 페이지 컨트롤로 큰 목록을 넘기거나, 검색해서 원하는 찬양을 찾을 수 있습니다.

## 찬양 검색하기

1. Songs 페이지 맨 위의 **Search Songs** 상자를 클릭하세요.
2. 찬양 **제목** 또는 **아티스트** 이름을 입력하세요.
3. 입력하는 동안 목록이 걸러지며, 찬양 목록에서 일치하는 찬양과 일치한 개수가 표시됩니다. **Clear**를 클릭하면 모든 찬양이 다시 나타납니다.

## 찬양 추가하기

1. Songs 페이지 맨 위의 **Add Song**을 클릭하세요.
2. **Search for a Song**에서 **Title or Artist**(제목 또는 아티스트)로 외부 찬양 데이터베이스를 검색하세요.
3. 추가할 찬양을 고르세요. 찾을 수 없다면 **Create Manually**(직접 만들기)를 클릭하세요.
4. 찬양은 기본 세부 정보가 미리 채워진 상태로 목록에 추가됩니다.

:::tip
찬양을 추가한 뒤에는 그 찬양을 클릭해 세부 정보를 검토하고 업데이트하거나, 편곡을 추가하거나, YouTube 영상이나 코드 악보 같은 외부 링크를 붙일 수 있습니다.
:::

### WorshipCommons의 무료 찬양 {#free-songs-from-worshipcommons}

검색 결과에는 일반 결과와 함께 **WorshipCommons — free** 섹션이 나타날 수도 있습니다. 이것들은 [WorshipCommons](https://worshipcommons.org)의 주일 사용 준비가 된 찬양으로, 예배에 사용할 수 있도록 검토되고 라이선스가 부여된 것입니다. 각 결과에는 라이선스 배지인 **Free for worship**(예배용 무료) 또는 **Public domain**(퍼블릭 도메인)이 표시되므로, 추가하기 전에 이용 조건을 알 수 있습니다.

- WorshipCommons 결과를 클릭하면 일반 검색 결과와 똑같이 목록에 추가됩니다.
- **View on WorshipCommons**를 클릭하면 원본 항목이 새 탭에서 열립니다.

WorshipCommons의 검토 과정을 통과한 찬양만 여기에 나타나므로, 선택 가능한 찬양이 주요 찬양 데이터베이스보다 적을 수 있습니다.

## 찬양 삭제하기

찬양 하나 이상의 옆 체크박스를 체크하세요(또는 머리글의 체크박스를 체크하면 표시된 모든 찬양을 선택합니다). 나타나는 막대에서 **Delete Selected**를 클릭한 다음 확인하세요. 선택을 해제하려면 **Clear**를 클릭하세요.

## 찬양 보기와 편집하기

찬양의 제목을 클릭하면 세부 정보 페이지가 열립니다. 찬양의 제목, 아티스트, 앨범, 조성, 길이, BPM, 박자 같은 세부 정보가 왼쪽에 나타나며, 편곡과 외부 링크도 함께 보입니다. 여기에서 다음을 할 수 있습니다.

- **찬양 세부 정보 편집** -- **Edit**를 클릭해 제목, 아티스트, 길이, 기타 메타데이터를 업데이트하세요. 끝나면 **Done**을 클릭합니다. 찬양을 목록에서 삭제하려면 **Edit**를 클릭한 다음 **Delete song**을 클릭하세요.
- **편곡 관리하기** -- 각 찬양에는 여러 편곡(예: 서로 다른 조성이나 버전)이 있을 수 있습니다. **Add Arrangement**를 클릭해 만들고, **Arrangements** 아래의 편곡 이름을 클릭해 여세요.
- **가사 추가하기** -- ChordPro 표기법(예: `[G]Amazing grace`)을 사용해 각 편곡의 가사를 입력하거나 업데이트하세요. 편집기 옆의 실시간 미리 보기가 입력하는 동안 서식이 적용된 코드 악보를 보여 주므로, 팀이 볼 화면을 정확히 확인할 수 있습니다.
- **조성 설정하기** -- 가사 옆의 조성 선택기를 사용해 각 편곡의 조성을 정하세요. 선택기는 음악인들이 보통 쓰는 방식(C, Db, D, Eb, E, F, F#, G, Ab, A, Bb, B)으로 조성을 나열합니다. 조성을 바꾸면 표시되는 코드가 즉시 바뀝니다. 편곡 페이지에서도, 예배 계획에서 찬양을 열 때도 똑같이 바뀌므로, 팀은 실제로 연주하는 조성의 코드를 항상 보게 됩니다. 코드 표기는 조성에 맞춰집니다. Bb나 Eb 같은 플랫 조성은 샤프 대신 플랫 코드 이름(Bb, Eb, Ab)으로 표시됩니다.
- **외부 링크 추가하기** -- YouTube 영상, 코드 악보, 다른 곳에 있는 악보 같은 자료로 연결되는 링크를 붙이세요.

## 편곡

편곡은 한 찬양의 서로 다른 버전을 뜻합니다. 예를 들어 빠른 현대 버전과 느린 어쿠스틱 버전, 또는 다른 팀을 위해 다른 조성으로 만든 같은 찬양이 있습니다. 같은 찬양의 편곡들은 제목과 아티스트를 공유하지만, 각자 독립된 설정을 가집니다.

- **Key**(조성) -- 편곡을 연주하는 음악적 조성
- **BPM** -- 분당 박자 수로 나타낸 템포
- **Length**(길이) -- 초 단위의 길이
- **Meter**(박자) -- 박자표(예: 4/4, 3/4, 6/8)
- **Sequence**(순서) -- 코드와 구간의 구조(예: 인트로 → 벌스 → 코러스 → 브리지)
- **Lyrics**(가사) -- 화면 표시나 프로젝션용
- **External links**(외부 링크) -- 코드 악보, YouTube 녹음, 악보, 또는 다른 자료

찬양을 [예배 순서](./service-order.md)에 추가할 때, 그 특정 예배에 쓸 편곡을 고를 수 있으므로 팀은 항상 올바른 버전으로 연습하고 연주합니다.

### 리허설 오디오

찬양 관리자는 편곡에 리허설 오디오 트랙을 첨부하여, 팀이 연습 전에 미리 들을 수 있게 할 수 있습니다.

1. 찬양을 열고 편곡을 고르세요.
2. **Upload Audio**를 클릭하세요.
3. MP3, M4A, 또는 AAC 파일을 고르세요(최대 25MB. 저장 공간을 적당히 쓰기 위해 WAV는 받지 않습니다).
4. 저장하세요. 그 편곡이 나타나는 곳이라면 어디에서든 트랙이 바로 재생됩니다. B1 Admin의 편곡 페이지, 그리고 팀원이 B1.church 교인 포털에서 예배 계획을 열 때도 재생됩니다. 오디오가 있는 계획 항목에는 썸네일 대신 음표 아이콘이 표시됩니다.

편곡을 삭제하면 업로드된 오디오 파일도 함께 삭제됩니다.

:::info
찬양 목록의 찬양은 계획 안의 [예배 순서](./service-order.md)에 바로 추가할 수 있으며, 찬양의 세부 정보와 선택한 편곡이 그 특정 예배에 연결됩니다.
:::
