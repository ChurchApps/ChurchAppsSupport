# 노래
<div class="article-intro">
노래 페이지는 예배 노래 라이브러리를 관리합니다. 모든 노래 세부 정보, 가사, 편곡을 한 곳에 두어 예배 팀이 예정된 서비스를 준비할 수 있게 합니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- B1 Admin의 **섬김** 섹션에서 노래 페이지에 접근합니다
- 선택적으로 [서비스 계획](./plans.md)을 설정합니다
</div>
## 노래 라이브러리 탐색
노래 페이지를 열면, 노래가 카드로 표시됩니다. 라이브러리를 스크롤하거나 검색을 사용하여 찾습니다.
## 노래 검색
1. 노래 페이지에서 **검색** 버튼을 클릭합니다
2. 노래 **제목** 또는 **아티스트** 이름을 입력합니다
3. 일치하는 노래가 필터링됩니다
## 노래 추가
1. **노래 추가**를 클릭합니다
2. 외부 노래 데이터베이스에서 검색합니다
3. 추가할 노래를 선택합니다
4. 노래가 라이브러리에 추가됩니다
## 노래 보기 및 편집
노래 카드를 클릭하여 세부 정보 페이지를 엽니다:
- **노래 세부 정보 편집** — 제목, 아티스트, 기간 등을 업데이트합니다
- **편곡 관리** — 각 편곡에 대한 여러 버전을 추가합니다
- **가사 추가** — 각 편곡에 대한 가사를 입력합니다 (ChordPro 표기법 지원)
- **키 설정** — 편곡의 음악 키를 지정합니다
- **외부 링크 추가** — YouTube 영상, 악보, 코드 차트에 링크를 추가합니다
## 편곡
편곡은 노래의 서로 다른 버전을 나타냅니다 (예: 빠른 현대 버전 vs. 느린 어쿠스틱):
- **키** — 편곡이 수행되는 음악 키
- **BPM** — 분당 박자 수
- **길이** — 초 단위 기간
- **미터** — 박자 (예: 4/4, 3/4)
- **가사** — 표시 또는 프로젝션용
- **외부 링크** — 악보, YouTube, 시트 음악 등
