# 노래

<div class="article-intro">

노래 페이지는 경배 노래 라이브러리를 관리합니다. 모든 노래 세부 정보, 가사, 편곡을 한 곳에 보관하여 경배 팀이 예정된 예배를 쉽게 준비하고 일관된 음악 목록을 유지할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin의 **Serving** 섹션으로 이동하여 노래 페이지에 액세스합니다
- 선택적으로, 노래를 [서비스 순서](./service-order.md)에 직접 연결할 수 있도록 [서비스 계획](./plans.md)이 설정되어 있습니다

</div>

## 노래 라이브러리 탐색

**노래** 페이지를 열면 노래가 카드로 표시됩니다. 각 카드에는 노래의 섬네일 이미지, 제목, 아티스트, 재생 시간이 표시됩니다. 라이브러리를 스크롤하거나 검색을 사용하여 필요한 것을 찾습니다.

## 노래 검색

1. 노래 페이지의 **검색** 버튼을 클릭합니다.
2. 노래 **제목** 또는 **아티스트** 이름을 입력합니다.
3. 결과는 입력할 때 필터링되어 라이브러리에서 일치하는 노래를 표시합니다.

## 노래 추가

1. 노래 페이지에서 **노래 추가**를 클릭합니다.
2. 제목이나 아티스트로 외부 노래 데이터베이스를 검색합니다.
3. 추가할 노래를 선택합니다.
4. 기본 정보가 미리 입력된 상태로 라이브러리에 노래가 추가됩니다.

:::tip
노래를 추가한 후, 이를 클릭하여 세부 정보를 검토 및 업데이트하고, 편곡을 추가하거나, YouTube 동영상이나 코드 차트 같은 외부 링크를 첨부합니다.
:::

## 노래 보기 및 편집

모든 노래 카드를 클릭하여 세부 정보 페이지를 엽니다. 여기에서 다음을 수행할 수 있습니다:

- **노래 세부 정보 편집** - 제목, 아티스트, 재생 시간 및 기타 메타데이터를 업데이트합니다.
- **편곡 관리** - 각 노래는 여러 편곡을 가질 수 있습니다 (예: 다양한 음역대 또는 버전). 필요에 따라 편곡을 추가, 편집 또는 제거합니다.
- **가사 추가** - 각 편곡의 가사를 입력하거나 업데이트합니다.
- **음역대 설정** - 가사 옆의 음역대 선택기를 사용하여 각 편곡의 음악 음역대를 지정합니다. 음역대를 변경하면 표시된 코드가 즉시 조옮김되며, 편곡 페이지와 서비스 계획에서 노래를 열 때 팀이 실제로 재생하는 음역대의 코드를 항상 볼 수 있습니다.
- **외부 링크 추가** - YouTube 동영상, 코드 차트, 다른 곳에서 호스팅되는 악보 등의 리소스에 링크를 첨부합니다.

## 편곡

편곡은 노래의 서로 다른 버전을 나타냅니다. 예를 들어, 더 빠른 현대적 버전 대 더 느린 어쿠스틱 버전, 또는 다른 팀을 위한 다른 음역대의 동일 곡입니다. 동일 곡의 각 편곡은 곡의 제목과 아티스트를 공유하지만 독립적인 설정을 가집니다:

- **음역대** - 편곡이 재생되는 음악 음역대
- **BPM** - 분당 비트 수의 템포
- **길이** - 초 단위의 재생 시간
- **박자** - 시간 서명 (예: 4/4, 3/4, 6/8)
- **수열** - 코드/섹션 구조 (예: Intro → Verse → Chorus → Bridge)
- **가사** - 표시 또는 프로젝션용
- **외부 링크** - 코드 차트, YouTube 녹음, 악보 또는 기타 리소스

[서비스 순서](./service-order.md)에 노래를 추가할 때, 그 특정 예배에 사용할 편곡을 선택할 수 있으므로 팀이 항상 올바른 버전을 연습하고 재생합니다.

### 연습 오디오

경배 관리자는 편곡에 연습 오디오 트랙을 첨부하여 팀이 연습 전에 미리 들을 수 있습니다:

1. 노래를 열고 편곡을 선택합니다.
2. **오디오 업로드**를 클릭합니다.
3. MP3, M4A 또는 AAC 파일을 선택합니다 (최대 25MB - WAV는 저장 사용량을 관리하기 위해 허용되지 않음).
4. 저장합니다. 트랙은 해당 편곡이 나타나는 곳 어디든 인라인으로 재생됩니다. B1 Admin의 편곡 페이지와 B1.church 회원 포털에서 팀 구성원이 서비스 계획을 열 때 재생됩니다. 오디오가 있는 계획 항목은 섬네일 대신 음표 아이콘을 표시합니다.

편곡을 삭제하면 업로드된 오디오 파일도 제거됩니다.

:::info
라이브러리의 노래를 [서비스 순서](./service-order.md) 내에서 계획에 직접 추가하여 노래 세부 정보와 선택한 편곡을 해당 특정 서비스에 연결할 수 있습니다.
:::
