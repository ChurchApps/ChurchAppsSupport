# 노래

<div class="article-intro">

노래 페이지는 예배 노래 라이브러리를 관리합니다. 모든 노래 세부 정보, 가사 및 편곡을 한 곳에 보관하여 예배 팀이 예정된 서비스를 쉽게 준비하고 일관된 레퍼토리를 유지할 수 있도록 하세요.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin의 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)에서 **섬김 > 노래**를 선택하여 노래 페이지에 액세스하세요
- 선택적으로 [서비스 계획](./plans.md)을 설정하여 [서비스 순서](./service-order.md)에 직접 노래를 연결할 수 있도록 하세요

</div>

## 노래 라이브러리 탐색

**노래** 페이지를 열면 노래가 카드로 표시됩니다. 각 카드는 노래의 썸네일 이미지, 제목, 아티스트 및 기간을 표시합니다. 라이브러리를 스크롤하거나 검색을 사용하여 필요한 것을 찾으세요.

## 노래 검색

1. 노래 페이지에서 **검색** 버튼을 클릭하세요.
2. 노래 **제목** 또는 **아티스트** 이름을 입력하세요.
3. 입력하면 결과가 필터링되어 라이브러리의 일치하는 노래를 표시합니다.

## 노래 추가

1. 노래 페이지에서 **노래 추가**를 클릭하세요.
2. 제목 또는 아티스트로 외부 노래 데이터베이스를 검색하세요.
3. 추가하려는 노래를 선택하세요.
4. 노래는 기본 세부 정보가 미리 채워진 상태로 라이브러리에 추가됩니다.

:::tip
노래를 추가한 후 클릭하여 세부 정보를 검토 및 업데이트하고, 편곡을 추가하거나, YouTube 비디오 또는 코드 차트와 같은 외부 링크를 첨부하세요.
:::

### WorshipCommons의 무료 노래

검색 결과에는 일반 결과와 함께 **WorshipCommons — 무료** 섹션이 포함될 수 있습니다. 이는 검토되고 예배 사용을 위해 라이선스된 [WorshipCommons](https://worshipcommons.org)의 주일 준비 노래입니다. 각 결과는 라이선스 배지 -- **예배를 위해 무료** 또는 **공개 도메인** -- 을 표시하므로 추가하기 전에 약관을 알 수 있습니다.

- 일반 검색 결과처럼 WorshipCommons 결과를 클릭하여 라이브러리에 추가하세요.
- **WorshipCommons에서 보기**를 클릭하여 새 탭에서 원래 목록을 열어보세요.

WorshipCommons의 검토 프로세스를 통과한 노래만 여기에 나타나므로 선택이 주 노래 데이터베이스보다 작을 수 있습니다.

## 노래 보기 및 편집

노래 카드를 클릭하여 상세 페이지를 열어보세요. 여기서 다음을 할 수 있습니다:

- **노래 세부 정보 편집** -- 제목, 아티스트, 기간 및 기타 메타데이터를 업데이트하세요.
- **편곡 관리** -- 각 노래는 여러 편곡(예: 다양한 키 또는 버전)을 가질 수 있습니다. 필요에 따라 편곡을 추가, 편집 또는 제거하세요.
- **가사 추가** -- ChordPro 표기법을 사용하여 각 편곡의 가사를 입력하거나 업데이트하세요(예: `[G]Amazing grace`). 편집기 옆의 라이브 미리보기는 입력할 때 형식이 지정된 코드 차트를 렌더링하므로 팀이 정확히 어떤 것을 보게 될지 볼 수 있습니다.
- **키 설정** -- 가사 옆의 키 선택기를 사용하여 각 편곡의 음악 키를 지정하세요. 키를 변경하면 편곡 페이지와 서비스 계획에서 노래를 열 때 모두 표시된 코드가 즉시 전조되므로 팀은 항상 실제로 재생하고 있는 키에서 코드를 봅니다.
- **외부 링크 추가** -- YouTube 비디오, 코드 차트 또는 다른 곳에서 호스팅되는 악보와 같은 리소스에 링크를 첨부하세요.

## 편곡

편곡은 노래의 별개의 버전을 나타냅니다 -- 예를 들어 느린 어쿠스틱 버전과 비교하여 더 빠른 현대 버전, 또는 다른 팀을 위해 다른 키의 동일한 노래입니다. 동일한 노래의 각 편곡은 노래 제목과 아티스트를 공유하지만 자체 독립적인 설정을 가집니다:

- **키** -- 편곡이 수행되는 음악 키
- **BPM** -- 분당 비트의 템포
- **길이** -- 초 단위의 기간
- **박자** -- 박자 (예: 4/4, 3/4, 6/8)
- **순서** -- 코드/섹션 구조 (예: Intro → Verse → Chorus → Bridge)
- **가사** -- 디스플레이 또는 투사용
- **외부 링크** -- 코드 차트, YouTube 녹음, 악보 또는 기타 리소스

[Service Order](./service-order.md)에 노래를 추가할 때 해당 서비스에 사용할 편곡을 선택할 수 있으므로 팀은 항상 올바른 버전을 리허설하고 재생합니다.

### 리허설 오디오

예배 관리자는 편곡에 리허설 오디오 트랙을 첨부할 수 있으므로 팀은 연습 전에 들을 수 있습니다:

1. 노래를 열고 편곡을 선택하세요.
2. **오디오 업로드**를 클릭하세요.
3. MP3, M4A 또는 AAC 파일을 선택하세요(최대 25MB -- 저장소 사용을 관리하기 위해 WAV는 수락되지 않음).
4. 저장하세요. 트랙은 해당 편곡이 나타나는 모든 곳에서 인라인으로 재생됩니다 -- B1 Admin의 편곡 페이지 및 팀 구성원이 B1.church 멤버 포털에서 열 때 서비스 계획에서. 오디오가 있는 계획 항목은 썸네일 대신 음표 아이콘을 표시합니다.

편곡을 삭제하면 업로드된 오디오 파일도 제거됩니다.

:::info
라이브러리의 노래를 계획 내에서 [서비스 순서](./service-order.md)에 직접 추가할 수 있으며, 노래 세부 정보와 선택된 편곡을 해당 서비스에 연결할 수 있습니다.
:::
