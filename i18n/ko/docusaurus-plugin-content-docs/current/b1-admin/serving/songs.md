# 찬양곡

<div class="article-intro">

찬양곡 페이지에서는 찬양 라이브러리를 관리합니다. 찬양의 세부 정보, 가사, 편곡을 한곳에 모아 두면 찬양팀이 다가오는 예배를 쉽게 준비하고 일관된 레퍼토리를 유지할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin의 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)에서 **Serving > Songs**(봉사 > 찬양곡)를 선택하여 찬양곡 페이지에 접근하세요
- 선택 사항으로, 찬양을 [예배 순서](./service-order.md)에 바로 연결할 수 있도록 [예배 계획](./plans.md)을 설정해 두세요

</div>

## 찬양곡 라이브러리 둘러보기 {#browsing-your-song-library}

**Songs**(찬양곡) 페이지를 열면 찬양곡이 표로 나열됩니다. 각 행에는 찬양의 썸네일 이미지, 제목, 아티스트, 길이가 표시됩니다. 목록 아래의 페이지 컨트롤로 큰 라이브러리를 넘겨 볼 수 있으며, 검색으로 원하는 찬양을 찾을 수도 있습니다.

## 찬양 검색하기 {#searching-for-songs}

1. 찬양곡 페이지 상단의 **Search Songs**(찬양 검색) 상자를 클릭하세요.
2. 찬양의 **제목** 또는 **아티스트** 이름을 입력하세요.
3. 입력하는 대로 목록이 필터링되어, 라이브러리에서 일치하는 찬양과 일치하는 개수가 표시됩니다. 모든 찬양을 다시 보려면 **Clear**(지우기)를 클릭하세요.

## 찬양 추가하기 {#adding-a-song}

1. 찬양곡 페이지 상단의 **Add Song**(찬양 추가)을 클릭하세요.
2. **Search for a Song**(찬양 검색)에서 **Title or Artist**(제목 또는 아티스트)로 외부 찬양 데이터베이스를 검색하세요.
3. 추가하려는 찬양을 선택하세요. 찾을 수 없다면 **Create Manually**(직접 만들기)를 클릭하세요.
4. 기본 세부 정보가 미리 채워진 상태로 찬양이 라이브러리에 추가됩니다.

:::tip
찬양을 추가한 후에는 찬양을 클릭하여 세부 정보를 검토하고 업데이트하거나, 편곡을 추가하거나, YouTube 영상이나 코드 악보 같은 외부 링크를 첨부하세요.
:::

### WorshipCommons의 무료 찬양 {#free-songs-from-worshipcommons}

검색 결과에는 일반 결과와 함께 **WorshipCommons — free**(WorshipCommons — 무료) 섹션이 나타날 수 있습니다. 이 찬양은 [WorshipCommons](https://worshipcommons.org)에서 제공하는 주일에 바로 쓸 수 있는 찬양으로, 검토를 거쳐 예배용으로 사용이 허가되었습니다. 각 결과에는 라이선스 배지가 표시됩니다. **Free for worship**(예배에 무료) 또는 **Public domain**(퍼블릭 도메인)이며, 추가하기 전에 이용 조건을 확인할 수 있습니다.

- WorshipCommons 결과를 클릭하면 일반 검색 결과와 마찬가지로 라이브러리에 추가됩니다.
- **View on WorshipCommons**(WorshipCommons에서 보기)를 클릭하면 원본 목록이 새 탭에서 열립니다.

WorshipCommons 심사 과정을 통과한 찬양만 여기에 나타나므로, 선택 항목은 주요 찬양 데이터베이스보다 적을 수 있습니다.

WorshipCommons 전체 라이브러리를 둘러보거나, 악보를 인쇄하거나, 슬라이드를 내보내려면 [WorshipCommons 문서](../../worship-commons/index.md)를 참고하세요.

## 찬양 삭제하기 {#deleting-songs}

한 곡 이상의 찬양 옆 체크박스를 선택하세요(표시된 모든 찬양을 선택하려면 머리글의 체크박스). 나타나는 막대에서 **Delete Selected**(선택 항목 삭제)를 클릭하고 확인하세요. 선택을 해제하려면 **Clear**를 클릭하세요.

## 찬양 보기 및 편집하기 {#viewing-and-editing-a-song}

찬양의 제목을 클릭하면 세부 정보 페이지가 열립니다. 찬양의 제목, 아티스트, 앨범, 키, 길이, BPM, 박자 같은 세부 정보가 왼쪽에 표시되며, 편곡과 외부 링크도 함께 나타납니다. 선택한 편곡의 가사와 키는 페이지의 나머지 부분을 채웁니다. 여기에서 다음을 할 수 있습니다.

- **찬양 세부 정보 편집** -- **Edit**(편집)를 클릭하여 제목, 아티스트, 길이, 기타 메타데이터를 업데이트하세요. 끝나면 **Done**(완료)을 클릭하세요. 찬양을 라이브러리에서 제거하려면 **Edit**를 클릭한 다음 **Delete song**(찬양 삭제)을 클릭하세요.
- **편곡 관리** -- 각 찬양에는 여러 편곡(예: 다른 키나 버전)이 있을 수 있습니다. **Add Arrangement**(편곡 추가)를 클릭하여 편곡을 만들고, **Arrangements**(편곡) 아래에서 편곡의 이름을 클릭하여 엽니다.
- **가사 추가** -- 편곡 이름 옆의 **Edit**를 클릭하면 이름, BPM, 박자, 길이, 순서, 가사를 변경할 수 있습니다. 가사는 ChordPro 표기법으로 입력하세요(예: `[G]Amazing grace`). 편집기 옆의 실시간 미리 보기가 입력하는 동안 서식이 적용된 코드 악보를 보여주므로, 팀이 보게 될 모습을 정확히 확인할 수 있습니다.
- **키 설정** -- 가사 위의 **Key**(키) 선택기로 편곡마다 음악의 키를 지정하세요. 선택기에는 음악가들이 보통 쓰는 방식으로 키가 나열됩니다(C, Db, D, Eb, E, F, F#, G, Ab, A, Bb, B). 키를 바꾸면 편곡 페이지와 예배 계획에서 찬양을 열 때 표시되는 코드가 즉시 조옮김되므로, 팀은 실제로 연주하는 키의 코드를 항상 볼 수 있습니다. 코드 표기는 키에 맞춰집니다. Bb나 Eb 같은 플랫 키에서는 샵 대신 플랫 코드 이름(Bb, Eb, Ab)이 표시됩니다.
- **외부 링크 추가** -- 왼쪽의 **External Links**(외부 링크) 옆 **Edit**를 클릭하면 YouTube, Spotify, Apple, CCLI, Hymnary 같은 서비스의 찬양에 링크할 수 있습니다. 다른 곳에 호스팅된 코드 악보나 악보에 대한 링크는 키에 추가하세요(**Manage keys**(키 관리) 참고).
- **키 관리** -- **Keys**(키) 아래에서 **Add key**(키 추가)를 클릭하여 편곡이 연주되는 키를 추가하세요(**Key Signature**(조표)와 "John's Key"(John의 키)처럼 선택적인 라벨). 키를 선택하고 **Add Files**(파일 추가)를 클릭하면 **Import from PraiseCharts**(PraiseCharts에서 가져오기), 해당 키의 **Add External Link**(외부 링크 추가)(예: 그 키의 코드 악보), 또는 **Upload Audio**(오디오 업로드)를 선택할 수 있습니다.

## 편곡 {#arrangements}

편곡은 찬양의 서로 다른 버전을 나타냅니다. 예를 들어 빠른 현대 버전과 느린 어쿠스틱 버전, 또는 다른 팀을 위해 키만 다르게 한 같은 찬양이 있습니다. 같은 찬양의 각 편곡은 찬양 제목과 아티스트를 공유하지만, 독립적인 설정을 가집니다.

- **Key**(키) -- 편곡을 연주하는 음악의 키
- **BPM** -- 분당 박자 수로 나타낸 템포
- **Length**(길이) -- 초 단위의 길이
- **Meter**(박자) -- 박자표(예: 4/4, 3/4, 6/8)
- **Sequence**(순서) -- 코드와 섹션 구조(예: Intro → Verse → Chorus → Bridge)
- **Lyrics**(가사) -- 화면 표시 또는 영상 송출용
- **External links**(외부 링크) -- 코드 악보, YouTube 녹음, 악보, 기타 자료

찬양을 [예배 순서](./service-order.md)에 추가할 때는 그 특정 예배에 사용할 편곡을 선택할 수 있으므로, 팀은 항상 올바른 버전을 연습하고 연주합니다.

### 연습용 오디오 {#rehearsal-audio}

찬양 관리자는 편곡에 연습용 오디오 트랙을 첨부하여, 팀이 연습 전에 미리 들어볼 수 있도록 할 수 있습니다.

1. 찬양을 열고 편곡을 선택하세요.
2. **Keys**(키) 아래에서 키를 선택하세요(편곡에 키가 없다면 먼저 **Add key**를 클릭하세요). **Add Files**를 클릭하고 **Upload Audio**(오디오 업로드)를 선택하세요.
3. MP3, M4A 또는 AAC 파일을 선택하세요(최대 25MB. 저장 공간을 관리 가능한 수준으로 유지하기 위해 WAV 파일은 허용되지 않습니다).
4. **Save**를 클릭하세요. 이 트랙은 편곡이 나타나는 곳이라면 어디에서든 바로 재생됩니다. B1 Admin의 편곡 페이지와, 팀원이 B1.church 회원 포털에서 여는 예배 계획에서 재생됩니다. 오디오가 있는 계획 항목에는 썸네일 대신 음표 아이콘이 표시됩니다.

편곡을 삭제하면 업로드된 오디오 파일도 함께 삭제됩니다.

:::info
라이브러리의 찬양은 계획 안의 [예배 순서](./service-order.md)에 바로 추가할 수 있으며, 찬양 세부 정보와 선택한 편곡이 그 특정 예배에 연결됩니다.
:::
