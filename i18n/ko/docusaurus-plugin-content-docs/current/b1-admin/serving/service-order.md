# 서비스 순서

<div class="article-intro">

서비스 순서는 경배 서비스의 요소 순서를 정의합니다. 이를 사용하여 여는 노래부터 닫는 기도까지 모든 것을 배치하여 전체 팀이 미리 서비스의 흐름을 알 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 서비스 순서를 작성하려는 날짜에 대해 [서비스 계획](./plans.md)을 만듭니다
- 선택적으로 [노래](./songs.md)를 라이브러리에 추가하여 서비스 순서에 직접 연결할 수 있습니다

</div>

## 서비스 순서에 액세스

1. **봉사**로 이동하여 사역을 선택합니다.
2. **계획 유형**을 클릭한 후 특정 **계획**을 엽니다.
3. 계획 세부 정보 페이지에서 **서비스 순서** 탭을 클릭합니다.

## 서비스 순서 작성

서비스 순서는 서비스 중에 발생할 순서대로 정렬된 항목 목록입니다. 일반적인 요소는 다음과 같습니다:

- 경배 노래
- 기도
- 성경 낭독
- 공지 사항
- 설교 또는 메시지
- 헌금
- 종료

## 서비스 순서에 항목 추가

1. **서비스 순서** 탭에서 **항목 추가**를 클릭합니다.
2. 추가하려는 요소의 유형을 선택합니다 (예: 라이브러리의 노래, 사용자 정의 항목, 제목 또는 **외부 항목**).
3. 제목 및 메모와 같은 항목의 세부 정보를 입력합니다.
4. **저장**을 클릭합니다.

:::tip
라이브러리에서 직접 [노래](./songs.md)를 추가할 수 있습니다. 이렇게 하면 가사 및 편곡을 포함한 노래 세부 정보가 서비스 계획에 연결되어 경배 팀이 필요한 모든 것을 갖게 됩니다.
:::

### 외부 제공자로부터 여러 항목 가져오기

**외부 항목**을 선택하면 단일 항목 양식 대신 연결된 레슨 제공자용 브라우저가 열립니다. 제공자의 콘텐츠를 검색하고 원하는 각 섹션 또는 작업 옆에 있는 상자를 선택합니다. 대화 상자는 선택한 수를 추적합니다 (예: "3개 선택"). 각각에 대해 항목 추가 흐름을 반복하는 대신 **가져오기(3)**를 클릭하여 모두를 한 번에 서비스 순서에 추가합니다.

:::tip
이것이 각 항목을 개별적으로 추가하는 대신 한 번에 전체 레슨의 섹션과 단서를 서비스 순서로 가져오는 가장 빠른 방법입니다.
:::

## 항목 재정렬

각 행의 왼쪽에 있는 핸들을 끌어 순서를 다시 정렬합니다. 항목이 착지할 파란선이나 섹션 헤더로 드롭하여 해당 섹션으로 이동합니다. 화면에 표시되는 순서는 팀이 서비스 중에 따를 순서입니다.

## 레슨 섹션 편집

레슨 및 커리큘럼 섹션 (예: "대형 그룹" 또는 "Engage 1")은 자체 스크립트 줄, 슬라이드 및 비디오를 보유합니다. 내부 항목을 변경하려면 서비스 순서에서 섹션을 클릭합니다. 섹션이 열려 내부의 모든 것이 표시됩니다. 음성 및 지침 줄은 **말하기**, **수행** 또는 **메모**로 표시된 전체 텍스트로 나타나고 슬라이드 또는 비디오는 썸네일과 함께 나타납니다.

- 모든 줄 옆의 **x**를 클릭하여 계획에서 제거합니다. 목록에 남아 있으며 취소선이 그어지고 다시 넣을 화살표가 있습니다.
- 텍스트를 클릭하여 다시 표현합니다. 다시 표현된 줄은 **원래 표현 복원**을 제공합니다.
- **저장**을 클릭합니다. 섹션은 서비스 순서의 단일 행으로 남아 있으며, **8개 항목 중 6개**와 같은 작은 레이블이 사용자 정의했음을 나타내고 실행 시간이 업데이트됩니다.

섹션을 언제든지 다시 열어 변경 사항을 보고, 줄을 다시 넣고, **원래 섹션 복원**을 선택하여 모두 실행 취소할 수 있습니다. 편집은 계획에만 영향을 줍니다. 원래 레슨은 절대 변경되지 않습니다. 인쇄된 계획과 자원봉사자가 보는 항목까지 이어집니다.

섹션의 항목이 자체 행으로 필요한 경우 (예: 두 줄 사이에 노래를 배치하려면), 섹션 행의 오른쪽 끝에 있는 화살표를 클릭하여 내용을 별도 행으로 표시합니다. 해당 행의 첫 번째 행의 화살표를 클릭하여 하나로 다시 접습니다. 이는 연결된 제공자의 콘텐츠에 대해 동일하게 작동합니다.

항목에 할당된 자원봉사자는 서비스 순서에서 바로 옆에 나타나므로 계획을 검토하는 사람은 누가 각 부분을 커버하는지 한 눈에 볼 수 있습니다.

## 시간 및 미디어

각 항목 및 섹션은 실행 시간과 시작 시간을 보여줍니다:

- 계획에 단일 서비스 시간이 선택된 경우, 왼쪽 레일은 각 항목이 시작되는 실제 **시계 시간**을 표시합니다 (예: 오전 9시 14분). 그렇지 않으면 서비스 시작부터의 경과 시간을 표시합니다.
- 섹션 헤더는 내부의 모든 것의 실행 시간을 합산합니다.
- 항목의 편집 화면에서 **분**/**초**를 입력하면 노래 및 사용자 정의 항목이 이 일정에 계산됩니다.
- 미디어 라이브러리에서 추가하는 항목 (이미지 또는 비디오 클립)은 **썸네일**을 표시하고 자동으로 시간이 지정됩니다. 비디오의 길이는 파일 자체에서 측정되고, 이미지는 화면에 남아 있을 때까지 약 5:00 계획 추정(기울임꼴로 표시)을 제공합니다. 여전히 각각을 특정 기간으로 편집할 수 있습니다.

## 항목 편집 및 제거

- 서비스 순서의 모든 항목을 클릭하여 세부 정보를 **편집**합니다.
- **삭제** 옵션을 사용하여 순서에서 항목을 제거합니다.

:::info
서비스 순서는 각 계획에 특정됩니다. 여기서 만드는 변경 사항은 선택한 계획에만 영향을 주며 다른 계획이나 노래 라이브러리를 변경하지 않습니다.
:::

### 항목 일괄 선택 및 삭제

섹션의 여러 항목을 하나씩 삭제하는 대신 한 번에 지우려면:

1. 섹션 헤더의 **항목 선택**을 클릭합니다.
2. 제거하려는 항목을 선택하거나 **섹션의 모두 선택**을 선택하여 해당 섹션 바로 아래의 모든 항목을 잡습니다.
3. **선택한 항목 삭제**를 클릭하고 확인합니다.
4. **선택 완료**를 클릭하여 선택 모드를 종료합니다.

:::info
일괄 선택은 섹션의 직접 자식에만 적용되며 하위 섹션 폴더 내에 중첩된 항목에는 적용되지 않습니다.
:::

## 특정 서비스 시간에 항목 포함

계획에 하나 이상의 서비스 시간(예: 오전 8시 및 오전 10시 서비스)이 있는 경우, 각 항목이 나타날 서비스를 선택할 수 있습니다. 이는 공지 사항이 한 서비스에만 관련이 있거나 노래가 한 서비스에서는 불리지만 다른 서비스에서는 불릴 때 유용합니다.

1. **시간** 탭에 정의된 두 개 이상의 서비스 시간이 있는 계획을 엽니다.
2. **서비스 순서** 탭에서 항목을 클릭하여 편집합니다.
3. **서비스에 포함**에서 시간으로 레이블이 지정된 각 서비스 시간에 대한 체크박스가 표시됩니다.
4. 항목을 건너뛸 서비스를 선택 해제합니다.
5. **저장**을 클릭합니다.

기본적으로 모든 항목이 모든 서비스에 포함됩니다. 제외된 서비스 시간은 해당 서비스로 필터링된 계획을 인쇄할 때 숨겨져 각 서비스는 관련 항목만 포함된 깔끔한 실행 시트를 받습니다.

:::tip
**서비스에 포함** 섹션은 계획에 하나 이상의 서비스 시간이 있을 때만 나타납니다. 서비스가 하나만 보이면 먼저 계획의 **시간** 탭을 편집하여 추가 서비스를 추가하세요.
:::

### 서비스별로 다른 위치 표시

항목에 **위치**가 설정되어 있으면 **서비스에 포함**의 각 선택된 서비스 시간도 자체 **이 서비스에 대한 위치** 드롭다운을 가져옵니다. 같은 섹션이 각 서비스에서 다른 자원봉사자가 담당할 때 사용합니다. **위와 동일**로 설정된 상태로 두어 항목의 기본 위치를 유지하거나 다른 위치를 선택하여 해당 서비스 시간에만 재정의하세요.

## 서비스 순서 공유

서비스 순서가 완료되면 계획 세부 정보 페이지에서 전체 계획(서비스 순서 포함)을 인쇄할 수 있습니다. 이렇게 하면 팀이 서비스의 완전한 개요를 얻습니다. 인쇄에 **자원봉사 이름 표시**가 켜져 있으면 각 섹션 헤더도 할당된 자원봉사자의 위치와 함께 인쇄되므로 팀이 앱을 열지 않고도 누가 해당 섹션을 담당하는지 볼 수 있습니다. 제목의 위치가 특정 서비스에 대해 재정의된 경우, 인쇄는 해당 계획의 서비스 전체에서 해결되는 모든 고유한 위치 이름을 표시합니다 (예: "경배 팀 / 청소년 팀").
