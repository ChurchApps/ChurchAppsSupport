# 예배 순서

<div class="article-intro">

예배 순서는 예배 안에서 요소들이 진행되는 차례를 정의합니다. 시작 찬양부터 마무리 기도까지 모든 것을 배치해서, 팀 전체가 미리 예배의 흐름을 파악할 수 있게 해줍니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 예배 순서를 구성하려는 날짜에 대한 [예배 일정](./plans.md)을 만드세요
- 선택적으로, 라이브러리에 [곡](./songs.md)을 추가해 두면 예배 순서에 바로 연결할 수 있습니다

</div>

## 예배 순서 접근하기

1. **섬김(Serving)**으로 이동해 사역을 선택합니다.
2. **일정 유형**을 클릭한 다음 특정 **일정**을 엽니다.
3. 일정 상세 페이지에서 **예배 순서(Service Order)** 탭을 클릭합니다.

## 예배 순서 구성하기

예배 순서는 예배 중에 진행될 순서대로 배열된 항목 목록입니다. 일반적인 요소는 다음과 같습니다.

- 찬양
- 기도
- 성경 봉독
- 공지
- 설교 또는 메시지
- 헌금
- 마침

## 예배 순서에 항목 추가하기

1. **예배 순서(Service Order)** 탭에서 **항목 추가(Add Item)**를 클릭합니다.
2. 추가할 요소의 유형을 선택합니다(예: 라이브러리의 곡, 사용자 지정 항목, 또는 제목).
3. 제목과 메모 등 항목의 세부 정보를 입력합니다.
4. **저장(Save)**을 클릭합니다.

:::tip
[곡(Songs)](./songs.md) 라이브러리에서 곡을 바로 추가할 수 있습니다. 이렇게 하면 가사와 편곡을 포함한 곡의 세부 정보가 예배 일정에 연결되어, 예배팀이 필요한 모든 것을 갖추게 됩니다.
:::

## 항목 순서 변경하기

각 행 왼쪽의 손잡이를 드래그해서 항목의 순서를 바꿀 수 있습니다 -- 항목을 놓고 싶은 위치의 파란 선 위에, 또는 다른 섹션으로 옮기려면 해당 섹션 제목 위에 드롭하세요. 화면에 표시되는 순서가 팀이 예배 중 따라야 할 순서입니다.

## 시간과 미디어

각 항목과 섹션은 얼마나 진행되는지, 언제 시작하는지를 보여줍니다.

- 일정에 단일 예배 시간이 선택되어 있으면 왼쪽 레일에는 각 항목이 시작되는 실제 **시각**(예: 오전 9:14)이 표시됩니다. 그렇지 않으면 예배 시작으로부터의 경과 시간이 표시됩니다.
- 섹션 제목에는 그 안에 포함된 모든 항목의 진행 시간 합계가 표시됩니다.
- 곡과 사용자 지정 항목은 항목 편집 화면에서 **분(Minutes)**/**초(Seconds)**를 입력해야 이 일정에 반영됩니다.
- 미디어 라이브러리(이미지 또는 비디오 클립)에서 추가한 항목은 **썸네일**을 표시하며 자동으로 시간이 계산됩니다 -- 비디오의 길이는 파일 자체에서 측정되며, 이미지는 진행자가 다음으로 넘기기 전까지 화면에 남아 있으므로 약 5:00의 예상 시간(이탤릭체로 표시)이 부여됩니다. 두 경우 모두 특정 시간으로 직접 수정할 수 있습니다.

## 항목 편집 및 삭제하기

- 예배 순서의 아무 항목이나 클릭하면 세부 정보를 **편집**할 수 있습니다.
- **삭제** 옵션을 사용해 순서에서 항목을 제거합니다.

:::info
예배 순서는 각 일정마다 별도로 존재합니다. 여기서 변경한 내용은 선택한 일정에만 영향을 주며, 다른 일정이나 곡 라이브러리에는 영향을 주지 않습니다.
:::

## 특정 예배 시간에만 항목 포함하기

일정에 예배 시간이 두 개 이상 있는 경우(예: 오전 8시와 오전 10시 예배), 각 항목이 어느 예배에 표시될지 선택할 수 있습니다. 특정 공지가 한 예배에만 해당하거나, 어떤 곡이 한 예배에서는 불리지만 다른 예배에서는 불리지 않을 때 유용합니다.

1. **시간(Times)** 탭에 예배 시간이 두 개 이상 정의된 일정을 엽니다.
2. **예배 순서(Service Order)** 탭에서 항목을 클릭해 편집합니다.
3. **포함할 예배(Include in Services)** 아래에서 각 예배 시간에 대한 체크박스를 확인할 수 있으며, 각 체크박스에는 해당 시간이 표시됩니다.
4. 항목을 건너뛸 예배의 체크를 해제합니다.
5. **저장(Save)**을 클릭합니다.

기본적으로 모든 항목은 모든 예배에 포함됩니다. 제외된 예배 시간은 해당 예배로 필터링해 일정을 인쇄할 때 숨겨지므로, 각 예배가 관련 있는 항목만 담긴 깔끔한 진행표를 받을 수 있습니다.

:::tip
**포함할 예배(Include in Services)** 섹션은 일정에 예배 시간이 두 개 이상 있을 때만 나타납니다. 예배가 하나만 보인다면, 먼저 일정의 **시간(Times)** 탭을 편집해 추가 예배를 만드세요.
:::

## 예배 순서 공유하기

예배 순서가 완성되면, 일정 상세 페이지에서 예배 순서를 포함한 전체 일정을 인쇄할 수 있습니다. 이를 통해 팀 전체가 예배의 전체 흐름을 파악할 수 있습니다.
