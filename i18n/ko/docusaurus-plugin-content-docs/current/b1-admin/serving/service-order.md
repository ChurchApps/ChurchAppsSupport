# 서비스 순서

<div class="article-intro">

서비스 순서는 예배 서비스의 요소 순서를 정의합니다. 이를 사용하여 개시 노래부터 종료 기도까지 모든 것을 배치하여 전체 팀이 미리 서비스 흐름을 알 수 있도록 하세요.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 서비스 순서를 작성하려는 날짜를 위해 [서비스 계획](./plans.md)을 만드세요
- 선택적으로 서비스 순서에 직접 연결할 수 있도록 라이브러리에 [노래](./songs.md)를 추가하세요

</div>

## 서비스 순서 액세스

1. **섬김**으로 이동하고 사역을 선택하세요.
2. **계획 유형**을 클릭한 다음 특정 **계획**을 열어보세요.
3. 계획 상세 페이지에서 **서비스 순서** 탭을 클릭하세요.

## 서비스 순서 구축

서비스 순서는 서비스 중에 발생할 순서대로 배열된 항목 목록입니다. 일반적인 요소는 다음과 같습니다:

- 예배 노래
- 기도
- 성경 읽기
- 공지
- 설교 또는 메시지
- 헌금
- 종료

## 서비스 순서에 항목 추가

1. **서비스 순서** 탭에서 **항목 추가**를 클릭하세요.
2. 추가하려는 요소 유형을 선택하세요(예: 라이브러리의 노래, 사용자 정의 항목, 제목 또는 **외부 항목**).
3. 제목 및 메모와 같은 항목에 대한 세부 정보를 입력하세요.
4. **저장**을 클릭하세요.

:::tip
[노래](./songs.md) 라이브러리에서 직접 노래를 추가할 수 있습니다. 이렇게 하면 가사 및 편곡을 포함한 노래 세부 정보가 서비스 계획에 연결되므로 예배 팀이 필요한 모든 것을 가질 수 있습니다.
:::

### 외부 제공자에서 여러 항목 가져오기

**외부 항목**을 선택하면 단일 항목 양식 대신 연결된 수업 제공자에 대한 브라우저가 열립니다. 제공자의 콘텐츠를 탐색(또는 검색)하고 원하는 각 섹션 또는 작업 옆의 상자를 선택하세요. 대화 상자는 선택한 항목을 추적합니다(예: "3개 선택") -- 각각에 대해 항목 추가 흐름을 반복하지 않고 모두 한 번에 서비스 순서에 추가하려면 **가져오기(3)**를 클릭하세요.

:::tip
이는 각 항목을 개별적으로 추가하지 않고 전체 수업 가치의 섹션과 단서를 한 번에 서비스 순서로 끌어오는 가장 빠른 방법입니다.
:::

## 항목 재정렬

각 행의 왼쪽 핸들로 항목을 드래그하여 순서를 재정렬하세요 -- 항목을 착지할 원하는 파란색 선으로 드롭하거나 섹션 헤더로 드롭하여 해당 섹션으로 이동하세요. 화면에 표시되는 순서는 팀이 서비스 중에 따를 순서입니다.

## 수업 섹션 편집

수업 및 교과과정 섹션(예: "Large Group" 또는 "Engage 1")은 자체 스크립트 라인, 슬라이드 및 비디오를 보유합니다. 내부를 변경하려면 서비스 순서의 섹션을 클릭하세요. 섹션이 열려 내부의 모든 내용을 표시합니다: 말하고 지시 라인은 **말하기**, **하기** 또는 **메모**로 표시된 전체 텍스트로 나타나고 슬라이드 또는 비디오는 썸네일로 나타납니다.

- 모든 라인 옆의 **x**를 클릭하여 계획에서 제거하세요. 이는 목록에 남아 있고 취소선이 그어져 있으며 다시 넣을 화살표가 있습니다.
- 텍스트를 클릭하여 다시 표현하세요. 다시 표현된 라인은 **원래 표현 복원**을 제공합니다.
- **저장**을 클릭하세요. 섹션은 서비스 순서에 단일 행으로 남아 있고 **6 of 8 items**과 같은 작은 레이블이 사용자 정의했음을 표시하고 실행 시간이 업데이트됩니다.

언제든지 섹션을 다시 열어 변경 사항을 보거나 라인을 다시 넣거나 **원래 섹션 복원**을 선택하여 모두 취소할 수 있습니다. 편집은 계획에만 영향을 미칩니다 -- 원래 수업은 절대 변경되지 않습니다 -- 인쇄된 계획과 자원봉사자가 보는 내용으로 전달됩니다.

섹션의 항목이 자체 행으로 필요한 경우(예: 두 라인 사이에 노래를 배치하려면) 섹션 행의 오른쪽 끝의 화살표를 클릭하여 내용을 별도의 행으로 표시하세요. 해당 행 중 첫 번째의 화살표를 클릭하여 다시 하나로 접으세요. 이는 연결된 모든 제공자의 콘텐츠에 대해 동일한 방식으로 작동합니다.

항목에 할당된 자원봉사자는 서비스 순서의 옆에 나타나므로 계획을 검토하는 모든 사람이 한눈에 누가 각 부분을 다루고 있는지 볼 수 있습니다.

## 타이밍 및 미디어

각 항목 및 섹션은 실행 시간과 시작 시간을 표시합니다:

- 계획에 단일 서비스 시간이 선택된 경우 왼쪽 레일은 각 항목이 시작하는 실제 **시계 시간**(예: 오전 9:14)을 표시합니다. 그렇지 않으면 서비스 시작 이후 경과 시간을 표시합니다.
- 섹션 헤더는 내부의 모든 것의 실행 시간을 합계합니다.
- 항목의 편집 화면에서 **분**/**초**를 입력하면 노래 및 사용자 정의 항목이 이 일정에 포함됩니다.
- 미디어 라이브러리(이미지 또는 비디오 클립)에서 추가하는 항목은 **썸네일**을 표시하고 자동으로 시간이 정해집니다 -- 비디오의 지속 시간은 파일 자체에서 측정되는 반면 이미지는 운영자가 진행할 때까지 화면에 남아있으므로 ~5:00 계획 추정(이탤릭체로 표시됨)을 제공합니다. 여전히 둘 다를 특정 기간으로 편집할 수 있습니다.

## 항목 편집 및 제거

- 서비스 순서의 모든 항목을 클릭하여 **편집** 세부 정보를 선택하세요.
- **삭제** 옵션을 사용하여 순서에서 항목을 제거하세요.

:::info
서비스 순서는 각 계획별입니다. 여기서 변경하는 내용은 선택된 계획에만 영향을 미치며 다른 계획이나 노래 라이브러리를 변경하지 않습니다.
:::

### 대량 선택 및 삭제 항목

한 번에 하나씩 삭제하는 대신 섹션의 여러 항목을 한 번에 제거하려면:

1. 섹션 헤더에서 **항목 선택**을 클릭하세요.
2. 제거하려는 항목을 확인하거나 **섹션의 모두 선택**을 확인하여 해당 섹션 바로 아래의 모든 항목을 선택하세요.
3. **선택 항목 삭제**를 클릭하고 확인하세요.
4. **선택 완료**를 클릭하여 선택 모드를 종료하세요.

:::info
대량 선택은 섹션의 직접 하위 항목에만 적용되고 하위 섹션 폴더 내에 중첩된 항목에는 적용되지 않습니다.
:::

## 특정 서비스 시간에 항목 포함

계획에 둘 이상의 서비스 시간(예: 오전 8시 및 오전 10시 서비스)이 있으면 각 항목이 표시되어야 하는 서비스를 선택할 수 있습니다. 이는 공지가 한 서비스에만 관련되거나 노래가 한 서비스에서는 불려지지만 다른 서비스에서는 불려지지 않을 때 유용합니다.

1. **과제** 탭의 **시간** 카드에 정의된 두 개 이상의 서비스 시간이 있는 계획을 열어보세요.
2. **서비스 순서** 탭에서 항목을 클릭하여 편집하세요.
3. **서비스에 포함**에서 시간으로 표시된 각 서비스 시간에 대한 확인란을 볼 수 있습니다.
4. 항목을 건너뛸 서비스의 선택을 취소하세요.
5. **저장**을 클릭하세요.

기본적으로 모든 항목이 모든 서비스에 포함됩니다. 제외된 서비스 시간은 해당 서비스로 필터링된 계획을 인쇄할 때 숨겨지므로 각 서비스는 관련 항목만 포함하는 깔끔한 실행 시트를 받습니다.

:::tip
**서비스에 포함** 섹션은 계획에 둘 이상의 서비스 시간이 있을 때만 나타납니다. 한 서비스만 보이면 계획의 **과제** 탭의 **시간** 카드를 사용하여 먼저 추가 서비스를 추가하세요.
:::

### 서비스당 다른 위치 표시

항목에 **위치**가 설정되면 **서비스에 포함**에서 확인된 각 서비스 시간도 자체 **이 서비스의 위치** 드롭다운을 가집니다. 동일한 섹션이 각 서비스에서 다른 자원봉사자가 다룰 때 사용하세요 -- 항목의 기본 위치를 유지하려면 **위**로 설정된 상태로 두거나 그 서비스 시간에만 재정의하려면 다른 위치를 선택하세요.

## 서비스 순서 공유

서비스 순서가 완료되면 계획 상세 페이지에서 전체 계획(서비스 순서 포함)을 인쇄할 수 있습니다. 이는 팀에 교회 이름 및 계획 이름으로 표제된 서비스의 완전한 요약을 제공합니다. 인쇄를 위해 **자원봉사자 이름 표시**가 켜져 있으면 각 섹션 헤더도 할당된 자원봉사자의 위치 옆에 인쇄되므로 팀은 앱을 열지 않고도 누가 해당 섹션을 다루고 있는지 볼 수 있습니다. 제목의 위치가 특정 서비스에 대해 재정의된 경우 인쇄는 해당 계획의 서비스 전체에서 해결되는 모든 고유 위치 이름을 표시합니다(예: "예배팀 / 청소년팀").
