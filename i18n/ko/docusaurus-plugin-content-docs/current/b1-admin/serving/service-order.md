# 서비스 순서
<div class="article-intro">
서비스 순서는 예배 서비스의 요소 순서를 정의합니다. 오프닝 곡부터 마감 기도까지 모든 것을 배치하여 전체 팀이 서비스 흐름을 알 수 있습니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- 서비스 계획이 [생성](./plans.md)되어야 합니다
- 선택적으로 [노래](./songs.md)가 라이브러리에 추가되어야 합니다
</div>
## 서비스 순서 접근
1. **섬김**으로 이동하고 사역을 선택합니다
2. **계획 유형**을 클릭한 후 특정 **계획**을 엽니다
3. 계획 세부 정보 페이지에서 **서비스 순서** 탭을 클릭합니다
## 항목 추가
1. **서비스 순서** 탭에서 **항목 추가**를 클릭합니다
2. 추가할 요소 유형을 선택합니다
3. 항목 세부 정보(제목 등)를 입력합니다
4. **저장**을 클릭합니다
:::tip
라이브러리에서 노래를 직접 추가할 수 있습니다.
:::
## 항목 재정렬
각 행의 왼쪽 핸들을 드래그하여 순서를 다시 정렬합니다.
