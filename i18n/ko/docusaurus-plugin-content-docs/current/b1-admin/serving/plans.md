# 서비스 계획
<div class="article-intro">
서비스 계획은 누가 언제 봉사하는지를 구성합니다. 각 계획은 특정 날짜와 사역과 연결되어, 매주 자원봉사팀을 조정하고 모든 서비스가 완전히 배치되도록 합니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- 섬김 영역에서 사역과 팀을 설정합니다
- 자원봉사자가 [사람 디렉토리](../people/adding-people.md)에 추가되고 팀에 할당되어야 합니다
</div>
## 계획 접근
1. 주 메뉴에서 **섬김**으로 이동합니다
2. 위쪽의 **사역 탭**을 선택합니다
3. **계획 유형**을 클릭하여 해당 계획 목록을 봅니다
4. 특정 계획을 클릭하여 엽니다
## 계획 생성
1. 계획 유형 보기에서 **새 계획**을 클릭합니다
2. 계획에 이름을 지정하거나 날짜를 사용합니다
3. 서비스의 **날짜**를 선택합니다
4. 이전 계획에서 복사하려면, 위치만 또는 위치와 할당을 선택합니다
5. 계획을 저장합니다
## 팀 구성원 할당
1. 계획을 열고 **할당** 탭으로 이동합니다
2. **위치 추가**를 클릭합니다
3. 자원봉사자를 선택하고 **추가**를 클릭합니다
4. 할당된 구성원이 팀 아래 표시됩니다
5. **자원봉사자에게 알리기**를 클릭하여 알림을 보냅니다
## 자원봉사자 미리 알림
B1는 자원봉사자에게 예정된 서비스 전에 자동으로 알림을 보낼 수 있습니다.
1. **섬김** 영역에서 사역을 선택합니다
2. 계획 유형 옆의 **편집** 아이콘을 클릭합니다
3. **미리 알림** 섹션에서 다음을 설정합니다:
   - **미리 알림 일수** — 쉼표로 구분된 날짜 (예: `7,1,0`)
   - **커스텀 메시지** — 추가 텍스트 (선택사항)
4. 계획 유형을 저장합니다
