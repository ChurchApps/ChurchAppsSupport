# 예배 일정

<div class="article-intro">

예배 일정은 누가 언제 섬기는지를 정리합니다. 각 일정은 특정 날짜와 사역에 연결되어 있어, 자원봉사자 팀을 주 단위로 조율하고 모든 예배에 충분한 인력이 배치되도록 하기가 쉬워집니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 섬김(Serving) 영역에서 사역과 팀을 설정하세요
- 자원봉사자가 [인물 디렉터리](../people/adding-people.md)에 등록되고 팀에 배정되어 있는지 확인하세요

</div>

## 일정 접근하기

1. 메인 메뉴에서 **섬김(Serving)**으로 이동합니다.
2. 페이지 상단의 **사역 탭**을 선택합니다.
3. **일정 유형**을 클릭하여 해당 유형의 일정 목록을 확인합니다.
4. 특정 일정을 클릭하여 엽니다.

:::info
일정을 관리하는 데 전체 관리자 권한이 필요하지는 않습니다. 사역의 구성원이라면 누구나 섬김 영역으로 이동해 Plans Edit 권한 없이도 자신의 사역에 대한 일정을 만들고, 편집하고, 배정할 수 있습니다. Plans Edit 역할을 가진 편집자는 모든 사역의 일정을 관리할 수 있습니다.
:::

## 일정 만들기

1. 일정 유형 화면에서 **새 일정(New Plan)**을 클릭합니다.
2. 일정에 이름을 붙이거나 날짜를 이름으로 사용합니다. 예배의 **날짜**를 선택합니다.
3. 이전 일정에서 복사하려면 직책만 복사할지, 직책과 배정을 모두 복사할지 선택합니다. 복사를 원하지 않으면 아무것도 선택하지 않으면 됩니다. 이전 일정의 예배 순서도 함께 복사할 수 있습니다.
4. 일정을 저장합니다. 이제 팀원을 배정하고 [예배 순서](./service-order.md)를 구성할 수 있습니다.

## 일정 상세 페이지

일정을 열면 두 개의 탭이 표시됩니다.

- **배정(Assignments)** -- 이 일정에 배정된 팀원을 관리합니다. 기존 팀에서 사람을 추가하고 누가 확정했는지 또는 아직 대기 중인지 확인할 수 있습니다.
- **[예배 순서](./service-order.md)** -- 찬양, 기도, 공지, 설교 같은 요소로 예배 순서를 구성합니다.

## 팀원 배정하기

1. 일정을 열고 **배정(Assignments)** 탭으로 이동합니다.
2. **직책 추가(add Position)**를 클릭하여 확장합니다. 직책 추가 양식에 정보를 입력합니다. 카테고리 이름은 원하는 대로 추가하면 됩니다.
3. **필요한 인원(People Needed)**을 클릭하고 그 직책을 맡을 자원봉사자를 선택합니다.
4. **추가(Add)**를 클릭하여 팀 명단에서 구성원을 추가합니다.
5. 배정된 구성원은 배정 상태와 함께 해당 팀 아래에 표시됩니다.
6. 자원봉사자에게 알리기를 클릭하면 B1 앱 또는 이메일로 알림을 보낼 수 있습니다.

각 직책에는 (예: "2/3"처럼) 인원 수 칩이 표시되어 얼마나 많은 자리가 채워졌는지 한눈에 볼 수 있습니다. 배정(Assignments) 탭 상단에는 진행률 표시줄과 요약 칩("전체 Y개 중 X개 직책 채움")이 표시되어 일정의 전체 인력 배치 현황을 보여주며, 모든 직책이 채워지면 **인력 배치 완료(Fully staffed)**로 바뀝니다.

:::tip
일정을 만들기 전에 사역 설정에서 팀을 미리 구성해 두세요. 이렇게 하면 배정할 수 있는 자원봉사자 풀이 항상 준비되어 있습니다.
:::

## 자원봉사자 알림

B1은 자원봉사자가 배정된 예배가 다가올 때 자동으로 알림을 보낼 수 있어, 매주 팀원을 일일이 챙길 필요가 없습니다. 알림은 확정한 사람과 아직 응답하지 않은 사람 모두를 포함해 **배정된 모든 사람**에게 이메일과 앱 내/푸시 알림으로 전송됩니다. 각 알림에는 자원봉사자의 직책, 예배 날짜, 일정 메모, 그리고 사용자 지정 메시지가 포함됩니다.

알림 시점과 내용은 **일정 유형**별로 설정되므로, 각 예배 종류마다 고유한 알림 일정을 유지할 수 있습니다.

1. **섬김(Serving)** 영역에서 해당 일정 유형이 속한 사역을 선택합니다.
2. 일정 유형 옆의 **편집(연필) 아이콘**을 클릭합니다.
3. **알림(Reminders)** 섹션에서 다음을 설정합니다.
   - **예배 며칠 전 알림(Reminder days before service)** -- 며칠 전에 보낼지 쉼표로 구분한 목록입니다. 예: `7,1,0`. 예배 당일에 알림을 보내려면 `0`을 사용하세요. 이 일정 유형에 대한 알림을 끄려면 이 필드를 비워 두세요.
   - **사용자 지정 알림 메시지(Custom reminder message)** *(선택 사항)* -- 알림에 추가되는 문구입니다. 예를 들어 "리허설을 위해 30분 일찍 도착하세요."
4. 일정 유형을 저장합니다.

새로 만든 일정 유형은 별도로 변경하지 않는 한 기본적으로 각 예배 **2일 전**에 자원봉사자에게 알림을 보냅니다.

:::tip
아직 확정하지 않은 자원봉사자는 알림 이메일 안에서 바로 **수락(Accept)**과 **거절(Decline)** 버튼을 사용할 수 있어, 로그인하지 않고도 응답할 수 있습니다.
:::

:::info
각 알림은 한 번만 전송됩니다. 아직 임시로 작성 중인(팀에 아직 전달되지 않은) 일정은 알림을 발송하지 않습니다.
:::

## 일정 유형에 그룹 연결하기

일정 유형 페이지의 일정 목록 아래에 있는 **그룹(Groups)** 섹션에서는 어떤 그룹이 멤버 포털에서 이 일정 유형의 일정을 볼 수 있는지 지정할 수 있습니다. 관리자 권한을 부여하지 않고도 해당 팀에게 다가오는 예배를 빠르게 알릴 수 있는 방법입니다.

1. 일정 유형 페이지에서 아래로 스크롤하여 **그룹(Groups)** 섹션으로 이동합니다.
2. **그룹 추가(Add Group)**를 클릭하고 드롭다운에서 그룹을 선택합니다.
3. **표시(Shows)** 열에서 해당 그룹의 구성원이 이 일정 유형에 대해 **과거(Past)**, **미래(Future)**, 또는 **둘 다(Both)**의 일정을 보게 할지 선택합니다.
4. 반복해서 추가 그룹을 연결하거나, 휴지통 아이콘을 클릭해 그룹을 제거합니다.

:::info
**표준(Standard)**으로 태그된 그룹만 선택 목록에 나타납니다. 연결된 그룹의 구성원은 B1 멤버 포털의 [일정(Plans)](/docs/b1-church/plans/) 탭에서 이 일정 유형의 일정을 자동으로 확인할 수 있으며, 선택한 과거/미래/둘 다 범위로 제한됩니다.
:::

## 일정 인쇄하기

팀에 배포할 일정을 인쇄할 수 있습니다. 일정을 열고 예배 순서 탭을 연 다음 **인쇄(Print)** 옵션을 사용하면 배정 내용과 예배 순서가 포함된 인쇄용 버전을 만들 수 있습니다. 리허설에서 나눠주거나 공용 공간에 게시할 때 유용합니다.

:::info
일정은 사역별로 정리됩니다. 일정을 만들거나 조회하기 전에 올바른 사역 탭에 있는지 확인하세요.
:::
