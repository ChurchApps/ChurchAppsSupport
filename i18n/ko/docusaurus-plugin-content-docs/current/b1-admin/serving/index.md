# 봉사

<div class="article-intro">

봉사 섹션은 자원봉사자를 조율하고 교회 예배를 계획하는 중심 공간입니다. 주일 예배, 주중 모임, 특별 행사 등 무엇을 준비하든, 여기서 모든 것을 한데 모아 각 팀이 누가 언제 섬기는지 정확히 알 수 있도록 하세요.

</div>

## 봉사 페이지 작동 방식 {#how-the-serving-page-works}

**Serving**(봉사) 페이지를 열면 상단에 사역이 탭으로 표시됩니다. 각 사역에는 고유한 계획 유형과 팀이 있으므로, 여러 사역을 각각 독립적으로 관리할 수 있습니다. 예를 들어 Worship(예배), Kids Ministry(어린이 사역), Hospitality(환대) 탭을 따로 둘 수 있습니다.

사역의 구성원인 관리자가 아닌 직원도 봉사 페이지에 접근할 수 있습니다. 이들은 자신이 속한 사역만 보게 되며, 전체 관리자 권한이 없어도 해당 사역의 계획, 배정, 계획 유형, 예배 순서를 만들고 편집할 수 있습니다.

:::tip
관리자라면 탭에 자신이 속한 사역과 아직 구성원이 없는 사역(**Mine**(내 사역))이 표시됩니다. 모든 사역을 보려면 **All**(전체)을 선택하세요. 여러 팀의 배정을 확인해야 할 때 유용합니다. 교회에 사역이 많다면 **Find a ministry**(사역 찾기) 상자가 나타나 이름으로 탭을 필터링할 수 있습니다.
:::

## 하위 섹션 {#sub-sections}

봉사 섹션에는 다음과 같은 주요 영역이 있습니다.

- **[계획](./plans.md)** -- 특정 날짜의 예배 계획을 만들고 팀에 자원봉사자를 배정하세요. 계획을 통해 누가 언제 섬기는지 정리하여, 모두가 미리 자신의 역할을 알 수 있습니다. 푸시, 이메일 또는 문자로 자동 [자원봉사자 알림](./plans.md#volunteer-reminders)을 설정하면 매 예배 전에 팀에 알림이 전송되며, **[계획 개요](./plans-overview.md)** 를 사용하면 여러 주에 걸친 모든 예정 배정을 하나의 표에서 볼 수 있습니다.
- **[찬양곡](./songs.md)** -- 가사, 편곡, 외부 링크가 포함된 찬양곡 라이브러리를 관리하세요. 찬양팀은 이를 활용해 다가오는 예배를 준비할 수 있습니다.
- **[작업](./tasks.md)** -- **My Work**(내 작업)에서 팀원에게 작업을 배정하고 추적하세요.
- **[워크플로](./workflows.md)** -- 시각적인 칸반 보드에서 사람들을 일련의 단계를 거쳐 이동시키세요. 예를 들어 새 방문자 후속 조치나 회원 가입 절차에 활용할 수 있습니다. 단계에서는 자동 작업(이메일 보내기, 며칠 기다리기, 그룹에 추가하기)을 실행할 수 있으며, 카드는 결과 버튼, 조건부 분기, 또는 이벤트와 일정 트리거에 따라 다음 단계로 넘어갑니다. 보고서 기능도 내장되어 있습니다.

## 시작하기 {#getting-started}

1. B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Serving**(봉사)을 펼친 다음 **Plans**(계획)를 클릭하세요.
2. **Add Ministry**(사역 추가)를 클릭하여 새 사역을 만들거나 **All**을 선택하여 기존의 모든 사역을 보세요. **사역 탭**을 선택하면 해당 사역의 계획 유형과 봉사 팀을 볼 수 있습니다.
3. **Create Plan Type**(계획 유형 만들기)(또는 **Add Plan Type**(계획 유형 추가))을 클릭하거나 기존 계획 유형을 선택하여 [예배 계획 만들기](./plans.md)를 시작하거나, [찬양곡](./songs.md) 및 [작업](./tasks.md) 하위 섹션을 살펴보세요.

:::info
계획을 만들기 전에 봉사 영역에서 사역을 만들고 각 사역 안에 팀을 만들어야 합니다. 사역 탭을 선택하고 **Serving Teams**(봉사 팀) 목록에서 **Create Serving Team**(봉사 팀 만들기)(또는 **New Serving Team**(새 봉사 팀))을 클릭하여 팀을 추가하세요.
:::
