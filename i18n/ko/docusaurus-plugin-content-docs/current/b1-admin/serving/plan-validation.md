# 계획 검증 및 자원봉사자 알림

<div class="article-intro">

B1 Admin은 주일 전에 자동으로 계획에서 문제를 확인합니다. 채워지지 않은 위치, 일정 충돌, 날짜를 차단한 자원봉사자들. 모든 것이 좋아 보이면 한 번의 클릭으로 전체 팀에 알릴 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [서비스 계획](./plans.md)을 만들고 자원봉사자를 위치에 할당합니다
- 충돌 감지가 겹침을 확인할 수 있도록 계획에 [서비스 시간](./plans.md)을 추가합니다
- 자원봉사자가 푸시 알림을 받기 위해 B1 모바일 앱을 설치했는지 확인합니다

</div>

## 검증 패널

모든 계획에는 계획을 작성할 때 자동으로 실행되는 **검증** 패널이 있습니다. 세 가지를 확인합니다:

### 채워지지 않은 위치

위치에 현재 할당된 것보다 더 많은 사람이 필요한 경우, 검증 패널은 아직 필요한 것을 정확히 나열합니다. 예를 들어 *"음향 담당: 1명 필요"*. 주가 도착하기 전에 계획이 완전히 채워졌는지 한 눈에 볼 수 있습니다.

### 일정 충돌

자원봉사자가 같은 계획 내에서 시간이 겹치는 두 위치에 할당된 경우, 검증 패널은 충돌을 표시합니다. 예를 들어 *"Jane Smith: 주일 예배 중 예배 인도자와 어린이 체크인 사이의 시간 충돌"*. 이것은 이중 예약이 일요일 아침 문제가 되기 전에 잡아냅니다.

### 차단 날짜

자원봉사자는 B1 모바일에서 이용할 수 없는 날짜를 설정할 수 있습니다. 누군가가 차단 날짜 중 하나에 해당하는 계획에 할당된 경우, 검증 패널은 자동으로 충돌을 표시하므로 대체를 찾을 수 있습니다.

### 계획 간 충돌

검증은 또한 모든 계획을 한 번에 확인합니다. 같은 자원봉사자가 시간이 겹치는 두 개의 다른 계획에서 할당되는 경우, 예를 들어 오전 9시 서비스와 오전 10시 서비스가 모두 오전 10시 30분까지 실행되는 경우, B1 Admin은 해당 사람을 계획 전체에서 이중 예약으로 표시합니다.

:::tip
검증을 실행하기 위해 아무것도 할 필요가 없습니다. 할당을 추가하거나 변경할 때마다 자동으로 업데이트됩니다. 계획을 작성할 때 패널을 주시하기만 하면 됩니다.
:::

## 자원봉사자 알림

계획이 설정되면 검증 패널에서 직접 할당된 모든 자원봉사자에게 한 번에 알릴 수 있습니다.

1. 계획을 열고 **검증** 패널로 스크롤합니다
2. 알림을 받지 않은 자원봉사자가 있는 경우, 몇 명이 알림을 받아야 하는지 보여주는 링크가 표시됩니다 (예: *"8명의 자원봉사자에게 알림"*)
3. 링크를 클릭하여 아직 알림을 받지 않은 모두에게 푸시 알림을 보냅니다
4. 자원봉사자는 자신이 예약되었음을 알리는 휴대폰에서 알림을 받고 할당을 확인하도록 요청받습니다

:::info
아직 알림을 받지 않은 자원봉사자만 포함됩니다. 나중에 계획에 누군가를 추가하면 링크가 다시 나타나므로 나머지 팀에 다시 알리지 않고 새로운 추가 사항을 알릴 수 있습니다.
:::

:::warning
자원봉사자는 푸시 알림을 받기 위해 B1.church 모바일 환경(홈 화면의 PWA 또는 여전히 사용 중인 사용자용 더 이상 사용되지 않는 B1 모바일 기본 앱)이 설치되어 있고 알림이 활성화되어 있어야 합니다. 설정 지침은 [앱으로 설치(PWA)](/docs/b1-church/getting-started/installing-pwa)를 참조하세요.
:::
