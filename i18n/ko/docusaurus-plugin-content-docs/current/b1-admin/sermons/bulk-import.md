# 대량 가져오기

<div class="article-intro">

대량 가져오기 페이지를 사용하면 YouTube 또는 Vimeo에서 비디오를 가져와 설교 라이브러리를 빠르게 채울 수 있습니다. 이것이 각 비디오를 하나씩 추가하는 것보다 기존 설교 콘텐츠를 가져오는 가장 빠른 방법입니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- **contentApi.streamingServices.edit** 권한이 필요합니다. 액세스 권한이 없으면 [역할 및 권한](../settings/roles-permissions.md)을 참조하세요.
- 설교를 가져올 [재생 목록](playlists)을 최소 하나 이상 만듭니다
- YouTube 채널 ID 또는 Vimeo 계정 정보를 준비합니다

</div>

## 원본 선택

1. B1 Admin에서 왼쪽 상단 모서리의 **섹션 메뉴**(작은 화살표가 있는 섹션 이름)를 열고 **설교**를 선택합니다. **설교 추가**를 클릭하고 메뉴에서 **대량 가져오기**를 선택합니다.
2. 클릭 가능한 두 개의 카드가 표시됩니다:
   - **YouTube** (빨강) -- YouTube 채널에서 비디오 가져오기
   - **Vimeo** (파랑) -- Vimeo 계정에서 비디오 가져오기
3. 설교가 호스팅되는 플랫폼의 카드를 클릭합니다.

:::tip
두 플랫폼에 비디오가 있는 경우 언제든지 돌아가서 원본을 전환할 수 있습니다.
:::

## 가져오기 전에

비디오를 가져오기 전에 비디오를 구성할 재생 목록이 최소 하나 이상 필요합니다. 아직 재생 목록을 만들지 않은 경우:

1. **재생 목록** 탭을 클릭합니다.
2. **첫 번째 재생 목록 만들기**를 클릭하고 이름, 설명, 게시 날짜 및 썸네일을 입력합니다.
3. **저장**을 클릭한 후 **대량 가져오기** 탭으로 돌아갑니다.

재생 목록 만들기 및 관리에 대한 자세한 지침은 [재생 목록](playlists)을 참조하세요.

## 비디오 가져오기

1. YouTube 또는 Vimeo를 선택한 후 제공된 필드에 **YouTube 채널 ID** 또는 **Vimeo 계정 정보**를 입력합니다.
2. **가져오기** 버튼을 클릭하여 채널 또는 계정에서 사용 가능한 모든 비디오를 검색합니다.
3. 가져온 후 체크박스가 있는 모든 비디오 목록이 표시됩니다.
4. 가져올 비디오 옆에 있는 상자를 선택합니다. 모두 선택하거나 특정 항목을 선택할 수 있습니다.
5. 선택적으로 **새 비디오 자동 가져오기**를 활성화하여 향후 업로드를 라이브러리에 자동으로 추가합니다.
6. **재생 목록으로 가져오기** 드롭다운을 클릭하여 이 비디오를 추가할 재생 목록을 선택합니다.
7. **가져오기** 버튼을 클릭하여 대량 가져오기를 완료합니다.

비디오는 제목, 설명, 날짜 및 썸네일을 포함한 모든 세부 정보와 함께 가져오게 됩니다.

:::info
대량 가져오기는 다른 플랫폼에서 마이그레이션할 때 시작하는 데 이상적입니다. 앞으로 개별 설교를 추가하려면 대신 [설교 관리](managing-sermons) 페이지를 사용하세요.
:::
