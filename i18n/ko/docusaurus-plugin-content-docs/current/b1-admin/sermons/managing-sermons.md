# 설교 관리

<div class="article-intro">

설교 페이지는 전체 설교 라이브러리를 표시합니다. 여기에서 새 설교를 추가하고, 기존 항목을 편집하고, 플레이리스트로 콘텐츠를 구성할 수 있습니다. 각 설교는 YouTube, Vimeo, Facebook 또는 사용자 정의 URL에서 호스팅되는 비디오 또는 오디오에 연결될 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- **contentApi.streamingServices.edit** 권한이 필요합니다. 액세스 권한이 없으면 [역할 및 권한](../settings/roles-permissions.md) 참조.
- 설교를 구성하려면 [플레이리스트](playlists) 최소 1개 생성
- YouTube, Vimeo 또는 Facebook의 비디오 ID 또는 URL 준비

</div>

## 설교 라이브러리 보기

1. B1 Admin에서 왼쪽 위 모서리의 **섹션 메뉴**(섹션 이름과 작은 화살표)를 열고 **설교**를 선택합니다.
2. 설교 페이지는 플레이리스트별로 구성된 모든 설교 항목을 표시합니다. 각 설교는 썸네일, 제목 및 날짜를 표시합니다.
3. 세부 정보를 보거나 편집하려면 아무 설교를 클릭합니다.

## 설교 추가

1. 오른쪽 위 모서리의 **설교 추가** 버튼을 클릭하고 드롭다운에서 **설교 추가**를 선택합니다.
2. 설교를 할당할 **플레이리스트**를 선택합니다.
3. **비디오 공급자**를 선택합니다. YouTube, Vimeo, Facebook 또는 사용자 정의 URL입니다. YouTube를 권장합니다. B1 시스템과 가장 잘 작동합니다.
4. 비디오 ID 또는 URL을 입력하고 **가져오기**를 클릭합니다. YouTube의 경우 비디오 ID는 YouTube URL에서 `v=` 뒤의 문자 문자열입니다.
5. **가져오기**를 클릭하면 게시 날짜, 지속 시간, 제목, 설명 및 썸네일을 포함한 설교 세부 정보가 자동으로 가져옵니다.
6. 원하는 변경 사항을 하고 **저장**을 클릭합니다.

:::tip
**설교 추가** 드롭다운에서 **영구 라이브 URL 추가**를 선택하여 영구 라이브 스트림 URL을 추가할 수도 있습니다. 이는 채널 ID를 사용하여 YouTube 채널의 라이브 스트림에 대한 지속적인 연결을 만듭니다. 자세한 내용은 [라이브 스트리밍](live-streaming) 참조.
:::

## 설교 편집

1. 라이브러리의 아무 설교를 클릭하여 세부 정보를 엽니다.
2. 필요에 따라 제목, 연설자, 날짜, 설명, 썸네일 또는 미디어 링크를 업데이트합니다.
3. **저장**을 클릭하여 변경 사항을 적용합니다.

## 설교 세부 정보

각 설교 항목에는 다음이 포함될 수 있습니다:

- **제목** -- 방문자에게 표시되는 설교 이름
- **연설자** -- 설교를 전달한 사람
- **날짜** -- 게시 또는 전달 날짜
- **설명** -- 설교 콘텐츠의 요약
- **썸네일** -- 설교 라이브러리에 표시되는 미리보기 이미지
- **비디오/오디오 링크** -- YouTube, Vimeo, Facebook 또는 사용자 정의 호스트의 설교 미디어에 대한 URL

## 라이브 스트림을 위해 설교 예정

설교를 추가한 후 라이브 스트림 페이지에서 방송하도록 예정할 수 있습니다:

1. **라이브 스트림 시간** 탭으로 이동합니다.
2. 예배를 편집하고 **비디오 설정** 아래에서 드롭다운에서 설교를 선택합니다.
3. 설교는 예정된 예배 시간에 재생됩니다.

:::info
대신 여러 설교를 한 번에 추가하려면 [일괄 가져오기](bulk-import) 도구를 사용하여 YouTube 또는 Vimeo 계정에서 비디오를 직접 가져옵니다.
:::
