# 설교 관리

<div class="article-intro">

설교 페이지는 전체 설교 라이브러리를 표시합니다. 여기서 새로운 설교를 추가하고, 기존 항목을 편집하며, 재생 목록별로 콘텐츠를 구성할 수 있습니다. 각 설교는 YouTube, Vimeo, Facebook 또는 사용자 정의 URL에서 호스팅되는 비디오 또는 오디오에 연결될 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- **contentApi.streamingServices.edit** 권한이 필요합니다. 액세스 권한이 없으시면 [역할 및 권한](../settings/roles-permissions.md)을 참조하세요.
- 설교를 구성할 [재생 목록](playlists)을 하나 이상 만드세요
- YouTube, Vimeo 또는 Facebook에서 비디오 ID 또는 URL을 준비하세요

</div>

## 설교 라이브러리 보기

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(좌상단의 검색 표시줄)를 열고 **설교**를 확장한 다음 **설교**를 클릭하세요.
2. 설교 페이지는 모든 설교 항목을 재생 목록별로 구성하여 표시합니다. 각 설교는 썸네일, 제목 및 날짜를 표시합니다.
3. 모든 설교를 클릭하여 세부 정보를 보거나 편집하세요.

## 설교 추가

1. 우상단의 **설교 추가** 버튼을 클릭하고 드롭다운에서 **설교 추가**를 선택하세요.
2. 설교를 할당할 **재생 목록**을 선택하세요.
3. **비디오 제공자**를 선택하세요 -- YouTube, Vimeo, Facebook 또는 사용자 정의 URL. B1 시스템에서 가장 잘 작동하므로 YouTube를 권장합니다.
4. 비디오 ID 또는 URL을 입력하고 **가져오기**를 클릭하세요. YouTube의 경우 비디오 ID는 YouTube URL의 `v=` 뒤의 문자 문자열입니다.
5. **가져오기**를 클릭하면 게시 날짜, 기간, 제목, 설명 및 썸네일을 포함한 설교 세부 정보가 자동으로 가져와집니다.
6. 원하는 대로 변경하고 **저장**을 클릭하세요.

:::tip
**설교 추가** 드롭다운에서 **영구 실시간 URL 추가**를 선택하여 영구 실시간 스트림 URL을 추가할 수도 있습니다. 이렇게 하면 채널 ID를 사용하여 YouTube 채널의 실시간 스트림에 대한 지속적인 연결이 생성됩니다. 자세한 내용은 [실시간 스트리밍](live-streaming)을 참조하세요.
:::

## 설교 편집

1. 라이브러리의 모든 설교를 클릭하여 세부 정보를 열어보세요.
2. 필요에 따라 제목, 스피커, 날짜, 설명, 썸네일 또는 미디어 링크를 업데이트하세요.
3. **저장**을 클릭하여 변경 사항을 적용하세요.

## 설교 세부 정보

각 설교 항목에는 다음이 포함될 수 있습니다:

- **제목** -- 방문자에게 표시되는 설교 이름
- **스피커** -- 설교를 전달한 사람
- **날짜** -- 게시 또는 전달 날짜
- **설명** -- 설교 내용 요약
- **썸네일** -- 설교 라이브러리에 표시되는 미리보기 이미지
- **비디오/오디오 링크** -- YouTube, Vimeo, Facebook 또는 사용자 정의 호스트의 설교 미디어에 대한 URL
- **오디오 파일 URL(팟캐스트용)** -- 이 설교의 MP3/M4A 파일에 대한 직접 링크입니다. URL을 붙여넣거나 **오디오 업로드**를 클릭하여 파일을 업로드하고 자동으로 채우세요. 이 필드(또는 직접 비디오 파일 링크)가 설정된 설교만 팟캐스트 피드에 포함됩니다.

## 팟캐스트 피드

최소한 하나의 설교에 오디오 또는 비디오 파일이 첨부되면 B1 Admin은 교회를 위한 팟캐스트 RSS 피드를 자동으로 생성합니다 -- 켜야 할 것이 없습니다. 설교 목록 아래 **팟캐스트 피드** 패널에서 찾아보세요. 복사 아이콘을 클릭하여 피드 URL을 복사한 다음 해당 URL을 Apple Podcasts, Spotify 또는 다른 팟캐스트 디렉토리에 제출하세요.

:::info
포함된 플레이어(예: YouTube 또는 Vimeo 비디오 ID)에만 링크하는 설교는 팟캐스트 피드에 나타나지 않습니다 -- 팟캐스트 앱은 직접적이고 다운로드 가능한 미디어 파일이 필요합니다. 설교를 포함시키려면 **오디오 파일 URL**을 추가하세요.
:::

## 실시간 스트림을 위한 설교 일정 계획

설교를 추가한 후 라이브 스트림 페이지에서 방송 일정을 계획할 수 있습니다:

1. Jump 메뉴에서 **설교 > 실시간 스트림 시간**을 선택하세요.
2. 서비스를 편집하고 **비디오 설정** 아래에서 드롭다운에서 설교를 선택하세요.
3. 설교는 예정된 서비스 시간에 재생됩니다.

:::info
하나씩 추가하는 대신 여러 설교를 한 번에 가져오려면 [대량 가져오기](bulk-import) 도구를 사용하여 YouTube 또는 Vimeo 계정에서 비디오를 직접 가져오세요.
:::
