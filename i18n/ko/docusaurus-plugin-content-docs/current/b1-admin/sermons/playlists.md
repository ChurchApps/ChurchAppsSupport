# 플레이리스트

<div class="article-intro">

플레이리스트를 통해 설교를 시리즈 또는 컬렉션으로 구성할 수 있습니다. 방문자가 B1.church 웹사이트의 설교 라이브러리를 탐색할 때 플레이리스트는 전체 설교 시리즈를 올바른 순서로 찾고 따라가도록 도움을 줍니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- **contentApi.streamingServices.edit** 권한이 필요합니다. 액세스 권한이 없으면 [역할 및 권한](../settings/roles-permissions.md) 참조.
- 플레이리스트를 위한 이름, 설명 및 썸네일 이미지 준비

</div>

## 플레이리스트 보기

1. B1 Admin에서 왼쪽 위 모서리의 **섹션 메뉴**(섹션 이름과 작은 화살표)를 열고 **설교**를 선택합니다.
2. 페이지 상단의 **플레이리스트** 탭을 클릭합니다.
3. 이름과 설명이 있는 기존 플레이리스트 목록이 표시됩니다.

## 플레이리스트 생성

1. **첫 번째 플레이리스트 생성** 버튼을 클릭합니다(플레이리스트가 없을 경우) 또는 **플레이리스트 추가**를 클릭합니다.
2. 플레이리스트의 **이름** 입력 -- 예: "신앙 재단" 또는 "시편의 여름"과 같은 설교 시리즈 제목.
3. **설명** 추가 -- 방문자에게 시리즈의 간단한 개요를 제공합니다.
4. **게시 날짜** 설정 -- 플레이리스트가 표시될 시기를 제어합니다.
5. **썸네일 이미지** 업로드 -- 시리즈를 시각적으로 나타냅니다.
6. **저장**을 클릭하여 플레이리스트를 생성합니다.

:::tip
설교를 추가하기 전에 플레이리스트를 만드세요. 이렇게 하면 나중에 재구성하는 대신 진행하면서 각 설교를 올바른 플레이리스트에 할당할 수 있습니다.
:::

## 플레이리스트에 설교 추가

[설교를 추가하거나 편집](managing-sermons)할 때 **플레이리스트** 드롭다운을 사용하여 설교를 플레이리스트에 할당합니다. 동일한 플레이리스트에 할당된 모든 설교는 함께 그룹화되어 웹사이트에 순서대로 표시됩니다.

:::info
[일괄 가져오기](bulk-import)를 수행할 때도 설교를 플레이리스트에 할당할 수 있습니다. YouTube 또는 Vimeo에서 가져올 때 **가져오기**를 클릭하기 전에 **플레이리스트로 가져오기** 드롭다운에서 플레이리스트를 선택합니다.
:::

## 플레이리스트가 웹사이트에 표시되는 방식

플레이리스트는 B1.church 웹사이트에 검색 가능한 컬렉션으로 표시됩니다. 방문자는 다음을 할 수 있습니다:

- 한눈에 사용 가능한 모든 설교 시리즈 보기
- 플레이리스트에 클릭하여 해당 시리즈의 모든 설교 보기
- 순서대로 설교를 보거나 듣기
