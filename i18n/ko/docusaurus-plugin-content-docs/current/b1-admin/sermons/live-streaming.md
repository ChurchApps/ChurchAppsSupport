# 라이브 스트리밍

<div class="article-intro">

Live Stream Times 페이지에서 교회의 스트리밍 일정을 설정하고, 예배 시간을 관리하며, 시청자 경험을 맞춤 설정할 수 있습니다. 주간 정기 예배나 일회성 행사를 설정하고, 채팅과 영상 옵션을 구성하며, 스트림이 언제 시작되는지 제어할 수 있습니다.

</div>

## 교육 동영상

<div class="prereqs">
<h4>시작하기 전에</h4>

- **contentApi.streamingServices.edit** 권한이 필요합니다. 접근 권한이 없다면 [역할 및 권한](../settings/roles-permissions.md)을 참고하세요.
- 자동 라이브 스트리밍을 사용할 계획이라면 YouTube 채널 ID를 준비하세요.
- 스트림 원본으로 사용할 [설교](managing-sermons) 또는 영구 라이브 URL을 하나 이상 추가하세요.

</div>

라이브 스트리밍은 점프 메뉴의 **Sermons** 섹션에 있는 두 페이지에서 관리합니다. 라이브 스트림 일정은 **Live Stream Times**에서, 스트리밍 페이지의 탭은 **Settings**에서 설정합니다.

## 예배 관리하기

### 예배 추가하기

1. B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 위의 검색창)를 열고 **Sermons**를 펼친 다음 **Live Stream Times**를 클릭하세요.
2. 페이지 위의 **Add Service** 버튼을 클릭해 새 예약 예배를 만드세요. 기존 예배는 이름, 시간, 제공업체, 길이가 나열된 표로 표시됩니다. 행의 편집 아이콘을 클릭하면 바꿀 수 있습니다.
3. **Service Name**을 입력하세요(예: "Sunday Morning").
4. **Service Time**을 설정하세요. 예배가 시작되는 요일과 시간을 고릅니다.
5. 정기 주간 예배라면 **Recurs Weekly**를 **Yes**로, 일회성 행사라면 **No**로 설정하세요.

### 채팅과 영상 설정하기

6. **Chat Settings**에서 예배 전후 몇 분 동안 채팅을 켤지 설정하세요. 방문자가 예배 전에 채팅을 시작하고, 예배가 끝난 뒤에도 계속 대화할 수 있습니다.
7. **Video Settings**에서 카운트다운이나 예배 전 콘텐츠를 위해 영상 스트림을 몇 분 일찍 시작할지 설정하세요. 채팅은 이 일찍 시작하는 영상보다 *몇 분 전에* 열립니다. 따라서 채팅의 "분 전" 설정 옆에 표시되는 시간은 두 숫자를 모두 합산합니다. 예를 들어 오전 10시 예배에서 채팅을 15분 전에 열고 영상을 5분 일찍 시작하면, 채팅은 오전 9시 40분에 열립니다.
8. 드롭다운에서 재생할 설교를 고르세요.
   - **Latest Sermon** -- 가장 최근에 추가한 영상을 자동으로 재생합니다.
   - **Current Live Service** -- 채널 ID를 사용해 YouTube의 현재 라이브 스트림을 재생합니다.
   - 이미 저장해 둔 특정 설교를 고를 수도 있습니다.
9. **Save**를 클릭해 예배를 예약하세요.

:::info
정기 예배로 설정하면 매주 자동으로 갱신됩니다. 일광 절약 시간이 시작되거나 끝나도 현지 시간은 그대로 유지됩니다. 예배는 필요한 만큼 추가할 수 있습니다. 방문자가 스트리밍 페이지에 들어오면 다음 예배 시간이 표시됩니다.
:::

## 송출 페이지 설정

라이브 스트림 옆에 나타나는 탭과 링크를 바꾸려면, 점프 메뉴에서 **Sermons**를 펼치고 **Settings**를 클릭하세요. **Stream Settings** 페이지에 **Content Tabs** 목록이 표시됩니다.

### 탭 추가하기

1. **Add** 버튼을 클릭해 라이브 스트림 페이지에 새 탭을 추가하세요.
2. **Link Type**을 고르세요. 사용자 지정 링크는 **External URL**을, 미리 디자인된 **Chat** 또는 **Prayer** 탭은 해당 항목을 고르세요.
3. Chat 탭이라면 **Tab Text** 상자에 이름만 입력하면 설정이 끝납니다.
4. 링크 탭이라면 탭 이름을 입력하고, 아이콘 버튼을 클릭해 아이콘을 고른 다음, URL을 입력하세요.
5. 설정한 탭이 라이브 스트리밍 페이지에 나타나, 시청자가 추가 자료와 대화형 기능을 이용할 수 있습니다.

### 송출 미리 보기

**Live Stream Times** 페이지 위의 **View Your Stream**을 클릭하면, 방문자에게 라이브 스트리밍 페이지가 어떻게 보이는지 로고, 예배 시간, 설정한 탭까지 그대로 확인할 수 있습니다.

## YouTube 생방송 설정하기

YouTube 채널을 자동 라이브 스트리밍에 연결하려면 다음과 같이 하세요.

1. **Sermons**로 가서 **Add Sermon**을 클릭한 다음 **Add Permanent Live URL**을 선택하세요.
2. 영상 제공업체는 기본값으로 **Current YouTube Live Stream**이 선택됩니다. **YouTube Channel ID**를 입력하세요.
3. 제목과 설명을 추가한 다음 **Save**를 클릭하세요.
4. **Live Stream Times**에서 예배를 만들고, 설교 드롭다운에서 영구 라이브 URL을 고르세요.

:::tip
YouTube 채널 ID를 찾으려면 YouTube 채널의 고급 설정으로 가서 Channel ID 값을 복사하세요.
:::

## 색상과 로고 꾸미기

라이브 스트리밍 페이지는 웹사이트의 [Appearance](../website/appearance) 설정을 사용합니다.

- **밝은 강조 색상과 어두운 글자**는 머리글에 사용됩니다.
- **어두운 강조 색상과 밝은 글자**는 사이드바에 사용됩니다.
- **Light Background Logo**(밝은 배경용 로고)가 스트리밍 페이지에 나타납니다. 배경이 투명하고 가로세로 비율이 4:1인 이미지를 사용하세요.

이 설정을 바꾸려면 **Website**, **Appearance**로 이동해 [색상 팔레트](../website/appearance#color-palette)와 [로고](../website/appearance#logo-and-branding) 설정을 업데이트하세요.

## 생방송 진행자 추가하기

팀원에게 공개 채팅과 함께 진행자 전용 채팅을 쓸 수 있는 권한을 주려면 다음과 같이 하세요.

1. 점프 메뉴에서 **Settings > Roles**를 선택하세요.
2. 플러스 버튼을 클릭하고 **Add Custom Role**을 선택하세요.
3. 역할 이름을 "Streaming Host"로 지정하고 **Save**를 클릭하세요.
4. 새 역할을 클릭한 다음 Members 섹션의 **Add**를 클릭해 사람을 추가하세요.
5. 아래로 스크롤해 **Edit Permissions**에서 **Content** 섹션을 펼치고 **Host Chat**을 선택하세요.

진행자가 라이브 스트림 페이지에 로그인하면, 방송 중 교회 직원끼리만 대화할 수 있는 비공개 **Host Chat** 탭이 공개 채팅 옆에 나타납니다.

:::info
역할을 만들고 권한을 관리하는 자세한 방법은 [역할 및 권한](../settings/roles-permissions.md)을 참고하세요.
:::

## 문제 해결

"Current YouTube Live Stream" 옵션과 채널 ID를 사용하는 자동 YouTube 라이브 스트림이 올바르게 표시되지 않는다면 다음을 시도해 보세요.

**증상:**
- 라이브 스트림 삽입 영역에 "Video unavailable"이 표시됩니다.
- 페이지는 열리지만 영상이 나타나지 않습니다.
- 직접 넣은 YouTube 삽입은 작동하지만, 채널 자동 라이브 스트림은 작동하지 않습니다.

**해결 방법:**
YouTube 채널에서 오래된 라이브 스트림이나 예정된 라이브 스트림이 있는지 확인하고 삭제하세요.

1. YouTube Studio로 이동하세요.
2. **Content**, 그다음 **Live**로 이동하세요.
3. 오래된 예약 라이브나 예정된 스트림이 있는지 찾으세요.
4. 이 오래된 항목이나 예정된 라이브 스트림 항목을 삭제하세요.
5. 라이브 스트림 페이지를 다시 테스트하세요.

:::warning
채널에 예약되었거나 지난 라이브 스트림 항목이 여러 개 있으면, YouTube의 자동 채널 라이브 스트림 삽입이 차단될 수 있습니다. 이 항목들을 지우면 YouTube가 현재 라이브 스트림을 올바르게 식별해 제공할 수 있습니다.
:::

**추가 요구 사항:**
- 라이브 스트림은 **Public**(공개)으로 설정해야 합니다(Unlisted나 Private이 아니어야 합니다).
- YouTube 스트림 설정에서 삽입이 허용되어 있어야 합니다.
- **YouTube** 제공업체(영상 ID 사용)가 아니라 **Current YouTube Live Stream** 제공업체(채널 ID 사용)를 사용하고 있어야 합니다.
