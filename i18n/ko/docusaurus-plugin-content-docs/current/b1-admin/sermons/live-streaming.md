# 라이브 스트리밍

<div class="article-intro">

라이브 스트림 시간 페이지를 통해 교회의 스트리밍 일정을 구성하고, 예배 시간을 관리하고, 시청자 경험을 사용자 정의할 수 있습니다. 정기적인 주간 예배나 일회성 이벤트를 설정하고, 채팅 및 비디오 설정을 구성하며, 스트림이 라이브로 전환되는 시기를 제어합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- **contentApi.streamingServices.edit** 권한이 필요합니다. 액세스 권한이 없으면 [역할 및 권한](../settings/roles-permissions.md) 참조.
- 자동 라이브 스트리밍을 사용할 계획이면 YouTube 채널 ID 준비
- 스트림 원본으로 사용할 [설교](managing-sermons) 또는 영구 라이브 URL 최소 1개 추가

</div>

페이지에는 두 개의 주요 탭이 있습니다: 라이브 스트림 일정을 관리하는 **예배** 및 스트리밍 페이지를 구성하는 **설정**.

## 예배 관리

### 예배 추가

1. B1 Admin에서 왼쪽 위 모서리의 **섹션 메뉴**(섹션 이름과 작은 화살표)를 열고 **설교**를 선택한 후 **라이브 스트림 시간** 탭을 클릭합니다.
2. **예배 추가** 버튼을 클릭하여 새 예정된 예배를 만듭니다.
3. **예배 이름**(예: "일요일 아침")을 입력합니다.
4. **예배 시간**을 설정합니다. 예배가 시작되는 요일과 시간을 선택합니다.
5. **매주 반복**을 **예**로 설정하여 정기적인 주간 예배를 하거나 **아니오**를 선택하여 일회성 이벤트로 합니다.

### 채팅 및 비디오 설정 구성

6. **채팅 설정** 아래에서 채팅을 활성화해야 할 예배 전후 시간(분)을 설정합니다. 이를 통해 방문자는 예배 시작 전에 채팅을 시작하고 이후에 계속할 수 있습니다.
7. **비디오 설정** 아래에서 카운트다운 또는 사전 예배 콘텐츠를 위해 비디오 스트림을 시작할 시간을 설정합니다.
8. 드롭다운에서 재생할 설교를 선택합니다:
   - **최신 설교** -- 자동으로 가장 최근에 추가한 비디오를 재생합니다.
   - **현재 라이브 예배** -- 채널 ID를 사용하여 YouTube에서 현재 라이브 스트림을 재생합니다.
   - 이미 저장한 특정 설교를 선택할 수도 있습니다.
9. **저장**을 클릭하여 예배를 예정합니다.

:::info
설정하면 반복되도록 서비스가 자동으로 매주 업데이트됩니다. 필요한 만큼 많은 예배를 추가할 수 있습니다. 방문자는 스트리밍 페이지를 방문할 때 다음 예정된 예배 시간을 보게 됩니다.
:::

## 스트리밍 페이지 설정

**설정** 탭을 클릭하여 라이브 스트림과 함께 표시되는 탭 및 링크를 사용자 정의합니다.

### 탭 추가

1. **추가** 버튼을 클릭하여 라이브 스트림 페이지에 새 탭을 추가합니다.
2. **채팅** 미리 설계된 탭을 선택하거나 외부 URL을 포함한 사용자 정의 탭을 추가합니다.
3. 채팅 탭의 경우 **탭 텍스트** 상자에 이름을 지정하기만 하면 설정이 완료됩니다.
4. 링크된 탭의 경우 탭 이름을 입력하고 아이콘 버튼을 클릭하여 아이콘을 선택한 후 URL을 입력합니다.
5. 구성된 탭이 라이브 스트리밍 페이지에 표시되어 방문자가 추가 리소스 및 대화형 기능에 액세스할 수 있습니다.

### 스트림 미리보기

**스트림 보기** 버튼을 클릭하여 방문자에게 라이브 스트리밍 페이지가 정확히 어떻게 보이는지 확인합니다. 로고, 예배 시간 및 구성된 탭을 포함합니다.

## YouTube 라이브 스트림 설정

자동 라이브 스트리밍을 위해 YouTube 채널을 연결하려면:

1. **설교**로 이동하고 **설교 추가**를 클릭한 후 **영구 라이브 URL 추가**를 선택합니다.
2. 비디오 공급자는 기본값이 **현재 YouTube 라이브 스트림**입니다. **YouTube 채널 ID**를 입력합니다.
3. 제목과 설명을 추가한 후 **저장**을 클릭합니다.
4. **라이브 스트림 시간**에서 예배를 만들고 설교 드롭다운에서 영구 라이브 URL을 선택합니다.

:::tip
YouTube 채널 ID를 찾으려면 YouTube 채널의 고급 설정으로 이동하여 채널 ID 값을 복사합니다.
:::

## 색상 및 로고 사용자 정의

라이브 스트림 페이지는 웹사이트의 [모양](../website/appearance) 설정을 사용합니다:

- **밝은 악센트 색상**과 어두운 텍스트는 헤더에 사용됩니다.
- **어두운 악센트 색상**과 밝은 텍스트는 사이드바에 사용됩니다.
- **밝은 배경 로고**가 스트리밍 페이지에 표시됩니다. 투명한 배경이 있고 4:1 종횡비인 이미지를 사용합니다.

이를 변경하려면 **웹사이트**로 이동한 후 **모양**을 선택하고 [색상 팔레트](../website/appearance#color-palette) 및 [로고](../website/appearance#logo-and-branding) 설정을 업데이트합니다.

## 스트리밍 호스트 추가

팀 구성원이 공개 채팅과 함께 호스트 전용 채팅에 액세스할 수 있도록 하려면:

1. 왼쪽 위 모서리의 **섹션 메뉴**(섹션 이름과 작은 화살표)를 열고 **설정**을 선택한 후 **역할**을 클릭합니다.
2. 더하기 버튼을 클릭하고 **사용자 정의 역할 추가**를 선택합니다.
3. 역할의 이름을 "스트리밍 호스트"로 지정하고 **저장**을 클릭합니다.
4. 새 역할을 클릭한 후 회원 섹션에서 **추가**를 클릭하여 사람을 추가합니다.
5. **권한 편집**으로 스크롤한 후 **콘텐츠** 섹션을 확장하고 **호스트 채팅**을 선택합니다.

호스트가 라이브 스트림 페이지에 로그인할 때 공개 채팅과 함께 직원 전용 대화를 위한 비공개 **호스트 채팅** 탭이 나타납니다.

:::info
역할 생성 및 권한 관리에 대한 자세한 내용은 [역할 및 권한](../settings/roles-permissions.md) 참조.
:::

## 문제 해결

"현재 YouTube 라이브 스트림" 옵션을 채널 ID와 함께 사용할 때 자동화된 YouTube 라이브 스트림이 올바르게 표시되지 않으면 다음을 시도하세요:

**증상:**
- 라이브 스트림 임베드는 "동영상을 사용할 수 없음"을 표시합니다
- 페이지가 로드되지만 비디오가 표시되지 않습니다
- 직접 YouTube 임베드는 작동하지만 자동화된 채널 라이브 스트림은 작동하지 않습니다

**솔루션:**
YouTube 채널에서 오래된 또는 예정된 라이브 스트림을 확인하고 삭제합니다:

1. YouTube 스튜디오로 이동합니다.
2. **콘텐츠**로 이동한 후 **라이브**를 선택합니다.
3. 오래된 예정된 라이브 또는 예정된 스트림을 찾습니다.
4. 이 오래된 또는 예정된 라이브 스트림 항목을 삭제합니다.
5. 라이브 스트림 페이지를 다시 테스트합니다.

:::warning
YouTube의 자동화된 채널 라이브 스트림 임베드는 채널에 여러 개의 예정된 또는 과거 라이브 스트림 항목이 있을 때 차단될 수 있습니다. 이를 제거하면 YouTube가 현재 라이브 스트림을 올바르게 식별하고 제공할 수 있습니다.
:::

**추가 요구사항:**
- 라이브 스트림이 **공개**(비공개 또는 비공개 아님)로 설정되어야 합니다.
- YouTube 스트림 설정에서 임베딩을 허용해야 합니다.
- 비디오 ID가 아닌 **현재 YouTube 라이브 스트림** 공급자(채널 ID 포함)를 사용하고 있는지 확인하세요.
