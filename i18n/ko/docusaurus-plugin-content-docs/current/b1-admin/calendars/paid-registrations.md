# 유료 등록

<div class="article-intro">

이벤트 등록은 단순한 인원 집계를 넘어설 수 있습니다. 가격이 있는 참석자 유형(예: 성인과 어린이)을 정의하고, 각자 가격과 수량이 있는 선택 추가 항목을 제공하며, 할인 코드를 만들고, 등록 시점에 교회의 기존 헌금 제공업체를 통해 결제를 받을 수 있습니다. 이벤트가 정원을 넘으면 선택 사항인 대기자 명단이 관심 있는 구성원을 순서대로 세워 두었다가 자리가 날 때 자동으로 등록시켜 줍니다.

</div>

## 등록 설정 열기

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **달력 > 등록**을 선택한 다음 이벤트를 엽니다(또는 달력에서 이벤트를 엽니다).
2. **등록 설정** 카드에 기본 항목인 **등록 켜기**, **정원**, **등록 시작/마감**, **태그**, **등록 질문**이 표시됩니다.
3. 기본 항목 아래에는 세 개의 접이식 항목이 있습니다. **참석자 유형**, **선택 항목**, **할인 코드**입니다.

## 참석자 유형

참석자 유형을 쓰면 참석자 종류에 따라 다른 가격을 매기고, 각 유형의 인원을 따로 제한할 수 있습니다.

1. **참석자 유형** 항목을 펼치고 **유형 추가**를 클릭합니다.
2. **이름**을 입력합니다(예: "성인", "어린이", "학생").
3. **가격**을 설정합니다. 무료 유형이라면 0을 입력하세요.
4. 이 유형에만 적용되는 **정원**을 선택 사항으로 설정할 수 있습니다(예: 어린이 자리 20석만). 유형별 제한이 필요 없으면 비워 두세요.
5. **저장**을 클릭합니다.

등록 중에는 각 참석자가 유형을 고릅니다. 매진된 유형은 **매진**으로 표시되며 선택할 수 없습니다. 명단에는 각 참석자의 유형과 유형별 누적 인원이 표시됩니다.

## 선택 항목

선택 항목은 티셔츠, 식사 옵션, 활동 업그레이드처럼 선택 사항으로 추가 구매할 수 있는 유료 항목입니다.

1. **선택 항목** 항목을 펼치고 **선택 항목 추가**를 클릭합니다.
2. **이름**, 선택 사항인 **설명**, **가격**을 입력합니다(0은 "무료"로 표시됩니다).
3. 선택 사항으로 **정원**(모든 등록을 합한 전체 수량)과 **최대 수량**(한 번의 등록으로 주문할 수 있는 최대 개수)을 설정할 수 있습니다.
4. **저장**을 클릭합니다.

등록자는 신청하면서 수량을 고르며, 합계는 정원에 포함되므로 초과 판매되지 않습니다.

## 할인 코드

1. **할인 코드** 항목을 펼치고 **할인 코드 추가**를 클릭합니다.
2. 등록자가 입력할 **코드**를 입력합니다.
3. **유형**(**비율** 또는 **금액**)과 그 **값**을 선택합니다.
4. 선택 사항으로 **시작일** / **종료일**, **최소 인원**(등록에 포함되어야 하는 최소 참석자 수), **최대 사용 횟수**로 코드를 제한할 수 있습니다.
5. **저장**을 클릭합니다.

각 코드에는 **사용** 횟수가 표시되어 얼마나 자주 사용되었는지 확인할 수 있습니다. 등록자가 코드를 적용하면 즉시 결과를 알 수 있으며, 코드가 만료되었거나, 아직 시작되지 않았거나, 참석자가 더 필요하다면 그 이유도 분명하게 안내됩니다.

## 대기자 명단 {#waitlist}

등록 설정 카드에서 **대기자 명단 사용**을 켜세요. 이벤트가 정원에 도달하면 다음과 같이 동작합니다.

- 새 등록자는 거절되는 대신 대기자 명단에 들어갈 수 있습니다. 같은 방식으로 신청을 마치되, 대기 중에는 결제가 건너뛰어집니다.
- 누군가 취소하면, 가장 오래 기다린 대기자 등록이 **자동으로 승격**되어 자리가 났다는 이메일을 받습니다. 결제할 잔액이 있다면 이메일에 교회의 B1 웹사이트에 있는 [내 등록](../../b1-church/events/my-registrations.md) 링크가 포함되어, 그곳에서 결제를 완료할 수 있습니다.
- 대기자 행의 **승격** 기능을 쓰면 언제든 수동으로 승격할 수 있습니다. 이벤트 정원을 늘린 뒤 유용합니다.

:::info
승격된 등록은 잔액이 결제될 때까지 **대기 중** 상태로 남습니다. 결제가 완료되거나 결제할 금액이 없으면 확정됩니다.
:::

## 등록 명단 {#the-registration-roster}

등록 페이지에서 이벤트를 열면 모든 등록을 볼 수 있습니다. 카드 제목에는 정원 대비 자리를 차지한 등록 수가 표시됩니다(예: *등록 (18 / 20)*). 대기 중이거나 확정된 등록만 포함됩니다. 대기자가 있으면 제목에 그 수가 더해지고(예: *· 대기자 3명*), 같은 수가 정원 막대 아래에도 표시됩니다. 정원 막대 위의 큰 숫자는 등록 수가 아니라 **사람 수**를 셉니다. 대기 중이거나 확정된 각 등록에 속한 모든 사람을 세므로, 네 명인 가족은 네 명으로 계산됩니다. 다만 정원 제한 자체는 여전히 등록 수를 기준으로 합니다. 표에는 **이름**, **구성원**, **유형**(각 참석자의 유형), **지불 / 합계**(아직 받지 못한 금액이 있으면 잔액 경고 표시), **상태**, **날짜**가 나오며, 표 위에는 유형별 인원 칩이 있습니다.

- 행의 세부 정보 아이콘을 클릭하면 **등록 상세** 대화 상자가 열립니다. 구성원, 선택 항목, 지불 / 잔액, 그리고 모든 청구 내역(금액, 방법, 날짜)을 보여 주는 **결제** 표가 있습니다.
- **CSV 내보내기**는 구성원, 참석자 유형, 선택 항목, 지불 / 합계 / 잔액, 상태, 그리고 등록 질문마다 하나씩의 열을 포함한 전체 명단을 내려받습니다.
- **참석자 추가**는 교회의 누구에게든 오프라인이나 전화로 받은 신청을 기록합니다. 사람을 고르고, 유료 이벤트라면 참석자 유형도 고릅니다. 이때 카드 결제는 이루어지지 않습니다. 유료 등록은 전체 금액이 잔액으로 남은 **대기 중** 상태로 저장됩니다. 교회에 온라인 헌금이 있다면 그 사람이 [내 등록](../../b1-church/events/my-registrations.md)에서 결제할 수 있고, 없다면 직접 받아야 합니다. 참석자를 추가하려면 등록 편집 권한이 필요합니다.

:::info
B1에서는 환불이 처리되지 않습니다. 취소된 유료 등록을 환불해야 한다면, 헌금 제공업체의 대시보드(예: Stripe)에서 환불하세요.
:::

## 결제 방식

결제는 교회가 이미 헌금에 사용하는 것과 같은 헌금 게이트웨이를 통해 이루어집니다. 카드 정보는 제공업체로 직접 전달되며 B1 서버에는 저장되지 않습니다. 가격은 항상 서버에서 설정된 유형, 선택 항목, 할인 코드를 바탕으로 계산되므로 등록자가 총액을 조작할 수 없습니다. 로그인한 구성원은 저장된 카드로 결제할 수 있습니다. 게스트는 결제 단계에서 카드 정보를 입력하고, 결제 전에 **로봇이 아닙니다** 확인란을 선택해야 합니다.

### 온라인 헌금이 없는 교회 {#churches-without-online-giving}

교회에 헌금 제공업체가 설정되어 있지 않아도 유료 이벤트는 등록을 받을 수 있습니다. 결제 단계에서는 온라인 결제를 사용할 수 없으며 등록자가 교회에 직접 결제할 수 있다는 안내가 나타나고, **등록 후 나중에 결제** 버튼을 누르면 등록이 저장됩니다. 등록은 전체 금액이 잔액으로 남은 **대기 중** 상태로 저장되며, 명단에는 잔액 경고와 함께 표시됩니다. 교회에서 평소 하던 방식대로 돈을 받으세요.

:::info
B1에서는 오프라인 결제를 받았다고 표시할 방법이 없습니다. 돈을 받은 뒤에도 잔액은 명단과 등록자의 [내 등록](../../b1-church/events/my-registrations.md) 카드에 그대로 남으므로, 누가 결제했는지 별도로 기록해 두세요.
:::
