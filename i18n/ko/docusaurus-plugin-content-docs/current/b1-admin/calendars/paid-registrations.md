# 유료 등록

<div class="article-intro">

이벤트 등록은 단순한 인원 집계를 넘어설 수 있습니다. 가격이 있는 참석자 유형(성인, 어린이 등)을 정의하고, 자체 가격과 수량이 있는 선택적 추가 옵션을 제공하며, 할인 코드를 만들고, 교회의 기존 후원 제공업체를 통해 등록 시 결제를 받을 수 있습니다. 이벤트가 마감되면 선택적 대기자 명단이 관심 있는 회원을 순서대로 관리하고 자리가 생기면 자동으로 승격시킵니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 먼저 이벤트에서 등록을 활성화하세요 — [캘린더 만들기](creating-calendars#enabling-event-registration) 참조
- 결제를 받으려면 교회에 [온라인 후원 설정](../donations/online-giving-setup.md)이 필요합니다(Stripe, PayPal, 또는 Kingdom Funding). 무료 이벤트는 후원 설정이 필요하지 않습니다.

</div>

## 등록 설정 열기

1. B1 Admin에서 **등록** 페이지로 이동하여 이벤트를 여세요(또는 캘린더에서 이벤트를 여세요).
2. **등록 설정** 카드에는 **등록 활성화**, **정원**, **등록 시작/종료**, **태그**, **등록 질문** 등 기본 사항이 표시됩니다.
3. 기본 사항 아래에는 **참석자 유형**, **선택 항목**, **할인 코드**라는 세 개의 아코디언이 있습니다.

## 참석자 유형

참석자 유형을 사용하면 다양한 종류의 참석자에게 다른 가격을 부과하고, 각각 별도로 상한을 설정할 수 있습니다.

1. **참석자 유형** 아코디언을 펼치고 **유형 추가**를 클릭하세요.
2. **이름**을 입력하세요(예: "성인", "어린이", "학생").
3. **가격**을 설정하세요. 무료 유형은 0을 사용하세요.
4. 선택적으로 해당 유형에만 적용되는 **정원**을 설정하세요(예: 어린이 자리 20개만). 유형별 제한이 없으면 비워 두세요.
5. **저장**을 클릭하세요.

등록 중 각 참석자는 유형을 선택하며, 마감된 유형은 **마감됨**으로 표시되어 선택할 수 없습니다. 명단은 각 참석자의 유형과 유형별 진행 인원 수가 표시됩니다.

## 선택 항목

선택 항목은 티셔츠, 식사 플랜, 활동 업그레이드와 같은 선택적 유료 추가 옵션입니다.

1. **선택 항목** 아코디언을 펼치고 **선택 항목 추가**를 클릭하세요.
2. **이름**, 선택적 **설명**, **가격**을 입력하세요(0은 "무료"로 표시됩니다).
3. 선택적으로 **정원**(모든 등록을 합산한 총 사용 가능 수량)과 **최대 수량**(등록 한 건에서 주문할 수 있는 최대 수량)을 설정하세요.
4. **저장**을 클릭하세요.

등록자는 신청 시 수량을 선택하며, 합계가 정원에 반영되어 초과 판매되지 않습니다.

## 할인 코드

1. **할인 코드** 아코디언을 펼치고 **할인 코드 추가**를 클릭하세요.
2. 등록자가 입력할 **코드**를 입력하세요.
3. **유형**을 선택하세요 — **비율** 또는 **금액** — 및 그 **값**.
4. 선택적으로 **시작일** / **종료일**, **최소 인원**(등록에 필요한 최소 참석자 수), **최대 사용 횟수**로 코드를 제한하세요.
5. **저장**을 클릭하세요.

각 코드는 사용된 횟수를 보여주는 **사용 횟수**를 표시하므로 얼마나 자주 사용되었는지 확인할 수 있습니다. 등록자는 코드를 적용할 때 즉각적인 피드백을 받습니다 — 코드가 만료되었거나, 아직 시작되지 않았거나, 더 많은 참석자가 필요한 경우 명확한 메시지가 표시됩니다.

## 대기자 명단

등록 설정 카드에서 **대기자 명단 활성화**를 켜세요. 이벤트가 정원에 도달하면:

- 신규 등록자는 거절되는 대신 대기자 명단 자리를 제안받습니다. 동일한 등록 절차를 완료합니다(대기 중에는 결제가 생략됩니다).
- 누군가 취소하면 가장 오래된 대기자 등록이 **자동으로 승격**되고 자리가 생겼다는 이메일을 받습니다. 잔액이 남아 있으면 이메일에 결제를 완료할 수 있는 링크가 포함됩니다.
- 대기 중인 행에서 **승격** 작업을 사용하여 언제든지 수동으로 승격시킬 수 있습니다 — 이벤트 정원을 늘린 후에 유용합니다.

:::info
승격된 등록은 잔액이 결제될 때까지 *보류 중* 상태로 유지됩니다. 결제(또는 결제할 금액이 없는 경우)가 완료되면 확정됩니다.
:::

## 등록 명단

등록 페이지에서 이벤트를 열면 모든 등록을 볼 수 있습니다. 표에는 **이름**, **인원**, **유형**(각 참석자의 유형), **결제/총액**(아직 잔액이 남아 있으면 경고 표시), **상태**, **날짜**와 표 위에 유형별 인원 수 칩이 표시됩니다.

- 행의 상세 아이콘을 클릭하면 **등록 상세 정보** 대화 상자가 열립니다 — 회원, 선택 항목, 결제/잔액, 그리고 모든 청구 내역(금액, 방법, 날짜)을 나열하는 **결제** 표가 표시됩니다.
- **CSV 내보내기**는 회원, 참석자 유형, 선택 항목, 결제/총액/잔액, 상태, 등록 질문별 열이 포함된 전체 명단을 다운로드합니다.
- **참석자 추가**를 사용하면 오프라인 신청도 수동으로 기록할 수 있습니다.

:::info
환불은 B1 내부에서 처리되지 않습니다. 취소된 유료 등록을 환불해야 하는 경우, 후원 제공업체의 대시보드(예: Stripe)에서 환불을 처리하세요.
:::

## 결제 작동 방식

결제는 교회가 이미 후원에 사용 중인 동일한 후원 게이트웨이를 통해 처리됩니다 — 카드 정보는 곧바로 제공업체로 전달되며 B1의 서버를 거치지 않습니다. 가격은 항상 구성된 유형, 선택 항목, 할인 코드를 기반으로 서버에서 계산되므로 등록자가 총액을 조작할 수 없습니다. 로그인한 회원은 저장된 카드로 결제할 수 있으며, 손님은 결제 시 카드 정보를 입력합니다.
