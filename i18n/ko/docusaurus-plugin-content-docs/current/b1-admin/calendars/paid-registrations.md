# 유료 등록

<div class="article-intro">

행사 등록은 단순한 인원 집계를 넘어설 수 있습니다. 가격이 있는 참가자 유형(예: 성인과 어린이)을 정의하고, 가격과 수량이 있는 선택 추가 상품을 제공하고, 할인 코드를 만들고, 교회가 이미 사용하는 헌금 제공업체를 통해 등록할 때 결제를 받을 수 있습니다. 행사가 가득 차면, 선택 사항인 대기자 명단이 관심 있는 교인의 순서를 지켜 주며 자리가 날 때마다 자동으로 등록합니다.

</div>

## 등록 설정 열기

1. B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 위의 검색창)를 열고 **Calendars > Registrations**를 선택한 다음 행사를 여세요(또는 캘린더에서 행사를 여세요).
2. **Registration Settings** 카드에는 기본 항목인 **Enable Registration**, **Capacity**, **Registration Opens/Closes**, **Tags**, **Registration Questions**가 표시됩니다.
3. 기본 항목 아래에는 세 개의 아코디언이 있습니다. **Attendee Types**, **Selections**, **Discount Codes**입니다.

## 참가자 유형

참가자 유형을 사용하면 참가자 종류에 따라 다른 가격을 매기고, 각 유형의 인원을 따로 제한할 수 있습니다.

1. **Attendee Types** 아코디언을 펼치고 **Add Type**을 클릭하세요.
2. **Name**을 입력하세요(예: "Adult", "Child", "Student").
3. **Price**를 설정하세요. 무료 유형이면 0을 입력하세요.
4. 이 유형에만 적용되는 **Capacity**를 선택 사항으로 설정하세요(예: 어린이 자리만 20개). 유형별 제한을 두지 않으려면 비워 두세요.
5. **Save**를 클릭하세요.

등록할 때 각 참가자는 유형을 고릅니다. 매진된 유형은 **Sold out**으로 표시되며 선택할 수 없습니다. 명단에는 각 참가자의 유형과 유형별 누적 인원이 표시됩니다.

## 선택 옵션

선택 옵션은 가격이 있는 선택 추가 상품입니다(예: 티셔츠, 식사 계획, 활동 업그레이드).

1. **Selections** 아코디언을 펼치고 **Add Selection**을 클릭하세요.
2. **Name**, 선택 사항인 **Description**, **Price**를 입력하세요(0은 "Free"로 표시됩니다).
3. 선택 사항으로 **Capacity**(모든 등록을 합친 총수량)와 **Max Qty**(한 등록에서 주문할 수 있는 최대 수량)를 설정하세요.
4. **Save**를 클릭하세요.

등록자는 가입할 때 수량을 고르며, 합계는 정원에 포함되므로 초과 판매가 발생하지 않습니다.

## 할인 코드

1. **Discount Codes** 아코디언을 펼치고 **Add Discount Code**를 클릭하세요.
2. 등록자가 입력할 **Code**를 입력하세요.
3. **Type**(**Percent** 또는 **Amount**)과 **Value**를 고르세요.
4. 선택 사항으로 **Start Date** / **End Date**, **Min Members**(등록에 포함되어야 하는 최소 참가자 수), **Max Uses**로 코드를 제한할 수 있습니다.
5. **Save**를 클릭하세요.

각 코드에는 **Uses** 횟수가 표시되어 지금까지 얼마나 사용되었는지 알 수 있습니다. 등록자가 코드를 적용하면 즉시 결과를 알 수 있으며, 코드가 만료되었거나 아직 시작되지 않았거나 참가자가 더 필요한 경우 분명한 메시지가 표시됩니다.

## 대기자 명단 {#waitlist}

Registration Settings 카드에서 **Enable Waitlist**를 켜세요. 행사 정원이 차면 다음과 같이 동작합니다.

- 새 등록자는 거절되는 대신 대기자 명단 자리를 받습니다. 같은 방식으로 신청을 마치되, 대기 중에는 결제가 건너뛰어집니다.
- 누군가 취소하면, 가장 먼저 대기 중이던 등록이 **자동으로 승격**되고, 자리가 났다는 이메일을 받습니다. 잔액이 남아 있다면 이메일에 교회 B1 사이트의 [내 등록](../../b1-church/events/my-registrations) 링크가 포함되어, 그곳에서 결제를 마칠 수 있습니다.
- 대기 중인 행의 **Promote** 작업으로 언제든지 수동 승격할 수 있습니다. 행사 정원을 늘린 뒤에 유용합니다.

:::info
승격된 등록은 잔액을 결제할 때까지 *보류(pending)* 상태로 남습니다. 결제하거나 결제할 금액이 없으면 등록이 확정됩니다.
:::

## 등록 명단 {#the-registration-roster}

등록 페이지에서 행사를 열면 모든 등록을 볼 수 있습니다. 카드 제목에는 정원 대비 자리를 차지한 등록 수가 표시됩니다(예: *Registrations (18 / 20)*). 보류 중이거나 확정된 등록만 정원에 포함됩니다. 대기 중인 사람이 있으면 제목에 그 수가 추가되며(예: *· 3 waitlisted*), 같은 수가 정원 막대 아래에도 표시됩니다. 표에는 **Name**, **Members**, **Type**(각 참가자의 유형), **Paid / Total**(잔액이 남아 있으면 경고 표시), **Status**, **Date**가 나오며, 표 위에는 유형별 인원 칩이 있습니다.

- 행의 상세 아이콘을 클릭하면 **Registration Details** 대화상자가 열립니다. 구성원, 선택 옵션, 결제/잔액, 모든 청구 내역(금액, 방법, 날짜)을 보여 주는 **Payments** 표가 있습니다.
- **Export CSV**는 구성원, 참가자 유형, 선택 옵션, 결제/총액/잔액, 상태, 등록 질문마다 한 열씩을 포함한 전체 명단을 내려받습니다.
- **Add Attendee**는 교회의 누구든 오프라인이나 전화로 신청한 경우를 기록합니다. 사람을 고르고, 유료 행사라면 참가자 유형도 고르세요. 이 사람의 카드로 요금이 청구되지는 않습니다. 유료 등록은 전체 금액이 잔액으로 남은 **pending** 상태로 저장됩니다. 교회에 온라인 헌금이 있으면 해당 사람이 [내 등록](../../b1-church/events/my-registrations)에서 결제할 수 있고, 없으면 직접 받으세요. 참가자를 추가하려면 Registrations Edit 권한이 필요합니다.

:::info
환불은 B1 내에서 처리되지 않습니다. 취소된 유료 등록을 환불해야 한다면 헌금 제공업체의 대시보드(예: Stripe)에서 환불하세요.
:::

## 결제 방식

결제는 교회가 헌금에 이미 사용하는 것과 같은 헌금 게이트웨이를 통해 이루어집니다. 카드 정보는 제공업체로 바로 전달되며 B1 서버를 거치지 않습니다. 가격은 설정한 유형, 선택 옵션, 할인 코드에 따라 항상 서버에서 계산되므로, 등록자가 총액을 조작할 수 없습니다. 로그인한 회원은 저장된 카드로 결제할 수 있습니다. 게스트는 결제 단계에서 카드를 입력하고, 결제하기 전에 **I'm not a robot** 확인란을 선택해야 합니다.

### 온라인 헌금이 없는 교회 {#churches-without-online-giving}

교회에 헌금 제공업체가 설정되어 있지 않아도 유료 행사는 등록을 받을 수 있습니다. 결제 단계에서는 온라인 결제를 사용할 수 없으며 교회에 직접 결제할 수 있다고 안내하고, **Register and Pay Later** 버튼을 누르면 등록이 저장됩니다. 이 등록은 전체 금액이 잔액으로 남은 **pending** 상태로 저장되며, 명단에는 잔액 경고와 함께 표시됩니다. 교회가 평소 하던 방식으로 돈을 받으세요.

:::info
B1에는 오프라인 결제를 받았다고 표시하는 방법이 없습니다. 잔액은 돈을 받은 뒤에도 명단과 등록자의 [내 등록](../../b1-church/events/my-registrations) 카드에 남아 있으므로, 누가 결제했는지 별도로 기록해 두세요.
:::
