# 유료 등록

<div class="article-intro">

이벤트 등록은 단순한 인원 파악을 넘어설 수 있습니다. 다양한 가격의 참석자 유형(성인 및 어린이 등)을 정의하고, 자신의 가격과 수량을 가진 선택 사항 추가 항목을 제공하고, 할인 코드를 생성하고, 교회의 기존 기부 제공자를 통해 등록 시 결제를 수집할 수 있습니다. 이벤트가 가득 차면 선택적 대기자 목록이 관심 있는 회원을 대기열에 유지하고 자리가 열릴 때 자동으로 승격합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 먼저 이벤트의 등록을 활성화하세요 -- [달력 생성](creating-calendars#enabling-event-registration)을 참조하세요
- 결제를 수집하려면 교회가 [온라인 기부를 구성](../donations/online-giving-setup.md)해야 합니다(Stripe, PayPal 또는 Kingdom Funding). 무료 이벤트는 기부 설정이 필요하지 않습니다.

</div>

## 등록 설정 열기

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **달력 > 등록**을 선택하고 이벤트를 열거나(또는 달력에서 이벤트 열기), 이벤트를 엽니다.
2. **등록 설정** 카드에는 기본 사항이 표시됩니다 -- **등록 활성화**, **용량**, **등록 시작/마감**, **태그**, **등록 질문**.
3. 기본 사항 아래에는 세 가지 아코디언이 있습니다: **참석자 유형**, **선택 사항**, **할인 코드**.

## 참석자 유형

참석자 유형을 사용하면 다양한 참석자에게 다른 가격을 청구할 수 있으며 각각을 별도로 제한할 수 있습니다.

1. **참석자 유형** 아코디언을 펼치고 **유형 추가**를 클릭합니다.
2. **이름**을 입력합니다(예: "성인", "어린이", "학생").
3. **가격**을 설정합니다. 무료 유형의 경우 0을 사용합니다.
4. 선택 사항으로 이 유형에 대한 **용량**을 설정합니다(예: 어린이 자리 20개만). 유형별 제한이 없으면 공란으로 두세요.
5. **저장**을 클릭합니다.

등록 중에 각 참석자는 유형을 선택하고, 품절 유형은 **품절**로 표시되며 선택할 수 없습니다. 이름부 보기에는 각 참석자의 유형과 유형별 실행 수가 표시됩니다.

## 선택 사항

선택 사항은 선택적인 가격이 책정된 추가 항목(T셔츠, 식사 계획, 활동 업그레이드 등)입니다.

1. **선택 사항** 아코디언을 펼치고 **선택 사항 추가**를 클릭합니다.
2. **이름**, 선택적 **설명**, **가격**을 입력합니다(0은 "무료"로 표시됨).
3. 선택 사항으로 **용량**(모든 등록에서 사용 가능한 총 수량)과 **최대 수량**(한 등록이 주문할 수 있는 최대 수)을 설정합니다.
4. **저장**을 클릭합니다.

등록자는 등록 중에 수량을 선택하고, 합계가 용량에 대해 계산되므로 과도한 판매가 없습니다.

## 할인 코드

1. **할인 코드** 아코디언을 펼치고 **할인 코드 추가**를 클릭합니다.
2. 등록자가 입력할 **코드**를 입력합니다.
3. **유형** -- **백분율** 또는 **금액** -- 및 **값**을 선택합니다.
4. 선택 사항으로 **시작 날짜** / **종료 날짜**, **최소 회원 수**(등록의 최소 참석자 수), **최대 사용 횟수**로 코드를 제한합니다.
5. **저장**을 클릭합니다.

각 코드는 **사용** 수를 표시하므로 얼마나 자주 사용되었는지 볼 수 있습니다. 등록자는 코드를 적용할 때 즉시 피드백을 받습니다 -- 코드가 만료되었거나, 아직 시작되지 않았거나, 더 많은 참석자가 필요한 경우를 포함한 명확한 메시지입니다.

## 대기자 목록

등록 설정 카드에서 **대기자 목록 활성화**를 켭니다. 이벤트가 용량에 도달하면:

- 새 등록자에게는 거부되는 대신 대기자 목록 자리가 제공됩니다. 동일한 등록을 완료합니다(결제는 대기 중인 동안 건너뜁니다).
- 누군가 취소하면 가장 오래된 대기자 목록 등록이 **자동으로 승격**되고 자리가 열렸다는 이메일을 받습니다. 잔액을 지불해야 하면 이메일은 결제를 완료하는 링크를 제공합니다.
- **승격** 작업으로 언제든지 대기자 목록 행에서 누군가를 수동으로 승격할 수 있습니다 -- 이벤트 용량을 늘린 후에 유용합니다.

:::info
승격된 등록은 잔액이 결제될 때까지 *대기 중* 상태로 유지됩니다. 결제(또는 지불할 것이 없음)는 확정합니다.
:::

## 등록 이름부

등록 페이지에서 이벤트를 열어 모든 등록을 봅니다. 테이블에는 **이름**, **회원**, **유형**(각 참석자의 유형), **결제됨 / 합계**(잔액이 지불되어야 할 때 잔액 경고 포함), **상태**, **날짜**가 표시되며, 테이블 위의 유형별 수 칩도 표시됩니다.

- 행의 상세 아이콘을 클릭하여 **등록 상세** 대화 상자를 엽니다 -- 회원, 선택 사항, 결제/잔액 및 모든 청구를 나열하는 **결제** 테이블(금액, 방법, 날짜).
- **CSV로 내보내기**는 전체 이름부를 회원, 참석자 유형, 선택 사항, 결제됨/합계/잔액, 상태 및 등록 질문당 한 개 열의 열과 함께 다운로드합니다.
- **참석자 추가**는 여전히 오프라인 등록을 수동으로 기록할 수 있습니다.

:::info
환불은 B1 내에서 처리되지 않습니다. 취소된 유료 등록을 환불해야 하는 경우 기부 제공자의 대시보드(예: Stripe)에서 환불을 발행하세요.
:::

## 결제의 작동 방식

결제는 기부를 위해 교회가 이미 사용하는 동일한 기부 게이트웨이를 통해 처리됩니다 -- 카드 세부 정보는 제공자에게 직접 이동하며 B1의 서버에 건드리지 않습니다. 가격은 항상 구성된 유형, 선택 사항 및 할인 코드에서 서버를 통해 계산되므로 등록자는 합계를 변조할 수 없습니다. 로그인한 회원은 저장된 카드로 결제할 수 있고, 손님은 체크아웃 시 카드를 입력합니다.
