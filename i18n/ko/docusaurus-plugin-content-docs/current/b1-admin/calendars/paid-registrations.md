# 유료 등록

<div class="article-intro">

이벤트 등록은 단순한 인원 집계를 넘어설 수 있습니다. 성인이나 어린이처럼 가격이 있는 참석자 유형을 정의하고, 자체 가격과 수량이 있는 선택 추가 옵션을 제공하며, 할인 코드를 만들고, 교회가 이미 사용하는 헌금 제공업체를 통해 등록 시 결제를 받을 수 있습니다. 이벤트가 정원에 차면 선택 사항인 대기자 명단이 관심 있는 구성원을 순서대로 기다리게 하고, 자리가 생기면 자동으로 등록시켜 줍니다.

</div>

## 등록 설정 열기 {#opening-registration-settings}

1. B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Calendars > Registrations**를 선택한 뒤 이벤트를 클릭합니다(또는 캘린더에서 이벤트를 클릭하고 **Manage Registrations**를 선택합니다).
2. **Edit settings**를 클릭합니다. **Registration Settings** 카드에는 기본 항목인 **Enable Registration**, **Capacity**, **Enable Waitlist**, **Registration Opens/Closes**, **Tags**, **Registration Questions**가 있고, **Save Settings** 버튼이 있습니다.
3. 기본 항목 아래에는 세 개의 접이식 패널이 있습니다. **Attendee Types**, **Selections**, **Discount Codes**입니다. 각 패널에는 **Save Settings**와는 별도의 **Save** 버튼이 있으며, 저장하지 않은 변경 사항이 있는 채로 나가려고 하면 B1이 경고합니다. 명단으로 돌아가려면 **Back to Registrations**를 클릭합니다.

## 참석자 유형 {#attendee-types}

참석자 유형을 사용하면 참석자 종류마다 다른 가격을 매기고, 각 유형의 인원도 따로 제한할 수 있습니다.

1. **Attendee Types** 패널을 펼치고 **Add Type**을 클릭합니다.
2. **Name**을 입력합니다(예: "Adult", "Child", "Student").
3. **Price**를 설정합니다. 무료 유형이라면 0을 입력합니다.
4. 선택 사항으로 이 유형만의 **Capacity**를 설정합니다(예: 어린이 자리 20석만). 유형별 제한을 두지 않으려면 비워 둡니다.
5. 선택 사항으로 **Sort**를 설정하여 유형이 나열되는 순서를 정합니다.
6. **Save**를 클릭합니다.

저장된 유형을 제거하려면 삭제 아이콘을 클릭하고 확인합니다. 바로 제거됩니다. 선택 항목과 할인 코드도 같은 방식으로 제거합니다.

등록할 때 각 참석자는 유형을 고릅니다. 매진된 유형은 **Sold out**으로 표시되며 선택할 수 없습니다. 명단에는 각 참석자의 유형과 유형별 누적 인원이 표시됩니다.

## 선택 항목 {#selections}

선택 항목은 티셔츠, 식사 플랜, 활동 업그레이드처럼 가격이 있는 선택 추가 옵션입니다.

1. **Selections** 패널을 펼치고 **Add Selection**을 클릭합니다.
2. **Name**, 선택 사항인 **Description**, **Price**를 입력합니다(0은 "Free"로 표시됩니다).
3. 선택 사항으로 **Capacity**(모든 등록을 합친 총 가능 수량)와 **Max Qty**(한 등록에서 주문할 수 있는 최대 수량)를 설정합니다.
4. **Save**를 클릭합니다.

등록자는 신청할 때 수량을 고르며, 합계는 정원에 포함되므로 초과 판매가 일어나지 않습니다.

## 할인 코드 {#discount-codes}

1. **Discount Codes** 패널을 펼치고 **Add Discount Code**를 클릭합니다.
2. 등록자가 입력할 **Code**를 입력합니다.
3. **Type**을 고릅니다. **Percent**(비율) 또는 **Amount**(금액)이며, 그다음 **Value**를 입력합니다.
4. 선택 사항으로 **Start Date** / **End Date**, **Min Members**(등록에 포함된 최소 참석자 수), **Max Uses**로 코드를 제한합니다.
5. **Save**를 클릭합니다.

각 코드에는 **Uses** 횟수가 표시되어 얼마나 자주 사용되었는지 알 수 있습니다. 등록자가 코드를 적용하면 즉시 피드백을 받습니다. 코드가 만료되었거나 아직 시작되지 않았거나 참석자가 더 필요하면 그 이유도 분명하게 알려 줍니다.

## 대기자 명단 {#waitlist}

등록 설정 카드에서 **Enable Waitlist**를 켭니다. 이벤트가 정원에 도달하면 다음과 같이 작동합니다.

- 새 등록자는 돌려보내지 않고 대기자 자리를 제안받습니다. 같은 가입 절차를 완료하며, 대기 중에는 결제 단계를 건너뜁니다.
- 누군가 취소하면 가장 오래된 대기자 등록이 **자동으로 등록**되고, 자리가 생겼다는 이메일을 받습니다. 결제할 잔액이 있으면 이메일은 교회 B1 사이트의 [내 등록](../../b1-church/events/my-registrations.md)으로 연결되며, 그곳에서 결제를 마칠 수 있습니다.
- 대기자 행의 **Promote** 작업으로 언제든지 수동으로 등록시킬 수 있습니다. 이벤트 정원을 늘린 뒤에 유용합니다.

:::info
등록된 대기자는 잔액을 낼 때까지 *pending* 상태로 남습니다. 결제하거나(또는 낼 금액이 없으면) 등록이 확정됩니다.
:::

## 등록 명단 {#the-registration-roster}

등록 페이지에서 이벤트를 열면 모든 등록을 볼 수 있습니다. 카드 제목에는 정원 대비 자리를 차지한 등록 수가 표시됩니다(예: *Registrations (18 / 20)*). 보류 중이거나 확정된 등록만 계산합니다. 대기자가 있으면 제목에 그 수가 추가되며(예: *· 3 waitlisted*), 같은 수가 정원 막대 아래에도 나타납니다. 정원 막대 위의 큰 숫자는 등록 건수가 아니라 **사람 수**를 셉니다. 즉 보류 중이거나 확정된 각 등록에 포함된 모든 사람을 세므로, 네 명인 가족은 네 명으로 계산됩니다. 정원 제한 자체는 여전히 등록 건수를 기준으로 합니다. 표에는 **Name**, **Members**, **Type**(각 참석자의 유형), **Paid / Total**(아직 낼 금액이 있으면 잔액 경고와 함께), **Status**, **Date**가 표시되며, 표 위에는 유형별 인원 칩이 있습니다.

- 행의 세부 정보 아이콘을 클릭하면 **Registration Details** 대화상자가 열립니다. 구성원, 선택 항목, 지불/잔액, 그리고 모든 청구 내역(금액, 방법, 날짜)을 나열한 **Payments** 표가 있습니다.
- **Export CSV**는 구성원, 참석자 유형, 선택 항목, 지불/합계/잔액, 상태, 등록 질문마다 한 열씩을 포함한 전체 명단을 내려받습니다.
- **Add Attendee**는 교회의 아무 사람에 대해서나 오프라인이나 전화 신청을 기록합니다. 사람을 고르고, 유료 이벤트라면 참석자 유형도 고릅니다. 이 사람에게 요금이 청구되지는 않습니다. 유료 등록은 전체 금액이 잔액으로 남은 **pending** 상태로 저장됩니다. 교회에 온라인 헌금이 있다면 본인이 [내 등록](../../b1-church/events/my-registrations.md)에서 낼 수 있고, 없다면 직접 받으세요. 참석자를 추가하려면 Registrations 편집 권한이 필요합니다.

:::info
B1 안에서는 환불을 처리하지 않습니다. 취소된 유료 등록을 환불해야 한다면 헌금 제공업체의 대시보드(예: Stripe)에서 환불하세요.
:::

## 결제 방식 {#how-payment-works}

결제는 교회가 헌금에 이미 사용하는 것과 같은 헌금 게이트웨이를 통해 이루어집니다. 카드 정보는 제공업체로 바로 전송되며 B1 서버를 거치지 않습니다. 가격은 항상 서버가 설정된 유형, 선택 항목, 할인 코드로 계산하므로 등록자가 합계를 조작할 수 없습니다. 로그인한 구성원은 저장된 카드로 결제할 수 있습니다. 게스트는 결제 시 카드를 입력해야 하며, 결제 전에 **I'm not a robot** 확인란을 체크해야 합니다.

### 온라인 헌금이 없는 교회 {#churches-without-online-giving}

교회에 헌금 제공업체가 설정되어 있지 않아도 유료 이벤트는 등록을 받을 수 있습니다. 결제 단계에서는 온라인 결제를 사용할 수 없으며 교회에 직접 결제할 수 있다고 등록자에게 알립니다. **Register and Pay Later** 버튼을 누르면 등록이 저장됩니다. 등록은 전체 금액이 잔액으로 남은 **pending** 상태로 저장되며, 명단에는 잔액 경고와 함께 표시됩니다. 돈은 교회가 평소 받는 방식으로 받으세요.

:::info
B1에는 오프라인 결제를 받았다고 표시하는 방법이 없습니다. 잔액은 돈을 받은 뒤에도 명단과 등록자의 [내 등록](../../b1-church/events/my-registrations.md) 카드에 남아 있으므로, 누가 결제했는지 별도로 기록해 두세요.
:::
