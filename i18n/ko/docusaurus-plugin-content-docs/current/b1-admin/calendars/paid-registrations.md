# 유료 등록

<div class="article-intro">

이벤트 등록은 단순히 인원을 세는 것 이상으로 갈 수 있습니다. 서로 다른 가격의 참석자 유형(예: 성인 및 아동)을 정의하고, 자체 가격 및 수량이 있는 선택적 추가 항목을 제공하고, 할인 코드를 만들고, 교회의 기존 기부 공급자를 통해 등록 시 결제를 수집할 수 있습니다. 이벤트가 가득 차면, 선택적 대기 목록은 관심 있는 구성원을 유지하고 자리가 열리면 자동으로 승격합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 먼저 이벤트에 등록 활성화 — [일정 생성](creating-calendars#enabling-event-registration) 참조
- 결제를 수집하려면 교회에 [온라인 기부 구성](../donations/online-giving-setup.md)이 필요합니다(Stripe, PayPal 또는 Kingdom Funding). 무료 이벤트는 기부 설정이 필요하지 않습니다.

</div>

## 등록 설정 열기

1. B1 Admin에서 **등록** 페이지로 이동한 후 이벤트를 엽니다(또는 일정에서 이벤트를 열기).
2. **등록 설정** 카드는 기본 사항(**등록 활성화**, **용량**, **등록 열기/닫기**, **태그** 및 **등록 질문**)을 표시합니다.
3. 기본 사항 아래에는 3개의 아코디언이 있습니다: **참석자 유형**, **선택 항목** 및 **할인 코드**.

## 참석자 유형

참석자 유형을 사용하면 여러 종류의 참석자에게 다른 가격을 청구하고 각각을 별도로 제한할 수 있습니다.

1. **참석자 유형** 아코디언을 확장하고 **유형 추가**를 클릭합니다.
2. **이름** 입력(예: "성인", "아동", "학생").
3. **가격** 설정합니다. 무료 유형의 경우 0을 사용합니다.
4. 선택적으로 이 유형에 대한 **용량**을 설정합니다(예: 아동 자리 20개만). 유형별 제한이 없으면 비워 두세요.
5. **저장**을 클릭합니다.

등록 중에 각 참석자는 유형을 선택합니다. 매진된 유형은 **매진됨**으로 표시되며 선택할 수 없습니다. 명부는 각 참석자의 유형과 유형별 실행 중인 개수를 표시합니다.

## 선택 항목

선택 항목은 선택적 가격 추가 항목입니다 — T셔츠, 식사 계획, 활동 업그레이드입니다.

1. **선택 항목** 아코디언을 확장하고 **선택 항목 추가**를 클릭합니다.
2. **이름**, 선택적 **설명** 및 **가격** 입력합니다("무료" 0 표시).
3. 선택적으로 **용량**(모든 등록에서 사용 가능한 총 개수) 및 **최대 수량**(하나의 등록이 주문할 수 있는 최대)을 설정합니다.
4. **저장**을 클릭합니다.

등록자는 가입 중에 수량을 선택하고 용량에 포함되므로 초과 판매를 할 수 없습니다.

## 할인 코드

1. **할인 코드** 아코디언을 확장하고 **할인 코드 추가**를 클릭합니다.
2. 등록자가 입력할 **코드** 입력합니다.
3. **유형** 선택 — **백분율** 또는 **금액** — 및 해당 **값**.
4. 선택적으로 **시작 날짜** / **종료 날짜**, **최소 구성원**(등록의 최소 참석자 수) 및 **최대 사용 횟수**로 코드를 제한합니다.
5. **저장**을 클릭합니다.

각 코드는 **사용** 개수를 표시하여 얼마나 자주 사용되었는지 볼 수 있습니다. 등록자는 코드를 적용할 때 즉시 피드백을 받습니다 — 코드가 만료되었거나, 시작되지 않았거나, 더 많은 참석자가 필요한 경우를 포함한 명확한 메시지입니다.

## 대기 목록

등록 설정 카드에서 **대기 목록 활성화** 켜기. 이벤트가 용량에 도달하면:

- 새 등록자는 거부되는 대신 대기 목록 자리를 제공합니다. 동일한 가입을 완료합니다(결제는 대기 목록에 있는 동안 건너뜁니다).
- 누군가 취소하면 가장 오래된 대기 목록 등록이 **자동으로 승격**되고 자리가 열렸음을 알려주는 이메일을 받습니다. 잔액이 있으면 이메일이 결제를 완료하는 링크를 제공합니다.
- **승격** 작업을 사용하여 언제든지 누군가를 수동으로 승격할 수 있습니다 — 이벤트 용량을 높인 후에 유용합니다.

:::info
승격된 등록은 잔액이 지불될 때까지 *보류 중* 상태로 유지됩니다. 지불하거나 지불할 것이 없으면 확인됩니다.
:::

## 등록 명부

등록 페이지에서 이벤트를 열어 모든 등록을 봅니다. 표는 **이름**, **구성원**, **유형**(각 참석자의 유형), **지불됨 / 총액**(잔액이 여전히 owed되는 경우 잔액 경고 포함), **상태** 및 **날짜**를 표시하며, 표 위에 유형별 개수 칩이 있습니다.

- 행의 세부 정보 아이콘을 클릭하여 **등록 세부 정보** 대화를 엽니다 — 구성원, 선택 항목, 지불됨/잔액 및 모든 청구를 나열하는 **결제** 표(금액, 방법, 날짜).
- **CSV 내보내기**는 구성원, 참석자 유형, 선택 항목, 지불됨/총액/잔액, 상태 및 등록 질문당 하나의 열이 있는 열을 포함하는 전체 명부를 다운로드합니다.
- **참석자 추가**는 여전히 오프라인 가입을 수동으로 기록할 수 있습니다.

:::info
환불은 B1 내에서 처리되지 않습니다. 취소된 지불 등록을 환불해야 하는 경우 기부 공급자의 대시보드에서 환불을 발급하세요(예: Stripe).
:::

## 결제 방식

결제는 교회가 기부에 이미 사용하는 동일한 기부 게이트웨이를 통과합니다 — 카드 세부 정보는 공급자에게 직접 이동하며 B1의 서버에 닿지 않습니다. 가격은 항상 구성된 유형, 선택 항목 및 할인 코드에서 서버에서 계산되므로 등록자는 합계로 변조할 수 없습니다. 로그인한 구성원은 저장된 카드로 지불할 수 있습니다. 손님은 체크아웃 시 카드를 입력합니다.
