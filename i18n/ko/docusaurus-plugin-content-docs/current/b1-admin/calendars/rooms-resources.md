# 방, 리소스 및 일정

<div class="article-intro">

방과 리소스를 사용하면 교회의 예약 가능한 공간과 장비를 추적할 수 있습니다. 그룹이나 팀이 이벤트에 방을 사용하거나 리소스를 빌리려고 하면 B1을 통해 요청할 수 있습니다 -- 요청을 승인하거나 거부하여 이중 예약을 방지할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin의 달력 섹션에 대한 관리자 권한이 필요합니다
- 예약 요청을 제출할 회원이 있는 [그룹](../groups/creating-groups)을 설정하세요

</div>

## 방 & 리소스 열기

B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **달력**을 확장한 후 **방 & 리소스**를 클릭합니다. 페이지에는 4개의 탭이 있습니다: **방**, **리소스**, **차단**, **템플릿**.

## 방

방은 달력 이벤트와 함께 예약할 수 있는 물리적 공간입니다 -- 성소, 예배 홀, 교실 등.

### 방 추가하기

1. **방** 탭에서 **방 추가**를 클릭합니다.
2. 방의 **이름**을 입력합니다.
3. 선택 사항으로 **용량**(최대 인원)을 설정합니다.
4. **승인 그룹**을 설정합니다 -- 그룹이 이 방을 요청하면 선택된 그룹의 리더가 통지를 받고 예약을 승인해야 합니다. 승인이 필요 없으면 공란으로 두세요.
5. **저장**을 클릭합니다.

### 방 편집 또는 삭제하기

방 옆의 편집 아이콘을 클릭하고 변경 사항을 만든 후 **저장**을 클릭합니다. **삭제**를 사용하여 방을 영구적으로 제거합니다.

## 리소스

리소스는 이벤트와 함께 예약할 수 있는 항목입니다 -- AV 장비, 프로젝터, 의자, 밴 등.

### 리소스 추가하기

1. **리소스** 탭을 클릭한 후 **리소스 추가**를 클릭합니다.
2. **이름**과 선택적 **설명**을 입력합니다.
3. 누군가 리소스 대출에 서명해야 하는 경우 **승인 그룹**을 설정합니다.
4. **저장**을 클릭합니다.

## 차단

차단은 특정 시간 동안 방이나 리소스가 예약되지 않도록 방지합니다 -- 개조, 예약된 기간 또는 유지보수.

### 차단 추가하기

1. **차단** 탭을 클릭한 후 **차단 추가**를 클릭합니다.
2. **방**, **리소스** 또는 모든 방과 리소스를 차단할지 선택합니다.
3. 차단을 위한 **시작** 및 **종료** 날짜/시간을 설정합니다.
4. 선택 사항으로 **사유** 메모를 추가합니다.
5. **저장**을 클릭합니다.

## 이벤트 템플릿

템플릿을 사용하면 재사용 가능한 이벤트 구성(제목, 설명 및 관련 그룹)을 저장할 수 있으므로 반복되는 이벤트를 일관되게 생성할 수 있습니다.

### 템플릿 추가하기

1. **템플릿** 탭을 클릭한 후 **템플릿 추가**를 클릭합니다.
2. 템플릿의 **이름**을 입력합니다.
3. 선택 사항으로 **그룹**을 링크하므로 템플릿에서 생성할 때 이벤트가 자동으로 해당 그룹에 연결됩니다.
4. **저장**을 클릭합니다.

새 이벤트를 생성할 때 직원은 기존 템플릿을 선택하여 이벤트 세부 정보를 미리 채울 수 있습니다.
