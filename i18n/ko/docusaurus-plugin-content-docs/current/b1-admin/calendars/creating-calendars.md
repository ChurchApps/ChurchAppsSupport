# 캘린더 만들기

<div class="article-intro">

B1 Admin에서 캘린더를 만들면 하나 이상의 그룹을 연결해 행사를 정리된 형태로 볼 수 있습니다. 행사는 각 그룹 내에서 그룹 리더가 관리하며, 캘린더는 그 행사들을 한곳에 모아 보여줍니다. 도메인 관리자라 하더라도 행사가 속한 그룹의 리더가 아니라면 캘린더 섹션에서 직접 행사를 추가하거나 편집할 수 없습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 캘린더에 포함하고 싶은 행사를 가진 [그룹](../groups/creating-groups.md)을 설정하세요
- B1 Admin의 Calendars 섹션에 대한 관리자 권한이 필요합니다

</div>

## 새 캘린더 만들기

1. B1 Admin에서 **웹사이트**로 이동한 다음 **캘린더** 섹션으로 들어갑니다.
2. **캘린더 추가**를 클릭합니다.
3. 캘린더의 **이름**을 입력합니다(예: "청소년 사역 행사" 또는 "교회 전체 캘린더").
4. 팀이 이 캘린더의 용도를 이해할 수 있도록 선택적으로 **설명**을 추가합니다.
5. **생성**을 클릭해 새 캘린더를 저장합니다.

## 캘린더 상세 페이지

캘린더를 만든 후 클릭하면 상세 페이지가 열립니다. 이 페이지에는 두 개의 주요 영역이 있습니다.

- **왼쪽 열** -- 연결된 그룹에서 가져온 행사를 보여주는 캘린더 보기.
- **오른쪽 열** -- 연결된 그룹 목록. 이 캘린더에 포함할 그룹을 관리하는 곳입니다.

## 그룹 연결하기

캘린더에 행사가 있는 그룹은 상세 페이지 오른쪽의 그룹 목록에 자동으로 표시됩니다.

1. 그룹 섹션에서 **추가**를 클릭해 캘린더에 그룹을 연결합니다.
2. 드롭다운에서 그룹을 선택합니다.
3. 해당 그룹의 **모든 행사**를 포함할지 **특정 행사**만 포함할지 선택합니다.
4. **저장**을 클릭합니다.

:::tip
캘린더에 그룹을 연결하는 것은 행사를 자동으로 모아 보여주는 강력한 방법입니다. 그룹 리더가 자신의 [그룹](../groups/creating-groups.md)에 행사를 추가하면, 별도의 추가 작업 없이 교회 전체 캘린더에 반영될 수 있습니다.
:::

:::info
교회 내 여러 그룹의 행사를 한데 모으는 단일 캘린더를 만들고 싶다면, 더 간편한 방법인 [큐레이션 캘린더](curated-calendar)를 참고하세요.
:::

## 행사 등록 활성화하기

캘린더 행사에 대해 등록을 활성화하면 회원들이 B1 웹사이트나 모바일 앱을 통해 신청할 수 있습니다.

1. 기존 행사를 클릭하거나 새 행사를 만듭니다.
2. 행사 편집기에서 **등록**을 켭니다.
3. 등록 설정을 구성합니다.
   - **정원** (선택 사항) -- 최대 등록 인원을 설정합니다. 인원 제한이 없다면 비워 두세요.
   - **등록 시작** -- 등록이 가능해지는 날짜와 시간입니다.
   - **등록 마감** -- 등록이 마감되는 날짜와 시간입니다.
   - **태그** -- 등록 가능한 행사를 분류하는 데 도움이 되는 쉼표로 구분된 라벨입니다(예: "청소년, 수련회, VBS").
   - **등록 질문** -- 선택적으로 [양식](../forms/creating-forms.md)을 연결해 등록자가 신청과 함께 추가 질문(식단 제한, 티셔츠 사이즈, 비상 연락처 등)에 답하도록 할 수 있습니다. 질문을 생략하려면 **없음**을 선택하세요.
   - **대기자 명단 활성화** -- 행사가 정원을 채우면 추가 등록자가 거부되는 대신 대기자 명단에 등록할 수 있게 합니다. [유료 등록](paid-registrations#waitlist)을 참고하세요.
4. 행사를 저장합니다.

유료 행사의 경우, 같은 설정 페이지에서 가격이 책정된 **참가자 유형**, 선택적인 **추가 선택 항목**, **할인 코드**를 정의할 수 있으며, 결제는 교회의 헌금 제공업체를 통해 수집됩니다. 전체 안내는 [유료 등록](paid-registrations)을 참고하세요.

등록이 활성화되면, 회원이 [B1 웹사이트](../../b1-church/events/registering)나 [B1 모바일 앱](../../b1-mobile/events/registering)에서 해당 행사를 볼 때 **이 행사 등록하기** 버튼이 표시됩니다. 양식을 연결했다면 등록자는 등록 과정 중 **질문** 단계를 보게 되고, 답변은 등록 정보와 함께 저장됩니다.

:::info
등록 질문은 **제한됨**으로 표시되지 않은 양식에서만 작동합니다. 제한된 양식은 표시되지 않고 등록 과정에서 자동으로 건너뛰어집니다. 따라서 행사에 질문을 연결할 때는 제한되지 않은 양식을 사용하세요.
:::

### 등록 관리하기

행사 등록을 확인하고 관리하려면 다음을 따르세요.

1. B1 Admin에서 **등록** 페이지로 이동합니다.
2. 등록이 활성화된 모든 행사의 표가 표시되며, 행사 제목, 날짜, 정원 대비 현재 등록 인원, 태그를 확인할 수 있습니다.
3. 행사를 클릭하면 이름, 인원 수, 참가자 유형, 결제 상태, 등록 날짜를 포함한 전체 등록 목록을 볼 수 있습니다.
4. 상세 페이지에서 다음 작업을 할 수 있습니다.
   - **참가자 추가** -- 오프라인이나 전화로 신청한 사람을 수동으로 등록합니다.
   - 개별 등록 **취소**
   - 등록을 영구적으로 **삭제**
   - 자리가 생기면 대기자 명단 등록을 **승격**
   - **CSV로 내보내기** -- 참가자 유형, 추가 선택 항목, 결제 금액, 질문 답변을 포함한 모든 등록 내역을 다운로드합니다.

행사에 등록 질문이 연결되어 있다면, 상세 페이지에는 아직 답변을 제출하지 않은 등록자를 빠르게 찾는 **답변 없는 항목만** 필터와, 답변이 완료된 각 등록 옆에 답변 내용을 볼 수 있는 **답변 보기** 버튼도 표시됩니다. 유료 행사에는 **유형** 열, **결제 완료/전체** 열, 유형별 인원 수, 결제 상세 대화 상자가 추가로 표시됩니다. 자세한 내용은 [유료 등록](paid-registrations#the-registration-roster)을 참고하세요.

:::tip
정원 진행률 표시줄을 활용해 행사가 얼마나 빠르게 채워지고 있는지 확인하세요. 행사가 정원에 도달하거나 초과하면 표시줄이 빨간색으로 바뀝니다.
:::
