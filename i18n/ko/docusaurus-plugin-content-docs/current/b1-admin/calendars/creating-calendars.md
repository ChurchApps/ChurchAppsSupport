# 달력 생성

<div class="article-intro">

B1 Admin에서 달력을 생성하면 하나 이상의 그룹을 연결하여 이벤트의 큐레이션된 보기를 구성할 수 있습니다. 이벤트는 그룹 리더에 의해 해당 그룹 내에서 관리되며, 달력은 해당 이벤트를 한 곳에 표시합니다. 편집 권한이 있는 관리자는 모든 그룹의 이벤트를 추가하거나 편집할 수 있습니다. 관리자가 아닌 그룹 리더는 본인이 이끄는 그룹의 이벤트만 관리할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 달력에 포함할 이벤트가 있는 [그룹](../groups/creating-groups.md)을 설정하세요
- B1 Admin의 달력 섹션에 대한 관리자 권한이 필요합니다

</div>

## 새 달력 생성하기

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **달력**을 확장한 후 **달력**을 클릭합니다.
2. **달력 추가**를 클릭합니다.
3. 달력의 **이름**을 입력합니다(예: "청년 사역 이벤트" 또는 "교회 메인 달력").
4. 선택 사항으로 **설명**을 추가하여 팀이 이 달력의 용도를 이해하도록 도와줍니다.
5. **만들기**를 클릭하여 새 달력을 저장합니다.

## 달력 상세 페이지

달력을 생성한 후 클릭하여 상세 페이지를 엽니다. 이 페이지에는 두 가지 주요 영역이 있습니다:

- **왼쪽 열** -- 연결된 그룹에서 가져온 이벤트를 표시하는 달력 보기입니다.
- **오른쪽 열** -- 관련 그룹 목록입니다. 여기서 이 달력에 포함된 그룹을 관리합니다.

## 그룹 연결하기

달력에 이벤트가 있는 그룹은 상세 페이지의 오른쪽에 있는 그룹 목록에 자동으로 나타납니다.

1. 그룹 섹션에서 **추가**를 클릭하여 그룹을 달력과 연결합니다.
2. 드롭다운에서 그룹을 선택합니다.
3. 해당 그룹의 **모든 이벤트**를 포함할지 **특정 이벤트**만 포함할지 선택합니다.
4. **저장**을 클릭합니다.

:::tip
달력에 그룹을 연결하는 것은 이벤트를 자동으로 집계하는 강력한 방법입니다. 그룹 리더가 [그룹](../groups/creating-groups.md)에 이벤트를 추가하면, 추가 작업 없이 교회 전체 달력으로 자동으로 흘러들어올 수 있습니다.
:::

:::info
여러 그룹에서 이벤트를 가져오는 단일 달력을 만들려면 [큐레이션된 달력](curated-calendar)을 참조하여 간소화된 방식을 확인하세요.
:::

## 이벤트 등록 활성화

달력 이벤트에 대해 등록을 활성화하여 회원이 B1 웹사이트 또는 모바일 앱을 통해 등록할 수 있도록 할 수 있습니다.

1. 기존 이벤트를 클릭하거나 새로운 이벤트를 만듭니다.
2. 이벤트 편집기에서 **등록**을 토글하여 활성화합니다.
3. 등록 설정을 구성합니다:
   - **용량** (선택 사항) -- 최대 등록 수를 설정합니다. 무제한으로 두려면 공란으로 두세요.
   - **등록 시작** -- 등록이 가능해지는 날짜와 시간입니다.
   - **등록 마감** -- 등록이 종료되는 날짜와 시간입니다.
   - **태그** -- 쉼표로 구분된 레이블(예: "청년, 수련회, vbs")로 등록 가능한 이벤트를 분류하는 데 도움이 됩니다.
   - **등록 질문** -- 선택 사항으로 [양식](../forms/creating-forms.md)을 첨부하여 등록자가 추가 질문(식이요법, T셔츠 사이즈, 응급 연락처 등)에 답하게 합니다. 질문을 건너뛰려면 **없음**을 선택합니다.
   - **대기자 목록 활성화** -- 이벤트가 가득 차면 추가 등록자가 거부되는 대신 대기자 목록에 참가할 수 있도록 합니다. [유료 등록](paid-registrations#waitlist)을 참조하세요.
4. 이벤트를 저장합니다.

유료 이벤트의 경우 동일한 설정 페이지에서 가격이 책정된 **참석자 유형**, 선택 사항인 **선택 사항**(추가 항목) 및 **할인 코드**를 정의하고, 교회의 기부 제공자를 통해 결제를 수집합니다. 전체 안내는 [유료 등록](paid-registrations)을 참조하세요.

등록이 활성화되면 회원이 [B1 웹사이트](../../b1-church/events/registering) 또는 [B1 모바일 앱](../../b1-mobile/events/registering)에서 이벤트를 볼 때 **이 이벤트에 등록** 버튼이 표시됩니다. 양식을 첨부한 경우 등록자는 등록 중에 **질문** 단계를 보게 되며 답변이 등록과 함께 저장됩니다.

:::info
등록 질문은 **제한됨**으로 표시되지 않은 양식에만 작동합니다. 제한된 양식은 등록 중에 표시되지 않고 자동으로 건너뛰므로, 이벤트에 질문을 첨부할 때는 제한되지 않은 양식을 사용하세요.
:::

### 등록 관리하기

이벤트의 등록을 보고 관리하려면:

1. Jump 메뉴에서 **달력 > 등록**을 선택합니다.
2. 등록이 활성화된 모든 이벤트의 테이블이 표시되며, 이벤트 제목, 날짜, 현재 등록 수 대 용량, 태그가 표시됩니다.
3. 이벤트를 클릭하면 이름, 회원 수, 참석자 유형, 결제 상태 및 등록 날짜를 포함한 전체 등록 목록이 표시됩니다.
4. 상세 페이지에서 다음을 할 수 있습니다:
   - **참석자 추가** -- 오프라인 또는 전화로 등록한 사람을 수동으로 등록합니다.
   - **취소** -- 개별 등록을 취소합니다.
   - **삭제** -- 등록을 영구적으로 삭제합니다.
   - **승격** -- 대기자 목록 등록을 승격합니다.
   - **CSV로 내보내기** -- 참석자 유형, 선택 사항, 결제 금액 및 답변을 포함한 모든 등록을 다운로드합니다.

이벤트에 등록 질문이 첨부된 경우 상세 페이지에도 답변하지 않은 등록자를 빠르게 찾기 위한 **답변하지 않은 질문만** 필터가 표시되며, 각 답변 등록의 **답변 보기** 버튼을 클릭하여 답변을 볼 수 있습니다. 유료 이벤트는 **유형** 열, **결제됨 / 합계** 열, 유형별 수 및 결제 상세 대화 상자를 추가합니다. [유료 등록](paid-registrations#the-registration-roster)을 참조하세요.

:::tip
용량 진행 표시줄을 사용하여 이벤트가 얼마나 빠르게 채워지는지 모니터링합니다. 이벤트가 용량에 도달하거나 초과하면 막대가 빨간색으로 변합니다.
:::
