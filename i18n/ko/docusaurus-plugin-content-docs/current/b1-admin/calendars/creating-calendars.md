# 달력 생성

<div class="article-intro">

B1 Admin에서 달력을 생성하면 하나 이상의 그룹을 연결하여 이벤트의 큐레이션된 보기를 구성할 수 있습니다. 이벤트는 그룹 리더가 각자의 그룹 내에서 관리하며, 달력은 해당 이벤트를 한 곳에 표시합니다. 편집 권한이 있는 관리자는 모든 그룹의 이벤트를 추가하거나 편집할 수 있습니다. 관리자가 아닌 그룹 리더는 본인이 이끄는 그룹의 이벤트만 관리할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 달력에 포함할 이벤트가 있는 [그룹](../groups/creating-groups.md)을 설정하세요
- B1 Admin의 달력 섹션에 대한 관리자 권한이 필요합니다

</div>

## 새 달력 생성하기

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **Calendars**를 펼친 다음 **Calendars**를 클릭합니다.
2. 페이지 상단의 **Add Calendar**를 클릭합니다. 새 달력 양식이 달력 목록 아래에 열립니다.
3. 달력의 **name**을 입력합니다(예: "Youth Ministry Events" 또는 "Main Church Calendar").
4. 선택 사항으로 **description**을 추가하여 팀이 이 달력의 용도를 이해하도록 돕습니다.
5. **Create**를 클릭하여 새 달력을 저장합니다.

## 달력 상세 페이지

달력을 만든 후 해당 행의 **Manage Events**를 클릭하면 상세 페이지가 열립니다. 이 페이지에는 두 개의 주요 영역이 있습니다:

- **왼쪽 열** -- 달력 이름과 작업 버튼(**New Event**, **Edit**, **Import .ics**, **Print**), 그리고 이 달력에 포함된 그룹을 보여 주는 **Groups in Calendar** 목록입니다. 그룹을 달력에서 제외하려면 해당 그룹 옆의 **Remove**를 클릭하세요.
- **주 영역** -- 연결된 그룹에서 가져온 이벤트를 보여 주는 **Calendar Events** 보기이며, 그 위에 **Subscribe**와 **Add Group** 버튼이 있습니다.

## 그룹 연결하기

달력에 이벤트가 있는 그룹은 상세 페이지 왼쪽의 **Groups in Calendar** 목록에 자동으로 나타납니다.

1. 달력 위의 **Add Group**을 클릭하여 그룹을 달력에 연결합니다.
2. 드롭다운에서 그룹을 선택합니다.
3. 해당 그룹의 **all events**(모든 이벤트)를 포함할지, 아니면 **specific events**(특정 이벤트)만 포함할지 선택합니다.
4. **Save**를 클릭합니다.

:::tip
그룹을 달력에 연결하면 이벤트를 자동으로 모을 수 있어 매우 유용합니다. 그룹 리더가 자신의 [그룹](../groups/creating-groups.md)에 이벤트를 추가하면, 별도의 작업 없이도 교회 전체 달력에 반영될 수 있습니다.
:::

:::info
여러 그룹의 이벤트를 모두 가져오는 하나의 달력을 만들고 싶다면, 간편한 방법인 [큐레이티드 달력](curated-calendar)을 참고하세요.
:::

## 이벤트 추가 및 편집 {#adding-and-editing-events}

달력 상세 페이지에서 **New Event**를 클릭하여 이벤트를 추가하거나, 달력에서 이벤트를 클릭한 다음 **Edit**를 클릭하여 수정합니다. **New Event** / **Edit Event** 양식에는 다음 필드가 있습니다:

- **Group** -- 이벤트가 속한 그룹입니다. 교회에 이벤트 템플릿이 있다면 **Template**을 선택하여 양식을 채울 수도 있습니다.
- **Title**
- **Event photo** -- **Add Photo**(또는 빈 사진 상자)를 클릭하여 이미지를 선택하거나 업로드합니다. 이미지는 가로 16:9 비율로 잘립니다. **Change Photo**를 클릭하면 교체할 수 있습니다. 사진은 웹사이트의 이벤트 페이지 상단에 표시되며, Calendar 요소가 **Upcoming events**를 보여 줄 때는 해당 타일로 표시됩니다([웹사이트에 이벤트 표시하기](#showing-events-on-your-website) 참고).
- **Description** -- 웹사이트의 이벤트 페이지에 표시됩니다. 굵은 글씨, 목록, 링크를 지원합니다.
- **Start**와 **End**, **Repeats**, 그리고 **Visibility**(**Public** 또는 **Private**).
- **Tags** -- `youth, students`처럼 쉼표로 구분된 라벨입니다. 웹사이트의 Calendar 요소는 특정 태그가 붙은 이벤트만 표시하도록 설정할 수 있습니다. 이 **Tags** 필드는 이벤트의 등록 설정에 표시되는 것과 같은 필드입니다.
- **Who can view notes**와 **Who can post notes** -- 이벤트 메모를 읽고 추가할 수 있는 사람입니다([이벤트 메모](#event-notes) 참고). **Staff only**(기본값), **Group leaders**(이벤트 그룹의 리더), **Group members**(이벤트 그룹의 모든 구성원, 리더 포함) 중에서 선택합니다.
- **Rooms**와 **Resources** -- 이벤트를 위한 공간과 장비를 예약합니다. [방, 리소스 및 일정 관리](rooms-resources)를 참고하세요.

**Save**를 클릭하세요. 이벤트가 반복되는 경우, 저장하면 시리즈의 모든 항목이 업데이트되므로 B1이 확인을 요청합니다.

### 이벤트 메모 {#event-notes}

각 이벤트에는 계획과 후속 조치를 위한 메모 스레드가 있습니다. 달력 상세 페이지에서 이벤트를 클릭하면 대화 상자에 이벤트의 세부 정보, 알림, 그리고 아래의 **Notes**가 표시됩니다. 메모를 입력하고 게시하면 스레드에 추가됩니다.

콘텐츠 편집 또는 달력 관리 권한이 있는 직원은 언제나 이벤트 메모를 읽고 게시할 수 있습니다. 이벤트의 **Who can view notes**와 **Who can post notes** 설정은 이벤트 그룹의 리더나 구성원도 같은 작업을 할 수 있는지 결정합니다.

### 웹사이트에 이벤트 표시하기 {#showing-events-on-your-website}

웹사이트에 달력을 게시하려면 페이지에 **Calendar** 요소를 추가하고 이 달력을 선택합니다. 이 요소는 월간 달력 또는 다가오는 이벤트 타일 격자를 표시할 수 있으며, 한 가지 태그가 붙은 이벤트로 제한할 수도 있습니다. 방문자가 이벤트를 클릭하면 해당 이벤트의 전용 페이지가 열립니다. [페이지 편집기의 Calendar 요소 사용하기](../website/page-editor.md#using-the-calendar-element)를 참고하세요.

## 이벤트 등록 사용하기 {#enabling-event-registration}

달력의 모든 이벤트에 대해 등록을 활성화하면, 교인들이 B1 웹사이트나 모바일 앱을 통해 신청할 수 있습니다.

1. 기존 이벤트를 클릭하거나 새 이벤트를 만듭니다.
2. 이벤트 편집기에서 **Registration**을 켜서 등록을 활성화합니다.
3. 등록 설정을 구성합니다:
   - **Capacity** (선택 사항) -- 최대 등록 인원을 설정합니다. 제한이 없다면 비워 두세요.
   - **Registration Opens** -- 등록이 시작되는 날짜와 시간입니다.
   - **Registration Closes** -- 등록이 마감되는 날짜와 시간입니다.
   - **Tags** -- 등록 가능한 이벤트를 분류하는 데 도움이 되는 쉼표로 구분된 라벨입니다(예: "youth, retreat, vbs").
   - **Registration Questions** -- 선택 사항으로 [양식](../forms/creating-forms.md)을 첨부하면, 등록자가 신청하면서 추가 질문(식이 제한, 티셔츠 사이즈, 비상 연락처 등)에 답할 수 있습니다. 질문을 생략하려면 **None**을 선택하세요.
   - **Enable Waitlist** -- 이벤트가 가득 찼을 때 추가 등록자를 거절하는 대신 대기자 명단에 등록하도록 합니다. [유료 등록의 대기자 명단](paid-registrations#waitlist)을 참고하세요.
4. 이벤트를 저장합니다.

유료 이벤트의 경우 같은 설정 페이지에서 가격이 지정된 **Attendee Types**(참석자 유형), 선택 사항인 **Selections**(추가 옵션), **Discount Codes**(할인 코드)를 정의할 수 있으며, 결제는 교회의 헌금 제공자를 통해 이루어집니다. 전체 과정은 [유료 등록](paid-registrations)을 참고하세요.

등록을 활성화하면 교인이 [B1 웹사이트](../../b1-church/events/registering) 또는 [B1 모바일 앱](../../b1-mobile/events/registering)에서 이벤트를 볼 때 **Register for this Event** 버튼이 표시됩니다. 양식을 첨부했다면 등록자는 등록 과정에서 **Questions** 단계를 거치며, 답변은 등록 정보와 함께 저장됩니다.

:::info
등록 질문은 **제한(Restricted)**이 설정되지 **않은** 양식에서만 작동합니다. 제한된 양식은 표시되지 않고 등록 과정에서 자동으로 건너뛰므로, 이벤트에 질문을 첨부할 때는 제한되지 않은 양식을 사용하세요.
:::

### 등록 관리하기

이벤트의 등록을 보고 관리하려면:

1. Jump 메뉴에서 **Calendars > Registrations**를 선택합니다.
2. 등록이 활성화된 모든 이벤트의 표가 나타나며, 이벤트 제목, 날짜, 현재 등록 인원 대 정원, 태그가 표시됩니다.
3. 이벤트를 클릭하면 이름, 구성원 수, 참석자 유형, 결제 상태, 등록 날짜를 포함한 전체 등록 목록을 볼 수 있습니다.
4. 상세 페이지에서 다음 작업을 할 수 있습니다:
   - **Add Attendee** -- 오프라인이나 전화로 신청한 사람을 수동으로 등록합니다.
   - 개별 등록을 **Cancel**(취소)합니다.
   - 등록을 영구적으로 **Delete**(삭제)합니다.
   - 자리가 생기면 대기자 명단의 등록을 **Promote**(승격)합니다.
   - **Export CSV** -- 참석자 유형, 선택 사항, 결제 금액, 질문 답변을 포함한 모든 등록 정보를 다운로드합니다.

이벤트에 등록 질문이 첨부되어 있으면 상세 페이지에 **Unanswered questions only** 필터가 표시되어, 아직 답변을 제출하지 않은 등록자를 빠르게 찾을 수 있습니다. 또한 답변한 각 등록에는 **View Answers** 버튼이 있어 응답을 볼 수 있습니다. 유료 이벤트에는 **Type** 열, **Paid / Total** 열, 유형별 인원 수, 결제 세부 정보 대화 상자가 추가됩니다. 자세한 내용은 [유료 등록의 등록 명단](paid-registrations#the-registration-roster)을 참고하세요.

:::tip
정원 진행 막대를 사용하면 이벤트가 얼마나 빠르게 차고 있는지 모니터링할 수 있습니다. 정원에 도달하거나 초과하면 막대가 빨간색으로 바뀝니다.
:::
