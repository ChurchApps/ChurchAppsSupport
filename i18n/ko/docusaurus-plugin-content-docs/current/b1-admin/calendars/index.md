# 캘린더

<div class="article-intro">

B1 Admin의 캘린더 섹션에서는 그룹의 이벤트를 모아 교회용 큐레이션 캘린더를 만들 수 있습니다. 그룹 리더는 자기 그룹의 이벤트를 관리하고, 관리자는 이 이벤트를 B1.church 웹사이트에 표시하는 캘린더를 만들어 성도들이 볼 수 있게 할 수 있습니다.

</div>

## 캘린더 보기 {#viewing-your-calendars}

1. B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **Calendars**를 펼친 뒤 **Calendars**를 클릭합니다.
2. Calendars 페이지에는 모든 캘린더가 이름과 상태와 함께 표로 나열됩니다. **Find a calendar** 상자로 목록을 거를 수 있습니다. 예약이나 이벤트 요청이 대기 중이면 페이지 상단의 **pending approvals** 링크가 [승인](./approvals.md) 페이지를 엽니다.
3. 행에 마우스를 올리면 캘린더를 여는 **Manage Events** 링크와, 이름을 바꾸거나 삭제할 수 있는 **Edit** 링크가 나타납니다.

Calendars 섹션과 그 안의 모든 페이지에는 **Edit Content** 권한이 필요합니다. **Calendars** 메뉴에는 **Calendars**, **Availability**, **Rooms & Resources**, **Approvals**, **Registrations**가 있습니다.

## 할 수 있는 일 {#what-you-can-do}

- **새 캘린더 추가** -- 페이지 상단의 **Add Calendar**를 클릭하여 특정 사역, 이벤트 유형, 목적을 위한 캘린더를 만듭니다. 단계별 안내는 [캘린더 만들기](./creating-calendars.md)를 참조하세요.
- **캘린더 편집** -- 아무 캘린더에서나 **Manage Events**를 클릭해 열고, 어떤 그룹이 포함되는지 관리합니다.
- **캘린더 게시** -- 캘린더를 B1.church 웹사이트에 표시하여 방문자가 교회의 다가오는 행사를 볼 수 있게 합니다.
- **큐레이션 캘린더 만들기** -- 여러 그룹의 이벤트를 하나의 캘린더 화면으로 모아 교회에서 진행되는 모든 일을 한눈에 볼 수 있게 합니다. 자세한 내용은 [큐레이션 캘린더](./curated-calendar.md)를 참조하세요.
- **공간과 자원 관리** -- 예약 가능한 공간과 장비를 추적하고 승인 요청을 처리합니다. 자세한 내용은 [공간 및 자원](./rooms-resources.md)을 참조하세요.
- **사용 가능 일정 보기** -- 모든 공간 및 자원 예약을 하나의 캘린더에서 보고, 다가오는 행사를 위해 공간을 예약합니다. 자세한 내용은 [사용 가능 일정 캘린더](./availability.md)를 참조하세요.
- **요청 승인** -- 공간, 자원, 이벤트 요청을 승인하거나 거절합니다. [캘린더 승인](./approvals.md)을 참조하세요.
- **등록 관리** -- 이벤트 등록을 켜고 누가 신청했는지 확인합니다. [이벤트 등록 켜기](./creating-calendars.md#enabling-event-registration)와 [유료 등록](./paid-registrations.md)을 참조하세요.

:::info
캘린더는 [그룹](../groups/creating-groups.md)과 밀접하게 연동됩니다. 그룹에 이벤트가 예정되어 있으면 그 이벤트를 캘린더로 가져올 수 있습니다. 그룹을 캘린더에 연결하는 방법은 [캘린더 만들기](./creating-calendars.md) 페이지를 참조하세요.
:::
