# 달력

<div class="article-intro">

B1 Admin의 달력 섹션을 사용하면 그룹의 이벤트를 함께 가져와 교회를 위한 큐레이션된 달력을 생성할 수 있습니다. 그룹 리더는 자신의 그룹의 이벤트를 관리하고, 관리자로서 B1.church 웹사이트에 표시할 이벤트 달력을 구성할 수 있습니다.

</div>

## 달력 보기

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **달력**을 확장한 후 **달력**을 클릭합니다.
2. 달력 페이지에 모든 달력의 이름과 상태가 나열됩니다.
3. 각 달력은 연결된 그룹도 표시합니다.

## 할 수 있는 작업

- **새 달력 추가** -- 추가 버튼을 클릭하여 특정 사역, 이벤트 유형 또는 목적의 달력을 생성합니다. 단계별 지침은 [달력 생성](creating-calendars)을 참조하세요.
- **달력 편집** -- 모든 달력을 클릭하여 열고 달력에 포함된 그룹을 관리합니다.
- **달력 발행** -- 달력을 B1.church 웹사이트에 표시하여 방문자가 교회의 예정된 이벤트를 볼 수 있습니다.
- **큐레이션된 달력 생성** -- 여러 그룹의 이벤트를 단일 달력 보기로 가져와 교회에서 일어나는 모든 것을 포괄적으로 확인합니다. 자세한 내용은 [큐레이션된 달력](curated-calendar)을 참조하세요.
- **방 및 리소스 관리** -- 예약 가능한 공간과 장비를 추적하고 승인 요청을 처리합니다. 자세한 내용은 [방 & 리소스](rooms-resources)를 참조하세요.
- **가용성 보기** -- 모든 방과 리소스 예약을 단일 달력에서 보고 예정된 이벤트를 위한 공간을 예약합니다. [가용성 달력](availability)을 참조하세요.

:::info
달력은 [그룹](../groups/creating-groups.md)과 밀접하게 작동합니다. 그룹이 이벤트를 예약하면 해당 이벤트를 달력에 가져올 수 있습니다. [달력 생성](creating-calendars) 페이지를 참조하여 그룹을 달력에 연결하는 방법을 배우세요.
:::
