# 큐레이션된 달력

<div class="article-intro">

큐레이션된 달력은 여러 그룹의 이벤트를 하나의 통합 달력 보기로 집계합니다. 이는 교회 전체의 달력을 생성하여 모든 사역과 그룹에서 일어나는 모든 것을 한 곳에 표시하는 데 이상적입니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 포함할 이벤트가 있는 [그룹](../groups/creating-groups.md)을 설정하세요
- 그룹 리더가 각각의 그룹에 이벤트를 추가했는지 확인하세요
- [달력 생성](creating-calendars)의 기본 사항을 숙지하세요

</div>

## 큐레이션된 달력 생성하기

1. B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **달력**을 확장한 후 **달력**을 클릭합니다.
2. **달력 추가**를 클릭하여 새 큐레이션된 달력을 생성합니다.
3. 달력에 **이름**을 지정합니다(예: "교회 이벤트" 또는 "이번 주 우리 교회").
4. **만들기**를 클릭하여 저장합니다.

## 달력에 그룹 추가하기

1. 새 달력을 클릭하여 엽니다.
2. 오른쪽의 **달력의 그룹** 섹션에서 **추가**를 클릭합니다.
3. 드롭다운 메뉴에서 그룹을 선택합니다.
4. 해당 그룹의 **모든 이벤트**를 추가할지 **특정 이벤트**만 추가할지 선택합니다.
5. **저장**을 클릭합니다.
6. 포함하려는 만큼의 그룹을 추가하려면 이 과정을 반복합니다.

:::tip
모든 활성 사역 그룹을 추가하여 교회에서 매주 일어나는 일에 대한 전체 그림을 회중에게 제공하는 포괄적인 달력을 만드세요.
:::

## 달력 공유하기

큐레이션된 달력이 설정되면 여러 방법으로 공유할 수 있습니다:

- **웹사이트에 삽입** -- 달력을 B1.church 웹사이트 페이지에 직접 표시하여 방문자가 열람할 수 있습니다.
- **ICS를 통해 구독** -- **구독**을 클릭하여 ICS 링크를 복사합니다. 회중이 이 링크를 Google 캘린더, Apple 캘린더, Outlook 또는 기타 캘린더 앱에 붙여넣어 동기화 상태로 유지할 수 있습니다.
- **ICS 파일 다운로드** -- 달력 파일을 다운로드하여 캘린더 애플리케이션으로 가져옵니다.

:::info
그룹 리더가 [그룹](../groups/creating-groups.md)에 새 이벤트를 추가하면 해당 이벤트가 큐레이션된 달력에 자동으로 나타납니다. 새 이벤트가 추가될 때마다 큐레이션된 달력을 수동으로 업데이트할 필요가 없습니다.
:::
