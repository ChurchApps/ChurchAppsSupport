# 가용성 달력

<div class="article-intro">

가용성 달력은 교회 전체의 모든 객실 및 리소스 예약의 조감도를 제공합니다. 여기서 예약된 내용을 볼 수 있고, 충돌이 발생하기 전에 발견하고, 모든 이벤트에 대해 직접 객실이나 리소스를 예약할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 객실 및 리소스 섹션에서 최소 하나의 [객실 또는 리소스](rooms-resources)를 설정합니다
- B1 Admin의 달력 섹션에 대한 편집 액세스가 필요합니다

</div>

## 가용성 달력 열기

B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색 표시줄)를 열고 **달력**을 확장하여 **가용성**을 클릭합니다.

## 달력 읽기

달력은 기본적으로 현재 월을 표시합니다. 맨 위의 화살표로 앞뒤로 이동하거나 월, 주 및 일 보기 간에 전환할 수 있습니다.

각 이벤트는 예약 상태별로 색상으로 코딩됩니다:

| 색상 | 의미 |
|-------|---------|
| 녹색 | 승인됨 |
| 주황색 | 승인 보류 중 |
| 회색 | 차단됨(사용 불가) |

이벤트 위에 마우스를 올리면 이벤트 제목과 이벤트가 첨부된 객실 또는 리소스가 표시됩니다.

## 객실 또는 리소스별로 필터링

왼쪽 상단의 **필터** 드롭다운을 사용하여 달력을 단일 객실 또는 리소스로 좁힙니다. **모든 객실 및 리소스**를 선택하여 전체 보기로 돌아갑니다.

## 객실 또는 리소스 예약

1. 페이지의 오른쪽 상단 모서리에서 **예약** 버튼을 클릭합니다.
2. 열리는 대화에서 이벤트 세부 정보를 작성합니다:
   - **제목** — 이벤트의 이름
   - **시작** 및 **종료** 날짜/시간
   - **가시성** — 공개 또는 비공개
   - **객실** — 예약할 객실 하나 이상을 선택합니다
   - **리소스** — 예약할 리소스 하나 이상을 선택합니다
3. 선택적으로 **설정** 및 **해제** 시간(분)을 설정합니다. 이는 이벤트 시작/종료 시간이 동일하게 유지되더라도 설정 및 정리를 위해 공간이 예약되도록 양쪽 끝의 예약을 패딩합니다.
4. 예약을 반복하려면 **반복**을 확인하고 반복을 구성합니다:
   - **반복 간격** -- 간격을 설정합니다(예: 2주마다).
   - **빈도** -- 매일, 매주 또는 매월. 매주는 요일을 특정할 수 있습니다; 매월은 고정 날짜 또는 "두 번째 화요일"과 같은 상대 패턴을 선택할 수 있습니다.
   - **종료** -- 안 함, 특정 날짜 또는 설정된 수의 발생 후.
5. 사용자 정의 예약 기간을 지정하려면(이벤트 시작/종료와 다르게) **사용자 정의 예약 기간**을 토글하고 기간 시작 및 종료 시간을 입력합니다. 객실이 이벤트의 나열된 시간 외에 액세스할 수 있어야 할 때 이를 사용합니다.
6. **저장**을 클릭하여 예약을 제출합니다.

:::info
객실이나 리소스에 **승인 그룹**이 구성된 경우 예약은 해당 그룹의 리더가 승인할 때까지 **보류 중**으로 나타납니다. 승인 워크플로는 [달력 승인](approvals)을 참조합니다.
:::

:::tip
달력은 저장하기 전에 충돌을 강조 표시합니다. 충돌 경고가 표시되면 시간을 조정하거나 다른 객실을 선택합니다.
:::
