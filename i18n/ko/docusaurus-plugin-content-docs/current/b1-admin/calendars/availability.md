# 가용성 달력

<div class="article-intro">

가용성 달력은 교회 전체의 모든 방과 자원 예약을 한눈에 볼 수 있습니다. 예약된 내용을 확인하고, 충돌이 생기기 전에 발견하고, 모든 행사를 위해 방이나 자원을 직접 예약할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 방과 자원 섹션에서 최소 하나의 [방이나 자원](rooms-resources)을 설정합니다
- B1 Admin의 달력 섹션에 대한 편집 액세스 권한이 필요합니다

</div>

## 가용성 달력 열기

B1 Admin에서 **섹션 메뉴**를 열고 **달력**을 선택한 후 **가용성**을 선택합니다.

## 달력 읽기

달력은 기본적으로 현재 월을 표시합니다. 위의 화살표로 앞뒤로 이동하거나 월, 주, 일 보기 사이에 전환할 수 있습니다.

각 행사는 예약 상태에 따라 색상이 지정됩니다:

| 색상 | 의미 |
|---|---|
| 초록색 | 승인됨 |
| 주황색 | 승인 대기 중 |
| 회색 | 차단됨 (사용 불가) |

행사를 마우스로 가리키면 행사 제목과 연결된 방 또는 자원이 표시됩니다.

## 방 또는 자원별로 필터링

페이지의 왼쪽 위에 있는 **필터** 드롭다운을 사용하여 달력을 단일 방 또는 자원으로 좁힙니다.

## 방 또는 자원 예약

1. 페이지의 오른쪽 위 **예약** 버튼을 클릭합니다.
2. 열리는 대화에서 행사 세부 정보를 입력합니다.
3. 선택적으로 **설정** 및 **정리** 시간(분)을 설정합니다.
4. 예약을 반복하려면 **반복**을 선택합니다.
5. **커스텀 예약 기간**을 전환하여 별도의 시간을 지정할 수 있습니다.
6. **저장**을 클릭하여 예약을 제출합니다.

:::info
방 또는 자원에 **승인 그룹**이 구성되어 있으면, 예약은 **대기**로 표시됩니다.
:::

:::tip
달력은 저장하기 전에 충돌을 강조합니다.
:::
