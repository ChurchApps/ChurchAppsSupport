# 가용성 일정

<div class="article-intro">

가용성 일정을 통해 교회 전체의 모든 객실 및 자원 예약을 한눈에 볼 수 있습니다. 여기에서 예정된 항목을 확인하고, 발생 전에 충돌을 발견하고, 모든 이벤트에 대해 직접 객실 또는 자원을 예약할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 객실 및 자원 섹션에서 최소 하나의 [객실 또는 자원](rooms-resources) 설정
- B1 Admin의 일정 섹션에 대한 편집 액세스 필요

</div>

## 가용성 일정 열기

B1 Admin에서 왼쪽 상단의 **섹션 메뉴**를 열고 **일정**을 선택한 후 **가용성**을 선택합니다.

## 일정 읽기

일정은 기본적으로 현재 월을 표시합니다. 맨 위의 화살표로 앞뒤로 이동하거나 월, 주, 일 보기 사이를 전환할 수 있습니다.

각 이벤트는 예약 상태별로 색상 코딩됩니다:

| 색상 | 의미 |
|-------|---------|
| 녹색 | 승인됨 |
| 주황색 | 승인 보류 중 |
| 회색 | 차단됨(사용 불가) |

이벤트 위에 마우스를 올리면 이벤트 제목과 연결된 객실 또는 자원이 표시됩니다.

## 객실 또는 자원별 필터링

맨 위 왼쪽의 **필터** 드롭다운을 사용하여 일정을 단일 객실 또는 자원으로 좁힙니다. **모든 객실 및 자원**을 선택하여 전체 보기로 돌아갑니다.

## 객실 또는 자원 예약

1. 페이지 오른쪽 상단의 **예약** 버튼을 클릭합니다.
2. 열리는 대화 상자에서 이벤트 세부 정보를 입력합니다:
   - **제목** — 이벤트의 이름
   - **시작** 및 **종료** 날짜/시간
   - **표시 여부** — 공개 또는 비공개
   - **객실** — 예약할 하나 이상의 객실 선택
   - **자원** — 예약할 하나 이상의 자원 선택
3. 선택적으로 **설정** 및 **정리** 시간(분)을 설정합니다. 이는 이벤트 시작/종료 시간이 동일하게 유지되는 동안 설정 및 정리를 위해 공간이 예약되도록 양쪽 끝에 패딩을 추가합니다.
4. 예약을 반복하려면 **반복**을 확인하고 반복을 구성합니다:
   - **매 반복** -- 간격 설정(예: 매 2주마다).
   - **빈도** -- 일일, 주간 또는 월간. 주간을 선택하면 특정 요일을 선택할 수 있습니다. 월간을 선택하면 월의 고정 날짜 또는 "두 번째 화요일"과 같은 상대 패턴을 선택할 수 있습니다.
   - **종료** -- 절대 안함, 특정 날짜에 또는 설정된 발생 수 후.
5. 이벤트 시작/종료와 다른 사용자 정의 예약 창을 지정하려면 **사용자 정의 예약 창**을 전환하고 창 시작 및 종료 시간을 입력합니다. 이벤트의 나열된 시간 외에 객실에 액세스할 수 있어야 할 때 이를 사용합니다.
6. **저장**을 클릭하여 예약을 제출합니다.

:::info
객실 또는 자원에 **승인 그룹**이 구성된 경우 예약이 해당 그룹의 지도자가 승인할 때까지 **보류 중**으로 나타납니다. 승인 워크플로우는 [일정 승인](approvals)을 참조하세요.
:::

:::tip
일정은 저장하기 전에 충돌을 강조 표시합니다. 충돌 경고가 보이면 시간을 조정하거나 다른 객실을 선택하세요.
:::
