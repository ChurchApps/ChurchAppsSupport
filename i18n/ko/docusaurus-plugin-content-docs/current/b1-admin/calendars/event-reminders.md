# 이벤트 미리알림

<div class="article-intro">

이벤트 미리알림은 이벤트가 발생하기 전에 올바른 사람들에게 자동으로 알립니다 — 예를 들어 "놓치지 마세요! 의료 워크샵은 내일 오전 9:00에 시작합니다." 이벤트에 한 번 미리알림을 구성하면 B1은 푸시 알림 및 이메일을 통해 일정에 따라 보냅니다. 구성원은 자신의 [알림 기본 설정](../../b1-church/getting-started/notification-preferences)에서 받는 미리알림을 제어할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 미리알림할 이벤트 만들기([일정 생성](creating-calendars) 참조)
- 등록된 참석자에게 도달하려면 이벤트에서 [등록 활성화](creating-calendars)
- 전체 그룹에 도달하려면 이벤트가 구성원이 있는 [그룹](../groups/creating-groups)에 속하는지 확인

</div>

## 미리알림 설정

미리알림을 이벤트의 **미리알림** 섹션에서 구성합니다.

- **새 이벤트를 만들** 때 저장하기 전에 이벤트 편집기의 **미리알림** 섹션을 확장합니다.
- **기존 이벤트**의 경우 이벤트의 **등록 세부 정보** 페이지를 열어(**등록** 섹션에서) 미리알림을 추가하거나 변경합니다.

1. **미리알림 활성화** 켜기.
2. 보낼 시기 **언제** 선택합니다. 최대 3개의 타이밍을 선택합니다: **7일 전**, **3일 전**, **1일 전** 및 **당일**.
3. 미리알림이 나가야 할 **하루 중 시간** 설정(기본값은 교회의 현지 시간대에서 **오전 9:00**)
4. **누가** 미리알림을 받아야 하는지 선택합니다(아래의 [누가 미리알림을 받는지](#누가-미리알림을-받는지) 참조).
5. 선택적으로 **메시지**를 추가합니다. 기본 문구를 사용하려면 빈 상태로 두거나 자신의 문구를 작성하세요 — `{{eventTitle}}`을 포함할 수 있으며 이벤트 이름으로 바뀝니다.
6. **채널** 선택: **푸시** 알림, **이메일** 또는 둘 다.
7. 이벤트를 저장합니다.

변경을 수행하면 **라이브 미리보기**는 미리알림을 받을 약 인원, 도달할 수 없는 참석자의 수, 다음 예정된 전송 시간을 보여줍니다 — 저장하기 전에 미리알림이 올바르게 보이도록 확인할 수 있습니다.

## 누가 미리알림을 받는지

**누가** 설정은 미리알림이 누구에게 가는지 제어합니다:

- **등록자만** -- 이벤트에 등록되고 사람 기록에 연결된 모든 사람. 이벤트에 등록이 활성화된 경우 기본값이므로 등록된 작은 이벤트에 대한 미리알림이 전체 그룹에 실수로 가지 않습니다.
- **가장(가족대표) / 등록자만** -- 등록자당 하나의 미리알림(등록한 사람)이 아닌 등록의 모든 가족 구성원.
- **그룹 구성원** -- 이벤트의 그룹의 모든 사람. 이벤트가 등록을 사용하지 않을 때 기본값입니다.
- **자동** -- 등록이 활성화되면 등록자를 사용하고, 그렇지 않으면 그룹을 사용합니다.

:::info
이름만으로 추가된 손님(연결된 사람 기록 없음)은 계정, 기기 또는 보낼 이메일이 없기 때문에 미리알림을 받을 수 없습니다. 미리보기는 이 그룹에 해당하는 참석자의 수를 알려주어 놀랄 일이 없도록 합니다. 통신을 거부한 구성원도 건너뜁니다.
:::

## 미리알림을 보낼 시기

- 미리알림은 선택한 시간대의 **시간**에 화재합니다(교회의 현지 시간대로) 선택한 각 오프셋에 대합니다.
- 이벤트의 날짜 또는 시간을 **변경**하면 보류 중인 미리알림이 자동으로 다시 예약됩니다 — 미리알림을 편집할 필요가 없습니다.
- 이벤트를 **삭제**하거나(또는 반복 이벤트의 단일 발생을 취소) 보류 중인 미리알림이 자동으로 취소됩니다.
- 반복 이벤트는 자동으로 처리됩니다: 각 예정된 발생은 자체 미리알림을 받습니다.

:::tip
미리알림은 **먼저 푸시를 보낸 후 이메일로 폴백**됩니다. 구성원이 푸시 알림을 활성화했다면 푸시를 받습니다; 그렇지 않으면 대신 이메일을 받습니다. 구성원은 [알림 기본 설정](../../b1-church/getting-started/notification-preferences)에서 알림 유형별로 원하는 채널을 선택합니다.
:::

## 구성원이 제어할 수 있는 항목

미리알림은 항상 각 구성원의 [알림 기본 설정](../../b1-church/getting-started/notification-preferences)을 존중합니다. 구성원은 다음을 수행할 수 있습니다:

- 다른 알림을 켜두면서 푸시 또는 이메일에 대해 **이벤트 미리알림**을 끕니다.
- **조용한 시간**을 설정하여 긴급하지 않은 알림이 합리적인 시간까지 기다리도록 합니다.

구성원이 이벤트 미리알림 거부를 선택하는 것을 재정의할 수 없습니다 — 이는 B1을 스팸 방지 규칙을 준수하게 유지하고 구성원이 받은 편지함을 제어하게 합니다.

## 봉사 미리알림

계획에 예약된 자원봉사자는 계획 세부 정보가 포함된 별도의 **봉사 미리알림**과 아직 응답하지 않은 경우 **수락 / 거부** 버튼이 이메일에 바로 표시되는 것을 받습니다. 이러한 미리알림은 일정 이벤트가 아닌 계획 유형에서 구성됩니다 — 자원봉사자 일정 및 미리알림 작동 방식은 [주일 자원봉사자](../guides/sunday-volunteers)를 참조하세요.
