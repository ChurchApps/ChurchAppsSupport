# 그룹

<div class="article-intro">

**그룹** 섹션에서는 교회 구성원을 사역, 소그룹, 성경 공부, 위원회 등으로 정리할 수 있습니다. 그룹은 교회 공동체 생활의 중추이며, 이 섹션은 모든 그룹을 한곳에서 만들고, 관리하고, 소통하는 도구를 제공합니다. **팀(Teams**)은 그룹과 별개라는 점에 유의하세요. 팀은 봉사와 자원봉사자 일정을 위해 사용합니다.

</div>

## 개요 {#overview}

그룹은 **분류(category**)별로 정리됩니다. 분류는 "Small Groups", "Ministries", "Committees"처럼 최상위 라벨입니다. 각 분류에는 여러 그룹이 들어갈 수 있으므로, 관련 그룹을 함께 두기 쉽습니다.

Groups 페이지를 열면 **Search groups...** 상자, 분류 버튼 줄, 그룹 표가 나타납니다. 각 그룹은 이름 아래에 분류와 라벨이 표시되며, 구성원 수도 함께 나옵니다. 검색 상자에 입력하면 이름이나 분류로 그룹을 찾을 수 있습니다. **All** 또는 분류 이름을 클릭하면 목록을 거를 수 있으며(추가 분류는 **More categories** 아래에 있습니다), **Name** 또는 **People** 열 머리글을 클릭하면 정렬됩니다. 모든 그룹을 다시 보려면 **Clear filters**를 클릭하세요.

페이지 머리글에는 이 섹션의 나머지 기능을 위한 버튼이 있습니다.

- **Group Health** -- 모든 그룹의 구성원과 출석을 비교합니다. [그룹 건강도](./groups-health.md)를 참조하세요.
- **pending requests**(예: "2 pending requests") -- 그룹 가입을 기다리는 사람이 있을 때 나타납니다. [그룹 가입 요청](./group-join-requests.md#for-administrators)을 참조하세요.
- **Export** -- 그룹 목록을 CSV 파일로 내려받습니다.
- **Add Group** -- 그룹을 만듭니다. [그룹 만들기](./creating-groups.md)를 참조하세요.

## 할 수 있는 일 {#what-you-can-do}

그룹 섹션에서 할 수 있는 일은 다음과 같습니다.

1. **그룹 만들기와 정리** -- 교회의 구조를 반영하도록 분류 안에 새 그룹을 추가합니다. [그룹 만들기](./creating-groups.md)를 참조하세요.

2. **그룹 구성원 관리** -- 구성원을 추가하고 제거하며, 리더를 지정하고, 그룹과 소통합니다. [그룹 구성원](./group-members.md)을 참조하세요.

3. **행사 일정 잡기** -- 각 그룹은 모임, 행사, 정기 활동을 위한 자체 캘린더를 가질 수 있습니다. [그룹 캘린더](./group-calendar.md)를 참조하세요.

4. **가입 요청 관리** -- 그룹이 **Request**(요청) 가입 정책을 사용하면, 가입을 원하는 사람들의 요청을 검토하고 승인하거나 거절합니다. [그룹 가입 요청](./group-join-requests.md)을 참조하세요.

5. **그룹 데이터 내보내기** -- 어떤 그룹이든 구성원 목록을 CSV 파일로 내려받아 스프레드시트나 우편물에 사용할 수 있습니다. 내보내기 방법은 [그룹 구성원](./group-members.md#exporting-group-data)을 참조하세요.

6. **그룹 건강도 확인** -- 모든 그룹의 성장, 이탈, 출석을 하나의 표에서 봅니다. [그룹 건강도](./groups-health.md)를 참조하세요.

## 시작하기 {#getting-started}

그룹에 접근하려면 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 상단의 검색창)를 열고 **People**을 펼친 뒤 **Groups**를 클릭하세요. 기존 그룹이 모두 나타나며, 분류별로 거를 수 있습니다.

:::tip
처음 시작한다면 교회 구조에 맞는 분류를 몇 개 만드는 것부터 하세요(예: "Ministries", "Small Groups", "Committees"). 그다음 각 분류 안에 개별 그룹을 추가하세요. 단계별 안내는 [그룹 만들기](./creating-groups.md)를 참조하세요.
:::

:::info
그룹 구성원은 그룹에 추가되기 전에 먼저 [사람(People)](../people/adding-people.md) 디렉터리에 있어야 합니다. B1을 처음 설정한다면 그룹을 만들기 전에 [구성원 데이터를 가져오세요](../people/importing-data.md).
:::
