# 그룹

<div class="article-intro">

**그룹** 섹션을 통해 교회 신도를 사역, 소그룹, 성경 공부, 위원회 등으로 조직할 수 있습니다. 그룹은 교회의 공동 체 삶의 근본이며 이 섹션은 한 곳에서 모든 그룹을 생성, 관리 및 소통할 수 있는 도구를 제공합니다. **팀**은 그룹과 별개입니다. 팀은 사역 및 자원봉사 일정 계획에 사용됩니다.

</div>

## 개요

그룹은 **범주**로 조직됩니다. 범주는 "소그룹", "사역" 또는 "위원회"와 같은 최상위 레이블입니다. 각 범주는 여러 그룹을 포함할 수 있으므로 관련 그룹을 함께 유지하기가 간단합니다.

그룹 페이지를 열면 상단에 다음을 표시하는 요약이 표시됩니다:

- **전체 그룹** -- 모든 범주 전체의 그룹 수
- **범주** -- 생성한 그룹 범주 수
- **전체 회원** -- 모든 그룹 전체 회원의 총합계

요약 아래는 그룹이 범주별로 나열되며 각 그룹의 회원 수가 표시됩니다.

## 수행할 수 있는 작업

그룹 섹션에서 수행할 수 있는 작업은 다음과 같습니다:

1. **그룹 생성 및 조직** -- 교회 구조를 반영하는 범주 내에 새 그룹을 추가합니다. [그룹 생성](./creating-groups.md) 참조.

2. **그룹 회원 관리** -- 회원을 추가 및 제거하고, 리더를 지정하고, 그룹과 소통합니다. [그룹 회원](./group-members.md) 참조.

3. **이벤트 일정 계획** -- 각 그룹은 만남, 이벤트 및 정기 활동을 위한 자체 달력을 가질 수 있습니다. [그룹 달력](./group-calendar.md) 참조.

4. **합류 요청 관리** -- 그룹이 **요청** 합류 정책을 사용할 때 합류하고 싶은 사람들의 들어오는 회원 요청을 검토하고 승인하거나 거부합니다. [그룹 합류 요청](./group-join-requests.md) 참조.

5. **그룹 데이터 내보내기** -- 아무 그룹의 회원 목록을 스프레드시트나 우편 발송에 사용할 수 있는 CSV 파일로 다운로드합니다. [그룹 회원](./group-members.md)의 내보내기 지침을 참조.

## 시작하기

그룹에 액세스하려면 B1 Admin 대시보드의 왼쪽 위 모서리에서 **섹션 메뉴**를 열고 **사람**을 선택한 다음 탐색 표시줄에서 **그룹** 탭을 클릭합니다. 범주별로 조직된 모든 기존 그룹이 표시됩니다.

:::tip
방금 시작하는 경우 교회 구조와 일치하는 몇 가지 범주(예: "사역", "소그룹", "위원회")를 만드는 것으로 시작합니다. 그런 다음 각 범주 내에 개별 그룹을 추가합니다. [그룹 생성](./creating-groups.md)에서 단계별 안내를 참조.
:::

:::info
그룹 회원은 먼저 [사람](../people/adding-people.md) 디렉토리에 존재해야 그룹에 추가할 수 있습니다. B1을 처음 설정하는 경우 그룹을 생성하기 전에 [회원 데이터를 가져오세요](../people/importing-data.md).
:::
