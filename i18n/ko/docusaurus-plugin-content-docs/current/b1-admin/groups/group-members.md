# 그룹 구성원

<div class="article-intro">

그룹을 만든 다음에는 구성원을 추가해야 합니다. 그룹의 상세 페이지에서 사람을 검색하고, 그룹에 추가하고, 리더를 지정하고, 메시지를 보내고, 구성원 명단을 내보낼 수 있습니다. 구성원 관리는 소그룹, 위원회, 반을 운영하는 데 필수적입니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin에 그룹이 하나 이상 설정되어 있어야 합니다. 아직 그룹을 만들지 않았다면 [그룹 만들기](creating-groups.md)를 참고하세요.
- 추가하려는 사람이 [사람](../people/adding-people.md) 목록에 이미 있어야 합니다. 없다면 아래의 구성원 검색 기능에서 직접 만들 수 있습니다.

</div>

## 그룹에 구성원 추가하기

1. [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)에서 **People > Groups**를 선택하고 관리하려는 그룹을 클릭합니다.
2. 그룹 페이지의 **Members** 섹션에서 **All members**를 클릭합니다. (팀과 사역 그룹은 바로 구성원 목록이 열립니다.)
3. 구성원 목록 아래의 **Add Person** 상자에 추가하려는 사람의 이름을 입력하고 **Enter**를 누르거나 검색 아이콘을 클릭합니다.
4. 검색 결과에서 사람의 이름이나 옆의 추가 아이콘을 클릭합니다.
5. 해당 사람이 그룹 구성원 목록에 나타납니다.

:::tip
아무것도 입력하기 전에도 **Add Person** 상자에 **최근 사람(Recent people)** 목록이 짧게 표시되어 클릭 한 번으로 바로 추가할 수 있습니다.
:::

작업을 마치면 그룹 이름이 있는 **Back to** 링크를 클릭하여 그룹 페이지로 돌아갑니다. 그룹 페이지에는 **Members**, **Sessions**, **Calendar**, **Health**에 대한 요약이 표시되며, 각 항목마다 전체 화면으로 이동하는 링크가 있습니다.

### 아직 B1에 없는 사람 추가하기

검색 결과가 없으면 **No records found** 메시지와 함께 **Add New Person** 링크가 나타납니다. 이를 클릭하고 사람의 이름, 성, 그리고 (선택 사항으로) 이메일을 입력한 다음 **Add**를 클릭하세요. 새 사람은 People 목록에 만들어지고 한 번에 그룹에 추가됩니다. 따로 다시 검색할 필요가 없습니다.

## 그룹 리더 지정하기

그룹 리더에게는 특별한 권한이 있습니다. 리더는 [그룹 캘린더](group-calendar.md)를 편집하고, 행사를 관리하며, 그룹 운영을 돕습니다.

1. 그룹 구성원 목록에서 리더로 지정할 사람을 찾습니다.
2. 이름 옆의 **별 아이콘**(**Make Leader**)을 클릭합니다.
3. 해당 사람이 그룹 리더로 지정되며 **Leader** 배지가 표시됩니다.

리더 권한을 해제하려면 별 아이콘(**Remove Leader Access**)을 다시 클릭합니다.

:::info
모든 그룹 구성원은 그룹 캘린더와 행사를 볼 수 있지만, 캘린더 행사를 추가하거나 편집할 수 있는 사람은 리더뿐입니다.
:::

## 그룹 구성원에게 메시지 보내기

B1 Admin에서 그룹의 모든 구성원에게 직접 연락할 수 있습니다.

1. 그룹의 구성원 목록 위에 있는 **Send a message to members** 아이콘을 클릭합니다.
2. 텍스트 상자에 메시지를 입력하거나(또는 **Templates**에서 하나를 고릅니다).
3. **Send**를 클릭합니다.

메시지는 그룹의 모든 구성원에게 전달됩니다.

## 그룹 구성원에게 이메일 보내기

그룹의 모든 구성원에게 서식이 적용된 이메일을 보낼 수 있습니다.

1. 그룹 상세 페이지에서 페이지 왼쪽의 **Email** 버튼을 클릭합니다.
2. Send Email 대화상자가 열리며, 이메일을 받을 구성원 수와 등록된 이메일 주소가 없는 구성원 수가 표시됩니다.
3. 선택 사항으로 드롭다운에서 **이메일 템플릿**을 고르거나 처음부터 메시지를 작성합니다. 템플릿을 만들거나 편집하려면 **Manage Templates**를 클릭하세요.
4. **제목(subject line)**을 입력합니다. 필드 칩을 클릭하여 병합 필드를 삽입할 수 있습니다: `{{firstName}}`, `{{lastName}}`, `{{displayName}}`, `{{email}}`, `{{churchName}}`.
5. HTML 편집기를 사용하여 **이메일 본문**을 작성합니다. 같은 병합 필드를 여기서도 사용할 수 있습니다.
6. **Send**를 클릭합니다.
7. 요약 화면에 이메일이 성공적으로 발송된 수와 건너뛴 구성원 수(등록된 이메일 없음)가 표시됩니다.

:::tip
주간 소식, 행사 공지, 기도 요청처럼 반복되는 메시지에는 재사용 가능한 이메일 템플릿을 만들어 두세요. 템플릿은 시간을 절약하고 메시지의 일관성을 유지하는 데 도움이 됩니다.
:::

### 교회의 그룹 이메일 사용 설정하기

B1의 모든 교회는 같은 주소에서 이메일을 보내므로 발신 평판을 함께 공유합니다. 모든 교회의 이메일이 스팸 폴더로 가지 않도록, ChurchApps 팀은 그룹 이메일을 보내기 전에 각 교회를 한 번씩 검토합니다.

교회가 아직 검토를 받지 않았다면 Send Email 대화상자에 메시지 편집기 대신 **Group email needs a quick review**가 표시됩니다.

1. **Request review**를 클릭합니다. ChurchApps 지원팀에 알림이 전달됩니다.
2. 대화상자가 **Review requested**로 바뀝니다. 이제 대화상자를 닫으셔도 됩니다.
3. 그룹 이메일은 보통 영업일 하루 이내에 사용 설정됩니다. 그 후 Send Email 대화상자를 다시 열어 메시지를 보내세요.

교회가 승인을 받기 전까지 B1은 [양식 후속 이메일](../forms/creating-forms.md#sending-a-follow-up-email)이나 [워크플로](../serving/workflows.md)의 **Send email** 단계도 발송하지 않습니다.

:::info 발송 한도
승인을 받은 후 교회는 하루에 교회가 직접 작성한 이메일을 최대 150통까지 보낼 수 있습니다. 깨끗한 발송 이력을 쌓으면 한도가 늘어나며, 최대 하루 2,000통까지 올라갑니다. 최근 메시지가 반송되거나 스팸으로 신고된 경우 그룹 이메일 발송이 일시 중지되고, 대화상자에서 지원팀에 문의하라는 안내가 표시됩니다. 발송이 일일 한도를 넘게 되면 B1은 해당 메일을 보내지 않고 오류를 표시합니다.
:::

## 그룹 구성원에게 문자 보내기

교회가 [문자 발송 서비스](../settings/church-settings.md#texting)를 연결하면, 그룹 페이지의 **Email** 버튼 옆에 **Text** 버튼(**Text this group**)이 나타납니다.

1. 그룹 상세 페이지에서 **Text**를 클릭합니다.
2. 대화상자에 문자를 받을 구성원 수가 표시됩니다. 휴대폰 번호가 없거나 수신을 거부한 구성원은 건너뜁니다.
3. 메시지를 입력합니다. 개인화하려면 메시지 상자 아래의 자리표시자 칩 중 하나를 클릭하세요. **First Name**, **Last Name**, **Display Name**, **Church Name** 중 하나를 커서 위치에 삽입할 수 있습니다. 각 자리표시자는 문자가 발송될 때 수신자 본인의 정보로 채워집니다.
4. **Send**를 클릭합니다.

자세한 내용은 [문자에 병합 필드 사용하기](../settings/church-settings.md#personalizing-texts-with-merge-fields)를 참고하세요.

## 그룹 데이터 내보내기

그룹 구성원 목록을 파일로 다운로드하려면 다음과 같이 합니다.

1. 그룹의 구성원 목록 위에 있는 **Export**를 클릭합니다.
2. 그룹 구성원 정보가 담긴 CSV 파일이 컴퓨터에 다운로드됩니다.

CSV 내보내기는 데이터를 다른 도구로 가져오거나 오프라인 기록을 보관할 때 유용합니다. 더 많은 내보내기 옵션은 [데이터 내보내기](../people/exporting-data.md)를 참고하세요.

## 구성원 목록 인쇄하기

그룹의 구성원 목록 위에 있는 **Print Roll Sheet**(프린터) 아이콘을 클릭하고 레이아웃을 선택합니다. 페이지가 새 탭에서 열리며 브라우저의 인쇄 대화상자가 자동으로 나타납니다.

- **Attendance Sheet** -- 날짜가 없는 출석부로, 교사가 손으로 표시할 수 있도록 **Present**와 **Absent** 칸이 있습니다. [출석 명단 인쇄하기](../attendance/recording-attendance.md#printing-a-roll-sheet)를 참고하세요.
- **Contact Roster** -- 그룹의 연락처 명단으로, 오늘 날짜가 적히고 교회 로고([Website > Appearance](../website/appearance.md)에서 업로드한 **Light Background Logo**가 있는 경우)와 그 아래 교회 이름, 그리고 그룹 이름이 상단에 표시됩니다. 각 구성원의 행에는 **Name**, **Phone**, **Email**, **Address**가 나옵니다. 리더는 먼저 나열되며 **Leader**로 표시되고, 나머지 구성원은 성 순으로 나옵니다. 전화번호는 구성원의 휴대폰 번호이며, 휴대폰이 없으면 집 또는 직장 번호가 표시됩니다. 수신을 거부한 구성원의 연락처 정보는 비워 둡니다.

:::warning
연락처 명단에는 구성원의 개인 연락처 정보가 포함되어 있습니다. 인쇄물은 그룹 리더와 꼭 필요한 사람에게만 나눠 주세요.
:::

## 그룹 구성원에게 푸시 알림 보내기

B1.church 앱을 기기에 설치하고 푸시 알림을 켜 둔 모든 그룹 구성원에게 푸시 알림을 직접 보낼 수 있습니다.

1. 그룹 상세 페이지에서 **Notify**를 클릭합니다(**Email**과 **Text** 버튼 아래에 있습니다. **Text** 버튼은 [문자 발송 서비스](../settings/church-settings.md#texting)가 연결되어야 나타납니다).
2. 그룹 구성원 중 푸시가 켜진 사람의 수를 보여 주는 대화상자가 열립니다.
3. 알림 세부 정보를 입력합니다.
   - **Title** *(필수)* -- 80자 이내의 짧은 요약입니다.
   - **Message** *(필수)* -- 240자 이내의 알림 본문입니다.
   - **Open link or flyer URL** *(선택)* -- 알림을 탭했을 때 열릴 앱 내 상대 경로(예: `/mobile/groups`) 또는 전체 `https://` URL입니다.
   - **Image URL** *(선택)* -- 지원되는 기기에서 알림과 함께 표시될 이미지의 `https://` URL입니다.
4. 실시간 미리보기에서 기기에 알림이 어떻게 보일지 확인할 수 있습니다.
5. **Send Notification**을 클릭합니다.

:::info
푸시 알림은 B1.church PWA를 설치하고 푸시 알림을 끄지 않은 그룹 구성원에게만 전달됩니다. 등록된 푸시 기기가 없거나 푸시를 끈 구성원은 건너뜀으로 집계되며, 발송 요약에서 도달한 수와 건너뛴 수를 확인할 수 있습니다.
:::

:::tip
발송 후 대화상자에 알림이 성공적으로 대기열에 들어간 수가 표시됩니다. 대부분의 구성원이 건너뛰기로 표시된다면, B1.church 사이트를 방문하여 홈 화면 앱으로 설치하고 요청 시 알림을 허용하도록 안내해 주세요.
:::

## 구성원 제거하기

그룹에서 누군가를 제외하려면 구성원 목록에서 그 사람의 이름을 찾아 항목 옆의 **remove** 버튼을 클릭합니다.

:::info
그룹에서 사람을 제외해도 교회 명부에서 삭제되지는 않습니다. 해당 사람은 여전히 [사람](../people/adding-people.md) 섹션에 남아 있으며, 언제든지 다시 그룹에 추가할 수 있습니다.
:::
