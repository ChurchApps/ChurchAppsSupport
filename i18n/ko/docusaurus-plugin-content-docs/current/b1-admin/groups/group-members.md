# 그룹 구성원

<div class="article-intro">

그룹을 만든 다음의 단계는 구성원을 추가하는 것입니다. 그룹의 상세 페이지에서 사람을 검색하고, 그룹에 추가하고, 리더를 지정하고, 메시지를 보내고, 구성원 명단을 내보낼 수 있습니다. 그룹 구성원을 관리하는 것은 소그룹, 위원회, 반을 운영하는 데 필수적입니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin에 최소 한 개의 그룹이 설정되어 있어야 합니다. 아직 그룹을 만들지 않았다면 [Creating Groups(그룹 만들기)](creating-groups.md)를 참고하세요.
- 추가할 사람은 이미 [People(교인)](../people/adding-people.md) 명부에 있어야 합니다. 없다면 아래의 구성원 검색 과정에서 새로 만들 수 있습니다.

</div>

## 그룹에 구성원 추가하기

1. [Jump menu(점프 메뉴)](../introduction.md#getting-around-with-the-jump-menu)에서 **People > Groups**를 선택하고 관리할 그룹을 클릭합니다.
2. 그룹 페이지의 **Members** 섹션에서 **All members**를 클릭합니다. (팀과 사역 그룹은 바로 구성원 목록으로 열립니다.)
3. 구성원 목록 아래의 **Add Person** 상자에 추가하려는 사람의 이름을 입력하고 **Enter**를 누르거나 검색 아이콘을 클릭합니다.
4. 검색 결과에서 사람의 이름을 클릭하거나, 그 옆의 추가 아이콘을 클릭합니다.
5. 그 사람이 그룹 구성원 목록에 나타납니다.

:::tip
아무것도 입력하기 전에도 **Add Person** 상자에는 **Recent people**(최근 사람) 목록이 짧게 표시되며, 한 번의 클릭으로 추가할 수 있습니다.
:::

작업을 마치면 그룹 이름이 적힌 **Back to** 링크를 클릭하여 그룹 페이지로 돌아갑니다. 그룹 페이지에는 **Members**(구성원), **Sessions**(세션), **Calendar**(캘린더), **Health**(상태) 요약이 표시되며, 각 항목은 전체 보기로 연결되는 링크가 있습니다. 그룹의 리더라면 **Leader notes**(리더 메모)도 표시됩니다([아래 Leader Notes](#leader-notes) 참고). 그룹에 양식이 연결되어 있다면 **Linked forms**(연결된 양식) 섹션도 나타납니다([아래 Linked Forms](#linked-forms) 참고).

### 아직 B1에 없는 사람 추가하기

검색 결과에 사람이 없으면 검색 결과에 **No records found**(기록 없음)와 **Add New Person**(새 교인 추가) 링크가 표시됩니다. 이를 클릭하고 이름, 성, (선택 사항) 이메일을 입력한 다음 **Add**를 클릭합니다. 새 사람은 교인 명부에 만들어지고 한 번에 그룹에 추가되므로, 다시 검색할 필요가 없습니다.

## 그룹 리더 지정하기 {#designating-group-leaders}

그룹 리더는 특별한 권한을 가집니다. 그룹 [캘린더](group-calendar.md)를 편집하고, 행사를 관리하며, 그룹을 함께 운영할 수 있습니다.

1. 그룹 구성원 목록에서 리더로 지정할 사람을 찾습니다.
2. 이름 옆의 **별(star) 아이콘**(**Make Leader**)을 클릭합니다.
3. 그 사람은 그룹 리더로 지정되며 **Leader** 배지가 표시됩니다.

리더 권한을 해제하려면 별(star) 아이콘(**Remove Leader Access**)을 다시 클릭합니다.

:::info
그룹의 모든 구성원은 그룹 캘린더와 행사를 볼 수 있지만, 캘린더 행사를 추가하거나 편집할 수 있는 사람은 리더뿐입니다.
:::

## 연결된 양식 {#linked-forms}

Stand Alone 양식이 [그룹에 연결](../forms/creating-forms.md#linking-a-form-to-a-group)되어 있으면, 그룹 페이지에 **Linked forms** 섹션이 표시됩니다. 여기에는 각 양식의 이름, **Open**(열림) 또는 **Closed**(마감됨) 상태, 연결된 양식의 수가 나타납니다. 이 섹션은 그룹의 리더와 양식을 관리할 수 있는 사람에게만 보이며, 연결된 양식이 하나 이상 있을 때만 나타납니다. 양식 관리자는 양식 이름을 클릭하여 양식을 열거나, **All forms**를 클릭하여 Forms 페이지로 이동할 수 있습니다.

그룹 리더는 [B1.church](../../b1-church/groups/group-details.md#linked-forms)의 그룹 페이지에서 이러한 양식의 답변을 읽고 인쇄합니다.

## 리더 메모 {#leader-notes}

그룹 리더는 나머지 그룹 구성원은 보지 않는 그룹에 관한 비공개 메모를 남길 수 있습니다. 예를 들어 후속 조치, 기도 제목, 목회적 관심사를 기록할 수 있습니다.

**Leader notes** 섹션은 해당 그룹의 리더에게만 그룹 페이지에 표시됩니다. 가장 최근 메모, 작성자와 작성 시각, 메모의 총 개수를 보여 줍니다.

1. 그룹 페이지에서 **Leader notes** 섹션의 **All notes**를 클릭합니다.
2. 상자에 메모를 입력하고 게시합니다. 메모에는 작성자의 이름과 사진, 게시된 날짜와 시각이 함께 표시됩니다.
3. 그룹 이름이 적힌 **Back to** 링크를 클릭하여 그룹 페이지로 돌아갑니다.

:::info
리더 메모는 그룹의 리더에게만 보입니다. 다른 구성원은 물론, 직원이나 관리자도 그 그룹의 리더가 아니라면 전체 권한이 있더라도 메모를 볼 수 없습니다. 다른 사람에게 접근 권한을 주려면 [리더로 지정](#designating-group-leaders)하세요. 리더는 [B1.church](../../b1-church/groups/group-details.md#leader-notes)의 그룹 페이지 **Leader notes** 섹션과 B1 Admin의 [Notes(메모)](../people/notes.md) 페이지 **Groups** 탭에서도 이 메모를 볼 수 있습니다.
:::

## 그룹 구성원에게 메시지 보내기

B1 Admin에서 그룹의 모든 구성원에게 직접 연락할 수 있습니다.

1. 그룹의 구성원 목록에서 목록 위의 **Send a message to members**(구성원에게 메시지 보내기) 아이콘을 클릭합니다.
2. 텍스트 상자에 메시지를 입력하거나 **Templates**(템플릿)에서 하나를 선택합니다.
3. **Send**를 클릭합니다.

메시지는 그룹의 모든 구성원에게 전달됩니다.

## 그룹 구성원에게 이메일 보내기

그룹의 모든 구성원에게 서식이 적용된 이메일을 보낼 수 있습니다.

1. 그룹 상세 페이지 왼쪽의 **Email** 버튼을 클릭합니다.
2. Send Email 대화상자가 열리며, 이메일을 받을 구성원 수와 이메일 주소가 없는 구성원 수가 표시됩니다.
3. 선택 사항으로 드롭다운에서 **email template**(이메일 템플릿)을 선택하거나, 처음부터 메시지를 작성합니다. 템플릿을 만들거나 편집하려면 **Manage Templates**(템플릿 관리)를 클릭합니다.
4. **subject line**(제목)을 입력합니다. 필드 칩을 클릭하여 병합 필드를 넣을 수 있습니다: `{{firstName}}`, `{{lastName}}`, `{{displayName}}`, `{{email}}`, `{{churchName}}`.
5. HTML 편집기를 사용하여 **email body**(이메일 본문)를 작성합니다. 같은 병합 필드를 여기에서도 사용할 수 있습니다.
6. **Send**를 클릭합니다.
7. 발송 요약에서 이메일이 성공적으로 발송된 수와 건너뛴 구성원 수(이메일 주소 없음)를 확인합니다.

:::tip
주간 소식, 행사 공지, 기도 제목 요청처럼 반복되는 소통을 위해 이메일 템플릿을 만들어 두세요. 템플릿은 시간을 절약하고 일관된 메시지를 보내도록 도와줍니다.
:::

### 교회의 그룹 이메일 사용 설정하기 {#turning-on-group-email-for-your-church}

B1의 모든 교회는 같은 주소에서 이메일을 보내므로, 발송 평판을 함께 공유합니다. 모든 교회의 이메일이 스팸 폴더로 가지 않도록, ChurchApps 팀은 그룹 이메일을 보내기 전에 각 교회를 한 번 검토합니다.

교회가 아직 검토를 받지 않았다면, Send Email 대화상자에는 메시지 편집기 대신 **Group email needs a quick review**(그룹 이메일에 간단한 검토가 필요합니다)가 표시됩니다.

1. **Request review**(검토 요청)를 클릭합니다. ChurchApps 지원팀에 알림이 전송됩니다.
2. 대화상자가 **Review requested**(검토 요청됨)로 바뀝니다. 대화상자를 닫아도 됩니다.
3. 그룹 이메일은 보통 영업일 하루 이내에 사용 설정됩니다. 그 후 Send Email 대화상자를 다시 열어 메시지를 보낼 수 있습니다.

교회가 승인되기 전까지 B1은 [양식 후속 이메일](../forms/creating-forms.md#sending-a-follow-up-email)이나 [workflows(워크플로)](../serving/workflows.md)의 **Send email**(이메일 보내기) 단계도 발송하지 않습니다.

:::info Sending limits(발송 한도)
승인 후 교회는 하루에 교회가 작성한 이메일을 최대 150통까지 보낼 수 있습니다. 교회가 깨끗한 발송 이력을 쌓아감에 따라 한도가 늘어나며, 최대 하루 2,000통까지 올라갑니다. 최근 메시지가 반송되었거나 스팸으로 표시되면 그룹 이메일 발송이 일시 중지되고, 대화상자에서 지원팀에 문의하라는 안내가 나타납니다. 발송이 하루 한도를 초과하게 되면 B1은 발송하지 않고 오류를 표시합니다.
:::

## 그룹 구성원에게 문자 보내기

교회가 [문자 메시지 제공업체](../settings/church-settings.md#texting)를 연결하면, 그룹 페이지의 **Email** 버튼 옆에 **Text** 버튼(**Text this group**)이 나타납니다.

1. 그룹 상세 페이지에서 **Text**를 클릭합니다.
2. 대화상자에 문자를 받을 구성원 수가 표시됩니다. 휴대폰 번호가 없거나 수신을 거부한 구성원은 건너뜁니다.
3. 메시지를 입력합니다. 메시지를 개인화하려면 메시지 상자 아래의 자리 표시자 칩(**First Name**(이름), **Last Name**(성), **Display Name**(표시 이름), **Church Name**(교회 이름))을 클릭하여 커서 위치에 삽입합니다. 문자가 발송될 때 각 자리 표시자는 수신자 본인의 정보로 채워집니다.
4. **Send**를 클릭합니다.

자세한 내용은 [Personalizing Texts with Merge Fields(병합 필드로 문자 개인화하기)](../settings/church-settings.md#personalizing-texts-with-merge-fields)를 참고하세요.

## 그룹 데이터 내보내기

그룹 구성원 목록을 파일로 다운로드하려면 다음과 같이 합니다.

1. 그룹의 구성원 목록에서 목록 위의 **Export**를 클릭합니다.
2. 그룹 구성원 정보가 담긴 CSV 파일이 컴퓨터로 다운로드됩니다.

CSV 내보내기는 데이터를 다른 도구로 가져오거나 오프라인 기록을 보관할 때 유용합니다. 더 많은 내보내기 옵션은 [Exporting Data(데이터 내보내기)](../people/exporting-data.md)를 참고하세요.

## 구성원 목록 인쇄하기

그룹의 구성원 목록에서 목록 위의 **Print Roll Sheet**(출석부 인쇄) (프린터) 아이콘을 클릭하고 레이아웃을 선택합니다. 페이지가 새 탭에서 열리고 브라우저의 인쇄 대화상자가 자동으로 나타납니다.

- **Attendance Sheet**(출석표) -- 날짜가 없는 반 명단으로, 교사가 손으로 표시할 수 있도록 **Present**(출석)와 **Absent**(결석) 칸이 있습니다. [Printing a Roll Sheet(출석부 인쇄하기)](../attendance/recording-attendance.md#printing-a-roll-sheet)를 참고하세요.
- **Contact Roster**(연락처 명단) -- 그룹의 연락처 목록입니다. 오늘 날짜가 표시되고, 교회 로고(업로드한 경우 [Website > Appearance](../website/appearance.md)의 **Light Background Logo**)가 맨 위에 나타나며, 그 아래에 교회 이름과 그룹 이름이 적힙니다. 각 구성원은 **Name**(이름), **Phone**(전화번호), **Email**(이메일), **Address**(주소)를 포함한 행으로 표시됩니다. 리더가 먼저 나오며 **Leader**로 표시되고, 나머지 구성원은 성 순서로 나열됩니다. 전화번호는 휴대폰 번호이며, 휴대폰 번호가 없으면 집 또는 직장 번호가 표시됩니다. 연락처 공개를 거부한 구성원의 연락처 정보는 비워 둡니다.

:::warning
연락처 명단에는 구성원의 개인 연락처 정보가 담겨 있습니다. 인쇄본은 그룹 리더와 필요한 사람에게만 공유하세요.
:::

## 그룹 구성원에게 푸시 알림 보내기

푸시 알림이 사용 설정된 B1.church 앱을 기기에 설치한 모든 그룹 구성원에게 직접 푸시 알림을 보낼 수 있습니다.

1. 그룹 상세 페이지에서 **Notify**(알림)를 클릭합니다. (**Email**과 **Text** 버튼 아래에 있으며, **Text** 버튼은 [문자 메시지 제공업체](../settings/church-settings.md#texting)가 연결된 경우에만 나타납니다.)
2. 그룹 구성원 중 푸시가 사용 설정된 사람이 몇 명인지 보여 주는 대화상자가 열립니다.
3. 알림 세부 정보를 입력합니다.
   - **Title**(제목) *(필수)* -- 80자 이내의 짧은 요약입니다.
   - **Message**(메시지) *(필수)* -- 240자 이내의 알림 본문입니다.
   - **Open link or flyer URL**(열 링크 또는 전단 URL) *(선택)* -- 알림을 탭했을 때 열리는 상대 앱 경로(예: `/mobile/groups`) 또는 전체 `https://` URL입니다.
   - **Image URL**(이미지 URL) *(선택)* -- 지원되는 기기에서 알림과 함께 표시되는 이미지의 `https://` URL입니다.
4. 실시간 미리보기에서 기기에 알림이 어떻게 보일지 확인합니다.
5. **Send Notification**(알림 보내기)을 클릭합니다.

:::info
푸시 알림은 B1.church PWA를 설치하고 푸시 알림을 끄지 않은 그룹 구성원에게만 전달됩니다. 등록된 푸시 기기가 없거나 푸시가 꺼져 있는 구성원은 건너뛴 것으로 집계되며, 발송 요약에는 도달한 구성원과 건너뛴 구성원의 수가 표시됩니다.
:::

:::tip
발송 후 대화상자에는 대기열에 성공적으로 추가된 알림 수가 표시됩니다. 대부분의 구성원이 건너뛴 것으로 표시된다면, 구성원에게 B1.church 사이트를 방문하여 홈 화면 앱으로 설치하고, 요청 시 알림을 허용하라고 안내하세요.
:::

## 구성원 제거하기

그룹에서 사람을 제거하려면 구성원 목록에서 그 사람의 이름을 찾아 항목 옆의 **remove**(제거) 버튼을 클릭합니다.

:::info
그룹에서 사람을 제거해도 교회 명부에서 삭제되지는 않습니다. 그 사람은 여전히 [People(교인)](../people/adding-people.md) 섹션에 나타나며, 언제든지 다시 그룹에 추가할 수 있습니다.
:::
