# 그룹 멤버

<div class="article-intro">

그룹을 생성한 후 다음 단계는 멤버를 추가하는 것입니다. 그룹의 상세 페이지에서 사람을 검색하고, 그룹에 추가하고, 리더를 지정하고, 메시지를 보내고, 멤버 목록을 내보낼 수 있습니다. 그룹 멤버십 관리는 소그룹, 위원회 및 클래스를 조율하는 데 필수적입니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin에서 최소한 하나의 그룹이 설정되어 있어야 합니다. 아직 그룹을 생성하지 않았다면 [그룹 생성](creating-groups.md)을 참조하십시오.
- 추가하려는 사람들은 이미 [사람](../people/adding-people.md) 디렉토리에 존재해야 합니다.

</div>

## 그룹에 멤버 추가하기

1. **그룹** 페이지로 이동하여 관리하려는 그룹을 클릭합니다.
2. **멤버** 탭을 클릭합니다.
3. 검색 상자에 추가하려는 사람의 이름을 입력합니다.
4. 검색 결과에서 그 사람의 이름 옆의 **추가**를 클릭합니다.
5. 이제 그 사람이 그룹 멤버 목록에 나타납니다.

:::tip
검색 상자를 비우고 **검색**을 클릭하여 전체 디렉토리를 탐색합니다. 이는 누군가의 이름의 정확한 철자를 확실히 모를 때 도움이 됩니다.
:::

## 그룹 리더 지정하기

그룹 리더는 특별한 권한이 있으며, 그들은 [그룹 달력](group-calendar.md)을 편집하고, 이벤트를 관리하고, 그룹을 조율하는 데 도움을 줄 수 있습니다.

1. 그룹 멤버 목록에서 리더로 만들려는 사람을 찾습니다.
2. 그들의 이름 옆에 있는 **녹색 열쇠 아이콘**을 클릭합니다.
3. 이제 그 사람이 그룹 리더로 지정됩니다.

리더 상태를 제거하려면 녹색 열쇠 아이콘을 다시 클릭하십시오.

:::info
그룹 멤버는 누구나 그룹 달력 및 이벤트를 볼 수 있지만, 달력 이벤트를 추가하거나 편집할 수 있는 것은 리더뿐입니다.
:::

## 그룹 멤버에게 메시지 보내기

B1 Admin에서 직접 그룹의 모든 멤버와 통신할 수 있습니다:

1. 그룹 상세 페이지에서 메시징 영역을 찾습니다.
2. 텍스트 상자에 메시지를 입력합니다.
3. **보내기**를 클릭합니다.

귀하의 메시지는 그룹의 모든 멤버에게 전달됩니다.

## 그룹 멤버에게 이메일 보내기

그룹의 모든 멤버에게 형식이 지정된 이메일을 보낼 수 있습니다:

1. 그룹 상세 페이지에서 **이메일 아이콘**을 클릭합니다.
2. 이메일 보내기 대화상자가 열리면, 이메일을 받을 멤버의 수와 파일에 이메일 주소가 없는 멤버의 수를 표시합니다.
3. 드롭다운에서 **이메일 템플릿**을 선택하거나, 처음부터 메시지를 작성합니다. 템플릿을 만들거나 편집하려면 **템플릿 관리**를 클릭합니다.
4. **제목 줄**을 입력합니다. 필드 칩을 클릭하여 병합 필드를 삽입할 수 있습니다: `{{firstName}}`, `{{lastName}}`, `{{displayName}}`, `{{email}}`, `{{churchName}}`.
5. HTML 편집기를 사용하여 **이메일 본문**을 작성합니다. 동일한 병합 필드를 여기에서도 사용할 수 있습니다.
6. **보내기**를 클릭합니다.
7. 요약이 성공적으로 보낸 이메일의 수와 건너뛴 멤버의 수(파일에 이메일이 없음)를 표시합니다.

:::tip
주간 업데이트, 이벤트 공지 또는 기도 요청 같은 반복적인 통신을 위해 재사용 가능한 이메일 템플릿을 만듭니다. 템플릿은 시간을 절약하고 일관된 메시징을 보장합니다.
:::

### 교회를 위해 그룹 이메일 켜기

B1의 모든 교회는 동일한 주소에서 이메일을 보내므로, 같은 전송 평판을 공유합니다. 모든 사람의 이메일이 스팸 폴더에 들어가지 않도록 하려면, ChurchApps 팀이 각 교회가 그룹 이메일을 보낼 수 있기 전에 검토합니다.

귀하의 교회가 아직 검토되지 않았다면, 이메일 보내기 대화상자는 메시지 편집기 대신 **그룹 이메일이 빠른 검토가 필요합니다**를 표시합니다:

1. **검토 요청**을 클릭합니다. ChurchApps 지원 팀이 알림을 받습니다.
2. 대화상자가 **검토 요청됨**으로 변경됩니다. 닫을 수 있습니다.
3. 그룹 이메일은 보통 업무일 하루 이내에 켜집니다. 그 후에 이메일 보내기 대화상자를 다시 열어 메시지를 보냅니다.

교회가 승인될 때까지, B1 또한 [양식 팔로우업 이메일](../forms/creating-forms.md#sending-a-follow-up-email) 또는 [워크플로우](../serving/workflows.md)의 **이메일 보내기** 단계를 보내지 않습니다.

:::info 전송 제한
승인 후, 교회는 매일 최대 150개의 교회 작성 이메일을 보낼 수 있습니다. 교회가 깨끗한 전송 기록을 쌓으면서 한도는 하루에 최대 2,000까지 증가합니다. 최근 메시지가 반송되거나 스팸으로 표시된 경우, 그룹 이메일이 일시 중지되고 대화상자가 지원팀에 연락하도록 요청합니다. 전송이 일일 한도를 초과하면, B1은 전송하지 않고 오류를 표시합니다.
:::

## 그룹 데이터 내보내기

그룹 멤버 목록을 파일로 다운로드하려면:

1. 그룹 상세 페이지에서 **다운로드 아이콘**을 클릭합니다.
2. 그룹의 멤버 정보가 포함된 CSV 파일이 컴퓨터에 다운로드됩니다.

대신 클래스에 대한 로그인 시트를 인쇄하려면, **인쇄 롤 시트**를 사용하십시오 -- [롤 시트 인쇄](../attendance/recording-attendance.md#printing-a-roll-sheet)를 참조하십시오.

CSV 내보내기는 다른 도구로 데이터를 가져오거나 오프라인 기록을 유지하는 데 유용합니다. 더 많은 내보내기 옵션은 [데이터 내보내기](../people/exporting-data.md)를 참조하십시오.

## 그룹 멤버에게 푸시 알림 보내기

기기에 B1.church 앱이 설치되어 있고 푸시 알림이 활성화된 모든 그룹 멤버에게 직접 푸시 알림을 보낼 수 있습니다.

1. 그룹 상세 페이지에서 헤더 툴바(이메일 및 SMS 아이콘 옆)의 **종 아이콘**을 클릭합니다.
2. 대화상자가 열리면 그룹의 몇 명의 멤버가 푸시를 활성화했는지 보여줍니다.
3. 알림 세부 정보를 작성합니다:
   - **제목** *(필수)* -- 최대 80자의 간단한 요약.
   - **메시지** *(필수)* -- 최대 240자의 알림 본문.
   - **링크 또는 전단지 URL 열기** *(선택사항)* -- 상대 앱 경로(예: `/mobile/groups`) 또는 알림을 탭했을 때 열리는 전체 `https://` URL.
   - **이미지 URL** *(선택사항)* -- 지원되는 기기에서 알림 옆에 나타나는 이미지의 `https://` URL.
4. 라이브 미리보기는 기기에서 알림이 어떻게 나타날지 보여줍니다.
5. **알림 보내기**를 클릭합니다.

:::info
푸시 알림은 B1.church PWA가 설치되어 있고 푸시 알림을 비활성화하지 않은 그룹 멤버에게만 전달됩니다. 등록된 푸시 기기가 없거나 푸시가 꺼진 멤버는 건너뜀으로 계산되며, 전송 요약은 도달한 수 대 건너뜀 수를 표시합니다.
:::

:::tip
보낸 후, 대화상자는 성공적으로 대기열에 포함된 알림의 수를 보여줍니다. 대부분의 멤버가 건너뜀으로 표시되면, B1.church 사이트를 방문하여 홈 화면 앱으로 설치하고 메시지가 표시될 때 알림을 허용하도록 상기시킵니다.
:::

## 멤버 제거하기

멤버 목록에서 그들의 이름을 찾고 그들의 항목 옆에 있는 **제거** 버튼을 클릭하여 그룹에서 제거합니다.

:::info
사람을 그룹에서 제거해도 교회 디렉토리에서는 삭제되지 않습니다. 그들은 여전히 [사람](../people/adding-people.md) 섹션에 나타나며 언제든지 그룹에 다시 추가할 수 있습니다.
:::
