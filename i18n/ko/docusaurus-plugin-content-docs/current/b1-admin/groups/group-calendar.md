# 그룹 캘린더

<div class="article-intro">

B1의 각 그룹은 자체 행사 캘린더를 가질 수 있습니다. 그룹 리더는 이를 사용해 모임, 활동, 반복 행사를 예약하고, 모든 그룹 회원은 다가오는 행사를 확인하고 관련 대화에 참여할 수 있습니다. 캘린더는 그룹을 정돈된 상태로 유지하고, 모든 사람이 다가오는 일정을 놓치지 않도록 도와줍니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1 Admin에 최소 한 명의 회원이 있는 그룹이 만들어져 있어야 합니다. [그룹 만들기](creating-groups.md)와 [그룹 회원](group-members.md)을 참고하세요.
- 캘린더 행사를 추가하거나 편집하려면 그룹 리더로 지정되어 있어야 합니다. 방법은 [그룹 리더 지정](group-members.md)을 참고하세요.

</div>

## 그룹 캘린더 접근하기

그룹 캘린더는 회원용 앱인 B1.church를 통해 이용할 수 있습니다.

1. B1 Admin에서 화면 오른쪽 상단의 **드롭다운 메뉴**를 클릭합니다.
2. **앱 전환**을 선택합니다.
3. **B1.church**를 선택합니다.
4. 왼쪽 사이드바에서 **그룹**을 클릭합니다.
5. 목록에서 원하는 그룹을 선택합니다.
6. 화면 왼쪽의 **캘린더**를 클릭합니다.

:::info
그룹 캘린더는 B1 Admin이 아닌 B1.church(회원용 앱)를 통해 관리됩니다. 그룹 리더는 관리자 대시보드에서 앱을 전환해 캘린더에 접근합니다.
:::

## 행사 추가하기

1. 그룹 캘린더에서 **행사 추가**를 클릭합니다.
2. 행사의 **제목**을 입력합니다.
3. 행사에 대한 간단한 **설명**을 작성합니다.
4. **시작 시간**과 **종료 시간**을 설정합니다.
5. **저장**을 클릭해 행사를 캘린더에 추가합니다.

## 반복 행사 설정하기

그룹이 정기적인 일정으로 모인다면, 행사가 자동으로 반복되도록 설정할 수 있습니다.

1. 행사를 만들거나 편집할 때 **반복** 체크박스를 선택합니다.
2. 행사가 어떻게 반복될지 선택합니다.
   - **간격** -- 발생 사이의 일수를 설정합니다. 예를 들어 "7"을 입력하면 7일마다 행사가 반복됩니다.
   - **빈도** -- **일**, **주**, **월** 단위 중에서 반복 방식을 선택합니다.
3. 행사를 저장합니다. 이제 예정된 각 발생 시점마다 캘린더에 표시됩니다.

:::tip
매주 토요일에 모이는 그룹이라면 빈도를 "주"로 설정하고 토요일을 선택하세요. 이후 해당 행사가 캘린더에 자동으로 채워집니다.
:::

## B1 Admin에서 대량으로 행사 만들기

B1 Admin의 그룹 페이지에도 직원이 한 시즌 전체의 모임을 한 번에 예약할 수 있는 **캘린더** 탭이 있습니다.

1. B1 Admin에서 그룹을 열고 **캘린더** 탭을 선택합니다.
2. **행사 추가**를 클릭해 **반복 행사 추가** 대화 상자를 엽니다.
3. 일정(매주, 격주, 매월, 또는 일회성), **첫 모임**과 **마지막 모임** 날짜를 선택하고, 필요하면 **공휴일 건너뛰기**를 선택합니다.
4. 모임 날짜 미리보기를 확인하고 건너뛸 항목의 체크를 해제합니다.
5. 회원이 이 행사에 응답할 수 있게 하려면(아래 참고) **RSVP 허용**을 체크한 상태로 두고 저장합니다.

## 행사 RSVP

그룹 행사는 각 회차에 대해 **예**, **아니요**, **미정** 중 하나로 RSVP(참석 여부 응답)를 받을 수 있습니다.

- **RSVP 허용**은 대량 추가 대화 상자를 통해 만든 행사에서는 기본적으로 켜져 있습니다. 해당 행사들에 대해 응답 기능을 끄려면 체크를 해제하세요. RSVP가 꺼진 행사는 캘린더 탭에서 **비활성화됨**으로 표시됩니다.
- B1 Admin의 그룹 캘린더 탭에서는 각 행사에 응답 요약이 표시됩니다(예: "예 5명 · 미정 2명 · 아니요 1명"). 이를 클릭하면 각 회차에 예, 미정, 아니요로 응답한 사람 목록을 보여주는 **RSVP 응답** 명단이 열립니다.

:::tip
RSVP는 정식 행사 등록 절차 없이도 리더가 참석 인원을 대략 파악할 수 있게 해줍니다. 유료 신청이나 정원 관리가 필요한 행사에는 [행사 등록](../calendars/creating-calendars.md#enabling-event-registration)을 대신 사용하세요.
:::

## 캘린더 보기

그룹 캘린더는 여러 보기 옵션을 제공합니다.

- **월간** -- 한 달 전체를 한눈에 봅니다.
- **주간** -- 이번 주에 집중합니다.
- **일간** -- 하루를 자세히 봅니다.
- **일정 목록** -- 다가오는 행사를 시간순으로 나열합니다.

캘린더 상단의 버튼으로 보기 방식을 전환할 수 있습니다.

## 행사 세부 정보와 대화

행사를 클릭하면 세부 정보를 볼 수 있습니다. 행사 세부 보기에서는 다음이 가능합니다.

- **회원과 리더**는 행사에 대한 대화를 시작하고 댓글을 남길 수 있습니다.
- **리더**는 행사 세부 정보를 편집하거나, 시간을 변경하거나, 행사를 삭제할 수 있습니다.

:::warning
행사를 삭제하면 영구적으로 제거됩니다. 반복 행사 중 한 회차만 취소하고 싶다면 삭제 대신 편집을 고려하세요.
:::

## 캘린더 구독하기

그룹 캘린더를 개인 캘린더와 동기화할 수 있습니다.

1. 그룹 캘린더 페이지에서 **구독**을 클릭합니다.
2. 안내에 따라 Google 캘린더, Apple 캘린더, Outlook 또는 구독을 지원하는 다른 캘린더 애플리케이션에 캘린더를 추가하세요.

:::tip
구독해 두면 B1을 따로 확인하지 않아도 개인 일정이 그룹 행사와 자동으로 동기화됩니다. 그룹 리더가 변경한 사항은 동기화된 캘린더에 자동으로 반영됩니다.
:::
