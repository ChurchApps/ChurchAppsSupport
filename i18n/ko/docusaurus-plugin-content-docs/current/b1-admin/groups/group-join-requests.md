# 그룹 가입 요청

<div class="article-intro">

그룹이 승인 기반 참여 정책으로 설정되어 있으면, 사람들이 참여를 요청할 수 있습니다. 그룹 리더와 관리자가 이 요청을 검토해 승인하거나 거절합니다. 이렇게 하면 교회가 그룹 구성원을 관리할 수 있으면서도, 사람들이 참여에 관심을 표현하기 쉬워집니다.

</div>

<h4>시작하기 전에</h4>

- 그룹을 관리할 권한이 있거나, 해당 특정 그룹의 리더여야 합니다. 자세한 내용은 [역할 및 권한](../people/roles-permissions.md)을 참고하세요.
- 그룹의 참여 정책이 **Request**(승인 필요)로 설정되어 있어야 합니다. 참여 정책 설정 방법은 [그룹 만들기](./creating-groups.md)를 참고하세요.

## 참여 정책 이해하기

그룹에는 세 가지 참여 정책이 있을 수 있습니다.

- **Open** -- 승인 없이 누구나 바로 참여할 수 있음
- **Request** -- 승인이 필요한 참여 요청을 제출함
- **Closed** -- 아무도 참여를 요청할 수 없음(구성원은 직접 추가해야 함)

그룹이 **Request** 정책을 쓰면, 모든 참여 시도는 이 페이지에서 설명하는 승인 절차를 거칩니다.

## 대기 중인 요청 보기

### 그룹 리더를 위한 방법

1. B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)를 열고 **People > Groups**를 선택하세요.
2. 그룹 이름을 클릭하세요.
3. **Members** 섹션에 대기 중인 요청 수가 표시됩니다. **All members**를 클릭하세요. 이 그룹의 대기 중인 요청이 구성원 목록 맨 위에 나타납니다.

### 관리자를 위한 방법

그룹 관리 권한이 있는 관리자는 모든 그룹의 대기 중인 요청을 볼 수 있습니다.

1. 점프 메뉴에서 **People > Groups**를 선택하세요.
2. 페이지 머리글의 **pending requests** 버튼을 클릭하세요(예: "3 pending requests"). 대기 중인 요청이 있을 때에만 나타납니다.
3. 교회 전체의 대기 중인 요청을 검토하세요.

## 가입 요청 검토하기

각 가입 요청에는 다음 정보가 표시됩니다.

- **사람의 이름과 사진** -- 참여를 요청한 사람
- **선택 사항 메시지** -- 참여하고 싶은 이유를 설명하는 개인 메시지(제공된 경우)
- **요청 날짜** -- 요청이 제출된 날짜

요청을 검토하려면 다음과 같이 하세요.

1. 메시지를 남겼다면 읽어 보세요.
2. 필요하면 사람의 이름을 클릭해 프로필을 확인하세요.
3. 승인할지 거절할지 결정하세요.

## 요청 승인하기

1. 가입 요청에서 **Approve**를 클릭하세요.
2. 그 사람은 즉시 그룹의 구성원으로 추가됩니다.
3. 요청자에게 승인되었다는 알림이 갑니다.
4. 요청은 시스템에서 승인됨으로 표시됩니다.

:::tip
요청을 승인하면 그 사람은 일반 그룹 구성원이 됩니다. 나중에 필요하면 [그룹 구성원](./group-members.md) 페이지에서 그룹 리더로 승격할 수 있습니다.
:::

## 요청 거절하기

1. 가입 요청에서 **Decline**을 클릭하세요.
2. 선택 사항으로 거절 사유를 입력하세요(500자 이하).
3. **Confirm**을 클릭하세요.
4. 요청자에게 거절 사유(입력한 경우)가 담긴 알림이 갑니다.
5. 요청은 거절됨으로 표시됩니다.

:::info
거절 사유를 알려 주면, 그 사람이 요청이 승인되지 않은 이유를 이해하고 나중에 다시 시도하거나 다른 그룹을 알아볼 수 있어 도움이 됩니다.
:::

## 할 일 페이지에서 승인하기 {#approving-from-the-tasks-page}

모든 가입 요청은 **Serving &rarr; My Work** 아래에 할 일도 만듭니다. 제목은 "*Person* requested to join *Group*."입니다. 이 할 일은 그룹 리더에게 배정됩니다. 그룹에 아직 리더가 없다면 **Group Members &gt; Edit** 권한이 있는 직원에게 가며, 그런 권한을 가진 사람이 아무도 없으면 교회의 도메인 관리자에게 갑니다. 이 방식으로 할 일을 받은 직원과 관리자에게는 할 일로 바로 연결되는 알림도 갑니다.

할 일을 열면 요청자의 이름, 그룹, 선택 사항 메시지가 보이며, 할 일 카드에서 바로 **Approve**와 **Decline** 버튼을 쓸 수 있습니다(Decline을 누르면 위에서 설명한 것과 같은 선택 사항 사유 입력란이 열림). 그래서 리더는 그룹의 구성원 목록을 열지 않고도 알림을 통해 요청을 처리할 수 있습니다.

둘 중 어느 쪽에서 요청을 결정하든(그룹의 구성원 목록이든 할 일 카드든) 모든 곳에서 요청이 닫히므로, 리더가 이미 처리된 요청의 오래된 할 일을 보는 일이 없습니다.

## 알림

가입 요청 시스템은 다음 알림을 자동으로 보냅니다.

- **요청이 제출되었을 때** -- 모든 그룹 리더에게 알림이 갑니다. 그룹에 리더가 없다면 대신 할 일을 배정받은 직원이나 관리자에게 알림이 갑니다(위 참고).
- **요청이 승인되었을 때** -- 요청자에게 확인이 갑니다.
- **요청이 거절되었을 때** -- 요청자에게 거절 사유(있는 경우)가 담긴 알림이 갑니다.

알림은 B1.church의 사용자 알림 센터와 모바일 앱에 나타납니다. B1 Admin의 알림 종 아이콘에서 가입 요청 알림(또는 그 **View Details**)을 클릭하면, 교회의 B1.church 사이트에서 그룹이 새 탭으로 열립니다.

## 교인 쪽에서 요청 관리하기

교인은 B1.church에서 자신의 가입 요청을 관리할 수 있습니다.

- 그룹 상세 페이지에서 대기 중인 요청의 상태를 볼 수 있습니다.
- 마음이 바뀌면 대기 중인 요청을 취소할 수 있습니다.
- 요청이 승인되었는지 거절되었는지 확인할 수 있습니다.

## 모범 사례

- **신속하게 응답하기** -- 사람들이 기다리지 않도록 24~48시간 안에 요청을 검토하세요.
- **거절 사유는 분명하게 쓰기** -- 다음 단계나 다른 선택지를 이해하도록 도우세요.
- **프로필 확인하기** -- 그 사람이 그룹에 잘 맞는지 프로필을 검토하세요.
- **기대치 알리기** -- 그룹 설명에 그룹이 누구를 위한 곳인지 분명하게 적으세요.
