# 그룹 가입 요청

<div class="article-intro">

그룹이 승인 기반 가입 정책으로 구성된 경우, 사람들은 가입 요청을 제출할 수 있습니다. 그룹 리더 및 관리자는 이 요청을 검토하고 승인하거나 거부합니다. 이것은 교회에 그룹 구성원을 제어하도록 하면서 사람들이 가입에 관심을 표현하기 쉽게 만듭니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 그룹을 관리할 수 있는 권한이 있거나 특정 그룹의 리더여야 합니다. 자세한 내용은 [역할 및 권한](../people/roles-permissions.md)을 참조하세요.
- 그룹의 가입 정책을 **요청**(승인 필요)으로 설정해야 합니다. 가입 정책을 구성하는 방법은 [그룹 생성](./creating-groups.md)을 참조하세요.

</div>

## 가입 정책 이해

그룹은 3가지 가입 정책을 가질 수 있습니다:

- **열기** -- 누구나 승인 없이 즉시 가입할 수 있습니다.
- **요청** -- 사람들이 승인이 필요한 가입 요청을 제출합니다.
- **닫기** -- 아무도 가입을 요청할 수 없습니다(구성원은 수동으로 추가해야 함).

그룹이 **요청** 정책을 사용하면, 모든 가입 시도는 이 페이지에 설명된 승인 워크플로를 거칩니다.

## 대기 중인 요청 보기

### 그룹 리더용

1. B1 Admin에서 **그룹**으로 이동합니다.
2. 그룹 이름을 클릭합니다.
3. 이 그룹의 대기 중인 요청이 **구성원** 탭의 상단에 표시됩니다.

### 관리자용

그룹 관리 권한이 있는 관리자는 모든 그룹의 대기 중인 요청을 볼 수 있습니다:

1. B1 Admin에서 **그룹**으로 이동합니다.
2. 페이지 헤더에서 **대기 중인 요청** 버튼을 클릭합니다(예: "3개의 대기 중인 요청"). 대기 중인 요청이 있을 때만 나타납니다.
3. 모든 대기 중인 요청 교회를 검토합니다.

## 가입 요청 검토

각 가입 요청에 표시됩니다:

- **사람의 이름과 사진** -- 가입을 요청하는 사람
- **선택적 메시지** -- 가입하려는 이유를 설명하는 개인 메시지(제공된 경우)
- **요청 날짜** -- 요청이 제출된 시기

요청을 검토하려면:

1. 제공된 경우 사람의 메시지를 읽습니다.
2. 필요한 경우 사람의 이름을 클릭하여 프로필을 봅니다.
3. 승인 또는 거부 여부를 결정합니다.

## 요청 승인

1. 가입 요청에서 **승인**을 클릭합니다.
2. 그 사람은 즉시 그룹의 구성원으로 추가됩니다.
3. 요청자는 요청이 승인되었다는 알림을 받습니다.
4. 요청은 시스템에서 승인됨으로 표시됩니다.

:::tip
요청을 승인하면 그 사람은 일반 그룹 구성원이 됩니다. 나중에 [그룹 구성원](./group-members.md) 페이지에서 그룹 리더로 승격할 수 있습니다.
:::

## 요청 거부

1. 가입 요청에서 **거부**를 클릭합니다.
2. 선택적으로 거부 사유를 입력합니다(최대 500자).
3. **확인**을 클릭합니다.
4. 요청자는 거부 사유와 함께 알림을 받습니다(제공된 경우).
5. 요청은 거부됨으로 표시됩니다.

:::info
거부 사유를 제공하면 그 사람이 요청이 승인되지 않은 이유를 이해하고 나중에 다시 시도하거나 다른 그룹을 탐색하도록 격려할 수 있습니다.
:::

## 작업 페이지에서 승인

모든 가입 요청은 또한 **봉사 &rarr; 내 작업**에서 "*사람* 요청 *그룹*에 가입합니다"라는 제목의 작업을 생성합니다. 그룹의 리더에게 할당됩니다. 그룹에 리더가 없으면 **그룹 구성원 > 편집** 권한이 있는 직원 또는 해당 권한이 없으면 교회의 도메인 관리자에게 전달됩니다. 이런 식으로 작업을 받는 직원 및 관리자는 직접 연결되는 알림도 받습니다.

작업을 열면 요청자의 이름, 그룹 및 선택적 메시지와 작업 카드에 **승인** 및 **거부** 버튼이 표시됩니다(거부는 위에 설명된 동일한 선택적 사유 필드를 엽니다). 이는 그룹의 가입 요청 탭으로 이동하지 않고 알림 기반 방식으로 요청을 처리하는 리더를 위한 두 번째 방법을 제공합니다.

두 곳 중 하나에서 요청을 결정합니다 -- 그룹의 가입 요청 탭 또는 작업 카드 -- 모든 곳에서 닫히므로 리더가 누군가 이미 처리한 요청의 오래된 작업을 볼 수 없습니다.

## 알림

가입 요청 시스템은 자동으로 알림을 보냅니다:

- **요청이 제출될 때** -- 모든 그룹 리더가 알림을 받습니다. 그룹에 리더가 없으면 작업이 할당된 직원 또는 관리자가 대신 알림을 받습니다(위 참조).
- **요청이 승인될 때** -- 요청자가 확인을 받습니다.
- **요청이 거부될 때** -- 요청자는 거부 사유가 있는 알림을 받습니다.

알림은 B1.church의 사용자의 알림 센터 및 모바일 앱에 나타납니다.

## 회원 측에서 요청 관리

사람들은 B1.church에서 자신의 가입 요청을 관리할 수 있습니다:

- 그룹 세부사항 페이지에서 대기 중인 요청의 상태를 봅니다.
- 마음을 바꾸면 대기 중인 요청을 취소합니다.
- 요청이 승인되었는지 또는 거부되었는지 확인합니다.

## 모범 사례

- **신속하게 대응합니다** -- 사람들이 기다리지 않도록 24-48시간 이내에 요청을 검토해봅니다.
- **거부 사유에서 명확하게 합니다** -- 사람들이 다음 단계 또는 대안을 이해하도록 도와봅니다.
- **프로필을 확인합니다** -- 그룹에 적합한지 확인하기 위해 사람의 프로필을 검토합니다.
- **기대를 소통합니다** -- 그룹 설명이 그룹의 대상을 명확하게 명시하는지 확인합니다.
