# 그룹 만들기

<div class="article-intro">

B1 Admin에서 그룹을 만드는 과정은 간단합니다. 카테고리를 설정하고, 그룹 이름을 정한 다음, 설정을 구성하면 됩니다. 그룹은 소그룹, 위원회, 클래스 등 의미 있는 단위로 교회를 조직하는 데 도움을 줍니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 그룹을 관리할 수 있는 권한을 가진 활성 B1 Admin 계정이 필요합니다. 자신의 접근 수준이 확실하지 않다면 [역할 및 권한](../people/roles-permissions.md)을 참고하세요.
- 그룹의 카테고리 구조를 미리 정하세요(예: "소그룹", "사역", "위원회"). 카테고리는 관련 그룹을 정리하는 데 도움이 됩니다.

</div>

## 새 그룹 추가하기

1. **B1 Admin 대시보드**로 이동합니다.
2. **그룹** 탭을 클릭합니다.
3. **그룹 추가**를 클릭하고 **카테고리 이름**을 입력합니다. 카테고리는 관련 그룹을 함께 정리하는 데 도움이 됩니다(예: "소그룹", "사역", "위원회"). 이미 존재하는 카테고리라면 목록에서 선택할 수 있습니다.
4. **그룹 이름**을 입력합니다.
5. **추가**를 클릭합니다. 새 그룹이 선택한 카테고리 아래 목록에 나타납니다.

## 그룹 설정 구성하기

그룹을 만든 후에는 추가 세부 정보를 입력할 수 있습니다.

1. 목록에서 **그룹 이름**을 클릭해 엽니다.
2. **연필 아이콘**을 클릭해 그룹 설정을 편집합니다.
3. 다음 옵션을 구성합니다.
   - **설명** -- 그룹에 대한 간략한 소개입니다. 회원에게 표시됩니다.
   - **모임 시간** -- 그룹이 일반적으로 모이는 시간입니다(예: "수요일 오후 7시").
   - **가입 정책** -- 이 그룹에 누가 가입할 수 있는지 선택합니다.
     - **자유 가입** -- 승인 없이 누구나 즉시 가입 가능
     - **가입 신청** -- 승인이 필요한 가입 신청을 제출해야 함([그룹 가입 신청](./group-join-requests.md) 참고)
     - **비공개** -- 리더나 관리자가 수동으로만 회원을 추가할 수 있음
   - **라벨** -- 그룹에 하나 이상의 설명 라벨을 지정합니다(예: "대면", "온라인", "신규 회원 환영"). 라벨은 직접 정의하는 자유 형식 태그로, 해당하는 항목을 모두 체크하면 됩니다. 라벨은 그룹 찾아보기 웹사이트 요소에서 그룹을 필터링하는 데 사용할 수 있습니다.
   - **비공개 그룹** -- 이 그룹과 명단을 공개 페이지, 그룹 찾기, 비회원으로부터 숨깁니다. 회복 사역이나 상담 사역처럼 민감한 그룹에 사용하세요. 이 경우 해당 그룹의 회원과 교회 직원만 볼 수 있습니다.
   - **출석 추적** -- 이 그룹의 [출석](../attendance/tracking-attendance.md)을 기록하려면 활성화하세요.
   - **예배 시간** -- 해당된다면 이 그룹을 특정 교회 예배 시간과 연결합니다. 예배 시간에 대한 자세한 내용은 [출석 설정](../attendance/setup.md)을 참고하세요.
4. **저장**을 클릭해 변경 사항을 적용합니다.

:::tip
명확한 설명과 모임 시간을 추가하면 회원이 그룹에 가입할 때 무엇을 기대할지 알 수 있습니다.
:::

## 그룹 복제하기

정기적으로 반복되는 클래스나 사역의 새 세션을 시작하시나요? 모든 설정을 다시 입력하는 대신 기존 그룹을 복제하세요.

1. 그룹을 열고 그룹 배너(편집 옆)에 있는 **복제** 아이콘을 클릭합니다.
2. 복제를 확인합니다.

복제본은 원본의 설정(카테고리, 설명, 모임 시간/장소, 가입 정책, 라벨, 캠퍼스)을 그대로 가져오지만 **회원은 가져오지 않습니다**. 새 그룹의 이름은 원본 이름 뒤에 " (복사본)"이 붙은 형태로 지정되며, 그룹 설정에서 이름을 변경할 수 있습니다.

## 그룹 보관하기

그룹이 더 이상 활동하지 않지만 삭제하는 대신 이력을 보관하고 싶다면 다음과 같이 하세요.

1. 그룹을 열고 **연필 아이콘**을 클릭해 설정을 편집합니다.
2. **보관**을 클릭하고 확인합니다.

보관된 그룹은 기본 그룹 목록에서 사라집니다. 다시 찾으려면 그룹 페이지 상단의 **보관된 항목 표시** 토글을 켠 다음 해당 그룹 옆의 **복원**을 클릭하세요.

:::info
그룹을 보관해도 회원, 출석 기록, 캘린더 행사는 삭제되지 않습니다. 복원할 때까지 기본 목록에서만 그룹이 숨겨집니다.
:::

## 다음 단계

그룹을 만들고 설정을 마쳤다면 이제 다음 작업을 할 수 있습니다.

- **회원 추가** -- 사람을 검색해 그룹에 추가합니다. 녹색 열쇠 아이콘을 사용해 그룹 리더를 지정하세요. [그룹 회원](./group-members.md)을 참고하세요.
- **캘린더 설정** -- 그룹을 위한 행사와 반복 모임을 만듭니다. [그룹 캘린더](./group-calendar.md)를 참고하세요.
- **소통하기** -- 그룹 페이지에서 바로 모든 그룹 회원에게 메시지를 보냅니다.
- **데이터 내보내기** -- 다운로드 아이콘을 클릭해 그룹 회원 목록을 내보냅니다.

:::info
교회의 모든 그룹은 메인 그룹 페이지에서 카테고리별로 정리됩니다. 교회가 성장함에 따라 언제든지 카테고리를 재배치하거나 이름을 바꿀 수 있습니다.
:::
