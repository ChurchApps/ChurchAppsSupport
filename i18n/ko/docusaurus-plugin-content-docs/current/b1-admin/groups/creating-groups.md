# 그룹 만들기

<div class="article-intro">

B1 Admin에서 그룹을 만드는 것은 간단합니다. 카테고리를 정하고, 그룹 이름을 짓고, 설정을 구성하면 됩니다. 그룹은 교회를 소그룹, 위원회, 반 같은 의미 있는 단위로 묶는 데 도움이 됩니다.

</div>

- 그룹의 카테고리 구조를 미리 정하세요(예: "소그룹", "사역", "위원회"). 카테고리는 관련된 그룹을 정리하는 데 도움이 됩니다.

## 새 그룹 추가하기

1. [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 상단의 검색 표시줄)를 열고 **사람**을 펼친 다음 **그룹**을 클릭합니다.
2. 페이지 머리글의 **그룹 추가**를 클릭합니다. 목록 아래에 **새 그룹** 양식이 열립니다. **카테고리 이름**을 입력합니다. 카테고리는 관련 그룹을 함께 묶는 데 도움이 됩니다(예: "소그룹", "사역", "위원회"). 카테고리가 이미 있다면 목록에서 선택할 수 있습니다.
3. 그룹의 **이름**을 입력합니다.
4. **추가**를 클릭합니다. 새 그룹이 목록에 나타나며, 그룹 이름 아래에 카테고리가 표시됩니다.

## 그룹 설정 구성하기

그룹을 만든 뒤에는 추가 세부 정보를 입력할 수 있습니다:

1. 목록에서 **그룹 이름**을 클릭해 그룹을 엽니다.
2. 그룹 세부 정보 아래, 그룹 페이지 왼쪽의 **편집** 버튼을 클릭합니다.
3. 다음 옵션을 구성합니다:
   - **설명** -- 그룹이 무엇에 관한 것인지 짧게 요약합니다. 구성원에게 보입니다.
   - **모임 시간** -- 그룹이 보통 모이는 시간입니다(예: "수요일 오후 7시").
   - **참여 정책** -- 누가 이 그룹에 참여할 수 있는지 고릅니다:
     - **공개** -- 누구나 승인 없이 바로 참여할 수 있습니다.
     - **요청** -- 참여하려면 승인이 필요한 참여 요청을 제출해야 합니다([그룹 참여 요청](./group-join-requests.md) 참고).
     - **비공개** -- 리더나 관리자가 직접 구성원을 추가해야 합니다.
   - **라벨** -- 그룹에 설명용 라벨을 하나 이상 붙입니다(예: "현장 모임", "온라인", "새 구성원 환영"). 라벨은 직접 정하는 자유 형식의 태그이며 해당하는 것을 모두 선택하세요. 웹사이트 요소인 그룹 탐색기에서 라벨로 그룹을 걸러 볼 수 있으며, 그룹 목록 웹사이트 요소는 하나의 라벨이 붙은 그룹을 보여 줍니다.
   - **기밀 그룹** -- 이 그룹과 명단을 공개 페이지, 그룹 찾기, 구성원이 아닌 사람에게서 숨깁니다. 회복 사역이나 상담 사역처럼 민감한 그룹에 쓰세요. 그룹 구성원과 교회 직원만 볼 수 있습니다.
   - **토론** -- 그룹의 채팅 피드를 켜거나 끕니다. 모든 구성원이 글을 올릴 수 있습니다. 기본값은 켜짐입니다.
   - **공지** -- 리더만 글을 올릴 수 있는 두 번째 채팅 피드를 켭니다. 구성원은 읽고 반응할 수 있지만 글은 리더만 올릴 수 있습니다. 기본값은 켜짐입니다.
   - **출석 기록** -- 이 그룹의 [출석](../attendance/tracking-attendance.md)을 기록하려면 켭니다.
   - **예배 시간** -- 해당되는 경우 그룹을 특정 교회 예배 시간과 연결합니다. 예배 시간에 대한 자세한 내용은 [출석 설정](../attendance/setup.md)을 참고하세요.
4. **저장**을 클릭해 변경 사항을 적용합니다.

:::tip
설명과 모임 시간을 분명하게 적으면, 구성원이 그룹에 참여할 때 무엇을 기대해야 할지 알 수 있습니다.
:::

:::info
토론과 공지를 모두 끄면 구성원 포털에서 그룹의 메시지 탭이 완전히 사라집니다. 하나만 끄면 그 탭만 숨겨지며, 구성원은 여전히 켜진 피드로 이동합니다. 기존 메시지는 어느 쪽이든 그대로 보관되며, 이 설정은 새 글 작성만 제어합니다.
:::

## 그룹 복제하기

반복되는 수업이나 사역의 새 학기를 시작하나요? 모든 설정을 다시 입력하는 대신 기존 그룹을 복제하세요:

1. 그룹을 열고 **복제**를 클릭합니다(그룹 페이지 왼쪽의 **편집** 버튼 아래에 있습니다).
2. 복제를 확인합니다.

복사본은 원래 그룹의 설정(카테고리, 설명, 모임 시간/장소, 참여 정책, 라벨, 캠퍼스)을 이어받지만, 구성원은 **이어받지 않습니다**. 새 그룹 이름은 원래 이름 뒤에 " (복사본)"이 붙어 만들어집니다. 그룹 설정에서 이름을 바꾸세요.

## 그룹 보관하기

그룹이 더 이상 활동하지 않지만 삭제하는 대신 기록은 남기고 싶을 때:

1. 그룹을 열고 **편집**을 클릭해 설정을 편집합니다.
2. **보관**을 클릭하고 확인합니다.

보관된 그룹은 기본 그룹 목록에서 사라집니다. 다시 찾으려면 그룹 페이지 상단의 카테고리 버튼 옆에 있는 **보관된 그룹 표시** 버튼을 클릭한 다음, 그룹 옆의 **복원**을 클릭해 되돌리세요.

:::info
그룹을 보관해도 구성원, 출석 기록, 달력 이벤트는 삭제되지 않습니다. 기본 목록에서 그룹을 숨길 뿐이며, 복원할 때까지 그렇게 유지됩니다.
:::

## 다음 단계

그룹을 만들고 설정한 뒤에는 다음을 할 수 있습니다:

- **구성원 추가** -- 사람을 검색해 그룹에 추가합니다. 별 아이콘(**리더로 지정**)을 사용해 그룹 리더를 지정하세요. [그룹 구성원](./group-members.md)을 참고하세요.
- **달력 설정** -- 그룹의 이벤트와 반복 모임을 만듭니다. [그룹 달력](./group-calendar.md)을 참고하세요.
- **소통** -- 그룹 페이지에서 모든 그룹 구성원에게 직접 메시지를 보냅니다.
- **데이터 내보내기** -- 그룹 구성원 목록 위의 **내보내기**를 클릭해 내려받습니다.

:::info
모든 그룹은 카테고리에 속하며, 그룹 목록 페이지에서 카테고리별로 목록을 걸러 볼 수 있습니다. 교회가 성장하면서 카테고리를 언제든지 재배열하거나 이름을 바꿀 수 있습니다.
:::
