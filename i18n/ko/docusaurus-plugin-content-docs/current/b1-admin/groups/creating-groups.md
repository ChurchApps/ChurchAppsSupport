# 그룹 만들기

<div class="article-intro">

B1 Admin에서 그룹을 만드는 것은 간단합니다. 카테고리를 정하고, 그룹 이름을 짓고, 설정을 구성하면 됩니다. 그룹은 소그룹, 위원회, 반 같은 의미 있는 단위로 교회를 조직하는 데 도움이 됩니다.

</div>

<h4>시작하기 전에</h4>

- 그룹을 관리할 권한이 있는 활성 B1 Admin 계정이 필요합니다. 접근 수준이 확실하지 않다면 [역할 및 권한](../people/roles-permissions.md)을 참고하세요.
- 그룹의 카테고리 구조를 정하세요(예: "Small Groups", "Ministries", "Committees"). 카테고리는 관련된 그룹을 함께 정리하는 데 도움이 됩니다.

## 새 그룹 추가하기

1. [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 위의 검색창)를 열고 **People**을 펼친 다음 **Groups**를 클릭하세요.
2. 페이지 머리글의 **Add Group**을 클릭하세요. 목록 아래에 **New Group** 양식이 열립니다. **Category Name**을 입력하세요. 카테고리는 관련된 그룹을 함께 묶는 데 도움이 됩니다(예: "Small Groups", "Ministries", "Committees"). 카테고리가 이미 있다면 목록에서 고를 수 있습니다.
3. 그룹의 **Name**(이름)을 입력하세요.
4. **Add**를 클릭하세요. 새 그룹이 목록에 나타나며, 이름 아래에 카테고리가 표시됩니다.

## 그룹 설정 구성하기

그룹을 만든 뒤에는 추가 세부 정보를 입력할 수 있습니다.

1. 목록에서 **그룹 이름**을 클릭해 그룹을 여세요.
2. 그룹 페이지 왼쪽, 그룹 세부 정보 아래의 **Edit** 버튼을 클릭하세요.
3. 다음 옵션을 설정하세요.
   - **Description** -- 그룹이 무엇을 하는지에 대한 짧은 요약. 구성원에게 보입니다.
   - **Meeting Times** -- 그룹이 보통 모이는 시간(예: "Wednesdays at 7 PM").
   - **Join Policy** -- 이 그룹에 누가 참여할 수 있는지 고르세요.
     - **Open** -- 승인 없이 누구나 바로 참여할 수 있음
     - **Request** -- 승인이 필요한 참여 요청을 제출해야 함([그룹 가입 요청](./group-join-requests.md) 참고)
     - **Closed** -- 리더나 관리자가 직접 구성원을 추가해야 함
   - **Labels** -- 그룹에 설명용 라벨을 하나 이상 붙이세요(예: "In-Person", "Online", "New Members Welcome"). 라벨은 직접 정의하는 자유형 태그이므로, 해당하는 것을 모두 체크하세요. 라벨은 그룹 찾아보기 웹사이트 요소에서 그룹을 거르는 데 쓸 수 있습니다.
   - **Confidential group** -- 이 그룹과 명단을 공개 페이지, 그룹 찾기, 구성원이 아닌 사람에게서 숨깁니다. 회복 사역이나 상담 사역처럼 민감한 그룹에 사용하세요. 그룹 구성원과 교회 직원만 볼 수 있습니다.
   - **Discussions** -- 그룹의 채팅 피드를 켜거나 끕니다. 모든 구성원이 글을 올릴 수 있습니다. 기본값은 켜짐입니다.
   - **Announcements** -- 리더만 글을 올릴 수 있는 두 번째 채팅 피드를 켭니다. 구성원은 읽고 반응할 수 있지만 글은 리더만 올릴 수 있습니다. 기본값은 켜짐입니다.
   - **Attendance Tracking** -- 이 그룹의 [출석](../attendance/tracking-attendance.md)을 기록하려면 켜세요.
   - **Service Times** -- 해당되는 경우 그룹을 특정 교회 예배 시간과 연결하세요. 예배 시간에 대한 자세한 내용은 [출석 설정](../attendance/setup.md)을 참고하세요.
4. **Save**를 클릭해 변경 내용을 적용하세요.

:::tip
설명과 모임 시간을 명확히 적어 두면, 교인이 그룹에 참여할 때 무엇을 기대할 수 있는지 알 수 있습니다.
:::

:::info
Discussions와 Announcements를 모두 끄면 교인 포털에서 그룹의 Messages 탭 자체가 사라집니다. 하나만 끄면 그 탭만 숨겨지고, 구성원은 아직 켜져 있는 피드로 이동합니다. 두 경우 모두 기존 메시지는 보존되며, 이 토글은 새 글 작성만 제어합니다.
:::

## 그룹 복제하기

반복되는 반이나 사역의 새 학기를 시작하나요? 모든 설정을 다시 입력하는 대신 기존 그룹을 복제하세요.

1. 그룹을 열고 **Duplicate**를 클릭하세요(그룹 페이지 왼쪽의 **Edit** 버튼 아래).
2. 복제를 확인하세요.

복사본에는 원래 그룹의 설정이 이어집니다. 카테고리, 설명, 모임 시간/장소, 참여 정책, 라벨, 캠퍼스가 포함되지만, 구성원은 **포함되지 않습니다**. 새 그룹 이름은 원래 이름 뒤에 " (Copy)"가 붙으며, 그룹 설정에서 이름을 바꾸세요.

## 그룹 보관하기

더 이상 활동하지 않지만 삭제하지 않고 기록을 남기고 싶은 그룹은 다음과 같이 보관하세요.

1. 그룹을 열고 **Edit**를 클릭해 설정을 편집하세요.
2. **Archive**를 클릭하고 확인하세요.

보관된 그룹은 기본 Groups 목록에서 빠집니다. 다시 찾으려면 Groups 페이지 위 카테고리 버튼 옆의 **Show archived** 버튼을 클릭하고, 그룹 옆의 **Restore**를 클릭해 되돌리세요.

:::info
그룹을 보관해도 구성원, 출석 기록, 캘린더 행사는 삭제되지 않습니다. 다시 복원하기 전까지 기본 목록에서 숨겨질 뿐입니다.
:::

## 다음 단계

그룹을 만들고 설정했다면 다음을 진행할 수 있습니다.

- **구성원 추가** -- 사람을 검색해 그룹에 추가하세요. 별 아이콘(**Make Leader**)을 사용하면 그룹 리더를 지정할 수 있습니다. [그룹 구성원](./group-members.md)을 참고하세요.
- **캘린더 설정** -- 그룹의 행사와 반복 모임을 만드세요. [그룹 캘린더](./group-calendar.md)를 참고하세요.
- **소통** -- 그룹 페이지에서 모든 그룹 구성원에게 직접 메시지를 보내세요.
- **데이터 내보내기** -- 그룹 구성원 목록 위의 **Export**를 클릭해 내려받으세요.

:::info
모든 그룹은 카테고리에 속하며, 메인 Groups 페이지에서 카테고리별로 목록을 거를 수 있습니다. 교회가 성장하면 카테고리를 언제든지 다시 배열하거나 이름을 바꿀 수 있습니다.
:::
