# 그룹 만들기

<div class="article-intro">

B1 Admin에서 그룹을 만드는 일은 간단합니다. 카테고리를 설정하고, 그룹 이름을 정한 다음, 설정을 구성하면 됩니다. 그룹은 교회를 소그룹, 위원회, 반과 같은 의미 있는 단위로 조직하는 데 도움을 줍니다.

</div>

<h4>시작하기 전에</h4>

- 그룹을 관리할 권한이 있는 활성 B1 Admin 계정이 필요합니다. 접근 수준이 확실하지 않다면 [Roles & Permissions(역할 및 권한)](../people/roles-permissions.md)을 참고하세요.
- 그룹의 카테고리 구조를 정하세요(예: "Small Groups(소그룹)", "Ministries(사역)", "Committees(위원회)"). 카테고리는 관련 그룹을 함께 정리하는 데 도움이 됩니다.

## 새 그룹 추가하기

1. [Jump menu(점프 메뉴)](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 상단의 검색창)를 열고 **People**을 펼친 다음 **Groups**를 클릭합니다.
2. 페이지 헤더의 **Add Group**을 클릭합니다. 목록 아래에 **New Group** 양식이 열립니다. **Category Name**(카테고리 이름)을 입력합니다. 카테고리는 관련 그룹을 함께 정리하는 데 도움이 됩니다(예: "Small Groups", "Ministries", "Committees"). 카테고리가 이미 있다면 목록에서 선택할 수 있습니다.
3. 그룹의 **Name**(이름)을 입력합니다.
4. **Add**를 클릭합니다. 새 그룹이 목록에 나타나며, 이름 아래에 카테고리가 표시됩니다.

## 그룹 설정 구성하기

그룹을 만든 후에는 다음과 같은 세부 정보를 추가할 수 있습니다.

1. 목록에서 **그룹 이름**을 클릭하여 그룹을 엽니다.
2. 그룹 세부 정보 아래, 그룹 페이지 왼쪽에 있는 **Edit** 버튼을 클릭합니다.
3. 다음 옵션을 구성합니다.
   - **Description**(설명) -- 그룹이 무엇에 관한 것인지 간략히 요약합니다. 구성원에게 보입니다.
   - **Meeting Times**(모임 시간) -- 그룹이 일반적으로 모이는 시간입니다(예: "Wednesdays at 7 PM").
   - **Join Policy**(가입 정책) -- 누가 이 그룹에 가입할 수 있는지 선택합니다.
     - **Open**(공개) -- 승인 없이 누구나 즉시 가입할 수 있습니다.
     - **Request**(요청) -- 승인이 필요한 가입 요청을 제출해야 합니다([Group Join Requests(그룹 가입 요청)](./group-join-requests.md) 참고).
     - **Closed**(비공개) -- 리더나 관리자가 직접 구성원을 추가해야 합니다.
   - **Labels**(라벨) -- 그룹에 해당하는 설명 라벨을 하나 이상 지정합니다(예: "In-Person(대면)", "Online(온라인)", "New Members Welcome(새 교인 환영)"). 라벨은 직접 정의하는 자유로운 태그이며, 해당하는 항목을 모두 체크합니다. 라벨은 Groups Browser 웹사이트 요소에서 그룹을 필터링하는 데 사용할 수 있습니다.
   - **Confidential group**(비밀 그룹) -- 이 그룹과 명단을 공개 페이지, 그룹 찾기, 구성원이 아닌 사람에게서 숨깁니다. 회복 사역이나 상담 사역처럼 민감한 그룹에 사용하세요. 그룹 구성원과 교회 직원만 볼 수 있습니다.
   - **Discussions**(토론) -- 모든 구성원이 글을 올릴 수 있는 그룹 채팅 피드를 켜거나 끕니다. 기본값은 켜짐입니다.
   - **Announcements**(공지) -- 리더만 글을 올릴 수 있는 두 번째 채팅 피드를 켭니다. 구성원은 글을 읽고 반응할 수 있지만 글은 리더만 올릴 수 있습니다. 기본값은 켜짐입니다.
   - **Attendance Tracking**(출석 추적) -- 이 그룹의 [출석](../attendance/tracking-attendance.md)을 기록하려면 켭니다.
   - **Service Times**(예배 시간) -- 해당하는 경우 그룹을 특정 교회 예배 시간과 연결합니다. 예배 시간에 대한 자세한 내용은 [Attendance Setup(출석 설정)](../attendance/setup.md)을 참고하세요.
4. **Save**를 클릭하여 변경 사항을 적용합니다.

:::tip
명확한 설명과 모임 시간을 적어 두면 구성원이 그룹에 가입할 때 무엇을 기대해야 할지 알 수 있습니다.
:::

:::info
Discussions와 Announcements를 모두 끄면 구성원 포털에서 그룹의 Messages 탭이 완전히 제거됩니다. 하나만 끄면 해당 탭만 숨겨지고, 구성원은 여전히 켜져 있는 피드로 이동합니다. 기존 메시지는 어느 쪽이든 그대로 유지되며, 이 설정은 새 글 게시만 제어합니다.
:::

## 그룹 복제하기

반복되는 수업이나 사역의 새 기수를 시작하나요? 모든 설정을 다시 입력하는 대신 기존 그룹을 복제하세요.

1. 그룹을 열고 그룹 페이지 왼쪽의 **Edit** 버튼 아래에 있는 **Duplicate**를 클릭합니다.
2. 복제를 확인합니다.

복사본에는 원래 그룹의 설정이 그대로 옮겨집니다. 즉 카테고리, 설명, 모임 시간/장소, 가입 정책, 라벨, 캠퍼스가 포함되지만, 구성원은 **포함되지 않습니다**. 새 그룹 이름은 원래 이름 뒤에 " (Copy)"가 붙습니다. 그룹 설정에서 이름을 바꾸세요.

## 그룹 보관하기

그룹이 더 이상 활동하지 않지만 삭제하지 않고 기록은 남기고 싶을 때 사용합니다.

1. 그룹을 열고 **Edit**를 클릭하여 설정을 편집합니다.
2. **Archive**를 클릭하고 확인합니다.

보관된 그룹은 기본 그룹 목록에서 사라집니다. 다시 찾으려면 Groups 페이지 상단의 카테고리 버튼 옆에 있는 **Show archived**를 클릭한 다음, 해당 그룹 옆의 **Restore**를 클릭하여 그룹을 되돌립니다.

:::info
그룹을 보관해도 구성원, 출석 기록, 캘린더 행사는 삭제되지 않습니다. 그룹을 기본 목록에서 숨기기만 하며, 복원할 때까지 그렇게 유지됩니다.
:::

## 다음 단계

그룹을 만들고 구성한 후에는 다음 작업을 진행할 수 있습니다.

- **구성원 추가** -- 사람을 검색하여 그룹에 추가합니다. 별(star) 아이콘(**Make Leader**)을 사용하여 그룹 리더를 지정합니다. [Group Members(그룹 구성원)](./group-members.md)를 참고하세요.
- **캘린더 설정** -- 그룹의 행사와 정기 모임을 만듭니다. [Group Calendar(그룹 캘린더)](./group-calendar.md)를 참고하세요.
- **소통** -- 그룹 페이지에서 모든 그룹 구성원에게 직접 메시지를 보냅니다.
- **데이터 내보내기** -- 그룹 구성원 목록 위의 **Export**를 클릭하여 다운로드합니다.

:::info
모든 그룹은 카테고리에 속하며, Groups 메인 페이지에서 카테고리별로 목록을 필터링할 수 있습니다. 교회가 성장함에 따라 카테고리를 언제든지 재배치하거나 이름을 바꿀 수 있습니다.
:::
