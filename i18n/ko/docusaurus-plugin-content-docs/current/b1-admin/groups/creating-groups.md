# 그룹 만들기

<div class="article-intro">

B1 Admin에서 그룹을 만드는 일은 간단합니다. 분류를 설정하고, 그룹 이름을 짓고, 설정을 구성하면 됩니다. 그룹은 교회를 소그룹, 위원회, 반 같은 의미 있는 단위로 나누는 데 도움이 됩니다.

</div>

<h4>시작하기 전에</h4>

- 그룹을 관리할 권한이 있는 활성 B1 Admin 계정이 필요합니다. 접근 수준이 확실하지 않다면 [역할 및 권한](../people/roles-permissions.md)을 참조하세요.
- 그룹의 분류 구조를 정하세요(예: "Small Groups", "Ministries", "Committees"). 분류는 관련 그룹을 함께 정리하는 데 도움이 됩니다.

## 새 그룹 추가하기 {#adding-a-new-group}

1. [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 상단의 검색창)를 열고 **People**을 펼친 뒤 **Groups**를 클릭합니다.
2. 페이지 머리글의 **Add Group**을 클릭합니다. 목록 아래에 **New Group** 양식이 열립니다. **Category Name**을 입력합니다. 분류는 관련 그룹을 함께 묶는 데 도움이 됩니다(예: "Small Groups", "Ministries", "Committees"). 분류가 이미 있다면 목록에서 고를 수 있습니다.
3. 그룹의 **Name**을 입력합니다.
4. **Add**를 클릭합니다(양식을 닫으려면 **Cancel**). 새 그룹이 목록에 나타나며, 이름 아래에 분류가 표시됩니다.

## 그룹 설정 구성하기 {#configuring-group-settings}

그룹을 만든 뒤 추가 세부 정보를 입력할 수 있습니다.

1. 목록에서 **그룹 이름**을 클릭해 엽니다.
2. 그룹 페이지 왼쪽의 그룹 세부 정보 아래에 있는 **Edit** 버튼을 클릭합니다. **Group Details** 양식이 열립니다.
3. 다음 옵션을 구성합니다.
   - **Category Name**과 **Group Name** -- 그룹의 분류를 바꾸거나 이름을 바꿉니다.
   - **Meeting Time**과 **Meeting Location** -- 그룹이 보통 언제, 어디에서 모이는지입니다(예: "Room 204"에서 "수요일 오후 7시").
   - **Description** -- 그룹이 무엇인지 짧게 요약한 설명이며, 서식 편집기로 작성합니다. 구성원에게 보입니다.
   - **Photo** -- 사진 상자나 **Add Photo**를 클릭해 그룹의 이미지를 고르거나 업로드합니다.
   - **Slug** -- 교회 사이트의 그룹 웹 주소에 쓰이는 짧은 키 이름입니다.
   - **Labels** -- 그룹에 설명용 라벨을 하나 이상 붙입니다(예: "In-Person", "Online", "New Members Welcome"). 라벨은 직접 정의하는 자유 형식 태그입니다. 해당하는 것을 모두 체크하거나 **Add New Label**을 클릭해 새로 만듭니다. 라벨은 Groups Browser 웹사이트 요소에서 그룹을 거르는 데 쓸 수 있으며, Group List 웹사이트 요소는 특정 라벨 하나를 가진 그룹만 보여 줄 수 있습니다.
   - **Campus** -- 교회에 캠퍼스가 둘 이상이면, 그룹이 속한 캠퍼스입니다.
   - **Enrollment** -- 이 그룹에 누가 가입할 수 있는지 고릅니다.
     - **Open (members can join immediately)** -- 승인 없이 누구나 바로 가입할 수 있습니다.
     - **Request to Join (leader approval required)** -- 승인이 필요한 가입 요청을 제출해야 합니다([그룹 가입 요청](./group-join-requests.md) 참조).
     - **Closed (admin-add only)** -- 리더나 관리자가 직접 구성원을 추가해야 합니다.
   - **Discussions** -- 그룹의 채팅 피드를 켜거나 끕니다. 어떤 구성원이든 글을 올릴 수 있습니다. 기본값은 켜짐(**Yes**)입니다.
   - **Announcements** -- 리더만 글을 올릴 수 있는 두 번째 채팅 피드를 켭니다. 구성원은 읽고 반응할 수 있지만, 글은 리더만 올릴 수 있습니다. 기본값은 켜짐(**Yes**)입니다.
   - **Show roster on website** -- **Yes**로 설정하면 교회 웹사이트의 그룹 페이지에 구성원 목록이 나열됩니다.
   - **Confidential group** -- 이 그룹과 명단을 공개 페이지, 그룹 찾기, 구성원이 아닌 사람에게서 숨깁니다. 회복 사역이나 상담 사역처럼 민감한 그룹에 사용하세요. 그룹 구성원과 교회 직원만 볼 수 있습니다.
4. 반이나 어린이 방의 경우 양식에는 다음 섹션도 있습니다.
   - **Age & Grade** -- **Minimum Age**와 **Maximum Age**(년과 월 단위), **Minimum Grade**와 **Maximum Grade**입니다. 체크인 때 알맞은 방을 추천하는 데 쓰입니다. 제한이 없으면 비워 두거나 **No limit**으로 둡니다. [체크인 안전](../attendance/checkin-safety.md#age-and-grade-room-guidance)을 참조하세요.
   - **Check-In Capacity** -- **Capacity**, **Guest Capacity**, **Children per Volunteer**, **Minimum Volunteers**, **Closed for Check-In**입니다. [체크인 안전](../attendance/checkin-safety.md#room-capacity-and-closing-a-room)을 참조하세요.
   - **Attendance** -- **Track Attendance**(이 그룹의 [출석](../attendance/tracking-attendance.md)을 기록하려면 **Yes**로 설정), **Attendance Reminder Emails**(그룹 캘린더 행사가 어제 열렸는데 출석이 기록되지 않았을 때 그룹 리더에게 알림), **Parent Pickup**, **Print Nametag**입니다(어린이 그룹의 체크인 옵션).
   - **Service Times (optional)** -- **Add Service Time**에서 예배 시간을 고르고 더하기 버튼을 클릭해 그룹을 연결합니다. 예배 시간 옆의 제거 아이콘을 클릭하면 연결이 해제됩니다. 예배 시간에 대한 자세한 내용은 [출석 설정](../attendance/setup.md)을 참조하세요.
5. 변경 내용을 적용하려면 **Save**를, 저장하지 않고 양식을 닫으려면 **Cancel**을 클릭합니다.

그룹 페이지 왼쪽에는 그룹의 분류, 모임 시간과 장소, 설명, 라벨, 예배 시간이 표시됩니다. 또한 **Track Attendance**, **Print Nametag**, **Parent Pickup**, **Discussions**, **Announcements**에는 체크 표시가 있어, 어떤 옵션이 켜져 있는지 한눈에 볼 수 있습니다.

:::tip
명확한 설명과 모임 시간을 적어 두면, 구성원이 그룹에 가입할 때 무엇을 기대할지 알 수 있습니다.
:::

:::info
Discussions와 Announcements를 둘 다 끄면, 구성원 포털에서 그룹의 메시지 탭 전체가 사라집니다. 하나만 끄면 그 탭만 숨겨지고, 구성원은 아직 켜져 있는 피드로 옮겨집니다. 기존 메시지는 어느 쪽이든 그대로 남으며, 이 스위치는 새 글 작성만 제어합니다.
:::

## 그룹 복제하기 {#duplicating-a-group}

반복되는 반이나 사역의 새 학기를 시작하나요? 모든 설정을 다시 입력하지 말고 기존 그룹을 복제하세요.

1. 그룹을 열고 **Duplicate**를 클릭합니다(그룹 페이지 왼쪽의 **Edit** 버튼 아래에 있습니다).
2. 복제를 확인합니다.

복사본은 원래 그룹의 설정을 가져옵니다. 분류, 설명, 사진, 모임 시간과 장소, 가입 방식, 라벨, 캠퍼스, 채팅 피드, 비공개 여부, 나이와 학년 제한, 체크인 정원, 출석 옵션입니다. 하지만 구성원과 예배 시간은 **가져오지 않습니다**. 새 그룹은 바로 열리며, 이름은 원래 이름에 " (Copy)"가 붙어 만들어집니다. 그룹 설정에서 이름을 바꾸세요.

## 그룹 보관하기 {#archiving-a-group}

그룹이 더 이상 활동하지 않지만 삭제하는 대신 기록을 남기고 싶을 때:

1. 그룹을 열고 **Edit**를 클릭하여 설정을 엽니다.
2. **Archive**를 클릭하고 확인합니다.

보관된 그룹은 기본 Groups 목록에서 빠집니다. 다시 찾으려면 Groups 페이지 상단의 분류 버튼 옆에 있는 **Show archived** 버튼을 클릭한 뒤, 그룹 옆의 **Restore**를 클릭하고 확인하여 되돌립니다.

:::info
그룹을 보관해도 구성원, 출석 기록, 캘린더 행사는 삭제되지 않습니다. 복원할 때까지 기본 목록에서만 숨겨집니다.
:::

## 그룹 삭제하기 {#deleting-a-group}

그룹을 영구히 제거하려면 그룹을 열고 **Edit**를 클릭한 뒤, **Group Details** 양식 하단의 **Delete**를 클릭하고 확인합니다. 삭제는 되돌릴 수 없습니다. 나중에 그룹 기록이 필요할 수도 있다면 대신 [보관](#archiving-a-group)하세요.

## 다음 단계 {#next-steps}

그룹을 만들고 구성한 뒤에는 다음을 할 수 있습니다.

- **구성원 추가** -- 사람을 검색해 그룹에 추가합니다. 별 아이콘(**Make Leader**)으로 그룹 리더를 지정합니다. [그룹 구성원](./group-members.md)을 참조하세요.
- **캘린더 설정** -- 그룹의 행사와 정기 모임을 만듭니다. [그룹 캘린더](./group-calendar.md)를 참조하세요.
- **소통** -- 그룹 페이지에서 그룹 구성원에게 이메일, 문자, 푸시 알림을 보냅니다. [그룹 구성원](./group-members.md#emailing-group-members)을 참조하세요.
- **데이터 내보내기** -- 구성원 목록 위의 **Export**를 클릭하여 내려받습니다. 그룹 전체 목록을 내려받으려면 Groups 페이지 머리글의 **Export**를 클릭하세요.

:::info
모든 그룹은 분류에 속하며, 메인 Groups 페이지에서 분류별로 목록을 거를 수 있습니다. 교회가 성장함에 따라 분류를 언제든지 다시 정렬하거나 이름을 바꿀 수 있습니다.
:::
