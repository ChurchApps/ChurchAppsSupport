# 그룹 만들기

<div class="article-intro">

B1 Admin에서 그룹을 만드는 것은 간단합니다. 카테고리를 설정하고, 그룹 이름을 정한 다음, 설정을 구성하면 됩니다. 그룹은 소그룹, 위원회, 반과 같은 단위로 교회를 체계적으로 조직하는 데 도움이 됩니다.

</div>

<h4>시작하기 전에</h4>

- 그룹을 관리할 권한이 있는 B1 Admin 계정이 있어야 합니다. 접근 권한 수준이 확실하지 않다면 [역할과 권한](../people/roles-permissions.md)을 참고하세요.
- 그룹의 카테고리 구조를 정해 두세요(예: "Small Groups", "Ministries", "Committees"). 카테고리는 관련 그룹을 함께 정리하는 데 도움이 됩니다.

</div>

## 새 그룹 추가하기

1. [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin 왼쪽 상단의 검색창)를 열고 **People**을 펼친 다음 **Groups**를 클릭합니다.
2. 페이지 헤더의 **Add Group**을 클릭합니다. 목록 아래에 **New Group** 양식이 열립니다. **Category Name**을 입력합니다. 카테고리는 관련 그룹을 함께 정리하는 데 도움이 됩니다(예: "Small Groups", "Ministries", "Committees"). 이미 있는 카테고리라면 목록에서 선택할 수 있습니다.
3. 그룹의 **Name**을 입력합니다.
4. **Add**를 클릭합니다. 새 그룹이 목록에 나타나며, 그룹 이름 아래에 카테고리가 표시됩니다.

## 그룹 설정 구성하기

그룹을 만든 후에는 다음과 같은 세부 정보를 추가할 수 있습니다.

1. 목록에서 **그룹 이름**을 클릭하여 엽니다.
2. 그룹 페이지 왼쪽, 그룹 세부 정보 아래의 **Edit** 버튼을 클릭합니다.
3. 다음 옵션을 구성합니다.
   - **Description** -- 그룹이 무엇을 하는지 간단히 요약한 내용입니다. 구성원에게 보입니다.
   - **Meeting Times** -- 그룹이 보통 모이는 시간(예: "Wednesdays at 7 PM").
   - **Join Policy** -- 이 그룹에 누가 가입할 수 있는지 선택합니다.
     - **Open** -- 승인 없이 누구나 즉시 가입할 수 있습니다.
     - **Request** -- 가입 요청을 제출해야 하며, 승인이 필요합니다([그룹 가입 요청](./group-join-requests.md) 참고).
     - **Closed** -- 리더나 관리자가 직접 구성원을 추가해야 합니다.
   - **Labels** -- 그룹에 하나 이상의 설명 라벨을 붙입니다(예: "In-Person", "Online", "New Members Welcome"). 라벨은 직접 정의하는 자유 형식의 태그이며, 해당하는 것을 모두 체크합니다. 라벨은 Groups Browser 웹사이트 요소에서 그룹을 필터링하는 데 사용할 수 있습니다.
   - **Confidential group** -- 이 그룹과 명단을 공개 페이지, 그룹 찾기, 그리고 구성원이 아닌 사람에게서 숨깁니다. 회복 모임이나 상담 사역처럼 민감한 그룹에 사용하세요. 그룹의 구성원과 교회 직원만 볼 수 있습니다.
   - **Discussions** -- 그룹의 채팅 피드를 켜거나 끕니다. 모든 구성원이 글을 올릴 수 있습니다. 기본값은 켜짐입니다.
   - **Announcements** -- 리더만 글을 올릴 수 있는 두 번째 채팅 피드를 켭니다. 구성원은 읽고 반응할 수 있지만 글은 리더만 올릴 수 있습니다. 기본값은 켜짐입니다.
   - **Attendance Tracking** -- 이 그룹의 [출석](../attendance/tracking-attendance.md)을 기록하려면 켭니다.
   - **Service Times** -- 해당되는 경우 그룹을 교회의 특정 예배 시간에 연결합니다. 예배 시간에 대한 자세한 내용은 [출석 설정](../attendance/setup.md)을 참고하세요.
4. **Save**를 클릭하여 변경 사항을 적용합니다.

:::tip
명확한 설명과 모임 시간을 적어 두면 구성원이 그룹에 가입했을 때 무엇을 기대해야 할지 알 수 있습니다.
:::

:::info
Discussions와 Announcements를 모두 끄면 멤버 포털에서 그룹의 Messages 탭이 완전히 제거됩니다. 하나만 끄면 해당 탭만 숨겨지고, 구성원은 여전히 켜져 있는 피드로 이동합니다. 기존 메시지는 어느 경우에도 보존되며, 토글은 새 글 작성만 제어합니다.
:::

## 그룹 복제하기

반복되는 수업이나 사역의 새 기수를 시작하나요? 모든 설정을 다시 입력하는 대신 기존 그룹을 복제하세요.

1. 그룹을 열고 **Duplicate**를 클릭합니다(그룹 페이지 왼쪽의 **Edit** 버튼 아래).
2. 복제를 확인합니다.

사본에는 원본의 설정 -- 카테고리, 설명, 모임 시간/장소, 가입 정책, 라벨, 캠퍼스 -- 이 그대로 복사되지만, 구성원은 **복사되지 않습니다**. 새 그룹의 이름은 원본 이름 뒤에 " (Copy)"가 붙어 만들어지며, 그룹 설정에서 이름을 바꿀 수 있습니다.

## 그룹 보관하기

그룹이 더 이상 활동하지 않지만 삭제하는 대신 기록을 남기고 싶을 때:

1. 그룹을 열고 **Edit**을 클릭하여 설정을 편집합니다.
2. **Archive**를 클릭하고 확인합니다.

보관된 그룹은 기본 Groups 목록에서 사라집니다. 다시 찾으려면 Groups 페이지 상단의 카테고리 버튼 옆에 있는 **Show archived** 버튼을 클릭한 다음, 그룹 옆의 **Restore**를 클릭하여 되돌립니다.

:::info
그룹을 보관해도 구성원, 출석 기록, 캘린더 행사는 삭제되지 않습니다. 그룹을 복원하기 전까지 기본 목록에서만 숨겨집니다.
:::

## 다음 단계

그룹을 만들고 구성했다면 다음을 진행할 수 있습니다.

- **구성원 추가** -- 사람을 검색하여 그룹에 추가합니다. 별 아이콘(**Make Leader**)을 사용하여 그룹 리더를 지정합니다. [그룹 구성원](./group-members.md)을 참고하세요.
- **캘린더 설정** -- 그룹의 행사와 반복 모임을 만듭니다. [그룹 캘린더](./group-calendar.md)를 참고하세요.
- **소통** -- 그룹 페이지에서 모든 그룹 구성원에게 직접 메시지를 보냅니다.
- **데이터 내보내기** -- 그룹 구성원 목록 위의 **Export**를 클릭하여 명단을 내려받습니다.

:::info
모든 그룹은 카테고리에 속하며, Groups 메인 페이지에서 카테고리별로 목록을 필터링할 수 있습니다. 교회가 성장함에 따라 카테고리를 언제든지 재정렬하거나 이름을 바꿀 수 있습니다.
:::
