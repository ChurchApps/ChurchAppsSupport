# 그룹 건강

<div class="article-intro">

그룹 건강 대시보드는 모든 그룹이 어떻게 진행되고 있는지 새의 눈높이에서 볼 수 있게 해줍니다 — 멤버십 트렌드, 출석 평균 및 지난 90일 동안의 성장 또는 감소 — 모두 하나의 정렬 가능한 테이블에서.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 의미 있는 데이터를 보려면 적어도 멤버를 가진 몇 개의 그룹이 필요합니다. [그룹 생성](creating-groups)을 참조하십시오.
- 출석 데이터는 기록된 세션에서 가져옵니다. [출석](../attendance/) 섹션을 참조하십시오.

</div>

## 그룹 건강 열기

B1 Admin에서, 왼쪽 상단의 **섹션 메뉴**를 열고 **사람**을 선택한 후, 네비게이션 바에서 **그룹**을 클릭하고 페이지 헤더의 **그룹 건강** 버튼을 클릭합니다. 대시보드는 각 그룹당 하나의 행이 있는 테이블을 로드합니다.

## 열

| 열 | 표시되는 것 |
|--------|--------------|
| **이름** | 그룹 상세 페이지로 연결되는 그룹 이름 |
| **카테고리** | 그룹의 카테고리 |
| **멤버** | 현재 활성 멤버 수 |
| **가입(90일)** | 지난 90일 동안 가입한 멤버 |
| **떠남(90일)** | 지난 90일 동안 떠난 멤버 |
| **이탈(90일)** | 90일 동안의 순 이탈률(백분율) |
| **평균 출석** | 출석 세션당 평균 인원 |

열 헤더를 클릭하여 해당 열로 테이블을 정렬합니다. 다시 클릭하면 정렬 방향이 반대가 됩니다.

## 건강 데이터 사용하기

- **높은 이탈 + 낮은 가입** — 축소되고 있으며 잃어버린 멤버를 대체하지 않는 그룹. 그룹 리더와의 대화가 가치 있습니다.
- **높은 가입 + 낮은 출석** — 사람들이 가입하지만 나타나지 않습니다. 참여 팔로우업을 고려하십시오.
- **높은 평균 출석** — 건강하고 활동적인 그룹. 다른 그룹의 잠재적 모델입니다.

:::tip
그룹 이름을 클릭하면 그룹의 상세 페이지로 직접 이동하여 개별 멤버, 출석 기록 및 달력 이벤트를 검토할 수 있습니다.
:::
