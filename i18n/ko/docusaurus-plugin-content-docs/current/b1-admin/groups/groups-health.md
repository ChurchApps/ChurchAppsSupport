# 그룹 건강 상태

<div class="article-intro">

그룹 건강 상태 대시보드는 모든 그룹이 어떻게 진행되고 있는지 한눈에 볼 수 있게 해줍니다 — 회원 증감 추이, 출석 평균, 지난 90일간의 성장 또는 감소 — 모두 정렬 가능한 단일 테이블에서 확인할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 의미 있는 데이터를 보려면 회원이 있는 그룹이 최소 몇 개 필요합니다. [그룹 만들기](creating-groups)를 참조하세요.
- 출석 데이터는 기록된 세션에서 가져옵니다. [출석](../attendance/) 섹션을 참조하세요.

</div>

## 그룹 건강 상태 열기

B1 Admin에서 [Jump 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 위의 검색 창)를 열고, **사람들**을 펼친 다음 **그룹**을 클릭하고, 페이지 헤더에서 **그룹 건강 상태** 버튼을 클릭합니다. 대시보드에는 그룹당 한 행씩 있는 테이블이 로드됩니다.

## 열

| 열 | 표시되는 내용 |
|--------|--------------|
| **이름** | 그룹 상세 페이지로 연결되는 그룹 이름 |
| **카테고리** | 그룹의 카테고리 |
| **회원** | 현재 활성 회원 수 |
| **참여(90일)** | 지난 90일 동안 참여한 회원 |
| **탈퇴(90일)** | 지난 90일 동안 탈퇴한 회원 |
| **이탈율(90일)** | 90일 동안의 순 이탈률(백분율) |
| **평균 출석** | 출석 세션당 평균 인원 |

모든 열 헤더를 클릭하면 해당 열로 테이블이 정렬됩니다. 다시 클릭하면 정렬 방향이 반대로 됩니다.

## 건강 상태 데이터 사용

- **높은 이탈율 + 낮은 참여** — 그룹이 축소되고 탈락한 회원을 보충하지 못하는 상황입니다. 그룹 지도자와의 대화가 필요합니다.
- **높은 참여 + 낮은 출석** — 사람들이 가입하지만 나타나지 않습니다. 참여 팔로우업을 고려하세요.
- **높은 평균 출석** — 건강하고 활동적인 그룹입니다. 다른 그룹을 위한 모범 사례입니다.

:::tip
그룹 이름을 클릭하면 개별 회원, 출석 기록 및 달력 이벤트를 검토할 수 있는 그룹 상세 페이지로 직접 이동합니다.
:::
