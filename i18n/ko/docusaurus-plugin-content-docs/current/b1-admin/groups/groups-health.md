# 그룹 건강도

<div class="article-intro">

그룹 건강도 대시보드는 모든 그룹이 어떻게 지내고 있는지 한눈에 보여 줍니다. 구성원 추이, 평균 출석, 지난 90일 동안의 성장 또는 감소를 정렬할 수 있는 하나의 표에서 확인할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 의미 있는 데이터를 보려면 구성원이 있는 그룹이 최소 몇 개는 있어야 합니다. [그룹 만들기](./creating-groups.md)를 참조하세요.
- 출석 데이터는 기록된 세션에서 가져옵니다. [출석](../attendance/index.md) 섹션을 참조하세요.

</div>

## 그룹 건강도 열기 {#opening-groups-health}

B1 Admin에서 [점프 메뉴](../introduction.md#getting-around-with-the-jump-menu)(왼쪽 상단의 검색창)를 열고 **People**을 펼친 뒤 **Groups**를 클릭하고, 페이지 머리글의 **Group Health** 버튼을 클릭합니다. 대시보드에는 그룹당 한 행인 표가 나타납니다.

## 열(Column) {#columns}

| 열 | 표시 내용 |
|--------|--------------|
| **Name** | 그룹 이름이며, 그룹 세부 정보 페이지로 연결됩니다. |
| **Category** | 그룹의 분류입니다. |
| **Members** | 현재 활동 중인 구성원 수입니다. |
| **Joined (90d)** | 지난 90일 동안 가입한 구성원입니다. |
| **Left (90d)** | 지난 90일 동안 떠난 구성원입니다. |
| **Churn (90d)** | 90일 동안의 순 이탈률(백분율)입니다. |
| **Avg Attendance** | 출석 세션당 평균 인원입니다. 출석이 기록되지 않았다면 "-"로 표시됩니다. |
| **Avg Age** | 생년월일이 등록된 구성원의 평균 나이입니다. |
| **Female** / **Male** | 여성과 남성 구성원의 수입니다. |

표는 처음에 이름순으로 정렬되어 있습니다. 열 머리글을 클릭하면 그 열 기준으로 정렬되며, 다시 클릭하면 정렬 방향이 바뀝니다. 페이지 상단의 **Groups**를 클릭하면 그룹 목록으로 돌아갑니다.

## 그룹 한 곳의 건강도 {#one-groups-health}

각 그룹의 페이지에는 **Health** 섹션이 있으며, 지난 90일 동안의 구성원, 가입, 탈퇴를 한 줄로 요약합니다. **See health**를 클릭하면 그 그룹의 건강도 화면이 열립니다. 이 화면에는 **Members**, **Joined (90d)**, **Left (90d)**, **Churn (90d)** 수치, **Membership Changes (12 months)** 차트, 출석을 추적하는 그룹의 **Attendance Trend** 차트, 그리고 구성원의 **Age**(나이)와 **Gender**(성별) 차트가 있습니다.

## 건강도 데이터 활용하기 {#using-health-data}

- **이탈이 높고 가입이 낮음** -- 그룹이 줄어드는데 떠난 구성원을 대체하지 못하고 있습니다. 그룹 리더와 이야기해 볼 가치가 있습니다.
- **가입이 높고 출석이 낮음** -- 사람들이 등록은 하지만 나오지 않고 있습니다. 참여를 높이기 위한 후속 조치를 고려하세요.
- **평균 출석이 높음** -- 건강하고 활동적인 그룹입니다. 다른 그룹의 모범 사례가 될 수 있습니다.

:::tip
그룹 이름을 클릭하면 그룹의 세부 정보 페이지로 바로 이동하여 개별 구성원, 출석 기록, 캘린더 행사를 검토할 수 있습니다.
:::
