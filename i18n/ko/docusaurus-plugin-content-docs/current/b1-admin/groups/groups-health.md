# 그룹 건강

<div class="article-intro">

그룹 건강 대시보드는 모든 그룹이 얼마나 잘하고 있는지를 한눈에 볼 수 있습니다 — 구성원 추세, 출석 평균 및 지난 90일 동안의 성장 또는 감소 — 모두 하나의 정렬 가능한 표에 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 의미 있는 데이터를 보려면 구성원이 있는 최소 몇 개의 그룹이 필요합니다. [그룹 생성](creating-groups)을 참조하세요.
- 출석 데이터는 기록된 세션에서 가져옵니다. [출석](../attendance/) 섹션을 참조하세요.

</div>

## 그룹 건강 열기

B1 Admin에서 왼쪽 상단의 **섹션 메뉴**를 열고 **사람**을 선택한 후 탐색 모음의 **그룹** 탭을 클릭하고 **건강**을 선택합니다. 대시보드는 그룹당 하나의 행을 포함하는 표를 로드합니다.

## 열

| 열 | 표시하는 내용 |
|--------|--------------|
| **이름** | 그룹의 이름, 그룹 세부 정보 페이지에 연결됨 |
| **카테고리** | 그룹의 카테고리 |
| **구성원** | 현재 활성 구성원 수 |
| **가입함(90d)** | 지난 90일 동안 가입한 구성원 |
| **떠남(90d)** | 지난 90일 동안 떠난 구성원 |
| **이탈율(90d)** | 90일 동안의 순 이탈율(백분율) |
| **평균 출석** | 출석 세션당 평균 인원 |

표 열 머리글을 클릭하여 해당 열로 표를 정렬합니다. 다시 클릭하여 정렬 방향을 반대로 합니다.

## 건강 데이터 사용

- **높은 이탈율 + 낮은 가입** — 축소되고 잃어버린 구성원을 대체하지 않는 그룹입니다. 그룹 지도자와의 대화가 필요합니다.
- **높은 가입 + 낮은 출석** — 사람들이 가입하지만 나타나지 않습니다. 참여 후속 조치를 고려하세요.
- **높은 평균 출석** — 건강하고 활동적인 그룹입니다. 다른 그룹의 잠재적 모델입니다.

:::tip
그룹 이름을 클릭하면 개별 구성원, 출석 기록 및 일정 이벤트를 검토할 수 있는 그룹의 세부 정보 페이지로 직접 이동합니다.
:::
