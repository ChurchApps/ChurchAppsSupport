# 그룹 건강

<div class="article-intro">

그룹 건강 대시보드는 모든 그룹이 얼마나 잘하고 있는지에 대한 조감도를 제공합니다. 과거 90일간의 회원 추세, 출석 평균 및 증가 또는 감소 — 모두 단일 정렬 가능한 테이블에 나타납니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 의미 있는 데이터를 보려면 최소한 몇 개 그룹과 회원이 필요합니다. [그룹 생성](creating-groups) 참조.
- 출석 데이터는 기록된 세션에서 가져옵니다. [출석](../attendance/) 섹션 참조.

</div>

## 그룹 건강 열기

B1 Admin에서 왼쪽 위 모서리의 **섹션 메뉴**를 열고 **사람**을 선택한 다음 탐색 표시줄에서 **그룹** 탭을 클릭하고 **건강**을 선택합니다. 대시보드는 그룹당 하나의 행이 있는 테이블을 로드합니다.

## 열

| 열 | 표시 내용 |
|--------|--------------|
| **이름** | 그룹 세부 정보 페이지에 연결된 그룹 이름 |
| **범주** | 그룹의 범주 |
| **회원** | 현재 활성 회원 수 |
| **합류(90일)** | 지난 90일간 합류한 회원 |
| **떠남(90일)** | 지난 90일간 떠난 회원 |
| **이탈(90일)** | 90일간의 순 이탈률(퍼센트) |
| **평균 출석** | 출석 세션당 평균 인원 |

아무 열 헤더를 클릭하여 해당 열로 테이블을 정렬합니다. 다시 클릭하면 정렬 방향이 반대가 됩니다.

## 건강 데이터 사용

- **높은 이탈 + 낮은 합류** — 축소되고 잃은 회원을 대체하지 않는 그룹입니다. 그룹 리더와의 대화 가치가 있습니다.
- **높은 합류 + 낮은 출석** — 사람들이 가입하고 있지만 참석하지 않습니다. 참여 후속 조치를 고려하세요.
- **높은 평균 출석** — 건강하고 활발한 그룹입니다. 다른 그룹의 잠재적 모델입니다.

:::tip
그룹 이름을 클릭하면 개별 회원, 출석 기록 및 달력 이벤트를 검토할 수 있는 그룹의 세부 페이지로 직접 이동합니다.
:::
