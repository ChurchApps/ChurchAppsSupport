# 알림 및 메시지

<div class="article-intro">

B1 Admin은 알림과 개인 메시지를 모든 페이지 오른쪽 위의 사용자 메뉴에 보관합니다. 프로필 사진 위의 빨간 숫자는 읽지 않은 알림과 메시지가 몇 개 기다리고 있는지 보여 주며, 페이지를 새로 고치지 않아도 작업하는 동안 업데이트됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [B1 Admin](https://admin.b1.church)에 로그인하세요. 로그인한 모든 사용자는 알림과 메시지를 받습니다.
- 알림과 메시지는 개인용입니다. 본인에게 보내진 것만 볼 수 있습니다.

</div>

## 사용자 메뉴 열기 {#opening-the-user-menu}

오른쪽 위의 프로필 사진(또는 그 옆의 화살표)을 클릭하세요. 메뉴에는 **Current church**와 다음 항목이 표시됩니다:

- **Messages**와 **Notifications**, 각각 읽지 않은 개수가 표시됩니다
- **Edit Profile** -- **Edit Account**는 [프로필](./profile/managing-profile.md)을 열고, **Edit Church Profile**은 교회 B1 사이트에 있는 디렉터리 프로필을 엽니다
- **Theme Preferences** -- **Default**, **Classic** 또는 **Custom** 색상, 그리고 **Light Mode** 또는 **Dark Mode**
- **Logout**, **Switch App**(B1.Church 또는 Lessons.church), **Switch Church**(계정이 속한 교회 목록)

## 알림 {#notifications}

알림은 본인이 처리해야 할 일을 알려 줍니다. 예를 들면 다음과 같습니다:

- [업무](./serving/tasks.md)가 본인에게 배정되었거나, 그룹 참여 요청 업무가 본인을 위해 만들어졌을 때
- [계획](./serving/plans.md)에 봉사 일정이 잡혔을 때
- 본인이 관리하는 [양식](./forms/managing-submissions.md)에 새 응답이 도착했을 때
- 누군가 본인의 그룹 중 한 곳에 글을 올리거나 공지를 보냈을 때

알림을 읽으려면:

1. 사용자 메뉴를 열고 **Notifications**를 클릭하세요.
2. 각 알림에는 짧은 메시지, 도착한 지 얼마나 되었는지(예: **1d**), 아직 보지 않았다면 **New** 태그가 표시됩니다. 목록을 열면 읽음으로 표시되고 개수가 지워집니다.
3. **View Details**(또는 알림 자체)를 클릭하면 해당 내용으로 이동합니다:
   - 업무는 B1 Admin에서 해당 업무를 엽니다.
   - 양식 응답은 B1 Admin에서 해당 양식의 응답을 엽니다.
   - 봉사 배정은 교회의 B1 사이트에서 계획을 새 탭으로 엽니다. 거기서 수락하거나 거절할 수 있습니다.
   - 다른 알림은 링크가 있다면 새 탭에서 그 링크를 엽니다.
4. 알림 하나를 삭제하려면 휴지통 아이콘을, 모두 삭제하려면 **Clear All**(확인 후)을 클릭하세요.

더 이상 알림이 없으면 목록에 **No notifications -- You're all caught up**!가 표시됩니다.

:::tip
알림을 받는 방법(푸시, 이메일, 앱 내 종 아이콘 또는 문자)과 조용한 시간은 교회 B1 사이트 또는 B1 앱의 [알림 설정](../b1-church/getting-started/notification-preferences.md)에서 설정합니다.
:::

## 메시지 {#messages}

**Messages**에는 교회 성도와 주고받는 본인만의 1:1 대화가 보관됩니다. 교회 B1 사이트와 B1 앱에서 보는 것과 같은 대화입니다.

### 읽고 답장하기 {#reading-and-replying}

1. 사용자 메뉴를 열고 **Messages**를 클릭하세요. 각 대화에는 상대방, 가장 최근 메시지(본인이 보냈다면 앞에 **You**:가 붙습니다), 보낸 시각, 읽지 않은 경우 **New** 태그가 표시됩니다.
2. 대화를 클릭하여 여세요. **Type a message**...에 입력하고 보내기 화살표를 클릭하세요. 이모지 버튼으로 이모지를 넣을 수 있습니다.
3. 뒤로 가기 화살표를 클릭하면 목록으로 돌아갑니다.

대화를 삭제하려면 휴지통 아이콘을 클릭하고 확인하세요.

### 새 메시지 시작하기 {#starting-a-new-message}

1. **Messages**에서 둥근 **+** 버튼을 클릭하세요.
2. **Search for a person** 아래에 이름을 입력하고 **Search**를 클릭하세요.
3. 사람을 클릭하고, 메시지를 작성한 다음 보내세요.
