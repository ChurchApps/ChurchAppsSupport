# WorshipCommons에서 찬양 찾기

<div class="article-intro">

**탐색** 페이지는 WorshipCommons의 찬양 라이브러리입니다. 이미 알고 있는 찬양을 검색하거나, 필터로 목록을 좁혀 주일에 사용할 새로운 찬양을 찾아보세요. 찬양을 검색하거나 재생하는 데 로그인할 필요는 없습니다.

</div>

## 라이브러리 검색하기

1. [worshipcommons.org](https://worshipcommons.org)에 접속한 뒤 페이지 상단의 **탐색**(또는 **찬양 둘러보기**)을 클릭하세요.
2. 검색창에 입력하세요. 제목, 첫 가사, 곡조 이름, 주제, 성경 구절, 작곡자로 검색할 수 있습니다. 입력하는 동안 결과가 바로 업데이트됩니다.
3. **정렬 기준** 메뉴에서 **다운로드 많은 순**, **저장 많은 순**, **최신순**, **제목 가나다순**으로 결과를 정렬할 수 있습니다.
4. 찬양 제목을 클릭하면 해당 [찬양 페이지](./song-page.md)가 열립니다.

:::tip
탐색 페이지 어디에서든 `/` 키를 누르면 검색창으로 바로 이동합니다.
:::

각 행에는 찬양의 작곡자, 연도, 성경 구절(있는 경우), 다운로드 및 저장 횟수, 최대 세 개의 주제, 조성, 분당 박자(BPM) 템포가 표시됩니다. 행 시작 부분의 재생 버튼을 클릭하면 목록을 벗어나지 않고 데모 녹음이나 피아노 미리듣기를 들을 수 있습니다.

## 찬양 필터링하기

**필터**를 클릭하면 필터 패널이 열리거나 닫힙니다(큰 화면에서는 처음부터 열려 있습니다). 같은 그룹 안에서는 여러 값을 선택할 수 있지만, 그룹 간에는 설정한 모든 필터와 일치하는 찬양만 표시됩니다. 각 옵션 옆의 숫자는 일치하는 찬양의 수를 나타냅니다.

- **주제** -- 찬양, 은혜, 소망, 성탄절 등의 주제입니다. 전체 목록은 **더 보기**를 클릭하세요.
- **완성도** -- 찬양 자료가 얼마나 갖추어져 있는지를 나타냅니다: **주일 사용 가능**, **악보**, **미검증 악보**, **코드 차트만**, **가사만**.
- **바로 사용 가능** -- **기타 하나로 가능**, **반주 있음**, **코드 차트 있음**, **악보 있음**, **스템 있음**.
- **조성**과 **박자** -- 특정 조성이나 찬송가 박자를 선택하세요.
- **템포** -- **느림**(분당 73박자 미만), **보통**(73~100), **빠름**(100 이상).
- **언어** -- 특정 언어로 된 찬양입니다.
- **출처** -- 찬양의 라이선스입니다. 예를 들어 **퍼블릭 도메인**, **예배용 무료**, 또는 크리에이티브 커먼즈 라이선스가 있습니다. ⚠ 표시가 있는 라이선스는 비상업적 사용만 허용됩니다.
- **추가 항목** -- **데모 녹음 있음**.

적용된 필터는 결과 위에 칩으로 표시됩니다. 칩의 **X**를 클릭하면 해당 필터가 제거되고, **모든 필터 지우기**를 클릭하면 처음부터 다시 시작할 수 있습니다.

:::info
**언어** 필터는 사이트에서 선택한 언어를 기본값으로 시작하므로, 사용하는 언어의 찬양이 먼저 보입니다. 모든 언어의 찬양을 보려면 결과 위의 언어 칩을 제거하세요. 사이트 언어를 바꾸려면 모든 페이지 하단의 지구본 선택기를 사용하세요.
:::

## 찾는 찬양이 없을 때

일치하는 결과가 없다면 필터를 완화하거나 검색어를 지우세요. WorshipCommons에는 퍼블릭 도메인이거나 작가가 공유하기로 선택한 찬양만 있으므로, 저작권이 있는 대부분의 찬양은 여기에 없습니다. 검색 결과가 없으면 **SongSelect에서 검색 →**을 클릭하여 CCLI 카탈로그에서 찬양을 찾아보세요.

## 다른 방식으로 둘러보기

모든 페이지 하단의 링크는 미리 정리된 목록으로 연결됩니다:

- **새로운 찬양** -- 라이브러리에 추가된 모든 찬양을 최신순으로 보여 줍니다.
- **퍼블릭 도메인 찬송가** -- 모든 용도로 자유롭게 사용할 수 있는 찬송가입니다.
- **CCLI 신고 불필요** -- 교회가 CCLI에 보고하지 않고도 사용할 수 있는 찬양입니다.
- **성탄절 찬양** -- 계절별로 모아 놓은 찬양입니다.

상단 메뉴의 **듣기**를 클릭하면 작가들이 최근 공유한 찬양을 무작위 순서로 차례대로 들을 수 있습니다. 찬양이 재생되는 동안 **+ 찬양 저장**을 클릭하면 저장한 찬양에 추가됩니다(로그인이 필요합니다).
