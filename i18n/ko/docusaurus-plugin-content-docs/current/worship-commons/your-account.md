# WorshipCommons 계정과 작곡가 페이지

<div class="article-intro">

WorshipCommons에서는 계정이 없어도 곡을 둘러보고, 재생하고, 인쇄하고, 프로젝션할 수 있습니다. 무료 계정을 만들면 곡을 저장하고, 직접 만든 곡을 공유하고, 수정을 제안하고, 보낸 모든 항목을 추적할 수 있습니다. 곡을 쓰는 분이라면 계정으로 교회에 표시되는 작곡가 페이지도 편집할 수 있습니다.

</div>

## 로그인 또는 계정 만들기

WorshipCommons는 ChurchApps 계정을 사용합니다. 이미 계정이 있다면(예: B1에서 만든 계정) 같은 이메일과 비밀번호로 로그인할 수 있습니다.

1. 상단 메뉴에서 **로그인**을 클릭합니다.
2. **이메일**과 **비밀번호**를 입력한 다음 **로그인**을 클릭합니다.

**계정을 만들려면:**

1. 로그인 페이지에서 **계정 만들기**를 클릭합니다.
2. **이름**, **성**, **이메일**을 입력한 다음 **계정 만들기**를 클릭합니다.
3. 이메일로 받은 6자리 코드를 확인하여 입력하고 **코드 확인**을 클릭합니다.
4. 8자 이상의 비밀번호를 선택하고 **비밀번호 확인** 칸에 다시 입력한 다음 **비밀번호 설정 및 로그인**을 클릭합니다.

**비밀번호를 잊으셨나요?** 로그인 페이지에서 **비밀번호를 잊으셨나요?**를 클릭하고, 이메일을 입력한 다음 **코드 보내기**를 클릭합니다. 그다음 이메일로 받은 코드를 입력하고 새 비밀번호를 설정하세요.

로그인하면 상단 메뉴에 이름이 표시됩니다. 이름을 클릭하면 **내 제출 항목** 또는 **보고**를 열거나 **로그아웃**할 수 있습니다.

## 저장한 곡

곡 페이지에서 하트를 클릭하면 곡을 저장할 수 있습니다. 상단 메뉴에서 **저장한 곡**을 클릭하면 저장한 모든 곡을 볼 수 있습니다. 저장한 곡은 계정에 보관되므로 로그인하는 모든 기기에서 볼 수 있습니다. 목록에서 곡을 빼려면 **제거**를 클릭하세요.

:::tip
저장한 곡은 간단한 즐겨찾기 목록입니다. 키와 구성 요소까지 포함해 특정 주일의 순서를 계획하려면 [서비스 계획](./service-plans.md)을 사용하세요.
:::

## 내 제출 항목

상단 메뉴에서 이름을 클릭하고 **내 제출 항목**을 선택하면 시작하거나 보낸 모든 곡과 변경 사항, 그리고 각각의 진행 상태를 볼 수 있습니다. 상단의 탭 **전체**, **임시 저장**, **검토 중**, **공개**, **승인되지 않음**을 사용하여 목록을 걸러볼 수 있습니다.

각 항목에는 유형(**새 곡**, **번역**, **편곡**, **수정**, **삭제 요청** 등)과 상태가 표시됩니다.

| 상태 | 의미 |
| --- | --- |
| **임시 저장** | 시작했지만 아직 보내지 않았습니다. **계속**을 클릭하여 마무리하거나 **임시 저장 삭제**를 클릭하여 제거할 수 있습니다. |
| **변경 요청됨** | 검토자가 변경을 요청했습니다. **계속**을 클릭하여 수정한 다음 다시 보내세요. |
| **검토 중** | 공개되기 전에 사람이 모든 곡을 검토하며, 보통 며칠 안에 완료됩니다. **철회**를 클릭하면 임시 저장 상태로 되돌릴 수 있습니다. |
| **공개** | 라이브러리에 있으며 교회가 무료로 사용할 수 있습니다. 다운로드 횟수와 링크가 표시됩니다. |
| **승인되지 않음** | 라이브러리에 들어가지 못했습니다. 검토자의 사유가 표시됩니다. |
| **철회됨** | 검토되기 전에 직접 철회했습니다. |
| **내려짐** | 요청에 따라 곡이 라이브러리에서 제거되었습니다. |

공개된 곡의 경우 **링크 복사**를 클릭하여 곡 페이지를 공유하거나, **수정 제안**을 클릭하여 변경을 제안하거나, **삭제 요청**을 클릭하여 내려 달라고 요청할 수 있습니다. [곡 수정 제안 및 곡 신고](./proposing-edits.md)를 참고하세요.

:::info
WorshipCommons 팀이 나를 곡의 공동 발행인으로 추가하면(예: 다른 사람이 업로드한 공동 작곡 곡), 직접 제출하지 않았더라도 **내 제출 항목**에 **공개** 상태로 표시됩니다. 곡의 발행인으로서 해당 곡의 라이선스가 공개 수정을 막더라도 변경할 수 있습니다.
:::

## 작곡가 페이지

라이브러리에 있는 모든 작곡가에게는 그가 쓴 곡을 나열하는 작곡가 페이지가 있으며, 각 곡의 연도, 키, 주제, 라이선스가 함께 표시됩니다. 교회는 곡 페이지에서 작곡가의 이름을 클릭하여 이 페이지에 접근합니다. 곡에 여러 작곡가가 있으면 각 이름이 해당 작곡가의 페이지로 연결됩니다.

작곡가 페이지에는 사진, 짧은 소개, 링크, 그리고 교회가 해당 작곡가의 다른 사역을 후원할 수 있는 후원 링크도 표시할 수 있습니다.

### 작곡가 페이지 편집하기

공개된 곡 중 하나가 본인의 이름으로 등록되면 작곡가 페이지가 생깁니다.

1. 상단 메뉴에서 이름을 클릭하고 **내 제출 항목**을 선택합니다.
2. **작곡가 프로필**을 클릭합니다.
3. **소개** 항목에 본인이 누구인지, 어떤 곡을 쓰는지 몇 문장으로 적습니다(최대 2,000자).
4. **링크** 항목에서 웹사이트 등 최대 5개의 링크를 추가합니다. 각 링크에 **라벨**과 웹 주소를 입력하세요. 다른 줄을 추가하려면 **링크 추가**를 클릭합니다.
5. **후원 링크** 항목에서 교회가 사역을 후원할 수 있는 곳(상점이나 사역 페이지 등)을 추가합니다. 다른 줄을 추가하려면 **후원 링크 추가**를 클릭합니다.
6. **프로필 저장**을 클릭합니다.

**작곡가 페이지 보기**를 클릭하면 교회가 보는 것과 같은 화면을 확인할 수 있습니다. 후원 링크는 각 곡 페이지에 **작곡가 페이지** 버튼으로도 표시됩니다.

:::tip
곡을 함께 작곡했거나 계정에 연결되지 않은 작곡가 페이지가 이미 있나요? [support@churchapps.org](mailto:support@churchapps.org)로 이메일을 보내 계정에 연결해 달라고 요청하세요.
:::
