# WorshipCommons 노래 발표 및 내보내기

<div class="article-intro">

WorshipCommons는 별도의 설치 없이 브라우저에서 바로 노래 가사를 화면에 띄울 수 있습니다. 교회에서 이미 프레젠테이션 소프트웨어를 사용하고 있다면, 대신 노래 슬라이드를 FreeShow, OpenLP, ProPresenter 또는 PowerPoint용으로 다운로드하거나, B1 Admin 노래 라이브러리에 노래를 추가하세요.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [worshipcommons.org](https://worshipcommons.org)에서 노래 페이지를 여세요. [노래 찾기](./finding-songs.md)를 참고하세요.
- 가사를 TV나 프로젝터에 띄우려면 HDMI 케이블로 컴퓨터를 연결하세요(또는 화면을 캐스팅하세요).

</div>

## 브라우저에서 예배 인도하기

**Lead worship**(예배 인도)은 음악을 재생하고 가사를 한 줄씩 보여주며, 노래하는 동안 각 단어를 하이라이트하는 전체 화면 보기입니다. 밴드가 없는 소그룹, 교실 또는 가정 교회를 위해 만들어졌습니다.

1. 노래 페이지에서 **Lead worship**을 클릭하세요. (노래에 함께 연주할 음악이 있을 때 버튼이 나타납니다.)
2. **Key**(조성)와 **Tempo**(템포)를 선택하세요. 노래에 피아노 미리듣기가 있으면 **Piano**(피아노) 또는 **Organ**(오르간)을 고를 수 있습니다.
3. **Verses**(절)를 클릭해 부를 절을 고르고, 화살표 버튼으로 순서를 바꾸세요.
4. 음악이 시작되기 전에 카운트를 원하면 **Count-in**(카운트인)을 켜세요.
5. **▶ Play**(재생)를 클릭하세요.

가사를 숨기려면 **Blank**(빈 화면)를, 고대비 화면을 원하면 **Contrast**(고대비)를, 화면을 가득 채우려면 **Fullscreen**(전체 화면)을 사용하세요. TV에 띄우는 빠른 단계는 **Put this on the TV**(TV에 띄우기)를 클릭하면 볼 수 있습니다.

:::tip
키보드 단축키: **Space** 재생/일시정지, **← →** 줄 이동, **↑ ↓** 절 이동, **B** 빈 화면, **H** 고대비, **F** 전체 화면, **Esc** 노래 페이지로 돌아가기. 단축키를 보려면 화면 하단의 **Show keys**(단축키 보기)를 클릭하세요.
:::

## 가사 프로젝션하기

**Open projector**(프로젝터 열기)는 화면마다 가사 한 섹션씩 보여주며, 직접 손으로 넘겨 가며 진행합니다. 라이브 연주자가 있을 때 사용하세요.

1. 노래 페이지에서 **Projection**(프로젝션) 패널을 찾아 **Open projector**(프로젝터 열기)를 클릭하세요.
2. **F**를 누르거나 **Fullscreen**(전체 화면)을 클릭해 화면을 가득 채우세요.
3. 화면을 클릭하거나 **Space** 또는 **→** 키를 눌러 다음 슬라이드로 넘어가세요. **←**를 누르면 이전 슬라이드로 돌아갑니다. 하단의 섹션 이름을 클릭하면 바로 그 섹션으로 이동합니다.
4. **B**를 눌러 화면을 비우고, **H**를 눌러 고대비로 전환하세요.
5. 끝나면 **Esc**를 누르거나 **← Back to song**(노래로 돌아가기)을 클릭하세요.

하단 바에는 현재 섹션, 슬라이드 수, 그리고 다음 내용이 표시됩니다. 노래의 저작자 표시 줄도 화면에 나타납니다.

## 슬라이드 내보내기

노래 페이지의 **Projection**(프로젝션) 패널에는 각 도구별 버튼이 있습니다. 하나를 클릭하면 노래를 다운로드합니다.

| 버튼 | 결과물 |
| --- | --- |
| **FreeShow** | [FreeShow](https://freeshow.app)로 가져올 수 있는 쇼 파일 |
| **PowerPoint** | PPTX 슬라이드 파일 |
| **OpenLP** | OpenLP로 가져올 수 있는 OpenLyrics 파일 |
| **ProPresenter** | ProPresenter로 가져올 수 있는 텍스트 파일 |
| **OnSong / PCO** | OnSong 또는 Planning Center에 붙여넣을 수 있도록 노래를 클립보드에 복사 |

버튼 아래의 참고 문구는 슬라이드가 어떻게 나뉘는지 알려 줍니다. 노래에 승인된 형식 맵(form map)이 있으면 슬라이드는 그 맵을 따르고, 없으면 기록된 절을 그대로 따릅니다. 모든 내보내기 파일에는 노래의 저작자 표시와 라이선스 정보가 포함됩니다.

:::tip
선택한 조성과 섹션으로 전체 세트를 한 번에 내보내려면 [예배 순서표](./service-plans.md)를 만든 뒤 그곳의 내보내기 버튼을 사용하세요.
:::

## B1에 WorshipCommons 노래 추가하기

교회에서 B1 Admin으로 예배를 계획한다면 아무것도 다운로드할 필요가 없습니다. WorshipCommons의 주일 예배용 노래는 B1 Admin의 노래 검색에서 **WorshipCommons — free**(WorshipCommons — 무료) 항목으로 나타납니다. 하나를 클릭하면 WorshipCommons 페이지와 연결된 상태로 노래 라이브러리에 추가됩니다.

단계는 [B1 Admin의 노래](../b1-admin/serving/songs.md#free-songs-from-worshipcommons)를 참고하세요.
