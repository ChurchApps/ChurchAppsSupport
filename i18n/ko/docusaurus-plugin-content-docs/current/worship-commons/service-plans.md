# WorshipCommons 서비스 계획

<div class="article-intro">

WorshipCommons의 서비스 계획은 주일의 셋리스트입니다. 곡의 순서를 정하고, 각 곡의 키와 카포, 구간을 고른 다음, 밴드와 공유할 링크 하나를 보내세요. 계획에서 악보 스탠드용 무대 보기를 열거나, 소책자를 인쇄하거나, 전체 셋을 프레젠테이션 소프트웨어로 내보낼 수 있습니다.

</div>

:::info
서비스 계획은 계정이 아니라 웹 브라우저에 저장되며, 사용하는 데 로그인할 필요도 없습니다. 공유 링크에는 셋 전체 내용이 담기므로 기기를 바꿀 때를 대비해 링크를 저장해 두세요. 교회에서 B1 Admin으로 예배를 계획한다면 대신 [계획](../b1-admin/serving/plans.md)을 참고하세요.
:::

## 서비스 계획 만들기

1. 상단 메뉴에서 **서비스 계획**을 클릭하세요.
2. "9월 14일 주일"이나 "청년 모임"처럼 이름을 입력하고 **서비스 계획 만들기**를 클릭하세요.

곡 페이지에서도 계획을 시작할 수 있습니다. 곡 페이지에서 **+ 서비스 계획에 추가**를 클릭한 다음, 목록 아래에 이름을 입력하고 **만들기**를 클릭하세요.

## 곡 추가하기

1. 곡 페이지를 여세요. 먼저 원하는 키를 설정하세요. 곡은 화면에 보이는 키로 계획에 들어갑니다.
2. **+ 서비스 계획에 추가**를 클릭하세요.
3. 계획 이름을 클릭하세요. 체크 표시가 나타나면 곡이 그 계획에 들어간 것입니다. 다시 클릭하면 제외됩니다.

그러면 버튼에 **✓ 포함**과 함께 계획 이름이 표시됩니다. 팝업에서 계획 이름이 적힌 **열기** 링크를 클릭하면 해당 계획으로 이동합니다.

## 셋 구성하기

**서비스 계획** 페이지에서 계획을 여세요. 각 곡에 대해 다음을 할 수 있습니다.

- **순서 변경** -- **↑**와 **↓** 버튼을 사용하거나 곡을 원하는 위치로 끌어다 놓으세요. **삭제**를 클릭하면 제외됩니다.
- **키** -- 곡의 **발행된 키** 중에서 고르거나, **미리보기(모든 키)**에 나열된 다른 키 중에서 고르세요.
- **카포** -- 카포 프렛을 선택하세요. 계획에 연주할 코드 모양이 표시됩니다.
- **구간** -- 절과 후렴의 순서를 정하세요. 화살표로 구간을 옮기고, **×**로 제외하고, **+ 구간 추가**로 구간을 추가할 수 있습니다(예: 반복되는 후렴). **기본값으로 재설정**을 클릭하면 곡의 기본 순서로 돌아갑니다.
- **편곡** -- "마지막에 후렴 2회 반복, 마지막 절은 무반주"처럼 밴드를 위한 짧은 메모를 입력하세요.

계획 상단에는 곡 수와 셋의 대략적인 길이가 표시됩니다. 변경 내용은 자동으로 저장됩니다.

## 팀과 공유하기

1. **공유 링크**를 클릭하세요. 링크가 클립보드에 복사됩니다.
2. 문자 메시지나 이메일로 밴드에 보내세요.

링크를 연 사람은 계정이 없어도 모든 키, 카포, 구간, 메모가 포함된 계획을 볼 수 있습니다. **사본 저장**을 클릭하면 자신의 브라우저에 수정 가능한 사본을 따로 보관할 수 있습니다.

**서비스 계획** 페이지에서는 계획을 **공유**, **이름 바꾸기**, **복제**, **삭제**할 수도 있습니다.

## 주일에 계획 사용하기

- **무대 모드** -- 악보 스탠드에 놓인 태블릿을 위해 화면마다 악보 하나씩 보여 줍니다. 화살표(또는 **←**와 **→** 키)로 곡 사이를 이동하고, 글자 크기 버튼으로 악보를 키울 수 있습니다. 무대 모드는 화면이 꺼지지 않도록 유지하려고 하며, 상단 막대에 **화면 켜짐 유지 중**이라고 표시되면 적용된 상태입니다.
- **소책자 인쇄** -- 모든 악보를 순서대로, 한 페이지에 하나씩 인쇄합니다. 표지에는 곡 목록과 키가 나옵니다. **큰 글씨** 또는 **코드 표시**를 고른 다음 **인쇄**를 클릭하세요.
- **OnSong / Planning Center용 복사** -- 선택한 키와 구간으로 모든 악보를 복사하여 바로 붙여 넣을 수 있게 합니다.

## 셋 내보내기

**FreeShow**, **OpenLP**, **ProPresenter**, **PowerPoint** 중 하나를 클릭하면 선택한 키와 구간으로 구성된 셋 전체를 해당 도구용으로 내려받습니다.

**가정교회 팩**을 클릭하면 각 곡의 악보(선택한 키), 가사, 슬라이드, 출처 표기, 셋리스트, LICENSE.txt 파일 하나가 담긴 ZIP 파일을 내려받습니다.

:::warning
**동일조건변경허락(CC BY-SA) 팩 포함**을 선택하지 않으면 CC BY-SA 라이선스 곡은 가정교회 팩에서 제외됩니다. 이 곡들을 포함하면 팩을 바탕으로 만든 모든 결과물을 같은 라이선스로 공유해야 합니다. 악보, 무대 모드, 소책자에는 이 곡들이 항상 포함됩니다.
:::
