# B1App 탐색

<div class="article-intro">

B1.church의 멤버 포털은 휴대폰 중심의 웹 앱으로 `/mobile` 아래에 있습니다. 모든 브라우저에서 작동하며 홈 화면에 설치할 수 있습니다. 이 페이지에서는 홈 대시보드, 아래쪽 탭 표시줄, 더 보기 메뉴, 그리고 내 페이지를 설명합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 개인 정보를 보려면 [로그인](./logging-in.md)되어 있어야 합니다. 로그아웃한 방문자도 공개 콘텐츠를 탐색할 수 있으며 계정이 필요한 기능이 있으면 **로그인** 버튼이 표시됩니다.

</div>

## 홈

`https://yourchurchname.b1.church/mobile`을 열면 `/mobile/dashboard`의 **홈** 대시보드로 이동합니다. 홈은 멤버 포털의 랜딩 페이지이며 다음을 표시합니다:

- 이름이 포함된 인사말
- 오늘의 성경 구절
- 교회에서 강조한 특별 카드
- 교회에서 활성화한 도구(그룹, 헌금, 체크인, 설교, 계획 등)의 **탐색** 그리드

탐색에서 카드를 탭하면 해당 도구가 열립니다. 교회에 대시보드에 맞는 것보다 더 많은 도구가 있으면 마지막 카드는 **더 보기**로, `/mobile/more`의 전체 목록을 엽니다.

## 아래쪽 탭 표시줄

휴대폰에서는 탭 표시줄이 화면 맨 아래에 고정됩니다:

- **홈** -- 항상 첫 번째 탭
- 교회가 구성한 최대 3개의 탭
- **더 보기** -- 탐색 메뉴를 엽니다.

교회에서 3개 이상의 탭을 구성했으면 나머지는 손실되지 않습니다: **더 보기** 메뉴와 대시보드의 탐색 그리드에 나타납니다. 교회 관리자는 B1 Admin의 **모바일 → 탐색** 아래에서 탭 순서를 설정합니다.

## 메뉴

**더 보기**를 탭하면 탐색 메뉴가 열립니다. 태블릿이나 데스크톱에서는 같은 메뉴가 화면의 왼쪽을 따라 항상 표시됩니다. 다음을 포함합니다:

- 이름과 사진, **프로필 편집** 바로 가기 — [프로필 편집](./editing-your-profile.md)을 참고하세요.
- **홈** 및 **내**
- **관리자 포털** -- 교회에서 관리자 권한이 있는 경우에만 표시됩니다; B1 Admin을 엽니다.
- 교회가 구성한 모든 탭, 순서대로
- **앱 설치** -- `/mobile/install`의 [설치 지침](./installing-pwa.md)을 엽니다.
- 밝음/어두움 모드 토글
- **로그인** 또는 **로그아웃**
- 교회의 이름과 개인 정보 보호 정책 링크

## 앱 바

모든 화면 상단의 바는 다음을 표시합니다:

- 화면 제목, 또는 홈의 교회 이름
- 세부 화면을 드릴다운했을 때의 뒤로 가기 화살표
- 알림 및 메시지용 **벨** 아이콘, 읽지 않은 항목에 대한 배지 포함
- 개인 프로필 페이지 `/mobile/profileEdit`를 여는 **프로필 사진** — [프로필 편집](./editing-your-profile.md)을 참고하세요.

## 내 페이지

**내** (`/mobile/me`)는 당신의 개인 허브입니다. 프로필, [알림 설정](./notification-preferences.md), 메시지, [헌금](../giving/), [등록](../events/my-registrations.md)으로의 바로 가기를 나열한 후, 당신을 위해 다가오는 것 -- 봉사 할당, 행사 등록, 그룹 행사 -- 와 당신의 가장 최근 알림을 나열합니다. 자세한 내용은 [내 페이지](./me-page)를 참고하세요.

로그아웃했으면 내 페이지는 대신 **로그인** 버튼을 표시합니다.

## 홈 화면에 설치

멤버 포털은 Progressive Web App입니다. `/mobile/install`을 방문하거나 (또는 메뉴에서 **앱 설치** 선택) 당신의 기기를 위한 단계별 지침을 받습니다. 설치되면 브라우저 크롬 없이 홈 화면에서 전체 화면으로 열립니다. [앱으로 설치(PWA)](./installing-pwa.md)를 참고하세요.

## 교회의 공개 웹사이트

멤버 포털 외부에서 교회의 공개 웹사이트는 관리자가 구성한 링크가 포함된 자체 헤더 탐색을 가지고 있습니다 -- [설교](../content/sermons.md), [성경](../content/bible.md), [라이브 스트리밍](../content/live-streaming.md), 공개 그룹 목록과 같은 페이지. 휴대폰에서 그 링크들은 헤더의 오른쪽 상단 햄버거 아이콘 뒤에 있습니다.

:::info
당신이 보는 탭과 도구는 교회에 따라 다릅니다. 관리자는 B1 Admin을 통해 멤버에게 어떤 섹션이 표시되는지 제어하므로, 여기에서 설명한 기능이 보이지 않으면 교회에서 활성화하지 않았을 수 있습니다.
:::
