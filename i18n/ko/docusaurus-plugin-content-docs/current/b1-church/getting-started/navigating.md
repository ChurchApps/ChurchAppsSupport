# B1App 둘러보기

<div class="article-intro">

B1.church의 회원 포털은 `/mobile` 아래에 있는 휴대폰 중심 웹 앱입니다. 어떤 브라우저에서든 사용할 수 있으며 홈 화면에 설치할 수도 있습니다. 이 페이지에서는 홈 대시보드, 하단 탭 바, 더 보기 페이지, 나 페이지를 설명합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 개인 정보를 보려면 [로그인](./logging-in.md)해야 합니다. 로그아웃한 방문자도 공개 콘텐츠를 둘러볼 수 있으며, 계정이 필요한 기능에서는 **로그인** 버튼이 표시됩니다.

</div>

## 홈 {#home}

`https://yourchurchname.b1.church/mobile`을 열면 회원 포털의 시작 페이지인 `/mobile/dashboard`의 **홈** 대시보드로 이동합니다. 홈은 인사말("좋은 아침입니다", "좋은 오후입니다", "좋은 저녁입니다"와 이름)과 오늘 날짜로 시작하며, 해당되는 경우에만 나타나는 섹션이 이어집니다:

- **최신 설교** -- 교회의 최신 설교이며, **모든 설교** 링크가 있습니다
- **오늘의 말씀** -- 오늘의 말씀이며, 누르면 전체 [오늘의 말씀](../content/verse-of-the-day.md) 페이지가 열립니다
- **섬기는 일** -- 다가오는 다음 섬김 배정이며, **모든 계획** 링크가 있습니다. 아직 응답이 필요한 배정이 있으면 가장 먼저 표시되며, **응답 필요** 배지와 **수락** / **거절** 버튼이 함께 나타나 홈에서 바로 응답할 수 있습니다(**거절**은 먼저 확인을 요청합니다). 그렇지 않으면 다음 배정에 **수락됨** 또는 **확정됨** 배지가 표시됩니다. 배정을 누르면 해당 계획이 열립니다.
- **내 그룹** -- 내 그룹 중 최대 세 개의 모임 시간과 장소이며, **모든 그룹** 링크가 있습니다
- **헌금** -- 올해 드린 금액("올해 헌금액"), **헌금하기** 버튼, 그리고 [헌금 내역](../giving/donation-history.md)으로 이동하는 **내역** 링크
- **_우리 교회_에서 더 보기** -- 하단 탭 바에 없고 위에 표시되지 않은, 교회가 켜 둔 나머지 도구의 버튼입니다. 자주 사용하는 항목이 앞쪽으로 옮겨집니다.

섬기는 일, 그룹, 헌금 섹션은 로그인했고, 교회가 해당 도구를 켜 두었고, 보여줄 것이 있을 때만 나타납니다(예: 다가오는 배정이나 그룹 한 개 이상). 컴퓨터에서는 홈이 두 개의 열로 배치됩니다.

로그아웃한 상태에서는 홈에 인사말 대신 **환영합니다** 제목, "로그인하여 그룹, 헌금 등을 확인하세요."라는 짧은 안내, **로그인** 버튼이 표시됩니다. 교회가 홈에 아무것도 설정하지 않았더라도 이 안내는 표시됩니다. 교회는 이 안내 문구를 바꾸거나 숨길 수 있습니다 -- [모바일 앱 설정](../../b1-admin/settings/mobile-app.md#home-screen-sign-in-prompt)을 참조하십시오. 숨겨진 경우에도 **더 보기** 페이지나 **나** 페이지에서 로그인할 수 있습니다.

## 하단 탭 바

휴대폰에서는 화면 하단에 탭 바가 고정되어 있습니다:

- **홈** -- 항상 첫 번째 탭입니다
- 교회가 설정한 탭 중 최대 세 개
- **더 보기** -- 더 보기 페이지를 엽니다

외부 웹사이트, 사용자 지정 페이지, 오늘의 말씀 링크에는 탭이 주어지지 않습니다. 교회가 설정한 탭이 탭 바에 다 들어가지 않으면, 나머지 탭은 사라지지 않고 **더 보기** 페이지와 홈의 **_우리 교회_에서 더 보기** 섹션에 나타납니다. 교회 관리자는 B1 Admin에서 **Mobile → Navigation**으로 이동하여 탭 순서를 설정합니다.

## 컴퓨터에서

컴퓨터나 큰 태블릿처럼 화면이 넓으면, 하단 탭 바 대신 화면 상단에 교회 색상의 헤더가 표시됩니다. 헤더에는 교회 이름(누르면 홈으로 돌아감), **홈**, 교회가 설정한 탭 중 최대 다섯 개, **더 보기**가 있으며, 오른쪽에는 알림 종 아이콘과 프로필 사진이 있습니다. 상세 화면을 열면 페이지 내용 위에 **뒤로** 링크가 나타납니다.

## 더 보기 페이지 {#the-more-page}

**더 보기**를 누르면 `/mobile/more`의 더 보기 페이지가 열립니다. 여기에는 다음이 있습니다:

- 이름과 사진, 그리고 **프로필 편집** 링크 -- [프로필 편집하기](./editing-your-profile.md)를 참조하십시오
- 교회 이름 아래에 교회가 설정한 모든 탭이 순서대로 표시됩니다. 외부 웹사이트 링크는 새 브라우저 탭에서 열립니다.
- **계정** 섹션:
  - **나** -- 개인 페이지(로그인한 경우에만)
  - **화면 설정** -- **라이트 모드**와 **다크 모드** 전환
  - **관리자 포털** -- 교회에서 관리자 권한이 있는 경우에만 표시되며, B1 Admin을 새 탭에서 엽니다
  - **앱 설치** -- `/mobile/install`의 [설치 안내](./installing-pwa.md)를 엽니다(앱이 설치되면 숨겨짐)
- **로그아웃**, 또는 로그아웃 상태라면 **로그인** 버튼
- 교회 이름과 개인정보 처리방침 링크

## 앱 바

휴대폰에서 모든 화면 위쪽의 바에는 다음이 표시됩니다:

- 홈과 기타 주요 화면에서는 교회 이름, 상세 화면으로 들어갔을 때는 뒤로 가기 화살표가 나타납니다. 화면 제목은 페이지 맨 위에 나타납니다.
- 알림과 메시지를 위한 **종** 아이콘과, 읽지 않은 항목을 나타내는 배지 -- 아래 [알림 및 메시지](#notifications-and-messages)를 참조하십시오
- **프로필 사진**. 누르면 `/mobile/profileEdit`의 프로필이 열립니다 -- [프로필 편집하기](./editing-your-profile.md)를 참조하십시오

종 아이콘과 프로필 사진은 로그인했을 때만 나타납니다.

## 알림 및 메시지 {#notifications-and-messages}

종을 누르면 두 섹션이 있는 패널이 열립니다:

- **메시지** -- 최근 개인 대화 목록이며, 새 대화를 시작하는 **새 메시지** 링크가 있습니다
- **알림** -- 최근 알림 목록이며, 읽지 않은 항목에는 **새로** 배지가 있습니다. 알림을 누르면 알림이 온 그룹, 계획, 또는 대화로 이동합니다.

각 섹션에는 읽지 않은 항목 수가 표시됩니다. 하단의 **모두 보기**를 누르면 `/mobile/notifications`의 전체 받은 편지함이 열립니다.

## 섹션이 있는 페이지

상세 페이지 -- 그룹, 계획, 나 페이지, 계획 및 헌금 화면 -- 은 탭 대신 섹션들로 구성된 한 페이지로 배치됩니다. 각 섹션은 짧은 미리보기를 보여주며, 섹션 머리글의 링크(**모든 회원**, **모든 행사**, **전체 예배 순서** 등)를 누르면 전체 목록이 열립니다. 이 보기 상단의 **돌아가기** 링크는 이전 페이지로 돌아갑니다.

## 나 페이지

**나**(`/mobile/me`)는 개인 허브입니다. **프로필 편집**과 **설정**([알림 기본 설정](./notification-preferences.md)) 버튼이 있는 이름과 사진을 보여준 뒤, 다가오는 일정(섬기는 배정, 행사 등록, 그룹 행사)을 보여주고, 이어서 가구, 그룹, 올해의 [헌금](../giving/), [등록](../events/my-registrations.md) 내역, 최근 알림과 메시지를 보여줍니다. 자세한 내용은 [나 페이지](./me-page)를 참조하십시오.

로그아웃한 상태에서는 나 페이지에 대신 **로그인** 버튼이 표시됩니다.

## 홈 화면에 설치하기

회원 포털은 프로그레시브 웹 앱(PWA)입니다. `/mobile/install`을 방문하거나(또는 더 보기 페이지에서 **앱 설치** 선택) 기기별 단계별 안내를 확인하십시오. 설치한 후에는 브라우저 크롬 없이 홈 화면에서 전체 화면으로 열립니다. [앱(PWA)으로 설치하기](./installing-pwa.md)를 참조하십시오.

## 교회의 공개 웹사이트

회원 포털 밖에서, 교회의 공개 웹사이트에는 관리자가 설정한 머리글 탐색 링크가 있습니다 -- [설교](../content/sermons.md), [성경](../content/bible.md), [실시간 방송](../content/live-streaming.md), 공개 그룹 목록 같은 페이지입니다. 휴대폰에서는 이 링크들이 머리글 오른쪽 위의 햄버거 아이콘 뒤에 있습니다.

:::info
보이는 탭과 도구는 교회마다 다릅니다. 관리자는 B1 Admin을 통해 회원에게 보이는 섹션을 제어하므로, 여기서 설명하는 기능이 보이지 않으면 교회가 해당 기능을 켜지 않았을 수 있습니다.
:::
