# B1App 둘러보기

<div class="article-intro">

B1.church의 교인 포털은 `/mobile` 경로에서 제공되는 휴대폰 중심의 웹 앱입니다. 어떤 브라우저에서나 사용할 수 있으며, 홈 화면에 설치할 수도 있습니다. 이 페이지에서는 홈 대시보드, 하단 탭 바, 더보기 페이지, 내 정보 페이지에 대해 설명합니다.

## 홈 {#home}

`https://yourchurchname.b1.church/mobile`에 접속하면 `/mobile/dashboard`의 **홈** 대시보드로 이동합니다. 홈은 교인 포털의 시작 페이지입니다. 상단에는 인사말("좋은 아침입니다", "좋은 오후입니다", 또는 "좋은 저녁입니다"와 이름)과 오늘 날짜가 표시되고, 그 아래에 해당하는 경우에만 나타나는 섹션들이 이어집니다.

- **사진 타일** -- 교회에서 사진을 지정한 탭(성경 구절 오늘의 말씀 포함)이 교회 이름 아래에 사진 타일로 나타납니다. 교회 설정에 따라 두 열 격자, 좌우로 넘겨 보는 가로 줄(자동으로 움직이기도 함), 또는 각 항목 옆에 작은 썸네일이 있는 목록 중 하나로 배열됩니다. 자세한 내용은 [홈 화면 타일](../../b1-admin/settings/mobile-app.md#home-screen-tiles)을 참고하세요. 가로 줄의 타일이 화면에 다 들어가지 않으면 줄 아래에 점들이 표시되어 현재 위치를 알려 줍니다. 점을 누르면 해당 타일로 바로 이동합니다. 줄은 계속 앞으로 움직이며, 마지막 타일 다음에는 처음 타일로 돌아갑니다. 탭 바에 자리가 있는 사진 탭도 모두 여기에 표시됩니다.
- **최근 설교** -- 교회의 가장 최근 설교이며, **모든 설교** 링크가 함께 있습니다.
- **오늘의 말씀** -- 오늘의 성경 구절입니다. 누르면 전체 [오늘의 말씀](../content/verse-of-the-day.md) 페이지가 열립니다.
- **섬김 일정** -- 다가오는 섬김 배정 목록이며, **모든 계획** 링크가 함께 있습니다. 아직 응답이 필요한 배정이 있으면 가장 먼저 표시되며, **응답 필요** 배지와 **수락** / **거절** 버튼이 함께 나타나 홈에서 바로 응답할 수 있습니다(**거절**은 먼저 확인을 요청합니다). 응답이 필요한 배정이 없으면 다음 배정에 **수락됨** 또는 **확정됨** 배지가 표시됩니다. 배정을 누르면 해당 계획이 열립니다.
- **내 소그룹** -- 모임 시간과 장소가 함께 표시되는 소그룹이 최대 세 개까지 나타나며, **모든 소그룹** 링크가 함께 있습니다.
- **다가오는 행사** -- 로그인한 경우, 다가오는 소그룹 행사 3개와 행사 등록 내역이 날짜순으로 함께 표시됩니다. 각 항목에는 날짜와 시간이 나오며, 행사에 사진이 있으면 썸네일도 보입니다. 각 줄에는 **행사**(소속 소그룹의 행사) 또는 **등록**(내가 [등록한](../events/registering.md) 행사) 표시가 붙습니다. 등록한 행사는 한 번만, 등록 항목으로 표시됩니다. 행사를 누르면 해당 소그룹의 행사 목록이, 등록 항목을 누르면 내 [등록 내역](../events/my-registrations.md)이 열립니다. **모든 다가오는 행사**를 누르면 [내 정보 페이지](./me-page.md#upcoming)에서 전체 목록을 볼 수 있으며, 여기에는 섬김 배정과 등록 내역도 포함됩니다.
- **내 출석**과 **내 양식** -- 교회에서 기능을 켜 두었다면, 최근 90일 동안의 출석 횟수와 가장 최근 방문 두 건, 그리고 최근에 제출한 양식 두 건이 전체 목록 링크와 함께 표시됩니다. 교회 설정과 관계없이 이 내용은 항상 [내 정보 페이지](./me-page.md)에 나타납니다. 자세한 내용은 [홈 화면 섹션](../../b1-admin/settings/mobile-app.md#home-screen-sections)을 참고하세요.
- **헌금** -- 올해 드린 금액("올해 헌금"으로 표시)과 **헌금하기** 버튼(교회가 온라인 헌금을 제공하는 경우에만 표시), 그리고 [헌금 내역](../giving/donation-history.md)으로 이동하는 **내역** 링크가 나타납니다. 교회가 교인의 헌금 내역 조회 기간을 이전 연도로 제한했거나 이 항목을 숨긴 경우에는 이 섹션이 나타나지 않으며, 대신 교회의 헌금 도구가 **다음 더보기** 아래에 버튼으로 표시됩니다.
- **다음 더보기** *교회 이름* -- 하단 탭 바에 없고 위에 표시되지도 않은, 교회가 켜 둔 나머지 도구들의 버튼입니다. 자주 사용하는 항목이 앞쪽으로 옮겨집니다.

섬김, 소그룹, 출석, 양식, 헌금 섹션은 로그인되어 있고, 교회가 해당 도구를 켜 두었으며, 보여 줄 내용이 있을 때만(예: 다가오는 배정이 있거나 소그룹이 하나 이상 있을 때) 나타납니다. 컴퓨터에서는 홈이 두 열로 배치됩니다.

로그아웃 상태에서는 홈에 인사말 대신 **환영합니다** 제목이 나타나며, 짧은 안내 문구("소그룹, 헌금 등을 보려면 로그인하세요.")와 **로그인** 버튼이 표시됩니다. 교회가 홈에 다른 내용을 아직 설정하지 않았더라도 이 안내 문구는 표시됩니다. 교회는 이 문구를 바꾸거나 숨길 수 있습니다. 자세한 내용은 [모바일 앱 설정](../../b1-admin/settings/mobile-app.md#home-screen-sign-in-prompt)을 참고하세요. 문구가 숨겨져 있더라도 **더보기** 페이지나 **내 정보** 페이지에서 로그인할 수 있습니다.

## 하단 탭 바

휴대폰에서는 화면 하단에 탭 바가 고정되어 있습니다.

- **홈** -- 항상 첫 번째 탭입니다.
- 교회가 설정한 탭 중 최대 세 개
- **더보기** -- 더보기 페이지를 엽니다.

소그룹, 헌금, 계획과 같은 기본 화면이 먼저 탭 자리를 차지하며, 남는 자리는 교회의 사용자 지정 페이지에 돌아갑니다. 외부 웹사이트 링크와 오늘의 말씀은 탭으로 표시되지 않습니다. 교회가 설정한 탭이 화면에 다 들어가지 않으면, 나머지 탭은 사라지지 않고 **더보기** 페이지와 홈의 **다음 더보기** 섹션에 나타납니다. 교회 관리자는 B1 Admin의 **모바일 → 탐색**에서 탭 순서를 정할 수 있습니다.

### 폴더 탭 {#folder-tabs}

교회는 여러 탭을 하나의 **폴더**로 묶을 수 있습니다. 폴더는 탭 바, 더보기 페이지, 또는 홈의 사진 타일처럼 다른 탭과 똑같이 나타나며, 누르면 폴더 이름이 적힌 화면이 열리고 그 안에 든 탭 목록이 표시됩니다. 폴더 안의 모든 탭에 사진이 있으면 사진 타일로, 그렇지 않으면 목록으로 표시됩니다. 폴더 안의 외부 웹사이트 링크는 새 브라우저 탭에서 열립니다. 폴더 안의 탭은 폴더 화면에만 나타나며, 탭 바나 **더보기** 페이지에는 표시되지 않습니다. 볼 수 있는 항목이 없는 폴더는 숨겨집니다.

## 컴퓨터에서 사용하기

컴퓨터나 큰 태블릿처럼 화면이 넓은 경우, 하단 탭 바 대신 화면 상단에 교회 색상의 헤더가 나타납니다. 헤더에는 교회 로고(로고가 없으면 교회 이름, 클릭하면 홈으로 이동), **홈**, 교회가 설정한 탭 중 최대 다섯 개, 그리고 **더보기**가 표시되며, 오른쪽에는 알림 종 아이콘과 프로필 사진이 있습니다. 상세 화면을 열면 페이지 내용 위에 **뒤로** 링크가 나타납니다.

## 더보기 페이지

**더보기**를 누르면 `/mobile/more` 경로의 더보기 페이지가 열립니다. 이 페이지에는 다음 내용이 있습니다.

- **프로필 편집** 링크가 있는 이름과 사진 -- 자세한 내용은 [프로필 수정하기](./editing-your-profile.md)를 참고하세요.
- 교회 이름 아래에 교회가 설정한 모든 탭이 순서대로 표시됩니다. 외부 웹사이트 링크는 새 브라우저 탭에서 열립니다.
- **계정** 섹션:
  - **내 정보** -- 나의 개인 페이지(로그인한 경우에만 표시)
  - **화면 설정** -- **밝은 모드**와 **어두운 모드** 사이를 전환합니다.
  - **관리자 포털** -- 교회에서 관리자 권한이 있는 경우에만 표시되며, 누르면 B1 Admin이 새 탭에서 열립니다.
  - **앱 설치** -- `/mobile/install`의 [설치 안내](./installing-pwa.md)를 엽니다(앱이 설치되면 숨겨집니다).
- **로그아웃**, 또는 로그아웃 상태라면 **로그인** 버튼
- 교회 이름과 개인정보 처리방침 링크

## 앱 상단 바

휴대폰에서는 모든 화면 상단의 바에 다음이 표시됩니다.

- 홈 및 기타 주요 화면에서는 교회 로고(교회가 로고를 올리지 않았다면 교회 이름), 상세 화면으로 들어갔을 때는 뒤로 가기 화살표가 나타납니다. 화면 제목은 페이지 본문 상단에 나타납니다.
- 알림과 메시지를 위한 **종** 아이콘이며, 읽지 않은 항목이 있으면 배지가 표시됩니다. 아래의 [알림과 메시지](#notifications-and-messages)를 참고하세요.
- **프로필 사진**: 누르면 `/mobile/profileEdit`의 내 프로필이 열립니다. 자세한 내용은 [프로필 수정하기](./editing-your-profile.md)를 참고하세요.

종 아이콘과 프로필 사진은 로그인한 경우에만 나타납니다.

## 알림과 메시지

종 아이콘을 누르면 두 개의 섹션이 있는 패널이 열립니다.

- **메시지** -- 최근 개인 대화 목록과 새 대화를 시작하는 **새 메시지** 링크
- **알림** -- 최근 알림 목록이며, 읽지 않은 알림에는 **새로운** 배지가 붙습니다. 알림을 누르면 해당 알림이 온 소그룹, 계획 또는 대화로 이동합니다.

각 섹션에는 읽지 않은 항목의 수가 표시됩니다. 하단의 **모두 보기**를 누르면 `/mobile/notifications`의 전체 받은 편지함이 열립니다.

## 섹션으로 구성된 페이지

상세 페이지(소그룹, 계획, 내 정보 페이지, 계획 및 헌금 화면)는 탭 대신 섹션으로 나뉜 한 페이지로 구성됩니다. 각 섹션에는 간단한 미리보기가 표시되며, 섹션 제목의 링크(예: **모든 교인**, **모든 행사**, **전체 예배 순서**)를 누르면 전체 목록이 열립니다. 해당 화면 상단의 **돌아가기** 링크를 누르면 이전 페이지로 돌아갑니다.

## 내 정보 페이지

**내 정보**(`/mobile/me`)는 나만의 개인 공간입니다. 이름과 사진, **프로필 편집** 및 **설정**([알림 설정](./notification-preferences.md)) 버튼이 표시되고, 이어서 다가오는 내용을 보여 줍니다. 여기에는 섬김 배정, 행사 등록, 소그룹 행사가 포함됩니다. 그 아래에는 가족 구성원, 소속 소그룹, 올해의 [헌금](../giving/index.md), 제출한 양식, 출석 기록, [등록 내역](../events/my-registrations.md), 그리고 최근 알림과 메시지가 나옵니다. 자세한 내용은 [내 정보 페이지](./me-page.md)를 참고하세요.

로그아웃 상태에서는 내 정보 페이지에 대신 **로그인** 버튼이 표시됩니다.

## 홈 화면에 설치하기

교인 포털은 프로그레시브 웹 앱(PWA)입니다. `/mobile/install`에 접속하거나 더보기 페이지에서 **앱 설치**를 선택하면 사용 중인 기기에 맞는 단계별 안내를 볼 수 있습니다. 설치하면 홈 화면에서 브라우저 도구 모음 없이 전체 화면으로 열립니다. 자세한 내용은 [앱으로 설치하기(PWA)](./installing-pwa.md)를 참고하세요.

## 교회 공개 웹사이트

교인 포털 바깥에서, 교회의 공개 웹사이트에는 관리자가 설정한 링크가 있는 자체 상단 메뉴가 있습니다. [설교](../content/sermons.md), [성경](../content/bible.md), [실시간 스트리밍](../content/live-streaming.md), 공개 소그룹 목록과 같은 페이지들입니다. 휴대폰에서는 이 링크들이 헤더 오른쪽 위의 햄버거 아이콘 뒤에 있습니다.

:::info
표시되는 탭과 도구는 교회마다 다릅니다. 관리자가 B1 Admin에서 교인에게 보이는 섹션을 결정하므로, 여기서 설명하는 기능이 보이지 않는다면 교회에서 그 기능을 켜 두지 않았을 수 있습니다.
:::
