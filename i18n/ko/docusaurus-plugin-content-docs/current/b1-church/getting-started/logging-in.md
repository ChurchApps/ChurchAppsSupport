# 로그인

<div class="article-intro">

B1.church에 로그인하면 교인 포털에 접근할 수 있습니다. 포털에서는 앞으로 있을 일을 확인하고, 그룹을 관리하고, 온라인으로 헌금하고, 교회가 설정한 모든 도구를 사용할 수 있습니다. 이 글에서는 로그인하는 방법, 사용자 메뉴 이동, 로그아웃 방법을 다룹니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- ChurchApps 계정이 필요합니다. 계정을 만들려면 [시작하기](../getting-started/)를 참고하세요.
- 교회의 B1.church 주소가 필요합니다(예: `https://yourchurchname.b1.church`).

</div>

## 로그인하는 방법

1. 교회의 B1.church 주소(예: `https://yourchurchname.b1.church`)로 이동합니다.
2. 머리글 오른쪽 상단의 **Login** 버튼을 클릭합니다.
3. **이메일 주소**와 **비밀번호**를 입력하거나, 교회가 단일 로그인을 켜 두었다면 **Continue with Google** 또는 **Continue with Microsoft**를 클릭합니다.
4. **Sign In**을 클릭합니다.

[이중 인증 로그인](../../b1-admin/profile/managing-profile.md#two-factor-sign-in)을 켜 두었다면, 다음 화면에서 코드를 요청합니다. 인증 앱의 6자리 코드나 백업 코드 중 하나를 입력하고 **Verify code**를 클릭하세요. B1.church 앱도 같은 방식으로 코드를 요청합니다.

로그인한 후에는 로그인 버튼을 클릭하기 전에 보고 있던 페이지로 돌아갑니다. 로그아웃 상태에서 교인 포털 페이지로 바로 이동했다면, 로그인 후 자동으로 그 페이지로 돌아갑니다.

## 로그인 상태 유지하기

로그아웃할 때까지 같은 브라우저나 설치된 앱에서 로그인 상태가 유지됩니다. 한동안 방문하지 않아도 세션은 최대 약 30일 동안의 미사용 기간을 유지합니다. 한 번 로그인하면 교회의 웹사이트와 교인 포털(`/mobile`)을 오갈 때도 로그인 상태가 유지되므로, 각 곳에서 다시 로그인할 필요가 없습니다.

## 교인 포털 접근하기

로그인한 후에는 페이지 오른쪽 상단의 **이름**을 클릭하고 메뉴에서 **Member Portal**을 선택하여 교인 포털에 들어갈 수 있습니다. 교인 포털에는 개인 교회 도구가 모두 있습니다. [홈 대시보드](./navigating.md), [Me 페이지](./me-page.md), [그룹](../groups/), [헌금](../giving/) 등이 있습니다.

## 사용자 메뉴

로그인하면 오른쪽 상단에 이름이 칩으로 표시됩니다. 이를 클릭하면 다음 옵션이 있는 메뉴가 열립니다.

- **Member Portal** -- 개인 교인 포털 대시보드로 이동합니다.
- **Edit Profile** -- 계정 설정을 업데이트하거나 교회 프로필을 편집합니다.
- **Logout** -- 계정에서 로그아웃합니다.

## 관리자 접근

적절한 권한이 있는 교회 관리자라면 사용자 메뉴에 **Admin Portal** 옵션도 보입니다. 이를 클릭하면 B1 Admin으로 이동하여 교회의 설정, 사람, 그룹, 콘텐츠를 관리할 수 있습니다.

## 비밀번호를 잊었을 때

비밀번호가 기억나지 않는다면:

1. 로그인 페이지에서 **Forgot Password**를 클릭합니다.
2. ChurchApps 계정에 연결된 이메일 주소를 입력하고 제출합니다.
3. **6자리 인증 코드**가 들어 있는 이메일을 확인합니다. 코드는 15분 동안 유효합니다.
4. 인증 화면에 코드를 입력하여 로그인합니다.
5. 로그인한 후 프로필로 가서 새 비밀번호를 선택합니다.

:::tip
코드가 몇 분 안에 도착하지 않으면 스팸 폴더를 확인하세요. 잘못된 시도가 다섯 번 누적되면 코드가 잠기므로, 그런 경우에는 Forgot Password 페이지에서 새 코드를 요청하세요.
:::

## 로그아웃하기

로그아웃하려면 오른쪽 상단의 **이름**을 클릭하고 **Logout**을 선택하세요. 로그아웃되며 공개 사이트로 돌아갑니다.
