# 로그인하기

<div class="article-intro">

B1.church에 로그인하면 타임라인을 확인하고, 그룹을 관리하고, 온라인으로 헌금하고, 교회에서 설정한 모든 도구를 사용할 수 있는 회원 포털에 접속할 수 있습니다. 이 문서에서는 로그인 방법, 사용자 메뉴 탐색, 로그아웃 방법을 다룹니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- ChurchApps 계정이 필요합니다. 계정을 만들려면 [시작하기](../getting-started/)를 참조하세요.
- 소속 교회의 B1.church URL이 필요합니다(예: `https://yourchurchname.b1.church`).

</div>

## 로그인하는 방법

1. 소속 교회의 B1.church URL로 이동합니다(예: `https://yourchurchname.b1.church`).
2. 헤더 우측 상단의 **Login** 버튼을 클릭합니다.
3. **이메일 주소**와 **비밀번호**를 입력하거나, 교회에서 SSO(싱글 사인온)를 활성화한 경우 **Continue with Google** 또는 **Continue with Microsoft**를 클릭합니다.
4. **Sign In**을 클릭합니다.

로그인 후에는 로그인 버튼을 클릭하기 전에 있던 페이지로 돌아갑니다. 로그아웃 상태에서 회원 포털 페이지로 직접 이동했다면, 로그인 후 자동으로 해당 페이지로 돌아갑니다.

## 회원 포털 접속하기

로그인하면 페이지 우측 상단의 **이름**을 클릭하고 메뉴에서 **Member Portal**을 선택하여 회원 포털에 접속할 수 있습니다. 회원 포털은 [타임라인](../community/timeline.md), [그룹](../groups/), [헌금](../giving/) 등 개인의 모든 교회 도구가 모여 있는 곳입니다.

## 사용자 메뉴

로그인 후 우측 상단에 이름이 칩 형태로 표시됩니다. 이를 클릭하면 다음 옵션이 있는 메뉴가 열립니다.

- **Member Portal** -- 개인 회원 포털 대시보드로 이동합니다.
- **Edit Profile** -- 계정 설정을 업데이트하거나 교회 프로필을 편집합니다.
- **Logout** -- 계정에서 로그아웃합니다.

## 관리자 접근

적절한 권한을 가진 교회 관리자인 경우 사용자 메뉴에 **Admin Portal** 옵션도 표시됩니다. 이를 클릭하면 교회의 설정, 인물, 그룹, 콘텐츠를 관리할 수 있는 B1 Admin으로 이동합니다.

## 비밀번호를 잊으셨나요

비밀번호가 기억나지 않는 경우:

1. 로그인 페이지에서 **Forgot Password**를 클릭합니다.
2. ChurchApps 계정에 연결된 이메일 주소를 입력하고 제출합니다.
3. 이메일에서 **6자리 인증 코드**가 포함된 메시지를 확인합니다. 코드는 15분간 유효합니다.
4. 인증 화면에서 코드를 입력하여 로그인합니다.
5. 로그인 후 프로필로 이동하여 새 비밀번호를 설정합니다.

:::tip
코드가 몇 분 내에 도착하지 않으면 스팸 폴더를 확인하세요. 5회 잘못 입력하면 코드가 잠기며, 이 경우 비밀번호 찾기 페이지에서 새 코드를 요청하세요.
:::

## 로그아웃하기

로그아웃하려면 우측 상단의 **이름**을 클릭하고 **Logout**을 선택합니다. 로그아웃되어 공개 사이트로 돌아갑니다.
