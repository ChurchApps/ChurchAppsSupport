# 로그인하기

<div class="article-intro">

B1.church에 로그인하면 회원 포털에 접속할 수 있습니다. 회원 포털에서는 앞으로 있을 일정을 확인하고, 그룹을 관리하고, 온라인으로 헌금하고, 교회가 설정한 모든 도구를 사용할 수 있습니다. 이 문서에서는 로그인하는 방법, 사용자 메뉴를 쓰는 방법, 로그아웃하는 방법을 설명합니다.

</div>

## 로그인 방법

1. 교회의 B1.church 주소(예: `https://yourchurchname.b1.church`)로 이동하세요.
2. 머리글 오른쪽 위의 **Login** 버튼을 클릭하세요.
3. **이메일 주소**와 **비밀번호**를 입력하거나, 교회가 단일 로그인(SSO)을 켜 두었다면 **Continue with Google** 또는 **Continue with Microsoft**를 클릭하세요.
4. **Sign In**을 클릭하세요.

[2단계 로그인](../../b1-admin/profile/managing-profile.md#two-factor-sign-in)을 켰다면, 다음 화면에서 코드를 입력하라고 나옵니다. 인증 앱에 표시된 6자리 코드나 백업 코드 중 하나를 입력하고 **Verify code**를 클릭하세요. B1.church 앱도 같은 방식으로 코드를 묻습니다.

로그인한 뒤에는 로그인 버튼을 누르기 전에 보고 있던 페이지로 돌아갑니다. 로그아웃 상태에서 회원 포털 페이지로 직접 이동했다면, 로그인 후 자동으로 그 페이지로 돌아갑니다.

## 로그인 상태 유지

로그아웃하기 전까지는 같은 브라우저나 설치한 앱에서 계속 로그인된 상태가 유지됩니다. 오랫동안 방문하지 않아도 마찬가지입니다. 세션은 약 30일 동안 활동이 없어도 유지됩니다. 한 번 로그인하면 교회 웹사이트와 회원 포털(`/mobile`) 사이를 오갈 때도 다시 로그인하지 않아도 됩니다.

## 회원 포털 이용하기

로그인한 뒤에는 페이지 오른쪽 위의 **이름**을 클릭하고 메뉴에서 **Member Portal**(회원 포털)을 선택하면 회원 포털에 들어갈 수 있습니다. 회원 포털에는 본인의 개인 교회 도구가 모여 있습니다. [홈 대시보드](./navigating.md), [내 페이지](./me-page.md), [그룹](../groups/), [헌금](../giving/) 등이 포함됩니다.

## 사용자 메뉴

로그인하면 오른쪽 위에 이름이 칩 형태로 나타납니다. 이를 클릭하면 다음 메뉴가 열립니다.

- **Member Portal** -- 개인 회원 포털 대시보드로 이동합니다.
- **Edit Profile** -- 계정 설정을 바꾸거나 교회 프로필을 수정합니다.
- **Logout** -- 계정에서 로그아웃합니다.

## 관리자 접근

교회 관리자이고 적절한 권한이 있다면, 사용자 메뉴에 **Admin Portal**(관리자 포털)도 나타납니다. 이를 클릭하면 B1 Admin으로 이동하여 교회 설정, 사람, 그룹, 콘텐츠를 관리할 수 있습니다.

## 비밀번호를 잊었을 때

비밀번호가 기억나지 않는다면 다음과 같이 하세요.

1. 로그인 페이지에서 **Forgot Password**를 클릭하세요.
2. ChurchApps 계정에 연결된 이메일 주소를 입력하고 제출하세요.
3. 이메일에서 **6자리 인증 코드**가 담긴 메시지를 확인하세요. 코드는 15분 동안 유효합니다.
4. 인증 화면에 코드를 입력해 로그인하세요.
5. 로그인한 뒤에는 프로필로 이동해 새 비밀번호를 설정하세요.

:::tip
코드가 몇 분 안에 도착하지 않으면 스팸 폴더를 확인하세요. 잘못된 코드를 다섯 번 입력하면 코드가 잠깁니다. 그런 경우에는 Forgot Password 페이지에서 새 코드를 요청하세요.
:::

## 로그아웃하기

로그아웃하려면 오른쪽 위의 **이름**을 클릭하고 **Logout**을 선택하세요. 로그아웃되어 공개 사이트로 돌아갑니다.
