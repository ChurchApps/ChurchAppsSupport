# 로그인하기

<div class="article-intro">

B1.church에 로그인하면 나에게 다가오는 일정을 확인하고, 그룹을 관리하고, 온라인으로 헌금하고, 교회에서 설정한 모든 도구를 사용할 수 있는 회원 포털에 접근할 수 있습니다. 이 문서에서는 로그인하는 방법, 사용자 메뉴 이용 방법, 로그아웃 방법을 설명합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- ChurchApps 계정이 필요합니다. 계정을 만들려면 [시작하기](../getting-started/)를 참고하세요.
- 교회의 B1.church 주소가 필요합니다(예: `https://yourchurchname.b1.church`).

</div>

## 로그인 방법

1. 교회의 B1.church 주소(예: `https://yourchurchname.b1.church`)로 이동하세요.
2. 머리글 오른쪽 위의 **Login** 버튼을 클릭하세요.
3. **이메일 주소**와 **비밀번호**를 입력하거나, 교회에서 단일 로그인을 사용한다면 **Continue with Google** 또는 **Continue with Microsoft**를 클릭하세요.
4. **Sign In**을 클릭하세요.

[2단계 로그인](../../b1-admin/profile/managing-profile.md#two-factor-sign-in)을 켜 두었다면 다음 화면에서 코드를 요청합니다. 인증 앱의 6자리 코드나 백업 코드 중 하나를 입력하고 **Verify code**를 클릭하세요. B1.church 앱도 같은 방식으로 코드를 요청합니다.

로그인하면 로그인 버튼을 누르기 전에 보고 있던 페이지로 돌아갑니다. 로그아웃 상태에서 회원 포털 페이지로 바로 이동했다면, 로그인 후 자동으로 그 페이지로 돌아갑니다.

## 로그인 상태 유지

로그아웃하기 전까지 같은 브라우저나 설치된 앱에서 로그인 상태가 유지됩니다. 한동안 방문하지 않아도 세션은 약 30일 동안 활동이 없어도 유지됩니다. 한 번 로그인하면 교회 웹사이트와 회원 포털(`/mobile`) 사이를 오갈 때도 로그인 상태가 유지되므로, 각 장소에서 다시 로그인할 필요가 없습니다.

## 회원 포털 이용하기

로그인한 뒤에는 페이지 오른쪽 위의 **이름**을 클릭하고 메뉴에서 **Member Portal**을 선택하면 회원 포털에 접근할 수 있습니다. 회원 포털에는 [Home 대시보드](./navigating.md), [Me 페이지](./me-page.md), [그룹](../groups/), [헌금](../giving/) 등 개인 교회 도구가 모두 모여 있습니다.

## 사용자 메뉴

로그인하면 오른쪽 위에 이름이 칩 형태로 표시됩니다. 이름을 클릭하면 다음 옵션이 있는 메뉴가 열립니다.

- **Member Portal** -- 개인 회원 포털 대시보드로 이동합니다.
- **Edit Profile** -- 계정 설정을 바꾸거나 교회 프로필을 수정합니다.
- **Logout** -- 계정에서 로그아웃합니다.

## 관리자 접근

적절한 권한이 있는 교회 관리자라면 사용자 메뉴에 **Admin Portal** 옵션도 보입니다. 이를 클릭하면 B1 Admin으로 이동해 교회의 설정, 교인, 그룹, 콘텐츠를 관리할 수 있습니다.

## 비밀번호를 잊었을 때

비밀번호가 기억나지 않는다면 다음과 같이 하세요.

1. 로그인 페이지에서 **Forgot Password**를 클릭하세요.
2. ChurchApps 계정에 연결된 이메일 주소를 입력하고 제출하세요.
3. **6자리 인증 코드**가 포함된 이메일을 확인하세요. 코드는 15분 동안 유효합니다.
4. 인증 화면에 코드를 입력해 로그인하세요.
5. 로그인한 뒤 프로필로 가서 새 비밀번호를 설정하세요.

:::tip
코드가 2~3분 안에 도착하지 않으면 스팸 폴더를 확인하세요. 잘못된 시도가 다섯 번 누적되면 코드가 잠기니, 그런 경우에는 Forgot Password 페이지에서 새 코드를 요청하세요.
:::

## 로그아웃하기

로그아웃하려면 페이지 오른쪽 위의 **이름**을 클릭하고 **Logout**을 선택하세요. 로그아웃되고 공개 사이트로 돌아갑니다.
