# 로그인

<div class="article-intro">

B1.church에 로그인하면 회원 포털에 접근할 수 있으며 이곳에서 앞으로의 일정을 보고, 그룹을 관리하고, 온라인으로 기부하고, 교회에서 설정한 모든 도구를 사용할 수 있습니다. 이 기사는 로그인 방법, 사용자 메뉴 탐색 및 로그아웃 방법을 설명합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- ChurchApps 계정이 필요합니다. [시작하기](../getting-started/)를 참조하여 만들기를 참조하세요.
- 교회의 B1.church URL이 필요합니다(예: `https://yourchurchname.b1.church`).

</div>

## 로그인 방법

1. 교회의 B1.church URL로 이동합니다(예: `https://yourchurchname.b1.church`).
2. 헤더의 오른쪽 상단에 있는 **로그인** 버튼을 클릭합니다.
3. **이메일 주소**와 **비밀번호**를 입력하거나, 교회에서 싱글 사인온이 활성화된 경우 **Google으로 계속** 또는 **Microsoft로 계속**을 클릭합니다.
4. **로그인**을 클릭합니다.

로그인한 후 로그인을 클릭하기 전에 있던 페이지로 돌아갑니다. 로그아웃된 상태에서 회원 포털 페이지로 직접 이동한 경우 로그인한 후 자동으로 해당 페이지로 돌아갑니다.

## 로그인 상태 유지

로그아웃하지 않는 한 같은 브라우저나 설치된 앱에서 로그인 상태를 유지합니다. 장시간 방문하지 않아도 로그인 상태가 유지됩니다. 세션은 약 30일간의 비활성 상태로 유지됩니다. 한 번 로그인하면 교회 웹사이트와 회원 포털(`/mobile`) 사이에서 이동할 때 로그인 상태가 유지되므로 각 위치에서 다시 로그인할 필요가 없습니다.

## 회원 포털 접근

로그인한 후 페이지의 오른쪽 상단에서 **이름**을 클릭하고 메뉴에서 **회원 포털**을 선택하여 회원 포털에 접근할 수 있습니다. 회원 포털은 [홈 대시보드](./navigating.md), [내 페이지](./me-page.md), [그룹](../groups/), [기부](../giving/) 등을 포함한 모든 개인 교회 도구가 있는 곳입니다.

## 사용자 메뉴

로그인한 후 이름이 오른쪽 상단에 칩으로 나타납니다. 이를 클릭하여 다음 옵션이 있는 메뉴를 엽니다:

- **회원 포털** -- 개인 회원 포털 대시보드로 이동합니다.
- **프로필 편집** -- 계정 설정을 업데이트하거나 교회 프로필을 편집합니다.
- **로그아웃** -- 계정에서 로그아웃합니다.

## 관리자 접근

적절한 권한이 있는 교회 관리자인 경우 사용자 메뉴에서 **관리자 포털** 옵션도 보게 됩니다. 이를 클릭하면 교회의 설정, 사람, 그룹 및 콘텐츠를 관리할 수 있는 B1 Admin으로 이동합니다.

## 비밀번호를 잊으신 경우

비밀번호를 기억할 수 없으면:

1. 로그인 페이지에서 **비밀번호 찾기**를 클릭합니다.
2. ChurchApps 계정에 연결된 이메일 주소를 입력하고 제출합니다.
3. **6자리 확인 코드**가 포함된 메시지를 확인합니다. 코드는 15분 동안 유효합니다.
4. 확인 화면에서 코드를 입력하여 로그인합니다.
5. 로그인한 후 프로필을 방문하여 새 비밀번호를 선택합니다.

:::tip
코드가 몇 분 내에 도착하지 않으면 스팸 폴더를 확인하세요. 5회 이상 잘못된 시도 후 코드가 잠깁니다. 이 경우 비밀번호 찾기 페이지에서 새 코드를 요청하세요.
:::

## 로그아웃

로그아웃하려면 오른쪽 상단에서 **이름**을 클릭하고 **로그아웃**을 선택합니다. 로그아웃되고 공개 사이트로 돌아갑니다.
