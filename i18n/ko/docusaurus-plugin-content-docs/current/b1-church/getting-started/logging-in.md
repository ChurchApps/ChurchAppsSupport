# 로그인하기

<div class="article-intro">

B1.church에 로그인하면 교인 포털에 접속하여 다가오는 일정을 확인하고, 그룹을 관리하고, 온라인으로 헌금하며, 교회가 설정한 모든 도구를 이용할 수 있습니다. 이 문서에서는 로그인하는 방법, 사용자 메뉴를 이용하는 방법, 로그아웃하는 방법을 다룹니다.

</div>

## 로그인하는 방법 {#how-to-log-in}

1. 교회의 B1.church 주소(예: `https://yourchurchname.b1.church`)로 이동합니다.
2. 헤더 오른쪽 상단의 **로그인** 버튼을 클릭합니다. 교회가 웹사이트에 **로그인** 버튼을 켜 두지 않았다면 대신 `https://yourchurchname.b1.church/login`으로 이동하세요.
3. **이메일 주소**와 **비밀번호**를 입력하거나, 교회가 통합 로그인을 켜 두었다면 **Google로 계속하기** 또는 **Microsoft로 계속하기**를 클릭합니다.
4. **로그인**을 클릭합니다.

[2단계 로그인](../../b1-admin/profile/managing-profile.md#two-factor-sign-in)을 켜 두었다면, 다음 화면에서 코드를 요청합니다. 인증 앱의 6자리 코드나 백업 코드 중 하나를 입력하고 **코드 확인**을 클릭하세요. 교인 포털도 같은 방식으로 코드를 요청합니다.

로그인한 후에는 로그인 버튼을 누르기 전에 보고 있던 페이지로 돌아갑니다. 로그아웃 상태에서 교인 포털 페이지에 직접 접속했다면, 로그인 후 그 페이지로 자동으로 돌아갑니다.

## 교인 포털에서 로그인하기 {#signing-in-from-the-member-portal}

교인 포털(`/mobile`)에는 자체 로그인 화면이 있습니다. 홈, **더보기** 페이지, 또는 계정이 필요한 화면에서 **로그인**을 탭하고, 이메일과 비밀번호를 입력한 다음 **로그인**을 탭하세요. 여기에서 **비밀번호를 잊으셨나요**?를 탭하여 비밀번호를 재설정하거나, 아직 계정이 없다면 **계정 만들기**를 탭할 수도 있습니다. Google과 Microsoft 로그인은 웹사이트의 로그인 페이지에서만 제공됩니다.

## 로그인 상태 유지 {#staying-signed-in}

같은 브라우저나 설치된 앱에서는 로그아웃하기 전까지 로그인 상태가 유지됩니다. 한동안 방문하지 않아도 마찬가지입니다. 세션은 약 30일 동안 활동이 없어도 유지됩니다. 한 번 로그인하면 교회 웹사이트와 교인 포털(`/mobile`) 사이를 오갈 때도 로그인 상태가 유지되므로, 각 장소에서 다시 로그인할 필요가 없습니다.

## 교인 포털 접속하기 {#accessing-the-member-portal}

로그인하면 페이지 오른쪽 상단의 **이름**을 클릭하고 메뉴에서 **교인 포털**을 선택하여 교인 포털에 접속할 수 있습니다. 교인 포털에는 [홈 대시보드](./navigating.md), [내 정보 페이지](./me-page.md), [그룹](../groups/index.md), [헌금](../giving/index.md) 등 개인 교회 도구가 모두 모여 있습니다.

## 사용자 메뉴 {#your-user-menu}

로그인하면 오른쪽 상단에 이름이 칩 형태로 나타납니다. 이를 클릭하면 다음 옵션이 있는 메뉴가 열립니다.

- **교인 포털** -- 개인 교인 포털 대시보드로 이동합니다.
- **프로필 편집** -- 두 가지 선택지가 더 열립니다. **계정 편집**(B1 Admin에서 로그인 이메일, 비밀번호, 2단계 인증 설정)과 **교회 프로필 편집**(교인 포털의 [디렉터리](../community/member-directory.md)에 있는 프로필)입니다.
- **로그아웃** -- 계정에서 로그아웃합니다.

## 관리자 접근 {#admin-access}

적절한 권한이 있는 교회 관리자라면 사용자 메뉴에 **관리자 포털** 옵션도 보입니다. 이를 클릭하면 B1 Admin으로 이동하여 교회의 설정, 교인, 그룹, 콘텐츠를 관리할 수 있습니다.

## 비밀번호를 잊으셨나요 {#forgot-your-password}

비밀번호가 생각나지 않는다면 다음과 같이 합니다.

1. 로그인 페이지에서 **비밀번호 찾기**를 클릭합니다(교인 포털에서는 **비밀번호를 잊으셨나요**?를 탭합니다).
2. ChurchApps 계정에 연결된 이메일 주소를 입력하고 **재설정**을 클릭합니다(교인 포털에서는 **코드 보내기**).
3. 이메일에서 **6자리 인증 코드**가 담긴 메시지를 확인합니다. 코드는 15분 동안 유효합니다.
4. 코드를 입력하고 **코드 확인**을 클릭합니다. 코드가 도착하지 않았다면 30초 후 **코드 다시 보내기**를 탭할 수 있습니다.
5. 새 비밀번호(최소 8자)를 정하고 확인을 위해 한 번 더 입력한 다음 **로그인**을 클릭합니다(교인 포털에서는 **저장 후 로그인**). 새 비밀번호로 로그인됩니다.

:::tip
몇 분 안에 코드가 도착하지 않으면 스팸 폴더를 확인하세요. 잘못된 시도가 다섯 번 누적되면 코드가 잠기므로, 그런 경우에는 비밀번호 찾기 페이지에서 새 코드를 요청하세요.
:::

## 로그아웃하기 {#logging-out}

로그아웃하려면 오른쪽 상단의 **이름**을 클릭하고 **로그아웃**을 선택하세요. 로그아웃되고 공개 사이트로 돌아갑니다.
