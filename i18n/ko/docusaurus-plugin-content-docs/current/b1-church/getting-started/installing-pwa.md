# PWA로 앱 설치하기

<div class="article-intro">

B1.church는 PWA(Progressive Web App)로의 설치를 지원하므로, 교회의 member portal을 휴대폰 홈 화면에 네이티브 앱처럼 추가할 수 있습니다. 이를 통해 App Store나 Google Play를 거치지 않고도 전체 화면의 앱과 같은 경험을 누릴 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 교회의 B1.church 주소가 필요합니다: `https://yourchurchname.b1.church`
- 지원되는 브라우저를 사용하세요: iOS에서는 **Safari**, Android에서는 **Chrome**

</div>

## PWA란 무엇인가요?

PWA(Progressive Web App)는 기기에 설치할 수 있고 네이티브 앱처럼 동작하는 웹사이트입니다. B1.church를 PWA로 설치하면 다음과 같이 동작합니다:

- 브라우저 탐색 막대 없이 전체 화면으로 열립니다
- 교회의 아이콘과 이름으로 홈 화면에 나타납니다
- 교회의 브랜딩 및 테마 색상과 자연스럽게 어울립니다

:::tip
별도의 앱을 App Store나 Google Play에서 설치하고 싶지 않다면 PWA가 좋은 선택입니다. 브라우저에서 이용하는 것과 같은 member portal 경험을 더 편리한 형태로 제공합니다.
:::

## 설치 페이지

가장 쉽게 설치하는 방법은 교회 전용 설치 페이지를 이용하는 것입니다:

```
https://yourchurchname.b1.church/mobile/install
```

이 페이지는 기기를 자동으로 감지하고 알맞은 안내를 보여줍니다:

- **iPhone** — 단계별 Safari "홈 화면에 추가" 안내
- **Android** — Chrome에서 한 번 탭하면 되는 **홈 화면에 설치** 버튼
- **데스크톱** — 휴대폰으로 스캔하여 설치 페이지를 열 수 있는 QR 코드

다음과 같은 방법으로 설치 페이지에 접속할 수 있습니다:

- member portal에서 **더보기**를 탭한 다음 **계정** 아래의 **앱 설치**를 탭합니다(앱이 이미 설치되어 있으면 이 항목은 숨겨집니다)
- 교회가 문자, 이메일 또는 주일 화면을 통해 공유하는 링크를 따라갑니다
- 브라우저에 URL을 직접 입력합니다

:::tip 교회 직원용
설치 페이지 링크를 교인들과 공유하세요. 주보, 뉴스레터 또는 슬라이드에 넣으면 됩니다. 이 페이지는 각 교인의 기기에 맞는 정확한 단계를 안내합니다. B1Admin 대시보드의 **앱 다운로드** 빠른 작업에서도 이 페이지에 접근할 수 있습니다.
:::

아래의 브라우저 단계를 따르면 교회 B1.church 사이트의 **어떤 페이지에서든** PWA를 직접 설치할 수도 있습니다. 설치 페이지는 이 과정을 단계별로 안내해 주는 방법일 뿐입니다.

설치된 앱을 실행하면 로그인할 준비가 된 member dashboard로 바로 열립니다.

## iPhone 설치 방법 (iOS — Safari)

1. iPhone에서 **Safari**를 열고 `https://yourchurchname.b1.church/mobile/install`로 이동합니다(`yourchurchname`을 교회의 URL 슬러그로 바꾸세요).
2. 화면 하단의 **공유** 버튼(위쪽 화살표가 있는 상자 모양)을 탭합니다.
3. 공유 시트를 아래로 스크롤한 다음 **홈 화면에 추가**를 탭합니다.
4. 이름은 기본적으로 교회 이름으로 표시됩니다. 오른쪽 상단의 **추가**를 탭합니다.

홈 화면에 앱 아이콘이 나타납니다. 이를 탭하면 전체 화면 모드로 member portal이 열립니다.

:::info
iOS에서 PWA를 설치하려면 Safari가 필요합니다. iPhone에서 Chrome이나 다른 브라우저를 사용 중이라면 먼저 Safari로 전환하세요.
:::

## Android 설치 방법 (Chrome)

1. Android 기기에서 **Chrome**을 열고 `https://yourchurchname.b1.church/mobile/install`로 이동합니다.
2. **홈 화면에 설치** 버튼을 탭합니다. (버튼이 보이지 않으면 오른쪽 상단의 점 세 개 메뉴(⋮)를 탭하고 **홈 화면에 추가**를 선택하세요.)
3. 확인 창이 나타나면 **추가**를 탭합니다.

홈 화면에 앱 아이콘이 나타납니다. 이를 탭하면 member portal이 열립니다.

## 설치 후

설치가 끝나면 PWA는 전용 전체 화면 창에서 member portal로 바로 열립니다. 다음을 할 수 있습니다:

- 기존 ChurchApps 계정으로 로그인합니다
- 교회가 활성화한 모든 교인 기능에 접근합니다 — 소그룹, 헌금, 체크인, 봉사 계획 등
- 홈 화면의 아이콘을 탭하여 언제든지 다시 열 수 있습니다

앱 아이콘에는 읽지 않은 메시지가 있을 때 **알림 배지**(작은 숫자 배지)가 표시되므로, 새로운 알림이 있는지 한눈에 확인할 수 있습니다.

:::info
PWA는 인터넷 연결이 필요합니다. 일부 네이티브 앱과 달리 모든 콘텐츠를 오프라인 사용을 위해 캐시하지 않습니다.
:::
