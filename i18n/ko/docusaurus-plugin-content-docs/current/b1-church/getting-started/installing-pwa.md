# 앱으로 설치하기 (PWA)

<div class="article-intro">

B1.church는 프로그레시브 웹 앱(PWA)으로 설치할 수 있어, 네이티브 앱처럼 교회의 회원 포털을 휴대폰 홈 화면에 추가할 수 있습니다. 앱스토어나 구글 플레이를 거치지 않고도 전체 화면의 앱과 같은 경험을 제공합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 소속 교회의 B1.church URL이 필요합니다: `https://yourchurchname.b1.church`
- 지원되는 브라우저를 사용하세요: iOS에서는 **Safari**, Android에서는 **Chrome**

</div>

## PWA란?

프로그레시브 웹 앱(PWA)은 기기에 설치할 수 있으며 네이티브 앱처럼 동작하는 웹사이트입니다. B1.church를 PWA로 설치하면 다음과 같은 특징이 있습니다.

- 브라우저 탐색 바 없이 전체 화면으로 열립니다
- 교회의 아이콘과 이름으로 홈 화면에 표시됩니다
- 교회의 브랜딩과 테마 색상에 맞춰 매끄럽게 작동합니다

:::tip
앱스토어나 구글 플레이에서 별도의 앱을 설치하고 싶지 않다면 PWA가 훌륭한 선택입니다. 브라우저에서 이용하는 것과 동일한 회원 포털 경험을 더 편리한 형태로 제공합니다.
:::

## 설치 페이지

가장 쉬운 설치 방법은 교회 전용 설치 페이지를 이용하는 것입니다.

```
https://yourchurchname.b1.church/mobile/install
```

이 페이지는 사용 중인 기기를 감지하여 올바른 안내를 자동으로 보여줍니다.

- **아이폰** — Safari의 "홈 화면에 추가" 단계별 안내
- **안드로이드** — Chrome에서 원탭으로 이용 가능한 **홈 화면에 설치** 버튼
- **데스크톱** — 휴대폰으로 스캔하여 설치 페이지를 열 수 있는 QR 코드

설치 페이지에는 여러 방법으로 접속할 수 있습니다.

- 회원 포털에서 메뉴(☰)를 열고 **앱 설치**를 탭합니다(앱이 이미 설치되어 있으면 항목이 숨겨집니다)
- 교회에서 문자, 이메일, 주일 화면 등을 통해 공유한 링크를 따라갑니다
- 브라우저에 URL을 직접 입력합니다

:::tip 교회 스태프 대상
회중에게 설치 페이지 링크를 공유하세요 -- 주보, 소식지, 슬라이드에 넣으면 됩니다. 각 회원의 기기에 맞는 정확한 단계를 안내해 줍니다. B1Admin 대시보드의 **앱 다운로드** 빠른 작업에서도 접속할 수 있습니다.
:::

아래 브라우저 단계를 이용하면 교회의 B1.church 사이트 **어느 페이지에서든** 수동으로 PWA를 설치할 수도 있습니다 -- 설치 페이지는 그저 안내가 딸린 방법일 뿐입니다.

설치된 앱을 실행하면 로그인할 준비가 된 회원 대시보드로 바로 이동합니다.

## 아이폰에 설치하기 (iOS — Safari)

1. 아이폰에서 **Safari**를 열고 `https://yourchurchname.b1.church/mobile/install`로 이동합니다(`yourchurchname`을 소속 교회의 URL 슬러그로 바꾸세요).
2. 화면 하단의 **공유** 버튼(위쪽을 가리키는 화살표가 있는 상자)을 탭합니다.
3. 공유 시트에서 아래로 스크롤하여 **홈 화면에 추가**를 탭합니다.
4. 이름은 기본적으로 교회 이름으로 설정됩니다. 우측 상단의 **추가**를 탭합니다.

홈 화면에 앱 아이콘이 표시됩니다. 이를 탭하면 회원 포털이 전체 화면 모드로 열립니다.

:::info
iOS에서 PWA를 설치하려면 Safari가 필요합니다. 아이폰에서 Chrome이나 다른 브라우저를 사용 중이라면 먼저 Safari로 전환하세요.
:::

## 안드로이드에 설치하기 (Chrome)

1. 안드로이드 기기에서 **Chrome**을 열고 `https://yourchurchname.b1.church/mobile/install`로 이동합니다.
2. **홈 화면에 설치** 버튼을 탭합니다. (버튼이 보이지 않으면 우측 상단의 점 3개 메뉴(⋮)를 탭하고 **홈 화면에 추가**를 선택합니다.)
3. 메시지가 표시되면 **추가**를 탭합니다.

홈 화면에 앱 아이콘이 표시됩니다. 이를 탭하면 회원 포털이 열립니다.

## 설치 후

설치가 완료되면 PWA는 전용 전체 화면 창에서 회원 포털로 바로 열립니다. 다음과 같은 작업을 할 수 있습니다.

- 기존 ChurchApps 계정으로 로그인
- 교회에서 활성화한 모든 회원 기능 이용 -- 그룹, 헌금, 체크인, 봉사 플랜 등
- 언제든지 홈 화면의 아이콘을 탭하여 다시 접속

읽지 않은 메시지가 있으면 앱 아이콘에 **알림 배지**(작은 숫자 배지)가 표시되어 새로운 소식이 있는지 한눈에 확인할 수 있습니다.

:::info
PWA는 인터넷 연결이 필요합니다. 일부 네이티브 앱과 달리 오프라인 사용을 위해 모든 콘텐츠를 캐시하지는 않습니다.
:::

## 기존 B1 Mobile 앱은 어떻게 되나요?

iOS와 Android용 레거시 네이티브 **B1 Mobile** 앱은 지원이 종료되어 더 이상 업데이트되지 않습니다. 앞으로는 PWA가 휴대폰에서 B1.church 회원 포털에 접속하는 공식 지원 방법이며, 네이티브 앱이 제공하던 회원 대상 기능을 모두 포함합니다. 이전에 네이티브 앱을 설치했다면 편한 시기에 PWA로 전환하세요.

지원이 종료된 앱에 대한 과거 문서는 [B1 Mobile 참조 페이지](/docs/b1-mobile/)를 참조하세요.
