# 앱(PWA)으로 설치하기

<div class="article-intro">

B1.church는 프로그레시브 웹 앱(PWA)으로 설치할 수 있으며, 이를 통해 교회의 교인 포털을 네이티브 앱처럼 휴대폰 홈 화면에 추가할 수 있습니다. 앱 스토어나 Google Play를 거치지 않고도 전체 화면의 앱과 같은 경험을 얻을 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 교회의 B1.church 주소가 필요합니다: `https://yourchurchname.b1.church`
- 지원되는 브라우저를 사용하세요: iOS에서는 **Safari**, Android에서는 **Chrome**

</div>

## PWA란? {#what-is-a-pwa}

프로그레시브 웹 앱(PWA)은 기기에 설치할 수 있고 네이티브 앱처럼 동작하는 웹사이트입니다. B1.church를 PWA로 설치하면 다음과 같이 동작합니다.

- 브라우저의 탐색 막대 없이 전체 화면으로 열립니다.
- 교회의 아이콘과 이름과 함께 홈 화면에 나타납니다.
- 교회의 브랜딩과 테마 색상에 맞추어 자연스럽게 작동합니다.

:::tip
앱 스토어나 Google Play에서 별도의 앱을 설치하고 싶지 않다면 PWA가 좋은 선택입니다. 브라우저에서 이용하는 것과 같은 교인 포털 경험을 더 편리한 형태로 제공합니다.
:::

## 설치 페이지 {#the-install-page}

가장 쉬운 설치 방법은 교회 전용 설치 페이지를 이용하는 것입니다.

```
https://yourchurchname.b1.church/mobile/install
```

이 페이지는 기기를 자동으로 감지하고 알맞은 안내를 보여 줍니다.

- **iPhone** -- Safari의 "홈 화면에 추가" 단계별 안내
- **Android** -- Chrome에서 한 번 탭하는 **홈 화면에 설치** 버튼
- **데스크톱** -- 휴대폰으로 스캔하면 그 기기에서 설치 페이지를 열 수 있는 QR 코드, 그리고 브라우저가 웹 앱 설치를 지원하면 **이 컴퓨터에 설치** 버튼

설치 페이지로 가는 방법은 여러 가지입니다.

- 교인 포털에서 **더보기**를 탭한 다음 **계정** 아래의 **앱 설치**를 탭합니다(앱이 이미 설치되어 있으면 이 항목은 숨겨집니다).
- 교회가 문자, 이메일, 주일 화면으로 공유한 링크를 따라갑니다.
- 브라우저에 URL을 직접 입력합니다.

:::tip 교회 직원용
설치 페이지 링크를 교인들과 공유하세요. 주보, 뉴스레터, 또는 슬라이드에 넣을 수 있습니다. 이 페이지는 각 교인에게 기기별 정확한 단계를 안내합니다. B1Admin 대시보드의 **앱 다운로드** 빠른 실행 항목에서도 이 페이지를 열 수 있습니다.
:::

교회 B1.church 사이트의 **아무 페이지**에서든 아래의 브라우저 단계를 따라 PWA를 수동으로 설치할 수도 있습니다. 설치 페이지는 이 과정을 단계별로 안내해 주는 방법일 뿐입니다.

설치된 앱을 실행하면 바로 교인 대시보드가 열리며, 로그인할 준비가 되어 있습니다.

## iPhone에 설치하기 (iOS - Safari) {#installing-on-iphone-ios--safari}

1. iPhone에서 **Safari**를 열고 `https://yourchurchname.b1.church/mobile/install`로 이동합니다(`yourchurchname`을 교회의 URL 슬러그로 바꾸세요).
2. 화면 하단의 **공유** 버튼(위쪽을 가리키는 화살표가 있는 상자 모양)을 탭합니다.
3. 공유 시트를 아래로 스크롤하고 **홈 화면에 추가**를 탭합니다.
4. 이름은 기본적으로 교회 이름이 채워집니다. 오른쪽 상단의 **추가**를 탭합니다.

홈 화면에 앱 아이콘이 나타납니다. 이를 탭하면 전체 화면 모드로 교인 포털이 열립니다.

:::info
iOS에서 PWA를 설치하려면 Safari가 필요합니다. iPhone에서 Chrome이나 다른 브라우저를 사용 중이라면 먼저 Safari로 전환하세요.
:::

## Android에 설치하기 (Chrome) {#installing-on-android-chrome}

1. Android 기기에서 **Chrome**을 열고 `https://yourchurchname.b1.church/mobile/install`로 이동합니다.
2. **홈 화면에 설치** 버튼을 탭합니다. (Chrome이 아직 설치 안내를 표시하지 않았다면 페이지에 그렇게 나타납니다. 이때는 오른쪽 상단의 점 세 개 메뉴(⋮)를 탭하고 **앱 설치**를 선택하세요.)
3. 표시되면 **설치**를 탭합니다.

홈 화면에 앱 아이콘이 나타납니다. 이를 탭하면 교인 포털이 열립니다.

## 설치 후 {#after-installing}

설치하면 PWA는 전용 전체 화면 창에서 바로 교인 포털을 엽니다. 설치된 앱에서 설치 페이지를 열면 단계 대신 "모두 완료되었습니다!"가 표시됩니다. 다음을 할 수 있습니다.

- 기존 ChurchApps 계정으로 로그인하기
- 교회가 켜 둔 모든 교인 기능 이용하기(그룹, 헌금, 체크인, 섬김 계획 등)
- 홈 화면의 아이콘을 탭하여 언제든지 돌아가기

읽지 않은 알림이나 메시지가 있으면 앱 아이콘에 **알림 배지**(작은 숫자 배지)가 표시되므로, 새로 기다리는 내용이 있는지 한눈에 알 수 있습니다.

:::info
PWA에는 인터넷 연결이 필요합니다. 일부 네이티브 앱과 달리 오프라인 사용을 위해 모든 콘텐츠를 저장하지는 않습니다.
:::
