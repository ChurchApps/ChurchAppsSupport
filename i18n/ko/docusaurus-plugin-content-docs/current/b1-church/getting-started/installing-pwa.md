# 앱으로 설치하기 (PWA)

<div class="article-intro">

B1.church는 PWA(Progressive Web App)로 설치할 수 있습니다. 이를 통해 교회의 회원 포털을 네이티브 앱처럼 휴대폰 홈 화면에 추가할 수 있습니다. 앱 스토어나 Google Play를 거치지 않고도 전체 화면의 앱과 같은 경험을 얻을 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 교회의 B1.church 주소가 필요합니다: `https://yourchurchname.b1.church`
- 지원되는 브라우저를 사용하세요. iOS에서는 **Safari**, Android에서는 **Chrome**입니다.

</div>

## PWA란 무엇인가요?

PWA(Progressive Web App)는 기기에 설치할 수 있고 네이티브 앱처럼 동작하는 웹사이트입니다. B1.church를 PWA로 설치하면 다음과 같이 됩니다.

- 브라우저 탐색 바 없이 전체 화면으로 열립니다.
- 교회의 아이콘과 이름으로 홈 화면에 나타납니다.
- 교회의 브랜딩과 테마 색상에 맞춰 원활하게 동작합니다.

:::tip
앱 스토어나 Google Play에서 별도의 앱을 설치하고 싶지 않다면 PWA가 좋은 선택입니다. 브라우저에서 이용하는 것과 같은 회원 포털 경험을 더 편리한 형태로 제공합니다.
:::

## 설치 페이지

가장 쉽게 설치하는 방법은 교회 전용 설치 페이지를 이용하는 것입니다.

```
https://yourchurchname.b1.church/mobile/install
```

이 페이지는 기기를 감지하여 올바른 안내를 자동으로 보여줍니다.

- **iPhone** -- 단계별 Safari "홈 화면에 추가" 안내
- **Android** -- Chrome의 **Install on Home Screen** 버튼을 한 번 탭
- **데스크톱** -- 휴대폰으로 스캔하여 설치 페이지를 여는 QR 코드

설치 페이지로 가는 방법은 여러 가지입니다.

- 회원 포털에서 **More**를 탭한 다음 **Account** 아래의 **Install App**을 탭합니다(앱이 이미 설치되어 있으면 이 항목은 숨겨집니다).
- 교회가 문자, 이메일 또는 주일 화면으로 공유한 링크를 따릅니다.
- 브라우저에 URL을 직접 입력합니다.

:::tip 교회 직원용
설치 페이지 링크를 성도들과 공유하세요. 주보, 뉴스레터 또는 슬라이드에 넣으면 됩니다. 각 회원이 자기 기기에 맞는 정확한 단계를 따라 할 수 있습니다. B1Admin 대시보드의 **Download the App** 빠른 작업에서도 이 페이지를 열 수 있습니다.
:::

아래의 브라우저 단계를 따라 교회 B1.church 사이트의 **아무 페이지**에서도 PWA를 직접 설치할 수 있습니다. 설치 페이지는 이 과정을 안내해 주는 방법일 뿐입니다.

설치된 앱을 실행하면 로그인할 준비가 된 회원 대시보드가 바로 열립니다.

## iPhone에 설치하기 (iOS -- Safari)

1. iPhone에서 **Safari**를 열고 `https://yourchurchname.b1.church/mobile/install`로 이동합니다(`yourchurchname`은 교회의 URL 슬러그로 바꿉니다).
2. 화면 하단의 **공유** 버튼(위쪽 화살표가 있는 상자)을 탭합니다.
3. 공유 시트를 아래로 스크롤하고 **Add to Home Screen**을 탭합니다.
4. 이름은 기본적으로 교회 이름으로 채워집니다. 오른쪽 상단의 **Add**를 탭합니다.

홈 화면에 앱 아이콘이 나타납니다. 이를 탭하면 전체 화면 모드로 회원 포털이 열립니다.

:::info
iOS에서 PWA를 설치하려면 Safari가 필요합니다. iPhone에서 Chrome이나 다른 브라우저를 사용 중이라면 먼저 Safari로 바꾸세요.
:::

## Android에 설치하기 (Chrome)

1. Android 기기에서 **Chrome**을 열고 `https://yourchurchname.b1.church/mobile/install`로 이동합니다.
2. **Install on Home Screen** 버튼을 탭합니다. (버튼이 보이지 않으면 오른쪽 상단의 점 세 개 메뉴(⋮)를 탭하고 **Add to Home screen**을 선택합니다.)
3. 나타나는 메시지에서 **Add**를 탭합니다.

홈 화면에 앱 아이콘이 나타납니다. 이를 탭하면 회원 포털이 열립니다.

## 설치 후

설치하면 PWA는 전용 전체 화면 창에서 바로 회원 포털을 엽니다. 다음을 할 수 있습니다.

- 기존 ChurchApps 계정으로 로그인합니다.
- 교회가 활성화한 모든 회원 기능(그룹, 헌금, 체크인, 봉사 계획 등)에 접근합니다.
- 언제든지 홈 화면의 아이콘을 탭하여 다시 들어옵니다.

읽지 않은 메시지가 있으면 앱 아이콘에 **알림 배지**(작은 숫자 표시)가 나타나므로, 새로 기다리는 내용이 있는지 한눈에 알 수 있습니다.

:::info
PWA는 인터넷 연결이 필요합니다. 일부 네이티브 앱과 달리 모든 콘텐츠를 오프라인 사용을 위해 저장하지는 않습니다.
:::

## 예전 B1 Mobile 앱은 어떻게 되나요?

iOS와 Android의 기존 네이티브 **B1 Mobile** 앱은 지원이 중단되어 더 이상 업데이트되지 않습니다. 앞으로 휴대폰에서 B1.church 회원 포털에 접속하는 공식 방법은 PWA이며, 네이티브 앱이 제공하던 회원용 기능을 모두 포함합니다. 이전에 네이티브 앱을 설치했다면 편한 때에 PWA로 전환하세요.

지원 중단된 앱에 대한 과거 문서는 [B1 Mobile 참조 페이지](/docs/b1-mobile/)를 참조하세요.
