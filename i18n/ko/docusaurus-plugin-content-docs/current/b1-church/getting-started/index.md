# B1.church 시작하기

<div class="article-intro">

B1.church는 교회의 온라인 공간입니다. 교회 공동체와 연결된 상태를 유지하고, 소식을 확인하고, 온라인으로 헌금하고, 예배를 체크인하는 등 많은 일을 할 수 있습니다. 이 섹션에서는 교인 포털에 접속하고 이용하는 기본 방법을 안내합니다.

</div>

## 교회 사이트 접속하기 {#accessing-your-churchs-site}

교회에는 보통 `https://yourchurchname.b1.church` 형식의 고유한 B1.church 주소가 있습니다. 컴퓨터, 태블릿, 휴대폰의 아무 웹 브라우저에서나 이 주소에 접속할 수 있습니다. 정확한 주소는 교회 지도자나 환영팀에 문의하세요.

처음 사이트에 접속하면 교회의 맞춤 브랜딩, 탐색 메뉴, 콘텐츠 페이지가 있는 공개 웹사이트가 보입니다.

## 계정 만들기 {#creating-an-account}

교인 포털과 그 기능을 이용하려면 ChurchApps 계정이 필요합니다.

1. 교회의 B1.church 주소에 접속합니다.
2. 페이지 오른쪽 상단의 **로그인** 버튼을 클릭합니다(버튼이 보이지 않으면 `/login`으로 이동하세요). 교인 포털에서는 대신 **로그인**을 탭합니다.
3. 로그인 화면에서 **회원 가입**을 선택합니다(교인 포털에서는 **계정 만들기**).
4. **이름**, **성**, **이메일 주소**를 입력하고 양식을 제출합니다.
5. 이메일에서 **6자리 인증 코드**를 확인하고 입력합니다.
6. **비밀번호**를 정합니다(최소 8자). 확인을 위해 한 번 더 입력하세요.

이제 로그인되었으며, 교인 포털의 모든 도구를 이용할 수 있습니다.

:::tip
교회에 이미 나를 등록해 두었다면, 교회 기록에 있는 것과 같은 이메일 주소를 사용하세요. 그러면 계정이 기존 교회 프로필과 연결됩니다.
:::

## 할 수 있는 일 {#what-you-can-do}

로그인하면 교인 포털에서 다음을 이용할 수 있습니다.

- 섬김, 그룹, 헌금의 미리 보기가 있는 **홈** 대시보드와, 나에게 다가오는 일정을 볼 수 있는 **내 정보** 페이지
- 참여 중인 **그룹**(대화와 행사 포함)
- 온라인 **헌금**
- 봉사 일정과 예배 세부 정보를 보여 주는 **계획**
- 예배와 행사를 위한 **체크인**
- 다른 교인을 찾고 연결될 수 있는 **커뮤니티** 디렉터리

## 휴대폰에서 이용하기 {#accessing-on-your-phone}

B1.church는 모든 모바일 브라우저에서 작동합니다. 더 앱처럼 쓰려면 교회의 교인 포털을 **프로그레시브 웹 앱(PWA**)으로 설치하세요. 기기별 안내를 보려면 `https://yourchurchname.b1.church/mobile/install`에 접속하거나, Safari나 Chrome에서 직접 홈 화면에 추가하세요. 앱 스토어는 필요하지 않습니다. 자세한 방법은 [앱(PWA)으로 설치하기](./installing-pwa.md)를 참고하세요.
