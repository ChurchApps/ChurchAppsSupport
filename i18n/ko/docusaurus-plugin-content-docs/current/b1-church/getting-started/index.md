# B1.church 시작하기

<div class="article-intro">

B1.church는 여러분 교회의 온라인 홈입니다. 회중과의 연결을 유지하고, 업데이트를 확인하고, 온라인으로 헌금하고, 예배에 체크인하는 등 다양한 활동을 할 수 있는 곳입니다. 이 섹션에서는 회원 포털에 접속하고 사용하는 기본 사항을 안내합니다.

</div>

## 소속 교회 사이트 접속하기

여러분의 교회는 보통 `https://yourchurchname.b1.church` 형식의 자체 B1.church URL을 가지고 있습니다. 컴퓨터, 태블릿, 휴대폰 등 어떤 기기의 웹 브라우저에서도 이 URL을 방문할 수 있습니다. 교회 리더십이나 환영팀에서 정확한 주소를 안내해 드릴 것입니다.

사이트를 처음 방문하면 교회 고유의 브랜딩, 탐색 메뉴, 콘텐츠 페이지가 있는 공개 웹사이트가 표시됩니다.

## 계정 만들기

회원 포털과 그 기능을 이용하려면 ChurchApps 계정이 필요합니다.

1. 소속 교회의 B1.church URL을 방문합니다.
2. 페이지 우측 상단의 **Login** 버튼을 클릭합니다.
3. 로그인 화면에서 새 계정을 **등록(Register)**하는 옵션을 선택합니다.
4. **이름**, **성**, **이메일 주소**를 입력하고 **비밀번호**를 설정합니다.
5. 등록 양식을 완료합니다.

등록 후에는 로그인하여 모든 도구를 갖춘 회원 포털에 접속할 수 있습니다.

:::tip
교회에서 이미 여러분을 시스템에 등록해 두었다면, 교회가 보유한 것과 동일한 이메일 주소를 사용하세요. 그러면 계정이 기존 교회 프로필과 연결됩니다.
:::

## 할 수 있는 일

로그인하면 회원 포털에서 다음과 같은 기능을 사용할 수 있습니다.

- 소속 그룹과 교회의 업데이트가 담긴 개인 **타임라인**
- 대화와 이벤트를 포함한, 소속되어 있는 **그룹**
- 헌금을 위한 온라인 **헌금(Giving)**
- 봉사 일정과 예배 세부 정보를 보여주는 **플랜(Plans)**
- 예배와 이벤트를 위한 **체크인**
- 다른 회원을 찾고 연결할 수 있는 **커뮤니티** 디렉터리

## 휴대폰에서 이용하기

B1.church는 모든 모바일 브라우저에서 작동합니다. 앱과 같은 경험을 원한다면 교회의 회원 포털을 **프로그레시브 웹 앱(PWA)**으로 설치하세요 -- `https://yourchurchname.b1.church/mobile/install`을 방문하면 기기별 맞춤 안내를 받을 수 있으며, Safari나 Chrome에서 직접 홈 화면에 추가할 수도 있습니다. 앱스토어가 필요 없습니다. 자세한 방법은 [앱으로 설치하기 (PWA)](./installing-pwa.md)를 참조하세요.

:::info
기존의 네이티브 B1 Mobile 앱은 지원이 종료되었습니다. 앞으로는 PWA가 휴대폰에서 B1.church를 이용하는 공식 지원 방법입니다 -- 참고용 과거 문서는 [B1 Mobile 참조 페이지](/docs/b1-mobile/)를 확인하세요.
:::
