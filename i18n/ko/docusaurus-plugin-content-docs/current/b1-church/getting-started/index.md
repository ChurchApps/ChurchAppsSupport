# B1.church 시작하기

<div class="article-intro">

B1.church는 교회의 온라인 공간입니다. 교인들과 연결된 상태를 유지하고, 소식을 확인하고, 온라인으로 헌금하고, 예배를 위해 체크인하는 등 다양한 일을 할 수 있는 곳입니다. 이 섹션에서는 회원 포털에 접속하고 사용하는 기본 방법을 안내합니다.

</div>

## 교회 사이트 접속하기

교회마다 고유한 B1.church 주소가 있으며, 일반적으로 `https://yourchurchname.b1.church` 형식입니다. 컴퓨터, 태블릿, 휴대폰의 웹 브라우저에서 이 주소에 접속할 수 있습니다. 정확한 주소는 교회 리더십 팀이나 환영 팀에 문의하시면 알 수 있습니다.

처음 사이트에 접속하면 교회의 맞춤 브랜딩, 탐색 메뉴, 콘텐츠 페이지가 포함된 공개 웹사이트가 나타납니다.

## 계정 만들기

회원 포털과 그 기능을 이용하려면 ChurchApps 계정이 필요합니다.

1. 교회의 B1.church 주소에 접속합니다.
2. 페이지 오른쪽 상단의 **Login** 버튼을 클릭합니다.
3. 로그인 화면에서 새 계정을 **Register**하는 옵션을 선택합니다.
4. **이름**, **성**, **이메일 주소**를 입력하고 **비밀번호**를 선택합니다.
5. 등록 양식을 작성하여 완료합니다.

등록을 마친 후에는 로그인하여 모든 도구를 갖춘 회원 포털에 접속할 수 있습니다.

:::tip
교회에서 이미 나를 시스템에 등록했다면, 교회에 등록된 것과 같은 이메일 주소를 사용하세요. 그러면 계정이 기존 교회 프로필과 연결됩니다.
:::

## 할 수 있는 일

로그인하면 회원 포털에서 다음 기능을 이용할 수 있습니다.

- 봉사, 그룹, 헌금 미리보기가 있는 **Home** 대시보드와 나에게 다가오는 일정을 보여주는 **Me** 페이지
- 대화와 행사를 포함하여 내가 속한 **그룹**
- 온라인 **헌금**(Giving)
- 봉사 일정과 예배 세부 정보를 보여주는 **계획표**(Plans)
- 예배와 행사를 위한 **체크인**(Check-In)
- 다른 회원을 찾고 연결할 수 있는 **커뮤니티** 디렉터리

## 휴대폰에서 접속하기

B1.church는 모든 모바일 브라우저에서 작동합니다. 더 앱과 비슷한 경험을 원하시면 교회 회원 포털을 **프로그레시브 웹 앱(PWA)**으로 설치하세요. 기기에 맞는 단계별 안내를 보려면 `https://yourchurchname.b1.church/mobile/install`을 방문하거나, Safari나 Chrome에서 직접 홈 화면에 추가하면 됩니다. 앱 스토어는 필요하지 않습니다. 자세한 방법은 [앱으로 설치하기(PWA)](./installing-pwa.md)를 참조하세요.
