# B1.church 시작하기

<div class="article-intro">

B1.church는 교회의 온라인 공간입니다. 성도들과 계속 연결되고, 소식을 확인하고, 온라인으로 헌금하고, 예배에 체크인하는 등 많은 일을 할 수 있는 곳입니다. 이 섹션에서는 회원 포털에 접속하고 사용하는 기본 방법을 안내합니다.

</div>

## 교회 사이트 접속하기

교회에는 보통 `https://yourchurchname.b1.church` 형식의 자체 B1.church 주소가 있습니다. 이 주소는 컴퓨터, 태블릿, 휴대폰의 어떤 웹 브라우저에서도 열 수 있습니다. 정확한 주소는 교회 지도자나 환영팀에게 문의하세요.

사이트를 처음 방문하면 교회의 맞춤 브랜딩, 탐색 메뉴, 콘텐츠 페이지가 있는 공개 웹사이트가 표시됩니다.

## 계정 만들기

회원 포털과 그 기능을 이용하려면 ChurchApps 계정이 필요합니다.

1. 교회의 B1.church 주소를 방문합니다.
2. 페이지 오른쪽 상단의 **Login** 버튼을 클릭합니다.
3. 로그인 화면에서 새 계정을 **Register**하는 옵션을 선택합니다.
4. **이름**, **성**, **이메일 주소**를 입력하고 **비밀번호**를 선택합니다.
5. 등록 양식을 완료합니다.

등록을 마치면 로그인하여 모든 도구가 있는 회원 포털에 접속할 수 있습니다.

:::tip
교회가 이미 나를 시스템에 등록해 두었다면, 교회에 등록된 것과 같은 이메일 주소를 사용하세요. 그러면 계정이 기존 교회 프로필과 연결됩니다.
:::

## 할 수 있는 일

로그인하면 회원 포털에서 다음을 이용할 수 있습니다.

- 봉사, 그룹, 헌금 내용을 미리 볼 수 있는 **Home** 대시보드와, 다가오는 일정을 보여주는 **Me** 페이지
- 대화와 이벤트를 포함하여 내가 속한 **Groups**(그룹)
- 헌금을 위한 온라인 **Giving**(헌금)
- 봉사 일정과 예배 세부 정보를 보여주는 **Plans**(계획)
- 예배와 행사를 위한 **Check-In**(체크인)
- 다른 회원을 찾고 연결할 수 있는 **Community**(커뮤니티) 디렉토리

## 휴대폰에서 이용하기

B1.church는 모든 모바일 브라우저에서 작동합니다. 더 앱과 같은 경험을 원한다면 교회의 회원 포털을 **PWA(Progressive Web App)**로 설치하세요. `https://yourchurchname.b1.church/mobile/install`을 방문하면 기기에 맞는 안내를 따라 할 수 있으며, Safari나 Chrome에서 직접 홈 화면에 추가할 수도 있습니다. 앱 스토어가 필요 없습니다. 자세한 내용은 [앱으로 설치하기(PWA)](./installing-pwa.md)를 참조하세요.

:::info
기존 네이티브 B1 Mobile 앱은 지원이 중단되었습니다. 앞으로 휴대폰에서 B1.church를 이용하는 공식 방법은 PWA입니다. 과거 문서는 [B1 Mobile 참조 페이지](/docs/b1-mobile/)를 참조하세요.
:::
