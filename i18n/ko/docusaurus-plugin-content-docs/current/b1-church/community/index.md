# 커뮤니티

<div class="article-intro">

B1.church의 **커뮤니티** 섹션은 교회 가족과 계속 연결되도록 도와줍니다. 교회 교인들을 찾고 알아볼 수 있는 교인 디렉터리를 제공합니다.

</div>

## 이 섹션에서 찾을 수 있는 내용 {#what-you-will-find}

- **[교인 디렉터리](./member-directory.md)** -- 교회 교인 디렉터리를 둘러보고 검색합니다. 이름으로 찾고 싶은 사람을 조회할 수 있습니다. 교인을 클릭하면 프로필 세부 정보를 볼 수 있습니다.
- **[메시지와 알림](./messages.md)** -- 다른 교인에게 개인 메시지를 보내고, 받은 편지함에서 알림을 확인합니다.
- **[타임라인](./timeline.md)** -- 예전의 통합 활동 피드로, 현재는 지원이 중단되었습니다. 이 페이지에서는 각 종류의 업데이트가 지금 어디에 있는지 설명합니다.

## 시작하기 {#getting-started}

커뮤니티 기능을 이용하려면 [로그인](../getting-started/logging-in.md)되어 있어야 합니다. 로그인하지 않은 경우 **커뮤니티** 탭에는 디렉터리 대신 로그인 안내가 표시됩니다.

교인 포털은 [홈 대시보드](../getting-started/navigating.md)에서 열립니다. **커뮤니티** 탭에서 교인 디렉터리에 접근할 수 있고, 앱 바의 **종 모양 아이콘**을 누르면 메시지와 알림이 열립니다.

:::info
디렉터리에서 볼 수 있는 교인과 정보는 교회의 개인 정보 설정에 따라 달라집니다. 모든 교인의 전체 프로필을 볼 수 없을 수도 있습니다. 공개되는 정보에 대해 궁금한 점이 있으면 교회 관리자에게 문의하세요.
:::

:::tip
[그룹](../groups/index.md)과 함께 커뮤니티 기능을 활용하면 일주일 내내 교회와 더 가깝게 연결될 수 있습니다.
:::
