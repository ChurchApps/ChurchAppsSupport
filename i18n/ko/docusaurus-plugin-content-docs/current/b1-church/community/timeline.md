# 타임라인

<div class="article-intro">

독립된 **타임라인** 탭은 폐지되었습니다. 이제 구성원 포털은 [홈 대시보드](../getting-started/navigating.md)로 열리며, 예전에 하나의 통합 피드에 나타나던 활동은 각각 해당하는 곳에 표시됩니다. 나 페이지, 알림, 그리고 각 그룹 안에서 확인할 수 있습니다.

</div>

## 타임라인 활동은 이제 어디에 있나요

| 예전에 타임라인에서 보던 것 | 지금 찾을 수 있는 곳 |
| --- | --- |
| 그룹 대화와 공지 | 각 [그룹](../groups/conversations.md) 안의 채팅(**Open chat**) |
| 나와 내 그룹의 다가오는 행사 | **나(Me)** 페이지(`/mobile/me`)와 각 그룹의 **Next event** 섹션 |
| 할 일과 봉사 배정 | **나(Me)** 페이지와 [계획(Plans)](../plans/) |
| 새 설교 | 홈의 **Latest sermon** 섹션과 [설교(Sermons)](../content/sermons.md) 탭 |
| 나에게 온 알림 | 앱 바의 **종** 아이콘 또는 `/mobile/notifications` |

## 나(Me) 페이지

[나 페이지](../getting-started/me-page)는 예전 피드를 가장 가깝게 대신합니다. 여기에는 다가오는 항목이 나열됩니다. 봉사 배정, 행사 등록, 그룹 행사가 포함되며, 제출한 양식, 출석 기록, 최근 알림도 보입니다. 프로필, 알림 설정, 메시지, 헌금, 등록 내역으로 바로 연결되는 링크도 있습니다.

## 알림

이전에는 타임라인 항목으로 나타나 주의가 필요했던 것들이 이제는 알림으로 전달됩니다. 앱 바의 종 아이콘을 누르면 최신 알림을 볼 수 있으며, **See all**을 누르거나 `/mobile/notifications`를 열면 전체 목록을 볼 수 있습니다. 알림을 누르면 그 알림이 시작된 그룹, 계획, 대화로 이동합니다. 어떤 알림을 받을지, 그리고 어떤 방식으로 받을지는 [알림 설정](../getting-started/notification-preferences.md)에서 조정할 수 있습니다.

:::tip
나 페이지가 비어 보인다면 아직 어떤 그룹에도 속해 있지 않을 수 있습니다. [그룹](../groups/browsing-groups.md) 페이지에서 가입할 그룹을 찾아보거나, 교회 관리자나 그룹 리더에게 그룹에 추가해 달라고 요청하세요.
:::
