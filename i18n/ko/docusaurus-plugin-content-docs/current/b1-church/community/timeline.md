# 타임라인 {#timeline}

<div class="article-intro">

독립된 **타임라인** 탭은 더 이상 제공되지 않습니다. 회원 포털은 이제 [홈 대시보드](../getting-started/navigating.md)에서 열리며, 예전에 하나의 통합 피드에 나타나던 활동은 각자 알맞은 곳에 표시됩니다. 즉, 나 페이지, 알림, 그리고 각 그룹 안에 나타납니다.

</div>

## 타임라인 활동은 이제 어디에 있나요 {#where-timeline-activity-lives-now}

| 예전에 타임라인에서 보던 것 | 이제 찾을 수 있는 곳 |
| --- | --- |
| 그룹 대화와 공지 | 각 [그룹](../groups/conversations.md) 안의 채팅(**채팅 열기**) |
| 나와 내 그룹의 다가오는 이벤트 | **나** 페이지(`/mobile/me`)와 각 그룹의 **다음 이벤트** 섹션 |
| 작업과 섬김 배정 | **나** 페이지와 [일정](../plans/) |
| 새 설교 | 홈의 **최신 설교** 섹션과 [설교](../content/sermons.md) 탭 |
| 나에게 알림을 보낸 항목 | 앱 바의 **종** 아이콘 또는 `/mobile/notifications` |

## 나 페이지 {#the-me-page}

[나 페이지](../getting-started/me-page)는 예전 피드를 가장 가깝게 대체하는 화면입니다. 나에게 다가오는 일, 즉 섬김 배정, 이벤트 등록, 그룹 이벤트를 나열하며, 제출한 양식, 출석 기록, 최근 알림도 함께 보여 줍니다. 또한 프로필, 알림 설정, 메시지, 헌금, 등록으로 바로 연결되는 링크가 있습니다.

## 알림 {#notifications}

예전에는 타임라인 항목으로 나타났고 주의가 필요했던 내용은 이제 알림으로 도착합니다. 앱 바의 종을 탭하면 최신 알림을 볼 수 있으며, **모두 보기**를 탭하거나(또는 `/mobile/notifications`를 열면) 전체 목록을 볼 수 있습니다. 알림을 탭하면 그 알림이 시작된 그룹, 일정, 또는 대화로 이동합니다. 어떤 알림을 어떻게 받을지는 [알림 설정](../getting-started/notification-preferences.md)에서 조절할 수 있습니다.

:::tip
나 페이지가 비어 보인다면 아직 어떤 그룹에도 속해 있지 않을 수 있습니다. [그룹](../groups/browsing-groups.md) 페이지에서 가입할 그룹을 찾아보거나, 교회 관리자나 그룹 리더에게 추가해 달라고 요청하세요.
:::
