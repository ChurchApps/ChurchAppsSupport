# 타임라인

<div class="article-intro">

독립형 **Timeline** 탭은 더 이상 제공되지 않습니다. 회원 포털은 이제 [홈 대시보드](../getting-started/navigating.md)에서 열리며, 예전에 하나의 통합 피드에 표시되던 활동은 이제 적절한 위치에 나타납니다. 즉, Me 페이지, 알림, 각 그룹 안에서 확인할 수 있습니다.

</div>

## 타임라인 활동은 이제 어디에 있나요

| 예전에 타임라인에서 보던 것 | 지금 찾을 수 있는 곳 |
| --- | --- |
| 그룹 대화와 공지 | 각 [그룹](../groups/conversations.md) 안의 채팅(**Open chat**) |
| 나와 내 그룹의 예정된 이벤트 | **Me** 페이지(`/mobile/me`)와 각 그룹의 **Next event** 섹션 |
| 작업과 봉사 배정 | **Me** 페이지와 [계획](../plans/) |
| 새 설교 | 홈의 **Latest sermon** 섹션과 [설교](../content/sermons.md) 탭 |
| 나에게 알림이 온 항목 | 앱 바의 **벨** 아이콘 또는 `/mobile/notifications` |

## Me 페이지

[Me 페이지](../getting-started/me-page)는 예전 피드를 가장 가깝게 대체하는 기능입니다. 봉사 배정, 이벤트 등록, 그룹 이벤트처럼 나에게 다가오는 항목과 가장 최근 알림을 나열하며, 프로필, 알림 설정, 메시지, 헌금, 등록 내역으로 바로 연결되는 링크가 있습니다.

## 알림

예전에 타임라인 항목으로 나타나 주의가 필요했던 내용은 이제 알림으로 도착합니다. 앱 바의 벨을 탭하면 최신 알림을 볼 수 있고, **See all**을 탭하거나(또는 `/mobile/notifications`를 열면) 전체 목록을 볼 수 있습니다. 알림을 탭하면 그 알림이 온 그룹, 계획 또는 대화로 이동합니다. 어떤 알림을 받을지, 그리고 어떤 방식으로 받을지는 [알림 설정](../getting-started/notification-preferences.md)에서 조정할 수 있습니다.

:::tip
Me 페이지가 비어 보인다면 아직 어떤 그룹의 회원도 아닐 수 있습니다. 참여할 그룹을 찾으려면 [그룹](../groups/browsing-groups.md) 페이지를 방문하거나, 교회 관리자나 그룹 리더에게 추가해 달라고 요청하세요.
:::
