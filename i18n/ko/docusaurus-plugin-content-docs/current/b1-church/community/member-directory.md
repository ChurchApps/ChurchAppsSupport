# 교인 디렉터리

<div class="article-intro">

교인 디렉터리를 통해 교회의 사람들을 둘러보고 검색할 수 있습니다. 같은 그룹의 교인을 찾고 싶든, 새로운 사람을 발견하고 싶든, 디렉터리를 이용하면 교회 가족과 쉽게 연결할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1.church 계정에 [로그인](../getting-started/logging-in.md)되어 있어야 합니다.
- 디렉터리는 **교인과 스태프**만 이용할 수 있습니다. 아직 교인이 되지 않은 방문자와 참석자에게는 "교인 전용" 메시지가 대신 표시됩니다.

</div>

## 디렉터리 접근하기

1. [사이드바 내비게이션](../getting-started/navigating.md)에서 **커뮤니티(Community)**를 클릭합니다.
2. 페이지 왼쪽에 표시 가능한 모든 교인의 목록이 로드됩니다.

## 교인 검색하기

이 페이지는 마스터-디테일 레이아웃을 사용합니다. 왼쪽에서 두 가지 방법으로 사람을 찾을 수 있습니다.

### 이름으로 검색하기

1. 검색 영역 상단에서 **사람(People)** 필터가 선택되어 있는지 확인합니다.
2. 검색창에 이름을 입력합니다.
3. **검색(Search)**을 클릭하거나 **Enter**를 눌러 결과를 확인합니다.

검색창을 비운 채로 **검색(Search)**을 클릭하면 전체 디렉터리 목록이 표시됩니다.

### 그룹으로 검색하기

1. 검색 영역 상단의 **그룹(Groups)** 필터를 클릭합니다.
2. 드롭다운 목록에서 그룹을 선택합니다.
3. **검색(Search)**을 클릭해 해당 그룹의 모든 구성원을 확인합니다.

:::tip
그룹으로 검색하는 것은 [그룹 모임](../groups/browsing-groups.md)에서 만났지만 이름이 잘 기억나지 않는 사람을 빠르게 찾는 방법입니다.
:::

## 디렉터리 둘러보기

교인은 성을 기준으로 알파벳순으로 나열되며 글자별 제목(A, B, C 등)으로 그룹화됩니다. 각 항목에는 교인의 사진, 표시 이름, 가족 이름이 표시되어 목록을 쉽게 훑어볼 수 있습니다.

## 교인 프로필 보기

목록에서 아무 교인이나 클릭하면 오른쪽 상세 패널에 프로필이 열립니다. 프로필에는 교회에서 설정한 대로 교인 정보가 표시되며, 여기에는 연락처, 가족 구성원, 그룹 소속 정보가 포함될 수 있습니다.

프로필 안에서 가족 구성원을 클릭하면 그들의 프로필로도 이동할 수 있습니다.

:::info
각 프로필에서 볼 수 있는 정보는 교회의 개인정보 보호 및 디렉터리 설정에 따라 달라집니다. 모든 교인에게 모든 필드가 표시되는 것은 아닙니다.
:::
