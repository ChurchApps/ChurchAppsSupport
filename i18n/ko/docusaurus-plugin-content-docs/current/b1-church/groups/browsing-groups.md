# 그룹 탐색하기

<div class="article-intro">

교회의 공개 그룹 페이지에서는 관심 있는 그룹을 쉽게 찾을 수 있습니다. 그룹은 카테고리별로 정리되어 있어서, 여러 종류의 그룹을 빠르게 훑어보고 자신에게 맞는 그룹을 찾을 수 있습니다.

## 그룹 페이지 찾기

교회의 B1.church 사이트에서 **Groups** 페이지로 이동하세요. 이 페이지는 누구나 볼 수 있으므로, 둘러보는 데 로그인할 필요가 없습니다.

## 그룹 정리 방식

그룹은 **카테고리**(라벨이라고도 함)별로 표시됩니다. 카테고리는 교회 관리자가 설정하며, "Small Groups", "Ministries", "Youth", "Bible Studies" 같은 라벨이 있을 수 있습니다. 각 카테고리에는 그 카테고리에 속한 모든 그룹이 표시됩니다.

## 그룹 카드 읽기

각 그룹은 다음 정보가 담긴 카드로 표시됩니다.

- **그룹 사진** -- 그룹을 나타내는 대표 이미지입니다. 사진이 설정되지 않았다면 기본 이미지가 표시됩니다.
- **그룹 이름** -- 사진 위에 눈에 띄게 표시됩니다.
- **모임 시간** -- 그룹이 보통 모이는 시간(예: "Wednesdays at 7 PM"). 시간이 설정되지 않았다면 자리 표시자가 나타납니다.
- **모임 장소** -- 그룹이 모이는 곳입니다. 장소가 설정되지 않았다면 자리 표시자가 나타납니다.
- **설명** -- 그룹이 어떤 곳인지 보여 주는 짧은 미리 보기로, 몇 줄로 제한됩니다. 그룹을 클릭하면 전체 설명을 읽을 수 있습니다.

## 그룹 보기

그룹 카드를 클릭하면 그룹의 상세 페이지가 열립니다. 여기에는 전체 설명, 그룹 리더에 대한 정보, 다가오는 캘린더 행사, 연락하는 방법이 있습니다.

:::tip
특정 종류의 그룹을 찾고 있다면 먼저 카테고리 제목을 훑어보세요. 모든 그룹을 스크롤하는 대신, 관심 있는 섹션으로 바로 갈 수 있습니다.
:::
