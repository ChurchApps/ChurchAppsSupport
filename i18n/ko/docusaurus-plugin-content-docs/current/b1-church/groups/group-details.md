# 그룹 상세정보

<div class="article-intro">

그룹 페이지에서 그룹을 클릭하면 그룹 상세 페이지로 이동합니다. 표시되는 내용은 로그인 여부에 따라 달라지며, 로그인한 회원은 추가 탭과 기능에 액세스할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [그룹 찾아보기](./browsing-groups.md)에서 볼 그룹을 찾습니다.
- 모든 탭에 완전히 액세스하려면 [계정에 로그인](../getting-started/logging-in.md)하세요.

</div>

## 방문자 보기 (로그인하지 않음)

로그인하지 않은 경우 다음이 표시됩니다.

- **히어로 섹션** -- 그룹의 사진, 이름, 모임 시간, 모임 위치를 보여주는 큰 배너 영역입니다.
- **설명** -- 그룹의 목적과 예상되는 사항을 설명하는 전체 설명입니다.
- **리더** -- 그룹의 리더의 아바타와 이름입니다. 리더의 이름을 클릭하여 프로필을 볼 수 있습니다.
- **캘린더 이벤트** -- 그룹의 예정된 이벤트 중 최대 3개가 표시되며, 각각 날짜와 이벤트 제목을 보여줍니다. 그룹에 예정된 이벤트가 없으면 이 섹션은 숨겨집니다.
- **로그인하여 참여** -- 페이지 하단의 버튼입니다. 로그인(또는 계정 만들기)하여 그룹에 참여하거나 참여를 요청합니다. 로그인 후 그룹으로 돌아가 바로 참여 단계로 진행합니다.

## 회원 보기 (로그인함)

로그인했지만 그룹의 회원이 아닌 경우 그룹의 히어로 섹션과 설명, 그리고 그룹의 참여 옵션이 표시됩니다(아래 [그룹에 참여](#그룹에-참여) 참조). 회원이 되면 다음 탭이 나타납니다.

회원인 경우 그룹 상세 페이지에 히어로 섹션과 탭 사이드바가 표시됩니다. 그룹이 Lessons.church 계획 유형과 연결되어 있고 이번 주 레슨에 부모용 가정 콘텐츠가 있으면, **이번 주 레슨** 카드가 히어로와 탭 사이에 나타납니다(회원만).

사용 가능한 탭은 다음과 같습니다.

- **정보** -- 그룹의 전체 설명으로 풍부한 텍스트 형식으로 렌더링됩니다. 그룹에 설명이 있는 경우에만 표시됩니다.
- **계획** -- 그룹의 서비스 계획입니다. 그룹에 계획이 있는 경우에만 표시됩니다.
- **메시지** -- 그룹 회원들이 메시지를 게시하고 서로 상호작용할 수 있는 공간입니다. 회원만 볼 수 있으며, 교회에서 이 그룹의 그룹 채팅을 활성화한 경우에만 표시됩니다. 자세한 내용은 [그룹 대화](./conversations.md)를 참조하세요.
- **회원** -- 그룹의 모든 회원 목록으로 사진과 이름을 보여줍니다. 회원의 이름을 클릭하여 [회원 디렉토리](../community/member-directory.md)에서 프로필을 방문할 수 있습니다.
- **출석** -- 그룹 리더(및 출석 권한이 있는 직원)에게만 표시됩니다. 그룹 모임에 참석한 사람을 추적할 수 있습니다.
- **이벤트** -- 모임과 이벤트를 보여주는 그룹의 캘린더입니다. 화살표를 사용하여 월 사이를 이동합니다. 월 이름 아래의 두 버튼으로 보기를 전환합니다. **월간 보기**(달력 아이콘)는 달력 격자를 보여 주며 날짜를 탭하면 해당 날의 이벤트를 볼 수 있고, **목록 보기**(목록 아이콘)는 해당 월의 이벤트를 날짜별로 묶어 날짜순으로 보여 줍니다. 현재 월을 보고 있을 때는 목록이 오늘부터 시작하므로 앞으로 남은 이벤트만 표시됩니다.
- **리소스** -- 그룹을 위해 게시된 공유 파일과 링크입니다. 업로드된 파일을 다운로드하거나 링크된 리소스를 열 수 있습니다.

## 리더 기능

그룹의 리더인 경우 추가 편집 기능이 있습니다.

- **이벤트 만들고 편집하기** -- **이벤트** 탭에서 그룹 캘린더에 이벤트를 추가합니다. 이벤트를 만들 때 이벤트와 함께 룸과 리소스를 예약할 수 있습니다. 사용 가능한 룸과 리소스를 선택하고, 선택적 설정 및 해제 시간을 설정하면 예약 요청이 자동으로 승인을 위해 제출됩니다.
- **리소스 관리** -- 파일을 업로드(최대 100MB 저장소), 링크를 추가하거나 기존 리소스를 삭제합니다.
- **출석 추적** -- **출석** 탭에서 그룹 세션의 출석을 기록합니다.

그룹의 이름, 설명 또는 회원 목록을 변경하려면 B1 Admin을 사용하세요. [그룹 회원](../../b1-admin/groups/group-members.md)을 참조하세요.

## 그룹에 참여

로그인했지만 아직 회원이 아닌 경우 그룹 상세 페이지에 참여 버튼이 나타납니다. 버튼 레이블은 그룹의 참여 정책에 따라 다릅니다.

- **그룹에 참여** -- 그룹이 개방되어 있습니다. 클릭하면 즉시 회원으로 추가됩니다.
- **참여 요청** -- 그룹에 승인이 필요합니다. 클릭하면 그룹 리더에게 선택적 메시지를 포함하여 요청을 제출할 수 있는 대화 상자가 열립니다. 요청 관리에 대한 자세한 내용은 [그룹에 참여 요청](./join-requests.md)을 참조하세요.

요청을 보낸 후 버튼은 **요청 대기 중** 알림으로 교체됩니다. "그룹 참여 요청이 전송되었습니다. 그룹 리더가 검토할 것입니다."

로그인하지 않은 상태에서 **로그인하여 참여**를 클릭한 경우 로그인 후 그룹으로 돌아가며 참여 단계가 자동으로 시작됩니다. 개방 그룹은 즉시 추가되고, 승인이 필요한 그룹은 **참여 요청** 대화 상자가 열립니다.

두 버튼 모두 나타나지 않으면 그룹이 닫혀 있으며 회원은 리더 또는 관리자가 수동으로 추가해야 합니다.

:::info
그룹에 참여하거나 참여를 요청하려면 로그인해야 합니다. 그룹이 닫혀 있고 참여하고 싶으면 교회 사무실이나 그룹의 리더 중 한 명에게 문의하세요.
:::
