# 그룹 세부 정보
<div class="article-intro">
그룹 페이지에서 그룹을 클릭하면, 그룹 세부 정보 페이지로 이동합니다. 로그인 여부에 따라 보이는 내용이 달라집니다.
</div>
<div class="prereqs">
<h4>시작하기 전에</h4>
- [그룹 탐색](./browsing-groups.md)을 통해 그룹을 찾습니다
- 모든 탭에 대한 전체 액세스를 위해 [로그인](../getting-started/logging-in.md)합니다
</div>
## 방문자 보기 (로그인하지 않음)
로그인하지 않으면, 다음을 봅니다:
- **히어로 섹션** — 그룹의 사진, 이름, 모임 시간, 위치를 보여줍니다
- **설명** — 그룹의 전체 설명
- **리더** — 그룹 리더의 아바타와 이름
- **달력 이벤트** — 그룹의 최대 3개 예정 이벤트
- **연락 양식** — 그룹 리더에게 메시지를 보낼 수 있는 양식
## 회원 보기 (로그인함)
로그인하면, 다음 탭이 사이드바에 표시됩니다:
- **그룹 세부 정보** — 그룹의 전체 설명
- **회원** — 그룹의 모든 회원 목록
- **달력** — 그룹 모임 및 이벤트 달력
- **대화** — 그룹 회원 간의 메시지 공간
- **자료** — 공유된 파일 및 링크
- **출석** — 그룹 리더만 볼 수 있습니다
## 리더 기능
그룹의 리더인 경우, 추가 편집 기능이 있습니다:
- **그룹 세부 정보 편집**
- **회원 관리**
- **이벤트 생성 및 편집**
- **자료 관리**
- **출석 기록**
## 그룹 가입
로그인했는데 아직 회원이 아닌 경우, 참여 버튼이 나타납니다.
