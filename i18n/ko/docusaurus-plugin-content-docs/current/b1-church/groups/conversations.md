# 그룹 대화

<div class="article-intro">

그룹 채팅은 그룹 구성원이 메시지를 게시하고 서로 소통하는 공간입니다. 대화를 이용해 주제를 논의하고, 소식을 나누고, 모임 사이에도 그룹과 연결된 상태를 유지하세요.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1.church 계정에 [로그인](../getting-started/logging-in.md)되어 있어야 합니다.
- 그룹 채팅에 접근하려면 해당 그룹의 구성원이어야 합니다. 그룹에 가입하는 방법은 [그룹 상세 정보](./group-details.md)를 참고하세요.

</div>

## 대화 접근하기 {#accessing-conversations}

1. [그룹 목록 페이지](./browsing-groups.md)에서 그룹을 클릭하여 그룹 상세 페이지로 이동합니다.
2. 로그인되어 있는지 확인합니다.
3. 그룹 이름 아래의 **채팅 열기**를 탭하거나, 최신 메시지를 미리 보여 주는 **메시지** 섹션을 탭합니다. 채팅이 전체 화면으로 열리며, 뒤로 가기 화살표를 탭하면 그룹으로 돌아갑니다.

## 토론과 공지사항 {#discussions-and-announcements}

그룹 채팅에는 교회에서 이 그룹에 대해 켜 둔 기능에 따라 두 가지 피드가 있을 수 있습니다. 채팅 상단의 그룹 이름 위에 표시되는 라벨을 보면 현재 어떤 피드에 있는지 알 수 있습니다.

- **채팅** -- 토론 공간으로, 모든 그룹 구성원이 메시지를 게시하고 다른 사람의 글에 답글을 달 수 있습니다.
- **공지사항** -- 모든 구성원이 꼭 봐야 하는 내용으로, 그룹 리더가 게시한 메시지입니다. 일반 구성원은 공지를 읽고 반응할 수 있지만 게시할 수는 없으며, 메시지 상자 대신 "그룹 리더만 공지를 게시할 수 있습니다."가 표시됩니다.

두 피드가 모두 켜져 있으면 채팅 상단의 **공지** 띠에 가장 최근 공지가 표시됩니다. **모든 공지**를 탭하면 공지 피드가 열리고, **채팅으로 돌아가기**를 탭하면 토론으로 돌아갑니다. (구성원은 그룹에 공지가 하나 이상 있을 때만 이 띠를 볼 수 있습니다.)

교회가 이 그룹에 두 피드 중 하나만 켜 두었다면, 채팅은 바로 그 피드로 열립니다. 둘 다 꺼져 있으면 그룹에는 채팅도 **메시지** 섹션도 없습니다.

## 메시지 게시하기 {#posting-a-message}

1. 그룹 페이지에서 **채팅 열기**를 탭합니다.
2. **채팅** 피드에 있는지 확인합니다(공지를 읽고 있다면 **채팅으로 돌아가기**를 탭하세요).
3. **메시지 보내기…** 상자에 메시지를 입력합니다.
4. 보내기 버튼을 탭하여 그룹과 공유합니다. 휴대폰이나 태블릿에서는 엔터 키를 누르면 줄이 바뀌고, 컴퓨터에서는 **Enter**가 전송, **Shift+Enter**가 줄 바꿈입니다.

메시지는 그룹의 모든 구성원에게 보입니다. 각 메시지에는 보낸 시각이 표시됩니다. 오늘 보낸 메시지는 시간만, 어제 보낸 메시지는 "어제"와 시간, 그보다 오래된 메시지는 날짜와 시간이 표시됩니다.

## 메시지 서식 지정하기 {#formatting-your-message}

메시지에 굵은 글씨, 기울임꼴, 목록을 추가할 수 있습니다.

1. 메시지 상자를 탭합니다. 선택된 상태에서는 그 아래에 **굵게**, **기울임꼴**, **글머리 기호 목록**, **번호 목록** 버튼 줄이 나타납니다.
2. 메시지를 입력하고, 서식을 적용할 단어나 줄을 선택한 다음 버튼을 탭합니다. 텍스트가 선택된 상태에서 같은 버튼을 다시 탭하면 서식이 제거됩니다. 아무것도 선택하지 않았다면 목록 버튼은 현재 줄에 서식을 적용합니다.
3. 평소처럼 메시지를 보냅니다.

컴퓨터에서는 굵게 **Ctrl+B**(Mac에서는 **Cmd+B**), 기울임꼴 **Ctrl+I**(**Cmd+I**)를 사용할 수도 있습니다.

도구 모음은 텍스트에 간단한 마크다운을 적용합니다. `**bold**`, `_italic_`, 줄 시작에 `- `를 쓰면 글머리 기호 목록, `1. `을 쓰면 번호 목록이 됩니다. 직접 입력해도 됩니다. 채팅의 모든 사람에게 서식이 적용된 메시지가 보이고, 웹 링크는 클릭할 수 있으며(새 탭에서 열립니다), 이미지 링크(.jpg, .png, .gif 등)는 메시지 아래에 그림으로 표시되고, 줄바꿈도 유지됩니다. 같은 서식이 공지사항, [리더 메모](./group-details.md#leader-notes), 개인 메시지에서도 작동합니다.

## 메시지 수정하거나 삭제하기 {#editing-or-deleting-your-messages}

내가 게시한 메시지는 수정하거나 삭제할 수 있습니다.

1. 메시지 아래의 **더 보기** 버튼(⋮)을 탭하여 메시지 메뉴를 엽니다.
2. 메시지 내용을 바꾸려면 **수정**을, 삭제하려면 **삭제**를 고릅니다.
   - 수정할 때는 메시지 내용이 입력란에 다시 불러와지고, 위에 **메시지 수정 중** 안내가 나타납니다(수정을 멈추려면 **취소**를 탭하세요). 내용을 바꾸고 보내면 저장됩니다.
   - 삭제할 때는 **메시지를 삭제하시겠습니까?** 확인 창이 나타납니다. **삭제**를 탭하면 대화의 모든 사람에게서 메시지가 영구적으로 제거됩니다.

:::info
내가 쓴 메시지만 수정할 수 있습니다. 그룹 리더는 다른 구성원의 메시지도 삭제할 수 있으며, 일반 구성원은 자신의 메시지에 대한 옵션만 볼 수 있습니다.
:::

## 메시지에 반응하기 {#reacting-to-messages}

그룹 채팅에서는 어떤 메시지에든 이모지로 반응할 수 있습니다.

1. 메시지 아래의 **반응 추가** 버튼을 탭합니다.
2. 여섯 가지 이모지 중 하나를 고릅니다: 👍 ❤️ 😂 🎉 🙏 😮.

반응은 메시지 아래에 작은 칩으로 나타나며, 각 이모지를 사용한 사람 수가 함께 표시됩니다. 내 반응은 강조 표시됩니다. 칩을 탭하거나(같은 이모지를 다시 고르면) 반응을 제거할 수 있고, 다른 이모지를 고르면 하나 더 추가됩니다. 반응은 채팅의 모든 사람에게 실시간으로 표시됩니다.

:::tip
그룹 대화는 각 그룹의 채팅에 있습니다. 예전의 통합 [타임라인](../community/timeline.md) 피드는 지원이 중단되었습니다. 주의가 필요한 활동은 앱 바의 **종** 아이콘 아래 알림으로 도착합니다.
:::

## 리더 기능 {#leader-features}

그룹 리더라면 그룹 채팅에서 추가 기능을 쓸 수 있습니다.

- **공지 게시하기** -- **모든 공지**를 탭하거나(공지만 켜져 있을 때는 채팅을 열고) 모든 그룹 구성원이 읽을 수 있는 메시지를 게시하세요.
- **메시지 삭제하기** -- 메시지 메뉴(⋮)에서 구성원의 메시지를 삭제할 수 있습니다.
- **토론에 게시하기** -- 다른 구성원과 똑같이 일반 토론에도 참여할 수 있습니다.

:::info
대화는 그룹마다 따로 있습니다. 한 그룹에 올린 메시지는 다른 그룹의 대화에 나타나지 않습니다.
:::
