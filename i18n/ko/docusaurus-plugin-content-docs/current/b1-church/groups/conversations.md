# 그룹 대화

<div class="article-intro">

그룹 페이지의 Conversations 탭은 그룹 구성원들이 메시지를 게시하고 서로 소통할 수 있는 공간입니다. 대화 기능을 활용해 주제를 논의하고, 소식을 공유하고, 모임 사이에도 그룹과 계속 연결되어 있으세요.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1.church 계정에 [로그인](../getting-started/logging-in.md)해야 합니다.
- Conversations 탭에 접속하려면 해당 그룹의 구성원이어야 합니다. 그룹 가입 방법은 [그룹 세부 정보](./group-details.md)를 참조하세요.

</div>

## 대화 탭 접속하기

1. [그룹 페이지](./browsing-groups.md)에서 그룹을 클릭하여 그룹 세부 정보 페이지로 이동합니다.
2. 로그인되어 있는지 확인합니다.
3. 사이드바에서 **Conversations** 탭을 클릭합니다.

## 토론과 공지사항

Conversations 탭에는 두 개의 하위 탭이 표시될 수 있습니다.

- **Discussions** -- 어떤 그룹 구성원이든 메시지를 게시하고 서로 답글을 달 수 있는 공간입니다. 기본 화면이며 항상 이용할 수 있습니다.
- **Announcements** -- 그룹 리더가 게시하는, 모든 구성원이 확인해야 할 중요한 메시지입니다. 일반 구성원은 공지사항을 읽을 수 있지만 작성은 리더만 가능합니다.

공지사항이 없고 사용자가 리더가 아닌 경우 탭 바 없이 Discussions 화면만 표시됩니다.

## 메시지 게시하기

1. 그룹 페이지에서 **Conversations** 탭을 엽니다.
2. (탭 바가 보이는 경우) **Discussions** 하위 탭에 있는지 확인합니다.
3. 텍스트 필드에 메시지를 입력합니다.
4. 메시지를 제출하여 그룹과 공유합니다.

메시지는 그룹의 모든 구성원에게 표시됩니다.

## 메시지 수정 또는 삭제하기

본인이 게시한 메시지는 언제든 수정하거나 삭제할 수 있습니다.

1. 메시지에 마우스를 올리거나(모바일에서는 탭하여) **더 보기** 버튼(⋮)을 표시합니다.
2. 버튼을 클릭해 메시지 메뉴를 엽니다.
3. 메시지 텍스트를 수정하려면 **Edit**, 삭제하려면 **Delete**를 선택합니다.
   - 수정 시 메시지 텍스트가 입력 필드에 다시 로드됩니다. 내용을 변경한 후 제출하여 저장합니다.
   - 삭제 시 확인 대화상자가 표시됩니다. **Confirm**을 클릭하면 메시지가 영구적으로 삭제됩니다.

:::info
본인이 게시한 메시지만 수정하거나 삭제할 수 있습니다. 다른 구성원이 게시한 메시지에는 수정/삭제 옵션이 표시되지 않습니다.
:::

## 메시지에 반응하기

그룹 채팅에서는 어떤 메시지에도 이모지로 반응할 수 있습니다.

1. 메시지를 탭하거나 마우스를 올린 후 **Add reaction**을 선택합니다.
2. 6가지 이모지 중 하나를 선택합니다: 👍 ❤️ 😂 🎉 🙏 😮.

반응은 메시지 아래에 작은 칩 형태로 표시되며 각 이모지를 사용한 인원수가 함께 나타납니다. 본인의 반응은 강조 표시됩니다 -- 칩을 탭하거나(같은 이모지를 다시 선택) 다른 이모지를 선택하면 반응을 제거하거나 추가할 수 있습니다. 반응은 채팅에 있는 모든 사람에게 실시간으로 표시됩니다.

:::tip
그룹 대화는 [타임라인](../community/timeline.md)에도 표시되므로 각 그룹을 일일이 방문하지 않아도 토론 내용을 확인할 수 있습니다.
:::

## 리더 전용 기능

그룹 리더인 경우 Conversations 탭에서 다음과 같은 추가 기능을 사용할 수 있습니다.

- **공지사항 게시** -- **Announcements** 하위 탭으로 전환하여 모든 그룹 구성원이 읽을 수 있는 메시지를 게시합니다.
- **토론 게시** -- 다른 구성원과 마찬가지로 일반 토론에도 참여할 수 있습니다.

:::info
대화는 각 그룹별로 별도로 관리됩니다. 한 그룹에 게시한 메시지는 다른 그룹의 대화에는 표시되지 않습니다.
:::
