# 그룹 대화

<div class="article-intro">

그룹 채팅은 그룹 구성원이 메시지를 게시하고 서로 소통하는 공간입니다. 대화를 이용해 주제를 논의하고, 소식을 나누고, 모임 사이에도 그룹과 연결된 상태를 유지하세요.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1.church 계정에 [로그인](../getting-started/logging-in.md)되어 있어야 합니다.
- 그룹 채팅에 접근하려면 해당 그룹의 구성원이어야 합니다. 그룹에 가입하는 방법은 [그룹 상세 정보](./group-details.md)를 참고하세요.

</div>

## 대화 접근하기

1. [그룹 목록 페이지](./browsing-groups.md)에서 그룹을 클릭하여 그룹 상세 페이지로 이동합니다.
2. 로그인되어 있는지 확인합니다.
3. 그룹 이름 아래의 **채팅 열기**를 탭하거나, 최신 메시지를 미리 보여 주는 **메시지** 섹션을 탭합니다. 채팅이 전체 화면으로 열리며, 뒤로 가기 화살표를 탭하면 그룹으로 돌아갑니다.

## 토론과 공지사항

그룹 채팅에는 교회에서 이 그룹에 대해 켜 둔 기능에 따라 두 가지 피드가 있을 수 있습니다. 채팅 상단의 그룹 이름 위에 표시되는 라벨을 보면 현재 어떤 피드에 있는지 알 수 있습니다.

- **채팅** -- 모든 그룹 구성원이 메시지를 게시하고 다른 사람의 메시지에 답글을 달 수 있는 토론 공간입니다.
- **공지사항** -- 그룹 리더가 게시하는, 모든 구성원이 반드시 확인해야 하는 메시지입니다. 일반 구성원은 공지사항을 읽고 반응할 수 있지만 게시는 리더만 할 수 있습니다. 일반 구성원에게는 메시지 입력창 대신 "그룹 리더만 공지사항을 게시할 수 있습니다."라는 문구가 표시됩니다.

두 피드가 모두 켜져 있으면 채팅 상단의 **공지** 띠에 가장 최근 공지사항이 표시됩니다. **모든 공지사항**을 탭하면 공지사항 피드가 열리고, **채팅으로 돌아가기**를 탭하면 토론으로 돌아갑니다. (구성원에게는 그룹에 공지사항이 하나 이상 있을 때만 이 띠가 보입니다.)

교회에서 두 피드 중 하나만 켜 두었다면 채팅을 열 때 해당 피드가 바로 열립니다. 두 피드가 모두 꺼져 있다면 그룹에는 채팅도 없고 **메시지** 섹션도 없습니다.

## 메시지 게시하기

1. 그룹 페이지에서 **채팅 열기**를 탭합니다.
2. **채팅** 피드에 있는지 확인합니다. 공지사항을 읽고 있다면 **채팅으로 돌아가기**를 탭하세요.
3. **메시지 보내기…** 입력창에 메시지를 입력합니다.
4. 전송 버튼을 탭하여 그룹에 메시지를 공유합니다. 휴대폰이나 태블릿에서는 엔터 키를 누르면 줄이 바뀝니다. 컴퓨터에서는 **Enter**를 누르면 전송되고, **Shift+Enter**를 누르면 줄이 바뀝니다.

작성한 메시지는 그룹의 모든 구성원에게 보입니다. 각 메시지에는 보낸 시간이 표시되는데, 오늘 보낸 메시지는 시간만, 어제 보낸 메시지는 "어제"와 시간을, 그보다 오래된 메시지는 날짜와 시간을 함께 보여 줍니다.

## 메시지 서식 지정하기 {#formatting-your-message}

메시지에 굵은 글씨, 기울임꼴, 목록을 추가할 수 있습니다.

1. 메시지를 입력한 뒤, 서식을 적용할 단어나 줄을 드래그하여 선택합니다.
2. 메시지 입력창 위에 작은 도구 모음이 나타나며, **굵게**, **기울임꼴**, **글머리 기호 목록**, **번호 매기기 목록** 버튼이 있습니다. 원하는 버튼을 탭하여 서식을 적용합니다. 텍스트가 여전히 선택된 상태에서 같은 버튼을 다시 탭하면 서식이 제거됩니다.
3. 평소와 같이 메시지를 전송합니다.

컴퓨터에서는 **Ctrl+B**(Mac에서는 **Cmd+B**)를 눌러 굵게, **Ctrl+I**(**Cmd+I**)를 눌러 기울임꼴을 적용할 수도 있습니다.

도구 모음은 텍스트에 간단한 마크다운을 추가합니다. 예를 들어 `**굵게**`, `_기울임꼴_`, 줄 맨 앞의 `- `는 글머리 기호 목록, `1. `은 번호 매기기 목록이 됩니다. 이 표기를 직접 입력해도 됩니다. 채팅에 있는 모든 사람이 서식이 적용된 메시지를 보며, 웹 링크는 계속 클릭할 수 있고, 줄바꿈도 유지됩니다. 같은 서식은 공지사항, [리더 메모](./group-details.md#leader-notes), 개인 메시지에서도 사용할 수 있습니다.

## 내 메시지 수정하거나 삭제하기

내가 게시한 메시지는 모두 수정하거나 삭제할 수 있습니다.

1. 메시지 아래의 **더 보기** 버튼(⋮)을 탭하여 메시지 메뉴를 엽니다.
2. 메시지 내용을 바꾸려면 **수정**을, 메시지를 지우려면 **삭제**를 선택합니다.
   - 수정할 때는 메시지 내용이 다시 입력창에 불러와지고, 그 위에 **메시지 수정 중** 안내가 표시됩니다(수정을 멈추려면 **취소**를 탭하세요). 내용을 고친 뒤 전송하면 저장됩니다.
   - 삭제할 때는 **메시지를 삭제할까요?** 확인 창이 나타납니다. **삭제**를 탭하면 대화에 참여한 모든 사람에게서 메시지가 영구적으로 삭제됩니다.

:::info
자신의 메시지만 수정할 수 있습니다. 그룹 리더는 다른 구성원의 메시지도 삭제할 수 있습니다. 일반 구성원에게는 자신의 메시지에 대한 옵션만 보입니다.
:::

## 메시지에 반응하기

그룹 채팅에서는 어떤 메시지에든 이모지로 반응할 수 있습니다.

1. 메시지 아래의 **반응 추가** 버튼을 탭합니다.
2. 여섯 가지 이모지 중 하나를 고릅니다: 👍 ❤️ 😂 🎉 🙏 😮.

반응은 메시지 아래에 작은 칩 형태로 나타나며, 각 이모지를 사용한 사람 수가 함께 표시됩니다. 내가 남긴 반응은 강조 표시됩니다. 칩을 탭하거나(같은 이모지를 다시 선택해도) 반응을 취소할 수 있고, 다른 이모지를 고르면 반응이 추가됩니다. 반응은 채팅에 있는 모든 사람에게 실시간으로 표시됩니다.

:::tip
그룹 대화는 각 그룹의 채팅에서 이루어집니다. 기존의 통합 [타임라인](../community/timeline.md) 피드는 더 이상 운영되지 않습니다. 확인이 필요한 활동은 앱 상단 막대의 **종** 아이콘 아래 알림으로 전달됩니다.
:::

## 리더 기능

그룹 리더라면 그룹 채팅에서 추가 기능을 사용할 수 있습니다.

- **공지사항 게시** -- **모든 공지사항**을 탭하거나(공지사항만 켜져 있다면 채팅을 열고) 모든 그룹 구성원이 읽을 수 있는 메시지를 게시합니다.
- **메시지 삭제** -- 메시지 메뉴(⋮)에서 구성원의 메시지를 삭제합니다.
- **토론 참여** -- 다른 구성원과 마찬가지로 일반 토론에도 참여할 수 있습니다.

:::info
대화는 그룹마다 별도로 운영됩니다. 한 그룹에 게시한 메시지는 다른 그룹의 대화에 나타나지 않습니다.
:::
