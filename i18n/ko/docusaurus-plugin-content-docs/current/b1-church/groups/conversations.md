# 그룹 대화

<div class="article-intro">

그룹 페이지의 메시지 탭은 그룹 구성원이 메시지를 게시하고 서로 상호 작용할 수 있는 공간입니다. 대화를 사용하여 주제를 논의하고, 업데이트를 공유하고, 모임 사이에 그룹과 연결을 유지하세요.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1.church 계정에 [로그인](../getting-started/logging-in.md)해야 합니다.
- 메시지 탭에 접근하려면 그룹의 구성원이어야 합니다. 그룹 가입 방법은 [그룹 세부정보](./group-details.md)를 참조하세요.

</div>

## 대화 접근

1. [그룹 페이지](./browsing-groups.md)에서 그룹을 클릭하여 그룹 세부 페이지로 이동합니다.
2. 로그인해 있는지 확인합니다.
3. 사이드바에서 **메시지** 탭을 클릭합니다.

## 토론 및 공지

메시지 탭은 교회가 이 그룹에 활성화한 피드에 따라 두 개의 하위 탭을 표시할 수 있습니다:

- **토론** -- 모든 그룹 구성원이 메시지를 게시하고 다른 사람에게 회신할 수 있는 공간입니다.
- **공지** -- 그룹 리더가 게시한 메시지로 모든 구성원이 봐야 할 중요한 메시지입니다. 일반 구성원은 공지를 읽고 반응할 수 있지만 리더만 게시할 수 있습니다. 일반 구성원이 게시하려고 하면 리더만 공지를 게시할 수 있으며 직접 메시지로 회신하도록 하는 메모가 표시됩니다.

교회에서 이 그룹에 대해 두 피드 중 하나만 활성화한 경우 탭 바 없이 해당 피드만 표시됩니다. 둘 다 꺼진 경우 그룹에 메시지 탭이 없습니다.

## 메시지 게시

1. 그룹 페이지에서 **메시지** 탭을 엽니다.
2. 탭 바가 표시된 경우 **토론** 하위 탭에 있는지 확인합니다.
3. 텍스트 필드에 메시지를 입력합니다.
4. 메시지를 제출하여 그룹과 공유합니다.

메시지는 그룹의 모든 구성원에게 표시됩니다.

## 메시지 편집 또는 삭제

게시한 메시지를 편집하거나 삭제할 수 있습니다:

1. 메시지 위로 마우스를 가져가거나(또는 모바일에서 탭) **더 많은 옵션** 버튼(⋮)을 표시합니다.
2. 버튼을 클릭하여 메시지 메뉴를 엽니다.
3. **편집**을 선택하여 메시지 텍스트를 수정하거나 **삭제**를 선택하여 제거합니다.
   - 편집할 때 메시지 텍스트가 입력 필드에 로드됩니다. 변경 사항을 만들고 제출하여 저장합니다.
   - 삭제할 때 확인 대화가 나타납니다. **확인**을 클릭하여 메시지를 영구적으로 제거합니다.

:::info
자신이 게시한 메시지만 편집하거나 삭제할 수 있습니다. 다른 구성원이 게시한 메시지는 편집/삭제 옵션을 표시하지 않습니다.
:::

## 메시지에 반응

그룹 채팅에서 이모지로 메시지에 반응할 수 있습니다:

1. 메시지를 탭하거나 마우스를 가져가 **반응 추가**를 선택합니다.
2. 6개의 이모지 중 하나를 선택합니다: 👍 ❤️ 😂 🎉 🙏 😮.

반응은 메시지 아래에 작은 칩으로 표시되며 각각을 사용한 사람 수의 개수가 있습니다. 자신의 반응은 강조 표시되며, 칩을 탭(또는 같은 이모지를 다시 선택)하여 제거하거나 다른 이모지를 선택하여 추가할 수 있습니다. 반응은 채팅의 모든 사람에게 실시간으로 표시됩니다.

:::tip
그룹 대화는 각 그룹의 **메시지** 탭에 있습니다. 예전 통합 [타임라인](../community/timeline.md) 피드는 더 이상 사용되지 않습니다. 주의가 필요한 활동은 앱 바의 **종 모양** 아이콘 아래에 알림으로 전달됩니다.
:::

## 리더 기능

그룹 리더인 경우 메시지 탭에서 다음과 같은 추가 기능이 있습니다:

- **공지 게시** -- **공지** 하위 탭으로 전환하고 모든 그룹 구성원이 읽을 수 있는 메시지를 게시합니다.
- **토론 게시** -- 다른 구성원과 마찬가지로 일반 토론에도 참여할 수 있습니다.

:::info
대화는 각 그룹에 특정됩니다. 한 그룹에 게시한 메시지는 다른 그룹의 대화에 나타나지 않습니다.
:::
