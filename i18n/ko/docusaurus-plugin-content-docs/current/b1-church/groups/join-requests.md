# 그룹에 참여 요청

<div class="article-intro">

일부 그룹은 회원이 되기 전에 승인이 필요합니다. 그룹에 이 설정이 있으면 참여 요청을 제출합니다(선택적으로 그룹 리더에게 메시지 포함). 리더가 승인 또는 거부할 때까지 기다립니다. 언제든지 보류 중인 요청의 상태를 보고 취소할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [로그인](../getting-started/logging-in.md)하여 B1.church 계정에 접속해야 합니다.

</div>

## 참여 대 참여 요청

그룹은 관리자가 설정한 다양한 참여 정책을 가질 수 있습니다.

- **개방** -- 그룹의 상세 페이지에서 **그룹에 참여**를 클릭하면 즉시 회원으로 추가됩니다.
- **요청 필수** -- **참여 요청**을 클릭하여 그룹 리더가 승인해야 하는 요청을 제출합니다.
- **폐쇄** -- 참여 버튼이 나타나지 않습니다. 회원은 리더가 수동으로 추가해야 합니다.

## 참여 요청을 제출하는 방법

1. 참여하려는 그룹을 찾아봅니다. 찾는 데 도움이 필요하면 [그룹 찾아보기](./browsing-groups.md)를 참조하세요.
2. 그룹의 상세 페이지를 엽니다.
3. **참여 요청**을 클릭합니다.
4. 참여하고 싶은 이유를 그룹 리더에게 설명하는 선택적 메시지를 작성할 수 있는 대화 상자가 나타납니다.
5. **제출**을 클릭하여 요청을 보냅니다.

그룹 페이지는 이제 버튼 대신 **요청 대기 중** 알림을 보여줍니다. 그룹의 리더들은 요청에 대한 알림을 받을 것입니다. 검토 후 결과에 대한 알림을 받을 것입니다.

:::tip
간단한 메시지(그룹에 대해 어떻게 알았는지 또는 얻고 싶은 것 등)를 포함하면 리더가 더 빨리 결정하는 데 도움이 됩니다.
:::

## 요청 상태 확인

요청을 제출한 후 **그룹** 페이지에서 상태를 볼 수 있습니다.

1. 교회의 B1.church 사이트에서 **그룹** 페이지로 이동합니다.
2. **보류 중인 요청** 섹션까지 아래로 스크롤합니다.
3. 각 보류 중인 요청은 그룹 이름과 제출한 날짜를 보여줍니다.

요청이 승인 또는 거부되면 알림을 받을 것입니다. 승인된 요청은 그룹의 회원으로 이동합니다.

## 요청 취소

리더가 요청을 검토하기 전에 마음이 바뀐 경우:

1. **그룹** 페이지로 이동합니다.
2. **보류 중인 요청** 섹션에서 요청을 찾습니다.
3. 요청 옆의 **취소**를 클릭합니다.

요청이 즉시 철회되고 리더는 더 이상 이를 보지 않을 것입니다.
