# 이벤트 RSVP

<div class="article-intro">

그룹 이벤트에서는 RSVP를 받아 리더가 누가 참석하는지 알 수 있습니다. 그룹 캘린더에서 예정된 각 이벤트에 "참석하시겠습니까?"라는 질문이 표시됩니다. 한 번의 탭으로 답하고, 언제든 마음을 바꿀 수 있으며, 다른 몇 명이 참석하는지 한눈에 확인할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [로그인](../getting-started/logging-in.md)되어 있어야 하며 해당 그룹의 회원이어야 합니다
- 이벤트에서 RSVP가 허용되어 있어야 합니다(기본적으로 켜져 있으며, 리더가 이벤트별로 끌 수 있습니다)

</div>

## 이벤트에 응답하기

1. 회원 포털에서 그룹을 열고 **이벤트** 탭으로 이동합니다. **월별 보기**에서는 날짜를 탭하여 해당 날의 이벤트를 보거나, **목록 보기**로 전환하여 이번 달의 예정된 모든 이벤트를 한꺼번에 볼 수 있습니다.
2. 예정된 각 이벤트 카드에는 **참석하시겠습니까?**와 함께 세 개의 버튼, 즉 **참석**, **미정**, **불참**이 표시됩니다.
3. 답변을 탭합니다. 선택한 항목이 강조 표시되고, 각 버튼에는 해당 응답을 한 사람 수가 실시간으로 표시됩니다.
4. 강조 표시된 답변을 다시 탭하면 선택이 해제되고, 다른 버튼을 탭하면 응답이 변경됩니다.

RSVP는 해당 특정 일정에만 적용됩니다. 매주 열리는 모임의 경우 매주 이벤트마다 따로 응답합니다.

## 그룹 리더를 위한 안내

- **응답 보기** -- 리더에게는 각 이벤트 카드에 **응답 보기** 버튼이 표시됩니다. 이 버튼을 누르면 참석, 미정, 불참 등 답변별로 모든 사람을 나열한 **응답** 시트가 열립니다. 아직 아무도 응답하지 않았다면 "아직 응답이 없습니다."라고 표시됩니다.
- **RSVP 켜기/끄기** -- 이벤트를 만들거나 편집할 때 **RSVP 허용** 스위치를 사용합니다. RSVP가 꺼진 이벤트에는 응답 버튼이 표시되지 않습니다. B1 Admin에서 이벤트를 일괄 생성하는 직원도 동일한 옵션을 사용할 수 있습니다. [그룹 캘린더](../../b1-admin/groups/group-calendar#event-rsvps)를 참조하세요.

:::tip
RSVP는 간단한 인원 파악용입니다. 이벤트에 신청 정보, 정원 관리 또는 결제가 필요하다면 [이벤트 등록](../events/registering)을 대신 사용하세요.
:::
