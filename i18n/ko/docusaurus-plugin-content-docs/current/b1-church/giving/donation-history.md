# 헌금 내역

<div class="article-intro">

로그인하면 과거 헌금의 전체 기록을 보고 세금 목적으로 헌금 명세서를 생성할 수 있습니다. 헌금 내역은 B1.church 계정의 **기부** 섹션에서 사용할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1.church 계정에 [로그인](../getting-started/logging-in.md)해야 합니다.
- 최소 1건 이상의 헌금을 한 적이 있어야 합니다. 시작하려면 [헌금하기](./making-donations.md)를 참고하세요.

</div>

## 내역 보기

1. B1.church 계정에 로그인합니다.
2. **기부** 섹션으로 이동합니다.
3. **내역** 탭을 클릭하여 과거 헌금을 봅니다.

상단에는 선택 가능한 기간 -- **올해**, **지난 30일**, **지난 90일**, 또는 **전체** -- 의 합계를 보여주는 **헌금** 카드가 있습니다. 드롭다운에서 선택합니다. 해당 기간의 헌금이 1개 이상의 통화로 지정되었으면 합계는 교회 통화로 변환되고 아래에 **현재 환율로 변환됨** 메모가 나타납니다.

합계 아래에 최근 활동이 다음과 함께 나열됩니다:

- **날짜** -- 헌금이 이루어진 때입니다.
- **방법** -- 결제한 방식입니다(예: "카드 - Visa" 또는 "은행 - ACH").
- **기금** -- 헌금이 지정된 기금입니다(예: 일반 기금, 건축 기금).
- **금액** -- 헌금 금액입니다(지정된 통화 단위).

:::info
아직 처리 중인 헌금은 기금 이름 옆에 "대기 중" 라벨과 함께 나타나며 금액은 다른 색으로 표시됩니다.
:::

## 명세서 내보내기 및 인쇄

최근 활동 목록 위의 **명세서 인쇄**를 클릭하여 새 탭에서 현재 달력 연도를 다루는 인쇄 가능한 헌금 명세서를 엽니다.

:::tip
새해가 시작될 때 조기에 명세서를 인쇄하세요. 세금 신고가 필요하기 전에, 작년 헌금이 아직 당신의 내역에 신선할 때입니다.
:::

## 정기 헌금

정기 헌금이 있으면 내역 탭의 **정기** 섹션에 각 항목을 금액, 간격, 결제 방법과 함께 나열합니다.

정기 헌금이 **Stripe**를 통해 청구되면, 취소하는 대신 **일시 중지**할 수 있습니다 -- 헌금 옆의 일시 중지 아이콘을 클릭하고 확인합니다. 같은 아이콘을 클릭하여 **재개**할 때까지 헌금이 중단됩니다; 일시 중지된 헌금은 목록에 **일시 중지됨**으로 표시됩니다. 다른 결제 제공자를 통한 정기 헌금은 여전히 편집하거나 취소할 수 있지만 일시 중지할 수는 없습니다.

저장된 결제 방법을 추가, 제거, 또는 변경하려면 **관리** 탭을 사용합니다.
