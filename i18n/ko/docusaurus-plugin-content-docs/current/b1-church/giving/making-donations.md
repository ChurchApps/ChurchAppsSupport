# 헌금하기

<div class="article-intro">

교회의 B1.church 사이트를 통해 헌금하는 방법은 두 가지입니다. 로그인이 필요 없는 공개 헌금 페이지와, 로그인이 필요한 교인 헌금 페이지입니다. 두 방법 모두 교회의 결제 제공업체(대부분의 교회는 Stripe를 사용합니다)가 제공하는 안전한 헌금 양식을 사용합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 공개 헌금에는 계정이 필요하지 않습니다. 교회의 **헌금** 페이지를 방문하기만 하면 됩니다.
- 헌금 내역 추적과 저장된 결제 방법을 사용하는 교인 헌금은 먼저 [로그인](../getting-started/logging-in.md)하세요.

</div>

## 공개 헌금 페이지(로그인 불필요) {#public-donation-page-no-login-required}

계정을 만들지 않아도 누구나 헌금할 수 있습니다.

1. 교회의 **헌금** 페이지로 이동합니다.
2. 헌금 양식이 페이지 왼쪽에 표시됩니다. 일회성 헌금은 **헌금하기**를, 일정에 따라 헌금하려면 **정기 헌금하기**(주기와 시작일을 선택)를 고릅니다.
3. **이름**, **성**, **이메일**을 입력한 다음 카드 정보를 입력합니다.
4. **기금** 아래에서 **금액**을 입력하고 **기금**을 고릅니다. 헌금을 여러 기금으로 나누려면 **더 추가**를 클릭하세요.
5. 필요하면 **메모**를 추가합니다. 교회가 허용한다면 거래 수수료를 부담하겠다는 확인란을 체크할 수 있습니다.
6. **헌금**을 클릭하여 헌금을 완료합니다.

헌금에 이름을 남기고 싶지 않다면 **익명으로 헌금하기(일회성 헌금에만 해당**)를 체크하세요. 이름 입력란과 정기 헌금 옵션은 사라집니다.

페이지 오른쪽의 **헌금 관리** 아래에는 은행 이체로 헌금하고 싶다면 **ACH 결제 안내**로 가는 링크가 있습니다. 헌금 내역 같은 추가 기능을 이용하려면 **로그인** 버튼(또는 양식 아래의 **로그인하여 기존 헌금 관리하기** 링크)을 사용하세요.

로그아웃 상태에서 교인 포털의 **헌금** 화면(`/mobile/donate`)에도 같은 양식이 표시되며, 그 아래에 **로그인하여 정기 헌금을 관리하고 내역 보기** 링크가 있습니다.

:::tip
이미 로그인한 상태에서 공개 헌금 페이지를 방문하면, 전체 헌금 내역과 저장된 결제 방법을 이용할 수 있는 교인 헌금 페이지로 자동 이동합니다.
:::

## 교인 헌금 페이지(로그인 상태) {#member-donation-page-logged-in}

로그인하면 교인 포털의 **헌금** 페이지 상단에 **헌금하기** 버튼과 **명세서 인쇄** 버튼이 나타나고, 그 아래에 다음 섹션이 이어집니다.

- **올해**(현재 연도가 제목으로 표시됨) -- 올해 헌금 총액과 헌금 건수, 그리고 **전체 내역** 링크가 있습니다. 자세한 내용은 [헌금 내역](./donation-history.md)을 참고하세요.
- **정기 헌금** -- 예약된 헌금이며, **관리** 링크가 있습니다.
- **최근 활동** -- 최근 헌금 3건이며, 헌금 양식을 여는 **지난번 헌금 반복** 링크가 있습니다.
- **결제 방법** -- 저장된 카드와 은행 계좌이며, 카드나 은행 계좌를 추가하고 저장된 항목을 수정하거나 삭제하는 **관리** 링크가 있습니다.
- 교회에 진행 중인 캠페인이 있다면 캠페인 진행 카드가 나타납니다.

헌금하려면 다음과 같이 합니다.

1. 교회의 **헌금** 탭, [홈 대시보드](../getting-started/navigating.md#home)의 **헌금** 섹션에 있는 **헌금하기** 버튼, 또는 [내 정보 페이지](../getting-started/me-page.md)의 **헌금** 섹션에 있는 **내역**에서 헌금 페이지를 엽니다. 헌금 페이지에서 **헌금하기**를 탭하면 헌금 양식이 열립니다.
2. **헌금하기** 또는 **정기 헌금하기**를 고릅니다.
3. 저장된 결제 방법을 선택하거나 새 카드 정보를 입력합니다. 새 카드를 입력할 때 **이 카드를 다음 헌금에 저장**을 체크하면 다음에도 사용할 수 있습니다(교회의 제공업체가 저장된 카드를 지원하는 경우).
4. 헌금할 **기금**을 고르고 **금액**을 입력합니다. 여러 기금에 헌금하려면 **더 추가**를 클릭하세요. 목록에는 교회가 헌금자에게 제공하는 기금만 표시됩니다. B1 Admin에서 다른 기금을 볼 수 있는 직원이라도 마찬가지입니다.
5. **헌금 미리 보기**를 클릭하여 헌금 내용을 확인한 다음 **헌금**을 클릭하여 완료합니다. **취소**를 누르면 헌금 페이지로 돌아갑니다.

헌금 처리가 끝나면 성공 메시지가 나타나고, 헌금은 [헌금 내역](./donation-history.md)에 표시됩니다.

:::info
헌금이 둘 이상의 통화로 기록되었다면, 올해 총액과 내역 총액은 교회의 통화로 환산되며 그 아래에 **현재 환율로 환산됨** 안내가 표시됩니다. 내역의 개별 헌금은 여전히 원래 통화로 표시됩니다.
:::

## 결제 방법 {#payment-methods}

헌금은 교회가 연결한 결제 제공업체를 통해 안전하게 처리됩니다. 사용할 수 있는 결제 수단은 제공업체에 따라 다릅니다.

- **Stripe** -- 신용카드 또는 체크카드, 또는 은행 계좌(ACH).
- **Kingdom Funding** -- 신용카드 또는 체크카드, 또는 은행 계좌(ACH).
- **Paystack**(아프리카의 교회) -- 현지 카드와 모바일 머니를 현지 통화로 이용합니다.
- **PayPal 및 Venmo** -- 이미 PayPal을 설정해 둔 교회는 일회성 헌금에 대해 카드 입력란 위에 **PayPal**과 **Venmo** 버튼이 표시됩니다. 정기 헌금은 카드 입력란을 사용합니다.

로그인하면 결제 방법을 다음에 쓸 수 있도록 저장할 수 있으므로, 다음 헌금이 더 빨라집니다.

:::info 로그인 없이 은행 계좌로 헌금하기
손님(로그인하지 않은 상태)으로 은행 계좌를 통해 헌금하는 경우, 은행에 로그인하여 계좌를 즉시 인증해야 합니다. 인증할 수 없다면 "이 은행 계좌를 즉시 인증할 수 없습니다. 카드로 헌금하시거나, 로그인하여 교인 헌금 프로필에서 은행 계좌를 추가하세요."가 표시됩니다. 인증에 며칠이 걸리는 은행 계좌는 로그인한 후에만 추가할 수 있습니다.
:::

:::warning
헌금이 처리되지 않으면 결제 정보를 다시 확인하고 시도해 보세요. 문제가 계속되면 도움을 받으려고 교회 사무실에 문의하세요.
:::
