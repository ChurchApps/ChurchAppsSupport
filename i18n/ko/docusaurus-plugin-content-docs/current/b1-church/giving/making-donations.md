# 헌금하기

<div class="article-intro">

교회의 B1.church 사이트를 통해 두 가지 방법으로 헌금할 수 있습니다: 공개 헌금 페이지(로그인 불필요)와 멤버 헌금 페이지(로그인 필요). 둘 다 Stripe에서 제공하는 안전한 헌금 양식을 사용합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 공개 헌금의 경우 계정이 필요하지 않습니다 -- 교회의 **기부** 페이지를 방문하기만 하면 됩니다.
- 내역 추적 및 저장된 결제 수단이 포함된 멤버 헌금의 경우, 먼저 계정에 [로그인](../getting-started/logging-in.md)하세요.

</div>

## 공개 헌금 페이지(로그인 불필요)

계정을 만들지 않고도 누구나 헌금할 수 있습니다:

1. 교회의 **기부** 페이지로 이동합니다.
2. 헌금 양식이 페이지 왼쪽에 표시됩니다. 헌금할 **기금**을 선택합니다.
3. 결제 정보와 헌금 금액을 입력합니다.
4. 양식을 제출하여 헌금을 완료합니다.

페이지 오른쪽에는 은행 이체로 기부하기를 선호하는 경우 **ACH 결제 지침**로 연결되는 링크가 있습니다. 또한 헌금 내역과 같은 추가 기능에 접근하기 위해 로그인하려는 경우 **로그인** 버튼도 있습니다.

:::tip
공개 헌금 페이지를 방문할 때 이미 로그인되어 있으면, 전체 헌금 내역과 저장된 결제 수단에 접근할 수 있는 멤버 헌금 페이지로 자동 리디렉션됩니다.
:::

## 멤버 헌금 페이지(로그인 필요)

로그인하면 헌금 경험에 추가 기능이 포함되며, 4개의 탭으로 구성됩니다:

- **개요** -- 올해 헌금 합계, 캠페인 진행 카드(교회에 활성 캠페인이 있는 경우), 그리고 원클릭 **반복** 버튼이 있는 가장 최근 기부.
- **기부** -- 헌금 양식입니다.
- **관리** -- 저장된 결제 수단(카드 또는 은행 계좌 추가, 제거, 또는 기본값 설정).
- **내역** -- 과거 헌금, 기간별 헌금 합계, 정기 기부, 명세서 내보내기. 자세한 내용은 [헌금 내역](./donation-history.md)을 참고하세요.

헌금하려면:

1. 교회의 **기부** 탭 또는 [내 페이지](../getting-started/me-page.md)의 바로 가기의 **헌금**에서 헌금 페이지를 엽니다. **개요**에 있으면 **기부** 탭을 선택합니다.
2. 헌금할 **기금**을 선택하고 헌금 금액을 입력합니다.
3. 기존에 저장된 결제 수단을 선택하거나 새로운 결제 정보를 입력합니다.
4. 양식을 제출하여 헌금을 완료합니다.

헌금이 처리되면 성공 메시지가 표시되고 헌금이 [헌금 내역](./donation-history.md)에 나타납니다.

:::info
당신이 한 헌금이 1개 이상의 통화로 기록되었으면, 개요 올해 합계 및 내역 기간 합계는 교회 통화로 변환되며, 아래에 **현재 환율로 변환됨** 메모가 있습니다. 내역의 개별 헌금은 여전히 원래 통화를 표시합니다.
:::

## 결제 방법

헌금은 **Stripe**를 통해 안전하게 처리됩니다. 신용카드, 직불카드로 결제하거나 ACH 은행 결제를 설정할 수 있습니다. 로그인하면 결제 수단을 저장하여 다음에 헌금할 때 더 빠르게 이용할 수 있습니다.

:::warning
헌금이 처리되지 않으면 결제 정보를 다시 확인하고 다시 시도하세요. 문제가 지속되면 교회 사무실에 연락하여 도움을 받으세요.
:::
