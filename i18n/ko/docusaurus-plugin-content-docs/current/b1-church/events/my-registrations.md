# 내 등록

<div class="article-intro">

회원 포털의 **등록** 페이지는 등록한 모든 이벤트의 본거지입니다. 여기에서 상태를 확인하고, 미결제 잔액을 결제하고, 참석자와 주문 내용을 수정하고, 등록을 완전히 취소할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [로그인](../getting-started/logging-in.md)되어 있어야 합니다 — 손님 등록은 여기에 표시되지 않습니다
- 최소 하나의 이벤트 등록이 필요합니다. [이벤트 등록하기](./registering)를 참조하세요.

</div>

## 등록 확인하기

회원 포털에서 **등록**을 여세요. 각 등록은 다음 정보를 표시하는 카드로 나타납니다:

- **이벤트 제목 및 날짜**
- **상태** 알약형 표시 — **확정됨**, **보류 중**, **대기자 명단**, 또는 **취소됨**
- 등록한 **회원**
- 결제 내역 — 결제된 총액 또는 아직 결제할 금액이 있는 경우 **미결제 잔액**

아직 아무것도 등록하지 않았다면 "아직 등록이 없습니다."가 표시됩니다.

## 결제 완료하기

미결제 잔액이 있는 등록에는 **결제 완료** 버튼이 표시됩니다 — 대기자 명단에서 승격되었거나, 직원이 수정하여 총액이 변경된 경우 가장 흔히 나타납니다.

1. **결제 완료**를 클릭하세요.
2. 주문 요약을 확인하고, 저장된 카드를 선택하거나 새 카드를 입력하여 결제하세요.
3. 잔액이 결제되면 등록이 **확정됨** 상태가 됩니다.

:::tip
대기자 명단 자리가 열리면 교회에서 보내는 이메일에 이 결제 단계로 바로 이동하는 링크가 포함됩니다.
:::

## 등록 수정하기

계획은 바뀌기 마련입니다. 등록에서 **수정**을 클릭하면 **등록 수정** 대화 상자가 열리며, 다음을 할 수 있습니다:

- **연락처 정보** 업데이트
- 각 회원의 **이름**과 **참석자 유형** 변경
- **선택 항목 수량** 조정(티셔츠나 식사 같은 추가 옵션)

수정할 때도 정원이 적용됩니다 — 참석자 유형이나 옵션이 그사이 마감되었다면 다른 것을 선택하라는 안내가 표시됩니다. 저장하면 총액이 다시 계산됩니다. 변경으로 인해 잔액이 남으면 카드에 **결제 완료** 버튼이 표시됩니다.

:::info
수정은 카드에 자동으로 청구되지 않습니다. 새 총액이 더 높으면 **결제 완료**로 차액을 결제하고, 더 낮으면 교회에 문의하여 환불을 요청하세요 — 환불은 교회 직원이 결제 제공업체를 통해 처리합니다.
:::

## 등록 취소하기

1. 카드에서 **등록 취소**를 클릭하세요.
2. 대화 상자에서 확인하세요 — 취소는 되돌릴 수 없습니다.

자리는 즉시 반납됩니다. 이벤트에 대기자 명단이 있다면 다음 순서인 사람이 자동으로 승격됩니다. 이미 결제한 금액은 자동으로 환불되지 않습니다 — 환불에 대해서는 교회 사무실에 문의하세요.
