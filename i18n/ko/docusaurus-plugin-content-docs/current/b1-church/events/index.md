# 이벤트

<div class="article-intro">

B1.church의 이벤트 섹션을 사용하면 다가오는 교회 이벤트를 둘러보고 웹사이트에서 바로 등록할 수 있습니다. 교회가 이벤트에 대한 등록을 활성화하면 몇 단계만으로 본인과 가족 구성원을 등록할 수 있으며, 유료 이벤트의 경우 참가자 유형과 옵션을 선택하고, 할인 코드를 적용하고, 등록 과정에서 안전하게 결제할 수 있습니다.

</div>

## 이벤트 둘러보기

이벤트는 교회 웹사이트에 월간 달력 형태로 또는 다가오는 이벤트의 타일 형태로 표시됩니다. 이벤트를 클릭하면 다음 내용이 표시된 전용 페이지가 열립니다.

- **이벤트 사진** -- 교회가 사진을 추가한 경우.
- **이벤트 제목과 설명** -- 이벤트에 대한 내용.
- **일시** -- 다음 일정의 날짜와 시간, 또는 반복 이벤트의 반복 패턴.
- **장소** -- 이벤트를 위해 예약된 방이 있는 경우.
- **이 이벤트에 등록하기** -- 등록 양식으로 이동하는 버튼. 이벤트에 대해 등록이 켜져 있을 때만 표시됩니다.
- **내 캘린더에 추가** -- Google 캘린더, Apple 캘린더, Outlook 또는 다른 캘린더 앱에서 열 수 있는 캘린더 파일로 이벤트를 다운로드합니다.

페이지 상단의 **모든 이벤트**를 탭하면 돌아갑니다. 다가오는 이벤트 타일 위의 **구독** 버튼을 사용하면 전체 캘린더의 ICS 링크를 복사하거나 다운로드할 수 있어, 새 이벤트가 본인의 캘린더 앱에 표시됩니다.

## 등록 상태

이벤트는 시기와 정원에 따라 다른 상태로 표시될 수 있습니다.

- **등록 가능** -- 등록할 수 있습니다.
- **아직 열리지 않음** -- 등록 기간이 시작되지 않았습니다. 시작일 이후에 다시 확인하세요.
- **마감** -- 등록 마감일이 지났습니다.
- **정원 마감** -- 모든 자리가 찼습니다.

:::tip
이벤트가 정원 마감이더라도 교회가 **대기자 명단**을 활성화했다면 참가할 수 있습니다. 자리가 나면 자동으로 이메일을 받게 됩니다. 그렇지 않다면 나중에 다시 확인하세요. 누군가 취소하면 자리가 날 수 있습니다.
:::

## 준비 사항

- B1.church 계정(또는 게스트로 등록 가능)
- 교회의 B1.church 웹사이트에 접속할 수 있을 것
