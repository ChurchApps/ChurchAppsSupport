# 이벤트

<div class="article-intro">

B1.church의 이벤트 섹션을 사용하면 다가오는 교회 이벤트를 둘러보고 웹사이트에서 직접 등록할 수 있습니다. 교회가 이벤트에 대한 등록 기능을 활성화하면 몇 단계만으로 본인과 가족 구성원을 등록할 수 있으며, 유료 이벤트의 경우 참가자 유형과 옵션을 선택하고 할인 코드를 적용하며 등록 과정에서 바로 안전하게 결제할 수 있습니다.

</div>

## 이벤트 둘러보기

이벤트는 교회 캘린더에 표시됩니다. 등록이 활성화된 이벤트를 열면 이벤트 세부 정보와 함께 **이 이벤트 등록하기** 버튼이 표시됩니다.

등록이 활성화된 이벤트에는 다음이 표시됩니다.

- **이벤트 제목 및 설명** -- 이벤트에 대한 내용입니다.
- **날짜 및 시간** -- 이벤트가 열리는 시점입니다.
- **등록 버튼** -- 등록 양식으로 이동하는 파란색 버튼입니다.

## 등록 상태

이벤트는 타이밍과 정원에 따라 다양한 상태를 표시할 수 있습니다.

- **오픈됨** -- 등록이 가능하며 신청할 수 있습니다.
- **아직 오픈되지 않음** -- 등록 기간이 아직 시작되지 않았습니다. 오픈 날짜 이후에 다시 확인하세요.
- **마감됨** -- 등록 마감일이 지났습니다.
- **정원 마감** -- 사용 가능한 모든 자리가 찼습니다.

:::tip
이벤트가 정원 마감 상태라도 교회가 **대기 명단**을 활성화한 경우 여전히 대기 명단에 등록할 수 있습니다 -- 자리가 나면 자동으로 이메일을 받게 됩니다. 그렇지 않다면 나중에 다시 확인해 보세요. 누군가 취소하면 자리가 생길 수 있습니다.
:::

## 필요한 것

- B1.church 계정 (또는 게스트로 등록 가능)
- 소속 교회의 B1.church 웹사이트 접속 권한
