# 행사

<div class="article-intro">

B1.church의 행사 섹션에서는 다가오는 교회 행사를 둘러보고 웹사이트에서 바로 등록할 수 있습니다. 교회가 행사의 등록을 켜 두었다면, 몇 단계만으로 본인과 가족을 등록할 수 있습니다. 유료 행사의 경우 참가자 유형과 옵션을 고르고, 할인 코드를 적용하고, 등록하면서 안전하게 결제할 수 있습니다.

</div>

## 행사 둘러보기 {#browsing-events}

행사는 교회 웹사이트의 월간 달력이나 다가오는 행사의 타일 형태로 표시됩니다. 행사를 클릭하면 행사 전용 페이지가 열리며, 다음 내용이 표시됩니다.

- **행사 사진** -- 교회가 사진을 추가했다면 표시됩니다.
- **행사 제목과 설명** -- 행사의 내용입니다.
- **일시** -- 다음 행사의 날짜와 시간, 또는 반복 행사의 반복 패턴입니다.
- **장소** -- 행사를 위해 예약된 공간이 있다면 표시됩니다.
- **이 행사에 등록하기** -- 등록 양식으로 이동하는 버튼입니다. 행사에 등록이 켜져 있을 때만 표시됩니다.
- **내 캘린더에 추가** -- Google 캘린더, Apple 캘린더, Outlook 또는 다른 캘린더 앱에서 열 수 있는 캘린더 파일로 행사를 내려받습니다.

페이지 상단의 **모든 행사**를 탭하면 이전 페이지로 돌아갑니다. 다가오는 행사 타일 위에 있는 **구독** 버튼을 사용하면 캘린더 전체의 ICS 링크를 복사하거나 내려받을 수 있어서, 새 행사가 내 캘린더 앱에도 표시됩니다.

## 등록 상태 {#registration-status}

행사의 등록 페이지를 열면, 시기와 정원에 따라 다음 중 하나가 표시됩니다.

- **등록 가능** -- 등록 양식이 나타나며, 행사에 정원이 있는 경우 얼마나 찼는지 보여 주는 막대(예: "4 / 50 자리 찼음")가 함께 표시됩니다.
- **등록 아직 열리지 않음** -- 등록 기간이 아직 시작되지 않았습니다. 페이지에는 "2026년 11월 16일에 등록이 시작됩니다."처럼 시작 날짜가 표시됩니다. 그때 다시 확인하세요.
- **마감** -- 페이지에 "등록 아직 열리지 않음"과 "이 행사의 등록이 마감되었습니다."가 표시됩니다. 등록 마감일이 지난 상태입니다.
- **정원 마감** -- 신청 가능한 자리가 모두 찼습니다. "이 행사의 정원인 50명에 도달했습니다."가 표시됩니다.

:::tip
행사가 정원 마감되었더라도, 교회가 **대기자 명단**을 켜 두었다면 대기 신청을 할 수 있습니다. 자리가 나면 자동으로 이메일을 받게 됩니다. 대기자 명단이 없다면 나중에 다시 확인하세요. 누군가 취소하면 자리가 날 수 있습니다.
:::
