# 이벤트 등록하기

<div class="article-intro">

교회가 이벤트에 대한 등록 기능을 활성화하면 간단한 단계별 절차를 통해 등록할 수 있습니다. 계정이 있든 게스트로 방문하든 본인과 가족 구성원을 등록할 수 있습니다. 유료 이벤트의 경우 참가자 유형을 선택하고, 선택 사항을 추가하고, 할인 코드를 적용한 후 마지막에 안전하게 결제합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 교회에서 해당 이벤트에 대한 등록 기능을 활성화해야 합니다
- 등록 기간이 열려 있어야 합니다(관리자가 설정한 오픈 날짜와 마감 날짜 사이)

</div>

## 1단계: 정보 입력

1. 교회 캘린더에서 등록하려는 이벤트를 열고 **이 이벤트 등록하기**를 클릭합니다.
2. 등록 페이지가 로드되며 이벤트 제목, 설명, 날짜가 표시됩니다.
3. **로그인한** 경우 양식에 본인의 이름이 표시되며 본인 계정으로 등록됨을 확인합니다.
4. **게스트**(로그인하지 않음)인 경우 다음을 입력합니다.
   - **이름**(필수)
   - **성**(필수)
   - **이메일**(필수)
   - **전화번호**(선택)
5. 이벤트에 참가자 유형이 있는 경우(예: 성인과 어린이가 다른 가격) **등록 유형**을 선택합니다. 각 유형마다 가격이 표시되며, 마감된 유형은 **매진**으로 표시됩니다.

:::info
이벤트에 정원 제한이 있는 경우 진행률 표시줄에 남은 자리 수가 표시됩니다. 이벤트가 정원 마감이고 교회가 대기 명단을 활성화한 경우에도 신청을 완료하여 대기 명단에 등록할 수 있습니다 -- 아래 [대기 명단 등록하기](#대기-명단-등록하기)를 참조하세요.
:::

## 2단계: 가족 구성원 추가

1. 추가로 가족 구성원을 등록하려면 각 사람의 **이름**과 **성**을 입력합니다.
2. 이벤트에 참가자 유형이 있는 경우 추가하는 각 사람마다 유형을 선택합니다.
3. **구성원 추가**를 클릭하여 더 많은 사람을 추가합니다(총 최대 10명).
4. 구성원 옆의 제거 버튼을 클릭하면 해당 사람을 등록에서 제외합니다.
5. 본인만 등록하는 경우 이 단계를 건너뛸 수 있습니다.

## 3단계: 옵션 및 선택 사항 고르기(제공되는 경우)

일부 이벤트는 티셔츠, 식사, 활동 업그레이드 등 유료 추가 옵션을 제공합니다.

1. 이벤트에 선택 항목이 있는 경우 **옵션 및 선택 사항** 단계가 표시됩니다.
2. 수량 조절 버튼을 사용해 원하는 개수를 선택합니다. 무료 옵션은 **무료**로 표시되며, 수량이 제한된 옵션은 남은 수량이 표시됩니다.
3. **계속**을 클릭합니다.

## 4단계: 질문에 답하기(요청된 경우)

일부 이벤트는 등록자에게 식이 제한, 티셔츠 사이즈, 비상 연락처 등 추가 질문에 답하도록 요청합니다.

1. 이벤트에 질문이 첨부된 경우 다음으로 **질문** 단계가 표시됩니다.
2. 답변을 입력하고 계속합니다.

이벤트에 첨부된 질문이 없으면 이 단계는 자동으로 건너뜁니다.

## 5단계: 결제하기(유료 이벤트)

등록에 비용이 있는 경우 **결제** 단계에서 각 참가자, 각 선택 항목, 할인 내역, **총액**을 나열하는 **주문 요약**이 표시됩니다.

- **할인 코드** -- 교회에서 코드를 제공한 경우 입력하고 **적용**을 클릭합니다. 할인이 즉시 반영되며, 코드가 만료되었거나 아직 시작되지 않았거나 더 많은 참가자가 필요한 경우 명확한 메시지가 표시됩니다.
- **로그인한 회원**은 저장된 카드로 결제하거나 **새 카드 사용**을 선택할 수 있습니다.
- **게스트**는 카드 정보를 직접 입력합니다.

**결제 및 등록**을 클릭하면 결제와 등록이 한 단계로 완료됩니다. 카드 정보는 교회의 결제 제공업체로 직접 전송되며 B1은 이를 저장하지 않습니다.

무료 등록은 이 단계를 건너뛰고 바로 확인 화면으로 이동합니다.

## 6단계: 확인

이벤트 세부 정보와 등록한 모든 사람의 목록이 담긴 확인 메시지가 표시됩니다. 또한 계정에 연결된 이메일 주소(또는 게스트로 입력한 이메일)로 **확인 이메일**을 받게 됩니다.

## 대기 명단 등록하기

이벤트가 정원 마감이고 교회가 대기 명단을 활성화한 경우, 첫 단계에서 다음과 같이 표시됩니다. *"이 이벤트는 정원이 마감되었습니다. 대기 명단에 등록하시면 자리가 나는 대로 알려드리겠습니다."* 평소처럼 신청을 완료하면 됩니다 -- 대기 명단에 있는 동안에는 결제 단계가 건너뜁니다. 자리가 나면 이메일을 받게 되며, 결제가 필요한 경우 결제를 완료할 수 있는 링크가 포함됩니다. [내 등록 내역](./my-registrations)에서도 상태를 확인하고 결제할 수 있습니다.

## 등록 변경 또는 취소하기

로그인한 경우 회원 포털의 **등록 내역** 페이지에서 직접 등록을 수정하거나 취소할 수 있습니다 -- [내 등록 내역](./my-registrations)을 참조하세요. 게스트는 교회 사무실에 문의해야 하며, 직원은 B1 Admin의 등록 페이지에서 변경할 수 있습니다.
