# 성경

<div class="article-intro">

B1.church에는 기본으로 내장된 성경 리더가 있어서 사이트를 떠나지 않고도 말씀을 읽을 수 있습니다. 리더가 페이지에 직접 포함되어 있어, 다른 교회 도구와 함께 어떤 본문이든 빠르게 찾아볼 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 성경 리더를 사용하는 데 로그인은 필요하지 않습니다. 성경 페이지는 누구나 볼 수 있습니다.
- 교회가 사이트 메뉴에 성경 페이지를 추가해 두어야 합니다.

</div>

## 성경 읽기 {#reading-the-bible}

1. 교회 사이트 메뉴에서 **성경** 페이지로 이동합니다.
2. 리더는 기본적으로 창세기 1장을 엽니다.
3. 리더 안의 탐색 도구를 사용하여 다른 권, 장, 절로 이동합니다.

성경 리더는 **YouVersion**을 기반으로 하며, 여러 언어로 된 다양한 성경 번역본을 이용할 수 있습니다.

## 본문 이동하기 {#navigating-passages}

내장된 리더에는 성경을 넘겨 볼 수 있는 도구가 있습니다. 다음과 같이 할 수 있습니다.

- 성경의 특정 권으로 이동하기
- 특정 장으로 바로 가기
- 장 안의 절을 스크롤하며 읽기
- 버전 선택 도구로 다른 성경 번역본으로 바꾸기
- 교회 웹사이트에서는 본문 위의 **이전 장**과 **다음 장** 버튼으로 권 안의 장을 차례로 넘기기

리더는 페이지의 본문 영역을 가득 채워서 편안하게 읽을 수 있는 충분한 공간을 제공합니다.

:::tip
교인 포털(`/mobile/bible`)에서는 선택한 권, 장, 번역본이 해당 기기에 기억되므로 리더를 다시 열면 마지막으로 읽던 곳에서 이어서 볼 수 있습니다. 웹사이트의 리더는 항상 창세기 1장에서 시작합니다.
:::

리더를 불러올 수 없으면 페이지에 그 사실이 표시되고, 대신 Bible.com에서 읽을 수 있는 버튼이 나타납니다(교인 포털에서는 Biblia.com 버튼도 함께 제공됩니다).

:::tip
매일 말씀을 읽을 때 빠르게 돌아올 수 있도록 브라우저에서 성경 페이지를 즐겨찾기에 추가해 두세요. 매일의 말씀 영감을 얻으려면 [오늘의 말씀](./verse-of-the-day.md)과 함께 이용하면 좋습니다.
:::

## 이용 가능 여부 {#availability}

성경 페이지는 B1.church에 기본으로 내장된 콘텐츠 기능입니다. 교회 메뉴에 **성경** 링크가 보이지 않으면 교회 관리자가 사이트 메뉴에 추가하지 않았을 수 있습니다. 추가를 요청하려면 교회 관리자에게 문의하세요.
