# 공과를 위한 교사 보기

<div class="article-intro">
교사 보기는 구조화된 섹션으로 공과 내용을 볼 수 있는 확장된 전체 화면 인터페이스를 제공합니다. 수업 시간에 교사와 지도자가 공과 자료를 더 쉽게 살펴볼 수 있습니다.
</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 교회에서 계획에 공과를 일정으로 잡아 두어야 합니다. 자세한 내용은 B1 Admin 가이드의 [공과 일정 잡기](../../b1-admin/serving/scheduling-lessons.md)를 참조하세요.
- 계획에 배정되어 있거나, B1.church 사이트에서 해당 계획을 볼 수 있는 권한이 있어야 합니다.
</div>

## 교사 보기 열기

공과의 확장된 교사 보기에 접근하려면 다음과 같이 합니다.

1. B1.church 회원 포털에서 **Plans**를 엽니다.
2. 가르칠 공과가 들어 있는 계획을 엽니다.
3. 계획 페이지 상단의 **Teach** 버튼을 클릭합니다.

공과는 수업에 최적화된 전체 화면 인터페이스에서 열립니다.

:::tip
교사 보기는 공과 내용을 화면이나 TV에 띄워 학생들이 함께 볼 때, 또는 태블릿으로 가르칠 때 특히 유용합니다.
:::

## 교사 보기 기능

### 섹션 탐색

교사 보기는 공과 내용을 섹션으로 나눠 보여줍니다.

- 공과의 각 주요 섹션은 제목이 붙은 별도의 블록으로 나타납니다.
- 상단의 **Sections**를 클릭하면 섹션 목록이 열리고, 하나를 골라 바로 이동할 수 있습니다.
- 제목에는 "Section 2 of 5"처럼 현재 있는 섹션이 표시됩니다.
- 섹션 목록을 이용하면 공과의 여러 부분을 자유롭게 건너뛸 수 있습니다.

### 스크롤 가능한 내용

기본 내용 영역에는 공과 자료 전체가 표시됩니다.

- 공과를 자연스럽게 스크롤하며 볼 수 있습니다.
- 스크롤하면 제목이 현재 보고 있는 섹션에 맞춰 자동으로 바뀝니다.
- 서식이 적용된 모든 텍스트, 이미지, 지시 사항이 명확하게 표시됩니다.

### 미디어 재생

공과에 동영상, 이미지 또는 기타 미디어가 포함된 경우에는 다음과 같습니다.

- 미디어 항목을 클릭하면 팝업 플레이어에서 열립니다.
- 동영상은 기본 컨트롤이 있는 전용 비디오 플레이어에서 재생됩니다.
- 이미지는 전체 화면으로 보기 위해 라이트박스에서 열립니다.
- 미디어 플레이어를 닫으면 공과 내용으로 돌아갑니다.

### 다운로드 가능한 자료

공과에 다운로드 가능한 파일(활동지, 색칠 그림 등)이 포함된 경우에는 다음과 같습니다.

- 각 자료마다 다운로드 버튼이 나타납니다.
- 클릭하면 파일을 기기에 바로 다운로드합니다.
- 파일은 PDF, 이미지 또는 콘텐츠 제작자가 제공한 기타 자료일 수 있습니다.

## 교실에서 교사 보기 사용하기

### 수업 전에

1. 수업이 시작되기 전에 교사 보기에서 공과를 엽니다.
2. 모든 섹션을 검토하고 내용을 익힙니다.
3. 필요한 인쇄용 자료를 다운로드합니다.
4. 동영상과 미디어가 제대로 재생되는지 미리 확인합니다.

### 수업 중에

1. 교사 보기를 기기에 열어 두거나 화면에 투영합니다.
2. 공과를 진행하면서 **Sections**를 사용하여 섹션 사이를 이동합니다.
3. 알맞은 때에 동영상을 재생하거나 이미지를 보여줍니다.
4. 위치를 잃지 않고 필요할 때 지시 사항을 스크롤하여 봅니다.

### 투영 화면에서

수업을 위해 투영할 때는 다음과 같이 합니다.

- 전체 화면 레이아웃은 방해 요소를 제거합니다.
- 큰 글씨는 교실 뒤편에서도 내용이 잘 보이게 합니다.
- 미디어 항목을 클릭하면 학생 전체에게 동영상이나 이미지를 보여줄 수 있습니다.
- 무선 마우스나 트랙패드로 탐색합니다.

## 교사 보기 닫기

교사 보기를 나가려면 다음 중 하나를 합니다.

- 상단 모서리의 **Close** 버튼(X)을 클릭합니다.
- 키보드의 **Esc** 키를 누릅니다.
- 계획 상세 보기로 돌아갑니다.

## 모바일 및 태블릿 사용

교사 보기는 태블릿과 모바일 기기에서도 작동합니다.

- **태블릿** -- 들고 다니며 볼 수 있는 공과 안내서가 필요한 교사에게 적합합니다.
- **휴대폰** -- 지원되지만, 화면이 작아 가르치기에는 덜 적합할 수 있습니다.
- **가로 방향** -- 모바일 기기에서 가장 좋은 보기 경험을 제공합니다.

## 일반 공과 보기와의 차이

| 기능 | 일반 보기 | 교사 보기 |
|---------|--------------|--------------|
| **레이아웃** | 간결하며 계획 안에 인라인으로 표시 | 전체 화면, 전용 보기 |
| **탐색** | 스크롤만 가능 | 섹션 목록 + 현재 섹션 제목과 함께 스크롤 |
| **미디어** | 페이지에 삽입 | 집중해서 볼 수 있는 팝업 플레이어 |
| **화면 공간** | 계획의 다른 항목도 표시 | 공과 내용을 최대화 |
| **적합한 용도** | 둘러보기와 계획 세우기 | 가르치기와 발표 |

## 모범 사례

- **미리 준비하기** -- 수업 전에 교사 보기에서 공과를 검토하여 화면 구성에 익숙해지세요.
- **섹션 표시해 두기** -- 핵심 활동이나 토론이 있는 섹션을 기록해 두세요.
- **미디어 테스트하기** -- 수업 시간 전에 동영상과 이미지가 제대로 불러와지는지 확인하세요.
- **자료는 일찍 다운로드하기** -- 인쇄용 자료를 수업 시간이 되어서야 내려받지 마세요.
- **더 큰 화면 사용하기** -- 최상의 수업 경험을 위해 화면에 투영하거나 태블릿을 사용하세요.

## 문제 해결

### 공과가 교사 보기에서 열리지 않을 때

- 계획에 공과가 올바르게 일정으로 잡혀 있는지 확인하세요.
- 계획을 볼 권한이 있는지 확인하세요.
- 페이지를 새로고침한 후 다시 시도하세요.

### 동영상이 재생되지 않을 때

- 인터넷 연결을 확인하세요.
- 기기가 미디어 재생을 허용하는지 확인하세요.
- 동영상을 별도의 탭에서 열어 보세요.
- 일부 콘텐츠 제공업체는 동영상 재생에 제한을 둘 수 있습니다.

### 모바일에서 내용이 잘려 보일 때

- 기기를 가로 방향으로 돌려 보세요.
- 필요하면 조금 축소해 보세요.
- 더 나은 가시성을 위해 태블릿이나 더 큰 기기를 사용하는 것을 고려하세요.
