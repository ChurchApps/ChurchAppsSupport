# 레슨용 교사 보기

<div class="article-intro">
교사 보기는 구조화된 섹션이 있는 레슨 콘텐츠를 보기 위한 확장된 전체 화면 인터페이스를 제공하여 교사와 리더가 수업 시간 동안 레슨 자료를 더 쉽게 탐색할 수 있도록 합니다.
</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 교회의 계획에 레슨이 예약되어 있어야 합니다. 자세한 내용은 [레슨 예약](../../b1-admin/serving/scheduling-lessons.md)에 대한 B1 Admin 가이드를 참고하세요.
- 계획에 할당되거나 B1.church 사이트에서 볼 수 있는 액세스 권한이 있어야 합니다.
</div>

## 교사 보기 열기

레슨의 확장된 교사 보기에 액세스하려면:

1. B1.church의 **계획** 섹션으로 이동합니다.
2. 가르칠 레슨이 포함된 계획을 엽니다.
3. **서비스 순서** 탭을 엽니다.
4. **가르치기** 버튼을 클릭합니다.

레슨이 가르치기에 최적화된 전체 화면 인터페이스에서 열립니다.

:::tip
교사 보기는 수업이 보기 위해 화면이나 TV에 레슨 콘텐츠를 프로젝션하거나 태블릿에서 가르칠 때 특히 유용합니다.
:::

## 교사 보기 기능

### 탭 네비게이션

교사 보기는 상단의 탭을 사용하여 레슨 콘텐츠를 섹션으로 구성합니다:

- 레슨의 각 주요 섹션이 별도의 탭으로 나타납니다.
- 탭을 클릭하여 해당 섹션으로 바로 이동합니다.
- 활성 섹션은 탭 표시줄에서 강조 표시됩니다.
- 탭을 사용하면 레슨의 다양한 부분으로 쉽게 이동할 수 있습니다.

### 스크롤 가능한 콘텐츠

주 콘텐츠 영역에 전체 레슨 자료가 표시됩니다:

- 레슨을 자연스럽게 스크롤합니다.
- 스크롤하면 활성 탭이 자동으로 보고 있는 섹션과 일치하도록 업데이트됩니다.
- 모든 형식의 텍스트, 이미지 및 지시사항이 명확하게 표시됩니다.

### 미디어 재생

레슨에 비디오, 이미지 또는 기타 미디어가 포함된 경우:

- 미디어 항목을 클릭하여 팝업 플레이어에서 엽니다.
- 비디오는 표준 제어 버튼이 있는 전용 비디오 플레이어에서 재생됩니다.
- 이미지는 전체 화면으로 보기 위해 라이트박스에서 열립니다.
- 미디어 플레이어를 닫으면 레슨 콘텐츠로 돌아갑니다.

### 다운로드 가능한 리소스

레슨에 다운로드 가능한 파일(활동 시트, 색칠하기 페이지 등)이 포함된 경우:

- 다운로드 버튼이 각 리소스에 대해 나타납니다.
- 클릭하여 파일을 디바이스로 직접 다운로드합니다.
- 파일에는 콘텐츠 작성자가 제공한 PDF, 이미지 또는 기타 자료가 포함될 수 있습니다.

## 교실에서 교사 보기 사용

### 수업 전

1. 수업이 시작되기 전에 교사 보기에서 레슨을 엽니다.
2. 모든 섹션을 검토하고 콘텐츠에 익숙해집니다.
3. 필요한 인쇄 가능한 리소스를 다운로드합니다.
4. 비디오나 미디어를 테스트하여 올바르게 재생되는지 확인합니다.

### 수업 중

1. 디바이스에서 교사 보기를 열어두거나 화면에 프로젝션합니다.
2. 탭을 사용하여 레슨을 진행하면서 섹션 간에 이동합니다.
3. 적절한 시간에 비디오를 재생하거나 이미지를 표시합니다.
4. 자리를 잃지 않고 필요에 따라 지시사항을 스크롤합니다.

### 프로젝션된 화면에서

클래스를 위해 프로젝션할 때:

- 전체 화면 레이아웃은 산만함을 제거합니다.
- 크고 읽기 쉬운 텍스트는 방 전체에서 콘텐츠를 볼 수 있도록 합니다.
- 미디어 항목을 클릭하여 전체 클래스에 비디오나 이미지를 표시합니다.
- 무선 마우스나 트랙패드를 사용하여 탐색합니다.

## 교사 보기 닫기

교사 보기를 종료하려면:

- 상단 모서리의 **닫기** 버튼(X)을 클릭합니다.
- 또는 키보드의 **Esc** 키를 누릅니다.
- 계획 세부 정보 보기로 돌아갑니다.

## 모바일 및 태블릿 사용

교사 보기는 태블릿과 모바일 디바이스에서 작동합니다:

- **태블릿** -- 휴대용 레슨 가이드를 원하는 교사에게 완벽합니다.
- **휴대폰** -- 지원되지만 더 작은 화면이 가르치기에 덜 이상적일 수 있습니다.
- **가로 모드** -- 모바일 디바이스에서 최고의 보기 환경을 제공합니다.

## 일반 레슨 보기와의 차이점

| 기능 | 일반 보기 | 교사 보기 |
|---------|---------|---------|
| **레이아웃** | 컴팩트, 계획과 함께 인라인 | 전체 화면, 전용 보기 |
| **탐색** | 스크롤만 | 탭 + 자동 강조 표시를 포함한 스크롤 |
| **미디어** | 페이지에 포함됨 | 집중적인 보기를 위한 팝업 플레이어 |
| **화면 공간** | 다른 계획 항목 표시 | 레슨 콘텐츠에 최대화됨 |
| **최고의 용도** | 탐색 및 계획 | 가르치기 및 프레젠테이션 |

## 모범 사례

- **미리 준비합니다** -- 레이아웃에 익숙해지기 위해 수업 전에 교사 보기에서 레슨을 검토합니다.
- **북마크 섹션** -- 주요 활동이나 토론이 포함된 탭을 메모합니다.
- **미디어 테스트** -- 수업 시간 전에 비디오와 이미지가 제대로 로드되는지 확인합니다.
- **리소스 미리 다운로드** -- 수업 시간에 인쇄물을 다운로드하는 것을 기다리지 마세요.
- **더 큰 화면 사용** -- 최고의 가르치기 경험을 위해 프로젝션하거나 태블릿을 사용합니다.

## 문제 해결

### 레슨이 교사 보기에서 열리지 않습니다.

- 레슨이 계획에서 올바르게 예약되었는지 확인합니다.
- 계획을 볼 수 있는 권한이 있는지 확인합니다.
- 페이지를 새로 고침하고 다시 시도합니다.

### 비디오가 재생되지 않습니다.

- 인터넷 연결을 확인합니다.
- 디바이스에서 미디어 재생을 허용하는지 확인합니다.
- 비디오를 별도의 탭에서 열어 봅니다.
- 일부 콘텐츠 제공자는 비디오 재생에 제한이 있을 수 있습니다.

### 모바일에서 콘텐츠가 잘린 것으로 보입니다.

- 디바이스를 가로 모드로 회전시킵니다.
- 필요한 경우 약간 확대합니다.
- 더 나은 가시성을 위해 태블릿이나 더 큰 디바이스를 사용하는 것을 고려하세요.
