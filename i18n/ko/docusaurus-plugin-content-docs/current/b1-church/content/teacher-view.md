# 수업 자료를 위한 교사 보기

<div class="article-intro">
교사 보기는 구조화된 섹션으로 수업 자료를 볼 수 있는 확장된 전체 화면 인터페이스를 제공합니다. 교사와 리더가 수업 시간에 수업 자료를 쉽게 탐색할 수 있도록 도와줍니다.
</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 교회의 계획에 수업이 예약되어 있어야 합니다. 자세한 내용은 B1 Admin 가이드의 [수업 예약하기](../../b1-admin/serving/scheduling-lessons.md)를 참고하세요.
- 계획에 배정되어 있거나, B1.church 사이트에서 계획을 볼 수 있는 권한이 있어야 합니다.
</div>

## 교사 보기 열기 {#opening-teacher-view}

수업의 확장된 교사 보기에 접근하려면 다음과 같이 합니다.

1. B1.church 교인 포털에서 **계획**을 엽니다.
2. 가르칠 수업이 포함된 계획을 엽니다.
3. 계획 페이지 상단의 **가르치기** 버튼을 클릭합니다.

수업은 수업에 최적화된 전체 화면 인터페이스로 열립니다.

**가르치기** 버튼은 계획의 예배 순서가 예약된 수업에서 바로 가져온 경우에 나타납니다. 교회가 계획의 예배 순서를 사용자 지정했다면 이 버튼은 표시되지 않지만, 수업의 인쇄용 파일은 계획의 **다운로드** 섹션에 계속 나타납니다.

:::tip
교사 보기는 수업 자료를 화면이나 TV에 띄워 학생들에게 보여 줄 때, 또는 태블릿으로 가르칠 때 특히 유용합니다.
:::

## 교사 보기 기능 {#teacher-view-features}

### 섹션 탐색 {#section-navigation}

교사 보기는 수업 자료를 섹션으로 나누어 보여 줍니다.

- 수업의 각 주요 섹션은 제목이 붙은 별도의 블록으로 나타납니다.
- 상단의 **섹션**을 클릭하면 섹션 목록이 열리고, 하나를 골라 바로 이동할 수 있습니다.
- 제목에는 "5개 중 2번째 섹션"처럼 현재 위치한 섹션이 표시됩니다.
- 섹션 목록을 사용하면 수업의 여러 부분을 자유롭게 건너뛰며 이동할 수 있습니다.
- 수업에 섹션이 둘 이상 있으면, 스크롤하는 동안에도 화면 하단에 이전과 다음 버튼이 고정되어 있으며, 각 버튼에는 이웃한 섹션의 이름이 표시됩니다.

### 스크롤 가능한 콘텐츠 {#scrollable-content}

기본 콘텐츠 영역에는 수업 자료 전체가 표시됩니다.

- 수업을 자연스럽게 스크롤하며 읽을 수 있습니다.
- 스크롤하면 보고 있는 섹션에 맞춰 제목이 자동으로 바뀝니다.
- 서식이 적용된 모든 텍스트, 이미지, 지침이 선명하게 표시됩니다.

### 미디어 재생 {#media-playback}

수업에 동영상, 이미지 또는 기타 미디어가 포함되어 있을 때는 다음과 같습니다.

- 미디어 항목을 클릭하면 팝업 플레이어에서 열립니다.
- 동영상은 기본 컨트롤이 있는 전용 비디오 플레이어에서 재생됩니다.
- 이미지는 라이트박스에서 전체 화면으로 볼 수 있습니다.
- 미디어 플레이어를 닫으면 수업 콘텐츠로 돌아갑니다.

### 내려받을 수 있는 자료 {#downloadable-resources}

수업에 내려받을 수 있는 파일(활동지, 색칠 그림 등)이 포함되어 있다면 다음과 같습니다.

- 수업의 마지막 섹션 뒤에 각 자료의 다운로드 버튼이 나타납니다.
- 클릭하면 파일을 기기에 바로 내려받을 수 있습니다.
- 파일은 PDF, 이미지 또는 콘텐츠 제작자가 제공한 기타 자료일 수 있습니다.

## 교실에서 교사 보기 사용하기 {#using-teacher-view-in-the-classroom}

### 수업 전 {#before-class}

1. 수업이 시작되기 전에 교사 보기로 수업을 엽니다.
2. 모든 섹션을 검토하고 내용을 익힙니다.
3. 필요한 인쇄용 자료를 내려받습니다.
4. 동영상과 미디어가 제대로 재생되는지 미리 확인합니다.

### 수업 중 {#during-class}

1. 기기에서 교사 보기를 열어 두거나 화면에 띄웁니다.
2. 수업을 진행하면서 **섹션**을 사용해 섹션 사이를 이동합니다.
3. 적절한 시점에 동영상을 재생하거나 이미지를 보여 줍니다.
4. 필요에 따라 지침을 스크롤하며, 읽던 위치를 잃지 않고 확인합니다.

### 투사 화면에서 {#on-a-projected-screen}

학생들에게 화면을 투사할 때는 다음과 같습니다.

- 전체 화면 레이아웃이 방해 요소를 없애 줍니다.
- 큰 글씨로 표시되어 교실 어디에서든 내용이 잘 보입니다.
- 미디어 항목을 클릭하면 동영상이나 이미지를 학생 전체에게 보여 줄 수 있습니다.
- 무선 마우스나 트랙패드로 이동할 수 있습니다.

## 교사 보기 닫기 {#closing-teacher-view}

교사 보기를 종료하려면 다음과 같이 합니다.

- 오른쪽 상단의 **닫기** 버튼(X)을 클릭합니다.
- 또는 키보드의 **Esc** 키를 누릅니다.
- 계획 상세 보기로 돌아갑니다.

## 모바일 및 태블릿 사용 {#mobile-and-tablet-use}

교사 보기는 태블릿과 모바일 기기에서도 작동합니다.

- **태블릿** -- 휴대용 수업 안내서가 필요한 교사에게 좋습니다.
- **휴대폰** -- 지원되지만, 화면이 작아 수업에는 덜 적합할 수 있습니다.
- **가로 방향** -- 모바일 기기에서 가장 좋은 화면 경험을 제공합니다.

## 일반 수업 보기와의 차이 {#differences-from-regular-lesson-view}

| 기능 | 일반 보기 | 교사 보기 |
|---------|--------------|--------------|
| **레이아웃** | 간결하며 계획 안에 인라인으로 표시 | 전체 화면, 전용 보기 |
| **탐색** | 스크롤만 가능 | 섹션 목록 + 현재 섹션 제목과 함께 스크롤 |
| **미디어** | 페이지에 삽입됨 | 집중해서 볼 수 있는 팝업 플레이어 |
| **화면 공간** | 다른 계획 항목도 표시 | 수업 콘텐츠를 최대한 넓게 표시 |
| **적합한 용도** | 둘러보기와 계획 세우기 | 가르치기와 발표 |

## 모범 사례 {#best-practices}

- **미리 준비하기** -- 수업 전에 교사 보기에서 수업을 검토하여 레이아웃에 익숙해지세요.
- **섹션 표시해 두기** -- 핵심 활동이나 토론이 있는 섹션을 기억해 두세요.
- **미디어 테스트하기** -- 수업 시간 전에 동영상과 이미지가 제대로 불러와지는지 확인하세요.
- **자료는 일찍 내려받기** -- 수업 시간까지 기다리지 말고 인쇄용 자료를 미리 내려받으세요.
- **더 큰 화면 사용하기** -- 최상의 수업 경험을 위해 화면을 투사하거나 태블릿을 사용하세요.

## 문제 해결 {#troubleshooting}

### 수업이 교사 보기로 열리지 않는 경우 {#lesson-doesnt-open-in-teacher-view}

- 계획에 수업이 올바르게 예약되었는지 확인하세요.
- 계획의 예배 순서를 사용자 지정했다면 **가르치기** 버튼이 숨겨집니다. [교사 보기 열기](#opening-teacher-view)를 참고하세요.
- 계획을 볼 권한이 있는지 확인하세요.
- 페이지를 새로 고친 다음 다시 시도하세요.

### 동영상이 재생되지 않는 경우 {#videos-wont-play}

- 인터넷 연결을 확인하세요.
- 기기에서 미디어 재생이 허용되어 있는지 확인하세요.
- 동영상을 별도의 탭에서 열어 보세요.
- 일부 콘텐츠 제공업체는 동영상 재생에 제한을 둘 수 있습니다.

### 모바일에서 콘텐츠가 잘려 보이는 경우 {#content-appears-cut-off-on-mobile}

- 기기를 가로 방향으로 돌리세요.
- 필요하면 화면을 약간 축소하세요.
- 더 잘 보이도록 태블릿이나 더 큰 기기를 사용하는 것을 고려하세요.
