# 체크인

<div class="article-intro">

B1.church의 **체크인** 기능을 사용하면 회원 포털에서 직접 본인과 가족 구성원의 교회 예배 출석을 체크인할 수 있습니다. 실제 체크인 키오스크를 방문하지 않아도 출석을 기록할 수 있는 편리한 방법입니다.

</div>

## 작동 방식

셀프 체크인을 사용하면 예배를 선택하고, 참석하는 가족 구성원을 고르고, 각 예배 시간마다 알맞은 그룹에 각 사람을 배정합니다. 확인하면 출석이 자동으로 기록됩니다.

## 시작하기

체크인에 접근하려면 회원 포털의 [탭 바 또는 More 페이지](../getting-started/navigating.md)에서 **Check-In**을 탭합니다. 이 기능을 사용하려면 [로그인](../getting-started/logging-in.md)되어 있어야 합니다. 로그인하지 않았다면 먼저 로그인하라는 안내가 나타납니다.

:::info
체크인 기능을 사용하려면 교회가 관리 설정에서 예배와 출석 그룹을 설정해 두어야 합니다. 체크인 페이지를 열었을 때 예배가 하나도 없다면 교회에서 아직 이 기능을 설정하지 않았을 수 있습니다. 도움이 필요하면 교회 관리자에게 문의하세요.
:::
