# 셀프 체크인

<div class="article-intro">

셀프 체크인 프로세스를 통해 몇 가지 간단한 단계로 자신과 가정의 출석을 기록할 수 있습니다. 이것은 교회의 물리적 키오스크를 사용하는 빠른 대체 방법입니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [로그인](../getting-started/logging-in.md)하여 B1.church 계정에 접속해야 합니다.
- 가정 구성원이 계정에 연결되어 있어야 합니다. 가족 구성원이 누락된 경우 교회 관리자에게 가정에 추가하도록 요청하세요.

</div>

## 체크인 흐름

체크인은 간단한 3단계 프로세스를 따릅니다. [사이드바](../getting-started/navigating.md)의 **체크인** 탭으로 이동하여 시작하세요.

### 1단계: 서비스 선택

체크인 페이지를 열면 사용 가능한 서비스 목록(예: "주일 아침" 또는 "수요일 저녁")이 표시됩니다. 각 서비스 카드는 교회에 여러 위치가 있는 경우 서비스 이름과 캠퍼스를 보여줍니다.

서비스를 클릭하여 선택하고 다음 단계로 이동합니다.

### 2단계: 가정 구성원 및 그룹 선택

서비스를 선택한 후 가정 구성원의 목록을 볼 수 있습니다. 참석할 각 사람에 대해:

1. 가정 구성원을 탭하여 항목을 확장합니다.
2. 선택한 서비스에 대해 사용 가능한 **서비스 시간**을 볼 수 있습니다.
3. 서비스 시간 옆의 **그룹 선택**을 클릭하여 사람이 체크인할 그룹(예: "주요 예배", "어린이 방 1", "청년부")을 선택합니다.
4. 참석할 각 가정 구성원에 대해 반복합니다.

모든 가정 구성원을 체크인할 필요가 없습니다. 실제로 있는 사람만 확장하고 그룹을 할당합니다.

### 3단계: 확인

참석할 모든 사람의 그룹을 선택한 후 페이지 하단의 **체크인 완료** 버튼을 클릭합니다.

체크인이 완료되었다는 확인이 표시되고 출석이 저장되었습니다. 잠시 후 페이지가 서비스 목록으로 돌아가 다음 체크인을 기다립니다.

교회에서 체크인 스테이션에서 이름표를 인쇄하는 경우 **체크인되었습니다!**가 QR 코드 및 보안 코드와 함께 표시됩니다. 체크인 스테이션에서 코드를 보여주세요. B1 Checkin 키오스크에서는 **코드 스캔**을 탭하고 QR 코드를 카메라 앞에 가져가세요. [휴대폰 체크인을 위한 레이블 인쇄](../../b1-checkin/check-in/looking-up-members#printing-labels-for-a-phone-check-in)를 참조하세요.

가정이 선택한 서비스에 대해 이미 체크인된 경우 가정 목록 위에 **체크인 코드 표시** 버튼이 나타납니다. 이를 탭하여 QR 코드 및 보안 코드를 다시 가져옵니다. 예를 들어 체크인 스테이션에 도달하기 전에 페이지를 닫은 경우입니다.

:::tip
체크인을 완료하기 전에 그룹 선택을 변경해야 하는 경우 서비스 시간 옆의 **변경** 버튼을 탭하여 다른 그룹을 선택합니다.
:::

## 알아야 할 사항

- 계정에 연결된 가정 구성원만 체크인할 수 있습니다. 가족 구성원이 누락된 경우 교회 관리자에게 가정에 추가하도록 요청하세요.
- 체크인 페이지에 서비스가 나타나지 않으면 교회에서 이 시간에 체크인을 위해 구성된 서비스가 없을 수 있습니다.

:::warning
체크인은 교회에서 활성 서비스가 구성되어 있을 때만 사용 가능합니다. 서비스가 나열되지 않으면 교회 사무실에 연락하여 셀프 체크인이 활성화되어 있는지 확인하세요.
:::
