# 셀프 체크인

<div class="article-intro">

셀프 체크인을 사용하면 몇 단계만으로 본인과 가족의 출석을 기록할 수 있습니다. 교회에 있는 실물 키오스크를 사용하는 것보다 빠른 방법입니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- B1.church 계정으로 [로그인](../getting-started/logging-in.md)되어 있어야 합니다.
- 가족 구성원이 계정에 연결되어 있어야 합니다. 가족 구성원이 보이지 않으면 교회 관리자에게 가구에 추가해 달라고 요청하세요.

</div>

## 체크인 과정

체크인은 세 단계의 간단한 과정으로 진행됩니다. 시작하려면 [하단 탭 바 또는 더보기 페이지](../getting-started/navigating.md)에서 **체크인**을 여세요.

### 1단계: 예배 선택

체크인 페이지를 열면 이용 가능한 예배 목록이 표시됩니다(예: "주일 오전" 또는 "수요일 저녁"). 교회에 여러 캠퍼스가 있는 경우 각 예배 카드에 예배 이름과 캠퍼스가 함께 표시됩니다.

예배를 클릭하여 선택하면 다음 단계로 넘어갑니다.

### 2단계: 가족 구성원 및 그룹 선택

예배를 선택하면 **참석자**에 가족 구성원이 표시됩니다. 참석하는 각 사람에 대해 다음을 진행하세요.

1. 가족 구성원을 탭하여 항목을 펼칩니다.
2. 선택한 예배의 이용 가능한 **예배 시간**이 표시됩니다. 교회에서 예배 시간별 체크인 일정을 설정해 두었다면, 해당 체크인이 열려 있는 동안(예: 예배 시작 30분 전부터 종료 직후까지)에만 선택할 수 있습니다. 그 시간 외에는 예배 시간이 **마감**으로 표시되며, 알려진 경우 개방 시간도 함께 표시됩니다(예: **마감 · 일요일 오전 9:30 개방**).
3. 예배 시간 옆의 **그룹 선택**을 탭하여 해당 사람이 체크인할 그룹을 고릅니다(예: "본당 예배," "유치부 1," "청소년부").
4. 참석하는 가족 구성원마다 이 과정을 반복합니다.

모든 가족 구성원을 체크인할 필요는 없습니다. 실제로 참석한 사람만 펼쳐서 그룹을 지정하면 됩니다.

오늘 이 예배에 이미 체크인한 사람은 이름 옆에 **이미 체크인함** 배지가 표시됩니다.

### 3단계: 확인

참석하는 모든 사람의 그룹을 선택했다면 페이지 하단의 버튼을 탭하세요. 선택한 인원 수가 표시됩니다(예: **1명 체크인** 또는 **3명 체크인**).

선택한 사람 중 오늘 이 예배에 이미 체크인한 사람이 있으면 **이미 체크인함** 창에 해당 인원이 먼저 표시됩니다. 그룹을 업데이트하려면 **다시 체크인**을, 돌아가려면 **취소**를 탭하세요.

체크인이 완료되고 출석이 저장되었다는 확인 메시지가 표시됩니다. 잠시 후 페이지가 예배 목록으로 돌아가며, 다음 체크인을 할 수 있는 상태가 됩니다.

교회에서 체크인 스테이션에서 이름표를 출력하는 경우, 대신 **체크인되었습니다!** 메시지와 QR 코드, 보안 코드가 표시됩니다. 체크인 스테이션에 코드를 보여 주어 이름표를 출력한 후 **완료**를 탭하세요. B1 Checkin 키오스크에서는 **코드 스캔**을 탭한 다음 QR 코드를 카메라에 가까이 대세요. 자세한 내용은 [휴대폰 체크인 라벨 출력](../../b1-checkin/check-in/looking-up-members.md#printing-labels-for-a-phone-check-in)을 참조하세요.

선택한 예배에 가족이 이미 체크인되어 있다면 **참석자** 제목 옆에 **체크인 코드 보기** 링크가 나타납니다. 이 링크를 탭하면 QR 코드와 보안 코드를 다시 표시할 수 있습니다. 예를 들어 체크인 스테이션에 도착하기 전에 페이지를 닫은 경우에 유용합니다.

:::tip
체크인을 완료하기 전에 그룹 선택을 변경해야 한다면, 예배 시간 옆의 **변경** 버튼을 탭하여 다른 그룹을 선택하세요.
:::

## 알아두면 좋은 사항

- 계정에 연결된 가족 구성원만 체크인할 수 있습니다. 가족 구성원이 보이지 않으면 교회 관리자에게 가구에 추가해 달라고 요청하세요.
- 체크인 페이지에 예배가 전혀 표시되지 않는다면, 현재 교회에 체크인용으로 설정된 예배가 없을 수 있습니다.
- 예배를 선택했을 때 "체크인은 일요일 오전 9:30에 열립니다." (또는 "지금은 이 예배의 체크인이 열려 있지 않습니다.")와 같은 메시지가 보이면, 해당 예배의 모든 시간이 현재 체크인 시간 범위에 포함되지 않은 것입니다. 체크인이 열린 후에 다시 시도하세요.
- 가족이 이전 예배 시간에 체크인했다면, 이전 시간이 마감된 후라도 나중 예배 시간이 열리면 돌아와서 해당 시간에 체크인할 수 있습니다.
- 선택한 방이 가득 찼거나 체크인이 닫혀 있으면 "선택하신 방이 가득 찼거나 체크인이 마감되었습니다. 봉사자에게 문의해 주세요."라는 메시지가 표시됩니다.
- 어린이 방에 다른 아이를 위한 봉사자가 충분히 체크인되어 있지 않으면, 방 이름을 포함한 메시지가 표시됩니다. 예를 들어 "유치부 1에 지금 다른 아이를 위한 봉사자가 부족합니다. 다른 방을 선택하거나 봉사자에게 문의해 주세요."와 같습니다.

:::warning
체크인은 교회에 활성화된 예배가 설정되어 있을 때만 이용할 수 있습니다. 예배 목록이 보이지 않는다면, 교회 사무실에 셀프 체크인이 활성화되어 있는지 확인하세요.
:::
