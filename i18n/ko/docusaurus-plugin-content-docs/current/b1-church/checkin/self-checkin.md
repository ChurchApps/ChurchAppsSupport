# 셀프 체크인

<div class="article-intro">

셀프 체크인 프로세스를 통해 자신과 가족을 몇 가지 간단한 단계로 출석을 기록할 수 있습니다. 교회의 물리적 키오스크를 사용하는 대신 빠른 대안입니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [B1.church 계정에 로그인](../getting-started/logging-in.md)해야 합니다.
- 가족 구성원이 계정과 연결되어 있어야 합니다. 가족 구성원이 빠져 있으면 교회 관리자에게 가족에 추가해달라고 요청하세요.

</div>

## 체크인 절차

체크인은 간단한 3단계 프로세스를 따릅니다. [사이드바](../getting-started/navigating.md)의 **체크인** 탭으로 이동하여 시작하세요.

### 단계 1: 서비스 선택

체크인 페이지를 열면 사용 가능한 서비스 목록이 표시됩니다(예: "일요일 아침" 또는 "수요일 저녁"). 각 서비스 카드는 서비스 이름과 교회에 여러 위치가 있는 경우 캠퍼스를 표시합니다.

서비스를 클릭하여 선택하고 다음 단계로 이동합니다.

### 단계 2: 가족 구성원 및 그룹 선택

서비스를 선택한 후 가족 구성원 목록이 표시됩니다. 참석하는 각 사람에 대해:

1. 가족 구성원을 탭하여 항목을 확장합니다.
2. 선택한 서비스의 사용 가능한 **서비스 시간**이 표시됩니다.
3. 서비스 시간 옆의 **그룹 선택**을 클릭하여 해당 사람이 체크인해야 할 그룹을 선택합니다("메인 예배", "어린이실 1", "청소년 그룹" 등).
4. 참석하는 각 가족 구성원에 대해 반복합니다.

모든 가족 구성원을 체크인할 필요는 없습니다. 실제로 참석한 사람만 확장하고 그룹을 할당하세요.

### 단계 3: 확인

참석한 모든 사람의 그룹을 선택한 후 페이지 하단의 **체크인 완료** 버튼을 클릭합니다.

체크인이 완료되었고 출석이 저장되었다는 확인 메시지가 표시됩니다. 잠깐 후 페이지가 서비스 목록으로 돌아가 다음 체크인을 준비합니다.

교회에서 체크인 스테이션에서 명찰을 인쇄하는 경우 대신 **체크인되었습니다!** QR 코드와 보안 코드가 표시됩니다. 체크인 스테이션에서 코드를 표시하여 명찰을 인쇄한 후 **완료**를 탭합니다.

:::tip
체크인을 완료하기 전에 그룹 선택을 변경해야 하는 경우 서비스 시간 옆의 **변경** 버튼을 탭하여 다른 그룹을 선택하세요.
:::

## 알아야 할 사항

- 계정과 연결된 가족 구성원만 체크인할 수 있습니다. 가족 구성원이 빠져 있으면 교회 관리자에게 가족에 추가해달라고 요청하세요.
- 체크인 페이지에 서비스가 표시되지 않으면 교회에 현재 체크인에 대해 구성된 서비스가 없을 수 있습니다.

:::warning
체크인은 활성 서비스가 구성된 경우에만 사용할 수 있습니다. 서비스가 나열되지 않으면 교회 사무실에 문의하여 셀프 체크인이 활성화되었는지 확인하세요.
:::
