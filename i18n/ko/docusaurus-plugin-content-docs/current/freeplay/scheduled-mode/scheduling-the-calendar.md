# 캘린더 예약하기

<div class="article-intro">

FreePlay Admin의 **Calendar** 페이지에서 각 화면 그룹이 무엇을 언제 재생할지 정합니다. 재생 목록, 예배 계획, 또는 제공업체 폴더에 대한 일정을 추가하고, 매주 반복하거나 한 번만 재생하도록 설정할 수 있습니다. 예약된 일정이 없으면 그룹의 기본 루프가 재생됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 화면 그룹을 하나 이상 만드세요. [화면 및 그룹 관리하기](./managing-screens#screen-groups)를 참고하세요.
- [재생 목록을 만들거나](./building-playlists), B1 Admin에서 계획 유형을 설정해 두세요.

</div>

## 캘린더 읽기

1. **Calendar**로 이동하세요.
2. 위쪽 탭에서 화면 그룹을 고르세요. 각 탭에는 그 그룹에 있는 일정 수가 표시됩니다.
3. 주간 보기는 월요일부터 일요일까지, 오전 6시부터 오후 10시까지입니다. 빨간 선은 현재 시각을 나타냅니다.
4. 화살표로 이전 주나 다음 주로 이동하거나, **Today**를 클릭해 이번 주로 돌아오세요.

페이지 부제목에는 캘린더가 사용하는 시간대가 표시됩니다. 일정은 교회의 시간대를 따르며, 이 시간대는 B1 Admin의 [교회 정보](../../b1-admin/settings/church-settings.md#time-zone)에서 설정합니다. 교회에 시간대가 설정되지 않았다면 FreePlay는 캠퍼스의 시간대를 사용합니다. 캘린더와 TV는 같은 시간대를 사용하므로, 캘린더에서 오전 9시에 놓은 블록은 컴퓨터의 시간대가 달라도 화면에서 오전 9시에 재생됩니다.

일정은 종류별로 색상이 구분됩니다. 범례에서 색상의 뜻을 확인하세요.

- **Default loop**(기본 루프) - 그룹에 기본 루프가 있으면 모든 것 뒤에 빗금 배경으로 표시됩니다.
- **Playlist**(재생 목록)
- **Service plan**(예배 계획)
- **Provider folder**(제공업체 폴더)

각 블록에는 이름이 표시되며, 높이가 높은 블록에는 시간, 반복 여부(**weekly**(매주) 또는 **once**(한 번)), 콘텐츠가 일찍 끝났을 때 어떻게 되는지도 함께 표시됩니다.

## 기본 루프 설정하기

기본 루프는 아무것도 예약되어 있지 않을 때 그룹의 화면에서 재생됩니다.

1. **Calendar** 페이지 상단의 **Default loop…**를 클릭하세요. 기본 루프가 이미 설정되어 있다면 버튼에는 **Default loop:** 뒤에 재생 목록 이름이 표시됩니다.
2. **Playlist**를 고르거나 **None — screen goes dark**(없음 — 화면 꺼짐)를 고르세요.
3. **Save**를 클릭하세요.

## 일정 추가하기

새 일정을 시작하는 방법은 세 가지입니다.

- 캘린더의 빈 곳을 클릭하세요. 양식이 열리며 그 요일과 30분 단위 시간이 미리 채워집니다.
- 상단의 **Add schedule**을 클릭하세요.
- 명령 팔레트(**Ctrl+K** 또는 **⌘K**)에서 **Add schedule**을 선택하세요.

그다음 양식을 채우세요.

1. **Play**(재생) - 무엇을 재생할지 고르세요.
   - **Playlists**(재생 목록) - 만들어 둔 재생 목록
   - **Service plans**(예배 계획) - B1 Admin의 계획 유형으로, **(current plan)**(현재 계획)으로 표시됩니다. 화면은 매주 그 계획 유형의 현재 계획을 재생합니다. 여기에는 Go Curriculum 수업(맞춤 설정한 수업 포함)도 포함되며, 이때는 계획 유형의 사역에 연결된 Go 로그인을 사용합니다.
   - **Provider folder…**(제공업체 폴더…) - **Choose a provider folder**(제공업체 폴더 선택)를 엽니다. 폴더를 찾아보고 **Use this folder**를 클릭하세요. 나중에 다른 폴더를 고르려면 **Change**를 클릭하세요.
2. **Repeats**(반복) - 이 일정을 재생할 요일을 고르세요. 한 날짜만 재생하려면 **One time**(한 번)을 켜고 **Date**(날짜)를 고르세요.
3. **Start**(시작)와 **End**(끝) - 일정이 시작하고 끝나는 시간입니다.
4. **If it finishes early**(일찍 끝나면) - 종료 시간 전에 콘텐츠가 다 나왔을 때 할 일입니다.
   - **Loop until the end time**(종료 시간까지 반복) - 처음부터 다시 시작합니다. 사이니지 루프, 공지, 카운트다운에 좋습니다.
   - **Teacher paced**(교사 진행) - 슬라이드가 교사의 리모컨을 기다립니다. 수업 화면은 마지막 슬라이드까지 종료 시간을 넘어서도 유지됩니다.
   - **Play once, then go back to the default loop**(한 번 재생한 뒤 기본 루프로 돌아가기)
5. 반복 일정이라면 **Starts**(시작일)를 첫 날짜로 설정하세요. **Ends**(종료)에서는 **Never**(없음)를 고르거나, **On date**(특정 날짜)를 고른 다음 **End date**(종료 날짜)를 입력하세요.
6. **Save**를 클릭하세요.

:::info
**Teacher paced**는 이전의 "마지막 슬라이드 유지" 옵션을 대체했습니다. 이전 옵션으로 저장된 일정은 이제 Teacher paced로 재생됩니다.
:::

## 일정 편집 또는 삭제하기

1. 캘린더에서 일정의 블록을 클릭하세요.
2. 원하는 항목을 바꾸고 **Save**를 클릭하거나, **Delete**를 클릭해 일정을 삭제하세요.

## 겹치는 일정

두 일정이 겹치면 양식에 경고가 표시됩니다. **Overlaps another schedule. The one that starts later wins.**(다른 일정과 겹칩니다. 나중에 시작하는 일정이 우선합니다.) 나중에 시작한 일정이 진행되는 동안 화면은 그 일정을 재생합니다. 그 일정이 끝나면, 앞선 일정이 아직 진행 중이라면 화면은 앞선 일정으로 돌아갑니다.

## 화면이 변경 사항을 가져오는 방식

페어링된 화면은 앞으로 7일 동안 예약된 모든 내용을 내려받으며, 스스로 변경 사항을 확인합니다. 캘린더를 편집한 뒤 TV를 직접 만질 필요는 없습니다. 화면이 필요한 내용을 모두 가지고 있는지 확인하려면 [화면 페이지](./managing-screens)의 **Ready through**(이 날짜까지 준비됨)를 확인하세요.
