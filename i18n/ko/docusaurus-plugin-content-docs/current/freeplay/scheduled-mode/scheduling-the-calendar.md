# 달력 예약하기

<div class="article-intro">

FreePlay Admin의 **달력** 페이지에서는 각 화면 그룹이 무엇을 언제 재생할지 정합니다. 재생 목록, 예배 계획, 또는 제공업체 폴더에 대한 일정을 추가하고, 매주 반복하거나 한 번만 재생하도록 설정하세요. 예약된 일정이 없으면 그룹의 기본 반복 재생이 재생됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 최소 한 개의 화면 그룹을 만드세요. [화면 및 그룹 관리](./managing-screens.md#screen-groups)를 참고하세요.
- [재생 목록을 만들거나](./building-playlists.md), B1 Admin에서 계획 유형을 설정해 두세요.

</div>

## 달력 읽기 {#reading-the-calendar}

1. **달력**으로 이동합니다.
2. 상단의 탭에서 화면 그룹을 고릅니다. 각 탭에는 그룹에 있는 일정 수가 표시됩니다.
3. 주간 보기는 월요일부터 일요일까지, 오전 6시부터 오후 10시까지 표시됩니다. 빨간 선은 현재 시각을 나타냅니다.
4. 화살표로 이전 주나 다음 주로 이동하거나, **오늘**을 클릭하여 이번 주로 돌아오세요.

페이지 부제목에는 달력이 사용하는 시간대가 표시됩니다. 일정은 교회의 시간대를 따르며, 이는 B1 Admin의 [교회 정보](../../b1-admin/settings/church-settings.md#time-zone)에서 설정합니다. 교회에 시간대가 설정되어 있지 않다면 FreePlay는 캠퍼스의 시간대를 사용합니다. 달력과 TV는 같은 시간대를 사용하므로, 컴퓨터가 다른 시간대로 설정되어 있더라도 달력에서 오전 9시에 배치한 블록은 화면에서도 오전 9시에 재생됩니다.

일정은 유형별로 색상이 구분됩니다. 범례에서 색상의 의미를 확인할 수 있습니다.

- **기본 반복 재생** - 그룹에 기본 반복 재생이 설정되어 있으면 모든 항목 뒤에 사선 무늬 배경으로 표시됩니다.
- **재생 목록**
- **예배 계획**
- **제공업체 폴더**

각 블록에는 이름이 표시되며, 높이가 큰 블록에는 시간, 반복 여부(**매주** 또는 **한 번**), 그리고 콘텐츠가 일찍 끝났을 때의 동작도 함께 표시됩니다.

## 기본 반복 재생 설정하기 {#setting-the-default-loop}

기본 반복 재생은 예약된 일정이 없을 때 그룹의 화면에서 재생됩니다.

1. **달력** 페이지 상단의 **기본 반복 재생**…을 클릭합니다. 기본 반복 재생이 이미 설정되어 있다면 버튼에는 **기본 반복 재생:** 뒤에 재생 목록 이름이 표시됩니다.
2. **재생 목록**을 고르거나 **없음 — 화면 끄기**를 고릅니다.
3. **저장**을 클릭합니다.

## 일정 추가하기 {#adding-a-schedule}

새 일정을 시작하는 방법은 세 가지입니다.

- 달력의 빈 칸을 클릭합니다. 그 요일과 30분 단위 시각이 미리 채워진 양식이 열립니다.
- 상단의 **일정 추가**를 클릭합니다.
- 명령 팔레트(**Ctrl+K** 또는 **⌘K**)에서 **일정 추가**를 고릅니다.

그다음 양식을 작성합니다.

1. **재생** - 재생할 항목을 고릅니다.
   - **재생 목록** - 만들어 둔 재생 목록 중 하나
   - **예배 계획** - B1 Admin의 계획 유형으로, **(현재 계획**)으로 표시됩니다. 화면은 매주 그 계획 유형의 현재 계획을 재생합니다. 여기에는 Go 커리큘럼 수업(맞춤 수업 포함)도 포함되며, 이 수업은 계획 유형의 사역에 연결된 Go 로그인을 사용합니다.
   - **제공업체 폴더…** - **제공업체 폴더 선택**을 엽니다. 폴더를 찾아 **이 폴더 사용**을 클릭하세요. 나중에 다른 폴더를 고르려면 **변경**을 클릭합니다.
2. **반복** - 이 일정을 재생할 요일을 선택합니다. 대신 특정한 날짜 하나만 재생하려면 **한 번**을 켜고 **날짜**를 고르세요.
3. **시작**과 **종료** - 일정이 시작하고 멈출 시각입니다.
4. **일찍 끝나면** - 종료 시각 전에 콘텐츠가 끝났을 때 할 일입니다.
   - **종료 시각까지 반복** - 처음부터 다시 시작합니다. 사이니지 반복 재생, 공지, 카운트다운에 좋습니다.
   - **교사가 진행** - 슬라이드는 교사의 리모컨을 기다립니다. 마지막 슬라이드까지 수업이 종료 시각을 넘어서도 계속 표시됩니다.
   - **한 번 재생한 뒤 기본 반복 재생으로 돌아가기**
5. 반복 일정이라면 **시작일**을 첫 날짜로 설정합니다. **종료**에서는 **없음**을 고르거나, **날짜 지정**을 고른 다음 **종료일**을 입력합니다.
6. **저장**을 클릭합니다.

:::info
**교사가 진행**은 이전의 "마지막 슬라이드 유지" 옵션을 대체했습니다. 그 옵션으로 저장된 일정은 이제 교사가 진행하는 일정으로 재생됩니다.
:::

## 일정 편집하거나 삭제하기 {#editing-or-deleting-a-schedule}

1. 달력에서 일정의 블록을 클릭합니다.
2. 원하는 항목을 바꾸고 **저장**을 클릭하거나, **삭제**를 클릭하여 일정을 지웁니다.

## 겹치는 일정 {#overlapping-schedules}

두 일정이 겹치면 양식에 경고가 표시됩니다. **다른 일정과 겹칩니다. 나중에 시작하는 일정이 우선합니다.** 나중 일정이 진행되는 동안에는 화면이 그 일정을 재생합니다. 나중 일정이 끝나고 앞선 일정이 아직 진행 중이라면, 화면은 앞선 일정으로 돌아갑니다.

## 화면이 변경 사항을 가져오는 방법 {#how-screens-pick-up-changes}

페어링된 화면은 앞으로 7일 동안 예약된 모든 내용을 내려받으며, 스스로 변경 사항을 확인합니다. 달력을 수정한 후에 TV를 직접 건드릴 필요는 없습니다. 화면이 필요한 자료를 모두 갖추었는지 확인하려면 [화면 페이지](./managing-screens.md)의 **다음 날짜까지 준비됨**을 확인하세요.
