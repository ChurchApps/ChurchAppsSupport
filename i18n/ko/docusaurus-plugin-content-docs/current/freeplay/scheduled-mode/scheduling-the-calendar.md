# 캘린더 예약하기

<div class="article-intro">

FreePlay Admin의 **Calendar** 페이지에서 각 화면 그룹이 무엇을 언제 재생할지 정합니다. 재생 목록, 예배 계획, 또는 제공자 폴더에 대한 일정을 추가하고, 매주 반복하거나 한 번만 재생하도록 설정할 수 있습니다. 예약된 내용이 없으면 그룹의 기본 루프가 재생됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 화면 그룹을 최소 하나 만드세요. [화면 및 그룹 관리하기](./managing-screens#screen-groups)를 참고하세요
- [재생 목록을 만들거나](./building-playlists), B1 Admin에 계획 유형이 설정되어 있어야 합니다

</div>

## 캘린더 읽기

1. **Calendar**로 이동합니다.
2. 상단 탭에서 화면 그룹을 고릅니다. 각 탭에는 그룹에 있는 일정 개수가 표시됩니다.
3. 주간 보기는 월요일부터 일요일까지, 오전 6시부터 오후 10시까지 표시됩니다. 현재 시각은 빨간 선으로 표시됩니다.
4. 화살표를 사용해 이전 주나 다음 주로 이동하거나, **Today**를 클릭해 이번 주로 돌아옵니다.

페이지 부제목에는 캘린더가 사용하는 시간대가 표시됩니다. 일정은 교회의 시간대를 따르며, 이 시간대는 B1 Admin의 [교회 정보](../../b1-admin/settings/church-settings.md#time-zone)에서 설정합니다. 교회에 시간대가 설정되어 있지 않으면 FreePlay는 캠퍼스의 시간대를 사용합니다. 캘린더와 TV는 같은 시간대를 사용하므로, 캘린더에서 오전 9시에 배치한 블록은 컴퓨터의 시간대가 다르더라도 화면에서 오전 9시에 재생됩니다.

일정은 유형별로 색상이 구분됩니다. 범례에서 색상을 확인할 수 있습니다.

- **기본 루프** - 그룹에 기본 루프가 있으면 모든 항목 뒤에 표시되는 빗금 배경입니다
- **재생 목록**
- **예배 계획**
- **제공자 폴더**

각 블록에는 이름이 표시되며, 높이가 큰 블록에는 시간, 반복 여부(**weekly** 또는 **once**), 콘텐츠가 일찍 끝날 때의 동작도 함께 표시됩니다.

## 기본 루프 설정하기

기본 루프는 예약된 내용이 없을 때 그룹의 화면에서 재생됩니다.

1. **Calendar** 페이지에서 헤더의 **Default loop…**를 클릭합니다. 이미 기본 루프가 설정되어 있다면 버튼에는 **Default loop:** 뒤에 재생 목록 이름이 표시됩니다.
2. **Playlist**를 고르거나, **None — screen goes dark**(화면 꺼짐)를 고릅니다.
3. **Save**를 클릭합니다.

## 일정 추가하기

새 일정을 시작하는 방법은 세 가지입니다.

- 캘린더의 빈 칸을 클릭합니다. 해당 요일과 30분 단위 시각이 이미 채워진 상태로 양식이 열립니다.
- 헤더의 **Add schedule**을 클릭합니다.
- 명령 팔레트(**Ctrl+K** 또는 **⌘K**)에서 **Add schedule**을 선택합니다.

그다음 양식을 채웁니다.

1. **Play** - 무엇을 재생할지 고릅니다.
   - **Playlists** - 만들어 둔 재생 목록 중 아무거나 고를 수 있습니다
   - **Service plans** - B1 Admin의 계획 유형으로, **(current plan)**이 표시됩니다. 화면은 매주 그 계획 유형의 현재 계획을 재생합니다. 여기에는 Go Curriculum 수업(직접 수정한 수업 포함)도 포함되며, 이때는 계획 유형의 사역에 연결된 Go 로그인을 사용합니다
   - **Provider folder…** - **Choose a provider folder**가 열립니다. 폴더를 찾아 들어가 **Use this folder**를 클릭합니다. 나중에 다른 폴더를 고르려면 **Change**를 클릭합니다
2. **Repeats** - 이 일정을 재생할 요일을 선택합니다. 특정 날짜 하나만 재생하려면 **One time**을 켜고 **Date**를 고릅니다.
3. **Start**와 **End** - 일정이 시작하고 끝나는 시각입니다.
4. **If it finishes early** - 종료 시각 전에 콘텐츠가 먼저 끝날 때 할 일입니다.
   - **Loop until the end time** - 처음부터 다시 시작합니다. 안내 화면 루프, 공지, 카운트다운에 적합합니다
   - **Teacher paced** - 슬라이드가 교사의 리모컨을 기다립니다. 마지막 슬라이드까지 수업 화면이 종료 시각을 넘어 유지됩니다
   - **Play once, then go back to the default loop** - 한 번 재생한 뒤 기본 루프로 돌아갑니다
5. 반복 일정이라면 **Starts**에 첫 날짜를 설정합니다. **Ends** 아래에서 **Never**를 고르거나, **On date**를 고르고 **End date**를 입력합니다.
6. **Save**를 클릭합니다.

:::info
**Teacher paced**가 이전의 "마지막 슬라이드 유지" 옵션을 대체했습니다. 그 옵션으로 저장된 일정은 이제 Teacher paced로 재생됩니다.
:::

## 일정 편집 또는 삭제하기

1. 캘린더에서 일정의 블록을 클릭합니다.
2. 원하는 항목을 바꾸고 **Save**를 클릭하거나, **Delete**를 클릭해 일정을 삭제합니다.

## 겹치는 일정

두 일정이 겹치면 양식에 경고가 표시됩니다. **Overlaps another schedule. The one that starts later wins.**(다른 일정과 겹칩니다. 나중에 시작하는 일정이 우선합니다.) 나중 일정이 진행되는 동안에는 화면이 그 일정을 재생합니다. 나중 일정이 끝나고 앞선 일정이 아직 진행 중이라면, 화면은 앞선 일정으로 돌아갑니다.

## 화면이 변경 사항을 가져오는 방식

페어링된 화면은 앞으로 7일 동안 예약된 모든 내용을 내려받고, 스스로 변경 사항이 있는지 확인합니다. 캘린더를 수정한 뒤 TV를 직접 만질 필요는 없습니다. 화면이 필요한 내용을 모두 받았는지 확인하려면 [화면 페이지](./managing-screens)의 **Ready through**를 보세요.
