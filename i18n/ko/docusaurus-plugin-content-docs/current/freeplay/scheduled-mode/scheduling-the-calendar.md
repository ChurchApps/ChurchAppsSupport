# 달력 예약하기 {#scheduling-the-calendar}

<div class="article-intro">

FreePlay Admin의 **달력** 페이지는 각 화면 그룹이 무엇을 언제 재생할지 제어합니다. 재생목록, 예배 계획, 또는 제공자 폴더에 대한 일정을 추가하고, 매주 반복하거나 한 번만 재생하도록 설정하세요. 예약된 내용이 없으면 그룹의 기본 반복이 재생됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 화면 그룹을 하나 이상 만드세요. [화면과 그룹 관리하기](./managing-screens#screen-groups)를 참조하세요.
- [재생목록을 만들거나](./building-playlists), B1 Admin에서 계획 유형을 설정해 두세요.

</div>

## 달력 읽기 {#reading-the-calendar}

1. **달력**으로 이동합니다.
2. 상단 탭에서 화면 그룹을 고릅니다. 각 탭에는 그 그룹의 일정 수가 표시됩니다.
3. 주 보기는 월요일부터 일요일까지, 오전 6시부터 오후 10시까지입니다. 빨간 선은 현재 시각을 나타냅니다.
4. 화살표로 이전 주나 다음 주로 이동하거나, **오늘**을 클릭하여 이번 주로 돌아오세요.

페이지 부제목에는 달력이 사용하는 시간대가 표시됩니다. 일정은 교회의 시간대를 따르며, 이는 B1 Admin의 [교회 정보](../../b1-admin/settings/church-settings.md#time-zone)에서 설정합니다. 교회에 시간대가 설정되어 있지 않다면 FreePlay는 캠퍼스의 시간대를 사용합니다. 달력과 TV는 같은 시간대를 사용하므로, 컴퓨터가 다른 시간대로 설정되어 있더라도 달력에서 오전 9:00에 놓은 블록은 화면에서도 오전 9:00에 재생됩니다.

일정은 유형별로 색상이 구분됩니다. 범례에서 색상을 설명합니다.

- **기본 반복** - 빗금 배경. 그룹에 기본 반복이 있으면 모든 것 뒤에 표시됩니다.
- **재생목록**
- **예배 계획**
- **제공자 폴더**

각 블록에는 이름이 표시되며, 높이가 큰 블록에는 시간, 반복 여부(**매주** 또는 **한 번**), 그리고 일찍 끝났을 때의 동작도 함께 표시됩니다.

## 기본 반복 설정하기 {#setting-the-default-loop}

기본 반복은 예약된 내용이 없을 때마다 그룹의 화면에서 재생됩니다.

1. **달력** 페이지에서 머리글의 **기본 반복…**을 클릭합니다. 이미 기본 반복이 설정되어 있다면 버튼에는 **기본 반복:** 뒤에 재생목록 이름이 표시됩니다.
2. **재생목록**을 고르거나, **없음 — 화면 끄기**를 고릅니다.
3. **저장**을 클릭합니다.

## 일정 추가하기 {#adding-a-schedule}

새 일정을 시작하는 방법은 세 가지입니다.

- 달력의 빈 곳을 클릭합니다. 그 날짜와 30분 단위 시각이 이미 채워진 양식이 열립니다.
- 머리글의 **일정 추가**를 클릭합니다.
- 명령 팔레트(**Ctrl+K** 또는 **⌘K**)에서 **일정 추가**를 고릅니다.

그다음 양식을 채웁니다.

1. **재생** - 재생할 내용을 고릅니다.
   - **재생목록** - 만든 재생목록 중 아무거나
   - **예배 계획** - B1 Admin의 계획 유형. **(현재 계획)**으로 표시됩니다. 화면은 매주 그 계획 유형의 현재 계획을 재생합니다. 사용자 지정한 공과를 포함한 Go Curriculum 공과도 여기에 포함되며, 이때는 계획 유형의 사역에 연결된 Go 로그인을 사용합니다.
   - **제공자 폴더…** - **제공자 폴더 선택**을 엽니다. 폴더로 이동한 다음 **이 폴더 사용**을 클릭하세요. 나중에 다른 폴더를 고르려면 **변경**을 클릭합니다.
2. **반복** - 이 일정이 재생될 요일을 선택합니다. 대신 특정 날짜 하나에만 재생하려면 **한 번**을 켜고 **날짜**를 고르세요.
3. **시작**과 **종료** - 일정이 시작하고 멈출 시각입니다.
4. **일찍 끝나면** - 종료 시각 전에 내용이 끝났을 때의 동작입니다.
   - **종료 시각까지 반복** - 처음부터 다시 시작합니다. 사이니지 반복, 공지, 카운트다운에 좋습니다.
   - **교사 진행** - 슬라이드는 교사의 리모컨을 기다립니다. 마지막 슬라이드까지 공과는 종료 시각을 넘어서도 떠 있습니다.
   - **한 번 재생한 뒤 기본 반복으로 돌아가기**
5. 반복 일정이라면 **시작** 날짜를 첫 날짜로 설정합니다. **종료** 아래에서 **없음**을 고르거나, **날짜 지정**을 고르고 **종료 날짜**를 입력합니다.
6. **저장**을 클릭합니다.

:::info
**교사 진행**은 이전의 "마지막 슬라이드 유지" 옵션을 대체했습니다. 그 옵션으로 저장된 일정은 이제 교사 진행으로 재생됩니다.
:::

## 일정 편집하거나 삭제하기 {#editing-or-deleting-a-schedule}

1. 달력에서 일정의 블록을 클릭합니다.
2. 원하는 필드를 바꾸고 **저장**을 클릭하거나, **삭제**를 클릭하여 일정을 제거합니다.

## 겹치는 일정 {#overlapping-schedules}

두 일정이 겹치면 양식에 경고가 표시됩니다. **다른 일정과 겹칩니다. 나중에 시작하는 일정이 우선합니다.** 나중의 일정이 실행되는 동안에는 화면이 그 일정을 재생합니다. 그 일정이 끝나면, 이전 일정이 아직 진행 중이라면 화면은 이전 일정으로 돌아갑니다.

## 화면이 변경 사항을 가져오는 방식 {#how-screens-pick-up-changes}

페어링된 화면은 앞으로 7일 동안 예약된 모든 내용을 내려받으며, 스스로 변경 사항을 확인합니다. 달력을 편집한 뒤에 TV를 만질 필요는 없습니다. 화면이 필요한 것을 모두 갖추었는지 보려면 [화면 페이지](./managing-screens)의 **다음까지 준비됨**을 확인하세요.
