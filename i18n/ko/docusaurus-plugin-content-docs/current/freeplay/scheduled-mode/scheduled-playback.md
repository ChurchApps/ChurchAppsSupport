# TV에서의 예약 재생

<div class="article-intro">

TV가 캘린더에 페어링되면 FreePlay가 대신 실행합니다. 향후 일주일 치 콘텐츠를 다운로드하고, 예정된 시간에 콘텐츠를 전환하며, 인터넷이 끊어져도 자체 저장소에서 계속 재생합니다. 교사나 봉사자는 여전히 TV 리모컨으로 일시정지, 건너뛰기, 이동을 할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [TV를 캘린더에 페어링](./pairing-a-screen)하십시오
- [캘린더에 콘텐츠를 배치](./scheduling-the-calendar)하거나, 화면의 그룹에 기본 루프를 설정하십시오

</div>

## TV가 스스로 하는 일

- **바로 일정으로 열림** - 페어링된 TV에서 FreePlay를 시작하면 예약 플레이어로 바로 이동합니다
- **미리 다운로드** - FreePlay는 향후 7일 동안 예약된 모든 파일과 기본 루프를 다운로드하고, 그 다운로드된 파일로 재생합니다
- **시계에 따라 재생** - 예약된 각 시작 시간에 화면이 해당 콘텐츠로 전환됩니다. 예약된 항목이 없으면 그룹의 기본 루프를 재생합니다
- **변경 사항 확인** - FreePlay는 주기적으로 FreePlay Admin에서 캘린더 변경 사항을 확인하고 새 항목을 다운로드합니다
- **잘못된 파일 복구** - 다운로드한 파일이 재생되지 않으면 FreePlay가 해당 파일을 건너뛰고 다시 다운로드합니다

첫 번째 파일이 도착하기 전에는 화면에 **일정 불러오는 중...** 또는 **X / Y 파일 다운로드 중**이 표시됩니다. 예약된 항목이 없고 그룹에 기본 루프가 없으면 **지금 예약된 항목이 없습니다**가 표시됩니다.

## 정보 패널

리모컨의 **선택**을 누르면 정보 패널이 열립니다. 몇 초 후 자동으로 닫힙니다. 패널에는 다음이 표시됩니다:

- **오른쪽 위** - 해당 날짜까지 모든 항목이 다운로드되었을 때는 **다음까지 준비됨**과 날짜가 표시되고, 파일이 여전히 들어오는 중이면 **다운로드 중**이 표시됩니다. 그 아래에는 다운로드된 파일 수와 진행률 표시줄이 나타납니다
- **왼쪽 아래** - 재생 중인 항목의 이름(또는 **기본 루프**), 현재 화면에 있는 항목, 그리고 다음에 재생될 항목과 시간
- **마지막 확인** - FreePlay가 마지막으로 일정 변경 사항을 확인한 시간

패널에는 세 개의 버튼도 있습니다:

- **이 재생 목록 고정** - 현재 콘텐츠를 루프로 계속 재생하고 캘린더는 무시합니다. 일정으로 돌아가려면 **재생 목록 고정 해제**를 선택하십시오
- **콘텐츠 찾아보기** - 예약 플레이어를 벗어나 연결된 제공자를 찾아봅니다
- **설정** - FreePlay 설정을 엽니다. 여기에서 [페어링을 해제하거나 다른 캘린더에 페어링](./pairing-a-screen#changing-or-unpairing-from-the-tv)할 수 있습니다

:::tip
콘텐츠를 찾아본 후 일정으로 돌아가려면 FreePlay를 닫았다가 다시 여십시오. 페어링된 TV는 항상 예약 플레이어로 열립니다.
:::

## 리모컨 조작

| 리모컨 버튼 | 동작 |
|---|---|
| **선택** | 정보 패널 열기 |
| **재생/일시정지** | 일시정지 또는 재개. 일시정지 중에는 재생 아이콘이 표시됩니다 |
| **오른쪽 화살표** | 다음 슬라이드 또는 비디오 |
| **왼쪽 화살표** | 이전 슬라이드 또는 비디오 |
| **위쪽 화살표** | 슬라이드 개요를 열어 원하는 슬라이드로 이동 |
| **빨리 감기** | 비디오에서 10초 앞으로 이동 |
| **되감기** | 비디오에서 10초 뒤로 이동 |
| **뒤로** | 슬라이드 개요 또는 정보 패널 닫기, 또는 정보 패널 열기 |

다음 및 이전 이동은 현재 재생 중인 콘텐츠 안에서만 이루어집니다. 일정이 반복 재생으로 설정된 경우에만 마지막 항목에서 첫 번째 항목으로 돌아갑니다. 빨리 감기와 되감기는 비디오 재생 중에만 작동합니다. 슬라이드에서는 아무 작업도 하지 않습니다.

### 슬라이드로 이동하기

**위쪽**을 눌러 슬라이드 개요를 엽니다. 현재 재생 목록이나 레슨의 모든 항목이 표시됩니다. 원하는 항목으로 이동한 다음 **선택**을 누르면 바로 그곳으로 이동합니다.

## 교사 진행 레슨

일정이 **교사 진행**으로 설정되면 이미지 슬라이드는 자동으로 넘어가지 않습니다. 교사가 **오른쪽 화살표**로 다음으로 넘깁니다. 비디오는 끝까지 재생된 다음 다음 항목으로 넘어갑니다.

교사 진행 레슨은 교사가 마지막 슬라이드에 도달하여 끝날 때까지 예약된 종료 시간을 지나도 화면에 계속 표시됩니다. 그 후에 화면은 다음 예정된 항목으로 넘어갑니다. 이렇게 하면 시간이 길어진 수업이 레슨 중간에 끊기지 않습니다.

## 브라우저에서 프레젠테이션하기 {#presenting-from-a-browser}

화면의 캘린더를 웹 브라우저에서 재생할 수도 있습니다. FreePlay Admin에서 **화면** 페이지의 화면을 연 다음 **브라우저에서 프레젠테이션**을 클릭하십시오. 브라우저는 TV와 같은 방식으로 해당 화면의 캘린더를 따르며, 컨트롤 막대에는 다음에 재생될 항목이 표시됩니다. **스페이스**로 일시정지, **←** / **→**로 건너뛰기, **F**로 전체 화면, **Esc**로 종료할 수 있습니다.
