# TV에서 일정에 따라 재생하기

<div class="article-intro">

TV가 일정표에 페어링되면 FreePlay가 알아서 실행합니다. 앞으로 일주일 치를 내려받고, 예약된 시각에 콘텐츠를 바꾸며, 인터넷이 끊기면 자체 저장소에서 계속 재생합니다. 교사나 봉사자는 여전히 TV 리모컨으로 일시 정지하고, 건너뛰고, 여기저기 이동할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [TV를 일정표에 페어링](./pairing-a-screen)하세요.
- [일정표에 무엇인가 넣거나](./scheduling-the-calendar), 화면의 그룹에 기본 반복 재생을 설정하세요.

</div>

## TV가 스스로 하는 일

- **일정 화면으로 바로 열림** - 페어링된 TV가 FreePlay를 시작하면 곧장 일정 재생 화면으로 갑니다.
- **미리 내려받음** - FreePlay는 앞으로 7일 동안 예약된 모든 파일과 기본 반복 재생 파일을 내려받고, 그 내려받은 파일에서 재생합니다.
- **시계에 맞춰 재생** - 예약된 각 시작 시각에 화면이 그 콘텐츠로 바뀝니다. 예약된 것이 없으면 그룹의 기본 반복 재생을 재생합니다.
- **변경 확인** - FreePlay는 주기적으로 FreePlay Admin에서 일정표 변경을 확인하고, 새로운 것은 내려받습니다.
- **잘못된 파일 수정** - 내려받은 파일이 재생되지 않으면 FreePlay가 건너뛰고 다시 내려받습니다.

첫 파일이 도착하기 전까지 화면에는 **Loading schedule...** 또는 **Downloading X of Y files**가 표시됩니다. 예약된 것이 없고 그룹에 기본 반복 재생도 없으면 **Nothing is scheduled right now**가 표시됩니다.

## 정보 패널

리모컨의 **Select**를 누르면 정보 패널이 열립니다. 몇 초 뒤 자동으로 닫힙니다. 패널에는 다음이 나타납니다.

- **오른쪽 위** - 그 날짜까지 모든 것이 내려받아졌을 때는 **Ready through**와 날짜가, 파일이 아직 들어오고 있을 때는 **Downloading**이 표시됩니다. 그 아래에는 내려받은 파일 수와 진행률 막대가 있습니다.
- **왼쪽 아래** - 재생 중인 항목의 이름(또는 **Default loop**), 화면에 있는 항목, 다음에 올 항목과 그 시각이 표시됩니다.
- **Last checked** - FreePlay가 마지막으로 일정 변경을 확인한 시각입니다.

패널에는 버튼 세 개도 있습니다.

- **Pin This Playlist** - 현재 콘텐츠를 반복 재생으로 고정하고 일정표는 무시합니다. 일정으로 돌아가려면 **Unpin Playlist**를 선택하세요.
- **Browse Content** - 예약된 재생 화면을 떠나 연결된 제공업체를 둘러봅니다.
- **Settings** - FreePlay 설정을 엽니다. 여기서 [페어링을 해제하거나 다른 일정표에 페어링](./pairing-a-screen#changing-or-unpairing-from-the-tv)할 수 있습니다.

:::tip
둘러본 뒤 일정으로 돌아가려면 **Content Providers** 화면에서 리모컨의 **Back**을 누르거나, **Settings**를 열고 **Pair to a calendar**를 선택한 뒤 **Back to schedule**을 고르세요. 페어링된 TV는 FreePlay가 다시 앞으로 올라올 때마다 예약된 재생 화면으로 돌아가며, 항상 예약된 재생 화면으로 열립니다.
:::

## 리모컨 조작

| 리모컨 버튼 | 동작 |
|---|---|
| **Select** | 정보 패널 열기 |
| **Play/Pause** | 일시 정지 또는 재개. 일시 정지 중에는 재생 아이콘이 나타납니다 |
| **오른쪽 화살표** | 다음 슬라이드 또는 동영상 |
| **왼쪽 화살표** | 이전 슬라이드 또는 동영상 |
| **위 화살표** | 슬라이드 개요를 열어 원하는 슬라이드로 이동 |
| **Fast Forward** | 동영상에서 10초 앞으로 |
| **Rewind** | 동영상에서 10초 뒤로 |
| **Back** | 슬라이드 개요나 정보 패널을 닫거나, 정보 패널을 엽니다 |

다음과 이전 이동은 지금 재생 중인 콘텐츠 안에서만 머무릅니다. 일정이 반복으로 설정된 경우에만 마지막 항목에서 첫 항목으로 돌아갑니다. Fast Forward와 Rewind는 동영상이 재생 중일 때만 작동합니다. 슬라이드에서는 아무 동작도 하지 않습니다.

### 슬라이드로 이동하기

**위**를 눌러 슬라이드 개요를 엽니다. 현재 재생 목록이나 수업의 모든 항목이 표시됩니다. 원하는 항목으로 이동한 뒤 **Select**를 누르면 바로 그곳으로 갑니다.

## 교사 진행 수업

일정이 **Teacher paced**로 설정되어 있으면, 이미지 슬라이드는 스스로 넘어가지 않습니다. 교사가 **오른쪽 화살표**로 앞으로 넘깁니다. 동영상은 끝까지 재생된 뒤 다음 항목으로 넘어갑니다.

교사 진행 수업은 마지막 슬라이드에 도달하여 끝날 때까지 예약된 종료 시각을 지나도 화면에 남아 있습니다. 그 뒤 화면은 다음에 예약된 것으로 넘어갑니다. 길어진 수업이 수업 도중에 잘리지 않도록 하기 위해서입니다.

## 브라우저에서 프레젠테이션하기

화면의 일정을 웹 브라우저에서도 재생할 수 있습니다. FreePlay Admin에서 **Screens** 페이지의 화면을 열고 **Present in browser**를 클릭하세요. 브라우저는 TV와 같은 방식으로 그 화면의 일정을 따르며, 컨트롤 막대가 다음에 올 항목을 보여 줍니다. **Space**로 일시 정지하고, **←** / **→**로 건너뛰며, **F**로 전체 화면, **Esc**로 종료합니다.
