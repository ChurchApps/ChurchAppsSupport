# TV에서 예약 재생하기

<div class="article-intro">

TV가 캘린더에 연결되면 FreePlay가 알아서 재생합니다. 다가오는 한 주의 콘텐츠를 다운로드하고, 예약된 시간에 맞춰 콘텐츠를 바꾸며, 인터넷이 끊겨도 기기 저장 공간에서 계속 재생합니다. 교사나 봉사자는 여전히 TV 리모컨으로 일시 정지하거나, 건너뛰거나, 원하는 위치로 이동할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [TV를 캘린더에 연결](./pairing-a-screen.md)하세요.
- [캘린더에 콘텐츠를 예약](./scheduling-the-calendar.md)하거나, 화면 그룹의 기본 반복 재생을 설정하세요.

</div>

## TV가 스스로 하는 일

- **바로 예약 화면 열기** -- 연결된 TV에서 FreePlay를 시작하면 예약 재생 화면으로 바로 이동합니다.
- **미리 다운로드하기** -- FreePlay는 앞으로 7일 동안 예약된 모든 파일과 기본 반복 재생 콘텐츠를 다운로드하고, 다운로드한 파일에서 재생합니다.
- **시간에 맞춰 재생하기** -- 예약된 시작 시간이 되면 화면이 해당 콘텐츠로 바뀝니다. 예약된 내용이 없으면 그룹의 기본 반복 재생 콘텐츠를 재생합니다.
- **변경 사항 확인하기** -- FreePlay는 주기적으로 FreePlay Admin에서 캘린더 변경 사항을 확인하고 새로운 내용을 다운로드합니다.
- **잘못된 파일 고치기** -- 다운로드한 파일이 재생되지 않으면 FreePlay가 그 파일을 건너뛰고 다시 다운로드합니다.

첫 번째 파일이 도착하기 전에는 화면에 **Loading schedule...** 또는 **Downloading X of Y files**가 표시됩니다. 예약된 내용이 없고 그룹에 기본 반복 재생 콘텐츠도 없다면 **Nothing is scheduled right now**가 표시됩니다.

## 정보 패널

리모컨의 **Select**를 누르면 정보 패널이 열립니다. 패널은 몇 초 후 자동으로 닫힙니다. 패널에는 다음 정보가 표시됩니다.

- **오른쪽 위** -- 해당 날짜까지 모든 콘텐츠가 다운로드되었을 때 **Ready through**와 날짜가 표시되고, 파일이 아직 도착하는 중이면 **Downloading**이 표시됩니다. 그 아래에는 다운로드된 파일 수와 진행 막대가 나타납니다.
- **왼쪽 아래** -- 재생 중인 콘텐츠의 이름(또는 **Default loop**), 화면에 표시된 항목, 다음에 재생될 내용과 시간이 표시됩니다.
- **Last checked** -- FreePlay가 마지막으로 예약 변경 사항을 확인한 시간입니다.

패널에는 버튼 세 개도 있습니다.

- **Pin This Playlist** -- 캘린더를 무시하고 현재 콘텐츠를 반복 재생합니다. 예약 재생으로 돌아가려면 **Unpin Playlist**를 선택하세요.
- **Browse Content** -- 예약 재생 화면을 떠나 연결된 제공자의 콘텐츠를 찾아볼 수 있습니다.
- **Settings** -- FreePlay 설정을 엽니다. 여기서 [연결을 해제하거나 다른 캘린더에 연결](./pairing-a-screen.md#changing-or-unpairing-from-the-tv)할 수 있습니다.

:::tip
콘텐츠를 찾아본 뒤 예약 재생으로 돌아가려면, **Content Providers** 화면에서 리모컨의 **Back**을 누르거나, **Settings**를 열고 **Pair to a calendar**를 선택한 뒤 **Back to schedule**을 고르세요. 연결된 TV는 FreePlay가 다시 앞으로 올라올 때마다 예약 재생 화면으로 돌아오며, 항상 예약 재생 화면으로 열립니다.
:::

## 리모컨 조작

| 리모컨 버튼 | 동작 |
|---|---|
| **Select** | 정보 패널 열기 |
| **Play/Pause** | 일시 정지 또는 재개. 일시 정지 중에는 재생 아이콘이 표시됨 |
| **오른쪽 화살표** | 다음 슬라이드 또는 영상 |
| **왼쪽 화살표** | 이전 슬라이드 또는 영상 |
| **위쪽 화살표** | 슬라이드 개요를 열어 원하는 슬라이드로 이동 |
| **Fast Forward** | 영상에서 10초 앞으로 이동 |
| **Rewind** | 영상에서 10초 뒤로 이동 |
| **Back** | 슬라이드 개요나 정보 패널 닫기, 또는 정보 패널 열기 |

다음 및 이전 이동은 지금 재생 중인 콘텐츠 안에서만 이루어집니다. 예약이 반복 재생으로 설정된 경우에만 마지막 항목에서 처음 항목으로 돌아갑니다. Fast Forward와 Rewind는 영상 재생 중에만 작동하며, 슬라이드에서는 아무 동작도 하지 않습니다.

### 슬라이드로 이동하기

**위쪽**을 누르면 슬라이드 개요가 열립니다. 현재 재생 목록이나 공과의 모든 항목이 표시됩니다. 원하는 항목으로 이동한 뒤 **Select**를 누르면 바로 그 위치로 이동합니다.

## 교사 진행 공과

예약을 **Teacher paced**로 설정하면 이미지 슬라이드는 자동으로 넘어가지 않습니다. 교사가 **오른쪽 화살표**로 다음 슬라이드로 넘깁니다. 영상은 끝까지 재생된 뒤 다음 항목으로 넘어갑니다.

교사 진행 공과는 예약된 종료 시간이 지나도 교사가 마지막 슬라이드에 도달해 끝날 때까지 화면에 계속 남아 있습니다. 그 뒤에 예약된 다음 콘텐츠로 넘어갑니다. 그래서 수업이 길어져도 공과 중간에 화면이 끊기지 않습니다.

## 브라우저에서 발표하기 {#presenting-from-a-browser}

화면의 캘린더를 웹 브라우저에서 재생할 수도 있습니다. FreePlay Admin의 **Screens** 페이지에서 화면을 열고 **Present in browser**를 클릭하세요. 브라우저는 TV와 같은 방식으로 해당 화면의 캘린더를 따르며, 조작 막대에 다음에 재생될 내용이 표시됩니다. **Space**로 일시 정지, **←** / **→**로 건너뛰기, **F**로 전체 화면, **Esc**로 종료할 수 있습니다.
