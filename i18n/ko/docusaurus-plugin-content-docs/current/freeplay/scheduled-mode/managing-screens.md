# 화면 및 그룹 관리

<div class="article-intro">

FreePlay Admin의 **Screens** 페이지에는 교회에 연결된 모든 TV가 나열되며, 각 TV가 지금 무엇을 재생하는지와 주일 준비가 되었는지 보여줍니다. 여기서 **화면 그룹**도 관리합니다. 같은 그룹의 화면은 하나의 캘린더와 하나의 기본 반복 재생 목록을 공유합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [admin.freeplay.church](https://admin.freeplay.church)에서 FreePlay Admin에 로그인하십시오
- [화면을 한 개 이상 연결](./pairing-a-screen)하십시오

</div>

## Screens 페이지

화면 상단의 세 가지 숫자로 상태를 빠르게 확인할 수 있습니다:

- **Online now** - 지난 15분 안에 연결 확인을 한 화면
- **Ready for Sunday** - 이번 주일까지 모든 파일을 다운로드한 예약 화면의 수
- **Needs attention** - 오프라인이거나 파일이 없는 화면

그 아래의 **Search screens**로 이름, 그룹, 또는 재생 중인 내용으로 화면을 찾습니다. 필터 칩으로 목록을 **All**, **Scheduled**, **Manual**, **Needs attention**, 또는 특정 그룹으로 좁힐 수 있습니다. 오른쪽의 토글로 **Table** 보기와 **Grid** 보기를 전환합니다.

각 화면에는 다음이 표시됩니다:

- **Label**(이름)과 기기 모델
- **Group**(그룹)
- **Mode**(모드) - **Scheduled**(예약) 또는 **Manual**(수동)
- **Now playing**(지금 재생 중) - 지금 화면에 나오는 내용. 수동 화면은 **Classroom · teacher presses Start**로 표시됩니다
- **Ready through**(다음까지 준비됨) - 화면이 다운로드를 마친 날짜. 파일을 다운로드하지 못했다면 대신 **N files missing**(파일 N개 없음)이 표시됩니다. 새 화면에는 **Waiting for first sync**(첫 동기화 대기 중)가 표시됩니다
- **Last seen**(마지막 확인) - 화면이 마지막으로 연결 확인을 한 시각. 한동안 연결 확인을 하지 않은 화면은 **Offline**(오프라인), 한 번도 연결되지 않은 화면은 **Never seen**(연결 기록 없음)으로 표시됩니다

**Present**를 사용하면 브라우저에서 화면의 캘린더를 재생하고, **Edit**를 사용하면 설정을 변경할 수 있습니다.

## 화면 보기

화면의 이름을 클릭하면 화면 페이지가 열립니다. 왼쪽에는 다음이 있습니다:

- **Present in browser** - TV에 나오는 모습 그대로 이 화면의 캘린더를 브라우저에서 전체 화면으로 재생합니다. [브라우저에서 보여주기](./scheduled-playback#presenting-from-a-browser)를 참조하십시오
- **Edit** - 이름, 그룹, 또는 모드를 변경합니다
- **More** > **Unpair** - TV 연결을 해제합니다. TV는 다시 연결 코드를 표시합니다

페이지의 나머지 부분은 다음 섹션으로 구성됩니다:

- **Now and next**(지금과 다음) - 지금 재생 중인 내용과 그 종료 시각, 이어서 다음 7일 동안 예약된 모든 내용. **Open calendar**를 클릭하면 이 그룹의 캘린더로 이동합니다
- **Downloads**(다운로드) - 모든 내용이 다운로드된 경우 **Ready through**와 날짜, 또는 없는 파일 목록
- **Device**(기기) - 기기 ID, 플랫폼, 모델, FreePlay 앱 버전, IP 주소, 사용 중 및 남은 저장 공간, 마지막 연결 시각, 모드
- **Recent**(최근) - 화면이 보고한 최근 활동

:::tip
화면에 파일이 없다고 표시되면 온라인 상태인지, 저장 공간이 남아 있는지 확인하십시오. TV는 다음 연결 확인 때 없는 파일을 스스로 다운로드합니다.
:::

## 화면 편집하기

1. 화면 옆이나 화면 페이지에서 **Edit**를 클릭합니다.
2. **Label**, **Group**, 또는 **Mode**(**Scheduled** 또는 **Manual**)를 변경합니다.
3. **Save**를 클릭합니다.

화면을 다른 그룹으로 옮기면 그 그룹의 캘린더로 바뀝니다.

## 화면 그룹 {#screen-groups}

화면 그룹은 같은 시간에 같은 내용을 재생하는 화면들의 모음으로, 예를 들어 "Lobby"(로비)나 "Kids Wing"(어린이 구역)과 같습니다. 각 그룹은 자체 캘린더를 가지며, 아무것도 예약되어 있지 않을 때 재생되는 **기본 반복 재생 목록**을 가질 수 있습니다.

그룹을 관리하려면 **Screens** 페이지 상단의 **Groups**를 클릭합니다. **Screen groups** 목록에는 각 그룹의 이름, 화면 수, 기본 반복 재생 목록이 표시됩니다. **Screens**를 클릭하면 돌아갑니다.

### 그룹 추가하기

1. **Screen groups** 보기에서 **Add group**을 클릭합니다.
2. **Name**(이름)을 입력합니다. 예: "Lobby".
3. **Default loop**(기본 반복 재생) 재생 목록을 고르거나 **None — screen goes dark**(없음 - 화면 꺼짐)를 그대로 둡니다.
4. **Save**를 클릭합니다.

화면을 연결하는 동안 **Group** 필드에서 **＋ New group…**을 선택하여 그룹을 만들 수도 있습니다.

### 그룹 편집 및 삭제하기

1. 그룹 옆의 **Edit**를 클릭합니다.
2. 이름이나 기본 반복 재생 목록을 변경한 뒤 **Save**를 클릭합니다.
3. 그룹을 제거하려면 **Delete**를 클릭하고 확인합니다.

:::warning
그룹을 삭제하면 그룹의 예약도 함께 삭제됩니다. 그 그룹의 화면은 다른 그룹으로 옮길 때까지 꺼진 상태가 됩니다.
:::
