# 예약 모드

<div class="article-intro">

예약 모드를 사용하면 FreePlay TV가 스스로 실행됩니다. **FreePlay Admin**([admin.freeplay.church](https://admin.freeplay.church))에서 재생 목록을 만들고 캘린더에 배치합니다. 이 캘린더에 연결된 각 TV는 향후 일주일 치 콘텐츠를 다운로드하고, 누군가 시작 버튼을 누르지 않아도 예정된 시간에 맞춰 예정된 내용을 재생합니다. 파일이 미리 다운로드되어 있으므로 Wi-Fi가 끊어져도 재생은 계속됩니다.

</div>

:::tip
FreePlay Admin은 B1 Admin에서 사용하는 것과 동일한 ChurchApps 로그인을 사용합니다. 별도의 계정을 만들 필요가 없습니다.
:::

## 구성 방식

FreePlay Admin에는 사이트 상단에 나열된 네 개의 주요 페이지가 있습니다:

- **[화면](./managing-screens)** - 페어링된 TV, 상태, 그리고 소속된 **화면 그룹**. 그룹에 속한 화면은 하나의 캘린더와 하나의 기본 루프를 공유합니다
- **[재생 목록](./building-playlists)** - 콘텐츠 제공자에서 선택한 이미지와 비디오의 루프
- **[캘린더](./scheduling-the-calendar)** - 각 화면 그룹이 재생할 내용과 재생 시점
- **[제공자](./building-playlists#connecting-providers)** - 재생 목록이 가져오는 콘텐츠 소스. 교회 전체를 위해 각 제공자를 한 번만 연결합니다

예약된 항목이 없으면 그룹의 화면은 그룹의 **기본 루프**를 재생합니다. 그룹에 기본 루프가 없으면 화면이 꺼집니다.

## 계획 모드와의 차이점

- **[계획 모드](../plan-mode/)**는 B1 Admin의 하나의 예배 계획 유형을 따릅니다. 누군가 TV에서 **계획 시작**을 누르면 그때 레슨이 재생됩니다
- **예약 모드**는 캘린더를 따릅니다. 콘텐츠는 설정한 시간에 시작되고 중지되므로 로비 사이니지, 공지 루프, 그리고 누군가 들어오기 전에 레슨이 표시되어야 하는 교실에 적합합니다

캘린더 항목에서도 예배 계획을 재생할 수 있습니다. 일정을 추가할 때 **예배 계획**에서 계획 유형을 선택하면, 화면은 그 주에 B1 Admin에서 현재 활성화된 계획을 재생합니다.

## 시작하기

다음 각 단계를 완료하기 전까지는 **화면** 페이지에 각 단계별 링크가 있는 **시작하기** 체크리스트가 표시됩니다:

1. **제공자 연결** - **제공자** 페이지에서 Dropbox, OneDrive, Lessons.church 또는 다른 소스를 연결합니다
2. **재생 목록 만들기** - 제공자에서 이미지와 비디오를 선택합니다
3. **캘린더에 배치하기** - 언제 무엇을 재생할지 선택하거나, 그룹의 기본 루프를 설정합니다
4. **화면 페어링** - TV에 표시된 네 자리 코드를 입력합니다

체크리스트를 숨기려면 **숨기기**를 클릭하십시오.

:::tip
**Ctrl+K**(Mac에서는 **⌘K**)를 누르거나 헤더의 검색 상자를 클릭하면 명령 팔레트가 열립니다. 여기에서 모든 페이지로 이동하거나 **화면 페어링**, **재생 목록 추가**, **일정 추가** 같은 작업을 시작할 수 있습니다.
:::
