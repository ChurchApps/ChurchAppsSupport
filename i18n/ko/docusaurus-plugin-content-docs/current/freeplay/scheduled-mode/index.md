# 예약 모드

<div class="article-intro">

예약 모드를 사용하면 FreePlay TV가 스스로 운영됩니다. [admin.freeplay.church](https://admin.freeplay.church)의 **FreePlay Admin**에서 재생 목록을 만들고 캘린더에 배치합니다. 이 캘린더에 연결된 각 TV는 앞으로 일주일 치 콘텐츠를 미리 내려받고, 아무도 시작 버튼을 누르지 않아도 시계에 맞춰 예약된 내용을 재생합니다. 파일이 미리 내려받아져 있으므로, Wi-Fi가 끊겨도 재생은 계속됩니다.

</div>

:::tip
FreePlay Admin은 B1 Admin에서 쓰는 것과 같은 ChurchApps 로그인을 사용합니다. 따로 만들 계정은 없습니다.
:::

## 구성 방식

FreePlay Admin에는 사이트 상단에 나열된 네 개의 주요 페이지가 있습니다.

- **[화면](./managing-screens)** - 페어링된 TV, 상태, 그리고 TV가 속한 **화면 그룹**입니다. 같은 그룹의 화면은 캘린더 하나와 기본 루프 하나를 공유합니다.
- **[재생 목록](./building-playlists)** - 콘텐츠 제공자에서 고른 이미지와 동영상의 반복 목록입니다.
- **[캘린더](./scheduling-the-calendar)** - 각 화면 그룹이 무엇을, 언제 재생할지 정합니다.
- **[제공자](./building-playlists#connecting-providers)** - 재생 목록이 가져오는 콘텐츠 출처입니다. 제공자는 교회 전체를 위해 한 번만 연결하면 됩니다.

예약된 내용이 없으면 그룹의 화면은 **기본 루프**를 재생합니다. 그룹에 기본 루프가 없으면 화면은 꺼진 상태가 됩니다.

## 계획 모드와의 차이

- **[계획 모드](../plan-mode/)**는 B1 Admin의 예배 계획 유형 하나를 따릅니다. 누군가 TV에서 **Start Plan**을 누르면 그때 수업이 재생됩니다.
- **예약 모드**는 캘린더를 따릅니다. 설정한 시각에 콘텐츠가 시작되고 멈추므로, 로비 안내 화면, 공지 루프, 수업 시작 전에 수업 화면이 떠 있어야 하는 교실에 알맞습니다.

캘린더 항목으로도 예배 계획을 재생할 수 있습니다. 일정을 추가할 때 **Service plans**에서 계획 유형을 고르면, 화면은 그 주에 B1 Admin에서 현재 활성화된 계획을 재생합니다. 여기에는 계획에서 직접 수정한 Go Curriculum 수업도 포함됩니다. 화면은 계획 유형의 사역에 연결된 Go Curriculum 로그인을 사용하며, 사역에 연결된 것이 없으면 교회의 Go Curriculum 연결을 사용합니다.

## 시작하기

아래 각 단계를 마치기 전까지 **화면** 페이지에는 각 단계로 가는 링크가 있는 **Get started** 체크리스트가 표시됩니다.

1. **제공자 연결** - **제공자** 페이지에서 Dropbox, OneDrive, Lessons.church 또는 다른 출처를 연결합니다.
2. **재생 목록 만들기** - 제공자에서 이미지와 동영상을 고릅니다.
3. **캘린더에 배치** - 무엇을 언제 재생할지 정하거나, 그룹의 기본 루프를 설정합니다.
4. **화면 페어링** - TV에 표시된 네 글자 코드를 입력합니다.

체크리스트를 숨기려면 **Hide**를 클릭합니다.

:::tip
**Ctrl+K**(Mac에서는 **⌘K**)를 누르거나 헤더의 검색창을 클릭하면 명령 팔레트가 열립니다. 여기서 원하는 페이지로 이동하거나 **Pair screen**, **Add playlist**, **Add schedule** 같은 작업을 시작할 수 있습니다.
:::

## 이 섹션의 내용

- **[화면 페어링하기](./pairing-a-screen)** - TV에 코드를 표시하고 FreePlay Admin에서 페어링합니다
- **[화면 및 그룹 관리하기](./managing-screens)** - 상태와 다운로드를 확인하고, 화면을 그룹으로 정리합니다
- **[제공자 연결 및 재생 목록 만들기](./building-playlists)** - 콘텐츠 출처를 연결하고 이미지와 동영상의 루프를 만듭니다
- **[캘린더 예약하기](./scheduling-the-calendar)** - 무엇을 언제 재생할지, 그리고 콘텐츠가 일찍 끝나면 어떻게 할지 정합니다
- **[TV에서 예약 재생](./scheduled-playback)** - TV가 스스로 하는 일과, 재생 중 리모컨 사용법입니다
