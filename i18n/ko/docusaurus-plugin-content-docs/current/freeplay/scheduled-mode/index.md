# 예약 모드 {#scheduled-mode}

<div class="article-intro">

예약 모드를 사용하면 FreePlay TV가 스스로 재생합니다. [admin.freeplay.church](https://admin.freeplay.church)의 **FreePlay Admin**에서 재생목록을 만들고 달력에 배치합니다. 이 달력에 연결된 각 TV는 앞으로 한 주의 내용을 내려받고, 시계에 맞춰 예약된 내용을 재생합니다. 아무도 시작 버튼을 누르지 않아도 됩니다. 파일은 미리 내려받아 두므로, Wi-Fi가 끊겨도 재생은 계속됩니다.

</div>

:::tip
FreePlay Admin은 B1 Admin에서 쓰는 것과 같은 ChurchApps 로그인을 사용합니다. 따로 만들 계정은 없습니다.
:::

## 전체 구조 {#how-it-fits-together}

FreePlay Admin에는 사이트 상단에 나열된 네 개의 주요 페이지가 있습니다.

- **[화면](./managing-screens)** - 페어링된 TV, 상태, 소속된 **화면 그룹**. 같은 그룹의 화면은 하나의 달력과 하나의 기본 반복을 공유합니다.
- **[재생목록](./building-playlists)** - 콘텐츠 제공자에서 고른 이미지와 동영상의 반복 목록
- **[달력](./scheduling-the-calendar)** - 각 화면 그룹이 무엇을 언제 재생할지
- **[제공자](./building-playlists#connecting-providers)** - 재생목록이 가져오는 콘텐츠 소스. 교회 전체에 대해 각 제공자를 한 번만 연결합니다.

예약된 내용이 없으면, 그룹의 화면은 **기본 반복**을 재생합니다. 그룹에 기본 반복이 없다면 화면은 꺼집니다.

## 계획 모드와의 차이 {#how-it-differs-from-plan-mode}

- **[계획 모드](../plan-mode/)**는 B1 Admin의 예배 계획 유형 하나를 따릅니다. 누군가 TV에서 **계획 시작**을 누르면, 그때 공과가 재생됩니다.
- **예약 모드**는 달력을 따릅니다. 내용은 설정한 시각에 시작하고 멈추므로, 로비 사이니지, 공지 반복, 사람들이 들어오기 전에 공과가 떠 있어야 하는 교실에 잘 맞습니다.

달력 항목으로도 예배 계획을 재생할 수 있습니다. 일정을 추가할 때 **예배 계획**에서 계획 유형을 고르면, 화면은 그 주에 B1 Admin에서 현재인 계획을 재생합니다. 여기에는 계획에서 사용자 지정한 공과를 포함한 Go Curriculum 공과도 포함됩니다. 이때 화면은 B1 Admin에서 계획 유형의 사역에 연결된 Go Curriculum 로그인을 사용하며, 사역에 연결된 것이 없으면 교회의 Go Curriculum 연결을 사용합니다.

## 시작하기 {#getting-started}

아래 각 단계를 마칠 때까지, **화면** 페이지에는 모든 단계에 대한 링크가 있는 **시작하기** 체크리스트가 표시됩니다.

1. **제공자 연결하기** - **제공자** 페이지에서 Dropbox, OneDrive, Lessons.church 또는 다른 소스를 연결합니다.
2. **재생목록 만들기** - 제공자에서 이미지와 동영상을 고릅니다.
3. **달력에 배치하기** - 언제 무엇을 재생할지 고르거나, 그룹의 기본 반복을 설정합니다.
4. **화면 페어링하기** - TV에 표시된 네 글자 코드를 입력합니다.

체크리스트를 닫으려면 **숨기기**를 클릭하세요.

:::tip
**Ctrl+K**(Mac에서는 **⌘K**)를 누르거나 머리글의 검색창을 클릭하면 명령 팔레트가 열립니다. 거기서 아무 페이지로나 이동하거나 **화면 페어링**, **재생목록 추가**, **일정 추가** 같은 작업을 시작할 수 있습니다.
:::
