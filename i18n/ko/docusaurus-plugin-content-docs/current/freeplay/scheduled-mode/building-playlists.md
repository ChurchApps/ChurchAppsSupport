# 제공업체 연결 및 재생 목록 만들기

<div class="article-intro">

재생 목록은 달력에 올려 두는 이미지와 동영상의 반복 재생입니다. FreePlay Admin에서 콘텐츠 제공업체를 교회 전체에 한 번 연결합니다. 그다음 이 제공업체들에서 파일을 골라 재생 목록을 만듭니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- [admin.freeplay.church](https://admin.freeplay.church)에서 FreePlay Admin에 로그인합니다
- Dropbox나 OneDrive처럼 연결하려는 제공업체 계정의 로그인 정보를 준비합니다

</div>

## 제공업체 연결하기 {#connecting-providers}

**제공업체** 페이지에는 콘텐츠 소스가 두 섹션으로 나뉘어 나열됩니다.

- **연결됨** - 지금 바로 사용할 수 있는 제공업체입니다. Lessons.church나 Bible Project처럼 로그인이 필요 없는 공개 제공업체는 항상 여기에 **공개 · 로그인 필요 없음**으로 표시됩니다. 연결된 계정은 **계정 연결됨**과 링크 만료 시기를 표시합니다.
- **사용 가능** - 사용하기 전에 로그인이 필요한 제공업체입니다.

제공업체를 연결하려면 다음과 같이 합니다.

1. **제공업체**로 이동합니다.
2. **사용 가능** 아래에서 제공업체를 찾아 **연결**을 클릭합니다.
3. 해당 제공업체에 로그인합니다.
   - Dropbox, Google Drive, OneDrive 같은 일부 제공업체는 로그인 팝업을 엽니다. 아무것도 나타나지 않으면 admin.freeplay.church에 대해 팝업을 허용하세요.
   - 다른 제공업체는 링크와 코드를 표시합니다. 링크를 방문하고, 코드를 입력하고, 액세스를 승인합니다. 완료되면 대화 상자가 자동으로 업데이트됩니다.
4. **계정이 성공적으로 연결되었습니다!**가 표시되면 해당 제공업체가 **연결됨**으로 이동합니다.

연결된 제공업체에서 할 수 있는 작업은 세 가지입니다.

- **찾아보기** - 제공업체의 폴더를 살펴봅니다
- **새로 고침** - 제공업체의 로그인을 갱신합니다
- **연결 해제** - 계정 연결을 끊습니다

:::info
FreePlay Admin의 제공업체 연결은 한 사람이나 한 TV가 아니라 교회 전체에 속합니다. 예약된 화면은 이 연결을 통해 파일을 받으므로, TV마다 제공업체에 로그인할 필요가 없습니다.
:::

**FreeShow**는 **교회 네트워크에 있음 · 각 TV가 스스로 찾음**으로 표시됩니다. FreePlay Admin에서 연결할 것은 없습니다.

## 재생 목록 페이지

**재생 목록** 페이지에는 각 재생 목록의 항목 수, 총 재생 시간, 사용 위치(그룹의 **기본 반복**이나 일정 수), 마지막 업데이트 시점이 나열됩니다. 각 행에는 다음 작업이 있습니다.

- **재생** - 브라우저에서 재생 목록을 전체 화면으로 재생합니다
- **편집** - 재생 목록 편집기를 엽니다
- **복제** - "(copy)"라는 이름의 사본을 만듭니다

## 재생 목록 만들기

1. **재생 목록**으로 이동하여 **재생 목록 추가**를 클릭합니다.
2. **이름**을 입력합니다(예: "Welcome loop").
3. **재생 목록 추가**를 클릭합니다. 재생 목록 편집기가 열립니다.

## 항목 추가하기

재생 목록 편집기는 왼쪽에 재생 목록의 **항목**을, 오른쪽에 **제공업체에서 추가**를 보여 줍니다.

1. 오른쪽에서 제공업체 탭을 선택합니다. 다른 소스를 추가하려면 **다른 제공업체 연결**을 클릭하며, 이는 **제공업체** 페이지를 엽니다.
2. 폴더를 클릭하여 안으로 들어갑니다. 경로 표시줄을 사용하여 위로 돌아갑니다.
3. 파일을 클릭하면 재생 목록의 끝에 추가됩니다. 재생 목록에 이미 있는 파일은 선택됨으로 표시됩니다.
4. 현재 폴더의 모든 항목을 한 번에 추가하려면 **모두 추가**를 클릭합니다. 이 버튼에는 아직 재생 목록에 없는 파일의 개수가 표시됩니다.
5. 편집기 상단의 **저장**을 클릭합니다.

:::warning
**저장**을 클릭하기 전까지는 변경 사항이 저장되지 않습니다. 저장하지 않고 나가려면 **취소**를 클릭하세요.
:::

## 항목 정리하기

왼쪽의 **항목** 목록에서 다음 작업을 할 수 있습니다.

- **순서 바꾸기** - 왼쪽의 손잡이를 끌어 항목을 옮깁니다
- **이미지 시간** - 이미지는 기본적으로 10초 동안 표시됩니다. 이미지 옆의 초 수를 변경합니다
- **동영상** - 동영상은 **끝까지 재생**으로 표시되며 전체 길이만큼 재생됩니다
- **제거** - 항목을 재생 목록에서 뺍니다

상단의 요약에는 항목 수와 재생 목록의 총 길이가 표시됩니다.

## 이름 바꾸기, 복제, 삭제하기

편집기 왼쪽 패널에는 재생 목록이 어디에 사용되는지 표시됩니다. 이 패널에는 다음 작업도 있습니다.

- **재생** - 브라우저에서 재생 목록을 재생합니다
- **이름 바꾸기** - 재생 목록의 이름을 변경합니다
- **복제** - 별도로 편집할 수 있는 사본을 만듭니다
- **삭제** - 재생 목록을 제거합니다. 이 재생 목록을 재생하던 일정은 그룹의 기본 반복으로 되돌아갑니다

## 브라우저에서 재생 목록 재생하기

**재생**을 클릭하면 재생 목록이 브라우저에서 전체 화면으로 재생됩니다. 재생 목록을 미리 보거나 프로젝터에 연결된 노트북에서 실행할 때 편리합니다. 마우스를 움직이면 컨트롤 막대가 나타나며, 다음 키를 사용할 수 있습니다.

| 키 | 동작 |
|---|---|
| **스페이스** | 일시 정지 또는 재개 |
| **←** / **→** | 이전 또는 다음 항목 |
| **F** | 전체 화면 전환 |
| **Esc** | 종료 |
