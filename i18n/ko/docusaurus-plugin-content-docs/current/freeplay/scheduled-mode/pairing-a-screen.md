# 화면 페어링하기

<div class="article-intro">

TV를 캘린더에 연결하려면 **FreePlay Admin**과 페어링하세요. TV에 네 글자 코드가 표시됩니다. [admin.freeplay.church](https://admin.freeplay.church)에서 이 코드를 입력하고, 이 TV가 따라갈 화면 그룹을 선택합니다. TV마다 한 번만 하면 됩니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- TV에 FreePlay를 설치하고 실행하세요. [시작하기](../getting-started/)를 참조하세요.
- FreePlay Admin에 로그인할 수 있도록 교회의 ChurchApps 로그인 정보를 준비하세요.
- 선택 사항: TV가 바로 재생할 내용이 있도록 먼저 [재생 목록을 만들고](./building-playlists) [예약](./scheduling-the-calendar)해 두세요.

</div>

## TV에 코드 표시하기

1. TV에서 사이드바 하단의 **설정**을 엽니다.
2. **캘린더에 페어링**을 선택합니다. TV가 아직 페어링되지 않았다면 해당 행에 **페어링되지 않음**이 표시됩니다.
3. **이 화면 페어링** 화면에 QR 코드와 네 글자 페어링 코드가 표시되며, **휴대폰으로 스캔하거나 freeplay.church/pair로 이동하여 이 코드를 입력하세요**라는 메시지가 나타납니다.
4. 코드 아래에서 FreePlay가 페어링 완료를 기다리는 동안 **확인 대기 중**이 깜박입니다.

코드는 15분 동안 유효하며, 코드 아래의 카운트다운이 남은 시간을 보여 줍니다. 시간이 다 되면 FreePlay가 자동으로 새 코드를 표시합니다. 새 코드를 원하면 **새 코드 생성**을, 설정으로 돌아가려면 **취소**를 선택할 수도 있습니다.

## FreePlay Admin에서 페어링하기

1. 휴대폰으로 QR 코드를 스캔하거나, 아무 컴퓨터나 휴대폰에서 **freeplay.church/pair**로 이동합니다. 로그인을 요청하면 로그인합니다. FreePlay Admin이 코드가 이미 입력된 **화면 페어링** 양식을 엽니다.
   - 직접 양식을 열 수도 있습니다. FreePlay Admin에서 **화면**으로 이동하여 **화면 페어링**을 클릭하세요.
2. **페어링 코드**를 확인합니다. TV에 표시된 네 글자입니다.
3. 여러 TV 중 이 TV를 구분할 수 있도록 **라벨**을 입력합니다(예: "로비 왼쪽"). 선택 사항입니다.
4. **그룹** 아래에서 이 TV가 따라갈 화면 그룹을 선택합니다. 새 그룹을 만들려면 **＋ 새 그룹…**을 선택하고 **새 그룹 이름**을 입력합니다.
5. **모드** 아래에서 **예약**을 그대로 둡니다. 그러면 TV가 그룹의 캘린더에 따라 자동으로 재생합니다.
6. **페어링**을 클릭합니다.

TV에 **연결됨!**이 표시된 후 **일정을 불러오는 중...**이 표시됩니다. TV는 예약된 콘텐츠를 다운로드하고 재생을 시작합니다. [TV에서 예약 재생](./scheduled-playback)을 참조하세요.

:::info
FreePlay Admin에 **That code didn't match a TV**가 표시되면 TV 화면의 코드를 확인하세요. 코드가 만료되었다면 TV가 지금 표시하고 있는 새 코드를 사용하세요.
:::

### 예약 모드와 수동 모드

**모드** 설정에는 두 가지 옵션이 있습니다.

- **예약** - 그룹의 캘린더에 따라 자동으로 재생합니다. 아무도 시작 버튼을 누를 필요가 없습니다.
- **수동** - 누군가 리모컨으로 콘텐츠를 선택합니다. 수동 화면도 **화면** 목록에 표시되지만 캘린더를 따르지 않으므로 **그룹** 필드가 비활성화됩니다.

나중에 [화면 페이지](./managing-screens)의 **편집**에서 화면의 모드를 바꿀 수 있습니다.

## 대신 서비스 계획에 페어링하기

**이 화면 페어링** 화면의 코드는 B1 Admin에서도 작동합니다. 거기에 코드를 입력하고 **다음 계획 유형 표시** 아래에서 계획 유형을 선택하면, TV는 캘린더 대신 해당 계획 유형을 [계획 모드](../plan-mode/)에서 따라갑니다. [기기 페어링](../plan-mode/device-pairing)을 참조하세요.

## TV에서 변경하거나 페어링 해제하기 {#changing-or-unpairing-from-the-tv}

TV가 페어링되면 **설정**의 **캘린더에 페어링** 행에 따라가는 화면 그룹의 이름이 표시됩니다. 이 행을 선택하면 세 가지 옵션이 있는 **페어링 대상** 대화 상자가 열립니다.

- **유지** - 대화 상자를 닫습니다. 아무것도 바뀌지 않습니다.
- **페어링 해제** - 일정을 따르지 않습니다. FreePlay가 **콘텐츠 제공자** 화면을 엽니다.
- **다른 캘린더에 페어링** - 페어링을 해제한 후 새 페어링 코드를 표시하여 TV를 다시 페어링할 수 있게 합니다.

:::warning
페어링을 해제하면 해당 캘린더를 위해 FreePlay가 다운로드한 파일이 삭제됩니다.
:::

## FreePlay Admin에서 페어링 해제하기

1. **화면**으로 이동하여 화면의 라벨을 클릭합니다.
2. **더 보기**를 클릭한 다음 **페어링 해제**를 클릭합니다.
3. 확인하려면 **페어링 해제**를 한 번 더 클릭합니다.

TV는 다시 페어링 코드를 표시합니다. 다시 사용하려면 언제든지 페어링하세요.
