# 레슨 콘텐츠 다운로드

<div class="article-intro">

교회와 교실을 선택한 후 FreePlay는 자동으로 오늘 예약된 레슨을 가져오고 모든 미디어 파일 다운로드를 시작합니다. 이 화면은 레슨을 시작하기 전에 콘텐츠가 준비될 때까지 기다리는 곳입니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 교회와 교실을 선택합니다 -- [교회 및 방 선택](./selecting-room) 참조
- TV가 초기 다운로드를 위해 인터넷에 연결되어 있는지 확인합니다

</div>

## 다운로드 작동 방식

1. FreePlay는 교실 일정을 확인하고 할당된 레슨을 로드합니다
2. 레슨 이름, 제목 및 설명이 화면에 나타나고, 레슨의 커버 이미지에 오버레이됩니다
3. 진행 표시기는 각 파일이 기기에 저장되면서 **Downloading item X of Y**를 보여줍니다
4. 모든 파일이 다운로드되면 **Start Lesson** 버튼이 재생 아이콘과 함께 나타납니다

다운로드 중에 아무것도 할 필요가 없습니다. FreePlay가 모든 것을 자동으로 처리합니다.

## 해상도

FreePlay는 기본값으로 720p에서 콘텐츠를 다운로드합니다. 해상도 설정(720p 또는 1080p)은 다운로드된 비디오 및 이미지 파일의 품질을 결정합니다. 큰 TV에서는 더 높은 해상도가 더 선명하게 보이지만 더 오래 걸리고 더 많은 저장소를 사용합니다.

:::info
해상도는 기본값으로 720p로 설정됩니다. 콘텐츠는 기기에 구성된 해상도에서 다운로드됩니다.
:::

## 레슨 시작

다운로드가 완료되면 **Start Lesson** 버튼이 화면 하단에 나타납니다. TV 리모컨을 사용하여 하이라이트하고 **Select**를 누르면 재생을 시작합니다.

## 자동 새로 고침

FreePlay는 매시간 업데이트된 콘텐츠를 확인합니다. 하루 중 일정이 변경되면 앱이 새 레슨을 자동으로 선택합니다. 또한 리모컨의 **Back**을 누르면 방 선택 화면으로 돌아가 다운로드 화면을 다시 입력하여 새로 고침을 강제할 수 있습니다.

:::tip
건물이 강한 인터넷 연결이 있는 동안 일요일 아침 전에 레슨을 다운로드합니다. 일단 다운로드되면 콘텐츠는 모든 네트워크 의존성 없이 오프라인에서 재생됩니다.
:::

## 다운로드 화면

FreePlay에는 기기에 다운로드한 모든 콘텐츠를 보고 관리할 수 있는 **Downloads** 화면이 포함되어 있습니다. 사이드바 하단의 **Settings**를 열고 **Downloads**를 선택합니다. 이는 로컬로 저장되고 오프라인 재생을 위해 준비된 것을 볼 수 있습니다. Downloads 화면을 사용하여 일요일 아침 전에 레슨이 완전히 다운로드되었는지 확인하거나 오래된 콘텐츠를 제거하여 저장소 공간을 확보합니다.

## 일정이 비어 있으면

선택한 교실에 대해 레슨이 예약되지 않으면 "The schedule could not be loaded. Make sure a lesson is scheduled for this class." 메시지가 표시됩니다. [freeplay.church](https://freeplay.church)에서 일정을 확인하고 올바른 레슨이 이 방에 할당되었는지 확인합니다.
