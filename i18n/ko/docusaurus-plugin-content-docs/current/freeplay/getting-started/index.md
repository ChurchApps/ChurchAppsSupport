# FreePlay 시작하기

<div class="article-intro">

FreePlay는 Android TV, Amazon Fire TV, 그리고 Apple TV에서 사용 가능합니다. 이 가이드는 앱을 설치하고, 처음 실행하고, 앱 전체에서 사용할 기본 TV 리모컨 컨트롤을 배우는 과정을 안내합니다.

</div>

우리의 **<a href="/guides/freeplay-quickstart" target="_blank">quick start video</a>**를 보세요 -- 몇 분 안에 FreePlay를 설치하고 콘텐츠 재생을 시작합니다. 기술 기술이 필요하지 않습니다.
:::

:::tip B1 Admin으로 설정 중입니까?
우리의 **<a href="/guides/freeplay-b1admin" target="_blank">step-by-step guide</a>**는 전체 설정을 다룹니다 -- 콘텐츠 제공자 연결부터 올바른 레슨이 매주 자신의 교실 TV에 자동으로 다운로드되도록 합니다.
:::

## FreePlay 설치

:::tip 기기를 구매합니까?
모든 스트리밍 스틱이 FreePlay를 실행할 수 없습니다 -- 최신 예산 Fire TV 모델은 할 수 없습니다. [기기 선택](./choosing-a-device.md)을 참조하면 구매할 것을 정확히 봅니다.
:::

### Android TV / Amazon Fire TV

1. TV에서 앱 스토어를 엽니다(**Google Play Store** 또는 **Amazon Appstore**)
2. **FreePlay**를 검색합니다
3. 앱을 선택하고 **Install**을 선택합니다

### Apple TV

1. Apple TV에서 **App Store**를 엽니다
2. **FreePlay**를 검색합니다
3. 앱을 선택하고 **Get**을 선택합니다

## 앱 실행

FreePlay를 처음 열면 FreePlay 로고를 가진 애니메이션 스플래시 화면을 봅니다. 앱은 이전에 연결된 콘텐츠 제공자를 확인합니다. 이미 제공자를 연결했다면 그 제공자의 콘텐츠 브라우저로 바로 이동합니다. 그렇지 않으면 첫 콘텐츠 소스에 연결할 수 있는 **Content Providers** 화면을 엽니다.

## TV 리모컨으로 네비게이션

FreePlay는 TV 리모컨을 위해 구축되었습니다. 앱 전체에서 사용할 컨트롤은 다음입니다:

- **방향 패드(위/아래/왼쪽/오른쪽)** - 화면의 항목 사이 이동
- **Select / OK 버튼** - 하이라이트된 항목 선택
- **왼쪽 화살표** - 모든 화면에서 사이드바 열기
- **오른쪽 화살표** - 사이드바 닫기 및 메인 콘텐츠 영역으로 돌아가기
- **Back / Menu 버튼** - 이전 화면으로 돌아가기

:::tip
콘텐츠를 찾을 때 사이드바는 좁은 아이콘 스트립으로 축소됩니다. 전체 레이블을 보고 확장하려면 리모컨의 왼쪽 화살표를 누르세요.
:::

## 사이드바

사이드바는 위에서 아래로 나열합니다:

- **Today's Plan** -- TV가 계획에 쌍을 이룰 때 표시됩니다. [Plan Mode](../plan-mode/) 참조
- **Announcements** -- 공지 폴더를 선택했으면 표시됩니다. [Announcements](../content-providers/announcements) 참조
- **Browse** -- 찾을 수 있는 각 연결된 콘텐츠 제공자. [콘텐츠 찾기 및 다운로드](../content-providers/browsing-content) 참조
- **Settings** -- 사이드바 하단. **Downloads**(이 기기에 저장한 콘텐츠 재생 또는 삭제)를 열고 **Providers**(콘텐츠 제공자 연결 및 공지 폴더 선택)
