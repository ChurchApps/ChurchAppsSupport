# FreePlay 시작하기

<div class="article-intro">

FreePlay는 Android TV, Amazon Fire TV, Apple TV에서 사용 가능합니다. 이 가이드는 앱을 설치하고, 처음으로 시작하며, 앱 전체에서 사용할 기본 TV 원격 제어를 학습하는 과정을 안내합니다.

</div>

:::tip FreePlay에 처음이신가요?
**<a href="/guides/freeplay-quickstart" target="_blank">빠른 시작 동영상</a>** 보기 - 단 몇 분 안에 FreePlay를 설치하고 콘텐츠 재생을 시작합니다. 기술 기술이 필요하지 않습니다.
:::

:::tip B1 Admin으로 설정하는 중입니까?
**<a href="/guides/freeplay-b1admin" target="_blank">단계별 가이드</a>**는 전체 설정을 다룹니다. 콘텐츠 제공업체 연결부터 올바른 수업이 매주 자동으로 교실 TV에 다운로드되는 것까지입니다.
:::

## FreePlay 설치

:::tip 장치를 구입하시나요?
모든 스트리밍 스틱이 FreePlay를 실행할 수 있는 것은 아닙니다. 최신 예산 Fire TV 모델은 할 수 없습니다. **[장치 선택](./choosing-a-device.md)**에서 정확히 무엇을 구매해야 하는지 참조합니다.
:::

### Android TV / Amazon Fire TV

1. TV의 앱 스토어를 엽니다 (**Google Play 스토어** 또는 **Amazon Appstore**)
2. **FreePlay** 검색
3. 앱을 선택하고 **설치** 선택

### Apple TV

1. Apple TV에서 **App Store** 열기
2. **FreePlay** 검색
3. 앱을 선택하고 **다운로드** 선택

## 앱 시작

FreePlay를 처음 열면 FreePlay 로고가 있는 애니메이션 스플래시 화면이 표시됩니다. 앱은 이전에 연결된 콘텐츠 제공업체를 확인합니다. 이미 제공업체를 연결한 경우 해당 제공업체의 콘텐츠 브라우저로 직접 이동합니다. 그렇지 않으면 **콘텐츠 제공업체** 화면으로 열어서 첫 번째 콘텐츠 소스에 연결할 수 있습니다.

## TV 원격으로 탐색

FreePlay는 TV 원격용으로 구축되었습니다. 앱 전체에서 사용할 제어:

- **방향 패드 (위/아래/좌/우)** - 화면의 항목 간 이동
- **선택 / OK 버튼** - 강조된 항목 선택
- **왼쪽 화살표** - 모든 화면에서 사이드바 열기
- **오른쪽 화살표** - 사이드바 닫기 및 주 콘텐츠 영역으로 돌아가기
- **뒤로 / 메뉴 버튼** - 이전 화면으로 이동

:::tip
콘텐츠를 탐색할 때 사이드바는 좁은 아이콘 스트립으로 축소됩니다. 원격에서 왼쪽 화살표를 눌러 확장하고 전체 레이블을 봅니다.
:::
