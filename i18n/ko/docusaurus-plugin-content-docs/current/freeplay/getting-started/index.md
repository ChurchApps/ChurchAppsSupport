# FreePlay 시작하기

<div class="article-intro">

FreePlay는 Android TV, Amazon Fire TV, Apple TV에서 사용할 수 있습니다. 이 가이드에서는 앱을 설치하고, 처음 실행하며, 앱 전체에서 사용하게 될 기본 TV 리모컨 조작법을 익히는 과정을 안내합니다.

</div>

:::tip FreePlay가 처음이신가요? 여기서 시작하세요
**<a href="/guides/freeplay-quickstart" target="_blank">빠른 시작 영상</a>**을 시청하세요 — 몇 분 만에 FreePlay를 설치하고 콘텐츠 재생을 시작할 수 있습니다. 기술 지식은 필요하지 않습니다.
:::

:::tip B1 Admin과 함께 설정하시나요?
**<a href="/guides/freeplay-b1admin" target="_blank">단계별 가이드</a>**에서 전체 설정 과정을 다룹니다. 콘텐츠 제공자 연결부터 매주 적절한 수업이 교실 TV로 자동으로 내려받아지도록 하는 방법까지 설명합니다.
:::

## FreePlay 설치하기

:::tip 기기를 구입하시나요?
모든 스트리밍 스틱이 FreePlay를 실행할 수 있는 것은 아닙니다. 최신 예산형 Fire TV 모델은 실행할 수 없습니다. 구입해야 할 기기는 **[기기 선택](./choosing-a-device.md)**에서 정확히 확인하세요.
:::

### Android TV / Amazon Fire TV

1. TV에서 앱 스토어(**Google Play 스토어** 또는 **Amazon Appstore**)를 엽니다.
2. **FreePlay**를 검색합니다.
3. 앱을 선택하고 **설치**를 선택합니다.

### Apple TV

1. Apple TV에서 **App Store**를 엽니다.
2. **FreePlay**를 검색합니다.
3. 앱을 선택하고 **받기**를 선택합니다.

## 앱 실행하기

FreePlay를 처음 열면 FreePlay 로고가 나타나는 애니메이션 스플래시 화면이 표시됩니다. 앱은 이전에 연결한 콘텐츠 제공자가 있는지 확인합니다. 이미 제공자를 연결했다면 해당 제공자의 콘텐츠 탐색 화면으로 바로 이동합니다. 그렇지 않으면 첫 번째 콘텐츠 소스를 연결할 수 있는 **Content Providers** 화면이 열립니다.

TV가 [예약 모드](../scheduled-mode/)에서 캘린더에 연결되어 있다면, FreePlay는 이 모든 과정을 건너뛰고 예약된 플레이어를 바로 엽니다.

## TV 리모컨으로 탐색하기

FreePlay는 TV 리모컨으로 조작하도록 설계되었습니다. 앱 전체에서 사용하게 될 조작 방법은 다음과 같습니다:

- **방향 패드(위/아래/왼쪽/오른쪽)** - 화면의 항목 사이를 이동합니다
- **선택 / OK 버튼** - 강조 표시된 항목을 선택합니다
- **왼쪽 화살표** - 어떤 화면에서든 사이드바를 엽니다
- **오른쪽 화살표** - 사이드바를 닫고 기본 콘텐츠 영역으로 돌아갑니다
- **뒤로 / 메뉴 버튼** - 이전 화면으로 돌아갑니다

:::tip
콘텐츠를 탐색할 때 사이드바는 아이콘이 있는 좁은 띠로 접힙니다. 리모컨의 왼쪽 화살표를 누르면 펼쳐져 전체 레이블이 보입니다.
:::

## 사이드바

사이드바에는 위에서 아래로 다음 항목이 나열됩니다:

- **Today's Plan** -- TV가 계획에 연결되어 있을 때 표시됩니다. [계획 모드](../plan-mode/)를 참고하세요.
- **Announcements** -- 공지 폴더를 선택한 후 표시됩니다. [공지](../content-providers/announcements)를 참고하세요.
- **Browse** -- 탐색할 수 있는 연결된 각 콘텐츠 제공자입니다. [콘텐츠 찾아보기 및 다운로드](../content-providers/browsing-content)를 참고하세요.
- **Settings** -- 사이드바 맨 아래에 있습니다. **Pair to a calendar**(이 TV를 캘린더 또는 계획에 연결 — [페어링 모드 선택하기](./pairing-modes) 참고), **Downloads**(이 기기에 저장된 콘텐츠 재생 또는 삭제), **Providers**(콘텐츠 제공자 연결 및 공지 폴더 선택)를 열 수 있습니다.
