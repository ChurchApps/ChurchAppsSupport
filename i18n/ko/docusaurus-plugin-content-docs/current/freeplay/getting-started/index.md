# FreePlay 시작하기

<div class="article-intro">

FreePlay는 Android TV, Amazon Fire TV, Apple TV에서 사용할 수 있습니다. 이 가이드에서는 앱을 설치하고, 처음 실행하고, 앱 전체에서 사용하게 될 기본 TV 리모컨 조작법을 배우는 과정을 안내합니다.

</div>

:::tip FreePlay가 처음이신가요? 여기서 시작하세요
**<a href="https://mautic.churchapps.org/guides/classroom-tv.html" target="_blank">교실 TV 단계별 안내</a>**를 따라 하세요. 계정이 없는 상태에서 시작해 예배 영상과 이번 주일 공과를 스스로 재생하는 교실 TV를 갖추기까지 짧은 동영상 8개로 안내합니다.

**<a href="/guides/freeplay-quickstart" target="_blank">빠른 시작 동영상</a>**을 보세요. FreePlay를 설치하고 몇 분 만에 콘텐츠 재생을 시작할 수 있습니다. 기술 지식은 필요하지 않습니다.
:::

:::tip B1 Admin으로 설정하시나요?
**<a href="/guides/freeplay-b1admin" target="_blank">단계별 안내</a>**에서 전체 설정 과정을 다룹니다. 콘텐츠 제공자 연결부터 매주 알맞은 공과가 교실 TV로 자동 다운로드되도록 하는 방법까지 설명합니다.
:::

## FreePlay 설치하기

:::tip 기기를 구매하시나요?
FreePlay는 Fire TV(새로운 Vega OS 스틱 포함), onn 같은 Android TV 및 Google TV 박스, Apple TV에서 실행됩니다. Roku에서는 실행되지 않습니다. 정확히 무엇을 사야 하는지는 **[기기 고르기](./choosing-a-device.md)**를 참고하세요.
:::

### Android TV / Amazon Fire TV

1. TV에서 앱 스토어(**Google Play 스토어** 또는 **Amazon Appstore**)를 여세요.
2. **FreePlay**를 검색하세요.
3. 앱을 선택하고 **Install**을 누르세요.

### Apple TV

1. Apple TV에서 **App Store**를 여세요.
2. **FreePlay**를 검색하세요.
3. 앱을 선택하고 **Get**을 누르세요.

## 앱 실행하기

FreePlay를 처음 열면 FreePlay 로고가 나타나는 애니메이션 시작 화면이 보입니다. 앱은 이전에 연결해 둔 콘텐츠 제공자가 있는지 확인합니다. 이미 제공자를 연결했다면 해당 제공자의 콘텐츠 찾아보기 화면으로 바로 이동합니다. 연결된 제공자가 없다면 첫 번째 콘텐츠 소스를 연결할 수 있는 **Content Providers** 화면이 열립니다.

TV가 [예약 모드](../scheduled-mode/index.md)에서 캘린더에 연결되어 있다면, FreePlay는 이 모든 과정을 건너뛰고 예약 재생 화면으로 바로 엽니다.

## TV 리모컨으로 조작하기

FreePlay는 TV 리모컨에 맞게 만들어졌습니다. 앱 전체에서 사용하게 될 조작 방법은 다음과 같습니다.

- **방향 패드(위/아래/왼쪽/오른쪽)** -- 화면의 항목 사이를 이동
- **Select / OK 버튼** -- 강조 표시된 항목 선택
- **왼쪽 화살표** -- 어느 화면에서든 사이드바 열기
- **오른쪽 화살표** -- 사이드바를 닫고 기본 콘텐츠 영역으로 돌아가기
- **Back / Menu 버튼** -- 이전 화면으로 돌아가기

:::tip
콘텐츠를 찾아볼 때 사이드바는 아이콘만 있는 좁은 띠로 접힙니다. 리모컨의 왼쪽 화살표를 누르면 펼쳐져 전체 이름이 보입니다.
:::

## 사이드바

사이드바에는 위에서 아래로 다음 항목이 나열됩니다.

- **Today's Plan** -- TV가 예배 순서에 연결되어 있을 때 표시됩니다. [예배 순서 모드](../plan-mode/index.md)를 참고하세요.
- **Announcements** -- 공지 폴더를 선택하면 표시됩니다. [공지](../content-providers/announcements.md)를 참고하세요.
- **Browse** -- 연결된 각 콘텐츠 제공자를 찾아볼 수 있습니다. [콘텐츠 찾아보기 및 다운로드](../content-providers/browsing-content.md)를 참고하세요.
- **Settings** -- 사이드바 맨 아래에 있습니다. **Pair to a calendar**(이 TV를 캘린더나 예배 순서에 연결하기 -- [연결 방식 선택하기](./pairing-modes.md)를 참고하세요), **Downloads**(이 기기에 저장된 콘텐츠 재생 또는 삭제), **Providers**(콘텐츠 제공자 연결 및 공지 폴더 선택)를 열 수 있습니다.
