# 페어링 모드 선택하기

<div class="article-intro">

FreePlay는 TV를 교회에 연결하는 두 가지 페어링 모드와, 콘텐츠 제공업체를 직접 탐색할 수 있는 기능을 제공합니다. **페어링 모드 선택** 화면은 이러한 옵션을 TV 리모컨으로 탐색할 수 있는 큰 카드 형태로 제시합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- FreePlay를 설치하고 처음 실행하세요 -- [시작하기](./index.md) 참조
- 탐색을 위해 TV 리모컨을 준비하세요

</div>

## 교실에 페어링

특정 TV가 특정 방에 예약된 레슨을 항상 표시하도록 하려면 **교실에 페어링**을 선택하세요. 레슨이 주간 일정으로 배정되는 어린이 사역 교실에 가장 적합한 옵션입니다.

**작동 방식:** 교회 이름으로 검색하고 교실을 선택하면 FreePlay가 오늘 해당 방에 예약된 레슨을 자동으로 가져옵니다. 매주 일요일 아침 TV를 켜기만 하면 올바른 레슨이 준비되어 있습니다.

**적합한 경우:** 항상 해당 방에 예약된 콘텐츠를 표시해야 하는 전용 교실 TV.

:::tip
TV를 페어링하기 전에 [freeplay.church](https://freeplay.church)에서 교실을 설정하세요. 이렇게 하면 교회를 검색할 때 방이 표시됩니다.
:::

## 플랜에 페어링

교회 예배 플랜을 따르려면 **플랜에 페어링**을 선택하세요. 이 모드는 **B1 Admin**에서 입력할 페어링 코드를 생성하여 TV를 특정 플랜 유형에 연결합니다. 그러면 TV는 현재 플랜에 배정된 콘텐츠를 다운로드하여 재생합니다.

**작동 방식:** FreePlay가 화면에 페어링 코드와 QR 코드를 표시합니다. 관리자가 **B1 Admin**에서 연결된 페이지를 열고 코드를 입력한 뒤, **플랜 표시 대상** 드롭다운에서 화면이 따라야 할 플랜 유형을 선택합니다. 승인되면 TV가 현재 플랜의 콘텐츠를 자동으로 불러옵니다.

**적합한 경우:** 예배 찬양 가사나 공지 슬라이드처럼 주간 예배 플랜에 연결된 콘텐츠를 표시하는 TV.

## 콘텐츠 제공업체

교실이나 플랜에 페어링할 필요가 없다면 콘텐츠 제공업체를 직접 탐색할 수 있습니다. [Lessons.church](../../lessons-church/)와 Bible Project 같은 제공업체는 필요할 때 다운로드하여 재생할 수 있는 콘텐츠를 제공합니다.

**적합한 경우:** 자원봉사자가 매주 재생할 콘텐츠를 수동으로 선택하는 TV, 또는 사용 가능한 콘텐츠를 탐색하고 싶을 때.

:::info
탐색 하단의 사이드바에서 언제든지 **제공업체** 화면에 접근할 수 있습니다. 콘텐츠를 탐색하고 재생하는 데 페어링 모드를 사용할 필요는 없습니다.
:::
