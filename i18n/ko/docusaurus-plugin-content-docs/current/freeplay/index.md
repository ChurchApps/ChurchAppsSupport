# FreePlay 개요

<div class="article-intro">

FreePlay는 교회를 위한 TV 앱으로, 교실 TV에 수업 콘텐츠를 표시합니다. Android TV, Amazon Fire TV, Apple TV에서 실행되며, 일요일 아침에 인터넷 연결 없이도 작동하도록 설계되었습니다. 자원봉사자는 주중에 수업 자료를 미리 다운로드해 두고, 수업이 시작될 때 재생 버튼만 누르면 됩니다.

</div>

:::tip FreePlay가 처음이신가요? 여기서 시작하세요
**<a href="/guides/freeplay-quickstart" target="_blank">빠른 시작 동영상</a>**을 시청하세요. FreePlay를 설치하고 몇 분 안에 콘텐츠 재생을 시작할 수 있습니다. 기술 지식은 필요하지 않습니다.
:::

:::tip 더 알아보고 싶으신가요?
**<a href="/guides/freeplay-b1admin" target="_blank">전체 설정 가이드</a>**에서는 B1 Admin을 연결하여 매주 올바른 수업 자료가 교실 TV에 자동으로 다운로드되도록 하는 방법을 안내합니다. 동영상과 단계별 설명이 포함되어 있습니다.
:::

## 주요 기능

- **오프라인 재생** - 예배 중에 Wi-Fi에 의존하지 않도록 동영상과 이미지 슬라이드를 미리 다운로드합니다
- **다운로드 관리** - **설정** > **다운로드**에서 다운로드한 모든 콘텐츠를 보고 관리합니다
- **예약 모드** - 재생 목록을 만들어 [admin.freeplay.church](https://admin.freeplay.church)의 캘린더에 배치하면, 페어링된 TV가 아무도 시작 버튼을 누르지 않아도 정해진 시간에 재생합니다 -- [예약 모드](./scheduled-mode/)를 참조하세요
- **계획 페어링** - 기기를 교회 예배 계획에 연결하여 여러 방의 콘텐츠를 조율합니다
- **콘텐츠 제공자** - [Lessons.church](/docs/lessons-church/), Bible Project, Dropbox, OneDrive 같은 외부 소스에서 콘텐츠를 찾아보고 다운로드합니다
- **공지 슬라이드** - 연결된 제공자의 슬라이드 폴더를 반복 재생합니다 -- [공지 슬라이드](./content-providers/announcements)를 참조하세요
- **TV 리모컨 지원** - 방향 버튼과 선택 버튼을 사용하여 일반 TV 리모컨만으로 앱 전체를 탐색할 수 있습니다
- **접을 수 있는 사이드바** - 화면을 어지럽히지 않으면서도 탐색 메뉴에 쉽게 접근할 수 있도록 얇은 사이드바를 제공합니다

## 작동 방식

FreePlay를 실행하면 콘텐츠 제공자에 연결되어 사용 가능한 콘텐츠를 확인합니다. 이후 폴더를 탐색하고, 미디어를 다운로드하고, 수업을 재생할 수 있습니다. 모든 기능은 대형 TV 화면에 맞게 최적화되어 있습니다.
