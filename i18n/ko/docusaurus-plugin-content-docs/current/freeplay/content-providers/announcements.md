# 공지

<div class="article-intro">

FreePlay는 TV의 공지 슬라이드 폴더를 반복 재생할 수 있습니다 -- 예를 들어, 로비에서 또는 수업 시작 전입니다. 연결된 콘텐츠 제공자 중 하나에서 폴더를 선택하면, FreePlay가 슬라이드를 기기에 다운로드하고, 사이드바에 **공지** 항목이 표시되어 언제든지 반복 재생을 시작할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- Google Drive 또는 Dropbox와 같은 공지 슬라이드가 있는 [콘텐츠 제공자에 연결](./connecting-providers)합니다
- 반복 재생하려는 이미지 또는 비디오를 해당 제공자에서 하나의 폴더에 함께 넣습니다

</div>

## 공지 폴더 선택

1. 사이드바 하단의 **설정**을 열고 **제공자**를 선택합니다
2. 슬라이드가 있는 연결된 제공자를 선택합니다 (**연결됨** 배지가 표시됨) **제공자 설정**을 엽니다
3. **공지에 사용**을 선택합니다
4. **공지 폴더 선택** 브라우저가 열립니다. 슬라이드가 있는 폴더에 도달할 때까지 폴더를 이동한 다음 해당 폴더 (또는 내부의 모든 파일)를 선택합니다
5. FreePlay가 슬라이드를 다운로드하고 **제공자 설정**으로 돌아갑니다. 여기서 행은 **"*폴더 이름*" 반복 -- *슬라이드 수* 다운로드됨**으로 읽습니다

한 번에 하나의 폴더만 공지에 사용됩니다. 다른 제공자에서 폴더를 선택하면 이전 폴더가 바뀝니다.

## 공지 재생

슬라이드가 다운로드되면 사이드바 상단 근처에 **공지** 항목이 표시됩니다 (TV에 표시되는 경우 **오늘 계획** 아래). 이를 선택하여 반복 재생을 시작합니다.

- 제공자가 파일에 자체 지속 시간을 제공하지 않으면 이미지가 화면에 15초 동안 유지됩니다
- 비디오는 다음 슬라이드로 이동하기 전에 끝까지 재생됩니다
- 마지막 슬라이드 후 반복 재생이 첫 번째부터 다시 시작됩니다
- 폴더에 단일 비디오가 있으면 제자리에서 반복됩니다

반복 재생은 기기에 저장된 파일에서 재생되므로 인터넷 연결 없이 계속 실행됩니다. 다른 콘텐츠와 동일한 리모컨 컨트롤을 사용할 수 있습니다 -- [수업 재생](../classroom-mode/playing-lessons) 참조.

## 슬라이드 업데이트

FreePlay는 앱이 시작될 때마다 공지 폴더를 확인하고, 새 슬라이드를 다운로드하고, 폴더에서 삭제된 슬라이드를 제거합니다.

즉시 확인하려면 제공자의 **제공자 설정**을 열고 **공지 업데이트 확인**을 선택합니다. 행은 완료되면 슬라이드 수와 함께 **최신 상태**를 표시합니다.

:::info
FreePlay가 제공자에 도달할 수 없거나 폴더가 비어 있으면 이미 있는 슬라이드를 계속 재생합니다. 공지를 완전히 중단하려면 아래에 설명된 대로 끕니다.
:::

:::warning
같은 파일 이름으로 새 버전으로 바뀐 슬라이드는 다시 다운로드되지 않습니다. 슬라이드를 변경하려면 새 파일로 추가하고 이전 파일을 삭제합니다.
:::

## 공지 끄기

제공자의 **제공자 설정**을 열고 **공지에 사용**을 다시 선택합니다. FreePlay가 폴더 사용을 중단하고, 기기에서 다운로드된 슬라이드를 삭제하고, 사이드바에서 **공지**를 제거합니다.

제공자를 연결 해제하면 해당 제공자로부터 온 공지도 꺼집니다.
