# 제공업체에 연결하기

<div class="article-intro">

제공업체의 콘텐츠를 탐색하려면 먼저 연결해야 합니다. 일부 제공업체는 QR 코드나 이메일 로그인을 통한 인증이 필요하며, 다른 제공업체는 클릭 한 번으로 연결할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- FreePlay를 설치하고 실행하세요 -- [시작하기](../getting-started/) 참조
- 탐색을 위해 TV 리모컨을 준비하세요
- 로그인이 필요한 제공업체의 경우, 계정 자격 증명을 준비하세요

</div>

:::tip B1 Admin과 FreePlay를 함께 설정하시나요?
저희의 **<a href="/guides/freeplay-b1admin" target="_blank">단계별 가이드</a>**는 B1 Admin 연결, 레슨 예약, FreePlay 연결까지 한 곳에서 안내합니다. 새 탭에서 열어 따라해 보세요.
:::

## 사용 가능한 제공업체 탐색하기

1. 사이드바에서 **콘텐츠 제공업체** 화면을 여세요 (하단의 **제공업체** 아이콘 선택)
2. 각 제공업체의 로고와 이름이 표시된 카드들이 그리드로 보입니다
3. 연결된 제공업체는 이름 아래에 녹색 **연결됨** 배지가 표시됩니다
4. 아직 사용할 수 없는 제공업체는 **출시 예정** 라벨이 표시됩니다

## 인증 없이 연결하기

일부 제공업체는 로그인이 필요하지 않습니다. 이러한 제공업체 중 하나를 선택하면 FreePlay가 즉시 연결하고 콘텐츠 브라우저를 엽니다. 자격 증명이 필요하지 않습니다.

## 기기 흐름 인증 (QR 코드)

일부 제공업체는 TV에서 스트리밍 앱에 로그인하는 방식과 유사한 기기 흐름을 사용합니다:

1. **콘텐츠 제공업체** 화면에서 제공업체 카드를 선택하세요
2. FreePlay가 QR 코드와 인증 URL을 표시합니다
3. 휴대폰으로 QR 코드를 스캔하거나, 표시된 URL을 다른 기기에서 방문하세요
4. TV 화면에 표시된 사용자 코드를 입력하세요
5. 휴대폰이나 컴퓨터에서 로그인 절차를 완료하세요
6. FreePlay가 로그인 성공을 감지하고 **연결됨!**을 표시합니다
7. 콘텐츠 브라우저가 자동으로 열립니다

:::info
깜빡이는 **인증 대기 중** 표시는 FreePlay가 로그인을 확인하고 있음을 나타냅니다. 코드는 몇 분 후 만료되므로 신속하게 절차를 완료하세요.
:::

**Go Curriculum**은 동일한 QR 코드 로그인 방식을 사용합니다 -- 코드를 스캔하고 gocurriculum.com 계정으로 로그인하여 연결하세요.

## 양식 로그인

다른 제공업체는 전통적인 이메일 및 비밀번호 로그인을 사용합니다:

1. 제공업체 카드를 선택하세요
2. 화면 키보드를 사용하여 **이메일**과 **비밀번호**를 입력하세요
3. **로그인** 버튼을 선택하세요
4. 자격 증명이 올바르면 FreePlay가 **연결됨!**을 표시하고 콘텐츠 브라우저를 엽니다

:::tip
리모컨의 방향 패드를 사용하여 이메일 필드, 비밀번호 필드, 로그인 버튼 사이를 이동하세요. 텍스트 필드에서 **선택**을 눌러 화면 키보드를 여세요.
:::

## 제공업체 연결 해제하기

이미 연결한 제공업체와의 연결을 해제하려면:

1. **콘텐츠 제공업체** 화면으로 이동하세요
2. **연결됨** 배지가 표시된 제공업체 카드를 선택하세요
3. 연결을 해제할지 확인하는 메시지가 표시됩니다
4. 연결을 제거하려면 **연결 해제**를 선택하세요

연결을 해제하면 해당 제공업체의 콘텐츠가 더 이상 사이드바에 표시되지 않습니다.

:::warning
연결을 해제하면 기기에 저장된 인증 정보가 제거됩니다. 나중에 다시 연결하려면 다시 로그인해야 합니다.
:::
