# 제공자에 연결하기

<div class="article-intro">

제공자의 콘텐츠를 찾아보려면 먼저 해당 제공자에 연결해야 합니다. 일부 제공자는 QR 코드나 이메일 로그인을 통한 인증이 필요하고, 다른 제공자는 한 번의 클릭으로 연결할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- FreePlay를 설치하고 실행하십시오 -- [시작하기](../getting-started/)를 참조하십시오
- TV 리모컨을 준비하십시오
- 로그인이 필요한 제공자의 경우 계정 자격 증명을 준비하십시오

</div>

:::tip B1 Admin과 FreePlay를 함께 설정하시나요?
**<a href="/guides/freeplay-b1admin" target="_blank">단계별 가이드</a>**에서 B1 Admin 연결, 레슨 예약, FreePlay 연결까지 한곳에서 안내합니다. 새 탭에서 열어 따라 하십시오.
:::

## 사용 가능한 제공자 찾아보기

1. 사이드바 하단의 **설정**을 열고 **제공자**를 선택하여 **콘텐츠 제공자** 화면을 엽니다
2. 각 제공자의 로고와 이름이 표시된 제공자 카드 그리드가 나타납니다
3. 연결된 제공자는 이름 아래에 녹색 **연결됨** 배지가 표시됩니다
4. 아직 사용할 수 없는 제공자에는 **출시 예정** 라벨이 표시됩니다

## 인증 없이 연결하기

일부 제공자는 로그인이 필요하지 않습니다. 이러한 제공자 중 하나를 선택하면 FreePlay가 즉시 연결하고 콘텐츠 브라우저를 엽니다. 자격 증명은 필요하지 않습니다.

## 기기 흐름 인증(QR 코드)

일부 제공자는 TV의 스트리밍 앱에 로그인하는 방식과 비슷한 기기 흐름을 사용합니다:

1. **콘텐츠 제공자** 화면에서 제공자 카드를 선택합니다
2. FreePlay가 제공자 이름, QR 코드, 확인 URL이 표시된 **다음에 연결** 화면을 보여 줍니다
3. 휴대폰으로 QR 코드를 스캔하거나, 아무 기기에서나 표시된 URL을 방문합니다
4. TV 화면에 표시된 코드를 입력합니다
5. 휴대폰이나 컴퓨터에서 로그인 과정을 완료합니다
6. FreePlay가 로그인 성공을 감지하고 **연결됨!**을 표시합니다
7. 콘텐츠 브라우저가 자동으로 열립니다

:::info
깜박이는 **확인 대기 중** 표시기는 FreePlay가 로그인을 확인하고 있음을 나타냅니다. 화면에는 코드가 만료되기까지 남은 시간(분)이 표시되므로 신속하게 과정을 완료하십시오. 시간이 다 되면 **새 코드 생성**을 선택하십시오.
:::

## 휴대폰 로그인(QR 코드 전용)

**Dropbox**, **OneDrive**, **Go Curriculum**은 입력할 코드 없이 약간 다른 QR 코드 로그인을 사용합니다:

1. **콘텐츠 제공자** 화면에서 제공자 카드를 선택합니다
2. FreePlay가 제공자 이름과 QR 코드가 표시된 **다음에 연결** 화면을 보여 줍니다
3. 휴대폰으로 QR 코드를 스캔하고 해당 제공자의 계정으로 로그인합니다(OneDrive는 Microsoft 계정, Go Curriculum은 gocurriculum.com 계정)
4. 액세스를 승인합니다. TV가 자동으로 연결되고 **연결됨!**을 표시합니다

화면에는 로그인을 마치기까지 남은 시간(분)이 표시됩니다.

## 양식 로그인

다른 제공자는 전통적인 이메일과 비밀번호 로그인을 사용합니다:

1. 제공자 카드를 선택합니다
2. 화면 키보드를 사용하여 **이메일**과 **비밀번호**를 입력합니다
3. **로그인** 버튼을 선택합니다
4. 자격 증명이 올바르면 FreePlay가 **연결됨!**을 표시하고 콘텐츠 브라우저를 엽니다

:::tip
리모컨의 방향 패드를 사용하여 이메일 필드, 비밀번호 필드, 로그인 버튼 사이를 이동하십시오. 텍스트 필드에서 **선택**을 누르면 화면 키보드가 열립니다.
:::

## 제공자 설정

**연결됨** 배지가 표시된 제공자 카드를 선택하면 **제공자 설정** 화면이 열립니다:

- **라이브러리 찾아보기** -- 사이드바에서 이 제공자의 콘텐츠 라이브러리를 표시하거나 숨깁니다
- **오늘의 레슨 자동 다운로드** -- 이 제공자를 오늘의 레슨 소스로 사용하고 파일을 미리 다운로드합니다(현재 레슨을 제공하는 제공자에만 표시됨)
- **공지에 사용** -- 이 제공자의 폴더를 선택하여 사이드바의 **공지** 항목에서 반복 재생합니다. [공지](./announcements)를 참조하십시오
- **공지 업데이트 확인** -- 공지 폴더를 선택하면 표시됩니다. 새 슬라이드를 다운로드하고 삭제된 슬라이드는 제거합니다
- **연결 해제** -- 연결을 제거합니다

## 제공자 연결 해제하기

이미 연결한 제공자의 연결을 해제하려면:

1. **콘텐츠 제공자** 화면(**설정** > **제공자**)으로 이동합니다
2. **연결됨** 배지가 표시된 제공자 카드를 선택합니다
3. **제공자 설정** 화면에서 **연결 해제**를 선택합니다

연결을 해제하면 해당 제공자의 콘텐츠는 사이드바에 더 이상 나타나지 않습니다. 해당 제공자의 폴더를 공지에 사용하고 있었다면 그 슬라이드도 함께 제거됩니다.

:::warning
연결을 해제하면 기기에 저장된 인증 정보가 제거됩니다. 나중에 다시 연결하려면 다시 로그인해야 합니다.
:::
