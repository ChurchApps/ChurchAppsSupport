# 콘텐츠 찾아보기 및 다운로드

<div class="article-intro">

콘텐츠 제공자에 연결하면 라이브러리를 탐색하고, 파일을 다운로드하고, TV에서 재생할 수 있습니다. 콘텐츠 브라우저는 폴더와 파일을 시각적인 그리드로 보여 주며, TV 리모컨으로 탐색할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 하나 이상의 콘텐츠 제공자에 연결하십시오 -- [제공자에 연결하기](./connecting-providers)를 참조하십시오
- TV 리모컨을 준비하십시오

</div>

## 콘텐츠 브라우저

콘텐츠 브라우저는 3열 카드 그리드로 항목을 표시합니다. 각 카드에는 썸네일 이미지와 제목이 표시됩니다. 항목에는 두 가지 유형이 있습니다:

- **폴더** - 썸네일 또는 폴더 아이콘으로 표시됩니다. 폴더를 선택하면 내용을 볼 수 있습니다.
- **파일** - 개별 미디어 항목(비디오 또는 이미지)입니다. 비디오 파일은 썸네일 위에 재생 아이콘이 겹쳐 표시됩니다.

화면 상단의 헤더에는 현재 폴더의 이름이 표시되며, 최상위 수준에 있을 때는 제공자 이름이 표시됩니다.

## 폴더 탐색하기

1. 리모컨의 방향 패드를 사용하여 폴더를 강조 표시합니다
2. **선택**을 눌러 폴더를 엽니다
3. 브라우저가 폴더의 내용을 불러옵니다. 하위 폴더이거나 재생 가능한 파일일 수 있습니다
4. 리모컨의 **뒤로**를 눌러 한 단계 위로 올라갑니다

제공자의 콘텐츠 구조가 허용하는 만큼 깊이 들어갈 수 있습니다. 브라우저는 폴더 경로를 기억하므로 각 단계를 거슬러 이동할 수 있습니다.

## Lessons.church 찾아보기

[Lessons.church](../../lessons-church/) 라이브러리는 웹사이트와 같은 방식으로 구성되어 있습니다. 최상위 수준에는 두 개의 폴더가 있습니다:

- **Lessons** - **프로그램**, **학습**, **레슨** 순으로 들어갑니다. 각 레슨에는 **베뉴(venue)** 목록이 표시됩니다. 베뉴는 유아부나 초등부처럼 특정 연령대나 환경을 위한 레슨의 버전입니다. 베뉴를 선택하면 해당 레슨 버전의 다운로드 화면이 열립니다
- **Add-Ons** - 카테고리별로 정리된 추가 비디오 및 자료

어느 단계에서든 **뒤로**를 누르면 한 단계 위로 올라갑니다.

## 콘텐츠 다운로드 및 재생

재생 가능한 파일이 들어 있는 폴더(또는 개별 파일)를 선택하면, FreePlay는 콘텐츠 제목과 표지 이미지, 그리고 두 가지 선택지를 표시합니다:

- **다운로드** - 모든 파일을 먼저 TV에 저장하므로 재생이 Wi-Fi에 의존하지 않습니다. 각 파일이 저장될 때마다 진행률 표시줄이 채워집니다. 완료되면 재생 아이콘이 있는 **시작** 버튼이 나타납니다. **선택**을 눌러 재생을 시작하십시오
- **스트리밍** - 파일을 저장하지 않고 인터넷을 통해 바로 재생을 시작합니다

:::tip
교회 건물의 인터넷 연결이 좋은 일요일 아침 전에 레슨을 다운로드하십시오. 한 번 다운로드하면 콘텐츠는 오프라인에서도 재생되며, 나중에 다시 재생하면 다시 다운로드하지 않고 즉시 로드됩니다.
:::

## 다운로드 관리

사이드바 하단의 **설정**을 열고 **다운로드**를 선택하면 이 TV에 저장된 모든 항목을 볼 수 있습니다:

- 다운로드 항목을 선택하면 재생됩니다
- 다운로드 항목을 강조 표시한 다음 모서리의 삭제 아이콘을 선택하면 해당 항목이 제거되고 저장 공간이 확보됩니다

화면에 **다운로드된 항목이 없습니다**가 표시되면 이 TV에는 아무것도 저장되어 있지 않은 것입니다.

## 제공자 콘텐츠 재생하기

재생 중에는 다음 컨트롤을 사용하십시오:

- **오른쪽 화살표** - 다음 항목
- **왼쪽 화살표** - 이전 항목
- **선택 / 재생-일시정지** - 비디오 일시정지 또는 재개
- **위쪽 화살표** - 메시지 선택기를 열어 특정 항목으로 이동
- **뒤로** - 콘텐츠 브라우저로 나가기

플레이어를 종료하면 현재 제공자의 최상위 수준에 있는 콘텐츠 브라우저로 돌아갑니다.

:::info
모든 플레이어 컨트롤에 대한 전체 참조는 [콘텐츠 재생](./playing-content)을 참조하십시오.
:::

## 제공자 전환하기

연결된 제공자는 왼쪽 사이드바의 **찾아보기** 제목 아래에 항목으로 표시됩니다. 다른 제공자로 전환하려면 다음과 같이 하십시오:

1. 리모컨의 **왼쪽** 화살표를 눌러 사이드바를 펼칩니다
2. 찾아보려는 제공자를 선택합니다
3. 콘텐츠 브라우저가 해당 제공자의 라이브러리로 새로 고쳐집니다

:::warning
폴더에 "사용할 수 있는 콘텐츠가 없습니다"라고 표시되면, 해당 수준에 제공자의 항목이 없는 것입니다. 다른 폴더로 이동하거나 나중에 다시 확인해 보십시오.
:::
