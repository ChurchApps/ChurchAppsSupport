# 콘텐츠 둘러보기 및 다운로드

<div class="article-intro">

콘텐츠 제공자에 연결하면 해당 제공자의 라이브러리를 둘러보고, 파일을 다운로드하고, TV에서 재생할 수 있습니다. 콘텐츠 브라우저에는 폴더와 파일이 시각적인 격자 형태로 표시되며, TV 리모컨으로 이동할 수 있습니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 최소 하나의 콘텐츠 제공자에 연결하세요 -- [제공자 연결하기](./connecting-providers.md)를 참고하세요
- TV 리모컨을 준비하세요

</div>

## 콘텐츠 브라우저

콘텐츠 브라우저는 항목을 3열 카드 격자로 표시합니다. 각 카드에는 썸네일 이미지와 제목이 나타납니다. 항목은 두 가지 유형이 있습니다.

- **폴더** - 썸네일이나 폴더 아이콘으로 표시됩니다. 폴더를 선택하면 내용을 볼 수 있습니다.
- **파일** - 개별 미디어 항목(동영상 또는 이미지)입니다. 동영상 파일은 썸네일 위에 재생 아이콘이 표시됩니다.

화면 상단의 헤더에는 현재 폴더의 이름이 표시되며, 최상위 수준에 있을 때는 제공자 이름이 표시됩니다.

## 폴더 탐색하기

1. 리모컨의 방향 패드를 사용하여 폴더를 강조 표시합니다
2. **선택** 버튼을 눌러 폴더를 엽니다
3. 브라우저가 폴더의 내용을 불러옵니다. 하위 폴더이거나 재생 가능한 파일일 수 있습니다
4. 리모컨의 **뒤로** 버튼을 눌러 한 단계 위로 올라갑니다

제공자의 콘텐츠 구조가 허용하는 만큼 깊이 들어갈 수 있습니다. 브라우저는 폴더 경로를 기억하므로 각 단계를 거쳐 다시 돌아갈 수 있습니다.

## Lessons.church 둘러보기

[Lessons.church](../../lessons-church/index.md) 라이브러리는 웹사이트와 같은 방식으로 구성되어 있습니다. 최상위 수준에는 두 개의 폴더가 있습니다.

- **Lessons** - **프로그램**, **학습**, **레슨** 순서로 들어갑니다. 각 레슨에는 **베뉴(venue)** 목록이 나타나는데, 베뉴는 특정 연령대나 환경(예: 유아부 또는 초등부)에 맞춘 레슨의 버전입니다. 베뉴를 선택하면 해당 버전의 다운로드 화면이 열립니다
- **Add-Ons** - 카테고리별로 분류된 추가 동영상과 자료

어느 단계에서든 **뒤로** 버튼을 누르면 한 단계 위로 올라갑니다.

## Go Curriculum 둘러보기

[gocurriculum.com 계정으로 로그인](./connecting-providers.md#phone-sign-in-qr-code-only)하면 Go Curriculum이 연령대인 **Elementary**와 **Preschool**을 보여줍니다. 연령대, 컬렉션, 레슨 순서로 들어가고, 레슨을 선택하면 다운로드 화면이 열립니다.

보이는 내용은 Go 멤버십에 따라 달라집니다.

- 멤버십이 포함하는 연령대만 표시됩니다. 로그인한 계정에 Go 멤버십이 없다면 라이브러리가 비어 있습니다
- 일부 동영상은 특정 멤버십 등급에서만 볼 수 있습니다. 멤버십에 포함되지 않은 동영상은 레슨에서 제외됩니다

## 콘텐츠 다운로드 및 재생하기

재생 가능한 파일이 들어 있는 폴더를 선택하거나(또는 개별 파일을 선택하면), FreePlay는 콘텐츠 제목과 표지 이미지, 그리고 두 가지 선택지를 보여줍니다.

- **다운로드** - 모든 파일을 먼저 TV에 저장하므로 재생이 Wi-Fi에 의존하지 않습니다. 각 파일이 저장될 때마다 진행 막대가 채워집니다. 완료되면 재생 아이콘이 있는 **시작** 버튼이 나타납니다. **선택** 버튼을 눌러 재생을 시작하세요
- **스트리밍** - 파일을 저장하지 않고 인터넷을 통해 바로 재생을 시작합니다

:::tip
교회 건물의 인터넷 연결이 안정적일 때 주일 아침 전에 레슨을 다운로드하세요. 다운로드가 끝나면 콘텐츠는 오프라인에서도 재생되며, 나중에 다시 재생하면 다시 다운로드하지 않고 즉시 불러옵니다.
:::

## 다운로드 관리하기

사이드바 하단의 **설정**을 연 다음 **다운로드**를 선택하면 이 TV에 저장된 모든 항목을 볼 수 있습니다.

- 다운로드 항목을 선택하면 재생됩니다
- 항목을 강조 표시한 후 모서리의 삭제 아이콘을 선택하면 해당 항목을 제거하고 저장 공간을 확보할 수 있습니다

화면에 **아직 다운로드된 항목이 없습니다**라고 표시되면, 이 TV에는 아무것도 저장되어 있지 않은 것입니다.

## 제공자 콘텐츠 재생하기

재생 중에는 다음 컨트롤을 사용하세요.

- **오른쪽 화살표** - 다음 항목
- **왼쪽 화살표** - 이전 항목
- **선택 / 재생-일시정지** - 동영상 일시정지 또는 재개
- **위쪽 화살표** - 메시지 선택기를 열어 특정 항목으로 이동
- **뒤로** - 콘텐츠 브라우저로 나가기

플레이어를 종료하면 현재 제공자의 최상위 수준에 있는 콘텐츠 브라우저로 돌아갑니다.

:::info
모든 플레이어 컨트롤에 대한 전체 참고 자료는 [콘텐츠 재생하기](./playing-content.md)를 참고하세요.
:::

## 제공자 전환하기

연결된 제공자는 왼쪽 사이드바의 **Browse** 제목 아래에 항목으로 표시됩니다. 다른 제공자로 전환하려면 다음과 같이 하세요.

1. 리모컨의 **왼쪽** 화살표를 눌러 사이드바를 펼칩니다
2. 둘러보고 싶은 제공자를 선택합니다
3. 콘텐츠 브라우저가 해당 제공자의 라이브러리로 새로 고쳐집니다

:::warning
폴더에 "사용 가능한 콘텐츠가 없습니다"라고 표시되면, 해당 수준에 제공자의 항목이 없는 것입니다. 다른 폴더로 이동하거나 나중에 다시 확인해 보세요.
:::
