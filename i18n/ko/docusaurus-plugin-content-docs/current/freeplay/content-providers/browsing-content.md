# 콘텐츠 찾기 및 다운로드

<div class="article-intro">

콘텐츠 제공자에 연결한 후 그 라이브러리를 찾고, 파일을 다운로드하고, TV에서 재생할 수 있습니다. 콘텐츠 브라우저는 TV 리모컨으로 네비게이트하는 폴더 및 파일의 시각적 그리드를 제공합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 최소 하나의 콘텐츠 제공자에 연결합니다 -- [제공자에 연결](./connecting-providers) 참조
- TV 리모컨을 네비게이션 준비합니다

</div>

## 콘텐츠 브라우저

콘텐츠 브라우저는 항목을 3열 카드 그리드로 표시합니다. 각 카드는 썸네일 이미지와 제목을 표시합니다. 두 가지 유형의 항목이 있습니다:

- **폴더** - 썸네일 또는 폴더 아이콘으로 나타납니다. 폴더를 선택하여 그 내용을 봅니다.
- **파일** - 개별 미디어 항목(비디오 또는 이미지). 비디오 파일은 그들의 썸네일에 재생 아이콘 오버레이를 표시합니다.

화면 상단의 헤더는 현재 폴더의 이름을 표시하거나, 루트 레벨에 있으면 제공자 이름을 표시합니다.

## 폴더 네비게이션

1. 리모컨의 방향 패드를 사용하여 폴더를 하이라이트합니다
2. **Select**를 눌러서 엽니다
3. 브라우저가 폴더의 내용을 로드하고, 더 많은 폴더 또는 재생 가능한 파일일 수 있습니다
4. 리모컨의 **Back**을 눌러서 한 수준 위로 갑니다

제공자의 콘텐츠 구조가 허용하는 만큼 깊이 드릴할 수 있습니다. 브라우저는 각 수준을 통해 네비게이트할 수 있도록 폴더 경로를 추적합니다.

## 콘텐츠 다운로드 및 재생

재생 가능한 파일을 포함하는 폴더를 선택하거나 개별 파일을 선택할 때 FreePlay는 다운로드 화면으로 이동합니다:

1. 콘텐츠 제목이 화면에 나타나고 선택한 폴더의 커버 이미지를 표시합니다
2. 진행 표시줄은 파일이 기기에 저장되면서 **Downloading item X of Y**를 표시합니다
3. 다운로드가 완료되면 재생 아이콘과 함께 **Start** 버튼이 나타납니다
4. **Select**를 누르면 재생을 시작합니다

:::tip
다운로드된 콘텐츠는 TV에 캐시됩니다. 나중에 동일한 콘텐츠를 재생하면 다시 다운로드하지 않고도 즉시 로드됩니다.
:::

## 제공자 콘텐츠 재생

재생은 레슨 재생과 동일한 방식으로 작동합니다. 이 컨트롤을 사용합니다:

- **오른쪽 화살표** - 다음 항목
- **왼쪽 화살표** - 이전 항목
- **Select / Play-Pause** - 비디오 일시 중지 또는 재개
- **위쪽 화살표** - 메시지 선택기를 열어 특정 항목으로 점프합니다
- **Back** - 콘텐츠 브라우저로 종료합니다

플레이어를 종료하면 현재 제공자의 루트 레벨의 콘텐츠 브라우저로 돌아갑니다.

:::info
모든 플레이어 컨트롤의 전체 참조는 [Playing Lessons](../classroom-mode/playing-lessons) 참조합니다.
:::

## 제공자 사이 전환

연결된 제공자는 왼쪽 사이드바의 **Browse** 제목 아래에 항목으로 나타납니다. 다른 제공자로 전환하려면:

1. 리모컨의 **Left** 화살표를 누르면 사이드바를 확장합니다
2. 찾고자 하는 제공자를 선택합니다
3. 콘텐츠 브라우저가 그 제공자의 라이브러리로 새로 고칩니다

:::warning
폴더가 "No content available"을 표시하면 제공자가 그 수준에서 항목을 가지지 않습니다. 다른 폴더로 네비게이트하거나 나중에 다시 확인해보세요.
:::
