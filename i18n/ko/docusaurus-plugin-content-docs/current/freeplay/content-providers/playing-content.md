# 콘텐츠 재생

<div class="article-intro">

FreePlay 플레이어는 화면을 가득 채우며 TV 리모컨에 맞게 만들어졌습니다. 제공자, 다운로드한 수업, 계획, 또는 공지 폴더의 동영상과 이미지 슬라이드를 재생하며, 자동으로 또는 사용자의 속도에 맞춰 넘어갑니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- 재생할 항목을 고르십시오. [콘텐츠 찾아보기 및 다운로드](./browsing-content), [계획 모드](../plan-mode/), 또는 [공지](./announcements)를 참조하십시오
- **Start**를 눌러 플레이어를 여십시오

</div>

:::info
캘린더에 연결된 화면은 조작이 약간 다른 별도의 예약 플레이어를 사용합니다. [TV에서 예약 재생](../scheduled-mode/scheduled-playback)을 참조하십시오.
:::

## 플레이어 조작

TV 리모컨으로 재생을 조작합니다:

| 리모컨 버튼 | 동작 |
|---|---|
| **Select / Play-Pause**(선택 / 재생-일시정지) | 일시 정지 또는 재생 재개 |
| **오른쪽 화살표** | 다음 슬라이드 또는 동영상으로 건너뛰기 |
| **왼쪽 화살표** | 이전 슬라이드 또는 동영상으로 돌아가기 |
| **Fast Forward**(빨리 감기) | 동영상에서 10초 앞으로 이동. 슬라이드에서는 다음 항목으로 이동 |
| **Rewind**(되감기) | 동영상에서 10초 뒤로 이동. 슬라이드에서는 이전 항목으로 이동 |
| **위 화살표** | 특정 항목으로 이동하려면 **Select a Message**(메시지 선택) 열기 |
| **Down / Back**(아래 / 뒤로) | 플레이어 종료 |

:::tip
터치를 지원하는 리모컨에서는 스와이프로도 조작할 수 있습니다. 왼쪽으로 스와이프하면 앞으로, 오른쪽으로 스와이프하면 뒤로 갑니다. 아래로 스와이프하면 **Select a Message**가 열리고, 위로 스와이프하면 플레이어를 종료합니다.
:::

## 동영상과 슬라이드

일시 정지하면 콘텐츠 위에 일시 정지 아이콘이 나타납니다. 다시 재개하려면 **Select** 또는 **Play-Pause**를 누르십시오.

동영상은 끝나면 다음 항목으로 넘어갑니다. 반복으로 설정된 동영상은 건너뛸 때까지 계속 반복됩니다.

이미지 슬라이드는 몇 초 후 스스로 넘어갑니다(제공자가 별도의 시간을 설정하지 않은 경우 5초). 더 빨리 넘어가려면 **오른쪽 화살표**를 누르고, 슬라이드를 화면에 머물게 하려면 일시 정지하십시오.

## 메시지 선택

재생 중에 **위**를 눌러 **Select a Message**를 엽니다. 모든 항목이 썸네일과 제목과 함께 나타나며, 재생 중인 항목에는 **NOW PLAYING**이 표시됩니다. 원하는 항목으로 이동하여 **Select**를 누르면 바로 그 항목으로 갑니다. 아무것도 바꾸지 않고 닫으려면 **Back**을 누르십시오.

## 플레이어 종료하기

리모컨의 **Down** 또는 **Back**을 누르면 플레이어를 나갑니다. 어디로 돌아가는지는 재생하던 내용에 따라 다릅니다:

- **제공자 콘텐츠** - 콘텐츠 찾아보기 화면으로 돌아갑니다
- **계획** - 계획 다운로드 화면으로 돌아갑니다. [계획 모드](../plan-mode/)를 참조하십시오
- **다운로드** - **Downloads** 화면으로 돌아갑니다

:::info
플레이어가 열려 있는 동안에는 화면이 켜진 상태로 유지되므로, 수업 도중 TV가 절전 모드로 들어가지 않습니다.
:::
