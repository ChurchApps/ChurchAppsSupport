# 계획 모드

<div class="article-intro">

계획 모드는 TV를 교회의 예배 계획에 연결합니다. 교실 일정에 따라 콘텐츠를 가져오는 대신, B1 Admin에서 교회 리더십이 설정한 계획을 따라갑니다. 이번 주 계획에 배정된 내용을 TV가 정확히 보여주기를 원할 때 이상적입니다.

</div>

## 다른 모드와의 차이점

- **[예약 모드](../scheduled-mode/)**는 FreePlay Admin의 캘린더에서 설정한 시간에 재생 목록을 재생하며, 아무도 Start를 누르지 않습니다
- **계획 모드**는 계획 유형에 연결된 콘텐츠를 가져오며, 수업, 제공자 프레젠테이션, 추가 자료, 그 밖의 미디어를 원하는 순서로 배치한 콘텐츠를 포함할 수 있습니다

계획 모드는 여러 출처의 콘텐츠가 섞여 있고 모두 하나의 순서로 정리된 예배 계획을 사용할 때 특히 유용합니다.

:::tip
현재 계획을 정해진 시간에 저절로 재생하고 싶으신가요? FreePlay Admin에서 캘린더 항목을 추가하고 **Service plans**(예배 계획) 아래에서 계획 유형을 선택하십시오. [캘린더 예약하기](../scheduled-mode/scheduling-the-calendar)를 참조하십시오.
:::

## 작동 방식

1. TV에서 **Settings** > **Pair to a calendar**(캘린더에 연결)를 열어 연결 코드를 표시합니다
2. 관리자가 B1 Admin에 그 코드를 입력하고 **Show Plans For**(다음 계획 표시) 아래에서 계획 유형을 선택합니다
3. 연결되면 FreePlay가 현재 계획을 불러오고 관련된 모든 미디어를 다운로드합니다
4. **Start Plan**을 눌러 재생을 시작합니다

TV는 계획 유형에 계속 연결된 상태로 유지됩니다. 매주 최신 계획과 그 콘텐츠를 자동으로 가져옵니다.
