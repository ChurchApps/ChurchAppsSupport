# 기기 페어링하기

<div class="article-intro">

플랜 모드를 사용하려면 TV를 B1 Admin의 플랜 유형과 페어링해야 합니다. FreePlay는 기기를 교회의 플랜에 연결하는 고유한 페어링 코드를 생성하여 매주 자동으로 콘텐츠를 전달합니다.

</div>

<div class="prereqs">
<h4>시작하기 전에</h4>

- FreePlay를 설치하고 실행하세요 -- [시작하기](../getting-started/) 참조
- [페어링 모드 화면](../getting-started/pairing-modes.md)에서 **플랜에 페어링**을 선택하세요
- 페어링을 완료하려면 컴퓨터나 휴대폰에서 **B1 Admin**에 접근할 수 있어야 합니다

</div>

## 페어링 코드 생성하기

1. **페어링 모드 선택** 화면에서 **플랜에 페어링**을 선택하세요
2. FreePlay가 서버에 접속하여 짧은 페어링 코드를 생성합니다
3. 코드가 화면 중앙에 큰 글자로 표시됩니다
4. 코드 아래에 깜빡이는 **연결 대기 중** 표시가 나타납니다

코드는 방 건너편에서도 쉽게 읽을 수 있도록 개별 문자로 표시됩니다.

## B1 Admin에서 코드 입력하기

1. 컴퓨터나 휴대폰에서 TV의 코드 아래에 표시된 주소로 이동하세요(또는 화면의 QR 코드를 스캔하세요) -- 이렇게 하면 B1 Admin의 **기기 인증** 페이지가 열립니다
2. QR 코드에서 자동으로 채워지지 않았다면 페어링 코드를 입력하세요
3. **플랜 표시 대상**에서 이 화면이 따를 플랜 유형을 선택하세요(예: "주일 예배"). 콘텐츠나 알림을 탐색하는 용도로만 화면을 사용하고 플랜을 연결하지 않으려면 **없음**으로 두세요
4. 기기를 승인하세요

FreePlay는 몇 초마다 서버에 페어링이 완료되었는지 확인합니다. **B1 Admin**이 연결을 확인하면 TV가 자동으로 플랜 다운로드 화면으로 이동합니다.

:::tip
동일한 코드를 사용하여 B1 Admin의 **프로필 → 기기 → 기기 추가**에서도 기기를 페어링할 수 있습니다 -- 동일한 **플랜 표시 대상** 플랜 유형 선택기를 제공합니다.
:::

## 플랜 콘텐츠 다운로드하기

페어링 후 FreePlay는 해당 플랜 유형의 현재 플랜을 불러옵니다. 다음이 표시됩니다:

- 플랜 이름과 예배 날짜
- 연결된 레슨 이름(플랜에 레슨 콘텐츠가 포함된 경우)
- **X/Y 항목 다운로드 중**을 보여주는 진행률 표시기

모든 미디어 파일이 다운로드되면 **플랜 시작** 버튼이 나타납니다. 리모컨의 **선택**을 눌러 재생을 시작하세요.

:::tip
플랜은 매시간 자동으로 새로고침됩니다. 하루 중 플랜이 업데이트되면 FreePlay는 별도의 수동 조작 없이 변경 사항을 반영합니다.
:::

## 대안: 교회 이름으로 검색하기

페어링 코드 흐름을 사용하고 싶지 않다면 페어링 화면 하단의 **또는 교회 이름으로 검색**을 선택할 수 있습니다. 그러면 교회 검색 화면으로 이동하여 교회를 찾고 대신 교실에 연결할 수 있습니다.

## 페어링에 실패한 경우

페어링 코드를 생성할 수 없는 경우(예: 네트워크 문제로 인해) **다시 시도** 버튼이 있는 오류 메시지가 표시됩니다. TV가 인터넷에 연결되어 있는지 확인한 후 다시 시도하세요.

:::warning
페어링 코드는 일정 기간 후 만료됩니다. 너무 오래 기다렸다면 페어링 화면으로 돌아가 새 코드를 생성하세요.
:::
