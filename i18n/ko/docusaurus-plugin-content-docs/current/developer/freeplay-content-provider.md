# FreePlay 콘텐츠 제공업체

<div class="article-intro">

FreePlay는 휴대폰, 태블릿, TV에서 공과와 기타 비디오 콘텐츠를 스트리밍하는 ChurchApps의 미디어 플레이어입니다. 공과 콘텐츠 라이브러리가 있고 이를 FreePlay에서 제공하고 싶다면, 이 가이드에 필요한 모든 내용이 있습니다.

</div>

## 브랜딩

연동을 시작하기 전에 다음이 필요합니다.

- **로고** -- **16:9** 비율의 로고 이미지(FreePlay UI의 제공업체 카드에 사용됨)
- **브랜드 이름** -- FreePlay에 표시할 조직의 원하는 이름

## API 엔드포인트

FreePlay는 몇 가지 REST 엔드포인트를 통해 서비스와 통신합니다. 제공업체마다 맞춤 어댑터를 작성하므로 정확한 URL 구조는 유연하지만, 아래 정보는 필요합니다.

### 인증

콘텐츠에 맞는 방식을 선택하세요.

| 방식 | 사용 시기 | 필요한 정보 |
|-------|-------------|--------------|
| **없음** | 공개 콘텐츠, 로그인 불필요 | 없음 -- 카탈로그 엔드포인트를 직접 호출합니다 |
| **OAuth (PKCE)** | 웹/모바일 로그인 | 인증 URL, 토큰 교환 엔드포인트, 클라이언트 ID, 범위 |
| **Device Flow** | TV 앱에 권장(사용자가 휴대폰에서 짧은 코드를 입력) | 기기 인증 엔드포인트, 토큰 폴링 엔드포인트, 클라이언트 ID |

:::tip
콘텐츠에 인증이 필요하다면, 인증 엔드포인트는 FreePlay가 탐색 및 공과 엔드포인트에 전달하여 접근을 승인받는 **사용자 토큰**을 반환해야 합니다.
:::

### 탐색 / 카탈로그

사용 가능한 모든 공과의 **폴더 트리**를 반환하는 엔드포인트(또는 엔드포인트 집합)입니다.

- 전체 트리를 반환하는 **단일 호출**일 수도 있고, 사용자가 더 깊이 들어갈 때마다 한 단계씩 반환하는 **여러 호출**일 수도 있습니다.
- 트리의 각 항목에는 다음이 포함되어야 합니다.

| 필드 | 필수 여부 | 설명 |
|-------|-----------|------|
| `id` | 예 | 폴더의 고유 식별자 |
| `name` | 예 | 폴더의 표시 이름 |
| `thumbnail` | 권장 | **16:9** 썸네일 URL |

### 공과 재생 목록

단일 공과의 **미디어 파일 재생 목록**을 반환하는 엔드포인트입니다.

재생 목록의 각 항목에는 다음이 포함되어야 합니다.

| 필드 | 필수 여부 | 설명 |
|-------|-----------|------|
| `title` | 예 | 미디어 항목의 표시 제목 |
| `mediaType` | 예 | `video` 또는 `image` |
| `url` | 예 | 파일에 대한 직접 다운로드 링크(아래 [미디어 형식](#media-formats) 참조) |
| `thumbnail` | 권장 | 항목의 썸네일 이미지 |
| `duration` | 권장 | 초 단위 길이(동영상의 경우) |

## 미디어 형식

FreePlay는 파일을 직접 다운로드하므로, 모든 미디어 항목은 **직접 링크**를 가져야 합니다(내장 플레이어나 페이지 리디렉션 불가).

| 유형 | 허용 형식 |
|------|-----------------|
| 동영상 | **MP4** (Apple 및 Android 기기에서 플랫폼 간 재생에 필수) |
| 이미지 | JPG, PNG 또는 GIF |
