# Webhooks

<div class="article-intro">

Webhooks를 사용하여 B1 이벤트를 다른 시스템에 동기화합니다.

</div>

## Webhook 생성

1. B1 Admin에서 **설정 > 개발자 > Webhooks**로 이동합니다.
2. **Webhook 추가**를 클릭합니다.
3. 이벤트 유형과 대상 URL을 선택합니다.
4. **저장**을 클릭합니다.
