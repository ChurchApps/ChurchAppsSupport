# 아키텍처
<div class="article-intro">
이 페이지는 핵심 ChurchApps 시스템의 크로스 레포 맵입니다. 이는 단일 프로젝트 설정이 아니라, 한 시스템이 전체적으로 어떻게 작동하는지를 문서화합니다.
</div>

## 생태계 한눈에

ChurchApps는 ~20개의 독립적인 레포지토리입니다. 클라이언트 앱은 HTTPS 및 WebSocket을 통해 백엔드 API와 통신합니다.

```
┌────────────────────────────────┐            ┌──────────────────────────────────────────┐
│  클라이언트                    │            │  API — 핵심 모듈식 모놀리스          │
│                                │            │                                          │
│  B1Admin      직원 대시보드    │   HTTPS    │   멤버십    출석    콘텐츠           │
│  B1App       회원 포털 +       │ ─────────▶ │   기부금    메시징   진행            │
│             교회 웹사이트      │ ◀───WS───▶ │                                          │
│  B1Checkin   체크인 키오스크   │            │   모듈당 하나의 MySQL 데이터베이스   │
│  B1Mobile  (유지 관리만)      │            └──────────────────────────────────────────┘
│  FreePlay    TV 콘텐츠 플레이어│
└───────────────┬────────────────┘
                │  npm를 통한 공유 코드 (@churchapps/*)
                ▼
   helpers · apphelper · apihelper
```
