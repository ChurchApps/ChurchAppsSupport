# Navegando pelos grupos

<div class="article-intro">

A página pública de grupos da sua igreja facilita a descoberta de grupos que despertam o seu interesse. Pesquise pelo nome ou restrinja a lista por categoria ou campus para encontrar o grupo ideal.

## Encontrando a página de grupos {#finding-the-groups-page}

Acesse a página **Encontre um grupo** (`/groups`) no site do B1.church da sua igreja. Essa página é pública, então você não precisa estar conectado para navegar. No portal de membros, o botão **Encontre um grupo** na tela **Grupos** abre a mesma página.

## Pesquisando e filtrando {#searching-and-filtering}

Todos os grupos públicos da igreja são exibidos juntos. Use os controles acima da lista para refiná-la:

- **Pesquisar grupos por nome ou descrição** -- Digite uma palavra para mostrar apenas os grupos cujo nome, descrição ou categoria a contenham.
- **Categoria** -- Escolha uma categoria, como "Pequenos Grupos", "Jovens" ou "Música", para mostrar apenas os grupos dela. Escolha **Todas as categorias** para ver tudo novamente. As categorias são configuradas pelos administradores da sua igreja, e este filtro só aparece quando há mais de uma.
- **Campus** -- Se sua igreja tiver mais de um campus, escolha um para ver apenas os grupos atribuídos a ele, ou **Todos os campus** para vê-los todos.

Se nada corresponder, a página diz "Nenhum grupo corresponde aos seus filtros."

Sua igreja também pode criar um link para a página de um único marcador de grupo, como `/groups/youth`, que lista apenas os grupos com esse marcador.

## Lendo os cartões de grupo {#reading-group-cards}

Cada grupo é exibido como um cartão com as seguintes informações:

- **Foto do grupo** -- Uma imagem de capa que representa o grupo. Se nenhuma foto tiver sido definida, é exibida uma imagem padrão.
- **Nome do grupo** -- Exibido em destaque sobre a foto.
- **Horário de encontro** -- Quando o grupo costuma se reunir (por exemplo, "Quartas às 19h"). Se nenhum horário estiver definido, aparece "--".
- **Local de encontro** -- Onde o grupo se reúne, à direita. Se nenhum local estiver definido, aparece "--".
- **Descrição** -- Uma breve prévia do que é o grupo, limitada a algumas linhas. Se o grupo não tiver descrição, o cartão diz "Nenhuma descrição informada." Clique no grupo para ler a descrição completa.

## Vendo um grupo {#viewing-a-group}

Clique em qualquer cartão de grupo para abrir a página completa de detalhes no portal de membros. Lá você encontra a descrição completa, os líderes do grupo, os próximos eventos e uma forma de participar.

:::tip
Se você procura um tipo específico de grupo, escolha-o primeiro no filtro **Categoria**. Assim você evita rolar por todos os grupos.
:::

## Seus grupos no portal de membros {#your-groups-in-the-member-portal}

A tela **Grupos** no portal de membros lista os grupos de que você participa. O cabeçalho mostra quantos grupos você integra (e quantas solicitações de participação estão pendentes).

- **Pesquisar seus grupos** -- Filtre seus grupos pelo nome.
- **Seus grupos** -- Os grupos que você mais abre, até cinco, cada um com seu horário e local de encontro. Toque em um deles para abri-lo.
- **Outros grupos** -- Os demais grupos de que você participa.
- **Solicitações pendentes** -- Grupos em que você pediu para entrar e que aguardam um líder. Veja [Solicitando participação em um grupo](./join-requests.md).
- **Próximos eventos** -- Eventos da igreja que aceitam inscrições, cada um com um link **Inscrever-se**. Veja [Inscrevendo-se em eventos](../events/registering.md).

Toque em **Encontre um grupo** para navegar por todos os grupos da igreja. Se você ainda não participa de nenhum grupo, a tela diz "Nenhum grupo ainda" com um botão **Navegar por grupos**; se você não estiver conectado, ela pede que você entre para ver seus grupos, mas ainda lista os **Próximos eventos** da igreja que aceitam inscrições para que você possa se inscrever.
