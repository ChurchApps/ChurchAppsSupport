# Navegando por grupos

<div class="article-intro">

A página pública de grupos da sua igreja facilita a descoberta de grupos que te interessam. Os grupos são organizados por categoria, para que você possa percorrer rapidamente os diferentes tipos de grupos e encontrar o ideal.

## Encontrando a página de grupos

Acesse a página **Grupos** no site B1.church da sua igreja. Ela é pública, então você não precisa estar conectado para navegar.

## Como os grupos são organizados

Os grupos são exibidos por **categoria** (também chamada de rótulo). As categorias são configuradas pelos administradores da igreja e podem incluir rótulos como "Pequenos grupos", "Ministérios", "Jovens" ou "Estudos bíblicos". Cada categoria mostra todos os grupos que pertencem a ela.

## Lendo os cartões dos grupos

Cada grupo é exibido como um cartão com as seguintes informações:

- **Foto do grupo** -- Uma imagem de capa que representa o grupo. Se nenhuma foto tiver sido definida, é exibida uma imagem padrão.
- **Nome do grupo** -- Exibido em destaque sobre a foto.
- **Horário de encontro** -- Quando o grupo normalmente se reúne (por exemplo, "Quartas-feiras às 19h"). Se nenhum horário estiver definido, aparece um espaço reservado.
- **Local de encontro** -- Onde o grupo se reúne. Se nenhum local estiver definido, aparece um espaço reservado.
- **Descrição** -- Uma prévia breve do que é o grupo, limitada a algumas linhas. Clique no grupo para ler a descrição completa.

## Visualizando um grupo

Clique em qualquer cartão de grupo para abrir a página completa de detalhes. Lá você encontrará a descrição completa, informações sobre os líderes do grupo, os próximos eventos do calendário e uma forma de entrar em contato.

:::tip
Se você procura um tipo específico de grupo, veja primeiro os títulos das categorias. Assim você vai direto à seção que interessa, em vez de percorrer todos os grupos.
:::
