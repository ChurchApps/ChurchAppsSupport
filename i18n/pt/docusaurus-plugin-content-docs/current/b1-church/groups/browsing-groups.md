# Navegando por Grupos

<div class="article-intro">

A página pública de grupos da sua igreja facilita a descoberta de grupos que despertam o seu interesse. Os grupos são organizados por categoria, para que você possa percorrer rapidamente diferentes tipos de grupo e encontrar o que combina com você.

## Encontrando a página de grupos

Acesse a página **Grupos** no site B1.church da sua igreja. Essa página é pública, então você não precisa estar conectado para navegar.

## Como os grupos são organizados

Os grupos são exibidos por **categoria** (também chamada de rótulo). As categorias são configuradas pelos administradores da sua igreja e podem incluir rótulos como "Pequenos grupos", "Ministérios", "Jovens" ou "Estudos bíblicos". Cada categoria mostra todos os grupos que pertencem a ela.

## Lendo os cartões de grupo

Cada grupo aparece como um cartão com as seguintes informações:

- **Foto do grupo** -- Uma imagem de capa que representa o grupo. Se nenhuma foto tiver sido definida, é exibida uma imagem padrão.
- **Nome do grupo** -- Exibido em destaque sobre a foto.
- **Horário de encontro** -- Quando o grupo costuma se reunir (por exemplo, "Quartas-feiras às 19h"). Se nenhum horário estiver definido, é exibido um espaço reservado.
- **Local de encontro** -- Onde o grupo se reúne. Se nenhum local estiver definido, é exibido um espaço reservado.
- **Descrição** -- Uma breve prévia do que é o grupo, limitada a algumas linhas. Clique no grupo para ler a descrição completa.

## Vendo um grupo

Clique em qualquer cartão de grupo para abrir a página completa de detalhes do grupo. Lá você encontrará a descrição completa, informações sobre os líderes do grupo, eventos futuros do calendário e uma forma de entrar em contato.

:::tip
Se você procura um tipo específico de grupo, comece examinando os títulos das categorias. Isso ajuda a ir direto à seção que lhe interessa, em vez de rolar por todos os grupos.
:::
