# Relatórios de Frequência

<div class="article-intro">

B1 Admin fornece três relatórios de frequência para ajudá-lo a entender como as pessoas estão se engajando com seus serviços e grupos. Cada relatório oferece uma perspectiva diferente sobre seus dados de frequência, desde tendências de alto nível até detalhamentos diários.

</div>

<div class="prereqs">
<h4>Antes de Começar</h4>

- Certifique-se de que a frequência está sendo [rastreada consistentemente](../attendance/tracking-attendance.md) para seus serviços e grupos
- Certifique-se de que seus [grupos](../groups/creating-groups.md) e serviços estão configurados no B1 Admin
- Você precisa das [permissões](../settings/roles-permissions.md) apropriadas para acessar relatórios

</div>

## Tendência de Frequência

O relatório Tendência de Frequência mostra como a frequência muda ao longo do tempo para seus serviços.

1. Vá diretamente para **admin.b1.church/reports/attendanceTrend** em seu navegador (relatórios não têm entrada no menu de navegação — marcador de endereço é a maneira mais fácil de voltar).
2. Defina o **intervalo de datas** para definir o período de tempo.
3. Selecione um **serviço** ou **grupo** para filtrar os resultados.
4. O relatório exibe uma linha de tendência mostrando contagens de frequência ao longo do período selecionado.

Este relatório é útil para identificar padrões como quedas sazonais, tendências de crescimento ou o impacto de eventos especiais.

## Frequência de Grupo

O relatório Frequência de Grupo mostra os totais de frequência por grupo para um intervalo de datas selecionado.

1. Vá diretamente para **admin.b1.church/reports/groupAttendance** em seu navegador.
2. Defina o **intervalo de datas** para o relatório.
3. Selecione o(s) **grupo(s)** que você quer revisar.
4. O relatório exibe os números de frequência total para cada grupo.

Use este relatório para comparar frequência entre grupos e identificar quais grupos estão crescendo ou precisam de atenção.

## Frequência de Grupo Diária

O relatório Frequência de Grupo Diária fornece um detalhamento dia a dia dos dados de frequência de seus grupos.

1. Vá diretamente para **admin.b1.church/reports/dailyGroupAttendance** em seu navegador.
2. Defina o **intervalo de datas** para o relatório.
3. Selecione o(s) **grupo(s)** que você quer revisar.
4. O relatório mostra números de frequência para cada dia individual dentro do intervalo.

Este relatório oferece detalhes granulares, que são úteis para entender variação semana a semana ou identificar dias específicos com frequência inusitadamente alta ou baixa.

:::tip
Use o relatório Tendência de Frequência para uma visão geral de alto nível e o relatório Frequência de Grupo Diária quando você precisa detalhar datas específicas.
:::

## Usos Práticos

- **Planejamento** -- Use tendências de frequência para planejar assentos, pessoal e recursos para próximos serviços.
- **Alcance** -- Identifique padrões de frequência em declínio cedo para que possa acompanhar os membros.
- **Relatórios do conselho** -- Inclua dados de frequência em seus relatórios de liderança regulares para mostrar a saúde do ministério.
- **Avaliação de eventos** -- Compare frequência antes e depois de eventos especiais para medir seu impacto.

:::warning
Os dados de frequência são registrados através de seus processos de check-in de grupo e serviço. Se a frequência não estiver sendo rastreada consistentemente, seus relatórios não refletirão com precisão a participação real. Veja [Rastreando Frequência](../attendance/tracking-attendance.md) para instruções de configuração.
:::
