# Lista de aniversários de casamento

<div class="article-intro">

Precisa de uma lista de todas as pessoas com aniversário de casamento em determinado mês -- para o boletim, os cartões ou os anúncios? A pesquisa de Pessoas permite filtrar por **Mês do aniversário de casamento** e exibir as datas diretamente nos resultados.

</div>

<div class="prereqs">
<h4>Antes de começar</h4>

- Certifique-se de que as datas de aniversário de casamento estejam cadastradas no perfil de cada pessoa. Veja [Como adicionar pessoas](../people/adding-people.md) para mais detalhes.
- Você precisa de permissão para visualizar pessoas. Veja [Funções e permissões](../settings/roles-permissions.md).

</div>

## Obtendo a lista de aniversários de casamento de um mês {#getting-an-anniversary-list-for-a-month}

1. Abra o [menu Jump](../introduction.md#getting-around-with-the-jump-menu) (a barra de pesquisa no canto superior esquerdo do B1 Admin), expanda **Pessoas** e clique em **Pessoas**.
2. Abaixo da caixa de pesquisa, clique em **Avançada**.
3. Expanda a seção **Demografia**, marque **Mês do aniversário de casamento** e escolha o mês.
4. Os resultados são atualizados assim que o filtro é marcado -- todas as pessoas com aniversário de casamento naquele mês aparecem.
5. Para ver as datas, altere **Exibir como** para **Tabela**, clique no ícone **Selecionar colunas** no cabeçalho da página e ative a coluna **Aniversário de casamento**. Use **Exportar** para baixar a lista como planilha, caso prefira ordená-la ou imprimi-la.

## Usos práticos {#practical-uses}

- **Boletins semanais** -- Gere a lista do mês atual e inclua os aniversários de casamento no boletim ou nos anúncios.
- **Cartões de aniversário de casamento** -- Exporte a lista do mês e entregue-a à equipe que escreve os cartões.
- **Celebrações de marcos** -- Combine com o filtro **Anos de casamento** para encontrar aniversários de marcos.

:::tip
Gere esta lista no início de cada mês, para ter tempo de preparar os cartões ou os anúncios antes das datas.
:::

:::info
Os dados de aniversário de casamento vêm do campo de aniversário de casamento do perfil de cada pessoa. Se alguém estiver sem essa informação, basta incluir a data no perfil. Veja [Como adicionar pessoas](../people/adding-people.md).
:::
