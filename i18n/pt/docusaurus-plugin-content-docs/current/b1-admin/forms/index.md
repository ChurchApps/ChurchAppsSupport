# Formulários

<div class="article-intro">

A seção Formulários permite que você crie formulários personalizados para inscrições, pesquisas, coleta de dados e muito mais. Seja para um cartão de visitante, uma inscrição em evento ou um formulário de pedido de oração, você pode criá-lo aqui e compartilhá-lo com sua congregação através de um link público ou do seu site B1.church.

</div>

## A Página de Formulários

Quando você abre **Formulários**, você verá essas abas:

- **Formulários** -- Mostra todos os seus formulários ativos.
- **Formulários Arquivados** -- Mostra formulários que foram arquivados. Você pode restaurar formulários arquivados a qualquer momento. Esta aba aparece apenas uma vez que pelo menos um formulário foi arquivado.

Cada formulário na lista exibe seu nome e, se configurado, uma URL pública que você pode compartilhar externamente.

## O Que Você Pode Fazer

Na página de Formulários, você pode:

- **Adicionar um formulário** -- Clique em **Adicionar Formulário** para criar um novo formulário personalizado.
- **Editar um formulário** -- Clique no nome de um formulário para abri-lo e modificar suas perguntas, membros ou configurações.
- **Arquivar um formulário** -- Mova formulários que você não precisa mais para a aba **Formulários Arquivados** para manter sua lista limpa.
- **Restaurar um formulário** -- Mude para a aba **Formulários Arquivados** e restaure qualquer formulário que deseja tornar ativo novamente.

## Trabalhando com um Formulário

Clique em qualquer nome de formulário para abri-lo. O editor de formulários tem até três abas:

- **Perguntas** -- Construa a estrutura do formulário adicionando campos com diferentes tipos. Veja [Criando Formulários](./creating-forms.md) para detalhes.
- **Membros do Formulário** -- Controle quem pode acessar e gerenciar o formulário (apenas para formulários autônomos).
- **Submissões do Formulário** -- Visualize as respostas que foram enviadas. Veja [Gerenciando Submissões](./managing-submissions.md) para detalhes.

:::tip
Formulários com uma URL pública podem ser compartilhados via link, incorporados no seu site ou incluídos em e-mails. Isso facilita a coleta de informações de pessoas que podem não ter uma conta na igreja.
:::

:::info
Você pode controlar quem tem acesso a cada formulário usando a aba **Membros do Formulário**. Atribua funções **Admin** ou **Apenas Visualizar** para dar à sua equipe o nível certo de acesso.
:::
