# Trazer Seu Próprio Armazenamento (BYOS)

Igrejas conseguem ~100MB de armazenamento de arquivo hospedado gratuitamente (as superfícies `/content/files`: Arquivos de Website, recursos de grupo). BYOS permite uma igreja vincular seu próprio armazenamento em nuvem — **Google Drive, Dropbox, OneDrive ou qualquer bucket compatível com S3 (AWS S3, Cloudflare R2, Backblaze B2)** — para que novos uploads vão direto para a conta da igreja com nenhum limite de plataforma.
