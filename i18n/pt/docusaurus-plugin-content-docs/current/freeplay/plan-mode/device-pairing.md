# Pareando seu dispositivo

<div class="article-intro">

Para usar o Modo de plano, você pareia sua TV com um tipo de plano no B1 Admin. O FreePlay mostra um código de pareamento curto na TV. Você informa esse código no B1 Admin e escolhe o tipo de plano a seguir, e a TV recebe automaticamente o conteúdo desse plano toda semana.

</div>

<div class="prereqs">
<h4>Antes de Começar</h4>

- Instale e abra o FreePlay. Consulte [Primeiros Passos](../getting-started/)
- Tenha acesso ao **B1 Admin** em um computador ou celular para concluir o pareamento

</div>

## Gerando o código de pareamento

1. Na TV, abra **Configurações** na parte inferior da barra lateral.
2. Selecione **Parear com um calendário**.
3. O FreePlay mostra um código de pareamento de quatro letras, em letras grandes, ao lado de um código QR.
4. Abaixo do código, um indicador pulsante **Aguardando confirmação** mostra que o FreePlay está esperando você concluir o pareamento.

O mesmo código funciona para o [Modo programado](../scheduled-mode/) no FreePlay Admin e para o Modo de plano no B1 Admin. O código QR e o endereço **freeplay.church/pair** exibidos na tela levam ao FreePlay Admin. Para o Modo de plano, ignore-os e informe o código no B1 Admin, conforme descrito abaixo.

## Informando o código no B1 Admin

1. No B1 Admin, acesse **Perfil** > **Dispositivos** e clique em **Adicionar Tela**.
2. Digite as quatro letras que aparecem na TV em **Código de Pareamento**.
3. Em **Mostrar Planos De**, escolha o tipo de plano que esta tela deve seguir, por exemplo "Culto de Domingo".
4. Salve.

O FreePlay verifica a cada poucos segundos se o pareamento foi concluído. Assim que o B1 Admin confirmar, a TV exibe **Conectado!** e passa para a tela de download do plano.

## Baixando o conteúdo do plano

Depois do pareamento, o FreePlay carrega o plano atual desse tipo de plano. Ele mostra:

- O nome do plano e a data do culto
- O nome da lição, se o plano incluir conteúdo de lição
- Um indicador de progresso mostrando **Baixando item X de Y**

Quando todos os arquivos de mídia tiverem sido baixados, o botão **Iniciar Plano** aparece. Pressione **Selecionar** no controle remoto para iniciar a reprodução.

:::tip
O plano é atualizado automaticamente a cada hora. Se alguém atualizar o plano durante o dia, o FreePlay recebe as alterações por conta própria.
:::

## Se o pareamento falhar

Se o FreePlay não conseguir gerar um código de pareamento (por exemplo, por um problema de rede), você verá uma mensagem de erro com um botão **Tentar novamente**. Verifique se a TV está conectada à internet e tente de novo.

:::warning
Os códigos de pareamento expiram após 15 minutos. O FreePlay mostra um novo código automaticamente quando o antigo expira, e você pode selecionar **Gerar novo código** a qualquer momento. Se o código que você informou não funcionar, use o que a TV está mostrando agora.
:::
