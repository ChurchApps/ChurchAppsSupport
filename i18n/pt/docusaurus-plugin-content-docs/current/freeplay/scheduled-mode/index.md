# Modo agendado

<div class="article-intro">

O Modo agendado permite que uma TV com FreePlay funcione sozinha. Você monta playlists e as coloca em um calendário no **FreePlay Admin**, em [admin.freeplay.church](https://admin.freeplay.church). Cada TV pareada a esse calendário baixa a semana seguinte e reproduz o que estiver agendado, no horário certo, sem que ninguém precise pressionar Iniciar. Como os arquivos já estão baixados, a reprodução continua mesmo se o Wi-Fi cair.

</div>

:::tip
O FreePlay Admin usa o seu login do ChurchApps, o mesmo que você usa no B1 Admin. Não há necessidade de criar uma conta separada.
:::

## Como tudo se encaixa

O FreePlay Admin tem quatro páginas principais, listadas no topo do site:

- **[Telas](./managing-screens)** - As TVs que você pareou, o status delas e os **grupos de telas** a que pertencem. Telas de um mesmo grupo compartilham um calendário e um loop padrão
- **[Playlists](./building-playlists)** - Loops de imagens e vídeos que você escolhe nos seus provedores de conteúdo
- **[Calendário](./scheduling-the-calendar)** - O que cada grupo de telas reproduz e quando
- **[Provedores](./building-playlists#connecting-providers)** - As fontes de conteúdo de onde suas playlists puxam o material. Você conecta cada uma uma única vez para a igreja inteira

Quando nada está agendado, as telas de um grupo reproduzem o **loop padrão** dele. Se o grupo não tiver um loop padrão, as telas ficam apagadas.

## Como é diferente do Modo de plano

- **[Modo de plano](../plan-mode/)** segue um tipo de plano de culto do B1 Admin. Alguém pressiona **Iniciar plano** na TV, e a lição é reproduzida quando isso acontece
- **Modo agendado** segue um calendário. O conteúdo começa e para nos horários que você define, por isso funciona bem para sinalização de saguão, loops de avisos e salas de aula em que a lição deve estar no ar antes de alguém entrar

Uma entrada do calendário ainda pode reproduzir um plano de culto. Escolha o tipo de plano em **Planos de culto** ao adicionar uma programação, e a tela reproduz o plano que estiver vigente no B1 Admin naquela semana.

## Primeiros passos

Até que você conclua cada uma destas etapas, a página **Telas** mostra uma lista de verificação **Primeiros passos** com um link para cada etapa:

1. **Conecte um provedor** - Vincule o Dropbox, o OneDrive, o Lessons.church ou outra fonte na página **Provedores**
2. **Crie uma playlist** - Escolha imagens e vídeos de um provedor
3. **Coloque no calendário** - Escolha o que será reproduzido e quando, ou defina um loop padrão para o grupo
4. **Pareie uma tela** - Digite o código de quatro letras mostrado na TV

Clique em **Ocultar** para dispensar a lista de verificação.

:::tip
Pressione **Ctrl+K** (**⌘K** no Mac), ou clique na caixa de busca no cabeçalho, para abrir a paleta de comandos. De lá, você pode ir a qualquer página ou iniciar uma ação como **Parear tela**, **Adicionar playlist** ou **Adicionar programação**.
:::
