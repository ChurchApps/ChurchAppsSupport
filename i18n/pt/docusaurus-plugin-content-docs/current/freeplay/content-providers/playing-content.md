# Reproduzindo Conteúdo

<div class="article-intro">

O player do FreePlay ocupa toda a tela e foi feito para controles remotos de TV. Ele reproduz vídeos e slides de imagem de um provedor, de uma lição baixada, de um plano ou da sua pasta de anúncios, e avança por eles automaticamente ou no seu ritmo.

</div>

<div class="prereqs">
<h4>Antes de Começar</h4>

- Escolha algo para reproduzir. Veja [Navegando e Baixando Conteúdo](./browsing-content), [Modo de Plano](../plan-mode/) ou [Anúncios](./announcements)
- Pressione **Iniciar** para abrir o player

</div>

:::info
Telas pareadas a um calendário usam um player agendado separado, com controles um pouco diferentes. Veja [Reprodução Agendada na TV](../scheduled-mode/scheduled-playback).
:::

## Controles do Player

Use o controle remoto da TV para controlar a reprodução:

| Botão do Controle | Ação |
|---|---|
| **Selecionar / Reproduzir-Pausar** | Pausar ou retomar |
| **Seta para a direita** | Pular para o próximo slide ou vídeo |
| **Seta para a esquerda** | Voltar para o slide ou vídeo anterior |
| **Avançar** | Avançar 10 segundos em um vídeo. Em um slide, ir para o próximo item |
| **Retroceder** | Voltar 10 segundos em um vídeo. Em um slide, ir para o item anterior |
| **Seta para cima** | Abrir **Selecionar uma Mensagem** para ir a um item específico |
| **Para baixo / Voltar** | Sair do player |

:::tip
Você também pode deslizar o dedo em controles remotos com touchscreen. Deslize para a esquerda para avançar, para a direita para voltar, para baixo para abrir **Selecionar uma Mensagem** e para cima para sair do player.
:::

## Vídeos e Slides

Ao pausar, um ícone de pausa aparece sobre o conteúdo. Pressione **Selecionar** ou **Reproduzir-Pausar** novamente para retomar.

Os vídeos passam para o próximo item ao terminar. Um vídeo configurado para repetição fica em loop até que você pule para frente.

Os slides de imagem avançam sozinhos após alguns segundos (5 segundos, a menos que o provedor defina seu próprio tempo). Pressione a **Seta para a direita** para avançar mais cedo, ou pause para manter um slide na tela.

## Selecionar uma Mensagem

Pressione **Para cima** durante a reprodução para abrir **Selecionar uma Mensagem**. Ela mostra todos os itens com uma miniatura e um título, e marca o item que está sendo reproduzido como **REPRODUZINDO AGORA**. Vá até qualquer item e pressione **Selecionar** para ir diretamente a ele. Pressione **Voltar** para fechar sem alterar nada.

## Saindo do Player

Pressione **Para baixo** ou **Voltar** no controle remoto para sair do player. Onde você vai parar depende do que estava sendo reproduzido:

- **Conteúdo de provedor** - Volta ao navegador de conteúdo
- **Um plano** - Volta à tela de download do plano. Veja [Modo de Plano](../plan-mode/)
- **Um download** - Volta à tela de **Downloads**

:::info
A tela permanece ativa enquanto o player estiver aberto, para que a TV não entre em suspensão no meio de uma lição.
:::
