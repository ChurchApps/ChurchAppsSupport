# Personalização

<div class="article-intro">

O Lessons.church oferece uma biblioteca de conteúdo de lições pronto para uso, mas cada igreja é diferente. Os recursos de personalização permitem adaptar o conteúdo das lições às suas salas, ao seu estilo de ensino e às suas faixas etárias, para que os voluntários vejam apenas o que é relevante para eles.

</div>

## Por que personalizar?

O conteúdo de lições no Lessons.church foi projetado para ser flexível. Uma única lição pode incluir seções para várias faixas etárias, atividades opcionais ou funções que não se aplicam a todas as salas. Em vez de pedir aos seus voluntários que ignorem mentalmente as partes que não se aplicam, você pode personalizar a lição para que eles vejam apenas o que é relevante para eles.

Por exemplo, uma lição pode incluir uma atividade de artesanato ideal para crianças pequenas, mas que não é adequada para a sua sala de quinto ano. Com a personalização, você pode ocultar essa seção para o grupo mais velho e mantê-la para o mais novo.

## O que você pode personalizar

- **Remover seções** -- Remova seções inteiras de uma lição que não se aplicam a uma sala ou faixa etária específica.
- **Remover funções ou ações** -- Remova funções ou ações individuais dentro de uma seção, caso não sejam necessárias.
- **Reordenar o conteúdo** -- Reorganize seções e ações para que sigam a sequência que você prefere para a sua sala.

## Específico da sala ou global

Cada vez que você faz uma alteração, escolhe o alcance dela:

- **Esta sala** -- A alteração afeta apenas a sala atual. As demais salas continuam vendo o conteúdo original.
- **Todas as salas** -- A alteração se aplica a todas as salas da sua igreja.

Essa flexibilidade permite criar visões diferentes da mesma lição para faixas etárias distintas, ou fazer uma alteração que valha para todas as salas de uma só vez.

:::tip
Se você é novo na personalização, comece com uma única sala para entender como o recurso funciona antes de aplicar alterações em todas as salas.
:::
