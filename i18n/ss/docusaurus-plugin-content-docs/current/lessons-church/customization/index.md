# Ukulawula

<div class="article-intro">

Lessons.church iniketa umtfombo wemifundziso lesekulungele kusetjentiswa, kodvwa libandla ngalinye liyahluka. Tindlela tekulawula tikuvumela kutilungisa kuvumelana nalamakhulu ekufundzisa wena, indlela yekufundzisa yakho, nemaqembu eminyaka, kutsi bavolontiya bakho babone kuphela lokuhambisana nabo.

</div>

## Kungani Kulawula?

Lokuqukethwe kwemfundziso ku-Lessons.church kwakhelwe kuba nemandlandlwana. Umfundziso lilodvwa lungafaka tigaba temaqembu emibili noma lapho kukhona tenti letingasebenzi, noma tindzima letingasebenzi kuleklasi ngalinye. Esikhundleni sekucela bavolontiya bakho kutsi bacofe emacondvweni tingcenye letingasebenzi, ungalulungisa umfundziso kutsi babone kuphela lokuhambisana nabo.

Ngekwesibonelo, umfundziso lingafaka umsebenti wekwenta lesebenta kahle kubantfwana labancane kodvwa lingafaneleki eklasini lelivesi lesihlanu. Ngekulawula, ungafihla leyo ngcenye kumqembu lomdzala kuyo ugcine kubalabancane.

## Lokungakulawula

- **Susa tigaba** -- Susa tigaba tonkhe temfundziso letingasebenzi kuleklasi noma kumqembu wemnyaka lotsite.
- **Susa tindzima noma tenti** -- Susa tindzima letikhetsiwe noma tenti ngaphakathi kwesigaba uma tingadzingeki.
- **Hlela kabusha lokuqukethwe** -- Hlela kabusha tigaba netenti kuvumelana nalokuhamba lolutsandza eklasini lakho.

## Ngeklasi Lilodvwa Noma Lonkhe

Njalo lapho wenta shintsho, uyakhetsa kutsi lisebenta kangakanani:

- **Leklasi Lelilodvwa** -- Shintsho lichaka kuleklasi lelikhona kuphela. Tinye tiklasi tibona lokuqukethwe lokwasekuqaleni.
- **Tonkhe Tiklasi** -- Shintsho lisebenta kuyo yonkhe ileklasi lelisebandleni lakho.

Lokuvumelekile lokungaguquki kusho kutsi ungaseta tindlela letehlukene temfundziso lefananako kumaqembu eminyaka ehlukene, noma wente shintsho lisebenta kuyo yonkhe indzawo ngasikhatsi sinye.

:::tip
Uma usha ngekulawula, qala ngeklasi lelilodvwa kutsi ubone kutsi lisebenta kanjani ngaphambi kwekusebentisa shintsho kuyo tonkhe tiklasi.
:::
