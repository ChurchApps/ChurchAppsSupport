# Kuphatsa Tinhlelo Temnyaka

<div class="article-intro">

Uhlelo lwemnyaka luluhlu lolulandzelanako lwetifundvo — viki 1, viki 2, viki 3 — lolusetjentiswa emabandleni kwi-B1 Admin. Ungashicilela uhlelo lwemnyaka lwanoma iyiphi inhlelo yetifundvo lesemtfolamphilo. Tinkhundla tekhalenda letikhetfwako titsela i-B1 Admin ngelinyanga viki 1 lekuwo, nangetiviki letimele kuwela eNhlanganisweni yePhasika noma yeKhisimusi.

</div>

<div class="prereqs">
<h4>Ngaphambi Kokuqala</h4>

- Kufanele uve nemvumo yomlawuli ye-Lessons.church
- Kufanele uve nalokungenani [inhlelo](./managing-programs.md) lenetifundvo letishicilelwe

</div>

## Kudala Uhlelo

1. Vula **Admin → Tinhlelo Temnyaka**.
2. Chofoza **Faka**.
3. Faka libito (njengesibonelo, "Elementary 2026–27" noma "High Voltage Year 1") nalokungaba yisilulumagama lesikhetfwako.
4. Ngaphandle kwalokukhetfwa, setsa **sikhetfo sendzawo lesidzingekako** — emagama endzawo ahlukaniswe ngetikhatsi, asetjentiswa uma viki lingacaciseli indzawo.
5. Ngaphandle kwalokukhetfwa, setsa **Umnyaka uqala ngu** (njengesibonelo Ngumasi) ukuze emabandla asebentise uhlelo emnyakeni wekhalenda langempela esikhundleni sedethi yekucala lenje kuphela.
6. Hlola **Shicilela** uma emabandla kudzingeka abone uhlelo kwi-B1 Admin. Ungayisheshi uma uhlelo lusalungiswa.
7. Faka tiviki kulanoma yiliphi lincwadzi lwetifundvo: khetsa **umtsombo**, bese inhlelo, sifundo, sifundvo, nendzawo. Chofoza **Faka**. Uhlelo lolulodvwa lungahlanganisa tinhlelo uma ulufisa. Sebentisa tintfo letitibhevu kutihlela kabusha.
8. Kuletifundo temacala lesikhatsini, setsa **Ntsamba** kuPhasika noma KuKhisimusi. Ntsamba viki lekugcina lesifundweni ukuze uchungechunge lufike kuLisontfo langaphambi kwaleliholide.
9. Gcina.

Emabandla asebentisa uhlelo lolushicilelwe kusuka ku-**B1 Admin → Serving → Plans → Schedule Lesson → Apply Year Plan**. Tinhlelo letinkhundla tekhalenda tibuta umnyaka lotsite nelitfulo letikhatsi; letinye tinhlelo tisasebentisa lilanga lekucala lekilasi nenani lemaviki. Emabandleni angahlela kabusha emaviki ngamanye ngemuva kwalokho; i-FreePlay idlala lokusekuhlelweni.
