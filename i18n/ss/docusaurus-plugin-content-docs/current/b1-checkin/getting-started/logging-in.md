# Kungena

<div class="article-intro">

Ngaphambi kokuba likhiyosi lisetjentiswe kekungena, udzinga kungena ngeakhawunti ye-ChurchApps lenelilungelo lekufinyelela ibandla lakho. Lelikhasi limboxa inqubo yekungena kokuqala, kukhetsa ibandla, kuziphatsa kwekungena ngekhanya, nendlela yekuphuma.

</div>

<div class="prereqs">
<h4>Ngaphambi Kokuqala</h4>

- Faka i-B1 Church Checkin ku-tabhulethi yakho ye-Android (bona [Getting Started](./index.md))
- Lungiselela i-imeyili ne-password yakho ye-ChurchApps
- Lolu akhawunti kudzingeka kube nelilungelo le-**Checkin** (noma **Edit Attendance**) ebandleni lakho. Umphathi wakho angalengeza kuB1 Admin ngaphansi kwe-**Settings > Roles** — bona [Check-In Kiosk Accounts](../../b1-admin/settings/roles-permissions.md#check-in-kiosk-accounts)

</div>

## Kungena Kokuqala

1. Vula i-app ye-B1 Church Checkin. Ngemuva kwesikrini sekuqala, uyakubona sikrini sekungena nelogo ye-B1 Church Checkin.
2. Faka **i-imeyili** yakho esigabeni sekucala.
3. Faka **i-password** yakho esigabeni sesibili.
4. Cindezela inkinobho ye-**Login**.

I-app iyavalidata tincwadzi zakho futsi ikungenisa. Uma i-imeyili noma i-password ingalungi, uyakubona umyalezo wephutsa ngaphansi kwesikrini.

Uma lolu akhawunti linesitjentisi se-[two-factor sign-in](../../b1-admin/profile/managing-profile.md#two-factor-sign-in), i-app ibe yetulela ikhodi. Faka ikhodi ye-6-digit kusuka ku-authenticator app yemnikati we-akhawunti, noma enye yetikhodi tekubuyisela, bese ucindezela **Login** futsi. Udzinga ikhodi kuphela kulokungena kokuqala; ngemuva kwaloko likhiyosi lihlala lingene.

:::info
Le yi-imeyili ne-password lotisebentisa ku-B1 Admin noma kunoma yimuphi omunye umkhiqizo we-ChurchApps. Awudzingi i-akhawunti leyehlukile yekhiyosi lekungena.
:::

## Kukhetsa Ibandla Lakho

Ngemuva kwekungena ngempumelelo, i-app ilayisha emabandleni lapho i-akhawunti yakho inelilungelo le-**Checkin** noma **Edit Attendance**. Emabandleni lapho unelilungelo lelinye kuphela liyasuswa. Uma kungasali lutfo, i-app ikhombisa **No check-in access** futsi ikucela kutsi umphathi webandla akungeze lilungelo le-Checkin kenye yetindzima takho. Ibandla ngalinye likhonjiswa njengekhadi lelikhombisa ligama lebandla nelogo (uma sewusetjentiswe kuB1 Admin).

- Uma i-akhawunti yakho ixhunyiwe **ebandleni linye kuphela**, usayakubona sikrini sekukhetsa. Cindezela ibandla lakho ukuze uqhubeke.
- Uma i-akhawunti yakho ixhunyiwe **emabandleni lamaningi**, cindezela ibandla lolifuna likhiyosi leli lisebentele.

Uma usukhethe ibandla, i-app ilayisha tilungiselelo tebandla letimayelana nemtsetfo nekubukeka. Logo lebandla lakho litawubonakala ekhanda kuwo wonkhe lamanye emasikrini.

## Kungena Ngekhanya Kutindzawo Letibuyelako

Ngemuva kwekungena lokuqala ngempumelelo, i-app igcina thokheni yekungena levikelekile nebandla lakho lolukhetsiwe kutabhulethi. Ayigcini i-password yakho. Ekuvulweni lesikhatsini lesilandzelako:

- I-app ikungenisa kabusha ngethokheni legcinwe.
- Uma wakhetsa ibandla ngaphambili, iyakubuyisela lokukhetsiwe futsi ikuyisa ngqo esikrinini **semikhosi** (services screen).
- Uma kungena lokugcinwe sekungasasebenzi, i-app ibuyela esikrinini sekungena kutsi ungene kabusha.

:::tip
Njengoba likhiyosi lingena ngekhanya, udzinga kufaka tincwadzi kanye kuphela ekusethweni kwekuqala. Ngemuva kwaloko, tabhulethi ingavulwa futsi isilungele.
:::

## Tilungiselelo Temphathi

Tilungiselelo temphathi tifihlwe ngekuhlosa kutsi emalunga ebandla asebentisa likhiyosi angashintja lukhiyo lwekumisa ngephutsa. Kutfola kutsi:

1. Cindezela **logo lebandla** ekhanda **kasikhombisa** ngekusheshisa (kuphindze kube sikhatsi lesingetulu kwetimphindvo letimbili).
2. Uma i-PIN yekhiyosi isetiwe, faka i-PIN lebuzwako.
3. Sikrini se-**Admin Settings** siyavuleka nemakhetfo lalandzelako:
   - **Change Service** — shintja sikhatsi lesikhetsiwe semikhosi
   - **Change Printer** — vula [tilungiselelo temshini wekuprinta](./printer-setup.md) kutfola futsi ukhetse emshini wekuprinta
   - **Set Admin PIN** (noma **Change Admin PIN** lapho sekusetiwe) — setha noma shintja i-PIN yekhiyosi evikela kufinyelela komphathi
   - **Emergency broadcast** — thumela umlayezo kubavikeli bemindeni yonkhe lebhalisiwe (bona [Emergency Broadcast](../check-in/checking-out.md#emergency-broadcast))
   - **Manned station mode** — iswichi lengeta kuphuma, kuvakasha/paging, kuprinta kabusha, nekuhlela iprofayela kulesiteshi (bona [Checking Out](../check-in/checking-out.md))
   - **Logout** — phuma uye esikrinini sekungena

   Cindezela **Back to Kiosk** kuze ubuyele ekungeneni.

:::warning
Kuphuma kususa tonkhe tincwadzi letigcinwe nekukhetsa kwebandla. Udzinga kuphindze ufake i-imeyili ne-password yakho ukuze usebentise likhiyosi futsi. Phuma kuphela uma udzinga kushintja tiakhawunti noma kulungiselela likhiyosi kabusha.
:::
