# Kuphetfa Kungena

<div class="article-intro">

Uma sewubuyekeze umndeni wakho futsi wenta noma yiphi imisebenti yeliqembu leDingekile, usulungele kuphetfa kungena. Lesi yisinyatselo sekugcina kuleyo ndlela yekhiyosiki -- ap ibeka ngekhompiyutha umsebenti wekuhamba etfempelini, ishicilele amalebhula, futsi iphindze isetelwe ngemndeni lotsite.

</div>

<div class="prereqs">
<h4>Ngaphambi Kokuqala</h4>

- [Buyekeza umndeni wakho](./household-review.md) esikrinini sekubuyekeza umndeni
- [Abela emaqembu](./group-assignment.md) kulamanye emalunga emndeni adzingeka kungena esigabeni noma esihlelweni lelitile
- Uma kudzingeka, [engeta tihambi](./adding-guests.md) letivakashela umndeni wakho

</div>

## Indlela Yekungena

1. Kusikrini sekubuyekeza umndeni, tfwesa inkinobho ye**Ngena** lepheshi lesikrini.
2. Ap ita ukuthumela lolwati lwemsebenti kuseva futsi ikhombise **iskrini lekuphumelela** lenesikhwama lesiluhlaza lesihlolwa kanye nemyalezo wekwemukelwa.

Yilokho lokukhona kwentekako. Umsebenti wemndeni wakho sewurekhodwe.

Uma kukhona lomuntfu lowakhetsa lowabe asengene kulesikhatsi namuhla, iwindi lelitsi **Sekungenile Kade** livela kuqala futsi ilibite. Tfwesa **Ngena Futsi** ukuze ugcine emaqembu lamasha, noma **Khansela** ukuze ubuyele esikrinini semndeni.

## Emakamelo Agcwele Nemalinganiso Bavolontiya

Uma libandla lakho lilungisele [tinhlelo tekuphepha](../../b1-admin/attendance/checkin-safety.md) etindzaweni letikamelo, iseva iyawuhlola ngaphambi kokugcina:

- Uma likamelo lelikhetsiwe **ligcwele noma livaliwe**, kungena akuyi kwenteka futsi ap itsi libito likamelo kuze ukhetse lelinye.
- Uma sikhatsi sesevisi sinesikhatsi sekungena [sekungena](../../b1-admin/attendance/setup.md#setting-a-check-in-schedule) futsi lesikhatsi sekungena singakavulwa khona manje, kungena etikamelweni tesikhatsi salesevisi nako kuyalaleka. Iskrini **Ungakangeni manje** itikhomba likamelo nesizatfu lesitsi "kungena akuvulekile manje"; tfwesa **Shintja Emakamelo** ukuze ukhetse sikhatsi sesevisi noma liqembu lelihlukile. (Tikhatsi tesevisi letisevaliwe tikhombisa **Valiwe** esikrinini [semndeni](./household-review.md) futsi ngeke tikhetfeke, ngako ngalokuvamile uyawubona lokusho kuphela uma lesikhatsi sivalwa ngesikhatsi sekungena.)
- Lumndeni lobe ungene ngesikhatsi sesevisi yangaphambilini ungabuya ngemuva kwesikhatsi bese wengeta sikhatsi sesevisi lesivuliwe, nanome isikhatsi sangaphambilini sesivalekile. Kungena lokukhona kwawo kuyagcinwa futsi akuyi kwenta kutsi kungena lokusha kwalengwe.
- Uma likamelo lebantfwana lingasekho bavolontiya labanele emalinganisweni alo, ap ikhombisa sexwayiso lesitsi umsebenti wesitfunti ungavumela ukuze uchubeke, noma ivimbe kungena ngalokuphelele -- kuncike kutsi libandla lakho lilungisele kanjani kuphoqelelwa kwemalinganiso.

## Kushicilelwa Kwemalebhula

Uma kukhona iphrinta yenethiwekhi lelungisiwe, ap ishicilela emalebhula ngalokuzenekelako ngemuva kokungena:

- **Emalebhula emagama** ashicilelwa ngalomuntfu ngamunye labelwe liqembu lelinesetingi ye**Print Nametag** livuliwe. Emalebhula emagama aletsa ligama lalomuntfu, kubelwa kwakhe eliqembu, nolwati lwemacala etilwane/tincomo uma lukhona emarekhodini.
- **Emaphepha ekutsatsa batali** ashicilelwa uma noma ngubani longeniwe asemqembwini lonesetingi ye**Parent Pickup** livuliwe. Labo longeniwe njengo**Mvolontiya** bayaphepha, ngako umsebenti wekunakekela bantfwana losebenta ekamelweni lekutsatsa batali ngeke atfole liphepha lekutsatsa. Liphepha lekutsatsa likhomba bantfwana, emaqembu abo, nekhodi lekuphepha lelikhetsekile lelinetinhlamvu **4** letehlukile.

:::info
Likhodi lefanako lekuphepha livela kulebhula lelitsi lemntfwana nasephepheni lekutsatsa lelitsi lebazali. Ngesikhatsi sekutsatsa, bavolontiya baqhathanisa emakhodi ukuze bacinisekise kutsi umuntfu lomdzala lotsatsa ngulowo lofanele kutsatsa lomntfwana ngamunye.
:::

Likhodi lekuphepha likhiqizelwa kusha ngalokungena ngakunye futsi isebentisa tinsisa temacondvo kuphela kanye netinombolo (tinsisa tetinsisa tiyasuswa kuze kugwenywe kwakheka emagama lafanele kungakafaneli).

:::warning
Uma emalebhula angashicilelwa, vula Tilungiselelo Tomphatsi ngekutfwesa **logo yeliBandla** kasikhombisa, bese utfwesa **Shintja Iphrinta** ukuze uhlole kuxhumeka kweprinta. Bona [Kusetfwa Kweprinta](../getting-started/printer-setup.md) ngetinyatselo tekulungisa tinkinga.
:::

## Lekwenteka Ngemuva Kokungena

- Uma iphrinta ilungisiwe, ap ishicilela emalebhula wonkhe bese ibuyela ngalokuzenekelako **esikrinini sekufuna**, sekulungele umndeni lolandzelako.
- Uma ingekho iphrinta elungisiwe, ap nayo ibuyela ngalokuzenekelako **esikrinini sekufuna**.

Noma yikuphi, iskrini lekuphumelela sihlala kuvulekile okungenani emasekhondi layisithupha kusukela lapho sivela khona (emasekhondi lasikhombisa uma kuchamunwa kufinyelelwa kwesinyatselo sekuhamba etfempelini somuntfu). Ngaleyo ndlela imindeni ingabona kutsi kungena kuhambile. Uma kushicilelwa kuthatha sikhatsi lesidzinde kunalelo, ap ibuyela emizuzwaneni lemitsatfu nesigamu ngemuva kwekuphela kwekushicilelwa.

Awudzingi kutfwesa lutfo ukuze ubuyele esikrinini sekufuna -- ap iphatsa lushintsho ngalokuzenekelako. Ngemuva kokuba iskrini lisesikhatsini lesincane, ungasitfwesa ukuze ubuyele masinyane; kutfwesa ekuqaleni kwemizuzwana lemitsatfu nesigamu kuyalalelwa, ngako kutfwesa kabili ngekhasi kunkinobho ye**Ngena** akususwa lesikhatsini.

:::tip
Ap isetelwa ngalokuphelele ngemuva kwekungena ngakunye, ngako kute ingozi yekutsi umndeni lobe ulubona lolwati lwemndeni lolunye.
:::

## Lekurekhodwako

Uma utfwesa **Ngena**, ap ithumela lokulandzelako kuseva ngemuntfu ngamunye welumndeni lonelikhetso leliqembu:

- **Umuntfu** lolungeniswa
- **Sevisi** lalo lelatsatfwa
- **Sikhatsi sesevisi** kanye **neliqembu** lalo labelwe kuwo

Lolu lwati lutfolakala ku-B1 Admin ngaphansi kwesigaba **Kuhamba Etfempelini**, lapho tiphatsi tebandla tingabona khona tirekhodi tekuhamba etfempelini futsi tiphatse tona. Bona [umhlahlandlela wekuphatsa kungena](../../b1-admin/attendance/check-in.md) kuze uthole imininingwane.
