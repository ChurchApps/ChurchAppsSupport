# Kuphakamisa Tinguquko Nekubika Tingoma ku-WorshipCommons

<div class="article-intro">

I-WorshipCommons iyathuthukiswa ngabantfu abayisebentisako. Noyiphi umuntu longene ngemvume angaphakamisa shintsho kwingoma lesebentako -- lulungisa ikhodi, engeze indzima, lulungise umbhalo, noma engeze lifayela lelitsite. Akukho lokushintjwa kuze kuvunywe ngumbukuri. Uma ingoma yabelwe ngumuntu longayinikile, noma kukhona lokungalungile, ungayibika.

</div>

<div class="prereqs">
<h4>Ngaphambi Kokuqala</h4>

- Ngena ku-WorshipCommons. Bona [I-akhawunti Yakho Nekhasi Lombhali](./your-account.md).
- Vula likhasi lengoma. Bona [Kufuna Tingoma](./finding-songs.md).

</div>

## Kuphakamisa Lushintjo

1. Ekhasini lengoma, tfola iphaneli **Ilungise** bese ucindzetela **Phakamisa lushintjo**.
2. Ngaphansi kwe-**Yini oyiphakamisako?**, khetsa kunye:
   - **Kulungisa** -- Lungisa emagama, tikhodi, noma tinchazelo, njengesikhombo sebhayibheli noma inkhiyo.
   - **Lifayela lelengeziwe** -- Engeze sikolo, sikena semculo, irekhodi ledemo, umculo wekwesekela, umculo we-MIDI, ama-stems, indzaba yekhava, noma lifayela lemagama. Lokunye ngaleyo ngoma akushintjwa.
   - **Irekhodi lemaster** -- Engeze irekhodi lelucedziwe lengoma ngaphansi kwelayisense yalo. Layisense yengoma ihlala ifanana.
   - **Sicelo sekususwa** -- Cela umbukuri kutsatse ingoma.
3. Yenta tinguquko takho noma engeze tifayela takho.
4. Ebhokisini lenothi, tsho kumbukuri kutsi yini leshintjiwe nangani (okungenani emalunga langu-10). Ngesicelo sekususwa, tsho kutsi ungubani nangani ingoma kufanele isuswe.
5. Hlola **Lushintjo lwami luyiqiniso, nalokungiwungezako ngikunikela kimi, futsi ngikunikela ngaphansi kwelayisense yale ngoma.** (Ticelo tekususwa aziphindzi kulelibhokisi.)
6. Cindzetela inkinobho ephansi, njengeyi **Phakamisa lushintjo lolu** noma **Cela kususwa**.

Umbukuri uyaqhathanisa lushintjo lakho nengoma lesebentako bese uyanquma. Landzela kwalo ku-**Tincumo tami**. Lapho kuvunyiwe, utawukhonjwa ekhasini lengoma ngaphansi kwe-**Labahlanganyela Nemashintjo** ethebhu i-**Mayelana Nemalungelo**.

:::info
Ngumbhali kuphela longashintja layisense yengoma. Uma uphakamisa kulungisa, layisense iyaboniswa kodvwa ayikwati kushintjwa.
:::

:::tip
Kungeta irekhodi lemaster lengoma, cindzetela **Engeta irekhodi lemaster** kuphaneli **Ilungise**. Uma ingoma inelifayela le-MIDI kodvwa ingenamaphepha emculo, ithebhu **Imaphepha emculo** ingakhombisa lilinki lekukusita kulabhalela lowo mculo.
:::

## Tingoma Letivalelwe Kulungiswa Lomphakathi

Netinye tibhali tikhetsa layisense legcina tonkhe tinguquko kubo. Kulezo ngoma, lilinki **Phakamisa lushintjo** aliboniswa, futsi kuvula likhasi lekuhlela kukhombisa **Umbhali wenta tonkhe tinguquko kulengoma.** Uma ubona inkinga, sebentisa lilinki **Ubone inkinga? Sitsi.** ukuyibika.

Tinhlobo letimbili tingaphakamisa tinguquko kungoma levaliwe:

- **Umshicileli wengoma** -- Akhawunti leyishicilele, kuhlanganisa nalabo WorshipCommons leyengeze njengabashicileli labambisanako.
- **Bakhombisi be-WorshipCommons** -- Emalunga eqembu lababuyekeza tibhalo.

Tinguquko tabo nako ziyahamba ngekuhlolwa njengetinye tinguquko.

## Kubika Ingoma

Sebentisa umbiko lapho ingoma yabelwe ngaphandle kwemvume yemnikati, noma lapho kukhona lokunye lokungalungile.

1. Ekhasini lengoma, cindzetela **Bika lengoma** ephaneli **Ilungise**. (Ungacindzetela futsi **Bika ingoma** ekugcineni kwanoma yiliphi likhasi.)
2. Ku-**Yiliphi ingoma?**, faka sihloko noma ikheli lelikhasi lengoma.
3. Ngaphansi kwe-**Yini inkinga?**, khetsa sizathu, njengalesi **Umuntu wabelane ngengoma angayinikile**, **Emagama noma umculo ngiwo akhiwe ngi-AI**, noma **Ikhodi noma tifayela tingalungile**.
4. Ngaphansi kwe-**Yini engalungile?**, chaza inkinga. Ngelilungelo lengoma, faka ukuthi ngubani lonelungelo ngalengoma kanye nendlela loyati ngayo.
5. Uma ukhetse **Umuntu wabelane ngengoma angayinikile**, khetsa futsi **Ungubani?**, faka ligama lakho nemaili yakho, hlola sitatimende sekuthembeka, bese ubhala ligama lakho lelisemtsetfweni leligcwele njenge-**Sayini** yakho.
6. Cindzetela **Thumela umbiko**.

Umuntu langempilo utakuphendvulela kungakapheli emalanga lamabili asebenta, futsi tikhalo temalungelo tiyahlolwa kuqala. Uma likhalo lesikhonjwa, i-WorshipCommons iyaphatsa kususa ingoma kungakapheli emahoreni langu-48. Ungaphinde uyithumelele i-imeyili ku-[support@churchapps.org](mailto:support@churchapps.org).
