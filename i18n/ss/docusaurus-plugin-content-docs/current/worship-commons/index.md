# Isibuyekezo se-WorshipCommons

<div class="article-intro">

WorshipCommons yilaibhurari lemahhala, levulekile yemaculo ekukhonteni emabandleni. Inemahamba lasesidzabeni nemaculo labelwane ngabo babhali labakhetse kubelana nawo, ngalinye linemagama, inkhomba yetinkhomba lungakwati kutfutsa kunoma yiliphi likhiyi, nemasiladi eSonto. Vakashela [worshipcommons.org](https://worshipcommons.org) ukuze uthole liculo, ushintse likhiyi, uphrinte inkhomba, bese ubeka emagama esikrini.

</div>

WorshipCommons yetikhulu tekukhokhela ekukhonteni, bahlangani bemaculo, nebasebenti betekhnoloji labadzinga emaculo labangawasebentisa ngaphandle kwetimali letengeziwe, nalaba bababhali labafuna kunika bandla labo emaculo abo. Awudzingi i-akhawunti ukuze ubhale, udlale, uphrinte, noma ubonise emaculo. I-akhawunti yemahhala ye-ChurchApps ikuvumela kugcina emaculo nakwabelana ngemaculo akho.

:::info
Lokufanele ukukwenta libandla lakho kuncike kulayisensi yaliculo ngalinye. Emahamba lasesidzabeni angasetfwa ngalokukhululekile kukho konkhe e-United States (ngekwemandla alo; emave lanye angahluka). Emaculo alabelwane ngaphansi kwe-WorshipCommons License angasetfwa ngemahhala ekukhonteni, futsi umbhali uyagcina tilungelo tekuhweba. Vula ithebhu ye-**About & rights** yaliculo ukuze ubone kahle lokuvunyelwe yiko. WorshipCommons ayitsatsi indzawo ye-CCLI license yemaculo lanye lolucula wona.
:::

## Tinhlobo Letibalulekile

- **Kufuna nemasefa** -- Funa ngetitukulo, umugca wekucala, ilingiso, indzikinsi, umBhalo, noma umbhali, bese uhlunga ngelikhiyi, lijubane, lulwimi, layisensi, nokunye. Bona [Kutfola Emaculo](./finding-songs.md).
- **Tinkhomba tetinkhomba nanoma yiliphi likhiyi** -- Tshintsha likhiyi, setfa i-capo, tshintsha ube tinombolo teNashville, bese uthinta inkhomba ukuze ubone sakhiwo salo esigitaleni nasepianoni. Bona [Likhasi Leliculo](./song-page.md).
- **Lalela liculo** -- Dlala irekhodi lesampula noma i-piano preview, uyinciphise ijubane, bese uciniseka ngemetronome.
- **Phrinta nelanda** -- Phrinta inkhomba yetinkhomba ngelikhiyi lakho, noma lande i-ChordPro, emagama, sheet music, nemaphakethe emsindvo nakabe ukhona.
- **Hola nekubonisa** -- Hola kukhonteni kusuka kusikrini sebrawuza nemagama alandzelana nemculo, noma vula i-lyrics projector elula. Bona [Kwetsa Nekuphuma Emaculo](./presenting-and-exporting.md).
- **Tiphumo** -- Landa emasiladi we-FreeShow, OpenLP, ProPresenter, noma PowerPoint, noma kopisha liculo lye-OnSong noma Planning Center. B1 Admin ingangeta emaculo e-WorshipCommons ngqo kulaibhurari yakho yemaculo.
- **Tihlelo tetinsita** -- Akha sethi yeSonto, khetsa likhiyi nemacembu weliculo ngalinye, bese wabelana ngelinki linye nebhendi. Bona [Tihlelo Tetinsita](./service-plans.md).
- **Yabelana ngemaculo akho** -- Layisha liculo lolubhalile, lokuhumusha, noma lokuhlelwe, bese ukhetsa kutsi lilayisensiwe kanjani. Bona [Kwabelana Ngeliculo](./sharing-a-song.md).
- **Tinguquko letiphindzaphindzekako** -- Noma ngubani lolungeniswe angacela kulungisa, futsi umbuyekezi uyanquma. Bona [Kucela Tinguquko Nekubika Emaculo](./proposing-edits.md).
- **Emakhasi emabhali** -- Umbhali ngamunye unekhasi lakhe lapho kulemaculo akhe, nelwati lwekuzibhala lolukhetsekako netixhumanisi. Bona [I-Akhawunti Yakho Nekhasi Lombhali](./your-account.md).
