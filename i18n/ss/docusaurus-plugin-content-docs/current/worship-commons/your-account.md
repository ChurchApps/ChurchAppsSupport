# I-akhawunti yakho ye-WorshipCommons nekhasi lakho lombhali

<div class="article-intro">

Ungakhangela, udlale, uphrinte, futsi uveze emaculo ku-WorshipCommons ngaphandle kwe-akhawunti. I-akhawunti lemahhala ikuvumela kutsi ugcine emaculo, wabelane ngemaculo akho, ucele kulungiswa, futsi ulandelele konkhe lokuthumele kona. Uma ubhala emaculo, i-akhawunti yakho ikuvumela nekutsi uhlele ikhasi lombhali emabandla abona.

</div>

## Ukungena noma Kwakha I-akhawunti

WorshipCommons isebentisa ii-akhawunti ze-ChurchApps. Uma usuvele unayo (njengaleyo ye-B1), ungasebentisa i-imeyili nelisiphiwo lefanako.

1. Chofoza **Ngena** emenywini lophezulu.
2. Faka **I-imeyili** yakho nelisiphiwo **Liphasiwedi**, bese uchofoza **Ngena**.

**Kuze ukhe i-akhawunti:**

1. Ekhasini lokungena, chofoza **Kha i-akhawunti**.
2. Faka **Libito**, **Sibongo**, kanye **ne-imeyili**, bese uchofoza **Kha i-akhawunti**.
3. Hlola i-imeyili yakho ngekhodi lenedijithi lesi-6, uyifake, bese uchofoza **Hlola ikhodi**.
4. Khetsa liphasiwedi lelinemalitjhana lesi-8 noma lelidlule, uliphindze ngaphansi kwe-**Hlola liphasiwedi**, bese uchofoza **Setfa liphasiwedi & ngena**.

**Ukhohlwe liphasiwedi?** Chofoza **Ukhohlwe liphasiwedi?** ekhasini lokungena, faka i-imeyili yakho, bese uchofoza **Thumela ikhodi**. Bese ufaka ikhodi lesemalini yakho, usete liphasiwedi lelisha.

Uma usunge, libito lakho liyavela emenywini lophezulu. Chofoza lona uvule **My submissions** noma **Report**, noma **Phuma**.

## Emaculo Lagciniwe

Chofoza sibhemu esicabanga ngaso ekhasini nalinaliphi culo ukuzeuligcine. Chofoza **Emaculo lagciniwe** emenywini lophezulu uve onkhe emaculo lowagcinile. Emaculo lagciniwe agcinwa ku-akhawunti yakho, ngako aveta kuwo onkhe emadivayisi lovela kuwo ungene. Chofoza **Susa** ukuze ususe culo ohlwini.

:::tip
Emaculo lagciniwe luhlu lolulula lwemaculo lotsandzako. Ukuhlela setfwebo lencono ngelilanga leliitsembe lelitsite, nemagama nemigca, sebentisa [Service Plans](./service-plans.md).
:::

## My Submissions

Chofoza libito lakho emenywini lophezulu bese ukhetsa **My submissions** uve onkhe emaculo nemashintji lowaqalisa noma lowathumela, nalokumele kuwo ngayinye. Sebentisa emathebhu asetulu -- **Konkhe**, **Emidvwebo**, **Ekuhlolweni**, **Kuphilile**, kanye **Akwamukelwanga** -- ukuhlunga luhlu.

Ngalinye lilandzelisa luhlobo lwalo (njenga **Culo lelisha**, **Kuhumusha**, **Kulungiswa kwemculo**, **Kulungisa**, kanye **Sicelo sekususwa**) kanye nesimo salo:

| Simo | Kusho ni |
| --- | --- |
| **Idrafti** | Iqalisiwe kodvwa ayikathunyelwa. Chofoza **Qhubeka** ukuze uyiphelelise noma **Susa idrafti** ukuze uyisuse. |
| **Kucelwe tintfo letishintjiwe** | Umbhekisisi ucele kutsi kushintjwe tintfo. Chofoza **Qhubeka**, wente tishintjo, bese uyithumela futsi. |
| **Ekuhlolweni** | Umuntu uyawufundza wonkhe culo ngaphambi kwekutsi luvele luphilile, ngalokuvamile ngaphakathi kwemalanga lambalwa. Chofoza **Hoxa** ukuze uyibuyisele ku-idrafti. |
| **Kuphilile** | Culo lisethalala lemculo futsi lingasetjentiswa ngemahhala ngemabandla. Uyawubona inombolo yalokuladzulwe kanye nelinki yalo. |
| **Akwamukelwanga** | Alizange lingene ethalala lemculo. Sizatfu lombhekisisi lisetfulwa. |
| **Ihoshiwe** | Uyililulele ngaphambi kwekutsi libhekiswe, ngalokuvela wena. |
| **Lisusiwe** | Culo lisusiwe ethalala lemculo, njengoba ucelile. |

Culo lelikhona ngiyo, chofoza **Kopisha ilinki** ukuze wabelane ngekhasi lalo, **Phakamisa shintja** ukuze uthumele kulungiswa, noma **Cela kususwa** ukuze ucele kutsi lisuswe. Bona [Proposing Edits and Reporting Songs](./proposing-edits.md).

:::info
Uma ithimba le-WorshipCommons likungeta njengomunye umshicileli wemculo -- njengekuba umculo lobhale wena nalomunye umuntu lowulayishe -- uyavela ku-**My submissions** njenge-**Kuphilile**, nakuba ungawuthumelanga wena. Njengomshicileli wemculo, ungashintja noma ngabe imphilo yalo ilivalela kuhlelo lwemphakathi.
:::

## Emakhasi Labhali

Lonkhe lombhali ethalala lemculo unekhasi lombhali lelitfola emaculo akhe, ngayinye ngayinye neminyaka yalo, sikhiye, timatiko, kanye nelayisensi. Emabandla afinyelela kulo ngekuchofoza libito lombhali ekhasini lemculo. Uma culo linebhali labaningi, ligama ngalinye liyavuleka libuke ikhasi lalo.

Ikhasi lombhali lingabonisa futsi isithombe, umlandvo lomfishane, timephu, kanye netinkhomba tekusekela lapho emabandla angasekela khona lomunye umsebenti walombhali.

### Kuhlela Ikhasi Lakho Lombhali

Uyawutfola ikhasi lakho lombhali nakuba nje culo lakho lilphilile futsi likubhalela wena.

1. Chofoza libito lakho emenywini lophezulu bese ukhetsa **My submissions**.
2. Chofoza **Iprofayili yombhali**.
3. Ngaphansi kwe-**Ngati wena**, bhala tinsetjana letimbalwa ngawe nemaculo lobhala (kuya kwetinhlamvu letingu-2,000).
4. Ngaphansi kwe-**Tinkhomba**, engeta tinkhomba letingafika kwetlihlanu, njengewebhusayithi yakho. Nika ngayinye i-**Lebhalwe** kanye nelikheli lalo lewebhu. Chofoza **Engeta inkhomba** ukuze ungete umtsetfo lolandzelako.
5. Ngaphansi kwe-**Tinkhomba tekusekela**, engeta tindzawo lapho emabandla angasekela khona umsebenti wakho, njengesitolo noma ikhasi lemsebenti. Chofoza **Engeta inkhomba yekusekela** ukuze ungete umtsetfo lolandzelako.
6. Chofoza **Gcina iprofayili**.

Chofoza **Bona ikhasi lakho lombhali** ukuze ulibone njengoba emabandla alibona. Tinkhomba takho tekusekela futsi tivela njenge-inkinobho ye-**Ikhasi lombhali wemculo** ekhasini ngalinye lemaculo akho.

:::tip
Ubhale emaculo akho ngekubambisana nalabanye, noma unekhasi lombhali lelingakahlanganiswa ne-akhawunti yakho? Thumela i-imeyili ku-[support@churchapps.org](mailto:support@churchapps.org) ucele kutsi lihlanganiswe.
:::
