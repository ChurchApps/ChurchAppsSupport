# Kuphrezenta Nekukhipha Emculo we-WorshipCommons

<div class="article-intro">

WorshipCommons ingeta emagama emculo esikrinini ngqo kusuka esiphequluli sakho, ngaphandle kwekufaka softhiwe lenye. Uma libandla lakho sekusebentisa softhiwe yekuphrezenta, khipha tindzikilidi temculo ku-FreeShow, OpenLP, ProPresenter, noma PowerPoint, noma engeta umculo kulabhulali yemculo ye-B1 Admin.

</div>

<div class="prereqs">
<h4>Ngaphambi Kokuqala</h4>

- Vula likhasi lemculo ku-[worshipcommons.org](https://worshipcommons.org). Bona [Kutfola Emculo](./finding-songs.md).
- Ukuze ukhombise emagama etelevishini noma kuprojekta, xhuma likhompyutha lakho kuyo ngekhebula ye-HDMI (noma sakaza sikrini sakho).

</div>

## Kuhola Kukhulekela Kusuka Esiphequluli

**Hola kukhulekela** ngumbono wesikrini lesigcwele lodlala umculo bese ukhombisa emagama umugca ngemugca, ugcamelele livi ngalinye njengoba livunyelwa. Yakhelwe liqembu lelincane, ikilasi, noma libandla lasekhaya lelingenaso iliband.

1. Esikhashini semculo, chofoza **Hola kukhulekela**. (Inkinobho itfola uma umculo unemculo wekudlala nawo.)
2. Khetsa **Ikhi** ne-**Itempo**. Uma umculo udlala kuhlola kwepiyano, ungakhetsa **Piyano** noma **Ogani**.
3. Chofoza **Tinhlatsi** ukukhetsa tinhlatsi lotakucula, bese ushintsha luhlelo lwato ngetinkinobho letinemitsi.
4. Vula **Kubala ngaphambi** uma ufuna kubalwa ngaphambi kwekutsi umculo uqale.
5. Chofoza **▶ Dlala**.

Sebentisa **Fihla** ukufihla emagama, **Umehluko** lesikrini lesinemehluko lomkhulu, nelesikrini **Sikrini lesigcwele** ukugcwalisa sikrini. Chofoza **Beka lokhu etelevishini** ngetinyathelo letisheshako tekukhombisa etelevishini.

:::tip
Tihlanganiso tekhibhodi: **Space** kudlala/kumisa, **← →** hamba umugca, **↑ ↓** hamba tinhlatsi, **B** fihla, **H** umehluko, **F** sikrini lesigcwele, **Esc** buyela emculweni. Chofoza **Bonisa tikhiye** ngaphansi kwesikrini ukuze utibone.
:::

## Kuveta Emagama

**Vula projekta** ikhombisa sigaba sinye semagama ngesikrini ngasinye, bese uhamba kuso ngesandla. Yisebentise uma unemculi lophila.

1. Esikhashini semculo, thola iphaneli **Projection** bese uchofoza **Vula projekta**.
2. Chofoza **F** noma chofoza **Sikrini lesigcwele** ukugcwalisa sikrini.
3. Chofoza sikrini, noma cindzetela **Space** noma khiye **→**, ukuya kulayidi lelilandzelako. Cindzetela **←** ukubuyela emuva. Chofoza ligama lesigaba ngaphansi ukuze uye kusona ngqo.
4. Cindzetela **B** ukufihla sikrini, bese **H** kumehluko lomkhulu.
5. Cindzetela **Esc** (noma chofoza **← Buyela emculweni**) uma useqedile.

Ibha yaphansi ikhombisa sigaba samanje, inombolo yemalayidi, nalokulandzelako. Umugca wesikweletu womculo nawo uvela esikrinini.

## Kukhipha Tindzikilidi

Iphaneli **Projection** esikhashini semculo inenkinobho yethuluzi ngalinye. Chofoza lenye ukulanda umculo:

| Inkinobho | Lokutfolwa |
| --- | --- |
| **FreeShow** | Ifayela lemboniso lokungenisa ku-[FreeShow](https://freeshow.app) |
| **PowerPoint** | Ludeki lwemalayidi lePPTX |
| **OpenLP** | Ifayela le-OpenLyrics lokungenisa ku-OpenLP |
| **ProPresenter** | Ifayela lombhalo lokungenisa ku-ProPresenter |
| **OnSong / PCO** | Ikopishela umculo ebhodini lekopi ukuze uwunamathisele ku-OnSong noma Planning Center |

Umbhalo ngaphansi kwetinkinobho utsi tindzikilidi tihlukaniswa kanjani. Uma umculo unemfanekiso wemajalagu lovunyelwe, tindzikilidi tilandzela wona; nakungenjalo tilandzela tinhlatsi njengoba tibhalwe. Yonkhe imikhipho ifaka sikweletu womculo nekredithi yelayisensi.

:::tip
Ukukhipha sonkhe sethi ngasikhatsinye, ngetikhiyi netigaba losikhetsile, akha [luhlelo lwelitiko](./service-plans.md) bese usebentisa tinkinobho tekukhipha lapho.
:::

## Kungeta Emculo we-WorshipCommons Ku-B1

Uma libandla lakho lihlela tinkhonzo ku-B1 Admin, awudzingi kulanda lutfo. Emculo lolungele Lisonto avela ekusesheni komculo ku-B1 Admin ngaphansi kwe-**WorshipCommons — mahhala**. Chofoza lenye ukuyengeta kulabhulali yemculo lakho, ihlanganiswe nalikhasi layo le-WorshipCommons.

Bona [Emculo ku-B1 Admin](../b1-admin/serving/songs.md#free-songs-from-worshipcommons) ngetinyathelo.
