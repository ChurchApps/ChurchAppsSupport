# Kutfola Emaculo Ku-WorshipCommons

<div class="article-intro">

Likhasi le-**Discover** ngumtfombo wemaculo we-WorshipCommons. Sesha iculo losati kade, noma nciphisa luhlu ngetihlungi kuze utfole lelisha lelitawusetfentfwa ngeSonto. Awudzingi kungena ngemvume kuze usesha noma udlale emaculo.

</div>

## Kusesha Umtfombo

1. Yana ku-[worshipcommons.org](https://worshipcommons.org) bese ucindzetela **Discover** (noma **Browse Songs**) phezulu kwelikhasi.
2. Bhala esikhalweni sekusesha. Ungasesha ngetitfoni, ligama lekucala lelihlabelelo, ligama lelithoni, indzikinsi, sitfumelo semibhalo, noma umbhali. Imiphumela ivuselelwa njengoba ubhala.
3. Sebentisa menyu ye-**Sort by** ukuhlela imiphumela nge-**Most downloaded**, **Most saved**, **Newest**, noma **Title A–Z**.
4. Cindzetela ligama lemculo kuvule [likhasi lemculo](./song-page.md).

:::tip
Cindzetela inkinobho `/` noma kuphi endzaweni yelikhasi le-Discover uyotfutfukela esikhalweni sekusesha.
:::

Umugca ngamunye ukhombisa umbhali wemculo, umnyaka, sitfumelo semibhalo (uma linalo), tinani tetitfose netilanda netikhetsa, kuya kutsatsu temitfombo lekufika kwetatfu, lichasi lalo, nejubane lalo nge-BPM. Cindzetela inkinobho yekudlala ekuqaleni kwemugca uze uzwe irekhodi lesampula noma kuhlolwa kwepiyano ngaphandle kekushiya luhlu.

## Kuhlunga Emaculo

Cindzetela **Filters** kuvula noma kuvala liphaneli letihlungi (livulekile ekucaleni emaskrinini lamakhulu). Ngaphakathi kweliqembu ungakhetsa ngaphezu kwelinye liphuzu; kuya kweminye imiqembu, lemculo kufanele uhambisane nawo wonkhe emahlungi losetile. Inombolo lelandzelana nalo lonkhe likhetfo ikhombisa tinani temaculo ahambisanako.

- **Theme** -- Tihloko letifana ne-Praise, Grace, Hope, noma Christmas. Cindzetela **Show more** ukutfola luhlu lonkhe.
- **Confidence** -- Kuphelela kwetinsita temculo: **Sunday-ready**, **Score**, **Unchecked score**, **Chart only**, noma **Lyrics only**.
- **Ready to use** -- **Works with just a guitar**, **Has accompaniment**, **Has chart**, **Has score**, noma **Has stems**.
- **Key** ne-**Meter** -- Khetsa lichasi lelitsite noma lemetha yelihlabelelo.
- **Tempo** -- **Slow** (ngaphansi kwe-73 BPM), **Moderate** (73–100), noma **Upbeat** (ngaphezu kwe-100).
- **Language** -- Emaculo ngelulwimi lelitsite.
- **Source** -- Layisenisi yemculo, njenge-**Public domain**, **Free for worship**, noma layisenisi ye-Creative Commons. Layisenisi lemakwe ⚠ ayisetfentfwa ngetinjongo tebucala kuphela.
- **Extras** -- **Has demo recording**.

Tihlungi letisebentako tivela njengetitfasa ngaphezulu kwemiphumela. Cindzetela **X** yetitfasa ukuze uyisuse, noma cindzetela **Clear all filters** ukuze uqale kabusha.

:::info
Lihlungi le-**Language** liqala ngaloluhlelo lolukhetsa kulesayithi, kuze ubone emaculo ngelulwimi lwakho kuqala. Ukuze ubone emaculo ngazo zonkhe tilimi, susa itfasa lelulwimi lelingaphezulu kwemiphumela. Ukushintsha lulwimi lwesayithi, sebentisa umkhetsi we-globe ngaphansi kwanoma yiliphi likhasi.
:::

## Uma Lemculo Lingatfolakali

Uma kungekho lohambisanako, susa lihlungi noma sisusa lokusesha. I-WorshipCommons iphatsa kuphela emaculo angasetfentfwa kwabanikati, noma lawo abhali bawakhetsile ukuwabelana, kanti ngako emaculo lalogunyeleliwe akhona lapha. Uma kusesha kungakhombisi lutfo, cindzetela **Search SongSelect →** ukuze ufune lemculo kulukhondlo lwe-CCLI.

## Tindlela Letinye Tekubheka

Tixhumanisi letisemaphansi kwanoma yiliphi likhasi tiyakuholela kuluhlu lwemaculo lolwenteke ngaphambilini:

- **New songs** -- Wonkhe emaculo lengeniswe emtfombeni, lamasha kakhulu kuqala.
- **Public domain hymns** -- Mahlabelelo angasetfentfwa ngayo yonkhe imisebenti.
- **No CCLI needed** -- Emaculo lomphakatsi wakho angawasebentisa ngaphandle kokubika ku-CCLI.
- **Christmas songs** -- Ligcwele lemaculo ekhethekile eKhisimusi.

Cindzetela **Listen** kuluhlu lwasetulu ukuze uzwe emaculo labelane nawo kutsi ngumbhali, ahlanganiswe, aphindze adlale lilandzelana. Cindzetela **+ Save song** ngenkhatsi lelinye lidlala ukuze ulingeze emaculweni akho lagciniwe (uyocelwa ukuba ungene ngemvume).
