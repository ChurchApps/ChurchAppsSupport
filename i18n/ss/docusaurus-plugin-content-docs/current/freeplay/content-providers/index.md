# Labahlinzeki Bekuqukethwe

<div class="article-intro">

Labahlinzeki bekuqukethwe ngetinsita letingaphandle letiniketa tincwadzi temfundziso, tividiyo, nemifanekiso lokudlalwa ku-TV yakho. I-FreePlay isekela labahlinzeki labaningi, ikuvumela kutsi uhlole futsi ulande kuqukethwe kusuka emitfombeni lehlukahlukene konke ku-app yinye.

</div>

## Labahlinzeki Labatfolakalako

Njengamanje i-FreePlay ifaka labahlinzeki balandzelako:

- **[Lessons.church](../../lessons-church/index.md)** - Incwadzi yemfundziso yebantfwana yemahhala, lenemtfombo lovulekile
- **Bible Project** - Tividiyo netinsita letihlola iBhayibheli
- **SignPresenter** - Kuqukethwe kwemiboniso nemabhodi wesonto
- **B1.church** - Kuqukethwe kusuka kusetiphu yakho ye-B1 yesonto
- **Go Curriculum** - Incwadzi yemfundziso kusuka ku-gocurriculum.com, ihlelwe ngemaqembu eminyaka (**Elementary** ne-**Preschool**), bese kuba ngeliqoqo nesifundvo. Ubona kuphela emaqembu eminyaka netividiyo lafakwa ku-umbhalo wakho we-Go
- **Dropbox** - Hlola futsi udlale tifanekiso netividiyo kusuka ku-Dropbox yakho
- **Jesus Film Project** - Emafilimu netividiyo letimfishane kusuka ku-Jesus Film Project
- **OneDrive** - Hlola futsi udlale tifanekiso, tividiyo, nemsindvo kusuka ku-Microsoft OneDrive yakho

:::note
I-Google Drive ne-FreeShow asaseke kuboniswa ku-app ye-FreePlay TV. Kuze usebentise kuqukethwe kwe-Google Drive ku-TV yakho, xhuma kuyo ku-[FreePlay Admin](../scheduled-mode/building-playlists.md#connecting-providers), engeze emafayela kuhlu lwekudlala, bese uhlela lolo hlu.
:::

:::info
Labanye labahlinzeki basaphakanyiswa. Uma likhadi lomhlinzeki likhombisa "Coming Soon," lokusho kutsi lolo hlinzeki alisatfolakali kuze alungiswe.
:::

## Kusebenta Kwabahlinzeki

Umhlinzeki ngamunye unemtfombo wakhe wekuqukethwe, lohlelwe ngetikhwatane netinsita. Uma sewuxhumekile kumhlinzeki, kuqukethwe kwakhe kuvela kumhleli wetikhwatane lapho ungangena kutikhwatane, ukhetse tintfo, bese uzilanda kute zidlalwe.

Labahlinzeki abaxhunyiwe bavela ngesikhatsi ngasecalinise lesingakhoya sekudzonsa esiceleni lesekhohlo sesikrini, ngaphansi kwesihloko ethi **Browse**. Ungashintja phakathi kwabahlinzeki ngekukhetsa bona esicalini, lokwenta kube lula kugcina ucheka phakathi kwemitfombo yekuqukethwe ngesikhatsi sekusetiphu.

Ungakhetsa futsi likhwatane kunoma ngubani labahlinzeki labaxhunyiwe bese uliphindzisela njenge-[announcements](./announcements.md) ku-TV yakho.

:::tip
Labahlinzeki loxhuma kubo ku-TV bavela kuleyo TV kuphela. Uma usebentisa [Imodi Yesikhatsi Lesihlelwe](../scheduled-mode/index.md), xhuma labahlinzeki kanye kuFreePlay Admin, bese tonkhe tiskrini letihlelwe tingadlala kuqukethwe kubo.
:::
