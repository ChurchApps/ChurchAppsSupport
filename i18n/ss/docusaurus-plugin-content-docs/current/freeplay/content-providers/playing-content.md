# Kudlala Lokuqukethwe

<div class="article-intro">

Umdlali weFreePlay ugcwalisa sikrini futsi wakhelwe tilawuli tetelevishini. Udlala tievidiyo netinkhemba letitsatsa kumhlinzeki, kulokulayishiwe, kusuka kulukhetfo, noma kusikhwama setibhengezo sakho, futsi uyatihambisa yena ngekhe noma ngesivinini sakho.

</div>

<div class="prereqs">
<h4>Ngaphambi Kokuqala</h4>

- Khetsa lokutawudlala. Bona [Ukusesha Nokulanda Lokuqukethwe](./browsing-content), [Imodi Yelukhetfo](../plan-mode/), noma [Tibhengezo](./announcements)
- Cinezela **Qala** ukuvula umdlali

</div>

:::info
Tiskrini letibotshelwe ikhalenda sisebentisa umdlali lohlelelwe lonetilawuli letehlukile kancane. Bona [Kudlala Lohlelelwe Ku-TV](../scheduled-mode/scheduled-playback).
:::

## Tilawuli Tomdlali

Sebentisa tilawuli take te-TV kulawula kudlala:

| Inkinobho Yetilawuli | Senti |
|---|---|
| **Khetsa / Misa-Qalisa** | Misa noma uqhubeke |
| **Ticinikhemba tesokudla** | Yeta kutinkhemba noma kulevidiyo lelandzelako |
| **Ticinikhemba tesobunxele** | Buyela kutinkhemba noma kulevidiyo lelandulele |
| **Fast Forward** | Hambela phambili imizuzwana lelishumi kulevidiyo. Esikhwameni, yeta kulotsite lelandzelako |
| **Rewind** | Buyela emuva imizuzwana lelishumi kulevidiyo. Esikhwameni, yeta kulotsite lelandulele |
| **Ticinikhemba letisemagumbini** | Vula **Khetsa Umlayeto** ukuze uye kulotsite lelikhethekile |
| **Phansi / Emuva** | Phuma kumdlali |

:::tip
Ungasebentisa futsi kuswayipha etilawulweni letisekela kuthinta. Swayipha ngakwesobunxele ukuze uye phambili, swayipha ngakwesokudla ukuze ubuyele emuva, swayipha phansi ukuze uvule **Khetsa Umlayeto**, bese uswayipha phezulu ukuze uphume kumdlali.
:::

## Tievidiyo Netinkhemba

Uma umisa, sithonjana sekumisa siyavela phezu kwalokuqukethwe. Cinezela **Khetsa** noma **Misa-Qalisa** futsi ukuze uqhubeke.

Tievidiyo tiyeta kulokulandzelako nasiphela. Levidiyo lelisetelwe kuphindzaphindza liyaphindzaphindza kuze ukhandze phambili.

Tinkhemba letifanisa tiyahamba tiyodvwa emasekhondi lambalwa (imizuzwana lemihlanu ngaphandle kutsi umhlinzeki usethe sikhatsi sakhe). Cinezela **Ticinikhemba tesokudla** ukuze uyete masinyane, noma misa ukuze ubambe tinkhemba esikrinini.

## Khetsa Umlayeto

Cinezela **Phezulu** ngesikhatsi kudlala ukuze uvule **Khetsa Umlayeto**. Ikhombisa yonkhe imitfombo nemagama, futsi imaka lokudlalwako ngu **NOW PLAYING**. Hamba kunoma iyiphi imitfombo bese ucinezela **Khetsa** ukuze uye kuyo masinyane. Cinezela **Emuva** ukuze uyivale ngaphandle kwekushintsha lutfo.

## Kuphuma Kumdlali

Cinezela **Phansi** noma **Emuva** kwiremothi yakho ukuze uphume kumdlali. Lapho uphela khona kuncike kutsi bewudlala ini:

- **Lokuqukethwe kemhlinzeki** - Buyela kumsingathi wekuqukethwe
- **Lukhetfo** - Buyela kusikrini sekulanda lukhetfo. Bona [Imodi Yelukhetfo](../plan-mode/)
- **Kulandziwe** - Buyela kusikrini se **Tilandziwe**

:::info
Sikrini sihlala sivulekile ngesikhatsi umdlali uvulekile, kotsi i-TV ingalali phakathi kwesifundvo.
:::
