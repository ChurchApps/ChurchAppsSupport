# Kuhlela Ikhalenda

<div class="article-intro">

Likhasi le-**Calendar** ku-FreePlay Admin libusa ukuthi liqembu ngalinye lesikrini lidlala ini nangabe nini. Engeza sheduli yepulelisi, sihlelo sesevisi, noma folda yomhlinzeki, bese uyisetha ukuthi iphindeke ngesonto noma idlale kanye nje. Lapho kungekho sheduli etsatfwako, luhlelo lwemtsetfo lweliqembu luyadlala.

</div>

<div class="prereqs">
<h4>Ngaphambi Kokuqala</h4>

- Dala liqembu lesikrini lesisodvwa. Bona [Kuphatha Tiskrini Namaqembu](./managing-screens.md#screen-groups)
- [Akha upulelisi](./building-playlists.md), noma lukhetsa luhlobo lwesihlelo se-B1 Admin

</div>

## Kufundza Ikhalenda

1. Yana ku-**Calendar**.
2. Khetsa liqembu lesikrini kutabhu letfwa phezulu. Ngalinye litabhu likhombisa kutsi liqembu linemashedule ingaki.
3. Umbono wesonto uhamba kusuka kuMsombuluko kuya kuSonto, kusuka ku-6 AM kuya ku-10 PM. Umugca obomvu uveta sikhatsi lesikhona.
4. Sebentisa tinti ukuya kulesonto lendlulile noma lelilandzelako, noma tfwebula **Today** ukubuyela kulesi sonto.

Umbhalo wephe ukhombisa sikhatsi sendzawo lesetfwako ikhalenda. Shedule ilandzela sikhatsi sendzawo sebandla lakho, lesiyisetha ku-B1 Admin ngaphansi kwe-[Church Information](../../b1-admin/settings/church-settings.md#time-zone). Uma bandla lakho lingakasetfwa sikhatsi sendzawo, i-FreePlay isebentisa sikhatsi sendzawo sesikhungo sakho. Ikhalenda kanye neTV tisebentisa sikhatsi sendzawo lesifanako, kotsi sigaba lesibekwe ngo-9:00 AM ekhalendeni lidlala nga-9:00 AM esikrinini, nome kuba likhompyutha yakho isetfwe kusikhatsi lesihlukile.

Ishedule ihlukaniswe ngemibala ngekutsi nguhlobo luni. Lishadi lichaza imibala:

- **Default loop** - Ingemuva lelinemigca, likhombisa ngaphambili kwako konkhe uma liqembu linelupheyiki lemtsetfo
- **Playlist**
- **Service plan**
- **Provider folder**

Ligiya ngalinye likhombisa ligama lalo, kanti tigiya letinde likhombisa nemasikhatsi, nekutsi liyaphindeka yini (**weekly** noma **once**), nekutsi kwenteka kini uma liphela ngaphambi kwesikhatsi.

## Kusetha Luhlelo Lwemtsetfo

Luhlelo lwemtsetfo lwliqembu ludlala etiskrinini letilo nanoma nini lapho kungakho lutfo lwelisheduliwe.

1. Ekhasini le-**Calendar**, tfwebula **Default loop…** esihlokweni. Uma luhlelo lwemtsetfo selusetfwe, litfwelo lichaza **Default loop:** lilandzelwe ligama lepulelisi.
2. Khetsa **Playlist**, noma khetsa **None — screen goes dark**.
3. Tfwebula **Save**.

## Kwengeta Sheduli

Kukhona tindlela letintsatfu tekuqala sheduli lensha:

- Tfwebula indzawo lengenalutfo ekhalenda. Ifomu iyavuleka ingumsebenti losuhlelwe ngalolo lusuku nehafu yelihora.
- Tfwebula **Add schedule** esihlokweni.
- Khetsa **Add schedule** kusikhatsi se-command palette (**Ctrl+K** noma **⌘K**).

Bese ugcwalisa ifomu:

1. **Play** - Khetsa lokudlalwako:
   - **Playlists** - Noma yiphi pulelisi lowakhile
   - **Service plans** - Luhlobo lwesihlelo kusuka ku-B1 Admin, lubhalwe **(current plan)**. Sikhombisa sihlelo lesikhona kuloluhlobo ngalinye sonkhe sonkhe lesonto, kuhlanganise nemakhwelo e-Go Curriculum (nalawo ahlelelwe), lasebentisa ilogini ye-Go lelihlanganiswe nalomsebenti woluhlobo lwesihlelo
   - **Provider folder…** - Iyavula **Choose a provider folder**. Bhabha uye kufolda bese utfwebula **Use this folder**. Kuze ukhetse enye folda kamuva, tfwebula **Change**
2. **Repeats** - Khetsa emalanga esonto lapho leshedule idlala khona. Kuze kube lilanga lelilodvwa, vula **One time** bese ukhetsa **Date**.
3. **Start** ne **End** - Tikhatsi letibhale kutsi shedule iyaqala nekutsi iyamisa nini.
4. **If it finishes early** - Lokufanele kwenteke uma lokuqukethwe kuphela ngaphambi kwesikhatsi lesiphelako:
   - **Loop until the end time** - Iyaqala kabusha kusukela ekuqaleni. Ihle kumabhodi etemphuno, tesaziso, nalabalanga
   - **Teacher paced** - Tibonakaliso tilindze isilawuli sematitjhere. Lesifundvo sihlala siboniswa ngaphesikhatsi kuze kube sigaba sekugcina
   - **Play once, then go back to the default loop**
5. Kushedule letiphindeka, setha **Starts** kulilanga lekuqala. Ngaphansi kwe-**Ends**, khetsa **Never**, noma khetsa **On date** bese ufaka **End date**.
6. Tfwebula **Save**.

:::info
**Teacher paced** ithathe indzawo yenkhetho lendala ethi "hold the last slide". Shedule lelondliwe ngaleyo nkhetho manje idlala njenge-teacher paced.
:::

## Kuhlela Noma Kususa Sheduli

1. Tfwebula ligiya lesheduli ekhalenda.
2. Shintja nanoma yiliphi licala bese utfwebula **Save**, noma tfwebula **Delete** ukuze ususe sheduli.

## Tishedule Letihlanganako

Uma tishedule timbili tihlanganile, ifomu likhombisa sexwayiso: **Overlaps another schedule. The one that starts later wins.** Kuyo lonkhe sikhatsi lesheduli lesamuva isasebenta, tiskrini tiyayidlala. Lapho iphela, tibuyela esheduleni lesandulela uma isasebenta.

## Tiskrini Tisebenta Kanjani Ngetinguquko

Tiskrini letibhangqiwe tiyalanda konkhe lekushedulelwe ematsatsi lalandzelako lasikhombisa-7, futsi tiyahlola tinguquko tiyedvwa. Awudzingi kuthinta i-TV ngemva kwekuhlela ikhalenda. Kuze ubone kutsi tiskrini tilungele, hlola i-**Ready through** ekhasini le-[Screens](./managing-screens.md).
