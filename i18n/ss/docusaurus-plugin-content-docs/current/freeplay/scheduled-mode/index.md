# Imodi Yesikhathi Esihleliwe

<div class="article-intro">

Imodi Yesikhathi Esihleliwe ivumela i-FreePlay TV ukuba isebente yodvwa. Wakha tinhlelo tekudlala bese utifaka ekhalendeni ku-**FreePlay Admin** ku-[admin.freeplay.church](https://admin.freeplay.church). Yonkhe i-TV ehlanganiswe nalelikhalenda ilanda sonkhe sonkhe lensuku lelilandzelako bese idlala loko okuhleliwe, ngesikhathi lesitsiwe, lapho kungekho muntfu locindzetela Start. Njengoba emafayela sewalandvwa, kudlala kuyaqhubeka noma i-Wi-Fi iphela.

</div>

:::tip
I-FreePlay Admin isebentisa ilogini yakho ye-ChurchApps, lefanako lesebentisa ku-B1 Admin. Akukho i-akhawunti leyehlukile ekufanele udalwe.
:::

## Indlela Konke Lokuhlanganako Ngayo

I-FreePlay Admin inemaphepha lamane lamkhulu, abhalwe phezulu esiteshini:

- **[Tiskrini](./managing-screens)** - Ti-TV lotibhangqe nato, simo sato, kanye ne **mapheyintsi wetiskrini** lato kuwo. Tiskrini letisemapheyintsini linye lisebentisa ikhalenda linye kanye ne-loop yekucala
- **[Tinhlelo tekudlala](./building-playlists)** - ti-loop tetithombe netividiyo tolukhetha kubahlinzeki bebucwebe bakho
- **[Ikhalenda](./scheduling-the-calendar)** - Lokudlalwa ngumphakatsi weskrini ngamunye, nangesikhathi
- **[Bahlinzeki](./building-playlists#connecting-providers)** - Timtfombo tebucwebe letinhlelo takho tekudlala tatsatsa kuto. Ukhuta ngalunye kanye kuphela kuyo yonkhe lebandla

Uma kungakho lokuhleliwe, tiskrini tesigaba tidlala i-**loop yekucala** yaso. Uma sigaba singenayo i-loop yekucala, tiskrini tiyavaleka.

## Indlela Lehlukana Ngayo Nemodi Yelinhlelo

- **[Imodi Yelinhlelo](../plan-mode/)** ilandzela luhlobo lulumbe lwelinhlelo lomsebenti kuB1 Admin. Umuntfu acindzetela **Start Plan** ku-TV, bese lifundvo lidlala lapho akwenta njalo
- **Imodi Yesikhathi Esihleliwe** ilandzela ikhalenda. Lokuphakatsiwe kuyaqala kuyeke ngetikhatsi lotisetako, ngako isebenta kahle etinhlelweni tetimphawu ekhefini, emalunga wesimemetelo, nasemakilasini lapho lifundvo kufanele libe lisekhatsi ngaphambi kwekutsi umuntfu angene

Ikhalenda lingasadlala nelinhlelo lomsebenti. Khetsa luhlobo lwelinhlelo ngaphansi kwe**Service plans** lapho ungeta khona sikhatsi, bese tiskrini tidlala linhlelo lomsebenti lelisemandleni ku-B1 Admin ngaleso sonto. Loku kuhlanganisa nemafundziso e-Go Curriculum, nalamanye layikhetsa kulelinhlelo. Tiskrini sisebentisa ilogini ye-Go Curriculum lehlanganiswe nemsebenti wesiphatsi selinhlelo ku-B1 Admin, noma kuhlanganiswa kwebandla ne-Go Curriculum uma umsebenti ungenayo.

## Kucala

Ngaphandle kwekutsi usenta konkhe lokulandzelako, siphepha se**Tiskrini** sitfola uhlu lwekuhlola lwe**Qala** lunelinkhomba yayo yonkhe imitsetfo:

1. **Hlanganisa umhlinzeki** - Hlanganisa i-Dropbox, i-OneDrive, i-Lessons.church, noma lesinye umtfombo ngesiphepha se**Bahlinzeki**
2. **Akha inhlelo yekudlala** - Khetsa tithombe netividiyo kumhlinzeki
3. **Yifake ekhalendeni** - Khetsa lokudlalwa nangesikhathi, noma setela i-loop yekucala yesigaba
4. **Hlanganisa iskrini** - Faka likhodi lenhlamvu ezine lebonakala ku-TV

Cindzetela **Fihla** ukuze uvale uhlu lwekuhlola.

:::tip
Cindzetela **Ctrl+K** (**⌘K** kuMac), noma ucindzetele libhokisi lekufuna esigcwaleni, uvule i-command palette. Kulapho ungaya khona kunoma yiphi siphepha noma wente sento njenga **Hlanganisa iskrini**, **Engeta inhlelo yekudlala**, noma **Engeta sikhatsi**.
:::
