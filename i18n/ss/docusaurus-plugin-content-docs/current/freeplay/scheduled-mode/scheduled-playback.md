# Ukudlala Lesihlelwe Ku-TV

<div class="article-intro">

Nxa i-TV isihlanganiswe nekhalenda, i-FreePlay iyiphatsa ngawe. Iyalanda sonkhe lesiseduze, iguqule lokuqukethwe ngesikhatsi lesihlelwe, futsi iqhubeka idlala kusuka esitoreji sayo nxa i-inthanethi ingasasebenti. Othishela noma umsebenzeli angasenta lokusalela: angamisa, adlule, futsi agijime ngesilawuli se-TV.

## Lokwenta i-TV Ngokwayo

- **Ivula ngqo kushedyuli** - Nxa i-TV ehlanganisiwe iqala i-FreePlay, iya ngqo kuplayer lehlelwe
- **Ilanda kusengaphambili** - I-FreePlay ilanda yonkhe imafayela lehlelwe kuleviki lelilandzelako, kanye neloophu yokuzenzakalela, bese idlala kusuka kulokulandziwe
- **Idlala ngesikhatsi** - Ngesikhatsi ngasinye lapho kuqala khona lokuqukethwe, sikrini siyashintjana siye kulokulandziwe. Nxa kungekho lokuhlelelwe, idlala iloophu yokuzenzakalela yeqembu
- **Ihlola ushintsho** - I-FreePlay ihlola i-FreePlay Admin njalo ukuze itfole ushintsho lwekhalenda, futsi ilande lokusha
- **Ilungisa emafayela lebonakalako** - Nxa lifayela lelilandziwe lingadlali, i-FreePlay iyayidlula bese iyilanda kabusha

Ngaphambi kokuthi emafayela lokuqala afike, sikrini sibonisa **Kulayisha ishedyuli...** noma **Kulanda emafayela angu-X kwangu-Y**. Nxa kungekho lokuhlelelwe futsi iqembu lingenayo iloophu yokuzenzakalela, sibonisa **Akukho lokuhlelelwe njengamanje**.

## Ipanele Lelulwazi

Cindzetela **Khetsa** ku-remote ukuvula ipanele lelulwazi. Liyavala lona ngalo emva kwemizuzwana lembalwa. Ipanele likhombisa:

- **Ngasemkhonweni wangenhla** - **Ilungele kuze kube** kulandzelwa ngelilanga nxa konkhe lokuya kulelilanga selilandiwe, noma **Kulanda** nxa emafayela asafika. Ngaphansi kwalokho, kukhombisa kutsi mangaki emafayela alandiwe, nebha yekuqhubeka
- **Ngasemkhonweni wangaphansi** - Ligama lalokudlalwako (noma **Iloophu yokuzenzakalela**), kutsi likuphi kusikrini, kanye nalokulandzelako nesikhatsi saso
- **Kuhlola kwekugcina** - Nxa i-FreePlay ihlole kugcina ushintsho lweshedyuli

Ipanele futsi linemacuba lamatsatfu:

- **Phina Le Playlist** - Gcina lokuqukethwe lokwamanje kudlala kuloophu, ungayinaki ikhalenda. Cindzetela **Khipha Playlist** ukubuyela kushedyuli
- **Hlola Lokuqukethwe** - Shiya i-player lehlelwe ukuze uhlole bahlinzeki lababhalisiwe
- **Tilungiselelo** - Vula tilungiselelo te-FreePlay, lapho ungakhipha khona noma uhlanganise nekhalenda lehlukile [](./pairing-a-screen#changing-or-unpairing-from-the-tv)

:::tip
Ukuze ubuyele kushedyuli emva kokuhlola, cindzetela **Emuva** ku-remote usuka kusikrini se-**Bahlinzeki Balokuqukethwe**, noma vula **Tilungiselelo**, khetsa **Hlanganisa nekhalenda**, bese ukhetsa **Buyela kushedyuli**. I-TV ehlanganisiwe iphindze ibuyele kuplayer lehlelwe nxa i-FreePlay ibuya ekubonakaleni, futsi njalo ivula kuplayer lehlelwe.
:::

## Tilawuli Te-Remote

| Inkinobho ye-Remote | Lesenteka |
|---|---|
| **Khetsa** | Vula ipanele lelulwazi |
| **Dlala/Misa** | Misa noma uqhubeke. Sitfombe sekudlala sivela nxa kumisiwe |
| **Umcibisho wesekudla** | Sitfombe lesilandzelako noma lividiyo |
| **Umcibisho wesekhohlo** | Sitfombe lesandulelako noma lividiyo |
| **Umcibisho wetulu** | Vula ukubuka kwetifanekiso ukuze ufike kunoma yisiphi sitfombe |
| **Phambilisa** | Yendlula imizuzwana engu-10 phambili kuvidiyo |
| **Buyisela emuva** | Buyela emuva imizuzwana engu-10 kuvidiyo |
| **Emuva** | Vala ukubuka kwetifanekiso noma ipanele lelulwazi, noma vula ipanele lelulwazi |

Lokulandzelako nalokwandulelako kuhlala ekulandzeleni kwalokuqukethwe lokudlalwako manje. Ayebuyeli kokucala nxa kufika ekugcineni kwelisha lokulandzelako, kuphela nxa ishedyuli isetelwe ukuphindzaphindza. Phambilisa nebuyisela emuva kusebenta kuphela ngesikhatsi kudlala lividiyo. Kusitfombe akwenti lutfo.

### Ukuya Esitfombeni

Cindzetela **Umcibisho wetulu** ukuvula ukubuka kwetifanekiso. Ibonisa yonkhe imitfombe lesendzaweni yeplaylisti noma lesifundvo lwamanje. Hamba kulowo ufuna, bese ucindzetela **Khetsa** ukuze ufike ngqo kuwo.

## Tifundvo Letihamba Ngesivinini Sotisho

Nxa ishedyuli isetelwe **Ngesivinini sotisho**, sitfombe asihambi siye phambili ngaso sona. Othishela uhamba phambili ngu-**Umcibisho wesekudla**. Lividiyo lidlala kuze kube sekugcineni bese lihamba kulelandzelako.

Sifundvo lesihamba ngesivinini sotisho sihlala esikrinini ngaphesi kwesikhatsi saso lesiphelile lesihlelwe, kuze othishela afike esitfombeni lesigcina bese sipheli. Ngemuva kwaloko, sikrini sihamba siye kulokulandzelako lokuhlelelwe. Lokhu kuvimbela kutsi likilasi lelihamba sikhatsi lesidze lingaphazanyiswa phakathi kwesifundvo.

## Kwetfula Usuka Ku-browser

Ungadlala futsi ikhalenda lesikrini ku-web browser. Ku-FreePlay Admin, vula sikrini kusuka ekhasini le-**Screens**, bese ucindzetela **Present in browser**. I-browser ilandzela ikhalenda lalesikrini njengo-TV, futsi ibha yetilawuli ibonisa lokulandzelako. Sebenta **Space** ukumisa, **←** / **→** ukudlula, **F** kusikrini sigcwele, futsi **Esc** ukuphuma.
