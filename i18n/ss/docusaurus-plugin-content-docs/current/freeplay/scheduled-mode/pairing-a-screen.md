# Kuxhumanisa Sikrini

<div class="article-intro">

Ukuze ubeke i-TV ekhalendeni, yixhumanise ne-**FreePlay Admin**. I-TV iveta likhodi lemagama lane. Uyifaka leyo khodi ku-[admin.freeplay.church](https://admin.freeplay.church) bese ukhetsa liqembu lesikrini lekhalenda lekufanele i-TV ilandzele. Lokhu wekwenta kanye nje nge-TV ngayinye.

</div>

<div class="prereqs">
<h4>Ngaphambi Kokuqala</h4>

- Faka uphinde uvule i-FreePlay ku-TV. Bona [Kuqala](../getting-started/)
- Ube nelogini ye-ChurchApps yebandla lakho ukuze ungene ku-FreePlay Admin
- Uma ufisa, [akha uhla lwemculo](./building-playlists) bese [uyihlela](./scheduling-the-calendar) kuqala ukuze i-TV ibe nalokudlala masinyane

</div>

## Kukhombisa Likhodi ku-TV

1. Ku-TV, vula **Settings** ngaphansi kwesidzidzi sekhohlo.
2. Khetsa **Pair to a calendar**. Umugca utfola **Not paired** uma i-TV ingakaxhunyani.
3. Sikrini **Pair this screen** sikhombisa likhodi le-QR kanye nelikhodi lemagama lane lekuxhuma, nalomlayeto othi **Scan with your phone, or go to freeplay.church/pair and enter this code**.
4. Ngaphansi kwelikhodi, **Waiting for confirmation** iyacaca njalo uma i-FreePlay ilindzele ukuthi uqedze kuxhuma.

Likhodi liphila imizuzu lelitfoli-shumi nesihlanu, futsi ikhawunta ngaphansi kwalo ikhombisa sikhatsi lesisele. Lisikhatsi siphelile, i-FreePlay ikhombisa likhodi lelisha ngayo yonkhe. Ungakhetsa futsi **Generate New Code** ukuze utfole elisha, noma **Cancel** ukuze ubuyele ku-Settings.

## Kuxhumanisa ku-FreePlay Admin

1. Skena likhodi le-QR ngefoni yakho, noma uye ku-**freeplay.church/pair** nakuyiphi ikhompyutha noma ifoni. Ngena uma ucelwa kutsi ungene. I-FreePlay Admin ivula fomu i-**Pair screen** nelikhodi seliveleligcwele.
   - Ungayivula nawe ngako. Ya ku-**Screens** ku-FreePlay Admin bese ucindzetela **Pair screen**.
2. Hlola i-**Pairing code**. Yimagama lane lakuseSikrini se-TV.
3. Faka i-**Label** ukuze ukwati kwehlukanisa le-TV kwetinye, njengo "Lobby left". Lokhu akudingeki.
4. Ngaphansi kwe-**Group**, khetsa liqembu lesikrini lekhalenda lekufanele le-TV ilandzele. Ukuze uqale elisha, khetsa **＋ New group…** bese ufaka **New group name**.
5. Ngaphansi kwe-**Mode**, shiya **Scheduled** likhetsiwe. I-TV itawudlala ngekhalenda yeliqembu ngekwayo.
6. Cindzetela **Pair**.

I-TV ikhombisa **Connected!** bese ikhombisa **Loading your schedule...**. Ikhipha lokuhleleleke bese iqala kudlala. Bona [Kudlala Ngekhalenda ku-TV](./scheduled-playback).

:::info
Uma i-FreePlay Admin ithi **That code didn't match a TV**, hlola likhodi lesikrinini. Uma liphelelwe sikhatsi, sebenzisa likhodi lelisha le-TV lesikhombisa njengamanje.
:::

### Okuhleleke Kanye Nokwenteka Ngesandla

Ku-**Mode** kunetinketho letimbili:

- **Scheduled** - Idlala ngekhalenda yeliqembu ngekwayo. Akudingeki kutsi umuntu acindzetele Start.
- **Manual** - Umuntu ukhetsa lokuqukethwe nge-remote. Sikrini sesandla sisabonakala ohlwini lwakho lwe-**Screens**, kodvwa asilandzeli ikhalenda, ngako inkhundla ye-**Group** iyavalwa.

Ungashintsha imodi yesikrini kamuva uyisebentise **Edit** kusikhatsi se-[Screens page](./managing-screens).

## Kuxhumanisa Nesikhatsi Sesevisi Kunalokuya

Likhodi lesikrini se-**Pair this screen** isebenta futsi ku-B1 Admin. Uma uyifaka lapho bese ukhetsa luhlobo lwesikhatsi ngaphansi kwe-**Show Plans For**, i-TV itawulandzela luhlobo lwesikhatsi lolo ku-[Plan Mode](../plan-mode/) esikhundleni sekhalenda. Bona [Kuxhumanisa Lidivayisi Lakho](../plan-mode/device-pairing).

## Kushintsha Noma Kuhlukanisa Kusuka ku-TV

Nakuba i-TV isixhunyiwe, umugca othi **Pair to a calendar** ku-**Settings** ukhombisa ligama leliqembu lesikrini lelilandzelwako. Khetsa umugca ukuze uvule incenye ye-**Paired to**, enetinketho letintsatfu:

- **Back to schedule** - Vala incenye ubuyele ku-scheduled player. Akukho lokushintsha ekuxhumekeni.
- **Unpair** - Yekela kulandzela ikhalenda. I-FreePlay ivula sikrini se-**Content Providers**.
- **Pair to a different calendar** - Hlukanisa, bese ukhombisa likhodi lelisha lekuxhuma ukuze uxhumanise i-TV futsi.

:::warning
Kuhlukanisa kususa lamafayela i-FreePlay ayelandzile kuleKhalenda.
:::

## Kuhlukanisa Kusuka ku-FreePlay Admin

1. Ya ku-**Screens** bese ucindzetela ligama lesikrini.
2. Cindzetela **More**, bese **Unpair**.
3. Cindzetela **Unpair** futsi ukuqinisekisa.

I-TV ibuyela kukukhombisa likhodi lekuxhuma. Yixhumanise futsi nanoma nini lapho ufuna kutsi isebente.
