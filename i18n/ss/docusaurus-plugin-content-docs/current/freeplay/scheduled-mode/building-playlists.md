# Kuxhumana Nebahlinzeki Nekwakha Tinhlu Tekudlala

<div class="article-intro">

Inhlu yekudlala ngumtfwalo wetithombe netivakatisi lotibeka kukhalenda. Ku-FreePlay Admin uxhuma bahlinzeki bakho bekuqukethwe kanye nje bonkhe lebandla. Kulandzela loko wakha tinhlu tekudlala ngekukhetsa tifayela kulaba bahlinzeki.

</div>

<div class="prereqs">
<h4>Ngaphambi Kokuqala</h4>

- Ngena ku-FreePlay Admin ku-[admin.freeplay.church](https://admin.freeplay.church)
- Ube nelolwazi lwekungena lwe-akhawunti yanoma yimuphi umhlinzeki ofuna ukuyi-xhuma, njengo-Dropbox noma OneDrive

</div>

## Kuxhuma Bahlinzeki

Likhasi le-**Providers** lidzwasa imitsombo yakho yekuqukethwe ngetigaba letimbili:

- **Connected** - Bahlinzeki longasebentisa manje. Bahlinzeki besidzabuko labangadzingi kungena, njengo-Lessons.church kanye ne-Bible Project, njalo bakhonjiswa lapha njenge-**Public · no sign-in needed** (Lesidzabuko · akudzingeki kungena). Ema-akhawunti axhunyiwe akhombisa **Account linked** (I-akhawunti ixhunyiwe) kanye nalapho kuphela khona kuxhuma.
- **Available** - Bahlinzeki labadzinga kutsi ungene ngaphambi kwekutsi ungabasebentisa.

Kutsi uxhume umhlinzeki:

1. Ya ku-**Providers**.
2. Fica umhlinzeki ngaphansi kwe-**Available** bese ucindzetela **Connect**.
3. Ngena ku-akhawunti yakho nalowo mhlinzeki:
   - Abanye bahlinzeki, njengo-Dropbox, Google Drive, no-OneDrive, bavula iwindzi lekungena. Nangabe kute lokuvela, vumela ama-popup ye-admin.freeplay.church.
   - Abanye bahlinzeki bakhombisa sixhumanisi nekhodi. Vakashela lesixhumanisi, faka likhodi, bese uvumela kufinyelela. Incwadzi iyavuselela yona nawuphelile.
4. Nawubona **Account linked successfully!** (I-akhawunti ixhunyiwe ngempumelelo!), umhlinzeki uyofika ku-**Connected**.

Bahlinzeki labaxhunyiwe banemisebenti lemitsatfu:

- **Browse** - Hlola emafolda omhlinzeki
- **Refresh** - Vuselela kungena kwemhlinzeki
- **Unlink** - Nqamula i-akhawunti

:::info
Kuxhumana kwebahlinzeki ku-FreePlay Admin kuyeBandla lonkhe, hhayi komuntu munye noma lilambu limbe. Tiskrini letihleliwe titfola tifayela tazo ngalokuxhumana, ngaleyo ndlela awudzingi kungena kumhlinzeki ngamunye kuwo wonkhe emalambu.
:::

**FreeShow** itsi **On your church network · each TV finds it itself** (Esinkhonteni sebandla lakho · lilambu ngalinye liyitfola lyodvwa). Akukho lokufanele kuxhunywa kuyo ku-FreePlay Admin.

## Likhasi Letinhlu Tekudlala

Likhasi le-**Playlists** lidzwasa inhlu nhlu yekudlala ngayinye ngenani letintfo tayo, bude bayo bonkhe, lapho isetfwa khona (**Default loop** yeliqoqo, noma inani lemakhalenda), kanye nalapho yavuselelwa khona ekugcina. Umugca ngamunye unemisebenti lena:

- **Present** - Dlala inhlu yekudlala ngesikrini esigcwele ku-bhrawuza yakho
- **Edit** - Vula umhleli wenhlu yekudlala
- **Duplicate** - Yenta likhophi lebitwa ngelithi "(ikhophi)"

## Kwakha Inhlu Yekudlala

1. Ya ku-**Playlists** bese ucindzetela **Add playlist**.
2. Faka **Name** (Ligama), njengo "Welcome loop" (Luhla lwekwemukelwa).
3. Cindzetela **Add playlist**. Umhleli wenhlu yekudlala uyavula.

## Kungenisa Tintfo

Umhleli wenhlu yekudlala ukhombisa **Items** (Tintfo) letisenhlu ngesobunxele kanye ne-**Add from provider** (Engeta kumhlinzeki) ngesokudla.

1. Ngesokudla, khetsa ithebhu yemhlinzeki. Kutsi wengete omunye umtsombo, cindzetela **Connect another** (Xhuma lenye), lenyula likhasi le-**Providers**.
2. Cindzetela emafolda kutsi ungene ngaphakathi. Sebentisa umugca wetindzawo kutsi ubuyele ngaphandle.
3. Cindzetela ifayela kutsi ulingete ekugcineni kwenhlu yekudlala. Tifayela letisenhlwini tiphawulwa njengetikhetsiwe.
4. Kutsi wengete tonkhe tintfo lesikhwameni lesikhona ngesikhatsi sinye, cindzetela **Add all** (Engeta tonkhe). Inkinobho ikhombisa kutsi tifayela lingakhi tingaki letingakangeni enhluyeni.
5. Cindzetela **Save** (Gcina) phezulu kwemhleli.

:::warning
Tinguquko akugcinwa kuze ucindzetele **Save**. Cindzetela **Cancel** (Khansela) kutsi uphume ngaphandle kokugcina.
:::

## Kuhlela Tintfo

Ohlwini lwe-**Items** ngesobunxele:

- **Reorder** - Hudzela intfo ngesibambi sayo ngesobunxele
- **Image timing** - Tithombe titfola emasekhondi lali-10 ngekuzenzekelako. Shintja inani lemasekhondi eduze kwesithombe
- **Videos** - Tivakatisi titfola **Plays to end** (Idlala kuze kuphele) bese idlala bude bayo bonkhe
- **Remove** - Susa intfo enhluyeni yekudlala

Umphakamo ngentasi ukhombisa inani letintfo kanye nebude bonkhe benhluyeni yekudlala.

## Kutsi Ubize Kabusha, Kuphindvwa, Nekususa

Lipaneli lesobunxele lomhleli likhombisa kutsi inhlu yekudlala isetfwa kuphi. Iphindze ibe nalemisebenti:

- **Present** - Dlala inhlu yekudlala ku-bhrawuza yakho
- **Rename** - Shintja ligama lenhlu yekudlala
- **Duplicate** - Yenta likhophi kutsi ulihlele ngalokwehlukile
- **Delete** - Susa inhlu yekudlala. Tikhatsi letibe ledlala yona tibuyela ku-loop yeliqoqo lelizenzekelako

## Kwetfula Inhlu Yekudlala Ku-bhrawuza Yakho

Cindzetela **Present** kutsi udlale inhlu yekudlala ngesikrini esigcwele ku-bhrawuza yakho. Lokhu kusiza nawufuna kubuka kucinisekisa inhlu yekudlala, noma kutsi uyidlalise uchukuma i-laptop exhunyiwe ku-projector. Hambisa imbewu kutsi ubonise umugca wetilawuli, bese usebentisa letimpandvuku:

| Inkinobho | Sento |
|---|---|
| **Space** | Misa noma uqalise kabusha |
| **←** / **→** | Intfo leyandulela noma leyelandzelako |
| **F** | Shintja sikrini esigcwele |
| **Esc** | Phuma |
