# Kuzulazula B1App

<div class="article-intro">

## Ikhasi Lekuqala {#home}

Kuvula `https://yourchurchname.b1.church/mobile` kukuyisa ku-**Ikhasi Lekuqala** ku`/mobile/dashboard`. Ikhasi lekuqala ngelo lelivela ekucaleni kwelilunga lamalunga. Liqala ngelisho lekuncoma ("Sawubona ekuseni", "Sawubona emini", noma "Sawubona kusihlwa" lilandvwe ligama lakho lekucala) nelilanga lanamuhla, lilandvwe ngemacembu lavela nje uma asebentako:

- **Matayela esithombeni** -- emathebhu lebelinikelwe sitfombe ngulo bandla lakho (kuhlanganisa Vesi Yensuku) avela njengematayela esithombeni ngaphansi kwelibito lebandla lakho. Kuya ngekukhetsa kwebandla lakho, ayabekwa njengemugca wemakholomu mabili, umugca lowuswayipha ngecala (lowungahamba nawo ngekwawo), noma luhlu lolunetifanekiso letincane ecaleni kwelibito ngalinye -- bona [Matayela Esikrinini Sekuqala](../../b1-admin/settings/mobile-app.md#home-screen-tiles). Uma umugca lowuswayipha unematayela lamaningi kunalawo langakwanela esikrinini, umugca wetindzawo letincane ngaphansi kwawo ukhombisa lapho ukhona khona; cofa itindzawo letincane ukuze uye kulelo tayela. Umugca uyaqhubeka uhamba phambili, uphindvulele kutayela lekucala nakube selitayela lokugcina. Yonkhe imathebhu yetithombe ivela lapha, nanoma nayo ilenindzawo ku-ibha lemathebhu.
- **Inkulumo yakamuva** -- inkulumo yakamuva yebandla lakho, linkinobho **Tonkhe tinkulumo** lelingasentsa ekhasini lonkhe.
- **Vesi Yensuku** -- livesi lanamuhla; cofa kuyo ukuze uvule ikhasi lonkhe le[Vesi Yensuku](../content/verse-of-the-day.md).
- **Uyakhonta** -- tindzawo takho letilandzelako tekukhonta, nelinkinobho **Tonkhe tinhlelo**. Uma noyiphi indzawo idzinga impendulo yakho, leto itakuvela kucala nelembulelo **Kudzinga impendulo** nemankinobho **Vuma** / **Nqaba** ukuze uphendvule ngqo kuHome (**Nqaba** itakucela kutsi uqinisekise kucala); lapho kungenjalo, tindzawo takho letilandzelako tovela nelembulelo **Kwemukelwe** noma **Kuqinisekisiwe**. Cofa indzawo ukuze uvule luhlelo lwayo.
- **Emaqembu akho** -- kuya kumaqembu lamatsatfu akho nesikhatsi sawo sekuhlangana nendzawo, nelinkinobho **Tonkhe emaqembu**.
- **Tehlakalo letilandzelako** -- uma usungene, tehlakalo letitsatfu letilandzelako temaqembu akho netibhalisiso tehlakalo tihlanganiswa ndzawonye, tihlelwe ngesikhatsi, ngalinye nelilanga nesikhatsi (nesithombe lesincane uma tehlakalo linesithombe). Umugca ngalawo ubhalwe **Tehlakalo** (tehlakalo lelivela emaqembini lolilungu lawo) noma **Libhalisiso** (tehlakalo lobhalise kulo [ngalo](../events/registering.md)); tehlakalo lobhalisele kulo likhombisa kanye njengelibhalisiso. Cofa tehlakalo ukuze uvule tehlakalo temqembu walo, noma libhalisiso ukuze uvule [tibhalisiso takho](../events/my-registrations.md). Cofa **Tonkhe tehlakalo letilandzelako** ukuze uvule luhlu lonkhe lwetehlakalo letilandzelako ekhasini lakho [Mina](./me-page.md#upcoming), lelifaka netindzawo takho tekukhonta netibhalisiso.
- **Kubakhona kwami** netimfomu **Tifomo tami** -- uma lebandla lakho litivulile, kangaki ubekhona kulamasonto langu-90 langaphambili nemisebenzi yakho lemibili lesanda kwenta, nemafomu lakho lamabili lasanda kuwafaka, netixhumanisi kuluhlu lonkhe. Lezi ziyavela njalo ekhasini lakho [Mina](./me-page.md) nanoma kunjani -- bona [Tindzawo Letikhombisa Ekhasini Lekuqala](../../b1-admin/settings/mobile-app.md#home-screen-sections).
- **Kuniketela** -- kangakanani usunikele ngalomnyaka ("Kuniketelwe ngu-" umnyaka wamanje), inkinobho **Nika** (kuvela kuphela uma lebandla lakho linikela ku-inthanethi), nelixhumanisi **Umlandvo** kuya kulumlandvo wakho [wekuniketela](../giving/donation-history.md). Iyafihleka uma lebandla lakho lenciphise umlandvo wekuniketela wemalunga noma liwufihlile, lapho kukhombisa khona lithuluzi lekuniketela lelibandla lakho njengenkinobho ngaphansi kwe**Kuvela ku-**.
- **Kuvela ku-** *lebandla lakho* -- tinkinobho tetinye tithuluzi lelibandla lakho lelivulile lelingakasese kumathebhu esikhwameni noma lelikhonjiwe ngenhla. Lawo ngiwasebentisa kakhulu ayaya ekucaleni.

Tindzawo tekukhonta, tamaqembu, tekubakhona, tematfomu, nekuniketela zivela kuphela uma usungene, lebandla lakho linalelo thuluzi livulekile, futsi unento yekukhombisa -- nasi sibonelo sisemsebenzini lolulandzelako noma nasinjengaqembu linye kuncane. Kukhompyutha, Ikhasi Lekuqala lihlelwe ngemakholomu mabili.

Uma ungakangeni, Ikhasi Lekuqala likhombisa sihloko **Siyakwemukela** esikhundleni sesisho sekucala, nesaci esifutsi ("Ngena uce ubone emaqembu akho, kuniketela, nekunye lokungaphezulu.") nenkinobho **Ngena**. Lesaci sikhombisa noma ngabe lebandla lakho alisacale kusetsa lutfo lolunye ngeKhasi Lekuqala. Lebandla lakho lingasichazela kabusha noma lisifihle -- bona [Tilungiselelo Telilunga Lamalunga](../../b1-admin/settings/mobile-app.md#home-screen-sign-in-prompt). Lapho sifihliwe, ungasangena usuka ekhasini le**Ngaphezulu** noma ekhasini le**Mina**.

## Ibha Lelingaphansi Lamathebhu

Esikrinini sefoni, ibha lamathebhu ibekwe ngaphansi kwesikrini:

- **Ikhasi Lekuqala** -- njalo ilithebhu lekucala
- Kuya kulitsatfu kulamathebhu lebandla lakho lilungisele
- **Ngaphezulu** -- livula ikhasi le-Ngaphezulu

Tindzawo letakhiwe ngaphakathi (njengo Emaqembu, Kuniketela, noma Tinhlelo) itfola tindzawo tekucala kucala; tindzawo letisele titfola tikhasi tebandla letilungiselelwe. Tixhumanisi tetiwebhu letingaphandle nelivesi lensuku kuphela lingatfoli ithebhu. Uma lebandla lakho lilungisele tithebhu letingaphezu kwaleto letilingana esikrinini, letinye tiyalahleka: tivela ekhasini le**Ngaphezulu** nasesigabeni se**Kuvela ku-** ekhasini lekuqala. Balawuli bebandla bayabeka ludzidzo lwamathebhu ku-B1 Admin ngaphansi kwe**Mobile → Navigation**.

### Ematabhu Esikhwama {#folder-tabs}

Lebandla lakho lingahlanganisa emathebhu lamaningi abe **sikhwama**. Sikhwama sivela njengalitheble lilinye -- ebhalini yetithebhu, ekhasini le**Ngaphezulu**, noma njengetayela lesithombe ekhasini lekuqala -- futsi ukucofa kuso kuvula sikrini lesikhombisa libito lesikhwama lelihlu lemathebhu lakuso. Uma yonkhe imathebhu esikhwameni inesithombe, ivela njengematayela esithombeni; uma kungenjalo ivela njengeluhlu. Tixhumanisi tetiwebhu letingaphandle esikhwameni tivulela ngetabhu lelisha lesiphequluli. Imathebhu lesikhwameni ivela kuphela esikrinini sesikhwama, hhayi ebhalini yetithebhu noma ekhasini le**Ngaphezulu**. Sikhwama lelingenalutfo lolubonakalako siyafihleka.

## Ekhompyutheni

Esikrinini lesikhulu, njengekhompyutha noma ithebulethi lenkhulu, ibha lamathebhu lelingaphansi lishintjwa yinhloko lekhombisa ngaphezulu kwesikrini ngumbala webandla lakho. Iveta logo lebandla lakho, noma libito lalo uma logo lingasetiwe (cofa kuyo ukuze ubuyele Ekhasini Lekuqala), **Ikhasi Lekuqala**, kuya kulitsatfu kulamathebhu lebandla lakho lilungisele, kanye ne**Ngaphezulu**, nesigidigidi nesithombe sakho sembhalo ngalapha ngesandla lesitfunti. Uma uvula sikrini lesinemininingwane, sixhumanisi se**Emuva** siveta ngentasi kwelitfuba lelicolwe.

## Ikhasi Le-Ngaphezulu

Ukucofa **Ngaphezulu** kuvula ikhasi le-Ngaphezulu ku`/mobile/more`. Lilandzelako:

- Libito lakho nesithombe sakho, nexhumanisi **Hlela Iphrofayili** -- bona [Kuhlela Iphrofayili Yakho](./editing-your-profile.md)
- Yonkhe imathebhu lebandla lakho lilungisele, ngalokulandzelana, ngaphansi kwelibito lebandla lakho. Tixhumanisi tetiwebhu letingaphandle tivulela ngetabhu lelisha lesiphequluli.
- Lichunkhu le**Akhawunti** lelinalo:
  - **Mina** -- likhasi lakho lomuntfu (kuphela uma ungene)
  - **Kubonakala** -- shintja phakathi kwe**Mode Yekukhanya** ne**Mode Lemnyama**
  - **Iphothali Yebalawuli** -- ivela kuphela uma unemvume yekulawula kulebandla lakho; ivula B1 Admin ngetabhu lelisha
  - **Faka I-App** -- ivula [imiyalelo yekufaka](./installing-pwa.md) ku`/mobile/install` (iyafihleka nase i-app sewakhiwe)
- **Phuma**, noma inkinobho **Ngena** uma ungakangeni
- Libito lebandla lakho nexhumanisi lenkhulumo yemfihlo

## Ibha Yesihloko

Esikrinini sefoni, ibha lelicolo ngaphezulu kwayo yonkhe imisebenzi likhombisa:

- Logo lebandla lakho (noma libito lalo, uma lebandla lingakalayisi logo) ekhasini lekuqala nakumakhasi lamakhulu, noma umcibisholo wekuya emuva uma uvule sikrini lesinemininingwane. Sihloko sesikrini sivela ngaphezulu kwelikhasi lalo.
- Sithombe sesivakashi lesikhombisa tilaleliso netindzaba, nalapho kukhona timphawu letingakafundwa -- bona [Tindzaba Netilaleliso](#notifications-and-messages) lapha ngaphansi
- **Sithombe sakho**, lesivula iphrofayili yakho ku`/mobile/profileEdit` -- bona [Kuhlela Iphrofayili Yakho](./editing-your-profile.md)

Sithombe sesivakashi nesithombe sakho sivela kuphela uma ungene.

## Tindzaba Netilaleliso

Kucofa sithombe sesivakashi kuvula iphaneli lenemacembu lamabili:

- **Tilaleliso** -- tinkhulumiso letimfihlo lesetulu, nexhumanisi **Umlaleli lomusha** kutsi uqale lenye
- **Tindzaba** -- tindzaba letisetulu, nelembulelo **Lelisha** kulezo longakafundwa. Cofa indzaba ukuze uye emaqembini, ku-luhlelo, noma kuloxoxo lolutsatse.

Lilungu ngalinye limatsamo likhombisa kutsi kangaki kunetintfo letingakafundwa. Cofa **Bona tonkhe** ngaphansi kuze uvule ibhokisi lakho lonkhe lemilayeto ku`/mobile/notifications`.

## Emakhasi Lanemacembu

Emakhasi lemininingwane -- liqembu, luhlelo, Mina, nemakhasi eTinhlelo neKuniketela -- ahlelwe njengekhasi linye lemacembu esikhundleni semathebhu. Ilungu ngalinye likhombisa kubukwa kwesikhashana, nexhumanisi ekhanda lelungu (njenge**Yonkhe emalungu**, **Tonkhe tehlakalo**, noma **Ngalokuphelele kwemkhonzo**) livula luhlu lonkhe. Ixhumanisi **Emuva ku** ngaphezulu kwaleso sikrini ibuyisela kulelikhasi lovele usuka kulo.

## Ikhasi Lami

**Mina** (`/mobile/me`) yindzawo yakho yemuntfu. Likhombisa libito lakho nesithombe sakho nemankinobho **Hlela Iphrofayili** ne**Tilungiselelo** ([tilungiselelo tetitatiso](./notification-preferences.md)), kulandzelwe kutsi yini lesondzele kuwe -- tindzawo tekukhonta, tibhalisiso temhlangano, netehlakalo temqembu -- kulandzelwe ngemndeni wakho, emaqembu akho, [kuniketela](../giving/index.md) kulomnyaka, Tifomo tosebentise, umlandvo wakho wekubakhona, [tibhalisiso](../events/my-registrations.md) takho, netatiso netilaleliso letisanda kufika. Bona [Ikhasi Lami](./me-page.md) kutsi ufunde kabanti.

Uma ungakangeni, ikhasi Lami likhombisa inkinobho **Ngena** esikhundleni salo.

## Kufaka Esikrinini Sakho Lesikhaya

Lilunga lamalunga liyi-Progressive Web App. Vakashela `/mobile/install` (noma khetsa **Faka I-App** ekhasini le**Ngaphezulu**) kutsi utfole imiyalelo lesitfunti sesitsatfu semshini wakho. Uma sesifakiwe, siyavula sigcwele sikrini kusukela esikrinini sakho lesikhaya, ngaphandle kwesiphequluli. Bona [Kufaka Njenge-App (PWA)](./installing-pwa.md).

## Liwebhu Lomphakatsi Lebandla Lakho

Ngaphandle kwelilunga lamalunga, liwebhu lomphakatsi lelibandla lakho linembhalo yayo lesiphezulu nexhumanisi labalawuli balo lababekile -- emakhasi njenge[tinkulumo](../content/sermons.md), [iBhayibheli](../content/bible.md), [kusakaza ngalokuphilako](../content/live-streaming.md), nelucwaningo lwemaqembu lomphakatsi. Esikrinini sefoni, lamaxhumanisi atfolakala ngaphansi kwesithombe se-hamburger ngaphezulu ngesandla lesitfunti kwembhalo.

:::info
Ematfuba nemathuluzi lobonako ayahluka ngebandla. Balawuli balawula tindzawo lebonakala emalungeni nge-B1 Admin, kutsi uma ungatfoli sici lecachazwe lapha, lebandla lakho lingakavuli.
:::
