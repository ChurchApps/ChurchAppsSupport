# Kufakwa Kwenani Lebantfu & Kutfutfuka

<div class="article-intro">

Inani lebantfu livumela kurekhoda inombolo lelula yakho yekuhamba -- ye-sevisi, sikhatsi sesevisi, noma liqembu -- ngaphandle kwekuhlola lutsini lwemalunga ngamagama. Sebentisa lokhu uma udzinga nje kutsi "bangaki labebekhona," bese uhlanganisa nalo Umbiko Wekutfutfuka Kwenani Lebantfu kutsi ulandzele inombolo leyo ngesikhatsi.

</div>

<div class="prereqs">
<h4>Ngaphambi Kwekucala</h4>

- Emabandla akho, tinkhonzo, nemasikhatsi tetinkhonzo kufanele kube sekumisiwe. Bona [Kusetfwa Kwekuhambela](setup.md).
- Kufakwa kwenani lebantfu kudinga imvume ye-**Attendance &gt; Edit**; kubuka umbiko wekutfutfuka kudinga **Attendance &gt; View**. Bona [Tindzima Netimvume](../settings/roles-permissions.md).

</div>

:::info
Inani lebantfu yindlela yekuhamba yenani lephelele kuphela, ehlukile ku-[Kurekhoda Kuhamba](recording-attendance.md). Uma udzinga kwati **ngubani** lohambile -- njengekutsi ulandzele labo labangabuyanga -- qhubeka usebentisa kuhamba lokuhlanganyelwe ngemagama kuma-Sessions eliqembu. Inani lebantfu ligcina inombolo kuphela.
:::

## Kurekhoda Inani Lebantfu

1. Vula **B1 Admin**, vula [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ibha yekufuna lesenhla kwesobunxele), nweta **People**, bese uchofoza **Attendance**.
2. Chofoza **Faka inani lebantfu** ekholomu yesobunxele.
3. Gcwalisa lifomu:
   - **Sevisi** *(kuyadingeka)*
   - **Sikhatsi Sesevisi** -- shiya kungenwa kuze urekhode inani lephelele kuwo wonkhe emasikhatsi etinkhonzo
   - **Liqembu** -- lokukhetsa; kuphela emaqembu lanekuhambela kuvuliwe lawalulwa. Shiya kungenwa uma kungesiqembu, Akukho liqembu (sevisi yonkhe).
   - **Lilanga**
   - **Inani Lebantfu** -- inombolo yephelele yebantfu lebakhona
4. Chofoza **Gcina**.

Ithebula **Inani Lebantfu Lelisanda** eceleni kwelifomu libala tincwadzi letitsatfu lakugcina nelilanga, sevisi, sikhatsi sesevisi, liqembu, nenani. Chofoza umugca kutsi uwulayishe kulifomu uma udzinga kulungisa noma kususa.

## Umbiko Wekutfutfuka Kwenani Lebantfu

1. Kusuka ekhasini lefanako le-**Attendance**, chofoza **All years** ekholomu yesobunxele, bese ukhetsa ithebhu **Headcount Trend**.
2. Sebentisa tihlungi **Campus**, **Service**, **Service Time**, ne-**Group** kuncane umbiko.

Umbiko ukhombisa tinani tebantfu letirekhodwe letihlanganisiwe ngeviki, njengetchati yemugca nethebula -- lendlela yemibiko lefanana naleyo lesetjentiswa ngama-[Attendance Trend ne-Group Attendance tabs](tracking-attendance.md). Tinani tebantfu letifakwe ngeviki lamanje titfola futsi ngaphansi kwe-**Headcounts this week** ekhasini lelikhulu le-Attendance.
