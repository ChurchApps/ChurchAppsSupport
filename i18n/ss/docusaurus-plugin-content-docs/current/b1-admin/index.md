# Sibuko Se-B1 Admin

<div class="article-intro">

B1 Admin sibhodi sakho sekuphatsa libandla. Siniketa emathulusi ekuphatsa yonkhe indzawo yemsebenti welibandla lakho -- kusukela kuluhlu lwemalunga neminikelo kuya ekwakhiweni kwewebhusayithi nekusakata bukhoma -- konkhe endzaweni yinye.

</div>

## Kucala

1. Vula i-browser yakho bese uya ku [admin.b1.church](https://admin.b1.church)
2. Ngena ngeligama lakho lekusebentisa nelifasikhodi
3. Utawufika ku **Dashboard**, leniketa simo lesibonisa live lelibandla lakho kanye **netento letisheshako** temisebenti lejwayelekile njengekwengeta bantfu, kudala emacembu, kubhala phasi iminikelo, netinye

:::tip
Musha ku-B1 Admin? Cala nge-[Introduction](./introduction.md) yekubona ividiyo lechaza konkhe, bese uvakashela ku-[Settings](./settings/index.md) kucondzisa imininingwane yelibandla lakho futsi umeme ticu takho.
:::

## Tintfo Letibalulekile

- **[Bantfu](./people/index.md)** - Phatsa luhlu lwemalunga elibandla lakho, wengete emalunga, uhlele imininingwane ngebunyenti, ulandzelele imindeni
- **[Emacembu](./groups/index.md)** - Dala uhlele emacembu elibandla ngesicelo sekungena nekuphatsa emalunga
- **[Kubakhona](./attendance/index.md)** - Setapisha likhampasi, tikhatsi tenkhonzo, futsi ulandzelele kubakhona
- **[Iminikelo](./donations/index.md)** - Bhala phasi imininikelo ngetimali letahlukene, uphatse tikhwama, ukhicite tincwadzi temininikelo
- **[Kukhonta](./serving/index.md)** - Hlela bavolontiya, udale tinhlelo tenkhonzo, uphatse imisebenti, futsi ushukumise bantfu ngetinyatselo tenchubo yemsebenti
- **[Emafomu](./forms/index.md)** - Yakha emafomu lakhetsiwe ekubhalisa nekucoca imininingwane
- **[Emabhikho](./reports/index.md)** - Buka emabhikho ekutalwa, ekubakhona, neminikelo
- **[Iwebhusayithi](./website/index.md)** - Yakha uphatse iwebhusayithi yelibandla lakho ngetitayela letikhetsiwe tekuhamba
- **[Tintshumayelo](./sermons/index.md)** - Phatsa layibrari yakho yetintshumayelo nekusakata bukhoma
- **[Emakhalendari](./calendars/index.md)** - Dala emakhalendari lakhetsiwe, uphatse kubhukwa kwendlu/situlo, futsi ubuke sikhatsi lesikhona
- **[Settings](./settings/index.md)** - Condzisa imininingwane yelibandla, tikhundla, imvumo, nemasimu lakhetsiwe emuntfu

:::info
Chofoza sithombe semfundo (?) lesisesitulwini sesekudla sangenhla saso sonkhe likhasi kutfola lusito nemibhalo ngekushesha.
:::

Kulusito, thumela imeyili ku [support@churchapps.org](mailto:support@churchapps.org).
