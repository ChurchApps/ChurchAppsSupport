# Uhlu Lwetinkhumbulo Temshado

<div class="article-intro">

Ufuna uhlu lwabo bonkhe labanemshado ngenyanga leniketiwe — ngemagazini yesonto, emakhadi, noma timemezelo? Kusesha kwaBantfu kukuvumela kuhlunga ngelikhalenda le-**Anniversary Month** futsi kutibonisa emadethi ngekhatsi kemiphumela.

</div>

<div class="prereqs">
<h4>Ngaphambi Kokuqala</h4>

- Qinisekisa kutsi emadethi etemshado afakwe kuphrofayili yalomunye nalomunye umuntfu. Bona [Kungeta Bantfu](../people/adding-people.md) kuze uthole imininingwane.
- Udzinga kuba nemvume yekubona Bantfu. Bona [Tindzima Netimvume](../settings/roles-permissions.md).

</div>

## Kutfola Uhlu Lwetemshado Ngenyanga

1. Vula [Umenyu we-Jump](../introduction.md#getting-around-with-the-jump-menu) (indzawo yekusesha lapho ekhoneni lokuphezulu lesobunxele kwe-B1 Admin), khulisa **People**, bese ucindzetela **People**.
2. Ngaphansi kwebhokisi lekusesha, cindzetela **Advanced**.
3. Khulisa sigaba **Demographics** bese uhlola **Anniversary Month**, bese ukhetsa inyanga.
4. Gijima kusesha — bonkhe labanemshado kulelo nyanga batawubonakala emiphumelweni.
5. Kuze ubone emadethi, shintsha **View as** ibe **Table**, bese ucindzetela sithonjana **Select columns** esihlokweni sekhasi, bese uvula ikholomu **Anniversary**. Sebenta **Export** kuze ulayishe uhlu njengesipredishithi uma ufuna kuhlela noma kushicilela.

## Kusebenta Lokujwayelekile

- **Timemezelo temasonto** -- Gijima uhlu lwalenyanga bese ufaka tetemshado etimemezelweni takho noma temagazini yesonto.
- **Emakhadi etemshado** -- Ekisa uhlu lwalenyanga bese uwunika ilungu leqembu lakho lekubhala emakhadi.
- **Tinhlanhla tetikhumbuzo letikhulu** -- Hlanganisa nesihlungi se-**Years Married** kuze utfole tikhumbuzo letikhulu temshado.

:::tip
Gijima lokhu ekuqaleni kwenyanga ngalinye kuze unesikhatsi sekulungiselela emakhadi noma timemezelo ngaphambi kokuba kufike tikhumbuzo temshado.
:::

:::info
Tedatha letemshado itsatfwa kusimo setemshado kuphrofayili yalomunye nalomunye umuntfu. Uma kukhona lomunye longekho, kudzingeka nje kutsi kwengetwe idethi kuphrofayili yakhe. Bona [Kungeta Bantfu](../people/adding-people.md).
:::

## Bona Futsi

Uma ufuna tetinsuku tekutalwa nato ngesikhatsi lesifanako, bona [Tinhlu Tetinsuku Tekutalwa Nata Temshado](./birthday-report.md) kuze uhlanganise tonkhe tetinhlobo kusesha linye.
