# Klasės televizoriaus prijungimas prie jūsų B1 Admin pamokų

<div class="article-intro">

Klasės televizorių galite prijungti prie savo B1 Admin pamokų naudodami **FreePlay**, nemokamą ChurchApps televizijos programėlę bažnyčioms. Prijungus televizorius rodys pamokų turinį, kurį suplanavote B1 Admin, todėl jūsų mokytojai galės jį naudoti tiesiai klasės ekrane.

</div>

<div class="prereqs">
<h4>Prieš pradedant</h4>

- Suplanuokite bent vieną pamoką B1 Admin (žr. [Pamokų planavimas](./scheduling-lessons.md))
- Įdiekite **FreePlay** televizoriuje arba „Fire Stick“ įrenginyje, kurį norite naudoti

</div>

## 1 žingsnis — Įdiekite FreePlay savo televizoriuje

Įdiekite **FreePlay** programėlę savo klasės ekrane:

- **Amazon Fire Stick / Fire TV**: „Amazon Appstore“ ieškokite **FreePlay**
- **Android TV / Google TV**: „Google Play“ parduotuvėje ieškokite **FreePlay**
- **Apple TV**: „App Store“ ieškokite **FreePlay**

Visas sąrankos instrukcijas rasite [FreePlay pradžios vadove](/docs/freeplay/getting-started/).

## 2 žingsnis — Prijunkite B1.church kaip turinio teikėją

1. Televizoriuje atidarykite **FreePlay** programėlę
2. Eikite į **Turinio teikėjų** ekraną (šoninėje juostoje pasirinkite **Teikėjų** piktogramą)
3. Pasiekiamų teikėjų sąraše raskite ir pasirinkite **B1.church**
4. Vykdykite ekrane pateikiamas instrukcijas ir prisijunkite naudodami savo B1 bažnyčios prisijungimo duomenis
5. Kai prisijungimas pavyks, FreePlay parodys **Prisijungta!**

Prisijungus B1.church atsiras jūsų FreePlay šoninėje juostoje. FreePlay atsisiųs pamokų turinį, kurį suplanavote B1 Admin, kad jūsų mokytojai galėtų jį tiesiogiai leisti klasės televizoriuje.

:::tip
Prisijungus mokytojai gali naudoti televizoriaus nuotolinio valdymo pultelį, kad pereitų per vaizdo įrašus ir skaidres savo tempu, kaip vyksta pamoka. Papildomos sąrankos ar USB laikmenų nereikia.
:::

:::info
Išsamius teikėjo autentifikavimo veiksmus (QR kodas, prisijungimas per formą ir pan.) rasite skyriuje [Prisijungimas prie teikėjų](/docs/freeplay/content-providers/connecting-providers).
:::
