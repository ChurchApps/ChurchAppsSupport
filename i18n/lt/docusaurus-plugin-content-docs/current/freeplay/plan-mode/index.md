# Plan Mode

<div class="article-intro">

Plan Mode povezuje vaš televizor su bažnyčios tarnystės planu. Užuot rodęs turinį pagal klasės tvarkaraštį, jis seka planą, kurį sudaro bažnyčios vadovybė B1 Admin programoje. Tai ideali galimybė, kai norite, kad televizorius rodytų tiksliai tai, kas numatyta einamosios savaitės plane.

</div>

## Kuo skiriasi nuo kitų režimų

- **[Tvarkaraščio režimas](../scheduled-mode/)** paleidžia grojaraščius iš FreePlay Admin kalendoriaus nustatytu laiku, be to, kad kas nors paspaustų Start
- **Plano režimas** įkelia turinį, susijusį su plano tipu, kuris gali apimti pamokas, tiekėjų pristatymus, papildinius ir kitą mediją, surikiuotą pagal pasirinktą tvarką

Plano režimas ypač naudingas, kai jūsų tarnystės plane yra įvairių šaltinių turinio, sudėto į vieną seką.

:::tip
Norite, kad dabartinis planas paleistų automatiškai nustatytu laiku? FreePlay Admin programoje pridėkite kalendoriaus įrašą ir skiltyje **Service plans** pasirinkite plano tipą. Žr. [Kalendoriaus planavimas](../scheduled-mode/scheduling-the-calendar).
:::

## Kaip tai veikia

1. Televizoriuje atidarykite **Settings** > **Pair to a calendar**, kad būtų rodomas susiejimo kodas
2. Administratorius įveda šį kodą programoje **B1 Admin** ir skiltyje **Show Plans For** pasirenka plano tipą
3. Susiejus, FreePlay įkelia dabartinį planą ir atsisiunčia visą su juo susijusią mediją
4. Paspauskite **Start Plan**, kad pradėtumėte atkūrimą

Televizorius lieka susietas su plano tipu. Kiekvieną savaitę jis automatiškai paima naujausią planą ir jo turinį.
