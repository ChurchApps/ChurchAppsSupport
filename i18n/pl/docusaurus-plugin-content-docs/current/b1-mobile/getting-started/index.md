# Pierwsze kroki

:::danger Aplikacja B1 Mobile jest wycofywana
Natywna aplikacja B1 Mobile została zastąpiona [progresywną aplikacją internetową (PWA) B1.church](../../b1-church/getting-started/installing-pwa.md). Nowi użytkownicy powinni zainstalować PWA z dowolnej strony pod adresem `https://yourchurchname.b1.church`, zamiast pobierać B1 Mobile ze App Store lub Google Play.
:::

<div class="article-intro">

Rozpoczęcie pracy z B1 Mobile zajmuje zaledwie kilka minut. Pobierz aplikację, zaloguj się na swoje konto ChurchApps, wybierz swój kościół i możesz zaczynać.

</div>

## Szybki start

1. **Pobierz** aplikację z [App Store](https://apps.apple.com) (iOS) lub [Google Play Store](https://play.google.com) (Android). Wyszukaj hasło „B1.church”.
2. **Zaloguj się** istniejącym kontem ChurchApps -- tym samym adresem e-mail i hasłem, których używasz na B1.church. Jeśli nie masz jeszcze konta, dotknij **Zarejestruj się**, aby je utworzyć.
3. **Wybierz swój kościół**, wyszukując go po nazwie. Wpisz co najmniej 3 znaki, aby zobaczyć wyniki.
4. **Odkryj pulpit** -- spersonalizowany ekran główny pokazuje szybkie linki do funkcji oferowanych przez Twój kościół.

To wszystko. Po wybraniu kościoła aplikacja wczyta jego branding, linki nawigacyjne i treści. Możesz zacząć korzystać z grup, darowizn, zameldowania i wszystkiego, co Twój kościół udostępnił.
