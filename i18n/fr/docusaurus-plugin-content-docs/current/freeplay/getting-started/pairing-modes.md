# Choisir un mode de jumelage

<div class="article-intro">

FreePlay propose deux modes de jumelage pour connecter votre TV à votre église, ainsi que la possibilité de parcourir directement les fournisseurs de contenu. L'écran **Sélectionner le mode de jumelage** présente ces options sous forme de grandes cartes que vous pouvez parcourir avec votre télécommande TV.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Installez FreePlay et lancez-le pour la première fois -- voir [Bien démarrer](./index.md)
- Ayez votre télécommande TV à portée de main pour la navigation

</div>

## Jumeler à une salle de classe

Choisissez **Jumeler à une salle de classe** lorsque vous souhaitez qu'une TV spécifique affiche toujours la leçon programmée pour une salle particulière. C'est la meilleure option pour les salles de classe de ministère pour enfants où les leçons sont attribuées selon un calendrier hebdomadaire.

**Comment ça marche :** vous recherchez votre église par nom, choisissez une salle de classe, et FreePlay récupère automatiquement la leçon programmée pour cette salle aujourd'hui. Chaque dimanche matin, il vous suffit d'allumer la TV et la bonne leçon est prête.

**Idéal pour :** les TV de salles de classe dédiées qui doivent toujours afficher le contenu programmé pour cette salle.

:::tip
Configurez vos salles de classe sur [freeplay.church](https://freeplay.church) avant de jumeler votre TV. Cela garantit que vos salles apparaissent lorsque vous recherchez votre église.
:::

## Jumeler à un plan

Choisissez **Jumeler à un plan** lorsque vous souhaitez suivre un plan de service d'église. Ce mode génère un code de jumelage que vous saisissez dans **B1 Admin** pour lier la TV à un type de plan spécifique. La TV télécharge et lit ensuite le contenu attribué au plan actuel.

**Comment ça marche :** FreePlay affiche à l'écran un code de jumelage et un code QR. Un administrateur ouvre la page liée dans **B1 Admin**, saisit le code, et choisit le type de plan que l'écran doit suivre dans une liste déroulante **Afficher les plans pour**. Une fois approuvé, la TV charge automatiquement le contenu du plan actuel.

**Idéal pour :** les TV qui affichent du contenu lié à votre plan de service hebdomadaire, comme les paroles de louange ou les diapositives d'annonces.

## Fournisseurs de contenu

Si vous n'avez pas besoin de jumeler avec une salle de classe ou un plan, vous pouvez parcourir directement les fournisseurs de contenu. Des fournisseurs comme [Lessons.church](../../lessons-church/) et Bible Project proposent du contenu que vous pouvez télécharger et lire à la demande.

**Idéal pour :** les TV où les bénévoles choisissent manuellement quoi diffuser chaque semaine, ou lorsque vous souhaitez explorer le contenu disponible.

:::info
Vous pouvez accéder à l'écran **Fournisseurs** à tout moment depuis la barre latérale en bas de la navigation. Vous n'avez pas besoin d'utiliser un mode de jumelage pour parcourir et lire du contenu.
:::
