# Mode programmé {#scheduled-mode}

<div class="article-intro">

Le mode programmé permet à un téléviseur FreePlay de fonctionner de lui-même. Vous créez des listes de lecture et les placez dans un calendrier dans **FreePlay Admin**, à l'adresse [admin.freeplay.church](https://admin.freeplay.church). Chaque téléviseur jumelé à ce calendrier télécharge la semaine à venir et diffuse ce qui est programmé, à l'heure prévue, sans que personne n'appuie sur Démarrer. Comme les fichiers sont déjà téléchargés, la lecture se poursuit même si le Wi-Fi est coupé.

</div>

:::tip
FreePlay Admin utilise votre identifiant ChurchApps, le même que pour B1 Admin. Il n'y a pas de compte distinct à créer.
:::

## Fonctionnement global {#how-it-fits-together}

FreePlay Admin comporte quatre pages principales, listées en haut du site :

- **[Écrans](./managing-screens)** - Les téléviseurs que vous avez jumelés, leur état et les **groupes d'écrans** auxquels ils appartiennent. Les écrans d'un même groupe partagent un calendrier et une boucle par défaut
- **[Listes de lecture](./building-playlists)** - Des boucles d'images et de vidéos que vous choisissez parmi vos fournisseurs de contenu
- **[Calendrier](./scheduling-the-calendar)** - Ce que chaque groupe d'écrans diffuse, et à quel moment
- **[Fournisseurs](./building-playlists#connecting-providers)** - Les sources de contenu dont vos listes de lecture se servent. Vous connectez chacune une seule fois pour toute l'église

Lorsque rien n'est programmé, les écrans d'un groupe diffusent sa **boucle par défaut**. Si le groupe n'a pas de boucle par défaut, les écrans restent noirs.

## Différence avec le mode plan {#how-it-differs-from-plan-mode}

- **[Mode plan](../plan-mode/)** suit un type de plan de service de B1 Admin. Quelqu'un appuie sur **Démarrer le plan** sur le téléviseur, et la leçon se lance à ce moment-là
- **Le mode programmé** suit un calendrier. Le contenu démarre et s'arrête aux heures que vous définissez, ce qui le rend bien adapté à la signalétique du hall, aux boucles d'annonces et aux salles de classe où la leçon doit être affichée avant l'arrivée de quiconque

Une entrée du calendrier peut aussi diffuser un plan de service. Choisissez le type de plan sous **Plans de service** lorsque vous ajoutez une programmation, et l'écran diffusera le plan en vigueur dans B1 Admin cette semaine-là. Cela inclut les leçons Go Curriculum, même celles que vous avez personnalisées dans le plan. L'écran utilise l'identifiant Go Curriculum lié au ministère du type de plan dans B1 Admin, ou la connexion Go Curriculum de l'église si le ministère n'en a pas.

## Premiers pas {#getting-started}

Tant que vous n'avez pas effectué chacune de ces étapes, la page **Écrans** affiche une liste de contrôle **Premiers pas** avec un lien pour chaque étape :

1. **Connecter un fournisseur** - Reliez Dropbox, OneDrive, Lessons.church ou une autre source sur la page **Fournisseurs**
2. **Créer une liste de lecture** - Choisissez des images et des vidéos chez un fournisseur
3. **La placer dans le calendrier** - Choisissez ce qui doit être diffusé et quand, ou définissez une boucle par défaut pour le groupe
4. **Jumeler un écran** - Saisissez le code de quatre lettres affiché sur le téléviseur

Cliquez sur **Masquer** pour fermer la liste de contrôle.

:::tip
Appuyez sur **Ctrl+K** (**⌘K** sur Mac), ou cliquez sur la zone de recherche de l'en-tête, pour ouvrir la palette de commandes. Vous pouvez y accéder à n'importe quelle page ou lancer une action comme **Jumeler un écran**, **Ajouter une liste de lecture** ou **Ajouter une programmation**.
:::
