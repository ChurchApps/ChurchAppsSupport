# Mode planifié

<div class="article-intro">

Le mode planifié permet à un téléviseur FreePlay de fonctionner tout seul. Vous créez des listes de lecture et les placez sur un calendrier dans **FreePlay Admin** à l'adresse [admin.freeplay.church](https://admin.freeplay.church). Chaque téléviseur associé à ce calendrier télécharge la semaine à venir et lit ce qui est prévu, à l'heure dite, sans que personne n'appuie sur Démarrer. Comme les fichiers sont déjà téléchargés, la lecture continue même si le Wi-Fi est coupé.

</div>

:::tip
FreePlay Admin utilise votre connexion ChurchApps, la même que celle que vous utilisez pour B1 Admin. Il n'y a aucun compte distinct à créer.
:::

## Fonctionnement d'ensemble

FreePlay Admin comporte quatre pages principales, listées en haut du site :

- **[Écrans](./managing-screens)** - Les téléviseurs que vous avez associés, leur état et les **groupes d'écrans** auxquels ils appartiennent. Les écrans d'un même groupe partagent un calendrier et une boucle par défaut
- **[Listes de lecture](./building-playlists)** - Boucles d'images et de vidéos que vous choisissez parmi vos fournisseurs de contenu
- **[Calendrier](./scheduling-the-calendar)** - Ce que chaque groupe d'écrans lit, et à quel moment
- **[Fournisseurs](./building-playlists#connecting-providers)** - Les sources de contenu dont vos listes de lecture sont extraites. Vous connectez chacune une seule fois pour toute l'église

Lorsque rien n'est planifié, les écrans d'un groupe lisent sa **boucle par défaut**. Si le groupe n'a pas de boucle par défaut, les écrans s'éteignent.

## Différence avec le mode plan

- **[Mode plan](../plan-mode/)** suit un type de plan de service de B1 Admin. Quelqu'un appuie sur **Démarrer le plan** sur le téléviseur, et la leçon se lance à ce moment-là
- **Le mode planifié** suit un calendrier. Le contenu démarre et s'arrête aux heures que vous définissez, ce qui convient bien à l'affichage dans le hall, aux boucles d'annonces et aux salles de classe où la leçon doit être à l'écran avant l'arrivée de quiconque

Une entrée du calendrier peut aussi lire un plan de service. Choisissez le type de plan sous **Plans de service** lorsque vous ajoutez un planning, et l'écran lit le plan en cours dans B1 Admin cette semaine-là.

## Démarrer

Tant que vous n'avez pas effectué chacune de ces étapes, la page **Écrans** affiche une liste de contrôle **Démarrer** avec un lien pour chaque étape :

1. **Connecter un fournisseur** - Reliez Dropbox, OneDrive, Lessons.church ou une autre source sur la page **Fournisseurs**
2. **Créer une liste de lecture** - Choisissez des images et des vidéos chez un fournisseur
3. **Placer sur le calendrier** - Choisissez ce qui est lu et quand, ou définissez une boucle par défaut pour le groupe
4. **Associer un écran** - Saisissez le code à quatre lettres affiché sur le téléviseur

Cliquez sur **Masquer** pour fermer la liste de contrôle.

:::tip
Appuyez sur **Ctrl+K** (**⌘K** sur Mac), ou cliquez sur la zone de recherche de l'en-tête, pour ouvrir la palette de commandes. Vous pouvez y accéder à n'importe quelle page ou lancer une action comme **Associer un écran**, **Ajouter une liste de lecture** ou **Ajouter un planning**.
:::
