# Connecter les fournisseurs et créer des listes de lecture

<div class="article-intro">

Une liste de lecture est une boucle d'images et de vidéos que vous placez dans le calendrier. Dans FreePlay Admin, vous connectez vos fournisseurs de contenu une seule fois pour toute l'église. Ensuite, vous créez des listes de lecture en choisissant des fichiers parmi ces fournisseurs.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Connectez-vous à FreePlay Admin sur [admin.freeplay.church](https://admin.freeplay.church)
- Ayez les identifiants de tout compte fournisseur que vous souhaitez lier, par exemple Dropbox ou OneDrive

</div>

## Connecter les fournisseurs {#connecting-providers}

La page **Fournisseurs** répertorie vos sources de contenu dans deux sections :

- **Connectés** -- Fournisseurs que vous pouvez utiliser immédiatement. Les fournisseurs publics qui ne nécessitent pas de connexion, comme Lessons.church et Bible Project, figurent toujours ici avec la mention **Public · aucune connexion requise**. Les comptes liés affichent **Compte lié** ainsi que la date d'expiration de la liaison.
- **Disponibles** -- Fournisseurs qui nécessitent une connexion avant de pouvoir être utilisés.

Pour connecter un fournisseur :

1. Allez dans **Fournisseurs**.
2. Repérez le fournisseur dans **Disponibles** et cliquez sur **Connecter**.
3. Connectez-vous à votre compte auprès de ce fournisseur :
   - Certains fournisseurs, comme Dropbox, Google Drive et OneDrive, ouvrent une fenêtre de connexion. Si rien n'apparaît, autorisez les fenêtres contextuelles pour admin.freeplay.church.
   - D'autres fournisseurs affichent un lien et un code. Visitez le lien, saisissez le code et approuvez l'accès. La boîte de dialogue se met à jour toute seule une fois l'opération terminée.
4. Lorsque vous voyez **Compte lié avec succès !**, le fournisseur passe dans **Connectés**.

Les fournisseurs connectés proposent trois actions :

- **Parcourir** -- Naviguer dans les dossiers du fournisseur
- **Actualiser** -- Renouveler la connexion au fournisseur
- **Délier** -- Déconnecter le compte

:::info
Les connexions aux fournisseurs dans FreePlay Admin appartiennent à toute l'église, et non à une personne ou à une seule télévision. Les écrans planifiés obtiennent leurs fichiers via ces connexions : vous n'avez donc pas à vous connecter à chaque fournisseur sur chaque télévision.
:::

**FreeShow** figure dans la liste avec la mention **Sur le réseau de votre église · chaque télévision le trouve elle-même**. Il n'y a rien à connecter pour celui-ci dans FreePlay Admin.

## La page Listes de lecture

La page **Listes de lecture** répertorie chaque liste de lecture avec son nombre d'éléments, sa durée totale, son lieu d'utilisation (**Boucle par défaut** pour un groupe, ou le nombre de planifications) et sa date de dernière mise à jour. Chaque ligne propose ces actions :

- **Présenter** -- Lire la liste de lecture en plein écran dans votre navigateur
- **Modifier** -- Ouvrir l'éditeur de liste de lecture
- **Dupliquer** -- Créer une copie nommée « (copie) »

## Créer une liste de lecture

1. Allez dans **Listes de lecture** et cliquez sur **Ajouter une liste de lecture**.
2. Saisissez un **Nom**, par exemple « Boucle d'accueil ».
3. Cliquez sur **Ajouter une liste de lecture**. L'éditeur de liste de lecture s'ouvre.

## Ajouter des éléments

L'éditeur de liste de lecture affiche les **Éléments** de votre liste à gauche et **Ajouter depuis un fournisseur** à droite.

1. À droite, choisissez un onglet de fournisseur. Pour ajouter une autre source, cliquez sur **Connecter un autre**, ce qui ouvre la page **Fournisseurs**.
2. Cliquez sur les dossiers pour y entrer. Utilisez le fil d'Ariane pour remonter.
3. Cliquez sur un fichier pour l'ajouter à la fin de la liste de lecture. Les fichiers déjà présents dans la liste sont marqués comme sélectionnés.
4. Pour ajouter d'un seul coup tout le contenu du dossier actuel, cliquez sur **Tout ajouter**. Le bouton indique le nombre de fichiers qui ne sont pas encore dans la liste.
5. Cliquez sur **Enregistrer** en haut de l'éditeur.

:::warning
Les modifications ne sont enregistrées qu'après un clic sur **Enregistrer**. Cliquez sur **Annuler** pour quitter sans enregistrer.
:::

## Organiser les éléments

Dans la liste **Éléments** à gauche :

- **Réordonner** -- Faites glisser un élément par sa poignée à gauche
- **Durée d'affichage des images** -- Les images restent affichées 10 secondes par défaut. Modifiez le nombre de secondes à côté d'une image
- **Vidéos** -- Les vidéos affichent **Lecture jusqu'à la fin** et durent leur longueur complète
- **Retirer** -- Supprimer un élément de la liste de lecture

Le résumé en haut indique le nombre d'éléments et la durée totale de la liste de lecture.

## Renommer, dupliquer et supprimer

Le panneau à gauche de l'éditeur indique où la liste de lecture est utilisée. Il propose aussi ces actions :

- **Présenter** -- Lire la liste de lecture dans votre navigateur
- **Renommer** -- Modifier le nom de la liste de lecture
- **Dupliquer** -- Créer une copie à modifier séparément
- **Supprimer** -- Retirer la liste de lecture. Les planifications qui la diffusent reviennent à la boucle par défaut du groupe

## Présenter une liste de lecture dans votre navigateur

Cliquez sur **Présenter** pour lire la liste de lecture en plein écran dans votre navigateur. C'est pratique pour prévisualiser une liste ou pour la diffuser depuis un ordinateur portable connecté à un projecteur. Déplacez la souris pour afficher la barre de commandes, puis utilisez ces touches :

| Touche | Action |
|---|---|
| **Espace** | Mettre en pause ou reprendre |
| **←** / **→** | Élément précédent ou suivant |
| **F** | Activer ou désactiver le plein écran |
| **Échap** | Quitter |
