# Connexion aux fournisseurs

<div class="article-intro">

Avant de pouvoir parcourir le contenu d'un fournisseur, vous devez vous y connecter. Certains fournisseurs exigent une authentification par code QR ou par connexion e-mail, tandis que d'autres peuvent être connectés en un seul clic.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Installez et lancez FreePlay -- voir [Bien démarrer](../getting-started/)
- Ayez votre télécommande TV à portée de main pour la navigation
- Pour les fournisseurs nécessitant une connexion, ayez vos identifiants de compte à disposition

</div>

:::tip Vous configurez B1 Admin et FreePlay ensemble ?
Notre **<a href="/guides/freeplay-b1admin" target="_blank">guide étape par étape</a>** explique comment relier B1 Admin, planifier une leçon et connecter FreePlay — le tout au même endroit. Ouvrez-le dans un nouvel onglet pour suivre les étapes.
:::

## Parcourir les fournisseurs disponibles

1. Ouvrez l'écran **Fournisseurs de contenu** depuis la barre latérale (sélectionnez l'icône **Fournisseurs** en bas)
2. Vous verrez une grille de cartes de fournisseurs, chacune affichant le logo et le nom du fournisseur
3. Les fournisseurs connectés affichent un badge vert **Connecté** sous leur nom
4. Les fournisseurs pas encore disponibles affichent une étiquette **Bientôt disponible**

## Connexion sans authentification

Certains fournisseurs ne nécessitent pas de connexion. Lorsque vous sélectionnez l'un de ces fournisseurs, FreePlay se connecte immédiatement et ouvre le navigateur de contenu. Aucun identifiant n'est nécessaire.

## Authentification par flux d'appareil (code QR)

Certains fournisseurs utilisent un flux d'appareil, semblable à la façon dont vous vous connectez aux applications de streaming sur une TV :

1. Sélectionnez la carte du fournisseur sur l'écran **Fournisseurs de contenu**
2. FreePlay affiche un code QR et une URL de vérification
3. Scannez le code QR avec votre téléphone, ou visitez l'URL affichée sur n'importe quel appareil
4. Saisissez le code utilisateur affiché sur l'écran de la TV
5. Terminez le processus de connexion sur votre téléphone ou ordinateur
6. FreePlay détecte la connexion réussie et affiche **Connecté !**
7. Le navigateur de contenu s'ouvre automatiquement

:::info
Un indicateur clignotant **En attente d'autorisation** montre que FreePlay vérifie votre connexion. Le code expire après quelques minutes, complétez donc le processus rapidement.
:::

**Go Curriculum** utilise ce même modèle de connexion par code QR -- scannez le code et connectez-vous avec votre compte gocurriculum.com pour vous connecter.

## Connexion par formulaire

D'autres fournisseurs utilisent une connexion traditionnelle par e-mail et mot de passe :

1. Sélectionnez la carte du fournisseur
2. Saisissez votre **E-mail** et **Mot de passe** à l'aide du clavier à l'écran
3. Sélectionnez le bouton **Se connecter**
4. Si vos identifiants sont corrects, FreePlay affiche **Connecté !** et ouvre le navigateur de contenu

:::tip
Utilisez le pavé directionnel de votre télécommande pour naviguer entre le champ e-mail, le champ mot de passe et le bouton de connexion. Appuyez sur **Sélectionner** sur un champ de texte pour ouvrir le clavier à l'écran.
:::

## Déconnexion d'un fournisseur

Pour vous déconnecter d'un fournisseur déjà connecté :

1. Allez à l'écran **Fournisseurs de contenu**
2. Sélectionnez la carte du fournisseur qui affiche le badge **Connecté**
3. Une invite de confirmation demande si vous souhaitez vous déconnecter
4. Choisissez **Déconnecter** pour supprimer la connexion

Après la déconnexion, le contenu du fournisseur n'apparaîtra plus dans votre barre latérale.

:::warning
La déconnexion supprime l'authentification enregistrée sur votre appareil. Vous devrez vous reconnecter si vous souhaitez vous reconnecter plus tard.
:::
