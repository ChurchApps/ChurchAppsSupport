# Parcourir et télécharger du contenu

<div class="article-intro">

Une fois que vous vous êtes connecté à un fournisseur de contenu, vous pouvez parcourir sa bibliothèque, télécharger des fichiers, et les jouer sur votre téléviseur. Le navigateur de contenu fournit une grille visuelle de dossiers et fichiers que vous naviguez avec votre télécommande TV.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Connectez-vous à au moins un fournisseur de contenu -- voir [Connexion aux fournisseurs](./connecting-providers)
- Ayez votre télécommande TV prête pour la navigation

</div>

## Le navigateur de contenu

Le navigateur de contenu affiche les éléments dans une grille à 3 colonnes de cartes. Chaque carte montre une image miniature et un titre. Il y a deux types d'éléments :

- **Dossiers** - Représentés par une image miniature ou une icône de dossier. Sélectionnez un dossier pour voir son contenu.
- **Fichiers** - Articles multimédias individuels (vidéos ou images). Les fichiers vidéo affichent une icône de lecture sur leur miniature.

L'en-tête en haut de l'écran affiche le nom du dossier actuel, ou le nom du fournisseur si vous êtes au niveau racine.

## Navigation dans les dossiers

1. Utilisez le pavé directionnel de votre télécommande pour mettre en évidence un dossier
2. Appuyez sur **Select** pour l'ouvrir
3. Le navigateur charge le contenu du dossier, qui peut être plus de dossiers ou des fichiers jouables
4. Appuyez sur **Back** sur votre télécommande pour remonter d'un niveau

Vous pouvez creuser aussi profond que la structure de contenu du fournisseur le permet. Le navigateur suit votre chemin de dossier afin que vous puissiez revenir à travers chaque niveau.

## Téléchargement et lecture de contenu

Quand vous sélectionnez un dossier qui contient des fichiers jouables (ou sélectionnez un fichier individuel), FreePlay passe à un écran de téléchargement :

1. Le titre du contenu apparaît à l'écran avec une image de couverture du dossier sélectionné
2. Une barre de progression affiche **Téléchargement de l'article X sur Y** alors que les fichiers sont enregistrés sur votre appareil
3. Une fois le téléchargement terminé, le bouton **Start** apparaît avec une icône de lecture
4. Appuyez sur **Select** pour commencer la lecture

:::tip
Le contenu téléchargé est mis en cache sur votre téléviseur. Si vous lisez le même contenu plus tard, il se charge instantanément sans retéléchargement.
:::

## Lecture du contenu du fournisseur

La lecture fonctionne de la même manière que la lecture des leçons. Utilisez ces contrôles :

- **Flèche droite** - Article suivant
- **Flèche gauche** - Article précédent
- **Select / Play-Pause** - Mettre en pause ou reprendre la vidéo
- **Flèche vers le haut** - Ouvrir le sélecteur de messages pour passer à un article spécifique
- **Back** - Quitter vers le navigateur de contenu

Quand vous quittez le lecteur, vous retournez au navigateur de contenu au niveau racine du fournisseur actuel.

:::info
Pour une référence complète de tous les contrôles du lecteur, voir [Jouer les leçons](../classroom-mode/playing-lessons).
:::

## Basculement entre fournisseurs

Les fournisseurs connectés apparaissent comme des articles sous le titre **Browse** dans la barre latérale sur la gauche. Pour basculer vers un autre fournisseur :

1. Appuyez sur la flèche **Left** sur votre télécommande pour développer la barre latérale
2. Sélectionnez le fournisseur que vous souhaitez parcourir
3. Le navigateur de contenu s'actualise avec la bibliothèque de ce fournisseur

:::warning
Si un dossier affiche « No content available », le fournisseur n'a aucun article à ce niveau. Essayez de naviguer vers un autre dossier ou revérifiez plus tard.
:::
