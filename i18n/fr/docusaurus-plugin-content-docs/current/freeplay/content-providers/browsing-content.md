# Parcourir et télécharger du contenu

<div class="article-intro">

Une fois connecté à un fournisseur de contenu, vous pouvez parcourir sa bibliothèque, télécharger des fichiers et les lire sur votre téléviseur. Le navigateur de contenu affiche une grille visuelle de dossiers et de fichiers que vous parcourez avec la télécommande du téléviseur.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Connectez-vous à au moins un fournisseur de contenu -- voir [Connexion aux fournisseurs](./connecting-providers)
- Ayez votre télécommande de téléviseur à portée de main pour la navigation

</div>

## Le navigateur de contenu

Le navigateur de contenu affiche les éléments dans une grille de cartes à 3 colonnes. Chaque carte affiche une vignette et un titre. Il existe deux types d'éléments :

- **Dossiers** - Représentés par une vignette ou une icône de dossier. Sélectionnez un dossier pour voir son contenu.
- **Fichiers** - Éléments multimédias individuels (vidéos ou images). Les fichiers vidéo affichent une icône de lecture superposée à leur vignette.

L'en-tête en haut de l'écran indique le nom du dossier actuel, ou le nom du fournisseur si vous êtes au niveau racine.

## Naviguer dans les dossiers

1. Utilisez la croix directionnelle de votre télécommande pour mettre en surbrillance un dossier
2. Appuyez sur **OK** pour l'ouvrir
3. Le navigateur charge le contenu du dossier, qui peut être d'autres dossiers ou des fichiers lisibles
4. Appuyez sur **Retour** sur votre télécommande pour remonter d'un niveau

Vous pouvez descendre aussi profondément que la structure de contenu du fournisseur le permet. Le navigateur garde en mémoire votre chemin dans les dossiers afin que vous puissiez revenir en arrière à chaque niveau.

## Parcourir Lessons.church

La bibliothèque [Lessons.church](../../lessons-church/) est organisée comme son site web. Au niveau supérieur, vous verrez deux dossiers :

- **Lessons** - Descendez par **programme**, puis **étude**, puis **leçon**. Chaque leçon liste ensuite ses **lieux**, c'est-à-dire les versions de la leçon pour une tranche d'âge ou un cadre particulier, comme Préscolaire ou Élémentaire. Sélectionnez un lieu pour ouvrir l'écran de téléchargement de cette version de la leçon
- **Compléments** - Vidéos et ressources supplémentaires, regroupées par catégorie

Appuyez sur **Retour** à n'importe quel niveau pour remonter d'une étape.

## Télécharger et lire du contenu

Lorsque vous sélectionnez un dossier contenant des fichiers lisibles (ou un fichier individuel), FreePlay affiche le titre du contenu avec une image de couverture et deux choix :

- **Télécharger** - Enregistrer tous les fichiers sur le téléviseur d'abord, afin que la lecture ne dépende pas du Wi-Fi. Une barre de progression se remplit à mesure que chaque fichier est enregistré. Une fois terminé, le bouton **Démarrer** apparaît avec une icône de lecture. Appuyez sur **OK** pour commencer la lecture
- **Diffuser** - Commencer à lire immédiatement via Internet sans enregistrer les fichiers

:::tip
Téléchargez les leçons avant le dimanche matin, pendant que le bâtiment dispose d'une bonne connexion Internet. Une fois téléchargé, le contenu se lit hors ligne, et si vous le relancez plus tard, il se charge instantanément sans être retéléchargé.
:::

## Gérer les téléchargements

Ouvrez **Paramètres** en bas de la barre latérale, puis sélectionnez **Téléchargements** pour voir tout ce qui est enregistré sur ce téléviseur :

- Sélectionnez un téléchargement pour le lire
- Mettez en surbrillance un téléchargement et sélectionnez l'icône de suppression dans son coin pour le retirer et libérer de l'espace de stockage

Si l'écran indique **Aucun téléchargement pour le moment**, rien n'a été enregistré sur ce téléviseur.

## Lire le contenu d'un fournisseur

Utilisez ces commandes pendant la lecture :

- **Flèche droite** - Élément suivant
- **Flèche gauche** - Élément précédent
- **OK / Lecture-Pause** - Mettre en pause ou reprendre la vidéo
- **Flèche haut** - Ouvrir le sélecteur de messages pour aller à un élément précis
- **Retour** - Quitter pour revenir au navigateur de contenu

Lorsque vous quittez le lecteur, vous revenez au navigateur de contenu, au niveau racine du fournisseur actuel.

:::info
Pour une référence complète de toutes les commandes du lecteur, voir [Lire le contenu](./playing-content).
:::

## Changer de fournisseur

Les fournisseurs connectés apparaissent comme des éléments sous le titre **Parcourir** dans la barre latérale à gauche. Pour passer à un autre fournisseur :

1. Appuyez sur la flèche **Gauche** de votre télécommande pour développer la barre latérale
2. Sélectionnez le fournisseur que vous voulez parcourir
3. Le navigateur de contenu se met à jour avec la bibliothèque de ce fournisseur

:::warning
Si un dossier affiche « Aucun contenu disponible », le fournisseur n'a aucun élément à ce niveau. Essayez de naviguer vers un autre dossier ou revenez plus tard.
:::
