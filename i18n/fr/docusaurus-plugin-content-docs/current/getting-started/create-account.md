# Créer votre compte

<div class="article-intro">

Pour commencer avec ChurchApps, il faut d'abord créer votre compte. Le processus ne prend que quelques minutes et vous donne accès à tous les outils ChurchApps, y compris B1 Admin, B1.church et Lessons.church.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Ayez une adresse e-mail valide prête pour la vérification du compte
- Consultez l'[aperçu de Bien démarrer](./index.md) pour comprendre ce que propose ChurchApps

</div>

## Inscription étape par étape

1. Allez sur [B1.church](https://b1.church) dans votre navigateur web.
2. Cliquez sur le bouton **S'inscrire**.
3. Saisissez votre **prénom**, **nom** et **adresse e-mail** -- ou, si votre église a activé l'authentification unique, cliquez sur **Continuer avec Google** ou **Continuer avec Microsoft** pour passer directement à l'étape 5 en utilisant votre compte existant.
4. Créez un mot de passe pour votre compte.
5. Soumettez le formulaire d'inscription.

## Confirmer votre e-mail

Après l'inscription, vous recevrez un e-mail de confirmation à l'adresse que vous avez fournie.

1. Consultez votre boîte de réception pour l'e-mail de confirmation de ChurchApps.
2. Cliquez sur le lien de confirmation dans l'e-mail.
3. Votre compte est maintenant vérifié et prêt à être utilisé.

:::tip
Si vous ne voyez pas l'e-mail de confirmation, vérifiez votre dossier spam ou courrier indésirable. L'e-mail provient de ChurchApps et peut prendre une minute ou deux pour arriver.
:::

## Configurer votre église

Après avoir confirmé votre e-mail et vous être connecté, vous aurez la possibilité de créer une nouvelle église ou de rejoindre une église existante.

**Pour créer une nouvelle église :**

1. Sélectionnez l'option pour **créer une nouvelle église**.
2. Saisissez le **nom de votre église** et les informations de base. Le formulaire d'inscription remplira automatiquement les détails de votre église si une correspondance est trouvée.
3. Terminez le processus de configuration.
4. Vous serez dirigé vers le **tableau de bord B1 Admin** où vous pourrez commencer à configurer votre église.

**Pour rejoindre une église existante :**

1. Sélectionnez l'option pour **rejoindre une église existante**.
2. Recherchez votre église par nom.
3. Demandez à rejoindre. Un administrateur de votre église devra approuver votre demande.

:::info
Si vous essayez de vous connecter avec un e-mail qui n'est pas encore enregistré, vous serez automatiquement dirigé vers le flux d'inscription afin de pouvoir créer un compte.
:::

:::info
La personne qui crée une nouvelle église se voit automatiquement attribuer le rôle **Administrateur du domaine**, qui accorde un accès complet à tous les paramètres et fonctionnalités. Vous pourrez ajouter d'autres administrateurs plus tard depuis la page **Rôles**.
:::

## Et ensuite ?

Une fois votre église configurée, consultez le guide de [Configuration initiale](./initial-setup.md) pour configurer les paramètres, l'image de marque et l'accès de l'équipe de votre église.
