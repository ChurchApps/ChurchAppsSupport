# Créer votre compte

<div class="article-intro">

Commencer avec ChurchApps commence par créer votre compte. Le processus prend seulement quelques minutes et vous donne accès à tous les outils ChurchApps, y compris B1 Admin, B1.church et Lessons.church.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Avoir une adresse e-mail valide prête pour la vérification du compte
- Consulter la [présentation Démarrage](./index.md) pour comprendre ce que ChurchApps offre

</div>

## Inscription étape par étape

1. Allez à [B1.church](https://b1.church) dans votre navigateur Web.
2. Cliquez sur le bouton **S'inscrire**.
3. Entrez votre **prénom**, **nom de famille** et **adresse e-mail** — ou, si votre église a l'authentification unique activée, cliquez sur **Continuer avec Google** ou **Continuer avec Microsoft** pour aller directement à l'étape 5 en utilisant votre compte existant.
4. Créez un mot de passe pour votre compte.
5. Soumettez le formulaire d'inscription.

:::info
Un compte ChurchApps fonctionne sur B1, Lessons.church et les autres applications ChurchApps. Si vous voyez **Vous avez déjà un compte ChurchApps. Veuillez vous connecter avec celui-ci à la place.**, cliquez sur **Connexion** et connectez-vous avec cet e-mail. Utilisez **Mot de passe oublié** si vous ne vous souvenez pas du mot de passe.
:::

## Confirmation de votre e-mail

Après l'inscription, vous recevrez un e-mail de confirmation à l'adresse que vous avez fournie.

1. Vérifiez votre boîte de réception pour l'e-mail de confirmation de ChurchApps.
2. Cliquez sur le lien de confirmation dans l'e-mail.
3. Votre compte est maintenant vérifié et prêt à être utilisé.

:::tip
Si vous ne voyez pas l'e-mail de confirmation, vérifiez votre dossier spam ou indésirable. L'e-mail provient de ChurchApps et peut prendre une minute ou deux pour arriver.
:::

## Configuration de votre église

Après avoir confirmé votre e-mail et vous être connecté, vous aurez la possibilité de créer une nouvelle église ou de rejoindre une église existante.

**Pour créer une nouvelle église :**

1. Sélectionnez l'option pour **créer une nouvelle église**.
2. Entrez le **nom de votre église** et les informations de base. Le formulaire d'inscription remplira automatiquement les détails de votre église si une correspondance est trouvée.
3. Complétez le processus de configuration.
4. Vous serez dirigé vers le **Tableau de bord**, la page d'accueil de B1 Admin, où vous pouvez commencer à configurer votre église.

**Pour rejoindre une église existante :**

1. Sélectionnez l'option pour **rejoindre une église existante**.
2. Recherchez votre église par son nom.
3. Demander à rejoindre. Un administrateur de votre église devra approuver votre demande.

:::info
Si vous essayez de vous connecter avec un e-mail qui n'est pas encore enregistré, vous serez automatiquement dirigé vers le flux d'inscription afin de pouvoir créer un compte.
:::

:::info
La personne qui crée une nouvelle église reçoit automatiquement le rôle **Domain Admin**, qui accorde un accès complet à tous les paramètres et fonctionnalités. Vous pouvez ajouter des administrateurs supplémentaires plus tard à partir de la page **Rôles**.
:::

## Quoi d'autre

Une fois que votre église est configurée, allez au guide [Configuration initiale](./initial-setup.md) pour configurer les paramètres, l'image de marque et l'accès à l'équipe de votre église.
