# Configuration initiale

<div class="article-intro">

Après avoir créé votre compte et votre église, il y a quelques étapes importantes pour configurer avant d'inviter votre équipe. Ce guide vous guide dans l'ordre de configuration recommandé afin que votre église soit prête dès le premier jour.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- [Créez votre compte](./create-account.md) et enregistrez votre église
- Ayez le logo et les ressources de marque de votre église prêts (optionnel mais recommandé)

</div>

## Étape 1 : Configurez les informations de votre église

1. Ouvrez le **menu de section** dans le coin supérieur gauche (le nom de la section avec la petite flèche) et choisissez **Paramètres**.
2. Cliquez sur **Modifier les paramètres**.
3. Entrez le **nom**, l'**adresse** et les **coordonnées** de votre église.
4. Cliquez sur **Enregistrer** pour appliquer vos modifications.

## Étape 2 : Configurez votre marque

1. À partir du **Tableau de bord**, accédez à **Site web**, puis sélectionnez **Apparence**.
2. Téléchargez le **logo** de votre église.
3. Configurez toutes les options de marque supplémentaires telles que les couleurs et les images.
4. Votre marque apparaîtra sur votre site web B1.church et dans l'application B1 Mobile.

:::tip
Avoir votre logo et votre marque prêts avant d'inviter les membres de l'équipe donne une impression soignée lorsqu'ils se connectent.
:::

## Étape 3 : Configurez les rôles et invitez votre équipe

1. Cliquez sur **Rôles** à partir de la page **Paramètres**.
2. Créez des rôles pour votre équipe (par exemple, « Pasteur », « Secrétaire », « Trésorier »).
3. Affectez les permissions appropriées à chaque rôle.
4. Ajoutez des membres de l'équipe en recherchant leurs comptes et en les affectant à des rôles.

## Étape 4 : Configurez vos domaines clés

Avec votre équipe en place, commencez à construire les domaines fondamentaux de B1 Admin :

1. **Personnes** -- Ajoutez les membres à votre répertoire d'église. C'est la base de tout le reste, alors commencez ici. Vous pouvez ajouter des personnes manuellement ou utiliser l'outil **Importer** depuis **Paramètres**.
2. **Groupes** -- Créez des groupes pour les petits groupes, les équipes de ministère, les classes et autres rassemblements.
3. **Participation** -- Configurez vos campus, services et heures de service pour le suivi de la participation.
4. **Donations** -- Configurez les fonds de donation et connectez votre passerelle de paiement (Stripe) pour accepter les donations en ligne.
5. **Site web** -- Créez votre site web public d'église en utilisant le constructeur de site web B1.church.

:::info
Vous n'avez pas besoin de configurer tous les domaines à la fois. De nombreuses églises commencent par **Personnes** et **Groupes**, puis ajoutent **Participation** et **Donations** à mesure qu'elles se sentent à l'aise avec la plateforme.
:::

## Ordre recommandé

Pour la plus fluide des expériences de configuration, nous suggérons cet ordre :

1. **Personnes** -- Ajoutez d'abord vos membres et assistants réguliers.
2. **Groupes** -- Organisez les gens en groupes significatifs.
3. **Participation** -- Commencez à suivre qui se présente chaque semaine.
4. **Donations** -- Configurez les donations une fois que vos personnes sont dans le système.
5. **Site web** -- Construisez votre site public en dernier, après que vos données soient en place.

Une fois que vous avez complété ces étapes, votre église est prête à fonctionner. Explorez la documentation [B1 Admin](/docs/b1-admin/) pour des guides détaillés sur chaque domaine.
