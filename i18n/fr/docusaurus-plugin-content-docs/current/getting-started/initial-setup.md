# Configuration initiale

<div class="article-intro">

Après avoir créé votre compte et votre église, quelques étapes importantes sont à configurer avant d'inviter votre équipe. Ce guide vous accompagne dans l'ordre de configuration recommandé, afin que votre église soit prête à fonctionner dès le premier jour.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- [Créer votre compte](./create-account.md) et enregistrer votre église
- Préparer le logo de votre église et vos éléments graphiques (facultatif, mais recommandé)

</div>

## Étape 1 : Configurer les informations de votre église

1. Ouvrez le [menu Jump](../b1-admin/introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche de B1 Admin), développez **Paramètres**, puis cliquez sur **Paramètres**.
2. Dans la section **Informations sur l'église**, cliquez sur **Modifier**.
3. Saisissez le **nom**, le **sous-domaine** et l'**adresse** de votre église.
4. Cliquez sur **Enregistrer** pour appliquer vos modifications.

## Étape 2 : Configurer votre image de marque

1. Dans le menu Jump, choisissez **Site web > Apparence**.
2. Importez le **logo de votre église**.
3. Configurez les autres options d'image de marque, comme les couleurs et les images.
4. Votre image de marque apparaîtra sur votre site web B1.church et dans l'application B1 App.

:::tip
Préparer votre logo et votre image de marque avant d'inviter les membres de votre équipe leur donne une excellente première impression lors de leur première connexion.
:::

## Étape 3 : Configurer les rôles et inviter votre équipe

1. Dans le menu Jump, choisissez **Paramètres > Rôles**.
2. Créez des rôles pour votre équipe (par exemple, « Pasteur », « Secrétaire », « Trésorier »).
3. Attribuez les autorisations appropriées à chaque rôle.
4. Ajoutez les membres de l'équipe en recherchant leurs comptes et en les affectant à des rôles.

## Étape 4 : Configurer vos domaines principaux

Une fois votre équipe en place, commencez à construire les domaines essentiels de B1 Admin :

1. **Personnes** -- Ajoutez des membres à l'annuaire de votre église. C'est la base de tout le reste, commencez donc par là. Vous pouvez ajouter des personnes manuellement ou utiliser l'outil **Import/Export** depuis **Paramètres**.
2. **Groupes** -- Créez des groupes pour les petits groupes, les équipes de ministère, les cours et autres rassemblements.
3. **Présence** -- Configurez vos campus, vos cultes et leurs horaires pour suivre la présence.
4. **Dons** -- Configurez les fonds de dons et connectez votre passerelle de paiement (Stripe) pour recevoir des dons en ligne.
5. **Site web** -- Créez le site web public de votre église à l'aide du générateur de sites B1.church.

:::info
Vous n'êtes pas obligé de configurer tous les domaines en même temps. Beaucoup d'églises commencent par **Personnes** et **Groupes**, puis ajoutent la **Présence** et les **Dons** à mesure qu'elles se familiarisent avec la plateforme.
:::

## Ordre recommandé

Pour une configuration plus fluide, nous vous suggérons cet ordre :

1. **Personnes** -- Ajoutez d'abord vos membres et les participants réguliers.
2. **Groupes** -- Organisez les personnes en groupes pertinents.
3. **Présence** -- Commencez à suivre qui participe chaque semaine.
4. **Dons** -- Configurez les dons une fois que vos personnes sont enregistrées dans le système.
5. **Site web** -- Créez votre site public en dernier, une fois vos données en place.

Une fois ces étapes terminées, votre église est prête à fonctionner. Consultez la documentation [B1 Admin](/docs/b1-admin/) pour des guides détaillés sur chacun des domaines.
