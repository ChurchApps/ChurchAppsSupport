# Configuration initiale

<div class="article-intro">

Après avoir créé votre compte et votre église, il y a quelques étapes importantes à configurer avant d'inviter votre équipe. Ce guide vous montre l'ordre de configuration recommandé pour que votre église soit prête à fonctionner dès le premier jour.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- [Créez votre compte](./create-account.md) et enregistrez votre église
- Ayez le logo et les ressources de marque de votre église prêts (optionnel mais recommandé)

</div>

## Étape 1 : Configurez les informations de votre église

1. Ouvrez le [menu Sauter](../b1-admin/introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche de B1 Admin), développez **Paramètres**, et cliquez sur **Paramètres**.
2. Cliquez sur **Modifier les paramètres**.
3. Entrez le **nom**, l'**adresse** et les **détails de contact** de votre église.
4. Cliquez sur **Enregistrer** pour appliquer vos modifications.

## Étape 2 : Configurez votre marque

1. Dans le menu Sauter, choisissez **Site Web > Apparence**.
2. Téléchargez le **logo de votre église**.
3. Configurez les options de marque supplémentaires telles que les couleurs et les images.
4. Votre marque apparaîtra sur votre site Web B1.church et dans l'application B1 Mobile.

:::tip
Avoir votre logo et votre marque prêts avant d'inviter les membres de l'équipe donne une première impression soignée quand ils se connectent.
:::

## Étape 3 : Configurez les rôles et invitez votre équipe

1. Dans le menu Sauter, choisissez **Paramètres > Rôles**.
2. Créez des rôles pour votre équipe (par exemple, "Pasteur", "Secrétaire", "Trésorier").
3. Assignez les permissions appropriées à chaque rôle.
4. Ajoutez les membres de l'équipe en cherchant leurs comptes et en les assignant à des rôles.

## Étape 4 : Configurez vos domaines clés

Avec votre équipe en place, commencez à construire les domaines clés de B1 Admin :

1. **Personnes** -- Ajoutez des membres à l'annuaire de votre église. C'est la base pour tout le reste, alors commencez ici. Vous pouvez ajouter des personnes manuellement ou utiliser l'outil **Importer** à partir de **Paramètres**.
2. **Groupes** -- Créez des groupes pour les petits groupes, les équipes de ministère, les classes et d'autres réunions.
3. **Présence** -- Configurez vos campus, services et horaires de service pour le suivi de la présence.
4. **Dons** -- Configurez les fonds de dons et connectez votre passerelle de paiement (Stripe) pour accepter les dons en ligne.
5. **Site Web** -- Créez votre site Web d'église public en utilisant le constructeur de site Web B1.church.

:::info
Vous n'avez pas besoin de configurer tous les domaines à la fois. Beaucoup d'églises commencent avec **Personnes** et **Groupes**, puis ajoutent **Présence** et **Dons** au fur et à mesure qu'elles se familiarisent avec la plateforme.
:::

## Ordre recommandé

Pour l'expérience de configuration la plus fluide, nous suggérons cet ordre :

1. **Personnes** -- Ajoutez d'abord vos membres et fidèles réguliers.
2. **Groupes** -- Organisez les personnes en groupes significatifs.
3. **Présence** -- Commencez à suivre qui se présente chaque semaine.
4. **Dons** -- Configurez les dons une fois que vos personnes sont dans le système.
5. **Site Web** -- Créez votre site public en dernier, après que vos données soient en place.

Une fois que vous avez terminé ces étapes, votre église est prête à fonctionner. Explorez la documentation [B1 Admin](/docs/b1-admin/) pour des guides détaillés sur chaque domaine.
