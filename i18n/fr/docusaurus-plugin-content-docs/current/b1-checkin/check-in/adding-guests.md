# Ajout de visiteurs {#adding-guests}

<div class="article-intro">

Si quelqu'un accompagne votre famille en visite et doit s'enregistrer avec votre foyer, vous pouvez l'ajouter en tant que visiteur directement depuis le kiosque. Cela est utile pour les enfants en visite, les proches ou les amis qui ne sont pas encore dans le système de l'église.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- [Recherchez votre famille](./looking-up-members.md) et sélectionnez un membre dans les résultats de recherche
- Soyez sur l'[écran de vérification du foyer](./household-review.md) où vous pouvez voir les membres de votre famille

</div>

## Comment ajouter un visiteur {#how-to-add-a-guest}

1. Depuis l'**écran de vérification du foyer**, appuyez sur le bouton **Ajouter un visiteur** situé sous la liste des membres du foyer.
2. Le formulaire d'ajout de visiteur apparaît avec ces champs :
   - **Prénom** -- Saisissez le prénom du visiteur.
   - **Nom** -- Saisissez le nom de famille du visiteur.
   - **Courriel** -- Facultatif. Saisissez le courriel du visiteur afin que l'église puisse faire un suivi après la visite.
3. Appuyez sur le bouton **Ajouter un visiteur** pour enregistrer.

Le visiteur est ajouté à votre foyer et vous êtes ramené à l'écran de vérification du foyer. Le nouveau visiteur apparaîtra dans votre liste de membres aux côtés de vos autres membres de famille.

:::info
Si le nom du visiteur correspond à une personne déjà dans le système qui n'est pas membre, l'application se liera à cet enregistrement existant au lieu de créer un doublon. Cela permet de maintenir la base de données de votre église propre. Dans ce cas, le courriel que vous avez saisi n'est pas enregistré ; il n'est ajouté qu'aux visiteurs nouvellement créés.
:::

## Après l'ajout d'un visiteur {#after-adding-a-guest}

Une fois le visiteur affiché dans la liste de votre foyer, vous pouvez :

- **Déployer sa carte** et lui [assigner un groupe](./group-assignment.md), comme pour tout autre membre de la famille.
- **[Enregistrer](./completing-checkin.md)** l'ensemble du foyer, visiteur compris.

## Annulation {#canceling}

Si vous changez d'avis, appuyez sur le bouton **Annuler** en bas du formulaire d'ajout de visiteur pour revenir à l'écran de vérification du foyer sans ajouter personne.

:::tip
L'ajout d'un visiteur au kiosque crée un enregistrement de personne dans la base de données de votre église. L'administrateur de votre église pourra mettre à jour les informations complètes du visiteur ultérieurement dans B1 Admin sous [Personnes](../../b1-admin/people/adding-people.md).
:::

## Prochaine étape {#next-step}

Après avoir ajouté des visiteurs et [assigné des groupes](./group-assignment.md) selon les besoins, vous êtes prêt à [finaliser l'enregistrement](./completing-checkin.md).
