# Recherche de membres

<div class="article-intro">

Après avoir sélectionné un service, vous accédez à l'écran de recherche de membres. C'est ici que vous recherchez votre famille pour pouvoir vous enregistrer. L'application permet de rechercher par numéro de téléphone ou par nom.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- [Sélectionnez un service](./selecting-service) à partir de l'écran des services
- Assurez-vous que votre ménage a été [ajouté au système](../../b1-admin/people/adding-people.md) par un administrateur de l'église

</div>

## Modes de recherche

L'écran de recherche offre deux modes de recherche. Vous pouvez basculer entre eux en appuyant sur le bouton bascule en haut de l'écran :

- **Téléphone** -- Recherche par numéro de téléphone. C'est le mode par défaut.
- **Nom** -- Recherche par nom.

## Recherche par numéro de téléphone

1. Assurez-vous que **Téléphone** est le mode de recherche actif (il est surligné en haut).
2. Appuyez sur le champ de recherche et entrez au moins **4 chiffres** de votre numéro de téléphone à l'aide du clavier à l'écran.
3. Appuyez sur le bouton **Rechercher** ou appuyez sur la touche de recherche du clavier.

L'application recherche les membres dont le numéro de téléphone correspond aux chiffres que vous avez entrés. Si vous entrez plus de 4 chiffres, elle utilise le numéro complet. Si vous entrez exactement 4, elle correspond aux 4 derniers chiffres des numéros de téléphone en dossier.

## Recherche par nom

1. Appuyez sur le bouton bascule **Nom** en haut de l'écran pour passer au mode de recherche par nom.
2. Entrez au moins **2 caractères** du nom de la personne dans le champ de recherche.
3. Appuyez sur le bouton **Rechercher**.

L'application recherche les membres dont le nom correspond à ce que vous avez saisi.

## Sélection d'une personne

Les résultats de la recherche apparaissent sous forme de cartes sous le champ de recherche. Chaque carte affiche le **nom** et la **photo** de la personne (si l'une d'elles est en dossier).

Appuyez sur la carte d'une personne pour la sélectionner. L'application charge tous les membres du ménage de cette personne et vous amène à l'[écran de révision du ménage](./household-review).

:::tip
La recherche par les 4 derniers chiffres d'un numéro de téléphone est le moyen le plus rapide de rechercher votre famille. Encouragez les membres à utiliser cette méthode pour une expérience d'enregistrement plus rapide.
:::

:::warning
Si aucun résultat n'est trouvé, l'application affiche un message pour vous le faire savoir. Double-vérifiez les chiffres ou le nom que vous avez entrés, ou essayez l'autre mode de recherche. Si vous êtes un visiteur pour la première fois, demandez à un bénévole de vous aider à être [ajouté au système](../../b1-admin/people/adding-people.md).
:::

## Inscription en tant qu'invité

Si votre église a l'enregistrement des invités par code QR activé, un lien **S'inscrire en tant qu'invité** apparaît sous la recherche sur l'écran de recherche. Les visiteurs pour la première fois peuvent l'utiliser pour ajouter leur famille au système de l'église avant de s'enregistrer.

1. Appuyez sur **S'inscrire en tant qu'invité**. Une fenêtre s'ouvre avec un code QR et le message « Scannez pour vous inscrire en tant qu'invité ».
2. Choisissez comment remplir le [formulaire d'enregistrement des invités](../../b1-church/checkin/guest-registration) :
   - **Sur votre téléphone** -- Scannez le code QR, remplissez le formulaire sur votre téléphone, et appuyez sur **OK** pour fermer la fenêtre.
   - **Sur le kiosque** -- Appuyez sur **S'inscrire ici** pour ouvrir le même formulaire directement sur la tablette. Remplissez-le et appuyez sur **S'inscrire**, puis appuyez sur **Terminé** (ou la flèche retour) pour revenir à l'écran de recherche.
3. Une fois inscrit, recherchez votre famille par nom ou numéro de téléphone pour vous enregistrer.

:::info
Le formulaire ouvert avec **S'inscrire ici** reste sur la page d'enregistrement des invités -- les visiteurs ne peuvent pas naviguer vers d'autres parties du site web de l'église depuis le kiosque. Si personne ne touche ou tape dans le formulaire pendant 2 minutes, le kiosque le ferme et revient à l'écran de recherche. Chaque fois que le formulaire se ferme, tout ce qui a été tapé dedans est effacé afin que la prochaine famille commence avec un formulaire vierge.
:::

## Impression d'étiquettes pour un enregistrement par téléphone

Les familles qui se sont déjà enregistrées sur leur téléphone via l'[auto-enregistrement B1 Church](../../b1-church/checkin/self-checkin) peuvent imprimer leurs badges au kiosque sans se rechercher.

1. Sur l'écran de recherche, appuyez sur le bouton **Scanner le code** (l'icône du code QR).
2. Tenez le code QR de votre téléphone face à la caméra. Si l'application demande l'accès à la caméra, appuyez sur **Autoriser la caméra**. La caméra avant est utilisée par défaut ; appuyez sur le bouton de basculement pour changer.
3. Le kiosque trouve l'enregistrement et imprime les étiquettes, puis revient à l'écran de recherche.

Le scan n'imprime que les étiquettes -- l'assiduité a déjà été enregistrée lorsque la famille s'est enregistrée sur son téléphone. Si le code ne correspond pas à un enregistrement actif, le kiosque affiche un message et revient à l'écran de recherche.

## Prochaine étape

Après avoir sélectionné une personne, vous allez [réviser votre ménage](./household-review) et gérer les affectations de groupe.
