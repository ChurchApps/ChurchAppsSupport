# Premiers pas avec B1.church

<div class="article-intro">

B1.church est le foyer en ligne de votre église. C'est l'endroit où vous vous rendez pour rester en contact avec votre congrégation, consulter les actualités, donner en ligne, vous enregistrer pour les services, et bien plus encore. Cette section vous présente les bases pour accéder au portail membre et l'utiliser.

</div>

## Accéder au site de votre église

Votre église dispose de sa propre URL B1.church, généralement au format `https://yourchurchname.b1.church`. Vous pouvez visiter cette URL depuis n'importe quel navigateur web sur votre ordinateur, tablette ou téléphone. Les responsables de votre église ou l'équipe d'accueil peuvent vous fournir l'adresse exacte.

Lors de votre première visite du site, vous verrez le site web public de votre église avec son image de marque personnalisée, ses menus de navigation et ses pages de contenu.

## Créer un compte

Pour accéder au portail membre et à ses fonctionnalités, vous avez besoin d'un compte ChurchApps.

1. Visitez l'URL B1.church de votre église.
2. Cliquez sur le bouton **Login** dans le coin supérieur droit de la page.
3. Sur l'écran de connexion, sélectionnez l'option pour **Register** un nouveau compte.
4. Saisissez votre **prénom**, votre **nom**, votre **adresse e-mail**, et choisissez un **mot de passe**.
5. Complétez le formulaire d'inscription.

Après l'inscription, vous pouvez vous connecter et accéder au portail membre avec tous ses outils.

:::tip
Si votre église vous a déjà ajouté à son système, utilisez la même adresse e-mail qu'elle a enregistrée. Cela reliera votre compte à votre profil d'église existant.
:::

## Ce que vous pouvez faire

Une fois connecté, le portail membre vous donne accès à :

- Votre **Timeline** personnelle avec les mises à jour de vos groupes et de votre église
- Les **Groups** auxquels vous appartenez, y compris les conversations et les événements
- Les **Giving** en ligne pour les dons
- Les **Plans** montrant votre calendrier de bénévolat et les détails du service
- Le **Check-In** pour les services et événements
- L'annuaire **Community** pour trouver et vous connecter avec d'autres membres

## Accéder depuis votre téléphone

B1.church fonctionne dans n'importe quel navigateur mobile. Pour une expérience plus proche d'une application, installez le portail membre de votre église comme **Progressive Web App (PWA)** -- visitez `https://yourchurchname.b1.church/mobile/install` pour des instructions guidées et spécifiques à votre appareil, ou ajoutez-la à votre écran d'accueil directement depuis Safari ou Chrome. Aucun app store requis. Voir [Installer en tant qu'application (PWA)](./installing-pwa.md) pour les instructions.

:::info
L'ancienne application native B1 Mobile a été abandonnée. La PWA est désormais le moyen pris en charge d'utiliser B1.church sur un téléphone -- voir la [page de référence B1 Mobile](/docs/b1-mobile/) pour la documentation historique.
:::
