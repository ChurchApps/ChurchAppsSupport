# Connexion

<div class="article-intro">

Vous connecter à B1.church vous donne accès au portail membre où vous pouvez consulter votre timeline, gérer des groupes, donner en ligne et utiliser tous les outils que votre église a mis en place. Cet article explique comment vous connecter, naviguer dans votre menu utilisateur et vous déconnecter.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin d'un compte ChurchApps. Voir [Premiers pas](../getting-started/) pour en créer un.
- Vous avez besoin de l'URL B1.church de votre église (par exemple, `https://yourchurchname.b1.church`).

</div>

## Comment se connecter

1. Accédez à l'URL B1.church de votre église (par exemple, `https://yourchurchname.b1.church`).
2. Cliquez sur le bouton **Login** dans le coin supérieur droit de l'en-tête.
3. Saisissez votre **adresse e-mail** et votre **mot de passe**, ou cliquez sur **Continue with Google** ou **Continue with Microsoft** si votre église a activé l'authentification unique.
4. Cliquez sur **Sign In**.

Après vous être connecté, vous serez ramené à la page sur laquelle vous étiez avant de cliquer sur connexion. Si vous avez accédé directement à une page du portail membre alors que vous étiez déconnecté, vous serez automatiquement redirigé vers cette page après vous être connecté.

## Accéder au portail membre

Une fois connecté, vous pouvez accéder au portail membre en cliquant sur votre **nom** dans le coin supérieur droit de la page et en sélectionnant **Member Portal** dans le menu. Le portail membre est l'endroit où se trouvent tous vos outils personnels d'église, y compris votre [timeline](../community/timeline.md), vos [groupes](../groups/), vos [dons](../giving/), et plus encore.

## Votre menu utilisateur

Après vous être connecté, votre nom apparaît sous forme de puce dans le coin supérieur droit. Cliquez dessus pour ouvrir un menu avec les options suivantes :

- **Member Portal** -- Accédez à votre tableau de bord personnel du portail membre.
- **Edit Profile** -- Mettez à jour les paramètres de votre compte ou modifiez votre profil d'église.
- **Logout** -- Déconnectez-vous de votre compte.

## Accès administrateur

Si vous êtes administrateur de l'église avec les autorisations appropriées, vous verrez également une option **Admin Portal** dans votre menu utilisateur. En cliquant dessus, vous accédez à B1 Admin où vous pouvez gérer les paramètres, les personnes, les groupes et le contenu de votre église.

## Mot de passe oublié

Si vous ne vous souvenez pas de votre mot de passe :

1. Cliquez sur **Forgot Password** sur la page de connexion.
2. Saisissez l'adresse e-mail associée à votre compte ChurchApps et validez.
3. Consultez votre e-mail pour un message contenant un **code de vérification à 6 chiffres**. Le code est valide pendant 15 minutes.
4. Saisissez le code sur l'écran de vérification pour vous connecter.
5. Une fois connecté, rendez-vous sur votre profil pour choisir un nouveau mot de passe.

:::tip
Si le code n'arrive pas dans les deux minutes, vérifiez votre dossier spam. Après cinq tentatives incorrectes, le code est bloqué -- demandez-en un nouveau depuis la page Mot de passe oublié si cela se produit.
:::

## Déconnexion

Pour vous déconnecter, cliquez sur votre **nom** dans le coin supérieur droit et sélectionnez **Logout**. Vous serez déconnecté et redirigé vers le site public.
