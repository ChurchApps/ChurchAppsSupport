# Connexion

<div class="article-intro">

Se connecter à B1.church vous donne accès au portail des membres, où vous pouvez voir ce qui vous attend, gérer vos groupes, donner en ligne et utiliser tous les outils que votre église a mis en place. Cet article explique comment vous connecter, naviguer dans votre menu utilisateur et vous déconnecter.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin d'un compte ChurchApps. Voir [Pour commencer](./index.md) pour en créer un.
- Vous avez besoin de l'adresse B1.church de votre église (par exemple `https://votreeglise.b1.church`).

</div>

## Comment se connecter

1. Accédez à l'adresse B1.church de votre église (par exemple `https://votreeglise.b1.church`).
2. Cliquez sur le bouton **Connexion** dans le coin supérieur droit de l'en-tête.
3. Saisissez votre **adresse courriel** et votre **mot de passe**, ou cliquez sur **Continuer avec Google** ou **Continuer avec Microsoft** si votre église a activé l'authentification unique.
4. Cliquez sur **Se connecter**.

Si vous avez activé la [connexion à deux facteurs](../../b1-admin/profile/managing-profile.md#two-factor-sign-in), l'écran suivant demande un code. Saisissez le code à 6 chiffres de votre application d'authentification, ou l'un de vos codes de secours, puis cliquez sur **Vérifier le code**. L'application B1.church demande le code de la même façon.

Après la connexion, vous revenez à la page où vous vous trouviez avant de cliquer sur connexion. Si vous êtes allé directement à une page du portail des membres alors que vous étiez déconnecté, vous y serez automatiquement renvoyé après la connexion.

## Rester connecté

Vous restez connecté sur le même navigateur ou la même application installée jusqu'à ce que vous vous déconnectiez, même si vous ne venez pas pendant un certain temps -- votre session est conservée pendant environ 30 jours d'inactivité. Une seule connexion vous garde aussi connecté lorsque vous passez du site web de votre église au portail des membres (`/mobile`), de sorte que vous n'avez pas à vous reconnecter à chaque endroit.

## Accéder au portail des membres

Une fois connecté, vous pouvez accéder au portail des membres en cliquant sur votre **nom** dans le coin supérieur droit de la page, puis en sélectionnant **Portail des membres** dans le menu. Le portail des membres regroupe tous vos outils ecclésiaux personnels, y compris votre [tableau de bord d'accueil](./navigating.md), la [page Moi](./me-page.md), les [groupes](../groups/index.md), les [dons](../giving/index.md) et bien plus encore.

## Votre menu utilisateur

Après la connexion, votre nom apparaît sous forme de pastille dans le coin supérieur droit. Cliquez dessus pour ouvrir un menu avec les options suivantes :

- **Portail des membres** -- Accéder à votre tableau de bord personnel du portail des membres.
- **Modifier le profil** -- Mettre à jour les paramètres de votre compte ou modifier votre profil d'église.
- **Déconnexion** -- Vous déconnecter de votre compte.

## Accès d'administrateur

Si vous êtes administrateur d'église avec les autorisations appropriées, vous verrez aussi une option **Portail d'administration** dans votre menu utilisateur. En cliquant dessus, vous accédez à B1 Admin, où vous pouvez gérer les paramètres, les personnes, les groupes et le contenu de votre église.

## Mot de passe oublié

Si vous ne vous souvenez plus de votre mot de passe :

1. Cliquez sur **Mot de passe oublié** sur la page de connexion.
2. Saisissez l'adresse courriel associée à votre compte ChurchApps et soumettez.
3. Vérifiez votre boîte courriel : vous y trouverez un message contenant un **code de vérification à 6 chiffres**. Le code est valide pendant 15 minutes.
4. Saisissez le code sur l'écran de vérification pour vous connecter.
5. Une fois connecté, rendez-vous sur votre profil pour choisir un nouveau mot de passe.

:::tip
Si le code n'arrive pas dans les deux minutes, vérifiez votre dossier des pourriels. Après cinq tentatives incorrectes, le code est verrouillé -- demandez-en un nouveau depuis la page Mot de passe oublié si cela se produit.
:::

## Se déconnecter

Pour vous déconnecter, cliquez sur votre **nom** dans le coin supérieur droit et sélectionnez **Déconnexion**. Vous serez déconnecté et renvoyé sur le site public.
