# Se connecter

<div class="article-intro">

Se connecter à B1.church vous donne accès au portail des membres, où vous pouvez voir ce qui vous attend, gérer vos groupes, faire des dons en ligne et utiliser tous les outils mis en place par votre église. Cet article explique comment vous connecter, naviguer dans votre menu utilisateur et vous déconnecter.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin d'un compte ChurchApps. Consultez [Premiers pas](./index.md) pour en créer un.
- Vous avez besoin de l'adresse B1.church de votre église (par exemple, `https://yourchurchname.b1.church`).

## Comment vous connecter {#how-to-log-in}

1. Rendez-vous à l'adresse B1.church de votre église (par exemple, `https://yourchurchname.b1.church`).
2. Cliquez sur le bouton **Connexion** dans le coin supérieur droit de l'en-tête. Si votre église n'a pas activé le bouton **Connexion** sur son site, accédez plutôt à `https://yourchurchname.b1.church/login`.
3. Saisissez votre **adresse courriel** et votre **mot de passe**, ou cliquez sur **Continuer avec Google** ou **Continuer avec Microsoft** si votre église a activé la connexion unique.
4. Cliquez sur **Se connecter**.

Si vous avez activé la [connexion en deux étapes](../../b1-admin/profile/managing-profile.md#two-factor-sign-in), l'écran suivant vous demande un code. Saisissez le code à 6 chiffres de votre application d'authentification, ou l'un de vos codes de secours, puis cliquez sur **Vérifier le code**. Le portail des membres demande le code de la même façon.

Après la connexion, vous serez redirigé vers la page que vous consultiez avant de cliquer sur connexion. Si vous êtes allé directement sur une page du portail des membres sans être connecté, vous y serez ramené automatiquement après la connexion.

## Se connecter depuis le portail des membres {#signing-in-from-the-member-portal}

Le portail des membres (`/mobile`) dispose de son propre écran de connexion. Appuyez sur **Se connecter** sur l'accueil, sur la page **Plus**, ou sur tout écran nécessitant un compte, saisissez votre courriel et votre mot de passe, puis appuyez sur **Se connecter**. Vous pouvez aussi appuyer sur **Mot de passe oublié ?** pour réinitialiser votre mot de passe, ou sur **Créer un compte** si vous n'en avez pas encore. La connexion avec Google et Microsoft n'est proposée que sur la page de connexion du site web.

## Rester connecté {#staying-signed-in}

Vous restez connecté sur le même navigateur ou la même application installée jusqu'à ce que vous vous déconnectiez, même si vous ne venez pas pendant un certain temps — votre session est conservée pendant environ 30 jours d'inactivité. Une seule connexion vous maintient également connecté lorsque vous passez du site web de votre église au portail des membres (`/mobile`), de sorte que vous n'avez pas à vous reconnecter à chaque endroit.

## Accéder au portail des membres {#accessing-the-member-portal}

Une fois connecté, vous pouvez accéder au portail des membres en cliquant sur votre **nom** dans le coin supérieur droit de la page et en sélectionnant **Portail des membres** dans le menu. Le portail des membres regroupe tous vos outils personnels de l'église, y compris votre [tableau de bord d'accueil](./navigating.md), votre [page Moi](./me-page.md), vos [groupes](../groups/index.md), vos [dons](../giving/index.md), et plus encore.

## Votre menu utilisateur {#your-user-menu}

Après la connexion, votre nom apparaît sous forme de pastille dans le coin supérieur droit. Cliquez dessus pour ouvrir un menu avec les options suivantes :

- **Portail des membres** -- Accédez à votre tableau de bord personnel du portail des membres.
- **Modifier le profil** -- Ouvre deux choix supplémentaires : **Modifier le compte** (votre courriel de connexion, votre mot de passe et vos paramètres de double authentification, dans B1 Admin) et **Modifier le profil d'église** (votre profil dans l'[annuaire](../community/member-directory.md) du portail des membres).
- **Déconnexion** -- Déconnectez-vous de votre compte.

## Accès administrateur {#admin-access}

Si vous êtes administrateur de l'église avec les autorisations appropriées, vous verrez également une option **Portail d'administration** dans votre menu utilisateur. En cliquant dessus, vous accédez à B1 Admin, où vous pouvez gérer les paramètres, les personnes, les groupes et le contenu de votre église.

## Mot de passe oublié {#forgot-your-password}

Si vous ne vous souvenez plus de votre mot de passe :

1. Cliquez sur **Mot de passe oublié** sur la page de connexion (dans le portail des membres, appuyez sur **Mot de passe oublié ?**).
2. Saisissez l'adresse courriel associée à votre compte ChurchApps et cliquez sur **Réinitialiser** (**Envoyer le code** dans le portail des membres).
3. Consultez votre courriel pour trouver un message contenant un **code de vérification à 6 chiffres**. Le code est valide pendant 15 minutes.
4. Saisissez le code et cliquez sur **Vérifier le code**. S'il n'est pas arrivé, vous pouvez appuyer sur **Renvoyer le code** après 30 secondes.
5. Choisissez un nouveau mot de passe (au moins 8 caractères), saisissez-le une deuxième fois pour le confirmer, puis cliquez sur **Se connecter** (**Enregistrer et se connecter** dans le portail des membres). Vous êtes connecté avec votre nouveau mot de passe.

:::tip
Si le code n'arrive pas dans les deux minutes, vérifiez votre dossier de courriels indésirables. Après cinq tentatives incorrectes, le code est verrouillé — demandez-en un nouveau depuis la page Mot de passe oublié si cela se produit.
:::

## Se déconnecter {#logging-out}

Pour vous déconnecter, cliquez sur votre **nom** dans le coin supérieur droit et sélectionnez **Déconnexion**. Vous serez déconnecté et redirigé vers le site public.
