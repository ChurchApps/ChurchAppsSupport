# Se connecter

<div class="article-intro">

Se connecter à B1.church vous donne accès au portail membre, où vous pouvez voir ce qui vous attend, gérer vos groupes, faire des dons en ligne et utiliser tous les outils que votre église a mis en place. Cet article explique comment vous connecter, naviguer dans votre menu utilisateur et vous déconnecter.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez avoir un compte ChurchApps. Consultez [Premiers pas](../getting-started/) pour en créer un.
- Vous avez besoin de l'adresse B1.church de votre église (par exemple `https://yourchurchname.b1.church`).

</div>

## Comment vous connecter

1. Rendez-vous à l'adresse B1.church de votre église (par exemple `https://yourchurchname.b1.church`).
2. Cliquez sur le bouton **Connexion** dans le coin supérieur droit de l'en-tête.
3. Saisissez votre **adresse e-mail** et votre **mot de passe**, ou cliquez sur **Continuer avec Google** ou **Continuer avec Microsoft** si votre église a activé l'authentification unique.
4. Cliquez sur **Se connecter**.

Si vous avez activé la [connexion en deux étapes](../../b1-admin/profile/managing-profile.md#two-factor-sign-in), l'écran suivant demande un code. Saisissez le code à 6 chiffres de votre application d'authentification, ou l'un de vos codes de secours, puis cliquez sur **Vérifier le code**. L'application B1.church demande le code de la même façon.

Après la connexion, vous serez ramené à la page où vous vous trouviez avant de cliquer sur Connexion. Si vous êtes allé directement sur une page du portail membre sans être connecté, vous y serez automatiquement renvoyé après la connexion.

## Rester connecté

Vous restez connecté sur le même navigateur ou la même application installée jusqu'à ce que vous vous déconnectiez, même si vous ne visitez pas le site pendant un certain temps -- votre session est conservée pendant environ 30 jours d'inactivité. Se connecter une fois vous garde aussi connecté lorsque vous passez du site web de votre église au portail membre (`/mobile`), de sorte que vous n'avez pas à vous reconnecter à chaque endroit.

## Accéder au portail membre

Une fois connecté, vous pouvez accéder au portail membre en cliquant sur votre **nom** dans le coin supérieur droit de la page, puis en sélectionnant **Portail membre** dans le menu. Le portail membre regroupe tous vos outils personnels d'église, y compris votre [tableau de bord d'accueil](./navigating.md), votre [page Moi](./me-page.md), les [groupes](../groups/), les [dons](../giving/) et plus encore.

## Votre menu utilisateur

Après la connexion, votre nom apparaît sous forme de pastille dans le coin supérieur droit. Cliquez dessus pour ouvrir un menu avec les options suivantes :

- **Portail membre** -- Accéder à votre tableau de bord personnel du portail membre.
- **Modifier le profil** -- Mettre à jour les paramètres de votre compte ou modifier votre profil d'église.
- **Déconnexion** -- Se déconnecter de votre compte.

## Accès administrateur

Si vous êtes administrateur de l'église avec les autorisations appropriées, vous verrez aussi une option **Portail d'administration** dans votre menu utilisateur. Cliquer dessus vous mène à B1 Admin, où vous pouvez gérer les paramètres, les personnes, les groupes et le contenu de votre église.

## Mot de passe oublié

Si vous ne vous souvenez plus de votre mot de passe :

1. Cliquez sur **Mot de passe oublié** sur la page de connexion.
2. Saisissez l'adresse e-mail associée à votre compte ChurchApps et soumettez.
3. Vérifiez votre boîte de réception : vous y trouverez un message contenant un **code de vérification à 6 chiffres**. Le code est valide pendant 15 minutes.
4. Saisissez le code sur l'écran de vérification pour vous connecter.
5. Une fois connecté, rendez-vous dans votre profil pour choisir un nouveau mot de passe.

:::tip
Si le code n'arrive pas dans les minutes qui suivent, vérifiez votre dossier de pourriels. Après cinq tentatives incorrectes, le code est verrouillé -- demandez-en un nouveau depuis la page Mot de passe oublié si cela se produit.
:::

## Se déconnecter

Pour vous déconnecter, cliquez sur votre **nom** dans le coin supérieur droit et sélectionnez **Déconnexion**. Vous serez déconnecté et renvoyé sur le site public.
