# Connexion

<div class="article-intro">

La connexion à B1.church vous donne accès au portail des membres où vous pouvez voir ce qui vous attend, gérer les groupes, donner en ligne et utiliser tous les outils que votre église a configurés. Cet article couvre comment se connecter, naviguer dans votre menu utilisateur et se déconnecter.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin d'un compte ChurchApps. Consultez [Démarrage](../getting-started/) pour en créer un.
- Vous avez besoin de l'URL B1.church de votre église (par exemple, `https://yourchurchname.b1.church`).

</div>

## Comment se connecter

1. Allez à l'URL B1.church de votre église (par exemple, `https://yourchurchname.b1.church`).
2. Cliquez sur le bouton **Connexion** dans le coin supérieur droit de l'en-tête.
3. Entrez votre **adresse email** et **mot de passe**, ou cliquez sur **Continuer avec Google** ou **Continuer avec Microsoft** si votre église a l'authentification unique activée.
4. Cliquez sur **Se connecter**.

Après vous être connecté, vous serez redirigé vers la page sur laquelle vous étiez avant de cliquer sur la connexion. Si vous avez navigué directement vers une page du portail des membres alors que vous étiez déconnecté, vous serez redirigé vers cette page automatiquement après vous être connecté.

## Rester connecté

Vous restez connecté sur le même navigateur ou application installée jusqu'à votre déconnexion, même si vous ne visitez pas pendant un certain temps -- votre session est conservée pendant environ 30 jours d'inactivité. La connexion une seule fois vous maintient également connecté lorsque vous vous déplacez entre le site web de votre église et le portail des membres (`/mobile`), vous n'avez donc pas besoin de vous connecter à nouveau à chaque endroit.

## Accès au portail des membres

Une fois connecté, vous pouvez accéder au portail des membres en cliquant sur votre **nom** dans le coin supérieur droit de la page et en sélectionnant **Portail des membres** dans le menu. Le portail des membres est l'endroit où tous vos outils personnels d'église se trouvent, y compris votre tableau de bord [Accueil](./navigating.md), la page [À propos de moi](./me-page.md), les [groupes](../groups/), les [dons](../giving/), et plus.

## Votre menu utilisateur

Après vous être connecté, votre nom apparaît sous forme de puce dans le coin supérieur droit. Cliquez dessus pour ouvrir un menu avec les options suivantes :

- **Portail des membres** -- Allez au tableau de bord de votre portail des membres personnels.
- **Modifier le profil** -- Mettez à jour vos paramètres de compte ou modifiez votre profil d'église.
- **Déconnexion** -- Déconnectez-vous de votre compte.

## Accès administrateur

Si vous êtes un administrateur d'église avec les autorisations appropriées, vous verrez également une option **Portail administrateur** dans votre menu utilisateur. Cliquer dessus vous amène à B1 Admin où vous pouvez gérer les paramètres, les personnes, les groupes et le contenu de votre église.

## Mot de passe oublié

Si vous ne pouvez pas vous souvenir de votre mot de passe :

1. Cliquez sur **Mot de passe oublié** sur la page de connexion.
2. Entrez l'adresse email associée à votre compte ChurchApps et soumettez.
3. Vérifiez votre email pour un message contenant un **code de vérification à 6 chiffres**. Le code est valide pendant 15 minutes.
4. Entrez le code sur l'écran de vérification pour vous connecter.
5. Une fois connecté, visitez votre profil pour choisir un nouveau mot de passe.

:::tip
Si le code n'arrive pas en quelques minutes, vérifiez votre dossier indésirable. Après cinq tentatives incorrectes, le code est verrouillé -- demandez une nouvelle tentative à partir de la page Mot de passe oublié si cela se produit.
:::

## Déconnexion

Pour vous déconnecter, cliquez sur votre **nom** dans le coin supérieur droit et sélectionnez **Déconnexion**. Vous serez déconnecté et redirigé vers le site public.
