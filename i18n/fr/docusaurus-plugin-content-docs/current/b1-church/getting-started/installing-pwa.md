# Installer comme application (PWA)

<div class="article-intro">

B1.church prend en charge l'installation en tant qu'application web progressive (PWA), ce qui vous permet d'ajouter le portail des membres de votre église à l'écran d'accueil de votre téléphone, exactement comme une application native. Vous profitez ainsi d'une expérience plein écran, proche d'une application, sans passer par l'App Store ni Google Play.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin de l'adresse B1.church de votre église : `https://yourchurchname.b1.church`
- Utilisez un navigateur pris en charge : **Safari** sur iOS ou **Chrome** sur Android

</div>

## Qu'est-ce qu'une PWA ? {#what-is-a-pwa}

Une application web progressive (PWA) est un site web qui peut être installé sur votre appareil et se comporte comme une application native. Lorsque vous installez B1.church comme PWA, il :

- S'ouvre en plein écran, sans barres de navigation du navigateur
- Apparaît sur votre écran d'accueil avec l'icône et le nom de votre église
- S'harmonise avec l'identité visuelle et les couleurs de votre église

:::tip
La PWA est une excellente option si vous préférez ne pas installer une application distincte depuis l'App Store ou Google Play. Elle offre la même expérience de portail des membres que dans le navigateur, sous une forme plus pratique.
:::

## La page d'installation {#the-install-page}

Le moyen le plus simple d'installer l'application est la page d'installation dédiée de votre église :

```
https://yourchurchname.b1.church/mobile/install
```

La page détecte votre appareil et affiche automatiquement les instructions appropriées :

- **iPhone** — instructions Safari pas à pas pour « Ajouter à l'écran d'accueil »
- **Android** — un bouton **Installer sur l'écran d'accueil** à appuyer une seule fois dans Chrome
- **Ordinateur** — un code QR à scanner avec votre téléphone pour ouvrir la page d'installation sur celui-ci, ainsi qu'un bouton **Installer sur cet ordinateur** si votre navigateur prend en charge l'installation d'applications web

Vous pouvez accéder à la page d'installation de plusieurs façons :

- Appuyez sur **Plus** dans le portail des membres, puis sur **Installer l'application** sous **Compte** (cet élément est masqué une fois l'application déjà installée)
- Suivez un lien que votre église partage par message texte, courriel ou depuis l'écran du dimanche
- Saisissez directement l'adresse dans votre navigateur

:::tip Pour le personnel de l'église
Partagez le lien de la page d'installation avec votre communauté — placez-le dans votre bulletin, votre infolettre ou sur une diapositive. Elle guide chaque membre dans les étapes exactes pour son appareil. Vous pouvez aussi y accéder via l'action rapide **Télécharger l'application** sur votre tableau de bord B1Admin.
:::

Vous pouvez également installer la PWA manuellement depuis **n'importe quelle page** du site B1.church de votre église en suivant les étapes du navigateur ci-dessous — la page d'installation n'est que la version guidée de cette procédure.

Lorsque vous lancez l'application installée, elle s'ouvre directement sur votre tableau de bord de membre, prête à ce que vous vous connectiez.

## Installer sur iPhone (iOS — Safari) {#installing-on-iphone-ios--safari}

1. Ouvrez **Safari** sur votre iPhone et accédez à `https://yourchurchname.b1.church/mobile/install` (remplacez `yourchurchname` par l'identifiant de l'adresse de votre église).
2. Appuyez sur le bouton **Partager** (la case avec une flèche pointant vers le haut) en bas de l'écran.
3. Faites défiler la feuille de partage vers le bas et appuyez sur **Sur l'écran d'accueil**.
4. Le nom proposé par défaut est celui de votre église. Appuyez sur **Ajouter** dans le coin supérieur droit.

L'icône de l'application apparaîtra sur votre écran d'accueil. Appuyez dessus pour ouvrir le portail des membres en plein écran.

:::info
L'installation de la PWA sur iOS nécessite Safari. Si vous utilisez Chrome ou un autre navigateur sur iPhone, passez d'abord à Safari.
:::

## Installer sur Android (Chrome) {#installing-on-android-chrome}

1. Ouvrez **Chrome** sur votre appareil Android et accédez à `https://yourchurchname.b1.church/mobile/install`.
2. Appuyez sur le bouton **Installer sur l'écran d'accueil**. (Si Chrome n'a pas encore proposé d'invite d'installation, la page vous le signale — appuyez sur le menu à trois points (⋮) dans le coin supérieur droit et sélectionnez plutôt **Installer l'application**.)
3. Appuyez sur **Installer** lorsque cela vous est demandé.

L'icône de l'application apparaîtra sur votre écran d'accueil. Appuyez dessus pour ouvrir le portail des membres.

## Après l'installation {#after-installing}

Une fois installée, la PWA s'ouvre directement sur le portail des membres, dans une fenêtre plein écran dédiée. Si vous ouvrez la page d'installation depuis l'application installée, elle affiche « Tout est prêt ! » au lieu des étapes. Vous pouvez :

- Vous connecter avec votre compte ChurchApps existant
- Accéder à toutes les fonctionnalités de membre activées par votre église — groupes, dons, enregistrement, plans de service, et plus encore
- Y revenir à tout moment en appuyant sur l'icône de votre écran d'accueil

L'icône de l'application affiche un **badge de notification** (un petit chiffre) lorsque vous avez des notifications ou des messages non lus, afin de voir d'un coup d'œil s'il y a quelque chose de nouveau pour vous.

:::info
La PWA nécessite une connexion Internet. Contrairement à certaines applications natives, elle ne met pas en cache tout le contenu pour une utilisation hors ligne.
:::
