# Modifier votre profil

<div class="article-intro">

La page de votre profil dans le portail des membres vous permet de mettre à jour vos coordonnées, de gérer les membres de votre foyer, de modifier l'adresse courriel et le mot de passe de votre compte, et de contrôler qui peut voir votre adresse postale, votre numéro de téléphone et votre adresse courriel.

</div>

## Ouvrir votre profil

Appuyez sur votre photo de profil dans la barre supérieure de l'application, ou appuyez sur **Modifier le profil** en haut de la page **Plus** ou sur votre [page Moi](./me-page.md), pour ouvrir **Votre profil** à `/mobile/profileEdit`. La page est une seule feuille composée de sections — **Photo et nom**, **Coordonnées**, **Foyer**, **Compte** et **Confidentialité** — chacune affichant vos informations actuelles avec un lien **Modifier** (ou **Ajouter un membre de la famille** / **Changer**) qui ouvre un panneau où vous effectuez vos modifications.

## Photo et nom, et coordonnées

Ces sections contiennent les informations que votre église voit sur votre fiche personnelle :

- **Photo et nom** — appuyez sur **Changer de photo** pour importer une nouvelle image, et modifiez votre **Titre**, vos prénoms et votre nom. Pour **Titre**, choisissez une suggestion (M., Mme, Mlle, Dr, Prof, Rév. ou Pasteur) ou saisissez le vôtre, jusqu'à 10 caractères.
- **Coordonnées** — courriel, téléphone mobile, téléphone à domicile, téléphone au travail, date de naissance et votre adresse (rue, ville, province ou État et code postal). Si vous activez les rappels par messages texte dans [Préférences de notification](./notification-preferences.md), ils seront envoyés à votre numéro de téléphone mobile.

Effectuez vos modifications dans le panneau, puis appuyez sur **Enregistrer les modifications**.

:::info
Si votre église exige une approbation pour les modifications de l'annuaire, la page affiche « Les modifications de votre profil sont soumises au personnel de l'église pour approbation. » et le bouton indique **Soumettre pour approbation**. Vos modifications sont alors envoyées sous forme de demande au lieu d'être appliquées immédiatement. Consultez [Approuver les modifications de profil](/docs/b1-admin/profile/approving-profile-changes) pour savoir comment votre église examine ces demandes.
:::

## Foyer

La section Foyer affiche les autres personnes liées à votre foyer, chacune avec son rôle dans le foyer (Chef de famille, Conjoint, Enfant, etc.). Appuyez sur un membre du foyer pour afficher ses détails.

Pour ajouter un membre de la famille qui ne figure pas encore dans le système :

1. Appuyez sur **Ajouter un membre de la famille**.
2. Saisissez son **Prénom**. Le **Nom** est prérempli avec votre nom de famille ; modifiez-le si le sien est différent.
3. Ajoutez, si vous le souhaitez, son **Titre** et son **Téléphone mobile**.
4. Choisissez son **Rôle dans le foyer** : **Chef de famille**, **Conjoint**, **Enfant** ou **Autre** (par défaut).
5. Appuyez sur **Ajouter**. La personne apparaît sous **Membres de famille en attente** avec son rôle. Appuyez sur **Retirer** pour la retirer de la liste. Répétez l'opération pour chaque autre personne.
6. Appuyez sur **Enregistrer les modifications** (ou **Soumettre pour approbation**).

Si votre église examine les modifications de l'annuaire, les nouveaux membres de la famille sont soumis avec vos autres modifications pour approbation par votre église. Sinon, ils sont ajoutés à votre foyer dès que vous enregistrez.

## Compte

La section Compte gère votre connexion plutôt que votre profil d'église. Appuyez sur **Modifier** pour l'ouvrir :

- **Nom d'affichage** — le prénom et le nom affichés sur votre compte de connexion (distinct du nom figurant sur votre profil d'église).
- **Changer le courriel** — modifiez l'adresse courriel que vous utilisez pour vous connecter.
- **Changer le mot de passe** — saisissez votre mot de passe actuel, puis votre nouveau mot de passe deux fois. Votre nouveau mot de passe doit comporter au moins 8 caractères.

Chaque partie possède son propre bouton **Enregistrer**.

## Confidentialité

La section Confidentialité indique qui peut voir vos coordonnées dans l'ensemble de ChurchApps. Appuyez sur **Changer** pour ouvrir **Préférences de visibilité** :

- **Me masquer de l'annuaire des membres** — un interrupteur qui vous retire entièrement de l'[annuaire des membres](../community/member-directory.md).
- **Visibilité de l'adresse**, **Visibilité du téléphone** et **Visibilité du courriel** — chacune possède sa propre liste déroulante. Vous pouvez, par exemple, partager votre courriel avec toute l'église tout en gardant votre adresse plus privée. Les options sont les suivantes :

| Niveau | Qui peut le voir |
|---|---|
| **Tout le monde** | Visible par toute personne pouvant consulter l'annuaire. |
| **Membres seulement** | Visible par les autres membres de l'église connectés. |
| **Mes groupes seulement** | Visible uniquement par les membres des groupes auxquels vous appartenez. |
| **Mes responsables de groupe et le personnel** | Visible uniquement par le personnel de l'église et les responsables des groupes auxquels vous appartenez. |
| **Personnel seulement** | Visible uniquement par le personnel de l'église (personnes ayant le statut d'adhésion Personnel ou l'autorisation d'affichage des personnes). |

Appuyez sur **Enregistrer** pour appliquer vos choix. Votre église définit une valeur par défaut pour chacun de ces trois champs (voir [Paramètres de l'application mobile](/docs/b1-admin/settings/mobile-app)), mais ce que vous choisissez ici remplace cette valeur par défaut pour votre propre fiche.

:::tip
Vous voyez toujours vos propres informations, quels que soient ces paramètres, et le personnel disposant de l'autorisation d'affichage des personnes peut toujours les voir également.
:::
