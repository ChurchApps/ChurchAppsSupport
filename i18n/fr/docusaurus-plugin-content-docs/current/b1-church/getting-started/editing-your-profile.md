# Modification de votre profil

<div class="article-intro">

La page de votre profil dans le portail membre vous permet de mettre à jour vos coordonnées, de gérer votre ménage, de modifier l'adresse e-mail et le mot de passe de votre compte, et de contrôler qui peut voir votre adresse, votre numéro de téléphone et votre adresse e-mail.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être [connecté](./logging-in.md) — la modification du profil nécessite un compte

</div>

## Ouvrir votre profil

Appuyez sur votre photo de profil dans la barre d'application supérieure, ou appuyez sur **Modifier le profil** en haut de la page **Plus** ou sur votre [page Me](./me-page.md), pour ouvrir **Votre profil** à l'adresse `/mobile/profileEdit`. La page se présente sous forme d'une seule feuille de sections -- **Photo et nom**, **Coordonnées**, **Ménage**, **Compte** et **Confidentialité** -- chacune affichant vos informations actuelles avec un lien **Modifier** (ou **Ajouter un membre de la famille** / **Changer**) qui ouvre un panneau dans lequel vous effectuez vos modifications.

## Photo et nom, et coordonnées

Ces sections contiennent les informations que votre église voit sur votre fiche personnelle :

- **Photo et nom** — appuyez sur **Changer la photo** pour envoyer une nouvelle image, et modifiez vos prénom, deuxième prénom et nom de famille.
- **Coordonnées** — E-mail, téléphone portable, téléphone fixe, téléphone professionnel, date de naissance, et votre adresse (rue, ville, région et code postal). Si vous activez les rappels par SMS dans les [Préférences de notification](./notification-preferences.md), ils seront envoyés à votre numéro de portable.

Effectuez vos modifications dans le panneau, puis appuyez sur **Enregistrer les modifications**.

:::info
Si votre église exige une approbation pour les modifications de l'annuaire, la page indique « Les modifications de votre profil sont transmises au personnel de l'église pour approbation. » et le bouton affiche **Soumettre pour approbation** — vos modifications sont envoyées sous forme de demande au lieu d'être appliquées immédiatement. Consultez [Approbation des modifications de profil](/docs/b1-admin/profile/approving-profile-changes) pour savoir comment votre église les examine.
:::

## Ménage

La section Ménage affiche les autres personnes liées à votre ménage, chacune avec son rôle dans le ménage (Chef de famille, Conjoint, Enfant, etc.). Appuyez sur un membre du ménage pour afficher ses détails.

Pour ajouter un membre de la famille qui n'est pas encore dans le système, appuyez sur **Ajouter un membre de la famille**, saisissez son prénom, puis appuyez sur **Ajouter**. Les nouveaux membres de la famille sont ajoutés à une liste en attente et sont soumis avec vos autres modifications de profil pour examen par votre église.

## Compte

La section Compte gère votre connexion plutôt que votre profil d'église. Appuyez sur **Modifier** pour l'ouvrir :

- **Nom d'affichage** — le prénom et le nom affichés sur votre connexion (distincts du nom figurant sur votre profil d'église).
- **Changer l'e-mail** — modifiez l'adresse e-mail que vous utilisez pour vous connecter.
- **Changer le mot de passe** — saisissez votre mot de passe actuel, puis votre nouveau mot de passe deux fois. Votre nouveau mot de passe doit comporter au moins 8 caractères.

Chaque partie possède son propre bouton **Enregistrer**.

## Confidentialité

La section Confidentialité indique qui peut voir vos coordonnées dans l'ensemble de ChurchApps. Appuyez sur **Changer** pour ouvrir **Préférences de visibilité** :

- **Me masquer de l'annuaire des membres** — un interrupteur qui vous retire entièrement de l'[annuaire des membres](../community/member-directory.md).
- **Visibilité de l'adresse**, **Visibilité du téléphone** et **Visibilité de l'e-mail** — chacune a son propre menu déroulant, ce qui vous permet par exemple de partager votre e-mail avec toute l'église tout en gardant votre adresse plus privée. Les options sont les suivantes :

| Niveau | Qui peut le voir |
|---|---|
| **Tout le monde** | Visible par toute personne pouvant consulter l'annuaire. |
| **Membres uniquement** | Visible par les autres membres de l'église connectés. |
| **Mes groupes uniquement** | Visible uniquement par les membres des groupes auxquels vous appartenez. |
| **Mes responsables de groupe et le personnel** | Visible uniquement par le personnel de l'église et les responsables des groupes auxquels vous appartenez. |
| **Personnel uniquement** | Visible uniquement par le personnel de l'église. |

Appuyez sur **Enregistrer** pour appliquer vos choix. Votre église définit une valeur par défaut pour chacun de ces trois champs — consultez [Paramètres de l'application mobile](/docs/b1-admin/settings/mobile-app) — mais le choix que vous faites ici remplace cette valeur par défaut pour votre propre fiche.

:::tip
Vous voyez toujours vos propres informations, quels que soient ces paramètres, et le personnel disposant de l'autorisation de consultation des personnes peut toujours les voir également.
:::
