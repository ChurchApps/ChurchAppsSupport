# Faire un don

<div class="article-intro">

Il y a deux façons de faire un don via le site B1.church de votre église : la page de donation publique (pas de connexion requise) et la page de donation des membres (connexion requise). Les deux utilisent un formulaire de donation sécurisé alimenté par Stripe.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Pour les dons publics, aucun compte n'est nécessaire -- visitez simplement la page **Donner** de votre église.
- Pour les dons des membres avec historique et méthodes de paiement enregistrées, [connectez-vous](../getting-started/logging-in.md) à votre compte d'abord.

</div>

## Page de donation publique (pas de connexion requise)

N'importe qui peut faire un don sans créer de compte :

1. Accédez à la page **Donner** de votre église.
2. Le formulaire de donation s'affiche sur le côté gauche de la page. Sélectionnez le **fonds** auquel vous souhaitez donner.
3. Entrez vos détails de paiement et le montant que vous souhaitez donner.
4. Soumettez le formulaire pour terminer votre don.

Sur le côté droit de la page, vous verrez un lien vers **Instructions pour le paiement ACH** si vous préférez donner par transfert bancaire. Il y a aussi un bouton **Se connecter** si vous souhaitez vous connecter pour accéder à des fonctionnalités supplémentaires comme l'historique des dons.

:::tip
Si vous êtes déjà connecté lorsque vous visitez la page de donation publique, vous serez automatiquement redirigé vers la page de donation des membres où vous avez accès à votre historique complet des dons et vos méthodes de paiement enregistrées.
:::

## Page de donation des membres (connecté)

Lorsque vous êtes connecté, l'expérience de donation inclut des fonctionnalités supplémentaires, organisées en quatre onglets :

- **Aperçu** -- Votre total de dons année à ce jour, une carte de progression de campagne (si votre église a une campagne active) et votre don le plus récent avec un bouton **Répéter** en un clic.
- **Donner** -- Le formulaire de donation.
- **Gérer** -- Vos méthodes de paiement enregistrées (ajouter, supprimer ou définir une carte ou un compte bancaire par défaut).
- **Historique** -- Vos dons passés, totaux de dons par période, dons récurrents et exports de relevés. Voir [Historique des dons](./donation-history.md) pour plus de détails.

Pour donner :

1. Ouvrez la page de donation à partir de l'onglet **Donner** de votre église ou à partir de **Dons** dans les Raccourcis sur votre [page Me](../getting-started/me-page.md). Si vous atterrissez sur **Aperçu**, sélectionnez l'onglet **Donner**.
2. Choisissez le **fonds** auquel vous souhaitez donner et entrez le montant de votre don.
3. Sélectionnez une méthode de paiement enregistrée existante ou entrez de nouveaux détails de paiement.
4. Soumettez le formulaire pour terminer votre don.

Après le traitement de votre don, un message de succès apparaîtra et votre don s'affichera dans votre [historique des dons](./donation-history.md).

:::info
Si les dons que vous avez faits ont été enregistrés en plusieurs devises, votre total d'aperçu année à ce jour et le total de la période d'historique sont convertis dans la devise de votre église, avec une note **Converti aux taux de change actuels** en dessous. Les dons individuels dans votre historique affichent toujours leur devise d'origine.
:::

## Méthodes de paiement

Les dons sont traités de manière sécurisée via **Stripe**. Vous pouvez payer par carte de crédit, carte de débit ou configurer un paiement bancaire ACH. Lorsque vous êtes connecté, vos méthodes de paiement peuvent être enregistrées pour une utilisation future, ce qui facilite votre prochain don.

:::warning
Si votre don ne passe pas, vérifiez vos détails de paiement et réessayez. Si le problème persiste, contactez votre bureau de l'église pour obtenir de l'aide.
:::
