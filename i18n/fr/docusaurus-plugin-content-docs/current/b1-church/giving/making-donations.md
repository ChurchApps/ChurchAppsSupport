# Faire un don

<div class="article-intro">

Il existe deux façons de faire un don via le site B1.church de votre église : la page de don publique (sans connexion requise) et la page de don pour les membres (connexion requise). Toutes deux utilisent un formulaire de don sécurisé fourni par Stripe.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Pour les dons publics, aucun compte n'est nécessaire -- il suffit de vous rendre sur la page **Donner** de votre église.
- Pour les dons de membres avec suivi de l'historique et modes de paiement enregistrés, [connectez-vous](../getting-started/logging-in.md) à votre compte au préalable.

</div>

## Page de don publique (sans connexion)

Toute personne peut faire un don sans créer de compte :

1. Accédez à la page **Donner** de votre église.
2. Le formulaire de don s'affiche à gauche de la page. Sélectionnez le **fonds** auquel vous souhaitez donner.
3. Saisissez vos informations de paiement et le montant que vous souhaitez donner.
4. Envoyez le formulaire pour finaliser votre don.

À droite de la page, vous verrez un lien **Instructions pour le paiement ACH** si vous préférez donner par virement bancaire. Un bouton **Connexion** est également disponible si vous souhaitez vous connecter pour accéder à des fonctionnalités supplémentaires, comme l'historique des dons.

:::tip
Si vous êtes déjà connecté lorsque vous visitez la page de don publique, vous serez automatiquement redirigé vers la page de don pour les membres, où vous avez accès à l'intégralité de votre historique de dons et à vos modes de paiement enregistrés.
:::

## Page de don pour les membres (connecté)

Lorsque vous êtes connecté, la page **Dons** du portail des membres affiche un bouton **Donner** et un bouton **Imprimer le relevé** en haut, suivis des sections suivantes :

- **Cette année** (titrée avec l'année en cours) -- Votre total des dons depuis le début de l'année et le nombre de dons, avec un lien **Tout l'historique**. Consultez [Historique des dons](./donation-history.md) pour plus de détails.
- **Récurrents** -- Vos dons programmés, avec un lien **Gérer**.
- **Activité récente** -- Vos trois derniers dons, avec un lien **Répéter le dernier don** qui ouvre le formulaire de don.
- **Modes de paiement** -- Vos cartes et comptes bancaires enregistrés, avec un lien **Gérer** pour en ajouter, en supprimer ou en définir un par défaut.
- Une carte de progression de campagne, si votre église dispose d'une campagne active.

Pour donner :

1. Ouvrez la page Dons depuis l'onglet **Donner** de votre église, depuis le bouton **Donner** de la section **Dons** de votre [tableau de bord Accueil](../getting-started/navigating.md#home), ou depuis **Historique** dans la section **Dons** de votre [page Moi](../getting-started/me-page.md). Sur la page Dons, touchez **Donner** pour ouvrir le formulaire de don.
2. Choisissez le **fonds** auquel vous souhaitez donner et saisissez le montant de votre don.
3. Sélectionnez un mode de paiement enregistré ou saisissez de nouvelles informations de paiement.
4. Envoyez le formulaire pour finaliser votre don.

Une fois votre don traité, un message de confirmation s'affiche et votre don apparaît dans votre [historique des dons](./donation-history.md).

:::info
Si les dons que vous avez effectués ont été enregistrés dans plusieurs devises, votre total de l'année et le total de l'historique sont convertis dans la devise de votre église, avec une note **Converti aux taux de change actuels** en dessous. Les dons individuels de votre historique affichent toujours leur devise d'origine.
:::

## Modes de paiement

Les dons sont traités en toute sécurité par **Stripe**. Vous pouvez payer par carte de crédit, carte de débit, ou configurer un prélèvement bancaire ACH. Lorsque vous êtes connecté, vos modes de paiement peuvent être enregistrés pour une utilisation future, ce qui facilite les dons suivants.

:::info Don par compte bancaire sans connexion
Si vous donnez en tant qu'invité (sans vous connecter) par compte bancaire, le compte doit être vérifié instantanément en vous connectant à votre banque. Si ce n'est pas possible, vous verrez le message : « Ce compte bancaire n'a pas pu être vérifié instantanément. Veuillez donner par carte, ou connectez-vous et ajoutez le compte bancaire à votre profil de dons. » Les comptes bancaires nécessitant quelques jours de vérification ne peuvent être ajoutés qu'après connexion.
:::

:::warning
Si votre don n'aboutit pas, vérifiez vos informations de paiement et réessayez. Si le problème persiste, contactez le secrétariat de votre église pour obtenir de l'aide.
:::
