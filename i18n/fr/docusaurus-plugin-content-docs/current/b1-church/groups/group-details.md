# Détails du groupe

<div class="article-intro">

Quand vous cliquez sur un groupe à partir de la page des groupes, vous êtes redirigé vers la page des détails du groupe. Ce que vous voyez dépend de votre connexion ou non, les membres connectés ayant accès à des onglets et des fonctionnalités supplémentaires.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Trouvez un groupe à afficher en [naviguant dans les groupes](./browsing-groups.md).
- Pour un accès complet à tous les onglets, [connectez-vous](../getting-started/logging-in.md) à votre compte.

</div>

## Vue du visiteur (Non connecté)

Si vous n'êtes pas connecté, vous verrez les éléments suivants :

- **Section héroïque** -- Une grande zone de bannière affichant la photo, le nom, l'heure de réunion et le lieu de réunion du groupe.
- **Description** -- La description complète du groupe expliquant son objectif et à quoi s'attendre.
- **Chefs de file** -- Avatars et noms des chefs de file du groupe. Vous pouvez cliquer sur le nom d'un chef de file pour afficher son profil.
- **Événements du calendrier** -- Jusqu'à trois événements à venir pour le groupe sont affichés, chacun affichant la date et le titre de l'événement. Si le groupe n'a pas d'événements à venir, cette section est masquée.
- **Formulaire de contact** -- Un formulaire qui vous permet d'envoyer un message directement aux chefs de file du groupe. Remplissez votre **prénom**, **nom de famille**, **e-mail**, **numéro de téléphone** et **message**, puis cliquez sur **Soumettre**. S'il y a plusieurs chefs de file, vous pouvez choisir lequel contacter dans une liste déroulante.

## Vue des membres (Connecté)

Quand vous êtes connecté, la page des détails du groupe affiche la section héroïque ainsi qu'une barre latérale d'onglets. Si votre groupe est associé à un type de plan Lessons.church et que la leçon de cette semaine contient du contenu à emporter pour les parents, une carte **Leçon de cette semaine** apparaît entre le héros et les onglets (membres uniquement).

Les onglets disponibles sont :

- **Détails du groupe** -- La description complète du groupe, rendue avec formatage du texte enrichi.
- **Membres** -- Une liste de tous les membres du groupe, affichant leur photo et leur nom. Vous pouvez cliquer sur le nom d'un membre pour visiter son profil dans l'[annuaire des membres](../community/member-directory.md).
- **Calendrier** -- Le calendrier du groupe affichant les réunions et les événements. Vous pouvez parcourir les événements à venir et passés.
- **Conversations** -- Un espace pour que les membres du groupe postent des messages et interagissent les uns avec les autres. Consultez [Conversations de groupe](./conversations.md) pour plus de détails.
- **Ressources** -- Fichiers partagés et liens qui ont été postés pour le groupe. Vous pouvez télécharger les fichiers téléchargés ou ouvrir les ressources liées.
- **Présence** -- Visible pour les chefs de file du groupe uniquement. Permet le suivi de qui a assisté aux réunions du groupe.

## Capacités des chefs de file

Si vous êtes un chef de file du groupe, vous avez des capacités d'édition supplémentaires :

- **Éditer les détails du groupe** -- Mettez à jour le nom, la description, l'heure de réunion et d'autres paramètres du groupe directement à partir de l'onglet **Détails**.
- **Gérer les membres** -- Ajoutez de nouveaux membres au groupe ou supprimez les membres existants à partir de l'onglet **Membres**.
- **Créer et éditer des événements** -- Ajoutez des événements au calendrier du groupe. Lors de la création d'un événement, vous pouvez réserver des salles et des ressources aux côtés -- choisissez parmi les salles et ressources disponibles, définissez les heures de configuration et de démontage optionnelles, et la demande de réservation est automatiquement soumise pour approbation.
- **Gérer les ressources** -- Téléchargez des fichiers (jusqu'à 100 Mo de stockage), ajoutez des liens ou supprimez les ressources existantes.
- **Ressources des chefs de file** -- Accédez à un onglet **Ressources (Chefs de file)** séparé avec des fichiers et des liens visibles uniquement pour les chefs de file du groupe.
- **Suivi de la présence** -- Enregistrez la présence pour les sessions du groupe à partir de l'onglet **Présence**.

## Rejoindre un groupe

Quand vous êtes connecté et pas encore membre, un bouton de participation apparaît sur la page des détails du groupe. L'étiquette du bouton dépend de la politique de participation du groupe :

- **Rejoindre le groupe** -- Le groupe est ouvert. Cliquer sur ceci vous ajoute immédiatement en tant que membre.
- **Demander à rejoindre** -- Le groupe nécessite une approbation. Cliquer sur ceci ouvre une dialogue où vous pouvez inclure un message facultatif au chef de file du groupe, puis soumettre votre demande. Consultez [Demande pour rejoindre un groupe](./join-requests.md) pour les détails sur la gestion de vos demandes.

Si aucun bouton n'apparaît, le groupe est fermé et les membres doivent être ajoutés manuellement par un chef de file ou un administrateur.

:::info
Si un groupe est fermé et que vous souhaitez le rejoindre, utilisez le formulaire de contact sur la vue du visiteur pour contacter les chefs de file du groupe.
:::
