# Demande d'Adhésion à un Groupe

<div class="article-intro">

Certains groupes exigent une approbation avant que vous puissiez devenir un membre. Lorsqu'un groupe a ce paramètre, vous soumettez une demande d'adhésion — en incluant éventuellement un message au leader du groupe — et attendez que le leader approuve ou refuse. Vous pouvez consulter le statut de vos demandes en attente et les annuler à tout moment.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être [connecté](../getting-started/logging-in.md) à votre compte B1.church pour demander d'adhérer à un groupe.

</div>

## Adhésion vs Demande d'Adhésion

Les groupes peuvent avoir des politiques d'adhésion différentes définies par leurs administrateurs :

- **Ouvert** -- Cliquez sur **Rejoindre le Groupe** sur la page de détail du groupe et vous êtes immédiatement ajouté comme membre.
- **Demande requise** -- Cliquez sur **Demander à Rejoindre** pour soumettre une demande qu'un leader du groupe doit approuver avant que vous deveniez un membre.
- **Fermé** -- Aucun bouton d'adhésion n'apparaît. Les membres doivent être ajoutés manuellement par les leaders.

## Comment Soumettre une Demande d'Adhésion

1. Parcourez pour trouver le groupe auquel vous voulez adhérer. Voir [Parcourir les Groupes](./browsing-groups.md) si vous avez besoin d'aide pour le trouver.
2. Ouvrez la page de détail du groupe.
3. Cliquez sur **Demander à Rejoindre**.
4. Une boîte de dialogue apparaît où vous pouvez éventuellement écrire un message au leader du groupe expliquant pourquoi vous souhaitez adhérer.
5. Cliquez sur **Soumettre** pour envoyer votre demande.

Les leaders du groupe recevront une notification concernant votre demande. Une fois qu'ils l'examinent, vous recevrez une notification avec le résultat.

:::tip
Inclure un court message — tel que comment vous avez entendu parler du groupe ou ce que vous espérez en obtenir — peut aider le leader à prendre une décision plus rapide.
:::

## Vérification du Statut de Vos Demandes

Après avoir soumis une demande, vous pouvez consulter son statut à partir de la page **Groupes** :

1. Naviguez vers la page **Groupes** sur le site B1.church de votre église.
2. Faites défiler jusqu'à la section **Demandes en Attente**.
3. Chaque demande en attente affiche le nom du groupe et la date à laquelle vous l'avez soumise.

Si une demande a été approuvée ou refusée, vous recevrez une notification — les demandes approuvées vous font entrer dans le groupe en tant que membre.
