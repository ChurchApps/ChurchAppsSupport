# Conversations de groupe

<div class="article-intro">

Le chat de groupe est un espace où les membres du groupe peuvent publier des messages et interagir entre eux. Utilisez les conversations pour discuter de sujets, partager des mises à jour et rester en contact avec votre groupe entre les réunions.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être [connecté](../getting-started/logging-in.md) à votre compte B1.church.
- Vous devez être membre du groupe pour accéder au chat de groupe. Consultez [Détails du groupe](./group-details.md) pour savoir comment rejoindre un groupe.

</div>

## Accéder aux conversations

1. Accédez à la page de détails du groupe en cliquant sur un groupe depuis la [page des groupes](./browsing-groups.md).
2. Assurez-vous d'être connecté.
3. Touchez **Ouvrir le chat** sous le nom du groupe, ou dans la section **Messages**, qui affiche un aperçu des derniers messages. Le chat s'ouvre en plein écran ; touchez la flèche de retour pour revenir au groupe.

## Discussions et annonces

Le chat de groupe peut comporter deux fils, selon ceux que votre église a activés pour ce groupe. L'étiquette au-dessus du nom du groupe, en haut du chat, indique celui dans lequel vous vous trouvez :

- **Chat** -- Discussions, où tout membre du groupe peut publier des messages et répondre aux autres.
- **Annonces** -- Messages publiés par les responsables du groupe, importants pour que tous les membres les voient. Les membres ordinaires peuvent lire les annonces et y réagir, mais seuls les responsables peuvent publier ; à la place d'une zone de saisie, les membres ordinaires voient le message « Seuls les responsables du groupe peuvent publier des annonces. »

Lorsque les deux fils sont activés, une bande **Annonce** en haut du chat affiche la dernière annonce. Touchez **Toutes les annonces** pour ouvrir le fil des annonces, et **Retour au chat** pour revenir aux discussions. (Les membres ne voient la bande qu'une fois que le groupe comporte au moins une annonce.)

Si votre église n'a activé qu'un seul des deux fils pour ce groupe, le chat s'ouvre directement sur ce fil. Si les deux sont désactivés, le groupe n'a pas de chat et pas de section **Messages**.

## Publier un message

1. Touchez **Ouvrir le chat** sur la page de votre groupe.
2. Assurez-vous d'être dans le fil **Chat** (touchez **Retour au chat** si vous lisez les annonces).
3. Saisissez votre message dans la zone **Envoyer un message…**.
4. Touchez le bouton d'envoi (ou appuyez sur **Entrée**) pour le partager avec le groupe.

Votre message sera visible par tous les membres du groupe.

## Modifier ou supprimer vos messages

Vous pouvez modifier ou supprimer tout message que vous avez publié :

1. Touchez le bouton **plus d'options** (⋮) sous votre message pour ouvrir le menu du message.
2. Choisissez **Modifier** pour changer le texte du message, ou **Supprimer** pour le retirer.
   - Lors de la modification, le texte du message revient dans le champ de saisie avec une note **Modification du message** au-dessus (touchez **Annuler** pour arrêter la modification). Effectuez vos changements et envoyez-les pour les enregistrer.
   - Lors de la suppression, une confirmation **Supprimer le message ?** apparaît. Touchez **Supprimer** pour retirer définitivement le message pour tous les participants de la conversation.

:::info
Vous ne pouvez modifier que vos propres messages. Les responsables du groupe peuvent aussi supprimer les messages des autres membres ; les membres ordinaires ne voient les options que sur leurs propres messages.
:::

## Réagir aux messages

Dans le chat de groupe, vous pouvez réagir à n'importe quel message avec un emoji :

1. Touchez le bouton **Ajouter une réaction** sous un message.
2. Choisissez l'un des six emojis : 👍 ❤️ 😂 🎉 🙏 😮.

Les réactions apparaissent sous forme de petites pastilles sous le message, avec le nombre de personnes ayant utilisé chacune d'elles. Votre propre réaction est mise en évidence -- touchez la pastille (ou choisissez de nouveau le même emoji) pour la retirer, ou choisissez un autre emoji pour en ajouter une autre. Les réactions s'affichent en direct pour tous les participants du chat.

:::tip
Les conversations de groupe se déroulent dans le chat de chaque groupe -- l'ancien fil combiné [Chronologie](../community/timeline.md) a été retiré. Les activités qui nécessitent votre attention vous parviennent sous forme de notification via l'icône de **cloche** dans la barre d'application.
:::

## Fonctions des responsables

Si vous êtes responsable d'un groupe, vous disposez de fonctions supplémentaires dans le chat de groupe :

- **Publier des annonces** -- Touchez **Toutes les annonces** (ou ouvrez le chat lorsque seules les annonces sont activées) et publiez des messages que tous les membres du groupe peuvent lire.
- **Supprimer des messages** -- Supprimez le message de n'importe quel membre depuis le menu du message (⋮).
- **Publier des discussions** -- Vous pouvez aussi participer aux discussions ordinaires, comme n'importe quel autre membre.

:::info
Les conversations sont propres à chaque groupe. Les messages que vous publiez dans un groupe n'apparaîtront pas dans les conversations d'un autre groupe.
:::
