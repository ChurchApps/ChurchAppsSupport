# Conversations de groupe

<div class="article-intro">

Le chat de groupe est un espace où les membres du groupe peuvent publier des messages et interagir entre eux. Utilisez les conversations pour discuter de sujets, partager des nouvelles et rester en contact avec votre groupe entre les rencontres.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être [connecté](../getting-started/logging-in.md) à votre compte B1.church.
- Vous devez être membre du groupe pour accéder au chat de groupe. Consultez [Détails du groupe](./group-details.md) pour savoir comment rejoindre un groupe.

</div>

## Accéder aux conversations {#accessing-conversations}

1. Accédez à la page de détail du groupe en cliquant sur un groupe depuis la [page des groupes](./browsing-groups.md).
2. Assurez-vous d'être connecté.
3. Appuyez sur **Ouvrir le chat** sous le nom du groupe, ou dans la section **Messages**, qui affiche un aperçu des derniers messages. Le chat s'ouvre en plein écran ; appuyez sur la flèche de retour pour revenir au groupe.

## Discussions et annonces {#discussions-and-announcements}

Le chat de groupe peut comporter deux fils, selon ceux que votre église a activés pour ce groupe. L'intitulé au-dessus du nom du groupe, en haut du chat, indique dans lequel vous vous trouvez :

- **Chat** -- Discussions, où tout membre du groupe peut publier des messages et répondre aux autres.
- **Annonces** -- Messages publiés par les responsables du groupe, importants pour que tous les membres les voient. Les membres ordinaires peuvent lire les annonces et y réagir, mais seuls les responsables peuvent publier ; à la place de la zone de message, les membres ordinaires voient « Seuls les responsables du groupe peuvent publier des annonces. »

Lorsque les deux fils sont activés, une bande **Annonce** en haut du chat affiche la dernière annonce. Appuyez sur **Toutes les annonces** pour ouvrir le fil des annonces, et sur **Retour au chat** pour revenir aux discussions. (Les membres ne voient la bande que lorsque le groupe comporte au moins une annonce.)

Si votre église n'a activé qu'un seul des deux fils pour ce groupe, le chat s'ouvre directement sur ce fil. Si les deux sont désactivés, le groupe n'a ni chat ni section **Messages**.

## Publier un message {#posting-a-message}

1. Appuyez sur **Ouvrir le chat** sur la page de votre groupe.
2. Assurez-vous d'être dans le fil **Chat** (appuyez sur **Retour au chat** si vous lisez les annonces).
3. Saisissez votre message dans la zone **Envoyer un message…**.
4. Appuyez sur le bouton d'envoi pour le partager avec le groupe. Sur téléphone ou tablette, la touche Entrée commence une nouvelle ligne ; sur ordinateur, **Entrée** envoie le message et **Maj+Entrée** commence une nouvelle ligne.

Votre message est visible par tous les membres du groupe. Chaque message indique sa date d'envoi : l'heure pour les messages du jour, « hier » et l'heure, ou la date et l'heure pour les plus anciens.

## Mettre en forme votre message {#formatting-your-message}

Vous pouvez ajouter du gras, de l'italique et des listes à un message :

1. Cliquez dans la zone de message. Lorsqu'elle est sélectionnée, une rangée de boutons **Gras**, **Italique**, **Liste à puces** et **Liste numérotée** s'affiche en dessous.
2. Rédigez votre message, sélectionnez les mots ou lignes à mettre en forme, puis appuyez sur un bouton pour l'appliquer. Appuyez de nouveau sur le même bouton, le texte étant toujours sélectionné, pour le retirer. Sans rien de sélectionné, les boutons de liste mettent en forme la ligne où vous vous trouvez.
3. Envoyez le message comme d'habitude.

Sur ordinateur, vous pouvez aussi utiliser **Ctrl+B** (ou **Cmd+B** sur Mac) pour le gras et **Ctrl+I** (**Cmd+I**) pour l'italique.

La barre d'outils ajoute une mise en forme markdown simple à votre texte : `**bold**`, `_italic_`, un `- ` en début de ligne pour une liste à puces, et `1. ` pour une liste numérotée. Vous pouvez aussi les saisir vous-même. Tous les membres du chat voient le message mis en forme, les liens web restent cliquables (ils s'ouvrent dans un nouvel onglet), un lien vers une image (.jpg, .png, .gif, etc.) affiche l'image sous le message, et les sauts de ligne sont conservés. La même mise en forme fonctionne dans les annonces, les [notes du responsable](./group-details.md#leader-notes) et les messages privés.

## Modifier ou supprimer vos messages {#editing-or-deleting-your-messages}

Vous pouvez modifier ou supprimer tout message que vous avez publié :

1. Appuyez sur le bouton **plus d'options** (⋮) sous votre message pour ouvrir le menu du message.
2. Choisissez **Modifier** pour changer le texte du message, ou **Supprimer** pour le retirer.
   - Lors de la modification, le texte du message revient dans la zone de saisie avec une mention **Modification du message** au-dessus (appuyez sur **Annuler** pour arrêter la modification). Apportez vos changements et envoyez-les pour les enregistrer.
   - Lors de la suppression, une confirmation **Supprimer le message ?** apparaît. Appuyez sur **Supprimer** pour retirer définitivement le message pour tous les participants de la conversation.

:::info
Vous ne pouvez modifier que vos propres messages. Les responsables du groupe peuvent aussi supprimer les messages des autres membres ; les membres ordinaires ne voient les options que sur leurs propres messages.
:::

## Réagir aux messages {#reacting-to-messages}

Dans le chat de groupe, vous pouvez réagir à n'importe quel message avec un emoji :

1. Appuyez sur le bouton **Ajouter une réaction** sous un message.
2. Choisissez l'un des six emojis : 👍 ❤️ 😂 🎉 🙏 😮.

Les réactions apparaissent sous forme de petites pastilles sous le message, avec le nombre de personnes ayant utilisé chacune d'elles. Votre propre réaction est mise en évidence — appuyez sur la pastille (ou choisissez de nouveau le même emoji) pour la retirer, ou choisissez un autre emoji pour en ajouter une autre. Les réactions s'affichent en direct pour tous les participants du chat.

:::tip
Les conversations de groupe vivent dans le chat de chaque groupe -- l'ancien fil combiné de la [Chronologie](../community/timeline.md) a été retiré. Les activités qui demandent votre attention arrivent sous forme de notification, sous l'icône **cloche** dans la barre d'application.
:::

## Fonctionnalités réservées aux responsables {#leader-features}

Si vous êtes responsable de groupe, vous disposez de fonctionnalités supplémentaires dans le chat de groupe :

- **Publier des annonces** -- Appuyez sur **Toutes les annonces** (ou ouvrez le chat lorsque seules les annonces sont activées) et publiez des messages que tous les membres du groupe peuvent lire.
- **Retirer des messages** -- Supprimez le message de n'importe quel membre depuis le menu du message (⋮).
- **Publier des discussions** -- Vous pouvez aussi participer aux discussions habituelles comme n'importe quel autre membre.

:::info
Les conversations sont propres à chaque groupe. Les messages que vous publiez dans un groupe n'apparaissent pas dans les conversations d'un autre groupe.
:::
