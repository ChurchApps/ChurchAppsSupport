# Conversations de groupe

<div class="article-intro">

Le chat de groupe est un espace où les membres du groupe peuvent publier des messages et interagir entre eux. Utilisez les conversations pour discuter de sujets, partager des nouvelles et rester en contact avec votre groupe entre les réunions.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être [connecté](../getting-started/logging-in.md) à votre compte B1.church.
- Vous devez être membre du groupe pour accéder au chat de groupe. Consultez [Détails du groupe](./group-details.md) pour savoir comment rejoindre un groupe.

</div>

## Accéder aux conversations

1. Accédez à la page de détails du groupe en cliquant sur un groupe depuis la [page des groupes](./browsing-groups.md).
2. Assurez-vous d'être connecté.
3. Appuyez sur **Ouvrir le chat** sous le nom du groupe, ou dans la section **Messages**, qui affiche un aperçu des derniers messages. Le chat s'ouvre en plein écran ; appuyez sur la flèche de retour pour revenir au groupe.

## Discussions et annonces

Le chat de groupe peut comporter deux fils, selon ceux que votre église a activés pour ce groupe. L'étiquette au-dessus du nom du groupe, en haut du chat, indique dans lequel vous vous trouvez :

- **Chat** -- Discussions, où tout membre du groupe peut publier des messages et répondre à ceux des autres.
- **Annonces** -- Messages publiés par les responsables du groupe, importants pour que tous les membres les voient. Les membres ordinaires peuvent lire les annonces et y réagir, mais seuls les responsables peuvent publier ; à la place de la zone de message, les membres ordinaires voient le texte « Seuls les responsables du groupe peuvent publier des annonces. »

Lorsque les deux fils sont activés, une bande **Annonce** en haut du chat affiche la dernière annonce. Appuyez sur **Toutes les annonces** pour ouvrir le fil des annonces, et sur **Retour au chat** pour revenir aux discussions. (Les membres ne voient la bande que lorsque le groupe compte au moins une annonce.)

Si votre église n'a activé qu'un seul des deux fils pour ce groupe, le chat s'ouvre directement sur ce fil. Si les deux sont désactivés, le groupe n'a pas de chat et il n'y a pas de section **Messages**.

## Publier un message

1. Appuyez sur **Ouvrir le chat** sur la page de votre groupe.
2. Assurez-vous d'être dans le fil **Chat** (appuyez sur **Retour au chat** si vous lisez les annonces).
3. Tapez votre message dans la zone **Envoyer un message…**.
4. Appuyez sur le bouton d'envoi pour le partager avec le groupe. Sur un téléphone ou une tablette, la touche Entrée commence une nouvelle ligne ; sur un ordinateur, **Entrée** envoie le message et **Maj+Entrée** commence une nouvelle ligne.

Votre message sera visible par tous les membres du groupe. Chaque message indique son heure d'envoi : l'heure pour les messages du jour, « hier » suivi de l'heure, ou la date et l'heure pour les messages plus anciens.

## Mettre en forme votre message {#formatting-your-message}

Vous pouvez ajouter du gras, de l'italique et des listes à un message :

1. Tapez votre message, puis sélectionnez les mots ou les lignes à mettre en forme.
2. Une petite barre d'outils apparaît au-dessus de la zone de message avec les boutons **Gras**, **Italique**, **Liste à puces** et **Liste numérotée**. Appuyez sur l'un d'eux pour l'appliquer. Appuyez à nouveau sur le même bouton, le texte étant toujours sélectionné, pour le retirer.
3. Envoyez le message comme d'habitude.

Sur un ordinateur, vous pouvez aussi appuyer sur **Ctrl+B** (ou **Cmd+B** sur Mac) pour le gras, et sur **Ctrl+I** (**Cmd+I**) pour l'italique.

La barre d'outils ajoute une mise en forme Markdown simple à votre texte : `**gras**`, `_italique_`, un `- ` en début de ligne pour une liste à puces, et `1. ` pour une liste numérotée. Vous pouvez aussi les saisir vous-même. Tous les membres du chat voient le message mis en forme, les liens web restent cliquables et les sauts de ligne sont conservés. La même mise en forme fonctionne dans les annonces, les [notes des responsables](./group-details.md#leader-notes) et les messages privés.

## Modifier ou supprimer vos messages

Vous pouvez modifier ou supprimer tout message que vous avez publié :

1. Appuyez sur le bouton **plus d'options** (⋮) sous votre message pour ouvrir le menu du message.
2. Choisissez **Modifier** pour changer le texte du message, ou **Supprimer** pour le retirer.
   - Lors de la modification, le texte du message revient dans le champ de saisie avec la mention **Modification du message** au-dessus (appuyez sur **Annuler** pour arrêter de modifier). Apportez vos changements, puis envoyez-les pour les enregistrer.
   - Lors de la suppression, une confirmation **Supprimer le message ?** apparaît. Appuyez sur **Supprimer** pour retirer définitivement le message pour tous les participants de la conversation.

:::info
Vous ne pouvez modifier que vos propres messages. Les responsables du groupe peuvent aussi supprimer les messages des autres membres ; les membres ordinaires ne voient les options que sur leurs propres messages.
:::

## Réagir aux messages

Dans le chat de groupe, vous pouvez réagir à n'importe quel message avec un emoji :

1. Appuyez sur le bouton **Ajouter une réaction** sous un message.
2. Choisissez l'un des six emojis : 👍 ❤️ 😂 🎉 🙏 😮.

Les réactions apparaissent sous forme de petites pastilles sous le message, avec le nombre de personnes ayant utilisé chacune d'elles. Votre propre réaction est mise en évidence : appuyez sur la pastille (ou choisissez à nouveau le même emoji) pour la retirer, ou choisissez un autre emoji pour en ajouter une autre. Les réactions s'affichent en direct pour tous les participants du chat.

:::tip
Les conversations de groupe se trouvent dans le chat de chaque groupe : l'ancien fil de [Chronologie](../community/timeline.md), qui regroupait tout, a été retiré. Les activités nécessitant votre attention vous parviennent sous forme de notification via l'icône **cloche** dans la barre d'application.
:::

## Fonctionnalités réservées aux responsables

Si vous êtes responsable de groupe, vous disposez de fonctionnalités supplémentaires dans le chat de groupe :

- **Publier des annonces** -- Appuyez sur **Toutes les annonces** (ou ouvrez le chat lorsque seules les annonces sont activées) et publiez des messages que tous les membres du groupe peuvent lire.
- **Supprimer des messages** -- Supprimez le message de n'importe quel membre depuis le menu du message (⋮).
- **Publier des discussions** -- Vous pouvez également participer aux discussions ordinaires, comme n'importe quel autre membre.

:::info
Les conversations sont propres à chaque groupe. Les messages que vous publiez dans un groupe n'apparaissent pas dans les conversations d'un autre groupe.
:::
