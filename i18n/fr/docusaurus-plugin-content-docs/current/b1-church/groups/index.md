# Groupes

<div class="article-intro">

Les groupes sont un excellent moyen de vous intégrer à la vie de votre église. Que vous cherchiez un petit groupe, une équipe de ministère, une étude biblique ou une opportunité de bénévolat, vous pouvez parcourir et rejoindre les groupes directement depuis le site B1.church de votre église.

</div>

## Ce que vous pouvez faire

Voici ce que vous pouvez faire avec les groupes dans B1App :

- **Parcourir les groupes publics** -- Consultez tous les groupes disponibles, organisés par catégorie. Chaque groupe affiche une photo, un nom, une heure de réunion, un lieu et une brève description.
- **Consulter les détails d'un groupe** -- Cliquez sur un groupe pour voir sa description complète, ses responsables et ses événements à venir dans le calendrier.
- **Rejoindre des groupes** -- Connectez-vous à un groupe pour en devenir membre. Les groupes ouverts vous permettent de rejoindre immédiatement ; les groupes soumis à approbation vous permettent d'envoyer une demande d'adhésion. Consultez [Demander à rejoindre un groupe](./join-requests.md).
- **Participer aux conversations** -- Une fois membre d'un groupe, vous pouvez publier des messages et interagir avec les autres membres dans le chat de groupe -- touchez **Ouvrir le chat** sur la page du groupe.
- **Accéder aux événements et aux ressources** -- Consultez le prochain événement du groupe (touchez **Tous les événements** pour le calendrier complet) et téléchargez les fichiers partagés ou ouvrez les liens depuis la section **Ressources**.

## Expérience publique et expérience connectée

Toute personne peut consulter la page des groupes de votre église et parcourir les groupes disponibles. Les visiteurs non connectés peuvent lire les descriptions des groupes, voir qui sont les responsables et consulter les événements à venir du calendrier. Pour rejoindre un groupe, les visiteurs cliquent sur **Se connecter pour rejoindre** et se connectent ou créent un compte.

Lorsque vous [vous connectez](../getting-started/logging-in.md) et êtes membre du groupe, la page de détails du groupe affiche davantage de sections : **Prochain événement**, **Messages**, **Membres**, **Ressources**, **Plans**, **Présence** et **À propos**. Certaines sections n'apparaissent que lorsqu'elles sont pertinentes -- par exemple, **À propos** nécessite une description du groupe, **Plans** nécessite des plans de service, **Messages** nécessite l'activation du chat de groupe, et **Présence** est affichée aux responsables du groupe et aux personnes autorisées à faire l'appel. Chaque section affiche un aperçu, avec un lien tel que **Tous les membres** ou **Tous les événements** pour ouvrir la liste complète. Les responsables de groupe disposent de fonctions de modification supplémentaires dans ces vues.

:::tip
Les conversations de groupe se déroulent dans le chat de chaque groupe, vos groupes apparaissent dans la section **Vos groupes** du [tableau de bord Accueil](../getting-started/navigating.md#home), et les événements à venir de vos groupes s'affichent sur la [page Moi](../getting-started/me-page.md). Les nouvelles activités qui nécessitent votre attention vous parviennent sous forme de notification dans le menu de la cloche.
:::
