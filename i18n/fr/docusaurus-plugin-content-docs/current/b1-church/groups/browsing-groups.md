# Parcourir les groupes

<div class="article-intro">

La page publique des groupes de votre église vous permet de découvrir facilement les groupes qui vous intéressent. Les groupes sont organisés par catégorie, ce qui vous permet de parcourir rapidement différents types de groupes et de trouver celui qui vous convient.

## Trouver la page des groupes

Accédez à la page **Groupes** du site B1.church de votre église. Cette page est accessible au public, vous n'avez donc pas besoin d'être connecté pour la parcourir.

## Comment les groupes sont organisés

Les groupes sont affichés par **catégorie** (aussi appelée étiquette). Les catégories sont définies par les administrateurs de votre église et peuvent comprendre des étiquettes comme « Petits groupes », « Ministères », « Jeunes » ou « Études bibliques ». Chaque catégorie affiche tous les groupes qui lui appartiennent.

## Lire les fiches de groupe

Chaque groupe est présenté sous forme de fiche qui comprend les renseignements suivants :

- **Photo du groupe** -- Une image de couverture représentant le groupe. Si aucune photo n'a été définie, une image par défaut est affichée.
- **Nom du groupe** -- Affiché en évidence sur la photo.
- **Heure de rencontre** -- Le moment où le groupe se réunit habituellement (par exemple « Mercredis à 19 h »). Si aucune heure n'est définie, un texte de remplacement est affiché.
- **Lieu de rencontre** -- L'endroit où le groupe se réunit. Si aucun lieu n'est défini, un texte de remplacement est affiché.
- **Description** -- Un bref aperçu de l'objet du groupe, limité à quelques lignes. Cliquez sur le groupe pour lire la description complète.

## Voir un groupe

Cliquez sur n'importe quelle fiche de groupe pour ouvrir la page de détail complète du groupe. Vous y trouverez la description complète, les renseignements sur les responsables du groupe, les prochains événements du calendrier et un moyen de communiquer avec le groupe.

:::tip
Si vous cherchez un type de groupe précis, parcourez d'abord les titres des catégories. Cela vous permet d'aller directement à la section qui vous intéresse au lieu de faire défiler tous les groupes.
:::
