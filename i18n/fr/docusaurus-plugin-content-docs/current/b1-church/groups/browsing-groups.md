# Parcourir les groupes

<div class="article-intro">

La page publique des groupes de votre église facilite la découverte des groupes qui vous intéressent. Les groupes sont organisés par catégorie, ce qui vous permet de parcourir rapidement les différents types de groupes et de trouver celui qui vous convient.

## Trouver la page des groupes

Accédez à la page **Groupes** du site B1.church de votre église. Cette page est accessible à tous, vous n'avez donc pas besoin d'être connecté pour parcourir les groupes.

## Comment les groupes sont organisés

Les groupes sont affichés par **catégorie** (également appelée étiquette). Les catégories sont configurées par les administrateurs de votre église et peuvent inclure des étiquettes telles que « Petits groupes », « Ministères », « Jeunesse » ou « Études bibliques ». Chaque catégorie affiche tous les groupes qui lui appartiennent.

## Lire les fiches de groupe

Chaque groupe est affiché sous forme de fiche avec les renseignements suivants :

- **Photo du groupe** -- une image de couverture qui représente le groupe. Si aucune photo n'a été définie, une image par défaut est affichée.
- **Nom du groupe** -- affiché en évidence sur la photo.
- **Horaire de rencontre** -- quand le groupe se réunit habituellement (par exemple « Les mercredis à 19 h »). Si aucun horaire n'est défini, un texte de remplacement est affiché.
- **Lieu de rencontre** -- l'endroit où le groupe se réunit. Si aucun lieu n'est défini, un texte de remplacement est affiché.
- **Description** -- un bref aperçu du sujet du groupe, limité à quelques lignes. Cliquez sur le groupe pour lire la description complète.

## Voir un groupe

Cliquez sur n'importe quelle fiche de groupe pour ouvrir la page de détail complète du groupe. Vous y trouverez la description complète, des renseignements sur les responsables du groupe, les événements à venir au calendrier et un moyen de prendre contact.

:::tip
Si vous cherchez un type de groupe précis, parcourez d'abord les titres des catégories. Cela vous permet d'aller directement à la section qui vous intéresse, au lieu de faire défiler tous les groupes.
:::
