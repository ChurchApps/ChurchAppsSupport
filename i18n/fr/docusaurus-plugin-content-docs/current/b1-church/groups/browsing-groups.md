# Parcourir les groupes

<div class="article-intro">

La page publique des groupes de votre église vous permet de découvrir facilement les groupes qui vous intéressent. Recherchez par nom ou réduisez la liste par catégorie ou par campus pour trouver celui qui vous correspond.

</div>

## Trouver la page des groupes {#finding-the-groups-page}

Accédez à la page **Trouver un groupe** (`/groups`) sur le site B1.church de votre église. Cette page est accessible à tous, vous n'avez donc pas besoin d'être connecté pour la parcourir. Dans le portail des membres, le bouton **Trouver un groupe** de l'écran **Groupes** ouvre la même page.

## Rechercher et filtrer {#searching-and-filtering}

Tous les groupes publics de l'église sont affichés ensemble. Utilisez les commandes au-dessus de la liste pour la réduire :

- **Rechercher des groupes par nom ou description** -- Saisissez un mot pour n'afficher que les groupes dont le nom, la description ou la catégorie le contient.
- **Catégorie** -- Choisissez une catégorie, comme « Petits groupes », « Jeunes » ou « Musique », pour n'afficher que ses groupes. Choisissez **Toutes les catégories** pour tout revoir. Les catégories sont configurées par les administrateurs de votre église, et ce filtre n'apparaît que lorsqu'il y en a plus d'une.
- **Campus** -- Si votre église compte plusieurs campus, choisissez-en un pour ne voir que les groupes qui lui sont rattachés, ou **Tous les campus** pour tous les voir.

Si rien ne correspond, la page indique « Aucun groupe ne correspond à vos filtres. »

Votre église peut aussi établir un lien vers une page pour une seule étiquette de groupe, comme `/groups/youth`, qui ne liste que les groupes portant cette étiquette.

## Lire les fiches de groupe {#reading-group-cards}

Chaque groupe est affiché sous forme de fiche qui contient les informations suivantes :

- **Photo du groupe** -- Une image de couverture représentant le groupe. Si aucune photo n'a été définie, une image par défaut est affichée.
- **Nom du groupe** -- Affiché en évidence sur la photo.
- **Horaire de rencontre** -- Le moment où le groupe se réunit habituellement (par exemple, « Mercredis à 19 h »). Si aucun horaire n'est défini, « -- » est affiché.
- **Lieu de rencontre** -- Où se réunit le groupe, à droite. Si aucun lieu n'est défini, « -- » est affiché.
- **Description** -- Un bref aperçu de ce que propose le groupe, limité à quelques lignes. Si le groupe n'a pas de description, la fiche indique « Aucune description fournie. » Cliquez sur le groupe pour lire la description complète.

## Consulter un groupe {#viewing-a-group}

Cliquez sur n'importe quelle fiche de groupe pour ouvrir la page de détail complète du groupe dans le portail des membres. Vous y trouverez la description complète, les responsables du groupe, les événements à venir et un moyen de vous joindre au groupe.

:::tip
Si vous recherchez un type de groupe précis, sélectionnez-le d'abord dans le filtre **Catégorie**. Vous évitez ainsi de faire défiler la liste de tous les groupes.
:::

## Vos groupes dans le portail des membres {#your-groups-in-the-member-portal}

L'écran **Groupes** du portail des membres liste les groupes auxquels vous appartenez. Le titre indique combien de groupes vous rejoignez (et combien de demandes d'adhésion sont en attente).

- **Rechercher dans vos groupes** -- Filtrez vos groupes par nom.
- **Vos groupes** -- Les groupes que vous ouvrez le plus souvent, jusqu'à cinq, chacun avec son horaire et son lieu de rencontre. Appuyez sur l'un d'eux pour l'ouvrir.
- **Autres groupes** -- Le reste de vos groupes.
- **Demandes en attente** -- Les groupes que vous avez demandé à rejoindre et qui attendent l'accord d'un responsable. Voir [Demander à rejoindre un groupe](./join-requests.md).
- **Événements à venir** -- Les événements de l'église qui acceptent les inscriptions, chacun avec un lien **S'inscrire**. Voir [S'inscrire à un événement](../events/registering.md).

Appuyez sur **Trouver un groupe** pour parcourir tous les groupes de l'église. Si vous n'êtes encore membre d'aucun groupe, l'écran indique « Aucun groupe pour le moment » avec un bouton **Parcourir les groupes** ; si vous n'êtes pas connecté, il vous invite à vous connecter pour voir vos groupes.
