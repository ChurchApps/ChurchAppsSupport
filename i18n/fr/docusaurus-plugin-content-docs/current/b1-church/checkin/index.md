# Enregistrement

<div class="article-intro">

La fonctionnalité **Enregistrement** de B1.church vous permet d'enregistrer votre présence, ainsi que celle des membres de votre ménage, aux services de l'église directement depuis le portail membre. C'est un moyen pratique de noter votre présence sans avoir à vous rendre à un kiosque d'enregistrement physique.

</div>

## Fonctionnement

Lorsque vous utilisez l'auto-enregistrement, vous sélectionnez un service, choisissez les membres de votre ménage qui y assistent et attribuez chaque personne au groupe approprié pour chaque horaire de service. Une fois que vous confirmez, votre présence est enregistrée automatiquement.

## Pour commencer

Pour accéder à l'enregistrement, appuyez sur **Enregistrement** dans la [barre d'onglets ou sur la page Plus](../getting-started/navigating.md) de votre portail membre. Vous devez être [connecté](../getting-started/logging-in.md) pour utiliser cette fonctionnalité -- si vous n'êtes pas connecté, il vous sera demandé de vous connecter d'abord.

:::info
La fonctionnalité d'enregistrement nécessite que votre église ait configuré des services et des groupes de présence dans ses paramètres d'administration. Si aucun service n'est disponible lorsque vous ouvrez la page d'enregistrement, votre église n'a peut-être pas encore configuré cette fonctionnalité. Contactez l'administrateur de votre église pour obtenir de l'aide.
:::
