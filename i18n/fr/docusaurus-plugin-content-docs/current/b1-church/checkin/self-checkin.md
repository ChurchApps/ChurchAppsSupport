# Enregistrement autonome {#self-check-in}

<div class="article-intro">

Le processus d'enregistrement autonome vous permet d'enregistrer votre présence et celle de votre foyer en quelques étapes seulement. C'est une alternative rapide à l'utilisation d'une borne physique à l'église.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être [connecté](../getting-started/logging-in.md) à votre compte B1.church.
- Les membres de votre foyer doivent être liés à votre compte. Si un membre de la famille manque, demandez à votre administrateur d'église de l'ajouter à votre foyer.

</div>

## Le processus d'enregistrement {#the-check-in-flow}

L'enregistrement suit un processus simple en trois étapes. Ouvrez **Enregistrement** depuis la [barre d'onglets ou la page Plus](../getting-started/navigating.md) pour commencer.

### Étape 1 : sélectionner un service {#step-1-select-a-service}

Lorsque vous ouvrez la page d'enregistrement, vous voyez la liste des services disponibles (par exemple « Dimanche matin » ou « Mercredi soir »). Chaque carte de service affiche son nom et, si votre église compte plusieurs sites, son campus.

Cliquez sur un service pour le sélectionner et passer à l'étape suivante.

### Étape 2 : sélectionner les membres du foyer et les groupes {#step-2-select-household-members-and-groups}

Après avoir sélectionné un service, vous voyez les membres de votre foyer sous **Qui est là**. Pour chaque personne présente :

1. Touchez le nom d'un membre du foyer pour développer sa fiche.
2. Vous verrez les **heures de service** disponibles pour le service sélectionné. Si votre église a défini un calendrier d'enregistrement pour une heure de service, vous ne pouvez la choisir que pendant que l'enregistrement est ouvert (par exemple, à partir de 30 minutes avant le service jusqu'à peu de temps après sa fin). En dehors de cette fenêtre, l'heure de service est listée comme **Fermé**, avec l'heure d'ouverture si elle est connue -- par exemple **Fermé · ouvre dim 9 h 30**.
3. Touchez **Choisir un groupe** à côté d'une heure de service pour sélectionner le groupe dans lequel la personne doit s'enregistrer (par exemple « Culte principal », « Salle des enfants 1 » ou « Groupe de jeunes »).
4. Répétez l'opération pour chaque membre du foyer présent.

Vous n'êtes pas obligé d'enregistrer chaque membre du foyer -- développez et attribuez des groupes uniquement aux personnes réellement présentes.

### Étape 3 : confirmation {#step-3-confirmation}

Une fois les groupes sélectionnés pour toutes les personnes présentes, touchez le bouton au bas de la page. Il indique le nombre de personnes sélectionnées -- par exemple **Enregistrer 1 personne** ou **Enregistrer 3 personnes**.

Vous verrez une confirmation indiquant que votre enregistrement est terminé et que votre présence a été enregistrée. Après un moment, la page revient à la liste des services, prête pour le prochain enregistrement.

Si votre église imprime des étiquettes de nom à une borne d'enregistrement, vous verrez plutôt **Vous êtes enregistré !** avec un code QR et un code de sécurité. Présentez le code à une borne d'enregistrement pour imprimer vos étiquettes de nom, puis touchez **Terminé**. Sur une borne B1 Checkin, touchez **Scanner le code** et présentez le code QR devant la caméra -- consultez [Impression des étiquettes pour un enregistrement par téléphone](../../b1-checkin/check-in/looking-up-members#printing-labels-for-a-phone-check-in).

Si votre foyer est déjà enregistré pour le service que vous sélectionnez, un lien **Afficher le code d'enregistrement** apparaît à côté du titre **Qui est là**. Touchez-le pour faire réapparaître le code QR et le code de sécurité -- par exemple, si vous avez fermé la page avant d'atteindre une borne d'enregistrement.

:::tip
Si vous devez modifier une sélection de groupe avant de terminer l'enregistrement, touchez le bouton **Modifier** à côté de n'importe quelle heure de service pour choisir un autre groupe.
:::

## Bon à savoir {#things-to-know}

- Vous ne pouvez enregistrer que les membres du foyer liés à votre compte. Si un membre de la famille manque, demandez à votre administrateur d'église de l'ajouter à votre foyer.
- Si aucun service n'apparaît sur la page d'enregistrement, votre église n'a peut-être aucun service configuré pour l'enregistrement pour le moment.
- Si vous sélectionnez un service et voyez un message comme « L'enregistrement ouvre dim 9 h 30. » (ou « L'enregistrement n'est pas ouvert pour ce service en ce moment. »), aucune des heures de ce service n'est actuellement dans sa fenêtre d'enregistrement. Réessayez lorsque l'enregistrement ouvrira.
- Si votre foyer s'est enregistré pour une heure de service antérieure, vous pouvez revenir vous enregistrer pour une heure de service ultérieure dès qu'elle ouvre, même après la fermeture de la précédente.
- Si une salle que vous avez choisie est pleine ou fermée, vous verrez le message « Une salle que vous avez choisie est pleine ou fermée pour l'enregistrement. Veuillez voir un bénévole. »

:::warning
L'enregistrement n'est disponible que si votre église a des services actifs configurés. Si aucun service ne figure dans la liste, vérifiez auprès du bureau de votre église si l'enregistrement autonome est activé.
:::
