# Auto-enregistrement

<div class="article-intro">

Le processus d'auto-enregistrement vous permet d'enregistrer votre présence pour vous et votre ménage en quelques étapes seulement. C'est une alternative rapide à l'utilisation d'un kiosque physique à l'église.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être [connecté](../getting-started/logging-in.md) à votre compte B1.church.
- Les membres de votre ménage doivent être liés à votre compte. Si un membre de la famille est manquant, demandez à l'administrateur de votre église de l'ajouter à votre ménage.

</div>

## Le flux d'enregistrement

L'enregistrement suit un processus simple en trois étapes. Accédez à l'onglet **Enregistrement** dans la [barre latérale](../getting-started/navigating.md) pour commencer.

### Étape 1 : Sélectionnez un service

Lorsque vous ouvrez la page d'enregistrement, vous verrez une liste des services disponibles (par exemple, « Dimanche matin » ou « Mercredi soir »). Chaque carte de service affiche le nom du service et le campus si votre église a plusieurs emplacements.

Cliquez sur un service pour le sélectionner et passer à l'étape suivante.

### Étape 2 : Sélectionnez les membres du ménage et les groupes

Après avoir sélectionné un service, vous verrez une liste de vos membres du ménage. Pour chaque personne qui assiste :

1. Appuyez sur un membre du ménage pour développer son entrée.
2. Vous verrez les **créneaux horaires du service** disponibles pour le service que vous avez sélectionné.
3. Cliquez sur **Sélectionner un groupe** à côté d'un créneau horaire pour choisir le groupe dans lequel la personne doit être enregistrée (tel que « Culte principal », « Salle pour enfants 1 » ou « Groupe de jeunes »).
4. Répétez pour chaque membre du ménage qui assiste.

Vous n'êtes pas obligé d'enregistrer chaque membre du ménage -- développez et assignez simplement les groupes pour les personnes qui sont réellement présentes.

### Étape 3 : Confirmation

Une fois que vous avez sélectionné les groupes pour tous ceux qui assistent, cliquez sur le bouton **Terminer l'enregistrement** au bas de la page.

Vous verrez une confirmation que votre enregistrement est complet et que votre présence a été sauvegardée. Après un moment, la page revient à la liste des services, prête pour le prochain enregistrement.

Si votre église imprime des badges au point d'enregistrement, vous voyez à la place **Vous êtes enregistré !** avec un code QR et un code de sécurité. Montrez le code au point d'enregistrement pour imprimer vos badges, puis appuyez sur **Terminé**. Au kiosque B1 Checkin, appuyez sur **Scanner le code** et tenez le code QR face à la caméra -- consultez [Impression d'étiquettes pour un enregistrement par téléphone](../../b1-checkin/check-in/looking-up-members#printing-labels-for-a-phone-check-in).

Si votre ménage est déjà enregistré pour le service que vous sélectionnez, un bouton **Afficher le code d'enregistrement** apparaît au-dessus de votre liste de ménage. Appuyez dessus pour réafficher le code QR et le code de sécurité -- par exemple, si vous avez fermé la page avant d'atteindre un point d'enregistrement.

:::tip
Si vous devez modifier une sélection de groupe avant de terminer l'enregistrement, appuyez sur le bouton **Modifier** à côté de n'importe quel créneau horaire pour choisir un groupe différent.
:::

## Choses à savoir

- Vous ne pouvez enregistrer que les membres du ménage qui sont liés à votre compte. Si un membre de la famille est manquant, demandez à l'administrateur de votre église de l'ajouter à votre ménage.
- Si aucun service n'apparaît sur la page d'enregistrement, votre église n'a peut-être pas de services configurés pour l'enregistrement pour le moment.

:::warning
L'enregistrement n'est disponible que lorsque votre église a des services actifs configurés. Si vous ne voyez aucun service listé, vérifiez auprès du bureau de votre église pour confirmer si l'auto-enregistrement est activé.
:::
