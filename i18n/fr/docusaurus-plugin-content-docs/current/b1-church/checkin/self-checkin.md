# Pointage autonome

<div class="article-intro">

Le pointage autonome vous permet d'enregistrer votre présence, ainsi que celle de votre foyer, en quelques étapes seulement. C'est une solution rapide qui remplace la borne physique de l'église.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être [connecté](../getting-started/logging-in.md) à votre compte B1.church.
- Les membres de votre foyer doivent être liés à votre compte. Si un membre de la famille manque, demandez à l'administrateur de votre église de l'ajouter à votre foyer.

## La procédure de pointage {#the-check-in-flow}

Le pointage suit un processus simple en trois étapes. Ouvrez **Pointage** depuis la [barre d'onglets ou la page Plus](../getting-started/navigating.md) pour commencer.

### Étape 1 : Choisir un service {#step-1-select-a-service}

Lorsque vous ouvrez la page de pointage, vous voyez la liste des services disponibles (par exemple, « Dimanche matin » ou « Mercredi soir »). Chaque carte de service affiche son nom et le campus, si votre église compte plusieurs lieux.

Touchez un service pour le sélectionner et passer à l'étape suivante.

### Étape 2 : Choisir les membres du foyer et les groupes {#step-2-select-household-members-and-groups}

Après avoir sélectionné un service, vous voyez les membres de votre foyer sous **Présents**. Pour chaque personne qui participe :

1. Touchez le nom d'un membre du foyer pour développer sa fiche.
2. Vous verrez les **horaires de service** disponibles pour le service sélectionné. Si votre église a défini un calendrier de pointage pour un horaire de service, vous ne pouvez le choisir que pendant que le pointage est ouvert (par exemple, de 30 minutes avant le service jusqu'à peu après sa fin). En dehors de cette plage, l'horaire de service est listé comme **Fermé**, avec l'heure d'ouverture si elle est connue -- par exemple, **Fermé · ouvre dim. 9 h 30**.
3. Touchez **Choisir un groupe** à côté d'un horaire de service pour sélectionner le groupe dans lequel la personne doit être pointée (par exemple « Culte principal », « Salle enfants 1 » ou « Groupe jeunes »). Les groupes sont classés sous leurs titres de catégorie (**Groupes généraux** pour ceux sans catégorie). Touchez **Aucun groupe** pour effacer le choix, ou **Retour** pour revenir sans rien modifier.
4. Répétez l'opération pour chaque membre du foyer qui participe.

Vous n'avez pas à pointer tous les membres du foyer -- développez et attribuez des groupes seulement aux personnes réellement présentes.

Toute personne déjà pointée pour ce service aujourd'hui affiche un insigne **Déjà pointé** à côté de son nom.

### Étape 3 : Confirmation {#step-3-confirmation}

Une fois les groupes choisis pour toutes les personnes présentes, touchez le bouton au bas de la page. Il indique le nombre de personnes sélectionnées -- par exemple, **Pointer 1 personne** ou **Pointer 3 personnes**.

Si une personne sélectionnée a déjà été pointée pour ce service aujourd'hui, une fenêtre **Déjà pointé** la nomme d'abord. Touchez **Pointer à nouveau** pour mettre à jour ses groupes, ou **Annuler** pour revenir en arrière.

Vous voyez alors **Pointage terminé** avec une liste **Où se trouve chacun** qui indique le groupe (et l'horaire de service) dans lequel chaque personne a été pointée. Après un instant, la page revient à la liste des services, prête pour le pointage suivant.

Si votre église imprime des étiquettes de nom à un poste de pointage, vous voyez plutôt **Vous êtes pointé !** avec un code QR, un code de sécurité et la liste **Où se trouve chacun**. Présentez le code à un poste de pointage pour imprimer vos étiquettes de nom, puis touchez **Terminé**. À une borne B1 Checkin, touchez **Numériser le code** et présentez le code QR devant la caméra -- voir [Imprimer les étiquettes pour un pointage par téléphone](../../b1-checkin/check-in/looking-up-members.md#printing-labels-for-a-phone-check-in).

Si votre foyer est déjà pointé pour le service que vous avez choisi, un lien **Afficher le code de pointage** apparaît à côté du titre **Présents**. Touchez-le pour faire réapparaître le code QR et le code de sécurité -- par exemple, si vous avez fermé la page avant d'arriver à un poste de pointage.

:::tip
Si vous devez modifier un choix de groupe avant de terminer le pointage, touchez le bouton **Modifier** à côté de n'importe quel horaire de service pour choisir un autre groupe.
:::

## Points à savoir {#things-to-know}

- Vous ne pouvez pointer que les membres de votre foyer liés à votre compte. Si un membre de la famille manque, demandez à l'administrateur de votre église de l'ajouter à votre foyer.
- Si aucun service n'apparaît sur la page de pointage, votre église n'a peut-être aucun service configuré pour le pointage à ce moment-là.
- Si vous sélectionnez un service et voyez un message tel que « Le pointage ouvre dim. 9 h 30. » (ou « Le pointage n'est pas ouvert pour ce service pour le moment. »), aucun des horaires de ce service n'est actuellement dans sa plage de pointage. Réessayez lorsque le pointage ouvrira.
- Si votre foyer a été pointé pour un horaire de service antérieur, vous pouvez revenir pointer pour un horaire ultérieur une fois celui-ci ouvert, même si le précédent est déjà fermé.
- Si une salle que vous avez choisie est complète ou fermée, vous verrez le message « Une salle que vous avez choisie est complète ou fermée pour le pointage. Veuillez voir un bénévole. »
- Si une salle pour enfants ne compte pas assez de bénévoles pointés pour un autre enfant, vous verrez un message qui nomme la salle -- par exemple, « La salle enfants 1 n'a pas assez de bénévoles pour un autre enfant pour le moment. Veuillez choisir une autre salle ou voir un bénévole. »

:::warning
Le pointage n'est disponible que lorsque votre église a des services actifs configurés. Si aucun service ne figure dans la liste, vérifiez auprès du bureau de l'église si le pointage autonome est activé.
:::
