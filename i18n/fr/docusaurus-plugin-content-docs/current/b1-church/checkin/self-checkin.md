# Enregistrement automatique

<div class="article-intro">

Le processus d'enregistrement automatique vous permet de noter votre présence, ainsi que celle des membres de votre foyer, en quelques étapes seulement. C'est une solution rapide de remplacement de la borne physique située à l'église.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être [connecté](../getting-started/logging-in.md) à votre compte B1.church.
- Les membres de votre foyer doivent être liés à votre compte. Si un membre de la famille manque, demandez à l'administrateur de votre église de l'ajouter à votre foyer.

## Le déroulement de l'enregistrement

L'enregistrement suit un processus simple en trois étapes. Ouvrez **Enregistrement** depuis la [barre d'onglets ou la page Plus](../getting-started/navigating.md) pour commencer.

### Étape 1 : Sélectionner un service

Lorsque vous ouvrez la page d'enregistrement, vous voyez la liste des services disponibles (par exemple « Dimanche matin » ou « Mercredi soir »). Chaque carte de service affiche le nom du service et, si votre église compte plusieurs sites, le campus.

Cliquez sur un service pour le sélectionner et passer à l'étape suivante.

### Étape 2 : Sélectionner les membres du foyer et les groupes

Après avoir sélectionné un service, vous voyez les membres de votre foyer sous **Qui est là**. Pour chaque personne présente :

1. Touchez un membre du foyer pour développer sa fiche.
2. Vous voyez les **horaires de service** disponibles pour le service sélectionné. Si votre église a défini une période d'enregistrement pour un horaire, vous ne pouvez le choisir que pendant que l'enregistrement est ouvert (par exemple, à partir de 30 minutes avant le service jusqu'à peu de temps après sa fin). En dehors de cette période, l'horaire est indiqué comme **Fermé**, avec la date d'ouverture si elle est connue, par exemple **Fermé · ouvre dim. 9 h 30**.
3. Touchez **Sélectionner un groupe** à côté d'un horaire pour choisir le groupe dans lequel la personne doit être enregistrée (par exemple « Culte principal », « Salle des enfants 1 » ou « Groupe des jeunes »).
4. Répétez l'opération pour chaque membre du foyer présent.

Vous n'avez pas besoin d'enregistrer tous les membres du foyer. Développez et attribuez des groupes uniquement pour les personnes réellement présentes.

Toute personne déjà enregistrée pour ce service aujourd'hui affiche un badge **Déjà enregistré** à côté de son nom.

### Étape 3 : Confirmation

Une fois les groupes sélectionnés pour toutes les personnes présentes, touchez le bouton en bas de la page. Il indique le nombre de personnes sélectionnées, par exemple **Enregistrer 1 personne** ou **Enregistrer 3 personnes**.

Si une personne que vous avez sélectionnée est déjà enregistrée pour ce service aujourd'hui, une fenêtre **Déjà enregistré** la mentionne en premier. Touchez **Enregistrer à nouveau** pour mettre à jour ses groupes, ou **Annuler** pour revenir en arrière.

Vous recevez ensuite une confirmation indiquant que votre enregistrement est terminé et que votre présence a été enregistrée. Après un instant, la page revient à la liste des services, prête pour le prochain enregistrement.

Si votre église imprime des étiquettes de nom à une borne d'enregistrement, vous voyez à la place **Vous êtes enregistré !** avec un code QR et un code de sécurité. Présentez ce code à une borne d'enregistrement pour imprimer vos étiquettes, puis touchez **Terminé**. Sur une borne B1 Checkin, touchez **Scanner le code** et présentez le code QR devant la caméra. Voir [Impression des étiquettes pour un enregistrement par téléphone](../../b1-checkin/check-in/looking-up-members.md#printing-labels-for-a-phone-check-in).

Si votre foyer est déjà enregistré pour le service sélectionné, un lien **Afficher le code d'enregistrement** apparaît à côté du titre **Qui est là**. Touchez-le pour afficher à nouveau le code QR et le code de sécurité, par exemple si vous avez fermé la page avant d'arriver à une borne d'enregistrement.

:::tip
Si vous devez modifier la sélection d'un groupe avant de terminer l'enregistrement, touchez le bouton **Modifier** à côté de n'importe quel horaire de service pour choisir un autre groupe.
:::

## Bon à savoir

- Vous ne pouvez enregistrer que les membres du foyer liés à votre compte. Si un membre de la famille manque, demandez à l'administrateur de votre église de l'ajouter à votre foyer.
- Si aucun service n'apparaît sur la page d'enregistrement, votre église n'a peut-être configuré aucun service pour l'enregistrement pour le moment.
- Si vous sélectionnez un service et voyez un message tel que « L'enregistrement ouvre dim. 9 h 30. » (ou « L'enregistrement n'est pas ouvert pour ce service pour le moment. »), aucun des horaires de ce service ne se situe actuellement dans sa période d'enregistrement. Réessayez lorsque l'enregistrement sera ouvert.
- Si votre foyer s'est enregistré pour un horaire précédent, vous pouvez revenir vous enregistrer pour un horaire ultérieur dès son ouverture, même si le premier est déjà fermé.
- Si une salle que vous avez choisie est complète ou fermée, vous verrez le message « Une salle que vous avez choisie est complète ou fermée pour l'enregistrement. Veuillez vous adresser à un bénévole. »
- Si une salle pour enfants ne compte pas assez de bénévoles enregistrés pour accueillir un autre enfant, vous verrez un message qui nomme la salle, par exemple « La Salle des enfants 1 n'a pas assez de bénévoles pour accueillir un autre enfant pour le moment. Veuillez choisir une autre salle ou vous adresser à un bénévole. »

:::warning
L'enregistrement n'est disponible que si votre église a configuré des services actifs. Si vous ne voyez aucun service, vérifiez auprès du bureau de votre église si l'enregistrement automatique est activé.
:::
