# Enregistrement autonome

<div class="article-intro">

L'enregistrement autonome vous permet de noter votre présence, ainsi que celle de votre foyer, en quelques étapes seulement. C'est une alternative rapide à l'utilisation d'une borne physique à l'église.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être [connecté](../getting-started/logging-in.md) à votre compte B1.church.
- Les membres de votre foyer doivent être rattachés à votre compte. S'il manque un membre de la famille, demandez à votre administrateur d'église de l'ajouter à votre foyer.

</div>

## Le parcours d'enregistrement

L'enregistrement suit un processus simple en trois étapes. Ouvrez **Enregistrement** depuis la [barre d'onglets ou la page Plus](../getting-started/navigating.md) pour commencer.

### Étape 1 : choisir un service

Lorsque vous ouvrez la page d'enregistrement, vous voyez la liste des services disponibles (par exemple « Culte du dimanche matin » ou « Soirée du mercredi »). Chaque carte de service affiche son nom et, si votre église compte plusieurs sites, le site concerné.

Cliquez sur un service pour le sélectionner et passer à l'étape suivante.

### Étape 2 : choisir les membres du foyer et les groupes

Après avoir sélectionné un service, vous verrez les membres de votre foyer sous **Qui est là**. Pour chaque personne présente :

1. Appuyez sur un membre du foyer pour développer sa fiche.
2. Vous verrez les **créneaux de culte** disponibles pour le service choisi. Si votre église a défini un calendrier d'enregistrement pour un créneau, vous ne pouvez le choisir que pendant que l'enregistrement est ouvert (par exemple, de 30 minutes avant le culte jusqu'à peu de temps après sa fin). En dehors de cette fenêtre, le créneau est affiché comme **Fermé**, avec l'heure d'ouverture si elle est connue, par exemple **Fermé · ouvre dim. 9:30**.
3. Appuyez sur **Choisir un groupe** à côté d'un créneau de culte pour sélectionner le groupe dans lequel la personne doit être enregistrée (par exemple « Culte principal », « Salle enfants 1 » ou « Groupe jeunes »).
4. Répétez l'opération pour chaque membre du foyer présent.

Vous n'avez pas besoin d'enregistrer chaque membre du foyer : développez et affectez des groupes uniquement aux personnes réellement présentes.

### Étape 3 : confirmation

Une fois les groupes sélectionnés pour toutes les personnes présentes, appuyez sur le bouton en bas de la page. Il indique le nombre de personnes sélectionnées, par exemple **Enregistrer 1 personne** ou **Enregistrer 3 personnes**.

Vous verrez une confirmation indiquant que votre enregistrement est terminé et que votre présence a été enregistrée. Après un instant, la page revient à la liste des services, prête pour le prochain enregistrement.

Si votre église imprime des badges à une borne d'enregistrement, vous verrez plutôt **Vous êtes enregistré !** avec un QR code et un code de sécurité. Présentez ce code à une borne d'enregistrement pour imprimer vos badges, puis appuyez sur **Terminé**. Sur une borne B1 Checkin, appuyez sur **Scanner le code** et présentez le QR code devant la caméra ; voir [Imprimer les étiquettes pour un enregistrement par téléphone](../../b1-checkin/check-in/looking-up-members#printing-labels-for-a-phone-check-in).

Si votre foyer est déjà enregistré pour le service sélectionné, un lien **Afficher le code d'enregistrement** apparaît à côté du titre **Qui est là**. Appuyez dessus pour afficher à nouveau le QR code et le code de sécurité, par exemple si vous avez fermé la page avant d'arriver à une borne d'enregistrement.

:::tip
Si vous devez modifier un choix de groupe avant de finaliser l'enregistrement, appuyez sur le bouton **Modifier** à côté de n'importe quel créneau de culte pour choisir un autre groupe.
:::

## Points à connaître

- Vous ne pouvez enregistrer que les membres du foyer rattachés à votre compte. S'il manque un membre de la famille, demandez à votre administrateur d'église de l'ajouter à votre foyer.
- Si aucun service n'apparaît sur la page d'enregistrement, votre église n'a peut-être aucun service configuré pour l'enregistrement pour le moment.
- Si vous sélectionnez un service et qu'un message du type « L'enregistrement ouvre dim. 9:30. » (ou « L'enregistrement n'est pas ouvert pour ce service actuellement. ») s'affiche, aucun des créneaux de ce service n'est actuellement dans sa fenêtre d'enregistrement. Réessayez lorsque l'enregistrement sera ouvert.
- Si votre foyer s'est enregistré pour un créneau de culte antérieur, vous pouvez revenir vous enregistrer pour un créneau ultérieur une fois celui-ci ouvert, même si le précédent est déjà terminé.
- Si une salle que vous avez choisie est complète ou fermée, vous verrez le message « Une salle que vous avez choisie est complète ou fermée pour l'enregistrement. Veuillez consulter un bénévole. »

:::warning
L'enregistrement n'est disponible que lorsque votre église a des services actifs configurés. Si aucun service n'apparaît, vérifiez auprès du secrétariat de l'église si l'enregistrement autonome est activé.
:::
