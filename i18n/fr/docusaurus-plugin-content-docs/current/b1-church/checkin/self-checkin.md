# Auto-enregistrement

<div class="article-intro">

Le processus d'auto-enregistrement vous permet d'enregistrer votre présence, ainsi que celle de votre ménage, en quelques étapes seulement. C'est une alternative rapide à l'utilisation d'un kiosque physique à l'église.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être [connecté](../getting-started/logging-in.md) à votre compte B1.church.
- Les membres de votre ménage doivent être liés à votre compte. Si un membre de la famille manque, demandez à l'administrateur de votre église de l'ajouter à votre ménage.

</div>

## Le déroulement de l'enregistrement

L'enregistrement suit un processus simple en trois étapes. Ouvrez **Enregistrement** depuis la [barre d'onglets ou la page Plus](../getting-started/navigating.md) pour commencer.

### Étape 1 : Sélectionner un service

Lorsque vous ouvrez la page d'enregistrement, vous voyez la liste des services disponibles (par exemple « Dimanche matin » ou « Mercredi soir »). Chaque carte de service affiche le nom du service et le campus, si votre église a plusieurs sites.

Cliquez sur un service pour le sélectionner et passer à l'étape suivante.

### Étape 2 : Sélectionner les membres du ménage et les groupes

Après avoir sélectionné un service, vous verrez les membres de votre ménage sous **Présents**. Pour chaque personne présente :

1. Appuyez sur un membre du ménage pour développer sa ligne.
2. Vous verrez les **horaires** disponibles pour le service que vous avez sélectionné. Si votre église a défini un calendrier d'enregistrement pour un horaire, celui-ci n'apparaît que lorsque l'enregistrement est ouvert (par exemple, de 30 minutes avant le service jusqu'à peu après sa fin).
3. Appuyez sur **Sélectionner un groupe** à côté d'un horaire pour choisir le groupe dans lequel la personne doit être enregistrée (par exemple « Culte principal », « Salle des enfants 1 » ou « Groupe des jeunes »).
4. Répétez l'opération pour chaque membre du ménage présent.

Vous n'avez pas besoin d'enregistrer tous les membres du ménage -- développez et attribuez des groupes uniquement aux personnes réellement présentes.

### Étape 3 : Confirmation

Une fois les groupes sélectionnés pour toutes les personnes présentes, appuyez sur le bouton en bas de la page. Il indique le nombre de personnes sélectionnées -- par exemple **Enregistrer 1 personne** ou **Enregistrer 3 personnes**.

Vous verrez une confirmation indiquant que votre enregistrement est terminé et que votre présence a été enregistrée. Après un instant, la page revient à la liste des services, prête pour le prochain enregistrement.

Si votre église imprime des étiquettes de nom à une borne d'enregistrement, vous voyez à la place **Vous êtes enregistré !** avec un code QR et un code de sécurité. Présentez le code à une borne d'enregistrement pour imprimer vos étiquettes de nom, puis appuyez sur **Terminé**. Sur un kiosque B1 Checkin, appuyez sur **Scanner le code** et présentez le code QR devant la caméra -- voir [Impression des étiquettes pour un enregistrement par téléphone](../../b1-checkin/check-in/looking-up-members#printing-labels-for-a-phone-check-in).

Si votre ménage est déjà enregistré pour le service que vous sélectionnez, un lien **Afficher le code d'enregistrement** apparaît à côté du titre **Présents**. Appuyez dessus pour faire réapparaître le code QR et le code de sécurité -- par exemple, si vous avez fermé la page avant d'atteindre une borne d'enregistrement.

:::tip
Si vous devez modifier une sélection de groupe avant de finaliser l'enregistrement, appuyez sur le bouton **Modifier** à côté de n'importe quel horaire pour choisir un autre groupe.
:::

## Points à connaître

- Vous ne pouvez enregistrer que les membres du ménage liés à votre compte. Si un membre de la famille manque, demandez à l'administrateur de votre église de l'ajouter à votre ménage.
- Si aucun service n'apparaît sur la page d'enregistrement, votre église n'a peut-être configuré aucun service pour l'enregistrement pour le moment.
- Si vous sélectionnez un service et voyez « L'enregistrement n'est pas ouvert pour ce service pour le moment », aucun des horaires de ce service ne se situe actuellement dans sa fenêtre d'enregistrement. Réessayez plus près de l'heure du service.
- Si une salle que vous avez choisie est complète ou fermée, vous verrez « Une salle que vous avez choisie est complète ou fermée pour l'enregistrement. Veuillez consulter un bénévole. »

:::warning
L'enregistrement n'est disponible que lorsque votre église a configuré des services actifs. Si vous ne voyez aucun service, vérifiez auprès du secrétariat de votre église si l'auto-enregistrement est activé.
:::
