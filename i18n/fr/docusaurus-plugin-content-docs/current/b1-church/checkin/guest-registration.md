# Inscription des visiteurs

<div class="article-intro">

Si vous visitez une église pour la première fois, vous pouvez vous inscrire, vous et votre famille, comme visiteurs à l'aide de la page d'inscription des visiteurs. Cela crée un dossier dans le système de l'église afin que les bénévoles puissent vous enregistrer à votre arrivée.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Votre église doit avoir activé l'inscription QR des visiteurs. Si ce n'est pas le cas, la page affiche « L'inscription des visiteurs n'est pas activée pour cette église. »
- Scannez le code QR affiché sur la borne d'enregistrement, appuyez sur **Inscrivez-vous ici** sur la borne, ou recevez un lien d'un bénévole de l'église

</div>

## Fonctionnement de l'inscription des visiteurs

L'inscription des visiteurs est conçue pour les personnes qui n'ont pas encore de compte. Sur la borne d'enregistrement de l'église, appuyez sur **S'inscrire comme visiteur** pour afficher un code QR qui mène à la page d'inscription. Vous pouvez également recevoir le lien d'un bénévole ou d'un agent d'accueil, ou le trouver sur un dépliant ou sur le site web de l'église.

Vous n'avez pas de téléphone sous la main ? Dans la même fenêtre de code QR sur la borne, appuyez sur **Inscrivez-vous ici** pour remplir le formulaire directement sur la borne. Consultez [S'inscrire comme visiteur](../../b1-checkin/check-in/looking-up-members.md#registering-as-a-guest) pour savoir comment cela fonctionne sur la borne.

La page s'ouvre avec le titre **Inscription des visiteurs**. Si l'église a ajouté une photo d'en-tête, elle apparaît en haut de la page ; sinon, vous verrez une petite icône.

## Inscrire votre famille

1. **Scannez le code QR** sur la borne d'enregistrement ou ouvrez le lien d'inscription des visiteurs sur votre téléphone. (Si vous avez appuyé sur **Inscrivez-vous ici** sur la borne, le formulaire est déjà ouvert.)
2. Remplissez la carte **Contact principal**. Le **prénom** et le **nom** sont toujours obligatoires. Selon ce que demande votre église, vous pourriez également voir :
   - **Titre** (comme M., Mme, Dr ou Pasteur), placé devant le nom
   - **Courriel** et **Téléphone**
   - **Situation familiale**
   - **Adresse domiciliaire** -- **Adresse**, **Complément d'adresse**, **Ville**, **Province/État** et **Code postal**. Cette adresse est commune à toute la famille.
3. Le formulaire commence par une deuxième carte, **Membre de la famille 2**. Saisissez son prénom et son nom, ou appuyez sur le **X** dans le coin de la carte pour la supprimer si vous vous inscrivez seul.
4. Pour ajouter d'autres personnes, appuyez sur **Ajouter un membre de la famille**. La nouvelle carte reprend automatiquement le nom de famille du contact principal. Vous pouvez inscrire jusqu'à 10 personnes à la fois.
5. Si votre église le demande, la carte de chaque personne peut aussi comporter **Titre**, **Téléphone**, **Date de naissance**, **Sexe** et **Niveau scolaire**. Chaque carte après celle du contact principal peut également demander un **Rôle dans le foyer** -- **Conjoint**, **Enfant** ou **Autre** -- afin que l'église sache quel lien unit chaque personne au contact principal.
6. Si votre église inclut une case **Commentaires** sous les membres de la famille, utilisez-la pour partager tout ce que vous souhaitez que l'église sache (jusqu'à 1 000 caractères).
7. Appuyez sur **S'inscrire** pour soumettre le formulaire.

Les champs marqués d'un astérisque (`*`) sont obligatoires. Si l'un d'eux est laissé vide, le formulaire affiche « Veuillez remplir tous les champs obligatoires. » et rien n'est soumis tant que vous ne les avez pas complétés.

## Après l'inscription

Une fois le formulaire soumis, un écran de confirmation apparaît avec le message : « Inscription terminée -- Tout est en ordre ! Un membre du personnel vous enregistrera sous peu. »

Votre inscription crée des dossiers dans la base de données de l'église :

- Un **foyer** est créé à partir du nom de famille du contact principal, celui-ci en étant le chef de famille.
- Des **fiches de personne** sont créées pour chaque membre de la famille, avec le statut d'adhésion « Visiteur ». Chaque membre de la famille reçoit le rôle dans le foyer que vous avez choisi, ou **Autre** si aucun rôle n'a été demandé.
- Les commentaires que vous avez saisis sont enregistrés comme note sur la fiche du contact principal, afin que le personnel de l'église puisse les lire.
- Si l'église a choisi un groupe pour les nouveaux visiteurs, votre famille y est ajoutée. L'église peut également enregistrer automatiquement votre présence si vous vous inscrivez pendant l'un des horaires de service prévus de ce groupe.
- Un bénévole ou un administrateur de l'église peut ensuite enregistrer votre famille à l'aide de la borne [B1 Checkin](../../b1-checkin/check-in/looking-up-members.md).

:::info
Si vous vous réinscrivez avec le même prénom et le même courriel ou numéro de téléphone, les dossiers de l'église vous reconnaissent et réutilisent votre profil existant au lieu d'en créer un doublon. Toute autre personne est ajoutée comme nouvelle. Si vous êtes déjà inscrit, vous pouvez aussi simplement rechercher votre nom ou votre numéro de téléphone sur la borne.
:::

:::tip
Si le formulaire demande votre adresse courriel, la fournir permet à l'église de faire un suivi avec vous après votre visite.
:::
