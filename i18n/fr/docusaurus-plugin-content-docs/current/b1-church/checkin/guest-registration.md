# Enregistrement des invités

<div class="article-intro">

Si vous visitez une église pour la première fois, vous pouvez vous inscrire, vous et votre famille, en tant qu'invités à l'aide de la page d'enregistrement des invités. Cela crée un enregistrement dans le système de l'église afin que les bénévoles puissent vous enregistrer à votre arrivée.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Votre église doit avoir l'enregistrement des invités par code QR activé
- Scannez le code QR affiché au kiosque d'enregistrement, appuyez sur **S'inscrire ici** au kiosque, ou recevez un lien d'un bénévole de l'église

</div>

## Comment fonctionne l'enregistrement des invités

L'enregistrement des invités est conçu pour les visiteurs qui n'ont pas encore de compte. Au kiosque d'enregistrement de l'église, appuyez sur **S'inscrire en tant qu'invité** pour afficher un code QR qui renvoie à la page d'enregistrement. Vous pouvez également recevoir le lien d'un bénévole ou d'un accueillant.

Vous n'avez pas de téléphone à portée de main ? Dans la même fenêtre de code QR du kiosque, appuyez sur **S'inscrire ici** pour remplir le formulaire directement sur le kiosque. Consultez [Inscription en tant qu'invité](../../b1-checkin/check-in/looking-up-members#registering-as-a-guest) pour savoir comment cela fonctionne sur le kiosque.

## Inscription de votre famille

1. **Scannez le code QR** au kiosque d'enregistrement ou ouvrez le lien d'enregistrement des invités sur votre téléphone. (Si vous avez appuyé sur **S'inscrire ici** au kiosque, le formulaire est déjà ouvert.)
2. Le formulaire d'enregistrement des invités s'affiche avec des champs pour le **contact principal** :
   - **Prénom** (obligatoire)
   - **Nom** (obligatoire)
   - **Email** (optionnel)
   - **Téléphone** (optionnel)
3. Pour ajouter des **membres de la famille**, appuyez sur **Ajouter un membre de la famille** et entrez leur prénom et nom. Vous pouvez ajouter jusqu'à 10 membres de la famille.
4. Pour supprimer un membre de la famille, appuyez sur le bouton de suppression à côté de son nom.
5. Appuyez sur **S'inscrire** pour soumettre.

## Après l'inscription

Une fois que vous avez soumis le formulaire, un écran de confirmation apparaît avec le message : « Inscription terminée -- Vous êtes tous prêts ! Un membre du personnel vous enregistrera bientôt ».

Votre inscription crée des enregistrements dans la base de données de l'église :

- Un **ménage** est créé en utilisant le nom de famille du contact principal.
- Des **enregistrements de personnes** sont créés pour chaque membre de la famille avec un statut d'adhésion « Invité ».
- Un bénévole ou un administrateur de l'église peut ensuite vous enregistrer à l'aide du kiosque [B1 Checkin](../../b1-checkin/check-in/looking-up-members).

:::info
Si votre email correspond à un enregistrement existant dans la base de données de l'église, le système se lie à cet enregistrement au lieu de créer un doublon. Cela maintient les données de l'église propres.
:::

:::tip
Fournir votre adresse email aide l'église à vous suivre après votre visite. C'est optionnel mais recommandé.
:::
