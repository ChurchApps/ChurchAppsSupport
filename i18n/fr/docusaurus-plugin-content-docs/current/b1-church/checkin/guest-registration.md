# Inscription des invités

<div class="article-intro">

Si vous visitez une église pour la première fois, vous pouvez vous inscrire, vous et votre famille, comme invités à l'aide de la page d'inscription des invités. Cela crée une fiche dans le système de l'église afin que les bénévoles puissent pointer votre arrivée à votre venue.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- L'inscription des invités par code QR doit être activée dans votre église. Si ce n'est pas le cas, la page affiche « L'inscription des invités n'est pas activée pour cette église. »
- Numérisez le code QR affiché sur la borne de pointage, touchez **S'inscrire ici** sur la borne, ou recevez un lien d'un bénévole de l'église

</div>

## Fonctionnement de l'inscription des invités {#how-guest-registration-works}

L'inscription des invités s'adresse aux visiteurs qui n'ont pas encore de compte. Sur la borne de pointage de l'église, touchez **S'inscrire comme invité** pour afficher un code QR qui mène à la page d'inscription. Vous pouvez aussi recevoir le lien d'un bénévole ou d'un accueillant, ou le trouver sur un feuillet ou sur le site web de l'église.

Vous n'avez pas votre téléphone sous la main ? Dans la même fenêtre du code QR sur la borne, touchez **S'inscrire ici** pour remplir le formulaire sur la borne elle-même. Voir [S'inscrire comme invité](../../b1-checkin/check-in/looking-up-members.md#registering-as-a-guest) pour savoir comment cela fonctionne sur la borne.

La page s'ouvre avec le titre **Inscription des invités**. Si l'église a ajouté une photo d'en-tête, elle apparaît en haut de la page ; sinon, vous verrez une petite icône.

## Inscrire votre famille {#registering-your-family}

1. **Numérisez le code QR** à la borne de pointage ou ouvrez le lien d'inscription des invités sur votre téléphone. (Si vous avez touché **S'inscrire ici** sur la borne, le formulaire est déjà ouvert.)
2. Remplissez la carte du **contact principal**. Le **prénom** et le **nom** sont toujours obligatoires. Selon ce que demande votre église, vous pourriez aussi voir :
   - **Titre** (comme M., Mme, Dr ou Pasteur), devant le nom
   - **Courriel** et **Téléphone**
   - **État civil**
   - **Adresse domiciliaire** -- **Adresse**, **Adresse, ligne 2**, **Ville**, **Province** et **Code postal**. Elle est commune à toute la famille.
3. Le formulaire commence par une deuxième carte pour le **membre de la famille 2**. Saisissez son prénom et son nom, ou touchez le **X** dans le coin de la carte pour la retirer si vous vous inscrivez seul.
4. Pour ajouter d'autres personnes, touchez **Ajouter un membre de la famille**. La nouvelle carte reprend automatiquement le nom de famille du contact principal. Vous pouvez inscrire jusqu'à 10 personnes à la fois.
5. Si votre église le demande, la carte de chaque personne peut aussi comporter **Titre**, **Téléphone**, **Date de naissance**, **Genre** et **Niveau scolaire**. Chaque carte après celle du contact principal peut aussi demander un **Rôle dans le foyer** -- **Conjoint**, **Enfant** ou **Autre** -- afin que l'église sache quel est le lien de chaque personne avec le contact principal.
6. Si votre église comporte une case **Commentaires** sous les membres de la famille, utilisez-la pour partager ce que vous souhaitez que l'église sache (jusqu'à 1 000 caractères).
7. Touchez **S'inscrire** pour envoyer le formulaire.

Les champs marqués d'un astérisque (`*`) sont obligatoires. Chaque carte doit comporter un prénom et un nom -- si l'un d'eux manque, le formulaire affiche « Le prénom et le nom sont obligatoires pour chaque membre. » Si un autre champ obligatoire est laissé vide, il affiche « Veuillez remplir tous les champs obligatoires. » Rien n'est envoyé tant que vous ne les avez pas remplis.

## Après l'inscription {#after-registering}

Une fois le formulaire envoyé, un écran de confirmation apparaît avec le message : « Inscription terminée -- Vous êtes prêt ! Un membre du personnel vous pointera sous peu. »

Votre inscription crée des fiches dans la base de données de l'église :

- Un **foyer** est créé à partir du nom de famille du contact principal, celui-ci en étant le chef de famille.
- Des **fiches de personnes** sont créées pour chaque membre de la famille, avec le statut de membre « Visiteur ». Chaque membre de la famille reçoit le rôle dans le foyer que vous avez choisi, ou **Autre** si aucun rôle n'a été demandé.
- Les commentaires que vous avez saisis sont enregistrés comme une note sur la fiche du contact principal, afin que le personnel de l'église puisse les lire.
- Si l'église a choisi un groupe pour les nouveaux invités, votre famille y est ajoutée. L'église peut aussi enregistrer automatiquement votre présence si vous vous inscrivez pendant l'un des horaires de service prévus de ce groupe.
- Un bénévole ou un administrateur de l'église peut ensuite pointer l'arrivée de votre famille à l'aide de la borne [B1 Checkin](../../b1-checkin/check-in/looking-up-members.md).

:::info
Si vous vous réinscrivez avec le même prénom et le même courriel ou numéro de téléphone, les dossiers de l'église vous reconnaissent et réutilisent votre profil existant au lieu d'en créer un doublon. Toute autre personne est ajoutée comme nouvelle. Si vous vous êtes déjà inscrit, vous pouvez aussi simplement rechercher votre nom ou votre numéro de téléphone sur la borne.
:::

:::tip
Si le formulaire vous demande votre adresse courriel, la fournir aide l'église à faire un suivi après votre visite.
:::
