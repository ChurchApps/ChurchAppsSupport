# Inscription des invités

<div class="article-intro">

Si vous visitez une église pour la première fois, vous pouvez vous inscrire, ainsi que votre famille, en tant qu'invités à l'aide de la page d'inscription des invités. Cela crée une fiche dans le système de l'église afin que les bénévoles puissent vous enregistrer à votre arrivée.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Votre église doit avoir activé l'inscription des invités par QR code. Si ce n'est pas le cas, la page affiche « L'inscription des invités n'est pas activée pour cette église. »
- Scannez le QR code affiché sur la borne d'enregistrement, appuyez sur **S'inscrire ici** sur la borne, ou recevez un lien d'un bénévole de l'église

</div>

## Fonctionnement de l'inscription des invités

L'inscription des invités est conçue pour les visiteurs qui n'ont pas encore de compte. Sur la borne d'enregistrement de l'église, appuyez sur **S'inscrire en tant qu'invité** pour afficher un QR code qui mène à la page d'inscription. Vous pouvez aussi recevoir le lien d'un bénévole ou d'un accueillant, ou le trouver sur un prospectus ou sur le site web de l'église.

Vous n'avez pas votre téléphone sous la main ? Dans la même fenêtre de QR code de la borne, appuyez sur **S'inscrire ici** pour remplir le formulaire directement sur la borne. Voir [S'inscrire en tant qu'invité](../../b1-checkin/check-in/looking-up-members#registering-as-a-guest) pour savoir comment cela fonctionne sur la borne.

La page s'ouvre avec le titre **Inscription des invités**. Si l'église a ajouté une photo d'en-tête, elle apparaît en haut de la page ; sinon, vous verrez une petite icône.

## Inscrire votre famille

1. **Scannez le QR code** à la borne d'enregistrement ou ouvrez le lien d'inscription des invités sur votre téléphone. (Si vous avez appuyé sur **S'inscrire ici** sur la borne, le formulaire est déjà ouvert.)
2. Remplissez la carte **Contact principal**. Le **Prénom** et le **Nom** sont toujours obligatoires. Selon ce que demande votre église, vous pourriez aussi voir :
   - **E-mail** et **Téléphone** ;
   - **Situation familiale** ;
   - **Adresse du domicile** : **Adresse**, **Complément d'adresse**, **Ville**, **Région** (ou État) et **Code postal**. Cette adresse est commune à toute la famille.
3. Le formulaire commence par une seconde carte pour le **Membre de la famille 2**. Saisissez son prénom et son nom, ou appuyez sur la **croix** dans le coin de la carte pour la retirer si vous vous inscrivez seul.
4. Pour ajouter d'autres personnes, appuyez sur **Ajouter un membre de la famille**. La nouvelle carte reprend automatiquement le nom de famille du contact principal. Vous pouvez inscrire jusqu'à 10 personnes à la fois.
5. Si votre église le demande, la carte de chaque personne peut aussi comporter **Date de naissance**, **Genre** et **Classe**.
6. Si votre église inclut une zone **Commentaires** sous les membres de la famille, utilisez-la pour transmettre tout ce que vous souhaitez faire savoir à l'église (1 000 caractères maximum).
7. Appuyez sur **S'inscrire** pour envoyer le formulaire.

Les champs marqués d'un astérisque (`*`) sont obligatoires. Si certains sont laissés vides, le formulaire affiche « Veuillez remplir tous les champs obligatoires. » et rien n'est envoyé tant que vous ne les avez pas complétés.

## Après l'inscription

Une fois le formulaire envoyé, un écran de confirmation s'affiche avec le message : « Inscription terminée -- Tout est prêt ! Un membre du personnel vous enregistrera sous peu. »

Votre inscription crée des enregistrements dans la base de données de l'église :

- Un **foyer** est créé à partir du nom de famille du contact principal, avec ce dernier comme chef de foyer.
- Des **fiches de personnes** sont créées pour chaque membre de la famille, avec le statut de membre « Visiteur ».
- Les commentaires que vous avez saisis sont enregistrés comme une note sur la fiche du contact principal, afin que le personnel de l'église puisse la consulter.
- Si l'église a choisi un groupe pour les nouveaux invités, votre famille y est ajoutée. L'église peut aussi enregistrer automatiquement votre présence si vous vous inscrivez pendant un créneau de culte de ce groupe.
- Un bénévole ou un administrateur de l'église peut ensuite enregistrer votre famille à l'aide de la borne [B1 Checkin](../../b1-checkin/check-in/looking-up-members).

:::info
Chaque inscription crée un nouveau foyer : merci de n'inscrire votre famille qu'une seule fois. Si vous êtes déjà inscrit, recherchez votre nom ou votre numéro de téléphone sur la borne à la place.
:::

:::tip
Si le formulaire demande votre adresse e-mail, la fournir permet à l'église de faire un suivi après votre visite.
:::
