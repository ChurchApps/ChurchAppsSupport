# Inscription des visiteurs

<div class="article-intro">

Si vous visitez une église pour la première fois, vous pouvez vous inscrire, ainsi que votre famille, comme visiteurs à l'aide de la page d'inscription des visiteurs. Cela crée une fiche dans le système de l'église afin que les bénévoles puissent vous pointer à votre arrivée.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Votre église doit avoir activé l'inscription des visiteurs par code QR. Si ce n'est pas le cas, la page affiche « L'inscription des visiteurs n'est pas activée pour cette église. »
- Scannez le code QR affiché à la borne de pointage, appuyez sur **S'inscrire ici** sur la borne, ou recevez un lien d'un bénévole de l'église

</div>

## Fonctionnement de l'inscription des visiteurs

L'inscription des visiteurs est conçue pour les personnes qui n'ont pas encore de compte. Sur la borne de pointage de l'église, appuyez sur **S'inscrire comme visiteur** pour afficher un code QR qui mène à la page d'inscription. Vous pouvez aussi recevoir le lien d'un bénévole ou d'un accueillant, ou le trouver sur un dépliant ou sur le site web de l'église.

Vous n'avez pas votre téléphone sous la main ? Dans la même fenêtre de code QR sur la borne, appuyez sur **S'inscrire ici** pour remplir le formulaire directement sur la borne. Consultez [S'inscrire comme visiteur](../../b1-checkin/check-in/looking-up-members#registering-as-a-guest) pour savoir comment cela fonctionne sur la borne.

La page s'ouvre avec le titre **Inscription des visiteurs**. Si l'église a ajouté une photo d'en-tête, elle apparaît en haut de la page ; sinon, vous verrez une petite icône.

## Inscrire votre famille

1. **Scannez le code QR** à la borne de pointage ou ouvrez le lien d'inscription des visiteurs sur votre téléphone. (Si vous avez appuyé sur **S'inscrire ici** sur la borne, le formulaire est déjà ouvert.)
2. Remplissez la carte **Contact principal**. Le **prénom** et le **nom** sont toujours obligatoires. Selon ce que demande votre église, vous pourriez aussi voir :
   - **Courriel** et **Téléphone**
   - **État civil**
   - **Adresse domiciliaire** -- **Adresse**, **Ligne d'adresse 2**, **Ville**, **Province/État** et **Code postal**. Elle est commune à toute la famille.
3. Le formulaire commence par une deuxième carte, pour le **Membre de famille 2**. Saisissez son prénom et son nom, ou appuyez sur le **X** dans le coin de la carte pour la retirer si vous vous inscrivez seul.
4. Pour ajouter d'autres personnes, appuyez sur **Ajouter un membre de la famille**. La nouvelle carte reprend automatiquement le nom de famille du contact principal. Vous pouvez inscrire jusqu'à 10 personnes à la fois.
5. Si votre église les demande, la carte de chaque personne peut aussi comporter la **date de naissance**, le **genre** et le **niveau scolaire**.
6. Si votre église comporte une zone **Commentaires** sous les membres de la famille, utilisez-la pour communiquer tout ce que vous voulez que l'église sache (jusqu'à 1 000 caractères).
7. Appuyez sur **Inscrire** pour soumettre.

Les champs marqués d'un astérisque (`*`) sont obligatoires. Si l'un d'eux est vide, le formulaire affiche « Veuillez remplir tous les champs obligatoires. » et rien n'est soumis tant que vous ne les avez pas remplis.

## Après l'inscription

Une fois le formulaire soumis, un écran de confirmation apparaît avec le message : « Inscription terminée -- Tout est en ordre ! Un membre du personnel vous pointera sous peu. »

Votre inscription crée des fiches dans la base de données de l'église :

- Un **foyer** est créé à partir du nom de famille du contact principal, avec ce contact comme chef de foyer.
- Des **fiches de personnes** sont créées pour chaque membre de la famille, avec le statut de membre « Visiteur ».
- Les commentaires que vous avez saisis sont enregistrés comme note sur la fiche du contact principal, afin que le personnel de l'église puisse les lire.
- Si l'église a choisi un groupe pour les nouveaux visiteurs, votre famille y est ajoutée. L'église peut aussi enregistrer automatiquement votre présence si vous vous inscrivez pendant un des horaires de service planifiés de ce groupe.
- Un bénévole ou un administrateur de l'église peut ensuite pointer votre famille à l'aide de la borne [B1 Checkin](../../b1-checkin/check-in/looking-up-members).

:::info
Si vous vous inscrivez de nouveau avec le même prénom et le même courriel ou numéro de téléphone, les dossiers de l'église vous reconnaissent et réutilisent votre profil existant au lieu d'en ajouter un doublon. Toute autre personne est ajoutée comme nouvelle. Si vous vous êtes déjà inscrit, vous pouvez aussi simplement rechercher votre nom ou votre numéro de téléphone sur la borne.
:::

:::tip
Si le formulaire demande votre adresse courriel, la fournir aide l'église à faire un suivi après votre visite.
:::
