# Inscription des visiteurs

<div class="article-intro">

Si vous visitez une église pour la première fois, vous pouvez vous inscrire, ainsi que votre famille, comme visiteurs à l'aide de la page d'inscription des visiteurs. Cela crée une fiche dans le système de l'église afin que les bénévoles puissent vous enregistrer à votre arrivée.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Votre église doit avoir activé l'inscription des visiteurs par code QR. Si ce n'est pas le cas, la page affiche « L'inscription des visiteurs n'est pas activée pour cette église. »
- Scannez le code QR affiché à la borne d'enregistrement, appuyez sur **Inscrivez-vous ici** sur la borne, ou recevez un lien d'un bénévole de l'église

</div>

## Fonctionnement de l'inscription des visiteurs

L'inscription des visiteurs est conçue pour les visiteurs qui n'ont pas encore de compte. Sur la borne d'enregistrement de l'église, appuyez sur **Inscrire un visiteur** pour afficher un code QR qui mène à la page d'inscription. Vous pouvez aussi recevoir le lien d'un bénévole ou d'un accueillant, ou le trouver sur un dépliant ou sur le site web de l'église.

Vous n'avez pas de téléphone sous la main ? Dans la même fenêtre du code QR sur la borne, appuyez sur **Inscrivez-vous ici** pour remplir le formulaire sur la borne elle-même. Consultez [S'inscrire comme visiteur](../../b1-checkin/check-in/looking-up-members#registering-as-a-guest) pour savoir comment cela fonctionne sur la borne.

La page s'ouvre avec le titre **Inscription des visiteurs**. Si l'église a ajouté une photo d'en-tête, elle apparaît en haut de la page ; sinon, vous verrez une petite icône.

## Inscrire votre famille

1. **Scannez le code QR** à la borne d'enregistrement ou ouvrez le lien d'inscription des visiteurs sur votre téléphone. (Si vous avez appuyé sur **Inscrivez-vous ici** sur la borne, le formulaire est déjà ouvert.)
2. Remplissez la carte **Contact principal**. Le **prénom** et le **nom de famille** sont toujours obligatoires. Selon ce que demande votre église, vous pourriez aussi voir :
   - **E-mail** et **Téléphone**
   - **État civil**
   - **Adresse domiciliaire** -- **Adresse**, **Ligne d'adresse 2**, **Ville**, **Province** et **Code postal**. Elle est partagée par toute la famille.
3. Le formulaire commence avec une deuxième carte pour le **Membre de la famille 2**. Saisissez son prénom et son nom de famille, ou appuyez sur le **X** dans le coin de la carte pour la retirer si vous vous inscrivez seul.
4. Pour ajouter d'autres personnes, appuyez sur **Ajouter un membre de la famille**. La nouvelle carte remplit automatiquement le nom de famille du contact principal. Vous pouvez inscrire jusqu'à 10 personnes à la fois.
5. Si votre église les demande, la carte de chaque personne peut aussi comprendre **Date de naissance**, **Sexe** et **Niveau scolaire**.
6. Si votre église inclut une case **Commentaires** sous les membres de la famille, utilisez-la pour partager ce que vous souhaitez que l'église sache (jusqu'à 1 000 caractères).
7. Appuyez sur **S'inscrire** pour envoyer.

Les champs marqués d'un astérisque (`*`) sont obligatoires. Si l'un d'eux est laissé vide, le formulaire affiche « Veuillez remplir tous les champs obligatoires. » et rien n'est envoyé tant que vous ne les avez pas remplis.

## Après l'inscription

Une fois le formulaire envoyé, un écran de confirmation apparaît avec le message : « Inscription terminée -- Tout est prêt ! Un membre du personnel vous enregistrera sous peu. »

Votre inscription crée des fiches dans la base de données de l'église :

- Un **foyer** est créé à partir du nom de famille du contact principal, le contact principal en étant le chef.
- Des **fiches de personnes** sont créées pour chaque membre de la famille avec le statut de membre « Visiteur ».
- Les commentaires que vous avez saisis sont enregistrés comme note sur la fiche du contact principal, pour que le personnel de l'église puisse les lire.
- Si l'église a choisi un groupe pour les nouveaux visiteurs, votre famille y est ajoutée. L'église peut aussi enregistrer automatiquement votre présence si vous vous inscrivez pendant l'un des horaires de service planifiés de ce groupe.
- Un bénévole ou un administrateur de l'église peut ensuite enregistrer votre famille à l'aide de la borne [B1 Checkin](../../b1-checkin/check-in/looking-up-members).

:::info
Si vous vous inscrivez à nouveau avec le même prénom et le même e-mail ou numéro de téléphone, les dossiers de l'église vous reconnaissent et réutilisent votre profil existant au lieu d'en créer un doublon. Toute autre personne est ajoutée comme nouvelle. Si vous vous êtes déjà inscrit, vous pouvez aussi simplement rechercher votre nom ou votre numéro de téléphone sur la borne.
:::

:::tip
Si le formulaire demande votre adresse e-mail, la fournir aide l'église à faire un suivi après votre visite.
:::
