# Sermons

<div class="article-intro">

La page Sermons vous permet de parcourir et de regarder les sermons enregistrés de votre église. La bibliothèque de sermons de votre église est affichée selon l'apparence et la mise en page que votre église a configurées, de sorte que l'aspect général correspond à l'identité visuelle de votre église.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Aucune connexion n'est nécessaire pour consulter les sermons. La page Sermons est accessible à tous.
- Votre église doit avoir ajouté du contenu de sermons via son portail d'administration.

</div>

## Parcourir les sermons sur le site web {#browsing-sermons-on-the-website}

1. Accédez à la page **Sermons** depuis la navigation du site de votre église.
2. La page s'ouvre sur **Listes de lecture** : une carte pour chaque série de sermons de votre église, avec son image et son titre.
3. Cliquez sur une liste de lecture pour voir les sermons qu'elle contient, chacun avec son image et son titre.
4. Cliquez sur un sermon pour le lire sur la page.

Les boutons au-dessus de la liste (**Listes de lecture**, puis le nom de la liste, puis le titre du sermon) vous permettent de revenir d'une étape en arrière. Les sermons peuvent être des vidéos hébergées sur des plateformes comme YouTube, Vimeo ou Facebook.

Chaque sermon possède aussi sa propre page à l'adresse `/sermons/` suivie de l'identifiant du sermon, que vous pouvez partager ou ajouter à vos favoris. Elle affiche la vidéo, le nom de la série, le titre, la date et la description.

:::info Flux de podcast
Les sermons de votre église sont également publiés sous forme de flux de podcast (RSS). Les applications de podcast et les lecteurs de flux peuvent le trouver depuis la page de n'importe quel sermon.
:::

## Sermons dans le portail des membres {#sermons-in-the-member-portal}

L'écran **Sermons** du portail des membres (`/mobile/sermons`) est organisé en une seule page composée de sections :

- **Regarder le dernier** en haut ouvre le sermon le plus récent. Lorsque votre église est en direct, il devient **Regarder en direct** et ouvre la [diffusion en direct](./live-streaming.md).
- **Dernier** -- le sermon le plus récent avec son image, sa série, sa date et sa durée.
- **En direct** -- affiché lorsqu'une diffusion est en cours ou commence dans les 24 heures, avec l'horaire du prochain culte. Appuyez dessus pour ouvrir la diffusion.
- **Récents** -- les trois sermons suivants. Appuyez sur **Tous les sermons** pour voir chaque sermon, filtrer par année, ou rechercher dans les titres et descriptions de toutes les années.
- **Séries** -- les trois séries les plus récentes de votre église, avec le nombre de sermons de chacune. Appuyez sur **Toutes les séries** pour la liste complète, ou sur une série pour voir ses sermons.

Appuyez sur un sermon pour l'ouvrir. Appuyez sur l'image ou sur **Regarder le sermon** pour le lire, sur **Partager** pour envoyer un lien, ou sur **Ouvrir le lien** pour ouvrir la vidéo sur son site d'origine. Vous trouverez ensuite une section **À propos** avec la description, ainsi qu'une liste **Dans cette série** avec un lien **Toute la série**.

:::tip
Si vous cherchez une diffusion en direct plutôt qu'un sermon enregistré, consultez plutôt la page [Diffusion en direct](./live-streaming.md).
:::

## Disponibilité {#availability}

La page Sermons est disponible lorsque votre église a ajouté du contenu de sermons via son portail d'administration. Si vous ne voyez pas de lien **Sermons** dans la navigation de votre église, cette fonctionnalité n'est peut-être pas encore configurée. Contactez l'administrateur de votre église pour plus d'informations.
