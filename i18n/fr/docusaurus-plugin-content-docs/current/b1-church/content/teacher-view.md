# Vue enseignant pour les leçons

<div class="article-intro">
La vue enseignant offre une interface élargie, en plein écran, pour consulter le contenu des leçons avec des sections structurées. Elle facilite la navigation dans le matériel de leçon pour les enseignants et les responsables pendant le temps de classe.
</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Votre église doit avoir des leçons planifiées dans un plan. Consultez le guide de B1 Admin sur [la planification des leçons](../../b1-admin/serving/scheduling-lessons.md) pour plus de détails.
- Vous devez être affecté au plan ou avoir l'accès pour le consulter sur votre site B1.church.
</div>

## Ouvrir la vue enseignant

Pour accéder à la vue enseignant élargie d'une leçon :

1. Ouvrez **Plans** dans le portail des membres B1.church
2. Ouvrez le plan qui contient la leçon que vous voulez enseigner
3. Cliquez sur le bouton **Enseigner** en haut de la page du plan

La leçon s'ouvre dans une interface en plein écran optimisée pour l'enseignement.

:::tip
La vue enseignant est particulièrement utile lorsque vous projetez le contenu de la leçon sur un écran ou un téléviseur pour que la classe le voie, ou lorsque vous enseignez depuis une tablette.
:::

## Fonctionnalités de la vue enseignant

### Navigation par sections

La vue enseignant organise le contenu de la leçon en sections :

- Chaque grande section de la leçon apparaît dans son propre bloc titré
- Cliquez sur **Sections** en haut pour ouvrir la liste des sections, puis choisissez-en une pour y aller directement
- L'en-tête indique la section dans laquelle vous vous trouvez, par exemple « Section 2 sur 5 »
- La liste des sections facilite les allers-retours entre les différentes parties de la leçon
- Lorsque la leçon comporte plus d'une section, les boutons précédent et suivant, libellés avec les noms des sections voisines, restent épinglés au bas de l'écran pendant que vous faites défiler

### Contenu défilant

La zone de contenu principale affiche l'ensemble du matériel de la leçon :

- Faites défiler la leçon naturellement
- Pendant que vous défilez, l'en-tête se met à jour automatiquement pour correspondre à la section que vous consultez
- Tout le texte mis en forme, les images et les instructions s'affichent clairement

### Lecture des médias

Lorsque les leçons comportent des vidéos, des images ou d'autres médias :

- Cliquez sur n'importe quel élément multimédia pour l'ouvrir dans un lecteur contextuel
- Les vidéos se lisent dans un lecteur vidéo dédié avec les commandes habituelles
- Les images s'ouvrent dans une visionneuse plein écran
- Fermez le lecteur multimédia pour revenir au contenu de la leçon

### Ressources téléchargeables

Si la leçon comporte des fichiers téléchargeables (feuilles d'activités, pages à colorier, etc.) :

- Des boutons de téléchargement apparaissent pour chaque ressource, après la dernière section de la leçon
- Cliquez pour télécharger directement les fichiers sur votre appareil
- Les fichiers peuvent être des PDF, des images ou d'autres documents fournis par le créateur du contenu

## Utiliser la vue enseignant en classe

### Avant le cours

1. Ouvrez la leçon dans la vue enseignant avant le début du cours
2. Passez en revue toutes les sections et familiarisez-vous avec le contenu
3. Téléchargez les ressources imprimables dont vous avez besoin
4. Testez les vidéos et les médias pour vous assurer qu'ils se lisent correctement

### Pendant le cours

1. Gardez la vue enseignant ouverte sur votre appareil ou projetez-la sur un écran
2. Utilisez **Sections** pour passer d'une section à l'autre au fil de la leçon
3. Lancez les vidéos ou affichez les images au moment approprié
4. Faites défiler les instructions au besoin sans perdre votre place

### Sur un écran projeté

Lorsque vous projetez pour la classe :

- La mise en page plein écran supprime les distractions
- Un texte grand et lisible reste visible depuis le fond de la salle
- Cliquez sur les éléments multimédias pour montrer des vidéos ou des images à toute la classe
- Naviguez à l'aide d'une souris ou d'un pavé tactile sans fil

## Quitter la vue enseignant

Pour quitter la vue enseignant :

- Cliquez sur le bouton **Fermer** (X) dans le coin supérieur
- Ou appuyez sur la touche **Échap** de votre clavier
- Vous revenez à la vue de détail du plan

## Utilisation sur tablette et mobile

La vue enseignant fonctionne sur les tablettes et les appareils mobiles :

- **Tablettes** -- Idéales pour les enseignants qui veulent un guide de leçon portable
- **Téléphones** -- Également pris en charge, bien que l'écran plus petit soit moins idéal pour enseigner
- **Mode paysage** -- Offre la meilleure expérience de visionnement sur les appareils mobiles

## Différences avec la vue ordinaire des leçons

| Fonctionnalité | Vue ordinaire | Vue enseignant |
|---------|--------------|--------------|
| **Mise en page** | Compacte, intégrée au plan | Plein écran, vue dédiée |
| **Navigation** | Défilement seulement | Liste des sections + défilement avec un en-tête de section courante |
| **Médias** | Intégrés à la page | Lecteur contextuel pour un visionnement ciblé |
| **Espace à l'écran** | Affiche les autres éléments du plan | Maximisé pour le contenu de la leçon |
| **Idéal pour** | Parcourir et planifier | Enseigner et présenter |

## Bonnes pratiques

- **Préparez-vous à l'avance** -- Passez les leçons en revue dans la vue enseignant avant le cours pour vous familiariser avec la mise en page
- **Repérez les sections** -- Notez les sections qui contiennent les activités ou les discussions clés
- **Testez les médias** -- Assurez-vous que les vidéos et les images se chargent bien avant le cours
- **Téléchargez les ressources tôt** -- N'attendez pas le moment du cours pour télécharger les documents à imprimer
- **Utilisez un plus grand écran** -- Projetez ou utilisez une tablette pour la meilleure expérience d'enseignement

## Dépannage

### La leçon ne s'ouvre pas dans la vue enseignant

- Assurez-vous que la leçon a bien été planifiée dans le plan
- Vérifiez que vous avez l'autorisation de consulter le plan
- Actualisez la page et réessayez

### Les vidéos ne se lisent pas

- Vérifiez votre connexion Internet
- Assurez-vous que votre appareil autorise la lecture des médias
- Essayez d'ouvrir la vidéo dans un autre onglet
- Certains fournisseurs de contenu peuvent imposer des restrictions de lecture

### Le contenu est coupé sur mobile

- Tournez votre appareil en mode paysage
- Réduisez légèrement le zoom si nécessaire
- Envisagez d'utiliser une tablette ou un appareil plus grand pour une meilleure lisibilité
