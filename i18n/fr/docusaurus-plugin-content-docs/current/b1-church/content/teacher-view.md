# Vue enseignant pour les leçons

<div class="article-intro">
La Vue enseignant fournit une interface agrandie en plein écran pour consulter le contenu des leçons avec des sections structurées, facilitant la navigation dans les matériels pédagogiques pour les enseignants et les animateurs pendant le cours.
</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Votre église doit avoir des leçons programmées dans un plan. Consultez le guide B1 Admin sur [Planifier les leçons](../../b1-admin/serving/scheduling-lessons.md) pour plus de détails.
- Vous devez être affecté au plan ou avoir accès pour le consulter sur votre site B1.church.
</div>

## Ouvrir la Vue enseignant

Pour accéder à la vue enseignant agrandie pour une leçon :

1. Accédez à la section **Plans** sur B1.church
2. Ouvrez le plan qui contient la leçon que vous voulez enseigner
3. Ouvrez l'onglet **Ordre de service**
4. Cliquez sur le bouton **Enseigner**

La leçon s'ouvrira dans une interface en plein écran optimisée pour l'enseignement.

:::tip
La Vue enseignant est particulièrement utile lorsque vous projetez le contenu des leçons sur un écran ou une télévision pour que la classe voie, ou lorsque vous enseignez à partir d'une tablette.
:::

## Fonctionnalités de la Vue enseignant

### Navigation par onglets

La vue enseignant organise le contenu des leçons en sections en utilisant des onglets en haut :

- Chaque section principale de la leçon apparaît comme un onglet séparé
- Cliquez sur n'importe quel onglet pour aller directement à cette section
- La section active est mise en évidence dans la barre d'onglets
- Les onglets facilitent la navigation entre différentes parties de la leçon

### Contenu défilable

La zone de contenu principal affiche tous les matériels pédagogiques :

- Parcourez la leçon naturellement
- Lors du défilement, l'onglet actif se met à jour automatiquement pour correspondre à la section que vous consultez
- Tout le texte formaté, les images et les instructions s'affichent clairement

### Lecture multimédia

Lorsque les leçons incluent des vidéos, des images ou d'autres médias :

- Cliquez sur n'importe quel élément multimédia pour l'ouvrir dans un lecteur contextuel
- Les vidéos sont lues dans un lecteur vidéo dédié avec des commandes standard
- Les images s'ouvrent dans une galerie pour une visualisation en plein écran
- Fermez le lecteur multimédia pour revenir au contenu de la leçon

### Ressources téléchargeables

Si la leçon inclut des fichiers téléchargeables (feuilles d'activité, pages à colorier, etc.) :

- Des boutons de téléchargement apparaissent pour chaque ressource
- Cliquez pour télécharger les fichiers directement sur votre appareil
- Les fichiers peuvent inclure des PDF, des images ou d'autres matériels fournis par le créateur de contenu

## Utiliser la Vue enseignant en classe

### Avant le cours

1. Ouvrez la leçon en Vue enseignant avant le début du cours
2. Examinez toutes les sections et familiarisez-vous avec le contenu
3. Téléchargez les ressources imprimables dont vous avez besoin
4. Testez les vidéos ou les médias pour vous assurer qu'ils se lisent correctement

### Pendant le cours

1. Gardez la Vue enseignant ouverte sur votre appareil ou projetez-la sur un écran
2. Utilisez les onglets pour passer d'une section à l'autre au fur et à mesure que vous progressez dans la leçon
3. Lisez des vidéos ou affichez des images aux moments opportuns
4. Parcourez les instructions selon vos besoins sans perdre votre place

### Sur un écran projeté

Lors de la projection pour la classe :

- La disposition en plein écran élimine les distractions
- Le texte grand et lisible rend le contenu visible de partout dans la salle
- Cliquez sur les éléments multimédia pour afficher des vidéos ou des images à toute la classe
- Naviguez à l'aide d'une souris sans fil ou d'un pavé tactile

## Fermer la Vue enseignant

Pour quitter la vue enseignant :

- Cliquez sur le bouton **Fermer** (X) dans le coin supérieur
- Ou appuyez sur la touche **Échap** de votre clavier
- Vous reviendrez à la vue des détails du plan

## Utilisation sur mobile et tablette

La Vue enseignant fonctionne sur les tablettes et appareils mobiles :

- **Tablettes** -- Parfait pour les enseignants qui veulent un guide de leçon portable
- **Téléphones** -- Également pris en charge, bien que le petit écran puisse être moins idéal pour l'enseignement
- **Mode paysage** -- Offre la meilleure expérience de visualisation sur les appareils mobiles

## Différences par rapport à la vue de leçon régulière

| Fonctionnalité | Vue normale | Vue enseignant |
|---------|--------------|--------------|
| **Disposition** | Compacte, intégrée au plan | Plein écran, vue dédiée |
| **Navigation** | Défilement uniquement | Onglets + défilement avec mise en évidence automatique |
| **Média** | Intégré à la page | Lecteur contextuel pour une visualisation concentrée |
| **Espace d'écran** | Affiche les autres éléments du plan | Maximisé pour le contenu des leçons |
| **Mieux adapté à** | La navigation et la planification | L'enseignement et la présentation |

## Meilleures pratiques

- **Préparez-vous à l'avance** -- Examinez les leçons en Vue enseignant avant le cours pour vous familiariser avec la disposition
- **Signet les sections** -- Notez les onglets qui contiennent des activités clés ou des discussions
- **Testez les médias** -- Assurez-vous que les vidéos et les images se chargent correctement avant le cours
- **Téléchargez les ressources tôt** -- N'attendez pas le moment du cours pour télécharger les documents imprimables
- **Utilisez un écran plus grand** -- Projetez ou utilisez une tablette pour la meilleure expérience d'enseignement

## Dépannage

### La leçon ne s'ouvre pas en Vue enseignant

- Assurez-vous que la leçon a été correctement programmée dans le plan
- Vérifiez que vous avez la permission de consulter le plan
- Actualisez la page et réessayez

### Les vidéos ne se lisent pas

- Vérifiez votre connexion Internet
- Assurez-vous que votre appareil autorise la lecture multimédia
- Essayez d'ouvrir la vidéo dans un onglet séparé
- Certains fournisseurs de contenu peuvent avoir des restrictions sur la lecture vidéo

### Le contenu semble coupé sur mobile

- Faites pivoter votre appareil en mode paysage
- Réduisez légèrement le zoom si nécessaire
- Envisagez d'utiliser une tablette ou un appareil plus grand pour une meilleure visibilité
