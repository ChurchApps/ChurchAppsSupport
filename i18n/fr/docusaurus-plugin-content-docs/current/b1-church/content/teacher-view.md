# Vue enseignant pour les leçons

<div class="article-intro">
La vue Enseignant offre une interface plein écran élargie pour afficher le contenu des leçons avec des sections structurées, ce qui facilite la navigation des enseignants et des responsables dans le matériel de leçon pendant le temps de classe.
</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Votre église doit avoir des leçons planifiées dans un plan. Consultez le guide de B1 Admin sur [la planification des leçons](../../b1-admin/serving/scheduling-lessons.md) pour plus de détails.
- Vous devez être assigné au plan ou avoir l'accès pour le consulter sur votre site B1.church.
</div>

## Ouvrir la vue Enseignant

Pour accéder à la vue enseignant élargie d'une leçon :

1. Ouvrez **Plans** dans le portail membre B1.church
2. Ouvrez le plan qui contient la leçon que vous voulez enseigner
3. Cliquez sur le bouton **Enseigner** en haut de la page du plan

La leçon s'ouvre dans une interface plein écran optimisée pour l'enseignement.

:::tip
La vue Enseignant est particulièrement utile lorsque vous projetez le contenu de la leçon sur un écran ou un téléviseur pour que la classe le voie, ou lorsque vous enseignez à partir d'une tablette.
:::

## Fonctionnalités de la vue Enseignant

### Navigation par section

La vue enseignant organise le contenu de la leçon en sections :

- Chaque grande section de la leçon apparaît comme un bloc avec son titre
- Cliquez sur **Sections** en haut pour ouvrir la liste des sections, puis choisissez-en une pour y accéder directement
- L'en-tête indique la section dans laquelle vous vous trouvez, par exemple « Section 2 sur 5 »
- La liste des sections permet de passer facilement d'une partie de la leçon à une autre
- Lorsque la leçon comporte plus d'une section, des boutons précédent et suivant, libellés avec le nom des sections voisines, restent épinglés au bas de l'écran pendant que vous faites défiler

### Contenu défilant

La zone de contenu principale affiche l'ensemble du matériel de leçon :

- Faites défiler la leçon naturellement
- Au fil du défilement, l'en-tête se met à jour automatiquement pour correspondre à la section que vous consultez
- Tout le texte mis en forme, les images et les instructions sont affichés clairement

### Lecture des médias

Lorsque les leçons comprennent des vidéos, des images ou d'autres médias :

- Cliquez sur n'importe quel élément multimédia pour l'ouvrir dans un lecteur contextuel
- Les vidéos se lisent dans un lecteur vidéo dédié avec les commandes standard
- Les images s'ouvrent dans une visionneuse plein écran
- Fermez le lecteur multimédia pour revenir au contenu de la leçon

### Ressources téléchargeables

Si la leçon comprend des fichiers téléchargeables (feuilles d'activités, pages à colorier, etc.) :

- Des boutons de téléchargement apparaissent pour chaque ressource, après la dernière section de la leçon
- Cliquez pour télécharger directement les fichiers sur votre appareil
- Les fichiers peuvent être des PDF, des images ou d'autres documents fournis par le créateur du contenu

## Utiliser la vue Enseignant en classe

### Avant le cours

1. Ouvrez la leçon dans la vue Enseignant avant le début du cours
2. Parcourez toutes les sections et familiarisez-vous avec le contenu
3. Téléchargez les ressources imprimables dont vous avez besoin
4. Testez les vidéos et les médias pour vous assurer qu'ils se lisent correctement

### Pendant le cours

1. Gardez la vue Enseignant ouverte sur votre appareil ou projetez-la sur un écran
2. Utilisez **Sections** pour passer d'une section à l'autre au fil de la leçon
3. Lancez les vidéos ou affichez les images au moment approprié
4. Faites défiler les instructions au besoin sans perdre votre place

### Sur un écran projeté

Lorsque vous projetez pour la classe :

- La mise en page plein écran élimine les distractions
- Un texte grand et lisible reste visible depuis le fond de la salle
- Cliquez sur les éléments multimédias pour montrer les vidéos ou les images à toute la classe
- Naviguez avec une souris ou un pavé tactile sans fil

## Fermer la vue Enseignant

Pour quitter la vue enseignant :

- Cliquez sur le bouton **Fermer** (X) dans le coin supérieur
- Ou appuyez sur la touche **Échap** de votre clavier
- Vous revenez à la vue des détails du plan

## Utilisation sur mobile et tablette

La vue Enseignant fonctionne sur les tablettes et les appareils mobiles :

- **Tablettes** -- Idéales pour les enseignants qui veulent un guide de leçon portable
- **Téléphones** -- Également pris en charge, bien que le petit écran soit moins idéal pour enseigner
- **Mode paysage** -- Offre la meilleure expérience de visualisation sur les appareils mobiles

## Différences avec la vue normale de la leçon

| Fonctionnalité | Vue normale | Vue Enseignant |
|----------------|-------------|----------------|
| **Mise en page** | Compacte, intégrée au plan | Plein écran, vue dédiée |
| **Navigation** | Défilement seulement | Liste des sections + défilement avec un en-tête de section courante |
| **Médias** | Intégrés à la page | Lecteur contextuel pour une visualisation ciblée |
| **Espace d'écran** | Affiche les autres éléments du plan | Maximisé pour le contenu de la leçon |
| **Idéal pour** | Parcourir et planifier | Enseigner et présenter |

## Bonnes pratiques

- **Préparez-vous à l'avance** -- Consultez les leçons dans la vue Enseignant avant le cours pour vous familiariser avec la mise en page
- **Repérez les sections** -- Notez les sections qui contiennent les activités ou les discussions clés
- **Testez les médias** -- Assurez-vous que les vidéos et les images se chargent correctement avant le cours
- **Téléchargez les ressources tôt** -- N'attendez pas le moment du cours pour télécharger les documents à imprimer
- **Utilisez un plus grand écran** -- Projetez ou utilisez une tablette pour la meilleure expérience d'enseignement

## Dépannage

### La leçon ne s'ouvre pas dans la vue Enseignant

- Assurez-vous que la leçon a bien été planifiée dans le plan
- Vérifiez que vous avez l'autorisation de consulter le plan
- Actualisez la page et réessayez

### Les vidéos ne se lisent pas

- Vérifiez votre connexion Internet
- Assurez-vous que votre appareil autorise la lecture des médias
- Essayez d'ouvrir la vidéo dans un onglet séparé
- Certains fournisseurs de contenu peuvent imposer des restrictions de lecture sur leurs vidéos

### Le contenu est coupé sur mobile

- Faites pivoter votre appareil en mode paysage
- Réduisez légèrement le zoom si nécessaire
- Envisagez d'utiliser une tablette ou un appareil plus grand pour une meilleure visibilité
