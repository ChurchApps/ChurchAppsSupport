# Mes inscriptions

<div class="article-intro">

La page **Inscriptions** du portail des membres est votre espace central pour chaque événement auquel vous vous êtes inscrit. Vous pouvez y vérifier votre statut, régler un solde impayé, modifier les personnes qui participent et ce que vous avez commandé, ou annuler entièrement une inscription.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être [connecté](../getting-started/logging-in.md) — les inscriptions en tant qu'invité n'apparaissent pas ici
- Vous devez avoir au moins une inscription à un événement. Voir [S'inscrire à un événement](./registering.md).

</div>

## Voir vos inscriptions {#viewing-your-registrations}

Ouvrez la page **Moi** du portail des membres et appuyez sur **Inscriptions** dans la section **Demandes et inscriptions**. Les inscriptions de votre foyer sont réparties entre **À venir** et **Passées** (les trois plus récentes parmi les passées sont affichées ; appuyez sur **Toutes les passées** pour voir les autres). Chaque inscription affiche :

- Le **titre et la date de l'événement**, suivis des **membres** que vous avez inscrits
- Un **statut** — **Inscrit**, **En attente**, **Sur liste d'attente** ou **Annulé**, ou **Solde dû** si un montant reste à payer
- La ligne de paiement — soit le montant payé sur le total (par exemple, « Total : 25,00 $ / 25,00 $ »), soit « Solde dû 25,00 $ sur 25,00 $ » avec un bouton **Effectuer le paiement**

Si vous ne vous êtes encore inscrit à aucun événement, le message « Vous ne vous êtes inscrit à aucun événement. Revenez bientôt pour découvrir les prochains événements. » s'affiche.

## Effectuer un paiement {#completing-a-payment}

Un bouton **Effectuer le paiement** apparaît sur toute inscription présentant un solde impayé — le plus souvent après que vous avez été promu depuis une liste d'attente, ou lorsqu'une modification effectuée par le personnel a changé votre total.

1. Cliquez sur **Effectuer le paiement**.
2. Vérifiez le récapitulatif de la commande, choisissez une carte enregistrée ou saisissez-en une nouvelle, puis payez.
3. Une fois le solde réglé, l'inscription s'affiche comme **Inscrit**.

:::tip
Lorsqu'une place se libère pour vous sur une liste d'attente, le courriel envoyé par votre église contient un lien direct vers cette étape de paiement.
:::

## Modifier une inscription {#editing-a-registration}

Les projets changent. Cliquez sur **Modifier** sur une inscription pour ouvrir la boîte de dialogue **Modifier l'inscription**, où vous pouvez :

- Modifier le **prénom**, le **nom** et le **type de participant** de chaque membre
- Ajuster les **quantités de sélection** (options supplémentaires comme des t-shirts ou des repas)

Cliquez sur **Enregistrer** pour conserver vos modifications, ou sur **Retour** pour fermer sans enregistrer. Pour modifier vos coordonnées, contactez le secrétariat de votre église.

La capacité reste applicable lors de la modification — si un type de participant ou une option est depuis épuisé, il vous sera demandé d'en choisir un autre. L'enregistrement recalcule votre total ; si la modification laisse un solde dû, un bouton **Effectuer le paiement** apparaît sur la carte.

:::info
La modification ne débite jamais votre carte automatiquement. Si votre nouveau total est plus élevé, réglez la différence avec **Effectuer le paiement** ; s'il est plus bas, contactez votre église au sujet d'un remboursement — les remboursements sont traités par le personnel de l'église via son fournisseur de paiement.
:::

## Annuler une inscription {#canceling-a-registration}

1. Cliquez sur **Annuler l'inscription** sur la carte.
2. Dans la boîte de dialogue **Annuler l'inscription ?**, cliquez sur **Annuler l'inscription** pour confirmer — l'annulation ne peut pas être annulée. Cliquez sur **Conserver** pour la laisser telle quelle.

L'inscription reste dans votre liste, marquée **Annulé**.

Votre place est libérée immédiatement. Si l'événement a une liste d'attente, la personne suivante est promue automatiquement. Tout paiement que vous avez effectué n'est pas remboursé automatiquement — contactez le secrétariat de votre église au sujet des remboursements.
