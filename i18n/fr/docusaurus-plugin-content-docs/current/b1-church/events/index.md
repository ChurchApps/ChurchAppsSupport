# Événements

<div class="article-intro">

La section Événements de B1.church vous permet de consulter les prochains événements de l'église et de vous y inscrire directement depuis le site web. Lorsque votre église active les inscriptions pour un événement, vous pouvez vous inscrire vous-même et inscrire les membres de votre famille en quelques étapes — et pour les événements payants, choisir les types de participants et les options, appliquer des codes de réduction et payer en toute sécurité au moment de l'inscription.

</div>

## Consulter les événements {#browsing-events}

Les événements apparaissent sur le site web de votre église, soit dans un calendrier mensuel, soit sous forme de vignettes d'événements à venir. Cliquez sur un événement pour ouvrir sa propre page, qui affiche :

- **Photo de l'événement** -- Si l'église en a ajouté une.
- **Titre et description de l'événement** -- Ce dont il s'agit.
- **Quand** -- La date et l'heure de la prochaine occurrence, ou le modèle de répétition pour un événement récurrent.
- **Où** -- Les salles réservées pour l'événement, le cas échéant.
- **S'inscrire à cet événement** -- Un bouton qui vous mène au formulaire d'inscription. Affiché uniquement lorsque les inscriptions sont activées pour l'événement.
- **Ajouter à mon agenda** -- Télécharge l'événement sous forme de fichier de calendrier que vous pouvez ouvrir dans Google Agenda, Calendrier Apple, Outlook ou une autre application d'agenda.

Appuyez sur **Tous les événements** en haut de la page pour revenir en arrière. Au-dessus des vignettes d'événements à venir, un bouton **S'abonner** vous permet de copier le lien ICS de l'agenda complet ou de le télécharger, afin que les nouveaux événements apparaissent dans votre propre application d'agenda.

## État des inscriptions {#registration-status}

Lorsque vous ouvrez la page d'inscription d'un événement, ce que vous voyez dépend du moment et de la capacité :

- **Ouvertes** -- Le formulaire d'inscription apparaît, avec une barre indiquant le nombre de places prises (par exemple, « 4 / 50 places prises ») lorsque l'événement a une limite de capacité.
- **Inscriptions non ouvertes** -- La période d'inscription n'a pas encore commencé. La page indique la date d'ouverture, par exemple « Les inscriptions ouvrent le 16 nov. 2026. » Revenez à ce moment-là.
- **Fermées** -- La page indique « Inscriptions non ouvertes » et « Les inscriptions à cet événement sont terminées. » La date limite d'inscription est dépassée.
- **Événement complet** -- Toutes les places disponibles ont été prises : « Cet événement a atteint sa capacité de 50 personnes. »

:::tip
Si un événement est complet, vous pouvez peut-être tout de même rejoindre la **liste d'attente** lorsque votre église l'a activée -- vous recevrez automatiquement un courriel si une place se libère. Sinon, revenez plus tard : des places peuvent se libérer si quelqu'un annule.
:::

## Ce dont vous avez besoin {#what-you-need}

- Un compte B1.church (ou vous pouvez vous inscrire en tant qu'invité)
- Un accès au site web de B1.church de votre église
