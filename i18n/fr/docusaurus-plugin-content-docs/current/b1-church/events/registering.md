# Inscription aux Événements

<div class="article-intro">

Lorsque votre église active l'inscription pour un événement, vous pouvez vous inscrire via un processus simple étape par étape. Vous pouvez vous inscrire et ajouter des membres de la famille, que vous ayez un compte ou que vous visitiez en tant qu'invité. Pour les événements payants, vous choisissez un type de participant, ajoutez des suppléments facultatifs, appliquez un code de réduction, et payez de manière sécurisée à la fin.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Votre église doit avoir l'inscription aux événements activée pour l'événement
- La fenêtre d'inscription doit être ouverte (entre les dates d'ouverture et de fermeture définies par l'administrateur)

</div>

## Étape 1 : Entrez Vos Informations

1. À partir du calendrier de l'église, ouvrez l'événement auquel vous voulez vous inscrire et cliquez sur **S'inscrire à cet Événement**.
2. La page d'inscription se charge affichant le titre, la description et la date de l'événement.
3. Si vous êtes **connecté**, le formulaire affiche votre nom et confirme que vous vous inscrivez sous votre compte.
4. Si vous êtes un **invité** (pas connecté), remplissez :
   - **Prénom** (requis)
   - **Nom** (requis)
   - **Email** (requis)
   - **Téléphone** (facultatif)
5. Si l'événement a des types de participants (par exemple, Adulte et Enfant à des prix différents), choisissez **votre type d'inscription**. Chaque type affiche son prix, et les types épuisés s'affichent comme **Épuisé**.

:::info
Si l'événement a une limite de capacité, une barre de progression affiche combien de places restent. Si l'événement est plein et votre église a activé une liste d'attente, vous pouvez toujours compléter l'inscription pour rejoindre la liste d'attente — voir [Rejoindre une Liste d'Attente](#joining-a-waitlist) ci-dessous.
:::

## Étape 2 : Ajouter des Membres de la Famille

1. Si vous voulez inscrire des membres de la famille supplémentaires, entrez leur **Prénom** et **Nom** pour chaque personne.
2. Si l'événement a des types de participants, choisissez un type pour chaque personne que vous ajoutez.
3. Cliquez sur **Ajouter un Membre** pour ajouter plus de personnes (jusqu'à 10 au total).
4. Cliquez sur le bouton supprimer à côté de n'importe quel membre pour l'enlever de l'inscription.
5. Si vous ne vous inscrivez que vous-même, vous pouvez ignorer cette étape.

## Étape 3 : Choisissez les Options et Sélections (Si Offert)

Certains événements offrent des suppléments à prix facultatifs — T-shirts, repas, mises à niveau d'activités.

1. Si l'événement a des sélections, une étape **Options et Sélections** apparaît.
2. Utilisez les steppers de quantité pour choisir combien de chacun vous voulez. Les options gratuites s'affichent comme **Gratuit**, et les options limitées affichent combien reste.
