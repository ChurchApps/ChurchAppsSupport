# Inscription comme bénévole

<div class="article-intro">

Parcourez les postes de bénévolat disponibles et inscrivez-vous vous-même aux prochains services directement depuis B1.church. Les postes sont organisés par catégorie afin que vous puissiez rapidement repérer où l'aide est nécessaire et rejoindre une équipe.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Un compte B1.church -- vous devez être connecté pour vous inscrire
- L'administrateur de votre église doit avoir activé l'inscription personnelle sur au moins un poste

</div>

## Parcourir les postes disponibles {#browsing-available-positions}

1. Accédez à la page **Occasions de bénévolat** (`/volunteer`) sur le site B1.church de votre église. Dans le portail des membres, appuyez sur **S'inscrire pour servir** dans l'écran **Plans** pour ouvrir plutôt l'écran **Bénévolat**.
2. Vous verrez la liste des plans de service à venir qui comportent des postes de bénévolat ouverts. Si votre église n'affiche que la semaine suivante pour chaque type de plan, les semaines ultérieures apparaissent une fois la semaine en cours passée.
3. Chaque plan affiche le **nom du plan**, la **date du service** et les **horaires de service**, le nombre de places ouvertes (ou **Complet**), ainsi qu'une barre indiquant le nombre de postes pourvus. La date du service est la date civile réelle du plan, quel que soit le fuseau horaire depuis lequel vous consultez. Sur le site web, chaque poste ouvert est listé avec le nombre de places disponibles ; dans le portail des membres, appuyez sur **Places ouvertes** pour masquer les plans déjà complets.
4. Cliquez sur **Voir et s'inscrire** sur le site web (ou appuyez sur le plan dans le portail des membres) pour voir ses postes.

Au sein d'un plan, les postes sont regroupés par catégorie (par exemple, « Musiciens », « Accueil », « Ministère des enfants ») puis listés par nom. Chaque poste affiche :

- **Nom du poste** -- Le rôle que vous pourriez tenir (par exemple, « Batteur », « Accueillant », « Préposé au café »).
- **Description** -- Les détails du rôle, si l'administrateur en a fourni.
- **Places disponibles** -- Le nombre de places déjà pourvues et le nombre restant (par exemple, « 2 places restantes sur 2 » sur le site web, ou « 0 sur 2 pourvues » dans le portail des membres).
- **Personnes inscrites** -- Si votre église a activé l'option **Afficher les noms des bénévoles sur la page d'inscription** pour le plan, une ligne « Inscrits : » liste les noms des personnes déjà en service à ce poste. Les noms ne sont affichés que lorsque vous êtes connecté.

## S'inscrire {#signing-up}

1. Repérez un poste pour lequel vous souhaitez vous porter volontaire.
2. Cliquez sur le bouton **S'inscrire** à côté du poste.
3. Un message de confirmation apparaît : « Vous êtes inscrit ! Merci de votre engagement. » (dans le portail des membres : « Vous êtes inscrit ! »).
4. Le poste affiche désormais une étiquette verte **Vous êtes inscrit** (**Inscrit** dans le portail des membres) ainsi qu'un bouton **Retirer**.

:::info
Vous devez être connecté pour vous inscrire. Si vous n'êtes pas connecté, la page affiche « Connectez-vous pour vous inscrire à un poste. » avec un lien de connexion, et les boutons **S'inscrire** sont désactivés.
:::

## Retirer une inscription {#removing-a-signup}

Si vos disponibilités changent et que vous ne pouvez plus servir :

1. Repérez le poste auquel vous êtes inscrit -- il affiche une étiquette verte « Vous êtes inscrit ».
2. Cliquez sur le bouton **Retirer**.
3. Dans la boîte de dialogue **Vous retirer ?** (**Retirer l'inscription ?** dans le portail des membres), cliquez sur **Retirer** pour confirmer.
4. Un message confirme : « Vous avez été retiré de ce poste. » (dans le portail des membres : « Votre inscription a été retirée. »).

## Dates limites {#deadlines}

Votre administrateur d'église peut fixer une date limite d'inscription pour chaque plan. Cette date limite correspond à un nombre d'heures défini avant le premier horaire de service du plan -- par exemple, une date limite de 2 heures pour un service à 10 h ferme les inscriptions à 8 h ce matin-là. Une fois la date limite passée :

- Vous ne pouvez plus vous inscrire à de nouveaux postes.
- Vous ne pouvez plus retirer vos inscriptions existantes.
- Un message en haut du plan indique « La date limite d'inscription pour ce plan est passée. » (dans le portail des membres : « La date limite d'inscription est passée. »).

## Capacité des postes {#position-capacity}

Chaque poste a un nombre limité de places. Lorsque toutes les places sont pourvues :

- Le bouton du poste affiche **Complet** et est désactivé.
- Sur le site web, le poste indique « Les 2 places sont pourvues » (avec son nombre de places).
- Si quelqu'un retire son inscription, la place se libère à nouveau.

:::tip
Consultez régulièrement la page des bénévoles, surtout en début de semaine. Les postes les plus demandés se remplissent rapidement : vous inscrire tôt vous donne le plus grand choix.
:::
