# Inscription comme bénévole

<div class="article-intro">

Parcourez les postes de bénévole disponibles et inscrivez-vous vous-même aux services à venir directement depuis B1.church. Les postes sont organisés par catégorie pour que vous trouviez rapidement où l'aide est nécessaire et rejoigniez une équipe.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Un compte B1.church -- vous devez être connecté pour vous inscrire
- L'administrateur de votre église doit avoir activé l'auto-inscription sur au moins un poste

</div>

## Parcourir les postes disponibles

1. Rendez-vous sur la page **Bénévolat** du site B1.church de votre église.
2. Vous verrez la liste des plannings de service à venir comportant des postes de bénévole ouverts. Dans chaque planning, les postes sont listés par catégorie, puis par nom. Si votre église n'affiche que la semaine suivante de chaque type de planning, les semaines suivantes apparaissent une fois la semaine en cours passée.
3. Chaque planning affiche le **nom du planning**, la **date du service** et les **horaires de service**. La date du service est la date calendaire réelle du planning, quel que soit le fuseau horaire depuis lequel vous consultez la page.

Les postes sont regroupés par catégorie (par exemple « Musique », « Accueil », « Ministère des enfants »). Chaque poste affiche :

- **Nom du poste** -- Le rôle que vous pourriez tenir (par exemple « Batteur », « Accueillant », « Serveur de café »).
- **Description** -- Détails sur le rôle, si l'administrateur en a fourni.
- **Places disponibles** -- Une barre de progression indiquant combien de places sont pourvues et combien restent.
- **Inscrits** -- Si votre église a activé **Afficher les noms des bénévoles sur la page d'inscription** pour le planning, une ligne « Inscrits : » indique les noms des personnes déjà engagées à ce poste. Les noms ne sont affichés que lorsque vous êtes connecté.

## S'inscrire

1. Repérez le poste pour lequel vous souhaitez vous porter volontaire.
2. Cliquez sur le bouton **S'inscrire** à côté du poste.
3. Un message de confirmation apparaît : « Vous êtes inscrit ! Merci pour votre engagement. »
4. Le poste affiche désormais un indicateur vert confirmant votre inscription.

:::info
Vous devez être connecté pour vous inscrire. Si vous n'êtes pas connecté, il vous sera demandé de vous connecter d'abord.
:::

## Annuler une inscription

Si vos disponibilités changent et que vous ne pouvez plus servir :

1. Repérez le poste auquel vous êtes inscrit -- il affiche un indicateur vert « Vous êtes inscrit ».
2. Cliquez sur le bouton **Retirer**.
3. Confirmez que vous souhaitez vous retirer du poste.
4. Un message confirme : « Vous avez été retiré de ce poste. »

## Dates limites

L'administrateur de votre église peut fixer une date limite d'inscription pour chaque planning. Cette date limite correspond à un nombre d'heures fixe avant le premier horaire de service du planning -- par exemple, une date limite de 2 heures pour un service de 10 h 00 ferme les inscriptions à 8 h 00 ce matin-là. Une fois la date limite passée :

- Vous ne pouvez plus vous inscrire à de nouveaux postes.
- Vous ne pouvez plus retirer les inscriptions existantes.
- Un message en haut du planning indique que la date limite d'inscription est passée.

## Capacité des postes

Chaque poste dispose d'un nombre limité de places. Lorsque toutes les places sont pourvues :

- Le poste s'affiche comme **Complet**.
- Le bouton d'inscription est désactivé.
- Si quelqu'un retire son inscription, la place se libère à nouveau.

:::tip
Consultez régulièrement la page Bénévolat, surtout en début de semaine. Les postes populaires se remplissent vite : s'inscrire tôt vous laisse le meilleur choix.
:::
