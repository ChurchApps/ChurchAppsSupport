# Fichiers

<div class="article-intro">

La page Fichiers est le dépôt central de tous les médias et documents utilisés sur le site web de votre église. Vous pouvez y téléverser, parcourir et gérer chaque image, document et fichier multimédia dont votre site a besoin.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Terminez la [configuration initiale](./initial-setup.md) de votre site web
- Optimisez les images avant de les téléverser pour des temps de chargement des pages plus rapides
- Préparez vos fichiers dans les formats web courants (PNG, JPG, PDF, etc.)

</div>

## Téléverser des fichiers {#uploading-files}

1. Dans B1 Admin, ouvrez le [menu de navigation rapide](../introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche), développez **Site web**, puis cliquez sur **Fichiers**.
2. Cliquez sur **Téléverser des fichiers** en haut de la page, ou sur **Choisir un fichier** dans le panneau **Téléverser des fichiers** à droite, puis sélectionnez un fichier sur votre ordinateur.
3. Le fichier est téléversé dès que vous le sélectionnez et apparaît dans le tableau des fichiers.

Le panneau Téléverser des fichiers indique aussi l'espace de stockage utilisé. 100 Mo sont fournis gratuitement ; une fois ce quota atteint, les boutons de téléversement sont masqués jusqu'à ce que vous supprimiez des fichiers ou ajoutiez de l'espace. Pour en obtenir davantage, reliez votre propre Google Drive, Dropbox, OneDrive ou compartiment S3 dans **Paramètres**, à la section **Stockage des fichiers**. Les fichiers sont alors stockés dans votre compte relié, et le panneau affiche **Stocké dans votre compte relié**.

:::tip
Pour de meilleurs résultats, optimisez les images avant de les téléverser. Des fichiers plus légers aident votre site à se charger plus vite pour les visiteurs. Des outils comme TinyPNG ou Squoosh peuvent compresser les images sans perte de qualité visible.
:::

## Parcourir les fichiers {#browsing-files}

Le tableau des fichiers liste chaque fichier téléversé avec son **nom** et sa **taille**. Cliquez sur le nom d'un fichier pour l'ouvrir dans un nouvel onglet. Donnez aux fichiers des noms clairs et descriptifs avant de les téléverser afin que votre équipe les retrouve rapidement.

## Utiliser les fichiers sur votre site web {#using-files-on-your-website}

1. Repérez le fichier dans le tableau des fichiers.
2. Cliquez sur **Copier le lien** pour copier l'URL du fichier (le bouton devient **Copié**). Vous pouvez coller cette URL dans les éléments d'image, les liens de téléchargement, ou partout ailleurs où une URL de fichier est acceptée.
3. Les fichiers que vous téléversez ici sont disponibles pour toutes les pages de votre site web et tous les blocs de contenu.

:::info
Lorsque vous construisez des pages dans [Gérer les pages](./managing-pages.md), vous pouvez référencer n'importe quel fichier téléversé ici par son URL. Vos médias restent ainsi organisés à un seul endroit central.
:::

## Supprimer des fichiers {#deleting-files}

1. Repérez le fichier à retirer dans le tableau des fichiers.
2. Cliquez sur **Supprimer** à côté, puis confirmez pour le retirer définitivement de votre bibliothèque.
3. Assurez-vous que le fichier n'est utilisé sur aucune page avant de le supprimer, car cela casserait les liens ou images qui le référencent.

:::warning
Les fichiers supprimés ne peuvent pas être récupérés. Vérifiez deux fois qu'un fichier n'est plus utilisé sur aucune page avant de le retirer.
:::
