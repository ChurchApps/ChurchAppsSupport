# Site web

<div class="article-intro">

La section Site web de B1 Admin vous offre un créateur de sites complet pour votre église. Vous pouvez créer des pages, personnaliser l'allure de votre site, gérer les fichiers médias et publier des calendriers d'événements -- sans écrire aucun code.

</div>

## Ce que vous pouvez faire {#what-you-can-do}

Le créateur de sites est organisé autour de ces grands domaines :

### Pages {#pages}

Créez et gérez toutes les pages de votre site web d'église. Le tableau **Pages** liste chaque page -- les pages créées automatiquement par le système portent un insigne **Généré**, et les autres sont des pages personnalisées que vous avez créées. Vous pouvez ajouter de nouvelles pages personnalisées, modifier les pages existantes ou convertir des pages générées automatiquement en pages personnalisées pour un contrôle total de leur contenu.

Vos liens de navigation sont listés dans le panneau **Navigation principale**, à côté du tableau des pages. Vous pouvez réordonner et imbriquer les liens par glisser-déposer pour définir la hiérarchie et l'ordre exacts que les visiteurs verront. Voir [Gérer les pages](./managing-pages.md).

### Blogue {#blog}

Publiez des nouvelles, des mises à jour et des méditations sous forme de billets de blogue à `/blog` sur votre site, avec un flux RSS. Voir le guide [Blogue](./blog.md).

### Blocs {#blocks}

Créez des composants de contenu réutilisables que vous pouvez placer sur plusieurs pages. Les blocs vous font gagner du temps lorsqu'un contenu, comme un appel à l'action, une bannière d'annonce ou une section de contact, apparaît à plus d'un endroit. Mettez un bloc à jour une seule fois et la modification s'applique partout où il est utilisé. Voir [Blocs réutilisables](./blocks.md).

### Apparence {#appearance}

Personnalisez le thème, les couleurs, les polices, le logo et l'espacement de votre site web. Vous pouvez appliquer des thèmes de style prédéfinis pour un démarrage rapide, ou peaufiner chaque détail avec l'éditeur de palette de couleurs, les réglages typographiques et le CSS personnalisé. Voir le guide [Apparence](./appearance.md) pour tous les détails.

### Fichiers {#files}

Téléversez et gérez tous vos médias -- images, documents et autres fichiers -- à un seul endroit central, et copiez les liens des fichiers pour les utiliser n'importe où sur votre site. Voir [Fichiers](./files.md) pour plus d'informations.

### Calendriers {#calendars}

Publiez des calendriers d'événements sur votre site web afin que les visiteurs voient ce qui se passe dans votre église. Créez des calendriers organisés qui regroupent les événements de plusieurs groupes dans une seule vue. Les calendriers ont leur propre élément **Calendriers** dans le menu de B1 Admin, distinct de **Site web**.

:::tip
Commencez par la [configuration initiale](./initial-setup.md) si vous configurez votre site web pour la première fois. Elle vous guide pour la configuration du domaine, la création de votre première page et le réglage de l'apparence de votre site.
:::
