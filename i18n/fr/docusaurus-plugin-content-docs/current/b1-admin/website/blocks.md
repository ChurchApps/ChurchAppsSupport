# Blocs réutilisables

<div class="article-intro">

Les blocs sont des éléments de contenu de site web que vous créez une fois et réutilisez sur autant de pages que vous le souhaitez -- une bannière d'appel à l'action, une bande de coordonnées ou un panneau d'horaires de services. Lorsque vous modifiez un bloc, chaque page qui l'utilise affiche le changement.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin de l'autorisation de modifier le contenu du site web
- Utilisez un ordinateur ou une tablette ; l'éditeur de blocs est le même éditeur plein écran que celui des pages

</div>

## Ouvrir les blocs {#opening-blocks}

1. Dans B1 Admin, ouvrez le [menu de navigation rapide](../introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche) et développez **Site web**.
2. Cliquez sur **Blocs**. La page **Blocs réutilisables** liste chaque bloc avec son **nom** et son **type**.

Si votre église dispose de plusieurs sites web, utilisez le sélecteur de site en haut de la page pour voir les blocs de chaque site. Le pied de page de votre site est aussi un bloc, mais il se modifie depuis **Pied de page du site** dans [Apparence](./appearance.md) et n'est pas listé ici.

## Ajouter un bloc {#adding-a-block}

1. Cliquez sur **Ajouter un bloc**.
2. Saisissez un **nom** que votre équipe reconnaîtra.
3. Choisissez le **type de bloc** :
   - **Élément(s)** -- un ou plusieurs éléments (texte, images, boutons, etc.) que vous déposez à l'intérieur d'une section d'une page.
   - **Section(s)** -- une ou plusieurs sections complètes que vous déposez sur une page, entre ses autres sections.
4. Cliquez sur **Enregistrer**. Le bloc apparaît dans la liste.

## Construire le contenu d'un bloc {#building-a-blocks-content}

1. Cliquez sur le nom du bloc, ou sur **Modifier** dans sa ligne. Le bloc s'ouvre dans l'[éditeur de pages](./page-editor.md).
2. Ajoutez et mettez en forme le contenu comme vous le feriez sur une page, en commençant par une section.
3. Les modifications s'enregistrent automatiquement. Cliquez sur **Quitter** dans la barre d'outils pour revenir à la liste des blocs.

## Utiliser un bloc sur une page {#using-a-block-on-a-page}

1. Ouvrez une page dans l'[éditeur de pages](./page-editor.md) et cliquez sur **Ajouter du contenu**.
2. Sélectionnez l'onglet **Blocs** dans le panneau **Ajouter des éléments**. (L'onglet n'apparaît qu'une fois que vous avez au moins un bloc.)
3. Faites glisser le bloc sur la page : un bloc d'éléments dans une section, ou un bloc de sections entre les sections.

La page affiche le contenu actuel du bloc. Pour le modifier, éditez le bloc lui-même depuis la page **Blocs** ; chaque page qui l'utilise est mise à jour.

## Renommer ou supprimer un bloc {#renaming-or-deleting-a-block}

1. Cliquez sur **Renommer** dans la ligne du bloc.
2. Modifiez le **nom** ou le **type de bloc** et cliquez sur **Enregistrer**, ou cliquez sur **Supprimer** et confirmez pour retirer définitivement le bloc.

:::warning
Les pages qui utilisent un bloc supprimé n'affichent plus son contenu. Vérifiez vos pages avant de supprimer un bloc en cours d'utilisation.
:::
