# Apparence {#appearance}

<div class="article-intro">

La page Apparence vous permet de personnaliser l'allure générale de votre site web d'église. Des couleurs et polices à l'espacement et au CSS personnalisé, vous contrôlez chaque aspect visuel de votre site depuis un seul endroit.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Terminez la [configuration initiale](./initial-setup.md) de votre site web
- Ayez le logo de votre église au format PNG, avec un arrière-plan transparent et un rapport d'aspect de 4:1
- Connaissez les couleurs de marque de votre église (valeurs hexadécimales) si vous disposez d'un guide de style

</div>

## Accéder aux paramètres d'apparence {#accessing-appearance-settings}

1. Dans B1 Admin, ouvrez le [menu de navigation rapide](../introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche) et développez **Site web**.
2. Cliquez sur **Apparence**.
3. La page **Styles du site** s'ouvre. La carte **Thème, polices et pied de page** affiche la liste **Paramètres de style** à gauche et un aperçu d'un site exemple à droite. Sous elle se trouvent les cartes **Annonce et widgets** et **Redirections et analytique**.

## Palette de couleurs {#color-palette}

1. Cliquez sur **Palette de couleurs** dans le panneau Paramètres de style.
2. Vous verrez les **couleurs de base** (nuances claire, d'accent et foncée) et les **couleurs sémantiques** (Principale, Secondaire, Succès, Avertissement et Erreur).
3. Cliquez sur n'importe quelle pastille de couleur pour ouvrir le sélecteur de couleurs. Faites glisser le curseur ou saisissez une valeur hexadécimale pour choisir votre couleur.
4. L'**aperçu des combinaisons de couleurs** montre comment vos couleurs choisies fonctionnent ensemble.
5. Utilisez les **palettes suggérées** pour partir d'un schéma de couleurs prédéfini. Cliquer sur une palette charge simplement ses couleurs dans l'éditeur.
6. Cliquez sur **Enregistrer la palette** pour appliquer vos couleurs au site, ou sur **Annuler** pour les abandonner.

## Typographie {#typography}

1. Cliquez sur **Polices** dans le panneau Paramètres de style.
2. Cliquez sur le bouton **Police des titres** ou **Police du texte** pour ouvrir le navigateur **Choisir une police**, qui liste les Google Fonts par popularité, dix par page. Saisissez dans **Rechercher** pour trouver une police par son nom, ou utilisez le **Filtre par catégorie** (Empattement, Sans empattement, Décorative, Manuscrite ou Chasse fixe). Cliquez sur une police pour la choisir. Vous pouvez aussi cliquer sur l'une des **combinaisons de polices populaires** pour définir les deux polices en une fois.
3. Cliquez sur **Enregistrer les polices** pour appliquer vos choix de polices.
4. Pour ajuster la hiérarchie des tailles des titres 1 à 4, cliquez sur **Échelle typographique** dans le panneau Paramètres de style. Utilisez les champs **Multiplicateur d'échelle**, **Taille de base** et **Hauteur de ligne** pour affiner, puis cliquez sur **Enregistrer la typographie**.

## Espacement {#spacing}

1. Cliquez sur **Échelle d'espacement** dans le panneau Paramètres de style.
2. Ajustez les valeurs d'espacement de Très petit à Très grand. Des exemples pratiques montrent l'effet de chaque valeur sur la mise en page.
3. Cliquez sur **Enregistrer l'espacement** pour appliquer les valeurs à l'ensemble de votre site.

## Logo et image de marque {#logo-and-branding}

1. Cliquez sur **Logo** dans le panneau Paramètres de style.
2. Téléversez votre **logo pour fond clair** et votre **logo pour fond foncé**. Utilisez des images au fond transparent et au rapport d'aspect de 4:1 pour de meilleurs résultats.
3. Téléversez une **image pour les réseaux sociaux** pour les aperçus de liens et une **icône de site (favicon)** pour l'icône de l'onglet du navigateur.
4. Vous pouvez facultativement saisir un **nom court PWA** (jusqu'à 12 caractères) -- le nom affiché sous l'icône de votre église lorsqu'une personne l'ajoute à l'écran d'accueil de son téléphone.
5. Cliquez sur **Enregistrer les modifications**. Les images téléversées ne sont pas conservées tant que vous n'avez pas enregistré ; si vous tentez de fermer ou de recharger l'onglet du navigateur avant, celui-ci vous avertit que des modifications ne sont pas enregistrées.

Les logos sont partagés par tous les sites web de votre église, ainsi que par votre application et vos documents imprimés, comme les feuilles de présence.

:::tip
Pour de meilleurs résultats, utilisez un logo au fond transparent, au format PNG. Vous vous assurez ainsi qu'il s'affiche bien sur les fonds clairs comme sur les fonds foncés, sur votre site web comme dans votre [application mobile](../settings/mobile-app.md).
:::

## Styles de navigation {#navigation-styles}

Personnalisez les couleurs de la barre de navigation de votre site pour les modes plein et transparent :

1. Cliquez sur **Navigation** dans le panneau Paramètres de style
2. Configurez les couleurs de **En-tête (plein)** et de **En-tête au-dessus de la bannière (transparent)**
3. Cliquez sur **Enregistrer la navigation** pour appliquer vos couleurs de navigation

Pour des instructions détaillées, voir [Styles de navigation](./navigation-styles.md).

## Pied de page du site {#site-footer}

Cliquez sur **Pied de page du site** dans le panneau Paramètres de style pour ouvrir votre pied de page dans l'éditeur de blocs. Construisez-le comme une section de page -- par exemple, votre adresse, vos horaires de service et vos réseaux sociaux -- puis cliquez sur **Quitter** lorsque vous avez terminé. Le pied de page apparaît au bas de chaque page utilisant la mise en page **En-tête et pied de page**. Chacun de vos sites web a son propre pied de page.

## Annonce et widgets {#announcement--widgets}

Les widgets du site apparaissent sur chaque page de votre site, flottant au-dessus du contenu de la page :

- **Bandeau d'annonce** -- Une barre amovible en haut de votre site pour les messages urgents, comme un événement à venir ou un changement de service.
- **Lanceur** -- Un bouton flottant qui ouvre un menu d'accès rapide, par exemple des liens vers les dons, le pointage ou le bulletin.

1. Repérez la carte **Annonce et widgets** sous les Paramètres de style.
2. Pour le **Bandeau d'annonce**, cochez **Activé** et renseignez le **texte**, un **URL du lien** et un **texte du lien** facultatifs, ainsi que la **couleur d'arrière-plan** et la **couleur du texte**. Définissez une **date de début** et une **date de fin** pour n'afficher le bandeau que pendant cette période.
3. Pour le **Lanceur**, cochez **Activé**, puis cliquez sur **Ajouter une action** pour chaque lien (jusqu'à cinq) et donnez-lui un **libellé**, une **URL** et une **icône**. Choisissez sa **position** (en bas à droite ou en bas à gauche) et sa **couleur**.
4. Cliquez sur **Enregistrer**.

Décochez **Activé** puis cliquez sur **Enregistrer** pour désactiver un widget. Ces widgets s'appliquent à tous les sites web de votre église.

Le bandeau d'annonce s'affiche aussi en haut de l'écran d'accueil de l'application B1 de votre église (le portail des membres à `/mobile`, y compris l'application installée), au-dessus de la salutation, avec le même texte, le même lien, les mêmes couleurs et les mêmes dates. Dans l'application, une **URL du lien** qui pointe vers l'une de vos propres pages (par exemple, `/food`) ouvre cette page dans l'application au lieu de charger votre site web. Voir [Naviguer dans B1App](../../b1-church/getting-started/navigating.md#home).

Quelques précisions sur le fonctionnement du bandeau :

- Sur les téléphones, un long texte passe à la ligne, et le lien passe sur sa propre ligne s'il ne tient pas.
- Sur votre site web, la barre de menu se place juste sous le bandeau d'annonce, de sorte que le bouton de menu reste visible. Les menus et les fenêtres contextuelles s'ouvrent au-dessus du bandeau.
- Lorsqu'une personne ferme le bandeau avec son bouton **×**, il reste masqué sur cet appareil pendant un jour, puis réapparaît. Si vous modifiez le **texte**, la nouvelle annonce s'affiche immédiatement, même pour les personnes qui ont fermé l'ancienne.

## Redirections et analytique {#redirects--analytics}

La carte **Redirections et analytique** (sous les Paramètres de style) regroupe deux paramètres distincts mais souvent nécessaires :

- **Analytique** -- Ajoutez votre **identifiant de mesure GA4** (format `G-XXXXXXXXXX`) et cliquez sur **Enregistrer** pour suivre la fréquentation de votre site web. Le même identifiant suit aussi les pages vues dans l'application B1 de votre église (le portail des membres à `/mobile`, y compris l'application installée), avec un `display_mode` valant `installed` ou `browser` afin de distinguer les visites depuis l'application installée des visites depuis le navigateur dans Google Analytics.
- **Redirections** -- Associez un ancien chemin d'URL à un nouveau, afin que les liens vers une page déplacée ou renommée continuent de fonctionner au lieu de produire une erreur 404. Saisissez l'ancien **chemin source** et le nouveau **chemin cible**, puis cliquez sur **Ajouter**. La redirection est enregistrée immédiatement et listée au-dessus des champs ; cliquez sur son icône de suppression pour la retirer. Les chemins sont enregistrés en minuscules, avec une barre oblique initiale et sans barre oblique finale. Une redirection a aussi priorité sur les pages intégrées de B1 (`/sermons`, `/stream`, `/donate`, `/bible` et `/votd`), ce qui vous permet d'envoyer cette adresse ailleurs (par exemple, vers votre propre page de prédications ou une chaîne YouTube). Elle ne remplace pas une page que vous avez créée vous-même à la même adresse. Supprimez d'abord cette page si vous voulez que la redirection s'applique.

## CSS et JavaScript personnalisés {#custom-css-and-javascript}

1. Cliquez sur **CSS et JavaScript** dans le panneau Paramètres de style.
2. Ajoutez du **CSS personnalisé** pour remplacer les styles par défaut dans le cadre d'une personnalisation avancée.
3. Ajoutez du **HTML personnalisé** pour les codes de suivi ou d'autres scripts.
4. Utilisez les sections **Exemples de CSS courants** et **Exemples de JavaScript courants** pour des extraits prêts à l'emploi, puis cliquez sur **Enregistrer les modifications**.

:::warning
Le CSS personnalisé est puissant, mais il peut casser la mise en page de votre site s'il est mal utilisé. La plupart des églises peuvent obtenir l'apparence souhaitée avec les commandes intégrées de couleurs, de polices et d'espacement. N'utilisez le CSS personnalisé que si vous êtes à l'aise avec le développement web.
:::

:::info
Votre site applique une politique de sécurité du contenu (CSP) qui bloque les scripts en ligne provenant de toute autre source. Le champ **HTML personnalisé** ici, ainsi que l'[élément HTML](./page-editor.md#using-the-html-element) sur les pages individuelles, sont les exceptions de confiance -- le code que vous y enregistrez s'exécute tel quel ; ne collez donc que des scripts provenant de sources de confiance (balises d'analytique, widgets de clavardage et intégrations similaires).
:::

## Thèmes de style {#style-themes}

Si vous voulez un point de départ rapide, les **palettes suggérées** de la section Palette de couleurs proposent des thèmes prédéfinis aux couleurs coordonnées. Cliquez sur l'une d'elles pour la charger, ajustez les couleurs de votre choix, puis cliquez sur **Enregistrer la palette**.
