# Approbation des modifications de profil

<div class="article-intro">

Quand votre église exige l'approbation d'un administrateur pour les mises à jour de profil, les membres soumettent leurs modifications via l'application B1 Mobile et ces demandes apparaissent comme des tâches dans B1 Admin. Ce guide explique comment les examiner et les approuver.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être membre du groupe désigné comme le **Groupe d'approbation des répertoires** dans **Mobile → B1 Mobile**
- Si aucun groupe d'approbation n'a été configuré, les modifications de profil sont appliquées immédiatement sans examen

</div>

## Où trouver les demandes en attente

Quand un membre soumet une modification de profil, elle apparaît comme une tâche assignée à votre groupe d'approbation. Vous pouvez la trouver à deux endroits :

**À partir du tableau de bord :**
1. Connectez-vous à B1 Admin -- le tableau de bord se charge automatiquement.
2. Dans la section **Tâches** sur le côté droit, cliquez sur l'onglet **Assigné à mes groupes**.
3. Toute demande de modification de profil en attente sera listée là.

**À partir de Serving → Mon travail :**
1. Dans la navigation supérieure, cliquez sur **Serving**.
2. Cliquez sur **Mon travail**.
3. Cliquez sur l'onglet **Assigné à mes groupes** sous Tâches.

## Examen et approbation d'une demande

1. Cliquez sur la tâche **Mise à jour du profil** pour l'ouvrir.
2. Sous **Modifications demandées**, vous verrez chaque champ que le membre veut mettre à jour avec la nouvelle valeur qu'il a soumise.
3. Examinez les modifications.
4. Cliquez sur **Appliquer** pour approuver et enregistrer les modifications sur son profil.

La tâche se fermeera automatiquement une fois les modifications appliquées.

## Configuration du groupe d'approbation

Si votre église veut que les modifications de profil exigent une approbation, un groupe d'approbation des répertoires doit d'abord être configuré.

1. Dans la navigation supérieure, cliquez sur **Mobile**.
2. Cliquez sur **B1 Mobile**.
3. Sous **Groupe d'approbation des répertoires**, sélectionnez le groupe dont les membres doivent examiner les demandes de modification de profil.
4. Cliquez sur **Enregistrer**.

Tout membre de ce groupe verra les demandes de modification de profil entrantes sous **Assigné à mes groupes** sur son tableau de bord.

:::tip
Assurez-vous que vos approbateurs sont des membres du groupe configuré -- seuls les membres du groupe verront les demandes.
:::
