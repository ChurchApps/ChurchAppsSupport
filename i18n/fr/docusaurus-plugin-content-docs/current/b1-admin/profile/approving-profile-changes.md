# Approuver les changements de profil

<div class="article-intro">

Lorsque votre église exige l'approbation d'un administrateur pour les mises à jour de profil, les membres soumettent leurs modifications via l'application mobile B1 et ces demandes apparaissent sous forme de tâches dans B1 Admin. Ce guide explique comment les examiner et les approuver.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être membre du groupe désigné comme **Groupe d'approbation d'annuaire** dans **Mobile → Portail des membres**
- Si aucun groupe d'approbation n'a été configuré, les changements de profil sont appliqués immédiatement sans examen

</div>

## Où trouver les demandes en attente

Lorsqu'un membre soumet un changement de profil, il apparaît sous forme de tâche assignée à votre groupe d'approbation. Vous pouvez le trouver à deux endroits :

**À partir du tableau de bord (votre page d'accueil) :**
1. Connectez-vous à B1 Admin - le tableau de bord se charge automatiquement.
2. Dans la section **Tâches** sur le côté droit, cliquez sur l'onglet **Assigné à mes groupes**.
3. Toutes les demandes de changement de profil en attente seront listées ici.

**À partir de Service → Mon travail :**
1. Dans la navigation du haut, cliquez sur **Service**.
2. Cliquez sur **Mon travail**.
3. Cliquez sur l'onglet **Assigné à mes groupes** sous Tâches.

## Examiner et approuver une demande

1. Cliquez sur la tâche **Mise à jour du profil** pour l'ouvrir.
2. Sous **Modifications demandées**, vous verrez chaque champ que le membre veut mettre à jour ainsi que la nouvelle valeur qu'il a soumise.
3. Examinez les changements.
4. Cliquez sur **Appliquer** pour approuver et enregistrer les modifications à son profil.

La tâche se fermera automatiquement une fois les modifications appliquées.

## Configurer le groupe d'approbation

Si votre église souhaite que les changements de profil nécessitent une approbation, un groupe d'approbation d'annuaire doit d'abord être configuré.

1. Dans la navigation du haut, cliquez sur **Mobile**.
2. Cliquez sur **Portail des membres** (la page "Paramètres du portail").
3. Sous **Groupe d'approbation d'annuaire**, sélectionnez le groupe dont les membres doivent examiner les demandes de changement de profil.
4. Cliquez sur **Enregistrer**.

Tout membre de ce groupe verra les demandes de changement de profil entrantes sous **Assigné à mes groupes** sur leur tableau de bord.

Le même groupe d'approbation d'annuaire examine également les **demandes de suppression de compte** - voir [Examiner les demandes de suppression de compte](./account-deletion.md).

:::tip
Assurez-vous que vos approbateurs sont réellement membres du groupe configuré - seuls les membres du groupe verront les demandes.
:::
