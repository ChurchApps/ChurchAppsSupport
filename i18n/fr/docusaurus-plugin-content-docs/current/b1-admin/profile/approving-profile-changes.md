# Approuver les modifications de profil

<div class="article-intro">

Lorsque votre église exige l'approbation d'un administrateur pour les mises à jour de profil, les membres soumettent leurs modifications via l'application B1 Mobile et ces demandes apparaissent sous forme de tâches dans B1 Admin. Ce guide explique comment les examiner et les approuver.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être membre du groupe désigné comme **Groupe d'approbation du répertoire** dans **Mobile → Portail des membres**
- Si aucun groupe d'approbation n'a été configuré, les modifications de profil sont appliquées immédiatement sans révision

</div>

## Où trouver les demandes en attente

Lorsqu'un membre soumet une modification de profil, elle apparaît en tant que tâche assignée à votre groupe d'approbation. Vous pouvez la trouver à deux endroits :

**À partir du Tableau de bord (votre page d'accueil) :**
1. Connectez-vous à B1 Admin — le Tableau de bord se charge automatiquement.
2. Dans la section **Tâches** sur le côté droit, cliquez sur l'onglet **Assignées à mes groupes**.
3. Toutes les demandes de modification de profil en attente seront listées ici.

**À partir de Activités → Mon travail :**
1. Ouvrez le [menu de saut](../introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche de B1 Admin) et développez **Activités**.
2. Cliquez sur **Mon travail**.
3. Cliquez sur l'onglet **Assignées à mes groupes** sous Tâches.

## Examiner et approuver une demande

1. Cliquez sur la tâche **Mise à jour du profil** pour l'ouvrir.
2. Sous **Modifications demandées**, vous verrez chaque champ que le membre souhaite mettre à jour ainsi que la nouvelle valeur qu'il a soumise.
3. Examinez les modifications.
4. Cliquez sur **Appliquer** pour approuver et enregistrer les modifications dans son profil.

La tâche se fermera automatiquement une fois les modifications appliquées.

## Configurer le groupe d'approbation

Si votre église souhaite que les modifications de profil nécessitent une approbation, un groupe d'approbation du répertoire doit d'abord être configuré.

1. Ouvrez le menu de saut et développez **Mobile**.
2. Cliquez sur **Portail des membres** (la page "Paramètres du portail").
3. Sous **Groupe d'approbation du répertoire**, sélectionnez le groupe dont les membres doivent examiner les demandes de modification de profil.
4. Cliquez sur **Enregistrer**.

N'importe quel membre de ce groupe verra les demandes entrantes de modification de profil sous **Assignées à mes groupes** sur son Tableau de bord.

Le même groupe d'approbation du répertoire examine également les **demandes de suppression de compte** -- voir [Examiner les demandes de suppression de compte](./account-deletion.md).

:::tip
Assurez-vous que vos approbateurs sont réellement membres du groupe configuré -- seuls les membres du groupe verront les demandes.
:::
