# Approbation des modifications de profil

<div class="article-intro">

Lorsque votre église exige l'approbation d'un administrateur pour les mises à jour de profil, les membres soumettent leurs modifications via l'application B1, et ces demandes apparaissent sous forme de tâches dans B1 Admin. Ce guide explique comment les examiner et les approuver.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être membre du groupe désigné comme **groupe d'approbation de l'annuaire** dans **Mobile &rarr; Portail membre**
- Si aucun groupe d'approbation n'a été configuré, les modifications de profil sont appliquées immédiatement, sans examen

</div>

## Où trouver les demandes en attente

Lorsqu'un membre soumet une modification de profil, celle-ci apparaît sous forme de tâche assignée à votre groupe d'approbation. Vous pouvez la trouver à deux endroits :

**Depuis le tableau de bord (votre page d'accueil) :**
1. Connectez-vous à B1 Admin. Le tableau de bord se charge automatiquement.
2. Dans la section **Mes tâches**, cliquez sur **Toutes les tâches**. (Mes tâches n'affiche que les tâches ouvertes qui vous sont assignées personnellement.)
3. Cliquez sur l'onglet **Assignées à mes groupes**. Les demandes de modification de profil en attente y sont listées.

**Depuis Serving &rarr; Mon travail :**
1. Ouvrez le [menu de navigation rapide](../introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche de B1 Admin) et développez **Serving**.
2. Cliquez sur **Mon travail**.
3. Cliquez sur l'onglet **Assignées à mes groupes** sous Tâches.

## Examiner et approuver une demande

1. Cliquez sur la tâche **Mise à jour du profil** pour l'ouvrir.
2. Sous **Modifications demandées**, vous verrez chaque champ que le membre souhaite mettre à jour, ainsi que la nouvelle valeur qu'il a soumise.
3. Examinez les modifications.
4. Cliquez sur **Appliquer** pour approuver et enregistrer les modifications dans son profil.

La tâche se fermera automatiquement une fois les modifications appliquées.

## Configurer le groupe d'approbation

Si votre église souhaite que les modifications de profil soient soumises à approbation, un groupe d'approbation de l'annuaire doit d'abord être configuré.

1. Ouvrez le menu de navigation rapide et développez **Mobile**.
2. Cliquez sur **Portail membre** (la page « Paramètres du portail »).
3. Sous **Groupe d'approbation de l'annuaire**, sélectionnez le groupe dont les membres doivent examiner les demandes de modification de profil.
4. Cliquez sur **Enregistrer**.

Tout membre de ce groupe verra les demandes de modification de profil entrantes sous **Assignées à mes groupes** sur son tableau de bord.

Le même groupe d'approbation de l'annuaire examine également les **demandes de suppression de compte** — voir [Examiner les demandes de suppression de compte](./account-deletion.md).

:::tip
Assurez-vous que vos approbateurs sont bien membres du groupe configuré : seuls les membres de ce groupe verront les demandes.
:::
