# Approuver les modifications de profil

<div class="article-intro">

Lorsque votre église exige l'approbation d'un administrateur pour les mises à jour de profil, les membres soumettent leurs modifications depuis l'application B1, et ces demandes apparaissent sous forme de tâches dans B1 Admin. Ce guide explique comment les examiner et les approuver.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être membre du groupe désigné comme **Groupe d'approbation de l'annuaire** dans **Mobile &rarr; Portail membre**
- Si aucun groupe d'approbation n'a été configuré, les modifications de profil sont appliquées immédiatement, sans examen

</div>

## Où trouver les demandes en attente {#where-to-find-pending-requests}

Lorsqu'un membre soumet une modification de profil, celle-ci apparaît sous forme de tâche assignée à votre groupe d'approbation. Vous pouvez la trouver à deux endroits :

**Depuis le Tableau de bord (votre page d'accueil) :**
1. Connectez-vous à B1 Admin -- le Tableau de bord se charge automatiquement.
2. Dans la section **Mes tâches**, cliquez sur **Toutes les tâches**. (Mes tâches ne répertorie que les tâches ouvertes qui vous sont assignées personnellement.)
3. Cliquez sur l'onglet **Assignées à mes groupes**. Les demandes de modification de profil en attente y seront répertoriées.

**Depuis Service &rarr; Mon travail :**
1. Ouvrez le [menu Accès rapide](../introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche de B1 Admin) et développez **Service**.
2. Cliquez sur **Mon travail**.
3. Cliquez sur l'onglet **Assignées à mes groupes** sous Tâches.

## Examiner et approuver une demande {#reviewing-and-approving-a-request}

1. Cliquez sur la tâche **Mise à jour du profil** pour l'ouvrir.
2. Sous **Modifications demandées**, vous verrez chaque champ que le membre souhaite mettre à jour, avec la nouvelle valeur soumise.
3. Examinez les modifications.
4. Cliquez sur **Appliquer** pour approuver et enregistrer les modifications dans son profil.

Une demande d'ajout d'un membre de la famille affiche le titre, le nom, le rôle dans le foyer et le téléphone mobile de la nouvelle personne sur une même ligne (par exemple, *M. John Smith · Enfant · 555-0100*). L'application de la demande crée cette personne dans le foyer du membre avec ces informations.

La tâche se ferme automatiquement une fois les modifications appliquées.

## Configurer le groupe d'approbation {#setting-up-the-approval-group}

Si votre église souhaite que les modifications de profil soient soumises à approbation, un groupe d'approbation de l'annuaire doit d'abord être configuré.

1. Ouvrez le menu Accès rapide et développez **Mobile**.
2. Cliquez sur **Portail membre** (la page « Paramètres du portail »).
3. Sous **Groupe d'approbation de l'annuaire**, sélectionnez le groupe dont les membres doivent examiner les demandes de modification de profil.
4. Cliquez sur **Enregistrer**.

Tout membre de ce groupe verra les demandes de modification de profil entrantes sous **Assignées à mes groupes** sur son Tableau de bord.

Le même groupe d'approbation de l'annuaire examine aussi les **demandes de suppression de compte** -- voir [Examiner les demandes de suppression de compte](./account-deletion.md).

:::tip
Assurez-vous que vos approbateurs sont bien membres du groupe configuré : seuls les membres du groupe verront les demandes.
:::
