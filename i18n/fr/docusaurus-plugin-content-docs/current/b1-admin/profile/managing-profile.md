# Gestion de votre profil

<div class="article-intro">

La page Profil vous permet de modifier vos paramètres de compte personnel. Votre profil est partagé dans tous les produits ChurchApps, donc toute modification que vous apportez ici se reflètera partout où vous utilisez ChurchApps.

</div>

## Informations de profil

La section supérieure de la page Profil contient vos détails de compte de base :

1. **E-mail** -- Votre adresse e-mail utilisée pour vous connecter et recevoir des notifications.
2. **Prénom** et **Nom de famille** -- Votre nom d'affichage dans ChurchApps.
3. **Mot de passe** -- Mettez à jour votre mot de passe de compte.

Pour mettre à jour vos informations, modifiez les champs et cliquez sur le bouton **Enregistrer les modifications**.

## Changement de mot de passe

1. Faites défiler jusqu'aux champs de mot de passe sur la page Profil.
2. Entrez votre **Mot de passe actuel**.
3. Entrez votre nouveau mot de passe dans le champ **Mot de passe**.
4. Réentrez-le dans le champ **Confirmer le mot de passe**.
5. Cliquez sur **Enregistrer les modifications**.

:::info
Votre mot de passe doit avoir au moins 8 caractères. Assurez-vous que les champs de mot de passe et de confirmation correspondent exactement. Vous devez confirmer votre mot de passe actuel pour le modifier.
:::

## Comptes liés

La section **Comptes liés** affiche tout service externe connecté à votre compte ChurchApps. Vous pouvez voir quels comptes sont liés et gérer ces connexions à partir de cette section.

## Préférences de thème

ChurchApps prend en charge les modes d'affichage clairs et sombres :

1. Trouvez le bouton bascule **Thème** sur votre page Profil.
2. Basculez entre le mode **Clair** et **Sombre**.
3. L'interface se mettra à jour immédiatement pour refléter votre choix.

Votre préférence de thème est enregistrée sur votre compte et s'appliquera à tous vos sessions.

## Suppression de compte

En bas de la page Profil, vous trouverez l'option pour supprimer définitivement votre compte. Cette action supprime votre compte et les données associées et ne peut pas être annulée.

:::warning
La suppression de compte est permanente et ne peut pas être annulée. Assurez-vous que vous souhaitez vraiment supprimer votre compte avant de procéder.
:::
