# Gérer votre profil

<div class="article-intro">

La page Profil vous permet de modifier les paramètres de votre compte personnel. Votre profil est partagé par tous les produits ChurchApps : toute modification effectuée ici sera répercutée partout où vous utilisez ChurchApps.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être connecté à votre compte ChurchApps
- Ayez à portée de main votre nouvelle adresse courriel ou votre nouveau mot de passe si vous comptez les modifier

</div>

## Ouvrir votre profil {#opening-your-profile}

Cliquez sur votre photo de profil en haut à droite de B1 Admin, puis choisissez **Modifier le profil**. La page Profil affiche votre nom et votre courriel à gauche, et les sections **Comptes liés**, **Connexion en deux étapes** et **Suppression du compte** à droite.

## Informations de profil {#profile-information}

La page Profil affiche votre nom et votre adresse courriel à gauche, avec un bouton **Modifier** en dessous. Cliquez sur **Modifier** pour ouvrir le formulaire **Modifier le compte**, qui contient vos informations de base :

1. **Courriel** -- Votre adresse courriel, utilisée pour vous connecter et recevoir les notifications.
2. **Prénom** et **Nom** -- Votre nom d'affichage dans ChurchApps.
3. **Mot de passe actuel**, **Nouveau mot de passe** et **Confirmer le mot de passe** -- Ne remplissez ces champs que pour changer de mot de passe ; laissez-les vides pour conserver l'actuel.

Pour mettre à jour vos informations, modifiez les champs puis cliquez sur le bouton **Enregistrer les modifications**. Un message **Modifications enregistrées.** confirme la mise à jour. Cliquez sur **Annuler** (ou sur le lien **Retour à** suivi de votre nom) pour revenir à votre profil sans enregistrer. Cliquez sur l'icône en forme d'œil dans un champ de mot de passe pour afficher ou masquer ce que vous avez saisi.

## Changer votre mot de passe {#changing-your-password}

1. Sur la page Profil, cliquez sur **Modifier**.
2. Saisissez votre **mot de passe actuel**.
3. Saisissez votre nouveau mot de passe dans le champ **Nouveau mot de passe**.
4. Ressaisissez-le dans le champ **Confirmer le mot de passe**.
5. Cliquez sur **Enregistrer les modifications**.

:::info
Votre mot de passe doit comporter au moins 8 caractères. Vérifiez que les champs du mot de passe et de la confirmation correspondent exactement. Vous devez confirmer votre mot de passe actuel pour le changer : si vous ne le connaissez plus, utilisez plutôt le lien **Mot de passe oublié** sur la page de connexion.
:::

## Comptes liés {#linked-accounts}

La section **Comptes liés** affiche les services externes que vous pouvez connecter à votre compte ChurchApps. Pour l'instant, il s'agit de **PraiseCharts**, utilisé pour trouver des chants et télécharger les partitions et les grilles d'accords des [chants](../serving/songs.md) du Service. Elle indique **Lié** ou **Non lié** :

- Cliquez sur **Lier** puis connectez-vous à PraiseCharts dans la fenêtre qui s'ouvre pour relier votre compte.
- Cliquez sur **S'inscrire** pour créer d'abord un compte PraiseCharts.
- Cliquez sur **Délier** pour le déconnecter.

## Connexion en deux étapes {#two-factor-sign-in}

La connexion en deux étapes ajoute une seconde étape à la connexion : après votre mot de passe (ou une connexion par Google, Microsoft ou lien envoyé par courriel), vous saisissez aussi un code à 6 chiffres provenant d'une application d'authentification sur votre téléphone, comme Google Authenticator, Microsoft Authenticator, 1Password ou Authy. Elle est facultative et désactivée par défaut. Une fois activée, elle s'applique à chaque connexion ChurchApps utilisant votre compte -- B1 Admin, le site et l'application B1.church de votre église, B1 Church Checkin, Lessons.church, FreePlay et les autres.

### Activer la connexion en deux étapes {#turning-it-on}

1. Sur la page Profil, repérez la section **Connexion en deux étapes** et cliquez sur **Activer**.
2. Scannez le code QR avec votre application d'authentification. Si vous ne pouvez pas le scanner, saisissez plutôt dans l'application la clé affichée sous **Impossible de scanner ? Saisissez cette clé :**.
3. Saisissez le **code à 6 chiffres** affiché par votre application, puis cliquez sur **Vérifier**.
4. B1 Admin affiche dix **codes de secours**. Chacun vous permet de vous connecter une fois si vous perdez votre téléphone. Cliquez sur **Copier** ou notez-les, conservez-les en lieu sûr, puis cliquez sur **Je les ai enregistrés**.

:::warning
Les codes de secours ne sont affichés qu'une seule fois. Si vous perdez votre téléphone et n'avez plus de codes de secours, un administrateur du serveur ChurchApps devra désactiver pour vous la connexion en deux étapes, après avoir confirmé votre identité.
:::

Lorsque la connexion en deux étapes est activée, la section indique **Activée** et affiche le nombre de codes de secours qu'il vous reste.

### Se connecter avec un code {#signing-in-with-a-code}

Après avoir saisi votre mot de passe, l'écran de connexion demande un code. Saisissez le code à 6 chiffres de votre application d'authentification, ou l'un de vos codes de secours, puis validez. Chaque code de secours ne fonctionne qu'une seule fois. Si le code est erroné, le message « Ce code n'est pas valide. Veuillez réessayer. » s'affiche. Après trop de codes erronés, les connexions à votre compte sont suspendues pendant un certain temps.

Rester connecté sur un appareil où vous vous êtes déjà connecté ne redemande pas de code ; celui-ci n'est demandé que lors d'une nouvelle connexion.

### Désactiver la connexion en deux étapes {#turning-it-off}

1. Dans la section **Connexion en deux étapes**, cliquez sur **Désactiver**.
2. Saisissez un code en cours de validité de votre application d'authentification, ou un code de secours.
3. Cliquez sur **Vérifier**.

:::info
La connexion en deux étapes ne peut pas être configurée sur les comptes de démonstration : la section y est donc masquée.
:::

## Préférences de thème {#theme-preferences}

B1 Admin vous permet de choisir un thème de couleurs et un mode d'affichage clair ou sombre :

1. Cliquez sur votre photo de profil en haut à droite de B1 Admin pour ouvrir votre menu utilisateur.
2. Sous **Préférences de thème**, choisissez un thème :
   - **Par défaut** -- L'apparence actuelle de B1 Admin : panneaux à bordure sur un fond épuré. Les nouveaux utilisateurs voient ce thème jusqu'à ce qu'ils en choisissent un autre.
   - **Classique** -- L'apparence précédente de B1 Admin, avec une bannière de page colorée, des cartes à ombre portée et un fond gris. Si vous utilisiez B1 Admin sur cet appareil avant l'arrivée de la nouvelle apparence et que vous n'avez jamais choisi de thème, vous restez sur Classique.
   - **Personnalisé** -- L'apparence par défaut, construite à partir de la couleur propre à votre église. Il utilise la couleur principale du mode clair définie dans **Mobile > Thème de l'application**, ou la couleur principale de votre site web si aucune couleur d'application n'est définie, afin que B1 Admin corresponde à l'application de vos membres.
3. Sous les thèmes, choisissez **Mode clair** ou **Mode sombre**.
4. L'interface se met à jour immédiatement pour refléter votre choix.

Vos choix sont mémorisés sur cet appareil et ce navigateur.

## Suppression du compte {#account-deletion}

Dans la section **Suppression du compte** de la page Profil, vous trouverez l'option de supprimer votre compte.

- Si votre église **n'a pas** configuré de groupe d'approbation de l'annuaire, la section affiche l'avertissement *« Attention, ces actions sont définitives »*. Cliquez sur **Supprimer mon compte** puis confirmez : votre compte et les données associées sont supprimés immédiatement et vous êtes déconnecté. Cette action est irréversible.
- Si votre église **a** configuré un groupe d'approbation de l'annuaire, la section indique que votre église examine les demandes de suppression. Cliquez sur **Supprimer mon compte**, puis sur **Envoyer la demande** : la demande est alors transmise à ce groupe pour examen. Le bouton est désactivé tant que la demande est en attente, et vous serez averti dès que votre église l'aura approuvée ou refusée. Voir [Examiner les demandes de suppression de compte](./account-deletion.md) pour la suite de la procédure.

:::warning
La suppression de compte -- qu'elle soit immédiate ou approuvée par votre église -- est définitive et ne peut pas être annulée.
:::

:::info
Si vous êtes le seul **Administrateur de domaine** de votre église, B1 ne supprimera pas votre compte. Il affiche « Vous êtes le seul administrateur de domaine de *église*. Désignez un autre administrateur de domaine avant de supprimer votre compte. » Ajoutez d'abord un autre utilisateur aux **Administrateurs de domaine**. Consultez [Rôles et autorisations](../settings/roles-permissions.md) pour plus de détails sur la gestion des rôles d'administrateur.
:::

:::info
La modification du profil est désactivée en mode démonstration. Si vous utilisez un compte de démonstration, vous ne pourrez pas modifier les paramètres de votre profil.
:::
