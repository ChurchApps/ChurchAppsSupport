# Gestion de votre profil

<div class="article-intro">

La page Profil vous permet de modifier les paramètres de votre compte personnel. Votre profil est partagé entre tous les produits ChurchApps, donc toute modification que vous apportez ici sera appliquée partout où vous utilisez ChurchApps.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être connecté à votre compte ChurchApps
- Ayez votre nouvelle adresse e-mail ou votre nouveau mot de passe prêt si vous comptez les modifier

</div>

## Informations du profil

La page Profil affiche votre nom et votre adresse e-mail à gauche, avec un bouton **Modifier** en dessous. Cliquez sur **Modifier** pour ouvrir le formulaire **Modifier le compte**, qui contient les informations de base de votre compte :

1. **E-mail** -- Votre adresse e-mail utilisée pour vous connecter et recevoir les notifications.
2. **Prénom** et **Nom** -- Votre nom d'affichage dans ChurchApps.
3. **Mot de passe** -- Mettez à jour le mot de passe de votre compte.

Pour mettre à jour vos informations, modifiez les champs puis cliquez sur le bouton **Enregistrer les modifications**. Cliquez sur **Annuler** (ou sur le lien **Retour à** avec votre nom) pour revenir à votre profil sans enregistrer.

## Modifier votre mot de passe

1. Sur la page Profil, cliquez sur **Modifier**.
2. Saisissez votre **mot de passe actuel**.
3. Saisissez votre nouveau mot de passe dans le champ **Nouveau mot de passe**.
4. Saisissez-le de nouveau dans le champ **Vérifier le mot de passe**.
5. Cliquez sur **Enregistrer les modifications**.

:::info
Votre mot de passe doit comporter au moins 8 caractères. Vérifiez que les champs du mot de passe et de la confirmation correspondent exactement. Vous devez confirmer votre mot de passe actuel pour le modifier -- si vous ne le connaissez pas, utilisez plutôt le lien **Mot de passe oublié** sur la page de connexion.
:::

## Comptes liés

La section **Comptes liés** affiche les services externes connectés à votre compte ChurchApps. Vous pouvez voir les comptes liés et gérer ces connexions depuis cette section.

## Préférences de thème

B1 Admin prend en charge les modes d'affichage clair et sombre :

1. Cliquez sur votre photo de profil dans le coin supérieur droit de B1 Admin pour ouvrir votre menu utilisateur.
2. Sous **Préférences de thème**, choisissez **Mode clair** ou **Mode sombre**.
3. L'interface se met à jour immédiatement pour refléter votre choix.

Votre choix est mémorisé sur cet appareil et ce navigateur.

## Suppression du compte

Dans la section **Suppression du compte** de la page Profil, vous trouverez l'option de supprimer votre compte.

- Si votre église **n'a pas** configuré de groupe d'approbation de l'annuaire, cliquer sur **Supprimer mon compte** supprime immédiatement votre compte et les données associées, et cette action est irréversible.
- Si votre église **a** configuré un groupe d'approbation de l'annuaire, votre demande est plutôt envoyée à ce groupe pour examen. Le bouton est désactivé pendant que la demande est en attente, et vous serez averti dès que votre église l'aura approuvée ou refusée. Consultez [Examen des demandes de suppression de compte](./account-deletion.md) pour connaître la suite.

:::warning
La suppression du compte -- qu'elle soit immédiate ou approuvée par votre église -- est définitive et ne peut pas être annulée.
:::

:::info
Si vous êtes **administrateur de domaine**, veillez à transférer les responsabilités administratives à un autre utilisateur avant de supprimer votre compte. Consultez [Rôles et autorisations](../settings/roles-permissions.md) pour plus de détails sur la gestion des rôles d'administrateur.
:::

:::info
La modification du profil est désactivée en mode démo. Si vous utilisez un compte de démonstration, vous ne pourrez pas modifier les paramètres de votre profil.
:::
