# Gestion de votre profil

La page Profil vous permet de modifier les paramètres de votre compte personnel. Votre profil est partagé entre tous les produits ChurchApps, donc toute modification que vous apportez ici sera reflétée partout où vous utilisez ChurchApps.

## Informations de profil

La section supérieure de la page Profil contient les détails de votre compte de base :

1. **E-mail** -- Votre adresse e-mail utilisée pour vous connecter et recevoir des notifications.
2. **Prénom** et **Nom** -- Votre nom d'affichage dans ChurchApps.
3. **Mot de passe** -- Mettez à jour le mot de passe de votre compte.

Pour mettre à jour vos informations, modifiez les champs et cliquez sur le bouton **Enregistrer les modifications**.

## Modification de votre mot de passe

1. Faites défiler jusqu'aux champs de mot de passe sur la page Profil.
2. Entrez votre **mot de passe actuel**.
3. Entrez votre nouveau mot de passe dans le champ **Mot de passe**.
4. Réentrez-le dans le champ **Confirmer le mot de passe**.
5. Cliquez sur **Enregistrer les modifications**.

:::info
Votre mot de passe doit avoir au moins 8 caractères. Assurez-vous que les champs mot de passe et confirmation correspondent exactement. Vous devez confirmer votre mot de passe actuel pour le modifier -- si vous ne vous en souvenez pas, utilisez le lien **Mot de passe oublié** sur la page de connexion à la place.
:::

## Comptes liés

La section **Comptes liés** affiche tous les services externes connectés à votre compte ChurchApps. Vous pouvez voir quels comptes sont liés et gérer ces connexions à partir de cette section.

## Préférences de thème

ChurchApps prend en charge les modes d'affichage clair et foncé :

1. Trouvez le bouton bascule **Thème** sur votre page Profil.
2. Basculez entre le mode **Clair** et **Sombre**.
3. L'interface se mettra à jour immédiatement pour refléter votre choix.

Votre préférence de thème est enregistrée sur votre compte et s'appliquera dans toutes vos sessions.

## Suppression de compte

En bas de la page Profil, vous trouverez l'option pour supprimer définitivement votre compte. Cette action supprime votre compte et les données associées et ne peut pas être annulée.

:::warning
La suppression du compte est permanente et ne peut pas être annulée. Assurez-vous vraiment de vouloir supprimer votre compte avant de continuer.
:::
