# Gérer votre profil

<div class="article-intro">

La page Profil vous permet de modifier les paramètres personnels de votre compte. Votre profil est partagé entre tous les produits ChurchApps : toute modification effectuée ici sera donc reflétée partout où vous utilisez ChurchApps.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être connecté à votre compte ChurchApps
- Ayez à portée de main votre nouvelle adresse e-mail ou votre nouveau mot de passe si vous prévoyez de les modifier

</div>

## Informations du profil

La page Profil affiche votre nom et votre adresse e-mail à gauche, avec un bouton **Modifier** en dessous. Cliquez sur **Modifier** pour ouvrir le formulaire **Modifier le compte**, qui contient les informations de base de votre compte :

1. **E-mail** : votre adresse e-mail, utilisée pour vous connecter et recevoir les notifications.
2. **Prénom** et **Nom** : votre nom d'affichage dans ChurchApps.
3. **Mot de passe** : mettez à jour votre mot de passe de compte.

Pour mettre à jour vos informations, modifiez les champs puis cliquez sur le bouton **Enregistrer les modifications**. Cliquez sur **Annuler** (ou sur le lien **Retour à** avec votre nom) pour revenir à votre profil sans enregistrer.

## Changer votre mot de passe

1. Sur la page Profil, cliquez sur **Modifier**.
2. Saisissez votre **mot de passe actuel**.
3. Saisissez votre nouveau mot de passe dans le champ **Nouveau mot de passe**.
4. Saisissez-le à nouveau dans le champ **Vérifier le mot de passe**.
5. Cliquez sur **Enregistrer les modifications**.

:::info
Votre mot de passe doit comporter au moins 8 caractères. Vérifiez que les champs du mot de passe et de la confirmation correspondent exactement. Vous devez confirmer votre mot de passe actuel pour le modifier. Si vous ne le connaissez pas, utilisez plutôt le lien **Mot de passe oublié** sur la page de connexion.
:::

## Comptes liés

La section **Comptes liés** affiche les services externes connectés à votre compte ChurchApps. Vous pouvez y voir les comptes liés et gérer ces connexions.

## Préférences d'affichage

B1 Admin vous permet de choisir un thème de couleurs et un mode d'affichage clair ou sombre :

1. Cliquez sur votre photo de profil dans le coin supérieur droit de B1 Admin pour ouvrir votre menu utilisateur.
2. Sous **Préférences de thème**, choisissez un thème :
   - **Par défaut** : l'apparence actuelle de B1 Admin, avec des panneaux bordés sur un fond épuré. Les nouveaux utilisateurs voient ce thème tant qu'ils n'en choisissent pas un autre.
   - **Classique** : l'apparence précédente de B1 Admin, avec une bannière de page colorée, des cartes ombrées et un fond gris. Si vous utilisiez B1 Admin sur cet appareil avant l'arrivée de la nouvelle apparence et n'avez jamais choisi de thème, vous restez sur Classique.
   - **Personnalisé** : l'apparence par défaut construite à partir de la couleur de votre église. Il utilise la couleur principale du mode clair définie dans **Mobile > Thème de l'application**, ou la couleur principale de votre site web si aucune couleur d'application n'est définie, afin que B1 Admin corresponde à l'application de vos membres.
3. Sous les thèmes, choisissez **Mode clair** ou **Mode sombre**.
4. L'interface se met à jour immédiatement pour refléter votre choix.

Vos choix sont mémorisés sur cet appareil et dans ce navigateur.

## Suppression du compte

Dans la section **Suppression du compte** de la page Profil, vous trouverez l'option permettant de supprimer votre compte.

- Si votre église n'a **pas** configuré de groupe d'approbation de l'annuaire, cliquer sur **Supprimer mon compte** supprime immédiatement votre compte et les données associées, et cette action est irréversible.
- Si votre église **a** configuré un groupe d'approbation de l'annuaire, votre demande est envoyée à ce groupe pour examen. Le bouton est désactivé tant que la demande est en attente, et vous serez averti lorsque votre église l'aura approuvée ou refusée. Consultez [Examiner les demandes de suppression de compte](./account-deletion.md) pour connaître la suite de la procédure.

:::warning
La suppression du compte, qu'elle soit immédiate ou approuvée par votre église, est définitive et ne peut pas être annulée.
:::

:::info
Si vous êtes **Administrateur de domaine**, veillez à transférer les responsabilités d'administration à un autre utilisateur avant de supprimer votre compte. Consultez [Rôles et autorisations](../settings/roles-permissions.md) pour plus de détails sur la gestion des rôles d'administration.
:::

:::info
La modification du profil est désactivée en mode démonstration. Si vous utilisez un compte de démonstration, vous ne pourrez pas modifier les paramètres de votre profil.
:::
