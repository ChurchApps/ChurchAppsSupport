# Gérer votre profil

<div class="article-intro">

La page Profil vous permet de modifier les paramètres personnels de votre compte. Votre profil est partagé par tous les produits ChurchApps ; toute modification apportée ici sera donc reflétée partout où vous utilisez ChurchApps.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez être connecté à votre compte ChurchApps
- Ayez votre nouvelle adresse e-mail ou votre nouveau mot de passe à portée de main si vous prévoyez les modifier

</div>

## Renseignements du profil

La page Profil affiche votre nom et votre adresse e-mail à gauche, avec un bouton **Modifier** en dessous. Cliquez sur **Modifier** pour ouvrir le formulaire **Modifier le compte**, qui contient vos renseignements de base :

1. **E-mail** -- Votre adresse e-mail utilisée pour vous connecter et recevoir les notifications.
2. **Prénom** et **Nom** -- Votre nom d'affichage dans ChurchApps.
3. **Mot de passe** -- Mettez à jour le mot de passe de votre compte.

Pour mettre à jour vos renseignements, modifiez les champs et cliquez sur le bouton **Enregistrer les modifications**. Cliquez sur **Annuler** (ou sur le lien **Retour à** portant votre nom) pour revenir à votre profil sans enregistrer.

## Changer votre mot de passe

1. Sur la page Profil, cliquez sur **Modifier**.
2. Saisissez votre **mot de passe actuel**.
3. Saisissez votre nouveau mot de passe dans le champ **Nouveau mot de passe**.
4. Saisissez-le à nouveau dans le champ **Vérifier le mot de passe**.
5. Cliquez sur **Enregistrer les modifications**.

:::info
Votre mot de passe doit comporter au moins 8 caractères. Assurez-vous que le mot de passe et sa confirmation correspondent exactement. Vous devez confirmer votre mot de passe actuel pour le modifier -- si vous ne le connaissez pas, utilisez plutôt le lien **Mot de passe oublié** sur la page de connexion.
:::

## Comptes liés

La section **Comptes liés** affiche tous les services externes connectés à votre compte ChurchApps. Vous pouvez y voir quels comptes sont liés et gérer ces connexions.

## Connexion en deux étapes {#two-factor-sign-in}

La connexion en deux étapes ajoute une deuxième étape à la connexion : après votre mot de passe (ou une connexion par Google, Microsoft ou lien e-mail), vous saisissez aussi un code à 6 chiffres provenant d'une application d'authentification sur votre téléphone, comme Google Authenticator, Microsoft Authenticator, 1Password ou Authy. Cette option est facultative et désactivée par défaut. Une fois activée, elle s'applique à chaque connexion ChurchApps qui utilise votre compte -- B1 Admin, le site et l'application B1.church de votre église, B1 Church Checkin, Lessons.church, FreePlay et les autres.

### Activer la fonction

1. Sur la page Profil, repérez la section **Connexion en deux étapes** et cliquez sur **Activer**.
2. Scannez le code QR avec votre application d'authentification. Si vous ne pouvez pas le scanner, saisissez plutôt dans l'application la clé affichée sous **Impossible de scanner ? Saisissez cette clé :**.
3. Saisissez le **code à 6 chiffres** affiché par votre application et cliquez sur **Vérifier**.
4. B1 Admin affiche dix **codes de secours**. Chacun vous permet de vous connecter une fois si vous perdez votre téléphone. Cliquez sur **Copier** ou notez-les, conservez-les en lieu sûr, puis cliquez sur **Je les ai enregistrés**.

:::warning
Les codes de secours ne sont affichés qu'une seule fois. Si vous perdez votre téléphone et n'avez plus de codes de secours, un administrateur serveur ChurchApps devra désactiver la connexion en deux étapes pour vous, après avoir confirmé votre identité.
:::

Lorsque la connexion en deux étapes est activée, la section affiche **Activée** et indique combien de codes de secours il vous reste.

### Se connecter avec un code

Après avoir saisi votre mot de passe, l'écran de connexion demande un code. Saisissez le code à 6 chiffres de votre application d'authentification, ou l'un de vos codes de secours, puis validez. Chaque code de secours ne fonctionne qu'une seule fois. Si le code est erroné, vous verrez le message « Ce code n'a pas fonctionné. Veuillez réessayer. » Après trop de codes erronés, les connexions à votre compte sont suspendues pendant un certain temps.

Rester connecté sur un appareil où vous êtes déjà connecté ne demande pas de nouveau code ; celui-ci n'apparaît que lorsque vous vous connectez à nouveau.

### Désactiver la fonction

1. Dans la section **Connexion en deux étapes**, cliquez sur **Désactiver**.
2. Saisissez un code actuel de votre application d'authentification, ou un code de secours.
3. Cliquez sur **Vérifier**.

:::info
La connexion en deux étapes ne peut pas être configurée sur les comptes de démonstration ; la section y est donc masquée.
:::

## Préférences de thème

B1 Admin vous permet de choisir un thème de couleurs et un mode d'affichage clair ou sombre :

1. Cliquez sur votre photo de profil dans le coin supérieur droit de B1 Admin pour ouvrir votre menu utilisateur.
2. Sous **Préférences de thème**, choisissez un thème :
   - **Par défaut** -- L'apparence actuelle de B1 Admin : panneaux à bordure sur un fond épuré. Les nouveaux utilisateurs voient ce thème jusqu'à ce qu'ils en choisissent un autre.
   - **Classique** -- L'apparence précédente de B1 Admin, avec une bannière de page colorée, des cartes avec ombre et un fond gris. Si vous utilisiez B1 Admin sur cet appareil avant l'arrivée de la nouvelle apparence et n'avez jamais choisi de thème, vous restez sur Classique.
   - **Personnalisé** -- L'apparence Par défaut construite à partir de la couleur propre à votre église. Elle utilise la couleur principale du mode clair de **Mobile > Thème de l'application**, ou la couleur principale de votre site web si aucune couleur d'application n'est définie, afin que B1 Admin corresponde à l'application de vos membres.
3. Sous les thèmes, choisissez **Mode clair** ou **Mode sombre**.
4. L'interface se met à jour immédiatement pour refléter votre choix.

Vos choix sont mémorisés sur cet appareil et dans ce navigateur.

## Suppression du compte

Dans la section **Suppression du compte** de la page Profil, vous trouverez l'option pour supprimer votre compte.

- Si votre église n'a **pas** configuré de groupe d'approbation du répertoire, cliquer sur **Supprimer mon compte** supprime immédiatement votre compte et les données associées, et cette action est irréversible.
- Si votre église **a** configuré un groupe d'approbation du répertoire, votre demande est plutôt envoyée à ce groupe pour examen. Le bouton est désactivé tant que la demande est en attente, et vous serez avisé une fois que votre église l'aura approuvée ou refusée. Consultez [Examiner les demandes de suppression de compte](./account-deletion.md) pour savoir ce qui se passe ensuite.

:::warning
La suppression du compte -- qu'elle soit immédiate ou approuvée par votre église -- est définitive et ne peut pas être annulée.
:::

:::info
Si vous êtes **administrateur de domaine**, veillez à transférer les responsabilités administratives à un autre utilisateur avant de supprimer votre compte. Consultez [Rôles et autorisations](../settings/roles-permissions.md) pour plus de détails sur la gestion des rôles d'administration.
:::

:::info
La modification du profil est désactivée en mode démonstration. Si vous utilisez un compte de démonstration, vous ne pourrez pas modifier les paramètres de votre profil.
:::
