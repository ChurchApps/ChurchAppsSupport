# Profil

<div class="article-intro">

La section Profil vous permet de gérer les paramètres de votre compte personnel dans ChurchApps. Pour l'ouvrir, cliquez sur votre photo de profil en haut à droite de B1 Admin, puis choisissez **Modifier le profil**. Votre profil est partagé par tous les outils ChurchApps : les modifications effectuées ici s'appliquent partout, de B1 Admin à l'application B1.

</div>

## Ce que vous pouvez faire {#what-you-can-do}

Depuis la section Profil, vous pouvez :

- **Mettre à jour votre nom et votre courriel** -- Gardez vos coordonnées à jour.
- **Changer votre mot de passe** -- Définissez un nouveau mot de passe pour votre compte.
- **Activer la connexion en deux étapes** -- Exigez un code généré par une application d'authentification lors de la connexion. Voir [Connexion en deux étapes](./managing-profile.md#two-factor-sign-in).
- **Changer de thème** -- Basculez entre le mode clair et le mode sombre depuis le menu utilisateur (cliquez sur votre photo de profil en haut à droite).
- **Gérer les appareils connectés** -- Consultez, associez, renommez et retirez les écrans ChurchAppsPlayer et FreePlay liés à votre compte.
- **Consulter les comptes liés** -- Voyez et gérez les services externes connectés à votre compte ChurchApps.
- **Approuver les demandes de modification de profil** -- Examinez et appliquez les mises à jour soumises par les membres.
- **Examiner les demandes de suppression de compte** -- Approuvez ou refusez les demandes des membres qui souhaitent supprimer leur compte.

## Sous-sections du profil {#profile-sub-sections}

La zone Profil comprend les pages suivantes :

1. **[Gérer votre profil](./managing-profile.md)** -- Modifiez vos informations personnelles, changez votre mot de passe, gérez les comptes liés, activez la connexion en deux étapes, ajustez les préférences de thème et gérez la suppression du compte.
2. **[Approuver les modifications de profil](./approving-profile-changes.md)** -- Examinez et approuvez les demandes de mise à jour de profil soumises par les membres via l'application B1.
3. **[Examiner les demandes de suppression de compte](./account-deletion.md)** -- Approuvez ou refusez les demandes des membres qui souhaitent supprimer leur compte.
4. **[Gérer les appareils](./devices.md)** -- Consultez, ajoutez, renommez et retirez les écrans ChurchAppsPlayer et FreePlay associés à votre compte.

:::tip
Gardez votre adresse courriel à jour. Elle sert à la récupération du compte et aux notifications importantes de votre église.
:::
