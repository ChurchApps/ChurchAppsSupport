# Profil

<div class="article-intro">

La section Profil vous permet de gérer les paramètres de votre compte personnel dans ChurchApps. Votre profil est partagé par tous les outils ChurchApps, de sorte que les modifications apportées ici s'appliquent partout -- de B1 Admin à l'application mobile B1.

</div>

## Ce que vous pouvez faire

Depuis la section Profil, vous pouvez :

- **Mettre à jour votre nom et votre courriel** -- Gardez vos coordonnées à jour.
- **Changer votre mot de passe** -- Définissez un nouveau mot de passe pour votre compte.
- **Activer la connexion à deux facteurs** -- Exigez un code d'une application d'authentification à chaque connexion. Voir [Connexion à deux facteurs](./managing-profile.md#two-factor-sign-in).
- **Changer de thème** -- Basculez entre le mode clair et le mode sombre depuis le menu utilisateur (cliquez sur votre photo de profil dans le coin supérieur droit).
- **Gérer les appareils connectés** -- Consultez et contrôlez les appareils ChurchAppsPlayer liés à votre compte.
- **Consulter les comptes liés** -- Voyez et gérez les services externes connectés à votre compte ChurchApps.
- **Approuver les demandes de modification de profil** -- Examinez et appliquez les mises à jour soumises par les membres.

## Sous-sections du profil

La zone Profil comprend les pages suivantes :

1. **[Gérer votre profil](./managing-profile.md)** -- Modifier vos renseignements personnels, changer votre mot de passe, gérer les comptes liés, activer la connexion à deux facteurs, ajuster les préférences de thème et gérer la suppression du compte.
2. **[Approuver les modifications de profil](./approving-profile-changes.md)** -- Examiner et approuver les demandes de mise à jour de profil soumises par les membres via l'application mobile B1.
3. **[Gérer les appareils](./devices.md)** -- Consulter, ajouter et gérer les appareils ChurchAppsPlayer associés à votre compte.

:::tip
Gardez votre adresse courriel à jour. Elle sert à récupérer votre compte et à recevoir les notifications importantes de votre église.
:::
