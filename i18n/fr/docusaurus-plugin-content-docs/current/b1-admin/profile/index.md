# Profil

<div class="article-intro">

La section Profil vous permet de gérer les paramètres de votre compte personnel dans ChurchApps. Votre profil est partagé entre tous les outils ChurchApps, donc les modifications que vous faites ici s'appliquent partout, de B1 Admin à l'application B1.

</div>

## Ce que vous pouvez faire

Depuis la section Profil, vous pouvez :

- **Mettre à jour votre nom et votre adresse e-mail** -- Gardez vos coordonnées à jour.
- **Changer votre mot de passe** -- Définissez un nouveau mot de passe pour votre compte.
- **Activer la connexion en deux étapes** -- Exiger un code provenant d'une application d'authentification lors de la connexion. Voir [Connexion en deux étapes](./managing-profile.md#two-factor-sign-in).
- **Changer de thème** -- Basculez entre le mode clair et le mode sombre depuis le menu utilisateur (cliquez sur votre photo de profil dans le coin supérieur droit).
- **Gérer les appareils connectés** -- Consultez et contrôlez les appareils ChurchAppsPlayer liés à votre compte.
- **Consulter les comptes liés** -- Voyez et gérez les services externes connectés à votre compte ChurchApps.
- **Approuver les demandes de modification de profil** -- Examinez et appliquez les mises à jour soumises par les membres.

## Sous-sections du profil

La zone Profil comprend les pages suivantes :

1. **[Gérer votre profil](./managing-profile.md)** -- Modifiez vos informations personnelles, changez votre mot de passe, gérez les comptes liés, activez la connexion en deux étapes, ajustez vos préférences de thème et gérez la suppression du compte.
2. **[Approuver les modifications de profil](./approving-profile-changes.md)** -- Examinez et approuvez les demandes de mise à jour de profil soumises par les membres via l'application B1.
3. **[Gérer les appareils](./devices.md)** -- Consultez, ajoutez et gérez les appareils ChurchAppsPlayer associés à votre compte.

:::tip
Gardez votre adresse e-mail à jour. Elle sert à la récupération de compte et aux notifications importantes de votre église.
:::
