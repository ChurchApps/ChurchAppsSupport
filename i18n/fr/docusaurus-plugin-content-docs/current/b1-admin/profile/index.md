# Profil

<div class="article-intro">

La section Profil vous permet de gérer les paramètres de votre compte personnel dans ChurchApps. Votre profil est partagé entre tous les outils ChurchApps, donc les modifications que vous apportez ici s'appliquent partout -- de B1 Admin à l'application mobile B1.

</div>

## Ce que vous pouvez faire

À partir de la section Profil, vous pouvez :

- **Mettre à jour votre nom et votre e-mail** -- Gardez vos informations de contact à jour.
- **Modifier votre mot de passe** -- Définissez un nouveau mot de passe pour votre compte.
- **Changer les thèmes** -- Basculez entre le mode clair et le mode sombre selon votre préférence.
- **Gérer les appareils connectés** -- Affichage et contrôle des appareils ChurchAppsPlayer liés à votre compte.
- **Afficher les comptes liés** -- Voir et gérer tous les services externes connectés à votre compte ChurchApps.
- **Approuver les demandes de modification de profil** -- Consulter et appliquer les mises à jour soumises par les membres.

## Sous-sections du profil

La zone Profil a les pages suivantes :

1. **[Gestion de votre profil](./managing-profile.md)** -- Modifiez vos informations personnelles, modifiez votre mot de passe, gérez les comptes liés, ajustez les préférences de thème et gérez la suppression de compte.
2. **[Approbation des modifications de profil](./approving-profile-changes.md)** -- Examinez et approuvez les demandes de mise à jour de profil soumises par les membres via B1 Mobile.

:::tip
Gardez votre adresse e-mail à jour. Elle est utilisée pour la récupération de compte et les notifications importantes de votre église.
:::
