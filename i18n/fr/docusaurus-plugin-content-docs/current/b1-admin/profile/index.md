# Profil

<div class="article-intro">

La section Profil vous permet de gérer vos paramètres de compte personnel dans ChurchApps. Votre profil est partagé dans tous les outils ChurchApps, donc les modifications que vous apportez ici s'appliquent partout -- de B1 Admin à l'application B1 Mobile.

</div>

## Ce que vous pouvez faire

À partir de la section Profil, vous pouvez :

- **Mettre à jour votre nom et votre e-mail** -- Gardez vos informations de contact actuelles.
- **Changer votre mot de passe** -- Définir un nouveau mot de passe pour votre compte.
- **Changer de thème** -- Basculer entre le mode clair et le mode sombre.
- **Gérer les appareils connectés** -- Afficher et contrôler les appareils ChurchAppsPlayer liés à votre compte.
- **Afficher les comptes liés** -- Voir et gérer tous les services externes connectés à votre compte ChurchApps.
- **Approuver les demandes de modification de profil** -- Examiner et appliquer les mises à jour soumises par les membres.

## Sous-sections du profil

La zone Profil a les pages suivantes :

1. **[Gestion de votre profil](./managing-profile.md)** -- Modifier vos informations personnelles, changer votre mot de passe, gérer les comptes liés, ajuster les préférences de thème et gérer la suppression de compte.
2. **[Approbation des modifications de profil](./approving-profile-changes.md)** -- Examiner et approuver les demandes de mise à jour de profil soumises par les membres.
3. **[Gestion des appareils](./devices.md)** -- Afficher, ajouter et gérer les appareils ChurchAppsPlayer appairés à votre compte.

:::tip
Gardez votre adresse e-mail à jour. Elle est utilisée pour la récupération de compte et les notifications importantes de votre église.
:::
