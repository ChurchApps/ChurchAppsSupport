# Suivi de la présence

<div class="article-intro">

Une fois vos campus, heures de service et groupes configurés, B1 Admin facilite l'examen des données de présence et l'identification des tendances. La page Présence fournit deux vues de génération de rapports -- l'onglet **Présence** pour les tendances à l'échelle de l'église et l'onglet **Groupes** pour les détails au niveau du groupe. Utilisez ces outils pour comprendre les modèles de croissance, identifier l'engagement déclinant et prendre des décisions basées sur les données pour votre église.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Votre structure de présence doit être configurée avec au moins un campus et une heure de service. Consultez [Configuration de la présence](setup.md) si vous ne l'avez pas encore fait.
- Les données de présence doivent être enregistrées avant que les rapports affichent les résultats. Les données peuvent provenir de l'[entrée manuelle](recording-attendance.md) ou de l'[enregistrement automatique](check-in.md).

</div>

## Affichage des tendances de présence

1. Ouvrez **B1 Admin**, puis ouvrez le **menu de section** dans le coin supérieur gauche et choisissez **Personnes**.
2. Cliquez sur l'onglet **Présence**.
3. Le rapport s'exécute automatiquement lorsque l'onglet s'ouvre, affichant la présence sur une plage de dates par défaut.

## Filtrage de vos données

Utilisez les filtres en haut de la page pour restreindre les résultats :

- **Plage de dates** -- choisissez une date de début et de fin pour vous concentrer sur une période spécifique.
- **Campus** -- sélectionnez un campus pour voir la présence uniquement pour cet emplacement.
- **Heure de service** -- choisissez une heure de service pour approfondir un rassemblement particulier.

Le graphique et les données se mettent à jour dès que vous modifiez un filtre, ce qui vous permet de comparer rapidement différentes périodes ou emplacements.

:::info
Les rapports s'exécutent automatiquement chaque fois que vous ouvrez l'onglet Présence, de sorte que vous verrez toujours les chiffres à jour sans avoir besoin de cliquer sur un bouton d'actualisation.
:::

## Présence par groupe

L'onglet **Groupes** affiche la présence ventilée par groupe individuel. Ceci est utile lorsque vous souhaitez surveiller une classe, une équipe de ministère ou un petit groupe spécifique plutôt que de regarder les chiffres de service globaux.

1. Sélectionnez l'onglet **Groupes**.
2. Choisissez un groupe dans la liste pour voir son historique de présence.
3. Utilisez le filtre de plage de dates pour ajuster la fenêtre de génération de rapports.

:::tip
La présence par groupe est particulièrement précieuse pour les [petits groupes](../groups/creating-groups.md) que les responsables souhaitent suivre l'engagement dans leur groupe au fil du temps.
:::

## Conseils pour utiliser les données de présence

- Examinez les tendances mensuellement pour détecter tôt les modèles saisonniers.
- Comparez les données au niveau du campus pour comprendre quels emplacements se développent.
- Utilisez les rapports au niveau du groupe pour assurer un suivi auprès des [groupes](../groups/group-members.md) qui affichent une présence en déclin.
- Combinez les informations de présence avec l'outil [Recherche IA](../people/ai-search.md) pour trouver les personnes qui n'ont pas participé récemment.
