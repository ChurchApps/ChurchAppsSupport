# Suivi de la présence

<div class="article-intro">

Une fois que vos campus, heures de service et groupes sont configurés, B1 Admin facilite l'examen des données de présence et l'identification des tendances. La page Présence fournit deux vues de rapport -- l'onglet **Présence** pour les tendances à l'échelle de l'église et l'onglet **Groupes** pour les détails au niveau du groupe. Utilisez ces outils pour comprendre les modèles de croissance, identifier l'engagement déclinant et prendre des décisions éclairées pour votre église.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Votre structure de présence doit être configurée avec au moins un campus et une heure de service. Consultez [Configuration de la présence](setup.md) si vous ne l'avez pas encore fait.
- Les données de présence doivent être enregistrées avant que les rapports ne montrent des résultats. Les données peuvent provenir de [l'entrée manuelle](recording-attendance.md) ou de [l'auto-présence](check-in.md).

</div>

## Affichage des tendances de présence

1. Ouvrez **B1 Admin**, puis ouvrez le **menu de section** dans le coin supérieur gauche et choisissez **Personnes**.
2. Cliquez sur l'onglet **Présence**.
3. Le rapport s'exécute automatiquement quand l'onglet s'ouvre, affichant la présence sur une plage de dates par défaut.

## Filtrage de vos données

Utilisez les filtres en haut de la page pour affiner les résultats :

- **Plage de dates** -- choisissez une date de début et de fin pour vous concentrer sur une période spécifique.
- **Campus** -- sélectionnez un campus pour voir la présence uniquement pour cet emplacement.
- **Heure de service** -- choisissez une heure de service pour approfondir une réunion particulière.

Le graphique et les données se mettent à jour dès que vous modifiez un filtre, vous pouvez donc comparer rapidement différentes périodes ou emplacements.

:::info
Les rapports s'exécutent automatiquement chaque fois que vous ouvrez l'onglet Présence, donc vous verrez toujours des chiffres à jour sans avoir besoin de cliquer sur un bouton d'actualisation.
:::

## Présence du groupe

L'onglet **Groupes** affiche la présence ventilée par groupe individuel. Ceci est utile quand vous voulez surveiller une classe, une équipe de ministère ou un petit groupe spécifique au lieu de regarder les chiffres globaux du service.

1. Sélectionnez l'onglet **Groupes**.
2. Choisissez un groupe dans la liste pour voir son historique de présence.
3. Utilisez le filtre de plage de dates pour ajuster la fenêtre de rapport.

:::tip
La présence du groupe est particulièrement précieuse pour les [petits groupes](../groups/creating-groups.md) les chefs de file qui veulent suivre l'engagement dans leur groupe au fil du temps.
:::

## Conseils pour utiliser les données de présence

- Examen les tendances mensuelles pour détecter rapidement les modèles saisonniers.
- Comparez les données au niveau du campus pour comprendre quels emplacements se développent.
- Utilisez les rapports au niveau du groupe pour faire un suivi avec les [groupes](../groups/group-members.md) qui montrent un déclin de la présence.
- Combinez les informations de présence avec l'outil [Recherche IA](../people/ai-search.md) pour trouver les personnes qui n'ont pas assisté récemment.
