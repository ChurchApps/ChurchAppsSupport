# Enregistrement de la présence

<div class="article-intro">

Une fois que vous avez configuré vos campus, les heures de service et les groupes, vous pouvez enregistrer manuellement la présence après chaque réunion. B1 Admin organise la présence autour de **sessions** -- une session par groupe par date de réunion. Vous créez la session, notez qui a assisté, et les données alimentent directement vos rapports de présence.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vos campus, heures de service et groupes doivent être configurés. Consultez [Configuration de la présence](setup.md) si vous ne l'avez pas encore fait.
- Les groupes que vous souhaitez suivre doivent avoir **Suivi de la présence** activé. Consultez [Configuration de la présence](setup.md) pour plus de détails.

</div>

## Création d'une session

Une session représente une occurrence d'une réunion de groupe -- par exemple, votre classe de maternelle à 3e année un dimanche spécifique.

1. Ouvrez **B1 Admin**, ouvrez le **menu de section** dans le coin supérieur gauche et choisissez **Personnes**, puis cliquez sur l'onglet **Groupes**.
2. Sélectionnez le groupe pour lequel vous souhaitez enregistrer la présence.
3. Cliquez sur l'onglet **Sessions**.
4. Cliquez sur **Nouveau** pour créer une nouvelle session.
5. Si le groupe est assigné à une heure de service, choisissez l'**Heure de service**. S'il s'agit d'un groupe non planifié, ce champ n'apparaîtra pas.
6. Sélectionnez la **Date de la session** -- il peut s'agir d'aujourd'hui, d'une date passée ou d'une date future.
7. Cliquez sur **Enregistrer**.

:::tip
Vous pouvez créer des sessions pour des dates passées pour rattraper la présence que vous n'aviez pas encore enregistrée, ou les créer à l'avance pour qu'elles soient prêtes quand votre groupe se réunit.
:::

## Marquage de la présence

Après avoir enregistré la session, les membres du groupe apparaissent sur le côté droit de la page.

1. Cochez la case en regard de chaque personne qui a assisté.
2. Les modifications sont enregistrées automatiquement -- il n'y a pas de bouton Enregistrer supplémentaire pour les marques de présence.

:::info
Seuls les membres du groupe actuel apparaissent dans la liste de session. Si quelqu'un a assisté mais n'est pas encore dans le groupe, [ajoutez-le d'abord au groupe](../groups/group-members.md), puis enregistrez sa présence.
:::

## Export de la présence dans une feuille de calcul

Vous pouvez télécharger un enregistrement de la session sous forme de fichier CSV à utiliser dans Excel, Numbers ou Google Sheets.

1. Ouvrez la session que vous souhaitez exporter.
2. Cliquez sur le bouton **Télécharger CSV**.
3. Ouvrez le fichier téléchargé dans votre application de feuille de calcul.

## Affichage de la présence enregistrée

Après avoir enregistré les sessions, les données apparaissent dans vos rapports de présence.

- **Onglet Présence** -- affiche les tendances à l'échelle de l'église au fil du temps. Consultez [Suivi de la présence](tracking-attendance.md).
- **Onglet Groupes** -- affiche la présence ventilée par groupe individuel.

:::tip
Si une session que vous venez de créer n'apparaît pas dans les rapports immédiatement, assurez-vous que la date de la session se situe dans la plage de dates sélectionnée dans les filtres des rapports.
:::
