# Enregistrer la présence

<div class="article-intro">

Une fois vos campus, heures de service et groupes configurés, vous pouvez enregistrer manuellement la présence après chaque rassemblement. B1 Admin organise la présence autour de **sessions** -- une session par groupe par date de réunion. Vous créez la session, marquez qui a participé, et les données s'intègrent directement dans vos rapports de présence.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vos campus, heures de service et groupes doivent être configurés. Consultez [Configuration de la présence](setup.md) si vous ne l'avez pas encore fait.
- Les groupes que vous souhaitez suivre doivent avoir **Suivre la présence** activé. Consultez [Configuration de la présence](setup.md) pour plus de détails.

</div>

## Créer une session

Une session représente une occurrence d'une réunion de groupe -- par exemple, votre classe de maternelle à 3ème année un dimanche spécifique.

1. Ouvrez **B1 Admin**, ouvrez le **menu de section** dans le coin supérieur gauche et choisissez **Personnes**, puis cliquez sur l'onglet **Groupes**.
2. Sélectionnez le groupe pour lequel vous souhaitez enregistrer la présence.
3. Cliquez sur l'onglet **Sessions**.
4. Cliquez sur **Nouvelle** pour créer une nouvelle session.
5. Si le groupe est assigné à une heure de service, choisissez l'**Heure de service**. S'il s'agit d'un groupe non programmé, ce champ n'apparaîtra pas.
6. Sélectionnez la **Date de la session** -- cela peut être aujourd'hui, une date passée ou une date future.
7. Cliquez sur **Enregistrer**.

:::tip
Vous pouvez créer des sessions pour les dates passées pour rattraper la présence que vous n'avez pas encore enregistrée, ou les créer à l'avance afin qu'elles soient prêtes lorsque votre groupe se réunit.
:::

## Marquer la présence

Après avoir enregistré la session, les membres du groupe apparaissent sur le côté droit de la page.

1. Cochez la case à côté de chaque personne qui a participé.
2. Les modifications sont enregistrées automatiquement -- il n'y a pas de bouton Enregistrer supplémentaire pour les marques de présence.

:::info
Seuls les membres actuels du groupe apparaissent dans la liste des sessions. Si quelqu'un a participé mais n'est pas encore dans le groupe, [ajoutez-le au groupe](../groups/group-members.md) d'abord, puis enregistrez sa présence.
:::

## Exporter la présence vers une feuille de calcul

Vous pouvez télécharger un dossier de la session en tant que fichier CSV à utiliser dans Excel, Numbers ou Google Sheets.

1. Ouvrez la session que vous souhaitez exporter.
2. Cliquez sur le bouton **Télécharger CSV**.
3. Ouvrez le fichier téléchargé dans votre application de feuille de calcul.

## Afficher la présence enregistrée

Après avoir enregistré les sessions, les données apparaissent dans vos rapports de présence.

- **Onglet Présence** -- affiche les tendances à l'échelle de l'église au fil du temps. Consultez [Suivi de la présence](tracking-attendance.md).
- **Onglet Groupes** -- affiche la présence ventilée par groupe individuel.

:::tip
Si une session que vous venez de créer n'apparaît pas immédiatement dans les rapports, assurez-vous que la date de la session se situe dans la plage de dates sélectionnée dans les filtres des rapports.
:::
