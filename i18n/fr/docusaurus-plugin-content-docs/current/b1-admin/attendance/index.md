# Présences

<div class="article-intro">

La section Présences de B1 Admin vous donne une vue complète de qui se présente à votre église et de la manière dont vos groupes évoluent dans le temps. De la configuration des campus et des horaires de service à l'examen des tendances et à la mise en place de l'auto-enregistrement, tout ce dont vous avez besoin pour suivre et comprendre les présences est géré depuis cette page.

</div>

## Vue d'ensemble de la page

Lorsque vous ouvrez la page Présences, vous voyez un en-tête avec les statistiques clés sur la configuration des présences de votre église :

- **Campus** -- le nombre de sites physiques que vous avez configurés
- **Horaires de service** -- le nombre total de services sur tous les campus
- **Groupes planifiés** -- les groupes assignés à un horaire de service spécifique
- **Groupes non planifiés** -- les groupes qui suivent les présences indépendamment d'un horaire de service

Sous l'en-tête, trois onglets organisent vos outils de présences.

## Onglets

### Configuration

L'onglet **Configuration** est l'endroit où vous configurez les éléments de base du suivi des présences. C'est ici que vous définissez vos campus, ajoutez des horaires de service à chaque campus, et assignez des [groupes](../groups/creating-groups.md) à ces horaires de service. Vous n'avez besoin de le faire qu'une seule fois, bien que vous puissiez le mettre à jour chaque fois que votre planning change. Consultez [Configuration des présences](setup.md) pour un guide complet.

### Présences

L'onglet **Présences** affiche les tendances de présence dans le temps. Utilisez les filtres pour restreindre les résultats par période, campus ou horaire de service, et repérer rapidement les tendances dans vos données. Consultez [Suivi des présences](tracking-attendance.md) pour plus de détails sur l'utilisation des rapports et des filtres.

### Groupes

L'onglet **Groupes** répartit les présences par groupe individuel. C'est utile lorsque vous voulez voir comment se porte un petit groupe, une classe ou une équipe de ministère spécifique plutôt que de regarder les chiffres à l'échelle de l'église.
