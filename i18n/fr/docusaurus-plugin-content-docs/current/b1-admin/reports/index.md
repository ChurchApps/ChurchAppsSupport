# Rapports

<div class="article-intro">

La page Rapports vous donne un accès rapide aux rapports pré-construits qui vous aident à comprendre vos données d'église. Utilisez ces rapports pour suivre les tendances de présence, surveiller l'activité de donation et rester connecté avec votre congrégation par des célébrations d'anniversaire.

</div>

## Rapports disponibles

Les rapports n'ont pas d'entrée dans le menu de navigation de B1 Admin -- allez directement à l'URL du rapport que vous voulez (le mettre en signet est le moyen le plus facile d'y revenir). Chaque rapport s'ouvre directement sur ses filtres.

- **[Rapport d'anniversaire](./birthday-report)** (`admin.b1.church/reports/birthdays`) -- Consultez les anniversaires à venir pour les membres de votre congrégation.
- **[Rapport d'anniversaire de mariage](./anniversary-report)** (`admin.b1.church/reports/anniversaries`) -- Consultez les anniversaires de mariage à venir pour les membres de votre congrégation.
- **[Tendance de présence](./attendance-reports)** (`admin.b1.church/reports/attendanceTrend`) -- Voyez comment les modèles de présence changent au fil du temps dans vos services.
- **[Présence par groupe](./attendance-reports)** (`admin.b1.church/reports/groupAttendance`) -- Consultez les totaux de présence par groupe pour une plage de dates sélectionnée.
- **[Présence quotidienne par groupe](./attendance-reports)** (`admin.b1.church/reports/dailyGroupAttendance`) -- Obtenez une ventilation jour après jour des données de présence par groupe.
- **[Résumé des dons](./donation-summary)** (`admin.b1.church/reports/donationSummary`) -- Examinez les totaux et les tendances de donation pour la planification financière.
- **[Journal d'audit](./audit-log)** -- Suivez tous les changements et actions dans votre système de gestion d'église (trouvé sous Paramètres > Journal d'audit).

## Utilisation des rapports

1. Allez directement à l'URL du rapport, telle que **admin.b1.church/reports/birthdays**.
2. Utilisez les **filtres** en haut du rapport pour affiner les données par plage de dates, groupe, service ou d'autres critères.
3. Examinez les résultats affichés dans le rapport.

:::tip
Exécutez des rapports régulièrement pour rester au courant des tendances de présence, des anniversaires à venir et des modèles de donation. Ces données vous aident à planifier les ministères et la sensibilisation plus efficacement.
:::

:::info
Les données de rapport dépendent de la saisie cohérente des données. Assurez-vous que votre équipe [suit la présence](../attendance/tracking-attendance.md), [enregistre les donations](../donations/recording-donations.md) et maintient les [dossiers des personnes](../people/adding-people.md) à jour pour les résultats les plus précis.
:::
