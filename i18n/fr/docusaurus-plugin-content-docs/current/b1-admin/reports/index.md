# Rapports

B1 Admin vous donne plusieurs façons de récupérer des données sur votre congrégation, la présence et les donations. La génération de rapports est intégrée aux sections pertinentes de l'application plutôt qu'une seule page Rapports.

## Où trouver les rapports

### Personnes
- **[Listes d'anniversaires et d'anniversaires](./anniversary-report)** -- Filtrez par Mois d'anniversaire ou Mois d'anniversaire dans **Personnes → Recherche avancée** pour obtenir une liste des anniversaires ou anniversaires à venir.

### Présence
- **[Rapports de présence](../attendance/tracking-attendance.md)** -- Les tendances de présence et les données de présence par groupe se trouvent dans la section **Présence**.

### Donations
- **[Résumé des donations](../donations/donation-reports.md)** -- Les totaux de dons et ventilations de fonds se trouvent dans la section **Donations**.

### Paramètres
- **[Journal d'audit](../settings/church-settings.md)** -- Suivre tous les changements et actions dans votre système de gestion d'église.

:::info
Les données du rapport dépendent d'une saisie de données cohérente. Assurez-vous que votre équipe [suit la présence](../attendance/tracking-attendance.md), [enregistre les donations](../donations/recording-donations.md) et maintient [les dossiers des personnes](../people/adding-people.md) à jour pour les résultats les plus précis.
:::
