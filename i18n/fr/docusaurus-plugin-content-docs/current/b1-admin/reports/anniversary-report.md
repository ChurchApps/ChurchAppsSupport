# Liste d'Anniversaire

<div class="article-intro">

Avez-vous besoin d'une liste de tous ceux ayant un anniversaire de mariage un mois donné — pour le bulletin, les cartes ou les annonces ? La recherche Personnes vous permet de filtrer par **Mois d'Anniversaire** et d'afficher les dates directement dans les résultats.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Assurez-vous que les dates d'anniversaire sont entrées sur le profil de chaque personne. Voir [Ajouter des Personnes](../people/adding-people.md) pour les détails.
- Vous avez besoin de la permission de voir Personnes. Voir [Rôles et Permissions](../settings/roles-permissions.md).

</div>

## Obtenir une Liste d'Anniversaire pour un Mois

1. Ouvrez le **menu de section** dans le coin supérieur gauche et choisissez **Personnes**.
2. Sous la boîte de recherche, cliquez sur **Avancé**.
3. Développez la section **Démographie** et cochez **Mois d'Anniversaire**, puis choisissez le mois.
4. Exécutez la recherche — tous ceux ayant un anniversaire ce mois-ci apparaissent dans les résultats.
5. Pour voir les dates, cliquez sur l'**icône des colonnes** en haut à droite des résultats et activez la colonne **Anniversaire**. Utilisez **Exporter** pour télécharger la liste en tant que feuille de calcul si vous préférez la trier ou l'imprimer.

## Utilisations Pratiques

- **Bulletins hebdomadaires** -- Exécutez la liste du mois actuel et incluez les anniversaires dans votre bulletin ou annonces.
- **Cartes d'anniversaire** -- Exportez la liste du mois et confiez-la à votre équipe d'écriture de cartes.
- **Célébrations de jalons** -- Combiné avec le filtre **Années Mariées** pour trouver les anniversaires jalons.

:::tip
Exécutez ceci au début de chaque mois pour avoir le temps de préparer les cartes ou annonces avant les anniversaires.
:::

:::info
Les données d'anniversaire proviennent du champ d'anniversaire sur le profil de chaque personne. Si quelqu'un manque, son profil a juste besoin que la date soit ajoutée. Voir [Ajouter des Personnes](../people/adding-people.md).
:::
