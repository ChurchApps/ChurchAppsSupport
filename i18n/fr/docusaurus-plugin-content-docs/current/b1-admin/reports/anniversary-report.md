# Rapport d'anniversaire de mariage

<div class="article-intro">

Le rapport d'anniversaire de mariage vous aide à rester connecté avec votre congrégation en montrant les membres avec les anniversaires de mariage à venir. Utilisez-le pour planifier des célébrations, envoyer des cartes ou faire des annonces pendant les services.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Assurez-vous que les dates d'anniversaire de mariage sont entrées sur le profil de chaque personne. Voir [Ajouter des personnes](../people/adding-people.md) pour plus de détails.
- Vous devez avoir les [permissions](../settings/roles-permissions.md) appropriées pour accéder aux rapports

</div>

## Exécution du rapport

1. Allez directement à **admin.b1.church/reports/anniversaries** dans votre navigateur (les rapports n'ont pas d'entrée dans le menu de navigation — mettre en signet l'adresse est le moyen le plus facile d'y revenir).
2. Choisissez le **Mois** que vous voulez dans la liste déroulante. Vous pouvez optionnellement limiter les résultats à un seul **Groupe**.
3. Cliquez sur **Exécuter le rapport**. Le rapport liste tout le monde avec un anniversaire de mariage dans ce mois, avec la date — prêt à lire directement dans un bulletin ou une liste d'annonces.

## Ce que le rapport affiche

Le rapport d'anniversaire de mariage affiche :

- **Anniversaire de mariage** -- La date de leur anniversaire de mariage.
- **Nom** -- Le nom de la personne de votre base de données d'église.

Les résultats couvrent le mois que vous avez sélectionné, ce qui facilite la visualisation de qui a un anniversaire de mariage à venir.

## Utilisations pratiques

- **Annonces hebdomadaires** -- Exécutez le rapport pour la semaine à venir et incluez les anniversaires de mariage dans votre bulletin ou vos annonces.
- **Cartes d'anniversaire de mariage** -- Générez une liste pour le mois et demandez à votre équipe d'envoyer des cartes d'anniversaire de mariage personnelles.
- **Animateurs de petits groupes** -- Les animateurs de groupe peuvent exécuter le rapport pour se souvenir des anniversaires de mariage des membres de leur groupe.
- **Célébrations de jalons** -- Filtrez des plages de dates spécifiques pour planifier les célébrations d'anniversaires de jalons.

:::tip
Exécutez ce rapport au début de chaque mois pour planifier à l'avance. Vous pouvez définir la plage de dates pour couvrir le mois entier afin d'avoir le temps de préparer des cartes ou des annonces.
:::

:::info
Les données d'anniversaire de mariage proviennent du champ anniversaire de mariage sur le profil de chaque personne. Assurez-vous que vos [dossiers d'adhésion](../people/adding-people.md) sont à jour pour des résultats précis.
:::
