# Notifications et messages

<div class="article-intro">

B1 Admin regroupe vos notifications et vos messages privés dans le menu utilisateur, en haut à droite de chaque page. Un chiffre rouge sur votre photo de profil indique le nombre de notifications et de messages non lus qui vous attendent, et il se met à jour pendant que vous travaillez, sans rafraîchir la page.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Connectez-vous à [B1 Admin](https://admin.b1.church). Chaque utilisateur connecté dispose de notifications et de messages.
- Les notifications et les messages sont personnels : vous ne voyez que ceux qui vous sont adressés.

</div>

## Ouvrir le menu utilisateur {#opening-the-user-menu}

Cliquez sur votre photo de profil (ou sur la flèche à côté) en haut à droite. Le menu affiche votre **Église actuelle** ainsi que les éléments suivants :

- **Messages** et **Notifications**, chacun avec son propre nombre d'éléments non lus
- **Modifier le profil** -- **Modifier le compte** ouvre votre [profil](./profile/managing-profile.md), et **Modifier le profil de l'église** ouvre votre profil d'annuaire sur le site B1 de votre église
- **Préférences de thème** -- couleurs **Par défaut**, **Classique** ou **Personnalisé**, et mode **Clair** ou **Sombre**
- **Déconnexion**, **Changer d'application** (B1.Church ou Lessons.church) et **Changer d'église** (affiche la liste des églises auxquelles votre compte appartient)

## Notifications {#notifications}

Les notifications vous signalent les éléments qui requièrent votre attention, par exemple :

- Une [tâche](./serving/tasks.md) vous a été assignée, ou une tâche de demande d'adhésion à un groupe a été créée à votre intention
- Vous avez été planifié pour servir sur un [plan](./serving/plans.md)
- Une nouvelle réponse est arrivée sur un [formulaire](./forms/managing-submissions.md) que vous gérez
- Quelqu'un a publié dans l'un de vos groupes ou a envoyé une annonce

Pour les lire :

1. Ouvrez le menu utilisateur et cliquez sur **Notifications**.
2. Chaque notification affiche un bref message, le temps écoulé depuis sa réception (par exemple **1j**), et une étiquette **Nouveau** si vous ne l'avez pas encore vue. Ouvrir la liste marque les notifications comme lues et remet le compteur à zéro.
3. Cliquez sur **Voir les détails** (ou sur la notification) pour accéder à son sujet :
   - Une tâche ouvre la tâche dans B1 Admin.
   - Une réponse de formulaire ouvre les réponses du formulaire dans B1 Admin.
   - Une affectation de service ouvre le plan sur le site B1 de votre église dans un nouvel onglet, où vous pouvez l'accepter ou la refuser.
   - Les autres notifications ouvrent leur lien, s'il en existe un, dans un nouvel onglet.
4. Cliquez sur l'icône de corbeille pour supprimer une notification, ou sur **Tout effacer** (puis confirmez) pour toutes les supprimer.

Lorsqu'il ne reste plus rien, la liste indique **Aucune notification -- Vous êtes à jour !**

:::tip
La manière dont vous êtes averti (notification push, courriel, cloche dans l'application ou SMS) ainsi que les heures de silence se configurent dans vos [Préférences de notification](../b1-church/getting-started/notification-preferences.md), sur le site B1 de votre église ou dans l'application B1.
:::

## Messages {#messages}

**Messages** regroupe vos conversations privées individuelles avec les personnes de votre église -- les mêmes conversations que celles que vous voyez sur le site B1 de votre église et dans l'application B1.

### Lire et répondre {#reading-and-replying}

1. Ouvrez le menu utilisateur et cliquez sur **Messages**. Chaque conversation affiche l'autre personne, le dernier message (précédé de **Vous :** si vous l'avez envoyé), la date d'envoi, et une étiquette **Nouveau** s'il n'a pas été lu.
2. Cliquez sur une conversation pour l'ouvrir. Saisissez votre texte dans **Saisissez un message...** puis cliquez sur la flèche d'envoi. Le bouton emoji ajoute un emoji.
3. Cliquez sur la flèche de retour pour revenir à la liste.

Pour supprimer une conversation, cliquez sur son icône de corbeille et confirmez.

### Démarrer un nouveau message {#starting-a-new-message}

1. Dans **Messages**, cliquez sur le bouton rond **+**.
2. Sous **Rechercher une personne**, saisissez un nom et cliquez sur **Rechercher**.
3. Cliquez sur la personne, rédigez votre message, puis envoyez-le.
