# Affichage numérique

<div class="article-intro">

Envoyez le contenu de vos leçons vers un téléviseur du hall d'accueil ou d'un couloir à l'aide d'un flux d'affichage numérique. Chaque type de plan dispose d'une URL de flux qui affiche toujours le contenu du plan en cours, de sorte qu'il n'y a rien à mettre à jour chaque semaine. Si vos téléviseurs utilisent FreePlay, vous pouvez plutôt y planifier le type de plan dans FreePlay Admin.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Configurez un [type de plan](./plans.md) avec [Lessons.church](../../b1-church/content/lessons.md) ou un autre contenu de leçon planifié
- Ayez un compte [SignPresenter](https://www.signpresenter.com) et un appareil configuré pour l'afficher, ou un téléviseur qui exécute [FreePlay](../../freeplay/)

</div>

## Obtenir l'URL du flux

1. Allez dans **Service**, sélectionnez le ministère qui contient votre type de plan, puis cliquez sur le type de plan pour l'ouvrir.
2. Cliquez sur **Affichage numérique** (l'icône de téléviseur) en haut de la page du type de plan.
3. Dans la fenêtre **Flux d'affichage numérique**, cliquez sur le bouton de copie à côté de **URL du flux**.

:::info
L'URL du flux est liée au type de plan, et non à un plan unique. Elle suit automatiquement le plan actuellement défini pour ce type de plan. Vous n'avez donc besoin de la configurer qu'une seule fois.
:::

## Connexion à SignPresenter

Le flux est conçu pour fonctionner avec [SignPresenter](https://www.signpresenter.com), une application d'affichage numérique tierce. Collez l'URL copiée dans SignPresenter en tant que flux externe pour afficher le contenu de votre leçon en cours sur un écran connecté.

Pour la configuration pas à pas dans SignPresenter, consultez le [guide Lessons.church de SignPresenter](https://support.signpresenter.com/topics/lessons-dot-church.html). La fenêtre contient aussi des liens vers ces instructions.

## Utiliser plutôt des téléviseurs FreePlay

Si vos écrans utilisent [FreePlay](../../freeplay/), vous n'avez pas besoin de l'URL du flux. La fenêtre **Flux d'affichage numérique** renvoie vers **admin.freeplay.church/calendar**, où vous pouvez planifier ce type de plan sur vos téléviseurs FreePlay :

1. Cliquez sur le lien **admin.freeplay.church/calendar** dans la fenêtre. FreePlay Admin utilise le même identifiant que B1 Admin.
2. Choisissez le groupe d'écrans correspondant à vos téléviseurs et cliquez sur **Ajouter une planification**.
3. Sous **Lecture**, choisissez votre type de plan dans **Plans de service**. Il est marqué **(plan actuel)**.
4. Définissez les jours et les heures, puis cliquez sur **Enregistrer**.

Les téléviseurs diffusent chaque semaine le plan en cours pour ce type de plan, aux heures que vous avez définies. Voir [Planifier le calendrier](../../freeplay/scheduled-mode/scheduling-the-calendar) pour toutes les options, et [Associer un écran](../../freeplay/scheduled-mode/pairing-a-screen) pour ajouter un téléviseur.

- Planifiez le contenu avec [Lessons.church](./scheduling-lessons.md)
- Planifiez vos téléviseurs FreePlay avec le [mode planifié](../../freeplay/scheduled-mode/)
