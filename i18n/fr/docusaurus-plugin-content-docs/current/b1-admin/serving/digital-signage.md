# Signalisation numérique

<div class="article-intro">

Envoyez le contenu de votre leçon vers un téléviseur dans un hall ou un couloir en utilisant un flux de signalisation numérique. Chaque type de plan obtient une URL de flux qui joue toujours le contenu du plan actuel, donc il n'y a rien à mettre à jour semaine après semaine.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Configurez un [type de plan](./plans.md) avec [Lessons.church](../../b1-church/content/lessons.md) ou autre contenu de leçon programmé
- Ayez un compte [SignPresenter](https://www.signpresenter.com) et un appareil configuré pour l'afficher

</div>

## Obtenir l'URL du flux

1. Accédez à **Service** et ouvrez le ministère contenant votre type de plan.
2. Cliquez sur le bouton **Signalisation numérique** (l'icône RSS) sur la page du type de plan.
3. Copiez l'URL du flux affichée dans la boîte de dialogue.

:::info
L'URL du flux est liée au type de plan, pas à un seul plan. Elle suit automatiquement le plan programmé comme courant pour ce type de plan, donc vous n'avez besoin de le configurer qu'une seule fois.
:::

## Connexion à SignPresenter

Le flux est conçu pour fonctionner avec [SignPresenter](https://www.signpresenter.com), une application de signalisation numérique tierce. Collez l'URL copiée dans SignPresenter comme flux externe pour afficher le contenu de votre leçon actuelle sur un écran connecté.

Pour les instructions étape par étape dans SignPresenter, voir le [guide Lessons.church de SignPresenter](https://support.signpresenter.com/topics/lessons-dot-church.html).

## Étapes suivantes

- Gérez les plans qui alimentent cet écran de signalisation sur la page [Plans](./plans.md)
- Programmez le contenu avec [Lessons.church](./scheduling-lessons.md)
