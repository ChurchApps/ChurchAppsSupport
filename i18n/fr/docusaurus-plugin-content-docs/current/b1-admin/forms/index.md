# Formulaires

<div class="article-intro">

La section Formulaires vous permet de créer des formulaires personnalisés pour les inscriptions, les enquêtes, la collecte de données, et plus. Que vous ayez besoin d'une carte de visite, d'une inscription à un événement ou d'un formulaire de demande de prière, vous pouvez la construire ici et la partager avec votre congrégation via un lien public ou votre site web B1.church.

</div>

## La page des formulaires

Quand vous ouvrez **Forms**, vous verrez ces onglets :

- **Forms** -- Affiche tous vos formulaires actifs.
- **Archived Forms** -- Affiche les formulaires qui ont été archivés. Vous pouvez restaurer les formulaires archivés à tout moment. Cet onglet n'apparaît qu'une fois qu'au moins un formulaire a été archivé.

Chaque formulaire dans la liste affiche son nom et, s'il est configuré, une URL publique que vous pouvez partager en externe.

## Ce que vous pouvez faire

À partir de la page Formulaires, vous pouvez :

- **Ajouter un formulaire** -- Cliquez sur **Add Form** pour créer un nouveau formulaire personnalisé.
- **Modifier un formulaire** -- Cliquez sur un nom de formulaire pour l'ouvrir et modifier ses questions, ses membres ou ses paramètres.
- **Archiver un formulaire** -- Déplacez les formulaires dont vous n'avez plus besoin vers l'onglet **Archived Forms** pour garder votre liste propre.
- **Restaurer un formulaire** -- Basculez vers l'onglet **Archived Forms** et restaurez n'importe quel formulaire que vous voulez rendre actif à nouveau.

## Travailler avec un formulaire

Cliquez sur n'importe quel nom de formulaire pour l'ouvrir. L'éditeur de formulaire a jusqu'à trois onglets :

- **Questions** -- Construisez la structure du formulaire en ajoutant des champs de différents types. Voir [Creating Forms](./creating-forms.md) pour plus de détails.
- **Form Members** -- Contrôlez qui peut accéder au formulaire et le gérer (formulaires autonomes uniquement).
- **Form Submissions** -- Affichez les réponses qui ont été soumises. Voir [Managing Submissions](./managing-submissions.md) pour plus de détails.

:::tip
Les formulaires avec une URL publique peuvent être partagés via un lien, intégrés sur votre site web ou inclus dans des emails. Cela facilite la collecte d'informations auprès de personnes qui pourraient ne pas avoir de compte d'église.
:::

:::info
Vous pouvez contrôler qui a accès à chaque formulaire en utilisant l'onglet **Form Members**. Attribuez les rôles **Admin** ou **View Only** pour donner à votre équipe le bon niveau d'accès.
:::
