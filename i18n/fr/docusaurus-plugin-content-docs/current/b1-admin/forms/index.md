# Formulaires

<div class="article-intro">

La section Formulaires vous permet de créer des formulaires personnalisés pour les inscriptions, les sondages, la collecte de données et bien plus encore. Qu'il s'agisse d'une carte de visiteur, d'une inscription à un événement ou d'un formulaire de demande de prière, vous pouvez le créer ici et le partager avec votre communauté par un lien public ou votre site B1.church.

</div>

## La page Formulaires {#the-forms-page}

Lorsque vous ouvrez **Formulaires**, vous voyez ces onglets :

- **Formulaires** -- Affiche tous vos formulaires actifs.
- **Formulaires archivés** -- Affiche les formulaires archivés. Vous pouvez restaurer les formulaires archivés à tout moment. Cet onglet n'apparaît qu'une fois qu'au moins un formulaire a été archivé.

Le nombre de formulaires est affiché au-dessus de la liste. Chaque formulaire de la liste affiche son nom et, pour les formulaires Autonomes, son adresse web publique que vous pouvez partager à l'extérieur (les formulaires Personnes affichent plutôt **Formulaire de profil de personne**). Passez la souris sur une ligne (sur téléphone, les liens sont toujours affichés) pour voir ses actions : **Modifier**, **Imprimer**, **Code QR** (formulaires Autonomes uniquement), **Dupliquer** et **Archiver**. Les formulaires archivés affichent **Imprimer** et **Restaurer**.

## Ce que vous pouvez faire {#what-you-can-do}

Depuis la page Formulaires, vous pouvez :

- **Ajouter un formulaire** -- Cliquez sur **Ajouter un formulaire** pour créer un nouveau formulaire personnalisé.
- **Rechercher un formulaire** -- Saisissez dans la zone **Rechercher un formulaire** pour filtrer la liste par nom.
- **Modifier un formulaire** -- Cliquez sur le nom d'un formulaire pour l'ouvrir et modifier ses questions, ses membres ou ses paramètres, ou cliquez sur **Modifier** sur sa ligne pour changer ses paramètres directement sur la page Formulaires.
- **Imprimer, partager ou copier un formulaire** -- Voir [Imprimer un formulaire vierge](./creating-forms.md#printing-a-blank-form), [Partager un formulaire avec un code QR](./creating-forms.md#sharing-a-form-with-a-qr-code) et [Dupliquer un formulaire](./creating-forms.md#duplicating-a-form).
- **Archiver un formulaire** -- Cliquez sur **Archiver** et confirmez pour déplacer un formulaire dont vous n'avez plus besoin vers l'onglet **Formulaires archivés** et garder votre liste propre. Ses soumissions sont conservées.
- **Restaurer un formulaire** -- Passez à l'onglet **Formulaires archivés**, cliquez sur **Restaurer** et confirmez pour rendre le formulaire à nouveau actif.

## Travailler avec un formulaire {#working-with-a-form}

Cliquez sur le nom d'un formulaire pour l'ouvrir. La partie gauche de la page affiche le nom du formulaire, son type et son lien public, avec un bouton **Modifier le formulaire** pour ses [paramètres](./creating-forms.md#configuring-form-properties) et un lien **Formulaires** pour revenir à la liste. Le formulaire comporte jusqu'à trois onglets, selon vos accès :

- **Questions** -- Construisez la structure du formulaire en ajoutant des champs de différents types. Voir [Créer des formulaires](./creating-forms.md) pour plus de détails.
- **Membres du formulaire** -- Contrôlez qui peut accéder au formulaire et le gérer (formulaires autonomes uniquement).
- **Soumissions du formulaire** -- Consultez les réponses soumises. Voir [Gérer les soumissions](./managing-submissions.md) pour plus de détails.

:::tip
Les formulaires dotés d'une adresse web publique peuvent être partagés par lien, intégrés sur votre site web ou inclus dans des courriels. Cela facilite la collecte d'informations auprès de personnes qui n'ont peut-être pas de compte dans votre église.
:::

:::info
Vous pouvez contrôler qui a accès à chaque formulaire grâce à l'onglet **Membres du formulaire**. Attribuez les rôles **Administrateur** ou **Consultation seulement** pour donner à votre équipe le niveau d'accès approprié.
:::
