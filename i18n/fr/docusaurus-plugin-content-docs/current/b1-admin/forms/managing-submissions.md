# Gestion des Soumissions

<div class="article-intro">

Une fois que votre formulaire est actif, les soumissions commencent à arriver. L'onglet Soumissions vous permet d'examiner chaque réponse, de suivre qui a soumis et d'utiliser les données pour assurer le suivi auprès de votre congrégation de manière opportune.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- [Créez un formulaire](./creating-forms.md) avec au moins une question
- Partagez le formulaire via son URL publique ou intégrez-le sur votre [site Web](../website/managing-pages.md)

</div>

## Affichage des soumissions

1. Ouvrez **Personnes** à partir du menu de section, puis cliquez sur **Formulaires** dans la barre de navigation.
2. Cliquez sur le formulaire que vous souhaitez examiner.
3. Allez à l'onglet **Soumissions**.

Vous verrez une liste de toutes les réponses reçues pour ce formulaire. Chaque soumission affiche les informations du répondant et la date à laquelle elle a été soumise.

## Examen des soumissions individuelles

Cliquez sur n'importe quelle soumission pour afficher les détails complets. Vous verrez toutes les réponses que la personne a fournies pour chaque question du formulaire.

Cliquez sur l'**icône d'impression** à côté de la soumission pour imprimer les réponses remplies de cette personne -- utile pour un fichier papier ou une version signée que vous avez besoin de conserver. Ceci est distinct de l'[impression d'un formulaire vierge](./creating-forms.md#printing-a-blank-form) ; il imprime les réponses déjà soumises d'une personne, pas une copie vierge. La même icône d'impression apparaît partout où une soumission est affichée, y compris sur le [profil d'une personne](../people/adding-people.md#working-with-forms).

## Comment les soumissions sont collectées

Les soumissions peuvent provenir de plusieurs canaux :

- **URL publique** -- Si votre formulaire a une URL publique (formulaires autonomes), n'importe qui ayant le lien peut soumettre une réponse. Partagez l'URL par e-mail, sur les réseaux sociaux ou par SMS.
- **Intégré sur votre site Web** -- Les formulaires intégrés sur votre site Web B1 collectent automatiquement les soumissions lorsque les visiteurs les remplissent.
- **Utilisation interne** -- Le personnel et les bénévoles peuvent également soumettre des formulaires au nom d'autres personnes directement dans B1 Admin.

:::tip
Vérifiez régulièrement l'onglet **Soumissions** pour les formulaires comme les cartes de visiteurs ou les demandes de prière, afin que vous puissiez faire un suivi rapidement.
:::

## Utilisation des données de soumission

Les données collectées par les formulaires peuvent vous aider à :

- Suivre les inscriptions aux événements et planifier en conséquence
- Assurer le suivi auprès des visiteurs ou des nouveaux membres
- Collecter les commentaires des sondages pour la planification du ministère
- Traiter les paiements pour les événements ou les programmes

:::info
Les membres du formulaire avec les rôles **Admin** ou **Affichage uniquement** peuvent accéder à l'onglet Soumissions. Assurez-vous que les bonnes personnes de votre équipe ont accès aux formulaires dont elles ont besoin en gérant les rôles dans l'onglet **Membres**.
:::

:::tip
Si un formulaire **Autonome** est défini pour créer un enregistrement de personne, les soumissions correspondant à une personne existante s'affichent également sur l'onglet **Formulaires** propre à cette personne dans la section Personnes -- pas seulement pour les formulaires de type Personnes.
:::
