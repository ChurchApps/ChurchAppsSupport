# Listes sauvegardées

<div class="article-intro">

Les **listes sauvegardées** vous permettent de stocker une requête de recherche sous un nom et de la réexécuter en un seul clic à tout moment. Construisez une liste une fois -- « Membres actifs au campus nord », « Visiteurs au cours des 90 derniers jours » ou tout filtre avancé -- et elle reste dans le panneau **Listes sauvegardées** de la page Personnes pour que vous n'ayez jamais à reconstruire la requête.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Exécutez au moins une recherche dans la section Personnes pour avoir des résultats à enregistrer. Consultez [Recherche de personnes](./searching-people.md) ou [Recherche IA](./ai-search.md).

</div>

## Enregistrement d'une recherche comme liste

1. Exécutez une recherche sur la page **Personnes** -- une recherche rapide, une recherche IA ou une recherche de filtre avancé.
2. Quand les résultats apparaissent, un bouton **Enregistrer comme liste** s'affiche dans l'en-tête de la page Personnes.
3. Cliquez sur **Enregistrer comme liste**.
4. Entrez un **Nom** pour la liste (obligatoire).
5. Entrez optionnellement une **Catégorie** pour grouper les listes connexes dans le panneau **Listes sauvegardées**.
6. Cliquez sur **Enregistrer**.

La liste est maintenant enregistrée dans le compte de votre église et apparaîtra dans le panneau **Listes sauvegardées** sur le côté gauche de la page Personnes.

:::info
Les listes sont partagées dans votre église -- quiconque ayant accès aux Personnes peut les voir et les charger. Seul le personnel ayant les permissions appropriées peut renommer ou supprimer les listes.
:::

## Chargement d'une liste sauvegardée

Dans le panneau **Listes sauvegardées** sur le côté gauche de la page Personnes, cliquez sur n'importe quel nom de liste. La recherche se réexécute instantanément avec la requête stockée, mettant à jour le tableau des résultats.

:::tip
Les listes sont des **requêtes en direct**, pas des instantanés. Chaque fois que vous chargez une liste, la recherche s'exécute à nouveau sur vos données actuelles.
:::

## Renommage et suppression de listes

Le personnel avec la permission de gestion peut renommer ou supprimer n'importe quelle liste directement à partir du panneau Listes sauvegardées.

- Cliquez sur l'**icône du crayon** en regard d'un nom de liste pour la renommer.
- Cliquez sur l'**icône de la corbeille** pour la supprimer.

## Cas d'usage

| Scénario | Comment construire la liste |
|----------|---------------------------|
| Tous les visiteurs | Recherche avancée : Statut d'adhésion = Visiteur |
| Membres sur un campus spécifique | Recherche avancée : Campus = [votre campus] |
| Personnes sans adresse e-mail | Recherche avancée : E-mail est vide |
| Résultats d'une question IA | Posez une question dans Recherche IA, puis enregistrez |
