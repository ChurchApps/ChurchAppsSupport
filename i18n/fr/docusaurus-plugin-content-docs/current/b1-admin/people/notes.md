# Notes

<div class="article-intro">

La page **Notes** rassemble au même endroit les notes récentes de l'ensemble de B1 Admin, afin que vous puissiez suivre les soins pastoraux, les suivis et la planification sans ouvrir chaque fiche. Elle liste les notes rédigées sur des personnes, sur les groupes que vous dirigez, sur les événements du calendrier et sur les cartes de flux de travail, les plus récentes en premier, et renvoie chacune vers l'endroit où elle a été rédigée.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- La page **Notes** apparaît dans le menu si vous avez l'autorisation **Modifier les personnes** ou si vous dirigez au moins un groupe. Voir [Attribuer des rôles](./roles-permissions.md).
- La page n'affiche que les notes que vous êtes déjà autorisé à lire. Chaque onglet suit les mêmes règles que la fiche à laquelle appartiennent les notes (voir [Ce que montre chaque onglet](#what-each-tab-shows)).

</div>

## Ouvrir la page Notes

1. Ouvrez le [menu de navigation rapide](../introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche de B1 Admin) et développez **Personnes**.
2. Cliquez sur **Notes**.
3. La page s'ouvre sur l'onglet **Personnes**. Utilisez les onglets de l'en-tête de la page pour passer entre **Personnes**, **Groupes**, **Événements** et **Flux de travail**.

## Lire la liste

Chaque note de la liste affiche :

- **Où elle a été rédigée** -- le nom de la personne, le nom du groupe, le titre de l'événement ou le titre de la carte de flux de travail. Cliquez sur le nom pour ouvrir cette fiche et lire le fil complet ou ajouter une note.
- **Confidentielle** -- un badge sur les notes de personnes provenant de la section Notes confidentielles de la personne.
- **Auteur et date** -- « Par » suivi du nom de l'auteur, puis de la date et de l'heure de publication.
- **La note elle-même** -- les notes longues sont raccourcies dans la liste. Ouvrez la fiche pour lire la note complète.

La liste affiche les notes les plus récentes en premier. Cliquez sur **Charger plus** au bas de la liste pour voir les plus anciennes.

Les notes rédigées sur une personne qui a été supprimée depuis, ou fusionnée dans une autre fiche, n'apparaissent pas dans l'onglet **Personnes**.

La page Notes est en lecture seule. Pour ajouter, modifier ou répondre à une note, cliquez sur le nom de la fiche pour l'ouvrir.

## Ce que montre chaque onglet {#what-each-tab-shows}

| Onglet | Notes affichées | Qui peut les voir | Clic sur le nom ouvre |
|-----|-------------|------------------|-------------------------|
| **Personnes** | Notes sur les fiches de personnes | Les personnes disposant de **Modifier les personnes**. Les notes confidentielles exigent aussi **Voir les notes confidentielles** | Les notes de la personne |
| **Groupes** | [Notes des responsables](../groups/group-members.md#leader-notes) sur les groupes | Uniquement les responsables de chaque groupe, même pour les administrateurs | Les notes du groupe |
| **Événements** | [Notes d'événement](../calendars/creating-calendars.md#event-notes) | Le personnel qui peut modifier le contenu ou administrer les calendriers, ainsi que toute personne autorisée par le paramètre **Qui peut voir les notes** de l'événement | Le calendrier du groupe de l'événement |
| **Flux de travail** | Notes sur les [cartes de flux de travail](../serving/workflows.md#working-the-board) | Toute personne pouvant ouvrir la carte, y compris la personne ou le groupe auquel elle est assignée | Le tableau de flux de travail de la carte |

Si un onglet ne contient rien que vous puissiez voir pour l'instant, il l'indique -- par exemple, « Aucune note pour les groupes que vous dirigez pour le moment. »

:::tip
Les fils de notes ont une icône de cloche pour les notifications. Cliquez dessus pour être averti des nouvelles notes de ce fil (l'icône change aussitôt), et cliquez à nouveau pour les mettre en sourdine. Ces réglages activé/désactivé n'apparaissent jamais comme notes sur la page Notes.
:::
