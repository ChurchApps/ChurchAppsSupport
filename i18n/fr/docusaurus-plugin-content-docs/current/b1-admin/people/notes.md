# Notes

<div class="article-intro">

La page **Notes** rassemble les notes récentes de l'ensemble de B1 Admin en un seul endroit, afin que vous puissiez faire le point sur le suivi pastoral, les relances et la planification sans ouvrir chaque fiche. Elle liste les notes rédigées sur les personnes, sur les groupes que vous dirigez, sur les événements du calendrier et sur les cartes de workflow, de la plus récente à la plus ancienne, et renvoie chacune vers l'endroit où elle a été écrite.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- La page **Notes** apparaît dans le menu si vous disposez de l'autorisation **Edit People** ou si vous dirigez au moins un groupe. Voir [Attribuer des rôles](./roles-permissions.md).
- La page n'affiche que les notes que vous êtes déjà autorisé à lire. Chaque onglet suit les mêmes règles que la fiche à laquelle appartiennent les notes (voir [Contenu de chaque onglet](#what-each-tab-shows)).

</div>

## Ouvrir la page Notes

1. Ouvrez le [menu de navigation rapide](../introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche de B1 Admin) et développez **People**.
2. Cliquez sur **Notes**.
3. La page s'ouvre sur l'onglet **People**. Utilisez les onglets de l'en-tête de la page pour basculer entre **People**, **Groups**, **Events** et **Workflows**.

## Lire la liste

Chaque note de la liste affiche :

- **Où elle a été écrite** -- le nom de la personne, le nom du groupe, le titre de l'événement ou le titre de la carte de workflow. Cliquez sur le nom pour ouvrir cette fiche, lire le fil complet ou ajouter une note.
- **Confidentiel** -- un badge sur les notes de personnes provenant de la section Notes confidentielles de la personne.
- **Qui l'a écrite et quand** -- « By » suivi du nom de l'auteur, puis de la date et de l'heure de publication.
- **La note elle-même** -- les notes longues sont raccourcies dans la liste. Ouvrez la fiche pour lire la note en entier.

La liste affiche les notes les plus récentes en premier. Cliquez sur **Load more** en bas de la page pour voir les plus anciennes.

La page Notes est en lecture seule. Pour ajouter, modifier ou répondre à une note, cliquez sur le nom de la fiche pour l'ouvrir.

## Contenu de chaque onglet {#what-each-tab-shows}

| Onglet | Notes affichées | Qui peut les voir | Cliquer sur le nom ouvre |
|-----|-------------|------------------|-------------------------|
| **People** | Notes sur les fiches de personnes | Les personnes disposant de **Edit People**. Les notes confidentielles nécessitent aussi **View Confidential Notes** | Les notes de la personne |
| **Groups** | [Notes du responsable](../groups/group-members.md#leader-notes) sur les groupes | Uniquement les responsables de chaque groupe, même pour les administrateurs | Les notes du groupe |
| **Events** | [Notes d'événement](../calendars/creating-calendars.md#event-notes) | Le personnel autorisé à modifier le contenu ou à administrer les calendriers, ainsi que toute personne autorisée par le paramètre **Who can view notes** de l'événement | Le calendrier du groupe de l'événement |
| **Workflows** | Notes sur les [cartes de workflow](../serving/workflows.md#working-the-board) | Toute personne pouvant ouvrir la carte, y compris la personne ou le groupe à qui elle est assignée | Le tableau de workflow de la carte |

Si un onglet ne contient encore rien que vous puissiez voir, la page l'indique -- par exemple, « No notes yet for groups you lead. » (Aucune note pour le moment pour les groupes que vous dirigez.)

:::tip
Les fils de notes disposent d'une icône de cloche pour les notifications. Cliquez dessus pour être averti des nouvelles notes de ce fil (l'icône change immédiatement), et cliquez à nouveau pour les mettre en sourdine. Ces réglages activé/désactivé n'apparaissent jamais comme des notes sur la page Notes.
:::
