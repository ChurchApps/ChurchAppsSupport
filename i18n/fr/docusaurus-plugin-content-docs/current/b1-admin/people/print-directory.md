# Annuaire imprimé

<div class="article-intro">

La fonctionnalité Annuaire imprimé génère un annuaire des membres mis en forme et imprimable pour votre église. Il regroupe les membres par foyer, comprend les coordonnées et les photos, et est conçu pour un rendu professionnel sur du papier format lettre standard.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin d'un compte B1 Admin actif avec l'autorisation de consulter les personnes.
- Pour un meilleur résultat, les personnes de votre annuaire doivent avoir une photo et des coordonnées renseignées.

</div>

## Ouvrir l'annuaire imprimé {#opening-the-print-directory}

1. Accédez à **Personnes** dans B1 Admin.
2. Cliquez sur **Annuaire imprimé** dans l'en-tête de la page Personnes.
3. L'annuaire imprimé s'ouvre dans un nouvel onglet du navigateur et commence à charger les données de votre annuaire.
4. Après environ 1,5 seconde, la boîte de dialogue d'impression de votre navigateur apparaît automatiquement.

:::tip
L'annuaire s'ouvre dans un onglet distinct afin que vous puissiez l'imprimer sans quitter la page Personnes. Une fois la boîte de dialogue d'impression fermée, cet onglet revient à la page Personnes : vous pouvez le fermer ou continuer à travailler dedans.
:::

## Ce qui est inclus {#what-gets-included}

L'annuaire imprimé comprend l'ensemble des **membres actifs** de votre église. Plus précisément :

- Les personnes ayant le statut d'appartenance **Inactif**, **Visiteur** ou **Décédé** sont automatiquement exclues.
- Les personnes qui se sont **retirées** de l'annuaire sont exclues.
- Toutes les autres personnes sont regroupées par **foyer**.

### Imprimer uniquement vos résultats de recherche {#printing-only-your-search-results}

Après avoir effectué une recherche sur la page Personnes -- une recherche rapide, une [recherche avancée](./searching-people.md#advanced-search), une [liste enregistrée](./lists.md) ou une [recherche IA](./ai-search.md) -- le bouton **Annuaire imprimé** devient **Imprimer les résultats**. En cliquant dessus, vous imprimez un annuaire ne contenant que les personnes de vos résultats plutôt que l'ensemble de l'église, avec la même mise en page.

Lors de l'impression des résultats de recherche, le filtre de statut d'appartenance ci-dessus ne s'applique pas : toutes les personnes recherchées sont incluses, même les visiteurs ou les personnes inactives. Les personnes qui se sont retirées de l'annuaire restent exclues. Pour revenir à l'impression de l'annuaire complet, effacez d'abord votre recherche.

## Mise en page de l'annuaire {#directory-layout}

L'annuaire imprimé comprend deux parties :

### Page de couverture {#cover-page}

La première page comprend :
- Le logo de votre église, s'il est défini
- Le nom de votre église
- Le titre « Annuaire des membres »
- L'année en cours
- La ville et la province ou l'État de votre église
- La date d'impression et le nombre de foyers inclus

### Fiches des membres {#member-listings}

Les pages suivantes répertorient les foyers par ordre alphabétique de nom de famille. Chaque fiche de foyer affiche :

- **Photos** -- Vignettes circulaires de chaque membre du foyer, avec leur nom en dessous
- **Nom d'affichage du foyer** -- Par exemple, « La famille Martin », « Jean et Julie Dupont », ou simplement le nom de la personne pour les personnes seules
- **Adresse** -- Adresse postale, ville, province ou état, et code postal
- **Téléphone** -- Le numéro de domicile, ou un numéro mobile si aucun membre du foyer n'a de numéro de domicile
- **Courriel** -- Adresse courriel principale
- **Anniversaires** -- Le prénom et la date d'anniversaire (mois et jour) de chaque membre
- **Anniversaire de mariage** -- S'il est renseigné

Les foyers sont organisés en **sections alphabétiques** (A, B, C, ...), avec un en-tête de section décoratif avant chaque groupe de lettre. Deux fiches de foyer apparaissent côte à côte sur chaque ligne.

## Paramètres d'impression {#print-settings}

L'annuaire est mis en forme pour du **papier format lettre** (8,5 po × 11 po) avec des marges de 0,5 pouce. Lorsque la boîte de dialogue d'impression du navigateur apparaît :

- Laissez le format de papier réglé sur **Lettre**
- Activez les **Graphiques d'arrière-plan** (parfois appelés « Imprimer les arrière-plans ») dans les paramètres d'impression de votre navigateur si vous voulez que les en-têtes de section s'impriment avec leur couleur
- L'orientation portrait est recommandée

:::info
L'annuaire respecte les sauts de page : les fiches de foyer et les en-têtes de section ne sont jamais coupés entre deux pages.
:::
