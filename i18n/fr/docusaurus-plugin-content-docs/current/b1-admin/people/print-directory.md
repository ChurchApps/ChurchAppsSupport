# Imprimer le répertoire

<div class="article-intro">

La fonctionnalité Imprimer le répertoire génère un répertoire de membres formaté et imprimable pour votre église. Il organise les membres par ménage, inclut les informations de contact et les photos, et est conçu pour avoir une apparence professionnelle lorsqu'il est imprimé sur du papier standard lettre.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin d'un compte B1 Admin actif avec la permission de voir les personnes.
- Les personnes de votre répertoire devraient avoir des photos et des informations de contact remplies pour de meilleurs résultats.

</div>

## Ouverture du répertoire d'impression

1. Accédez à **Personnes** dans B1 Admin.
2. Cliquez sur l' **icône d'impression** (icône d'imprimante) dans la barre d'outils en haut de la carte des résultats Personnes. Il apparaît à côté du bouton Exporter.
3. Le répertoire d'impression s'ouvre dans un nouvel onglet du navigateur et commence à charger les données de votre répertoire.
4. Après environ 1.5 secondes, la boîte de dialogue d'impression de votre navigateur apparaît automatiquement.

:::tip
Le répertoire s'ouvre dans un onglet séparé afin que vous puissiez l'imprimer sans quitter la page Personnes. Après l'apparition de la boîte de dialogue d'impression, l'onglet revient automatiquement.
:::

## Qu'est-ce qui est inclus

Le répertoire d'impression inclut tous les **membres actifs** de votre église. Spécifiquement :

- Les personnes avec un statut d'adhésion **Inactif** ou **Visiteur** sont automatiquement exclues.
- Les personnes qui se sont **désabonnées** du répertoire sont exclues.
- Tous les autres sont regroupés par **ménage**.

### Impression uniquement de vos résultats de recherche

Après avoir exécuté une recherche sur la page Personnes -- une recherche rapide, une [Recherche avancée](./searching-people.md#advanced-search), une [Liste enregistrée](./lists.md) ou une [Recherche par IA](./ai-search.md) -- l'icône d'impression change en **Imprimer les résultats**. Cliquer dessus imprime un répertoire de juste les personnes de vos résultats au lieu de toute l'église, en utilisant la même mise en page.

Lors de l'impression des résultats de recherche, le filtre de statut d'adhésion ci-dessus ne s'applique pas : tous les personnes que vous avez recherchées sont incluses, même les visiteurs ou les personnes inactives. Les personnes qui se sont désabonnées du répertoire sont toujours exclues. Pour revenir à l'impression du répertoire complet, effacez d'abord votre recherche.

## Mise en page du répertoire

Le répertoire imprimé a deux parties :

### Page de couverture

La première page inclut :
- Le nom de votre église
- Le titre « Répertoire des membres »
- L'année actuelle
- L'emplacement de votre église
- Un décompte du nombre total de ménages inclus

### Listes des membres

Les pages restantes répertorient les ménages alphabétiquement par nom de famille. Chaque carte de ménage affiche :

- **Photos** -- Des miniatures circulaires pour chaque membre du ménage, avec leur nom ci-dessous
- **Nom d'affichage du ménage** -- Par exemple, « La Famille Smith », « Jean et Jeanne Dupont » ou simplement le nom de la personne pour les individus
- **Adresse** -- Adresse postale, ville, région et code postal
- **Téléphone** -- Numéro de domicile ou de téléphone mobile
- **E-mail** -- Adresse e-mail principale
- **Anniversaires** -- Formatés comme des dates individuelles pour chaque membre du ménage
- **Anniversaire de mariage** -- S'il est enregistré

Les ménages sont organisés en **sections alphabétiques** (A, B, C, ...) avec un en-tête de section décoratif avant chaque groupe de lettres. Deux cartes de ménage apparaissent côte à côte sur chaque ligne.

## Paramètres d'impression

Le répertoire est formaté pour du **papier lettre** (8,5" × 11") avec des marges de 0,5 pouce. Lorsque la boîte de dialogue d'impression du navigateur apparaît :

- Laissez le format de papier défini sur **Lettre**
- Activez les **Graphiques d'arrière-plan** (parfois appelé « Imprimer les arrière-plans ») dans les paramètres d'impression de votre navigateur si vous souhaitez que les en-têtes de section s'impriment avec leur style de couleur
- L'orientation portrait est recommandée

:::info
Le répertoire respecte les sauts de page — les cartes de ménage et les en-têtes de section ne seront pas divisés sur plusieurs pages.
:::
