# Imprimer le Répertoire

<div class="article-intro">

La fonctionnalité Imprimer le Répertoire génère un répertoire des membres formaté et imprimable pour votre église. Il organise les membres par ménage, inclut les informations de contact et les photos, et est conçu pour avoir une apparence professionnelle lorsqu'imprimé sur du papier de format lettre standard.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin d'un compte B1 Admin actif avec la permission de voir les personnes.
- Les personnes dans votre répertoire doivent avoir des photos et des informations de contact remplies pour les meilleurs résultats.

</div>

## Ouverture du Répertoire d'Impression

1. Naviguez vers **Personnes** dans B1 Admin.
2. Cliquez sur l'**icône d'impression** (icône d'imprimante) dans la barre d'outils en haut de la carte des résultats Personnes. Il apparaît à côté du bouton Exporter.
3. Le Répertoire d'Impression s'ouvre dans un nouvel onglet du navigateur et commence à charger les données de votre répertoire.
4. Après environ 1,5 secondes, la boîte de dialogue d'impression de votre navigateur apparaîtra automatiquement.

:::tip
Le répertoire s'ouvre dans un onglet séparé pour que vous puissiez l'imprimer sans quitter la page Personnes. Après que la boîte de dialogue d'impression apparaît, l'onglet retourne automatiquement.
:::

## Ce Qui Est Inclus

Le répertoire imprimé inclut tous les **membres actifs** de votre église. Spécifiquement :

- Les personnes avec un statut d'adhésion **Inactif** ou **Visiteur** sont automatiquement exclues.
- Les personnes qui se sont **désinscrites** du répertoire sont exclues.
- Tous les autres sont regroupés par **ménage**.

## Mise en Page du Répertoire

Le répertoire imprimé a deux parties :

### Page de Couverture

La première page inclut :
- Le nom de votre église
- Le titre "Répertoire des Membres"
- L'année actuelle
- L'emplacement de votre église
- Un comptage du nombre total de ménages inclus

### Inscriptions de Membres

Les pages restantes énumèrent les ménages alphabétiquement par nom de famille. Chaque carte de ménage affiche :

- **Photos** -- Miniatures circulaires pour chaque membre du ménage, avec leur nom ci-dessous
- **Nom d'affichage du ménage** -- Par exemple, "La Famille Smith", "John & Jane Doe", ou simplement le nom de la personne pour les individus
- **Adresse** -- Adresse postale, ville, état et code postal
- **Téléphone** -- Numéro de maison ou mobile
