# Édition en masse des personnes

L'édition en masse vous permet de mettre à jour plusieurs personnes à la fois. Vous pouvez modifier le statut d'adhésion, le statut matrimonial, le sexe, les préférences de désabonnement et l'adhésion aux groupes.

## Sélection des personnes

1. Naviguez vers **Personnes** dans B1 Admin
2. Utilisez la recherche ou les filtres pour trouver les personnes
3. Cochez les cases pour les sélectionner
4. Cliquez sur **Actions en masse** quand disponible

## Actions disponibles

- **Définir le statut d'adhésion** - Visiteur, Participant régulier, Membre, Personnel, Inactif
- **Définir le statut matrimonial** - Inconnu, Célibataire, Marié, Divorcé, Veuf
- **Définir le sexe** - Non spécifié, Homme, Femme
- **Définir le désabonnement** - Oui/Non
- **Ajouter à un groupe** - Sélectionnez un ou plusieurs groupes
- **Supprimer du groupe** - Supprimez des groupes sélectionnés
- **Supprimer les personnes** - Suppression permanente (confirmez avec DELETE)

Pour chaque action, choisissez si vous voulez **Remplacer tous** ou **Mettre à jour uniquement vide**.

:::warning
La suppression de personnes est permanente et supprime toutes leurs données (informations personnelles, appartenances aux groupes, dossiers de présence, historique de donation, soumissions de formulaires).
:::

## Meilleures pratiques

- Testez d'abord sur quelques enregistrements
- Utilisez des filtres pour affiner votre sélection
- Documentez les changements importants
- Coordonnez avec votre équipe
