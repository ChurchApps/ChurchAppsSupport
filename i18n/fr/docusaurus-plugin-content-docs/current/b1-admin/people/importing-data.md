# Import de données

<div class="article-intro">

L'outil B1 Transfer facilite l'importation de vos données existantes dans B1, que vous commenciez à partir d'une feuille de calcul, migriez depuis une autre plateforme de gestion d'église ou importiez des dossiers de dons. Il peut également être utilisé pour exporter ou sauvegarder vos données à tout moment.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin d'un compte B1 Admin actif avec accès à **Paramètres**.
- Ayez vos données exportées et prêtes de votre système précédent avant de commencer.
- Cet outil est destiné à la migration de données initiale. Si vous utilisez B1 depuis un moment, importer à nouveau peut créer des dossiers en double.

</div>

## Accès à l'outil de transfer

1. Connectez-vous à **B1 Admin**.
2. Ouvrez le **menu de section** dans le coin supérieur gauche et choisissez **Paramètres**.
3. Cliquez sur le bouton **Import/Export** en haut à droite de l'en-tête de page.
4. Cela ouvrira l'outil **B1 Transfer** dans un nouvel onglet.

L'outil de transfer vous guide à travers quatre étapes : Source, Aperçu, Destination et Exécution.

## Étape 1 - Choisissez votre source

Sélectionnez d'où proviennent vos données. Il y a sept options :

- **Base de données B1** -- Récupère les données directement de votre église B1 existante.
- **Zip d'importation B1** -- Un fichier zip au format de B1.
- **Zip d'importation Breeze** -- Un fichier zip contenant des fichiers exportés de Breeze ChMS.
- **Zip Planning Center** -- Un fichier zip ou CSV exporté de Planning Center.
- **CSV/Excel personnalisé** -- Tout fichier CSV ou Excel contenant des données de personnes.
- **CSV Tithe.ly** -- Un fichier d'export de personnes ou de dons de Tithe.ly.
- **CSV CCB/Pushpay** -- Un CSV d'export de personnes ou de dons de Church Community Builder ou Pushpay.

## Étape 2 - Aperçu de vos données

Après le téléchargement, l'outil affiche un aperçu de tout ce qui sera importé. Utilisez les onglets pour examiner chaque type de données :

- **Personnes** -- Listées par ménage.
- **Groupes** -- Organisés par campus, service et catégorie.
- **Présence** -- Dates de session et comptages de visites.
- **Donations** -- Lots, fonds et montants.
- **Formulaires** -- Noms et types de contenu des formulaires.

## Étape 3 - Choisissez votre destination

Sélectionnez où vous voulez que les données aillent :

- **Base de données B1** -- Importe directement dans la base de données B1 de votre église.
- **Zip d'export B1** -- Télécharge vos données sous forme de fichier zip au format B1.
- **Zip d'export Breeze** -- Convertit vos données au format Breeze.
- **Zip Planning Center** -- Convertit vos données au format Planning Center.

## Étape 4 - Exécution

L'outil traite le transfer et affiche la progression pour chaque étape. Ne fermez pas votre navigateur pendant que le transfer est en cours.

## Après l'importation

Une fois le transfer terminé, prenez quelques minutes pour vérifier vos données :

1. Parcourez la page Personnes et vérifiez quelques profils.
2. Vérifiez que les noms, e-mails, numéros de téléphone et adresses ont été correctement importés.
3. Vérifiez que les connexions des ménages sont intactes.
4. Examinez les groupes et dossiers de dons importés.
