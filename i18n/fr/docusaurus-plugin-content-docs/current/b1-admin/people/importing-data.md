# Importation de données

L'outil B1 Transfer facilite l'importation de vos données existantes dans B1, que vous commenciez à zéro à partir d'une feuille de calcul, migriez depuis une autre plateforme de gestion d'église ou importiez des dossiers de donation. Il peut également être utilisé pour exporter ou sauvegarder vos données à tout moment.

## Accès à l'outil de transfert

1. Connectez-vous à **B1 Admin**.
2. Ouvrez le **menu de section** dans le coin supérieur gauche et choisissez **Paramètres**.
3. Cliquez sur le bouton **Importer/Exporter** en haut à droite de l'en-tête de la page.
4. Cela ouvrira l'outil **B1 Transfer** dans un nouvel onglet à [transfer.b1.church](https://transfer.b1.church).

L'outil de transfert vous guide à travers quatre étapes : Source, Aperçu, Destination et Exécution.

## Étape 1 - Choisissez votre source

Sélectionnez d'où proviennent vos données. Il y a sept options :

- **Base de données B1** -- Récupère les données directement de votre église B1 existante. Utile pour faire une sauvegarde ou convertir vos données dans un autre format.
- **Import Zip B1** -- Un fichier zip au format propre de B1.
- **Import Zip Breeze** -- Un fichier zip contenant les fichiers exportés de Breeze ChMS.
- **Planning Center Zip** -- Un fichier zip ou CSV exporté depuis Planning Center.
- **CSV/Excel personnalisé** -- N'importe quel fichier CSV ou Excel contenant les données de personnes.
- **Tithe.ly CSV** -- Un fichier d'export de personnes ou de donations de Tithe.ly.
- **CCB / Pushpay CSV** -- Un CSV d'export de personnes ou de donations de Church Community Builder ou Pushpay.

## Étape 2 - Aperçu de vos données

Après le chargement, l'outil affiche un aperçu de tout ce qui sera importé. Utilisez les onglets pour consulter chaque type de données :

- **Personnes** -- Listées par ménage, avec photos si incluses.
- **Groupes** -- Organisés par campus, service, heure et catégorie.
- **Présence** -- Dates de session, groupes et décomptes de visites.
- **Donations** -- Lots, fonds, donateurs et montants.
- **Formulaires** -- Noms des formulaires et types de contenu.

Vérifiez cela attentivement avant de continuer.

## Étape 3 - Choisissez votre destination

Sélectionnez où vous voulez que les données aillent :

- **Base de données B1** -- Importe directement dans la base de données B1 de votre église.
- **Export Zip B1** -- Télécharge vos données en tant que fichier zip au format B1.
- **Export Zip Breeze** -- Convertit vos données au format Breeze.
- **Planning Center Zip** -- Convertit vos données au format Planning Center.

## Étape 4 - Exécuter

L'outil traite le transfert et affiche la progression pour chaque étape. Ne fermez pas votre navigateur pendant que le transfert est en cours.

:::warning
N'fermez pas votre navigateur pendant le transfert. Attendez que toutes les étapes affichent comme terminées.
:::
