# Démarrer votre église avec B1

<div class="article-intro">

Un guide d'intégration complet pour les nouvelles églises -- de la création de votre compte à l'importation de votre répertoire de membres et à la configuration de vos premières fonctionnalités. Suivez ces étapes dans l'ordre pour mettre votre église en service sur B1.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Une adresse courriel valide
- Le logo et les éléments d'image de marque de votre église (couleurs, images) -- recommandés, mais pas obligatoires pour commencer

</div>

## Étape 1 : Créer votre compte {#step-1-create-your-account}

Inscrivez votre église et devenez le premier administrateur.

Suivez le guide [Créer un compte](../../getting-started/create-account.md) pour :

1. Aller sur b1.church et vous inscrire avec votre courriel
2. Vérifier votre adresse courriel
3. Choisir « Créer une nouvelle église » et saisir le nom de votre église
4. Vous devenez automatiquement l'administrateur de domaine, avec un accès complet à tout

## Étape 2 : Configurer les paramètres de l'église {#step-2-configure-church-settings}

Saisissez les renseignements de base et l'image de marque de votre église.

Suivez le guide [Paramètres de l'église](../settings/church-settings.md) pour :

1. Dans le [menu Jump](../introduction.md#getting-around-with-the-jump-menu), choisissez **Paramètres > Paramètres** et cliquez sur **Modifier** dans la section **Renseignements sur l'église**
2. Saisissez le nom et l'adresse de votre église, puis définissez votre **Sous-domaine** (il deviendra votre-eglise.b1.church)
3. Téléversez le logo de votre église et choisissez vos couleurs sous **Site web > Apparence** (voir [Logo et image de marque](../website/appearance.md#logo-and-branding)), puis définissez les couleurs de l'application B1 sous **Mobile > Thème de l'application**

:::tip
Votre sous-domaine apparaît dans l'adresse de votre site web et de votre page de dons ; choisissez donc un nom court et reconnaissable (par exemple « grace » pour l'Église communautaire Grace).
:::

## Étape 3 : Configurer les rôles et inviter votre équipe {#step-3-set-up-roles--invite-your-team}

Contrôlez qui a accès à quoi et intégrez votre équipe.

Suivez le guide [Rôles et autorisations](../settings/roles-permissions.md) pour :

1. Dans le menu Jump, choisissez **Paramètres > Rôles** et créez des rôles pour votre équipe (par exemple « Pasteur », « Administration », « Équipe financière », « Responsable de la louange »)
2. Attribuez des autorisations précises à chaque rôle afin que les personnes ne voient que ce dont elles ont besoin
3. Invitez les membres de l'équipe en cliquant sur **Ajouter** dans le panneau **Membres** d'un rôle -- B1 propose de leur envoyer une invitation par courriel (utilisez **Créer un nouvel utilisateur** pour une personne qui ne fait pas encore partie de votre église)

:::info
Vous n'avez pas à tout faire seul. Invitez tôt votre personnel de bureau, vos pasteurs et vos responsables de ministère afin qu'ils puissent aider à configurer leurs secteurs.
:::

## Étape 4 : Importer vos personnes {#step-4-import-your-people}

Intégrez à B1 votre répertoire de membres existant.

Suivez le guide [Importation de données](../people/importing-data.md). Dans **Paramètres**, cliquez sur **Importer/Exporter** pour ouvrir l'outil de transfert B1, puis choisissez votre source :

1. **CSV / Excel personnalisé** -- exportez depuis votre système actuel ou votre tableur, téléversez le fichier et associez vos colonnes aux champs B1
2. **Migration depuis un autre système** -- téléversez un export de **Breeze**, **Planning Center**, **Tithe.ly** ou **CCB / Pushpay**

:::tip
Vous migrez depuis Breeze ? Exportez vos fichiers **Personnes**, **Étiquettes** et **Contributions**, compressez-les ensemble dans un fichier zip et téléversez ce zip comme **Fichier zip d'importation Breeze** -- vos personnes, vos groupes et vos dons seront transférés en une seule étape.
:::

## Étape 5 : Configurer l'application mobile {#step-5-configure-the-mobile-app}

Personnalisez l'expérience de l'application B1 pour votre communauté.

Suivez le guide [Paramètres de l'application mobile](../settings/mobile-app.md) pour :

1. Dans le menu Jump, choisissez **Mobile > Navigation** et cliquez sur **Ajouter un onglet** pour choisir les onglets qui apparaissent dans l'application B1 de vos membres
2. Définissez le nom, l'icône et le **Type d'onglet** de chaque onglet (Bible, Diffusion en direct, Prédications, Don, URL externe, Page interne, etc.)
3. Utilisez la **Visibilité** de chaque onglet pour contrôler qui le voit

## Étape 6 : Commencer à configurer les fonctionnalités {#step-6-start-setting-up-features}

Maintenant que les bases sont en place, suivez ces guides pour configurer des fonctionnalités précises :

- [Configurer les dons en ligne](./online-giving.md) -- acceptez les dons par votre site web et votre application
- [Lancer le site web de votre église](./launch-website.md) -- créez le site web de votre église
- [Gérer des petits groupes](./small-groups.md) -- organisez les groupes, les études bibliques et les ministères
- [Configurer l'enregistrement des enfants](./childrens-checkin.md) -- enregistrement par borne pour le ministère des enfants
- [Gérer les bénévoles du dimanche](./sunday-volunteers.md) -- coordonnez vos équipes de service
- [Créer votre bibliothèque de prédications](./sermon-library.md) -- mettez les prédications en ligne et configurez la diffusion en direct
- [Suivre les présences](./track-attendance.md) -- suivez qui fréquente les services et les groupes

## Terminé ! {#youre-done}

Votre église est configurée sur B1. Votre équipe a accès, vos personnes sont importées, et vous êtes prêt à utiliser les fonctionnalités qui comptent le plus pour votre ministère. Consultez les guides de fonctionnalités ci-dessus pour configurer chaque domaine.
