# Gérer les petits groupes

<div class="article-intro">

Créez des petits groupes, des études bibliques ou des équipes de ministère avec la gestion des membres, les calendriers de groupe et les conversations. Publiez un calendrier des événements de l'église sur votre site web afin que les visiteurs sachent ce qui se passe et que les membres restent connectés via le portail web et l'application mobile.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Un compte B1 Admin avec un accès administrateur
- [Personnes ajoutées à votre annuaire](../people/adding-people.md) (les membres des groupes doivent d'abord exister dans l'annuaire)

</div>

## Étape 1 : Créer les catégories et les groupes {#step-1-create-group-categories--groups}

Organisez vos groupes en catégories afin que les membres trouvent facilement ce qui les intéresse.

Suivez le guide [Créer des groupes](../groups/creating-groups.md) pour :

1. Dans le [menu Accès rapide](../introduction.md#getting-around-with-the-jump-menu), choisir **Personnes > Groupes**, puis cliquer sur **Ajouter un groupe**
2. Saisir un **Nom de catégorie** pour organiser vos groupes (par exemple « Petits groupes », « Études bibliques », « Équipes de ministère », « Comités ») ainsi que le **Nom** du groupe (par exemple « Groupe d'hommes du mardi soir », « Étude biblique des femmes »), puis cliquer sur **Ajouter**
3. Ouvrez le groupe, cliquez sur **Modifier**, puis renseignez l'**Heure de réunion**, le **Lieu de réunion** et la **Description**. Définissez l'**Inscription** pour choisir si les personnes peuvent rejoindre le groupe immédiatement, doivent en faire la demande, ou sont ajoutées uniquement par les responsables

## Étape 2 : Ajouter les membres et les responsables {#step-2-add-members--leaders}

Renseignez vos groupes avec des membres et désignez des responsables qui pourront gérer leurs propres équipes.

Suivez le guide [Membres du groupe](../groups/group-members.md) pour :

1. Sur la page du groupe, cliquer sur **Tous les membres**, puis rechercher des personnes dans la zone **Ajouter une personne** pour les ajouter
2. Désigner les responsables de groupe à l'aide de l'icône en forme d'étoile (**Nommer responsable**) — les responsables bénéficient de droits supplémentaires

:::tip
Les responsables de groupe peuvent gérer le calendrier de leur groupe, publier des conversations et coordonner les événements sans avoir besoin d'un accès administrateur complet.
:::

## Étape 3 : Configurer les calendriers de groupe {#step-3-set-up-group-calendars}

Donnez à chaque groupe son propre calendrier pour les réunions et les événements.

Suivez le guide [Calendrier du groupe](../groups/group-calendar.md) pour :

1. Ajouter des réunions récurrentes (par exemple « Tous les mardis à 19 h ») et des événements ponctuels (par exemple « Barbecue du groupe — 15 mars »)
2. Les responsables de groupe ajoutent et gèrent les événements de leur propre groupe sur B1.church
3. Dans B1 Admin, vous pouvez planifier toute une saison de réunions d'un coup : ouvrez le groupe, cliquez sur **Tous les événements** dans la section **Calendrier**, puis cliquez sur **+ Ajouter des événements**

## Étape 4 : Créer un calendrier pour toute l'église {#step-4-create-a-church-wide-calendar}

Regroupez les événements de tous vos groupes dans un seul calendrier pour toute l'église.

Suivez les guides [Créer des calendriers](../calendars/creating-calendars.md) et [Calendrier sélectionné](../calendars/curated-calendar.md) pour :

1. Dans le menu Accès rapide, choisir **Calendriers > Calendriers**, cliquer sur **Ajouter un calendrier**, saisir un **Nom du calendrier**, puis cliquer sur **Créer**
2. Ouvrir le calendrier, cliquer sur **Ajouter un groupe**, choisir un groupe, puis sélectionner **Ajouter tous les événements du groupe** (ou seulement certains événements). Répétez l'opération pour chaque groupe
3. Cliquer sur **S'abonner** pour partager le lien d'abonnement ICS afin que les membres puissent ajouter les événements à leurs applications de calendrier personnelles (Google Agenda, Calendrier Apple, Outlook)

:::info
Lorsque vous ajoutez tous les événements d'un groupe, le calendrier sélectionné reprend automatiquement les nouveaux événements : lorsqu'un responsable de groupe ajoute un événement, celui-ci apparaît aussi dans le calendrier de l'église.
:::

## Étape 5 : Publier sur votre site web {#step-5-publish-to-your-website}

Rendez vos groupes et votre calendrier visibles pour les visiteurs et les membres sur votre site B1.

Suivez le guide [Éditeur de pages](../website/page-editor.md) pour :

1. Ajouter un élément **Calendrier** à une page de votre site B1 pour afficher le calendrier sélectionné
2. Ajouter un élément **Explorateur de groupes** (ou **Liste des groupes**) afin que les visiteurs puissent parcourir les groupes disponibles et découvrir comment les rejoindre

## Étape 6 : Expérience des membres {#step-6-member-experience}

Les membres peuvent découvrir, rejoindre et participer aux groupes depuis leur téléphone ou leur ordinateur.

1. Les membres parcourent et rejoignent les groupes sur [B1.church](../../b1-church/groups/browsing-groups.md)
2. Les membres des groupes peuvent consulter les détails, les calendriers et publier dans les [conversations](../../b1-church/groups/conversations.md)
3. Toutes les fonctionnalités des groupes sont également disponibles dans l'[application B1](../../b1-church/groups/index.md)

:::info
Les membres retrouvent leurs groupes, leurs prochains événements et les conversations de groupe sur le web comme sur mobile : tout reste synchronisé.
:::

## C'est terminé ! {#youre-done}

Vos petits groupes sont configurés et reliés entre eux. Les membres peuvent découvrir les groupes, consulter les événements et rester connectés grâce aux conversations, le tout sur votre site web et dans votre application mobile. Les responsables de groupe peuvent gérer leurs équipes de manière indépendante.
