# Gérer les petits groupes

<div class="article-intro">

Configurez des petits groupes, des études bibliques ou des équipes de ministère avec la gestion des membres, les calendriers de groupe et les conversations. Publiez un calendrier événementiel global sur votre site web afin que les visiteurs puissent voir ce qui se passe et que les membres restent connectés via le portail web et l'application mobile.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Un compte B1 Admin avec un accès administrateur
- [Personnes ajoutées à votre annuaire](../people/adding-people.md) (les membres du groupe doivent d'abord exister)

</div>

## Étape 1 : Créer les catégories et les groupes

Organisez vos groupes en catégories pour que les membres puissent facilement trouver ce qui les intéresse.

Suivez le guide [Créer des groupes](../groups/creating-groups.md) pour :

1. Créer des catégories afin d'organiser vos groupes (par ex. « Petits groupes », « Études bibliques », « Équipes de ministère », « Comités »)
2. Créer des groupes dans chaque catégorie (par ex. « Groupe des hommes du mardi soir », « Étude biblique des femmes », « Ministère de la jeunesse »)
3. Ajouter une description et un horaire de rencontre pour chaque groupe

## Étape 2 : Ajouter les membres et les responsables

Remplissez vos groupes de membres et désignez des responsables qui pourront gérer leurs propres équipes.

Suivez le guide [Membres du groupe](../groups/group-members.md) pour :

1. Rechercher des personnes et les ajouter aux groupes appropriés
2. Désigner les responsables de groupe à l'aide de l'icône en forme d'étoile (**Nommer responsable**) — les responsables disposent de permissions supplémentaires

:::tip
Les responsables de groupe peuvent gérer le calendrier de leur groupe, publier des conversations et coordonner des événements sans avoir besoin d'un accès administrateur complet.
:::

## Étape 3 : Configurer les calendriers de groupe

Donnez à chaque groupe son propre calendrier pour ses rencontres et ses événements.

Suivez le guide [Calendrier de groupe](../groups/group-calendar.md) pour :

1. Ajouter des rencontres récurrentes (par ex. « Tous les mardis à 19 h ») et des événements ponctuels (par ex. « Barbecue du groupe - 15 mars »)
2. Les responsables de groupe peuvent ajouter et gérer les événements de leur propre groupe

## Étape 4 : Créer un calendrier global de l'église

Regroupez les événements de tous vos groupes dans un seul calendrier unifié pour l'ensemble de l'église.

Suivez les guides [Créer des calendriers](../calendars/creating-calendars.md) et [Calendrier personnalisé](../calendars/curated-calendar.md) pour :

1. Créer un calendrier personnalisé qui regroupe les événements de plusieurs groupes dans une vue unifiée
2. Partager le lien d'abonnement ICS afin que les membres puissent ajouter les événements à leurs applications de calendrier personnelles (Google Agenda, Calendrier Apple, Outlook)

:::info
Un calendrier personnalisé regroupe automatiquement les événements des groupes que vous y connectez. Lorsqu'un responsable de groupe ajoute un événement, celui-ci apparaît aussi dans le calendrier de l'église.
:::

## Étape 5 : Publier sur votre site web

Rendez vos groupes et votre calendrier visibles pour les visiteurs et les membres sur votre site B1.

Suivez le guide [Gérer les pages](../website/managing-pages.md) pour :

1. Ajouter une section Calendrier à votre site B1 pour afficher le calendrier personnalisé
2. Ajouter une section Groupes afin que les visiteurs puissent parcourir les groupes disponibles et découvrir comment s'y inscrire

## Étape 6 : L'expérience des membres

Les membres peuvent découvrir, rejoindre et participer à des groupes depuis leur téléphone ou leur ordinateur.

1. Les membres parcourent et rejoignent les groupes sur [B1.church](../../b1-church/groups/browsing-groups.md)
2. Les membres des groupes peuvent consulter les détails, les calendriers et publier dans les [conversations](../../b1-church/groups/conversations.md)
3. Toutes les fonctionnalités de groupe sont également disponibles dans l'[application B1](../../b1-church/groups/index.md)

:::info
Les membres voient leurs groupes, les événements à venir et les conversations de groupe sur le web comme sur mobile — tout reste synchronisé.
:::

## Vous avez terminé !

Vos petits groupes sont configurés et reliés entre eux. Les membres peuvent découvrir les groupes, consulter les événements et rester connectés grâce aux conversations — le tout sur votre site web et votre application mobile. Les responsables de groupe peuvent gérer leurs équipes de manière indépendante.
