# Importation en masse

<div class="article-intro">

La page Importation en masse vous permet de remplir rapidement votre bibliothèque de sermons en important des vidéos de YouTube ou Vimeo. C'est la façon la plus rapide d'apporter votre contenu de sermon existant plutôt que d'ajouter chaque vidéo une par une.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin de la permission **contentApi.streamingServices.edit**. Voir [Rôles et permissions](../settings/roles-permissions.md) si vous n'avez pas l'accès.
- Créez au moins une [playlist](playlists) pour importer vos sermons dans
- Ayez votre ID de chaîne YouTube ou vos informations de compte Vimeo à portée de main

</div>

## Choix de votre source

1. Dans B1 Admin, ouvrez le **menu de section** dans le coin supérieur gauche (le nom de la section avec la petite flèche) et choisissez **Sermons**, puis cliquez sur l'onglet **Importation en masse**.
2. Vous verrez deux cartes cliquables :
   - **YouTube** (rouge) -- Importez les vidéos d'une chaîne YouTube
   - **Vimeo** (bleu) -- Importez les vidéos d'un compte Vimeo
3. Cliquez sur la carte pour la plateforme où vos sermons sont hébergés.

:::tip
Vous pouvez revenir et changer de sources à tout moment si vous avez des vidéos sur les deux plates-formes.
:::

## Avant l'importation

Avant d'importer des vidéos, vous avez besoin d'au moins une playlist pour les organiser. Si vous n'avez pas encore créé de playlists :

1. Cliquez sur l'onglet **Playlists**.
2. Cliquez sur **Créer la première playlist** et remplissez le nom, la description, la date de publication et la miniature.
3. Cliquez sur **Enregistrer**, puis retournez à l'onglet **Importation en masse**.

Voir [Playlists](playlists) pour les instructions détaillées sur la création et la gestion des playlists.

## Importation de vidéos

1. Après avoir sélectionné YouTube ou Vimeo, entrez votre **ID de chaîne YouTube** ou les **informations de votre compte Vimeo** dans le champ fourni.
2. Cliquez sur le bouton **Récupérer** pour récupérer toutes les vidéos disponibles de votre chaîne ou compte.
3. Après la récupération, vous verrez une liste de toutes vos vidéos avec des cases à cocher.
4. Cochez les cases à côté des vidéos que vous voulez importer. Vous pouvez tout sélectionner ou en choisir des spécifiques.
5. Éventuellement, activez **Importation automatique des nouvelles vidéos** pour ajouter automatiquement les futurs téléchargements à votre bibliothèque.
6. Cliquez sur le menu déroulant **Importer dans la playlist** pour choisir dans quelle playlist ces vidéos doivent être ajoutées.
7. Cliquez sur le bouton **Importer** pour compléter l'importation en masse.

Vos vidéos seront importées avec tous leurs détails, incluant les titres, les descriptions, les dates et les miniatures.

:::info
L'importation en masse est idéale pour commencer quand vous migrez d'une autre plateforme. Pour ajouter des sermons individuels à l'avenir, utilisez plutôt la page [Gestion des sermons](managing-sermons).
:::
