# Playlists

<div class="article-intro">

Les playlists vous permettent d'organiser vos sermons en séries ou en collections. Quand les visiteurs parcourent votre bibliothèque de sermons sur votre site web B1.church, les playlists les aident à trouver et à suivre une série de sermons complète dans le bon ordre.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin de la permission **contentApi.streamingServices.edit**. Voir [Rôles et permissions](../settings/roles-permissions.md) si vous n'avez pas l'accès.
- Ayez un nom, une description et une image de miniature à portée de main pour votre playlist

</div>

## Affichage des playlists

1. Dans B1 Admin, ouvrez le **menu de section** dans le coin supérieur gauche (le nom de la section avec la petite flèche) et choisissez **Sermons**.
2. Cliquez sur l'onglet **Playlists** en haut de la page.
3. Vous verrez une liste de toutes vos playlists existantes avec leurs noms et descriptions.

## Création d'une playlist

1. Cliquez sur le bouton **Créer la première playlist** (si vous n'avez pas de playlists) ou cliquez sur **Ajouter une playlist**.
2. Entrez un **nom** pour la playlist -- par exemple, le titre de la série de sermons comme "Fondations de la foi" ou "Été dans les Psaumes".
3. Ajoutez une **description** pour donner aux visiteurs un bref aperçu de la série.
4. Définissez une **date de publication** pour contrôler quand la playlist devient visible.
5. Téléchargez une **image de miniature** pour représenter la série visuellement.
6. Cliquez sur **Enregistrer** pour créer votre playlist.

:::tip
Créez vos playlists d'abord avant d'ajouter des sermons. De cette façon, vous pouvez assigner chaque sermon à la bonne playlist au fur et à mesure, plutôt que de réorganiser plus tard.
:::

## Ajout de sermons à une playlist

Quand vous [ajoutez ou modifiez un sermon](managing-sermons), vous le assignez à une playlist en utilisant le menu déroulant **Playlist**. Tous les sermons assignés à la même playlist sont regroupés ensemble et affichés dans l'ordre sur votre site web.

:::info
Vous pouvez aussi assigner les sermons aux playlists pendant l'[Importation en masse](bulk-import). Quand vous importez de YouTube ou Vimeo, sélectionnez une playlist du menu déroulant **Importer dans la playlist** avant de cliquer sur **Importer**.
:::

## Comment les playlists apparaissent sur votre site web

Les playlists sont affichées sur votre site web B1.church comme des collections navigables. Les visiteurs peuvent :

- Voir toutes les séries de sermons disponibles d'un coup d'œil
- Cliquer dans une playlist pour afficher tous les sermons de cette série
- Regarder ou écouter les sermons dans l'ordre
