# Playlists

<div class="article-intro">

Les playlists vous permettent d'organiser vos sermons en séries ou en collections. Lorsque les visiteurs parcourent votre bibliothèque de sermons sur votre site Web B1.church, les playlists les aident à trouver et à suivre une série de sermons complète dans le bon ordre.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin de la permission **contentApi.streamingServices.edit**. Consultez [Rôles & Autorisations](../settings/roles-permissions.md) si vous n'avez pas accès.
- Ayez un nom, une description et une image miniature prêts pour votre playlist

</div>

## Affichage des playlists

1. Dans B1 Admin, ouvrez le [menu Sauter](../introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche), développez **Sermons**, et cliquez sur **Sermons**.
2. Trouvez le panneau **Playlists** sur la page **Sermons** (à côté de la liste des sermons).
3. Vous verrez une liste de toutes vos playlists existantes avec leurs noms et descriptions.

## Création d'une playlist

1. Cliquez sur le bouton **Créer la première playlist** (si vous n'avez pas encore de playlists) ou cliquez sur le bouton **Ajouter** (+) dans l'en-tête du panneau **Playlists**.
2. Entrez un **nom** pour la playlist -- par exemple, le titre de la série de sermons comme « Fondements de la foi » ou « L'été dans les Psaumes ».
3. Ajoutez une **description** pour donner aux visiteurs un bref aperçu de la série.
4. Définissez une **date de publication** pour contrôler quand la playlist devient visible.
5. Téléchargez une **image miniature** pour représenter la série visuellement.
6. Cliquez sur **Enregistrer** pour créer votre playlist.

:::tip
Créez d'abord vos playlists avant d'ajouter des sermons. De cette façon, vous pouvez attribuer chaque sermon à la bonne playlist au fur et à mesure, plutôt que de réorganiser plus tard.
:::

## Ajout de sermons à une playlist

Lorsque vous [ajoutez ou modifiez un sermon](managing-sermons), vous l'attribuez à une playlist à l'aide du menu déroulant **Playlist**. Tous les sermons attribués à la même playlist sont regroupés ensemble et affichés dans l'ordre sur votre site Web.

:::info
Vous pouvez également attribuer des sermons à des playlists lors de l'[Importation en masse](bulk-import). Lors de l'importation à partir de YouTube ou Vimeo, sélectionnez une playlist dans le menu déroulant **Importer dans la playlist** avant de cliquer sur **Importer**.
:::

## Comment les playlists apparaissent sur votre site Web

Les playlists s'affichent sur votre site Web B1.church comme des collections consultables. Les visiteurs peuvent :

- Voir toutes les séries de sermons disponibles en un coup d'œil
- Cliquer dans une playlist pour afficher tous les sermons de cette série
- Regarder ou écouter les sermons dans l'ordre
