# Santé des Groupes

<div class="article-intro">

Le tableau de bord Santé des Groupes vous donne une vue d'ensemble de la façon dont tous vos groupes se portent — tendances d'adhésion, moyennes de participation, et croissance ou attrition au cours des 90 derniers jours — tout dans un seul tableau triable.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin d'au moins quelques groupes avec des membres pour voir des données significatives. Voir [Création de Groupes](creating-groups).
- Les données de participation sont extraites des sessions enregistrées. Voir la section [Participation](../attendance/).

</div>

## Ouverture de Santé des Groupes

Dans B1 Admin, ouvrez le **menu de section** dans le coin supérieur gauche et choisissez **Personnes**, puis cliquez sur l'onglet **Groupes** dans la barre de navigation et sélectionnez **Santé**. Le tableau de bord charge un tableau avec une ligne par groupe.

## Colonnes

| Colonne | Ce qu'elle affiche |
|--------|--------------|
| **Nom** | Le nom du groupe, lié à la page de détail du groupe |
| **Catégorie** | La catégorie du groupe |
| **Membres** | Comptage actuel des membres actifs |
| **Adhésions (90j)** | Membres qui ont adhéré au cours des 90 derniers jours |
| **Départs (90j)** | Membres qui ont quitté au cours des 90 derniers jours |
| **Attrition (90j)** | Taux d'attrition net en pourcentage sur 90 jours |
| **Participation Moyenne** | Comptage moyen de têtes par session de participation |

Cliquez sur n'importe quel en-tête de colonne pour trier le tableau par cette colonne. Cliquez à nouveau pour inverser le sens du tri.

## Utilisation des Données de Santé

- **Attrition élevée + adhésions faibles** — un groupe qui rétrécit et ne remplace pas les membres perdus. Vaut une conversation avec le leader du groupe.
- **Adhésions élevées + participation faible** — les gens s'inscrivent mais n'assistent pas. Envisagez une relance d'engagement.
- **Participation moyenne élevée** — un groupe actif et sain. Modèle potentiel pour d'autres groupes.

:::tip
Cliquer sur un nom de groupe vous mène directement à la page de détail du groupe où vous pouvez examiner les membres individuels, les dossiers de participation, et les événements du calendrier.
:::
