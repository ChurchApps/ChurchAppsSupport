# Santé des groupes

<div class="article-intro">

Le tableau de bord Santé des groupes vous donne une vue d'ensemble de la façon dont tous vos groupes se portent — les tendances d'adhésion, les moyennes de présence et la croissance ou l'attrition au cours des 90 derniers jours -- tout dans un tableau unique triable.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin d'au moins quelques groupes avec des membres pour voir des données significatives. Voir [Création de groupes](creating-groups).
- Les données de présence sont extraites des sessions enregistrées. Voir la section [Présence](../attendance/).

</div>

## Ouverture de Santé des groupes

Dans B1 Admin, ouvrez le **menu de section** dans le coin supérieur gauche et choisissez **Personnes**, puis cliquez sur l'onglet **Groupes** dans la barre de navigation et sélectionnez **Santé**. Le tableau de bord charge un tableau avec une ligne par groupe.

## Colonnes

| Colonne | Ce qu'il montre |
|--------|--------------|
| **Nom** | Le nom du groupe, lié à la page de détail du groupe |
| **Catégorie** | La catégorie du groupe |
| **Membres** | Nombre actuel de membres actifs |
| **Adhérents (90j)** | Membres qui ont adhéré au cours des 90 derniers jours |
| **Partis (90j)** | Membres qui ont quitté au cours des 90 derniers jours |
| **Churn (90j)** | Taux de churn net en pourcentage sur 90 jours |
| **Présence moyenne** | Nombre moyen de têtes par session de présence |

Cliquez sur n'importe quel en-tête de colonne pour trier le tableau par cette colonne. Cliquez à nouveau pour inverser le sens du tri.

## Utilisation des données de santé

- **Churn élevé + adhésions faibles** — un groupe qui rétrécit et ne remplace pas les membres perdus. La peine d'une conversation avec le leader du groupe.
- **Adhésions élevées + présence faible** — les gens s'inscrivent mais ne se présentent pas. Envisagez un suivi d'engagement.
- **Présence moyenne élevée** — un groupe sain et actif. Modèle potentiel pour d'autres groupes.

:::tip
Cliquer sur un nom de groupe vous amène directement à la page de détail du groupe où vous pouvez examiner les membres individuels, les dossiers de présence et les événements du calendrier.
:::
