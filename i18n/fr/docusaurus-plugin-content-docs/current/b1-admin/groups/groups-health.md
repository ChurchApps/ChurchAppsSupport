# Santé des groupes

<div class="article-intro">

Le tableau de bord Santé des groupes vous donne une vue d'ensemble de comment tous vos groupes vont -- tendances d'adhésion, moyennes d'attendance et croissance ou attrition au cours des 90 derniers jours -- tout dans un seul tableau triable.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin d'au moins quelques groupes avec des membres pour voir des données significatives. Voir [Creating Groups](creating-groups).
- Les données d'attendance sont extraites des sessions enregistrées. Voir la section [Attendance](../attendance/).

</div>

## Ouvrir la santé des groupes

Dans B1 Admin, ouvrez le [menu de saut](../introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche), développez **People**, cliquez sur **Groups**, et cliquez ensuite sur le bouton **Group Health** dans l'en-tête de la page. Le tableau de bord charge un tableau avec une ligne par groupe.

## Colonnes

| Colonne | Ce qu'elle affiche |
|--------|--------------|
| **Name** | Le nom du groupe, lié à la page de détail du groupe |
| **Category** | La catégorie du groupe |
| **Members** | Nombre actuel de membres actifs |
| **Joined (90d)** | Membres qui ont rejoint au cours des 90 derniers jours |
| **Left (90d)** | Membres qui ont quitté au cours des 90 derniers jours |
| **Churn (90d)** | Taux de churn net en pourcentage sur 90 jours |
| **Avg Attendance** | Nombre moyen de personnes par session d'attendance |

Cliquez sur n'importe quel en-tête de colonne pour trier le tableau par cette colonne. Cliquez à nouveau pour inverser la direction du tri.

## Utiliser les données de santé

- **Churn élevé + adhésions faibles** — un groupe qui rétrécit et ne remplace pas les membres perdus. Cela mérite une conversation avec le leader du groupe.
- **Adhésions élevées + attendance faible** — les gens s'inscrivent mais ne se présentent pas. Considérez un suivi d'engagement.
- **Attendance moyenne élevée** — un groupe sain et actif. Modèle potentiel pour d'autres groupes.

:::tip
Cliquer sur un nom de groupe vous amène directement à la page de détail du groupe où vous pouvez examiner les membres individuels, les dossiers d'attendance et les événements du calendrier.
:::
