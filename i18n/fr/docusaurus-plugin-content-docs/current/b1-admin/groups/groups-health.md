# Santé des groupes

<div class="article-intro">

Le tableau de bord Santé des groupes vous offre une vue d'ensemble de la façon dont tous vos groupes se portent - tendances d'adhésion, moyennes de participation et croissance ou attrition au cours des 90 derniers jours - tout dans un tableau triable unique.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez avoir au moins quelques groupes avec des membres pour voir des données significatives. Voir [Créer des groupes](creating-groups).
- Les données de participation sont extraites des sessions enregistrées. Consultez la section [Participation](../attendance/).

</div>

## Ouvrir Santé des groupes

Dans B1 Admin, ouvrez le **menu de section** dans le coin supérieur gauche et choisissez **Personnes**, puis cliquez sur **Groupes** dans la barre de navigation et cliquez sur le bouton **Santé des groupes** dans l'en-tête de la page. Le tableau de bord charge un tableau avec une ligne par groupe.

## Colonnes

| Colonne | Ce qu'elle affiche |
|--------|--------------|
| **Nom** | Le nom du groupe, lié à la page de détail du groupe |
| **Catégorie** | La catégorie du groupe |
| **Membres** | Nombre actuel de membres actifs |
| **Adhérents (90j)** | Membres qui ont adhéré au cours des 90 derniers jours |
| **Partis (90j)** | Membres qui ont quitté au cours des 90 derniers jours |
| **Attrition (90j)** | Taux d'attrition net en pourcentage sur 90 jours |
| **Participation moyenne** | Effectif moyen par session de participation |

Cliquez sur l'en-tête d'une colonne pour trier le tableau selon cette colonne. Cliquez à nouveau pour inverser le sens du tri.

## Utiliser les données de santé

- **Attrition élevée + adhésions faibles** — un groupe qui rétrécit et ne remplace pas les membres perdus. Cela vaut la peine d'en discuter avec le leader du groupe.
- **Adhésions élevées + participation faible** — les gens s'inscrivent mais ne se présentent pas. Envisagez un suivi d'engagement.
- **Participation moyenne élevée** — un groupe sain et actif. Modèle potentiel pour d'autres groupes.

:::tip
Cliquer sur le nom d'un groupe vous amène directement à la page de détail du groupe où vous pouvez consulter les membres individuels, les enregistrements de participation et les événements du calendrier.
:::
