# Créer des groupes

<div class="article-intro">

Créer un groupe dans B1 Admin est simple. Vous allez configurer une catégorie, nommer votre groupe, puis configurer ses paramètres. Les groupes vous aident à organiser votre église en unités significatives comme les petits groupes, les comités et les classes.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin d'un compte B1 Admin actif avec l'autorisation de gérer les groupes. Consultez [Rôles et autorisations](../people/roles-permissions.md) si vous n'êtes pas sûr de votre niveau d'accès.
- Décidez d'une structure de catégories pour vos groupes (par exemple, « Petits groupes », « Ministères », « Comités »). Les catégories aident à garder les groupes liés organisés.

</div>

## Ajouter un nouveau groupe

1. Accédez au **tableau de bord B1 Admin**.
2. Cliquez sur l'onglet **Groupes**.
3. Cliquez sur **Ajouter un groupe** et saisissez un **nom de catégorie**. Les catégories vous aident à organiser les groupes liés entre eux (par exemple, « Petits groupes », « Ministères » ou « Comités »). Si une catégorie existe déjà, vous pouvez la sélectionner dans la liste.
4. Saisissez le **nom du groupe**.
5. Cliquez sur **Ajouter**. Votre nouveau groupe apparaîtra dans la liste sous la catégorie choisie.

## Configurer les paramètres du groupe

Une fois votre groupe créé, vous pouvez renseigner des détails supplémentaires :

1. Cliquez sur le **nom du groupe** dans la liste pour l'ouvrir.
2. Cliquez sur l'**icône crayon** pour modifier les paramètres du groupe.
3. Configurez les options suivantes :
   - **Description** -- Un bref résumé de l'objet du groupe. Ceci est visible par les membres.
   - **Horaires de réunion** -- Quand le groupe se réunit habituellement (par exemple, « Mercredis à 19h »).
   - **Politique d'adhésion** -- Choisissez qui peut rejoindre ce groupe :
     - **Ouvert** -- N'importe qui peut rejoindre immédiatement sans approbation
     - **Sur demande** -- Les personnes doivent soumettre une demande d'adhésion nécessitant une approbation (voir [Demandes d'adhésion à un groupe](./group-join-requests.md))
     - **Fermé** -- Les membres doivent être ajoutés manuellement par les responsables ou les administrateurs
   - **Étiquettes** -- Attribuez une ou plusieurs étiquettes descriptives au groupe (par exemple, « En personne », « En ligne », « Nouveaux membres bienvenus »). Les étiquettes sont des tags libres que vous définissez ; cochez toutes celles qui s'appliquent. Les étiquettes peuvent être utilisées pour filtrer les groupes dans l'élément de site web Navigateur de groupes.
   - **Groupe confidentiel** -- Masquer ce groupe et sa liste de membres des pages publiques, du chercheur de groupes, et des non-membres. Utilisez ceci pour les groupes sensibles comme les ministères de rétablissement ou d'accompagnement ; seuls les membres du groupe et le personnel de l'église peuvent le voir.
   - **Suivi des présences** -- Activez cette option si vous souhaitez enregistrer les [présences](../attendance/tracking-attendance.md) pour ce groupe.
   - **Horaires de service** -- Associez le groupe à des horaires de service d'église spécifiques le cas échéant. Consultez [Configuration des présences](../attendance/setup.md) pour plus de détails sur les horaires de service.
4. Cliquez sur **Enregistrer** pour appliquer vos modifications.

:::tip
Ajouter une description claire et un horaire de réunion aide les membres à savoir à quoi s'attendre lorsqu'ils rejoignent un groupe.
:::

## Dupliquer un groupe

Vous démarrez une nouvelle session d'une classe ou d'un ministère récurrent ? Plutôt que de ressaisir tous les paramètres, dupliquez un groupe existant :

1. Ouvrez le groupe et cliquez sur l'icône **dupliquer** dans la bannière du groupe (à côté de Modifier).
2. Confirmez la duplication.

La copie reprend les paramètres de l'original -- catégorie, description, horaire/lieu de réunion, politique d'adhésion, étiquettes et campus -- mais **pas** ses membres. Le nouveau groupe porte le nom de l'original avec « (Copie) » ajouté ; renommez-le depuis les paramètres du groupe.

## Archiver un groupe

Lorsqu'un groupe n'est plus actif mais que vous voulez conserver son historique plutôt que de le supprimer :

1. Ouvrez le groupe et cliquez sur l'**icône crayon** pour modifier ses paramètres.
2. Cliquez sur **Archiver** et confirmez.

Les groupes archivés disparaissent de la liste principale des Groupes. Pour en retrouver un, activez le bouton **Afficher les archivés** en haut de la page Groupes, puis cliquez sur **Restaurer** à côté du groupe pour le ramener.

:::info
Archiver un groupe ne supprime pas ses membres, son historique de présences ou ses événements de calendrier -- cela masque simplement le groupe de la liste par défaut jusqu'à ce que vous le restauriez.
:::

## Étapes suivantes

Après avoir créé et configuré votre groupe, vous êtes prêt à :

- **Ajouter des membres** -- Rechercher des personnes et les ajouter au groupe. Utilisez l'icône de clé verte pour désigner les responsables de groupe. Consultez [Membres du groupe](./group-members.md).
- **Configurer un calendrier** -- Créer des événements et des réunions récurrentes pour le groupe. Consultez [Calendrier du groupe](./group-calendar.md).
- **Communiquer** -- Envoyer des messages à tous les membres du groupe directement depuis la page du groupe.
- **Exporter des données** -- Cliquez sur l'icône de téléchargement pour exporter la liste des membres de votre groupe.

:::info
Tous les groupes de votre église sont organisés par catégories sur la page principale Groupes. Vous pouvez toujours réorganiser ou renommer les catégories à mesure que votre église grandit.
:::
