# Calendrier du groupe

<div class="article-intro">

Chaque groupe dans B1 peut avoir son propre calendrier d'événements. Les responsables de groupe l'utilisent pour planifier des réunions, des activités et des événements récurrents, tandis que tous les membres du groupe peuvent voir les événements à venir et participer aux conversations à leur sujet. Le calendrier garde votre groupe organisé et veille à ce que chacun reste informé de ce qui arrive.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin d'un groupe créé dans B1 Admin avec au moins un membre. Consultez [Créer des groupes](creating-groups.md) et [Membres du groupe](group-members.md).
- Pour ajouter ou modifier des événements de calendrier, vous devez être désigné comme responsable de groupe. Consultez [Désigner des responsables de groupe](group-members.md) pour les instructions.

</div>

## Accéder au calendrier du groupe

Le calendrier du groupe est accessible via l'application destinée aux membres, B1.church :

1. Depuis B1 Admin, cliquez sur le **menu déroulant** en haut à droite de votre écran.
2. Sélectionnez **Changer d'application**.
3. Choisissez **B1.church**.
4. Cliquez sur **Groupes** dans la barre latérale gauche.
5. Sélectionnez votre groupe dans la liste.
6. Cliquez sur **Calendrier** sur le côté gauche de l'écran.

:::info
Le calendrier du groupe est géré via B1.church (l'application des membres) plutôt que via B1 Admin. Les responsables de groupe y accèdent en changeant d'application depuis le tableau de bord administrateur.
:::

## Ajouter un événement

1. Depuis le calendrier du groupe, cliquez sur **Ajouter un événement**.
2. Saisissez un **titre** pour l'événement.
3. Rédigez une courte **description** de l'objet de l'événement.
4. Définissez l'**heure de début** et l'**heure de fin**.
5. Cliquez sur **Enregistrer** pour ajouter l'événement au calendrier.

## Configurer des événements récurrents

Si votre groupe se réunit selon un horaire régulier, vous pouvez configurer des événements pour qu'ils se répètent automatiquement :

1. Lors de la création ou de la modification d'un événement, cochez la case **Récurrent**.
2. Choisissez comment l'événement doit se répéter :
   - **Intervalle** -- Définissez un nombre de jours entre les occurrences. Par exemple, saisir « 7 » répète l'événement tous les 7 jours.
   - **Fréquence** -- Choisissez de répéter par **jour**, **semaine** ou **mois**.
3. Enregistrez l'événement. Il apparaîtra désormais dans le calendrier à chaque occurrence planifiée.

:::tip
Pour un groupe qui se réunit tous les samedis, réglez la fréquence sur « semaine » et choisissez samedi. L'événement se peuplera automatiquement dans le calendrier à l'avenir.
:::

## Créer des événements en masse dans B1 Admin

La page du groupe dans B1 Admin comporte également un onglet **Calendrier** où le personnel peut planifier toute une saison de réunions en une seule fois :

1. Ouvrez le groupe dans B1 Admin et sélectionnez l'onglet **Calendrier**.
2. Cliquez sur **Ajouter des événements** pour ouvrir la boîte de dialogue **Ajouter des événements récurrents**.
3. Choisissez l'horaire (hebdomadaire, toutes les 2 semaines, mensuel, ou unique), les dates de **Première réunion** et **Dernière réunion**, et optionnellement **Ignorer les jours fériés**.
4. Passez en revue l'aperçu des dates de réunion et décochez celles à ignorer.
5. Laissez **Autoriser les RSVP** coché si vous souhaitez que les membres puissent répondre à ces événements (voir ci-dessous), puis enregistrez.

## RSVP aux événements

Les événements de groupe peuvent recueillir des RSVP — un **Oui**, **Non**, ou **Peut-être** pour chaque occurrence de l'événement.

- **Autoriser les RSVP** est activé par défaut pour les événements créés via la boîte de dialogue d'ajout en masse ; décochez pour désactiver les réponses pour ces événements. Les événements avec les RSVP désactivés apparaissent comme **Désactivé** dans l'onglet calendrier.
- Sur l'onglet calendrier du groupe dans B1 Admin, chaque événement affiche un résumé des réponses (par exemple, « 5 oui · 2 peut-être · 1 non »). Cliquez pour ouvrir la liste **Réponses RSVP**, qui répertorie qui a répondu oui, peut-être et non pour cette occurrence.

:::tip
Les RSVP donnent aux responsables un décompte sans la formalité d'une inscription complète à l'événement. Pour les inscriptions payantes ou les événements avec gestion de capacité, utilisez plutôt l'[inscription aux événements](../calendars/creating-calendars.md#enabling-event-registration).
:::

## Consulter le calendrier

Le calendrier du groupe propose plusieurs options d'affichage :

- **Mois** -- Voir le mois complet en un coup d'œil.
- **Semaine** -- Se concentrer sur la semaine en cours.
- **Jour** -- Voir un seul jour en détail.
- **Agenda** -- Voir une liste des événements à venir par ordre chronologique.

Basculez entre les vues à l'aide des boutons en haut du calendrier.

## Détails de l'événement et conversations

Cliquez sur n'importe quel événement pour voir ses détails. Depuis la vue de détail de l'événement :

- **Les membres et les responsables** peuvent démarrer des conversations et laisser des commentaires à propos de l'événement.
- **Les responsables** peuvent modifier les détails de l'événement, changer les horaires, ou supprimer l'événement.

:::warning
Supprimer un événement le retire définitivement. Si vous devez annuler une seule occurrence d'un événement récurrent, envisagez plutôt de le modifier.
:::

## S'abonner au calendrier

Vous pouvez synchroniser le calendrier du groupe avec votre calendrier personnel :

1. Depuis la page du calendrier du groupe, cliquez sur **S'abonner**.
2. Suivez les instructions pour ajouter le calendrier à Google Agenda, Apple Calendar, Outlook, ou toute autre application de calendrier prenant en charge les abonnements.

:::tip
S'abonner garde votre emploi du temps personnel synchronisé avec les événements de votre groupe sans avoir besoin de consulter B1 séparément. Tout changement effectué par les responsables de groupe apparaîtra automatiquement dans votre calendrier synchronisé.
:::
