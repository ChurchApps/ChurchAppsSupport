# Calendrier du groupe

<div class="article-intro">

Chaque groupe dans B1 peut disposer de son propre calendrier d'événements. Les responsables du groupe s'en servent pour planifier les réunions, les activités et les événements récurrents, tandis que tous les membres du groupe peuvent consulter les événements à venir et participer aux échanges à leur sujet. Le calendrier aide à organiser le groupe et à garantir que chacun est informé de ce qui s'en vient.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous avez besoin d'un groupe créé dans B1 Admin comportant au moins un membre. Consultez [Créer des groupes](creating-groups.md) et [Membres du groupe](group-members.md).
- Pour ajouter ou modifier des événements du calendrier, vous devez être désigné comme responsable du groupe. Consultez [Désigner les responsables du groupe](group-members.md) pour les instructions.

</div>

## Accéder au calendrier du groupe

Le calendrier du groupe est accessible via l'application destinée aux membres B1.church :

1. Depuis B1 Admin, cliquez sur le **menu déroulant** dans le coin supérieur droit de votre écran.
2. Sélectionnez **Switch App**.
3. Choisissez **B1.church**.
4. Ouvrez **Groups** (un onglet de la barre de navigation inférieure sur un téléphone, ou dans l'en-tête supérieur sur un ordinateur).
5. Sélectionnez votre groupe dans la liste.
6. Sous **Next event**, cliquez sur **All events** pour ouvrir la vue **Events** du groupe. Utilisez le bouton **Calendar** pour afficher une vue mensuelle.

:::info
Le calendrier du groupe est géré via B1.church (l'application destinée aux membres) plutôt que depuis B1 Admin. Les responsables du groupe y accèdent en changeant d'application depuis le tableau de bord d'administration.
:::

## Ajouter un événement

1. Depuis le calendrier du groupe, cliquez sur **Add Event**.
2. Saisissez un **title** pour l'événement.
3. Rédigez une courte **description** de l'événement.
4. Définissez l'**heure de début** et l'**heure de fin**.
5. Cliquez sur **Save** pour ajouter l'événement au calendrier.

## Configurer des événements récurrents

Si votre groupe se réunit régulièrement, vous pouvez configurer la répétition automatique des événements :

1. Lors de la création ou de la modification d'un événement, cochez la case **Recurring**.
2. Choisissez la manière dont l'événement doit se répéter :
   - **Interval** -- Définissez un nombre de jours entre les occurrences. Par exemple, saisir « 7 » répète l'événement tous les 7 jours.
   - **Frequency** -- Choisissez de répéter par **day**, **week** ou **month**.
3. Enregistrez l'événement. Il apparaîtra désormais dans le calendrier à chaque occurrence prévue.

:::tip
Pour un groupe qui se réunit tous les samedis, réglez la fréquence sur « week » et choisissez samedi. L'événement sera automatiquement reporté dans le calendrier à l'avenir.
:::

## Créer des événements en lot dans B1 Admin

La page du groupe dans B1 Admin comporte également une section **Calendar** qui permet au personnel de planifier une saison entière de réunions en une seule fois :

1. Ouvrez le groupe dans B1 Admin et, dans la section **Calendar**, cliquez sur **All events**.
2. Cliquez sur **+ Add Events** pour ouvrir la boîte de dialogue **Add Recurring Events**.
3. Choisissez le calendrier (chaque semaine, toutes les 2 semaines, chaque mois ou une seule fois), les dates de la **First Meeting** et de la **Last Meeting**, et, si vous le souhaitez, **Skip holidays**.
4. Examinez l'aperçu des dates de réunion et décochez celles que vous voulez ignorer.
5. Laissez **Allow RSVPs** coché si vous souhaitez que les membres puissent répondre à ces événements (voir ci-dessous), puis enregistrez.

## Confirmations de participation aux événements

Les événements de groupe peuvent recueillir des confirmations de participation (RSVP) : un **Yes**, **No** ou **Maybe** pour chaque occurrence de l'événement.

- **Allow RSVPs** est activé par défaut pour les événements créés via la boîte de dialogue d'ajout en lot ; décochez-le pour désactiver les réponses de ces événements. Les événements dont les RSVP sont désactivés apparaissent comme **Disabled** dans la liste des événements du groupe.
- Dans la liste des événements du groupe dans B1 Admin, chaque événement affiche un résumé des réponses (par exemple, « 5 yes · 2 maybe · 1 no »). Cliquez dessus pour ouvrir la liste **RSVP Responses**, qui indique qui a répondu oui, peut-être ou non pour cette occurrence.

:::tip
Les RSVP donnent aux responsables un décompte des participants sans la lourdeur d'une inscription complète à l'événement. Pour les inscriptions payantes ou les événements à capacité limitée, utilisez plutôt [l'inscription à un événement](../calendars/creating-calendars.md#enabling-event-registration).
:::

## Afficher le calendrier

Le calendrier du groupe propose plusieurs modes d'affichage :

- **Month** -- Voir le mois entier d'un seul coup d'œil.
- **Week** -- Se concentrer sur la semaine en cours.
- **Day** -- Afficher une seule journée en détail.
- **Agenda** -- Voir la liste des événements à venir dans l'ordre chronologique.

Passez d'un mode d'affichage à l'autre à l'aide des boutons en haut du calendrier.

## Détails des événements et discussions

Cliquez sur un événement pour en afficher les détails. Depuis la vue détaillée de l'événement :

- **Les membres et les responsables** peuvent lancer des discussions et laisser des commentaires sur l'événement.
- **Les responsables** peuvent modifier les détails de l'événement, changer les horaires ou supprimer l'événement.

:::warning
Supprimer un événement le retire définitivement. Si vous devez annuler une seule occurrence d'un événement récurrent, modifiez-le plutôt.
:::

## S'abonner au calendrier

Vous pouvez synchroniser le calendrier du groupe avec votre calendrier personnel :

1. Depuis la page du calendrier du groupe, cliquez sur **Subscribe**.
2. Suivez les instructions pour ajouter le calendrier à Google Calendar, Apple Calendar, Outlook ou à toute autre application de calendrier prenant en charge les abonnements.

:::tip
S'abonner permet de garder votre emploi du temps personnel synchronisé avec les événements de votre groupe, sans avoir à consulter B1 séparément. Toute modification apportée par les responsables du groupe apparaîtra automatiquement dans votre calendrier synchronisé.
:::
