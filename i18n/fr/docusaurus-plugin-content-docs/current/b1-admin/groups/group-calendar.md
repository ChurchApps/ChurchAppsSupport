# Calendrier du groupe {#group-calendar}

<div class="article-intro">

Chaque groupe dans B1 peut avoir son propre calendrier d'événements. Les responsables de groupe l'utilisent pour planifier les rencontres, les activités et les événements récurrents, tandis que tous les membres du groupe peuvent consulter les événements à venir et participer aux discussions à leur sujet. Le calendrier garde votre groupe organisé et permet à chacun de rester informé de ce qui s'en vient.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez avoir créé un groupe dans B1 Admin comptant au moins un membre. Consultez [Créer des groupes](creating-groups.md) et [Membres du groupe](group-members.md).
- Pour ajouter ou modifier des événements du calendrier, vous devez être désigné comme responsable de groupe. Consultez [Désigner les responsables de groupe](group-members.md) pour les instructions.

</div>

## Accéder au calendrier du groupe {#accessing-the-group-calendar}

Le calendrier du groupe est accessible depuis l'application destinée aux membres B1.church :

1. Depuis B1 Admin, cliquez sur le **menu déroulant** dans le coin supérieur droit de votre écran.
2. Sélectionnez **Changer d'application**.
3. Choisissez **B1.church**.
4. Ouvrez **Groupes** (un onglet dans la barre d'onglets du bas sur un téléphone, ou dans l'en-tête supérieur sur un ordinateur).
5. Sélectionnez votre groupe dans la liste.
6. Sous **Prochain événement**, cliquez sur **Tous les événements** pour ouvrir la vue **Événements** du groupe. Utilisez le bouton **Calendrier** pour afficher une vue mensuelle.

:::info
Le calendrier du groupe se gère depuis B1.church (l'application destinée aux membres) plutôt que depuis B1 Admin. Les responsables de groupe y accèdent en changeant d'application depuis le tableau de bord d'administration.
:::

## Ajouter un événement {#adding-an-event}

1. Depuis le calendrier du groupe, cliquez sur **Ajouter un événement**.
2. Saisissez un **titre** pour l'événement.
3. Rédigez une courte **description** de l'événement.
4. Définissez l'**heure de début** et l'**heure de fin**.
5. Cliquez sur **Enregistrer** pour ajouter l'événement au calendrier.

## Configurer des événements récurrents {#setting-up-recurring-events}

Si votre groupe se réunit régulièrement, vous pouvez configurer des événements qui se répètent automatiquement :

1. Lors de la création ou de la modification d'un événement, cochez la case **Récurrent**.
2. Choisissez la façon dont l'événement se répète :
   - **Intervalle** -- Définissez un nombre de jours entre chaque occurrence. Par exemple, saisir « 7 » répète l'événement tous les 7 jours.
   - **Fréquence** -- Choisissez de répéter par **jour**, **semaine** ou **mois**.
3. Enregistrez l'événement. Il apparaîtra maintenant au calendrier à chaque occurrence prévue.

:::tip
Pour un groupe qui se réunit chaque samedi, réglez la fréquence sur « semaine » et choisissez samedi. L'événement se remplira automatiquement dans le calendrier à partir de maintenant.
:::

## Créer des événements en lot dans B1 Admin {#bulk-creating-events-in-b1-admin}

La page du groupe dans B1 Admin comporte aussi une section **Calendrier** où le personnel peut planifier toute une saison de rencontres d'un coup :

1. Ouvrez le groupe dans B1 Admin et, dans la section **Calendrier**, cliquez sur **Tous les événements**.
2. Cliquez sur **+ Ajouter des événements** pour ouvrir la boîte de dialogue **Ajouter des événements récurrents**.
3. Choisissez le calendrier (chaque semaine, toutes les 2 semaines, chaque mois ou une seule fois), les dates de **première rencontre** et de **dernière rencontre**, et facultativement **Ignorer les jours fériés**.
4. Vérifiez l'aperçu des dates de rencontre et décochez celles que vous voulez sauter.
5. Laissez **Autoriser les RSVP** coché si vous voulez que les membres puissent répondre à ces événements (voir ci-dessous), puis enregistrez.

## RSVP aux événements {#event-rsvps}

Les événements de groupe peuvent recueillir des RSVP -- un **Oui**, **Non** ou **Peut-être** pour chaque occurrence de l'événement.

- **Autoriser les RSVP** est activé par défaut pour les événements créés via la boîte de dialogue d'ajout en lot ; décochez-le pour désactiver les réponses pour ces événements. Les événements dont les RSVP sont désactivés apparaissent comme **Désactivé** dans la liste des événements du groupe.
- Dans la liste des événements du groupe de B1 Admin, chaque événement affiche un résumé des réponses (par exemple, « 5 oui · 2 peut-être · 1 non »). Cliquez dessus pour ouvrir la liste **Réponses RSVP**, qui indique qui a répondu oui, peut-être ou non pour cette occurrence.

:::tip
Les RSVP donnent aux responsables un décompte des participants sans la formalité d'une inscription complète à l'événement. Pour les inscriptions payantes ou les événements à capacité limitée, utilisez plutôt [l'inscription à l'événement](../calendars/creating-calendars.md#enabling-event-registration).
:::

## Afficher le calendrier {#viewing-the-calendar}

Le calendrier du groupe offre plusieurs modes d'affichage :

- **Mois** -- Voir le mois complet d'un coup d'œil.
- **Semaine** -- Se concentrer sur la semaine en cours.
- **Jour** -- Voir une seule journée en détail.
- **Agenda** -- Voir la liste des événements à venir dans l'ordre chronologique.

Changez de mode d'affichage à l'aide des boutons en haut du calendrier.

## Détails de l'événement et discussions {#event-details-and-conversations}

Cliquez sur un événement pour en voir les détails. Depuis la vue détaillée de l'événement :

- **Les membres et les responsables** peuvent démarrer des discussions et laisser des commentaires sur l'événement.
- **Les responsables** peuvent modifier les détails de l'événement, changer les heures ou supprimer l'événement.

:::warning
La suppression d'un événement le retire définitivement. Si vous voulez annuler une seule occurrence d'un événement récurrent, envisagez plutôt de le modifier.
:::

## S'abonner au calendrier {#subscribing-to-the-calendar}

Vous pouvez synchroniser le calendrier du groupe avec votre calendrier personnel :

1. Depuis la page du calendrier du groupe, cliquez sur **S'abonner**.
2. Suivez les étapes pour ajouter le calendrier à Google Agenda, Calendrier Apple, Outlook ou toute autre application de calendrier qui prend en charge les abonnements.

:::tip
S'abonner permet de garder votre horaire personnel synchronisé avec les événements de votre groupe sans avoir à consulter B1 séparément. Toute modification apportée par les responsables de groupe apparaîtra automatiquement dans votre calendrier synchronisé.
:::
