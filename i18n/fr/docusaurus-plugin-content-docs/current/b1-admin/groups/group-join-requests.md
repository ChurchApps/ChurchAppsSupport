# Demandes d'adhésion aux groupes

<div class="article-intro">

Lorsqu'un groupe est configuré avec une politique d'adhésion sur approbation, les personnes peuvent soumettre des demandes pour le rejoindre. Les responsables et administrateurs de groupes examinent ces demandes et les acceptent ou les refusent. Cela permet à votre église de contrôler la composition des groupes, tout en facilitant la démarche des personnes qui souhaitent les rejoindre.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Vous avez besoin de la permission de gérer les groupes, ou vous devez être responsable du groupe concerné. Consultez [Rôles et permissions](../people/roles-permissions.md) pour plus de détails.
- Le groupe doit avoir sa politique d'adhésion réglée sur **Demande** (approbation requise). Consultez [Créer des groupes](./creating-groups.md) pour savoir comment configurer les politiques d'adhésion.

</div>

## Comprendre les politiques d'adhésion

Les groupes peuvent avoir trois politiques d'adhésion différentes :

- **Ouvert** -- Chacun peut rejoindre immédiatement, sans approbation
- **Demande** -- Les personnes soumettent une demande d'adhésion qui doit être approuvée
- **Fermé** -- Personne ne peut demander à rejoindre le groupe (les membres doivent être ajoutés manuellement)

Lorsqu'un groupe utilise la politique **Demande**, toutes les tentatives d'adhésion passent par le processus d'approbation décrit sur cette page.

## Voir les demandes en attente

### Pour les responsables de groupe

1. Dans B1 Admin, ouvrez le [menu Sauter](../introduction.md#getting-around-with-the-jump-menu) et choisissez **Personnes > Groupes**
2. Cliquez sur le nom du groupe
3. La section **Membres** indique le nombre de demandes en attente. Cliquez sur **Tous les membres** -- les demandes en attente de ce groupe apparaissent en haut de la liste des membres

### Pour les administrateurs

Les administrateurs disposant de permissions de gestion des groupes peuvent voir les demandes en attente de tous les groupes :

1. Dans le menu Sauter, choisissez **Personnes > Groupes**
2. Cliquez sur le bouton **demandes en attente** dans l'en-tête de la page (par exemple, « 3 demandes en attente »). Il n'apparaît que lorsqu'il y a des demandes en attente.
3. Examinez toutes les demandes en attente de l'église

## Examiner une demande d'adhésion

Chaque demande d'adhésion affiche :

- **Nom et photo de la personne** -- La personne qui demande à rejoindre le groupe
- **Message facultatif** -- Un message personnel expliquant pourquoi la personne souhaite rejoindre le groupe (s'il a été fourni)
- **Date de la demande** -- Date à laquelle la demande a été soumise

Pour examiner une demande :

1. Lisez le message de la personne, si elle en a fourni un
2. Cliquez sur le nom de la personne pour consulter son profil si nécessaire
3. Décidez d'accepter ou de refuser la demande

## Accepter une demande

1. Cliquez sur **Accepter** sur la demande d'adhésion
2. La personne est immédiatement ajoutée au groupe en tant que membre
3. Le demandeur reçoit une notification indiquant que sa demande a été acceptée
4. La demande est marquée comme acceptée dans le système

:::tip
Lorsque vous acceptez une demande, la personne devient un membre ordinaire du groupe. Vous pourrez ensuite la promouvoir responsable de groupe si nécessaire, depuis la page [Membres du groupe](./group-members.md).
:::

## Refuser une demande

1. Cliquez sur **Refuser** sur la demande d'adhésion
2. Indiquez éventuellement un motif de refus (500 caractères maximum)
3. Cliquez sur **Confirmer**
4. Le demandeur reçoit une notification contenant votre motif de refus (s'il a été fourni)
5. La demande est marquée comme refusée

:::info
Indiquer un motif de refus aide la personne à comprendre pourquoi sa demande n'a pas été acceptée, et peut l'encourager à réessayer plus tard ou à explorer d'autres groupes.
:::

## Accepter depuis la page des tâches {#approving-from-the-tasks-page}

Chaque demande d'adhésion crée également une tâche sous **Service &rarr; Mon travail**, intitulée « *Personne* a demandé à rejoindre *Groupe* ». Elle est assignée aux responsables du groupe. Si le groupe n'a pas encore de responsable, elle est attribuée à tout membre du personnel disposant de la permission **Group Members &gt; Edit**, ou aux administrateurs de domaine de votre église si personne ne dispose de cette permission. Le personnel et les administrateurs qui reçoivent la tâche de cette façon reçoivent aussi une notification qui y mène directement.

L'ouverture de la tâche affiche le nom du demandeur, le groupe et son message facultatif, avec les boutons **Accepter** et **Refuser** directement sur la carte de la tâche (Refuser ouvre le même champ de motif facultatif décrit ci-dessus). Les responsables disposent ainsi d'une deuxième façon, pilotée par les notifications, de traiter une demande sans ouvrir la liste des membres du groupe.

Décider d'une demande depuis l'un ou l'autre endroit -- la liste des membres du groupe ou sa carte de tâche -- la clôture partout : les responsables ne voient ainsi jamais une tâche obsolète pour une demande déjà traitée.

## Notifications

Le système de demandes d'adhésion envoie automatiquement des notifications :

- **Lorsqu'une demande est soumise** -- Tous les responsables du groupe reçoivent une notification. Si le groupe n'a pas de responsable, ce sont plutôt le personnel ou les administrateurs assignés à la tâche qui sont avisés (voir ci-dessus).
- **Lorsqu'une demande est acceptée** -- Le demandeur reçoit une confirmation
- **Lorsqu'une demande est refusée** -- Le demandeur reçoit une notification avec le motif de refus éventuel

Les notifications apparaissent dans le centre de notifications de l'utilisateur sur B1.church et dans l'application mobile. Dans la cloche de notifications de B1 Admin, un clic sur une notification de demande d'adhésion (ou sur **Voir les détails**) ouvre le groupe sur le site B1.church de votre église, dans un nouvel onglet.

## Gérer les demandes côté membre

Les personnes peuvent gérer leurs propres demandes d'adhésion depuis B1.church :

- Consulter l'état de leurs demandes en attente sur la page de détail du groupe
- Annuler une demande en attente si elles changent d'avis
- Voir si leur demande a été acceptée ou refusée

## Bonnes pratiques

- **Répondez rapidement** -- Essayez d'examiner les demandes dans les 24 à 48 heures pour que les personnes ne restent pas dans l'attente
- **Soyez clair dans les motifs de refus** -- Aidez les personnes à comprendre les étapes suivantes ou les autres options possibles
- **Consultez les profils** -- Vérifiez le profil de la personne pour voir si elle convient au groupe
- **Communiquez les attentes** -- Assurez-vous que la description de votre groupe indique clairement à qui il s'adresse
