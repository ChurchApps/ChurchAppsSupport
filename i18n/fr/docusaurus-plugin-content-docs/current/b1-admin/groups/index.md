# Groupes

<div class="article-intro">

La section **Groupes** vous permet d'organiser les membres de votre église en ministères, petits groupes, études bibliques, comités, etc. Les groupes sont l'épine dorsale de la vie communautaire de votre église, et cette section vous donne les outils pour créer, gérer et communiquer avec chaque groupe en un seul endroit. Notez que les **Teams** sont distincts des Groupes — les Teams sont utilisés pour la planification des services et du bénévolat.

</div>

## Aperçu

Les groupes sont organisés par **catégorie**. Une catégorie est un libellé de haut niveau tel que « Petits Groupes », « Ministères » ou « Comités ». Chaque catégorie peut contenir plusieurs groupes, ce qui facilite le maintien des groupes associés ensemble.

Lorsque vous ouvrez la page Groupes, vous verrez un résumé en haut affichant :

- **Total de groupes** -- le nombre de groupes dans toutes les catégories
- **Catégories** -- le nombre de catégories de groupes que vous avez créées
- **Total de membres** -- le nombre combiné de membres dans tous les groupes

Sous le résumé, vos groupes sont répertoriés par catégorie avec le nombre de membres indiqué pour chaque groupe.

## Ce que vous pouvez faire

Voici ce que vous pouvez accomplir dans la section Groupes :

1. **Créer et organiser des groupes** -- Ajoutez de nouveaux groupes dans les catégories pour refléter la structure de votre église. Voir [Création de groupes](./creating-groups.md).

2. **Gérer les membres du groupe** -- Ajoutez et supprimez des membres, désignez des responsables et communiquez avec vos groupes. Voir [Membres du groupe](./group-members.md).

3. **Planifier les événements** -- Chaque groupe peut avoir son propre calendrier pour les réunions, les événements et les activités récurrentes. Voir [Calendrier du groupe](./group-calendar.md).

4. **Gérer les demandes d'adhésion** -- Lorsqu'un groupe utilise la politique d'adhésion **Request**, examinez et approuvez ou refusez les demandes d'adhésion entrantes des personnes qui souhaitent rejoindre. Voir [Demandes d'adhésion au groupe](./group-join-requests.md).

5. **Exporter les données du groupe** -- Téléchargez les listes de membres pour tout groupe sous forme de fichier CSV pour une utilisation dans des feuilles de calcul ou des envois de courrier. Voir [Membres du groupe](./group-members.md) pour les instructions d'exportation.

## Commencer

Pour accéder aux Groupes, ouvrez le [menu Sauter](../introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche de B1 Admin), développez **Personnes**, et cliquez sur **Groupes**. Vous verrez tous vos groupes existants organisés par catégorie.

:::tip
Si vous commencez tout juste, commencez par créer quelques catégories qui correspondent à la structure de votre église (par exemple, « Ministères », « Petits Groupes », « Comités »). Ensuite, ajoutez des groupes individuels dans chaque catégorie. Voir [Création de groupes](./creating-groups.md) pour une procédure pas à pas.
:::

:::info
Les membres du groupe doivent d'abord exister dans votre répertoire [Personnes](../people/adding-people.md) avant de pouvoir être ajoutés à un groupe. Si vous configurez B1 pour la première fois, [importez vos données de membres](../people/importing-data.md) avant de créer des groupes.
:::
