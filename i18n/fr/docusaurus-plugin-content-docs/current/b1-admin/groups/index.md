# Groupes

<div class="article-intro">

La section **Groupes** vous permet d'organiser les membres de votre église en ministères, petits groupes, études bibliques, comités, etc. Les groupes sont l'épine dorsale de la vie communautaire de votre église, et cette section vous donne les outils pour créer, gérer et communiquer avec chaque groupe en un seul endroit. Notez que les **Équipes** sont séparées des groupes — les équipes sont utilisées pour le service et la planification des bénévoles.

</div>

## Aperçu

Les groupes sont organisés par **catégorie**. Une catégorie est un libellé de niveau supérieur comme "Petits groupes", "Ministères" ou "Comités". Chaque catégorie peut contenir plusieurs groupes, ce qui rend facile de garder les groupes connexes ensemble.

Quand vous ouvrez la page Groupes, vous verrez un résumé en haut montrant :

- **Total des groupes** -- le nombre de groupes dans toutes les catégories
- **Catégories** -- le nombre de catégories de groupes que vous avez créées
- **Total des membres** -- le décompte combiné des membres dans tous les groupes

Sous le résumé, vos groupes sont listés par catégorie avec le décompte des membres montré pour chaque groupe.

## Ce que vous pouvez faire

Voici ce que vous pouvez accomplir dans la section Groupes :

1. **Créez et organisez les groupes** -- Ajoutez de nouveaux groupes dans les catégories pour refléter la façon dont votre église est structurée. Voir [Création de groupes](./creating-groups.md).

2. **Gérez les membres du groupe** -- Ajoutez et supprimez les membres, désignez les leaders et communiquez avec vos groupes. Voir [Membres du groupe](./group-members.md).

3. **Planifiez les événements** -- Chaque groupe peut avoir son propre calendrier pour les réunions, les événements et les activités récurrentes. Voir [Calendrier du groupe](./group-calendar.md).

4. **Gérez les demandes d'adhésion** -- Quand un groupe utilise la politique d'adhésion **Demande**, examinez et approuvez ou refusez les demandes d'adhésion entrantes de personnes qui veulent adhérer. Voir [Demandes d'adhésion au groupe](./group-join-requests.md).

5. **Exportez les données du groupe** -- Téléchargez les listes de membres de n'importe quel groupe en tant que fichier CSV pour une utilisation dans des feuilles de calcul ou des envois. Voir [Membres du groupe](./group-members.md) pour les instructions d'exportation.

## Prise en main

Pour accéder aux groupes, ouvrez le **menu de section** dans le coin supérieur gauche de votre tableau de bord B1 Admin et choisissez **Personnes**, puis cliquez sur l'onglet **Groupes** dans la barre de navigation. Vous verrez tous vos groupes existants organisés par catégorie.

:::tip
Si vous ne faites que commencer, commencez par créer quelques catégories qui correspondent à votre structure d'église (par exemple, "Ministères", "Petits groupes", "Comités"). Ensuite, ajoutez des groupes individuels dans chaque catégorie. Voir [Création de groupes](./creating-groups.md) pour une procédure pas à pas.
:::

:::info
Les membres du groupe doivent d'abord exister dans votre répertoire [Personnes](../people/adding-people.md) avant de pouvoir être ajoutés à un groupe. Si vous configurez B1 pour la première fois, [importez vos données de membre](../people/importing-data.md) avant de créer des groupes.
:::
