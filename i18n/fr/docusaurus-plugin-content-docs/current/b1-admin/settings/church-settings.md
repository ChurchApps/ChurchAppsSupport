# Paramètres d'église

<div class="article-intro">

La page Paramètres d'église est l'endroit où vous configurez les informations de base, les coordonnées et la marque de votre église. Ces détails sont utilisés dans tous les outils ChurchApps, y compris votre site web B1.church et l'application B1 Mobile.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez avoir la permission « Modifier les paramètres d'église ». Consultez [Rôles et permissions](./roles-permissions.md) si vous n'avez pas accès.
- Ayez l'adresse, les coordonnées et le logo de votre église prêts

</div>

## Édition des informations de votre église

1. Dans B1 Admin, ouvrez le **menu de section** dans le coin supérieur gauche (le nom de la section avec la petite flèche) et choisissez **Paramètres**.
2. Cliquez sur le bouton **Modifier les paramètres** dans l'en-tête.
3. Mettez à jour l'un des champs suivants :
   - **Nom de l'église** -- Le nom affiché dans tous les produits ChurchApps.
   - **Adresse** -- L'adresse physique de votre église.
   - **Coordonnées** -- Numéro de téléphone, e-mail et autres détails de contact.
4. Cliquez sur **Enregistrer** pour appliquer vos modifications.

## Configuration de votre sous-domaine

Votre église reçoit un sous-domaine gratuit à **votreeglise.b1.church**. C'est l'adresse web où les membres et les visiteurs peuvent accéder à la présence en ligne de votre église.

1. Sur la page Paramètres, localisez le champ **Sous-domaine**.
2. Entrez votre sous-domaine préféré (par exemple, « gracechurch » pour gracechurch.b1.church).
3. Enregistrez vos modifications.

:::info
Votre sous-domaine doit être unique dans toutes les églises ChurchApps. Si votre nom préféré est pris, essayez d'ajouter votre ville ou état (par exemple, « gracechurch-dallas »).
:::

## Configuration de la marque

Personnalisez la façon dont votre église apparaît dans tous les outils ChurchApps :

1. Téléchargez votre **logo d'église** en cliquant sur la zone du logo et en sélectionnant un fichier image.
2. Ajoutez toute **image d'église** supplémentaire utilisée sur votre site web et [application mobile](./mobile-app.md).

:::tip
Pour de meilleurs résultats, utilisez un logo avec un fond transparent au format PNG. Cela garantit qu'il a fière allure sur les fonds clairs et sombres.
:::

## Premier jour de la semaine

Choisissez le jour où vos calendriers commencent. La liste déroulante **Premier jour de la semaine** dans la section Informations d'église par défaut sur **Dimanche**, mais peut être défini sur n'importe quel jour. Une fois modifié, il est honoré dans les grilles de calendrier dans B1 Admin et le portail des membres B1.church -- les calendriers des groupes, les calendriers organisés et l'éditeur d'événements sont tous disposés en commençant le jour que vous choisissez.

## Promotion de classe

Si vous suivez la **Classe** sur les enfants et les étudiants, B1 peut automatiquement augmenter tout le monde d'une classe à une date que vous choisissez (par exemple, le 1er août) plutôt que de vous obliger à éditer chaque profil à la main.

1. Sur la page Paramètres, trouvez l'option **Promotion de classe**.
2. Activez-la et choisissez le **mois et le jour** pour promouvoir les classes chaque année.
3. Enregistrez vos modifications.

## Import et export

Le bouton **Importer/Exporter** dans l'en-tête Paramètres ouvre un outil dédié dans une nouvelle fenêtre de navigateur. Utilisez-le pour :

- Importer les données des membres d'un autre système de gestion d'église.
- Exporter vos données ChurchApps pour la sauvegarde ou la migration.

C'est particulièrement utile lorsque vous configurez votre église pour la première fois et devez transférer les dossiers existants dans ChurchApps.

:::warning
Lors de l'importation de données, sauvegardez toujours vos dossiers existants en premier. Les opérations d'importation ajoutent des données à votre système et peuvent créer des entrées en double si elles sont exécutées plusieurs fois.
:::
