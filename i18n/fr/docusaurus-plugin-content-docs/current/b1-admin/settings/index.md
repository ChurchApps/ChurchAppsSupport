# Paramètres

<div class="article-intro">

La section Paramètres est l'endroit où vous configurez le compte de votre église, son image de marque et les options administratives dans B1 Admin. À partir d'ici, vous pouvez gérer tout, du nom de votre église et de votre sous-domaine jusqu'aux permissions des utilisateurs et à la configuration de l'application mobile.

</div>

## Ce que vous trouverez ici

La section Paramètres est organisée dans les sous-sections suivantes, accessibles depuis la barre latérale :

1. **Paramètres** -- Configurez les informations de base, l'image de marque et le sous-domaine de votre église. Consultez [Paramètres de l'église](./church-settings.md) pour plus de détails.
2. **Sites** -- Ajoutez et gérez plusieurs emplacements physiques pour votre église. Une fois créés, les sites apparaissent sur les profils de personnes, dans la configuration de la présence et dans le tableau de bord Démographie. Consultez [Sites](./campuses.md) pour plus de détails.
3. **Champs personnalisés** -- Définissez vos propres champs à suivre sur les personnes (une date, un nombre, une réponse oui/non ou une liste de choix), puis remplissez-les sur les profils et effectuez des recherches à partir de ceux-ci. Consultez [Champs personnalisés](./custom-fields.md) pour plus de détails.
3. **Applications mobiles** -- Configurez et personnalisez les onglets de navigation qui apparaissent dans la [PWA B1.church](/docs/b1-church/getting-started/installing-pwa) pour vos membres (les mêmes onglets sont également affichés par l'application native B1 Mobile désormais obsolète). Consultez [Paramètres de l'application mobile](./mobile-app.md) pour plus de détails.
4. **Modèles d'e-mail** -- Enregistrez du contenu d'e-mail réutilisable à envoyer manuellement ou depuis un flux de travail. Consultez [Modèles d'e-mail](./email-templates.md) pour plus de détails.
5. **Administration serveur** -- Accédez à des outils d'administration avancés pour gérer les paramètres au niveau du serveur de votre église.
6. **Formulaires** -- Créez et gérez des formulaires personnalisés pour recueillir des informations auprès de votre congrégation.

## La page principale des paramètres

Lorsque vous ouvrez pour la première fois la page Paramètres, vous verrez le **nom de votre église** et son **sous-domaine** affichés en haut. L'en-tête propose des boutons d'accès rapide pour les tâches courantes :

- **Modifier les paramètres** -- Mettez à jour le nom, l'adresse, les coordonnées et l'image de marque de votre église.
- **Applications mobiles** -- Accédez directement à la configuration de l'application mobile.
- **Rôles** -- Gérez les rôles et permissions des utilisateurs de votre équipe.
- **Importer/Exporter** -- Transférez des données entre systèmes à l'aide de l'outil d'import/export.

:::tip
Commencez par configurer le nom de votre église et son image de marque sous **Modifier les paramètres**, puis configurez les [Rôles](./roles-permissions.md) pour inviter les membres de votre équipe avec le bon niveau d'accès.
:::

:::info
Pour savoir comment vos données sont protégées, consultez [Sécurité des données](./data-security.md).
:::
