# Paramètres

<div class="article-intro">

La section Paramètres est l'endroit où vous configurez le compte, l'image de marque et les options administratives de votre église dans B1 Admin. À partir d'ici, vous pouvez gérer tout, du nom de votre église et du sous-domaine aux permissions des utilisateurs et à la configuration de l'application mobile.

</div>

## Ce que vous trouverez ici

La zone Paramètres est organisée dans les sous-sections suivantes:

1. **Settings** -- Configurez les informations de base, l'image de marque et le sous-domaine de votre église. Voir [Paramètres de l'église](./church-settings.md) pour les détails. Pour utiliser votre propre nom de domaine (par exemple votreglise.org), voir [Domaine personnalisé](./custom-domain.md).
2. **Campuses** -- Ajouter et gérer plusieurs emplacements physiques pour votre église. Une fois créés, les campus apparaissent sur les profils des personnes, dans la configuration de l'assistance et dans le tableau de bord Démographie. Accessible sous forme de carte sur la page Paramètres principale plutôt que comme élément de navigation distinct. Voir [Campuses](./campuses.md) pour les détails.
3. **Custom Fields** -- Définissez vos propres champs à suivre sur les personnes (une date, un nombre, une réponse oui/non ou une liste de sélection), puis remplissez-les dans les profils et recherchez-les. Également accessible en tant que carte sur la page Paramètres principale. Voir [Champs personnalisés](./custom-fields.md) pour les détails.
4. **Email Templates** -- Enregistrez le contenu des e-mails réutilisables pour les envoyer manuellement ou à partir d'un flux de travail. Voir [Modèles de courrier électronique](./email-templates.md) pour les détails.
5. **Server Admin** -- Accédez aux outils d'administration avancés pour gérer les paramètres de niveau serveur de votre église.

:::info
La configuration des **applications mobiles** et les **formulaires** ont maintenant leurs propres éléments de navigation de niveau supérieur -- **Mobile** et **Forms** (trouvés sous **People**) -- plutôt que de vivre à l'intérieur de Paramètres. Voir [Paramètres de l'application mobile](./mobile-app.md) et [Création de formulaires](/docs/b1-admin/forms/creating-forms) pour les détails.
:::

## La page Paramètres principale

Lorsque vous ouvrez pour la première fois la page Paramètres, vous verrez le **nom de votre église** et le **sous-domaine** affichés en haut. L'en-tête fournit des boutons d'accès rapide pour les tâches courantes:

- **Email Templates** -- Accédez directement à la gestion des modèles de courrier électronique.
- **Audit Log** -- Afficher un journal des modifications apportées à votre compte d'église.
- **Batches** -- Accédez directement aux lots de dons.
- **Import/Export** -- Transférer des données entre les systèmes à l'aide de l'outil d'import/export.

Sous l'en-tête, ouvrez la section **Church Information** pour modifier le nom de votre église, l'adresse, les informations de contact et l'image de marque -- voir [Paramètres de l'église](./church-settings.md). Pour gérer les rôles des utilisateurs, cliquez sur **Roles** dans la barre de navigation Paramètres -- voir [Rôles et permissions](./roles-permissions.md).

:::tip
Commencez par configurer le nom et l'image de marque de votre église sous **Church Information**, puis configurez [Roles](./roles-permissions.md) pour inviter vos membres de l'équipe avec le niveau d'accès approprié.
:::

:::info
Pour plus d'informations sur la façon dont vos données sont protégées, voir [Sécurité des données](./data-security.md).
:::
