# Paramètres

<div class="article-intro">

La section Paramètres est l'endroit où vous configurez le compte de votre église, l'image de marque et les options administratives dans B1 Admin. À partir de là, vous pouvez gérer tout, du nom de votre église et du sous-domaine aux permissions des utilisateurs et à la configuration de l'application mobile.

</div>

## Ce que vous trouverez ici

La zone Paramètres est organisée dans les sous-sections suivantes :

1. **Paramètres** -- Configurez les informations de base de votre église, l'image de marque et le sous-domaine. Consultez [Paramètres de l'église](./church-settings.md) pour plus de détails.
2. **Campus** -- Ajoutez et gérez plusieurs emplacements physiques pour votre église. Une fois créés, les campus apparaissent sur les profils de personnes, dans la configuration de la présence et dans le tableau de bord Démographie. Consultez [Campus](./campuses.md) pour plus de détails.
3. **Champs personnalisés** -- Définissez vos propres champs à suivre sur les personnes (une date, un nombre, une réponse oui/non ou une liste de choix), puis remplissez-les sur les profils et recherchez-les. Consultez [Champs personnalisés](./custom-fields.md) pour plus de détails.
3. **Applications mobiles** -- Configurez et personnalisez les onglets de navigation qui apparaissent dans l'[PWA B1.church](/docs/b1-church/getting-started/installing-pwa) pour vos membres (les mêmes onglets sont également rendus par l'application native B1 Mobile obsolète). Consultez [Paramètres de l'application mobile](./mobile-app.md) pour plus de détails.
4. **Modèles d'e-mail** -- Enregistrez le contenu d'e-mail réutilisable pour envoyer manuellement ou à partir d'un flux de travail. Consultez [Modèles d'e-mail](./email-templates.md) pour plus de détails.
5. **Admin du serveur** -- Accédez aux outils d'administration avancés pour gérer les paramètres au niveau du serveur de votre église.
6. **Formulaires** -- Créez et gérez des formulaires personnalisés pour collecter des informations de votre congrégation.

## La page Paramètres principale

Quand vous ouvrez d'abord la page Paramètres, vous verrez le **nom de votre église** et le **sous-domaine** affichés en haut. L'en-tête fournit des boutons d'accès rapide pour les tâches courantes :

- **Modifier les paramètres** -- Mettez à jour le nom de votre église, l'adresse, les informations de contact et l'image de marque.
- **Applications mobiles** -- Accédez directement à la configuration de l'application mobile.
- **Rôles** -- Gérez les rôles des utilisateurs et les permissions pour votre équipe.
- **Import/Export** -- Transférez les données entre les systèmes à l'aide de l'outil import/export.

:::tip
Commencez par configurer le nom de votre église et l'image de marque sous **Modifier les paramètres**, puis configurez les [Rôles](./roles-permissions.md) pour inviter vos membres de l'équipe avec le bon niveau d'accès.
:::

:::info
Pour plus d'informations sur la protection de vos données, consultez [Sécurité des données](./data-security.md).
:::
