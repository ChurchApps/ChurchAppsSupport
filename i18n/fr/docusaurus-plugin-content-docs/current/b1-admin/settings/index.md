# Paramètres

<div class="article-intro">

La section Paramètres est l'endroit où vous configurez le compte, la marque et les options administratives de votre église dans B1 Admin. À partir d'ici, vous pouvez gérer tout, du nom de votre église et du sous-domaine aux permissions des utilisateurs et à la configuration de l'application mobile.

</div>

## Ce que vous trouverez ici

La zone Paramètres est organisée dans les sous-sections suivantes :

1. **Paramètres** -- Configurez les informations de base de votre église, la marque, le sous-domaine, la région (format de date et de téléphone), le fournisseur de SMS et le stockage de fichiers. Voir [Paramètres de l'église](./church-settings.md) pour plus de détails. Pour utiliser votre propre nom de domaine (par exemple votreeglise.org), voir [Domaine personnalisé](./custom-domain.md).
2. **Lieux d'implantation** -- Ajoutez et gérez plusieurs emplacements physiques pour votre église. Une fois créés, les lieux d'implantation apparaissent sur les profils des personnes, dans la configuration de la participation et dans le tableau de bord Données démographiques. Accédé en tant que fiche sur la page Paramètres principale plutôt qu'en tant qu'élément de navigation distinct. Voir [Lieux d'implantation](./campuses.md) pour plus de détails.
3. **Champs personnalisés** -- Définissez vos propres champs à suivre sur les personnes (une date, un nombre, une réponse oui/non, ou une liste de choix), puis remplissez-les sur les profils et recherchez-les. Également accédé en tant que fiche sur la page Paramètres principale. Voir [Champs personnalisés](./custom-fields.md) pour plus de détails.
4. **Modèles d'e-mail** -- Enregistrez le contenu d'e-mail réutilisable pour l'envoi manuel ou à partir d'un flux de travail. Voir [Modèles d'e-mail](./email-templates.md) pour plus de détails.
5. **Administration du serveur** -- Accédez aux outils d'administration avancés pour gérer les paramètres au niveau du serveur de votre église.

:::info
La configuration **Applications mobiles** et **Formulaires** ont maintenant leurs propres éléments de navigation de haut niveau -- **Mobile** et **Formulaires** (trouvés sous **Personnes**) -- plutôt que de vivre à l'intérieur des Paramètres. Voir [Paramètres de l'application mobile](./mobile-app.md) et [Création de formulaires](/docs/b1-admin/forms/creating-forms) pour plus de détails.
:::

## La page principale des paramètres

Lorsque vous ouvrez la page Paramètres pour la première fois, vous verrez votre **nom d'église** et votre **sous-domaine** affichés en haut. L'en-tête fournit des boutons d'accès rapide pour les tâches courantes :

- **Modèles d'e-mail** -- Accédez directement à la gestion du modèle d'e-mail.
- **Journal d'audit** -- Affichez un journal des modifications apportées à travers le compte de votre église.
- **Lots** -- Accédez directement aux lots de dons.
- **Importation/Exportation** -- Transférez les données entre les systèmes à l'aide de l'outil d'importation/exportation.

Sous l'en-tête, ouvrez la section **Informations de l'église** pour modifier le nom, l'adresse, les coordonnées de contact et la marque de votre église -- voir [Paramètres de l'église](./church-settings.md). Pour gérer les rôles des utilisateurs, ouvrez le [menu Accès rapide](../introduction.md#getting-around-with-the-jump-menu) et choisissez **Paramètres > Rôles** -- voir [Rôles et autorisations](./roles-permissions.md).

:::tip
Commencez par configurer le nom et la marque de votre église sous **Informations de l'église**, puis configurez les [Rôles](./roles-permissions.md) pour inviter les membres de votre équipe avec le bon niveau d'accès.
:::

:::info
Pour plus d'informations sur la protection de vos données, voir [Sécurité des données](./data-security.md).
:::
