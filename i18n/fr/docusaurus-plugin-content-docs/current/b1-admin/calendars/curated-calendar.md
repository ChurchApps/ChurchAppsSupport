# Calendrier personnalisé

<div class="article-intro">

Un calendrier personnalisé regroupe les événements de plusieurs groupes dans une seule vue de calendrier. C'est idéal pour créer un calendrier de toute l'église qui présente tout ce qui se passe dans l'ensemble de vos ministères et groupes, au même endroit.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Configurez les [groupes](../groups/creating-groups.md) dont vous souhaitez inclure les événements
- Assurez-vous que les responsables de groupe ont ajouté des événements à leurs groupes respectifs
- Familiarisez-vous avec les bases de [Créer des calendriers](creating-calendars)

</div>

## Créer un calendrier personnalisé

1. Dans B1 Admin, ouvrez le [menu Accès rapide](../introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche), développez **Calendriers**, et cliquez sur **Calendriers**.
2. Cliquez sur **Ajouter un calendrier** pour créer un nouveau calendrier personnalisé.
3. Donnez un **nom** à votre calendrier (par exemple, « Événements de l'église » ou « Cette semaine à notre église »).
4. Cliquez sur **Créer** pour l'enregistrer.

## Ajouter des groupes à votre calendrier

1. Cliquez sur **Gérer les événements** de votre nouveau calendrier pour l'ouvrir.
2. Cliquez sur **Ajouter un groupe** au-dessus du calendrier. Les groupes que vous ajoutez apparaissent dans la liste **Groupes dans le calendrier** à gauche de la page.
3. Sélectionnez un groupe dans la liste déroulante. Chaque groupe de votre église est listé, y compris les groupes dont vous ne faites pas partie.
4. Choisissez d'ajouter **tous les événements** de ce groupe ou seulement **certains événements**.
5. Cliquez sur **Enregistrer**.
6. Répétez l'opération pour ajouter autant de groupes que vous le souhaitez.

Chaque événement n'est listé qu'une seule fois, même si vous l'avez ajouté seul et aussi ajouté son groupe entier. La liste **Groupes dans le calendrier** n'affiche que les groupes ajoutés avec tous leurs événements.

Pour retirer un élément du calendrier, cliquez sur l'événement et choisissez **Retirer du calendrier**. L'événement reste dans son groupe. S'il provient d'un groupe entier, le retirer supprime tous les événements de ce groupe du calendrier.

:::tip
Ajoutez tous vos groupes de ministère actifs pour créer un calendrier complet qui donne à votre communauté une vue d'ensemble de ce qui se passe dans votre église chaque semaine.
:::

## Partager votre calendrier

Une fois votre calendrier personnalisé configuré, vous pouvez le partager de plusieurs façons :

- **Intégrer sur votre site web** -- Ajoutez un élément **Calendrier** à une page pour afficher le calendrier sous forme de grille mensuelle ou de vignettes d'événements à venir, éventuellement limité aux événements portant une étiquette. Chaque événement renvoie vers sa propre page de votre site. Consultez [Utiliser l'élément Calendrier](../website/page-editor.md#using-the-calendar-element).
- **S'abonner via ICS** -- Cliquez sur **S'abonner** pour copier le lien ICS. Votre communauté peut coller ce lien dans Google Agenda, Calendrier Apple, Outlook ou toute autre application de calendrier pour rester synchronisée.
- **Télécharger le fichier ICS** -- Téléchargez le fichier du calendrier pour l'importer dans une application de calendrier.

:::info
Lorsque les responsables de groupe ajoutent de nouveaux événements à leurs [groupes](../groups/creating-groups.md), ces événements apparaissent automatiquement dans votre calendrier personnalisé. Vous n'avez pas besoin de mettre à jour le calendrier manuellement à chaque ajout.
:::

:::note Événements privés
Seuls les événements **publics** apparaissent dans le calendrier personnalisé de votre site web et dans son abonnement ICS. Dans B1 Admin, le personnel autorisé à modifier le contenu voit aussi les événements **privés** du groupe dans le calendrier personnalisé, afin de pouvoir vérifier le planning complet pendant que vous composez le calendrier.
:::
