# Calendrier organisé

<div class="article-intro">

Un calendrier organisé regroupe les événements de plusieurs groupes dans une seule vue de calendrier. C'est idéal pour créer un calendrier à l'échelle de toute l'église, qui présente tout ce qui se passe dans l'ensemble de vos ministères et groupes à un seul endroit.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Configurez les [groupes](../groups/creating-groups.md) dont vous souhaitez inclure les événements
- Assurez-vous que les responsables de groupe ont ajouté des événements à leurs groupes respectifs
- Familiarisez-vous avec les bases de la [création de calendriers](./creating-calendars.md)

</div>

## Créer un calendrier organisé {#creating-a-curated-calendar}

1. Dans B1 Admin, ouvrez le [menu Jump](../introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche), développez **Calendriers** et cliquez sur **Calendriers**.
2. Cliquez sur **Ajouter un calendrier** pour créer un nouveau calendrier organisé.
3. Donnez à votre calendrier un **Nom du calendrier** (par exemple « Événements de l'église » ou « Cette semaine à notre église »).
4. Cliquez sur **Créer** pour l'enregistrer.

## Ajouter des groupes à votre calendrier {#adding-groups-to-your-calendar}

1. Cliquez sur le nom de votre nouveau calendrier (ou sur **Gérer les événements** sur sa ligne) pour l'ouvrir.
2. Cliquez sur **Ajouter un groupe** au-dessus du calendrier. Les groupes que vous ajoutez apparaissent dans la liste **Groupes dans le calendrier** à gauche de la page.
3. Choisissez un groupe dans **Sélectionner un groupe**. Tous les groupes de votre église sont listés, y compris ceux dont vous ne faites pas partie.
4. Choisissez **Ajouter tous les événements du groupe**, ou **Ajouter des événements précis** puis cliquez sur les événements souhaités.
5. Cliquez sur **Enregistrer**.
6. Répétez l'opération pour ajouter autant de groupes que vous le souhaitez.

Chaque événement n'est listé qu'une fois, même si vous l'avez ajouté seul et aussi ajouté tout son groupe. La liste **Groupes dans le calendrier** n'affiche que les groupes ajoutés avec tous leurs événements.

Pour retirer un élément du calendrier, cliquez sur l'événement et choisissez **Retirer du calendrier**. L'événement reste dans son groupe. Si l'événement provient d'un groupe entier, son retrait supprime tous les événements de ce groupe de ce calendrier.

:::tip
Ajoutez tous vos groupes de ministère actifs pour créer un calendrier complet qui donne à votre communauté une vue d'ensemble de ce qui se passe dans votre église chaque semaine.
:::

## Partager votre calendrier {#sharing-your-calendar}

Une fois votre calendrier organisé configuré, vous pouvez le partager de plusieurs façons :

- **Intégrer sur votre site web** -- Ajoutez un élément **Calendrier** à une page pour afficher le calendrier sous forme de grille mensuelle ou de vignettes d'événements à venir, éventuellement limitées aux événements portant une seule étiquette. Chaque événement renvoie vers sa propre page sur votre site. Voir [Utiliser l'élément Calendrier](../website/page-editor.md#using-the-calendar-element).
- **S'abonner via ICS** -- Cliquez sur **S'abonner** au-dessus du calendrier et choisissez **Copier le lien ICS**. Votre communauté peut coller ce lien dans Google Agenda, Calendrier Apple, Outlook ou toute autre application de calendrier pour rester synchronisée.
- **Télécharger le fichier ICS** -- Cliquez sur **S'abonner** et choisissez **Télécharger le fichier ICS** pour importer le calendrier dans une application de calendrier.
- **Imprimer** -- Cliquez sur **Imprimer** sur la page du calendrier pour obtenir une version imprimable.

:::info
Lorsque les responsables de groupe ajoutent de nouveaux événements à leurs [groupes](../groups/creating-groups.md), ces événements apparaissent automatiquement dans votre calendrier organisé. Vous n'avez pas besoin de mettre à jour manuellement le calendrier organisé à chaque ajout d'événement.
:::

:::note Événements privés
Seuls les événements **publics** apparaissent sur le calendrier organisé de votre site web et dans son abonnement ICS. Dans B1 Admin, le personnel autorisé à modifier le contenu voit aussi les événements **privés** du groupe dans le calendrier organisé, afin de pouvoir vérifier le programme complet pendant qu'il prépare le calendrier.
:::
