# Salles, ressources et planification

<div class="article-intro">

Les salles et ressources vous permettent de suivre les espaces réservables et les équipements de votre église. Quand un groupe ou une équipe souhaite utiliser une salle ou emprunter une ressource pour un événement, il peut la demander via B1 — et vous pouvez approuver ou rejeter ces demandes pour éviter les réservations en double.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez avoir accès administratif à la section Calendriers dans B1 Admin
- Configurez les [groupes](../groups/creating-groups) dont les membres soumettront les demandes de réservation

</div>

## Ouverture des salles et ressources

Dans B1 Admin, ouvrez le [menu Accès rapide](../introduction.md#getting-around-with-the-jump-menu) (la barre de recherche en haut à gauche), développez **Calendriers**, et cliquez sur **Salles et ressources**. La page a quatre onglets : **Salles**, **Ressources**, **Blocages**, et **Modèles**.

## Salles

Les salles sont des espaces physiques qui peuvent être réservés avec des événements de calendrier — un sanctuaire, une salle de réception, une salle de classe, etc.

### Ajouter une salle

1. Sous l'onglet **Salles**, cliquez sur **Ajouter une salle**.
2. Entrez un **nom** pour la salle.
3. Optionnellement définissez une **capacité** (nombre maximum de personnes).
4. Définissez un **groupe d'approbation** — quand un groupe demande cette salle, les responsables du groupe choisi sont notifiés et doivent approuver la réservation. Laissez vide si aucune approbation n'est nécessaire.
5. Cliquez sur **Enregistrer**.

### Modification ou suppression d'une salle

Cliquez sur l'icône de modification en regard de n'importe quelle salle, effectuez vos modifications, et cliquez sur **Enregistrer**. Utilisez **Supprimer** pour supprimer définitivement une salle.

## Ressources

Les ressources sont des articles qui peuvent être réservés avec un événement — équipement AV, projecteurs, chaises, un fourgon, etc.

### Ajouter une ressource

1. Cliquez sur l'onglet **Ressources**, puis sur **Ajouter une ressource**.
2. Entrez un **nom** et optionnellement une **description**.
3. Définissez un **groupe d'approbation** si quelqu'un doit approuver les emprunts de ressources.
4. Cliquez sur **Enregistrer**.

## Blocages

Les blocages empêchent les salles ou ressources d'être réservées pendant certaines périodes — pour les rénovations, les périodes réservées, ou la maintenance.

### Ajouter un blocage

1. Cliquez sur l'onglet **Blocages**, puis sur **Ajouter un blocage**.
2. Choisissez de bloquer une **Salle**, une **Ressource**, ou toutes les salles et ressources.
3. Définissez la **date/heure** de **début** et de **fin** du blocage.
4. Optionnellement ajoutez une note de **raison**.
5. Cliquez sur **Enregistrer**.

## Modèles d'événements

Les modèles vous permettent d'enregistrer une configuration d'événement réutilisable — titre, description, et groupes associés — afin que les événements récurrents puissent être créés de manière cohérente.

### Ajouter un modèle

1. Cliquez sur l'onglet **Modèles**, puis sur **Ajouter un modèle**.
2. Entrez un **nom** pour le modèle.
3. Optionnellement reliez un **groupe** de sorte que l'événement soit automatiquement connecté à ce groupe quand il est créé à partir du modèle.
4. Cliquez sur **Enregistrer**.

Quand créer un nouvel événement, le personnel peut choisir un modèle existant pour pré-remplir les détails de l'événement.
