# Enregistrement des donations

<div class="article-intro">

L'enregistrement des donations dans B1 Admin se fait via le système Lots. Vous créez un lot pour représenter une collecte (comme une offrande du dimanche), puis vous ajoutez des donations individuelles à ce lot. Cela maintient vos dossiers de donation organisés et faciles à réconcilier.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Configurez vos [fonds](funds.md) afin que vous puissiez assigner les donations aux bonnes catégories
- Créez un [lot](batches.md) pour contenir les donations que vous êtes sur le point d'entrer
- Assurez-vous que les donateurs se trouvent dans votre [répertoire des personnes](../people/adding-people.md) afin que vous puissiez les rechercher lors de l'entrée de cadeaux

</div>

## Création d'un lot et ajout de donations

1. Dans **B1 Admin**, ouvrez le **menu de section** dans le coin supérieur gauche et choisissez **Donations**, puis cliquez sur **Lots**.
2. Cliquez sur **Ajouter un lot**.
3. Entrez un nom pour le lot (par exemple, « Offrande du dimanche - 5 janvier ») et sélectionnez la date. Cliquez sur **Enregistrer**.
4. Votre nouveau lot apparaît dans la liste affichant zéro donation et \,00.
5. Cliquez sur le **nom du lot** pour l'ouvrir.

## Saisie de donations individuelles

1. Dans la page de détail du lot, tapez le nom du donateur dans le **champ de recherche** pour le trouver.
2. Après avoir sélectionné une personne, le formulaire d'entrée de donation apparaît avec des champs pour **Date**, **Méthode de paiement**, **Fonds**, **Montant** et **Numéro de chèque**.
3. Remplissez les détails et cliquez sur **Ajouter une donation**.
4. La donation est ajoutée au tableau ci-dessous, et le formulaire se réinitialise afin que vous puissiez entrer la suivante.

:::tip
Vous pouvez entrer rapidement plusieurs donations à la suite sans quitter la page du lot. Le formulaire se réinitialise après chaque entrée afin que vous puissiez passer par une pile de chèques ou d'enveloppes efficacement.
:::

## Division d'une donation sur plusieurs fonds

Parfois, un seul donateur donne à plus d'un fonds dans une seule transaction. Pour gérer cela :

1. Cliquez sur le bouton **Modifier** sur la ligne de donation.
2. Dans le formulaire d'édition, ajoutez des montants à différents fonds. Le total sera automatiquement calculé à partir des montants individuels du fonds.
3. Cliquez sur **Enregistrer** pour mettre à jour la donation.

:::info
La division des donations sur les fonds est courante quand un donateur écrit un seul chèque désigné à plusieurs fins, comme le fonds général et les missions.
:::

## Modification ou suppression de donations

Pour modifier une donation, cliquez sur le bouton **Modifier** sur sa ligne dans le lot. Vous pouvez modifier la date, le montant, le fonds, la méthode de paiement ou tout autre détail. Cliquez sur **Enregistrer** lorsque vous avez terminé.

:::tip
L'en-tête de la page du lot se met à jour automatiquement pour afficher le nombre total de donations et le montant en dollars combiné à mesure que vous ajoutez ou modifiez les entrées. Utilisez cela pour réconcilier avec votre bon de dépôt.
:::

## Étapes suivantes

- Vérifiez vos entrées en utilisant [Rapports de donation](donation-reports.md) pour vérifier la précision
- En fin d'année, générez [Relevés de donation](giving-statements.md) pour vos donateurs
