# Enregistrement des donations

<div class="article-intro">

L'enregistrement des donations dans B1 Admin se fait via le système de lots. Vous créez un lot pour représenter une collecte (comme une offrande du dimanche), puis vous ajoutez les donations individuelles à ce lot. Cela garde vos dossiers de dons organisés et faciles à réconcilier.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Configurez vos [fonds](funds.md) pour pouvoir assigner les donations aux bonnes catégories
- Créez un [lot](batches.md) pour contenir les donations que vous êtes sur le point d'entrer
- Assurez-vous que les donateurs sont dans votre [répertoire des personnes](../people/adding-people.md) pour que vous puissiez les rechercher lors de l'entrée des dons

</div>

## Création d'un lot et ajout de donations

1. Dans **B1 Admin**, ouvrez le **menu de section** dans le coin supérieur gauche et choisissez **Donations**, puis cliquez sur **Lots**.
2. Cliquez sur **Ajouter un lot**.
3. Entrez un nom pour le lot (par exemple, « Offrande du dimanche - 5 jan ») et sélectionnez la date. Cliquez sur **Enregistrer**.
4. Votre nouveau lot apparaît dans la liste montrant zéro donation et 0,00 $.
5. Cliquez sur le **nom du lot** pour l'ouvrir.

## Entrée des donations individuelles

1. Sur la page de détails du lot, tapez le nom du donateur dans le **champ de recherche** pour le trouver.
2. Après avoir sélectionné une personne, le formulaire d'entrée de donation apparaît avec des champs pour **Date**, **Mode de paiement**, **Fonds**, **Montant** et **Numéro de chèque**.
3. Remplissez les détails et cliquez sur **Ajouter une donation**.
4. La donation est ajoutée au tableau ci-dessous, et le formulaire se réinitialise pour que vous puissiez en saisir le suivant.

:::tip
Vous pouvez rapidement entrer plusieurs donations d'affilée sans quitter la page du lot. Le formulaire se réinitialise après chaque entrée pour que vous puissiez parcourir rapidement une pile de chèques ou d'enveloppes.
:::

## Répartition d'une donation sur plusieurs fonds

Parfois, un seul donateur donne à plus d'un fonds dans une seule transaction. Pour gérer cela :

1. Cliquez sur le bouton **Modifier** sur la ligne de donation.
2. Dans le formulaire d'édition, ajoutez des montants à différents fonds. Le total se calculera automatiquement à partir des montants des fonds individuels.
3. Cliquez sur **Enregistrer** pour mettre à jour la donation.

:::info
Répartir les donations sur plusieurs fonds est courant quand un donateur écrit un seul chèque destiné à plusieurs fins, comme le Fonds général et les missions.
:::

## Édition ou suppression de donations

Pour modifier une donation, cliquez sur le bouton **Modifier** sur sa ligne dans le lot. Vous pouvez changer la date, le montant, le fonds, le mode de paiement ou tout autre détail. Cliquez sur **Enregistrer** quand vous avez terminé.

:::tip
L'en-tête de la page du lot se met à jour automatiquement pour afficher le nombre total de donations et le montant en dollars combiné à mesure que vous ajoutez ou modifiez des entrées. Utilisez ceci pour réconcilier avec votre bordereau de dépôt.
:::
