# Donations

<div class="article-intro">

La section Donations dans B1 Admin fournit tout ce dont vous avez besoin pour gérer les dons de votre église. De l'enregistrement des offrandes hebdomadaires à la génération des déclarations fiscales de fin d'année, tous vos outils de donation sont organisés en un seul endroit pour que vous puissiez rester maître de vos finances d'église.

</div>

## Sous-sections

Vous trouverez les pages suivantes dans la section Donations :

### Résumé

La page **Résumé** vous donne un aperçu visuel de toute l'activité de dons. Elle affiche des graphiques et des rapports filtrés pour que vous puissiez rapidement voir les tendances de donations dans votre église. Consultez [Rapports de donations](donation-reports.md) pour plus de détails sur l'utilisation des outils de résumé et de rapport.

### Lots

Les **[Lots](batches.md)** vous permettent de regrouper les donations ensemble -- par exemple, tous les chèques et l'argent liquide collectés lors d'une offrande du dimanche. Chaque lot suit son nombre de donations et son montant total pour une réconciliation facile.

### Fonds

Les **[Fonds](funds.md)** catégorisent vos donations par objet. Les exemples courants incluent le Fonds général, le Fonds de construction et les missions. Vous pouvez marquer chaque fonds comme déductible d'impôts ou non.

### Relevés

La page **[Relevés](giving-statements.md)** génère les relevés de dons de fin d'année pour vos donateurs. Vous pouvez télécharger des fichiers CSV individuels ou imprimer tous les relevés à la fois.

### Import Stripe

Si vous acceptez les donations en ligne via Stripe, l'outil **[Import Stripe](stripe-import.md)** vous permet d'extraire ces transactions dans B1 Admin pour que tout soit en un seul endroit.

## Dons en ligne

B1 Admin s'intègre à **Stripe** et **PayPal** pour accepter les donations en ligne. Une fois configurés, les membres peuvent donner via votre site B1.church et ces donations apparaissent automatiquement dans vos dossiers. Consultez [Configuration des dons en ligne](online-giving-setup.md) pour commencer.

:::tip
Si vous débutez avec les donations dans B1 Admin, commencez par [configurer vos fonds](funds.md), puis [créez votre premier lot](batches.md) et [enregistrez les donations](recording-donations.md) dedans.
:::
