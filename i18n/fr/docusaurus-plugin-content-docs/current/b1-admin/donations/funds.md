# Gestion des fonds

<div class="article-intro">

Les fonds vous permettent de classer les dons selon leur objectif afin de suivre le montant que votre église reçoit pour chaque domaine de ministère. Les fonds courants comprennent le Fonds général, le Fonds de construction, les Missions et le Ministère jeunesse, mais vous pouvez en créer autant que nécessaire.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous devez avoir accès à la section **Dons** de B1 Admin
- Décidez quelles catégories de dons votre église doit utiliser et si chacune doit être déductible d'impôt

</div>

## La page Fonds {#the-funds-page}

Accédez à **Dons > Fonds** pour voir la liste de tous vos fonds. Chaque ligne affiche le nom du fonds et son **Statut fiscal** (déductible ou non déductible d'impôt), qui détermine si les dons versés à ce fonds apparaissent sur les [relevés de dons](giving-statements.md) de fin d'année.

## Créer un nouveau fonds {#creating-a-new-fund}

1. Cliquez sur **Ajouter un fonds** en haut de la page.
2. Saisissez un nom pour le fonds (par exemple « Fonds de construction »).
3. Cochez la case **Déductible d'impôt** si les dons versés à ce fonds doivent figurer sur les relevés de dons. Les dons versés à des fonds non déductibles restent tout de même listés dans les dons du donateur sur sa fiche personne.
4. Laissez **Visible pour les donateurs** cochée pour afficher le fonds sur les formulaires de dons publics et des membres, ou décochez-la pour masquer le fonds aux donateurs tout en continuant de l'utiliser pour les dons saisis manuellement.
5. Cliquez sur **Enregistrer**.

Le nouveau fonds apparaît immédiatement dans votre liste et est disponible lors de la saisie des dons.

## Modifier et supprimer des fonds {#editing-and-deleting-funds}

- Pour modifier un fonds, cliquez sur **Modifier** sur sa ligne. Vous pouvez changer le nom, activer ou désactiver le paramètre déductible d'impôt, ou activer ou désactiver **Visible pour les donateurs** pour l'afficher ou le masquer sur les formulaires de dons.
- Pour supprimer un fonds, ouvrez le formulaire de modification, cliquez sur **Supprimer**, puis confirmez.
- Pour partager un lien qui ouvre votre page de dons avec ce fonds déjà sélectionné, cliquez sur **Lien de don** sur sa ligne (voir [Liens avec un fonds et un montant prédéfinis](online-giving-setup.md#links-with-a-preset-fund-and-amount)).

:::warning
La suppression d'un fonds ne retire pas les dons qui lui avaient été précédemment attribués. Ces enregistrements de dons restent dans le système, mais le fonds ne sera plus disponible pour de nouveaux dons.
:::

:::info
Les fonds masqués aux donateurs affichent un badge **Masqué** à côté de leur nom dans cette liste. Les fonds masqués restent utilisables pour les dons saisis manuellement dans B1 Admin -- ils n'apparaissent simplement pas comme option sur les formulaires de dons publics ou des membres.
:::

## Consulter le détail d'un fonds {#viewing-fund-details}

Cliquez sur le **nom d'un fonds** pour ouvrir sa page de détail. Cette page affiche :

- **Résumé** -- une ligne sous le titre de la page indiquant le nombre de dons, le nombre de donateurs et le montant total pour la période affichée
- **Boutons d'année** -- la page s'ouvre sur l'année en cours ; cliquez sur une autre année pour afficher cette année civile
- **Filtre par plage de dates** -- définissez une **Date de début** et une **Date de fin**, puis cliquez sur **Filtrer** pour restreindre les résultats à une période donnée
- **Historique des dons** -- une liste des dons versés à ce fonds avec la date, le lot, le donateur et le montant. Cliquez sur **Exporter** au-dessus de la liste pour la télécharger au format CSV.

Cette vue est utile lorsque vous devez faire un rapport sur une initiative de dons précise ou vérifier la progression vers un objectif de collecte de fonds.

## Tri et exportation {#sorting-and-exporting}

- Utilisez les en-têtes de colonnes pour trier les fonds par nom.
- Cliquez sur **Exporter** en haut de la page pour télécharger votre liste de fonds sous forme de tableur (CSV).

:::tip
Configurez vos fonds avant de commencer à [enregistrer des dons](recording-donations.md). Avoir tous les fonds en place dès le départ garantit que les dons sont correctement classés.
:::

## Étapes suivantes {#next-steps}

Une fois vos fonds configurés, vous pouvez les attribuer aux dons lors de [l'enregistrement des dons](recording-donations.md) dans un lot. Assurez-vous de marquer les fonds appropriés comme déductibles d'impôt avant de générer les [relevés de dons](giving-statements.md).
