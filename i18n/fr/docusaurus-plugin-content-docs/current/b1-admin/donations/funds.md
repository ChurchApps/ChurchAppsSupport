# Gérer les fonds

<div class="article-intro">

Les fonds vous permettent de classer les dons selon leur objectif afin de suivre le montant que reçoit votre église pour chaque domaine du ministère. Parmi les fonds courants figurent le Fonds général, le Fonds de construction, les Missions et le Ministère des jeunes, mais vous pouvez en créer autant que nécessaire.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Vous aurez besoin d'un accès à la section **Dons** de B1 Admin
- Déterminez quelles catégories de dons votre église doit utiliser et si chacune doit être déductible des impôts

</div>

## La page Fonds

Accédez à **Dons > Fonds** pour voir la liste de tous vos fonds. Chaque ligne affiche le nom du fonds et son **Statut fiscal** (déductible ou non déductible des impôts), qui détermine si les dons versés à ce fond figurent sur les [relevés de dons](giving-statements.md) de fin d'année.

## Créer un nouveau fonds

1. Cliquez sur **Ajouter un fonds** en haut de la page.
2. Saisissez un nom pour le fonds (par exemple, "Fonds de construction").
3. Cochez la case **Déductible des impôts** si les dons à ce fonds doivent figurer sur les relevés de dons. Les dons aux fonds non déductibles restent tout de même listés dans les dons du donateur, sur sa fiche personne.
4. Laissez **Visible pour les donateurs** coché pour afficher le fonds sur les formulaires de don publics et destinés aux membres, ou décochez-le pour le masquer aux donateurs tout en l'utilisant pour les dons enregistrés manuellement.
5. Cliquez sur **Enregistrer**.

Le nouveau fonds apparaît immédiatement dans votre liste et est disponible lors de la saisie des dons.

## Modifier et supprimer des fonds

- Pour modifier un fonds, cliquez sur **Modifier** sur sa ligne. Vous pouvez changer le nom, activer ou désactiver le paramètre déductible des impôts, ou activer ou désactiver **Visible pour les donateurs** pour l'afficher ou le masquer sur les formulaires de don.
- Pour supprimer un fonds, ouvrez le formulaire de modification et cliquez sur **Supprimer**.

:::warning
La suppression d'un fonds ne supprime pas les dons qui lui étaient précédemment affectés. Ces enregistrements de dons restent dans le système, mais le fonds ne sera plus disponible pour de nouveaux dons.
:::

:::info
Les fonds masqués aux donateurs affichent un badge **Masqué** à côté de leur nom dans cette liste. Les fonds masqués fonctionnent toujours pour les dons saisis manuellement dans B1 Admin -- ils n'apparaissent simplement pas comme option sur les formulaires de don publics ou destinés aux membres.
:::

## Consulter le détail d'un fonds

Cliquez sur un **nom de fonds** pour ouvrir sa page de détail. Cette page affiche :

- **Résumé** -- une ligne sous le titre de la page avec le nombre de dons, le nombre de donateurs et le montant total
- **Filtre par plage de dates** -- définissez une **Date de début** et une **Date de fin**, puis cliquez sur **Filtrer** pour restreindre les résultats à une période donnée
- **Historique des dons** -- une liste des dons à ce fonds avec la date, le lot, le donateur et le montant. Cliquez sur **Exporter** au-dessus de la liste pour la télécharger au format CSV.

Cette vue est utile lorsque vous devez faire un rapport sur une initiative de dons précise ou vérifier la progression vers un objectif de collecte de fonds.

## Tri et exportation

- Utilisez les en-têtes de colonnes pour trier les fonds par nom.
- Cliquez sur **Exporter** en haut de la page pour télécharger la liste de vos fonds sous forme de tableur (CSV).

:::tip
Configurez vos fonds avant de commencer à [enregistrer des dons](recording-donations.md). Disposer de tous les fonds dès le départ garantit que les dons sont correctement classés dès le début.
:::

## Étapes suivantes

Une fois vos fonds configurés, vous pouvez les affecter aux dons lors de [l'enregistrement des dons](recording-donations.md) par lot. Assurez-vous de marquer les fonds appropriés comme déductibles des impôts avant de générer des [relevés de dons](giving-statements.md).
