# Tableau de bord {#dashboard}

<div class="article-intro">

Le tableau de bord est votre écran d'accueil dans B1 Mobile. Il vous donne un accès rapide aux fonctionnalités proposées par votre église, organisées selon votre utilisation de l'application. La disposition s'adapte au fil du temps pour mettre en avant les fonctionnalités que vous utilisez le plus.

</div>

:::info Cette page décrit l'application native dépréciée
L'écran Accueil de l'application B1.church (`/mobile`), qui remplace B1 Mobile, fonctionne différemment : il affiche des sections telles que votre dernier sermon, le service à venir, vos groupes, les événements à venir et les dons, ainsi que des vignettes photo pour les onglets auxquels votre église a attribué une photo. Voir [Navigation dans B1App](../../b1-church/getting-started/navigating.md#home). Les administrateurs peuvent choisir la disposition de ces vignettes photo dans [Paramètres de l'application mobile](../../b1-admin/settings/mobile-app.md#home-screen-tiles).
:::

## Section d'accueil {#welcome-section}

En haut du tableau de bord, vous voyez un message de bienvenue accompagné du logo de votre église (ou de son nom si aucun logo n'est défini) et d'un slogan « restez connecté ». Cette section confirme l'église que vous consultez actuellement.

## Liens en vedette {#featured-links}

Sous la section d'accueil, votre fonctionnalité la plus consultée apparaît sous forme de grande **carte principale**, avec une image de fond et le nom de la fonctionnalité. C'est la fonctionnalité que vous utilisez le plus souvent, placée en haut pour un accès d'une seule pression.

## Cartes en vedette {#featured-cards}

Sous la carte principale, vous voyez jusqu'à deux **cartes en vedette** affichées côte à côte. Elles correspondent à vos deuxième et troisième fonctionnalités les plus consultées. Chaque carte affiche une image de fond et le nom de la fonctionnalité. Appuyez sur l'une ou l'autre carte pour accéder directement à cette fonctionnalité.

## Actions rapides {#quick-actions}

Les autres fonctionnalités apparaissent dans une grille **Actions rapides** sous les cartes en vedette. Chaque élément affiche une icône et un libellé. Il s'agit de tous les autres liens de navigation configurés par votre église, qui vous donnent accès à tout, des [groupes](../groups/) et des [dons](../giving/) jusqu'à l'[enregistrement](../checkin/), aux [sermons](../content/sermons.md) et plus encore.

## Comment la disposition s'adapte {#how-the-layout-adapts}

La disposition du tableau de bord est personnalisée en fonction de vos habitudes d'utilisation. Chaque fois que vous appuyez sur une fonctionnalité, l'application enregistre la fréquence de votre visite. Les fonctionnalités que vous utilisez plus souvent remontent en haut du tableau de bord :

- Votre fonctionnalité la **plus consultée** devient la carte principale.
- Vos **deuxième et troisième fonctionnalités les plus consultées** deviennent les cartes en vedette.
- **Toutes les autres** apparaissent dans la grille Actions rapides.

Si vous n'avez pas encore utilisé l'application, les fonctionnalités apparaissent dans l'ordre par défaut configuré par votre église. Au fil du temps, le tableau de bord se réorganise pour correspondre à vos habitudes.

:::info
Les fonctionnalités disponibles sur votre tableau de bord sont configurées par l'administrateur de votre église via [B1 Admin](../../b1-admin/). Si vous ne voyez pas une fonctionnalité attendue, contactez le secrétariat de votre église.
:::

## Actualiser le tableau de bord {#refreshing-the-dashboard}

Faites glisser vers le bas sur le tableau de bord pour l'actualiser. Cela recharge les liens et le contenu de votre église afin de vous assurer que vous voyez les informations les plus récentes.

## Navigation {#navigation}

Depuis le tableau de bord, vous pouvez accéder à toutes les parties de l'application :

- Appuyez sur l'**icône hamburger** (trois lignes horizontales) dans le coin supérieur gauche pour ouvrir le menu latéral avec toutes les options de navigation.
- Appuyez sur l'**icône cloche** dans le coin supérieur droit pour consulter vos [notifications](../community/notifications.md).
- Appuyez sur n'importe quelle carte ou élément d'action rapide pour accéder directement à cette fonctionnalité.
