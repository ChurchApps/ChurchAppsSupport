# Tableau de bord

<div class="article-intro">

Le tableau de bord est votre écran d'accueil dans B1 Mobile. Il vous donne un accès rapide aux fonctionnalités proposées par votre église, organisées selon la façon dont vous utilisez l'application. La disposition s'adapte au fil du temps pour mettre en avant les fonctionnalités que vous utilisez le plus.

</div>

:::info Cette page décrit l'application native dépréciée
L'écran Accueil de l'application B1.church (`/mobile`), qui remplace B1 Mobile, fonctionne différemment : il affiche des sections telles que votre dernière prédication, les services à venir, vos groupes, les événements à venir et les dons, ainsi que des vignettes photo pour les onglets pour lesquels votre église a fourni une photo. Voir [Navigation dans B1App](../../b1-church/getting-started/navigating.md#home). Les administrateurs peuvent choisir la disposition de ces vignettes photo dans les [Paramètres de l'application mobile](../../b1-admin/settings/mobile-app.md#home-screen-tiles).
:::

## Section d'accueil

En haut du tableau de bord, vous voyez un message de bienvenue avec le logo de votre église (ou son nom si aucun logo n'est défini) et une formule « restez connectés ». Cette section confirme l'église que vous consultez actuellement.

## Liens en vedette

Sous la section d'accueil, la fonctionnalité que vous utilisez le plus apparaît sous forme de grande **carte principale** avec une image de fond et le nom de la fonctionnalité. C'est la fonctionnalité que vous utilisez le plus souvent, mise en avant pour un accès en une seule touche.

## Cartes en vedette

Sous la carte principale, vous verrez jusqu'à deux **cartes en vedette** côte à côte. Elles représentent vos deuxième et troisième fonctionnalités les plus consultées. Chaque carte affiche une image de fond et le nom de la fonctionnalité. Touchez l'une ou l'autre carte pour accéder directement à cette fonctionnalité.

## Actions rapides

Les autres fonctionnalités apparaissent dans une grille **Actions rapides** sous les cartes en vedette. Chaque élément affiche une icône et un libellé. Il s'agit de tous les autres liens de navigation configurés par votre église, qui vous donnent accès à tout, des [groupes](../groups/) et [dons](../giving/) jusqu'au [pointage](../checkin/), aux [prédications](../content/sermons.md) et plus encore.

## Comment la disposition s'adapte

La disposition du tableau de bord est personnalisée selon vos habitudes d'utilisation. À chaque fois que vous touchez une fonctionnalité, l'application enregistre la fréquence de vos visites. Les fonctionnalités que vous utilisez le plus souvent remontent en haut du tableau de bord :

- Votre fonctionnalité **la plus consultée** devient la carte principale.
- Vos **deuxième et troisième fonctionnalités les plus consultées** deviennent les cartes en vedette.
- **Toutes les autres** apparaissent dans la grille Actions rapides.

Si vous n'avez pas encore utilisé l'application, les fonctionnalités apparaissent dans l'ordre par défaut configuré par votre église. Au fil du temps, le tableau de bord se réorganise pour correspondre à vos habitudes.

:::info
Les fonctionnalités disponibles sur votre tableau de bord sont configurées par l'administrateur de votre église via [B1 Admin](../../b1-admin/). Si vous ne voyez pas une fonctionnalité que vous attendez, contactez le secrétariat de votre église.
:::

## Actualiser le tableau de bord

Tirez vers le bas sur le tableau de bord pour l'actualiser. Cela recharge les liens et le contenu de votre église afin que vous voyiez les informations les plus récentes.

## Navigation

Depuis le tableau de bord, vous pouvez accéder à toutes les parties de l'application :

- Touchez l'**icône hamburger** (trois lignes horizontales) en haut à gauche pour ouvrir le menu latéral avec toutes les options de navigation.
- Touchez l'**icône cloche** en haut à droite pour consulter vos [notifications](../community/notifications.md).
- Touchez n'importe quelle carte ou action rapide pour accéder directement à cette fonctionnalité.
