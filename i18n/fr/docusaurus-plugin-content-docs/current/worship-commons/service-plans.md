# Plans de service WorshipCommons

<div class="article-intro">

Un plan de service sur WorshipCommons est une liste de chants pour le dimanche. Placez les chants dans l'ordre, choisissez la tonalité, le capodastre et les sections pour chacun, puis partagez un seul lien avec votre groupe de musiciens. Depuis le plan, vous pouvez ouvrir une vue scène pour un pupitre, imprimer un livret ou exporter l'ensemble du set vers votre logiciel de présentation.

</div>

:::info
Les plans de service sont enregistrés dans votre navigateur web, et non dans votre compte. Vous n'avez pas besoin de vous connecter pour les utiliser. Un lien de partage contient l'ensemble du set : enregistrez-le si vous changez d'appareil. Si votre église planifie ses services dans B1 Admin, consultez plutôt [Plans](../b1-admin/serving/plans.md).
:::

## Créer un plan de service

1. Cliquez sur **Plans de service** dans le menu supérieur.
2. Saisissez un nom, par exemple « Dimanche 14 septembre » ou « Soirée jeunes », puis cliquez sur **Créer un plan de service**.

Vous pouvez aussi créer un plan à partir de n'importe quel chant. Sur la page du chant, cliquez sur **+ Ajouter à un plan de service**, saisissez un nom sous la liste, puis cliquez sur **Créer**.

## Ajouter des chants

1. Ouvrez la page d'un chant. Choisissez d'abord la tonalité souhaitée, car le chant est ajouté au plan dans la tonalité affichée à l'écran.
2. Cliquez sur **+ Ajouter à un plan de service**.
3. Cliquez sur le nom du plan. Une coche indique que le chant figure dans ce plan. Cliquez à nouveau pour le retirer.

Le bouton affiche alors **✓ Dans** suivi du nom du plan. Cliquez sur le lien **Ouvrir** portant le nom du plan dans la fenêtre contextuelle pour accéder au plan.

## Organiser le set

Ouvrez un plan depuis la page **Plans de service**. Pour chaque chant, vous pouvez :

- **Réordonner** -- Utilisez les boutons **↑** et **↓**, ou faites glisser le chant à un nouvel emplacement. Cliquez sur **Retirer** pour le supprimer.
- **Tonalité** -- Choisissez parmi les tonalités **Publiées** du chant ou toute autre tonalité (listée sous **Aperçu (toute tonalité)**).
- **Capodastre** -- Choisissez une case de capodastre. Le plan indique alors les accords à jouer.
- **Sections** -- Définissez l'ordre des couplets et des refrains. Utilisez les flèches pour déplacer une section, **×** pour la supprimer et **+ Ajouter une section** pour en ajouter une (par exemple, un refrain répété). Cliquez sur **Rétablir par défaut** pour revenir à l'ordre habituel du chant.
- **Arrangement** -- Saisissez une courte note pour le groupe, par exemple « Refrain ×2 à la fin, dernier couplet a cappella ».

En haut du plan s'affichent le nombre de chants et la durée approximative du set. Les modifications sont enregistrées automatiquement.

## Partager avec votre équipe

1. Cliquez sur **Copier le lien de partage**. Le lien est copié dans le presse-papiers.
2. Envoyez-le à votre groupe par SMS ou par courriel.

Toute personne qui ouvre le lien voit le plan avec toutes les tonalités, les capodastres, les sections et les notes, sans avoir besoin de compte. Elle peut cliquer sur **Enregistrer une copie** pour conserver sa propre copie modifiable dans son navigateur.

Sur la page **Plans de service**, vous pouvez également **Partager**, **Renommer**, **Dupliquer** ou **Supprimer** un plan.

## Utiliser le plan le dimanche

- **Mode scène** -- Affiche une partition par écran, pour une tablette sur un pupitre. Utilisez les flèches (ou les touches **←** et **→**) pour passer d'un chant à l'autre, et les boutons de taille de texte pour agrandir la partition. Le mode scène essaie d'empêcher la mise en veille de l'écran ; la barre indique si l'option **Maintien de l'écran allumé** est active.
- **Imprimer le livret** -- Imprime chaque partition dans l'ordre, une par page, avec une couverture listant les chants et les tonalités. Choisissez **Texte en grand** ou **Afficher les accords**, puis cliquez sur **Imprimer**.
- **Copier pour OnSong / Planning Center** -- Copie toutes les partitions dans vos tonalités et sections, prêtes à être collées.

## Exporter le set

Cliquez sur **FreeShow**, **OpenLP**, **ProPresenter** ou **PowerPoint** pour télécharger l'ensemble du set pour cet outil, dans les tonalités et sections que vous avez choisies.

Cliquez sur **Pack église de maison** pour télécharger une archive ZIP contenant la partition de chaque chant dans votre tonalité, les paroles, les diapositives, les attributions, une liste du set et un fichier LICENSE.txt.

:::warning
Les chants sous licence CC BY-SA sont exclus du pack église de maison, sauf si vous cochez **Pack partage à l'identique (inclure les chants CC BY-SA)**. Si vous les incluez, tout ce que vous créez à partir du pack doit être partagé sous la même licence. Les partitions, le mode scène et le livret incluent toujours ces chants.
:::
