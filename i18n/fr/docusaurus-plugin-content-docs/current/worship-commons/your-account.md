# Votre compte WorshipCommons et votre page d'auteur

<div class="article-intro">

Vous pouvez parcourir, lire, imprimer et projeter des chants sur WorshipCommons sans compte. Un compte gratuit vous permet d'enregistrer des chants, de partager vos propres chants, de proposer des modifications et de suivre tout ce que vous avez envoyé. Si vous écrivez des chants, votre compte vous permet aussi de modifier la page d'auteur que voient les églises.

</div>

## Se connecter ou créer un compte

WorshipCommons utilise les comptes ChurchApps. Si vous en avez déjà un (par exemple, depuis B1), vous pouvez utiliser la même adresse e-mail et le même mot de passe.

1. Cliquez sur **Se connecter** dans le menu supérieur.
2. Saisissez votre **e-mail** et votre **mot de passe**, puis cliquez sur **Se connecter**.

**Pour créer un compte :**

1. Sur la page de connexion, cliquez sur **Créer un compte**.
2. Saisissez votre **prénom**, votre **nom** et votre **e-mail**, puis cliquez sur **Créer le compte**.
3. Consultez votre boîte e-mail pour trouver un code à 6 chiffres, saisissez-le, puis cliquez sur **Vérifier le code**.
4. Choisissez un mot de passe d'au moins 8 caractères, saisissez-le à nouveau sous **Vérifier le mot de passe**, puis cliquez sur **Définir le mot de passe et se connecter**.

**Vous avez oublié votre mot de passe ?** Cliquez sur **Mot de passe oublié ?** sur la page de connexion, saisissez votre e-mail et cliquez sur **Envoyer le code**. Saisissez ensuite le code reçu par e-mail et définissez un nouveau mot de passe.

Une fois connecté, votre prénom apparaît dans le menu supérieur. Cliquez dessus pour ouvrir **Mes envois** ou **Signaler**, ou pour **Se déconnecter**.

## Chants enregistrés

Cliquez sur le cœur de n'importe quelle page de chant pour l'enregistrer. Cliquez sur **Chants enregistrés** dans le menu supérieur pour voir tous les chants que vous avez enregistrés. Ils sont stockés dans votre compte, donc ils apparaissent sur chaque appareil depuis lequel vous vous connectez. Cliquez sur **Retirer** pour supprimer un chant de la liste.

:::tip
Les chants enregistrés forment une simple liste de favoris. Pour préparer un programme pour un dimanche précis, avec les tonalités et les sections, utilisez [Programmes de culte](./service-plans.md).
:::

## Mes envois

Cliquez sur votre nom dans le menu supérieur et choisissez **Mes envois** pour voir chaque chant et chaque modification que vous avez commencés ou envoyés, ainsi que leur état d'avancement. Utilisez les onglets en haut -- **Tous**, **Brouillons**, **En cours d'examen**, **En ligne** et **Non acceptés** -- pour filtrer la liste.

Chaque entrée indique son type (comme **Nouveau chant**, **Traduction**, **Arrangement**, **Correction** ou **Demande de retrait**) ainsi que son statut :

| Statut | Signification |
| --- | --- |
| **Brouillon** | Commencé mais pas encore envoyé. Cliquez sur **Continuer** pour le terminer ou sur **Supprimer le brouillon** pour l'effacer. |
| **Modifications demandées** | Un relecteur a demandé des modifications. Cliquez sur **Continuer**, apportez-les, puis renvoyez le chant. |
| **En cours d'examen** | Une personne lit chaque chant avant sa mise en ligne, généralement dans les quelques jours. Cliquez sur **Retirer** pour le ramener à l'état de brouillon. |
| **En ligne** | Présent dans la bibliothèque et gratuit pour les églises. Vous verrez son nombre de téléchargements et son lien. |
| **Non accepté** | Le chant n'a pas été intégré à la bibliothèque. Le motif du relecteur est affiché. |
| **Retiré** | Vous l'avez retiré avant son examen. |
| **Dépublié** | Le chant a été retiré de la bibliothèque, à votre demande. |

Pour un chant en ligne, cliquez sur **Copier le lien** pour partager sa page, sur **Proposer une modification** pour envoyer une correction, ou sur **Demander le retrait** pour demander qu'il soit retiré. Consultez [Proposer des modifications et signaler des chants](./proposing-edits.md).

:::info
Si l'équipe WorshipCommons vous ajoute comme co-éditeur d'un chant -- par exemple un chant que vous avez co-écrit et que quelqu'un d'autre a téléversé --, il apparaît dans **Mes envois** avec le statut **En ligne**, même si vous ne l'avez pas envoyé vous-même. En tant qu'éditeur du chant, vous pouvez y apporter des modifications même lorsque sa licence en interdit les modifications publiques.
:::

## Pages d'auteur

Chaque auteur de la bibliothèque dispose d'une page d'auteur qui présente ses chants, avec l'année, la tonalité, les thèmes et la licence de chacun. Les églises y accèdent en cliquant sur le nom d'un auteur depuis une page de chant. Lorsqu'un chant a plusieurs auteurs, chaque nom mène à sa propre page.

Une page d'auteur peut aussi afficher un portrait, une courte biographie, des liens et des liens de soutien permettant aux églises de soutenir les autres travaux de l'auteur.

### Modifier votre page d'auteur

Vous disposerez d'une page d'auteur dès qu'un de vos chants sera en ligne et vous y sera crédité en tant qu'auteur.

1. Cliquez sur votre nom dans le menu supérieur et choisissez **Mes envois**.
2. Cliquez sur **Profil d'auteur**.
3. Sous **À propos de vous**, rédigez quelques phrases sur qui vous êtes et sur les chants que vous écrivez (jusqu'à 2 000 caractères).
4. Sous **Liens**, ajoutez jusqu'à cinq liens, comme votre site web. Donnez à chacun un **libellé** et son adresse web. Cliquez sur **Ajouter un lien** pour ajouter une autre ligne.
5. Sous **Liens de soutien**, indiquez les endroits où les églises peuvent soutenir votre travail, comme une boutique ou une page de ministère. Cliquez sur **Ajouter un lien de soutien** pour ajouter une autre ligne.
6. Cliquez sur **Enregistrer le profil**.

Cliquez sur **Voir votre page d'auteur** pour la voir telle que les églises la découvrent. Vos liens de soutien apparaissent également sous forme de bouton **Page du compositeur** sur chacune de vos pages de chant.

:::tip
Vous avez co-écrit vos chants, ou vous disposez déjà d'une page d'auteur qui n'est pas liée à votre compte ? Écrivez à [support@churchapps.org](mailto:support@churchapps.org) pour demander son association à votre compte.
:::
