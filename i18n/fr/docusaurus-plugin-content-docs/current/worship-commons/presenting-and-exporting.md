# Présenter et exporter les chants de WorshipCommons

<div class="article-intro">

WorshipCommons peut afficher les paroles d'un chant sur un écran directement depuis votre navigateur, sans rien installer. Si votre église utilise déjà un logiciel de présentation, téléchargez plutôt les diapositives du chant pour FreeShow, OpenLP, ProPresenter ou PowerPoint, ou ajoutez le chant à votre bibliothèque de chants de B1 Admin.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Ouvrez la page du chant sur [worshipcommons.org](https://worshipcommons.org). Voir [Trouver des chants](./finding-songs.md).
- Pour afficher les paroles sur un téléviseur ou un projecteur, reliez votre ordinateur à l'écran avec un câble HDMI (ou diffusez votre écran).

</div>

## Diriger la louange depuis le navigateur

**Diriger la louange** est un affichage plein écran qui joue la musique et affiche les paroles ligne par ligne, en mettant en évidence chaque mot au moment où il est chanté. Il est conçu pour un petit groupe, une classe ou une maison d'église sans groupe musical.

1. Sur la page du chant, cliquez sur **Diriger la louange**. (Le bouton apparaît lorsque le chant comporte une musique à accompagner.)
2. Choisissez la **Tonalité** et le **Tempo**. Lorsque le chant joue un extrait de piano, vous pouvez choisir **Piano** ou **Orgue**.
3. Cliquez sur **Couplets** pour choisir les couplets à chanter et modifier leur ordre à l'aide des flèches.
4. Activez le **Compte à rebours** si vous voulez un décompte avant le début de la musique.
5. Cliquez sur **▶ Lecture**.

Utilisez **Vide** pour masquer les paroles, **Contraste** pour un écran à fort contraste, et **Plein écran** pour occuper tout l'écran. Cliquez sur **Afficher sur le téléviseur** pour voir les étapes rapides d'affichage sur un téléviseur.

:::tip
Raccourcis clavier : **Espace** lecture/pause, **← →** changer de ligne, **↑ ↓** changer de couplet, **B** vide, **H** contraste, **F** plein écran, **Échap** retour au chant. Cliquez sur **Afficher les raccourcis** en bas de l'écran pour les voir.
:::

## Projeter les paroles

**Ouvrir le projecteur** affiche une section de paroles par écran, et vous passez de l'une à l'autre manuellement. Utilisez-le lorsque vous avez des musiciens en direct.

1. Sur la page du chant, repérez le panneau **Projection** et cliquez sur **Ouvrir le projecteur**.
2. Appuyez sur **F** ou cliquez sur **Plein écran** pour occuper tout l'écran.
3. Cliquez sur l'écran, ou appuyez sur **Espace** ou la touche **→**, pour passer à la diapositive suivante. Appuyez sur **←** pour revenir en arrière. Cliquez sur le nom d'une section en bas pour y accéder directement.
4. Appuyez sur **B** pour vider l'écran et sur **H** pour le contraste élevé.
5. Appuyez sur **Échap** (ou cliquez sur **← Retour au chant**) lorsque vous avez terminé.

La barre inférieure indique la section en cours, le nombre de diapositives et la suite. La ligne de crédit du chant apparaît également à l'écran.

## Exporter les diapositives

Le panneau **Projection** de la page du chant comporte un bouton pour chaque outil. Cliquez sur l'un d'eux pour télécharger le chant :

| Bouton | Ce que vous obtenez |
| --- | --- |
| **FreeShow** | Un fichier de présentation à importer dans [FreeShow](https://freeshow.app) |
| **PowerPoint** | Un diaporama au format PPTX |
| **OpenLP** | Un fichier OpenLyrics à importer dans OpenLP |
| **ProPresenter** | Un fichier texte à importer dans ProPresenter |
| **OnSong / PCO** | Copie le chant dans votre presse-papiers pour le coller dans OnSong ou Planning Center |

La note sous les boutons indique comment les diapositives sont découpées. Si le chant dispose d'un plan de découpage approuvé, les diapositives le suivent ; sinon, elles suivent les couplets tels qu'ils sont écrits. Chaque exportation comprend l'attribution du chant et la mention de sa licence.

:::tip
Pour exporter tout un programme d'un coup, dans les tonalités et sections que vous avez choisies, créez un [plan de service](./service-plans.md) et utilisez-y les boutons d'exportation.
:::

## Ajouter des chants de WorshipCommons à B1

Si votre église planifie ses cultes dans B1 Admin, vous n'avez rien à télécharger. Les chants de WorshipCommons prêts pour le dimanche apparaissent dans la recherche de chants de B1 Admin, sous **WorshipCommons — free**. Cliquez sur l'un d'eux pour l'ajouter à votre bibliothèque de chants, avec un lien vers sa page WorshipCommons.

Voir [Chants dans B1 Admin](../b1-admin/serving/songs.md#free-songs-from-worshipcommons) pour les étapes.
