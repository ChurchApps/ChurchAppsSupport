# Gestion des plans annuels

<div class="article-intro">

Un plan annuel est une liste ordonnée de leçons -- semaine 1, semaine 2, semaine 3 -- que les églises appliquent dans B1 Admin. Vous pouvez publier un plan pour n'importe quel curriculum de la bibliothèque. Les plans sont stockés dans la base de données et ne sont pas liés à une année civile.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Avoir les permissions admin pour Lessons.church
- Avoir au moins un [programme](./managing-programs.md) avec des leçons publiées

</div>

## Création d'un plan

1. Ouvrez **Admin → Plans annuels**.
2. Cliquez sur **Ajouter**.
3. Entrez un nom (par exemple, « Elementary 2026–27 » ou « High Voltage Year 1 ») et un slug optionnel.
4. Optionnellement, définissez une **préférence de lieu par défaut** -- noms de lieux séparés par des virgules.
5. Cochez **Publier** quand les églises doivent voir le plan dans B1 Admin.
6. Ajoutez les semaines de n'importe quel curriculum. Un seul plan peut mélanger les programmes.
7. Enregistrez.

Les églises appliquent un plan publié depuis **B1 Admin → Serving → Plans → Planifier une leçon → Appliquer un plan annuel**. Cela remplit les 12-52 prochaines semaines de leur planning de service.
