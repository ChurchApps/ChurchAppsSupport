# Gestion des Plans Annuels

<div class="article-intro">

Un plan annuel est une liste ordonnée de leçons — semaine 1, semaine 2, semaine 3 — que les églises appliquent dans B1 Admin. Vous pouvez publier un plan pour n'importe quel curriculum de la bibliothèque. Les plans sont stockés dans la base de données et ne sont pas liés à une année civile.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- Avoir les permissions d'administrateur pour Lessons.church
- Avoir au moins un [programme](./managing-programs.md) avec des leçons publiées

</div>

## Création d'un Plan

1. Ouvrez **Admin → Plans Annuels**.
2. Cliquez sur **Ajouter**.
3. Entrez un nom (par exemple, "Élémentaire 2026–27" ou "High Voltage Année 1") et un slug facultatif.
4. Définissez éventuellement une **préférence de lieu par défaut** — noms de lieu séparés par des virgules utilisés lorsqu'une semaine ne spécifie pas de lieu.
5. Cochez **Publier** lorsque les églises devraient voir le plan dans B1 Admin. Laissez-le désactivé pour un brouillon.
6. Ajoutez des semaines de n'importe quel curriculum : choisissez une **source**, puis programme, étude, leçon et lieu. Cliquez sur **Ajouter**. Un seul plan peut mélanger les programmes si vous le souhaitez. Utilisez les flèches pour réorganiser.
7. Enregistrer.

Les églises appliquent un plan publié à partir de **B1 Admin → Serving → Plans → Programmer une Leçon → Appliquer un Plan Annuel**. Cela remplit les 12–52 prochaines semaines sur leur horaire de service. Elles modifient les semaines individuelles là-bas après; FreePlay joue ce qui est sur le plan.
