# Aperçu du portail

<div class="article-intro">

Après vous être connecté à Lessons.church, vous êtes redirigé vers le **Portail** -- le tableau de bord de votre église pour gérer les salles de classe et les horaires de leçon. C'est l'endroit où vous passerez la plupart de votre temps pour organiser le curriculum de votre église.

</div>

<div class="prereqs">
<h4>Avant de commencer</h4>

- [Créer un compte](./creating-account.md) et se connecter à votre église
- Connectez-vous à [Lessons.church](https://lessons.church)

</div>

## Ce que vous voyez

Le portail est organisé en deux zones principales :

- **Salles de classe** (côté droit) -- Une liste des salles de classe de votre église. Cliquez sur le nom d'une salle de classe pour afficher ses leçons planifiées. Vous pouvez également ajouter de nouvelles salles de classe ou modifier celles existantes à partir d'ici.
- **Leçons planifiées** (côté gauche) -- Une fois que vous sélectionnez une salle de classe, cette zone affiche les leçons qui ont été planifiées pour elle. Si vous n'avez pas encore configuré de salles de classe, vous verrez une vidéo d'instructions de configuration.

## Ce que vous pouvez faire à partir du portail

À partir du portail, vous pouvez :

1. **Gérer les salles de classe** -- Ajouter, modifier ou supprimer des salles de classe. Chaque salle de classe peut être liée à une équipe de bénévoles et à un groupe de parents/étudiants.
2. **Afficher et gérer les leçons planifiées** -- Voir quelles leçons arrivent pour chaque salle de classe et faire les modifications nécessaires.
3. **S'abonner aux flux de salle de classe** -- Cliquez sur l'icône de flux en regard d'une salle de classe pour obtenir une URL de flux de liste de lecture.
4. **Accéder aux fournisseurs externes** -- Utilisez la page **Fournisseurs externes** pour configurer des sources de contenu tiers.
5. **Accéder à la zone admin** -- Si vous avez les permissions admin, vous verrez une option **Admin** dans la navigation.

## Navigation

La navigation du portail comprend :

- **Accueil** -- Retour à la page d'accueil publique de Lessons.church.
- **Calendriers** -- La vue du portail principal pour gérer les salles de classe et les horaires de leçon.
- **Fournisseurs externes** -- Configurer les fournisseurs de leçons tiers.
- **Admin** -- Gérer les programmes, les études et le contenu des leçons.

:::info
L'option **Admin** n'apparaît que si votre compte a été autorisé à modifier le contenu. La plupart du personnel d'église utiliseront les pages **Calendriers** et **Fournisseurs externes** pour la gestion quotidienne.
:::

## Commencer

Si c'est votre première visite au portail et que vous n'avez créé de salles de classe, commencez par cliquer sur **Ajouter la première salle de classe** dans le panneau des salles de classe. Donnez un nom à votre salle de classe et enregistrez-la. De là, vous pouvez commencer à [planifier les leçons](../classrooms/scheduling-lessons.md).
