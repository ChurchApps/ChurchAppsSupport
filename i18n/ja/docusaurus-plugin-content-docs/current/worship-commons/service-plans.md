# WorshipCommons礼拝プラン

<div class="article-intro">

WorshipCommonsの礼拝プランは、日曜礼拝のセットリストです。曲を並べ、それぞれの曲のキー、カポ、セクションを選んだら、1つのリンクをバンドと共有します。プランからは、譜面台用のステージ表示を開いたり、冊子を印刷したり、セット全体をプレゼンテーションソフトに書き出したりできます。

</div>

:::info
礼拝プランはアカウントではなく、お使いのWebブラウザに保存されます。利用にサインインは不要です。共有リンクにはセット全体の情報が含まれるため、別の端末に移る場合はリンクを保存しておいてください。教会がB1 Adminで礼拝を計画している場合は、代わりに[プラン](../b1-admin/serving/plans.md)をご覧ください。
:::

## 礼拝プランの作成

1. 上部のメニューで**礼拝プラン**をクリックします。
2. 「9月14日の日曜礼拝」や「青年集会」などの名前を入力し、**礼拝プランを作成**をクリックします。

任意の曲からプランを作成することもできます。曲のページで**+ 礼拝プランに追加**をクリックし、一覧の下に名前を入力して**作成**をクリックします。

## 曲の追加

1. 曲のページを開きます。曲は画面に表示されているキーでプランに追加されるため、先に使いたいキーを設定してください。
2. **+ 礼拝プランに追加**をクリックします。
3. プラン名をクリックします。チェックマークが表示されれば、その曲はそのプランに入っています。もう一度クリックすると削除されます。

ボタンには、**✓ 入っています**とプラン名が表示されます。ポップアップにあるプラン名の**開く**リンクをクリックすると、そのプランに移動します。

## セットの整理

**礼拝プラン**ページからプランを開きます。曲ごとに次の操作ができます。

- **並べ替え** -- **↑**と**↓**ボタンを使うか、曲を新しい位置までドラッグします。**削除**をクリックすると取り除けます。
- **キー** -- 曲の**公開済み**のキー、または**プレビュー（任意のキー）**に一覧されている他のキーから選びます。
- **カポ** -- カポの位置を選びます。プランには、演奏すべきコードフォームが表示されます。
- **セクション** -- 各番と繰り返し部分の順序を設定します。矢印でセクションを移動し、**×**で削除し、**+ セクションを追加**で（例えば繰り返しのサビなど）追加します。**初期設定に戻す**をクリックすると、曲の通常の順序に戻ります。
- **アレンジ** -- 「最後にサビを2回、最後の番はアカペラ」など、バンドへの短いメモを入力します。

プランの上部には、曲数とセットのおおよその長さが表示されます。変更は自動的に保存されます。

## チームとの共有

1. **共有リンク**をクリックします。リンクがクリップボードにコピーされます。
2. テキストメッセージやメールでバンドに送ります。

リンクを開いた人は、アカウントがなくても、すべてのキー、カポ、セクション、メモを含むプランを見られます。**コピーを保存**をクリックすると、自分のブラウザに編集可能な独自のコピーを保存できます。

**礼拝プラン**ページでは、プランの**共有**、**名前の変更**、**複製**、**削除**も行えます。

## 日曜礼拝でのプランの使用

- **ステージモード** -- 譜面台に置いたタブレット向けに、画面ごとに1つの譜面を表示します。矢印（または**←**と**→**キー）で曲を移動し、文字サイズボタンで譜面を大きくできます。ステージモードは画面がスリープしないように努めます。バーに**画面をスリープさせない**と表示されていれば、この機能が有効です。
- **冊子を印刷** -- すべての譜面を順番に、1ページに1つずつ印刷します。表紙には曲名とキーが一覧されます。**大きい文字**または**コードを表示**を選び、**印刷**をクリックします。
- **OnSong / Planning Center用にコピー** -- 選んだキーとセクションですべての譜面をコピーし、そのまま貼り付けられる状態にします。

## セットの書き出し

**FreeShow**、**OpenLP**、**ProPresenter**、または**PowerPoint**をクリックすると、選んだキーとセクションで、そのツール用のセット全体をダウンロードできます。

**家庭礼拝パック**をクリックすると、各曲の選んだキーの譜面、歌詞、スライド、クレジット表示、セットリスト、そして1つのLICENSE.txtファイルを含むZIPがダウンロードされます。

:::warning
CC BY-SAライセンスの曲は、**共有ライセンス版パック（CC BY-SAの曲を含む）**にチェックを入れない限り、家庭礼拝パックから除外されます。これらの曲を含める場合、パックから作成したものはすべて同じライセンスで共有しなければなりません。譜面、ステージモード、冊子には、常にこれらの曲が含まれます。
:::
