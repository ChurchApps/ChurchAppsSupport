# WorshipCommons の概要

<div class="article-intro">

WorshipCommons は、教会のための無料で公開されている賛美歌ライブラリです。パブリックドメインの賛美歌や、作者が共有することを選んだ歌が収録されています。各曲には歌詞、どのキーにも移調できるコードチャート、日曜礼拝用のスライドが含まれています。[worshipcommons.org](https://worshipcommons.org) にアクセスすると、曲を探し、キーを変え、チャートを印刷し、歌詞をスクリーンに映すことができます。

</div>

WorshipCommons は、追加料金なしで使える曲を必要とする礼拝リーダー、音楽奉仕者、技術ボランティアのための場所です。また、教会に自分の曲を提供したいソングライターにとっても役立ちます。曲を閲覧、演奏、印刷、投影するのにアカウントは必要ありません。無料の ChurchApps アカウントを作成すると、曲を保存したり、自分の曲を共有したりできます。

:::info
教会でどこまで利用できるかは、各曲のライセンスによって異なります。パブリックドメインの賛美歌は、アメリカ合衆国ではあらゆる用途に無料で使えます（ベストエフォートのため、他の国では異なる場合があります）。WorshipCommons ライセンスのもとで共有されている曲は礼拝での利用が無料で、作者が商業上の権利を保持します。曲の **About & rights** タブを開くと、何が許可されているかを正確に確認できます。WorshipCommons は、その他の歌唱曲に必要な CCLI ライセンスに代わるものではありません。
:::

## 主な機能

- **検索とフィルター** -- タイトル、冒頭の歌詞、旋律、テーマ、聖書箇所、作者で検索し、キー、テンポ、言語、ライセンスなどで絞り込めます。詳しくは [曲を探す](./finding-songs.md) を参照してください。
- **どのキーのコードチャートも** -- 移調、カポの設定、ナッシュビル・ナンバーへの切り替えができ、コードをタップするとギターとピアノの押さえ方を確認できます。詳しくは [曲のページ](./song-page.md) を参照してください。
- **曲を聴く** -- デモ録音やピアノのプレビューを再生し、速度を落として練習したり、メトロノームを使って練習したりできます。
- **印刷とダウンロード** -- 自分のキーのコードチャートを印刷したり、曲にデータがある場合は ChordPro、歌詞、楽譜、オーディオパックをダウンロードしたりできます。
- **礼拝のリードと投影** -- 音楽に合わせて歌詞が進むブラウザのタブから礼拝をリードしたり、シンプルな歌詞プロジェクターを開いたりできます。詳しくは [曲の発表とエクスポート](./presenting-and-exporting.md) を参照してください。
- **エクスポート** -- FreeShow、OpenLP、ProPresenter、PowerPoint 用のスライドをダウンロードしたり、OnSong や Planning Center 用に曲をコピーしたりできます。B1 Admin では、WorshipCommons の曲を自分の曲ライブラリに直接追加できます。
- **礼拝プラン** -- 日曜日の礼拝に向けた曲目を組み立て、各曲のキーとセクションを選び、1つのリンクをバンドメンバーと共有できます。詳しくは [礼拝プラン](./service-plans.md) を参照してください。
- **自分の曲を共有** -- 自分が書いた曲、翻訳、編曲をアップロードし、そのライセンスの方法を選べます。詳しくは [曲の共有](./sharing-a-song.md) を参照してください。
- **コミュニティによる編集** -- サインインしているユーザーなら誰でも修正を提案でき、レビュー担当者が判断します。詳しくは [編集の提案と曲の報告](./proposing-edits.md) を参照してください。
- **作者ページ** -- すべての作者には、その人の曲の一覧が表示されるページが用意されます。任意で経歴やリンクも掲載できます。詳しくは [アカウントと作者ページ](./your-account.md) を参照してください。
