# WorshipCommons の賛美曲を表示・書き出す

<div class="article-intro">

WorshipCommons では、何もインストールせずにブラウザから賛美曲の歌詞を画面に表示できます。教会ですでにプレゼンテーションソフトを使っている場合は、FreeShow、OpenLP、ProPresenter、PowerPoint 用に曲のスライドをダウンロードするか、B1 Admin の賛美曲ライブラリに曲を追加してください。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [worshipcommons.org](https://worshipcommons.org) で曲のページを開きます。[曲を探す](./finding-songs.md)を参照してください。
- 歌詞をテレビやプロジェクターに表示するには、HDMI ケーブルでコンピューターを接続します（または画面をキャストします）。

</div>

## ブラウザからリードワーship を行う

**Lead worship** は、音楽を再生し、歌詞を一行ずつ表示する全画面表示です。歌われるのに合わせて単語がハイライトされます。バンドがない小グループ、教室、家の集会などで使うことを想定しています。

1. 曲のページで **Lead worship** をクリックします。（伴奏の音源がある曲にのみボタンが表示されます。）
2. **Key**（キー）と **Tempo**（テンポ）を選びます。曲にピアノのプレビューがある場合は、**Piano**（ピアノ）または **Organ**（オルガン）を選べます。
3. **Verses** をクリックして歌う節を選び、矢印ボタンで順番を入れ替えます。
4. 音楽が始まる前にカウントを入れたい場合は **Count-in** をオンにします。
5. **▶ Play** をクリックします。

**Blank** で歌詞を非表示にし、**Contrast** で高コントラストの画面に切り替え、**Fullscreen** で画面いっぱいに表示します。**Put this on the TV** をクリックすると、テレビに表示する手順をすぐに確認できます。

:::tip
キーボードショートカット：**Space** で再生／一時停止、**← →** で行を移動、**↑ ↓** で節を移動、**B** で非表示、**H** でコントラスト、**F** で全画面、**Esc** で曲のページに戻ります。画面下部の **Show keys** をクリックすると一覧を確認できます。
:::

## 歌詞を投影する

**Open projector** では、歌詞を一度に一つのセクションずつ表示し、手動で次へ進めます。生演奏のミュージシャンと一緒に使う場合に便利です。

1. 曲のページで **Projection** パネルを見つけ、**Open projector** をクリックします。
2. **F** を押すか **Fullscreen** をクリックして、画面いっぱいに表示します。
3. 画面をクリックするか、**Space** または **→** キーを押すと次のスライドに進みます。**←** キーを押すと前に戻ります。画面下部のセクション名をクリックすると、そのセクションに直接移動できます。
4. **B** を押すと画面が非表示になり、**H** を押すと高コントラスト表示になります。
5. 終わったら **Esc** を押すか、**← Back to song** をクリックします。

画面下部のバーには、現在のセクション、スライドの枚数、次に表示される内容が表示されます。曲のクレジット表記も画面に表示されます。

## スライドを書き出す

曲のページにある **Projection** パネルには、ツールごとのボタンがあります。ボタンをクリックすると曲がダウンロードされます。

| ボタン | 書き出される内容 |
| --- | --- |
| **FreeShow** | [FreeShow](https://freeshow.app) にインポートするショーファイル |
| **PowerPoint** | PPTX 形式のスライドデッキ |
| **OpenLP** | OpenLP にインポートする OpenLyrics ファイル |
| **ProPresenter** | ProPresenter にインポートするテキストファイル |
| **OnSong / PCO** | OnSong または Planning Center に貼り付けるため、曲をクリップボードにコピーします |

ボタンの下の注記に、スライドの分け方が説明されています。曲に承認済みのフォームマップがある場合はそれに従い、ない場合は歌詞に書かれた節に従ってスライドが作られます。すべての書き出しには、曲の帰属表示とライセンスのクレジットが含まれます。

:::tip
選んだキーとセクションで一連の曲をまとめて書き出すには、[礼拝プラン](./service-plans.md)を作成し、そこにある書き出しボタンを使用してください。
:::

## WorshipCommons の賛美曲を B1 に追加する

礼拝のプランを B1 Admin で作成している場合、何もダウンロードする必要はありません。WorshipCommons の日曜礼拝ですぐに使える賛美曲は、B1 Admin の賛美曲検索に **WorshipCommons — free** として表示されます。曲をクリックすると賛美曲ライブラリに追加され、WorshipCommons のページへのリンクも設定されます。

手順については、[B1 Admin の賛美曲](../b1-admin/serving/songs.md#free-songs-from-worshipcommons)を参照してください。
