# WorshipCommonsで賛美曲を探す

<div class="article-intro">

**Discover**ページは、WorshipCommonsの曲ライブラリです。すでに知っている曲を検索したり、フィルターで一覧を絞り込んだりして、日曜日に使える新しい曲を見つけられます。曲の検索や再生にサインインは必要ありません。

</div>

## ライブラリを検索する

1. [worshipcommons.org](https://worshipcommons.org)にアクセスし、ページ上部の**Discover**(または**Browse Songs**)をクリックします。
2. 検索ボックスに入力します。タイトル、歌い出しの言葉、曲名のもとになった旋律名、テーマ、聖句の箇所、作詞者で検索できます。入力に合わせて結果が更新されます。
3. **Sort by**メニューを使って、結果を**Most downloaded**(ダウンロード数順)、**Most saved**(保存数順)、**Newest**(新しい順)、**Title A–Z**(タイトルのA–Z順)に並べ替えます。
4. 曲のタイトルをクリックすると、その[曲のページ](./song-page.md)が開きます。

:::tip
Discoverページのどこでも`/`キーを押すと、検索ボックスにすばやく移動できます。
:::

各行には、曲の作詞者、制作年、聖句の箇所(ある場合)、ダウンロード数と保存数、テーマ(最大3つ)、キー、テンポ(BPM)が表示されます。行の先頭にある再生ボタンをクリックすると、一覧を離れることなくデモ録音またはピアノのプレビューを聴けます。

## 曲を絞り込む

**Filters**をクリックすると、フィルターパネルを開いたり閉じたりできます(画面の大きいデバイスでは最初から開いています)。同じグループの中では複数の項目を選べます。異なるグループをまたいで設定した場合、曲はすべての条件に一致する必要があります。各項目の横の数字は、一致する曲の数を示しています。

- **Theme**(テーマ) -- Praise(賛美)、Grace(恵み)、Hope(希望)、Christmas(クリスマス)などの主題です。全項目を見るには**Show more**をクリックします。
- **Confidence**(完成度) -- 曲の資料がどれだけそろっているかを示します。**Sunday-ready**(すぐ使える)、**Score**(楽譜あり)、**Unchecked score**(楽譜未確認)、**Chart only**(コード譜のみ)、**Lyrics only**(歌詞のみ)から選びます。
- **Ready to use**(すぐ使える素材) -- **Works with just a guitar**(ギターだけで演奏可能)、**Has accompaniment**(伴奏あり)、**Has chart**(コード譜あり)、**Has score**(楽譜あり)、**Has stems**(音源パートあり)から選びます。
- **Key**(キー)と**Meter**(拍子) -- 特定のキーや賛美歌の拍子を選びます。
- **Tempo**(テンポ) -- **Slow**(遅い、73 BPM未満)、**Moderate**(中くらい、73～100)、**Upbeat**(速い、100以上)から選びます。
- **Language**(言語) -- 特定の言語の曲を表示します。
- **Source**(出典) -- 曲のライセンスです。**Public domain**(パブリックドメイン)、**Free for worship**(礼拝での無償利用可)、クリエイティブ・コモンズのライセンスなどがあります。⚠の付いたライセンスは非営利利用に限られます。
- **Extras**(その他) -- **Has demo recording**(デモ録音あり)。

有効なフィルターは、結果の上にチップとして表示されます。チップの**X**をクリックすると削除でき、**Clear all filters**をクリックするとすべて解除できます。

:::info
**Language**フィルターは、サイトで選択している言語が初期値になっているため、まずはその言語の曲が表示されます。すべての言語の曲を見るには、結果の上にある言語のチップを削除してください。サイトの表示言語を変更するには、どのページでも下部にある地球儀のアイコンから選択します。
:::

## 曲が見つからない場合

該当する曲がない場合は、フィルターを緩めるか、検索語を消去してください。WorshipCommonsに掲載されているのは、パブリックドメインの曲や、作詞者が共有を選んだ曲だけです。そのため、著作権で保護された曲の多くはここにはありません。検索結果が空の場合は、**Search SongSelect →**をクリックすると、CCLIのカタログで曲を探せます。

## そのほかの探し方

どのページの下部にあるリンクから、あらかじめ用意された一覧に進めます。

- **New songs**(新着の曲) -- ライブラリに追加されたすべての曲を、新しいものから順に表示します。
- **Public domain hymns**(パブリックドメインの賛美歌) -- あらゆる用途で無償で使える賛美歌です。
- **No CCLI needed**(CCLI報告不要) -- CCLIへの報告なしで教会で使える曲です。
- **Christmas songs**(クリスマスの曲) -- 季節に合わせた曲集です。

上部メニューの**Listen**をクリックすると、作詞者が最近共有した曲を、シャッフルされた順で続けて聴けます。再生中に**+ Save song**をクリックすると、保存した曲に追加できます(サインインが必要です)。
