# WorshipCommons の曲ページ

<div class="article-intro">

WorshipCommons のすべての曲には、歌詞とコードが載った専用のページがあります。曲を聴く方法、練習ツール、印刷用の楽譜、ダウンロードもそろっています。このページの機能は、曲をアカウントに保存する場合を除き、サインインなしで利用できます。

</div>

## ページ上部の内容

ページの上部には、曲のカバー、タイトル、歌い出しの歌詞、作詞・作曲者と年、そして讃美歌の旋律名（ある場合）が表示されます。その下には次の項目があります。

- **ライセンスバッジ** -- 例：**Public domain**（パブリックドメイン）、**WC**（礼拝での無料利用）、または **CC BY** などのクリエイティブ・コモンズ・バッジ。
- **テーマと拍子** -- テーマや拍子のタグをクリックすると、同じタグを持つ他の曲を探せます。
- **キー、BPM、拍子記号、推定演奏時間**。曲におすすめのキーがある場合は **Recommended key**（おすすめのキー）も表示されます。

右側には主な操作ボタンがあります。

- **Lead worship**（礼拝で使う） -- 歌詞と音楽を追いながら見られる全画面表示を開きます。詳しくは [曲の表示と書き出し](./presenting-and-exporting.md) をご覧ください。
- **+ Add to service plan**（礼拝プランに追加） -- 画面に表示されているキーで、曲を [礼拝プラン](./service-plans.md) のいずれかに追加します。
- **ハート（曲を保存）** -- 曲をアカウントに保存します。先にサインインを求められます。
- **Songwriter's page**（作者のページ） -- 作者が、教会からの支援を受け付けるリンクを追加している場合に表示されます。

作者の名前をクリックすると、その人の [作者ページ](./your-account.md#writer-pages) が開き、ライブラリにあるすべての曲が一覧で表示されます。

## 曲を聴く

曲に音源がある場合、タイトルの下にプレーヤーが表示されます。再生ボタンをクリックすると聴けます。

- 作者が録音を共有している場合は、**Demo recording**（デモ録音）または **Master recording**（マスター録音）が流れます。
- そうでない場合は **Piano preview**（ピアノによる試聴）が流れます。これは旋律のファイルをピアノで演奏したものです。ピアノの試聴は、ページで選んだキーに合わせて再生されるので、実際に歌うキーで曲を確認できます。

## コードと歌詞

**Chords & lyrics**（コードと歌詞）タブには楽譜が表示されます。その上のツールバーを使って、チームに合わせて設定できます。

1. **Key**（キー） -- 新しいキーを選ぶと、すべてのコードが移調されます。元のキーには **(original)**（原曲）と表示されます。
2. **Capo**（カポ） -- カポの位置を選びます。楽譜には、演奏するコードフォーム（例：**2 — C shapes**）が表示されます。曲自体は選んだキーで鳴ります。
3. **Transpose**（移調） -- **−** または **+** をクリックすると、キーを半音ずつ下げたり上げたりできます。
4. **Display**（表示） -- **Chords** をオフにすると歌詞だけの表示になります。**Nashville** をオンにすると、コードが数字で表示されます。
5. **Text size**（文字サイズ）と **Columns**（段組み） -- 文字を大きくしたり、楽譜を2段組みで表示したりできます。

コードにマウスを合わせるか、タップすると、ギターとピアノでの押さえ方が表示されます。長い曲では、**Jump to**（移動）ボタンを使うと、番の歌詞やサビへすぐにスクロールできます。

:::info
歌詞だけの曲には、コードがないため、キー、カポ、コードの設定は表示されません。
:::

楽譜の下には次の項目があります。

- **Print / PDF**（印刷 / PDF） -- 選んだキー、カポ、コードの設定で、印刷用の楽譜を開きます。そのページで **Text size**（文字サイズ）（**Large print**（大きな文字）を含む）を選び、**2 columns**（2段組み）または **Show chords**（コードを表示）を選んでから、**Print**（印刷）をクリックします。PDF として保存するには、ブラウザの印刷ダイアログを使います。
- **ChordPro** と **Lyrics (TXT)** -- 曲を ChordPro ファイルまたはプレーンテキストとしてダウンロードします。
- **Copy lyrics**（歌詞をコピー） -- コードを除いた歌詞をクリップボードにコピーします。
- **Chart PDF**（楽譜 PDF） -- 曲に既製の楽譜 PDF がある場合に表示されます。

ページ下部の一行には、その曲を CCLI に報告する必要があるかどうかが書かれています。WorshipCommons の曲の多くは報告の必要がありません。

## 楽譜（五線譜）

スコアのある曲には **Sheet music**（楽譜）タブが表示されます。選んだキーで旋律が表示されます。**Full score with all parts →**（全パートのフルスコア →）をクリックすると、フルスコアが開きます。そこで **Key**（キー）と **Part**（パート）を選び、**Print**（印刷）をクリックできます。作者が楽譜の PDF をアップロードしている場合は、ここにも表示されます。**Open full size →**（原寸で開く →）と **Download PDF**（PDF をダウンロード）のリンクが使えます。

## 概要と権利

**About & rights**（概要と権利）タブでは、「この曲はどこから来たのか、使ってもよいのか」がわかります。次の内容が表示されます。

- 作者、曲の聖書箇所、テーマ、拍子
- **Sing it to another tune**（別の旋律で歌う） -- 同じ拍子の他の讃美歌の旋律
- **Contributors & changes**（貢献者と変更） -- 曲に関わった人と、承認された編集内容
- **Rights**（権利） -- ライセンスで許可されていること、許可されていないこと、必ず守るべきこと。**Copy attribution**（クレジットをコピー）をクリックすると、週報やスライドに使うクレジット表記をコピーできます。

## 練習ツール

**Practice**（練習）パネルは、チームのリハーサルに役立ちます。

- **Tempo**（テンポ） -- スライダーまたは **−** と **+** ボタンで、音楽を遅くしたり速くしたりできます（50%〜150%）。
- **Practice parts**（パートの練習） -- 音楽に複数のパート（ソプラノ、アルト、テノール、バスなど）がある場合、パートをクリックするとそのパートだけを聴けます。**All**（すべて）をクリックすると、全パートをまとめて聴けます。
- **Metronome**（メトロノーム） -- **▶ Metronome** をクリックすると、現在のテンポでクリック音が鳴ります。
- **Play**（音を鳴らす）ノート -- ページのキーの開始音を鳴らし、会衆の音程を合わせられます。

## ダウンロードと投影

**Downloads**（ダウンロード）パネルには、常に現在のキーとカポでの **Chord chart (print)**（コード譜（印刷用））があります。作者が共有した内容によっては、**Composition pack**（作曲パック）、**Audio pack**（オーディオパック）、**Multitracks (ZIP)**（マルチトラック（ZIP））も表示されることがあります。

**Projection**（投影）パネルでは、歌詞のプロジェクターを開き、スライドを書き出せます。詳しくは [曲の表示と書き出し](./presenting-and-exporting.md) をご覧ください。

## 聖書箇所、関連する曲、翻訳

ページの下部には次の項目があります。

- **Scripture connection**（聖書とのつながり） -- 曲の聖書箇所を、World English Bible の本文とともに表示します。曲にまだ聖書箇所がない場合は、**Propose one →**（提案する →）をクリックして箇所を提案できます。
- **Related songs**（関連する曲） -- 同じ言語の別バージョンの曲や、似たタイトルの曲。
- **Translations**（翻訳） -- 他の言語版の曲。**Add one →**（追加する →）をクリックすると翻訳を共有できます（[曲の共有](./sharing-a-song.md) をご覧ください）。曲のライセンスで翻訳が許可されていない場合は、**Translations need the writer's permission.**（翻訳には作者の許可が必要です。）と表示されます。
