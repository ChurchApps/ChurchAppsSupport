# あなたの WorshipCommons アカウントとライターページ

<div class="article-intro">

WorshipCommons では、アカウントがなくても曲の閲覧、再生、印刷、投影ができます。無料アカウントを作成すると、曲の保存、ご自身の曲の共有、修正の提案、送信した内容の確認ができるようになります。曲を書いている方は、アカウントを使って教会に表示されるライターページを編集することもできます。

</div>

## サインインとアカウントの作成

WorshipCommons は ChurchApps のアカウントを使用します。すでにアカウントをお持ちの場合（例：B1 をご利用の場合）、同じメールアドレスとパスワードでサインインできます。

1. 上部メニューの **サインイン** をクリックします。
2. **メールアドレス** と **パスワード** を入力し、**サインイン** をクリックします。

**アカウントを作成するには：**

1. サインインページで **アカウントを作成** をクリックします。
2. **名** と **姓**、**メールアドレス** を入力し、**アカウントを作成** をクリックします。
3. メールで届いた 6 桁のコードを確認し、入力して **コードを確認** をクリックします。
4. 8 文字以上のパスワードを設定し、**パスワードの確認** 欄にもう一度入力して、**パスワードを設定してサインイン** をクリックします。

**パスワードを忘れた場合：** サインインページで **パスワードをお忘れですか？** をクリックし、メールアドレスを入力して **コードを送信** をクリックします。その後、メールで届いたコードを入力し、新しいパスワードを設定してください。

サインインすると、上部メニューにお名前が表示されます。それをクリックすると **マイ投稿** や **レポート** を開いたり、**サインアウト** したりできます。

## 保存した曲

各曲のページにあるハートをクリックすると、その曲を保存できます。上部メニューの **保存した曲** をクリックすると、保存したすべての曲を確認できます。保存した曲はアカウントに保存されるため、サインインしたどの端末からでも表示されます。リストから曲を外すには **削除** をクリックします。

:::tip
保存した曲は、いわばお気に入りリストです。特定の日曜日の、キーや構成を含めた礼拝の曲順を計画したい場合は、[礼拝プラン](./service-plans.md)をご利用ください。
:::

## マイ投稿

上部メニューでお名前をクリックし、**マイ投稿** を選ぶと、ご自身が作成または送信したすべての曲と変更内容、およびそれぞれの進行状況を確認できます。上部のタブ（**すべて**、**下書き**、**確認中**、**公開中**、**不採用**）を使って一覧を絞り込めます。

各項目には種類（**新しい曲**、**翻訳**、**編曲**、**修正**、**削除依頼**など）と状態が表示されます。

| 状態 | 意味 |
| --- | --- |
| **下書き** | 作成を始めたものの、まだ送信していない状態です。**続きを編集** をクリックして完成させるか、**下書きを削除** をクリックして削除できます。 |
| **修正が必要** | 確認者が変更を求めています。**続きを編集** をクリックして修正し、再度送信してください。 |
| **確認中** | 公開前に、担当者がすべての曲を確認します。通常は数日以内に完了します。**取り下げ** をクリックすると、下書きに戻せます。 |
| **公開中** | ライブラリに掲載され、教会が無料で利用できる状態です。ダウンロード数とリンクが表示されます。 |
| **不採用** | ライブラリには掲載されませんでした。確認者の理由が表示されます。 |
| **取り下げ済み** | 確認が行われる前に、ご自身で取り下げた状態です。 |
| **削除済み** | ご依頼に基づき、曲がライブラリから削除された状態です。 |

公開中の曲については、**リンクをコピー** をクリックしてその曲のページを共有したり、**修正を提案** をクリックして編集内容を送ったり、**削除を依頼** をクリックして削除を依頼したりできます。詳しくは [修正の提案と曲の報告](./proposing-edits.md)をご覧ください。

:::info
WorshipCommons チームが、あなたを曲の共同公開者として追加した場合（例：あなたが共作し、別の方がアップロードした曲など）、ご自身で送信していなくても、その曲は **マイ投稿** に **公開中** として表示されます。その曲の公開者として、ライセンスにより一般からの編集が閉じられている場合でも、変更を加えることができます。
:::

## ライターページ

ライブラリに掲載されているすべてのライターには、その方の曲を一覧できるライターページがあります。各曲の発表年、キー、テーマ、ライセンスが表示されます。教会は、曲のページでライターの名前をクリックしてこのページを開きます。曲に複数のライターがいる場合、それぞれの名前がそれぞれのページにリンクされます。

ライターページには、ポートレート写真、短いプロフィール、リンク、そして教会がライターの他の活動を支援できるサポートリンクも掲載できます。

### ライターページの編集

ご自身の曲が公開されており、その曲にご自身が作者としてクレジットされていると、ライターページが作成されます。

1. 上部メニューでお名前をクリックし、**マイ投稿** を選びます。
2. **ライタープロフィール** をクリックします。
3. **自己紹介** の下に、ご自身について、そして作っている曲について数文を書きます（2,000 文字まで）。
4. **リンク** の下に、ウェブサイトなどのリンクを最大 5 件追加します。それぞれに **ラベル** と Web アドレスを入力します。別の行を追加するには **リンクを追加** をクリックします。
5. **サポートリンク** の下に、ストアや活動ページなど、教会があなたの活動を支援できる場所を追加します。別の行を追加するには **サポートリンクを追加** をクリックします。
6. **プロフィールを保存** をクリックします。

**ライターページを表示** をクリックすると、教会から見た表示を確認できます。サポートリンクは、ご自身の各曲のページに **ソングライターのページ** ボタンとしても表示されます。

:::tip
曲を共作した場合や、アカウントに紐づいていないライターページがすでにある場合は、[support@churchapps.org](mailto:support@churchapps.org) までメールでご連絡ください。紐づけを依頼できます。
:::
