# WorshipCommonsで曲を共有する

<div class="article-intro">

曲を作詞作曲し、教会がそれを自由に歌えるようにしたい場合は、WorshipCommonsで共有できます。ライブラリにある曲の翻訳や編曲を共有することもできます。すべての曲は公開前に担当者が確認します。通常は数日以内に完了します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- WorshipCommonsにサインインします。[アカウントと作曲者ページ](./your-account.md)を参照してください。
- 18歳以上であり、その曲を作詞作曲したか、著作権を管理している必要があります。すべての共作者が書面で同意している必要があります。
- 歌詞を用意し、教会がメロディーを学べる方法を少なくとも1つ用意してください。デモ録音（スマートフォンでの録音で構いません）、楽譜、MIDIファイル、または動画リンクのいずれかです。

</div>

## 投稿を始める

1. 上部のメニューで**For Songwriters**をクリックします。
2. ページの4つのステップ（**The song**、**Files**、**License**、**Your word**）に従います。上部のステップ名をクリックすると、そのステップに移動できます。

曲にタイトルが付くと、作業内容は自動的に下書きとして保存されます。フォーム上部の**Draft saved**の表示を確認してください。後で作業を再開するには、**My submissions**から**Continue**をクリックします。

:::info
曲をアップロードせずに公開したい作曲者は、すべてのページの下部にリンクがある**Call for songs**ページから公開通知をコピーできます。
:::

## ステップ1: 曲の情報

1. **What are you adding?**で、**New song**、**Translation of an existing song**、または**Arrangement of an existing song**を選びます。
2. **Title**を入力します。
3. **Writer(s)**に、コードチャートに記載すべき共作者の名前を、正確にすべて入力します。
4. **Year written**、**Original key**、**Tempo (BPM)**を追加します。キーは、ご自身で選ぶまで最初のコードから読み取られます。
5. 当てはまる**Themes**をクリックします。全一覧は**More themes**をクリックして表示します。
6. 曲の**Language**を選びます。曲が聖書箇所に基づく場合は、**Scripture reference**を追加します（例：イザヤ書40:4）。教会は曲のページでその箇所を確認できます。
7. 教会がすでにCCLIに曲を報告している場合は、教会に変更が生じないよう、**CCLI number (optional)**を追加します。
8. **Lyrics and chords**に歌詞を、セクションごとに貼り付けます。各セクションは名前（Verse 1、Chorusなど）で始めてください。コードは任意です。音節の前に角括弧で囲んで入力します（例：`[G]Holy, holy`）。**Load from a ChordPro or text file**をクリックして、ファイルから読み込むこともできます。

**Chart preview**には、教会に曲がどのように表示されるかが示されます。問題がある場合は、その下に一覧表示されます。

:::warning
ライブラリにある曲と似ている場合は、その曲へのリンク付きの警告が表示されます。同じ曲である場合は、コピーをアップロードするのではなく、その曲を開いて編集を提案してください。
:::

### 翻訳または編曲を共有する

**Translation of an existing song**または**Arrangement of an existing song**を選んだ場合：

1. **The original song**で、ライブラリをタイトルで検索し、一覧から原曲を選びます。
2. 翻訳の場合は、**Translator**を入力し、曲の新しい**Language**を選びます（原曲の言語とは異なる必要があります）。編曲の場合は、**Arranger**を入力します。
3. 残りのステップは通常どおり入力します。編曲では、原曲のタイトル、作詞作曲者、キーが初期値として入ります。

WorshipCommonsは、2つの曲のページを双方向にリンクします。原曲にはすでに旋律が含まれているため、ファイルは任意です。

:::info
ライセンスによっては、翻訳や編曲が許可されていない場合があります。そうした曲は一覧に利用不可として表示され、作曲者の許可が必要であることが示されます。原曲をご自身で公開した場合は、その翻訳を引き続き追加できます。
:::

## ステップ2: ファイル

ファイルをボックスにドロップするか、ボックスをクリックしてファイルを選択します。各ボックスには、受け付けるファイル形式とサイズの上限が表示されます。

- **Demo recording** -- MP3、WAV、またはM4A
- **Accompaniment track** -- 主旋律の歌声を除いた伴奏
- **Sheet music** -- リードシートまたはボーカル譜（PDFまたはMusicXML）
- **MIDI melody** -- 教会はブラウザで、ピアノのプレビューとして再生できます
- **Multitracks** -- パートごとに1ファイルずつ、すべて1小節目から始まるステムのZIP
- **Cover art** -- JPG、PNG、またはWebP
- **Video link** -- 教会が曲を聴ける、YouTube（またはその他）のWebアドレス

録音をアップロードする場合は、**This recording is mine (or I have the owner's permission to share it).**にチェックを入れます。

## ステップ3: ライセンス

まず、何を提供するかを選びます。**The composition**（曲のみ）、または**The composition and a master recording**（曲とマスター音源）のいずれかです。

次に、**Composition license**を選びます。どのオプションでも、曲は礼拝での使用について永続的に無料になります。違いは、作曲者が保持する権利にあります。

- **Free for worship**（推奨）-- 教会は、歌う、映写する、印刷する、配信する、移調する、編曲する、翻訳することができます。作曲者は、録音と楽譜の販売、シンクロ（映像との同期利用）、コンサート、ラジオ、および曲の所有権を保持します。
- **CC BY 4.0** -- 誰でも、クレジットを表示する限り、商用利用を含むあらゆる目的で使用できます。
- **Public domain** -- 誰でも、あらゆる目的で使用できます。作曲者は何も保持しません（永続的なCC0の放棄宣言です）。

オプションの下にある**Read the license.**をクリックすると、全文を読めます。

マスター音源も提供する場合は、**Master recording**のステップが表示されます。完成したミックスをアップロードし、そのライセンスを選びます。マスター音源のライセンスは、曲のライセンスと異なっていても構いません。

## ステップ4: 確認

内容を確認し、すべてのチェックボックスにチェックを入れて、以下を確認します。18歳以上であること、曲を作詞作曲したこと（または著作権を管理していること）、すべての共作者が同意していること、出版社や権利団体がこの許諾を行う権利を奪っていないこと、礼拝での使用は永久であることを理解していること、そして歌詞と旋律はAIによって生成されたものではなく、人が作成したものであることです。

:::warning
後に曲の削除を求めた場合でも、教会はすべての複製を保持することができます。教会に永続的に提供してもよい曲だけを共有してください。
:::

## 審査への提出

1. **Add it to the commons**をクリックします。不足している項目がある場合は、ボタンの上に一覧が表示されます。項目をクリックすると、その箇所に移動します。
2. **Thank you — it's in review**と表示されるまで待ちます。

**My submissions**で曲の状況を確認できます。審査担当者が変更を依頼すると、ステータスは**Changes requested**に変わり、**Continue**をクリックしたときにフォーム上部に担当者のメモが表示されます。承認されると、**Live**と表示されます。
