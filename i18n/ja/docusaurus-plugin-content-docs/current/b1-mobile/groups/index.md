# グループ

<div class="article-intro">

B1 Mobileのグループ機能は、あなたにとって大切な人々や奉仕チームとのつながりを保つのに役立ちます。小グループ、聖書研究会、ボランティアチーム、奉仕団体のいずれに所属していても、グループ画面は教会コミュニティで行われているすべての活動を見渡せる場所です。

</div>

## 表示される内容

**グループ**画面を開くと、グループは訪問頻度に応じて並べられます。

- **メイングループ** -- 最も頻繁に訪れるグループは、画面上部に大きなヒーローカードとして目立つように表示されます。タップすると、そのグループの詳細ページにすぐ移動します。
- **注目のグループ** -- 次によく訪れるグループは、ヒーローカードのすぐ下に注目カードとして表示されます。普段よく利用するグループに素早くアクセスできます。
- **すべてのグループ** -- 注目のグループの下では、教会のその他のグループを参照できます。

この配置により、最も気にかけているグループに一度のタップで到達しやすくなるとともに、それ以外のグループにもアクセスできます。

## できること

グループ画面からできることは次のとおりです。

- **グループを参照する** -- 教会の参加可能なグループをスクロールして、新しいグループを見つけて参加できます。
- **グループの詳細を見る** -- グループをタップすると、投稿、メンバー、グループ情報など、そのグループのプロフィールすべてを確認できます。
- **タイムラインを追う** -- 統合タイムラインには、所属するすべてのグループの投稿や活動が一か所に表示されるので、更新を見逃しません。
- **つながりを保つ** -- グループメンバーが共有している内容を確認したり、会話を追ったり、グループのコンテンツに参加したりできます。

:::tip
グループ画面は、[ダッシュボード](../dashboard/index.md)と同じように、あなたの利用状況に合わせて変化します。よく訪れるグループほど上位に表示され、素早くアクセスできるようになります。
:::
