# グループの詳細

<div class="article-intro">

グループ画面からグループをタップすると、そのグループの詳細ページが開きます。このページでは、グループに関するすべての情報を確認でき、投稿、メンバー一覧、グループ情報などのコンテンツを操作できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobile をインストール](../getting-started/installing.md)し、アカウントに[ログイン](../getting-started/logging-in.md)してください
- [グループ](./index.md)画面を開いてください

</div>

## 表示される内容

グループの詳細ページには、グループの全体像が表示されます。

- **グループ情報** -- グループの名前、説明、集まりの詳細、およびグループリーダーが入力したその他の情報です。
- **投稿とタイムライン** -- このグループ専用の投稿や活動のフィードです。リーダーやメンバーが共有したお知らせ、アナウンス、会話などを確認できます。
- **メンバー** -- グループに所属しているメンバーを確認できます。一緒に活動する人を把握したり、見慣れた顔を見つけたりするのに役立ちます。

## グループのコンテンツを操作する

グループの詳細ページからは、次のようなかたちでグループとやり取りできます。

- **投稿を読む** -- グループのタイムラインをスクロールして、最新の活動に追いつけます。
- **メンバーのプロフィールを見る** -- メンバーをタップすると、[メンバーディレクトリ](../community/member-directory.md)でそのメンバーのプロフィール情報を確認できます。
- **最新情報をチェックする** -- 定期的に確認すると、グループリーダーや他のメンバーからの新しい投稿、アナウンス、更新情報を見逃さずに済みます。

## グループ詳細を開く

1. B1 Mobile で**グループ**画面を開きます。
2. 任意のグループをタップします。おすすめのヒーローグループ、注目のカード、リスト内のどのグループでも構いません。
3. グループの詳細ページが開き、すべてのコンテンツと情報が表示されます。

:::tip
最もよく見るグループは、グループ画面の上部にヒーローカードとして表示されます。お気に入りのグループには、いつでもワンタップでアクセスできます。
:::
