# グループのタイムライン

<div class="article-intro">

B1 Mobile の「グループ」画面には、所属するすべてのグループの活動を1つのフィードにまとめたタイムラインがあります。グループを1つずつ確認しなくても、このフィードをスクロールするだけで、すべての出来事を把握できます。

</div>

:::info
グループのタイムライン機能は、改善作業のため一時的に利用できません。その間も、「グループ」画面から個々のグループを閲覧することはできます。
:::

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobile をインストール](../getting-started/installing)し、アカウントに[ログイン](../getting-started/logging-in)する
- 教会の少なくとも1つのグループのメンバーであること

</div>

## 仕組み

グループのタイムラインには、所属するすべてのグループの投稿、会話、更新情報が統合されます。グループのリーダーやメンバーがコンテンツを共有すると、時系列順にタイムラインに表示されます。そのため、グループを切り替えなくても、グループでの活動全体を一度に確認できます。

## タイムラインに表示される内容

タイムラインには、所属するグループのさまざまなコンテンツが表示されます。

- **投稿** -- グループのリーダーやメンバーが共有したメッセージや更新情報。
- **会話** -- グループ内で進行中のディスカッション。
- **更新** -- お知らせ、イベントのリマインダー、その他グループでの活動。

タイムラインの各項目には投稿元のグループが表示されるため、読んでいる内容がどのグループの話題なのかがすぐにわかります。

## 最新情報の確認

タイムラインは、教会のコミュニティとのつながりを一目で確認するのに便利です。活用のためのヒントをいくつかご紹介します。

- **定期的に確認する** -- 「グループ」画面を開き、タイムラインをスクロールして最近の活動をチェックしましょう。
- **詳細を見る** -- 気になる投稿があれば、その投稿またはグループ名をタップすると、[グループの詳細ページ](./group-details)で詳しい情報を確認できます。
- **すべてを一か所で** -- グループごとに移動する必要はありません。タイムラインがすべての活動を集めて表示します。

:::info
タイムラインに表示されるのは、教会に関連付けられたグループの活動のみです。投稿が表示されない場合は、グループに最近の活動がないか、まだどのグループにも参加していない可能性があります。
:::

:::tip
[プッシュ通知](../community/notifications.md)を有効にすると、アプリを使用していないときでも、グループに新しい投稿があればお知らせを受け取れます。
:::

- [通知](../community/notifications.md) -- グループの活動に関する通知を受け取る
