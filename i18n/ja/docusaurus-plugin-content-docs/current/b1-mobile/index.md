# B1 Mobile（非推奨）

:::danger 非推奨 — 代わりに B1.church をご利用ください
iOS および Android 向けのネイティブアプリ B1 Mobile は**非推奨**となり、開発も終了しています。その機能は現在、**B1.church プログレッシブウェブアプリ（PWA）**で提供されています。`https://yourchurchname.b1.church` からアクセスでき、iPhone や Android のホーム画面に追加できます。App Store からのダウンロードは不要で、同じメンバーポータルの機能をお使いいただけます。

**教会のメンバーの方へ：** 代わりのアプリを携帯電話に設定する方法は、[アプリとしてインストール（PWA）](../b1-church/getting-started/installing-pwa.md)をご覧ください。

**教会の管理者の方へ：** メンバーには App Store や Google Play のリンクではなく、教会のサイト（`https://yourchurchname.b1.church`）をご案内ください。どのページからでも PWA をインストールできます。

以下のページは、従来のネイティブアプリを引き続き使用している教会向けに参考として残しています。
:::

<div class="article-intro">

B1 Mobile は、iOS と Android で B1.church を利用するためのコンパニオンのネイティブアプリでした。教会のメンバーが外出先でも、グループ、献金、チェックイン、奉仕計画、メンバーディレクトリ、非公開メッセージ、説教、聖書、今日の聖句、レッスンなどを利用できました。

</div>

このアプリでは、B1.church で使用しているものと同じ ChurchApps アカウントを使用しました。ログインして教会を選択すると、アプリは教会のブランディングと設定に合わせて表示を調整しました。複数の教会に所属している場合は、いつでも教会を切り替えることができました。

B1 Mobile はプッシュ通知に対応しており、教会やグループからの重要な更新を見逃さないようにできました。ホーム画面のダッシュボードは利用状況に応じて内容が変わり、よく使う機能が上部に表示され、すぐにアクセスできました。

## 主な機能

- **グループ** -- 所属するグループを表示し、会話に参加して、グループのメンバーとつながり続けられます。
- **献金** -- スマートフォンから直接教会に献金できます。
- **イベント** -- 今後のイベントを閲覧し、スマートフォンから直接登録できます。
- **チェックイン** -- 礼拝やイベントに、自分と家族のチェックインができます。
- **奉仕計画** -- 今後の礼拝の計画、割り当てられたボランティアの役割を確認し、空いている役割に申し込めます。
- **メンバーディレクトリ** -- 教会のディレクトリを閲覧し、メンバーのプロフィールを表示できます。
- **メッセージ** -- 他の教会のメンバーと非公開メッセージを送受信できます。
- **説教** -- 教会の説教を視聴または聴くことができます。
- **聖書** -- アプリ内で聖書を読むことができます。
- **今日の聖句** -- 毎日の聖句で一日を始められます。
- **レッスン**（*非推奨 — [FreePlay](/docs/freeplay/) に置き換え*）-- 以前は Lessons.church のレッスンをアプリ内に埋め込むために使用されていました。
