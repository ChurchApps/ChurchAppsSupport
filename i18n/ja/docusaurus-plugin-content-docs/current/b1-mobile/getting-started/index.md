# はじめに

:::danger B1 Mobile は非推奨です
ネイティブアプリの B1 Mobile は、[B1.church Progressive Web App (PWA)](../../b1-church/getting-started/installing-pwa.md) に置き換えられました。新規ユーザーは、App Store や Google Play から B1 Mobile をダウンロードする代わりに、`https://yourchurchname.b1.church` の任意のページから PWA をインストールしてください。
:::

<div class="article-intro">

B1 Mobile の利用開始には数分しかかかりません。アプリをダウンロードして ChurchApps アカウントでサインインし、所属する教会を選択すれば、すぐに使い始められます。

</div>

## クイックスタート

1. [App Store](https://apps.apple.com)（iOS）または [Google Play ストア](https://play.google.com)（Android）から**アプリをダウンロード**します。「B1.church」で検索してください。
2. 既存の ChurchApps アカウントで**ログイン**します。B1.church で使用しているものと同じメールアドレスとパスワードです。アカウントがまだない場合は、**登録**をタップして作成してください。
3. 教会の名前で検索して**所属する教会を選択**します。結果を表示するには、少なくとも 3 文字を入力してください。
4. **ダッシュボードを確認**します。パーソナライズされたホーム画面には、教会が提供している機能へのクイックリンクが表示されます。

これで完了です。教会を選択すると、アプリに教会のブランディング、ナビゲーションリンク、コンテンツが読み込まれます。教会が有効にしているグループ、献金、チェックインなどの機能を使い始められます。
