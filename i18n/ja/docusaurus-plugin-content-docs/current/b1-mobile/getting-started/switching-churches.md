# 教会の切り替え

<div class="article-intro">

複数の教会に所属している場合、B1 Mobileでは簡単に教会を切り替えられます。ChurchAppsを利用しているすべての教会で同じアカウントが使えるため、ログインは1つだけで済みます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobileをインストール](./installing)して、アカウントに[ログイン](./logging-in)してください

</div>

## 教会の切り替え方法

1. 左上にある**ハンバーガーアイコン**（横線が3本のアイコン）をタップして、ドロワーメニューを開きます。
2. ドロワーのヘッダーにある、現在の教会名が表示されたボタンをタップします（教会が選択されていない場合は**教会を探す**と表示されています）。
3. **教会検索**画面が表示されます。最近訪れた教会が上部に表示されるので、すばやく選択できます。
4. 最近の教会をタップして切り替えるか、検索欄に入力して別の教会を探します。

教会を切り替えると、アプリはその教会のブランディング、ナビゲーションリンク、コンテンツで再読み込みされます。[ダッシュボード](../dashboard/)、[グループ](../groups/)、その他のデータも、新しく選択した教会の内容に切り替わります。

## 教会の検索

教会検索画面の検索欄に、教会名を3文字以上入力してください。一致する教会が下のリストに表示されます。選択したい教会をタップしてください。

:::info
結果が表示されない場合は、別の表記を試すか、教会名の一部だけを短く入力してみてください。検索はChurchAppsに登録されている教会名を対象に行われます。
:::

## 最近の教会

教会検索画面には、以前訪れた教会が記憶されています。検索語を入力していない場合は、最近の教会が自動的に表示されます。普段よく利用する教会へすばやく戻ることができます。

:::tip
教会を切り替えるために、ログアウトして再度ログインする必要はありません。ChurchAppsのアカウントは1つで、すべての教会で使えます。教会検索画面から別の教会を選ぶだけで準備完了です。
:::
