# アプリのインストール

:::danger B1 Mobile は非推奨です。代わりに PWA をインストールしてください
ネイティブアプリの B1 Mobile は、現在はアップデートされていません。代わりに、教会のサイト（`https://yourchurchname.b1.church`）から **B1.church Progressive Web App（PWA）** をインストールすることをおすすめします。PWA はどのページからでもインストールできます。iOS または Android のホーム画面に数秒で追加でき、ネイティブアプリのすべての機能を利用できます。

手順については、[アプリとしてのインストール（PWA）](../../b1-church/getting-started/installing-pwa.md)をご覧ください。
:::

<div class="article-intro">

B1 Mobile は iOS と Android の両方のデバイスで利用できます。アプリは無料で、インストールもすぐに終わるので、教会とのつながりをすぐに始められます。

</div>

## ダウンロード

- **iOS** -- iPhone または iPad で **App Store** を開き、**B1.church** を検索します。**入手** をタップしてダウンロードとインストールを行います。
- **Android** -- Android デバイスで **Google Play ストア** を開き、**B1.church** を検索します。**インストール** をタップしてダウンロードとインストールを行います。

最初の検索で結果が表示されない場合は、「B1 Mobile」で検索してみてください。

## インストール後

アプリをインストールしたら、ホーム画面から開きます。教会を検索して選択できる教会検索画面が表示されます。すでに ChurchApps のアカウントをお持ちの場合は、すぐに[ログイン](./logging-in)できます。お持ちでない場合は、ログイン画面からアカウントを作成できます。

アプリがプッシュ通知の許可を求めてきます。教会やグループからの最新情報を受け取れるように、通知を許可することをおすすめします。

:::tip
セットアップ時にプッシュ通知の許可を求められたら、許可してください。これにより、[グループの活動](../groups/group-timeline.md)、[メッセージ](../community/messaging.md)、[奉仕の割り当て](../serving/viewing-plans.md)について、タイムリーな更新を受け取れるようになります。
:::

## アプリの更新

B1 Mobile は、新機能や改善を含む更新を定期的に受け取ります。通常はデバイスがアプリを自動的に更新しますが、手動で確認することもできます。

1. iOS の場合は **App Store**、Android の場合は **Google Play ストア** を開きます。
2. **B1.church** を検索します。
3. 更新がある場合は、**アップデート** をタップします。

:::info
B1 Mobile は、Apple デバイスでは iOS 14 以降、Android デバイスでは Android 6.0 以降が必要です。
:::

## 代わりに PWA を使用する

ネイティブアプリの B1 Mobile は非推奨となり、**B1.church Progressive Web App（PWA）** に置き換えられました。PWA は Safari または Chrome からインストールでき、App Store からのダウンロードは不要です。新規インストールではすべて PWA をおすすめします。手順については、[アプリとしてのインストール（PWA）](/docs/b1-church/getting-started/installing-pwa)をご覧ください。
