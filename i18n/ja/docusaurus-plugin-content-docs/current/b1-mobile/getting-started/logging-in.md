# ログイン

<div class="article-intro">

B1 Mobileでは、B1.churchやその他のChurchAppsの製品で使用しているChurchAppsアカウントをそのまま使用します。すでにアカウントをお持ちの場合は、既存のメールアドレスとパスワードでサインインできます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- iOSまたはAndroidデバイスに[B1 Mobileをインストール](./installing)してください

</div>

## ログインの方法

1. B1 Mobileアプリを開きます。
2. ドロワーメニューまたはログインのプロンプトから**ログイン**を選択します。
3. **メールアドレス**と**パスワード**を入力します。
4. **サインイン**をタップします。

サインインすると、[ダッシュボード](../dashboard/)に移動します。まだ教会を選択していない場合は、教会を検索して選択するよう求められます。

## 新規アカウントの作成

ChurchAppsアカウントをまだお持ちでない場合は、アプリ内で直接作成できます。

1. ログイン画面の下部にある**登録**リンクをタップします。
2. **名**、**姓**、**メールアドレス**を入力します。
3. ご入力いただいた情報に一致する教会が見つかった場合、フォームに教会が自動で入力されます。
4. **登録**をタップします。
5. 仮のパスワードが記載されたメールが届いていないか確認します。
6. アプリに戻り、**ログイン**をタップして、メールアドレスとメールに記載された仮のパスワードでサインインします。

初めてログインした後は、[プロフィール設定](../profile/editing-profile.md)からパスワードを変更できます。

:::info
まだ登録されていないメールアドレスでログインしようとすると、アカウントを作成できる登録画面に自動的に移動します。
:::

:::warning
登録メールが数分以内に届かない場合は、迷惑メールフォルダを確認してください。
:::

## パスワードを忘れた場合

パスワードを忘れた場合は、ログイン画面で**パスワードをお忘れですか？**をタップし、メールアドレスを入力します。15分間有効な**6桁の確認コード**が記載されたメールが届きます。確認画面でコードを入力してサインインし、その後[プロフィール設定](../profile/editing-profile.md)からパスワードを更新してください。

:::warning
確認コードの入力を5回間違えるとコードがロックされます。その場合は、パスワードをお忘れの場合の画面に戻り、新しいコードをリクエストしてください。
:::

## ログイン状態の維持

B1 Mobileは、セッション間でサインイン状態を維持します。アプリを開くたびにログインし直す必要はありません。何らかの理由でサインアウトされた場合は、メールアドレスとパスワードで再度ログインしてください。

## ログアウト

アプリからログアウトするには:

1. 左上にある**ハンバーガーアイコン**（横線3本）をタップして、ドロワーメニューを開きます。
2. ドロワーメニューの一番下までスクロールします。
3. **サインアウト**をタップします。

サインアウトされ、いつでも認証情報を使って再度ログインできます。
