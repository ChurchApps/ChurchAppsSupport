# チェックイン

<div class="article-intro">

B1 Mobileを使えば、スマートフォンから自分と家族の礼拝出席チェックインを行えます。受付の端末で並ぶ必要がなく、教会の建物に入る前に出席を記録できます。

</div>

## 仕組み

チェックインの手順は簡単な複数のステップで構成されており、礼拝を選択し、出席する人を選び、それぞれのグループを割り当てるまで案内されます。確認すると、出席は自動的に記録されます。

## はじめに

チェックインにアクセスするには、B1 Mobileの**チェックイン**セクションを開きます。この機能を使うにはログインしている必要があります。サインインしていない場合は、まず[ログイン](../getting-started/logging-in)するよう求められます。

:::info
チェックイン機能を使うには、教会が管理設定で礼拝と出席グループを設定している必要があります。チェックイン画面を開いても礼拝が表示されない場合、教会でこの機能がまだ設定されていない可能性があります。サポートが必要な場合は、教会の管理者にお問い合わせください。
:::

## できること

- **家族のチェックイン** -- 出席する家族を選択し、全員の出席をまとめて記録します。家族の管理については[世帯](../profile/household.md)をご覧ください。
- **礼拝と時間の選択** -- 教会が設定した利用可能な礼拝と時間帯から選択します。
- **グループの割り当て** -- 礼拝ごとに、メイン礼拝、キッズルーム、ユースグループなど、適切なグループに各人を配置します。
