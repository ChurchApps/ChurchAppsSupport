# セルフチェックイン

<div class="article-intro">

B1 Mobile からのチェックインは、数回の操作で完了するシンプルな手順です。キオスクの列に並ぶことなく、数タップで自分と世帯のメンバーの出席を記録できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobile をインストール](../getting-started/installing.md)し、アカウントに[ログイン](../getting-started/logging-in.md)する
- プロフィールに[世帯のメンバー](../profile/household.md)が登録されていることを確認する

</div>

## チェックインの流れ

### ステップ 1: 礼拝とお時間を選択する

チェックイン画面を開くと、利用可能な礼拝と時間の一覧が表示されます。これらは教会が設定したもので、「日曜日 午前 9:00」や「水曜日 夕方 6:30」などの選択肢が含まれている場合があります。

1. 利用可能な礼拝の選択肢を確認します。
2. 参加する礼拝と時間をタップします。

### ステップ 2: 世帯のメンバーを選択する

礼拝を選ぶと、世帯のメンバーの一覧が表示されます。

1. 世帯のメンバーの一覧を確認します。
2. 礼拝に参加する人を一人ずつ選択します。

全員をチェックインさせる必要はありません。実際に出席している人だけを選択してください。

### ステップ 3: グループを割り当てる

選択した人ごとに、その礼拝でのグループを割り当てます。グループには、「メインの礼拝」「キッズルーム 1」「キッズルーム 2」「ユースグループ」などの選択肢があります。

1. 選択した世帯のメンバーごとに、適切な**グループ**をタップして選びます。
2. 年齢や役割に合ったグループに、それぞれ正しく割り当てられていることを確認してください。

### ステップ 4: 確認

出席するすべての人のグループを割り当てたら、チェックインを完了します。

1. 選択内容に誤りがないか確認します。
2. チェックインを確定します。
3. 出席が記録されたことを知らせる確認画面が表示されます。

## 知っておきたいこと

- アカウントに紐づいている世帯のメンバーだけをチェックインできます。一覧に表示されない人がいる場合は、教会の管理者に依頼して、[世帯](../profile/household.md)に追加してもらってください。
- チェックイン画面に礼拝が表示されない場合、現時点でチェックイン用に設定された礼拝がない可能性があります。
- 確定する前に選択を変更したい場合は、前の画面に戻って選び直すことができます。

:::warning
確定する前に、礼拝の時間とグループの割り当てが正しいことを必ず確認してください。出席が記録された後の変更は、教会の管理者が行う必要がある場合があります。
:::

:::tip
教会へ向かう途中にチェックイン画面を開いておくと、到着後すぐにチェックインできます。手続きは数秒で終わります。
:::
