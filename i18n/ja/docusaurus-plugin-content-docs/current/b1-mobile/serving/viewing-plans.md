# プランの表示

<div class="article-intro">

B1 Mobile のプラン画面では、奉仕スケジュールの全体像を確認できます。次の割り当てをすばやく見つけたり、過去の奉仕履歴を振り返ったりできるよう、画面は 2 つのタブに分かれています。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobile をインストール](../getting-started/installing)し、アカウントに[ログイン](../getting-started/logging-in)してください
- 教会の管理者から、少なくとも 1 つの奉仕プランに割り当てられている必要があります

</div>

## 自分のプランにアクセスする

1. 画面下のナビゲーションで **奉仕** をタップします。
2. プラン画面が開き、上部に **今後** と **過去** の 2 つのタブが表示されます。

## 「今後」タブ

**今後** タブは、次に予定されている奉仕を確認するための画面です。上部には、次の割り当てを示すヒーローカードが表示されます。プラン名、日付、担当する役割が含まれます。これにより、いつ奉仕が必要かを一目で把握できます。

ヒーローカードの下には、各ステータスの割り当て件数をまとめた統計が表示されます。

- **依頼済み** -- 奉仕を依頼されていますが、まだ返答していない状態です。
- **確定** -- 割り当てを承諾した状態です。
- **保留中** -- 割り当てについて、さらに対応が必要な状態です。

画面をさらに下にスクロールすると、今後の奉仕時間がすべて、日付、役割、ステータスとともに表で表示されます。

## 「過去」タブ

**過去** タブをタップすると、これまでの奉仕履歴が表示されます。これまで奉仕したプランが、新しい順に並んでいます。奉仕の積み重ねを確認するのに役立ちます。

## プランの詳細を表示する

今後のプランでも過去のプランでも、任意のプランをタップすると詳細が開きます。詳細画面には次の内容が含まれます。

- **礼拝の流れ** -- 時間と項目の詳細を含む、礼拝の完全な順序です。礼拝の流れを把握できます。
- **自分の割り当て** -- 担当する役割、必要な時間、現在のステータスです。
- **チームの割り当て** -- プランで奉仕する全員の概要です。ほかに誰がチームにいるかを確認できます。

## プランを印刷する

プランの詳細はオフラインでの確認用に印刷できます。プランの詳細画面で **印刷** オプションを使うと、礼拝の流れと割り当てを印刷用の形式で出力できます。リハーサル、舞台裏での確認、紙の資料を希望するチームメンバーへの共有に便利です。

:::tip
**今後** タブを定期的に確認して、スケジュールを把握しておきましょう。ヒーローカードには常に次の予定が表示されるため、アプリを開くだけで次にいつ奉仕するかがすぐにわかります。
:::

:::info
新しいプランに割り当てられたときや、割り当てのステータスが変わったときには、[プッシュ通知](../community/notifications.md)が届きます。更新を見逃すことはありません。
:::
