# ボランティア登録

<div class="article-intro">

B1 Mobile から、募集中のボランティア枠を確認し、今後の礼拝への登録を直接行えます。どの枠に空きがあるか、残りの定員が何人かを確認し、数回タップするだけでチームに参加できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobile をインストール](../getting-started/installing)し、アカウントに[ログイン](../getting-started/logging-in)してください
- 教会の管理者が、少なくとも1つの枠で自己登録を有効にしている必要があります

</div>

## ボランティアの募集を確認する

1. アプリのナビゲーションから **Volunteer** セクションを開きます。
2. 空きのある今後の礼拝プランの一覧が表示されます。教会が各プランの種類ごとに直近1週間分のみを表示している場合、現在の週が過ぎると次の週のプランが表示されます。
3. 各プランのカードには次の内容が表示されます:
   - **プラン名**と**礼拝日**
   - 登録済みの枠の合計を示す**全体の進捗バー**
   - **ステータス** -- 残りの空き枠の数。すべて埋まっている場合は「Full」と表示されます
   - 各役割と残りの空き枠数を示す**枠のチップ**
4. **View and Sign Up** をタップすると、そのプランのすべての枠を確認できます。

## 枠に登録する

1. プランをタップして詳細を開きます。
2. 枠はカテゴリごとにまとめられています(例: 「Band」「Hospitality」「Kids Ministry」)。
3. 各枠には、役割名、説明、利用可能な枠数が表示されます。
4. 希望する枠の横にある **Sign Up** をタップします。
5. 確認のアラートが表示されます: 「You're signed up! Thank you for volunteering.」
6. 登録が完了すると、その枠に緑色のインジケーターが表示されます。

:::info
枠に登録するにはログインが必要です。必要な場合、アプリからログインを求める表示が出ます。
:::

## 登録を取り消す

1. 登録した枠を探します -- 緑色の「You're signed up」インジケーターが表示されています。
2. **Remove** をタップします。
3. 本当によろしいか確認するダイアログが表示されます。
4. 確定すると、その枠から自分を外すことができます。

## 締め切りと定員

- **締め切り** -- 教会によっては、礼拝の前に締め切り時刻が設定されている場合があります。締め切りを過ぎると、登録や登録の取り消しはできません。締め切りを過ぎたプランの上部にはバナーが表示されます。
- **定員** -- 各枠には登録できる人数の上限があります。定員に達すると、登録ボタンが無効になります。キャンセルがあれば、枠は再び空きになります。

:::tip
新しいボランティアの募集や担当の変更について最新情報を受け取るには、[プッシュ通知](../community/notifications.md)を有効にしてください。
:::
