# 奉仕

<div class="article-intro">

B1 Mobile の**奉仕**セクションでは、奉仕の予定を手軽に確認できます。礼拝チームで働く方も、入口での出迎えをする方も、キッズ・ミニストリーを手伝う方も、ここで自分がいつ予定されているのか、どの役割を担当するのかを確認できます。

</div>

## 表示される内容

- **今後の担当** -- 今後の奉仕の時間をひと目で確認できるので、次にいつ必要とされているかをいつでも把握できます。
- **過去の奉仕履歴** -- すでに奉仕した内容を振り返ることができ、長期間の関わりを記録しておけます。
- **担当ポジション** -- 割り当てられた各担当には、与えられたポジションと現在のステータス(依頼中、確定済み、または返答待ち)が表示されます。
- **ボランティアの募集** -- 空いているポジションを確認し、今後の礼拝に[自分で申し込む](./volunteer-signup)ことができます。

## はじめに

奉仕のスケジュールを確認するには、アプリ下部のナビゲーションで**奉仕**をタップします。担当の情報を見るにはログインしている必要があります。サインインしていない場合は、まず[ログイン](../getting-started/logging-in)するよう案内が表示されます。

:::info
割り当てられた予定だけが表示されます。担当が何も表示されない場合は、まだどの奉仕チームにも追加されていないということです。奉仕に参加するには、教会の管理者または奉仕リーダーにお問い合わせください。
:::
