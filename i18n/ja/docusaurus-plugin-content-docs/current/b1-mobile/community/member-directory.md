# メンバーディレクトリ

<div class="article-intro">

B1 Mobileのメンバーディレクトリでは、教会内のメンバーを閲覧・検索できます。同じグループのメンバーを探すときも、日曜日に会った人を見つけたいときも、ディレクトリを使えば簡単につながれます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobileをインストール](../getting-started/installing)し、アカウントに[ログイン](../getting-started/logging-in)してください

</div>

## ディレクトリを開く

1. アプリのナビゲーションで**ディレクトリ**を選択します。
2. ディレクトリが読み込まれ、教会のメンバーが五十音順・アルファベット順に表示されます。

## ディレクトリを閲覧する

メンバーは姓の頭文字ごとに並べられ、文字の見出し(A、B、Cなど)の下にまとめられています。リストをスクロールして、教会の仲間を閲覧できます。各項目にはメンバーの名前と写真が表示されるので、探している人を見つけやすくなっています。

## メンバーを検索する

探している人が分かっている場合は、ディレクトリ上部の検索バーを使うのが最も早い方法です。

1. 画面上部の**検索バー**をタップします。
2. 名前を入力します。
3. 入力に合わせてリストがリアルタイムで絞り込まれ、一致する結果が表示されます。

:::tip
メンバーが多い教会では特に便利です。リスト全体をスクロールする手間が省けます。名前の最初の数文字を入力すると、すぐに結果を絞り込めます。
:::

## メンバーのプロフィールを表示する

リストのメンバーをタップすると、そのプロフィールが開きます。プロフィールページには次の内容が含まれる場合があります。

- **連絡先情報** -- 電話番号、メールアドレス、教会が公開しているその他の情報。
- **家族のつながり** -- この人のプロフィールにリンクされている[世帯のメンバー](../profile/household.md)。家族をタップすると、その人のプロフィールに移動できます。

:::info
各プロフィールに表示される情報は、教会のプライバシーとディレクトリの設定によって異なります。メンバーによっては、表示されない項目もあります。メンバーは[プライバシー設定](../profile/privacy-settings.md)から自分の公開範囲を管理できます。どの情報が共有されるかについて質問がある場合は、教会の管理者にお問い合わせください。
:::
