# メッセージ

<div class="article-intro">

B1 Mobile には非公開メッセージ機能が含まれており、アプリから教会の他のメンバーと 1 対 1 で会話できます。個人の電話番号やメールアドレスを共有しなくても、手軽に連絡を取り合えます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobile をインストール](../getting-started/installing)し、アカウントに[ログイン](../getting-started/logging-in)してください

</div>

## メッセージを開く

1. アプリのナビゲーションで **メッセージ** をタップします。
2. これまでの会話が一覧表示されるので、すぐに開けます。

## 新しい会話を始める

1. メッセージ画面で、新しい会話を始めるオプションをタップします。
2. 検索欄を使って、メッセージを送りたいメンバーを探します。[メンバーディレクトリ](./member-directory)からメンバーを探すこともできます。
3. 検索結果からメンバーを選択します。
4. メッセージを入力し、**送信** をタップします。

新しい会話は会話一覧に表示されるので、後からも簡単に再開できます。

## メッセージの閲覧と送信

会話を開くと、やり取りのメッセージ全体が表示されます。各メッセージには送信者のアバターと名前が表示されるので、誰の発言かがひと目でわかります。返信するには、画面下部の入力欄にメッセージを入力し、**送信** をタップします。

## メッセージの編集

送信後に内容を訂正したい場合は、メッセージを編集できます。変更したいメッセージをタップし、編集のオプションを選んで修正し、保存してください。更新されたメッセージが、会話内の元のメッセージと置き換わります。

## 会話一覧

進行中のすべての会話は、メッセージのメイン画面に一覧表示されます。一覧には相手の名前とアバターが表示されるので、目的の会話を見つけやすくなっています。会話をタップすると開き、前回の続きから再開できます。

## 会話の削除

会話を一覧から削除したい場合は、会話の行の右側にあるゴミ箱アイコンをタップし、確認してください。会話はご自身の画面から消えますが、相手の画面には相手側のやり取りの履歴が残ります。後で同じ相手と再び話したい場合は、新しく会話を始めてください。

:::tip
メッセージ機能は、ボランティア仲間との連絡調整や、教会で知り合った人へのフォローアップ、友人の近況確認などに役立ちます。教会でのやり取りを 1 か所にまとめておけて便利です。
:::

:::info
[プッシュ通知](./notifications)を有効にすると、アプリを開いていなくても新しいメッセージが届いたときに通知を受け取れます。
:::
