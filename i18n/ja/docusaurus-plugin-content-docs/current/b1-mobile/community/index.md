# コミュニティ

<div class="article-intro">

B1 Mobile の**コミュニティ**機能を使うと、スマートフォンから教会の仲間とのつながりを保てます。他のメンバーを探したいとき、すぐにメッセージを送りたいとき、最新のお知らせを確認したいときも、すべてワンタップでアクセスできます。

</div>

## 利用できる機能

- **[Member Directory](./member-directory.md)** -- 教会のメンバーディレクトリを閲覧・検索できます。名前で人を探し、メンバーをタップすると、連絡先情報や家族のつながりを含むプロフィールを確認できます。
- **[Messaging](./messaging.md)** -- 他の教会メンバーと非公開のメッセージを送受信できます。新しい会話を始めたり、既存の会話の続きから再開したりできます。
- **[Notifications](./notifications.md)** -- グループの活動、メッセージ、奉仕の割り当て、その他教会からの重要なお知らせについて、プッシュ通知で最新情報を受け取れます。

## はじめに

コミュニティ機能を利用するにはログインが必要です。サインインしていない状態でこれらの項目を開こうとすると、[ログイン](../getting-started/logging-in.md)するよう求められます。

メンバーディレクトリ、メッセージ、お知らせには、いずれもアプリのナビゲーションからアクセスできます。これらを使えば、人を探したり、非公開でやり取りしたり、教会での出来事を把握したりするのが簡単になります。

:::info
ディレクトリで表示されるメンバーや情報は、教会のプライバシー設定によって異なります。ご自身の公開範囲は、[プライバシー設定](../profile/privacy-settings.md)画面で管理できます。共有される内容についてご不明な点があれば、教会の管理者にお問い合わせください。
:::
