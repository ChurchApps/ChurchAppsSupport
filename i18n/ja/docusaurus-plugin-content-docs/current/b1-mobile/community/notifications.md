# 通知

<div class="article-intro">

B1 Mobileでは、プッシュ通知を使って教会での出来事をお知らせします。アプリを開いて更新を確認する必要はなく、重要な情報が自動的に届きます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobileをインストール](../getting-started/installing.md)し、アカウントに[ログイン](../getting-started/logging-in.md)してください
- 端末の設定で、B1 Mobileの通知を許可してください

</div>

## 通知される内容

通知の対象には、次のような様々なアクティビティが含まれます。

- **メッセージ** -- 誰かから[個人メッセージ](./messaging.md)が届いたとき
- **グループのアクティビティ** -- 所属する[グループ](../groups/index.md)の更新、投稿、会話
- **奉仕の割り当て** -- [計画](../serving/viewing-plans.md)に割り当てられたとき、または割り当ての状態が変わったとき
- **その他の更新** -- 一般的なお知らせや、あなたに関係するアクティビティ

## 通知の確認

1. アプリの右上にある**ベルのアイコン**をタップするか、ナビゲーションの**通知**をタップします。
2. 通知画面には、最近の通知がタブ表示で一覧されます。目的のものをすばやく見つけられるように整理されています。

各通知には、更新内容の簡単な要約が表示されます。通知をタップすると、関連するコンテンツに直接移動します。たとえば、メッセージの通知をタップすると会話が開き、奉仕の通知をタップすると計画画面に移動します。

## 通知の削除

通知を読んだ後は削除して、新しい情報に集中できるようにできます。

- **通知を1件削除する** -- 通知の行の右側にあるゴミ箱のアイコンをタップすると、その通知だけが削除されます。
- **すべての通知を消去する** -- 通知一覧の上部にある**すべて消去**をタップすると、すべての通知が一度に削除されます。すべて消去される前に確認が求められます。

通知を削除しても表示が変わるだけで、元のアクティビティ（メッセージ、計画、グループの投稿）は削除されません。複数の端末で通知を有効にしている場合、ある端末で消去すると、他の端末にも同期されます。

## プッシュ通知

B1 Mobileは、アプリが開いていないときでも更新を受け取れるように、端末にプッシュ通知を送信します。プッシュ通知を受け取るには、端末の設定で B1 Mobileの通知を許可しておいてください。

### プッシュ通知の有効化

- **iOS** -- **設定** > **通知** > **B1 Mobile** の順に進み、**通知を許可**をオンにします。
- **Android** -- **設定** > **アプリ** > **B1 Mobile** > **通知** の順に進み、通知が有効になっていることを確認します。

:::warning
通知が届かない場合は、端末の設定で通知が有効になっているか確認してください。通知はアカウントに紐づいているため、アプリにログインしているかどうかも確認してください。
:::

:::tip
通知の設定は端末単位で管理できます。通知が多すぎると感じる場合は、端末の設定で通知の表示方法やタイミングを調整してください。
:::
