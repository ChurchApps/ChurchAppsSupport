# イベント

<div class="article-intro">

B1 Mobile のイベント機能では、教会の今後のイベントを閲覧し、スマートフォンから直接登録できます。教会がイベントの登録を有効にしている場合、数回タップするだけで、ご自身やご家族を登録できます。

</div>

## 登録可能なイベントを探す

登録が有効なイベントは、グループのカレンダーに表示されます。登録可能なイベントをタップすると、イベントの詳細に **登録** ボタンが表示されます。

イベントには、次のようなステータスが表示される場合があります。

- **受付中** -- 登録を受け付けており、申し込みができます。
- **受付開始前** -- 登録期間がまだ始まっていません。
- **受付終了** -- 登録の締め切りを過ぎています。
- **満席** -- 利用可能な枠がすべて埋まっています。

## 必要なもの

- [B1 Mobile をインストール](../getting-started/installing.md)し、[ログイン](../getting-started/logging-in.md)していること
- 対象のイベントで、教会がイベント登録を有効にしていること
