# イベントへの登録

<div class="article-intro">

簡単な3つのステップで、B1 Mobileから教会のイベントに直接登録できます。スマートフォンから、ご自身の登録に加えて家族の追加も行えます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobileをインストール](../getting-started/installing.md)し、アカウントに[ログイン](../getting-started/logging-in.md)してください
- イベントで登録が有効になっており、登録期間内である必要があります

</div>

## ステップ1: 情報を入力する

1. 登録が有効になっているグループカレンダーのイベントを開き、**登録**をタップします。
2. 登録画面に、イベントのタイトル、説明、日付が表示されます。
3. ログインしているため、フォームにはアカウントでの登録であることが表示されます。

:::info
イベントに定員がある場合、残りの空き数を示すプログレスバーが表示されます。定員に達している場合は、登録できません。
:::

## ステップ2: 家族を追加する

1. 他の家族も登録する場合は、それぞれの人について**名**と**姓**を入力します。
2. **メンバーを追加**をタップすると、さらに人を追加できます（合計10人まで）。
3. 登録から外したいメンバーの横にある削除ボタンをタップします。
4. ご自身のみを登録する場合は、このステップを省略してください。

## ステップ3: 確認する

1. イベントの詳細と登録情報を確認します。
2. 登録を確定します。
3. イベントの詳細と登録したすべての人が記載された確認メッセージが表示されます。

また、アカウントに関連付けられたメールアドレスに**確認メール**が届きます。

## 登録のキャンセル

キャンセルが必要な場合は、教会の管理者に連絡してください。管理者はB1 Adminの登録ページからキャンセルできます。
