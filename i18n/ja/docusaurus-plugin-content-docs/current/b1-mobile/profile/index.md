# プロフィール

<div class="article-intro">

B1 Mobile のプロフィールでは、ご自身の個人情報、世帯、プライバシー設定を管理できます。ここで更新した内容はすべての ChurchApps サービスに反映されるため、変更は一か所で行うだけで済みます。

</div>

## プロフィールのタブ

プロフィール画面はいくつかのタブで構成されています。

### プロフィール

**プロフィール**タブでは、氏名、連絡先、プロフィール写真などの個人情報を確認・編集できます。プロフィールを最新の状態に保つことで、教会からの連絡を受け取りやすくなります。

### 世帯

**世帯**タブには、ご家族のメンバーと世帯内での役割が表示されます。この情報は、家族全員をまとめて[チェックイン](../checkin/)できる機能などで使われます。

### 公開設定

**公開設定**タブでは、[ディレクトリ](../community/member-directory.md)で他の教会メンバーに見えるご自身の情報を管理できます。どの個人情報を共有し、どの情報を非公開のままにするかを選べます。

### 保留中

**保留中**タブには、管理者の承認を待っている、ご自身が送信したプロフィールの変更内容が表示されます。

### アカウント

**アカウント**タブから、セキュリティ設定にアクセスできます。

## マイカードとマイタスク

教会から[ワークフローカード](../../b1-admin/serving/workflows.md)や[タスク](../../b1-admin/serving/tasks.md)を割り当てられている場合、**自分**画面に**マイカード**と**マイタスク**のセクションが表示され、**ホーム**には短い**フォローアップ**の一覧が表示されます。これらのセクションは、割り当てられた項目があるときだけ表示されます。完了したタスクは表示されません。割り当てられたすべてを確認するには、**すべてのカード**、**すべてのタスク**、または**すべて**をタップしてください。

カードをタップすると開きます。次の操作ができます。

- カードのステップ、期限、対象者を確認できます。ディレクトリで対象者が表示されている場合、その人の名前をタップするとディレクトリのプロフィールが開きます。
- ステップが完了したら、**完了**(またはステップの結果を示すボタン)をタップします。
- 1日、3日、または7日間、**スヌーズ**できます。
- **メモ**を読んだり追加したりできます。ここに書いたメモは、B1 Admin でスタッフがカード上で見るメモと同じものです。

通常のタスクをタップすると、誰から割り当てられたか、誰に関するタスクか、そしてメモを確認できます。通常のタスクを完了にする操作は、引き続き B1 Admin で行います。

## プロフィールへのアクセス

1. ドロワーメニューを開きます。
2. **プロフィール**をタップして、プロフィール画面を開きます。
3. 画面上部のタブを使って、各セクションを切り替えます。
