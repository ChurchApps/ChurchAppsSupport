# 世帯

<div class="article-intro">

プロフィール画面の**世帯**タブには、ご家族のメンバーが表示されます。ここで、どのメンバーが世帯に含まれているか、またメンバー同士がどのように関係しているかを確認できます。これはチェックインなどの機能に欠かせない情報です。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobile をインストール](../getting-started/installing.md)し、アカウントに[ログイン](../getting-started/logging-in.md)してください

</div>

## 表示される内容

**世帯**タブを開くと、世帯に属する人々の一覧が表示されます。各メンバーの項目には、次の内容が表示されます。

- **名前** -- その人の姓名
- **役割** -- 世帯内での役割（「世帯主」や「その他」など）
- **プロフィール写真** -- 写真がアップロードされている場合に表示されます

世帯は、教会のシステム内でご家族を結びつける共有のグループです。

## 世帯情報が重要な理由

世帯の情報は、B1 Mobile および ChurchApps 全体のいくつかの機能で使用されます。

- **チェックイン** -- [サービスやイベントにチェックイン](../checkin/self-checkin.md)する際、一人ずつではなく世帯全員をまとめてチェックインできます。
- **教会の記録** -- 教会では、世帯のデータを使って家族の記録を整理し、家族単位での連絡に役立てています。
- **ディレクトリ** -- [教会のディレクトリ](../community/member-directory.md)では、[プライバシー設定](./privacy-settings.md)によって、他のメンバーに世帯情報が表示される場合があります。

## 世帯を表示する

1. ドロワーメニューを開き、**プロフィール**をタップします。
2. **世帯**タブを選択します。
3. 世帯に含まれるご家族の一覧を確認します。

:::info
世帯のメンバーシップは、通常、教会の管理者が管理します。世帯に人を追加したり削除したりする必要がある場合は、教会の事務所にお問い合わせください。
:::

## 情報を最新の状態に保つ

ご家族の詳細情報を更新する必要がある場合は、本人が[自分のプロフィールを編集](./editing-profile.md)することも、教会の管理者に変更を依頼することもできます。世携情報を正確に保つことで、ご家族全員が[チェックイン](../checkin/index.md)などの機能をスムーズに利用できます。
