# プロフィールの編集

<div class="article-intro">

**プロフィール**タブでは、個人情報を更新して、教会に常に正しい情報が登録されているようにできます。ここで行った変更は、B1.church やお使いの教会が利用するその他のアプリを含め、ChurchApps のすべてのサービスに反映されます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobile をインストール](../getting-started/installing)し、アカウントに[ログイン](../getting-started/logging-in)してください

</div>

## 編集できる項目

プロフィールには、次の個人情報が含まれます。

- **名と姓** -- ChurchApps 全体で表示される名前
- **メールアドレス** -- 教会からの連絡やアカウントの復旧に使用されます
- **電話番号** -- 必要なときに教会から連絡を受けられるようにするためのものです
- **住所** -- 教会の記録に使用する自宅の住所です
- **プロフィール写真** -- [ディレクトリ](../community/member-directory.md)やアプリ全体であなたを表す画像です

## 情報の更新方法

1. ドロワーメニューを開き、**プロフィール**をタップします。
2. **プロフィール**タブが選択されていない場合は、そのタブを選択します。
3. 更新したい項目をタップし、内容を変更します。
4. 編集が終わったら、変更を保存します。

更新された情報は自動的に同期されます。あなたのプロフィールを閲覧できる人(あなたの[プライバシー設定](./privacy-settings)による制限があります)には、新しい情報がすぐに表示されます。

:::tip
メールアドレスと電話番号は最新の状態に保ってください。教会はこの情報を使って、重要なお知らせやリマインダーを送信します。
:::

## プロフィール写真

**プロフィール**タブから、プロフィール写真を追加または変更できます。写真は、[メンバーディレクトリ](../community/member-directory.md)、グループのメンバー一覧、そしてプロフィールが表示されるその他の場所に表示されます。

## ChurchApps 全体での変更

ChurchApps のすべてのサービスは同じアカウントシステムを共有しているため、B1 Mobile で行った変更は、[B1.church](../../b1-church/)、教会の管理ツール、そして接続されているその他のサービスにすぐに反映されます。それぞれの場所で個別に情報を更新する必要はありません。

:::info
教会によっては、特定のプロフィール変更に管理者の承認が必要な場合があります。更新内容がすぐに表示されない場合は、プロフィール画面の**保留中**タブで状況を確認してください。
:::
