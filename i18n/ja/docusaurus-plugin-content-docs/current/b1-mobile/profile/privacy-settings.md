# プライバシー設定

<div class="article-intro">

プロフィール画面の**公開範囲**タブでは、ディレクトリ内で他の教会メンバーに表示される情報を管理できます。どの個人情報を公開し、どの情報を非公開にするかはご自身で決められます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobile をインストール](../getting-started/installing)し、アカウントに[ログイン](../getting-started/logging-in)してください

</div>

## 公開範囲の管理

1. ドロワーメニューを開き、**プロフィール**をタップします。
2. **公開範囲**タブを選択します。
3. 各項目を確認し、他のメンバーに表示するかどうかを選択します。
4. 変更を保存します。

次のような項目について公開範囲を設定できます:

- **電話番号** -- 他のメンバーに電話番号を表示するかどうか
- **メールアドレス** -- [ディレクトリ](../community/member-directory.md)にメールアドレスを表示するかどうか
- **住所** -- 自宅の住所を他の人に表示するかどうか

初期設定では、教会によって一部の項目が表示または非表示になっている場合があります。これらの設定は、いつでもご自身の希望に合わせて変更できます。

:::tip
どの情報が他の人に見えるかわからない場合は、**公開範囲**タブを開いて現在の設定を確認してください。変更はいつでも後から行えます。
:::

## 保留中の変更

**保留中**タブには、管理者の承認を待っているプロフィールの更新内容が表示されます。教会によっては、特定の変更を有効にする前に管理者による確認と承認を必要とする場合があります。承認が必要な変更を行った場合は、現在の状態とともにここに表示されます。

:::info
行った変更がまだ反映されていない場合は、**保留中**タブを確認してください。教会の管理者による承認が先に必要な場合があります。
:::

## アカウント設定

**アカウント**タブでは、セキュリティ設定にアクセスできます。このタブを使用して、アカウントへのアクセスやセキュリティに関する設定を管理してください。

## プロフィールタブの概要

| タブ | 用途 |
|---|---|
| **プロフィール** | [個人情報](./editing-profile)と写真を編集する |
| **世帯** | [家族メンバーを表示する](./household) |
| **公開範囲** | ディレクトリで他の人に表示される内容を管理する |
| **保留中** | 承認待ちのプロフィール変更を確認する |
| **アカウント** | セキュリティ設定を管理する |

これらのタブを組み合わせて使うことで、ご自身の個人情報と、教会コミュニティ内での共有方法を完全にコントロールできます。
