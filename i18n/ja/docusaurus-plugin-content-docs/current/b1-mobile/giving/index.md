# 寄付

<div class="article-intro">

B1 Mobile を使えば、スマートフォンから寄付の機能をすべて利用して教会を支援できます。少額をすぐに寄付したい場合も、寄付履歴を確認したい場合も、支払い方法を管理したい場合も、必要な機能はすべて一か所にまとめられています。

</div>

## 寄付のタブ

寄付の画面は、4つのタブで構成されています。

- **概要** -- 寄付の概要を表示します。年初からの合計額、これまでの寄付回数、直近の寄付の詳細を確認できます。直近の寄付と同じ金額をすぐに寄付できる **繰り返し** ボタンもあります。
- **寄付** -- 新しく寄付を行います。基金を選び、金額を入力して、支払い情報を入力すると寄付が完了します。
- **管理** -- 保存済みの支払い方法を表示して管理します。新しいカードを追加したり、使わなくなったカードを削除したりできます。
- **履歴** -- これまでのすべての寄付を一覧で表示します。寄付の記録をすべて確認できます。

## 支払いの仕組み

B1 Mobile を通じて行われるすべての寄付は、**Stripe** で安全に処理されます。支払い情報は Stripe の安全なインフラストラクチャで扱われ、ChurchApps のサーバーに保存されることはありません。安心して寄付できます。

:::info
利用できる基金や支払い処理の設定は、教会の管理者が [B1 Admin](../../b1-admin/) で行います。アプリに寄付のオプションが表示されない場合は、教会でまだこの機能が設定されていない可能性があります。
:::

## できること

寄付の画面では、次のことができます。

- **特定の基金へ寄付する** -- 一般基金、宣教基金、建築基金などから、寄付先の基金を選べます。
- **寄付を確認する** -- 年初からの概要を確認したり、寄付履歴をすべて見たりできます。
- **支払い方法を保存する** -- カード情報を保存しておけば、次回からの寄付がすばやく行えます。
- **寄付を繰り返す** -- 1回のタップで、直近の寄付と同じ金額をすばやく寄付できます。
