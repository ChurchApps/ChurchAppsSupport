# 寄付履歴

<div class="article-intro">

B1 Mobileでは、2つのタブで寄付の状況を明確に確認できます。**概要**タブでは要約を、**履歴**タブではすべての寄付の詳細な記録を見ることができます。これらを活用して、一年を通した皆様の献げ物の状況をご確認ください。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobileをインストール](../getting-started/installing)し、アカウントに[ログイン](../getting-started/logging-in)してください
- 履歴を確認するために、[少なくとも一度寄付](./making-donations)してください

</div>

## 概要タブ

**概要**タブでは、寄付の状況をひと目で把握できます。次の内容が表示されます。

- **年初からの合計** -- 今年これまでに寄付した合計金額です。
- **寄付の回数** -- 今年行った個々の寄付の件数です。
- **直近の寄付** -- 最新の寄付の金額や日付などの詳細です。
- **繰り返しボタン** -- 直近の寄付の横にある**繰り返し**ボタンをタップするだけで、同じ金額をもう一度寄付できます。毎回同じ金額を献げている場合に便利です。

概要タブは、寄付のセクションを開いたときの良い出発点です。現在の状況を確認でき、すぐに再度寄付することもできます。

## 履歴タブ

**履歴**タブには、過去のすべての寄付が詳細な一覧で表示されます。各項目には次の情報が含まれます。

- **日付** -- 寄付が行われた日付です。
- **基金** -- 寄付の対象となった基金です。
- **金額** -- 寄付の金額です。

一覧をスクロールすると、寄付の全記録を確認できます。一年を通した献げ物の記録を振り返る場合や、過去の特定の寄付を探す場合に役立ちます。

:::tip
**概要**タブを定期的に確認して、献げ物の目標を把握しましょう。年初からの合計を見れば、進み具合がひと目でわかります。
:::
