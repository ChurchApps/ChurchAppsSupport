# 支払い方法の管理

<div class="article-intro">

ギビングセクションの**管理**タブでは、保存済みの支払い方法を確認して管理できます。カードを保存しておくと、毎回詳細を入力し直すことなく、次回以降の寄付をすばやく行えます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobile をインストール](../getting-started/installing)し、アカウントに[ログイン](../getting-started/logging-in)してください

</div>

## 保存済みの支払い方法を確認する

**管理**タブを開くと、保存済みのすべての支払い方法が一覧で表示されます。各項目にはカードの種類とカード番号の下4桁が表示されるため、どのカードかを簡単に見分けられます。

## 新しい支払い方法を追加する

新しいカードを追加するには、次の手順に従ってください。

1. B1 Mobile の**ギビング**セクションを開きます。
2. **管理**タブをタップします。
3. 新しい支払い方法を追加するオプションをタップします。
4. カードの詳細を入力します。情報は処理のために**Stripe** へ安全に送信されます。
5. 保存が完了すると、新しいカードが支払い方法の一覧に表示されます。

保存したカードは、次回**寄付**タブから[寄付を行う](./making-donations)際に、支払いオプションとして利用できるようになります。

## 支払い方法を削除する

保存しておく必要がなくなったカードは、**管理**タブから削除できます。

1. 保存済みの支払い方法の一覧から、削除したいカードを探します。
2. そのカードの横にある削除のオプションをタップします。
3. 削除を確定します。

カードを削除すると、寄付を行う際の支払いオプションに表示されなくなります。

:::info
支払い方法を削除しても、過去の寄付には影響しません。[寄付履歴](./donation-history)もそのまま残ります。
:::

:::tip
すばやく寄付できるよう、少なくとも1つの支払い方法を保存しておくことをおすすめします。そうすると、**概要**タブの**繰り返す**ボタンを1回タップするだけで、再度寄付できます。
:::
