# 献金をする

<div class="article-intro">

B1 Mobileからの献金はすばやく簡単にできます。献金セクションの**寄付**タブで数ステップの手順に沿って進めるだけなので、どこにいても教会を支援できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobileをインストール](../getting-started/installing.md)して、アカウントに[ログイン](../getting-started/logging-in.md)する
- クレジットカードまたはデビットカードを用意しておくか、事前に[支払い方法を保存](./managing-payments.md)しておく

</div>

## 献金の方法

1. B1 Mobileで**献金**セクションを開きます。
2. **寄付**タブをタップします。
3. 献金したい**基金**を選びます。教会によっては、一般基金、宣教基金、建設基金などの基金が複数用意されている場合があります。
4. 献金したい**金額**を入力します。
5. **支払い情報**を入力します。保存済みの支払い方法がある場合は、ここで選択できます。そうでない場合は、カード情報を入力してください。
6. 献金を送信します。

献金の処理が完了すると、献金が成功したことを示す確認画面が表示されます。献金内容は**履歴**タブにも表示されます。

## 安全な支払い

すべての支払いは、信頼性が高く広く利用されている決済プラットフォームである**Stripe**を通じて処理されます。カード情報はStripeが安全に取り扱い、ChurchAppsのサーバーに保存されることはありません。財務情報が保護されていることを安心してご利用ください。

:::warning
送信する前に、献金額と基金に誤りがないか必ず確認してください。献金は即時に処理され、アプリ内から取り消すことはできません。
:::

## 同じ金額をすばやく繰り返す

前回と同じ金額で献金したい場合は、献金の手順を最初から行う必要はありません。**概要**タブには直近の献金内容と**繰り返し**ボタンが表示されます。そのボタンをタップすると、同じ金額の献金をすばやく再度送信できます。

:::tip
定期的に献金される場合は、**管理**タブで支払い方法を保存しておくと、次回からさらに早く献金できます。詳しくは[支払い方法の管理](./managing-payments.md)をご覧ください。
:::
