# 聖書

<div class="article-intro">

B1 Mobileには聖書リーダーが組み込まれているので、アプリから直接みことばを読めます。リーダーは聖書画面に埋め込まれているため、別のアプリに切り替えることなく、どの箇所にもすぐにアクセスできます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobileをインストール](../getting-started/installing.md)し、アカウントに[ログイン](../getting-started/logging-in.md)します
- 教会で聖書機能が有効になっている必要があります

</div>

## 聖書を読む

1. ドロワーメニューから**聖書**画面を開きます。
2. リーダーに既定の箇所が表示されます。
3. リーダー内のナビゲーションコントロールを使って、別の書、章、節に移動します。

聖書リーダーは、YouVersionまたは教会が設定した別のプロバイダーによって動作します。どのプロバイダーを使用していても、読書の操作方法は同じです。

## 箇所の移動

埋め込みリーダーには、みことばの中を移動するためのコントロールがあります。次のような操作ができます。

- 聖書の特定の書を選んで表示する
- 特定の章に直接移動する
- 章の中の節をスクロールして読む

リーダーは画面いっぱいに表示されるため、お使いの端末で快適に読むのに十分な広さがあります。

:::tip
聖書画面を毎日の習慣に取り入れてみてください。どこにいても手軽にみことばを読むことができます。[今日の聖句](./verse-of-the-day.md)と合わせて使うと、日々の励ましにもなります。
:::

## 利用可能な条件

聖書画面は、教会がこの機能を有効にしている場合に利用できます。ドロワーメニューに**聖書**の項目が表示されない場合は、教会の管理者がアプリに追加していない可能性があります。追加を依頼するには、教会の管理者に連絡してください。
