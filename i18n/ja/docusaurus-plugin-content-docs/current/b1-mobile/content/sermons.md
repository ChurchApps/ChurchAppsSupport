# 説教

<div class="article-intro">

説教画面では、教会で録画された説教を閲覧して視聴できます。見逃したメッセージを追いかけたり、心に響いた説教をもう一度聴いたりするのに便利な場所です。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobile をインストール](../getting-started/installing.md)し、アカウントに[ログイン](../getting-started/logging-in.md)してください
- 教会の管理ポータルで説教コンテンツが設定されている必要があります

</div>

## 表示される内容

説教画面は、2つの主要なセクションを持つタブ形式の表示になっています。

- **プレイリストタブ** -- 教会の説教プレイリスト(シリーズ)を日付順に表示します。各プレイリストには関連する説教がまとめられているため、数週間にわたるシリーズを最初から最後まで追いやすくなります。
- **最近タブ** -- 個々の説教を新しい順に一覧表示します。最新のメッセージが常に一番上に表示されます。

画面の上部には、最新の説教が注目カードとして表示され、最新のメッセージにすばやくアクセスできます。

## ライブ配信のカウントダウン

[ライブ配信](./live-streaming.md)が今後24時間以内に予定されている場合、説教画面にカウントダウンタイマーが表示されます。次の礼拝の配信開始時刻がわかるので、ライブで視聴する予定を立てやすくなります。

## 説教の視聴方法

1. ドロワーメニューから**説教**画面を開きます。
2. **プレイリスト**または**最近**タブを閲覧して、見たい説教を探します。
3. 説教をタップして開き、視聴を始めます。

プレイリストをタップすると、そのシリーズのすべての説教を表示し、見たい特定の説教を選ぶこともできます。

説教には、YouTube、Vimeo、Facebook などのプラットフォームでホストされた動画や音声が含まれている場合があります。説教をタップすると、メディアはアプリ内で直接再生されます。

## 各説教に表示される情報

各説教のエントリには、次の情報が表示されることがあります。

- **タイトル** -- 説教の名前
- **説教者** -- メッセージを語った人
- **日付** -- 説教が録画または公開された日
- **サムネイル** -- 説教のプレビュー画像

:::tip
説教画面にカウントダウンが表示されている場合は、それをタップすると、開始時に[ライブ配信](./live-streaming.md)へ直接移動できます。
:::

## 利用条件

説教画面は、教会が管理ポータルで説教コンテンツを追加している場合に利用できます。アプリに**説教**が表示されない場合は、教会でまだこの機能が設定されていない可能性があります。
