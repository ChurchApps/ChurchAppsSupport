# コンテンツ

<div class="article-intro">

B1 Mobile では、教会が共有するすべてのコンテンツに、スマートフォンから一か所でアクセスできます。教会の設定によっては、説教、ライブ配信、聖書の朗読、今日の聖句、レッスン教材などを利用できる場合があります。いずれもアプリを離れることなくご覧いただけます。

</div>

## 利用可能なコンテンツ機能

### 説教

教会で収録された説教を閲覧・視聴できます。説教はプレイリストやシリーズごとに整理されているため、過去のメッセージを探したり、現在のシリーズに沿って聴いたりするのが簡単です。

### ライブ配信

教会の礼拝ライブ放送をアプリで直接視聴できます。礼拝がライブ配信されているときは、どこにいても接続して視聴できます。

### 聖書

内蔵の聖書リーダーで御言葉を読めます。アプリを切り替えることなく、書巻、章、節を移動できます。

### 今日の聖句

毎日変わる、美しく整えられた聖書の聖句画像を表示できます。画像はデバイスの画面の向きに合わせて自動的に調整されます。

### レッスン（非推奨）

アプリ内のレッスン画面は、教室での再生には **[FreePlay](/docs/freeplay/)** に、閲覧には [Lessons.church](https://lessons.church) を直接開く方法に置き換えられました。詳しくは [Lessons の参照ページ](./lessons) をご覧ください。

## コンテンツの探し方

コンテンツ機能は、アプリのドロワーメニューから利用できます。上に挙げたすべての機能が表示されるとは限らず、どの機能を有効にするかは教会の管理者が決めています。目的の機能が見当たらない場合は、教会でまだ設定されていない可能性があります。

:::info
コンテンツ機能は、教会の管理者が [B1 Admin](../../b1-admin/) で設定します。想定している機能が表示されない場合は、教会の事務所にお問い合わせください。
:::
