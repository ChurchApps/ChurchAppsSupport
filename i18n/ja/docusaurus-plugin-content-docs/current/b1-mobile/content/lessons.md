# レッスン（非推奨）

:::danger レッスン画面はFreePlayに置き換えられました
アプリ内の**レッスン**画面は非推奨になりました。Lessons.churchのカリキュラムコンテンツは、現在はChurchAppsの無料テレビアプリ**[FreePlay](/docs/freeplay/)**で提供されています。FreePlayは教室のスクリーン、Fire TV、Apple TV、Android TVに対応しており、オフライン再生、教室でのペアリング、テレビのリモコンに適した操作性を備えています。アプリ内のレッスン画面ではこれらの機能を提供できませんでした。

スマートフォンやタブレットでカリキュラムを閲覧する必要があるボランティアや教師の方は、ブラウザで[Lessons.church](https://lessons.church)に直接サインインしてください。
:::

レッスン画面では、教会のカリキュラムと学習教材にアクセスできました。コンテンツはLessons.churchプラットフォームから提供され、B1 Mobile内に直接埋め込まれていたため、別のアプリに切り替えることなくレッスンを閲覧できました。

## レッスンへのアクセス

1. ドロワーメニューから**レッスン**画面を開きます。
2. Lessons.churchのコンテンツがアプリ内で直接読み込まれます。
3. 教会が公開しているカリキュラムを閲覧します。

どのレッスンやプログラムがここに表示されるかは、教会が設定します。表示されるのは、教会のチームがスケジュールまたは割り当てたコンテンツです。

## できること

レッスン画面を開くと、教会が設定した教材を閲覧できます。教会の設定によっては、次のようなものが見つかることがあります。

- **レッスンプラン** -- セクションとアクティビティで構成された構造化された概要
- **プレゼンテーションとメディア** -- レッスンに合わせて使用するスライド、動画、画像
- **ダウンロード可能なリソース** -- さらなる学習のためのファイルや教材

レッスン内の個別のセクションをタップすると、その内容を表示できます。ナビゲーションコントロールを使うと、セクション間を移動したり、レッスン一覧に戻ったりできます。

:::info
Lessons.churchは、B1 Mobileと連携する別のChurchAppsプラットフォームです。教会の管理者は、Lessons.churchポータルを通じてレッスンコンテンツを管理します。
:::

## 利用可能性

教会がLessons.churchを通じてカリキュラムを設定していると、レッスン画面が表示されます。ドロワーメニューに**レッスン**のオプションが見当たらない場合は、教会にレッスンコンテンツが設定されていない可能性があります。詳しくは教会の管理者にお問い合わせください。
