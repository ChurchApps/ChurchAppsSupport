# 今日のみことば

<div class="article-intro">

「今日のみことば」画面には、毎日の聖書の節が美しく整えられた画像として表示されます。アプリを開くたびに、みことばで一日を始めたり、ちょっとした励ましを得たりするための簡単な方法です。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobileをインストール](../getting-started/installing.md)して、アカウントに[ログイン](../getting-started/logging-in.md)してください
- 所属する教会で「今日のみことば」機能が有効になっている必要があります

</div>

## みことばの表示

1. ドロワーメニューから**今日のみことば**画面を開きます。
2. 画面に、本日のみことばがスタイル付きの画像で表示されます。
3. 新しいみことばは毎日自動的に表示されます。

特別な操作は必要ありません。画面を開くだけで、その日のみことばが表示されます。

## 画面の向きへの対応

みことばの画像は、端末の画面の向きに合わせて自動的に調整されます。スマートフォンやタブレットの持ち方によって、次の3つの形式のいずれかで表示されます。

- **縦向き（9:16）** — スマートフォンを縦に持ったときに最適化された表示です
- **横向き（16:9）** — タブレットやスマートフォンを横に持ったときに適しています
- **正方形（1:1）** — 画面の縦横の長さがほぼ同じ場合に使用されます

アプリは画面の向きを検出して最適な形式を選ぶため、どのように端末を持っていても、みことばは常に見やすく表示されます。端末を回転させると、画像も新しい向きに合わせて更新されます。

:::tip
「今日のみことば」を毎朝の習慣に取り入れてみてください。毎日アプリを開いて、一日を始める前に少し黙想する時間を持つことができます。
:::

## 利用について

「今日のみことば」は、B1 Mobileに組み込まれているコンテンツ機能です。ドロワーメニューに表示されない場合は、教会の管理者がアプリに追加していない可能性があります。利用を希望する場合は、教会の管理者に問い合わせてください。
