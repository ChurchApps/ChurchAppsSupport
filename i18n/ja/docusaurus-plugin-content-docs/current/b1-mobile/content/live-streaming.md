# ライブ配信

<div class="article-intro">

B1 Mobileでは、教会のライブ配信をスマートフォンから直接視聴できます。礼拝の配信中であれば、どこにいてもリアルタイムで視聴できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [B1 Mobileをインストール](../getting-started/installing)し、アカウントに[ログイン](../getting-started/logging-in)してください
- 教会でライブ配信のスケジュールが設定されている必要があります

</div>

## ライブ配信を視聴する

1. ドロワーメニューから**Stream**画面を開くか、ライブ配信の開始直前に[Sermons](./sermons)画面のカウントダウンをタップします。
2. 現在配信中の礼拝がある場合、動画プレーヤーが自動的に読み込まれ、配信が再生されます。
3. アプリ内で配信を直接視聴します。

現在ライブ配信が行われていない場合、画面にはオフラインのコンテンツや次回の礼拝に関する情報が表示されることがあります。

## ライブ配信画面への移動

ライブ配信にアクセスする方法は2つあります。

- **ドロワーメニュー** -- ドロワーメニューを開き、**Stream**をタップすると、ライブ配信画面に直接移動します。
- **Sermons画面** -- 24時間以内にライブ配信が予定されている場合、[Sermons](./sermons)画面にカウントダウンが表示されます。配信が始まると、そこからライブ配信画面に移動できます。

## 礼拝の前後

教会では、配信を視聴できる時間帯を個別に設定しています。礼拝が始まる前にカウントダウンやオフラインのメッセージが表示されることがあります。配信が終了すると、ライブ配信画面はオフラインの状態に戻ります。

:::info
ライブ配信画面にカウントダウンやオフラインのメッセージが表示されている場合、次回の礼拝はまだ始まっていません。表示されている礼拝の時間にもう一度確認してください。
:::

## 利用条件

ライブ配信画面は、教会でライブ配信のスケジュールが設定されている場合に利用できます。アプリのドロワーメニューに**Stream**が表示されない場合、教会でライブ配信が設定されていない可能性があります。詳しくは教会の管理者にお問い合わせください。

:::tip
次回のライブ配信がいつ始まるかは、[Sermons](./sermons)画面のカウントダウンタイマーで確認できます。
:::
