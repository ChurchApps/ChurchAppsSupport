# ダッシュボード

<div class="article-intro">

ダッシュボードは、B1 Mobile のホーム画面です。教会が提供している機能に素早くアクセスでき、アプリの使い方に応じて並べられます。利用するにつれてレイアウトが変わり、よく使う機能が目立つ位置に表示されます。

</div>

:::info このページは非推奨のネイティブアプリについて説明しています
B1 Mobile に代わる B1.church アプリ（`/mobile`）のホーム画面は、動作が異なります。最新の説教、今後の奉仕、所属グループ、今後のイベント、献金などのセクションが表示され、教会が写真を設定したタブには写真のタイルも表示されます。詳しくは [B1Appのナビゲーション](../../b1-church/getting-started/navigating.md#home) をご覧ください。管理者は [モバイルアプリ設定](../../b1-admin/settings/mobile-app.md#home-screen-tiles) で、これらの写真タイルのレイアウトを選択できます。
:::

## ようこそセクション

ダッシュボードの上部には、ようこそメッセージと教会のロゴ（ロゴが未設定の場合は教会名）、そして「つながりを保つ」というキャッチコピーが表示されます。このセクションで、現在表示している教会を確認できます。

## 注目のリンク

ようこそセクションの下には、最もよく利用する機能が、背景画像と機能名付きの大きな**ヒーローカード**として表示されます。これは最も頻繁に使う機能で、ワンタップですぐに開けるよう一番上に配置されています。

## 注目のカード

ヒーローカードの下には、最大2つの**注目のカード**が左右に並んで表示されます。これらは2番目と3番目によく使う機能です。各カードには背景画像と機能名が表示されます。どちらかのカードをタップすると、その機能に直接移動します。

## クイックアクション

残りの機能は、注目のカードの下にある**クイックアクション**のグリッドに表示されます。各項目にはアイコンとラベルが表示されます。ここには、教会が設定したその他のナビゲーションリンクがすべて含まれ、[グループ](../groups/)や[献金](../giving/)から、[チェックイン](../checkin/)、[説教](../content/sermons.md)などまで、さまざまな機能にアクセスできます。

## レイアウトが変わる仕組み

ダッシュボードのレイアウトは、利用パターンに基づいて個人ごとに最適化されます。機能をタップするたびに、アプリはその機能を開いた回数を記録します。よく使う機能ほど、ダッシュボードの上位に移動します。

- **最もよく使う**機能が、ヒーローカードになります。
- **2番目と3番目によく使う**機能が、注目のカードになります。
- **それ以外のすべて**の機能は、クイックアクションのグリッドに表示されます。

まだアプリを使っていない場合は、教会が設定したデフォルトの順序で機能が表示されます。利用を続けると、ダッシュボードはあなたの使い方に合わせて並べ替えられていきます。

:::info
ダッシュボードに表示される機能は、教会の管理者が [B1 Admin](../../b1-admin/) で設定します。表示されるはずの機能が見当たらない場合は、教会の事務所にお問い合わせください。
:::

## ダッシュボードの更新

ダッシュボードを下にスワイプすると、更新されます。教会のリンクやコンテンツが再読み込みされ、最新の情報が表示されます。

## ナビゲーション

ダッシュボードから、アプリのあらゆる場所に移動できます。

- 左上の**ハンバーガーアイコン**（横線が3本のアイコン）をタップすると、すべてのナビゲーションオプションがあるドロワーメニューが開きます。
- 右上の**ベルアイコン**をタップすると、[お知らせ](../community/notifications.md)を確認できます。
- カードやクイックアクションの項目をタップすると、その機能に直接移動します。
