# ロールと権限

<div class="article-intro">

ロールを使うと、ChurchAppsアカウント内で各ユーザーがアクセスできる範囲を管理できます。スタッフやボランティア、その他のチームメンバーごとにカスタムロールを作成し、それぞれに適したアクセス権を与えることで、データを安全に保てます。

## ロールへのアクセス

1. B1 Adminで、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**設定**を展開します。
2. **ロール**をクリックします。
3. ロールのページには、教会に定義されているすべてのロールが表示されます。**メンバー**列には、各ロールに所属しているユーザー数が表示され、**(Everyone)** の行には **All users** と表示されます。

## ロールページの見方

ロールページは2つのパネルに分かれています。

- **左側** — 選択したロールに割り当てられているメンバーの一覧を表示します。
- **右側** — そのロールに設定できる権限の項目を表示します。

ロール名をクリックすると、そのロールのメンバーと権限を表示・管理できます。

## ロールへのユーザーの追加

1. メンバーを追加したいロールを選択します。
2. 左側の**検索欄**を使って、追加したい人物を探します。
3. 検索結果からその人物を選択します。
4. その人物はすぐにロールに追加されます。

## ロールからのユーザーの削除

1. 削除したいユーザーが含まれるロールを選択します。
2. 左側のメンバー一覧から、そのユーザーを探します。
3. 名前の横にある**削除ボタン**をクリックします。

## 権限の設定

各ロールには、B1 Adminの特定の領域へのアクセス権を付与できます。**権限を編集**パネルでは、権限が展開可能なセクションにまとめられています。セクションには、**出欠**、**コンテンツ**、**献金**、**フォームとプラン**、**レッスン**、**メッセージ**、**人とグループ**、**タスク**などがあります。**権限をフィルター**のボックスに入力すると、一致する権限だけを表示できます。

権限のチェックボックスをオンまたはオフにすると、そのロールに権限を付与したり、削除したりできます。各セクションの見出しには、そのロールが持つ権限の数（例：**5件中2件**）が表示され、チェックボックスを切り替えると数字も更新されます。

### 献金に関する権限

**献金**セクションには、次の権限があります。

- **献金の概要を表示** — 献金の概要、バッチ、ファンド、キャンペーン、献金明細のページを含む、献金セクションを表示できます。
- **献金を表示** — バッチに含まれる献金など、個々の献金を表示できます。
- **献金を編集** — 献金とバッチの追加、編集、削除、および[バッチを締めて再開する](../donations/batches.md#closing-and-reopening-a-batch)操作がすべて可能な、完全な管理権限です。
- **献金を入力** — バッチを追加し、献金を入力、編集、削除できます。ただし、対象は未締めのバッチのみです。この権限だけを持つ人は、バッチを削除したり、締めたり再開したりすることはできず、オンライン献金で入ったものを変更することもできません。
- **設定を編集** — 献金の設定を管理できます。

**献金を入力**はあるものの**献金の概要を表示**がない人には、**献金**の下で**バッチ**ページだけが表示されます。集計チームのロールには、**献金を入力**と**献金を表示**の両方を付与してください。そうすると、バッチを開いて自分が入力した献金を確認できます。詳しくは、[バッチを変更できる人](../donations/batches.md#who-can-change-a-batch)をご覧ください。

### 名前のみの閲覧

**人とグループ**セクションには、**人の名前のみを表示**という権限が含まれています。これは、人物の詳細なディレクトリにはアクセスさせずに、名前で人を探す必要があるボランティア（たとえば検索欄で人物を選ぶ場合）に使用します。この権限だけを持つ人は、次のようになります。

- 名前で人を検索でき、最近追加された人のリストを見られますが、表示されるのは各人の名前、写真、会員ステータスだけです
- メールアドレスで検索したり、連絡先を見たり、**人**ディレクトリを開いたりすることはできません

クラスの出欠を取るボランティアには、**人の名前のみを表示**と、**出欠を表示**または**出欠を編集**を組み合わせて付与してください。そうすると、そのボランティアのメニューの**人**は**グループ**を開くようになり、**すべてのグループ**の一覧から各クラスのメンバー名とセッションを確認できます。**出欠を編集**もあれば、[出欠を記録](../attendance/recording-attendance.md)したり、名前で検索して来訪者を追加したりすることもできます。名前は人物の記録へのリンクにはなりません。また、機密グループは、ボランティアがそのメンバーでない限り表示されません。

B1 Adminは、ロールが持っていない権限を必要とするリンクやボタンを非表示にします。たとえば、**すべてのグループ**の一覧は、グループを編集できる人、グループメンバーを表示できる人、または人を表示できる人のみが利用できます。また、**人の名前のみを表示**と**出欠を表示**または**出欠を編集**の両方を持つ人も利用できます（それ以外の人はダッシュボードに戻されます）。出欠の設定は**サービスを編集**がある場合にのみ表示されます。グループの**メール**ボタンは**グループメンバーを編集**の権限を持つ人にのみ表示されます（この権限はグループにメールを送信するために必要です）。グループの名簿を印刷するには**グループメンバーを表示**の権限が必要か、そのグループのリーダーである必要があります。カレンダーのイベントを削除するには**コンテンツを編集**の権限が必要です（ただし、自分が出した保留中のリクエストを取り下げる場合を除きます）。

### チェックイン用キオスクのアカウント

[B1 Checkin](../../b1-checkin/getting-started/logging-in.md)のキオスクにサインインするアカウントには、**出欠**セクションの**チェックイン**権限（または**出欠を編集**）が必要です。**チェックイン**だけがあれば、キオスクは名前や電話番号で家族を検索し、チェックインとチェックアウトを行い、子どもを迎えに来られる人を表示できます。ただし、人のディレクトリにはアクセスできません。

チェックインは、もう**(Everyone)** の行からは付与されなくなりました。ほかの権限を持つロールに所属していても、キオスクを操作できるわけではありません。キオスクのアカウントを使うには、「チェックインボランティア」などのロールに**チェックイン**を追加し、キオスクのアカウントをそのロールに入れてください。

:::warning
**ドメイン管理者**は、ChurchAppsアカウントのすべての領域に完全にアクセスできます。その権限は変更も制限もできません。このロールは、最も信頼できる管理者のみに付与してください。
:::

:::tip
「会計」には**献金**のみ、「集計チーム」には**献金を入力**と**献金を表示**、「チェックインボランティア」には**出欠**のみなど、用途に合った個別のロールを作成しましょう。これは最小権限の原則に従うもので、データの安全性を保つことにつながります。ChurchAppsがお客様の情報をどのように保護しているかについては、[データセキュリティ](./data-security.md)をご覧ください。
:::
