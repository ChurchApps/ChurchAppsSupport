# カスタムフィールド

<div class="article-intro">

**カスタムフィールド**を使うと、すべての人物レコードに独自の情報を記録できます。身元調査（バックグラウンドチェック）の有効期限、Tシャツのサイズ、バプテスマクラスの受講状況など、B1に標準のフィールドがない情報を管理できます。設定画面でフィールドを一度定義すれば、各人物のプロフィールに値を入力し、その値で検索やリストの作成ができます。単一のカスタムデータを保存するためだけに人物フォームを作成していた従来の回避策は、これで不要になります。

</div>

<h4>始める前に</h4>

- フィールドを定義したり値を入力したりするには、**People**の編集権限と**設定**エリアへのアクセスが必要です。People の閲覧権限を持つ人は値を見ることができます。詳しくは[役割と権限](./roles-permissions.md)を参照してください。
- 始める前に、何を記録したいか、どの種類（テキスト、数値、日付、はい/いいえ、選択リスト）が最も適しているかを決めておいてください。

## カスタムフィールドを開く

B1 Admin で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**設定 > 設定**を選択して、左側のリストから**カスタムフィールド**をクリックすると、**カスタムフィールド**セクションに移動します。**/settings/custom-fields** に直接アクセスすることもできます。定義済みのフィールドがすべて、**名前**と**フィールドの種類**とともに一覧表示されます。まだフィールドを作成していない場合、パネルには *「カスタムフィールドはまだ追加されていません。」* と表示されます。

## フィールドを追加する

1. **フィールドを追加**をクリックします。
2. 右側に開くエディターで**名前**を入力します。これは人物のプロフィールや検索でスタッフに表示されるラベルです（例: *身元調査の有効期限*）。
3. **フィールドの種類**を選択します:
   - **テキストボックス** — 自由形式の短いテキスト。
   - **整数** — 小数点のない数値（例: 人数）。
   - **小数** — 小数点を含めることができる数値。
   - **日付** — カレンダーの日付。
   - **はい/いいえ** — 単純なはい・いいえの回答。
   - **複数選択** — 選択リスト。この種類を選ぶと**選択肢エディター**が表示され、人が選べる各選択肢を追加できます。
4. **保存**をクリックします。

このフィールドは、すべての人物のプロフィールで利用できるようになります。

:::info
フィールドの種類は[フォームの質問](../forms/creating-forms.md)と同じものなので、B1全体で値が一貫して動作します。
:::

## フィールドを編集する

リスト内のフィールドの行をクリックすると、エディターで再度開きます。名前、種類、選択肢を変更し、**保存**をクリックします。

:::warning
すでに値が入力されているフィールドの**フィールドの種類**を変更すると（例: テキストボックスから日付へ）、以前に入力された値が新しい種類と合わない形式のまま残る可能性があります。スタッフがフィールドへの入力を始めた後は、種類の変更に十分注意してください。
:::

## フィールドを削除する

フィールドを編集用に開き、**削除**をクリックします。確認メッセージが表示されます: *「このカスタムフィールドを削除してもよろしいですか？保存されているすべての値も削除されます。」* フィールドを削除すると、フィールドと**それに保存されているすべての人物の値**が完全に削除されます。この操作は元に戻せません。

## 人物の値を入力する

カスタムフィールドが少なくとも1つ作成されると、その値は各人物のレコードにある標準の詳細情報と並んで表示されます。プロフィールの左側にある連絡先の詳細とともに表示され、その人物の他の情報と同じ編集フォームで編集します。最初のフィールドを定義するまでは、追加の項目は表示されません。

1. **People**で人物のレコードを開きます。
2. プロフィールの左側、連絡先の詳細の下にある**編集**ボタンをクリックします。
3. 編集フォームの下部にある**カスタムフィールド**エリアまでスクロールし、各フィールドの値を入力します。各フィールドには、その種類に合った入力欄が表示されます。日付フィールドには日付ピッカー、はい/いいえフィールドにははい/いいえのドロップダウン、複数選択には選択リストが表示されます。
4. **保存**をクリックします。カスタムフィールドの値は、その人物の他の詳細とともに保存されます。

プロフィールに戻ると、値が入力されているフィールドは、連絡先の詳細の下に *フィールド名: 値* の形式で表示されます（はい/いいえの回答は *はい* または *いいえ* と表示され、複数選択では選択肢のラベルが表示されます）。空欄のフィールドは非表示になります。値を削除するには、人物を編集してフィールドをクリアし、保存します。空の値は空白として保存されず、レコードから削除されます。

:::tip
典型的な活用例はボランティアの安全管理です。*身元調査の有効期限* という**日付**フィールドを作成し、各ボランティアの日付を記録したうえで、期限が過ぎた人にフラグを立てる[保存済みリスト](../people/lists.md)を作成します。
:::

## カスタムフィールドで検索し、リストを作成する

カスタムフィールドは完全に検索可能です:

1. **People**ページで、[詳細検索](../people/searching-people.md)を開きます。
2. **カスタムフィールド**カテゴリを展開します。
3. 絞り込みたいフィールドにチェックを入れ、演算子を選択して値を入力します。提供される演算子は、フィールドの種類によって異なります:
   - **テキストボックス** — 含む、一致する、で始まる、で終わる。
   - **整数 / 小数** — 等しい、より大きい、以上、より小さい、以下。
   - **日付** — 等しい、以降（より大きい）、以前（より小さい）。
   - **はい/いいえ** — はい、またはいいえに等しい。
   - **複数選択** — いずれかの選択肢に等しい、または含む。

カスタムフィールドの検索は、[リスト](../people/lists.md)として保存できます。リストは常に最新の結果を返すクエリなので、*身元調査の有効期限が今日より前* で作成したリストは、開くたびにすべての人を再チェックします。手動での更新は不要です。

## カスタムフィールドを列として表示する

全員のフィールドの値をまとめて確認するには、**People**ページの列として追加します。**表示形式**を**表**に切り替え、ページヘッダーの**列を選択**アイコンをクリックし、**カスタム**タブに切り替えて、フィールドにチェックを入れます。各人物の値が、標準の列の隣に独自の列として表示されます。詳しくは[カスタムフィールドを列として表示する](../people/searching-people.md#showing-custom-fields-as-columns)を参照してください。

## 統合時の動作

[2つの人物レコードを統合](../people/adding-people.md)すると、カスタムフィールドの値は自動的に引き継がれます。残す側の人物は自分の値を保持します。削除される側の人物だけに値があったフィールドについては、その値がコピーされるので、何も失われません。
