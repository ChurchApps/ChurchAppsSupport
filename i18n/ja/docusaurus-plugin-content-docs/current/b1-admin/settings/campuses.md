# キャンパス

<div class="article-intro">

教会の礼拝の場所が複数ある場合、**キャンパス**機能を使うと、各メンバーとグループがどの拠点に所属しているかを管理できます。設定すると、キャンパスは人物プロフィール、出席設定、人口統計ダッシュボードの選択肢として表示されます。複数拠点の教会は、B1 Admin 全体でキャンパス別に絞り込み、検索、レポート作成ができます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- キャンパスを管理するには **教会設定の編集** 権限が必要です。詳しくは [役割と権限](./roles-permissions.md) を参照してください。

</div>

## キャンパス設定を開く

B1 Admin で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（画面左上の検索バー）を開き、**設定 > 設定** を選択します。左側のリストで **キャンパス** をクリックすると、**キャンパス** セクションまでスクロールします。直接 **/settings/campuses** にアクセスすることもできます。設定済みのすべてのキャンパスが、名前、所在地、タイムゾーンとともに一覧で表示されます。

## キャンパスを追加する

1. **キャンパスを追加** をクリックします。
2. キャンパスの詳細を入力します。
   - **名前**（必須）— B1 Admin 全体で表示される名称です（例：「メインキャンパス」や「北キャンパス」）。
   - **住所** — キャンパスの番地などの住所です（参考情報として表示され、教会設定の本部住所とは別のものです）。
   - **市区町村 / 都道府県 / 郵便番号** — キャンパスの所在地です。
   - **タイムゾーン** — このキャンパスの IANA タイムゾーンです（例：*America/Chicago*）。このキャンパスの礼拝の[チェックイン時間](../attendance/setup.md#setting-a-check-in-schedule)は、このタイムゾーンで開始・終了します。**なし** に設定した場合は、教会の[タイムゾーン](./church-settings.md#time-zone)が使われます。キャンパスごとに異なるタイムゾーンにある場合に便利です。
   - **ウェブサイト** — このキャンパス独自のウェブサイトがあれば、そのURLを任意で入力します。
3. **保存** をクリックします。

## キャンパスを編集する

一覧のキャンパスの行をクリックすると、右側のパネルで編集画面が開きます。項目を更新して **保存** をクリックします。

## キャンパスを削除する

キャンパスを編集画面で開き、**削除** をクリックします。確認を求められます。キャンパスを削除しても、そのキャンパスに所属している人物は削除されません。その人物のキャンパス欄が空欄になるだけです。

## 人物をキャンパスに割り当てる

キャンパスを作成した後、スタッフは人物のプロフィールから所属キャンパスを設定できます。

1. **人物** で人物の記録を開きます。
2. **編集** をクリックします。
3. **キャンパス** のドロップダウンからキャンパスを選びます。
4. **保存** をクリックします。

人物ページから一括でキャンパスを更新することもできます。複数の人物を選択し、**一括編集** を使って、全員のキャンパス欄をまとめて設定します。

## キャンパスで絞り込む

キャンパスを設定すると、B1 Admin 全体をキャンパス別に絞り込めます。

- **人物検索** — 詳細検索でキャンパスの条件を追加するか、キャンパスに絞り込んだ[保存済みリスト](../people/lists.md)を読み込みます。
- **人口統計** — 少なくとも1人にキャンパスが設定されていると、[人口統計ダッシュボード](../people/demographics.md)にキャンパスの円グラフが表示されます。
- **出席設定** — 出席画面の各礼拝時間を、キャンパスに紐付けできます。

:::tip
単一拠点の教会では、キャンパスを設定する必要はありません。キャンパス関連の機能はすべて任意です。キャンパスが1つも存在しない場合、キャンパス欄やグラフは単に表示されません。
:::
