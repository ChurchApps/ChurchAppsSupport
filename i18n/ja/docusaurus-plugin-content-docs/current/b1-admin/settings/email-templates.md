# メールテンプレート

<div class="article-intro">

メールテンプレートでは、ウェルカムメッセージ、イベントのリマインダー、献金へのお礼など、再利用できるメール内容を保存できます。保存しておけば、あなた(または[ワークフロー](../serving/workflows.md))がワンクリックで送信できるため、毎回一から文章を書く必要がありません。同じ一覧には、グループや個人のテキストメッセージウィンドウで使うテキストメッセージテンプレートも含まれます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1 Admin の設定エリアにアクセスできる必要があります。

</div>

## メールテンプレートへのアクセス

1. B1 Admin で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)(左上の検索バー)を開き、**設定**を展開します。
2. **メールテンプレート**をクリックします。
3. 件名、カテゴリ、最終更新日を含む既存のテンプレートの一覧が表示されます。

## テンプレートの作成

1. **新規テンプレート**をクリックします。
2. 一覧で識別するための**テンプレート名**を入力し、テンプレートを整理するために**カテゴリ**を選択します(一般、イベント、グループ、献金、ウェルカム、テキスト)。テキストメッセージのテンプレートを作成する場合は、**テキスト**を選択します(下記の[テキストテンプレート](#text-templates)を参照)。
3. **件名**を入力します。
4. リッチテキストエディターを使って**本文**を書きます。
5. **保存**をクリックします。

## 差し込みフィールド

件名または本文の上にある差し込みフィールドのチップをクリックすると、カーソル位置にそのフィールドが挿入されます。先に挿入したい場所の文字をクリックしてから、チップをクリックしてください。挿入後もカーソルは同じ位置に残るため、挿入されたフィールドの直後に続けて入力できます。本文をクリックせずに本文のチップをクリックした場合、フィールドは本文の末尾に追加されます。メールが送信されると、各差し込みフィールドは受信者の実際の情報に置き換えられます。

- `{{firstName}}`、`{{lastName}}`、`{{displayName}}` -- 受信者の名前
- `{{email}}` -- 受信者のメールアドレス
- `{{churchName}}` -- 教会の名前

## テキストテンプレート

カテゴリが**テキスト**のテンプレートは、メールではなくテキストメッセージ用のプレーンテキストメッセージです。

- 件名はありません。リッチテキストエディターは、最大1,600文字まで入力できるプレーンな**テキストメッセージ**ボックスに置き換わります。
- ボックスの上にある差し込みフィールドのチップをクリックすると、`{{firstName}}`、`{{lastName}}`、`{{displayName}}`、`{{email}}`、`{{churchName}}` のいずれかがカーソル位置に挿入されます。
- テキストテンプレートは、[グループ](../groups/group-members.md#texting-group-members)または個人のテキストウィンドウにある**テンプレートを読み込む(任意)**のピッカーに表示されます。選択するとメッセージが入力され、送信前に編集することもできます。
- ワークフローの**メールを送信**アクションを含め、メールテンプレートのピッカーには表示されません。

テキストメッセージの送信には、接続済みの[テキストメッセージプロバイダー](./church-settings.md#texting)が必要です。

## テンプレートのプレビュー

**プレビュー**をクリックすると、保存または送信する前に、差し込みフィールドにサンプルデータを入れた件名と本文の表示を確認できます。

## テンプレートの使用

保存したテンプレートは、個人またはグループ宛てのメールを作成するときに選択でき、[ワークフロー](../serving/workflows.md)のアクションとしても使用できます。教会がこれらを送信するには、事前に ChurchApps チームによるグループメールの承認が一度必要です。詳しくは、[教会のグループメールを有効にする](../groups/group-members.md#turning-on-group-email-for-your-church)を参照してください。

## 編集と削除

テンプレートを更新するには、そのテンプレートの横にある**編集**アイコンをクリックします。完全に削除するには、**削除**アイコンをクリックします。
