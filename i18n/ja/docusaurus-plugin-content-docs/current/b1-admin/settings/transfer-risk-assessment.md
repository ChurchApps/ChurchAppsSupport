# 移転リスク評価

<div class="article-intro">

本書は、UK GDPR および EU GDPR に基づき、英国/EEA から米国への個人データの国際移転に関連するリスクについて、ChurchApps が行った評価を記録するものです。データ処理者として ChurchApps が保持する内部コンプライアンス記録です。

</div>

**最終レビュー日:** 2026年4月

## 1. 移転の詳細

| 項目 | 詳細 |
|---|---|
| **データ輸出者** | 英国/EEA に所在し、ChurchApps を利用する教会（データ管理者） |
| **データ輸入者** | 米国から運営する ChurchApps（データ処理者） |
| **データ主体の区分** | 教会員、出席者、訪問者、寄付者、ボランティア、子ども（保護者や管理者が管理） |
| **個人データの区分** | 氏名、メールアドレス、電話番号、郵便住所、生年月日、性別、婚姻状況、プロフィール写真、寄付記録、出席記録、グループへの所属、ボランティアの割り当て、メッセージの履歴 |
| **機微データ** | 意図的に収集しているものはありません。健康データ、生体データ、犯罪歴は保存していません。金融口座情報（クレジットカードや銀行口座）は ChurchApps では一切保存せず、Stripe が直接処理します。 |
| **移転の目的** | 教会管理ソフトウェアサービスの提供（会員管理、寄付、出席管理、コミュニケーション、ボランティアのスケジュール管理、イベント登録） |
| **移転先の国** | 米国 |
| **移転の仕組み** | EU 標準契約条項（SCC）および英国国際データ移転補遺（IDTA）を、AWS データ処理補遺を通じて組み込み |

## 2. 復処理者

| 復処理者 | 役割 | 所在地 | 移転の仕組み |
|---|---|---|---|
| **Amazon Web Services (AWS)** | インフラのホスティング、データ保存、コンテンツ配信（us-east-2 リージョン） | 米国 | SCC を含む AWS DPA（AWS サービス規約に自動的に含まれる） |
| **Stripe** | 寄付の決済処理 | 米国 | SCC を含む Stripe DPA |

クレジットカードおよび銀行口座のデータは、ユーザーのブラウザから Stripe へ直接送信され、ChurchApps のサーバーに保存されることも、ChurchApps のサーバーを経由することもありません。

## 3. リスク評価

### 3.1 暗号化

- **転送時:** ユーザーと ChurchApps のサーバー間のすべての通信は、TLS/HTTPS によって暗号化されます。
- **保存時:** AWS 上に保存されるデータは、AWS 管理の暗号化によって保存時にも暗号化されます。

### 3.2 アクセス制御

- 本番サーバーへのアクセスは、ChurchApps の理事会のメンバーである2名に限定されています。
- 開発者、ボランティア、その他の理事は、本番サーバーやデータベースにアクセスできません。
- データベースサーバーはファイアウォールの内側にあり、インターネットから直接アクセスすることはできません。
- 教会のデータは論理的に分離されており、各教会はアプリケーションレベルのアクセス制御によって、自らのデータにのみアクセスできます。

### 3.3 データの分離

データは、6つの独立したデータベース（Membership、Giving、Attendance、Messaging、Doing、Content）に分散されて保存されています。1つのデータベースが侵害されても、他のデータベースのデータが露出することはありません。たとえば、Giving データベースには寄付の金額と日付が含まれますが、寄付者の氏名や連絡先情報は含まれません（それらは Membership に保存されています）。

### 3.4 データの最小化

- クレジットカードや銀行口座の情報は保存していません（Stripe が処理します）。
- パスワードは一方向のハッシュ化によって保存されており、復元することはできません。
- 教会は、会員からどのようなデータを収集するかを管理できます。

### 3.5 データ主体の権利

ChurchApps は、教会がデータ主体からの請求に対応できるよう、技術的なツールを提供しています。

- **アクセスとポータビリティ:** 機械可読な JSON 形式での完全なデータエクスポート。
- **消去:** 6つのデータベースすべてにわたる匿名化。個人データを汎用的な値に置き換えつつ、財務報告に必要な集計記録は保持します。
- **処理の制限:** 会員ステータスを非アクティブにすると、その人物は検索、ディレクトリ、レポート、メッセージングの対象から除外されますが、記録自体は保持されます。
- **訂正:** 会員と管理者は、アプリケーションを通じて個人情報を編集できます。

### 3.6 侵害の通知

ChurchApps は、個人データの侵害を認識してから72時間以内に、影響を受ける教会へ通知することを約束します。これは[利用規約](https://churchapps.org/terms)（第11.6条）に記載されています。

### 3.7 米国政府によるアクセスのリスク

米国でホスティングされるデータに関連する主なリスクは、FISA 第702条または大統領令12333に基づき、米国の政府機関によってアクセスされる可能性です。以下の理由から、このリスクは**低い**と評価されます。

- ChurchApps が処理するのは教会の会員と出席の データであり、情報収集上の価値があるデータではありません。
- データ主体は教会の会員と出席者であり、監視プログラムの対象として一般的に狙われる区分には当たりません。
- 機微な個人データ（健康、金融口座、政治的意見など）は保存していません。
- AWS の DPA には、政府からのアクセス要請と透明性レポートに関する取り決めが含まれています。
- EU-米国データプライバシー枠組み（2023年に制定）は、認証を受けた米国の組織へのデータ移転に対して、追加的な保護措置を提供します。

## 4. 全体的なリスクの結論

本国際移転によるデータ主体へのリスクは**低い**と評価されます。以下の要素を組み合わせることで、

- 法的な移転の仕組みとしての標準契約条項
- 転送時および保存時の暗号化
- 認可を受けた2名のみに限定された厳格なアクセス制御
- 独立したデータベースによるデータの分離
- 金融口座情報の非保存
- 処理されるデータの機微性および情報収集上の価値の低さ
- すべてのデータ主体の権利を行使するための技術的ツール

移転されたデータが、英国/EEA 内で保証される保護と本質的に同等の水準の保護を受けることを確保するための、十分な補完的措置が講じられていると判断します。

## 5. レビューのスケジュール

本評価は、年に1回、またはデータ処理、復処理者、もしくは国際データ移転を規律する法的枠組みに重大な変更があった場合に、レビューされます。
