# 教会設定

<div class="article-intro">

教会設定ページでは、教会の基本情報、連絡先、ブランディングを設定します。ここで入力した情報は、B1.church ウェブサイトや B1 App を含む ChurchApps のすべてのツールで使用されます。

</div>

## 教会情報の編集

1. B1 Admin で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**設定** を展開して **設定** をクリックします。
2. ページ上部の **教会情報** セクションで **編集** をクリックします。
3. 以下の項目を必要に応じて更新します。
   - **教会名** -- すべての ChurchApps 製品に表示される名前です。
   - **住所** -- 教会の実際の住所です。
   - **連絡先情報** -- 電話番号、メールアドレス、その他の連絡先です。
   - **タイムゾーン** -- 教会のタイムゾーンです。下記の [タイムゾーン](#time-zone) を参照してください。
4. **保存** をクリックして変更を適用します。

## サブドメインの設定

教会には無料のサブドメイン **yourchurch.1.church** が割り当てられます。メンバーや訪問者は、このウェブアドレスから教会のオンラインページにアクセスできます。

1. 設定ページで、**教会情報** セクションの **編集** をクリックし、**サブドメイン** 欄を探します。
2. 希望するサブドメインを入力します（例：gracechurch.1.church にする場合は "gracechurch"）。
3. 変更を保存します。

:::info
サブドメインは、すべての ChurchApps 教会の中で一意である必要があります。希望する名前がすでに使われている場合は、市区町村や州名を追加してみてください（例："gracechurch-dallas"）。
:::

訪問者に独自のドメイン（例：**`www.gracechurch.org`**）でサイトを見てもらいたい場合は、[カスタムドメイン](./custom-domain.md) を参照してください。

## ブランディングの設定

ChurchApps のすべてのツールで教会の見え方をカスタマイズします。

1. ロゴ領域をクリックして画像ファイルを選択し、**教会のロゴ** をアップロードします。
2. ウェブサイトや [モバイルアプリ](./mobile-app.md) で使用する追加の **教会の画像** があれば追加します。

:::tip
最良の結果を得るには、背景が透明の PNG 形式のロゴを使用してください。明るい背景と暗い背景のどちらでも見栄えよく表示されます。
:::

## 週の始まりの曜日

カレンダーを週のどの曜日から始めるかを選択します。教会情報セクションの **週の始まりの曜日** のドロップダウンは初期値が **日曜日** ですが、任意の曜日に変更できます。変更すると、B1 Admin と B1.church のメンバーポータルのカレンダー表示に反映されます。グループカレンダー、キュレーションカレンダー、イベントエディターのすべてで、選択した曜日から週が始まります。

## タイムゾーン

**教会情報** セクションの **タイムゾーン** ドロップダウンで、教会のタイムゾーンを設定します（例：*America/Chicago*）。空欄にする場合は **なし** を選択します。保存すると、教会情報の概要にタイムゾーンが表示されます。

B1 は、イベントのリマインダーや [FreePlay](../../freeplay/scheduled-mode/scheduling-the-calendar.md) テレビのスケジュールなど、教会全体の時刻にこのタイムゾーンを使用します。[チェックインのスケジュール](../attendance/setup.md#setting-a-check-in-schedule) は、まずサービスの [キャンパス](./campuses.md) のタイムゾーンを基準にし、キャンパスにタイムゾーンが設定されていない場合にのみ教会のタイムゾーンを使用します。すべてのキャンパスが同じタイムゾーンにある場合は、教会とそれぞれのキャンパスの両方に設定してください。

## 地域（日付と電話番号の形式）

**地域** 設定は、B1 全体で日付と時刻の表記方法を決定します。初期値は米国の形式です（例：「Sep 28, 2026」や「9/28/2026」）。米国以外の教会は、独自の形式に切り替えられます。たとえば英語（英国）を選ぶと、「28 Sept 2026」や「28/09/2026」と表示されます。

1. 設定ページの左側のリストで **地域** をクリックし、**地域** セクションの **編集** をクリックします。
2. **地域** ドロップダウンから地域を選択します。各項目にはサンプルの日付が表示されるので、日付の表示形式を確認できます。
3. **保存** をクリックします。

地域セクションには、選択した地域、**日付の形式** のサンプル、**電話番号** の形式が表示されます。

### 電話番号の形式

同じ地域セクションにある **電話番号** 設定では、人物のレコードで電話番号を入力する方法を決めます。

- **国際（国番号付き）** -- 初期値です。電話番号欄に国旗の選択ツールが表示され、国番号付きで保存されます（例：+1 918 555 1234）。
- **ローカル（入力どおり）** -- 電話番号欄は通常のテキストボックスになり、入力したとおりに国番号を追加せず保存されます（例：0701 234 5678）。教会が現地の形式で番号を記録しており、B1 に国番号を追加させたくない場合に選択します。

**ローカル** を選択すると、地域セクションにも地域名の横に「Local phone numbers」と表示されます。

:::tip
テキストメッセージは、電話番号に国番号が含まれているときに最もうまく送信されます。B1 からテキストメッセージを送る場合は **国際** 形式のままにするか、ローカルモードで入力する番号に国番号を含めてください。
:::

地域設定は、B1 Admin と B1.church ウェブサイト・メンバーポータルの日付と時刻に適用されます。対象には説教、ブログ記事、グループカレンダー、奉仕計画が含まれるため、メンバーもスタッフと同じ形式で日付を確認できます。

## テキストメッセージ {#texting}

テキストメッセージのプロバイダーを接続すると、B1 Admin から個人または グループ全体に SMS を送信できます。メッセージはお使いのプロバイダーのアカウントを通して送信されるため、そのプロバイダーの料金と制限が適用されます。

1. 設定ページの左側のリストで **テキストメッセージ** をクリックし、**テキストメッセージ** セクションの **編集** をクリックします。
2. **プロバイダー** を選択します。
   - **Clearstream** -- **API キー** を入力します。Clearstream のアカウント設定の API Keys で作成できます。
   - **Text In Church** -- **API キー** を入力します。先に Text In Church サポートに開発者向け API のアクセスを依頼してから、Account Settings > Developer API セクションでキーを作成します。
   - **Nalo Solutions**（ガーナ） -- Nalo Solutions のアカウントの認証キーを **API キー** として入力し、Nalo が承認した **送信者 ID**（最大 11 文字）を入力します。
   - **Twilio** -- 教会自身の Twilio アカウントを使用します。Twilio は直接請求します。[Twilio Console](https://console.twilio.com) から **Account SID** と **Auth Token** をコピーし、**送信元番号** を入力します。送信元番号は A2P 10DLC に登録された Twilio の電話番号で、`+15551234567` のような形式です。保存後、下記の受信 Webhook URL を Twilio の番号の **A message comes in** Webhook に貼り付けると、STOP の返信も B1 に記録されます。
3. **保存** をクリックします。

テキストメッセージの送信を停止するには、**プロバイダー** を **なし** に設定して保存します。これにより、保存されたプロバイダーが削除されます。

### STOP と返信した人の配信停止

プロバイダーを保存したら、**編集** をクリックしてテキストメッセージのセクションを再度開きます。プロバイダーの設定の下に、読み取り専用の **受信（STOP）Webhook URL** 欄が表示されます。この欄は教会ごとに固有のウェブアドレスです。欄をクリックしてアドレスを選択しコピーし、テキストメッセージのプロバイダーの受信メッセージ（返信）Webhook の設定に貼り付けます。上記のプロバイダーのうち、受信した返信を Webhook に転送できるものであれば利用できます。

この設定後、テキストメッセージに対して **STOP**（または STOPALL、UNSUBSCRIBE、CANCEL、END、QUIT、OPTOUT、REVOKE）と返信した人がいると、B1 は携帯電話番号が一致するすべての人を探し、配信停止として記録し、テキストによるリマインダーをオフにします。その後、その人はグループへのテキストメッセージから除外されます。それ以外の返信は無視されます。

:::info
この機能では、**ディレクトリにメンバーを表示しない** と同じ配信停止の設定を使用します。そのため、STOP と返信した人のプロフィールには **ディレクトリ非表示** とも表示されます。この欄は、保存されたプロバイダーが選択されている場合にのみ表示されます。ドロップダウンを別のプロバイダーに切り替えた場合は、URL を再表示するために先に保存してください。
:::

プロバイダーが接続されると、テキストを送信する権限のあるスタッフには、グループのページに **グループにテキスト** のボタン、携帯電話番号が登録された人のページに **テキストメッセージを送信** のボタンが表示されます。メッセージを入力して **送信** をクリックします。ダイアログには文字数と SMS のセグメント数が表示されます。グループの場合は、送信前に何人のメンバーがテキストを受け取るかも表示されます。

- 携帯電話番号が登録されていないメンバーはスキップされます。
- **ディレクトリにメンバーを表示しない** を選択したメンバーは、配信停止として扱われてスキップされます。
- 同じ携帯電話番号を共有する家族メンバーには、テキストが 1 回だけ送信されます。

### 差し込みフィールドでテキストをパーソナライズする {#personalizing-texts-with-merge-fields}

メッセージ欄の下にあるテキストダイアログには、プレースホルダーのチップが表示されます：**名**、**姓**、**表示名**、**教会名**。チップをクリックすると、そのプレースホルダー（`{{firstName}}`、`{{lastName}}`、`{{displayName}}`、または `{{churchName}}`）がカーソル位置に挿入されます。送信時には、各プレースホルダーが受信者ごとの情報に置き換えられます。そのため、`{{firstName}}さん、日曜日にお会いしましょう！` のようなグループ向けテキストは、それぞれのメンバーの名前付きで届きます。プレースホルダーは、グループへのテキストと個人へのテキストの両方で使用できます。グループへのテキストでは、**グループ名** のチップ（`{{groupName}}`）も使用でき、グループの名前に置き換えられます。

メッセージを再利用するには、[テキストテンプレート](./email-templates.md#text-templates)（カテゴリーが **テキスト** のメールテンプレート）として保存し、テキストウィンドウ上部の **テンプレートを読み込む（任意）** から選択します。

:::info
1,600 文字の制限は、入力したままのメッセージに適用されます。プレースホルダーに値が入った後、1,600 文字を超えた部分は、その長さで切り捨てられます。
:::

テキストは、[ワークフロー](../serving/workflows.md#sending-a-text) の **テキストを送信** アクションのステップからも自動的に送信できます。このアクションも同じプロバイダーとプレースホルダーを使用します。

## ファイルストレージ

初期設定では、ウェブサイトへのアップロードファイル（[ファイル](../website/files.md) から）やその他のコンテンツ領域のファイルは、B1 の無料のホスティングストレージを使用します（上限 100MB）。より多くの容量が必要な場合は、代わりに独自のクラウドストレージを接続できます。その場合、新しいアップロードはプラットフォームの上限なしで直接お使いのアカウントに保存されます。

1. 設定ページの左側のリストで **ファイルストレージ** をクリックし、**ファイルストレージ** セクションの **編集** をクリックします。
2. プロバイダーを選択します：**Google Drive**、**Dropbox**、**OneDrive**、または **S3 互換バケット**（AWS S3、Cloudflare R2、Backblaze B2 など）。
3. Google Drive、Dropbox、OneDrive の場合は **接続** をクリックし、サインインしてアクセスを許可します。S3 互換バケットの場合は、アクセスキー、シークレット、バケット名、公開 URL のベースを入力します。
4. **保存** をクリックします。

:::info
この設定は、ウェブサイトのファイルや同様のコンテンツ領域への新しいアップロードにのみ影響します。ギャラリーの画像、サムネイル、ロゴ、人物の写真は、常に B1 の初期ストレージに保存されます。
:::

## 進級

子どもや生徒の **学年** を記録している場合、B1 は、一人ひとりのプロフィールを手作業で編集する代わりに、選択した日付（例：8 月 1 日）に全員を自動的に 1 学年上げられます。

1. 設定ページの左側のリストで **進級** をクリックし、**進級** セクションの **編集** をクリックします。
2. スイッチをオンにし（**有効** と表示されます）、毎年進級させる **月** と **日** を選択します。その日になると、学年が設定されているすべての人が 1 学年上がり、12 年生は **卒業** に変わります。
3. 変更を保存します。

自動進級を停止するには、スイッチをオフにして **無効** と表示させ、保存します。進級日は削除され、学年は自動では変わらなくなります。

## ボランティア受付 {#volunteer-signup}

初期設定では、[ボランティア受付](../../b1-church/serving/volunteer-signup.md) を見るメンバーには、空きのある今後のすべての週が表示されます。この一覧が長くなる場合は、計画の種類ごとに次の 1 週間だけを表示できます。

1. 設定ページの左側のリストで **ボランティア受付** をクリックし、**ボランティア受付** セクションの **編集** をクリックします。
2. **計画の種類ごとに次の 1 週間のみ表示** をオンにします。
3. 変更を保存します。

この設定をオンにすると、計画の種類ごとに次に予定されている計画のみが表示されます。次の週は、その日付を過ぎると表示されます。セクションの **表示する週** の行には、**計画の種類ごとに次の 1 週間のみ** または **今後のすべての週** と表示されます。

## 献金プライバシー {#giving-privacy}

献金のアクセス権を持つ人は通常、人物のレコードで、その人の献金合計を確認できます（[人物のレコード](../people/adding-people.md#editing-details) を参照）。レコードを開くたびに金額が画面に表示されるのを避けたい場合は、誰かが求めるまで金額を非表示にできます。

1. 設定ページの左側のリストで **献金プライバシー** をクリックし、**献金プライバシー** セクションの **編集** をクリックします。
2. **人物のレコードの献金を、クリックするまで非表示にする** をオンにします。
3. 変更を保存します。

この設定をオンにすると、人物のレコードの献金カードに「人物のレコードでは献金は非表示になっています。」と表示されます。**献金を表示** をクリックすると、その人の献金が読み込まれて表示されます。別の人物を開くと、再び非表示になります。献金を閲覧できる人は変わりません。献金のアクセス権を持つ人だけがこのカードを見られます。

## データのインポートとエクスポート

設定ページで教会名の下にある **インポート/エクスポート** のリンクをクリックすると、専用のツールが新しいブラウザーウィンドウで開きます。このツールでは次のことができます。

- 他の教会管理システムから会員データをインポートする。
- バックアップや移行のために ChurchApps のデータをエクスポートする。

これは、教会を初めて設定する際に、既存のレコードを ChurchApps に移す必要がある場合に特に役立ちます。

:::warning
データをインポートする前に、既存のレコードを必ずバックアップしてください。インポート処理はシステムにデータを追加するため、複数回実行すると重複したエントリーが作成される場合があります。
:::
