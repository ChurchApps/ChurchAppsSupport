# 教会設定

<div class="article-intro">

教会設定ページでは、教会の基本情報、連絡先、ブランディングを設定します。ここで入力した情報は、B1.church ウェブサイトや B1 Mobile アプリを含む、すべての ChurchApps ツールで使用されます。

</div>

## 教会情報の編集

1. B1 Admin で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)(左上の検索バー)を開き、**設定**を展開して、**設定**をクリックします。
2. ページ上部の**教会情報**セクションで、**編集**をクリックします。
3. 以下の項目を必要に応じて更新します:
   - **教会名** -- すべての ChurchApps 製品に表示される名前です。
   - **住所** -- 教会の実際の住所です。
   - **連絡先情報** -- 電話番号、メールアドレスなどの連絡先です。
   - **タイムゾーン** -- 教会のタイムゾーンです。下記の[タイムゾーン](#time-zone)を参照してください。
4. **保存**をクリックして変更を適用します。

## サブドメインの設定

教会には、無料のサブドメイン **yourchurch.1.church** が割り当てられます。メンバーや訪問者が教会のオンライン情報にアクセスできるWebアドレスです。

1. 設定ページで、**教会情報**セクションの**編集**をクリックし、**サブドメイン**欄を探します。
2. 希望のサブドメインを入力します(例: gracechurch.1.church にする場合は "gracechurch")。
3. 変更を保存します。

:::info
サブドメインは、すべての ChurchApps 教会の中で一意である必要があります。希望の名前がすでに使われている場合は、都市名や州名を追加してみてください(例: "gracechurch-dallas")。
:::

訪問者が独自のドメイン(例: **`www.gracechurch.org`**)でサイトにアクセスできるようにしたい場合は、[カスタムドメイン](./custom-domain.md)を参照してください。

## ブランディングの設定

すべての ChurchApps ツールで、教会の見た目をカスタマイズします:

1. ロゴ欄をクリックして画像ファイルを選択し、**教会ロゴ**をアップロードします。
2. ウェブサイトや[モバイルアプリ](./mobile-app.md)で使う追加の**教会画像**があれば、追加します。

:::tip
最良の結果を得るには、背景が透明な PNG 形式のロゴを使用してください。ライトとダークのどちらの背景でも見栄えがよくなります。
:::

## 週の始まりの曜日

カレンダーを開始する曜日を選択します。教会情報セクションの**週の始まり**ドロップダウンは初期値が**日曜日**ですが、任意の曜日に変更できます。変更すると、B1 Admin と B1.church のメンバーポータルのカレンダー表示に反映されます。グループカレンダー、カスタムカレンダー、イベントエディターのいずれも、選択した曜日から週が始まります。

## タイムゾーン

**教会情報**セクションの**タイムゾーン**ドロップダウンで、教会のタイムゾーンを設定します(例: *America/Chicago*)。空欄にする場合は**なし**を選択します。保存すると、教会情報の概要にタイムゾーンが表示されます。

B1 は、イベントのリマインダーや [FreePlay](../../freeplay/scheduled-mode/scheduling-the-calendar.md) の TV に表示されるスケジュールなど、教会全体の時刻にこのタイムゾーンを使用します。[チェックインのスケジュール](../attendance/setup.md#setting-a-check-in-schedule)は、まずサービスが行われる[拠点](./campuses.md)のタイムゾーンで計算され、その拠点にタイムゾーンが設定されていない場合にのみ教会のタイムゾーンが使われます。すべての拠点が同じタイムゾーンにある場合は、教会と各拠点の両方で設定してください。

## 地域(日付と電話番号の形式)

**地域**設定は、B1 全体で日付と時刻をどの形式で表示するかを決めます。初期値は米国形式です(例: 「Sep 28, 2026」「9/28/2026」)。米国以外の教会は、自国の形式に切り替えられます。たとえば英語(英国)を選ぶと、「28 Sept 2026」「28/09/2026」のように表示されます。

1. 設定ページの左側のリストで**地域**をクリックし、**地域**セクションの**編集**をクリックします。
2. **地域**ドロップダウンから地域を選択します。各項目にはサンプルの日付が表示されるので、日付の見え方を確認できます。
3. **保存**をクリックします。

地域セクションには、選択した地域、**日付の形式**のサンプル、**電話番号**の形式が表示されます。

### 電話番号の形式

同じ地域セクションにある**電話番号**設定では、人物のレコードに電話番号を入力する方法を決めます:

- **国際(国番号付き)** -- 初期値です。電話番号欄には国旗のピッカーが表示され、国番号付きで保存されます(例: +1 918 555 1234)。
- **ローカル(入力どおり)** -- 電話番号欄は通常のテキストボックスになり、入力した番号を国番号を追加せずそのまま保存します(例: 0701 234 5678)。教会で国内の書式で番号を書いていて、B1 に国番号を追加させたくない場合に選択します。

**ローカル**を選択すると、地域セクションの地域名の横に「Local phone numbers」と表示されます。

:::tip
SMS は、電話番号に国番号が含まれている場合にもっともうまく送信されます。B1 から SMS を送信する場合は、**国際**形式を使うか、ローカルモードで入力する番号に国番号を含めてください。
:::

地域設定は、B1 Admin と B1.church のウェブサイトおよびメンバーポータルのすべての日付と時刻に適用されます。説教、ブログ記事、グループカレンダー、奉仕計画も含まれるため、メンバーはスタッフと同じ形式で日付を見ることができます。

## SMS 送信 {#texting}

SMS プロバイダーを接続すると、B1 Admin から個人やグループ全体に SMS を送信できます。SMS は、ご自身がプロバイダーと契約しているアカウントから送信されるため、料金や制限はそのプロバイダーのものが適用されます。

1. 設定ページの左側のリストで**SMS 送信**をクリックし、**SMS 送信**セクションの**編集**をクリックします。
2. **プロバイダー**を選択します:
   - **Clearstream** -- **API キー**を入力します。Clearstream のアカウント設定の API Keys で作成できます。
   - **Text In Church** -- **API キー**を入力します。まず Text In Church サポートに開発者向け API へのアクセスを依頼し、その後アカウント設定の Developer API セクションでキーを作成します。
   - **Nalo Solutions**(ガーナ) -- Nalo Solutions アカウントの認証キーを **API キー**として入力し、Nalo から承認された **送信者 ID**(最大 11 文字)を入力します。
   - **Twilio** -- 教会自身の Twilio アカウントを使用します。料金は Twilio から直接請求されます。[Twilio コンソール](https://console.twilio.com)から **Account SID** と **Auth Token** をコピーし、**送信元番号**を入力します。送信元番号は A2P 10DLC に登録された Twilio の電話番号で、`+15551234567` のような形式で入力します。保存後、下記の受信 Webhook URL を Twilio の番号の **A message comes in** Webhook に貼り付けると、STOP の返信も B1 に記録されます。
3. **保存**をクリックします。

SMS の送信を停止するには、**プロバイダー**を**None**に設定して保存します。これで保存されたプロバイダーが削除されます。

### STOP と返信した人の配信停止

プロバイダーを保存したら、**編集**をクリックして SMS 送信セクションを開き直します。プロバイダーの設定の下に、読み取り専用の **受信(STOP)Webhook URL** 欄があり、教会ごとに固有のWebアドレスが表示されます。欄をクリックしてアドレスを選択し、コピーして、SMS プロバイダーの受信メッセージ(返信)Webhook の設定に貼り付けます。上記のプロバイダーのうち、受信した返信を Webhook に転送できるものであれば、この方法を使えます。

設定後、誰かが送信したメッセージに **STOP**(または STOPALL、UNSUBSCRIBE、CANCEL、END、QUIT、OPTOUT、REVOKE)と返信すると、B1 は携帯電話番号が一致するすべての人を探し、配信停止として記録して、その人のテキストによるリマインダーをオフにします。その後、その人はグループへの SMS から除外されます。それ以外の返信は無視されます。

:::info
これは**メンバーディレクトリに表示しない**と同じ配信停止設定を使うため、STOP と返信した人のプロフィールには**ディレクトリから非表示**とも表示されます。この欄は、保存されたプロバイダーが選択されている場合にのみ表示されます。ドロップダウンを別のプロバイダーに切り替えた場合は、URL を再度表示するために先に保存してください。
:::

プロバイダーを接続すると、SMS の送信権限があるスタッフには、グループのページに**このグループに SMS を送信**ボタン、携帯電話番号が登録されている人のページに**SMS を送信**ボタンが表示されます。メッセージを入力して**送信**をクリックします。ダイアログには文字数と SMS のセグメント数が表示されます。グループの場合は、送信前に何人が受け取るかが表示されます:

- 携帯電話番号が登録されていないメンバーはスキップされます。
- **メンバーディレクトリに表示しない**を選択したメンバーは、配信停止として扱われ、スキップされます。
- 同じ携帯電話番号を共有する家族メンバーには、SMS は 1 回だけ送信されます。

### 差し込み項目でメッセージをパーソナライズする {#personalizing-texts-with-merge-fields}

メッセージ入力欄の下に、SMS ダイアログのプレースホルダーのチップが表示されます: **名**、**姓**、**表示名**、**教会名**。チップをクリックすると、カーソル位置にプレースホルダー(`{{firstName}}`、`{{lastName}}`、`{{displayName}}`、または `{{churchName}}`)が挿入されます。送信時に、各プレースホルダーは受信者の情報に置き換えられます。そのため、`Hi {{firstName}}, see you Sunday!` のようなグループ向けメッセージは、それぞれのメンバーの名前付きで届きます。プレースホルダーは、グループ向けと個人向けの両方のメッセージで使えます。グループへのメッセージでは、**グループ名**チップ(`{{groupName}}`)も使えます。これはグループの名前に置き換えられます。

メッセージを再利用するには、[テキストテンプレート](./email-templates.md#text-templates)(**SMS** カテゴリのメールテンプレート)として保存し、SMS ウィンドウの上部にある**テンプレートを読み込む(任意)**から選択します。

:::info
1,600 文字の上限は、入力中のメッセージに適用されます。差し込み項目が置き換えられたあと、1,600 文字を超えたテキストは、その長さで切り捨てられます。
:::

テキストは、[ワークフロー](../serving/workflows.md#sending-a-text)の**SMS を送信**アクションによって自動的に送信することもできます。このアクションでも、同じプロバイダーと差し込み項目が使われます。

## ファイルストレージ

初期設定では、ウェブサイトの([ファイル](../website/files.md)から)アップロードしたファイルや、その他のコンテンツ領域のファイルは、B1 の無料ホスティングストレージ(最大 100MB)に保存されます。さらに容量が必要な場合は、代わりに独自のクラウドストレージを接続できます。接続後は、新しいアップロードがプラットフォームの上限なしで、直接お使いのアカウントに保存されます。

1. 設定ページの左側のリストで**ファイルストレージ**をクリックし、**ファイルストレージ**セクションの**編集**をクリックします。
2. プロバイダーを選択します: **Google Drive**、**Dropbox**、**OneDrive**、または **S3 互換バケット**(AWS S3、Cloudflare R2、Backblaze B2 など)。
3. Google Drive、Dropbox、OneDrive の場合は、**接続**をクリックし、サインインしてアクセスを許可します。S3 互換バケットの場合は、アクセスキー、シークレット、バケット名、公開URLのベースを入力します。
4. **保存**をクリックします。

:::info
これは、ウェブサイトの「ファイル」および同様のコンテンツ領域への新しいアップロードにのみ影響します。ギャラリー画像、サムネイル、ロゴ、人物の写真は、常に B1 の標準ストレージに保存されます。
:::

## 進級

子どもや生徒の**学年**を記録している場合、B1 は、各プロフィールを手動で編集しなくても、指定した日付(例: 8 月 1 日)に全員の学年を自動的に 1 つ上げることができます。

1. 設定ページの左側のリストで**進級**をクリックし、**進級**セクションの**編集**をクリックします。
2. スイッチをオンにし(**有効**と表示されます)、毎年学年を上げる**月**と**日**を選択します。その日になると、学年のある全員が 1 学年上がり、12 年生は**卒業**になります。
3. 変更を保存します。

自動進級を停止するには、スイッチをオフにして**無効**と表示させ、保存します。進級日が削除され、学年は自動的には変わらなくなります。

## ボランティア募集 {#volunteer-signup}

初期設定では、[ボランティア募集](../../b1-church/serving/volunteer-signup.md)を閲覧するメンバーには、空きのある予定の週がすべて表示されます。一覧が長くなる場合は、各計画の種類について次の 1 週間だけを表示することもできます。

1. 設定ページの左側のリストで**ボランティア募集**をクリックし、**ボランティア募集**セクションの**編集**をクリックします。
2. **計画の種類ごとに次の 1 週間だけを表示する**をオンにします。
3. 変更を保存します。

この設定をオンにすると、各計画の種類には次に予定されている計画のみが表示されます。次の週は、その日付が過ぎると表示されます。セクションの**表示する週**の行には、**計画の種類ごとに次の 1 週間のみ**または**予定されているすべての週**と表示されます。

## 献金のプライバシー {#giving-privacy}

献金へのアクセス権がある人は、通常、[人物レコード](../people/adding-people.md#editing-details)で人の献金合計を確認できます。レコードを開くたびに金額が画面に表示されるのを避けたい場合は、誰かが求めるまで非表示にできます。

1. 設定ページの左側のリストで**献金のプライバシー**をクリックし、**献金のプライバシー**セクションの**編集**をクリックします。
2. **人物レコードの献金を、クリックするまで非表示にする**をオンにします。
3. 変更を保存します。

この設定をオンにすると、人物レコードの献金カードには「人物レコードでは献金が非表示になっています。」と表示されます。**献金を表示**をクリックすると、その人の献金が読み込まれて表示されます。別の人のレコードを開くと、再び非表示になります。献金を閲覧できる人は変わりません。献金へのアクセス権を持つ人だけがこのカードを見ることができます。

## インポートとエクスポート

設定ページで教会名の下にある **インポート/エクスポート** リンクをクリックすると、新しいブラウザウィンドウで専用のツールが開きます。このツールでは次のことができます:

- 他の教会管理システムから、メンバーのデータをインポートする。
- バックアップや移行のために、ChurchApps のデータをエクスポートする。

これは、教会を初めて設定するときに、既存のレコードを ChurchApps に移す必要がある場合に特に役立ちます。

:::warning
データをインポートする前に、必ず既存のレコードをバックアップしてください。インポート処理ではデータが追加され、複数回実行すると重複したエントリが作成される場合があります。
:::
