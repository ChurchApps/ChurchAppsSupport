# 設定

<div class="article-intro">

設定セクションでは、B1 Admin で教会のアカウント、ブランディング、管理オプションを設定できます。教会名やサブドメインから、ユーザーの権限、モバイルアプリの構成まで、ここからすべて管理できます。

</div>

## ここで確認できる内容

設定エリアは、次のサブセクションで構成されています。

1. **設定** -- 教会の基本情報、ブランディング、サブドメイン、地域（日付と電話番号の形式）、テキストメッセージのプロバイダー、ファイルストレージを設定します。詳しくは [教会設定](./church-settings.md) を参照してください。独自のドメイン名（例：yourchurch.org）を使うには、[カスタムドメイン](./custom-domain.md) を参照してください。
2. **キャンパス** -- 教会の複数の拠点を追加・管理します。作成したキャンパスは、人物のプロフィール、出欠の設定、人口統計ダッシュボードに表示されます。個別のナビゲーション項目ではなく、メインの設定ページ内のセクションとして表示されます。詳しくは [キャンパス](./campuses.md) を参照してください。
3. **カスタムフィールド** -- 人物について記録する独自の項目（日付、数値、はい/いいえ、またはリストからの選択）を定義し、プロフィールに入力したり、その項目で検索したりできます。こちらもメインの設定ページ内のセクションとして表示されます。詳しくは [カスタムフィールド](./custom-fields.md) を参照してください。
4. **メールテンプレート** -- 手動での送信やワークフローからの送信に再利用できるメール本文を保存します。詳しくは [メールテンプレート](./email-templates.md) を参照してください。
5. **監査ログ** と **バッチ** -- アカウント全体で行われた変更を確認します（[監査ログ](../reports/audit-log.md)）。また、一括インポートや一括操作を確認し、元に戻すこともできます（**バッチ**）。
6. **サーバー管理** -- 教会のサーバーレベルの設定を管理するための高度な管理ツールにアクセスします。

:::info
**モバイルアプリ**の設定と**フォーム**は、現在では設定の内側ではなく、それぞれ独立したトップレベルのナビゲーション項目になっています。**人物**の下にある**モバイル**と**フォーム**です。詳しくは [モバイルアプリの設定](./mobile-app.md) と [フォームの作成](/docs/b1-admin/forms/creating-forms) を参照してください。
:::

## メインの設定ページ

設定ページを初めて開くと、左側のパネルに**教会名**、**サブドメイン**、住所が表示されます。また、システム間でデータを移行するためのインポート/エクスポートツールを開く **インポート/エクスポート** リンクもあります。

その下の**設定項目**一覧には、各設定セクションへのリンクがあります。**教会情報**、**一般**、**地域**、**献金**、**テキストメッセージ**、**ファイルストレージ**、**ドメイン**、**学年進級**、**チェックイン**、**キャンパス**、**カスタムフィールド**、**開発者**です。まだ設定が必要なセクション（献金、テキストメッセージ、ドメインなど）には、小さな点が表示されます。すべてのセクションは1つのページにまとめられています。一覧の項目名をクリックするとそのセクションに移動し、そのままスクロールしても構いません。各セクションには現在の設定が表示され、変更するにはセクション内の**編集**をクリックします。

**メールテンプレート**、**監査ログ**、**バッチ**は別のページです。**設定**の下にある [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu) から開いてください。

まずは**教会情報**セクションで、教会の名前、住所、連絡先情報を編集しましょう。詳しくは [教会設定](./church-settings.md) を参照してください。ユーザーのロールを管理するには、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu) を開いて **設定 > ロール** を選択してください。詳しくは [ロールと権限](./roles-permissions.md) を参照してください。

:::tip
まず **教会情報** で教会名とブランディングを設定し、次に [ロール](./roles-permissions.md) を設定して、チームメンバーを適切なアクセス権限で招待しましょう。
:::

:::info
データの保護について詳しくは、[データセキュリティ](./data-security.md) を参照してください。
:::
