# カスタムドメイン

<div class="article-intro">

お持ちのドメイン（例：**`www.yourchurch.org`**）を B1 サイトに向けると、訪問者はデフォルトの yourchurch.b1.church ではなく、教会の実際の Web アドレスからサイトにアクセスできるようになります。

</div>

## ステップ1 — 最初にDNSレコードを追加する

B1 にドメインを追加する前に、ドメインの管理サービス（GoDaddy、Namecheap、Cloudflare など）で、そのドメインを B1 のサーバーに向ける必要があります。

次のいずれかのレコードを追加してください。CNAME を推奨します。

| 種類 | ホスト | 値 |
|------|------|-------|
| CNAME | `www` | `proxy.b1.church` |
| A | `yourchurch.org` | `3.23.251.61` |

`www` のアドレスには **CNAME** を使用してください。ルートドメイン（www なし）で CNAME がサポートされていない場合、またはルートドメインでも使えるようにしたい場合は、**A レコード**を使用してください。

DNS の変更が反映されるまでに、数分から数時間かかることがあります。

## ステップ2 — B1 でドメインを追加する

DNS が B1 を向いたら、次の手順に進みます。

1. B1 Admin で **Settings（設定）** に移動します。
2. 左側のリストで **Domains（ドメイン）** をクリックし、**Domains** セクションの **Edit（編集）** をクリックします。
3. 入力欄にドメインを入力し、**Save（保存）** をクリックします。

事前に **+** ボタンを押す必要はありません。入力欄にドメインを入力したまま保存すると、そのドメインが追加されます。保存前に複数のドメインをリストに追加したい場合は、**+**（または **Enter** キー）を使用してください。

B1 は SSL を自動的に処理するため、証明書を別途購入する必要はありません。

:::warning
DNS レコードが設定される前に B1 でドメインを追加しようとすると、保存されません。必ず先に DNS を設定してください。
:::

## 動作の確認

保存後、ブラウザでドメインにアクセスしてください。B1 のサイトが表示されれば完了です。エラーが表示される場合は、DNS の反映がまだ完了していない可能性があります。数分待ってから再度お試しください。

DNS の反映状況は [dnschecker.org](https://dnschecker.org) でも確認できます。ドメインを検索し、CNAME または A レコードが表示されるかをご確認ください。
