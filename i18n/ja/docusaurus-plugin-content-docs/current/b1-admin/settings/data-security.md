# データセキュリティ

<div class="article-intro">

完全に安全なシステムは存在しませんが、ChurchApps はデータセキュリティを真剣に考えています。このページでは、B1.church Admin およびその他の ChurchApps 製品に入力されたすべてのデータを保護するために講じている対策を説明します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- このページを確認して、教会のデータがどのように保護されているかを理解してください
- [役割と権限](./roles-permissions.md)を設定して、機密情報にアクセスできる人を管理してください
- [プライバシーポリシー](https://churchapps.org/privacy)に目を通してください

</div>

## 保存する機密データの制限

私たちの第一の方針は、必要以上の機密データを保存しないことです。つまり、寄付に使用されたクレジットカードや銀行口座の情報は、一切保存しません。B1.church Admin または B1 を使って寄付が行われた場合、クレジットカードのデータは私たちのサーバーには送信されず、お客様の決済ゲートウェイ（Stripe）にのみ送信されます。そのため、データ漏えいが発生した場合でも、クレジットカードや銀行口座の情報が漏えいすることはありません。

また、パスワードをシステム内に保存することもありません。すべてのパスワードは、一部のデータを破棄する一方向のハッシュアルゴリズムで処理されるため、データベースからパスワードを取り出すことは、私たちを含め誰にもできません。パスワードを検証するときは、入力された値を同じ一方向ハッシュに通し、同じ結果になるかどうかを確認します。

これら2つの情報源を除くと、残る機密データは氏名と連絡先情報のリストだけです。

:::tip
ChurchApps はクレジットカードや銀行口座の情報を保存しないため、最悪のデータ漏えいが起きたとしても、金融口座の詳細が露出することはありません。危険にさらされるのは氏名と連絡先情報だけです。
:::

## 業界標準のベストプラクティスの採用

私たちは、サーバーとの間でやり取りされるすべてのデータを HTTPS で暗号化するなど、セキュリティの業界標準のベストプラクティスを採用しています。すべてのサーバーは、Amazon Web Services の安全な物理データセンターでホストされています。すべてのデータベースサーバーはファイアウォールの内側に置かれ、インターネットからはアクセスできません。

## データの分離

データは範囲に応じて、異なるデータベースに分けて格納されています。API（Membership、Giving、Attendance、Messaging、Doing、Lessons）はそれぞれ独立したデータの箱で、独自のデータベースを持っています。ひとつが侵害されても、他のものも侵害されない限り、データの有用性は限られます。たとえば、Giving API／データベースが侵害された場合、攻撃者は寄付の一覧と日付にアクセスできる可能性がありますが、カードや銀行口座のデータには決してアクセスできません。また、どのユーザーが寄付をしたのか、どの教会への寄付なのかはわかりません。それらのデータは別の Membership データベースに保存されているためです。

:::info
データを分離しているため、ひとつのシステムが侵害されても、教会のすべてのデータにアクセスできるわけではありません。各 API は独自のデータベースを使って独立して動作するため、起こりうる侵害の影響が限定されます。
:::

## アクセスの制限

本番サーバーへのアクセスは、アクセスが必要なサーバー管理者に厳しく制限されています。現在は、理事でもある2名のみです。開発者、ボランティア、その他の理事はいずれも、本番サーバーへのアクセスを許可されていません。

## プライバシーポリシー

お客様のデータはお客様のものであり、第三者に販売されることは決してありません。完全なプライバシーポリシーは[こちら](https://churchapps.org/privacy)でお読みいただけます。

## GDPR への対応

ChurchApps は、英国または欧州連合（EU）に在住するメンバーがいる教会の GDPR 対応をサポートしています。主要な要件への対応方法は次のとおりです。

### データ主体の権利

ChurchApps は、教会がデータ主体からの請求に対応できるよう、ツールを提供しています。

- **アクセス権（第15条）** — メンバーは、教会に連絡して自分の個人データのコピーを請求できます。管理者は、B1.church Admin の個人詳細ページにある**データ管理**セクションから、任意の人物のデータをエクスポートできます。
- **消去権（第17条）** — メンバーは、自分のプロフィールページから自分でアカウントの削除を請求できるほか（[アカウント削除の請求を確認する](../profile/account-deletion.md)を参照）、教会に直接連絡することもできます。管理者は、個人詳細ページの**データ管理**セクションから、すべてのモジュールにわたって人物のデータを匿名化することもできます。匿名化では、個人情報は一般的な値に置き換えられますが、教会の財務報告に必要な集計記録（寄付の合計、出席者数）は保持されます。
- **処理の制限権（第18条）** — メンバーは、教会に連絡して、コミュニケーションのオプトアウトを含む処理の制限を請求できます。
- **データポータビリティの権利（第20条）** — 管理者は、要求したメンバーに代わって、個人データを構造化された機械可読な JSON 形式でエクスポートできます。

### データ管理ツールの使い方

個人の GDPR データツールにアクセスするには、次の手順に従ってください。

1. B1 Admin の**人物**に移動し、その人物の記録を開きます。
2. **編集**をクリックして、編集モードに入ります。
3. **データ管理**セクション（初期状態では折りたたまれています）までスクロールし、クリックして展開します。
4. **データをエクスポート**を使うと、その人物について保存されているすべてのデータを JSON ファイルとしてダウンロードできます。
5. **匿名化**を使うと、個人情報を一般的な値に置き換えられます。確認のため `ANONYMIZE` と入力するよう求められます。この操作は元に戻せません。

:::warning
匿名化は恒久的な操作です。寄付の合計と出席者数は財務報告のために保持されますが、個人を特定できる情報（氏名、メールアドレス、住所など）はすべて削除され、復元することはできません。
:::

### データ処理

ChurchApps は、お客様の教会（**データ管理者**）に代わって**データ処理者**として機能します。[データ処理契約](https://churchapps.org/terms)では、再委託先の利用、侵害通知の手順、解約時のデータ取り扱いなど、各当事者の責任を定めています。

### 国際データ移転

ChurchApps のデータは、米国内の Amazon Web Services（AWS）でホストされています。英国／EU からの国際データ移転は、[AWS データ処理補遺](https://aws.amazon.com/compliance/data-processing-addendum/)に基づく AWS の標準契約条項（SCC）でカバーされています。AWS の DPA は、すべてのお客様向けに AWS サービス規約へ自動的に組み込まれています。SCC などの適切な移転メカニズムが整っている場合、EU 域内でのホスティングは必須ではありません。

移転リスクがどのように評価されているかの詳細は、[移転リスク評価](./transfer-risk-assessment.md)をご覧ください。

### 再委託先

- **Amazon Web Services（AWS）** — インフラストラクチャのホスティング、データ保存、コンテンツ配信
- **Stripe** — 寄付の決済処理（ChurchApps はカード情報を保存しません）

:::info
個人データの取り扱いに関する詳細は、[プライバシーポリシー](https://churchapps.org/privacy)および[利用規約](https://churchapps.org/terms)をご覧ください。GDPR への対応についてご質問がある場合は、support@churchapps.org までご連絡ください。
:::
