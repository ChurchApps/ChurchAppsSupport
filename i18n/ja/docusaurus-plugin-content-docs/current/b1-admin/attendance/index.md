# 出欠

<div class="article-intro">

B1 Admin の出欠セクションでは、教会に誰が来ているか、グループがどのように成長しているかを時系列で把握できます。キャンパスや礼拝時間の設定から、傾向の確認、セルフチェックインの設定まで、出欠を追跡し理解するために必要なものがすべてこのページから管理できます。

</div>

## ページの概要

ページを開くには、左上の検索バーである[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)を開き、**People** を展開して **Attendance** をクリックします。ページは **今週**(日曜日から土曜日まで)の概要から始まります。

左の列には、その週の日付と、**部屋にいる人** の合計数が表示されます。今週人数が入力されていればその人数の合計、そうでなければチェックインした人数です。合計の下には、チェックイン数、カウント数、ゲスト数が表示され、礼拝が複数ある場合は礼拝ごとの内訳も表示されます。今週まだ誰もチェックインしていない場合は、出欠のあった直近の週が表示されます。

ページのメイン領域には次の内容が表示されます。

- **Rooms** -- 今週チェックインしたグループごとの、チェックイン数(チェックイン定員のあるグループには定員バーも表示)。グループをクリックすると開きます。
- **Guests** -- 今週ゲストとしてチェックインした人。名前をクリックすると、その人の記録が開きます。
- **Last 13 weeks** -- 週ごとのチェックイン数を示す小さな棒グラフと、チェックインがあった週の数。
- **Headcounts this week** -- 今週の礼拝について入力された人数。

## アクション

左の列には、ページのアクションも並んでいます。それぞれはメイン領域で開きます。週ごとの概要に戻るには、**Attendance** の戻るリンクをクリックしてください。

### セットアップ

**Setup** をクリックすると、出欠管理の基本要素を設定できます。ここでキャンパスを定義し、各キャンパスに礼拝と礼拝時間を追加します(各礼拝時間にはオプションでチェックインのスケジュールを設定できます)。また、それらの礼拝時間に割り当てられている[グループ](../groups/creating-groups.md)を確認できます。上部には、キャンパス、礼拝時間、スケジュールありとなしのグループ、グループの総数の件数が表示されます。設定は一度行えば十分ですが、スケジュールが変わったときはいつでも更新できます。詳しい手順は [出欠セットアップ](setup.md) をご覧ください。

### All years(レポート)

**All years** をクリックすると、出欠レポートが開きます。上部のタブで **Attendance Trend**(教会全体の傾向の推移)、**Headcount Trend**(週ごとの人数合計)、**Group Attendance**(グループごとの出欠内訳)を切り替えられます。フィルターを使うと、期間、キャンパス、礼拝時間で結果を絞り込めます。レポートとフィルターの使い方の詳細は [出欠の追跡](tracking-attendance.md) をご覧ください。

### Enter headcount(人数を入力)

**Enter headcount** をクリックすると、名簿を作成する代わりに、礼拝、礼拝時間、またはグループの合計人数を簡単に記録できます。詳しくは [人数の入力と推移](headcount-entry.md) をご覧ください。

### Kiosk(キオスク)

**Kiosk** をクリックすると **Kiosk Theme** の設定が開き、チェックイン用キオスクの背景画像とアイドル画面の動作を設定できます。**Check-in kiosk, QR, and labels** のリンクから、完全な [B1 CheckIn の設定](check-in.md)に移動できます。

## 次のステップ

- [出欠セットアップ](setup.md) -- キャンパス、礼拝時間、グループを設定する
- [出欠の記録](recording-attendance.md) -- グループの集まりの出欠を手動で入力し、クラスの出席表を印刷する
- [出欠の追跡](tracking-attendance.md) -- 傾向を確認し、レポートを絞り込む
- [人数の入力と推移](headcount-entry.md) -- 名簿なしで合計人数を記録し、グラフ化する
- [チェックイン](check-in.md) -- 礼拝のセルフチェックインを設定する
- [チェックインの安全対策](checkin-safety.md) -- 部屋の定員、ボランティアの比率、お迎えの人、呼び出し

:::tip
出欠を初めて設定する場合は、まず [出欠セットアップ](setup.md) のガイドでキャンパスと礼拝時間を定義してください。それが済んだら、[出欠を手動で記録](recording-attendance.md)するか、[セルフチェックイン](check-in.md)を設定できます。
:::
