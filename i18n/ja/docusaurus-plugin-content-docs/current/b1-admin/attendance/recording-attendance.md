# 出席の記録

<div class="article-intro">

キャンパス、礼拝時間、グループの設定が済んだら、集会のあとに出席を手動で記録できます。B1 Adminでは出席を**セッション**単位で管理します。セッションとは、1つのグループについて1回の集会日ごとに1つ作られる記録のことです。セッションを作成し、出席者にチェックを付けると、そのデータが出席レポートに直接反映されます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- キャンパス、礼拝時間、グループが設定されている必要があります。まだの場合は[出席の初期設定](setup.md)を参照してください。
- 出席を追跡したいグループで**出席を追跡**が有効になっている必要があります。詳しくは[出席の初期設定](setup.md)を参照してください。
- 出席を保存するには**出席の編集**権限が必要です。人物について**名前のみ表示**権限しかない奉仕者も、この方法で出席を記録できます。その場合は**グループ**からクラスを開くと、メンバーの名前だけが表示されます。詳しくは[名前のみ表示](../settings/roles-permissions.md#people-names-only)を参照してください。

</div>

## セッションの作成

セッションは、グループの集会1回分を表します。たとえば、特定の日曜日に行われる幼稚園〜3年生のクラスなどです。

1. **B1 Admin**を開き、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（画面左上の検索バー）を開いて、**人物**を展開し、**グループ**をクリックします。
2. 出席を記録したいグループを選択します。
3. グループのページにある**セッション**欄で、**すべてのセッション**をクリックします。
4. **新規**をクリックして、新しいセッションを作成します。
5. グループに礼拝時間が割り当てられている場合は、**礼拝時間**を選択します。スケジュールされていないグループの場合、この項目は表示されません。
6. **セッション日**を選択します。今日の日付、過去の日付、未来の日付のいずれも指定できます。
7. **保存**をクリックします。

### 礼拝時間内のすべてのクラス分のセッションを追加する

同じ礼拝時間に別のグループも集まる場合（たとえば、日曜9時の子どもたちのクラスすべて）、グループごとに移動しなくても、まとめてセッションを作成できます。

1. 上記の手順に従い、**礼拝時間**を選択します。
2. **_礼拝時間_ のほかの _N_ 件のグループにも追加**にチェックを入れます。チェックボックスには、その礼拝時間に割り当てられている他のグループの数が表示されます。このチェックボックスは、新しいセッションを追加するときに、同じ時間に集まる他のグループが少なくとも1つある場合にだけ表示されます。
3. **保存**をクリックします。

現在のグループと、同じ日付・同じ礼拝時間の他の各グループに対してセッションが作成されます。その日付と礼拝時間にすでにセッションがあるグループは飛ばされるので、重複は作られません。

:::tip
まだ記録していない出席を後から入力するために過去の日付のセッションを作成したり、グループの集会の前に準備しておくために事前にセッションを作成したりできます。
:::

## セッションのメモ {#session-notes}

各セッションにはメモを付けられます。メモには、扱った内容の要約、お知らせ、祈りの課題などを書けます。

1. セッションを追加するとき、またはセッション一覧の横にある**編集**（鉛筆）アイコンをクリックした後、日付の下にある**メモ（扱った内容、お知らせ、祈りの課題）**の欄に入力します。ツールバーで太字、リスト、リンクを追加できます。
2. **保存**をクリックします。

メモはセッションの出席一覧の上部に表示されます。また、B1.churchでグループのページの**ミーティング**欄に表示され、グループのメンバーが読めるミーティングメモにもなります。グループのリーダーはそこでメモを書いたり編集したりすることもできます。詳しくは[グループの詳細](../../b1-church/groups/group-details.md#meeting-notes-and-attendance)を参照してください。

## 出席の記録

セッションを選択すると、その出席一覧が表示されます。グループのメンバーが全員、姓の順に並んで表示され、それぞれにチェックボックスがあります。すでに出席として記録されている人にはチェックが入っています。

1. 出席した人ごとにチェックボックスをオンにします。全員を一度に変更するには、**すべて選択**または**すべて解除**を使います。
2. 一覧の上にある件数（例：「15人中12人出席」）は、チェックボックスを操作するたびに更新されます。
3. **出席を保存**をクリックします。保存するまで記録はされず、保存が完了するとメッセージが表示されます。保存中にブラウザのタブを閉じようとしたり再読み込みしようとしたりすると、変更が失われないようブラウザが先に確認を表示します。

すでに出席として記録されている人のチェックを外して保存すると、その人はセッションから削除されます。

### 訪問者の追加

グループのメンバーではない人を記録するには、出席一覧の横にある人物検索で、その人を検索します。データベースにまだ登録されていない場合は、検索画面から新規に作成できます。どちらの場合も、その人はチェック済みの状態で一覧に追加されます。記録するには**出席を保存**をクリックします。

キオスクでチェックインした人には**奉仕者**または**ゲスト**のラベルが表示されます。グループのメンバーではない人には**ゲスト**のラベルが表示されます。

## まだ出席が未入力のグループの確認

同じ礼拝時間に複数のクラスが集まる場合、その日付で出席がまだ入力されていないクラスをひと目で確認できます。

1. 礼拝時間が設定されているセッションを開きます。
2. 出席一覧の上部にある**まだ出席が必要なグループ**をクリックします。
3. その礼拝時間に割り当てられているすべてのグループが一覧表示されたダイアログが開きます。上部には「8グループ中5グループ入力済み」のような概要が表示されます。

その日付で出席者が1人もいないグループには**未入力**のラベルが表示され、一覧の先頭に並びます。出席のあるグループには**入力済み**と、出席として記録された人数が表示されます（例：「入力済み（12）」）。グループ名をクリックすると、そのグループのセッション一覧が開き、同じ日付のセッションがあらかじめ選択された状態になるので、すぐに出席を記録できます。そのグループにその日付のセッションがまだない場合は、セッション一覧が開くので、セッションを追加できます。

:::tip
**すべてのクラスを印刷**や[礼拝時間内のすべてのクラス分のセッションを追加する](#adding-sessions-for-every-class-in-a-service-time)と組み合わせて使うと便利です。まずセッションを作成し、出席表を配布したら、**まだ出席が必要なグループ**を使って、どの出席表がまだ入力されていないかを確認します。
:::

## 出席表の印刷

出席表は、先生が手書きで出席を記録し、後で入力するために提出してもらえる印刷用のクラス名簿です。各表には、教会のロゴ（[ウェブサイト > 外観](../website/appearance.md)でアップロードした**明るい背景用ロゴ**）と、その下に教会名が表示されます。さらに、クラス名の下に大きな**日付**欄と礼拝時間が表示されます。メンバーは2列に並んで表示されるので（左の列を上から下へ読み、次に右の列を読みます）、1ページにより多くの名前が収まります。各メンバーには**出席**と**欠席**のチェックボックスがあります。また、訪問者用の空欄と**担当者 / メモ**欄もあります。

- **セッションから印刷** -- セッションの出席一覧の上部にある**出席表を印刷**（プリンター）アイコンをクリックします。表にはそのセッションの日付と礼拝時間が表示されます。
- **礼拝時間のすべてのクラス** -- セッションに礼拝時間が設定されている場合は、**すべてのクラスを印刷**をクリックすると、その礼拝時間に割り当てられているクラスごとに1枚ずつ出席表が印刷されます。各クラスは別のページに印刷されます。
- **メンバー一覧から印刷** -- グループのページで**すべてのメンバー**をクリックし、メンバー一覧の上にある**出席表を印刷**アイコンをクリックして**出席表**を選ぶと、日付のない出席表が印刷されます。同じメニューには、各メンバーの電話番号、メールアドレス、住所が載った**連絡先名簿**のレイアウトもあります。詳しくは[メンバー一覧の印刷](../groups/group-members.md#printing-the-member-list)を参照してください。

出席表は新しいタブで開き、ブラウザの印刷ダイアログが自動的に表示されます。

## 出席記録のスプレッドシートへの書き出し

セッションの記録をCSVファイルとしてダウンロードすると、Excel、Numbers、Googleスプレッドシートで利用できます。

1. 書き出したいセッションを開きます。
2. 出席一覧の上部にある**書き出し**ボタンをクリックします。
3. ダウンロードしたファイルをスプレッドシートアプリで開きます。

ファイルには、グループのメンバーごとに1行ずつ、名前と出席か欠席かが記録されます。さらに、セッションの日付とメモも含まれます。

## 記録された出席の確認

セッションを記録すると、そのデータが出席レポートに表示されます。

- **出席の推移**タブ（出席ページの**すべての年**の下）-- 教会全体の時間経過による傾向を表示します。詳しくは[出席の追跡](tracking-attendance.md)を参照してください。
- **グループ別の出席**タブ -- 個々のグループごとの出席を内訳で表示します。詳しくは[出席レポート](../reports/attendance-reports.md#group-attendance)を参照してください。

:::tip
作成したばかりのセッションがすぐにレポートに表示されない場合は、セッションの日付がレポートのフィルターで選択した日付範囲に含まれているかを確認してください。
:::
