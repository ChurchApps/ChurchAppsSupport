# チェックインラベルデザイナー

<div class="article-intro">

ラベルデザイナーでは、家族がお子さまをチェックインするときに印刷されるネームタグと引き取り票のテンプレートを作成し、カスタマイズできます。各ラベルに表示する情報、その配置、見た目を細かく設定できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [出席管理](./setup.md) を設定し、チェックインが有効な礼拝時間を少なくとも 1 つ設定してください
- ラベルが印刷されるように [チェックイン](./check-in.md) を設定してください
- 出席管理セクションへの管理者アクセスが必要です

</div>

## ラベルデザイナーを開く

B1 Admin で、左上の検索バーである [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu) を開き、**Mobile** を展開して **B1 CheckIn** をクリックします。次に、Check-in Labels カードの **Design Labels** ボタンをクリックします。保存済みのラベルテンプレートの一覧が、種類ごとに **Nametag**（ネームタグ）と **Pickup Slip**（引き取り票）に分かれて表示されます。

## ラベルの種類

- **Nametag** — 印刷して子どもに取り付けるラベルです。通常、子どもの名前、クラスやセッション、セキュリティコードが含まれます。
- **Pickup Slip** — 保護者に渡すラベルです。通常、セキュリティコードと、チェックインした子どもの一覧が含まれます。

B1 には、標準的な 3.5 × 1.1 インチのサーマルラベル用に作られた、ネームタグと引き取り票のデフォルトテンプレートが最初から用意されています。

## ラベルテンプレートの作成

1. **Add** をクリックし、メニューから開始点を選びます：**Nametag 3.5" x 1.1"**、**Pickup Slip 3.5" x 1.1"**、または **Blank**。
2. 新しいテンプレートがラベルエディターで開きます。

### ラベルエディター

エディターには、設定されたサイズでラベルの縮小プレビューが表示されます。左側のパネルで次の項目を設定できます：

- **Name** — テンプレート名です（管理用の表示のみ）。
- **Label Type** — Nametag または Pickup Slip
- **Width / Height** — ラベルのサイズ（インチ単位）

### ブロックの追加

ラベルは「ブロック」で構成されます。ブロックとは、ラベルのキャンバス上に配置される個々のコンテンツの要素です。**Add Block** をクリックして新しいブロックを挿入し、その種類を選択します：

- **Field** — 印刷時にデータの値を取り込みます：
  - `person.displayName` — 氏名
  - `sessions` — チェックインしたサービスやクラス
  - `securityCode` — ランダムに生成された引き取り用のセキュリティコード
  - `children` — 子どもの一覧（引き取り票用）
  - `person.nametagNotes` — 本人の記録にある特記事項
  - `person.isBirthdayWeek` — 本人の誕生日（月と日）がチェックインの日の 3 日前から 3 日後までの範囲にある場合は true
  - `campus` — キャンパス名
- **Text** — 入力する固定のテキストです（見出し、ラベル、説明文など）。
- **Barcode** — セキュリティコードをエンコードしたバーコードです。

### ブロックの配置

各ブロックには、ラベルキャンバスに対する割合（0〜100）で指定する **X**、**Y**、**Width**、**Height** の項目があります。これらを調整して、コンテンツを正確に配置します。以下の項目も設定できます：

- **Font Size** — 文字サイズ（ポイント単位）
- **Bold** — 太字のオン／オフを切り替えます。
- **Align** — 文字の配置（左揃え、中央揃え、右揃え）
- **Condition** — 項目が空の場合にブロックを非表示にするかどうかを設定できます（例：値がある場合にのみ nametagNotes を表示）。`person.isBirthdayWeek` と組み合わせると、チェックインの数日前後が誕生日の子どものネームタグにのみ、誕生日のイラストやテキストを表示することもできます。

### 保存

**Save** をクリックしてテンプレートを保存します。更新されたテンプレートは、次回 B1 Checkin でラベルを印刷する際に使用されます。

## テンプレートの並べ替え

ネームタグや引き取り票のテンプレートが複数ある場合、B1 Checkin は既定で一覧の最初のテンプレートを使用します。テンプレートをドラッグして並べ替えてください。

## テンプレートの削除

テンプレートの行にある削除アイコンをクリックし、確認してください。ある種類の最後のテンプレートを削除すると、既定の組み込みテンプレートが復元されます。

:::tip
テンプレートを編集したら、次の礼拝の前にテスト印刷を行い、レイアウトが正しいか確認してください。
:::
