# 出席状況の確認

<div class="article-intro">

キャンパス、礼拝時間、グループの設定が済んだら、B1 Admin で出席データを簡単に確認し、傾向を把握できます。出席ページを開くと今週の出席の概要が表示され、**All years** のレポートには主に2つの表示があります。教会全体の傾向を見る **Attendance Trend** タブと、グループ単位の詳細を見る **Group Attendance** タブです。これらのツールを使って成長の傾向を理解し、参加が減っている箇所を見つけ、教会の意思決定にデータを活用してください。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 出席の設定で、少なくとも1つのキャンパスと礼拝時間を登録しておく必要があります。まだの場合は [出席の設定](setup.md) を参照してください。
- レポートに結果を表示するには、出席データが記録されている必要があります。データは [手動入力](recording-attendance.md) または [セルフチェックイン](check-in.md) から取り込めます。

</div>

## 出席の傾向を表示する

1. **B1 Admin** を開き、画面左上の検索バーである [Jump メニュー](../introduction.md#getting-around-with-the-jump-menu) を開いて **People** を展開し、**Attendance** をクリックします。
2. 左の列で **All years** をクリックします。既定では **Attendance Trend** タブが選択されています。
3. タブを開くとレポートが自動的に実行され、週ごとの出席者総数が表示されます。

:::tip
今週の状況をすばやく確認したい場合は、出席のメインページを見てください。今週会場にいる人数、部屋(グループ)ごとの内訳、ゲストの数、直近13週間のチェックイン数の棒グラフが表示されます。レポートを実行する必要はありません。
:::

## データを絞り込む

**Filter Report** ボックスのフィルターで結果を絞り込み、**Run Report** をクリックします。

- **Campus** -- 特定のキャンパスの出席だけを表示します。
- **Service** -- 1つの礼拝に絞り込みます。
- **Service Time** -- 特定の礼拝時間を選び、その集まりを詳しく確認します。
- **Group** -- 1つのグループの出席を表示します。
- **Start Date** と **End Date** -- 対象とする期間です。既定ではレポートは1年前から今日までの過去1年分を対象とし、終了日は終日含まれます。

レポートには、週ごとの総訪問数の棒グラフと表が表示されます。各週には、その週の日曜日の日付が付きます。表には **Session Dates** 列もあり、その週に出席があった実際の日付を一覧表示します(例: 「9/27, 9/30」)。これにより、週の途中に行われた集まりが日曜日と同じ週にどのように計上されているかを確認できます。

:::info
Attendance Trend タブを開くたびにレポートが自動で実行されるため、更新ボタンを押さなくても常に最新の数字が表示されます。
:::

## グループの出席

**Group Attendance** タブには、各グループの集まりに誰が出席したかが表示されます。礼拝全体の数字ではなく、特定のクラス、奉仕チーム、小グループの状況を把握したいときに役立ちます。

1. **All years** のレポートで **Group Attendance** タブを選択します。
2. 必要に応じて **Campus** と **Service** を選びます。
3. **Start Date** と **End Date** を設定します。既定では前の日曜日から今日までが対象になります。
4. **Run Report** をクリックします。

結果は、まず集まりの日付ごとに、次に礼拝時間とグループごとにまとめられ、各グループの下に出席した人が一覧表示されます。礼拝時間、グループ、名前はアルファベット順に並ぶため、各見出しは1回だけ表示されます。各人の行には、出席が記録された時刻を示す **Checked In** 列(時刻が記録されていない場合は空欄)と、**Membership Status** 列(例: Member や Visitor)も表示されるため、ゲストをひと目で見分けられます。

データをダウンロードするには、**Download Options** をクリックして **Summary** を選択します。CSV ファイルには、グループのメンバーごとに1行があり、グループ、名前の順に並びます。また、対象期間内の日付付きの集まりごとに列があり(例: 「Sunday - 9:00 AM (2026-09-27)」)、各セルには **present** または **absent** が記入されます。

:::tip
グループの出席データは、時間の経過とともにグループ内の参加状況を把握したい [小グループ](../groups/creating-groups.md) のリーダーにとくに役立ちます。
:::

## 出席データを活用するヒント

- 季節的な傾向を早めにつかめるよう、毎月傾向を確認しましょう。
- キャンパス単位のデータを比較し、どの拠点が成長しているかを把握しましょう。
- 出席が減っている [グループ](../groups/group-members.md) には、グループ単位のレポートを使ってフォローアップしましょう。
- [AI 検索](../people/ai-search.md) ツールと組み合わせて、最近出席していない人を見つけましょう。
