# 出席設定

<div class="article-intro">

出席を記録する前に、B1 Admin に教会の物理的な拠点、礼拝の開始時間、そして各礼拝にどのグループが参加するかを設定する必要があります。この一度きりの設定によって、教会全体の出席の追跡とレポートの基盤が作られます。

<div class="prereqs">
<h4>始める前に</h4>

- **出席の編集（Edit Services）** 権限を持つ、有効な B1 Admin アカウントが必要です。**設定（Setup）** オプションは、この権限を持つ人にのみ表示されます。出席を閲覧するだけでは不十分です。アクセスレベルがわからない場合は、[役割と権限](../people/roles-permissions.md)をご覧ください。
- 礼拝の時間にグループを割り当てる予定がある場合は、先に[グループを作成](../groups/creating-groups.md)しておいてください。

## 主要な概念

- **キャンパス（Campus）** -- 教会が集まる物理的な場所（例：「メインキャンパス」「北キャンパス」）。キャンパスは**設定（Settings）**で管理します。
- **礼拝（Service）** -- キャンパスで定期的に行われる集会（例：「日曜礼拝」「水曜集会」）。
- **礼拝時間（Service Time）** -- 礼拝が行われる特定の時刻（例：「9:00 AM」「11:00 AM」）。
- **予定グループ（Scheduled Group）** -- 特定の礼拝時間に割り当てられたグループ。出席はその礼拝の文脈で記録されます。
- **非予定グループ（Unscheduled Group）** -- 礼拝時間に紐づかず、独自に出席を記録するグループ。

## 出席の構造を設定する

1. **B1 Admin** を開き、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開いて、**人（People）**を展開します。
2. **出席（Attendance）**をクリックし、左の列にある**設定（Setup）**をクリックします。**礼拝の構造（Service structure）**の表が開き、上部にキャンパス、礼拝時間、予定グループと非予定グループの数が表示されます。表に追加、編集、削除を行うと、数はすぐに更新されます。
3. **キャンパスを管理（Manage Campuses）**（**礼拝の構造**パネルの右上）をクリックします。**設定 → キャンパス（Settings → Campuses）**に移動します。**キャンパスを追加（Add Campus）**をクリックし、拠点の名前を入力して（住所とタイムゾーンは任意です）、**保存（Save）**をクリックします。
4. **人 → 出席（People → Attendance）**に戻り、**設定（Setup）**をクリックします。登録したキャンパスが設定表に表示されます。
5. キャンパスの下にある**礼拝（Service）**列の **+ ボタン**をクリックします。「日曜礼拝」などの礼拝名を入力し、**保存（Save）**をクリックします。
6. 礼拝の下にある**時間（Time）**列の **+ ボタン**をクリックします。「9:00 AM」などの**礼拝時間**名を入力し、必要に応じて[チェックインのスケジュール](#setting-a-check-in-schedule)を入力して、**保存（Save）**をクリックします。礼拝時間ごとに繰り返してください。
7. グループを礼拝時間に紐づけるには、**人 > グループ（People > Groups）**からグループを開き、**編集（Edit）**をクリックして**礼拝時間を追加（Add Service Time）**を使用します。詳しくは次のセクションをご覧ください。

### グループで出席の追跡を有効にする

グループの出席を記録する前に、そのグループで出席の追跡（Track Attendance）をオンにする必要があります。

1. ジャンプメニューで**人 > グループ（People > Groups）**を選び、グループを選択します。
2. グループ名の下にある**編集（Edit）**ボタンをクリックします。
3. **出席の追跡（Track Attendance）**を**はい（Yes）**に設定します。
4. **保存（Save）**をクリックします。

:::tip
前の手順でグループを礼拝時間に割り当てた場合は、グループの編集画面にある**礼拝時間を追加（Add Service Time）**オプションを使って、正しい礼拝に紐づけてください。これにより、セッションが正しいキャンパスと時間に関連付けられます。
:::

:::tip
水曜の小グループのように、通常の礼拝以外に集まり、独自に出席を記録するグループの場合は、非予定グループのままにしておくこともできます。それでも出席レポートの**グループ出席（Group Attendance）**レポートには表示されます。
:::

## チェックインのスケジュールを設定する

各礼拝時間には任意のチェックインスケジュールを設定できます。これにより、[セルフチェックイン](check-in.md)が毎週自動的に開いたり閉じたりします。スケジュールを設定しない場合、その礼拝時間のチェックインはいつでも利用できます（部屋が満員など、他の理由で閉じられていない限り）。

1. **設定（Setup）**画面で、**時間（Time）**列の礼拝時間の名前をクリックします（または新しく追加します）。
2. **チェックインのスケジュール（Check-in Schedule）**の下で、礼拝時間が行われる曜日の**曜日（Day）**を選択します。
3. **開始時刻（Start Time）**を設定し、必要に応じて**終了時刻（End Time）**を設定します。
4. **チェックイン開始（分前）（Open check-in (minutes before start)）**を入力します。たとえば `30` と入力すると、礼拝開始の30分前にチェックインが開きます。
5. **チェックイン終了（分後）（Close check-in (minutes after end)）**を入力します。たとえば `15` と入力すると、終了時刻の15分後までチェックインが開いたままになります。終了時刻を設定していない場合は、開始時刻から数えます。**終了時刻（End Time）**と**チェックイン終了（Close check-in）**の両方が空欄の場合、その日の終わりまでチェックインが開いたままになります。
6. **保存（Save）**をクリックします。

スケジュールは毎週繰り返され、礼拝が行われるキャンパスのタイムゾーンを基準に計算されます。そのキャンパスにタイムゾーンが設定されていない場合は、教会の[タイムゾーン](../settings/church-settings.md#time-zone)が使われ、それもなければタイムゾーンが設定されている最初のキャンパスのタイムゾーン、最後にイースタン時間（America/New_York）が使われます。チェックインが間違った時刻に開く場合は、[キャンパス](../settings/campuses.md)で該当キャンパスの**タイムゾーン（Time Zone）**を確認してください。スケジュールを削除するには、**曜日（Day）**を**スケジュールなし（No schedule）**に戻して**保存（Save）**をクリックします。スケジュールは、**曜日（Day）**と**開始時刻（Start Time）**の両方が設定されている場合にのみ有効になります。

礼拝時間のチェックインの時間帯が閉じている間は、次のようになります。

- **B1.church のセルフチェックイン**では、その礼拝時間に**閉鎖（Closed）**と表示され（例：**閉鎖 · 日曜 9:30 AM に開始**）、選択できません。礼拝のすべての時間が閉じている場合、家族にはチェックインの開始時刻（例：「チェックインは日曜 9:30 AM に開始します」）が表示されます。
- **B1 Checkin キオスクアプリ**でも、その礼拝時間は開始時刻と共に**閉鎖（Closed）**と表示されます。ある礼拝のすべての時間が閉じている場合、キオスクはその礼拝のチェックインがいつ開始するかを表示します。閉じた礼拝時間にすでにチェックインしている人は、代わりにグループが**チェックイン済み（Checked in）**と表示されます。チェックインの途中で時間帯が閉じた場合、キオスクはチェックインを完了せず、影響を受けた部屋を示す**まだチェックインできません（Can't check in yet）**の画面を表示するので、家族は別の部屋を選べます。

以前の礼拝時間にすでにチェックインした世帯は、前の時間帯が閉じた後でも、まだ開いている後の礼拝時間を追加できます。既存のチェックイン記録は保持されます。

:::tip
早く到着する家族やボランティアがチェックインできるように、開始の30〜45分前など余裕のある開始時間を設定し、礼拝開始後に遅れてくる人もチェックインできるように、終了後の締め切りは短めに設定することをおすすめします。
:::

## 設定を編集する

設定はいつでも更新できます。キャンパス、礼拝時間、またはグループを選択して**編集（Edit）**をクリックすると詳細を変更でき、**削除（Delete）**をクリックすると削除できます。

:::info
礼拝時間を削除しても、過去の出席記録は削除されません。スケジュールを変更しても、過去のデータは保持されます。
:::
