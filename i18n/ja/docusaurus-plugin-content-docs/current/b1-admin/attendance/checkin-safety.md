# チェックインの安全対策

<div class="article-intro">

B1には、チェックインのための子どもの安全管理機能が備わっています。部屋の定員と、ボランティア1人あたりの子どもの人数の上限、キオスクでの年齢・学年の案内、会員・ゲスト・ボランティアを区別するチェックインの種類、そして世帯ごとの信頼できる送迎者リストがあり、チェックアウト時に確認されます。このページでは、B1 Adminで各安全機能を設定する方法を説明します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [出席の構成](setup.md)と[チェックインキオスク](check-in.md)を設定しておいてください
- 部屋は、礼拝時間に紐づいた[グループ](../groups/creating-groups.md)です。以下の安全設定はグループ上にあります
- 保護者への呼び出しと緊急一斉連絡には、接続済みのテキストメッセージサービス（[Text In Church](../integrations/services/text-in-church.md)、[Clearstream](../integrations/services/clearstream.md)、またはMutual Ministry）が必要です

</div>

## 部屋の定員と部屋の受付停止

各チェックインの部屋（グループ）は、独自の上限を設定できます。グループを開き、**編集**をクリックして設定を編集し、**チェックインの定員**セクションを探してください。

- **定員** -- この部屋に同時にチェックインできる最大人数です。部屋が満員になると、そこへのチェックインはできなくなり、キオスクに満員の部屋の名前が表示されます。
- **ゲストの定員** -- 部屋に入れるゲストの人数に対する、任意の別枠の上限です。
- **チェックイン受付停止** -- **はい**に設定すると、この部屋へのすべてのチェックインを直ちに停止します（たとえば、クラスが中止になったときや部屋が使えないときなど）。チェックアウトは引き続き行えます。

## ボランティアの配置比率

グループの**チェックインの定員**セクションには、人員配置のルールも含まれています。

- **ボランティア1人あたりの子どもの人数** -- チェックイン済みのボランティア1人が担当できる子どもの最大人数です（例：5に設定すると、ボランティア1人が子ども5人を担当します）。
- **最低ボランティア数** -- 子どもがこの部屋にチェックインできるようになるまでに、チェックインしている必要があるボランティアの最小人数です。

ボランティアは、キオスクで**ボランティア**の種類を選んでチェックインすると、これらのルールにカウントされます（下の[チェックインの種類](#check-in-types)を参照）。

### 警告と制限の選択

比率をどの程度厳格に適用するかは、教会全体の設定です。

1. B1 Adminで**設定**を開き、**チェックイン**セクションを開きます。
2. **ボランティア比率の適用**を設定します。
   - **警告（確認後に許可）** -- 部屋が比率を超えている、または最低ボランティア数を下回っている場合、キオスクに警告が表示されます。スタッフが確認すれば、そのまま続行できます。これがデフォルトです。
   - **制限（チェックインを防止）** -- 十分な数のボランティアがチェックインするまで、その部屋へのチェックインは拒否されます。

:::info
定員とチェックイン受付停止は常に厳格な上限です。警告か制限かの選択は、ボランティアの比率にのみ適用されます。
:::

## チェックインの種類

チェックインのたびに、その人が**会員**、**ゲスト**、**ボランティア**のいずれかであるかが記録されます。種類は、キオスクの世帯画面にあるチップで選びます（デフォルトは会員です）。種類は安全ルールに反映されます。ボランティアは比率の算定に含まれ、ゲストは部屋のゲストの定員に含まれます。

## 年齢・学年による部屋の案内

各部屋に年齢または学年の範囲を設定できます。これにより、キオスクがご家族を適切な部屋へ案内します。

- グループの設定で**年齢と学年**セクションを使い、部屋の最低年齢・最高年齢（年と月）、および／または学年を設定します。
- キオスクでは、子どもが該当する部屋は強調表示され、該当しない部屋は薄く表示されます。薄く表示された部屋も、スタッフの確認があれば選択できます。この案内が、チェックインを完全にブロックすることはありません。

学年は、教会の**進級日**に切り替わります。

1. B1 Adminで**設定**を開き、**進級**セクションを開きます。
2. 教会で生徒が進級する月と日を設定します（例：8月1日）。キオスクに表示される年齢と学年は、直近の進級日時点で計算されます。

## 信頼できる送迎者と送迎不可の人

各世帯には、その世帯の子どもを迎えに来てもよい人、または来てはいけない人のリストを登録できます。

1. **人物**で人物のページを開き、**送迎**カードを探します。
2. **追加**をクリックします。既存の人物を検索するか、システムに登録されていない人は、**名前**、**続柄**、写真を入力して追加します。
3. **ステータス**を設定します。
   - **信頼できる** -- チェックアウト時、この人は写真付きのタップ可能な送迎カードとして表示され、確認済みの送迎を素早く行えます。
   - **送迎不可** -- この名前で送迎しようとする人がいた場合、キオスクは警告を表示してチェックアウトをブロックします。スタッフは上書きできます。上書きの記録は出席記録に残ります。

カード上の人のステータスのチップをクリックすると、「信頼できる」と「送迎不可」を切り替えられます。

:::tip
信頼できる送迎者には、可能な限り写真を登録してください。チェックアウト画面に写真が表示されるため、ボランティアは目の前の人物を視覚的に確認できます。
:::

## 保護者への呼び出しと緊急一斉連絡

どちらの機能も、教会が接続しているテキストメッセージサービスを通じてメッセージを送信します。内蔵のSMSサービスはないため、まずサポートされているサービスのいずれかを設定しておく必要があります。

- **保護者への呼び出し** -- スタッフが対応中のキオスクのチェックアウト画面から、チェックイン済みの子どもの保護者に、テキストメッセージを送信できます（例：「保育室までお越しください」）。
- **緊急一斉連絡** -- スタッフがキオスクの管理設定から、選択した礼拝について、チェックイン済みのすべての世帯の保護者に一度にテキストメッセージを送信できます。送信するには、確認のために**EMERGENCY**と入力する必要があります。

テキストメッセージの受信を停止している人や、携帯電話番号が登録されていない人は自動的にスキップされます。キオスクには、送信された件数とスキップされた件数が表示されます。

キオスク側の手順は、[チェックアウトと子どもの安全](../../b1-checkin/check-in/checking-out.md)を参照してください。
