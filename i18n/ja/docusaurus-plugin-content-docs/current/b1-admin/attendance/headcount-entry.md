# 出席者数の入力とトレンド

<div class="article-intro">

出席者数では、名前付きの名簿を確認せずに、礼拝・礼拝時間・グループごとの合計出席人数を簡単に記録できます。「何人来ていたか」だけを知りたいときに使い、出席者数トレンドレポートと組み合わせると、その数値の推移を確認できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- キャンパス、礼拝、礼拝時間が設定されている必要があります。[出席の設定](setup.md)を参照してください。
- 出席者数を入力するには**出席 &gt; 編集**の権限が必要です。トレンドレポートを閲覧するには**出席 &gt; 表示**の権限が必要です。[役割と権限](../settings/roles-permissions.md)を参照してください。

</div>

:::info
出席者数は、[出席の記録](recording-attendance.md)の合計のみの代替手段です。**誰が**出席したかを把握する必要がある場合(例: 最近来ていない人へのフォローアップ)は、グループのセッションで名前付きの出席記録を引き続き使用してください。出席者数は数値のみを保存します。
:::

## 出席者数の記録

1. **B1 Admin** を開き、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)(左上の検索バー)を開いて、**People** を展開し、**Attendance** をクリックします。
2. 左側の列にある **Enter headcount** をクリックします。
3. フォームに入力します:
   - **Service**(*必須*)
   - **Service Time** -- 空欄のままにすると、すべての礼拝時間を合計した数値として記録されます
   - **Group** -- 任意です。出席の追跡が有効なグループのみが一覧に表示されます。「No group (whole service)」にしたい場合は空欄のままにします。
   - **Date**
   - **Headcount** -- 出席した人の合計数
4. **Save** をクリックします。

フォームの横にある **Recent Headcounts** の表には、直近の数件の記録が日付、礼拝、礼拝時間、グループ、人数とともに表示されます。修正や削除が必要な場合は、行をクリックするとフォームに読み込まれます。

## 出席者数トレンドレポート

1. 同じ **Attendance** ページで、左側の列の **All years** をクリックし、**Headcount Trend** タブを選択します。
2. **Campus**、**Service**、**Service Time**、**Group** のフィルターを使って、レポートを絞り込みます。

レポートには、記録された出席者数が週ごとに合計されて、折れ線グラフと表の両方で表示されます。これは[出席トレンドとグループ出席タブ](tracking-attendance.md)と同じレポートの形式です。今週入力された出席者数は、メインの Attendance ページの **Headcounts this week** にも表示されます。
