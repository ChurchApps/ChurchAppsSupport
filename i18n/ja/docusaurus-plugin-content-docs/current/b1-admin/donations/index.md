# 寄付

<div class="article-intro">

B1 Admin の寄付セクションでは、教会の献金管理に必要なすべての機能を利用できます。週ごとの献金の記録から年末の税務明細書の作成まで、寄付に関するツールがひとつにまとめられているので、教会の財務を常に把握できます。

</div>

## サブセクション

寄付セクションには、次のページがあります。

### 概要

**概要**ページでは、すべての献金の動きを視覚的に確認できます。グラフやフィルター付きのレポートが表示されるので、教会全体の寄付の傾向をすばやく把握できます。概要とレポートのツールの詳しい使い方については、[寄付レポート](donation-reports.md)をご覧ください。

### バッチ

**[バッチ](batches.md)**では、寄付をグループにまとめられます。たとえば、日曜日の献金で集めた小切手や現金をひとつのバッチにまとめられます。各バッチには寄付の件数と合計金額が記録されるので、照合がしやすくなります。バッチの集計が終わったら、**寄付の編集**権限を持つ人がそのバッチを締めることができます。締めたバッチは、集計を担当するボランティアが変更できなくなります。**寄付の入力**権限を持つボランティアは、寄付セクションの他の部分を見ることなく、未締切のバッチに献金を追加できます。

### ファンド

**[ファンド](funds.md)**では、寄付を目的別に分類します。一般会計、建築基金、宣教などが一般的な例です。各ファンドについて、税控除の対象かどうかを設定できます。

### 明細書

**[明細書](giving-statements.md)**ページでは、寄付者向けの年末の献金明細書を作成できます。個別のCSVファイルをダウンロードすることも、すべての明細書をまとめて印刷することもできます。

### Stripe インポート

オンライン献金をStripeで受け付けている場合は、**[Stripe インポート](stripe-import.md)**ツールを使って、それらの取引をB1 Admin に取り込めます。これにより、すべてのデータを1つのシステムで管理できます。

## オンライン献金

B1 Admin は、オンライン献金の受け付けに**Stripe**と**PayPal**を利用できます。設定が完了すると、会員はB1.church のサイトから献金でき、それらの寄付は自動的に記録に反映されます。設定を始めるには、[オンライン献金の設定](online-giving-setup.md)をご覧ください。

:::tip
B1 Admin での寄付の管理が初めての場合は、まず[ファンドを設定](funds.md)し、次に[最初のバッチを作成](batches.md)して、そのバッチに[寄付を記録](recording-donations.md)することから始めてください。
:::
