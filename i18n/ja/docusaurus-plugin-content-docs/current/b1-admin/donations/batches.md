# 献金バッチ

<div class="article-intro">

バッチは、献金をまとめて管理し、照合しやすくするための単位です。通常、1つのバッチは日曜日の献金や特別行事での献金など、1回の集金を表します。バッチを使うと整理しやすくなり、記録が実際の入金と一致しているかを簡単に確認できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 献金を記録するときに利用できるよう、[資金を設定](funds.md)しておいてください
- バッチページを表示するには、**寄付の概要を表示**、**寄付を編集**、または**寄付を入力**の権限が必要です（[バッチを変更できる人](#who-can-change-a-batch)を参照）

</div>

## バッチページ

**寄付 > バッチ**に移動すると、バッチの一覧が表示されます。各行には次の項目が表示されます。

- **名前** -- バッチに付けたラベル
- **日付** -- 集金の日付
- **寄付件数** -- バッチに含まれる個別の寄付の件数
- **合計** -- 合計金額
- **状態** -- **未締め**または**締め済み**（[バッチの締めと締め直し](#closing-and-reopening-a-batch)を参照）

一覧の上には年のボタンがあり、特定の年のバッチだけを表示したり、**すべて**のバッチを表示したりできます。一行の要約には、表示中のバッチの件数、寄付の件数、合計金額が表示されます。

## 新しいバッチの作成

1. ページ上部の**バッチを追加**をクリックします。
2. わかりやすい名前を入力します（例：「日曜礼拝の献金 - 2月9日」）。
3. 集金の日付を選択します。
4. **保存**をクリックします。

新しいバッチが一覧に表示され、寄付を追加できる状態になります。

## バッチの操作

- **寄付を表示** -- バッチ名をクリックすると、そのバッチに含まれる個別の寄付がすべて表示されます。そこから寄付を追加、編集、削除できるほか、**CSVをインポート**をクリックして、スプレッドシートから多数の寄付を一度に追加することもできます（[CSVファイルから寄付をインポートする](recording-donations.md#importing-donations-from-a-csv-file)を参照）。
- **バッチの詳細を編集** -- バッチの行にある**編集**ボタンをクリックすると、名前や日付を変更できます。バッチを削除できるのは**寄付を編集**の権限を持つ人だけです。
- **並べ替え** -- 列見出しを使って、名前または日付順にバッチを並べ替えます。
- **エクスポート** -- ページ上部の**エクスポート**をクリックすると、表示中のバッチをスプレッドシート（CSV）としてダウンロードできます。
- **失敗したイベント** -- 決済ゲートウェイでの問題が報告されている場合、ページ上部に**失敗したイベント**ボタン（未解決のイベント数付き）が表示されます。クリックすると、バッチの下にあるイベント一覧の表示と非表示を切り替えられます。
- **Stripeからのインポート** -- ページ上部の**不足しているStripe取引をインポート**をクリックすると、[Stripeインポート](stripe-import.md)ツールが開きます。このボタンは、教会の献金ゲートウェイがStripeの場合にのみ表示されます。

## 寄付を入力した人

バッチに入力された寄付には、寄付者の名前の下に**入力者**と担当者の名前が表示されます。そのため、署名シートがなくても誰が入力したかがわかります。B1は、サインインしている人を自動的に記録します。その後に寄付を編集しても、この情報は変わりません。**CSVをインポート**で取り込んだ寄付には、インポートを実行した人が表示されます。

オンライン献金、[Stripeインポート](stripe-import.md)ツールで追加された寄付、および2026年11月にこの機能が追加される前に入力された寄付には、名前は表示されません。

## バッチの締めと締め直し

バッチを数えて入金し終えたら、締めてください。そうすると、寄付は締めた時点の状態のまま変わらなくなります。

1. バッチを開きます。
2. ページ上部の**バッチを締める**をクリックします。

バッチ名の横にある状態のチップが**未締め**から**締め済み**に変わり、バッチページの**状態**列にも**締め済み**と表示されます。また、バッチの上部に、このバッチが締められていることを示す通知が表示されます。バッチが締められている間も、**寄付を入力**の権限を持つ人はバッチを表示できますが、寄付の追加、編集、削除や、バッチ名と日付の変更はできません。

再び変更するには、バッチを開いて**バッチを締め直す**をクリックします。新しいバッチは、常に未締めの状態で作成されます。

:::info
**バッチを締める**と**バッチを締め直す**のボタンが表示されるのは、**寄付を編集**の権限を持つ人だけです。また、この権限を持つ人は、修正が必要な場合にバッチを締め直さなくても、締めたバッチ内の寄付を変更できます。
:::

## バッチを変更できる人

バッチを扱える権限は、次の2つの[役割の権限](../settings/roles-permissions.md)です。

- **寄付を編集** -- すべての操作が可能です。バッチの追加と削除、締めと締め直し、バッチが未締めか締め済みかに関係なく、任意の寄付の追加、編集、削除ができます。
- **寄付を入力** -- 献金を数える係や、献金を入力するボランティアのための権限です。バッチの追加と、寄付の追加、編集、削除ができますが、バッチが未締めの間に限られます。バッチの削除、締めや締め直し、オンライン献金で入ってきた寄付の変更はできません。

**寄付を入力**の権限を持ち、**寄付の概要を表示**の権限を持たない人には、B1 Adminメニューに**寄付**が表示されます。これをクリックすると、バッチページに直接移動します。**概要**、**資金**、**キャンペーン**、**寄付明細書**は、この人には表示されません。バッチを開いて中の寄付を見るには、その役割に**寄付を表示**の権限も必要です。

:::tip
よくある設定として、「集計チーム」の役割に**寄付を入力**と**寄付を表示**の権限を与え、入金の照合が済んだ後に各バッチを締める会計担当者には**寄付を編集**の権限を与える方法があります。
:::

## バッチの印刷

バッチを開き、寄付一覧の上にある**印刷**をクリックすると、集計チームや入金記録用に紙のコピーを印刷できます。印刷物には次の内容が含まれます。

- 教会のレターヘッド -- ロゴ（[ウェブサイト > 外観](../website/appearance.md)の**明るい背景用ロゴ**、アップロードしている場合）と、その下に教会名を表示します。続けてバッチ名とバッチの日付が表示されます。
- バッチ内のすべての寄付 -- 寄付者の名前、入力者、方法、メモ、日付、金額を含みます（返金された献金には取り消し線が引かれ、返金済みと表示されます）
- **資金の小計** -- バッチ内の各資金に寄付された合計額
- **バッチの合計** -- バッチ全体の合計金額

**印刷**ボタンは、バッチに寄付が1件以上ある場合にのみ表示されます。

### 複数のバッチをまとめて印刷する

ある期間のバッチをまとめて印刷するには（たとえば先月分の入金すべて）、**バッチ**ページの上部で、**エクスポート**の隣にある**印刷**をクリックします。**バッチを印刷**ページが開き、画面上のバッチに合わせた**開始日**と**終了日**が表示されます。選択した年の1月1日から12月31日まで、または**すべて**を選択した場合は最も古いバッチの日付から最も新しいバッチの日付までが設定されます。どちらの日付も変更して、別の期間を選択できます。

指定した期間内（開始日と終了日を含む）の日付のバッチはすべて、1つのバッチにつき1ページで、日付順に印刷されます。レイアウトは、単一バッチの印刷物と同じです。寄付のないバッチは除外されます。期間内のバッチに寄付が1件もない場合は、「この日付範囲に寄付のあるバッチはありません。」と表示されます。**印刷**をクリックするとブラウザの印刷ダイアログが開き、**閉じる**をクリックするとバッチ一覧に戻ります。

## バッチをQuickBooks Onlineにエクスポートする

バッチを開き、**QuickBooks用にエクスポート**をクリックすると、バッチが仕訳としてダウンロードされます。このファイルは、QuickBooks Onlineにインポートできます（**設定 > データのインポート > 仕訳**）。ファイルには、バッチの合計額を**未入金資金**に借方として記録する行が1つと、各資金に対して貸方として記録する行が1つずつ含まれます。勘定科目名には、各資金の名前が使用されます。インポート時にQuickBooksから、これらの名前を勘定科目表に対応付けるよう求められます。そのため、会計担当者が収入科目を呼ぶ名前と同じように資金に名前を付けるか、インポート時に一度だけ対応付けを設定してください。

:::tip
後で見つけやすいように、バッチには一貫した名前を付けてください。日付と集金の種類を含めると（例：「日曜午前 - 2025-02-09」）、件数が増えても一覧を整理しておけます。
:::
