# 寄付明細書

<div class="article-intro">

毎年末、寄付者は税控除の対象となる寄付の概要を記録用に必要とします。B1 Admin を使えば、すべての寄付者分の明細書をまとめて作成でき、手作業にかかる何時間もの時間を節約できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [基金](funds.md)が**税控除対象**として正しく設定されていることを確認してください。税控除対象の基金への寄付のみが明細書に表示されます
- すべての寄付が[記録](recording-donations.md)され、オンライン取引がある場合は[Stripe からインポート](stripe-import.md)されていることを確認してください

</div>

## 寄付明細書へのアクセス

1. **B1 Admin** で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)(左上の検索バー)を開き、**寄付**を展開します。
2. **寄付明細書**をクリックします。**一括寄付明細書**ページが開きます。

## 明細書の作成

1. **年を選択**パネルで、ドロップダウンから**年**を選択します。今年または過去5年のいずれかを選べます。
2. ページには、その年(1月1日から12月31日まで)に日付が設定された寄付のみが読み込まれるため、教会の寄付履歴が何年分あっても素早く開きます。別の年を選ぶと、その年の寄付で概要が更新されます。年の下にある**概要**パネルには、次のようなその年の統計が表示されます。
   - **寄付者数合計** -- 寄付をした人の数
   - **寄付件数合計** -- 個々の寄付記録の数
   - **寄付金額合計** -- すべての寄付の合計金額

## 明細書のダウンロード

**ダウンロードオプション**パネルには、寄付者に明細書を届けるための2つの方法があります。

### CSVファイルとしてダウンロード

**個別のCSVファイル**の下にある**ZIPをダウンロード**をクリックすると、寄付者ごとの個別のCSVファイルを含むZIPファイルがダウンロードされます。明細書を個別にメールで送りたい場合や、他のシステムにインポートしたい場合に便利です。

### 明細書をすべて印刷

**印刷用明細書**の下にある**すべて印刷**(ボタンには明細書の数が表示されます)をクリックすると、選択した年のすべての寄付者の明細書の印刷用ビューがブラウザーに開きます。そこからブラウザーの印刷機能を使ってプリンターに送信してください。各明細書は新しいページから始まるため、折りたたんで郵送できる状態になります。明細書は寄付者の姓、次に名の順に並びます。

[ウェブサイト > 外観](../website/appearance.md)で**明るい背景用ロゴ**をアップロードしている場合、各明細書の明細書タイトルの上、中央にロゴが印刷されます。これは**すべて印刷**と、寄付者の記録から印刷する個別の寄付者の明細書の両方に適用されます。

:::tip
記録が新しいうちに、1月の早い時期に明細書を作成しましょう。明細書を作成する前に、基金が税控除対象として正しく設定されているか再確認してください。税控除対象の基金への寄付のみが含まれます。
:::

:::info
寄付明細書には、**税控除対象**設定が有効な基金に割り当てられた寄付のみが含まれます。基金が税控除対象として設定されていない場合、その基金の寄付は明細書に表示されません。この設定は[基金](funds.md)ページで管理できます。
:::

## カナダ、オーストラリア、ニュージーランドの領収書形式

米国以外の教会は、明細書をそれぞれの国の公式な領収書のレイアウトに切り替えることができます。寄付明細書ページの上部にある**明細書の形式**をクリックするか(または**設定**に移動して**寄付**セクションを開きます)、**明細書の形式**を**カナダ**、**オーストラリア**、または**ニュージーランド**に設定し、表示される項目に入力します。入力する項目は、登録番号(カナダ税務署の登録番号、ABN、またはニュージーランドの慈善団体登録番号)、組織の住所、領収書への署名権限を持つ人の名前、そしてカナダの場合は領収書を発行する都市です。

明細書には、税務当局が求める文言が記載されます(カナダの場合は「Official Receipt for Income Tax Purposes」(所得税申告用の公式領収書)とCRAの参照番号)。さらに、`YEAR-DONORID` の形式の領収書番号、税控除対象の基金からの寄付のみで計算された控除対象金額、非控除対象の基金への寄付に関する別の行も含まれます。寄付者が B1.church から自分の明細書を印刷すると、同じ領収書の欄が表示されます。

## B1.church でメンバーに表示される内容

同じ**寄付**設定セクションで、B1.church の各メンバーの寄付ページに表示される内容も管理します。

- **メンバーの寄付履歴**では、メンバーが閲覧できる年を選択します。初期設定は**全年**です。**2025年まで**(または他の年)を選ぶと、その年までの履歴のみが表示されるため、許可するまでメンバーはそれ以降の年を閲覧または印刷できません。修正や返金の作業が終わるまで今年の表示を控えたいときに使ってください。**非表示**にすると、寄付履歴、年間合計、明細書の印刷がすべて表示されなくなります。メンバーは引き続き寄付できます。
- **寄付に関する注記**は、メンバーの寄付ページと寄付履歴に表示される短いメッセージで、ここで作業する寄付明細書を含め、すべての寄付明細書の下部に印刷されます。返金ポリシーなどの内容に使用してください。

これらの設定が変えるのはメンバーに表示される内容のみです。このページからは引き続き任意の年の明細書を印刷できます。
