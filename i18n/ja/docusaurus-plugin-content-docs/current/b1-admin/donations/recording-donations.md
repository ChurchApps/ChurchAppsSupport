# 寄付の記録

<div class="article-intro">

B1 Admin で寄付を記録するには、バッチ機能を使います。まずバッチを作成して献金の集まり（日曜日の献金など）を表し、そのバッチに個々の寄付を追加します。こうすることで、献金の記録を整理しやすくなり、照合もしやすくなります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 寄付を正しい区分に割り当てられるよう、[資金](funds.md)を設定してください
- 入力する寄付を保存するための[バッチ](batches.md)を作成してください
- 献金者を照会できるよう、寄付者が[人物ディレクトリ](../people/adding-people.md)に登録されていることを確認してください
- バッチに寄付を入力するには、**寄付の編集**、または**寄付の入力**と**寄付の表示**の両方の権限が必要です（[バッチを変更できる人](batches.md#who-can-change-a-batch)を参照）

</div>

## バッチの作成と寄付の追加

1. **B1 Admin** で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（画面左上の検索バー）を開き、**寄付**を展開して、**バッチ**をクリックします。
2. ページ上部の **バッチを追加** をクリックします。
3. バッチの名前（例：「日曜献金 - 1月5日」）を入力し、日付を選択します。**保存** をクリックします。
4. 新しいバッチが一覧に表示され、寄付件数は 0、金額は $0.00 と表示されます。
5. **バッチ名** をクリックして開きます。

## 個々の寄付の入力

1. バッチの詳細ページでは、寄付の一覧の横に寄付入力パネルが表示されます。**人物または匿名を選択** の下の検索欄に寄付者の名前を入力して探すか、**匿名** をクリックします。（ページ上部の **寄付を追加** をクリックすると、このパネルに移動します。）
2. 人物を選択すると、入力フォームに **日付**、**方法**（小切手、現金、カード、現物から選択）、**資金**、**メモ**、**金額**、そして **小切手番号**（カード献金の場合は **下4桁**、現物献金の場合は内容を説明する **品目**）の各項目が表示されます。別の人物を選ぶには、寄付者名の横の **変更** をクリックします。
3. 詳細を入力して **寄付を追加** をクリックします（または Enter キーを押します）。
4. 寄付が寄付の一覧に追加され、フォームがリセットされるので、次の寄付を入力できます。

:::info
バッチが[締め切り](batches.md#closing-and-reopening-a-batch)られている場合、**寄付の編集** 権限がない人には入力パネルと **編集** リンクが表示されず、バッチの上部に締め切られていることを示す通知が表示されます。**寄付の編集** 権限を持つ人に再開してもらってください。
:::

:::tip
バッチのページを離れずに、複数の寄付を続けて素早く入力できます。小切手や献金封筒の束を効率よく処理できるよう、入力のたびにフォームがリセットされます。
:::

## CSV ファイルからの寄付のインポート {#importing-donations-from-a-csv-file}

寄付のデータがすでにスプレッドシートにある場合（たとえば別の献金システムからの書き出しや、集計担当者の集計表など）は、一件ずつ入力する代わりにバッチへインポートできます。

1. バッチを開き、ページ上部の **CSV をインポート** をクリックします。（このボタンは、バッチを変更できる権限があり、教会に[資金](funds.md)が少なくとも 1 つ登録されている場合に表示されます。）
2. **CSV ファイルを選択** をクリックして、ファイルを選びます。ファイルには見出し行が必要で、列の順序は任意です。
   - **金額**（必須。`Total` も使用できます）-- 通貨記号やカンマは無視されるので、`$1,250.00` でも問題ありません。金額は 0 より大きい必要があります。
   - **日付** -- `2026-10-25` または `10/25/2026` のような形式を使用します。空欄の場合は、バッチの日付が使われます。
   - **資金** -- 資金の名前です。大文字・小文字は区別されません。空欄の場合は、最初の資金が使われます。
   - **方法** -- **小切手**、**現金**、**カード**、**現物** のいずれかです。空欄の場合は **小切手** が使われます。
   - **小切手番号** -- 小切手番号（またはその他の支払いの詳細）です。
   - **メモ**
   - **メール**、**名前**、または **名** と **姓** -- 寄付者をデータベース内の人物と照合するために使用されます。「Smith, John」のように書かれた名前は「John Smith」として読み取られます。
3. プレビューを確認します。各行には、行番号、ファイルに記載された寄付者、**照合結果**、資金、金額が表示されます。
   - 人物の名前が表示されている場合、寄付者が照合されたことを意味します。B1 はまずメールアドレスで、次に完全一致する名前で照合し、該当する人物が 1 人だけの場合にのみ照合します。
   - **見つからない — 匿名** と表示される場合は、一致する人物が見つからなかったことを意味します。その寄付は匿名としてインポートされ、後で割り当てられるように、メモに寄付者名を含む「インポート元:」が追加されます。
   - **無効な金額**、**不明な資金**、**不明な方法**、**無効な日付** などの赤いメッセージは、その行がスキップされることを意味します。ファイルを修正して再度選択すると、その行が含まれます。
4. **インポート** をクリックします（ボタンには、インポートされる行数が表示されます）。寄付がバッチに追加されます。

:::tip
インポート後は、匿名の寄付で **編集** を使い、正しい人物を選択してください。「インポート元:」のメモには、ファイルでその寄付の提供者とされていた人物が表示されています。
:::

## 人物の記録からの献金の登録

バッチを開かずに単一の献金を記録するには、**人物** で寄付者の記録を開き、**献金を記録** をクリックします（献金の概要、または人物の献金ビューにあります）。

1. **日付** と **金額** を設定します。
2. **資金** と **方法**（小切手、現金、カード、現物から選択）を選び、必要に応じて **小切手番号**、**下4桁**、または（現物献金の場合は）**品目** を入力します。
3. 必要に応じて **メモ** を追加し、**保存** をクリックします。

献金は、その日付のバッチに保存されます。その日付のバッチがまだ存在しない場合は、日付を名前にしたバッチが自動的に作成されます。

## 1 つの寄付を複数の資金に分割する

1 人の寄付者が 1 回の取引で複数の資金に寄付することがあります。その場合は次のように処理します。

1. 入力パネルの下にある **詳細な寄付エディタ** のリンクをクリックします（または、既存の寄付の行で **編集** をクリックします）。
2. 詳細エディタで、異なる資金に金額を追加します。合計は、各資金の金額から自動的に計算されます。
3. **保存** をクリックして寄付を更新します。

:::info
1 人の寄付者が、一般基金や宣教など複数の目的を指定した小切手を 1 枚書く場合、寄付を複数の資金に分割することはよくあります。
:::

## 寄付の編集と削除

寄付を編集するには、バッチ内のその行にある **編集** ボタンをクリックします。日付、金額、資金、支払い方法（小切手、現金、カード、現物から選択）、その他の詳細を変更できます。現物献金の場合、エディタでは詳細欄のラベルが **品目** になり、提供された物を説明できます。完了したら **保存** をクリックします。

:::tip
ページ上部のバッチ名の下の行は、項目を追加または編集すると、バッチの日付、献金件数、合計金額を自動的に更新して表示します。預け入れ伝票との照合に使用してください。
:::

## 寄付の返金

寄付者が誤って請求された場合や、返金を求めた場合は、完了した寄付を編集画面から直接返金できます。決済ゲートウェイのダッシュボードに移動する必要はありません。

1. 寄付を開き、**編集** をクリックします。
2. フォーム下部の削除の横にある **返金** ボタンをクリックします。
3. ダイアログで確認します。「この寄付を決済ゲートウェイ経由で全額返金しますか？この操作は取り消せません。」

寄付は元の決済ゲートウェイを通じて全額返金され、寄付の一覧では **返金済み** と表示されます。

:::warning
返金は全額のみ可能です。B1 Admin から一部のみを返金する方法はありません。また、返金は一度確定すると取り消せません。
:::

:::info
**返金** ボタンは、オンラインで支払われた寄付（決済ゲートウェイの取引がある寄付）で、まだ **完了** ステータスのものにのみ表示されます。手入力された寄付（現金、小切手）には返金する決済ゲートウェイの取引がないため、代わりに編集または削除してください。
:::

## 1 件の献金の領収書の印刷

小切手を渡されたとき、イベントや T シャツの代金が支払われたとき、または来訪した団体から寄付があったときは、バッチ全体や年末の明細書の代わりに、その献金だけの領収書を印刷できます。

1. その寄付を含むバッチを開きます。
2. 寄付の行の **編集** の横にある **領収書** をクリックします。寄付の編集フォームの下部にある **領収書** からも実行できます。
3. **印刷** をクリックするか、戻るには **閉じる** をクリックします。

領収書は、献金明細書と同じレイアウトを使用します。教会と寄付者（または「匿名」）、献金の日付と方法、各資金と金額、メモ、教会の献金メモ、そして **明細書の形式** を設定している場合は正式な領収書欄が表示されます（[献金明細書](giving-statements.md)を参照）。その欄の領収書番号は、寄付の ID です。

:::info
「物品またはサービスの提供なし」という文言は、その献金に含まれるすべての資金が税控除対象としてマークされている場合にのみ印刷されます。イベント参加費や購入品など、控除対象外の資金に献金の一部が含まれる場合、その文言は省かれ、慈善的な寄付ではなく支払いとして読めるようになります。
:::

:::tip
オンラインの献金には、自動的にお礼のメールが送信されるため、領収書は主に手入力した献金に役立ちます。
:::
