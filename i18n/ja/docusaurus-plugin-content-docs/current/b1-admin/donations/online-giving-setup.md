# オンライン献金の設定

<div class="article-intro">

B1 Adminは**Stripe**、**PayPal**、**Kingdom Funding**、**Paystack**（アフリカの教会向け）と連携しているため、メンバーはB1.church サイトからオンラインで献金できます。設定が完了すると、オンラインの寄付は手入力の献金と一緒に寄付記録へ自動的に表示され、すべてを1つのシステムで管理できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 献金者が献金の用途を指定できるよう、[寄付基金](funds.md)を設定してください
- [stripe.com](https://stripe.com)でStripeアカウントを作成し、有効化してください（テストモードを解除します）
- B1 Adminのログイン情報を用意してください

</div>

## Stripeの設定

1. まだアカウントをお持ちでない場合は、[stripe.com](https://stripe.com)でアカウントを作成してください。必ず**アカウントを有効化**し、テストモードを解除してください。
2. Stripeで**Developers > API Keys**に移動します。
3. **Publishable Key**（公開可能キー）をコピーします。
4. [B1 Admin](https://admin.b1.church/)にログインします。
5. **Settings**に移動し、**Giving**セクションを開きます。
6. **Giving**セクションの**Edit**をクリックします。
7. **Provider**を**Stripe**に設定します。
8. Publishable Keyを**Public Key**欄に貼り付けます。
9. Stripeに戻り、**Secret Key**（シークレットキー）を表示します（表示は一度だけなので、必ずバックアップを保存してください）。
10. Secret Keyを**Secret Key**欄に貼り付け、**Save**をクリックします。

:::warning
Stripeのシークレットキーは一度しか表示されません。Stripeダッシュボードから離れる前に、安全な場所にコピーしてください。紛失した場合は、新しいキーを生成する必要があります。
:::

## 通貨の選択

プロバイダーとしてStripeを選択すると、APIキーの横に**Currency**（通貨）のドロップダウンが表示されます。寄付が正しく請求されるよう、Stripeアカウントの決済通貨と一致する通貨を選択してください。

対応している通貨には、USD、EUR、GBP、CAD、AUD、INR、JPY、SGD、HKD、SEK、NOK、DKK、CHF、MXN、BRLなどがあります。アカウントの既定の通貨は、[Stripeダッシュボード](https://dashboard.stripe.com/settings/currencies)で確認または変更できます。

:::info
ここで選択した通貨は、単発の寄付、定期的なサブスクリプション、手数料の計算、寄付レポートに使用されます。後から通貨を変更した場合、新しい寄付とサブスクリプションだけが新しい通貨を使用します。既存の定期献金は、作成時の通貨のまま継続されます。
:::

:::warning
Stripeアカウントが選択した通貨を受け付けるように設定されていることを確認してください。Stripeアカウントが選択した通貨に対応していない場合、チェックアウト時に寄付が失敗します。
:::

## Apple PayとGoogle Pay

Stripeを利用している教会では、公開の献金ページにApple PayとGoogle Payのボタンが自動的に表示されます。単発の献金では、献金者が基金と金額を選択すると、カード入力欄の上にボタンが表示されます。ボタンは、献金者のブラウザやデバイスにウォレットが設定されている場合にのみ表示されます。定期献金では、引き続きカードまたは銀行口座の入力欄を使用します。

Google Payは設定不要です。Apple Payを利用するには、献金ページのドメインをStripeに登録する必要があります。B1は、ドメインで献金ページが初めて読み込まれたときに自動的に登録します。iPhoneでApple Payボタンが表示されない場合は、Stripeダッシュボードの**Settings > Payment method domains**を確認し、`yoursubdomain.b1.church`（またはカスタムドメイン）が一覧に含まれ、確認済みになっていることを確かめてください。

## 匿名の献金

公開の献金ページで、献金者は**Give anonymously**（匿名で献金する）にチェックを入れることができます。匿名の献金には献金者の情報が紐付けられず、献金者が選んだ基金には引き続き入金され、バッチやレポートでは**Anonymous**（匿名）と表示されます。領収書を送るために献金者のメールアドレスは引き続き必要ですが、個人の記録は作成されません。匿名の献金は単発のみで、どの献金明細書にも表示されません。

## 定期献金の失敗

Stripeでの定期献金が失敗した場合（たとえばカードの有効期限切れや拒否など）、失敗した請求は**Donations > Failed Gifts**（寄付 > 失敗した献金）に、献金者、金額、日付、およびゲートウェイが返した理由とともに表示されます。献金者が支払い方法を更新したら、**Retry**（再試行）をクリックして請求を再度試みてください。

請求が失敗した場合、B1は献金者にメールを送信します。さらに、まだ決済が完了していない場合は3日後と7日後にもメールを送り、B1.churchで支払い方法を更新するためのリンクを案内します。

:::info
この機能が登場する前にStripeを設定していた場合は、**Settings** > **Giving**を開き、編集をクリックして、**Save**を一度クリックしてください。これによりStripeのWebhookが更新され、失敗した請求がB1に報告されるようになります。
:::

## B1.churchサイトに献金ページを追加する

1. [b1.church](https://b1.church/)にアクセスし、ログインします。
2. **Settings**アイコンをクリックします。
3. **Add Tab**をクリックします。
4. 種類として**Donation**を選択します。
5. タブの名前を入力します（例：「Give」）。その後、**Save**をクリックします。
6. 必要に応じてタブのアイコンを変更します。アイコンの検索欄に「Giv」と入力すると、献金に関連するアイコンが見つかります。

これで献金ページが公開されました。メンバーは`yoursubdomain.b1.church/donate`にアクセスできます。

## 献金のリンクを共有する

献金用のURLを確認するには、**B1 Admin**に移動し、**Settings**アイコンをクリックしてサブドメインを表示します。献金リンクは次の形式になります。

`https://yoursubdomain.b1.church/donate`

このリンクをウェブサイト、メール、週報に掲載すると、メンバーがオンラインで献金できる場所を知ることができます。

### 基金と金額が事前に設定されたリンク

特定の基金に直接誘導するには、**Donations > Funds**に移動し、基金の**Giving Link**（献金リンク）をクリックします。必要に応じて金額を入力してから、リンクをコピーします。ダイアログには同じリンクのQRコードも表示されます。**Download PNG**をクリックすると、週報、スライド、ポスター用に保存できます。献金者がリンクを開くかコードを読み取ると、献金ページで基金と金額があらかじめ選択された状態になります。リンクの形式は次のとおりです。

`https://yoursubdomain.b1.church/donate?fundId=FUND_ID&amount=25`

同じパラメーターは、ウェブサイトビルダーの**Donate Link**要素でも使用できます。

## 寄付の通知

Stripeは寄付を受け取るたびにメールで通知を送信します。通知先のメールアドレスを変更するには、Stripeダッシュボードに移動し、右上のプロフィールをクリックして**Profile**を選び、メールアドレスを更新してください。

## 手数料の負担オプション

献金ページを設定して、献金者が任意で処理手数料を負担できるようにすることもできます。これにより、教会は寄付金額の全額を受け取れます。この設定は、B1 Admin内の教会設定で管理します。

:::tip
設定後は、オンライン献金を会衆に案内する前に、少額のテスト献金を行い、すべてが正常に動作することを確認してください。
:::

## Kingdom Fundingの設定

Kingdom Fundingは、クレジットカード、デビットカード、ACH銀行振込に対応したキリスト教系の決済処理会社です。教会がKingdom Fundingに登録している場合は、献金ゲートウェイとして接続できます。

:::info
Kingdom Funding連携は現在ベータ版です。有効化するには、B1の担当者にお問い合わせください。
:::

1. [kingdomfundinginternational.com](https://kingdomfundinginternational.com/churches/apply)でサインアップするか、ログインします。
2. Kingdom Fundingの加盟店ポータルから**Security Key**（公開キー）と**Private Key**（秘密キー）を取得します。
3. B1 Adminで**Settings**に移動し、**Giving**セクションを開いて編集をクリックします。
4. **Provider**を**Kingdom Funding**に設定します。
5. Security Keyを**Security Key**欄に、Private Keyを**Private Key**欄に貼り付けます。
6. Kingdom Fundingから受け取った**Webhook Key**を設定し、表示されたWebhookのURLをKingdom Fundingの加盟店設定にコピーします。これにより、Kingdom FundingがB1に完了した取引を通知できるようになります。
7. 保存します。

接続が完了すると、メンバーは献金ページでカード/銀行口座の切り替えを確認でき、クレジットカードまたはACH振込で献金できます。

## PayPalとVenmoのボタン

プロバイダーとしてPayPalを利用している教会では、単発の献金について、献金ページのカード入力欄の上に**PayPal**と**Venmo**のボタンが表示されます。ボタンをクリックした献金者はPayPalのウィンドウで支払いを完了し、その献金は他のオンライン寄付と同様に記録されます。Venmoは、アメリカ合衆国の献金者で、PayPalが対象と判断したデバイスを使用している場合にのみ表示されます。定期献金では、引き続きカード入力欄を使用します。

## Paystack（アフリカ）の設定

Stripeは、ガーナ、ナイジェリア、ケニア、南アフリカ、コートジボワールの教会にはアカウントを開設していません。[Paystack](https://paystack.com)は開設できます。Paystackは現地のカード、**モバイルマネー**（MTN MoMo、Vodafone Cash、AirtelTigo、M-PESA）、銀行振込、USSDに対応しており、献金者は現地通貨（GHS、NGN、KES、ZAR、XOF）で支払うことができます。

1. 教会の事業登録証明書と現地の銀行口座を使って[paystack.com](https://paystack.com)に登録し、Paystackの有効化（本番稼働）審査を完了させます。
2. Paystackダッシュボードで**Settings → API Keys & Webhooks**を開き、**Public Key**と**Secret Key**をコピーします（テスト用キーではなく本番用キーを使用してください）。
3. B1 Adminで**Settings**に移動し、**Giving**セクションを開いて編集をクリックします。
4. **Provider**を**Paystack**に設定し、Public KeyとSecret Keyを貼り付けて、**Currency**を選択します。
5. プロバイダーの下に表示される**webhook URL**をコピーし、Paystackダッシュボード（**Settings → API Keys & Webhooks**）に戻って**Webhook URL**欄に貼り付けます。これにより、定期献金とモバイルマネーによる支払いが記録されるようになります。
6. 保存します。

献金者は、安全なPaystackのウィンドウで支払いを完了します。その際、カード、モバイルマネー、銀行振込から選択できます。注意事項は次のとおりです。

- **定期献金**にはカードが必要です。モバイルマネーは自動で再請求できないため、Paystackでは単発のモバイルマネー献金のみ許可されています。
- Paystackの定期献金はB1からキャンセルできますが、一時停止や編集はできません。金額を変更する場合は、キャンセルしてから新しく作成してください。
- **Processing Fee**（処理手数料）の既定値は、通貨ごとのPaystackの現地カード料金に基づいています。交渉した料金が異なる場合は、編集してください。
