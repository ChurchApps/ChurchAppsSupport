# Stripe インポート

<div class="article-intro">

Stripe でオンライン献金を受け付けている場合、Stripe インポートツールを使うと、それらの取引を B1 Admin に取り込めます。これにより、すべての献金データを 1 か所にまとめられます。自動同期されなかった取引を見つけるのにも特に便利です。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [オンライン献金の設定](online-giving-setup.md)を完了して、Stripe アカウントを B1 Admin に接続してください。**Stripe インポート**メニュー項目とバッチページのボタンは、教会の献金ゲートウェイが Stripe に設定されている場合にのみ表示され、献金を編集できる権限を持つユーザーにのみ表示されます。
- 取り込みたい期間について、Stripe ダッシュボードに献金があることを確認してください。

</div>

## 仕組み

インポートは 2 段階の流れで行います。まず取り込まれる内容をプレビューし、次にインポートを確定します。この試行実行の方式により、データが作成される前にすべての内容を確認できます。

## 取引のインポート

1. **B1 Admin** で、**寄付 > Stripe インポート**に移動します。（**バッチ**ページの上部にある**不足している Stripe 取引をインポート**をクリックすることもできます。）
2. **Stripe インポート**ページが開きます。
3. インポートしたい取引の**日付範囲**を選択します。
4. **プレビュー**をクリックして、試行実行による確認を行います。

## プレビューの確認

プレビューには、Stripe から取得した各取引と、そのステータス表示が一覧されます。

- **新規** -- この取引はまだインポートされていません。このまま進めると取り込まれます。
- **インポート済み** -- この取引は B1 Admin に既に存在するため、スキップされます。
- **スキップ** -- この取引は別の理由（返金や決済失敗など）により除外されています。

画面上部の概要欄には、各カテゴリの取引の合計件数と関連する金額が表示されます。

:::info
プレビューの段階では、レコードは作成されません。確定する前に結果を確認するための読み取り専用のチェックです。
:::

## インポートの完了

1. プレビューの結果と概要の合計を確認します。
2. **不足分をインポート**をクリックして、**新規**とマークされたすべての取引を取り込みます。
3. インポートが完了すると、各取引の横にあるステータスバッジが更新され、結果が表示されます。

## Stripe インポートを使うためのヒント

- 記録を最新に保つため、定期的に（毎週または毎月）インポートを実行してください。
- 取引が**インポート済み**と表示される場合、B1 Admin に一致するレコードが既にあることを意味します。対応は不要です。
- 特定の取引を探している場合は、日付範囲フィルターを使って特定の期間に絞り込んでください。

:::tip
インポート後、[バッチ](batches.md)ページにアクセスして、取り込まれた献金が正しく表示されていること、そして合計額が Stripe ダッシュボードの数字と一致していることを確認してください。
:::

## 次のステップ

- [献金レポート](donation-reports.md)を確認して、取り込んだ取引を他の献金データと合わせて見直します。
- 正確な[献金明細書](giving-statements.md)を作成するため、取り込んだ献金が正しい[基金](funds.md)に割り当てられていることを確認します。
