# 寄付レポート

<div class="article-intro">

B1 Adminでは、教会の献金データを表示・分析するいくつかの方法を利用できます。寄付の**概要**ページにあるダッシュボードでは、グラフとフィルターによる視覚的な概要を確認できます。レポートセクションでは、より詳細な寄付サマリーレポートを利用できます。これらのツールを使って献金の傾向を把握したり、理事会の準備をしたり、記録の照合を行ったりしてください。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 寄付が[バッチで記録されている](recording-donations.md)か、[Stripeからインポート](stripe-import.md)されていることを確認してください
- 寄付が正しく分類されるよう、[基金](funds.md)が正しく設定されていることを確認してください

</div>

## 献金ダッシュボード

献金ダッシュボードは、**寄付**セクションを開いたときに最初に表示される**概要**ページの**ダッシュボード**ビューです。

1. [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（B1 Adminの左上にある検索バー）を開き、**寄付**を展開して**概要**をクリックします。**概要**ページが**ダッシュボード**ビューで開きます。右上の**ビュー**切り替えで**ダッシュボード**と**寄付が途絶えた人**を切り替えられます。
2. レポートの上にある**週次**、**月次**、**四半期**の切り替えを使って、献金のまとめ方を選択します。
3. **レポートの絞り込み**パネルで**開始日**と**終了日**を設定します（初期値は1年前から昨日までです）。必要に応じて**基金**を選択し、**レポートを実行**をクリックします。ページを開くと、初期値でレポートが自動的に実行されます。
4. 選択した期間の献金指標を、4つの**KPIカード**で表示します。
   - **献金総額** -- 寄付された合計金額。
   - **平均献金額** -- 1件あたりの平均寄付額。
   - **ユニーク寄付者数** -- 献金した人の延べ人数ではなく、個別の人数。
   - **寄付総件数** -- 個々の寄付の総件数。
5. KPIの下にある棒グラフには、週・月・四半期ごとの献金額が基金別に示されます。
6. **ダウンロードオプション**をクリックして**概要**を選ぶと、期間別・基金別の合計をCSVでエクスポートできます。印刷アイコンをクリックすると、レポートを印刷できます。[ウェブサイト > 外観](../website/appearance.md)で設定した教会のロゴ（アップロード済みの場合は**明るい背景用ロゴ**）と教会名が、印刷されたレポートの上部中央に表示されます。B1 Adminをダークモードで使用していても、印刷物は暗い文字と明るいグラフで出力されます。

期間内の寄付が複数の通貨で行われていた場合、KPIの合計は教会の通貨に換算され、カードの下に**現在の為替レートで換算**という注記が表示されます。詳しくは[多通貨対応](./multi-currency.md#converted-totals)を参照してください。

:::info
ダッシュボードに表示されるのは集計された献金データです。寄付者の個人名は含まれません。寄付者ごとの詳細は、[バッチ](batches.md)ページで確認してください。
:::

## 寄付が途絶えた人

**ビュー**切り替えで**寄付が途絶えた人**を選ぶと、ある期間には献金していたものの、その後は献金していない人の一覧が表示されます。初期設定では、前年の暦年と今年の年初来を比較します。どちらかの日付範囲を変更すると、検索範囲を広げたり狭めたりできます。各行には、その人の名前、最後の献金日、前の期間の合計額が表示されます。**ダウンロードオプション > 概要**をクリックすると、フォローアップのダイレクトメールや電話連絡用のリストとして、一覧をCSVでダウンロードできます。

## 寄付者ごとの詳細を確認する

誰が、いくら、どの基金に献金したかの内訳を確認するには、次の手順に従ってください。

1. **寄付 > バッチ**に移動します。
2. **バッチ名**をクリックして開きます。
3. バッチの詳細ページには、各寄付が一覧で表示されます。寄付方法（小切手番号やカードの下4桁を含む）、寄付者の名前、日付、メモ、金額が含まれ、一番下に合計が表示されます。
4. 寄付の行で**編集**をクリックすると、その寄付の詳細（基金を含む）を確認できます。
5. 一覧の上にある**エクスポート**をクリックすると、そのバッチのすべての寄付者情報と寄付情報を含むCSVをダウンロードできます。

## 寄付サマリーレポート

寄付のレポート機能は、寄付セクションに組み込まれています。**概要**ページが寄付サマリーレポートの役割を果たします。

1. ジャンプメニューで**寄付 > 概要**を選択します。
2. **ダッシュボード**ビューで、**レポートの絞り込み**パネルの**開始日**と**終了日**を設定し、**レポートを実行**をクリックします。
3. **ダウンロードオプション**をクリックし、**概要**を選択すると、レポートをCSVファイルとしてエクスポートできます。

## データのエクスポート

寄付データは、次のような複数の場所からエクスポートできます。

- **概要**ページ -- 週別、月別、四半期別、基金別の献金合計をCSVでダウンロード
- **バッチの詳細**ページ -- 寄付者情報を含む個々の寄付をCSVでダウンロード
- **基金の詳細**ページ -- 特定の基金の寄付履歴をダウンロード

:::tip
年末の報告では、**概要**ページのエクスポートと[献金明細書](giving-statements.md)ツールを組み合わせると、全体の傾向と寄付者ごとの明細書の両方を用意できます。
:::

## 次のステップ

- 年末に寄付者向けの[献金明細書](giving-statements.md)を作成する
- 寄付の詳細を確認するために、個々の[バッチ](batches.md)を見直す
- カテゴリー別の献金内訳を確認するために、[基金](funds.md)の詳細ページをチェックする
