# キャンペーンと献金の誓約

<div class="article-intro">

キャンペーンを使うと、建築基金、宣教旅行、特別プロジェクトなど、特定の目標に向けた募金活動を実施できます。メンバーからの誓約額と実際の献金を並べて記録し、進捗をリアルタイムで確認できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [献金基金](funds)を設定しておきます。各キャンペーンは基金に紐づけられます。
- B1 Admin の献金セクションにアクセスできる必要があります。

</div>

## キャンペーンを開く

B1 Admin で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（画面左上の検索バー）を開き、**献金**を展開して **キャンペーン**をクリックします。すべてのキャンペーンが、基金、期間、目標金額、これまでの誓約総額、献金総額とともに表に表示されます。表の上の概要行には、キャンペーン数と誓約額・献金額の合計が表示されます。

## キャンペーンを作成する

1. ページ上部の **キャンペーンを追加** をクリックします。
2. キャンペーンの詳細を入力します。
   - **名前**（必須）：このキャンペーンの表示名です（例：「建築基金 2026」）。
   - **基金**：このキャンペーンに関連付ける献金基金です。
   - **開始日** / **終了日**：募金の期間です。
   - **目標**：キャンペーンの目標金額です。
3. **保存**をクリックします。

## 進捗を確認する

各キャンペーンの行には次の情報が表示されます。

- **目標**：目標金額
- **誓約額**：メンバーが献金を誓約した合計額
- **献金額**：募金期間中に、このキャンペーンの基金へ実際に寄付された合計額
- **進捗**：目標に対してどの程度達成したかを示すバーと割合

キャンペーン名をクリックすると詳細画面が開きます。目標の達成率が表示され、個別の誓約の一覧が出てきます。各行には献金者ごとの誓約額と献金額、そしてステータス（**未開始**、**進行中**、**達成**、**誓約額超過**、または誓約をせずに献金した人の場合は**誓約なし**）が表示されます。献金者は姓、名の順に並びます。列見出しをクリックすると、その列で並べ替えできます。詳細画面上部の**エクスポート**をクリックすると、誓約の一覧を CSV としてダウンロードできます。

## 誓約を追加する

誓約とは、メンバーがキャンペーンに対して献金することを約束したものです。誓約を記録するには、次の手順に従います。

1. キャンペーンを開きます。
2. ページ上部の **誓約を追加** をクリックします。
3. 誓約をする**人物**を選択します。
4. 誓約の**金額**を入力します。
5. 必要に応じて、誓約の**日付**を設定します。
6. **保存**をクリックします。

誓約はキャンペーンの詳細に表示され、キャンペーン一覧の**誓約額**に加算されます。誓約を変更するには、該当する行の**編集**をクリックします。

:::tip
誓約と実際の献金は別々に扱われます。誓約は約束を記録するもので、献金は実際の寄付を記録するものです。キャンペーン上では両方が表示されるため、誓約がどの程度果たされているかを確認できます。
:::

## キャンペーンの編集と削除

キャンペーンの名前、目標、期間、基金を更新するには、キャンペーンの行の**編集**（またはキャンペーン詳細画面上部の**キャンペーンを編集**）をクリックします。キャンペーンとその誓約を完全に削除するには、**削除**をクリックします。キャンペーンを削除しても、そのキャンペーンの基金に記録された献金は削除されません。
