# 基金の管理

<div class="article-intro">

基金を使うと、寄付を目的別に分類し、教会の各ミニストリー分野にどれだけ寄付が集まっているかを把握できます。一般基金、建設基金、宣教、青年ミニストリーなどが一般的な基金ですが、必要な数だけ作成できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1 Admin の **Donations** セクションへのアクセス権が必要です
- 教会で必要な献金の種類と、それぞれを税控除対象にするかどうかを決めておいてください

</div>

## 基金ページ

**Donations > Funds** に移動すると、すべての基金の一覧が表示されます。各行には基金名と **Tax Status**（税控除対象または非控除対象）が表示されます。このステータスによって、その基金への寄付が年末の [献金明細書](giving-statements.md) に記載されるかどうかが決まります。

## 新しい基金の作成

1. ページ上部の **Add Fund** をクリックします。
2. 基金の名前を入力します（例：「建設基金」）。
3. この基金への寄付を献金明細書に含めたい場合は、**Tax Deductible** にチェックを入れます。非控除対象の基金への献金も、寄付者の個人記録上の献金履歴には引き続き表示されます。
4. 基金を寄付フォームの公開画面や会員向け画面に表示したい場合は **Visible to Donors** にチェックを入れたままにします。寄付者からは非表示にしつつ、手動で記録する寄付には引き続き使用したい場合はチェックを外します。
5. **Save** をクリックします。

新しい基金は一覧にすぐ表示され、寄付を入力するときに選択できるようになります。

## 基金の編集と削除

- 基金を編集するには、その行の **Edit** をクリックします。名前を変更したり、税控除の設定を切り替えたり、**Visible to Donors** をオンまたはオフにして寄付フォームでの表示を切り替えたりできます。
- 基金を削除するには、編集フォームを開いて **Delete** をクリックします。

:::warning
基金を削除しても、以前その基金に割り当てられた寄付は削除されません。寄付の記録はシステム内に残りますが、その基金は新しい寄付に使えなくなります。
:::

:::info
寄付者から非表示にされた基金は、この一覧で名前の横に **Hidden** バッジが表示されます。非表示の基金も B1 Admin で手動記録する寄付には引き続き使用できます。公開または会員向けの寄付フォームで選択肢として表示されないだけです。
:::

## 基金の詳細の確認

**基金名** をクリックすると詳細ページが開きます。このページには次の情報が表示されます。

- **Summary** -- ページタイトルの下に表示される行で、献金件数、寄付者数、合計金額が示されます
- **Date range filter** -- **Start Date** と **End Date** を設定して **Filter** をクリックすると、特定の期間に結果を絞り込めます
- **Donation history** -- この基金への寄付の一覧で、日付、バッチ、寄付者、金額が表示されます。一覧の上にある **Export** をクリックすると CSV としてダウンロードできます

この画面は、特定の献金の取り組みについて報告したいときや、募金目標に対する進捗を確認したいときに役立ちます。

## 並べ替えとエクスポート

- 列見出しを使うと、基金を名前順に並べ替えられます。
- ページ上部の **Export** をクリックすると、基金の一覧をスプレッドシート（CSV）としてダウンロードできます。

:::tip
[寄付の記録](recording-donations.md) を始める前に基金を設定しておきましょう。すべての基金があらかじめ揃っていれば、寄付を最初から正しく分類できます。
:::

## 次のステップ

基金の設定が済んだら、[寄付の記録](recording-donations.md) でバッチに寄付を登録するときに、各寄付へ基金を割り当てられます。[献金明細書](giving-statements.md) を発行する前に、該当する基金に税控除対象の設定が正しくされていることを確認してください。
