# 多通貨対応

<div class="article-intro">

B1の多通貨機能を使うと、教会は異なる通貨で献金を受け付けて記録できます。海外の会員、宣教師、または異なる国にある複数の拠点を持つ教会に特に便利です。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 献金を管理する権限が必要です。詳しくは[役割と権限](../people/roles-permissions.md)を参照してください。
- 多通貨取引に対応しているStripeで[オンライン献金](./online-giving-setup.md)を設定してください。
- 複数の通貨を扱う際の教会の会計上の要件を把握しておいてください。

</div>

## 多通貨機能の有効化

多通貨対応はB1ではデフォルトで有効になっています。有効にすると次のことができます。

- 会員はオンラインで献金する際に、自国の通貨で寄付できます
- 任意の通貨で献金を手動で記録できます
- 献金レポートには元の通貨の金額が表示されます
- オンライン献金では、通貨換算はStripeが自動的に行います

## 対応通貨

本システムは、次のような主要な世界の通貨をすべてサポートしています。

- **USD** -- 米ドル
- **EUR** -- ユーロ
- **GBP** -- 英ポンド
- **CAD** -- カナダドル
- **AUD** -- オーストラリアドル
- **MXN** -- メキシコペソ
- **BRL** -- ブラジルレアル
- **INR** -- インドルピー
- **CNY** -- 中国元
- **JPY** -- 日本円
- その他多数...

オンライン献金で利用できる通貨は、Stripeアカウントで対応している通貨によって異なります。

## 異なる通貨での献金の記録

### オンライン献金

会員がStripeを通じてオンラインで献金する場合:

1. 会員はチェックアウト時に希望の通貨を選択します
2. Stripeがその通貨で決済を処理します
3. 献金は元の通貨の金額でB1に記録されます
4. 必要な通貨換算は、Stripeが教会アカウントの既定の通貨へ自動的に行います

### 手動入力

現金または小切手による献金を異なる通貨で記録するには:

1. B1 Adminで**Donations > Batches**に移動し、バッチを開きます
2. バッチページの上部にある**Add Donation**をクリックします
3. 通貨のドロップダウンから通貨を選択します
4. その通貨で金額を入力します
5. 献金のその他の詳細を入力します
6. **Save**をクリックします

## 多通貨の献金の確認

### 献金レポート

献金レポートには、金額が元の通貨で表示されます。

- 個々の献金記録には通貨コードが表示されます (例: 「$100.00 USD」)
- 合計は通貨ごとに計算されます
- 特定の通貨で絞り込むことができます

### 換算後の合計

B1が単一の合計額を表示する場合（献金サマリーのKPIカード、献金バッチの合計、ファンドの合計など）、教会の既定の通貨以外で記録された献金は、現在の為替レートで教会の通貨に換算されます。これにより、異なる通貨を単純に足し合わせるのではなく、意味のある一つの数値として合計が表示されます。換算が適用された場合は、合計の下に**Converted at current exchange rates**という注記が表示されます。個々の献金明細は、引き続き元の通貨で表示されます。

### 献金明細書

献金明細書を作成すると:

- 各献金には元の通貨が表示されます
- 合計は通貨ごとに内訳が示されます
- 会員は、それぞれの通貨でどれだけ献金したかを正確に確認できます

## Stripeとの連携

オンライン献金では、多通貨取引はStripeが処理します。

- **自動換算** -- Stripeが通貨を教会アカウントの既定の通貨に換算します
- **為替レート** -- Stripeは現在の市場の為替レートを使用します
- **手数料** -- 通貨換算には追加のStripe手数料がかかる場合があります
- **入金通貨** -- 資金は教会アカウントの既定の通貨で入金されます

:::info
現在の換算レートや、多通貨取引に関連する手数料は、Stripeのダッシュボードで確認してください。
:::

## 会計上の考慮事項

複数の通貨を扱う際には:

- **記録管理** -- 正確な集計のため、元の献金額と通貨を記録しておいてください
- **為替レート** -- Stripeの換算レートは、銀行のレートと異なる場合があることに注意してください
- **税務上の領収書** -- 税務申告で異なる通貨の献金をどのように報告するか、会計士に相談してください
- **ファンドへの配分** -- 通貨に関係なく、献金を特定のファンドに配分できます

## ベストプラクティス

- **既定の通貨** -- ほとんどの取引で使われる教会の主要な通貨を既定の通貨に設定してください
- **明確な案内** -- チェックアウト時に、献金者がどの通貨で献金しているのかを伝えてください
- **一貫したレポート** -- 合計は常に教会の通貨に自動換算されます。元の金額を確認する必要がある場合は、献金ごとの通貨フィルターを使用してください
- **定期的な照合** -- 通貨換算を考慮しながら、Stripeの入金額を献金記録と照合してください

## 制限事項

- 決済処理の通貨換算は、オンライン献金についてのみStripeが行います。手動の献金は、入力された金額のまま自動換算なしで記録されます
- 過去のレポートと個々の献金明細には、常に献金が記録された元の通貨が表示されます
- 合計（KPIカード、バッチの合計、ファンドの合計）は、現在の為替レートで教会の通貨に換算されます。これらのレートは、資金が決済された時点の銀行またはStripeのレートとわずかに異なる場合があります
