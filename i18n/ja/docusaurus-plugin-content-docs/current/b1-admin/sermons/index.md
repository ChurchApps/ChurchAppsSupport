# 説教

<div class="article-intro">

B1 Admin の説教セクションでは、教会の説教ライブラリとライブ配信を管理できます。個々の説教を追加したり、プレイリストにまとめたり、ライブ配信のスケジュールを設定したりできます。また、YouTube や Vimeo にある既存のコンテンツを一括でインポートすることもできます。

</div>

:::info
説教セクションにアクセスするには、**contentApi.streamingServices.edit** 権限が必要です。メニューに説教が表示されない場合は、教会の管理者に適切な役割の付与を依頼してください。権限の管理について詳しくは、[役割と権限](../settings/roles-permissions.md)を参照してください。
:::

## できること

説教セクションは、主に4つの領域で構成されています。

### 説教

ライブラリ内の個々の説教エントリを追加・管理します。各説教には、タイトル、話し手、日付、説明、サムネイル、動画または音声コンテンツへのリンクを含めることができます。説教は YouTube、Vimeo、Facebook、またはカスタムの動画 URL にリンクできます。詳しくは、[説教の管理](./managing-sermons.md)を参照してください。

### プレイリスト

説教をシリーズやコレクションにまとめます。プレイリストを使うと、会衆が説教シリーズを順番に見つけやすくなります。各プレイリストには、名前、説明、サムネイルを個別に設定できます。詳しくは、[プレイリスト](./playlists.md)を参照してください。

### ライブ配信の時間

教会のライブ配信スケジュールを設定します。毎週の定期礼拝や単発のイベントを設定し、チャットと動画の設定を管理して、配信を開始するタイミングを制御できます。訪問者には、ライブ配信ページに次回の礼拝時間が表示されます。**説教**の下にある別の**設定**ページでは、ライブ配信の横に表示されるタブ(チャット、祈祷、カスタムリンク)を制御できます。セットアップの手順は、[ライブ配信](./live-streaming.md)を参照してください。

### 一括インポート

YouTube や Vimeo から動画をまとめてインポートし、説教ライブラリをすばやく充実させます。既存の説教コンテンツを B1 に移行する最も速い方法です。始めるには、[一括インポート](./bulk-import.md)を参照してください。

:::tip
説教を初めて設定する場合は、まず[プレイリスト](./playlists.md)を作成し、次に[説教を個別に追加](./managing-sermons.md)するか、YouTube または Vimeo から[一括でインポート](./bulk-import.md)してください。
:::
