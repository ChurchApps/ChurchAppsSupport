# 一括インポート

<div class="article-intro">

「一括インポート」ページでは、YouTube または Vimeo から動画をインポートして、説教ライブラリをすばやく登録できます。動画を1本ずつ追加するよりも、既存の説教コンテンツを取り込む最も速い方法です。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- **contentApi.streamingServices.edit** 権限が必要です。この権限がない場合は、[役割と権限](../settings/roles-permissions.md)を参照してください。
- 説教をインポートする先の[プレイリスト](playlists)を少なくとも1つ作成してください
- YouTube チャンネル ID または Vimeo アカウントの情報を用意してください

</div>

## インポート元の選択

1. B1 Admin で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**説教**を展開して **説教** をクリックします。**説教を追加** をクリックし、メニューから **一括インポート** を選択します。
2. **インポート元を選択** の下に、次の2つの選択肢が表示されます。
   - **YouTube** -- YouTube チャンネルから動画をインポートします
   - **Vimeo** -- Vimeo アカウントから動画をインポートします
3. 説教が掲載されているプラットフォームのオプションをクリックします（または、その説明の下にある **YouTube からインポート** / **Vimeo からインポート** をクリックします）。ページ上部の **戻る** をクリックすると、インポート元の選択画面に戻ります。

:::tip
両方のプラットフォームに動画がある場合は、いつでも戻ってインポート元を切り替えられます。
:::

## インポート前の準備

動画をインポートする前に、動画を整理するためのプレイリストを少なくとも1つ用意しておく必要があります。まだプレイリストを作成していない場合は、次の手順で作成してください。

1. **説教** ページに戻り、**プレイリスト** パネルを探します。
2. **最初のプレイリストを作成** をクリックし、名前、説明、公開日、サムネイルを入力します。
3. **保存** をクリックし、**説教を追加** をクリックして **一括インポート** を選ぶと、一括インポート画面に戻ります。

プレイリストの作成と管理の詳しい手順は、[プレイリスト](playlists)を参照してください。

## 動画のインポート

1. YouTube または Vimeo を選択したら、表示された欄に **YouTube チャンネル ID** または **Vimeo アカウント情報** を入力します。
2. **取得** ボタンをクリックして、チャンネルまたはアカウントの利用可能な動画をすべて取得します。
3. 取得が完了すると、すべての動画がチェックボックス付きの一覧で表示されます。
4. インポートしたい動画のチェックボックスをオンにします。すべて選択することも、個別に選ぶこともできます。
5. 必要に応じて **新しい動画を自動インポート** を有効にすると、今後アップロードされる動画が自動的にライブラリに追加されます。
6. **インポート先のプレイリスト** のドロップダウンをクリックして、これらの動画を追加するプレイリストを選択します。
7. **インポート** ボタンをクリックして、一括インポートを完了します。

動画は、タイトル、説明、日付、サムネイルを含むすべての詳細情報とともにインポートされます。YouTube のタイトルや説明に含まれる `&`、アポストロフィ、引用符などの特殊文字は、`&amp;` のようなコードではなく、入力されたとおりに表示されます。

:::info
一括インポートは、他のプラットフォームから移行する際の開始に最適です。今後、個別に説教を追加する場合は、代わりに[説教の管理](managing-sermons)ページを参照してください。
:::
