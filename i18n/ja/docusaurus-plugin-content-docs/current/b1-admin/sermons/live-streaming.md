# ライブ配信

<div class="article-intro">

ライブ配信設定ページでは、教会の配信スケジュールの設定、礼拝時間の管理、視聴者向け画面のカスタマイズを行えます。毎週の定期礼拝や単発のイベントを設定し、チャットや動画の設定を行い、配信の開始タイミングを管理できます。

</div>

## トレーニング動画

<div class="prereqs">
<h4>始める前に</h4>

- **contentApi.streamingServices.edit** の権限が必要です。アクセス権がない場合は [役割と権限](../settings/roles-permissions.md) を参照してください。
- 自動ライブ配信を利用する場合は、YouTubeチャンネルIDを準備しておいてください。
- 配信元として使うため、少なくとも1つの [説教](./managing-sermons.md) または常設のライブURLを追加してください。

</div>

ライブ配信は、ジャンプメニューの **説教** セクションにある2つのページから管理します。ライブ配信のスケジュールを管理する **ライブ配信時間** と、配信ページのタブを設定する **設定** です。

## 礼拝の管理

### 礼拝の追加

1. B1 Adminで [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**説教** を展開して **ライブ配信時間** をクリックします。
2. ページ上部の **礼拝を追加** ボタンをクリックして、新しい予定礼拝を作成します。既存の礼拝は、礼拝名、時間、配信プロバイダー、長さを示す表に一覧表示されます。変更するには行の編集アイコンをクリックします。
3. **礼拝名** を入力します（例：「日曜朝礼拝」）。
4. **礼拝時間** を設定します。礼拝が始まる曜日と時刻を選びます。
5. 毎週の定期礼拝の場合は **定期開催** を **はい**、単発のイベントの場合は **いいえ** に設定します。

### チャットと動画の設定

6. **チャット設定** で、礼拝の何分前から何分後までチャットを有効にするかを設定します。これにより、来場者は礼拝の開始前から話を始めたり、終了後も会話を続けたりできます。
7. **動画設定** で、カウントダウンや礼拝前のコンテンツのために、動画配信を何分前に開始するかを設定します。チャットは早期動画の開始よりさらに *前* の時間に開くため、チャットの「何分前」設定の横に表示される時刻はこの2つの値の合計を反映しています。例えば、10:00の礼拝で、チャットを15分前から開き、早期開始を5分前に設定した場合、チャットは9:40に開きます。
8. ドロップダウンから再生する説教を選択します。
   - **最新の説教** -- 最近追加された動画を自動的に再生します。
   - **現在のライブ礼拝** -- チャンネルIDを使用して、YouTubeの現在のライブ配信を再生します。
   - 既に保存済みの特定の説教を選ぶこともできます。
9. **保存** をクリックして礼拝をスケジュールします。

:::info
定期設定にしている場合、礼拝は毎週自動的に更新されます。夏時間の開始または終了時も、現地時間は同じに保たれます。必要な数だけ礼拝を追加できます。視聴者が配信ページを開くと、次に予定されている礼拝時間が表示されます。
:::

## 配信ページの設定

ライブ配信と並んで表示されるタブやリンクをカスタマイズするには、ジャンプメニューを開き、**説教** を展開して **設定** をクリックします。**配信設定** ページに **コンテンツタブ** の一覧が表示されます。

### タブの追加

1. **追加** ボタンをクリックして、ライブ配信ページに新しいタブを追加します。
2. **リンクの種類** を選択します。カスタムリンクの場合は **外部URL**、あらかじめ用意された **チャット** または **お祈り** のタブから選ぶこともできます。
3. チャットタブの場合は、**タブのテキスト** ボックスに名前を入力するだけで設定は完了です。
4. リンクタブの場合は、タブ名を入力し、アイコンボタンをクリックしてアイコンを選び、URLを入力します。
5. 設定したタブは、視聴者が追加のリソースや対話型の機能を利用できるよう、ライブ配信ページに表示されます。

### 配信のプレビュー

**ライブ配信時間** ページの上部にある **配信を表示** をクリックすると、ロゴ、礼拝時間、設定したタブを含め、来場者に実際にどのように見えるかを確認できます。

## YouTubeライブ配信の設定

YouTubeチャンネルを自動ライブ配信に接続するには、次の手順に従います。

1. **説教** に移動し、**説教を追加** をクリックしてから、**常設のライブURLを追加** を選択します。
2. 動画プロバイダーの初期値は **現在のYouTubeライブ配信** です。**YouTubeチャンネルID** を入力します。
3. タイトルと説明を追加してから、**保存** をクリックします。
4. **ライブ配信時間** で礼拝を作成し、説教のドロップダウンから常設のライブURLを選択します。

:::tip
YouTubeチャンネルIDを確認するには、YouTubeチャンネルの詳細設定に移動し、チャンネルIDの値をコピーしてください。
:::

## 配色とロゴのカスタマイズ

ライブ配信ページでは、ウェブサイトの [外観](../website/appearance.md) の設定が使われます。

- ヘッダーには、暗い文字色と組み合わせた **明るいアクセントカラー** が使われます。
- サイドバーには、明るい文字色と組み合わせた **暗いアクセントカラー** が使われます。
- **明るい背景用のロゴ** が配信ページに表示されます。背景が透明で、縦横比が4:1の画像を使用してください。

これらを変更するには、**ウェブサイト** から **外観** に進み、[配色パレット](../website/appearance.md#color-palette) と [ロゴ](../website/appearance.md#logo-and-branding) の設定を更新してください。

## 配信ホストの追加

公開チャットと並んで、ホスト専用チャットを利用できるようチームメンバーに権限を与えるには、次の手順に従います。

1. ジャンプメニューで **設定 > 役割** を選択します。
2. プラスボタンをクリックし、**カスタム役割を追加** を選択します。
3. 役割名を「配信ホスト」とし、**保存** をクリックします。
4. 新しく作成した役割をクリックし、メンバーセクションの **追加** をクリックして人を追加します。
5. **権限を編集** まで下にスクロールし、**コンテンツ** セクションを展開して、**ホストチャット** にチェックを入れます。

配信ホストがライブ配信ページにログインすると、配信中にスタッフだけで会話できる非公開の **ホストチャット** タブが、公開チャットと並んで表示されます。

:::info
役割の作成や権限の管理について詳しくは、[役割と権限](../settings/roles-permissions.md) を参照してください。
:::

## トラブルシューティング

チャンネルIDを使った「現在のYouTubeライブ配信」オプションで、自動YouTubeライブ配信が正しく表示されない場合は、次の対処を試してください。

**症状:**
- ライブ配信の埋め込みに「動画は利用できません」と表示される
- ページは読み込まれるものの、動画が表示されない
- YouTubeの直接埋め込みは動作するが、チャンネルの自動ライブ配信は動作しない

**解決方法:**
YouTubeチャンネルで、古いライブ配信や今後予定されているライブ配信がないか確認し、削除してください。

1. YouTube Studioを開きます。
2. **コンテンツ** から **ライブ** に移動します。
3. 古い予定ライブや、今後予定されている配信がないか確認します。
4. 古いまたは予定されているライブ配信を削除します。
5. ライブ配信ページをもう一度テストします。

:::warning
チャンネルに予定済みまたは過去のライブ配信が複数残っていると、YouTubeの自動チャンネルライブ配信の埋め込みがブロックされることがあります。これらを削除すると、YouTubeが現在のライブ配信を正しく識別して配信できるようになります。
:::

**追加の要件:**
- ライブ配信は **公開**（限定公開や非公開ではない）に設定されている必要があります。
- YouTubeの配信設定で、埋め込みが許可されている必要があります。
- 動画IDを使う **YouTube** プロバイダーではなく、チャンネルIDを使う **現在のYouTubeライブ配信** プロバイダーを使用していることを確認してください。
