# プレイリスト

<div class="article-intro">

プレイリストを使うと、説教を連続シリーズやコレクションとしてまとめることができます。訪問者が B1.church のウェブサイトで説教ライブラリを閲覧するとき、プレイリストがあれば、一連の説教シリーズを正しい順番で見つけて追いかけやすくなります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- **contentApi.streamingServices.edit** の権限が必要です。アクセス権がない場合は、[ロールと権限](../settings/roles-permissions.md)を参照してください。
- プレイリストの名前、説明、サムネイル画像を用意してください

</div>

## プレイリストを表示する

1. B1 Admin で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**説教**を展開して、**説教**をクリックします。
2. **説教**ページの**プレイリスト**パネル（説教一覧の横）を見つけます。
3. 既存のすべてのプレイリストが、名前と説明とともに一覧表示されます。

## プレイリストを作成する

1. まだプレイリストがない場合は**最初のプレイリストを作成**ボタンをクリックします。すでにある場合は、**プレイリスト**パネルの**プレイリストを追加**ボタンをクリックします。
2. プレイリストの**名前**を入力します。例：「Faith Foundations」や「Summer in the Psalms」のような説教シリーズのタイトル。
3. 訪問者にシリーズの概要が伝わるよう、**説明**を追加します。
4. **公開日**を設定して、プレイリストが表示される日時を指定します。
5. シリーズを視覚的に表すための**サムネイル画像**をアップロードします。
6. **保存**をクリックして、プレイリストを作成します。

:::tip
説教を追加する前に、先にプレイリストを作成しておくことをおすすめします。そうすれば、後で整理し直す必要がなく、説教を追加するたびに正しいプレイリストに割り当てられます。
:::

## 説教をプレイリストに追加する

[説教を追加または編集](./managing-sermons.md)するときに、**プレイリスト**ドロップダウンで説教をプレイリストに割り当てます。同じプレイリストに割り当てられたすべての説教はまとめられ、ウェブサイト上で順番どおりに表示されます。

:::info
[一括インポート](./bulk-import.md)の際にも、説教をプレイリストに割り当てられます。YouTube または Vimeo からインポートする場合は、**インポート先のプレイリスト**ドロップダウンからプレイリストを選択してから、**インポート**をクリックします。
:::

## プレイリストがウェブサイトに表示される方法

プレイリストは、B1.church のウェブサイトで閲覧可能なコレクションとして表示されます。訪問者は次のことができます。

- 利用可能なすべての説教シリーズを一目で確認する
- プレイリストをクリックして、そのシリーズのすべての説教を表示する
- 説教を順番どおりに視聴または聴取する
