# 説教の管理

<div class="article-intro">

「説教」ページでは、教会の説教ライブラリ全体を表示します。ここから新しい説教を追加したり、既存の項目を編集したり、プレイリストごとにコンテンツを整理したりできます。各説教は、YouTube、Vimeo、Facebook、またはカスタム URL でホストされている動画や音声にリンクできます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- **contentApi.streamingServices.edit** 権限が必要です。アクセス権がない場合は、[役割と権限](../settings/roles-permissions.md)を参照してください。
- 説教を整理するための [プレイリスト](playlists) を少なくとも 1 つ作成してください
- YouTube、Vimeo、または Facebook の動画 ID または URL を用意してください

</div>

## 説教ライブラリの表示

1. B1 Admin で [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)(左上の検索バー)を開き、**説教** を展開して **説教** をクリックします。
2. 説教ページには、説教の項目が表で表示されます。表には各説教の **プレイリスト**、タイトル、**公開日** が含まれます。表の上にある検索ボックスを使うと、一覧を絞り込めます。プレイリストは、表の横にある **プレイリスト** パネルに表示されます。
3. 任意の説教の行にある **編集** をクリックすると、詳細を表示または編集できます。

## 説教の追加

1. 右上の **説教を追加** ボタンをクリックし、ドロップダウンから **説教を追加** を選択します。
2. 説教を割り当てる **プレイリスト** を選択します。
3. **動画プロバイダー** を選択します。YouTube、Vimeo、Facebook、またはカスタム URL から選べます。B1 システムとの相性が最も良いため、YouTube をおすすめします。
4. 動画の ID または URL を入力して **取得** をクリックします。YouTube の場合、動画 ID は YouTube の URL にある `v=` の後ろの文字列です。
5. **取得** をクリックすると、公開日、再生時間、タイトル、説明、サムネイルなどの説教の詳細が自動的に読み込まれます。
6. 必要な変更を加えて、**保存** をクリックします。

:::tip
**説教を追加** のドロップダウンから **恒久的なライブ配信 URL を追加** を選ぶと、恒久的なライブ配信の項目も追加できます。これにより、チャンネル ID を使って YouTube チャンネルのライブ配信と継続的に接続できます。詳しくは [ライブ配信](live-streaming) を参照してください。
:::

## 説教の編集

1. ライブラリ内の任意の説教の行で **編集** をクリックし、詳細を開きます。
2. 必要に応じて、タイトル、話者、日付、説明、サムネイル、またはメディアのリンクを更新します。
3. **保存** をクリックして変更を適用します。

## 説教の詳細

各説教の項目には、次の情報を含めることができます。

- **タイトル** -- 訪問者に表示される説教の名前
- **話者** -- 説教を行った人
- **日付** -- 公開日または説教を行った日
- **説明** -- 説教内容の概要
- **サムネイル** -- 説教ライブラリに表示されるプレビュー画像
- **動画/音声のリンク** -- YouTube、Vimeo、Facebook、またはカスタムホストにある説教メディアの URL
- **ポッドキャスト用の音声ファイル URL** -- この説教の MP3/M4A ファイルへの直接リンク。URL を貼り付けるか、**音声をアップロード** をクリックしてファイルをアップロードすると、自動的に入力されます。この項目、または動画ファイルへの直接リンクが設定されている説教のみ、ポッドキャストフィードに含まれます。

## ポッドキャストフィード

音声ファイルまたは動画ファイルが添付された説教が少なくとも 1 つあると、B1 Admin が教会用のポッドキャスト RSS フィードを自動的に生成します。有効にする設定はありません。フィードは説教一覧の下にある **ポッドキャストフィード** パネルにあります。コピーアイコンをクリックしてフィードの URL をコピーし、その URL を Apple Podcasts、Spotify、またはその他のポッドキャストディレクトリに登録してください。

:::info
YouTube や Vimeo の動画 ID のように、埋め込みプレーヤーへのリンクだけを持つ説教は、ポッドキャストフィードに表示されません。ポッドキャストアプリには、直接ダウンロードできるメディアファイルが必要です。説教を含めるには、**音声ファイル URL** を追加してください。
:::

## ライブ配信用の説教のスケジュール

説教を追加した後、ライブ配信ページで放送をスケジュールできます。

1. ジャンプメニューで **説教 > ライブ配信時間** を選択します。
2. 礼拝を編集し、**動画設定** の下のドロップダウンから説教を選択します。
3. 説教は、設定した礼拝時間に再生されます。

:::info
説教を 1 つずつ追加する代わりに複数の説教をまとめてインポートする場合は、[一括インポート](bulk-import) ツールを使うと、YouTube または Vimeo アカウントから動画を直接取り込めます。
:::
