# レポート

<div class="article-intro">

B1 Adminでは、教会の会員、出席、献金に関するデータを取得するためのいくつかの方法を利用できます。レポート機能は、単独のレポートページではなく、アプリ内の関連するセクションに組み込まれています。

</div>

## レポートの探し方

### 会員
- **[誕生日と記念日のリスト](./birthday-report.md)** -- **会員 → 詳細検索**で誕生月または記念日の月で絞り込むと、今後の誕生日や記念日の一覧を取得できます。

### 出席
- **[出席レポート](./attendance-reports.md)** -- 出席の傾向やグループの出席データは**出席**セクションにあります。

### 献金
- **[献金の概要](./donation-summary.md)** -- 献金の合計額や基金ごとの内訳は**献金**セクションにあります。

### 設定
- **[監査ログ](./audit-log.md)** -- 教会管理システム内のすべての変更や操作を追跡できます(**設定 → 監査ログ**にあります)。

:::info
レポートのデータは、データ入力の一貫性に左右されます。最も正確な結果を得るために、チームが[出席を記録](../attendance/tracking-attendance.md)し、[献金を記録](../donations/recording-donations.md)し、[会員の記録](../people/adding-people.md)を最新の状態に保つようにしてください。
:::
