# 生年月日・結婚記念日のリスト

<div class="article-intro">

ブレティン、お知らせ、カードのために、特定の月に誕生日や結婚記念日を迎える方の一覧が必要ですか？ People の検索では、**Birth Month** と **Anniversary Month** で教会の会員を絞り込めます。検索結果には日付もそのまま表示されます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 各個人のプロフィールに生年月日（と結婚記念日）が入力されていることを確認してください。[人の追加](../people/adding-people.md)を参照してください。
- People を表示する権限が必要です。[ロールと権限](../settings/roles-permissions.md)を参照してください。

</div>

## 月ごとの誕生日リストの取得

1. [Jump メニュー](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin の左上にある検索バー）を開き、**People** を展開して **People** をクリックします。
2. 検索ボックスの下にある **Advanced** をクリックします。
3. **Demographics** セクションを展開し、**Birth Month** にチェックを入れて、月を選択します。
4. 検索を実行すると、その月に誕生日を迎える全員が結果に表示されます。
5. 日付を表示するには、**View as** を **Table** に切り替え、ページ上部の **Select columns** アイコンをクリックして **Birthday** 列を有効にします。並べ替えや印刷を表計算ソフトで行いたい場合は、**Export** をクリックしてリストをダウンロードできます。

## 結婚記念日リストの取得

手順は同じです。**Demographics** セクションで **Anniversary Month** にチェックを入れ（またはそれに加えて）、月を選択し、結果で **Anniversary** 列を有効にします。

## 活用例

- **週次のブレティン** -- 当月のリストを取得し、そのままブレティンに名前を載せます。
- **誕生日・結婚記念日のカード** -- 当月のリストをエクスポートして、カードを書くチームに渡します。
- **節目の年齢** -- **Age** フィルターと組み合わせて、節目の誕生日を迎える方を見つけます。

:::tip
どちらのリストも、各個人のプロフィールにある生年月日と結婚記念日の項目から作成されます。該当する方が表示されない場合は、プロフィールに日付を追加してください。
:::

:::info
以前のバージョンの B1 Admin には、誕生日専用の Reports ページがありました。このページは廃止されました。現在は上記の People 検索フィルターを使用してください。結婚記念日も同じ方法で検索できます。
:::
