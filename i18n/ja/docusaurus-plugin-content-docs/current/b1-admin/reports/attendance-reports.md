# 出席レポート

<div class="article-intro">

B1 Admin では、礼拝やグループへの参加状況を把握するための3種類の出席レポートを利用できます。それぞれのレポートは、全体的な傾向から日ごとの内訳まで、出席データの異なる視点を提供します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

-礼拝やグループの[出席記録](../attendance/tracking-attendance.md)が一貫して行われていることを確認してください
- [グループ](../groups/creating-groups.md)と礼拝が B1 Admin で設定されていることを確認してください
- レポートにアクセスするために、適切な[権限](../settings/roles-permissions.md)が必要です

</div>

## 出席の推移

出席の推移レポートでは、礼拝ごとの出席数が時間とともにどのように変化しているかを確認できます。

1. ブラウザで **admin.b1.church/reports/attendanceTrend** に直接アクセスしてください（レポートはナビゲーションメニューには表示されません。アドレスをブックマークしておくと、すぐに戻れて便利です）。同じレポートは出席ページからも開けます。**All years** をクリックし、**Attendance Trend** タブを選択してください。
2. 必要に応じて **Campus**（キャンパス）、**Service**（礼拝）、**Service Time**（礼拝時間）、**Group**（グループ）を選択して、結果を絞り込めます。
3. **Start Date**（開始日）と **End Date**（終了日）を設定します。初期設定では、1年前から今日までの過去1年間が対象になり、終了日も含まれます。**Run Report** をクリックしてください。
4. レポートには、週ごとの総出席数を示す棒グラフと表が表示されます。各週には、その週の日曜日の日付がラベルとして付けられます。表の **Session Dates**（セッション日）列には、その週で実際に出席記録があった日付が一覧表示されます（例：「9/27, 9/30」）。

このレポートは、季節による落ち込みや成長傾向、特別なイベントの影響などのパターンを把握するのに役立ちます。

## グループ出席

グループ出席レポートでは、指定した期間内に各グループのセッションに誰が出席したかを確認できます。

1. ブラウザで **admin.b1.church/reports/groupAttendance** に直接アクセスするか、出席ページで **All years** をクリックし、**Group Attendance** タブを選択してください。
2. 必要に応じて **Campus**（キャンパス）と **Service**（礼拝）を選択します。
3. **Start Date**（開始日）と **End Date**（終了日）を設定します。初期設定では、直近の日曜日から今日までが対象になり、終了日も含まれます。
4. **Run Report** をクリックします。

結果は、セッション日、礼拝時間、グループの順にまとめられ、各グループの下に出席者が一覧表示されます。礼拝時間、グループ、氏名はアルファベット順に並べられます。各人の名前の横には、**Checked In**（チェックイン時刻）列に出席が記録された時刻が表示されます（記録がない場合は空欄です）。**Membership Status**（会員区分）列には、会員や来訪者などの状況が表示されます。特定の礼拝時間に集まらないグループのセッションも含まれており、その場合は礼拝時間なしで表示されます。

スプレッドシートをダウンロードするには、**Download Options** をクリックして **Summary** を選択します。CSV ファイルには次の内容が含まれます。

- 期間内に集まったグループごとに、メンバー1人につき1行。グループ、氏名の順に並びます。
- 最初の列には、氏名とグループ名が入ります。
- 日付付きのセッションごとに1列。列名は礼拝、礼拝時間、日付の組み合わせで表示されます（例：「Sunday - 9:00 AM (2026-09-27)」）。各人は **present**（出席）または **absent**（欠席）で示されます。礼拝時間がないセッションは、日付のみで名前が付けられます。

このレポートは、グループ間の出席を比較し、どのグループが成長しているか、あるいは support が必要かを見極めるために使用してください。

## 日ごとのグループ出席

日ごとのグループ出席レポート（タイトルは **Group attendance by day**）では、1つのグループについて、日ごとの出席人数を確認できます。

1. ブラウザで **admin.b1.church/reports/dailyGroupAttendance** に直接アクセスしてください。
2. **Campus**、**Service**、**Service Time** のドロップダウンを使って一覧を絞り込み、確認したい **Group**（グループ）を選択します。
3. レポートを実行します。グループが集まったすべての日付が、古い順に一覧表示されます。各行には **Date**（日付）と、その日に記録された **Attendees**（出席者数）が表示されます。

このレポートでは細かい詳細を確認できるため、週ごとのばらつきを把握したり、出席者数が特に多い日・少ない日を特定したりするのに役立ちます。

:::tip
全体像を把握するには出席の推移レポートを、特定の日付を詳しく調べたいときは日ごとのグループ出席レポートを使ってください。
:::

## 活用例

- **計画** -- 出席の推移を参考に、今後の礼拝の座席、スタッフ、リソースを計画します。
- **アウトリーチ** -- 出席の減少傾向を早期に見つけ、メンバーへのフォローアップを行います。
- **役員会報告** -- 定期的なリーダーシップ向けの報告に出席データを含め、教会の働きの状況を示します。
- **イベントの評価** -- 特別なイベントの前後で出席を比較し、その影響を測定します。

:::warning
出席データは、グループや礼拝のチェックイン処理を通じて記録されます。出席記録が一貫して行われていない場合、レポートは実際の参加状況を正確に反映しません。設定方法については[出席の記録](../attendance/tracking-attendance.md)を参照してください。
:::
