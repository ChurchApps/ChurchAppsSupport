# 監査ログ

<div class="article-intro">

監査ログは、チャーチマネジメントシステム全体における重要な操作や変更をすべて記録します。ログインの履歴を確認したり、人物レコードへの変更者を追跡したり、権限の更新を監視したりして、チーム内の説明責任を果たすために活用してください。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- サーバー管理者アクセス権を持つB1 Adminアカウント
- **設定**に移動して監査ログを探します

</div>

## 監査ログの表示

1. [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（B1 Adminの左上にある検索バー）を開き、**設定**を展開します。
2. **監査ログ**をクリックします。
3. ログには最近のエントリが表で表示されます。列は以下のとおりです。
   - **日付** -- 操作が行われた日時。
   - **カテゴリ** -- 操作の種類（すばやく確認できるよう色分けされています）。
   - **操作** -- 実行された内容（例：create、update、delete、login_success）。
   - **対象** -- 影響を受けたレコードの種類とID。
   - **IPアドレス** -- 操作を行ったユーザーのIPアドレス。
   - **詳細** -- 行われた具体的な変更の概要。

## ログの絞り込み

ページ上部のフィルターを使って、結果を絞り込めます。

- **カテゴリ** -- 操作の種類で絞り込みます。
  - **すべてのカテゴリ** -- すべてを表示します。
  - **ログイン** -- ログインの成功と失敗。
  - **人物** -- 人物レコードの作成、更新、削除。
  - **権限** -- 権限の付与と取り消し。
  - **寄付** -- 寄付レコードの変更。
  - **グループ** -- グループ管理の操作。
  - **フォーム** -- フォーム送信の履歴。
  - **設定** -- 構成の変更。
- **開始日** -- この日付以降のエントリを表示します。
- **終了日** -- この日付までのエントリを表示します。

フィルターを設定したら、**検索**をクリックして結果を更新します。

## カテゴリについて

各カテゴリは、すぐに識別できるよう色分けされています。

- **ログイン** -- 青のチップ。ログインの成功と失敗を記録します。
- **人物** -- 紫のチップ。人物レコードの作成、更新、削除を記録します。
- **権限** -- 赤のチップ。アクセス権の付与や取り消しを記録します。
- **寄付** -- 緑のチップ。寄付レコードの変更を記録します。
- **グループ** -- グレーのチップ。グループ管理の操作を記録します。
- **フォーム** -- オレンジのチップ。フォーム送信の履歴を記録します。
- **設定** -- 黄色のチップ。構成の変更を記録します。

## ログのエクスポート

ログのエントリが表示されているときに、**CSVダウンロード**ボタンが表示されます。クリックすると、現在絞り込まれている結果を、オフラインでの確認や記録保管のためにスプレッドシートへ書き出せます。

## ページ送り

表の下部にあるページ送りコントロールを使って、結果を移動できます。1ページあたり25、50、100件のエントリを表示できます。

:::info
監査ログのエントリは1年間自動的に保持されます。365日より古いエントリは、システムの性能を維持するために削除されます。
:::

:::tip
特に新しいチームメンバーを迎えたときや、大きな構成変更を行ったあとは、監査ログを定期的に確認してください。予期しない操作を早期に発見できます。
:::
