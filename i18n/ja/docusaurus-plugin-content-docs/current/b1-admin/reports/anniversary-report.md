# 結婚記念日リスト

<div class="article-intro">

月ごとに結婚記念日を迎える人の一覧が必要ですか？ 週報、カード、お知らせに使えます。人物検索では **Anniversary Month** で絞り込み、結果の中に日付を表示できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 各人のプロフィールに結婚記念日が入力されていることを確認してください。詳しくは [人の追加](../people/adding-people.md) を参照してください。
- 人物を表示する権限が必要です。詳しくは [ロールと権限](../settings/roles-permissions.md) を参照してください。

</div>

## 月ごとの結婚記念日リストを取得する

1. [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin の左上にある検索バー）を開き、**People** を展開して **People** をクリックします。
2. 検索ボックスの下にある **Advanced** をクリックします。
3. **Demographics** セクションを展開し、**Anniversary Month** にチェックを入れて、月を選択します。
4. 検索を実行します。その月に結婚記念日を迎える全員が結果に表示されます。
5. 日付を確認するには、**View as** を **Table** に切り替え、ページ上部の **Select columns** アイコンをクリックして **Anniversary** 列を有効にします。並べ替えや印刷をしたい場合は、**Export** をクリックしてスプレッドシートとしてダウンロードできます。

## 活用例

- **週報** -- 当月のリストを取得し、週報やお知らせに記念日を載せます。
- **記念日カード** -- 当月のリストを書き出し、カードを書くチームに渡します。
- **節目のお祝い** -- **Years Married** フィルターと組み合わせて、節目の記念日を見つけます。

:::tip
記念日が来る前にカードやお知らせを準備できるよう、毎月初めにこの検索を実行することをおすすめします。
:::

:::info
結婚記念日のデータは、各人のプロフィールにある記念日の項目から取得されます。リストに載っていない人は、プロフィールに日付を追加する必要があります。詳しくは [人の追加](../people/adding-people.md) を参照してください。
:::

##関連項目
