# 寄付サマリー

<div class="article-intro">

寄付サマリーレポートでは、教会の献金活動を一目で把握できます。寄付の合計額の追跡、献金傾向の監視、リーダーシップチーム向けの財務報告の準備に使用してください。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 寄付がシステムに[一貫して記録されている](../donations/recording-donations.md)ことを確認してください
- 財務レポートにアクセスするには、適切な[権限](../settings/roles-permissions.md)が必要です

</div>

## レポートの実行

1. ブラウザで **admin.b1.church/reports/donationSummary** に直接アクセスしてください（レポートはナビゲーションメニューに表示されません。このアドレスをブックマークしておくと、簡単に戻れます）。
2. **日付範囲** を設定して、レポートの対象期間を指定します。
3. **ファンド**などの追加フィルターを適用して、結果を絞り込みます。
4. 選択した期間の献金サマリーがレポートに表示されます。

## レポートの内容

寄付サマリーレポートには、次の情報が含まれます。

- **寄付の合計** -- 選択した期間の献金総額。
- **寄付者数** -- 寄付をした個別の寄付者の人数。
- **ファンド別の金額** -- 該当する場合、ファンドごとの献金の内訳。

## 活用例

- **財務計画** -- 献金の傾向を確認し、将来の収入を予測して予算を立てます。
- **理事会報告** -- 定例の理事会やリーダーシップ会議向けに、わかりやすい献金データのサマリーを作成します。
- **年末レビュー** -- 年間全体でレポートを実行し、年次財務サマリーを準備します。
- **キャンペーンの追跡** -- ファンドで絞り込み、特別な献金キャンペーンや建築プロジェクトの進捗を追跡します。
- **季節分析** -- 異なる期間の献金を比較し、季節ごとのパターンを把握します。

:::tip
教会の財務状況を把握するため、このレポートは毎月実行することをおすすめします。月ごとのデータを比較すると、傾向を早い段階で発見できます。
:::

:::warning
寄付データは、システムに記録された寄付から取得されます。オンライン献金、小切手処理、手入力のいずれの方法であっても、最も正確なレポートを得るために寄付を一貫して入力してください。詳しくは[寄付の記録](../donations/recording-donations.md)を参照してください。
:::
