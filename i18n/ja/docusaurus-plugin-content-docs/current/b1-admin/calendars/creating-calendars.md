# カレンダーの作成

<div class="article-intro">

B1 Adminでカレンダーを作成すると、1つ以上のグループを接続して、イベントを厳選した表示にまとめられます。イベントは各グループのグループリーダーが管理し、カレンダーにはそれらのイベントが一か所に表示されます。編集権限を持つ管理者は、どのグループのイベントも追加・編集できます。管理者以外のグループリーダーは、自分が担当するグループのイベントのみ管理できます。

</div>

## 新しいカレンダーの作成

1. B1 Adminで、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**カレンダー**を展開して、**カレンダー**をクリックします。
2. ページ上部の**カレンダーを追加**をクリックします。カレンダー一覧の下に新規カレンダーのフォームが開きます。
3. カレンダーの**名前**を入力します（例：「青少年ミニストリーのイベント」「メインチャーチカレンダー」）。
4. 任意で**説明**を追加し、このカレンダーの用途をチーム内で把握しやすくします。
5. **作成**をクリックして新しいカレンダーを保存します。

## カレンダーの詳細ページ

カレンダーを作成したら、その行の**イベントを管理**をクリックして詳細ページを開きます。このページには主に2つのエリアがあります。

- **左の列** — カレンダーの名前と操作ボタン（**新規イベント**、**編集**、**.ics をインポート**、**印刷**）が表示され、その下に**カレンダー内のグループ**一覧があり、このカレンダーに含まれるグループが示されます。グループの横の**削除**をクリックすると、そのグループをカレンダーから外せます。
- **メインエリア** — 接続されたグループから取り込まれたイベントを表示する**カレンダーのイベント**ビューで、その上に**購読**と**グループを追加**ボタンがあります。

## グループの接続

カレンダーにイベントがあるグループは、詳細ページ左側の**カレンダー内のグループ**一覧に自動的に表示されます。

1. カレンダーの上にある**グループを追加**をクリックして、グループをカレンダーに関連付けます。
2. ドロップダウンからグループを選択します。一覧には、自分が所属するグループだけでなく、教会内のすべてのグループが含まれます。
3. そのグループの**すべてのイベント**を含めるか、**特定のイベント**のみを含めるかを選びます。
4. **保存**をクリックします。

各イベントはカレンダーに1回だけ表示されます。グループ全体を追加すると、それまでに1件ずつ追加していたイベントはグループの項目にまとめられます。すでにカレンダーに入っているグループから特定のイベントを選んでも、新たに追加されるものはありません。グループ全体として追加されたグループだけが**カレンダー内のグループ**に一覧表示されます。

### .ics ファイルのインポート

**.ics をインポート**をクリックすると、別のカレンダーからイベントを取り込めます。イベントを所属させる**グループ**を選び、**.ics ファイルを選択**をクリックするかファイルの内容を貼り付けて、**インポート**をクリックします。イベントはそのグループ内に作成され、グループもインポート元のカレンダーに追加されるため、すぐにそこに表示されます。

### カレンダーからのイベントの削除

カレンダー上のイベントをクリックしてから、**カレンダーから削除**をクリックします。これはこのカレンダーからイベントを外すだけで、イベント自体はそのグループに残ります。グループ全体が追加されたためにイベントがカレンダーに表示されている場合、削除すると、そのグループのすべてのイベントがこのカレンダーから外れます（イベントはグループには残ります）。イベントを完全に削除するには、[グループのカレンダー](../groups/group-calendar.md)から削除してください。

:::tip
グループをカレンダーに接続すると、イベントを自動的に集約できて便利です。グループリーダーが自分の[グループ](../groups/creating-groups.md)にイベントを追加すると、あなたの手間をかけずに教会全体のカレンダーに反映されます。
:::

:::info
グループをまたいで教会内の多くのグループからイベントを取り込む単一のカレンダーを作りたい場合は、手早い方法として[厳選カレンダー](./curated-calendar.md)をご覧ください。
:::

## イベントの追加と編集 {#adding-and-editing-events}

カレンダー詳細ページで**新規イベント**をクリックするとイベントを追加できます。また、カレンダー上のイベントをクリックしてから**編集**をクリックすると変更できます。**新規イベント**／**イベントを編集**フォームには次の項目があります。

- **グループ** — イベントが所属するグループです。教会にイベントテンプレートがある場合は、**テンプレート**を選んでフォームに入力することもできます。
- **タイトル**
- **イベント写真** — **写真を追加**（または空の写真欄）をクリックして画像を選択またはアップロードします。画像は16:9の横長に切り抜かれます。**写真を変更**をクリックすると差し替えられます。写真はウェブサイト上のイベントページの上部に表示され、カレンダー要素で**今後のイベント**を表示する場合はそのタイルとして使われます（[ウェブサイトでのイベントの表示](#showing-events-on-your-website)を参照）。
- **説明** — ウェブサイト上のイベントページに表示されます。太字、リスト、リンクを使用できます。
- **開始**と**終了**、**繰り返し**、**公開範囲**（**公開**または**非公開**）。
- **タグ** — カンマ区切りのラベル（例：`youth, students`）。ウェブサイトのカレンダー要素は、特定のタグを持つイベントのみを表示するように設定できます。これは、イベントの登録設定に表示される**タグ**フィールドと同じものです。
- **メモを閲覧できるユーザー**と**メモを投稿できるユーザー** — イベントのメモを読んだり追加したりできるユーザーを指定します（[イベントメモ](#event-notes)を参照）。**スタッフのみ**（既定）、**グループリーダー**（イベントのグループのリーダー）、または**グループメンバー**（リーダーを含め、イベントのグループ内のすべての人）から選びます。
- **施設**と**リソース** — イベントのためにスペースや備品を予約します。[施設、リソース、スケジュール](./rooms-resources.md)をご覧ください。

**保存**をクリックします。イベントが繰り返しの場合、B1は確認を求めます。シリーズ全体のすべての回が更新されるためです。

### イベントメモ {#event-notes}

各イベントには、計画やフォローアップのための独自のメモスレッドがあります。カレンダー詳細ページでイベントをクリックすると、ダイアログにイベントの詳細、リマインダー、その下に**メモ**が表示されます。メモを入力して投稿すると、スレッドに追加されます。

コンテンツの編集またはカレンダーの管理権限を持つスタッフは、常にイベントメモを閲覧・投稿できます。イベントの**メモを閲覧できるユーザー**と**メモを投稿できるユーザー**の設定により、イベントのグループのリーダーやメンバーにも許可するかどうかが決まります。

### ウェブサイトでのイベントの表示 {#showing-events-on-your-website}

カレンダーをウェブサイトに表示するには、ページに**カレンダー**要素を追加して、このカレンダーを選択します。この要素には月間カレンダーや今後のイベントのタイルのグリッドを表示でき、1つのタグを持つイベントのみに限定することもできます。訪問者がイベントをクリックすると、そのイベントの専用ページが開きます。詳しくは[カレンダー要素の使い方](../website/page-editor.md#using-the-calendar-element)をご覧ください。

## イベント登録の有効化 {#enabling-event-registration}

カレンダーのどのイベントについても登録を有効にでき、メンバーはB1ウェブサイトまたはモバイルアプリから申し込めます。

1. 既存のイベントをクリックするか、新しいイベントを作成します。
2. イベントエディターで**登録**のスイッチをオンにします。
3. 登録設定を行います。
   - **定員**（任意）— 登録の上限数を設定します。無制限にする場合は空欄のままにします。
   - **登録開始** — 登録を受け付け始める日時です。
   - **登録終了** — 登録を締め切る日時です。
   - **タグ** — 登録可能なイベントを分類するためのカンマ区切りのラベル（例：「youth, retreat, vbs」）。
   - **登録の質問** — 任意で[フォーム](../forms/creating-forms.md)を添付すると、申込者は申し込みの一環として追加の質問（食事制限、Tシャツのサイズ、緊急連絡先など）に回答できます。質問を省略する場合は**なし**を選びます。
   - **キャンセル待ちを有効化** — イベントが定員に達した場合、申込者を断る代わりにキャンセル待ちに参加させます。[有料登録](./paid-registrations.md#waitlist)をご覧ください。
4. イベントを保存します。

有料イベントの場合、同じ設定ページで、料金付きの**参加者タイプ**、任意の**オプション選択**（追加購入）、**割引コード**を定義できます。支払いは教会の献金プロバイダーを通じて受け付けられます。詳しい手順は[有料登録](./paid-registrations.md)をご覧ください。

登録を有効にすると、メンバーが[B1.church または B1 App](../../b1-church/events/registering.md)でイベントを表示したときに**このイベントに登録**ボタンが表示されます。フォームを添付した場合、登録者は登録中に**質問**のステップが表示され、その回答が登録内容とともに保存されます。

:::info
登録の質問は、**制限付き**に設定されていないフォームでのみ機能します。制限付きフォームは、登録中に表示されずに自動的にスキップされるため、イベントに質問を添付するときは制限のないフォームを使用してください。
:::

### 登録の管理

イベントの登録を表示・管理するには：

1. ジャンプメニューで**カレンダー > 登録**を選びます。
2. 登録が有効なすべてのイベントを一覧できる表が表示されます。イベント名、日付、現在の登録数と定員、タグが表示されます。
3. イベントをクリックすると、登録の全リストが表示されます。名前、メンバー数、参加者タイプ、支払い状況、登録日が含まれます。
4. 詳細ページでは次の操作ができます。
   - **参加者を追加** — 電話や対面などオフラインで申し込んだ人を手動で登録します。
   - 個々の登録を**キャンセル**
   - 登録を完全に**削除**
   - 空きが出たときにキャンセル待ちの登録を**繰り上げ**
   - **CSV を書き出し** — 参加者タイプ、オプション選択、支払い額、質問への回答を含むすべての登録をダウンロードします。

イベントに登録の質問が添付されている場合、詳細ページには、まだ回答していない登録者をすばやく見つけるための**未回答の質問のみ**フィルターも表示され、回答済みの各登録には、回答内容を確認するための**回答を表示**ボタンが表示されます。有料イベントでは、**種類**列、**支払い済み／合計**列、タイプごとの人数、支払いの詳細ダイアログが追加されます。詳しくは[有料登録](./paid-registrations.md#the-registration-roster)をご覧ください。

:::tip
定員の進捗バーを使うと、イベントがどのくらいの速さで埋まっているかを確認できます。定員に達した、または超えた場合、バーは赤くなります。
:::
