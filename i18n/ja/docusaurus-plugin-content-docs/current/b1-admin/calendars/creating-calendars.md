# カレンダーの作成

<div class="article-intro">

B1 Adminでカレンダーを作成すると、複数のグループを関連付けて、イベントを厳選して表示できます。イベントは各グループのグループリーダーが管理し、カレンダーではそれらのイベントを一か所にまとめて表示します。編集権限を持つ管理者は、任意のグループのイベントを追加・編集できます。管理者以外のグループリーダーは、自分が担当するグループのイベントのみ管理できます。

</div>

## 新しいカレンダーの作成

1. B1 Adminで、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**カレンダー**を展開して、**カレンダー**をクリックします。
2. ページ上部の**カレンダーを追加**をクリックします。カレンダー一覧の下に新しいカレンダーのフォームが開きます。
3. カレンダーの**名前**を入力します（例：「青少年ミニストリーのイベント」や「メインチャーチカレンダー」）。
4. 任意で**説明**を追加し、チームがそのカレンダーの目的を把握できるようにします。
5. **作成**をクリックして、新しいカレンダーを保存します。

## カレンダーの詳細ページ

カレンダーを作成したら、その行の**イベントを管理**をクリックして詳細ページを開きます。このページは主に2つのエリアで構成されています。

- **左側の列**：カレンダーの名前と操作ボタン（**新しいイベント**、**編集**、**.icsをインポート**、**印刷**）があり、その下にカレンダーに含まれるグループを示す**カレンダー内のグループ**の一覧があります。グループをカレンダーから外すには、そのグループの横にある**削除**をクリックします。
- **メインエリア**：接続されたグループから取り込まれたイベントを表示する**カレンダーイベント**ビューがあり、その上に**購読**ボタンと**グループを追加**ボタンがあります。

## グループの関連付け

カレンダーにイベントがあるグループは、詳細ページ左側の**カレンダー内のグループ**一覧に自動的に表示されます。

1. カレンダーの上にある**グループを追加**をクリックして、グループをカレンダーに関連付けます。
2. ドロップダウンからグループを選択します。一覧には、自分が所属しているグループだけでなく、教会内のすべてのグループが含まれます。
3. そのグループの**すべてのイベント**を含めるか、**特定のイベント**のみを含めるかを選択します。
4. **保存**をクリックします。

各イベントはカレンダーに一度だけ表示されます。グループ全体を追加すると、それまでに1件ずつ追加していたイベントはグループの項目にまとめられます。すでにカレンダーにあるグループから特定のイベントを選んでも、新たに追加されるものはありません。グループ全体として追加されたものだけが**カレンダー内のグループ**に表示されます。

### .icsファイルのインポート

**.icsをインポート**をクリックすると、別のカレンダーからイベントを取り込めます。イベントを所属させる**グループ**を選び、**.icsファイルを選択**をクリックするかファイルの内容を貼り付けてから、**インポート**をクリックします。イベントはそのグループに作成され、グループはインポート元のカレンダーに追加されるため、イベントはすぐにそのカレンダーに表示されます。

### カレンダーからイベントを削除する

カレンダー上のイベントをクリックしてから、**カレンダーから削除**をクリックします。これはこのカレンダーからイベントを外すだけで、イベント自体は所属するグループに残ります。イベントがグループ全体の追加によってカレンダーに含まれている場合、削除するとそのグループのすべてのイベントがこのカレンダーから外れます（イベントはグループに残ります）。イベントを完全に削除するには、[グループのカレンダー](../groups/group-calendar.md)から削除してください。

:::tip
グループをカレンダーに関連付けると、イベントを自動的にまとめることができて便利です。グループリーダーが[グループ](../groups/creating-groups.md)にイベントを追加すると、あなたが何もしなくても教会全体のカレンダーに反映されます。
:::

:::info
教会内の多くのグループからイベントを取り込む1つのカレンダーを作成したい場合は、手軽な方法として[厳選カレンダー](./curated-calendar.md)をご覧ください。
:::

## イベントの追加と編集 {#adding-and-editing-events}

イベントを追加するには、カレンダーの詳細ページで**新しいイベント**をクリックします。既存のイベントを変更するには、カレンダー上のイベントをクリックしてから**編集**をクリックします。**新しいイベント**/**イベントを編集**フォームには、次の項目があります。

- **グループ**：イベントが所属するグループです。教会にイベントテンプレートがある場合は、**テンプレート**を選んでフォームに内容を自動入力することもできます。
- **タイトル**
- **イベントの写真**：**写真を追加**（または空の写真欄）をクリックして画像を選択またはアップロードします。画像は16:9の横長に切り抜かれます。**写真を変更**をクリックすると差し替えられます。この写真は、ウェブサイト上のイベントページの上部に表示されるほか、カレンダー要素で**今後のイベント**を表示する場合にはイベントのタイルとして表示されます（[ウェブサイトへのイベント表示](#showing-events-on-your-website)を参照）。
- **説明**：ウェブサイト上のイベントページに表示されます。太字、リスト、リンクを使用できます。
- **開始**と**終了**、**繰り返し**、**公開範囲**（**公開**または**非公開**）。
- **タグ**：カンマで区切ったラベル（例：`youth, students`）。ウェブサイトのカレンダー要素では、特定のタグを持つイベントのみを表示するように設定できます。これは、イベントの登録設定にあるものと同じ**タグ**欄です。
- **メモを閲覧できるユーザー**と**メモを投稿できるユーザー**：イベントのメモを読んだり追加したりできるユーザーを指定します（[イベントメモ](#event-notes)を参照）。**スタッフのみ**（初期設定）、**グループリーダー**（イベントのグループのリーダー）、**グループメンバー**（リーダーを含む、イベントのグループの全員）から選択します。
- **施設**と**リソース**：イベントのためにスペースや設備を予約します。[施設、リソース、スケジュール](./rooms-resources.md)を参照してください。

**保存**をクリックします。イベントが繰り返しの場合、B1は確認を求めます。シリーズ全体のすべての回が更新されるためです。

### イベントメモ {#event-notes}

各イベントには、計画やフォローアップのための独自のメモスレッドがあります。カレンダーの詳細ページでイベントをクリックすると、ダイアログにイベントの詳細、リマインダー、その下に**メモ**が表示されます。メモを入力して投稿すると、スレッドに追加されます。

コンテンツの編集またはカレンダーの管理権限を持つスタッフは、常にイベントメモを閲覧および投稿できます。イベントの**メモを閲覧できるユーザー**と**メモを投稿できるユーザー**の設定によって、イベントのグループのリーダーやメンバーにも許可するかどうかが決まります。

### ウェブサイトへのイベント表示 {#showing-events-on-your-website}

ウェブサイトにカレンダーを表示するには、ページに**カレンダー**要素を追加して、このカレンダーを選択します。この要素では、月間カレンダーまたは今後のイベントのタイルのグリッドを表示でき、1つのタグを持つイベントのみに限定することもできます。イベントをクリックした訪問者は、そのイベント専用のページを開きます。詳しくは[カレンダー要素の使用](../website/page-editor.md#using-the-calendar-element)を参照してください。

## イベント登録の有効化 {#enabling-event-registration}

カレンダーのどのイベントにも登録を有効にできます。これにより、メンバーはB1ウェブサイトまたはモバイルアプリから申し込めるようになります。

1. 既存のイベントをクリックするか、新しいイベントを作成します。
2. イベントエディターで**登録**をオンにします。
3. 登録の設定を行います。
   - **定員**（任意）：登録の上限数を設定します。無制限の場合は空欄のままにします。
   - **登録開始**：登録が可能になる日時です。
   - **登録締切**：登録が締め切られる日時です。
   - **タグ**：登録可能なイベントを分類するためのカンマ区切りのラベル（例：「youth, retreat, vbs」）です。
   - **登録の質問**（任意）：[フォーム](../forms/creating-forms.md)を添付すると、申し込み時に追加の質問（食事制限、Tシャツのサイズ、緊急連絡先など）に回答してもらえます。質問をしない場合は**なし**を選択します。
   - **キャンセル待ちを有効にする**：定員に達した後、登録を断る代わりに追加の申込者をキャンセル待ちに登録できるようにします。[有料登録](./paid-registrations.md#waitlist)を参照してください。
4. イベントを保存します。

有料イベントの場合、同じ設定ページで価格付きの**参加者タイプ**、任意の**オプション選択**（追加オプション）、**割引コード**を設定できます。支払いは教会の寄付サービス事業者を通じて受け付けます。詳しい手順は[有料登録](./paid-registrations.md)を参照してください。

登録を有効にすると、メンバーが[B1ウェブサイト](../../b1-church/events/registering.md)または[B1モバイルアプリ](../../b1-mobile/events/registering.md)でイベントを表示したときに、**このイベントに登録**ボタンが表示されます。フォームを添付している場合、登録者は登録中に**質問**ステップが表示され、その回答が登録内容と一緒に保存されます。

:::info
登録の質問は、**制限付き**に設定されていないフォームでのみ機能します。制限付きのフォームは、表示されずに登録中に自動的にスキップされます。そのため、イベントに質問を添付する場合は、制限のないフォームを使用してください。
:::

### 登録の管理

イベントの登録を表示および管理するには、次の手順に従います。

1. ジャンプメニューで**カレンダー > 登録**を選択します。
2. 登録が有効になっているすべてのイベントの表が表示されます。イベント名、日付、現在の登録数と定員、タグが表示されます。
3. イベントをクリックすると、登録の全一覧が表示されます。名前、メンバー数、参加者タイプ、支払い状況、登録日が含まれます。
4. 詳細ページでは、次の操作ができます。
   - **参加者を追加**：電話やオフラインで申し込んだ人を手動で登録します。
   - 個々の登録を**キャンセル**します。
   - 登録を完全に**削除**します。
   - 空きが出たときに、キャンセル待ちの登録を**繰り上げ**ます。
   - **CSVを書き出す**：参加者タイプ、オプション選択、支払い金額、質問への回答を含むすべての登録をダウンロードします。

イベントに登録の質問が添付されている場合、詳細ページには、まだ回答していない登録者をすばやく見つけるための**未回答の質問のみ**フィルターも表示されます。また、回答済みの各登録には、回答を確認するための**回答を表示**ボタンがあります。有料イベントでは、**種類**の列、**支払い済み / 合計**の列、種類ごとの人数、支払いの詳細ダイアログが追加されます。詳しくは[有料登録](./paid-registrations.md#the-registration-roster)を参照してください。

:::tip
定員の進捗バーを使うと、イベントがどれくらいの速さで埋まっているかを確認できます。バーは、イベントが定員に達するか超えると赤くなります。
:::
