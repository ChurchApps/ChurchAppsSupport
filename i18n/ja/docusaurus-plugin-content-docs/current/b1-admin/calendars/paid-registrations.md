# Paid Registrations

<div class="article-intro">

イベントへの登録は、単純な人数確認にとどまりません。料金付きの参加者タイプ（大人や子どもなど）を設定したり、独自の価格と数量を持つ任意の追加オプションを用意したり、割引コードを作成したり、教会で既に利用している献金プロバイダーを通じて登録時に支払いを受け付けたりできます。イベントが定員に達した場合は、任意で待機リストを設定でき、空きが出るとメンバーを自動的に繰り上げて登録します。

</div>

<h4>始める前に</h4>

- まず、イベントで登録を有効にしてください。詳しくは [カレンダーの作成](creating-calendars#enabling-event-registration) を参照してください。
- オンラインで支払いを受け付けるには、教会で[オンライン献金の設定](../donations/online-giving-setup.md)（Stripe、PayPal、またはKingdom Funding）を済ませておく必要があります。無料のイベントであれば献金の設定は不要です。オンライン献金が未設定でも有料の登録は利用できますが、参加者は教会に直接支払うことになります。詳しくは [オンライン献金を設定していない教会](#churches-without-online-giving) を参照してください。

## 登録設定を開く

1. B1 Adminで、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**Calendars > Registrations** を選択して、対象のイベントを開きます（カレンダーからイベントを開くこともできます）。
2. **Registration Settings** カードには基本設定が表示されます。項目は **Enable Registration**、**Capacity**、**Registration Opens/Closes**、**Tags**、**Registration Questions** です。
3. 基本設定の下には、3つのアコーディオンがあります。**Attendee Types**、**Selections**、**Discount Codes** です。

## 参加者タイプ

参加者タイプを使うと、参加者の種類ごとに異なる料金を設定でき、それぞれの定員も個別に制限できます。

1. **Attendee Types** アコーディオンを開き、**Add Type** をクリックします。
2. **Name** に名前を入力します（例：「大人」「子ども」「学生」）。
3. **Price** を設定します。無料のタイプにする場合は 0 を入力します。
4. 必要に応じて、そのタイプだけの **Capacity** を設定します（例：子どもの枠を20名のみにする）。タイプごとの上限を設けない場合は空欄のままにします。
5. **Save** をクリックします。

登録時には、参加者それぞれがタイプを選択します。売り切れのタイプには **Sold out** と表示され、選択することはできません。名簿には、各参加者のタイプと、タイプごとの人数の集計が表示されます。

## 追加オプション

追加オプションは、Tシャツ、食事プラン、アクティビティのアップグレードなど、任意で追加できる有料の項目です。

1. **Selections** アコーディオンを開き、**Add Selection** をクリックします。
2. **Name**、任意で **Description**、そして **Price** を入力します（0 を入力すると「Free」と表示されます）。
3. 必要に応じて **Capacity**（全登録を通じた合計の数量）と **Max Qty**（1件の登録で注文できる上限数）を設定します。
4. **Save** をクリックします。

登録者は申し込み時に数量を選択します。合計数は定員に対してカウントされるため、販売数が定員を超えることはありません。

## 割引コード

1. **Discount Codes** アコーディオンを開き、**Add Discount Code** をクリックします。
2. 登録者が入力する **Code** を入力します。
3. **Type** で **Percent**（割合）または **Amount**（金額）を選び、**Value** を入力します。
4. 必要に応じて、**Start Date** / **End Date**、**Min Members**（登録に含まれる参加者の最低人数）、**Max Uses**（最大使用回数）でコードの利用条件を制限できます。
5. **Save** をクリックします。

各コードには **Uses** の数が表示され、何回使用されたかを確認できます。登録者がコードを適用すると、すぐにフィードバックが表示されます。コードの有効期限が切れている場合、まだ開始していない場合、参加者の人数が不足している場合には、その旨が明確に表示されます。

## 待機リスト

Registration Settings カードで **Enable Waitlist** をオンにします。イベントが定員に達すると、次のように動作します。

- 新しい登録者は、登録を断られるのではなく、待機リストの枠を提示されます。通常どおり申し込みを完了できます（待機中は支払い手続きがスキップされます）。
- 誰かがキャンセルすると、待機リストで最も古い登録が**自動的に繰り上げ**られ、空きが出たことを知らせるメールが届きます。未払いの残高がある場合、メールには教会のB1サイトの [My Registrations](../../b1-church/events/my-registrations) へのリンクが含まれており、そこから支払いを完了できます。
- 待機中の行にある **Promote** 操作を使うと、いつでも手動で繰り上げができます。イベントの定員を増やした後などに便利です。

:::info
繰り上げられた登録は、残高が支払われるまで*保留中（pending）*のままです。支払いが完了するか、支払うものがない場合に確定します。
:::

## 登録名簿

登録ページからイベントを開くと、すべての登録を確認できます。カードのタイトルには、定員に対して何件の登録が枠を確保しているかが表示されます（例：*Registrations (18 / 20)*）。枠を確保しているのは、保留中と確定済みの登録のみです。待機中の登録がある場合、タイトルに件数が追加されます（例：*· 3 waitlisted*）。同じ件数が定員バーの下にも表示されます。表には **Name**、**Members**、**Type**（各参加者のタイプ）、**Paid / Total**（未払い残高がある場合は警告付き）、**Status**、**Date** が表示されます。表の上には、タイプごとの人数の集計チップも表示されます。

- 行の詳細アイコンをクリックすると、**Registration Details** ダイアログが開きます。ここには、メンバー、追加オプション、支払済み額と残高、そしてすべての支払い（金額、支払い方法、日付）を一覧できる **Payments** の表が表示されます。
- **Export CSV** を使うと、名簿全体をダウンロードできます。CSVには、メンバー、参加者タイプ、追加オプション、支払済み/合計/残高、ステータス、そして登録質問ごとの列が含まれます。
- **Add Attendee** を使うと、教会内の任意の人について、オフラインまたは電話での申し込みを記録できます。その人物を選び、有料イベントの場合は参加者タイプも選択します。この操作ではカードへの請求は行われません。有料の登録は、支払うべき全額が残高として記録された**保留中（pending）**の状態で保存されます。教会がオンライン献金を利用している場合、本人は [My Registrations](../../b1-church/events/my-registrations) から支払うことができます。そうでない場合は、直接受け取ってください。参加者を追加するには、Registrations の編集権限が必要です。

:::info
返金は B1 内では処理されません。キャンセルされた有料の登録を返金する必要がある場合は、献金プロバイダーの管理画面（例：Stripe）から返金を行ってください。
:::

## 支払いの仕組み

支払いは、教会が献金に既に使用しているのと同じ献金ゲートウェイを通じて処理されます。カード情報は直接プロバイダーに送信されるため、B1のサーバーを経由することはありません。料金は常にサーバー側で、設定された参加者タイプ、追加オプション、割引コードに基づいて計算されるため、登録者が合計金額を改ざんすることはできません。ログインしているメンバーは、保存済みのカードで支払うことができます。ゲストはチェックアウト時にカード情報を入力し、支払いの前に **I'm not a robot** のチェックボックスにチェックを入れる必要があります。

### オンライン献金を設定していない教会

教会で献金プロバイダーを設定していない場合でも、有料のイベントで登録を受け付けることができます。支払い画面では、オンライン決済が利用できないこと、また教会に直接支払えることが登録者に表示されます。**Register and Pay Later** ボタンを押すと、登録が保存されます。登録は、支払うべき全額が残高として記録された**保留中（pending）**の状態で保存され、名簿には残高の警告付きで表示されます。お金の受け取りは、教会の通常の方法で行ってください。

:::info
B1には、オフラインの支払いを受領済みとして記録する機能はありません。残高は、受け取った後も名簿と登録者の [My Registrations](../../b1-church/events/my-registrations) カードに残るため、誰が支払い済みかを独自に記録しておいてください。
:::
