# イベントのリマインダー

<div class="article-intro">

イベントのリマインダーは、イベントの前に適切な人へ自動的に通知を送る機能です。たとえば「お忘れなく！ ヘルスケアのワークショップは明日の午前9時から始まります。」といった通知を送れます。リマインダーはイベントに一度設定するだけで、B1 がスケジュールどおりにプッシュ通知、メール、そして教会でテキストメッセージを設定している場合はテキストメッセージで送信します。メンバーは自分の [通知設定](../../b1-church/getting-started/notification-preferences) で、受け取るリマインダーを選べます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- リマインダーを送りたいイベントを作成します（[カレンダーの作成](creating-calendars) を参照）
- 登録済みの参加者に送るには、イベントで [登録を有効にして](creating-calendars) ください
- グループ全体に送るには、イベントがメンバーのいる [グループ](../groups/creating-groups) に属していることを確認してください

</div>

## リマインダーの設定

リマインダーは、イベントの **Reminders** セクションで設定します。

- **新しいイベントを作成する**場合は、保存する前にイベントエディターの **Reminders** セクションを開きます。
- **既存のイベント**の場合は、イベントの **Registration Details** ページ（**Registrations** セクションから開きます）を開き、リマインダーを追加または変更します。

1. **Enable reminders** をオンにします。
2. **When**（送信タイミング）を選びます。**7 days before**、**3 days before**、**1 day before**、**Day of** から、最大3つまで選択できます。
3. リマインダーを送る **Time of day**（時刻）を設定します。初期値は **9:00 AM** で、教会の[タイムゾーン](../settings/church-settings.md#time-zone)が基準になります。
4. **Who**（送信対象）を選びます（下の[リマインダーの送信対象](#who-gets-reminded)を参照）。
5. 必要に応じて **Message**（メッセージ）を入力します。空欄のままにすると初期の文面が使われます。独自の文面を書く場合は、`{{eventTitle}}` を含めると、イベント名に置き換えられます。
6. **Channels**（送信方法）を選びます。**Push**（プッシュ通知）、**Email**（メール）、そして教会で[テキストメッセージのプロバイダー](../settings/church-settings.md#texting)を接続している場合は **Text**（テキスト）を選べます。
7. イベントを保存します。

設定を変更すると、**live preview**（ライブプレビュー）に、リマインダーを受け取る人数のおおよその見込み、連絡できない参加者の数、次に送信される予定日時が表示されます。保存する前に、リマインダーの内容を確認できます。

## リマインダーの送信対象

**Who** の設定で、リマインダーを送る相手を決めます。

- **Registrants only**（登録者のみ）: 個人の記録にリンクされている、イベントに登録済みのすべての人が対象です。イベントで登録が有効な場合の初期値です。そのため、少人数の登録制イベントのリマインダーが、誤って教会全体のグループに送られることはありません。
- **Heads / registrants only**（代表者・登録者のみ）: 登録ごとに1通送ります（登録した本人が対象）。登録に含まれるすべての家族に送るわけではありません。
- **Group members**（グループのメンバー）: イベントのグループに所属するすべての人が対象です。イベントで登録を使わない場合の初期値です。
- **Auto**（自動）: 登録が有効な場合は登録者に、そうでない場合はグループに送ります。

:::info
名前だけで追加されたゲスト（個人の記録とリンクされていない人）は、アカウント、デバイス、メールアドレスがないため、リマインダーを受け取れません。プレビューには、この条件に当てはまる参加者の人数が表示されるので、予想外の結果を防げます。また、連絡を受け取らない設定にしているメンバーにも送信されません。
:::

## リマインダーが送信されるタイミング

- リマインダーは、選択したオフセットごとに、教会の現地時間で、設定した **時刻** に送信されます。
- イベントの **日付または時刻を変更**すると、保留中のリマインダーは自動的に再スケジュールされます。リマインダーを編集する必要はありません。
- イベントを **削除**した場合（または定期イベントの1回分を取り消した場合）、保留中のリマインダーは自動的にキャンセルされます。
- 定期イベントは自動的に処理されます。今後の各回に、それぞれリマインダーが設定されます。

:::tip
リマインダーは、まず **プッシュ通知** で送信され、プッシュ通知が使えない場合は **メール** で送信されます。メンバーがプッシュ通知を有効にしていれば、プッシュ通知が届きます。有効になっていなければ、代わりにメールが届きます。メンバーは、通知の種類ごとに受け取る方法を[通知設定](../../b1-church/getting-started/notification-preferences)で選べます。
:::

## テキストのリマインダー

**Text** の送信方法は、教会にテキストメッセージのプロバイダーが接続されている場合にのみ表示されます。テキストは教会のテキストメッセージプロバイダーを通じて送信され、送信のたびに教会に費用が発生する場合があります。プッシュ通知やメールのリマインダーに加えて送信され、次の条件を満たす人だけに送られます。

- [通知設定](../../b1-church/getting-started/notification-preferences) で **Text messages**（テキストメッセージ）をオンにしている
- プロフィールに携帯電話番号が登録されている

各テキストは、教会の名前で始まり、1通の SMS に収まる長さで、「Reply STOP to opt out.」（配信停止は STOP と返信してください）で終わります。STOP と返信した人には、教会からのテキストが送られなくなります。STOP の返信を B1 に届けるには、[テキストメッセージの設定](../settings/church-settings.md#texting)に表示される **Inbound (STOP) webhook URL**（受信（STOP）webhook の URL）を、プロバイダーの受信メッセージ用 webhook に貼り付けてください。

## メンバーが管理できる内容

リマインダーは、必ず各メンバーの[通知設定](../../b1-church/getting-started/notification-preferences)に従います。メンバーは次のことができます。

- 他の通知はオンのまま、**Event Reminders**（イベントのリマインダー）をプッシュ通知、メール、テキストのそれぞれについてオフにする。
- **Text messages** で、テキストのリマインダーのオン・オフを切り替える。
- **quiet hours**（おやすみ時間）を設定し、緊急性の低い通知を適切な時間まで待たせる。

メンバーがイベントのリマインダーの受信を停止している場合、その選択を上書きすることはできません。これは、B1 が迷惑メール防止のルールに準拠し、メンバーが自分の受信箱を管理できるようにするためです。

## 奉仕のリマインダー

プランに割り当てられたボランティアには、プランの詳細が記載された別の **奉仕のリマインダー** が届きます。まだ返信していない場合は、メール内に **Accept / Decline**（承諾 / 辞退）ボタンも表示されます。これらのリマインダーは、カレンダーのイベントではなく、プランの種類で設定します。テキストで送信することもできます。ボランティアの割り当てとリマインダーの仕組みについては、[ボランティアのリマインダー](../serving/plans#volunteer-reminders)と[日曜日のボランティア](../guides/sunday-volunteers)を参照してください。
