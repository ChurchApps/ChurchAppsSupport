# 部屋・リソース・スケジュール

<div class="article-intro">

部屋とリソースでは、教会内で予約できるスペースや機材を管理できます。グループやチームがイベントで部屋を使いたい場合や、リソースを借りたい場合は、B1 からリクエストを送信できます。承認または却下することで、二重予約を防げます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1 Admin のカレンダーセクションへの管理者アクセスが必要です
- 予約リクエストを送信するメンバーが含まれる[グループ](../groups/creating-groups)を設定しておいてください

</div>

## 部屋・リソース画面を開く

B1 Admin で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（画面左上の検索バー）を開き、**カレンダー**を展開して **部屋・リソース**をクリックします。この画面には **部屋**、**リソース**、**ブロックアウト**、**テンプレート**の4つのタブがあります。画面上部の追加ボタンは選択中のタブに合わせて変わり、**検索**ボックスで現在の一覧を絞り込めます。

## 部屋

部屋とは、カレンダーのイベントと一緒に予約できる物理的なスペースのことです。たとえば礼拝堂、交流ホール、教室などが該当します。

### 部屋の追加

1. **部屋**タブで、画面上部の **部屋を追加**をクリックします。
2. 部屋の**名前**を入力します。
3. 必要に応じて**定員**（最大収容人数）を設定します。
4. **承認グループ**を設定します。グループがこの部屋をリクエストすると、選択したグループのリーダーに通知が届き、予約の承認が必要になります。承認が不要な場合は空欄のままにしてください。
5. **保存**をクリックします。

### 部屋の編集・削除

任意の部屋の横にある**編集**をクリックし、変更を加えてから**保存**をクリックします。部屋を完全に削除するには**削除**を使用します。

## リソース

リソースとは、イベントと一緒に予約できる備品のことです。AV機器、プロジェクター、椅子、バンなどが該当します。

### リソースの追加

1. **リソース**タブをクリックし、**リソースを追加**をクリックします。
2. **名前**を入力し、必要に応じて**説明**を入力します。
3. リソースの貸し出しに承認が必要な場合は、**承認グループ**を設定します。
4. **保存**をクリックします。

## ブロックアウト

ブロックアウトを使うと、改修、予約済みの期間、メンテナンスなどの理由で、特定の時間帯に部屋やリソースが予約されないようにできます。

### ブロックアウトの追加

1. **ブロックアウト**タブをクリックし、**ブロックアウトを追加**をクリックします。
2. **部屋**、**リソース**、またはすべての部屋とリソースのどれをブロックするかを選択します。
3. ブロックアウトの**開始**と**終了**の日付と時刻を設定します。
4. 必要に応じて**理由**のメモを追加します。
5. **保存**をクリックします。

## イベントテンプレート

テンプレートを使うと、タイトル、説明、関連グループなど、再利用できるイベントの設定を保存できます。これにより、定期的なイベントを一貫した内容で作成できます。

### テンプレートの追加

1. **テンプレート**タブをクリックし、**テンプレートを追加**をクリックします。
2. テンプレートの**名前**を入力します。
3. 必要に応じて**グループ**をリンクします。こうすると、テンプレートから作成されたイベントが自動的そのグループに関連付けられます。
4. **保存**をクリックします。

新しいイベントを作成するとき、スタッフは既存のテンプレートを選択して、イベントの詳細を事前に入力できます。
