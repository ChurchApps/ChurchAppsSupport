# 利用可能状況カレンダー

<div class="article-intro">

利用可能状況カレンダーでは、教会内のすべての部屋やリソースの予約を一覧で確認できます。ここから予定を把握し、競合を事前に見つけ、任意のイベントに部屋やリソースを直接予約できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- **部屋とリソース**セクションで、少なくとも1つの[部屋またはリソース](./rooms-resources.md)を設定しておいてください
- B1 Admin の**カレンダー**セクションを編集できる権限が必要です

</div>

## 利用可能状況カレンダーを開く

B1 Admin で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**カレンダー**を展開して、**利用可能状況**をクリックします。

## カレンダーの見方

カレンダーには、初期設定では今月が表示されます。上部の矢印で前後に移動したり、月、週、日の表示を切り替えたりできます。

各予定は予約の状態によって色分けされています。

| 色 | 意味 |
|-------|---------|
| 緑 | 承認済み |
| オレンジ | 承認待ち |
| グレー | 予約不可（利用できません） |

予定にカーソルを合わせると、予定のタイトルと、紐づいている部屋またはリソースが表示されます。

## 部屋またはリソースで絞り込む

左上の**部屋 / リソース**のドロップダウンを使うと、カレンダーを1つの部屋またはリソースに絞り込めます。**すべての部屋とリソース**を選ぶと、全体表示に戻ります。

## 部屋またはリソースを予約する

1. ページ上部の**予約**ボタンをクリックします。
2. 開いたダイアログで、予定の詳細を入力します。
   - **タイトル** — 予定の名前
   - **開始**と**終了**の日付と時刻
   - **公開設定** — 公開または非公開
   - **部屋** — 予約する部屋を1つ以上選択します
   - **リソース** — 予約するリソースを1つ以上選択します
3. 必要に応じて、**準備**と**片付け**の時間（分単位）を設定します。予定の開始時刻と終了時刻は変わりませんが、前後にこの時間を加えて、準備や片付けのためにスペースを確保します。
4. 同じ予約を繰り返す場合は、**繰り返し**にチェックを入れ、繰り返しの設定を行います。
   - **繰り返し間隔** -- 間隔を指定します（例：2週間ごと）。
   - **頻度** -- 毎日、毎週、または毎月から選びます。毎週を選ぶと曜日を指定でき、毎月を選ぶと月の固定日、または「第2火曜日」のような相対的なパターンを指定できます。
   - **終了** -- 終了しない、特定の日付で終了する、または指定した回数の後に終了する、から選びます。
5. 予定の開始・終了とは別に予約期間を指定したい場合は、**カスタム予約期間**をオンにして、期間の開始時刻と終了時刻を入力します。予定に記載されている時間の外でも部屋を使えるようにする必要がある場合に使用します。
6. **保存**をクリックして予約を送信します。

:::info
部屋またはリソースに**承認グループ**が設定されている場合、そのグループのリーダーが承認するまで、予約は**承認待ち**と表示されます。承認の流れについては、[カレンダーの承認](./approvals.md)を参照してください。
:::

:::tip
保存する前に、カレンダーが競合を強調表示します。競合の警告が表示された場合は、時間を調整するか、別の部屋を選んでください。
:::
