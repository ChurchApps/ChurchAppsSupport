# カレンダー

<div class="article-intro">

B1 Admin のカレンダーセクションでは、グループのイベントをまとめて、教会用のキュレーションカレンダーを作成できます。グループリーダーは自分のグループのイベントを管理し、管理者はそれらのイベントを B1.church のウェブサイト上に表示するカレンダーを作成して、会衆が見られるようにできます。

</div>

## カレンダーを表示する

1. B1 Admin で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**Calendars** を展開して **Calendars** をクリックします。
2. Calendars ページには、すべてのカレンダーの名前とステータスが表で表示されます。**Find a calendar** のボックスを使って一覧を絞り込めます。
3. 各行には、カレンダーを開く **Manage Events** リンクと、名前の変更や削除を行う **Edit** リンクがあります。

## できること

- **新しいカレンダーを追加する** -- ページ上部の **Add Calendar** をクリックして、特定の奉仕、イベントの種類、または目的のためのカレンダーを作成します。手順については [カレンダーの作成](creating-calendars) を参照してください。
- **カレンダーを編集する** -- 任意のカレンダーの **Manage Events** をクリックして開き、そのカレンダーに含めるグループを管理します。
- **カレンダーを公開する** -- カレンダーを B1.church のウェブサイトに表示して、訪問者が教会の今後のイベントを確認できるようにします。
- **キュレーションカレンダーを作成する** -- 複数のグループからイベントを1つのカレンダー表示にまとめ、教会で行われているすべてのことを一覧できます。詳しくは [キュレーションカレンダー](curated-calendar) を参照してください。
- **部屋とリソースを管理する** -- 予約可能なスペースや機材を管理し、承認リクエストを処理します。詳しくは [部屋とリソース](rooms-resources) を参照してください。
- **空き状況を確認する** -- 部屋とリソースのすべての予約を1つのカレンダーで確認し、今後のイベントのためにスペースを予約します。詳しくは [空き状況カレンダー](availability) を参照してください。

:::info
カレンダーは [グループ](../groups/creating-groups.md) と密接に連携しています。グループにイベントが予定されていると、そのイベントをカレンダーに取り込めます。グループをカレンダーに関連付ける方法については、[カレンダーの作成](creating-calendars) のページを参照してください。
:::
