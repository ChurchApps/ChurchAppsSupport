# キュレーションカレンダー

<div class="article-intro">

キュレーションカレンダーは、複数のグループのイベントを1つの統合されたカレンダー表示にまとめます。教会内のすべての活動やグループの予定を1か所で表示する、教会全体のカレンダーを作るのに最適です。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 含めたいイベントを持つ[グループ](../groups/creating-groups.md)を設定しておく
- グループリーダーが、それぞれのグループにイベントを追加していることを確認する
- [カレンダーの作成](creating-calendars)の基本に慣れておく

</div>

## キュレーションカレンダーを作成する

1. B1 Adminで、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（画面左上の検索バー）を開き、**Calendars**を展開して、**Calendars**をクリックします。
2. **Add Calendar**をクリックして、新しいキュレーションカレンダーを作成します。
3. カレンダーに**名前**を付けます（例：「教会イベント」や「今週の教会の予定」）。
4. **Create**をクリックして保存します。

## カレンダーにグループを追加する

1. 新しいカレンダーの**Manage Events**をクリックして開きます。
2. カレンダーの上にある**Add Group**をクリックします。追加したグループは、ページ左側の**Groups in Calendar**リストに表示されます。
3. ドロップダウンメニューからグループを選択します。自分がメンバーでないグループも含め、教会内のすべてのグループが一覧に表示されます。
4. そのグループの**すべてのイベント**を追加するか、**特定のイベント**のみを追加するかを選択します。
5. **Save**をクリックします。
6. 含めたいグループの数だけ、この手順を繰り返します。

イベントは、単独で追加した場合と、グループ全体を追加した場合の両方があっても、カレンダー上には1回だけ表示されます。**Groups in Calendar**リストには、すべてのイベントを含めて追加されたグループのみが表示されます。

カレンダーからイベントを外すには、そのイベントをクリックして**Remove from Calendar**を選びます。イベントはグループ内に残ります。グループ全体から追加されたイベントを外すと、そのグループのすべてのイベントがこのカレンダーから削除されます。

:::tip
すべての活動中のグループを追加すると、会衆が毎週教会で行われていることを全体として把握できる、包括的なカレンダーを作成できます。
:::

## カレンダーを共有する

キュレーションカレンダーの設定が完了したら、いくつかの方法で共有できます。

- **ウェブサイトに埋め込む** -- ページに**Calendar**要素を追加すると、カレンダーを月単位のグリッド表示、または今後のイベントのタイル表示で表示できます。1つのタグが付いたイベントのみに絞り込むこともできます。各イベントは、サイト上のそれぞれのページにリンクします。詳しくは[カレンダー要素の使い方](../website/page-editor.md#using-the-calendar-element)をご覧ください。
- **ICSで購読する** -- **Subscribe**をクリックしてICSリンクをコピーします。会衆はこのリンクをGoogleカレンダー、Appleカレンダー、Outlook、その他のカレンダーアプリに貼り付けて、最新の状態を保つことができます。
- **ICSファイルをダウンロードする** -- カレンダーファイルをダウンロードして、カレンダーアプリにインポートします。

:::info
グループリーダーが[グループ](../groups/creating-groups.md)に新しいイベントを追加すると、そのイベントは自動的にキュレーションカレンダーに表示されます。新しいイベントが追加されるたびにキュレーションカレンダーを手動で更新する必要はありません。
:::

:::note 非公開のイベント
ウェブサイト上のキュレーションカレンダーとそのICS購読には、**公開**イベントのみが表示されます。B1 Adminでは、コンテンツを編集できるスタッフは、グループの**非公開**イベントもキュレーションカレンダー上で確認できます。これにより、カレンダーを作成する際に全体のスケジュールを確認できます。
:::
