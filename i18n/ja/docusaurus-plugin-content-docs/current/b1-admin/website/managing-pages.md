# ページの管理

<div class="article-intro">

Webサイトのページ画面は、教会のWebサイトにあるすべてのページを作成、編集、整理するための中心的な場所です。この1つの画面で、ページの内容とサイトのナビゲーションの両方を管理できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [初期設定](./initial-setup.md)を完了して、ドメインと基本的なサイト設定を行ってください
- コンテンツと画像を準備してください。メディアファイルは、先に[ファイル](./files.md)マネージャーでアップロードしてください。

</div>

:::info
教会に複数のWebサイトがある場合（例えば、キャンパスごとに別のサイトがある場合）は、Webサイトのページ画面の上部にあるサイト切り替えを使って、サイト間を移動できます。各サイトには、それぞれ独自のページ、ナビゲーション、[外観](./appearance.md)設定があります。
:::

## ページの種類を理解する

**ページ**の表には、サイト上のすべてのページが**パス**と**タイトル**で一覧表示されます。ページには次の2種類があります。

- **自動生成** -- 教会のデータに基づいてシステムが自動的に作成したページです（例：グループのページ、説明会のページ、説明会ライブラリ内の説明会ごとの個別ページ）。これらのページには**自動生成**のバッジが表示され、データが変わると自動的に更新されます。
- **カスタム** -- 自分で内容とレイアウトを用意して作成したページです。

内容やデザインを完全に管理したい場合は、自動生成されたページをカスタムページに変換できます。自動生成ページの横にある**変換**をクリックし、確認してください。

## ページの追加と編集

1. Webサイトのページ画面の右上にある**ページを追加**ボタンをクリックします。
2. ページの種類（空白またはテンプレート）を選び、名前を付けます。
3. いずれかのページの横にある**コンテンツを編集**をクリックして[ページエディター](./page-editor.md)を開き、セクション、テキスト、画像、その他の要素を追加します。
4. ページの横にある**ページ設定**をクリックして、ページタイトル、URLパス、その他のメタデータを更新します。
5. **パス**列でページのパスをクリックすると、公開中のページが新しいタブで開き、訪問者にどのように表示されるかを正確に確認できます。

:::tip
ホームページには、URLパスとして `/` だけを設定してください。それ以外のページには、`/about` や `/contact` のように内容がわかるパスを使ってください。
:::

### ページ設定

どのページでも**ページ設定**を開くと、次の項目を設定できます。

- **タイトルとURLパス** -- ページの名前と、サイト上のアドレスです。
- **公開範囲** -- ページを閲覧できる対象を、全員、メンバーのみ、スタッフのみ、特定のグループのメンバーから選びます。個別のパスワードを使わずに、スタッフ専用のリソースページなどの非公開ページを簡単に制限できます。
- **メタ説明** -- 検索エンジンの検索結果やSNSのリンクプレビューに表示される短い要約です。
- **リダイレクト** -- 古いURLパスをこのページに転送します。これにより、削除したページへのリンクやブックマークが引き続き機能します。

## ナビゲーションの管理

Webサイトのページ画面の右側にある**メインナビゲーション**パネルには、ナビゲーションのリンクが表示されます。これらのリンクは、訪問者がWebサイトで目にするメニューを制御します。

1. **追加**をクリックして、新しいナビゲーションリンクを作成します。サイト内の任意のページ、または外部URLを指定できます。
2. リンクの順番を変えるには、目的の順番にドラッグ＆ドロップします。また、リンクを親項目の下にネストすると、ドロップダウンメニューを作成できます。
3. リンクをクリックすると**リンク設定**が開きます。そこで、テキスト、URL、親ページを変更できます。
4. リンクをナビゲーションから削除するには、**リンク設定**を開いて**削除**をクリックします。

:::info
ナビゲーションリンクを削除しても、ページ自体は削除されません。ページは引き続き存在し、URLで直接アクセスできます。メニューに表示されなくなるだけです。
:::

## サイト全体のスイッチ

**メインナビゲーション**パネルのリンクの下には、Webサイト全体に適用される2つのスイッチがあります。

- **ログインを表示** -- Webサイトのナビゲーションバーに**ログイン**ボタンを表示します。
- **公開Webサイトを無効にする** -- 公開Webサイトをオフにします。教会がB1をメンバーポータル、献金、登録のためだけに使い、メインのWebサイトは別の場所に置いている場合に使用します。

### 公開Webサイトを無効にすると何が起きるか

**公開Webサイトを無効にする**をオンにすると、次のようになります。

- ホームページやカスタムページを含むすべての公開ページは、サインインしていない訪問者をログイン画面に案内します。サインイン後は、要求したページに戻ります。
- サインイン済みのメンバーには、通常どおりナビゲーションや、グループや説明会などの組み込みの**自動生成**ページを含むWebサイト全体が表示されます。自動生成ページはページの表には表示されなくなります。
- 検索エンジンにはサイトをインデックスしないよう指示されます。サイトマップは空になり、`robots.txt` はすべてのクロールをブロックします。

次のリンクは引き続き使えるため、メンバーとゲストはこれらにアクセスできます。

- ログインとログアウト
- メンバーポータル（`/mobile` 以下のすべて）
- [イベント登録](../guides/event-registration.md)のリンクとゲスト登録

公開Webサイトがオフの間は、スイッチの下に警告が表示されます。ページを再表示するには、スイッチを再度オフにしてください。サイトが無効になっている間も、何も削除されません。

:::info
この設定は教会全体に適用されます。サイトが複数ある場合は、サイト切り替えで選択しているサイトだけでなく、すべてのサイトが無効になります。
:::

## サイトを整理するためのヒント

- 訪問者がすぐに目的のものを見つけられるよう、最上位のナビゲーションは5～6項目に抑えてください。
- 関連する下位ページにはネストしたリンクを使ってください（例：「About」のドロップダウンの中に「私たちのチーム」「信仰告白」「歴史」を入れる）。
- スマートフォンでナビゲーションを確認し、小さい画面でも問題なく動作することを確かめてください。
- ページには、訪問者がどのような内容を見られるかわかりやすい、明確で具体的な名前を付けてください。

:::tip
ページに[フォーム](../forms/creating-forms.md)を追加すると、登録、祈りの課題、その他の情報を訪問者から集めることができます。
:::

## サイトテンプレートから始める

サイトをゼロから作る場合は、1ページずつ作成する代わりに**サイトテンプレート**を使って始めることができます。サイトテンプレートを使うと、ホーム、About、Connect、Give などのあらかじめ用意されたページ一式が、仮のコンテンツとナビゲーションリンクとともに作成されます。

1. ページ画面で、**ページを追加**ボタンの横にある**テンプレートから開始**ボタンをクリックします。
2. 利用可能なテンプレートを確認し、1つをクリックしてページ構成をプレビューします。
3. 気に入ったテンプレートが見つかったら、**テンプレートを適用**をクリックします。
4. まだ存在しないページが作成され、ナビゲーションに追加されます。既存のページはそのまま残ります。

テンプレートを適用したら、各ページを[ページエディター](./page-editor.md)で開き、仮のテキストと画像を教会の実際のコンテンツに置き換えてください。

:::info
サイトテンプレートが作成するのはページの構成とナビゲーションです。サイトの配色やフォントは上書きされません。これらは[外観](./appearance.md)で管理します。
:::

## 画像のライトボックス

訪問者がWebサイト上の画像をクリックすると、画像が全画面のライトボックスで開きます。これにより、ページを離れることなく、写真を大きいサイズで見ることができます。特別な設定は必要ありません。ライトボックスは、ページのコンテンツにある画像に対して自動的に有効になります。
