# ブログ

<div class="article-intro">

ブログページでは、お知らせ、更新情報、デボーション記事を教会のWebサイトに公開できます。投稿は `/blog` の一覧カードとして表示されるほか、それぞれ固有のURLを持ち、Zapierなどの他のツールが新着投稿を監視できるRSSフィードにも掲載されます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- Webサイトの[初期設定](./initial-setup.md)を完了してください
- 訪問者がメニューからブログを見つけられるようにしたい場合は、[ページの管理](./managing-pages.md)から `/blog` へのナビゲーションリンクを追加してください

</div>

## ブログへのアクセス

1. B1 Adminで、画面左上の検索バーである[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)を開き、**Website**を展開します。
2. **Blog**をクリックします。
3. ブログページには、すべての投稿が状態と公開日とともに一覧表示されます。

## 投稿の追加

1. 右上の**Add Post**をクリックします。
2. **Title**(タイトル)を入力します。URLに使える**Web address**(スラッグ)は、入力に合わせて自動的に生成されます。別のアドレスにしたい場合は直接編集できます。
3. **Excerpt**(抜粋)を追加します。これは短い要約で、投稿一覧、メタディスクリプション、RSSフィードに表示されます。空欄のままにすると、投稿本文の冒頭から自動的に生成されます。
4. **Content**エディタでMarkdownを使って投稿本文を書きます。**Preview**をクリックすると、書式を適用した投稿の見た目を確認できます。
5. **Category**(既存のものから選ぶか、新しく入力)を選び、必要に応じてカンマ区切りの**Tags**を入力します。
6. **Select Image**をクリックして[ファイル](./files.md)のギャラリーから写真を選ぶか、新しい写真をアップロードします。アップロードした写真は、16:9の比率に固定された組み込みのトリミングツールで開くので、投稿のヘッダーや一覧カードに合うように写真を切り抜けます。
7. **Author**(著者)を設定します。初期値はあなたですが、データベース内の任意の人物を検索して選択できます。
8. 投稿を公開する準備ができたら、**Published**をオンにし、**Publish Date**(公開日)を設定します。下書きとして保存する場合はオフのままにします。

:::tip
**Publish Date**を未来の日付に設定すると、投稿を予約できます。その日付になるまで訪問者からは非表示になり、ブログの一覧には**Scheduled**のラベルが表示されます。
:::

## 投稿の状態

一覧の各投稿には、次の3つの状態のいずれかが表示されます。

- **Draft**(下書き) -- 未公開です。管理画面からのみ見えます。
- **Scheduled**(予約済み) -- **Published**がオンですが、公開日が未来の日付です。
- **Published**(公開済み) -- Webサイトで公開されており、RSSフィードにも含まれています。

## 投稿の編集、プレビュー、削除

- 投稿の横にある**Edit**をクリックすると、変更できます。
- (公開済みの投稿に表示される)**View on Site**をクリックすると、Webサイト上の公開投稿を新しいタブで開きます。
- **Delete**をクリックすると、投稿を完全に削除します。

## 訪問者からのブログの見え方

公開済みの投稿は `{yoursite}/blog` に表示され、1ページに10件ずつ並びます。**Older**/**Newer**のリンクで過去の投稿をめくることができ、カテゴリフィルターと、各投稿の著者名と写真も表示されます。タグもクリック可能なチップとして表示され、訪問者は同じ方法でタグごとに一覧を絞り込めます。個々の投稿は `{yoursite}/blog/{slug}` にあり、同じカテゴリの関連投稿も表示されます。ブログページではRSSフィードも公開しており、フィードリーダーやZapierのような自動化ツールが自動的に検出できます。

:::info
ブログの投稿は、通常のWebサイトのページとは別のコンテンツタイプです。[ページエディタ](./page-editor.md)では作成されず、ページの一覧にも表示されません。これにより、ブログの作成は素早く、文章を書くことに集中できます。
:::

## 投稿の下にコメントを追加する

B1では、ブログのコメント機能は提供していません。ただし、コメントサービスを追加できます。また、ニュースレターの登録フォームや献金ボタンなど、ほかのものをすべての投稿の下に配置することもできます。

1. [Hyvor Talk](https://talk.hyvor.com)、[FastComments](https://fastcomments.com)、[Disqus](https://disqus.com)などのコメントサービスに登録し、埋め込みコードをコピーします。
2. ブログページで**Below Every Post**までスクロールします。
3. 埋め込みコードを貼り付けて、**Save**をクリックします。

コードは、公開済みのすべての投稿の本文の下に表示されます。モデレーションとスパム対策はコメントサービスが行うため、そのダッシュボードを定期的に確認してください。

:::tip
ボックスを空にして**Save**をクリックすると、すべての投稿からコードが削除されます。このボックスが表示されるのは、教会の設定を編集できる権限を持つ人だけです。
:::
