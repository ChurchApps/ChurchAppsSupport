# 外観

<div class="article-intro">

外観ページでは、教会のウェブサイト全体の見た目や雰囲気をカスタマイズできます。色やフォント、余白、カスタム CSS まで、サイトの視覚的な要素をすべて 1 か所から管理できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- ウェブサイトの[初期設定](initial-setup)を完了しておく
- 背景が透明で縦横比が 4:1 の PNG 形式の教会ロゴを用意しておく
- 既存のスタイルガイドがある場合は、教会のブランドカラー(16 進数の値)を確認しておく

</div>

## 外観設定を開く

1. B1 Admin で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)(左上の検索バー)を開き、**Website** を展開します。
2. **Appearance** をクリックします。
3. **Site Styles** ページが表示されます。**Theme, fonts & footer** カードには、左側に **Style Settings** の一覧、右側にサンプルサイトのプレビューが表示されます。その下には **Announcement & widgets** カードと **Redirects & analytics** カードがあります。

## カラーパレット {#color-palette}

1. スタイル設定パネルで **Color Palette** をクリックします。
2. **Base Colors**(ライト、アクセント、ダークの各色調)と **Semantic Colors**(Primary、Secondary、Success、Warning、Error)が表示されます。
3. 色のスウォッチをクリックすると、カラーピッカーが開きます。セレクターをドラッグするか、16 進数の値を入力して色を選びます。
4. **Color Combinations Preview** で、選んだ色の組み合わせ方を確認できます。
5. **Suggested Palettes** を使うと、あらかじめデザインされた配色をすぐに適用できます。
6. 満足したら **Save Palette** をクリックします。

## タイポグラフィ

1. スタイル設定パネルで **Fonts** をクリックします。
2. **Heading Font** または **Body Font** のボタンをクリックして、フォントブラウザーを開きます。名前で検索したり、Serif、Sans Serif、Display、Handwriting、Monospace などのカテゴリーから選んだりできます。**Popular Font Combinations** から選ぶこともできます。
3. **Save Fonts** をクリックして、フォントの選択を適用します。
4. 見出し 1 から見出し 4 までの文字サイズの階層を調整するには、スタイル設定パネルで **Typography Scale** をクリックします。**Type Scale** の倍率、**Base Size**、**Line Height** の各項目で微調整し、**Save Typography** をクリックします。

## 余白

1. スタイル設定パネルで **Spacing Scale** をクリックします。
2. Extra Small から Extra Large までの余白の値を調整します。各値がレイアウトにどう影響するかは、実例で確認できます。
3. **Save Spacing** をクリックすると、サイト全体に値が適用されます。

## ロゴとブランディング {#logo-and-branding}

1. スタイル設定パネルで **Logo** をクリックします。
2. **Light Background Logo** と **Dark Background Logo** をアップロードします。最適な結果を得るには、背景が透明で縦横比が 4:1 の画像を使用してください。
3. リンクのプレビュー用に **Social Media Image** を、ブラウザータブのアイコン用に **Favicon** をアップロードします。
4. **Save Changes** をクリックします。画像は保存するまで反映されないため、保存前にブラウザータブを閉じたり再読み込みしたりしようとすると、未保存の変更があることを知らせる警告が表示されます。

:::tip
最適な結果を得るには、背景が透明の PNG 形式のロゴを使用してください。こうすると、ウェブサイトと[モバイルアプリ](../settings/mobile-app.md)の明るい背景と暗い背景の両方で、きれいに表示されます。
:::

## ナビゲーションのスタイル

ナビゲーションバーの色を、通常表示と透過表示の両方でカスタマイズできます。

1. スタイル設定パネルで **Navigation** をクリックします
2. **Header (solid)** と **Header over hero (transparent)** の色を設定します
3. **Save Navigation** をクリックして、ナビゲーションの色を適用します

詳しい手順については、[ナビゲーションのスタイル](./navigation-styles.md)を参照してください。

## お知らせとウィジェット

サイトのウィジェットは、サイトのすべてのページに、ページの内容の上に浮かぶ形で表示されます。

- **Announcement Banner** -- サイトの上部に表示される、閉じられるバーです。近日開催のイベントや礼拝の変更など、時間に関わるお知らせに使います。
- **Launcher** -- 押すとクイックアクセスメニューが開く浮きボタンです。たとえば、献金、チェックイン、週報へのリンクを置けます。

1. スタイル設定の下にある **Announcement & widgets** カードを探します。
2. 表示したいウィジェットをオンにし、テキスト、リンク、色を設定します。
3. **Save** をクリックします。

## リダイレクトと分析

スタイル設定の下にある **Redirects & analytics** カードには、互いに関係のない、ただどちらもよく必要になる 2 つの設定があります。

- **Analytics** -- **GA4 Measurement ID**(形式は `G-XXXXXXXXXX`)を追加すると、ウェブサイトの訪問者の動きを追跡できます。同じ ID で、教会の B1 アプリ(`/mobile` にあるメンバーポータル。インストール済みのアプリを含みます)のページビューも記録されます。その際、`display_mode` として `installed` または `browser` が付与されるので、Google アナリティクスで、インストール済みアプリからの訪問とブラウザーからの訪問を区別できます。
- **Redirects** -- 古い URL のパスを新しいパスに対応づけます。移動または名前を変更したページへのリンクが 404 エラーになる代わりに、正しく機能し続けます。古い **From** のパスと新しい **To** のパスを入力し、**Save** をクリックします。リダイレクトは、B1 に組み込まれたページ(`/sermons`、`/stream`、`/donate`、`/bible`、`/votd`)よりも優先されるため、そのアドレスを別の場所に転送できます(たとえば、教会独自の説教ページや YouTube チャンネルなど)。同じアドレスに自分で作成したページがある場合は、リダイレクトより自作ページが優先されます。リダイレクトを適用したい場合は、先にそのページを削除してください。

## カスタム CSS と JavaScript

1. スタイル設定パネルで **CSS & Javascript** をクリックします。
2. 既定のスタイルを上書きする高度なカスタマイズには **Custom CSS** を追加します。
3. トラッキングコードやその他のスクリプトには **Custom HTML** を追加します。
4. Google アナリティクスの連携など、サンプルのコードは **Common JavaScript Examples** セクションを参照してください。

:::warning
カスタム CSS は強力ですが、使い方を誤ると、サイトのレイアウトが崩れることがあります。ほとんどの教会は、組み込みの色、フォント、余白の設定だけで望みの見た目を実現できます。カスタム CSS は、ウェブ開発に慣れている場合にのみ使用してください。
:::

:::info
お使いのサイトには、他のソースからのインラインスクリプトをブロックするコンテンツセキュリティポリシーが適用されています。ここにある **Custom HTML** 欄と、個々のページにある [HTML 要素](page-editor#using-the-html-element)は例外として許可されています。ここに保存したコードはそのまま実行されるため、信頼できるソース(アナリティクスのタグ、チャットウィジェットなど、同様の埋め込みコード)からのスクリプトだけを貼り付けてください。
:::

## スタイルテーマ

手早く始めたい場合は、カラーパレットのセクションにある **Suggested Palettes** を使ってください。ワンクリックで、色の組み合わせが統一された、あらかじめ用意されたテーマを設定できます。テーマを適用した後でも、個々の設定は自由に微調整できます。
