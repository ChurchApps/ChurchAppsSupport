# 初期設定

<div class="article-intro">

すべての B1 アカウントには、すぐに使えるウェブサイトが付いています。このガイドでは、教会のドメインの設定、サイトの外観の調整、最初のページの作成、ナビゲーションの整理までの手順を説明します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 管理者権限を持つ B1.church アカウントが必要です
- 独自ドメインを使用する場合は、DNS プロバイダー（GoDaddy、Cloudflare、AWS など）のログイン情報を用意してください
- 最良の結果を得るため、背景が透明な PNG 形式の教会ロゴを用意してください

</div>

## ドメインの設定

教会には、B1.church 上のサブドメインが自動的に割り当てられます（例：`yourchurch.b1.church`）。独自のカスタムドメインを B1 サイトに向けることもできます。

1. admin.b1.church にアクセスするか、プロフィールのドロップダウンをクリックして **アプリを切り替え** を選び、**B1.church Admin** に移動します。
2. [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**設定** を展開して、**設定** をクリックします。
3. **教会情報** セクションを開いて、サブドメインを確認します。スペースを含まない、短くてわかりやすい名前に設定してください。
4. カスタムドメインを使用するには、DNS プロバイダー（GoDaddy、Cloudflare、AWS など）にログインし、2 つのレコードを追加します。
   - ルートドメインを `3.23.251.61` に向ける **A レコード**
   - `www` を `proxy.b1.church` に向ける **CNAME レコード**
5. B1.church Admin に戻り、同じ設定ページの **ドメイン** セクションを開いて、カスタムドメインをリストに追加し、**追加**、**保存** の順にクリックします。数分以内に、カスタムドメインからサイトにアクセスできるようになります。

:::tip
「設定」メニューが表示されない場合は、教会アカウントを設定した担当者に「教会設定の編集」権限を付与してもらってください。詳しくは[役割と権限](../settings/roles-permissions.md)をご覧ください。
:::

## 最初のページの作成

1. B1 Admin で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**ウェブサイト** を展開して、**ページ** をクリックします。
2. 右上隅の **ページを追加** をクリックします。
3. ページの種類として **空白** を選び、「Home」と名前を付けます。
4. **ページ設定** をクリックし、ホームページの URL パスを `/`（テキストなしのスラッシュ 1 文字）に設定します。その他のページは `/page-name` の形式にします。
5. **コンテンツを編集** をクリックして作成を始めます。すべてのページは **セクション** から始める必要があります。セクションは、他のすべての要素を入れる器の役割を果たします。
6. セクションを追加したら、再度 **コンテンツを追加** をクリックして、テキスト、画像、動画、カード、フォームなどを、セクション内にドラッグして挿入します。

:::info
ページやナビゲーションの詳しい操作方法については、[ページの管理](./managing-pages.md)をご覧ください。ビジュアルエディターの詳しいガイドについては、[ページエディターの使い方](./page-editor.md)をご覧ください。
:::

## サイトの外観の設定

1. ジャンプメニューで **ウェブサイト > 外観** を選びます。
2. **カラーパレット** を使って、プライマリ、セカンダリ、アクセントの各色をブランドカラーに設定します。
3. **フォント** で、フォントブラウザから見出し用と本文用のフォントを選びます。
4. スタイル設定の **ロゴ** に教会のロゴをアップロードします。明るい背景用と暗い背景用の両方のバージョンを用意してください。
5. **サイトフッター** に、教会の連絡先情報とリンクを設定します。

:::info
外観で行った変更は、ウェブサイト全体に反映されます。各設定の詳しい手順については、[外観](./appearance.md)のページをご覧ください。
:::

## ナビゲーションの設定

ナビゲーションのリンクは、ウェブサイトのページ画面に表示されます。リンクを整理するには、次の手順に従ってください。

1. **追加** をクリックして新しいナビゲーションリンクを作成し、いずれかのページにリンクさせます。
2. リンクをドラッグ＆ドロップして、並び替えたり、親項目の下にネストしたりします。
3. サイトをプレビューして、ナビゲーションが正しく表示されているか確認します。
