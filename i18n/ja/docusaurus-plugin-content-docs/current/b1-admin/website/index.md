# ウェブサイト

<div class="article-intro">

B1 Admin のウェブサイトセクションでは、教会のための本格的なウェブサイトビルダーをご利用いただけます。ページの作成、サイトの見た目のカスタマイズ、メディアファイルの管理、イベントカレンダーの公開を、コードを一切書かずに行えます。

</div>

## できること

ウェブサイトビルダーは、次の主要な領域で構成されています。

### ページ

教会のウェブサイトにあるすべてのページを作成・管理できます。**ページ**の表には各ページが一覧表示されます。システムが自動的に作成したページには **Generated** バッジが付き、それ以外はお好みで作成したカスタムページです。新しいカスタムページを追加したり、既存のページを編集したり、自動生成されたページをカスタムページに変換して内容を完全に管理したりできます。

ナビゲーションリンクは階層構造(ツリー)で表示されます。ドラッグ&ドロップでリンクの順序を変更し、訪問者に見せたい階層と順番を正確に設定できます。

### ブログ

ニュース、お知らせ、デボーションをブログ記事として公開できます。記事はサイトの `/blog` に掲載され、RSS フィードも利用できます。詳しくは [ブログ](blog) のガイドをご覧ください。

### ブロック

複数のページに配置できる再利用可能なコンテンツコンポーネントを作成できます。行動喚起、お知らせバナー、連絡先セクションなど、複数の場所に表示されるコンテンツがある場合に便利です。ブロックを一度更新すれば、それを使用しているすべての場所に変更が反映されます。

### 外観

ウェブサイトのテーマ、色、フォント、ロゴ、余白をカスタマイズできます。あらかじめ用意されたスタイルテーマをすぐに適用することも、カラーパレットエディター、文字組みの設定、カスタム CSS を使ってすべての細部を調整することもできます。詳細は [外観](appearance) のガイドをご覧ください。

### ファイル

画像、ドキュメント、その他のファイルなどのメディア資産をすべて一か所にアップロードして管理し、サイト内のどこでも使えるようにファイルのリンクをコピーできます。詳しくは [ファイル](files) をご覧ください。

### カレンダー

ウェブサイトにイベントカレンダーを公開し、教会で行われている活動を訪問者が確認できるようにします。複数のグループのイベントを1つの画面にまとめた、厳選されたカレンダーを作成できます。カレンダーは B1 Admin のメニューに **カレンダー** として独立した項目があり、**ウェブサイト** とは別になっています。

:::tip
ウェブサイトを初めて設定する場合は、[初期設定](initial-setup) から始めてください。ドメインの設定、最初のページの作成、サイトの外観の設定について順を追って説明しています。
:::
