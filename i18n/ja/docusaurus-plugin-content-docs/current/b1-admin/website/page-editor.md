# ページエディターの使い方

<div class="article-intro">

B1のページエディターは、コードを書かずに教会のWebサイトのページをデザインできる、ビジュアルなドラッグ&ドロップ型のビルダーです。セクションやコンテンツブロックを追加し、スタイルをカスタマイズし、作業内容をプレビューして、変更を元に戻すことができます。すべてブラウザ内で行えます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [初期設定](./initial-setup.md)を完了し、Webサイトの設定を済ませてください
- [ページの管理](./managing-pages.md)で、少なくとも1つのページを作成してください
- エディターを使うには、**content.edit**権限が必要です

## エディターを開く

1. B1 Adminで、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**Website**を展開して、**Pages**をクリックします。
2. ページ一覧から編集したいページを見つけ、**Edit Content**をクリックします。

エディターは全画面表示で開きます。左パネルにはページの構成と利用可能なコンテンツ要素が表示され、中央エリアにはページのライブプレビューが表示されます。

:::info
エディターは、B1 Adminのテーマ設定にかかわらず常にライトモードで表示されます。また、[外観](./appearance.md)で選んだ見出しフォントと本文フォントを使用します。これにより、プレビューがWebサイトの訪問者に表示される見た目と正確に一致します。
:::

## ページの構造：セクションと要素

すべてのページは、次の2つのレベルで構成されます。

- **セクション** -- ページを水平の帯に分割する最上位のコンテナです（例：ヒーローセクション、コンテンツブロック、フッターの帯）。コンテンツを追加する前に、ページには少なくとも1つのセクションが必要です。
- **要素** -- セクション内に配置される個々のコンテンツ部品です（テキスト、画像、ボタン、カード、フォーム、カレンダーなど）。

### セクションを追加する

1. **Add Section**（または左パネル上部の**+**ボタン）をクリックします。
2. 開始方法を選びます。
   - **テンプレートから** -- カテゴリ（Hero、About、Services、Givingなど）ごとに整理されたセクションテンプレートのギャラリーを閲覧し、1つをクリックすると、スタイルと内容が設定済みのセクションとして挿入されます。追加後に、すべてを自由に変更できます。
   - **空のセクション** -- 列レイアウト（1列、2列、3列など）を選んで、ゼロから作成します。
3. 新しいセクションがプレビューに表示されます。クリックして選択すると、背景色、余白などのスタイルオプションを設定できます。

### セクションのレイアウトを切り替える

すでにセクションを作成したけれど、別の構成にしたい場合は、そのセクションのレイアウト切り替え機能を使います。ギャラリーから別の列構成を選ぶと、既存のコンテンツと要素はそのまま保持されます。

### セクションに要素を追加する

1. プレビュー内のセクションをクリックして選択します。
2. **Add Content**をクリックし、一覧から要素の種類を選びます。
   - **テキスト** -- 見出し、段落、リッチテキスト
   - **画像** -- 写真をアップロードするか、写真へのリンクを設定します
   - **ボタン** -- クリック可能なコールトゥアクションのリンク
   - **カード** -- 画像、タイトル、説明文を含むカード
   - **フォーム** -- [フォーム](../forms/creating-forms.md)をページに直接埋め込みます。フォームに[ヘッダー画像](../forms/creating-forms.md#adding-a-header-photo)がある場合は、質問の上に表示されます
   - **カレンダー** -- イベントカレンダーを表示します
   - **FAQ** -- アコーディオン形式の質問と回答のブロック
   - **動画** -- URLを指定して動画を埋め込みます
   - **グループブラウザー** -- 教会のすべてのグループを一覧できるディレクトリです。検索、カテゴリフィルター、ラベルフィルターを任意で使えます。**レイアウト**は**グリッド**（既定）または**スクロール（自動）**から選べます。[スクロールレイアウト](#scrolling-layouts)を参照してください
   - **グループリスト** -- 公開グループのタイルを表示します。特定のラベルが付いたグループだけに絞ることもできます。**レイアウト**は**グリッド**（既定。1行に最大3つのタイル）または**スクロール（自動）**から選べます。[スクロールレイアウト](#scrolling-layouts)を参照してください
   - **アイコン機能** -- 機能や奉仕活動の紹介に使える、アイコン、タイトル、短い説明文
   - **ギャラリー** -- 複数の写真をグリッドまたは組積状のレイアウトで表示します
   - **証言** -- 1つ以上の引用文と、著者名、役割、写真
   - **ソーシャルアイコン** -- 教会のソーシャルメディアのプロフィールへのリンク付きアイコンです。Facebook、Instagram、WhatsApp、YouTube、X、TikTok、Vimeo、Podcastに対応しています。表示したいものごとにリンクを入力してください。**WhatsApp**の場合は、電話番号を含む`https://wa.me/`のリンクか、グループの招待リンクを使用します
   - **カウントダウン** -- 日付または毎週の礼拝時間までの残り時間を表示するタイマーです
   - **統計** -- ラベル付きの大きな数字を並べて表示します（会員数、年数、キャンパス数など）
   - **献金キャンペーンの進捗** -- 献金キャンペーンのライブ進捗バーで、基金の目標額に対して集まった合計額を表示します
   - **スタッフグリッド** -- グループのメンバーの写真カードです。グループの**公開名簿**オプションをオンにしておく必要があります
   - **礼拝時間** -- キャンパスの礼拝スケジュールを、出席設定から自動的に取り込みます
   - **説教** -- 説教ライブラリを、全体のブラウザー、またはグリッド、リスト、注目の最新回のレイアウトで表示します
   - **地図** -- 教会の住所を中心に表示する埋め込み地図です
   - **表** -- 表形式のコンテンツ用の、行と列からなるシンプルなグリッドです
   - **写真付きテキスト** -- テキストと画像を横に並べて表示します
   - **ロゴ** -- [外観](./appearance.md)から取り込んだ教会のロゴです
   - **ライブ配信** -- ライブ配信のプレーヤーをページに直接埋め込みます
   - **ポッドキャスト** -- 指定した外部のポッドキャストRSSフィードのURLから取得したエピソード一覧です。表示するエピソード数や、日付と説明文を表示するかどうかを設定できます。公開サイトの各エピソードには音声プレーヤーと**Download**リンクがあり、エピソードのタイトル名で音声ファイルを保存できます。これは任意のポッドキャストフィードをサイトに掲載するための機能です。自分の説教をポッドキャストとして公開する場合は、代わりに[説教の管理](../sermons/managing-sermons.md#your-podcast-feed)を参照してください
   - **寄付** -- 献金ボタンまたは埋め込みの寄付フォームです
   - **HTML** -- 独自の生のHTMLです。サードパーティ製ウィジェットの埋め込みなど、高度な用途向けです（[HTML要素の使い方](#using-the-html-element)を参照してください）
   - **iFrame** -- URLを指定して外部コンテンツを埋め込みます
3. 表示される設定パネルで要素を構成します。

### HTML要素の使い方

**HTML**要素には2つの入力欄があります。

- **HTML Content** -- ページに表示するマークアップです。ここに含めた`<script>`タグは、公開サイト上で実行されます。
- **JavaScript（scriptタグを除く）** -- ページの読み込み時に実行されるスクリプトのコードです。ベンダーの埋め込みスニペットを、`<script>`タグを含めたままここに貼り付けることもでき、その場合も公開サイト上で実行されます。

JavaScriptの入力欄に、Webアドレスだけ（画像のリンクなど）を貼り付けると、入力欄が赤く変わり、*「これはJavaScriptではなく、Webアドレスです。」*という警告が表示されます。この欄にアドレスだけを入力しても何も起こりません。画像を表示するには、**画像**要素を使うか、**HTML Content**に`<img src="...">`を記入してください。

### カレンダー要素の使い方 {#using-the-calendar-element}

**カレンダー**要素は、作成済みのカレンダーのいずれかのイベントを表示します。

1. **Select**で、**Group Calendar**（1つのグループのイベント。一覧には自分が所属するグループが表示されます）または**Curated Calendar**（**Calendars**で作成したカレンダー。[キュレーションカレンダー](../calendars/curated-calendar.md)を参照）を選びます。
2. **Select Calendar**で、グループまたはカレンダーを選びます。
3. **Display**で、表示方法を選びます。
   - **月間カレンダー** -- 訪問者がページをめくって見られる月単位のグリッドです。各イベントは所属するグループの色で表示されるため、グループのイベントはどのカレンダーでも同じ色になります。色はBで自動的に割り当てられるため、設定は不要です。
   - **今後のイベント** -- 次の12件のイベントをタイルのグリッドで表示します。繰り返しのイベントは、次回の日付で1回だけ表示されます。各タイルには、イベントの写真（写真がない場合はテーマの濃い色を背景にしたタイトル）、日付のバッジ、曜日と時刻、説明文の最初の行が表示されます。タイルの上の**Subscribe**ボタンから、訪問者はカレンダーのICSリンクをコピーするかダウンロードできます。この表示では**レイアウト**設定が表示され、**グリッド**（既定）または**スクロール（自動）**を選べます。後者では、タイルが1行に並び、自動的に横へスクロールします（[スクロールレイアウト](#scrolling-layouts)を参照）。**キュレーションカレンダー**の場合は、**グループバッジ**設定をオンにすると、各イベントのタイルの右上に、そのグループのカレンダーの色でグループ名が表示されます。アーカイブされたグループや非公開のグループのイベントにはバッジは付きません。
4. 一部のイベントだけを表示するには、**Only events tagged**にタグを入力します（例：`youth`）。**Tags**にその語を含むイベントだけが表示されます。空欄のままにすると、すべてのイベントが表示されます。タグは各イベントに設定します。[イベントの追加と編集](../calendars/creating-calendars.md#adding-and-editing-events)を参照してください。

どちらの表示でも、イベントをクリックすると、Webサイト上のそのイベント専用のページが開きます。イベントページには、イベントの写真、タイトル、日時、説明文のほか、**When**（繰り返しイベントの場合は繰り返しのパターンを含む）と**Where**（そのイベントに予約された部屋）を示すボックスが表示されます。登録が有効な場合は**Register for this Event**ボタンも表示され、**Add to my calendar**リンクからは、イベントをカレンダーファイルとしてダウンロードできます。検索エンジンが検索結果にイベントの日付や詳細を表示できるように、ページは設定されています。ページに表示されるキュレーションカレンダーのイベントページ（今後6か月以内のイベント）は、サイトマップにも掲載されるため、検索エンジンに見つけてもらいやすくなります。

### スクロールレイアウト {#scrolling-layouts}

**グループブラウザー**、**グループリスト**、およびカレンダー要素の**今後のイベント**表示にある**スクロール（自動）**レイアウトは、タイルをグリッドではなく1行に並べます。スマートフォンでは各タイルが行の幅いっぱいに表示され、パソコンでは2つのタイルが横に並びます。収まりきらないタイルがある場合、この行は次のように動作します。

- 約4秒ごとに1つ先のタイルへ進み、最後のタイルの後は最初のタイルに戻って繰り返します。
- 訪問者がタイルにマウスを合わせる、タッチする、またはタブでフォーカスすると一時停止し、数秒後に再開します。
- 下にドットの列が表示されます。タイルごとに1つのドットがあり、現在のタイルのドットは塗りつぶされます。訪問者はドットをクリックして、そのタイルに移動できます。

動きを減らす設定の端末では、行は静止したままで、訪問者が自分でスワイプまたはスクロールして移動します。すべてのタイルが収まる場合は、行は動かず、ドットも表示されません。

### コンテンツの並べ替え

各項目の左側にある取っ手アイコン（6つの点）をドラッグして、セクションや要素の順序を変更できます。要素はセクション内でドラッグして並べ替えたり、別のセクションに移動したりできます。

## ページのスタイル設定

### セクションのスタイル

セクションをクリックすると、スタイルパネルが開きます。次の項目を設定できます。

- **背景** -- 単色、グラデーション、または画像です。画像背景を使う場合、**Focal Point**のピッカーで、セクションの拡大縮小時に中央に残す画像の部分をクリックして指定できます。**Overlay**の色オプションでは、画像に半透明の色味を重ねて、文字の読みやすさを高めることができます。
- **余白** -- セクション内の上下の間隔
- **幅** -- 全幅、または中央寄せ・幅を制限したもの
- **区切り線** -- セクションの上端または下端に表示する装飾的な形状の区切り（波、斜め、曲線、三角形など）です。色、高さ、反転の設定が可能です

### 要素のスタイル

要素をクリックすると、スタイルパネルが開きます。よく使う設定には、フォントサイズ、色、配置、マージン、余白があります。画像の場合は、代替テキストとリンク先を設定できます。

### カスタムCSS

高度なスタイル設定のために、各セクションと各要素には**Custom CSS**欄があり、独自のCSSルールを記述できます。これらのルールはその要素にだけ適用されるため、ページの他の部分に意図せず影響することはありません。

:::tip
カスタムフォントや全体の色など、サイト全体に適用するスタイルが必要な場合は、個々のページでカスタムCSSを使うのではなく、[外観](./appearance.md)の設定を使ってください。
:::

## ページのプレビュー

ツールバーのプレビュー操作を使うと、さまざまな画面サイズでページの見た目を確認できます。

- **デスクトップ** -- 全幅のブラウザー表示
- **モバイル** -- スマートフォンサイズの狭い表示

スマートフォンでは、行内の列は、行の設定で**Mobile Width**を指定しない限り、全幅で上下に積み重なって表示されます。説教とポッドキャストの一覧では、スマートフォンで各エピソードのテキストがサムネイルの下に積み重なって表示されます。

訪問者と同じ表示でライブページを確認するには、ページ一覧に戻り、ページのパスをクリックします。新しいブラウザータブで開きます。

## アクセシビリティのチェック

ツールバーの**Accessibility**アイコンをクリックすると、画像の代替テキストの欠落、色のコントラスト不足、見出しの順序の乱れなど、よくある問題をすばやくチェックできます。各問題は、修正が必要な要素に直接リンクしているため、その場で修正できます。

## 変更を元に戻す

エディターは編集履歴を自動的に記録します。ツールバーのボタンまたはキーボードショートカットを使って操作できます。

- **Undo**（Ctrl+Z / Cmd+Z） -- 直前の操作を取り消します
- **Redo**（Ctrl+Shift+Z、またはCtrl+Y / Cmd+Shift+Z） -- 取り消した操作をやり直します

ページを以前のスナップショットに戻すこともできます。ツールバーの**View history**をクリックすると、説明付きの保存済みスナップショットの一覧が表示されます。任意の項目をクリックすると、その時点に戻ります。

:::warning
スナップショットを復元すると、現在のページのコンテンツがスナップショットの内容に置き換えられます。これは標準の元に戻すボタンでは取り消せません。以前の状態に戻せるようにしておきたい場合は、古いスナップショットを復元する前に、現在の状態のスナップショットを保存してください。
:::

## 保存と公開

変更は作業中に自動的に保存されます。ツールバーのステータス表示で、変更が保存されたかどうかを確認できます。

### 下書きと公開状態

ページには**公開済み**の状態があり、訪問者がいつ変更内容を見られるかを制御します。ツールバーには、現在の状態を示すステータスチップが表示されます。

- **保存時に公開** -- ページは公開のワークフローを使用しません。保存したすべての変更は、すぐに公開されます。これは新しいページの既定の設定です。
- **未公開の変更あり** -- ページは以前に公開されたことがありますが、最後に公開してから変更を加えています。訪問者には、以前に公開されたバージョンがまだ表示されています。
- **公開済み** -- ページは公開されており、保存した内容は訪問者に表示されている内容と一致しています。

変更を公開するには、ツールバーの**Publish**ボタンをクリックします。ページはすぐに公開されます。

訪問者に表示される内容に影響を与えずに、最後に公開したバージョンに戻すには、その他メニュー（⋮）を開き、**Discard unpublished changes**をクリックします。

公開のワークフローの使用をやめるには、その他メニューを開き、**Turn off publishing**をクリックします。以後、編集内容はすぐに公開されるようになります。

:::tip
下書きと公開のワークフローは、ページを準備しておき、適切なタイミングで公開したい場合に使ってください（例：今後のイベント用のページ）。ページを作成してプレビューし、準備ができたら**Publish**をクリックします。
:::
