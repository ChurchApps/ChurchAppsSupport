# ページエディターの使い方

<div class="article-intro">

B1 のページエディターは、コードを書かずにチャーチのウェブサイトのページをデザインできる、ドラッグ&ドロップ式のビジュアルビルダーです。セクションやコンテンツブロックを追加したり、スタイルをカスタマイズしたり、プレビューを確認したり、変更を元に戻したりできます。すべてブラウザ内で操作できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [初期設定](initial-setup)を完了し、ウェブサイトの設定を済ませてください
- [ページの管理](managing-pages)で、少なくとも 1 つのページを作成してください
- エディターを使うには **content.edit** 権限が必要です

</div>

## エディターを開く

1. B1 Admin で、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**Website** を展開して **Pages** をクリックします。
2. ページの一覧から編集したいページを見つけ、**Edit Content** をクリックします。

エディターは全画面で開きます。左側のパネルにはページの構造と利用可能なコンテンツ要素が表示され、中央のエリアにはページのライブプレビューが表示されます。

:::info
エディターは、B1 Admin のテーマ設定に関係なく常にライトモードで表示されます。また、[外観](appearance)で選んだ見出しフォントと本文フォントを使用します。これにより、プレビューがウェブサイトの訪問者に実際に表示される見た目と一致します。
:::

## ページの構造：セクションと要素

すべてのページは 2 つのレベルで構成されます。

- **セクション** -- ページを水平の帯に分ける最上位のコンテナです（例：ヒーローセクション、コンテンツブロック、フッターの帯など）。コンテンツを追加する前に、すべてのページに少なくとも 1 つのセクションが必要です。
- **要素** -- セクション内に配置される個々のコンテンツで、テキスト、画像、ボタン、カード、フォーム、カレンダーなどがあります。

### セクションを追加する

1. プレビュー上部の **Add Section**（または左パネル上部の **+** ボタン）をクリックします。
2. 開始方法を選びます。
   - **テンプレートから** -- カテゴリ（Hero、About、Services、Giving など）ごとに整理されたセクションテンプレートのギャラリーを参照し、1 つをクリックすると、スタイルが設定済みで内容が入ったセクションとして挿入されます。追加後に何でもカスタマイズできます。
   - **空のセクション** -- 列のレイアウト（1 列、2 列、3 列など）を選び、ゼロから作成します。
3. 新しいセクションがプレビューに表示されます。クリックして選択すると、背景色、余白、その他のスタイルオプションを設定できます。

### セクションのレイアウトを切り替える

すでにセクションを作成したものの、別の構成にしたい場合があるかもしれません。そのセクションのレイアウト切り替えツールを使うと、既存のコンテンツと要素をそのまま残したまま、ギャラリーから別の列構成に入れ替えられます。

### セクションに要素を追加する

1. プレビュー内のセクションの中をクリックして、そのセクションを選択します。
2. **Add Content** をクリックし、一覧から要素の種類を選びます。
   - **Text** -- 見出し、段落、リッチテキスト
   - **Image** -- 写真をアップロードするか、写真へのリンクを設定します
   - **Button** -- クリックできる行動喚起のリンク
   - **Card** -- 画像、タイトル、説明文
   - **Form** -- ページに[フォーム](../forms/creating-forms)を直接埋め込みます。フォームに[ヘッダー写真](../forms/creating-forms.md#adding-a-header-photo)がある場合は、質問の上に表示されます
   - **Calendar** -- イベントカレンダーを表示します
   - **FAQ** -- アコーディオン形式の質問と回答のブロック
   - **Video** -- URL で動画を埋め込みます
   - **Groups Browser** -- すべてのチャーチのグループを一覧できるディレクトリです。検索、カテゴリフィルター、ラベルフィルターを任意で使えます
   - **Icon Feature** -- アイコン、タイトル、短い説明文を組み合わせたもので、特徴や活動の紹介に使います
   - **Gallery** -- 複数の写真をグリッドまたはマソナリー形式で表示します
   - **Testimonial** -- 1 つ以上の推薦文を、著者の名前、役割、写真とともに表示します
   - **Social Icons** -- チャーチのソーシャルメディアのプロフィールへのリンク付きアイコンです。Facebook、Instagram、WhatsApp、YouTube、X、TikTok、Vimeo、Podcast に対応しています。表示したいものごとにリンクを入力してください。**WhatsApp** の場合は、電話番号を含む `https://wa.me/` のリンクか、グループの招待リンクを使用します
   - **Countdown** -- 日付や毎週の礼拝時間まで残り時間を表示するタイマーです
   - **Stats** -- ラベル付きの大きな数字を横に並べて表示します（会員数、創立年数、拠点数など）
   - **Campaign Progress** -- 献金キャンペーンのライブ進捗バーで、資金目標に対して集まった合計額を表示します
   - **Staff Grid** -- グループのメンバーの写真付きカードです。グループの **public roster**（公開名簿）オプションをオンにしておく必要があります
   - **Service Times** -- 拠点ごとの礼拝スケジュールです。出席の設定から自動的に取得されます
   - **Sermons** -- 説教ライブラリです。フルのブラウザ表示、またはグリッド、リスト、注目の最新回のレイアウトで表示できます
   - **Map** -- チャーチの住所を中心に表示する埋め込み地図です
   - **Table** -- 表形式のデータを行と列のシンプルなグリッドで表示します
   - **Text with Photo** -- テキストと画像を横に並べて表示します
   - **Logo** -- [外観](appearance)から取得されるチャーチのロゴです
   - **Live Stream** -- ライブ配信のプレーヤーをページに直接埋め込みます
   - **Podcast** -- お使いの外部ポッドキャストの RSS フィード URL から取得したエピソードの一覧です。表示するエピソード数や、日付と説明文を表示するかどうかを設定できます。公開サイトでは、各エピソードに音声プレーヤーと、エピソードのタイトルで音声ファイルを保存する **Download** リンクが表示されます。これは任意のポッドキャストフィードをサイトで紹介するためのものです。ご自身の説教をポッドキャストとして公開する場合は、代わりに[説教の管理](../sermons/managing-sermons.md#your-podcast-feed)を参照してください
   - **Donation** -- 献金ボタンまたは埋め込み型の献金フォーム
   - **HTML** -- 独自の生の HTML です。サードパーティのウィジェットを埋め込むなど、高度な用途に使います（[HTML 要素の使い方](#using-the-html-element)を参照）
   - **iFrame** -- URL で外部コンテンツを埋め込みます
3. 表示される設定パネルを使って、要素を設定します。

### HTML 要素の使い方

**HTML** 要素には 2 つの入力欄があります。

- **HTML Content** -- ページに表示するマークアップです。ここに含めた `<script>` タグは、公開サイトで実行されます。
- **JavaScript（script タグを除く）** -- ページの読み込み時に実行されるスクリプトのコードです。ベンダーが提供する埋め込みスニペットを、`<script>` タグを含めたままここに貼り付けることもでき、その場合も公開サイトで実行されます。

JavaScript の入力欄に Web アドレスだけ（画像のリンクなど）を貼り付けると、入力欄が赤くなり、*「これは JavaScript ではなく、Web アドレスです。」* という警告が表示されます。この欄にアドレスだけを入力しても何も起こりません。画像を表示するには、**Image** 要素を使うか、**HTML Content** に `<img src="...">` を記述してください。

### カレンダー要素の使い方 {#using-the-calendar-element}

**Calendar** 要素は、お持ちのカレンダーのいずれかのイベントを表示します。

1. **Select** で **Group Calendar**（1 つのグループのイベント。一覧には所属しているグループが表示されます）または **Curated Calendar**（**Calendars** で作成したカレンダー。[キュレーションカレンダー](../calendars/curated-calendar)を参照）を選びます。
2. **Select Calendar** で、グループまたはカレンダーを選びます。
3. **Display** で、表示方法を選びます。
   - **Month calendar** -- 訪問者がページをめくって見られる月単位のグリッドです。
   - **Upcoming events** -- 次の 12 件のイベントをタイルのグリッドで表示します。繰り返しイベントは次回の日付に 1 回だけ表示されます。各タイルには、イベントの写真（写真がない場合はテーマの濃い色にタイトルを表示）、日付バッジ、曜日と時刻、説明文の 1 行目が表示されます。タイルの上にある **Subscribe** ボタンを使うと、訪問者はカレンダーの ICS リンクをコピーしたり、ダウンロードしたりできます。この表示方法では **Layout** の設定が表示されます。**Grid**（既定）または **Scrolling (automatic)** を選べます。後者はタイルを 1 列に並べ、自動的に横へスクロールさせます。
4. 一部のイベントだけを表示するには、**Only events tagged** に単語を入力します（例：`youth`）。**Tags** にその単語を含むイベントだけが表示されます。空欄のままにすると、すべてのイベントが表示されます。タグは各イベントに設定します。[イベントの追加と編集](../calendars/creating-calendars.md#adding-and-editing-events)を参照してください。

どちらの表示方法でも、イベントをクリックすると、ウェブサイト上のそのイベント専用のページが開きます。イベントページには、イベントの写真、タイトル、日時、説明文のほか、**When**（繰り返しイベントの場合は繰り返しのパターンを含む）と **Where**（そのイベントのために予約された部屋）を示すボックスが表示されます。登録が有効になっている場合は **Register for this Event** ボタン、カレンダーファイルとしてダウンロードできる **Add to my calendar** リンクも表示されます。検索エンジンが検索結果にイベントの日付や詳細を表示できるように設定されています。ページに表示されるキュレーションカレンダーのイベントページ（今後 6 か月以内のイベント）は、サイトマップにも掲載されるため、検索エンジンで見つけてもらえます。

### コンテンツの並べ替え

各項目の左側にある取っ手アイコン（6 つの点）をドラッグして、セクションや要素の順番を変えられます。要素はセクション内で移動することも、別のセクションに移動することもできます。

## ページのスタイルを設定する

### セクションのスタイル

セクションをクリックすると、そのスタイルパネルが開きます。次の項目を設定できます。

- **Background** -- 単色、グラデーション、または画像。画像を背景にする場合は、**Focal Point** のピッカーでクリックして、セクションの拡大縮小時に中央に残す画像の部分を指定できます。**Overlay** の色オプションを使うと、画像の上に半透明の色を重ねて、文字を読みやすくできます。
- **Padding** -- セクション内の上下の余白
- **Width** -- 全幅、または中央寄せ・幅を制限した表示
- **Dividers** -- セクションの上端または下端に付ける装飾的な形状の区切り（波、斜め、曲線、三角形など）。色、高さ、反転のオプションを設定できます

### 要素のスタイル

要素をクリックすると、そのスタイルパネルが開きます。一般的なオプションには、文字サイズ、色、配置、マージン、余白があります。画像の場合は、代替テキストとリンク先を設定できます。

### カスタム CSS

より高度なスタイル設定のために、各セクションと要素には **Custom CSS** の欄があり、独自の CSS ルールを書けます。これらのルールはその要素だけに適用されるため、ページの他の部分に意図せず影響することはありません。

:::tip
カスタムフォントや共通の色など、サイト全体にスタイルを適用したい場合は、個別のページでカスタム CSS を使うのではなく、[外観](appearance)の設定を使ってください。
:::

## ページのプレビュー

ツールバーのプレビューコントロールを使って、さまざまな画面サイズでページの見た目を確認できます。

- **Desktop** -- ブラウザの全幅で表示します
- **Mobile** -- スマートフォンサイズの幅の狭い表示です

スマートフォンでは、行の設定で **Mobile Width** を指定しない限り、行内の列は全幅で上下に積み重なって表示されます。説教とポッドキャストの一覧では、スマートフォンで各エピソードのテキストがサムネイルの下に表示されます。

訪問者が実際に見る公開ページを確認するには、ページの一覧に戻り、ページのパスをクリックします。新しいブラウザタブで開きます。

## アクセシビリティの確認

ツールバーの **Accessibility** アイコンをクリックすると、よくある問題について簡単なチェックを実行できます。対象は、代替テキストのない画像、色のコントラストの低さ、見出しの順序の誤りなどです。各問題は修正が必要な要素に直接リンクしているため、その場で修正できます。

## 変更を元に戻す

エディターは編集履歴を自動的に記録します。ツールバーのボタンまたはキーボードショートカットを使って操作できます。

- **Undo**（Ctrl+Z / Cmd+Z） -- 直前の操作を取り消します
- **Redo**（Ctrl+Shift+Z または Ctrl+Y / Cmd+Shift+Z） -- 取り消した操作をやり直します

ページを以前のスナップショットに戻すこともできます。ツールバーの **View history** をクリックすると、説明付きの保存済みスナップショットの一覧が表示されます。任意の項目をクリックすると、その時点に戻ります。

:::warning
スナップショットに戻すと、現在のページの内容が、そのスナップショットのバージョンに置き換えられます。この操作は通常の元に戻すボタンでは取り消せません。以前の状態に戻る可能性を残したい場合は、古いスナップショットに戻す前に、現在の状態のスナップショットを保存してください。
:::

## 保存と公開

変更は作業中に自動的に保存されます。ツールバーのステータスインジケーターに、変更が保存されたかどうかが表示されます。

### 下書きと公開の状態

ページには **公開済み**の状態があり、訪問者に変更がいつ表示されるかを制御します。ツールバーには現在の状態を示すステータスチップが表示されます。

- **Live on save** -- ページは公開のワークフローを使いません。保存されたすべての変更は、すぐに公開されます。これは新規ページの既定の設定です。
- **Unpublished changes** -- ページは以前に公開されていますが、最後の公開以降に変更を加えています。訪問者には、以前に公開されたバージョンが引き続き表示されます。
- **Published** -- ページは公開されており、保存された内容が訪問者に表示される内容と一致しています。

変更を公開するには、ツールバーの **Publish** ボタンをクリックします。ページはすぐに公開されます。

訪問者に表示される内容に影響を与えずに最後に公開したバージョンに戻すには、その他メニュー（⋮）を開き、**Discard unpublished changes** をクリックします。

公開のワークフローの使用をやめるには、その他メニューを開き、**Turn off publishing** をクリックします。その後、編集内容はすぐに公開されるようになります。

:::tip
ページを準備して、適切なタイミングで初めて公開したい場合（例：今後のイベントのため）は、下書きと公開のワークフローを使ってください。ページを作成してプレビューで確認し、準備ができたら **Publish** をクリックします。
:::
