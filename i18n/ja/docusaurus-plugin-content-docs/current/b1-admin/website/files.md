# ファイル

<div class="article-intro">

ファイルページは、教会のウェブサイトで使用するすべてのメディアとドキュメントを一元管理する場所です。ここから、サイトに必要なすべての画像、ドキュメント、メディアファイルをアップロード、閲覧、管理できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- ウェブサイトの[初期設定](initial-setup)を完了している
- ページの読み込みを速くするため、アップロード前に画像を最適化する
- ファイルを一般的なウェブ形式（PNG、JPG、PDFなど）で準備する

</div>

## ファイルのアップロード

1. B1 Adminで、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**Website**を展開して、**Files**をクリックします。
2. 右側の**Upload Files**パネルで**Choose File**をクリックし、コンピューターからファイルを選択します。（ページ上部の**Upload Files**ボタンを押しても、同じパネルが開きます。）
3. ファイルがアップロードされ、ファイル一覧に表示されます。

Upload Filesパネルには、現在使用しているストレージ容量も表示されます。100 MBまでは無料で利用できます。さらに容量が必要な場合は、**Settings**の**File Storage**セクションで、ご自身のGoogle Drive、Dropbox、OneDrive、またはS3バケットを連携してください。

:::tip
最良の結果を得るために、アップロード前に画像を最適化してください。ファイルサイズが小さいほど、訪問者にとってウェブサイトの読み込みが速くなります。TinyPNGやSquooshなどのツールを使えば、画質をほとんど落とさずに画像を圧縮できます。
:::

## ファイルの閲覧

ファイル一覧には、アップロードされたすべてのファイルが**Name**（名前）と**Size**（サイズ）とともに表示されます。ファイル名をクリックすると、新しいタブでファイルが開きます。チームがすぐに見つけられるよう、アップロード前にファイルにわかりやすい名前を付けておきましょう。

## ウェブサイトでのファイルの使用

1. ファイル一覧で目的のファイルを見つけます。
2. **Copy link**をクリックして、ファイルのURLをコピーします。このURLは、画像要素、ダウンロードリンク、その他ファイルのURLを受け付ける場所に貼り付けられます。
3. ここにアップロードしたファイルは、ウェブサイトのすべてのページやコンテンツブロックで使用できます。

:::info
[ページの管理](managing-pages)でページを作成する際、ここにアップロードしたファイルはURLで参照できます。これにより、すべてのメディアを一か所にまとめて整理できます。
:::

## ファイルの削除

1. ファイル一覧で削除したいファイルを見つけます。
2. その横の**Delete**をクリックし、確認して、ライブラリからファイルを完全に削除します。
3. ファイルを削除する前に、どのページでも使用されていないことを確認してください。使用中のファイルを削除すると、それを参照しているリンクや画像が壊れます。

:::warning
削除したファイルは復元できません。削除する前に、どのページでも使用されていないことを必ず再確認してください。
:::
