# 日曜日のボランティアを管理する

<div class="article-intro">

ボランティアチームを設定し、毎週の礼拝プランを作成し、役割を割り当て、賛美曲を含む礼拝の進行表を組み立て、日曜日のタスクを割り当てます。完了すると、ボランティアは B1 のウェブサイトとモバイルアプリで自分の担当を確認でき、その場で承諾または辞退できるようになります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 管理者権限のある B1 Admin アカウント
- ボランティアが[人物ディレクトリに追加されていること](../people/adding-people.md)

</div>

## ステップ 1：ボランティアチームを作成する

ボランティアを チームに分けておくと、奉仕分野ごとに担当を管理できます。

[グループの作成](../groups/creating-groups.md)と[グループメンバー](../groups/group-members.md)のガイドに従って、次の作業を行います。

1. カテゴリを作成する（例：「日曜朝のチーム」）
2. 「礼拝チーム」「音響・映像」「受付・案内」「子ども伝道ボランティア」などのグループを作成する
3. 各グループに、ボランティアの名前を検索して「追加」をクリックし、メンバーを加える

:::tip
チームのリーダーは、グループのメンバーリスト（グループページの **All members** をクリック）で星のアイコン（**Make Leader**）を使って指定します。リーダーは自分のグループのカレンダーを管理し、チームの調整を行うことができます。
:::

## ステップ 2：賛美曲のライブラリを作る

毎週の礼拝プランに取り込めるように、賛美曲を登録しておきます。

[賛美曲](../serving/songs.md)のガイドに従って、次の作業を行います。

1. 賛美曲をタイトル、作者、長さとともに追加する
2. 各曲について、歌詞とキーの指定を含むアレンジメントを追加する
3. YouTube の演奏、コード譜、楽譜への外部リンクを追加する

:::info
ここに追加した賛美曲は、後でどの礼拝プランにも取り込めます。ライブラリは一度作れば、毎週繰り返し使えます。
:::

## ステップ 3：礼拝プランを作成する

プランは、ボランティアにどこで奉仕が必要かを伝える毎週の割り当てです。

[プラン](../serving/plans.md)のガイドに従って、次の作業を行います。

1. Serving に進み、奉仕分野のタブを選んで、プランの種類を開く
2. **New Plan** をクリックし、礼拝の日付を選ぶ。複数の日曜日をまとめて設定する場合は、前回のプランからコピーし、**Number of plans** に数を入力する
3. プランの **Serving Team Assignments** セクションで、役割を追加してボランティアを割り当てる
4. ボランティアには、担当の状態（Requested、Confirmed、Pending）が表示される
5. プランの種類について[ボランティアへのリマインダー](../serving/plans.md#volunteer-reminders)をオンにすると、礼拝の前にプッシュ通知、メール、またはテキストメッセージでボランティアに通知されます

## ステップ 4：礼拝の進行表を組み立てる

礼拝の始めから終わりまでの流れを決めます。

[礼拝の進行表](../serving/service-order.md)のガイドに従って、次の作業を行います。

1. プランを開き、上部にある **Order of Service** セクションを探す
2. **Add** をクリックして要素を追加する：賛美曲（ライブラリから）、祈り、聖書朗読、お知らせ、説教、献金、閉会など
3. 項目をドラッグ＆ドロップして、礼拝の流れを並べ替える

:::info
礼拝の進行表はプランごとに設定されます。ここでの変更は、他のプランや賛美曲のマスターライブラリには影響しません。
:::

## ステップ 5：日曜日のタスクを割り当てる

一度限りの日曜日の担当を管理し、抜け漏れを防ぎます。

[タスク](../serving/tasks.md)のガイドに従って、次の作業を行います。

1. 「聖餐の準備」「週報の印刷」「音響機器のセットアップ」など、担当業務のタスクを作成する
2. 各タスクを、責任者または担当グループに割り当てる
3. タスクは **Serving > My Work**、担当者のダッシュボード、モバイルアプリに表示される

:::info
B1 Admin では、繰り返しのスケジュールでタスクを作成することはできなくなりました。人を段階的に進める繰り返しの業務には、スケジュールのトリガーを使った[ワークフロー](../serving/workflows.md)を利用してください。
:::

## ステップ 6：セルフサービスの申し込みを有効にする（任意）

管理者が割り当てるのを待つのではなく、ボランティアが自分で役割に申し込めるようにします。

1. プランを作成または編集するときに、**Signup Deadline**（礼拝の何時間前か）を設定し、セルフサービスの申し込みを締め切るタイミングを決めます。時間は、プランの最初の礼拝時刻から逆算されます。期限を設けない場合は空欄のままにします。新しいプランには、前回のプランの締め切り設定が引き継がれます。
2. 任意で **Show volunteer names on signup page** をオンにすると、ほかに誰が申し込んでいるかをボランティアが確認できるようになります。
3. 各役割について **Allow Self-Signup** のチェックボックスをオンにすると、セルフサービスで申し込めるようになります。
4. 各役割に **Description** を追加して、どんな奉仕内容かをボランティアに分かるようにします。

セルフサービスの役割を作成すると、[B1.church](../../b1-church/serving/volunteer-signup)と [B1 Mobile アプリ](../../b1-mobile/serving/volunteer-signup)のボランティア申し込みページに自動的に表示されます。会員は募集中の役割を見て、残りの枠数を確認し、ワンクリックで申し込めます。

:::tip
管理者が割り当てる役割とセルフサービスの役割を、同じプランに組み合わせてください。たとえば、礼拝リーダーは直接割り当て、受付やコーヒーの係は自分で選んで申し込めるようにします。
:::

## ステップ 7：ボランティアに知らせる

割り当てられたボランティアは、自分のプランを自動的に確認でき、返答することもできます。

1. ボランティアは [B1.church](../../b1-church/plans/viewing-plans.md)と [B1 Mobile アプリ](../../b1-mobile/serving/viewing-plans.md)でプランを確認できる
2. どちらのプラットフォームからでも、割り当てを直接承諾または辞退できる
3. 都合のつかない週については、ブロックアウト日を設定できる
4. リハーサル用にプランを印刷したり、舞台裏に掲示したりできる
5. ボランティアは[ボランティア申し込みページ](../../b1-church/serving/volunteer-signup)から募集中の役割を見て、申し込みできる

:::tip
モバイルアプリのプッシュ通知により、新しい割り当てを受けたときや、プランが変更されたときにボランティアに知らせが届きます。
:::

## 完了です！

ボランティア管理の仕組みの設定が完了しました。毎週新しいプランを作成して役割を割り当てれば、チームは携帯電話やパソコンで必要な情報をすべて確認できます。
