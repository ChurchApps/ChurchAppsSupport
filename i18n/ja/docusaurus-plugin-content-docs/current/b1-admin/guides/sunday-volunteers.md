# 日曜日のボランティアを管理する

<div class="article-intro">

ボランティアチームを設定し、週間の奉仕計画を作成し、担当を割り当て、賛美曲を含む礼拝の進行を組み立て、日曜日のタスクを割り当てます。完了すると、ボランティアは B1 のウェブサイトとモバイルアプリで自分の担当を確認でき、その場で承諾または辞退できるようになります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 管理者権限を持つ B1 Admin アカウント
- [人物ディレクトリに追加された](../people/adding-people.md)ボランティア

</div>

## ステップ 1：ボランティアチームを作成する

ボランティアを チーム に分けて、奉仕分野ごとに担当を管理できるようにします。

[グループの作成](../groups/creating-groups.md)と[グループメンバー](../groups/group-members.md)のガイドに従って、次の作業を行います。

1. カテゴリを作成する（例：「日曜礼拝チーム」）
2. 「賛美チーム」「音響・映像」「受付」「キッズミニストリーのボランティア」などのグループを作成する
3. 各グループに、ボランティアの名前を検索して「追加」をクリックし、メンバーを追加する

:::tip
チームリーダーは、グループのメンバー一覧（グループページの **All members** をクリック）で星のアイコン（**Make Leader**）を使って指定します。リーダーは自分のグループのカレンダーを管理し、チームの調整を行えます。
:::

## ステップ 2：賛美曲のライブラリを作成する

賛美曲を追加しておくと、毎週の奉仕計画にすぐ取り込めます。

[賛美曲](../serving/songs.md)のガイドに従って、次の作業を行います。

1. タイトル、アーティスト、長さを指定して賛美曲を追加する
2. 各曲に、歌詞とキーの指定を含むアレンジを追加する
3. YouTube の演奏動画、コードチャート、楽譜への外部リンクを追加する

:::info
ここに追加した賛美曲は、後でどの奉仕計画にも取り込めます。ライブラリは一度作れば、毎週繰り返し使えます。
:::

## ステップ 3：奉仕計画を作成する

奉仕計画は、ボランティアがどこで必要とされているかを示す週間の担当表です。

[奉仕計画](../serving/plans.md)のガイドに従って、次の作業を行います。

1. 奉仕のページに移動し、担当する分野のタブを選んで、計画の種類を開く
2. **New Plan** をクリックし、礼拝の日付を選ぶ。複数の日曜日をまとめて設定する場合は、前の計画からコピーし、**Number of plans** に件数を入力する
3. 計画の **Serving Team Assignments** セクションで、奉仕の役割を追加し、ボランティアを割り当てる
4. ボランティアには、自分の担当の状態（Requested、Confirmed、Pending）が表示される
5. 計画の種類に対して[ボランティアへのリマインダー](../serving/plans.md#volunteer-reminders)をオンにすると、各礼拝の前に、プッシュ通知、メール、またはテキストメッセージでボランティアに知らせられる

## ステップ 4：礼拝の進行を作成する

礼拝の初めから終わりまでの流れを組み立てます。

[礼拝の進行](../serving/service-order.md)のガイドに従って、次の作業を行います。

1. 計画を開き、上部にある **Order of Service** のセクションを探す
2. **Add** をクリックして要素を追加する。賛美曲（ライブラリから）、祈り、聖書朗読、お知らせ、説教、献金、閉会などがあります
3. 項目をドラッグ＆ドロップして、礼拝の流れの順序を入れ替える

:::info
礼拝の進行は計画ごとに設定されます。ここでの変更は、他の計画や賛美曲のマスターライブラリには影響しません。
:::

## ステップ 5：日曜日のタスクを割り当てる

一度限りの日曜日の担当を追跡し、対応漏れがないようにします。

[タスク](../serving/tasks.md)のガイドに従って、次の作業を行います。

1. 「聖餐の準備」「週報の印刷」「音響機材のセットアップ」などの担当を、タスクとして作成する
2. 各タスクを、担当者またはグループに割り当てる
3. タスクは、**奉仕 > My Work**、担当者のダッシュボード、モバイルアプリに表示される

:::info
B1 Admin では、タスクを繰り返しのスケジュールで作成することはできなくなりました。人を段階的に進める繰り返しの作業には、スケジュールのトリガーを使った[ワークフロー](../serving/workflows.md)を利用してください。
:::

## ステップ 6：セルフサービスでの申し込みを有効にする（任意）

管理者が割り当てるのを待たず、ボランティアが自分で役割に申し込めるようにします。

1. 計画を作成または編集するときに、**Signup Deadline**（礼拝の何時間前か）を設定し、セルフサービスの申し込みを締め切るタイミングを決めます。時間は、計画の最初の礼拝時刻から逆算されます。締め切りを設けない場合は空欄のままにします。新しい計画は、前の計画の締め切りを引き継いで始まります。
2. 必要に応じて **Show volunteer names on signup page** をオンにすると、ボランティアが他に誰が申し込んでいるかを確認できます。
3. 各役割で **Allow Self-Signup** のチェックボックスをオンにすると、セルフサービスで申し込めるようになります。
4. 各役割に **Description** を追加し、ボランティアがその役割の内容を把握できるようにします。

セルフサービスの役割を作成すると、[B1.church と B1 App](../../b1-church/serving/volunteer-signup.md)のボランティア申し込みページに自動的に表示されます。メンバーは募集中の役割を閲覧し、残りの空き数を確認して、ワンクリックで申し込めます。

:::tip
同じ計画の中で、管理者が割り当てる役割と、セルフサービスの役割を組み合わせてください。たとえば、賛美のリーダーは直接割り当て、受付やコーヒーの担当は自分で選べるようにします。
:::

## ステップ 7：ボランティアに知らせる

割り当てられたボランティアには、自分の計画が自動的に表示され、応答することができます。

1. ボランティアは [B1.church と B1 App](../../b1-church/plans/viewing-plans.md) で自分の計画を確認できる
2. スマートフォンまたはパソコンから、直接担当を承諾または辞退できる
3. 参加できない週については、不参加日を設定できる
4. 計画は、リハーサル用に印刷したり、舞台裏に掲示したりできる
5. ボランティアは、[ボランティア申し込みページ](../../b1-church/serving/volunteer-signup.md)から募集中の役割を閲覧し、申し込めます

:::tip
B1 App のプッシュ通知により、新しい担当が割り当てられたときや、計画が変更されたときに、ボランティアに知らせることができます。
:::

## 完了です！

ボランティア管理の仕組みが整いました。毎週、新しい計画を作成して役割を割り当てれば、チームはスマートフォンやパソコンでその内容をすべて確認できます。
