# B1で教会をスタートする

<div class="article-intro">

新しい教会のための完全なオンボーディングガイドです。アカウントの作成から、メンバー名簿のインポート、最初の機能の設定まで、順を追って説明します。これらの手順に従うと、教会がB1を使い始められます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 有効なメールアドレス
- 教会のロゴとブランディング素材（色、画像）。開始には必須ではありませんが、用意することをおすすめします

</div>

## ステップ1：アカウントを作成する

教会を登録し、最初の管理者になります。

[アカウントの作成](../../getting-started/create-account.md)ガイドに従って、次の操作を行ってください。

1. b1.church にアクセスし、メールアドレスで登録する
2. メールアドレスを確認する
3. 「新しい教会を作成」を選び、教会名を入力する
4. 自動的にドメイン管理者となり、すべての機能に完全にアクセスできるようになる

## ステップ2：教会の設定を行う

教会の基本情報とブランディングを入力します。

[教会の設定](../settings/church-settings.md)ガイドに従って、次の操作を行ってください。

1. 教会名、住所、電話番号、メールアドレスを入力する
2. サブドメインを設定する（yourchurch.b1.church の形式になります）
3. 教会のロゴと画像をアップロードする

:::tip
サブドメインは教会のWebサイトURLや献金ページのURLに表示されるため、短くて覚えやすいものを選んでください（例：Grace Community Church の場合は「grace」）。
:::

## ステップ3：役割を設定し、チームを招待する

誰がどの機能にアクセスできるかを管理し、チームを参加させます。

[役割と権限](../settings/roles-permissions.md)ガイドに従って、次の操作を行ってください。

1. チームのための役割を作成する（例：「牧師」「事務管理者」「経理チーム」「礼拝リーダー」）
2. 各役割に特定の権限を割り当て、必要な情報だけが表示されるようにする
3. メンバーを追加して役割を割り当て、チームに招待する

:::info
すべてを一人で行う必要はありません。事務スタッフ、牧師、奉仕リーダーを早い段階で招待すると、それぞれの担当分野の設定を手伝ってもらえます。
:::

## ステップ4：メンバーをインポートする

既存のメンバー名簿をB1に取り込みます。

[データのインポート](../people/importing-data.md)ガイドを参照してください。方法は2つあります。

1. **CSVアップロード**：現在使用しているシステムやスプレッドシートから書き出し、CSV形式に整えてB1にアップロードする
2. **Breezeからの移行**：ワンクリックで、メンバー、写真、グループ、献金、出席記録をまとめて取り込む

:::tip
Breezeから移行しますか？インポートツールを使えば、メンバー、写真、グループ、献金、出席履歴をすべて一度に取り込めます。最も早く始められる方法です。
:::

## ステップ5：モバイルアプリを設定する

会衆に合わせて、B1モバイルアプリの画面をカスタマイズします。

[モバイルアプリの設定](../settings/mobile-app.md)ガイドに従って、次の操作を行ってください。

1. メンバーのB1モバイルアプリに表示するタブを選ぶ
2. タブの名前、アイコン、種類（聖書、ライブ配信、献金、Webサイトなど）を設定する
3. 会衆に表示する機能を管理する

## ステップ6：各機能の設定を始める

基本の設定が整ったら、次のガイドに従って特定の機能を設定してください。

- [オンライン献金を設定する](./online-giving.md)：Webサイトやアプリを通じて献金を受け付けます
- [教会のWebサイトを公開する](./launch-website.md)：教会のWebサイトを作成します
- [小グループを運営する](./small-groups.md)：グループ、聖書研究会、奉仕団体を組織します
- [子どもチェックインを設定する](./childrens-checkin.md)：子どもの奉仕のためのキオスク式チェックインです
- [日曜日の奉仕者を管理する](./sunday-volunteers.md)：奉仕チームを調整します
- [説教ライブラリを作成する](./sermon-library.md)：説教をオンラインで公開し、ライブ配信を設定します
- [出席を記録する](./track-attendance.md)：礼拝やグループへの出席状況を把握します

## 完了です！

教会のB1での設定が整いました。チームがアクセスでき、メンバーのインポートも済み、教会の働きにとって最も重要な機能を使い始める準備ができています。上記の機能ガイドを参照して、各分野を設定してください。
