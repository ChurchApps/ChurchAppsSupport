# B1 で教会をスタートする

<div class="article-intro">

新しい教会のための完全なオンボーディングガイドです。アカウントの作成からメンバーディレクトリのインポート、最初の機能の設定まで、この順番に従って進めることで、B1 で教会の運用を開始できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 有効なメールアドレス
- 教会のロゴとブランディング素材（色、画像）— 推奨ですが、開始に必須ではありません

</div>

## ステップ 1：アカウントを作成する

教会を登録し、最初の管理者になります。

[アカウントの作成](../../getting-started/create-account.md) ガイドに従って以下を行います：

1. b1.church にアクセスし、メールアドレスで登録する
2. メールアドレスを確認する
3. 「新しい教会を作成」を選び、教会名を入力する
4. 自動的にドメイン管理者となり、すべての機能にフルアクセスできます

## ステップ 2：教会の設定を構成する

教会の基本情報とブランディングを入力します。

[教会の設定](../settings/church-settings.md) ガイドに従って：

1. 教会名、住所、電話番号、メールアドレスを入力する
2. サブドメインを設定する（yourchurch.b1.church になります）
3. 教会のロゴと画像をアップロードする

:::tip
サブドメインはウェブサイトのURLや献金ページのURLに表示されるため、短くて覚えやすいものを選びましょう（例：Grace Community Church の場合は「grace」）。
:::

## ステップ 3：役割を設定し、チームを招待する

誰が何にアクセスできるかを管理し、チームを参加させます。

[役割と権限](../settings/roles-permissions.md) ガイドに従って：

1. チーム用の役割を作成する（例：「牧師」「事務管理者」「財務チーム」「礼拝リーダー」）
2. 各役割に特定の権限を割り当て、必要な情報だけが表示されるようにする
3. メンバーを追加して役割を割り当て、チームメンバーを招待する

:::info
すべてを一人で行う必要はありません。事務スタッフ、牧師、奉仕リーダーを早めに招待すれば、それぞれの分野の設定を手伝ってもらえます。
:::

## ステップ 4：メンバー情報を取り込む

既存のメンバーディレクトリを B1 に取り込みます。

[データのインポート](../people/importing-data.md) ガイドに従ってください。選択肢は2つあります：

1. **CSV アップロード** — 現在のシステムやスプレッドシートから書き出し、CSV 形式にして B1 にアップロードする
2. **Breeze 移行** — ワンクリックで、人物、写真、グループ、献金、出席記録をまとめて取り込む

:::tip
Breeze から移行しますか？インポートツールは、人物、写真、グループ、献金、出席履歴をすべて一度に取り込みます。最も速く始められる方法です。
:::

## ステップ 5：モバイルアプリを設定する

会衆に合わせて B1 App の体験をカスタマイズします。

[モバイルアプリの設定](../settings/mobile-app.md) ガイドに従って：

1. メンバーの B1 App に表示するタブを選択する
2. タブの名前、アイコン、種類（聖書、ライブ配信、献金、ウェブサイトなど）を設定する
3. 会衆に表示する機能を管理する

## ステップ 6：機能の設定を始める

基盤が整ったので、以下のガイドに従って個別の機能を設定しましょう：

- [オンライン献金を設定する](./online-giving.md) — ウェブサイトやアプリを通じて献金を受け付けます
- [教会ウェブサイトを公開する](./launch-website.md) — 教会のウェブサイトを作成します
- [小グループを運営する](./small-groups.md) — グループ、聖書研究会、奉仕団体を整理します
- [子どもチェックインを設定する](./childrens-checkin.md) — 子どもの奉仕のためのキオスク式チェックイン
- [日曜日のボランティアを管理する](./sunday-volunteers.md) — 奉仕チームを調整します
- [説教ライブラリを構築する](./sermon-library.md) — 説教をオンラインに公開し、ライブ配信を設定します
- [出席を記録する](./track-attendance.md) — 礼拝やグループに来ている人を把握します

## 完了です！

教会の B1 での設定が完了しました。チームがアクセスでき、メンバー情報がインポートされ、奉仕に最も重要な機能を使い始める準備が整いました。上記の機能ガイドを参照して、各分野を設定してください。
