# 教会の出席を記録する

<div class="article-intro">

礼拝やグループの出席記録を設定しましょう。キャンパスとサービス時間の設定から、手動での記録、セルフサービスのチェックインアプリを使った記録、レポートでの傾向の確認まで、一連の流れを説明します。この手順を終えると、誰がいつ出席しているかを全体として把握できるようになります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 管理者権限のあるB1 Adminアカウント
- [ディレクトリに追加された人物](../people/adding-people.md)
- 記録したい活動のために[作成されたグループ](../groups/creating-groups.md)

</div>

## ステップ1：キャンパスとサービスを設定する

教会の集会の場所と時間を登録します。

[出席の設定](../attendance/setup.md)のガイドに従って、次の作業を行います。

1. キャンパスを追加します（例：「メインキャンパス」）
2. サービス時間を追加します（例：「日曜 午前9時」「日曜 午前11時」「水曜 午後7時」）
3. 各サービス時間にグループを割り当て、その時間に行われるクラスや活動を定義します

## ステップ2：グループの出席記録を有効にする

出席を追跡したいグループで、出席記録をオンにします。

[グループの作成](../groups/creating-groups.md)のガイドに従って、次の作業を行います。

1. 追跡したい各グループを編集し、「出席を記録する」をオンにします
2. グループをサービス時間に関連付けて、正しいサービスに出席が記録されるようにします

:::info
すべてのグループで出席記録が必要なわけではありません。子ども向けのクラス、小グループ、日曜学校など、参加状況を把握したいグループに限って有効にしてください。
:::

## ステップ3：出席を手動で記録する

各サービスと各グループに誰が出席したかをチェックします。

[出席の記録](../attendance/recording-attendance.md)のガイドに従って、次の作業を行います。

1. グループを開き、「セッション」欄の「すべてのセッション」をクリックして、日付とサービス時間のセッションを追加します。「他のグループにも追加」にチェックを入れると、そのサービス時間に行われるすべてのクラスのセッションを一度に作成できます。
2. 各グループの出席者にチェックを入れます

:::tip
手動の記録は、大人向けの礼拝や小グループ、チェックイン端末を使うのが難しい場合に適しています。
:::

## ステップ4：セルフチェックインを設定する（任意）

タブレットの端末を使って、メンバーが自分でチェックインできるようにします。

[チェックイン](../attendance/check-in.md)のガイドに従って、次の作業を行います。

1. セルフサービスのチェックインのために、タブレットにB1 Checkinアプリをインストールします
2. メンバーは自分の名前を検索し、自分と家族のチェックインを行います
3. チェックインで記録された出席は、手動で入力された記録と並んで表示されます。データに違いはありません

:::info
ハードウェアやプリンターの設定を含む、子どもの活動の完全なセットアップについては、[子どものチェックインガイド](./childrens-checkin.md)をご覧ください。
:::

## ステップ5：出席レポートを確認する

教会全体の参加状況を大きな視点で確認します。

[出席レポート](../reports/attendance-reports.md)のガイドに従ってください。次の3種類のレポートを利用できます。

1. **出席の推移**：時間の経過とともに出席がどう変化したかを確認し、増加や減少の傾向を把握します
2. **グループの出席**：指定した期間の各グループのセッションに誰が出席したかを確認します。CSVでダウンロードできます
3. **日別のグループ出席**：日ごとの内訳を表示し、詳しく分析できます

:::info
レポートには、手動で記録された出席とセルフチェックインによる出席の両方が含まれます。どちらの方法で記録されたデータも同じように表示され、同じレポートに反映されます。
:::

## 完了です！

出席の記録の設定が完了しました。手動で記録する場合も、チェックインアプリを使う場合も、その両方を使う場合も、すべてのデータは同じレポートに集約されます。これにより、教会全体の参加状況を明確に把握できます。
