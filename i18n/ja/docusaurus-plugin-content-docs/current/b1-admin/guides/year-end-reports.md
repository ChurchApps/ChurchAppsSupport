# 年末の寄付金報告書を作成する

<div class="article-intro">

寄付記録の最終確定、基金設定の確認、そして寄付者全員への税控除対象の寄付金明細書の作成という年末の手順を説明します。通常、前年分を1月上旬に行います。

</div>

<div class="prereqs">
<h4>開始する前に</h4>

- 財務機能へのアクセス権を持つ B1 Admin アカウント
- 1年を通して記録された寄付（Stripe経由のオンライン寄付、および手入力分）
- オンライン寄付を受け付けている場合は、Stripe アカウントへのアクセス

</div>

## ステップ1：Stripe の最終取引をインポートする

年末のオンライン寄付がすべてシステムに登録されていることを確認します。

[Stripe インポート](../donations/stripe-import.md)のガイドに従って、次の操作を行います。

1. 寄付 > Stripe インポートに移動する
2. 年末をカバーする日付範囲を選択する（例：12月1日～12月31日）
3. まず「プレビュー」をクリックして内容を確認し、「不足分をインポート」をクリックして確定する

:::warning
明細書を作成する前に、このインポートを実行してください。インポートしていない取引は寄付者の明細書に表示されません。
:::

## ステップ2：寄付レポートを確認する

明細書を作成する前に、記録が正確であることを確認します。

[寄付レポート](../donations/donation-reports.md)のガイドに従って、次の操作を行います。

1. 年間の寄付サマリーページを確認する
2. 基金ごとの合計を確認し、食い違いがないか銀行明細と照合する
3. 必要に応じて個々のバッチをクリックし、寄付者単位の詳細を確認する

## ステップ3：基金の税控除ステータスを確認する

明細書が正確になるよう、各基金の税控除設定が正しいことを確認します。

[基金](../donations/funds.md)のガイドに従って、次の操作を行います。

1. 各基金を開き、税控除の設定が正しいか確認する

:::info
税控除対象として設定された基金への寄付のみが寄付明細書に表示されます。税控除対象であるべき基金がそのように設定されていない場合は、明細書を作成する前に更新してください。
:::

## ステップ4：寄付明細書を作成する

寄付者向けの正式な寄付明細書を作成します。

[寄付明細書](../donations/giving-statements.md)のガイドに従って、次の操作を行います。

1. **寄付 > 寄付明細書** に移動する
2. ドロップダウンから年を選択し、概要の統計情報を確認する
3. ダウンロード方法を選択する：
   - **ZIP をダウンロード** — 寄付者ごとに1つずつの個別 CSV ファイル
   - **すべて印刷** — 各明細書が新しいページに出力される印刷用ビュー。教会のロゴ（アップロード済みの場合）が上部に表示されます

:::tip
記録が新しいうちに、1月上旬に明細書を作成しましょう。郵送前に問題を見つける時間が取れます。
:::

## ステップ5：寄付者に配布する

明細書を寄付者の手元に届けます。

1. 明細書を印刷して郵送するか、個々の CSV を寄付者にメールで送付する
2. メンバーは [B1.church](../../b1-church/giving/donation-history.md) および [B1 Mobile アプリ](../../b1-church/giving/donation-history.md)から、自分の寄付履歴を確認したり明細書を印刷したりすることもできます

## 完了です！

年末の寄付金報告書の作成は完了です。寄付者は税控除対象の明細書を受け取り、今年度の財務記録は確定しました。
