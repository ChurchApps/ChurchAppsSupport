# 年末寄付報告書の作成

<div class="article-intro">

年間の寄付記録の確定、基金設定の確認、そしてすべての寄付者向けの税控除対象寄付明細書の作成までの年末の手順を説明します。通常は、前年の暦年分を1月上旬に行います。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 財務機能へのアクセス権を持つB1 Adminアカウント
- 年間を通じて記録された寄付（Stripe経由のオンラインおよび／または手入力）
- オンライン寄付を受け付けている場合は、Stripeアカウントへのアクセス

</div>

## ステップ1：Stripeの最終取引をインポートする

年末のオンライン寄付がすべてシステムに登録されていることを確認します。

[Stripeインポート](../donations/stripe-import.md)のガイドに従って、以下を行います。

1. 寄付 > Stripeインポートに移動します
2. 年末をカバーする日付範囲を選択します（例：12月1日～12月31日）
3. まず「プレビュー」をクリックして内容を確認し、「未インポート分を取り込む」をクリックして確定します

:::warning
明細書を作成する前に、このインポートを実行してください。インポートしていない取引は寄付者の明細書に表示されません。
:::

## ステップ2：寄付レポートを確認する

明細書を作成する前に、記録が正確であることを確認します。

[寄付レポート](../donations/donation-reports.md)のガイドに従って、以下を行います。

1. 年間の寄付サマリーページを確認します
2. 基金ごとの合計を確認し、銀行明細と照合して不一致がないか調べます
3. 必要に応じて個別のバッチをクリックし、寄付者ごとの詳細を確認します

## ステップ3：基金の税務ステータスを確認する

明細書が正確になるよう、各基金の税控除設定が正しいことを確認します。

[基金](../donations/funds.md)のガイドに従って、以下を行います。

1. 各基金を開き、税控除の設定が正しいことを確認します

:::info
税控除対象としてマークされた基金への寄付のみが寄付明細書に表示されます。税控除対象であるべき基金がそのようにマークされていない場合は、明細書を作成する前に更新してください。
:::

## ステップ4：寄付明細書を作成する

寄付者向けの正式な寄付明細書を作成します。

[寄付明細書](../donations/giving-statements.md)のガイドに従って、以下を行います。

1. **寄付 > 寄付明細書**に移動します
2. ドロップダウンから年を選択し、サマリー統計を確認します
3. ダウンロード方法を選択します：
   - **ZIPをダウンロード** — 寄付者ごとに1つのCSVファイル
   - **すべて印刷** — 各明細書が新しいページに出力される印刷用ビュー（教会のロゴをアップロードしている場合は上部に表示されます）

:::tip
記録が新しいうちに、1月の早い時期に明細書を作成しましょう。発送前に問題を見つける時間が確保できます。
:::

## ステップ5：寄付者に配布する

明細書を寄付者の手元に届けます。

1. 明細書を印刷して郵送するか、個別のCSVを寄付者にメールで送信します
2. メンバーは、[B1.churchまたはB1アプリ](../../b1-church/giving/donation-history.md)で自身の寄付履歴を確認し、明細書を印刷することもできます

## 完了です！

年末の寄付報告書の作成は完了です。寄付者は税控除対象の明細書を受け取り、教会の財務記録も当年度分が確定しました。
