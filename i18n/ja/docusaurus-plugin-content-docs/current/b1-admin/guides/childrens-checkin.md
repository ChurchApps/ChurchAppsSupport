# 子ども向けミニストリーのチェックインを設定する

<div class="article-intro">

このガイドでは、教会で子ども向けチェックインシステムを稼働させるために必要なすべての手順を説明します。データベースへの家族の登録、年齢に合わせたグループの設定、日曜日の朝のネームタグ印刷までを扱います。完了すると、保護者はキオスク用のタブレットで子どもをチェックインさせ、対応するセキュリティタグを受け取れるようになります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [admin.b1.church](https://admin.b1.church) で教会のアカウントを作成します
- 管理者権限があることを確認してください。必要に応じて [役割と権限](../people/roles-permissions.md) を参照してください
- 任意：別のシステムから移行する場合は、家族のCSVファイルを準備してください

</div>

## ステップ1：データベースに家族を追加する

チェックインを機能させるには、まずシステムが家族の情報を把握している必要があります。各子どもは、世帯機能を通じて保護者と紐付けられている必要があります。

少なくとも1家族を追加するには、[人の追加](../people/adding-people.md) ガイドに従ってください。次の点に注意してください。

- 先に保護者を追加します
- 次に、各子どもを追加します
- [世帯エディター](../people/adding-people.md#managing-households) を使って、同じ世帯にまとめます

:::tip
追加する家族が数家族以上ある場合は、一人ずつ追加するのではなく、[CSVインポート](../people/importing-data.md) ツールを使用してください。数分でディレクトリ全体を取り込めます。
:::

## ステップ2：子どものグループを作成する

グループは、子どもがチェックインするクラスを定義します。通常は年齢層ごとに1つのグループを作成します。

次のようなグループを作成するには、[グループの作成](../groups/creating-groups.md) ガイドに従ってください。

- **ナーサリー**（0〜2歳）
- **プリスクール**（3〜5歳）
- **エレメンタリー**（6〜10歳）

教会のミニストリーの構成に合わせて、名称や年齢範囲を調整できます。

## ステップ3：キャンパスとサービスを設定する

チェックインは特定の礼拝時間に紐付けられます。少なくとも1つのキャンパスと1つのサービスを設定する必要があります。

[出席の設定](../attendance/setup.md) ガイドに従って、次の作業を行ってください。

1. キャンパスを追加します（例：「メインキャンパス」）
2. サービスを追加します（例：「日曜日の朝」）
3. サービスの時刻を設定します（例：「午前9時」）。必要に応じて、[チェックインスケジュール](../attendance/setup.md#setting-a-check-in-schedule) を設定すると、各礼拝の前に自動でチェックインが開始され、礼拝後に自動で終了します
4. 子どものグループをサービスに割り当てます

## ステップ4：チェックインアプリを設定する

次に、タブレットにチェックインアプリをインストールして、すべてを接続します。

1. **B1 Checkinアプリ**をインストールします。ダウンロードリンクは [チェックイン](../attendance/check-in.md) の記事を参照してください
2. B1 Adminの認証情報でサインインします
3. キャンパスとサービスの時刻を選択します

詳しい設定手順は、[チェックイン](../attendance/check-in.md) の記事全体を参照してください。

## ステップ5：機器を準備する

キオスク用のタブレットが必要です。ネームタグ用にBrother製のラベルプリンターを使う場合は、そちらも用意してください。

最低限、次のものが必要です。
- **Androidタブレット または Amazon Fireタブレットを1台**。[推奨タブレット](../attendance/check-in.md#recommended-hardware) を参照してください
- **Brother製ラベルプリンターを1台**。Bluetooth と WiFi に対応しているため、QL-1110NWB を推奨します
- **Brother DK-1201 ラベル**（1-1/7" x 3-1/2"）

:::warning
B1 Checkinアプリに対応しているのは Brother製のラベルプリンターのみです。他社製のプリンターは動作しません。
:::

## ステップ6：テストチェックインを実行する

日曜日の朝より前に、テストを行ってください。

1. タブレットで B1 Checkinアプリを開きます
2. キャンパスと正しいサービスの時刻を選択します
3. 追加した家族のいずれかを検索します
4. 子どもをチェックインさせ、次の点を確認します
   - B1 Adminの **出席** に出席記録が表示されること
   - プリンターを使用している場合、ネームタグが正しく印刷されること

:::tip
本番前に、受付チームのボランティアにチェックインの手順を説明しておいてください。通常は5分程度の簡単な説明で十分です。
:::

## 完了です！

子ども向けミニストリーのチェックインの準備が整いました。保護者は家族を検索し、子どもを選択して、キオスクでチェックインできます。出席はB1 Adminに自動で記録されます。
