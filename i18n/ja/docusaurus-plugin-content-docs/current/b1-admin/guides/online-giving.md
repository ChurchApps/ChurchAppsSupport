# オンライン献金を設定する

<div class="article-intro">

教会でオンライン献金を受け付けるために必要な作業を順に説明します。献金基金の作成、決済処理のためのStripe接続、そして献金ページの会衆との共有までを扱います。完了すると、メンバーはウェブサイトやモバイルアプリから献金できるようになります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 管理者権限を持つB1 Adminアカウント。詳しくは[役割と権限](../people/roles-permissions.md)をご覧ください
- Stripeアカウント（必要な場合は[stripe.com](https://stripe.com)で無料で作成できます）

</div>

## ステップ1：献金基金を作成する

献金基金は、寄付者が献金先として選べるカテゴリです。献金を受け付けるには、少なくとも1つの基金が必要です。

[基金](../donations/funds.md)のガイドに従って、献金カテゴリを設定してください。

1. よく使われる基金を作成します（例：「一般基金」「建設基金」「宣教基金」）
2. 税控除の対象となる基金に適切な設定をします。これは年末の献金明細書に影響します

:::tip
基金はいつでも追加できます。よく使われる献金カテゴリから始めるとよいでしょう。
:::

## ステップ2：Stripeを接続する

Stripeがすべての決済処理を担当します。Stripeアカウントを B1 Adminに接続すると、献金が教会の銀行口座に入金されるようになります。

[オンライン献金の設定](../donations/online-giving-setup.md)のガイドに従って、Stripeを接続してください。

1. Stripeのダッシュボードにログインし、公開可能キー（Publishable Key）とシークレットキー（Secret Key）を確認します
2. B1 Adminで「設定」を開き、両方のキーを入力します

:::warning
Stripeではシークレットキーが一度しか表示されません。Stripeのダッシュボードを離れる前にコピーして保存してください。紛失した場合は、新しいキーを生成する必要があります。
:::

## ステップ3：ウェブサイトに献金ページを追加する

B1ウェブサイトに献金ページを追加して、献金しやすくしましょう。

[オンライン献金の設定](../donations/online-giving-setup.md)と[ページの管理](../website/managing-pages.md)のガイドに従って、次の作業を行ってください。

1. B1.churchサイトに「寄付する」タブを追加します
2. 献金ページのURLは `https://yoursubdomain.b1.church/donate` になります
3. メンバーはログインせずに献金できます（公開ページ）。ログインすると、保存済みの支払い方法や献金履歴を利用できます

## ステップ4：テスト献金を行う

会衆に知らせる前に、すべてが正しく動作するか確認しましょう。

1. 少額のテスト献金を行い、最初から最後まで流れが正しく動作するか確認します
2. B1 Adminの「献金」で、その献金が表示されているか確認します

:::tip
実際の請求を発生させずに確認したい場合は、まずStripeのテストモードを使用してください。その後、会衆に知らせる前にライブモードに切り替えます。
:::

## ステップ5：会衆に知らせる

メンバーがオンラインで献金できることを周知しましょう。

1. ウェブサイト、メールマガジン、週報、ソーシャルメディアで献金用URLを共有します
2. メンバーは[B1アプリ](../../b1-church/giving/index.md)からも献金できます。献金機能はアプリに組み込まれています

:::info
ログインしたメンバーは、支払い方法を保存したり、定期献金を設定したり、献金履歴を確認したりできます。匿名での献金も可能で、ログインは不要です。
:::

## ステップ6：継続的な管理

献金記録を最新の状態に保ち、年間を通して報告書を作成しましょう。

1. 記録を最新に保つため、[Stripeの取引をインポート](../donations/stripe-import.md)を定期的に（毎週または毎月）行います
2. [献金レポートを表示](../donations/donation-reports.md)して、献金の傾向や基金ごとの合計を確認します
3. 寄付者の税務用に[年間献金明細書を作成](../donations/giving-statements.md)します

:::tip
記録を最新に保つため、Stripeのインポートは少なくとも月に1回行いましょう。年末の全作業については[年次レポートガイド](./year-end-reports.md)をご覧ください。
:::

## 完了です

これで教会でオンライン献金を受け付けられるようになりました。メンバーはウェブサイト、B1アプリ、またはウェブブラウザが使えるどの端末からでも献金できます。すべての献金は自動的にB1 Adminで記録されます。
