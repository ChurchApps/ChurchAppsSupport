# オンライン献金を設定する

<div class="article-intro">

教会でオンライン献金を受け付けるために必要な手順を説明します。献金基金の作成、支払い処理のためのStripeの接続、会衆への献金ページの共有までを行います。完了すると、会員はウェブサイトやモバイルアプリからオンラインで献金できるようになります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 管理者権限を持つB1 Adminアカウント。[役割と権限](../people/roles-permissions.md)を参照してください
- Stripeアカウント（必要な場合は [stripe.com](https://stripe.com) で無料で作成できます）

</div>

## ステップ1：献金基金を作成する

基金とは、献金者が献金できるカテゴリのことです。献金を受け付けるには、少なくとも1つの基金が必要です。

[基金](../donations/funds.md)のガイドに従って、献金カテゴリを設定してください。

1. よく使われる基金を作成します（例：「一般基金」「建築基金」「宣教」）
2. 税控除の対象となる基金には適切に印を付けます。これは年末の献金明細書に影響します

:::tip
基金はいつでも追加できます。まずはよく使われる献金カテゴリから始めてください。
:::

## ステップ2：Stripeを接続する

支払い処理はすべてStripeが行います。献金が銀行口座に入金されるように、StripeアカウントをB1 Adminに接続します。

[オンライン献金の設定](../donations/online-giving-setup.md)のガイドに従って、Stripeを接続してください。

1. Stripeのダッシュボードにログインし、公開可能キー（Publishable Key）とシークレットキー（Secret Key）を取得します
2. B1 Adminで「設定」に進み、両方のキーを入力します

:::warning
Stripeでシークレットキーが表示されるのは一度だけです。Stripeのダッシュボードを離れる前にコピーして保存してください。紛失した場合は、新しいキーを生成する必要があります。
:::

## ステップ3：ウェブサイトに献金ページを追加する

B1のウェブサイトに献金ページを追加して、献金しやすくしましょう。

[オンライン献金の設定](../donations/online-giving-setup.md)と[ページの管理](../website/managing-pages.md)のガイドに従って、次の作業を行います。

1. B1.churchサイトに「寄付」タブを追加します
2. 献金ページのURLは `https://yoursubdomain.b1.church/donate` になります
3. 会員はログインせずに献金できます（公開ページ）。ログインすると、保存済みの支払い方法や献金履歴を利用できます

## ステップ4：テスト献金を行う

会衆に告知する前に、すべてが正しく動作するか確認してください。

1. 少額のテスト献金を行い、処理の流れ全体が機能することを確認します
2. B1 Adminの「献金」で、その献金が表示されているか確認します

:::tip
実際に課金せずに確認したい場合は、まずStripeのテストモードを使用してください。その後、会衆に告知する前にライブモードに切り替えてください。
:::

## ステップ5：会衆に告知する

オンラインで献金できることを、会員に知らせましょう。

1. ウェブサイト、メールマガジン、週報、ソーシャルメディアで献金URLを共有します
2. 会員は[B1モバイルアプリ](../../b1-church/giving/index.md)からも献金できます。献金機能はアプリに組み込まれています

:::info
ログインした会員は、支払い方法の保存、定期献金の設定、献金履歴の確認ができます。匿名での献金も可能で、ログインは不要です。
:::

## ステップ6：継続的な管理

献金記録を最新の状態に保ち、年間を通じてレポートを作成しましょう。

1. 定期的（毎週または毎月）に[Stripeの取引をインポート](../donations/stripe-import.md)して、記録を最新の状態に保ちます
2. [献金レポートを確認](../donations/donation-reports.md)して、献金の傾向や基金ごとの合計を把握します
3. 献金者の税務記録のために、[年末の献金明細書を作成](../donations/giving-statements.md)します

:::tip
記録を最新の状態に保つため、Stripeのインポートは少なくとも毎月実行してください。年末の全手順については、[年末レポートのガイド](./year-end-reports.md)を参照してください。
:::

## 完了です！

教会でオンライン献金の受け付けが始まりました。会員は、ウェブサイト、B1モバイルアプリ、またはウェブブラウザを搭載したあらゆる端末から献金できます。すべての献金はB1 Adminで自動的に記録されます。
