# 教会のウェブサイトを公開する

<div class="article-intro">

B1.church には、追加料金なしで使える本格的なウェブサイト作成ツールが含まれています。このガイドでは、教会のウェブサイトをゼロから作成する手順を説明します。ホームページの設定、外観のカスタマイズ、主要ページの追加、そして必要に応じてオンライン献金やイベント登録フォームの接続までを扱います。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 教会のロゴを用意してください（背景が透明な PNG が最適です）
- サイトのブランドカラーを 2〜3 色選んでください
- 独自ドメイン（例：yourchurch.com）を使う場合は、DNS プロバイダー（GoDaddy、Cloudflare など）の管理画面にアクセスできるようにしてください
- サイトでオンライン献金を利用したい場合は、先に [オンライン献金の設定](../donations/online-giving-setup.md)（Stripe）を完了してください

</div>

## ステップ 1：ウェブサイトの初期設定

まずはホームページと基本的なサイト構成を作成します。

[ウェブサイトの初期設定](../website/initial-setup.md) ガイドに従って、次の操作を行います。

1. B1 Admin で **Website** に移動します
2. ヒーローセクション、ウェルカムメッセージ、主要な情報を含むホームページを作成します
3. 教会の名称とキャッチフレーズを追加します

## ステップ 2：外観の設定

サイトの色、フォント、ロゴ、フッターなど、ビジュアルのアイデンティティを設定します。

[外観](../website/appearance.md) ガイドに従って、次の操作を行います。

1. 教会のロゴをアップロードします
2. メインカラーとアクセントカラーを設定します
3. ナビゲーションバーとフッターを設定します
4. 変更内容をプレビューします

:::tip
カラーパレットはシンプルに保ちましょう。メインカラーとアクセントカラーを 1 色ずつ選べば、通常は十分です。残りの調整はウェブサイトビルダーが行ってくれます。
:::

## ステップ 3：コンテンツページを追加する

訪問者が最も必要とするページを作成します。

[ページの管理](../website/managing-pages.md) ガイドに従って、次のようなページを作成します。

- **About** — 教会の歩み、信仰の内容、指導者の紹介
- **Sermons** — [説教ライブラリ](../sermons/managing-sermons.md)へのリンク
- **Events** — 今後のイベントと登録
- **Give** — オンライン献金のページ（[Stripe の設定](../donations/online-giving-setup.md)が必要です）
- **Contact** — 所在地、礼拝の時間、連絡先情報

## ステップ 4：独自ドメインを接続する

デフォルトの B1 の URL ではなく、独自のドメイン名（yourchurch.com など）を使いたい場合は、次の手順を行います。

1. B1 Admin で **Settings** を開き、**Domains** セクションに移動します
2. 独自ドメインを入力します
3. ドメインプロバイダーの管理画面で DNS レコードを更新し、B1 を指すように設定します

:::info
DNS の変更が反映されるまで最長 48 時間かかることがあります。その間、独自ドメインではサイトにすぐアクセスできない場合があります。反映されるまでの間も、デフォルトの B1 の URL は引き続き利用できます。
:::

## ステップ 5：献金とフォームを追加する

インタラクティブな要素を加えて、サイトを充実させましょう。

- **オンライン献金** — 会員がウェブサイトから直接献金できるセクションを追加します。まず [オンライン献金の設定](../donations/online-giving-setup.md) で Stripe を設定してください。
- **登録フォーム** — イベントの申し込み、訪問者カード、ボランティアの応募用に、[スタンドアロンフォーム](../forms/creating-forms.md)を埋め込めます。任意のページにフォーム要素を追加する方法は、[ページの管理](../website/managing-pages.md)を参照してください。

## 完了です！

教会のウェブサイトが公開されました。URL を会衆やソーシャルメディアで共有しましょう。コンテンツの更新、ページの追加、外観の調整は、いつでも B1 Admin のダッシュボードから行えます。
