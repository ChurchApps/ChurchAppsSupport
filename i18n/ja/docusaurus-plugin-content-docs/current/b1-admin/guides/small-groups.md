# スモールグループを運営する

<div class="article-intro">

メンバー管理、グループカレンダー、会話機能を使って、スモールグループ、聖書研究会、ミニストリーチームを設定しましょう。教会全体のイベントカレンダーをウェブサイトに公開すると、訪問者は教会の活動を確認でき、メンバーはWebポータルとモバイルアプリを通じてつながりを保てます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 管理者アクセス権のあるB1 Adminアカウント
- [ディレクトリに登録された人物](../people/adding-people.md)（グループメンバーは事前に登録されている必要があります）

</div>

## ステップ1: グループのカテゴリとグループを作成する

グループをカテゴリに分類すると、メンバーが探しているグループを簡単に見つけられます。

[グループの作成](../groups/creating-groups.md)ガイドに従って、次の作業を行います。

1. グループを整理するためのカテゴリを作成します（例：「スモールグループ」「聖書研究」「ミニストリーチーム」「委員会」）
2. 各カテゴリ内にグループを作成します（例：「火曜夜の男性グループ」「女性の聖書研究会」「青年ミニストリー」）
3. 各グループに説明と集まりの時間を追加します

## ステップ2: メンバーとリーダーを追加する

グループにメンバーを追加し、自分のチームを管理できるリーダーを任命します。

[グループメンバー](../groups/group-members.md)ガイドに従って、次の作業を行います。

1. 人物を検索し、適切なグループに追加します
2. 星のアイコン（**リーダーに設定**）を使ってグループリーダーを任命します。リーダーには追加の権限が与えられます

:::tip
グループリーダーは、管理者としての完全なアクセス権がなくても、自分のグループのカレンダーを管理し、会話を投稿し、イベントを調整できます。
:::

## ステップ3: グループカレンダーを設定する

各グループに、集まりやイベント用のカレンダーを用意しましょう。

[グループカレンダー](../groups/group-calendar.md)ガイドに従って、次の作業を行います。

1. 定期的な集まり（例：「毎週火曜日の午後7時」）と単発のイベント（例：「グループのバーベキュー - 3月15日」）を追加します
2. グループリーダーは、自分のグループのイベントを追加・管理できます

## ステップ4: 教会全体のカレンダーを作成する

すべてのグループのイベントを一つの統合カレンダーにまとめ、教会全体で共有します。

[カレンダーの作成](../calendars/creating-calendars.md)と[キュレーションカレンダー](../calendars/curated-calendar.md)ガイドに従って、次の作業を行います。

1. 複数のグループからイベントを集めて一つの統合ビューに表示するキュレーションカレンダーを作成します
2. ICSの購読リンクを共有すると、メンバーは個人のカレンダーアプリ（Googleカレンダー、Appleカレンダー、Outlook）にイベントを追加できます

:::info
キュレーションカレンダーは、接続されたグループのイベントを自動的にまとめます。グループリーダーがイベントを追加すると、教会のカレンダーにも表示されます。
:::

## ステップ5: ウェブサイトに公開する

グループとカレンダーを、B1ウェブサイト上で訪問者やメンバーに見えるようにします。

[ページの管理](../website/managing-pages.md)ガイドに従って、次の作業を行います。

1. B1ウェブサイトにカレンダーセクションを追加し、キュレーションカレンダーを表示します
2. グループセクションを追加し、訪問者が参加可能なグループを閲覧し、参加方法を知ることができるようにします

## ステップ6: メンバーの体験

メンバーは、スマートフォンやパソコンからグループを探し、参加し、活動に加わることができます。

1. メンバーは[B1.church](../../b1-church/groups/browsing-groups.md)でグループを閲覧し、参加できます
2. グループメンバーは詳細やカレンダーを確認でき、[会話](../../b1-church/groups/conversations.md)に投稿できます
3. グループの機能はすべて[B1モバイルアプリ](../../b1-church/groups/index.md)でも利用できます

:::info
メンバーは、ウェブでもモバイルでも、自分のグループ、今後のイベント、グループの会話を確認できます。すべてが常に同期されています。
:::

## 完了です！

スモールグループの設定と接続が完了しました。メンバーはグループを探し、イベントを確認し、会話を通じてつながりを保てます。これらはすべてウェブサイトとモバイルアプリで利用できます。グループリーダーは、自分のチームを独立して管理できます。
