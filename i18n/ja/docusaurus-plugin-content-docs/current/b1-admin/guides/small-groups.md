# 小グループを運営する

<div class="article-intro">

メンバー管理、グループカレンダー、会話機能を使って、小グループ、聖書研究会、奉仕チームを設定しましょう。ウェブサイトに教会全体のイベントカレンダーを公開すると、訪問者は行事を確認でき、メンバーはウェブポータルやモバイルアプリを通じてつながり続けられます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 管理者権限を持つ B1 Admin のアカウント
- [名簿への人の追加](../people/adding-people.md)（グループのメンバーは事前に名簿に登録されている必要があります）

</div>

## ステップ 1：グループのカテゴリとグループを作成する

グループをカテゴリに分けて整理しておくと、メンバーが探しているグループを見つけやすくなります。

[グループの作成](../groups/creating-groups.md)のガイドに従って、次の作業を行ってください。

1. グループを整理するためのカテゴリを作成する（例：「小グループ」「聖書研究会」「奉仕チーム」「委員会」）
2. 各カテゴリ内にグループを作成する（例：「火曜夜の男性グループ」「女性の聖書研究会」「青年奉仕」）
3. 各グループに説明と集会の時間を追加する

## ステップ 2：メンバーとリーダーを追加する

グループにメンバーを登録し、自分のチームを管理できるリーダーを指定します。

[グループメンバー](../groups/group-members.md)のガイドに従って、次の作業を行ってください。

1. 人を検索し、適切なグループに追加する
2. 星のアイコン（**Make Leader**）を使ってグループリーダーを指定する。リーダーには追加の権限が与えられます

:::tip
グループリーダーは、管理者の完全な権限がなくても、自分のグループのカレンダーを管理し、会話を投稿し、行事を調整できます。
:::

## ステップ 3：グループカレンダーを設定する

各グループに、集会やイベント用のカレンダーを用意しましょう。

[グループカレンダー](../groups/group-calendar.md)のガイドに従って、次の作業を行ってください。

1. 定期的な集会（例：「毎週火曜日 19時」）と単発のイベント（例：「グループのバーベキュー - 3月15日」）を追加する
2. グループリーダーは、自分のグループのイベントを追加・管理できます

## ステップ 4：教会全体のカレンダーを作成する

すべてのグループのイベントを、教会全体のための一つのカレンダーにまとめます。

[カレンダーの作成](../calendars/creating-calendars.md)と[キュレーションカレンダー](../calendars/curated-calendar.md)のガイドに従って、次の作業を行ってください。

1. 複数のグループからイベントを集めて一つの統合ビューに表示するキュレーションカレンダーを作成する
2. ICS の購読リンクを共有し、メンバーが個人のカレンダーアプリ（Google カレンダー、Apple カレンダー、Outlook）にイベントを追加できるようにする

:::info
キュレーションカレンダーは、接続されたグループのイベントを自動的にまとめます。グループリーダーがイベントを追加すると、それが教会のカレンダーにも表示されます。
:::

## ステップ 5：ウェブサイトに公開する

B1 ウェブサイト上で、訪問者とメンバーにグループとカレンダーを見えるようにします。

[ページの管理](../website/managing-pages.md)のガイドに従って、次の作業を行ってください。

1. キュレーションカレンダーを表示するカレンダーのセクションを B1 ウェブサイトに追加する
2. 訪問者が参加可能なグループを確認し、参加方法を知ることができるよう、グループのセクションを追加する

## ステップ 6：メンバーの体験

メンバーは、スマートフォンやパソコンからグループを見つけ、参加し、活動に加わることができます。

1. メンバーは [B1.church](../../b1-church/groups/browsing-groups.md) でグループを探して参加する
2. グループのメンバーは、詳細やカレンダーを確認し、[会話](../../b1-church/groups/conversations.md)に投稿できる
3. グループに関するすべての機能は [B1 App](../../b1-church/groups/index.md) でも利用できる

:::info
メンバーは、ウェブでもモバイルでも、自分のグループ、今後のイベント、グループの会話を確認できます。すべての情報は常に同期されています。
:::

## 完了です！

小グループの設定と接続が完了しました。メンバーはグループを見つけ、イベントを確認し、会話を通じてつながり続けられます。これらはすべて、ウェブサイトとモバイルアプリで利用できます。グループリーダーは、それぞれのチームを独立して管理できます。
