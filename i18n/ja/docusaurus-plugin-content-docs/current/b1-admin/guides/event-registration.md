# イベント登録を設定する

<div class="article-intro">

イベント登録フォームを作成し、参加者の情報や任意の支払いを収集して、教会のWebサイトに埋め込み、届いた申し込みを管理します。この手順を終えると、教会のどのイベントにも使える共有可能な登録ページができあがります。

</div>

:::info
**イベント登録の方法は2つあります：** このガイドでは**フォームによる登録**を扱います。カスタム項目や支払いの収集を細かく管理できます。参加者を把握するだけの簡単なイベントでは、カレンダーに組み込まれた**ネイティブのイベント登録**を使ってください。設定方法は[カレンダーの作成](../calendars/creating-calendars.md#enabling-event-registration)を参照してください。ネイティブ登録では、メンバーが定員管理、受付期間、確認メールに対応した状態で[B1 Webサイト](../../b1-church/events/registering.md)や[モバイルアプリ](../../b1-church/events/registering.md)から直接申し込めます。
:::

<div class="prereqs">
<h4>始める前に</h4>

- 管理者権限のあるB1 Adminアカウント
- 支払いを収集する場合：先に[Stripeの設定](../donations/online-giving-setup.md)が必要です

</div>

## ステップ1：スタンドアロンフォームを作成する

スタンドアロンフォームには、誰でもアクセスできる専用の公開URLがあります。イベント登録に最適です。

[フォームの作成](../forms/creating-forms.md)ガイドに従って、次の操作を行います：

1. フォームに移動し、「フォームを追加」をクリックします
2. 種類として「スタンドアロン」を選びます。これにより、フォーム専用の公開URLが作られます
3. イベント名を付けます（例：「男性リトリート登録」「VBSお申し込み」）

## ステップ2：質問を追加する

登録者から集める必要のある項目を作成します。

[フォームの作成](../forms/creating-forms.md#adding-questions)ガイドに従って質問を追加します：

1. 「質問」タブに移動し、必要な情報の項目を追加します。名前、メールアドレス、電話番号、食事制限、Tシャツのサイズ、緊急連絡先などです
2. 食事の希望や参加するセッションの選択など、選択肢がある場合は複数選択を使います

:::warning
支払い項目の種類を使うには、Stripeの設定が必要です。オンライン献金をまだ設定していない場合は、支払い項目を追加する前に[オンライン献金の設定](../donations/online-giving-setup.md)を確認してください。
:::

## ステップ3：フォームの設定を行う

登録フォームをいつ、どのように利用できるかを管理します。

1. 登録の受付を期間限定にする場合は、受付期間を設定します
2. 公開URLをコピーします。このURLをそのまま共有できます
3. 申し込みの管理を手伝ってもらうために、「管理者」または「閲覧のみ」の権限を持つフォームメンバーを追加します

## ステップ4：Webサイトに埋め込む

教会のWebサイトに追加して、登録フォームを見つけやすくします。

[ページの管理](../website/managing-pages.md)ガイドに従って次の操作を行います：

1. B1 Webサイトのエディターで、ページに新しいセクションを追加し、フォーム要素を選択します
2. 一覧から登録フォームを選びます

:::tip
スタンドアロンのURLは、メール、SNS、教会の週報でも共有してください。目に触れる場所が多いほど、申し込みも増えます。
:::

## ステップ5：申し込みを管理する

届いた登録を確認し、必要なときにデータを書き出します。

[フォームの回答の管理](../forms/managing-submissions.md)ガイドに従って次の操作を行います：

1. 「回答」タブで、届いた回答を順番に確認します
2. 表計算ソフトでの利用、人数の集計、イベント担当者との共有のために、CSVに書き出します

## 完了です！

イベント登録が公開されました。リンクを共有し、Webサイトに埋め込んで、B1 Adminから申し込み状況を確認してください。イベントが終わったら、記録用に最終的な一覧を書き出してください。
