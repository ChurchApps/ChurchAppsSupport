# イベント登録を設定する

<div class="article-intro">

イベント登録フォームを作成し、参加者情報とオプションの支払いを収集して、教会のウェブサイトに埋め込み、届いた申し込みを管理します。完了すると、どの教会イベントにも使える共有可能な登録ページができています。

</div>

:::info
**イベント登録の2つの方法：** このガイドでは**フォームベースの登録**を扱います。カスタム項目や支払い受付を細かく管理できます。参加者を把握するだけの簡単なイベントには、カレンダーに組み込まれた**ネイティブのイベント登録**を使ってください。設定方法は[カレンダーの作成](../calendars/creating-calendars.md#enabling-event-registration)をご覧ください。ネイティブ登録では、定員管理、受付期間、確認メールを備えた登録を、[B1.church または B1 App](../../b1-church/events/registering.md)から会員が直接行えます。
:::

<div class="prereqs">
<h4>始める前に</h4>

- 管理者権限を持つB1 Adminアカウント
- 支払いを受け付ける場合：先に[Stripeの設定](../donations/online-giving-setup.md)が必要です

</div>

## ステップ1：スタンドアロンフォームを作成する

スタンドアロンフォームには、誰でもアクセスできる専用の公開URLがあります。イベント登録に最適です。

[フォームの作成](../forms/creating-forms.md)ガイドに従って、次の手順を行います。

1. フォームに移動し、「フォームを追加」をクリックします
2. 種類として「スタンドアロン」を選びます。これでフォームに専用の公開URLが割り当てられます
3. イベント名を付けます（例：「男性研修会の申し込み」「VBSの申し込み」）

## ステップ2：質問を追加する

登録者から集めたい項目を設定します。

[フォームの作成](../forms/creating-forms.md#adding-questions)ガイドに従って質問を追加します。

1. 「質問」タブに移動し、必要な情報の項目を追加します。例：氏名、メールアドレス、電話番号、食事制限、Tシャツのサイズ、緊急連絡先など
2. 食事の希望や参加するセッションの選択など、選択肢がある場合は複数選択を使います

:::warning
支払い項目の種類を使うには、Stripeの設定が必要です。まだオンライン献金を設定していない場合は、支払い項目を追加する前に[オンライン献金の設定](../donations/online-giving-setup.md)をご覧ください。
:::

## ステップ3：フォームの設定を行う

登録フォームをいつ、どのように利用可能にするかを設定します。

1. 登録の受付を期間限定にする場合は、受付期間を設定します
2. 公開URLをコピーします。このURLをそのまま共有できます
3. 申し込みの管理を手伝ってもらうため、「管理者」または「閲覧のみ」の権限を持つメンバーを追加します

## ステップ4：ウェブサイトに埋め込む

教会のウェブサイトに追加して、登録フォームを見つけやすくします。

[ページの管理](../website/managing-pages.md)ガイドに従って次の手順を行います。

1. B1のウェブサイトエディタで、ページに新しいセクションを追加し、フォーム要素を選択します
2. 一覧から登録フォームを選びます

:::tip
スタンドアロンのURLは、メール、SNS、教会の週報でも共有しましょう。目に触れる場所が増えるほど、申し込みも増えます。
:::

## ステップ5：申し込みを管理する

届いた登録を確認し、必要なときにデータを書き出します。

[申し込みの管理](../forms/managing-submissions.md)ガイドに従って次の手順を行います。

1. 「申し込み」タブで、届いた回答を確認します
2. 表計算ソフトでの利用、参加人数の把握、イベント担当者との共有のために、CSVに書き出します

## 完了です

イベント登録が公開されました。URLを共有し、ウェブサイトに埋め込み、B1 Adminで申し込み状況を確認しましょう。イベント終了後は、記録用に最終的な一覧を書き出してください。
