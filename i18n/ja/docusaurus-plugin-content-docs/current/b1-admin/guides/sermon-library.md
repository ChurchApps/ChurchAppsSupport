# 説教ライブラリとライブ配信の構築

<div class="article-intro">

既存の説教動画をオンラインで公開し、ライブ配信を設定しましょう。YouTube や Vimeo の既存ライブラリの取り込みから、対話型チャット付きの定期ライブ礼拝のスケジュール設定まで、手順をご紹介します。完了すると、会衆はウェブサイトやモバイルアプリで過去の説教を視聴し、ライブ礼拝に参加できるようになります。

</div>

## トレーニング動画

<div class="prereqs">
<h4>始める前に</h4>

- コンテンツ管理権限を持つ B1 Admin アカウント
- 説教動画を掲載した YouTube または Vimeo のチャンネル（既存のアーカイブを取り込む場合）
- YouTube チャンネル ID（ライブ配信に使用します。YouTube Studio の設定で確認できます）

</div>

## ステップ 1：説教プレイリストを作成する

プレイリストを使うと、説教をシリーズやコレクションごとに整理でき、閲覧しやすくなります。

[プレイリスト](../sermons/playlists.md)のガイドに従って、次の作業を行ってください。

1. 「2024 年の日曜礼拝」「結婚シリーズ」「クリスマス礼拝」などのシリーズやコレクションを作成する
2. 各プレイリストに、名前、説明、公開日、サムネイルを入力する

:::tip
説教を追加する前にプレイリストを作成しておきましょう。そうすると、説教を追加しながら適切なシリーズに振り分けやすくなります。
:::

## ステップ 2：既存の説教を取り込む

YouTube や Vimeo にすでに説教動画がある場合は、まとめて一括で取り込めます。

[一括インポート](../sermons/bulk-import.md)のガイドに従って、次の作業を行ってください。

1. YouTube または Vimeo のチャンネル URL を入力する
2. プレビューを表示し、取り込まれる動画を確認する
3. 「インポート」をクリックして、すべての動画を一度に追加する

## ステップ 3：説教を個別に追加する

単発で追加する説教や、一括インポートに含まれない説教は、個別に追加します。

[説教の管理](../sermons/managing-sermons.md)のガイドに従って、次の作業を行ってください。

1. 動画の URL（YouTube、Vimeo、Facebook のいずれか）を貼り付ける
2. タイトル、説明、サムネイル、再生時間は動画のメタデータから自動的に入力される
3. 説教をプレイリストに割り当てる

## ステップ 4：ライブ配信を設定する

YouTube チャンネルを連携させると、B1 のサイトでライブ配信が自動的に表示されるようになります。

[ライブ配信](../sermons/live-streaming.md)のガイドに従って、次の作業を行ってください。

1. 配信設定で YouTube チャンネル ID を入力する
2. 定期礼拝のスケジュールを設定する（例：毎週日曜日の午前 10 時）
3. **Sermons > Settings** ページで、配信ページのタブ（チャット、祈りの课題、カスタムリンク）をカスタマイズする

:::info
YouTube でライブ配信を開始すると、B1 の配信ページに自動的に配信が表示されます。日曜日の朝に追加の操作は必要ありません。
:::

## ステップ 5：ウェブサイトに掲載する

説教ライブラリとライブ配信を、訪問者が簡単に利用できるようにしましょう。

[ページの管理](../website/managing-pages.md)のガイドに従って、次の作業を行ってください。

1. B1 ウェブサイトに説教のセクションを追加し、訪問者がライブラリを閲覧できるようにする
2. ライブ配信のセクションを追加し、ライブ視聴の体験を提供する

## ステップ 6：モバイルからのアクセス

会員は、どのデバイスからでも説教やライブ礼拝にアクセスできます。

1. 会員は [B1 Mobile アプリ](../../b1-church/content/sermons.md)および [B1.church](../../b1-church/content/sermons.md) で説教を視聴できます
2. チャット付きのライブ配信は、両方のプラットフォームで利用できます

:::info
ライブチャット機能を使うと、オンラインの会衆がリアルタイムで参加できます。まるで会場に一緒にいるような体験になります。
:::

## 完了です

説教ライブラリがオンラインで公開され、ライブ配信の設定も完了しました。会員はいつでも過去の説教を視聴でき、どこからでもライブ礼拝に参加できます。新しい説教の動画は自動的に同期されるようになります。
