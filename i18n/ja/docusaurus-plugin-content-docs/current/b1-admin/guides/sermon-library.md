# 説教ライブラリとライブ配信の構築

<div class="article-intro">

既存のYouTubeまたはVimeoのライブラリをインポートするところから、説教アーカイブをオンラインにし、ライブ配信を設定するまで。双方向のチャット付きで定期的なライブ礼拝をスケジュールできます。完了すると、会衆はウェブサイトやモバイルアプリで過去の説教を視聴したり、ライブ礼拝に参加したりできるようになります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- コンテンツ管理の権限を持つB1 Adminアカウント
- 説教動画があるYouTubeまたはVimeoのチャンネル（アーカイブのインポート用）
- YouTubeチャンネルID（ライブ配信用。YouTube Studioの設定で確認できます）

</div>

## ステップ1：説教プレイリストを作成する

プレイリストは、説教をシリーズやコレクションに分類し、見つけやすくします。

[プレイリスト](../sermons/playlists.md)のガイドに従って、次の作業を行います。

1. 「2024年日曜メッセージ」「結婚シリーズ」「クリスマス礼拝」などのシリーズやコレクションを作成する
2. 各プレイリストに名前、説明、公開日、サムネイルを追加する

:::tip
説教を追加する前にプレイリストを作成しましょう。説教を追加する際に、適切なシリーズへ整理しやすくなります。
:::

## ステップ2：既存の説教をインポートする

YouTubeやVimeoに説教動画がすでにある場合は、まとめて一度に取り込めます。

[一括インポート](../sermons/bulk-import.md)のガイドに従って、次の作業を行います。

1. YouTubeまたはVimeoのチャンネルURLを入力する
2. インポートをプレビューして、取り込まれる動画を確認する
3. 「インポート」をクリックして、すべてを一度に追加する

## ステップ3：個別の説教を追加する

単発で追加する場合や、一括インポートに含まれない説教は、個別に追加します。

[説教の管理](../sermons/managing-sermons.md)のガイドに従って、次の作業を行います。

1. 動画のURL（YouTube、Vimeo、Facebook）を貼り付ける
2. タイトル、説明、サムネイル、再生時間は動画のメタデータから自動入力される
3. 説教をプレイリストに割り当てる

## ステップ4：ライブ配信を設定する

YouTubeチャンネルを接続すると、B1のサイトがライブ配信を自動的に取得します。

[ライブ配信](../sermons/live-streaming.md)のガイドに従って、次の作業を行います。

1. 配信設定にYouTubeチャンネルIDを入力する
2. 定期的な礼拝のスケジュールを設定する（例：毎週日曜日の午前10時）
3. **説教 > 設定**ページで配信ページのタブ（チャット、祈りの課題、カスタムリンク）をカスタマイズする

:::info
YouTubeでライブを開始すると、B1の配信ページが自動的にその配信を取得します。日曜の朝に追加の操作は必要ありません。
:::

## ステップ5：ウェブサイトに表示する

説教ライブラリとライブ配信を、訪問者がすぐに利用できるようにします。

[ページの管理](../website/managing-pages.md)のガイドに従って、次の作業を行います。

1. B1ウェブサイトに説教のセクションを追加し、訪問者がライブラリを閲覧できるようにする
2. ライブ視聴のためのライブ配信セクションを追加する

## ステップ6：モバイルでのアクセス

メンバーは、どのデバイスからでも説教やライブ礼拝にアクセスできます。

1. メンバーは[B1.churchおよびB1アプリ](../../b1-church/content/sermons.md)で説教を視聴できる
2. チャット付きのライブ配信は、スマートフォンとパソコンのどちらでも利用できる

:::info
ライブチャット機能により、オンラインの会衆もリアルタイムで参加できます。会場にいるのと同じように礼拝に加わることができます。
:::

## 完了です！

説教ライブラリがオンラインになり、ライブ配信の設定も完了しました。メンバーはいつでも過去の説教に追いつくことができ、どこからでもライブ礼拝に参加できます。新しい説教の動画は自動的に同期されるようにできます。
