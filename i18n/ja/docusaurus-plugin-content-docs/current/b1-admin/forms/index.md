# フォーム

<div class="article-intro">

フォームのセクションでは、登録、アンケート、データ収集などに使えるカスタムフォームを作成できます。来場者カード、イベントの申し込み、祈りの依頼フォームなど、必要なフォームをここで作成し、公開リンクや B1.church のウェブサイトを通じて会衆と共有できます。

</div>

## フォームのページ

**フォーム**を開くと、次のタブが表示されます。

- **フォーム** -- 有効なフォームがすべて表示されます。
- **アーカイブ済みフォーム** -- アーカイブされたフォームが表示されます。アーカイブ済みのフォームはいつでも復元できます。このタブは、少なくとも 1 つのフォームがアーカイブされると表示されます。

一覧の各フォームには、名前と、設定されている場合は外部に共有できる公開 URL が表示されます。

## できること

フォームのページでは、次の操作ができます。

- **フォームを追加** -- **フォームを追加**をクリックして、新しいカスタムフォームを作成します。
- **フォームを検索** -- **フォームを検索**のボックスに入力すると、名前で一覧を絞り込めます。
- **フォームを編集** -- フォーム名をクリックして開くと、質問、メンバー、設定を変更できます。
- **フォームをアーカイブ** -- 不要になったフォームを**アーカイブ済みフォーム**タブに移動すると、一覧を整理できます。
- **フォームを復元** -- **アーカイブ済みフォーム**タブに切り替えて、有効に戻したいフォームを復元します。

## フォームの操作

フォーム名をクリックして開きます。フォームエディターには最大 3 つのタブがあります。

- **質問** -- さまざまな種類の項目を追加して、フォームの構成を作成します。詳しくは [フォームの作成](./creating-forms.md) を参照してください。
- **フォームメンバー** -- フォームへのアクセスと管理ができるユーザーを設定します(独立したフォームの場合のみ)。
- **フォームの回答** -- 送信された回答を表示します。詳しくは [回答の管理](./managing-submissions.md) を参照してください。

:::tip
公開 URL があるフォームは、リンクで共有したり、ウェブサイトに埋め込んだり、メールに含めたりできます。教会のアカウントを持たない人からも、簡単に情報を集められます。
:::

:::info
**フォームメンバー**タブを使うと、各フォームへのアクセス権を管理できます。**管理者**または**閲覧のみ**の役割を割り当てると、チームに適切なレベルのアクセス権を与えられます。
:::
