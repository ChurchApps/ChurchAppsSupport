# フォームの作成

<div class="article-intro">

教会の会員から情報を集めるためのカスタムフォームを作成できます。イベントの参加登録、アンケート、訪問者カード、会員申し込みなどのフォームを作成できます。フォームはデータベース内の人物に紐付けることも、独自の公開URLを持つ単独のページとして使うこともできます。

</div>

- **支払い**を集めるフォームを使うには、[オンライン献金用にStripeを設定](../donations/online-giving-setup.md)しておく必要があります。

## 新しいフォームの作成

1. [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)(B1 Adminの左上にある検索バー)を開き、**People**を展開して**Forms**をクリックします。
2. **Add Form**をクリックします。
3. フォームの**名前**を入力します。
4. **Associate With**のドロップダウンからフォームの種類を選びます。
   - **People** — データベース内の[人物レコード](../people/adding-people.md)に回答を関連付けます。人物フォームは人物のレコードから入力されるため、共有可能なリンクは作成されません。
   - **Stand Alone** — 独自の公開URLを持つ独立したフォームを作成します。外部からの登録に最適です。スタンドアロンのフォームだけが[ヘッダー写真](#adding-a-header-photo)、[QRコード](#sharing-a-form-with-a-qr-code)、[紐付けたグループ](#linking-a-form-to-a-group)、そして**Create a person record from submissions**を利用できます。
5. **Save**をクリックしてフォームを作成します。

新しいフォームが一覧に表示されます。それをクリックして質問の追加を始めます。

## 白紙のフォームを印刷する {#printing-a-blank-form}

配布用の紙のコピーが必要ですか？受付で使う訪問者カードや、インターネットを利用できない人が手書きで記入するフォームなどです。フォーム一覧で該当フォームの横にある**Print**をクリックするとプレビューが開き、そこで**Print**をクリックします。空欄には各質問ごとに下線またはチェックボックスが印刷され、手書きで記入できます。必須の質問にはアスタリスクが付きます。ページの上部には、教会のロゴ([Website > Appearance](../website/appearance.md)で**Light Background Logo**をアップロードしている場合はそのロゴ)と教会名が表示され、その下にフォーム名が続きます。印刷オプションはこれ以外にありません。フォーム全体を印刷するか、何も印刷しないかのどちらかです。

## QRコードでフォームを共有する {#sharing-a-form-with-a-qr-code}

スタンドアロンのフォームには、フォーム一覧で横に**QR Code**リンクが表示されます(アーカイブされたフォームには表示されません)。それをクリックすると、フォームの公開URLのQRコードが開き、その下にリンクが表示されます。**Download PNG**をクリックすると、コードを画像として保存でき、週報に印刷したりスライドに表示したりできます。スマートフォンでスキャンした人は、そのままフォームを開けます。

## 質問の追加 {#adding-questions}

1. フォームを開いて**Questions**タブに移動します。
2. **Add Question**をクリックします。
3. Providerのドロップダウンから**フィールドの種類**を選びます。選べる種類は次のとおりです。
   - **Textbox** — 短いテキストの回答用
   - **Date** — 日付の選択用
   - **Email** — メールアドレス用
   - **Phone Number** — 電話番号の入力用
   - **Multiple Choice** — 用意された選択肢から選ぶ用
   - **Payment** — 支払いを受け付ける用
4. 質問の**Title**と、任意で**Description**を入力します。説明は、回答者がフォームに記入するときに質問の下に表示されます。「アレルギーがあれば教えてください。」のようなヒントを書くのに使えます。
5. 必須項目にする場合は**Require an answer**にチェックを入れます。
6. **Save**をクリックします。
7. 必要な数だけ繰り返して質問を追加します。

:::warning
**Payment**のフィールドを使うには、Stripeの設定が必要です。まだオンライン献金を設定していない場合は、支払いフィールドを追加する前に[オンライン献金の設定](../donations/online-giving-setup.md)をご覧ください。サインインせずにフォームで支払う人は、カードが受け付けられる前に**I'm not a robot**のチェックを入れる必要があります。
:::

## フォームのメンバーの管理 {#managing-form-members}

1. フォームを開いて**Form Members**タブに移動します。
2. 人物を検索し、役割を付けて追加します。
   - **Admin** — フォームの編集と全回答の閲覧ができます。
   - **View Only** — 回答の閲覧はできますが、フォームの編集はできません。

## フォームをグループに紐付ける {#linking-a-form-to-a-group}

スタンドアロンのフォームは、どのグループにも紐付けられます。たとえば、小グループ用の祈りの課題フォームや、青年部の旅行用の医療同意書などです。

1. フォームの**Details**を開きます。
2. **Linked group**の下で、グループを選択するか、**None**のままにします。
3. **Save**をクリックします。

フォームを紐付けると、次のようになります。

- **グループのメンバー**は、フォームが公開されている間、B1.churchのグループページにある**Forms**のセクションでフォームを確認できます。**Fill out**ボタンを押すとフォームが開きます([グループの詳細](../../b1-church/groups/group-details.md#linked-forms)を参照)。
- **グループのリーダー**は、公開が終わったフォームも確認でき、すべての回答を読んだり印刷したりできます(個別の回答または**Print all**)。リーダーは回答を閲覧できるだけで、[フォームのメンバー](#managing-form-members)でもない限りフォームを編集することはできません。
- **B1 Admin**では、グループのページに**Linked forms**のセクションが表示され、紐付けられた各フォームが**Open**または**Closed**と一覧表示されます。このセクションは、グループのリーダーとフォームを管理できる人に表示されます。詳しくは[グループメンバー](../groups/group-members.md#linked-forms)を参照してください。

フォームは、公開期間の外にあるときに閉じられた状態になります。アーカイブされたフォームはグループページに表示されません。

### 回答者をグループに自動的に追加する {#automatically-adding-submitters-to-a-group}

フォームをグループに紐付けただけでは、誰もグループに追加されません。回答者全員を紐付けたグループの名簿に加えるには、フォームの詳細で**Create a person record from submissions**も有効にし、**Save**をクリックします。

誰かがフォームを送信するたびに、一致した人物(または新しく作成された人物)がグループに追加されます(既にグループにいるメンバーはスキップされます)。たとえば、キャンプの申し込みフォームで、キャンプの名簿となるグループを自動的に作成したい場合に便利です。

### フォロー―アップのメールを送る

**Create a person record from submissions**を有効にしておくと、フォームを送信した人全員にメールを送ることもできます。フォームの詳細で**Follow-up Email Subject**と**Follow-up Email Body**に入力します。どちらにも`{firstName}`と`{churchName}`のトークンを使えます。メールは、両方の欄が入力されているときだけ送信されます。

:::info
フォローアップのメールは、教会がグループメールの送信を承認された後にのみ送信され、教会の1日あたりのメール送信数に含まれます。詳しくは[教会のグループメールを有効にする](../groups/group-members.md#turning-on-group-email-for-your-church)を参照してください。
:::

## フォームの複製

既存のフォームを新しいフォームの出発点として再利用するには、フォーム一覧でそのフォームの横にある**Duplicate**をクリックし、確認します。B1は、すべての質問を含む完全なコピーを作成します。その後、名前を変更したり、独立して編集したりできます。

:::tip
複製は、登録の質問が毎年変わらない定期イベントに便利です。昨年のフォームを複製して、名前と日付を更新すれば準備完了です。
:::

## フォームのプロパティの設定

フォームの名前や設定は、いつでも変更できます。スタンドアロンのフォームには、誰とでも共有できる固有の**公開URL**が表示されます。また、**Description**欄もあります。これは公開フォームのページで質問の上に表示されるテキストで、記入を始める前にフォームの目的を伝えるのに役立ちます。

### ヘッダー写真の追加 {#adding-a-header-photo}

スタンドアロンのフォームには、フォームの上部に**Header Photo**を表示できます。フォームの詳細で写真のボックスまたは**Add Photo**をクリックし、画像を選ぶかアップロードします(16:9の形に切り抜かれます)。**Save**をクリックします。写真は、フォーム名の下、説明の上に表示されます。公開URLのページや、Webサイトの**Form**要素でフォームを埋め込んだ場所にも表示されます。**Change Photo**で差し替えたり、**Remove**で削除したりできます。

**Thank You Message**欄には、フォームを送信した後に表示されるメッセージを設定します。フォームの公開URLのページにも表示されます。空欄のままにすると、「フォームを送信していただきありがとうございます！」と表示されます。

:::tip
スタンドアロンのフォームは、イベントの参加登録に最適です。公開URLをメール やSNSで共有したり、フォームを教会のWebサイトに直接埋め込んだりできます。
:::

:::info
フォームをB1のWebサイトに埋め込むには、Webサイトのエディターを開き、新しいセクションを追加して**Form**要素を選択します。次に、表示したいフォームを選びます。Webサイトの編集について詳しくは、[ページの管理](../website/managing-pages.md)を参照してください。
:::
