# フォーム回答の管理

<div class="article-intro">

フォームを公開すると、回答が届き始めます。**フォーム回答**タブでは、すべての回答を確認し、誰が回答したかを把握できます。また、そのデータを使って、会衆へのフォローアップを適切なタイミングで行えます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 質問を 1 つ以上含む[フォームを作成](./creating-forms.md)する
- フォームの公開 URL で共有するか、[ウェブサイト](../website/managing-pages.md)に埋め込む

</div>

## 回答の確認

1. [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin の左上にある検索バー）を開き、**People** を展開して、**Forms** をクリックします。
2. 確認したいフォームをクリックします。
3. **フォーム回答**タブに移動します。

そのフォームに届いたすべての回答が一覧で表示されます。各回答には回答者の情報と送信日が表示され、その後にフォームの質問ごとに 1 列ずつ並びます。質問が多いフォームでは、表を横にスクロールして残りの列を確認してください。

## 個別の回答の確認

任意の回答をクリックすると、詳細を確認できます。フォームの各質問に対して、その人が入力したすべての回答が表示されます。

回答の横にある**印刷アイコン**をクリックすると、その人の記入内容を印刷できます。紙の記録や、手元に保管が必要な署名入りの同意書がある場合に便利です。印刷物では、教会のロゴ（[ウェブサイト > 外観](../website/appearance.md)で設定した**明るい背景用ロゴ**。アップロードしている場合）が上部中央に表示され、その下に教会名が入ります。印刷物は、B1 Admin をダークモードで使っていても、常に白い紙に黒い文字で印刷されます。

これは[空白のフォームを印刷](./creating-forms.md#printing-a-blank-form)する機能とは別のものです。印刷されるのは、その人が送信済みの回答内容だけで、空のフォームではありません。同じ印刷アイコンは、回答が表示される場所（[人物のプロフィール](../people/adding-people.md#working-with-forms)など）にも表示されます。

## 回答者の変更

回答が誤った人物に紐付いている場合（たとえば、家族 2 人が同じメールアドレスを使っている場合）は、正しい人物に移動するか、紐付けを解除できます。

1. **フォーム回答**タブで、その人物の名前の横にある**担当者を変更**アイコン（2 つの矢印）をクリックします。同じアイコンは、[人物のプロフィール](../people/adding-people.md#working-with-forms)上の回答の横にも表示されます。
2. **担当者を変更**のダイアログで正しい人物を検索し、**この人物に移動**をクリックします。
3. または、**紐付けを解除（匿名）**をクリックして、回答をどの人物からも切り離します。その回答は**匿名**と表示されます。

変わるのは紐付けだけです。回答内容はそのままで、確認メールが再送されることもありません。

:::info
人物レコードを作成する設定のフォームで、教会のサイトにサインインした状態で送信された場合、回答はその人自身のレコードに紐付けられます。たとえ同じメールアドレスを持つ別の人物がデータベースにいても同様です。[2 つの人物レコードを統合](../people/adding-people.md)すると、削除された人物のフォーム回答は、残された人物に移動します。
:::

## 回答の収集方法

回答は複数の経路から届きます。

- **公開 URL** -- フォームに公開 URL がある場合（スタンドアロンフォーム）、そのリンクを持つ誰でも回答できます。URL はメール、ソーシャルメディア、テキストメッセージなどで共有できます。
- **ウェブサイトへの埋め込み** -- B1 のウェブサイトに埋め込まれたフォームは、訪問者が記入すると自動的に回答を収集します。
- **社内利用** -- スタッフやボランティアは、B1 Admin 内で他の人に代わってフォームを送信することもできます。

:::tip
訪問者カードや祈りのリクエストなどのフォームは、**フォーム回答**タブを定期的に確認して、すぐにフォローアップできるようにしましょう。
:::

## 回答データの活用

フォームで収集したデータは、次のような目的に役立ちます。

- イベントの参加登録を把握し、それに応じて準備する
- 訪問者や新しいメンバーにフォローアップする
- 奉仕計画に役立てるためのアンケート結果を集める
- イベントやプログラムの支払いを処理する

:::info
**管理者**または**閲覧のみ**の役割を持つフォームメンバーは、**フォーム回答**タブにアクセスできます。**フォームメンバー**タブで役割を管理し、チームの適切な人が必要なフォームにアクセスできるようにしてください。
:::

:::info
スタンドアロンフォームが[グループに紐付けられている](./creating-forms.md#linking-a-form-to-a-group)場合、そのグループのリーダーは、フォームメンバーでなくても、B1.church のグループページから回答を閲覧・印刷できます。また、リーダーは、そのグループのイベントの登録質問への回答もそこで確認できます。詳しくは[グループの詳細](../../b1-church/groups/group-details.md#linked-forms)をご覧ください。
:::

:::tip
**スタンドアロン**フォームが人物レコードを作成する設定の場合、既存の人物に一致した回答は、人物ページの**フォーム**セクションにも表示されます。人物ページに表示されるのは、People タイプのフォームの回答だけではありません。
:::
