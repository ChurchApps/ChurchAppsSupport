# B1 Adminのレッスンを教室のテレビに接続する

<div class="article-intro">

**FreePlay**を使うと、教室のテレビをB1 Adminのレッスンに接続できます。FreePlayは、ChurchAppsが教会向けに提供している無料のテレビアプリです。接続すると、テレビにB1 Adminでスケジュール設定したレッスンの内容が表示され、教室の画面上で教師が利用できるようになります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1 Adminでレッスンを少なくとも1つスケジュール設定する（[レッスンのスケジュール設定](./scheduling-lessons.md)を参照）
- 使用するテレビまたはFire Stickに**FreePlay**をインストールする

</div>

## ステップ1 — テレビにFreePlayをインストールする

教室のディスプレイに**FreePlay**アプリをインストールします。

- **Amazon Fire Stick / Fire TV** — Amazon Appstoreで**FreePlay**を検索する
- **Android TV / Google TV** — Google Playストアで**FreePlay**を検索する
- **Apple TV** — App Storeで**FreePlay**を検索する

セットアップの詳しい手順については、[FreePlay入門ガイド](/docs/freeplay/getting-started/)をご覧ください。

## ステップ2 — B1.churchをコンテンツプロバイダーとして接続する

1. テレビで**FreePlay**アプリを開く
2. **コンテンツプロバイダー**画面に移動する（サイドバーの**プロバイダー**アイコンを選択）
3. 利用可能なプロバイダーの一覧から**B1.church**を見つけて選択する
4. 画面の指示に従い、B1の教会アカウントでサインインする
5. 接続が成功すると、FreePlayに**Connected!**と表示される

接続が完了すると、B1.churchがFreePlayのサイドバーに表示されます。FreePlayはB1 Adminでスケジュール設定したレッスンの内容を取得するため、教師は教室のテレビでそのまま再生できます。

:::tip
接続後は、教師がテレビのリモコンを使い、レッスンの流れに合わせて動画やスライドを自分のペースで進められます。別途の設定やUSBドライブは必要ありません。
:::

:::info
認証方法（QRコード、フォームログインなど）の詳細については、[プロバイダーへの接続](/docs/freeplay/content-providers/connecting-providers)をご覧ください。
:::
