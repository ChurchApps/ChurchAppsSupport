# 奉仕

<div class="article-intro">

奉仕セクションは、ボランティアの調整と礼拝計画の中心となる場所です。日曜礼拝、平日の集まり、特別なイベントのいずれを企画する場合でも、ここにすべてをまとめることで、各チームが誰をいつ担当するのかを正確に把握できます。

</div>

## 奉仕ページの仕組み

**奉仕**ページを開くと、画面上部のタブに奉仕部門が表示されます。各部門には独自の計画タイプとチームがあるため、複数の部門を個別に管理できます。たとえば、礼拝、子どもメinistry、おもてなしなど、部門ごとにタブを分けることができます。

部門のメンバーである管理者以外のスタッフも、奉仕ページにアクセスできます。表示されるのは所属する部門のみで、完全な管理者権限がなくても、自分の部門の計画、担当割り当て、計画タイプ、礼拝の進行を作成・編集できます。

:::tip
管理者の場合、タブには所属する部門 (**自分の部門**) が表示されます。すべての部門を表示するには **すべて** を選択してください。複数のチームの担当割り当てを確認する必要があるときに便利です。教会に部門が多い場合は、**部門を検索** ボックスが表示され、名前でタブを絞り込めます。
:::

## サブセクション

奉仕セクションには、次の主要な領域があります。

- **[計画](./plans.md)** -- 特定の日付の礼拝計画を作成し、ボランティアをチームに割り当てます。計画により、誰がいつ奉仕するのかを事前に整理でき、全員が自分の役割をあらかじめ把握できます。[ボランティアへのリマインダー](./plans.md#volunteer-reminders)をプッシュ通知、メール、またはテキストメッセージで自動送信するよう設定すると、各礼拝の前にチームに通知できます。また、**[計画の概要](./plans-overview.md)** を使うと、複数週にわたるすべての今後の担当割り当てを1つのグリッドで確認できます。
- **[曲](./songs.md)** -- 歌詞、編曲、外部リンクを含む賛美曲のライブラリを管理します。賛美チームは、今後の礼拝の準備にこれを活用できます。
- **[タスク](./tasks.md)** -- チームメンバーにタスクを割り当てて追跡します。タスクは **自分の仕事** から確認できます。
- **[ワークフロー](./workflows.md)** -- 視覚的なカンバンボード上で、人々を一連のステップに沿って進めます。例として、新規来訪者へのフォローアップや入会手続きなどがあります。ステップでは自動処理（メール送信、数日間の待機、グループへの追加など）を実行でき、カードは結果ボタン、条件分岐、またはイベントやスケジュールのトリガーによって次に進みます。組み込みのレポート機能もあります。

## はじめに

1. B1 Admin で、左上の検索バーである[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)を開き、**奉仕**を展開して **計画** をクリックします。
2. **部門を追加** をクリックして新しい部門を作成するか、**すべて** を選んで既存のすべての部門を表示します。**部門のタブ** を選択すると、その計画タイプと奉仕チームを表示できます。
3. **計画タイプを作成** (または **計画タイプを追加**) をクリックするか、既存の計画タイプを選択して、[礼拝計画の作成](./plans.md)を始めます。[曲](./songs.md)や[タスク](./tasks.md)のサブセクションを確認することもできます。

:::info
計画を作成する前に、奉仕エリアで部門を作成し、各部門内でチームを作成しておく必要があります。
:::
