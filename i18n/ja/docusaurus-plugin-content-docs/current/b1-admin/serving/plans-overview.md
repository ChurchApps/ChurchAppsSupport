# プラン一覧の概要

<div class="article-intro">

プラン一覧の概要では、複数の礼拝日にわたるすべての奉仕者の割り当てを一度に確認できます。各プランを個別に開く必要はなく、1つのグリッドで今後数週間の各担当にだれが奉仕しているかを確認でき、まだ埋まっていない枠もすばやく見つけられます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 奉仕エリアで、少なくとも1つの部門とプランの種類を作成します
- 日付と奉仕者の割り当てを含む[礼拝プラン](./plans.md)を作成します
- 奉仕者が[人物ディレクトリ](../people/adding-people.md)に追加されていることを確認します

</div>

## 概要の表示方法

1. B1 Adminで、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**奉仕**を展開して、**プラン**をクリックします。
2. ページ上部の**部門タブ**を選択します。
3. **プランの種類**一覧で、プランの種類の横にある**概要**をクリックするか、プランの種類を開いてページ上部の**概要**をクリックします。

概要には、そこから開いたプランの種類の内容が表示されます。概要の上部にあるプランの種類の名前をクリックすると、そのプランの一覧に戻ります。

## グリッドの見方

概要には、次のような内容を表示するグリッドが表示されます。

- **行**は各担当（例：「音楽：ギター」「技術：プロジェクション」）を表し、カテゴリごとにグループ化されています
- **列**は今後の礼拝日（例：「4月14日」「4月21日」）を表します
- **セル**は、その日にその担当に割り当てられている奉仕者の名前を示します

**赤色**で強調表示されたセルは未割り当てを意味します。まだ奉仕者が割り当てられていないことを示しています。このため、個別にプランを開かなくても、人員の不足箇所を一目で確認できます。

:::tip
担当が多い場合でもグリッドをコンパクトに保つため、奉仕者の名前は短縮形（名と姓のイニシャル。例：「John D.」）で表示されます。
:::

## 概要から直接奉仕者を割り当てる

空いている枠を埋めるために、個別のプランを開く必要はありません。グリッド内の任意のセルをクリックすると、その担当と日付の割り当てパネルが開きます。そこから次の操作ができます。

- チームから割り当てる人を選択する
- すでに割り当てられている人の横にある**削除**をクリックして、その枠から外す
- 概要を離れずに変更を保存する

これにより、プランを行き来することなく、週と担当をまたいで、1回の操作でスケジュール全体の人員を配置できます。

## 概要から自動スケジューリングする

**自動スケジュール**をクリックすると、B1が現在のグリッド内の空いている未割り当ての枠をすべて一度に埋めます。表示中の各プランについて、各担当に紐づくグループから候補者を選び、空いている枠を自動的に埋めます。表示中のプランのうち、何件を埋められたかも報告されます。同じ奉仕者が同じパスで2つの日付に二重予約されないよう、プランは1件ずつ順番に埋められます。

:::info
自動スケジュールは、すでに空いている枠のみを埋めます。既存の割り当てを置き換えることはありません。
:::

## スケジュールされているすべての奉仕者にメールを送る

**奉仕者にメール**をクリックすると、現在フィルターされている日付範囲と部門内で割り当てられているすべての奉仕者に、一度に通知を送信できます。プランごとにメールを送る必要はありません。B1は、送信されたメールの件数と失敗した件数を報告します。

## スケジュールされているすべての奉仕者にテキストを送る

教会が[テキストメッセージのプロバイダー](../settings/church-settings.md#texting)を接続しており、プランの編集とテキスト送信の両方の権限がある場合、概要の上部に**奉仕者にテキスト**ボタンが表示されます。

1. **奉仕者にテキスト**をクリックします。
2. ダイアログには、テキストを受け取る奉仕者の人数（例：「14人中12人の奉仕者がこのテキストを受け取ります」）、配信停止している人数、電話番号が登録されていない人数が表示されます。
3. **メッセージ**を入力します。プレースホルダーをクリックすると、各奉仕者の名前または教会名を挿入できます。
4. **送信**をクリックします。B1は送信されたテキストの件数を報告します。

日付範囲内で割り当てられた各奉仕者には、複数の日付に奉仕している場合でも、プロフィールに登録されている携帯電話番号に1通のテキストが送られます。同じ電話番号を共有している人（家族の電話など）には1通だけ送られます。以前のテキストに対してSTOPと返信した奉仕者はスキップされます。

:::info
テキストは教会独自のテキストメッセージプロバイダーを通じて送信されるため、そのプロバイダーの料金が適用されます。教会のテキストクレジットが不足している場合は、送信が停止し、ダイアログにその旨が表示されます。1回の送信で届くのは最大200人の奉仕者です。それ以上の場合は、日付範囲を絞り込んでください。
:::

## 奉仕者のスケジュールを強調表示する

**強調表示**のドロップダウンを使うと、チームの中から特定の人を選べます。その人が割り当てられているすべてのセルがグリッド内で強調されるため、別の枠に追加する前に、すでにどこで奉仕しているかを確認できます。**すべて**を選ぶと、強調表示がオフになります。

## 概要の表示を絞り込む

グリッドの上にあるコントロールを使って、概要に表示する内容を調整できます。設定を変更すると、グリッドはすぐに更新されます。

- **すべての担当 / 未割り当てのみ** — **未割り当てのみ**を選ぶと、すべての日付がすでに埋まっている行が非表示になります。これにより、まだ奉仕者が必要な担当だけに集中できます。
- **開始日 / 終了日** — 既定では、概要は今後12週間分を表示します。日付を入力すると、範囲を広げたり狭めたりできます。

## CSVへの書き出し

**CSVを書き出す**をクリックすると、現在のグリッドがスプレッドシートとしてダウンロードされます。書き出しには、フィルターされた日付範囲内のすべての担当と奉仕者の割り当てが含まれるため、部門リーダーと共有したり、計画会議用に印刷したりするのに便利です。

:::info
CSVの書き出しには、現在適用されているフィルターがそのまま反映されます。ダウンロードには、グリッドに表示されている日付とプランの種類のみが含まれます。
:::
