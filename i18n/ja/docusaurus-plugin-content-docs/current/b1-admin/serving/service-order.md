# 礼拝の順序

<div class="article-intro">

礼拝の順序は、礼拝で行われる要素の流れを定めるものです。開始の賛美から閉会の祈りまで、すべてをここで整理しておくと、チーム全員があらかじめ礼拝の流れを把握できます。

</div>

## 礼拝の順序へのアクセス

1. **奉仕**に移動し、対象の奉仕チームを選択します。
2. **プランの種類**をクリックし、特定の**プラン**を開きます。
3. **礼拝の順序**セクションは、プランページの上部、**奉仕チームの割り当て**の上にあります。

## 礼拝の順序の作成

礼拝の順序は、礼拝中に行われる順番に並べた項目のリストです。一般的な要素には次のようなものがあります。

- 賛美曲
- 祈り
- 聖書朗読
- お知らせ
- 説教やメッセージ
- 献金
- 閉会

## 礼拝の順序への項目の追加

1. **礼拝の順序**セクションで**追加**をクリックし、追加する内容を選択します。**セクションを追加**（項目をまとめる見出し）、**項目**（任意の項目）、**賛美曲**（ライブラリから選択）、または**レッスンから追加**のいずれかです。**セクションを追加**を直接クリックすることもできます。
2. セクション内に項目を追加するには、そのセクションの見出しにある追加メニューを使用し、**賛美曲**、**項目**、または**外部項目**を選択します。
3. タイトルや備考など、項目の詳細を入力します。
4. **保存**をクリックします。

:::tip
[賛美曲](./songs.md)ライブラリから直接賛美曲を追加できます。これにより、歌詞や編曲を含む曲の詳細が礼拝プランにリンクされ、奉仕チームに必要な情報がすべてそろいます。賛美曲を選ぶと、各キーの横に編曲名が表示されるため、同じキーの編曲も見分けやすくなります。
:::

### 外部提供元から複数の項目をまとめて取り込む

**外部項目**（または**レッスンから追加**）を選択すると、単一項目のフォームではなく、連携しているレッスン提供元のブラウザーが開きます。提供元のコンテンツを参照（または検索）し、追加したいセクションや操作のチェックボックスをオンにします。ダイアログには選択数（例：「3件選択済み」）が表示されます。**取り込む (3)**をクリックすると、選択したすべての項目を一度に礼拝の順序に追加できます。項目ごとに追加の操作を繰り返す必要はありません。

GO! Curriculum、Dropbox、Google ドライブ、OneDrive などの一部の提供元は、セクションではなく、ファイル（動画、スライド、画像）の集合としてレッスンを提供します。**レッスンから追加**でこれらの提供元を参照すると、ファイルがフォルダーと並んで表示されます。ファイルをクリックすると、そのファイルが独立した項目として礼拝の順序に追加されます。

:::tip
この方法を使うと、項目を1つずつ追加する代わりに、レッスン1つ分のセクションと進行の指示をまとめて一度に礼拝の順序へ取り込めます。最も速い方法です。
:::

### 連携したレッスンのカスタマイズ

プランにレッスンが連携されている場合、礼拝の順序には最初にそのレッスンの**レッスンプレビュー**が表示されます。**カスタマイズ**をクリックする（またはセクション、項目、賛美曲を追加する）と、レッスンのセクションがプランにコピーされ、編集できるようになります。GO! Curriculum のレッスンのように、ファイルの一覧だけで構成されているレッスンでは、ファイルはレッスン名のセクションにまとめられます。そのため、独自の項目を追加するためのセクションバーは引き続き利用できます。

## 項目の並べ替え

各行の左側にあるハンドルで項目をドラッグし、並び順を変更します。項目を配置したい位置の青い線にドロップするか、セクションの見出しにドロップすると、そのセクションに移動します。画面に表示される順序が、礼拝中に奉仕チームが従う流れになります。

## レッスンセクションの編集

レッスンやカリキュラムのセクション（例：「大人数グループ」や「導入1」）には、それぞれ話す内容の行、スライド、動画が含まれています。その内容を変更するには、礼拝の順序でセクションをクリックします。セクションを開くと、含まれているすべての内容が表示されます。話す内容や指示の行は全文が表示され、**話す**、**行う**、または**備考**のラベルが付きます。スライドや動画はサムネイル付きで表示されます。

- 行の横にある**×**をクリックすると、その行をプランから外せます。行は取り消し線付きで一覧に残り、元に戻すための矢印が表示されます。
- テキストをクリックすると、文言を書き換えられます。書き換えた行には**元の文言に戻す**が表示されます。
- **保存**をクリックします。セクションは礼拝の順序で1行のままで、「8件中6件」などの小さなラベルが表示され、カスタマイズ済みであることがわかります。所要時間も更新されます。

セクションはいつでも再度開いて、変更内容を確認したり、行を元に戻したりできます。また、**元のセクションに戻す**を選ぶと、すべての変更を取り消せます。編集はあなたのプランにのみ反映され、元のレッスンが変更されることはありません。編集内容は印刷したプランや、奉仕ボランティアが見る内容にも反映されます。

セクションの中の項目を、それ自体の行として扱いたい場合（例：2つの行の間に賛美曲を入れたい場合）は、セクション行の右端にある矢印をクリックして、中身を個別の行として表示します。それらの行の最初の行にある矢印をクリックすると、1つの行に戻せます。この操作は、連携しているどの提供元のコンテンツでも同じように行えます。

項目に割り当てられたボランティアは、礼拝の順序でその項目の横に表示されます。そのため、プランを確認する人は、どの部分を誰が担当しているかを一目で把握できます。

## 時間とメディア

各項目とセクションには、所要時間と開始時刻が表示されます。

- プランで単一の礼拝時刻が選択されている場合、左側のレールには各項目の開始する**時刻**（例：午前9:14）が表示されます。それ以外の場合は、礼拝開始からの経過時間が表示されます。
- セクションの見出しには、その中のすべての項目の合計時間が表示されます。
- 賛美曲とカスタム項目は、項目の編集画面で**分**と**秒**を入力すると、このスケジュールに含まれます。
- メディアライブラリから追加した項目（画像や動画クリップ）にはサムネイルが表示され、時間は自動的に計算されます。動画の長さはファイル自体から測定されます。画像は、オペレーターが次に進めるまで画面に表示されるため、約5:00の計画上の目安時間（斜体で表示）が割り当てられます。どちらの場合も、編集して特定の時間を設定できます。

## 項目の編集と削除

- 礼拝の順序の項目をクリックすると、その詳細を**編集**できます。
- **削除**オプションを使うと、項目を順序から取り除けます。

:::info
礼拝の順序は、プランごとに個別に管理されます。ここで行った変更は、選択したプランにのみ反映され、他のプランや賛美曲ライブラリは変更されません。
:::

### 項目の一括選択と削除

セクション内の複数の項目を1つずつ削除する代わりにまとめて削除するには、次の手順に従います。

1. セクションの見出しにある**項目を選択**をクリックします。
2. 削除したい項目にチェックを入れるか、そのセクション直下のすべての項目を選ぶために**セクション内をすべて選択**にチェックを入れます。
3. **選択した項目を削除**をクリックし、確認します。
4. **選択を完了**をクリックして、選択モードを終了します。

:::info
一括選択は、セクションの直下の項目にのみ適用されます。サブセクションのフォルダー内にネストされた項目は対象になりません。
:::

## 特定の礼拝時刻への項目の割り当て

プランに複数の礼拝時刻がある場合（例：午前8時と午前10時の礼拝）、各項目をどの礼拝に表示するかを選択できます。お知らせが1つの礼拝にしか関係ない場合や、賛美曲が一方の礼拝でのみ歌われる場合に便利です。

1. 礼拝時刻が2つ以上あるプランを開きます。**奉仕チームの割り当て**セクションの**時刻**をクリックすると、時刻を確認または追加できます。
2. **礼拝の順序**セクションで、編集したい項目をクリックします。
3. **含める礼拝**の下に、各礼拝時刻のチェックボックスが表示されます。ラベルには時刻が表示されています。
4. 項目を省略すべき礼拝のチェックを外します。
5. **保存**をクリックします。

初期設定では、すべての項目がすべての礼拝に含まれます。除外された礼拝時刻は、その礼拝に絞り込んでプランを印刷するときに非表示になります。そのため、各礼拝には関係する項目だけを含んだ進行表が配られます。

:::tip
**含める礼拝**は、プランに礼拝時刻が2つ以上ある場合にのみ表示されます。礼拝が1つしか表示されない場合は、プランの**奉仕チームの割り当て**セクションの**時刻**をクリックして、先に礼拝を追加してください。
:::

### 礼拝ごとに異なる担当を表示する

項目に**担当**が設定されている場合、**含める礼拝**でチェックされた各礼拝時刻には、それぞれ**この礼拝の担当**のドロップダウンも表示されます。同じセクションを礼拝ごとに別のボランティアが担当する場合に使用します。**上と同じ**のままにすると、項目の既定の担当が使われます。別の担当を選ぶと、その礼拝時刻だけ担当を上書きできます。

## 礼拝の順序の共有

礼拝の順序が完成したら、プランページの上部にある**印刷**ボタンで、礼拝の順序を含むプラン全体を印刷できます。教会名とプラン名が見出しに入った、礼拝全体の進行表が奉仕チームに配れます。印刷時に**ボランティア名を表示**がオンになっている場合、各セクションの見出しには、担当ボランティアの担当名も印刷されます。そのため、奉仕チームはアプリを開かなくても、そのセクションを誰が担当しているかを確認できます。ある見出しの担当が特定の礼拝で上書きされている場合は、そのプランのすべての礼拝にわたって解決される、異なる担当名がすべて印刷されます（例：「礼拝チーム / 青年チーム」）。
