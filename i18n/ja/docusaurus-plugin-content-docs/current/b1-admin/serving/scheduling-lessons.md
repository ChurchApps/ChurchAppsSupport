# Lessons.church からレッスンをスケジュールする

<div class="article-intro">

B1 Admin は [Lessons.church](https://lessons.church) と直接連携しているため、礼拝プランの中から教室のカリキュラムをスケジュールできます。ボランティア、担当割り当て、レッスンの内容をすべて一か所で管理できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 奉仕エリアで部門を設定する
- [Lessons.church](https://lessons.church) のアカウントを用意する。教会にまだアカウントがない場合は、先にそちらで登録してください

</div>

:::tip ガイド付きの手順で進める
最初から最後までの設定を見たいですか？ **<a href="/guides/freeplay-b1admin" target="_blank">ステップごとのガイド</a>** では、コンテンツプロバイダーの連携、レッスンのスケジュール設定、教室のテレビへの FreePlay の接続を扱っています。短い動画と、進めながらチェックできる手順書があります。
:::

## ステップ 1 — Lessons.church アカウントを連携する

これは部門ごとに一度だけ行う設定です。コンテンツを閲覧してスケジュールする前に、Lessons.church アカウントを接続する必要があります。

1. [B1 Admin](https://admin.b1.church/) にログインし、**奉仕** に進みます
2. 連携したい部門を開きます（例: 子ども部門）
3. **コンテンツプロバイダー** のセクションまでスクロールします
4. **新しいプロバイダーをリンク** をクリックします
5. 一覧から **Lessons.church** を選択します
6. コードが表示されたデバイス認証の画面が出ます
7. [lessons.church](https://lessons.church) にアクセスしてログインし、そのコードを入力して連携を承認します
8. 承認されると、B1 Admin の Lessons.church の下に **連携済み** と表示されます

:::info
コンテンツプロバイダーのセクションは部門ごとに設定されます。複数の部門（例: 子ども部門と青年部門）がある場合は、部門ごとに Lessons.church を個別に連携する必要があります。
:::

Lessons.church だけが選択肢ではありません。同じ **新しいプロバイダーをリンク** の一覧には、SignPresenter、The Bible Project、Jesus Film Project、Go Curriculum、Dropbox、Google Drive、OneDrive など、ほかのカリキュラムやファイルの提供元もあります。どれも同じ手順で連携でき、レッスンを選ぶときにプロバイダーとして切り替えられます。

## ステップ 2 — レッスンをスケジュールする

連携が済んだら、プランから直接レッスンをスケジュールできます。

1. B1 Admin で **奉仕 → プラン** に進みます
2. 部門のタブを選択し、**プランタイプを追加**（部門にまだプランタイプがない場合は **プランタイプを作成**）をクリックします。プランタイプには「子どもの礼拝」や「日曜学校」のような名前を付けます
3. 作成したプランタイプをクリックし、**レッスンをスケジュール** をクリックします。このメニューから、1 つのレッスンをスケジュールしたり、シリーズをまとめてスケジュールしたり、**年間プランを適用** で Lessons.church の公開済みの年間シーケンスを読み込んだりできます
4. レッスンの **日付** を選択します（初期値は次の日曜日です）
5. **レッスンを選択** をクリックします。コンテンツの閲覧ダイアログが開きます
6. ダイアログでは、**Lessons.church** がプロバイダーとして選ばれた状態で開きます（このプランタイプで以前のレッスンに使ったプロバイダーが選ばれている場合もあります）。ほかのプロバイダーも連携していれば、ダイアログ上部で切り替えられます
7. コンテンツを閲覧します:
   - **プログラム**（例: 「子ども向け聖書物語」）を選択します
   - そのプログラム内の **スタディ**（例: 「創造と初期の物語」）を選択します
   - 特定の **レッスン** を選択します
   - **会場** を選択します。これは対象年齢に合わせたレッスンの版です

   ほかのプロバイダーは、コンテンツの構成が異なります。たとえば **Go Curriculum** は **Elementary** や **Preschool** から始まり、次にシリーズ、そしてレッスンそのものが続きます。この場合、会場を選ぶ必要はありません。
8. **レッスンを関連付け** をクリックして確定します
9. ボランティアに対する **コピーのオプション** を選びます:
   - **なし** — 新しいプランで、ボランティアは引き継がれません
   - **役割のみ** — 前のプランからボランティアの役割はコピーしますが、担当者は引き継ぎません
   - **役割と担当者** — 役割と担当ボランティアの両方をコピーします *（最も一般的）*
10. **保存** をクリックします

プランは自動的に作成され、名前も付きます（例: 「2月23日 - Elementary」）。ボランティアはプランを開いて自分の担当を確認し、日曜日の前にレッスンの内容を見ておくことができます。

:::warning
教室の対象年齢に合った **会場** を必ず選んでください。会場を間違えると、ボランティアが別の年齢向けの内容を見ることになります。
:::

## シリーズをまとめてスケジュールする

同じシリーズの複数のレッスンを一度にスケジュールするには、**レッスンをスケジュール → 一括スケジュール** をクリックします:

1. **開始レッスン** の下で **レッスンを選択** をクリックし、最初にスケジュールしたいレッスンを選びます
2. **開始日** を設定し、**間隔**（**毎週** または **隔週**）を選びます
3. 前のプランからコピーする内容を選びます（**なし**、**役割のみ**、または **役割と担当者**）
4. 一覧を確認します。開始レッスンとそのシリーズの残りのレッスンが、それぞれ日付付きで表示されます。省きたいものはチェックを外してください
5. **保存** をクリックすると、レッスンごとに 1 つのプランが作成されます

Lessons.church の場合、一覧には各レッスンで使われる **会場** も表示されます。これは開始レッスンで選んだ会場と名前で照合されます（レッスンにその会場がない場合は、別の会場が使われ **代替** と表示されます）。Go Curriculum のように会場の区分がないプロバイダーでは、レッスンはそのままスケジュールされ、会場の列は表示されません。

## レッスン全体のうち一部だけを残す

教室で毎回同じ部分（たとえば冒頭の動画、暗唱聖句、物語の質問など）を使い、残りはライブで行う場合は、プランを一つずつ編集する代わりに、その削除内容をプランタイプごとに一度保存できます:

1. スケジュール済みのレッスンのプランを一つ開き、**カスタマイズ** をクリックします
2. 通常どおり、使わないセクションを削除します。暗唱聖句の動画のように、セクションの中の一つのステップだけを残したい場合は、そのセクションを展開してステップに分け、ほかのステップを削除します
3. 礼拝の順序の下で、**このプランタイプのすべてのレッスンに使用**（リンク名にはプランタイプの名前が入ります）をクリックします
4. 残すパーツの一覧を確認します。**すでにスケジュールされた今後のレッスンも削除する** はチェックしたままにしておくと、そのプランタイプにすでにスケジュールされているレッスンも同じように削除されます（礼拝の順序は置き換えられます）
5. **保存** をクリックします

これ以降、**レッスンをスケジュール**、**一括スケジュール**、**年間プランを適用**、または **レッスンをリンク** でそのプランタイプにスケジュールされるレッスンは、同じパーツだけを残した状態で作成されます。そのため、FreePlay は教室のテレビで必要なパーツだけを再生します。パーツは名前で照合されるため、名前が少し変わったセクション（「大きな聖書物語の質問」が「聖書物語の質問」になった場合など）も見つかります。毎週名前が変わるセクション内のステップ（聖句の参照にちなんで名付けられた暗唱聖句の動画など）は、そのセクション内での位置によって残されます。

レッスンがこのパターンに合わない場合（パーツがない、その週に動画や画像がない、名前ではなく位置で残された、などの場合）、そのプランは一致した内容だけに削除され、フラグが立ちます。プラン一覧のプランの下と、プランページの上部に警告が表示され、部門のリーダーには通知が届きます。日曜日の前に、そのプランの礼拝の順序を確認してください。警告は礼拝の順序を編集するか、**非表示** をクリックすると消えます。レッスンの中に一致するものが一つもなければ、そのレッスンは削除されずにそのまま残り、フラグが立ちます。

すでに礼拝の順序があるプランは、スケジュールされても変更されません。保存されている削除内容を変えたい場合は、別のプランをカスタマイズして、**Elementary の保存済みの削除内容を置き換える**（こちらもプランタイプの名前が入ります）をクリックしてください。削除をやめたい場合は、プランタイプの **編集** ダイアログを開き、**レッスンの削除内容** の横にある **クリア** をクリックします。

## Go Curriculum のリーダーガイド

Go Curriculum のレッスンをスケジュールすると、プランの礼拝の順序はそのレッスンの **Large Group** リーダーガイドから作られます。ガイドの各パートがセクションになり、その中の各ステップは種類（say、do、play、note など）と本文付きで一覧に表示されます。動画やほかのメディアを再生するステップには、そのファイルも一緒に含まれるため、順番どおりに再生されます。（Large Group のガイドがないレッスンでは、メディアファイルの単純な一覧が使われます。）

小グループ向けの教材があるシリーズには、それぞれ **Small Group Guides** フォルダーもあります。このフォルダーを開いてレッスンを選ぶと、そのレッスンの **Small Group** ガイドをスケジュールできます。ガイドは「レッスン名 - Small Group」のような名前になります。小グループ用の別のプランタイプを作るときに便利です。小グループのガイドは主に話し合いのステップで、通常はメディアがありません。このフォルダーは一覧の先頭に表示されるため、そこにあるレッスンからシリーズを一括スケジュールしても、このフォルダーが含まれることはありません。

## 年間プランを適用する

カリキュラムの発行元が Lessons.church で年間プランを公開している場合、一度の操作で、その全体のシーケンスをこのプランタイプに読み込めます:

1. **レッスンをスケジュール → 年間プランを適用** をクリックします
2. 公開されている年間プランを選びます
3. プランが暦に基づいている場合（例: Ark Kids）は、**対象年** を選びます。イースターとクリスマスの学習は、その年の日付に配置されます。年の一部だけをスケジュールする場合は、最初と最後のクラスの日付を調整してください
4. プランが暦に基づいていない場合は、最初のクラスの日付（1 週目はその日付になり、以降の週は 7 日間隔になります）と、作成する週数（12、24、44、または 52）を設定します
5. 必要に応じて、前のプランからボランティアの役割をコピーします
6. 一覧をプレビューします。不要な週はチェックを外してください。その後のレッスンは、空いている次の日曜日に順に移動し、穴があいたままにはなりません。暦に基づくプランで、すでにプランがある日付は同じように飛ばされます
7. 保存します。各週は通常どおり編集できる奉仕プランになります。レッスン、ボランティア、日付を変更できます。FreePlay は、その週のプランに設定されている内容を再生します

:::tip
**事前に計画する** — 複数週分のレッスンを一度にスケジュールすると、チームが前もって準備できます。プランの表示画面にある過去のレッスン一覧を使うと、同じ内容を誤って繰り返すのを防げます。
:::

## レッスンの内容をカスタマイズする

レッスンをスケジュールしたら、教室に合わせて調整できます。当てはまらないセクションを削除したり、教室で使わない役割を非表示にしたり、好みの流れに合わせて内容の順序を並べ替えたりできます。カスタマイズは一つの教室だけに保存することも、教会のすべての教室に適用することもできます。

手順の詳細は [レッスンのカスタマイズ](/docs/lessons-church/customization/customizing-lessons) のガイドをご覧ください。

## FreePlay で教室のテレビにレッスンを再生する

B1 Admin でのレッスンのスケジュール設定は、**[FreePlay](/docs/freeplay/)** と組み合わせると効果的です。FreePlay は、教室のテレビや Fire Stick 向けの ChurchApps の無料メディアプレーヤーです。プランの設定が済むと、FreePlay は Lessons.church からレッスンの内容を直接取得し、教室で全画面再生できます。教師はテレビのリモコンで進行を管理し、レッスンの流れに合わせて動画やスライドを進めます。

つまり、ボランティアは自分のスマートフォンでプランを確認し、教室のテレビではレッスンの内容が再生されます。別途の設定も、USB ドライブも、直前のあわただしい準備も必要ありません。

[FreePlay をコンテンツプロバイダーに接続する方法を学ぶ →](/docs/freeplay/content-providers/connecting-providers)

## お使いのカリキュラムプロバイダーが表示されない場合

利用できるプロバイダーの一覧は増え続けています。教会が使っているカリキュラムプロバイダーがまだ B1 Admin に表示されない場合は、お問い合わせください。追加できるよう対応します。

以下のメッセージをコピーして、カリキュラムプロバイダーに直接送っていただいても構いません。プロバイダーから当方に連絡があれば、連携の設定を進めます。

---

> **件名: ChurchApps 連携のご依頼**
>
> [カリキュラムプロバイダーのチーム名] 様
>
> 御社のカリキュラムを大変気に入っており、毎週子どもたちと使っています。また、ボランティアとサービスプランの管理には ChurchApps を、教室のテレビでレッスンの内容を再生するには FreePlay（freeplay.church）を使っています。教師にとって大きな助けになっています。
>
> 現在は御社のカリキュラムを別々に管理していますが、もし ChurchApps と連携していただければ、礼拝プランの中から御社のレッスンを直接スケジュールし、FreePlay を通じて教室の画面で再生できるようになります。普段使っているツールから離れる必要もありません。
>
> ChurchApps はすでにいくつかのカリキュラムプロバイダーと連携しており、御社とも連携する準備ができています。**support@churchapps.org** までご連絡いただき、話を始めていただけますか？ 実現できれば大変うれしく思います。
>
> よろしくお願いいたします。
