# タスク

<div class="article-intro">

タスクを使うと、教会内の人やグループに対して行動項目を割り当てられます。1回限りの ToDo でも定期的な役割でも、タスクを使えば何をいつまでに行う必要があり、誰が担当するのかを把握できるので、見落としを防げます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- タスクを割り当てたい人や[グループ](../groups/creating-groups.md)が B1 Admin に登録されていることを確認してください
- [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)で **Serving > My Work** を選ぶと、タスクを確認できます

</div>

## タスクを表示する

ジャンプメニューで **Serving > My Work** を選びます（または「My Work」と検索します）。**Tasks** の一覧には、各タスクのタイトル、関連付けられた人やグループ、担当者、作成日、ステータスが表示されます。一覧の横には、**My Cards** の下に[ワークフロー](./workflows.md)のカードも表示されます。担当者は、B1 アプリの **Me** 画面からも自分のカードや未完了のタスクを確認し、対応できます。

一覧の上にあるタブで、**Assigned to Me**（自分に割り当てられたタスク）、**Assigned to My Groups**（自分のグループに割り当てられたタスク）、**Requested by Me**（自分が依頼したタスク）を切り替えられます。各タブには、そこに含まれるタスクの件数が表示されます。

:::tip
既定では、未完了のタスクのみが表示されます。完了したタスクを見るには、一覧の上にある **Closed** を選んでください。
:::

## タスクを作成する

1. **My Work** ページで **Add Task** をクリックします。**New Task** フォームが開きます。
2. 必要に応じて **Associate with** の欄をクリックし、タスクの対象となる人またはグループを選びます。特定の人に関係しない、自分用のリマインダーのような単純な ToDo の場合は空欄のままにします。
3. **Assign to** の欄をクリックします。**Select a Person or Group** ウィンドウで、**Person** タブで検索するか、**Group** タブに切り替えてグループを検索し、結果を選択します。
4. タスクの **Title**（タイトル）を入力します。
5. 必要に応じて **Due date**（期限日）を選択します。
6. 担当者への詳細や指示を **Notes**（メモ）に入力します。
7. **Save** をクリックします。

タスクは一覧に表示され、担当者のダッシュボードとモバイルアプリにも表示されます。

## タスクを管理する

タスクをクリックすると、詳細ページが開きます。このページでは次のことができます。

- **タスクを完了または再開する** -- 作業が終わったら **Close task** をクリックします。再度開くには **Reopen task** をクリックします。
- **タスクを割り当て直す** -- **Assign** をクリックして、別の人またはグループを選びます。
- **対象の人を変更する** -- **Associate** をクリックして別の人またはグループを選ぶか、**No person or group** を選んで関連付けを解除します。
- **期限日を変更する** -- **Due** 欄で日付を選びます。欄の外をクリックすると保存されます。（[奉仕の割り当て確認](./workflows.md#serving-assignment-confirmations)のために作成されたタスクは期限日が表示されますが、ここでは変更できません。）
- **メモを追加する** -- タスクのメモに、担当者向けの更新情報や詳細を投稿します。
- **リマインダーを設定する** -- 下記の[タスクのリマインダー](#task-reminders)を参照してください。

## タスクのリマインダー

期限日が設定されているタスクは、期限前に担当者へリマインドを送ることができます。

1. タスクのページで、**Reminders** の横にある **Edit** をクリックします。
2. **Send reminders for this task** をオンにします。
3. **When should reminders go out?**（リマインダーをいつ送るか）で、**7 days before**（7日前）、**3 days before**（3日前）、**1 day before**（1日前）、**Day of**（当日）から最大3つまで選びます。
4. **Time of Day**（時刻）を設定し、必要に応じて **Message**（メッセージ）を入力します。
5. **Send By**（送信方法）で **Push**、**Email**、そして教会に[テキストメッセージのプロバイダー](../settings/church-settings.md#texting)が接続されている場合は **Text** を選びます。
6. **Save Reminders** をクリックします。

タスクに期限日が設定されていない場合、B1 は **Due** 欄で期限日を設定するまでリマインダーが送信されないと警告を表示します。テキストメッセージによるリマインダーは、[通知設定](../../b1-church/getting-started/notification-preferences.md)で **Text messages** をオンにしている人にのみ届きます。また、テキストメッセージは1通ごとに教会の費用がかかる場合があります。

## タスクのライフサイクル

1. 新しいタスクは、ステータスが **Open**（未完了）の状態で始まります。
2. 担当者には通知が届き、ダッシュボード、**Serving > My Work**、またはモバイルアプリからタスクを確認できます。
3. 作業が完了したら、担当者（または管理者）が **Close task** をクリックします。
4. 完了したタスクは既定の表示からは消えますが、タスク一覧の上の **Closed** を選べば引き続き見つけられます。

:::info
B1 Admin では、スケジュールに従って定期的なタスクを作成する機能は提供されなくなりました。人への定期的なフォローアップには、[スケジュールトリガー](./workflows.md#schedule-triggers)を設定した[ワークフロー](./workflows.md)を使ってください。
:::

:::tip
新来館者のフォローアップや入会手続きなど、同じ段階を多くの人が順に進む場合は、[ワークフロー](./workflows.md)を使ってください。ワークフローでは、タスクがステップ、期限日、振り分けを備えたドラッグ＆ドロップのボード上のカードになります。
:::

:::info
B1 の他の機能によって自動的に作成されるタスクもあります。これらは通常のメモ／再割り当て画面ではなく、専用の確認カードで開きます。[グループ参加申請](../groups/group-join-requests.md#approving-from-the-tasks-page)、[プロフィール変更の申請](../profile/approving-profile-changes.md)、[アカウント削除の申請](../profile/account-deletion.md)がこの方式で処理されます。
:::
