# 礼拝プラン

<div class="article-intro">

礼拝プランでは、誰がいつ奉仕するかを整理できます。各プランは特定の日付と奉仕部門に結び付けられているため、ボランティアチームを週ごとに調整し、すべての礼拝に十分な人員を配置できます。

</div>

## プランへのアクセス

1. B1 Adminで、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**奉仕**を展開して、**プラン**をクリックします。
2. ページ上部の**奉仕部門タブ**を選択します。
3. **プランの種類**をクリックすると、その種類のプラン一覧が表示されます。一覧の上にある**今後**と**過去**を使うと、将来のプランと過去のプランを切り替えられます。**今後**では今日以降のプランが直近のものから順に表示され、日付のないプランは最後に表示されます。**過去**では過去のプランだけが新しいものから順に表示されます。
4. 特定のプランをクリックして開きます。

各プランのページには、そのプランの種類と**プラン**へのリンクが表示されるため、ブラウザの戻るボタンを使わずに上の階層へ戻れます。

:::info
プランの管理に管理者のフルアクセス権は必要ありません。奉仕部門のメンバーであれば、誰でも奉仕エリアに移動して、自分の部門のプランを作成、編集、スケジュール設定できます（プラン編集の権限は不要です）。プラン編集の役割を持つ編集者は、すべての奉仕部門のプランを管理できます。
:::

## プランの作成

1. プランの種類のページで、ページ上部の**新規プラン**をクリックします。
2. プランに名前を付けるか、日付を名前として使用します。礼拝の**日付**を選択します。
3. 奉仕部門に[テンプレート](./plan-templates.md)がある場合は、**テンプレートから開始**で選択すると、礼拝順序、ポジション、メモを一度に設定できます。
4. テンプレートを使わず、以前のプランからコピーしたい場合は、**前のプランからコピー**を使って**ポジションのみ**または**ポジションと割り当て**を選択します。コピーしない場合は**なし**を選択します。**礼拝順序をコピー**にチェックを入れることもできます。以前のプランからコピーすると、新しいプランには、そのプランの**メモ**、**申し込み期限**、**申し込みページにボランティア名を表示**の設定、自動代替の設定も引き継がれるため、毎週入力し直す必要はありません。これらの設定は、新しいプランの設定画面で変更できます。
5. コピーしながら複数のプランをまとめて作成する場合は、**繰り返し間隔**と**頻度**（日、週、月）を選択し、**プランの数**（最大12）を入力します。月の場合、**曜日指定**で、同じ日付（毎月15日など）または同じ曜日（第2土曜日など）を選べます。B1は保存前に日付の一覧を表示し、日付ごとに1つずつプランを作成します。各プランは直前のプランからコピーされます。プランが日付で名前付けされている場合、新しく作成される各プランは、それぞれの日付に応じた名前になります。
6. 必要に応じて**申し込み期限（礼拝の何時間前）**を設定します。新しいプランは前のプランの期限を引き継ぐため、ここで変更できます。期限を設けない場合は空欄のままにします。期限の計算方法については、[プラン設定](#plan-settings)を参照してください。
7. プランを保存します。これで、チームメンバーの割り当てと[礼拝順序](./service-order.md)の作成を始められます。

:::tip
繰り返しの設定は、前のプランからポジション、割り当て、礼拝順序のいずれかをコピーしている間のみ利用できます。
:::

## プラン詳細ページ

プランを開くと、ページ上部にプラン名、奉仕部門、プランの種類、礼拝日が表示され、**編集**と**印刷**のボタンがあります。その下には、次のすべてが1ページに表示されます。

- **[礼拝順序](./service-order.md)** — 賛美、祈り、お知らせ、説教などの要素を使って礼拝順序を作成します。
- **奉仕チームの割り当て** — このプランに割り当てるチームメンバーを管理します。既存のチームからメンバーを追加でき、確定済みか保留中かを確認できます。ポジションの上にあるリンクから、プランの**メモ**と**時間**を開けます。

## チームメンバーの割り当て

1. プランを開き、**奉仕チームの割り当て**までスクロールします。
2. **ポジションを追加**をクリックします。ポジションの追加フォームに情報を入力します。カテゴリ名には任意の名前を入力できます。教会内の誰でもそのポジションを埋められるようにする場合（特定のチームのメンバーだけに限定しない場合）は、**ボランティアグループ**を**なし**のままにします。
3. **必要な人数**をクリックし、そのポジションを埋めるボランティアを選択します。ポジションに**ボランティアグループ**が設定されている場合は、そのグループのメンバーから選択します。ボランティアグループが**なし**に設定されている場合は、教会内の誰でも検索できます。
4. **追加**をクリックして、チームの名簿からメンバーを追加します。
5. 割り当てられたメンバーは、割り当て状況とともに所属チームの下に表示されます。
6. **ボランティアに通知**をクリックして、B1アプリ内またはメールで通知します。プランで[確認ワークフロー](#plan-settings)を使用している場合、通知すると、ボランティアが応答するまで各依頼を追跡するワークフローカードも作成されます。

各ポジションには件数のチップ（例：「2/3」）が表示され、埋まっている枠数を一目で確認できます。**奉仕チームの割り当て**の見出しの下には、「X件中Y件のポジションが埋まっています」という概要が表示され、プラン全体の人員状況と、あと何人必要かがわかります。すべてのポジションが埋まると、「完全に配置済み」に切り替わります。

:::tip
プランを作成する前に、教会の設定で奉仕チームを設定しておくことをおすすめします。そうすることで、割り当てに使える準備の整ったボランティアのプールができます。
:::

### 空のプランへのポジションのコピー

プランにまだポジションがなく、同じ種類の以前のプランがある場合は、**奉仕チームの割り当て**に**前のプランからコピー**のリンクが表示されます。**ポジションのみ**または**ポジションと割り当て**を選ぶと、開いているプランに、前のプランのポジション（とボランティア）を追加できます。コピーは現在のプランに追加されます。同じ日付のプランが2つ作成されるわけではありません。

## プラン設定

各プランには追加の設定があり、プランの種類の一覧でプランの横にある**編集**、またはプランページ上部の**編集**ボタンをクリックして設定できます。プランに戻るには**完了**（またはプラン名）をクリックします。主な設定は次のとおりです。

- **申し込み期限（礼拝の何時間前）** — 礼拝の何時間前にボランティアの申し込みを締め切るかを指定します。時間は、プランの最初の**礼拝**の時刻から逆算されます（プランに他に時間がない場合を除き、リハーサルやその他の時間は除外されます）。たとえば、午前10時の礼拝に対して2時間の期限を設定すると、その日の午前8時に申し込みが締め切られます。プランに時間が設定されていない場合は、教会のタイムゾーンにおける礼拝日の午前9時から期限が計算されます。期限を過ぎると、ボランティアは申し込みも取り消しもできなくなります。礼拝開始時刻を過ぎても申し込みを受け付けたい場合は、負の数を入力します。期限を設けない場合は、空欄のままにするか、入力を消去します。
- **確認ワークフロー** — [奉仕の割り当て確認ワークフロー](./workflows.md#serving-assignment-confirmations)を選択すると、ボランティアが承諾または辞退するまで、このプランの奉仕依頼をメールとテキストでフォローアップできます。公開済みのプランでボランティアに**通知**すると、新しい依頼ごとに、そのワークフローのボードに個別のカードが作成され、通知リンクの上に「*新しいリクエストには確認ワークフローを使用します。*」というメモが表示されます。通常の通知を維持したい場合は、**既存の割り当て通知を使用**のままにします。有効な確認ワークフローだけが一覧に表示されます。先に**奉仕 > ワークフロー**で作成してください。
- **申し込みページにボランティア名を表示** — チェックを入れると、ログイン済みのボランティアは、B1.churchの申し込みページで、各ポジションに既に申し込んでいる他のメンバーを確認できます。ログインしていない訪問者には名前が表示されることはありません。
- **仮押さえ** — スケジュールを公開する準備が整うまで、割り当てをボランティアから非表示にします。
- **ボランティアが辞退した場合に代替者を自動でスケジュール** — チェックを入れると、割り当てられたボランティアがポジションを辞退した場合、B1がチームの名簿で次に対応可能な人に自動で連絡し、奉仕できるかどうかを尋ねます。承諾する人が見つかるまで、この処理が名簿の順に続きます。手動でフォローアップしなくても、ポジションを埋めた状態を保てます。

:::tip
メンバーの申し込みページでは、各プランの空いているポジションがカテゴリごとに、さらに名前順に表示されます。**プランの種類ごとに次の1週間のみ表示**を[設定 > ボランティア申し込み](../settings/church-settings.md#volunteer-signup)でオンにしない限り、メンバーには空きポジションがある今後のすべての週が表示されます。
:::

## ボランティアへのリマインダー {#volunteer-reminders}

B1は、ボランティアが割り当てられている礼拝の前に、自動でリマインダーを送信できます。そのため、毎週チームに一人ずつ連絡する必要がありません。リマインダーは、**スケジュール済みのすべての人**に送信されます。これには、確定した人と、まだ返答していない人の両方が含まれます。例外は、[確認ワークフロー](./workflows.md#serving-assignment-confirmations)を通じて送信された依頼です。このワークフローでは承諾後にのみリマインダーが送られます。承諾前のフォローアップはワークフローが担当するためです。各リマインダーメールには、ボランティアのポジション、礼拝日、プランのメモ、カスタムメッセージが含まれます。

リマインダーの時期と内容は**プランの種類**ごとに設定されるため、礼拝の種類ごとに異なるスケジュールを設定できます。

1. **奉仕**エリアで、プランの種類が含まれる奉仕部門を選択します。
2. **プランの種類**の一覧で、そのプランの種類の横にある**編集**をクリックします。
3. **リマインダー**のセクションを展開し、**このタイプのプランのリマインダーを送信**をオンにします。
4. **リマインダーはいつ送信しますか？**で、次のタイミングから最大3つを選択します：**7日前**、**3日前**、**2日前**、**1日前**、または**当日**。
5. リマインダーを送信する**時刻**を設定します。
6. 必要に応じて**メッセージ**を追加します。空欄のままにすると、デフォルトのリマインダーの文面が使用されます。
7. **送信方法**で、**プッシュ**、**メール**、そして教会が[テキストメッセージのプロバイダー](../settings/church-settings.md#texting)を接続している場合は**テキスト**を選択します。
8. **リマインダーを保存**をクリックします。

プランの種類のリマインダーは、オンにするまで無効です。

:::tip
まだ確認していないボランティアには、リマインダーメールの中に**承諾**と**辞退**のボタンが表示されるため、サインインせずに返答できます。
:::

### テキストリマインダー

**テキスト**のオプションは、教会がテキストメッセージのプロバイダーを接続している場合にのみ表示されます。テキストは教会のテキストメッセージのプロバイダーを通じて送信され、送信のたびに教会に費用が発生する場合があります。ボランティアがテキストリマインダーを受け取るのは、[通知設定](../../b1-church/getting-started/notification-preferences.md)で**テキストメッセージ**をオンにしており、プロフィールに携帯電話番号が登録されている場合のみです。各テキストは教会の名前で始まり、1通のテキストメッセージに収まるように作成され、「Reply STOP to opt out.」で終わります。STOPと返信した人は、その教会からのテキストを受け取らなくなります。STOPの返信をB1に届けるには、[テキストメッセージの設定](../settings/church-settings.md#texting)にある**受信（STOP）Webhook URL**を、プロバイダーの受信メッセージ用Webhookに貼り付けてください。

指定した期間内にスケジュールされているすべての人に、今すぐテキストを送信するには、[プランの概要](./plans-overview.md#texting-everyone-scheduled)の**ボランティアにテキスト送信**を使用します。

:::info
各リマインダーは1回だけ送信されます。テキストリマインダーは、プッシュ通知やメールの代わりではなく、それらに加えて送信されます。
:::

## プランの種類へのグループの関連付け

プランの種類のページにあるプラン一覧の下には、**関連付けられたグループ**のセクションがあり、どのグループがメンバーポータルからこのプランの種類のプランを閲覧できるかを設定できます。これは、管理者権限を与えずに、適切なチームに今後の礼拝を知らせる手軽な方法です。

1. プランの種類のページで、ページ上部の**関連付けられたグループ**をクリックします（またはそのセクションまでスクロールします）。
2. **グループを追加**をクリックし、ドロップダウンからグループを選択します。
3. **表示対象**の列で、そのグループのメンバーに、このプランの種類について**過去のプランのみ**、**今後のプランのみ**、**過去と今後のプラン**のどれを表示するかを選択します。
4. 他のグループを関連付けるには同じ操作を繰り返します。グループを削除するには、ゴミ箱のアイコンをクリックします。

:::info
選択肢に表示されるのは、**標準**としてタグ付けされたグループのみです。関連付けられたグループのメンバーは、B1メンバーポータルのグループページで、このプランの種類のプランを自動的に確認できます。表示されるのは、選択した期間内のプランに限られます。
:::

プランがLessons.churchのレッスンである場合、関連付けられたグループのメンバーには、グループページに**今週のレッスン**カードも表示されます（要点、聖句、保護者向けの質問が含まれます）。ここで保護者向けのグループを関連付け、フィルターを**過去のプランのみ**に設定すると、今日のレッスンが含まれます。奉仕チームは通常、**今後のプランのみ**または**過去と今後のプラン**を使用します。

## プランの印刷

チームに配布するために、プランを印刷できます。プランを開き、ページ上部の**印刷**をクリックすると、割り当てと礼拝順序を含む印刷用のバージョンが生成されます。印刷物の上部には、教会のロゴ（[ウェブサイト > 外観](../website/appearance.md)でアップロードした**明るい背景用ロゴ**）と教会名、そしてプラン名が表示されるため、バラバラになったページでも見分けやすくなります。リハーサルで配布したり、共用スペースに掲示したりするのに便利です。

印刷物には、空になる項目は含まれません。ボランティアが割り当てられていない場合はチームの枠が表示されず、礼拝順序はページ全体の幅を使います。長さが設定された項目がない場合は**長さ**の列が省かれ、プランに礼拝の時間も長さもない場合は**時間**の列も省かれます。礼拝日が表示される黒の**礼拝順序**の見出しバーを非表示にするには、印刷ページ上部の**礼拝順序の見出しを表示**のチェックを外します。B1 Adminは、そのブラウザでの選択を記憶します。

:::info
プランは奉仕部門ごとに整理されています。プランを作成または表示する前に、正しい奉仕部門のタブを選択していることを確認してください。
:::

## 次のステップ

- [プランの概要](./plans-overview.md)を使うと、複数の週にわたるすべての今後の割り当てを1つの表で確認でき、空いているポジションを見つけられます。また、表から直接ボランティアを割り当てることもできます。
- プランの構成を[プランテンプレート](./plan-templates.md)として保存しておくと、今後のプランにワンクリックで適用できます。
- 曲、朗読、その他の要素を使って[礼拝順序](./service-order.md)を作成します。
- ライブラリの[曲](./songs.md)を、礼拝順序に直接追加します。
- [タスク](./tasks.md)を使うと、チームメンバーにフォローアップの作業項目を割り当てられます。
- [デジタルサイネージ](./digital-signage.md)を使って、ロビーのテレビに現在のレッスンの内容を表示します。
