# プラン検証とボランティアへの通知

<div class="article-intro">

B1 Adminは日曜日の前に、プランに問題がないかを自動的にチェックします。募集枠の空き、スケジュールの重複、日付を不可に設定しているボランティアなどです。問題がなければ、ワンクリックでチーム全員に通知できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [礼拝プラン](./plans.md)を作成し、ボランティアを各ポジションに割り当てる
- 重複チェックができるように、プランに[礼拝時間](./plans.md)を追加する
- ボランティアがプッシュ通知を受け取れるよう、B1 Mobileアプリをインストールしておく

</div>

## 検証パネル

すべての礼拝プランには**検証**パネルがあり、プランを作成している間は自動的に実行されます。次の3つをチェックします。

### 募集枠の空き
ポジションに必要な人数が現在の割り当て人数より多い場合、検証パネルには不足している人数が表示されます。例：*「音響担当：あと1名必要です。」* 当日より前に、プランの人員が揃っているかを一目で確認できます。

### スケジュールの重複
同じプラン内で、時間が重なる2つのポジションにボランティアが割り当てられている場合、検証パネルが重複を表示します。例：*「Jane Smith：日曜礼拝中に、礼拝リーダーと子どもチェックインの時間が重複しています。」* 日曜の朝に問題になる前に、二重予約を見つけられます。

### 不可日
ボランティアは B1 Mobileで、参加できない日付を設定できます。不可日の範囲内にあるプランに割り当てられている場合、検証パネルが自動的に競合を表示するので、代わりの人を探せます。

### プラン間の重複
検証は、すべてのプランをまとめて確認します。同じボランティアが、時間の重なる2つの異なるプランに割り当てられている場合、例えば午前9時の礼拝と午前10時の礼拝がどちらも午前10時30分まで続く場合、B1 Adminはその人をプラン間で二重予約として表示します。

:::tip
検証を実行するための操作は不要です。割り当てを追加または変更するたびに自動で更新されます。プランを作成する間は、パネルに注意を払うだけで十分です。
:::

## ボランティアへの通知

プランが決まったら、検証パネルから割り当てられた全ボランティアに一度に通知できます。

1. プランを開き、**検証**パネルまでスクロールする
2. 未通知のボランティアがいる場合、通知が必要な人数を示すリンクが表示されます（例：*「8名のボランティアに通知」*）
3. リンクをクリックすると、まだ通知していない全員にプッシュ通知を送信します
4. ボランティアのスマートフォンに、スケジュールされたことと、割り当てを確認するよう促す通知が届きます

:::info
まだ通知されていないボランティアのみが対象です。後からプランに人を追加すると、リンクが再び表示されるので、他のメンバーに再通知することなく、追加した人にだけ通知できます。
:::

### 確認ワークフローを使うプラン

プランの設定で[確認ワークフロー](./workflows.md#serving-assignment-confirmations)が指定されている場合、パネルには*「新しいリクエストは確認ワークフローを使用します。アプリ内通知は引き続き有効です。各リクエストが承諾または辞退されると、フォローアップは停止します。」*と表示されます。この場合：

- 通知リンクがカウントするのは、まだ通知されておらず、かつ未回答のボランティアのみです。
- リンクをクリックすると、通常のアプリ内通知が送信され、ワークフローのボードにリクエストごとのカードが1枚ずつ作成されます。その後、ワークフローがメールとテキストメッセージによるフォローアップを送信し、必要に応じてリクエストを電話担当者に引き継ぎます。
- プランは仮押さえ状態ではなく公開済みである必要があり、ワークフローは有効である必要があります。そうでない場合、パネルには*「リクエストを送信できませんでした。選択したワークフローが有効で、プランが公開されているか確認してから、もう一度お試しください。」*と表示されます。

:::warning
ボランティアがプッシュ通知を受け取るには、B1.churchのモバイル版（ホーム画面に追加したPWA、または旧版のネイティブアプリB1 Mobileを使っている場合は非推奨のそのアプリ）をインストールし、通知を有効にしておく必要があります。設定方法は[アプリとしてインストール（PWA）](/docs/b1-church/getting-started/installing-pwa)を参照してください。
:::
