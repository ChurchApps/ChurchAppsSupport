# 賛美曲

<div class="article-intro">

賛美曲ページでは、礼拝で使う賛美曲のライブラリを管理できます。曲の詳細、歌詞、アレンジを一か所にまとめておくことで、賛美チームは今後の礼拝の準備を効率よく進められ、レパートリーも統一して管理できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1 Admin の[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)で **Serving > Songs** を選ぶと、賛美曲ページを開けます
- 必要に応じて、先に[礼拝プラン](./plans.md)を設定しておくと、曲を[礼拝の順序](./service-order.md)に直接リンクできます

</div>

## 賛美曲ライブラリの閲覧

**Songs** ページを開くと、賛美曲が表形式で一覧表示されます。各行には、曲のサムネイル画像、タイトル、アーティスト、長さが表示されます。曲数が多い場合は一覧の下にあるページ操作で移動するか、検索して目的の曲を探してください。

## 賛美曲の検索

1. 賛美曲ページ上部の **Search Songs** ボックスをクリックします。
2. 曲の **タイトル** またはアーティスト名を入力します。
3. 入力に合わせて一覧が絞り込まれ、ライブラリ内の一致した曲と件数が表示されます。すべての曲を再表示するには **Clear** をクリックします。

## 賛美曲の追加

1. 賛美曲ページ上部の **Add Song** をクリックします。
2. **Search for a Song** で、外部の賛美曲データベースを **Title or Artist** で検索します。
3. 追加したい曲を選択します。見つからない場合は **Create Manually** をクリックします。
4. 基本情報が自動入力された状態で、曲がライブラリに追加されます。

:::tip
曲を追加したら、その曲をクリックして詳細を確認・更新したり、アレンジを追加したり、YouTube動画やコードチャートなどの外部リンクを添付したりできます。
:::

### WorshipCommons の無料の賛美曲

検索結果には、通常の結果と並んで **WorshipCommons — 無料** のセクションが表示される場合があります。これらは [WorshipCommons](https://worshipcommons.org) から提供される、日曜礼拝ですぐに使える賛美曲で、礼拝での利用に向けて審査され、ライセンスが付与されたものです。各結果にはライセンスのバッジ（**Free for worship**（礼拝での利用可）または **Public domain**（パブリックドメイン））が表示されるので、追加する前に利用条件を確認できます。

- WorshipCommons の結果をクリックすると、通常の検索結果と同じように、ライブラリに曲を追加できます。
- **View on WorshipCommons** をクリックすると、元のページが新しいタブで開きます。

WorshipCommons の審査を通過した曲だけがここに表示されるため、メインの賛美曲データベースに比べて選択肢は少なくなる場合があります。

WorshipCommons のライブラリ全体を閲覧したり、楽譜を印刷したり、スライドを書き出したりするには、[WorshipCommons のドキュメント](../../worship-commons/index.md)を参照してください。

## 賛美曲の削除

1 曲以上の横にあるチェックボックスをオンにします（表示されているすべての曲を選択する場合は、ヘッダーのチェックボックスをオンにします）。次に、表示されるバーの **Delete Selected** をクリックし、確認します。選択を解除するには **Clear** をクリックします。

## 賛美曲の表示と編集

曲のタイトルをクリックすると、詳細ページが開きます。左側には曲のタイトル、アーティスト、アルバム、キー、長さ、BPM、拍子などの詳細が表示され、アレンジや外部リンクも表示されます。このページから次の操作ができます。

- **賛美曲の詳細を編集する** — **Edit** をクリックすると、タイトル、アーティスト、長さなどのメタデータを更新できます。編集が終わったら **Done** をクリックします。曲をライブラリから削除するには、**Edit** をクリックしてから **Delete song** をクリックします。
- **アレンジを管理する** — 1 つの曲には複数のアレンジを登録できます（キーやバージョンが異なる場合など）。**Add Arrangement** をクリックするとアレンジを作成でき、**Arrangements** の下にあるアレンジ名をクリックすると開けます。
- **歌詞を追加する** — 各アレンジの歌詞を、ChordPro の記法で入力または更新します（例：`[G]Amazing grace`）。エディターの横にあるライブプレビューには、入力に合わせて整形されたコードチャートが表示されるため、賛美チームに実際にどう見えるかを確認できます。
- **キーを設定する** — 歌詞の横にあるキーピッカーで、各アレンジの調を指定します。キーピッカーには、音楽家が通常書く表記で調が並んでいます（C, Db, D, Eb, E, F, F#, G, Ab, A, Bb, B）。キーを変更すると、アレンジのページと礼拝プランから曲を開いたときの両方で、表示されるコードが即座に移調されます。そのため、賛美チームは実際に演奏する調のコードを常に確認できます。コードの綴りもキーに合わせて変わります。Bb や Eb などの変ホ調系のキーでは、シャープではなくフラット表記（Bb, Eb, Ab）のコード名が表示されます。
- **外部リンクを追加する** — YouTube動画、コードチャート、ほかの場所にある楽譜などのリソースへのリンクを添付できます。

## アレンジ

アレンジは、同じ曲の異なるバージョンを表します。たとえば、テンポの速いモダンなバージョンと、ゆっくりしたアコースティックなバージョン、あるいは別のチーム向けに別のキーにした同じ曲などです。同じ曲の各アレンジは、タイトルとアーティストを共有しますが、それぞれ独自の設定を持ちます。

- **キー** — アレンジを演奏する調
- **BPM** — テンポ（1 分あたりの拍数）
- **長さ** — 秒単位の長さ
- **拍子** — 拍子記号（例：4/4、3/4、6/8）
- **構成** — コードやセクションの構造（例：イントロ → ヴァース → コーラス → ブリッジ）
- **歌詞** — 表示やプロジェクション用の歌詞
- **外部リンク** — コードチャート、YouTubeの録音、楽譜、そのほかのリソース

曲を[礼拝の順序](./service-order.md)に追加するときに、その礼拝で使うアレンジを選べるため、賛美チームは常に正しいバージョンで練習し、演奏できます。

### 練習用音源

礼拝の管理者は、アレンジに練習用の音源トラックを添付できます。これにより、チームは練習の前に事前に聴くことができます。

1. 曲を開き、アレンジを選択します。
2. **Upload Audio** をクリックします。
3. MP3、M4A、AAC のいずれかのファイルを選択します（最大 25 MB。ストレージの使用量を抑えるため、WAV は受け付けていません）。
4. 保存します。このアレンジが表示される場所（B1 Admin のアレンジページ、およびチームメンバーが B1.church のメンバーポータルで開いたときの礼拝プラン）では、トラックがその場で再生されます。音源付きのプラン項目は、サムネイルの代わりに音符のアイコンが表示されます。

アレンジを削除すると、アップロードされた音源ファイルも削除されます。

:::info
ライブラリの賛美曲は、プラン内の[礼拝の順序](./service-order.md)に直接追加できます。その際、曲の詳細と選択したアレンジが、その礼拝に紐付けられます。
:::
