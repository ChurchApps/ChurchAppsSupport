# 楽曲

<div class="article-intro">

楽曲ページでは、礼拝で使う楽曲ライブラリを管理できます。楽曲の詳細、歌詞、アレンジをひとつにまとめておけるため、礼拝チームは今後の礼拝の準備をしやすくなり、レパートリーも一貫して保てます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1 Admin の[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)で **Serving > Songs** を選ぶと、楽曲ページを開けます
- 必要に応じて、[礼拝プラン](./plans.md)を先に設定しておくと、楽曲を[礼拝の順序](./service-order.md)に直接リンクできます

</div>

## 楽曲ライブラリを閲覧する

**Songs** ページを開くと、楽曲が表形式で一覧表示されます。各行には楽曲のサムネイル画像、タイトル、アーティスト、長さが表示されます。大規模なライブラリを移動するには、一覧の下にあるページ操作を使うか、検索して目的の楽曲を探してください。

## 楽曲を検索する

1. 楽曲ページ上部の **Search Songs** ボックスをクリックします。
2. 楽曲の **タイトル**または**アーティスト**名を入力します。
3. 入力するとリストが絞り込まれ、一致した楽曲と件数が表示されます。すべての楽曲を再表示するには **Clear** をクリックします。

## 楽曲を追加する

1. 楽曲ページ上部の **Add Song** をクリックします。
2. **Search for a Song** で、外部の楽曲データベースを **Title or Artist** から検索します。
3. 追加したい楽曲を選択します。見つからない場合は **Create Manually** をクリックします。
4. 基本情報が自動入力された状態で、楽曲がライブラリに追加されます。

:::tip
楽曲を追加したら、その楽曲をクリックして詳細を確認・更新したり、アレンジを追加したり、YouTube動画やコード譜などの外部リンクを添付したりできます。
:::

### WorshipCommonsの無料楽曲

検索結果には、通常の結果に加えて **WorshipCommons — free** のセクションが表示される場合があります。これらは [WorshipCommons](https://worshipcommons.org) の楽曲で、礼拝での利用について審査・ライセンス取得済みのものです。各結果にはライセンスバッジ（**Free for worship** または **Public domain**）が表示されるので、追加する前に利用条件を確認できます。

- WorshipCommonsの結果をクリックすると、通常の検索結果と同様にライブラリへ追加されます。
- **View on WorshipCommons** をクリックすると、元のページが新しいタブで開きます。

WorshipCommonsの審査を通過した楽曲だけが表示されるため、メインの楽曲データベースより選択肢は少なくなる場合があります。

## 楽曲を削除する

1 曲以上の楽曲の横にあるチェックボックスをオンにします（表示中のすべての楽曲を選択するには、ヘッダーのチェックボックスをオンにします）。続いて表示されるバーで **Delete Selected** をクリックし、確認してください。選択を解除するには **Clear** をクリックします。

## 楽曲を表示・編集する

楽曲のタイトルをクリックすると、詳細ページが開きます。左側には楽曲のタイトル、アーティスト、アルバム、キー、長さ、BPM、拍子などの詳細が表示され、アレンジと外部リンクもあわせて表示されます。このページでは次の操作ができます。

- **楽曲の詳細を編集する** -- **Edit** をクリックすると、タイトル、アーティスト、長さなどのメタデータを更新できます。終わったら **Done** をクリックします。楽曲をライブラリから削除するには、**Edit** をクリックしてから **Delete song** をクリックします。
- **アレンジを管理する** -- 1 つの楽曲には複数のアレンジ（キーやバージョンの違いなど）を登録できます。**Add Arrangement** をクリックして新しいアレンジを作成し、**Arrangements** の下にあるアレンジ名をクリックすると開けます。
- **歌詞を追加する** -- ChordPro記法（例：`[G]Amazing grace`）を使って、各アレンジの歌詞を入力・更新します。エディタの横にあるライブプレビューには、入力に合わせて整形されたコード譜が表示されるので、チームに表示される内容をそのまま確認できます。
- **キーを設定する** -- 歌詞の横にあるキーピッカーで、各アレンジの調を指定します。ピッカーには、音楽家が一般的に表記する形式でキーが並んでいます（C, Db, D, Eb, E, F, F#, G, Ab, A, Bb, B）。キーを変更すると、アレンジのページでも、礼拝プランから楽曲を開いたときにも、表示されるコードがすぐに移調されます。そのため、チームは実際に演奏するキーのコードを常に確認できます。コードのつづりもキーに合わせて変わり、Bb や Eb などのフラットのキーでは、シャープではなくフラットのコード名（Bb, Eb, Ab）が表示されます。
- **外部リンクを追加する** -- YouTube動画、コード譜、他所でホストされている楽譜などの資料へのリンクを添付できます。

## アレンジ

アレンジは、楽曲の異なるバージョンを表します。たとえば、テンポの速い現代的なバージョンと、ゆったりしたアコースティックなバージョン、あるいは別のチーム向けに異なるキーにした同じ楽曲などが該当します。同じ楽曲のアレンジ同士は、楽曲のタイトルとアーティストを共有しますが、それぞれ独立した設定を持ちます。

- **キー** — アレンジを演奏する調
- **BPM** — 1 分あたりの拍数によるテンポ
- **長さ** — 秒単位の演奏時間
- **拍子** — 拍子記号（例：4/4、3/4、6/8）
- **構成** — コードやセクションの流れ（例：イントロ → ヴァース → コーラス → ブリッジ）
- **歌詞** — 表示やプロジェクション用
- **外部リンク** — コード譜、YouTubeの録音、楽譜、その他の資料

楽曲を [礼拝の順序](./service-order.md)に追加するときは、その礼拝で使用するアレンジを選べます。そのため、チームは常に正しいバージョンで練習し、演奏できます。

### リハーサル用音声

礼拝の管理者は、アレンジにリハーサル用の音声トラックを添付できます。これにより、チームは練習の前に事前に聴いておけます。

1. 楽曲を開き、アレンジを選択します。
2. **Upload Audio** をクリックします。
3. MP3、M4A、またはAACのファイルを選択します（最大 25 MB。ストレージ使用量を抑えるため、WAVは受け付けていません）。
4. 保存します。そのアレンジが表示される場所であれば、音声トラックがインラインで再生されます。B1 Admin のアレンジページや、チームメンバーが B1.church のメンバーポータルで礼拝プランを開いたときにも再生されます。音声付きのプラン項目にはサムネイルの代わりに音符アイコンが表示されます。

アレンジを削除すると、アップロードされた音声ファイルも削除されます。

:::info
ライブラリの楽曲は、プラン内の [礼拝の順序](./service-order.md)に直接追加できます。その際、楽曲の詳細と選択したアレンジが、その特定の礼拝に紐付けられます。
:::
