# プランテンプレート

<div class="article-intro">

プランテンプレートを使うと、プランの礼拝順序や奉仕者の配置を再利用可能なひな形として保存し、今後のプランにワンクリックで適用できます。毎週同じ構成を一から作り直す必要はなく、一度保存すれば必要なだけ今後のプランに適用できます。

</div>

- 礼拝順序または配置を定義した[礼拝プラン](plans.md)を少なくとも1つ作成してください
- B1 Admin の **Serving** エリアにアクセスできる必要があります

## プランをテンプレートとして保存する

1. **Serving** エリアから既存のプランを開きます。
2. プランの **礼拝順序** セクションで、**テンプレートとして保存** をクリックします。
3. テンプレートに名前を付けます（例：「標準の日曜礼拝」や「礼拝＋説教」）。
4. 保存します。テンプレートには、保存した時点のプランの礼拝順序、配置、メモが記録されます。

## テンプレートの管理

任意のプランタイプのページで、プラン一覧の上にある **テンプレート** をクリックすると **プランテンプレート** が開きます。そこでは次の操作ができます。

- **名前変更**：テンプレートの表示名を変更します
- **プランから更新**：テンプレートの内容を、プランの現在の状態で置き換えます（標準の構成を見直した後に便利です）
- **適用**：テンプレートを1つ以上の今後のプランに反映します
- **削除**：不要になったテンプレートを削除します

## テンプレートをプランに適用する

1. プランタイプのページで、プラン一覧の上にある **テンプレート** をクリックします。
2. 使用したいテンプレートの横にある **適用** アイコン（コピーのアイコン）をクリックします。
3. 適用先の今後のプランを、チェックボックスで選択します。
4. コピーする内容を選びます。
   - **礼拝順序**：選択したプランの礼拝順序の項目を、テンプレートの項目で置き換えます
   - **配置**：選択したプランの配置（およびその割り当て）を、テンプレートの配置で置き換えます
5. **適用** をクリックします。

テンプレートにメモが含まれている場合、適用すると選択したプランのメモもテンプレートのメモで置き換えられます。

:::warning
配置を適用すると、選択したプランの既存の配置と割り当てがすべて置き換えられます。適用する前に、それらの配置にすでに奉仕者を割り当てていないか確認してください。
:::

:::tip
曲や説教の流れは毎週同じにしたいけれど、奉仕者の割り当ては毎週異なる場合は、配置を含めず礼拝順序だけを適用してください。
:::

## テンプレートから新しいプランを作成する

テンプレートは、ミニストリー内のプランタイプ間で共有されます。**新しいプラン** をクリックしたときにミニストリーにテンプレートがあると、新規プランのフォームに **テンプレートから開始** のリストが表示されます。テンプレートを選んで保存すると、そのテンプレートの礼拝順序、配置、メモを持つ新しいプランが作成されます。テンプレートを選ぶと、そのプランでは **前のプランからコピー** のオプションは使用できなくなります。

## テンプレートを最新の状態に保つ

標準の礼拝構成が変わった場合は、テンプレートマネージャーを開き、**プランから更新** を使って最新のプランからテンプレートを同期してください。ゼロから作り直す必要はありません。
