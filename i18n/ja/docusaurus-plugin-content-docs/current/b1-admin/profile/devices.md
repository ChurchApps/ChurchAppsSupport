# デバイスの管理

<div class="article-intro">

デバイスページでは、お使いのアカウントに接続されている ChurchAppsPlayer と FreePlay のデバイスを管理できます。これらのデバイスは、教会内の画面でストリーミングコンテンツや教会のメディアを表示するために使用されます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- ChurchAppsPlayer デバイスの電源が入っていて、インターネットに接続されていることを確認してください
- デバイスの画面に表示されているペアリングコードを控えてください
- まだの場合は、[プロフィール設定](./managing-profile.md)を確認してください

</div>

## デバイスの表示

デバイスページを開くと、登録されているすべてのデバイスが次の情報とともに表で表示されます。

- **ラベル** -- デバイスに割り当てた名前です。
- **登録日** -- デバイスが初めてアカウントとペアリングされた日時です。
- **最終アクティブ日** -- デバイスが最後にアカウントへ接続された日時です。

## 新しいデバイスの追加

1. デバイスページ上部の **画面を追加** ボタンをクリックします。
2. **ペアリングコード** の入力を求められます。
3. 接続したい ChurchAppsPlayer または FreePlay デバイスの画面に表示されているペアリングコードを確認します。
4. コードを入力します。FreePlay TV の場合は、**次のプランを表示** のドロップダウンで、その画面が従うプランの種類を選択できます。閲覧と通知のみにデバイスを使用する場合は、**なし** のままにしてください。
5. 確定します。ペアリングに成功すると、デバイスが表に表示されます。

:::tip
ペアリングを行う前に、デバイスの電源が入っていて、インターネットに接続されていることを確認してください。ペアリングコードはデバイスの画面に表示されています。
:::

## デバイスのラベルの編集

1. デバイス一覧表で、対象のデバイスの横にある **編集** をクリックします。
2. ラベルを、わかりやすい名前に変更します（例：「礼拝堂メイン画面」や「ロビーディスプレイ」）。
3. 変更を保存します。

:::tip
わかりやすいラベルを付けておくと、特に教会に複数の画面を設置している場合に、どのデバイスがどれなのかを簡単に見分けられます。
:::

## デバイスへのアクセスの管理

デバイスページを使うと、どのデバイスが教会のストリーミングやコンテンツにアクセスできるかを把握できます。使用しなくなったデバイスは、アカウントから削除することで、デバイス一覧を整理し、安全に保つことができます。

:::warning
接続されているデバイスを定期的に確認し、現在使用している承認済みのデバイスだけがアカウントに接続されていることを確認してください。セキュリティを維持するため、使用しなくなったデバイスは削除してください。
:::
