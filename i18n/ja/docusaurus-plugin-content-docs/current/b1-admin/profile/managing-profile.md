# プロフィールの管理

<div class="article-intro">

プロフィールページでは、個人のアカウント設定を編集できます。プロフィールはすべての ChurchApps 製品で共有されるため、ここで行った変更は ChurchApps を利用するすべての場所に反映されます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- ChurchApps アカウントにログインしている必要があります
- メールアドレスやパスワードを変更する場合は、新しい値を用意しておいてください

</div>

## プロフィール情報

プロフィールページの左側には、お名前とメールアドレスが表示され、その下に **編集** ボタンがあります。**編集** をクリックすると **アカウントの編集** フォームが開きます。このフォームには、基本的なアカウント情報が含まれています。

1. **メールアドレス** -- ログインと通知の受信に使用するメールアドレスです。
2. **名** と **姓** -- ChurchApps 全体で表示される名前です。
3. **パスワード** -- アカウントのパスワードを更新します。

情報を更新するには、項目を編集して **変更を保存** ボタンをクリックします。保存せずにプロフィールに戻るには、**キャンセル**（またはお名前が表示された **戻る** リンク）をクリックします。

## パスワードの変更

1. プロフィールページで **編集** をクリックします。
2. **現在のパスワード** を入力します。
3. **新しいパスワード** 欄に新しいパスワードを入力します。
4. **パスワードの確認** 欄に、もう一度同じパスワードを入力します。
5. **変更を保存** をクリックします。

:::info
パスワードは8文字以上にしてください。パスワードと確認用の入力が完全に一致していることを確認してください。パスワードを変更するには現在のパスワードの入力が必要です。現在のパスワードがわからない場合は、代わりにログインページの **パスワードをお忘れですか** リンクをご利用ください。
:::

## 連携アカウント

**連携アカウント** セクションには、ChurchApps アカウントに接続されている外部サービスが表示されます。このセクションで、連携されているアカウントを確認したり、接続を管理したりできます。

## 二要素サインイン

二要素サインインは、ログイン時に追加の手順を設けるものです。パスワード（または Google、Microsoft、メールのサインインリンク）の入力後に、スマートフォンの認証アプリ（Google Authenticator、Microsoft Authenticator、1Password、Authy など）に表示される6桁のコードも入力します。この機能は任意で、初期状態ではオフになっています。オンにすると、お使いのアカウントでログインするすべての ChurchApps サービスに適用されます。B1 Admin、教会の B1.church サイトとアプリ、B1 Church Checkin、Lessons.church、FreePlay などが対象です。

### オンにする方法

1. プロフィールページで **二要素サインイン** セクションを見つけ、**オンにする** をクリックします。
2. 認証アプリで QR コードを読み取ります。読み取れない場合は、**スキャンできませんか？このキーを入力してください:** の下に表示されるキーを、アプリに直接入力します。
3. アプリに表示された **6桁のコード** を入力し、**確認** をクリックします。
4. B1 Admin に **バックアップコード** が10個表示されます。各コードは、スマートフォンをなくした場合に1回だけサインインするために使用できます。**コピー** をクリックするか書き留めて、安全な場所に保管し、**保存しました** をクリックします。

:::warning
バックアップコードは一度しか表示されません。スマートフォンをなくし、使えるバックアップコードもない場合は、ChurchApps のサーバー管理者が本人確認を行った上で、二要素サインインをオフにする必要があります。
:::

二要素サインインがオンの間は、セクションに **オン** と表示され、残りのバックアップコードの数も表示されます。

### コードを使ったサインイン

パスワードを入力すると、ログイン画面でコードの入力を求められます。認証アプリに表示された6桁のコード、またはバックアップコードのいずれかを入力して送信してください。バックアップコードは、それぞれ1回しか使用できません。コードが正しくない場合は、「コードが正しくありません。もう一度お試しください。」と表示されます。誤ったコードを何度も入力すると、そのアカウントのログインが一時的に停止されます。

すでにログインしている端末でサインインの状態を保っている場合、再度コードを求められることはありません。コードが必要になるのは、新たにログインする場合のみです。

### オフにする方法

1. **二要素サインイン** セクションで **オフにする** をクリックします。
2. 認証アプリに表示されている現在のコード、またはバックアップコードを入力します。
3. **確認** をクリックします。

:::info
デモアカウントでは二要素サインインを設定できないため、このセクションは表示されません。
:::

## テーマの設定

B1 Admin では、カラーテーマと、明るい表示モードまたは暗い表示モードを選択できます。

1. B1 Admin の右上にあるプロフィール写真をクリックして、ユーザーメニューを開きます。
2. **テーマの設定** で、テーマを選択します。
   - **デフォルト** -- 現在の B1 Admin の見た目です。枠線のあるパネルを、すっきりとした背景に配置しています。新しいユーザーには、別のテーマを選ぶまでこのテーマが表示されます。
   - **クラシック** -- 以前の B1 Admin の見た目です。カラーのページバナー、影付きのカード、グレーの背景が特徴です。新しい見た目が登場する前に、この端末で B1 Admin を使い、テーマを選択していなかった場合は、引き続きクラシックが適用されます。
   - **カスタム** -- 教会独自の色を使ったデフォルトの見た目です。**モバイル > アプリテーマ** のライトモードのメインカラーを使用します。アプリの色が設定されていない場合は、Web サイトのメインカラーを使用します。そのため、B1 Admin がメンバー向けアプリと同じ色合いになります。
3. テーマの下で、**ライトモード** または **ダークモード** を選択します。
4. 画面には選択内容がすぐに反映されます。

選択内容は、その端末とブラウザーに保存されます。

## アカウントの削除

プロフィールページの **アカウントの削除** セクションに、アカウントを削除するための項目があります。

- 教会で削除承認グループが設定されていない場合は、**自分のアカウントを削除** をクリックすると、アカウントと関連データがすぐに削除されます。この操作は取り消せません。
- 教会で削除承認グループが設定されている場合は、代わりにリクエストがそのグループに送られ、確認されます。リクエストが処理されるまでボタンは無効になります。教会が承認または却下すると通知が届きます。その後の流れについては、[アカウント削除リクエストの確認](./account-deletion.md)をご覧ください。

:::warning
アカウントの削除は、即時実行されるものでも教会が承認したものでも、恒久的な操作であり、元に戻すことはできません。
:::

:::info
**ドメイン管理者** の場合は、アカウントを削除する前に、管理権限を別のユーザーに移してください。管理者の役割の管理について詳しくは、[役割と権限](../settings/roles-permissions.md)をご覧ください。
:::

:::info
デモモードではプロフィールの編集はできません。デモアカウントを使用している場合、プロフィール設定を変更することはできません。
:::
