# プロフィール

<div class="article-intro">

プロフィールセクションでは、ChurchApps の個人アカウント設定を管理できます。プロフィールは ChurchApps のすべてのツールで共有されるため、ここで行った変更は B1 Admin から B1 App まで、どこにでも反映されます。

</div>

## できること

プロフィールセクションでは、次のことができます。

- **名前とメールアドレスを更新する** -- 連絡先情報を常に最新の状態に保ちます。
- **パスワードを変更する** -- アカウントの新しいパスワードを設定します。
- **2 要素認証をオンにする** -- ログイン時に認証アプリのコードを要求するようにします。詳しくは [2 要素認証](./managing-profile.md#two-factor-sign-in) を参照してください。
- **テーマを切り替える** -- ユーザーメニュー(画面右上のプロフィール写真をクリック)から、ライトモードとダークモードを切り替えます。
- **接続済みデバイスを管理する** -- アカウントにリンクされている ChurchAppsPlayer デバイスを確認し、管理します。
- **連携アカウントを確認する** -- ChurchApps アカウントに接続されている外部サービスを確認し、管理します。
- **プロフィール変更の申請を承認する** -- メンバーから送信されたプロフィール更新を確認し、反映します。

## プロフィールのサブセクション

プロフィールエリアには、次のページがあります。

1. **[プロフィールの管理](./managing-profile.md)** -- 個人情報の編集、パスワードの変更、連携アカウントの管理、2 要素認証の設定、テーマの調整、アカウントの削除を行います。
2. **[プロフィール変更の承認](./approving-profile-changes.md)** -- B1 App を通じてメンバーから送信されたプロフィール更新の申請を確認し、承認します。
3. **[デバイスの管理](./devices.md)** -- アカウントとペアリングされている ChurchAppsPlayer デバイスを確認、追加、管理します。

:::tip
メールアドレスは常に最新の状態にしておいてください。アカウントの復旧や、教会からの重要なお知らせに使用されます。
:::
