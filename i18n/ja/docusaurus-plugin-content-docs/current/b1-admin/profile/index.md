# プロフィール

<div class="article-intro">

プロフィールのセクションでは、ChurchAppsの個人アカウント設定を管理できます。プロフィールはすべてのChurchAppsツールで共有されるため、ここで行った変更はB1 Adminからモバイルアプリの B1 Mobile まで、どこにでも反映されます。

</div>

## できること

プロフィールのセクションでは、次のことができます。

- **名前とメールアドレスの更新** — 連絡先情報を最新の状態に保ちます。
- **パスワードの変更** — アカウントの新しいパスワードを設定します。
- **二段階認証のオン** — ログイン時に認証アプリのコードを求めるようにします。詳しくは [二段階認証](./managing-profile.md#two-factor-sign-in) をご覧ください。
- **テーマの切り替え** — ユーザーメニュー（右上のプロフィール写真をクリック）からライトモードとダークモードを切り替えます。
- **接続済みデバイスの管理** — アカウントにリンクされている ChurchAppsPlayer デバイスを確認・管理します。
- **連携アカウントの確認** — ChurchAppsアカウントに接続されている外部サービスを確認・管理します。
- **プロフィール変更リクエストの承認** — メンバーから送信された更新内容を確認し、適用します。

## プロフィールのサブセクション

プロフィールの領域には、次のページがあります。

1. **[プロフィールの管理](./managing-profile.md)** — 個人情報の編集、パスワードの変更、連携アカウントの管理、二段階認証のオン、テーマ設定の調整、アカウントの削除を行います。
2. **[プロフィール変更の承認](./approving-profile-changes.md)** — B1 Mobile からメンバーが送信したプロフィール更新リクエストを確認し、承認します。
3. **[デバイスの管理](./devices.md)** — アカウントとペアリングされた ChurchAppsPlayer デバイスを確認、追加、管理します。

:::tip
メールアドレスは常に最新の状態にしておいてください。アカウントの復旧や、教会からの重要なお知らせに使用されます。
:::
