# プロフィール変更の承認

<div class="article-intro">

教会がプロフィールの更新に管理者の承認を必要としている場合、メンバーはB1 Appから変更を申請し、そのリクエストはB1 Adminのタスクとして表示されます。このガイドでは、それらを確認して承認する方法を説明します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- **メニュー → メンバーポータル**で「ディレクトリ承認グループ」に指定されているグループのメンバーである必要があります
- 承認グループが設定されていない場合、プロフィールの変更は確認なしに即座に適用されます

</div>

## 保留中のリクエストの探し方

メンバーがプロフィールの変更を申請すると、承認グループに割り当てられたタスクとして表示されます。次の2か所で確認できます。

**ダッシュボード（ホームページ）から:**
1. B1 Adminにログインします。ダッシュボードが自動的に表示されます。
2. **マイタスク**セクションで、**すべてのタスク**をクリックします。（マイタスクには、自分個人に割り当てられた未完了のタスクだけが表示されます。）
3. **自分のグループに割り当て**タブをクリックします。保留中のプロフィール変更リクエストがここに一覧表示されます。

**奉仕 → マイワークから:**
1. [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（B1 Adminの左上にある検索バー）を開き、**奉仕**を展開します。
2. **マイワーク**をクリックします。
3. タスクの下にある**自分のグループに割り当て**タブをクリックします。

## リクエストの確認と承認

1. **プロフィール更新**タスクをクリックして開きます。
2. **リクエストされた変更**の下に、メンバーが更新したい各項目と、送信された新しい値が表示されます。
3. 変更内容を確認します。
4. **適用**をクリックして承認し、変更をメンバーのプロフィールに保存します。

変更が適用されると、タスクは自動的に完了になります。

## 承認グループの設定

教会でプロフィールの変更に承認を必要とする場合は、先にディレクトリ承認グループを設定しておく必要があります。

1. ジャンプメニューを開き、**モバイル**を展開します。
2. **メンバーポータル**（「ポータル設定」ページ）をクリックします。
3. **ディレクトリ承認グループ**で、プロフィール変更リクエストを確認すべきメンバーが属するグループを選択します。
4. **保存**をクリックします。

このグループのメンバーであれば、ダッシュボードの**自分のグループに割り当て**に、受信したプロフィール変更リクエストが表示されるようになります。

同じディレクトリ承認グループが**アカウント削除リクエスト**も確認します。詳しくは[アカウント削除リクエストの確認](./account-deletion.md)をご覧ください。

:::tip
承認者が設定されたグループの実際のメンバーであることを確認してください。リクエストが表示されるのはグループのメンバーだけです。
:::
