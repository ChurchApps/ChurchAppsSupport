# B1 Admin 概要

<div class="article-intro">

B1 Admin は、教会の管理用ダッシュボードです。会員名簿や献金から、Web サイトの構築やライブ配信まで、教会運営のあらゆる側面を管理するためのツールを、ひとつの場所にまとめて提供します。

</div>

## はじめに

1. ブラウザで [admin.b1.church](https://admin.b1.church) を開きます
2. ユーザー名とパスワードでサインインします
3. ホームページとなる **ダッシュボード** が表示されます。今週の礼拝の式次第、リアルタイムでチェックインしている人と奉仕中の人、対応が必要な項目(承認待ちや参加申請など)、未完了のタスク、所属グループが一覧で確認できます

:::tip
B1 Admin を初めてお使いですか？ まず [はじめに](./introduction) で動画による操作説明をご覧ください。その後、[設定](./settings/) で教会情報を登録し、チームのメンバーを招待してください。
:::

## ダッシュボードについて

ダッシュボードは B1 Admin のホームページ(`/`)です。教会の週間礼拝を中心に構成されています。

- **今週の礼拝** -- 現在または次の礼拝計画の名前と式次第です。計画の全体を開くリンクもあります
- **ライブステータス** -- 日曜日にチェックインが始まると、会場にいる人数、この時間に奉仕している人、初めて来られたゲスト、部屋ごとの収容状況(容量バー付き)が表示されます
- **要対応** -- 対応が必要な承認待ちやグループへの参加申請
- **マイタスク** と **マイグループ** -- 未完了のタスク(**タスクを追加** で新規作成、または **すべてのタスク** で一覧表示)と、所属しているグループ

ダッシュボードに表示される内容は、お使いの [役割](./settings/roles-permissions.md) によって異なります。たとえば、礼拝計画の全体を開くリンクは、その計画を開く権限がある場合(計画を編集できる、計画の部門に所属している、またはその計画で奉仕している場合)にのみ表示されます。**すべてのグループ** のリンクは、グループを管理できる、グループのメンバーを閲覧できる、または人の情報を閲覧できる場合にのみ表示されます。

:::tip
説教、カレンダー、モバイル、設定など、すべてのセクションには、B1 Admin の左上にある [ジャンプメニュー](./introduction.md#getting-around-with-the-jump-menu) からアクセスできます。メニューをクリックするか、**Ctrl+K**(Mac の場合は **Cmd+K**)を押し、項目を探すか名前を入力してください。
:::

## 主な機能

- **[人物](./people/)** - 教会の名簿を管理し、会員を追加し、データを一括編集できます。家族単位または並べ替え可能な表形式で閲覧できます。各人物のページでは、左側に基本情報、右側に出席、献金、グループ、メモ、フォームの概要が表示されます。**登録日** の検索で、最近追加された人を見つけられます。[メモ](./people/notes) のページでは、人物、グループ、イベント、ワークフローカードにわたる最近のメモを一覧で確認できます
- **[グループ](./groups/)** - 教会のグループを作成し、整理できます。参加申請、メンバー管理、グループへのメール送信、再利用可能なテキストテンプレートと「グループ名」の差し込み項目を使った個別のグループ向けテキストメッセージ、印刷可能な連絡先名簿に対応しています。各グループのページでは、左側にアクションが並び、右側にメンバー、礼拝、カレンダー、グループの状態の概要が表示されます
- **[出席](./attendance/)** - キャンパス、礼拝時間を設定し、記名式の出席を記録できます。印刷可能なクラス出席表で、まだ出席が入力されていないクラスを確認できます。人数だけを記録する簡易出席と推移レポートにも対応しています。各礼拝時間にチェックインのスケジュールを設定すると、セルフチェックインが自動的に開始・終了します(各キャンパスのタイムゾーンに基づきます)。初めて来られたゲストは、お好みの項目を指定した [QR コード](./attendance/check-in#guest-registration-via-qr-code) から登録できます
- **[献金](./donations/)** - 複数の通貨で献金を記録し、献金の種類を管理できます。個人の記録から単一の献金を登録できます。献金の束(1 つずつ、または日付範囲内のすべて)を、教会のレターヘッドに小計付きで印刷できます。集計が終わった束は締めることができます。CSV ファイルから束を取り込めます。**献金を入力** の権限を持つ集計チームが献金を入力できます。教会のロゴ入りの献金明細書を作成できます
- **[奉仕](./serving/)** - ボランティアを調整し、礼拝計画を作成できます(週ごとに最大 12 週間先までコピーすることも可能です)。プッシュ通知、メール、テキストでリマインダーを送信できます。**ボランティアにテキスト** で、予定が入っている全員にテキストメッセージを送れます。タスクを管理し、メールやテキストの送信、職員への通知、出席の記録、ボランティアが奉仕の割り当てを確認したかの追跡ができる、段階的なワークフローを進めることができます。定期的なワークフロールールで、献金が途絶えた定期献金者を見つけられます。印刷された計画では、空の列は省略されます
- **[フォーム](./forms/)** - 登録やデータ収集のためのカスタムフォームを作成できます。ヘッダー画像を追加し、QR コードで単独のフォームを共有できます。フォームをグループにリンクすると、グループのリーダーが回答を閲覧・印刷できます
- **[レポート](./reports/)** - 誕生日、出席、献金のレポートを閲覧できます
- **[Web サイト](./website/)** - カスタムのナビゲーションスタイルで教会の Web サイトを構築・管理できます。GA4 ID を使って、Web サイトと B1 アプリへのアクセスを追跡できます。公開サイトをオフにして、会員専用ポータルのみを残すこともできます
- **[説教](./sermons/)** - 説教のライブラリ、ライブ配信、自動生成されるポッドキャストフィードを管理できます
- **[カレンダー](./calendars/)** - 厳選されたカレンダーを作成し、部屋や備品の予約を管理し、空き状況を確認できます。料金を設定した参加者区分で[イベント登録](./calendars/paid-registrations)を受け付けられます。参加者を手動で追加し、課金せずに登録できます。教会がオンライン献金を利用していない場合は、後から登録と支払いができるようにすることもできます
- **[設定](./settings/)** - 1 ページにまとめられた設定で、すべてを構成できます。クイックジャンプの一覧を使って、教会情報、地域、日付と電話番号の形式、テキストメッセージ(ご自身の Twilio アカウントを含む)、会員数付きの役割、権限、カスタムの人物項目などを設定できます

:::info
どのページの右上にある「?」アイコンをクリックすると、ヘルプとドキュメントにすぐにアクセスできます。カラーテーマ(**デフォルト**、**クラシック**、**カスタム**)を変更したり、ライトモードとダークモードを切り替えたりするには、ユーザーメニューを開き、**テーマの設定** を使用してください。認証アプリのコードでアカウントを保護するには、プロフィールで [2 段階サインイン](./profile/managing-profile#two-factor-sign-in) をオンにしてください。
:::

サポートが必要な場合は、[support@churchapps.org](mailto:support@churchapps.org) までメールでお問い合わせください。
