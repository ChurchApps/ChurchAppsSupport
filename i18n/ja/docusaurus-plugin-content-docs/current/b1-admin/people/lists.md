# 保存したリスト

<div class="article-intro">

**保存したリスト**を使うと、検索条件に名前を付けて保存し、いつでもワンクリックで再実行できます。「Campus North のアクティブメンバー」「過去90日間のビジター」など、任意の詳細フィルターを一度作成すれば、People ページの一番上に表示され続けるので、同じ検索条件を何度も作り直す必要がありません。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 保存する結果を得るために、People セクションで少なくとも1回は検索を実行してください。[People の検索](./searching-people.md)または [AI 検索](./ai-search.md)を参照してください。

</div>

## 検索を리스트として保存する

1. **People** ページで検索を実行します。クイック検索、AI 検索、詳細フィルター検索のいずれでも構いません。
2. 結果が表示されると、People ページのヘッダーに **Save as List** ボタンが表示されます。
3. **Save as List** をクリックします。
4. **List Name**（必須）を入力します。
5. 任意で **Category** を入力し、関連するリストをグループ化します（例：「アウトリーチ」「メンバーシップ」）。
6. **Who can see this list** で **All staff** または **Only me** を選択します。
7. **Save** をクリックします。

リストが保存され、People ページ上部の保存済みリストの行に、**Everyone** の隣にボタンとして表示されます。**Only me** に設定したリストには小さな鍵アイコンが表示されます。

:::info
**All staff** に設定したリストは教会全体で共有されます。People へのアクセス権を持つスタッフは誰でも閲覧して読み込めます。リストの変更や削除は、適切な権限を持つスタッフonly が行えます。
:::

## 保存したリストを読み込む

People ページの上部で、任意のリスト名をクリックします。保存された検索条件がすぐに再実行され、結果が更新されます。教会全体のディレクトリに戻るには **Everyone** をクリックします。

リストは（カテゴリーを設定している場合）カテゴリーごとにグループ化され、カテゴリーのないリストは最後に表示されます。

:::tip
リストは**スナップショット**ではなく**ライブクエリ**です。リストを読み込むたびに、現在のデータに対して検索が新たに実行されるため、条件に新しく一致した人も表示されます。
:::

## リストの名前変更と削除

マネージ権限を持つスタッフは、People ページからどのリストでも名前を変更したり削除したりできます。まずリストをクリックして読み込んでください。すると、リスト名の横に2つのアイコンが表示されます。

- **List Settings**（歯車）アイコンをクリックすると、名前、カテゴリー、共有設定などを変更できます。
- **Delete**（ゴミ箱）アイコンをクリックすると、リストを削除できます（確認を求められます）。

## 活用例

| シナリオ | リストの作成方法 |
|---|---|
| すべてのビジター | 詳細検索：Membership Status = Visitor |
| 特定のキャンパスのメンバー | 詳細検索：Campus = [お使いのキャンパス] |
| メールアドレスが未登録の人 | 詳細検索：Email is empty |
| 身元調査の有効期限が切れたボランティア | 詳細検索：[カスタムフィールド](../settings/custom-fields.md)「Background check expires」が今日より前 |
| AI への質問の結果 | AI 検索で質問し、保存する |
