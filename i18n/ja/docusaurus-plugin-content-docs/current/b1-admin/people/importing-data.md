# データのインポート

<div class="article-intro">

B1 Transfer ツールを使えば、既存のデータを B1 に簡単に取り込めます。スプレッドシートから新たに始める場合も、別の教会管理プラットフォームから移行する場合も、献金記録をインポートする場合も対応できます。また、データのエクスポートやバックアップにも、いつでも使用できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- **設定** にアクセスできる、有効な B1 Admin アカウントが必要です。
- 始める前に、以前使っていたシステムからデータをエクスポートし、準備しておいてください。
- このツールは初期のデータ移行を目的としています。すでに B1 をしばらく使用している場合、再度インポートすると重複したレコードが作成される可能性があります。

</div>

## Transfer ツールへのアクセス

1. **B1 Admin** にログインします。
2. [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**設定** を展開して、**設定** をクリックします。
3. 左側の設定メニューの上部にある、教会名の下の **Import/Export** リンクをクリックします。
4. **B1 Transfer** ツールが新しいタブで [transfer.b1.church](https://transfer.b1.church) に開きます。

Transfer ツールは、ソース、プレビュー、送信先、実行の4つのステップで進みます。

---

## ステップ 1 - ソースを選択

データの取得元を選択します。選択肢は7つあります。

- **B1 Database** — 既存の B1 教会のデータを直接取得します。バックアップを作成したり、データを別の形式に変換したりする際に便利です。このオプションを使用するには、ログインしている必要があります。
- **B1 Import Zip** — B1 独自の形式の zip ファイルです。主に以前の B1 エクスポートを復元する際に使用します。B1 エクスポートの Zip を **B1 Database** に読み込むと、エクスポートに含まれるすべての内容が復元されます（[データのエクスポート](./exporting-data.md#full-data-export-from-settings)を参照）。ファイルを読み取れない場合、ツールは最初からやり直すのではなく、エラーを表示します。
- **Breeze Import Zip** — Breeze ChMS からエクスポートしたファイルを含む zip ファイルです。
- **Planning Center Zip** — Planning Center からエクスポートした zip または CSV ファイルです。
- **Custom CSV / Excel** — 人物データを含む任意の CSV または Excel ファイルです。アップロード後、インポートを進める前に、列を B1 のフィールドに割り当てます。
- **Tithe.ly CSV** — Tithe.ly からエクスポートした人物データまたは献金データのファイルです（CSV または Excel 形式に対応）。
- **CCB / Pushpay CSV** — Church Community Builder または Pushpay からエクスポートした人物データまたは献金データの CSV です。

ファイルをアップロード領域にドラッグ＆ドロップするか、クリックして参照することもできます。

---

## ステップ 1b - フィールドを割り当てる（Custom CSV / Excel のみ）

**Custom CSV / Excel** を選択した場合、ファイルをアップロードすると、プレビューに進む前にフィールド割り当て画面が表示されます。

ファイルの各列は、サンプル値とともに一覧表示されます。各列について、ドロップダウンを使用して対応する B1 のフィールドを選択します。ツールは「First Name」「Email」「Zip Code」などの一般的な列名を自動検出しますが、すべての行を確認し、見落とされた箇所があれば修正してください。

割り当て可能な B1 のフィールドは次のとおりです。

- First Name、Last Name、Middle Name、Nickname、Display Name、Title/Prefix、Suffix
- Email、Home Phone、Mobile Phone、Work Phone
- Address Line 1、Address Line 2、City、State、Zip Code
- Birth Date、Anniversary、Gender、Marital Status、Membership Status
- Household/Family Name
- Group Name — 名前を指定して人物をグループに追加します
- **Custom Field (match by name)** — 列の値を、教会の[カスタム人物フィールド](../settings/custom-fields.md)のいずれかに保存します。**B1 field name** ボックスが表示され、列の見出しが自動入力されます。B1 に表示されている項目名どおりに変更してください（大文字と小文字は区別されません）。
- **Form Answer (custom field)** — 列の値を、人物のレコードに紐づくカスタムフィールドとして保存します。このオプションを使用する場合、フォームに名前を付けるよう求められます。

日付は `9/17/1994` のような一般的な形式で入力でき、自動的に変換されます。カスタムフィールドについては、Yes/No のフィールドは Yes、No、Y、N、True、False、1、0 などの値を受け付けます。選択式のフィールドは、選択肢のテキストまたはその値のどちらでも受け付けます。

:::info
インポートする前に、B1 Admin でカスタム人物フィールドを作成しておいてください。インポートが完了すると、**Custom Fields** ステップに、B1 のフィールドと一致しない列名が一覧表示され、フィールドの種類に合わない値の件数が表示されます。そのような値はスキップされ、残りのインポートは完了します。
:::

インポートしない列は **(Skip)** に設定できます。次に進むには、名前のフィールド（First Name または Last Name）の少なくとも一方を割り当てる必要があります。

**Confirm Mapping & Import** をクリックすると、プレビューに進みます。

---

## ステップ 2 - データをプレビューする

アップロード後、ツールはインポートされるすべてのデータのプレビューを表示します。タブを使用して、各データの種類を確認します。

- **People** — 世帯ごとに一覧表示されます（写真が含まれている場合は写真も表示されます）。
- **Groups** — キャンパス、礼拝、時間帯、カテゴリごとに整理されています。
- **Attendance** — セッションの日付、グループ、来場回数。
- **Donations** — バッチ、ファンド、寄付者、金額。
- **Forms** — フォーム名とコンテンツの種類。

次に進む前に、内容をよく確認してください。問題がある場合は、**Start Over** をクリックして、元のファイルを修正してください。

---

## ステップ 3 - 送信先を選択

データの送信先を選択します。

- **B1 Database** — 教会の B1 データベースに直接インポートします。このオプションを選択すると、ツールは追加されるレコードの最終件数を表示します。**Start Transfer** をクリックして確定します。
- **B1 Export Zip** — データを B1 形式の zip ファイルとしてダウンロードします。このファイルは、後で **B1 Import Zip** を使って復元できます。バックアップに便利です。
- **Breeze Export Zip** — データを Breeze 形式に変換します。
- **Planning Center Zip** — データを Planning Center 形式に変換します。

:::warning
ソースと送信先に同じ形式は選択できません。同じ形式を選択すると、誤って重複が作成されないようにツールが警告を表示します。
:::

---

## ステップ 4 - 実行

ツールはデータの移行処理を行い、各ステップの進行状況を表示します。

- キャンパス、礼拝、時間帯
- 人物
- 写真
- グループとグループメンバー
- 献金
- 出席
- フォーム、質問、回答、フォームの回答
- カスタムフィールド（カスタムフィールドの列を割り当てた場合）
- 圧縮中（zip ファイルの送信先の場合のみ）

送信先が **B1 Database** の場合、進行状況カードのタイトルは **Import Progress** で、完了時に **Import Complete!**（またはエラーがあった場合は **Import Completed with Errors**）と表示されます。zip ファイルの送信先の場合は、同じメッセージの「Import」が「Export」に置き換わります。

:::info
**B1 Import Zip** を復元する場合、ファイル内に存在しない項目を参照しているレコードは、インポートを停止せずにスキップされます。対象は、ZIP に含まれていない人物またはグループのグループメンバーシップ、削除されたグループまたは人物の出席記録、削除された礼拝時間とグループの間のリンクです。礼拝時間に一度も紐づけられていなかった出席セッションは、引き続き復元されます。同様に、エクスポート時にダウンロードまたは読み取りができない写真は除外され、**Photos** ステップは処理を続けます。
:::

:::warning
移行の実行中は、ブラウザを閉じないでください。すべてのステップが完了と表示されるまで待ってください。
:::

---

## Breeze Import Zip の準備

1. Breeze で **設定** に移動し、左側のサイドバーにある **Export** をクリックします。
2. **People**、**Tags**、**Contributions** の3つのファイルを、それぞれ個別にエクスポートします。
3. 3つのファイルをすべて選択し、右クリックして、1つの zip ファイルに圧縮します。
   - Mac の場合：ファイルを選択し、右クリックして **圧縮** を選択します。
   - PC の場合：ファイルを選択し、右クリックして **送る** を選択してから、**圧縮 (zip 形式) フォルダー** を選択します。
4. ステップ 1 で **Breeze Import Zip** オプションを使って、zip ファイルをアップロードします。

Breeze からのインポートでは、人物、グループ（タグ）、献金記録が自動的に移行されます。

---

## Planning Center エクスポートの準備

1. Planning Center にログインし、**People** プロダクトを開きます。
2. 左側のサイドバーで **Lists** をクリックし、移行したい全員を含むリストを作成します。（教会の全会衆のリストがすでにある場合は、そのリストを使用してください。）
3. リストを開き、**export** オプションを使って、人物データを **CSV** ファイルとしてダウンロードします。残したいフィールドを含めてください。名前、メールアドレス、電話番号、住所、生年月日、性別、会員ステータスはすべて B1 に引き継がれます。
4. Planning Center から複数のファイルが提供された場合は、すべて選択し、右クリックして1つの zip ファイルに圧縮します。
   - Mac の場合：ファイルを選択し、右クリックして **圧縮** を選択します。
   - PC の場合：ファイルを選択し、右クリックして **送る** を選択してから、**圧縮 (zip 形式) フォルダー** を選択します。
5. ステップ 1 で **Planning Center Zip** オプションを使って、CSV または zip ファイルをアップロードします。

アップロード後、プレビューに進み、インポートを実行する前に、人物と世帯が正しく表示されているかを確認してください。

---

## Tithe.ly エクスポートの準備

1. Tithe.ly で、**People** のデータを CSV または Excel ファイルとしてエクスポートします。献金記録を取り込みたい場合は、別途 **Giving** ファイルもエクスポートできます。
2. ツールは列名に基づいて、ファイルに人物データと献金データのどちらが含まれているかを自動的に判別します。
3. ステップ 1 で **Tithe.ly CSV** オプションを使って、ファイルをアップロードします。

:::info
Tithe.ly のエクスポートは、一度に1つのファイルずつインポートできます。人物データと献金データを別々にインポートする必要がある場合は、処理を2回実行してください。
:::

---

## CCB または Pushpay エクスポートの準備

1. Church Community Builder または Pushpay で、**People** のデータを CSV ファイルとしてエクスポートします。別途、献金／寄付のファイルをエクスポートすることもできます。
2. ツールは列名に基づいて、ファイルに人物データと献金データのどちらが含まれているかを自動的に判別します。
3. ステップ 1 で **CCB / Pushpay CSV** オプションを使って、ファイルをアップロードします。

---

## インポート後の確認

移行が完了したら、数分かけてデータを確認してください。

1. [人物](../people/adding-people.md)ページを開き、いくつかのプロフィールを抜き取りで確認します。
2. 名前、メールアドレス、電話番号、住所が正しく取り込まれているかを確認します。
3. 世帯のつながりが維持されているかを確認します。移行元のデータに世帯内の役割（Head、Spouse、Child、Other）がある場合、それは引き継がれます。B1 Import Zip の場合は **householdRole** 列、Breeze または Tithe.ly の場合は **Family Role**、CCB / Pushpay の場合は **Family Position** が対象です。「Head of Household」「Primary」「Wife」「Son」などの役割は、対応する B1 の役割に変換されます。Planning Center と Custom CSV / Excel のインポートには役割の列がないため、これらの人物には **Other** が設定されます。役割は、[人物](../people/adding-people.md#managing-households)ページで、その人物の世帯から変更できます。
4. インポートしたグループと献金記録を確認します。

問題に気づいた場合は、人物ページから個別のプロフィールを編集できます。また、移行ツールを再度実行して、[データをエクスポート](exporting-data.md)してバックアップを取ることもできます。
