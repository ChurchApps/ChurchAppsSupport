# 人物

<div class="article-intro">

**人物**セクションは、B1 Admin における教会管理の中核です。ここでは教会の名簿を管理できます。メンバーの検索、新しい人の追加、プロフィールの表示と編集、世帯の管理などを行います。小規模な会衆でも大規模な会衆でも、人物の記録を整理しておくことは、B1 の他のすべての機能を支える基盤になります。

</div>

## できること

人物セクションで利用できる主な機能は次のとおりです。

1. **名簿を検索する** — クイック検索バーを使って名前で人を探せます。また、詳細フィルターや AI による自然言語検索を使えば、探している人を正確に見つけられます。詳しくは [人物の検索](./searching-people.md) と [AI 検索](./ai-search.md) を参照してください。

2. **検索条件をリストとして保存する** — 任意の検索やフィルターに名前を付けてリストとして保存すると、ワンクリックで再度読み込めます。詳しくは [保存したリスト](./lists.md) を参照してください。

3. **属性の内訳を確認する** — 年齢、性別、婚姻状況、メンバーシップの状態、キャンパスごとに、会衆の内訳をグラフで確認できます。グラフの任意の区画をクリックすると、その区画に含まれる人を詳しく見られます。詳しくは [人口統計](./demographics.md) を参照してください。

4. **新しい人を追加する** — 名簿に個人をすばやく追加し、プロフィールの詳細、連絡先情報、世帯のつながりを入力できます。手順について詳しくは [人物の追加](./adding-people.md) を参照してください。

5. **人物をまとめて編集する** — メンバーシップの状態、婚姻状況、性別、オプトアウト設定、グループへの所属を変更して、複数の人を一度に更新できます。同じ変更を多くの人に行う場合に便利です。詳しくは [一括編集](./bulk-editing.md) を参照してください。

6. **名簿を印刷する** — 世帯ごとにまとめられ、写真と連絡先情報を含んだ、整形済みの印刷可能なメンバー名簿を作成できます。詳しくは [名簿の印刷](./print-directory.md) を参照してください。

7. **データのインポートとエクスポート** — CSV ファイルからメンバーデータを取り込んだり、Breeze など他の教会管理システムから移行したりできます。また、名簿はいつでも CSV にエクスポートできます。詳しくは [データのインポート](./importing-data.md) と [データのエクスポート](./exporting-data.md) を参照してください。

8. **プロフィールを管理する** — 各人の詳細なプロフィールを表示・編集できます。連絡先情報、世帯のメンバー、[グループへの所属](../groups/group-members.md)、[出席履歴](../attendance/tracking-attendance.md)、[寄付](../donations/recording-donations.md)、[カスタムフォーム](../forms/creating-forms.md) などが含まれます。プロフィールの左側には、その人の氏名、連絡先の詳細、世帯が表示され、その隣に出席、献金、グループ、メモ、フォームの概要が並びます。住所や自宅・勤務先の電話番号にカーソルを合わせると、ワンクリックでコピーできます。

9. **役割と権限を割り当てる** — 役割を割り当てることで、チームのどのメンバーが B1 Admin のどの部分にアクセスできるかを管理できます。詳しくは [役割の割り当て](./roles-permissions.md) を参照してください。

## はじめに

人物セクションを開くには、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（B1 Admin の左上にある検索バー）を開き、**人物**を展開して、**人物**をクリックします。世帯ごとに並んだ教会の名簿が表示され、上部に検索バーがあります。**表示形式**の切り替えを使うと、**世帯**の一覧と個人の**表**を切り替えられます。

:::tip
B1 を初めて設定する場合は、まず[既存のメンバーデータをインポート](./importing-data.md)してください。その後、必要に応じてプロフィールを確認し、整理してください。
:::
