# AI検索

<div class="article-intro">

**AI検索**機能を使うと、従来の検索欄やフィルターを使わずに、普段の言葉で書いた質問から教会の名簿を検索できます。特定のフィルター条件を組み立てる代わりに、探したい内容を日常的な言葉で説明するだけで済みます。複雑な質問にも素早く答えられ、教会員について知りたいことを簡単に調べられます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 人を閲覧する権限を持つ、有効なB1 Adminアカウントが必要です。アクセス権限が分からない場合は、[ロールと権限](roles-permissions.md)を参照してください。
- 標準の[人の検索](searching-people.md)ツールに慣れていると役立ちますが、必須ではありません。

</div>

## 仕組み

AI検索は人工知能を使ってご質問の内容を解釈し、人物データベースから一致する結果を返します。同僚に質問するような感覚で尋ねることができます。

1. B1 Adminの**人物**ページに移動します。
2. 検索ボックスの下にある**質問**をクリックして、**AI検索**ボックスを開きます。
3. 普段の言葉で質問を入力します。
4. **検索**をクリックして質問を実行します。
5. 一致する人物を表示するように結果リストが更新されます。

**検索をクリア**をクリックすると、質問が消去され、すべての名簿に戻ります。

:::info
AI検索に接続できない場合は、*「AI検索は一時的に利用できません。しばらくしてから再度お試しいただくか、上の検索をご利用ください。」*と表示されます。入力した質問は保持されるため、少し時間をおいて再度お試しいただけます。その間は、クイック検索または**詳細**検索をご利用ください。
:::

## 質問の例

次のような質問ができます。

- 「過去3か月間に出席していない人は誰ですか?」
- 「30歳未満のメンバーをすべて表示してください」
- 「青年グループに子どもがいる家族を一覧にしてください」
- 「今年教会に加わった人は誰ですか?」
- 「メールアドレスが登録されていない人をすべて表示してください」
- 「75001の郵便番号に住んでいるメンバーはどなたですか?」

:::tip
質問はできるだけ具体的に書いてください。詳しく伝えるほど、結果はより正確になります。
:::

## AI検索を使うとき

AI検索は、次のような場合に特に役立ちます。

- 従来のフィルターでは設定しにくい、複数の条件を組み合わせて検索したいとき。
- どの項目で検索すればよいか正確に分からないとき。
- レポートを作成せずに、教会について素早く答えを知りたいとき。

:::info
AI検索は、標準のクイック検索や**詳細**フィルターと併用できます。ご都合に合う方法をお選びください。単純な名前の検索には[クイック検索](searching-people.md)が最も速い方法です。より複雑な質問には、AI検索が力を発揮します。
:::

その他の検索オプションについては、[人の検索](./searching-people.md)を参照してください。
