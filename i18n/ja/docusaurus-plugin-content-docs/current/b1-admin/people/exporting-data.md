# データのエクスポート

<div class="article-intro">

B1 Admin では、教会のデータをエクスポートして、スプレッドシートで利用したり、チームと共有したり、バックアップとして保存したりできます。名前とメールアドレスの簡単なリストが必要な場合でも、データベース全体のエクスポートが必要な場合でも、ニーズに合わせた方法があります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- エクスポートしたいデータを閲覧する権限を持つ、有効な B1 Admin アカウントが必要です。アクセスレベルがわからない場合は、[役割と権限](roles-permissions.md)をご覧ください。
- データベース全体をエクスポートするには、**設定**エリアへのアクセスが必要です。

</div>

## 人物ページからのエクスポート

ディレクトリを最も速くエクスポートする方法は、**人物**ページから直接行うことです:

1. [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)(B1 Admin の左上にある検索バー)を開き、**人物**を展開して、**人物**をクリックします。
2. 検索バーやフィルターを使って、エクスポートしたい結果を絞り込みます(または、フィルターをかけずにすべての人をエクスポートすることもできます)。フィルタリングのヒントについては、[人物の検索](searching-people.md)をご覧ください。
3. 人物ページのヘッダーにある**エクスポート**ボタンをクリックします。
4. 現在の結果に含まれる人物の名前、連絡先情報、住所、その他の標準フィールドを含む CSV ファイルが、お使いのコンピューターにダウンロードされます。

:::tip
エクスポートには、現在の結果に含まれるすべての人が含まれます。必要な人だけをエクスポートするには、先に検索を実行するか、[保存済みリスト](./lists.md)を読み込むか、**詳細**検索を使用してください。
:::

## 設定からの全データエクスポート

B1 のすべてのデータ(人物だけでなく)を完全にエクスポートするには、設定のエクスポートツールを使用します:

1. ジャンプメニューで、**設定 > 設定**を選択します。
2. 左側の設定メニューの上部にある教会名の下の**インポート/エクスポート**リンクをクリックします。
3. **データソース**のドロップダウンから **B1 データベース**を選択します。
4. データのプレビューを確認し、**保存先に進む**をクリックします。
5. エクスポート先として **B1 エクスポート Zip** を選択します。
6. すべての項目に緑色のチェックマークが表示されるまで、エクスポートの進行状況を監視します。
7. エクスポートファイルが自動的にダウンロードされます。ダウンロードフォルダーで `B1Export` ファイルを探してください。
8. ファイルを解凍すると、Excel、Google スプレッドシート、または Numbers で開ける個別の CSV ファイル(`people.csv` など)にアクセスできます。

:::info
B1 エクスポート Zip は、教会データの完全なバックアップです。以下が含まれます:

- 写真付きの人物と世帯(世帯の引き取り連絡先を含む)
- キャンパス、礼拝、礼拝時間
- グループとグループメンバー
- 資金と寄付(複数の資金に分割された寄付を含む)
- 出席
- フォーム、質問、回答、および回答内容
- カスタムフィールドとその値
- 保存済みの人物リスト

エクスポート中に人物の写真をダウンロードまたは読み取れない場合、その写真はスキップされ、写真なしでエクスポートが続行されます。

復元するには、ソースとして **B1 インポート Zip**、保存先として **B1 データベース**を選択します([データのインポート](./importing-data.md)を参照)。世帯、引き取り連絡先、保存済みリストは、人物と一緒に再構築されます。保存済みリストのフィルターは、復元されたグループ、資金、キャンパス、カスタムフィールドを参照するように設定されます。
:::

## グループデータのエクスポート

個々のグループのメンバーリストもエクスポートできます。**グループ**ページで、グループを開き、**ダウンロードアイコン**をクリックすると、そのグループのメンバーリストをエクスポートできます。詳細は[グループメンバー](../groups/group-members.md)をご覧ください。

:::info
エクスポートされた CSV ファイルは、Microsoft Excel、Google スプレッドシート、Apple Numbers など、主要なすべての表計算アプリケーションで利用できます。
:::
