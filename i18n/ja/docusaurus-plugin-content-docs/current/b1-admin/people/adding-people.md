# 人の追加

<div class="article-intro">

人員セクションは B1 Admin の基盤であり、教会のメンバーデータベースです。その他のすべての機能（グループ、出席、献金、フォーム）は人のレコードに紐づいています。このガイドでは、データベースへの人の追加、詳細の編集、家族メンバーの世帯への紐づけについて説明します。

</div>

<h4>始める前に</h4>

- 人を管理する権限を持つ有効な B1 Admin アカウントが必要です。アクセスレベルがわからない場合は、[ロールと権限](roles-permissions.md)を参照してください。
- 数人以上を追加する場合は、代わりに [CSV インポート](importing-data.md)ツールの利用をご検討ください。

## 人の追加

1. B1.church の管理ダッシュボードに移動します。
2. [Jump メニュー](../introduction.md#getting-around-with-the-jump-menu)（左上の検索バー）を開き、**People** を展開して、**People** をクリックします。
3. ページヘッダーの **Add Person** ボタンをクリックします。ページが下にスクロールし、ディレクトリの下にある **Add New Person** フォームが表示されます。
4. 人の **First Name**（名）、**Last Name**（姓）、**Email**（メールアドレス）を入力し、**Add** をクリックします。

その人のプロフィールページが開き、詳細をさらに追加できる状態になります。

:::tip
他の教会管理システムから移行する場合は、[データのインポート](importing-data.md)機能を使うと、CSV ファイルからディレクトリ全体を取り込めます。一人ずつ追加するより大幅に速く済みます。
:::

### 重複の警告

入力したメールアドレス（または、詳細編集フォームから人を作成する場合は、電話番号、あるいは名・姓・生年月日が一致する人）が、すでにデータベースにある人と一致すると、新しいレコードを保存する前に **Possible Duplicate** ダイアログが表示されます。一致した各人のメールアドレス、電話番号、生年月日が一覧表示されるので、比較できます。

- 一致する人の横にある **Use Existing** をクリックすると、新規作成せず、その人のレコードを使用します。
- 一致する候補が見つかっても新しい人を追加したい場合は、**Create Anyway** をクリックします。

この確認は、新しい人を作成する場合にのみ行われます。既存のレコードを編集しても表示されることはありません。これは新たな重複を防ぐためのもので、すでに存在する 2 つのレコードを統合するものではありません。

## 詳細の編集

1. 人のプロフィールページで、左側の連絡先情報の下にある **Edit** ボタンをクリックします。
2. **Personal Details** フォームで、追加情報を入力します。たとえば、**Title**（一覧から Mr、Mrs、Miss、Ms、Dr、Prof、Rev、Pastor を選ぶか、10 文字以内で独自に入力）、ミドルネーム、会員ステータス（**Visitor**、**Guest**、**Regular Attendee**、**Member**、**Staff**、**Inactive**、**Deceased**）、日付、住所、電話番号、そして（子どもや学生の場合は）学年と学校などです。
3. **Save** をクリックして個人情報を保存します。

プロフィールの左側には、人の写真、名前、会員ステータス、連絡先、[カスタムフィールド](../settings/custom-fields.md)の値、所属する世帯が表示されます。世帯の下にある **Added** には、レコードが作成された日付が表示されます（2026 年 10 月下旬以降に追加された人のみ）。写真をクリックすると変更できます。**Edit** ボタンの下には、さらにいくつかの操作があります。**Workflow**（人を[ワークフロー](../serving/workflows.md)に追加）、**Merge**（統合）、**Export**、**Export Data** です。

プロフィールの残りの部分には、関連情報の種類ごとに概要が表示されます。

- **Attendance**（出席）: 直近数週間のうち、その人が出席した週と、直近の来場記録が表示されます。**All years** をクリックすると、キャンパス、礼拝、礼拝時間、グループ、キオスクでのチェックイン時刻を含む **Checked In** 列などを含む、全期間の来場履歴が表示されます。キオスクでのチェックインがない記録にはダッシュ（-）が表示されます。**Print** をクリックすると印刷できます（印刷物には、上部中央に教会のロゴと名前、その下に人の名前が表示されます）。個人ではなく教会全体の傾向を見たい場合は、[出席の追跡](../attendance/tracking-attendance.md)を参照してください。
- **Donations**（献金）: 今年の献金を表示します。控除対象外の基金への献金も含まれます。**All years** をクリックすると、全期間の[献金履歴](../donations/recording-donations.md)が表示されます。**Log a gift** をクリックすると、新しい献金を記録できます。教会で[献金のプライバシー設定](../settings/church-settings.md#giving-privacy)を有効にしている場合、**Show giving** をクリックするまで金額は非表示のままです。
- **Groups**（グループ）: その人の[グループへの所属](../groups/group-members.md)を一覧表示します。記録がある場合は、各グループへの **Joined**（参加日）も表示されます。
- **Notes**（メモ）: その人に関する最近のメモ（牧会的ケア、フォローアップなど）を表示します。**All notes** をクリックすると、メモの閲覧や追加ができます。各メモには、書いた人と投稿された日時が表示されます。すべての人の最近のメモをまとめて確認するには、[メモ](./notes.md)ページを使用してください。
- **Forms**（フォーム）: その人のフォームの一覧と、各フォームが提出済みかどうかを表示します（下の[フォームの操作](#working-with-forms)を参照）。

これらの詳細画面を開いたら、上部にあるその人の名前の **Back to** リンクをクリックすると、プロフィールに戻れます。

## 人へのメール送信

人のメールアドレスが登録されている場合、プロフィールの左側にある連絡先情報の下に **Email** ボタンが表示されます。

1. その人のプロフィールで **Email** をクリックします。
2. その人の名前がタイトルになった **Email** ダイアログが開き、**Sending to** に相手のアドレスが表示されます。
3. 必要に応じて **Load Template (optional)** から保存済みのテンプレートを選択します。
4. **Subject**（件名）を入力し、メッセージを作成します。
5. **Send Email** をクリックします。

代わりに、お使いのメールソフトでメッセージを作成したい場合は、**Open in my email app** をクリックします。

:::info
B1 からの送信には、グループメールと同じ承認手続きと 1 日の送信上限が適用されます。教会がまだ承認されていない場合、ダイアログでレビューの申請を求められます。その間も **Open in my email app** をクリックして送信できます。詳しくは、[教会のグループメールを有効にする](../groups/group-members.md#turning-on-group-email-for-your-church)を参照してください。グループメンバーを編集する権限がないユーザーは、**Email** をクリックするとメールアプリが直接開きます。
:::

## フォームの操作

人のプロフィールから、カスタムフォームに直接記入できます。これらは、[フォームの作成](../forms/creating-forms.md)ガイドに従って作成できるユーザー定義のフォームです。

1. その人のプロフィールで **Forms** セクションを探します。各フォームの名前と、**Submitted**（提出済み）または **Not submitted**（未提出）の状態が表示されています。
2. フォームの名前をクリックして開きます（すべてのフォームの一覧を見るには **All forms** をクリックします）。
3. フォームの **編集アイコン**（鉛筆）をクリックし、詳細を入力して **Save** をクリックします。

フォームが提出されたら、その横にある **印刷アイコン** をクリックすると、その人の入力内容を印刷できます。同じフォームの提出が 1 件だけの場合は、回答の上に **Submitted** と提出日が表示されます。

提出が誤った人に紐づいてしまった場合は、その横にある **Change person** アイコン（2 つの矢印）をクリックすると、別の人に移動したり、紐づけを解除したりできます。詳しくは、[提出の対象者の変更](../forms/managing-submissions.md#changing-the-person-on-a-submission)を参照してください。

:::info
人のプロフィールに紐づくフォームは、**People** フォームタイプを使用します。イベント登録のような単独のフォームが必要な場合は、フォームガイドの[単独フォームのオプション](../forms/creating-forms.md)を参照してください。
:::

:::tip
人に関する追加情報を 1、2 項目だけ記録したい場合（日付、数値、はい/いいえの回答など）は、フォームの代わりに [カスタムフィールド](../settings/custom-fields.md)を使用してください。入力がより手早く、高度な検索でも直接検索できます。
:::

## 世帯の管理 {#managing-households}

世帯機能を使うと、家族のメンバーをまとめてリンクできます。これは特に[チェックイン](../attendance/check-in.md)で役立ちます。保護者が子どもたち全員を一度にチェックインさせられるためです。

1. 人のプロフィールで、左側の **Household** 見出しの横にある **Edit** をクリックします。
2. 世帯エディターが開きます。現在の人の **世帯内の役割**（例: Head（世帯主）、Spouse（配偶者）、Child（子ども）、Other（その他））を選択します。
3. **Add** アイコンをクリックして、別の世帯メンバーを追加します。
4. **Add Household Member** の下の検索ボックスに人の名前を入力し、**Enter** キーを押すか、検索アイコンをクリックします。（入力前には、**Recent people**（最近の人）の短い一覧が表示されます。）
5. 検索結果に目的の人が表示されたら、名前またはその横の追加アイコンをクリックします。
6. その人の世帯内の役割を選択し、**Save** をクリックして世帯の設定を完了します。
