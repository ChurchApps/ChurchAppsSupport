# ノート

<div class="article-intro">

**ノート**ページには、B1 Adminの各所に書かれた最近のノートが一か所にまとめられます。各記録を開かなくても、牧会的なケア、フォローアップ、計画の進捗を確認できます。人物、リーダーを務めるグループ、カレンダーのイベント、ワークフローカードに書かれたノートが新しいものから順に表示され、それぞれ書かれた場所へのリンクがあります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- **ノート**ページは、**人物の編集**権限を持っているか、少なくとも1つのグループのリーダーである場合にメニューに表示されます。詳しくは[役割の割り当て](./roles-permissions.md)を参照してください。
- このページには、あなたが既に閲覧できるノートだけが表示されます。各タブは、ノートが属する記録と同じルールに従います([各タブの表示内容](#what-each-tab-shows)を参照)。

</div>

## ノートページを開く

1. [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)(B1 Adminの左上にある検索バー)を開き、**人物**を展開します。
2. **ノート**をクリックします。
3. ページは**人物**タブで開きます。ページ上部のタブを使って、**人物**、**グループ**、**イベント**、**ワークフロー**を切り替えます。

## 一覧の見方

一覧の各ノートには、次の情報が表示されます。

- **書かれた場所** -- 人物の名前、グループ名、イベントのタイトル、またはワークフローカードのタイトルです。名前をクリックすると、その記録を開き、スレッド全体を読んだり、ノートを追加したりできます。
- **機密** -- 人物のノートに付くバッジで、人物の「機密ノート」セクションから作成されたことを示します。
- **書いた人と日時** -- 「By」の後に作成者の名前、続けて投稿された日付と時刻が表示されます。
- **ノートの本文** -- 長いノートは一覧では短縮されます。全文を読むには記録を開いてください。

一覧では、最新のノートが先頭に表示されます。下部の**さらに読み込む**をクリックすると、古いノートが表示されます。

削除された人物や、別の記録に統合された人物に書かれたノートは、**人物**タブに表示されません。

ノートページは読み取り専用です。ノートを追加、編集、または返信するには、記録の名前をクリックして開いてください。

## 各タブの表示内容 {#what-each-tab-shows}

| タブ | 表示されるノート | 閲覧できるユーザー | 名前をクリックして開く先 |
|-----|-------------|------------------|-------------------------|
| **人物** | 人物の記録に書かれたノート | **人物の編集**権限を持つユーザー。機密ノートには**機密ノートの閲覧**権限も必要 | 人物のノート |
| **グループ** | グループに対する[リーダーノート](../groups/group-members.md#leader-notes) | 管理者であっても、各グループのリーダーのみ | グループのノート |
| **イベント** | [イベントノート](../calendars/creating-calendars.md#event-notes) | コンテンツの編集権限またはカレンダーの管理権限を持つスタッフ、およびイベントの**ノートを閲覧できる人**の設定で許可されたユーザー | イベントのグループのカレンダー |
| **ワークフロー** | [ワークフローカード](../serving/workflows.md#working-the-board)に書かれたノート | カードを開けるすべてのユーザー(カードの担当者となっている人物またはグループを含む) | カードのワークフローボード |

タブに表示できるノートがまだない場合は、その旨が表示されます。たとえば「あなたがリーダーを務めるグループのノートはまだありません」と表示されます。

:::tip
ノートのスレッドには、通知用のベルアイコンがあります。クリックすると、そのスレッドの新しいノートについて通知を受け取れます(アイコンはすぐに変わります)。もう一度クリックすると通知をオフにできます。これらのオン/オフの設定が、ノートページにノートとして表示されることはありません。
:::
