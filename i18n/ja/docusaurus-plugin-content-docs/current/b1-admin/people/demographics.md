# 人口統計

<div class="article-intro">

**人口統計**ダッシュボードでは、教会の会衆の全体像を視覚的に把握できます。どのような人々が、どれくらいいるのか、そして年齢層、性別、婚姻状況、キャンパスごとにメンバーがどのように分布しているかを確認できます。すべてのグラフはインタラクティブで、任意の区分をクリックすると、その人々だけを表示する絞り込み済みの人物検索にすぐ移動します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 人物がディレクトリに登録されている必要があります。始め方については、[人物の追加](./adding-people.md)または[データのインポート](./importing-data.md)を参照してください。
- キャンパスのグラフを表示するには、先に[設定 → キャンパス](../settings/campuses.md)でキャンパスを設定しておく必要があります。

</div>

## 人口統計を開く

**人物**ページのページヘッダーにある**人口統計**をクリックします。ページの上部にはメンバー総数が表示され、その下に後述のグラフが並びます。

## グラフ

### 年齢分布

各年齢層（例：0～9歳、10～17歳、18～24歳、以降65歳以上まで）に該当する人数を示すグループ化された棒グラフです。各棒は**女性**、**男性**、**未設定**の3つの系列に分かれているため、各年齢層内の性別内訳をひと目で確認できます。

### メンバーシップ状況

メンバーシップ状況（例：メンバー、定期出席者、訪問者など）ごとに会衆の内訳を示すドーナツグラフです。

### 性別

ディレクトリ内の女性、男性、未設定の記録の割合を示すドーナツグラフです。

### 婚姻状況

婚姻状況の値（例：既婚、独身、死別など）ごとの内訳を示すドーナツグラフです。

### キャンパス

教会のキャンパス間で人々がどのように分布しているかを示すドーナツグラフです。このグラフは、キャンパスが設定されており、かつ少なくとも1人がキャンパスに割り当てられている場合にのみ表示されます。キャンパスが割り当てられていない人は**未設定**として表示されます。

## データの絞り込み

ドーナツグラフの任意の区分、または年齢グラフの任意の棒の区分をクリックすると、その人々だけを表示するように事前に絞り込まれた**人物**ページに移動します。絞り込みはページの読み込み完了後も維持され、リストの上に表示される件数には、一致した世帯数と人数が示されます。これを使って連絡先リストを素早く作成したり、一括操作を実行したり、区分をエクスポートしたりできます。たとえば、メンバーシップ状況の**訪問者**の区分をクリックすると、すべての訪問者を確認でき、その後ワークフローに送信できます。

:::tip
絞り込まれた結果を表示したら、人物検索の**リストとして保存**を使うと、その絞り込み条件を今後も利用できるように保存できます。詳しくは[保存済みリスト](./lists.md)を参照してください。
:::
