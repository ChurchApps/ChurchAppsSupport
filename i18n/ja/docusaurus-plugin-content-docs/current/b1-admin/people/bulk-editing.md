# 人物の一括編集

<div class="article-intro">
一括編集を使うと、複数の人物をまとめて更新できます。同じ変更を多くの人に行う場合に時間を節約できます。メンバーシップステータス、婚姻状況、性別、ディレクトリ掲載拒否の設定、グループ所属を、1回の操作でまとめて変更できます。
</div>

<div class="prereqs">
<h4>始める前に</h4>

- 人物データを管理する権限が必要です。詳しくは[ロールと権限](./roles-permissions.md)を参照してください。
- 編集したい人物は、すでに追加またはインポートしておく必要があります。必要に応じて[人物の追加](./adding-people.md)を参照してください。
</div>

## 一括編集する人物の選択

1. B1 Admin で**人物**に移動します
2. 検索またはフィルターを使って、更新したい人物を探します
3. チェックボックスをオンにして人物を選択します
   - **世帯**表示では、世帯をチェックすると、その世帯のすべての人が選択されます
   - **テーブル**表示（**表示形式**の切り替えで選択）では、人物を個別に選択できます
   - または、リストの上にあるチェックボックスを使って、表示されているすべての人物を選択できます
4. 1人以上を選択すると、リストの上のバーに選択数が表示され、**選択解除**ボタンと**アクション**ボタンが表示されます

:::tip
特定の条件に合う多数の人物を更新する場合は、[AI検索](./ai-search.md)機能やフィルターを使って対象者を絞り込んでから、該当するすべての人物を選択してください。
:::

## 利用できる一括操作

**アクション**メニューには、次のオプションがあります。

### メンバーシップステータスの更新

選択したすべての人物のメンバーシップステータスを更新します。

1. **アクション** → **メンバーシップステータスを設定**をクリックします
2. 新しいステータスを選びます
   - **訪問者** -- 初めて来た人、または時々来る人
   - **ゲスト** -- チェックイン端末で登録された家族などのゲスト
   - **常連参加者** -- 頻繁に参加しているが、メンバーではない人
   - **メンバー** -- 正式な教会メンバー
   - **スタッフ** -- 教会のスタッフ
   - **非アクティブ** -- もう参加していない人
   - **死去** -- すでに亡くなった人
3. 更新モードを選びます
   - **すべて上書き** -- 選択したすべての人物の現在のステータスを置き換えます
   - **空欄のみ更新** -- ステータスが未設定の人物だけに設定します
4. **更新**をクリックします

### 婚姻状況の更新

婚姻状況をまとめて更新します。

1. **アクション** → **婚姻状況を設定**をクリックします
2. 新しい状況を選びます
   - **不明**
   - **未婚**
   - **既婚**
   - **離婚**
   - **死別**
3. 既存の値を上書きするか、空欄の項目のみ更新するかを選びます
4. **更新**をクリックします

### 性別の更新

複数の人物の性別情報を更新します。

1. **アクション** → **性別を設定**をクリックします
2. 値を選びます
   - **未指定**
   - **男性**
   - **女性**
3. 更新モード（すべて上書きまたは空欄のみ）を選びます
4. **更新**をクリックします

### ディレクトリ掲載拒否の更新

人物がコミュニケーションを拒否しているかどうかを設定します。

1. **アクション** → **ディレクトリ掲載拒否を設定**をクリックします
2. 次のいずれかを選びます
   - **いいえ** -- コミュニケーションを許可します（拒否設定を解除）
   - **はい** -- コミュニケーションを拒否します（拒否設定を有効化）
3. 更新モードを選びます
4. **更新**をクリックします

:::warning
掲載拒否の設定を変更する際は注意してください。明示的に拒否している人物には、新たな同意を得ない限り、連絡を送らないようにしてください。
:::

### カスタムフィールドの設定

選択したすべての人物に対して、はい/いいえの[カスタムフィールド](../settings/custom-fields.md)の値をまとめて設定します。

1. **アクション** → **カスタムフィールドを設定**をクリックします。
2. 設定したいはい/いいえのカスタムフィールドを選びます。
3. 適用する値（**はい**または**いいえ**）を選びます。
4. **更新**をクリックします。

:::info
この一括操作で使用できるのは、はい/いいえのカスタムフィールドだけです。それ以外の種類のフィールドを設定するには、人物ごとに個別に編集してください。
:::

### グループへの追加

選択したすべての人物を1つ以上のグループに追加します。

1. **アクション** → **グループに追加**をクリックします
2. 人物を追加したいグループを検索して選択します
3. 複数のグループを選択して、すべてのグループに人物を追加できます
4. **グループに追加**をクリックします

追加された各人物は、選択したグループの一般メンバーとして登録されます。後からリーダーに昇格させる必要がある場合は、[グループメンバー](../groups/group-members.md)ページから行えます。

### グループからの削除

選択したすべての人物を1つ以上のグループから削除します。

1. **アクション** → **グループから削除**をクリックします
2. 人物を削除したいグループを検索して選択します
3. 複数のグループを選択できます
4. **グループから削除**をクリックします

:::info
この操作は、指定したグループから人物を外すだけです。人物の記録自体は削除されません。
:::

### 人物の削除

選択した人物を教会のデータベースから完全に削除します。

1. **アクション** → **削除**をクリックします
2. **選択した人物の削除**ダイアログで、削除される人数の確認が表示されます
3. **削除**をクリックします

:::danger
人物の削除は完全な操作であり、元に戻すことはできません。次のような、その人物のすべてのデータが削除されます。
- 個人情報
- グループ所属
- 出欠記録
- 寄付履歴
- フォームの送信内容

本当にシステムから削除してよい場合にのみ、この操作を使用してください。
:::

## 一括編集の結果

一括操作が完了すると、次の内容を含む概要が表示されます。

- **選択合計** -- 操作の対象になった人数
- **更新成功** -- 変更されたレコードの数
- **失敗** -- 更新できなかったレコード（該当する場合）
- **変更なし** -- 変更が不要だったレコード（例：「空欄のみ更新」モードを使用した場合）

更新に失敗したものがあれば、その理由を示すエラーの詳細が表示されます。

## ベストプラクティス

- **少しずつ始める** -- 正しい変更になるかを確かめるため、まずは数件で一括操作を試してください
- **フィルターを使う** -- 正しい人物だけを更新するため、人物を選択する前にフィルターやAI検索でリストを絞り込んでください
- **選択内容を二重に確認する** -- 一括変更を適用する前に、選択した人物を確認してください
- **「空欄のみ更新」モードを使う** -- 既存の情報を上書きせず、不足しているデータだけを補いたいときに使ってください
- **大きな変更は記録する** -- 後で参照できるように、一括更新の内容をメモしておいてください
- **チームと連携する** -- 大規模な一括変更を行う際は、他の管理者にも知らせてください

## よくある利用例

### 新しいメンバーの更新

メンバーシップクラスの後で、参加者全員をメンバーステータスに更新します。

1. クラスに参加した人物を検索します
2. 全員を選択します
3. **アクション** → **メンバーシップステータスを設定** → **メンバー**を使います

### 小グループの編成

複数の人物を新しい小グループに追加します。

1. グループに入れたい人物を検索します
2. 人物を選択します
3. **アクション** → **グループに追加**を使い、その小グループを選択します

### データの整理

既婚のカップルの婚姻状況の空欄を埋めます。

1. （世帯情報を使って）既婚の人物をフィルターで絞り込みます
2. 婚姻状況が空欄の人物を選択します
3. **アクション** → **婚姻状況を設定** → **既婚** → **空欄のみ更新**を使います
