# ディレクトリの印刷

<div class="article-intro">

ディレクトリの印刷機能は、教会のメンバー向けに整形された印刷用のディレクトリを作成します。メンバーを世帯ごとに整理し、連絡先や写真を含め、標準的なレターサイズの用紙に印刷したときにプロフェッショナルに見えるように設計されています。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 人物を閲覧する権限を持つ、有効な B1 Admin アカウントが必要です。
- 最良の結果を得るために、ディレクトリに登録される人物には写真と連絡先情報を入力しておいてください。

</div>

## ディレクトリの印刷を開く

1. B1 Admin で **People** に移動します。
2. People ページのヘッダーにある **Print Directory** をクリックします。
3. Print Directory が新しいブラウザタブで開き、ディレクトリのデータの読み込みを開始します。
4. 約 1.5 秒後に、ブラウザの印刷ダイアログが自動的に表示されます。

:::tip
ディレクトリは別のタブで開かれるため、People ページを離れることなく印刷できます。印刷ダイアログが表示されると、そのタブは自動的に元のページへ戻ります。
:::

## 印刷される内容

印刷ディレクトリには、教会のすべての**有効なメンバー**が含まれます。具体的には次のとおりです。

- **Inactive**、**Visitor**、**Deceased** のメンバーシップステータスの人物は、自動的に除外されます。
- ディレクトリへの掲載を**辞退**している人物は除外されます。
- それ以外の人物は、**世帯**ごとにグループ化されます。

### 検索結果のみを印刷する

People ページで検索を実行すると（クイック検索、[詳細検索](./searching-people.md#advanced-search)、[保存済みリスト](./lists.md)、または [AI 検索](./ai-search.md)）、**Print Directory** ボタンが **Print Results** に変わります。これをクリックすると、教会全体ではなく、検索結果に含まれる人物だけのディレクトリが同じレイアウトで印刷されます。

検索結果を印刷する場合、上記のメンバーシップステータスによるフィルターは適用されません。検索した人物は、Visitor や Inactive であってもすべて含まれます。ただし、ディレクトリへの掲載を辞退している人物は引き続き除外されます。全体のディレクトリを印刷する状態に戻すには、先に検索をクリアしてください。

## ディレクトリのレイアウト

印刷されるディレクトリは、次の 2 つの部分で構成されます。

### 表紙

最初のページには次の内容が含まれます。

- 教会の名称
- 「Member Directory」というタイトル
- 現在の年
- 教会の所在地
- 含まれる世帯の合計数

### メンバーの一覧

残りのページでは、世帯が姓のアルファベット順に並べられます。各世帯のカードには次の内容が表示されます。

- **写真** -- 世帯の各メンバーの円形のサムネイルと、その下の名前
- **世帯の表示名** -- たとえば「The Smith Family」、「John & Jane Doe」、または個人の場合はその人の名前のみ
- **住所** -- 番地、市区町村、都道府県、郵便番号
- **電話** -- 自宅または携帯電話の番号
- **メール** -- 主要なメールアドレス
- **誕生日** -- 世帯の各メンバーごとに個別の日付として表示
- **結婚記念日** -- 登録されている場合

世帯は**アルファベット順のセクション**（A、B、C、...）に分けられ、各文字のグループの前には装飾的なセクションヘッダーが付きます。世帯カードは各行に 2 つずつ横に並んで表示されます。

## 印刷設定

ディレクトリは、0.5 インチの余白を持つ**レターサイズの用紙**（8.5" × 11"）向けに整形されています。ブラウザの印刷ダイアログが表示されたら、次の点を確認してください。

- 用紙サイズは **Letter** のままにします。
- セクションヘッダーを色付きのスタイルで印刷したい場合は、ブラウザの印刷設定で **Background graphics**（「背景のグラフィック」や「背景を印刷」と表示される場合もあります）を有効にします。
- 縦向き（ポートレート）を推奨します。

:::info
ディレクトリはページの区切りを考慮します。世帯カードとセクションヘッダーがページをまたいで分割されることはありません。
:::
