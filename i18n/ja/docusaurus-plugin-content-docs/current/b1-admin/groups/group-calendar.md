# グループカレンダー

<div class="article-intro">

B1 の各グループには、それぞれ専用のイベントカレンダーを設定できます。グループリーダーは、ミーティング、活動、定期的なイベントの予定を立てるために使います。グループのメンバーは今後のイベントを確認したり、イベントについての会話に参加したりできます。カレンダーがあることで、グループの予定が整理され、全員が今後の予定を把握できるようになります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1 Admin で、メンバーが 1 人以上いるグループを作成しておく必要があります。[グループの作成](creating-groups.md)と[グループメンバー](group-members.md)を参照してください。
- カレンダーのイベントを追加または編集するには、グループリーダーに指定されている必要があります。手順については、[グループリーダーの指定](group-members.md)を参照してください。

</div>

## グループカレンダーへのアクセス

グループカレンダーは、メンバー向けアプリの B1.church から利用できます。

1. B1 Admin で、画面右上の**ドロップダウンメニュー**をクリックします。
2. **アプリを切り替える**を選択します。
3. **B1.church** を選びます。
4. **グループ**を開きます（スマートフォンでは下部のタブバー、パソコンでは上部のヘッダーにあります）。
5. 一覧からご自分のグループを選択します。
6. **次のイベント**の下にある**すべてのイベント**をクリックして、グループの**イベント**画面を開きます。月表示にする場合は、そこにある**カレンダー**の切り替えを使ってください。

:::info
グループカレンダーは、B1 Admin ではなく B1.church（メンバー向けアプリ）で管理します。グループリーダーは、管理画面のダッシュボードからアプリを切り替えてアクセスします。
:::

## イベントの追加

1. グループカレンダーで、**イベントを追加**をクリックします。
2. イベントの**タイトル**を入力します。
3. イベントの内容を簡単に説明する**説明**を書きます。
4. **開始時刻**と**終了時刻**を設定します。
5. **保存**をクリックして、イベントをカレンダーに追加します。

## 定期イベントの設定

グループが定期的に集まる場合は、イベントを自動的に繰り返すように設定できます。

1. イベントを作成または編集するときに、**繰り返し**のチェックボックスをオンにします。
2. イベントの繰り返し方を選びます。
   - **間隔** -- 繰り返しの間隔を日数で設定します。たとえば「7」と入力すると、7 日ごとにイベントが繰り返されます。
   - **頻度** -- **日**、**週**、**月**のいずれかの単位で繰り返すかを選びます。
3. イベントを保存します。これで、予定されたそれぞれの日程でカレンダーに表示されるようになります。

:::tip
毎週土曜日に集まるグループの場合は、頻度を「週」に設定し、土曜日を選びます。その後のイベントは自動的にカレンダーに表示されます。
:::

## B1 Admin での一括イベント作成

B1 Admin のグループページにも**カレンダー**のセクションがあり、スタッフはここで一季分のミーティングをまとめて予定できます。

1. B1 Admin でグループを開き、**カレンダー**のセクションで**すべてのイベント**をクリックします。
2. **+ イベントを追加**をクリックして、**定期イベントを追加**のダイアログを開きます。
3. スケジュール（毎週、2 週間ごと、毎月、または 1 回のみ）、**最初のミーティング**と**最後のミーティング**の日付を選び、必要に応じて**祝日をスキップ**を選びます。
4. ミーティング日程のプレビューを確認し、スキップしたい日程のチェックを外します。
5. メンバーがこれらのイベントに返答できるようにしたい場合は、**RSVP を許可**をオンのままにしてから保存します（後述）。

## イベントの出欠確認（RSVP）

グループイベントでは、イベントの日程ごとに**はい**、**いいえ**、**未定**の出欠回答を集めることができます。

- **RSVP を許可**は、一括追加ダイアログで作成したイベントではデフォルトでオンになっています。そのイベントで回答を受け付けない場合は、チェックを外してください。RSVP をオフにしたイベントは、グループのイベント一覧で**無効**と表示されます。
- B1 Admin のグループのイベント一覧では、各イベントに回答の集計が表示されます（例：「はい 5 · 未定 2 · いいえ 1」）。クリックすると **RSVP 回答**の名簿が開き、その日程に対して誰が「はい」「未定」「いいえ」と答えたかを確認できます。

:::tip
RSVP を使うと、正式なイベント登録の手間をかけずに、リーダーが参加人数を把握できます。有料の申し込みや定員管理が必要なイベントでは、代わりに[イベント登録](../calendars/creating-calendars.md#enabling-event-registration)を利用してください。
:::

## カレンダーの表示

グループカレンダーには、複数の表示方法があります。

- **月** -- 1 か月全体を一目で確認できます。
- **週** -- 今週の予定に集中できます。
- **日** -- 1 日の予定を詳しく表示します。
- **予定リスト** -- 今後のイベントを日時順に一覧で表示します。

表示方法は、カレンダー上部のボタンで切り替えられます。

## イベントの詳細と会話

イベントをクリックすると、その詳細を表示できます。イベントの詳細画面では次のことができます。

- **メンバーとリーダー**は、イベントについて会話を始めたり、コメントを残したりできます。
- **リーダー**は、イベントの詳細や時刻を編集したり、イベントを削除したりできます。

:::warning
イベントを削除すると、完全に削除され元に戻せません。定期イベントの 1 回分だけを取り消したい場合は、削除ではなく編集することを検討してください。
:::

## カレンダーの購読

グループカレンダーを個人のカレンダーと同期できます。

1. グループカレンダーのページで、**購読**をクリックします。
2. 画面の案内に従って、Google カレンダー、Apple カレンダー、Outlook、その他の購読に対応したカレンダーアプリにカレンダーを追加します。

:::tip
購読すると、B1 を別途確認しなくても、個人の予定とグループのイベントを同期しておけます。グループリーダーによる変更は、同期されたカレンダーに自動的に反映されます。
:::
