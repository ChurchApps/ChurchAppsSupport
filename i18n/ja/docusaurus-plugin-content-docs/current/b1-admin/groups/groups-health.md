# グループの健全性

<div class="article-intro">

グループの健全性ダッシュボードでは、すべてのグループの状況を一目で確認できます。メンバー数の推移、平均出席者数、過去90日間の増加または減少が、並べ替え可能な1つの表にまとめられています。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 意味のあるデータを表示するには、メンバーがいるグループが少なくとも数件必要です。[グループの作成](creating-groups)を参照してください。
- 出席データは記録されたセッションから取得されます。[出席](../attendance/)セクションを参照してください。

</div>

## グループの健全性を開く

B1 Admin で、画面左上の検索バーである[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)を開き、**People** を展開して **Groups** をクリックします。次に、ページヘッダーの **Group Health** ボタンをクリックします。ダッシュボードが読み込まれ、グループごとに1行ずつ表示された表が表示されます。

## 列

| 列 | 表示内容 |
|--------|--------------|
| **名前** | グループ名。グループの詳細ページへのリンクになっています |
| **カテゴリ** | グループのカテゴリ |
| **メンバー数** | 現在のアクティブなメンバー数 |
| **参加 (90日)** | 過去90日間に参加したメンバー |
| **退会 (90日)** | 過去90日間に退会したメンバー |
| **離脱率 (90日)** | 90日間の純離脱率（パーセント） |
| **平均出席者数** | 出席セッションごとの平均人数 |

いずれかの列見出しをクリックすると、その列で表が並べ替えられます。もう一度クリックすると、並べ替えの向きが逆になります。

## 健全性データの活用

- **離脱率が高く、参加者が少ない** — メンバーが減少しており、離れたメンバーの補充もできていないグループです。グループリーダーと話し合う価値があります。
- **参加者は多いが、出席者が少ない** — 登録はしているものの、実際には参加していない人がいます。フォローアップを検討してください。
- **平均出席者数が多い** — 健全で活発なグループです。他のグループのお手本になる可能性があります。

:::tip
グループ名をクリックすると、そのグループの詳細ページに直接移動します。そこで個々のメンバー、出席記録、カレンダーのイベントを確認できます。
:::
