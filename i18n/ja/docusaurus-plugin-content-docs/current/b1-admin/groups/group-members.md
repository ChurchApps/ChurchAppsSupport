# グループメンバー

<div class="article-intro">

グループを作成したら、次はメンバーを追加します。グループの詳細ページから、人を検索したり、グループに追加したり、リーダーを割り当てたり、メッセージを送信したり、メンバーリストをエクスポートしたりできます。グループのメンバーを管理することは、小グループ、委員会、クラスを運営するうえで欠かせません。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1 Admin で少なくとも1つのグループを設定しておく必要があります。まだグループを作成していない場合は、[グループの作成](creating-groups.md)を参照してください。
- 追加したい人は、すでに [人](../people/adding-people.md) のディレクトリに登録されている必要があります。登録されていない場合は、メンバー検索から作成できます（下記参照）。

</div>

## グループへのメンバーの追加

1. [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)で **人 > グループ** を選び、管理したいグループをクリックします。
2. グループページの **メンバー** セクションで **すべてのメンバー** をクリックします。（チームや奉仕グループは、直接メンバーリストが開きます。）
3. メンバーリストの下にある **人を追加** ボックスに、追加したい人の名前を入力し、**Enter** キーを押すか検索アイコンをクリックします。
4. 検索結果に表示された人の名前、またはその横の追加アイコンをクリックします。
5. その人がグループのメンバーリストに表示されます。

:::tip
何か入力する前に、**人を追加** ボックスには **最近の人** の短いリストが表示されます。ここから1クリックで追加できます。
:::

作業が終わったら、グループ名が付いた **戻る** リンクをクリックして、グループページに戻ります。グループページには、**メンバー**、**予定**、**カレンダー**、**健全性** の概要が表示され、それぞれに詳細画面へのリンクがあります。あなたがグループのリーダーの場合は、**リーダーメモ** も表示されます（下記の [リーダーメモ](#leader-notes) を参照）。グループにフォームがリンクされている場合は、**リンクされたフォーム** セクションも表示されます（下記の [リンクされたフォーム](#linked-forms) を参照）。

### まだ B1 に登録されていない人を追加する

検索しても該当者が見つからない場合、検索結果に **該当する記録はありません** と **新しい人を追加** リンクが表示されます。そのリンクをクリックし、名、姓、（任意で）メールアドレスを入力して **追加** をクリックします。新しい人は人のディレクトリに作成され、同時にグループに追加されるため、改めて検索する必要はありません。

## グループリーダーの指定 {#designating-group-leaders}

グループリーダーには特別な権限があります。[グループカレンダー](group-calendar.md)を編集したり、予定を管理したり、グループの運営を調整したりできます。

1. グループのメンバーリストで、リーダーに指定したい人を探します。
2. その人の名前の横にある **星のアイコン**（**リーダーに指定**）をクリックします。
3. その人はグループリーダーとして指定され、**リーダー** バッジが表示されます。

リーダーの権限を解除するには、もう一度星のアイコン（**リーダー権限を削除**）をクリックします。

:::info
グループのメンバーは全員グループカレンダーと予定を閲覧できますが、カレンダーの予定を追加・編集できるのはリーダーだけです。
:::

## リンクされたフォーム {#linked-forms}

単独のフォームを[グループにリンク](../forms/creating-forms.md#linking-a-form-to-a-group)すると、グループページに **リンクされたフォーム** セクションが表示されます。このセクションには、各フォームの名前、**受付中** か **受付終了** かの状態、リンクされているフォームの数が表示されます。このセクションは、グループのリーダーとフォームを管理できる人にのみ表示され、フォームが1つ以上リンクされている場合にだけ表示されます。フォームの管理者は、フォーム名をクリックしてフォームを開いたり、**すべてのフォーム** をクリックしてフォームページに移動したりできます。

グループリーダーは、[B1.church](../../b1-church/groups/group-details.md#linked-forms) のグループページから、これらのフォームへの回答を読んだり印刷したりできます。

## リーダーメモ {#leader-notes}

グループリーダーは、グループに関する非公開のメモを残せます。たとえば、フォローアップ、祈りの課題、牧会上の懸念などを記録できます。このメモは、グループの他のメンバーには表示されません。

**リーダーメモ** セクションは、そのグループのリーダーにのみグループページに表示されます。最新のメモ、投稿者と投稿日時、メモの件数が表示されます。

1. グループページで、**リーダーメモ** セクションの **すべてのメモ** をクリックします。
2. ボックスにメモを入力して投稿します。メモは、投稿者の名前と写真、投稿された日時とともに一覧表示されます。
3. グループ名が付いた **戻る** リンクをクリックして、グループページに戻ります。

:::info
リーダーメモは、グループのリーダーにだけ表示されます。他のメンバーはもちろん、すべての権限を持つスタッフや管理者であっても、そのグループのリーダーでなければ閲覧できません。別の人に閲覧権限を与えるには、その人を[リーダーに指定](#designating-group-leaders)してください。リーダーは、[B1.church](../../b1-church/groups/group-details.md#leader-notes) のグループページの **リーダーメモ** セクションや、B1 Admin の [メモ](../people/notes.md) ページの **グループ** タブでもこれらのメモを確認できます。
:::

## グループメンバーへのメッセージ送信

B1 Admin から、グループのすべてのメンバーに直接連絡できます。

1. グループのメンバーリストで、リストの上にある **メンバーにメッセージを送信** アイコンをクリックします。
2. テキストボックスにメッセージを入力します（または **テンプレート** から選択します）。
3. **送信** をクリックします。

メッセージは、グループのすべてのメンバーに届きます。

## グループメンバーへのメール送信

グループのすべてのメンバーに、書式を整えたメールを送信できます。

1. グループの詳細ページで、ページ左側の **メール** ボタンをクリックします。
2. メール送信ダイアログが開きます。メールを受け取るメンバーの数と、メールアドレスが登録されていないメンバーの数が表示されます。
3. 必要に応じて、ドロップダウンから **メールテンプレート** を選択するか、ゼロからメッセージを作成します。テンプレートを作成・編集するには **テンプレートを管理** をクリックします。
4. **件名** を入力します。フィールドのチップをクリックすると、差し込みフィールドを挿入できます。挿入できるのは、`{{firstName}}`、`{{lastName}}`、`{{displayName}}`、`{{email}}`、`{{churchName}}` と、**グループ名**（`{{groupName}}`）です。グループ名には、そのグループの名前が入ります。
5. HTML エディタを使って**メール本文**を作成します。同じ差し込みフィールドをここでも使えます。
6. **送信** をクリックします。
7. 送信が完了すると、正常に送信されたメールの件数と、スキップされたメンバーの件数（メールアドレス未登録）の概要が表示されます。

:::tip
毎週のアップデート、イベントのお知らせ、祈りの依頼など、定期的に行う連絡には、再利用できるメールテンプレートを作成しましょう。テンプレートを使うと時間を節約でき、メッセージの内容も統一できます。
:::

### 教会でグループメールを有効にする {#turning-on-group-email-for-your-church}

B1 のすべての教会は、同じアドレスからメールを送信するため、送信者の評価を共有しています。全員のメールが迷惑メールフォルダに入らないようにするため、ChurchApps チームは、グループメールを送信できるようになる前に、教会ごとに一度審査を行います。

教会がまだ審査を受けていない場合、メール送信ダイアログにはメッセージエディタの代わりに **グループメールには簡単な審査が必要です** と表示されます。

1. **審査をリクエスト** をクリックします。ChurchApps サポートチームに通知が届きます。
2. ダイアログの表示が **審査をリクエスト済み** に変わります。ダイアログを閉じても構いません。
3. グループメールは、通常1営業日以内に有効になります。有効になったら、メール送信ダイアログをもう一度開いてメッセージを送信できます。

教会が承認されるまで、B1 は [フォームのフォローアップメール](../forms/creating-forms.md#sending-a-follow-up-email) や、[ワークフロー](../serving/workflows.md) の **メールを送信** ステップも送信しません。

:::info 送信上限
承認後、教会が1日に送信できる教会作成のメールは最大150通です。教会の送信実績が良好であれば、上限は徐々に増え、1日最大2,000通まで送信できるようになります。最近送信したメッセージがバウンスしたり、迷惑メールとして報告されたりした場合、グループメールは一時停止され、ダイアログからサポートへの問い合わせを求められます。1日の上限を超える送信を行おうとすると、B1 は送信を行わず、エラーを表示します。
:::

## グループメンバーへのテキストメッセージ送信

教会が [テキストメッセージサービス](../settings/church-settings.md#texting) を接続すると、グループページの **メール** ボタンの横に **テキスト** ボタン（**このグループにテキスト**）が表示されます。

1. グループの詳細ページで **テキスト** をクリックします。
2. テキストを受け取るメンバーの数がダイアログに表示されます。携帯電話番号が登録されていないメンバーや、受信を拒否しているメンバーはスキップされます。
3. 必要に応じて **テンプレートを読み込む（任意）** から保存済みのテキストメッセージを選び、メッセージ欄に入力します。教会に [テキストテンプレート](../settings/email-templates.md#text-templates) がある場合にこの選択肢が表示されます。設定を編集できる人には **テンプレートを管理** リンクも表示されます。
4. メッセージを入力または編集します。個別の内容にするには、メッセージボックスの下にあるプレースホルダーのチップをクリックします。**名**、**姓**、**表示名**、**教会名**、**グループ名** のいずれかを選ぶと、カーソル位置に挿入されます。各プレースホルダーは、テキストが送信されるときに受信者本人の情報に置き換えられます。**グループ名** には、そのグループの名前が入ります。
5. **送信** をクリックします。

詳しくは、[差し込みフィールドを使ったテキストのパーソナライズ](../settings/church-settings.md#personalizing-texts-with-merge-fields) を参照してください。

## グループデータのエクスポート

グループのメンバーリストをファイルとしてダウンロードするには、次の手順に従います。

1. グループのメンバーリストで、リストの上にある **エクスポート** をクリックします。
2. グループのメンバー情報を含む CSV ファイルが、お使いのコンピューターにダウンロードされます。

CSV エクスポートは、データを他のツールに取り込んだり、オフラインの記録を残したりするときに便利です。その他のエクスポートオプションについては、[データのエクスポート](../people/exporting-data.md) を参照してください。

## メンバーリストの印刷

グループのメンバーリストで、リストの上にある **出席表を印刷** （プリンターの）アイコンをクリックし、レイアウトを選びます。ページが新しいタブで開き、ブラウザーの印刷ダイアログが自動的に表示されます。

- **出席表** — 日付のないクラス名簿です。教師が手作業で印を付けられるように、**出席** と **欠席** の欄があります。詳しくは、[出席簿の印刷](../attendance/recording-attendance.md#printing-a-roll-sheet) を参照してください。
- **連絡先名簿** — グループの連絡先リストです。今日の日付が入り、教会のロゴ（[ウェブサイト > 外観](../website/appearance.md) でアップロードした **明るい背景用ロゴ**。アップロードしていない場合はなし）の下に教会名、その下にグループ名が表示されます。各メンバーは、**名前**、**電話**、**メール**、**住所** の列に情報が記載された1行で表されます。リーダーは先頭に並び、**リーダー** と表示されます。その後、他のメンバーが姓順に並びます。電話番号は、メンバーの携帯電話番号が表示されます。携帯電話番号がない場合は、自宅または勤務先の電話番号が表示されます。連絡を拒否しているメンバーの連絡先情報は空欄になります。

:::warning
連絡先名簿には、メンバーの個人的な連絡先情報が含まれています。印刷したものは、グループのリーダーや、必要とする人にだけ共有してください。
:::

## グループメンバーへのプッシュ通知の送信

プッシュ通知をオンにして B1.church アプリをインストールしているグループメンバー全員に、直接プッシュ通知を送信できます。

1. グループの詳細ページで **通知** をクリックします（**メール** と **テキスト** ボタンの下にあります。**テキスト** ボタンは [テキストメッセージサービス](../settings/church-settings.md#texting) を接続すると表示されます）。
2. ダイアログが開き、プッシュ通知を有効にしているグループメンバーの人数が表示されます。
3. 通知の内容を入力します。
   - **タイトル** *（必須）* — 短い概要です。80文字以内で入力します。
   - **メッセージ** *（必須）* — 通知の本文です。240文字以内で入力します。
   - **開くリンクまたはチラシの URL** *（任意）* — 通知をタップしたときに開くアプリ内の相対パス（例: `/mobile/groups`）または完全な `https://` の URL です。
   - **画像の URL** *（任意）* — 対応する端末で通知と一緒に表示される画像の `https://` の URL です。
4. 通知が端末にどのように表示されるかが、プレビューで確認できます。
5. **通知を送信** をクリックします。

:::info
プッシュ通知は、B1.church PWA をインストールしていて、プッシュ通知をオフにしていないグループメンバーにのみ届きます。プッシュ用の端末が登録されていないメンバーや、プッシュ通知をオフにしているメンバーはスキップされたものとして扱われ、送信の概要には、届いた人数とスキップされた人数が表示されます。
:::

:::tip
送信後、ダイアログには正常にキューに入った通知の件数が表示されます。多くのメンバーがスキップされている場合は、B1.church サイトを開き、ホーム画面にアプリとしてインストールし、通知が表示されたら許可するよう案内してください。
:::

## メンバーの削除

グループからメンバーを削除するには、メンバーリストでその人の名前を探し、名前の横にある **削除** ボタンをクリックします。

:::info
グループから人を削除しても、教会のディレクトリからは削除されません。その人は引き続き [人](../people/adding-people.md) のセクションに表示され、いつでもグループに再度追加できます。
:::
