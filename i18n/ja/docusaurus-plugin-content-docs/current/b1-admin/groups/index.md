# グループ

<div class="article-intro">

**グループ**セクションでは、教会のメンバーを奉仕団体、小グループ、聖書研究会、委員会などに分けて整理できます。グループは教会のコミュニティ活動の中核であり、このセクションでは、すべてのグループを一か所で作成、管理し、連絡を取るためのツールを利用できます。**チーム**はグループとは別のものである点にご注意ください。チームは奉仕やボランティアのスケジュール管理に使われます。

</div>

## 概要

グループは**カテゴリー**ごとに整理されます。カテゴリーとは、「小グループ」「奉仕団体」「委員会」などの最上位のラベルのことです。各カテゴリーには複数のグループを含めることができるため、関連するグループをまとめて管理しやすくなります。

グループページを開くと、**グループを検索...**の検索ボックス、カテゴリーボタンの並び、そしてグループの一覧表が表示されます。各グループの名前の下には、カテゴリーとラベル、およびメンバー数が表示されます。**すべて**またはカテゴリー名をクリックすると一覧を絞り込めます（その他のカテゴリーは**その他のカテゴリー**の中にあります）。また、**名前**または**人数**の列見出しをクリックすると並べ替えができます。

## できること

グループセクションでは、次のような操作ができます。

1. **グループの作成と整理** -- カテゴリーの中に新しいグループを追加し、教会の組織構成を反映させます。詳しくは[グループの作成](./creating-groups.md)をご覧ください。

2. **グループメンバーの管理** -- メンバーの追加や削除、リーダーの指定、グループへの連絡を行います。詳しくは[グループメンバー](./group-members.md)をご覧ください。

3. **予定の登録** -- 各グループには、ミーティング、行事、定期的な活動のための専用カレンダーを持たせることができます。詳しくは[グループカレンダー](./group-calendar.md)をご覧ください。

4. **参加申請の管理** -- グループが**リクエスト**の参加方式を使っている場合、参加を希望する人からの加入申請を確認し、承認または辞退できます。詳しくは[グループの参加申請](./group-join-requests.md)をご覧ください。

5. **グループデータの書き出し** -- 任意のグループのメンバー一覧を CSV ファイルとしてダウンロードし、表計算ソフトや郵送物の作成に使えます。書き出しの手順については[グループメンバー](./group-members.md)をご覧ください。

## はじめに

グループを開くには、[ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（B1 管理画面の左上にある検索バー）を開き、**人物**を展開して**グループ**をクリックします。既存のすべてのグループが表示され、カテゴリーで絞り込むことができます。

:::tip
初めて使う場合は、まず教会の組織構成に合ったカテゴリーをいくつか作成するとよいでしょう（例：「奉仕団体」「小グループ」「委員会」）。そのあとで、各カテゴリーに個別のグループを追加してください。手順の詳細は[グループの作成](./creating-groups.md)をご覧ください。
:::

:::info
グループにメンバーを追加する前に、そのメンバーが[人物](../people/adding-people.md)のディレクトリに登録されている必要があります。B1 を初めてセットアップする場合は、グループを作成する前に[メンバーデータをインポート](../people/importing-data.md)してください。
:::
