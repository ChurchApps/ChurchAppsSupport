# グループの作成

<div class="article-intro">

B1 Adminでグループを作成するのは簡単です。カテゴリを設定し、グループ名を入力してから、各種設定を行います。グループを使うと、小規模グループ、委員会、クラスなど、教会内の活動を意味のある単位にまとめて整理できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- グループを管理する権限を持つ、有効なB1 Adminアカウントが必要です。アクセス権限のレベルがわからない場合は、[役割と権限](../people/roles-permissions.md)をご覧ください。
- グループのカテゴリ構成を決めておきましょう（例：「小規模グループ」「奉仕」「委員会」）。カテゴリを設定すると、関連するグループを整理しやすくなります。

</div>

## 新しいグループの追加

1. [ジャンプメニュー](../introduction.md#getting-around-with-the-jump-menu)（B1 Adminの左上にある検索バー）を開き、**People**を展開して、**Groups**をクリックします。
2. ページヘッダーの**Add Group**をクリックします。一覧の下に**New Group**フォームが開きます。**Category Name**を入力します。カテゴリを使うと関連するグループをまとめられます（例：「小規模グループ」「奉仕」「委員会」）。既存のカテゴリを使う場合は、一覧から選択できます。
3. グループの**Name**を入力します。
4. **Add**をクリックします。新しいグループが一覧に表示され、名前の下にカテゴリが表示されます。

## グループ設定の構成

グループを作成したら、詳しい情報を追加できます。

1. 一覧の**グループ名**をクリックして開きます。
2. グループページの左側、グループの詳細の下にある**Edit**ボタンをクリックします。
3. 次の項目を設定します。
   - **Description**：グループの内容の簡単な概要です。メンバーに表示されます。
   - **Meeting Times**：グループが通常集まる日時です（例：「毎週水曜日 19:00」）。
   - **Join Policy**：このグループに参加できる人を選びます。
     - **Open**：承認なしで誰でもすぐに参加できます。
     - **Request**：参加リクエストを提出する必要があり、承認が必要です（[グループ参加リクエスト](./group-join-requests.md)をご覧ください）。
     - **Closed**：リーダーまたは管理者が手動でメンバーを追加します。
   - **Labels**：グループに説明的なラベルを1つ以上割り当てます（例：「対面」「オンライン」「新しいメンバー歓迎」）。ラベルは自由に定義できるタグです。該当するものをすべてチェックしてください。ラベルは、Groups Browserのウェブサイト要素でグループを絞り込むのにも使えます。
   - **Confidential group**：このグループとその名簿を、公開ページ、グループ検索、およびメンバー以外の人から非表示にします。回復支援やカウンセリングの奉仕など、機密性の高いグループに使用してください。表示できるのはグループのメンバーと教会スタッフだけです。
   - **Discussions**：グループのチャットフィードのオン／オフを切り替えます。任意のメンバーが投稿できます。初期設定はオンです。
   - **Announcements**：リーダーだけが投稿できる2つ目のチャットフィードを有効にします。メンバーは閲覧してリアクションできますが、投稿できるのはリーダーだけです。初期設定はオンです。
   - **Attendance Tracking**：このグループの[出席](../attendance/tracking-attendance.md)を記録したい場合は有効にします。
   - **Service Times**：該当する場合は、グループを特定の礼拝時間に関連付けます。礼拝時間の詳細は[出席の設定](../attendance/setup.md)をご覧ください。
4. **Save**をクリックして変更を適用します。

:::tip
わかりやすい説明と集会時間を追加しておくと、参加者がグループに参加したときに何を期待できるかがわかりやすくなります。
:::

:::info
DiscussionsとAnnouncementsの両方をオフにすると、メンバーポータルでグループのMessagesタブが完全に削除されます。どちらか一方だけをオフにすると、そのタブだけが非表示になり、メンバーは残っているフィードに移動します。どちらの場合も既存のメッセージは保持されます。これらの切り替えは、新しい投稿の可否を制御するだけです。
:::

## グループの複製

定期的に開催されるクラスや奉仕の新しい期を始めるところですか？すべての設定を入力し直す代わりに、既存のグループを複製できます。

1. グループを開き、**Duplicate**をクリックします（グループページの左側にある**Edit**ボタンの下にあります）。
2. 複製を確認します。

コピーには元のグループの設定（カテゴリ、説明、集会時間・場所、参加ポリシー、ラベル、キャンパス）が引き継がれますが、メンバーは**引き継がれません**。新しいグループの名前は元のグループ名に「 (Copy)」を付けたものになります。名前を変更するには、グループ設定から行ってください。

## グループのアーカイブ

グループが活動していないものの、削除せずに履歴を残しておきたい場合は、次の手順を行います。

1. グループを開き、**Edit**をクリックして設定を編集します。
2. **Archive**をクリックし、確認します。

アーカイブされたグループは、メインのGroups一覧に表示されなくなります。再び表示するには、Groupsページ上部のカテゴリボタンの横にある**Show archived**ボタンをクリックし、対象グループの横にある**Restore**をクリックします。

:::info
グループをアーカイブしても、メンバー、出席履歴、カレンダーのイベントは削除されません。アーカイブ中は、既定の一覧から非表示になるだけです。元に戻すまでの間の状態です。
:::

## 次のステップ

グループを作成して設定したら、次の作業に進めます。

- **メンバーの追加**：人を検索してグループに追加します。星のアイコン（**Make Leader**）を使うと、グループのリーダーを指定できます。詳しくは[グループメンバー](./group-members.md)をご覧ください。
- **カレンダーの設定**：グループのイベントや定例の集まりを作成します。詳しくは[グループカレンダー](./group-calendar.md)をご覧ください。
- **連絡**：グループページから、グループのメンバー全員に直接メッセージを送信します。
- **データの書き出し**：グループのメンバー一覧の上にある**Export**をクリックして、データをダウンロードします。

:::info
すべてのグループはカテゴリに所属しており、メインのGroupsページではカテゴリ別に一覧を絞り込めます。教会の成長に合わせて、いつでもカテゴリを並べ替えたり名前を変更したりできます。
:::
