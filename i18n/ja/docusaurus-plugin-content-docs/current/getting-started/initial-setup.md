# 初期設定

<div class="article-intro">

アカウントと教会を作成したら、チームを招待する前にいくつか重要な設定を行います。このガイドでは推奨される設定順序を説明します。これに従えば、初日から教会の運用を始められます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [アカウントを作成](./create-account.md)して教会を登録する
- 教会のロゴとブランディング素材を準備する（任意ですが推奨します）

</div>

## ステップ 1: 教会情報を設定する

1. [ジャンプメニュー](../b1-admin/introduction.md#getting-around-with-the-jump-menu)（B1 Admin 画面左上の検索バー）を開き、**設定**を展開して、**設定**をクリックします。
2. **教会情報**セクションで、**編集**をクリックします。
3. 教会の**名前**、**サブドメイン**、**住所**を入力します。
4. **保存**をクリックして変更を適用します。

## ステップ 2: ブランディングを設定する

1. ジャンプメニューで、**ウェブサイト > 外観**を選択します。
2. **教会のロゴ**をアップロードします。
3. 色や画像などの追加のブランディング設定を行います。
4. 設定したブランディングは、B1.church のウェブサイトと B1 App に表示されます。

:::tip
チームメンバーを招待する前にロゴとブランディングを準備しておくと、メンバーがログインしたときに洗練された第一印象を与えられます。
:::

## ステップ 3: 役割を設定してチームを招待する

1. ジャンプメニューで、**設定 > 役割**を選択します。
2. チーム用の役割を作成します（例: 「牧師」「書記」「会計」）。
3. 各役割に適切な権限を割り当てます。
4. メンバーのアカウントを検索して追加し、役割に割り当てます。

## ステップ 4: 主要な領域を設定する

チームの準備ができたら、B1 Admin の中核となる領域の設定を始めましょう。

1. **人** -- 教会の名簿にメンバーを追加します。これはすべての基礎になるので、最初に取り組みましょう。個別に追加することも、**設定**の**インポート/エクスポート**ツールを使うこともできます。
2. **グループ** -- 小グループ、奉仕チーム、クラス、その他の集まりのためのグループを作成します。
3. **出欠** -- 出欠を記録するために、キャンパス、礼拝、礼拝時間を設定します。
4. **献金** -- 献金基金を設定し、オンライン献金を受け付けるために決済ゲートウェイ（Stripe）を接続します。
5. **ウェブサイト** -- B1.church のウェブサイトビルダーを使って、公開用の教会ウェブサイトを作成します。

:::info
すべての領域を一度に設定する必要はありません。多くの教会は**人**と**グループ**から始め、プラットフォームに慣れてから**出欠**と**献金**を追加しています。
:::

## 推奨される設定順序

スムーズに設定を進めるために、次の順序をお勧めします。

1. **人** -- まず、メンバーと定期的に出席する方を追加します。
2. **グループ** -- 人を意味のあるグループに分けます。
3. **出欠** -- 毎週の出席者の記録を開始します。
4. **献金** -- 人がシステムに登録された後、献金を設定します。
5. **ウェブサイト** -- データが揃った後で、公開用のサイトを最後に作成します。

これらの手順が完了すれば、教会の運用を始める準備が整います。各領域の詳しいガイドについては、[B1 Admin](/docs/b1-admin/) のドキュメントをご覧ください。
