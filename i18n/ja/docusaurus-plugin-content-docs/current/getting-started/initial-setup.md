# 初期設定

<div class="article-intro">

アカウントと教会の作成が終わったら、チームを招待する前に設定しておきたい重要な手順がいくつかあります。このガイドでは推奨される設定の順序を説明します。これに沿って進めれば、初日から教会の運営を始められます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [アカウントを作成する](./create-account.md)と教会を登録する
- 教会のロゴとブランディング素材を用意する（任意ですが、用意することをおすすめします）

</div>

## ステップ1：教会の情報を設定する

1. [ジャンプメニュー](../b1-admin/introduction.md#getting-around-with-the-jump-menu)（B1 Admin の左上にある検索バー）を開き、**設定**を展開して、**設定**をクリックします。
2. **教会情報**セクションで、**編集**をクリックします。
3. 教会の**名前**、**サブドメイン**、**住所**を入力します。
4. **保存**をクリックして変更を適用します。

## ステップ2：ブランディングを設定する

1. ジャンプメニューから**ウェブサイト > 外観**を選択します。
2. 教会の**ロゴ**をアップロードします。
3. 色や画像など、その他のブランディング設定を行います。
4. 設定したブランディングは、B1.church のウェブサイトと B1 Mobile アプリに表示されます。

:::tip
チームメンバーを招待する前にロゴやブランディングを準備しておくと、メンバーが初めてログインしたときに洗練された第一印象を与えられます。
:::

## ステップ3：役割を設定してチームを招待する

1. ジャンプメニューから**設定 > 役割**を選択します。
2. チームのための役割を作成します（例：「牧師」「書記」「会計」）。
3. 各役割に適切な権限を割り当てます。
4. メンバーのアカウントを検索して役割に割り当て、チームメンバーを追加します。

## ステップ4：主要な分野を設定する

チームが整ったら、B1 Admin の中核となる分野の設定を進めましょう。

1. **人物**：教会の名簿にメンバーを追加します。ほかのすべての基盤になるので、最初に取り組みましょう。人物は手動で追加するか、**設定**にある**インポート/エクスポート**ツールを使って追加できます。
2. **グループ**：小グループ、奉仕チーム、クラス、その他の集まりのためのグループを作成します。
3. **出席**：出席を記録するために、キャンパス、礼拝、礼拝時間を設定します。
4. **献金**：献金基金を設定し、オンライン献金を受け付けるために決済サービス（Stripe）を接続します。
5. **ウェブサイト**：B1.church のウェブサイトビルダーを使って、公開用の教会ウェブサイトを作成します。

:::info
すべての分野を一度に設定する必要はありません。多くの教会は、まず**人物**と**グループ**から始め、プラットフォームに慣れてから**出席**と**献金**を追加しています。
:::

## 推奨される設定の順序

スムーズに設定を進めるために、次の順序をおすすめします。

1. **人物**：まず、メンバーと定期的に出席する人を登録します。
2. **グループ**：人々を意味のあるグループにまとめます。
3. **出席**：毎週誰が出席したかの記録を始めます。
4. **献金**：人物が登録されたら、献金を設定します。
5. **ウェブサイト**：データが揃ってから、最後に公開用のサイトを作成します。

これらの手順を終えると、教会の運用を始める準備が整います。各分野の詳しいガイドは [B1 Admin](/docs/b1-admin/) のドキュメントをご覧ください。
