# アカウントの作成

<div class="article-intro">

ChurchAppsを使い始めるには、まずアカウントを作成します。手続きは数分で完了し、B1 Admin、B1.church、Lessons.churchを含むすべてのChurchAppsツールを利用できるようになります。

## 登録手順

1. Webブラウザで[B1.church](https://b1.church)にアクセスします。
2. **登録**ボタンをクリックします。
3. **名前**、**姓**、**メールアドレス**を入力します。教会でシングルサインオンが有効になっている場合は、**Googleで続行**または**Microsoftで続行**をクリックすると、既存のアカウントを使って手順5に直接進めます。
4. アカウントのパスワードを作成します。
5. 登録フォームを送信します。

:::info
1つのChurchAppsアカウントで、B1、Lessons.church、その他のChurchAppsアプリをすべて利用できます。**すでにChurchAppsアカウントをお持ちです。そのアカウントでサインインしてください。**と表示された場合は、**ログイン**をクリックし、そのメールアドレスでサインインしてください。パスワードを忘れた場合は**パスワードをお忘れですか**を使用してください。
:::

## メールアドレスの確認

登録後、入力したメールアドレス宛に確認メールが届きます。

1. 受信トレイでChurchAppsからの確認メールを探します。
2. メール内の確認リンクをクリックします。
3. アカウントの確認が完了し、利用できるようになります。

:::tip
確認メールが見当たらない場合は、迷惑メールフォルダを確認してください。メールはChurchAppsから送信され、届くまでに1、2分かかる場合があります。
:::

## 教会の設定

メールアドレスを確認してログインすると、新しい教会を作成するか、既存の教会に参加するかを選択できます。

**新しい教会を作成する場合:**

1. **新しい教会を作成**のオプションを選択します。
2. **教会名**と基本情報を入力します。一致する教会が見つかった場合、登録フォームに教会の詳細が自動的に入力されます。
3. 設定手続きを完了します。
4. B1 Adminのホームページである**ダッシュボード**に移動します。ここから教会の設定を始められます。

**既存の教会に参加する場合:**

1. **既存の教会に参加**のオプションを選択します。
2. 教会名で検索します。
3. 参加をリクエストします。参加リクエストは、教会の管理者が承認する必要があります。

:::info
まだ登録されていないメールアドレスでログインしようとすると、自動的に登録画面に移動し、アカウントを作成できます。
:::

:::info
新しい教会を作成した人には、すべての設定と機能へのフルアクセスを持つ**ドメイン管理者**の役割が自動的に割り当てられます。追加の管理者は、後から**役割**ページで設定できます。
:::
