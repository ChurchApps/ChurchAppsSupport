# はじめに

<div class="article-intro">

ChurchApps へようこそ -- 教会の成長を支えるために設計された、無料のオープンソースツールです。小規模な会衆でも大規模な多拠点の組織でも、ChurchApps は教会コミュニティを管理し、成長させるために必要なものをすべて提供します。

## すでにサインアップ済みですか？ ここから始めましょう

最初の15分間にやること:

1. **教会らしくしましょう。** 教会名、住所、ロゴを追加して、B1、ウェブサイト、アプリが教会の姿を反映するようにします。[初期設定の手順1と2](./initial-setup.md#step-1-configure-your-church-information)をご覧ください。
2. **メンバーを追加しましょう。** 数名を手動で追加するか、スプレッドシートや以前の教会管理ソフトから名簿全体をインポートします。[メンバーのインポート](../b1-admin/people/importing-data.md)（動画あり）をご覧ください。
3. **チームを招待しましょう。** スタッフや主要なボランティアに、適切な権限を付けてアクセスを許可します。[役割と権限](../b1-admin/settings/roles-permissions.md)をご覧ください。

### 最初のプロジェクトを選びましょう

- **子ども向けの教室:** 礼拝の映像を流す教室のテレビを設定し、今週日曜日の無料の [Lessons.church](../lessons-church/index.md) レッスンも、[FreePlay](../freeplay/index.md) で単独で再生できるようにします。**<a href="https://mautic.churchapps.org/guides/classroom-tv.html" target="_blank">教室のテレビをステップごとに設定する</a>**（短い動画8本、約15分）に沿って進めてください。
- **小グループ:** [小グループを運営する](../b1-admin/guides/small-groups.md)
- **教会のウェブサイト:** [ウェブサイトを公開する](../b1-admin/guides/launch-website.md)
- **オンライン献金:** [オンライン献金を設定する](../b1-admin/guides/online-giving.md)
- **子どものチェックイン:** [チェックインを設定する](../b1-admin/guides/childrens-checkin.md)
- **日曜日のボランティア:** [日曜日のボランティアを管理する](../b1-admin/guides/sunday-volunteers.md)
- **出席:** [出席を記録する](../b1-admin/guides/track-attendance.md)
- **説教とライブ配信:** [説教ライブラリを作成する](../b1-admin/guides/sermon-library.md)

ここが初めてで、まだアカウントがない場合は、[アカウントの作成](./create-account.md)から始めてください。

## ChurchApps の製品

ChurchApps には、互いに連携して動作するいくつかの製品が含まれています:

- **B1 Admin** -- 教会管理ダッシュボードです。メンバー、グループ、出席、献金、ウェブサイトのコンテンツなどを、ひとつの場所から管理できます。[B1 Admin ガイド](/docs/b1-admin/)
- **B1.church** -- 教会の公開ウェブサイトとメンバー用ポータルです。メンバーは説教を視聴したり、ディレクトリにアクセスしたり、オンラインで献金したり、つながりを保ったりできます。[B1.church ガイド](/docs/b1-church/)
- **Lessons.church** -- 日曜学校、小グループ、聖書研究のための無料の教会カリキュラムです。増え続けるレッスンのライブラリに、費用をかけずにアクセスできます。[Lessons.church ガイド](/docs/lessons-church/)
- **FreePlay** -- レッスン、礼拝の映像、お知らせを教室や廊下のテレビ（Fire TV、Android TV、Apple TV）で再生する無料のテレビアプリです。スケジュールに沿った再生もできます。[FreePlay を設定する](/docs/freeplay/)
- **FreeShow** -- 礼拝のための無料のプレゼンテーションソフトです。集会中に歌詞、スライド、メディアを表示できます。[freeshow.app](https://freeshow.app)
- **WorshipCommons** -- 教会が無料で歌える賛美の公開ライブラリです。パブリックドメインの讃美歌や、作詞家・作曲家が共有した歌を、コード譜、歌詞、移調、音声付きで提供します。[worshipcommons.org](https://worshipcommons.org)

:::info
ChurchApps のツールはすべて**100%無料**です。利用制限も、プレミアムプランも、隠れた料金もありません。ChurchApps は寄付とボランティアに支えられた非営利団体です。
:::

## このドキュメントの内容

このドキュメントでは、ChurchApps を使い始めるために必要なことを順を追って説明します。次のことを学べます:

1. アカウントを作成し、教会を登録する。
2. 教会の基本設定とブランディングを行う。
3. 適切な役割と権限でチームを設定する。
4. ツールを使って会衆を管理し始める。
