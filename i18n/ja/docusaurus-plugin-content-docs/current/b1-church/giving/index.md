# 献金

<div class="article-intro">

B1Appを使えば、オンラインでの献金を通して教会を支援できます。少額の単発の献金をしたい場合でも、定期的な献金を管理したい場合でも、必要なものはすべてお使いの教会のB1.churchサイトから利用できます。

</div>

## 概要

B1Appでは、献金の方法が2つあります。

- **一般からの献金** -- ログインしなくても誰でも献金できます。教会の献金ページにアクセスし、献金先の基金を選択して、支払い情報を入力してください。アカウントは必要ありません。
- **ログインした状態での献金** -- 献金の前に[ログイン](../getting-started/logging-in.md)すると、献金がご自身のアカウントに紐づけられます。これにより、過去の献金履歴の全体を確認したり、印刷可能な献金明細を発行したり、定期献金を管理したり、保存済みの支払い方法を利用したりできるようになります。

## できること

献金セクションで利用できる機能は次のとおりです。

- **特定の基金への献金** -- 教会によっては、一般基金、建設基金、宣教基金など、複数の基金が設定されている場合があります。献金の振り先を選ぶことができます。
- **クレジットカードまたは銀行口座での支払い** -- 献金はStripeを通じて安全に処理されます。クレジットカードまたはデビットカードで支払うことができます。口座振替(ACH)による支払い手順も用意されています。
- **定期献金の設定** -- ログインしたメンバーは、献金を忘れないように、自動的に繰り返される定期献金を設定できます。
- **献金履歴の確認** -- 日付、支払い方法、基金、金額を含む過去の献金の一覧を確認できます。
- **献金明細の印刷** -- 税務上の記録用に、当年または前年の印刷可能な献金明細を発行できます。
- **支払い方法の管理** -- 今後の献金をより速く行えるよう、支払い方法を保存して管理できます。

教会によっては、メンバーが確認できる献金履歴の年数を制限したり、履歴を非表示にしたりすることができます。また、献金ページと明細に表示される献金に関するお知らせを追加することもできます。詳しくは[献金履歴](./donation-history.md#if-your-church-limits-giving-history)をご覧ください。

:::info
献金はStripeを通じて安全に処理されます。お支払い情報がB1.churchのサーバーに保存されることはありません。
:::
