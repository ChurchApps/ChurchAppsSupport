# 寄付履歴

<div class="article-intro">

ログインしている場合、過去の寄付の完全な記録を確認し、税務用の献金明細書を作成できます。寄付履歴は、メンバーポータルの**献金**ページから確認できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1.church アカウントに[ログイン](../getting-started/logging-in.md)している必要があります。
- 少なくとも1回は寄付を行っている必要があります。始め方については[寄付をする](./making-donations.md)を参照してください。

</div>

## 履歴の確認

1. B1.church アカウントにログインします。
2. **献金**ページ(教会の**寄付**タブ)を開くか、[ホームダッシュボード](../getting-started/navigating.md#home)の**献金**セクションにある**履歴**をタップします。
3. **すべての履歴**をタップすると、過去の寄付が表示されます。(ホームの**履歴**リンクは、この画面を直接開きます。)

上部では年(または**すべて**)を選ぶと、その期間の合計額、含まれる献金の件数、まだ保留中の件数を確認できます。その期間の寄付が複数の通貨で行われた場合、合計額は教会の通貨に換算され、その下に「現在の為替レートで換算」という注記が表示されます。

合計額の下には、寄付が月ごとにまとめて表示されます。各項目には次の情報が表示されます。

- **基金** -- 寄付の送り先の基金(例: 一般基金、建物基金)。
- **日付**と**方法** -- 寄付が行われた日時と支払い方法(例: 「カード - Visa」や「銀行 - ACH」)。
- **金額** -- 寄付の金額(寄付された通貨で表示)。

:::info
処理中の寄付には、金額の下に**保留中**のバッジが表示されます。
:::

**献金に戻る**をタップすると、献金ページに戻ります。

## 教会が献金履歴を制限している場合

メンバーが閲覧できる献金履歴の範囲は、教会が設定します。詳しくは[献金明細書](../../b1-admin/donations/giving-statements.md#what-members-see-in-b1church)を参照してください。

- **すべての年**(初期設定) -- このページのすべての内容が利用できます。
- **指定の年まで** -- その年以降の献金は、履歴、合計額、明細書に表示されません。献金ページには、現在の年の合計額の代わりにその年の合計額が表示されます。教会では、訂正作業を終えるまで現在の年を保留するためにこの設定を使うことがあります。
- **非表示** -- 献金ページから、年間合計、**最近のアクティビティ**、**すべての履歴**、**明細書を印刷**が削除されます。寄付や定期的な献金、支払い方法の管理は引き続き行えます。

教会が公開していない年の明細書を開こうとすると、「この献金明細書は利用できません。写しが必要な場合は教会にお問い合わせください。」と表示されます。

教会は、返金ポリシーなどの短い案内である**献金に関するお知らせ**を追加することもあります。これは献金ページ、寄付フォーム、**すべての履歴**の上部に表示され、献金明細書の下部にも印刷されます。

## 教会がオンライン献金を提供していない場合

教会がオンライン献金を設定していない場合でも、現金や小切手など、教会があなたについて記録した献金は確認できます。サインインした状態で献金ページを開くと、「この教会ではオンライン献金がまだ設定されていません。記録された献金と明細書は以下のとおりです。」というお知らせが表示されます。年間合計、**最近のアクティビティ**、**すべての履歴**、**明細書を印刷**は、通常どおり使用できます。**寄付する**ボタン、**前回と同じ額を寄付**、**定期的な献金**と**支払い方法**のセクションは表示されません。ホームダッシュボードの**献金**セクションにも、合計額と**履歴**リンクが表示されますが、**寄付する**ボタンは表示されません。

## 明細書の書き出しと印刷

献金ページの上部にある**明細書を印刷**をタップすると、現在の暦年(または教会が最後に公開した年)を対象とした印刷用の献金明細書が新しいタブで開きます。別の年を印刷するには、**すべての履歴**を開いて年を選び、合計額の横にある**明細書を印刷**をタップします。

:::tip
前年の寄付がまだ履歴に残っているうちに、税務申告に必要になる前、新年の早い時期に明細書を印刷しておくことをおすすめします。
:::

## 定期的な寄付

定期的な献金が設定されている場合、献金ページの**定期的な献金**セクションに、各献金の金額、基金、間隔、支払い方法が表示されます。**管理**をタップすると**定期的な献金と支払い方法**が開き、変更できます。

定期的な寄付が **Stripe** で処理されている場合は、キャンセルではなく**一時停止**できます。寄付の横にある一時停止アイコンをクリックして確定してください。同じアイコンを再度クリックして**再開**するまで、献金は行われません。一時停止中の寄付は、一覧で**一時停止中**と表示されます。その他の決済プロバイダーによる定期的な寄付は編集またはキャンセルできますが、一時停止はできません。

支払い方法を追加、削除、変更するには、**支払い方法**セクションの**管理**をタップします。
