# 献金履歴

<div class="article-intro">

ログインしている場合、過去の献金の完全な記録を確認し、税務目的の献金明細書を作成できます。献金履歴は、メンバーポータルの**献金**ページから利用できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1.churchアカウントに[ログイン](../getting-started/logging-in.md)している必要があります。
- 少なくとも1回は献金を行っている必要があります。始め方については[献金の方法](./making-donations.md)をご覧ください。

</div>

## 履歴を表示する

1. B1.churchアカウントにログインします。
2. **献金**ページ（教会の**寄付**タブ）を開くか、[ホームダッシュボード](../getting-started/navigating.md#home)の**献金**セクションで**履歴**をタップします。
3. **すべての履歴**をタップすると、過去の献金が表示されます。（ホームの**履歴**リンクからは、この表示に直接移動します。）

画面上部では、年（または**すべて**）を選ぶと、その期間の合計金額、含まれる献金の件数、まだ保留中の件数を確認できます。その期間の献金が複数の通貨で行われている場合、合計額は教会の通貨に換算され、その下に**現在の為替レートで換算**という注記が表示されます。

合計の下には、献金が月ごとにまとめて表示され、それぞれに以下の情報が含まれます。

- **基金** -- 献金の充当先の基金（例：一般基金、建築基金）。
- **日付**と**方法** -- 献金が行われた日付と支払い方法（例：「Card - Visa」や「Bank - ACH」）。
- **金額** -- 献金の金額。献金された通貨で表示されます。

:::info
処理中の献金は、金額の下に**保留中**のバッジが表示されます。
:::

**献金に戻る**をタップすると、献金ページに戻ります。

## 教会が献金履歴を制限している場合

教会は、メンバーが閲覧できる献金履歴の範囲を選択できます。詳しくは[献金明細書](../../b1-admin/donations/giving-statements.md#what-members-see-in-b1church)をご覧ください。

- **すべての年**（初期設定）-- このページのすべての内容が利用できます。
- **指定の年まで** -- その年以降の献金は、履歴、合計、明細書に表示されません。献金ページには、現在の年の合計ではなく、その年の合計が表示されます。教会は、修正作業を終えるまで当年分を保留するためにこの設定を使うことがあります。
- **非表示** -- 献金ページから、年間合計、**最近のアクティビティ**、**すべての履歴**、**明細書を印刷**が削除されます。献金や定期献金、支払い方法の管理は引き続き行えます。

教会が公開していない年の明細書を開こうとすると、「この献金明細書は利用できません。控えが必要な場合は教会にお問い合わせください。」と表示されます。

教会は**献金に関する注記**（返金ポリシーなどの短いメッセージ）を追加することもできます。この注記は、献金ページの上部、献金フォーム、**すべての履歴**の上部に表示され、献金明細書の末尾にも印刷されます。

## 教会がオンライン献金を提供していない場合

教会がオンライン献金を設定していない場合でも、現金や小切手など、教会が記録した献金は確認できます。サインインした状態で献金ページを開くと、「この教会ではオンライン献金がまだ設定されていません。記録された献金と明細書は以下のとおりです。」という注記が表示されます。年間合計、**最近のアクティビティ**、**すべての履歴**、**明細書を印刷**は、通常どおり利用できます。**献金する**ボタン、**前回と同じ献金**、**定期献金**および**支払い方法**のセクションは表示されません。ホームダッシュボードの**献金**セクションにも、合計と**履歴**リンクは表示されますが、**献金する**ボタンは表示されません。

## 明細書の書き出しと印刷

献金ページ上部の**明細書を印刷**をタップすると、現在の暦年（または教会が最後に公開した年）を対象とした印刷用の献金明細書が新しいタブで開きます。別の年を印刷するには、**すべての履歴**を開いて年を選び、合計の横にある**明細書を印刷**をタップします。

明細書はページ中央に配置され、教会のロゴ（教会がアップロードしている場合）、年、対象期間（1月1日から12月31日まで）、発行日が表示されます。その下には、あなたの氏名と連絡先が教会名・住所と並べて表示され、献金の合計額と基金ごとの合計額の概要、そしてすべての献金の日付、方法、基金、金額を示す表が続きます。末尾には、その年に教会があなたから受け取ったすべての献金が記載されていることを示す注記と、教会が登録済みの非営利団体であり、無形の宗教的恩恵を除いて献金と引き換えに商品やサービスを提供していない旨の簡単な免責事項が印刷されます。教会に献金に関する注記がある場合は、その後に印刷されます。

:::tip
昨年の献金がまだ履歴に残っているうちに、税務申告で必要になる前の新年早々に明細書を印刷しておくことをおすすめします。
:::

## 定期献金

定期的な献金がある場合、献金ページの**定期献金**セクションに、それぞれの金額、基金、間隔、支払い方法が一覧表示されます。**管理**をタップすると**定期献金と支払い方法**が開き、変更できます。

定期献金が**Stripe**経由で処理されている場合は、解約ではなく**一時停止**を選択できます。該当する献金の横にある一時停止アイコンをクリックし、確認してください。同じアイコンをクリックして**再開**するまで献金は停止されます。一時停止中の献金は、一覧で**一時停止中**と表示されます。その他の決済プロバイダーを通じた定期献金は、編集や解約は可能ですが、一時停止はできません。

保存済みの支払い方法を追加、削除、変更するには、**支払い方法**セクションの**管理**をタップします。
