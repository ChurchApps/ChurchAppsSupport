# 寄付をする

<div class="article-intro">

教会のB1.churchサイトから寄付する方法は2つあります。ログイン不要の公開寄付ページと、ログインが必要なメンバー用寄付ページです。どちらもStripeを利用した安全な寄付フォームを使用します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 公開寄付の場合、アカウントは不要です。教会の**寄付**ページにアクセスするだけで利用できます。
- 寄付履歴の確認や保存済みの支払い方法を使ったメンバー寄付をする場合は、まず[ログイン](../getting-started/logging-in.md)してください。

</div>

## 公開寄付ページ（ログイン不要）

アカウントを作成しなくても、誰でも寄付できます。

1. 教会の**寄付**ページに移動します。
2. ページの左側に寄付フォームが表示されます。寄付したい**基金**を選択します。
3. お支払い情報と寄付金額を入力します。
4. フォームを送信して寄付を完了します。

ページの右側には、銀行振込で寄付したい場合のための**ACH支払いの手順**へのリンクがあります。寄付履歴などの追加機能を利用したい場合は、**ログイン**ボタンからサインインできます。

:::tip
すでにログインした状態で公開寄付ページにアクセスすると、メンバー用の寄付ページに自動的に移動します。そこでは、寄付の全履歴や保存済みの支払い方法を確認できます。
:::

## メンバー寄付ページ（ログイン時）

ログインしている場合、メンバーポータルの**寄付**ページの上部には**寄付する**ボタンと**明細を印刷**ボタンが表示されます。その下に以下のセクションが並びます。

- **今年**（現在の年が表示されます）：年初からの寄付総額と寄付回数です。**すべての履歴**リンクがあります。詳しくは[寄付履歴](./donation-history.md)を参照してください。
- **定期**：定期的な寄付の設定です。**管理**リンクがあります。
- **最近のアクティビティ**：直近3件の寄付です。**前回の寄付を繰り返す**リンクから寄付フォームを開けます。
- **支払い方法**：保存済みのカードや銀行口座です。**管理**リンクから追加、削除、既定の設定ができます。
- 教会で有効なキャンペーンがある場合は、キャンペーンの進捗カードが表示されます。

寄付の手順は以下のとおりです。

1. 教会の**寄付**タブ、[ホームダッシュボード](../getting-started/navigating.md#home)の**寄付**セクションにある**寄付する**ボタン、または[マイページ](../getting-started/me-page.md)の**寄付**セクションにある**履歴**から寄付ページを開きます。寄付ページで**寄付する**をタップすると寄付フォームが開きます。
2. 寄付したい**基金**を選び、寄付金額を入力します。一覧に表示されるのは、教会が寄付者向けに提供している基金のみです。B1 Adminで他の基金を閲覧できるスタッフの場合でも、この点は同じです。
3. 保存済みの支払い方法を選ぶか、新しいお支払い情報を入力します。
4. フォームを送信して寄付を完了します。

寄付の処理が完了すると成功メッセージが表示され、寄付が[寄付履歴](./donation-history.md)に表示されます。

:::info
複数の通貨で寄付を行っている場合、年初からの合計と履歴の合計は教会の通貨に換算されます。その下には「**現在の為替レートで換算**」という注記が表示されます。履歴内の個々の寄付は、元の通貨のまま表示されます。
:::

## 支払い方法

寄付はStripeを通じて安全に処理されます。クレジットカード、デビットカードで支払うことができ、ACH銀行振込を設定することもできます。ログインしている場合は、支払い方法を今後の利用のために保存できるため、次回からの寄付がより簡単になります。

:::info ログインせずに銀行口座で寄付する場合
ゲストとしてログインせずに銀行口座で寄付する場合は、お使いの銀行にサインインして、口座をその場で確認する必要があります。確認できない場合は、「この銀行口座はその場で確認できませんでした。カードで寄付するか、サインインして寄付プロフィールから銀行口座を追加してください。」と表示されます。数日かかる確認が必要な銀行口座は、サインイン後にのみ追加できます。
:::

:::warning
寄付が完了しない場合は、お支払い情報を確認してから、もう一度お試しください。問題が解決しない場合は、教会の事務所にお問い合わせください。
:::
