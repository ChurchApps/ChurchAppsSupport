# 寄付をする

<div class="article-intro">

B1.church のサイトから寄付する方法は、2 つあります。ログイン不要の公開寄付ページと、ログインが必要な会員向け寄付ページです。どちらも Stripe を利用した安全な寄付フォームを使用します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 公開寄付の場合、アカウントは必要ありません。教会の **Donate** ページにアクセスするだけです。
- 寄付履歴の確認や支払い方法の保存を行う会員向け寄付をする場合は、まず [ログイン](../getting-started/logging-in.md) してください。

</div>

## 公開寄付ページ（ログイン不要）

アカウントを作成しなくても、どなたでも寄付できます。

1. 教会の **Donate** ページに移動します。
2. ページの左側に寄付フォームが表示されます。寄付したい **ファンド** を選択します。
3. 支払い情報と寄付金額を入力します。
4. フォームを送信して、寄付を完了します。

ページの右側には、銀行振込で寄付したい場合のための **ACH 支払いの手順** へのリンクがあります。寄付履歴などの追加機能を利用したい場合は、**Login** ボタンからサインインできます。

:::tip
公開寄付ページにアクセスしたときにすでにログインしている場合は、会員向け寄付ページに自動的に移動します。そこでは、これまでの寄付の全履歴や保存済みの支払い方法を確認できます。
:::

## 会員向け寄付ページ（ログイン時）

ログインすると、会員ポータルの **Giving** ページの上部に **Give** ボタンと **Print Statement** ボタンが表示され、その下に次のセクションが並びます。

- **This year**（現在の年が見出しになります）― 今年の寄付総額と寄付回数を表示し、**All history** リンクがあります。詳細は [寄付履歴](./donation-history.md) を参照してください。
- **Recurring** ― 定期的な寄付の一覧です。**Manage** リンクから管理できます。
- **Recent Activity** ― 直近 3 回の寄付を表示します。**Repeat last gift** リンクを押すと、寄付フォームが開きます。
- **Payment methods** ― 保存済みのカードや銀行口座を表示します。**Manage** リンクから追加、削除、既定の支払い方法の設定ができます。
- 教会で実施中のキャンペーンがある場合は、キャンペーンの進捗カードが表示されます。

寄付をするには、次の手順に従ってください。

1. 教会の **Donate** タブ、[ホームダッシュボード](../getting-started/navigating.md#home) の **Giving** セクションにある **Give** ボタン、または [Me ページ](../getting-started/me-page.md) の **Giving** セクションにある **History** から、献金ページを開きます。Giving ページで **Give** をタップすると、寄付フォームが開きます。
2. 寄付したい **ファンド** を選択し、寄付金額を入力します。
3. 保存済みの支払い方法を選ぶか、新しい支払い情報を入力します。
4. フォームを送信して、寄付を完了します。

寄付の処理が完了すると成功メッセージが表示され、寄付は [寄付履歴](./donation-history.md) に反映されます。

:::info
複数の通貨で寄付を記録している場合、今年の寄付総額と History の合計は、教会の通貨に換算して表示されます。その下には **Converted at current exchange rates**（現在の為替レートで換算）と表示されます。寄付履歴の個々の寄付は、元の通貨で表示されたままです。
:::

## 支払い方法

寄付は **Stripe** を通じて安全に処理されます。クレジットカード、デビットカードでお支払いいただけるほか、ACH による銀行振替を設定することもできます。ログインしている場合は、次回以降に便利なように支払い方法を保存できます。

:::info サインインせずに銀行口座で寄付する場合
ゲストとして（ログインせずに）銀行口座から寄付する場合、銀行にサインインして口座をその場で確認する必要があります。口座をその場で確認できない場合は、「この銀行口座はその場で確認できませんでした。カードで寄付するか、サインインして献金プロフィールに銀行口座を追加してください。」と表示されます。数日かけて確認が必要な銀行口座は、サインインした後にのみ追加できます。
:::

:::warning
寄付が完了しない場合は、支払い情報を確認してから、もう一度お試しください。問題が解決しない場合は、教会の事務所にお問い合わせください。
:::
