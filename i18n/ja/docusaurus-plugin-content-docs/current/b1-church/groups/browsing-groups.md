# グループを探す

<div class="article-intro">

教会の公開グループページでは、興味のあるグループを簡単に見つけられます。グループはカテゴリごとに整理されているため、さまざまな種類のグループをすばやく確認し、自分に合うグループを見つけることができます。

</div>

## グループページを開く

教会の B1.church サイトで **グループ** ページに移動します。このページは一般公開されているため、閲覧するのにログインする必要はありません。

## グループの分類

グループは **カテゴリ**（ラベルとも呼ばれます）ごとに表示されます。カテゴリは教会の管理者が設定し、「小グループ」「奉仕部門」「若者」「聖書研究」などのラベルが含まれることがあります。各カテゴリには、そのカテゴリに属するすべてのグループが表示されます。

## グループカードの見方

各グループは、以下の情報を含むカードとして表示されます。

- **グループの写真** -- グループを代表するカバー画像です。写真が設定されていない場合は、既定の画像が表示されます。
- **グループ名** -- 写真の上に目立つように表示されます。
- **集会の時間** -- グループが通常集まる時間です（例：「水曜日の午後7時」）。時間が設定されていない場合は、プレースホルダーが表示されます。
- **集会の場所** -- グループが集まる場所です。場所が設定されていない場合は、プレースホルダーが表示されます。
- **説明** -- グループの内容を簡単に紹介するもので、数行に省略されています。全文を読むには、グループをクリックしてください。

## グループの詳細を見る

気になるグループのカードをクリックすると、グループの詳細ページが開きます。そこでは、説明の全文、リーダーに関する情報、今後のカレンダーイベント、そしてグループへの連絡方法を確認できます。

:::tip
特定の種類のグループを探している場合は、まずカテゴリの見出しを確認してください。すべてのグループを順番にスクロールするのではなく、興味のあるセクションにすぐに移動できます。
:::
