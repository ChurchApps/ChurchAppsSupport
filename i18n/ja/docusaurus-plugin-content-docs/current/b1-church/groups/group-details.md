# グループの詳細

<div class="article-intro">

グループページからグループをクリックすると、グループの詳細ページに移動します。表示される内容は、ログインしているかどうかによって異なります。ログインしているメンバーには、追加のセクションや機能が表示されます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [グループを探す](./browsing-groups.md)で、表示したいグループを見つけます。
- すべてのセクションを利用するには、アカウントに[ログイン](../getting-started/logging-in.md)してください。

</div>

## 訪問者の表示（ログインしていない場合）

ログインしていない場合は、次の内容が表示されます。

- **ヘッダー** -- グループ名と、その集まりの時間および場所です。パソコンでは、グループの写真がその上に表示されます。
- **参加するにはサインイン** -- グループ名の下にあるボタンです。サインイン（またはアカウント作成）すると、グループに参加したり、参加をリクエストしたりできます。サインイン後は、グループページに戻り、参加の手順にすぐ進みます。
- **概要** -- グループの目的や参加時に知っておくとよいことを説明する、グループの詳しい説明です。
- **リーダー** -- グループのリーダーの名前です。リーダーの名前をタップすると、そのプロフィールを表示できます。
- **今後のイベント** -- グループの今後のイベントを最大3件表示します。日付、時刻、イベント名が表示され、登録を受け付けているイベントには**登録**リンクが表示されます。今後のイベントがない場合、このセクションは表示されません。

## メンバーの表示（ログインしている場合）

ログインしていても、グループのメンバーでない場合は、グループのヘッダーと**概要**セクション、およびグループへの参加オプションが表示されます（下記の[グループへの参加](#joining-a-group)を参照）。次に説明するセクションは、メンバーになると表示されます。

メンバーになると、グループのヘッダーにグループ名、ミーティングの曜日・時刻・場所が表示されます。教会がグループチャットを有効にしている場合は、**チャットを開く**ボタンも表示されます。グループのリーダーであれば、名前の下に**あなた · リーダー**のタグが表示されます。パソコンでは、ヘッダーは左側の列に表示され、グループの写真とともに、各セクションがその右側に並びます。

このページは、セクションが一枚に並んだ構成です。各セクションには短いプレビューが表示されます。セクションの見出しにあるリンクをタップすると、全体を表示できます。元の画面に戻るには、「*グループ名*へ戻る」をタップします。利用可能なセクションは次のとおりです。

- **次のイベント** -- グループの次の今後のイベントです。**参加** / **未定** / **不参加** ボタンがあります（[イベントへの出欠回答](./event-rsvps.md)を参照）。**すべてのイベント**をタップすると、グループのカレンダーを開けます。矢印で月を移動でき、**カレンダー**（日をタップするとその日のイベントを表示する月表示）と**リスト**（その月のイベントを日付順に、日ごとにまとめて表示）を切り替えられます。今月を表示している場合、リストは今日から始まるため、これから行われるイベントだけが表示されます。グループのイベントにタグが付いている場合は、タグで絞り込めます。
- **今週のレッスン** -- グループがLessons.churchのプランタイプに関連付けられていて、今週のレッスンに保護者向けの持ち帰り用コンテンツがある場合、**次のイベント**の下に表示されます（メンバーのみ）。
- **ミーティング** -- グループの最近のミーティングを、新しいものから順に表示します。各ミーティングには、日付、出席者数（例：「12人中8人が出席」）、または未来の日付の場合は**今後**、そのミーティングのリーダーのメモが表示されます。メモ内の太字、リスト、リンクはそのまま表示されます。**すべてのミーティング**をタップすると、すべて表示されます。ミーティングは、メモまたは出欠記録がある場合にのみ表示されます。詳しくは下記の[ミーティングのメモと出欠](#meeting-notes-and-attendance)を参照してください。
- **リーダーメモ** -- グループのリーダーだけに表示されます。新しい2件のリーダーメモを表示します。**メモを開く**をタップすると、すべてのメモを読んだり、新しいメモを投稿したりできます。詳しくは下記の[リーダーメモ](#leader-notes)を参照してください。
- **フォーム** -- 教会がグループにリンクしたフォームを、一度に最大3件表示します。メンバーには、受付中のフォームが表示され、それぞれに**記入する**ボタンがあります。リーダーには、終了したフォーム（**終了**と表示）、各フォームの回答数、グループのイベントの登録フォーム（**イベント登録**と表示）も表示されます。**すべてのフォーム**をタップすると、すべて表示されます。グループにリンクされたフォームがある場合のみ表示されます。詳しくは下記の[リンクされたフォーム](#linked-forms)を参照してください。
- **メッセージ** -- グループチャットの最新のメッセージです。**チャットを開く**をタップすると、読んだり投稿したりできます。メンバーのみに表示され、教会がこのグループのグループチャットを有効にしている場合にのみ表示されます。詳しくは[グループの会話](./conversations.md)を参照してください。
- **メンバー** -- グループのメンバー（リーダーが先頭）のプレビューと、メンバーとリーダーの人数です。**すべてのメンバー**をタップすると全員の一覧が表示され、**メンバーを検索**で検索できます。メンバーの名前をタップすると、[メンバーディレクトリ](../community/member-directory.md)内のそのプロフィールを表示できます。
- **リソース** -- グループに投稿された共有ファイルとリンクの最初の数件です。**すべてのリソース**をタップすると、すべて表示されます。アップロードされたファイルはダウンロードでき、リンクされたリソースは開くことができます。
- **プラン** -- グループの次の礼拝プランです。**すべてのプラン**をタップすると、すべて表示されます。グループにプランがある場合のみ表示されます。
- **概要** -- グループの詳しい説明を、リッチテキストの書式で表示します。説明がある場合のみ表示されます。

メンバーには、ページの下部に**グループを退会**リンクも表示されます。

## リーダーの機能

グループのリーダーには、次の追加の編集機能があります。

- **イベントの作成と編集** -- **すべてのイベント**をタップし、**イベントを追加**をタップすると、グループのカレンダーにイベントを追加できます。イベントを作成するときに、部屋やリソースを同時に予約できます。利用可能な部屋とリソースを選択し、必要に応じて準備時間と片付け時間を設定すると、予約リクエストが自動的に承認のために送信されます。
- **繰り返しイベントの編集** -- 繰り返しイベントを開いて編集すると、B1 はまず、どの日付を変更するかを尋ねます。**この日のみ**、**この日以降すべて**、または**すべての日付**から選択し、**保存**をクリックしてイベントを開きます。**この日のみ**を選んだ場合、**繰り返し**スイッチは非表示になり、変更（または削除）はその1日分にのみ適用されます。
- **イベントの削除** -- イベントの横にある鉛筆アイコンをタップし、**イベントを削除**をタップして確認します。繰り返しイベントの場合、削除は開いたときに選択した日付の範囲に従います。つまり、この日のみ、この日以降すべて、またはシリーズ全体です。削除された日付は、グループカレンダーやメンバーの今後のイベントには表示されなくなります。
- **イベントのリマインダーの設定** -- 既存のイベントを編集するときに**リマインダーを送信**をオンにすると、開始前に参加者へリマインダーを送信します。送信するタイミング、**時刻**、**誰にリマインドしますか？**、任意の**メッセージ**を指定し、**送信方法**で**プッシュ**、**メール**、または教会がテキストメッセージを設定している場合は**テキスト**を選択します。テキストメッセージは、[通知設定](../getting-started/notification-preferences.md)でテキストリマインダーをオンにした人にのみ送信されます。
- **リソースの管理** -- ファイルのアップロード（最大100 MBのストレージ）、リンクの追加、既存のリソースの削除ができます。
- **ミーティングのメモの作成と出欠の記録** -- **ミーティング**セクションで**メモを追加**と**出欠を取る**を使用します。詳しくは[ミーティングのメモと出欠](#meeting-notes-and-attendance)を参照してください。
- **プライベートなリーダーメモの管理** -- **リーダーメモ**セクションを使用します。詳しくは[リーダーメモ](#leader-notes)を参照してください。
- **フォームの回答の閲覧と印刷** -- **フォーム**セクションを使用します。詳しくは[リンクされたフォーム](#linked-forms)を参照してください。

グループの名前、説明、メンバーリストを変更するには、B1 Admin を使用します。[グループメンバー](../../b1-admin/groups/group-members.md)を参照してください。

### ミーティングのメモと出欠 {#meeting-notes-and-attendance}

グループのリーダー、および出欠を取ることができるスタッフには、**ミーティング**セクションのヘッダーに**メモを追加**と**出欠を取る**が表示されます。メンバーには、同じミーティングの一覧とメモが表示されるため、欠席した週があっても内容を確認できます。

ミーティングの振り返りを書くには:

1. **メモを追加**をタップします。
2. ミーティングの**日付**を選択します。初期値は、過去1週間の最新のミーティング、または今日です。ミーティングの前にメモを投稿するため、未来の日付を選択することもできます。
3. **メモ**欄にメモを入力します（例：扱った内容、お知らせ、祈りの課題）。ツールバーで太字、リスト、リンクを追加できます。
4. **保存**をタップします。

その日付にすでにメモがある場合は、そのメモが開き、編集できます。**出欠を取る**画面には、日付の下に同じ**メモ**欄があるため、出欠を取りながら振り返りを書くことができます。リーダーは、一覧のミーティングをタップして、その出欠とメモを開くこともできます。ミーティングのメモは、B1 Admin のグループの**セッション**でスタッフが見るセッションメモと同じです。[出欠の記録](../../b1-admin/attendance/recording-attendance.md#session-notes)を参照してください。

### リーダーメモ {#leader-notes}

**リーダーメモ**は、グループのリーダーだけが利用できるプライベートなフィードです。たとえば、フォローアップや牧会上の懸念事項を記録するために使用します。このフィードを見たり投稿したりできるのは、グループのリーダーだけです。他のメンバーは見ることができず、グループのリーダーでない限り、教会のスタッフも見ることはできません。

1. **リーダーメモ**セクションで、**メモを開く**（または任意のメモ）をタップします。
2. 下部の欄にメモを入力し、送信します。

誰かが投稿するまでは、フィードには「まだメモはありません」と表示され、「このグループのリーダーだけがこれらのメモを見ることができます。」という注意書きが表示されます。リーダーは、B1 Admin のグループページで同じメモを確認できます。[グループメンバー](../../b1-admin/groups/group-members.md#leader-notes)を参照してください。

### リンクされたフォーム {#linked-forms}

教会のスタッフは、B1 Admin でフォームをグループにリンクできます。たとえば、祈りの依頼カードや旅行の同意書などです（[グループへのフォームのリンク](../../b1-admin/forms/creating-forms.md#linking-a-form-to-a-group)を参照）。リンクされたフォームは、グループの**フォーム**セクションに表示されます。メンバーは**記入する**をタップしてフォームを開き、送信します。

リーダーは回答を読んだり印刷したりすることもできます。

1. **フォーム**セクションでフォームをタップします（または**すべてのフォーム**をタップして選択します）。グループのイベントの登録で、登録時の質問がある場合は、その登録もここに一覧表示されます。
2. 一覧には、回答した各人と送信日が表示されます。サインインしていない人の回答は**匿名**と表示されます。
3. 人をタップすると、その人の回答が表示されます。各質問は、その回答の上に表示されます。
4. その人の回答を印刷するには**印刷**をタップします。フォームのすべての回答を印刷するには、一覧の上にある**すべて印刷**をタップします。

印刷物の上部中央には、教会のロゴ（B1 Admin で**明るい背景用ロゴ**をアップロードしている場合）と教会名が表示され、その下にフォーム名、続いて各人の回答が名前と送信日を見出しとして表示されます。リーダーは回答を読むことはできますが、変更したりフォームを編集したりすることはできません。一覧に戻るには**すべてのフォーム**をタップします。

## グループへの参加

ログインしていて、まだメンバーでない場合は、グループの詳細ページに参加ボタンが表示されます。ボタンのラベルは、グループの参加ポリシーによって異なります。

- **グループに参加** -- グループは公開されています。クリックすると、すぐにメンバーとして追加されます。
- **参加をリクエスト** -- グループは承認が必要です。クリックすると、ダイアログが開き、グループのリーダーへの任意のメッセージを含めて、リクエストを送信できます。リクエストの管理については、[グループへの参加リクエスト](./join-requests.md)を参照してください。

リクエストを送信すると、ボタンは**リクエスト保留中**の表示に置き換わります：「参加リクエストを送信しました。グループのリーダーが確認します。」

ログインしていない状態で**参加するにはサインイン**をクリックした場合は、サインイン後にグループに戻り、参加の手順が自動的に始まります。公開グループの場合はすぐに追加され、承認が必要なグループの場合は**参加をリクエスト**ダイアログが開きます。

どちらのボタンも表示されない場合、そのグループは締め切られており、リーダーまたは管理者が手動でメンバーを追加する必要があります。

:::info
グループに参加する、または参加をリクエストするには、サインインしている必要があります。グループが締め切られていて参加したい場合は、教会の事務所またはグループのリーダーにお問い合わせください。
:::
