# グループの詳細

<div class="article-intro">

グループページからグループをクリックすると、グループの詳細ページが表示されます。表示される内容は、ログインしているかどうかによって異なります。ログイン済みのメンバーには、追加のセクションや機能が表示されます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [グループを探す](./browsing-groups.md)ことで、表示するグループを見つけられます。
- すべてのセクションを利用するには、アカウントに[ログイン](../getting-started/logging-in.md)してください。

</div>

## 訪問者の表示（未ログイン時）

ログインしていない場合、次の内容が表示されます。

- **ヘッダー** -- グループ名と、ミーティングの日時および場所です。パソコンでは、グループの写真がヘッダーの上に表示されます。
- **参加するにはサインイン** -- グループ名の下にあるボタンです。サインイン（またはアカウントを作成）すると、グループに参加したり、参加申請したりできます。サインイン後は、グループページに戻り、参加の手順にそのまま進みます。
- **概要** -- グループの目的や活動内容を説明する、グループの詳しい説明です。
- **リーダー** -- グループのリーダーの名前です。リーダーの名前をタップすると、そのプロフィールを表示できます。
- **今後のイベント** -- グループの今後のイベントを最大3件表示します。各イベントには日付、時間、イベント名が表示され、登録を受け付けているイベントには**登録**リンクが表示されます。今後のイベントがない場合、このセクションは表示されません。

## メンバーの表示（ログイン時）

ログインしているものの、グループのメンバーではない場合は、グループのヘッダーと**概要**セクションが表示されます。あわせて、グループへの参加オプションも表示されます（下記の[グループへの参加](#joining-a-group)を参照してください）。次に説明するセクションは、メンバーになった後に表示されます。

メンバーになると、グループのヘッダーには、グループ名、ミーティングの曜日、時間、場所が表示されます。教会でグループチャットを有効にしている場合は、**チャットを開く**ボタンも表示されます。グループのリーダーである場合は、名前の下に**あなた・リーダー**のタグが表示されます。パソコンでは、ヘッダーは左側の列に配置され、グループの写真が表示されます。各セクションはその右側に並びます。

このページは、複数のセクションが縦に並んだ一枚のページです。各セクションには簡単なプレビューが表示されます。セクションの見出しにあるリンクをタップすると、全体の表示に移動します。元に戻るには、**「グループ名」に戻る**をタップします。利用できるセクションは次のとおりです。

- **次のイベント** -- グループの次の予定イベントです。**参加**、**たぶん**、**不参加**のボタンがあります（[イベントへの出欠回答](./event-rsvps.md)を参照してください）。登録が必要なイベントには**登録**リンクが表示されます。登録が完了すると、このカードとイベントの全件一覧の両方で、その時点の状態（**登録済み**、**保留中**、**キャンセル待ち**のいずれか）が表示されます。その表示をタップすると、[自分の登録内容](../events/my-registrations.md)が開きます。**すべてのイベント**をタップすると、グループのカレンダーが開きます。矢印で月を切り替えられます。表示方法は**カレンダー**（日付をタップすると、その日のイベントが表示される月表示）と**リスト**（その月のイベントを日付順に、日ごとにまとめて表示）から選べます。現在の月を表示している場合、リストは今日から始まるため、これから行われるイベントだけが表示されます。グループのイベントにタグが付いている場合は、タグで絞り込めます。
- **今週のレッスン** -- グループが Lessons.church のプラン種別に関連付けられていて、今週のレッスンに保護者向けの持ち帰り資料がある場合、**次のイベント**の下に表示されます（メンバーのみ）。
- **ミーティング** -- グループの最近のミーティングを、新しいものから順に表示します。各ミーティングには、日付、出席人数（例：「12人中8人出席」）、未来の日付の場合は**予定**が表示されます。さらに、そのミーティングに対するリーダーのメモも表示されます。太字、リスト、リンクはそのまま残ります。**すべてのミーティング**をタップすると、すべて表示されます。ミーティングは、メモまたは出席記録が登録されると表示されるようになります。下記の[ミーティングのメモと出席記録](#meeting-notes-and-attendance)を参照してください。
- **リーダーメモ** -- グループのリーダーだけに表示されます。最新の2件のリーダーメモを表示します。**メモを開く**をタップすると、すべてのメモを読んだり、新しいメモを投稿したりできます。下記の[リーダーメモ](#leader-notes)を参照してください。
- **フォーム** -- 教会がグループに関連付けたフォームを、一度に最大3件まで表示します。メンバーには、受付中のフォームが表示されます。各フォームには**記入する**ボタンがあります。リーダーには、締め切られたフォーム（**締め切り**と表示）、各フォームの回答数、グループのイベントの登録フォーム（**イベント登録**と表示）も表示されます。**すべてのフォーム**をタップすると、すべて表示されます。グループにフォームが関連付けられている場合にのみ表示されます。下記の[関連フォーム](#linked-forms)を参照してください。
- **メッセージ** -- グループチャットの最新メッセージです。**チャットを開く**をタップすると、読んだり投稿したりできます。メンバーにのみ表示され、教会がこのグループでグループチャットを有効にしている場合に限り表示されます。詳しくは[グループの会話](./conversations.md)を参照してください。
- **メンバー** -- グループのメンバーのプレビューです（リーダーが先頭に表示されます）。メンバーとリーダーの人数も表示されます。**すべてのメンバー**をタップすると全員の一覧が表示され、**メンバーを検索**で検索できます。メンバーの名前をタップすると、[メンバーディレクトリ](../community/member-directory.md)でそのプロフィールを表示できます。
- **リソース** -- グループに投稿された共有ファイルとリンクのうち、最初の数件を表示します。**すべてのリソース**をタップすると、すべて表示されます。アップロードされたファイルはダウンロードでき、リンクされたリソースは開けます。
- **プラン** -- グループの次の礼拝プランです。**すべてのプラン**をタップすると、すべて表示されます。グループにプランがある場合にのみ表示されます。
- **概要** -- グループの詳しい説明を、リッチテキストの書式付きで表示します。説明が登録されている場合にのみ表示されます。

メンバーには、ページの下部に**グループを退会**リンクも表示されます。

## リーダーの権限

グループのリーダーである場合、次の追加の編集機能を利用できます。

- **イベントの作成と編集** -- **すべてのイベント**をタップし、次に**イベントを追加**をタップすると、グループのカレンダーにイベントを追加できます。イベントを作成する際には、部屋や設備を同時に予約できます。利用可能な部屋や設備を選択し、必要に応じて準備と片付けの時間を設定すると、予約リクエストが自動的に承認依頼として送信されます。
- **繰り返しイベントの編集** -- 繰り返しイベントを開いて編集すると、B1 はまず、変更対象の日付を尋ねます。**この日のみ**、**この日以降すべて**、**すべての日付**のいずれかを選び、**保存**をクリックしてイベントを開きます。**この日のみ**を選んだ場合、**繰り返し**のスイッチは表示されず、変更内容（または削除）はその1日分にのみ適用されます。
- **イベントの削除** -- イベントの横にある鉛筆アイコンをタップし、次に**イベントを削除**をタップして確定します。繰り返しイベントの場合、削除はイベントを開いたときに選んだ日付の範囲に従います。つまり、**この日のみ**、**この日以降すべて**、またはシリーズ全体のいずれかです。削除された日付は、グループのカレンダーやメンバーの今後のイベントに表示されなくなります。
- **イベントのリマインダーの設定** -- 既存のイベントを編集するときに**リマインダーを送信**をオンにすると、開始前に参加者へ通知できます。送信するタイミング、**時刻**、**誰に通知しますか？**、任意の**メッセージ**を設定します。次に、**送信方法**で**プッシュ**、**メール**、または教会でテキストメッセージを設定している場合は**テキスト**を選びます。テキストメッセージは、[通知設定](../getting-started/notification-preferences.md)でテキストリマインダーをオンにしている人にのみ送信されます。
- **リソースの管理** -- ファイルのアップロード（最大100 MBまで）、リンクの追加、既存のリソースの削除ができます。
- **ミーティングのメモの作成と出席の記録** -- **ミーティング**セクションの**メモを追加**と**出席を記録**を使用します。[ミーティングのメモと出席記録](#meeting-notes-and-attendance)を参照してください。
- **リーダーの非公開メモの管理** -- **リーダーメモ**セクションを使用します。[リーダーメモ](#leader-notes)を参照してください。
- **フォームの回答の閲覧と印刷** -- **フォーム**セクションを使用します。[関連フォーム](#linked-forms)を参照してください。

グループの名前、説明、メンバー一覧を変更するには、B1 Admin を使用してください。[グループメンバー](../../b1-admin/groups/group-members.md)を参照してください。

### ミーティングのメモと出席記録 {#meeting-notes-and-attendance}

グループのリーダーと、出席を記録できるスタッフには、**ミーティング**セクションの見出しに**メモを追加**と**出席を記録**が表示されます。メンバーにも同じミーティング一覧とメモが表示されるため、欠席した週があっても内容を確認できます。

ミーティングの内容をまとめるには、次の手順に従います。

1. **メモを追加**をタップします。
2. ミーティングの**日付**を選びます。初期値は、過去1週間で最も新しいミーティングの日付、または今日です。ミーティングの前に投稿するために、未来の日付を選ぶこともできます。
3. **メモ**欄にメモを書きます。たとえば、扱った内容、お知らせ、祈りの要望などです。ツールバーで太字、リスト、リンクを追加できます。
4. **保存**をタップします。

その日付にすでにメモがある場合は、そのメモが開き、編集できます。**出席を記録**の画面にも、日付の下に同じ**メモ**欄があるため、出席を記録しながら内容をまとめられます。リーダーは、一覧のミーティングをタップして、出席とメモを開くこともできます。ミーティングのメモは、B1 Admin のグループの**セッション**で、スタッフが見るセッションメモと同じものです。詳しくは[出席の記録](../../b1-admin/attendance/recording-attendance.md#session-notes)を参照してください。

### リーダーメモ {#leader-notes}

**リーダーメモ**は、グループのリーダーだけが見られる非公開のフィードです。たとえば、フォローアップや牧会的な配慮事項を記録するために使用します。閲覧や投稿ができるのは、グループのリーダーだけです。他のメンバーには表示されず、グループのリーダーでない教会スタッフにも表示されません。

1. **リーダーメモ**セクションで、**メモを開く**をタップします（または任意のメモをタップします）。
2. 下部の入力欄にメモを入力し、送信します。文字を選択すると、太字や斜体にしたり、リストに変換したりできます。詳しくは[メッセージの書式設定](./conversations.md#formatting-your-message)を参照してください。

誰も投稿していない場合、フィードには「メモはまだありません」と表示され、「このグループのリーダーだけがこのメモを見られます。」という注意書きが添えられます。リーダーは、B1 Admin のグループページでも同じメモを確認できます。[グループメンバー](../../b1-admin/groups/group-members.md#leader-notes)を参照してください。

### 関連フォーム {#linked-forms}

教会のスタッフは、B1 Admin でフォームをグループに関連付けることができます。たとえば、祈りの要望カードや旅行の同意書などです（[フォームをグループに関連付ける](../../b1-admin/forms/creating-forms.md#linking-a-form-to-a-group)を参照してください）。関連付けられたフォームは、グループの**フォーム**セクションに表示されます。メンバーは**記入する**をタップしてフォームを開き、送信できます。

リーダーは、回答を閲覧したり印刷したりすることもできます。

1. **フォーム**セクションでフォームをタップします（または**すべてのフォーム**をタップして選びます）。グループのイベントの登録のうち、登録時の質問があるものも、ここに一覧表示されます。
2. 一覧には、回答した各人と提出日が表示されます。サインインしていない人の回答は**匿名**と表示されます。
3. 人をタップすると、その人の回答が表示されます。各質問は、その回答の上に表示されます。
4. その人の回答を印刷するには**印刷**をタップします。フォームのすべての回答を印刷するには、一覧の上にある**すべて印刷**をタップします。

印刷物の上部中央には、教会のロゴ（B1 Admin で設定した**明るい背景用ロゴ**がある場合はそのロゴ）と教会名が表示されます。その下にフォーム名、さらに各人の回答が続きます。見出しには、回答者の名前と提出日が付きます。リーダーは回答を閲覧できますが、変更したりフォームを編集したりすることはできません。一覧に戻るには**すべてのフォーム**をタップします。

## グループへの参加

ログインしていて、まだメンバーではない場合、グループの詳細ページに参加ボタンが表示されます。ボタンの表示は、グループの参加ポリシーによって異なります。

- **グループに参加** -- グループは公開されています。クリックすると、すぐにメンバーとして追加されます。
- **参加を申請** -- グループでは承認が必要です。クリックすると、グループのリーダー宛てに任意のメッセージを添えられるダイアログが開きます。その後、申請を送信します。申請の管理方法について詳しくは、[グループへの参加申請](./join-requests.md)を参照してください。

参加を申請すると、ボタンは**申請を保留中**の表示に置き換わります。「参加申請を送信しました。グループのリーダーが確認します。」と表示されます。

ログインしていない状態で**参加するにはサインイン**をクリックした場合は、サインイン後にグループページに戻り、参加の手順が自動的に始まります。公開グループの場合はすぐに追加されます。承認が必要なグループの場合は、**参加を申請**のダイアログが開きます。

どちらのボタンも表示されない場合、そのグループは締め切られており、メンバーはリーダーまたは管理者が手動で追加する必要があります。

:::info
グループに参加する、または参加を申請するには、サインインしている必要があります。グループが締め切られていて参加したい場合は、教会の事務所またはグループのリーダーにお問い合わせください。
:::
