# グループへの参加リクエスト

<div class="article-intro">

グループによっては、メンバーになる前に承認が必要な場合があります。そのようなグループでは、参加リクエストを送信します（グループリーダーへのメッセージを添えることもできます）。その後、リーダーが承認するか却下するまで待ちます。保留中のリクエストの状態はいつでも確認でき、取り消すこともできます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- グループに参加リクエストを送るには、B1.church アカウントに[ログイン](../getting-started/logging-in.md)している必要があります。

</div>

## 参加とリクエストの違い

グループは、管理者によって異なる参加ポリシーを設定できます。

- **オープン** -- グループの詳細ページで **Join Group** をクリックすると、すぐにメンバーとして追加されます。
- **リクエストが必要** -- **Request to Join** をクリックしてリクエストを送信します。メンバーになるには、グループリーダーの承認が必要です。
- **クローズド** -- 参加ボタンは表示されません。メンバーはリーダーが手動で追加します。

## 参加リクエストの送信方法

1. 参加したいグループを探します。見つけ方がわからない場合は、[グループを探す](./browsing-groups.md)を参照してください。
2. グループの詳細ページを開きます。
3. **Request to Join** をクリックします。
4. ダイアログが表示されます。任意で、参加を希望する理由などをグループリーダー宛てのメッセージとして書けます。
5. **Submit** をクリックして、リクエストを送信します。

グループのページには、ボタンの代わりに **Request Pending** の表示が出ます。グループのリーダーには、あなたのリクエストについて通知が届きます。リーダーが確認すると、結果の通知が届きます。

:::tip
簡単なメッセージ（グループをどこで知ったか、参加して何を得たいか など）を添えると、リーダーが素早く判断しやすくなります。
:::

## リクエストの状態を確認する

リクエストを送信した後は、**Groups** ページから状態を確認できます。

1. 教会の B1.church サイトで **Groups** ページに移動します。
2. **Pending Requests** のセクションまでスクロールします。
3. 保留中の各リクエストには、グループ名と送信日が表示されます。

リクエストが承認または却下されると、通知が届きます。承認されたリクエストは、そのグループのメンバーとして登録されます。

## リクエストを取り消す

リーダーが確認する前に気が変わった場合は、次の手順で取り消せます。

1. **Groups** ページに移動します。
2. **Pending Requests** のセクションで、該当するリクエストを探します。
3. リクエストの横にある **Cancel** をクリックします。

リクエストはすぐに取り下げられ、リーダーには表示されなくなります。
