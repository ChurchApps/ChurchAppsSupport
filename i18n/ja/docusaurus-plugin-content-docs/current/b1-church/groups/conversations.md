# グループの会話

<div class="article-intro">

グループチャットは、グループのメンバーがメッセージを投稿し、互いにやり取りするための場所です。会議と会議の間も、会話を使ってトピックについて話し合ったり、近況を共有したり、グループとのつながりを保ったりできます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1.churchのアカウントに[ログイン](../getting-started/logging-in.md)している必要があります。
- グループチャットを利用するには、そのグループのメンバーである必要があります。グループへの参加方法は[グループの詳細](./group-details.md)を参照してください。

</div>

## 会話へのアクセス

1. [グループ一覧ページ](./browsing-groups.md)でグループをクリックして、グループの詳細ページに移動します。
2. ログインしていることを確認します。
3. グループ名の下にある **チャットを開く**、または最新のメッセージをプレビューする **メッセージ** セクションをタップします。チャットが全画面で開きます。グループに戻るには、戻る矢印をタップします。

## ディスカッションとお知らせ

グループチャットには、教会がこのグループで有効にしている設定によって、2種類のフィードが表示されることがあります。チャットの上部、グループ名の上にあるラベルで、現在どちらのフィードを表示しているかがわかります。

- **チャット** -- ディスカッションです。グループのメンバーは誰でもメッセージを投稿し、他のメンバーに返信できます。
- **お知らせ** -- グループのリーダーが投稿する、すべてのメンバーに見てほしい重要なメッセージです。一般のメンバーはお知らせを読んでリアクションできますが、投稿できるのはリーダーだけです。一般のメンバーには、メッセージ入力欄の代わりに「グループリーダーのみがお知らせを投稿できます。」と表示されます。

両方のフィードが有効な場合、チャットの上部にある **お知らせ** の帯に最新のお知らせが表示されます。**すべてのお知らせ** をタップするとお知らせのフィードが開き、**チャットに戻る** をタップするとディスカッションに戻ります。(メンバーに帯が表示されるのは、グループにお知らせが1件以上ある場合だけです。)

教会がこのグループで片方のフィードだけを有効にしている場合は、チャットを開くとそのフィードが直接表示されます。両方とも無効な場合、グループにはチャットがなく、**メッセージ** セクションも表示されません。

## メッセージの投稿

1. グループのページで **チャットを開く** をタップします。
2. **チャット** フィードを表示していることを確認します。お知らせを読んでいる場合は、**チャットに戻る** をタップします。
3. **メッセージを入力…** の入力欄にメッセージを入力します。
4. 送信ボタンをタップすると、グループに共有されます。スマートフォンやタブレットでは、Returnキーで改行します。パソコンでは、**Enter** で送信し、**Shift+Enter** で改行します。

投稿したメッセージは、グループのすべてのメンバーに表示されます。各メッセージには送信日時が表示されます。今日のメッセージは時刻、昨日のメッセージは「昨日」と時刻、それより前のメッセージは日付と時刻で表示されます。

## メッセージの書式設定 {#formatting-your-message}

メッセージには太字、斜体、リストを追加できます。

1. メッセージを入力し、書式を設定したい単語や行を選択します。
2. メッセージ入力欄の上に小さなツールバーが表示され、**太字**、**斜体**、**箇条書き**、**番号付きリスト** のボタンがあります。ボタンをタップして適用します。テキストを選択したまま同じボタンをもう一度タップすると、書式が解除されます。
3. 通常どおりメッセージを送信します。

パソコンでは、**Ctrl+B**(Macでは **Cmd+B**)で太字、**Ctrl+I**(**Cmd+I**)で斜体にすることもできます。

ツールバーは、テキストに簡単なMarkdownを追加します。`**太字**`、`_斜体_`、行頭の `- ` は箇条書き、`1. ` は番号付きリストになります。これらを直接入力することもできます。チャットのすべてのメンバーには書式が適用されたメッセージが表示され、Webリンクはクリックできたままで、改行も保持されます。同じ書式は、お知らせ、[リーダーのメモ](./group-details.md#leader-notes)、プライベートメッセージでも使えます。

## 自分のメッセージの編集と削除

投稿したメッセージは、編集または削除できます。

1. メッセージの下にある **その他のオプション** ボタン(⋮)をタップして、メッセージメニューを開きます。
2. **編集** を選ぶとメッセージ本文を変更でき、**削除** を選ぶとメッセージを削除できます。
   - 編集時は、メッセージ本文が入力欄に読み込まれ、上に「**メッセージを編集中**」と表示されます(編集をやめるには **キャンセル** をタップします)。変更して送信すると保存されます。
   - 削除時は、「**メッセージを削除しますか？**」という確認が表示されます。**削除** をタップすると、会話のすべてのメンバーからメッセージが完全に削除されます。

:::info
編集できるのは自分のメッセージだけです。グループのリーダーは、他のメンバーのメッセージも削除できます。一般のメンバーには、自分のメッセージに対するオプションだけが表示されます。
:::

## メッセージへのリアクション

グループチャットでは、どのメッセージにも絵文字でリアクションできます。

1. メッセージの下にある **リアクションを追加** ボタンをタップします。
2. 6種類の絵文字から1つ選びます: 👍 ❤️ 😂 🎉 🙏 😮

リアクションは、メッセージの下に小さなチップとして表示され、それぞれの絵文字を使った人数が表示されます。自分のリアクションは強調表示されます。チップをタップする(または同じ絵文字をもう一度選ぶ)と取り消され、別の絵文字を選ぶと追加されます。リアクションは、チャットのすべてのメンバーにリアルタイムで表示されます。

:::tip
グループの会話は、各グループのチャットで行われます。以前すべてをまとめて表示していた[タイムライン](../community/timeline.md)フィードは廃止されました。対応が必要な通知は、アプリバーの **ベル** アイコンから確認できます。
:::

## リーダー向けの機能

グループのリーダーには、グループチャットでの追加機能があります。

- **お知らせの投稿** -- **すべてのお知らせ** をタップします(お知らせだけが有効な場合は、チャットを開きます)。そして、すべてのグループメンバーが読めるメッセージを投稿します。
- **メッセージの削除** -- メッセージメニュー(⋮)から、どのメンバーのメッセージでも削除できます。
- **ディスカッションへの投稿** -- 他のメンバーと同じように、通常のディスカッションに参加することもできます。

:::info
会話は、グループごとに分かれています。あるグループに投稿したメッセージは、別のグループの会話には表示されません。
:::
