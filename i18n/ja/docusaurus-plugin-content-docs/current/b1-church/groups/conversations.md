# グループの会話

<div class="article-intro">

グループチャットは、グループのメンバーがメッセージを投稿して互いにやり取りできる場所です。会議と会議の間も、話題について話し合ったり、近況を共有したり、グループとのつながりを保ったりするために会話機能を使いましょう。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1.church アカウントに[ログイン](../getting-started/logging-in.md)している必要があります。
- グループチャットにアクセスするには、そのグループのメンバーである必要があります。グループへの参加方法は[グループの詳細](./group-details.md)をご覧ください。

</div>

## 会話にアクセスする

1. [グループ一覧ページ](./browsing-groups.md)からグループをクリックして、グループの詳細ページを開きます。
2. ログインしていることを確認します。
3. グループ名の下の **Open chat** をタップするか、最新のメッセージをプレビュー表示している **Messages** セクションをタップします。チャットが全画面で開きます。グループに戻るには、戻る矢印をタップします。

## ディスカッションとお知らせ

グループチャットには、教会がこのグループで有効にしている機能に応じて、2 種類のフィードがあります。チャット上部のグループ名の上にあるラベルで、現在どちらのフィードを表示しているかがわかります。

- **Chat** -- ディスカッションです。グループのどのメンバーもメッセージを投稿したり、他のメンバーの投稿に返信したりできます。
- **Announcements** -- グループリーダーが投稿する、全メンバーに見てほしい重要なメッセージです。一般のメンバーはお知らせを読んだり、リアクションしたりできますが、投稿できるのはリーダーだけです。一般のメンバーには、メッセージ入力欄の代わりに「Only group leaders can post announcements.」と表示されます。

両方のフィードが有効な場合、チャット上部の **Announcement** 欄に最新のお知らせが表示されます。**All announcements** をタップするとお知らせのフィードが開き、**Back to chat** をタップするとディスカッションに戻ります。(この欄は、グループにお知らせが 1 件以上ある場合にのみメンバーに表示されます。)

教会がこのグループで 2 つのフィードのうち一方だけを有効にしている場合、チャットは直接そのフィードで開きます。両方とも無効な場合、グループにはチャットも **Messages** セクションもありません。

## メッセージを投稿する

1. グループのページで **Open chat** をタップします。
2. **Chat** フィードを表示していることを確認します。お知らせを読んでいる場合は **Back to chat** をタップします。
3. **Send a message…** の入力欄にメッセージを入力します。
4. 送信ボタンをタップするか、**Enter** キーを押して、グループにメッセージを共有します。

投稿したメッセージは、グループのすべてのメンバーに表示されます。

## 自分のメッセージを編集または削除する

投稿したメッセージは、どれでも編集または削除できます。

1. メッセージの下にある **more options** ボタン(⋮)をタップして、メッセージのメニューを開きます。
2. メッセージの本文を変更するには **Edit** を、メッセージを削除するには **Delete** を選択します。
   - 編集すると、メッセージの本文が入力欄に戻り、その上に **Editing message** と表示されます。(編集を中止するには **Cancel** をタップします。)変更を加えて送信すると保存されます。
   - 削除すると **Delete message?** の確認が表示されます。**Delete** をタップすると、会話のすべての参加者からメッセージが完全に削除されます。

:::info
編集できるのは自分のメッセージだけです。グループリーダーは他のメンバーのメッセージを削除することもできます。一般のメンバーには、自分のメッセージに対するメニューだけが表示されます。
:::

## メッセージにリアクションする

グループチャットでは、どのメッセージにも絵文字でリアクションできます。

1. メッセージの下にある **Add reaction** ボタンをタップします。
2. 6 種類の絵文字 👍 ❤️ 😂 🎉 🙏 😮 から 1 つを選びます。

リアクションはメッセージの下に小さなチップとして表示され、それぞれの絵文字を使った人数が示されます。自分のリアクションは強調表示されます。チップをタップする(または同じ絵文字をもう一度選ぶ)と取り消せます。別の絵文字を選ぶと、もう 1 つ追加できます。リアクションは、チャットのすべての参加者にリアルタイムで表示されます。

:::tip
グループの会話は、各グループのチャットに表示されます。以前のまとめて表示する[タイムライン](../community/timeline.md)フィードは廃止されました。確認が必要なアクティビティは、アプリバーの**ベル**アイコンの下に通知として届きます。
:::

## リーダー向けの機能

グループリーダーであれば、グループチャットで次のような追加の機能を使えます。

- **お知らせを投稿する** -- **All announcements** をタップする(お知らせだけが有効な場合はチャットを開く)と、グループの全メンバーが読めるメッセージを投稿できます。
- **メッセージを削除する** -- メッセージのメニュー(⋮)から、どのメンバーのメッセージでも削除できます。
- **ディスカッションに投稿する** -- 他のメンバーと同様に、通常のディスカッションにも参加できます。

:::info
会話はグループごとに分かれています。あるグループに投稿したメッセージは、別のグループの会話には表示されません。
:::
