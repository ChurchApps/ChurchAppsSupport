# イベントへの出欠回答

<div class="article-intro">

グループのイベントでは、リーダーが参加者を把握できるように出欠を集めることができます。グループのページとカレンダーでは、今後のイベントごとに**参加**、**未定**、**不参加**のボタンが表示されます。タップするだけで回答でき、いつでも変更できます。他に何人が参加するかもひと目で確認できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [ログイン](../getting-started/logging-in.md)していて、そのグループのメンバーである必要があります
- そのイベントで出欠回答が許可されている必要があります(初期設定ではオンです。リーダーはイベントごとにオフにできます)

</div>

## イベントへの回答方法

1. メンバーポータルでグループを開きます。グループの次のイベントは**次のイベント**セクションに表示されます。他のイベントを見るには**すべてのイベント**をタップします。**カレンダー**表示では日付をタップするとその日のイベントが表示されます。**リスト**表示に切り替えると、今月の今後のイベントをまとめて確認できます。
2. 今後のイベントには、それぞれ**参加**、**未定**、**不参加**の3つのボタンが表示されます。
3. 回答をタップします。選んだボタンがハイライトされ、各ボタンには同じ回答をした人数がリアルタイムで表示されます。
4. ハイライトされている回答をもう一度タップすると取り消せます。別のボタンをタップすると回答を変更できます。

出欠回答は、そのイベントの回ごとに適用されます。たとえば毎週の集まりでは、週ごとのイベントに個別に回答します。

## グループリーダーの方へ

- **回答の確認** -- リーダーは、グループのカレンダー(**すべてのイベント**)の各イベントに**回答を見る**リンクが表示されます。リンクをタップすると**回答**シートが開き、参加、未定、不参加の回答ごとに全員が一覧表示されます。まだ誰も回答していない場合は「まだ回答がありません」と表示されます。
- **出欠回答のオン/オフ** -- イベントの作成時または編集時に**出欠回答を許可**のスイッチを使用します。出欠回答をオフにしたイベントには、回答ボタンは表示されません。B1 Adminで一括してイベントを作成するスタッフも、同じオプションを利用できます。詳しくは[グループカレンダー](../../b1-admin/groups/group-calendar#event-rsvps)を参照してください。

:::tip
出欠回答は簡単な人数確認のための機能です。申込みの詳細情報、定員管理、または支払いが必要なイベントでは、代わりに[イベント登録](../events/registering)を使用してください。
:::
