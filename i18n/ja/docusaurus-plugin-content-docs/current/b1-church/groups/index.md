# グループ

<div class="article-intro">

グループは、教会の仲間とつながる素晴らしい方法です。小規模グループ、奉仕チーム、聖書研究会、ボランティアの機会など、どれをお探しでも、教会の B1.church サイトから直接グループを閲覧して参加できます。

</div>

## できること

B1App でグループを使ってできることは次のとおりです:

- **公開グループを閲覧** — 利用可能なすべてのグループをカテゴリごとに表示します。各グループには写真、名前、集会の時間、場所、簡単な説明が表示されます。
- **グループの詳細を表示** — グループをタップすると、詳しい説明、リーダー、今後のカレンダーイベントが表示されます。
- **グループに参加** — グループに接続してメンバーになれます。オープンなグループはすぐに参加でき、承認が必要なグループは参加リクエストを送信できます。詳しくは [グループへの参加をリクエストする](./join-requests.md) を参照してください。
- **会話に参加** — グループのメンバーになると、グループチャットでメッセージを投稿し、他のメンバーとやり取りできます。グループページの **チャットを開く** をタップしてください。
- **イベントとリソースにアクセス** — グループの次のイベントを確認できます (**すべてのイベント** をタップすると全カレンダーが表示されます)。また、**リソース** セクションから共有ファイルやリンクをダウンロードできます。

## 公開ページとログイン後の表示

誰でも教会のグループページを訪れて、利用可能なグループを閲覧できます。ログインしていない訪問者は、グループの説明を見たり、リーダーを確認したり、今後のカレンダーイベントをチェックしたりできます。グループに参加するには、訪問者は **参加するにはサインイン** をクリックし、サインインするかアカウントを作成します。

[ログイン](../getting-started/logging-in.md)してグループのメンバーになると、グループの詳細ページにより多くのセクションが表示されます: **次のイベント**、**集会**、**メッセージ**、**メンバー**、**リソース**、**計画**、**概要**。一部のセクションは該当する場合にのみ表示されます。たとえば **概要** にはグループの説明が、**計画** には奉仕の計画が、**メッセージ** にはグループチャットが有効になっている必要があります。各セクションにはプレビューが表示され、**すべてのメンバー** や **すべてのイベント** などのリンクから全リストを開けます。グループのリーダーは、これらの画面で追加の編集機能を利用できます。

**集会** には、グループの最近の集会が新しい順に表示され、各集会のリーダーのメモと出席者数が示されます。欠席した週があるメンバーも、ここで内容を確認できます。グループのリーダーと、出席を記録できるスタッフには、セクションのヘッダーに **メモを追加** と **出席を記録** が表示されます。**メモを追加** では、今後の集会を含む任意の日付に短いメモを投稿でき、メモには太字、リスト、リンクを含めることができます。**出席** 画面には日付の下に同じ **メモ** 欄があるため、出席を記録しながら集会の振り返りを書くことができます。集会をタップすると、その出席記録が開きます。詳しくは [集会メモと出席](./group-details.md#meeting-notes-and-attendance) を参照してください。

グループのリーダーには **リーダーメモ** セクションも表示されます。これは非公開のフィードで、グループのリーダーがメンバーや教会スタッフには見えないメモを残せます。詳しくは [リーダーメモ](./group-details.md#leader-notes) を参照してください。

:::tip
グループでの会話は各グループのチャットで行われます。参加しているグループは [ホームダッシュボード](../getting-started/navigating.md#home) の **あなたのグループ** セクションに表示され、グループの今後のイベントは [Me ページ](../getting-started/me-page.md) に表示されます。対応が必要な新しいアクティビティは、ベルメニューの通知として届きます。
:::
