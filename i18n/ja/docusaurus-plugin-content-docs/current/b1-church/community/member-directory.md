# メンバーディレクトリ

<div class="article-intro">

メンバーディレクトリでは、教会の人を閲覧したり検索したりできます。グループの仲間を探すときも、新しく来た人を見つけたいときも、ディレクトリを使えば教会の家族とのつながりを簡単に持てます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1.church アカウントに[ログイン](../getting-started/logging-in.md)している必要があります。
- ディレクトリを開ける人は、教会の**ディレクトリに表示**の設定に従います。選択肢は**管理者のみ**、**メンバー以上**（デフォルト）、**通常の出席者以上**、**訪問者以上**です。そのレベルに満たない人には「メンバー限定」と表示されます。「人物 > 表示」権限を持つスタッフは常にディレクトリを開けます。**管理者のみ**に設定されている場合は、スタッフの会員ステータスを持つ人であっても、権限を持つスタッフだけが開けます。ゲストや非アクティブのステータスの人は、どの設定でも開けません。詳しくは [メンバーディレクトリとメッセージの設定](../../b1-admin/settings/mobile-app.md#member-directory--messaging-settings) をご覧ください。

</div>

## ディレクトリへのアクセス

1. [タブバーまたは「その他」ページ](../getting-started/navigating.md)で**コミュニティ**をタップします（教会によっては別の名前になっている場合があります）。
2. **ディレクトリ**が開き、人数と表示可能なすべての教会メンバーのリストが表示されます。

## メンバーの検索

リストの上部にある**メンバーを検索**の欄に名前を入力します。入力に合わせてリストが絞り込まれ、一致した部分の名前が強調表示されます。欄を消去すると、ディレクトリ全体が再び表示されます。

## ディレクトリの閲覧

メンバーは名の最初の文字によって、A、B、C などの文字見出しの下にまとめられ、各文字の中では姓順に並んでいます。各項目にはメンバーの写真、表示名、会員ステータスが表示されるため、リストをざっと見て探しやすくなっています。

## メンバープロフィールの表示

リスト内のメンバーをタップすると、そのプロフィールが開きます。プロフィールには、メンバーの名前、写真、会員ステータスが表示されます。情報が登録されている場合は、**メッセージ**、**電話**、または**テキスト**を送るボタンも表示されます。その下の**連絡先情報**セクションには、教会とメンバーが共有することを選んだ詳細（メールアドレス、電話番号、住所など）が表示されます。**世帯のメンバー**には、同じ世帯の他の人が一覧表示されます。

プロフィール内で世帯のメンバーをタップすると、その人のプロフィールに移動できます。自分のプロフィールでは、**プロフィールを編集**ボタンから[プロフィールの編集](../getting-started/editing-your-profile.md)画面に進めます。

:::info
各プロフィールに表示される情報は、教会のプライバシーとディレクトリの設定によって異なります。すべてのメンバーで全項目が表示されるとは限りません。
:::

:::info
教会の[プライベートメッセージの最低年齢](/docs/b1-admin/settings/mobile-app#member-directory--messaging-settings)に満たないメンバーは、ディレクトリに引き続き表示されますが、そのメンバーにプライベートメッセージを送る選択肢は利用できません。
:::
