# 会員ディレクトリ

<div class="article-intro">

会員ディレクトリでは、教会の会員を閲覧・検索できます。グループの仲間を探すときも、新しい会員を見つけたいときも、ディレクトリを使えば教会の家族とのつながりを簡単に持てます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1.churchアカウントに[ログイン](../getting-started/logging-in.md)している必要があります。
- ディレクトリを開ける人は、教会の**ディレクトリに表示**設定に従います。選択肢は**管理者のみ**、**メンバー以上**（初期設定）、**定期的な出席者以上**、**訪問者以上**です。そのレベルに満たない人には「メンバーのみ」というメッセージが表示されます。人員の閲覧権限（People > View）を持つスタッフは常にディレクトリを開けます。設定が**管理者のみ**の場合は、スタッフの会員ステータスを持つ人であっても、この権限を持つスタッフだけが開けます。ゲストまたは非アクティブのステータスの人は、どの設定でも開けません。詳しくは[会員ディレクトリとメッセージの設定](../../b1-admin/settings/mobile-app.md#member-directory--messaging-settings)をご覧ください。

</div>

## ディレクトリを開く

1. [タブバーまたは「その他」ページ](../getting-started/navigating.md)で**コミュニティ**をタップします（教会によっては別の名前になっている場合があります）。
2. **ディレクトリ**が開き、人数と表示可能なすべての教会会員の一覧が表示されます。

## 会員を検索する

一覧の上部にある**会員を検索**のボックスに名前を入力します。入力するたびに一覧が絞り込まれ、一致する部分の名前がハイライトされます。ボックスを空にすると、ディレクトリ全体が再び表示されます。

## ディレクトリを閲覧する

会員は名前の最初の文字によって、文字の見出し（A、B、C など）の下にグループ分けされ、各文字の中では姓の順に並べられます。各項目には会員の写真、表示名、会員ステータスが表示されるため、一覧を素早く見渡せます。

## 会員プロフィールを見る

一覧の会員をタップすると、そのプロフィールが開きます。プロフィールには会員の名前、写真、会員ステータスが表示され、情報が利用可能な場合は**メッセージ**、**電話**、**テキスト**のボタンも表示されます。その下の**連絡先情報**セクションには、教会と会員が共有することを選んだ情報（メールアドレス、電話番号、住所など）が表示されます。**世帯メンバー**には、同じ世帯の他の人が一覧で表示されます。

**メッセージ**をタップすると、その人との個人的な会話が開きます。文字を太字や斜体にしたり、リストを追加したりするには、文字を選択して表示されるツールバーを使います。これは[グループチャット](../groups/conversations.md#formatting-your-message)と同じ方法です。

プロフィール内の世帯メンバーをタップすると、その人のプロフィールに移動できます。自分のプロフィールには**プロフィールを編集**ボタンがあり、[プロフィールの編集](../getting-started/editing-your-profile.md)に進めます。

:::info
各プロフィールに表示される情報は、教会のプライバシーとディレクトリの設定によって異なります。会員によっては、すべての項目が表示されない場合があります。
:::

:::info
教会の[個人メッセージの最低年齢](/docs/b1-admin/settings/mobile-app#member-directory--messaging-settings)未満の会員は、ディレクトリに引き続き表示されますが、個人メッセージを送るオプションは利用できません。
:::
