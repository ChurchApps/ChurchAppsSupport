# コミュニティ

<div class="article-intro">

B1.church の **コミュニティ** セクションでは、教会の仲間とのつながりを保つことができます。メンバーディレクトリを使って、他の教会メンバーを探したり、その人について知ったりできます。

</div>

## 見られる内容

- **[メンバーディレクトリ](./member-directory.md)** -- 教会のメンバーディレクトリを閲覧・検索できます。名前で探したり、グループで絞り込んだりして、探している人を見つけられます。メンバーをクリックすると、プロフィールの詳細を確認できます。
- **[タイムライン](./timeline.md)** -- 以前の統合アクティビティフィードです。現在は提供を終了しています。このページでは、各種の更新情報が現在どこに表示されるかを説明しています。

## はじめに

コミュニティ機能を利用するには、[ログイン](../getting-started/logging-in.md)している必要があります。サインインしていない場合、**コミュニティ** タブにはディレクトリの代わりにサインイン案内が表示されます。

メンバーポータルは [ホームダッシュボード](../getting-started/navigating.md) から開きます。**コミュニティ** タブからメンバーディレクトリにアクセスできます。

:::info
ディレクトリで閲覧できるメンバーや情報は、教会のプライバシー設定によって異なります。すべてのメンバーの詳細なプロフィールが見られるとは限りません。どの情報が共有されるかについてご不明な点があれば、教会の管理者にお問い合わせください。
:::

:::tip
[グループ](../groups/index.md) と併せてコミュニティ機能を活用すると、一週間を通して教会とのつながりを深めやすくなります。
:::
