# タイムライン

<div class="article-intro">

独立した**タイムライン**タブは廃止されました。メンバーポータルは現在、[ホームダッシュボード](../getting-started/navigating.md)で開きます。以前は1つのフィードにまとめて表示されていたアクティビティは、それぞれの適切な場所に移動しました。具体的には、**Me**ページ、通知、各グループ内です。

</div>

## タイムラインのアクティビティの新しい場所

| 以前タイムラインで見られたもの | 現在の確認場所 |
| --- | --- |
| グループの会話とお知らせ | 各[グループ](../groups/conversations.md)内のチャット（**チャットを開く**） |
| あなたとグループの今後のイベント | **Me**ページ（`/mobile/me`）と各グループの**次のイベント**セクション |
| タスクと奉仕の割り当て | **Me**ページと[プラン](../plans/) |
| 新しい説教 | ホームの**最新の説教**セクションと[説教](../content/sermons.md)タブ |
| あなたに通知が届いたもの | アプリバーのベルアイコン、または `/mobile/notifications` |

## Meページ

[Meページ](../getting-started/me-page)は、以前のフィードに最も近い代わりの機能です。あなたに関係する今後の予定（奉仕の割り当て、イベント登録、グループイベント）、提出したフォーム、出席履歴、最新の通知を一覧で表示します。また、プロフィール、通知設定、メッセージ、献金、登録のページへのリンクもあります。

## 通知

以前はタイムラインの項目として表示され、対応が必要だったものは、現在は通知として届きます。アプリバーのベルをタップすると最新の通知を確認できます。すべての通知を見るには、**すべて表示**をタップするか、`/mobile/notifications` を開いてください。通知をタップすると、その通知の元となったグループ、プラン、または会話に移動します。どの通知を受け取るか、またその受け取り方は、[通知設定](../getting-started/notification-preferences.md)で管理できます。

:::tip
Meページに何も表示されない場合は、まだどのグループにも参加していない可能性があります。[グループ](../groups/browsing-groups.md)ページで参加できるグループを探すか、教会の管理者またはグループリーダーに追加を依頼してください。
:::
