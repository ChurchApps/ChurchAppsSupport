# B1.church

<div class="article-intro">

B1.church は、教会のメンバー向けポータルです。メンバーは、ここで教会とのつながりを保ち、教会のツールにアクセスし、週を通してコミュニティと交流できます。各教会には `https://yourchurchname.b1.church` という専用の URL が割り当てられます。

</div>

メンバーが B1.church のサイトを訪れると、教会のブランディング、ナビゲーションリンク、コンテンツページを備えた公開ウェブサイトが表示されます。ログイン後は、個人の教会ツールがすべてまとめられている **メンバーポータル** を利用できます。

## 主な機能

- **ホームと自分** -- メンバーポータルは [ホームダッシュボード](./getting-started/navigating.md) から始まり、今後の奉仕の割り当て、所属グループ、今年の献金の概要が表示されます。[自分のページ](./getting-started/me-page.md) には、奉仕の割り当て、イベント登録、グループの予定など、今後のご自身の予定が一覧で表示されるほか、最近の通知、送信したフォーム、出席履歴も確認できます。
- **グループ** -- 所属しているグループを表示し、グループのメンバーを確認し、会話に参加し、出席を記録し、グループに関連付けられたフォームに記入できます（リーダーは回答を閲覧・印刷できます）。
- **献金** -- 教会がオンラインでの献金を受け付けていなくても、オンラインで教会に献金でき、献金履歴や明細を確認できます。
- **イベント** -- 今後のイベントを閲覧し、ご自身とご家族の登録ができます。
- **奉仕** -- 礼拝プラン、ご自身のボランティアの役割を確認し、募集中のボランティア活動に申し込めます。[通知設定](./getting-started/notification-preferences.md) で、奉仕やイベントのリマインダーをテキストメッセージで受け取るように選択できます（いつでも STOP と返信して停止できます）。
- **プラン** -- 今後の礼拝プランを確認し、割り当てられた役割を承諾または辞退し、賛美の詳細と礼拝の順序にアクセスできます。
- **チェックイン** -- ご自身と世帯のメンバーを礼拝やイベントにチェックインさせることができます。ゲストは QR コードから登録でき、再訪したゲストは二重登録されず、既存のプロフィールと照合されます。
- **コミュニティディレクトリ** -- 教会のメンバーディレクトリを閲覧し、プロフィールを表示し、ダイレクトメッセージを送信できます。ご自身の連絡先情報を誰に表示するかは、[プロフィールのプライバシー](./getting-started/editing-your-profile.md#privacy) セクションで管理できます。
- **サインインのセキュリティ** -- [二段階認証](../b1-admin/profile/managing-profile.md#two-factor-sign-in) を有効にすると、パスワードに加えて認証アプリのコードを使ってサインインできます。
- **コンテンツ** -- 説教の閲覧、聖書の閲読、ライブ配信の視聴、デイリーみことばの閲覧・共有・ダウンロード（過去のみことばを含む）がすべて教会のサイトから行えます。（カリキュラムの再生は現在 [FreePlay](/docs/freeplay/) で提供されています。ポータル内のレッスンタブは非推奨です。）

:::
