# セルフチェックイン

<div class="article-intro">

セルフチェックインを使うと、数ステップで自分と家族の出席を記録できます。教会にあるキオスク端末を使う代わりに、手軽に利用できる方法です。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1.church アカウントに[ログイン](../getting-started/logging-in.md)しておく必要があります。
- 家族がアカウントに紐づけられている必要があります。家族が表示されない場合は、教会の管理者に世帯へ追加してもらってください。

</div>

## チェックインの流れ

チェックインは簡単な3ステップで行います。[タブバーまたは「その他」ページ](../getting-started/navigating.md)から**チェックイン**を開いて始めてください。

### ステップ1：礼拝を選択する

チェックインのページを開くと、利用可能な礼拝の一覧が表示されます（例：「日曜朝の礼拝」「水曜夜の礼拝」）。各礼拝のカードには礼拝名が表示され、教会に複数の拠点がある場合は拠点名も表示されます。

礼拝をタップして選択すると、次のステップに進みます。

### ステップ2：世帯のメンバーとグループを選択する

礼拝を選択すると、**出席者**の下に世帯のメンバーが表示されます。出席する方それぞれについて、次の操作を行います。

1. 世帯のメンバーをタップして項目を展開します。
2. 選択した礼拝の利用可能な**礼拝時間**が表示されます。教会がチェックインの時間枠を設定している場合、その時間帯にチェックインが開いている間だけ選択できます（例：礼拝開始の30分前から終了後しばらくまで）。時間枠外では礼拝時間が**受付終了**と表示され、わかっている場合は次回の開始時刻も示されます（例：**受付終了 · 日曜 9:30 AM に開始**）。
3. 礼拝時間の横にある**グループを選択**をタップし、その方をチェックインさせるグループを選びます（例：「メイン礼拝」「キッズルーム1」「ユースグループ」）。
4. 出席する世帯のメンバーごとに繰り返します。

全員をチェックインする必要はありません。実際に出席している方だけを展開し、グループを割り当ててください。

### ステップ3：確認

出席する全員のグループを選択したら、ページ下部のボタンをタップします。ボタンには選択した人数が表示されます（例：**1人をチェックイン**、**3人をチェックイン**）。

チェックインが完了し、出席が保存されたことを示す確認が表示されます。しばらくすると礼拝の一覧に戻り、次のチェックインに備えられます。

教会で受付端末にて名札を印刷する場合は、代わりに**チェックインが完了しました！**と、QRコードとセキュリティコードが表示されます。受付端末でこのコードを提示すると名札が印刷されます。その後、**完了**をタップしてください。B1 Checkin のキオスク端末では、**コードをスキャン**をタップし、QRコードをカメラにかざしてください。詳しくは[スマートフォンでのチェックイン用ラベルの印刷](../../b1-checkin/check-in/looking-up-members.md#printing-labels-for-a-phone-check-in)をご覧ください。

選択した礼拝にすでに世帯がチェックイン済みの場合、**出席者**の見出しの横に**チェックインコードを表示**のリンクが表示されます。タップすると、QRコードとセキュリティコードが再度表示されます。たとえば、受付端末に行く前にページを閉じてしまった場合に便利です。

:::tip
チェックインを完了する前にグループの選択を変更したい場合は、礼拝時間の横にある**変更**ボタンをタップして、別のグループを選択してください。
:::

## 知っておきたいこと

- チェックインできるのは、自分のアカウントに紐づけられた世帯のメンバーだけです。家族が表示されない場合は、教会の管理者に世帯へ追加してもらってください。
- チェックインのページに礼拝が表示されない場合、教会では現時点でチェックイン用の礼拝が設定されていない可能性があります。
- 礼拝を選択したときに「チェックインは日曜 9:30 AM に開始します。」（または「この礼拝のチェックインは現在行っていません。」）と表示される場合、その礼拝のすべての時間が現在チェックイン時間枠内にありません。チェックインが開始されてから再度お試しください。
- 世帯が以前の礼拝時間にチェックイン済みの場合でも、後の礼拝時間が開始されたら、その時間に改めてチェックインできます。前の礼拝時間が終了した後でも問題ありません。
- 選択した部屋が満員または閉鎖中の場合、「選択した部屋は満員か、チェックインを受け付けていません。ボランティアにお声がけください。」と表示されます。

:::warning
チェックインは、教会で有効な礼拝が設定されている場合にのみ利用できます。礼拝が一覧に表示されない場合は、教会の事務所にセルフチェックインが有効かどうかをご確認ください。
:::
