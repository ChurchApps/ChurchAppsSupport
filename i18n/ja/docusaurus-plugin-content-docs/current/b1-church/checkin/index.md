# チェックイン

<div class="article-intro">

B1.church の **チェックイン** 機能を使うと、メンバーポータルから直接、ご自身と世帯のメンバーの礼拝への出席登録ができます。チェックイン機器のある場所へ行かなくても、出席を簡単に記録できます。

</div>

## 仕組み

セルフチェックインでは、礼拝を選び、出席する世帯のメンバーを選択して、礼拝の時間ごとに各人を適切なグループに割り当てます。確定すると、出席は自動的に記録されます。

## はじめに

チェックインにアクセスするには、メンバーポータルの[タブバーまたは「その他」ページ](../getting-started/navigating.md)で **チェックイン** をタップします。この機能を使うには[ログイン](../getting-started/logging-in.md)している必要があります。サインインしていない場合は、まずログインするよう求められます。

:::info
チェックイン機能を利用するには、教会の管理設定で礼拝と出席グループが設定されている必要があります。チェックインページを開いたときに利用できる礼拝がない場合は、この機能がまだ設定されていない可能性があります。ご不明な点は教会の管理者にお問い合わせください。
:::
