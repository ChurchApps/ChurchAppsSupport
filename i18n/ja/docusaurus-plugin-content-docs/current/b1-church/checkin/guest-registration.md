# ゲスト登録

<div class="article-intro">

教会に初めて来られる場合は、ゲスト登録ページを使ってご自身とご家族をゲストとして登録できます。これにより教会のシステムに記録が作成され、来場時にボランティアがチェックインを行えるようになります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 教会でQRゲスト登録が有効になっている必要があります。有効でない場合、ページに「この教会ではゲスト登録が有効になっていません。」と表示されます。
- チェックイン端末に表示されているQRコードをスキャンするか、端末の**ここで登録**をタップするか、教会のボランティアからリンクを受け取ってください。

</div>

## ゲスト登録の仕組み

ゲスト登録は、まだアカウントをお持ちでない方を対象としています。教会のチェックイン端末で**ゲストとして登録**をタップすると、登録ページにつながるQRコードが表示されます。ボランティアや受付スタッフからリンクを受け取るか、チラシや教会のウェブサイトから見つけることもできます。

スマートフォンがお手元にない場合は、端末に表示される同じQRコードの画面で**ここで登録**をタップし、端末上でフォームに入力することもできます。端末での操作方法については、[ゲストとして登録する](../../b1-checkin/check-in/looking-up-members.md#registering-as-a-guest)をご覧ください。

ページは**ゲスト登録**というタイトルで開きます。教会がヘッダー画像を追加している場合はページ上部に表示され、そうでない場合は小さなアイコンが表示されます。

## ご家族の登録

1. チェックイン端末の**QRコードをスキャン**するか、スマートフォンでゲスト登録のリンクを開いてください。（端末で**ここで登録**をタップした場合は、フォームがすでに開いています。）
2. **代表者連絡先**のカードに入力します。**名**と**姓**は必ず入力が必要です。教会の設定によっては、以下の項目も表示される場合があります。
   - **敬称**（Mr、Mrs、Dr、牧師など）。名前の前に付きます。
   - **メールアドレス**と**電話番号**
   - **婚姻状況**
   - **住所** -- **番地**、**番地以降（建物名など）**、**市区町村**、**都道府県**、**郵便番号**。こちらはご家族全員で共有されます。
3. フォームには、次に**家族メンバー2**のカードが表示されます。そのメンバーの名と姓を入力してください。お一人でご登録される場合は、カードの隅にある**×**をタップして削除します。
4. 人数を追加するには**家族メンバーを追加**をタップします。新しく追加されたカードには、代表者の姓が自動で入力されます。一度に最大10名まで登録できます。
5. 教会が必要とする場合、各メンバーのカードには**敬称**、**電話番号**、**生年月日**、**性別**、**学年**の項目も表示されることがあります。代表者以外のカードには、**世帯内の続柄**（**配偶者**、**子ども**、**その他**）を選択する項目が表示される場合もあります。これにより、教会は各メンバーが代表者とどのような関係にあるかを把握できます。
6. 教会で家族メンバーの下に**コメント**欄がある場合は、教会に伝えたいことがあればご記入ください（1,000文字まで）。
7. **登録**をタップして送信します。

アスタリスク（`*`）が付いた項目は必須です。未入力の必須項目がある場合、フォームに「必須項目をすべて入力してください。」と表示され、入力されるまで送信されません。

## 登録後

フォームを送信すると、「登録完了 -- 準備が整いました！スタッフがまもなくチェックインの手続きを行います。」というメッセージが表示された確認画面が現れます。

登録により、教会のデータベースに以下の情報が作成されます。

- 代表者の姓を使って**世帯**が作成され、代表者が世帯主として登録されます。
- ご家族の各メンバーについて、「訪問者」の会員ステータスで**人物レコード**が作成されます。各メンバーには、選択いただいた世帯内の続柄が設定されます。続柄の入力がない場合は**その他**が設定されます。
- ご入力いただいたコメントは、代表者の記録にメモとして保存され、教会のスタッフが確認できます。
- 教会で新規ゲスト向けのグループが設定されている場合、ご家族はそのグループに追加されます。また、そのグループの礼拝時間内に登録された場合は、出席が自動で記録されることもあります。
- 教会のボランティアまたは管理者が、[B1 Checkin](../../b1-checkin/check-in/looking-up-members.md)端末を使ってご家族をチェックインさせることができます。

:::info
同じ名と同じメールアドレスまたは電話番号で再度登録された場合、教会の記録がそれを認識し、重複を作成せずに既存のプロフィールを再利用します。それ以外の方は新規として追加されます。すでに登録済みの場合は、端末でお名前または電話番号を検索していただくこともできます。
:::

:::tip
フォームでメールアドレスを求められた場合は、ご入力いただくと、ご来場後に教会から連絡を受けやすくなります。
:::
