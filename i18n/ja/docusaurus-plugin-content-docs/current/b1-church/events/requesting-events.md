# イベントと部屋のリクエスト

<div class="article-intro">

教会が予約可能な部屋やリソースを管理している場合、メンバーポータルから直接、必要な部屋や備品を指定してイベントをリクエストできます。既存の予約との競合は選択時に表示され、リクエストは教会の承認に回されます。リクエストの状況確認やキャンセルは「My Requests」から行えます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- メンバーポータルに[ログイン](../getting-started/logging-in.md)している必要があります
- 教会の B1 Admin で部屋またはリソースが設定されている必要があります。設定されていない場合、リクエストのリンクは表示されません

</div>

## リクエストの送信

1. メンバーポータルで **Me** ページを開き、**リクエストと登録** セクションの **イベントをリクエスト** をタップします。
2. イベントの基本情報を入力します。**イベント名**、任意の **説明**、**開始** と **終了** の時刻（または **終日**）、そして **繰り返し** を設定するかどうかを指定してください。
3. 必要な **部屋** と **リソース** を選択します。リソースについては **数量** を設定できます。
4. 競合の警告に注意してください。時間が部屋やリソースの既存の予約と重なる場合、*「この時間は既存の予約と競合しています。」* と表示されます。時間を変更するか、別のものを選んでください。
5. **リクエストを送信** をタップします。

送信後、**リクエストを送信しました** という概要画面に、リクエストした各部屋・リソースの状態が表示されます:

- **承認済み** -- 承認グループが設定されていない部屋またはリソースのため、すぐに予約されます。
- **承認待ち** -- 教会の担当者による承認が必要です。

## リクエストの確認

Me ページから **My Requests** を開きます。各リクエストには、イベント名、リクエストした日時、ステータスのラベルが表示されます:

- **保留中** -- 判断待ち
- **承認済み** -- 予約が確定しています
- **却下** -- リクエストが拒否されました

リクエストがまだ保留中の場合は、**リクエストをキャンセル** で取り下げられます（確認を求められます。キャンセルは取り消せません）。

:::info
リクエストは教会のスタッフが B1 Admin の[承認ページ](../../b1-admin/calendars/approvals)で確認します。どの部屋やリソースに承認が必要かは教会によって異なります。詳しくは[部屋とリソース](../../b1-admin/calendars/rooms-resources)を参照してください。
:::
