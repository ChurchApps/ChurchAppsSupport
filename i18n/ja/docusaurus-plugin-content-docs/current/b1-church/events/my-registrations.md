# マイ登録

<div class="article-intro">

メンバーポータルの **登録** ページは、申し込んだすべてのイベントを確認できる拠点です。ここから、ステータスの確認、未払い残高の支払い、参加者や注文内容の変更、または登録の完全なキャンセルができます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [ログイン](../getting-started/logging-in.md)している必要があります。ゲストとしての登録はここには表示されません
- 少なくとも1件のイベント登録が必要です。[イベントへの登録](./registering.md)を参照してください。

</div>

## 登録の確認

メンバーポータルで **登録** を開きます。各登録は次の情報を示すカードとして表示されます：

- **イベント名と日付**
- **ステータス**のピル：**確定**、**保留中**、**キャンセル待ち**、または**キャンセル済み**
- 登録した**メンバー**
- 支払い行：支払い済みの合計額、または未払いの場合は**残高未払い**

まだ何も登録していない場合は、「登録はまだありません」と表示されます。

## 支払いを完了する

未払い残高のある登録には**支払いを完了**ボタンが表示されます。最も多いのは、キャンセル待ちから繰り上げられたとき、またはスタッフによる編集で合計額が変わったときです。

1. **支払いを完了**をクリックします。
2. 注文内容を確認し、保存済みのカードを選ぶか新しいカードを入力して支払います。
3. 残高が支払われると、登録は**確定**になります。

:::tip
キャンセル待ちの空きが出ると、教会から送られるメールには、この支払い手続きへの直接のリンクが含まれています。
:::

## 登録の編集

予定は変わるものです。登録の**編集**をクリックすると**登録の編集**ダイアログが開き、次の操作ができます：

- **連絡先**を更新する
- 各メンバーの**名前**と**参加者の種類**を変更する
- **選択数量**（Tシャツや食事などのオプション）を調整する

編集時にも定員の制限は適用されます。参加者の種類やオプションがその後売り切れている場合は、別の選択肢を選ぶよう求められます。保存すると合計額が再計算されます。変更の結果、未払い残高が生じた場合は、カードに**支払いを完了**ボタンが表示されます。

:::info
編集によって自動的にカードへ請求されることはありません。合計額が増えた場合は**支払いを完了**で差額を支払ってください。減った場合は、返金について教会に問い合わせてください。返金は教会のスタッフが決済プロバイダーを通じて行います。
:::

## 登録のキャンセル

1. カードの**登録をキャンセル**をクリックします。
2. ダイアログで確認します。キャンセルは取り消すことができません。

あなたの席は直ちに解放されます。イベントにキャンセル待ちリストがある場合は、順番が次の人に自動的に繰り上げられます。お支払い済みの金額は自動的には返金されません。返金については教会の事務所に問い合わせてください。
