# イベント

<div class="article-intro">

B1.church のイベントセクションでは、教会の今後のイベントを閲覧し、ウェブサイトから直接登録できます。教会がイベントの登録を有効にしている場合、数ステップで本人と家族を登録できます。有料イベントでは、参加者の種類やオプションを選び、割引コードを適用して、登録の一環として安全に支払うことができます。

</div>

## イベントの閲覧

イベントは教会のウェブサイトに、月間カレンダーまたは今後のイベントのタイル表示で掲載されます。イベントをクリックすると、個別のページが開き、次の内容が表示されます。

- **イベントの写真** -- 教会が写真を追加している場合に表示されます。
- **イベント名と説明** -- イベントの内容です。
- **日時** -- 次回の開催日時、または定期イベントの繰り返しパターンです。
- **場所** -- イベントのために予約された部屋（ある場合）です。
- **このイベントに登録** -- 登録フォームに進むボタンです。イベントで登録が有効になっている場合のみ表示されます。
- **マイカレンダーに追加** -- Google カレンダー、Apple カレンダー、Outlook などのカレンダーアプリで開けるカレンダーファイルをダウンロードします。

ページ上部の **すべてのイベント** をタップすると戻れます。今後のイベントのタイルの上には **購読** ボタンがあり、カレンダー全体の ICS リンクをコピーまたはダウンロードできるため、新しいイベントを自分のカレンダーアプリに表示できます。

## 登録状況

イベントは、時期や定員によって次のいずれかの状況を表示することがあります。

- **受付中** -- 登録を受け付けており、申し込みできます。
- **受付前** -- 登録期間がまだ始まっていません。受付開始日以降に再度ご確認ください。
- **受付終了** -- 登録の締め切りを過ぎています。
- **満員** -- 利用可能な枠がすべて埋まっています。

:::tip
イベントが満員の場合でも、教会がキャンセル待ちを有効にしていれば、**キャンセル待ち**に登録できることがあります。空きが出るとメールで自動的にお知らせします。それ以外の場合は、後で再度ご確認ください。キャンセルが出れば空きが生じることがあります。
:::

## 必要なもの

- B1.church のアカウント（またはゲストとして登録することもできます）
- 教会の B1.church ウェブサイトへのアクセス
