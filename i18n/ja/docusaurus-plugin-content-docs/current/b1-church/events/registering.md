# イベントへの登録

<div class="article-intro">

教会でイベントの登録が有効になっている場合、簡単なステップに沿って申し込めます。アカウントをお持ちの方も、ゲストとして訪問する方も、ご自身と家族を登録できます。有料イベントでは、参加区分を選び、必要に応じて追加オプションを選択し、割引コードを適用してから、最後に安全に支払いができます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- そのイベントで教会の登録機能が有効になっている必要があります
- 登録期間内である必要があります（管理者が設定した開始日と終了日の間）

</div>

## ステップ1：情報を入力する

1. 教会のカレンダーから登録したいイベントを開き、**このイベントに登録**をクリックします。
2. 登録ページが開き、イベント名、説明、日付が表示されます。複数日にわたるイベントでは、開始日と終了日の両方が表示されます。
3. **ログイン**している場合、フォームにお名前が表示され、ご自身のアカウントで登録されることが確認できます。
4. **ゲスト**（ログインしていない）の場合は、次の項目を入力してください。
   - **名**（必須）
   - **姓**（必須）
   - **メールアドレス**（必須）
   - **電話番号**（任意）
5. イベントに参加区分がある場合（例：料金の異なる大人と子ども）、**ご自身の登録区分**を選んでください。各区分には料金が表示され、定員に達した区分は**満席**と表示されます。

:::info
イベントに定員がある場合は、残りの空席数がプログレスバーで表示されます。イベントが満席で、教会が補欠待ちリストを有効にしている場合は、申し込みを完了すると補欠待ちリストに加わることができます。詳しくは下記の[補欠待ちリストへの参加](#joining-a-waitlist)をご覧ください。
:::

## ステップ2：家族を追加する

1. ご家族も一緒に登録する場合は、一人ずつ**名**と**姓**を入力してください。
2. イベントに参加区分がある場合は、追加した各メンバーの区分を選んでください。
3. **メンバーを追加**をクリックすると、さらに人を追加できます（合計10名まで）。
4. 登録から外したいメンバーの横にある削除ボタンをクリックしてください。
5. ご自身だけを登録する場合は、このステップを飛ばして構いません。

## ステップ3：オプションと選択項目を選ぶ（提供されている場合）

イベントによっては、Tシャツ、食事、アクティビティのアップグレードなど、有料の追加オプションが用意されている場合があります。

1. イベントに選択項目がある場合、**オプションと選択項目**のステップが表示されます。
2. 数量の＋／−ボタンを使って、各オプションの数を選んでください。無料のオプションには**無料**と表示され、数量が限られているオプションには残数が表示されます。
3. **続ける**をクリックします。

## ステップ4：質問に答える（質問がある場合）

イベントによっては、食事制限、Tシャツのサイズ、緊急連絡先など、登録者に追加の質問への回答を求める場合があります。

1. イベントに質問が設定されている場合、次に**質問**のステップが表示されます。
2. 回答を入力して、次に進んでください。

イベントに質問が設定されていない場合、このステップは自動的にスキップされます。

## ステップ5：支払う（有料イベントの場合）

登録に費用がかかる場合、**支払い**のステップに**注文内容**が表示されます。ここには、参加者ごとの内容、選択したオプション、割引、そして**合計**が一覧で示されます。

- **割引コード** — 教会からコードを受け取っている場合は、入力して**適用**をクリックしてください。割引はすぐに反映されます。コードの有効期限が切れている場合、まだ利用開始前の場合、または参加人数の条件を満たしていない場合は、その旨が明確に表示されます。
- **ログイン中のメンバー**は、保存済みのカードで支払うか、**新しいカードを使用**を選べます。
- **ゲスト**は、カード情報を直接入力し、支払い前に**私はロボットではありません**のチェックを入れてください。

**支払いと登録**をクリックすると、支払いと登録が一度に完了します。カード情報は教会の決済サービスに直接送信され、B1 が保存することはありません。

無料の登録の場合、このステップは省略され、すぐに確認画面に進みます。

教会がオンラインでの支払いを受け付けていない場合、支払いのステップには *「このイベントではオンライン決済はご利用いただけません。今すぐ登録し、教会に直接お支払いいただけます。」* と表示されます。**登録して後で支払う**をクリックして完了してください。登録は、支払うべき残高として表示された金額とともに保存されます。残高は教会に直接お支払いください。

## ステップ6：確認

イベントの詳細と、登録したすべての方の一覧を含む確認メッセージが表示されます。また、アカウントに登録されているメールアドレス（ゲストの場合は入力したメールアドレス）宛に**確認メール**も届きます。

## 補欠待ちリストへの参加

イベントが満席で、教会が補欠待ちリストを有効にしている場合、最初のステップに *「このイベントは満席です。補欠待ちリストに参加すると、空きが出たときにご連絡します。」* と表示されます。通常どおり申し込みを進めてください。補欠待ちの間は支払いがスキップされます。空席が出ると、メールが届きます。支払いが必要な場合は、支払い用のリンクも含まれています。ステータスの確認や支払いは、[マイ登録](./my-registrations)から行うこともできます。

## 登録の変更・キャンセル

ログインしている場合は、メンバーポータルの**登録**ページから、ご自身で登録を編集またはキャンセルできます。詳しくは[マイ登録](./my-registrations)をご覧ください。ゲストの方は教会の事務所にお問い合わせください。スタッフは B1 Admin の登録ページから変更できます。
