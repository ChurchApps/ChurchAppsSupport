# イベントへの登録

<div class="article-intro">

教会でイベントの登録が有効になっている場合、簡単なステップに沿って申し込みができます。アカウントをお持ちの方もゲストとしてご利用の方も、ご自身と家族を登録できます。有料イベントでは、参加者の種類を選び、任意のオプションを追加し、割引コードを適用して、最後に安全にお支払いいただけます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- イベントの登録機能が、所属する教会で有効になっている必要があります
- 登録期間内である必要があります（管理者が設定した開始日と終了日の間）

</div>

## ステップ1：情報の入力

1. 教会のカレンダーから登録したいイベントを開き、**このイベントに登録**をクリックします。
2. 登録ページが開き、イベント名、説明、日付が表示されます。複数日にわたるイベントの場合は、開始日と終了日の両方が表示されます。
3. **ログイン済み**の場合、フォームにお名前が表示され、アカウントで登録されることが確認できます。
4. **ゲスト**（ログインしていない場合）の場合は、以下を入力してください：
   - **名**（必須）
   - **姓**（必須）
   - **メールアドレス**（必須）
   - **電話番号**（任意）
5. イベントに参加者の種類がある場合（例：大人と子どもで料金が異なる）、**ご自身の登録の種類**を選びます。各種類に料金が表示され、売り切れの種類には**売り切れ**と表示されます。

:::info
イベントに定員がある場合、残りの空席数がプログレスバーで表示されます。イベントが満席で、教会がキャンセル待ちを有効にしている場合でも、申し込みを完了するとキャンセル待ちに参加できます。詳しくは下記の[キャンセル待ちへの参加](#joining-a-waitlist)をご覧ください。
:::

## ステップ2：家族の追加

1. 家族も一緒に登録する場合は、一人ずつ**名**と**姓**を入力します。
2. イベントに参加者の種類がある場合は、追加する方ごとに種類を選びます。
3. **メンバーを追加**をクリックすると、さらに登録できます（合計10名まで）。
4. 登録から外したいメンバーの横にある削除ボタンをクリックします。
5. ご自身だけを登録する場合は、このステップを省略できます。

## ステップ3：オプションと選択項目（提供されている場合）

イベントによっては、有料の追加オプションが用意されています。例：Tシャツ、食事、アクティビティのアップグレードなど。

1. イベントに選択項目がある場合、**オプションと選択項目**のステップが表示されます。
2. 数量の増減ボタンを使って、それぞれ必要な数を選びます。無料のオプションには**無料**と表示され、数に限りのあるオプションには残り数が表示されます。
3. **続ける**をクリックします。

## ステップ4：質問への回答（質問がある場合）

イベントによっては、登録者に追加の質問への回答を求めることがあります。食事制限、Tシャツのサイズ、緊急連絡先などがその例です。

1. イベントに質問が設定されている場合、次に**質問**のステップが表示されます。
2. 回答を入力して次に進みます。

イベントに質問が設定されていない場合、このステップは自動的に省略されます。

## ステップ5：支払い（有料イベント）

登録に費用がかかる場合、**支払い**のステップに**注文内容**が表示されます。参加者ごと、選択項目ごと、割引、そして**合計**が一覧で確認できます。

- **割引コード** -- 教会からコードを受け取っている場合は、入力して**適用**をクリックします。割引はすぐに反映されます。コードの有効期限が切れている場合、まだ有効になっていない場合、または参加者数の条件を満たしていない場合は、その旨がはっきりと表示されます。
- **ログイン済みのメンバー**は、保存済みのカードで支払うか、**新しいカードを使用**を選べます。
- **ゲスト**は、カード情報を直接入力し、支払い前に**私はロボットではありません**のチェックボックスにチェックを入れます。

**支払いと登録**ボタンをクリックすると、支払いと登録を一度に完了できます。ボタンには合計金額が表示されます（例：**25.00ドルを支払い、登録**）。カード情報は教会の決済サービスに直接送信され、B1が保存することはありません。

無料で登録する場合、このステップは省略され、すぐに確認画面に進みます。

教会がオンライン決済を受け付けていない場合、支払いのステップには次のように表示されます。*「このイベントではオンライン決済は利用できません。今すぐ登録し、教会に直接お支払いいただけます。」* 完了するには**登録して後で支払う**をクリックします。登録は、表示された金額が未払い残高として保存されます。残高は教会に直接お支払いください。

## ステップ6：確認

確認メッセージに、イベントの詳細と登録したすべての方の一覧が表示されます。また、アカウントに登録されているメールアドレス（ゲストの場合は入力したメールアドレス）宛てに、**確認メール**が届きます。

**登録して後で支払う**を選んだ場合、メンバーポータルには代わりに**登録保留中**と表示されます。**保留中**のバッジが付き、「あなたの席は次の期間まで確保されています」というメッセージとともに、未払い残高（例：「未払い残高 25.00ドル / 合計 25.00ドル」）が表示されます。

登録が完了すると、グループのページにある**登録**リンクは、あなたの状態（**登録済み**、**保留中**、または**キャンセル待ち**）に置き換わります。また、ホーム画面の**今後のイベント**に、**登録**のタグ付きでイベントが表示されます。

## キャンセル待ちへの参加

イベントが満席で、教会がキャンセル待ちを有効にしている場合、最初のステップに次のメッセージが表示されます。*「このイベントは満席です。キャンセル待ちに参加いただければ、空きが出たときにご連絡します。」* 通常どおり申し込みを完了してください。キャンセル待ちの間は支払いはスキップされます。空席が出ると、メールが届きます。支払いが必要な場合は、支払いを完了するためのリンクが含まれています。登録状況の確認や支払いは、[マイ登録](./my-registrations.md)からも行えます。

## 登録の変更またはキャンセル

ログインしている場合は、メンバーポータルの**登録**ページから、ご自身で登録の編集またはキャンセルができます。詳しくは[マイ登録](./my-registrations.md)をご覧ください。ゲストの方は教会の事務所にお問い合わせください。スタッフは、B1 Adminの登録ページから変更を行えます。
