# プロフィールの編集

<div class="article-intro">

メンバーポータルのプロフィールページでは、連絡先情報の更新、世帯の管理、アカウントのメールアドレスとパスワードの変更、住所・電話番号・メールアドレスを誰に表示するかの設定ができます。

</div>

## プロフィールを開く

上部のアプリバーにあるプロフィール写真をタップするか、**その他**ページの上部、または[マイページ](./me-page.md)にある**プロフィールを編集**をタップすると、`/mobile/profileEdit` の**あなたのプロフィール**が開きます。このページは複数のセクションからなる1枚のシートで、**写真と名前**、**連絡先**、**世帯**、**アカウント**、**プライバシー**の各セクションがあります。各セクションには現在の情報が表示され、**編集**リンク（または**家族を追加** / **変更**）があります。これをタップすると、変更を行うためのパネルが開きます。

## 写真・名前と連絡先

これらのセクションには、教会があなたの人物レコードで確認できる情報が含まれます。

- **写真と名前** — **写真を変更**をタップして新しい写真をアップロードし、名（First）、ミドルネーム（Middle）、姓（Last）を編集できます。
- **連絡先** — メールアドレス、携帯電話、自宅電話、勤務先電話、生年月日、住所（番地、市区町村、都道府県、郵便番号）。[通知設定](./notification-preferences.md)でテキストメッセージによるリマインダーをオンにすると、携帯電話番号に届きます。

パネルで変更を行い、**変更を保存**をタップします。

:::info
教会がディレクトリの変更に承認を必要としている場合、ページには「プロフィールへの変更は教会のスタッフに送られ、承認されます。」と表示され、ボタンには**承認のために送信**と表示されます。編集内容は即座に反映されず、リクエストとして送信されます。教会がこれをどのように確認するかについては、[プロフィール変更の承認](/docs/b1-admin/profile/approving-profile-changes)を参照してください。
:::

## 世帯

「世帯」セクションには、あなたの世帯に紐づいている他の方々が、それぞれの世帯内の役割（世帯主、配偶者、子どもなど）とともに表示されます。世帯のメンバーをタップすると、詳細を確認できます。

まだシステムに登録されていない家族を追加するには、**家族を追加**をタップし、その方の名前を入力して**追加**をタップします。新しい家族は保留中のリストに追加され、他のプロフィール変更とあわせて教会による確認のために送信されます。

## アカウント

「アカウント」セクションでは、教会のプロフィールではなく、ログインに関する情報を管理します。**編集**をタップして開きます。

- **表示名** — ログイン時に表示される名前（姓と名）。教会のプロフィールの名前とは別に設定できます。
- **メールアドレスを変更** — ログインに使用するメールアドレスを更新します。
- **パスワードを変更** — 現在のパスワードを入力し、新しいパスワードを2回入力します。新しいパスワードは8文字以上である必要があります。

各項目には、それぞれ**保存**ボタンがあります。

## プライバシー

「プライバシー」セクションでは、ChurchApps 全体であなたの連絡先情報を誰が閲覧できるかを表示します。**変更**をタップして**表示設定**を開きます。

- **メンバーディレクトリに表示しない** — オンにすると、[メンバーディレクトリ](../community/member-directory.md)からあなたの情報が完全に削除されます。
- **住所の表示範囲**、**電話番号の表示範囲**、**メールアドレスの表示範囲** — それぞれに個別のドロップダウンがあるため、例えばメールアドレスは教会全体に共有しつつ、住所はより非公開にするといった設定ができます。選択肢は次のとおりです。

| レベル | 閲覧できる人 |
|---|---|
| **全員** | ディレクトリを閲覧できるすべての人に表示されます。 |
| **会員のみ** | ログインしている他の教会メンバーに表示されます。 |
| **自分のグループのみ** | 自分が所属するグループのメンバーのみに表示されます。 |
| **自分のグループのリーダーとスタッフ** | 教会スタッフと、自分が所属するグループのリーダーのみに表示されます。 |
| **スタッフのみ** | 教会スタッフ（スタッフの会員ステータスまたは「人物」の閲覧権限を持つ人）のみに表示されます。 |

**保存**をタップして選択内容を適用します。教会は3つの項目それぞれにデフォルト設定を定めており（[モバイルアプリの設定](/docs/b1-admin/settings/mobile-app)を参照）、ここで選んだ内容は、あなた自身の情報についてはそのデフォルトより優先されます。

:::tip
これらの設定にかかわらず、ご自身の情報は常に表示されます。また、「人物」の閲覧権限を持つスタッフも常に閲覧できます。
:::
