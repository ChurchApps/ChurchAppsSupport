# プロフィールの編集

<div class="article-intro">

メンバーポータルのプロフィールページでは、連絡先情報の更新、世帯メンバーの管理、アカウントのメールアドレスとパスワードの変更ができます。また、住所、電話番号、メールアドレスを誰に表示するかも設定できます。

</div>

## プロフィールを開く

画面上部のアプリバーにあるプロフィール写真をタップするか、**その他**ページまたは[マイページ](./me-page.md)上部の**プロフィールを編集**をタップすると、`/mobile/profileEdit` の**あなたのプロフィール**が開きます。このページは「**写真と名前**」「**連絡先**」「**世帯**」「**アカウント**」「**プライバシー**」のセクションで構成されています。各セクションには現在の情報が表示されており、**編集**のリンク（または**家族を追加** / **変更**）から変更用のパネルを開けます。

## 写真と名前、連絡先

これらのセクションには、教会が個人の記録として把握する情報が含まれます。

- **写真と名前**：**写真を変更**をタップして新しい写真をアップロードできるほか、**敬称**、名（ファースト）、ミドルネーム、姓（ラスト）を編集できます。**敬称**は候補（Mr、Mrs、Miss、Ms、Dr、Prof、Rev、Pastor）から選ぶか、10文字以内で自由に入力できます。
- **連絡先**：メールアドレス、携帯電話、自宅電話、勤務先電話、生年月日、住所（番地、市区町村、都道府県、郵便番号）。[通知設定](./notification-preferences.md)でテキストによるリマインダーをオンにすると、携帯電話番号に送られます。

パネルで変更を入力し、**変更を保存**をタップしてください。

:::info
教会がディレクトリの変更に承認を求めている場合、ページには「プロフィールの変更は教会スタッフの承認に回されます。」と表示され、ボタンは**承認を申請**になります。この場合、編集内容はすぐには反映されず、申請として送信されます。教会による確認の方法については、[プロフィール変更の承認](/docs/b1-admin/profile/approving-profile-changes)をご覧ください。
:::

## 世帯

世帯セクションには、あなたの世帯に紐づく他のメンバーが、世帯内の役割（世帯主、配偶者、子どもなど）とともに表示されます。世帯メンバーをタップすると詳細を確認できます。

まだシステムに登録されていない家族を追加するには、次の手順に従ってください。

1. **家族を追加**をタップします。
2. **名（ファースト）**を入力します。**姓（ラスト）**にはあなたの姓が初期値として入っているので、異なる場合は変更してください。
3. 必要に応じて**敬称**と**携帯電話**を入力します。
4. **世帯内の役割**を選びます。**世帯主**、**配偶者**、**子ども**、**その他**（初期値）から選べます。
5. **追加**をタップします。追加したメンバーは役割とともに**保留中の家族**に表示されます。リストから外すには**削除**をタップします。他にも追加する場合は繰り返してください。
6. **変更を保存**（または**承認を申請**）をタップします。

教会がディレクトリの変更を確認している場合、新しい家族は他の変更とあわせて申請され、教会の承認を待ちます。それ以外の場合は、保存するとすぐに世帯に追加されます。

## アカウント

アカウントセクションでは、教会のプロフィールではなく、ログインに関する情報を管理します。**編集**をタップして開いてください。

- **表示名**：ログイン時に表示される姓名です（教会のプロフィールに表示される名前とは別に設定できます）。
- **メールアドレスを変更**：サインインに使用するメールアドレスを更新します。
- **パスワードを変更**：現在のパスワードを入力し、新しいパスワードを2回入力します。新しいパスワードは8文字以上にする必要があります。

それぞれの項目には個別の**保存**ボタンがあります。

## プライバシー

プライバシーセクションでは、ChurchApps全体で誰があなたの連絡先情報を見られるかを確認できます。**変更**をタップすると**表示設定**が開きます。

- **メンバーディレクトリから自分を非表示にする**：オンにすると、[メンバーディレクトリ](../community/member-directory.md)からあなたの情報が完全に削除されます。
- **住所の公開範囲**、**電話番号の公開範囲**、**メールアドレスの公開範囲**：それぞれ個別のドロップダウンで設定できます。たとえば、メールアドレスは教会全体に公開しつつ、住所はより限定的にすることができます。選択肢は次のとおりです。

| 公開レベル | 閲覧できる人 |
|---|---|
| **全員** | ディレクトリを閲覧できる全員に表示されます。 |
| **会員のみ** | サインイン済みの他の教会メンバーに表示されます。 |
| **自分のグループのみ** | 参加しているグループのメンバーのみに表示されます。 |
| **自分のグループのリーダーとスタッフ** | 教会スタッフと、参加しているグループのリーダーのみに表示されます。 |
| **スタッフのみ** | 教会スタッフ（スタッフの会員ステータスまたは名簿の閲覧権限を持つ人）のみに表示されます。 |

選択内容を適用するには**保存**をタップしてください。3つの項目それぞれには教会がデフォルト値を設定しています（[モバイルアプリの設定](/docs/b1-admin/settings/mobile-app)をご覧ください）。ただし、ここで選んだ設定は、あなたの記録についてはそのデフォルト値より優先されます。

:::tip
この設定に関係なく、ご自身の情報は常に見ることができます。また、名簿の閲覧権限を持つスタッフも常に閲覧できます。
:::
