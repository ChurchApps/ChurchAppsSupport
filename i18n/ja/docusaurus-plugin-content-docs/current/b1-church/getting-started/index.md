# B1.church を始める

<div class="article-intro">

B1.church は、あなたの教会のオンラインの拠点です。ここでは、教会の仲間とのつながりを保ち、最新情報を確認し、オンラインで献金し、礼拝のチェックインを行うなど、さまざまなことができます。このセクションでは、メンバーポータルへのアクセスと基本的な使い方を説明します。

</div>

## 教会のサイトにアクセスする

教会には専用の B1.church URL があり、通常は `https://yourchurchname.b1.church` の形式です。このURLには、パソコン、タブレット、スマートフォンのどのウェブブラウザからでもアクセスできます。正確なアドレスは、教会の役員またはウェルカムチームにお尋ねください。

初めてサイトを開くと、教会独自のブランドデザイン、ナビゲーションメニュー、コンテンツページを備えた、教会の公開ウェブサイトが表示されます。

## アカウントを作成する

メンバーポータルとその機能を利用するには、ChurchApps アカウントが必要です。

1. 教会の B1.church URL にアクセスします。
2. ページ右上の **ログイン** ボタンをクリックします。
3. ログイン画面で、新規アカウントを **登録** するオプションを選択します。
4. **名**、**姓**、**メールアドレス**を入力し、**パスワード**を設定します。
5. 登録フォームを入力して完了します。

登録後は、ログインしてメンバーポータルのすべてのツールを利用できます。

:::tip
教会がすでにあなたを登録システムに追加している場合は、教会に登録されているものと同じメールアドレスを使用してください。そうすると、アカウントが既存の教会プロフィールと紐づけられます。
:::

## できること

ログインすると、メンバーポータルで次のことができます。

- 奉仕、グループ、献金の概要を表示する **ホーム** ダッシュボードと、あなたの今後の予定を表示する **自分** ページ
- 参加している **グループ**（会話やイベントを含む）
- 寄付のための **オンライン献金**
- 奉仕のスケジュールや礼拝の詳細を示す **プラン**
- 礼拝やイベントの **チェックイン**
- 他のメンバーを探してつながるための **コミュニティ** のディレクトリ

## スマートフォンでの利用

B1.church は、どのモバイルブラウザでも利用できます。よりアプリに近い操作感を得るには、教会のメンバーポータルを **プログレッシブウェブアプリ（PWA）** としてインストールしてください。デバイスごとの手順は `https://yourchurchname.b1.church/mobile/install` で案内されています。Safari または Chrome から直接ホーム画面に追加することもできます。アプリストアは必要ありません。手順については [アプリとしてインストール（PWA）](./installing-pwa.md) を参照してください。
