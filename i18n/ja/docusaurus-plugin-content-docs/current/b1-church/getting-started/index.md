# B1.church のはじめに

<div class="article-intro">

B1.church は、教会のオンラインの拠点です。信徒の皆さまが教会とのつながりを保ち、お知らせを確認し、オンラインで献金し、礼拝やイベントのチェックインを行うなど、さまざまなことができる場所です。このセクションでは、メンバーポータルへのアクセスと基本的な使い方を説明します。

</div>

## 教会のサイトにアクセスする

教会には専用の B1.church URL があり、通常は `https://yourchurchname.b1.church` の形式です。このURLには、パソコン、タブレット、スマートフォンのどのウェブブラウザからでもアクセスできます。正確なアドレスは、教会の役員や受付チームにお尋ねください。

初めてサイトにアクセスすると、教会独自のブランディング、ナビゲーションメニュー、コンテンツページを備えた公開ウェブサイトが表示されます。

## アカウントを作成する

メンバーポータルとその機能を利用するには、ChurchApps アカウントが必要です。

1. 教会の B1.church URL にアクセスします。
2. ページ右上の **Login** ボタンをクリックします。
3. ログイン画面で **Register** を選び、新しいアカウントを登録します。
4. **名（ファースト ネーム）**、**姓（ラスト ネーム）**、**メールアドレス** を入力し、**パスワード** を設定します。
5. 登録フォームの入力を完了します。

登録後、ログインすると、すべてのツールを備えたメンバーポータルを利用できます。

:::tip
教会がすでにあなたを登録している場合は、教会の記録にあるものと同じメールアドレスを使用してください。そうすると、アカウントが既存の教会プロフィールと紐づけられます。
:::

## できること

ログインすると、メンバーポータルでは次のことができます。

- サービスや グループ、寄付の概要を表示する **Home** ダッシュボードと、参加予定の内容を確認できる **Me** ページ
- 参加している **Groups**（会話やイベントを含む）
- 寄付のための オンライン **Giving**
- ボランティアのスケジュールや礼拝の詳細を示す **Plans**
- 礼拝やイベントの **Check-In**
- 他のメンバーを探してつながるための **Community** ディレクトリ

## スマートフォンでアクセスする

B1.church は、どのモバイルブラウザでも利用できます。よりアプリに近い操作感を求める場合は、教会のメンバーポータルを **プログレッシブ ウェブ アプリ（PWA）** としてインストールできます。機種ごとの手順は `https://yourchurchname.b1.church/mobile/install` で確認できます。または、Safari や Chrome から直接ホーム画面に追加することもできます。アプリストアは必要ありません。手順について詳しくは、[アプリとしてインストール（PWA）](./installing-pwa.md) をご覧ください。

:::info
旧ネイティブアプリの B1 Mobile は提供終了となりました。今後スマートフォンで B1.church を利用するには PWA をお使いください。過去のドキュメントについては、[B1 Mobile リファレンスページ](/docs/b1-church/index.md) をご覧ください。
:::
