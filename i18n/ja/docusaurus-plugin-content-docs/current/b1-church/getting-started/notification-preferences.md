# 通知設定

<div class="article-intro">

通知設定では、教会から受け取る通知の種類と、その受け取り方を選べます。受け取り方は、プッシュ通知、メール、アプリ内のベルアイコン、そして教会がテキストメッセージを送信している場合はテキストメッセージから選択できます。通知の種類ごとに細かく調整したり、通知を控える時間帯を設定したり、すべての通知を一度にミュートしたりできます。これらはすべて1つの画面で行えます。

</div>

## 通知設定を開く

1. **Me**ページに移動し、名前の下にある**設定**をタップします。

ベルアイコンをタップし、**すべて表示**をタップして受信トレイを開き、そのページ上部の**通知設定**をタップすることもできます。

## 全体の設定

画面上部には、すべての通知に適用される設定があります。

- **すべてミュート** -- 重要ではないすべての通知を一時的に停止します。
- **プッシュ通知** -- お使いのデバイスでプッシュ通知をオンまたはオフにします。
- **テキストメッセージ** -- 教会がテキストメッセージを設定している場合にのみ表示されます。オンにすると、奉仕やイベントのリマインダーが、プロフィールに登録された携帯電話番号にテキストメッセージで届きます。初期状態ではオフになっており、オンにするまで届きません。
- **メールの頻度** -- メール通知の届き方を選択します。
  - **通知ごと** -- 出来事が発生するたびにメールを送信します。
  - **1日のダイジェスト** -- 通知をまとめて、1日1通のメールで送信します。
  - **受け取らない** -- 通知メールを送信しません。
- **通知を控える時間帯** -- 邪魔されたくない時間帯の開始時刻と終了時刻（およびタイムゾーン）を設定します。緊急ではない通知は、この時間帯が終わるまで保留されます。

## 通知の種類ごとの選択

全体の設定の下には、通知の種類の一覧があります。それぞれについて、受け取りたい方法をオンまたはオフに設定できます。

- **プッシュ** -- お使いのデバイスに届く通知です。
- **メール** -- 受信トレイに届くメッセージです。
- **アプリ内** -- アプリ内のベルアイコンやバッジで表示されます。
- **テキスト** -- 携帯電話に届くテキストメッセージです。この列は、教会がテキストメッセージを設定している場合にのみ表示されます。また、テキストメッセージを送信できるのは一部の種類（**イベントのリマインダー**、**奉仕とスケジュール**、**タスクとフォローアップ**など）に限られます。テキストは、**テキストメッセージ**もオンになっている場合にのみ届きます。

よくある通知の種類には、**イベントのリマインダー**、**奉仕とスケジュール**、**ダイレクトメッセージ**、**グループチャット**、**祈りのリクエスト**、**教会からのお知らせ**があります。たとえば、ダイレクトメッセージのプッシュ通知はオンのままにし、お知らせのプッシュ通知はオフにする、といった設定ができます。

:::info
一部の通知の種類は**常にオン**で、オフにはできません。対象は、**アカウントとセキュリティ**、**献金の領収書と明細**、**チェックインの安全通知**です。これらはセキュリティ上および法的な理由から必要なため、小さなロックアイコンが表示されます。それ以外の通知は、すべてご自身で管理できます。
:::

一部の通知の種類（販促や募金に関するメッセージなど）は**初期状態でオフ**になっており、ご自身がオプトインした場合にのみ届きます。

## テキストメッセージの受け取りを停止する

テキストメッセージを受け取らないようにするには、**テキストメッセージ**をオフにして保存します。また、教会から届いたテキストメッセージに**STOP**と返信すると、その番号を教会からのテキストメッセージ配信から除外できます。

## 変更を保存する

通知設定を調整したら、**設定を保存**をタップします。変更はすぐに反映され、B1を利用するすべての場所に適用されます。

:::tip
セキュリティに関するアラートや、子どものチェックインの安全に関するメッセージなど、緊急性の高い通知は、通知を控える時間帯であっても届きます。日常的な更新は、その時間帯が終わるまで保留されます。
:::
