# B1Appの操作方法

<div class="article-intro">

B1.churchの会員ポータルは、スマートフォン向けに作られたWebアプリで、`/mobile`で提供されています。どのブラウザでも利用でき、ホーム画面に追加することもできます。このページでは、ホームダッシュボード、画面下部のタブバー、「その他」ページ、「自分」ページについて説明します。

</div>

## ホーム {#home}

`https://yourchurchname.b1.church/mobile`を開くと、`/mobile/dashboard`の**ホーム**ダッシュボードが表示されます。ホームは会員ポータルのトップページです。最初に「おはようございます」「こんにちは」「こんばんは」のあいさつと名前、今日の日付が表示されます。その下には、該当する場合のみ表示されるセクションが続きます。

- **写真タイル** -- 教会が写真を設定したタブ（今日のみことばを含む）が、教会名の下に写真タイルとして表示されます。教会の設定によって、2列のグリッド、横にスワイプできる列（自動で動くこともあります）、または各項目の横に小さなサムネイルが付いたリストのいずれかで表示されます。詳しくは[ホーム画面のタイル](../../b1-admin/settings/mobile-app.md#home-screen-tiles)を参照してください。タブバーに表示枠がある写真タブも、すべてここに表示されます。
- **最新の説教** -- 教会の最新の説教です。**すべての説教**リンクがあります。
- **今日のみことば** -- 今日のみことばです。タップすると、[今日のみことば](../content/verse-of-the-day.md)の全ページが開きます。
- **奉仕予定** -- 直近の奉仕の割り当てです。**すべての計画**リンクがあります。まだ返答が必要な割り当てがある場合は、それが先頭に表示され、**返答待ち**のバッジと**承諾**・**辞退**ボタンが付きます。ホームから直接返答できます（**辞退**を押すと、まず確認が表示されます）。返答が必要な割り当てがない場合は、直近の割り当てに**承諾済み**または**確定**のバッジが表示されます。割り当てをタップすると、その計画が開きます。
- **あなたのグループ** -- 参加しているグループのうち最大3つを、集会の時間と場所とともに表示します。**すべてのグループ**リンクもあります。
- **今後のイベント** -- サインインしている場合、参加しているグループの直近3件のイベントを、日付と時間とともに表示します（イベントに写真がある場合はサムネイルも表示されます）。イベントをタップすると、そのグループのイベント一覧が開きます。**今後のイベントをすべて表示**をタップすると、[自分ページ](./me-page.md#upcoming)の今後のイベント一覧が開きます。この一覧には、奉仕の割り当てと申し込みも含まれます。
- **自分の出席**と**自分のフォーム** -- 教会がこれらを有効にしている場合に表示されます。出席は直近90日間の回数と直近2回の訪問を、フォームは直近2件の提出を表示し、それぞれ全件の一覧へのリンクがあります。これらは教会の設定に関係なく、[自分ページ](./me-page.md)には常に表示されます。詳しくは[ホーム画面のセクション](../../b1-admin/settings/mobile-app.md#home-screen-sections)を参照してください。
- **献金** -- 今年（現在の年）の献金額、**献金する**ボタン（教会がオンライン献金を提供している場合のみ表示）、そして[献金履歴](../giving/donation-history.md)への**履歴**リンクを表示します。教会が会員の献金履歴の表示期間を過去の年に制限している場合や、献金履歴を非表示にしている場合は、このセクションは表示されません。その代わりに、教会の献金ツールが**その他の機能**の下にボタンとして表示されます。
- **その他の機能（*教会名*から）** -- タブバーや上のセクションにまだ表示されていない、教会が有効にしたその他のツールのボタンです。よく使うものほど先頭に表示されます。

奉仕、グループ、出席、フォーム、献金のセクションは、サインインしていて、教会がそのツールを有効にしていて、表示する内容がある場合（例：今後の割り当てや、少なくとも1つのグループ）にのみ表示されます。パソコンでは、ホームは2列でレイアウトされます。

サインインしていない場合、ホームでは、あいさつの代わりに**ようこそ**という見出しが表示され、短い案内文（「サインインすると、グループや献金などを確認できます。」）と**サインイン**ボタンが表示されます。教会がホームに何も設定していない場合でも、この案内文は表示されます。教会はこの案内文の文言を変えたり、非表示にしたりできます。詳しくは[モバイルアプリの設定](../../b1-admin/settings/mobile-app.md#home-screen-sign-in-prompt)を参照してください。案内文が非表示になっている場合でも、**その他**ページまたは**自分**ページからサインインできます。

## 画面下部のタブバー

スマートフォンでは、画面の下部にタブバーが固定されています。

- **ホーム** -- 常に最初のタブです
- 教会が設定したタブのうち最大3つ
- **その他** -- 「その他」ページを開きます

グループ、献金、計画などの組み込み画面は、先にタブの枠を使います。余った枠は、教会が作成したカスタムページに割り当てられます。外部サイトへのリンクと今日のみことばには、タブが割り当てられることはありません。教会が設定したタブの数が表示枠を超える場合でも、残りのタブは失われません。それらは**その他**ページと、ホームの**その他の機能**に表示されます。教会の管理者は、B1 Adminの**モバイル → ナビゲーション**で、タブの並び順を設定します。

## パソコンでの表示

パソコンやタブレットなど、画面が広い場合は、画面下部のタブバーの代わりに、画面上部にヘッダーが表示されます。ヘッダーの色は教会のテーマカラーです。ヘッダーには、教会のロゴ（ロゴが未設定の場合は教会名）が表示されます。これをクリックするとホームに戻ります。その右側には**ホーム**、教会が設定したタブのうち最大5つ、**その他**が並び、右端には通知のベルとプロフィール写真があります。詳細画面を開くと、ページ内容の上に**戻る**リンクが表示されます。

## 「その他」ページ

**その他**をタップすると、`/mobile/more`の「その他」ページが開きます。このページには次の内容があります。

- あなたの名前と写真、および**プロフィールを編集**リンク -- 詳しくは[プロフィールの編集](./editing-your-profile.md)を参照してください
- 教会が設定したすべてのタブ（順番どおり）。教会名の下に表示されます。外部サイトへのリンクは、ブラウザの新しいタブで開きます。
- **アカウント**セクション（次の項目を含みます）
  - **自分** -- あなた個人のページです（サインイン時のみ）
  - **表示設定** -- **ライトモード**と**ダークモード**を切り替えます
  - **管理ポータル** -- 教会で管理者権限がある場合のみ表示されます。B1 Adminが新しいタブで開きます
  - **アプリをインストール** -- `/mobile/install`の[インストール手順](./installing-pwa.md)を開きます（アプリがインストール済みの場合は非表示になります）
- **サインアウト**。サインインしていない場合は**サインイン**ボタンが表示されます
- 教会名と、プライバシーポリシーへのリンク

## アプリバー

スマートフォンでは、すべての画面の上部のバーに次の内容が表示されます。

- ホームやそのほかの主要画面では、教会のロゴ（教会がロゴをアップロードしていない場合は教会名）が表示されます。詳細画面に進んでいる場合は、戻る矢印が表示されます。画面のタイトルはページ上部に表示されます。
- 通知とメッセージのための**ベル**アイコン。未読がある場合はバッジが表示されます。詳しくは下の[通知とメッセージ](#notifications-and-messages)を参照してください。
- あなたの**プロフィール写真**。タップすると、`/mobile/profileEdit`のプロフィールが開きます。詳しくは[プロフィールの編集](./editing-your-profile.md)を参照してください。

ベルとプロフィール写真は、サインインしている場合のみ表示されます。

## 通知とメッセージ

ベルをタップすると、2つのセクションを持つパネルが開きます。

- **メッセージ** -- 直近の個人的な会話が表示されます。**新しいメッセージ**リンクから、新しい会話を始めることもできます。
- **通知** -- 直近の通知が表示されます。未読の通知には**新着**バッジが付きます。通知をタップすると、その通知の元となったグループ、計画、または会話に移動します。

各セクションには、未読の件数が表示されます。一番下の**すべて表示**をタップすると、`/mobile/notifications`の受信箱全体が開きます。

## セクションで構成されたページ

グループ、計画、自分ページ、計画と献金の画面などの詳細ページは、タブではなく、セクションで区切られた1ページとして表示されます。各セクションには短いプレビューが表示されます。セクションの見出しにあるリンク（**全メンバー**、**すべてのイベント**、**礼拝の全順序**など）をタップすると、全件の一覧が開きます。その画面の上部にある**戻る先**リンクで、元のページに戻ります。

## 自分ページ

**自分**（`/mobile/me`）は、あなた個人のための中心的なページです。あなたの名前と写真、**プロフィールを編集**と**設定**（[通知の設定](./notification-preferences.md)）ボタンが表示されます。その下には、今後の予定（奉仕の割り当て、イベントの申し込み、グループのイベント）が続き、さらに世帯、グループ、今年の[献金](../giving/index.md)、提出したフォーム、出席履歴、[申し込み](../events/my-registrations.md)、最近の通知とメッセージが表示されます。詳しくは[自分ページ](./me-page.md)を参照してください。

サインインしていない場合、自分ページには代わりに**サインイン**ボタンが表示されます。

## ホーム画面へのインストール

会員ポータルはプログレッシブウェブアプリ（PWA）です。`/mobile/install`にアクセスするか（または「その他」ページで**アプリをインストール**を選択して）、お使いの機器に合わせた手順を確認できます。インストールすると、ブラウザの枠のない全画面表示で、ホーム画面から開けるようになります。詳しくは[アプリとしてのインストール（PWA）](./installing-pwa.md)を参照してください。

## 教会の公開ウェブサイト

会員ポータル以外では、教会の公開ウェブサイトに、管理者が設定したヘッダーのナビゲーションがあります。[説教](../content/sermons.md)、[聖書](../content/bible.md)、[ライブ配信](../content/live-streaming.md)、公開グループ一覧などのページへのリンクです。スマートフォンでは、これらのリンクはヘッダー右上のハンバーガーアイコンの中にあります。

:::info
表示されるタブやツールは教会によって異なります。どの機能を会員に表示するかは管理者がB1 Adminで設定します。ここで説明する機能が見当たらない場合は、教会がその機能を有効にしていない可能性があります。
:::
