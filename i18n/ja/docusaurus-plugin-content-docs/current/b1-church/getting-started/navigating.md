# B1Appのナビゲーション

<div class="article-intro">

B1.churchのメンバーポータルは、スマートフォン向けに設計されたWebアプリで、`/mobile`配下にあります。どのブラウザでも動作し、ホーム画面にインストールすることもできます。このページでは、ホームダッシュボード、画面下部のタブバー、「その他」ページ、「自分」ページについて説明します。

</div>

## ホーム {#home}

`https://yourchurchname.b1.church/mobile`を開くと、`/mobile/dashboard`の**ホーム**ダッシュボードが表示されます。ホームはメンバーポータルのトップページです。最初に挨拶（「おはようございます」「こんにちは」「こんばんは」にお名前を添えた表示）と今日の日付が表示され、該当する場合にのみ以下のセクションが続きます：

- **写真タイル** -- 教会が写真を設定したタブ（今日のみことばを含む）は、教会名の下に写真タイルとして表示されます。教会の設定によって、2列のグリッド、横にスワイプできる一列（自動で動くこともあります）、または各名前の横に小さなサムネイルが付いたリストのいずれかで表示されます。詳しくは[ホーム画面のタイル](../../b1-admin/settings/mobile-app.md#home-screen-tiles)をご覧ください。横並びの列に画面に収まらない数のタイルがある場合、その下にドットが並び、現在の位置を示します。ドットをタップすると該当のタイルへ移動します。列は前へ進み続け、最後のタイルの後は最初のタイルに戻ります。タブバーにも表示されているタブであっても、写真付きのタブはすべてここに表示されます。
- **最新の説教** -- 教会の最新の説教です。**すべての説教**へのリンクがあります。
- **今日のみことば** -- 本日のみことばです。タップすると[今日のみことば](../content/verse-of-the-day.md)ページ全体が開きます。
- **奉仕のご予定** -- 直近の奉仕の割り当てです。**すべての計画**へのリンクがあります。まだ返答が必要な割り当てがある場合は、**返答待ち**バッジと**承諾**／**辞退**ボタンが付いて先頭に表示されるので、ホーム画面からそのまま返答できます（**辞退**の場合は先に確認が表示されます）。それ以外の場合は、次の割り当てに**承諾済み**または**確定**のバッジが表示されます。割り当てをタップすると、その計画が開きます。
- **参加中のグループ** -- 参加しているグループのうち最大3件を、開催日時と場所とともに表示します。**すべてのグループ**へのリンクもあります。
- **今後のイベント** -- サインインしている場合、今後のグループイベントとイベント登録の直近3件が、日付順にまとめて表示されます。各項目には日付と時刻が表示されます（イベントに写真がある場合はサムネイルも表示されます）。各行には**イベント**（参加しているグループのイベント）または**登録**（[登録済み](../events/registering.md)のイベント）のラベルが付きます。登録済みのイベントは一度だけ、登録として表示されます。イベントをタップするとそのグループのイベント一覧が、登録をタップすると[登録一覧](../events/my-registrations.md)が開きます。**今後のイベントをすべて表示**をタップすると、[「自分」ページ](./me-page.md#upcoming)で今後の予定の全体が開きます。こちらには奉仕の割り当てや登録も含まれます。
- **出席状況**と**マイフォーム** -- 教会が有効にしている場合、過去90日間の出席回数と直近2回の出席、および直近2件のフォーム提出が表示され、それぞれ全一覧へのリンクがあります。これらは設定に関わらず、常に[「自分」ページ](./me-page.md)にも表示されます。詳しくは[ホーム画面のセクション](../../b1-admin/settings/mobile-app.md#home-screen-sections)をご覧ください。
- **献金** -- 今年の献金額（「今年の献金額」）、**献金する**ボタン（教会がオンライン献金を提供している場合のみ表示）、そして[献金履歴](../giving/donation-history.md)への**履歴**リンクです。教会がメンバーの献金履歴の表示期間を過去の年に限定しているか、非表示にしている場合はこのセクションは表示されません。その場合、教会の献金ツールは**その他の機能**の下にボタンとして表示されます。
- **その他の機能**（*教会名*）-- 教会が有効にしている機能のうち、タブバーや上に表示されていないものがボタンとして並びます。よく使うものほど先頭に移動します。

奉仕、グループ、出席、フォーム、献金のセクションは、サインインしていて、教会がその機能を有効にしており、表示する内容がある場合にのみ表示されます（例：今後の割り当てがある、または少なくとも1つのグループに参加している場合）。パソコンでは、ホームは2列で表示されます。

サインアウトしている場合、ホームには挨拶の代わりに**ようこそ**の見出しと、短い案内文（「サインインすると、グループ、献金などをご覧いただけます。」）、**サインイン**ボタンが表示されます。この案内文は、教会がホーム画面の他の内容をまだ設定していない場合でも表示されます。教会はこの案内文の文言を変更したり、非表示にしたりできます。詳しくは[モバイルアプリの設定](../../b1-admin/settings/mobile-app.md#home-screen-sign-in-prompt)をご覧ください。非表示の場合でも、**その他**ページまたは**自分**ページからサインインできます。

## 画面下部のタブバー

スマートフォンでは、画面の下部にタブバーが固定表示されます：

- **ホーム** -- 常に最初のタブです
- 教会が設定したタブのうち最大3つ
- **その他** -- 「その他」ページを開きます

組み込みの画面（グループ、献金、計画など）が優先的にタブの枠を使い、空いた枠は教会独自のページに割り当てられます。外部サイトへのリンクと今日のみことばには、タブが割り当てられることはありません。教会が設定したタブが表示できる数を超える場合でも、残りのタブは失われません。それらは**その他**ページと、ホームの**その他の機能**に表示されます。教会の管理者は、B1 Adminの**モバイル → ナビゲーション**でタブの順序を設定します。

### フォルダータブ {#folder-tabs}

教会は複数のタブを**フォルダー**にまとめることができます。フォルダーは他のタブと同じように、タブバー、**その他**ページ、またはホームの写真タイルとして表示されます。タップすると、フォルダー名の付いた画面が開き、中に含まれるタブの一覧が表示されます。フォルダー内のすべてのタブに写真がある場合は写真タイルとして表示され、そうでない場合はリストで表示されます。フォルダー内の外部サイトへのリンクは、ブラウザの新しいタブで開きます。フォルダー内のタブは、そのフォルダーの画面にのみ表示され、タブバーや**その他**ページには表示されません。表示できる内容がないフォルダーは非表示になります。

## パソコンで

パソコンや大きめのタブレットなど画面幅が広い場合は、画面下部のタブバーの代わりに、教会のテーマカラーの画面上部ヘッダーが表示されます。ヘッダーには教会のロゴ（ロゴが未設定の場合は教会名）が表示され、クリックするとホームに戻ります。その横に**ホーム**、教会が設定したタブのうち最大5つ、そして**その他**が並び、右側にベルアイコンとプロフィール写真があります。詳細画面を開くと、ページ内容の上に**戻る**リンクが表示されます。

## 「その他」ページ

**その他**をタップすると、`/mobile/more`の「その他」ページが開きます。このページには以下が含まれます：

- お名前と写真、そして**プロフィールを編集**リンク — [プロフィールの編集](./editing-your-profile.md)を参照
- 教会が設定したすべてのタブを、教会名の下に設定順に表示します。外部サイトへのリンクは、ブラウザの新しいタブで開きます。
- **アカウント**セクション。以下を含みます：
  - **自分** -- 個人ページ（サインイン時のみ）
  - **表示設定** -- **ライトモード**と**ダークモード**を切り替えます
  - **管理ポータル** -- 教会で管理者権限がある場合にのみ表示されます。B1 Adminを新しいタブで開きます
  - **アプリをインストール** -- `/mobile/install`の[インストール手順](./installing-pwa.md)を開きます（インストール済みの場合は非表示）
- **サインアウト**、またはサインアウト中の場合は**サインイン**ボタン
- 教会名とプライバシーポリシーへのリンク

## アプリバー

スマートフォンでは、各画面の上部のバーに以下が表示されます：

- ホームやその他の主要画面では教会のロゴ（ロゴが未登録の場合は教会名）、詳細画面を開いている場合は戻る矢印が表示されます。画面のタイトルは、ページ上部に表示されます。
- 通知とメッセージ用の**ベル**アイコン。未読がある場合はバッジが表示されます。下記の[通知とメッセージ](#notifications-and-messages)をご覧ください
- **プロフィール写真**。タップすると`/mobile/profileEdit`のプロフィールが開きます — [プロフィールの編集](./editing-your-profile.md)を参照

ベルとプロフィール写真は、サインインしている場合にのみ表示されます。

## 通知とメッセージ

ベルをタップすると、2つのセクションがあるパネルが開きます：

- **メッセージ** -- 最近の個人的なやり取り。**新しいメッセージ**リンクから新規作成できます
- **通知** -- 最近の通知。未読のものには**新着**バッジが付きます。通知をタップすると、その元となったグループ、計画、またはやり取りへ移動します。

各セクションには未読の件数が表示されます。下部の**すべて表示**をタップすると、`/mobile/notifications`の受信トレイ全体が開きます。

## セクションで構成されたページ

詳細ページ（グループ、計画、「自分」ページ、計画と献金の画面）は、タブではなくセクションを並べた1ページとして表示されます。各セクションには簡単なプレビューが表示され、セクションの見出しにあるリンク（**全メンバー**、**すべてのイベント**、**礼拝の全体の流れ**など）から全一覧を開けます。その表示画面の上部にある**元のページに戻る**リンクで、元のページに戻れます。

## 「自分」ページ

**自分**（`/mobile/me`）は、あなた専用のページです。お名前と写真が表示され、**プロフィールを編集**ボタンと**設定**ボタン（[通知設定](./notification-preferences.md)）があります。その下には、今後の予定（奉仕の割り当て、イベント登録、グループイベント）が表示され、続いて世帯、参加しているグループ、今年の[献金](../giving/index.md)、提出したフォーム、出席履歴、[登録](../events/my-registrations.md)、最近の通知とメッセージが表示されます。詳しくは[「自分」ページ](./me-page.md)をご覧ください。

サインアウトしている場合、「自分」ページには代わりに**サインイン**ボタンが表示されます。

## ホーム画面へのインストール

メンバーポータルはプログレッシブウェブアプリ（PWA）です。お使いの端末向けの手順は`/mobile/install`にアクセスするか（または「その他」ページで**アプリをインストール**を選択）ご確認ください。インストール後は、ブラウザの枠なしで、ホーム画面から全画面で開きます。[アプリとしてインストール（PWA）](./installing-pwa.md)をご覧ください。

## 教会の公開ウェブサイト

メンバーポータルの外にある教会の公開ウェブサイトには、管理者が設定したリンクを含む独自のヘッダーナビゲーションがあります。例えば、[説教](../content/sermons.md)、[聖書](../content/bible.md)、[ライブ配信](../content/live-streaming.md)、公開グループ一覧などのページがあります。スマートフォンでは、これらのリンクはヘッダー右上のハンバーガーアイコンの中にあります。

:::info
教会によって表示されるタブや機能は異なります。管理者はB1 Adminを通じて、メンバーに表示するセクションを管理しています。ここで説明している機能が表示されない場合は、教会がその機能を有効にしていない可能性があります。
:::
