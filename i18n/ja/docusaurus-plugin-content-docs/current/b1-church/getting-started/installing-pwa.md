# PWA としてアプリをインストール

<div class="article-intro">

B1.church は Progressive Web App（PWA）としてのインストールに対応しています。これにより、教会のメンバーポータルをスマートフォンのホーム画面に、ネイティブアプリと同じように追加できます。App Store や Google Play を経由せずに、全画面でアプリのような操作性を利用できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 教会の B1.church URL が必要です：`https://yourchurchname.b1.church`
- 対応ブラウザを使用してください：iOS では **Safari**、Android では **Chrome**

</div>

## PWA とは？

Progressive Web App（PWA）は、デバイスにインストールでき、ネイティブアプリのように動作する Web サイトです。B1.church を PWA としてインストールすると、次のようになります。

- ブラウザのナビゲーションバーを表示せずに全画面で開く
- 教会のアイコンと名前でホーム画面に表示される
- 教会のブランディングやテーマカラーと一貫した見た目で動作する

:::tip
別途 App Store や Google Play からアプリをインストールしたくない場合に、PWA は最適な選択肢です。ブラウザで利用できるのと同じメンバーポータルの機能を、より手軽な形で利用できます。
:::

## インストールページ

インストールするもっとも簡単な方法は、教会専用のインストールページを開くことです。

```
https://yourchurchname.b1.church/mobile/install
```

このページはお使いのデバイスを自動で判別し、適切な手順を表示します。

- **iPhone**：Safari の「ホーム画面に追加」の手順を順番に表示
- **Android**：Chrome の **ホーム画面にインストール** ボタンをタップするだけ
- **デスクトップ**：QR コードが表示されるので、スマートフォンで読み取ってインストールページを開けます

インストールページには、次のいずれかの方法で移動できます。

- メンバーポータルで **その他** をタップし、**アカウント** の下にある **アプリをインストール** をタップする（アプリがインストール済みの場合、この項目は表示されません）
- 教会からテキスト、メール、または日曜日のスクリーンで共有されたリンクをたどる
- ブラウザに URL を直接入力する

:::tip 教会スタッフの方へ
インストールページのリンクを信徒の皆さんと共有してください。週報、ニュースレター、スライドに掲載するのがおすすめです。このページでは、各メンバーのデバイスに合わせた手順を案内します。また、B1Admin のダッシュボードにある **アプリをダウンロード** のクイックアクションからもアクセスできます。
:::

インストールページを使わず、教会の B1.church サイトの **任意のページ** から、下記のブラウザの手順で PWA を手動でインストールすることもできます。インストールページは、その手順を案内してくれる便利なページにすぎません。

インストールしたアプリを起動すると、ログインの準備が整ったメンバーダッシュボードに直接開きます。

## iPhone（iOS・Safari）へのインストール

1. iPhone で **Safari** を開き、`https://yourchurchname.b1.church/mobile/install` にアクセスします（`yourchurchname` は教会の URL スラッグに置き換えてください）。
2. 画面下部の **共有** ボタン（上向きの矢印が付いた四角いアイコン）をタップします。
3. 共有シートを下にスクロールし、**ホーム画面に追加** をタップします。
4. 名前は初期設定で教会の名前になります。右上の **追加** をタップします。

ホーム画面にアプリのアイコンが表示されます。タップすると、メンバーポータルが全画面モードで開きます。

:::info
iOS で PWA をインストールするには Safari が必要です。iPhone で Chrome など別のブラウザを使っている場合は、先に Safari に切り替えてください。
:::

## Android（Chrome）へのインストール

1. Android デバイスで **Chrome** を開き、`https://yourchurchname.b1.church/mobile/install` にアクセスします。
2. **ホーム画面にインストール** ボタンをタップします。（ボタンが表示されない場合は、右上の三点メニュー（⋮）をタップし、**ホーム画面に追加** を選択してください。）
3. 表示されたプロンプトで **追加** をタップします。

ホーム画面にアプリのアイコンが表示されます。タップすると、メンバーポータルが開きます。

## インストール後について

インストールが完了すると、PWA は専用の全画面ウィンドウでメンバーポータルに直接開きます。次のことができます。

- 既存の ChurchApps アカウントでログインする
- 教会が有効にしているすべてのメンバー向け機能（グループ、献金、チェックイン、奉仕計画など）を利用する
- ホーム画面のアイコンをタップして、いつでも戻る

未読のメッセージがあると、アプリのアイコンに **通知バッジ**（小さな数字のバッジ）が表示されます。新しい連絡があるかどうかをひと目で確認できます。

:::info
PWA の利用にはインターネット接続が必要です。一部のネイティブアプリとは異なり、オフラインで使うためにすべてのコンテンツをキャッシュすることはありません。
:::

## 以前の B1 Mobile アプリについて

iOS と Android の従来のネイティブアプリ **B1 Mobile** は非推奨となり、現在は更新されていません。今後、スマートフォンから B1.church のメンバーポータルにアクセスする方法としては PWA がサポートされており、ネイティブアプリが提供していたメンバー向けの機能はすべて含まれています。以前にネイティブアプリをインストールしていた場合は、都合の良いときに PWA に切り替えてください。

非推奨となったアプリの過去のドキュメントについては、[B1 Mobile リファレンスページ](/docs/b1-church/index.md) をご覧ください。
