# アプリとしてインストール (PWA)

<div class="article-intro">

B1.church はプログレッシブウェブアプリ (PWA) としてのインストールに対応しており、教会のメンバーポータルをスマートフォンのホーム画面に、ネイティブアプリと同じように追加できます。App Store や Google Play を経由せずに、全画面表示でアプリのような操作性が得られます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 教会の B1.church URL が必要です: `https://yourchurchname.b1.church`
- 対応ブラウザをご利用ください: iOS では **Safari**、Android では **Chrome**

</div>

## PWA とは？

プログレッシブウェブアプリ (PWA) は、デバイスにインストールでき、ネイティブアプリのように動作するウェブサイトです。B1.church を PWA としてインストールすると、次のようになります。

- ブラウザのナビゲーションバーなしで全画面表示される
- 教会のアイコンと名前でホーム画面に表示される
- 教会のブランディングやテーマカラーに合わせてスムーズに動作する

:::tip
App Store や Google Play から別のアプリをインストールしたくない場合に、PWA は便利な選択肢です。ブラウザで利用するのと同じメンバーポータルを、より手軽な形で利用できます。
:::

## インストールページ

インストールの最も簡単な方法は、教会専用のインストールページを利用することです。

```
https://yourchurchname.b1.church/mobile/install
```

このページはお使いのデバイスを自動で判別し、適切な手順を表示します。

- **iPhone** — Safari で「ホーム画面に追加」を行う手順を順番に表示
- **Android** — Chrome で **ホーム画面にインストール** ボタンをワンタップで利用可能
- **デスクトップ** — スマートフォンで読み取ってインストールページを開ける QR コードを表示

インストールページには、次の方法でアクセスできます。

- メンバーポータルで **その他** をタップし、**アカウント** の下にある **アプリをインストール** をタップする (アプリがすでにインストールされている場合、この項目は表示されません)
- 教会からテキストメール、またはメール、日曜日のスクリーンで共有されたリンクをたどる
- ブラウザに URL を直接入力する

:::tip 教会スタッフの方へ
インストールページのリンクを会衆と共有してください。週報、ニュースレター、スライドに掲載するのがおすすめです。各メンバーがお使いのデバイスに応じた手順を案内できます。また、B1Admin ダッシュボードの **アプリをダウンロード** クイックアクションからもアクセスできます。
:::

インストールページは手順を案内する便利な入口ですが、下記のブラウザ操作を使えば、教会の B1.church サイトの **任意のページ** から PWA を手動でインストールすることもできます。

インストール済みのアプリを起動すると、ログインの準備が整った状態でメンバーダッシュボードが直接開きます。

## iPhone へのインストール (iOS — Safari)

1. iPhone で **Safari** を開き、`https://yourchurchname.b1.church/mobile/install` にアクセスします (`yourchurchname` は、教会の URL スラッグに置き換えてください)。
2. 画面下部の **共有** ボタン (上向き矢印の付いた箱のアイコン) をタップします。
3. 共有シートを下にスクロールし、**ホーム画面に追加** をタップします。
4. 名前には初期値として教会の名前が入ります。右上の **追加** をタップします。

ホーム画面にアプリのアイコンが表示されます。タップすると、メンバーポータルが全画面表示で開きます。

:::info
iOS で PWA をインストールするには Safari が必要です。iPhone で Chrome など別のブラウザを使用している場合は、先に Safari に切り替えてください。
:::

## Android へのインストール (Chrome)

1. Android デバイスで **Chrome** を開き、`https://yourchurchname.b1.church/mobile/install` にアクセスします。
2. **ホーム画面にインストール** ボタンをタップします。(ボタンが表示されない場合は、右上の三点メニュー (⋮) をタップし、**ホーム画面に追加** を選択してください。)
3. 確認が表示されたら **追加** をタップします。

ホーム画面にアプリのアイコンが表示されます。タップすると、メンバーポータルが開きます。

## インストール後

インストールが完了すると、PWA は専用の全画面ウィンドウでメンバーポータルを直接開きます。次のことができます。

- 既存の ChurchApps アカウントでログインする
- 教会で有効になっているすべてのメンバー向け機能 (グループ、献金、チェックイン、奉仕計画など) を利用する
- ホーム画面のアイコンをタップして、いつでも戻る

未読のメッセージがあるとアプリのアイコンに **通知バッジ** (小さな数字の付いたバッジ) が表示されるので、新しい連絡があるかどうかをひと目で確認できます。

:::info
PWA の利用にはインターネット接続が必要です。一部のネイティブアプリとは異なり、すべてのコンテンツをオフライン用にキャッシュすることはありません。
:::
