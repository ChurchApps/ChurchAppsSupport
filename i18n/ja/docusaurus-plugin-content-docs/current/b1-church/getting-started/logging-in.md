# ログイン

<div class="article-intro">

B1.church にログインすると、メンバーポータルを利用できます。メンバーポータルでは、今後の予定の確認、グループの管理、オンライン献金、教会が設定したすべてのツールの利用ができます。この記事では、サインインの方法、ユーザーメニューの使い方、ログアウトの方法を説明します。

</div>

## ログインの方法

1. 教会の B1.church URL にアクセスします(例: `https://yourchurchname.b1.church`)。
2. ヘッダー右上の**ログイン**ボタンをクリックします。
3. **メールアドレス**と**パスワード**を入力するか、教会でシングルサインオンが有効な場合は**Google で続行**または**Microsoft で続行**をクリックします。
4. **サインイン**をクリックします。

[二要素認証](../../b1-admin/profile/managing-profile.md#two-factor-sign-in)を有効にしている場合は、次の画面でコードの入力を求められます。認証アプリに表示される6桁のコード、またはバックアップコードのいずれかを入力し、**コードを確認**をクリックしてください。B1.church アプリでも同じ方法でコードを入力します。

サインイン後は、ログインする前に表示していたページに戻ります。ログアウトした状態でメンバーポータルのページに直接アクセスした場合は、サインイン後に自動的にそのページに戻ります。

## サインイン状態の維持

ログアウトするまで、同じブラウザまたはインストール済みのアプリでサインインした状態が続きます。しばらく利用しなくても、セッションは約30日間の非アクティブ状態まで維持されます。一度サインインすれば、教会のウェブサイトとメンバーポータル(`/mobile`)を行き来しても再度ログインする必要はありません。

## メンバーポータルへのアクセス

ログイン後は、ページ右上の**お名前**をクリックし、メニューから**メンバーポータル**を選択すると、メンバーポータルにアクセスできます。メンバーポータルには、個人用の教会ツールがすべてそろっています。たとえば、[ホームダッシュボード](./navigating.md)、[マイページ](./me-page.md)、[グループ](../groups/)、[献金](../giving/)などがあります。

## ユーザーメニュー

ログイン後は、ページ右上にお名前がチップ状に表示されます。クリックすると、次のオプションが並んだメニューが開きます。

- **メンバーポータル** — 個人用のメンバーポータルのダッシュボードに移動します。
- **プロフィールを編集** — アカウント設定を変更したり、教会のプロフィールを編集したりします。
- **ログアウト** — アカウントからサインアウトします。

## 管理者向けのアクセス

教会の管理者で適切な権限を持っている場合は、ユーザーメニューに**管理ポータル**も表示されます。これをクリックすると B1 Admin に移動し、教会の設定、人物、グループ、コンテンツを管理できます。

## パスワードを忘れた場合

パスワードを思い出せない場合は、次の手順に従ってください。

1. ログインページの**パスワードを忘れた場合**をクリックします。
2. ChurchApps アカウントに登録されているメールアドレスを入力し、送信します。
3. メールを確認し、**6桁の認証コード**が記載されたメッセージを探します。コードの有効期限は15分です。
4. 認証画面でコードを入力し、サインインします。
5. サインインしたら、プロフィールページで新しいパスワードを設定します。

:::tip
数分待ってもコードが届かない場合は、迷惑メールフォルダを確認してください。誤ったコードを5回入力するとコードがロックされます。その場合は、パスワードを忘れた場合のページから新しいコードをリクエストしてください。
:::

## ログアウト

ログアウトするには、ページ右上の**お名前**をクリックし、**ログアウト**を選択します。サインアウトされ、公開サイトに戻ります。
