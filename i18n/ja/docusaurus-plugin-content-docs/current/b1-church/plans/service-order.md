# 礼拝の順序

<div class="article-intro">

プランを開くと、**礼拝の順序**セクションにその礼拝の最初のいくつかの項目が表示されます。**礼拝の全体の順序**をタップすると、すべての流れを確認できます。これにより、あなたと奉仕チームは、各要素の時間配分、賛美曲の詳細、説明を含めた礼拝の流れを共有して把握できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1.church のアカウントに[ログイン](../getting-started/logging-in.md)している必要があります。
- 礼拝の順序を表示するには、[プラン一覧](./viewing-plans.md)からプランを開きます。

</div>

## 礼拝の順序の内容

礼拝の順序は、礼拝中に行われる順番どおりに並んだ項目の一覧として表示されます。各項目には次の情報が含まれます。

- **累積時間** -- 礼拝の開始からの経過時間です。各要素がいつ始まる予定かがわかります。
- **項目の名前と説明** -- 賛美曲のタイトル、祈り、お知らせなど、要素の名前と、補足やメモがあればそれも表示されます。
- **所要時間** -- その項目にかかると予定されている時間です。

項目は関連する要素をまとめる**見出し**の下に整理されています(例:「礼拝の賛美」「メッセージ」)。これにより、礼拝全体の構成をひと目で把握しやすくなります。

レッスンやカリキュラムのセクションは、その下にある個々の活動のフォルダーとして展開することもできます。セクションをクリックすると、その活動の展開や折りたたみができ、奉仕チームが順に進める各ステップを確認できます。

## 賛美の歌詞とコードの表示

礼拝の順序で賛美曲をクリックすると、その歌詞とコードが開きます。上部の**調号**ドロップダウンを使うと、その場でコードを移調できます。楽器や歌声の音域に合わせて、礼拝リーダーが計画した調とは別の調が必要な場合に便利です。

## カリキュラムとレッスンの内容

プランに、[Lessons.church](../content/lessons.md)などのプロバイダーから提供されたカリキュラムやレッスンの内容が関連付けられている場合、礼拝の順序の中にその内容のプレビューが表示されます。これには、レッスンのセクション、プレゼンテーション資料、奉仕チームが礼拝に必要とするその他の資料が含まれることがあります。

## 礼拝の順序の印刷

B1.church のメンバー向けアプリには、プランを印刷する機能はありません。奉仕者の名簿と礼拝の順序全体を印刷したものが必要な場合は、スタッフに B1 Admin から印刷を依頼してください。詳しくは[プランの印刷](../../b1-admin/serving/plans.md#printing-plans)をご覧ください。
