# 予定の表示

<div class="article-intro">

「予定」ページでは、割り当てられているすべての礼拝の予定を確認できます。返信が必要な予定、今後の予定、奉仕したことのある予定が分かり、各予定を開いて詳細を見ることもできます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1.church アカウントに[ログイン](../getting-started/logging-in.md)している必要があります。
- 少なくとも1つの礼拝の予定に割り当てられている必要があります。予定が表示されない場合は、教会の管理者または奉仕リーダーに問い合わせてください。

</div>

## 自分の予定にアクセスする

1. タブバー、[「その他」ページ](../getting-started/navigating.md#the-more-page)、またはホーム画面の**あなたが奉仕している**セクションにある**すべての予定**をタップします。
2. 自分が組み込まれている予定が表示されます。

## 予定ページ

ページの上部には、今後の割り当てのうち確定済みの数と、まだ返信が必要な数が表示されます。また、[奉仕者の登録](../serving/volunteer-signup.md)ページを開く**奉仕に登録する**ボタンもあります。その下のページは、以下のセクションに分かれています。

- **返信が必要** -- まだ回答していない割り当てです。予定を開かずに返信できるよう、それぞれに**承諾**と**辞退**のボタンがあります。**辞退**をタップすると、まず確認を求められます。返信を待っている項目がある場合にのみ表示されます。
- **今後** -- 次の3件の割り当てです。残りを見るには**今後のすべて**をタップします。
- **奉仕不可日** -- 奉仕できない日付です。**日付を追加**をタップし、**開始日**と**終了日**を選んで**保存**をタップします。奉仕不可日の横にある**削除**をタップすると、その日付を削除できます。チームリーダーはこの日付を確認し、あなたを避けて予定を組みます。
- **過去** -- 今年奉仕した回数と、最後に奉仕した日です。**過去の割り当て**をタップすると全件が表示され、年で絞り込めます。

各割り当てには、**奉仕日**、**予定名**、あなたの**担当**、そしてステータスのバッジが表示されます。ステータスは、**承諾済み**、**確定**、**辞退**、**返信待ち**のいずれかです。まだ回答していない場合は**返信が必要**と表示されます。

:::info
教会によっては、予定されている礼拝の前に、メールとアプリの通知で**リマインダー**を送る場合があります。教会がテキストメッセージを送っている場合は、[通知設定](../getting-started/notification-preferences.md)で**テキストメッセージ**をオンにすると、テキストでも受け取れます。まだ返信していない場合は、リマインダーのメールからそのまま**承諾**または**辞退**できます。サインインは必要ありません。
:::

## 予定の詳細を表示する

予定をタップして開きます。予定のページでは、上部に予定名と奉仕日が表示され、続いて次のセクションが並びます。

- **あなたの割り当て** -- この予定であなたが担当する各ポジションです。チーム、あなたのステータス、そしてあなたが必要とされている**礼拝時間**が表示されます。まだ回答していない場合は、ここで**承諾**または**辞退**をタップできます。**辞退**をタップすると、まず確認を求められます。
- **礼拝の順序** -- 礼拝の最初のいくつかの項目と、項目の総数です。すべてを見るには**礼拝の順序をすべて表示**をタップします。詳しくは[礼拝の順序](./service-order.md)を参照してください。
- **奉仕チーム** -- あなたと一緒に奉仕する人と、その担当ポジションです。人数とチーム数も表示されます。すべてのチームとそのメンバーを見るには**すべてのチーム**をタップします。
- **予定のメモ** -- 予定の作成者がチーム向けに追加したメモです。
- **ダウンロード** -- 予定に添付されたレッスン教材のファイルです。ある場合のみ表示されます。

礼拝の順序の全体ページまたはチーム一覧ページの上部にある**戻る先:** *予定名* をタップすると、予定に戻れます。

## 承諾済みの割り当てを辞退する

承諾した後に予定が合わなくなった場合でも、予定のページから辞退できます。

1. 予定を開き、**あなたの割り当て**からご自分のポジションを探します。**承諾済み**のバッジが表示されています。
2. そのポジションの下にある赤い**辞退**リンクをタップします。
3. 「この割り当てを辞退しますか?」という確認が表示されます。「チームリーダーに、このポジションで奉仕できなくなったことが通知されます。」
4. **辞退**をタップして確定するか、**キャンセル**をタップして割り当てを維持します。

ステータスが**辞退**に変わります。**辞退**をタップすると、予定のページ、予定ページの**返信が必要**、またはホーム画面の**あなたが奉仕している**のいずれからでも、同じ確認が表示されます。誤タップで割り当てが辞退されることはありません。

## 辞退した割り当てを承諾する {#accepting-a-declined-assignment}

辞退した後に気が変わった場合は、予定を開きます。**辞退**のバッジが表示されているポジションの下にある**承諾**をタップします。ステータスは**承諾済み**に戻ります。

**辞退**と**承諾**のリンクは、礼拝時間が終わるまでのみ利用できます。その後は、予定のページから割り当てを変更することはできません。

割り当てに一度も返信せず、礼拝時間が過ぎている場合は、予定のページに**承諾**と**辞退**の代わりに**回答期限切れ**のバッジが表示されます。このとき、*「この奉仕時間は過ぎたため、もう返信できません。」* というメモが表示されます。

:::tip
複数の予定に割り当てられている場合、一覧は日付順に並ぶので、直近の約束が先頭に表示されます。スケジュールを把握しておくため、定期的に確認してください。
:::

## レッスンの教師表示

予定に、コンテンツ提供元(Lessons.church など)のカリキュラムが関連付けられている場合、**礼拝の順序**セクションにレッスンのセクションが表示され、予定のページ上部に**教える**ボタンが現れます。

**教える**をクリックすると、教師向けの全画面レッスン表示が開きます。整形された指導内容、埋め込みのメディア、メモ、段階的な指示が含まれています。閉じると予定に戻ります。

教える表示では、レッスンの内容がセクションごとに整理されています。次のことができます。

- 上部の**セクション**をタップして、セクションの一覧を表示し、レッスンの任意の部分へ直接移動します
- レッスンの内容をスクロールします。見出しには現在のセクションが表示されます(例:「5つのうち2番目のセクション」)
- メディア項目(動画、画像、アクティビティ)をクリックすると、モーダルダイアログで表示されます。音声リンク(讃美歌の音源や説教の抜粋)は、内蔵のオーディオプレーヤーでその場で再生されます
- 行動の種類は見分けやすく表示されます。**話す**は会話の吹き出しに、**行う**は太字に、**メモ**は強調されたコールアウトに表示されます

:::tip
教える表示は、教室や小グループを導く際に特に役立ちます。すべてのレッスン内容を、スマートフォンやタブレットで使いやすい、見やすく整理された形式で表示するためです。
:::
