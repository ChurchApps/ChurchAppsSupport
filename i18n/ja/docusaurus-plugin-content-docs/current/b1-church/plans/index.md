# プラン

<div class="article-intro">

B1.church の **プラン** セクションでは、割り当てられたサービスプランを確認できます。礼拝チームで奉仕する場合も、子ども会の奉仕や他の分野での奉仕の場合も、ここで出席の予定日、担当する役割、サービスの流れを確認できます。

</div>

## 表示される内容

プランには、教会の設定によって複数の種類の内容が含まれることがあります。

- **割り当て** -- 割り当てられた役割と必要とされる日程を確認できます。各割り当てには、役割名、サービスの日付、現在のステータス（「承諾済み」「辞退」「返信待ち」など）が表示されます。新しい割り当てを承諾または辞退でき、予定が変わった場合は承諾済みの割り当てを辞退することもできます。
- **サービスの順序** -- 所要時間、曲の情報、項目の説明など、サービスの順序を表示できるため、事前にサービスの流れを把握できます。
- **カリキュラムの内容** -- 一部のプランには、[Lessons.church](../content/lessons.md) などの提供元の関連レッスンやカリキュラムの内容が含まれます。この内容はプラン内で直接プレビューできます。
- **不在日の設定** -- ブロックアウト日を管理することで、担当リーダーに不在日を知らせることができます。
- **ホームでのプレビュー** -- 直近の割り当ても[ホーム ダッシュボード](../getting-started/navigating.md#home)の「奉仕中」セクションに表示されます。返信が必要な割り当ては、そこで承諾または辞退できます。

## はじめに

プランを表示するには、タブバーまたはメンバーポータルの「その他」ページで **プラン** をタップします。プランを表示するには[ログイン](../getting-started/logging-in.md)している必要があります。サインインしていない場合は、先にログインするよう求められます。

:::info
割り当てられたプランのみが表示されます。プランが一覧に表示されない場合は、まだ奉仕チームに追加されていないことを意味します。教会の管理者または奉仕のリーダーに相談して、参加の方法を確認してください。
:::
