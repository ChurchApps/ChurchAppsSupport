# ブログ

<div class="article-intro">

ブログページでは、教会からのニュース、お知らせ、デボーションの記事を掲載しています。投稿はカテゴリーとタグで整理されているため、関心のあるトピックを簡単に探せます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- ブログ記事を読むのにログインは必要ありません。ブログページは誰でも閲覧できます。
- ブログページを表示するには、教会が少なくとも1件の投稿を公開している必要があります。

</div>

## 投稿の閲覧

1. 教会のサイトのナビゲーションから **ブログ** ページに移動します。
2. 投稿は新しいものから順に、1ページあたり10件ずつ表示されます。ページ下部の **古い投稿** / **新しい投稿** のリンクを使って、アーカイブを移動できます。
3. 投稿をクリックすると、全文を読むことができます。

## カテゴリーまたはタグで絞り込む

任意の投稿、またはブログ一覧にある **カテゴリー** または **タグ** のチップをクリックすると、該当する投稿だけに絞り込まれます。特定のトピックやシリーズをまとめて確認したいときに便利です。

## 関連記事

各投稿の末尾には **関連記事** のセクションがあり、同じカテゴリーの他の投稿が表示されます。

## RSSで購読する

すべての教会のブログはRSSフィードを配信しています。フィードリーダーや自動化ツールで購読すると、新しい投稿が公開されたときに自動で通知を受け取れるので、手動で確認し直す必要がありません。

## 利用可能な条件

ブログページは、教会が少なくとも1件の投稿を公開すると利用できるようになります。教会のナビゲーションに **ブログ** のリンクが表示されない場合は、まだ設定されていない可能性があります。詳しくは教会の管理者にお問い合わせください。
