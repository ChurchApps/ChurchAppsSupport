# 説教

<div class="article-intro">

説教ページでは、教会で録画された説教を閲覧して視聴できます。教会の説教ライブラリは、教会が設定した外観とレイアウトで表示されるため、教会のブランドイメージに沿った見た目になります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 説教の閲覧にログインは必要ありません。説教ページは誰でも閲覧できます。
- 教会の管理ポータルから、説教コンテンツが追加されている必要があります。

</div>

## 説教の閲覧

1. 教会のサイトのナビゲーションから**説教**ページに移動します。
2. 利用可能な説教の一覧が表示されます。通常、プレイリストまたはシリーズごとに整理されています。
3. 視聴または聴きたい説教をクリックします。

説教には、YouTube、Vimeo、Facebookなどのプラットフォームでホスティングされた動画または音声コンテンツが含まれる場合があります。説教をクリックすると、そのページ上でメディアが直接再生されます。

## 表示される内容

各説教の項目には、次の情報が表示される場合があります。

- **タイトル** -- 説教の名前
- **話し手** -- メッセージを語った人
- **日付** -- 説教が録画または公開された日
- **説明** -- 説教の内容の要約
- **サムネイル** -- 説教のプレビュー画像

教会は説教をプレイリストまたはシリーズにまとめています。これにより、複数週にわたるシリーズを追いかけたり、特定のテーマの説教を探したりしやすくなります。

:::tip
録画された説教ではなく、ライブ配信を見たい場合は、代わりに[ライブ配信](./live-streaming.md)ページをご確認ください。
:::

## 利用について

説教ページは、教会が管理ポータルから説教コンテンツを追加すると利用できるようになります。教会のナビゲーションに**説教**のリンクが表示されない場合は、この機能がまだ設定されていない可能性があります。詳しくは教会の管理者にお問い合わせください。
