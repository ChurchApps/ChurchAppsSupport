# 今日のみことば

<div class="article-intro">

「今日のみことば」ページでは、毎日の聖書の一節が美しく整えられた画像として表示されます。みことばで一日を始めたり、週の間ずっと励ましを得たりするための簡単な方法です。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 「今日のみことば」を見るのにログインは必要ありません。このページは誰でも閲覧できます。
- 教会のサイトのナビゲーションに「今日のみことば」ページを追加している必要があります。

</div>

## みことばを見る

1. 教会のサイトのナビゲーションから **今日のみことば** ページに移動します。
2. ページには今日のみことばが画像として表示され、みことばの本文、箇所、今日の日付が画像の横または下に表示されます。
3. 新しいみことばは毎日自動的に表示されます。

特に操作は必要ありません。ページを開くだけで、その日のみことばが表示されます。

## 過去のみことば

今日のみことばの下にある **今週** のセクションには、直近の日のみことばが表示されます。

- 教会のウェブサイトでは、直前の6日分が写真付きのカードとして一列に並び、自動でゆっくりスクロールします(マウスを重ねたりタッチしたりしている間は一時停止します)。
- メンバーポータル(`/mobile`)では、直前の3日分が、各みことばの箇所、日付、本文とともに一覧で表示されます。

任意の日をクリックまたはタップすると、その日のみことばが写真、本文全体、今日のみことばと同じ共有ボタンとダウンロードボタン付きで開きます。

**過去のみことば** をクリックすると、今年の1月1日から昨日までのすべての日のみことばを表示できます。新しい順に月ごとにまとめられています。ウェブサイトでは **今週** の列の下に一覧が開きます(もう一度 **過去のみことば** をクリックすると非表示になります)。メンバーポータルでは、独立した画面が開き、戻るリンクがあります。任意の日付をクリックすると、その日のみことばが開きます。

## 画面サイズへの対応

みことばの画像は、画面に合わせて自動的に調整されます。お使いの端末や ウィンドウのサイズによって、次の3つの形式のいずれかで表示されます。

- **ワイド(16:9)** -- デスクトップモニターやノートパソコンに最適
- **正方形(1:1)** -- タブレットサイズの画面に適しています
- **縦長(9:16)** -- 縦向きに持ったスマートフォンに最適化されています

ページは画面の寸法を検出して最適な形式を選ぶため、どの端末で見ても、みことばが常に見やすく表示されます。ブラウザのウィンドウのサイズを変えると、画像も新しいサイズに合わせて更新されます。教会のウェブサイトでは、縦に長いスマートフォンの画面には縦長の写真ではなく正方形の写真が表示されるため、みことばが細い帯に押し込められることはありません。

## みことばを共有する

今日のみことばと、開いた過去の日のみことばには、3つのボタンがあります。

- **共有** -- みことばの本文、箇所、みことばの画像へのリンクを共有します。端末に共有メニューがない場合は、本文とリンクがクリップボードにコピーされます。
- **画像を共有** -- みことばの画像そのものを共有するため、投稿したりメッセージで送ったりできます。ファイルを共有できない端末(多くのデスクトップブラウザなど)では、代わりに画像がダウンロードされます。
- **ダウンロード** -- みことばの画像を端末に保存します。

教会のウェブサイトでは、これらのボタンは常にワイド(16:9)の画像を使用します。メンバーポータルでは、お使いの画面に合った形式を使用します。

:::tip
毎日「今日のみことば」を確認する習慣をつけ、さらに [聖書リーダー](./bible.md) で箇所を読み進めてみてください。
:::

## 提供について

「今日のみことば」はB1.churchに組み込まれているコンテンツ機能です。教会のナビゲーションに表示されない場合は、教会の管理者がサイトのメニューに追加していない可能性があります。依頼するには、教会の管理者に連絡してください。
