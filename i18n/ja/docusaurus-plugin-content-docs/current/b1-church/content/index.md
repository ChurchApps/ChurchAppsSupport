# コンテンツ

<div class="article-intro">

B1.churchでは、教会が共有するコンテンツに会衆がアクセスできる中央の場所を提供します。教会の設定によっては、メンバーポータルから説教、ライブ配信、聖書の朗読、日々の御言葉、レッスン資料などにアクセスできます。

</div>

## 利用可能なコンテンツ機能

### 説教

教会で録画された説教を閲覧して視聴できます。教会の説教ライブラリはプレイリストやシリーズごとに整理されているため、過去のメッセージを簡単に見つけられます。

### ライブ配信

B1.church上で教会のライブ放送を直接視聴できます。礼拝がライブ中であれば、配信に参加してチャットで他の視聴者と交流できます。

### 聖書

内蔵の聖書リーダーで御言葉を読むことができます。サイトを離れることなく、書、章、節を移動できます。

### 今日の御言葉

毎日変わる、美しく整えられた聖句の画像を表示できます。画像は画面に合わせて自動的に調整されます。どの日の御言葉も共有またはダウンロードでき、過去の日の御言葉を閲覧することもできます。

### レッスン

教会の計画に基づいて予定されたレッスンを表示できます。教師またはリーダーの方は**教師ビュー**を使うと、教えたり提示したりするのに最適な、全画面で見やすいレッスン表示を利用できます。

### レッスン（非推奨 - 埋め込みタブ）

埋め込みの**レッスン**タブは非推奨となりました。カリキュラムの再生は現在、ChurchAppsの教室用スクリーン向け無料TVアプリである**[FreePlay](/docs/freeplay/)**で行います。スマートフォン、タブレット、またはコンピューターでカリキュラムを閲覧するには、[Lessons.church](https://lessons.church)に直接サインインしてください。詳細は[レッスンのリファレンスページ](./lessons.md)をご覧ください。

## コンテンツの探し方

コンテンツのページは、教会のサイトナビゲーションからアクセスできます。どのコンテンツ機能を有効にし、メニューにどのように表示するかは、教会の管理者が決めます。上に記載された特定のコンテンツ機能が表示されない場合は、お使いの教会で設定されていない可能性があります。

:::info
[説教](./sermons.md)と[聖書](./bible.md)は公開で利用できます。その他の機能には[ログイン](../getting-started/logging-in.md)が必要な場合があります。
:::
