# ライブ配信

<div class="article-intro">

ライブ配信ページでは、教会の礼拝を開催と同時に B1.church からご覧いただけます。教会が配信中であれば、動画と一緒に表示される双方向機能を使って参加できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- ライブ配信の視聴にログインは必要ありません。配信ページは誰でも閲覧できます。
- 教会で配信スケジュールが設定されている必要があります。ライブ配信が可能な時間帯については、教会の礼拝時間をご確認ください。

</div>

## ライブ配信を視聴する

1. 教会のサイトのナビゲーションから **Stream** ページに移動します。
2. 礼拝が現在配信中か、まもなく始まる場合は、動画プレーヤーが自動的に読み込まれます。
3. そのページで直接配信をご覧ください。

現在ライブ配信が行われていない場合は、オフラインのコンテンツや次回の礼拝時間に関する情報が表示されることがあります。

## 双方向機能

ライブ配信ページには、教会の設定によって、動画と並べて双方向のタブが表示されることがあります。以下のような機能が含まれる場合があります。

- **チャット** -- 配信中に、メッセージを送ったり、他の視聴者と交流したりできます。チャットは通常、礼拝開始の数分前から有効になり、終了後もしばらく利用できます。ログインしなくてもチャットに参加できます。表示される指示に従って、表示名を選んでください。
- **その他のタブ** -- 教会によっては、週報、説教メモ、[献金ページ](../giving/making-donations.md)、その他の資料へのリンクを含むカスタムタブが追加されていることがあります。

視聴中は、タブのアイコンまたはラベルをクリックして、利用可能な機能を切り替えられます。

## 礼拝の前後

教会では、配信や双方向機能を利用できるようになる時間を個別に設定しています。礼拝が正式に始まる前にチャットに参加でき、他の人にあいさつする時間を持てる場合もあります。礼拝の終了後も、チャットがしばらく開いたままになることがあります。

:::info
配信ページにオフラインのコンテンツやカウントダウンが表示される場合は、次回の礼拝がまだ始まっていません。表示されている礼拝時間に改めてご確認ください。
:::

:::tip
見逃した説教を探していますか？[説教](./sermons.md)ページで、教会の過去のメッセージを閲覧できます。
:::

## 利用可否

ライブ配信ページは、教会で配信スケジュールが設定されている場合に利用できます。ナビゲーションに **Stream** のリンクが表示されない場合は、教会でライブ配信が設定されていない可能性があります。詳しくは教会の管理者にお問い合わせください。
