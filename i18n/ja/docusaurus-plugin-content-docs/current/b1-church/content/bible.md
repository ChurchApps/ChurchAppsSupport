# 聖書

<div class="article-intro">

B1.church には聖書リーダーが組み込まれているので、サイトを離れることなく聖書を読むことができます。リーダーはページ内に直接埋め込まれており、教会のその他のツールと並んで、どの箇所にもすばやくアクセスできます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 聖書リーダーを使うのにログインは必要ありません。聖書ページは一般公開されています。
- 教会のサイトのナビゲーションに聖書ページが追加されている必要があります。

</div>

## 聖書を読む

1. 教会のサイトのナビゲーションから **聖書** ページに移動します。
2. リーダーはデフォルトで創世記 1:1 を表示して開きます。
3. リーダー内のナビゲーションコントロールを使って、別の書、章、節に移動します。

聖書リーダーは **YouVersion** を利用しており、多言語にわたる幅広い聖書訳から選んで読むことができます。

## 箇所の移動

埋め込みリーダーには、聖書の中を移動するためのコントロールがあります。次のことができます：

- 聖書の特定の書を選んで表示する
- 特定の章に移動する
- 章の中の節をスクロールして読む
- バージョン選択メニューを使って別の聖書訳に切り替える

リーダーはページのコンテンツ領域いっぱいに表示されるので、ゆったりと読むことができます。

:::tip
選択した書、章、訳は記憶されるので、リーダーを再度開いたときは前回読んでいた位置から始まります。
:::

:::tip
ブラウザで聖書ページをブックマークしておくと、毎日の聖書通読にすぐ戻れます。[今日の聖句](./verse-of-the-day.md)と組み合わせると、毎日の御言葉の励みになります。
:::

## 利用可能性

聖書ページは B1.church に組み込まれているコンテンツ機能です。教会のナビゲーションに **聖書** のリンクが表示されない場合は、教会の管理者がサイトメニューに追加していない可能性があります。追加を依頼するには、教会の管理者に連絡してください。
