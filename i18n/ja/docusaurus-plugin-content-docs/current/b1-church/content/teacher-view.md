# レッスンのティーチャービュー

<div class="article-intro">
ティーチャービューは、レッスンの内容を構造化されたセクションで表示する拡大表示の全画面インターフェースです。授業中に、教師やリーダーがレッスン教材の中を移動しやすくなります。
</div>

<div class="prereqs">
<h4>始める前に</h4>

- 教会のプランにレッスンが予定されている必要があります。詳しくは B1 Admin ガイドの [レッスンのスケジュール設定](../../b1-admin/serving/scheduling-lessons.md) を参照してください。
- プランに割り当てられているか、B1.church サイトでプランを表示する権限が必要です。
</div>

## ティーチャービューを開く

レッスンの拡大ティーチャービューを開くには:

1. B1.church のメンバーポータルで **Plans** を開きます
2. 教えたいレッスンを含むプランを開きます
3. プランページの上部にある **Teach** ボタンをクリックします

レッスンは、授業用に最適化された全画面インターフェースで開きます。

:::tip
ティーチャービューは、レッスンの内容をスクリーンやテレビに映して生徒に見せるときや、タブレットを使って教えるときに特に便利です。
:::

## ティーチャービューの機能

### セクションのナビゲーション

ティーチャービューでは、レッスンの内容がセクションごとに整理されています。

- レッスンの各主要セクションは、それぞれタイトル付きのブロックとして表示されます
- 上部の **Sections** をクリックするとセクションの一覧が開き、選んだセクションへ直接移動できます
- 見出しには「5 セクション中 2 番目」のように、現在のセクションが表示されます
- セクションの一覧を使うと、レッスンのさまざまな部分へすばやく移動できます
- レッスンに複数のセクションがある場合、前へ・次へのボタンが画面下部に固定表示されます。ボタンには隣接するセクションの名前が表示され、スクロール中も常に使えます

### スクロール可能なコンテンツ

メインのコンテンツ領域には、レッスン教材の全体が表示されます。

- レッスンを自然にスクロールして読み進められます
- スクロールすると、見出しが表示中のセクションに合わせて自動的に更新されます
- 書式付きのテキスト、画像、指示はすべてわかりやすく表示されます

### メディアの再生

レッスンに動画、画像、その他のメディアが含まれている場合:

- メディア項目をクリックすると、ポップアップのプレーヤーで開きます
- 動画は標準の操作ボタンが付いた専用のビデオプレーヤーで再生されます
- 画像はライトボックスで全画面表示されます
- メディアプレーヤーを閉じると、レッスンの内容に戻ります

### ダウンロード可能なリソース

レッスンにダウンロード可能なファイル（活動用シート、塗り絵など）が含まれている場合:

- レッスンの最後のセクションの後に、リソースごとにダウンロードボタンが表示されます
- クリックすると、ファイルを直接デバイスにダウンロードできます
- ファイルには、コンテンツ制作者が提供した PDF、画像、その他の教材が含まれることがあります

## 教室でのティーチャービューの使い方

### 授業の前に

1. 授業が始まる前に、ティーチャービューでレッスンを開きます
2. すべてのセクションに目を通し、内容に慣れておきます
3. 必要な印刷用リソースをダウンロードします
4. 動画やメディアを再生して、正しく再生されるか確認します

### 授業中

1. ティーチャービューを開いたまま、デバイスで表示するか、スクリーンに映します
2. **Sections** を使って、レッスンを進めながらセクション間を移動します
3. 適切なタイミングで動画を再生したり、画像を表示したりします
4. 必要に応じて指示をスクロールし、読んでいた位置を見失わないようにします

### 投影スクリーンで使う場合

クラス向けに投影するときは:

- 全画面レイアウトなので、余計なものが目に入りません
- 文字が大きく読みやすいため、教室の後ろからでも内容が見えます
- メディア項目をクリックすると、動画や画像をクラス全体に表示できます
- ワイヤレスマウスやトラックパッドで操作できます

## ティーチャービューを閉じる

ティーチャービューを終了するには:

- 画面の隅にある **Close** ボタン（X）をクリックします
- または、キーボードの **Esc** キーを押します
- プランの詳細表示に戻ります

## モバイルとタブレットでの利用

ティーチャービューはタブレットやモバイルデバイスでも使えます。

- **タブレット** -- 持ち運べるレッスンガイドとして最適です
- **スマートフォン** -- 対応していますが、画面が小さいため授業には向かない場合があります
- **横向き** -- モバイルデバイスで最も見やすい表示になります

## 通常のレッスン表示との違い

| 機能 | 通常の表示 | ティーチャービュー |
|---------|--------------|--------------|
| **レイアウト** | コンパクトで、プラン内に組み込まれている | 全画面の専用表示 |
| **ナビゲーション** | スクロールのみ | セクション一覧と、現在のセクションを示す見出し付きのスクロール |
| **メディア** | ページ内に埋め込み | 集中して見られるポップアッププレーヤー |
| **画面の使い方** | 他のプラン項目も表示される | レッスンの内容を最大限に表示する |
| **適した用途** | 閲覧と計画 | 授業と発表 |

## ベストプラクティス

- **事前に準備する** -- 授業前にティーチャービューでレッスンを確認し、レイアウトに慣れておきます
- **セクションに目印をつける** -- 重要な活動や話し合いが含まれるセクションをメモしておきます
- **メディアをテストする** -- 授業の前に、動画や画像が正しく読み込まれるか確認します
- **リソースは早めにダウンロードする** -- 印刷用の資料は授業直前ではなく、早めにダウンロードします
- **大きな画面を使う** -- 最適な授業環境にするため、スクリーンに投影するかタブレットを使います

## トラブルシューティング

### レッスンがティーチャービューで開かない

- レッスンがプランに正しくスケジュールされているか確認します
- そのプランを表示する権限があるか確認します
- ページを再読み込みして、もう一度試します

### 動画が再生されない

- インターネット接続を確認します
- デバイスでメディアの再生が許可されているか確認します
- 動画を別のタブで開いてみます
- コンテンツ提供者によっては、動画の再生に制限がある場合があります

### モバイルでコンテンツが切れて表示される

- デバイスを横向きにします
- 必要に応じて少し縮小表示にします
- より見やすくするために、タブレットやより大きなデバイスの使用を検討します
