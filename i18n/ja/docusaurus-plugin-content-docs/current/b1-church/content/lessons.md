# Lessons（非推奨）

:::danger Lessons タブは FreePlay に置き換えられました
B1.church に埋め込まれていた **Lessons** タブは非推奨になりました。Lessons.church からのカリキュラム再生は、現在 **[FreePlay](/docs/freeplay/)** を通じて提供されています。FreePlay は ChurchApps の無料 TV アプリで、教室のスクリーン、Fire TV、Apple TV、Android TV に対応しています。オフライン再生、教室でのペアリング、テレビのリモコンでの操作など、埋め込みタブでは提供できなかった機能があります。

カリキュラムを直接閲覧、スケジュール設定、編集するには、ブラウザで [Lessons.church](https://lessons.church) にサインインしてください。教室のテレビでレッスンを再生するには、テレビデバイスに [FreePlay](/docs/freeplay/getting-started/) をインストールしてください。

B1Admin でレッスンプランの種類が関連付けられたグループの保護者には、[グループの詳細](../groups/group-details.md) ページに**今週のレッスン**が表示されます。この非推奨タブには表示されません。
:::

<div class="article-intro">

**Lessons** タブでは、教会のカリキュラムと学習教材にアクセスできました。コンテンツは Lessons.church プラットフォームから提供され、B1.church 内に直接埋め込まれていたため、別のサイトに移動する必要はありませんでした。

</div>

## Lessons へのアクセス

1. B1.church のメンバーポータルにログインします。
2. [メンバーナビゲーション](../getting-started/navigating.md)で **Lessons** タブをクリックします。
3. Lessons.church のコンテンツがそのページ内に直接読み込まれます。

Lessons タブを開くと、ログイン情報は自動的に引き継がれます。Lessons.church に別途サインインし直す必要はありません。

## できること

Lessons タブ内では、教会が利用可能にしたカリキュラムを閲覧できます。教会の設定によって、次のようなものが見つかることがあります。

- **レッスンプラン** -- セクションと活動を含む構造化されたアウトライン
- **プレゼンテーションとメディア** -- レッスンに添える スライド、動画、画像
- **ダウンロード可能なリソース** -- さらに学習するためのファイルや追加教材

レッスン内の個々のセクションをクリックすると、ダイアログウィンドウで内容を表示できます。**Back** ボタンでセクション一覧に戻り、**Close** ボタンでダイアログを閉じます。

:::tip
[グループの詳細](../groups/group-details.md)ページの**今週のレッスン**に、グループに割り当てられたレッスンが表示されます。Lessons タブに直接移動しなくても、割り当てられたカリキュラムを簡単に確認できます。
:::

## 利用条件

Lessons タブは、教会が Lessons.church でカリキュラムを設定すると表示されます。メンバーナビゲーションに **Lessons** タブが表示されない場合は、教会にレッスンコンテンツが設定されていない可能性があります。詳細は教会の管理者にお問い合わせください。
