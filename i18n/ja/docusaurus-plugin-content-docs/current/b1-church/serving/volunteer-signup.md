# ボランティアへの登録

<div class="article-intro">

B1.church から直接、募集中のボランティアの役割を確認し、今後の礼拝に登録できます。役割はカテゴリーごとに整理されているので、助けが必要な場所をすぐに見つけて、チームに加わることができます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1.church のアカウント。登録するにはログインしている必要があります
- 教会の管理者が、少なくとも 1 つの役割で自己登録を有効にしている必要があります

</div>

## 募集中の役割を確認する

1. 教会の B1.church ウェブサイトで、**Volunteer** ページに移動します。
2. ボランティアの募集がある今後の礼拝プランの一覧が表示されます。各プランの中では、役割がカテゴリーごとに、さらに名前順に並んでいます。教会の設定で各プランタイプの直近 1 週間分のみが表示されている場合、後の週のプランは現在の週が終わると表示されます。
3. 各プランには、**プラン名**、**礼拝日**、**礼拝時間**が表示されます。礼拝日は、どのタイムゾーンから見ても、そのプランの実際の日付です。

役割はカテゴリーごとにグループ化されています(例: 「Band」「Hospitality」「Kids Ministry」)。各役割には次の情報が表示されます。

- **役割名** -- あなたが担当する役割です(例: 「Drummer」「Greeter」「Coffee Server」)。
- **説明** -- 管理者が入力した場合、役割の詳細です。
- **空き枠** -- 埋まっている枠と残りの枠数を示すプログレスバーです。
- **登録者** -- 教会がプランの **Show volunteer names on signup page** を有効にしている場合、「Signed up:」の行に、その役割にすでに登録している人の名前が表示されます。名前は、サインインしているときにのみ表示されます。

## 登録する

1. 登録したい役割を見つけます。
2. その役割の横にある **Sign Up** ボタンをクリックします。
3. 「You're signed up! Thank you for volunteering.」という確認メッセージが表示されます。
4. その役割に緑色のマークが表示され、登録済みであることが確認できます。

:::info
登録するにはログインしている必要があります。ログインしていない場合は、先にログインするよう求められます。
:::

## 登録を取り消す

予定が変わり、奉仕できなくなった場合は、次の手順に従ってください。

1. 登録した役割を見つけます。緑色の「You're signed up」マークが表示されています。
2. **Remove** ボタンをクリックします。
3. 役割から自分を削除してよいか確認します。
4. 「You have been removed from this position.」というメッセージが表示され、取り消しが完了します。

## 締め切り

教会の管理者は、プランごとに登録の締め切りを設定できます。締め切りは、プランの最初の礼拝時刻より一定時間前に設定されます。たとえば、午前 10 時の礼拝に対して 2 時間前の締め切りが設定されている場合、登録は同日の午前 8 時に締め切られます。締め切りを過ぎると、次のようになります。

- 新しい役割に登録できなくなります。
- 既存の登録を取り消せなくなります。
- プランの上部に、登録締め切りを過ぎたことを示すメッセージが表示されます。

## 役割の定員

各役割には登録できる人数の上限があります。すべての枠が埋まると、次のようになります。

- 役割に **Full** と表示されます。
- 登録ボタンが無効になります。
- 誰かが登録を取り消すと、その枠が再び空きになります。

:::tip
特に週の初めのうちに、ボランティアのページを定期的に確認してください。人気のある役割はすぐに埋まるため、早めに登録すると、より多くの選択肢から選べます。
:::
