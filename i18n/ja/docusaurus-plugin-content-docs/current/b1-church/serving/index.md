# 奉仕

<div class="article-intro">

B1.church の奉仕セクションでは、ボランティアの募集を閲覧し、教会内の担当枠に申し込むことができます。割り当てられた予定や礼拝進行表を確認できることに加え、人員が必要なポジションに自分から申し込むこともできるようになりました。

</div>

## できること

- **ボランティアの募集を閲覧する** -- 空きのあるポジションがある今後の奉仕予定を確認できます。
- **ポジションに申し込む** -- ポジションを選び、ワンクリックで自分を登録できます。
- **自分の予定を確認する** -- 今後および過去の[奉仕の割り当て](../plans/viewing-plans)を確認できます。
- **割り当てに応答する** -- 割り当てられたポジションを、予定ページまたはホームの **奉仕予定** セクションから承諾または辞退できます。承諾後に予定が変わった場合は、奉仕が終わるまで[承諾済みの割り当てを辞退](../plans/viewing-plans#declining-an-accepted-assignment)できます。
- **申し込みを取り消す** -- 予定が変わった場合は、締め切り前であれば自分での申し込みを取り消せます。

## 仕組み

教会の管理者が奉仕予定を作成し、一部のポジションを自分で申し込めるものとして設定します。これらのポジションは、「バンド」「おもてなし」「キッズミニストリー」などのカテゴリごとに分けて、ボランティアの申し込みページに表示されます。各ポジションの空き人数を確認し、対応できるポジションに申し込むことができます。

:::info
ボランティアのページに表示されるのは、教会の管理者が自己申し込みを有効にしたポジションのみです。一部のポジションは、直接の割り当てによってのみ埋められる場合があります。
:::
