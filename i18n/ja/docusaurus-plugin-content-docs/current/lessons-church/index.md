# Lessons.church

<div class="article-intro">

Lessons.church は教会向けの完全無料のカリキュラムプラットフォームです。購読料も手数料もなく、利用制限もありません。未就学児から大人まで、さまざまな年齢層を対象に、12以上の提供元による189以上の学習シリーズ、1,100以上の動画ベースのレッスンを提供しています。

</div>

## できること

Lessons.church を使うと、教会では次のようなことができます。

- **コンテンツを閲覧する** -- 複数の提供元による、拡充され続けているプログラムや学習シリーズのライブラリを、年齢層やテーマ別に探せます。
- **クラスを設定する** -- 教会の奉仕体制に合わせてクラスを作成できます(例: 未就学児、小学生、ユース、成人など)。
- **レッスンを予定する** -- 必要な日程に合わせて、特定のレッスンをクラスに割り当てられます。
- **自分の必要に合わせてカスタマイズする** -- 教会の教え方や好みに合わせて、レッスンの内容を調整できます。
- **クラスで発表する** -- 内蔵のプレゼンターモードを使えば、授業中にレッスンを一段ずつ進めて提示できます。

## コンテンツの構成

Lessons.church では、カリキュラムを次のような階層で整理しています。

1. **プログラム** -- 提供元による最上位のカリキュラムシリーズです(例: 子ども向けの奉仕プログラム)。
2. **学習シリーズ** -- プログラム内の関連するレッスンのまとまりです(例: 特定のテーマを扱う4週間のシリーズ)。
3. **レッスン** -- 学習シリーズ内の個々の授業で、通常は1回のクラスで使用します。
4. **会場版** -- 特定の年齢層や場面に合わせて調整されたレッスンの版です(例: 未就学児向けの版と小学生向けの版)。

## 連携機能

Lessons.church は、コンテンツを届けるために他の ChurchApps ツールとも連携します。

- **B1.church** -- ボランティアや保護者は B1 アプリから、今後のレッスンや最近のレッスンを確認できます。
- **FreeShow** -- FreeShow のプレゼンテーションソフトを使えば、レッスンの内容を画面に表示できます。
- **[FreePlay](https://freeplay.church)** -- Android TV、Fire TV、Apple TV 向けの FreePlay アプリを使えば、レッスンをテレビに直接表示できます。
