# 学習の管理

<div class="article-intro">

学習とは、プログラム内の関連するレッスンのまとまりです。たとえば、4週間にわたる「善いサマリア人」というシリーズは、子ども向けミニストリープログラムの中の一つの学習にあたります。このガイドでは、管理画面での学習の作成、編集、整理について説明します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 管理画面で[プログラムを少なくとも1つ作成する](./managing-programs.md)
- Lessons.church の管理者権限を持っている（[管理の概要](./index.md)を参照）

</div>

## 学習の作成

1. **Admin** エリアに移動し、学習を追加したいプログラムを展開します。
2. **Add Study** をクリックします。
3. 以下の項目を入力します。
   - **Name** — 学習の表示名です（例：「善いサマリア人」）。
   - **Slug** — URLに使いやすい識別子です（例：「the-good-samaritan」）。
   - **Description** — この学習で扱う内容と、含まれるレッスン数の概要です。
   - **Image** — 学習のサムネイル画像をアップロードします。
4. 学習を保存します。

## 学習の編集

1. 管理画面の一覧で学習名をクリックします。
2. 必要に応じて項目を更新します。
3. 変更を保存します。

## カテゴリの割り当て

親プログラムで学習カテゴリを使用している場合は、学習をカテゴリに割り当てることができます。

1. 管理画面で学習を開きます。
2. ドロップダウンから **Category** を選択します。
3. 保存します。

カテゴリは、学習数の多いプログラムを利用者が閲覧しやすくするのに役立ちます。たとえば、「旧約聖書」「新約聖書」「テーマ別」といったカテゴリを設けることができます。

## 学習内のレッスンの管理

学習には1つ以上のレッスンが含まれます。管理画面で学習を展開するとそのレッスンを確認でき、**Add Lesson** をクリックすると新しいレッスンを作成できます。レッスンの内容を作成する方法の詳細は、[レッスンの管理](./managing-lessons.md)を参照してください。

## 学習全体に対するリソースのアップロード

学習全体に関連するダウンロード可能なファイル（シリーズの概要、宣伝用グラフィック、保護者向けニュースレターのテンプレートなど）を添付できます。

1. 管理画面で学習を開きます。
2. **Resources** セクションに移動します。
3. ファイルをアップロードします。

:::tip
学習の説明は、教会のリーダーの視点を意識して書きましょう。テーマ、対象年齢層、レッスン数を簡潔にまとめておくと、教会がそのシリーズを採用するかどうかを判断しやすくなります。
:::
