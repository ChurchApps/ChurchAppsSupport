# プログラムの管理

<div class="article-intro">

プログラムは、Lessons.church におけるカリキュラムの最上位のコンテナです。プログラムはカリキュラムシリーズ全体を表します。たとえば「Ark Kids」や「Youth Foundations」がこれにあたります。このガイドでは、管理画面でのプログラムの作成、編集、整理について説明します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- Lessons.church の管理者権限があること（[管理概要](./index.md)を参照）
- プログラム名、説明、サムネイル画像を用意すること

</div>

## プログラムの作成

1. **管理**エリアに移動します。
2. **プログラムを追加**をクリックします。
3. 以下の項目を入力します。
   - **名前** -- プログラムの表示名（例: "Ark Kids"）。
   - **スラッグ** -- URL に使える識別子（例: "ark-kids"）。Web アドレスで使用されます。
   - **説明** -- プログラムの内容を簡単にまとめたもの。
   - **画像** -- プログラムを表すサムネイル画像をアップロードします。
4. プログラムを保存します。

作成したプログラムは、管理画面のプログラム一覧に表示されます。スタディとレッスンが追加されると、公開サイトにも表示されるようになります。

## プログラムの編集

1. 管理画面の一覧でプログラム名をクリックします。
2. 任意の項目（**名前**、**スラッグ**、**説明**、**画像**）を更新します。
3. 変更を保存します。

## プログラム内のスタディの整理

プログラムを作成したら、そこにスタディを追加できます。管理画面では、スタディがプログラムの下に入れ子で表示されます。プログラムの横にある展開矢印をクリックすると、そのプログラムのスタディが表示されます。ここから新しいスタディを追加することもできます。詳しくは[スタディの管理](./managing-studies.md)を参照してください。

## スタディカテゴリ

プログラムにスタディが多い場合は、**カテゴリ**に分けて整理できます。カテゴリを使うと、トピック、年齢層、その他の任意の基準でスタディをグループ化できます。これにより、利用者は大規模なプログラムを閲覧しやすくなります。

## プログラムレベルのリソースのアップロード

プログラムにダウンロード可能なファイルを添付できます。これは、特定のスタディやレッスンではなく、プログラム全体に関わるリソースです。たとえば、スコープ・アンド・シーケンスの文書やボランティア向けのハンドブックなどが該当します。

1. 管理画面でプログラムを開きます。
2. **リソース**セクションに移動します。
3. ファイルをアップロードします。

## キャッシュのクリア

プログラムを変更した後、更新内容を公開サイトに反映するためにキャッシュのクリアが必要な場合があります。管理エリアの**キャッシュをクリア**オプションを使って、コンテンツを更新してください。

:::tip
わかりやすいプログラム名と明確な説明を設定しましょう。教会がカリキュラムライブラリを閲覧するときに最初に目にするのがこの情報です。良い概要があれば、そのプログラムが自分たちの必要に合っているかを判断しやすくなります。
:::
