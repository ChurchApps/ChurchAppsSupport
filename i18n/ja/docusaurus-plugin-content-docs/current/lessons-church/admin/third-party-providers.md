# サードパーティプロバイダー

<div class="article-intro">

Lessons.church は Open Lesson Format を通じて外部のカリキュラムプロバイダーに対応しています。これにより、教会は他の組織のカリキュラムを接続し、内蔵のライブラリと並べて教室のスケジュールに組み込めます。チームは複数のソースのカリキュラムを一か所で利用できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 教会の教室スケジュールを管理できるアカウントで Lessons.church にログインします
- 接続したい外部プロバイダーからフィード URL を入手します。このフィードは [Open Lesson Format](./open-lesson-format.md) でレッスンを返す必要があります

</div>

## プロバイダーの追加

1. Lessons.church のナビゲーションで **External Providers** をクリックします。**External Lesson Providers** ページが開きます。
2. **Add Provider** をクリックします。まだプロバイダーを追加していない場合は、代わりに **Add First Provider** をクリックします。
3. **Provider Name** を入力します。これは、チームがプロバイダーを選ぶときに表示される名前です。
4. **API URL** を入力します。これは、プロバイダーがカリキュラムを Open Lesson Format で公開している場所のアドレスです。
5. **Save** をクリックします。

プロバイダーは教会専用に追加されます。追加後は、教室の[レッスンをスケジュールする](../classrooms/scheduling-lessons.md)際に **Provider** の選択肢として表示され、[年間計画](./managing-year-plans.md)を作成する際には **Source** の選択肢として表示されます。

## プロバイダーの管理

**External Lesson Providers** ページには、教会が追加したすべてのプロバイダーが一覧表示されます。変更するには次のようにします。

- **編集** -- **Edit provider**(鉛筆)アイコンをクリックし、**Provider Name** または **API URL** を変更して、**Save** をクリックします。
- **削除** -- **Edit provider** アイコンをクリックしてから、削除(ゴミ箱)アイコンをクリックし、確認します。

## Open Lesson Format とは

Open Lesson Format は、プログラム、学習会、レッスン、会場、セクション、アクションといったカリキュラムの内容を構造化して記述する標準化されたスキーマです。このフォーマットでコンテンツを公開している組織は、Lessons.church にプロバイダーとして追加できます。

Lessons.church を通じてカリキュラムを提供することに関心のあるコンテンツプロバイダーの方は、[Open Lesson Format](./open-lesson-format.md) ガイドで完全なスキーマのドキュメントを確認できます。

## サードパーティプロバイダーを使う理由

- **教会の選択肢が広がります** -- 教会はプラットフォームを離れることなく、より多様なカリキュラムを閲覧できます。
- **すべてが一か所に** -- ボランティアや調整担当者は、レッスンを探してスケジュールするために複数のウェブサイトを訪れる必要がありません。
- **簡単なセットアップ** -- プロバイダーの追加には、名前とフィード URL を入力するだけです。手作業でのデータ入力やファイルのアップロードは必要ありません。

:::info
サードパーティのコンテンツは、外部プロバイダーが管理しています。プロバイダーのコンテンツが欠けていたり古かったりする場合、問題はプロバイダー側で解決する必要があるかもしれません。
:::

:::tip
外部プロバイダーのレッスンがスケジュールされた後の表示については、ブラウジングのセクションにある [外部プロバイダー](../browsing/external-providers.md) を参照してください。
:::
