# サードパーティ プロバイダー

<div class="article-intro">

Lessons.church は、Open Lesson Format を通じて外部のカリキュラム プロバイダーに対応しています。つまり、他の組織のコンテンツをインポートし、内蔵のライブラリと並べて利用できます。これにより、教会は複数のソースのカリキュラムを 1 か所で利用できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- Lessons.church の管理者権限があること（[管理の概要](./index.md)を参照）
- 接続したい外部プロバイダーからフィード URL を入手しておくこと

</div>

## プロバイダーの追加

1. **管理** エリアに移動します。
2. **サードパーティ** ページを開きます。
3. **プロバイダーを追加** をクリックします（新しい接続を追加する同等のボタンでも可）。
4. プロバイダーの **フィード URL** を入力します。これは、プロバイダーが Open Lesson Format でカリキュラム データを公開している URL です。
5. 接続を保存します。

保存すると、Lessons.church はプロバイダーのコンテンツをインポートします。プロバイダーのプログラム、学習、レッスンが、あなたのコンテンツと並んでカリキュラム ライブラリに表示されます。

## プロバイダーの管理

**サードパーティ** ページでは、接続されているすべてのプロバイダーを確認できます。各プロバイダーについて、次の操作ができます。

- **表示**: インポートされたコンテンツを確認し、正しく取り込まれたかを確かめます。
- **更新**: プロバイダーがエンドポイントを変更した場合に、フィード URL を更新します。
- **削除**: そのプロバイダーのコンテンツを含めたくなくなった場合に、プロバイダーを削除します。

## Open Lesson Format とは

Open Lesson Format は、プログラム、学習、レッスン、会場、セクション、アクションといったカリキュラム コンテンツを構造化された形で記述する、標準化されたスキーマです。このフォーマットでコンテンツを公開している組織であれば、Lessons.church のプロバイダーとして追加できます。

Lessons.church を通じてカリキュラムを提供することに関心のあるコンテンツ プロバイダーの方は、完全なスキーマのドキュメントを [Open Lesson Format](./open-lesson-format.md) のガイドでご覧いただけます。

## サードパーティ プロバイダーを使う理由

- **教会にとっての選択肢の拡大**: 教会は、プラットフォームを離れることなく、より多様なカリキュラムを閲覧できます。
- **すべてが 1 か所に**: ボランティアや調整担当者が、レッスンを探してスケジュールするために複数のウェブサイトを訪れる必要はありません。
- **簡単な設定**: プロバイダーの追加にはフィード URL だけで済みます。手作業でのデータ入力やファイルのアップロードは不要です。

:::info
サードパーティのコンテンツは外部プロバイダーが管理しています。プロバイダーのコンテンツが欠けている、または古いことに気付いた場合は、その問題は提供元で解決が必要な場合があります。
:::

:::tip
教会レベルの外部プロバイダー設定（管理者レベルではないもの）については、閲覧セクションの [外部プロバイダー](../browsing/external-providers.md) ページをご覧ください。
:::
