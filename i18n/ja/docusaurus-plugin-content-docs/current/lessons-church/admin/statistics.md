# 統計

<div class="article-intro">

統計ページでは、管理者がコンテンツの利用状況を確認できます。どのスタディが最も人気があるか、どの教会がリソースをダウンロードしているか、そしてそれらの教会が地理的にどこにあるかを把握できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- Lessons.church の管理者権限があること([管理概要](./index.md)を参照)
- 公開済みのコンテンツを含む[プログラム](./managing-programs.md)が少なくとも 1 つあること

</div>

## 統計へのアクセス

1. **管理**エリアに移動します。
2. **Stats** または **Statistics** ページを選択します。
3. 統計を表示したい**プログラム**を選択します。

## 表示できる内容

統計ページでは、ダウンロードデータをいくつかの視点で確認できます。

### スタディ別のダウンロード数

選択したプログラム内の各スタディについて、ユニークなダウンロード数の内訳を表示します。どのシリーズが最も注目されているかを把握でき、コンテンツ制作にどこで力を入れるべきかを判断する助けになります。

### 教会一覧

プログラムのリソースをダウンロードした教会の一覧です。どのような層に利用されているか、また、コンテンツがどの程度広く採用されているかを把握できます。

### 地域分布

ダウンロードしている教会がどこにあるかを地図で表示します。カリキュラムの地理的な広がりを理解し、コンテンツが人気のある地域を見つけるのに役立ちます。

### 日付範囲でのフィルタリング

すべての統計を日付範囲で絞り込み、特定の期間に焦点を当てられます。時間の経過に伴う傾向を見たり、新しくリリースしたスタディの効果を測ったりするのに便利です。

1. 日付ピッカーを使って**開始日**と**終了日**を設定します。
2. 統計が、その範囲内のアクティビティのみを反映するように更新されます。

## 統計の効果的な活用方法

ダウンロードデータを活かすためのヒントをいくつか紹介します。

- **人気のコンテンツを特定する** -- 最も多くダウンロードされているスタイルやトピックのコンテンツを、さらに増やすことに力を注ぎます。
- **新しいリリースを追跡する** -- 新しいスタディを公開した後、日付で絞り込んで、どれくらい速く利用されているかを確認します。
- **利用者を理解する** -- 教会一覧と地図を使って、誰がコンテンツを利用しているかを確認し、そうしたコミュニティに働きかけることを検討します。

:::info
統計はユニークなダウンロードに基づいています。同じ教会が同じリソースを複数回ダウンロードしても、1 回として数えられます。
:::
