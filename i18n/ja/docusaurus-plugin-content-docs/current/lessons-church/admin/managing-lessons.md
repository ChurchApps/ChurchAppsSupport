# レッスンの管理

<div class="article-intro">

レッスンは、スタディの中の個々の授業セッションです。各レッスンは、1回のクラスの時間に行われる内容を表します。ここでは、ボランティアが教えるときに使う詳細な内容(会場、セクション、役割、アクション)を作成します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [プログラムを作成](./managing-programs.md)し、そこに[スタディを追加](./managing-studies.md)します
- Lessons.church の管理者権限があること([管理の概要](./index.md)を参照)

</div>

## レッスンの作成

1. **管理** エリアに移動し、プログラムとスタディを展開して、レッスンを追加したいスタディを探します。
2. **レッスンを追加** をクリックします。
3. レッスンの **名前** などの詳細を入力します。
4. レッスンを保存します。

## 保護者への持ち帰り情報

各レッスンには、説明欄の下に任意の **保護者への持ち帰り情報** セクションがあります。ここに入力した項目は、授業のあとに保護者がB1グループで(および教室の保護者ページで)見るものです。レッスンの説明文の2つ目としてではありません。

| 項目 | 目的 |
|---|---|
| **要点** | 一文。「神さまは約束を守られます。」 |
| **聖句** | 暗唱聖句の箇所と短い本文。 |
| **質問** | PDFがなくても、保護者が車での移動中に聞ける質問を1つ。 |
| **補足メモ** | 追加の内容(祈りのヒント、家庭でできる活動など)。Markdown形式。空の場合は非表示。 |

要点と質問1つは、概要よりも重要です。その週に保護者向けの内容がない場合は、4項目すべてを空のままにしてください。何も表示されません。

説明欄に保護者向けの内容を入れないでください。説明欄は、lessons.church でレッスンを閲覧する教師向けのカタログ用の文章です。

## レッスンの構造を理解する

各レッスンは、いくつかの階層で構成されています。

- **会場 (Venues)** ―― 年齢層や場面ごとに異なるバージョンのレッスンです。例えば、同じレッスンに「未就学児」会場と「小学生」会場を用意することができます。
- **セクション** ―― 会場内の区切りで、「ようこそ」「動画」「聖書の話」「アクティビティ」などがあります。セクションは授業時間の流れを管理します。
- **役割とアクション** ―― 各セクション内で役割(例：「メインの先生」「小グループのリーダー」)を割り当て、各役割に具体的なアクションを設定します。

## アクションの種類

セクション内の役割に割り当てられるアクションには、次の4種類があります。

- **話す (Say)** ―― ボランティアがクラスに向けて話す文章、または言い換えて伝える内容です。
- **行う (Do)** ―― 実行する身体的な活動や指示です。
- **メモ (Note)** ―― ボランティア向けの背景情報やリマインダーです(読み上げません)。
- **再生 (Play)** ―― セクション中に再生する動画または音声クリップです。

## 会場の追加

1. 管理画面でレッスンを開きます。
2. **会場を追加** をクリックします。
3. 会場の名前を入力します(例：「未就学児」や「小学生」)。
4. 保存します。これで、この会場にセクションを追加できるようになります。

## セクションとアクションの追加

1. 会場を展開して、そのセクションを表示します。
2. **セクションを追加** をクリックし、名前を入力します(例：「ようこそ」)。
3. セクション内で **アクションを追加** をクリックします。
4. **役割**、**アクションの種類**(話す、行う、メモ、再生のいずれか)を選び、内容を入力します。
5. 保存します。

この手順を繰り返して、レッスンの流れ全体を作成します。

## レッスンレベルのリソースのアップロード

レッスンに、ダウンロード可能な資料を直接添付できます。例えば、その週専用のアクティビティシートやぬり絵などです。

1. 管理画面でレッスンを開きます。
2. **リソース** セクションに移動します。
3. ファイルをアップロードします。

:::tip
ボランティアの視点でレッスンを作成してください。セクションとアクションを順番にたどり、初めてのボランティアが他に準備をしなくても進められるかどうかを自問してみてください。
:::
