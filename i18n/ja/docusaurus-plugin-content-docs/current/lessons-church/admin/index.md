# 管理

<div class="article-intro">

Lessons.churchの管理エリアは、コンテンツ作成者と管理者がレッスンライブラリを管理する場所です。ここでカリキュラムの構造を組み立て、リソースをアップロードし、利用統計を確認し、サードパーティのコンテンツプロバイダーと連携できます。

</div>

:::warning
管理機能にはそれに応じた権限が必要です。管理オプションが表示されない場合は、教会の管理者に連絡してアクセス権の付与を依頼してください。
:::

## できること

管理エリアでは、コンテンツを完全に管理できます。

- **プログラムの作成と編集** -- 名前、説明、画像、スラッグを設定して、最上位のカリキュラムシリーズを作成します。
- **スタディの管理** -- 各プログラム内で、関連するレッスンのグループを整理します。
- **レッスンの作成** -- 会場、セクション、役割、アクションを設定して、個別のレッスンを追加します。
- **リソースのアップロード** -- プログラム、スタディ、またはレッスンのレベルで、ダウンロード可能なファイル（PDF、アクティビティシート、画像など）を添付します。
- **統計の確認** -- どのコンテンツが、誰によって、どこからダウンロードされているかを確認します。
- **プロバイダーの設定** -- Open Lesson Formatを使用する外部カリキュラムプロバイダーを接続します。これは管理エリアではなく、**External Providers**ページから行います。
- **年間計画** -- 任意のカリキュラムについて、第1週、第2週、第3週…の順序を公開します。教会はB1 Adminでこれを適用します。

## コンテンツの階層構造

管理者として、コンテンツがどのように構成されているかを理解しておくと役立ちます。

1. **プログラム**には、1つ以上のスタディが含まれます。
2. **スタディ**には、1つ以上のレッスンが含まれます。
3. **レッスン**には、1つ以上の会場（年齢層ごとのバリエーション）が含まれます。
4. **会場**にはセクションが含まれ、**セクション**には役割ごとのアクションが含まれます。

各レベルには、それぞれ独自のダウンロード可能なリソースを添付できます。
