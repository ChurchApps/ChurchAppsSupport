# 年間プランの管理

<div class="article-intro">

年間プランとは、教会がB1 Adminで適用するレッスンの順序付きリストのことです（第1週、第2週、第3週…）。ライブラリにあるどのカリキュラムについてもプランを公開できます。任意のカレンダー項目を設定すると、B1 Adminは第1週がどの月に属するか、またどの週をイースターやクリスマスに合わせる必要があるかを判断できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- Lessons.churchの管理者権限があること
- 公開済みのレッスンを含む[プログラム](./managing-programs.md)が少なくとも1つあること

</div>

## プランの作成

1. **管理 → 年間プラン** を開きます。
2. **追加** をクリックします。
3. 名前（例：「小学生 2026–27」や「High Voltage 1年目」）と、必要に応じてスラッグを入力します。
4. 必要に応じて**既定の会場の優先設定**を指定します。週に会場が指定されていない場合に使われる会場名をカンマ区切りで入力します。
5. 必要に応じて**年の開始月**（例：1月）を設定します。これにより、教会は開始日だけでなく実際の暦年に基づいてプランを適用できます。
6. 教会のメンバーがB1 Adminでプランを見られるようにする場合は**公開**にチェックを入れます。下書きとして残す場合はチェックを外したままにします。
7. 任意のカリキュラムから週を追加します。**ソース**を選び、プログラム、学習、レッスン、会場を選択してから**追加**をクリックします。1つのプランに複数のプログラムを混在させることもできます。矢印を使って順序を並べ替えます。
8. 季節のシリーズの場合は、週の**アンカー**をイースターまたはクリスマスに設定します。シリーズが該当する祝日の前の日曜日で終わるように、学習の最後の週をアンカーに設定してください。
9. 保存します。

教会は、**B1 Admin → 奉仕 → プラン → レッスンをスケジュール → 年間プランを適用** から公開済みのプランを適用します。カレンダーにアンカーされたプランでは対象年と日付の範囲を指定します。それ以外のプランでは、引き続き最初の日付と週数を使用します。適用後、教会はそこで個々の週を編集します。FreePlayはプランに設定された内容をそのまま再生します。
