# レッスンのカスタマイズ

<div class="article-intro">

このガイドでは、教室に合わせてレッスンをカスタマイズする方法を説明します。カスタマイズを使うと、コンテンツを削除したり並べ替えたりして、ボランティアに必要な内容だけを表示できます。過不足のない内容にできます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- ポータルで[教室を少なくとも1つ設定する](../classrooms/setting-up-classrooms.md)
- カスタマイズしたい教室に[レッスンをスケジュールする](../classrooms/scheduling-lessons.md)
- [カスタマイズの概要](./index.md)を読んで、何をカスタマイズできるかを確認する

</div>

## カスタマイズ画面を開く

1. ログインして、**ポータル**に移動します。
2. カスタマイズしたいレッスンがある**教室**を選択します。
3. 教室のスケジュールでレッスンを見つけ、その名前の下にある**カスタマイズ**をクリックします。

**レッスンのカスタマイズ**ページには、レッスンのセクションが一覧表示されます。各セクションの下には役割があり、各役割の下にはアクションがあります。各行の右側にはボタンがあります。

- **上矢印**と**下矢印**：項目を隣の項目と入れ替えて、一つ上または下に移動します
- **削除**（ゴミ箱アイコン）：項目を削除します

:::info
**カスタマイズ**は Lessons.church のレッスンにのみ表示されます。外部プロバイダーからスケジュールされたレッスンには、代わりに**レッスンを表示**が表示され、カスタマイズはできません。
:::

## 変更の適用範囲を選択する

上矢印、下矢印、またはゴミ箱アイコンをクリックするたびに、**選択したカスタマイズを次に適用：**というメニューが表示されます。

- **この教室のみ**：変更は現在の教室だけに適用されます。他の教室には影響しません。
- **すべての教室**：変更は教会内のすべての教室に適用されます。

どちらかを選択すると、変更はすぐに保存されます。別途保存の手順はありません。

## セクションを削除する

セクションが教室に合わない場合は、セクション全体を削除できます。これは、レッスンに複数の年齢層向けのコンテンツが含まれていて、そのうち一つだけが必要な場合に便利です。たとえば、レッスンに「就学前のアクティビティ」と「小学生のアクティビティ」の両方のセクションがある場合、教室に合わない方を削除できます。

1. 削除したいセクションを見つけます。
2. そのセクションの**削除**（ゴミ箱アイコン）ボタンをクリックします。
3. **この教室のみ**または**すべての教室**を選択します。

セクションは削除済みと表示され、そのすべての役割とアクションも含まれます。ボランティアには、このレッスンでそのセクションが表示されなくなります。

## 役割やアクションを削除する

セクション内では、特定の役割やアクションを削除できます。たとえば、セクションに「礼拝リーダー」の役割が含まれているのに、教室にその役割がない場合は、セクション全体を削除せずに、その役割だけを削除できます。

1. セクションの下の一覧で、役割またはアクションを見つけます。
2. その**削除**（ゴミ箱アイコン）ボタンをクリックし、変更を適用する範囲を選択します。

## コンテンツを並べ替える

セクション、役割、アクションを並べ替えて、好みの流れに合わせることができます。

1. 移動したい項目の**上矢印**または**下矢印**をクリックします。
2. 変更を適用する範囲を選択します。項目は隣の項目と入れ替わります。

項目が希望の順序になるまで繰り返します。新しい順序は、ボランティアがレッスンを表示したときに見える順序になります。

## 削除を取り消す

削除した項目を元に戻すには、その**削除**ボタンをもう一度クリックします。メニューには**なし**も表示されるようになります。**なし**を選択すると削除が解除され、項目が再び表示されます。または、もう一方の選択肢を選んで、削除を適用する範囲を変更することもできます。

:::tip
まずは一つの教室で、一つのレッスンをカスタマイズすることから始めてください。手順に慣れてきたら、カスタマイズをすべての教室に広く適用できます。
:::

## カスタマイズが役立つ場合

カスタマイズが特に役立つのは、次のような場合です。

- レッスンに複数の年齢層向けのコンテンツがあり、関連する部分だけを表示したい場合
- 教室で特定の役割を使わない場合（専任の礼拝リーダーや技術担当のボランティアなど）
- レッスンの流れについて、デフォルトで用意された順序とは別の順序にしたい場合

:::info
すべてのレッスンをカスタマイズする必要はありません。コンテンツがそのままで教室に合う場合は、この手順を省略して、[発表](../presenting/index.md)に直接進むことができます。
:::
