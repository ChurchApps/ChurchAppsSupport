# カスタマイズ

<div class="article-intro">

Lessons.churchには、すぐに使えるレッスンコンテンツのライブラリが用意されていますが、教会ごとにニーズは異なります。カスタマイズ機能を使うと、特定のクラスルーム、指導スタイル、年齢層に合わせてレッスンコンテンツを調整でき、ボランティアには自分に関係のある内容だけが表示されます。

</div>

## なぜカスタマイズするのか？

Lessons.churchのレッスンコンテンツは、柔軟に使えるように設計されています。1つのレッスンに、複数の年齢層向けのセクション、任意のアクティビティ、またはすべてのクラスルームには当てはまらない役割が含まれている場合があります。ボランティアに、関係のない部分を読み飛ばしてもらう代わりに、レッスンをカスタマイズして、自分に関係のある内容だけが表示されるようにできます。

たとえば、あるレッスンには未就学児向けには最適だけれど、小学5年生のクラスルームには向かない工作アクティビティが含まれているかもしれません。カスタマイズを使えば、年上のグループではそのセクションを非表示にし、年下のグループでは表示したままにできます。

## カスタマイズできる内容

- **セクションの削除** -- 特定のクラスルームや年齢層に当てはまらないレッスン全体のセクションを削除します。
- **役割またはアクションの削除** -- 必要ない場合は、セクション内の個別の役割やアクションを削除します。
- **コンテンツの並べ替え** -- セクションとアクションを並べ替えて、クラスルームに合った流れに整えます。

## クラスルーム限定か、全体か

変更を加えるたびに、その適用範囲を選択します。

- **このクラスルーム** -- 変更は現在のクラスルームにのみ適用されます。他のクラスルームには元のコンテンツが表示されます。
- **すべてのクラスルーム** -- 変更は教会内のすべてのクラスルームに適用されます。

この柔軟性により、同じレッスンを年齢層ごとに異なる表示にしたり、すべてのクラスルームに一度に適用される変更を加えたりできます。

:::tip
カスタマイズに慣れていない場合は、すべてのクラスルームに変更を適用する前に、まず1つのクラスルームで試して仕組みを確認することをおすすめします。
:::
