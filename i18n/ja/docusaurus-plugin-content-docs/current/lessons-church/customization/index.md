# カスタマイズ

<div class="article-intro">

Lessons.church には、すぐに使えるレッスンコンテンツのライブラリが用意されていますが、教会ごとに状況は異なります。カスタマイズ機能を使うと、お使いの教室、指導スタイル、年齢層に合わせてレッスンコンテンツを調整でき、ボランティアの方には関連する内容だけを表示させることができます。

</div>

## なぜカスタマイズするのか

Lessons.church のレッスンコンテンツは、柔軟に使えるように設計されています。1つのレッスンに、複数の年齢層向けのセクション、任意のアクティビティ、すべての教室には当てはまらない役割などが含まれている場合があります。ボランティアの方に、対象外の部分を頭の中で読み飛ばしてもらう代わりに、レッスンをカスタマイズして、その方に関係する内容だけが表示されるようにできます。

たとえば、レッスンには、未就学児には最適だけれども、5年生の教室には向かない工作のアクティビティが含まれている場合があります。カスタマイズを使えば、年上のグループではそのセクションを非表示にし、年下のグループでは残しておくことができます。

## カスタマイズできる内容

- **セクションの削除** -- 特定の教室や年齢層に当てはまらないレッスンのセクション全体を非表示にします。
- **役割やアクションの非表示** -- 必要ない場合は、セクション内の個々の役割やアクションを削除します。
- **コンテンツの並べ替え** -- セクションやアクションを並べ替えて、教室で好みの流れに合わせます。

## 教室ごとか、全体か

カスタマイズを保存するときに、適用範囲を選択します。

- **単一の教室** -- カスタマイズは現在の教室にのみ適用されます。他の教室には元のコンテンツが表示されます。
- **すべての教室** -- カスタマイズは、教会内のすべての教室に適用されます。

この柔軟性により、同じレッスンでも年齢層ごとに異なる表示を設定したり、すべての教室に一度に適用される変更を加えたりできます。

:::tip
カスタマイズに慣れていない場合は、すべての教室に変更を適用する前に、まず単一の教室で試して動作を確認することをおすすめします。
:::
