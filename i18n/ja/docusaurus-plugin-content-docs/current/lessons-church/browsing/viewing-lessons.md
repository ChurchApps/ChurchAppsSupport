# レッスンの表示

<div class="article-intro">

Lessons.church の各レッスンは、構造化された内容、ダウンロード可能な教材、複数の年齢層への対応を備えた完全な授業セッションです。このガイドでは、レッスンのページを移動して使い方を説明し、授業の準備に役立てる方法を紹介します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [プログラムと学習](./programs-and-studies.md)を読んで、コンテンツの整理方法を理解する
- プログラムと学習を参照して、見たいレッスンを探す

</div>

## レッスンへの移動

レッスンを表示するには、コンテンツの階層をたどって移動します。

1. ホームページで**プログラム**をクリックします。
2. プログラムのページから**学習**を選択します。
3. 学習のページから見たい**レッスン**をクリックします。

## 表示される内容

レッスンのページは、いくつかのエリアで構成されています。

### 動画

レッスンに動画が含まれている場合は、ページの上部に表示されます。クリックすると、ブラウザーで直接再生されます。動画は主な教えの部分として使われることが多く、特に子ども向けの教会学校で多く使用されています。

### セクションと役割

各レッスンは**セクション**(例：「導入」「聖書の物語」「アクティビティ」「締めくくり」)に分かれています。各セクション内では、コンテンツが**役割**ごとに整理されています。

- **リーダー** -- 主な指導者または発表者
- **ヘルパー** -- サポートを行うボランティア
- カリキュラム作成者が定義したその他のカスタムの役割

各役割には、ボランティアが何をすべきかを正確に示す**アクション**が並んでいます。

- **話す** -- 声に出して読む台本や話す要点
- **行う** -- 実際に行う指示や活動
- **メモ** -- ボランティア向けの背景情報やヒント
- **再生** -- 動画や音声クリップを再生するきっかけ

### ダウンロード可能な教材

レッスンには、印刷して使えるファイルが含まれている場合があります。例えば次のようなものです。

- PDF の配布資料
- アクティビティシート
- 塗り絵
- 工作の手順
- 保護者へのお持ち帰り用シート

これらの資料にアクセスするには、レッスンのページ内にあるダウンロードリンクを探してください。印刷用の資料の準備について詳しくは、[ダウンロードと教材](../presenting/downloads.md)を参照してください。

## 会場の切り替え

多くのレッスンは、就学前、小学生、プレティーンなど、異なる年齢層を表す複数の**会場**に対応しています。会場を使うと、同じレッスンのテーマを、各グループに合ったレベルに調整できます。

会場を切り替えるには、次の手順に従ってください。

1. レッスンのページで**会場セレクター**を探します。
2. 別の会場名をクリックします(例：**小学生**から**就学前**に切り替える)。
3. ページが更新され、その年齢層向けに設計された内容、台本、教材が表示されます。

:::tip
複数の年齢層を教えている場合は、授業の前に各会場を確認しておくと、内容が異なるレベルにどのように調整されているかを把握できます。
:::
