# 検索

<div class="article-intro">

教えたいトピックは分かっていても、どのプログラムや学習に含まれているか分からないときは、検索機能を使うと適切なコンテンツをすばやく見つけられます。検索は Lessons.church ライブラリ内のプログラム、学習、レッスンすべてが対象です。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [コンテンツの閲覧](./index.md)の概要を読んで、利用できるすべての移動方法を確認してください

</div>

## 検索の方法

1. Lessons.church サイトの上部にある**検索**アイコンをクリックして、検索ボックスを開きます。
2. キーワードまたはフレーズを入力します(例:「赦し」「ダビデとゴリアテ」「祈り」)。入力中に一致する結果がボックスの下に一覧で表示されます。結果をクリックすると、そのページに直接移動します。
3. **Enter** キーを押すと、検索結果の全ページが開きます。

## 検索の仕組み

検索は、Lessons.church ライブラリにあるすべてのプログラム、学習、レッスンの名前、説明、カテゴリ、年齢層を対象にします。単語の先頭部分にも一致するため、「bapt」と入力すると「baptism」が見つかります。名前に一致した場合が最も高く評価され、プログラムと学習は個々のレッスンより少し上位に表示されます。外部プロバイダーのコンテンツは検索結果に含まれません。

## 結果の見方

各結果には**プログラム**、**学習**、**レッスン**のいずれかのラベルと、設定されている場合は年齢層が表示されます。学習には所属するプログラムが、レッスンには所属する学習とプログラムが表示されます。結果をクリックすると、そのページに直接移動します。レッスンのページには、全内容、セクション、役割、ダウンロード可能な資料が表示されます。

## 検索を使うとき

検索が特に役立つのは次のような場合です。

- 特定の聖書の物語やトピックがあり、それを扱うカリキュラムをすべて確認したいとき。
- 特別なシリーズを計画しており、特定のテーマに関するレッスンを探す必要があるとき。
- 利用可能なプログラムにまだ詳しくなく、提供内容をすばやく確認したいとき。

:::tip
入力した語句により多く一致する結果ほど上位に表示されます。目的の結果が埋もれている場合は、具体的な語句をもう一つ追加してみてください。例えば「善きサマリア人」と入力すると、そのたとえ話に関するレッスンが一番上に来ます。
:::

すでに使いたいプログラムが決まっている場合は、プログラムから閲覧する方が通常は速いです。コンテンツの階層構造の移動方法について詳しくは、[プログラムと学習](./programs-and-studies.md)を参照してください。
