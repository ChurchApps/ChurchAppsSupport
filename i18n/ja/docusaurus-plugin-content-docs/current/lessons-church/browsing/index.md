# コンテンツを閲覧する

<div class="article-intro">

Lessons.church では、誰でも自由に閲覧できる教会カリキュラムのライブラリを提供しています。利用可能なコンテンツを見るのにアカウントやログインは必要ありません。サイトにアクセスして、そのまま見て回るだけで構いません。このセクションでは、カリキュラムを探して閲覧するためのさまざまな方法を説明します。

</div>

## ホームページ

Lessons.church に初めてアクセスすると、ホームページで利用可能なすべてのコンテンツの概要を確認できます。

- **注目のプログラム** -- 厳選されたカリキュラムシリーズがページ上部に表示されます。人気のコンテンツや最近更新されたコンテンツを簡単に見つけられます。
- **すべてのプログラム** -- 注目のセクションの下には、利用可能なすべてのカリキュラムプログラムの一覧があります。各プログラムのレッスン数や学習数などの統計情報も表示されます。
- **プロバイダーのコンテンツ** -- Lessons.church のコンテンツと外部のカリキュラムプロバイダーのコンテンツが一緒に表示されるので、1 か所で探すことができます。

## コンテンツの探し方

カリキュラムライブラリを移動する方法はいくつかあります。

1. **プログラムから閲覧する** -- ホームページでプログラムをクリックすると、そのプログラムの学習とレッスンが表示されます。特定のカリキュラムシリーズを詳しく見たいときに最適な方法です。詳しくは [プログラムと学習](./programs-and-studies.md) を参照してください。

2. **検索する** -- 検索ページを使うと、ライブラリ全体からキーワードでレッスンを探せます。トピックは分かっているものの、どのプログラムに含まれているか分からないときに便利です。詳しくは [検索](./searching.md) を参照してください。

3. **外部プロバイダーを探す** -- 一部のコンテンツは、Open Lesson Format で公開しているサードパーティのカリキュラムプロバイダーから提供されています。内蔵のコンテンツと同じように、それらのプログラムや学習を閲覧できます。詳しくは [外部プロバイダー](./external-providers.md) を参照してください。

## ログインは不要

閲覧はすべて自由に行えます。アカウントを作成しなくても、プログラム、学習、レッスン、ダウンロード可能な資料、動画を見ることができます。クラスルームのレッスンをスケジュールしたり、コンテンツをカスタマイズしたりしたくなったら、そのときに[無料アカウントを作成](../getting-started/creating-account.md)できます。

:::tip
特定の学習に入る前に、まずホームページでいくつかのプログラムを見て、カリキュラムの構成をつかんでおくとよいでしょう。
:::
