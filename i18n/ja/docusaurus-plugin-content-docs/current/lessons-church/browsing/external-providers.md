# 外部プロバイダー

<div class="article-intro">

Lessons.church は自社のカリキュラムだけに限定されていません。サードパーティのカリキュラム提供者は、**オープンレッスン形式**を通じてコンテンツを公開できます。教会がプロバイダーを追加すると、Lessons.church のライブラリの隣にあるそのプロバイダーのレッスンを、教室向けにスケジュールできるようになります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [プログラムと学習課程](./programs-and-studies.md)を読んで、コンテンツの整理方法を理解してください
- プロバイダー接続を追加するには、教会の教室スケジュールにアクセスできる [Lessons.church アカウント](../getting-started/creating-account.md)が必要です

</div>

## 外部プロバイダーとは

外部プロバイダーとは、オープンレッスン形式、つまりプラットフォームをまたいでレッスンコンテンツを共有できる標準を使って教会向けカリキュラムを公開する組織のことです。提供者がこの形式でコンテンツを公開すると、Lessons.church はそれを読み取り、自社のレッスンと同じレイアウトで表示できます。

これにより、複数のウェブサイトを訪れることなく、より幅広いカリキュラムの中から選べるようになります。

## プロバイダー接続の追加

教会がオープンレッスン形式に対応したカリキュラム提供者を利用している場合:

1. Lessons.church アカウントにログインします。
2. ナビゲーションの **External Providers** をクリックします。
3. **Add Provider** をクリックし、**Provider Name** とプロバイダーの **API URL** を入力して、**Save** をクリックします。

手順の詳細は、[サードパーティプロバイダー](../admin/third-party-providers.md)を参照してください。

:::info
外部プロバイダーは、追加した教会専用になります。そのプログラムは Lessons.church の公開ホームページや検索結果には表示されません。
:::

## 外部コンテンツの利用

プロバイダーを追加すると、スケジュールを組む際にそのプログラム、学習課程、レッスンを利用できるようになります。

1. [教室のスケジュールにレッスンを追加する](../classrooms/scheduling-lessons.md)際に、**Provider** でプロバイダーを選択します。
2. **Program**、**Study**、**Lesson**、**Venue** は、Lessons.church のレッスンを選ぶときと同じ方法で選択します。
3. 教室のスケジュールで、予定された外部レッスンの下にある **View Lesson** をクリックすると開きます。内蔵のレッスンと同じレイアウトで表示され、セクション、役割、アクション、動画、ダウンロード可能な資料が含まれます。

:::note
外部プロバイダーのレッスンは、[カスタマイズ](../customization/customizing-lessons.md)できません。**Customize** リンクが表示されるのは Lessons.church のレッスンのみです。
:::

## コンテンツ制作者の方へ

Lessons.church でコンテンツを公開することに関心のあるカリキュラム発行者の方は、オープンレッスン形式を使って、プログラム、学習課程、レッスンを標準化された方法で共有できます。連携の詳細については、Lessons.church チームへお問い合わせいただくか、開発者向けドキュメントをご覧ください。

:::tip
プロバイダーの追加、編集、削除の手順については、[サードパーティプロバイダー](../admin/third-party-providers.md)を参照してください。
:::
