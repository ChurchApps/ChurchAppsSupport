# 外部プロバイダー

<div class="article-intro">

Lessons.church は自社のカリキュラムだけに限定されません。サードパーティのカリキュラムプロバイダーは、**Open Lesson Format**（オープン・レッスン・フォーマット）を使ってコンテンツを公開でき、そのコンテンツは Lessons.church の組み込みプログラムと並んで表示されるため、一元化された閲覧体験が得られます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [プログラムと学習課程](./programs-and-studies.md)を読んで、コンテンツがどのように整理されているかを理解してください
- プロバイダー接続を追加するには、教会のポータルにアクセスできる [Lessons.church アカウント](../getting-started/creating-account.md)が必要です

</div>

## 外部プロバイダーとは

外部プロバイダーとは、Open Lesson Format（レッスンコンテンツをプラットフォームをまたいで共有できる標準規格）を使って教会向けカリキュラムを公開する組織のことです。プロバイダーがこの形式でコンテンツを提供すると、Lessons.church はそれを取り込み、自社のプログラムと同じように表示できます。

これにより、複数のウェブサイトを訪れることなく、より幅広いカリキュラムを利用できるようになります。

## 外部コンテンツの閲覧

外部プロバイダーのコンテンツは、組み込みコンテンツとまったく同じように動作します。

1. 外部プロバイダーのプログラムは、他のプログラムと並んで Lessons.church のホームページに表示されます。
2. **プログラム**をクリックすると、その学習課程が表示されます。
3. **学習課程**をクリックすると、そのレッスンが表示されます。
4. レッスンは、セクション、役割、アクション、動画、ダウンロード可能な教材など、同じレイアウトで表示されます。

外部コンテンツ専用の特別な手順や別のセクションはありません。すべてが 1 つのライブラリに統合されているため、簡単に閲覧できます。

## プロバイダー接続の追加

教会が Open Lesson Format に対応したカリキュラムプロバイダーを利用しており、そのコンテンツを Lessons.church ポータルで使えるようにしたい場合は、次の手順を行います。

1. Lessons.church アカウントにログインします。
2. ポータルの **External Providers**（外部プロバイダー）ページに移動します。
3. 外部プロバイダーの接続 URL を追加します。
4. そのプログラムと学習課程が、教会で閲覧、スケジュール登録、教室での利用に使えるようになります。

:::info
外部プロバイダーの接続追加は Lessons.church ポータルから行い、ログインしたアカウントが必要です。プラットフォーム側で既に追加されたコンテンツの閲覧には、アカウントは必要ありません。
:::

## コンテンツ制作者の方へ

Lessons.church でご自身のコンテンツを提供したいカリキュラム発行者の方は、Open Lesson Format を使うと、プログラム、学習課程、レッスンを標準化された形で共有できます。統合の詳細については、Lessons.church チームにお問い合わせいただくか、開発者向けドキュメントをご覧ください。

:::tip
プラットフォームレベルでサードパーティのプロバイダーフィードを管理している管理者の方は、管理セクションの[サードパーティプロバイダー](../admin/third-party-providers.md)をご覧ください。
:::
