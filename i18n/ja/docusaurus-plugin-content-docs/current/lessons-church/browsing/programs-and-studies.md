# プログラムと学習単元

<div class="article-intro">

Lessons.church のすべてのカリキュラムは、明確な階層構造で整理されています。この構造を理解しておくと、教会に合ったコンテンツをすばやく見つけ、関連するレッスン同士を簡単に行き来できるようになります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- コンテンツを探すさまざまな方法を理解するために、[コンテンツの閲覧](./index.md)の概要をご確認ください

</div>

## コンテンツの階層

コンテンツは、最も広い範囲から最も具体的な範囲へと整理されています。

- **提供元** -- カリキュラムを公開している組織です（Lessons.church またはサードパーティの提供元）。
- **プログラム** -- 「Ark Kids」や「NextLevel」などのカリキュラムシリーズです。各プログラムは、テーマや対象年齢層を中心に設計された関連する学習単元の集まりです。
- **学習単元** -- プログラム内の一つの単元で、「よきサマリア人」などが該当します。各学習単元には、数週間にわたって続けて教えることを想定したレッスンのまとまりが含まれます。
- **レッスン** -- 学習単元内の個々の授業です。各レッスンには、セクション、役割、アクション、ダウンロード可能な教材が含まれます。
- **対象年齢** -- レッスンの年齢層別バージョンです（例：就学前や小学生向け）。対象年齢を選ぶと、同じレッスンを異なる聴衆に合わせて調整できます。

## プログラムの閲覧

プログラムを探すには、次の手順に従ってください。

1. Lessons.church のホームページにアクセスします。
2. 利用可能なプログラムの一覧をスクロールするか、上部にある注目のプログラムを確認します。
3. **プログラム名**またはその画像をクリックして、プログラムのページを開きます。

各プログラムのページには、次の内容が含まれています。

- **説明** -- カリキュラムの内容と、対象となる人々の概要です。
- **プログラム画像** -- シリーズを象徴するビジュアルです。
- **紹介動画** -- 一部のプログラムには短いプレビュー動画があり、導入前にコンテンツのスタイルや品質を確認できます。
- **学習単元** -- プログラム内のすべての学習単元の一覧です。カテゴリ別に分類されている場合もあります。

## 学習単元の閲覧

プログラムのページから、次の手順に従ってください。

1. 学習単元の一覧を確認します。プログラムが学習単元をカテゴリに分けている場合は、それに従ってグループ表示されます。
2. **学習単元名**をクリックして、学習単元のページを開きます。
3. 学習単元のページには、その単元に含まれるすべてのレッスンが、教える順序で表示されます。

ここから任意のレッスンをクリックすると、セクション、役割、ダウンロード可能な教材を含む全内容を確認できます。詳しい手順については、[レッスンの閲覧](./viewing-lessons.md)をご覧ください。

:::info
プログラムと学習単元は、カリキュラムの提供元が管理しています。コンテンツ制作者である場合は、[管理](../admin/index.md)エリアから自分のプログラムと学習単元を管理できます。
:::
