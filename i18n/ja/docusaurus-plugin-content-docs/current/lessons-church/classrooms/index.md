# 教室

<div class="article-intro">

教室は、Lessons.church で教会の授業を整理する基本単位です。教室とは、授業が行われる物理的または仮想的な部屋を指します。たとえば「未就学児の部屋」「小学校低学年クラス」「成人聖書研究」などです。このセクションでは、教室の作成と、教室への授業のスケジュール設定について説明します。

</div>

## 教室が重要な理由

教室を設定すると、子ども向けの活動、青年グループ、その他の教育の場に明確な体制を作れます。教室ごとに独自のスケジュールが設定されるため、ボランティアは何をいつ教えるべきかを常に把握できます。紙の予定表を回したり、直前にメールで連絡したりする必要はなく、全員がポータルで今後の予定を確認できます。

## 教室でできること

- **教室を無制限に作成** -- 教会に必要なだけ教室を設定できます。上限はないため、年齢層、拠点、プログラムごとに別々の教室を用意できます。
- **授業をスケジュール** -- 特定の授業を特定の日付で各教室に割り当てます。スケジュールでは、過去の授業と今後の授業をひと目で確認できます。
- **コンテンツをカスタマイズ** -- ボランティアが自分の年齢層に関係する内容だけを見られるよう、教室ごとに授業内容を調整します。詳しくは [カスタマイズ](../customization/index.md) をご覧ください。

## 教室の仕組み

教室は、Lessons.church の授業コンテンツを、教会の実際の授業スケジュールとつなぐ役割を果たします。一般的な流れは次のとおりです。

1. Lessons.church で利用可能なプログラムや研究教材を [閲覧](../browsing/index.md) します。
2. 教会の部屋や年齢層に合わせて教室を設定します。
3. 今後の日付に合わせて、各教室に授業をスケジュールします。
4. ボランティアは自分の教室を開いて、予定されている内容を確認し、準備します。
