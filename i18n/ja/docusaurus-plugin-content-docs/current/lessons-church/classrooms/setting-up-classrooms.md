# クラスルームの設定

<div class="article-intro">

レッスンをスケジュールする前に、教室や学習環境を表すクラスルームを作成する必要があります。このガイドでは、Lessons.church ポータルでクラスルームを作成、命名、管理する手順を説明します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [アカウントを作成する](../getting-started/creating-account.md)と、教会との接続
- [ポータルの概要](../getting-started/portal-overview.md)に慣れておく

</div>

## クラスルームの作成

1. [Lessons.church](https://lessons.church) でアカウントにログインします。
2. **ポータル** に移動します。ここは、クラスルームやスケジュールを管理する教会の中心的なハブです。
3. **クラスルーム** ボックスで **追加** をクリックします。まだクラスルームがない場合は、代わりに **最初のクラスルームを追加** をクリックします。
4. **クラスルーム名** を入力します。ボランティアがすぐに分かる、わかりやすい名前を選んでください。例：「未就学児」「小学校 1〜2 年生」「中学生」など。
5. **保存** をクリックします。新しいクラスルームが **クラスルーム** の一覧にすぐに表示されます。

教会にある教室や年齢層ごとに、これらの手順を繰り返してください。必要な数だけクラスルームを作成できます。

## 初回セットアップ

まだクラスルームを設定していない場合、ポータルにセットアップ動画が表示され、手順を案内します。この動画では、クラスルームの作成と最初のレッスンのスケジュール設定の基本を扱います。Lessons.church を初めて使う方にとって良い出発点です。

:::tip
クラスルームの名前は、ボランティアがすでに教室を呼んでいる名前に合わせてください。みんなが「Pre-K の部屋」と呼んでいるなら、「幼児教育室 101 号室」のような堅い名前ではなく「Pre-K」と名付けましょう。
:::

## クラスルームの管理

クラスルームはポータルのダッシュボードに表示され、いつでも管理できます。ここから次の操作が行えます。

- **クラスルーム名の変更** -- 該当するクラスルームの横にある **クラスルームを編集**（鉛筆）アイコンをクリックし、**クラスルーム名** を変更して **保存** をクリックします。
- **クラスルームの削除** -- **クラスルームを編集** をクリックし、次に **クラスルームを削除**（ゴミ箱）アイコンをクリックして確認します。
- **スケジュールの表示** -- クラスルームをクリックすると、そのレッスンスケジュールが表示されます。

## 次のステップ

クラスルームの設定が済んだら、[レッスンのスケジュール設定](./scheduling-lessons.md)に進み、ボランティアが毎週何を教えるべきかを把握できるようにしましょう。
