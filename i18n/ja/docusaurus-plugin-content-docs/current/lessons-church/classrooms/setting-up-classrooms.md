# 教室の設定

<div class="article-intro">

レッスンをスケジュールする前に、授業を行う環境を表す教室を作成する必要があります。このガイドでは、Lessons.church のポータルで教室を作成、命名、管理する手順を説明します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [アカウントを作成する](../getting-started/creating-account.md)し、教会と接続する
- [ポータルの概要](../getting-started/portal-overview.md)に慣れておく

</div>

## 教室を作成する

1. [Lessons.church](https://lessons.church) でアカウントにログインします。
2. **ポータル**に移動します。ここが教会の教室やスケジュールを管理する中心的な場所です。
3. **教室を追加**をクリックします。
4. 教室の名前を入力します。ボランティアがすぐにわかる、わかりやすい名前を選んでください。例：「未就学児」「小学校 K〜2年」「中学校」など。
5. 新しい教室を保存します。すぐにポータルのダッシュボードに表示されます。

教会にある部屋や年齢層ごとに、この手順を繰り返してください。必要な数だけ教室を作成できます。

## 初回セットアップ

まだ教室を設定していない場合、ポータルにセットアップ動画が表示され、手順を案内します。この動画では、教室の作成と最初のレッスンのスケジュール設定の基本を扱います。Lessons.church を初めて使う方にとって良い出発点です。

:::tip
教室の名前は、ボランティアがふだん部屋を呼んでいる言い方に合わせてください。みんなが「プレK の部屋」と呼んでいるなら、「Early Childhood Education Room 101」のような堅い名前ではなく「プレK」と名付けましょう。
:::

## 教室を管理する

教室はポータルのダッシュボードに表示され、いつでも管理できます。ここからは次のことができます。

- **教室の名前を変更する** -- 部屋や年齢層が変わった場合は、名前を更新してください。
- **教室を削除する** -- 不要になった教室を削除します。
- **スケジュールを表示する** -- 教室をクリックすると、その教室のレッスンスケジュールを確認できます。

## 次のステップ

教室の設定が終わったら、[レッスンのスケジュール設定](./scheduling-lessons.md)に進み、ボランティアが毎週何を教えればよいかを把握できるようにしましょう。
