# レッスンのスケジュール設定

<div class="article-intro">

教室の設定が済んだら、次はボランティアが何をいつ教えるのかを把握できるように、レッスンをスケジュールします。スケジュール設定によって、Lessons.church のレッスン内容を教室のカレンダーに結び付けられます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- ポータルで[教室を少なくとも1つ設定する](./setting-up-classrooms.md)
- [コンテンツライブラリを閲覧する](../browsing/index.md)で、教えたいプログラムと学習を探す

</div>

## 教室のスケジュールを表示する

1. ログインして、**ポータル**に移動します。
2. スケジュールを組みたい**教室**をクリックします。
3. スケジュール画面には、**直近の過去4回のレッスン**と**今後の4回のレッスン**が表示されます。これにより、最近教えた内容と今後の予定をすぐに確認できます。

## スケジュールにレッスンを追加する

1. 教室のスケジュール画面から、新しいレッスンを追加するボタンをクリックします。
2. レッスンの**日付**を選択します。
3. 教えたい**プログラム**を選びます(例:「子どものための聖書物語」)。
4. そのプログラム内の**学習**を選択します(例:「創造と初期の物語」)。
5. スケジュールしたい特定の**レッスン**を選びます。
6. この教室に適した**会場**を選びます。会場とは、年齢層ごとに調整されたレッスン内容のバージョンを指します(例:「未就学児」や「小学生」)。適切な会場を選ぶことで、ボランティアは自分の教室の年齢層に合ったコンテンツを確認できます。
7. スケジュールしたレッスンを保存します。

これで、そのレッスンが指定した日付の教室のスケジュールに表示されます。

:::info
プログラム、学習、レッスンは Lessons.church におけるコンテンツの階層構造です。プログラムには複数の学習が含まれ、各学習には個々のレッスンが含まれます。会場は、同じレッスンの年齢別バリエーションを提供します。詳しくは [プログラムと学習](../browsing/programs-and-studies.md) をご覧ください。
:::

## ボランティアがスケジュールを利用する方法

レッスンをスケジュールしておくと、ボランティアはポータルを開いて自分の教室を選ぶだけで、今後の予定をすぐに確認できます。事前にレッスン内容を確認したり、必要な資料をダウンロードしたりして、準備を整えて来られます。次に何を教えるのかで迷うこともなくなります。

## スケジュール設定のヒント

- **事前に計画する** -- 教会では、公開済みの年間計画を適用することを含め、教室のレッスンを [B1 Admin](../../b1-admin/serving/scheduling-lessons.md) でスケジュールしています。
- **一貫性を保つ** -- プログラムを順番どおりに進めると、子どもたちは前週に学んだことを土台に学びを積み重ねられます。
- **履歴を確認する** -- 過去のレッスン一覧を使って、同じ内容を誤って繰り返していないか確認しましょう。

:::warning
教室の年齢層に合った会場を必ず選んでください。誤った会場を選ぶと、ボランティアが別の年齢層向けのコンテンツを見てしまいます。
:::

## 次のステップ

レッスンをスケジュールした後は、教室ごとの指導スタイルや年齢層のニーズに合わせて、[レッスン内容をカスタマイズする](../customization/customizing-lessons.md)とよいでしょう。授業の時間になったら、[プレゼンテーション](../presenting/index.md)について学び、レッスンを効果的に届ける方法を確認してください。
