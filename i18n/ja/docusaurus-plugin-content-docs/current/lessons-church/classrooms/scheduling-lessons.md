# レッスンのスケジュール設定

<div class="article-intro">

教室の設定が済んだら、次はレッスンをスケジュールして、ボランティアが何をいつ教えるべきかを正確に把握できるようにします。スケジュール設定によって、Lessons.churchのレッスンコンテンツが教室のカレンダーと結びつきます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- ポータルで[教室を少なくとも1つ設定する](./setting-up-classrooms.md)
- [コンテンツライブラリを参照する](../browsing/index.md)で、教えたいプログラムと学習を探す

</div>

## 教室のスケジュールを表示する

1. ログインして、**ポータル**に移動します。
2. スケジュールを設定したい**教室**をクリックします。
3. **レッスンスケジュール**のボックスに、その教室にスケジュールされたすべてのレッスンが、日付の新しい順に表示されます。各レッスンには**今後**、**今日**、**過去**のいずれかのタグが付いているため、最近教えた内容と、これから教える内容をひと目で確認できます。

## レッスンをスケジュールに追加する

1. **レッスンスケジュール**のボックスで、**スケジュールを追加**をクリックします。教室にまだスケジュールがない場合は、代わりに**最初のスケジュールを追加**をクリックします。
2. レッスンの**スケジュール日**を入力します。
3. [外部プロバイダー](../admin/third-party-providers.md)を追加している場合は、**プロバイダー**を選択します。Lessons.churchのライブラリからスケジュールする場合は、**Lessons.church**のままにしておきます。
4. 教えたい**プログラム**を選択します(例:「子ども向け聖書物語」)。
5. そのプログラム内の**学習**を選択します(例:「創造と初期の物語」)。
6. スケジュールしたい特定の**レッスン**を選びます。
7. この教室に適した**会場**を選択します。会場とは、年齢グループごとに調整されたレッスンコンテンツのバージョンを指します(例:「未就学児」や「小学生」)。適切な会場を選ぶと、ボランティアが教室の年齢層に合ったコンテンツを見ることができます。
8. **保存**をクリックします。事前に内容を確認したい場合は、**プレビュー / 印刷**をクリックすると、新しいタブでレッスンが開きます。

これで、そのレッスンが指定した日付の教室のスケジュールに表示されるようになります。

:::info
プログラム、学習、レッスンは、Lessons.churchにおけるコンテンツの階層構造です。プログラムには複数の学習が含まれ、各学習には個々のレッスンが含まれます。会場は、同じレッスンの年齢別のバリエーションを提供します。詳しくは[プログラムと学習](../browsing/programs-and-studies.md)を参照してください。
:::

## ボランティアによるスケジュールの利用方法

レッスンをスケジュールすると、ボランティアはポータルを開いて自分の教室を選択するだけで、これから何があるかをすぐに確認できます。レッスンの内容を事前に確認したり、必要な資料をダウンロードしたりして、準備を整えて来られます。次に何を教えるかで迷うことはなくなります。

## スケジュール設定のヒント

- **事前に計画する** -- 教会は[B1 Admin](../../b1-admin/serving/scheduling-lessons.md)で教室のレッスンをスケジュールします。公開済みの年間計画を適用することもできます。
- **一貫性を保つ** -- プログラムを順番に進めると、子どもたちは前の週に学んだことを土台にして学びを積み重ねられます。
- **履歴を確認する** -- 過去のレッスン一覧を使って、同じ内容を誤って繰り返していないか確認します。

:::warning
教室の年齢層に合った会場を必ず選んでください。誤った会場を選ぶと、ボランティアは別の年齢層向けに作られたコンテンツを見ることになってしまいます。
:::

## 次のステップ

レッスンをスケジュールした後は、教室ごとに[レッスンの内容をカスタマイズする](../customization/customizing-lessons.md)ことで、指導スタイルや年齢層のニーズに合わせられます。授業の時間になったら、[発表](../presenting/index.md)について学び、レッスンを効果的に届けましょう。
