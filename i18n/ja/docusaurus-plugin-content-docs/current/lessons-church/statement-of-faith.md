# 信仰告白

<div class="article-intro">

人の手によって作られたいかなる声明も、聖書が示す信仰の全体を言い尽くすことはできないと私たちは認めています。それでも、ChurchApps を一つの組織として支える中心的な信仰を明確にするため、この声明を公表します。これらの信仰は、Lessons.church で提供されるすべてのカリキュラムの選定とレビューの指針となります。

</div>

**神:** 唯一の聖なる神がおられ、父、子、聖霊という三つの位格において永遠に存在されます。神はすべての見えるものと見えないものを創造されました。神は知恵、力、愛において完全であり、過去、現在、未来のすべてを知っておられます。そして、贖いについての神の主権的な計画は、世の基が据えられる前に定められていました。(創 1:1-2、申 6:4、ヘブ 11:3、エフェ 1:9-10、黙 13:8)

**イエス:** イエス・キリストは神の独り子であり、処女マリアから生まれ、完全な神であると同時に完全な人であり、私たちの救い主であり主です。罪のないイエスは、私たちの罪のために身代わりの犠牲として十字架で死なれ、神の怒りを身に負い、イエスを信じるすべての人を神と和解させてくださいました。イエスは体をもって復活し、罪と死に勝利されました。そして父の右の座に昇られ、栄光のうちに再臨されるまで、王、大祭司、また弁護者として今も統治しておられます。(ヨハ 3:16、コロ 1:15; 2:9-15、一コリ 15:3-8, 20-28、二コリ 5:18-21、ヘブ 4:14-15)

**聖霊:** 聖霊は完全な神であり、教会と世界において働いておられます。聖霊は福音を照らし、罪を自覚させることによって、すべての人をキリストへと導かれます。聖霊は信者の内に住まわれ、実り豊かなキリスト者の歩みへと人を変え、導き、確信を与え、力づけてくださいます。(ヨハ 16:8-11、使 2:38、二コリ 3:17-18、ガラ 3:2)

**聖書:** 神は聖書において啓示されています。聖書は神の霊感によって記された唯一の御言葉であり、その語るすべてのことにおいて誤りがありません。聖書は信仰と生活のあらゆる事柄における最終的な権威です。(二テモ 3:16、二ペト 1:20-21)

**人間:** 神はすべての人を男性と女性として、ご自身のかたちに創造されました。それゆえ、すべての人は本質的な価値と目的を持っています。最初の男と女であるアダムとエバの罪によって、死がこの世に入りました。すべての人は罪を犯し、神の栄光に届かず、神から離れ、イエス・キリストの血によらなければ希望がありません。(創 1:26-27、創 3 章、ロマ 3:23、エフェ 2:1-3)

**救い:** 救いはキリストのみにあり、恵みによって信仰を通してすべての人に差し出されています。生きた信仰は、悔い改め、告白、浸礼による洗礼、そして従順な生き方によって示されます。(ロマ 3:23; 5:12、使 2:38、ガラ 3:26-29、エフェ 2:4-10)

**教会:** 教会はこの地上におけるキリストのからだであり、キリストがかしらです。神の教会は、すべての信者による祭司職から成り立ち、神から与えられた賜物に応じて福音の奉仕者として仕えます。教会は共に、キリストが再び来られるまで、すべての国の人々を弟子とするために召されています。(マタ 28:18-20、エフェ 3:10; 4:11-13、コロ 1:18、一ペト 2:9-10)

**キリストの再臨:** キリストは目に見える形で再び来られ、被造物を回復し、世界を裁かれます。信者は体の復活を経て神とともに天で永遠の命を受け、不信者は地獄で永遠の裁きを受けます。天においては罪はもはやなく、キリストにある人々は神との交わりの中で永遠に生きます。(使 1:11、二テサ 1:5-12、一テサ 4:13-18、黙 20:11-15)

## カリキュラムに関する指針

Lessons.church は、多様なキリスト教の出版元によるカリキュラムを用いています。私たちが提供するすべてのレッスンは、聖書的な正確さと教理的な健全さについて、社内のレビューによって精査されています。教会の中には多様な見解があることを私たちは理解しており、私たちは共通する点で一致することを選びます。各カリキュラムの著者に関する情報は、個々のレッスンの「About」セクションに記載されています。

特定のレッスンやシリーズについてご質問がある場合は、お気軽に私たちにお問い合わせください。
