# ボランティア向けガイド

<div class="article-intro">

Lessons.church のすべてのレッスンには、特定のボランティアの役割に合わせたガイドが含まれています。レッスンプラン全体を各ボランティアに渡す代わりに、その役割に関連する指示だけを示したガイドを案内できます。これにより、内容がシンプルで分かりやすくなります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [レッスンの閲覧](../browsing/viewing-lessons.md)を読んで、レッスンの構成を理解する
- ガイドを準備したいレッスンに移動する

</div>

## ガイドの構成

レッスンは**セクション**（例：「ウェルカム」「聖書の物語」「小グループでの活動」）に分けられています。各セクション内では、**役割**に特定の**アクション**が割り当てられています。アクションには次の4種類があります。

- **話す** -- ボランティアが読み上げる、または言い換えて伝える台本のテキスト。
- **する** -- ボランティアが行う身体的な動作や活動。
- **メモ** -- ボランティア向けの背景情報やリマインダー（声には出さない）。
- **再生** -- クラスで再生する動画または音声クリップ。

ボランティアがガイドを開くと、各セクションが順番に表示され、その人の役割に割り当てられたアクションだけが表示されます。これにより、内容がシンプルで分かりやすく保たれます。

## ボランティアガイドの表示

1. 準備したいレッスンを開きます。
2. そのレッスンの会場に関連付けられた**役割**の一覧を探します。
3. 役割名をクリックして、その役割のガイドを開きます。

ガイドは、各セクションを段階的な手順として表示します。ボランティアは、授業中にスマートフォン、タブレット、またはコンピューターでスクロールして確認できます。

## ガイドの印刷

紙のコピーを希望するボランティアのために、どのガイドもブラウザーから直接印刷できます。

1. 対象の役割のガイドを開きます。
2. ブラウザーの**印刷**機能を使います（**Ctrl+P** または **Cmd+P**）。
3. ページを印刷するか、PDF として保存して後で配布します。

:::tip
ボランティアには、事前にガイドのリンクを共有しておきましょう。授業前に自分の指示を確認できます。平日に一度目を通しておくと、日曜の朝に全員が安心して準備できます。
:::

## 複数の役割

レッスンによっては、複数の役割があります。たとえば、主担当の教師、小グループのリーダー、技術担当のボランティアなどです。役割ごとに専用のガイドがあるため、レッスンに必要な数だけ専門的なガイドを用意できます。

:::info
教室で使わない役割がある場合は、[カスタマイズ](../customization/customizing-lessons.md)機能でその役割を非表示にできます。そうすれば、ボランティアには必要な役割だけが表示されます。
:::
