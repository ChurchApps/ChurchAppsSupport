# ダウンロードと教材

<div class="article-intro">

Lessons.church のレッスンには、印刷したりデジタルで共有したりできるダウンロード可能な教材が付いています。これらの教材はレッスンの内容を補完し、授業中や授業後にボランティアや生徒が取り組める具体的な素材を提供します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [レッスンを閲覧する](../browsing/viewing-lessons.md)か、[クラスのスケジュール](../classrooms/scheduling-lessons.md)から予定されているレッスンを開きます

</div>

## 教材の種類

レッスンや提供元によって、次のような教材が見つかることがあります。

- **アクティビティシート** -- 授業中に生徒が取り組む実践的なワークシートです。
- **塗り絵** -- 年少の年齢層向けの印刷用ページです。
- **リーダーガイド** -- 教師向けの詳しい指示と背景情報です。
- **補足の PDF** -- 追加の読み物、持ち帰り用のシート、保護者向けの配布資料などです。

すべてのレッスンにこれらがすべて含まれているわけではありません。利用できる教材は、コンテンツ提供者が用意したものによって異なります。

## ダウンロードの探し方

教材は次の3つのレベルで提供されています。

- **プログラムレベル** -- カリキュラムシリーズ全体に適用される一般的な教材です。
- **スタディレベル** -- プログラム内の特定のスタディに関連する教材です。
- **レッスンレベル** -- 個々のレッスン向けの教材です。

教材をダウンロードするには、次の手順に従ってください。

1. レッスン、スタディ、またはプログラムのページに移動します。
2. ページの **Downloads** または **Resources** セクションを探します。
3. ファイル名をクリックして、デバイスにダウンロードします。

ファイルは通常 PDF 形式で、すぐに印刷できる状態になっています。

## 授業の準備

授業の数日前にダウンロード可能な教材を確認しておくとよいでしょう。

1. 次のレッスンを開き、利用可能なダウンロードを確認します。
2. 予想される出席者数分だけ、アクティビティシートと塗り絵を印刷します。
3. レッスンの流れを把握できるように、リーダーガイドに目を通します。
4. 授業の終わりに配布する持ち帰り用の教材を用意します。

:::info
提供元によっては、個々のレッスンに添付するのではなく、すべての教材をスタディレベルにまとめて含めている場合があります。特定のレッスンページにダウンロードが見当たらない場合は、上位のスタディまたはプログラムのページを確認してください。
:::

:::tip
ボランティア向けに、教材のダウンロードと印刷を含む週次チェックリストを作成しておくと便利です。これにより、日曜日の朝に準備を忘れることを防げます。
:::
