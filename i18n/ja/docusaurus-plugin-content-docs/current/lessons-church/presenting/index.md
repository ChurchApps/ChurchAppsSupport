# プレゼンテーション

<div class="article-intro">

Lessons.church は、ボランティアが自信を持って各レッスンを教えられるようにするためのツールを提供します。スクリーンにコンテンツを投影する場合も、印刷したガイドを配る場合も、アクティビティシートを配布する場合も、必要なものはすべてプラットフォームに組み込まれています。

</div>

## プレゼンターモード

教える時間になったら、どのレッスンからでも **プレゼンターモード** を直接起動できます。これは教室のスクリーンやプロジェクター向けに設計された、全画面表示のビューです。FreeShow プレゼンテーションソフトや、自動表示のための [FreePlay](https://freeplay.church) とも連携します。

## ボランティア向けガイド

各レッスンには役割ごとのガイドが含まれており、ボランティアは何を言い、何をすればよいかを正確に把握できます。受付担当者には受付の指示が、小グループのリーダーにはリーダー向けの指示が表示されるなど、役割に応じた内容になっています。ガイドはクラス中にスマートフォンやタブレットで確認することも、事前に印刷しておくこともできます。

## ダウンロード可能な資料

レッスンには、アクティビティシート、塗り絵、リーダー向けガイド、補足の PDF などのダウンロード可能な資料が付属しています。これらの資料はプログラム、学習コース、レッスンの各レベルで利用できるため、必要なものをひとつの場所からまとめて入手できます。

## すべてをまとめる

日曜日の朝の典型的な流れは、次のようになります。

1. 週の初めに、アクティビティシートや塗り絵をダウンロードして印刷しておきます。
2. ボランティア向けガイドのリンクをチームに共有し、各自の役割を確認してもらいます。
3. 教室のコンピューターやテレビで、レッスンを **プレゼンターモード** で開きます。
4. ボランティアが各自のガイドを見ながらついてこられるよう、レッスンの各セクションを順に進めます。

:::tip
授業の数日前に資料を準備し、ガイドのリンクを共有しておくと、ボランティアが見直す時間を持て、日曜日の朝に自信を持って臨めます。
:::
