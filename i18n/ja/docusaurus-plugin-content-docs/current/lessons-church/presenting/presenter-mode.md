# プレゼンターモード

<div class="article-intro">

プレゼンターモードは、レッスンを全画面で投影に適した表示に切り替えます。教室のスクリーン、プロジェクター、テレビに表示することを想定しており、授業中にクラス全員がレッスンの内容を追えるようにします。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [レッスンをスケジュールする](../classrooms/scheduling-lessons.md)を教室に設定するか、[コンテンツライブラリ](../browsing/index.md)からレッスンを開きます
- ディスプレイ（プロジェクター、テレビ、またはモニター）が接続され、設定されていることを確認します

</div>

## プレゼンターモードに入る

1. 表示したいレッスンを開きます。
2. レッスンページで **Present** ボタンをクリックします。
3. レッスンが黒い背景と大きく読みやすい文字の全画面表示に切り替わります。

プレゼンターモードに入ったら、画面上のナビゲーションコントロールを使って、セクションごとにレッスンを進めることができます。

## 表示の見た目

プレゼンターモードは、投影スクリーン上で内容が際立つように、すっきりとした暗い背景を使います。レッスンの各セクションは一度に1つずつ表示され、現在の活動に集中できるようになっています。テキスト、画像、動画の埋め込みは、教室のどこからでも読みやすいように整えられます。

## FreeShow での利用

Lessons.church は、無料のプレゼンテーションアプリである [FreeShow](https://freeshow.app) と連携しています。FreeShow は Lessons.church からレッスンの内容を直接取り込めるため、既存のプレゼンテーションの流れにレッスンのスライドを組み込むことができます。すでに礼拝の歌詞やお知らせに FreeShow を使っている場合に特に便利です。

## FreePlay での利用

**[FreePlay](https://freeplay.church)** を使うと、別のコンピューターを用意しなくてもテレビにレッスンを表示できます。Android TV、Fire TV、または Apple TV の機器にアプリをインストールし、Lessons.church の教室に接続すると、スケジュールされたレッスンが自動的に表示されます。専用のスクリーンがある教室に最適な、手を使わずに操作できる方法です。設定方法は [FreePlay のドキュメント](/docs/freeplay/)をご覧ください。

:::tip
プロジェクターを使う場合は、プレゼンターモードに入る前に、ディスプレイがプロジェクターにミラーリングまたは拡張されるように設定してください。これにより、全画面表示が正しい画面に表示されます。
:::

## プレゼンターモードを終了する

プレゼンターモードを終了するには、**Escape** キーを押すか、画面の隅にある終了ボタンをクリックします。通常のレッスン表示に戻ります。
