# アカウントの作成

<div class="article-intro">

Lessons.church は、B1.church と同じ ChurchApps アカウントシステムを使用しています。すでに ChurchApps アカウントをお持ちの場合は、そのままログインできます。お持ちでない場合も、登録には数分しかかからず、カリキュラムライブラリ全体をご利用いただけます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- アカウント確認に使用できる有効なメールアドレスをご用意ください
- 教会がすでに Lessons.church を使用している場合は、新しい教会プロフィールを作成する前に管理者に詳細を確認してください

</div>

## 新規アカウントの登録

1. Web ブラウザで [Lessons.church](https://lessons.church) にアクセスします。
2. 上部のナビゲーションバーにある **Login** をクリックします。
3. ログインページで **Register** をクリックし、新しいアカウントを作成します。
4. **名（ファーストネーム）**、**姓（ラストネーム）**、**メールアドレス**を入力します。
5. アカウントの **パスワード** を作成します。
6. 登録フォームを送信します。

登録後、既存の教会に接続するか、新しい教会プロフィールを作成するかを選択する画面が表示されます。

## 教会への接続

**新しい教会を作成する場合:**

1. **新しい教会を作成** のオプションを選択します。
2. **教会名**と基本情報を入力します。
3. 設定を完了します。Lessons.church における教会の管理者になります。

**既存の教会に参加する場合:**

1. 教会の名前で検索します。
2. 検索結果から教会を選択します。
3. 教会の管理者に、適切な権限を付与してもらう必要がある場合があります。

:::tip
教会の誰かがすでに Lessons.church を設定している場合は、クラスルームやスケジュールを管理するための適切な権限があるかどうか、その人に確認してください。
:::

## 既存のアカウントでのログイン

B1.church や他の ChurchApps ツールで、すでに ChurchApps アカウントをお持ちの場合:

1. [Lessons.church](https://lessons.church) にアクセスし、**Login** をクリックします。
2. 既存の **メールアドレス** と **パスワード** を入力します。
3. クラスルームやスケジュールを管理できるポータルに移動します。

:::info
ChurchApps アカウントは、すべての ChurchApps 製品で利用できます。1 つのアカウントで、B1 Admin、B1.church、Lessons.church などにアクセスできます。
:::
