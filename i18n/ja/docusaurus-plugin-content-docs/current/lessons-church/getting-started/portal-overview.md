# ポータルの概要

<div class="article-intro">

Lessons.church にログインすると、**ポータル**に移動します。ポータルは、教会の教室とレッスンスケジュールを管理するダッシュボードです。教会のカリキュラムを整理するときは、主にこの画面で作業することになります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [アカウントを作成する](./creating-account.md)と、教会に接続します
- [Lessons.church](https://lessons.church)にログインします

</div>

## 画面の構成

ポータルは、大きく分けて2つのエリアで構成されています。

- **教室**（右側）—— 教会の教室の一覧です。教室名をクリックすると、その教室に予定されているレッスンを表示できます。ここから新しい教室を追加したり、既存の教室を編集したりすることもできます。
- **予定されたレッスン**（左側）—— 教室を選択すると、その教室に予定されているレッスンがこのエリアに表示されます。まだ教室を設定していない場合は、設定方法を説明したビデオが表示されるので、それを見ながら始めることができます。

## ポータルでできること

ポータルでは、次のような操作ができます。

1. **教室を管理する**—— 教室の追加、編集、削除を行います。各教室は、ボランティアチーム（B1アプリで今後のレッスンを確認できます）と、保護者・生徒のグループ（最近のレッスンにアクセスできます）にリンクできます。この教室スケジュールの方式をまだ使用している教会では、保護者は教室のページ（`?upcoming=1` を付けないページ）を開くと、持ち帰り用のコンテンツを確認できます。B1Admin のプランタイプを使用している教会では、代わりに B1 の関連グループのページに持ち帰り用のカードが表示されます。
2. **予定されたレッスンを表示・管理する**—— 各教室の今後のレッスンを確認し、必要に応じて変更します。
3. **教室のフィードを購読する**—— 教室の横にあるフィードアイコンをクリックすると、対応するアプリで使用できるプレイリストのフィードURLを取得できます。
4. **外部プロバイダーにアクセスする**—— **外部プロバイダー**ページを使うと、Open Lesson Format に対応したサードパーティのコンテンツソースを設定できます。これにより、Lessons.church の組み込みライブラリ以外のプロバイダーからもレッスンを取り込めます。
5. **管理エリアにアクセスする**—— 管理権限がある場合は、ナビゲーションに**管理**オプションが表示されます。管理エリアでは、コンテンツのレベルでプログラム、学習、レッスンを管理できます。

## ナビゲーション

ポータルのナビゲーションには、次の項目があります。

- **ホーム**—— 公開されている Lessons.church のホームページに戻り、コンテンツを閲覧できます。
- **スケジュール**—— 教室とレッスンスケジュールを管理するための、ポータルのメイン画面です。
- **外部プロバイダー**—— サードパーティのレッスンプロバイダーを設定します。
- **管理**—— プログラム、学習、レッスンのコンテンツを管理します（管理権限がある場合のみ表示されます）。

:::info
**管理**オプションは、アカウントにコンテンツ編集の権限が付与されている場合にのみ表示されます。ほとんどの教会スタッフは、日常的な管理には**スケジュール**ページと**外部プロバイダー**ページを使用します。
:::

## はじめに

ポータルを初めて開き、まだ教室を作成していない場合は、教室パネルの **最初の教室を追加** をクリックしてください。教室に名前を付けて（例：「未就学児」や「3～5年生」）保存します。その後、[レッスンの予定を立てる](../classrooms/scheduling-lessons.md)ことができます。
