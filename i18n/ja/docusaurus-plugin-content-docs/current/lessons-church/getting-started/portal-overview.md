# ポータルの概要

<div class="article-intro">

Lessons.church にログインすると、**ポータル**が表示されます。ここは教会のクラスルームとレッスンスケジュールを管理するダッシュボードです。教会のカリキュラムを整理する際は、主にこのページで作業することになります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [アカウントの作成](./creating-account.md)を行い、教会に接続してください
- [Lessons.church](https://lessons.church) にログインしてください

</div>

## 画面の構成

ポータルは**クラスルーム管理**ページで開きます。このページは次の2つの主要なエリアで構成されています。

- **クラスルーム**(右側)―― 教会のクラスルームの一覧です。クラスルーム名をクリックすると、そのクラスルームの予定レッスンを表示できます。このエリアから新しいクラスルームを追加したり、既存のクラスルームを編集したりすることもできます。
- **レッスンスケジュール**(左側)―― クラスルームを選択すると、そのクラスルームに予定されているレッスンがこのエリアに表示されます。まだクラスルームを設定していない場合は、設定方法を説明したビデオが表示されます。

## ポータルでできること

ポータルでは、次の操作を行えます。

1. **クラスルームの管理**―― クラスルームの追加、編集、削除を行います。各クラスルームは、ボランティアチーム(B1 app で今後のレッスンを確認できます)と、保護者・生徒のグループ(最近のレッスンにアクセスできます)にリンクできます。このクラスルーム方式を使用している教会では、保護者は(`?upcoming=1` を付けずに)クラスルームのページを開くと、持ち帰り用のコンテンツを確認できます。B1Admin のプラン種別を使用している教会では、代わりに B1 の関連グループのページに持ち帰り用カードが表示されます。
2. **予定レッスンの表示と管理**―― 各クラスルームの今後のレッスンを確認し、必要に応じて変更します。
3. **クラスルームフィードの購読**―― クラスルームの横にあるフィードアイコンをクリックすると、対応するアプリで使用できるプレイリストのフィード URL を取得できます。
4. **外部プロバイダーへのアクセス**―― **外部プロバイダー**ページでは、Open Lesson Format に対応したサードパーティのコンテンツソースを設定できます。これにより、Lessons.church の標準ライブラリ以外のプロバイダーからもレッスンを取り込めます。
5. **管理エリアへのアクセス**―― 管理者権限をお持ちの場合は、ナビゲーションに**管理**のオプションが表示されます。管理エリアでは、コンテンツレベルでプログラム、スタディ、レッスンを管理できます。

## ナビゲーション

ポータルのナビゲーションには、次の項目があります。

- **ホーム**―― 公開されている Lessons.church のホームページに戻り、コンテンツを閲覧できます。
- **スケジュール**―― クラスルームとレッスンスケジュールを管理するための、ポータルの主要な画面です。
- **外部プロバイダー**―― サードパーティのレッスンプロバイダーを設定します。
- **管理**―― プログラム、スタディ、レッスンのコンテンツを管理します(管理権限をお持ちの場合にのみ表示されます)。

:::info
**管理**のオプションは、コンテンツ編集権限が付与されているアカウントにのみ表示されます。ほとんどの教会スタッフは、日常の管理には**スケジュール**と**外部プロバイダー**のページを使用します。
:::

## はじめに

ポータルに初めてアクセスし、まだクラスルームを作成していない場合は、クラスルームパネルの**最初のクラスルームを追加**をクリックしてください。クラスルームに名前(例: 「未就学児」や「3～5年生」)を付けて保存します。その後、[レッスンのスケジュール設定](../classrooms/scheduling-lessons.md)に進めます。
