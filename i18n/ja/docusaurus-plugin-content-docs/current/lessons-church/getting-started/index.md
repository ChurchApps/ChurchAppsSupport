# はじめに

<div class="article-intro">

Lessons.church は完全無料でご利用いただけます。定期購読も、試用期間も、機能制限もありません。このセクションでは、アカウントの作成、教会の接続、ポータルの操作方法を順に説明します。読み終えたら、すぐにレッスンのスケジュール設定を始められます。

</div>

## 必要なもの

Lessons.church を始めるには、次の手順が必要です。

1. **アカウントを作成する** -- [Lessons.church](https://lessons.church) で、お名前、メールアドレス、パスワードを入力して登録します。B1.church で既にお持ちの ChurchApps アカウントをそのまま使用できます。
2. **教会を接続する** -- 登録後、既存の教会プロフィールに接続するか、新しい教会プロフィールを作成します。これにより、クラスルームとスケジュールが教会に紐付けられます。
3. **クラスルームを設定する** -- 奉仕に合わせてクラスルームを作成します（例：「未就学児」「小学1～3年生」「ユース」）。クラスルームは、レッスンのスケジュールを設定し、整理する場所です。
4. **レッスンのスケジュールを設定する** -- コンテンツライブラリを閲覧し、ニーズに合った教材を見つけて、クラスルームにレッスンを設定します。

クラスルームの設定とレッスンのスケジュール設定が完了すると、ボランティアの方はポータルからコンテンツにアクセスし、クラスでレッスンを提示できます。

:::tip
すでに B1.church の ChurchApps アカウントをお持ちの場合は、同じ認証情報で Lessons.church にログインできます。改めて登録する必要はありません。
:::
