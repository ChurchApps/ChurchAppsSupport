# プランモード

<div class="article-intro">

プランモードは、TVを教会の礼拝プランに接続します。授業スケジュールに基づいてコンテンツを取得するのではなく、B1 Adminで教会のリーダーシップが設定したプランに従います。今週のプランで指定された内容をそのままTVに表示したい場合に最適です。

</div>

## 他のモードとの違い

- **[スケジュールモード](../scheduled-mode/)** は、FreePlay Adminのカレンダーで設定した時刻に、再生リストを自動で再生します。Startを押す必要はありません
- **プランモード** は、プランの種類に紐づいたコンテンツを取得します。レッスン、プロバイダーのプレゼンテーション、アドオン、その他のメディアを、任意の順序で配置できます

プランモードは、異なるソースのコンテンツを組み合わせて、1つの流れにまとめた礼拝プランを使う場合に特に便利です。

:::tip
現在のプランを、設定した時刻に自動で再生したいですか？ FreePlay Adminでカレンダーの予定を追加し、**Service plans** の下からプランの種類を選択してください。詳しくは [カレンダーのスケジュール設定](../scheduled-mode/scheduling-the-calendar) をご覧ください。
:::

## 仕組み

1. TVで **Settings** > **Pair to a calendar** を開き、ペアリングコードを表示します
2. 管理者が **B1 Admin** でそのコードを入力し、**Show Plans For** からプランの種類を選択します
3. ペアリングが完了すると、FreePlayは現在のプランを読み込み、関連するすべてのメディアをダウンロードします
4. **Start Plan** を押して再生を開始します

TVは、プランの種類とペアリングされたままになります。毎週、最新のプランとそのコンテンツを自動的に取得します。
