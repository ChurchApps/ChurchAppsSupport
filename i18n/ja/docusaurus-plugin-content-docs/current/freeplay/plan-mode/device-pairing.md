# デバイスのペアリング

<div class="article-intro">

プランモードを使うには、テレビを B1 Admin のプランの種類とペアリングします。FreePlay はテレビに短いペアリングコードを表示します。そのコードを B1 Admin に入力し、従うプランの種類を選ぶと、テレビには毎週そのプランのコンテンツが自動的に届きます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- FreePlay をインストールして起動します。[はじめに](../getting-started/index.md)を参照してください
- ペアリングを完了するために、コンピューターまたはスマートフォンで **B1 Admin** を使える状態にしておきます

</div>

## ペアリングコードを生成する

1. テレビで、サイドバーの下部にある **設定** を開きます。
2. **カレンダーとペアリング** を選択します。
3. FreePlay に、QR コードの横に大きな文字で 4 文字のペアリングコードが表示されます。
4. コードの下には、点滅する **確認を待っています** のインジケーターが表示されます。これは、ペアリングの完了操作を待っていることを示しています。

同じコードは、FreePlay Admin の [スケジュールモード](../scheduled-mode/index.md) と、B1 Admin のプランモードの両方で使えます。画面に表示される QR コードと **freeplay.church/pair** のアドレスは、FreePlay Admin を開きます。プランモードでは、それらは無視して、以下の手順どおりに B1 Admin でコードを入力してください。

## B1 Admin でコードを入力する

1. B1 Admin で **プロフィール** > **デバイス** に移動し、**画面を追加** をクリックします。
2. テレビに表示された 4 文字を **ペアリングコード** に入力します。
3. **表示するプラン** で、この画面に従わせたいプランの種類を選びます。たとえば「Sunday Service」などです。
4. **保存** します。

FreePlay は数秒ごとに、ペアリングが完了したかどうかを確認します。B1 Admin で確認が取れると、テレビには **接続しました！** と表示され、プランのダウンロード画面に進みます。

## プランのコンテンツをダウンロードする

ペアリング後、FreePlay はそのプランの種類の現在のプランを読み込みます。次の内容が表示されます。

- プラン名と礼拝の日付
- プランにレッスンのコンテンツが含まれている場合は、そのレッスン名
- **項目 X / Y をダウンロード中** と表示される進行状況インジケーター

すべてのメディアファイルのダウンロードが完了すると、**プランを開始** ボタンが表示されます。リモコンの **決定** を押すと、再生が始まります。

:::tip
プランは 1 時間ごとに自動で更新されます。日中にだれかがプランを更新しても、FreePlay は自動的に変更を取り込みます。
:::

## ペアリングに失敗した場合

FreePlay がペアリングコードを生成できない場合（たとえばネットワークの問題があるときなど）、**再試行** ボタンが付いたエラーメッセージが表示されます。テレビがインターネットに接続されていることを確認してから、もう一度お試しください。

:::warning
ペアリングコードの有効期限は 15 分です。古いコードの期限が切れると、FreePlay は自動的に新しいコードを表示します。また、いつでも **新しいコードを生成** を選択できます。入力したコードが機能しない場合は、テレビに今表示されているコードを使ってください。
:::
