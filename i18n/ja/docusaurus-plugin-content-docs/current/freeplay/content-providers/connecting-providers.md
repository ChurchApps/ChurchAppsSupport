# プロバイダーへの接続

<div class="article-intro">

プロバイダーのコンテンツを閲覧するには、まずそのプロバイダーに接続する必要があります。認証が必要なプロバイダーもあれば、ワンクリックで接続できるプロバイダーもあります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- FreePlayをインストールして起動する -- [はじめに](../getting-started/)を参照
- テレビのリモコンを用意しておく
- ログインが必要なプロバイダーの場合は、アカウントの認証情報を用意しておく

</div>

:::tip B1 AdminとFreePlayを一緒に設定しますか?
**<a href="/guides/freeplay-b1admin" target="_blank">ステップごとのガイド</a>**では、B1 Adminのリンク、レッスンのスケジュール設定、FreePlayの接続を一つにまとめて説明しています。新しいタブで開いて、手順に沿って進めてください。
:::

## 利用可能なプロバイダーの確認

1. サイドバー下部の**設定**を開き、**プロバイダー**を選択して**コンテンツプロバイダー**画面を開きます
2. プロバイダーのロゴと名前が表示されたカードがグリッド状に並んでいます
3. 接続済みのプロバイダーは、名前の下に緑色の**接続済み**バッジが表示されます
4. まだ利用できないプロバイダーには**近日公開**と表示されます

## 認証なしでの接続

ログインを必要としないプロバイダーもあります。このようなプロバイダーを選択すると、FreePlayは直ちに接続し、コンテンツブラウザーを開きます。認証情報は必要ありません。

## デバイスフロー認証(QRコード)

一部のプロバイダーは、動画ストリーミングアプリにテレビでサインインする場合と同様のデバイスフローを使用します:

1. **コンテンツプロバイダー**画面でプロバイダーのカードを選択します
2. FreePlayに、プロバイダー名、QRコード、確認用URLが表示された**接続先**画面が表示されます
3. スマートフォンでQRコードを読み取るか、任意のデバイスで表示されたURLにアクセスします
4. テレビ画面に表示されたコードを入力します
5. スマートフォンまたはコンピューターでサインインの手続きを完了します
6. FreePlayがログインの成功を検出し、**接続しました!**と表示します
7. コンテンツブラウザーが自動的に開きます

:::info
点滅する**確認を待っています**インジケーターは、FreePlayがログインを確認中であることを示します。画面には、コードの有効期限までの残り時間が分単位で表示されるので、手早く手続きを完了してください。期限が切れた場合は**新しいコードを生成**を選択します。
:::

## スマートフォンでのサインイン(QRコードのみ)

**Dropbox**、**OneDrive**、**Go Curriculum**は、入力するコードがない、やや異なるQRコードサインインを使用します:

1. **コンテンツプロバイダー**画面でプロバイダーのカードを選択します
2. FreePlayに、プロバイダー名とQRコードが表示された**接続先**画面が表示されます
3. スマートフォンでQRコードを読み取り、そのプロバイダーのアカウントでサインインします(OneDriveの場合はMicrosoftアカウント、Go Curriculumの場合はgocurriculum.comのアカウント)
4. アクセスを承認します。テレビは自動的に接続し、**接続しました!**と表示します

画面には、サインインを完了するまでの残り時間が表示されます。

## フォームによるログイン

それ以外のプロバイダーは、従来のメールアドレスとパスワードによるログインを使用します:

1. プロバイダーのカードを選択します
2. 画面上のキーボードを使って**メールアドレス**と**パスワード**を入力します
3. **サインイン**ボタンを選択します
4. 認証情報が正しければ、FreePlayは**接続しました!**と表示し、コンテンツブラウザーを開きます

:::tip
リモコンの方向パッドを使って、メールアドレスの欄、パスワードの欄、サインインボタンの間を移動します。テキスト欄で**決定**を押すと、画面上のキーボードが開きます。
:::

## プロバイダーの設定

**接続済み**バッジが表示されているプロバイダーのカードを選択すると、**プロバイダーの設定**画面が開きます:

- **ライブラリを表示** -- このプロバイダーのコンテンツライブラリをサイドバーに表示するか非表示にするかを設定します
- **今日のレッスンを自動ダウンロード** -- このプロバイダーを今日のレッスンの提供元として使用し、そのファイルを事前にダウンロードします(現在のレッスンを提供しているプロバイダーのみ表示されます)
- **お知らせに使用** -- このプロバイダーのフォルダーを選択すると、サイドバーの**お知らせ**項目でループ再生されます。[お知らせ](./announcements)を参照
- **お知らせの更新を確認** -- お知らせ用のフォルダーを選択すると表示されます。新しいスライドをダウンロードし、削除されたスライドを取り除きます
- **切断** -- 接続を解除します

## プロバイダーの切断

すでに接続済みのプロバイダーから切断するには:

1. **コンテンツプロバイダー**画面(**設定** > **プロバイダー**)に移動します
2. **接続済み**バッジが表示されているプロバイダーのカードを選択します
3. **プロバイダーの設定**画面で**切断**を選択します

切断すると、そのプロバイダーのコンテンツはサイドバーに表示されなくなります。お知らせ用にそのプロバイダーのフォルダーを使用していた場合は、それらのスライドも削除されます。

:::warning
切断すると、保存された認証情報がデバイスから削除されます。後で再接続する場合は、再度サインインする必要があります。
:::
