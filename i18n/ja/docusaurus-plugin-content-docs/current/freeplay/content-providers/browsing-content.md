# コンテンツの閲覧とダウンロード

<div class="article-intro">

コンテンツプロバイダーに接続したら、そのライブラリを閲覧し、ファイルをダウンロードして、テレビで再生できます。コンテンツブラウザーには、フォルダーとファイルが視覚的なグリッドで表示され、テレビのリモコンで移動できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 少なくとも1つのコンテンツプロバイダーに接続してください -- [プロバイダーへの接続](./connecting-providers.md)を参照
- テレビのリモコンを用意してください

</div>

## コンテンツブラウザー

コンテンツブラウザーには、項目が3列のカードグリッドで表示されます。各カードにはサムネイル画像とタイトルが表示されます。項目には2種類あります:

- **フォルダー** - サムネイルまたはフォルダーアイコンで表示されます。フォルダーを選択すると、その中身が表示されます。
- **ファイル** - 個々のメディア項目（動画または画像）です。動画ファイルは、サムネイルの上に再生アイコンが重なって表示されます。

画面上部のヘッダーには、現在のフォルダー名が表示されます。ルートレベルにいる場合は、プロバイダー名が表示されます。

## フォルダーの移動

1. リモコンの方向キーを使って、フォルダーにフォーカスを合わせます
2. リモコンの**決定**を押して開きます
3. ブラウザーがフォルダーの中身を読み込みます。中身はフォルダーの場合も、再生可能なファイルの場合もあります
4. リモコンの**戻る**を押すと、1つ上の階層に戻ります

フォルダーの階層は、プロバイダーのコンテンツ構造が許す限り深く進めます。ブラウザーはフォルダーのパスを記録しているので、各階層を順に戻ることができます。

## Lessons.churchの閲覧

[Lessons.church](../../lessons-church/index.md)のライブラリは、そのウェブサイトと同じ構造で整理されています。最上位には2つのフォルダーがあります:

- **Lessons** - **プログラム**、**学習**、**レッスン**の順に進みます。各レッスンには**会場**（Preschool、Elementaryなど、特定の年齢層や環境向けのレッスンのバージョン）が一覧表示されます。会場を選択すると、そのバージョンのダウンロード画面が開きます
- **Add-Ons** - カテゴリごとに整理された追加の動画やリソース

どの階層でも**戻る**を押すと、1つ上の階層に戻ります。

## Go Curriculumの閲覧

[gocurriculum.comアカウントでサインインする](./connecting-providers.md#phone-sign-in-qr-code-only)と、Go Curriculumが年齢層（**Elementary**と**Preschool**）を表示します。年齢層、コレクション、レッスンの順に進み、レッスンを選択するとそのダウンロード画面が開きます。

表示される内容は、Goのメンバーシップによって異なります:

- 表示されるのは、メンバーシップの対象となる年齢層だけです。ログインアカウントにGoのメンバーシップがない場合、ライブラリは空になります
- 一部の動画は、特定のメンバーシップレベルでのみ利用できます。メンバーシップに含まれない動画は、レッスンから除外されます

## コンテンツのダウンロードと再生

再生可能なファイルを含むフォルダー（または個別のファイル）を選択すると、FreePlayにコンテンツのタイトルとカバー画像、そして2つの選択肢が表示されます:

- **ダウンロード** - すべてのファイルをテレビに先に保存します。再生時にWi-Fiに依存しなくなります。各ファイルが保存されるたびに進行バーが進みます。完了すると、再生アイコン付きの**開始**ボタンが表示されます。**決定**を押すと再生が始まります
- **ストリーミング** - ファイルを保存せず、インターネット経由ですぐに再生を開始します

:::tip
建物のインターネット接続が安定している日曜の朝より前に、レッスンをダウンロードしておきましょう。ダウンロードしたコンテンツはオフラインで再生でき、後で再度再生する際も、再ダウンロードせずにすぐに読み込まれます。
:::

## ダウンロードの管理

サイドバーの下部にある**設定**を開き、**ダウンロード**を選択すると、このテレビに保存されているすべてのコンテンツが表示されます:

- ダウンロードを選択すると再生されます
- ダウンロードにフォーカスを合わせ、その角にある削除アイコンを選択すると、削除されて保存容量が解放されます

画面に**まだダウンロードはありません**と表示される場合、このテレビには何も保存されていません。

## プロバイダーのコンテンツの再生

再生中は、次のコントロールを使用します:

- **右矢印** - 次の項目
- **左矢印** - 前の項目
- **決定 / 再生・一時停止** - 動画の一時停止または再開
- **上矢印** - メッセージセレクターを開き、特定の項目にジャンプ
- **戻る** - コンテンツブラウザーに戻る

プレーヤーを終了すると、現在のプロバイダーのルートレベルにあるコンテンツブラウザーに戻ります。

:::info
すべてのプレーヤーコントロールの詳細については、[コンテンツの再生](./playing-content.md)を参照してください。
:::

## プロバイダーの切り替え

接続済みのプロバイダーは、左側のサイドバーの**ブラウズ**見出しの下に項目として表示されます。別のプロバイダーに切り替えるには、次の手順に従います:

1. リモコンの**左**矢印を押して、サイドバーを展開します
2. 閲覧したいプロバイダーを選択します
3. コンテンツブラウザーが更新され、そのプロバイダーのライブラリが表示されます

:::warning
フォルダーに「コンテンツがありません」と表示される場合、そのレベルにはプロバイダーの項目がありません。別のフォルダーに移動するか、後でもう一度確認してください。
:::
