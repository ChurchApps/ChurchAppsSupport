# コンテンツの閲覧とダウンロード

<div class="article-intro">

コンテンツプロバイダーに接続すると、そのライブラリを閲覧し、ファイルをダウンロードして、テレビで再生できます。コンテンツブラウザーには、フォルダーとファイルが視覚的なグリッドで表示され、テレビのリモコンで移動できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 少なくとも1つのコンテンツプロバイダーに接続していること -- [プロバイダーへの接続](./connecting-providers)を参照
- テレビのリモコンを用意していること

</div>

## コンテンツブラウザー

コンテンツブラウザーには、項目が3列のカードグリッドで表示されます。各カードにはサムネイル画像とタイトルが表示されます。項目には次の2種類があります。

- **フォルダー** - サムネイルまたはフォルダーアイコンで表示されます。フォルダーを選択すると、その中身が表示されます。
- **ファイル** - 個別のメディア項目(動画または画像)です。動画ファイルのサムネイルには再生アイコンが重ねて表示されます。

画面上部のヘッダーには、現在のフォルダー名が表示されます。ルートレベルにいる場合は、プロバイダー名が表示されます。

## フォルダーの移動

1. リモコンの方向パッドを使って、フォルダーにカーソルを合わせます
2. **Select**を押して開きます
3. ブラウザーがフォルダーの内容を読み込みます。さらにフォルダーが含まれる場合も、再生可能なファイルが含まれる場合もあります
4. リモコンの**Back**を押すと、1つ上の階層に戻ります

プロバイダーのコンテンツ構造が許す限り、階層を深く進むことができます。ブラウザーはフォルダーの経路を記録しているので、各階層を順に戻ることができます。

## Lessons.churchの閲覧

[Lessons.church](../../lessons-church/)のライブラリは、そのウェブサイトと同じ構成になっています。最上位レベルには2つのフォルダーがあります。

- **Lessons** - **プログラム**、**学習**、**レッスン**の順に進みます。各レッスンには**会場**が一覧表示されます。会場とは、幼児科や小学生科など、特定の年齢層や場面に合わせたレッスンのバージョンのことです。会場を選択すると、そのバージョンのレッスンをダウンロードする画面が開きます
- **Add-Ons** - カテゴリーごとに分類された追加の動画や資料です

どの階層にいても、**Back**を押すと1つ上に戻ります。

## コンテンツのダウンロードと再生

再生可能なファイルを含むフォルダー(または個別のファイル)を選択すると、FreePlayにコンテンツのタイトルとカバー画像、そして2つの選択肢が表示されます。

- **Download** - すべてのファイルを先にテレビに保存します。これにより、再生がWi-Fiに依存しなくなります。各ファイルの保存が進むにつれて進捗バーが満たされていきます。完了すると、再生アイコン付きの**Start**ボタンが表示されます。**Select**を押すと再生が始まります
- **Stream** - ファイルを保存せず、インターネット経由ですぐに再生を開始します

:::tip
教会の建物のインターネット接続が安定しているうちに、日曜日の朝より前にレッスンをダウンロードしておきましょう。一度ダウンロードすると、コンテンツはオフラインで再生でき、後で再度再生する場合もダウンロードし直すことなくすぐに読み込まれます。
:::

## ダウンロードの管理

サイドバーの下部にある**Settings**を開き、**Downloads**を選択すると、このテレビに保存されているすべてのコンテンツが表示されます。

- ダウンロードを選択すると再生されます
- ダウンロードにカーソルを合わせ、その角にある削除アイコンを選択すると、削除して保存容量を空けられます

画面に**No downloads yet**と表示されている場合は、このテレビには何も保存されていません。

## プロバイダーコンテンツの再生

再生中は次の操作を使用します。

- **右矢印** - 次の項目
- **左矢印** - 前の項目
- **Select / Play-Pause** - 動画を一時停止または再開
- **上矢印** - メッセージ選択画面を開き、特定の項目に移動
- **Back** - コンテンツブラウザーに戻る

プレーヤーを終了すると、現在のプロバイダーのルートレベルにあるコンテンツブラウザーに戻ります。

:::info
すべてのプレーヤー操作の詳細は、[コンテンツの再生](./playing-content)を参照してください。
:::

## プロバイダーの切り替え

接続済みのプロバイダーは、左側のサイドバーの**Browse**見出しの下に項目として表示されます。別のプロバイダーに切り替えるには、次の手順に従います。

1. リモコンの**左**矢印を押して、サイドバーを展開します
2. 閲覧したいプロバイダーを選択します
3. コンテンツブラウザーが、そのプロバイダーのライブラリに更新されます

:::warning
フォルダーに「No content available」と表示される場合は、そのレベルにプロバイダーの項目がありません。別のフォルダーに移動するか、後でもう一度確認してください。
:::
