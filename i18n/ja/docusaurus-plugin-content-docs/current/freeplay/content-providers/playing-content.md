# 再生コンテンツ

<div class="article-intro">

FreePlay のプレーヤーは画面全体に表示され、テレビのリモコンで操作できるように作られています。プロバイダーの動画や画像スライド、ダウンロード済みのレッスン、プラン、お知らせフォルダーのコンテンツを再生でき、自動で次に進むことも、自分のペースで進めることもできます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 再生するコンテンツを選びます。[コンテンツの閲覧とダウンロード](./browsing-content.md)、[プランモード](../plan-mode/index.md)、[お知らせ](./announcements.md)を参照してください
- **開始** を押してプレーヤーを開きます

</div>

:::info
カレンダーに連動している画面では、操作内容が少し異なる予約再生プレーヤーを使います。[テレビでの予約再生](../scheduled-mode/scheduled-playback.md)を参照してください。
:::

## プレーヤーの操作

テレビのリモコンで再生を操作します。

| リモコンのボタン | 動作 |
|---|---|
| **決定 / 再生・一時停止** | 一時停止または再開 |
| **右矢印** | 次のスライドまたは動画に進む |
| **左矢印** | 前のスライドまたは動画に戻る |
| **早送り** | 動画を10秒先に送る。スライドの場合は次の項目に進む |
| **巻き戻し** | 動画を10秒戻す。スライドの場合は前の項目に戻る |
| **上矢印** | **メッセージを選択** を開き、特定の項目に移動する |
| **下 / 戻る** | プレーヤーを終了する |

:::tip
タッチ操作に対応したリモコンではスワイプも使えます。左にスワイプで次へ、右にスワイプで前へ、下にスワイプで **メッセージを選択** を開き、上にスワイプでプレーヤーを終了します。
:::

## 動画とスライド

一時停止すると、コンテンツの上に一時停止アイコンが表示されます。もう一度 **決定** または **再生・一時停止** を押すと再開します。

動画は再生が終わると次の項目に進みます。ループに設定された動画は、自分で次に進むまで繰り返し再生されます。

画像スライドは数秒後に自動で次に進みます(プロバイダーが別の時間を設定していない場合は5秒です)。早く次に進みたいときは **右矢印** を押し、スライドを表示したままにしたいときは一時停止します。

## メッセージを選択

再生中に **上** を押すと **メッセージを選択** が開きます。すべての項目がサムネイルとタイトル付きで表示され、再生中の項目には **再生中** と表示されます。任意の項目に移動して **決定** を押すと、すぐにその項目に移ります。何も変更せずに閉じるには **戻る** を押します。

## プレーヤーの終了

リモコンの **下** または **戻る** を押すとプレーヤーを終了します。終了後にどの画面に戻るかは、再生していたコンテンツによって異なります。

- **プロバイダーのコンテンツ** - コンテンツブラウザーに戻ります
- **プラン** - プランのダウンロード画面に戻ります。[プランモード](../plan-mode/index.md)を参照してください
- **ダウンロード済みのコンテンツ** - **ダウンロード** 画面に戻ります

:::info
プレーヤーを開いている間は画面がスリープしないため、レッスンの途中でテレビがスリープすることはありません。
:::
