# コンテンツプロバイダー

<div class="article-intro">

コンテンツプロバイダーとは、TV で再生するレッスン資料、動画、画像を提供する外部サービスのことです。FreePlay は複数のプロバイダーに対応しており、さまざまなソースのコンテンツを 1 つのアプリで閲覧・ダウンロードできます。

</div>

## 利用可能なプロバイダー

FreePlay には現在、次のプロバイダーが含まれています。

- **[Lessons.church](../../lessons-church/index.md)** - 無料かつオープンソースの子ども向けカリキュラム
- **Bible Project** - 聖書を解説する動画とリソース
- **SignPresenter** - 教会向けのプレゼンテーションおよびサイネージ用コンテンツ
- **B1.church** - ご自身の B1 教会環境からのコンテンツ
- **Go Curriculum** - gocurriculum.com のカリキュラム。年齢層（**Elementary** と **Preschool**）、そしてコレクション、レッスンの順に整理されています。表示されるのは、Go のメンバーシップに含まれる年齢層と動画のみです
- **Dropbox** - ご自身の Dropbox 内の画像と動画を閲覧・再生
- **Jesus Film Project** - Jesus Film Project の映画と動画クリップ
- **OneDrive** - ご自身の Microsoft OneDrive 内の画像、動画、音声を閲覧・再生

:::note
Google Drive と FreeShow は、FreePlay TV アプリにはもう表示されません。Google Drive のコンテンツを TV で使うには、[FreePlay Admin](../scheduled-mode/building-playlists.md#connecting-providers) でアカウントを接続し、ファイルをプレイリストに追加して、そのプレイリストをスケジュールしてください。
:::

:::info
一部のプロバイダーは現在も追加中です。プロバイダーのカードに「Coming Soon」と表示されている場合、そのプロバイダーはまだ接続できません。
:::

## プロバイダーの仕組み

各プロバイダーには、フォルダーとファイルで整理された独自のコンテンツライブラリがあります。プロバイダーに接続すると、そのコンテンツがフォルダーブラウザーに表示され、カテゴリーの中へ進んだり、項目を選んだり、再生用にダウンロードしたりできます。

接続済みのプロバイダーは、画面左側のサイドバーに **Browse** の見出しの下に表示されます。サイドバーでプロバイダーを選択すると切り替えられるため、セットアップ中にコンテンツのソース間を簡単に移動できます。

また、接続済みのどのプロバイダーからもフォルダーを 1 つ選び、TV で[アナウンス](./announcements.md)としてループ再生させることができます。

:::tip
TV 上で接続したプロバイダーは、その TV でのみ使用されます。[スケジュールモード](../scheduled-mode/index.md)を使用する場合は、代わりに FreePlay Admin でプロバイダーを一度接続してください。そうすると、スケジュールされたすべての画面からそのプロバイダーのコンテンツを再生できます。
:::
