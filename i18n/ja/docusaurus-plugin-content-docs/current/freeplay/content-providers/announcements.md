# お知らせ

<div class="article-intro">

FreePlay では、お知らせ用のスライドのフォルダーをテレビでループ再生できます。たとえばロビーや授業の開始前などに使えます。接続済みのコンテンツプロバイダーの中からフォルダーを選ぶと、FreePlay がそのスライドを端末にダウンロードし、サイドバーに**お知らせ**の項目が表示されます。この項目からいつでもループ再生を開始できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- お知らせのスライドを保存している[コンテンツプロバイダーに接続](./connecting-providers)します(Dropbox や OneDrive など)
- 再生したい画像や動画を、そのプロバイダー内の 1 つのフォルダーにまとめておきます

</div>

## お知らせ用フォルダーの選択

1. サイドバー下部の**設定**を開き、**プロバイダー**を選択します
2. スライドを保存している接続済みのプロバイダー(**接続済み**バッジが表示されています)を選択して、**プロバイダーの設定**を開きます
3. **お知らせに使用**を選択します
4. **お知らせ用フォルダーを選択**のブラウザーが開きます。スライドのあるフォルダーまで移動し、そのフォルダー(またはその中の任意のファイル)を選択します
5. FreePlay がスライドをダウンロードして**プロバイダーの設定**に戻ります。該当の行には **"*フォルダー名*" をループ再生中 -- *枚数* 枚のスライドをダウンロード済み**と表示されます

お知らせに使用できるフォルダーは一度に 1 つだけです。別のプロバイダーのフォルダーを選択すると、以前のフォルダーは置き換えられます。

## お知らせの再生

スライドのダウンロードが完了すると、サイドバーの上部(テレビに**今日のプラン**が表示されている場合はその下)に**お知らせ**の項目が表示されます。選択するとループ再生が始まります。

- 画像は、プロバイダーがファイルに個別の表示時間を設定していない限り、15 秒間表示されます
- 動画は最後まで再生してから次のスライドに進みます
- 最後のスライドの後は、最初のスライドからループが再開されます
- フォルダーに動画が 1 本だけある場合は、その場で繰り返し再生されます

ループ再生は端末に保存されたファイルから行われるため、インターネット接続がなくても続けて再生できます。その他のコンテンツと同じリモコン操作を使用できます。詳しくは[コンテンツの再生](./playing-content)をご覧ください。

## スライドの更新

FreePlay はアプリの起動のたびにお知らせ用フォルダーを確認し、新しいスライドをダウンロードするとともに、フォルダーから削除されたスライドを端末からも削除します。

すぐに確認したい場合は、プロバイダーの**プロバイダーの設定**を開き、**お知らせの更新を確認**を選択します。確認が完了すると、その行に**最新です**とスライド数が表示されます。

:::info
FreePlay がプロバイダーに接続できない場合、またはフォルダーが空で返ってきた場合は、すでに保存されているスライドの再生を続けます。お知らせの使用を完全にやめるには、後述の手順でオフにしてください。
:::

:::warning
同じファイル名で新しいバージョンに置き換えられたスライドは、再ダウンロードされません。スライドを変更するには、新しいファイルとして追加し、古いファイルを削除してください。
:::

## お知らせをオフにする

プロバイダーの**プロバイダーの設定**を開き、もう一度**お知らせに使用**を選択します。FreePlay はそのフォルダーの使用を停止し、ダウンロード済みのスライドを端末から削除して、サイドバーから**お知らせ**を取り除きます。

プロバイダーの接続を解除すると、そのプロバイダーから設定されたお知らせもオフになります。
