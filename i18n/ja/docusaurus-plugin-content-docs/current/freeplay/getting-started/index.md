## FreePlay のインストール

:::tip 機器を購入する場合
FreePlay は Fire TV（新しい Vega OS 搭載スティックを含む）、onn などの Android TV・Google TV ボックス、Apple TV で動作します。Roku では動作しません。購入すべき機器の詳細は **[機器の選び方](./choosing-a-device.md)** をご覧ください。
:::

### Android TV / Amazon Fire TV

1. テレビのアプリストア（**Google Play ストア**または **Amazon アプリストア**）を開きます
2. **FreePlay** を検索します
3. アプリを選択し、**インストール**を選びます

### Apple TV

1. Apple TV の **App Store** を開きます
2. **FreePlay** を検索します
3. アプリを選択し、**入手**を選びます

## アプリの起動

FreePlay を初めて開くと、FreePlay のロゴが表示されるアニメーション付きのスプラッシュ画面が現れます。アプリは以前に接続したコンテンツプロバイダーがないか確認します。すでにプロバイダーを接続している場合は、そのプロバイダーのコンテンツブラウザーに直接移動します。接続していない場合は、最初のコンテンツソースを接続できる **コンテンツプロバイダー** 画面が開きます。

テレビが [スケジュールモード](../scheduled-mode/) でカレンダーとペアリングされている場合、FreePlay はこれらの手順を省略し、スケジュールされたプレーヤーをすぐに開きます。

## テレビのリモコンでの操作

FreePlay はテレビのリモコンで操作するように設計されています。アプリ全体で使う主な操作は次のとおりです。

- **方向キー（上／下／左／右）** - 画面上の項目を移動します
- **選択 / OK ボタン** - 選択中の項目を決定します
- **左矢印** - どの画面からでもサイドバーを開きます
- **右矢印** - サイドバーを閉じて、メインのコンテンツ領域に戻ります
- **戻る / メニューボタン** - 前の画面に戻ります

:::tip
コンテンツを閲覧中は、サイドバーが狭いアイコンのバーに折りたたまれます。リモコンの左矢印を押すと展開され、すべてのラベルが表示されます。
:::

## サイドバー

サイドバーには、上から下へ次の項目が並びます。

- **今日のプラン** -- テレビがプランとペアリングされている場合に表示されます。[プランモード](../plan-mode/)をご覧ください
- **お知らせ** -- お知らせのフォルダーを選択すると表示されます。[お知らせ](../content-providers/announcements)をご覧ください
- **閲覧** -- 接続されている各コンテンツプロバイダーを閲覧できます。[コンテンツの閲覧とダウンロード](../content-providers/browsing-content)をご覧ください
- **設定** -- サイドバーの最下部にあります。**カレンダーとペアリング**（このテレビをカレンダーまたはプランに接続します。[ペアリングモードの選び方](./pairing-modes)をご覧ください）、**ダウンロード**（この機器に保存されたコンテンツの再生や削除）、**プロバイダー**（コンテンツプロバイダーの接続とお知らせフォルダーの選択）を開けます
