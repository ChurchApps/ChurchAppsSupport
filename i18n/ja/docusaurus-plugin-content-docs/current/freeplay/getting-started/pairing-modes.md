# ペアリングモードの選び方

<div class="article-intro">

FreePlayでは、テレビを3つの方法で動かせます。FreePlay Adminで設定したカレンダーに従う方法、B1 Adminの礼拝プランに従う方法、またはリモコンでボランティアが選んだものを再生する方法です。どちらのペアリング方法も、テレビの同じ画面から始まります。ペアリングコードをどこで入力するかによって、テレビが使うモードが決まります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- FreePlayをインストールし、初めて起動してください。[はじめに](./index.md)を参照してください
- テレビのリモコンを用意してください

</div>

## ペアリングコードの取得

1. テレビで、サイドバー下部の**設定**を開きます。
2. **カレンダーとペアリング**を選択します。
3. FreePlayに4文字のペアリングコードとQRコードが表示されます。コードの有効期限は15分です。期限が切れると、FreePlayが自動的に新しいコードを表示します。

## スケジュールモード（FreePlay Admin）

テレビを自動で動かしたいときは、[admin.freeplay.church](https://admin.freeplay.church)のFreePlay Adminでコードを入力します。再生リストを作成し、一群のスクリーン用のカレンダーに配置すると、テレビは決められた時刻に再生します。誰も開始ボタンを押す必要はありません。

**仕組み:** テレビに表示されたQRコードをスキャンするか、**freeplay.church/pair**にアクセスします。次に、テレビが従うべきスクリーングループのカレンダーを選び、**ペアリング**をクリックします。テレビは翌週分をダウンロードし、オフラインでも時計に従って再生します。

**適している用途:** ロビーや廊下のサイネージ、お知らせのループ再生、人が集まる時間にはすでに授業が流れているべき教室など。

詳しくは**[スケジュールモード](../scheduled-mode/index.md)**をご覧ください。

## プランモード（B1 Admin）

テレビを礼拝プランの種類に従わせたいときは、B1 Adminでコードを入力します。テレビは現在のプランのコンテンツをダウンロードし、ボランティアが**プランを開始**を押すと再生されます。

**仕組み:** B1 Adminで、テレビに表示されたコードを使ってスクリーンを追加し、**表示するプラン**でプランの種類を選びます。毎週、テレビはそのプランの種類で最新のプランを取得します。

**適している用途:** 毎週の礼拝プランに関連するコンテンツをテレビに表示し、再生を開始するタイミングを人が決める場合。

詳しくは**[プランモード](../plan-mode/index.md)**をご覧ください。

:::tip
礼拝プランをスケジュールに沿って再生することもできます。FreePlay Adminでカレンダーの予定を追加し、**礼拝プラン**でプランの種類を選んでください。
:::

## コンテンツプロバイダー（ペアリングなし）

テレビをペアリングする必要がない場合は、コンテンツプロバイダーを直接閲覧できます。[Lessons.church](../../lessons-church/index.md)やBible Projectなどのプロバイダーには、好きなときにダウンロードして再生できるコンテンツがあります。

**適している用途:** ボランティアが毎週再生する内容を選ぶテレビや、利用可能なコンテンツを探したいとき。

:::info
サイドバー下部の**設定**から、いつでも**プロバイダー**画面を開けます。コンテンツを閲覧して再生するためにテレビをペアリングする必要はありません。
:::
