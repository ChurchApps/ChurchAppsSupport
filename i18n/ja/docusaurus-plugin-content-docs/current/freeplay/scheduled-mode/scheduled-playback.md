# テレビでのスケジュール再生

<div class="article-intro">

テレビをカレンダーとペアリングすると、FreePlayが自動で再生を行います。今後1週間分の内容をダウンロードし、予定の時刻になると内容を切り替えます。インターネットが切断されても、端末内に保存したファイルから再生を続けます。教師やボランティアは、テレビのリモコンで一時停止、スキップ、任意の場所への移動を行えます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [テレビをカレンダーとペアリングする](./pairing-a-screen.md)
- [カレンダーにコンテンツを予定する](./scheduling-the-calendar.md)、または画面のグループに既定のループを設定する

</div>

## テレビが自動で行うこと

- **スケジュール画面からの起動** - ペアリング済みのテレビでFreePlayを起動すると、予定された再生画面に直接移動します
- **事前ダウンロード** - FreePlayは今後7日間に予定されたすべてのファイルと既定のループをダウンロードし、そのダウンロード済みファイルから再生します
- **時刻どおりの再生** - 予定された各開始時刻になると、画面がその内容に切り替わります。予定がない場合は、グループの既定のループを再生します
- **変更の確認** - FreePlayは定期的にFreePlay Adminでカレンダーの変更を確認し、新しい内容があればダウンロードします
- **不良ファイルの修復** - ダウンロードしたファイルが再生できない場合、FreePlayはそのファイルをスキップして再度ダウンロードします

最初のファイルが届くまでは、画面に**Loading schedule...**または**Downloading X of Y files**と表示されます。予定がなく、グループに既定のループもない場合は、**Nothing is scheduled right now**と表示されます。

## 情報パネル

リモコンの**Select**を押すと情報パネルが開きます。数秒後に自動で閉じます。パネルには次の情報が表示されます。

- **右上** - すべての内容のダウンロードが完了している日付を示す**Ready through**と日付。ファイルをまだ受信中の場合は**Downloading**と表示されます。その下に、ダウンロード済みのファイル数と進行状況バーが表示されます
- **左下** - 再生中の内容の名前（または**Default loop**）、画面に表示中の項目、次に再生される内容とその時刻
- **Last checked** - FreePlayがスケジュールの変更を最後に確認した時刻

パネルには3つのボタンがあります。

- **Pin This Playlist** - 現在の内容をループで再生し続け、カレンダーを無視します。スケジュールに戻すには**Unpin Playlist**を選択します
- **Browse Content** - 予定された再生画面を離れ、接続済みのプロバイダーを閲覧します
- **Settings** - FreePlayの設定を開きます。ここで[カレンダーとのペアリングを解除する、または別のカレンダーにペアリングする](./pairing-a-screen.md#changing-or-unpairing-from-the-tv)ことができます

:::tip
閲覧後にスケジュールへ戻るには、**Content Providers**画面でリモコンの**Back**を押すか、**Settings**を開いて**Pair to a calendar**を選択し、**Back to schedule**を選びます。ペアリング済みのテレビは、FreePlayがフォアグラウンドに戻るたびに予定された再生画面へ戻ります。起動時も常に予定された再生画面が開きます。
:::

## リモコン操作

| リモコンのボタン | 操作 |
|---|---|
| **Select** | 情報パネルを開く |
| **Play/Pause** | 一時停止または再開。一時停止中は再生アイコンが表示されます |
| **右矢印** | 次のスライドまたは動画へ移動 |
| **左矢印** | 前のスライドまたは動画へ移動 |
| **上矢印** | スライド一覧を開き、任意のスライドへ移動 |
| **Fast Forward** | 動画を10秒早送り |
| **Rewind** | 動画を10秒巻き戻し |
| **Back** | スライド一覧または情報パネルを閉じる。情報パネルを開く |

次と前の操作は、現在再生中の内容の中だけで移動します。最後の項目から最初の項目へ戻るのは、スケジュールがループに設定されている場合のみです。早送りと巻き戻しは動画の再生中にのみ機能します。スライドの表示中は何もしません。

### スライドへの移動

上矢印を押すとスライド一覧が開きます。現在のプレイリストまたはレッスンのすべての項目が表示されます。目的の項目に移動して**Select**を押すと、そのスライドへ直接移動します。

## 教師のペースで進むレッスン

スケジュールが**Teacher paced**に設定されている場合、画像スライドは自動では進みません。教師が**右矢印**を押して次に進みます。動画は最後まで再生され、そのあと次の項目に移ります。

教師のペースで進むレッスンは、教師が最後のスライドに到達して終了するまで、予定終了時刻を過ぎても画面に表示され続けます。その後、次に予定された内容へ切り替わります。これにより、予定より長引いた授業がレッスンの途中で打ち切られることを防ぎます。

## ブラウザからの再生

画面のカレンダーをWebブラウザで再生することもできます。FreePlay Adminの**Screens**ページで画面を開き、**Present in browser**をクリックします。ブラウザはテレビと同じようにその画面のカレンダーに従い、コントロールバーに次に再生される内容が表示されます。**Space**キーで一時停止、**←** / **→**でスキップ、**F**で全画面表示、**Esc**で終了します。
