# プロバイダーの接続とプレイリストの作成

<div class="article-intro">

プレイリストとは、カレンダーに設定する画像と動画のループのことです。FreePlay Admin では、コンテンツプロバイダーを教会全体で一度だけ接続します。その後、それらのプロバイダーからファイルを選んでプレイリストを作成します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [admin.freeplay.church](https://admin.freeplay.church) で FreePlay Admin にサインインします
- DropboxやOneDriveなど、接続したいプロバイダーアカウントのログイン情報を用意しておきます

</div>

## プロバイダーの接続

**プロバイダー**ページには、コンテンツのソースが次の2つのセクションに分けて表示されます：

- **接続済み** - 今すぐ使用できるプロバイダーです。Lessons.church や Bible Project などのサインイン不要の公開プロバイダーは、常にここに **Public · no sign-in needed** として表示されます。リンク済みのアカウントには **アカウントリンク済み** と、リンクの有効期限が表示されます。
- **利用可能** - 使用する前にサインインが必要なプロバイダーです。

プロバイダーを接続するには：

1. **プロバイダー**に移動します。
2. **利用可能**の中からプロバイダーを探し、**接続**をクリックします。
3. そのプロバイダーのアカウントにサインインします：
   - Dropbox、Google ドライブ、OneDrive などの一部のプロバイダーでは、サインイン用のポップアップが開きます。何も表示されない場合は、admin.freeplay.church でポップアップを許可してください。
   - その他のプロバイダーでは、リンクとコードが表示されます。リンクにアクセスしてコードを入力し、アクセスを承認してください。完了すると、ダイアログは自動的に更新されます。
4. 「アカウントのリンクに成功しました！」と表示されたら、そのプロバイダーは**接続済み**に移動します。

接続済みのプロバイダーでは、次の3つの操作ができます：

- **参照** - プロバイダーのフォルダーを閲覧します
- **更新** - プロバイダーのサインインを更新します
- **リンク解除** - アカウントの接続を解除します

:::info
FreePlay Admin でのプロバイダー接続は、個人や1台のTVではなく、教会全体に属します。スケジュール設定された画面は、これらの接続を通じてファイルを取得するため、TVごとに各プロバイダーへサインインする必要はありません。
:::

**FreeShow** は **教会のネットワーク上 · 各TVが自動的に検出** として表示されます。FreePlay Admin で接続する必要はありません。

## プレイリストページ

**プレイリスト**ページには、各プレイリストについて、アイテム数、合計再生時間、使用場所（グループの場合は **デフォルトループ**、またはスケジュールの数）、最終更新日時が表示されます。各行には次の操作があります：

- **プレゼン** - ブラウザでプレイリストを全画面再生します
- **編集** - プレイリストエディターを開きます
- **複製** - 「(copy)」という名前のコピーを作成します

## プレイリストの作成

1. **プレイリスト**に移動し、**プレイリストを追加**をクリックします。
2. **名前**を入力します（例：「Welcome loop」）。
3. **プレイリストを追加**をクリックします。プレイリストエディターが開きます。

## アイテムの追加

プレイリストエディターでは、左側にプレイリストの**アイテム**、右側に**プロバイダーから追加**が表示されます。

1. 右側でプロバイダーのタブを選択します。別のソースを追加するには、**別のプロバイダーを接続**をクリックします。**プロバイダー**ページが開きます。
2. フォルダーをクリックして中に入ります。上の階層に戻るには、パンくずリストを使用します。
3. ファイルをクリックすると、プレイリストの末尾に追加されます。プレイリストに既にあるファイルは、選択済みとして表示されます。
4. 現在のフォルダー内のすべてを一度に追加するには、**すべて追加**をクリックします。ボタンには、まだプレイリストに含まれていないファイルの数が表示されます。
5. エディターの上部にある**保存**をクリックします。

:::warning
変更は**保存**をクリックするまで保存されません。保存せずに終了するには**キャンセル**をクリックします。
:::

## アイテムの並べ替え

左側の**アイテム**リストでは：

- **並べ替え** - 左側のハンドルをドラッグしてアイテムを移動します
- **画像の表示時間** - 画像はデフォルトで10秒間表示されます。画像の横にある秒数を変更できます
- **動画** - 動画には **最後まで再生** と表示され、全長にわたって再生されます
- **削除** - アイテムをプレイリストから取り除きます

上部の概要には、アイテム数とプレイリストの合計時間が表示されます。

## 名前の変更、複製、削除

エディターの左側のパネルには、プレイリストの使用場所が表示されます。また、次の操作もできます：

- **プレゼン** - ブラウザでプレイリストを再生します
- **名前の変更** - プレイリストの名前を変更します
- **複製** - 別途編集するためのコピーを作成します
- **削除** - プレイリストを削除します。このプレイリストを再生していたスケジュールは、グループのデフォルトループに戻ります

## ブラウザでのプレイリストのプレゼン

**プレゼン**をクリックすると、ブラウザでプレイリストが全画面で再生されます。プレイリストのプレビューや、プロジェクターに接続されたノートパソコンからの再生に便利です。マウスを動かしてコントロールバーを表示し、次のキーを使用します：

| キー | 操作 |
|---|---|
| **スペース** | 一時停止または再開 |
| **←** / **→** | 前または次のアイテム |
| **F** | 全画面表示の切り替え |
| **Esc** | 終了 |
