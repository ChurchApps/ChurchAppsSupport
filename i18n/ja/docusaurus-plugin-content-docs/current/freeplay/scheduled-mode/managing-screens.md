# スクリーンとグループの管理

<div class="article-intro">

FreePlay Admin の **スクリーン** ページには、教会に登録されているすべてのテレビが一覧表示され、現在再生中の内容と、日曜日の準備ができているかどうかが示されます。このページでは **スクリーングループ** も管理できます。同じグループのスクリーンは、1つのカレンダーと1つの既定のループを共有します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [admin.freeplay.church](https://admin.freeplay.church) で FreePlay Admin にサインインする
- [スクリーンを少なくとも1台ペアリングする](./pairing-a-screen.md)

</div>

## スクリーンページ

画面上部の3つの数字で、状態をすばやく確認できます:

- **現在オンライン** - 過去15分以内にチェックインしたスクリーン
- **日曜日の準備完了** - 今度の日曜日までのすべてのファイルがダウンロード済みの、予定されたスクリーンの数
- **要対応** - オフラインになっているか、ファイルが不足しているスクリーン

その下の **スクリーンを検索** を使うと、ラベル、グループ、再生中の内容でスクリーンを探せます。フィルターチップで一覧を **すべて**、**予定**、**手動**、**要対応**、または特定のグループのいずれかに絞り込めます。右側のトグルで **表** と **グリッド** の表示を切り替えられます。

各スクリーンには次の情報が表示されます:

- **ラベル** と機種名
- **グループ**
- **モード** - **予定** または **手動**
- **再生中** - 今画面に表示されている内容。手動のスクリーンには **教室 · 先生が開始を押す** と表示されます
- **準備完了日** - スクリーンがダウンロード済みの日付。ファイルがダウンロードされていない場合は、代わりに **N 件のファイルが不足** と表示されます。新しいスクリーンには **最初の同期を待機中** と表示されます
- **最終確認** - スクリーンが最後にチェックインした時刻。しばらくチェックインしていないスクリーンには **オフライン** と表示され、一度も接続したことがないスクリーンには **接続なし** と表示されます

**プレゼント** を使うと、スクリーンのカレンダーをブラウザで再生できます。**編集** を使うと設定を変更できます。

## スクリーンの表示

スクリーンのラベルをクリックすると、そのページが開きます。左側には次の項目があります:

- **ブラウザでプレゼント** - このスクリーンのカレンダーを、テレビに表示されるのと同じようにブラウザで全画面再生します。[ブラウザからのプレゼント](./scheduled-playback.md#presenting-from-a-browser)を参照してください
- **編集** - ラベル、グループ、モードを変更します
- **その他** > **ペアリング解除** - テレビとの接続を解除します。テレビはペアリングコードの表示に戻ります

ページの残りには次のセクションがあります:

- **現在と次** - 現在の再生内容と、その終了時刻。その後に、今後7日間に予定されているすべての内容が続きます。このグループのカレンダーに移動するには **カレンダーを開く** をクリックします
- **ダウンロード** - すべてがダウンロード済みの場合は **日付まで準備完了**、不足しているファイルがある場合はそのファイルの一覧
- **デバイス** - デバイスID、プラットフォーム、機種、FreePlay アプリのバージョン、IPアドレス、使用/空きストレージ、最終確認、モード
- **最近** - スクリーンから報告された最新のアクティビティ

:::tip
スクリーンにファイルの不足が表示される場合は、オンラインになっていて、ストレージに空きがあることを確認してください。テレビは次回チェックインしたときに、不足しているファイルを自動的にダウンロードします。
:::

## スクリーンの編集

1. スクリーンの横、またはそのページの **編集** をクリックします。
2. **ラベル**、**グループ**、または **モード**（**予定** または **手動**）を変更します。
3. **保存** をクリックします。

スクリーンを別のグループに移動すると、そのグループのカレンダーに切り替わります。

## スクリーングループ

スクリーングループとは、同じ内容を同じタイミングで再生するスクリーンの集まりです。「ロビー」や「子ども用ウィング」などがその例です。各グループには専用のカレンダーがあり、何も予定されていないときに再生される **既定のループ** を設定できます。

グループを管理するには、**スクリーン** ページ上部の **グループ** をクリックします。**スクリーングループ** の一覧に、各グループの名前、スクリーン数、既定のループが表示されます。**スクリーン** をクリックすると戻ります。

### グループの追加

1. **スクリーングループ** の表示で、**グループを追加** をクリックします。
2. **名前** を入力します。例：「ロビー」
3. **既定のループ** のプレイリストを選ぶか、**なし — スクリーンは消灯します** のままにします。
4. **保存** をクリックします。

スクリーンをペアリングするときに **グループ** 欄で **＋ 新しいグループ…** を選んで、グループを作成することもできます。

### グループの編集と削除

1. グループの横にある **編集** をクリックします。
2. 名前または既定のループを変更し、**保存** をクリックします。
3. グループを削除するには **削除** をクリックし、確認します。

:::warning
グループを削除すると、そのスケジュールも削除されます。そのグループのスクリーンは、別のグループに移動されるまで消灯したままになります。
:::
