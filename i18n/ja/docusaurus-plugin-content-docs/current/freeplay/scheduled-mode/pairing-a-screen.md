# スクリーンをペアリングする

<div class="article-intro">

テレビをカレンダーに接続するには、**FreePlay Admin** でペアリングします。テレビには4文字のコードが表示されます。そのコードを [admin.freeplay.church](https://admin.freeplay.church) に入力し、テレビに表示するカレンダーを持つスクリーングループを選択します。この操作はテレビごとに1回だけ行います。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- テレビに FreePlay をインストールして起動します。[はじめに](../getting-started/index.md) を参照してください
- FreePlay Admin にサインインできるよう、教会の ChurchApps ログインを用意します
- 必要に応じて、テレビがすぐに再生できるよう、先に [プレイリストを作成](./building-playlists.md) して [スケジュールを設定](./scheduling-the-calendar.md) しておきます

</div>

## テレビにコードを表示する

1. テレビで、サイドバー下部の **設定** を開きます。
2. **カレンダーにペアリング** を選択します。テレビがまだペアリングされていない場合、この行には **未ペアリング** と表示されます。
3. **このスクリーンをペアリング** 画面に、QR コードと4文字のペアリングコードが表示されます。「スマートフォンでスキャンするか、freeplay.church/pair にアクセスしてこのコードを入力してください」というメッセージも表示されます。
4. コードの下では、ペアリング操作の完了を FreePlay が待っている間、**確認を待っています** が点滅します。

コードの有効期限は15分です。コードの下にあるカウントダウンに残り時間が表示されます。時間が切れると、FreePlay は自動的に新しいコードを表示します。新しいコードを直ちに取得したい場合は **新しいコードを生成** を、設定に戻る場合は **キャンセル** を選択します。

## FreePlay Admin でペアリングする

1. スマートフォンで QR コードをスキャンするか、任意のパソコンやスマートフォンで **freeplay.church/pair** にアクセスします。求められた場合はサインインします。FreePlay Admin が、コードが入力済みの **スクリーンをペアリング** フォームを開きます。
   - 自分でフォームを開くこともできます。FreePlay Admin で **スクリーン** に移動し、**スクリーンをペアリング** をクリックします。
2. **ペアリングコード** を確認します。テレビに表示されている4文字です。
3. 複数のテレビを区別できるよう **ラベル** を入力します（例：「ロビー左」）。これは任意項目です。
4. **グループ** で、このテレビが従うカレンダーを持つスクリーングループを選択します。新しいグループを作成する場合は **＋ 新しいグループ…** を選択し、**新しいグループ名** を入力します。
5. **モード** は **スケジュール** のままにします。テレビはグループのカレンダーに従って自動的に再生されます。
6. **ペアリング** をクリックします。

テレビに **接続しました！** と表示され、続いて **スケジュールを読み込んでいます...** と表示されます。テレビはスケジュールされたコンテンツをダウンロードして再生を開始します。詳しくは [テレビでのスケジュール再生](./scheduled-playback.md) を参照してください。

:::info
FreePlay Admin に **そのコードに一致するテレビが見つかりません** と表示された場合は、テレビ画面のコードを確認してください。コードの有効期限が切れている場合は、テレビに現在表示されている新しいコードを使用してください。
:::

### スケジュールとマニュアル

**モード** 設定には2つの選択肢があります。

- **スケジュール** - グループのカレンダーに従って自動的に再生します。再生ボタンを押す人は必要ありません。
- **マニュアル** - リモコンでコンテンツを選択します。マニュアルのスクリーンも **スクリーン** 一覧には表示されますが、カレンダーには従わないため、**グループ** フィールドは無効になります。

スクリーンのモードは、後から [スクリーンのページ](./managing-screens.md) の **編集** から変更できます。

## 代わりにサービスプランにペアリングする

**スクリーンをペアリング** 画面のコードは、B1 Admin でも使用できます。B1 Admin でコードを入力し、**プランの表示対象** でプランの種類を選択すると、テレビはカレンダーではなく、その種類のプランに従って [プランモード](../plan-mode/index.md) で動作します。詳しくは [デバイスのペアリング](../plan-mode/device-pairing.md) を参照してください。

## テレビからペアリングを変更または解除する

テレビがペアリングされると、**設定** の **カレンダーにペアリング** の行に、追従しているスクリーングループの名前が表示されます。この行を選択すると **ペアリング先** ダイアログが開き、次の3つの選択肢が表示されます。

- **スケジュールに戻る** - ダイアログを閉じて、スケジュール再生画面に戻ります。ペアリングは変更されません。
- **ペアリングを解除** - スケジュールへの追従を停止します。FreePlay は **コンテンツプロバイダー** 画面を開きます。
- **別のカレンダーにペアリング** - ペアリングを解除したうえで、テレビを再度ペアリングできるように新しいペアリングコードを表示します。

:::warning
ペアリングを解除すると、そのカレンダー用に FreePlay がダウンロードしたファイルが削除されます。
:::

## FreePlay Admin からペアリングを解除する

1. **スクリーン** に移動し、スクリーンのラベルをクリックします。
2. **その他** をクリックし、次に **ペアリングを解除** をクリックします。
3. 確認のため、もう一度 **ペアリングを解除** をクリックします。

テレビはペアリングコードの表示に戻ります。再度使用するときは、もう一度ペアリングしてください。
