# スケジュールモード

<div class="article-intro">

スケジュールモードを使うと、FreePlay TV を自動で動かせます。[admin.freeplay.church](https://admin.freeplay.church) の **FreePlay Admin** でプレイリストを作成し、カレンダーに配置します。そのカレンダーに紐づけられた TV は、翌週分のコンテンツをダウンロードしておき、スケジュールどおりの時刻に、誰も Start を押さなくても再生を始めます。ファイルはあらかじめダウンロードされているため、Wi-Fi が切れても再生は続きます。

</div>

:::tip
FreePlay Admin は、B1 Admin で使っているものと同じ ChurchApps のログインでご利用いただけます。別途アカウントを作成する必要はありません。
:::

## 全体の構成

FreePlay Admin には、サイト上部に並ぶ主要なページが 4 つあります:

- **[画面](./managing-screens.md)** - ペアリング済みの TV、そのステータス、所属する**画面グループ**。グループ内の画面は 1 つのカレンダーと 1 つの既定ループを共有します
- **[プレイリスト](./building-playlists.md)** - コンテンツプロバイダーから選んだ画像と動画のループ
- **[カレンダー](./scheduling-the-calendar.md)** - 各画面グループが再生する内容と、その時刻
- **[プロバイダー](./building-playlists.md#connecting-providers)** - プレイリストの取得元となるコンテンツソース。各プロバイダーは教会全体で一度接続すれば済みます

何もスケジュールされていないとき、グループの画面は**既定ループ**を再生します。グループに既定ループがない場合、画面は消灯したままになります。

## プランモードとの違い

- **[プランモード](../plan-mode/index.md)** は、B1 Admin の礼拝プランの種類を 1 つ追跡します。誰かが TV で **Start Plan** を押すと、そのときにレッスンが再生されます
- **スケジュールモード**はカレンダーに従います。設定した時刻にコンテンツが開始・終了するため、ロビーのサイネージ、お知らせのループ、誰かが入室する前にレッスンを表示しておきたい教室などに適しています

カレンダーの項目で礼拝プランを再生することもできます。スケジュールを追加する際に **Service plans** でプランの種類を選ぶと、その週に B1 Admin で有効になっているプランが画面に再生されます。これには Go Curriculum のレッスンも含まれ、プラン上でカスタマイズしたものも対象になります。画面は、B1 Admin でそのプランの種類の礼拝グループに紐づいた Go Curriculum のログイン情報を使用します。グループに紐づけがない場合は、教会の Go Curriculum 接続を使用します。

## はじめに

以下の各手順を完了するまで、**Screens** ページには各ステップへのリンク付きの **Get started** チェックリストが表示されます:

1. **プロバイダーを接続する** - **Providers** ページで Dropbox、OneDrive、Lessons.church などのソースをリンクします
2. **プレイリストを作成する** - プロバイダーから画像と動画を選びます
3. **カレンダーに配置する** - 再生する内容と時刻を選ぶか、グループの既定ループを設定します
4. **画面をペアリングする** - TV に表示された 4 文字のコードを入力します

**Hide** をクリックすると、チェックリストを閉じられます。

:::tip
**Ctrl+K**（Mac の場合は **⌘K**）を押すか、ヘッダーの検索ボックスをクリックすると、コマンドパレットが開きます。ここから任意のページに移動したり、**Pair screen**、**Add playlist**、**Add schedule** などのアクションを開始したりできます。
:::
