# カレンダーのスケジュール設定

<div class="article-intro">

FreePlay Admin の **カレンダー** ページでは、各スクリーングループが何をいつ再生するかを管理します。プレイリスト、礼拝プラン、またはプロバイダーフォルダーのスケジュールを追加し、毎週繰り返すか一度だけ再生するかを設定できます。スケジュールが何も設定されていない場合は、グループの既定のループが再生されます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- スクリーングループを少なくとも 1 つ作成してください。[スクリーンとグループの管理](./managing-screens.md#screen-groups) を参照してください
- [プレイリストを作成する](./building-playlists.md)、または B1 Admin でプランの種類を設定しておいてください

</div>

## カレンダーの見方

1. **カレンダー** に移動します。
2. 上部のタブからスクリーングループを選択します。各タブには、そのグループのスケジュール数が表示されます。
3. 週表示は月曜日から日曜日までで、午前 6 時から午後 10 時までです。赤い線は現在時刻を示します。
4. 矢印を使って前週または翌週に移動するか、**今日** をクリックして今週に戻ります。

ページのサブタイトルには、カレンダーで使用されるタイムゾーンが表示されます。スケジュールは教会のタイムゾーンに従います。このタイムゾーンは B1 Admin の [教会情報](../../b1-admin/settings/church-settings.md#time-zone) で設定します。教会にタイムゾーンが設定されていない場合は、FreePlay がキャンパスのタイムゾーンを使用します。カレンダーと TV は同じタイムゾーンを使用するため、カレンダーで午前 9 時に配置したブロックは、お使いのコンピューターのタイムゾーンが異なっていても、画面上では午前 9 時に再生されます。

スケジュールはタイプごとに色分けされています。凡例で色の意味を確認できます。

- **既定のループ** - グループに既定のループが設定されている場合、すべての背後に斜線の背景で表示されます
- **プレイリスト**
- **礼拝プラン**
- **プロバイダーフォルダー**

各ブロックには名前が表示されます。高さのあるブロックには、時間、繰り返し設定（**毎週** または **1 回**）、および早く終わった場合の動作も表示されます。

## 既定のループの設定

既定のループは、スケジュールが何も設定されていないときに、グループのスクリーンで再生されます。

1. **カレンダー** ページのヘッダーで **既定のループ…** をクリックします。既定のループがすでに設定されている場合、ボタンには **既定のループ:** に続けてプレイリストの名前が表示されます。
2. **プレイリスト** を選択するか、**なし — 画面を消灯** を選択します。
3. **保存** をクリックします。

## スケジュールの追加

新しいスケジュールを作成するには、次の 3 つの方法があります。

- カレンダーの空いている場所をクリックします。その日と 30 分単位の時間があらかじめ入力された状態でフォームが開きます。
- ヘッダーの **スケジュールを追加** をクリックします。
- コマンドパレット（**Ctrl+K** または **⌘K**）から **スケジュールを追加** を選択します。

次に、フォームに入力します。

1. **再生** - 再生する内容を選択します。
   - **プレイリスト** - 作成済みの任意のプレイリスト
   - **礼拝プラン** - B1 Admin のプランの種類です。**(現在のプラン)** と表示されたものは、そのプランの種類で現在有効なプランを毎週再生します。Go カリキュラムのレッスン（カスタマイズされたものを含む）も対象で、これらはプランの種類に紐付いた奉仕団体の Go ログインを使用します
   - **プロバイダーフォルダー…** - **プロバイダーフォルダーを選択** が開きます。フォルダーを参照して **このフォルダーを使用** をクリックします。後で別のフォルダーを選ぶには **変更** をクリックします
2. **繰り返し** - このスケジュールを再生する曜日を選択します。特定の日付だけにする場合は、**1 回** をオンにして **日付** を選択します。
3. **開始** と **終了** - スケジュールの開始時刻と終了時刻です。
4. **早く終わった場合** - 終了時刻より前にコンテンツがなくなったときの動作です。
   - **終了時刻までループ** - 最初から繰り返します。サイネージのループ、お知らせ、カウントダウンに適しています
   - **講師のペース** - スライドは講師のリモコンを待ちます。最後のスライドまで、レッスンは終了時刻を過ぎても表示され続けます
   - **1 回再生して既定のループに戻る**
5. 繰り返しのスケジュールの場合は、**開始日** に最初の日付を設定します。**終了日** では、**なし** を選択するか、**指定日まで** を選択して **終了日** を入力します。
6. **保存** をクリックします。

:::info
**講師のペース** は、以前の「最後のスライドを保持」オプションに代わるものです。そのオプションで保存されたスケジュールは、講師のペースとして再生されるようになります。
:::

## スケジュールの編集と削除

1. カレンダー上でスケジュールのブロックをクリックします。
2. 任意の項目を変更して **保存** をクリックするか、**削除** をクリックしてスケジュールを削除します。

## スケジュールの重複

2 つのスケジュールが重なっている場合、フォームに警告が表示されます：**他のスケジュールと重複しています。開始時刻が遅い方が優先されます。** 後から始まるスケジュールが実行中は、スクリーンにはそちらが再生されます。そのスケジュールが終了し、先に始まったスケジュールがまだ実行中であれば、スクリーンは先のスケジュールに戻ります。

## スクリーンへの変更の反映

ペアリング済みのスクリーンは、今後 7 日間にスケジュールされているすべての内容をダウンロードし、自動的に変更を確認します。カレンダーを編集した後に TV を操作する必要はありません。スクリーンに必要なものがすべて揃ったかどうかを確認するには、[スクリーンのページ](./managing-screens.md) の **準備完了（〜まで）** を確認してください。
