# FreePlay の概要

<div class="article-intro">

FreePlay は、教会の教室用テレビにレッスンのコンテンツを表示するための教会向けテレビアプリです。Android TV、Amazon Fire TV、Apple TV で動作し、日曜の朝などインターネット接続がない状態でも使えるように設計されています。ボランティアは週の間にレッスン教材を事前にダウンロードしておき、クラスが始まったら再生ボタンを押すだけで済みます。

</div>

:::tip FreePlay が初めての方はこちら
**<a href="/guides/freeplay-quickstart" target="_blank">クイックスタート動画</a>** をご覧ください。数分で FreePlay をインストールし、コンテンツの再生を始められます。専門的な技術知識は必要ありません。
:::

:::tip さらに詳しく設定したい方へ
**<a href="/guides/freeplay-b1admin" target="_blank">完全セットアップガイド</a>** では、B1 Admin と連携して、毎週適切なレッスンが教室のテレビに自動でダウンロードされるように設定する手順を説明します。動画と文章による手順の両方を掲載しています。
:::

## 主な機能

- **オフライン再生** - 動画や画像スライドを事前にダウンロードしておけば、礼拝中に Wi-Fi に頼る必要がありません
- **ダウンロードの管理** - **設定** > **ダウンロード** で、ダウンロード済みのすべてのコンテンツを表示・管理できます
- **スケジュールモード** - [admin.freeplay.church](https://admin.freeplay.church) で再生リストを作成してカレンダーに配置すると、ペアリングされたテレビが、誰も再生ボタンを押さなくても適切な時刻に再生します。詳しくは [スケジュールモード](./scheduled-mode/index.md) をご覧ください
- **プランのペアリング** - 端末を教会の礼拝プランに紐づけ、複数の部屋でコンテンツを連携させられます
- **コンテンツプロバイダー** - [Lessons.church](/docs/lessons-church/)、Bible Project、Dropbox、OneDrive などの外部ソースからコンテンツを閲覧・ダウンロードできます
- **お知らせ** - 接続されたプロバイダーのフォルダにあるスライドをループ再生できます。詳しくは [お知らせ](./content-providers/announcements.md) をご覧ください
- **テレビのリモコンに対応** - 方向ボタンと決定ボタンを備えた一般的なテレビのリモコンで、アプリ全体を操作できます
- **折りたたみ可能なサイドバー** - スリムなサイドバーにより、画面を散らかすことなくナビゲーションにアクセスできます

## 仕組み

FreePlay を起動すると、コンテンツプロバイダーに接続し、利用可能なコンテンツを確認します。その後、フォルダの閲覧、メディアのダウンロード、レッスンの再生を行えます。すべて大画面テレビでの利用に合わせて最適化されています。
