# FreePlay コンテンツプロバイダー

<div class="article-intro">

FreePlay は、スマートフォン、タブレット、テレビでレッスンやその他の動画コンテンツをストリーミング再生するための ChurchApps のメディアプレーヤーです。レッスンコンテンツのライブラリがあり、それを FreePlay で利用できるようにしたい場合は、このガイドで提供に必要な内容をすべて説明します。

</div>

## ブランディング

連携を始める前に、以下の情報が必要です。

- **ロゴ** -- **16:9** のアスペクト比のロゴ画像(FreePlay の UI でプロバイダーカードに使用します)
- **ブランド名** -- FreePlay で組織名として表示する希望の名称

## API エンドポイント

FreePlay は、少数の REST エンドポイントを通じてお客様のサービスと通信します。プロバイダーごとにカスタムアダプターを作成するため、正確な URL 構造は柔軟に決められますが、以下の情報が必要です。

### 認証

コンテンツに合ったモデルを選択してください。

| モデル | 使用する場合 | 必要な情報 |
|-------|-------------|--------------|
| **なし** | 公開コンテンツで、サインインが不要な場合 | なし -- カタログのエンドポイントを直接呼び出します |
| **OAuth (PKCE)** | Web/モバイルでのサインイン | 認可 URL、トークン交換エンドポイント、クライアント ID、スコープ |
| **デバイスフロー** | TV アプリに推奨(ユーザーがスマートフォンで短いコードを入力します) | デバイス認可エンドポイント、トークンポーリングエンドポイント、クライアント ID |

:::tip
コンテンツに認証が必要な場合、認証エンドポイントは **ユーザートークン** を返します。FreePlay はこのトークンを閲覧およびレッスンのエンドポイントに渡し、アクセスを承認します。
:::

### 閲覧 / カタログ

利用可能なすべてのレッスンの **フォルダーツリー** を返すエンドポイント(またはエンドポイントの集合)です。

- 全体のツリーを返す **1 回の呼び出し** でも、ユーザーが階層を下るごとに 1 階層ずつ返す **複数回の呼び出し** でも構いません。
- ツリーの各項目には、以下を含めてください。

| フィールド | 必須 | 説明 |
|-------|----------|-------------|
| `id` | はい | フォルダーの一意の識別子 |
| `name` | はい | フォルダーの表示名 |
| `thumbnail` | 推奨 | **16:9** のサムネイル URL |

### レッスンプレイリスト

1 つのレッスンの **メディアファイルのプレイリスト** を返すエンドポイントです。

プレイリストの各項目には、以下を含めてください。

| フィールド | 必須 | 説明 |
|-------|----------|-------------|
| `title` | はい | メディア項目の表示タイトル |
| `mediaType` | はい | `video` または `image` |
| `url` | はい | ファイルへの直接ダウンロードリンク(下記の[メディア形式](#media-formats)を参照) |
| `thumbnail` | 推奨 | 項目のサムネイル画像 |
| `duration` | 推奨 | 再生時間(秒単位、動画の場合) |

## メディア形式

FreePlay はファイルを直接ダウンロードするため、すべてのメディア項目には **直接リンク**(埋め込みプレイヤーやページのリダイレクトは不可)が必要です。

| 種類 | 対応形式 |
|------|-----------------|
| 動画 | **MP4**(Apple および Android デバイスでのクロスプラットフォーム再生に必要) |
| 画像 | JPG、PNG、GIF |

## 補足

- **JSON を返す REST API** が一般的な連携パターンですが、プロバイダーごとにカスタムアダプターを作成するため、ほぼどのような API 形式にも対応できます。
