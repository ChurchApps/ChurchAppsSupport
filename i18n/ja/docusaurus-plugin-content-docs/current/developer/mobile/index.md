# モバイルアプリ

<div class="article-intro">

ChurchAppsのモバイルアプリは**React Native**と**Expo**で構築されており、Android、iOS、Android TVでネイティブな操作体験を提供します。すべてのモバイルアプリは同じExpoベースのツールチェーンを共有しているため、1つのアプリをビルドできれば、他のアプリもすべてビルドできます。

</div>

## アプリ

| アプリ | 用途 | プラットフォーム |
|-----|---------|----------|
| [B1 Mobile](./b1-mobile.md) | 教会員向けの主要アプリ | Android、iOS |
| B1 Checkin | チェックインステーション用のキオスクアプリ | Android、iOS |
| LessonsScreen | 教室でレッスンを表示するためのAndroid TVアプリ | Android TV |

### B1 Mobile

教会員のための主要アプリです。メンバーは名簿を閲覧したり、献金機能を利用したり、出席を確認したり、通知を受け取ったり、教会コミュニティと交流したりできます。詳細は[B1 Mobileセットアップガイド](./b1-mobile.md)をご覧ください。

### B1 Checkin

教会のチェックインステーション向けに作られた専用のキオスクアプリです。タッチ操作に適したシンプルなインターフェースを備えており、メンバーが子どもをチェックインさせたり、礼拝やイベントへの出席を記録したりできます。

### LessonsScreen

教室でレッスンコンテンツを表示するAndroid TVアプリです。教師はレッスンのスライド、動画、アクティビティをTV画面に送信でき、授業中にカリキュラム教材を簡単に提示できます。

:::info
すべてのモバイルアプリは同じExpoベースのツールチェーンを共有しており、類似したセットアップ手順に従います。[B1 Mobile](./b1-mobile.md)ガイドは、すべてのモバイルプロジェクトに共通するセットアップ手順の参考資料として役立ちます。
:::
