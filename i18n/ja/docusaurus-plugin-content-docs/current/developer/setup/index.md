# セットアップ

<div class="article-intro">

このセクションでは、ChurchAppsプロジェクトのローカル開発環境を設定する手順を説明します。フロントエンドで共有のデモAPIを利用して手早く開発することも、バックエンドの作業のためにスタック全体をローカルで動かすこともできます。

</div>

## 2つのアプローチ

ローカルで開発する方法は、必要なスタックの範囲によって2つあります。

### 1. デモAPIを利用する（最も簡単）

**フロントエンドのプロジェクト**（Webアプリ、モバイルアプリ、デスクトップアプリ）に取り組む場合は、ローカルのアプリから共有のデモAPIを参照するのが最も早い方法です。データベースやバックエンドの設定は不要です。

デモAPIのベースURLは次のとおりです。

```
https://api.demo.churchapps.org
```

各APIモジュールは、このベースの下の次のようなパスで利用できます。

```
https://api.demo.churchapps.org/membership
https://api.demo.churchapps.org/attendance
https://api.demo.churchapps.org/giving
```

デモ環境では`main`ブランチの最新コードが動いており、サンプルデータは毎晩再投入されます。そこで作成したものは残らない前提で利用してください。（以前のステージング環境`api.staging.churchapps.org`は廃止されました。一部のサンプル`.env`ファイルにはまだステージングのURLが記載されていることがあるので、デモまたはローカルのURLに置き換えてください。）

:::tip
この方法を使えば、数分でフロントエンドの変更を始められます。ほとんどのコントリビューターにおすすめの方法です。
:::

### 2. すべてをローカルで実行する

APIのコードを変更する場合やオフラインで作業する場合は、スタック全体をローカルで実行できます。この場合はMySQL 8.0以降と追加の設定が必要です。詳しい手順は[APIのローカル設定](../api/local-setup)のガイドを参照してください。

## はじめに

以下のページを順番に進めてください。

1. **[前提条件](prerequisites)** -- 必要なツール（Node.js、Git、MySQLなど）をインストールします
2. **[プロジェクトの概要](project-overview)** -- 存在するプロジェクトとその役割を把握します
3. **[環境変数](environment-variables)** -- `.env`ファイルを設定して、すべてを接続します

:::info
ChurchAppsの各プロジェクトは独立したGitリポジトリです。作業したいプロジェクトだけをクローンすれば十分です。
:::
