# B1 Church Checkin のはじめに

<div class="article-intro">

B1 Church Checkin の設定には数分しかかかりません。このセクションでは、Android タブレットへのアプリのインストール、ChurchApps アカウントでのログイン、そしてネットワークラベルプリンターの任意の設定について説明します。

</div>

## 必要なもの

- **Android タブレット** -- キオスク形式での利用には 10 インチのタブレットが最適です。
- **ChurchApps アカウント** -- B1 Admin など、ChurchApps の製品で使用しているメールアドレスとパスワードです。
- **ネットワークラベルプリンター**（任意） -- 名前ラベルや保護者向けの引き取り票を印刷するために使用します。アプリはローカルネットワークをスキャンして、対応するプリンターを見つけることができます。

## インストール

1. Android タブレットで **Google Play ストア** を開きます。
2. **B1 Church Checkin** を検索します。
3. **インストール** をタップし、ダウンロードが完了するまで待ちます。
4. アプリを開きます。初期化中はスプラッシュ画面が表示されます。

## 初回セットアップ

アプリを初めて起動すると、次の 3 つのステップに進みます。

1. **[ログイン](./logging-in.md)** -- メールアドレスとパスワードを入力して認証します。
2. **[教会を選択](./logging-in.md)** -- アカウントが複数の教会に紐づいている場合は、このキオスクで使用する教会を選択します。
3. **[プリンターを設定](./printer-setup.md)** -- ラベル印刷用にネットワークプリンターを設定します。ラベルが不要な場合はこのステップを飛ばせます。

初回ログイン後、アプリはログイン情報と教会の選択内容を保存します。次回以降の起動では、サービス画面に自動的に直接移動します。

:::info
アプリは起動するたびに、無線（OTA）アップデートを確認します。アップデートがある場合は、ログイン画面が表示される前に自動的にダウンロードされ、適用されます。
:::

:::tip
キオスクを設定する前に、教会の管理者が B1 Admin でサービス、サービス時間、グループを設定しておいてください。詳しくは [出席の設定ガイド](../../b1-admin/attendance/setup.md) を参照してください。
:::
