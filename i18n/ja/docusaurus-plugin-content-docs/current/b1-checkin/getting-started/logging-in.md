# ログイン

<div class="article-intro">

キオスクでチェックインを行う前に、教会へのアクセス権を持つ ChurchApps アカウントでサインインする必要があります。このページでは、初回ログインの手順、教会の選択、自動ログインの動作、ログアウトの方法について説明します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- Android タブレットに B1 Church Checkin をインストールしてください([はじめに](./index.md)を参照)
- ChurchApps アカウントのメールアドレスとパスワードを用意してください
- アカウントには、教会で **Checkin** 権限(または **Edit Attendance** 権限)が必要です。管理者が B1 Admin の **Settings > Roles** で追加します。詳しくは [チェックインキオスクのアカウント](../../b1-admin/settings/roles-permissions.md#check-in-kiosk-accounts) を参照してください

</div>

## 初回ログイン

1. B1 Church Checkin アプリを開きます。スプラッシュ画面の後、B1 Church Checkin のロゴが表示されたログイン画面が表示されます。
2. 最初の欄に **メールアドレス** を入力します。
3. 2 番目の欄に **パスワード** を入力します。
4. **Login** ボタンをタップします。

アプリが認証情報を検証し、サインインします。メールアドレスまたはパスワードが正しくない場合は、画面下部にエラーメッセージが表示されます。

アカウントで [二要素認証](../../b1-admin/profile/managing-profile.md#two-factor-sign-in) が有効になっている場合は、アプリからコードの入力を求められます。アカウント所有者の認証アプリに表示されている 6 桁のコード、またはバックアップコードのいずれかを入力し、もう一度 **Login** をタップしてください。このコードが必要になるのは初回ログイン時のみで、その後はキオスクがサインイン状態を維持します。

:::info
これは、B1 Admin や他の ChurchApps 製品で使用しているものと同じメールアドレスとパスワードです。チェックインキオスク用に別のアカウントを用意する必要はありません。
:::

## 教会の選択

サインインに成功すると、アプリはアカウントに **Checkin** または **Edit Attendance** 権限がある教会を読み込みます。他の権限のみを持つ教会は除外されます。除外された結果、対象の教会が一つもない場合は **No check-in access** と表示され、教会の管理者に、役割のいずれかに Checkin 権限を追加してもらうよう依頼するよう求められます。各教会は、教会名と(B1 Admin でロゴが設定されている場合は)ロゴを示すカードとして表示されます。

- アカウントが **1 つの教会のみ** に紐付けられている場合でも、選択画面が表示されます。続行するには、教会をタップしてください。
- アカウントが **複数の教会** に紐付けられている場合は、このキオスクで利用したい教会をタップしてください。

教会を選択すると、アプリはその教会のブランディングと表示設定を読み込みます。以降のすべての画面のヘッダーに、教会のロゴが表示されます。

## 再訪時の自動ログイン

初回のサインインに成功すると、アプリは安全なサインイン トークンと選択した教会の情報をタブレットに保存します。パスワードは保存されません。次回以降に起動すると、次の動作になります。

- アプリは保存されたトークンを使ってサインインし直します。
- 以前に教会を選択していた場合は、その選択を復元し、**services screen** に直接移動します。
- 保存されたサインインが無効になっている場合は、ログイン画面に戻るので、もう一度サインインしてください。

:::tip
キオスクは自動でログインするため、認証情報を入力するのは初回セットアップ時の一度だけで済みます。その後はタブレットの電源を入れるだけで使用できる状態になります。
:::

## 管理設定

キオスクを使用する教会のメンバーが誤って設定を変更しないよう、管理設定は意図的に非表示になっています。管理設定を開くには、次の手順に従ってください。

1. ヘッダーの **教会のロゴ** を、2 秒以内に **7 回** 続けてタップします。
2. キオスクの PIN が設定されている場合は、求められたら PIN を入力します。
3. **Admin Settings** 画面が開き、次のオプションが表示されます。
   - **Change Service** — 選択中のサービス時間を切り替えます
   - **Change Printer** — [プリンターの設定](./printer-setup.md)を開き、プリンターを検索して選択します
   - **Set/Change PIN** — 管理者アクセスを保護するキオスクの PIN を設定または変更します
   - **Logout** — サインアウトし、ログイン画面に戻ります

:::warning
ログアウトすると、保存されているすべての認証情報と教会の選択が消去されます。キオスクを再び使用するには、メールアドレスとパスワードを入力し直す必要があります。アカウントを切り替える場合やキオスクを再設定する場合にのみ、ログアウトしてください。
:::
