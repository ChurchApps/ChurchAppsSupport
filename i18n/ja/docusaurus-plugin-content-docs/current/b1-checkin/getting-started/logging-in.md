# ログイン

<div class="article-intro">

キオスクでチェックインを行う前に、お使いの教会へのアクセス権がある ChurchApps アカウントでサインインする必要があります。このページでは、初回ログインの手順、教会の選択、自動ログインの動作、ログアウト方法について説明します。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- Android タブレットに B1 Church Checkin をインストールします（[はじめに](./index.md)を参照）
- ChurchApps アカウントのメールアドレスとパスワードを用意します
- アカウントには、お使いの教会で **チェックイン** 権限（または **出欠の編集**）が必要です。管理者が B1 Admin の **設定 > 役割** で追加します。詳しくは [チェックインキオスク用アカウント](../../b1-admin/settings/roles-permissions.md#check-in-kiosk-accounts)を参照してください

</div>

## 初回ログイン

1. B1 Church Checkin アプリを開きます。スプラッシュスクリーンの後に、B1 Church Checkin のロゴが表示されたログイン画面が現れます。
2. 最初の欄に **メールアドレス** を入力します。
3. 2番目の欄に **パスワード** を入力します。
4. **ログイン** ボタンをタップします。

アプリが認証情報を確認し、サインインします。メールアドレスまたはパスワードが正しくない場合は、画面下部にエラーメッセージが表示されます。

アカウントで [二要素認証](../../b1-admin/profile/managing-profile.md#two-factor-sign-in) が有効になっている場合は、続けてコードの入力を求められます。アカウント所有者の認証アプリに表示される6桁のコード、またはバックアップコードのいずれかを入力し、もう一度 **ログイン** をタップしてください。コードが必要になるのは最初のログイン時のみです。その後はキオスクのサインイン状態が維持されます。

:::info
これは B1 Admin や他の ChurchApps 製品で使用しているものと同じメールアドレスとパスワードです。チェックインキオスク用に別のアカウントを用意する必要はありません。
:::

## 教会の選択

サインインに成功すると、アプリはお使いのアカウントに **チェックイン** または **出欠の編集** の権限がある教会を読み込みます。それ以外の権限しかない教会は表示されません。該当する教会が1つもない場合は、**チェックインへのアクセス権がありません** と表示されます。その場合は、教会の管理者に役割のいずれかへチェックイン権限を追加してもらってください。各教会は、教会名と（B1 Admin で設定されていれば）ロゴを表示したカードとして表示されます。

- アカウントが **1つの教会のみ** に紐づいている場合も、選択画面が表示されます。お使いの教会をタップして続行してください。
- アカウントが **複数の教会** に紐づいている場合は、このキオスクで利用したい教会をタップしてください。

教会を選択すると、アプリはその教会のブランディングと外観の設定を読み込みます。以降のすべての画面のヘッダーに、教会のロゴが表示されます。

## 次回以降の自動ログイン

初回のログインに成功すると、アプリは安全なサインイン用トークンと選択した教会をタブレットに保存します。パスワードは保存されません。次回以降に起動したときの動作は次のとおりです。

- 保存されたトークンを使って、自動的にサインインします。
- 以前に教会を選択していた場合は、その選択を復元し、**サービス画面** に直接移動します。
- 保存されたサインインが無効になっている場合は、ログイン画面に戻り、再度サインインできるようにします。

:::tip
キオスクは自動でログインするため、認証情報を入力するのは初期設定の際の一度だけで済みます。その後はタブレットの電源を入れるだけで使用できる状態になります。
:::

## 管理者設定

教会のメンバーがキオスクを使用する際に、誤って設定を変更してしまわないよう、管理者設定は意図的に非表示になっています。管理者設定を開くには、次の手順に従います。

1. ヘッダーの **教会のロゴ** を、素早く（2秒以内に）**7回** タップします。
2. キオスクの PIN が設定されている場合は、表示された際に PIN を入力します。
3. **管理者設定** 画面が開き、次のオプションが表示されます。
   - **サービスを変更** — 選択中のサービス時間を切り替えます
   - **プリンターを変更** — [プリンター設定](./printer-setup.md)を開き、プリンターを検索して選択します
   - **管理者 PIN を設定**（設定済みの場合は **管理者 PIN を変更**）— 管理者機能を保護するキオスク PIN を設定または更新します
   - **緊急一斉連絡** — チェックイン済みのすべての世帯の保護者にテキストメッセージを送信します（[緊急一斉連絡](../check-in/checking-out.md#emergency-broadcast)を参照）
   - **有人受付モード** — このステーションにチェックアウト、呼び出し、再印刷、プロフィール編集の機能を追加するスイッチです（[チェックアウト](../check-in/checking-out.md)を参照）
   - **ログアウト** — サインアウトし、ログイン画面に戻ります

   チェックインに戻るには **キオスクに戻る** をタップします。

:::warning
ログアウトすると、保存されているすべての認証情報と教会の選択が消去されます。キオスクを再び使用するには、メールアドレスとパスワードを再度入力する必要があります。アカウントを切り替える場合や、キオスクの設定を変更する必要がある場合にのみログアウトしてください。
:::
