# プリンターの設定

<div class="article-intro">

B1 Church Checkin では、ネットワーク対応のラベルプリンターで名札ラベルや保護者用の引き渡し票を印刷できます。プリンターの設定は任意です。プリンターを使わず、出席記録のみに使うこともできます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1 Church Checkin アプリに[ログイン](./logging-in.md)し、教会を選択します
- 対応するネットワークラベルプリンターを、タブレットと同じ Wi-Fi ネットワークに接続します

</div>

## 推奨ラベル

B1 Checkin の標準ラベルテンプレートは **1.1" × 3.5"** のラベル用に作られています。

**Brother QL プリンター**を使う場合は、**Brother DK-1201**（1.1" × 3.5"）のラベルを使用してください。Brother プリンターは、プリンターにセットされたロールの実際のサイズを検出します。ロールがテンプレートのサイズと一致しない場合、プリンターは印刷しません。別のサイズは使わないでください。

[Brother DK-1201 互換ラベル 12ロール（Amazon）](https://www.amazon.com/dp/B0716XB6JG?tag=signpresenter-20)

## プリンター設定の開き方

**管理者設定**メニューから、いつでもプリンター設定画面を開けます。

1. ヘッダーの**教会のロゴ**を、2秒以内に**7回**続けてタップします。
2. キオスク PIN が設定されている場合は、求められたら PIN を入力します。
3. 管理者設定画面で、**プリンターを変更**をタップします。

プリンター設定画面が開きます。ここでプリンターを検索し、選択して、テスト印刷を実行できます。

## プリンターの検索

プリンター設定画面が開くと、アプリは自動的にローカルネットワーク上の対応プリンターを検索します。検索中は、「プリンターを検索中」というメッセージとともに読み込み表示が出ます。

検索が完了すると、見つかったプリンターの一覧が表示されます。各プリンターのカードには次の情報が表示されます。

- **プリンターの機種名**
- ネットワーク上の**プリンターの IP アドレス**

一覧の末尾には、常に**プリンターなし**の項目があります。

:::warning
プリンターを検索で見つけるには、タブレットとプリンターが同じローカルネットワークに接続されている必要があります。プリンターが表示されない場合は、両方の機器が同じ Wi-Fi ネットワークに接続されていること、またプリンターの電源が入っていることを確認してください。
:::

## プリンターの選択

1. 使用するプリンターをタップします。選択されたプリンターのカードにチェックマークが付き、強調表示されます。
2. 実際のプリンターを使わずに印刷する場合（テストや出席記録のみのモード）は、**プリンターなし**を選択します。

## テスト印刷

選択を保存する前に、接続が正常に動作するかを確認できます。

1. 一覧からプリンターを選択します。
2. 画面下部の**テスト印刷**ボタンをタップします。
3. アプリがテストラベルをプリンターに送信します。プリンターが正しく接続されていれば、テストページが印刷されます。

**プリンターなし**を選択した状態で**テスト印刷**をタップすると、プリンターが選択されていないことを知らせるアラートが表示されます。

:::tip
次の礼拝の前には、プリンターを選択した後に必ずテスト印刷を行い、接続を確認してください。
:::

## 選択内容の保存

プリンターの選択が決まったら、次の手順で保存します。

1. 画面下部の**保存して再起動**ボタンをタップします。
2. アプリがプリンターの選択を保存し、設定を反映するために再起動します。

プリンターの選択はアプリを再起動しても保持されます。プリンターを変更したい場合を除き、再度設定する必要はありません。

:::info
キオスクを別の場所に移動したり、ネットワーク構成を変更したりした場合は、プリンター設定に戻ってプリンターを再検索し、選択内容を更新してください。
:::

## 次のステップ

プリンターの設定が済んだら、チェックインを始められます。[チェックインの流れ](../check-in/index.md)では全体の手順を説明しています。最初のステップは[礼拝の選択](../check-in/selecting-service.md)です。
