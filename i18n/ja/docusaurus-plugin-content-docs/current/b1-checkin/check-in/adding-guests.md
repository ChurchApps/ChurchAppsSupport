# ゲストの追加

<div class="article-intro">

ご家族を訪ねてこられた方が、ご家族と一緒にチェックインする必要がある場合は、キオスクから直接ゲストとして追加できます。教会のシステムにまだ登録されていない、訪問中のお子さま、親戚、友人の方などに便利です。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [ご家族を検索する](./looking-up-members)で、検索結果から会員を選択します
- ご家族の会員が表示される[世帯の確認画面](./household-review)を開いておきます

</div>

## ゲストを追加する方法

1. **世帯の確認画面**で、世帯メンバーの一覧の下にある **ゲストを追加** ボタンをタップします。
2. ゲスト追加フォームが表示され、次の2つの項目があります。
   - **名** -- ゲストの名を入力します。
   - **姓** -- ゲストの姓を入力します。
3. **ゲストを追加** ボタンをタップして保存します。

ゲストが世帯に追加され、世帯の確認画面に戻ります。新しいゲストは、他のご家族と並んで会員の一覧に表示されます。

:::info
ゲストの名前が、会員ではないもののシステムにすでに登録されている方と一致する場合、アプリは重複レコードを作成せず、既存のレコードにリンクします。これにより、教会のデータベースを整理された状態に保てます。
:::

## ゲスト追加後の操作

ゲストが世帯の一覧に表示されたら、次の操作ができます。

- **カードを展開**して、他のご家族と同様に[グループに割り当てます](./group-assignment)。
- ゲストを含む世帯全体を[チェックイン](./completing-checkin)します。

## 取り消し

追加を取りやめる場合は、ゲスト追加フォーム下部の **キャンセル** ボタンをタップすると、誰も追加せずに世帯の確認画面に戻ります。

:::tip
キオスクでゲストを追加すると、教会のデータベースに人物レコードが作成されます。ゲストの詳しい情報は、後から教会の管理者が B1 Admin の[人物](../../b1-admin/people/adding-people.md)で更新できます。
:::

## 次のステップ

ゲストを追加し、必要に応じて[グループを割り当てた](./group-assignment)後は、[チェックインを完了](./completing-checkin)できます。
