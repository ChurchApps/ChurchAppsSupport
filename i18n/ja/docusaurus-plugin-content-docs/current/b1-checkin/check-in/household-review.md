# 世帯を確認する

<div class="article-intro">

検索結果からメンバーを選択すると、アプリは世帯全員を読み込み、世帯確認画面に表示します。この画面はチェックイン処理の中心となる場所で、家族全員を確認し、チェックインの前にグループの割り当てを管理できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- サービス画面で[サービスを選択](./selecting-service)する
- [メンバーを検索](./looking-up-members)し、検索結果からそのメンバーを選択する

</div>

## 世帯メンバーの表示

世帯の各メンバーは、次の情報を含むカードとして表示されます。

- 本人の**写真**(写真が登録されていない場合はプレースホルダーのアイコン)
- 本人の**表示名**
- **現在のグループ割り当ての概要**(カードが折りたたまれている場合は、名前の下に小さなチップとして表示されます)
- カードの右側にある**展開/折りたたみの矢印**

## メンバーの展開

メンバーのカードをタップすると展開されます。展開すると、選択したサービス内の**サービス時間**ごとに行が表示されます。サービス時間は、予定の曜日と開始時刻が設定されていればそれらの順に、設定されていなければ名前に含まれる時刻の順に並びます(例:「9:00 AM」は「10:30 AM」より前に表示されます)。時刻が名前に含まれていないサービス時間は、最後にアルファベット順で並びます。各行には次の情報が表示されます。

- **サービス時間の名前**(例:「9:00 AM」や「11:00 AM」)
- そのサービス時間で**提供されているグループ**。名前の下に一覧表示されます(例:「保育、就学前、大人の聖書の授業」)。選択する前に、どのクラスが利用できるかを確認できます。
- **現在割り当てられているグループ**を示すボタン。まだグループが割り当てられていない場合は「**グループを選択**」と表示されます。

サービス時間に[チェックインのスケジュール](../../b1-admin/attendance/setup#setting-a-check-in-schedule)が設定されていて、現在その受付時間外である場合、行にはボタンの代わりに**締切**と表示されます。次の受付開始時刻がわかる場合は、**締切 · 日曜 9:30 AM に受付開始**のように表示されます。その人がすでにそのサービス時間にチェックイン済みの場合は、ボタンの代わりにグループ名とチェックマークが表示されます(例:**キッズルーム1 · チェックイン済み**)。受付時間が締め切られていても、どこにいるかを確認できます。

グループのボタンをタップすると、[グループ選択画面](./group-assignment)に移動します。そこで、そのメンバーとサービス時間のグループを選択または変更できます。

展開されたカードには、**会員**、**ゲスト**、**ボランティア**のチップも表示されます。いずれかをタップすると、その人のチェックインの種類を設定できます。既定は会員です。この種類は子ども部屋で重要です。ボランティアは部屋の「ボランティア対児童」の比率に含まれ、ゲストは教会が設定したゲストの定員に含まれます。

メンバーのカードをもう一度タップすると、折りたたまれます。

:::tip
家族全員をグループに割り当てる必要はありません。メイン礼拝に出席する大人は、グループの割り当てをしなくても構いません。特定のクラスやプログラムにチェックインする必要があるメンバーだけ、グループを割り当ててください。
:::

## この画面からの操作

世帯確認画面では、次の3つの操作ができます。

- **メンバーを展開**し、サービス時間のボタンをタップして[グループを割り当てる、または変更する](./group-assignment)。
- メンバー一覧の下にある**ゲストを追加**ボタンをタップして、世帯に[ゲストを追加する](./adding-guests)。
- 画面下部の**チェックイン**ボタンをタップして、世帯全員の[チェックインを完了する](./completing-checkin)。

:::info
同じサービスの以前のチェックインで割り当てられたグループは、自動的に読み込まれます。お子さまが毎週同じグループに参加している場合は、何も変更せず、確認してチェックインするだけで済む場合があります。
:::

##次のステップ

- 特定のクラスやプログラムにチェックインする必要がある家族メンバーに、[グループを割り当てる](./group-assignment)。
- 家族と一緒に来ている人がいる場合は、[ゲストを追加する](./adding-guests)。
- 全員の割り当てが正しければ、[チェックインを完了する](./completing-checkin)。
