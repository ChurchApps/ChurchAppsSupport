# グループの割り当て

<div class="article-intro">

世帯確認画面で礼拝時間ボタンをタップすると、グループ選択画面が開きます。ここでは、その礼拝時間にご家族のどのメンバーがどのグループまたはクラスに参加するかを選びます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- 世帯確認画面で[世帯を確認する](./household-review.md)
- 割り当てたいメンバーを展開し、礼拝時間ボタンをタップする
- 教会の管理者が[グループを作成](../../b1-admin/groups/creating-groups.md)し、B1 Admin で礼拝時間に紐付けていることを確認する

</div>

## グループの構成

グループは**カテゴリ**ごとに表示されます。各カテゴリは次の内容を示すカードとして表示されます。

- **カテゴリ名**(例:「子ども」「若者」「大人」)
- そのカテゴリ内の**グループ数**

カテゴリのカードをタップすると展開され、中の個別のグループが表示されます。もう一度タップすると折りたたまれます。

## グループの選択

1. **カテゴリ**をタップして展開します。
2. そのカテゴリ内のグループの一覧を確認します。各グループには名前と、右側に選択アイコンが表示されます。
3. 割り当てたい**グループ名**をタップします。

アプリは選択内容を保存し、[世帯確認画面](./household-review.md)に戻ります。そのメンバーの礼拝時間ボタンには、選んだグループの名前が表示されるようになります。

## 年齢と学年のガイド

教会が部屋に年齢または学年の範囲を設定している場合、一覧で適切な部屋を案内します。対象者が条件を満たす部屋は**強調表示**され、年齢または学年が範囲外の部屋は**薄く表示**されます。薄く表示された部屋も選択はできますが、選択するにはスタッフの確認が必要です。年齢と学年は教会の進級日を基準に計算されるため、新学年に切り替わった後も情報が正しく保たれます。

## 「なし」の選択

ご家族のメンバーをこの礼拝時間のどのグループにも割り当てない場合は、画面下部の**なし**ボタンをタップします。その礼拝時間の既存のグループ割り当てが解除され、世帯確認画面に戻ります。

:::tip
主礼拝に出席し、特定のグループやクラスへのチェックインが不要な大人の方には、**なし**のオプションを使用してください。
:::

## グループの割り当てを変更する

すでに割り当てられたグループを変更するには、次の手順に従います。

1. [世帯確認画面](./household-review.md)に戻ります。
2. 変更したいグループのメンバーを展開します。
3. 礼拝時間ボタンをタップします(現在割り当てられているグループ名が表示されています)。
4. 別のグループを選択するか、**なし**をタップします。

:::info
グループとカテゴリは、教会の管理者が B1 Admin で設定します。グループが見つからない場合や、誤ったカテゴリに入っている場合は、管理者に[グループの設定](../../b1-admin/groups/creating-groups.md)の更新を依頼してください。
:::

## 次のステップ

グループを割り当てた後は、[世帯確認画面](./household-review.md)に戻って次の操作を行います。

- 追加のご家族メンバーにグループを割り当てる
- 家族と一緒に来ている方がいる場合は、[ゲストを追加](./adding-guests.md)する
- すべての割り当てが完了したら、[チェックインを完了](./completing-checkin.md)する
