# チェックインの完了

<div class="article-intro">

世帯の確認と必要なグループ割り当てが済んだら、チェックインを確定できます。これはキオスクでの操作の最後の手順です。アプリが出席情報を送信し、ラベルを印刷して、次の家族のために初期化されます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [世帯を確認する](./household-review.md)（世帯確認画面で行います）
- 特定のクラスやプログラムにチェックインする家族がいる場合は、[グループを割り当てる](./group-assignment.md)
- 任意で、一緒に来ている方がいれば[ゲストを追加する](./adding-guests.md)

</div>

## チェックインの方法

1. **世帯確認画面**で、画面下部の **Check-in** ボタンをタップします。
2. アプリが出席データをサーバーに送信し、緑のチェックマークと歓迎メッセージが表示された**成功画面**を表示します。

以上で完了です。ご家族の出席が記録されました。

## 部屋の定員と保育ボランティアの人数比

教会が部屋に[安全上の上限](../../b1-admin/attendance/checkin-safety.md)を設定している場合、サーバーは保存前にその上限を確認します。

- 選択した部屋が**定員に達している、または閉鎖されている**場合、チェックインは完了せず、アプリが該当の部屋名を表示するので、別の部屋を選び直せます。
- 礼拝時間に[チェックインのスケジュール](../../b1-admin/attendance/setup.md#setting-a-check-in-schedule)が設定されていて、現在そのチェックイン時間帯が開いていない場合は、その礼拝時間の部屋へのチェックインも同様に拒否されます。**Can't check in yet**（まだチェックインできません）画面に該当の部屋が表示され、理由として「チェックインは現在受け付けていません」と示されます。別の礼拝時間またはグループを選ぶには **Change Rooms**（部屋を変更）をタップします。（受付が終了している礼拝時間は[世帯画面](./household-review.md)で **Closed**（終了）と表示され、選択できません。そのため、この表示になるのは通常、チェックインの途中で受付時間が終了した場合に限られます。）
- 以前の礼拝時間にチェックインした世帯は、その受付時間が終わった後でも、あとから受付中の礼拝時間を追加できます。以前のチェックイン記録は保持され、新しいチェックインが拒否される原因にはなりません。
- 子ども向けの部屋で保育ボランティアの人数が人数比を満たしていない場合、教会の人数比の設定によって、スタッフが確認して続行できる警告が表示されるか、チェックインが完全にブロックされます。

## ラベルの印刷

ネットワークプリンターが設定されている場合、チェックイン後にアプリが自動的にラベルを印刷します。

- **名札ラベル**は、**Print Nametag**（名札を印刷）が有効になっているグループに割り当てられた人ごとに印刷されます。名札ラベルには、本人の名前、グループの割り当て、登録されている場合はアレルギーやメモ情報が含まれます。
- **保護者用の引き取り票**は、チェックインした人の中に **Parent Pickup**（保護者による引き取り）が有効なグループに所属する人がいる場合に印刷されます。**ボランティア**としてチェックインした人は対象外です。そのため、保護者引き取り対象の部屋で奉仕する保育スタッフには引き取り票は出ません。引き取り票には、子どもの名前、グループの割り当て、そして一意の**4文字のセキュリティコード**が記載されます。

:::info
同じセキュリティコードが、子どもの名札ラベルと保護者の引き取り票の両方に記載されます。お迎えの際、ボランティアがコードを照合して、正しい大人が子どもを引き取りに来ているかを確認します。
:::

セキュリティコードは、チェックインのたびに新しく生成されます。使用するのは子音と数字のみです（不適切な単語が偶然できないよう、母音は除外されています）。

:::warning
ラベルが印刷されない場合は、**教会のロゴ**を7回タップして管理設定を開き、**Change Printer**（プリンターを変更）をタップしてプリンターの接続を確認してください。トラブルシューティングの手順は[プリンターの設定](../getting-started/printer-setup.md)をご覧ください。
:::

## チェックイン後の動作

- プリンターが設定されている場合、アプリはすべてのラベルを印刷したのち、自動的に**検索画面**に戻り、次の家族を迎える準備が整います。
- プリンターが設定されていない場合も、アプリは自動的に**検索画面**に戻ります。

いずれの場合も、成功画面は表示されてから少なくとも6秒間は表示されたままになります（誰かの出席の節目を祝う場合は8秒間）。これにより、ご家族はチェックインが成功したことを確認できます。印刷に6秒以上かかる場合は、印刷が終わってから約1.5秒後に戻ります。

検索画面に戻るために何かをタップする必要はありません。画面の切り替えはアプリが自動的に行います。画面が少し表示された後であれば、タップすると直ちに戻ります。最初の1.5秒間のタップは無視されるため、**Check-in** を素早く2回タップしても、画面を飛ばしてしまうことはありません。

:::tip
アプリはチェックインのたびに完全にリセットされるため、ある家族の情報が別の家族に見えてしまうおそれはありません。
:::

## 記録される内容

**Check-in** をタップすると、グループの割り当てがあるすべての世帯メンバーについて、次の情報がサーバーに送信されます。

- チェックインする**人物**
- 参加する**礼拝**
- 割り当てられた**礼拝時間**と**グループ**

このデータは B1 Admin の出席セクションに表示され、教会の管理者が出席記録を確認・管理できます。詳細は[チェックイン管理ガイド](../../b1-admin/attendance/check-in.md)をご覧ください。
