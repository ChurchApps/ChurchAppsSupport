# チェックインを完了する

<div class="article-intro">

世帯の確認と必要なグループの割り当てが済んだら、チェックインを確定できます。これはキオスクでの作業の最後のステップです。アプリは出席データを送信し、ラベルを印刷して、次のご家族のために初期状態に戻ります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- [世帯を確認する](./household-review.md)（世帯確認画面で行います）
- 特定のクラスやプログラムに参加するご家族がいる場合は、[グループを割り当てる](./group-assignment.md)
- 必要に応じて、一緒に来ているご家族が いる場合は [ゲストを追加する](./adding-guests.md)

</div>

## チェックインの方法

1. **世帯確認画面**の下部にある **「チェックイン」** ボタンをタップします。
2. アプリは出席データをサーバーに送信し、緑のチェックマークと歓迎メッセージの入った **成功画面**を表示します。

これで完了です。ご家族の出席が記録されました。

選択した人の中に、本日この礼拝ですでにチェックイン済みの人がいる場合は、まず **「すでにチェックイン済み」** のウィンドウが表示され、該当者の名前が示されます。新しいグループの選択を保存するには **「再度チェックイン」** をタップし、世帯画面に戻るには **「キャンセル」** をタップします。

## 満員の部屋とボランティアの配置比率

教会が部屋に[安全上の上限](../../b1-admin/attendance/checkin-safety.md)を設定している場合、サーバーは保存前にその上限を確認します。

- 選択した部屋が **満員または閉鎖中** の場合、チェックインは完了せず、アプリが該当の部屋名を示すので、別の部屋を選び直せます。
-礼拝時間に[チェックインのスケジュール](../../b1-admin/attendance/setup.md#setting-a-check-in-schedule)が設定されていて、現在そのチェックイン時間帯が開いていない場合は、その礼拝時間の部屋へのチェックインも拒否されます。**「まだチェックインできません」** の画面には、「現在チェックインは開いていません」という理由とともに部屋が表示されます。別の礼拝時間またはグループを選ぶには **「部屋を変更」** をタップします。（すでに終了している礼拝時間は[世帯画面](./household-review.md)で **「終了」** と表示され、選択できません。そのため、この表示が出るのは通常、チェックインの途中で時間帯が終了した場合に限られます。）
- 以前の礼拝時間にチェックインした世帯が後から戻ってきて、開いている別の礼拝時間を追加することもできます。その時間帯が前の時間帯より後に終了していても構いません。既存のチェックイン記録は保持され、新しいチェックインが拒否されることはありません。
- 子ども向けの部屋で配置比率に対してボランティアが不足している場合、教会の比率の適用方法の設定に応じて、アプリは職員が確認して続行できる警告を表示するか、チェックインを完全にブロックします。

## ラベルの印刷

ネットワークプリンターが設定されている場合、チェックイン後にアプリが自動的にラベルを印刷します。

- **名札ラベル** は、**「名札を印刷」** が有効になっているグループに割り当てられている人ごとに印刷されます。名札ラベルには、その人の名前、グループの割り当て、登録されているアレルギーや備考の情報（ある場合）が含まれます。
- **保護者用お迎え票** は、**「保護者お迎え」** が有効になっているグループに、チェックインした人が一人でもいる場合に印刷されます。**ボランティア** としてチェックインした人は対象外です。そのため、保護者お迎えの部屋で奉仕している保育スタッフにはお迎え票は印刷されません。お迎え票には、子どもの名前、グループの割り当て、そして一意の **4文字のセキュリティコード** が記載されます。

:::info
同じセキュリティコードが、子どもの名札ラベルと保護者のお迎え票の両方に記載されます。お迎えの際には、ボランティアがコードを照合して、各お子さんを正しい大人が迎えに来ていることを確認します。
:::

セキュリティコードは、チェックインのたびに新しく生成されます。不適切な言葉にならないよう、母音を除いた子音と数字のみを使用します。

:::warning
ラベルが印刷されない場合は、**教会のロゴ** を7回タップして管理者設定を開き、**「プリンターを変更」** をタップしてプリンターの接続を確認してください。トラブルシューティングの手順は[プリンターの設定](../getting-started/printer-setup.md)を参照してください。
:::

## チェックイン後の動作

- プリンターが設定されている場合、アプリはすべてのラベルを印刷した後、自動的に **検索画面** に戻り、次のご家族を迎える準備をします。
- プリンターが設定されていない場合も、アプリは自動的に **検索画面** に戻ります。

どちらの場合も、成功画面は表示されてから少なくとも6秒間は表示されたままになります。これにより、ご家族はチェックインが成功したことを確認できます。（誰かの出席回数がマイルストーンに達して祝福表示される場合は8秒間表示されます。）印刷に6秒以上かかる場合は、印刷が終わってから約1.5秒後に戻ります。

検索画面に戻るために何かをタップする必要はありません。アプリが自動的に画面を切り替えます。画面が表示されてしばらくすると、タップしてすぐに戻ることもできます。最初の1.5秒間のタップは無視されるので、**「チェックイン」** を素早く二度タップしても、この画面が飛ばされることはありません。

:::tip
アプリはチェックインのたびに完全にリセットされるため、あるご家族の情報が別のご家族に表示されるおそれはありません。
:::

## 記録される内容

**「チェックイン」** をタップすると、アプリはグループの割り当てがある世帯の各メンバーについて、次の情報をサーバーに送信します。

- チェックインする **人**
- その人が参加する **礼拝**
- その人が割り当てられた **礼拝時間** と **グループ**

このデータは B1 Admin の出席セクションに表示され、教会の管理者が出席記録を確認・管理できます。詳細は[チェックイン管理ガイド](../../b1-admin/attendance/check-in.md)を参照してください。
