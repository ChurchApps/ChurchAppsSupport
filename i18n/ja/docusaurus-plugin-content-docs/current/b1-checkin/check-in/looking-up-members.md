# メンバーを検索する

<div class="article-intro">

サービスを選択すると、メンバー検索画面が表示されます。この画面でご家族を検索して、チェックインできます。アプリでは電話番号または名前で検索できます。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- サービス画面で[サービスを選択する](./selecting-service.md)
- 教会の管理者によって、ご家族が[システムに登録されている](../../b1-admin/people/adding-people.md)ことを確認する

</div>

## 検索モード

検索画面には2つの検索モードがあります。画面上部の切り替えをタップすると、モードを切り替えられます:

- **電話** -- 電話番号で検索します。これが既定のモードです。
- **名前** -- 名前で検索します。

## 電話番号で検索する

1. **電話**が選択されていることを確認します(画面上部で強調表示されています)。
2. 検索欄をタップし、画面のキーパッドを使って電話番号の数字を4桁以上入力します。
3. **検索**ボタンをタップするか、キーボードの検索キーを押します。

アプリは、入力した数字に一致する電話番号を持つメンバーを検索します。5桁以上入力した場合は、入力した番号全体を使います。ちょうど4桁を入力した場合は、登録されている電話番号の末尾4桁と照合します。

## 名前で検索する

1. 画面上部の**名前**の切り替えをタップして、名前検索モードに切り替えます。
2. 検索欄に、本人の名前を2文字以上入力します。
3. **検索**ボタンをタップします。

アプリは、入力した文字に一致する名前を持つメンバーを検索します。

## 本人を選択する

検索結果は検索欄の下にカードとして表示されます。各カードには、本人の**名前**と(登録されている場合は)**写真**が表示されます。

本人のカードをタップして選択します。アプリはその方の世帯の全メンバーを読み込み、[世帯の確認画面](./household-review.md)に進みます。

:::tip
電話番号の末尾4桁で検索するのが、ご家族を探す最も速い方法です。チェックインをよりスムーズにするため、メンバーの皆さまにこの方法をおすすめしてください。
:::

:::warning
結果が見つからない場合、アプリにその旨のメッセージが表示されます。入力した数字または名前を確認するか、別の検索モードを試してください。初めて来館された方は、ボランティアに声をかけて[システムに登録](../../b1-admin/people/adding-people.md)してもらってください。
:::

## ゲストとして登録する

教会でQRコードによるゲスト登録が有効になっている場合、検索画面の検索欄の下に**ゲストとして登録**のリンクが表示されます。初めて来館された方は、このリンクを使ってチェックインの前にご家族を教会のシステムに登録できます。

1. **ゲストとして登録**をタップします。QRコードと「ゲスト登録のためにスキャンしてください」というメッセージが表示された画面が開きます。
2. [ゲスト登録フォーム](../../b1-church/checkin/guest-registration.md)への入力方法を選びます:
   - **スマートフォンで入力** -- QRコードをスキャンし、スマートフォンでフォームに入力してから、**OK**をタップして画面を閉じます。
   - **受付端末で入力** -- **ここで登録**をタップすると、同じフォームがタブレット上で開きます。入力して**登録**をタップしたあと、**完了**(または戻る矢印)をタップして検索画面に戻ります。
3. 登録が完了したら、名前または電話番号でご家族を検索し、チェックインします。

:::info
**ここで登録**で開いたフォームは、ゲスト登録ページに留まります。受付端末から教会のWebサイトの他のページに移動することはできません。2分間フォームに触れられず、何も入力されなかった場合は、受付端末がフォームを閉じて検索画面に戻ります。フォームが閉じられるたびに、入力された内容は消去されるので、次のご家族は空白のフォームから始められます。
:::

## スマートフォンでチェックイン済みの場合のラベル印刷

[B1 Churchのセルフチェックイン](../../b1-church/checkin/self-checkin.md)で、スマートフォンからすでにチェックインしているご家族は、ご自身で検索しなくても、受付端末で名札を印刷できます。

1. 検索画面で、**コードをスキャン**ボタン(QRコードのアイコン)をタップします。
2. スマートフォンのQRコードをカメラにかざします。アプリがカメラへのアクセスを求めた場合は、**カメラを許可**をタップします。既定ではインカメラが使われます。切り替えボタンをタップするとカメラを切り替えられます。
3. 受付端末がチェックインを見つけてラベルを印刷し、検索画面に戻ります。

スキャンによって印刷されるのはラベルのみです。出席は、ご家族がスマートフォンでチェックインした時点ですでに記録されています。コードが有効なチェックインと一致しない場合は、受付端末にメッセージが表示され、検索画面に戻ります。
