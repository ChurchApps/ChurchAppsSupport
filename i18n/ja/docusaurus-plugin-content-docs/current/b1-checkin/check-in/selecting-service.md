# サービスの選択

<div class="article-intro">

チェックインの最初のステップは、参加するサービスを選ぶことです。サービス選択画面は、アプリの読み込みが完了するとすぐに表示されます。ここで選んだサービスによって、その後のチェックインの流れで利用できるサービス時間とグループが決まります。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- B1 Church Checkin アプリに[ログイン](../getting-started/logging-in.md)し、教会を選択します
- 教会の管理者が B1 Admin で[サービスとサービス時間を設定](../../b1-admin/attendance/setup.md)していることを確認します

</div>

## 仕組み

1. ログイン後（または次回以降の起動で自動ログインされた後）、アプリに**サービス画面**が表示されます。
2. 教会に設定されているすべてのサービスの一覧が表示されます。各サービスは、サービス名（例：「日曜午前」「水曜夜」）が書かれたカードとして表示されます。
3. 参加するサービスをタップします。

アプリは、そのサービスに紐づくサービス時間とグループを読み込み、[メンバー検索画面](./looking-up-members.md)に進みます。

## チェックインが開いていない場合

管理者がサービス時間に[チェックインのスケジュール](../../b1-admin/attendance/setup.md#setting-a-check-in-schedule)を設定している場合、アプリは、そのサービス時間のチェックイン受付時間内にだけ、ご家族がそのサービス時間を選べるようにします。現在受付時間外のサービス時間も[世帯確認画面](./household-review.md)には表示されますが、グループのボタンは表示されず、**閉鎖中**（例：**閉鎖中 · 日曜 9:30 に開始**）と表示されます。

タップしたサービスのすべてのサービス時間が閉鎖中の場合、アプリはチェックインが開始する時刻を表示します（例：**「このサービスのチェックインは日曜 9:30 に開始します。」**）。開始時刻が表示できない場合は、**「このサービスは現在チェックインを受け付けていません。」**と表示されます。**「戻る」**をタップしてサービス一覧に戻り、別のサービスを選ぶか、受付時間が始まるまで待ってから再度お試しください。

:::info
チェックインの受付時間は、サービスの拠点（キャンパス）のタイムゾーンに従います。その拠点にタイムゾーンが設定されていない場合は、教会のタイムゾーンが使用されます。サービス時間の開始時刻が正しくないように見える場合は、管理者に拠点または教会の設定でタイムゾーンを確認してもらってください。また、世帯確認画面では、キオスクはタブレット本体の時計を使ってサービス時間の開始・終了を判断します。タブレットの時刻とタイムゾーンが正しく設定されているか確認してください。
:::

:::info
サービスは、教会の管理者が B1 Admin の出席（Attendance）セクションで設定します。想定しているサービスが表示されない場合は、管理者に[出席の設定](../../b1-admin/attendance/setup.md)で作成されているかを確認してもらってください。
:::

## 裏側で行われること

サービスを選択すると、アプリはサーバーから次の3つの情報を取得します。

- そのサービスの**サービス時間**（例：1つのサービスに午前9:00と午前11:00の時間枠がある場合）。
- 各サービス時間で利用できる**グループ**（例：乳児室、未就学児、小学生）。
- どのグループがどのサービス時間に利用できるかを決める**グループとサービス時間の紐づけ**。

このデータはローカルにキャッシュされるため、その後のチェックインの処理が速く、スムーズに動作します。

:::tip
教会に設定されているサービスが1つだけでも、次に進むにはそのサービスをタップする必要があります。アプリが自動で選択することはありません。
:::

## 次のステップ

サービスを選択したら、電話番号または名前で[ご家族を検索](./looking-up-members.md)します。
