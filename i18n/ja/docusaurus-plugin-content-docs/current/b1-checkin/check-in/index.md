# チェックインの流れ

<div class="article-intro">

B1 Church Checkin のチェックイン処理は、シンプルで段階的な流れになっています。教会のメンバーはキオスクに近づき、自分の家族を見つけ、グループの割り当てを確認してチェックインします。すべて1分以内に完了します。このセクションでは、キオスクでのチェックイン操作の各ステップを説明します。

</div>

## チェックインの流れの概要

1. **[サービスを選択する](./selecting-service)** -- 参加するサービスを選びます(例: 日曜午前、日曜午後、水曜日の集会)。
2. **[家族を検索する](./looking-up-members)** -- 電話番号または姓で検索し、システム内で自分を見つけます。
3. **[世帯を確認する](./household-review)** -- 家族全員と、現在のグループ割り当てを確認します。
4. **[グループを割り当てる](./group-assignment)** -- 各サービス時間に、家族それぞれが参加するクラスやグループを選びます。
5. **[ゲストを追加する](./adding-guests)**(任意) -- 一緒に来ている訪問者がいる場合は、世帯にゲストとして追加します。
6. **[チェックインを完了する](./completing-checkin)** -- チェックインボタンをタップして出席を記録し、ラベルを印刷します。
7. **[チェックアウト](./checking-out)**(有人ステーション) -- お迎えの時間に、セキュリティコードと引き取り者を確認します。信頼できる引き取り者リスト、保護者への呼び出し、ラベルの再印刷にも対応しています。

チェックインが完了すると、アプリは成功画面を表示し、次の家族のために自動的に検索画面に戻ります。

:::tip
この一連の流れは、教会のメンバーが単独で操作できるように設計されています。ボランティアがキオスクを操作する必要はありませんが、初めて来られた方を手伝えるように近くにスタッフがいると、なお良いでしょう。
:::

## 始める前に

チェックインキオスクを使用する前に、B1 Admin で次の項目が設定されていることを確認してください。

- **サービスとサービス時間**が、出席設定で登録されていること。詳しくは[出席の設定ガイド](../../b1-admin/attendance/setup.md)を参照してください。
- **グループ**が作成され、適切なサービス時間に紐付けられていること。詳しくは[グループの作成](../../b1-admin/groups/creating-groups.md)を参照してください。
- **グループ設定**でラベル印刷が有効になっていること。名札が必要なグループでは **Print Nametag** を、保護者への引き渡し票が必要な子ども向けグループでは **Parent Pickup** を有効にします。
- **人物**がシステムに登録され、世帯との関連付けが行われていること。詳しくは[人物の追加](../../b1-admin/people/adding-people.md)を参照してください。

:::info
キオスク自体のセットアップがまだの場合は、インストール、ログイン、プリンターの設定手順について [はじめに](../getting-started/) を参照してください。
:::
