# チェックアウトとお子さまの安全

<div class="article-intro">

チェックアウトは、チェックインの流れを締めくくる工程です。保護者が引き取り用ラベルのセキュリティコードを提示し、キオスクが引き取りに来た人を確認したうえで、お子さまをチェックアウトします。有人ステーションには安全のための機能も用意されています。信頼できる引き取り者の確認、保護者へのページング(テキストメッセージ送信)、セキュリティラベルの再印刷、緊急一斉連絡です。

</div>

<div class="prereqs">
<h4>始める前に</h4>

- チェックアウトは、キオスクの管理設定で **有人** モードに設定されたステーションで利用できます
- お子さまは、セキュリティコードが印刷された引き取り用ラベルを付けて [チェックイン](./completing-checkin.md) している必要があります
- ページングと緊急一斉連絡には、B1 Admin で教会のテキスト送信プロバイダーが接続されている必要があります

</div>

## チェックアウトを開始する

1. 有人ステーションで、検索画面の **Check Out** をタップします。
2. ご家族の引き取り用ラベルに記載されている4文字の **セキュリティコード** を入力します。手入力のほか、画面上のキーパッドを使うこともできます。USB または Bluetooth のスキャナーでラベルのバーコードを読み取ることもできます。4文字すべて入力されると、コードは自動的に送信されます。
   - スキャナーがない場合は、コード欄の下にある **Scan** をタップすると、タブレットのカメラを使えます。**Scan pickup code** の画面で引き取り用ラベルの QR コードまたはバーコードをカメラにかざすと、コードが自動入力されます。既定では背面カメラが使われます。切り替えボタンをタップするとカメラを変更でき、**Cancel** をタップすると手入力に戻れます。
3. キオスクに、そのコードでチェックインしているお子さまの一覧が表示されます。

## 引き取りに来た人を確認する

チェックアウト画面では、お子さまを引き取りに来た人を確認します。

- そのご家庭の **信頼できる引き取り者** は、写真と続柄を添えたカードで表示されます。目の前にいる人のカードをタップしてください。
- **世帯の成人** も写真のグリッドで表示されます。
- **Other** を選ぶと、一覧にない人の名前を入力できます。

入力された名前が、そのご家庭で **Not Authorized**(引き取り不可)に設定されている人と一致した場合、キオスクは警告を表示してチェックアウトを止めます。スタッフは **Override**(上書き)を選ぶと、そのままチェックアウトを続行できます。上書きした記録は、その人の名前とともに出席記録に残ります。

引き取り者が確認できたら、チェックアウトをタップします。引き取り者の名前は出席記録に保存されます。

:::info
信頼できる引き取り者と引き取り不可の人は、教会スタッフが B1 Admin の各人物のページで管理します。詳しくは [チェックインの安全対策](../../b1-admin/attendance/checkin-safety.md#trusted-and-not-authorized-pickup-people) をご覧ください。
:::

## 保護者にページングする

礼拝中に保護者を呼び出したい場合があります。おむつ交換が必要なときや、お子さまが泣いているときなどです。有人ステーションのチェックアウト画面から、スタッフは **ページ** を送信できます。ページは、教会のテキスト送信プロバイダーを通じて、お子さまの保護者や後見人に届くテキストメッセージです。テキストの受信を停止している人や、携帯電話番号が登録されていない人には送信されません。キオスクには送信された件数が表示されます。

## ラベルを再印刷する

ネームタグや引き取り用ラベルをなくしたり破損したりした場合、有人ステーションのスタッフは、セキュリティコードを入力したうえで、チェックアウト画面からご家族のラベルを **再印刷** できます。再印刷には、チェックイン時と同じプリンターとラベルテンプレートが使われます。

## 緊急一斉連絡

緊急時には、スタッフが現在の礼拝に **チェックイン中のすべてのお子さま** の保護者に、まとめてテキストを送信できます。

1. キオスクの **管理設定** を開きます(ヘッダーのロゴを素早く7回タップします。PIN が設定されている場合は、その入力も必要です)。
2. **Emergency broadcast**(緊急一斉連絡)をタップします。
3. メッセージを入力し、確認欄に **EMERGENCY** と入力します。入力するまで **Send broadcast**(一斉送信)ボタンは無効のままです。
4. キオスクには、メッセージを受信した端末の台数と、スキップされた人数(受信停止または携帯電話番号なし)が表示されます。

:::warning
一斉連絡は、選択した礼拝にチェックインしているすべてのご家庭に送信されます。避難、施錠、悪天候など、本当に緊急の場合にのみ使用してください。
:::
