# Profil

<div class="article-intro">

Razdelek Profil vam omogoča upravljanje osebnih nastavitev računa v ChurchApps. Vaš profil je skupen vsem orodjem ChurchApps, zato se spremembe, ki jih tukaj naredite, uveljavijo povsod -- od B1 Admin do aplikacije B1 Mobile.

</div>

## Kaj lahko počnete

V razdelku Profil lahko:

- **Posodobite ime in e-poštni naslov** -- Ohranite svoje kontaktne podatke posodobljene.
- **Spremenite geslo** -- Nastavite novo geslo za svoj račun.
- **Vklopite dvostopenjsko prijavo** -- Zahtevajte kodo iz aplikacije za overjanje ob prijavi. Glejte [Dvostopenjska prijava](./managing-profile.md#two-factor-sign-in).
- **Preklapljate teme** -- Preklopite med svetlim in temnim načinom v uporabniškem meniju (kliknite svojo profilno sliko v zgornjem desnem kotu).
- **Upravljate povezane naprave** -- Oglejte si in nadzirajte, katere naprave ChurchAppsPlayer so povezane z vašim računom.
- **Oglejte si povezane račune** -- Oglejte si in upravljajte vse zunanje storitve, povezane z vašim računom ChurchApps.
- **Odobrite zahteve za spremembo profila** -- Pregledajte in uveljavite posodobitve, ki so jih poslali člani.

## Podstrani profila

Območje Profil ima naslednje strani:

1. **[Upravljanje vašega profila](./managing-profile.md)** -- Uredite svoje osebne podatke, spremenite geslo, upravljajte povezane račune, vklopite dvostopenjsko prijavo, prilagodite nastavitve teme in urejate brisanje računa.
2. **[Odobritev sprememb profila](./approving-profile-changes.md)** -- Pregledajte in odobrite zahteve za posodobitev profila, ki so jih člani poslali prek aplikacije B1 Mobile.
3. **[Upravljanje naprav](./devices.md)** -- Oglejte si, dodajte in upravljajte naprave ChurchAppsPlayer, seznanjene z vašim računom.

:::tip
Ohranjajte svoj e-poštni naslov posodobljen. Uporablja se za obnovitev računa in pomembna obvestila vaše cerkve.
:::
