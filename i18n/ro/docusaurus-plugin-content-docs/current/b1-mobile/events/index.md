# Evenimente

<div class="article-intro">

Funcționalitatea Evenimente din B1 Mobile vă permite să răsfoiți evenimentele bisericii viitoare și să vă înscrieți direct de pe telefon. Atunci când biserica dvs. activează înscrierea pentru un eveniment, vă puteți înscrie singur și membrii familiei cu doar câteva atingeri.

</div>

## Găsirea evenimentelor cu înscriere

Evenimentele cu înscriere activată apar în calendarele grupurilor dvs. Când atingeți un eveniment la care este disponibilă înscrierea, veți vedea butonul **Înscrie-te** în detaliile evenimentului.

Evenimentele pot afișa stări diferite:

- **Deschis** -- Înscrierea este disponibilă și vă puteți înscrie.
- **Nu este încă deschis** -- Perioada de înscriere nu a început încă.
- **Închis** -- Termenul limită pentru înscriere a trecut.
- **Complet** -- Toate locurile disponibile au fost ocupate.
