# Clase

<div class="article-intro">

Las clases son la base de cómo organizas la enseñanza en tu iglesia en Lessons.church. Una clase representa un espacio físico o virtual donde se imparten las lecciones; por ejemplo, "Sala de preescolar", "Primaria K-2" o "Estudio bíblico de adultos". Esta sección cubre la creación de clases y la programación de lecciones para ellas.

</div>

## Por qué importan las clases

Cuando configuras las clases, creas una estructura clara para tu ministerio infantil, grupos juveniles o cualquier entorno de enseñanza. Cada clase tiene su propio calendario, para que tus voluntarios siempre sepan exactamente qué enseñar y cuándo. En lugar de pasar horarios en papel o enviar correos de última hora, todos pueden consultar el portal para ver qué viene.

## Qué puedes hacer con las clases

- **Crear clases ilimitadas** -- Configura tantas clases como necesite tu iglesia. No hay límite, así que puedes tener clases separadas para cada grupo de edad, sede o programa.
- **Programar lecciones** -- Asigna lecciones específicas a cada clase en fechas concretas. Tu calendario muestra de un vistazo las lecciones pasadas y las próximas.
- **Personalizar el contenido** -- Adapta el contenido de las lecciones para cada clase, de modo que los voluntarios solo vean lo relevante para su grupo de edad. Consulta [Personalización](../customization/index.md) para más detalles.

## Cómo encajan las clases

Las clases conectan el contenido de las lecciones en Lessons.church con el calendario de enseñanza real de tu iglesia. Este es el flujo de trabajo habitual:

1. [Explora](../browsing/index.md) los programas y estudios disponibles en Lessons.church.
2. Configura tus clases para que coincidan con las salas y los grupos de edad de tu iglesia.
3. Programa lecciones para cada clase en las fechas próximas.
4. Los voluntarios abren su clase para ver lo que está programado y prepararse.
