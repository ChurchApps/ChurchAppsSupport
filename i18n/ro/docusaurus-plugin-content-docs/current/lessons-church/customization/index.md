# Personalizare

<div class="article-intro">

Lessons.church oferă o bibliotecă de conținut pentru lecții gata de utilizare, dar fiecare biserică este diferită. Funcțiile de personalizare vă permit să adaptați conținutul lecțiilor la sălile de clasă, stilul de predare și grupele de vârstă specifice, astfel încât voluntarii să vadă doar ceea ce este relevant pentru ei.

</div>

## De ce să personalizați?

Conținutul lecțiilor de pe Lessons.church este conceput pentru a fi flexibil. O singură lecție poate include secțiuni pentru mai multe grupe de vârstă, activități opționale sau roluri care nu se aplică tuturor sălilor de clasă. În loc să le cereți voluntarilor să sară mental peste părțile care nu le sunt utile, puteți personaliza lecția astfel încât să vadă doar ceea ce este relevant pentru ei.

De exemplu, o lecție poate include o activitate de lucru manual potrivită pentru preșcolari, dar care nu este potrivită pentru clasa a cincea. Prin personalizare, puteți ascunde această secțiune pentru grupa mai mare, păstrând-o pentru cea mai mică.

## Ce puteți personaliza

- **Eliminarea secțiunilor** -- Ascundeți secțiuni întregi ale unei lecții care nu se aplică unei anumite săli de clasă sau grupe de vârstă.
- **Ascunderea rolurilor sau acțiunilor** -- Eliminați roluri sau acțiuni individuale dintr-o secțiune, dacă nu sunt necesare.
- **Reordonarea conținutului** -- Rearanjați secțiunile și acțiunile pentru a le potrivi fluxului pe care îl preferați în sala de clasă.

## Specific unei săli de clasă sau global

Când salvați o personalizare, alegeți cât de larg se aplică:

- **O singură sală de clasă** -- Personalizarea afectează doar sala de clasă curentă. Celelalte săli de clasă văd conținutul original.
- **Toate sălile de clasă** -- Personalizarea se aplică în fiecare sală de clasă din biserica dumneavoastră.

Această flexibilitate înseamnă că puteți configura vederi diferite ale aceleiași lecții pentru grupe de vârstă diferite sau puteți face o modificare care se aplică peste tot deodată.

:::tip
Dacă sunteți nou în personalizare, începeți cu o singură sală de clasă, pentru a vedea cum funcționează, înainte de a aplica modificările în toate sălile de clasă.
:::
