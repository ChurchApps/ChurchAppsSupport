# Gestionarea programelor

<div class="article-intro">

Programele sunt containerele de nivel superior pentru curriculum în Lessons.church. Un program reprezintă o serie completă de curriculum, de exemplu „Ark Kids” sau „Youth Foundations”. Acest ghid explică cum să creezi, să editezi și să organizezi programele în zona de administrare.

</div>

<div class="prereqs">
<h4>Înainte de a începe</h4>

- Ai nevoie de permisiuni de administrator pentru Lessons.church (vezi [Prezentarea generală a administrării](./index.md))
- Pregătește un nume de program, o descriere și o imagine de previzualizare

</div>

## Crearea unui program

1. Accesează zona **Admin**.
2. Fă clic pe **Adaugă program**.
3. Completează următoarele câmpuri:
   - **Nume** -- Numele afișat al programului (de exemplu, „Ark Kids”).
   - **Slug** -- Un identificator prietenos pentru URL (de exemplu, „ark-kids”). Acesta este folosit în adresele web.
   - **Descriere** -- Un rezumat scurt al conținutului programului.
   - **Imagine** -- Încarcă o imagine de previzualizare care reprezintă programul.
4. Salvează programul.

Noul tău program va apărea acum în lista de programe din zona de administrare și, odată ce are studii și lecții, pe site-ul public.

## Editarea unui program

1. Fă clic pe numele programului din lista de administrare.
2. Actualizează oricare dintre câmpuri (**Nume**, **Slug**, **Descriere** sau **Imagine**).
3. Salvează modificările.

## Organizarea studiilor într-un program

Odată ce un program există, poți adăuga studii la el. Studiile apar sub program în vizualizarea de administrare. Fă clic pe săgeata de extindere de lângă un program pentru a vedea studiile sale sau adaugă un studiu nou de acolo. Pentru detalii, consultă [Gestionarea studiilor](./managing-studies.md).

## Categoriile de studii

Dacă programul tău are multe studii, le poți organiza în **categorii**. Categoriile grupează studiile după subiect, grupă de vârstă sau alte criterii alese de tine. Acest lucru facilitează navigarea utilizatorilor printr-un program mare.

## Încărcarea resurselor la nivel de program

Poți atașa fișiere descărcabile unui program. Acestea sunt resurse care se aplică programului în întregime, nu unui anumit studiu sau unei anumite lecții, de exemplu un document cu scopul și succesiunea conținutului sau un manual pentru voluntari.

1. Deschide programul în vizualizarea de administrare.
2. Accesează secțiunea **Resurse**.
3. Încarcă fișierele.

## Golirea memoriei cache

După ce faci modificări la un program, s-ar putea să fie nevoie să golești memoria cache, astfel încât actualizările să apară pe site-ul public. Folosește opțiunea **Golește memoria cache** din zona de administrare pentru a reîmprospăta conținutul.

:::tip
Alege un nume descriptiv pentru program și scrie o descriere clară. Aceasta este prima informație pe care o văd bisericile când răsfoiesc biblioteca de curriculum, așa că un rezumat bun le ajută să decidă dacă programul corespunde nevoilor lor.
:::
