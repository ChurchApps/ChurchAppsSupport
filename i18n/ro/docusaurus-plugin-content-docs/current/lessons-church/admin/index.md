# Administrare

<div class="article-intro">

Zona de administrare din Lessons.church este locul în care creatorii de conținut și administratorii gestionează biblioteca de lecții. De aici puteți construi structura curriculară, încărca resurse, consulta statisticile de utilizare și conecta furnizori externi de conținut.

</div>

:::warning
Accesul la administrare necesită permisiunile corespunzătoare. Dacă nu vedeți opțiunile de administrare, contactați administratorul bisericii pentru a solicita acces.
:::

## Ce puteți face

Zona de administrare vă oferă control deplin asupra conținutului:

- **Creați și editați programe** -- Configurați serii curriculare de nivel superior, cu nume, descrieri, imagini și sluguri.
- **Gestionați studiile** -- Organizați grupuri de lecții conexe în cadrul fiecărui program.
- **Construiți lecții** -- Adăugați lecții individuale cu variante, secțiuni, roluri și acțiuni.
- **Încărcați resurse** -- Atașați fișiere descărcabile (PDF-uri, fișe de activități, imagini) la nivel de program, studiu sau lecție.
- **Vizualizați statisticile** -- Aflați ce conținut este descărcat, de către cine și de unde.
- **Configurați furnizorii** -- Conectați furnizori externi de materiale curriculare care utilizează Open Lesson Format. Acest lucru se face din pagina **Furnizori externi**, nu din zona de administrare.
- **Planuri anuale** -- Publicați secvențe de săptămâna 1, 2, 3… pentru orice curriculum. Bisericile le aplică în B1 Admin.

## Ierarhia conținutului

Ca administrator, este util să înțelegeți cum este structurat conținutul:

1. **Programele** conțin unul sau mai multe studii.
2. **Studiile** conțin una sau mai multe lecții.
3. **Lecțiile** conțin una sau mai multe variante (adaptări pentru grupe de vârstă).
4. **Variantele** conțin secțiuni, iar secțiunile conțin acțiuni pe bază de roluri.

Fiecare nivel poate avea propriile resurse descărcabile atașate.
