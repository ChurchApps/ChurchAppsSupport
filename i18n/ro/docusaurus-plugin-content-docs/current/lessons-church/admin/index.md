# Administrare

<div class="article-intro">

Zona de administrare din Lessons.church este locul în care creatorii de conținut și administratorii gestionează biblioteca de lecții. De aici puteți construi structura programei, încărca resurse, consulta statisticile de utilizare și conecta furnizori externi de conținut.

</div>

:::warning
Accesul la administrare necesită permisiunile corespunzătoare. Dacă nu vedeți opțiunile de administrare, contactați administratorul bisericii pentru a solicita acces.
:::

## Ce puteți face

Zona de administrare vă oferă control deplin asupra conținutului:

- **Creați și editați programe** -- Configurați serii curriculare de nivel superior, cu nume, descrieri, imagini și slug-uri.
- **Gestionați studiile** -- Organizați grupuri de lecții conexe în cadrul fiecărui program.
- **Construiți lecții** -- Adăugați lecții individuale cu variante, secțiuni, roluri și acțiuni.
- **Încărcați resurse** -- Atașați fișiere descărcabile (PDF-uri, fișe de activități, imagini) la nivelul programului, al studiului sau al lecției.
- **Vizualizați statisticile** -- Vedeți ce conținut este descărcat, de către cine și de unde.
- **Configurați furnizorii** -- Conectați furnizori externi de programe care utilizează Open Lesson Format.
- **Planuri anuale** -- Publicați secvențe pentru săptămânile 1, 2, 3… pentru orice programă. Bisericile le aplică în B1 Admin.

## Structura conținutului

Ca administrator, este util să înțelegeți cum este structurat conținutul:

1. **Programele** conțin unul sau mai multe studii.
2. **Studiile** conțin una sau mai multe lecții.
3. **Lecțiile** conțin una sau mai multe variante (adaptări pentru grupe de vârstă).
4. **Variantele** conțin secțiuni, iar secțiunile conțin acțiuni pe roluri.

Fiecare nivel poate avea propriile resurse descărcabile atașate.
