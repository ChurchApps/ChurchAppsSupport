# Modul Plan

<div class="article-intro">

Modul Plan conectează televizorul la un plan de slujbă al bisericii. În loc să extragă conținutul pe baza unui program de clasă, urmează planul configurat de conducerea bisericii în B1 Admin. Este ideal atunci când vrei ca un televizor să afișeze exact ce este atribuit în planul săptămânii curente.

</div>

## Cum diferă de celelalte moduri

- **[Modul programat](../scheduled-mode/)** redă liste de redare dintr-un calendar din FreePlay Admin, la orele pe care le setezi, fără ca cineva să apese Start
- **Modul Plan** preia conținutul asociat unui tip de plan, care poate include lecții, prezentări ale furnizorilor, suplimente și alte materiale media aranjate într-o ordine personalizată

Modul Plan este util în mod deosebit atunci când planul tău de slujbă include un amestec de conținut din surse diferite, toate organizate într-o singură secvență.

:::tip
Vrei ca planul curent să se redea singur la o oră stabilită? În FreePlay Admin, adaugă o intrare în calendar și alege tipul de plan sub **Planuri de slujbă**. Vezi [Programarea calendarului](../scheduled-mode/scheduling-the-calendar).
:::

## Cum funcționează

1. Pe televizor, deschide **Setări** > **Asociază cu un calendar** pentru a afișa un cod de asociere
2. Un administrator introduce acest cod în **B1 Admin** și alege tipul de plan sub **Afișează planurile pentru**
3. Odată asociat, FreePlay încarcă planul curent și descarcă toate materialele media asociate
4. Apasă **Pornește planul** pentru a începe redarea

Televizorul rămâne asociat cu tipul de plan. În fiecare săptămână, preia automat cel mai recent plan și conținutul acestuia.
