# Transmisiuni live

<div class="article-intro">

Pagina Transmisiune live vă permite să urmăriți serviciile bisericii dumneavoastră pe măsură ce au loc, direct de pe B1.church. Când biserica dumneavoastră transmite, vă puteți conecta și participa folosind funcțiile interactive alături de videoclip.

</div>

<div class="prereqs">
<h4>Înainte de a începe</h4>

- Nu este necesară autentificarea pentru a urmări o transmisiune live. Pagina Stream este accesibilă public.
- Biserica dumneavoastră trebuie să aibă configurat un program de transmisiune. Verificați orele serviciilor bisericii pentru a vedea când sunt disponibile transmisiunile live.

</div>

## Urmărirea unei transmisiuni live

1. Accesați pagina **Stream** din meniul de navigare al site-ului bisericii dumneavoastră.
2. Dacă un serviciu este în desfășurare sau urmează să înceapă, player-ul video se va încărca automat.
3. Urmăriți transmisiunea direct pe pagină.

Când nu există o transmisiune live activă, este posibil să vedeți conținut offline sau informații despre următorul serviciu programat.

## Funcții interactive

Pagina de transmisiune live poate include file interactive alături de videoclip, în funcție de ce a configurat biserica dumneavoastră. Acestea pot include:

- **Chat** -- Trimiteți mesaje și interacționați cu alți spectatori în timpul transmisiunii. Chat-ul este de obicei activat cu câteva minute înainte de începerea serviciului și rămâne disponibil o perioadă după încheierea acestuia. Puteți participa la chat fără autentificare -- alegeți doar un nume afișat atunci când vi se solicită.
- **File suplimentare** -- Biserica dumneavoastră poate adăuga file personalizate cu linkuri către buletine, note de predică, [pagini de donații](../giving/making-donations.md) sau alte resurse.

Faceți clic pe pictogramele sau etichetele filelor pentru a comuta între funcțiile disponibile în timpul urmăririi.

## Înainte și după serviciu

Biserica dumneavoastră stabilește ore specifice la care transmisiunea și funcțiile interactive devin disponibile. Este posibil să puteți intra în chat înainte ca serviciul să înceapă oficial, ceea ce vă oferă timp să îi salutați pe ceilalți. După încheierea serviciului, chat-ul poate rămâne deschis o scurtă perioadă pentru conversații continue.

:::info
Dacă pagina de transmisiune afișează conținut offline sau un numărător inversat, următorul serviciu programat nu a început încă. Reveniți la ora serviciului indicată.
:::

:::tip
Căutați o predică înregistrată pe care ați ratat-o? Accesați pagina [Predici](./sermons.md) pentru a vedea mesajele anterioare ale bisericii dumneavoastră.
:::

## Disponibilitate

Pagina Transmisiune live este disponibilă atunci când biserica dumneavoastră a configurat un program de transmisiune. Dacă nu vedeți un link **Stream** în meniul de navigare, este posibil ca biserica dumneavoastră să nu aibă configurată transmisiunea live. Contactați administratorul bisericii pentru detalii.
