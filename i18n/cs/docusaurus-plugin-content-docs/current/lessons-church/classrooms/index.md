# Klassenzimmer

<div class="article-intro">

Klassenzimmer bilden die Grundlage für die Organisation des Unterrichts in Ihrer Gemeinde in Lessons.church. Ein Klassenzimmer steht für einen physischen oder virtuellen Raum, in dem Lektionen unterrichtet werden, zum Beispiel „Vorschulraum“, „Grundschule 1.–2. Klasse“ oder „Erwachsenen-Bibelstunde“. Dieser Abschnitt behandelt das Anlegen von Klassenzimmern und das Planen von Lektionen für diese Räume.

</div>

## Warum Klassenzimmer wichtig sind

Wenn Sie Klassenzimmer einrichten, schaffen Sie eine klare Struktur für Ihre Kinderarbeit, Jugendgruppen oder jede andere Lernumgebung. Jedes Klassenzimmer erhält einen eigenen Zeitplan, sodass Ihre Ehrenamtlichen immer genau wissen, was sie wann unterrichten sollen. Statt Papierpläne weiterzureichen oder kurzfristige E-Mails zu verschicken, kann jeder im Portal nachsehen, was ansteht.

## Was Sie mit Klassenzimmern tun können

- **Unbegrenzt viele Klassenzimmer anlegen** -- Richten Sie so viele Klassenzimmer ein, wie Ihre Gemeinde benötigt. Es gibt keine Begrenzung, sodass Sie für jede Altersgruppe, jeden Standort oder jedes Programm eigene Klassenzimmer haben können.
- **Lektionen planen** -- Weisen Sie jedem Klassenzimmer an bestimmten Terminen bestimmte Lektionen zu. Ihr Zeitplan zeigt vergangene und kommende Lektionen auf einen Blick.
- **Inhalte anpassen** -- Passen Sie die Lektionsinhalte für jedes Klassenzimmer an, damit Ehrenamtliche nur das sehen, was für ihre Altersgruppe relevant ist. Details finden Sie unter [Anpassung](../customization/index.md).

## Wie Klassenzimmer zusammenpassen

Klassenzimmer verbinden die Lektionsinhalte auf Lessons.church mit dem tatsächlichen Unterrichtsplan Ihrer Gemeinde. Der typische Ablauf sieht so aus:

1. Stöbern Sie in den verfügbaren Programmen und Studien auf Lessons.church, [siehe Durchsuchen](../browsing/index.md).
2. Richten Sie Ihre Klassenzimmer so ein, dass sie den Räumen und Altersgruppen Ihrer Gemeinde entsprechen.
3. Planen Sie Lektionen für die kommenden Termine in jedem Klassenzimmer ein.
4. Ehrenamtliche öffnen ihr Klassenzimmer, um zu sehen, was geplant ist, und sich vorzubereiten.
