# Začínáme

<div class="article-intro">

Lessons.church je zcela zdarma. Nejsou zde žádná předplatná, zkušební období ani omezení funkcí. Tato část vás provede vytvořením účtu, připojením vaší církve a orientací v portálu, abyste mohli hned začít plánovat lekce.

</div>

## Co potřebujete

Abyste mohli začít s Lessons.church, budete potřebovat:

1. **Vytvořit účet** -- Zaregistrujte se na [Lessons.church](https://lessons.church) pomocí svého jména, e-mailu a hesla. Použijete stejný účet ChurchApps, který můžete již mít z B1.church.
2. **Připojit svou církev** -- Po registraci se připojte ke svému existujícímu profilu církve nebo vytvořte nový. Tím propojíte své třídy a rozvrhy s vaší církví.
3. **Nastavit třídy** -- Vytvořte třídy odpovídající vaší službě (například „Předškoláci", „1.–3. třída" nebo „Mládež"). Třídy slouží k plánování a organizaci lekcí.
4. **Začít plánovat lekce** -- Prohlédněte si knihovnu obsahu, najděte studium, které odpovídá vašim potřebám, a naplánujte lekce do svých tříd.

Jakmile budou vaše třídy nastaveny a lekce naplánovány, mohou dobrovolníci přistupovat k obsahu prostřednictvím portálu a předávat lekce svým třídám.

:::tip
Pokud již máte účet ChurchApps z B1.church, můžete se přihlásit na Lessons.church pomocí stejných přihlašovacích údajů -- není třeba se znovu registrovat.
:::
