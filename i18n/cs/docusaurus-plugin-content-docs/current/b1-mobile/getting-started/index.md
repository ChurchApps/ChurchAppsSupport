# Začínáme

:::danger B1 Mobile je zastaralý
Nativní aplikace B1 Mobile byla nahrazena [progresivní webovou aplikací (PWA) B1.church](../../b1-church/getting-started/installing-pwa.md). Noví uživatelé by měli nainstalovat PWA z libovolné stránky na `https://yourchurchname.b1.church` namísto stahování B1 Mobile z App Store nebo Google Play.
:::

<div class="article-intro">

Začít s aplikací B1 Mobile zabere jen pár minut. Stáhněte si aplikaci, přihlaste se pomocí svého účtu ChurchApps, vyberte svůj sbor a můžete začít.

</div>

## Rychlý start

1. **Stáhněte** aplikaci z [App Store](https://apps.apple.com) (iOS) nebo z [Google Play Store](https://play.google.com) (Android). Vyhledejte „B1.church“.
2. **Přihlaste se** pomocí svého stávajícího účtu ChurchApps -- stejného e-mailu a hesla, které používáte na B1.church. Pokud účet ještě nemáte, klepněte na **Registrovat** a vytvořte si ho.
3. **Vyberte svůj sbor** vyhledáním podle názvu. Pro zobrazení výsledků zadejte alespoň 3 znaky.
4. **Prozkoumejte přehled** -- vaše přizpůsobená domovská obrazovka zobrazuje rychlé odkazy na funkce, které váš sbor nabízí.

To je vše. Jakmile vyberete svůj sbor, aplikace načte jeho branding, navigační odkazy a obsah. Můžete začít používat skupiny, dary, check-in a všechno ostatní, co má váš sbor zapnuté.
