# Een scherm koppelen

<div class="article-intro">

Om een tv aan een agenda te koppelen, koppel je hem aan **FreePlay Admin**. De tv toont een code van vier letters. Die code voer je in op [admin.freeplay.church](https://admin.freeplay.church) en je kiest de schermgroep waarvan de agenda moet worden gevolgd. Dit doe je maar één keer per tv.

</div>

<div class="prereqs">
<h4>Voordat je begint</h4>

- Installeer FreePlay op de tv en start de app. Zie [Aan de slag](../getting-started/index.md)
- Zorg dat je een ChurchApps-account voor je kerk hebt, zodat je kunt inloggen op FreePlay Admin
- Optioneel: [maak eerst een afspeellijst](./building-playlists.md) en [plan deze in](./scheduling-the-calendar.md), zodat de tv meteen iets kan afspelen

</div>

## De code op de tv tonen

1. Open op de tv **Instellingen** onderaan de zijbalk.
2. Selecteer **Koppelen aan een agenda**. In die rij staat **Niet gekoppeld** zolang de tv nog niet is gekoppeld.
3. Op het scherm **Dit scherm koppelen** zie je een QR-code en een koppelcode van vier letters, met de melding **Scan met je telefoon, of ga naar freeplay.church/pair en voer deze code in**.
4. Onder de code knippert **Wachten op bevestiging** zolang FreePlay wacht tot jij het koppelen hebt afgerond.

De code is 15 minuten geldig. Een aftelklok onder de code laat zien hoeveel tijd er nog over is. Wanneer de tijd om is, toont FreePlay automatisch een nieuwe code. Je kunt ook **Nieuwe code genereren** selecteren voor een nieuwe code, of **Annuleren** selecteren om terug te gaan naar Instellingen.

## Koppelen in FreePlay Admin

1. Scan de QR-code met je telefoon, of ga op een willekeurige computer of telefoon naar **freeplay.church/pair**. Log in als daarom wordt gevraagd. FreePlay Admin opent het formulier **Scherm koppelen** met de code al ingevuld.
   - Je kunt het formulier ook zelf openen. Ga in FreePlay Admin naar **Schermen** en klik op **Scherm koppelen**.
2. Controleer de **Koppelcode**. Dit zijn de vier letters op de tv.
3. Vul een **Label** in zodat je deze tv van de andere kunt onderscheiden, bijvoorbeeld „Lobby links“. Dit is optioneel.
4. Kies onder **Groep** de schermgroep waarvan de agenda deze tv moet volgen. Om een nieuwe groep te maken, kies je **＋ Nieuwe groep…** en vul je een **Nieuwe groepsnaam** in.
5. Laat onder **Modus** de optie **Gepland** geselecteerd. De tv speelt dan zelfstandig af volgens de agenda van de groep.
6. Klik op **Koppelen**.

De tv toont **Verbonden!** en daarna **Je agenda wordt geladen...**. Hij downloadt wat is ingepland en begint met afspelen. Zie [Gepland afspelen op de tv](./scheduled-playback.md).

:::info
Als FreePlay Admin meldt dat **Die code past bij geen enkele tv**, controleer dan de code op het scherm. Als de code is verlopen, gebruik dan de nieuwe code die de tv nu toont.
:::

### Gepland of handmatig

De instelling **Modus** heeft twee opties:

- **Gepland** - Speelt zelfstandig af volgens de agenda van de groep. Niemand hoeft op Start te drukken.
- **Handmatig** - Iemand kiest inhoud met de afstandsbediening. Een handmatig scherm verschijnt wel in je lijst **Schermen**, maar het volgt geen agenda, dus het veld **Groep** is uitgeschakeld.

Je kunt de modus van een scherm later wijzigen via **Bewerken** op de [pagina Schermen](./managing-screens.md).

## In plaats daarvan koppelen aan een dienstplan

De code op het scherm **Dit scherm koppelen** werkt ook in B1 Admin. Als je die code daar invoert en onder **Plannen tonen voor** een plantype kiest, volgt de tv dat plantype in de [Planmodus](../plan-mode/index.md) in plaats van een agenda. Zie [Je apparaat koppelen](../plan-mode/device-pairing.md).

## Koppeling wijzigen of opheffen op de tv

Zodra de tv is gekoppeld, toont de rij **Koppelen aan een agenda** in **Instellingen** de naam van de schermgroep die hij volgt. Selecteer de rij om het dialoogvenster **Gekoppeld aan** te openen. Daarin staan drie opties:

- **Terug naar planning** - Sluit het dialoogvenster en ga terug naar de geplande speler. Er verandert niets aan de koppeling.
- **Koppeling opheffen** - Stop met het volgen van een agenda. FreePlay opent het scherm **Contentaanbieders**.
- **Koppelen aan een andere agenda** - Hef de koppeling op en toon daarna een nieuwe koppelcode, zodat je de tv opnieuw kunt koppelen.

:::warning
Als je de koppeling opheft, worden de bestanden verwijderd die FreePlay voor die agenda heeft gedownload.
:::

## Koppeling opheffen in FreePlay Admin

1. Ga naar **Schermen** en klik op het label van het scherm.
2. Klik op **Meer** en daarna op **Koppeling opheffen**.
3. Klik nogmaals op **Koppeling opheffen** om te bevestigen.

De tv toont weer een koppelcode. Koppel hem opnieuw wanneer je dat wilt.
