# Підключення пристрою

<div class="article-intro">

Щоб використовувати режим плану, ви підключаєте свій телевізор до типу плану в B1 Admin. FreePlay показує на телевізорі короткий код підключення. Ви вводите цей код у B1 Admin і вибираєте тип плану, за яким слід іти, а телевізор щотижня автоматично отримує вміст цього плану.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Встановіть і запустіть FreePlay. Див. [Початок роботи](../getting-started/index.md)
- Маєте доступ до **B1 Admin** на комп'ютері або телефоні, щоб завершити підключення

</div>

## Створення коду підключення

1. На телевізорі відкрийте **Налаштування** внизу бічної панелі.
2. Виберіть **Підключити до календаря**.
3. FreePlay показує великими літерами чотирилітерний код підключення поруч із QR-кодом.
4. Під кодом блимаючий індикатор **Очікування підтвердження** показує, що FreePlay чекає, поки ви завершите підключення.

Той самий код працює для [Режиму за розкладом](../scheduled-mode/index.md) у FreePlay Admin і для режиму плану в B1 Admin. QR-код і адреса **freeplay.church/pair** на екрані відкривають FreePlay Admin. Для режиму плану ігноруйте їх і введіть код у B1 Admin, як описано нижче.

## Введення коду в B1 Admin

1. У B1 Admin перейдіть до **Профіль** > **Пристрої** і натисніть **Додати екран**.
2. Введіть чотири літери з телевізора в поле **Код підключення**.
3. У розділі **Показувати плани для** виберіть тип плану, за яким має йти цей екран, наприклад «Недільне служіння».
4. Збережіть зміни.

FreePlay кожні кілька секунд перевіряє, чи завершено підключення. Щойно B1 Admin його підтверджує, на телевізорі з'являється напис **Підключено!**, і він переходить на екран завантаження плану.

## Завантаження вмісту плану

Після підключення FreePlay завантажує поточний план для цього типу плану. На екрані відображається:

- Назва плану та дата служіння
- Назва уроку, якщо план містить матеріали уроку
- Індикатор ходу роботи з написом **Завантаження елемента X з Y**

Коли всі медіафайли завантажено, з'являється кнопка **Почати план**. Натисніть **Вибрати** на пульті, щоб почати відтворення.

:::tip
План оновлюється автоматично щогодини. Якщо хтось оновить план упродовж дня, FreePlay підхопить зміни самостійно.
:::

## Якщо підключення не вдалося

Якщо FreePlay не може створити код підключення (наприклад, через проблеми з мережею), ви побачите повідомлення про помилку з кнопкою **Спробувати знову**. Переконайтеся, що телевізор підключено до інтернету, і спробуйте ще раз.

:::warning
Коди підключення спливають через 15 хвилин. Коли старий код закінчується, FreePlay сам показує новий, а **Створити новий код** можна вибрати будь-коли. Якщо введений вами код не працює, використовуйте той, що зараз показано на телевізорі.
:::
