# Матеріали для завантаження

<div class="article-intro">

Уроки на Lessons.church супроводжуються ресурсами для завантаження, які можна роздрукувати або поширити в цифровому вигляді. Ці матеріали доповнюють зміст уроку та дають вашим волонтерам і учням щось відчутне для роботи під час і після заняття.

</div>

</div>

## Типи матеріалів

Залежно від уроку та постачальника ви можете знайти такі ресурси:

- **Робочі аркуші** -- Практичні завдання, які учні виконують під час заняття.
- **Розмальовки** -- Сторінки для друку для молодших вікових груп.
- **Посібники для керівника** -- Детальні інструкції та довідкова інформація для вчителів.
- **Додаткові PDF-файли** -- Додаткові матеріали для читання, листівки для дому або роздаткові матеріали для батьків.

Не кожен урок містить усі ці матеріали. Доступні ресурси залежать від того, що надав постачальник контенту.

## Де знайти матеріали для завантаження

Ресурси доступні на трьох рівнях:

- **Рівень програми** -- Загальні ресурси, які стосуються всієї навчальної серії.
- **Рівень дослідження** -- Матеріали, пов'язані з конкретним вивченням у межах програми.
- **Рівень уроку** -- Ресурси для окремого уроку.

Щоб завантажити матеріали:

1. Перейдіть на сторінку уроку, дослідження або програми.
2. Знайдіть розділ **Downloads** або **Resources** на сторінці.
3. Натисніть назву файлу, щоб завантажити його на свій пристрій.

Файли зазвичай мають формат PDF і готові до друку.

## Підготовка до заняття

Гарною практикою є перевіряти наявність матеріалів для завантаження за кілька днів до заняття:

1. Відкрийте майбутній урок і перегляньте доступні завантаження.
2. Роздрукуйте достатню кількість робочих аркушів і розмальовок для очікуваної кількості відвідувачів.
3. Перегляньте посібник для керівника, щоб ознайомитися з ходом уроку.
4. Відкладіть матеріали для дому, щоб роздати їх наприкінці заняття.

:::info
Деякі постачальники розміщують усі свої матеріали на рівні дослідження, а не прикріплюють їх до окремих уроків. Якщо ви не бачите завантажень на сторінці конкретного уроку, перевірте сторінку батьківського дослідження або програми.
:::

:::tip
Створіть для своїх волонтерів щотижневий контрольний список, який включає завантаження та друк матеріалів. Це гарантує, що нічого не буде забуто до недільного ранку.
:::
