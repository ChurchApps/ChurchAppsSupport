# Керування вивченнями

<div class="article-intro">

Вивчення — це серія пов’язаних між собою уроків у межах програми. Наприклад, серія з чотирьох тижнів під назвою «Милосердний самарянин» була б вивченням у складі більшої програми дитячого служіння. Цей посібник пояснює, як створювати, редагувати та впорядковувати вивчення в адміністративному розділі.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- [Створіть принаймні одну програму](./managing-programs.md) в адміністративному розділі
- Мати права адміністратора для Lessons.church (див. [Огляд адміністрування](./index.md))

</div>

## Створення вивчення

1. Перейдіть до розділу **Admin** і розгорніть програму, до якої хочете додати вивчення.
2. Натисніть **Add Study**.
3. Заповніть такі поля:
   - **Name** -- Назва вивчення, яка відображатиметься користувачам (наприклад, «Милосердний самарянин»).
   - **Slug** -- Зручний для URL ідентифікатор (наприклад, "the-good-samaritan").
   - **Description** -- Короткий опис того, що охоплює вивчення, і скільки уроків воно містить.
   - **Image** -- Завантажте мініатюру для вивчення.
4. Збережіть вивчення.

## Редагування вивчення

1. Натисніть назву вивчення у списку адміністратора.
2. За потреби змініть будь-які поля.
3. Збережіть зміни.

## Призначення категорії

Якщо батьківська програма використовує категорії вивчень, ви можете призначити до них своє вивчення:

1. Відкрийте вивчення в адміністративному перегляді.
2. Виберіть **Category** у випадаючому списку.
3. Збережіть.

Категорії допомагають користувачам переглядати програми з великою кількістю вивчень. Наприклад, можна створити категорії «Старий Заповіт», «Новий Заповіт» і «Тематичні».

## Керування уроками у межах вивчення

Вивчення містять один або більше уроків. Розгорніть вивчення в адміністративному перегляді, щоб побачити його уроки, або натисніть **Add Lesson**, щоб створити новий. Докладніше про наповнення уроків читайте в розділі [Керування уроками](./managing-lessons.md).

## Завантаження ресурсів на рівні вивчення

Ви можете прикріпити файли для завантаження, які стосуються всього вивчення, наприклад огляд серії, промографіку або шаблон листа для батьків.

1. Відкрийте вивчення в адміністративному перегляді.
2. Перейдіть до розділу **Resources**.
3. Завантажте файли.

:::tip
Пишіть опис вивчення, маючи на увазі церковних лідерів. Чіткий короткий опис теми, цільової вікової групи та кількості уроків допомагає церквам вирішити, чи використовувати цю серію.
:::
