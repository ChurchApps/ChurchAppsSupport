# Адміністрування

<div class="article-intro">

Адміністративна зона Lessons.church призначена для авторів контенту та адміністраторів, які керують бібліотекою уроків. Звідси ви можете створювати структуру навчальної програми, завантажувати ресурси, переглядати статистику використання та підключати сторонніх постачальників контенту.

</div>

:::warning
Для доступу до адміністративної зони потрібні відповідні дозволи. Якщо ви не бачите адміністративних опцій, зверніться до адміністратора вашої церкви, щоб отримати доступ.
:::

## Що можна робити

Адміністративна зона дає вам повний контроль над вашим контентом:

- **Створювати та редагувати програми** -- Налаштовувати навчальні серії верхнього рівня з назвами, описами, зображеннями та slug.
- **Керувати дослідженнями** -- Упорядковувати групи пов'язаних уроків у межах кожної програми.
- **Створювати уроки** -- Додавати окремі уроки з варіантами для вікових груп, розділами, ролями та діями.
- **Завантажувати ресурси** -- Прикріплювати файли для завантаження (PDF, робочі аркуші, зображення) на рівні програми, дослідження або уроку.
- **Переглядати статистику** -- Дізнаватися, який контент завантажують, ким і де.
- **Налаштовувати постачальників** -- Підключати зовнішніх постачальників навчальних матеріалів, які використовують Open Lesson Format. Це робиться на сторінці **Зовнішні постачальники**, а не в адміністративній зоні.
- **Річні плани** -- Публікувати послідовності «тиждень 1, 2, 3…» для будь-якої навчальної програми. Церкви застосовують їх у B1 Admin.

## Структура контенту

Як адміністратору, вам корисно розуміти, як упорядковано контент:

1. **Програми** містять одне або кілька досліджень.
2. **Дослідження** містять один або кілька уроків.
3. **Уроки** містять один або кілька варіантів (адаптації для різних вікових груп).
4. **Варіанти** містять розділи, а розділи містять дії, призначені для ролей.

Кожен рівень може мати власні ресурси для завантаження.
