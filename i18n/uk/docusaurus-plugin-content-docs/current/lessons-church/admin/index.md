# Адміністрування

<div class="article-intro">

Адміністративна зона в Lessons.church — це місце, де творці контенту та адміністратори керують бібліотекою уроків. Звідси можна створювати структуру навчальної програми, завантажувати матеріали, переглядати статистику використання та підключати сторонніх постачальників контенту.

</div>

:::warning
Для доступу до адміністрування потрібні відповідні дозволи. Якщо ви не бачите параметрів адміністрування, зверніться до адміністратора вашої церкви, щоб отримати доступ.
:::

## Що можна робити

Адміністративна зона дає повний контроль над вашим контентом:

- **Створювати та редагувати програми** -- Налаштовувати верхньорівневі навчальні серії з назвами, описами, зображеннями та slug-ами.
- **Керувати дослідженнями** -- Упорядковувати групи пов'язаних уроків у межах кожної програми.
- **Створювати уроки** -- Додавати окремі уроки з варіантами для вікових груп, розділами, ролями та діями.
- **Завантажувати матеріали** -- Прикріплювати файли для завантаження (PDF, робочі аркуші, зображення) на рівні програми, дослідження або уроку.
- **Переглядати статистику** -- Дивитися, який контент завантажують, ким і звідки.
- **Налаштовувати постачальників** -- Підключати зовнішніх постачальників навчальних програм, які використовують формат Open Lesson Format.
- **Річні плани** -- Публікувати послідовності «тиждень 1, 2, 3…» для будь-якої навчальної програми. Церкви застосовують їх у B1 Admin.

## Структура контенту

Як адміністратору, вам корисно розуміти, як влаштований контент:

1. **Програми** містять одне або кілька досліджень.
2. **Дослідження** містять один або кілька уроків.
3. **Уроки** містять один або кілька варіантів (відмінності для вікових груп).
4. **Варіанти** містять розділи, а розділи містять дії, прив'язані до ролей.

Кожен рівень може мати власні матеріали для завантаження.
