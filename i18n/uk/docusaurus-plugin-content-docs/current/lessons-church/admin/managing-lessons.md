# Керування уроками

<div class="article-intro">

Уроки -- це окремі навчальні заняття в межах курсу. Кожен урок відповідає тому, що відбувається під час одного заняття. Тут ви створюєте детальний зміст -- місця проведення, розділи, ролі та дії -- яким користуватимуться волонтери під час викладання.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Маєте права адміністратора для Lessons.church (див. [Огляд адміністрування](./index.md))

## Створення уроку

1. Перейдіть до розділу **Admin**, розгорніть програму та вивчення і знайдіть вивчення, до якого хочете додати урок.
2. Натисніть **Add Lesson**.
3. Введіть **Name** та інші відомості про урок.
4. Збережіть урок.

## Домашній матеріал для батьків

Кожен урок має необов'язковий розділ **Parent take-home** у межах опису. Ці поля бачать батьки у своїй групі B1 після заняття (а також на сторінці для батьків у класі). Це не другий опис уроку.

| Поле | Призначення |
|---|---|
| **Bottom line** | Одне речення. «Бог дотримується Своїх обітниць.» |
| **Verse** | Посилання на вірш для запам'ятовування та короткий текст. |
| **Question** | Одне запитання для дороги додому, яке батьки можуть поставити без PDF. |
| **Optional note** | Додаткове (підказка для молитви, сімейна активність). Підтримує Markdown. Прихований, якщо порожній. |

Головна думка та одне запитання важливіші за огляд. Якщо на цей тиждень для батьків нічого немає, залиште всі чотири поля порожніми -- тоді нічого не відображатиметься.

Не вміщуйте текст для батьків в **Description**. Description -- це каталожний опис для вчителів, які переглядають уроки на lessons.church.

## Розуміння структури уроку

Кожен урок складається з кількох рівнів:

- **Venues** -- різні версії уроку для різних вікових груп або умов. Наприклад, для одного уроку можна мати місце «Дошкільний» і місце «Початкова школа».
- **Sections** -- сегменти всередині місця, наприклад «Welcome», «Video», «Bible Story» та «Activity». Розділи визначають перебіг часу заняття.
- **Roles and Actions** -- у межах кожного розділу ви призначаєте ролі (наприклад, «Головний вчитель» або «Керівник малої групи») і даєте кожній ролі конкретні дії.

## Типи дій

Для ролі в межах розділу можна призначити чотири типи дій:

- **Say** -- текст, який волонтер має вимовити або переказати класу своїми словами.
- **Do** -- фізична активність або інструкція для виконання.
- **Note** -- довідкова інформація або нагадування для волонтера (не читається вголос).
- **Play** -- відео або аудіоуривок, який відтворюється під час розділу.

## Додавання місця проведення

1. Відкрийте урок в адміністративному вигляді.
2. Натисніть **Add Venue**.
3. Введіть назву місця (наприклад, «Дошкільний» або «Початкова школа»).
4. Збережіть. Тепер до цього місця можна додавати розділи.

## Додавання розділів і дій

1. Розгорніть місце, щоб побачити його розділи.
2. Натисніть **Add Section** і дайте розділу назву (наприклад, «Welcome»).
3. У межах розділу натисніть **Add Action**.
4. Оберіть **role**, **action type** (Say, Do, Note або Play) і введіть вміст.
5. Збережіть.

Повторюйте цей процес, доки не побудуєте повний хід уроку.

## Завантаження ресурсів на рівні уроку

Ви можете прикріпити до уроку матеріали для завантаження -- наприклад, аркуш із завданнями або розмальовку, призначені саме для цього тижня.

1. Відкрийте урок в адміністративному вигляді.
2. Перейдіть до розділу **Resources**.
3. Завантажте файли.

:::tip
Складайте урок з погляду волонтера. Пройдіть розділи та дії по порядку й запитайте себе, чи зміг би волонтер, який робить це вперше, виконати все без жодної додаткової підготовки.
:::
