# Lessons.church

<div class="article-intro">

Lessons.church — це повністю безкоштовна платформа з навчальними програмами для церков. Немає підписок, плат і обмежень на використання. Вона пропонує понад 1 100 відеоуроків у понад 189 курсах від понад 12 провайдерів, для вікових груп від дошкільного віку до дорослих.

</div>

## Що можна робити

За допомогою Lessons.church ваша церква може:

- **Переглядати контент** -- Досліджувати зростаючу бібліотеку програм і курсів від різних провайдерів, упорядкованих за віковою групою та темою.
- **Створювати класи** -- Створювати класи, які відповідають структурі вашого служіння (наприклад, дошкільний, молодший шкільний, молодіжний або дорослий).
- **Планувати уроки** -- Призначати конкретні уроки для ваших класів на потрібні дати.
- **Налаштовувати під свої потреби** -- Коригувати зміст уроків відповідно до стилю навчання та вподобань вашої церкви.
- **Проводити заняття** -- Використовувати вбудований режим презентації, щоб покроково проводити уроки під час заняття.

## Як організовано контент

Lessons.church організовує навчальні матеріали за чіткою ієрархією:

1. **Програми** -- Курс верхнього рівня від провайдера (наприклад, програма дитячого служіння).
2. **Курси** -- Група пов'язаних уроків у межах програми (наприклад, чотиритижнева серія на конкретну тему).
3. **Уроки** -- Окреме навчальне заняття в межах курсу, зазвичай для одного класного зібрання.
4. **Варіанти** -- Різні версії уроку, адаптовані для конкретних вікових груп або умов (наприклад, версія для дошкільного віку та версія для молодшого шкільного віку).

## Інтеграції

Lessons.church працює з іншими інструментами ChurchApps, щоб допомогти вам доставляти контент:

- **B1.church** -- Волонтери та батьки можуть переглядати найближчі та нещодавні уроки через застосунок B1.
- **FreeShow** -- Використовуйте програмне забезпечення для презентацій FreeShow, щоб відображати зміст уроку на екрані.
- **[FreePlay](https://freeplay.church)** -- Відображайте уроки безпосередньо на телевізорі за допомогою застосунку FreePlay для Android TV, Fire TV та Apple TV.
