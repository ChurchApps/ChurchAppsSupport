# Налаштування

<div class="article-intro">

Lessons.church пропонує бібліотеку готових уроків, але кожна церква інша. Функції налаштування дозволяють адаптувати вміст уроків до ваших класів, стилю викладання та вікових груп, щоб волонтери бачили лише те, що для них актуально.

</div>

## Навіщо налаштовувати?

Вміст уроків на Lessons.church розроблено гнучким. Один урок може містити розділи для кількох вікових груп, необов'язкові заняття або ролі, які не стосуються кожного класу. Замість того щоб змушувати волонтерів ментально пропускати непотрібні частини, ви можете налаштувати урок так, щоб вони бачили лише те, що для них важливо.

Наприклад, урок може містити творче заняття, яке добре підходить для дошкільнят, але не пасує вашому класу п'ятикласників. Завдяки налаштуванню ви можете приховати цей розділ для старшої групи, залишивши його для молодшої.

## Що можна налаштувати

- **Видалення розділів** -- Видаліть цілі розділи уроку, які не стосуються конкретного класу чи вікової групи.
- **Видалення ролей або дій** -- Видаліть окремі ролі або дії всередині розділу, якщо вони не потрібні.
- **Зміна порядку вмісту** -- Перестановте розділи та дії відповідно до послідовності, яка вам зручніша для вашого класу.

## Для одного класу чи для всіх

Кожного разу, коли ви вносите зміну, ви обираєте, наскільки широко вона діятиме:

- **Цей клас** -- Зміна стосується лише поточного класу. Інші класи бачать оригінальний вміст.
- **Усі класи** -- Зміна застосовується до всіх класів у вашій церкві.

Ця гнучкість дозволяє створити різні версії одного уроку для різних вікових груп або внести зміну, яка одразу діє скрізь.

:::tip
Якщо ви лише починаєте працювати з налаштуваннями, почніть з одного класу, щоб побачити, як це працює, перш ніж застосовувати зміни до всіх класів.
:::
