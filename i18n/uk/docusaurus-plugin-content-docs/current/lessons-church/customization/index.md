# Налаштування

<div class="article-intro">

Lessons.church містить бібліотеку готових уроків, але кожна церква відрізняється від інших. Функції налаштування дозволяють адаптувати вміст уроків до ваших класів, стилю викладання та вікових груп, щоб волонтери бачили лише те, що стосується саме їх.

</div>

## Навіщо налаштовувати?

Вміст уроків на Lessons.church розроблено гнучким. Один урок може містити розділи для кількох вікових груп, необов'язкові заняття або ролі, які не стосуються кожного класу. Замість того щоб просити волонтерів самостійно пропускати непотрібні частини, ви можете налаштувати урок так, щоб вони бачили лише те, що для них актуально.

Наприклад, урок може містити творче заняття, яке чудово підходить для дошкільнят, але не пасує до класу п'ятикласників. За допомогою налаштування ви можете приховати цей розділ для старшої групи, залишивши його для молодшої.

## Що можна налаштувати

- **Видалення розділів** -- Приховати цілі розділи уроку, які не стосуються конкретного класу або вікової групи.
- **Приховування ролей або дій** -- Видалити окремі ролі або дії всередині розділу, якщо вони не потрібні.
- **Зміна порядку вмісту** -- Переставити розділи та дії, щоб відповідати бажаному перебігу заняття у вашому класі.

## Для окремого класу або для всіх

Під час збереження налаштування ви обираєте, наскільки широко воно застосовуватиметься:

- **Один клас** -- Налаштування впливає лише на поточний клас. В інших класах відображається оригінальний вміст.
- **Усі класи** -- Налаштування застосовується до всіх класів вашої церкви.

Ця гнучкість дозволяє створювати різні варіанти одного уроку для різних вікових груп або внести зміну, яка одразу діятиме скрізь.

:::tip
Якщо ви вперше використовуєте налаштування, почніть з одного класу, щоб побачити, як це працює, і лише потім застосовуйте зміни до всіх класів.
:::
