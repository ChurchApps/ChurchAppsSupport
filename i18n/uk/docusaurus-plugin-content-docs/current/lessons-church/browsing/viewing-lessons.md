# Перегляд уроків

<div class="article-intro">

Кожен урок на Lessons.church є повноцінним навчальним заняттям зі структурованим змістом, матеріалами для завантаження та підтримкою кількох вікових груп. Цей посібник пояснює, як переміщатися сторінкою уроку та користуватися нею для підготовки до заняття.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Ознайомтеся з тим, як організовано зміст, прочитавши [Програми та дослідження](./programs-and-studies.md)
- Перейдіть до програми та дослідження, щоб знайти потрібний урок

</div>

## Як відкрити урок

Щоб переглянути урок, перейдіть крізь ієрархію змісту:

1. Натисніть **програму** на головній сторінці.
2. Виберіть **дослідження** на сторінці програми.
3. Натисніть **урок**, який хочете переглянути, на сторінці дослідження.

## Що ви побачите

Сторінка уроку складається з кількох розділів:

### Відео

Якщо урок містить відео, воно з'являється у верхній частині сторінки. Натисніть, щоб відтворити його безпосередньо у браузері. Відео часто використовують як основний навчальний фрагмент, особливо в дитячому служінні.

### Розділи та ролі

Кожен урок поділено на **розділи** (наприклад, «Вступ», «Біблійна історія», «Активність», «Завершення»). Усередині кожного розділу зміст упорядковано за **ролями**:

- **Керівник** -- Основний вчитель або ведучий
- **Помічник** -- Волонтери, які допомагають
- Інші власні ролі, визначені автором програми

Кожна роль містить свої **дії**, які точно підказують волонтеру, що робити:

- **Сказати** -- Текст або тези для озвучення
- **Зробити** -- Фізичні інструкції або дії для виконання
- **Примітка** -- Довідкова інформація або поради для волонтера
- **Відтворити** -- Вказівки відтворити відео- або аудіофрагмент

### Матеріали для завантаження

До уроків можуть входити файли, які можна завантажити й роздрукувати, зокрема:

- PDF-роздатки
- Робочі аркуші для активностей
- Розмальовки
- Інструкції з виготовлення виробів
- Листівки для батьків, які можна забрати додому

Шукайте посилання для завантаження на сторінці уроку, щоб отримати ці ресурси. Докладніше про підготовку друкованих матеріалів див. у розділі [Завантаження та матеріали](../presenting/downloads.md).

## Перемикання між віковими групами

Багато уроків підтримують кілька **вікових груп** (venues), які відповідають різним віковим категоріям, наприклад «Дошкільнята», «Молодші школярі» або «Передпідлітки». Вікові групи дозволяють адаптувати одну й ту саму тему уроку до відповідного рівня для кожної групи.

Щоб перемикатися між віковими групами:

1. Знайдіть **перемикач вікових груп** на сторінці уроку.
2. Натисніть іншу назву групи (наприклад, перейдіть від **Молодших школярів** до **Дошкільнят**).
3. Сторінка оновиться й покаже зміст, тексти та матеріали, призначені для цієї вікової категорії.

:::tip
Якщо ви навчаєте кілька вікових груп, перегляньте кожну з них перед заняттям, щоб побачити, як зміст адаптовано для різних рівнів.
:::
