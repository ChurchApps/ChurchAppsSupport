# Звіт про пожертви

<div class="article-intro">

Звіт «Зведення пожертв» дає чітку картину щодо діяльності вашої церкви з пожертвувань. Використовуйте його, щоб відстежувати загальні суми пожертв, стежити за тенденціями та готувати фінансові звіти для вашої керівної команди.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Переконайтеся, що пожертви послідовно [записуються](../donations/recording-donations.md) у вашій системі
- Для доступу до фінансових звітів вам потрібні відповідні [дозволи](../settings/roles-permissions.md)

</div>

## Як запустити звіт

1. Перейдіть безпосередньо за адресою **admin.b1.church/reports/donationSummary** у вашому браузері (звіти не мають пункту в меню навігації, тому найзручніше зберегти цю адресу в закладках).
2. Встановіть **діапазон дат**, щоб визначити період звітності.
3. Застосуйте додаткові фільтри, наприклад за **фондом** або іншими критеріями, щоб звузити результати.
4. Звіт відобразить зведення пожертв за вибраний період.

## Що показує звіт

Звіт «Зведення пожертв» містить:

- **Загальна сума пожертв** -- Загальна сума пожертв за вибраний період.
- **Кількість donors** -- Кількість унікальних жертводавців, які зробили внесок.
- **Суми за фондами** -- Розбивка пожертв за різними фондами, якщо це застосовно.

## Практичне використання

- **Фінансове планування** -- Аналізуйте тенденції пожертв, щоб прогнозувати майбутні надходження та планувати бюджет.
- **Звіти для ради** -- Готуйте зведення для регулярних засідань ради або керівної команди з чіткими даними про пожертви.
- **Підсумки року** -- Запускайте звіт за весь рік, щоб підготувати річні фінансові зведення.
- **Відстеження кампаній** -- Фільтруйте за фондом, щоб відстежувати прогрес спеціальних кампаній зі збору пожертв або будівельних проєктів.
- **Сезонний аналіз** -- Порівнюйте пожертви за різні періоди, щоб зрозуміти сезонні закономірності.

:::tip
Запускайте цей звіт щомісяця, щоб бути в курсі фінансового стану вашої церкви. Порівняння даних місяць до місяця допомагає швидко помічати тенденції.
:::

:::warning
Дані про пожертви беруться із записаних внесків у вашій системі. Переконайтеся, що пожертви вносяться послідовно -- чи то через онлайн-пожертви, обробку чеків або ручне введення -- для найточніших звітів. Детальніше див. у розділі [Запис пожертв](../donations/recording-donations.md).
:::
