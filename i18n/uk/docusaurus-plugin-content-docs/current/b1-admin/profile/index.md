# Профіль

<div class="article-intro">

Розділ «Профіль» дозволяє керувати налаштуваннями вашого особистого облікового запису в ChurchApps. Ваш профіль спільний для всіх інструментів ChurchApps, тож зміни, які ви тут внесете, діятимуть скрізь -- від B1 Admin до B1 App.

</div>

## Що можна робити

У розділі «Профіль» ви можете:

- **Оновлювати ім'я та електронну пошту** -- Тримайте свою контактну інформацію актуальною.
- **Змінювати пароль** -- Встановіть новий пароль для свого облікового запису.
- **Увімкнути двофакторний вхід** -- Вимагати код із застосунку-автентифікатора під час входу. Див. [Двофакторний вхід](./managing-profile.md#two-factor-sign-in).
- **Перемикати теми** -- Перемикайтеся між світлим і темним режимом у меню користувача (натисніть своє фото профілю у верхньому правому куті).
- **Керувати підключеними пристроями** -- Переглядайте та контролюйте, які пристрої ChurchAppsPlayer прив'язані до вашого облікового запису.
- **Переглядати пов'язані облікові записи** -- Переглядайте та керуйте зовнішніми сервісами, підключеними до вашого облікового запису ChurchApps.
- **Схвалювати запити на зміну профілю** -- Переглядайте та застосовуйте оновлення, надіслані учасниками.

## Підрозділи профілю

Розділ «Профіль» містить такі сторінки:

1. **[Керування профілем](./managing-profile.md)** -- Редагуйте особисту інформацію, змінюйте пароль, керуйте пов'язаними обліковими записами, увімкайте двофакторний вхід, налаштовуйте тему оформлення та видаляйте обліковий запис.
2. **[Схвалення змін профілю](./approving-profile-changes.md)** -- Переглядайте та схвалюйте запити на оновлення профілю, надіслані учасниками через B1 App.
3. **[Керування пристроями](./devices.md)** -- Переглядайте, додавайте та керуйте пристроями ChurchAppsPlayer, сполученими з вашим обліковим записом.

:::tip
Стежте за тим, щоб ваша електронна адреса була актуальною. Вона використовується для відновлення доступу до облікового запису та для важливих сповіщень від вашої церкви.
:::
