# Профіль

<div class="article-intro">

Розділ «Профіль» дозволяє керувати особистими налаштуваннями облікового запису в ChurchApps. Ваш профіль спільний для всіх інструментів ChurchApps, тож зміни, які ви тут вносите, застосовуються скрізь — від B1 Admin до застосунку B1 Mobile.

</div>

## Що можна зробити

У розділі «Профіль» ви можете:

- **Оновити ім'я та електронну пошту** -- Тримайте свої контактні дані актуальними.
- **Змінити пароль** -- Встановіть новий пароль для свого облікового запису.
- **Увімкнути двофакторний вхід** -- Вимагати код із застосунку-автентифікатора під час входу. Див. [Двофакторний вхід](./managing-profile.md#two-factor-sign-in).
- **Перемикати теми** -- Перемикатися між світлим і темним режимом у меню користувача (натисніть на фото профілю у верхньому правому куті).
- **Керувати підключеними пристроями** -- Переглядати та контролювати, які пристрої ChurchAppsPlayer прив'язані до вашого облікового запису.
- **Переглядати пов'язані облікові записи** -- Переглядати та керувати зовнішніми сервісами, підключеними до вашого облікового запису ChurchApps.
- **Схвалювати запити на зміну профілю** -- Переглядати та застосовувати оновлення, надіслані учасниками.

## Підрозділи профілю

Розділ «Профіль» містить такі сторінки:

1. **[Керування профілем](./managing-profile.md)** -- Редагування особистих даних, зміна пароля, керування пов'язаними обліковими записами, увімкнення двофакторного входу, налаштування теми та видалення облікового запису.
2. **[Схвалення змін профілю](./approving-profile-changes.md)** -- Перегляд і схвалення запитів на оновлення профілю, надісланих учасниками через B1 Mobile.
3. **[Керування пристроями](./devices.md)** -- Перегляд, додавання та керування пристроями ChurchAppsPlayer, сполученими з вашим обліковим записом.

:::tip
Тримайте адресу електронної пошти актуальною. Вона використовується для відновлення облікового запису та важливих сповіщень від вашої церкви.
:::
