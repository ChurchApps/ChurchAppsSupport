# Масова зміна даних людей

<div class="article-intro">
Масове редагування дозволяє оновити кількох людей одночасно, що заощаджує час, коли однакову зміну потрібно внести для багатьох осіб. Ви можете змінити статус членства, сімейний стан, стать, налаштування відмови від розсилок і належність до груп однією операцією.
</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Вам потрібен дозвіл на керування даними людей. Докладніше див. [Ролі та дозволи](./roles-permissions.md).
- Ви маєте вже додати або імпортувати людей, яких хочете редагувати. За потреби див. [Додавання людей](./adding-people.md).
</div>

## Вибір людей для масового редагування

1. Перейдіть до розділу **People** у B1 Admin.
2. Скористайтеся пошуком або фільтрами, щоб знайти людей, яких потрібно оновити.
3. Позначте людей прапорцями.
   - У поданні **Households** позначення домогосподарства вибирає всіх, хто в ньому є.
   - У поданні **Table** (перемикається за допомогою перемикача **View as**) можна вибирати людей окремо.
   - Або скористайтеся прапорцем над списком, щоб вибрати всіх видимих людей.
4. Щойно ви виберете принаймні одну людину, над списком з'явиться рядок, який показує кількість вибраних, а також кнопки **Clear Selection** і **Actions**.

:::tip
Якщо потрібно оновити велику групу людей за певними критеріями, скористайтеся функцією [AI Search](./ai-search.md) або фільтрами, щоб спочатку звузити список, а потім вибрати всіх відповідних людей.
:::

## Доступні масові дії

Меню **Actions** містить кілька варіантів:

### Оновлення статусу членства

Оновіть статус членства для всіх вибраних людей:

1. Натисніть **Actions** → **Set Membership Status**.
2. Оберіть новий статус:
   - **Visitor** -- відвідувачі, які прийшли вперше або час від часу
   - **Guest** -- гості, наприклад сім'ї, зареєстровані на кіоску самореєстрації
   - **Regular Attendee** -- постійні відвідувачі, які не є членами церкви
   - **Member** -- офіційні члени церкви
   - **Staff** -- штатні працівники церкви
   - **Inactive** -- люди, які більше не відвідують церкву
   - **Deceased** -- люди, які померли
3. Оберіть режим оновлення:
   - **Overwrite all** -- замінити поточний статус для всіх вибраних людей
   - **Only update empty** -- встановити статус лише тим, у кого його немає
4. Натисніть **Update**.

### Оновлення сімейного стану

Масово змініть сімейний стан:

1. Натисніть **Actions** → **Set Marital Status**.
2. Оберіть новий статус:
   - **Unknown**
   - **Single**
   - **Married**
   - **Divorced**
   - **Widowed**
3. Оберіть, чи перезаписувати наявні значення, чи оновлювати лише порожні поля.
4. Натисніть **Update**.

### Оновлення статі

Оновіть інформацію про стать для кількох людей:

1. Натисніть **Actions** → **Set Gender**.
2. Оберіть значення:
   - **Unspecified**
   - **Male**
   - **Female**
3. Оберіть режим оновлення (перезаписати все або лише порожні поля).
4. Натисніть **Update**.

### Оновлення статусу відмови від розсилок

Керуйте тим, чи відмовилися люди від повідомлень:

1. Натисніть **Actions** → **Set Directory Opt-Out**.
2. Оберіть:
   - **No** -- дозволити повідомлення (зняти відмову)
   - **Yes** -- заблокувати повідомлення (встановити відмову)
3. Оберіть режим оновлення.
4. Натисніть **Update**.

:::warning
Будьте обережні, змінюючи статус відмови від розсилок. Люди, які явно відмовилися від повідомлень, не повинні їх отримувати без нової згоди.
:::

### Встановлення власного поля

Встановіть значення Yes/No для [власного поля](../settings/custom-fields.md) відразу для всіх вибраних людей:

1. Натисніть **Actions** → **Set Custom Field**.
2. Оберіть власне поле типу Yes/No, яке хочете встановити.
3. Оберіть значення (**Yes** або **No**) для застосування.
4. Натисніть **Update**.

:::info
Для цієї масової дії доступні лише власні поля типу Yes/No. Щоб встановити поля інших типів, редагуйте кожну людину окремо.
:::

### Додавання до групи

Додайте всіх вибраних людей до однієї або кількох груп:

1. Натисніть **Actions** → **Add to Group**.
2. Знайдіть і оберіть групу (групи), до яких потрібно додати людей.
3. Можна вибрати кілька груп, щоб додати людей до всіх них.
4. Натисніть **Add to Groups**.

Кожна людина буде додана як звичайний учасник вибраної групи (груп). Пізніше, за потреби, ви можете призначити окремих людей керівниками групи на сторінці [Учасники групи](../groups/group-members.md).

### Видалення з групи

Видаліть усіх вибраних людей з однієї або кількох груп:

1. Натисніть **Actions** → **Remove from Group**.
2. Знайдіть і оберіть групу (групи), з яких потрібно видалити людей.
3. Можна вибрати кілька груп.
4. Натисніть **Remove from Groups**.

:::info
Ця дія лише видаляє людей із зазначених груп. Вона не видаляє їхні записи про людей.
:::

### Видалення людей

Назавжди видаліть вибраних людей з бази даних вашої церкви:

1. Натисніть **Actions** → **Delete**.
2. Діалогове вікно **Delete Selected People** попросить підтвердити, скільки людей буде видалено.
3. Натисніть **Delete**.

:::danger
Видалення людей є незворотним. Буде видалено всі їхні дані, зокрема:
- Особиста інформація
- Членство в групах
- Записи про відвідуваність
- Історія пожертв
- Відправлені форми

Використовуйте цю дію, лише якщо ви впевнені, що хочете видалити цих людей із системи.
:::

## Результати масового редагування

Після виконання масової дії ви побачите підсумок, який містить:

- **Total selected** -- скільки людей було включено в операцію
- **Successfully updated** -- скільки записів було змінено
- **Failed** -- записи, які не вдалося оновити (за наявності)
- **Unchanged** -- записи, які не потребували змін (наприклад, у режимі «only update empty»)

Якщо деякі оновлення не вдалися, ви побачите відомості про помилки з поясненням причини.

## Найкращі практики

- **Починайте з малого** -- спершу протестуйте масові операції на кількох записах, щоб переконатися, що вносите правильні зміни.
- **Використовуйте фільтри** -- звузьте список за допомогою фільтрів або AI-пошуку, перш ніж вибирати людей, щоб оновити лише потрібних осіб.
- **Перевіряйте вибір** -- перегляньте вибраних людей перед застосуванням масових змін.
- **Використовуйте режим «only update empty»** -- коли потрібно заповнити відсутні дані, не перезаписуючи наявну інформацію.
- **Документуйте великі зміни** -- зберігайте нотатки про масові оновлення, щоб мати змогу звернутися до них пізніше.
- **Координуйте дії з командою** -- повідомляйте інших адміністраторів про великі масові зміни.

## Типові сценарії використання

### Оновлення нових членів

Після заняття для майбутніх членів церкви оновіть статус усіх відвідувачів на Member:

1. Знайдіть людей, які відвідали заняття.
2. Виберіть усіх.
3. Скористайтеся **Actions** → **Set Membership Status** → **Member**.

### Організація малих груп

Додайте кількох людей до нової малої групи:

1. Знайдіть людей, яких хочете додати до групи.
2. Виберіть їх.
3. Скористайтеся **Actions** → **Add to Group** і оберіть малу групу.

### Очищення даних

Заповніть відсутній сімейний стан для подружніх пар:

1. Відфільтруйте людей, які перебувають у шлюбі (використовуючи інформацію про домогосподарство).
2. Виберіть тих, у кого сімейний стан не заповнено.
3. Скористайтеся **Actions** → **Set Marital Status** → **Married** → **Only update empty**.
