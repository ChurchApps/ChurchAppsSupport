# Збережені списки

<div class="article-intro">

**Збережені списки** дають змогу зберегти пошуковий запит під назвою та повторно запускати його одним клацанням у будь-який час. Створіть список один раз, наприклад «Активні члени в кампусі Північ», «Відвідувачі за останні 90 днів» або будь-який розширений фільтр. Він залишатиметься вгорі сторінки «Люди», тож вам не доведеться щоразу будувати запит заново.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Виконайте принаймні один пошук у розділі «Люди», щоб мати результати для збереження. Див. [Пошук людей](./searching-people.md) або [Пошук зі ШІ](./ai-search.md).

</div>

## Збереження пошуку як списку

1. Виконайте пошук на сторінці **Люди**: швидкий пошук, пошук зі ШІ або пошук із розширеним фільтром.
2. Коли з'являться результати, у заголовку сторінки «Люди» з'явиться кнопка **Зберегти як список**.
3. Натисніть **Зберегти як список**.
4. Введіть **Назву списку** (обов'язково).
5. За бажання введіть **Категорію**, щоб згрупувати пов'язані списки (наприклад, «Охоплення» або «Членство»).
6. У розділі **Хто може бачити цей список** виберіть **Весь персонал** або **Тільки я**.
7. Натисніть **Зберегти**.

Список збережено, і він з'являється як кнопка в рядку збережених списків угорі сторінки «Люди», поруч із кнопкою **Усі**. Списки з позначкою **Тільки я** мають невеликий значок замка.

:::info
Списки з доступом **Весь персонал** є спільними для всієї вашої церкви: їх можуть бачити та завантажувати всі, хто має доступ до розділу «Люди». Змінювати або видаляти списки можуть лише працівники з відповідним дозволом.
:::

## Завантаження збереженого списку

Угорі сторінки «Люди» натисніть назву будь-якого списку. Пошук миттєво повториться зі збереженим запитом, і результати оновляться. Натисніть **Усі**, щоб повернутися до всього каталогу.

Списки групуються за категоріями (якщо ви призначили категорію), а списки без категорії відображаються наприкінці.

:::tip
Списки є **динамічними запитами**, а не знімками. Щоразу, коли ви завантажуєте список, пошук виконується заново за вашими поточними даними, тож з'являться й люди, які щойно відповідають критеріям.
:::

## Перейменування та видалення списків

Працівники з правом керування можуть перейменувати або видалити будь-який список на сторінці «Люди». Спочатку натисніть список, щоб завантажити його. Тоді поруч із назвою з'являться дві іконки:

- Натисніть іконку **Налаштування списку** (шестерня), щоб перейменувати список або змінити його категорію, доступ та інші параметри.
- Натисніть іконку **Видалити** (кошик), щоб видалити список (вам буде запропоновано підтвердити дію).

## Сценарії використання

| Сценарій | Як створити список |
|---|---|
| Усі відвідувачі | Розширений пошук: Статус членства = Відвідувач |
| Члени в конкретному кампусі | Розширений пошук: Кампус = [ваш кампус] |
| Люди без адреси електронної пошти | Розширений пошук: Електронна пошта порожня |
| Волонтери з простроченою перевіркою на судимість | Розширений пошук: [Користувацьке поле](../settings/custom-fields.md) «Перевірка на судимість спливає» має дату до сьогодні |
| Результати відповіді на запитання ШІ | Поставте запитання в пошуку зі ШІ, а потім збережіть результат |
