# Відстеження відвідуваності церкви

<div class="article-intro">

Налаштуйте відстеження відвідуваності для богослужінь і груп: від налаштування кампусів і часу служінь до запису відвідуваності вручну або через застосунок самообслуговування для реєстрації, а також перегляду тенденцій у звітах. Після завершення ви матимете повну картину того, хто і коли відвідує церкву.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Обліковий запис B1 Admin з правами адміністратора
- [Людей, доданих до вашого каталогу](../people/adding-people.md)
- [Створені групи](../groups/creating-groups.md) для служінь, відвідуваність яких ви хочете відстежувати

</div>

## Крок 1: Налаштуйте кампуси та служіння

Визначте, де і коли відбуваються ваші зібрання.

Скористайтеся посібником [Налаштування відвідуваності](../attendance/setup.md), щоб:

1. Додати ваш кампус (наприклад, «Головний кампус»)
2. Додати час служінь (наприклад, «Неділя, 9:00», «Неділя, 11:00», «Середа, 19:00»)
3. Призначити групи для кожного часу служіння, щоб визначити, які класи чи служіння відбуваються під час кожного богослужіння

## Крок 2: Увімкніть відстеження відвідуваності груп

Увімкніть відстеження відвідуваності для груп, які ви хочете контролювати.

Скористайтеся посібником [Створення груп](../groups/creating-groups.md), щоб:

1. Відредагувати кожну групу, відвідуваність якої хочете відстежувати, і увімкнути «Відстежувати відвідуваність»
2. Прив'язати групи до часу служінь, щоб відвідуваність фіксувалася для правильного служіння

:::info
Не кожній групі потрібне відстеження відвідуваності. Увімкніть його для груп, де хочете відстежувати участь, наприклад для дитячих класів, малих груп, недільної школи тощо.
:::

## Крок 3: Запишіть відвідуваність вручну

Відмічайте, хто відвідав кожне служіння та групу.

Скористайтеся посібником [Запис відвідуваності](../attendance/recording-attendance.md), щоб:

1. Відкрити групу, натиснути **Усі сесії** в її розділі **Сесії** та додати сесію для дати і часу служіння. Позначте **Також додати для інших груп**, щоб одразу створити сесії для всіх класів у цей час служіння.
2. Відмітити, хто відвідав кожну групу

:::tip
Ручне відстеження чудово підходить для дорослих служінь, малих груп та будь-яких ситуацій, коли терміналу самореєстрації використовувати не практично.
:::

## Крок 4: Налаштуйте самореєстрацію (необов'язково)

Дозвольте учасникам реєструватися самостійно за допомогою планшетного терміналу.

Скористайтеся посібником [Реєстрація](../attendance/check-in.md), щоб:

1. Встановити застосунок B1 Checkin на планшет для самостійної реєстрації
2. Учасники знаходять своє ім'я і реєструються самостійно разом із родиною
3. Записи реєстрації з'являються разом із записами, внесеними вручну, без жодної різниці в даних

:::info
Повне налаштування реєстрації дітей, включно з обладнанням і принтерами, описано в [Посібнику з реєстрації дітей](./childrens-checkin.md).
:::

## Крок 5: Перегляньте звіти про відвідуваність

Отримайте загальну картину участі у житті вашої церкви.

Скористайтеся посібником [Звіти про відвідуваність](../reports/attendance-reports.md). Доступні три види звітів:

1. **Тенденція відвідуваності** — перегляньте відвідуваність за часом, щоб помітити зростання або спад
2. **Відвідуваність груп** — дивіться, хто відвідав кожну сесію групи за певний період, із можливістю завантаження CSV
3. **Щоденна відвідуваність груп** — поденний розподіл для детального аналізу

:::info
Звіти поєднують відвідуваність, записану вручну, і відвідуваність через самореєстрацію. Дані відображаються однаково незалежно від способу — обидва методи подаються в одні й ті самі звіти.
:::

## Готово!

Ваше відстеження відвідуваності налаштовано. Незалежно від того, чи записуєте ви відвідуваність вручну, чи використовуєте застосунок для реєстрації, або обидва способи, всі дані потрапляють в одні звіти, тож ви матимете чітку картину участі у житті вашої церкви.
