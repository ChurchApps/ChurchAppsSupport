# Користувацькі поля

<div class="article-intro">

**Користувацькі поля** дозволяють відстежувати власну інформацію в записі кожної людини. Це корисно для даних, для яких у B1 немає вбудованого поля, наприклад дати закінчення перевірки на судимість, розміру футболки або статусу курсу хрещення. Поле визначається один раз у розділі налаштувань, після чого ви заповнюєте значення в профілі кожної людини і можете шукати за ним або створювати списки. Це замінює старий обхідний спосіб, коли для збереження однієї користувацької властивості створювали форму для людей.

## Відкриття користувацьких полів

У B1 Admin відкрийте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (рядок пошуку у верхньому лівому куті), виберіть **Налаштування > Налаштування** і натисніть **Користувацькі поля** у списку зліва, щоб перейти до розділу **Користувацькі поля**. Також можна одразу перейти за адресою **/settings/custom-fields**. Ви побачите список усіх визначених полів з їхньою **назвою** та **типом поля**. Якщо ще жодного поля не створено, на панелі буде написано: «Користувацькі поля ще не додано».

## Додавання поля

1. Натисніть **Додати поле**.
2. В редакторі, що відкриється праворуч, введіть **назву**. Це мітка, яку персонал бачитиме в профілях людей і під час пошуку (наприклад, *Перевірка на судимість спливає*).
3. Виберіть **тип поля**:
   - **Текстове поле** — вільний короткий текст.
   - **Ціле число** — числа без десяткової частини (наприклад, кількість).
   - **Десятковий дріб** — числа, які можуть містити десяткові знаки.
   - **Дата** — календарна дата.
   - **Так/Ні** — просту відповідь так або ні.
   - **Множинний вибір** — список для вибору. Коли ви обираєте цей тип, з'являється **редактор варіантів**, у якому можна додати кожен варіант, який можуть вибрати люди.
4. Натисніть **Зберегти**.

Тепер поле доступне в профілі кожної людини.

:::info
Типи полів ті самі, що й для [питань у формах](../forms/creating-forms.md), тож значення поводяться однаково в усьому B1.
:::

## Редагування поля

Натисніть будь-який рядок поля в списку, щоб знову відкрити його в редакторі. Змініть назву, тип або варіанти та натисніть **Зберегти**.

:::warning
Зміна **типу поля** для поля, у якому вже є значення (наприклад, із Текстового поля на Дату), може залишити раніше введені значення у форматі, який не відповідає новому типу. Змінюйте типи обережно, коли персонал уже почав заповнювати поле.
:::

## Видалення поля

Відкрийте поле для редагування та натисніть **Видалити**.系統 попросить підтвердити дію: *«Ви впевнені, що хочете видалити це користувацьке поле? Збережені в ньому значення також буде видалено».* Видалення поля назавжди прибирає його **і всі значення, збережені для нього**, у всіх людей. Цю дію неможливо скасувати.

## Заповнення значень у записі людини

Щойно з'являється принаймні одне користувацьке поле, його значення розміщуються поруч із вбудованими відомостями в записі кожної людини. Переглядати їх можна разом із контактними даними людини ліворуч від профілю, а редагувати — у тій самій формі, що й решту інформації про людину. Нічого додаткового не з'являється, доки ви не визначите перше поле.

1. Відкрийте запис людини в розділі **Люди**.
2. Натисніть кнопку **Редагувати** ліворуч у профілі, під контактними даними людини.
3. Прокрутіть до області **Користувацькі поля** внизу форми редагування та заповніть значення для кожного поля. Кожне поле показує елемент введення, що відповідає його типу: календар для полів «Дата», випадаючий список «Так/Ні» для полів «Так/Ні», список для вибору для «Множинного вибору» тощо.
4. Натисніть **Зберегти**. Значення користувацьких полів збережуться разом з рештою даних про людину.

Повернувшись до профілю, ви побачите, що будь-яке поле зі значенням тепер відображається під контактними даними людини у форматі *Назва поля: значення* (відповіді «Так/Ні» виводяться як *Так* або *Ні*, а для «Множинного вибору» показується назва обраного варіанта). Порожні поля просто приховуються. Щоб видалити значення, відредагуйте людину, очистіть поле і збережіть зміни. Порожнє значення видаляється із запису, а не зберігається як порожнє.

:::tip
Класичний приклад використання — безпека волонтерів: створіть поле **Дата** під назвою *Перевірка на судимість спливає*, внесіть дату для кожного волонтера, а потім побудуйте [збережений список](../people/lists.md), який позначатиме тих, чия дата вже минула.
:::

## Пошук і створення списків за користувацькими полями

За користувацькими полями можна виконувати повний пошук:

1. На сторінці **Люди** відкрийте [Розширений пошук](../people/searching-people.md).
2. Розгорніть категорію **Користувацькі поля**.
3. Позначте поле, за яким хочете фільтрувати, виберіть оператор і введіть значення. Доступні оператори відповідають типу поля:
   - **Текстове поле** — містить, дорівнює, починається з, закінчується на.
   - **Ціле число / Десятковий дріб** — дорівнює, більше, більше або дорівнює, менше, менше або дорівнює.
   - **Дата** — дорівнює, пізніше (більше), раніше (менше).
   - **Так/Ні** — дорівнює Так або Ні.
   - **Множинний вибір** — дорівнює або містить один із варіантів.

Будь-який пошук за користувацьким полем можна зберегти як [список](../people/lists.md). Списки є динамічними запитами, тож список, побудований на умові *Перевірка на судимість спливає раніше за сьогодні*, перевіряє всіх людей щоразу, коли ви його відкриваєте, без ручного оновлення.

## Відображення користувацького поля як стовпця

Щоб одразу побачити значення поля для всіх людей, додайте його як стовпець на сторінці **Люди**. Перемкніть **Переглянути як** на **Таблиця**, натисніть значок **Вибрати стовпці** в заголовку сторінки, перейдіть на вкладку **Користувацькі** і позначте потрібне поле. Значення кожної людини з'явиться в окремому стовпці поруч із вбудованими. Див. [Відображення користувацьких полів як стовпців](../people/searching-people.md#showing-custom-fields-as-columns).

## Що відбувається під час злиття

Коли ви [об'єднуєте два записи людей](../people/adding-people.md), значення користувацьких полів переносяться автоматично. Людина, яку ви залишаєте, зберігає власні значення. Для будь-якого поля, де значення було лише у видаленої людини, це значення копіюється, тож нічого не втрачається.
