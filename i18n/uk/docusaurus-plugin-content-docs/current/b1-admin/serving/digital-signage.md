# Цифрова реклама

<div class="article-intro">

Надсилайте вміст своїх уроків на телевізор у фойє або коридорі через стрічку цифрової реклами. Для кожного типу плану є URL-адреса стрічки, яка завжди відтворює вміст поточного плану, тому щотижня нічого не потрібно оновлювати. Якщо ваші телевізори працюють під управлінням FreePlay, ви можете натомість запланувати тип плану на них у FreePlay Admin.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Налаштуйте [тип плану](./plans.md) з [Lessons.church](../../b1-church/content/lessons.md) або іншим уроковим вмістом, запланованим на дату
- Мати обліковий запис [SignPresenter](https://www.signpresenter.com) і пристрій, налаштований для його відображення, або телевізор із [FreePlay](../../freeplay/index.md)

</div>

## Отримання URL-адреси стрічки

1. Перейдіть до **Serving**, виберіть служіння, що містить ваш тип плану, і натисніть на тип плану, щоб відкрити його.
2. Натисніть **Digital Signage** (значок телевізора) у верхній частині сторінки типу плану.
3. У діалоговому вікні **Digital Signage Feed** натисніть кнопку копіювання поруч із **Feed Url**.

:::info
URL-адреса стрічки прив'язана до типу плану, а не до окремого плану. Вона автоматично відстежує той план, який запланований як поточний для цього типу, тож налаштувати її потрібно лише один раз.
:::

## Підключення до SignPresenter

Стрічку створено для роботи з [SignPresenter](https://www.signpresenter.com) — сторонньою програмою цифрової реклами. Вставте скопійовану URL-адресу в SignPresenter як зовнішню стрічку, щоб відображати поточний уроковий вміст на підключеному екрані.

Покрокові інструкції щодо налаштування всередині SignPresenter дивіться в [посібнику SignPresenter для Lessons.church](https://support.signpresenter.com/topics/lessons-dot-church.html). У діалоговому вікні також є посилання на ці інструкції.

## Використання телевізорів FreePlay

Якщо ваші екрани працюють під управлінням [FreePlay](../../freeplay/index.md), URL-адреса стрічки вам не потрібна. У діалоговому вікні **Digital Signage Feed** є посилання на **admin.freeplay.church/calendar**, де ви можете запланувати цей тип плану на телевізорах FreePlay:

1. Натисніть посилання **admin.freeplay.church/calendar** у діалоговому вікні. FreePlay Admin використовує той самий логін, що й B1 Admin.
2. Виберіть групу екранів для своїх телевізорів і натисніть **Add schedule**.
3. У розділі **Play** виберіть свій тип плану зі списку **Service plans**. Він позначений як **(current plan)**.
4. Встановіть дні та час, а потім натисніть **Save**.

Щотижня телевізори відтворюватимуть той план, який є поточним для цього типу плану, у встановлений вами час. Це працює і з уроками Go Curriculum, зокрема з планами, які ви налаштували самостійно. FreePlay входить в систему через обліковий запис Go Curriculum, пов'язаний із служінням у розділі **Content Providers** (див. [Планування уроків](./scheduling-lessons.md)), або через підключення Go Curriculum вашої церкви, якщо для служіння його немає. Усі варіанти дивіться в [Плануванні календаря](../../freeplay/scheduled-mode/scheduling-the-calendar.md), а щоб додати телевізор, — у [Прив'язці екрана](../../freeplay/scheduled-mode/pairing-a-screen.md).

:::note
URL-адреса стрічки не містить медіа Go Curriculum, оскільки цей вміст потребує логіна Go Curriculum вашої церкви. Щоб показати урок Go Curriculum на телевізорі у фойє або класній кімнаті, використовуйте FreePlay.
:::

## Наступні кроки

- Керуйте планами, які передають цю цифрову рекламу, на сторінці [Plans](./plans.md)

- Розмістіть телевізори FreePlay за календарем у [Scheduled Mode](../../freeplay/scheduled-mode/index.md)
