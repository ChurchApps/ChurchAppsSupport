# Пожертви

<div class="article-intro">

Розділ «Пожертви» у B1 Admin містить усе необхідне для керування пожертвами вашої церкви. Від запису щотижневих пожертв до формування річних податкових довідок: усі інструменти для пожертв зібрано в одному місці, тож ви легко контролюватимете фінанси церкви.

</div>

## Підрозділи

У розділі «Пожертви» ви знайдете такі сторінки:

### Підсумок

Сторінка **Підсумок** дає наочний огляд усієї діяльності, пов'язаної з пожертвами. Вона показує діаграми та відфільтровані звіти, щоб ви швидко бачили тенденції пожертв у вашій церкві. Докладніше про використання підсумку та інструментів звітування див. у розділі [Звіти про пожертви](donation-reports.md).

### Пакети

**[Пакети](batches.md)** дозволяють групувати пожертви. Наприклад, усі чеки та готівку, зібрані під час недільного збору, можна об'єднати в один пакет. Кожен пакет відстежує кількість пожертв і загальну суму, що спрощує звірку. Щойно пакет підраховано, особа з дозволом **Редагувати пожертви** може його закрити, щоб волонтери, які рахують кошти, більше не могли його змінювати. Волонтери з дозволом **Вносити пожертви** можуть додавати подарунки до відкритих пакетів, не бачачи решти розділу «Пожертви».

### Фонди

**[Фонди](funds.md)** класифікують ваші пожертви за призначенням. Типові приклади: Загальний фонд, Фонд будівництва та Місії. Для кожного фонду можна позначити, чи є він податково вирахуваним.

### Довідки

Сторінка **[Довідки](giving-statements.md)** формує річні довідки про пожертви для ваших жертводавців. Ви можете завантажити окремі файли CSV або одразу надрукувати всі довідки.

### Імпорт зі Stripe

Якщо ви приймаєте онлайн-пожертви через Stripe, інструмент **[Імпорт зі Stripe](stripe-import.md)** дозволяє перенести ці транзакції до B1 Admin, щоб усе зберігалося в одній системі.

## Онлайн-пожертви

B1 Admin інтегрується зі **Stripe** та **PayPal** для прийняття онлайн-пожертв. Після налаштування члени громади можуть жертвувати через ваш сайт B1.church, а ці пожертви автоматично з'являтимуться у ваших записах. Щоб почати, див. [Налаштування онлайн-пожертв](online-giving-setup.md).

:::tip
Якщо ви вперше працюєте з пожертвами в B1 Admin, почніть з [налаштування фондів](funds.md), потім [створіть перший пакет](batches.md) і [внесіть пожертви](recording-donations.md) до нього.
:::
