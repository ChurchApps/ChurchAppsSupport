# Стан груп

<div class="article-intro">

Панель «Стан груп» дає змогу оглянути, як справи в усіх ваших групах: тенденції членства, середню відвідуваність і зростання або відтік за останні 90 днів. Усі дані зібрано в одну таблицю, яку можна сортувати.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Потрібно щонайменше кілька груп із учасниками, щоб дані були змістовними. Див. [Створення груп](creating-groups).
- Дані про відвідуваність беруться із записаних зустрічей. Див. розділ [Відвідуваність](../attendance/).

</div>

## Відкриття панелі «Стан груп»

У B1 Admin відкрийте [меню швидкого переходу](../introduction.md#getting-around-with-the-jump-menu) (панель пошуку у верхньому лівому куті), розгорніть **Людей**, натисніть **Групи», а потім кнопку **Стан груп** у заголовку сторінки. Панель завантажить таблицю, де кожен рядок відповідає одній групі.

## Стовпці

| Стовпець | Що показує |
|----------|------------|
| **Назва** | Назва групи з посиланням на сторінку деталей групи |
| **Категорія** | Категорія групи |
| **Учасники** | Поточна кількість активних учасників |
| **Приєдналися (90 днів)** | Учасники, які приєдналися за останні 90 днів |
| **Вибули (90 днів)** | Учасники, які вибули за останні 90 днів |
| **Відтік (90 днів)** | Чистий відсоток відтоку за 90 днів |
| **Середня відвідуваність** | Середня кількість присутніх на одній зустрічі з відвідуваністю |

Натисніть будь-який заголовок стовпця, щоб відсортувати таблицю за ним. Натисніть ще раз, щоб змінити напрямок сортування.

## Як користуватися даними про стан

- **Високий відтік + мало приєднань** — група, яка зменшується й не поповнюється. Варто поговорити з керівником групи.
- **Багато приєднань + низька відвідуваність** — люди записуються, але не приходять. Варто подбати про залучення.
- **Висока середня відвідуваність** — здорова й активна група. Може слугувати зразком для інших груп.

:::tip
Натиснувши назву групи, ви перейдете безпосередньо на сторінку її деталей, де можна переглянути окремих учасників, записи відвідуваності та події в календарі.
:::
