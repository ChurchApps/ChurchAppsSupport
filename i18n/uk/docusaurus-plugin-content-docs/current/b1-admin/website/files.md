# Файли

<div class="article-intro">

Сторінка «Файли» є центральним сховищем для всіх медіафайлів і документів, які використовуються на вашому сайті парафії. Звідси ви можете завантажувати, переглядати та керувати кожним зображенням, документом і медіафайлом, потрібним вашому сайту.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Виконайте [початкове налаштування](initial-setup) для вашого сайту
- Оптимізуйте зображення перед завантаженням, щоб сторінки відкривалися швидше
- Підготуйте файли у поширених веб-форматах (PNG, JPG, PDF тощо)

</div>

## Завантаження файлів

1. У B1 Admin відкрийте [меню переходів](../introduction.md#getting-around-with-the-jump-menu) (панель пошуку у верхньому лівому куті), розгорніть **Website** і натисніть **Files**.
2. На панелі **Upload Files** праворуч натисніть **Choose File** і виберіть файл на вашому комп'ютері. (Кнопка **Upload Files** у верхній частині сторінки відкриває ту саму панель.)
3. Ваш файл завантажиться і з'явиться в таблиці файлів.

На панелі Upload Files також показано, скільки сховища ви використовуєте. Безкоштовно надається 100 МБ; щоб отримати більше, підключіть власний Google Drive, Dropbox, OneDrive або S3-бакет у розділі **File Storage** на сторінці **Settings**.

:::tip
Щоб досягти найкращого результату, оптимізуйте зображення перед завантаженням. Менший розмір файлів допомагає вашому сайту швидше відкриватися для відвідувачів. Інструменти на кшталт TinyPNG або Squoosh можуть стискати зображення без помітної втрати якості.
:::

## Перегляд файлів

У таблиці файлів перелічено всі завантажені файли з їхніми **Name** (назвою) та **Size** (розміром). Натисніть назву файлу, щоб відкрити його в новій вкладці. Перед завантаженням давайте файлам зрозумілі й описові назви, щоб ваша команда могла швидко їх знайти.

## Використання файлів на вашому сайті

1. Знайдіть файл у таблиці файлів.
2. Натисніть **Copy link**, щоб скопіювати URL файлу. Цей URL можна вставити в елементи зображень, посилання для завантаження або будь-яке інше місце, яке приймає URL файлу.
3. Файли, які ви завантажуєте тут, доступні для використання на всіх сторінках вашого сайту та в усіх блоках контенту.

:::info
Створюючи сторінки в розділі [Керування сторінками](managing-pages), ви можете посилатися на будь-який файл, завантажений сюди, за його URL. Так усі ваші медіа зберігаються в одному центральному місці.
:::

## Видалення файлів

1. Знайдіть файл, який хочете видалити, у таблиці файлів.
2. Натисніть **Delete** поруч із ним і підтвердьте дію, щоб назавжди видалити файл з вашої бібліотеки.
3. Перед видаленням переконайтеся, що файл не використовується на жодній сторінці, інакше посилання або зображення, які на нього вказують, перестануть працювати.

:::warning
Видалені файли неможливо відновити. Перевірте двічі, що файл більше не використовується на жодній сторінці, перш ніж його видаляти.
:::
