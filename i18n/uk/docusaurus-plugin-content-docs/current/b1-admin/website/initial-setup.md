# Початкове налаштування

<div class="article-intro">

Кожен обліковий запис B1 має готовий веб-сайт. Цей посібник проведе вас через налаштування домену вашої церкви, оформлення сайту, створення перших сторінок і організацію навігації.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Потрібен обліковий запис B1.church з правами адміністратора
- Якщо ви використовуєте власний домен, підготуйте облікові дані для входу до свого провайдера DNS (наприклад, GoDaddy, Cloudflare або AWS)
- Підготуйте логотип церкви у форматі PNG з прозорим фоном для найкращого результату

</div>

## Налаштування домену

Вашій церкві автоматично надається піддомен на B1.church (наприклад, `yourchurch.b1.church`). Ви також можете прив'язати власний домен до свого сайту B1.

1. Перейдіть до **B1.church Admin**, відкривши admin.b1.church, або натиснувши випадаюче меню свого профілю та обравши **Перемкнути застосунок**.
2. Відкрийте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (рядок пошуку у верхньому лівому куті), розгорніть **Налаштування** та натисніть **Налаштування**.
3. Відкрийте розділ **Інформація про церкву**, щоб переглянути свій піддомен. Задайте коротку й легко впізнавану назву без пробілів.
4. Щоб використовувати власний домен, увійдіть до свого провайдера DNS (наприклад, GoDaddy, Cloudflare або AWS) і додайте два записи:
   - **A-запис** для кореневого домену, що вказує на `3.23.251.61`
   - **CNAME-запис** для `www`, що вказує на `proxy.b1.church`
5. Поверніться до B1.church Admin, відкрийте розділ **Домени** на тій самій сторінці налаштувань, додайте свій власний домен до списку та натисніть **Додати**, а потім **Зберегти**. Ваш сайт стане доступним за власним доменом протягом кількох хвилин.

:::tip
Якщо ви не бачите пункту «Налаштування», попросіть особу, яка створила обліковий запис вашої церкви, надати вам дозвіл «Редагувати налаштування церкви». Докладніше див. [Ролі та дозволи](../settings/roles-permissions.md).
:::

## Створення першої сторінки

1. В B1 Admin відкрийте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (рядок пошуку у верхньому лівому куті), розгорніть **Веб-сайт** і натисніть **Сторінки**.
2. Натисніть **Додати сторінку** у верхньому правому куті.
3. Оберіть **Порожня** як тип сторінки та назвіть її «Головна».
4. Натисніть **Налаштування сторінки** і задайте для головної сторінки шлях URL `/` (коса риска без тексту). Інші сторінки використовують формат `/назва-сторінки`.
5. Натисніть **Редагувати вміст**, щоб почати створення. Кожна сторінка має починатися з **розділу** — це контейнер для всіх інших елементів.
6. Після додавання розділу знову натисніть **Додати вміст**, щоб вставити текст, зображення, відео, картки, форми та інші елементи, перетягнувши їх у свій розділ.

:::info
Докладні інструкції щодо роботи зі сторінками та навігацією див. у розділі [Керування сторінками](managing-pages). Повний посібник із візуального редактора див. у розділі [Використання редактора сторінок](page-editor).
:::

## Налаштування оформлення сайту

1. У меню Jump оберіть **Веб-сайт > Оформлення**.
2. За допомогою **Палітри кольорів** задайте фірмові кольори для основного, другорядного та акцентного тонів.
3. У розділі **Шрифти** оберіть шрифти для заголовків і основного тексту з каталогу шрифтів.
4. Завантажте логотип церкви в розділі **Логотип** у **Налаштуваннях стилю**. Додайте версії для світлого й темного фону.
5. Налаштуйте **Нижній колонтитул сайту** з контактною інформацією та посиланнями вашої церкви.

:::info
Зміни, які ви вносите в розділі «Оформлення», застосовуються до всього вашого веб-сайту. Докладні інструкції щодо кожного параметра див. на сторінці [Оформлення](appearance).
:::

## Налаштування навігації

Посилання навігації відображаються в перегляді сторінок веб-сайту. Щоб їх упорядкувати:

1. Натисніть **Додати**, щоб створити нове посилання навігації, і вкажіть на одну зі своїх сторінок.
2. Перетягуйте посилання, щоб змінити їх порядок або вкласти їх під батьківські пункти.
3. Перегляньте свій сайт, щоб переконатися, що навігація виглядає правильно.
