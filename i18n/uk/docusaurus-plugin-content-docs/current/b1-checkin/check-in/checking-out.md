# Оформлення виходу та безпека дітей

<div class="article-intro">

Оформлення виходу завершує процес реєстрації дітей: батьки показують код безпеки з етикетки для отримання, кіоск перевіряє, хто забирає дитину, і дітей відмічають як вибулих. На станціях із живим персоналом також доступні засоби безпеки: перевірка довірених осіб для забирання, текстові повідомлення для виклику батьків, повторний друк етикеток безпеки та екстрена розсилка.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Оформлення виходу доступне на станціях, встановлених у режим **з персоналом** у налаштуваннях кіоска
- Діти мають бути [зареєстровані](./completing-checkin) з надрукованою етикеткою для отримання, на якій є код безпеки
- Для виклику батьків і екстрених розсилок вашій церкві потрібно підключити постачальника текстових повідомлень у B1 Admin

</div>

## Початок оформлення виходу

1. На станції з персоналом натисніть **Check Out** на екрані пошуку.
2. Введіть 4-символьний **код безпеки** з етикетки для отримання сім'ї. Можна ввести його вручну, скористатися екранною клавіатурою або відсканувати штрих-код етикетки USB- чи Bluetooth-сканером — код відправиться автоматично, щойно буде введено всі 4 символи.
   - Немає сканера? Натисніть **Scan** під полем коду, щоб використати камеру планшета. Утримуйте QR-код або штрих-код етикетки перед камерою у вікні **Scan pickup code** — код буде введено автоматично. За замовчуванням використовується задня камера; натисніть кнопку перемикання, щоб змінити камеру, або **Cancel**, щоб повернутися до введення вручну.
3. Кіоск показує дітей, зареєстрованих за цим кодом.

## Перевірка того, хто забирає дитину

На екрані оформлення виходу запитується, хто забирає дітей:

- **Довірені особи для забирання** з цього домогосподарства відображаються як картки з фотографією та ступенем родинного зв'язку — натисніть на картку людини, яка стоїть перед вами.
- **Дорослі члени домогосподарства** також відображаються у сітці з фотографіями.
- **Інше** дозволяє ввести ім'я особи, якої немає в списку.

Якщо введене ім'я збігається з особою, позначеною як **Not Authorized** для цього домогосподарства, кіоск блокує оформлення виходу з попередженням. Працівник може натиснути **Override**, щоб продовжити попри це, — перевизначення фіксується в записі відвідуваності разом з ім'ям особи.

Після підтвердження особи, що забирає дитину, натисніть «check out». Ім'я особи, що забирає дитину, зберігається із записом про відвідуваність.

:::info
Довірені особи для забирання та особи, яким заборонено забирати дітей, керуються працівниками церкви на сторінці кожної особи в B1 Admin — див. [Безпека реєстрації](../../b1-admin/attendance/checkin-safety#trusted-and-not-authorized-pickup-people).
:::

## Виклик батьків

Потрібен батько чи мати під час служіння — зміна підгузка, дитина плаче? На екрані оформлення виходу на станції з персоналом працівники можуть надіслати **виклик**: текстове повідомлення батькам або опікунам дитини через постачальника текстових повідомлень церкви. Батьки, які відмовилися від текстових повідомлень або не мають мобільного номера, пропускаються, а кіоск показує, скільки повідомлень було надіслано.

## Повторний друк етикеток

Якщо бейдж або етикетка для отримання загублені чи пошкоджені, працівники на станції з персоналом можуть **повторно надрукувати** етикетки сім'ї з екрана оформлення виходу після введення коду безпеки. Для повторного друку використовуються той самий принтер і ті самі шаблони етикеток, що й для початкової реєстрації.

## Екстрена розсилка

У надзвичайній ситуації працівники можуть одночасно надіслати текстове повідомлення опікунам **кожної зареєстрованої дитини** на поточне служіння:

1. Відкрийте **налаштування адміністратора** кіоска (7 швидких натискань на логотип у заголовку, а також PIN-код, якщо його встановлено).
2. Натисніть **Emergency broadcast**.
3. Введіть повідомлення, потім введіть **EMERGENCY** у полі підтвердження — кнопка **Send broadcast** залишатиметься неактивною, доки ви цього не зробите.
4. Кіоск повідомить, скільки телефонів отримали повідомлення і скільки людей було пропущено (відмовилися від розсилки або не мають мобільного номера).

:::warning
Розсилка надсилається кожному зареєстрованому домогосподарству для обраного служіння. Використовуйте її лише в справжніх надзвичайних ситуаціях — евакуація, блокування, сильна негода.
:::
