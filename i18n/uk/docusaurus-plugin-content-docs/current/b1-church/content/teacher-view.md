# Вигляд для викладача для уроків

<div class="article-intro">
Вигляд для викладача відкриває розширений повноекранний інтерфейс для перегляду вмісту уроків зі структурованими розділами, що полегшує викладачам та керівникам орієнтуватися в матеріалах уроку під час заняття.
</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- У вашій церкві мають бути заплановані уроки в плані. Докладніше див. посібник B1 Admin про [планування уроків](../../b1-admin/serving/scheduling-lessons.md).
- Вас мають призначити до плану або надати доступ для його перегляду на вашому сайті B1.church.
</div>

## Відкриття вигляду для викладача

Щоб відкрити розширений вигляд для викладача для уроку:

1. Відкрийте **Plans** на порталі учасників B1.church.
2. Відкрийте план, який містить урок, який ви хочете викладати.
3. Натисніть кнопку **Teach** угорі сторінки плану.

Урок відкриється в повноекранному інтерфейсі, оптимізованому для викладання.

:::tip
Вигляд для викладача особливо корисний, коли вміст уроку проєктується на екран або телевізор, щоб клас бачив його, або коли ви викладаєте з планшета.
:::

## Можливості вигляду для викладача

### Навігація розділами

Вигляд для викладача організовує вміст уроку за розділами:

- Кожен великий розділ уроку відображається як окремий блок із заголовком.
- Натисніть **Sections** угорі, щоб відкрити список розділів, а потім оберіть потрібний, щоб одразу перейти до нього.
- Заголовок показує, в якому розділі ви зараз перебуваєте, наприклад «Section 2 of 5».
- Список розділів дозволяє легко перескакувати між різними частинами уроку.
- Коли в уроці більше одного розділу, кнопки «попередній» і «наступний» із назвами сусідніх розділів залишаються закріпленими внизу екрана під час прокручування.

### Прокручуваний вміст

Основна область вмісту показує повні матеріали уроку:

- Прокручуйте урок природно.
- Під час прокручування заголовок автоматично оновлюється відповідно до розділу, який ви переглядаєте.
- Усі форматовані тексти, зображення та інструкції відображаються чітко.

### Відтворення медіа

Коли уроки містять відео, зображення чи інші медіа:

- Натисніть будь-який медіаелемент, щоб відкрити його у спливаючому програвачі.
- Відео відтворюються у спеціальному відеопрогравачі зі стандартними елементами керування.
- Зображення відкриваються в лайтбоксі для перегляду на весь екран.
- Закрийте медіапрогравач, щоб повернутися до вмісту уроку.

### Ресурси для завантаження

Якщо урок містить файли для завантаження (аркуші з завданнями, розмальовки тощо):

- Кнопки завантаження з'являються для кожного ресурсу після останнього розділу уроку.
- Натисніть, щоб завантажити файли безпосередньо на ваш пристрій.
- Файли можуть бути у форматі PDF, зображеннями або іншими матеріалами, наданими автором вмісту.

## Використання вигляду для викладача на занятті

### Перед заняттям

1. Відкрийте урок у вигляді для викладача до початку заняття.
2. Перегляньте всі розділи та ознайомтеся з вмістом.
3. Завантажте всі потрібні матеріали для друку.
4. Перевірте відео та медіа, щоб переконатися, що вони відтворюються правильно.

### Під час заняття

1. Тримайте вигляд для викладача відкритим на своєму пристрої або проєктуйте його на екран.
2. Використовуйте **Sections**, щоб переходити між розділами під час проходження уроку.
3. Відтворюйте відео або показуйте зображення у відповідний момент.
4. Прокручуйте інструкції за потреби, не втрачаючи свого місця.

### На проєкційному екрані

Під час проєктування для класу:

- Повноекранний макет прибирає відволікаючі елементи.
- Великий, чіткий текст добре видно з будь-якої точки кімнати.
- Натискайте на медіаелементи, щоб показати відео або зображення всьому класу.
- Керуйте за допомогою бездротової миші або трекпада.

## Закриття вигляду для викладача

Щоб вийти з вигляду для викладача:

- Натисніть кнопку **Close** (X) у верхньому куті.
- Або натисніть клавішу **Esc** на клавіатурі.
- Ви повернетеся до перегляду деталей плану.

## Використання на планшетах і мобільних пристроях

Вигляд для викладача працює на планшетах і мобільних пристроях:

- **Планшети** -- ідеально підходять викладачам, які хочуть мати портативний путівник по уроку.
- **Телефони** -- також підтримуються, хоча менший екран може бути менш зручним для викладання.
- **Альбомна орієнтація** -- забезпечує найкращий перегляд на мобільних пристроях.

## Відмінності від звичайного перегляду уроку

| Функція | Звичайний вигляд | Вигляд для викладача |
|---------|--------------|--------------|
| **Макет** | Компактний, вбудований у план | Повноекранний, окремий вигляд |
| **Навігація** | Лише прокручування | Список розділів + прокручування з заголовком поточного розділу |
| **Медіа** | Вбудовані на сторінку | Спливаючий програвач для зосередженого перегляду |
| **Простір екрана** | Показує інші елементи плану | Максимізований для вмісту уроку |
| **Найкраще для** | Перегляду та планування | Викладання та презентації |

## Найкращі практики

- **Підготовка заздалегідь** -- переглядайте уроки у вигляді для викладача до заняття, щоб ознайомитися з макетом.
- **Позначайте розділи** -- відзначайте, які розділи містять ключові активності чи обговорення.
- **Перевіряйте медіа** -- переконайтеся, що відео та зображення завантажуються правильно до початку заняття.
- **Завантажуйте ресурси заздалегідь** -- не чекайте до заняття, щоб завантажити матеріали для друку.
- **Використовуйте більший екран** -- проєктуйте або використовуйте планшет для найкращого досвіду викладання.

## Усунення несправностей

### Урок не відкривається у вигляді для викладача

- Переконайтеся, що урок правильно запланований у плані.
- Перевірте, чи маєте ви дозвіл на перегляд плану.
- Оновіть сторінку і спробуйте знову.

### Відео не відтворюються

- Перевірте підключення до інтернету.
- Переконайтеся, що ваш пристрій дозволяє відтворення медіа.
- Спробуйте відкрити відео в окремій вкладці.
- Деякі постачальники контенту можуть мати обмеження на відтворення відео.

### Вміст обрізано на мобільному пристрої

- Поверніть пристрій у альбомну орієнтацію.
- За потреби трохи зменште масштаб.
- Розгляньте використання планшета або більшого пристрою для кращої видимості.
