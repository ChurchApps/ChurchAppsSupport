# Показ і експорт пісень WorshipCommons

<div class="article-intro">

WorshipCommons може виводити текст пісні на екран прямо з браузера, без жодного встановлення. Якщо у вашій церкві вже використовується програмне забезпечення для презентацій, натомість завантажте слайди пісні для FreeShow, OpenLP, ProPresenter або PowerPoint чи додайте пісню до своєї бібліотеки пісень B1 Admin.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Відкрийте сторінку пісні на [worshipcommons.org](https://worshipcommons.org). Див. [Пошук пісень](./finding-songs.md).
- Щоб показати текст на телевізорі або проєкторі, підключіть комп'ютер до нього кабелем HDMI (або транслюйте екран).

</div>

## Проведення богослужіння в браузері

**Провести богослужіння** — це повноекранний перегляд, який відтворює музику та показує слова рядок за рядком, підсвічуючи кожне слово під час співу. Він призначений для невеликої групи, класу або домашньої церкви без гурту.

1. На сторінці пісні натисніть **Провести богослужіння**. (Кнопка з'являється, якщо для пісні є музика для супроводу.)
2. Виберіть **Тональність** і **Темп**. Коли пісня програє попередній перегляд на фортепіано, можна вибрати **Фортепіано** або **Орган**.
3. Натисніть **Куплети**, щоб вибрати, які куплети співати, і змінити їх порядок за допомогою кнопок зі стрілками.
4. Увімкніть **Відлік**, якщо хочете почути відлік перед початком музики.
5. Натисніть **▶ Відтворити**.

Використовуйте **Приховати**, щоб сховати слова, **Контраст** для висококонтрастного екрана та **Повноекранний режим**, щоб заповнити весь екран. Натисніть **Вивести на телевізор**, щоб отримати короткі кроки для показу на телевізорі.

:::tip
Комбінації клавіш: **Пробіл** — відтворити або призупинити, **← →** — перейти до рядка, **↑ ↓** — перейти до куплета, **B** — приховати, **H** — контраст, **F** — повноекранний режим, **Esc** — повернутися до пісні. Натисніть **Показати клавіші** внизу екрана, щоб їх побачити.
:::

## Проєктування тексту

**Відкрити проєктор** показує на екрані один розділ тексту, а ви переходите між розділами вручну. Використовуйте цей режим, коли у вас грають живі музиканти.

1. На сторінці пісні знайдіть панель **Проєкція** і натисніть **Відкрити проєктор**.
2. Натисніть **F** або **Повноекранний режим**, щоб заповнити екран.
3. Клацніть на екран або натисніть **Пробіл** чи клавішу **→**, щоб перейти до наступного слайда. Натисніть **←**, щоб повернутися назад. Клацніть назву розділу внизу, щоб одразу перейти до нього.
4. Натисніть **B**, щоб приховати екран, і **H** для високого контрасту.
5. Коли закінчите, натисніть **Esc** (або **← Назад до пісні**).

Нижня панель показує поточний розділ, кількість слайдів і наступний розділ. Рядок з авторством пісні також з'являється на екрані.

## Експорт слайдів

На панелі **Проєкція** на сторінці пісні є кнопка для кожного інструмента. Натисніть одну, щоб завантажити пісню:

| Кнопка | Що ви отримаєте |
| --- | --- |
| **FreeShow** | Файл показу для імпорту у [FreeShow](https://freeshow.app) |
| **PowerPoint** | Презентацію у форматі PPTX |
| **OpenLP** | Файл OpenLyrics для імпорту в OpenLP |
| **ProPresenter** | Текстовий файл для імпорту в ProPresenter |
| **OnSong / PCO** | Копіює пісню в буфер обміну для вставки в OnSong або Planning Center |

Примітка під кнопками пояснює, як поділено слайди. Якщо для пісні є затверджена карта форм, слайди їй відповідають; інакше слайди йдуть за куплетами у тому порядку, у якому вони записані. Кожен експорт містить авторство пісні та інформацію про ліцензію.

:::tip
Щоб експортувати весь набір одразу, у вибраних тональностях і розділах, створіть [план служіння](./service-plans.md) і скористайтеся там кнопками експорту.
:::

## Додавання пісень WorshipCommons до B1

Якщо ваша церква планує служіння в B1 Admin, нічого завантажувати не потрібно. Готові до недільного служіння пісні з WorshipCommons з'являються в пошуку пісень B1 Admin у розділі **WorshipCommons — безкоштовно**. Натисніть на одну з них, щоб додати її до бібліотеки пісень. Вона матиме посилання на сторінку WorshipCommons.

Кроки див. у розділі [Пісні в B1 Admin](../b1-admin/serving/songs.md#free-songs-from-worshipcommons).
