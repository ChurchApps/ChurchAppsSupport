# Розгортання веб-застосунку

<div class="article-intro">

Веб-застосунки ChurchApps розгортаються як статичні сайти в **Amazon S3** з **CloudFront** як CDN. Розгортання автоматизовано через GitHub Actions, але за потреби його також можна запустити вручну.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Налаштуйте веб-застосунок локально та переконайтеся, що він збирається -- див. [Веб-застосунки](../web-apps/)
- Налаштуйте облікові дані AWS з доступом до S3 і CloudFront
- Знайте назву цільового бакета S3 та ідентифікатор дистрибуції CloudFront

</div>

## Кроки розгортання

1. **Зберіть застосунок** -- згенеруйте статичний результат:

   ```bash
   npm run build
   ```

2. **Синхронізуйте з S3** -- завантажте результат збірки до бакета S3:

   ```bash
   aws s3 sync build/ s3://bucket-name
   ```

3. **Інвалідуйте CloudFront** -- очистіть кеш CDN, щоб користувачі отримали останню версію:

   ```bash
   aws cloudfront create-invalidation --distribution-id YOUR_DIST_ID --paths "/*"
   ```

## Автоматичне розгортання

Робочі процеси GitHub Actions автоматично виконують розгортання під час надсилання змін до гілки `main`. Робочий процес виконує всі три кроки вище -- збірку, синхронізацію з S3 та інвалідацію CloudFront -- без втручання вручну.

:::info
Зазвичай ці команди вручну запускати не потрібно. Злиття pull request у `main` запускає автоматизований конвеєр розгортання.
:::

:::tip
Якщо потрібно перевірити збірку локально перед розгортанням, запустіть `npm run build` і перегляньте результат у каталозі `build/`. Ви можете обслуговувати його будь-яким сервером статичних файлів, щоб переконатися, що все працює.
:::
