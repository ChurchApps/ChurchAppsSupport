# Документація для розробників

<div class="article-intro">

ChurchApps — це колекція з близько 20 проєктів з відкритим вихідним кодом, які разом утворюють повноцінну платформу для управління церквою. Проєкти охоплюють бекенд-API, веб-застосунки, мобільні застосунки, настільний застосунок і спільні бібліотеки — усі написані мовою TypeScript. Цей розділ містить усе необхідне для налаштування локального середовища розробки та початку участі в проєкті.

</div>

## Архітектура загалом

Проєкти є **незалежними репозиторіями** (а не монорепозиторієм). Спільний код публікується в npm у просторі імен `@churchapps/*` і підключається як звичайні залежності. Це означає, що ви можете працювати з окремим проєктом, не клонуючи всю екосистему.

Ключові особливості:

- **Мова:** TypeScript у всьому проєкті
- **Бекенд:** API на Node.js / Express, розгорнуті в AWS Lambda через Serverless Framework
- **Веб:** React 19 (Vite і Next.js), Material-UI 7
- **Мобільні застосунки:** React Native з Expo
- **База даних:** MySQL 8.0, окрема база даних для кожного модуля API
