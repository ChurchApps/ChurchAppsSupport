# Документація для розробників

<div class="article-intro">

ChurchApps — це колекція з приблизно 20 проєктів з відкритим вихідним кодом, які разом утворюють повну платформу для керування церквою. Проєкти охоплюють бекенд API, веб-застосунки, мобільні застосунки, настільний застосунок і спільні бібліотеки, і всі вони написані на TypeScript. Цей розділ містить усе, що потрібно для налаштування локального середовища розробки та початку роботи над проєктом.

</div>

## Архітектура загалом

Проєкти є **незалежними репозиторіями** (а не монорепозиторієм). Спільний код публікується в npm в області `@churchapps/*` і використовується як звичайні залежності. Це означає, що ви можете працювати з окремим проєктом, не клонуючи всю екосистему.

Основні характеристики:

- **Мова:** TypeScript у всіх проєктах
- **Бекенд:** API на Node.js / Express, які розгортаються в AWS Lambda через Serverless Framework
- **Веб:** React 19 (Vite і Next.js), Material-UI 7
- **Мобільні застосунки:** React Native з Expo
- **База даних:** MySQL 8.0, окрема база даних для кожного модуля API

- **[Налаштування](setup/)** — локальне середовище розробки, необхідні компоненти та конфігурація

  - [Огляд проєктів](setup/project-overview) — усі проєкти в одному місці
  - [Змінні середовища](setup/environment-variables) — налаштування файлів `.env`
- **[API](api/)** — локальне налаштування основного API, ініціалізація бази даних і структура модулів
- **[Веб-застосунки](web-apps/)** — локальний запуск B1Admin, B1App і LessonsApp
- **[Мобільні застосунки](mobile/)** — збірка B1Mobile та інших застосунків Expo
- **[Спільні бібліотеки](shared-libraries/)** — робота з Helpers, ApiHelper і AppHelper
- **[Розгортання](deployment/)** — розгортання API, веб-застосунків і мобільних застосунків
- **[Провайдер контенту FreePlay](freeplay-content-provider)** — інтеграція вашої бібліотеки уроків з FreePlay
