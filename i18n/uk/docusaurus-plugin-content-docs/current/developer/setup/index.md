# Налаштування

<div class="article-intro">

Цей розділ допоможе вам налаштувати локальне середовище розробки для проєктів ChurchApps. Ви можете або спрямувати свій фронтенд на спільні демо-API для швидкої розробки, або запустити повний стек локально для роботи з бекендом.

</div>

## Два підходи

Існує два способи локальної розробки, залежно від того, скільки частин стеку вам потрібно:

### 1. Використання демо-API (найпростіше)

Якщо ви працюєте над **фронтенд-проєктом** (веб-застосунок, мобільний застосунок або настільний застосунок), найшвидший шлях — спрямувати ваш локальний застосунок на спільні демо-API. Не потрібна ні база даних, ні налаштування бекенду.

Базова URL-адреса демо-API:

```
https://api.demo.churchapps.org
```

Кожен модуль API доступний за шляхом під цією базовою адресою, наприклад:

```
https://api.demo.churchapps.org/membership
https://api.demo.churchapps.org/attendance
https://api.demo.churchapps.org/giving
```

Демо-середовище працює на останньому коді з `main`, а його тестові дані щоночі наповнюються заново, тому не очікуйте, що створене там збережеться. (Колишнє тестове середовище, `api.staging.churchapps.org`, було вимкнено. Деякі зразки файлів `.env` можуть досі містити URL тестового середовища — замініть їх на демо- або локальні URL.)

:::tip
Цей підхід дозволяє почати вносити зміни у фронтенд за лічені хвилини. Він рекомендований для більшості учасників.
:::

### 2. Запуск усього локально

Якщо вам потрібно змінювати код API або працювати без інтернету, можна запустити повний стек локально. Для цього потрібен MySQL 8.0+ та додаткове налаштування. Докладні інструкції дивіться у посібнику [локальне налаштування API](../api/local-setup.md).

## Початок роботи

Виконуйте ці сторінки в такому порядку:

1. **[Передумови](./prerequisites.md)** -- Встановіть необхідні інструменти (Node.js, Git, MySQL тощо)
2. **[Огляд проєкту](./project-overview.md)** -- Дізнайтеся, які проєкти існують і що вони роблять
3. **[Змінні середовища](./environment-variables.md)** -- Налаштуйте файли `.env`, щоб усе був пов'язано між собою

:::info
Кожен проєкт ChurchApps є окремим Git-репозиторієм. Клонуйте лише ті проєкти, з якими плануєте працювати.
:::
