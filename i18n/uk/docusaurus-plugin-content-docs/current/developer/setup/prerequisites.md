## Усі проєкти

Ці інструменти потрібні незалежно від того, над яким проєктом ви працюєте:

| Інструмент | Версія | Примітки |
|------|---------|-------|
| **Node.js** | 20+ | Для B1App і LessonsApp (Next.js 16) потрібна версія 22+; для Api — 24+ |
| **npm** | Постачається з Node.js | Використовується як менеджер пакетів у всіх проєктах |
| **Git** | Остання версія | Кожен проєкт є окремим репозиторієм |

:::tip
Для зручного перемикання між версіями Node скористайтеся менеджером версій, наприклад [nvm](https://github.com/nvm-sh/nvm) (macOS/Linux) або [nvm-windows](https://github.com/coreybutler/nvm-windows) (Windows).
:::

## Розробка серверної частини (API)

Якщо ви плануєте запускати API локально (а не підключатися до демонстраційних API):

| Інструмент | Версія | Примітки |
|------|---------|-------|
| **MySQL** | 8.0+ | Кожен модуль API використовує власну базу даних |

Для основного API знадобиться шість баз даних: `membership`, `attendance`, `content`, `giving`, `messaging` і `doing`. До складу API входять скрипти для ініціалізації схеми — див. посібник [Локальне налаштування API](../api/local-setup.md).

## Розробка мобільних застосунків

Для B1Checkin, LessonsScreen або інших застосунків на React Native / Expo:

| Інструмент | Версія | Примітки |
|------|---------|-------|
| **Expo CLI** | Остання версія | Встановлення глобально: `npm install -g expo-cli` |
| **Android Studio** | Остання версія | Потрібна для розробки під Android (включає Android SDK) |
| **Xcode** | Остання версія | Потрібна для розробки під iOS (лише macOS) |

:::info
Для швидкого тестування можна використовувати застосунок Expo Go на фізичному пристрої без Android Studio чи Xcode. Однак для створення промислових збірок потрібні нативні інструменти.
:::

## Розробка FreeShow (настільний застосунок)

FreeShow має додаткові залежності для нативної збірки, оскільки він компілює нативні модулі Node (наприклад, `canvas`):

### Усі платформи

| Інструмент | Версія | Примітки |
|------|---------|-------|
| **Python** | 3.12 | Потрібен для `node-gyp` під час компіляції нативних модулів |
| **setuptools** | Остання версія | Встановлення через `pip install setuptools` |

### Windows

| Інструмент | Примітки |
|------|-------|
| **Visual Studio** | Достатньо видання Community |
| **Робоче навантаження «Desktop development with C++»** | Виберіть під час встановлення Visual Studio |
| **Windows 10 SDK** | Входить до робочого навантаження C++; переконайтеся, що його вибрано |

Інструменти збірки Visual Studio можна встановити через командний рядок:

```bash
npm install --global windows-build-tools
```

Або встановіть Visual Studio Community і під час інсталяції виберіть робоче навантаження «Desktop development with C++».

### Linux

```bash
sudo apt-get install libfontconfig1-dev
```

### macOS

Зазвичай достатньо інструментів командного рядка Xcode:

```bash
xcode-select --install
```

## Перевірка встановлення

Виконайте ці команди, щоб переконатися, що все встановлено:

```bash
node --version    # Має вивести v20.x.x або вище
npm --version     # Має вивести 10.x.x або вище
git --version     # Має вивести git version 2.x.x
mysql --version   # Потрібно лише для локальної розробки API
```
