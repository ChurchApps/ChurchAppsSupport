## Усі проєкти

Ці інструменти потрібні незалежно від того, з яким проєктом ви працюєте:

| Інструмент | Версія | Примітки |
|------|---------|-------|
| **Node.js** | 20+ | Для B1App та LessonsApp (Next.js 16) потрібна версія 22+; для Api потрібна версія 24+ |
| **npm** | Постачається з Node.js | Використовується як менеджер пакетів у всіх проєктах |
| **Git** | Остання | Кожен проєкт є окремим репозиторієм |

:::tip
Щоб легко перемикатися між версіями Node, використовуйте менеджер версій, наприклад [nvm](https://github.com/nvm-sh/nvm) (macOS/Linux) або [nvm-windows](https://github.com/coreybutler/nvm-windows) (Windows).
:::

## Розробка бекенд-API

Якщо ви плануєте запускати API локально (а не звертатися до демонстраційних API):

| Інструмент | Версія | Примітки |
|------|---------|-------|
| **MySQL** | 8.0+ | Кожен модуль API використовує власну базу даних |

Для основного API знадобиться шість баз даних: `membership`, `attendance`, `content`, `giving`, `messaging` та `doing`. API містить скрипти для ініціалізації схеми — див. посібник [локальне налаштування API](../api/local-setup).

## Розробка мобільних застосунків

Для B1Mobile, B1Checkin, LessonsScreen або інших застосунків React Native / Expo:

| Інструмент | Версія | Примітки |
|------|---------|-------|
| **Expo CLI** | Остання | Встановлення глобально: `npm install -g expo-cli` |
| **Android Studio** | Остання | Потрібна для розробки під Android (включає Android SDK) |
| **Xcode** | Остання | Потрібна для розробки під iOS (лише macOS) |

:::info
Для швидкого тестування на фізичному пристрої можна використовувати застосунок Expo Go — без Android Studio чи Xcode. Однак для створення продакшн-збірок потрібні нативні інструментальні засоби.
:::

## Розробка FreeShow (настільний застосунок)

FreeShow має додаткові залежності для нативної збірки, оскільки компілює нативні модулі Node (наприклад, `canvas`):

### Усі платформи

| Інструмент | Версія | Примітки |
|------|---------|-------|
| **Python** | 3.12 | Потрібен для `node-gyp` під час компіляції нативних модулів |
| **setuptools** | Остання | Встановлення через `pip install setuptools` |

### Windows

| Інструмент | Примітки |
|------|-------|
| **Visual Studio** | Достатньо редакції Community |
| **Робоче навантаження "Desktop development with C++"** | Виберіть під час встановлення Visual Studio |
| **Windows 10 SDK** | Входить до робочого навантаження C++; переконайтеся, що його вибрано |

Інструменти збірки Visual Studio можна встановити через командний рядок:

```bash
npm install --global windows-build-tools
```

Або встановіть Visual Studio Community і під час інсталяції виберіть робоче навантаження "Desktop development with C++".

### Linux

```bash
sudo apt-get install libfontconfig1-dev
```

### macOS

Зазвичай достатньо інструментів командного рядка Xcode:

```bash
xcode-select --install
```

## Перевірка встановлення

Виконайте ці команди, щоб переконатися, що все встановлено:

```bash
node --version    # Має вивести v20.x.x або вище
npm --version     # Має вивести 10.x.x або вище
git --version     # Має вивести git version 2.x.x
mysql --version   # Потрібно лише для локальної розробки API
```
