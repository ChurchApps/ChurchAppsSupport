# API

<div class="article-intro">

API ChurchApps є **модульним моноліттом**: одна кодова база обслуговує шість модулів даних, кожен зі власною базою даних. Така архітектура дає організаційні переваги мікросервісів (чіткі межі, незалежні сховища даних) за операційної простоти єдиного розгортання.

</div>

## Модулі

| Модуль | Призначення |
|--------|-------------|
| **Membership** | Люди, групи, домогосподарства, дозволи |
| **Attendance** | Служіння, сесії, записи реєстрації |
| **Content** | Сторінки, розділи, елементи, трансляції |
| **Giving** | Пожертви, фонди, обробка платежів |
| **Messaging** | Розмови, сповіщення, електронна пошта |
| **Doing** | Завдання, плани, призначення |

## Технологічний стек

- **Середовище виконання:** Node.js 24.x з TypeScript (модулі ES)
- **Фреймворк:** Express
- **Впровадження залежностей:** Inversify (маршрутизація на основі декораторів)
- **База даних:** MySQL -- окрема база даних для кожного модуля, кожна зі своїм пулом з'єднань
- **Автентифікація:** автентифікація на основі JWT через `CustomAuthProvider`
- **Розгортання:** AWS Lambda через Serverless Framework v3

## Порти

| Протокол | Порт | Опис |
|----------|------|------|
| HTTP | `8084` | Основний REST API |
| WebSocket | `8087` | Підключення WebSocket у реальному часі |

## Функції Lambda

Під час розгортання в AWS API працює як шість функцій Lambda:

- **`web`** -- Обробляє всі HTTP-запити
- **`socket`** -- Керує підключеннями WebSocket
- **`timer15Min`** -- Запускається кожні 30 хвилин для надсилання сповіщень електронною поштою (назва є історичною)
- **`timerMidnight`** -- Запускається щодня для надсилання дайджестів електронною поштою та виконання завдань технічного обслуговування
- **`timerScheduledTasks`** -- Запускається щодня для виконання автоматизацій, що настали, та обробки прострочених робочих процесів
- **`timerWebhooks`** -- Запускається щохвилини для доставки вихідних вебхуків із черги

## Спільні бібліотеки

API залежить від двох спільних пакетів ChurchApps:

- **[`@churchapps/helpers`](../shared-libraries/helpers)** -- Базові утиліти (DateHelper, ApiHelper тощо)
- **[`@churchapps/apihelper`](../shared-libraries/api-helper)** -- Утиліти сервера Express, включно з автентифікацією, допоміжними засобами для роботи з базами даних та інтеграціями з AWS

:::info
API використовує модулі ES (`"type": "module"` у `package.json`). Переконайтеся, що ваші імпорти використовують синтаксис модулів ES.
:::
