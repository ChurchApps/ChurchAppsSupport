# Ендпоінти відвідуваності

<div class="article-intro">

Модуль відвідуваності керує локаціями кампусів, службами, часами служб, сесіями відвідуваності, візитами та сесіями візитів. Він забезпечує інфраструктуру для відстеження того, хто відвідав яку службу чи зустріч групи, підтримує процеси реєстрації та пропонує звіти про тенденції й підсумки відвідуваності.

</div>

**Базовий шлях:** `/attendance`

## Кампуси

Базовий шлях: `/attendance/campuses`

Стандартний контролер CRUD (успадковує GenericCrudController). Надає маршрути `getById`, `getAll`, `post` і `delete` через базовий клас CRUD.

| Метод | Шлях | Автентифікація | Дозвіл | Опис |
|--------|------|------------|------------|-------------|
| GET | `/` | JWT | — | Отримати список усіх кампусів церкви |
| GET | `/:id` | JWT | — | Отримати кампус за ID |
| POST | `/` | JWT | Services.Edit | Створити або оновити кампуси |
| DELETE | `/:id` | JWT | Services.Edit | Видалити кампус |

## Служби

Базовий шлях: `/attendance/services`

Успадковує GenericCrudController з маршрутами CRUD `getById`, `getAll`, `post` і `delete`. Ендпоінти `getAll` (`GET /`) та `search` перевизначено власними реалізаціями.

| Метод | Шлях | Автентифікація | Дозвіл | Опис |
|--------|------|------------|------------|-------------|
| GET | `/` | JWT | — | Отримати список усіх служб (включає інформацію про кампус) |
| GET | `/:id` | JWT | — | Отримати службу за ID |
| GET | `/search?campusId=` | JWT | — | Шукати служби за ID кампусу |
| POST | `/` | JWT | Services.Edit | Створити або оновити служби |
| DELETE | `/:id` | JWT | Services.Edit | Видалити службу |

### Приклад: пошук служб за кампусом

```
GET /attendance/services/search?campusId=abc-123
Authorization: Bearer <token>
```

```json
[
  {
    "id": "svc-001",
    "churchId": "church-123",
    "campusId": "abc-123",
    "name": "Sunday Morning"
  }
]
```

## Часи служб

Базовий шлях: `/attendance/servicetimes`

Успадковує GenericCrudController з маршрутами CRUD `getById`, `post` і `delete`. Ендпоінти `getAll` та `search` мають власні реалізації.

| Метод | Шлях | Автентифікація | Дозвіл | Опис |
|--------|------|------------|------------|-------------|
| GET | `/` | JWT | — | Отримати список усіх часів служб. Фільтр за `?serviceId=`. Додайте `?include=groups`, щоб долучити дані груп. Кожен рядок містить обчислене логічне значення `checkinOpen` (false лише тоді, коли для часу служби задано розклад реєстрації, а його вікно зараз закрите). Вікно вимірюється в часовому поясі кампусу служби, далі в часовому поясі церкви, потім у часовому поясі першого кампусу, який його має, і нарешті America/New_York |
| GET | `/:id` | JWT | — | Отримати час служби за ID |
| GET | `/search?campusId=&serviceId=` | JWT | — | Шукати часи служб за кампусом і службою |
| GET | `/public/:churchId` | Публічний | — | Отримати дерево кампус → служба → час для церкви. Забезпечує елемент `serviceTimes` у конструкторі веб-сайту |
| POST | `/` | JWT | Services.Edit | Створити або оновити часи служб. Необов’язкові поля розкладу: `dayOfWeek` (0 = неділя … 6), `startTime` / `endTime` (`HH:mm`), `checkinOpenMinutes` (до початку), `checkinCloseMinutes` (після завершення). Реєстрація обмежується часом, лише якщо задано і `dayOfWeek`, і `startTime` |
| DELETE | `/:id` | JWT | Services.Edit | Видалити час служби |

## Групові часи служб

Базовий шлях: `/attendance/groupservicetimes`

Пов’язує групи з конкретними часами служб.

| Метод | Шлях | Автентифікація | Дозвіл | Опис |
|--------|------|------------|------------|-------------|
| GET | `/` | JWT | — | Отримати список усіх зв’язків групи з часом служби. Фільтр за `?groupId=` дозволяє отримати зв’язки з назвами служб |
| GET | `/:id` | JWT | — | Отримати зв’язок групи з часом служби за ID |
| POST | `/` | JWT | Services.Edit | Створити або оновити зв’язки групи з часом служби |
| DELETE | `/:id` | JWT | Services.Edit | Видалити зв’язок групи з часом служби |

## Записи відвідуваності

Базовий шлях: `/attendance/attendancerecords`

Надає доступні лише для читання агреговані подання даних відвідуваності для звітності та відображення.

| Метод | Шлях | Автентифікація | Дозвіл | Опис |
|--------|------|------------|------------|-------------|
| GET | `/` | JWT | Attendance.View | Завантажити записи відвідуваності для особи. Потрібен `?personId=` |
| GET | `/my` | JWT | — | Лише для власних даних: записи відвідуваності авторизованого учасника за останні 12 місяців, від найновіших. Повертає `401`, якщо користувача не пов’язано з особою. Забезпечує розділ **Моя відвідуваність** на сторінці B1 Me |
| GET | `/tree` | JWT | — | Завантажити повне дерево відвідуваності (кампуси, служби, часи служб, групи) |
| GET | `/trend?campusId=&serviceId=&serviceTimeId=&groupId=` | JWT | Attendance.View Summary | Завантажити дані про тенденції відвідуваності з необов’язковими фільтрами |
| GET | `/groups?serviceId=&week=` | JWT | Attendance.View | Завантажити відвідуваність груп для служби за певний тиждень |
| GET | `/sessionStatus?serviceTimeId=&date=` | JWT | Attendance.View | Для кожної групи, призначеної до часу служби, повернути `{ groupId, sessionId, attendanceCount }` за цю дату (`date` у форматі `YYYY-MM-DD`; `sessionId` має значення null, якщо в групи немає сесії). Забезпечує діалог **Who Still Needs Attendance** в B1Admin |
| GET | `/search?campusId=&serviceId=&serviceTimeId=&groupId=&startDate=&endDate=` | JWT | Attendance.View | Шукати записи відвідуваності з фільтрами (кампус, служба, час служби, група, діапазон дат) |

### Приклад: тенденції відвідуваності

```
GET /attendance/attendancerecords/trend?serviceId=svc-001
Authorization: Bearer <token>
```

```json
[
  { "week": "2025-01-05", "count": 142 },
  { "week": "2025-01-12", "count": 156 },
  { "week": "2025-01-19", "count": 138 }
]
```

## Сесії

Базовий шлях: `/attendance/sessions`

Успадковує GenericCrudController з маршрутами CRUD `getById` і `delete`. Ендпоінти `getAll` і `save` мають власні реалізації, які також дозволяють керівникам груп керувати сесіями своїх груп.

| Метод | Шлях | Автентифікація | Дозвіл | Опис |
|--------|------|------------|------------|-------------|
| GET | `/` | JWT | Attendance.View або керівник групи | Отримати список усіх сесій. Фільтр за `?groupId=` (включає назви). Керівники груп можуть переглядати сесії своїх груп |
| GET | `/:id` | JWT | Attendance.View | Отримати сесію за ID |
| POST | `/` | JWT | Attendance.Edit або керівник групи | Створити або оновити сесії. Керівники груп можуть зберігати сесії для своїх груп |
| DELETE | `/:id` | JWT | Attendance.Edit | Видалити сесію |

## Візити

Базовий шлях: `/attendance/visits`

Керує окремими записами візитів (особа відвідує конкретну дату) і забезпечує процес реєстрації.

| Метод | Шлях | Автентифікація | Дозвіл | Опис |
|--------|------|------------|------------|-------------|
| GET | `/` | JWT | Attendance.View | Отримати список усіх візитів. Фільтр за `?personId=` |
| GET | `/:id` | JWT | Attendance.View | Отримати візит за ID |
| GET | `/checkin?serviceId=&peopleIds=` | JWT | Attendance.View або Attendance.Checkin | Завантажити дані реєстрації осіб на службі. Повертає візити з сесіями візитів за останню зафіксовану дату |
| POST | `/` | JWT | Attendance.Edit | Створити або оновити візити |
| POST | `/checkin?serviceId=&peopleIds=` | JWT | Attendance.Edit або Attendance.Checkin | Надіслати дані реєстрації. Створює й оновлює візити та сесії візитів, видаляє застарілі записи |
| DELETE | `/:id` | JWT | Attendance.Edit | Видалити візит |

### Приклад: процес реєстрації

**Крок 1 — Завантаження наявних даних реєстрації:**

```
GET /attendance/visits/checkin?serviceId=svc-001&peopleIds=person-1,person-2
Authorization: Bearer <token>
```

```json
[
  {
    "id": "visit-001",
    "personId": "person-1",
    "visitDate": "2025-01-19T00:00:00.000Z",
    "visitSessions": [
      {
        "id": "vs-001",
        "sessionId": "sess-001",
        "visitId": "visit-001",
        "session": {
          "id": "sess-001",
          "groupId": "group-001",
          "serviceTimeId": "st-001",
          "sessionDate": "2025-01-19T00:00:00.000Z"
        }
      }
    ]
  }
]
```

**Крок 2 — Надсилання реєстрації:**

```
POST /attendance/visits/checkin?serviceId=svc-001&peopleIds=person-1,person-2
Authorization: Bearer <token>

[
  {
    "personId": "person-1",
    "visitSessions": [
      {
        "session": { "serviceTimeId": "st-001", "groupId": "group-001" }
      }
    ]
  }
]
```

Якщо цільовий час служби має розклад реєстрації, а його вікно закрите (вимірюється в тому самому порядку часових поясів, що й у `checkinOpen`, із пріоритетом кампусу), нічого не зберігається, а відповідь має вигляд `409 { "error": "notOpen", "groups": [{ "groupId", "groupName", "reason": "notOpen" }] }`. Порушення ліміту місць і співвідношення волонтерів також повертають 409 (`error: "capacity"` або `"ratio"`). Сесії, які особа вже має на сьогодні (повторно надіслані з кожною реєстрацією), не перевіряються за вікном часу, тож домогосподарство може додати відкритий час служби після того, як вікно попереднього вже закрилося.

## Сесії візитів

Базовий шлях: `/attendance/visitsessions`

Керує зв’язком між візитами та сесіями (на якій конкретній сесії особа була під час візиту). Також надає швидкий ендпоінт реєстрації та ендпоінт завантаження/експорту.

| Метод | Шлях | Автентифікація | Дозвіл | Опис |
|--------|------|------------|------------|-------------|
| GET | `/` | JWT | Attendance.View або керівник групи | Отримати список сесій візитів. Фільтр за `?sessionId=`. Керівники груп можуть переглядати сесії візитів своїх груп |
| GET | `/:id` | JWT | Attendance.View | Отримати сесію візиту за ID |
| GET | `/download/:sessionId` | JWT | Attendance.View | Завантажити відвідуваність сесії (повертає імена осіб зі статусом присутності або відсутності) |
| POST | `/` | JWT | Attendance.Edit | Створити або оновити сесії візитів |
| POST | `/log` | JWT | Attendance.Edit або керівник групи | Швидко зафіксувати відвідуваність особи в сесії. Автоматично створює візит, якщо це потрібно. Керівники груп можуть фіксувати відвідуваність для своїх груп |
| DELETE | `/:id` | JWT | Attendance.Edit | Видалити сесію візиту за ID |
| DELETE | `/?personId=&sessionId=` | JWT | Attendance.Edit або керівник групи | Вилучити особу з сесії. Видаляє сесію візиту, а також батьківський візит, якщо не залишилося жодної сесії. Керівники груп можуть вилучати відвідуваність для своїх груп |

### Приклад: швидка фіксація відвідуваності

```
POST /attendance/visitsessions/log
Authorization: Bearer <token>

{
  "personId": "person-001",
  "visitSessions": [
    { "sessionId": "sess-001" }
  ]
}
```

```json
{}
```

## Серії відвідувань

Базовий шлях: `/attendance/streaks`

Відстежує серії відвідувань окремих людей — кількість тижнів поспіль, протягом яких особа відвідувала служби. Корисно для метрик залученості та геймифікації.

| Метод | Шлях | Автентифікація | Дозвіл | Опис |
|--------|------|------------|------------|-------------|
| GET | `/person/:personId` | JWT | — | Завантажити серії відвідувань для особи |
