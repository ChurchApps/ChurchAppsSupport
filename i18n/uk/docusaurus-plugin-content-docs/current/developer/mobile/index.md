# Мобільні застосунки

<div class="article-intro">

Мобільні застосунки ChurchApps створено на основі **React Native** та **Expo**. Вони забезпечують нативний досвід роботи на Android, iOS і Android TV. Усі мобільні застосунки використовують один і той самий інструментарій на основі Expo, тож якщо ви вмієте збирати один із них, ви зможете зібрати й інші.

</div>

## Застосунки

| Застосунок | Призначення | Платформа |
|-----|---------|----------|
| [B1 Mobile](./b1-mobile.md) | Основний застосунок для членів церкви | Android, iOS |
| B1 Checkin | Кіоск для станцій реєстрації | Android, iOS |
| LessonsScreen | Застосунок для Android TV для показу уроків у класах | Android TV |

### B1 Mobile

Основний застосунок для членів церкви. За його допомогою користувачі можуть переглядати каталоги, отримувати доступ до пожертв, відмічати відвідуваність, отримувати сповіщення та взаємодіяти зі своєю церковною спільнотою. Докладніше дивіться в [посібнику з налаштування B1 Mobile](./b1-mobile.md).

### B1 Checkin

Спеціалізований застосунок-кіоск для станцій реєстрації в церквах. Він має простий інтерфейс, зручний для сенсорного керування, і дає змогу членам церкви реєструвати дітей та фіксувати відвідуваність богослужінь і заходів.

### LessonsScreen

Застосунок для Android TV, який показує навчальні матеріали в класах. Викладачі можуть надсилати слайди уроків, відео та завдання на екран телевізора, що спрощує подачу навчального матеріалу під час занять.

:::info
Усі мобільні застосунки використовують один і той самий інструментарій на основі Expo та дотримуються схожих процедур налаштування. Посібник [B1 Mobile](./b1-mobile.md) слугує довідником із загального процесу налаштування для всіх мобільних проєктів.
:::
