# Мобільні застосунки

<div class="article-intro">

Мобільні застосунки ChurchApps створено на основі **React Native** та **Expo**. Вони забезпечують нативний досвід роботи на Android, iOS і Android TV. Усі мобільні застосунки використовують один спільний інструментарій на основі Expo, тож якщо ви вмієте зібрати один із них, то зможете зібрати й решту.

</div>

## Застосунки

| Застосунок | Призначення | Платформа |
|-----|---------|----------|
| B1 Checkin | Кіоск-застосунок для станцій реєстрації | Android, iOS |
| LessonsScreen | Застосунок для Android TV для показу уроків у класах | Android TV |

:::info
Застосунок для учасників громади — це B1 App, тобто розділ `/mobile` у B1App, який учасники встановлюють як прогресивний веб-застосунок (PWA). Це веб-застосунок, а не проєкт Expo. Щоб запустити його локально, див. [Веб-застосунки](../web-apps/index.md).
:::

### B1 Checkin

Спеціалізований кіоск-застосунок для станцій реєстрації в церквах. Він надає простий інтерфейс, зручний для сенсорного керування, щоб учасники могли реєструвати дітей і фіксувати відвідуваність богослужінь та заходів.

### LessonsScreen

Застосунок для Android TV, який відображає навчальний матеріал у класах. Викладачі можуть надсилати слайди уроків, відео та завдання на екран телевізора, що спрощує показ навчальних матеріалів під час занять.

## Локальне налаштування

Усі мобільні застосунки використовують один спільний інструментарій на основі Expo і дотримуються подібних кроків налаштування. Як приклад розглянемо B1 Checkin:

1. Встановіть **Node.js**, Android Studio (для емулятора Android) і Xcode (для симулятора iOS, лише для macOS). Див. [Передумови](../setup/prerequisites.md).
2. Клонуйте репозиторій і встановіть залежності (B1 Checkin використовує Yarn):

   ```bash
   git clone https://github.com/ChurchApps/B1Checkin.git
   cd B1Checkin && yarn install
   ```

3. Скопіюйте `dotenv.sample.txt` до `.env` і вкажіть стейдж, до якого застосунок має підключатися (`dev` для локального API). Див. [Змінні середовища](../setup/environment-variables.md#b1checkin-react-native--expo).
4. Запустіть сервер розробки Expo командою `yarn start`, а потім виконайте `yarn android` або `yarn ios`, щоб запустити застосунок на емуляторі чи пристрої.

Про релізні збірки та оновлення Over-the-Air див. [Розгортання мобільних застосунків](../deployment/mobile.md).
