# Веб-застосунки

<div class="article-intro">

ChurchApps включає три веб-застосунки, кожна з яких призначена для різної аудиторії та мети. Вони використовують спільну технологічну основу: React 19, TypeScript і Material-UI 7, але відрізняються інструментами збірки та цільовими платформами розгортання.

</div>

## Застосунки з першого погляду

| Застосунок | Призначення | Фреймворк | Порт для розробки |
|-----|---------|-----------|----------|
| [**B1Admin**](./b1-admin.md) | Панель адміністрування церкви | React 19 + Vite + MUI 7 | 5173 |
| [**B1App**](./b1-app.md) | Публічний застосунок для членів церкви | Next.js 16 + React 19 + MUI 7 | 3301 |
| [**LessonsApp**](./lessons-app.md) | Керування контентом уроків | Next.js 16 + React 19 | 3501 |

## Спільний технологічний стек

Усі три веб-застосунки створено з використанням:

- **TypeScript** -- повна типізація від початку до кінця
- **React 19** -- бібліотека UI-компонентів
- **Material-UI 7** -- система дизайну та набір компонентів
- **React Query 5** -- керування станом серверних даних

## Спільні компоненти

Застосунки використовують спільні UI-компоненти та утиліти через сімейство пакетів `@churchapps/apphelper*`:

| Пакет | Призначення |
|---------|---------|
| `@churchapps/apphelper` | Основні спільні React-компоненти |
| `@churchapps/apphelper-login` | UI-компоненти автентифікації |
| `@churchapps/apphelper-donations` | Форми пожертв і внесків |
| `@churchapps/apphelper-forms` | Компоненти конструктора форм |
| `@churchapps/apphelper-markdown` | Відображення Markdown |
| `@churchapps/apphelper-website` | Компоненти веб-сайту та CMS |

:::tip
Щоб дізнатися більше про локальну розробку цих спільних пакетів, див. документацію [AppHelper](../shared-libraries/app-helper.md).
:::

## Скрипт postinstall

Кожен веб-застосунок має скрипт `postinstall`, який копіює файли локалізації та CSS-ресурси з `@churchapps/apphelper` до проєкту. Він виконується автоматично після `npm install`.

:::info
Якщо компоненти виглядають без стилів після встановлення залежностей, скрипт `postinstall` міг не виконатися належним чином. Ви можете запустити його вручну командою `npm run postinstall`.
:::

## Інструменти збірки

Застосунки використовують два різні інструменти збірки:

- **B1Admin** використовує **Vite** -- швидкий сучасний збирач, ідеальний для односторінкових застосунків
- **B1App** і **LessonsApp** використовують **Next.js** -- що забезпечує рендеринг на сервері, маршрутизацію на основі файлів і оптимізовані продакшн-збірки
