# B1App

<div class="article-intro">

B1App — це публічний застосунок для членів церкви, побудований на Next.js. Він забезпечує досвід для членів, зокрема профілі, каталоги груп, пряму трансляцію та сторінки пожертв.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Встановіть **Node.js 22+** та **Git** -- див. [Передумови](../setup/prerequisites)
- Налаштуйте адресу API (демонстраційну або локальну) -- див. [Змінні середовища](../setup/environment-variables)

</div>

:::warning
B1App потребує Node.js 22 або новішої версії. Старіші версії не підтримуються.
:::

## Налаштування

### 1. Клонуйте репозиторій

```bash
git clone https://github.com/ChurchApps/B1App.git
```

### 2. Встановіть залежності

```bash
cd B1App
npm install
```

### 3. Налаштуйте змінні середовища

```bash
cp dotenv.sample.txt .env
```

Відкрийте `.env` і налаштуйте URL-адреси кінцевих точок `NEXT_PUBLIC_*_API`. Вони можуть вказувати на спільний демонстраційний API (`https://api.demo.churchapps.org`) або на ваш локальний екземпляр API. Зразковий файл може все ще містити застарілі URL-адреси тестового середовища; замініть їх.

### 4. Запустіть сервер розробки

```bash
npm run dev
```

Сервер розробки Next.js запускається за адресою [http://localhost:3301](http://localhost:3301).

## Основні команди

| Команда | Опис |
|---------|------|
| `npm run dev` | Запустити сервер розробки Next.js на порту 3301 |
| `npm run build` | Виробнича збірка через Next.js |
| `npm run test` | Запустити наскрізні тести за допомогою Playwright |
| `npm run lint` | Запустити лінтер Next.js |

## Основні змінні середовища

| Змінна | Опис |
|--------|------|
| `NEXT_PUBLIC_*_API` | URL-адреси кінцевих точок API для кожного модуля |

:::info
Скрипт `postinstall` копіює файли локалізації та CSS з `@churchapps/apphelper`. Якщо компоненти виглядають без стилів після встановлення, виконайте `npm run postinstall` вручну.
:::

## Технологічний стек

- **Next.js 16** з TypeScript
- **React 19** для компонентів інтерфейсу
- **Material-UI 7** для системи дизайну
- **React Query 5** для стану на сервері
- **`@churchapps/apphelper*`** пакети для спільних компонентів

## Розгортання

Виробничі збірки розгортаються на **S3 + CloudFront**:

1. `npm run build` створює оптимізовану збірку Next.js
2. Результат збірки синхronізується з кошиком S3
3. Запускається інвалідація CloudFront, щоб відображати нову версію

:::tip
Докладні інструкції щодо розгортання див. у посібнику [Розгортання веб-застосунків](../deployment/web-apps).
:::
