# B1 Admin

<div class="article-intro">

B1Admin — це панель адміністрування церкви, односторінковий застосунок (SPA) на React, побудований на Vite та Material-UI. Працівники церкви використовують її для керування людьми, групами, відвідуваністю, пожертвами, контентом та іншим.

</div>

<div class="prereqs">
<h4>Перш ніж почати</h4>

- Установіть **Node.js 22+** та **Git** -- див. [Передумови](../setup/prerequisites.md)
- Налаштуйте цільову адресу API (demo або local) -- див. [Змінні середовища](../setup/environment-variables.md)

</div>

## Налаштування

### 1. Клонуйте репозиторій

```bash
git clone https://github.com/ChurchApps/B1Admin.git
```

### 2. Установіть залежності

```bash
cd B1Admin
npm install
```

### 3. Налаштуйте змінні середовища

```bash
cp dotenv.sample.txt .env
```

Відкрийте `.env` і налаштуйте кінцеві точки API. Ви можете вказати або спільний демо-API (`https://api.demo.churchapps.org`), або ваш локальний екземпляр API. Зразковий файл може все ще містити застарілі URL тестового середовища; замініть їх.

### 4. Запустіть сервер розробки

```bash
npm start
```

Це запустить сервер розробки Vite. Застосунок буде доступний у браузері з увімкненою гарячою заміною модулів (HMR).

## Ключові змінні середовища

| Змінна | Опис |
|----------|-------------|
| `REACT_APP_STAGE` | Назва середовища (наприклад, `demo`, як у зразковому файлі, `prod` або `selfhost`) |
| `PORT` | Порт сервера розробки (за замовчуванням: `3101`) |
| `REACT_APP_*_API` | URL-адреси кінцевих точок API для кожного модуля |

:::info
Скрипт `postinstall` копіює файли локалізації та CSS з `@churchapps/apphelper`. Якщо компоненти виглядають без стилів, виконайте `npm run postinstall` вручну.
:::

## Ключові команди

| Команда | Опис |
|---------|-------------|
| `npm start` | Запустити сервер розробки Vite |
| `npm run build` | Збірка для продакшну через Vite |
| `npm run test` | Запустити наскрізні тести з Playwright |
| `npm run lint` | Запустити ESLint з автовиправленням |

## Стек технологій

- **React 19** з TypeScript
- **Vite** для інструментів збірки та сервера розробки
- **Material-UI 7** для компонентів інтерфейсу
- **React Query 5** для стану сервера
- **`@churchapps/apphelper*`** пакети для спільних компонентів

## Розгортання

Продакшн-збірки розгортаються в **S3 + CloudFront**:

1. `npm run build` генерує статичні ресурси
2. Ресурси синхронізуються з бакетом S3
3. Запускається інвалідація CloudFront, щоб відображати нову версію

:::tip
Детальні інструкції з розгортання див. у посібнику [Розгортання веб-застосунків](../deployment/web-apps.md).
:::
