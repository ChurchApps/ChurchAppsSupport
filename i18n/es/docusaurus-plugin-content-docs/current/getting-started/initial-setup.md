# Configuración Inicial

<div class="article-intro">

Después de crear tu cuenta e iglesia, hay algunos pasos importantes para configurar antes de invitar a tu equipo. Esta guía te camina por el orden de configuración recomendado para que tu iglesia esté lista desde el primer día.

</div>

<div class="prereqs">
<h4>Antes de Comenzar</h4>

- [Crea tu cuenta](./create-account.md) y registra tu iglesia
- Ten tu logo de iglesia y activos de marca listos (opcional pero recomendado)

</div>

## Paso 1: Configura la Información de Tu Iglesia

1. Abre el **menú de sección** en la esquina superior izquierda (el nombre de la sección con la pequeña flecha) y elige **Configuración**.
2. Haz clic en **Editar Configuración**.
3. Ingresa el **nombre** de tu iglesia, **dirección** y **detalles de contacto**.
4. Haz clic en **Guardar** para aplicar tus cambios.

## Paso 2: Configura Tu Marca

1. Desde el **Panel Principal** (tu página de inicio), navega a **Sitio Web**, luego selecciona **Apariencia**.
2. Carga el **logo de tu iglesia**.
3. Configura cualquier opción de marca adicional como colores e imágenes.
4. Tu marca aparecerá en tu sitio web B1.church y en la aplicación B1 Mobile.

:::tip
Tener tu logo y marca listos antes de invitar a miembros del equipo da una impresión pulida cuando inicien sesión.
:::

## Paso 3: Configura Roles e Invita a Tu Equipo

1. Haz clic en **Roles** desde la página **Configuración**.
2. Crea roles para tu equipo (por ejemplo, "Pastor", "Secretario", "Tesorero").
3. Asigna los permisos apropiados a cada rol.
4. Añade miembros del equipo buscando sus cuentas y asignándolos a roles.

## Paso 4: Configura Tus Áreas Clave

Con tu equipo en su lugar, comienza a construir las áreas centrales de B1 Admin:

1. **Personas** -- Añade miembros a tu directorio de iglesia. Esta es la base para todo lo demás, así que comienza aquí. Puedes añadir personas manualmente o usar la herramienta **Importar** desde **Configuración**.
2. **Grupos** -- Crea grupos para grupos pequeños, equipos de ministerio, clases y otras reuniones.
3. **Asistencia** -- Configura tus sedes, servicios y horarios de servicio para rastrear la asistencia.
4. **Donaciones** -- Configura fondos de donación y conecta tu puerta de enlace de pago (Stripe) para aceptar donaciones en línea.
5. **Sitio Web** -- Construye tu sitio web de iglesia pública usando el constructor de sitios web B1.church.

:::info
No necesitas configurar cada área de una vez. Muchas iglesias comienzan con **Personas** y **Grupos**, luego añaden **Asistencia** y **Donaciones** conforme se sienten cómodas con la plataforma.
:::

## Orden Recomendado

Para la experiencia de configuración más suave, sugerimos este orden:

1. **Personas** -- Añade tus miembros y asistentes regulares primero.
2. **Grupos** -- Organiza personas en grupos significativos.
3. **Asistencia** -- Comienza a rastrear quién se presenta cada semana.
4. **Donaciones** -- Configura donaciones una vez que tus personas estén en el sistema.
5. **Sitio Web** -- Construye tu sitio público, después de que tus datos estén en su lugar.

Una vez que hayas completado estos pasos, tu iglesia está lista para comenzar. Explora la documentación de [B1 Admin](/docs/b1-admin/) para guías detalladas de cada área.
