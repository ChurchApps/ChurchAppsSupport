# Puntos Finales de Mensajería

El módulo de Mensajería maneja conversaciones en tiempo real, mensajes de chat, notificaciones push, entrega de SMS/correo electrónico y conexiones WebSocket. Proporciona la capa de comunicación utilizada en todas las aplicaciones de ChurchApps.

**Ruta base:** `/messaging`

## Resumen de Superficies de Integración

Ver la documentación completa de API para todos los detalles sobre conversaciones, mensajes, notificaciones y dispositivos.
