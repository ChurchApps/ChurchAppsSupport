# Administración

<div class="article-intro">

El área de administración de Lessons.church es donde los creadores de contenido y los administradores gestionan la biblioteca de lecciones. Desde aquí puedes desarrollar la estructura de tu currículo, subir recursos, revisar las estadísticas de uso y conectar proveedores de contenido de terceros.

</div>

:::warning
El acceso de administrador requiere los permisos adecuados. Si no ves las opciones de administración, comunícate con el administrador de tu iglesia para solicitar acceso.
:::

## Lo que puedes hacer

El área de administración te ofrece control total sobre tu contenido:

- **Crear y editar programas** -- Configura series de currículo de nivel superior con nombres, descripciones, imágenes y slugs.
- **Gestionar estudios** -- Organiza grupos de lecciones relacionadas dentro de cada programa.
- **Crear lecciones** -- Agrega lecciones individuales con venues, secciones, roles y acciones.
- **Subir recursos** -- Adjunta archivos descargables (PDF, hojas de actividades, imágenes) a nivel de programa, estudio o lección.
- **Ver estadísticas** -- Consulta qué contenido se descarga, quién lo descarga y desde dónde.
- **Configurar proveedores** -- Conecta proveedores externos de currículo que usan el Open Lesson Format. Esto se hace desde la página **External Providers**, no desde el área de administración.
- **Planes anuales** -- Publica secuencias de semana 1, 2, 3… para cualquier currículo. Las iglesias las aplican en B1 Admin.

## Jerarquía del contenido

Como administrador, te conviene entender cómo está estructurado el contenido:

1. **Los programas** contienen uno o más estudios.
2. **Los estudios** contienen una o más lecciones.
3. **Las lecciones** contienen uno o más venues (variaciones por grupo de edad).
4. **Los venues** contienen secciones, y las secciones contienen acciones basadas en roles.

Cada nivel puede tener sus propios recursos descargables adjuntos.
