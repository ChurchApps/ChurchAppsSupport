# Resumen del portal

<div class="article-intro">

Después de iniciar sesión en Lessons.church, accederá al **Portal**: el panel de su iglesia para administrar aulas y calendarios de lecciones. Aquí pasará la mayor parte del tiempo cuando organice el currículo de su iglesia.

</div>

<div class="prereqs">
<h4>Antes de comenzar</h4>

- [Cree una cuenta](./creating-account.md) y conéctela a su iglesia
- Inicie sesión en [Lessons.church](https://lessons.church)

</div>

## Qué verá

El portal se abre en la página **Administración de aulas**, que se organiza en dos áreas principales:

- **Aulas** (lado derecho): una lista de las aulas de su iglesia. Haga clic en el nombre de un aula para ver sus lecciones programadas. Desde aquí también puede agregar aulas nuevas o editar las existentes.
- **Calendario de lecciones** (lado izquierdo): una vez que seleccione un aula, esta área muestra las lecciones programadas para ella. Si todavía no ha configurado ningún aula, verá un video con instrucciones de configuración para ayudarle a empezar.

## Qué puede hacer desde el portal

Desde el portal, puede:

1. **Administrar aulas**: agregar, editar o eliminar aulas. Cada aula puede vincularse a un equipo de voluntarios (para que vean las próximas lecciones en la aplicación B1) y a un grupo de padres o estudiantes (para que puedan acceder a las lecciones recientes). Las iglesias que todavía usan esta ruta de calendario de aulas: los padres abren la página del aula (sin `?upcoming=1`) para ver el contenido para llevar a casa. Las iglesias que usan tipos de plan de B1Admin ven la tarjeta de contenido para llevar en la página del grupo asociado en B1.
2. **Ver y administrar las lecciones programadas**: consulte qué lecciones están próximas para cada aula y realice los cambios necesarios.
3. **Suscribirse a las fuentes de las aulas**: haga clic en el ícono de fuente junto a un aula para obtener una URL de fuente de lista de reproducción que puede usar con aplicaciones compatibles.
4. **Acceder a los proveedores externos**: use la página **Proveedores externos** para configurar fuentes de contenido de terceros que sean compatibles con el Formato de Lección Abierta. Esto le permite incorporar lecciones de otros proveedores, además de la biblioteca integrada de Lessons.church.
5. **Acceder al área de administración**: si tiene permisos de administrador, verá una opción **Administración** en la navegación. El área de administración le permite gestionar programas, estudios y lecciones a nivel de contenido.

## Navegación

La navegación del portal incluye:

- **Inicio**: regrese a la página principal pública de Lessons.church para explorar el contenido.
- **Calendarios**: la vista principal del portal para administrar aulas y calendarios de lecciones.
- **Proveedores externos**: configure proveedores de lecciones de terceros.
- **Administración**: gestione programas, estudios y contenido de lecciones (visible solo si tiene permisos de administrador).

:::info
La opción **Administración** solo aparece si su cuenta tiene permisos para editar contenido. La mayoría del personal de la iglesia usará las páginas **Calendarios** y **Proveedores externos** para la administración diaria.
:::

## Primeros pasos

Si visita el portal por primera vez y todavía no ha creado ningún aula, comience haciendo clic en **Agregar primera aula** en el panel de aulas. Asigne un nombre a su aula (por ejemplo, "Preescolar" o "3.º a 5.º grado") y guárdelo. A partir de ahí, puede comenzar a [programar lecciones](../classrooms/scheduling-lessons.md).
