# Administrar Páginas

<div class="article-intro">

La vista Páginas del Sitio Web es tu centro de control para crear, editar y organizar todas las páginas de tu sitio web de iglesia. Puedes administrar tanto el contenido de tu página como la navegación de tu sitio desde esta pantalla única.

</div>

<div class="prereqs">
<h4>Antes de Empezar</h4>

- Completa la [Configuración Inicial](initial-setup) para configurar tu dominio y configuración básica del sitio
- Ten tu contenido e imágenes listos. Usa el administrador de [Archivos](files) para cargar activos multimedia primero.

</div>

:::info
Si tu iglesia tiene más de un sitio web (por ejemplo, sitios separados por campus), usa el selector de sitio en la parte superior de la vista Páginas del Sitio Web para saltar entre ellos. Cada sitio tiene sus propias páginas, navegación y configuración de [apariencia](appearance).
:::

## Comprendiendo los Tipos de Página

La tabla **Páginas** lista cada página de tu sitio junto con su estado:

- **Generada** -- Páginas que fueron creadas automáticamente por el sistema según los datos de tu iglesia (por ejemplo, una página de Grupos, una página de Sermones, o una página individual para cada sermón en tu biblioteca). Estas páginas se actualizan a sí mismas a medida que tus datos cambian.
- **Personalizada** -- Páginas que creaste tú mismo con tu propio contenido y diseño.

Puedes convertir cualquier página generada automáticamente en una página personalizada si deseas control total sobre su contenido y diseño.

## Agregar y Editar Páginas

1. Haz clic en el botón **Agregar Página** en la esquina superior derecha de la tabla Páginas.
2. Elige un tipo de página (en blanco o una plantilla) y dale un nombre.
3. Haz clic en **Editar** junto a cualquier página para abrir el [editor de página](page-editor), donde puedes agregar secciones, texto, imágenes y otros elementos.
4. Haz clic en **Configuración de Página** para actualizar el título de página, ruta de URL y otros metadatos.
5. Usa el botón **Previsualizar** para abrir tu página en una nueva ventana y ver exactamente cómo se verá para los visitantes.

:::tip
Para tu página de inicio, establece la ruta de URL en solo `/`. Para todas las demás páginas, usa una ruta descriptiva como `/acerca-de` o `/contacto`.
:::

### Configuración de Página

Abre **Configuración de Página** en cualquier página para configurar:

- **Título y Ruta de URL** -- El nombre de página y su dirección en tu sitio.
- **Visibilidad** -- Elige quién puede ver la página: todos, solo miembros, solo personal, o miembros de grupos específicos. Esta es una forma rápida de cercar una página privada (como una página de recursos para personal) sin una contraseña separada.
- **Descripción de Meta** -- Un resumen corto mostrado en resultados de motores de búsqueda y vistas previas de enlaces en redes sociales.
- **Redirecciones** -- Apunta una ruta de URL anterior a esta página, para que los enlaces y favoritos a una página retirada sigan funcionando.

## Administrar Navegación

La vista Páginas del Sitio Web muestra tus enlaces de navegación. Estos enlaces controlan el menú que los visitantes ven en tu sitio web.

1. Haz clic en **Agregar** para crear un nuevo enlace de navegación. Puedes apuntarlo a cualquier página de tu sitio o a una URL externa.
2. Para reordenar enlaces, arrastra y suelta en el orden que deseas. También puedes anidar enlaces bajo un elemento principal para crear menús desplegables.
3. Haz clic en el icono **Editar** junto a cualquier enlace para cambiar su etiqueta, URL o posición.
4. Para eliminar un enlace de la navegación, haz clic en el icono **Eliminar**.

:::info
Eliminar un enlace de navegación no elimina la página en sí. La página aún existe y puede ser accedida directamente por su URL -- simplemente no aparecerá en el menú.
:::

## Consejos para Organizar Tu Sitio

- Mantén tu navegación de nivel superior a cinco o seis elementos para que los visitantes encuentren cosas rápidamente.
- Usa enlaces anidados para sub-páginas relacionadas (por ejemplo, un menú desplegable "Acerca de" con "Nuestro Equipo", "Creencias" e "Historia").
- Revisa tu navegación en dispositivos móviles haciendo clic en **Vista Previa Móvil** para asegurarte de que funciona bien en pantallas más pequeñas.
- Dale a las páginas nombres claros y descriptivos que ayuden a los visitantes a entender qué encontrarán.

:::tip
Puedes agregar [formularios](../forms/creating-forms.md) a tus páginas para recopilar registros, solicitudes de oración u otra información de visitantes.
:::

## Comenzar desde una Plantilla de Sitio

Si estás construyendo tu sitio desde cero, puedes iniciarlo usando una **Plantilla de Sitio** en lugar de crear páginas una por una. Una plantilla de sitio crea un conjunto de páginas preconstructas — inicio, acerca, conectar, dar y otras -- con contenido placeholder y enlaces de navegación ya conectados.

1. En la pantalla Páginas, haz clic en el botón **Plantillas de Sitio** (junto al botón **Agregar Página**).
2. Navega por las plantillas disponibles y haz clic en una para obtener una vista previa de su estructura de página.
3. Cuando encuentres una que te guste, haz clic en **Aplicar Plantilla**.
4. Las páginas que aún no existen se crean y se agregan a tu navegación. Las páginas existentes se dejan como están.

Después de aplicar una plantilla, abre cada página en el [editor de página](page-editor) para reemplazar el texto y las imágenes placeholder con el contenido real de tu iglesia.

:::info
Las plantillas de sitio crean estructura de página y navegación. No anulan tu esquema de colores del sitio o fuentes -- esos se controlan con [Apariencia](appearance).
:::

## Lightbox de Imagen

Cuando los visitantes hacen clic en una imagen en tu sitio web, se abre en una superposición de lightbox de pantalla completa. Esto permite a las personas ver fotos en un tamaño más grande sin dejar la página. No se requiere configuración -- el lightbox está habilitado automáticamente para imágenes en tu contenido de página.
