# Sitio Web

<div class="article-intro">

La sección Sitio Web en B1 Admin te proporciona un constructor de sitios web completo para tu iglesia. Puedes crear páginas, personalizar la apariencia de tu sitio, administrar archivos multimedia y publicar calendarios de eventos -- todo sin escribir ningún código.

</div>

## Lo Que Puedes Hacer

El constructor de Sitio Web se organiza en estas áreas principales:

### Páginas

Crea y administra todas las páginas de tu sitio web de iglesia. La tabla **Páginas** enumera cada página -- las páginas creadas automáticamente por el sistema llevan una insignia **Generated**, y el resto son páginas personalizadas que creaste tú. Puedes agregar nuevas páginas personalizadas, editar las existentes, o convertir páginas generadas automáticamente en páginas personalizadas para tener control total sobre su contenido.

Tus enlaces de navegación se muestran en una estructura de árbol. Puedes reordenar enlaces mediante arrastrar y soltar para establecer la jerarquía exacta y el orden que deseas que los visitantes vean.

### Blog {#blog}

Publica noticias, actualizaciones y devocionales como entradas de blog en `/blog` en tu sitio, con una fuente RSS. Consulta la guía [Blog](./blog.md).

### Bloques

Construye componentes de contenido reutilizables que puedas colocar en múltiples páginas. Los bloques te ahorran tiempo cuando tienes contenido como una llamada a la acción, un banner de anuncio, o una sección de contacto que aparece en más de un lugar. Actualiza un bloque una vez y el cambio se aplica en todas partes donde se use.

### Apariencia

Personaliza el tema, colores, fuentes, logo y espaciado de tu sitio web. Puedes aplicar temas de estilo preconstructos para un inicio rápido o ajustar cada detalle con el editor de paleta de colores, configuración de tipografía y CSS personalizado. Consulta la guía [Apariencia](./appearance.md) para detalles completos.

### Archivos

Carga y administra todos tus activos multimedia -- imágenes, documentos y otros archivos -- en una ubicación central, y copia enlaces de archivos para usar en cualquier lugar de tu sitio. Consulta [Archivos](./files.md) para más información.

### Calendarios

Publica calendarios de eventos en tu sitio web para que los visitantes vean qué está sucediendo en tu iglesia. Crea calendarios curados que extraigan eventos de múltiples grupos en una sola vista. Los calendarios tienen su propio elemento **Calendars** en el menú de B1 Admin, separado de **Website**.

:::tip
Comienza con [Configuración Inicial](./initial-setup.md) si estás configurando tu sitio web por primera vez. Te guía a través de la configuración del dominio, crear tu primera página y configurar la apariencia de tu sitio.
:::
