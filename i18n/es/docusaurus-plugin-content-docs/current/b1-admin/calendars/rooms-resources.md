# Salas, Recursos y Programación

<div class="article-intro">

Salas y Recursos te permiten rastrear espacios y equipos reservables de tu iglesia. Cuando un grupo o equipo desea usar una sala o tomar prestado un recurso para un evento, puede solicitar a través de B1 — y tú puedes aprobar o rechazar esas solicitudes para evitar doble reserva.

</div>

<div class="prereqs">
<h4>Antes de Comenzar</h4>

- Necesitas acceso administrativo a la sección Calendarios en B1 Admin
- Configura [grupos](../groups/creating-groups) cuyos miembros enviarán solicitudes de reserva

</div>

## Abriendo Salas y Recursos

En B1 Admin, ve a **Calendarios** y selecciona **Salas y Recursos**. La página tiene cuatro pestañas: **Salas**, **Recursos**, **Bloqueos**, y **Plantillas**.

## Salas

Las salas son espacios físicos que pueden ser reservados junto con eventos del calendario — un santuario, un salón de confraternidad, un aula, etc.

### Agregando una Sala

1. En la pestaña **Salas**, haz clic en **Agregar Sala**.
2. Ingresa un **nombre** para la sala.
3. Opcionalmente establece una **capacidad** (número máximo de personas).
4. Establece un **Grupo de Aprobación** — cuando un grupo solicita esta sala, los líderes del grupo elegido se notifican y deben aprobar la reserva. Deja en blanco si no se necesita aprobación.
5. Haz clic en **Guardar**.

### Editando o Eliminando una Sala

Haz clic en el icono de edición junto a cualquier sala, haz tus cambios, y haz clic en **Guardar**. Usa **Eliminar** para eliminar una sala permanentemente.

## Recursos

Los recursos son elementos que se pueden reservar junto con un evento — equipo AV, proyectores, sillas, una furgoneta, etc.

### Agregando un Recurso

1. Haz clic en la pestaña **Recursos**, luego **Agregar Recurso**.
2. Ingresa un **nombre** y opcionalmente una **descripción**.
3. Establece un **Grupo de Aprobación** si alguien necesita aprobar el préstamo de recursos.
4. Haz clic en **Guardar**.

## Bloqueos

Los bloqueos evitan que las salas o recursos se reserven durante ciertos tiempos — para renovaciones, períodos reservados, o mantenimiento.

### Agregando un Bloqueo

1. Haz clic en la pestaña **Bloqueos**, luego **Agregar Bloqueo**.
2. Elige si bloquear una **Sala**, un **Recurso**, o todas las salas y recursos.
3. Establece la **fecha/hora de inicio** y **fecha/hora de fin** para el bloqueo.
4. Opcionalmente agrega una nota de **razón**.
5. Haz clic en **Guardar**.

## Plantillas de Eventos

Las plantillas te permiten guardar una configuración de evento reutilizable — título, descripción, y grupos asociados — para que eventos recurrentes se puedan crear consistentemente.

### Agregando una Plantilla

1. Haz clic en la pestaña **Plantillas**, luego **Agregar Plantilla**.
2. Ingresa un **nombre** para la plantilla.
3. Opcionalmente vincula un **grupo** para que el evento se conecte automáticamente a ese grupo cuando se cree desde la plantilla.
4. Haz clic en **Guardar**.

Cuando se crea un nuevo evento, el personal puede elegir una plantilla existente para rellenar previamente los detalles del evento.
