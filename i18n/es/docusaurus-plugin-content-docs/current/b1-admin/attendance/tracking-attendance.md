# Rastrear Asistencia

<div class="article-intro">

Una vez que tus campus, horarios de servicio y grupos estén configurados, B1 Admin facilita revisar datos de asistencia e identificar tendencias. La página de Asistencia proporciona dos vistas de reportes -- la pestaña **Asistencia** para tendencias a nivel de iglesia y la pestaña **Grupos** para detalle a nivel de grupo. Usa estas herramientas para entender patrones de crecimiento, identificar participación en declive, y tomar decisiones basadas en datos para tu iglesia.

</div>

<div class="prereqs">
<h4>Antes de Comenzar</h4>

- Tu estructura de asistencia debe estar configurada con al menos un campus y horario de servicio. Consulta [Configuración de Asistencia](setup.md) si aún no lo has hecho.
- Los datos de asistencia deben estar registrados antes de que los reportes muestren resultados. Los datos pueden provenir de [entrada manual](recording-attendance.md) o [auto registrarse](check-in.md).

</div>

## Ver Tendencias de Asistencia

1. Abre **B1 Admin**, luego abre el **menú de sección** en la esquina superior izquierda y elige **Personas**.
2. Haz clic en la pestaña **Asistencia**.
3. El reporte se ejecuta automáticamente cuando abre la pestaña, mostrando asistencia sobre un rango de fechas por defecto.

## Filtrar tus Datos

Usa los filtros en la parte superior de la página para reducir los resultados:

- **Rango de Fechas** -- elige una fecha de inicio y fin para enfocarte en un período específico.
- **Campus** -- selecciona un campus para ver asistencia solo de esa ubicación.
- **Horario de Servicio** -- elige un horario de servicio para profundizar en una reunión particular.

El gráfico y los datos se actualizan tan pronto como cambies un filtro, para que puedas comparar rápidamente diferentes períodos de tiempo o ubicaciones.

:::info
Los reportes se ejecutan automáticamente cada vez que abres la pestaña de Asistencia, así que siempre verás números actualizados sin necesidad de hacer clic en un botón de actualizar.
:::

## Asistencia de Grupos

La pestaña **Grupos** muestra la asistencia desglosada por grupo individual. Esto es útil cuando quieres monitorear una clase específica, equipo de ministerio, o grupo pequeño en lugar de ver números de servicio generales.

1. Selecciona la pestaña **Grupos**.
2. Elige un grupo de la lista para ver su historial de asistencia.
3. Usa el filtro de rango de fechas para ajustar la ventana de reportes.

:::tip
La asistencia de grupos es especialmente valiosa para líderes de [grupos pequeños](../groups/creating-groups.md) que quieren rastrear participación dentro de su grupo a lo largo del tiempo.
:::

## Consejos para Usar Datos de Asistencia

- Revisa tendencias mensualmente para detectar patrones estacionales temprano.
- Compara datos a nivel de campus para entender qué ubicaciones están creciendo.
- Usa reportes a nivel de grupo para hacer seguimiento con [grupos](../groups/group-members.md) que muestren asistencia en declive.
- Combina información de asistencia con la herramienta [Búsqueda de IA](../people/ai-search.md) para encontrar personas que no han asistido recientemente.
