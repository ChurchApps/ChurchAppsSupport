# Rastreando Asistencia

<div class="article-intro">

Una vez que tus campus, horarios de servicio, y grupos estén configurados, B1 Admin facilita la revisión de datos de asistencia y la identificación de tendencias. La página de Asistencia proporciona dos vistas de reportes -- la pestaña **Asistencia** para tendencias de toda la iglesia y la pestaña **Grupos** para detalle a nivel de grupo. Usa estas herramientas para entender patrones de crecimiento, identificar el declive de compromiso, y tomar decisiones basadas en datos para tu iglesia.

</div>

<div class="prereqs">
<h4>Antes de comenzar</h4>

- Tu estructura de asistencia debe estar configurada con al menos un campus y horario de servicio. Ver [Configuración de Asistencia](setup.md) si aún no lo has hecho.
- Los datos de asistencia necesitan ser registrados antes de que los reportes muestren resultados. Los datos pueden venir de [entrada manual](recording-attendance.md) o [auto check-in](check-in.md).

</div>

## Viendo tendencias de asistencia

1. Abre **B1 Admin**, luego abre el **menú de sección** en la esquina superior izquierda y elige **Personas**.
2. Haz clic en la pestaña **Asistencia**.
3. El reporte se ejecuta automáticamente cuando se abre la pestaña, mostrando asistencia sobre un rango de fechas predeterminado.

## Filtrando tus datos

Usa los filtros en la parte superior de la página para reducir los resultados:

- **Rango de fechas** -- elige una fecha de inicio y fin para enfocarte en un período específico.
- **Campus** -- selecciona un campus para ver asistencia solo para esa ubicación.
- **Horario de Servicio** -- elige un horario de servicio para profundizar en una reunión particular.

El gráfico y datos se actualizan en cuanto cambies un filtro, para que puedas comparar rápidamente diferentes períodos o ubicaciones.

:::info
Los reportes se ejecutan automáticamente cada vez que abres la pestaña Asistencia, para que siempre veas números actualizados sin necesidad de hacer clic en un botón de actualización.
:::

## Asistencia de grupo

La pestaña **Grupos** muestra asistencia desglosada por grupo individual. Esto es útil cuando quieres monitorear una clase específica, equipo de ministerio, o pequeño grupo en lugar de mirar números de servicio generales.

1. Selecciona la pestaña **Grupos**.
2. Elige un grupo de la lista para ver su historial de asistencia.
3. Usa el filtro de rango de fechas para ajustar la ventana de reportes.

:::tip
La asistencia de grupo es especialmente valiosa para [líderes de pequeños grupos](../groups/creating-groups.md) que quieren rastrear el compromiso dentro de su grupo a lo largo del tiempo.
:::

## Consejos para usar datos de asistencia

- Revisa tendencias mensualmente para detectar patrones estacionales temprano.
- Compara datos a nivel de campus para entender qué ubicaciones están creciendo.
- Usa reportes a nivel de grupo para hacer seguimiento con [grupos](../groups/group-members.md) que muestren declive de asistencia.
- Combina perspectivas de asistencia con la herramienta [Búsqueda de IA](../people/ai-search.md) para encontrar personas que no han asistido recientemente.
