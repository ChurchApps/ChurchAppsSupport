# Rastreando Asistencia

<div class="article-intro">

Una vez que tus sedes, horarios de servicio y grupos están configurados, B1 Admin hace que sea fácil revisar datos de asistencia e identificar tendencias. La página de Asistencia proporciona dos vistas de reportes -- la pestaña **Tendencia de Asistencia** para tendencias de toda la iglesia y la pestaña **Asistencia de Grupo** para detalle a nivel de grupo. Usa estas herramientas para entender patrones de crecimiento, identificar disminución en la participación y tomar decisiones basadas en datos para tu iglesia.

</div>

<div class="prereqs">
<h4>Antes de Comenzar</h4>

- Tu estructura de asistencia debe estar configurada con al menos una sede y horario de servicio. Consulta [Configuración de Asistencia](setup.md) si aún no lo has hecho.
- Los datos de asistencia necesitan ser registrados antes de que los reportes muestren resultados. Los datos pueden provenir de [entrada manual](recording-attendance.md) o [auto registro](check-in.md).

</div>

## Viendo Tendencias de Asistencia

1. Abre **B1 Admin**, luego abre el **menú de sección** en la esquina superior izquierda y elige **Personas**.
2. Haz clic en la pestaña **Tendencia de Asistencia**.
3. El reporte se ejecuta automáticamente cuando la pestaña se abre, mostrando la asistencia durante un rango de fecha predeterminado.

## Filtrando Tus Datos

Usa los filtros en la parte superior de la página para limitar los resultados:

- **Rango de Fechas** -- elige una fecha de inicio y fin para enfocarte en un período específico.
- **Sede** -- selecciona una sede para ver la asistencia solo para esa ubicación.
- **Horario de Servicio** -- elige un horario de servicio para profundizar en un encuentro particular.

La gráfica y los datos se actualizan tan pronto como cambies un filtro, así que puedes comparar rápidamente diferentes períodos de tiempo o ubicaciones.

:::info
Los reportes se ejecutan automáticamente cada vez que abres la pestaña Tendencia de Asistencia, por lo que siempre verás números actualizados sin necesidad de hacer clic en un botón de actualizar.
:::

## Asistencia de Grupo

La pestaña **Asistencia de Grupo** muestra la asistencia desglosada por grupo individual. Esto es útil cuando quieres monitorear una clase específica, equipo ministerial o grupo pequeño en lugar de ver números generales del servicio.

1. Selecciona la pestaña **Asistencia de Grupo**.
2. Elige un grupo de la lista para ver su historial de asistencia.
3. Usa el filtro de rango de fechas para ajustar la ventana de reportes.

:::tip
La asistencia de grupo es especialmente valiosa para líderes de [grupos pequeños](../groups/creating-groups.md) que quieren rastrear la participación dentro de su grupo a lo largo del tiempo.
:::

## Consejos para Usar Datos de Asistencia

- Revisa tendencias mensualmente para detectar patrones estacionales temprano.
- Compara datos a nivel de sede para entender qué ubicaciones están creciendo.
- Usa reportes a nivel de grupo para hacer seguimiento con [grupos](../groups/group-members.md) que muestren asistencia en declive.
- Combina perspectivas de asistencia con la herramienta de [Búsqueda de IA](../people/ai-search.md) para encontrar personas que no han asistido recientemente.
