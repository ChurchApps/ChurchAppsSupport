# Configuración

<div class="article-intro">

La sección Configuración es donde configuras la cuenta de tu iglesia, marca y opciones administrativas en B1 Admin. Desde aquí puedes administrar todo, desde el nombre de tu iglesia y subdominio hasta permisos de usuario y configuración de aplicación móvil.

</div>

## Lo que encontrarás aquí

El área Configuración se organiza en las siguientes subsecciones:

1. **Configuración**: configura la información básica de tu iglesia, marca y subdominio. Ver [Configuración de la iglesia](./church-settings.md) para detalles. Para usar tu propio nombre de dominio (p. ej. tuiglesia.org), ver [Dominio personalizado](./custom-domain.md).
2. **Sedes**: agrega y administra múltiples ubicaciones físicas para tu iglesia. Una vez creadas, las sedes aparecen en perfiles de personas, en configuración de asistencia y en el panel de Datos demográficos. Se alcanza como una tarjeta en la página Configuración principal en lugar de un elemento de navegación separado. Ver [Sedes](./campuses.md) para detalles.
3. **Campos personalizados**: define tus propios campos para rastrear en personas (una fecha, número, respuesta sí/no, o lista de selección), luego complétalos en perfiles y busca en ellos. También se alcanza como una tarjeta en la página Configuración principal. Ver [Campos personalizados](./custom-fields.md) para detalles.
4. **Plantillas de correo electrónico**: guarda contenido de correo electrónico reutilizable para enviar manualmente o desde un flujo de trabajo. Ver [Plantillas de correo electrónico](./email-templates.md) para detalles.
5. **Administrador del servidor**: accede a herramientas de administración avanzadas para administrar la configuración de nivel de servidor de tu iglesia.

:::info
La configuración de **Aplicaciones móviles** y **Formularios** ahora tiene sus propios elementos de navegación de nivel superior: **Móvil** y **Formularios** (encontrados bajo **Personas**): en lugar de vivir dentro de Configuración. Ver [Configuración de aplicación móvil](./mobile-app.md) y [Crear formularios](/docs/b1-admin/forms/creating-forms) para detalles.
:::

## La página Configuración principal

Cuando primero abres la página Configuración, verás el **nombre de tu iglesia** y **subdominio** mostrados en la parte superior. El encabezado proporciona botones de acceso rápido para tareas comunes:

- **Plantillas de correo electrónico**: ir directamente a la administración de plantillas de correo electrónico.
- **Registro de auditoría**: ver un registro de cambios realizados en la cuenta de tu iglesia.
- **Lotes**: ir directamente a lotes de donación.
- **Importar/Exportar**: transferir datos entre sistemas usando la herramienta de importación/exportación.

Debajo del encabezado, abre la sección **Información de la iglesia** para editar el nombre de tu iglesia, dirección, información de contacto y marca: ver [Configuración de la iglesia](./church-settings.md). Para administrar roles de usuario, haz clic en **Roles** en la barra de navegación Configuración: ver [Roles y permisos](./roles-permissions.md).

:::tip
Comienza configurando el nombre de tu iglesia y marca bajo **Información de la iglesia**, luego configura [Roles](./roles-permissions.md) para invitar a los miembros de tu equipo con el nivel correcto de acceso.
:::

:::info
Para información sobre cómo se protegen tus datos, ver [Seguridad de datos](./data-security.md).
:::
