# Configuración

<div class="article-intro">

La sección de Configuración es donde configuras la cuenta, marca y opciones administrativas de tu iglesia en B1 Admin. Desde aquí puedes gestionar todo, desde el nombre y subdominio de tu iglesia hasta los permisos de usuario y la configuración de la aplicación móvil.

</div>

## Lo que Encontrarás Aquí

El área de Configuración está organizada en las siguientes subsecciones accesibles desde la barra lateral:

1. **Configuración** -- Configura la información básica, la marca y el subdominio de tu iglesia. Consulta [Configuración de la Iglesia](./church-settings.md) para más detalles.
2. **Sedes** -- Agrega y administra varias ubicaciones físicas para tu iglesia. Una vez creadas, las sedes aparecen en los perfiles de las personas, en la configuración de asistencia y en el panel de Demografía. Consulta [Sedes](./campuses.md) para más detalles.
3. **Campos Personalizados** -- Define tus propios campos para registrar en las personas (una fecha, número, respuesta sí/no o lista de opciones), luego complétalos en los perfiles y búscalos. Consulta [Campos Personalizados](./custom-fields.md) para más detalles.
3. **Aplicaciones Móviles** -- Configura y personaliza las pestañas de navegación que aparecen en la [PWA de B1.church](/docs/b1-church/getting-started/installing-pwa) para tus miembros (las mismas pestañas también se muestran en la aplicación nativa B1 Mobile en desuso). Consulta [Configuración de la Aplicación Móvil](./mobile-app.md) para más detalles.
4. **Plantillas de Correo Electrónico** -- Guarda contenido de correo electrónico reutilizable para enviarlo manualmente o desde un flujo de trabajo. Consulta [Plantillas de Correo Electrónico](./email-templates.md) para más detalles.
5. **Administración del Servidor** -- Accede a herramientas de administración avanzadas para gestionar la configuración a nivel de servidor de tu iglesia.
6. **Formularios** -- Crea y administra formularios personalizados para recopilar información de tu congregación.

## La Página Principal de Configuración

Cuando abres por primera vez la página de Configuración, verás el **nombre de tu iglesia** y el **subdominio** mostrados en la parte superior. El encabezado ofrece botones de acceso rápido para tareas comunes:

- **Editar Configuración** -- Actualiza el nombre, dirección, información de contacto y marca de tu iglesia.
- **Aplicaciones Móviles** -- Ve directamente a la configuración de la aplicación móvil.
- **Roles** -- Administra los roles y permisos de usuario para tu equipo.
- **Importar/Exportar** -- Transfiere datos entre sistemas usando la herramienta de importación/exportación.

:::tip
Comienza configurando el nombre y la marca de tu iglesia en **Editar Configuración**, luego configura [Roles](./roles-permissions.md) para invitar a los miembros de tu equipo con el nivel de acceso adecuado.
:::

:::info
Para obtener información sobre cómo se protegen tus datos, consulta [Seguridad de Datos](./data-security.md).
:::
