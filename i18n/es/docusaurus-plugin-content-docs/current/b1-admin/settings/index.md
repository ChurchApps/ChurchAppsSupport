# Configuración

<div class="article-intro">

La sección Configuración es donde configuras la cuenta de tu iglesia, marca y opciones administrativas en B1 Admin. Desde aquí puedes administrar todo, desde el nombre de tu iglesia y subdominio hasta los permisos de usuarios y la configuración de la aplicación móvil.

</div>

## Qué encontrarás aquí

El área de Configuración está organizada en las siguientes subsecciones:

1. **Configuración**: configura la información básica de tu iglesia, marca, subdominio, región (formato de fecha y de teléfono), proveedor de mensajes de texto y almacenamiento de archivos. Ver [Configuración de iglesia](./church-settings.md) para detalles. Para usar tu propio nombre de dominio (por ejemplo, tuiglesia.org), ver [Dominio personalizado](./custom-domain.md).
2. **Sedes**: agrega y administra múltiples ubicaciones físicas para tu iglesia. Una vez creadas, las sedes aparecen en perfiles de personas, en la configuración de asistencia y en el panel de Demografía. Se accede como una sección en la página Configuración principal en lugar de un elemento de navegación separado. Ver [Sedes](./campuses.md) para detalles.
3. **Campos personalizados**: define tus propios campos para rastrear en personas (una fecha, número, respuesta de sí/no o lista de selección), luego completa los valores en perfiles y búsqueda en ellos. También se accede como una sección en la página Configuración principal. Ver [Campos personalizados](./custom-fields.md) para detalles.
4. **Plantillas de correo electrónico**: guarda contenido de correo electrónico reutilizable para enviar manualmente o desde un flujo de trabajo. Ver [Plantillas de correo electrónico](./email-templates.md) para detalles.
5. **Registro de auditoría** y **Lotes**: revisa los cambios realizados en la cuenta de tu iglesia ([Registro de auditoría](../reports/audit-log.md)), y revisa o deshaz importaciones y acciones masivas (**Lotes**).
6. **Administrador de servidor**: accede a herramientas de administración avanzadas para administrar la configuración del nivel de servidor de tu iglesia.

:::info
**Aplicaciones móviles** configuración y **Formularios** ahora tienen elementos de navegación de nivel superior propios: **Móvil** y **Formularios** (encontrados en **Personas**), en lugar de vivir dentro de Configuración. Ver [Configuración de aplicación móvil](./mobile-app.md) y [Crear formularios](/docs/b1-admin/forms/creating-forms) para detalles.
:::

## La página de configuración principal

Cuando abres primero la página Configuración, el panel de la izquierda muestra el **nombre de tu iglesia**, **subdominio** y dirección, junto con un enlace **Importar/Exportar** que abre la herramienta de importación/exportación para transferir datos entre sistemas.

Debajo, una lista **Configuración** enlaza a cada sección de configuración: **Información de iglesia**, **General**, **Región**, **Donaciones**, **Mensajes de texto**, **Almacenamiento de archivos**, **Dominios**, **Promoción de grado**, **Check-In**, **Sedes**, **Campos personalizados** y **Desarrollador**. Las secciones que aún necesitan configuración (como Donaciones, Mensajes de texto o Dominios) se marcan con un pequeño punto. Todas las secciones están en una sola página: haz clic en un nombre de la lista para desplazarte hasta él, o simplemente desplázate hacia abajo. Cada sección muestra su configuración actual; haz clic en **Editar** dentro de una sección para cambiarla.

**Plantillas de correo electrónico**, **Registro de auditoría** y **Lotes** son páginas separadas: ábrelas desde el [menú Saltar](../introduction.md#getting-around-with-the-jump-menu) en **Configuración**.

Empieza por la sección **Información de iglesia** para editar el nombre de tu iglesia, dirección e información de contacto: ver [Configuración de iglesia](./church-settings.md). Para administrar roles de usuarios, abre el [menú Saltar](../introduction.md#getting-around-with-the-jump-menu) y elige **Configuración > Roles**: ver [Roles y permisos](./roles-permissions.md).

:::tip
Comienza configurando el nombre de tu iglesia y marca bajo **Información de iglesia**, luego configura [Roles](./roles-permissions.md) para invitar a los miembros de tu equipo con el nivel de acceso correcto.
:::

:::info
Para información sobre cómo se protegen tus datos, ver [Seguridad de datos](./data-security.md).
:::
