# Configuración

<div class="article-intro">

La sección Configuración es donde configuras la cuenta de tu iglesia, marca y opciones administrativas en B1 Admin. Desde aquí puedes administrar todo, desde el nombre de tu iglesia y subdominio hasta los permisos de usuarios y la configuración de la aplicación móvil.

</div>

## Qué encontrarás aquí

El área de Configuración está organizada en las siguientes subsecciones:

1. **Configuración**: configura la información básica de tu iglesia, marca, subdominio, región (formato de fecha), proveedor de mensajes de texto y almacenamiento de archivos. Ver [Configuración de iglesia](./church-settings.md) para detalles. Para usar tu propio nombre de dominio (por ejemplo, tuiglesia.org), ver [Dominio personalizado](./custom-domain.md).
2. **Sedes**: agrega y administra múltiples ubicaciones físicas para tu iglesia. Una vez creadas, las sedes aparecen en perfiles de personas, en la configuración de asistencia y en el panel de Demografía. Se accede como una tarjeta en la página Configuración principal en lugar de un elemento de navegación separado. Ver [Sedes](./campuses.md) para detalles.
3. **Campos personalizados**: define tus propios campos para rastrear en personas (una fecha, número, respuesta de sí/no o lista de selección), luego completa los valores en perfiles y búsqueda en ellos. También se accede como una tarjeta en la página Configuración principal. Ver [Campos personalizados](./custom-fields.md) para detalles.
4. **Plantillas de correo electrónico**: guarda contenido de correo electrónico reutilizable para enviar manualmente o desde un flujo de trabajo. Ver [Plantillas de correo electrónico](./email-templates.md) para detalles.
5. **Administrador de servidor**: accede a herramientas de administración avanzadas para administrar la configuración del nivel de servidor de tu iglesia.

:::info
**Aplicaciones móviles** configuración y **Formularios** ahora tienen elementos de navegación de nivel superior propios: **Móvil** y **Formularios** (encontrados en **Personas**), en lugar de vivir dentro de Configuración. Ver [Configuración de aplicación móvil](./mobile-app.md) y [Crear formularios](/docs/b1-admin/forms/creating-forms) para detalles.
:::

## La página de configuración principal

Cuando abres primero la página Configuración, verás el **nombre de tu iglesia** y **subdominio** mostrados en la parte superior. El encabezado proporciona botones de acceso rápido para tareas comunes:

- **Plantillas de correo electrónico**: salta directamente a la administración de plantillas de correo electrónico.
- **Registro de auditoría**: ve un registro de cambios realizados en la cuenta de tu iglesia.
- **Lotes**: salta directamente a lotes de donación.
- **Importar/Exportar**: transfiere datos entre sistemas usando la herramienta de importación/exportación.

Debajo del encabezado, abre la sección **Información de iglesia** para editar el nombre de tu iglesia, dirección, información de contacto y marca: ver [Configuración de iglesia](./church-settings.md). Para administrar roles de usuarios, abre el [menú Saltar](../introduction.md#getting-around-with-the-jump-menu) y elige **Configuración > Roles**: ver [Roles y permisos](./roles-permissions.md).

:::tip
Comienza configurando el nombre de tu iglesia y marca bajo **Información de iglesia**, luego configura [Roles](./roles-permissions.md) para invitar a los miembros de tu equipo con el nivel de acceso correcto.
:::

:::info
Para información sobre cómo se protegen tus datos, ver [Seguridad de datos](./data-security.md).
:::
