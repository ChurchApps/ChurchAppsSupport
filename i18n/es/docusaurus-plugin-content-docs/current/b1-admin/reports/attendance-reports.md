# Reportes de Asistencia

<div class="article-intro">

B1 Admin proporciona tres reportes de asistencia para ayudarte a entender cómo las personas se están comprometiendo con tus servicios y grupos. Cada reporte ofrece una perspectiva diferente en tus datos de asistencia, desde tendencias de alto nivel hasta desgloses diarios.

</div>

<div class="prereqs">
<h4>Antes de Comenzar</h4>

- Asegúrate de que la asistencia esté siendo [registrada consistentemente](../attendance/tracking-attendance.md) para tus servicios y grupos
- Asegúrate de que tus [grupos](../groups/creating-groups.md) y servicios estén configurados en B1 Admin
- Necesitas los [permisos](../settings/roles-permissions.md) apropiados para acceder a los reportes

</div>

## Tendencia de Asistencia

El reporte de Tendencia de Asistencia muestra cómo cambia la asistencia a lo largo del tiempo para tus servicios.

1. Ve directamente a **admin.b1.church/reports/attendanceTrend** en tu navegador (los reportes no tienen entrada en el menú de navegación — marcar la dirección es la forma más fácil de volver a ella).
2. Establece el **rango de fechas** para definir el período de tiempo.
3. Selecciona un **servicio** o **grupo** para filtrar los resultados.
4. El reporte muestra una línea de tendencia con los conteos de asistencia en el período seleccionado.

Este reporte es útil para detectar patrones como caídas estacionales, tendencias de crecimiento o el impacto de eventos especiales.

## Asistencia de Grupo

El reporte de Asistencia de Grupo muestra totales de asistencia por grupo para un rango de fechas seleccionado.

1. Ve directamente a **admin.b1.church/reports/groupAttendance** en tu navegador.
2. Establece el **rango de fechas** para el reporte.
3. Selecciona el/los **grupo(s)** que deseas revisar.
4. El reporte muestra cifras de asistencia total para cada grupo.

Usa este reporte para comparar asistencia entre grupos e identificar cuáles están creciendo o necesitan atención.

## Asistencia Diaria de Grupo

El reporte de Asistencia Diaria de Grupo proporciona un desglose día a día de datos de asistencia para tus grupos.

1. Ve directamente a **admin.b1.church/reports/dailyGroupAttendance** en tu navegador.
2. Establece el **rango de fechas** para el reporte.
3. Selecciona el/los **grupo(s)** que deseas revisar.
4. El reporte muestra números de asistencia para cada día individual dentro del rango.

Este reporte te brinda detalle granular, que es útil para entender la variación semana a semana o identificar días específicos con asistencia inusualmente alta o baja.

:::tip
Usa el reporte de Tendencia de Asistencia para una visión general de alto nivel y el reporte de Asistencia Diaria de Grupo cuando necesites profundizar en fechas específicas.
:::

## Usos Prácticos

- **Planificación** -- Usa tendencias de asistencia para planificar asientos, personal y recursos para servicios próximos.
- **Alcance** -- Identifica patrones de asistencia decreciente temprano para que puedas dar seguimiento a los miembros.
- **Reportes de junta** -- Incluye datos de asistencia en tus reportes de liderazgo regulares para mostrar la salud del ministerio.
- **Evaluación de eventos** -- Compara asistencia antes y después de eventos especiales para medir su impacto.

:::warning
Los datos de asistencia se registran a través de tus procesos de check-in de grupo y servicio. Si la asistencia no se registra consistentemente, tus reportes no reflejarán con precisión la participación real. Ver [Seguimiento de Asistencia](../attendance/tracking-attendance.md) para instrucciones de configuración.
:::
