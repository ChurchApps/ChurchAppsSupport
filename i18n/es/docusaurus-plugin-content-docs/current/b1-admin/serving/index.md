# Servicio

<div class="article-intro">

La sección Servicio es su centro para coordinar voluntarios y planificar servicios de iglesia. Ya sea que esté organizando adoración dominical, reuniones entre semanas o eventos especiales, aquí es donde reúne todo para que sus equipos sepan exactamente quién está sirviendo y cuándo.

</div>

## Cómo Funciona la Página de Servicio

Cuando abre la página **Servicio**, verá sus ministerios mostrados como pestañas en la parte superior. Cada ministerio tiene sus propios tipos de planes y equipos, para que pueda administrar múltiples ministerios de forma independiente. Por ejemplo, puede tener pestañas separadas para Adoración, Ministerio Infantil y Hospitalidad.

El personal no administrativo que son miembros de un ministerio también pueden acceder a la página Servicio. Solo verán los ministerios a los que pertenecen y pueden crear y editar planes, asignaciones, tipos de planes y el orden de servicio para su ministerio sin necesidad de permisos de administrador completo.

:::tip
Si es un administrador, alterne **Mostrar Todo** para ver todos los ministerios a la vez. Esto es útil cuando necesita verificar asignaciones en múltiples equipos.
:::

## Subsecciones

La sección Servicio incluye estas áreas clave:

- **[Planes](./plans.md)** -- Crear planes de servicio para fechas específicas y asignar voluntarios a equipos. Los planes le ayudan a organizar quién está sirviendo cuándo, para que todos sepan su función con anticipación. Configure [recordatorios de voluntarios](./plans.md#volunteer-reminders) automáticos para que su equipo sea notificado antes de cada servicio, y use la **[Descripción General de Planes](./plans-overview.md)** para ver todas las asignaciones próximas en múltiples semanas en una cuadrícula.
- **[Canciones](./songs.md)** -- Administre su biblioteca de canciones de adoración con letras, arreglos y enlaces externos. Su equipo de adoración puede usar esto para prepararse para los próximos servicios.
- **[Tareas](./tasks.md)** -- Asigne y realice un seguimiento de tareas para sus miembros del equipo desde **Mi Trabajo**.
- **[Flujos de Trabajo](./workflows.md)** -- Mueva personas a través de una serie de pasos en un tablero Kanban visual, como seguimiento de visitantes nuevos o un proceso de membresía. Los pasos pueden ejecutar acciones automatizadas (enviar un correo electrónico, esperar algunos días, agregar a un grupo), y las tarjetas avanzan por botones de resultado, enrutamiento condicional, o activadores de evento y programación -- con informes incorporados.

## Primeros Pasos

1. Navegue a **Servicio** desde el menú principal en B1 Admin.
2. Haga clic en el botón agregar ministerio para crear un nuevo ministerio o alterne "mostrar todo" para ver las pestañas de ministerio existentes. Seleccione una **pestaña de ministerio** para ver sus tipos de planes y equipos.
3. Elija "crear un tipo de plan" o elija un tipo de plan existente para comenzar a [crear planes de servicio](./plans.md), o explore las subsecciones [Canciones](./songs.md) y [Tareas](./tasks.md).

:::info
Antes de poder crear planes, necesitará crear sus Ministerios en el área Servicio y Equipos dentro de cada Ministerio.
:::
