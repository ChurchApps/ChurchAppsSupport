# Servicio

<div class="article-intro">

La sección de Servicio es tu centro para coordinar voluntarios y planificar servicios de iglesia. Ya sea que estés organizando adoración el domingo, reuniones entre semana o eventos especiales, aquí es donde lo reúnes todo para que tus equipos sepan exactamente quién está sirviendo y cuándo.

</div>

## Cómo Funciona la Página de Servicio

Cuando abres la página **Servicio**, verás tus ministerios mostrados como pestañas en la parte superior. Cada ministerio tiene sus propios tipos de planes y equipos, para que puedas gestionar múltiples ministerios de forma independiente. Por ejemplo, podrías tener pestañas separadas para Adoración, Ministerio Infantil y Hospitalidad.

El personal no administrador que es miembro de un ministerio también puede acceder a la página de Servicio. Solo verá los ministerios a los que pertenece y puede crear y editar planes, asignaciones, tipos de planes y el orden del servicio para su ministerio sin necesidad de permisos de administrador completo.

:::tip
Si eres administrador, las pestañas muestran los ministerios a los que perteneces (**Mis**). Elige **Todos** para ver todos los ministerios. Esto es útil cuando necesitas verificar asignaciones en múltiples equipos. Si tu iglesia tiene muchos ministerios, aparece un cuadro **Buscar un ministerio** para filtrar las pestañas por nombre.
:::

## Sub-Secciones

La sección de Servicio incluye estas áreas clave:

- **[Planes](./plans.md)** -- Crea planes de servicio para fechas específicas y asigna voluntarios a equipos. Los planes te ayudan a organizar quién está sirviendo cuándo, para que todos sepan su rol con anticipación. Configura [recordatorios automáticos de voluntarios](./plans.md#volunteer-reminders) por push, correo electrónico o mensaje de texto para que tu equipo sea notificado antes de cada servicio, y usa la **[Descripción General de Planes](./plans-overview.md)** para ver todas las asignaciones próximas en múltiples semanas en una cuadrícula.
- **[Canciones](./songs.md)** -- Gestiona tu biblioteca de canciones de adoración con letras, arreglos y enlaces externos. Tu equipo de adoración puede usar esto para prepararse para los próximos servicios.
- **[Tareas](./tasks.md)** -- Asigna y realiza un seguimiento de tareas para los miembros de tu equipo desde **Mi Trabajo**.
- **[Flujos de Trabajo](./workflows.md)** -- Mueve personas a través de una serie de pasos en un tablero visual de Kanban, como seguimiento de nuevo visitante o un proceso de membresía. Los pasos pueden ejecutar acciones automatizadas (enviar un correo electrónico, esperar algunos días, añadir a un grupo), y las tarjetas avanzan por botones de resultado, enrutamiento condicional o activadores de eventos y horarios -- con informes integrados.

## Primeros Pasos

1. En B1 Admin, abre el [menú Saltar](../introduction.md#getting-around-with-the-jump-menu) (la barra de búsqueda en la esquina superior izquierda), expande **Servicio** y haz clic en **Planes**.
2. Haz clic en **Añadir Ministerio** para crear un nuevo ministerio, o elige **Todos** para ver todos los ministerios existentes. Selecciona una **pestaña de ministerio** para ver sus tipos de planes y equipos de servicio.
3. Haz clic en **Crear Tipo de Plan** (o **Añadir Tipo de Plan**) o elige un tipo de plan existente para empezar a [crear planes de servicio](./plans.md), o explora las sub-secciones [Canciones](./songs.md) y [Tareas](./tasks.md).

:::info
Antes de poder crear planes, necesitarás crear tus Ministerios en el área de Servicio y Equipos dentro de cada Ministerio.
:::
