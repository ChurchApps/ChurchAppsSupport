# Formularios

<div class="article-intro">

La sección Formularios le permite crear formularios personalizados para registros, encuestas, recopilación de datos y más. Ya sea que necesite una tarjeta de visitante, un registro de evento o un formulario de solicitud de oración, puede construirlo aquí y compartirlo con su congregación a través de un enlace público o su sitio web B1.church.

</div>

## La página de formularios

Cuando abre **Forms**, verá estas pestañas:

- **Forms** — Muestra todos sus formularios activos.
- **Archived Forms** — Muestra formularios que han sido archivados. Puede restaurar formularios archivados en cualquier momento. Esta pestaña solo aparece una vez que al menos un formulario ha sido archivado.

Cada formulario en la lista muestra su nombre y, si está configurado, una URL pública que puede compartir externamente.

## Lo que puede hacer

Desde la página Formularios, puede:

- **Añadir un formulario** — Haga clic en **Add Form** para crear un formulario personalizado nuevo.
- **Editar un formulario** — Haga clic en un nombre de formulario para abrirlo y modificar sus preguntas, miembros o configuración.
- **Archivar un formulario** — Mueva formularios que ya no necesita a la pestaña **Archived Forms** para mantener su lista limpia.
- **Restaurar un formulario** — Vaya a la pestaña **Archived Forms** y restaure cualquier formulario que desee activar nuevamente.

## Trabajar con un formulario

Haga clic en cualquier nombre de formulario para abrirlo. El editor de formulario tiene hasta tres pestañas:

- **Questions** — Construya la estructura del formulario añadiendo campos de diferentes tipos. Vea [Creación de formularios](./creating-forms.md) para obtener detalles.
- **Form Members** — Controle quién puede acceder y gestionar el formulario (solo formularios independientes).
- **Form Submissions** — Vea respuestas que han sido enviadas. Vea [Gestión de envíos](./managing-submissions.md) para obtener detalles.

:::tip
Los formularios con una URL pública se pueden compartir a través de enlace, incrustar en su sitio web o incluir en correos electrónicos. Esto facilita la recopilación de información de personas que quizás no tengan una cuenta de iglesia.
:::

:::info
Puede controlar quién tiene acceso a cada formulario usando la pestaña **Form Members**. Asigne roles de **Admin** o **View Only** para darle a su equipo el nivel correcto de acceso.
:::
