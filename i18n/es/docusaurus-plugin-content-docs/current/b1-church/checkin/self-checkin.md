# Autoregistro

<div class="article-intro">

El proceso de autoregistro te permite registrar tu asistencia y la de tu familia en solo unos pocos pasos. Es una alternativa rápida al uso de un kiosco físico en la iglesia.

</div>

<div class="prereqs">
<h4>Antes de comenzar</h4>

- Debes [iniciar sesión](../getting-started/logging-in.md) en tu cuenta de B1.church.
- Los miembros de tu familia deben estar vinculados a tu cuenta. Si falta algún familiar, pide a tu administrador de la iglesia que lo agregue a tu hogar.

</div>

## El proceso de registro

El registro sigue un proceso sencillo de tres pasos. Abre **Registro** desde la [barra de pestañas o la página Más](../getting-started/navigating.md) para comenzar.

### Paso 1: Selecciona un servicio

Cuando abras la página de registro, verás una lista de los servicios disponibles (por ejemplo, “Domingo por la mañana” o “Miércoles por la noche”). Cada tarjeta de servicio muestra el nombre del servicio y la sede, si tu iglesia tiene varias ubicaciones.

Haz clic en un servicio para seleccionarlo y pasar al siguiente paso.

### Paso 2: Selecciona los miembros de la familia y los grupos

Después de seleccionar un servicio, verás los miembros de tu familia bajo **Quién está aquí**. Para cada persona que asista:

1. Toca el nombre de un miembro de la familia para expandir su entrada.
2. Verás los **horarios** disponibles para el servicio que seleccionaste. Si tu iglesia ha establecido un horario de registro para un horario de servicio, solo podrás elegirlo mientras el registro esté abierto (por ejemplo, desde 30 minutos antes del servicio hasta poco después de que termine). Fuera de ese periodo, el horario aparece como **Cerrado**, junto con la hora de apertura si se conoce; por ejemplo, **Cerrado · abre dom 9:30 AM**.
3. Toca **Seleccionar grupo** junto a un horario para elegir en qué grupo se registrará la persona (por ejemplo, “Adoración principal”, “Sala de niños 1” o “Grupo de jóvenes”).
4. Repite el proceso para cada miembro de la familia que asista.

No necesitas registrar a todos los miembros de tu familia; solo expande y asigna grupos a las personas que realmente están presentes.

Quienes ya se hayan registrado para este servicio hoy mostrarán una insignia **Ya registrado** junto a su nombre.

### Paso 3: Confirmación

Una vez que hayas seleccionado los grupos de todas las personas que asistan, toca el botón en la parte inferior de la página. Este botón cuenta las personas que has seleccionado; por ejemplo, **Registrar a 1 persona** o **Registrar a 3 personas**.

Si alguien que seleccionaste ya se registró para este servicio hoy, aparecerá una ventana de **Ya registrado** que los menciona primero. Toca **Registrar de nuevo** para actualizar sus grupos, o **Cancelar** para volver atrás.

Verás una confirmación de que tu registro se completó y tu asistencia se guardó. Después de un momento, la página volverá a la lista de servicios, lista para el siguiente registro.

Si tu iglesia imprime etiquetas con el nombre en una estación de registro, verás en cambio **¡Estás registrado!** con un código QR y un código de seguridad. Muestra el código en una estación de registro para imprimir tus etiquetas con el nombre y, luego, toca **Listo**. En un kiosco de B1 Checkin, toca **Escanear código** y acerca el código QR a la cámara; consulta [Imprimir etiquetas para un registro desde el teléfono](../../b1-checkin/check-in/looking-up-members.md#printing-labels-for-a-phone-check-in).

Si tu familia ya está registrada para el servicio que seleccionaste, aparecerá un enlace **Mostrar código de registro** junto al encabezado **Quién está aquí**. Tócalo para volver a mostrar el código QR y el código de seguridad; por ejemplo, si cerraste la página antes de llegar a una estación de registro.

:::tip
Si necesitas cambiar la selección de un grupo antes de completar el registro, toca el botón **Cambiar** junto a cualquier horario para elegir un grupo diferente.
:::

## Cosas que debes saber

- Solo puedes registrar a los miembros de la familia que estén vinculados a tu cuenta. Si falta algún familiar, pide a tu administrador de la iglesia que lo agregue a tu hogar.
- Si no aparece ningún servicio en la página de registro, es posible que tu iglesia no tenga servicios configurados para el registro en este momento.
- Si seleccionas un servicio y ves un mensaje como “El registro abre dom 9:30 AM.” (o “El registro no está abierto para este servicio en este momento.”), ninguno de los horarios de ese servicio está dentro de su periodo de registro. Inténtalo de nuevo cuando se abra el registro.
- Si tu familia se registró para un horario de servicio anterior, puedes volver y registrarte para un horario posterior cuando se abra, incluso si el anterior ya cerró.
- Si una sala que elegiste está llena o cerrada, verás el mensaje: “Una sala que elegiste está llena o cerrada para el registro. Por favor, consulta a un voluntario.”
- Si una sala de niños no tiene suficientes voluntarios registrados para otro niño, verás un mensaje con el nombre de la sala; por ejemplo: “Sala de niños 1 no tiene suficientes voluntarios para otro niño en este momento. Por favor, elige otra sala o consulta a un voluntario.”

:::warning
El registro solo está disponible cuando tu iglesia tiene servicios activos configurados. Si no ves ningún servicio en la lista, consulta con la oficina de tu iglesia para confirmar si el autoregistro está habilitado.
:::
