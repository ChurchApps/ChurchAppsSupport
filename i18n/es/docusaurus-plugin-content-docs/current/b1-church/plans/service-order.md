# Orden de Servicio

<div class="article-intro">

Cuando abres un plan, la pestaña **Orden de Servicio** muestra la secuencia de elementos para ese servicio. Esto te da a ti y a tu equipo una vista compartida del flujo del servicio, incluyendo el tiempo, detalles de canciones y descripciones para cada elemento.

</div>

<div class="prereqs">
<h4>Antes de Comenzar</h4>

- Debes estar [registrado](../getting-started/logging-in.md) en tu cuenta de B1.church.
- Abre un plan desde tu [lista de Planes](./viewing-plans.md) para ver su orden de servicio.

</div>

## Lo Que Muestra la Orden de Servicio

La orden de servicio se muestra como una lista de elementos en el orden en que ocurrirán durante el servicio. Cada elemento incluye:

- **Tiempo acumulativo** -- El tiempo acumulado desde el inicio del servicio, para que sepas cuándo se espera que comience cada elemento.
- **Etiqueta y descripción del elemento** -- El nombre del elemento (como el título de una canción, oración o anuncio) junto con cualquier nota o descripción.
- **Duración** -- Cuánto tiempo se espera que dure el elemento.

Los elementos se organizan bajo **encabezados** que agrupan elementos relacionados (por ejemplo, "Conjunto de Adoración" o "Mensaje"). Esto hace que sea fácil escanear la estructura general del servicio.

Las secciones de lecciones y plan de estudios también pueden expandirse en una carpeta de acciones individuales anidadas debajo -- haz clic en la sección para expandir o contraer sus acciones y ver cada paso que tu equipo seguirá.

## Viendo Letras y Acordes de Canciones

Haz clic en una canción en la orden de servicio para abrir sus letras y acordes. Usa el menú desplegable **Tonalidad** en la parte superior para transponer los acordes sobre la marcha -- útil si tu instrumento o rango vocal necesita una tonalidad diferente de la que el líder de adoración planeó.

## Contenido de Plan de Estudios y Lecciones

Si el plan tiene contenido de plan de estudios o lecciones asociado de un proveedor como [Lessons.church](../content/lessons.md), verás una vista previa de ese contenido dentro de la orden de servicio. Esto puede incluir secciones de lecciones, materiales de presentación y otros recursos que tu equipo necesita para el servicio.

## Imprimiendo la Orden de Servicio

La aplicación de miembros de B1.church no tiene una opción de impresión para planes. Si necesitas una copia impresa con la lista del equipo y la orden de servicio completa, pide a un miembro del personal que la imprima desde B1 Admin. Consulta [Imprimiendo Planes](../../b1-admin/serving/plans.md#printing-plans).
