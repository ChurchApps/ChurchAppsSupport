# Orden del Servicio

<div class="article-intro">

Cuando abres un plan, la sección **Orden del Servicio** muestra la secuencia de elementos para ese servicio. Esto te da a ti y a tu equipo una vista compartida del flujo del servicio, incluyendo tiempos, detalles de canciones y descripciones de cada elemento.

</div>

<div class="prereqs">
<h4>Antes de Comenzar</h4>

- Debes haber [iniciado sesión](../getting-started/logging-in.md) en tu cuenta de B1.church.
- Abre un plan desde tu [lista de Planes](./viewing-plans.md) para ver su orden de servicio.

</div>

## Lo Que Muestra el Orden del Servicio

El orden del servicio se muestra como una lista de elementos en el orden en que ocurrirán durante el servicio. Cada elemento incluye:

- **Tiempo acumulado** -- El tiempo transcurrido desde el inicio del servicio, para que sepas cuándo se espera que comience cada elemento.
- **Etiqueta y descripción del elemento** -- El nombre del elemento (como el título de una canción, una oración o un anuncio) junto con cualquier nota o descripción.
- **Duración** -- Cuánto tiempo se espera que tome el elemento.

Los elementos están organizados bajo **encabezados** que agrupan elementos relacionados (por ejemplo, "Set de Adoración" o "Mensaje"). Esto facilita examinar la estructura general del servicio.

## Ver Letras y Acordes de Canciones

Haz clic en una canción en el orden del servicio para abrir su letra y acordes. Usa el menú desplegable **Armadura de Clave** en la parte superior para transponer los acordes sobre la marcha -- útil si tu instrumento o rango vocal necesita una clave diferente a la que planeó el líder de adoración.

## Currículo y Contenido de Lecciones

Si el plan tiene currículo asociado o contenido de lecciones de un proveedor como [Lessons.church](../content/lessons.md), verás una vista previa de ese contenido dentro del orden del servicio. Esto puede incluir secciones de lecciones, materiales de presentación y otros recursos que tu equipo necesita para el servicio.

## Imprimir el Orden del Servicio

Puedes imprimir una versión formateada del orden del servicio para llevar contigo el día del servicio.

1. Abre el plan desde tu lista de **Planes**.
2. En la sección **Orden del Servicio**, haz clic en el ícono de **imprimir** en la esquina superior derecha.
3. Se abre una nueva ventana con un diseño imprimible que incluye:
   - La **fecha del servicio** en la parte superior.
   - **Asignaciones de equipo** agrupadas por categoría a la izquierda, mostrando cada posición y quién la ocupa.
   - El **orden de servicio completo** a la derecha con columnas de tiempo, detalles del elemento y duración.
4. El cuadro de diálogo de impresión de tu navegador se abrirá automáticamente para que puedas imprimir o guardar como PDF.

:::tip
El orden de servicio impreso es una excelente referencia para tener a mano durante los ensayos o el servicio mismo. Incluye tanto el listado del equipo como el orden completo del servicio en una sola página.
:::
