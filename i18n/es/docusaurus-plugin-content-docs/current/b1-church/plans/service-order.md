# Orden de servicio

<div class="article-intro">

Cuando abres un plan, la sección **Service Order** muestra los primeros elementos de ese servicio; toca **Full service order** para ver la secuencia completa. Esto le da a ti y a tu equipo una vista compartida del flujo del servicio, incluidos los tiempos, la información de las canciones y las descripciones de cada elemento.

</div>

<div class="prereqs">
<h4>Antes de comenzar</h4>

- Debes [haber iniciado sesión](../getting-started/logging-in.md) en tu cuenta de B1.church.
- Abre un plan desde tu [lista de planes](./viewing-plans.md) para ver su orden de servicio.

</div>

## Qué muestra el orden de servicio

El orden de servicio se presenta como una lista de elementos en el orden en que ocurrirán durante el servicio. Cada elemento incluye:

- **Tiempo acumulado**: el tiempo transcurrido desde el inicio del servicio, para que sepas cuándo se espera que comience cada elemento.
- **Etiqueta y descripción del elemento**: el nombre del elemento (como el título de una canción, una oración o un anuncio), junto con las notas o descripciones que tenga.
- **Duración**: cuánto tiempo se espera que dure el elemento.

Los elementos se organizan bajo **encabezados** que agrupan los elementos relacionados (por ejemplo, "Worship Set" o "Message"). Así es más fácil revisar la estructura general del servicio.

Las secciones de lecciones y currículo también pueden desplegarse en una carpeta con las acciones individuales anidadas debajo: haz clic en la sección para expandir o contraer sus acciones y ver cada paso que recorrerá tu equipo.

## Ver la letra y los acordes de las canciones

Haz clic en una canción del orden de servicio para abrir su letra y sus acordes. Usa el menú **Key Signature** en la parte superior para transportar los acordes sobre la marcha; es útil si tu instrumento o tu rango vocal necesitan una tonalidad distinta a la que planeó el líder de adoración.

## Currículo y contenido de lecciones

Si el plan tiene currículo o contenido de lecciones asociado de un proveedor como [Lessons.church](../content/lessons.md), verás una vista previa de ese contenido dentro del orden de servicio. Puede incluir secciones de lecciones, materiales de presentación y otros recursos que tu equipo necesita para el servicio.

## Imprimir el orden de servicio

La app para miembros de B1.church no tiene una opción para imprimir planes. Si necesitas una copia impresa con la lista del equipo y el orden de servicio completo, pide a un miembro del personal que la imprima desde B1 Admin. Consulta [Imprimir planes](../../b1-admin/serving/plans.md#printing-plans).
