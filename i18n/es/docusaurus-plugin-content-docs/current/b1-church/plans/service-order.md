# Orden del servicio

<div class="article-intro">

Cuando abres un plan, la sección **Orden del servicio** muestra los primeros elementos de ese servicio; toca **Orden completo del servicio** para ver toda la secuencia. Así tú y tu equipo tienen una vista compartida del flujo del servicio, con los tiempos, los detalles de las canciones y las descripciones de cada elemento.

</div>

<div class="prereqs">
<h4>Antes de comenzar</h4>

- Debes [iniciar sesión](../getting-started/logging-in.md) en tu cuenta de B1.church.
- Abre un plan desde tu [lista de planes](./viewing-plans.md) para ver su orden del servicio.

</div>

## Qué muestra el orden del servicio {#what-the-service-order-shows}

El orden del servicio se muestra como una lista de elementos en el orden en que ocurrirán durante el servicio. Cada elemento incluye:

- **Tiempo acumulado** -- El tiempo transcurrido desde el inicio del servicio, para que sepas cuándo se espera que comience cada elemento.
- **Etiqueta y descripción del elemento** -- El nombre del elemento (como el título de una canción, una oración o un anuncio) junto con cualquier nota o descripción.
- **Duración** -- Cuánto tiempo se espera que dure el elemento.

Los elementos se organizan bajo **encabezados** que agrupan elementos relacionados (por ejemplo, "Set de alabanza" o "Mensaje"). Cada encabezado muestra el tiempo total de sus elementos. Esto facilita revisar la estructura general del servicio.

Las canciones muestran una nota musical y la tonalidad en la que se tocarán (por ejemplo, "Tonalidad de Sol"). Un elemento con un enlace adjunto muestra su nombre como enlace; tócalo para abrirlo (los enlaces de audio se reproducen directamente en la página).

Las secciones de lecciones y currículo también pueden expandirse en una carpeta con las acciones individuales anidadas debajo: haz clic en la sección para expandir o contraer sus acciones y ver cada paso que recorrerá tu equipo.

## Ver letras y acordes de canciones {#viewing-song-lyrics-and-chords}

Haz clic en una canción del orden del servicio para abrir sus detalles: el artista, los botones de **Armadura de clave**, las **Letras** (con acordes cuando la canción los tiene), datos de la canción como álbum, BPM, tonalidad, compás y duración, y **Enlaces** a la canción en servicios como Spotify, YouTube o PraiseCharts. Toca una tonalidad en **Armadura de clave** para transponer los acordes al instante, útil si tu instrumento o tu rango vocal necesitan una tonalidad diferente a la que planeó el líder de alabanza. Toca **Cerrar** cuando termines.

## Currículo y contenido de lecciones {#curriculum-and-lesson-content}

Si el plan tiene asociado currículo o contenido de lecciones de un proveedor como [Lessons.church](../content/lessons.md), verás una vista previa de ese contenido dentro del orden del servicio. Puede incluir secciones de la lección, materiales de presentación y otros recursos que tu equipo necesita para el servicio.

## Imprimir el orden del servicio {#printing-the-service-order}

La aplicación móvil de B1.church no tiene una opción para imprimir los planes. Si necesitas una copia impresa con la lista del equipo y el orden completo del servicio, pide a un miembro del personal que la imprima desde B1 Admin. Consulta [Imprimir planes](../../b1-admin/serving/plans.md#printing-plans).
