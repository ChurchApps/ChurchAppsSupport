# Planes de servicio de WorshipCommons

<div class="article-intro">

Un plan de servicio en WorshipCommons es una lista de canciones para el domingo. Ordena las canciones, elige la tonalidad, el capo y las secciones de cada una, y luego comparte un único enlace con tu banda. Desde el plan puedes abrir una vista de escenario para un atril, imprimir un folleto o exportar todo el set a tu software de presentaciones.

</div>

:::info
Los planes de servicio se guardan en tu navegador web, no en tu cuenta, y no necesitas iniciar sesión para usarlos. Un enlace para compartir contiene todo el set, así que guárdalo si cambias de dispositivo. Si tu iglesia planifica los servicios en B1 Admin, consulta [Planes](../b1-admin/serving/plans.md).
:::

## Crear un plan de servicio

1. Haz clic en **Planes de servicio** en el menú superior.
2. Escribe un nombre, como "Domingo 14 de septiembre" o "Noche de jóvenes", y haz clic en **Crear plan de servicio**.

También puedes empezar un plan desde cualquier canción. En la página de la canción, haz clic en **+ Añadir al plan de servicio**, escribe un nombre debajo de la lista y haz clic en **Crear**.

## Añadir canciones

1. Abre la página de una canción. Primero elige la tonalidad que quieres, porque la canción se añade al plan en la tonalidad que aparece en pantalla.
2. Haz clic en **+ Añadir al plan de servicio**.
3. Haz clic en el nombre del plan. Una marca de verificación indica que la canción está en ese plan. Haz clic de nuevo para quitarla.

El botón muestra entonces **✓ En** seguido del nombre del plan. Haz clic en el enlace **Abrir** con el nombre del plan en la ventana emergente para ir al plan.

## Organizar el set

Abre un plan desde la página **Planes de servicio**. Para cada canción puedes:

- **Reordenar** -- Usa los botones **↑** y **↓**, o arrastra la canción a una nueva posición. Haz clic en **Quitar** para eliminarla.
- **Tonalidad** -- Elige entre las tonalidades **Publicadas** de la canción o cualquier otra (listadas bajo **Vista previa (cualquier tonalidad)**).
- **Capo** -- Elige un traste para el capo. El plan muestra qué acordes tocar.
- **Secciones** -- Define el orden de las estrofas y los coros. Usa las flechas para mover una sección, **×** para quitarla y **+ Añadir sección** para agregar una (por ejemplo, un coro repetido). Haz clic en **Restablecer al predeterminado** para volver al orden habitual de la canción.
- **Arreglo** -- Escribe una nota breve para la banda, como "Coro ×2 al final, última estrofa a capela".

Arriba del plan se muestra el número de canciones y la duración aproximada del set. Los cambios se guardan automáticamente.

## Compartir con tu equipo

1. Haz clic en **Compartir enlace**. El enlace se copia al portapapeles.
2. Envíalo a tu banda por mensaje de texto o correo electrónico.

Cualquiera que abra el enlace verá el plan con cada tonalidad, capo, sección y nota, sin necesidad de una cuenta. Puede hacer clic en **Guardar una copia** para conservar su propia copia editable en el navegador.

En la página **Planes de servicio** también puedes **Compartir**, **Renombrar**, **Duplicar** o **Eliminar** un plan.

## Usar el plan el domingo

- **Modo escenario** -- Muestra una partitura por pantalla para una tableta en un atril. Usa las flechas (o las teclas **←** y **→**) para moverte entre canciones, y los botones de tamaño de texto para agrandar la partitura. El modo escenario intenta evitar que la pantalla se apague; la barra indica si está **Manteniendo la pantalla activa**.
- **Imprimir folleto** -- Imprime todas las partituras en orden, una por página, con una portada que enumera las canciones y tonalidades. Elige **Texto grande** o **Mostrar acordes** y haz clic en **Imprimir**.
- **Copiar para OnSong / Planning Center** -- Copia todas las partituras en tus tonalidades y secciones, listas para pegar.

## Exportar el set

Haz clic en **FreeShow**, **OpenLP**, **ProPresenter** o **PowerPoint** para descargar todo el set para esa herramienta, en las tonalidades y secciones que elegiste.

Haz clic en **Paquete para iglesias en casa** para descargar un ZIP con la partitura de cada canción en tu tonalidad, la letra, las diapositivas, la atribución, una lista del set y un archivo LICENSE.txt.

:::warning
Las canciones con licencia CC BY-SA se excluyen del paquete para iglesias en casa a menos que marques **Paquete con licencia compartida (incluir canciones CC BY-SA)**. Si las incluyes, todo lo que crees a partir del paquete debe compartirse bajo la misma licencia. Las partituras, el modo escenario y el folleto siempre incluyen estas canciones.
:::
