# Conectarse a los proveedores

<div class="article-intro">

Antes de poder explorar el contenido de un proveedor, necesitas conectarte a él. Algunos proveedores requieren autenticación mediante un código QR o un inicio de sesión por correo electrónico, mientras que otros se pueden conectar con un solo clic.

</div>

<div class="prereqs">
<h4>Antes de comenzar</h4>

- Instala e inicia FreePlay -- consulta [Primeros pasos](../getting-started/)
- Ten a mano el control remoto de tu TV para la navegación
- Para los proveedores que requieren inicio de sesión, ten disponibles tus credenciales de cuenta

</div>

:::tip ¿Configurando B1 Admin y FreePlay juntos?
Nuestra **<a href="/guides/freeplay-b1admin" target="_blank">guía paso a paso</a>** explica cómo vincular B1 Admin, programar una lección y conectar FreePlay, todo en un solo lugar. Ábrela en una pestaña nueva para seguirla mientras trabajas.
:::

## Explorar los proveedores disponibles

1. Abre la pantalla **Content Providers** desde la barra lateral (selecciona el ícono **Providers** en la parte inferior)
2. Verás una cuadrícula de tarjetas de proveedores, cada una con el logotipo y el nombre del proveedor
3. Los proveedores conectados muestran una insignia verde de **Connected** debajo de su nombre
4. Los proveedores que aún no están disponibles muestran una etiqueta de **Coming Soon**

## Conectarse sin autenticación

Algunos proveedores no requieren inicio de sesión. Cuando seleccionas uno de estos proveedores, FreePlay se conecta de inmediato y abre el explorador de contenido. No se necesitan credenciales.

## Autenticación por flujo de dispositivo (código QR)

Ciertos proveedores usan un flujo de dispositivo, similar a como inicias sesión en las aplicaciones de transmisión en una TV:

1. Selecciona la tarjeta del proveedor en la pantalla **Content Providers**
2. FreePlay muestra un código QR y una URL de verificación
3. Escanea el código QR con tu teléfono, o visita la URL mostrada desde cualquier dispositivo
4. Ingresa el código de usuario que aparece en la pantalla de la TV
5. Completa el proceso de inicio de sesión en tu teléfono o computadora
6. FreePlay detecta el inicio de sesión exitoso y muestra **Connected!**
7. El explorador de contenido se abre automáticamente

:::info
Un indicador pulsante de **Waiting for authorization** muestra que FreePlay está verificando tu inicio de sesión. El código caduca después de varios minutos, así que completa el proceso con prontitud.
:::

**Go Curriculum** usa este mismo patrón de inicio de sesión por código QR: escanea el código e inicia sesión con tu cuenta de gocurriculum.com para conectarte.

## Inicio de sesión por formulario

Otros proveedores usan un inicio de sesión tradicional de correo electrónico y contraseña:

1. Selecciona la tarjeta del proveedor
2. Ingresa tu **Email** y **Password** usando el teclado en pantalla
3. Selecciona el botón **Sign In**
4. Si tus credenciales son correctas, FreePlay muestra **Connected!** y abre el explorador de contenido

:::tip
Usa el pad direccional de tu control remoto para moverte entre el campo de correo electrónico, el campo de contraseña y el botón de inicio de sesión. Presiona **Select** en un campo de texto para abrir el teclado en pantalla.
:::

## Desconectar un proveedor

Para desconectarte de un proveedor al que ya te has conectado:

1. Ve a la pantalla **Content Providers**
2. Selecciona la tarjeta del proveedor que muestra la insignia **Connected**
3. Aparecerá un mensaje de confirmación preguntando si deseas desconectarte
4. Elige **Disconnect** para eliminar la conexión

Después de desconectarte, el contenido del proveedor ya no aparecerá en tu barra lateral.

:::warning
Desconectarte elimina la autenticación guardada en tu dispositivo. Necesitarás iniciar sesión de nuevo si quieres volver a conectarte más tarde.
:::
