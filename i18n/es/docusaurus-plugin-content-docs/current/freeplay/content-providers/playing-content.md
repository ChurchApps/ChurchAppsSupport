# Reproducir contenido

<div class="article-intro">

El reproductor de FreePlay ocupa toda la pantalla y está diseñado para los mandos a distancia de los televisores. Reproduce vídeos y diapositivas de imagen de un proveedor, de una lección descargada, de un plan o de tu carpeta de anuncios, y avanza por ellos automáticamente o a tu ritmo.

</div>

<div class="prereqs">
<h4>Antes de empezar</h4>

- Elige algo para reproducir. Consulta [Explorar y descargar contenido](./browsing-content), [Modo plan](../plan-mode/) o [Anuncios](./announcements)
- Pulsa **Iniciar** para abrir el reproductor

</div>

:::info
Las pantallas vinculadas a un calendario usan un reproductor programado independiente con controles ligeramente distintos. Consulta [Reproducción programada en el televisor](../scheduled-mode/scheduled-playback).
:::

## Controles del reproductor

Usa el mando a distancia del televisor para controlar la reproducción:

| Botón del mando | Acción |
|---|---|
| **Seleccionar / Reproducir-Pausa** | Pausar o reanudar |
| **Flecha derecha** | Saltar a la siguiente diapositiva o vídeo |
| **Flecha izquierda** | Volver a la diapositiva o vídeo anterior |
| **Avance rápido** | Saltar 10 segundos hacia delante en un vídeo. En una diapositiva, ir al siguiente elemento |
| **Rebobinar** | Retroceder 10 segundos en un vídeo. En una diapositiva, ir al elemento anterior |
| **Flecha arriba** | Abrir **Seleccionar un mensaje** para saltar a un elemento concreto |
| **Abajo / Atrás** | Salir del reproductor |

:::tip
También puedes usar gestos en mandos con pantalla táctil. Desliza a la izquierda para avanzar, a la derecha para retroceder, hacia abajo para abrir **Seleccionar un mensaje** y hacia arriba para salir del reproductor.
:::

## Vídeos y diapositivas

Cuando pausas, aparece un icono de pausa sobre el contenido. Pulsa **Seleccionar** o **Reproducir-Pausa** de nuevo para reanudar.

Los vídeos pasan al siguiente elemento cuando terminan. Un vídeo configurado para repetirse se reproduce en bucle hasta que saltas a otro elemento.

Las diapositivas de imagen avanzan solas después de unos segundos (5 segundos, salvo que el proveedor establezca su propio tiempo). Pulsa la **Flecha derecha** para avanzar antes, o pausa para mantener una diapositiva en pantalla.

## Seleccionar un mensaje

Pulsa **Arriba** durante la reproducción para abrir **Seleccionar un mensaje**. Muestra todos los elementos con una miniatura y un título, y marca el que se está reproduciendo como **REPRODUCIENDO AHORA**. Desplázate hasta cualquier elemento y pulsa **Seleccionar** para saltar directamente a él. Pulsa **Atrás** para cerrarlo sin cambiar nada.

## Salir del reproductor

Pulsa **Abajo** o **Atrás** en el mando para salir del reproductor. A dónde vuelves depende de lo que estabas reproduciendo:

- **Contenido de un proveedor** - Vuelves al explorador de contenido
- **Un plan** - Vuelves a la pantalla de descarga del plan. Consulta [Modo plan](../plan-mode/)
- **Una descarga** - Vuelves a la pantalla **Descargas**

:::info
La pantalla permanece activa mientras el reproductor está abierto, para que el televisor no entre en suspensión en medio de una lección.
:::
