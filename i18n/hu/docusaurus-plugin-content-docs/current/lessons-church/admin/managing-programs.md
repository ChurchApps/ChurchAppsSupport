# Programok kezelése

<div class="article-intro">

A programok a Lessons.church tananyagainak legfelső szintű tárolói. Egy program egy teljes tananyag-sorozatot jelent, például „Ark Kids” vagy „Youth Foundations”. Ez az útmutató a programok létrehozását, szerkesztését és szervezését ismerteti az adminisztrációs felületen.

</div>

<div class="prereqs">
<h4>Mielőtt elkezdi</h4>

- Rendelkezzen adminisztrátori jogosultsággal a Lessons.church-höz (lásd: [Adminisztráció áttekintése](./index.md))
- Készítsen elő egy programnevet, leírást és bélyegképet

</div>

## Program létrehozása

1. Lépjen az **Admin** területre.
2. Kattintson az **Add Program** gombra.
3. Töltse ki a következő mezőket:
   - **Name** -- A program megjelenő neve (pl. „Ark Kids”).
   - **Slug** -- Egy URL-barát azonosító (pl. „ark-kids”). Ez a webcímekben jelenik meg.
   - **Description** -- Rövid összefoglaló arról, mit fed le a program.
   - **Image** -- Töltsön fel egy bélyegképet, amely képviseli a programot.
4. Mentse a programot.

Az új program ezentúl megjelenik az adminisztrációs programlistában, és amint lesznek hozzá tanulmányai és leckéi, a nyilvános oldalon is.

## Program szerkesztése

1. Kattintson a program nevére az adminisztrációs listában.
2. Módosítsa a mezők bármelyikét (**Name**, **Slug**, **Description** vagy **Image**).
3. Mentse a módosításokat.

## Tanulmányok szervezése a programon belül

Amint létezik a program, tanulmányokat adhat hozzá. A tanulmányok az adminisztrációs nézetben a program alatt jelennek meg. Kattintson a program melletti lenyíló nyílra a tanulmányok megtekintéséhez, vagy onnan adjon hozzá újat. További részletekért lásd: [Tanulmányok kezelése](./managing-studies.md).

## Tanulmány-kategóriák

Ha a programnak sok tanulmánya van, azokat **kategóriákba** rendezheti. A kategóriák témakör, korosztály vagy más Ön által választott szempont szerint csoportosítják a tanulmányokat. Ez megkönnyíti a felhasználók számára a nagy programokban való böngészést.

## Program szintű erőforrások feltöltése

Letölthető fájlokat csatolhat a programhoz. Ezek a program egészére vonatkoznak, nem egy konkrét tanulmányra vagy leckére, például egy témaköri áttekintő dokumentum vagy egy önkéntesi kézikönyv.

1. Nyissa meg a programot az adminisztrációs nézetben.
2. Lépjen a **Resources** szakaszra.
3. Töltse fel a fájljait.

## Gyorsítótár törlése

A program módosítása után előfordulhat, hogy törölnie kell a gyorsítótárat, hogy a frissítések megjelenjenek a nyilvános oldalon. Használja az adminisztrációs területen a **Clear Cache** lehetőséget a tartalom frissítéséhez.

:::tip
Válasszon kifejező programnevet, és írjon világos leírást. Ez az első dolog, amit az egyházak látnak, amikor a tananyagtárat böngészik, ezért egy jó összefoglaló segít nekik eldönteni, hogy a program megfelel-e az igényeiknek.
:::
