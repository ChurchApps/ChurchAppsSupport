# Первоначальная настройка

<div class="article-intro">

После создания учетной записи и церкви нужно выполнить несколько важных шагов настройки, прежде чем приглашать команду. В этом руководстве описан рекомендуемый порядок настройки, чтобы ваша церковь была готова к работе с первого дня.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- [Создайте учетную запись](./create-account.md) и зарегистрируйте свою церковь
- Подготовьте логотип церкви и материалы для брендинга (необязательно, но рекомендуется)

</div>

## Шаг 1: Настройте информацию о церкви

1. Откройте [меню Jump](../b1-admin/introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу B1 Admin), разверните раздел **Настройки** и нажмите **Настройки**.
2. В разделе **Информация о церкви** нажмите **Редактировать**.
3. Введите **название** церкви, **поддомен** и **адрес**.
4. Нажмите **Сохранить**, чтобы применить изменения.

## Шаг 2: Настройте брендинг

1. В меню Jump выберите **Сайт > Внешний вид**.
2. Загрузите **логотип церкви**.
3. Настройте дополнительные параметры брендинга, например цвета и изображения.
4. Ваш брендинг будет отображаться на сайте B1.church и в приложении B1 App.

:::tip
Если подготовить логотип и брендинг до приглашения членов команды, при их первом входе сложится аккуратное первое впечатление.
:::

## Шаг 3: Настройте роли и пригласите команду

1. В меню Jump выберите **Настройки > Роли**.
2. Создайте роли для своей команды (например, «Пастор», «Секретарь», «Казначей»).
3. Назначьте каждой роли соответствующие права доступа.
4. Добавьте членов команды, найдя их учетные записи и назначив им роли.

## Шаг 4: Настройте основные разделы

Когда команда будет на месте, начните заполнять основные разделы B1 Admin:

1. **Люди** -- Добавьте членов в церковный справочник. Это основа для всего остального, поэтому начните именно с этого раздела. Людей можно добавить вручную или с помощью инструмента **Импорт/Экспорт** в разделе **Настройки**.
2. **Группы** -- Создайте группы для малых групп, служебных команд, классов и других собраний.
3. **Посещаемость** -- Настройте кампусы, службы и время служений для учета посещаемости.
4. **Пожертвования** -- Создайте фонды пожертвований и подключите платежный шлюз (Stripe), чтобы принимать онлайн-пожертвования.
5. **Сайт** -- Создайте публичный сайт церкви с помощью конструктора сайтов B1.church.

:::info
Не обязательно настраивать все разделы сразу. Многие церкви начинают с **Люди** и **Группы**, а затем добавляют **Посещаемость** и **Пожертвования», когда привыкают к платформе.
:::

## Рекомендуемый порядок

Для наиболее удобной настройки рекомендуем следующий порядок:

1. **Люди** -- Сначала добавьте своих членов и постоянных посетителей.
2. **Группы** -- Распределите людей по осмысленным группам.
3. **Посещаемость** -- Начните отслеживать, кто приходит каждую неделю.
4. **Пожертвования** -- Настройте прием пожертвований, когда люди уже будут в системе.
5. **Сайт** -- Создайте публичный сайт последним, когда данные уже будут на месте.

Выполнив эти шаги, вы можете считать, что церковь готова к работе. Подробные руководства по каждому разделу см. в документации [B1 Admin](/docs/b1-admin/).
