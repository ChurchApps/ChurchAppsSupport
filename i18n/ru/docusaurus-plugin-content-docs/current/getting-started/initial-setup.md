# Начальная настройка

<div class="article-intro">

После создания вашей учетной записи и церкви необходимо выполнить несколько важных шагов для настройки перед приглашением вашей команды. Это руководство проведет вас через рекомендуемый порядок настройки, чтобы ваша церковь была готова с первого дня.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- [Создайте вашу учетную запись](./create-account.md) и зарегистрируйте вашу церковь
- Подготовьте логотип вашей церкви и ресурсы брендирования (опционально, но рекомендуется)

</div>

## Шаг 1: Настройка информации о вашей церкви

1. Откройте **section menu** в верхнем левом углу (название раздела со стрелкой) и выберите **Settings**.
2. Нажмите **Edit Settings**.
3. Введите **name**, **address** и **contact details** вашей церкви.
4. Нажмите **Save** для применения ваших изменений.

## Шаг 2: Настройка вашего брендирования

1. С **Dashboard** (вашей домашней страницы) перейдите на **Website**, затем выберите **Appearance**.
2. Загрузите **church logo**.
3. Настройте любые дополнительные опции брендирования, такие как цвета и изображения.
4. Ваше брендирование будет отображаться на вашем веб-сайте B1.church и в мобильном приложении B1.

:::tip
Подготовив логотип и брендирование перед приглашением членов команды, вы создадите полированное первое впечатление при их входе.
:::

## Шаг 3: Настройка ролей и приглашение вашей команды

1. Нажмите **Roles** на странице **Settings**.
2. Создайте роли для вашей команды (например, "Pastor", "Secretary", "Treasurer").
3. Назначьте соответствующие разрешения для каждой роли.
4. Добавьте членов команды, выполнив поиск их учетных записей и назначив их ролям.

## Шаг 4: Настройка ваших ключевых областей

Когда ваша команда на месте, начните разработку основных областей B1 Admin:

1. **People** -- Добавьте членов в справочник вашей церкви. Это основание для всего остального, поэтому начните отсюда. Вы можете добавлять людей вручную или использовать инструмент **Import** из **Settings**.
2. **Groups** -- Создавайте группы для небольших групп, команд служения, классов и других собраний.
3. **Attendance** -- Настройте ваши кампусы, службы и время служб для отслеживания посещаемости.
4. **Donations** -- Установите фонды пожертвований и подключите ваш платежный шлюз (Stripe) для приема онлайн-пожертвований.
5. **Website** -- Постройте ваш открытый веб-сайт церкви, используя конструктор веб-сайтов B1.church.

:::info
Вам не нужно устанавливать каждую область сразу. Многие церкви начинают с **People** и **Groups**, затем добавляют **Attendance** и **Donations**, когда они привыкают к платформе.
:::

## Рекомендуемый порядок

Для наиболее гладкого опыта настройки мы предлагаем этот порядок:

1. **People** -- Сначала добавьте ваших членов и постоянных посетителей.
2. **Groups** -- Организуйте людей в значимые группы.
3. **Attendance** -- Начните отслеживать, кто приходит каждую неделю.
4. **Donations** -- Установите дающее, как только ваши люди окажутся в системе.
5. **Website** -- Постройте свой открытый сайт в последнюю очередь, после того, как ваши данные будут на месте.

После завершения этих шагов ваша церковь готова работать. Изучите документацию [B1 Admin](/docs/b1-admin/) для подробных руководств по каждой области.
