# Начальная установка

<div class="article-intro">

После создания вашей учётной записи и церкви есть несколько важных шагов для настройки перед приглашением вашей команды. Это руководство проведёт вас через рекомендуемый порядок настройки, чтобы ваша церковь была готова на день первый.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- [Создайте вашу учётную запись](./create-account.md) и зарегистрируйте вашу церковь
- Имейте логотип вашей церкви и брендинг активы готовыми (опционально, но рекомендуется)

</div>

## Шаг 1: Настройка информации о вашей церкви

1. Откройте **меню раздела** в левом верхнем углу (название раздела со стрелкой) и выберите **Параметры**.
2. Нажмите **Редактировать параметры**.
3. Введите **название**, **адрес** и **контактные данные** вашей церкви.
4. Нажмите **Сохранить**, чтобы применить изменения.

## Шаг 2: Настройка вашего брендинга

1. С **панели управления** перейдите на **Веб-сайт**, затем выберите **Внешний вид**.
2. Загрузите **логотип вашей церкви**.
3. Настройте все дополнительные опции брендинга, такие как цвета и изображения.
4. Ваш брендинг будет отображаться на вашем веб-сайте B1.church и в приложении B1 Mobile.

:::tip
Наличие вашего логотипа и брендинга готовыми перед приглашением членов команды даёт отполированное первое впечатление при входе.
:::

## Шаг 3: Настройка ролей и приглашение вашей команды

1. Нажмите **Роли** со страницы **Параметры**.
2. Создавайте роли для вашей команды (например, "Пастор", "Секретарь", "Казначей").
3. Назначьте соответствующие разрешения каждой роли.
4. Добавьте членов команды, найдя их учётные записи и назначив их ролям.

## Шаг 4: Настройка ваших ключевых областей

С вашей командой на месте, начните строить основные области B1 Admin:

1. **Люди** — добавьте членов в каталог вашей церкви. Это основание для всего остального, поэтому начните отсюда. Вы можете добавлять людей вручную или использовать инструмент **Импорт** из **Параметры**.
2. **Группы** — создавайте группы для малых групп, команд служения, классов и других собраний.
3. **Посещаемость** — настраивайте кампусы, службы и времена служб для отслеживания посещаемости.
4. **Пожертвования** — настройте фонды пожертвований и подключите свой платёжный шлюз (Stripe) для приёма онлайн пожертвований.
5. **Веб-сайт** — постройте ваш общедоступный веб-сайт церкви с помощью конструктора веб-сайтов B1.church.

:::info
Вам не нужно настраивать все области сразу. Много церквей начинают с **Люди** и **Группы**, затем добавляют **Посещаемость** и **Пожертвования** когда они становятся комфортнее с платформой.
:::

## Рекомендуемый порядок

Для самого гладкого опыта установки мы предлагаем этот порядок:

1. **Люди** — сначала добавьте ваших членов и обычных присутствующих.
2. **Группы** — организуйте людей в значимые группы.
3. **Посещаемость** — начните отслеживать, кто показывается каждую неделю.
4. **Пожертвования** — установите пожертвование, как только люди в системе.
5. **Веб-сайт** — постройте ваш публичный сайт в последнюю очередь, после того как данные на месте.

Как только вы завершили эти шаги, ваша церковь готова пойти. Изучите документацию [B1 Admin](/docs/b1-admin/) для подробных руководств каждой области.
