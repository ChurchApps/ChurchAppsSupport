# Мобильные приложения

<div class="article-intro">

Мобильные приложения ChurchApps созданы на **React Native** и **Expo** и работают как нативные приложения на Android, iOS и Android TV. Все мобильные приложения используют один и тот же инструментарий на основе Expo, поэтому если вы можете собрать одно из них, то сможете собрать и остальные.

</div>

## Приложения

| Приложение | Назначение | Платформа |
|-----|---------|----------|
| B1 Checkin | Киоск для пунктов регистрации | Android, iOS |
| LessonsScreen | Приложение для Android TV для показа уроков в классах | Android TV |

:::info
Приложение для участников — B1 App, а именно раздел `/mobile` в B1App, который участники устанавливают как Progressive Web App. Это веб-приложение, а не проект Expo; чтобы запустить его локально, см. [Веб-приложения](../web-apps/index.md).
:::

### B1 Checkin

Специализированное приложение-киоск для пунктов регистрации в церквях. Оно предлагает простой интерфейс, удобный для касаний, с помощью которого участники могут регистрировать детей и отмечать посещаемость богослужений и мероприятий.

### LessonsScreen

Приложение для Android TV, которое показывает учебные материалы в классах. Преподаватели могут отправлять слайды уроков, видео и задания на экран телевизора, что упрощает демонстрацию учебного материала на занятиях.

## Локальная настройка

Все мобильные приложения используют один и тот же инструментарий на основе Expo и следуют схожим шагам настройки. На примере B1 Checkin:

1. Установите **Node.js**, Android Studio (для эмулятора Android) и Xcode (для симулятора iOS, только для macOS) — см. [Предварительные требования](../setup/prerequisites.md).
2. Клонируйте репозиторий и установите зависимости (B1 Checkin использует Yarn):

   ```bash
   git clone https://github.com/ChurchApps/B1Checkin.git
   cd B1Checkin && yarn install
   ```

3. Скопируйте `dotenv.sample.txt` в `.env` и укажите стенд, к которому должно подключаться приложение (`dev` для локального API) — см. [Переменные окружения](../setup/environment-variables.md#b1checkin-react-native--expo).
4. Запустите сервер разработки Expo командой `yarn start`, затем выполните `yarn android` или `yarn ios`, чтобы запустить приложение на эмуляторе или устройстве.

Сборку релизных версий и обновления по воздуху (over-the-air) см. в разделе [Развёртывание мобильных приложений](../deployment/mobile.md).
