# Самостоятельное размещение с Docker

<div class="article-intro">

Запустите собственный приватный экземпляр B1 Admin, портал B1 member, API и MySQL database на любой машине с Docker -- домовый сервер, $5 VPS или на-предпр коробка. Один `docker compose up` строит и запускает все. Если вы бы предпочли не управлять сервером вообще, см. [Self-Hosting on Railway](./railway-template) для управляемой альтернативы.

</div>
