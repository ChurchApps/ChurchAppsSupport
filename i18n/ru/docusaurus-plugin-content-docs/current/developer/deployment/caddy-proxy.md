# Прокси Caddy пользовательского домена

<div class="article-intro">

Пользовательские домены церкви (`mychurch.org` → веб-сайт церкви B1) завершаются на одной Windows EC2 box, работающей на Caddy. Коробка владеет сертификатами TLS, разрешает каждый домен его сайту `{sub}.b1.church` и обратным прокси с переписанным заголовком Host. Его вся конфигурация состоит из двух файлов -- статичного `Caddyfile` и `hosts.map`, обновленного из Membership API -- поэтому она выживает перезагрузки без состояния во время выполнения. Эта страница охватывает, как коробка построена с нуля, как она работает, и испытанные на поле подводные камни, которые укусят любого, кто перестраивает это.

</div>

Для того, как запрос разрешается в церковь/сайт, как только он достигает B1App, см. [Website Routing & Multi-Site](../architecture/websites).
