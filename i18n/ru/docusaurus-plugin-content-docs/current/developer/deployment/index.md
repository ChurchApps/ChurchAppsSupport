# Развёртывание

<div class="article-intro">

ChurchApps использует разные стратегии развёртывания в зависимости от типа проекта: API развёртываются в AWS Lambda, веб-приложения — как статические сайты в S3 с CloudFront, а мобильные приложения собираются и распространяются через Expo EAS и магазины приложений.

</div>

## Развёртывание по типу проекта

| Тип проекта | Цель развёртывания | Инструменты |
|-------------|-------------------|---------|
| [API](./apis) | AWS Lambda | Serverless Framework v3 (среда выполнения Node.js 22.x) |
| [Веб-приложения](./web-apps) | S3 + CloudFront | Статическая сборка, синхронизация с S3, инвалидация CloudFront |
| [Мобильные приложения](./mobile) | Магазины приложений | Expo EAS Build + OTA-обновления |
| [Самостоятельное развёртывание (Railway)](./railway-template) | Railway | Шаблон в один клик: MySQL + Api + B1Admin + B1App |
| [Самостоятельное развёртывание (Docker)](./docker) | Любой хост с Docker | Установка одной командой; готовые образы GHCR + Caddy, `./deploy/b1` для обновления/резервного копирования/отката |
| [Прокси Caddy для собственного домена](./caddy-proxy) | Windows EC2 (Elastic IP `3.23.251.61`) | Статический Caddyfile + служба WinSW + плановая синхронизация карт |
| FreeShow | Прямая загрузка | Electron Builder (бинарные файлы для всех платформ) |

## Среды

| Среда | Назначение |
|-------------|-------------|
| `dev` | Локальная разработка |
| `demo` | Публичный демо-стенд; развёртывается при каждом push в `main`, поэтому служит для предпродакшн-тестирования |
| `prod` | Производственная среда |

:::info
Каждая среда имеет собственный набор конечных точек API, баз данных и конфигурации. Настройки конкретной среды управляются через файлы `.env` локально и через AWS SSM Parameter Store в развёрнутых средах.
:::
