## Все проекты

Это требуется независимо от того, над каким проектом вы работаете:

| Инструмент | Версия | Примечания |
|------|---------|---------|
| **Node.js** | 20+ | Для B1App и LessonsApp (Next.js 16) нужна версия 22+; для Api — 24+ |
| **npm** | Идёт с Node.js | Используется как менеджер пакетов во всех проектах |
| **Git** | Последняя | Каждый проект — отдельный репозиторий |

:::tip
Для переключения между версиями Node удобно использовать менеджер версий: [nvm](https://github.com/nvm-sh/nvm) (macOS/Linux) или [nvm-windows](https://github.com/coreybutler/nvm-windows) (Windows).
:::

## Разработка бэкенда API

Если вы планируете запускать API локально (а не использовать демо-API):

| Инструмент | Версия | Примечания |
|------|---------|---------|
| **MySQL** | 8.0+ | Каждый модуль API использует собственную базу данных |

Для основного API понадобятся шесть баз данных: `membership`, `attendance`, `content`, `giving`, `messaging` и `doing`. В API есть скрипты инициализации схемы — см. руководство по [локальной настройке API](../api/local-setup.md).

## Разработка мобильных приложений

Для B1Mobile, B1Checkin, LessonsScreen или других приложений на React Native / Expo:

| Инструмент | Версия | Примечания |
|------|---------|---------|
| **Expo CLI** | Последняя | Установка глобально: `npm install -g expo-cli` |
| **Android Studio** | Последняя | Нужна для разработки под Android (включает Android SDK) |
| **Xcode** | Последняя | Нужна для разработки под iOS (только macOS) |

:::info
Для быстрого тестирования можно использовать приложение Expo Go на физическом устройстве — без Android Studio или Xcode. Однако для сборки продакшн-бинарников нужны нативные инструменты.
:::

## Разработка FreeShow (настольное приложение)

FreeShow требует дополнительных зависимостей для нативной сборки, потому что компилирует нативные модули Node (например, `canvas`):

### Все платформы

| Инструмент | Версия | Примечания |
|------|---------|---------|
| **Python** | 3.12 | Требуется `node-gyp` для компиляции нативных модулей |
| **setuptools** | Последняя | Установка через `pip install setuptools` |

### Windows

| Инструмент | Примечания |
|------|-------|
| **Visual Studio** | Достаточно версии Community |
| **Нагрузка «Desktop development with C++»** | Выбирается при установке Visual Studio |
| **Windows 10 SDK** | Входит в нагрузку C++; убедитесь, что он отмечен |

Инструменты сборки Visual Studio можно установить из командной строки:

```bash
npm install --global windows-build-tools
```

Или установите Visual Studio Community и выберите нагрузку «Desktop development with C++» при установке.

### Linux

```bash
sudo apt-get install libfontconfig1-dev
```

### macOS

Обычно достаточно Xcode Command Line Tools:

```bash
xcode-select --install
```

## Проверка установки

Выполните эти команды, чтобы убедиться, что всё установлено:

```bash
node --version    # Должно вывести v20.x.x или выше
npm --version     # Должно вывести 10.x.x или выше
git --version     # Должно вывести git version 2.x.x
mysql --version   # Нужно только для локальной разработки API
```
