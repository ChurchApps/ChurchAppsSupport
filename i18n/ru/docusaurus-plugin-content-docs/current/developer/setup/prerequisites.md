## Все проекты

Эти инструменты обязательны независимо от того, над каким проектом вы работаете:

| Инструмент | Версия | Примечания |
|------|---------|-------|
| **Node.js** | 20+ | Версия 22+ нужна для B1App и LessonsApp (Next.js 16) |
| **npm** | Поставляется с Node.js | Используется как менеджер пакетов во всех проектах |
| **Git** | Последняя | Каждый проект — отдельный репозиторий |

:::tip
Используйте менеджер версий Node, например [nvm](https://github.com/nvm-sh/nvm) (macOS/Linux) или [nvm-windows](https://github.com/coreybutler/nvm-windows) (Windows), чтобы легко переключаться между версиями Node.
:::

## Разработка backend API

Если вы планируете запускать API локально (а не подключаться к демо-API):

| Инструмент | Версия | Примечания |
|------|---------|-------|
| **MySQL** | 8.0+ | Каждый модуль API использует собственную базу данных |

Для основного API понадобятся шесть баз данных: `membership`, `attendance`, `content`, `giving`, `messaging` и `doing`. В API есть скрипты для инициализации схемы — см. руководство [локальная настройка API](../api/local-setup).

## Разработка мобильных приложений

Для B1Mobile, B1Checkin, LessonsScreen или других приложений на React Native / Expo:

| Инструмент | Версия | Примечания |
|------|---------|-------|
| **Expo CLI** | Последняя | Установка глобально: `npm install -g expo-cli` |
| **Android Studio** | Последняя | Нужна для разработки под Android (включает Android SDK) |
| **Xcode** | Последняя | Нужна для разработки под iOS (только macOS) |

:::info
Для быстрого тестирования на физическом устройстве можно использовать приложение Expo Go, без Android Studio и Xcode. Однако для сборки production-бинарников нужны нативные инструменты.
:::

## Разработка FreeShow (настольное приложение)

FreeShow требует дополнительных зависимостей для нативной сборки, так как компилирует нативные модули Node (например, `canvas`):

### Все платформы

| Инструмент | Версия | Примечания |
|------|---------|-------|
| **Python** | 3.12 | Требуется `node-gyp` для компиляции нативных модулей |
| **setuptools** | Последняя | Установка через `pip install setuptools` |

### Windows

| Инструмент | Примечания |
|------|-------|
| **Visual Studio** | Достаточно версии Community |
| **Рабочая нагрузка «Desktop development with C++»** | Выберите при установке Visual Studio |
| **Windows 10 SDK** | Входит в набор C++; убедитесь, что он отмечен |

Инструменты сборки Visual Studio можно установить из командной строки:

```bash
npm install --global windows-build-tools
```

Или установите Visual Studio Community и выберите рабочую нагрузку «Desktop development with C++» при установке.

### Linux

```bash
sudo apt-get install libfontconfig1-dev
```

### macOS

Обычно достаточно Xcode Command Line Tools:

```bash
xcode-select --install
```

## Проверка установки

Выполните эти команды, чтобы убедиться, что всё установлено:

```bash
node --version    # Should print v20.x.x or higher
npm --version     # Should print 10.x.x or higher
git --version     # Should print git version 2.x.x
mysql --version   # Only needed for local API development
```
