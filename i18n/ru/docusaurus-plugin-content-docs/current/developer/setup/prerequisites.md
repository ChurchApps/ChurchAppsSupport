# Предварительные требования

<div class="article-intro">

Необходимые инструменты зависят от того, над какими проектами вы планируете работать. На этой странице перечислено всё необходимое программное обеспечение, сгруппированное по направлениям разработки: от общих требований до инструментов для конкретных платформ.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Убедитесь, что у вас есть права администратора на компьютере для установки программ

</div>

## Все проекты

Эти инструменты требуются независимо от того, над каким проектом вы работаете:

| Инструмент | Версия | Примечания |
|------|---------|-------|
| **Node.js** | 20+ | Для B1App и LessonsApp (Next.js 16) требуется версия 22+; для Api — 24+ |
| **npm** | Поставляется с Node.js | Используется как менеджер пакетов во всех проектах |
| **Git** | Последняя версия | Каждый проект хранится в отдельном репозитории |

:::tip
Используйте менеджер версий Node, например [nvm](https://github.com/nvm-sh/nvm) (macOS/Linux) или [nvm-windows](https://github.com/coreybutler/nvm-windows) (Windows), чтобы легко переключаться между версиями Node.
:::

## Разработка бэкенд API

Если вы планируете запускать API локально (а не подключаться к демонстрационным API):

| Инструмент | Версия | Примечания |
|------|---------|-------|
| **MySQL** | 8.0+ | Каждый модуль API использует собственную базу данных |

Для основного API понадобятся шесть баз данных: `membership`, `attendance`, `content`, `giving`, `messaging` и `doing`. В составе API есть скрипты для инициализации схемы — см. руководство [локальная настройка API](../api/local-setup.md).

## Разработка мобильных приложений

Для B1Checkin, LessonsScreen или других приложений на React Native / Expo:

| Инструмент | Версия | Примечания |
|------|---------|-------|
| **Expo CLI** | Последняя версия | Установка глобально: `npm install -g expo-cli` |
| **Android Studio** | Последняя версия | Необходима для разработки под Android (включает Android SDK) |
| **Xcode** | Последняя версия | Необходим для разработки под iOS (только macOS) |

:::info
Для быстрого тестирования на физическом устройстве можно использовать приложение Expo Go без Android Studio и Xcode. Однако для сборки производственных версий необходимы нативные инструменты разработки.
:::

## Разработка FreeShow (настольное приложение)

FreeShow требует дополнительных зависимостей для сборки, так как он компилирует нативные модули Node (например, `canvas`):

### Все платформы

| Инструмент | Версия | Примечания |
|------|---------|-------|
| **Python** | 3.12 | Требуется `node-gyp` для компиляции нативных модулей |
| **setuptools** | Последняя версия | Установка через `pip install setuptools` |

### Windows

| Инструмент | Примечания |
|------|-------|
| **Visual Studio** | Достаточно версии Community |
| **Рабочая нагрузка «Разработка классических приложений на C++»** | Выберите при установке Visual Studio |
| **Windows 10 SDK** | Входит в набор C++; убедитесь, что он отмечен |

Инструменты сборки Visual Studio можно установить из командной строки:

```bash
npm install --global windows-build-tools
```

Или установите Visual Studio Community и выберите рабочую нагрузку «Разработка классических приложений на C++» во время установки.

### Linux

```bash
sudo apt-get install libfontconfig1-dev
```

### macOS

Обычно достаточно инструментов командной строки Xcode:

```bash
xcode-select --install
```

## Проверка установки

Выполните эти команды, чтобы убедиться, что всё установлено:

```bash
node --version    # Должна вывести v20.x.x или выше
npm --version     # Должна вывести 10.x.x или выше
git --version     # Должна вывести git version 2.x.x
mysql --version   # Нужна только для локальной разработки API
```
