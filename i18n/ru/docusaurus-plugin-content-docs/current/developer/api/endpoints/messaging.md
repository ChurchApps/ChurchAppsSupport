# Обмен сообщениями API

Эндпоинты обмена сообщениями позволяют вам отправлять и получать сообщения между членами церкви программно.

## Отправка сообщения

```
POST /messaging/messages
{
  "toPersonId": "string",
  "subject": "string",
  "content": "string"
}
```

## Получение сообщений

```
GET /messaging/messages
GET /messaging/messages/{id}
```

## Лучшие практики

- Всегда проверяйте разрешения перед отправкой сообщения
- Используйте санитизацию для предотвращения инъекций
- Логируйте все отправленные сообщения
