# Эндпоинты контента

<div class="article-intro">

Модуль контента управляет страницами сайта, разделами, элементами, блоками, записями блога, перенаправлениями, проповедями, плейлистами, потоковыми службами, событиями, курируемыми календарями, файлами, галереями, переводами Библии и поиском стихов, песнями, аранжировками, глобальными стилями, стоковыми фотографиями и настройками. Это самый крупный модуль API. Он обеспечивает работу CMS, медиа и потокового вещания, планирования богослужений и функций Библии во всех приложениях ChurchApps.

</div>

**Базовый путь:** `/content`

## Страницы

Базовый путь: `/content/pages`

| Метод | Путь | Авторизация | Разрешение | Описание |
|--------|------|------|------------|-------------|
| GET | `/:churchId/tree?url=&id=` | Публичный | — | Загрузить полное дерево страницы (разделы, элементы, блоки) по URL или ID. При запросе по URL внутренние ID удаляются. Запросы по URL учитывают `pages.visibility` — страница с ограниченным доступом возвращает `{ restricted: true, visibility }`, если только (необязательный) JWT не удовлетворяет условию доступа |
| GET | `/public/:churchId` | Публичный | — | Список публичных страниц (`url`, `title`, `metaDescription`); только с `visibility = everyone` |
| GET | `/:id` | JWT | — | Получить страницу по ID |
| GET | `/` | JWT | — | Получить все страницы церкви |
| POST | `/duplicate/:id` | JWT | Content.Edit | Дублировать страницу со всеми разделами и элементами |
| POST | `/temp/ai` | JWT | Content.Edit | Сохранить страницу, созданную ИИ (страница, разделы и элементы одним вызовом) |
| POST | `/importTree` | JWT | Content.Edit | Создать страницу из вложенного дерева (`title`, `url`, `sections[].elements[]…`). Всегда вставляет данные в церковь вызывающего; ID в теле запроса игнорируются. Строки должны включать дочерние `column`. Максимум 30 разделов / 500 элементов |
| POST | `/` | JWT | Content.Edit | Создать или обновить страницы (пакетно) |
| DELETE | `/:id` | JWT | Content.Edit | Удалить страницу |

### Пример: загрузка дерева страницы

```
GET /content/pages/abc-church-id/tree?url=/about
```

```json
{
  "name": "About",
  "url": "/about",
  "sections": [
    {
      "background": "#FFFFFF",
      "textColor": "dark",
      "elements": [
        { "elementType": "textWithPhoto", "answers": { "text": "Welcome" } }
      ]
    }
  ]
}
```

## Записи (блог)

Базовый путь: `/content/posts`

Записи блога хранятся как отдельные строки: `title`, `slug` (уникален для каждой церкви), `excerpt`, `content` (тело в формате markdown), `authorId`, `photoUrl`, `publishDate`, `category` и `tags`. Запись опубликована, как только задана дата `publishDate` и она находится в прошлом. Эндпоинты чтения дополняют каждую запись полем `authorName`, полученным по `authorId`. См. [Архитектура конструктора сайтов](../../architecture/website-builder#blog).

| Метод | Путь | Авторизация | Разрешение | Описание |
|--------|------|------|------------|-------------|
| GET | `/public/:churchId?category=&tag=&page=&pageSize=` | Публичный | — | Список опубликованных записей с постраничной навигацией (максимум 50 на страницу) |
| GET | `/public/:churchId/categories` | Публичный | — | Уникальные категории среди опубликованных записей |
| GET | `/public/:churchId/slug/:slug` | Публичный | — | Получить опубликованную запись по slug |
| GET | `/rss/:churchId?siteUrl=` | Публичный | — | RSS 2.0 лента опубликованных записей (ссылки формируются как `{siteUrl}/blog/{slug}`) |
| GET | `/:id` | JWT | — | Получить запись по ID |
| GET | `/` | JWT | — | Список всех записей церкви |
| POST | `/` | JWT | Content.Edit | Создать или обновить записи (пакетно) |
| DELETE | `/:id` | JWT | Content.Edit | Удалить запись |

## Перенаправления

Базовый путь: `/content/redirects`

URL-перенаправления для каждой церкви (`fromPath` → `toPath`), не более 200 на церковь. Пути нормализуются (приводятся к нижнему регистру, с ведущим слэшем, без завершающего слэша), а `fromPath` уникален для каждой церкви. B1App обрабатывает их при запросах, которые привели бы к 404, и отвечает HTTP 308.

| Метод | Путь | Авторизация | Разрешение | Описание |
|--------|------|------|------------|-------------|
| GET | `/public/:churchId?path=` | Публичный | — | Определить перенаправление для пути (или вернуть все перенаправления, если `path` не указан) |
| GET | `/:id` | JWT | — | Получить перенаправление по ID |
| GET | `/` | JWT | — | Список всех перенаправлений церкви |
| POST | `/` | JWT | Content.Edit | Создать или обновить перенаправления. Отклоняет `fromPath = toPath` и соблюдает ограничение в 200 записей |
| DELETE | `/:id` | JWT | Content.Edit | Удалить перенаправление |

## События

Базовый путь: `/content/events`

| Метод | Путь | Авторизация | Разрешение | Описание |
|--------|------|------|------------|-------------|
| GET | `/timeline/group/:groupId?eventIds=` | JWT | — | Загрузить события временной шкалы для группы (включает даты исключений, поэтому удалённые вхождения можно пропускать) |
| GET | `/timeline?eventIds=` | JWT | — | Загрузить события временной шкалы для групп текущего пользователя (включает даты исключений) |
| GET | `/subscribe?churchId=&groupId=&curatedCalendarId=` | Публичный | — | Подписаться на события как на ICS-ленту календаря |
| GET | `/group/:groupId` | JWT | — | Получить события группы (включает даты исключений) |
| GET | `/public/group/:churchId/:groupId` | Публичный | — | Получить публичные события группы |
| GET | `/public/:churchId/:id` | Публичный | — | Получить одно событие для его публичной страницы, с `roomNames` (комнаты из бронирований, которые не отклонены). Возвращает `null` для событий в ожидании или отклонённых, а также для закрытых событий, не принимающих регистраций |
| GET | `/public/:churchId/:id/ical` | Публичный | — | Скачать это отдельное событие как файл `.ics` (`text/calendar`, даты исключений учтены). `404`, если событие скрыто по тем же правилам |
| GET | `/:id` | JWT | — | Получить событие по ID |
| POST | `/` | JWT | — | Создать или обновить события (пакетно) |
| DELETE | `/:id` | JWT | Content.Edit, Calendars.Admin или руководитель группы | Удалить событие и его бронирования. Руководители группы события могут его удалить, а автор запроса может отозвать собственный запрос в ожидании |

Записи событий включают `photoUrl` (фото события 16:9, которое отображается на публичной странице события и в плитках ближайших событий), `tags` (через запятую, используются фильтром тегов элемента «Календарь» сайта) и `notesViewRole` / `notesPostRole` (`staff`, если `null`, `leaders` или `members`), которые определяют доступ к беседе `eventNote` — см. [Контроль доступа к заметкам группы и события](./messaging.md#group-and-event-notes-access-control). Ответы публичных курируемых событий также содержат `photoUrl` и `tags` каждого события.

## Библии

Базовый путь: `/content/bibles`

Все эндпоинты Библии публичные (аутентификация не требуется). Данные загружаются из внешних источников и кэшируются локально. Запросы к api.bible прерываются через 15 секунд; при таймауте возвращается **504**.

| Метод | Путь | Авторизация | Разрешение | Описание |
|--------|------|------|------------|-------------|
| GET | `/` | Публичный | — | Список всех переводов Библии (загружает из источника, если кэш пуст) |
| GET | `/stats?startDate=&endDate=` | Публичный | — | Получить статистику поиска по Библии за диапазон дат |
| GET | `/availableTranslations/:source` | Публичный | — | Список доступных переводов из источника (например, api.bible) |
| GET | `/updateTranslations` | Публичный | — | Синхронизировать все переводы из всех источников |
| GET | `/updateTranslations/:source` | Публичный | — | Синхронизировать переводы из конкретного источника |
| GET | `/updateCopyrights` | Публичный | — | Обновить сведения об авторских правах для переводов, где их нет |
| GET | `/:translationKey/updateCopyright` | Публичный | — | Обновить авторские права для конкретного перевода |
| GET | `/:translationKey/search?query=&limit=` | Публичный | — | Поиск стихов в переводе |
| GET | `/:translationKey/books` | Публичный | — | Получить книги перевода (кэширует локально) |
| GET | `/:translationKey/:bookKey/chapters` | Публичный | — | Получить главы книги (кэширует локально) |
| GET | `/:translationKey/chapters/:chapterKey/verses` | Публичный | — | Получить стихи главы (кэширует локально) |
| GET | `/:translationKey/verses/:startVerseKey-:endVerseKey` | Публичный | — | Получить текст стихов для диапазона. Записывает поиски в журнал. Некоторые переводы обходят кэш из-за лицензионных условий |

  { "verseKey": "GEN.1.3", "content": "And God said, \"Let there be light,\" and there was light.", "bookKey": "GEN", "chapterNumber": 1, "verseNumber": 3 }
