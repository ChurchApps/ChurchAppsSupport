# Конечные точки Content

<div class="article-intro">

Модуль Content управляет страницами сайта, разделами, элементами, блоками, записями блога, перенаправлениями, проповедями, плейлистами, стриминговыми сервисами, событиями, курируемыми календарями, файлами, галереями, переводами Библии и поиском стихов, песнями, аранжировками, глобальными стилями, стоковыми фотографиями и настройками. Это самый большой модуль в API, он обеспечивает работу CMS, медиа и стриминга, планирования богослужений и функций Библии во всех приложениях ChurchApps.

</div>

**Базовый путь:** `/content`

## Страницы

Базовый путь: `/content/pages`

| Метод | Путь | Аутентификация | Разрешение | Описание |
|--------|------|------|------------|-------------|
| GET | `/:churchId/tree?url=&id=` | Публичный | — | Загружает полное дерево страницы (разделы, элементы, блоки) по URL или ID. При запросе по URL удаляет внутренние ID. Запросы по URL учитывают `pages.visibility` — страница с ограничением возвращает `{ restricted: true, visibility }`, если только (необязательный) JWT не удовлетворяет ограничению |
| GET | `/public/:churchId` | Публичный | — | Список публичных страниц (`url`, `title`, `metaDescription`); только с `visibility = everyone` |
| GET | `/:id` | JWT | — | Получает страницу по ID |
| GET | `/` | JWT | — | Список всех страниц церкви |
| POST | `/duplicate/:id` | JWT | Content.Edit | Дублирует страницу со всеми разделами и элементами |
| POST | `/temp/ai` | JWT | Content.Edit | Сохраняет страницу, созданную ИИ (страница, разделы и элементы одним вызовом) |
| POST | `/importTree` | JWT | Content.Edit | Создает страницу из вложенного дерева (`title`, `url`, `sections[].elements[]…`). Всегда добавляет страницу в церковь вызывающего; ID в теле запроса игнорируются. Строки должны включать свои дочерние `column`. Максимум 30 разделов / 500 элементов |
| POST | `/` | JWT | Content.Edit | Создает или обновляет страницы (пакетно) |
| DELETE | `/:id` | JWT | Content.Edit | Удаляет страницу |

### Пример: загрузка дерева страницы

```
GET /content/pages/abc-church-id/tree?url=/about
```

```json
{
  "name": "About",
  "url": "/about",
  "sections": [
    {
      "background": "#FFFFFF",
      "textColor": "dark",
      "elements": [
        { "elementType": "textWithPhoto", "answers": { "text": "Welcome" } }
      ]
    }
  ]
}
```

## Записи (блог)

Базовый путь: `/content/posts`

Записи блога — это самостоятельные строки: `title`, `slug` (уникальный для каждой церкви), `excerpt`, `content` (тело в формате markdown), `authorId`, `photoUrl`, `publishDate`, `category` и `tags`. Запись публикуется, как только задана дата `publishDate` и она в прошлом. Конечные точки чтения дополняют каждую запись полем `authorName`, определенным по `authorId`. См. [Архитектура конструктора сайтов](../../architecture/website-builder#blog).

| Метод | Путь | Аутентификация | Разрешение | Описание |
|--------|------|------|------------|-------------|
| GET | `/public/:churchId?category=&tag=&page=&pageSize=` | Публичный | — | Список опубликованных записей с постраничной разбивкой (максимум 50 на страницу) |
| GET | `/public/:churchId/categories` | Публичный | — | Уникальные категории опубликованных записей |
| GET | `/public/:churchId/slug/:slug` | Публичный | — | Получает опубликованную запись по slug |
| GET | `/rss/:churchId?siteUrl=` | Публичный | — | Лента RSS 2.0 опубликованных записей (ссылки формируются как `{siteUrl}/blog/{slug}`) |
| GET | `/:id` | JWT | — | Получает запись по ID |
| GET | `/` | JWT | — | Список всех записей церкви |
| POST | `/` | JWT | Content.Edit | Создает или обновляет записи (пакетно) |
| DELETE | `/:id` | JWT | Content.Edit | Удаляет запись |

## Перенаправления

Базовый путь: `/content/redirects`

URL-перенаправления для каждой церкви (`fromPath` → `toPath`), не более 200 на церковь. Пути нормализуются (в нижний регистр, с ведущей косой чертой, без завершающей косой черты), значение `fromPath` уникально для каждой церкви. B1App применяет эти перенаправления при ошибках 404 и возвращает HTTP 308.

| Метод | Путь | Аутентификация | Разрешение | Описание |
|--------|------|------|------------|-------------|
| GET | `/public/:churchId?path=` | Публичный | — | Определяет путь (или выводит все перенаправления, если `path` не указан) |
| GET | `/:id` | JWT | — | Получает перенаправление по ID |
| GET | `/` | JWT | — | Список всех перенаправлений церкви |
| POST | `/` | JWT | Content.Edit | Создает или обновляет перенаправления. Отклоняет `fromPath = toPath` и соблюдает ограничение в 200 строк |
| DELETE | `/:id` | JWT | Content.Edit | Удаляет перенаправление |

| Метод | Путь | Аутентификация | Разрешение | Описание |
|--------|------|------|------------|-------------|

| DELETE | `/:id` | JWT | Content.Edit | Удаляет событие |

Записи о событиях включают `photoUrl` (фото события в формате 16:9, которое отображается на публичной странице события и в плитках ближайших событий), `tags` (через запятую, используется фильтром тегов элемента Calendar на сайте) и `notesViewRole` / `notesPostRole` (`staff`, если `null`, `leaders` или `members`), которые определяют доступ к беседе `eventNote` события — см. [Контроль доступа к заметкам групп и событий](./messaging.md#group-and-event-notes-access-control). Ответы публичных курируемых событий также содержат `photoUrl` и `tags` для каждого события.

## Библии

Базовый путь: `/content/bibles`

Все конечные точки Библии публичны (аутентификация не требуется). Данные загружаются из внешних источников и кешируются локально.

| Метод | Путь | Аутентификация | Разрешение | Описание |
|--------|------|------|------------|-------------|
| GET | `/` | Публичный | — | Список всех переводов Библии (загружает из источника, если кеш пуст) |
| GET | `/stats?startDate=&endDate=` | Публичный | — | Получает статистику поиска по Библии за диапазон дат |
| GET | `/availableTranslations/:source` | Публичный | — | Список доступных переводов из источника (например, api.bible) |
| GET | `/updateTranslations` | Публичный | — | Синхронизирует все переводы из всех источников |
| GET | `/updateTranslations/:source` | Публичный | — | Синхронизирует переводы из конкретного источника |
| GET | `/updateCopyrights` | Публичный | — | Обновляет сведения об авторских правах для переводов, у которых их нет |
| GET | `/:translationKey/updateCopyright` | Публичный | — | Обновляет авторские права для конкретного перевода |
| GET | `/:translationKey/search?query=&limit=` | Публичный | — | Поиск стихов в переводе |
| GET | `/:translationKey/books` | Публичный | — | Получает книги перевода (кеширует локально) |
| GET | `/:translationKey/:bookKey/chapters` | Публичный | — | Получает главы книги (кеширует локально) |
| GET | `/:translationKey/chapters/:chapterKey/verses` | Публичный | — | Получает стихи главы (кеширует локально) |
| GET | `/:translationKey/verses/:startVerseKey-:endVerseKey` | Публичный | — | Получает текст стихов диапазона. Фиксирует обращения к тексту. Некоторые переводы обходят кеширование из-за лицензии |

### Пример: получение текста стихов

```
GET /content/bibles/de4e12af7f28f599-02/verses/GEN.1.1-GEN.1.3
```

```json
[
  { "verseKey": "GEN.1.1", "content": "In the beginning God created the heavens and the earth.", "bookKey": "GEN", "chapterNumber": 1, "verseNumber": 1 },
  { "verseKey": "GEN.1.2", "content": "Now the earth was formless and empty...", "bookKey": "GEN", "chapterNumber": 1, "verseNumber": 2 },
  { "verseKey": "GEN.1.3", "content": "And God said, \"Let there be light,\" and there was light.", "bookKey": "GEN", "chapterNumber": 1, "verseNumber": 3 }
]
```

## Сведения о песнях

Базовый путь: `/content/songDetails`

Сведения о песнях глобальны (не привязаны к церкви). Они содержат канонические метаданные песен, общие для всех церквей.

| Метод | Путь | Аутентификация | Разрешение | Описание |
|--------|------|------|------------|-------------|
| GET | `/:id` | JWT | — | Получает сведения о песне по ID (глобально) |
| GET | `/` | JWT | — | Список сведений о песнях для церкви |
| POST | `/create` | JWT | — | Создает сведения о песне по ID PraiseCharts (возвращает существующие, если уже созданы). Автоматически загружает метаданные из PraiseCharts и MusicBrainz |
| POST | `/` | JWT | — | Создает или обновляет сведения о песнях (пакетно) |

## PraiseCharts

Базовый путь: `/content/praiseCharts`

Интеграция с PraiseCharts для поиска песен для богослужения и загрузки нотных листов.

| Метод | Путь | Аутентификация | Разрешение | Описание |
|--------|------|------|------------|-------------|
| GET | `/raw/:id` | JWT | — | Получает необработанные данные PraiseCharts для песни |
| GET | `/hasAccount` | JWT | — | Проверяет, привязана ли к пользователю учетная запись PraiseCharts |
| GET | `/search?q=` | JWT | — | Поиск в каталоге PraiseCharts |
| GET | `/products/:id?keys=` | JWT | — | Получает продукты для песни (из библиотеки, если пользователь аутентифицирован, иначе из каталога) |
| GET | `/arrangement/raw/:id?keys=` | JWT | — | Получает необработанные данные аранжировки из библиотеки |
| GET | `/download?skus=&keys=&file_name=` | JWT | — | Загружает файл из PraiseCharts (PDF или ZIP). Возвращает `{ redirectUrl }` |
| GET | `/authUrl?returnUrl=` | Публичный | — | Получает URL авторизации OAuth для PraiseCharts |
| GET | `/access?verifier=&token=&secret=` | JWT | — | Обменивает верификатор OAuth на токен доступа и сохраняет его в настройках пользователя |
| GET | `/library` | JWT | — | Просмотр библиотеки PraiseCharts пользователя |
