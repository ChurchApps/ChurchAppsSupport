# Эндпоинты Membership

<div class="article-intro">

Модуль Membership управляет людьми, церквями, группами, домохозяйствами, ролями, правами, формами и настройками. Это самый большой модуль, и он предоставляет основной уровень идентификации и авторизации для всех остальных модулей.

</div>

**Базовый путь:** `/membership`

## People

Базовый путь: `/membership/people`

| Метод | Путь | Авторизация | Разрешение | Описание |
|--------|------|------|------------|-------------|
| GET | `/` | JWT | People.View или Member | Список всех людей церкви |
| GET | `/:id` | JWT | People.View или собственная запись | Получить человека по ID (включая отправленные формы) |
| GET | `/ids?ids=` | JWT | People.View или Member | Получить несколько людей по ID, перечисленным через запятую |
| GET | `/basic?ids=` | JWT | — | Получить базовую информацию (только имя) для нескольких людей |
| GET | `/names?ids=` | JWT | Любое право церкви | `[{ id, name: { display, first, last }, photo }]`, отсортировано по фамилии, затем по имени, для перечисленных через запятую ID, которые вызывающий уже имеет, чтобы роли без People.View (пожертвования, посещаемость) могли подписывать людей. Без поиска и без фильтра каталога |
| POST | `/names` | JWT | Любое право церкви | То же, что `GET /names`. Тело: `{ peopleIds }` (или `{ ids }`) |
| GET | `/recent` | JWT | People.View, Member или People.ViewNames | Недавно добавленные люди. Вызывающие только с People.ViewNames получают базовую модель (`id`, `name.display`, `photo`, `membershipStatus`), при этом люди, отказавшиеся от показа, исключаются |
| GET | `/search?term=&email=` | JWT | People.View, Member или People.ViewNames | Поиск людей по имени или email (до 100, сортировка по фамилии, затем по имени). Вызывающие только с People.ViewNames получают поиск по имени с базовой моделью; поиск по `email` возвращает `[]` |
| GET | `/search/phone?number=` | JWT | People.View или Member | Поиск по номеру телефона |
| GET | `/search/group?groupId=` | JWT | People.View или Member | Получить людей в конкретной группе |
| GET | `/household/:householdId` | JWT | — | Получить всех людей в домохозяйстве |
| GET | `/attendance` | JWT | People.Edit | Загрузить посетителей с фильтрами (campusId, serviceId, serviceTimeId, groupId, categoryName, startDate, endDate) |
| GET | `/timeline?personIds=&groupIds=` | JWT | — | Загрузить данные хронологии для людей и групп |
| GET | `/directory/:id` | JWT | — | Получить человека для представления в каталоге (учитывает настройки видимости) |
| GET | `/claim/:churchId` | JWT | — | Привязать запись человека к текущему пользователю в церкви |
| POST | `/` | JWT | People.Edit или EditSelf | Создать или обновить людей (пакетно) |
| POST | `/search` | JWT | People.View, Member или People.ViewNames | Поиск людей (вариант POST). Тело: `{ term }` или `{ email }`; те же правила для ограниченных по именам, что и у `GET /search` |
| POST | `/advancedSearch` | JWT | People.View или Member | Поиск по нескольким условиям (возраст, birthMonth, membershipStatus и т. д.) |
| POST | `/loadOrCreate` | Public | — | Найти или создать человека по email. Тело: `{ churchId, email, firstName, lastName }` |
| POST | `/household/:householdId` | JWT | People.Edit | Обновить назначения участников домохозяйства |
| POST | `/public/email` | Public | — | Отправить email человеку. Тело: `{ churchId, personId, subject, body, appName }` |
| POST | `/apiEmails` | Internal | — | Загрузить email людей по ID (сервер-сервер, требуется jwtSecret) |
| DELETE | `/:id` | JWT | People.Edit | Удалить человека |

### Пример: поиск людей

```
GET /membership/people/search?term=John
Authorization: Bearer <token>
```

```json
[
  {
    "id": "abc-123",
    "name": { "first": "John", "last": "Smith" },
    "contactInfo": { "email": "john@example.com" },
    "membershipStatus": "Member"
  }
]
```

### Пример: создание человека

```
POST /membership/people
Authorization: Bearer <token>

[{ "firstName": "Jane", "lastName": "Doe", "contactInfo": { "email": "jane@example.com" } }]
```

## Permissions

Базовый путь: `/membership/permissions`

| Метод | Путь | Авторизация | Разрешение | Описание |
|--------|------|------|------------|-------------|
| GET | `/` | JWT | — | Получить полный список доступных прав |

Каждая запись содержит `apiName`, `section` (тип содержимого), `action`, а также метки `displaySection` / `displayAction`, которые показывает редактор ролей B1Admin. Недавно добавленные права: `MembershipApi` / `People` / `View Names` (**Просмотр только имен людей**, в разделе **Люди и группы**) и `GivingApi` / `Donations` / `Enter` (**Ввод пожертвований**, в разделе **Пожертвования**; см. [Пакеты пожертвований](./giving.md#donation-batches)).
