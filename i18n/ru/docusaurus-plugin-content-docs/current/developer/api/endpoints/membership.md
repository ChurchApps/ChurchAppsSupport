# Эндпоинты Membership

<div class="article-intro">

Модуль Membership управляет людьми, церквями, группами, домохозяйствами, ролями, разрешениями, формами и настройками. Это самый большой модуль; он предоставляет основной слой идентификации и авторизации для всех остальных модулей.

</div>

**Базовый путь:** `/membership`

## Люди

Базовый путь: `/membership/people`

| Метод | Путь | Авторизация | Разрешение | Описание |
|--------|------|------------|-------------|-------------|
| GET | `/` | JWT | People.View или Member | Список всех людей церкви |
| GET | `/:id` | JWT | People.View или собственная запись | Получить человека по ID (включая отправки форм) |
| GET | `/ids?ids=` | JWT | People.View или Member | Получить несколько человек по ID через запятую |
| GET | `/basic?ids=` | JWT | — | Получить базовую информацию (только имя) для нескольких человек |
| GET | `/names?ids=` | JWT | Любое разрешение церкви | `[{ id, name: { display }, photo }]` для ID через запятую, которые вызывающий уже видит, чтобы роли без People.View (пожертвования, посещаемость) могли подписывать людей. Без поиска и без фильтра справочника |
| POST | `/names` | JWT | Любое разрешение церкви | То же, что `GET /names`. Тело: `{ peopleIds }` (или `{ ids }`) |
| GET | `/recent` | JWT | People.View или Member | Недавно добавленные люди |
| GET | `/search?term=&email=` | JWT | People.View или Member | Поиск людей по имени или email |
| GET | `/search/phone?number=` | JWT | People.View или Member | Поиск по номеру телефона |
| GET | `/search/group?groupId=` | JWT | People.View или Member | Получить людей в конкретной группе |
| GET | `/household/:householdId` | JWT | — | Получить всех людей домохозяйства |
| GET | `/attendance` | JWT | People.Edit | Загрузить посетителей с фильтрами (campusId, serviceId, serviceTimeId, groupId, categoryName, startDate, endDate) |
| GET | `/timeline?personIds=&groupIds=` | JWT | — | Загрузить данные хронологии для людей и групп |
| GET | `/directory/:id` | JWT | — | Получить человека для вида справочника (учитывает настройки видимости) |
| GET | `/claim/:churchId` | JWT | — | Привязать запись человека к текущему пользователю в церкви |
| POST | `/` | JWT | People.Edit или EditSelf | Создать или обновить людей (пакетно) |
| POST | `/search` | JWT | People.View или Member | Поиск людей (вариант POST) |
| POST | `/advancedSearch` | JWT | People.View или Member | Поиск по нескольким условиям (возраст, birthMonth, membershipStatus и др.) |
| POST | `/loadOrCreate` | Public | — | Найти или создать человека по email. Тело: `{ churchId, email, firstName, lastName }` |
| POST | `/household/:householdId` | JWT | People.Edit | Обновить назначения членов домохозяйства |
| POST | `/public/email` | Public | — | Отправить письмо человеку. Тело: `{ churchId, personId, subject, body, appName }` |
| POST | `/apiEmails` | Internal | — | Загрузить email людей по ID (межсерверный вызов, требуется jwtSecret) |
| DELETE | `/:id` | JWT | People.Edit | Удалить человека |

### Пример: поиск людей

```
GET /membership/people/search?term=John
Authorization: Bearer <token>
```

```json
[
  {
    "id": "abc-123",
    "name": { "first": "John", "last": "Smith" },
    "contactInfo": { "email": "john@example.com" },
    "membershipStatus": "Member"
  }
]
```

### Пример: создание человека

```
POST /membership/people
Authorization: Bearer <token>

[{ "firstName": "Jane", "lastName": "Doe", "contactInfo": { "email": "jane@example.com" } }]
```

| Метод | Путь | Авторизация | Разрешение | Описание |

| POST | `/login` | Public | — | Вход (email/пароль, обновление JWT или authGuid) |
| POST | `/register` | Public | — | Зарегистрировать нового пользователя |
| POST | `/forgot` | Public | — | Отправить письмо для сброса пароля |
| POST | `/setPasswordGuid` | Public | — | Установить пароль по auth GUID из ссылки в письме |
| POST | `/verifyCredentials` | Public | — | Проверить email/пароль и вернуть связанные церкви |
| POST | `/loadOrCreate` | JWT | — | Найти или создать пользователя по email/userId |
| POST | `/setDisplayName` | JWT | — | Обновить имя и фамилию пользователя |
| POST | `/updateEmail` | JWT | — | Изменить адрес электронной почты пользователя |
| POST | `/updatePassword` | JWT | — | Изменить пароль пользователя (минимум 6 символов) |
| POST | `/updateOptedOut` | JWT | — | Установить статус отказа от рассылки для человека |
| POST | `/sendInviteEmail` | JWT | People.Edit | Отправить приглашение человеку в этой церкви (`email`, `personName`, `contextName`). Пользователь, который ни разу не входил, получает ссылку **Set Your Password**, действующую 7 дней. Учитывается в дневном лимите писем церкви (`429`, когда лимит достигнут) |
| GET | `/search?term=` | JWT | Server.Admin | Поиск всех пользователей по имени/email |
| DELETE | `/` | JWT | — | Удалить учетную запись текущего пользователя |
