# Вебхуки

Вебхуки позволяют вашему приложению получать уведомления в реальном времени при возникновении событий в B1.

## Типы событий

- **person.created** — новый человек добавлен
- **person.updated** — информация о человеке обновлена
- **donation.created** — новое пожертвование записано
- **attendance.recorded** — посещаемость записана
- **group.updated** — информация о группе обновлена

## Создание вебхука

1. Перейдите в **Settings > Developer > Webhooks**
2. Нажмите **New Webhook**
3. Введите URL для получения событий
4. Выберите типы событий
5. Нажмите **Save**

## Формат события

Каждое событие отправляется как POST с JSON:

```json
{
  "eventType": "string",
  "data": {
    "id": "string",
    "...": "..."
  },
  "timestamp": "2024-01-01T00:00:00Z"
}
```

## Безопасность

- Проверяйте подпись события в заголовке `X-Signature`
- Используйте HTTPS для вебхука
- Используйте конкретные типы событий, которые вам нужны

## Советы

- Обрабатывайте события асинхронно
- Логируйте все полученные события
- Реализуйте механизм повтора для отказоустойчивости
