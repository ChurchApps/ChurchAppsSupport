# Документация для разработчиков

<div class="article-intro">

ChurchApps — это набор примерно из 20 проектов с открытым исходным кодом, которые вместе образуют полноценную платформу для управления церковью. Проекты включают бэкенд API, веб-приложения, мобильные приложения, настольное приложение и общие библиотеки — все они написаны на TypeScript. Этот раздел содержит всё необходимое, чтобы настроить локальную среду разработки и начать вносить вклад.

</div>

## Архитектура в общих чертах

Проекты представляют собой **независимые репозитории** (а не монорепозиторий). Общий код публикуется в npm под областью `@churchapps/*` и подключается как обычные зависимости. Это означает, что вы можете работать над одним проектом, не клонируя всю экосистему.

Ключевые особенности:

- **Язык:** TypeScript везде
- **Бэкенд:** API на Node.js / Express, развёрнутые в AWS Lambda через Serverless Framework
- **Веб:** React 19 (Vite и Next.js), Material-UI 7
- **Мобильные приложения:** React Native с Expo
- **База данных:** MySQL 8.0, по одной базе данных на каждый модуль API
