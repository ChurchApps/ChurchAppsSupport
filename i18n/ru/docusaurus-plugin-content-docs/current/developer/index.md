# Документация для разработчиков

<div class="article-intro">

ChurchApps — это набор из примерно 20 проектов с открытым исходным кодом, которые вместе образуют полноценную платформу для управления церковью. Проекты включают серверные API, веб-приложения, мобильные приложения, настольное приложение и общие библиотеки — все они написаны на TypeScript. Этот раздел содержит всё необходимое для настройки локальной среды разработки и начала участия в проекте.

</div>

## Архитектура в общих чертах

Проекты представляют собой **независимые репозитории** (а не монорепозиторий). Общий код публикуется в npm под областью `@churchapps/*` и подключается как обычная зависимость. Это означает, что вы можете работать над одним проектом, не клонируя всю экосистему целиком.

Ключевые особенности:

- **Язык:** TypeScript во всех проектах
- **Бэкенд:** API на Node.js / Express, развёртываемые в AWS Lambda с помощью Serverless Framework
- **Веб:** React 19 (Vite и Next.js), Material-UI 7
- **Мобильные приложения:** React Native с Expo
- **База данных:** MySQL 8.0, по одной базе данных на каждый модуль API
