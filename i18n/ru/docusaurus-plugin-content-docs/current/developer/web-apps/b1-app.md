# B1App

<div class="article-intro">

B1App — это публичное приложение для членов церкви, построенное на Next.js. Оно предоставляет участникам возможности работы с профилями, каталогами групп, прямыми трансляциями и страницами пожертвований.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Установите **Node.js 22+** и **Git** — см. [Требования](../setup/prerequisites)
- Настройте цель API (демо или локальную) — см. [Переменные окружения](../setup/environment-variables)

</div>

:::warning
B1App требует Node.js 22 или новее. Более ранние версии не поддерживаются.
:::

## Настройка

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/ChurchApps/B1App.git
```

### 2. Установите зависимости

```bash
cd B1App
npm install
```

### 3. Настройте переменные окружения

```bash
cp dotenv.sample.txt .env
```

Откройте `.env` и настройте URL-адреса конечных точек `NEXT_PUBLIC_*_API`. Они могут указывать на общий демо-API (`https://api.demo.churchapps.org`) или на ваш локальный экземпляр API. Пример файла может всё ещё содержать устаревшие адреса тестовых серверов; замените их.

### 4. Запустите сервер разработки

```bash
npm run dev
```

Сервер разработки Next.js запускается по адресу [http://localhost:3301](http://localhost:3301).

## Основные команды

| Команда | Описание |
|---------|----------|
| `npm run dev` | Запуск сервера разработки Next.js на порту 3301 |
| `npm run build` | Продакшен-сборка через Next.js |
| `npm run test` | Запуск сквозных тестов с Playwright |
| `npm run lint` | Запуск линтера Next.js |

## Основные переменные окружения

| Переменная | Описание |
|------------|----------|
| `NEXT_PUBLIC_*_API` | URL-адреса конечных точек API для каждого модуля |

:::info
Скрипт `postinstall` копирует файлы локалей и CSS из `@churchapps/apphelper`. Если компоненты выглядят без стилей после установки, запустите `npm run postinstall` вручную.
:::

## Стек технологий

- **Next.js 16** с TypeScript
- **React 19** для UI-компонентов
- **Material-UI 7** как дизайн-система
- **React Query 5** для серверного состояния
- Пакеты **`@churchapps/apphelper*`** для общих компонентов

## Развёртывание

Продакшен-сборки развёртываются в **S3 + CloudFront**:

1. `npm run build` создаёт оптимизированную сборку Next.js
2. Результат сборки синхронизируется с S3-бакетом
3. Запускается инвалидация CloudFront, чтобы отдавать новую версию

:::tip
Подробные инструкции по развёртыванию см. в руководстве [Развёртывание веб-приложений](../deployment/web-apps).
:::
