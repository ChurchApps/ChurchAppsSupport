# B1 Admin

<div class="article-intro">

B1Admin -- это панель администрирования церкви: одностраничное приложение на React, созданное с помощью Vite и Material-UI. Сотрудники церкви используют его для управления людьми, группами, посещаемостью, пожертвованиями, контентом и многим другим.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Установите **Node.js 22+** и **Git** -- см. [Предварительные требования](../setup/prerequisites)
- Настройте цель API (демо или локальную) -- см. [Переменные окружения](../setup/environment-variables)

</div>

## Настройка

### 1. Клонирование репозитория

```bash
git clone https://github.com/ChurchApps/B1Admin.git
```

### 2. Установка зависимостей

```bash
cd B1Admin
npm install
```

### 3. Настройка переменных окружения

```bash
cp dotenv.sample.txt .env
```

Откройте `.env` и настройте конечные точки API. Можно указать либо общий демо-API (`https://api.demo.churchapps.org`), либо ваш локальный экземпляр API. Пример файла может все еще содержать адреса снятых с эксплуатации тестовых сред; замените их.

### 4. Запуск dev-сервера

```bash
npm start
```

Запускается dev-сервер Vite. Приложение будет доступно в браузере с включенной горячей заменой модулей (HMR).

## Ключевые переменные окружения

| Переменная | Описание |
|----------|-------------|
| `REACT_APP_STAGE` | Название окружения (например, `demo`, как в примере файла, `prod` или `selfhost`) |
| `PORT` | Порт dev-сервера (по умолчанию: `3101`) |
| `REACT_APP_*_API` | URL конечных точек API для каждого модуля |

:::info
Скрипт `postinstall` копирует файлы локализации и CSS из `@churchapps/apphelper`. Если компоненты выглядят без стилей, выполните `npm run postinstall` вручную.
:::

## Основные команды

| Команда | Описание |
|---------|-------------|
| `npm start` | Запуск dev-сервера Vite |
| `npm run build` | Продакшн-сборка через Vite |
| `npm run test` | Запуск сквозных тестов с Playwright |
| `npm run lint` | Запуск ESLint с автоисправлением |

## Стек технологий

- **React 19** с TypeScript
- **Vite** для инструментов сборки и dev-сервера
- **Material-UI 7** для компонентов интерфейса
- **React Query 5** для серверного состояния
- **`@churchapps/apphelper*`** -- пакеты с общими компонентами

## Развертывание

Продакшн-сборки развертываются в **S3 + CloudFront**:

1. `npm run build` генерирует статические ресурсы
2. Ресурсы синхронизируются с S3-бакетом
3. Запускается инвалидация CloudFront, чтобы отдавать новую версию

:::tip
Подробные инструкции по развертыванию см. в руководстве [Развертывание веб-приложений](../deployment/web-apps).
:::
