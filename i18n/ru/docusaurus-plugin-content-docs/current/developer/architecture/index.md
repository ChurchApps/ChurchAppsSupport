# Архитектура

<div class="article-intro">

Эти страницы - это карты кросс-repo системы: они документируют, как система ChurchApps работает end-to-end -- по приложениям, модулям API и общим библиотекам -- а не как настроен какой-либо один проект. Прочитайте их перед изменением поведения системы; прочитайте [Setup](../setup/), чтобы запустить проект и раздел [API](../api/) для справки на уровне конечной точки.

</div>

## Экосистема с первого взгляда

ChurchApps - это ~20 независимых репозиториев (не монорепо). Клиентские приложения взаимодействуют с небольшим набором backend API по HTTPS и WebSocket и обмениваются кодом через npm пакеты, опубликованные в области `@churchapps`.
