# Маршрутизация веб-сайта и мультисайт

<div class="article-intro">

Одна церковь теперь может обслуживать более одного отдельного веб-сайта, и каждый может жить на поддомене `*.b1.church` или на полностью пользовательском, принадлежащем церкви домене. Эта страница отображает слой маршрутизации, который сидит *под* конструктором: как входящий запрос разрешается в церковь **и** на определенный сайт, модель многосайта (часовой `siteId`, который держит каждый предсуществующий сайт без изменений), и краю пользовательского домена -- самоуправляемый прокси-сервер Caddy на EC2, который завершает TLS и переписывает каждый домен церкви на его вышестоящий `*.b1.church`. Для того, что фактически отображается после разрешения запроса -- дерево page/section/element -- см. [Website Builder](./website-builder).
