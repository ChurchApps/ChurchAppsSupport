# Регистрация события

<div class="article-intro">

Собственная регистрация события живет в модуле контента и, с волны платных регистраций, несет полную модель коммерции: типы участников с ценой, выборы надстроек с ценой, коды скидок, платежи через существующий шлюз пожертвований церкви и список ожидания, управляемый статусом. Путь денег намеренно переиспользует стек пожертвований -- контроллер регистрации взимает плату через ту же абстракцию `GatewayService` / `IGatewayProvider`, документированную в [Giving](./giving), поэтому никакие данные карты или знание SDK шлюза не живут в модуле контента. Эта страница отображает модель данных, правила определения цены и мощности, а также регистрацию, платеж и потоки списка ожидания.

</div>
