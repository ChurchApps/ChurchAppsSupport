# Архитектура конструктора веб-сайтов

<div class="article-intro">

Каждый сайт церкви, обслуживаемый B1App, отображается из дерева контента -- страницы, разделы, элементы -- хранящихся в ContentApi и редактируемых визуально в B1Admin. Одна общая библиотека компонентов отображает как предварительный просмотр редактора, так и живой сайт, один каталог типов элементов определяет, что может появиться на странице, и отдельная служба AI может генерировать или переписывать это дерево. Эта страница отображает весь стек: контракт элемента в `@churchapps/helpers`, конвейер рендеринга, элементы данных церкви, виджеты по всему сайту, слой блога, страницы, управляемые доступом, SEO, генерация AI и диалоговые формы.

</div>
