# Регистрации

<div class="article-intro">

Регистрация - это одна система с тремя передними дверями: приложение киоска B1Checkin для персоналом управляемых и самообслуживающихся станций, самостоятельная регистрация внутри портала членов B1App, и администраторская посещаемость в B1Admin. Все три пишут на тот же модуль посещаемости в основном Api, и маршрутизация классов полностью движима Group -- нет отдельного объекта "locations" или "rooms". Слой безопасности детей сидит сверху: per-visit типы регистрации, серверные врата мощности и волонтерского соотношения, киоск-side право на возраст/класс, проверка надежного забора в выезде и страница родителя на провайдере текстов церкви. Эта страница отображает модель данных, потоки регистрации, слой безопасности и конвейер печати этикеток.

</div>
