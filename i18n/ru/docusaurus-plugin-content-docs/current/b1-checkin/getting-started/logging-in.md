# Вход в систему

<div class="article-intro">

Прежде чем использовать киоск для регистрации, нужно войти в учётную запись ChurchApps, которая имеет доступ к вашей церкви. На этой странице описаны первый вход, выбор церкви, автоматический вход и выход из системы.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Установите B1 Church Checkin на ваш планшет Android (см. [Начало работы](./index.md))
- Приготовьте email и пароль вашей учётной записи ChurchApps

</div>

## Первый вход

1. Откройте приложение B1 Church Checkin. После заставки появится экран входа с логотипом B1 Church Checkin.
2. Введите ваш **email address** в первом поле.
3. Введите ваш **password** во втором поле.
4. Нажмите кнопку **Login**.

Приложение проверяет учётные данные и выполняет вход. Если email или пароль неверны, внизу экрана появится сообщение об ошибке.

Если для учётной записи включён [двухфакторный вход](../../b1-admin/profile/managing-profile.md#two-factor-sign-in), приложение запросит код. Введите 6-значный код из приложения-аутентификатора владельца учётной записи или один из его резервных кодов и снова нажмите **Login**. Код нужен только для этого первого входа; после этого киоск остаётся в системе.

:::info
Это тот же email и пароль, которые вы используете для B1 Admin или любого другого продукта ChurchApps. Для киоска регистрации отдельная учётная запись не нужна.
:::

## Выбор церкви

После успешного входа приложение загружает список церквей, связанных с вашей учётной записью. Каждая церковь отображается карточкой с названием и логотипом (если он задан в B1 Admin).

- Если ваша учётная запись связана **только с одной церковью**, экран выбора всё равно появится. Нажмите на свою церковь, чтобы продолжить.
- Если ваша учётная запись связана **с несколькими церквями**, нажмите на ту церковь, которую должен обслуживать этот киоск.

Как только вы выбрали церковь, приложение загружает её фирменный стиль и настройки внешнего вида. Логотип вашей церкви будет отображаться в заголовке на всех последующих экранах.

## Автоматический вход при повторных запусках

После первого успешного входа приложение сохраняет на планшете защищённый токен входа и выбранную церковь. Пароль оно не хранит. При последующих запусках:

- Приложение входит в систему, используя сохранённый токен.
- Если вы ранее выбрали церковь, выбор восстанавливается, и вы сразу попадаете на **экран служений**.
- Если сохранённый вход больше не действителен, приложение возвращается на экран входа, чтобы вы могли войти снова.

:::tip
Поскольку киоск входит в систему автоматически, учётные данные нужно ввести только один раз при первоначальной настройке. После этого планшет можно включить, и он будет готов к работе.
:::

## Настройки администратора

Настройки администратора намеренно скрыты, чтобы участники церкви, использующие киоск, случайно не изменили конфигурацию. Чтобы открыть их:

1. Нажмите на **логотип церкви** в заголовке **семь раз** подряд (в течение двух секунд).
2. Если установлен PIN киоска, введите его, когда появится запрос.
3. Откроется экран **Admin Settings** со следующими пунктами:
   - **Change Service** — переключить выбранное время служения
   - **Change Printer** — открыть [настройки принтера](./printer-setup), чтобы найти и выбрать принтер
   - **Set/Change PIN** — задать или изменить PIN киоска, который защищает доступ к администрированию
   - **Logout** — выйти из системы и вернуться на экран входа

:::warning
Выход из системы удаляет все сохранённые учётные данные и выбор церкви. Чтобы снова использовать киоск, нужно будет заново ввести email и пароль. Выходите из системы, только если нужно сменить учётную запись или перенастроить киоск.
:::
