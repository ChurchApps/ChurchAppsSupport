# Вход в систему

<div class="article-intro">

Прежде чем использовать киоск для регистрации, нужно войти с учётной записью ChurchApps, которая имеет доступ к вашей церкви. На этой странице описаны первый вход, выбор церкви, автоматический вход при повторном запуске и выход из системы.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Установите B1 Church Checkin на ваш Android-планшет (см. [Начало работы](./index.md))
- Подготовьте email и пароль вашей учётной записи ChurchApps
- Учётной записи нужно право **Checkin** (или **Edit Attendance**) в вашей церкви. Администратор добавляет его в B1 Admin в разделе **Settings > Roles** — см. [Учётные записи киоска регистрации](../../b1-admin/settings/roles-permissions.md#check-in-kiosk-accounts)

</div>

## Первый вход

1. Откройте приложение B1 Church Checkin. После заставки появится экран входа с логотипом B1 Church Checkin.
2. Введите свой **адрес электронной почты** в первое поле.
3. Введите свой **пароль** во второе поле.
4. Нажмите кнопку **Login**.

Приложение проверяет ваши учётные данные и выполняет вход. Если email или пароль неверны, внизу экрана появится сообщение об ошибке.

Если для учётной записи включён [двухфакторный вход](../../b1-admin/profile/managing-profile.md#two-factor-sign-in), приложение запросит код. Введите 6-значный код из приложения-аутентификатора владельца учётной записи или один из его резервных кодов и снова нажмите **Login**. Код нужен только для этого первого входа; после этого киоск остаётся в системе.

:::info
Это тот же email и пароль, которые вы используете для B1 Admin или любого другого продукта ChurchApps. Отдельная учётная запись для киоска регистрации не нужна.
:::

## Выбор церкви

После успешного входа приложение загружает церкви, в которых ваша учётная запись имеет право **Checkin** или **Edit Attendance**. Церкви, где у вас есть только другие права, не отображаются. Если подходящих церквей не осталось, приложение показывает **No check-in access** и просит администратора вашей церкви добавить право Checkin к одной из ваших ролей. Каждая церковь отображается карточкой с названием и логотипом церкви (если он настроен в B1 Admin).

- Если ваша учётная запись связана **только с одной церковью**, экран выбора всё равно появится. Нажмите на свою церковь, чтобы продолжить.
- Если ваша учётная запись связана **с несколькими церквями**, нажмите на ту церковь, которую этот киоск должен обслуживать.

Когда вы выбираете церковь, приложение загружает её фирменный стиль и настройки внешнего вида. Логотип церкви будет показываться в заголовке на всех последующих экранах.

## Автоматический вход при повторных запусках

После первого успешного входа приложение сохраняет на планшете защищённый токен входа и выбранную церковь. Пароль оно не сохраняет. При последующих запусках:

- Приложение входит в систему автоматически, используя сохранённый токен.
- Если вы ранее выбрали церковь, выбор восстанавливается, и вы сразу переходите к **экрану служений**.
- Если сохранённый вход больше не действителен, приложение возвращает вас на экран входа, чтобы вы могли войти снова.

:::tip
Поскольку киоск входит в систему автоматически, учётные данные нужно ввести только один раз при первоначальной настройке. После этого планшет можно включать, и он будет готов к работе.
:::

## Настройки администратора

Настройки администратора намеренно скрыты, чтобы участники церкви, пользующиеся киоском, не могли случайно изменить конфигурацию. Чтобы открыть их:

1. Нажмите **логотип церкви** в заголовке **семь раз** подряд (в течение двух секунд).
2. Если установлен PIN киоска, введите PIN, когда появится запрос.
3. Откроется экран **Admin Settings** с такими параметрами:
   - **Change Service** — переключить выбранное время служения
   - **Change Printer** — открыть [настройки принтера](./printer-setup.md), чтобы найти и выбрать принтер
   - **Set/Change PIN** — задать или изменить PIN киоска, который защищает доступ администратора
   - **Logout** — выйти из системы и вернуться на экран входа

:::warning
Выход из системы удаляет все сохранённые учётные данные и выбор церкви. Чтобы снова пользоваться киоском, придётся заново ввести email и пароль. Выходите из системы, только когда нужно сменить учётную запись или перенастроить киоск.
:::
