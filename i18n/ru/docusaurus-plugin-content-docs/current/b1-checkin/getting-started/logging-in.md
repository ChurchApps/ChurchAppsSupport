# Вход в систему

<div class="article-intro">

Прежде чем использовать киоск для регистрации, нужно войти под учётной записью ChurchApps, которая имеет доступ к вашей церкви. На этой странице описаны первый вход в систему, выбор церкви, автоматический вход и выход из системы.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Установите B1 Church Checkin на свой Android-планшет (см. [Начало работы](./index.md))
- Подготовьте адрес электронной почты и пароль от учётной записи ChurchApps
- Учётной записи нужно разрешение **Checkin** (или **Edit Attendance**) в вашей церкви. Его добавляет администратор в B1 Admin в разделе **Settings > Roles** — см. [Учётные записи киоска регистрации](../../b1-admin/settings/roles-permissions.md#check-in-kiosk-accounts)

</div>

## Первый вход

1. Откройте приложение B1 Church Checkin. После заставки появится экран входа с логотипом B1 Church Checkin.
2. Введите **адрес электронной почты** в первом поле.
3. Введите **пароль** во втором поле.
4. Нажмите кнопку **Login**.

Приложение проверяет данные и выполняет вход. Если адрес электронной почты или пароль неверны, внизу экрана появится сообщение об ошибке.

Если для учётной записи включена [двухфакторная аутентификация](../../b1-admin/profile/managing-profile.md#two-factor-sign-in), приложение запросит код. Введите 6-значный код из приложения-аутентификатора владельца учётной записи или один из его резервных кодов и снова нажмите **Login**. Код нужен только при первом входе: после этого киоск остаётся в системе.

:::info
Это тот же адрес электронной почты и пароль, которые вы используете в B1 Admin или других продуктах ChurchApps. Отдельная учётная запись для киоска регистрации не нужна.
:::

## Выбор церкви

После успешного входа приложение загружает церкви, в которых ваша учётная запись имеет разрешение **Checkin** или **Edit Attendance**. Церкви, где у вас есть только другие разрешения, не отображаются. Если подходящих церквей нет, приложение показывает сообщение **No check-in access** и просит попросить администратора церкви добавить разрешение Checkin одной из ваших ролей. Каждая церковь отображается карточкой с названием и логотипом (если он настроен в B1 Admin).

- Если ваша учётная запись привязана **только к одной церкви**, экран выбора всё равно появится. Нажмите на свою церковь, чтобы продолжить.
- Если учётная запись привязана **к нескольким церквям**, нажмите на ту, которую этот киоск должен обслуживать.

После выбора церкви приложение загружает её фирменный стиль и настройки оформления. Логотип церкви будет отображаться в заголовке на всех последующих экранах.

## Автоматический вход при повторном использовании

После первого успешного входа приложение сохраняет на планшете защищённый токен входа и выбранную церковь. Пароль не сохраняется. При последующих запусках:

- Приложение выполняет вход с помощью сохранённого токена.
- Если церковь была выбрана ранее, выбор восстанавливается, и приложение сразу переходит на **экран служений**.
- Если сохранённый вход больше не действителен, приложение возвращается на экран входа, чтобы вы могли войти заново.

:::tip
Поскольку киоск входит автоматически, данные для входа нужно ввести только один раз при первоначальной настройке. После этого планшет достаточно включить, и он будет готов к работе.
:::

## Настройки администратора

Настройки администратора намеренно скрыты, чтобы участники церкви, использующие киоск, случайно не изменили конфигурацию. Чтобы открыть их:

1. Семь раз быстро нажмите на **логотип церкви** в заголовке (в течение двух секунд).
2. Если установлен PIN-код киоска, введите его по запросу.
3. Откроется экран **Admin Settings** со следующими пунктами:
   - **Change Service** — смена выбранного времени служения
   - **Change Printer** — открыть [настройки принтера](./printer-setup.md), чтобы найти и выбрать принтер
   - **Set Admin PIN** (или **Change Admin PIN**, если PIN уже задан) — установка или изменение PIN-кода киоска, который защищает доступ администратора
   - **Emergency broadcast** — отправить SMS опекунам всех зарегистрированных семей (см. [Экстренная рассылка](../check-in/checking-out.md#emergency-broadcast))
   - **Manned station mode** — переключатель, который добавляет на эту станцию выдачу детей, вызов, повторную печать и редактирование профиля (см. [Выдача детей](../check-in/checking-out.md))
   - **Logout** — выход из системы и возврат на экран входа

   Нажмите **Back to Kiosk**, чтобы вернуться к регистрации.

:::warning
Выход из системы удаляет все сохранённые данные для входа и выбор церкви. Чтобы снова пользоваться киоском, придётся заново ввести адрес электронной почты и пароль. Выходите из системы, только когда нужно сменить учётную запись или перенастроить киоск.
:::
