# Проверка состава семьи

<div class="article-intro">

После выбора человека из результатов поиска приложение загружает всю вашу семью и отображает её на экране проверки. Это центральный узел процесса регистрации, где вы можете увидеть всех членов семьи и управлять их назначениями в группы перед регистрацией.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- [Выберите служение](./selecting-service.md) на экране служений
- [Найдите участника](./looking-up-members.md) и выберите его из результатов поиска

</div>

## Просмотр членов семьи

Каждый член семьи отображается в виде карточки, на которой есть:

- Его **фото** (или значок-заглушка, если фото не загружено)
- Его **отображаемое имя**
- **Краткая сводка текущих назначений в группы** (показывается мелкими чипами под именем, когда карточка свёрнута)
- Значок **Уже зарегистрирован**, если он уже зарегистрирован на это служение сегодня
- **Стрелку развернуть/свернуть** справа

## Развёртывание карточки участника

Нажмите на карточку участника, чтобы развернуть её. В развёрнутом виде вы увидите строку для каждого **времени служения** в выбранном служении, от более раннего к позднему. Времена служения упорядочены по запланированному дню и времени начала, если они заданы; в противном случае — по времени в их названии (так что «9:00» идёт раньше «10:30»); времена служения без времени в названии идут в конце, по алфавиту. Каждая строка содержит:

- **Название времени служения** (например, «9:00» или «11:00»)
- **Группы, доступные в это время служения**, перечисленные под названием (например, «Ясли, Дошкольники, Взрослый библейский класс»), чтобы вы могли увидеть, какие занятия доступны, прежде чем сделать выбор
- **Кнопку** с назначенной группой или «Выбрать группу», если группа ещё не назначена

Если для времени служения задано [расписание регистрации](../../b1-admin/attendance/setup.md#setting-a-check-in-schedule) и его окно сейчас закрыто, вместо кнопки строка показывает **Закрыто** — с временем следующего открытия, если оно есть, например **Закрыто · открывается вс 9:30**. Если человек уже зарегистрирован на это время служения, строка вместо этого показывает его группу с галочкой (например, **Детская комната 1 · Зарегистрирован**), чтобы вы видели, где он находится, даже если окно уже закрыто.

Нажмите кнопку группы, чтобы перейти к [экрану выбора группы](./group-assignment.md), где можно выбрать или изменить группу для этого человека и времени служения.

Развёрнутая карточка также показывает чипы **Участник**, **Гость** и **Волонтёр**. Нажмите на один из них, чтобы указать, как этот человек регистрируется — по умолчанию выбран «Участник». Тип важен для детских комнат: волонтёры учитываются в соотношении волонтёров и детей в комнате, а гости учитываются в рамках любой гостевой вместимости, установленной вашей церковью.

Нажмите на карточку участника ещё раз, чтобы свернуть её.

:::tip
Не обязательно назначать в группу каждого члена семьи. Взрослые, которые присутствуют на основном богослужении, могут остаться без назначения в группу. Назначайте группы только тем участникам, которым нужно зарегистрироваться в конкретный класс или программу.
:::

## Навигация с этого экрана

С экрана проверки семьи доступны три действия:

- **Разверните карточку участника** и нажмите кнопку времени служения, чтобы [назначить или изменить группу](./group-assignment.md).
- **Нажмите кнопку «Добавить гостя»** под списком участников, чтобы [добавить гостя](./adding-guests.md) в свою семью.
- **Нажмите кнопку «Регистрация»** внизу экрана, чтобы [завершить регистрацию](./completing-checkin.md) для всей семьи.

:::info
Все назначения групп из предыдущей регистрации на то же служение загружаются автоматически. Если ваши дети каждую неделю ходят в одни и те же группы, возможно, ничего менять не придётся — просто проверьте и зарегистрируйтесь.
:::
