# Просмотр вашего домохозяйства

<div class="article-intro">

После выбора человека из результатов поиска приложение загружает все ваше домохозяйство и отображает его на экране просмотра домохозяйства. Это центральный центр процесса регистрации, где вы можете видеть всех в вашей семье и управлять их назначениями групп перед регистрацией.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- [Выберите служение](./selecting-service) на экране служений
- [Найдите участника](./looking-up-members) и выберите его из результатов поиска

</div>

## Просмотр членов домохозяйства

Каждый член домохозяйства появляется как карточка с:

- Их **фотография** (или значок-заполнитель, если нет фотографии на файле)
- Их **имя отображения**
- **Резюме их текущих назначений групп** (показано как небольшие чипы под именем, когда карточка свернута)
- **Стрелка развертывания/свертывания** на правой стороне

## Развертывание участника

Нажмите на карточку участника, чтобы развернуть ее. При развертывании вы увидите строку для каждого **времени служения** в выбранном служении. Каждая строка показывает:

- **Имя времени служения** (например, "9:00 AM" или "11:00 AM")
- **Группы, предложенные** в это время служения, указанные под именем (например, "Детская, Дошкольное отделение, Класс Библии для взрослых"), чтобы вы могли увидеть, какие классы доступны перед выбором
- **Кнопку**, показывающую текущую назначенную группу, или "Выбрать группу", если группа еще не назначена

Нажмите кнопку группы, чтобы перейти на [экран выбора группы](./group-assignment), где вы можете выбрать или изменить группу для этого человека и времени служения.

Развернутая карточка также показывает чипы **Участник**, **Гость** и **Волонтер**. Нажмите одну, чтобы установить, как этот человек регистрируется — "Участник" по умолчанию. Тип имеет значение для детских комнат: волонтеры считаются в соотношении волонтер-ребенок для комнаты, а гости считаются в соответствии с любой вместимостью гостей, которую установила ваша церковь.

Нажмите на карточку члена снова, чтобы свернуть ее.

:::tip
Вам не нужно назначать каждого члена семьи в группу. Взрослые, которые присутствуют на основном служении, могут остаться без назначения группы. Назначайте группы только для членов, которые должны быть зарегистрированы в определенном классе или программе.
:::

## Навигация с этого экрана

С экрана просмотра домохозяйства у вас есть три варианта:

- **Развернуть участника** и нажать кнопку времени служения, чтобы [назначить или изменить группу](./group-assignment).
- **Нажать кнопку "Добавить гостя"** под списком членов, чтобы [добавить гостя](./adding-guests) в ваше домохозяйство.
- **Нажать кнопку "Регистрация"** в нижней части экрана, чтобы [завершить регистрацию](./completing-checkin) для всех в домохозяйстве.

:::info
Любые назначения групп из предыдущей регистрации на то же служение предварительно загружаются автоматически. Если ваши дети посещают одни и те же группы каждую неделю, вам может не потребоваться что-либо изменять — просто просмотрите и зарегистрируйтесь.
:::

- [Добавьте гостя](./adding-guests), если кто-то посещает вашу семью.
