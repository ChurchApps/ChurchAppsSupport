# Проверка вашего домохозяйства

<div class="article-intro">

После того как вы выбрали человека из результатов поиска, приложение загружает ваше домохозяйство и показывает его на экране проверки домохозяйства. Это центральная точка процесса регистрации, где вы можете увидеть всех членов семьи и управлять назначением групп перед регистрацией.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- [Выберите служение](./selecting-service) на экране служений
- [Найдите участника](./looking-up-members) и выберите его из результатов поиска

</div>

## Просмотр членов домохозяйства

Каждый член домохозяйства отображается как карточка, на которой есть:

- Его **фото** (или значок-заглушка, если фото не загружено)
- Его **отображаемое имя**
- **Краткая сводка текущих назначений групп** (небольшие чипы под именем, когда карточка свернута)
- **Стрелка разворачивания/сворачивания** справа

## Развертывание участника

Нажмите на карточку участника, чтобы развернуть ее. В развернутом виде вы увидите строку для каждого **времени служения** в выбранном служении, начиная с самого раннего. Времена служения сортируются по запланированному дню и времени начала, если они заданы, иначе по времени в названии (так «9:00 AM» идет раньше «10:30 AM»); времена служения без времени в названии идут последними, в алфавитном порядке. Каждая строка показывает:

- **Название времени служения** (например, «9:00 AM» или «11:00 AM»)
- **Группы, доступные в это время служения**, перечисленные под названием (например, «Nursery, Preschool, Adult Bible Class»), чтобы вы видели, какие занятия доступны, прежде чем выбрать
- **Кнопку** с текущей назначенной группой или «Select Group», если группа еще не назначена

Если для времени служения есть [расписание регистрации](../../b1-admin/attendance/setup#setting-a-check-in-schedule) и его окно сейчас закрыто, в строке вместо кнопки показывается **Closed** — с указанием следующего времени открытия, если оно есть, например **Closed · opens Sun 9:30 AM**. Если человек уже зарегистрирован на это время служения, в строке вместо кнопки показывается его группа с галочкой (например, **Kids Room 1 · Checked in**), чтобы вы видели, где он находится, даже если окно уже закрыто.

Нажмите на кнопку группы, чтобы перейти на [экран выбора группы](./group-assignment), где можно выбрать или изменить группу для этого человека и времени служения.

В развернутой карточке также показаны чипы **Member**, **Guest** и **Volunteer**. Нажмите один из них, чтобы указать, как этот человек регистрируется — по умолчанию выбран Member. Тип важен для детских комнат: волонтеры учитываются в соотношении волонтеров к детям в помещении, а гости учитываются в лимите гостевой вместимости, если ваша церковь ее установила.

Нажмите на карточку участника еще раз, чтобы свернуть ее.

:::tip
Необязательно назначать группу каждому члену семьи. Взрослые, которые посещают основное богослужение, могут остаться без назначения группы. Назначайте группы только тем участникам, которым нужна регистрация в конкретный класс или программу.
:::

## Навигация с этого экрана

С экрана проверки домохозяйства доступны три действия:

- **Разверните участника** и нажмите кнопку времени служения, чтобы [назначить или изменить группу](./group-assignment).
- **Нажмите кнопку Add Guest** под списком участников, чтобы [добавить гостя](./adding-guests) в ваше домохозяйство.
- **Нажмите кнопку Check-in** внизу экрана, чтобы [завершить регистрацию](./completing-checkin) для всего домохозяйства.

:::info
Назначения групп из предыдущей регистрации на то же служение загружаются автоматически. Если ваши дети каждую неделю ходят в одни и те же группы, возможно, ничего менять не придется — просто проверьте и зарегистрируйтесь.
:::
