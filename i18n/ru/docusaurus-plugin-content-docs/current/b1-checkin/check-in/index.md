# Процесс регистрации

<div class="article-intro">

Процесс регистрации в B1 Church Checkin следует простому пошаговому потоку. Участник церкви подходит к киоску, находит свою семью, подтверждает назначения в группы и регистрируется — все это менее чем за минуту. В этом разделе описан каждый шаг процесса регистрации через киоск.

</div>

## Процесс регистрации в общих чертах

1. **[Выберите служение](./selecting-service)** — Выберите служение, которое вы посещаете (например, воскресное утреннее, воскресное вечернее, будничное).
2. **[Найдите свою семью](./looking-up-members)** — Найдите себя в системе по номеру телефона или фамилии.
3. **[Просмотрите свою семью](./household-review)** — Просмотрите всех членов семьи и их текущие назначения в группы.
4. **[Назначьте группы](./group-assignment)** — Выберите, какой класс или группу должен посещать каждый член семьи для каждого времени служения.
5. **[Добавьте гостей](./adding-guests)** (необязательно) — Добавьте посетителя в свою семью, если он присоединяется к вам.
6. **[Завершите регистрацию](./completing-checkin)** — Нажмите кнопку регистрации, чтобы отправить данные о посещаемости и распечатать бирки.
7. **[Выдача](./checking-out)** (на пунктах с персоналом) — Во время выдачи проверьте код безопасности и человека, забирающего ребенка, с использованием списков доверенных лиц, вызова родителя и повторной печати бирок.

После завершения регистрации приложение отображает экран успеха и автоматически возвращается на экран поиска, готовое к следующей семье.

:::tip
Весь процесс разработан так, чтобы участники церкви могли пользоваться им самостоятельно. Волонтерам не нужно управлять киоском, хотя присутствие кого-то рядом, чтобы помочь новым посетителям, всегда хорошая идея.
:::

## Прежде чем начать

Убедитесь, что следующее настроено в B1 Admin перед использованием киоска регистрации:

- **Служения и времена служений** настроены в разделе настроек посещаемости. См. [руководство по настройке посещаемости](../../b1-admin/attendance/setup.md).
- **Группы** созданы и связаны с соответствующими временами служений. См. [создание групп](../../b1-admin/groups/creating-groups.md).
- **Настройки групп** сконфигурированы для печати бирок: включите **Печать именной бирки** для групп, которым нужны именные бирки, и **Выдача родителям** для детских групп, которым нужны талоны выдачи.
- **Люди** добавлены в систему с указанием семейных связей. См. [добавление людей](../../b1-admin/people/adding-people.md).

:::info
Если вы еще не настроили сам киоск, см. раздел [Начало работы](../getting-started/) с инструкциями по установке, входу в систему и настройке принтера.
:::
