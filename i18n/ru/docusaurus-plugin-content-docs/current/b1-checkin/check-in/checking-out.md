# Выезд и безопасность детей

<div class="article-intro">

При выезде B1 Checkin подтверждает, что правильный взрослый забирает каждого ребенка. Используйте доверенных лиц для забора, режим пейджинга для связи с родителями и экстренное вещание для срочных уведомлений.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Настройте [доверенные лица для забора](../../b1-admin/attendance/checkin-safety.md#trusted-and-not-authorized-pickup-people)
- Подключите поставщика текстовых сообщений для пейджинга ([Text In Church](../../b1-admin/integrations/services/text-in-church) или Clearstream)

</div>

## Экран выезда

При нажатии на "Checkout" на киоске:

1. Отображается фотография и имя ребенка
2. Экран показывает доверенных лиц для забора для этого хозяйства
3. Персонал может нажать на доверенного лица для подтверждения выезда

## Проверка личности

Если человек, пришедший забрать ребенка, не является доверенным лицом:

1. Персонал может ввести их имя
2. B1 проверяет против "Not Authorized" списка
3. Если они внесены в черный список, появляется предупреждение
4. Персонал может переопределить и записать причину

## Пейджинг родителей

Если нужно найти родителя/опекуна:

1. На экране выезда нажмите **Page Parent**
2. Введите сообщение (например, "Please come to the nursery")
3. Нажмите **Send**
4. B1 отправляет текстовое сообщение всем родителям/опекунам в этом хозяйстве

## Экстренное вещание

При срочной ситуации персонал может отправить сообщение всем:

1. На admin экране киоска нажмите **Emergency Broadcast**
2. Выберите служение
3. Введите сообщение
4. Введите **EMERGENCY** для подтверждения
5. Нажмите **Send**

B1 отправляет текстовое сообщение всем прихожанам хозяйств для выбранного служения.

## Запись переопределений

Любые переопределения выезда (когда к неавторизованному лицу выписан ребенок) записываются в отчет посещаемости с отметкой о времени и причиной.
