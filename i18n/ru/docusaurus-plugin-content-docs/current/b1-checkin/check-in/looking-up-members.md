# Поиск участников

<div class="article-intro">

После выбора службы вы попадаете на экран поиска участников. Здесь вы ищете свою семью, чтобы отметить вход. Приложение поддерживает поиск по номеру телефона или по имени.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- [Выберите службу](./selecting-service.md) на экране служб
- Убедитесь, что ваша семья [добавлена в систему](../../b1-admin/people/adding-people.md) администратором церкви

</div>

## Режимы поиска {#search-modes}

На экране поиска доступны два режима. Переключаться между ними можно нажатием на переключатель вверху экрана:

- **Phone** — поиск по номеру телефона. Это режим по умолчанию.
- **Name** — поиск по имени.

## Поиск по номеру телефона {#searching-by-phone-number}

1. Убедитесь, что активен режим **Phone** (он выделен вверху).
2. Нажмите на поле поиска и введите не менее **4 цифр** вашего номера телефона с экранной клавиатуры.
3. Нажмите кнопку **Search** или клавишу поиска на клавиатуре.

Приложение ищет участников, номер телефона которых совпадает с введёнными цифрами. Если вы вводите больше 4 цифр, используется полный номер. Если вы вводите ровно 4 цифры, поиск идёт по последним 4 цифрам номеров телефонов из базы.

## Поиск по имени {#searching-by-name}

1. Нажмите на переключатель **Name** вверху экрана, чтобы перейти в режим поиска по имени.
2. Введите не менее **2 символов** имени человека в поле поиска.
3. Нажмите кнопку **Search**.

Приложение ищет участников, чьи имена совпадают с введённым текстом.

## Выбор человека {#selecting-a-person}

Результаты поиска появляются в виде карточек под полем поиска. На каждой карточке показаны **имя** и **фото** человека (если оно есть в базе).

Нажмите на карточку человека, чтобы выбрать его. Приложение загрузит всех участников его домохозяйства и перейдёт к [экрану проверки домохозяйства](./household-review.md).

:::tip
Поиск по последним 4 цифрам номера телефона — самый быстрый способ найти свою семью. Рекомендуйте участникам этот способ для более быстрой регистрации.
:::

:::warning
Если ничего не найдено, приложение покажет сообщение. Проверьте введённые цифры или имя либо попробуйте другой режим поиска. Если вы посещаете церковь впервые, попросите волонтёра помочь вам [добавиться в систему](../../b1-admin/people/adding-people.md).
:::

## Регистрация в качестве гостя {#registering-as-a-guest}

Если в вашей церкви включена гостевая регистрация по QR-коду, под поиском на экране появляется ссылка **Register as guest**. Посетители, которые пришли впервые, могут использовать её, чтобы добавить свою семью в систему церкви перед регистрацией.

1. Нажмите **Register as guest**. Откроется окно с QR-кодом и надписью «Scan to register as a guest.»
2. Выберите, как заполнить [форму гостевой регистрации](../../b1-church/checkin/guest-registration.md):
   - **На своём телефоне** — отсканируйте QR-код, заполните форму на телефоне и нажмите **OK**, чтобы закрыть окно.
   - **На киоске** — нажмите **Register here**, чтобы открыть ту же форму прямо на планшете. Заполните её, нажмите **Register**, затем нажмите **Done** (или стрелку «назад»), чтобы вернуться на экран поиска.
3. После регистрации найдите свою семью по имени или номеру телефона, чтобы отметить вход.

:::info
Форма, открытая по **Register here**, остаётся на странице гостевой регистрации: из киоска нельзя перейти к другим разделам сайта церкви. Если в течение 2 минут никто не трогает форму и ничего в неё не вводит, киоск закрывает её и возвращает на экран поиска. Каждый раз, когда форма закрывается, всё введённое в неё очищается, чтобы следующая семья начинала с пустой формы.
:::

## Печать этикеток при регистрации по телефону {#printing-labels-for-a-phone-check-in}

Семьи, которые уже зарегистрировались по телефону через [самостоятельную регистрацию B1 Church](../../b1-church/checkin/self-checkin.md), могут распечатать именные наклейки на киоске, не выполняя поиск.

1. На экране поиска нажмите кнопку **Scan code** (значок QR-кода).
2. Поднесите QR-код с вашего телефона к камере. Если приложение запросит доступ к камере, нажмите **Allow Camera**. По умолчанию используется фронтальная камера; чтобы переключить её, нажмите кнопку переворота.
3. Киоск находит регистрацию и печатает этикетки, затем возвращается на экран поиска.

Сканирование только печатает этикетки — посещаемость уже была записана, когда семья зарегистрировалась по телефону. Если код не соответствует активной регистрации, киоск покажет сообщение и вернётся на экран поиска.

## Следующий шаг {#next-step}
