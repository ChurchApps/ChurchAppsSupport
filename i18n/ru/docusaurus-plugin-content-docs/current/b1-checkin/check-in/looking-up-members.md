# Поиск членов

<div class="article-intro">

После выбора службы вы попадаете на экран поиска членов. Здесь вы ищете свою семью, чтобы зарегистрировать свое присутствие. Приложение поддерживает поиск по номеру телефона или по имени.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- [Выберите службу](./selecting-service) на экране услуг
- Убедитесь, что ваша семья была [добавлена в систему](../../b1-admin/people/adding-people.md) администратором церкви

</div>

## Режимы поиска

Экран поиска предлагает два режима поиска. Вы можете переключаться между ними, нажав переключатель в верхней части экрана:

- **Телефон** -- поиск по номеру телефона. Это режим по умолчанию.
- **Имя** -- поиск по имени.

## Поиск по номеру телефона

1. Убедитесь, что **Телефон** является активным режимом поиска (он выделен в верхней части).
2. Нажмите на поле поиска и введите по крайней мере **4 цифры** вашего номера телефона, используя экранную клавиатуру.
3. Нажмите кнопку **Поиск** или нажмите клавишу поиска на клавиатуре.

Приложение ищет членов, номер телефона которых соответствует введенным цифрам. Если вы введете более 4 цифр, оно использует полный номер. Если вы введете ровно 4 цифры, оно сравнивает с последними 4 цифрами номеров телефонов в системе.

## Поиск по имени

1. Нажмите переключатель **Имя** в верхней части экрана, чтобы перейти в режим поиска по имени.
2. Введите по крайней мере **2 символа** имени человека в поле поиска.
3. Нажмите кнопку **Поиск**.

Приложение ищет членов, имя которых соответствует введенному тексту.

## Выбор человека

Результаты поиска отображаются в виде карточек под полем поиска. На каждой карточке показаны **имя** и **фото** человека (если они есть в системе).

Нажмите на карточку человека, чтобы выбрать его. Приложение загружает всех членов семьи этого человека и переводит вас на [экран просмотра семьи](./household-review).

:::tip
Поиск по последним 4 цифрам номера телефона - это самый быстрый способ найти свою семью. Рекомендуйте членам использовать этот метод для более быстрого процесса регистрации.
:::

:::warning
Если результатов не найдено, приложение выдает сообщение. Еще раз проверьте введенные цифры или имя или попробуйте другой режим поиска. Если вы впервые посетитель, попросите помощь у волонтера для [добавления в систему](../../b1-admin/people/adding-people.md).
:::

## Регистрация в качестве гостя

Если в вашей церкви включена QR-регистрация гостей, ссылка **Зарегистрироваться как гость** появляется под поиском на экране поиска. Впервые посещающие могут использовать ее для добавления своей семьи в систему церкви перед регистрацией присутствия.

1. Нажмите **Зарегистрироваться как гость**. Откроется окно с QR-кодом и сообщением "Отсканируйте, чтобы зарегистрироваться в качестве гостя."
2. Выберите, как заполнить [форму регистрации гостя](../../b1-church/checkin/guest-registration):
   - **На вашем телефоне** -- отсканируйте QR-код, заполните форму на вашем телефоне и нажмите **OK**, чтобы закрыть окно.
   - **На киоске** -- нажмите **Зарегистрироваться здесь**, чтобы открыть ту же форму прямо на планшете. Заполните ее и нажмите **Зарегистрироваться**, затем нажмите **Готово** (или стрелку возврата), чтобы вернуться на экран поиска.
3. После регистрации найдите свою семью по имени или номеру телефона для регистрации присутствия.

:::info
Форма, открытая с помощью **Зарегистрироваться здесь**, остается на странице регистрации гостей -- посетители не могут просматривать другие части веб-сайта церкви с киоска. Если никто не касается форму и не вводит данные в течение 2 минут, киоск закрывает ее и возвращается на экран поиска. Каждый раз, когда форма закрывается, все введенные данные стираются, поэтому следующая семья начинает с пустой формой.
:::

## Печать этикеток для проверки с телефона

Семьи, которые уже зарегистрировались на своем телефоне через [B1 Church самостоятельная регистрация](../../b1-church/checkin/self-checkin), могут распечатать свои бирки имен на киоске без самостоятельного поиска.

1. На экране поиска нажмите кнопку **Отсканировать код** (значок QR-кода).
2. Поднесите QR-код со своего телефона к камере. Если приложение попросит доступ к камере, нажмите **Разрешить доступ к камере**. По умолчанию используется фронтальная камера; нажмите кнопку переворота для переключения.
3. Киоск находит регистрацию присутствия и печатает этикетки, затем возвращается на экран поиска.

Сканирование только печатает этикетки -- присутствие уже было записано, когда семья зарегистрировалась на своем телефоне. Если код не соответствует активной регистрации, киоск выдает сообщение и возвращается на экран поиска.

## Следующий шаг

После выбора человека вы будете [просматривать вашу семью](./household-review) и управлять назначениями группы.
