# Завершение регистрации

<div class="article-intro">

Когда вы просмотрели свою семью и при необходимости назначили группы, можно завершить регистрацию. Это последний шаг в работе киоска: приложение отправляет данные о посещаемости, печатает этикетки и сбрасывается для следующей семьи.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- [Проверьте свою семью](./household-review) на экране проверки семьи
- [Назначьте группы](./group-assignment) для членов семьи, которым нужно зарегистрироваться на конкретный класс или программу
- По желанию [добавьте гостей](./adding-guests), которые приехали вместе с вашей семьёй

</div>

## Как зарегистрироваться

1. На **экране проверки семьи** нажмите кнопку **Check-in** внизу экрана.
2. Приложение отправляет данные о посещаемости на сервер и показывает **экран успеха** с зелёной галочкой и приветственным сообщением.

Больше ничего делать не нужно. Посещаемость вашей семьи записана.

## Заполненные комнаты и соотношение волонтёров

Если в вашей церкви настроены [ограничения безопасности](../../b1-admin/attendance/checkin-safety) для комнат, сервер проверяет их перед сохранением:

- Если выбранная комната **заполнена или закрыта**, регистрация не проходит, и приложение называет комнату, чтобы вы могли выбрать другую.
- Если у времени служения есть [расписание регистрации](../../b1-admin/attendance/setup#setting-a-check-in-schedule), а окно регистрации сейчас не открыто, регистрация в комнаты этого времени служения также отклоняется. На экране **Can't check in yet** указана комната с причиной «check-in isn't open right now»; нажмите **Change Rooms**, чтобы выбрать другое время служения или группу. (Времена служения, которые уже закрыты, когда вы [выбираете служение](./selecting-service#when-check-in-isnt-open), скрыты, так что обычно вы увидите это только в случае, если окно закрылось во время регистрации.)
- Если в детской комнате **не хватает волонтёров** по установленному соотношению, приложение либо показывает предупреждение, которое может подтвердить сотрудник, чтобы продолжить, либо полностью блокирует регистрацию — в зависимости от того, как ваша церковь настроила контроль соотношения.

## Печать этикеток

Если настроен сетевой принтер, приложение автоматически печатает этикетки после регистрации:

- **Именные этикетки** печатаются для каждого человека, назначенного в группу, где включена настройка **Print Nametag**. На именных этикетках указаны имя человека, назначенная группа, а также информация об аллергиях и заметки, если они есть в записи.
- **Талоны для выдачи родителям** печатаются, если кто-либо из зарегистрированных людей находится в группе, где включена настройка **Parent Pickup**. Люди, зарегистрированные как **Volunteer**, пропускаются, поэтому помощник по уходу за детьми, работающий в комнате Parent Pickup, не получает талон. На талоне указаны дети, их группы и уникальный **4-символьный код безопасности**.

:::info
Один и тот же код безопасности указан и на именной этикетке ребёнка, и на талоне родителя. При выдаче ребёнка волонтёры сверяют коды, чтобы убедиться, что его забирает нужный взрослый.
:::

Код безопасности создаётся заново при каждой регистрации и содержит только согласные и цифры (гласные исключены, чтобы не образовывались неподходящие слова).

:::warning
Если этикетки не печатаются, откройте настройки администратора, нажав **логотип церкви** семь раз, затем нажмите **Change Printer**, чтобы проверить подключение принтера. Шаги по устранению неполадок см. в разделе [Настройка принтера](../getting-started/printer-setup).
:::

## Что происходит после регистрации

- Если принтер настроен, приложение печатает все этикетки, а затем автоматически возвращается на **экран поиска**, готовое к следующей семье.
- Если принтер не настроен, экран успеха показывается несколько секунд, а затем приложение автоматически возвращается на **экран поиска**.

Нажимать ничего не нужно, чтобы вернуться на экран поиска — приложение выполняет переход автоматически.

:::tip
Приложение полностью сбрасывается после каждой регистрации, поэтому нет риска, что одна семья увидит информацию другой семьи.
:::

## Что записывается

Когда вы нажимаете **Check-in**, приложение отправляет на сервер для каждого члена домохозяйства, у которого есть назначение в группу:

- **человека**, который регистрируется
- **служение**, которое он посещает
- **время служения** и **группу**, в которую он назначен

Эти данные отображаются в B1 Admin в разделе Attendance, где администраторы церкви могут просматривать и управлять записями о посещаемости. Подробнее см. в [руководстве по администрированию регистрации](../../b1-admin/attendance/check-in.md).
