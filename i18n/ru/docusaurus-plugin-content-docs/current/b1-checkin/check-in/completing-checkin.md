# Завершение регистрации

<div class="article-intro">

Когда вы проверили свою семью и при необходимости назначили группы, можно завершить регистрацию. Это последний шаг в работе с киоском: приложение отправляет данные о посещаемости, печатает этикетки и готовится к следующей семье.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- [Проверьте свою семью](./household-review.md) на экране проверки семьи
- [Назначьте группы](./group-assignment.md) тем членам семьи, которым нужно зарегистрироваться в определённый класс или программу
- При необходимости [добавьте гостей](./adding-guests.md), которые пришли вместе с вашей семьёй

</div>

## Как завершить регистрацию

1. На **экране проверки семьи** нажмите кнопку **Check-in** внизу экрана.
2. Приложение отправляет данные о посещаемости на сервер и показывает **экран успеха** с зелёной галочкой и приветственным сообщением.

Больше ничего делать не нужно. Посещение вашей семьи записано.

Если кто-то из выбранных людей уже зарегистрировался на это богослужение сегодня, сначала появится окно **Уже зарегистрирован**, в котором будут указаны эти люди. Нажмите **Зарегистрировать снова**, чтобы сохранить новый выбор групп, или **Отмена**, чтобы вернуться к экрану семьи.

## Заполненные комнаты и соотношение волонтёров

Если в вашей церкви для комнат настроены [ограничения безопасности](../../b1-admin/attendance/checkin-safety.md), сервер проверяет их перед сохранением:

- Если выбранная комната **заполнена или закрыта**, регистрация не проходит, и приложение называет комнату, чтобы вы могли выбрать другую.
- Если у времени богослужения есть [расписание регистрации](../../b1-admin/attendance/setup.md#setting-a-check-in-schedule), а окно регистрации сейчас не открыто, регистрация в комнаты этого времени также отклоняется. На экране **Регистрация пока недоступна** указана комната с причиной «регистрация сейчас не открыта». Нажмите **Изменить комнаты**, чтобы выбрать другое время богослужения или группу. (Времена богослужений, которые уже закрыты, отображаются как **Закрыто** на [экране семьи](./household-review.md) и не могут быть выбраны, поэтому обычно вы увидите это сообщение, только если окно закрылось во время регистрации.)
- Семья, которая регистрировалась на более раннее время богослужения, может вернуться позже и добавить открытое время богослужения, даже если предыдущее окно уже закрылось. Существующие регистрации сохраняются и не приводят к отказу в новой регистрации.
- Если в детской комнате **не хватает волонтёров** для нужного соотношения, приложение либо показывает предупреждение, которое сотрудник может подтвердить, чтобы продолжить, либо полностью блокирует регистрацию. Что именно происходит, зависит от того, как ваша церковь настроила контроль соотношения.

## Печать этикеток

Если настроен сетевой принтер, приложение автоматически печатает этикетки после регистрации:

- **Именные бейджи** печатаются для каждого человека, назначенного в группу, где включена настройка **Print Nametag** (печать именного бейджа). На именном бейдже указаны имя человека, его группа и, если они есть в записях, сведения об аллергии и примечания.
- **Талоны для выдачи родителям** печатаются, если среди зарегистрированных есть человек из группы с включённой настройкой **Parent Pickup** (выдача родителям). Люди, зарегистрированные как **Volunteer** (волонтёр), пропускаются, поэтому помощник по уходу за детьми, работающий в комнате выдачи, талон не получает. В талоне перечислены дети, их группы и уникальный **4-символьный код безопасности**.

:::info
Один и тот же код безопасности указан и на именном бейдже ребёнка, и на талоне родителя. При выдаче ребёнка волонтёры сверяют коды, чтобы убедиться, что ребёнка забирает правильный взрослый.
:::

Код безопасности создаётся заново при каждой регистрации и содержит только согласные буквы и цифры. Гласные исключены, чтобы из кода не могли получиться неприличные слова.

:::warning
Если этикетки не печатаются, откройте настройки администратора, семь раз нажав на **логотип церкви**, затем нажмите **Сменить принтер**, чтобы проверить подключение. Шаги по устранению неполадок см. в разделе [Настройка принтера](../getting-started/printer-setup.md).
:::

## Что происходит после регистрации

- Если принтер настроен, приложение печатает все этикетки, а затем автоматически возвращается на **экран поиска**, готовый к следующей семье.
- Если принтер не настроен, приложение так же автоматически возвращается на **экран поиска**.

В любом случае экран успеха остаётся на экране не меньше 6 секунд с момента появления (8 секунд, если отмечается достижение человека по количеству посещений), чтобы семьи видели, что регистрация прошла успешно. Если печать занимает больше времени, приложение возвращается примерно через полторы секунды после её завершения.

Нажимать ничего не нужно, чтобы вернуться на экран поиска: переход происходит автоматически. Когда экран уже некоторое время отображается, на него можно нажать, чтобы вернуться сразу. Нажатие в первые полторы секунды игнорируется, поэтому быстрое двойное нажатие на **Check-in** не пропустит экран.

:::tip
После каждой регистрации приложение полностью сбрасывается, поэтому одна семья не увидит информацию другой.
:::

## Что сохраняется

Когда вы нажимаете **Check-in**, приложение отправляет на сервер следующие данные для каждого члена семьи, которому назначена группа:

- **человек**, который регистрируется
- **служение**, которое он посещает
- **время богослужения** и **группа**, в которые он назначен

Эти данные появляются в B1 Admin в разделе «Посещаемость», где администраторы церкви могут просматривать и управлять записями о посещаемости. Подробности см. в [руководстве администратора по регистрации](../../b1-admin/attendance/check-in.md).
