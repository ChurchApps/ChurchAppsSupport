# Обзор B1 Church Checkin

<div class="article-intro">

B1 Church Checkin — это приложение самообслуживания для киосков на iPad и Android-планшетах. Оно позволяет участникам найти свою семью, распределить детей по группам или классам и напечатать именные бейджи и талоны для выдачи детей — всё это без волонтёра за стойкой.

</div>

## Как это работает

Установите iPad или Android-планшет в фойе или на зоне приёма. Участники подходят, ищут свою семью по номеру телефона или фамилии, просматривают данные семьи, выбирают, какую группу должен посещать каждый, и нажимают **Check-in**. Приложение автоматически печатает именные бейджи и талоны, затем сбрасывается для следующей семьи.

## Основные возможности

- **Поиск участников на самообслуживании** — поиск по номеру телефона или фамилии, чтобы быстро найти свою семью.
- **Просмотр семьи** — все члены семьи с фото и текущими назначениями в группы видны сразу.
- **Назначение групп** — каждого члена семьи можно распределить в нужный класс или группу для выбранного времени служения.
- **Регистрация гостей** — добавить гостя в свою семью на месте, указав имя и фамилию.
- **Регистрация гостей по QR-коду** — показывать QR-код, который посетители сканируют, чтобы [зарегистрироваться самостоятельно](../b1-church/checkin/guest-registration) на своём телефоне до регистрации на служение, или позволить им нажать **Register here**, чтобы заполнить ту же форму на киоске.
- **Печать бейджей** — печать именных бейджей для детей и талонов для выдачи детей с уникальными кодами безопасности.
- **Поддержка сетевых принтеров** — поиск и настройка сетевых принтеров прямо из приложения.
- **Автоматический вход** — после первого входа приложение запоминает учётные данные и при следующих запусках сразу открывает экран служений.
- **Поддержка нескольких церквей** — если ваша учётная запись связана с несколькими церквями, можно выбрать, в какую из них регистрировать.
- **Фирменный стиль церкви** — приложение показывает логотип вашей церкви в заголовке после выбора церкви.
