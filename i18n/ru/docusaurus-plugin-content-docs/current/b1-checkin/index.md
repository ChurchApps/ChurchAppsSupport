# Обзор B1 Church Checkin

<div class="article-intro">

B1 Church Checkin — это приложение для самообслуживания на киоске для iPad и планшетов Android. Это позволяет членам церкви найти свою семью, назначить детей в группы или классы и распечатать бирки с именами и квитанции для родителей — всё без необходимости волонтёра у стойки.

</div>

## Как это работает

Поместите iPad или планшет Android в ваше вестибюле или зону приветствия. Члены подходят, ищут свою семью по номеру телефона или фамилии, проверяют своих близких, выбирают, какие группы должна посетить каждая семья, и нажимают **Зарегистрировать**. Приложение автоматически печатает бирки с именами и квитанции для родителей, а затем сбрасывает к следующей семье.

## Ключевые возможности

- **Самостоятельный поиск членов** — найдите своё домохозяйство по номеру телефона или фамилии быстро.
- **Обзор домохозяйства** — видьте всех членов семьи с фотографиями и текущие назначения групп с одного взгляда.
- **Назначение группы** — назначьте каждого члена семьи правильному классу или группе для выбранного времени обслуживания.
- **Регистрация гостя** — добавьте гостя в вашу семью на месте с именем и фамилией.
- **Регистрация гостя через QR-код** — отобразите QR-код, который посетители могут отсканировать, чтобы [зарегистрировать себя](../b1-church/checkin/guest-registration) на своём телефоне перед входом.
- **Печать этикеток** — печатайте бирки с именами для детей и квитанции для родителей с уникальными кодами безопасности.
- **Поддержка сетевых принтеров** — обнаруживайте и настраивайте сетевые принтеры прямо из приложения.
- **Автоматический вход** — после первого входа приложение запомнит ваши учётные данные и перейдёт прямо к экрану служб при будущих запусках.
- **Поддержка несколько церквей** — если ваша учётная запись связана с несколькими церквами, вы можете выбрать, в какую приходить.
- **Брендинг церкви** — приложение отображает логотип вашей церкви в заголовке после выбора церкви.
