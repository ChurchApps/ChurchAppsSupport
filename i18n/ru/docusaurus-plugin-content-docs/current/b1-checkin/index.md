# Обзор B1 Church Checkin

<div class="article-intro">

B1 Church Checkin - это приложение самообслуживания для киосков на iPad и планшетов Android. Это позволяет членам церкви найти свою семью, назначить детей в группы или классы и распечатать бирки имен и квитанции вывоза для родителей -- все это без помощи волонтера за столом.

</div>

## Как это работает

Поместите iPad или планшет Android в вашем холле или зоне приветствия. Члены подходят, ищут свою семью по номеру телефона или фамилии, просматривают свою семью, выбирают, в какие группы должен посещать каждый человек, и нажимают **Регистрация**. Приложение автоматически печатает бирки имен и квитанции вывоза, а затем перезагружается для следующей семьи.

## Ключевые особенности

- **Самообслуживание поиска членов** -- поиск по номеру телефона или фамилии для быстрого поиска вашей семьи.
- **Просмотр семьи** -- просмотрите всех членов семьи с фотографиями и текущими назначениями группы в один взгляд.
- **Назначение группы** -- назначьте каждого члена семьи в правильный класс или группу для выбранного времени службы.
- **Регистрация гостя** -- добавьте гостя в вашу семью на месте с первым и последним именем.
- **QR-регистрация гостей** -- отображение QR-кода, который посетители могут отсканировать для [самостоятельной регистрации](../b1-church/checkin/guest-registration) на своем телефоне перед регистрацией, или позвольте им нажать **Зарегистрироваться здесь**, чтобы заполнить ту же форму на киоске.
- **Печать этикеток** -- печать бирок имен для детей и квитанций вывоза для родителей с уникальными кодами безопасности.
- **Поддержка сетевых принтеров** -- обнаружение и настройка сетевых принтеров непосредственно из приложения.
- **Автоматический вход** -- после первого входа приложение запоминает ваши учетные данные и переходит прямо на экран услуг при будущих запусках.
- **Поддержка нескольких церквей** -- если ваша учетная запись связана с более чем одной церковью, вы можете выбрать, в какой из них зарегистрироваться.
- **Брендинг церкви** -- приложение отображает логотип вашей церкви в заголовке после выбора церкви.
