# Презентация и экспорт песен WorshipCommons

<div class="article-intro">

WorshipCommons может выводить текст песни на экран прямо из браузера, без установки чего-либо. Если в вашей церкви уже используется программа для презентаций, скачайте слайды песни для FreeShow, OpenLP, ProPresenter или PowerPoint либо добавьте песню в свою библиотеку песен B1 Admin.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Откройте страницу песни на [worshipcommons.org](https://worshipcommons.org). См. [Поиск песен](./finding-songs.md).
- Чтобы показать текст на телевизоре или проекторе, подключите компьютер к нему кабелем HDMI (или выведите экран по беспроводной связи).

</div>

## Ведение служения из браузера

**Lead worship** (Ведение служения) — это полноэкранный режим, который воспроизводит музыку и показывает слова построчно, подсвечивая каждое слово по мере пения. Он создан для небольшой группы, класса или домашней церкви без группы музыкантов.

1. На странице песни нажмите **Lead worship**. (Кнопка появляется, когда для песни есть музыка для аккомпанемента.)
2. Выберите **Key** (Тональность) и **Tempo** (Темп). Если у песни есть фрагмент фортепиано, можно выбрать **Piano** (Фортепиано) или **Organ** (Орган).
3. Нажмите **Verses** (Куплеты), чтобы выбрать, какие куплеты петь, и изменить их порядок стрелками.
4. Включите **Count-in** (Отсчёт), если хотите отсчёт перед началом музыки.
5. Нажмите **▶ Play** (Воспроизвести).

Используйте **Blank** (Очистить), чтобы скрыть слова, **Contrast** (Контраст) для экрана с высокой контрастностью и **Fullscreen** (Полный экран), чтобы заполнить весь экран. Нажмите **Put this on the TV** (Вывести на телевизор), чтобы быстро посмотреть, как вывести это на телевизор.

:::tip
Горячие клавиши: **Пробел** — воспроизведение/пауза, **← →** — переход по строке, **↑ ↓** — переход по куплетам, **B** — очистка экрана, **H** — контраст, **F** — полный экран, **Esc** — возврат к песне. Нажмите **Show keys** (Показать клавиши) внизу экрана, чтобы увидеть их полный список.
:::

## Проецирование текста

**Open projector** (Открыть проектор) показывает один раздел текста на экран, и вы переключаетесь между ними вручную. Используйте этот режим, если у вас выступают живые музыканты.

1. На странице песни найдите панель **Projection** (Проекция) и нажмите **Open projector** (Открыть проектор).
2. Нажмите **F** или кнопку **Fullscreen** (Полный экран), чтобы заполнить экран.
3. Нажмите на экран, пробел или клавишу **→**, чтобы перейти к следующему слайду. Нажмите **←**, чтобы вернуться назад. Нажмите на название раздела внизу, чтобы сразу перейти к нему.
4. Нажмите **B**, чтобы очистить экран, и **H** для высокой контрастности.
5. Нажмите **Esc** (или **← Back to song** (Назад к песне)), когда закончите.

В нижней панели показаны текущий раздел, количество слайдов и следующий раздел. Строка с авторством песни тоже появляется на экране.

## Экспорт слайдов

На панели **Projection** (Проекция) на странице песни есть кнопка для каждого инструмента. Нажмите на нужную, чтобы скачать песню:

| Кнопка | Что вы получите |
| --- | --- |
| **FreeShow** | Файл показа для импорта в [FreeShow](https://freeshow.app) |
| **PowerPoint** | Презентацию в формате PPTX |
| **OpenLP** | Файл OpenLyrics для импорта в OpenLP |
| **ProPresenter** | Текстовый файл для импорта в ProPresenter |
| **OnSong / PCO** | Копирует песню в буфер обмена для вставки в OnSong или Planning Center |

Примечание под кнопками объясняет, как разбиты слайды. Если у песни есть утверждённая схема формы, слайды следуют ей; в противном случае слайды повторяют куплеты в исходном виде. Каждый экспорт содержит указание авторства песни и информацию о лицензии.

:::tip
Чтобы экспортировать сразу весь набор в выбранных тональностях и разделах, создайте [план служения](./service-plans.md) и используйте там кнопки экспорта.
:::

## Добавление песен WorshipCommons в B1

Если ваша церковь планирует служения в B1 Admin, ничего скачивать не нужно. Готовые к воскресному служению песни из WorshipCommons появляются в поиске песен B1 Admin в разделе **WorshipCommons — free** (бесплатно). Нажмите на песню, чтобы добавить её в библиотеку песен со ссылкой на её страницу в WorshipCommons.

Шаги см. в разделе [Песни в B1 Admin](../b1-admin/serving/songs.md#free-songs-from-worshipcommons).
