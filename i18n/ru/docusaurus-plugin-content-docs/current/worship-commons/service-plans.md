# Планы служений WorshipCommons

<div class="article-intro">

План служения в WorshipCommons — это список песен на воскресное богослужение. Расставьте песни по порядку, выберите тональность, каподастр и разделы для каждой из них, а затем поделитесь одной ссылкой с группой музыкантов. Из плана можно открыть вид для пюпитра, распечатать буклет или экспортировать весь набор в программу для презентаций.

</div>

:::info
Планы служений сохраняются в вашем веб-браузере, а не в аккаунте, и для их использования не нужно входить в систему. Ссылка для совместного доступа содержит весь набор песен, поэтому сохраните её, если переходите на другое устройство. Если ваша церковь планирует служения в B1 Admin, см. [Планы](../b1-admin/serving/plans.md).
:::

## Создание плана служения

1. Нажмите **Планы служений** в верхнем меню.
2. Введите название, например «Воскресенье, 14 сентября» или «Молодёжный вечер», и нажмите **Создать план служения**.

План можно также создать из любой песни. На странице песни нажмите **+ Добавить в план служения**, введите название под списком и нажмите **Создать**.

## Добавление песен

1. Откройте страницу песни. Сначала выберите нужную тональность, так как песня добавляется в план в той тональности, которая показана на экране.
2. Нажмите **+ Добавить в план служения**.
3. Нажмите название плана. Галочка покажет, что песня уже в этом плане. Чтобы убрать песню, нажмите на неё ещё раз.

После этого кнопка будет показывать **✓ В плане** и название плана. Чтобы перейти к плану, нажмите ссылку **Открыть** с названием плана во всплывающем окне.

## Порядок набора

Откройте план на странице **Планы служений**. Для каждой песни вы можете:

- **Изменить порядок** — используйте кнопки **↑** и **↓** или перетащите песню на новое место. Нажмите **Удалить**, чтобы убрать песню из плана.
- **Тональность** — выберите одну из **опубликованных** тональностей песни или любую другую (они перечислены в разделе **Предпросмотр (любая тональность)**).
- **Каподастр** — выберите лад каподастра. План покажет, какие аккордовые аппликатуры играть.
- **Разделы** — задайте порядок куплетов и припевов. Стрелками переместите раздел, кнопкой **×** удалите его, а **+ Добавить раздел** добавит новый (например, повторяющийся припев). Нажмите **Сбросить по умолчанию**, чтобы вернуться к обычному порядку песни.
- **Аранжировка** — напишите короткую заметку для группы, например: «Припев ×2 в конце, последний куплет a cappella».

Вверху плана указаны количество песен и примерная продолжительность набора. Изменения сохраняются автоматически.

## Совместная работа с командой

1. Нажмите **Поделиться ссылкой**. Ссылка будет скопирована в буфер обмена.
2. Отправьте её группе музыкантов по SMS или электронной почте.

Любой, кто откроет ссылку, увидит план со всеми тональностями, каподастрами, разделами и заметками, и аккаунт для этого не понадобится. Чтобы сохранить собственную редактируемую копию в браузере, можно нажать **Сохранить копию**.

На странице **Планы служений** вы также можете **Поделиться**, **Переименовать**, **Дублировать** или **Удалить** план.

## Использование плана в воскресенье

- **Режим сцены** — показывает одну песенную карту на экране, что удобно для планшета на пюпитре. Для перехода между песнями используйте стрелки (или клавиши **←** и **→**), а для увеличения карты — кнопки размера текста. Режим сцены старается не давать экрану гаснуть; полоска показывает, включено ли **Экран не выключается**.
- **Печать буклета** — печатает все карты по порядку, по одной на странице, с обложкой, на которой перечислены песни и тональности. Выберите **Крупный текст** или **Показать аккорды», затем нажмите **Печать**.
- **Копировать для OnSong / Planning Center** — копирует все карты в ваших тональностях и разделах, готовые для вставки.

## Экспорт набора

Нажмите **FreeShow**, **OpenLP**, **ProPresenter** или **PowerPoint**, чтобы скачать весь набор для нужной программы — в выбранных вами тональностях и разделах.

Нажмите **Пакет для домашней церкви**, чтобы скачать ZIP-архив, в котором есть карта каждой песни в вашей тональности, текст, слайды, указание авторства, список набора и один файл LICENSE.txt.

:::warning
Песни под лицензией CC BY-SA не включаются в пакет для домашней церкви, если только вы не отметили **Пакет с share-alike (включить песни CC BY-SA)**. Если вы их включаете, всё, что вы создадите на основе пакета, должно распространяться на тех же условиях лицензии. Карты, режим сцены и буклет всегда включают эти песни.
:::
