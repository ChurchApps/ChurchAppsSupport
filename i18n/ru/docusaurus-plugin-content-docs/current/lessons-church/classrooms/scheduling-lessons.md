# Планирование уроков

Функция планирования позволяет вам назначить уроки классным комнатам и расписанию.

## Создание расписания

1. Перейдите в раздел **Classrooms**
2. Выберите классную комнату
3. Нажмите **Schedule Lesson**
4. Выберите урок
5. Установите дату и время
6. Нажмите **Save**

## Управление расписанием

Вы можете видеть все запланированные уроки:

- По классной комнате
- По дате
- По учителю
- По сериям

## Напоминания

Учителя получат напоминания о запланированных уроках перед датой проведения.

## Отмена урока

1. На запланированном уроке нажмите **Cancel**
2. Опционально добавьте причину отмены
3. Учителю будет отправлено уведомление об отмене
