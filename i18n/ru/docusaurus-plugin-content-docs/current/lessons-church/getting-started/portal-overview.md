# Обзор портала

Портал LessonsChurch предоставляет доступ к библиотеке уроков и инструментам управления классными комнатами.

## Области портала

### Для администраторов

- Управление уроками и сериями
- Управление классными комнатами
- Просмотр статистики использования
- Управление доступом пользователей

### Для учителей

- Просмотр запланированных уроков
- Доступ к материалам урока
- Загрузка ресурсов
- Отправка отзывов

### Для учащихся

- Просмотр материалов урока
- Выполнение заданий
- Взаимодействие с учителем
- Просмотр оценок

## Начало работы

1. Перейдите на портал LessonsChurch
2. Войдите с учетными данными вашей церкви
3. Выберите свою роль
4. Начните использовать портал

## Поддержка

Если вам нужна помощь:

- Свяжитесь с администратором вашей школы
- Посетите справку портала
- Свяжитесь с поддержкой ChurchApps
