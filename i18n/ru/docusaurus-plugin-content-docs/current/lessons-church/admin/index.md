# Администраторство LessonsChurch

Раздел администратора LessonsChurch позволяет вам управлять уроками, наборами уроков и классными комнатами.

## Подразделы

- **Managing Lessons** — создание и редактирование уроков
- **Managing Year Plans** — управление годовыми планами обучения
- **Open Lesson Format** — формат открытых уроков

## Типичные задачи

- Создание новых уроков
- Организация уроков по сериям
- Управление расписанием классных комнат
- Просмотр использования уроков

## Начало работы

1. Перейдите в раздел **Admin** в LessonsChurch
2. Выберите нужный раздел
3. Начните управление содержимым
