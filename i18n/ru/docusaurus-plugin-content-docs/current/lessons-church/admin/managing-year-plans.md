# Управление годовыми планами

<div class="article-intro">

Годовой план - это упорядоченный список уроков -- неделя 1, неделя 2, неделя 3 -- которые церкви применяют в B1 Admin. Вы можете опубликовать план для любой учебной программы в библиотеке. Планы хранятся в базе данных и не привязаны к календарному году.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Иметь права администратора для Lessons.church
- Иметь по крайней мере одну [программу](./managing-programs.md) с опубликованными уроками

</div>

## Создание плана

1. Откройте **Admin → Year Plans**.
2. Нажмите **Add**.
3. Введите имя (например, "Elementary 2026–27" или "High Voltage Year 1") и дополнительный slug.
4. При необходимости установите **default venue preference** -- названия мест, разделенные запятыми, используемые, когда неделя не указывает место.
5. Отметьте **Publish**, когда церкви должны видеть план в B1 Admin. Оставьте его отключенным для черновика.
6. Добавьте недели из любой учебной программы: выберите **source**, затем программу, исследование, урок и место. Нажмите **Add**. Один план может смешивать программы, если вы хотите. Используйте стрелки для переупорядочивания.
7. Сохраните.
