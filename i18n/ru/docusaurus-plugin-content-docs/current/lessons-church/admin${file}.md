# managing-year-plans

Документация по управлению managing-year-plans в LessonsChurch.

## Обзор

Этот раздел охватывает управление managing-year-plans.

## Основные функции

- Создание и редактирование
- Организация по категориям
- Публикация контента
- Отслеживание использования

## Начало работы

1. Перейдите в раздел Admin
2. Выберите managing-year-plans
3. Начните создание контента

## Лучшие практики

- Используйте описательные названия
- Организуйте по сериям
- Добавляйте метаданные для поиска
- Протестируйте перед публикацией
