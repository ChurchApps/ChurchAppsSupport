# Настройка

<div class="article-intro">

Lessons.church предоставляет библиотеку готовых материалов для уроков, но каждая церковь уникальна. Функции настройки позволяют адаптировать содержимое уроков под конкретные классы, стиль преподавания и возрастные группы, чтобы волонтёры видели только то, что актуально для них.

</div>

## Зачем настраивать?

Материалы уроков на Lessons.church задуманы как гибкие. Один урок может включать разделы для нескольких возрастных групп, необязательные занятия или роли, которые подходят не всем классам. Вместо того чтобы заставлять волонтёров мысленно пропускать неподходящие части, вы можете настроить урок так, чтобы они видели только то, что относится к их классу.

Например, в уроке может быть творческое задание, которое отлично подходит дошкольникам, но не годится для пятого класса. С помощью настройки вы можете скрыть этот раздел для старшей группы, сохранив его для младшей.

## Что можно настраивать

- **Удаление разделов** — удалите целые разделы урока, которые не подходят для конкретного класса или возрастной группы.
- **Удаление ролей или действий** — уберите отдельные роли или действия внутри раздела, если они не нужны.
- **Изменение порядка содержимого** — переставьте разделы и действия в том порядке, который лучше подходит вашему классу.

## Для одного класса или для всех

При каждом изменении вы выбираете, насколько широко оно будет применяться:

- **Этот класс** — изменение затрагивает только текущий класс. Остальные классы видят исходное содержимое.
- **Все классы** — изменение применяется ко всем классам вашей церкви.

Такая гибкость позволяет создать разные варианты одного и того же урока для разных возрастных групп или сразу внести изменение, которое будет действовать везде.

:::tip
Если вы только начинаете работать с настройкой, сначала попробуйте её на одном классе, прежде чем применять изменения ко всем классам.
:::
