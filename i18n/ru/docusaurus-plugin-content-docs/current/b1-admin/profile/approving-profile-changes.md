# Одобрение изменений профиля

<div class="article-intro">

Когда члены запрашивают изменения в своем профиле, администраторы могут просматривать и утверждать эти изменения перед их применением.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужно разрешение на управление профилями
- В ваших параметрах должна быть включена функция утверждения изменений профиля

</div>

## Просмотр запросов на изменение

1. Перейдите в раздел **Profile** в B1 Admin
2. Нажмите на вкладку **Profile Change Requests**
3. Вы видите список ожидающих запросов на изменение

## Информация о запросе

Для каждого запроса вы видите:

- **Person Name** — кто запросил изменение
- **Change Type** — какой тип информации меняется
- **Old Value** — текущее значение
- **New Value** — запрошенное новое значение
- **Date Requested** — когда была подана заявка

## Одобрение изменения

Чтобы одобрить изменение:

1. На запросе нажмите **Approve**
2. Изменение применяется к профилю человека
3. Человек получает уведомление об одобрении

## Отклонение изменения

Чтобы отклонить изменение:

1. На запросе нажмите **Decline**
2. Опционально добавьте сообщение с причиной отказа
3. Нажмите **Send**
4. Человек получает уведомление об отклонении

## Типы изменений

Члены могут запросить изменения для:

- **Contact Information** — имя, телефон, адрес электронной почты, адрес
- **Demographics** — пол, дата рождения, семейное положение
- **Photo** — их фото профиля

## Массовое одобрение

Вы можете одобрить несколько запросов:

1. Выберите флажки рядом с запросами
2. Нажмите **Approve Selected**
3. Все выбранные изменения применяются

## Просмотр утвержденных изменений

На этой же странице вы можете видеть историю утвержденных и отклоненных изменений.
