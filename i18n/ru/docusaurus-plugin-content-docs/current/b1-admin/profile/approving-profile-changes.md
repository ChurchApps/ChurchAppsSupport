# Одобрение изменений профиля

<div class="article-intro">

Когда ваша церковь требует одобрения администратором для обновления профиля, участники отправляют свои изменения через мобильное приложение B1, и эти запросы появляются как задачи в B1 Admin. Это руководство объясняет, как их рассмотреть и одобрить.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вы должны быть членом группы, указанной как **Группа утверждения каталога** в **Мобильное приложение &rarr; Портал участника**
- Если группа утверждения не настроена, изменения профиля применяются немедленно без рассмотрения

</div>

## Где найти ожидающие запросы

Когда участник отправляет изменение профиля, оно появляется как задача, назначенная вашей группе утверждения. Вы можете найти его в двух местах:

**На панели управления (ваша домашняя страница):**
1. Войдите в B1 Admin — панель управления загружается автоматически.
2. В разделе **Задачи** на правой стороне нажмите вкладку **Назначено моим группам**.
3. Все ожидающие запросы на изменение профиля будут перечислены там.

**Из Служение &rarr; Мои дела:**
1. В верхней навигации нажмите **Служение**.
2. Нажмите **Мои дела**.
3. Нажмите вкладку **Назначено моим группам** в разделе "Задачи".

## Рассмотрение и одобрение запроса

1. Нажмите на задачу **Обновление профиля**, чтобы открыть ее.
2. В разделе **Запрошенные изменения** вы увидите каждое поле, которое участник хочет обновить, вместе с новым значением, которое он отправил.
3. Рассмотрите изменения.
4. Нажмите **Применить**, чтобы одобрить и сохранить изменения в их профиле.

Задача автоматически закроется после применения изменений.

## Настройка группы утверждения

Если ваша церковь хочет, чтобы изменения профиля требовали одобрения, сначала должна быть настроена группа утверждения каталога.

1. В верхней навигации нажмите **Мобильное приложение**.
2. Нажмите **Портал участника** (страница "Параметры портала").
3. В разделе **Группа утверждения каталога** выберите группу, члены которой должны рассматривать запросы на изменение профиля.
4. Нажмите **Сохранить**.

Любой член этой группы будет видеть входящие запросы на изменение профиля в разделе **Назначено моим группам** на своей панели управления.

Та же группа утверждения каталога также рассматривает **запросы на удаление учетной записи** — см. раздел [Рассмотрение запросов на удаление учетной записи](./account-deletion.md).

:::tip
Убедитесь, что ваши одобряющие лица действительно являются членами настроенной группы — только члены группы будут видеть запросы.
:::
