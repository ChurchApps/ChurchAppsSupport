# Утверждение изменений профиля

<div class="article-intro">

Когда ваша церковь требует одобрения администратора для обновлений профиля, члены отправляют свои изменения через приложение B1 Mobile и эти запросы появляются как задачи в B1 Admin. Это руководство объясняет, как просмотреть и одобрить их.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вы должны быть членом группы, обозначенной как **Directory Approval Group** в **Mobile &rarr; B1 Mobile**
- Если группа одобрений не была настроена, изменения профиля применяются немедленно без рассмотрения

</div>

## Где найти ожидающие запросы

Когда член отправляет изменение профиля, он появляется как задача, назначенная вашей группе одобрений. Вы можете найти его в двух местах:

**От панели управления:**
1. Войдите в B1 Admin -- Dashboard загружается автоматически.
2. В разделе **Tasks** на правой стороне нажмите вкладку **Assigned to My Groups**.
3. Любые ожидающие запросы изменения профиля будут перечислены там.

**От Serving &rarr; My Work:**
1. В верхней навигации нажмите **Serving**.
2. Нажмите **My Work**.
3. Нажмите вкладку **Assigned to My Groups** под Tasks.

## Рассмотрение и утверждение запроса

1. Нажмите задачу **Profile Update**, чтобы открыть ее.
2. Под **Requested Changes**, вы увидите каждое поле, которое член хочет обновить, вместе с новым значением, которое они отправили.
3. Пересмотрите изменения.
4. Нажмите **Apply**, чтобы одобрить и сохранить изменения в его профиль.

Задача закроется автоматически, когда изменения будут применены.

## Установка группы одобрений

Если ваша церковь хочет, чтобы изменения профиля требовали одобрения, вначале должна быть настроена группа Directory Approval.

1. В верхней навигации нажмите **Mobile**.
2. Нажмите **B1 Mobile**.
3. Под **Directory Approval Group**, выберите группу, члены которой должны рассмотреть запросы изменения профиля.
4. Нажмите **Save**.

Любой член этой группы будет видеть входящие запросы изменения профиля под **Assigned to My Groups** на их панели управления.

:::tip
Убедитесь, что ваши одобряющие лица фактически являются членами настроенной группы -- только члены группы увидят запросы.
:::
