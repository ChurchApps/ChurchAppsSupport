# Одобрение изменений профиля

<div class="article-intro">

Если ваша церковь требует одобрения администратора для обновлений профиля, участники отправляют изменения через приложение B1, и эти запросы появляются в B1 Admin как задачи. В этом руководстве объясняется, как их просматривать и одобрять.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Вы должны быть участником группы, назначенной как **Группа одобрения каталога** в разделе **Мобильное приложение &rarr; Портал участников**
- Если группа одобрения не настроена, изменения профиля применяются сразу, без проверки

</div>

## Где найти ожидающие запросы

Когда участник отправляет изменение профиля, оно появляется как задача, назначенная вашей группе одобрения. Найти её можно в двух местах:

**С панели управления (домашней страницы):**
1. Войдите в B1 Admin -- панель управления загрузится автоматически.
2. В разделе **Мои задачи** нажмите **Все задачи**. (В разделе «Мои задачи» перечисляются только открытые задачи, назначенные лично вам.)
3. Перейдите на вкладку **Назначено моим группам**. Все ожидающие запросы на изменение профиля будут перечислены там.

**Из раздела Служение &rarr; Моя работа:**
1. Откройте [меню быстрого перехода](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу B1 Admin) и разверните пункт **Служение**.
2. Нажмите **Моя работа**.
3. Нажмите вкладку **Назначено моим группам** в разделе «Задачи».

## Просмотр и одобрение запроса

1. Нажмите на задачу **Изменение профиля**, чтобы открыть её.
2. В разделе **Запрошенные изменения** вы увидите каждое поле, которое участник хочет обновить, и новое значение, которое он указал.
3. Просмотрите изменения.
4. Нажмите **Применить**, чтобы одобрить и сохранить изменения в профиле участника.

Запрос на добавление члена семьи показывает обращение, имя, роль в домохозяйстве и мобильный телефон нового человека в одной строке (например, *Mr John Smith · Child · 555-0100*). При применении этого запроса в домохозяйстве участника создаётся новый человек с этими данными.

Задача закроется автоматически после применения изменений.

## Настройка группы одобрения

Если ваша церковь хочет, чтобы изменения профиля требовали одобрения, сначала нужно настроить группу одобрения каталога.

1. Откройте меню быстрого перехода и разверните пункт **Мобильное приложение**.
2. Нажмите **Портал участников** (страница «Настройки портала»).
3. В разделе **Группа одобрения каталога** выберите группу, участники которой должны просматривать запросы на изменение профиля.
4. Нажмите **Сохранить**.

Любой участник этой группы будет видеть входящие запросы на изменение профиля в разделе **Назначено моим группам** на своей панели управления.

Та же группа одобрения каталога рассматривает и **запросы на удаление аккаунта** -- см. [Рассмотрение запросов на удаление аккаунта](./account-deletion.md).

:::tip
Убедитесь, что проверяющие действительно являются участниками настроенной группы -- запросы видят только участники группы.
:::
