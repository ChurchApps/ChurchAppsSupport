# Согласование изменений профиля {#approving-profile-changes}

<div class="article-intro">

Если ваша церковь требует согласования администратором для обновлений профиля, участники отправляют изменения через приложение B1, а запросы появляются в B1 Admin как задачи. В этом руководстве объясняется, как их проверять и согласовывать.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Вы должны состоять в группе, назначенной как **Directory Approval Group** в разделе **Mobile &rarr; Member portal**
- Если группа согласования не настроена, изменения профиля применяются сразу, без проверки

</div>

## Где найти ожидающие запросы {#where-to-find-pending-requests}

Когда участник отправляет изменение профиля, оно появляется как задача, назначенная вашей группе согласования. Найти её можно в двух местах:

**С Dashboard (главной страницы):**
1. Войдите в B1 Admin — Dashboard загружается автоматически.
2. В разделе **My tasks** нажмите **All tasks**. (В My tasks показаны только открытые задачи, назначенные лично вам.)
3. Откройте вкладку **Assigned to My Groups**. Все ожидающие запросы на изменение профиля будут там.

**Из Serving &rarr; My Work:**
1. Откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в левом верхнем углу B1 Admin) и раскройте **Serving**.
2. Нажмите **My Work**.
3. Откройте вкладку **Assigned to My Groups** в разделе Tasks.

## Проверка и согласование запроса {#reviewing-and-approving-a-request}

1. Нажмите на задачу **Profile Update**, чтобы открыть её.
2. В разделе **Requested Changes** вы увидите каждое поле, которое участник хочет обновить, и новое значение, которое он указал.
3. Проверьте изменения.
4. Нажмите **Apply**, чтобы согласовать и сохранить изменения в его профиле.

Запрос на добавление члена семьи показывает обращение, имя, роль в домохозяйстве, номер мобильного телефона и адрес электронной почты нового человека в одной строке (например, *Mr John Smith · Child · 555-0100 · john@example.com*), а рядом с ней — его фото, если участник его добавил. При применении запроса в домохозяйстве участника создаётся этот человек с указанными данными и фото.

Задача закроется автоматически, как только изменения будут применены.

## Настройка группы согласования {#setting-up-the-approval-group}

Если ваша церковь хочет, чтобы изменения профиля требовали согласования, сначала нужно настроить Directory Approval Group.

1. Откройте меню Jump и раскройте **Mobile**.
2. Нажмите **Member portal** (страница «Portal settings»).
3. В разделе **Directory Approval Group** выберите группу, участники которой должны проверять запросы на изменение профиля.
4. Нажмите **Save**.

Любой участник этой группы будет видеть входящие запросы на изменение профиля в разделе **Assigned to My Groups** на своём Dashboard.

Та же Directory Approval Group также проверяет **запросы на удаление учётной записи** — см. [Проверка запросов на удаление учётной записи](./account-deletion.md).

:::tip
Убедитесь, что согласующие действительно состоят в настроенной группе: запросы видят только участники группы.
:::
