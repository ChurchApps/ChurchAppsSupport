# Одобрение изменений профиля

<div class="article-intro">

Когда ваша церковь требует одобрения администратора для обновления профиля, члены отправляют свои изменения через приложение B1 Mobile, и эти запросы появляются как задачи в B1 Admin. Это руководство объясняет, как просмотреть и одобрить их.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вы должны быть членом группы, обозначенной как **Группа утверждения справочника** в **Mobile → Портал членов**
- Если группа утверждения не настроена, изменения профиля применяются немедленно без проверки

</div>

## Где найти ожидающие запросы

Когда член отправляет изменение профиля, оно появляется как задача, назначенная вашей группе утверждения. Вы можете найти его в двух местах:

**С панели управления (ваша домашняя страница):**
1. Войдите в B1 Admin - панель управления загружается автоматически.
2. В разделе **Задачи** с правой стороны щелкните вкладку **Назначено моим группам**.
3. Любые запросы на изменение профиля в ожидании будут перечислены там.

**Из Serving → My Work:**
1. Откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу B1 Admin) и разверните **Serving**.
2. Щелкните **My Work**.
3. Щелкните вкладку **Назначено моим группам** в разделе "Задачи".

## Проверка и одобрение запроса

1. Щелкните на задачу **Обновление профиля**, чтобы открыть ее.
2. Под **Запрошенные изменения** вы увидите каждое поле, которое член хочет обновить, вместе с новым значением, которое он отправил.
3. Проверьте изменения.
4. Щелкните **Применить**, чтобы одобрить и сохранить изменения в его профиль.

Задача закроется автоматически после применения изменений.

## Настройка группы утверждения

Если ваша церковь хочет, чтобы изменения профиля требовали одобрения, сначала должна быть настроена группа "Утверждение справочника".

1. Откройте меню Jump и разверните **Mobile**.
2. Щелкните **Портал членов** (страница "Параметры портала").
3. В разделе **Группа утверждения справочника** выберите группу, членов которой должны проверять запросы на изменение профиля.
4. Щелкните **Сохранить**.

Любой член этой группы будет видеть входящие запросы на изменение профиля под **Назначено моим группам** на своей панели управления.

Та же группа утверждения справочника также рассматривает **запросы на удаление учетной записи** - см. [Проверка запросов на удаление учетной записи](./account-deletion.md).

:::tip
Убедитесь, что ваши утверждающие лица действительно являются членами настроенной группы - только члены группы будут видеть запросы.
:::
