# Управление профилем

<div class="article-intro">

Страница Profile позволяет редактировать настройки вашей личной учётной записи. Ваш профиль общий для всех продуктов ChurchApps, поэтому любые изменения, сделанные здесь, отражаются везде, где вы используете ChurchApps.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вы должны войти в свою учётную запись ChurchApps
- Приготовьте новый адрес электронной почты или пароль, если собираетесь их менять

</div>

## Сведения профиля

На странице Profile слева показаны ваше имя и адрес электронной почты, а под ними — кнопка **Edit**. Нажмите **Edit**, чтобы открыть форму **Edit Account» с основными данными учётной записи:

1. **Email** — адрес электронной почты для входа и получения уведомлений.
2. **First Name** и **Last Name** — ваше отображаемое имя в ChurchApps.
3. **Password** — обновление пароля учётной записи.

Чтобы обновить данные, измените поля и нажмите кнопку **Save Changes**. Нажмите **Cancel** (или ссылку **Back to** с вашим именем), чтобы вернуться к профилю без сохранения.

## Смена пароля

1. На странице Profile нажмите **Edit**.
2. Введите **Current password**.
3. Введите новый пароль в поле **New password**.
4. Повторите его в поле **Verify password**.
5. Нажмите **Save Changes**.

:::info
Пароль должен содержать не менее 8 символов. Убедитесь, что поля пароля и подтверждения совпадают полностью. Чтобы сменить пароль, нужно подтвердить текущий. Если вы его не помните, используйте ссылку **Forgot Password** на странице входа.
:::

## Связанные аккаунты

В разделе **Linked Accounts** показаны внешние сервисы, подключённые к вашей учётной записи ChurchApps. Здесь вы можете посмотреть, какие аккаунты связаны, и управлять этими подключениями.

## Двухфакторный вход

Двухфакторный вход добавляет второй шаг при входе: после пароля (или входа через Google, Microsoft либо ссылку, отправленную на email) нужно ввести 6-значный код из приложения-аутентификатора на телефоне, например Google Authenticator, Microsoft Authenticator, 1Password или Authy. Он необязателен и по умолчанию выключен. Когда он включён, действует для каждого входа в ChurchApps, который использует вашу учётную запись: B1 Admin, сайт и приложение вашей церкви B1.church, B1 Church Checkin, Lessons.church, FreePlay и остальные.

### Включение

1. На странице Profile найдите раздел **Two-Factor Sign-In** и нажмите **Turn on**.
2. Отсканируйте QR-код приложением-аутентификатором. Если отсканировать не получается, введите в приложение ключ, показанный под надписью **Can't scan? Enter this key:**.
3. Введите **6-digit code**, который показывает приложение, и нажмите **Verify**.
4. B1 Admin покажет десять **backup codes** (резервных кодов). Каждый из них позволяет войти один раз, если вы потеряете телефон. Нажмите **Copy** или запишите их, сохраните в надёжном месте и нажмите **I saved them**.

:::warning
Резервные коды показываются только один раз. Если вы потеряете телефон и резервных кодов не останется, администратор сервера ChurchApps должен будет отключить для вас двухфакторный вход после подтверждения вашей личности.
:::

Когда двухфакторный вход включён, в разделе отображается **On» и количество оставшихся резервных кодов.

### Вход с кодом

После ввода пароля экран входа запросит код. Введите 6-значный код из приложения-аутентификатора или один из резервных кодов и отправьте его. Каждый резервный код работает только один раз. Если код неверный, вы увидите сообщение «That code didn't work. Please try again.» После слишком большого числа неверных кодов вход в вашу учётную запись приостанавливается на некоторое время.

Если вы остаётесь в системе на устройстве, с которого уже входили, код повторно не запрашивается; он появляется только при новом входе.

### Отключение

1. В разделе **Two-Factor Sign-In** нажмите **Turn off**.
2. Введите текущий код из приложения-аутентификатора или резервный код.
3. Нажмите **Verify**.

:::info
Двухфакторный вход нельзя настроить на демо-аккаунтах, поэтому раздел там скрыт.
:::

## Настройки темы

B1 Admin позволяет выбрать цветовую тему и светлый или тёмный режим отображения:

1. Нажмите на фото профиля в правом верхнем углу B1 Admin, чтобы открыть меню пользователя.
2. В разделе **Theme Preferences** выберите тему:
   - **Default** — текущий вид B1 Admin: панели с рамками на чистом фоне. Новые пользователи видят эту тему, пока не выберут другую.
   - **Classic** — прежний вид B1 Admin с цветной полосой страницы, карточками с тенями и серым фоном. Если вы пользовались B1 Admin на этом устройстве до появления нового вида и ни разу не выбирали тему, вы останетесь на Classic.
   - **Custom** — вид Default, построенный на основном цвете вашей церкви. Он использует основной цвет для светлого режима из **Mobile > App Theme** или основной цвет вашего сайта, если цвет приложения не задан, так что B1 Admin соответствует вашему приложению для участников.
3. Под темами выберите **Light Mode** или **Dark Mode**.
4. Интерфейс сразу обновится в соответствии с вашим выбором.

Ваш выбор запоминается для этого устройства и браузера.

## Удаление учётной записи

В разделе **Account Deletion** на странице Profile есть возможность удалить учётную запись.

- Если в вашей церкви **не** настроена группа одобрения каталога (Directory Approval Group), нажатие **Delete my account** немедленно удаляет вашу учётную запись и связанные данные, и это нельзя отменить.
- Если в вашей церкви **настроена** группа одобрения каталога, ваш запрос отправляется этой группе на рассмотрение. Кнопка недоступна, пока запрос ожидает решения, и вы получите уведомление, когда церковь его одобрит или отклонит. Что будет дальше, см. в разделе [Рассмотрение запросов на удаление учётной записи](./account-deletion.md).

:::warning
Удаление учётной записи — будь то немедленное или одобренное вашей церковью — необратимо.
:::

:::info
Если вы **Domain Admin**, перед удалением своей учётной записи передайте административные обязанности другому пользователю. Подробности о управлении административными ролями см. в [Roles & Permissions](../settings/roles-permissions.md).
:::

:::info
В демо-режиме редактирование профиля отключено. Если вы используете демо-аккаунт, вы не сможете вносить изменения в настройки профиля.
:::
