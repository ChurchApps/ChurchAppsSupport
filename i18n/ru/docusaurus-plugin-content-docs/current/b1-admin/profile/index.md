# Профиль

<div class="article-intro">

Раздел Profile позволяет управлять настройками вашей личной учетной записи в ChurchApps. Ваш профиль общий для всех инструментов ChurchApps, поэтому изменения, которые вы вносите здесь, применяются везде -- от B1 Admin до приложения B1 Mobile.

</div>

## Что вы можете делать

В разделе Profile вы можете:

- **Обновить имя и адрес электронной почты** -- Поддерживайте контактные данные в актуальном состоянии.
- **Сменить пароль** -- Установите новый пароль для вашей учетной записи.
- **Переключать тему** -- Переключайтесь между светлым и темным режимом через пользовательское меню (нажмите на ваше фото профиля в правом верхнем углу).
- **Управлять подключенными устройствами** -- Просматривайте и контролируйте, какие устройства ChurchAppsPlayer привязаны к вашей учетной записи.
- **Просматривать связанные учетные записи** -- Смотрите и управляйте внешними сервисами, подключенными к вашей учетной записи ChurchApps.
- **Одобрять запросы на изменение профиля** -- Рассматривайте и применяйте обновления, которые отправили участники церкви.

## Подразделы профиля

В разделе Profile есть следующие страницы:

1. **[Управление вашим профилем](./managing-profile.md)** -- Редактирование личных данных, смена пароля, управление связанными учетными записями, настройка темы и удаление учетной записи.
2. **[Одобрение изменений профиля](./approving-profile-changes.md)** -- Рассмотрение и одобрение запросов на изменение профиля, отправленных участниками через B1 Mobile.
3. **[Управление устройствами](./devices.md)** -- Просмотр, добавление и управление устройствами ChurchAppsPlayer, связанными с вашей учетной записью.

:::tip
Всегда поддерживайте адрес электронной почты в актуальном состоянии. Он используется для восстановления доступа к учетной записи и для важных уведомлений от вашей церкви.
:::
