# Профиль

<div class="article-intro">

Раздел «Профиль» позволяет управлять личными настройками учётной записи в ChurchApps. Чтобы открыть его, нажмите на фото профиля в правом верхнем углу B1 Admin и выберите **Edit Profile**. Ваш профиль общий для всех инструментов ChurchApps, поэтому изменения, сделанные здесь, действуют везде — от B1 Admin до приложения B1.

</div>

## Что вы можете делать {#what-you-can-do}

В разделе «Профиль» вы можете:

- **Обновить имя и электронную почту** -- Поддерживайте контактные данные в актуальном состоянии.
- **Сменить пароль** -- Задайте новый пароль для вашей учётной записи.
- **Включить двухфакторный вход** -- Требовать код из приложения-аутентификатора при входе. См. [Двухфакторный вход](./managing-profile.md#two-factor-sign-in).
- **Переключать темы** -- Переключайтесь между светлым и тёмным режимом в пользовательском меню (нажмите на фото профиля в правом верхнем углу).
- **Управлять подключёнными устройствами** -- Просматривайте, сопрягайте, переименовывайте и удаляйте экраны ChurchAppsPlayer и FreePlay, привязанные к вашей учётной записи.
- **Просматривать связанные учётные записи** -- Смотрите и управляйте внешними сервисами, подключёнными к вашей учётной записи ChurchApps.
- **Согласовывать запросы на изменение профиля** -- Проверяйте и применяйте обновления, которые отправили участники.
- **Проверять запросы на удаление учётной записи** -- Одобряйте или отклоняйте запросы участников на удаление их учётных записей.

## Разделы профиля {#profile-sub-sections}

В разделе «Профиль» есть следующие страницы:

1. **[Управление вашим профилем](./managing-profile.md)** -- Редактирование личных данных, смена пароля, управление связанными учётными записями, включение двухфакторного входа, настройка темы и удаление учётной записи.
2. **[Согласование изменений профиля](./approving-profile-changes.md)** -- Проверка и согласование запросов на обновление профиля, которые участники отправили через приложение B1.
3. **[Проверка запросов на удаление учётной записи](./account-deletion.md)** -- Одобрение или отклонение запросов участников на удаление их учётных записей.
4. **[Управление устройствами](./devices.md)** -- Просмотр, добавление, переименование и удаление экранов ChurchAppsPlayer и FreePlay, сопряжённых с вашей учётной записью.

:::tip
Следите за тем, чтобы адрес электронной почты был актуальным. Он используется для восстановления доступа и для важных уведомлений от вашей церкви.
:::
