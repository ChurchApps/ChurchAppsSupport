# Профиль

<div class="article-intro">

Раздел Profile позволяет управлять настройками вашей личной учётной записи в ChurchApps. Ваш профиль общий для всех инструментов ChurchApps, поэтому изменения, сделанные здесь, действуют везде — от B1 Admin до мобильного приложения B1.

</div>

## Что можно делать

В разделе Profile вы можете:

- **Обновить имя и email** — поддерживайте контактные данные в актуальном состоянии.
- **Сменить пароль** — задайте новый пароль для вашей учётной записи.
- **Включить двухфакторный вход** — требовать код из приложения-аутентификатора при входе. См. [Двухфакторный вход](./managing-profile.md#two-factor-sign-in).
- **Переключать темы** — переключайтесь между светлым и тёмным режимом в меню пользователя (нажмите на фото профиля в правом верхнем углу).
- **Управлять подключёнными устройствами** — просматривайте и контролируйте, какие устройства ChurchAppsPlayer привязаны к вашей учётной записи.
- **Просматривать связанные аккаунты** — смотрите и управляйте внешними сервисами, подключёнными к вашей учётной записи ChurchApps.
- **Одобрять запросы на изменение профиля** — рассматривайте и применяйте обновления, которые отправили участники.

## Разделы профиля

В разделе Profile есть следующие страницы:

1. **[Управление профилем](./managing-profile.md)** — редактирование личных данных, смена пароля, управление связанными аккаунтами, включение двухфакторного входа, настройка тем оформления и удаление учётной записи.
2. **[Одобрение изменений профиля](./approving-profile-changes.md)** — просмотр и одобрение запросов на обновление профилей, отправленных участниками через B1 Mobile.
3. **[Управление устройствами](./devices.md)** — просмотр, добавление и управление устройствами ChurchAppsPlayer, сопряжёнными с вашей учётной записью.

:::tip
Поддерживайте адрес электронной почты в актуальном состоянии. Он используется для восстановления доступа к учётной записи и для важных уведомлений от вашей церкви.
:::
