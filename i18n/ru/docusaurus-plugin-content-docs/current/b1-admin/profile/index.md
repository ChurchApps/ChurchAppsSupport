# Профиль

<div class="article-intro">

Раздел «Профиль» позволяет управлять личными настройками учётной записи в ChurchApps. Ваш профиль общий для всех инструментов ChurchApps, поэтому изменения, сделанные здесь, применяются везде -- от B1 Admin до B1 App.

</div>

## Что можно делать

В разделе «Профиль» вы можете:

- **Обновлять имя и адрес электронной почты** -- поддерживайте контактные данные в актуальном состоянии.
- **Менять пароль** -- задайте новый пароль для своей учётной записи.
- **Включать двухфакторный вход** -- требуйте ввод кода из приложения-аутентификатора при входе в систему. См. [Двухфакторный вход](./managing-profile.md#two-factor-sign-in).
- **Переключать тему оформления** -- переключайтесь между светлой и тёмной темой через меню пользователя (нажмите на фото профиля в правом верхнем углу).
- **Управлять подключёнными устройствами** -- просматривайте и контролируйте, какие устройства ChurchAppsPlayer привязаны к вашей учётной записи.
- **Просматривать связанные аккаунты** -- смотрите и управляйте внешними сервисами, подключёнными к вашей учётной записи ChurchApps.
- **Подтверждать запросы на изменение профиля** -- проверяйте и применяйте обновления, отправленные участниками.

## Разделы профиля

Раздел «Профиль» содержит следующие страницы:

1. **[Управление профилем](./managing-profile.md)** -- редактирование личных данных, смена пароля, управление связанными аккаунтами, включение двухфакторного входа, настройка темы оформления и удаление учётной записи.
2. **[Подтверждение изменений профиля](./approving-profile-changes.md)** -- проверка и подтверждение запросов на обновление профиля, отправленных участниками через B1 App.
3. **[Управление устройствами](./devices.md)** -- просмотр, добавление и управление устройствами ChurchAppsPlayer, привязанными к вашей учётной записи.

:::tip
Следите за тем, чтобы адрес электронной почты был актуальным. Он используется для восстановления доступа к учётной записи и для важных уведомлений от вашей церкви.
:::
