# Профиль

<div class="article-intro">

Раздел «Профиль» позволяет управлять настройками вашей личной учётной записи в ChurchApps. Ваш профиль общий для всех инструментов ChurchApps, поэтому изменения, которые вы вносите здесь, применяются везде -- от B1 Admin до приложения B1 Mobile.

</div>

## Что вы можете делать

В разделе «Профиль» вы можете:

- **Обновить имя и email** -- поддерживать контактные данные в актуальном состоянии.
- **Сменить пароль** -- задать новый пароль для учётной записи.
- **Включить двухфакторный вход** -- требовать код из приложения-аутентификатора при входе. См. [Двухфакторный вход](./managing-profile.md#two-factor-sign-in).
- **Переключать темы** -- переключаться между светлым и тёмным режимом в меню пользователя (нажмите на фото профиля в правом верхнем углу).
- **Управлять подключёнными устройствами** -- просматривать и контролировать, какие устройства ChurchAppsPlayer привязаны к вашей учётной записи.
- **Просматривать связанные учётные записи** -- видеть и управлять внешними сервисами, подключёнными к вашей учётной записи ChurchApps.
- **Одобрять запросы на изменение профиля** -- просматривать и применять обновления, отправленные участниками.

## Подразделы профиля

В разделе «Профиль» есть следующие страницы:

1. **[Управление профилем](./managing-profile.md)** -- редактирование личных данных, смена пароля, управление связанными учётными записями, включение двухфакторного входа, настройка темы оформления и удаление учётной записи.
2. **[Одобрение изменений профиля](./approving-profile-changes.md)** -- просмотр и одобрение запросов на обновление профиля, отправленных участниками через B1 Mobile.
3. **[Управление устройствами](./devices.md)** -- просмотр, добавление и управление устройствами ChurchAppsPlayer, связанными с вашей учётной записью.

:::tip
Следите за тем, чтобы адрес электронной почты был актуальным. Он используется для восстановления доступа к учётной записи и для важных уведомлений от вашей церкви.
:::
