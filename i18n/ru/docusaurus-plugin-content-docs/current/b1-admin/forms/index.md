# Формы

<div class="article-intro">

Раздел Forms позволяет вам создавать пользовательские формы для регистраций, опросов, сбора данных и многого другого. Нужна ли вам карточка посетителя, регистрация на мероприятие или форма просьбы о молитве, вы можете построить это здесь и поделиться с вашей общиной через публичную ссылку или ваш веб-сайт B1.church.

</div>

## Страница Forms

Когда вы откроете **Forms**, вы увидите эти вкладки:

- **Forms** -- Показывает все ваши активные формы.
- **Archived Forms** -- Показывает формы, которые были архивированы. Вы можете восстановить архивированные формы в любое время. Эта вкладка появляется только после архивирования хотя бы одной формы.

Каждая форма в списке отображает его имя и, если настроено, публичный URL, который вы можете поделиться внешне.

## Что вы можете сделать

На странице Forms вы можете:

- **Добавить форму** -- Нажмите **Add Form** для создания новой пользовательской формы.
- **Отредактировать форму** -- Нажмите на имя формы для ее открытия и изменения вопросов, членов или параметров.
- **Архивировать форму** -- Перемещайте формы, которые вам больше не нужны, на вкладку **Archived Forms**, чтобы сохранить ваш список чистым.
- **Восстановить форму** -- Перейдите на вкладку **Archived Forms** и восстановите любую форму, которую вы хотите снова сделать активной.

## Работа с формой

Нажмите на любое имя формы для ее открытия. Редактор формы имеет до трех вкладок:

- **Questions** -- Постройте структуру формы, добавляя поля разных типов. См. [Creating Forms](./creating-forms.md) для подробной информации.
- **Form Members** -- Контролируйте, кто может получить доступ и управлять формой (только отдельные формы).
- **Form Submissions** -- Просмотрите ответы, которые были отправлены. См. [Managing Submissions](./managing-submissions.md) для подробной информации.

:::tip
Формы с публичным URL-адресом можно поделиться по ссылке, встроить на ваш веб-сайт или включить в письма. Это облегчает сбор информации от людей, которые могут не иметь учетную запись церкви.
:::

:::info
Вы можете контролировать, кто имеет доступ к каждой форме, используя вкладку **Form Members**. Назначьте роли **Admin** или **View Only**, чтобы дать вашей команде правильный уровень доступа.
:::
