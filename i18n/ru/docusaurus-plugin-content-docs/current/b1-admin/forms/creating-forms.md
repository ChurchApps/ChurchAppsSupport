# Создание форм

<div class="article-intro">

Создавайте пользовательские формы, чтобы собирать информацию от вашей общины. Вы можете создавать формы для регистрации на события, опросов, карточек гостей, заявлений о членстве и многого другого. Формы могут быть связаны с людьми в вашей базе или использоваться как отдельные страницы с собственным публичным адресом.

</div>

## Создание новой формы {#creating-a-new-form}

1. Откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу B1 Admin), раскройте **People** и нажмите **Forms**.
2. Нажмите **Add Form**.
3. Введите **name** вашей формы.
4. Выберите тип формы в выпадающем списке **Associate With**:
   - **People** — связывает ответы с [карточками людей](../people/adding-people.md) в вашей базе. Формы People заполняются из карточки человека, поэтому для них нет ссылки для общего доступа.
   - **Stand Alone** — создает независимую форму с собственным публичным адресом, идеально подходящую для внешней регистрации. Только формы Stand Alone предлагают [фото в шапке](#adding-a-header-photo), [QR-код](#sharing-a-form-with-a-qr-code), [связанную группу](#linking-a-form-to-a-group) и **Create a person record from submissions**.
5. Для формы Stand Alone остальные [свойства](#configuring-form-properties) можно заполнить сейчас или позже.
6. Нажмите **Save**, чтобы создать форму.

Новая форма появится в списке. Нажмите на нее, чтобы начать добавлять вопросы.

## Печать пустой формы {#printing-a-blank-form}

Нужна бумажная копия, чтобы раздать — например, карточка гостя у стойки приветствия или форма для человека без доступа в интернет, которую он заполнит от руки? Нажмите **Print** рядом с формой в основном списке Forms, чтобы открыть предпросмотр, затем нажмите **Print**. Пустые поля печатаются с линией или флажком для каждого вопроса, чтобы люди могли заполнить их от руки; обязательные вопросы отмечены звездочкой. Вверху страницы показан логотип вашей общины (**Light Background Logo** из раздела [Сайт > Оформление](../website/appearance.md), если вы его загрузили) с названием общины под ним, а затем название формы. Других параметров печати нет — печатается вся форма целиком или ничего.

## Публикация формы с QR-кодом {#sharing-a-form-with-a-qr-code}

У форм Stand Alone в основном списке Forms рядом есть ссылка **QR Code** (у архивных форм ее нет). Нажмите ее, чтобы открыть QR-код для публичного адреса формы с ссылкой под ним. Нажмите **Download PNG**, чтобы сохранить код как изображение, которое можно напечатать на бюллетенях или показать на слайдах. Любой, кто его отсканирует, откроет форму на своем телефоне.

## Добавление вопросов {#adding-questions}

1. Откройте вашу форму и перейдите на вкладку **Questions**.
2. Нажмите **Add Question**.
3. Выберите **Field Type**:
   - **Textbox** — для коротких текстовых ответов
   - **Whole Number** и **Decimal** — для чисел
   - **Date** — для выбора даты
   - **Yes/No** — для ответа «да» или «нет»
   - **Email** — для адресов электронной почты
   - **Phone Number** — для ввода телефона
   - **Text Area** — для длинных ответов
   - **Multiple Choice** — для выбора одного из нескольких вариантов
   - **Checkbox** — для отметки любого количества вариантов
   - **Payment** — для приема платежей
4. Введите **Title** и при желании **Description** для вопроса. Описание появляется под вопросом, когда люди заполняют форму, поэтому используйте его для подсказок, например «Укажите любые аллергии, о которых нам нужно знать».
5. Заполните дополнительные поля для выбранного типа:
   - Для текстовых, числовых, датных, email и телефонных вопросов необязательный **Placeholder** показывает образец текста внутри пустого поля.
   - Для **Multiple Choice** и **Checkbox** добавьте каждый вариант в разделе **Choices**: введите **Value** (что сохраняется) и **Text** (что видят люди), затем нажмите кнопку добавления. Чтобы убрать вариант, нажмите значок удаления.
   - Для **Payment** выберите **Fund**, на который пойдут деньги, и **Amount**.
6. Отметьте **Require an answer for this question**, если поле обязательно. (У вопросов оплаты этой опции нет.)
7. Нажмите **Save**.
8. Повторите, чтобы добавить другие вопросы.

На вкладке **Questions** перечислен каждый вопрос с его типом и отметкой, обязателен ли он. Нажмите на название вопроса, чтобы его изменить, или нажмите **Delete** в форме вопроса и подтвердите, чтобы удалить его. Используйте стрелки **Move up** и **Move down** в строке, чтобы изменить порядок вопросов.

:::warning
Тип поля **Payment** требует настроенного Stripe. Если вы еще не настроили онлайн-пожертвования, см. [Настройка онлайн-пожертвований](../donations/online-giving-setup.md), прежде чем добавлять поля оплаты. Люди, которые платят в форме без входа в систему, должны отметить проверку **I'm not a robot**, прежде чем карта будет принята.
:::

## Управление участниками формы {#managing-form-members}

У форм Stand Alone есть вкладка **Form Members**, которая дает доступ именно к этой форме.

1. Откройте вашу форму и перейдите на вкладку **Form Members**.
2. В поле **Add Person** найдите человека и нажмите значок добавления рядом с его именем. Новые участники получают роль **View Only**.
3. В столбце **Permission** нажмите нужную роль:
   - **Admin** — может редактировать форму и просматривать все ответы.
   - **View Only** — может просматривать ответы, но не может редактировать форму.
4. Включите **Email Notification** для всех, кто должен получать письмо каждый раз, когда форма отправлена.

Чтобы убрать человека из формы, нажмите **Remove** в его строке и подтвердите.

## Связывание формы с группой {#linking-a-form-to-a-group}

Любую форму Stand Alone можно связать с группой — например, форму прошений о молитве для малой группы или медицинское разрешение для поездки молодежи:

1. Откройте форму и нажмите **Edit Form** (или нажмите **Edit** рядом с формой в списке Forms).
2. В разделе **Linked group** выберите группу или оставьте значение **None**.
3. Нажмите **Save**.

Когда форма связана:

- **Участники группы** видят форму в разделе **Forms** на странице группы на B1.church, пока форма открыта, с кнопкой **Fill out**, которая ее открывает (см. [Сведения о группе](../../b1-church/groups/group-details.md#linked-forms)).
- **Руководители группы** также видят закрытые формы и могут читать ответы на каждый ответ и печатать их (один ответ или **Print all**). Руководители могут только просматривать ответы — редактировать форму они не могут, если они также не являются [участниками формы](#managing-form-members).
- **В B1 Admin** на странице группы есть раздел **Linked forms**, который перечисляет каждую связанную форму со статусом **Open** или **Closed**. Он виден руководителям группы и людям, которые могут администрировать формы. См. [Участники группы](../groups/group-members.md#linked-forms).

Форма закрыта, когда она находится вне периода доступности. Архивные формы на странице группы не показываются.

### Автоматическое добавление отправителей в группу {#automatically-adding-submitters-to-a-group}

Связывание формы с группой само по себе никого в нее не добавляет. Чтобы добавить каждого отправителя в список связанной группы, также отметьте **Create a person record from submissions** в настройках формы и нажмите **Save**.

Каждый раз, когда кто-то отправляет форму, найденный или только что созданный человек добавляется в группу (существующие участники группы пропускаются). Это полезно для таких случаев, как форма записи в лагерь, которая должна автоматически формировать группу-список участников лагеря.

### Отправка письма с продолжением {#sending-a-follow-up-email}

Если отмечено **Create a person record from submissions**, можно также отправлять письмо каждому, кто отправил форму. Заполните **Follow-up Email Subject** и **Follow-up Email Body** в настройках формы. В обоих полях можно использовать метки `{firstName}` и `{churchName}`. Письмо отправляется только тогда, когда заполнены оба поля.

:::info
Письма с продолжением отправляются только после того, как вашей общине одобрят отправку групповых писем, и учитываются в дневном лимите писем вашей общины. См. [Включение групповых писем для вашей общины](../groups/group-members.md#turning-on-group-email-for-your-church).
:::

## Дублирование формы {#duplicating-a-form}

Чтобы использовать форму как основу для новой, нажмите **Duplicate** рядом с формой в списке Forms и подтвердите. Появится сообщение **Form duplicated**, и B1 создаст точную копию формы — включая все вопросы, — которую можно затем переименовать и редактировать независимо.

:::tip
Дублирование удобно для повторяющихся событий, где вопросы регистрации из года в год остаются прежними. Дублируйте форму прошлого года, обновите название и даты — и все готово.
:::

## Настройка свойств формы {#configuring-form-properties}

Название и настройки формы можно обновить в любое время: откройте форму и нажмите **Edit Form** в левой части страницы или нажмите **Edit** рядом с формой в списке Forms. В левой части страницы формы показан тип формы (**People** или **Stand Alone**) и, для форм Stand Alone, то, является ли она **Public** или **Restricted**, а также ее уникальный **public URL**, которым можно поделиться с кем угодно.

Настройки **Edit Form**:

- **Form Name** — название, которое видно в B1 Admin и вверху формы.
- **Description** *(Stand Alone)* — текст над вопросами на публичной странице формы, полезный, чтобы объяснить людям, для чего форма, прежде чем они начнут ее заполнять.
- **Header Photo** *(Stand Alone)* — см. [Добавление фото в шапке](#adding-a-header-photo).
- **Form Access** *(Stand Alone)* — **Public** позволяет заполнить форму любому, у кого есть ссылка; **Restricted** требует, чтобы люди вошли на сайт вашей общины, прежде чем откроют ее.
- **Set Form Availability Timeframe** *(Stand Alone)* — выберите **Yes** и задайте **Availability Start Date** и **Availability End Date**, чтобы принимать ответы только между этими датами. Вне их форма закрыта.
- **Thank You Message** — что люди видят после отправки (см. ниже).
- **Display Mode** — **Standard** показывает все вопросы на одной странице; **Conversational (one question at a time)** проводит по вопросам по одному.
- **Create a person record from submissions** *(Stand Alone)*, **Linked group** и поля письма с продолжением — см. [Связывание формы с группой](#linking-a-form-to-a-group) и [Отправка письма с продолжением](#sending-a-follow-up-email).

Нажмите **Save**, чтобы сохранить изменения. Чтобы навсегда удалить форму, нажмите **Delete** в настройках формы и подтвердите; чтобы оставить ее, но скрыть из списка, вместо этого [архивируйте](./index.md#what-you-can-do) ее.

### Добавление фото в шапке {#adding-a-header-photo}

Формы Stand Alone могут показывать **Header Photo** вверху формы. В настройках формы нажмите на блок для фото или **Add Photo**, затем выберите или загрузите изображение (оно обрезается до формата 16:9). Нажмите **Save**. Фото появляется под названием формы, над описанием, на странице публичного адреса формы и везде, где форма встроена элементом сайта **Form**. Используйте **Change Photo**, чтобы заменить его, или **Remove**, чтобы убрать.

Используйте поле **Thank You Message**, чтобы задать, что люди видят после отправки формы, в том числе на странице публичного адреса. Если оставить поле пустым, они увидят «Thank you for submitting the form!».

:::tip
Формы Stand Alone отлично подходят для регистрации на события. Делитесь публичным адресом по email, в социальных сетях или встраивайте форму прямо на сайт вашей общины.
:::

:::info
Чтобы встроить форму на ваш сайт B1, откройте редактор сайта, добавьте новый раздел и выберите элемент **Form**. Затем выберите нужную форму. Подробности о редактировании сайта см. в разделе [Управление страницами](../website/managing-pages.md).
:::
