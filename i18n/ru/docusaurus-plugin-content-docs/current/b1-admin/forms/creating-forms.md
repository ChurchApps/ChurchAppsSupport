# Создание форм

<div class="article-intro">

Создавайте пользовательские формы для сбора информации от вашей общины. Вы можете создавать формы для регистрации на мероприятия, опросов, карточек посетителей, заявлений о членстве и многого другого. Формы можно связать с людьми в вашей базе данных или использовать как отдельные страницы с собственным публичным URL-адресом.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Для форм **Люди** (связанных с записями людей) сначала нужны [люди в вашей базе данных](../people/adding-people.md).
- Для форм, которые принимают **платежи**, должен быть настроен [Stripe для онлайн-пожертвований](../donations/online-giving-setup.md).

</div>

## Создание новой формы

1. Откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу B1 Admin), разверните **Люди** и нажмите **Формы**.
2. Нажмите **Добавить форму**.
3. Введите **название** для вашей формы.
4. Выберите тип формы из выпадающего списка:
   - **Люди** — связывает отправки с [записями людей](../people/adding-people.md) в вашей базе данных.
   - **Отдельная форма** — создает независимую форму с собственным публичным URL-адресом, идеально подходящую для внешних регистраций.
5. Нажмите **Сохранить**, чтобы создать форму.

Ваша новая форма появится в списке. Нажмите на нее, чтобы начать добавлять вопросы.

## Печать пустой формы {#printing-a-blank-form}

Нужна бумажная копия для раздачи -- например, карточка посетителя для стойки регистрации или форма, которую может заполнить от руки человек без доступа в интернет? Нажмите **Печать** рядом с формой в основном списке форм, чтобы открыть предпросмотр, затем нажмите **Печать**. Пустые поля печатаются с подчеркиванием или флажком для каждого вопроса, чтобы люди могли заполнить их от руки; обязательные вопросы отмечены звездочкой. Вверху страницы отображается логотип вашей церкви (**Логотип для светлого фона** из [Сайт > Внешний вид](../website/appearance.md), если вы его загрузили), под ним название церкви, а затем название формы. Других параметров печати нет -- можно распечатать либо всю форму целиком, либо ничего.

## Добавление вопросов

1. Откройте вашу форму и перейдите на вкладку **Вопросы**.
2. Нажмите **Добавить вопрос**.
3. Выберите **тип поля** из выпадающего списка Provider. Доступны следующие типы:
   - **Текстовое поле** — для коротких текстовых ответов
   - **Дата** — для выбора даты
   - **Эл. почта** — для адресов электронной почты
   - **Номер телефона** — для ввода номера телефона
   - **Множественный выбор** — для выбора из заранее заданных вариантов
   - **Оплата** — для приема платежей
4. Введите **Заголовок** и необязательное **Описание** для вопроса.
5. Установите флажок **Обязательный ответ**, если поле обязательно для заполнения.
6. Нажмите **Сохранить**.
7. Повторите, чтобы добавить другие вопросы.

:::warning
Для типа поля **Оплата** требуется настроенный Stripe. Если вы еще не настроили онлайн-пожертвования, см. [Настройка онлайн-пожертвований](../donations/online-giving-setup.md) перед добавлением платежных полей.
:::

## Управление участниками формы

1. Откройте вашу форму и перейдите на вкладку **Участники формы**.
2. Найдите человека и добавьте его с ролью:
   - **Администратор** — может редактировать форму и просматривать все отправки.
   - **Только просмотр** — может просматривать отправки, но не может редактировать форму.

## Автоматическое добавление отправителей в группу {#automatically-adding-submitters-to-a-group}

Когда включена опция **Создать запись человека из отправок**, вы также можете связать форму с группой, чтобы каждый отправитель автоматически добавлялся в состав этой группы:

1. Откройте **Детали** вашей формы и включите **Создать запись человека из отправок**.
2. В разделе **Добавить отправителей в группу** выберите группу, в которую нужно добавлять отправителей, или оставьте значение **Нет**.
3. Нажмите **Сохранить**.

Каждый раз, когда кто-то отправляет форму, найденный или только что созданный человек добавляется в группу (участники, которые уже состоят в группе, пропускаются). Это полезно, например, для формы записи в лагерь, которая должна автоматически формировать список участников группы лагеря.

### Отправка письма с напоминанием {#sending-a-follow-up-email}

Если включена опция **Создать запись человека из отправок**, вы также можете отправлять письмо каждому, кто отправил форму. Заполните поля **Тема письма с напоминанием** и **Текст письма с напоминанием** в деталях формы. В обоих полях можно использовать токены `{firstName}` и `{churchName}`. Письмо отправляется только тогда, когда заполнены оба поля.

:::info
Письма с напоминанием отправляются только после того, как вашей церкви разрешили отправку групповых писем, и они учитываются в дневном лимите писем вашей церкви. См. [Включение групповой рассылки для вашей церкви](../groups/group-members.md#turning-on-group-email-for-your-church).
:::

## Дублирование формы

Чтобы использовать форму как основу для новой, нажмите **Дублировать** рядом с формой в списке форм и подтвердите действие. B1 создаст точную копию формы, включая все вопросы, которую затем можно переименовать и редактировать независимо.

:::tip
Дублирование удобно для регулярных мероприятий, где вопросы регистрации из года в год остаются прежними. Продублируйте форму прошлого года, обновите название и даты, и все готово.
:::

## Настройка свойств формы

Вы можете в любой момент изменить название и настройки формы. Для форм Stand Alone также доступен уникальный **публичный URL-адрес**, которым можно поделиться с кем угодно, и поле **Описание** -- текст над вопросами на публичной странице формы, полезный для того, чтобы объяснить людям, для чего нужна форма, прежде чем они начнут ее заполнять.

Используйте поле **Сообщение с благодарностью**, чтобы задать текст, который люди увидят после отправки формы, в том числе на странице публичного URL-адреса. Если оставить поле пустым, они увидят сообщение «Thank you for submitting the form!»

:::tip
Формы Stand Alone отлично подходят для регистрации на мероприятия. Поделитесь публичным URL-адресом по электронной почте, в социальных сетях или встройте форму прямо на сайт вашей церкви.
:::

:::info
Чтобы встроить форму на ваш сайт B1, откройте редактор сайта, добавьте новый раздел и выберите элемент **Форма**. Затем выберите форму, которую хотите показать. Подробнее о редактировании сайта см. в [Управление страницами](../website/managing-pages.md).
:::
