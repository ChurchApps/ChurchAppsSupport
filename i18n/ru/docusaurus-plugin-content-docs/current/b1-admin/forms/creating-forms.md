# Создание форм

<div class="article-intro">

Создавайте пользовательские формы, чтобы собирать информацию от вашей паствы. Вы можете создавать формы для регистрации на мероприятия, опросов, визитных карточек, заявок на членство и многого другого. Формы могут быть связаны с людьми в вашей базе данных или использоваться как отдельные страницы со своим публичным URL.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Для форм **People** (связанных с карточками людей) вам сначала нужны [люди в вашей базе данных](../people/adding-people.md).
- Для форм, которые принимают **платежи**, необходимо настроить [Stripe для онлайн-пожертвований](../donations/online-giving-setup.md).

</div>

## Создание новой формы

1. Откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу B1 Admin), разверните **People** и нажмите **Forms**.
2. Нажмите **Add Form**.
3. Введите **название** вашей формы.
4. Выберите тип формы из выпадающего списка:
   - **People** — связывает отправки с [карточками людей](../people/adding-people.md) в вашей базе данных.
   - **Stand Alone** — создает независимую форму со своим публичным URL, идеально подходит для внешних регистраций.
5. Нажмите **Save**, чтобы создать форму.

Ваша новая форма появится в списке. Нажмите на нее, чтобы начать добавлять вопросы.

## Печать пустой формы

Нужна бумажная копия, чтобы раздать? Например, визитная карточка на стойке приветствия или форма для человека без доступа в интернет, которую он заполнит от руки? Нажмите **Print** рядом с формой в общем списке Forms, чтобы открыть предварительный просмотр, затем нажмите **Print**. Пустые поля печатаются с подчеркиванием или флажком для каждого вопроса, чтобы люди могли заполнить их от руки; обязательные вопросы отмечены звездочкой. Вверху страницы отображается логотип вашей церкви (**Light Background Logo** из раздела [Website > Appearance](../website/appearance.md), если вы его загрузили) с названием церкви под ним, затем название формы. Других параметров печати нет — можно распечатать всю форму целиком или ничего.

## Добавление вопросов

1. Откройте форму и перейдите на вкладку **Questions**.
2. Нажмите **Add Question**.
3. Выберите **тип поля** из выпадающего списка Provider. Доступные типы включают:
   - **Textbox** — для коротких текстовых ответов
   - **Date** — для выбора даты
   - **Email** — для адресов электронной почты
   - **Phone Number** — для ввода телефона
   - **Multiple Choice** — для выбора из заранее заданных вариантов
   - **Payment** — для приема платежей
4. Введите **Title** и, при желании, **Description** для вопроса. Описание появляется под вопросом, когда люди заполняют форму, поэтому используйте его для подсказок вроде «Укажите любые аллергии, о которых нам следует знать».
5. Установите флажок **Require an answer**, если поле обязательное.
6. Нажмите **Save**.
7. Повторите, чтобы добавить другие вопросы.

:::warning
Тип поля **Payment** требует настроенного Stripe. Если вы еще не настроили онлайн-пожертвования, см. [Настройка онлайн-пожертвований](../donations/online-giving-setup.md), прежде чем добавлять поля для платежей.
:::

## Управление участниками формы

1. Откройте форму и перейдите на вкладку **Form Members**.
2. Найдите человека и добавьте его с ролью:
   - **Admin** — может редактировать форму и просматривать все отправки.
   - **View Only** — может просматривать отправки, но не может редактировать форму.

## Автоматическое добавление отправителей в группу

Когда включена опция **Create a person record from submissions**, вы также можете связать форму с группой, чтобы каждый отправитель автоматически добавлялся в состав этой группы:

1. Откройте **Details** вашей формы и включите **Create a person record from submissions**.
2. В разделе **Add submitters to a group** выберите группу, в которую нужно добавлять отправителей, или оставьте значение **None**.
3. Нажмите **Save**.

Каждый раз, когда кто-то отправляет форму, найденный или только что созданный человек добавляется в группу (участники, которые уже состоят в группе, пропускаются). Это полезно, например, для формы записи в летний лагерь, которая должна автоматически формировать группу участников лагеря.

### Отправка письма с последующим уведомлением

Когда включено **Create a person record from submissions**, вы также можете отправлять письмо каждому, кто отправил форму. Заполните **Follow-up Email Subject** и **Follow-up Email Body** в сведениях формы. В обоих полях можно использовать метки `{firstName}` и `{churchName}`. Письмо отправляется только тогда, когда заполнены оба поля.

:::info
Письма с последующим уведомлением отправляются только после того, как вашей церкви разрешили отправку групповой электронной почты, и учитываются в вашем дневном лимите писем. См. [Включение групповой электронной почты для вашей церкви](../groups/group-members.md#turning-on-group-email-for-your-church).
:::

## Дублирование формы

Чтобы использовать форму как основу для новой, нажмите **Duplicate** рядом с формой в списке Forms и подтвердите действие. B1 создаст точную копию формы, включая все вопросы, которую затем можно переименовать и редактировать независимо.

:::tip
Дублирование удобно для регулярных мероприятий, где вопросы регистрации из года в год остаются прежними. Продублируйте форму прошлого года, обновите название и даты — и все готово.
:::

## Настройка свойств формы

Вы можете изменить название формы и её настройки в любое время. Для форм Stand Alone вы также увидите уникальный **публичный URL**, которым можно поделиться с любым человеком, а также поле **Description** — текст, который отображается над вопросами на публичной странице формы; он полезен, чтобы объяснить людям, для чего форма, прежде чем они начнут её заполнять.

Используйте поле **Thank You Message**, чтобы задать текст, который люди видят после отправки формы, в том числе на странице публичного URL. Если оставить поле пустым, они увидят «Thank you for submitting the form!»

:::tip
Формы Stand Alone отлично подходят для регистрации на мероприятия. Делитесь публичным URL по электронной почте, в социальных сетях или встраивайте форму прямо на сайт вашей церкви.
:::

:::info
Чтобы встроить форму на ваш сайт B1, откройте редактор сайта, добавьте новую секцию и выберите элемент **Form**. Затем выберите форму, которую хотите отобразить. Подробности о редактировании сайта см. в [Управление страницами](../website/managing-pages.md).
:::
