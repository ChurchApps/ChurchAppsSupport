# Создание форм

<div class="article-intro">

Создавайте пользовательские формы для сбора информации от вашей конгрегации. Вы можете создавать формы для регистрации событий, опросов, карточек посетителей, заявок о членстве и многого другого. Формы могут быть связаны с людьми в вашей базе данных или использоваться как отдельные страницы со своим собственным публичным URL.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Для форм **Люди** (связанные с записями людей) вам нужны [люди в вашей базе данных](../people/adding-people.md) в первую очередь.
- Для форм, которые собирают **платежи**, вы должны иметь [Stripe, настроенный для онлайн-благотворительности](../donations/online-giving-setup.md).

</div>

## Создание новой формы

1. Откройте **Люди** из меню раздела, затем нажмите **Формы** в панели навигации.
2. Нажмите **Добавить форму**.
3. Введите **название** для вашей формы.
4. Выберите тип формы из раскрывающегося списка:
   - **Люди** -- Связывает подачу с [записями людей](../people/adding-people.md) в вашей базе данных.
   - **Отдельно** -- Создаёт независимую форму со своим собственным публичным URL, идеальна для внешних регистраций.
5. Нажмите **Сохранить**, чтобы создать форму.

Ваша новая форма появится в списке. Нажмите на неё, чтобы начать добавлять вопросы.

## Печать пустой формы

Нужна бумажная копия для раздачи -- для карточки посетителя на столе приветствия или формы, которую кто-то без доступа в Интернет может заполнить вручную? Нажмите **значок печати** рядом с формой в основном списке "Формы", чтобы открыть предпросмотр, затем нажмите **Печать**. Пустые поля печатаются с подчёркиванием или флажком для каждого вопроса, поэтому люди могут заполнить их вручную; требуемые вопросы отмечены звёздочкой. Нет других параметров печати -- печатайте всю форму или ничего не печатайте.

## Добавление вопросов

1. Откройте вашу форму и перейдите на вкладку **Вопросы**.
2. Нажмите **Добавить вопрос**.
3. Выберите **тип поля** из раскрывающегося списка "Провайдер". Доступные типы включают:
   - **Текстовое поле** -- Для кратких текстовых ответов
   - **Дата** -- Для выбора даты
   - **Электронная почта** -- Для адресов электронной почты
   - **Номер телефона** -- Для ввода телефона
   - **Множественный выбор** -- Для выбора из предопределённых вариантов
   - **Платёж** -- Для сбора платежей
4. Введите **Название** и дополнительное **Описание** для вопроса.
5. Отметьте **Требовать ответ**, если поле является обязательным.
6. Нажмите **Сохранить**.
7. Повторите для добавления дополнительных вопросов.

:::warning
Тип поля **Платёж** требует, чтобы Stripe был настроен. Если вы ещё не установили онлайн-благотворительность, см. [Установка онлайн-благотворительности](../donations/online-giving-setup.md) перед добавлением полей платежа.
:::

## Управление членами формы

1. Откройте вашу форму и перейдите на вкладку **Члены**.
2. Выполните поиск человека и добавьте его с ролью:
   - **Администратор** -- Может редактировать форму и просматривать все подачи.
   - **Только просмотр** -- Может просматривать подачи, но не может редактировать форму.

## Автоматическое добавление отправителей в группу

Когда включена опция **Создать запись человека из подач**, вы также можете связать форму с группой, чтобы каждый отправитель автоматически добавлялся в список группы:

1. Откройте **Подробности** вашей формы и включите **Создать запись человека из подач**.
2. Под **Добавить отправителей в группу**, выберите группу для добавления отправителей или оставьте её установленной на **Нет**.
3. Нажмите **Сохранить**.

Каждый раз, когда кто-то отправляет форму, совпадающий или вновь созданный человек добавляется в группу (существующие члены группы пропускаются). Это полезно для таких вещей, как форма регистрации в лагере, которая должна автоматически создавать список группы лагеря.

### Отправка ответного письма по электронной почте

Когда включена опция **Создать запись человека из подач**, вы также можете отправить электронное письмо каждому человеку, который отправляет форму. Заполните **Тему ответного письма** и **Текст ответного письма** в подробностях формы. Вы можете использовать токены `{firstName}` и `{churchName}` в обоих. Письмо отправляется только когда оба поля заполнены.

:::info
Ответные письма отправляются только после того, как ваша церковь одобрена для отправки группового письма, и они рассчитываются в соответствии с ежедневным лимитом писем вашей церкви. См. [Включение группового письма для вашей церкви](../groups/group-members.md#turning-on-group-email-for-your-church).
:::

## Дублирование формы

Чтобы переиспользовать форму как отправную точку для новой, нажмите значок **Дублировать** (значок копирования) рядом с формой в списке "Формы". B1 создаёт точную копию формы -- включая все вопросы -- которую вы затем можете переименовать и редактировать независимо.

:::tip
Дублирование удобно для повторяющихся событий, где вопросы регистрации остаются прежними год за годом. Дублируйте форму прошлого года, обновите название и даты, и вы готовы.
:::

## Настройка свойств формы

Вы можете обновить название и параметры вашей формы в любое время. Для отдельных форм вы также увидите уникальный **публичный URL**, который вы можете поделиться с кем-либо, а также поле **Описание** -- текст, отображаемый выше вопросов на странице публичной формы, полезный для того, чтобы сказать людям, для чего предназначена форма, прежде чем они начнут её заполнять.

:::tip
Отдельные формы отлично подходят для регистрации событий. Поделитесь публичным URL по электронной почте, в социальных сетях или встройте форму непосредственно на веб-сайт вашей церкви.
:::

:::info
Чтобы встроить форму на веб-сайт B1, перейдите в редактор веб-сайта, добавьте новый раздел и выберите элемент **Форма**. Затем выберите форму, которую вы хотите отобразить. Подробности см. в разделе [Управление страницами](../website/managing-pages.md).
:::
