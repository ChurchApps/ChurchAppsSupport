# Создание форм

<div class="article-intro">

Создавайте пользовательские формы для сбора информации от вашей общины. Вы можете создавать формы для регистрации мероприятий, опросов, карточек посетителей, заявлений о членстве и многого другого. Формы можно связать с людьми в вашей базе данных или использовать как отдельные страницы с собственным публичным URL-адресом.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Для форм **Люди** (связанные с записями людей) вам нужны [люди в вашей базе данных](../people/adding-people.md) в первую очередь.
- Для форм, которые собирают **платежи**, вы должны иметь [Stripe, настроенный для онлайн-благожертвований](../donations/online-giving-setup.md).

</div>

## Создание новой формы

1. Откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (поле поиска в верхнем левом углу B1 Admin), разверните **People** и нажмите **Forms**.
2. Нажмите **Add Form**.
3. Введите **имя** для вашей формы.
4. Выберите тип формы из раскрывающегося списка:
   - **People** — Связывает отправки с [записями людей](../people/adding-people.md) в вашей базе данных.
   - **Stand Alone** — Создает независимую форму с собственным публичным URL, идеально подходящую для внешних регистраций.
5. Нажмите **Save** для создания формы.

Ваша новая форма появится в списке. Нажмите на нее для начала добавления вопросов.

## Печать пустой формы

Нужна бумажная копия для раздачи -- для карточки посетителя на приветственной стойке или формы, которую кто-то без доступа в Интернет может заполнить вручную? Нажмите на **значок печати** рядом с формой в основном списке Forms для открытия предпросмотра, затем нажмите **Print**. Пустые поля печатаются с подчеркиванием или флажком для каждого вопроса, чтобы люди могли заполнить их вручную; обязательные вопросы отмечены звездочкой. Название вашей церкви печатается вверху над названием формы. Нет других параметров печати -- печатайте всю форму или ничего.

## Добавление вопросов

1. Откройте вашу форму и перейдите на вкладку **Questions**.
2. Нажмите **Add Question**.
3. Выберите **тип поля** из раскрывающегося списка Provider. Доступные типы включают:
   - **Textbox** — Для коротких текстовых ответов
   - **Date** — Для выбора даты
   - **Email** — Для адресов электронной почты
   - **Phone Number** — Для ввода телефона
   - **Multiple Choice** — Для выбора из предопределенных вариантов
   - **Payment** — Для сбора платежей
4. Введите **Title** и необязательное **Description** для вопроса.
5. Установите флажок **Require an answer**, если поле обязательно.
6. Нажмите **Save**.
7. Повторите для добавления дополнительных вопросов.

:::warning
Тип поля **Payment** требует настройки Stripe. Если вы еще не настроили онлайн-благожертвования, см. [Online Giving Setup](../donations/online-giving-setup.md) перед добавлением полей платежей.
:::

## Управление членами формы

1. Откройте вашу форму и перейдите на вкладку **Form Members**.
2. Поищите человека и добавьте его с ролью:
   - **Admin** — Может редактировать форму и просматривать все отправки.
   - **View Only** — Может просматривать отправки, но не может редактировать форму.

## Автоматическое добавление отправляющих в группу

Когда **Create a person record from submissions** включено, вы также можете связать форму с группой, чтобы каждый отправляющий автоматически добавлялся в список группы:

1. Откройте **Details** вашей формы и включите **Create a person record from submissions**.
2. Под **Add submitters to a group** выберите группу для добавления отправляющих или оставьте **None**.
3. Нажмите **Save**.

Каждый раз, когда кто-то отправляет форму, совпадающий или вновь созданный человек добавляется в группу (существующие члены группы пропускаются). Это полезно для таких вещей, как форма регистрации лагеря, которая должна автоматически построить список лагеря.

### Отправка письма для дальнейшего контакта

С **Create a person record from submissions** включено, вы также можете отправить письмо каждому человеку, который отправляет форму. Заполните **Follow-up Email Subject** и **Follow-up Email Body** в деталях формы. Вы можете использовать токены `{firstName}` и `{churchName}` в обоих. Письмо отправляется только при заполнении обоих полей.

:::info
Письма для дальнейшего контакта отправляются только после того, как ваша церковь одобрена для отправки группового письма, и они учитываются в ежедневном лимите электронной почты вашей церкви. См. [Turning On Group Email for Your Church](../groups/group-members.md#turning-on-group-email-for-your-church).
:::

## Дублирование формы

Чтобы переиспользовать форму как отправную точку для новой, нажмите **Duplicate** значок (значок копирования) рядом с формой в списке Forms. B1 создает точную копию формы — включая все вопросы — которую вы затем можете переименовать и редактировать независимо.

:::tip
Дублирование удобно для повторяющихся мероприятий, где вопросы регистрации остаются неизменными из года в год. Дублируйте форму прошлого года, обновите имя и даты, и вы готовы.
:::

## Настройка свойств формы

Вы можете обновить имя и параметры вашей формы в любое время. Для форм Stand Alone вы также увидите уникальный **публичный URL-адрес**, который вы можете поделиться с кем-либо, вместе с полем **Description** -- текст, показываемый выше вопросов на странице публичной формы, полезный для рассказа людям, для чего предназначена форма, перед тем как они начнут ее заполнять.

Используйте поле **Thank You Message** для установки того, что люди видят после отправки формы, включая на странице публичного URL формы. Если оставить его пустым, они видят "Thank you for submitting the form!"

:::tip
Формы Stand Alone отлично подходят для регистрации на мероприятия. Поделитесь публичным URL-адресом по электронной почте, в социальных сетях или встройте форму прямо на веб-сайт вашей церкви.
:::

:::info
Чтобы встроить форму на ваш веб-сайт B1, перейдите в редактор веб-сайта, добавьте новый раздел и выберите элемент **Form**. Затем выберите форму, которую вы хотите отобразить. См. [Managing Pages](../website/managing-pages.md) для подробной информации об редактировании вашего веб-сайта.
:::
