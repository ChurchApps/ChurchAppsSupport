# Создание форм

<div class="article-intro">

Создавайте пользовательские формы для сбора информации от ваших прихожан. Вы можете создавать формы для регистрации на события, опросов, карточек посетителей, заявок на членство и многого другого. Формы можно связать с людьми в вашей базе данных или использовать как автономные страницы с их собственным общедоступным URL.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Для форм **People** (связанных с записями о людях), вам сначала нужны [люди в вашей базе данных](../people/adding-people.md).
- Для форм, которые собирают **платежи**, вы должны иметь [Stripe настроен для онлайн-пожертвований](../donations/online-giving-setup.md).

</div>

## Создание новой формы

1. Перейдите в **Forms** из главного меню.
2. Нажмите **Add Form**.
3. Введите **имя** для вашей формы.
4. Выберите тип формы из раскрывающегося списка:
   - **People** — связывает отправки с [записями о людях](../people/adding-people.md) в вашей базе данных.
   - **Stand Alone** — создает независимую форму с ее собственным общедоступным URL, идеальна для внешних регистраций.
5. Нажмите **Save** для создания формы.

Ваша новая форма появится в списке. Нажмите на нее, чтобы начать добавлять вопросы.

## Добавление вопросов

1. Откройте вашу форму и перейдите на вкладку **Questions**.
2. Нажмите **Add Question**.
3. Выберите **field type** из раскрывающегося списка Provider. Доступные типы включают:
   - **Textbox** — для кратких текстовых ответов
   - **Date** — для выбора даты
   - **Email** — для электронных адресов
   - **Phone Number** — для ввода телефона
   - **Multiple Choice** — для выбора из предопределенных опций
   - **Payment** — для сбора платежей
4. Введите **Title** и необязательное **Description** для вопроса.
5. Отметьте **Require an answer**, если поле обязательно.
6. Нажмите **Save**.
7. Повторите для добавления дополнительных вопросов.

:::warning
Тип поля **Payment** требует, чтобы Stripe был настроен. Если вы еще не установили онлайн-пожертвования, см. [Настройку онлайн-пожертвований](../donations/online-giving-setup.md) перед добавлением полей платежей.
:::

## Управление членами формы

1. Откройте вашу форму и перейдите на вкладку **Members**.
2. Найдите человека и добавьте его с ролью:
   - **Admin** — может редактировать форму и просматривать все отправки.
   - **View Only** — может просматривать отправки, но не может редактировать форму.

## Автоматическое добавление отправляющих в группу

Когда включена функция **Create a person record from submissions**, вы также можете связать форму с группой, чтобы каждый отправляющий автоматически добавлялся в ростер группы:

1. Откройте **Details** вашей формы и включите **Create a person record from submissions**.
2. Под **Add submitters to a group** выберите группу для добавления отправляющих или оставьте установленным на **None**.
3. Нажмите **Save**.

Каждый раз, когда кто-то отправляет форму, сопоставленный или вновь созданный человек добавляется в группу (существующие члены группы пропускаются). Это полезно для таких вещей, как форма регистрации на лагерь, которая должна автоматически создавать ростер группы лагеря.

## Дублирование формы

Чтобы переиспользовать форму как отправную точку для новой, нажмите значок **Duplicate** (значок копирования) рядом с формой в списке Forms. B1 создает точную копию формы — включая все вопросы — которую вы затем можете переименовать и редактировать независимо.

:::tip
Дублирование удобно для повторяющихся событий, где вопросы регистрации остаются одинаковыми из года в год. Продублируйте форму прошлого года, обновите имя и даты, и вы готовы к работе.
:::

## Настройка свойств формы

Вы можете обновить имя и параметры вашей формы в любое время. Для форм Stand Alone вы также увидите уникальный **public URL**, который вы можете поделить с кем-либо.

:::tip
Формы Stand Alone отлично подходят для регистрации на события. Поделитесь общедоступным URL через электронную почту, социальные сети или встройте форму непосредственно на ваш сайт церкви.
:::

:::info
Чтобы встроить форму на ваш сайт B1, перейдите в редактор веб-сайта, добавьте новый раздел и выберите элемент **Form**. Затем выберите форму, которую хотите отобразить. Подробности см. в [Управлении страницами](../website/managing-pages.md).
:::
