# Создание форм

<div class="article-intro">

Создавайте пользовательские формы, чтобы собирать информацию от членов вашей общины. Вы можете создавать формы для регистрации на мероприятия, опросов, карточек гостей, заявлений о членстве и многого другого. Формы могут быть связаны с людьми в вашей базе данных или использоваться как отдельные страницы с собственным публичным адресом.

</div>

## Создание новой формы

1. Откройте [меню быстрого перехода](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу B1 Admin), разверните пункт **Люди** и нажмите **Формы**.
2. Нажмите **Добавить форму**.
3. Введите **название** формы.
4. Выберите тип формы в выпадающем списке **Связать с**:
   - **Люди** -- связывает отправки с [карточками людей](../people/adding-people.md) в вашей базе данных. Формы для людей заполняются из карточки человека, поэтому для них не создаётся ссылка для общего доступа.
   - **Отдельная** -- создаёт независимую форму с собственным публичным адресом, подходящую для внешней регистрации. Только отдельные формы поддерживают [фото в шапке](#adding-a-header-photo), [QR-код](#sharing-a-form-with-a-qr-code), [связанную группу](#linking-a-form-to-a-group) и опцию **Создавать карточку человека из отправок**.
5. Нажмите **Сохранить**, чтобы создать форму.

Новая форма появится в списке. Нажмите на неё, чтобы начать добавлять вопросы.

## Печать пустой формы {#printing-a-blank-form}

Нужна бумажная копия для раздачи -- например, карточка гостя у стойки регистрации или форма для человека без доступа в интернет, которую можно заполнить от руки? Нажмите **Печать** рядом с формой в общем списке форм, чтобы открыть предварительный просмотр, затем нажмите **Печать**. Пустые поля печатаются с подчёркиванием или флажком для каждого вопроса, чтобы их можно было заполнить от руки; обязательные вопросы отмечены звёздочкой. Вверху страницы показан логотип вашей церкви (**Логотип для светлого фона** из раздела [Веб-сайт > Оформление](../website/appearance.md), если вы его загрузили), под ним название церкви, а затем название формы. Других параметров печати нет: печатается либо вся форма целиком, либо ничего.

## Отправка формы с QR-кодом {#sharing-a-form-with-a-qr-code}

У отдельных форм в общем списке форм рядом есть ссылка **QR-код** (у архивных форм её нет). Нажмите её, чтобы открыть QR-код для публичного адреса формы; под ним показана ссылка. Нажмите **Скачать PNG**, чтобы сохранить код как изображение, которое можно напечатать в бюллетене или показать на слайдах. Любой, кто отсканирует код, откроет форму на своём телефоне.

## Добавление вопросов {#adding-questions}

1. Откройте форму и перейдите на вкладку **Вопросы**.
2. Нажмите **Добавить вопрос**.
3. Выберите **тип поля** в выпадающем списке Provider. Доступны следующие типы:
   - **Текстовое поле** -- для коротких текстовых ответов
   - **Дата** -- для выбора даты
   - **Email** -- для адресов электронной почты
   - **Номер телефона** -- для ввода телефона
   - **Множественный выбор** -- для выбора из заданных вариантов
   - **Оплата** -- для приёма платежей
4. Введите **Заголовок** и при желании **Описание** вопроса. Описание отображается под вопросом, когда люди заполняют форму, поэтому используйте его для подсказок, например «Укажите любые аллергии, о которых нам нужно знать».
5. Отметьте **Требуется ответ**, если поле обязательное.
6. Нажмите **Сохранить**.
7. Повторите действия, чтобы добавить другие вопросы.

:::warning
Тип поля **Оплата** требует настроенного Stripe. Если онлайн-пожертвования ещё не настроены, см. раздел [Настройка онлайн-пожертвований](../donations/online-giving-setup.md), прежде чем добавлять поля оплаты. Люди, которые платят через форму без входа в систему, должны отметить флажок **Я не робот**, прежде чем карта будет принята.
:::

## Управление участниками формы {#managing-form-members}

1. Откройте форму и перейдите на вкладку **Участники формы**.
2. Найдите человека и добавьте его с ролью:
   - **Администратор** -- может редактировать форму и просматривать все отправки.
   - **Только просмотр** -- может просматривать отправки, но не может редактировать форму.

## Связывание формы с группой {#linking-a-form-to-a-group}

Любую отдельную форму можно связать с группой -- например, форму запросов на молитву для малой группы или медицинское разрешение для поездки молодёжи:

1. Откройте **Сведения** вашей формы.
2. В разделе **Связанная группа** выберите группу или оставьте значение **Нет**.
3. Нажмите **Сохранить**.

Когда форма связана:

- **Участники группы** видят форму в разделе **Формы** на странице группы на B1.church, пока форма открыта; рядом есть кнопка **Заполнить**, которая её открывает (см. [Сведения о группе](../../b1-church/groups/group-details.md#linked-forms)).
- **Руководители группы** также видят закрытые формы и могут читать ответы на каждую отправку и печатать их (одну отправку или **Распечатать все**). Руководители могут только просматривать ответы -- они не могут редактировать форму, если только они не являются также [участниками формы](#managing-form-members).
- **В B1 Admin** на странице группы есть раздел **Связанные формы**, в котором каждая связанная форма отображается как **Открыта** или **Закрыта**. Он виден руководителям группы и людям, которые могут управлять формами. См. [Участники группы](../groups/group-members.md#linked-forms).

Форма закрыта, если она находится вне периода доступности. Архивные формы на странице группы не отображаются.

### Автоматическое добавление отправителей в группу {#automatically-adding-submitters-to-a-group}

Сама по себе связь формы с группой никого в неё не добавляет. Чтобы добавить каждого отправителя в список группы, также включите **Создавать карточку человека из отправок** в сведениях формы и нажмите **Сохранить**.

Каждый раз, когда кто-то отправляет форму, найденный или новый человек добавляется в группу (участники группы, которые уже состоят в ней, пропускаются). Это удобно, например, для формы записи на лагерь, которая должна автоматически формировать список участников лагеря.

### Отправка письма с благодарностью после заполнения {#sending-a-follow-up-email}

Если включено **Создавать карточку человека из отправок**, вы также можете отправлять письмо каждому, кто отправил форму. Заполните **Тему письма после отправки** и **Текст письма после отправки** в сведениях формы. В обоих полях можно использовать метки `{firstName}` и `{churchName}`. Письмо отправляется только тогда, когда заполнены оба поля.

:::info
Письма после отправки уходят только после того, как вашей церкви разрешили отправку групповых писем, и они учитываются в ежедневном лимите писем вашей церкви. См. [Включение групповой рассылки для вашей церкви](../groups/group-members.md#turning-on-group-email-for-your-church).
:::

## Дублирование формы

Чтобы использовать форму как основу для новой, нажмите **Дублировать** рядом с формой в списке форм и подтвердите действие. B1 создаст точную копию формы, включая все вопросы, которую затем можно переименовать и редактировать независимо.

:::tip
Дублирование удобно для повторяющихся мероприятий, где вопросы регистрации из года в год остаются прежними. Продублируйте форму прошлого года, обновите название и даты -- и всё готово.
:::

## Настройка свойств формы

Название и параметры формы можно обновить в любое время. Для отдельных форм также доступны уникальный **публичный адрес**, которым можно поделиться с кем угодно, и поле **Описание** -- текст, который показывается над вопросами на публичной странице формы; он полезен, чтобы объяснить людям, для чего нужна форма, прежде чем они начнут её заполнять.

### Добавление фото в шапку {#adding-a-header-photo}

В отдельных формах можно показать **Фото в шапке** вверху формы. В сведениях формы нажмите на поле для фото или **Добавить фото**, затем выберите или загрузите изображение (оно обрезается в формат 16:9). Нажмите **Сохранить**. Фото появляется под названием формы, над описанием, на странице публичного адреса формы и везде, где форма встроена с помощью элемента сайта **Форма**. Используйте **Изменить фото**, чтобы заменить его, или **Удалить**, чтобы убрать.

В поле **Текст благодарности** задайте, что люди увидят после отправки формы, в том числе на странице публичного адреса формы. Если оставить поле пустым, они увидят сообщение «Спасибо за отправку формы!»

:::tip
Отдельные формы отлично подходят для регистрации на мероприятия. Делитесь публичным адресом по электронной почте, в социальных сетях или встраивайте форму прямо на сайт вашей церкви.
:::

:::info
Чтобы встроить форму на сайт B1, откройте редактор сайта, добавьте новый раздел и выберите элемент **Форма**. Затем выберите форму, которую хотите показать. Подробности о редактировании сайта см. в разделе [Управление страницами](../website/managing-pages.md).
:::
