# Обзор B1 Admin

<div class="article-intro">

B1 Admin — это панель управления вашей церковью. Она предоставляет инструменты для управления всеми аспектами деятельности вашей церкви -- от справочников участников и пожертвований до создания сайта и прямых трансляций -- все в одном месте.

</div>

## Начало работы

1. Откройте браузер и перейдите на [admin.b1.church](https://admin.b1.church)
2. Войдите, используя имя пользователя и пароль
3. Вы попадете на **панель управления**, которая предоставляет обзор данных вашей церкви вместе с **быстрыми действиями** для распространенных задач, таких как добавление людей, создание групп, запись пожертвований и многое другое

:::tip
Впервые в B1 Admin? Начните с [Введения](./introduction) для видео-обзора, затем перейдите в раздел [Настройки](./settings/), чтобы настроить информацию о вашей церкви и пригласить свою команду.
:::

## Ключевые возможности

- **[Люди](./people/)** - Управляйте справочником вашей церкви, добавляйте участников, массово редактируйте данные, отслеживайте домохозяйства
- **[Группы](./groups/)** - Создавайте и организуйте церковные группы с заявками на вступление и управлением участниками
- **[Посещаемость](./attendance/)** - Настройте кампусы, время служений и отслеживайте посещаемость
- **[Пожертвования](./donations/)** - Записывайте пожертвования в разных валютах, управляйте фондами, формируйте отчеты
- **[Служение](./serving/)** - Координируйте волонтеров, создавайте планы служений, управляйте задачами и проводите людей через пошаговые процессы
- **[Формы](./forms/)** - Создавайте пользовательские формы для регистраций и сбора данных
- **[Отчеты](./reports/)** - Просматривайте отчеты по дням рождения, посещаемости и пожертвованиям
- **[Сайт](./website/)** - Создавайте и управляйте сайтом вашей церкви с пользовательскими стилями навигации
- **[Проповеди](./sermons/)** - Управляйте библиотекой проповедей и прямыми трансляциями
- **[Календари](./calendars/)** - Создавайте подобранные календари, управляйте бронированием помещений и ресурсов, просматривайте доступность
- **[Настройки](./settings/)** - Настройте информацию о церкви, роли, права доступа и пользовательские поля людей

:::info
Нажмите на значок вопросительного знака в правом верхнем углу любой страницы для быстрого доступа к справке и документации.
:::
