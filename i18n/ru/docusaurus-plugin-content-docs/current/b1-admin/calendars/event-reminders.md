# Напоминания о событиях

Настройте автоматические напоминания перед событиями через толчок-уведомления и электронную почту.

## Настройка напоминания

1. Откройте событие
2. Перейдите в раздел **Reminders**
3. Включите **Enable reminders**
4. Выберите время отправки (7 дней, 3 дня, 1 день, день события)
5. Выберите канал (толчок, электронная почта или оба)
6. Сохраните событие

## Кто получит напоминание

Напоминания отправляются:

- Зарегистрированным участникам события
- Членам группы, если событие не использует регистрацию

## Контроль членов

Члены могут управлять своими предпочтениями напоминаний в параметрах уведомлений.

## Советы

- Отправляйте напоминания за день перед событием
- Используйте описательные сообщения
- Проверьте предпросмотр перед сохранением
