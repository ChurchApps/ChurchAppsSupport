# Платные регистрации

<div class="article-intro">

Регистрация на мероприятие может быть больше, чем простой подсчёт участников. Вы можете задать типы участников с ценами (например, взрослый и ребёнок), предложить необязательные дополнительные опции с собственными ценами и количеством, создать промокоды и принимать оплату при регистрации через существующего провайдера пожертвований вашей церкви. Когда мероприятие заполняется, необязательный лист ожидания сохраняет очередь для заинтересованных участников и автоматически переводит их на освободившиеся места.

</div>

## Открытие настроек регистрации

1. В B1 Admin откройте [меню быстрого перехода](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), выберите **Календари > Регистрации** и откройте своё мероприятие (или откройте его из календаря).
2. Карточка **Настройки регистрации** содержит основные параметры: **Включить регистрацию**, **Вместимость**, **Открытие/закрытие регистрации**, **Теги** и **Вопросы для регистрации**.
3. Ниже основных параметров находятся три раскрывающихся раздела: **Типы участников**, **Выборы** и **Промокоды**.

## Типы участников

Типы участников позволяют назначать разные цены для разных категорий участников и ограничивать количество мест в каждой категории отдельно.

1. Раскройте раздел **Типы участников** и нажмите **Добавить тип**.
2. Введите **Название** (например, «Взрослый», «Ребёнок», «Студент»).
3. Укажите **Цену**. Для бесплатного типа укажите 0.
4. При необходимости задайте **Вместимость** только для этого типа (например, только 20 мест для детей). Оставьте поле пустым, если ограничения для типа не нужны.
5. Нажмите **Сохранить**.

При регистрации каждый участник выбирает тип; типы, на которые не осталось мест, отображаются как **Распродано** и не могут быть выбраны. В списке участников показан тип каждого участника и количество по каждому типу.

## Выборы

Выборы -- это необязательные платные дополнения: футболки, пакеты питания, улучшенные варианты участия в занятиях.

1. Раскройте раздел **Выборы** и нажмите **Добавить выбор**.
2. Введите **Название**, при желании **Описание**, и **Цену** (при значении 0 отображается «Бесплатно»).
3. При необходимости задайте **Вместимость** (общее количество доступных единиц по всем регистрациям) и **Макс. количество** (наибольшее количество, которое может заказать одна регистрация).
4. Нажмите **Сохранить**.

Участники выбирают количество при регистрации, и итоговые суммы учитываются в вместимости, поэтому вы не продадите больше, чем есть.

## Промокоды

1. Раскройте раздел **Промокоды** и нажмите **Добавить промокод**.
2. Введите **Код**, который участники будут вводить.
3. Выберите **Тип** -- **Процент** или **Сумма** -- и укажите его **Значение**.
4. При необходимости ограничьте действие кода датами **Начала** и **Окончания**, а также **Мин. участников** (минимальное число участников в регистрации) и **Макс. использований**.
5. Нажмите **Сохранить**.

У каждого кода есть счётчик **Использований**, чтобы вы видели, как часто он был применён. Участники сразу получают отклик, когда применяют код, включая понятные сообщения, если код истёк, ещё не начал действовать или требует большего количества участников.

## Лист ожидания {#waitlist}

Включите **Включить лист ожидания** в карточке настроек регистрации. Когда мероприятие достигает вместимости:

- Новым участникам предлагается место в листе ожидания вместо отказа. Они проходят ту же процедуру регистрации (пока они в листе ожидания, оплата пропускается).
- Когда кто-то отменяет регистрацию, самая ранняя регистрация из листа ожидания **автоматически переводится** на место, и этот человек получает письмо о том, что место освободилось. Если у него есть задолженность, письмо содержит ссылку на раздел [Мои регистрации](../../b1-church/events/my-registrations.md) на сайте B1 вашей церкви, где он может оплатить регистрацию.
- Вы можете перевести человека вручную в любое время с помощью действия **Перевести** в строке листа ожидания -- это удобно, например, после увеличения вместимости мероприятия.

:::info
Переведённые регистрации остаются *ожидающими*, пока не будет оплачен остаток; после оплаты (или если оплачивать нечего) регистрация подтверждается.
:::

## Список участников {#the-registration-roster}

Откройте мероприятие на странице «Регистрации», чтобы увидеть все регистрации. В заголовке карточки показано, сколько регистраций занимают место относительно вместимости (например, *Регистрации (18 / 20)*). Учитываются только ожидающие и подтверждённые регистрации; если есть люди в листе ожидания, в заголовке добавляется их количество (например, *· 3 в листе ожидания*), а то же число появляется под полосой вместимости. Большое число над полосой вместимости считает **людей**, а не регистрации -- всех участников каждой ожидающей или подтверждённой регистрации, поэтому семья из четырёх человек засчитывается как четыре. Лимит вместимости по-прежнему считает регистрации. В таблице есть столбцы **Имя**, **Участники**, **Тип** (тип каждого участника), **Оплачено / Всего** (с предупреждением, если остался долг), **Статус** и **Дата**, а над таблицей -- счётчики по типам.

- Нажмите значок сведений в строке, чтобы открыть диалоговое окно **Сведения о регистрации** -- участники, выборы, оплачено/остаток и таблица **Платежи** с каждым начислением (сумма, способ, дата).
- **Экспорт CSV** скачивает полный список с колонками для участников, типов, выборов, оплачено/всего/остатка, статуса и отдельной колонкой для каждого вопроса регистрации.
- **Добавить участника** оформляет регистрацию, сделанную офлайн или по телефону, для любого человека в вашей церкви. Выберите человека и, для платного мероприятия, его тип участника. С его карты деньги не списываются: платная регистрация сохраняется как **ожидающая** с полной суммой к оплате. Если у вашей церкви есть онлайн-пожертвования, человек может оплатить её в разделе [Мои регистрации](../../b1-church/events/my-registrations.md); в противном случае примите оплату лично. Для добавления участников нужно право «Редактирование регистраций».

:::info
Возвраты в B1 не оформляются. Если нужно вернуть деньги за отменённую платную регистрацию, выполните возврат в панели вашего провайдера пожертвований (например, Stripe).
:::

## Как работает оплата

Платежи проходят через тот же платёжный шлюз, который ваша церковь уже использует для пожертвований: данные карты передаются напрямую провайдеру и никогда не попадают на серверы B1. Цены всегда рассчитываются на сервере по настроенным типам, выборам и промокодам, поэтому участник не может изменить итоговую сумму. Авторизованные участники могут платить сохранённой картой. Гости вводят данные карты при оплате и должны отметить флажок **Я не робот** перед оплатой.

### Церкви без онлайн-пожертвований {#churches-without-online-giving}

Если у вашей церкви не настроен провайдер пожертвований, платные мероприятия всё равно могут принимать регистрации. На шаге оплаты участникам сообщается, что онлайн-оплата недоступна и они могут заплатить церкви напрямую; кнопка **Зарегистрироваться и оплатить позже** сохраняет регистрацию. Она сохраняется как **ожидающая** с полной суммой к оплате и появляется в списке участников с предупреждением о задолженности. Собирайте деньги так, как ваша церковь обычно это делает.

:::info
B1 не может отметить офлайн-платёж как полученный. Задолженность остаётся в списке участников и в карточке участника в разделе [Мои регистрации](../../b1-church/events/my-registrations.md) и после того, как вы получили деньги, поэтому ведите собственный учёт тех, кто оплатил.
:::
