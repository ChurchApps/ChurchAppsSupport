# Платные регистрации

Ощите события с платежами, типами участников, добавок и кодов скидок.

## Типы участников

Определите разные цены для разных типов:

1. Откройте событие
2. На странице регистрации нажмите **Add Type**
3. Введите название (например, Adult, Child)
4. Установите цену
5. Сохраните

## Добавки (Selections)

Предложите необязательные платные опции:

1. Нажмите **Add Selection**
2. Введите имя (например, T-Shirt)
3. Установите цену и возможное количество
4. Сохраните

## Коды скидок

1. Нажмите **Add Discount Code**
2. Введите код, выберите процент или сумму
3. Установите сроки действия и лимиты использования
4. Сохраните

## Список ожидания

Когда событие заполняется:

1. Новые регистранты добавляются в список ожидания
2. Когда место открывается, они автоматически продвигаются
3. Отправляется уведомление о необходимости оплаты

## Управление платежами

1. На странице регистраций просмотрите статус платежа
2. Отправьте напоминание на оплату
3. Обработайте возвраты через поставщика платежей
