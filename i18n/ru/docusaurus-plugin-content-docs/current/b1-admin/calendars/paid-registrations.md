# Платные регистрации

<div class="article-intro">

Регистрация на событие может выходить за рамки простого подсчета количества участников. Вы можете определить типы участников с ценами (например, взрослый и ребенок), предложить опциональные дополнения с их собственными ценами и количествами, создать коды скидок и собрать платежи при регистрации через существующего поставщика взносов вашей церкви. Когда событие заполняется, опциональный список ожидания позволяет заинтересованным членам оставаться в очереди и повышает их автоматически при открытии мест.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Сначала включите регистрацию на событие -- см. [Создание календарей](creating-calendars#enabling-event-registration)
- Для сбора платежей, вашей церкви нужно [сконфигурировано онлайн-взносы](../donations/online-giving-setup.md) (Stripe, PayPal, или Kingdom Funding). Бесплатные события не требуют установки взносов.

</div>

## Открытие параметров регистрации

1. В B1 Admin откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (поисковую строку в левом верхнем углу), выберите **Календари > Регистрации**, и откройте ваше событие (или откройте событие из его календаря).
2. Карточка **Параметры регистрации** показывает основы -- **Включить регистрацию**, **Вместимость**, **Регистрация открывается/закрывается**, **Теги**, и **Вопросы регистрации**.
3. Ниже основ находятся три разделения: **Типы участников**, **Выборки**, и **Коды скидок**.

## Типы участников

Типы участников позволяют вам устанавливать разные цены для разных видов участников и ограничивать каждый отдельно.

1. Разверните раздел **Типы участников** и нажмите **Добавить тип**.
2. Введите **имя** (например, "Взрослый", "Ребенок", "Студент").
3. Установите **цену**. Используйте 0 для бесплатного типа.
4. Опционально установите **вместимость** только для этого типа (например, только 20 мест для детей). Оставьте пусто для без ограничений по типам.
5. Нажмите **Сохранить**.

При регистрации каждый участник выбирает тип; проданные типы показаны как **Распроданы** и не могут быть выбраны. Реестр показывает тип каждого участника и подсчеты по типам.

## Выборки

Выборки - это опциональные платные дополнения -- футболки, планы питания, улучшения деятельности.

1. Разверните раздел **Выборки** и нажмите **Добавить выборку**.
2. Введите **имя**, опциональное **описание**, и **цену** (0 показывается как "Бесплатно").
3. Опционально установите **вместимость** (всего доступно для всех регистраций) и **Макс количество** (максимум, который может заказать одна регистрация).
4. Нажмите **Сохранить**.

Регистранты выбирают количества при регистрации, и итоги учитываются в отношении вместимости, поэтому вы никогда не переселитесь.

## Коды скидок

1. Разверните раздел **Коды скидок** и нажмите **Добавить код скидки**.
2. Введите **код**, который будут вводить регистранты.
3. Выберите **тип** -- **Процент** или **Сумма** -- и его **значение**.
4. Опционально ограничьте код **датой начала** / **датой окончания**, **минимум членов** (минимальное количество участников в регистрации), и **максимум использований**.
5. Нажмите **Сохранить**.

Каждый код показывает счет **использований**, поэтому вы можете видеть, как часто он был использован. Регистранты получают мгновенную обратную связь при применении кода -- включая четкие сообщения, когда код истек, не начался, или требует больше участников.

## Список ожидания

Включите **Включить список ожидания** в карточке "Параметры регистрации". Когда событие достигает вместимости:

- Новым регистрантам предлагается место в списке ожидания вместо отказа. Они выполняют ту же регистрацию (платежи пропускаются при нахождении в списке ожидания).
- Когда кто-то отменяет, самая старая регистрация из списка ожидания **повышается автоматически** и получает электронное письмо о том, что место открылось. Если они должны баланс, электронное письмо ссылает их для завершения платежа.
- Вы можете повысить кого-то вручную в любое время с действием **Повысить** в строке из списка ожидания -- полезно после повышения вместимости события.

:::info
Повышенные регистрации остаются *в ожидании* до тех пор, пока не будет оплачен баланс; оплата (или если нечего платить) подтверждает их.
:::

## Реестр регистраций

Откройте событие со страницы "Регистрации", чтобы увидеть каждую регистрацию. Таблица показывает **имя**, **члены**, **тип** (тип каждого участника), **оплачено / всего** (с предупреждением о балансе при задолженности), **статус**, и **дату**, плюс чипы подсчетов по типам выше таблицы.

- Нажмите значок деталей в строке, чтобы открыть диалог **Детали регистрации** -- члены, выборки, оплачено/баланс, и таблица **платежей**, перечисляющая каждый платеж (сумма, метод, дата).
- **Экспортировать CSV** загружает полный реестр с колонками для членов, типов участников, выборок, оплачено/всего/баланс, статуса, и одну колонку за вопрос регистрации.
- **Добавить участника** все еще позволяет вам записать регистрации в офлайне вручную.

:::info
Возвраты не обрабатываются внутри B1. Если вам нужно вернуть деньги за отмененную платную регистрацию, выполните возврат из панели управления вашего поставщика взносов (например, Stripe).
:::

## Как работает платеж

Платежи проходят через ту же шлюз взносов, которую ваша церковь уже использует для взносов -- данные карты идут прямо поставщику и никогда не трогают серверы B1. Цены всегда вычисляются на сервере из ваших сконфигурированных типов, выборок и кодов скидок, поэтому регистрант не может изменить итог. Зарегистрированные члены могут платить сохраненной карточкой; гости вводят карточку при оформлении.
