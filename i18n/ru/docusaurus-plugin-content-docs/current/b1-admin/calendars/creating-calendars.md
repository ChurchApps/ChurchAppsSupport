# Создание календарей

<div class="article-intro">

Создание календаря в B1 Admin позволяет вам построить подобранное представление событий, объединив одну или несколько групп. Событиями управляют лидеры групп в рамках своих групп, а ваш календарь отображает эти события в одном месте. Даже администратор домена не может добавлять или редактировать события напрямую в разделе календарей, если только он не является лидером группы, к которой относятся эти события.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Настройте [группы](../groups/creating-groups.md), события которых вы хотите включить в свой календарь
- Вам нужен административный доступ к разделу «Календари» в B1 Admin

</div>

## Создание нового календаря

1. В B1 Admin перейдите в раздел **Сайт**, затем в раздел **Календари**.
2. Нажмите **Добавить календарь**.
3. Введите **название** для вашего календаря (например, «События молодежного служения» или «Основной церковный календарь»).
4. При желании добавьте **описание**, чтобы помочь вашей команде понять, для чего предназначен этот календарь.
5. Нажмите **Создать**, чтобы сохранить новый календарь.

## Страница сведений о календаре

После создания календаря нажмите на него, чтобы открыть страницу сведений. На этой странице есть две основные области:

- **Левая колонка** -- Представление календаря, отображающее события, подтягиваемые из подключенных групп.
- **Правая колонка** -- Список связанных групп. Здесь вы управляете тем, какие группы включены в этот календарь.

## Подключение групп

Группы, у которых есть события в календаре, автоматически появляются в списке групп справа на странице сведений.

1. Нажмите **Добавить** в разделе групп, чтобы связать группу с вашим календарем.
2. Выберите группу из выпадающего списка.
3. Выберите, включать ли **все события** этой группы или только **отдельные события**.
4. Нажмите **Сохранить**.

:::tip
Подключение групп к вашему календарю — это мощный способ автоматически агрегировать события. Когда лидер группы добавляет событие в свою [группу](../groups/creating-groups.md), оно может попасть в общецерковный календарь без каких-либо дополнительных действий с вашей стороны.
:::

:::info
Если вы хотите создать единый календарь, который собирает события из множества групп по всей вашей церкви, см. раздел [Подобранный календарь](curated-calendar) с оптимизированным подходом.
:::

## Включение регистрации на событие

Вы можете включить регистрацию для любого события календаря, чтобы участники могли записываться через сайт B1 или мобильное приложение.

1. Нажмите на существующее событие или создайте новое.
2. В редакторе события включите переключатель **Регистрация**.
3. Настройте параметры регистрации:
   - **Вместимость** (необязательно) -- Установите максимальное число регистраций. Оставьте пустым для неограниченной вместимости.
   - **Регистрация открывается** -- Дата и время, когда регистрация становится доступной.
   - **Регистрация закрывается** -- Дата и время, когда регистрация закрывается.
   - **Теги** -- Метки через запятую (например, «молодежь, выезд, детский лагерь») для категоризации событий с регистрацией.
   - **Вопросы регистрации** -- При желании прикрепите [форму](../forms/creating-forms.md), чтобы регистрирующиеся отвечали на дополнительные вопросы (диетические ограничения, размер футболки, экстренный контакт и т. д.) в процессе регистрации. Выберите **Нет**, чтобы пропустить вопросы.
   - **Включить список ожидания** -- Когда мест на событие не остается, позвольте дополнительным регистрирующимся присоединиться к списку ожидания вместо отказа. См. [Платные регистрации](paid-registrations#waitlist).
4. Сохраните событие.

Для платных событий та же страница настроек позволяет определить тарифицируемые **Типы участников**, дополнительные **Опции** (доп. услуги) и **Промокоды** с оплатой через платежного провайдера вашей церкви. Полное руководство см. в разделе [Платные регистрации](paid-registrations).

После включения регистрации участники увидят кнопку **Зарегистрироваться на это событие** при просмотре события на [сайте B1](../../b1-church/events/registering) или в [приложении B1 Mobile](../../b1-mobile/events/registering). Если вы прикрепили форму, регистрирующиеся увидят шаг **Вопросы** в процессе регистрации, и их ответы будут сохранены вместе с регистрацией.

:::info
Вопросы регистрации работают только с формами, которые **не** отмечены как ограниченные. Ограниченная форма автоматически пропускается во время регистрации, а не отображается, поэтому используйте неограниченную форму при прикреплении вопросов к событию.
:::

### Управление регистрациями

Чтобы просматривать и управлять регистрациями на ваши события:

1. Перейдите на страницу **Регистрации** в B1 Admin.
2. Вы увидите таблицу всех событий с включенной регистрацией, показывающую название события, дату, текущее количество регистраций относительно вместимости и теги.
3. Нажмите на событие, чтобы увидеть полный список регистраций, включая имена, число участников, типы участников, статус оплаты и дату регистрации.
4. На странице сведений вы можете:
   - **Добавить участника** -- Вручную зарегистрировать того, кто записался офлайн или по телефону.
   - **Отменить** отдельные регистрации
   - **Удалить** регистрации навсегда
   - **Перевести** из списка ожидания при появлении свободного места
   - **Экспортировать CSV** -- Скачать все регистрации, включая типы участников, опции, суммы оплаты и ответы на вопросы

Если к событию прикреплены вопросы регистрации, на странице сведений также отображается фильтр **Только без ответов** для быстрого поиска регистрирующихся, которые еще не отправили ответы, и кнопка **Просмотреть ответы** на каждой регистрации с ответами. Платные события добавляют столбец **Тип**, столбец **Оплачено / Всего**, счетчики по типам и диалог сведений об оплате -- см. [Платные регистрации](paid-registrations#the-registration-roster).

:::tip
Используйте индикатор заполненности вместимости, чтобы отслеживать, насколько быстро заполняются события. Индикатор становится красным, когда событие заполнено или превышает вместимость.
:::
