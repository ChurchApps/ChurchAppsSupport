# Создание календарей

<div class="article-intro">

Создание календаря в B1 Admin позволяет собрать персонализированное представление событий, подключив одну или несколько групп. События ведут руководители групп внутри своих групп, а ваш календарь показывает их в одном месте. Администраторы с правом редактирования могут добавлять и изменять события для любой группы. Руководители групп, не являющиеся администраторами, могут управлять событиями только для групп, которые они возглавляют.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Настройте [группы](../groups/creating-groups.md), события которых хотите включить в календарь
- Нужен административный доступ к разделу «Календари» в B1 Admin

</div>

## Создание нового календаря

1. В B1 Admin откройте [меню перехода](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), раскройте **Календари** и нажмите **Календари**.
2. Нажмите **Добавить календарь** вверху страницы. Форма нового календаря откроется под списком календарей.
3. Введите **название** календаря (например, «События молодежного служения» или «Главный церковный календарь»).
4. При желании добавьте **описание**, чтобы команда понимала, для чего нужен этот календарь.
5. Нажмите **Создать**, чтобы сохранить новый календарь.

## Страница сведений о календаре

После создания календаря нажмите **Управление событиями** в его строке, чтобы открыть страницу сведений. На ней две основные области:

- **Левая колонка** -- название календаря с его действиями (**Новое событие**, **Редактировать**, **Импорт .ics** и **Печать**), а затем список **«Группы в календаре»**, где показано, какие группы включены в этот календарь. Нажмите **Удалить** рядом с группой, чтобы убрать ее из календаря.
- **Основная область** -- представление **События календаря** с событиями из подключенных групп, а над ним кнопки **Подписаться** и **Добавить группу**.

## Подключение групп

Группы, у которых есть события в календаре, автоматически появляются в списке **Группы в календаре** слева на странице сведений.

1. Нажмите **Добавить группу** над календарем, чтобы связать группу с вашим календарем.
2. Выберите группу из выпадающего списка. В списке есть все группы вашей церкви, а не только те, в которых состоите вы.
3. Выберите, включать ли **все события** этой группы или только **отдельные события**.
4. Нажмите **Сохранить**.

Каждое событие появляется в календаре только один раз. Если вы добавляете всю группу, все ее события, которые вы уже добавили по одному, объединяются в запись группы, а выбор отдельных событий из группы, которая уже есть в календаре, ничего нового не добавляет. В списке **Группы в календаре** отображаются только группы, добавленные целиком.

### Импорт файла .ics

Нажмите **Импорт .ics**, чтобы загрузить события из другого календаря. Выберите **Группу**, к которой должны относиться события, затем нажмите **Выбрать файл .ics** или вставьте содержимое файла и нажмите **Импорт**. События будут созданы в этой группе, а группа будет добавлена в календарь, из которого вы импортировали данные, поэтому события сразу появятся там.

### Удаление события из календаря

Нажмите на событие в календаре, затем нажмите **Удалить из календаря**. Это действие убирает событие только из этого календаря -- само событие остается в своей группе. Если событие попало в календарь потому, что добавлена вся группа, удаление уберет из этого календаря все события группы (сами события при этом останутся в группе). Чтобы удалить событие окончательно, удалите его в [календаре группы](../groups/group-calendar.md).

:::tip
Подключение групп к календарю -- удобный способ автоматически собирать события. Когда руководитель группы добавляет событие в свою [группу](../groups/creating-groups.md), оно может попасть в общецерковный календарь без дополнительной работы с вашей стороны.
:::

:::info
Если вы хотите создать один календарь, который собирает события многих групп по всей церкви, см. [Курированный календарь](curated-calendar) -- это более простой подход.
:::

## Добавление и редактирование событий {#adding-and-editing-events}

Нажмите **Новое событие** на странице сведений календаря, чтобы добавить событие, либо нажмите событие в календаре и затем **«Редактировать»**, чтобы его изменить. Форма **Новое событие** / **Редактирование события** содержит следующие поля:

- **Группа** -- группа, к которой относится событие. Если в вашей церкви есть шаблоны событий, можно выбрать **Шаблон**, чтобы заполнить форму.
- **Название**
- **Фото события** -- нажмите **Добавить фото** (или пустое поле для фото), чтобы выбрать или загрузить изображение, которое обрезается до широкого формата 16:9. Нажмите **Изменить фото**, чтобы заменить его. Фото показывается вверху страницы события на вашем сайте и как его плитка, когда элемент «Календарь» отображает **Ближайшие события** (см. [Показ событий на вашем сайте](#showing-events-on-your-website)).
- **Описание** -- отображается на странице события на вашем сайте. Поддерживаются полужирный текст, списки и ссылки.
- **Начало** и **Окончание**, **Повторяется** и **Видимость** (**Публичное** или **Приватное**).
- **Теги** -- метки через запятую, например `молодежь, студенты`. Элемент «Календарь» на вашем сайте можно настроить так, чтобы он показывал только события с определенным тегом. Это то же поле **«Теги»**, что и в настройках регистрации на событие.
- **Кто может видеть заметки** и **Кто может публиковать заметки** -- кто может читать и добавлять заметки к событию (см. [Заметки к событию](#event-notes)). Выберите **Только сотрудники** (по умолчанию), **Руководители групп** (руководители группы события) или **Участники группы** (все участники группы события, включая ее руководителей).
- **Помещения** и **Ресурсы** -- бронирование пространства и оборудования для события. См. [Помещения, ресурсы и расписание](rooms-resources).

Нажмите **Сохранить**. Если событие повторяется, B1 попросит подтверждение, потому что сохранение обновит все вхождения в серии.

### Заметки к событию {#event-notes}

У каждого события есть собственная ветка заметок для планирования и последующих действий. Нажмите событие на странице сведений календаря; в диалоге будут показаны его детали, напоминания и **Заметки** ниже. Введите заметку и опубликуйте ее, чтобы добавить в ветку.

Сотрудники, которые имеют право редактировать содержимое или управлять календарями, всегда могут читать и публиковать заметки к событиям. Настройки **Кто может видеть заметки** и **Кто может публиковать заметки** в самом событии определяют, могут ли это делать также руководители или участники группы события.

### Показ событий на вашем сайте {#showing-events-on-your-website}

Чтобы разместить календарь на сайте, добавьте элемент **Календарь** на страницу и выберите этот календарь. Элемент может показывать месячную сетку или сетку плиток предстоящих событий, а также может быть ограничен событиями с одним тегом. Посетители, которые нажимают на событие, открывают его страницу. См. [Использование элемента «Календарь»](../website/page-editor.md#using-the-calendar-element).

## Включение регистрации на событие {#enabling-event-registration}

Вы можете включить регистрацию на любое событие календаря, чтобы участники записывались через сайт B1 или мобильное приложение.

1. Нажмите на существующее событие или создайте новое.
2. В редакторе события переключите **Регистрация**, чтобы включить ее.
3. Настройте параметры регистрации:
   - **Вместимость** (необязательно) -- максимальное количество регистраций. Оставьте пустым для неограниченного количества.
   - **Регистрация открывается** -- дата и время, когда становится доступна регистрация.
   - **Регистрация закрывается** -- дата и время, когда регистрация закрывается.
   - **Теги** -- метки через запятую (например, «молодежь, выезд, ВБС») для категоризации событий с регистрацией.
   - **Вопросы для регистрации** -- при желании прикрепите [форму](../forms/creating-forms.md), чтобы участники отвечали на дополнительные вопросы (диетические ограничения, размер футболки, контакт для экстренной связи и т. д.) при записи. Выберите **Нет**, чтобы не задавать вопросы.
   - **Включить лист ожидания** -- когда мест не осталось, дополнительные участники могут встать в лист ожидания вместо отказа. См. [Платные регистрации](paid-registrations#waitlist).
4. Сохраните событие.

Для платных событий на той же странице настроек можно определить **Типы участников** с ценами, дополнительные **Выбора** (опции) и **Коды скидок**; оплата принимается через платежного провайдера вашей церкви. Полное описание см. в разделе [Платные регистрации](paid-registrations).

Когда регистрация включена, участники увидят кнопку **Зарегистрироваться на событие** при просмотре события на [сайте B1](../../b1-church/events/registering) или в [мобильном приложении B1](../../b1-mobile/events/registering). Если вы прикрепили форму, участники увидят шаг **Вопросы** во время регистрации, а их ответы сохранятся вместе с регистрацией.

:::info
Вопросы для регистрации работают только с формами, которые **не** помечены как ограниченные. Ограниченная форма пропускается автоматически во время регистрации и не показывается, поэтому при прикреплении вопросов к событию используйте неограниченную форму.
:::

### Управление регистрациями

Чтобы просматривать и управлять регистрациями на ваши события:

1. В меню перехода выберите **Календари > Регистрации**.
2. Вы увидите таблицу всех событий с включенной регистрацией, с названием события, датой, текущим количеством регистраций и вместимостью, а также тегами.
3. Нажмите на событие, чтобы увидеть полный список регистраций, включая имена, количество участников, типы участников, статус оплаты и дату регистрации.
4. На странице сведений вы можете:
   - **Добавить участника** -- вручную зарегистрировать человека, который записался офлайн или по телефону.
   - **Отменить** отдельные регистрации.
   - **Удалить** регистрации безвозвратно.
   - **Продвинуть** участников из листа ожидания, когда освобождается место.
   - **Экспорт CSV** -- скачать все регистрации, включая типы участников, выбранные опции, суммы платежей и ответы на вопросы.

Если к событию прикреплены вопросы для регистрации, на странице сведений также есть фильтр **«Только без ответов»**, чтобы быстро найти участников, которые еще не ответили на вопросы, и кнопка **Посмотреть ответы** у каждой регистрации с ответами, чтобы увидеть их. Для платных событий добавляются колонка **Тип**, колонка **Оплачено / Всего**, счетчики по типам и диалог с подробностями платежей -- см. [Платные регистрации](paid-registrations#the-registration-roster).

:::tip
Используйте полосу заполнения вместимости, чтобы следить за тем, как быстро заполняются события. Полоса становится красной, когда событие достигло или превысило вместимость.
:::
