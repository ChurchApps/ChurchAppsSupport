# Создание календарей

Создавайте календари в B1 Admin, чтобы построить куратированный вид событий, подключив одну или несколько групп.

## Создание нового календаря

1. Перейдите в **Website → Calendars**
2. Нажмите **Add Calendar**
3. Введите имя (например, "Youth Ministry Events")
4. Добавьте описание
5. Нажмите **Create**

## Подключение групп

После создания календаря:

1. Нажмите **Add** в разделе групп
2. Выберите группу
3. Выберите, включать ли все события или конкретные события
4. Нажмите **Save**

События группы автоматически появляются в календаре.

## Включение регистрации

1. Откройте событие
2. Переключите **Registration**
3. Установите параметры регистрации
4. Сохраните событие

Члены смогут зарегистрироваться через сайт B1.

## Управление регистрациями

1. Перейдите на страницу **Registrations**
2. Выберите событие
3. Просмотрите и управляйте регистрациями

## Советы

- Название календаря должно быть понятным членам
- Используйте описание для объяснения цели календаря
- Регулярно обновляйте события
- Используйте теги для категоризации
