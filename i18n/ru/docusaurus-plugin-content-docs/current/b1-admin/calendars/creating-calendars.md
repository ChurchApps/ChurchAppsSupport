# Создание календарей

<div class="article-intro">

Создание календаря в B1 Admin позволяет создать организованный вид событий, подключив одну или несколько групп. События управляются лидерами групп внутри их групп, а ваш календарь отображает эти события в одном месте. Администраторы с правом на редактирование могут добавлять или редактировать события для любой группы. Лидеры групп без прав администратора могут управлять событиями только для групп, которыми они руководят.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Установите [группы](../groups/creating-groups.md), события которых вы хотите включить в календарь
- Вам нужен административный доступ к разделу "Календари" в B1 Admin

</div>

## Создание нового календаря

1. В B1 Admin откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (поисковую строку в левом верхнем углу), разверните **Календари**, и нажмите **Календари**.
2. Нажмите **Добавить календарь**.
3. Введите **имя** для вашего календаря (например, "События молодежного служения" или "Основной календарь церкви").
4. Добавьте опциональное **описание**, чтобы помочь вашей команде понять, для чего нужен этот календарь.
5. Нажмите **Создать**, чтобы сохранить новый календарь.

## Страница деталей календаря

После создания календаря нажмите на него, чтобы открыть страницу деталей. На этой странице два основных раздела:

- **Левая колонка** -- Вид календаря, показывающий события, получаемые из подключенных групп.
- **Правая колонка** -- Список связанных групп. Здесь вы управляете, какие группы включены в этот календарь.

## Подключение групп

Группы, которые имеют события в календаре, автоматически появляются в списке групп с правой стороны страницы деталей.

1. Нажмите **Добавить** в разделе групп, чтобы связать группу с вашим календарем.
2. Выберите группу из раскрывающегося списка.
3. Выберите, включать ли **все события** из этой группы или только **определенные события**.
4. Нажмите **Сохранить**.

:::tip
Подключение групп к вашему календарю - это мощный способ автоматически объединить события. Когда лидер группы добавляет событие в их [группу](../groups/creating-groups.md), оно может попасть в календарь вашей церкви без дополнительной работы с вашей стороны.
:::

:::info
Если вы хотите создать один календарь, который получает события из множества групп по всей вашей церкви, см. [Организованный календарь](curated-calendar) для оптимизированного подхода.
:::

## Включение регистрации событий

Вы можете включить регистрацию для любого события календаря, чтобы члены могли зарегистрироваться через веб-сайт B1 или мобильное приложение.

1. Нажмите на существующее событие или создайте новое.
2. В редакторе событий переключите **Регистрация**, чтобы включить ее.
3. Настройте параметры регистрации:
   - **Вместимость** (опционально) -- Установите максимальное количество регистраций. Оставьте пусто для неограниченного.
   - **Регистрация открывается** -- Дата и время, когда становится доступна регистрация.
   - **Регистрация закрывается** -- Дата и время, когда закрывается регистрация.
   - **Теги** -- Разделенные запятыми метки (например, "молодежь, отступление, летняя школа") для помощи в категоризации регистрируемых событий.
   - **Вопросы регистрации** -- Опционально присоедините [форму](../forms/creating-forms.md), чтобы регистранты отвечали на дополнительные вопросы (диетические ограничения, размер футболки, контакт экстренной помощи и т.д.) как часть регистрации. Выберите **Нет**, чтобы пропустить вопросы.
   - **Включить список ожидания** -- Когда событие заполняется, разрешить дополнительным регистрантам присоединиться к списку ожидания вместо отказа. См. [Платные регистрации](paid-registrations#waitlist).
4. Сохраните событие.

Для платных событий та же страница параметров позволяет вам определить цены **Типы участников**, опциональные **Выборки** (дополнения), и **Коды скидок**, с платежом, собранным через поставщика взносов вашей церкви. См. [Платные регистрации](paid-registrations) для полного описания.

После включения регистрации, члены увидят кнопку **Зарегистрироваться на это событие**, когда они просматривают событие на [B1 веб-сайте](../../b1-church/events/registering) или [B1 мобильном приложении](../../b1-mobile/events/registering). Если вы присоедините форму, регистранты увидят шаг **Вопросы** при регистрации и их ответы сохраняются с их регистрацией.

:::info
Вопросы регистрации работают только с формами, которые **не** отмечены как Ограниченные. Ограниченная форма пропускается автоматически при регистрации, а не показывается, поэтому используйте неограниченную форму при присоединении вопросов к событию.
:::

### Управление регистрациями

Для просмотра и управления регистрациями для ваших событий:

1. В Jump меню выберите **Календари > Регистрации**.
2. Вы увидите таблицу всех событий с включенной регистрацией, показывающую название события, дату, текущий счет регистраций и вместимость, и теги.
3. Нажмите на событие, чтобы увидеть полный список регистраций, включая имена, количество членов, типы участников, статус платежа, и дату регистрации.
4. На странице деталей вы можете:
   - **Добавить участника** -- Вручную зарегистрировать того, кто зарегистрировался в офлайне или по телефону.
   - **Отменить** отдельные регистрации
   - **Удалить** регистрации навсегда
   - **Повысить** регистрации из списка ожидания, когда открывается место
   - **Экспортировать CSV** -- Загрузить все регистрации, включая типы участников, выборки, суммы платежей, и ответы на вопросы

Если событие имеет присоединенные Вопросы регистрации, страница деталей также показывает фильтр **Только неотвеченные вопросы**, чтобы быстро найти регистрантов, которые еще не отправили ответы, и кнопку **Просмотреть ответы** на каждой отвеченной регистрации, чтобы увидеть их ответы. Платные события добавляют колонку **Тип**, колонку **Оплачено / Всего**, подсчеты по типам, и диалог деталей платежей -- см. [Платные регистрации](paid-registrations#the-registration-roster).

:::tip
Используйте панель прогресса вместимости, чтобы отслеживать, как быстро заполняются события. Панель становится красной, когда событие на полной вместимости или превышает вместимость.
:::
