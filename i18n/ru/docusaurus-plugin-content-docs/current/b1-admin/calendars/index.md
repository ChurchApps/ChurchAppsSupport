# Календари

<div class="article-intro">

Раздел "Календари" в B1 Admin позволяет вам создавать организованные календари для вашей церкви, собирая события из ваших групп. Лидеры групп управляют событиями своей группы, а как администратор вы можете создавать календари, которые отображают эти события на вашем веб-сайте B1.church для вашей общины.

</div>

## Просмотр ваших календарей

1. В B1 Admin откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (поисковую строку в левом верхнем углу), разверните **Календари**, и нажмите **Календари**.
2. Страница "Календари" показывает таблицу всех ваших календарей с их именем и статусом. Используйте поле **Find a calendar**, чтобы отфильтровать список.
3. В каждой строке есть ссылка **Manage Events**, чтобы открыть календарь, и ссылка **Edit**, чтобы переименовать или удалить его.

## Что вы можете делать

- **Добавить новый календарь** -- Нажмите **Add Calendar** вверху страницы, чтобы создать календарь для определенного служения, типа события или цели. См. [Создание календарей](./creating-calendars.md) для пошагового руководства.
- **Редактировать календарь** -- Нажмите **Manage Events** у любого календаря, чтобы открыть его и управлять, какие группы включены в него.
- **Опубликовать календари** -- Календари можно отобразить на вашем веб-сайте B1.church, чтобы посетители могли видеть предстоящие события в вашей церкви.
- **Создать организованные календари** -- Получайте события из нескольких групп в один вид календаря для полного взгляда на все, что происходит в вашей церкви. См. [Организованный календарь](./curated-calendar.md) для деталей.
- **Управлять помещениями и ресурсами** -- Отслеживайте забронируемые пространства и оборудование и обрабатывайте запросы на одобрение. См. [Помещения и ресурсы](./rooms-resources.md) для деталей.
- **Просмотреть наличие** -- Увидьте все бронирования помещений и ресурсов в одном календаре и забронируйте пространства для предстоящих событий. См. [Календарь наличия](./availability.md) для деталей.

:::info
Календари работают тесно с [Группами](../groups/creating-groups.md). Когда группы имеют запланированные события, эти события могут быть получены в ваши календари. См. страницу [Создание календарей](./creating-calendars.md), чтобы узнать, как подключить группы к календарям.
:::
