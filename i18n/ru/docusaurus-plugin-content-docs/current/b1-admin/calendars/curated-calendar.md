# Курированный календарь

<div class="article-intro">

Курированный календарь объединяет события из нескольких групп в один общий вид календаря. Это идеальный вариант для создания общецерковного календаря, который показывает все, что происходит во всех ваших служениях и группах, в одном месте.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Настройте [группы](../groups/creating-groups.md), события которых хотите включить
- Убедитесь, что руководители групп добавили события в свои группы
- Ознакомьтесь с основами [создания календарей](creating-calendars)

</div>

## Создание курированного календаря

1. В B1 Admin откройте [меню перехода](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), раскройте **Календари** и нажмите **Календари**.
2. Нажмите **Добавить календарь**, чтобы создать новый курированный календарь.
3. Дайте календарю **название** (например, «События церкви» или «Эта неделя в нашей церкви»).
4. Нажмите **Создать**, чтобы сохранить его.

## Добавление групп в календарь

1. Нажмите **Управление событиями** в новом календаре, чтобы открыть его.
2. Нажмите **Добавить группу** над календарем. Добавленные группы появятся в списке **Группы в календаре** слева на странице.
3. Выберите группу из выпадающего меню. Здесь перечислены все группы вашей церкви, в том числе те, в которых вы не состоите.
4. Выберите, добавлять ли **все события** этой группы или только **отдельные события**.
5. Нажмите **Сохранить**.
6. Повторите эти действия, чтобы добавить столько групп, сколько нужно.

Каждое событие указывается один раз, даже если вы добавили его отдельно и одновременно добавили всю его группу. В списке **Группы в календаре** показываются только группы, добавленные вместе со всеми своими событиями.

Чтобы убрать что-то из календаря, нажмите на событие и выберите **Удалить из календаря**. Событие останется в своей группе. Если событие попало из целой группы, его удаление убирает все события этой группы из календаря.

:::tip
Добавьте все активные группы служений, чтобы создать полный календарь, который даст вашей общине целостную картину того, что происходит в вашей церкви каждую неделю.
:::

## Совместное использование календаря

После настройки курированного календаря его можно разместить несколькими способами:

- **Встроить на сайт** -- добавьте элемент **Календарь** на страницу, чтобы показать календарь в виде месячной сетки или плиток предстоящих событий, при желании ограниченных событиями с одним тегом. Каждое событие ведет на собственную страницу на вашем сайте. См. [Использование элемента «Календарь»](../website/page-editor.md#using-the-calendar-element).
- **Подписка через ICS** -- нажмите **Подписаться**, чтобы скопировать ссылку ICS. Члены общины могут вставить эту ссылку в Google Календарь, Календарь Apple, Outlook или любое другое приложение календаря, чтобы оставаться в курсе.
- **Скачать файл ICS** -- скачайте файл календаря, чтобы импортировать его в приложение календаря.

:::info
Когда руководители групп добавляют новые события в свои [группы](../groups/creating-groups.md), эти события автоматически появляются в вашем курированном календаре. Вам не нужно вручную обновлять курированный календарь каждый раз, когда добавляется новое событие.
:::

:::note Приватные события
На курированном календаре на вашем сайте и в его подписке ICS показываются только **публичные** события. В B1 Admin сотрудники, которые могут редактировать содержимое, также видят **приватные** события групп в курированном календаре, чтобы проверить полное расписание во время сборки календаря.
:::
