# Организованный календарь

<div class="article-intro">

Организованный календарь объединяет события из нескольких групп в один унифицированный вид календаря. Это идеально для создания календаря всей церкви, который показывает все, что происходит по всем вашим служениям и группам в одном месте.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Установите [группы](../groups/creating-groups.md), события которых вы хотите включить
- Убедитесь, что лидеры групп добавили события в свои соответствующие группы
- Ознакомьтесь с основами [Создания календарей](creating-calendars)

</div>

## Создание организованного календаря

1. В B1 Admin откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (поисковую строку в левом верхнем углу), разверните **Календари**, и нажмите **Календари**.
2. Нажмите **Добавить календарь**, чтобы создать новый организованный календарь.
3. Дайте вашему календарю **имя** (например, "События церкви" или "На этой неделе в нашей церкви").
4. Нажмите **Создать**, чтобы сохранить его.

## Добавление групп в ваш календарь

1. Нажмите на ваш новый календарь, чтобы открыть его.
2. В разделе **Группы в календаре** с правой стороны нажмите **Добавить**.
3. Выберите группу из раскрывающегося меню.
4. Выберите, добавлять ли **все события** из этой группы или только **определенные события**.
5. Нажмите **Сохранить**.
6. Повторите этот процесс, чтобы добавить столько групп, сколько хотите включить.

:::tip
Добавьте все ваши активные группы служения, чтобы создать всесторонний календарь, который дает вашей общине полную картину того, что происходит в вашей церкви каждую неделю.
:::

## Поделитесь своим календарем

После установки организованного календаря вы можете поделиться им несколькими способами:

- **Встройте на свой веб-сайт** -- Календарь можно отобразить непосредственно на страницах вашего веб-сайта B1.church для посетителей.
- **Подпишитесь через ICS** -- Нажмите **Подписаться**, чтобы скопировать ссылку ICS. Ваша община может вставить эту ссылку в Google Calendar, Apple Calendar, Outlook или любое другое приложение календаря, чтобы оставаться в синхронизации.
- **Загрузите файл ICS** -- Загрузите файл календаря для импорта в приложение календаря.

:::info
Когда лидеры групп добавляют новые события в их [группы](../groups/creating-groups.md), эти события автоматически появляются в вашем организованном календаре. Вам не нужно вручную обновлять организованный календарь каждый раз, когда добавляется новое событие.
:::

:::note Частные события
В организованном календаре на вашем сайте и в его ICS-подписке отображаются только **публичные** события. В B1 Admin сотрудники, которые могут редактировать контент, также видят в организованном календаре **частные** события группы, чтобы вы могли проверить полное расписание при составлении календаря.
:::
