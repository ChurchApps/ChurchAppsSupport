# Импорт данных

<div class="article-intro">

Инструмент B1 Transfer упрощает перенос существующих данных в B1, независимо от того, начинаете ли вы с нуля из электронной таблицы, мигрируете ли с другой платформы управления церковью или импортируете записи о пожертвованиях. Его также можно использовать для экспорта или резервной копии ваших данных в любое время.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужна активная учетная запись B1 Admin с доступом к **Settings**.
- Имейте ваши данные, экспортированные и готовые из вашей предыдущей системы перед началом.
- Этот инструмент предназначен для первоначальной миграции данных. Если вы уже используете B1 какое-то время, повторный импорт может создать дубликаты записей.

</div>

## Доступ к инструменту передачи

1. Войдите в **B1 Admin**.
2. Откройте **меню раздела** в верхнем левом углу (имя раздела со стрелкой) и выберите **Settings**.
3. Нажмите кнопку **Import/Export** в верхнем правом углу заголовка страницы.
4. Это откроет инструмент **B1 Transfer** в новой вкладке на [transfer.b1.church](https://transfer.b1.church).

Инструмент передачи проведет вас через четыре шага: Source, Preview, Destination и Run.

## Шаг 1 - Выберите ваш источник

Выберите, откуда приходят ваши данные. Есть семь опций:

- **B1 Database** — получает данные непосредственно из вашей существующей церкви B1. Полезно для создания резервной копии или преобразования ваших данных в другой формат. Вы должны быть авторизованы для использования этой опции.
- **B1 Import Zip** — ZIP-файл в собственном формате B1. Это в основном используется для восстановления предыдущего экспорта B1.
- **Breeze Import Zip** — ZIP-файл, содержащий экспортированные файлы из Breeze ChMS.
- **Planning Center Zip** — ZIP или CSV файл, экспортированный из Planning Center.
- **Custom CSV / Excel** — любой CSV или Excel файл, содержащий данные о людях. После загрузки вы будете сопоставлять ваши столбцы полям B1 перед тем как импорт продолжится.
- **Tithe.ly CSV** — файл экспорта людей или пожертвований из Tithe.ly (формат CSV или Excel принимается).
- **CCB / Pushpay CSV** — CSV экспорта людей или пожертвований из Church Community Builder или Pushpay.

Вы можете перетащить ваш файл в область загрузки или нажать для его поиска.

## Шаг 2 - Просмотр ваших данных

После загрузки инструмент отображает предпросмотр всего, что будет импортировано. Используйте вкладки для просмотра каждого типа данных:

- **People** — перечислены по хозяйству, с фотографиями, если включены.
- **Groups** — организованы по кампусу, служению, времени и категории.
- **Attendance** — даты сеансов, группы и количество посещений.
- **Donations** — партии, фонды, жертвователи и суммы.
- **Forms** — имена форм и типы контента.

Внимательно просмотрите это перед продолжением. Если что-то выглядит неправильно, нажмите **Start Over** и исправьте ваш исходный файл.

## Шаг 3 - Выберите ваш пункт назначения

Выберите, куда вы хотите, чтобы данные пошли:

- **B1 Database** — импортирует непосредственно в базу данных B1 вашей церкви. После выбора инструмент покажет окончательный подсчет записей для добавления. Нажмите **Start Transfer** для подтверждения.
- **B1 Export Zip** — загружает ваши данные как ZIP-файл формата B1. Хорошо для резервных копий.
- **Breeze Export Zip** — конвертирует ваши данные в формат Breeze.
- **Planning Center Zip** — конвертирует ваши данные в формат Planning Center.

## Шаг 4 - Запуск

Инструмент обрабатывает передачу и показывает прогресс для каждого шага:

- Кампусы, служения и времена
- Люди
- Фотографии
- Группы и члены групп
- Пожертвования
- Посещаемость
- Формы, вопросы, ответы и отправки форм
- Сжатие (для ZIP пункт назначений)

:::warning
Не закрывайте ваш браузер пока передача выполняется. Ждите, пока все шаги не будут завершены.
:::

## После импорта

После завершения передачи потратьте несколько минут для проверки ваших данных:

1. Перейдите на страницу [People](../people/adding-people.md) и выборочно проверьте несколько профилей.
2. Подтвердите, что имена, электронные письма, номера телефонов и адреса пришли правильно.
3. Проверьте, что связи хозяйств остаются неповреждены.
4. Просмотрите любые импортированные группы и записи о пожертвованиях.

Если вы заметите проблемы, вы можете редактировать отдельные профили со страницы People. Вы также можете запустить инструмент передачи снова для [экспорта ваших данных](exporting-data.md) в качестве резервной копии.
