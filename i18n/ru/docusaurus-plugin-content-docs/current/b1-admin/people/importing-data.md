# Импорт данных

<div class="article-intro">

Инструмент B1 Transfer помогает перенести ваши существующие данные в B1: начать с нуля из таблицы, перейти из другой системы управления церковью или импортировать записи о пожертвованиях. Его также можно использовать для экспорта или резервного копирования данных в любое время.

</div>

<h4>Перед началом</h4>

- Нужна активная учётная запись B1 Admin с доступом к **Settings**.
- Заранее экспортируйте данные из предыдущей системы и подготовьте их.
- Этот инструмент предназначен для первоначального переноса данных. Если вы уже давно используете B1, повторный импорт может создать дубликаты записей.

## Открытие инструмента Transfer

1. Войдите в **B1 Admin**.
2. Откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **Settings** и нажмите **Settings**.
3. Нажмите ссылку **Import/Export** под названием вашей церкви в верхней части левого меню настроек.
4. Откроется инструмент **B1 Transfer** в новой вкладке по адресу [transfer.b1.church](https://transfer.b1.church).

Инструмент проведёт вас через четыре шага: Source, Preview, Destination и Run.

---

## Шаг 1 — Выберите источник

Укажите, откуда поступают ваши данные. Доступно семь вариантов:

- **B1 Database** — получает данные напрямую из вашей существующей базы B1. Удобно для резервной копии или для преобразования данных в другой формат. Чтобы использовать этот вариант, нужно войти в систему.
- **B1 Import Zip** — zip-файл в собственном формате B1. В основном используется для восстановления предыдущего экспорта B1. Если загрузить B1 Export Zip обратно в **B1 Database**, восстанавливается всё, что содержит экспорт (см. [Экспорт данных](./exporting-data.md#full-data-export-from-settings)). Если файл не удаётся прочитать, инструмент показывает ошибку, а не начинает всё заново.
- **Breeze Import Zip** — zip-файл с экспортированными из Breeze ChMS файлами.
- **Planning Center Zip** — zip- или CSV-файл, экспортированный из Planning Center.
- **Custom CSV / Excel** — любой CSV- или Excel-файл с данными о людях. После загрузки вам нужно будет сопоставить столбцы с полями B1, прежде чем импорт продолжится.
- **Tithe.ly CSV** — файл с людьми или пожертвованиями, экспортированный из Tithe.ly (принимаются форматы CSV или Excel).
- **CCB / Pushpay CSV** — CSV-файл с людьми или пожертвованиями из Church Community Builder или Pushpay.

Файл можно перетащить в область загрузки или нажать, чтобы выбрать его в проводнике.

---

## Шаг 1b — Сопоставьте поля (только для Custom CSV / Excel)

Если вы выбрали **Custom CSV / Excel**, после загрузки файла инструмент покажет экран сопоставления полей, прежде чем перейти к предпросмотру.

Каждый столбец вашего файла отображается вместе с примером значения. Для каждого столбца выберите в раскрывающемся списке подходящее поле B1. Инструмент автоматически распознает распространённые названия столбцов, например «First Name», «Email» или «Zip Code», но проверьте каждую строку и исправьте всё, что он пропустил.

Доступные поля B1:

- First Name, Last Name, Middle Name, Nickname, Display Name, Title/Prefix, Suffix
- Email, Home Phone, Mobile Phone, Work Phone
- Address Line 1, Address Line 2, City, State, Zip Code
- Birth Date, Anniversary, Gender, Marital Status, Membership Status
- Household/Family Name
- Group Name — назначает человека в группу по её названию
- **Custom Field (match by name)** — сохраняет столбец в одно из [пользовательских полей людей](../settings/custom-fields.md) вашей церкви. Появится поле **B1 field name**, заполненное заголовком столбца. Измените его на название поля точно так, как оно записано в B1 (регистр букв не имеет значения).
- **Form Answer (custom field)** — сохраняет значение столбца как пользовательское поле в записи человека. Если вы используете этот вариант, вам будет предложено задать название формы.

Даты могут быть в распространённых форматах, например `9/17/1994`, и автоматически преобразуются. Для пользовательских полей поля «да/нет» принимают значения вроде Yes, No, Y, N, True, False, 1 и 0, а поля с выбором из нескольких вариантов принимают как текст варианта, так и его значение.

:::info
Создайте пользовательские поля людей в B1 Admin до импорта. Когда импорт завершится, шаг **Custom Fields** покажет все названия столбцов, которые не совпадают ни с одним полем B1, и посчитает значения, не соответствующие типу поля. Такие значения пропускаются, а остальной импорт всё равно завершается.
:::

Столбцы, которые не нужно импортировать, можно установить в **(Skip)**. Хотя бы одно поле имени (First Name или Last Name) должно быть сопоставлено, прежде чем вы сможете продолжить.

Нажмите **Confirm Mapping & Import**, чтобы перейти к предпросмотру.

---

## Шаг 2 — Просмотрите данные

После загрузки инструмент показывает предпросмотр всего, что будет импортировано. Используйте вкладки, чтобы просмотреть каждый тип данных:

- **People** — список по домохозяйствам, с фото, если они включены.
- **Groups** — упорядочено по кампусу, служению, времени и категории.
- **Attendance** — даты сессий, группы и количество посещений.
- **Donations** — пакеты, фонды, жертвователи и суммы.
- **Forms** — названия форм и типы содержимого.

Внимательно проверьте всё перед тем, как продолжить. Если что-то выглядит неправильно, нажмите **Start Over** и исправьте исходный файл.

---

## Шаг 3 — Выберите место назначения

Укажите, куда должны попасть данные:

- **B1 Database** — импорт напрямую в базу данных вашей церкви в B1. После выбора этого варианта инструмент покажет итоговое количество записей для добавления. Нажмите **Start Transfer**, чтобы подтвердить.
- **B1 Export Zip** — скачивает данные в виде zip-файла формата B1, который можно позже восстановить через **B1 Import Zip**. Подходит для резервных копий.
- **Breeze Export Zip** — преобразует данные в формат Breeze.
- **Planning Center Zip** — преобразует данные в формат Planning Center.

:::warning
Источник и назначение не могут быть в одном формате. Если они совпадают, инструмент выдаст предупреждение, чтобы предотвратить случайное дублирование.
:::

---

## Шаг 4 — Запуск

Инструмент выполняет перенос и показывает ход выполнения каждого шага:

- Campuses, Services и Times
- People
- Photos
- Groups и Group Members
- Donations
- Attendance
- Forms, Questions, Answers и Form Submissions
- Custom Fields (если вы сопоставляли столбцы Custom Field)
- Compressing (только для назначений в виде zip-файла)

Если назначение — **B1 Database**, карточка прогресса называется **Import Progress** и завершается сообщением **Import Complete!** (или **Import Completed with Errors**). Для назначений в виде zip-файла те же сообщения говорят **Export**.

:::info
При восстановлении **B1 Import Zip** записи, ссылающиеся на то, чего больше нет в файле, пропускаются, а не останавливают импорт: членства в группах для людей или групп, которых нет в zip-файле, посещаемость удалённых групп или людей, а также связи между группами и удалёнными временами служения. Сессии посещаемости, которые никогда не были привязаны ко времени служения, всё равно восстанавливаются. Аналогично, при экспорте фото, которое нельзя скачать или прочитать, не включается в файл, чтобы шаг **Photos** продолжал работу.
:::

:::warning
Не закрывайте браузер, пока выполняется перенос. Дождитесь, пока все шаги не отобразятся как завершённые.
:::

## Подготовка Breeze Import Zip

1. В Breeze откройте **Settings** и нажмите **Export** в левом боковом меню.
2. Экспортируйте три отдельных файла: **People**, **Tags** и **Contributions**.
3. Выделите все три файла, щёлкните правой кнопкой мыши и заархивируйте их в один zip-файл.
   - На Mac: выделите файлы, щёлкните правой кнопкой и выберите **Compress**.
   - На ПК: выделите файлы, щёлкните правой кнопкой, выберите **Send to**, затем **Compressed (zipped) folder**.
4. Загрузите zip-файл, выбрав вариант **Breeze Import Zip** на шаге 1.

Импорт из Breeze автоматически переносит людей, группы (теги) и записи о пожертвованиях.

## Подготовка экспорта Planning Center

1. Войдите в Planning Center и откройте продукт **People**.
2. В левом боковом меню нажмите **Lists** и создайте список, который включает всех, кого вы хотите перенести. (Если у вас уже есть список всей общины, используйте его.)
3. Откройте список и с помощью его опции **export** скачайте данные людей в виде файла **CSV**. Включите поля, которые хотите сохранить: имя, email, телефон, адрес, дату рождения, пол и статус членства — всё это переносится в B1.
4. Если Planning Center выдал несколько файлов, выделите их все, щёлкните правой кнопкой и заархивируйте в один zip-файл.
   - На Mac: выделите файлы, щёлкните правой кнопкой и выберите **Compress**.
   - На ПК: выделите файлы, щёлкните правой кнопкой, выберите **Send to**, затем **Compressed (zipped) folder**.
5. Загрузите CSV или zip, выбрав вариант **Planning Center Zip** на шаге 1.

После загрузки перейдите к предпросмотру и убедитесь, что люди и домохозяйства выглядят правильно, прежде чем запускать импорт.

---

## Подготовка экспорта Tithe.ly

1. В Tithe.ly экспортируйте данные **People** в формате CSV или Excel. Если нужно импортировать записи о пожертвованиях, можно также экспортировать отдельный файл **Giving**.
2. Инструмент автоматически определит, содержит файл данные о людях или о пожертвованиях, по названиям столбцов.
3. Загрузите файл, выбрав вариант **Tithe.ly CSV** на шаге 1.

:::info
Экспорты Tithe.ly импортируются по одному файлу за раз. Если нужно импортировать людей и пожертвования отдельно, запустите процесс дважды.
:::

---

## Подготовка экспорта CCB или Pushpay

1. В Church Community Builder или Pushpay экспортируйте данные **People** в формате CSV. Также можно экспортировать отдельный файл с пожертвованиями/взносами.
2. Инструмент автоматически определит, содержит файл данные о людях или о пожертвованиях, по названиям столбцов.
3. Загрузите файл, выбрав вариант **CCB / Pushpay CSV** на шаге 1.

---

## После импорта

После завершения переноса уделите несколько минут проверке данных:

1. Откройте страницу [People](../people/adding-people.md) и выборочно просмотрите несколько профилей.
2. Убедитесь, что имена, email, телефоны и адреса перенеслись правильно.
3. Проверьте, что связи в домохозяйствах сохранились. Роль каждого человека в домохозяйстве (Head, Spouse, Child или Other) переносится, если она есть в исходных данных: столбец **householdRole** в B1 Import Zip, **Family Role** в Breeze или Tithe.ly и **Family Position** в CCB / Pushpay. Такие роли, как «Head of Household», «Primary», «Wife» или «Son», преобразуются в соответствующую роль B1. В импорте Planning Center и Custom CSV / Excel столбца с ролью нет, поэтому этим людям назначается **Other**; роль можно изменить в домохозяйстве человека на странице [People](../people/adding-people.md#managing-households).
4. Просмотрите импортированные группы и записи о пожертвованиях.

Если вы замечаете проблемы, отредактируйте отдельные профили на странице People. Также можно запустить инструмент переноса повторно, чтобы [экспортировать данные](exporting-data.md) в качестве резервной копии.
