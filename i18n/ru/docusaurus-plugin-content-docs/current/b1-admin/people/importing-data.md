# Импорт данных

<div class="article-intro">

Инструмент B1 Transfer упрощает перенос существующих данных в B1 — будь то начало работы с нуля из таблицы, переход из другой платформы для управления церковью или импорт записей о пожертвованиях. Его также можно использовать для экспорта или резервного копирования данных в любое время.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужна активная учетная запись B1 Admin с доступом к **Settings**.
- Перед началом подготовьте и выгрузите данные из своей предыдущей системы.
- Этот инструмент предназначен для первоначального переноса данных. Если вы уже давно используете B1, повторный импорт может создать дубликаты записей.

</div>

## Открытие инструмента переноса

1. Войдите в **B1 Admin**.
2. Откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), разверните **Settings** и нажмите **Settings**.
3. Нажмите ссылку **Import/Export** под названием вашей церкви в верхней части левого меню настроек.
4. Откроется инструмент **B1 Transfer** в новой вкладке по адресу [transfer.b1.church](https://transfer.b1.church).

Инструмент переноса проведет вас через четыре шага: Source, Preview, Destination и Run.

---

## Шаг 1 — Выбор источника

Выберите, откуда поступают ваши данные. Доступно семь вариантов:

- **B1 Database** — получает данные напрямую из вашей существующей базы B1. Полезно для создания резервной копии или преобразования данных в другой формат. Чтобы использовать этот вариант, нужно быть авторизованным.
- **B1 Import Zip** — zip-файл в собственном формате B1. В основном используется для восстановления предыдущего экспорта B1. Загрузка B1 Export Zip обратно в **B1 Database** восстанавливает всё, что содержит экспорт (см. [Экспорт данных](./exporting-data.md#full-data-export-from-settings)). Если файл невозможно прочитать, инструмент покажет ошибку вместо того, чтобы начать заново.
- **Breeze Import Zip** — zip-файл с экспортированными из Breeze ChMS файлами.
- **Planning Center Zip** — zip- или CSV-файл, экспортированный из Planning Center.
- **Custom CSV / Excel** — любой CSV- или Excel-файл с данными о людях. После загрузки вы сопоставите столбцы с полями B1, прежде чем импорт продолжится.
- **Tithe.ly CSV** — файл экспорта людей или пожертвований из Tithe.ly (принимаются форматы CSV или Excel).
- **CCB / Pushpay CSV** — CSV-файл экспорта людей или пожертвований из Church Community Builder или Pushpay.

Вы можете перетащить файл в область загрузки или нажать, чтобы выбрать его на компьютере.

---

## Шаг 1b — Сопоставление полей (только для Custom CSV / Excel)

Если вы выбрали **Custom CSV / Excel**, после загрузки файла инструмент покажет экран сопоставления полей перед переходом к предварительному просмотру.

Каждый столбец вашего файла показан рядом с примером значения. Для каждого столбца используйте выпадающий список, чтобы выбрать соответствующее поле B1. Инструмент автоматически распознает распространенные названия столбцов, например «First Name», «Email» или «Zip Code», но проверьте каждую строку и исправьте то, что он пропустил.

Доступные поля B1 включают:

- First Name, Last Name, Middle Name, Nickname, Display Name, Title/Prefix, Suffix
- Email, Home Phone, Mobile Phone, Work Phone
- Address Line 1, Address Line 2, City, State, Zip Code
- Birth Date, Anniversary, Gender, Marital Status, Membership Status
- Household/Family Name
- Group Name — назначает человека в группу по названию
- **Custom Field (match by name)** — сохраняет столбец в одно из [пользовательских полей человека](../settings/custom-fields.md) вашей церкви. Появляется поле **B1 field name**, заполненное заголовком столбца. Измените его на название поля точно так, как оно записано в B1 (регистр букв не имеет значения).
- **Form Answer (custom field)** — сохраняет значение столбца как пользовательское поле, привязанное к карточке человека. Если вы используете этот вариант, система попросит указать название формы.

Даты могут быть в распространенных форматах, например `9/17/1994`, и автоматически преобразуются. Для пользовательских полей поля «Да/Нет» принимают значения вроде Yes, No, Y, N, True, False, 1 и 0, а поля с множественным выбором принимают либо текст варианта, либо его значение.

:::info
Создайте пользовательские поля людей в B1 Admin до импорта. Когда импорт завершится, шаг **Custom Fields** покажет названия столбцов, которые не совпадают ни с одним полем B1, и подсчитает значения, не соответствующие типу поля. Такие значения будут пропущены, а остальная часть импорта все равно завершится.
:::

Столбцы, которые не нужно импортировать, можно установить в значение **(Skip)**. Прежде чем продолжить, нужно сопоставить хотя бы одно поле с именем (First Name или Last Name).

Нажмите **Confirm Mapping & Import**, чтобы перейти к предварительному просмотру.

---

## Шаг 2 — Предварительный просмотр данных

После загрузки инструмент покажет предварительный просмотр всего, что будет импортировано. Используйте вкладки, чтобы просмотреть каждый тип данных:

- **People** — список по домохозяйствам, с фотографиями, если они были включены.
- **Groups** — организованы по кампусу, службе, времени и категории.
- **Attendance** — даты сессий, группы и количество посещений.
- **Donations** — пакеты, фонды, жертвователи и суммы.
- **Forms** — названия форм и типы содержимого.

Внимательно проверьте данные перед продолжением. Если что-то выглядит неправильно, нажмите **Start Over** и исправьте исходный файл.

---

## Шаг 3 — Выбор места назначения

Выберите, куда должны попасть данные:

- **B1 Database** — импорт напрямую в базу данных B1 вашей церкви. После выбора этого варианта инструмент покажет итоговое количество записей для добавления. Нажмите **Start Transfer**, чтобы подтвердить.
- **B1 Export Zip** — скачивает ваши данные в виде zip-файла формата B1, который позже можно восстановить с помощью **B1 Import Zip**. Подходит для резервных копий.
- **Breeze Export Zip** — преобразует ваши данные в формат Breeze.
- **Planning Center Zip** — преобразует ваши данные в формат Planning Center.

:::warning
Источник и место назначения не могут быть в одном формате. Если они совпадают, инструмент предупредит вас, чтобы избежать случайного дублирования.
:::

---

## Шаг 4 — Выполнение

Инструмент обрабатывает перенос и показывает ход выполнения каждого шага:

- Campuses, Services и Times
- People
- Photos
- Groups и Group Members
- Donations
- Attendance
- Forms, Questions, Answers и Form Submissions
- Custom Fields (если вы сопоставили какие-либо столбцы Custom Field)
- Compressing (только для назначений в виде zip-файла)

Когда местом назначения является **B1 Database**, карточка прогресса называется **Import Progress** и завершается сообщением **Import Complete!** (или **Import Completed with Errors**). Для назначений в виде zip-файла те же сообщения содержат слово **Export**.

:::warning
Не закрывайте браузер во время переноса. Дождитесь, пока все шаги не отметятся как выполненные.
:::

## Подготовка Breeze Import Zip

1. В Breeze откройте **Settings** и нажмите **Export** в левой боковой панели.
2. Экспортируйте три отдельных файла: **People**, **Tags** и **Contributions**.
3. Выделите все три файла, щелкните правой кнопкой мыши и упакуйте их в один zip-файл.
   - На Mac: выделите файлы, щелкните правой кнопкой мыши и выберите **Compress**.
   - На ПК: выделите файлы, щелкните правой кнопкой мыши, выберите **Send to**, затем **Compressed (zipped) folder**.
4. Загрузите zip-файл с помощью варианта **Breeze Import Zip** на шаге 1.

Импорт из Breeze автоматически переносит людей, группы (теги) и записи о пожертвованиях.

---

## Подготовка экспорта Planning Center

1. Войдите в Planning Center и откройте продукт **People**.
2. В левой боковой панели нажмите **Lists** и создайте список, который включает всех, кого хотите перенести. (Если у вас уже есть список всей паствы, используйте его.)
3. Откройте список и с помощью его опции **export** загрузите людей в виде файла **CSV**. Включите поля, которые хотите сохранить: имя, электронная почта, телефон, адрес, дата рождения, пол и статус членства — все они переносятся в B1.
4. Если Planning Center создал несколько файлов, выделите их все, щелкните правой кнопкой мыши и упакуйте в один zip-файл.
   - На Mac: выделите файлы, щелкните правой кнопкой мыши и выберите **Compress**.
   - На ПК: выделите файлы, щелкните правой кнопкой мыши, выберите **Send to**, затем **Compressed (zipped) folder**.
5. Загрузите CSV- или zip-файл с помощью варианта **Planning Center Zip** на шаге 1.

После загрузки перейдите к предварительному просмотру и убедитесь, что люди и домохозяйства отображаются правильно, прежде чем запускать импорт.

---

## Подготовка экспорта Tithe.ly

1. В Tithe.ly экспортируйте данные **People** в виде CSV- или Excel-файла. Если вы хотите перенести записи о пожертвованиях, также можно экспортировать отдельный файл **Giving**.
2. Инструмент автоматически определит, содержит ли файл данные о людях или о пожертвованиях, по названиям столбцов.
3. Загрузите файл с помощью варианта **Tithe.ly CSV** на шаге 1.

:::info
Файлы экспорта Tithe.ly импортируются по одному файлу за раз. Если нужно импортировать людей и пожертвования отдельно, выполните процесс дважды.
:::

---

## Подготовка экспорта CCB или Pushpay

1. В Church Community Builder или Pushpay экспортируйте данные **People** в виде CSV-файла. Также можно экспортировать отдельный файл с пожертвованиями/взносами.
2. Инструмент автоматически определит, содержит ли файл данные о людях или о пожертвованиях, по названиям столбцов.
3. Загрузите файл с помощью варианта **CCB / Pushpay CSV** на шаге 1.

---

## После импорта

После завершения переноса уделите несколько минут проверке данных:

1. Откройте страницу [People](../people/adding-people.md) и выборочно просмотрите несколько профилей.
2. Убедитесь, что имена, адреса электронной почты, номера телефонов и адреса перенесены правильно.
3. Проверьте, сохранились ли связи в домохозяйствах. Роль каждого человека в домохозяйстве (Head, Spouse, Child или Other) переносится, если она есть в исходных данных: столбец **householdRole** в B1 Import Zip, **Family Role** в Breeze или Tithe.ly и **Family Position** в CCB / Pushpay. Такие роли, как «Head of Household», «Primary», «Wife» или «Son», преобразуются в соответствующую роль B1. В импортах Planning Center и Custom CSV / Excel столбца роли нет, поэтому этим людям назначается роль **Other**; роль можно изменить в домохозяйстве человека на странице [People](../people/adding-people.md#managing-households).
4. Проверьте импортированные группы и записи о пожертвованиях.

Если вы заметили проблемы, вы можете отредактировать отдельные профили на странице People. Также можно снова запустить инструмент переноса, чтобы [экспортировать данные](exporting-data.md) как резервную копию.
