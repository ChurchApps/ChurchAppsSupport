# Экспорт данных

<div class="article-intro">

B1 Admin позволяет экспортировать данные вашей церкви, чтобы использовать их в таблицах, передавать команде или сохранять резервную копию. Нужен ли вам быстрый список имен и адресов электронной почты или полная выгрузка базы данных, для этого есть подходящие варианты.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужна активная учетная запись B1 Admin с правом просмотра данных, которые вы хотите экспортировать. Если вы не уверены в своем уровне доступа, см. [Роли и разрешения](roles-permissions.md).
- Для полного экспорта базы данных нужен доступ к разделу **Settings**.

</div>

## Экспорт со страницы People

Самый быстрый способ выгрузить справочник — со страницы **People**:

1. Откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу B1 Admin), разверните **People** и нажмите **People**.
2. Используйте строку поиска или фильтры, чтобы сузить результаты, которые хотите экспортировать (или оставьте всё без фильтра, чтобы экспортировать всех). См. [Поиск людей](searching-people.md) для советов по фильтрации.
3. Нажмите кнопку **Export** в заголовке страницы People.
4. На ваш компьютер будет скачан CSV-файл с людьми из текущих результатов, включая имя, контактные данные, адрес и другие стандартные поля.

:::tip
В экспорт попадают все люди из текущих результатов. Сначала выполните поиск, загрузите [сохраненный список](./lists.md) или воспользуйтесь поиском **Advanced**, чтобы экспортировать только нужных людей.
:::

## Полный экспорт данных из Settings

Чтобы выгрузить все данные B1 целиком (не только людей), используйте инструмент экспорта в разделе Settings:

1. В меню Jump выберите **Settings > Settings**.
2. Нажмите ссылку **Import/Export** под названием вашей церкви в верхней части левого меню настроек.
3. В выпадающем списке **Data Source** выберите **B1 Database**.
4. Просмотрите предварительный просмотр данных и нажмите **Continue to Destination**.
5. В качестве места назначения выберите **B1 Export Zip**.
6. Следите за ходом экспорта, пока все элементы не отметятся зелеными галочками.
7. Файл экспорта скачается автоматически. Ищите файл `B1Export` в папке загрузок.
8. Распакуйте архив, чтобы получить отдельные CSV-файлы (например, `people.csv`), которые можно открыть в Excel, Google Sheets или Numbers.

:::info
B1 Export Zip — это полная резервная копия данных вашей церкви. Она содержит:

- людей (с фотографиями) и домохозяйства, включая контакты для выдачи детей из домохозяйства
- кампусы, службы и время служений
- группы и участников групп
- фонды и пожертвования, включая взносы, распределенные по нескольким фондам
- посещаемость
- формы, вопросы, отправки и ответы
- пользовательские поля и их значения
- сохраненные списки людей

Чтобы восстановить данные, выберите **B1 Import Zip** в качестве источника и **B1 Database** в качестве назначения (см. [Импорт данных](./importing-data.md)). Домохозяйства, контакты для выдачи детей и сохраненные списки восстанавливаются вместе с людьми. Фильтры сохраненных списков переназначаются на восстановленные группы, фонды, кампусы и пользовательские поля.
:::

## Экспорт данных групп

Вы также можете экспортировать списки участников отдельных групп. На странице **Groups** откройте группу и нажмите **значок загрузки**, чтобы экспортировать список участников этой группы. Подробности см. в [Участники группы](../groups/group-members.md).

:::info
Экспортированные CSV-файлы работают во всех основных приложениях для работы с таблицами, включая Microsoft Excel, Google Sheets и Apple Numbers.
:::
