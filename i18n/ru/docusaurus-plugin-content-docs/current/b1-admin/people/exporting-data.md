# Экспорт данных

<div class="article-intro">

B1 Admin позволяет вам экспортировать данные вашей церкви для использования в электронных таблицах, совместного использования с вашей командой или сохранения резервной копии. Независимо от того, нужен ли вам быстрый список имен и адресов электронной почты или полный экспорт базы данных, есть варианты, соответствующие вашим потребностям.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужна активная учетная запись B1 Admin с разрешением на просмотр данных, которые вы хотите экспортировать. См. [Roles & Permissions](roles-permissions.md), если вы не уверены в вашем уровне доступа.
- Для полного экспорта базы данных вам нужен доступ к области **Settings**.

</div>

## Экспорт со страницы People

Самый быстрый способ экспортировать каталог — прямо со страницы **People**:

1. Откройте **меню раздела** в верхнем левом углу и выберите **People**.
2. Используйте поле поиска или фильтры, чтобы сузить результаты, которые вы хотите экспортировать (или оставьте его нефильтрованным для экспорта всех). См. [Searching People](searching-people.md) для советов по фильтрации.
3. Используйте **column selector** для выбора столбцов, которые вы хотите включить в экспорт (например, Name, Email, Phone, Address).
4. Нажмите кнопку **Export**.
5. Файл CSV загружается на ваш компьютер с данными, которые в данный момент показаны в таблице.

:::tip
Настройте столбцы перед экспортом. Файл CSV будет включать ровно столбцы, которые у вас видны, поэтому вы можете адаптировать экспорт к своим потребностям, не редактируя файл впоследствии.
:::

## Полный экспорт данных из параметров

Для полного экспорта всех ваших данных B1 (не только людей), используйте инструмент экспорта в Settings:

1. Откройте **меню раздела** в верхнем левом углу и выберите **Settings**.
2. Нажмите **Import/Export** в верхней навигации.
3. Выберите **B1 Database** из раскрывающегося меню **Data Source**.
4. Проверьте предварительный просмотр данных и нажмите **Continue to Destination**.
5. Выберите **B1 Export Zip** в качестве назначения экспорта.
6. Мониторьте прогресс экспорта до тех пор, пока все элементы не покажут зеленые галочки.
7. Файл экспорта загружается автоматически. Ищите файл `B1Export` в папке загрузок.
8. Разархивируйте файл для доступа к отдельным файлам CSV (таким как `people.csv`), которые вы можете открыть в Excel, Google Sheets или Numbers.

:::info
Полные экспорты данных включают людей, группы, пожертвования, посещаемость и многое другое — все в вашей базе данных B1. Это также отличный способ создать периодическую резервную копию записей вашей церкви.
:::

## Экспорт данных группы

Вы также можете экспортировать списки членов для отдельных групп. На странице **Groups** откройте группу и нажмите **download icon** для экспорта списка членов этой группы. См. [Group Members](../groups/group-members.md) для получения дополнительной информации.

:::info
Экспортированные CSV файлы работают со всеми основными приложениями электронных таблиц, включая Microsoft Excel, Google Sheets и Apple Numbers.
:::
