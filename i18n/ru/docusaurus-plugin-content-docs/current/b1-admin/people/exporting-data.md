# Экспорт данных

<div class="article-intro">

B1 Admin позволяет экспортировать данные вашей церкви, чтобы вы могли использовать их в электронных таблицах, делиться с вашей командой или сохранить резервную копию. Нужен ли вам быстрый список имен и адресов электронной почты или полный экспорт базы данных, есть варианты для ваших потребностей.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужна активная учетная запись B1 Admin с разрешением на просмотр данных, которые вы хотите экспортировать. См. [Роли и разрешения](roles-permissions.md) если вы не уверены в уровне вашего доступа.
- Для полного экспорта базы данных вам нужен доступ к области **Settings**.

</div>

## Экспорт со страницы People

Самый быстрый способ экспортировать справочник — прямо из страницы **People**:

1. Откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (поисковую строку в верхнем левом углу B1 Admin), разверните **People** и щелкните **People**.
2. Используйте поисковую строку или фильтры, чтобы сузить результаты, которые вы хотите экспортировать (или оставьте неотфильтрованным, чтобы экспортировать всех). Советы по фильтрации см. в [Searching People](searching-people.md).
3. Используйте **column selector** чтобы выбрать, какие столбцы вы хотите включить в экспорт (например, Name, Email, Phone, Address).
4. Щелкните кнопку **Export**.
5. CSV-файл загрузится на ваш компьютер с данными, которые в настоящее время показаны в таблице.

:::tip
Настройте свои столбцы перед экспортом. CSV-файл будет включать ровно столбцы, которые вы видите, чтобы вы могли адаптировать экспорт к своим потребностям без редактирования файла позже.
:::

## Полный экспорт данных из параметров

Для полного экспорта всех ваших данных B1 (не только людей), используйте инструмент экспорта в Settings:

1. В меню Jump выберите **Settings > Settings**.
2. Щелкните кнопку **Import/Export** в верхнем правом углу заголовка страницы.
3. Выберите **B1 Database** из раскрывающегося меню **Data Source**.
4. Просмотрите предпросмотр данных и щелкните **Continue to Destination**.
5. Выберите **B1 Export Zip** как место назначения экспорта.
6. Отслеживайте прогресс экспорта, пока все элементы не будут отмечены зеленой галочкой.
7. Файл экспорта загрузится автоматически. Найдите файл `B1Export` в папке загрузок.
8. Распакуйте файл, чтобы получить доступ к отдельным CSV-файлам (например `people.csv`), которые вы можете открыть в Excel, Google Sheets или Numbers.

:::info
Полные экспорты данных включают людей, группы, пожертвования, посещаемость и многое другое — все в вашей базе данных B1. Это также отличный способ создать периодическую резервную копию записей вашей церкви.
:::

## Экспорт данных группы

Вы также можете экспортировать списки членов отдельных групп. На странице **Groups** откройте группу и щелкните **значок загрузки** чтобы экспортировать список членов этой группы. Более подробную информацию см. в [Group Members](../groups/group-members.md).

:::info
Экспортированные CSV-файлы работают со всеми основными приложениями электронных таблиц, включая Microsoft Excel, Google Sheets и Apple Numbers.
:::
