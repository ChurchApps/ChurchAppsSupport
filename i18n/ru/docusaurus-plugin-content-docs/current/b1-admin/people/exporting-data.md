# Экспорт данных

<div class="article-intro">

B1 Admin позволяет экспортировать данные вашей церкви, чтобы использовать их в электронных таблицах, делиться ими с командой или хранить резервную копию. Нужен ли вам быстрый список имен и адресов электронной почты или полный экспорт базы данных — есть варианты под любые задачи.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужна активная учетная запись B1 Admin с разрешением на просмотр данных, которые вы хотите экспортировать. См. [Роли и разрешения](roles-permissions.md), если вы не уверены в своем уровне доступа.
- Для полного экспорта базы данных нужен доступ к разделу **Настройки**.

</div>

## Экспорт со страницы «Люди»

Самый быстрый способ экспортировать справочник — прямо со страницы **Люди**:

1. Откройте [меню перехода](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу B1 Admin), разверните **Люди** и нажмите **Люди**.
2. Используйте строку поиска или фильтры, чтобы сузить результаты для экспорта (или оставьте без фильтров, чтобы экспортировать всех). Советы по фильтрации см. в разделе [Поиск людей](searching-people.md).
3. Нажмите кнопку **Экспорт** в заголовке страницы «Люди».
4. На ваш компьютер будет скачан файл CSV с людьми из текущих результатов, включая их имя, контактные данные, адрес и другие стандартные поля.

:::tip
Экспорт включает всех людей из текущих результатов. Сначала выполните поиск, загрузите [Сохраненный список](./lists.md) или воспользуйтесь расширенным поиском **Расширенный**, чтобы экспортировать только нужных вам людей.
:::

## Полный экспорт данных из Настроек {#full-data-export-from-settings}

Чтобы полностью экспортировать все данные B1 (не только людей), используйте инструмент экспорта в Настройках:

1. В меню перехода выберите **Настройки > Настройки**.
2. Нажмите ссылку **Импорт/Экспорт** под названием вашей церкви в верхней части левого меню настроек.
3. В выпадающем списке **Источник данных** выберите **База данных B1**.
4. Просмотрите предпросмотр данных и нажмите **Продолжить к назначению**.
5. Выберите **B1 Export Zip** в качестве назначения экспорта.
6. Следите за ходом экспорта, пока все элементы не покажут зеленые галочки.
7. Файл экспорта скачается автоматически. Ищите файл `B1Export` в папке загрузок.
8. Распакуйте архив, чтобы получить отдельные файлы CSV (например, `people.csv`), которые можно открыть в Excel, Google Таблицах или Numbers.

:::info
B1 Export Zip — это полная резервная копия данных вашей церкви. В нее входят:

- люди (с фотографиями) и домохозяйства, включая контакты для самовывоза из домохозяйств
- кампусы, служения и времена служений
- группы и участники групп
- фонды и пожертвования, включая подарки, разделенные между несколькими фондами
- посещаемость
- формы, вопросы, отправки и ответы
- пользовательские поля и их значения
- сохраненные списки людей

Если фотографию человека не удается скачать или прочитать во время экспорта, эта фотография пропускается, и экспорт продолжается без нее.

Чтобы восстановить данные, выберите **B1 Import Zip** в качестве источника и **База данных B1** в качестве назначения (см. [Импорт данных](./importing-data.md)). Домохозяйства, контакты для самовывоза и сохраненные списки восстанавливаются вместе с людьми. Фильтры сохраненных списков переназначаются на восстановленные группы, фонды, кампусы и пользовательские поля.
:::

## Экспорт данных групп

Вы также можете экспортировать списки участников отдельных групп. На странице **Группы** откройте группу и нажмите **значок загрузки**, чтобы экспортировать список участников этой группы. См. подробности в разделе [Участники группы](../groups/group-members.md).

:::info
Экспортированные файлы CSV работают со всеми основными программами для электронных таблиц, включая Microsoft Excel, Google Таблицы и Apple Numbers.
:::
