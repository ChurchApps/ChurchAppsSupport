# Экспорт данных

<div class="article-intro">

B1 Admin позволяет экспортировать данные вашей церкви, чтобы работать с ними в таблицах, делиться с командой или сохранять резервную копию. Нужен ли вам быстрый список имён и адресов электронной почты или полный экспорт базы — для этого есть подходящие варианты.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Нужна активная учётная запись B1 Admin с правом просматривать данные, которые вы хотите экспортировать. Если вы не уверены в своём уровне доступа, см. [Роли и права доступа](roles-permissions.md).
- Для полного экспорта базы нужен доступ к разделу **Settings**.

</div>

## Экспорт со страницы «Люди» {#exporting-from-the-people-page}

Быстрее всего экспортировать каталог прямо со страницы **People**:

1. Откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в левом верхнем углу B1 Admin), раскройте **People** и нажмите **People**.
2. Используйте строку поиска или фильтры, чтобы сузить результаты для экспорта (или оставьте без фильтра, чтобы экспортировать всех). Советы по фильтрации см. в разделе [Поиск людей](searching-people.md).
3. Нажмите кнопку **Export** в заголовке страницы People.
4. На ваш компьютер скачается CSV-файл `people.csv` с людьми из текущих результатов: их имя, контактные данные, адрес и другие стандартные поля. Если вы ничего не искали, экспорт включает весь каталог, даже если на странице показана только его первая часть.

:::tip
Экспорт включает всех, кто попадает в текущие результаты. Сначала выполните поиск, загрузите [Сохранённый список](./lists.md) или используйте расширенный поиск **Advanced**, чтобы выгрузить только нужных людей.
:::

## Полный экспорт данных из Settings {#full-data-export-from-settings}

Чтобы полностью выгрузить все данные B1 (не только людей), используйте инструмент экспорта в Settings:

1. В меню Jump выберите **Settings > Settings**.
2. Нажмите ссылку **Import/Export** под названием вашей церкви в верхней части левого меню настроек.
3. В выпадающем списке **Data Source** выберите **B1 Database**.
4. Просмотрите предварительный просмотр данных и нажмите **Continue to Destination**.
5. В качестве назначения экспорта выберите **B1 Export Zip**.
6. Следите за ходом экспорта, пока все элементы не отметятся зелёными галочками.
7. Файл экспорта скачается автоматически. Ищите файл `B1Export` в папке загрузок.
8. Распакуйте архив, чтобы получить отдельные CSV-файлы (например, `people.csv`), которые можно открыть в Excel, Google Sheets или Numbers.

:::info
B1 Export Zip — это полная резервная копия данных вашей церкви. В неё входят:

- люди (с фотографиями) и домохозяйства, включая контакты для выдачи детей
- кампусы, служения и время служений
- группы и участники групп
- фонды и пожертвования, включая пожертвования, разделённые между несколькими фондами
- посещаемость
- формы, вопросы, отправки и ответы
- пользовательские поля и их значения
- сохранённые списки людей

Если фотографию человека не удаётся загрузить или прочитать во время экспорта, эта фотография пропускается, а экспорт продолжается без неё.

Чтобы восстановить данные, выберите **B1 Import Zip** в качестве источника и **B1 Database** в качестве назначения (см. [Импорт данных](./importing-data.md)). Домохозяйства, контакты для выдачи детей и сохранённые списки восстанавливаются вместе с людьми. Фильтры сохранённых списков связываются с восстановленными группами, фондами, кампусами и пользовательскими полями.
:::

## Экспорт данных групп {#exporting-group-data}

Вы также можете экспортировать списки участников отдельных групп. Откройте группу на странице **Groups** и нажмите **значок загрузки**, чтобы выгрузить список участников этой группы. Подробнее см. в разделе [Участники группы](../groups/group-members.md).

:::info
Экспортированные CSV-файлы открываются во всех основных табличных редакторах, включая Microsoft Excel, Google Sheets и Apple Numbers.
:::
