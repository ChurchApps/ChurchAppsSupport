# Массовое редактирование людей

<div class="article-intro">
Массовое редактирование позволяет обновить сразу нескольких людей, экономя время, когда одно и то же изменение нужно внести многим. Вы можете изменить статус членства, семейное положение, пол, отказ от каталога, кампус, пользовательские поля «Да/Нет», членство в группах и рабочие процессы одной операцией или удалить людей.
</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Нужно право на управление данными людей. Подробности см. в [Роли и права доступа](./roles-permissions.md).
- Вы уже должны были добавить или импортировать людей, которых хотите отредактировать. При необходимости см. [Добавление людей](./adding-people.md).
</div>

## Выбор людей для массового редактирования {#selecting-people-for-bulk-editing}

1. Перейдите в раздел **People** в B1 Admin.
2. Используйте поиск или фильтры, чтобы найти людей, которых хотите обновить.
3. Отметьте людей флажками.
   - В представлении **Households** отметка домохозяйства выбирает всех, кто в него входит.
   - В представлении **Table** (переключается кнопкой **View as**) можно выбирать людей по одному.
   - Либо используйте флажок над списком, чтобы выбрать всех видимых людей.
4. Когда выбран хотя бы один человек, над списком появляется панель с количеством выбранных, кнопкой **Clear Selection** и кнопкой **Actions**.

:::tip
Если нужно обновить большую группу людей по определённым критериям, сначала сузьте список с помощью [AI Search](./ai-search.md) или фильтров, а затем выберите всех подходящих людей.
:::

## Доступные массовые действия {#available-bulk-actions}

Меню **Actions** содержит перечисленные ниже пункты. Каждый из них открывает небольшой диалог, который сообщает, сколько людей будет изменено: выберите значение и нажмите **Apply**. Новое значение заменяет то, что было у каждого выбранного человека. По завершении внизу страницы появляется сообщение с количеством обновлённых людей.

### Set Membership Status {#set-membership-status}

1. Нажмите **Actions** → **Set Membership Status**.
2. Выберите новый **Membership Status**:
   - **Visitor** -- Впервые пришедшие или редко приходящие люди
   - **Guest** -- Гости, например семьи, зарегистрированные на киоске регистрации
   - **Regular Attendee** -- Частые посетители, которые не являются членами церкви
   - **Member** -- Официальные члены церкви
   - **Staff** -- Сотрудники церкви
   - **Inactive** -- Люди, которые больше не посещают церковь
   - **Deceased** -- Умершие
3. Нажмите **Apply**.

### Set Marital Status {#set-marital-status}

1. Нажмите **Actions** → **Set Marital Status**.
2. Выберите **Unknown**, **Single**, **Married**, **Divorced** или **Widowed**.
3. Нажмите **Apply**.

### Set Gender {#set-gender}

1. Нажмите **Actions** → **Set Gender**.
2. Выберите **Unspecified**, **Male** или **Female**.
3. Нажмите **Apply**.

### Set Directory Opt-Out {#set-directory-opt-out}

Отказ от каталога определяет, попадают ли люди в каталог участников — [печатный каталог](./print-directory.md) и каталог участников в приложении B1. Это та же настройка, что и **Hide me from the member directory** в карточке человека.

1. Нажмите **Actions** → **Set Directory Opt-Out**.
2. Выберите **Opted Out Yes**, чтобы скрыть выбранных людей из каталога, или **Opted Out No**, чтобы снова показать их.
3. Нажмите **Apply**.

:::warning
Люди, которые сами решили скрыться из каталога, должны оставаться скрытыми, если только они не попросили снова включить их в список.
:::

### Set Campus {#set-campus}

Этот пункт появляется, когда в вашей церкви настроены [кампусы](../settings/campuses.md).

1. Нажмите **Actions** → **Set Campus**.
2. Выберите кампус.
3. Нажмите **Apply**.

### Set Custom Field {#set-custom-field}

Установите значение [пользовательского поля](../settings/custom-fields.md) «Да/Нет» сразу для всех выбранных людей:

1. Нажмите **Actions** → **Set Custom Field**.
2. Выберите **Custom Field** типа «Да/Нет», который хотите задать.
3. Выберите **Value** (**Yes** или **No**) для применения.
4. Нажмите **Apply**.

:::info
Для этого массового действия доступны только пользовательские поля «Да/Нет». Чтобы задать поля других типов, редактируйте каждого человека отдельно. Если в вашей церкви нет полей «Да/Нет», диалог сообщит об этом.
:::

### Add to Group {#add-to-group}

1. Нажмите **Actions** → **Add to Group**.
2. Выберите **Group**, в которую нужно добавить людей. Чтобы поместить их в совершенно новую группу, отметьте **Create New Group** и введите **New Group Name**.
3. Нажмите **Apply**.

Каждый человек добавляется в группу как обычный участник. Позже вы можете назначить отдельных людей руководителями групп на странице [Участники группы](../groups/group-members.md). Чтобы добавить людей в несколько групп, повторите действие для каждой группы.

### Remove from Group {#remove-from-group}

1. Нажмите **Actions** → **Remove from Group**.
2. Выберите **Group**, из которой нужно удалить людей.
3. Нажмите **Apply**.

:::info
Это действие только удаляет людей из группы. Карточки людей при этом не удаляются.
:::

### Add to Workflow {#add-to-workflow}

Добавьте выбранных людей в [рабочий процесс](../serving/workflows.md) в виде карточек:

1. Нажмите **Actions** → **Add to Workflow**.
2. Выберите рабочий процесс.
3. Нажмите **Apply**.

### Delete People {#delete-people}

Удалите выбранных людей из базы данных церкви:

1. Нажмите **Actions** → **Delete**.
2. Диалог **Delete Selected People** попросит подтвердить, сколько человек будет удалено.
3. Нажмите **Delete**.

:::danger
Удалённые люди исчезают из каталога, групп и поиска. Используйте это действие, только если вы точно уверены, что хотите удалить этих людей из системы.
:::

Себя выбрать нельзя, поэтому массово удалить или отредактировать собственную карточку не получится.


## Рекомендации {#best-practices}

- **Начинайте с малого** -- Сначала проверьте массовые операции на нескольких записях, чтобы убедиться, что вносите правильные изменения.
- **Используйте фильтры** -- Сузьте список с помощью фильтров или AI Search перед выбором людей, чтобы обновлять только нужных.
- **Перепроверяйте выбор** -- Просмотрите выбранных людей перед применением массовых изменений.
- **Документируйте крупные изменения** -- Записывайте, что и когда массово обновили, чтобы при необходимости вернуться к этому.
- **Согласуйте с командой** -- Предупреждайте других администраторов, когда вносите большие массовые изменения.

## Типовые сценарии {#common-use-cases}

### Обновление новых членов церкви {#updating-new-members}

После занятий по членству переведите всех участников в статус Member:

1. Найдите людей, которые посещали занятия.
2. Выберите их всех.
3. Используйте **Actions** → **Set Membership Status** → **Member**.

### Организация малых групп {#organizing-small-groups}

Добавьте нескольких человек в новую малую группу:

1. Найдите людей, которых хотите включить в группу.
2. Выберите их.
3. Используйте **Actions** → **Add to Group** и выберите малую группу.

### Очистка данных {#cleaning-up-data}

Отметьте группу бывших посетителей как неактивных:

1. Откройте **Advanced** в поиске и отфильтруйте людей, которых хотите обновить (например, всех, кто давно не приходил).
2. Выберите их.
3. Используйте **Actions** → **Set Membership Status** → **Inactive**.
