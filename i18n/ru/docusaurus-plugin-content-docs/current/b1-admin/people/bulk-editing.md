# Массовое редактирование людей

<div class="article-intro">
Массовое редактирование позволяет вам обновлять нескольких людей сразу, экономя время, когда вы делаете один и тот же ч изменения многим людям. Вы можете обновлять статус членства, семейное положение, пол, параметры отказа от коммуникаций и членства в группе в одной операции.
</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужно разрешение на управление данными о людях. Подробности см. в [Роли и разрешения](./roles-permissions.md).
- Вы должны уже добавить или импортировать людей, которых вы хотите редактировать. Если нужно, см. [Добавление людей](./adding-people.md).
</div>

## Выбор людей для массового редактирования

1. Перейдите в **People** в B1 Admin
2. Используйте инструменты поиска или фильтрации, чтобы найти людей, которых вы хотите обновить
3. Установите флажки рядом с названием каждого человека для их выбора
   - Вы можете выбирать людей отдельно
   - Или используйте флажок заголовка, чтобы выбрать всех видимых людей на текущей странице
4. После выбора минимум одного человека появится кнопка **Bulk Actions**

:::tip
Если вам нужно обновить большую группу людей на основе определенных критериев, используйте функцию [AI Search](./ai-search.md) или фильтры для сужения вашего списка, затем выберите всех соответствующих людей.
:::

## Доступные массовые действия

Меню **Bulk Actions** предоставляет несколько опций:

### Обновить статус членства

Обновляйте статус членства для всех выбранных людей:

1. Нажмите **Bulk Actions** → **Set Membership Status**
2. Выберите новый статус:
   - **Visitor** — первичные или случайные посещаю щие
   - **Regular Attendee** — частые посетители, которые не являются членами
   - **Member** — официальные члены церкви
   - **Staff** — персонал церкви
   - **Inactive** — люди, которые больше не посещают
3. Выберите режим обновления:
   - **Overwrite all** — замените текущий статус для всех выбранных людей
   - **Only update empty** — установите статус только для людей, у которых его нет
4. Нажмите **Update**

### Обновить семейное положение

Обновляйте семейное положение в массовом порядке:

1. Нажмите **Bulk Actions** → **Set Marital Status**
2. Выберите новый статус:
   - **Unknown**
   - **Single**
   - **Married**
   - **Divorced**
   - **Widowed**
3. Выберите, перезаписывать ли существующие значения или только обновлять пустые поля
4. Нажмите **Update**

### Обновить пол

Обновляйте информацию о поле для нескольких людей:

1. Нажмите **Bulk Actions** → **Set Gender**
2. Выберите значение:
   - **Unspecified**
   - **Male**
   - **Female**
3. Выберите режим обновления (перезапись всех или только пустых)
4. Нажмите **Update**

### Обновить статус отказа от коммуникаций

Контролируйте, отказались ли люди от коммуникаций:

1. Нажмите **Bulk Actions** → **Set Opted Out**
2. Выберите:
   - **No** — разрешить коммуникации (удалить отказ)
   - **Yes** — блокировать коммуникации (установить отказ)
3. Выберите режим обновления
4. Нажмите **Update**

:::warning
Будьте осторожны при изменении статуса отказа. Люди, которые явно отказались, не должны получать коммуникации, если они не дали нового согласия.
:::

### Установить пользовательское поле

Установите значение пользовательского поля Yes/No [custom field](../settings/custom-fields.md) для всех выбранных людей сразу:

1. Нажмите **Bulk Actions** → **Set Custom Field**.
2. Выберите пользовательское поле Yes/No, которое вы хотите установить.
3. Выберите значение (**Yes** или **No**) для применения.
4. Нажмите **Update**.

:::info
Для этого массового действия доступны только пользовательские поля Yes/No. Чтобы установить другие типы полей, редактируйте каждого человека отдельно.
:::

### Добавить в группу

Добавьте всех выбранных людей в одну или несколько групп:

1. Нажмите **Bulk Actions** → **Add to Group**
2. Найдите и выберите группы для добавления людей
3. Вы можете выбрать несколько групп для добавления людей во все них
4. Нажмите **Add to Groups**

Каждый человек будет добавлен как обычный член выбранных групп. Позже вы можете повысить отдельных людей до лидеров групп со страницы [Group Members](../groups/group-members.md).

### Удалить из группы

Удалите всех выбранных людей из одной или нескольких групп:

1. Нажмите **Bulk Actions** → **Remove from Group**
2. Найдите и выберите группы для удаления людей из них
3. Вы можете выбрать несколько групп
4. Нажмите **Remove from Groups**

:::info
Это действие только удаляет людей из указанных групп. Оно не удаляет их записи о людях.
:::

### Удалить людей

Окончательно удалите выбранных людей из базы данных вашей церкви:

1. Нажмите **Bulk Actions** → **Delete**
2. Просмотрите список людей, которые будут удалены
3. Введите **DELETE** в поле подтверждения
4. Нажмите **Confirm Delete**

:::danger
Удаление людей является постоянным и не может быть отменено. Это удалит все их данные, включая:
- Личную информацию
- Членство в группах
- Записи о посещаемости
- История пожертвований
- Отправки форм

Используйте это действие только если вы абсолютно уверены, что хотите удалить этих людей из вашей системы.
:::

## Результаты массового редактирования

После завершения массового действия вы увидите сводку, показывающую:

- **Total selected** — сколько людей включены в операцию
- **Successfully updated** — сколько записей было изменено
- **Failed** — все записи, которые не удалось обновить (если применимо)
- **Unchanged** — записи, которые не нуждались в изменениях (например, при использовании режима "only update empty")

Если какие-либо обновления не удались, вы увидите детали ошибки, объясняющие почему.

## Лучшие практики

- **Начните с малого** — сначала протестируйте массовые операции на нескольких записях, чтобы убедиться, что вы делаете правильные изменения
- **Используйте фильтры** — сузьте ваш список с помощью фильтров или AI поиска перед выбором людей, чтобы убедиться, что вы обновляете только правильные люди
- **Дважды проверьте выборы** — просмотрите выбранных людей перед применением массовых изменений
- **Используйте режим "only update empty"** — когда вы хотите заполнить пропущенные данные без перезаписи существующей информации
- **Задокументируйте основные изменения** — ведите записи об обновлениях в массовом порядке на случай, если вам потребуется обратиться к ним позже
- **Координируйте с вашей командой** — дайте другим администраторам знать, когда вы делаете крупные массовые изменения

## Типичные варианты использования

### Обновление новых членов

После класса членства обновите всех участников на статус Member:

1. Найдите людей, которые посещали класс
2. Выберите их всех
3. Используйте **Bulk Actions** → **Set Membership Status** → **Member**

### Организация небольших групп

Добавьте нескольких людей в новую небольшую группу:

1. Найдите людей, которых вы хотите в группе
2. Выберите их
3. Используйте **Bulk Actions** → **Add to Group** и выберите небольшую группу

### Очистка данных

Заполните пропущенное семейное положение для супружеских пар:

1. Отфильтруйте людей, которые женаты (используя информацию о хозяйстве)
2. Выберите тех, у которых пусто семейное положение
3. Используйте **Bulk Actions** → **Set Marital Status** → **Married** → **Only update empty**
