# Поиск людей

<div class="article-intro">

Страница **People** показывает каталог вашей церкви в виде поискового списка домохозяйств или сортируемой таблицы отдельных людей. Вы можете быстро найти любого члена общины, выбрать, какие сведения показывать, и экспортировать результаты. Эффективный поиск необходим для повседневных задач администрирования церкви: связи с посетителями, подготовки списков контактов и ведения записей об участниках.

## Домохозяйства и табличный вид

Страница People выводит ваш каталог по **домохозяйствам**, сгруппированным по алфавиту. В каждой строке показаны фото домохозяйства, его название (например, «The Smith Family») и имена всех его членов. Нажмите на домохозяйство, чтобы открыть профиль главы домохозяйства, или на имя любого члена, чтобы открыть его профиль. Над списком указано, сколько домохозяйств и людей показано.

Переключатель **View as** над списком позволяет переключаться между **Households** и **Table**. Вид **Table** показывает одного человека в строке, и именно здесь можно сортировать и выбирать столбцы (см. ниже). B1 запоминает ваш выбор на этом устройстве.

В виде **Table** статус членства каждого человека отображается под его именем, и у каждого из семи статусов свой цвет -- тот же, что и в профиле человека. Тот, кому назначена роль в домохозяйстве **Child**, также получает метку **Child** рядом со статусом. Чтобы отметить человека как ребёнка, задайте его роль в [панели домохозяйства](./adding-people.md#managing-households) в его профиле.

По умолчанию страница загружает первую часть вашего каталога. Если людей больше, нажмите **Show All Members** под списком, чтобы загрузить всех.

## Быстрый поиск

Поле **Find a household or person** вверху страницы People позволяет искать участников в режиме реального времени:

1. Нажмите на **поле поиска** вверху страницы People.
2. Начните вводить имя.
3. Результаты будут фильтроваться автоматически по мере ввода (небольшая задержка около полсекунды, чтобы поиск не запускался при каждом нажатии клавиши).
4. Список ниже обновится и покажет только подходящие результаты.

Нажмите **Clear** (под полем поиска), чтобы сбросить поиск и снова показать весь каталог.

:::tip
Нажимать Enter не нужно. Поиск запускается автоматически, как только вы перестаёте печатать.
:::

## Сортировка результатов

В виде **Table** люди перечислены по фамилии, затем по имени. Вы можете отсортировать каталог иначе, нажав на любой заголовок столбца:

1. Нажмите на **заголовок столбца** (например, **Name** или **Email**), чтобы отсортировать по этому столбцу.
2. Нажмите на тот же заголовок ещё раз, чтобы поменять порядок сортировки на обратный.

Так легко найти людей по алфавиту, по возрасту или по любому другому видимому столбцу.

## Настройка столбцов

Не всю информацию нужно видеть сразу. Вы можете выбрать, какие столбцы отображаются в таблице:

1. Нажмите на значок **Select columns** в заголовке страницы People. (Столбцы применяются к виду **Table**.)
2. Отмечайте или снимайте отметки со столбцов, чтобы показать или скрыть их. Доступны следующие столбцы:
   - **Photo**
   - **Name**
   - **Email**
   - **Phone**
   - **Address**
   - **Birth Date**
   - **Age**
   - **Gender**
   - **Membership Status**
   - **Campus**
   - **Date Added** -- когда была создана запись о человеке
3. Таблица сразу обновляется в соответствии с вашим выбором. Нажмите **Done**, чтобы закрыть диалог **Select Columns**.

### Показ пользовательских полей как столбцов {#showing-custom-fields-as-columns}

В выборе столбцов есть две вкладки: **Standard** содержит встроенные столбцы, перечисленные выше, а **Custom** содержит ваши [пользовательские поля](../settings/custom-fields.md), а также вопросы из любых форм People. Отметьте пользовательское поле на вкладке **Custom**, чтобы добавить его как столбец, и значение этого поля для каждого человека появится в таблице. Значения отображаются так же, как в профиле человека: поля «да/нет» показывают *Yes* или *No*, поля с выбором показывают название варианта, а даты -- в коротком формате. У людей без значения в этом поле ячейка пустая.

## Экспорт результатов поиска

Вы можете в любой момент скачать текущие результаты поиска в виде CSV-файла:

1. Примените любой нужный поиск или фильтры.
2. Нажмите кнопку **Export** в заголовке страницы People.
3. На ваш компьютер скачается CSV-файл, который можно открыть в Excel, Google Sheets или любой программе для работы с таблицами.

Подробнее об экспорте см. в разделе [Экспорт данных](./exporting-data.md).

:::tip
Для более сложных запросов -- например, чтобы найти всех, кто не приходил последние три месяца, -- попробуйте функцию [AI Search](./ai-search.md), которая позволяет искать с помощью вопросов на обычном языке.
:::

## Расширенный поиск {#advanced-search}

Расширенный поиск позволяет создавать точные фильтры, комбинируя условия. Чтобы открыть его, нажмите **Advanced** под полем поиска на странице People, затем разверните категорию и отметьте поля, по которым хотите фильтровать (можно нажать на название поля или на его флажок), выбрав оператор и значение для каждого. Категории включают **Names**, **Demographics**, **Contact**, **Membership**, **Activity** (пожертвования и посещаемость) и **Custom Fields**.

Чтобы найти новых людей, откройте **Membership** и отметьте **Date Added**. По умолчанию выбрано **in the last N days** с числом 30, так что всех, добавленных за последний месяц, можно найти в один клик; измените количество дней или переключитесь на *equals / after / before*, чтобы выбрать дату. **Birth Date** и **Anniversary** также предлагают **in the last N days**. Дата **Date Added** записывается только для людей, созданных начиная с конца октября 2026 года; у людей, добавленных раньше, даты нет, поэтому этот фильтр их не найдёт.

Категория **Custom Fields** перечисляет [пользовательские поля](../settings/custom-fields.md) вашей церкви -- поля, которые вы определяете в настройках для учёта собственных сведений (например, даты истечения проверки биографии). Доступные операторы соответствуют типу каждого поля: текстовые поля поддерживают *contains / equals / starts with / ends with*, числовые поля -- операторы сравнения, поля дат -- *equals / after / before*, а поля «да/нет» и с выбором позволяют выбрать значение. Любое поле, по которому можно фильтровать здесь, можно сохранить как действующий [список](./lists.md).

## Сохранение поиска в виде списков

После выполнения поиска в заголовке страницы People появляется кнопка **Save as List**. Нажмите её, чтобы сохранить текущий запрос под названием и, при желании, в категории, и в будущих сеансах быстро загружать его снова. Подробности см. в разделе [Сохранённые списки](./lists.md).
