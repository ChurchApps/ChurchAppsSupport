# Поиск людей

<div class="article-intro">

Страница **Люди** отображает справочник вашей церкви в виде таблицы с возможностью поиска и сортировки. Вы можете быстро найти любого человека в вашей конгрегации, настроить отображаемую информацию и экспортировать результаты. Эффективный поиск необходим для повседневных административных задач церкви, таких как работа с гостями, подготовка контактных списков и ведение записей участников.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Вам нужна активная учетная запись B1 Admin с правом просмотра людей. См. [Роли и права доступа](roles-permissions.md), если вы не уверены в уровне своего доступа.
- В справочнике вашей церкви должны быть люди. Если вы еще никого не добавили, см. [Добавление людей](adding-people.md) или [Импорт данных](importing-data.md).

</div>

## Быстрый поиск

Строка поиска вверху страницы «Люди» позволяет находить участников в режиме реального времени:

1. Нажмите на **поле поиска** вверху страницы «Люди».
2. Начните вводить имя, email или другое ключевое слово.
3. Результаты будут фильтроваться автоматически по мере ввода (есть небольшая задержка около половины секунды, чтобы поиск не выполнялся на каждое нажатие клавиши).
4. Таблица ниже обновится, показывая только совпадающие результаты.

:::tip
Вам не нужно нажимать Enter. Поиск запускается автоматически после того, как вы перестаете печатать.
:::

## Сортировка результатов

Вы можете сортировать справочник, нажимая на любой заголовок столбца в таблице:

1. Нажмите на **заголовок столбца** (например, **Имя** или **Email**), чтобы отсортировать по этому столбцу.
2. Нажмите на тот же заголовок еще раз, чтобы изменить порядок сортировки на обратный.

Это упрощает поиск людей в алфавитном порядке, по возрасту или по любому другому видимому столбцу.

## Настройка столбцов

Не вся информация должна быть видна одновременно. Вы можете выбрать, какие столбцы отображаются в таблице:

1. Найдите выпадающий список **выбора столбцов** рядом с верхней частью таблицы.
2. Отметьте или снимите отметку со столбцов, чтобы показать или скрыть их. Доступные столбцы включают:
   - **Фото**
   - **Имя**
   - **Email**
   - **Телефон**
   - **Адрес**
   - **Дата рождения**
   - **Возраст**
   - **Пол**
   - **Статус членства**
   - **Кампус**
3. Таблица немедленно обновится, отражая ваш выбор.

:::info
Ваш выбор столбцов влияет на то, что включается при экспорте в CSV. Настройте столбцы перед экспортом, чтобы получить именно те данные, которые вам нужны.
:::

## Постраничная навигация

Когда в вашем справочнике много записей, результаты разбиваются на страницы. Используйте элементы **постраничной навигации** внизу таблицы для перемещения между страницами. Текущая страница и общее число записей отображаются, чтобы вы всегда знали, где находитесь в списке.

:::tip
Если вы хотите увидеть больше результатов сразу, уточните поиск, чтобы сузить список, а не листать большой справочник.
:::

## Экспорт результатов поиска

Вы можете в любое время скачать текущие результаты поиска в виде CSV-файла:

1. Примените любой поиск или фильтры, которые вам нужны.
2. Настройте столбцы, чтобы включить нужные данные.
3. Нажмите кнопку **Экспорт**.
4. CSV-файл будет скачан на ваш компьютер, готовый к открытию в Excel, Google Sheets или любом другом приложении для работы с таблицами.

Подробнее об экспорте см. в разделе [Экспорт данных](./exporting-data.md).

:::tip
Для более сложных запросов -- например, чтобы найти всех, кто не посещал церковь последние три месяца -- попробуйте функцию [ИИ-поиск](./ai-search.md), которая позволяет искать с помощью вопросов на обычном языке.
:::

## Расширенный поиск

Расширенный поиск позволяет строить точные фильтры, комбинируя условия. Откройте его со страницы «Люди», затем разверните категорию и отметьте поля, по которым хотите фильтровать, выбрав оператор и значение для каждого. Категории включают **Имена**, **Демография**, **Контакты**, **Членство**, **Активность** (пожертвования и посещаемость) и **Пользовательские поля**.

Категория **Пользовательские поля** перечисляет [пользовательские поля](../settings/custom-fields.md) вашей церкви — поля, которые вы определяете в настройках для отслеживания собственной информации (такой как дата истечения проверки биографии). Предлагаемые операторы соответствуют типу каждого поля: текстовые поля поддерживают *содержит / равно / начинается с / заканчивается на*, числовые поля поддерживают операторы сравнения, поля даты поддерживают *равно / после / до*, а поля «да/нет» и «множественный выбор» позволяют выбрать значение. Любое поле, которое можно здесь отфильтровать, можно сохранить как живой [список](./lists.md).

## Сохранение поисков как списков

После выполнения поиска в заголовке страницы «Люди» появляется кнопка **Сохранить как список** (значок закладки). Нажмите ее, чтобы сохранить текущий запрос под именем и, по желанию, категорией, чтобы можно было мгновенно загружать его в будущих сеансах. Полные сведения см. в разделе [Сохраненные списки](./lists.md).
