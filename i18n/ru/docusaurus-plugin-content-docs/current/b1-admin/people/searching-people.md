# Поиск людей

<div class="article-intro">

Страница **People** показывает каталог церкви в виде списка домохозяйств с поиском или в виде таблицы с сортировкой по отдельным людям. Вы можете быстро найти любого человека в своей общине, настроить, какая информация отображается, и экспортировать результаты. Эффективный поиск необходим для повседневной административной работы: контакта с гостями, подготовки списков контактов и ведения записей об участниках.

## Домохозяйства и табличный вид

Страница People показывает каталог по **домохозяйствам**, сгруппированным по алфавиту. В каждой строке отображаются фото домохозяйства, его название (например, «Семья Смит») и имена всех его членов. Нажмите на домохозяйство, чтобы открыть профиль главы домохозяйства, или нажмите на имя любого члена семьи, чтобы открыть его профиль. Над списком показано количество отображаемых домохозяйств и людей.

Используйте переключатель **View as** над списком, чтобы переключаться между **Households** и **Table**. Вид **Table** показывает одного человека в строке, и именно там можно сортировать данные и выбирать столбцы (см. ниже). B1 запоминает ваш выбор на этом устройстве.

По умолчанию страница загружает первую часть вашего каталога. Если людей больше, нажмите **Show All Members** под списком, чтобы загрузить всех.

## Быстрый поиск

Поле **Find a household or person** вверху страницы People позволяет искать участников в реальном времени:

1. Нажмите на **поле поиска** вверху страницы People.
2. Начните вводить имя.
3. Результаты будут фильтроваться автоматически по мере ввода (есть небольшая задержка около полсекунды, чтобы поиск не запускался на каждое нажатие клавиши).
4. Список ниже обновится и покажет только подходящие результаты.

Нажмите **Clear** (под полем поиска), чтобы сбросить поиск и снова показать весь каталог.

:::tip
Нажимать Enter не нужно. Поиск запускается автоматически, когда вы перестаёте печатать.
:::

## Сортировка результатов

В виде **Table** люди перечислены по фамилии, затем по имени. Отсортировать каталог иначе можно, нажав на любой заголовок столбца:

1. Нажмите на **заголовок столбца** (например, **Name** или **Email**), чтобы отсортировать по этому столбцу.
2. Нажмите на тот же заголовок ещё раз, чтобы изменить порядок сортировки на обратный.

Так удобно искать людей по алфавиту, по возрасту или по любому другому видимому столбцу.

## Настройка столбцов

Не вся информация должна быть видна одновременно. Вы можете выбрать, какие столбцы отображаются в таблице:

1. Нажмите значок **Select columns** в заголовке страницы People. (Столбцы относятся к виду **Table**.)
2. Отметьте или снимите отметку со столбцов, чтобы показать или скрыть их. Доступны следующие столбцы:
   - **Photo**
   - **Name**
   - **Email**
   - **Phone**
   - **Address**
   - **Birth Date**
   - **Age**
   - **Gender**
   - **Membership Status**
   - **Campus**
   - **Date Added** — когда была создана запись о человеке
3. Таблица сразу обновляется в соответствии с вашим выбором. Нажмите **Done**, чтобы закрыть диалог **Select Columns**.

### Пользовательские поля как столбцы

В выборе столбцов есть две вкладки: **Standard** содержит встроенные столбцы, перечисленные выше, а **Custom** содержит [Custom Fields](../settings/custom-fields.md) вашей церкви, а также вопросы из любых форм для людей. Отметьте пользовательское поле на вкладке **Custom**, чтобы добавить его как столбец, и значение каждого человека для этого поля появится в таблице. Значения показываются так же, как в профиле человека: поля Yes/No выводят *Yes* или *No*, поля Multiple Choice — название варианта, а даты — в коротком формате. У людей без значения для поля ячейка остаётся пустой.

## Экспорт результатов поиска

Вы можете в любой момент скачать текущие результаты поиска в виде файла CSV:

1. Примените любой нужный поиск или фильтры.
2. Нажмите кнопку **Export** в заголовке страницы People.
3. CSV-файл скачается на ваш компьютер, его можно открыть в Excel, Google Sheets или любом другом приложении для таблиц.

Подробнее об экспорте см. [Экспорт данных](./exporting-data.md).

:::tip
Для более сложных запросов — например, чтобы найти всех, кто не приходил последние три месяца, — попробуйте функцию [AI Search](./ai-search.md), которая позволяет искать с помощью вопросов на обычном языке.
:::

## Расширенный поиск

Advanced Search позволяет создавать точные фильтры, комбинируя условия. Откройте его, нажав **Advanced** под полем поиска на странице People, затем разверните категорию и отметьте поля, по которым хотите фильтровать (можно нажать на название поля или на его флажок), выбирая для каждого оператор и значение. Категории включают **Names**, **Demographics**, **Contact**, **Membership**, **Activity** (пожертвования и посещаемость) и **Custom Fields**.

Чтобы найти новых людей, откройте **Membership** и отметьте **Date Added**. По умолчанию выбрано **in the last N days** с числом 30, так что всех, добавленных за последний месяц, можно найти одним нажатием; измените количество дней или переключитесь на *equals / after / before*, чтобы выбрать дату. **Birth Date** и **Anniversary** также предлагают **in the last N days». Date Added записывается только для людей, созданных с конца октября 2026 года; у людей, добавленных раньше, даты нет, поэтому этот фильтр их не найдёт.

Категория **Custom Fields** перечисляет [Custom Fields](../settings/custom-fields.md) вашей церкви — поля, которые вы определяете в Settings для учёта собственных данных (например, даты истечения проверки на судимость). Доступные операторы соответствуют типу каждого поля: текстовые поля поддерживают *contains / equals / starts with / ends with*, числовые поля — операторы сравнения, поля дат — *equals / after / before*, а поля Yes/No и Multiple Choice позволяют выбрать значение. Любое поле, по которому здесь можно фильтровать, можно сохранить как действующий [List](./lists.md).

## Сохранение поиска как списка

После выполнения поиска в заголовке страницы People появляется кнопка **Save as List**. Нажмите её, чтобы сохранить текущий запрос под названием и необязательной категорией, и вы сможете быстро загрузить его в будущих сеансах. Подробности см. в [Saved Lists](./lists.md).
