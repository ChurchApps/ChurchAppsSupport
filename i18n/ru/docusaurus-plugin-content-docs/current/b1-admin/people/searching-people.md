# Поиск людей

<div class="article-intro">

Страница **People** показывает каталог вашей церкви в виде списка домохозяйств с возможностью поиска или в виде сортируемой таблицы отдельных людей. Вы можете быстро найти любого члена общины, настроить, какая информация отображается, и экспортировать результаты. Эффективный поиск необходим для повседневной работы церкви: связи с гостями, подготовки контактных списков и ведения записей о членах.

## Домохозяйства и табличный вид

Страница People показывает ваш каталог по **домохозяйствам**, сгруппированным по алфавиту. В каждой строке отображаются фото домохозяйства, его название (например, «The Smith Family») и имена всех его членов. Нажмите на домохозяйство, чтобы открыть профиль главы семьи, или на имя любого участника, чтобы открыть его профиль. Над списком отображается счётчик с количеством показанных домохозяйств и людей.

С помощью переключателя **View as** над списком можно переключаться между **Households** и **Table**. В виде **Table** каждый человек занимает отдельную строку; здесь же можно сортировать и выбирать столбцы (см. ниже). B1 запоминает ваш выбор на этом устройстве.

По умолчанию страница загружает первую часть каталога. Если людей больше, нажмите **Show All Members** под списком, чтобы загрузить всех.

## Быстрый поиск

Поле **Find a household or person** вверху страницы People позволяет находить участников в реальном времени:

1. Нажмите **поле поиска** в верхней части страницы People.
2. Начните вводить имя.
3. Результаты будут фильтроваться автоматически по мере ввода (есть небольшая задержка около полсекунды, чтобы поиск не запускался на каждое нажатие клавиши).
4. Список ниже обновится и покажет только подходящие результаты.

Нажмите **Clear** (под полем поиска), чтобы сбросить поиск и снова показать весь каталог.

:::tip
Нажимать Enter не нужно. Поиск запускается автоматически, как только вы перестаёте печатать.
:::

## Сортировка результатов

В виде **Table** люди перечислены по фамилии, затем по имени. Чтобы отсортировать каталог иначе, нажмите на заголовок любого столбца:

1. Нажмите **заголовок столбца** (например, **Name** или **Email**), чтобы отсортировать по этому столбцу.
2. Нажмите на тот же заголовок ещё раз, чтобы изменить порядок сортировки на обратный.

Так легко найти людей по алфавиту, по возрасту или по любому другому видимому столбцу.

## Настройка столбцов

Не вся информация должна быть видна сразу. Можно выбрать, какие столбцы отображать в таблице:

1. Нажмите значок **Select columns** в заголовке страницы People. (Столбцы применяются к виду **Table**.)
2. Отмечайте или снимайте отметки со столбцов, чтобы показать или скрыть их. Доступны следующие столбцы:
   - **Photo**
   - **Name**
   - **Email**
   - **Phone**
   - **Address**
   - **Birth Date**
   - **Age**
   - **Gender**
   - **Membership Status**
   - **Campus**
3. Таблица сразу обновится в соответствии с вашим выбором. Нажмите **Done**, чтобы закрыть диалог **Select Columns**.

### Показ пользовательских полей как столбцов

В выборе столбцов есть две вкладки: **Standard** содержит встроенные столбцы, перечисленные выше, а **Custom** — ваши [пользовательские поля](../settings/custom-fields.md), а также вопросы из любых форм People. Отметьте пользовательское поле на вкладке **Custom**, чтобы добавить его как столбец; значение этого поля для каждого человека появится в таблице. Значения отображаются так же, как в профиле человека: поля «да/нет» показывают *Yes* или *No*, поля с выбором из нескольких вариантов показывают подпись варианта, а даты отображаются в коротком формате. У людей без значения для этого поля ячейка пустая.


## Экспорт результатов поиска

Текущие результаты поиска можно в любой момент скачать как CSV-файл:

1. Примените нужные поиск или фильтры.
2. Нажмите кнопку **Export** в заголовке страницы People.
3. CSV-файл загрузится на ваш компьютер и будет готов к открытию в Excel, Google Sheets или любом другом приложении для таблиц.

Подробнее об экспорте см. [Экспорт данных](./exporting-data.md).

:::tip
Для более сложных запросов, например чтобы найти всех, кто не приходил последние три месяца, попробуйте функцию [AI Search](./ai-search.md), которая позволяет искать с помощью вопросов на обычном языке.
:::

## Расширенный поиск

Расширенный поиск позволяет создавать точные фильтры, комбинируя условия. Чтобы открыть его, нажмите **Advanced** под строкой поиска на странице People, затем разверните нужную категорию и отметьте поля, по которым хотите фильтровать (можно нажать на название поля или на его флажок), выбрав оператор и значение для каждого из них. Категории включают **Names**, **Demographics**, **Contact**, **Membership**, **Activity** (пожертвования и посещаемость) и **Custom Fields**.

Категория **Custom Fields** перечисляет [пользовательские поля](../settings/custom-fields.md) вашей церкви — те, которые вы задаёте в Settings, чтобы отслеживать собственную информацию (например, дату истечения срока проверки биографических данных). Доступные операторы соответствуют типу каждого поля: текстовые поля поддерживают *contains / equals / starts with / ends with*, числовые — операторы сравнения, поля дат — *equals / after / before*, а поля «да/нет» и с выбором из нескольких вариантов позволяют выбрать значение. Любое поле, по которому здесь можно фильтровать, можно сохранить как действующий [список](./lists.md).

## Сохранение поиска как списка

После выполнения поиска в заголовке страницы People появляется кнопка **Save as List**. Нажмите её, чтобы сохранить текущий запрос под именем и, при желании, категорией, чтобы в будущих сессиях быстро открывать его снова. Подробнее см. [Сохранённые списки](./lists.md).
