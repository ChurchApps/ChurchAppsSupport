# Поиск людей

<div class="article-intro">

Страница **People** показывает каталог вашей церкви в виде списка домохозяйств с возможностью поиска или в виде таблицы с сортировкой по отдельным людям. Вы можете быстро найти любого члена общины, настроить, какая информация отображается, и экспортировать результаты. Эффективный поиск необходим для повседневной работы администратора церкви: связи с гостями, подготовки контактных списков и управления карточками участников.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Нужна активная учетная запись B1 Admin с правом на просмотр людей. Если вы не уверены в своем уровне доступа, см. [Роли и разрешения](roles-permissions.md).
- В каталоге церкви должны быть люди. Если вы еще никого не добавили, см. [Добавление людей](adding-people.md) или [Импорт данных](importing-data.md).

</div>

## Представления по домохозяйствам и таблица

Страница People выводит каталог по **домохозяйствам**, сгруппированным по алфавиту. В каждой строке показаны фото домохозяйства, его название (например, «The Smith Family») и имена всех его членов. Нажмите на домохозяйство, чтобы открыть профиль главы домохозяйства, или нажмите на имя любого члена, чтобы открыть его профиль. Над списком отображается счетчик домохозяйств и людей.

Используйте переключатель **View as** над списком, чтобы переключаться между **Households** и **Table**. Представление **Table** показывает одного человека в строке, и здесь можно сортировать и выбирать столбцы (см. ниже). B1 запоминает ваш выбор на этом устройстве.

По умолчанию страница загружает первую часть каталога. Если людей больше, нажмите **Show All Members** под списком, чтобы загрузить всех.

## Быстрый поиск

Поле **Find a household or person** вверху страницы People позволяет находить участников в режиме реального времени:

1. Нажмите на **поле поиска** вверху страницы People.
2. Начните вводить имя.
3. Результаты будут фильтроваться автоматически по мере ввода (есть небольшая задержка около полсекунды, чтобы поиск не запускался на каждое нажатие клавиши).
4. Список ниже обновится и покажет только подходящие результаты.

Нажмите **Clear** (под полем поиска), чтобы сбросить поиск и снова показать весь каталог.

:::tip
Нажимать Enter не нужно. Поиск выполняется автоматически, когда вы перестаете печатать.
:::

## Сортировка результатов

В представлении **Table** люди перечислены по фамилии, затем по имени. Вы можете отсортировать каталог иначе, нажав на любой заголовок столбца:

1. Нажмите на **заголовок столбца** (например, **Name** или **Email**), чтобы отсортировать по этому столбцу.
2. Нажмите на тот же заголовок еще раз, чтобы изменить порядок сортировки на обратный.

Так легко найти людей по алфавиту, по возрасту или по любому другому видимому столбцу.

## Настройка столбцов

Не вся информация должна быть видна одновременно. Вы можете выбрать, какие столбцы показывать в таблице:

1. Нажмите значок **Select columns** в заголовке страницы People. (Столбцы применяются к представлению **Table**.)
2. Отмечайте или снимайте отметки с столбцов, чтобы показать или скрыть их. Доступны следующие столбцы:
   - **Photo**
   - **Name**
   - **Email**
   - **Phone**
   - **Address**
   - **Birth Date**
   - **Age**
   - **Gender**
   - **Membership Status**
   - **Campus**
3. Таблица сразу обновится в соответствии с вашим выбором.

### Показ пользовательских полей как столбцов {#showing-custom-fields-as-columns}

В окне выбора столбцов две вкладки: **Standard** содержит встроенные столбцы, перечисленные выше, а **Custom** содержит [пользовательские поля](../settings/custom-fields.md) вашей церкви, а также вопросы из любых форм для людей. Отметьте пользовательское поле на вкладке **Custom**, чтобы добавить его как столбец; значение каждого человека для этого поля появится в таблице. Значения отображаются так же, как в профиле человека: поля Да/Нет показывают *Yes* или *No*, поля с множественным выбором показывают название варианта, а даты отображаются в коротком формате. У людей без значения в этом поле ячейка будет пустой.


## Экспорт результатов поиска

Вы можете в любой момент скачать текущие результаты поиска в виде CSV-файла:

1. Примените нужные поиск или фильтры.
2. Нажмите кнопку **Export** в заголовке страницы People.
3. CSV-файл будет скачан на ваш компьютер, его можно открыть в Excel, Google Sheets или любой другой программе для работы с таблицами.

Подробнее об экспорте см. [Экспорт данных](./exporting-data.md).

:::tip
Для более сложных запросов — например, чтобы найти всех, кто не приходил последние три месяца, — попробуйте функцию [AI Search](./ai-search.md), которая позволяет искать с помощью вопросов на обычном языке.
:::

## Расширенный поиск {#advanced-search}

Расширенный поиск позволяет создавать точные фильтры, комбинируя условия. Откройте его, нажав **Advanced** под полем поиска на странице People, затем раскройте категорию и отметьте нужные поля, выбрав для каждого оператор и значение. Категории включают **Names**, **Demographics**, **Contact**, **Membership**, **Activity** (пожертвования и посещаемость) и **Custom Fields**.

Категория **Custom Fields** содержит [пользовательские поля](../settings/custom-fields.md) вашей церкви — поля, которые вы определяете в настройках, чтобы отслеживать собственную информацию (например, дату окончания проверки биографических данных). Доступные операторы соответствуют типу каждого поля: текстовые поля поддерживают *contains / equals / starts with / ends with* (содержит / равно / начинается с / заканчивается на), числовые поля поддерживают операторы сравнения, поля дат — *equals / after / before* (равно / после / до), а поля Да/Нет и с множественным выбором позволяют выбрать значение. Любое поле, по которому здесь можно фильтровать, можно сохранить как действующий [список](./lists.md).

## Сохранение поисков как списков

После выполнения поиска в заголовке страницы People появляется кнопка **Save as List**. Нажмите её, чтобы сохранить текущий запрос под названием и, при желании, категорией, — тогда его можно будет быстро открыть в следующих сессиях. Подробнее см. [Сохраненные списки](./lists.md).
