# Печать справочника

<div class="article-intro">

Функция Print Directory создает форматированный, печатный справочник членов для вашей церкви. Он организует членов по домохозяйству, включает контактную информацию и фотографии и разработан для профессионального вида при печати на стандартной бумаге размером Letter.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужна активная учетная запись B1 Admin с разрешением на просмотр людей.
- Люди в вашем справочнике должны иметь заполненные фотографии и контактную информацию для лучших результатов.

</div>

## Открытие справочника печати

1. Перейдите к **People** в B1 Admin.
2. Щелкните **значок печати** (значок принтера) на панели инструментов в верхней части карточки результатов People. Он появляется рядом с кнопкой Export.
3. Print Directory откроется в новой вкладке браузера и начнет загружать данные справочника.
4. Примерно через 1,5 секунды автоматически появится диалог печати браузера.

:::tip
Справочник открывается в отдельной вкладке, чтобы вы могли его распечатать, не покидая страницу People. После появления диалога печати вкладка автоматически переходит назад.
:::

## Что входит

Печатный справочник включает всех **активных членов** вашей церкви. В частности:

- Люди со статусом членства **Inactive** или **Visitor** автоматически исключаются.
- Люди, которые **выбрали отказ** от справочника, исключаются.
- Все остальные сгруппированы по **домохозяйству**.

### Печать только результатов поиска

После того как вы выполните поиск на странице People — быстрый поиск, [Advanced Search](./searching-people.md#advanced-search), [Saved List](./lists.md) или [AI Search](./ai-search.md) — значок печати изменяется на **Print Results**. Щелкнув на нём, вы печатаете справочник только людей в ваших результатах вместо всей церкви, используя одинаковый макет.

При печати результатов поиска фильтр статуса членства выше не применяется: все люди, которых вы искали, включены, даже Visitors или Inactive люди. Люди, которые выбрали отказ от справочника, все равно исключаются. Чтобы вернуться к печати полного справочника, сначала очистите поиск.

## Макет справочника

Печатный справочник состоит из двух частей:

### Обложка

Первая страница включает:
- Имя вашей церкви
- Название "Member Directory"
- Текущий год
- Местоположение вашей церкви
- Подсчет общего количества включенных домохозяйств

### Списки членов

Остальные страницы перечисляют домохозяйства в алфавитном порядке по фамилии. Каждая карточка домохозяйства показывает:

- **Фотографии** — круглые миниатюры для каждого члена домохозяйства с их именем внизу
- **Имя домохозяйства** — например "The Smith Family", "John & Jane Doe" или просто имя человека для отдельных лиц
- **Адрес** — улица, город, штат и почтовый индекс
- **Телефон** — домашний или мобильный номер
- **Email** — основной адрес электронной почты
- **Дни рождения** — отформатированы в виде отдельных дат для каждого члена домохозяйства
- **Годовщина** — если записана

Домохозяйства организованы в **алфавитных разделы** (A, B, C, ...) с декоративным заголовком раздела перед каждой группой букв. На каждой строке две карточки домохозяйства выглядят рядом.

## Параметры печати

Справочник отформатирован для **бумаги размером Letter** (8,5" × 11") с полями 0,5 дюйма. Когда появляется диалог печати браузера:

- Оставьте размер бумаги установленным на **Letter**
- Включите **Background graphics** (иногда называется "Print backgrounds") в параметрах печати браузера, если вы хотите, чтобы заголовки разделов печатались с их цветовым стилем
- Рекомендуется портретная ориентация

:::info
Справочник соблюдает разрывы страниц — карточки домохозяйства и заголовки разделов не будут разбиты на страницах.
:::
