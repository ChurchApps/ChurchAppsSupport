# Печать справочника

<div class="article-intro">

B1 Admin позволяет вам создавать и печатать красиво отформатированный справочник членов вашей церкви. Выберите, кого включить, настройте форматирование и распечатайте копию для раздачи вашей общине.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Люди должны существовать в вашем справочнике. Для начала см. [Добавление людей](./adding-people.md).
- Убедитесь, что люди имеют основную информацию (имя, адрес, номер телефона), которую вы хотите печатать.

</div>

## Создание справочника

1. Перейдите на страницу **People** в B1 Admin.
2. Используйте фильтры для выбора, кого включить (например, только членов, исключение неактивных).
3. Нажмите кнопку **Print Directory** в верхней части страницы.
4. Это откроет предпросмотр вашего справочника.

## Настройка параметров печати

В предпросмотре справочника вы можете настроить:

- **Title** — имя справочника (например, "Grace Church Directory")
- **Include photos** — показывать ли фотографии членов
- **Include phone** — показывать ли номера телефонов
- **Include email** — показывать ли адреса электронной почты
- **Include addresses** — показывать ли физические адреса
- **Sort by** — как упорядочивать записи (по фамилии, имени или кампусу)
- **Columns** — сколько столбцов информации показывать на странице

После изменения параметров предпросмотр обновляется автоматически.

## Печать справочника

1. После настройки параметров нажмите кнопку **Print** в предпросмотре.
2. Используйте стандартный диалог печати вашего браузера для выбора принтера и настроек.
3. Рассмотрите параметры:
   - Выбор "Color" для печати в цвете (фотографии выглядят лучше)
   - Выбор "Double-sided" для экономии бумаги
   - Выбор формата бумаги (обычно Letter или A4)

## Экспорт справочника

Вместо печати вы также можете экспортировать справочник как PDF:

1. В предпросмотре справочника нажмите кнопку **Export as PDF**.
2. Выберите местоположение сохранения на вашем компьютере.
3. Поделитесь PDF или архивируйте его для будущей справки.

## Советы для лучших результатов

- Убедитесь, что фотографии членов загружены для наиболее профессионального вида
- Используйте фильтры для исключения неактивных или ненужных членов перед печатью
- Печать в двусторонней печати экономит бумагу и выглядит более профессионально
- Получите обновленный справочник каждый год и архивируйте копию для ваших записей
