# Печать директории

<div class="article-intro">

Функция Print Directory генерирует отформатированную, пригодную к печати членскую директорию для вашей церкви. Она организует членов по домохозяйствам, включает контактную информацию и фотографии, и предназначена для профессионального вида при печати на стандартной бумаге размера письма.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужна активная учетная запись B1 Admin с разрешением на просмотр людей.
- Люди в вашей директории должны иметь фотографии и контактную информацию, заполненную для лучших результатов.

</div>

## Открытие печати директории

1. Перейдите к **People** в B1 Admin.
2. Нажмите **print icon** (значок принтера) на панели инструментов в верхней части карточки результатов People. Он появляется рядом с кнопкой Export.
3. Печать директории открывается на новой вкладке браузера и начинает загружать данные директории.
4. После около 1,5 секунды, диалог печати вашего браузера появится автоматически.

:::tip
Директория открывается на отдельной вкладке, чтобы вы могли распечатать его, не покидая страницу People. После появления диалога печати, вкладка навигирует обратно автоматически.
:::

## Что включено

Печать директория включает всех **active members** вашей церкви. Конкретно:

- Люди с **Inactive** или **Visitor** статус членства автоматически исключены.
- Люди, которые **opted out** директории исключены.
- Все остальные сгруппированы по **household**.

## Расположение директории

Печатная директория имеет две части:

### Обложка

Первая страница включает:
- Название вашей церкви
- Название "Member Directory"
- Текущий год
- Место расположения вашей церкви
- Подсчет общего количества домохозяйств включено

### Списки членов

Оставшиеся страницы перечисляют домохозяйства в алфавитном порядке по фамилии. Каждая карточка домохозяйства показывает:

- **Photos** -- Круглые миниатюры для каждого члена домохозяйства, с их именем ниже
- **Household display name** -- Например, "The Smith Family", "John & Jane Doe", или просто имя человека для особ
- **Address** -- Улица, город, штат и почтовый индекс
- **Phone** -- Домашний или мобильный номер
- **Email** -- Основной адрес электронной почты
- **Birthdays** -- Отформатирован как отдельные даты для каждого члена домохозяйства
- **Anniversary** -- Если записано

Домохозяйства организованы в **alphabetical sections** (A, B, C, ...) с декоративным заголовком раздела перед каждой группой букв. Две карточки домохозяйства появляются рядом на каждой строке.

## Параметры печати

Директория форматирована для **letter-size paper** (8.5" × 11") с 0.5-дюймовыми полями. Когда диалог печати браузера появляется:

- Оставьте размер бумаги установленным на **Letter**
- Включите **Background graphics** (иногда называется "Print backgrounds") в параметрах печати браузера, если вы хотите, чтобы заголовки разделов печатались с их стилизацией цвета
- Портретная ориентация рекомендуется

:::info
Директория соблюдает разрывы страниц -- карточки домохозяйства и заголовки разделов не будут разделены между страницами.
:::
