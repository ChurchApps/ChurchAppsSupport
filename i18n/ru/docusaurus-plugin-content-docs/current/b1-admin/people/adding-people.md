# Добавление людей

<div class="article-intro">

Раздел «Люди» — это основа B1 Admin — база данных участников вашей церкви. Каждая другая функция (группы, посещаемость, пожертвования, формы) связана с записями людей. Это руководство проведет вас через добавление человека в базу данных, редактирование его данных и связывание членов семьи в домохозяйства.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Вам нужна активная учетная запись B1 Admin с правом управления людьми. См. [Роли и права доступа](roles-permissions.md), если вы не уверены в уровне своего доступа.
- Если вы добавляете больше нескольких человек, рассмотрите использование инструмента [Импорт из CSV](importing-data.md) вместо этого.

</div>

## Добавление человека

1. Перейдите на панель управления B1.church Admin.
2. Нажмите на **Люди** в левой боковой панели.
3. Нажмите кнопку **Добавить человека** в правом верхнем углу.
4. Заполните имя, фамилию и email человека, затем нажмите **Добавить**.

Откроется страница профиля человека, готовая к добавлению дополнительных данных.

:::tip
Если вы переходите с другой системы управления церковью, функция [Импорт данных](importing-data.md) позволяет перенести весь ваш справочник из CSV-файла — намного быстрее, чем добавлять людей по одному.
:::

## Редактирование данных

1. На странице профиля человека нажмите **карандаш редактирования** рядом с его именем.
2. Заполните дополнительную информацию, такую как отчество, статус членства, даты, адрес, номера телефонов и (для детей и учащихся) класс и школу.
3. Нажмите **Сохранить**, чтобы сохранить личную информацию.

Профиль также включает несколько вкладок с сопутствующей информацией:

- **Заметки** — Добавляйте заметки о человеке (пастырская забота, последующие контакты и т. д.)
- **Группы** — Просматривайте и управляйте [членством в группах](../groups/group-members.md)
- **Посещаемость** — Просматривайте [записи посещаемости](../attendance/tracking-attendance.md)
- **Пожертвования** — Просматривайте [историю пожертвований](../donations/recording-donations.md)

## Работа с формами

Вы можете заполнять пользовательские формы прямо со страницы профиля человека. Это формы, определяемые пользователем, которые можно создать, следуя руководству [Создание форм](../forms/creating-forms.md).

1. На странице профиля человека нажмите выпадающий список **Формы**, чтобы выбрать форму.
2. Нажмите **Добавить форму**, чтобы открыть ее.
3. Заполните данные формы и нажмите **Сохранить**.

:::info
Формы, привязанные к профилю человека, используют тип формы **Люди**. Если вам нужна отдельная форма (например, для регистрации на событие), см. раздел [Автономная форма](../forms/creating-forms.md) в руководстве по формам.
:::

:::tip
Если вам нужно отслеживать только одну-две дополнительные единицы информации о людях — дату, число, ответ да/нет — используйте [Пользовательские поля](../settings/custom-fields.md) вместо формы. Их быстрее заполнять, и они доступны для поиска прямо в расширенном поиске.
:::

## Управление домохозяйствами

Домохозяйства позволяют связывать членов семьи вместе. Это особенно полезно для [регистрации (check-in)](../attendance/check-in.md), где родитель может зарегистрировать всех своих детей сразу.

1. На странице профиля человека нажмите **карандаш редактирования** рядом с названием домохозяйства.
2. Откроется редактор домохозяйства. Выберите **роль в домохозяйстве** для текущего человека (например, глава семьи, супруг(а), ребенок).
3. Нажмите **Добавить**, чтобы добавить еще одного члена домохозяйства.
4. Введите имя человека в поле поиска и нажмите **Поиск**.
5. Когда человек появится в результатах поиска, нажмите **Выбрать**.
6. Выберите его роль в домохозяйстве и нажмите **Сохранить**, чтобы завершить настройку домохозяйства.
