# Добавление людей

<div class="article-intro">

Раздел "Люди" — это основа B1 Admin — это база данных членов вашей церкви. Каждая другая функция (группы, посещаемость, пожертвования, формы) привязана к записям персоны. Это руководство проведет вас через добавление кого-то в вашу базу данных, редактирование их деталей и связывание членов семьи в домохозяйства.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужна активная учетная запись B1 Admin с разрешением управления людьми. См. [Роли и разрешения](roles-permissions.md), если вы не уверены в своем уровне доступа.
- Если вы добавляете больше нескольких человек, рассмотрите возможность использования инструмента [CSV Import](importing-data.md).

</div>

## Добавление человека

1. Перейдите на панель управления B1.church Admin.
2. Откройте **меню раздела** в верхнем левом углу и выберите **Люди**.
3. Нажмите кнопку **Добавить человека** в верхнем правом углу.
4. Заполните имя, фамилию и адрес электронной почты человека, затем нажмите **Добавить**.

Страница профиля человека откроется, готовая для вас, чтобы добавить дополнительные детали.

:::tip
Если вы переходите из другой системы управления церковью, функция [Импорт данных](importing-data.md) позволяет вам привести весь справочник из CSV-файла — намного быстрее, чем добавление людей по одному.
:::

### Предупреждения о дубликатах

Если адрес электронной почты (или, при создании человека из полной формы редактирования, номер телефона или совпадающие имя + фамилия + дата рождения) совпадает с кем-то уже в вашей базе данных, перед сохранением новой записи появляется диалоговое окно **Возможный дубликат**. Он перечисляет каждого совпадающего человека вместе с их адресом электронной почты, телефоном и датой рождения, чтобы вы могли сравнить.

- Нажмите **Использовать существующего** рядом с совпадением, чтобы вместо этого использовать запись этого человека.
- Нажмите **Создать в любом случае**, чтобы добавить нового человека, даже если было найдено возможное совпадение.

Это проверяет дубликаты только при создании совершенно нового человека — редактирование существующей записи никогда это не вызывает. Это только предотвращает новые дубликаты; он не объединяет две записи, которые уже существуют.

## Редактирование деталей

1. На странице профиля человека нажмите на **карандаш редактирования** рядом с его именем.
2. Заполните дополнительную информацию, такую как среднее имя, статус членства, даты, адрес, номера телефонов и (для детей и студентов) класс и школу.
3. Нажмите **Сохранить**, чтобы сохранить личную информацию.

Профиль также включает несколько вкладок для связанной информации:

- **Заметки** — Добавьте заметки о человеке (пастырская забота, последующие действия и т. д.)
- **Группы** — Просмотр и управление [членством в группе](../groups/group-members.md)
- **Посещаемость** — Просмотр индивидуальной истории посещения этого человека, включая кампус, служение, время служения, группу и столбец **Зарегистрирован** с временем регистрации киоска (показан как тире для посещений, записанных без регистрации киоска). Для тенденций на уровне церкви, а не истории одного человека, см. [Отслеживание посещаемости](../attendance/tracking-attendance.md)
- **Пожертвования** — Просмотр [истории пожертвований](../donations/recording-donations.md)

## Работа с формами

Вы можете заполнять пользовательские формы прямо со страницы профиля человека. Это определяемые пользователем формы, которые вы можете создавать, следуя руководству [Создание форм](../forms/creating-forms.md).

1. На странице профиля человека нажмите на раскрывающийся список **Формы**, чтобы выбрать форму.
2. Нажмите **Добавить форму**, чтобы открыть ее.
3. Заполните детали формы и нажмите **Сохранить**.

После отправки формы нажмите на **значок печати** рядом с ней, чтобы распечатать заполненные ответы этого человека.

:::info
Формы, связанные с профилем человека, используют тип формы **Люди**. Если вам нужна самостоятельная форма (например, регистрация на событие), см. опцию [Самостоятельная форма](../forms/creating-forms.md) в руководстве форм.
:::

:::tip
Если вам нужно отслеживать только один или два дополнительных фрагмента информации о людях — дату, число, ответ "да/нет" — используйте [Пользовательские поля](../settings/custom-fields.md) вместо формы. Они быстрее заполняются и можно искать непосредственно в "Расширенном поиске".
:::

## Управление домохозяйствами

Домохозяйства позволяют вам связывать членов семьи вместе. Это особенно полезно для [регистрации](../attendance/check-in.md), где родитель может зарегистрировать всех своих детей сразу.

1. На странице профиля человека нажмите на **карандаш редактирования** рядом с названием домохозяйства.
2. Откроется редактор домохозяйства. Выберите **роль домохозяйства** для текущего человека (например, Глава, Супруг, Ребенок).
3. Нажмите **Добавить**, чтобы добавить еще одного члена домохозяйства.
4. Введите имя человека в поле поиска и нажмите **Поиск**.
5. Когда человек появится в результатах поиска, нажмите **Выбрать**.
6. Выберите их роль в домохозяйстве и нажмите **Сохранить**, чтобы завершить установку домохозяйства.
