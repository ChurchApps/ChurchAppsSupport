# Сохраненные списки

<div class="article-intro">

**Saved Lists** позволяют вам хранить запрос поиска под названием и повторно запускать его одним нажатием в любое время. Построить список один раз -- "Active Members in Campus North", "Visitors in the last 90 days", или любой продвинутый фильтр -- и он остается в панели **Saved Lists** на странице People, поэтому вам никогда не нужно перестраивать запрос снова.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Запустите по крайней мере один поиск в разделе People, чтобы у вас были результаты для сохранения. См. [Searching People](./searching-people.md) или [AI Search](./ai-search.md).

</div>

## Сохранение поиска как списка

1. Запустите поиск на странице **People** -- быстрый поиск, AI поиск, или поиск с продвинутым фильтром.
2. Когда результаты появляются, кнопка **Save as List** (значок закладки) показывает в заголовке страницы People.
3. Нажмите **Save as List**.
4. Введите **Name** для списка (требуется).
5. При необходимости введите **Category**, чтобы сгруппировать связанные списки вместе в панели **Saved Lists** (например, "Outreach" или "Membership").
6. Нажмите **Save**.

Список теперь сохраняется в учетную запись вашей церкви и появится в панели **Saved Lists** на левой стороне страницы People.

:::info
Списки распределяются по всей вашей церкви -- любой с доступом People может видеть и загружать их. Только персонал с соответствующим разрешением может переименовывать или удалять списки.
:::

## Загрузка сохраненного списка

В панели **Saved Lists** на левой стороне страницы People нажмите на любое имя списка. Поиск переоборотится мгновенно с сохраненным запросом, обновляя таблицу результатов.

Списки сгруппированы по категориям (если вы назначили одну), с некатегоризованными списками в последнем.

:::tip
Списки - это **live queries**, не снимки. Каждый раз, когда вы загружаете список, поиск запускается свежо против ваших текущих данных, поэтому новые люди, которые теперь соответствуют критериям, будут отображаться.
:::

## Переименование и удаление списков

Персонал с разрешением управления может переименовывать или удалять любой список прямо из панели Saved Lists.

- Нажмите на **pencil icon** рядом с именем списка, чтобы переименовать его.
- Нажмите на **trash icon**, чтобы удалить его (вас попросят подтвердить).

## Варианты использования

| Сценарий | Как создать список |
|---|---|
| Все посетители | Advanced search: Membership Status = Visitor |
| Члены на определенном кампусе | Advanced search: Campus = [your campus] |
| Люди без адреса электронной почты | Advanced search: Email is empty |
| Волонтеры с истекшей проверкой фона | Advanced search: [Custom Field](../settings/custom-fields.md) "Background check expires" is before today |
| Результаты из AI вопроса | Спросите вопрос в AI Search, затем сохраните |
