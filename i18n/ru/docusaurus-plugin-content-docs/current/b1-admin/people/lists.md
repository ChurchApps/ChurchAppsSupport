# Сохраненные списки

<div class="article-intro">

Сохраненные списки — это переиспользуемые фильтры, которые автоматически обновляются, чтобы показать людей, соответствующих вашим критериям. Вместо того чтобы каждый раз вручную фильтровать, сохраните фильтр как список для быстрого доступа позже, и B1 будет хранить людей, которые соответствуют критериям в реальном времени.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Люди должны существовать в вашем справочнике. Для начала см. [Добавление людей](./adding-people.md).

</div>

## Создание сохраненного списка

1. Перейдите на страницу **People** в B1 Admin.
2. Используйте фильтры для сужения людей в соответствии с вашими критериями (например, статус членства, возрастной диапазон, кампус).
3. После того как у вас есть фильтры, которые вам нравятся, нажмите **Save as List** в верхней части страницы.
4. Дайте вашему списку имя (например, "First Time Visitors" или "Active Small Group Leaders").
5. Нажмите **Save**.

Ваш новый список отображается в меню **Saved Lists** слева и доступен со страницы **People** каждый раз, когда вам нужно.

## Использование сохраненного списка

После сохранения списка вы можете быстро получить к нему доступ:

1. Перейдите на страницу **People**.
2. Посмотрите на панель слева под **Saved Lists**.
3. Нажмите на любой список для его загрузки.

Список показывает всех людей, которые в настоящее время соответствуют критериям, автоматически обновляя результаты при изменении данных вашей церкви.

## Типы сохраненных списков

Сохраненные списки могут быть созданы на основе множества критериев:

- **Статус членства** — найдите всех посетителей, регулярных посетителей, членов, персонал или неактивных людей
- **Демография** — люди в возрастном диапазоне, конкретного пола или семейного положения
- **Членство в группе** — люди, состоящие в конкретной группе
- **История посещаемости** — люди, которые посетили или не посетили определенные события
- **История пожертвований** — люди, которые давали в конкретный период
- **Дата создания** — люди, добавленные в систему в конкретный период
- **Кампус** — люди, назначенные определенному кампусу

## Редактирование или удаление списка

Чтобы изменить критерии списка:

1. Нажмите на сохраненный список для загрузки его.
2. Обновите фильтры по необходимости.
3. Нажмите **Save as List** и выберите **Update Existing** для обновления текущего списка.

Чтобы удалить список, щелкните правой кнопкой мыши (или нажмите долго на мобильном устройстве) на списке в панели слева и выберите **Delete**.

## Типичные варианты использования

- **Первые визиты** — создайте список новых посетителей для отправления приветственного письма
- **Лидеры малых групп** — сохраните список людей с ролью лидера для целей коммуникаций
- **Невышедшие** — создайте список людей, которые давно не посещали, для последующего наблюдения
- **Готовые к членству** — люди, готовые для класса членства
