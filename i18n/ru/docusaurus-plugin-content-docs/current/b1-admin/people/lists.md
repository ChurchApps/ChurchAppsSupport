# Сохраненные списки

<div class="article-intro">

**Saved Lists** позволяют вам хранить запрос поиска под названием и повторно запускать его одним нажатием в любое время. Построить список один раз -- "Active Members in Campus North", "Visitors in the last 90 days", или любой продвинутый фильтр -- и он остается вверху страницы People, поэтому вам никогда не нужно перестраивать запрос снова.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Запустите по крайней мере один поиск в разделе People, чтобы у вас были результаты для сохранения. См. [Searching People](./searching-people.md) или [AI Search](./ai-search.md).

</div>

## Сохранение поиска как списка

1. Запустите поиск на странице **People** -- быстрый поиск, AI поиск, или поиск с продвинутым фильтром.
2. Когда результаты появляются, кнопка **Save as List** показывает в заголовке страницы People.
3. Нажмите **Save as List**.
4. Введите **List Name** для списка (требуется).
5. При необходимости введите **Category**, чтобы сгруппировать связанные списки вместе (например, "Outreach" или "Membership").
6. В разделе **Who can see this list** выберите **All staff** или **Only me**.
7. Нажмите **Save**.

Список теперь сохраняется в учетную запись вашей церкви и появляется кнопкой в ряду сохраненных списков вверху страницы People, рядом с **Everyone**. Списки с пометкой **Only me** отмечены маленьким значком замка.

:::info
Списки с доступом **All staff** распределяются по всей вашей церкви -- любой с доступом People может видеть и загружать их. Только персонал с соответствующим разрешением может изменять или удалять списки.
:::

## Загрузка сохраненного списка

Вверху страницы People нажмите на любое имя списка. Поиск мгновенно повторится с сохраненным запросом и обновит результаты. Нажмите **Everyone**, чтобы вернуться ко всему справочнику.

Списки сгруппированы по категориям (если вы назначили одну), с некатегоризованными списками в последнем.

:::tip
Списки - это **live queries**, не снимки. Каждый раз, когда вы загружаете список, поиск запускается свежо против ваших текущих данных, поэтому новые люди, которые теперь соответствуют критериям, будут отображаться.
:::

## Переименование и удаление списков

Персонал с разрешением управления может переименовывать или удалять любой список со страницы People. Сначала загрузите список, нажав на него — рядом с его именем появятся два значка:

- Нажмите на значок **List Settings** (шестеренка), чтобы переименовать список или изменить его категорию, доступ и другие настройки.
- Нажмите на значок **Delete** (корзина), чтобы удалить его (вас попросят подтвердить).

## Варианты использования

| Сценарий | Как создать список |
|---|---|
| Все посетители | Advanced search: Membership Status = Visitor |
| Члены на определенном кампусе | Advanced search: Campus = [your campus] |
| Люди без адреса электронной почты | Advanced search: Email is empty |
| Волонтеры с истекшей проверкой фона | Advanced search: [Custom Field](../settings/custom-fields.md) "Background check expires" is before today |
| Результаты из AI вопроса | Спросите вопрос в AI Search, затем сохраните |
