# Сохраненные списки

<div class="article-intro">

**Сохраненные списки** позволяют вам сохранить поисковый запрос под именем и повторно запускать его одним щелчком в любое время. Постройте список один раз — «Активные участники в кампусе Норт», «Гости за последние 90 дней» или любой расширенный фильтр — и он останется в вашей боковой панели, чтобы вам больше не пришлось повторно строить запрос.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Выполните хотя бы один поиск в разделе «Люди», чтобы у вас были результаты для сохранения. См. [Поиск людей](./searching-people.md) или [ИИ-поиск](./ai-search.md).

</div>

## Сохранение поиска как списка

1. Выполните поиск на странице **Люди** — быстрый поиск, ИИ-поиск или поиск с расширенным фильтром.
2. Когда появятся результаты, в заголовке страницы «Люди» появится кнопка **Сохранить как список** (значок закладки).
3. Нажмите **Сохранить как список**.
4. Введите **название** для списка (обязательно).
5. При желании введите **категорию**, чтобы сгруппировать связанные списки в боковой панели (например, «Работа с прихожанами» или «Членство»).
6. Нажмите **Сохранить**.

Теперь список сохранен в учетной записи вашей церкви и появится в панели **Сохраненные списки** слева на странице «Люди».

:::info
Списки являются общими для всей вашей церкви — любой, у кого есть доступ к разделу «Люди», может их видеть и загружать. Только сотрудники с соответствующим правом могут переименовывать или удалять списки.
:::

## Загрузка сохраненного списка

В панели **Сохраненные списки** слева на странице «Люди» нажмите на любое название списка. Поиск мгновенно перезапускается с сохраненным запросом, обновляя таблицу результатов.

Списки сгруппированы по категориям (если вы назначили категорию), с несгруппированными списками, отображаемыми последними.

:::tip
Списки — это **живые запросы**, а не снимки состояния. Каждый раз при загрузке списка поиск заново выполняется по вашим текущим данным, поэтому новые люди, теперь соответствующие критериям, будут отображаться.
:::

## Переименование и удаление списков

Сотрудники с правом управления могут переименовывать или удалять любой список прямо из панели «Сохраненные списки».

- Нажмите на **значок карандаша** рядом с названием списка, чтобы переименовать его.
- Нажмите на **значок корзины**, чтобы удалить его (у вас запросят подтверждение).

## Примеры использования

| Сценарий | Как построить список |
|---|---|
| Все гости | Расширенный поиск: Статус членства = Гость |
| Участники определенного кампуса | Расширенный поиск: Кампус = [ваш кампус] |
| Люди без email-адреса | Расширенный поиск: Email пуст |
| Волонтеры с истекшей проверкой биографии | Расширенный поиск: [Пользовательское поле](../settings/custom-fields.md) «Срок действия проверки биографии истекает» раньше сегодняшнего дня |
| Результаты вопроса к ИИ | Задайте вопрос в ИИ-поиске, затем сохраните |
