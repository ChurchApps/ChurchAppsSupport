# Прямые трансляции

<div class="article-intro">

Страница «Live Stream Times» позволяет настроить расписание трансляций вашей церкви, управлять временами служений и настраивать то, как зрители видят трансляцию. Задавайте регулярные еженедельные служения или разовые события, настраивайте чат и видео и управляйте тем, когда трансляция выходит в эфир.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Нужно право **contentApi.streamingServices.edit**. Если у вас нет доступа, см. [Роли и права](../settings/roles-permissions.md).
- Подготовьте ID вашего канала YouTube, если планируете автоматические трансляции
- Добавьте хотя бы одну [проповедь](./managing-sermons.md) или постоянную ссылку на прямой эфир, чтобы использовать её как источник трансляции

</div>

Прямыми трансляциями управляют две страницы в разделе **Sermons** меню перехода: **Live Stream Times** для расписания трансляций и **Settings** для настройки вкладок на странице трансляции.

## Управление служениями

### Добавление служения

1. В B1 Admin откройте [меню перехода](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в левом верхнем углу), разверните **Sermons** и нажмите **Live Stream Times**.
2. Нажмите кнопку **Add Service** вверху страницы, чтобы создать новое запланированное служение. Существующие служения перечислены в таблице с названием, временем, провайдером и продолжительностью каждого; чтобы изменить строку, нажмите значок редактирования.
3. Введите **Service Name** (например, «Sunday Morning»).
4. Задайте **Service Time** -- выберите день и время начала служения.
5. Установите **Recurs Weekly** в значение **Yes** для регулярных еженедельных служений или **No** для разового события.

### Настройка чата и видео

6. В разделе **Chat Settings** укажите, за сколько минут до служения и через сколько минут после него должен быть включён чат. Так посетители могут начать общаться до начала служения и продолжить после.
7. В разделе **Video Settings** укажите, за сколько времени до служения запускать видеопоток для обратного отсчёта или контента до служения. Чат открывается за столько минут *до* начала раннего видео, поэтому время, показанное рядом с настройкой «минут до», учитывает оба значения. Например, при служении в 10:00 с 15 минутами чата до и ранним стартом за 5 минут чат откроется в 9:40.
8. Выберите, какую проповедь воспроизводить, в выпадающем списке:
   - **Latest Sermon** -- автоматически воспроизводит последнее добавленное видео.
   - **Current Live Service** -- воспроизводит текущую трансляцию с YouTube по вашему ID канала.
   - Также можно выбрать любую конкретную проповедь, которую вы уже сохранили.
9. Нажмите **Save**, чтобы запланировать служение.

:::info
Если служение регулярное, оно будет обновляться каждую неделю автоматически. Оно сохраняет одно и то же местное время при переходе на летнее время и обратно. Можно добавить сколько угодно служений. Посетители увидят ближайшее запланированное время служения, когда откроют вашу страницу трансляции.
:::

## Настройки страницы трансляции

Чтобы настроить вкладки и ссылки, которые отображаются рядом с прямой трансляцией, откройте меню перехода, разверните **Sermons** и нажмите **Settings**. На странице **Stream Settings** показан список **Content Tabs**.

### Добавление вкладок

1. Нажмите кнопку **Add**, чтобы добавить новую вкладку на страницу трансляции.
2. Выберите **Link Type**: **External URL** для пользовательской ссылки или одну из готовых вкладок **Chat** или **Prayer**.
3. Для вкладки Chat достаточно ввести название в поле **Tab Text** -- настройка на этом завершена.
4. Для вкладки-ссылки введите название вкладки, выберите значок, нажав на кнопку значка, и введите URL.
5. Настроенные вкладки появятся на странице трансляции, где зрители смогут открыть дополнительные ресурсы и интерактивные функции.

### Предпросмотр трансляции

На странице **Live Stream Times** нажмите **View Your Stream** вверху страницы, чтобы увидеть, как страница трансляции будет выглядеть для посетителей, включая ваш логотип, времена служений и настроенные вкладки.

## Настройка YouTube-трансляции

Чтобы подключить ваш канал YouTube для автоматических трансляций:

1. Перейдите в **Sermons**, нажмите **Add Sermon**, затем выберите **Add Permanent Live URL**.
2. Провайдером видео по умолчанию будет **Current YouTube Live Stream**. Введите ваш **YouTube Channel ID**.
3. Добавьте название и описание, затем нажмите **Save**.
4. На странице **Live Stream Times** создайте служение и выберите вашу постоянную ссылку на прямой эфир в выпадающем списке проповедей.

:::tip
Чтобы найти ID вашего канала YouTube, откройте расширенные настройки вашего канала и скопируйте значение Channel ID.
:::

## Настройка цветов и логотипа

Страница вашей трансляции использует настройки [внешнего вида](../website/appearance.md) вашего сайта:

- Для шапки используется **светлый акцентный цвет** с тёмным текстом.
- Для боковой панели используется **тёмный акцентный цвет** со светлым текстом.
- На странице трансляции показывается ваш **Light Background Logo**. Используйте изображение с прозрачным фоном и соотношением сторон 4:1.

Чтобы изменить эти параметры, перейдите в **Website**, затем **Appearance**, и обновите настройки [цветовой палитры](../website/appearance.md#color-palette) и [логотипа](../website/appearance.md#logo-and-branding).

## Добавление ведущих трансляции

Чтобы дать членам команды доступ к чату только для ведущих наряду с публичным чатом:

1. В меню перехода выберите **Settings > Roles**.
2. Нажмите кнопку плюса и выберите **Add Custom Role**.
3. Назовите роль «Streaming Host» и нажмите **Save**.
4. Нажмите на новую роль, затем нажмите **Add** в разделе Members, чтобы добавить людей.
5. Прокрутите вниз до **Edit Permissions**, разверните раздел **Content** и отметьте **Host Chat**.

Когда ведущие входят на страницу трансляции, рядом с публичным чатом появляется закрытая вкладка **Host Chat** для разговоров только для сотрудников во время эфира.

:::info
Подробнее о создании ролей и управлении правами см. в разделе [Роли и права](../settings/roles-permissions.md).
:::

## Устранение неполадок

Если автоматическая трансляция YouTube не отображается корректно при использовании варианта «Current YouTube Live Stream» с вашим Channel ID, попробуйте следующее:

**Признаки:**
- Встроенный плеер трансляции показывает «Video unavailable»
- Страница загружается, но видео не появляется
- Прямые встраивания YouTube работают, а автоматическая трансляция канала -- нет

**Решение:**
Проверьте свой канал YouTube на наличие старых или запланированных трансляций и удалите их:

1. Перейдите в YouTube Studio.
2. Откройте **Content**, затем **Live**.
3. Найдите старые запланированные трансляции или предстоящие запланированные эфиры.
4. Удалите эти старые или запланированные записи трансляций.
5. Снова проверьте страницу трансляции.

:::warning
Автоматическое встраивание трансляции канала YouTube может быть заблокировано, если в канале несколько запланированных или прошедших записей трансляций. Их удаление позволяет YouTube правильно определить и показать вашу текущую трансляцию.
:::

**Дополнительные требования:**
- Трансляция должна быть **Public** (не Unlisted и не Private).
- Встраивание должно быть разрешено в настройках трансляций YouTube.
- Убедитесь, что используется провайдер **Current YouTube Live Stream** (с Channel ID), а не провайдер **YouTube** (с Video ID).
