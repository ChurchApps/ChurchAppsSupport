# Прямая трансляция

<div class="article-intro">

Страница "Времена прямой трансляции" позволяет вам настроить расписание трансляции вашей церкви, управлять временем служений и настроить опыт зрителя. Настройте повторяющиеся еженедельные служения или разовые события, настройте параметры чата и видео и управляйте, когда ваш поток начинает вещание.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам требуется разрешение **contentApi.streamingServices.edit**. См. [Роли и разрешения](../settings/roles-permissions.md), если у вас нет доступа.
- Имейте готовым ID канала YouTube, если вы планируете использовать автоматизированную прямую трансляцию
- Добавьте хотя бы одну [проповедь](managing-sermons) или постоянный прямой URL для использования в качестве источника потока

</div>

Страница имеет две основные вкладки: **Служения** для управления расписанием прямой трансляции и **Параметры** для настройки вашей страницы трансляции.

## Управление служениями

### Добавление служения

1. В B1 Admin откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **Проповеди** и щелкните **Времена прямой трансляции**.
2. Щелкните кнопку **Добавить служение**, чтобы создать новое запланированное служение.
3. Введите **Имя служения** (например, "Воскресенское утро").
4. Установите **Время служения** - выберите день и время начала вашего служения.
5. Установите **Повторять еженедельно** на **Да** для обычных еженедельных служений или **Нет** для разового события.

### Настройка параметров чата и видео

6. В разделе **Параметры чата** установите, за сколько минут до и после служения должен быть включен чат. Это позволяет посетителям начать чат перед началом служения и продолжить после.
7. В разделе **Параметры видео** установите, за сколько времени начать видеопоток для обратного отсчета или содержимого перед служением.
8. Выберите, какую проповедь проигрывать из раскрывающегося списка:
   - **Последняя проповедь** - автоматически воспроизводит ваше самое недавно добавленное видео.
   - **Текущее прямое служение** - воспроизводит вашу текущую прямую трансляцию с YouTube, используя ваш ID канала.
   - Вы также можете выбрать любую конкретную проповедь, которую вы уже сохранили.
9. Щелкните **Сохранить**, чтобы запланировать ваше служение.

:::info
Ваше служение будет автоматически обновляться каждую неделю, если оно установлено как повторяющееся. Вы можете добавить столько служений, сколько вам нужно. Посетители будут видеть время следующего запланированного служения, когда они посетят вашу страницу трансляции.
:::

## Параметры страницы трансляции

Щелкните вкладку **Параметры**, чтобы настроить вкладки и ссылки, которые появляются рядом с вашей прямой трансляцией.

### Добавление вкладок

1. Щелкните кнопку **Добавить**, чтобы добавить новую вкладку на вашу страницу прямой трансляции.
2. Выберите предварительно разработанную вкладку **Чат** или добавьте пользовательскую вкладку с внешним URL.
3. Для вкладки "Чат" просто дайте ей имя в поле **Текст вкладки** и настройка завершена.
4. Для связанной вкладки введите имя вкладки, выберите значок, щелкнув кнопку значка, и введите URL.
5. Ваши настроенные вкладки появятся на странице прямой трансляции для зрителей, чтобы получить доступ к дополнительным ресурсам и интерактивным функциям.

### Предварительный просмотр вашего потока

Щелкните кнопку **Просмотреть ваш поток**, чтобы увидеть, как ваша страница прямой трансляции будет выглядеть для посетителей, включая ваш логотип, время служений и настроенные вкладки.

## Настройка вашей прямой трансляции YouTube

Чтобы подключить ваш канал YouTube для автоматизированной прямой трансляции:

1. Перейдите в **Проповеди** и щелкните **Добавить проповедь**, затем выберите **Добавить постоянный прямой URL**.
2. Поставщик видео по умолчанию - **Текущая прямая трансляция YouTube**. Введите ваш **ID канала YouTube**.
3. Добавьте название и описание, затем щелкните **Сохранить**.
4. В **Времена прямой трансляции** создайте служение и выберите ваш постоянный прямой URL из раскрывающегося списка проповедей.

:::tip
Чтобы найти ваш ID канала YouTube, перейдите в расширенные параметры вашего канала YouTube и скопируйте значение ID канала.
:::

## Настройка цветов и логотипа

Ваша страница прямой трансляции использует параметры [Внешний вид](../website/appearance) вашего веб-сайта:

- **Светлый цвет акцента** с темным текстом используется для заголовка.
- **Темный цвет акцента** со светлым текстом используется для боковой панели.
- Ваш **Светлый логотип фона** появляется на странице трансляции. Используйте изображение с прозрачным фоном и соотношением сторон 4:1.

Чтобы изменить это, перейдите в **Веб-сайт**, затем **Внешний вид** и обновите параметры [Цветовая палитра](../website/appearance#color-palette) и [Логотип](../website/appearance#logo-and-branding).

## Добавление хостов трансляции

Чтобы дать членам команды доступ к чату только для хостов рядом с публичным чатом:

1. В меню Jump выберите **Параметры > Роли**.
2. Щелкните кнопку плюс и выберите **Добавить пользовательскую роль**.
3. Назовите роль "Хост трансляции" и щелкните **Сохранить**.
4. Щелкните новую роль, затем щелкните **Добавить** в разделе "Члены", чтобы добавить людей.
5. Прокрутите вниз к **Редактирование разрешений**, разверните раздел **Содержание** и установите флажок **Чат хоста**.

Когда хосты входят на страницу прямой трансляции, рядом с публичным чатом появляется приватная вкладка **Чат хоста** для разговора только для сотрудников во время трансляции.

:::info
Для получения дополнительной информации о создании ролей и управлении разрешениями см. [Роли и разрешения](../settings/roles-permissions.md).
:::

## Устранение неисправностей

Если ваша автоматизированная прямая трансляция YouTube неправильно отображается при использовании опции "Текущая прямая трансляция YouTube" с вашим ID канала, попробуйте следующее:

**Симптомы:**
- Встроенный видеопоток показывает "Видео недоступно"
- Страница загружается, но видео не появляется
- Прямые встраивания YouTube работают, но автоматизированная прямая трансляция канала не работает

**Решение:**
Проверьте ваш канал YouTube на предмет старых или предстоящих запланированных трансляций и удалите их:

1. Перейдите на YouTube Studio.
2. Перейдите в **Содержание**, затем **Прямые**.
3. Найдите любые старые запланированные прямые трансляции или предстоящие запланированные потоки.
4. Удалите эти старые или запланированные записи о прямых трансляциях.
5. Протестируйте вашу страницу прямой трансляции снова.

:::warning
Автоматизированное встраивание канала прямой трансляции YouTube может быть заблокировано, если в вашем канале есть несколько запланированных или прошлых записей о прямых трансляциях. Удаление этих записей позволяет YouTube правильно определить и предоставить вашу текущую прямую трансляцию.
:::

**Дополнительные требования:**
- Ваша прямая трансляция должна быть установлена как **Публичная** (не Скрытая или Приватная).
- Встраивание должно быть разрешено в параметрах вашего потока YouTube.
- Убедитесь, что вы используете поставщика **Текущая прямая трансляция YouTube** (с ID канала), а не поставщика **YouTube** (с ID видео).
