# Прямые трансляции

<div class="article-intro">

Страница Live Stream Times позволяет настроить расписание трансляций вашей церкви, управлять временем служений и настраивать внешний вид для зрителей. Задавайте регулярные еженедельные служения или разовые события, настраивайте чат и видео и контролируйте, когда трансляция выходит в эфир.

</div>

- Добавьте хотя бы одну [проповедь](managing-sermons) или постоянную ссылку на прямой эфир, которая будет источником трансляции

Прямые трансляции управляются с двух страниц в разделе **Sermons** меню Jump: **Live Stream Times** для управления расписанием трансляций и **Settings** для настройки вкладок на странице трансляции.

## Управление служениями

### Добавление служения

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **Sermons** и нажмите **Live Stream Times**.
2. Нажмите кнопку **Add Service** в верхней части страницы, чтобы создать новое запланированное служение. Существующие служения перечислены в таблице с названием, временем, провайдером и продолжительностью каждого служения; чтобы изменить запись, нажмите значок редактирования в её строке.
3. Введите **Service Name** (например, «Sunday Morning»).
4. Укажите **Service Time** -- выберите день и время начала служения.
5. Установите **Recurs Weekly** в значение **Yes** для регулярных еженедельных служений или **No** для разового события.

### Настройка чата и видео

6. В разделе **Chat Settings** укажите, за сколько минут до и через сколько минут после служения должен включаться чат. Это позволяет посетителям начать общение до начала служения и продолжить его после.
7. В разделе **Video Settings** укажите, за сколько времени до начала запускать видеотрансляцию для обратного отсчёта или контента перед служением. Чат открывается за указанное число минут *до* начала раннего видео, поэтому время, показанное рядом с настройкой «минут до» для чата, учитывает оба числа. Например, для служения в 10:00 при 15 минутах чата до начала и раннем старте за 5 минут чат откроется в 9:40.
8. Выберите проповедь для воспроизведения в выпадающем списке:
   - **Latest Sermon** -- Автоматически воспроизводит последнее добавленное видео.
   - **Current Live Service** -- Воспроизводит текущую прямую трансляцию с YouTube, используя ваш Channel ID.
   - Также можно выбрать любую конкретную проповедь из уже сохранённых.
9. Нажмите **Save**, чтобы запланировать служение.

:::info
Если служение повторяется еженедельно, оно будет автоматически обновляться каждую неделю. Оно сохраняет одно и то же местное время при переходе на летнее время и обратно. Вы можете добавить столько служений, сколько нужно. Посетители увидят время следующего запланированного служения, когда откроют страницу трансляции.
:::

## Настройки страницы трансляции

Чтобы настроить вкладки и ссылки рядом с прямой трансляцией, откройте меню Jump, разверните **Sermons** и нажмите **Settings**. На странице **Stream Settings** отображается список **Content Tabs**.

### Добавление вкладок

1. Нажмите кнопку **Add**, чтобы добавить новую вкладку на страницу трансляции.
2. Выберите **Link Type**: **External URL** для собственной ссылки или одну из готовых вкладок **Chat** или **Prayer**.
3. Для вкладки Chat достаточно указать название в поле **Tab Text** -- и настройка готова.
4. Для вкладки со ссылкой введите название вкладки, выберите значок, нажав кнопку значка, и введите URL.
5. Настроенные вкладки появятся на странице прямой трансляции, чтобы зрители могли открыть дополнительные ресурсы и интерактивные функции.

### Предпросмотр трансляции

На странице **Live Stream Times** нажмите **View Your Stream** в верхней части страницы, чтобы увидеть, как страница трансляции будет выглядеть для посетителей, включая логотип, время служений и настроенные вкладки.

## Настройка прямой трансляции на YouTube

Чтобы подключить канал YouTube для автоматической прямой трансляции:

1. Перейдите в **Sermons**, нажмите **Add Sermon**, затем выберите **Add Permanent Live URL**.
2. Провайдер видео по умолчанию -- **Current YouTube Live Stream**. Введите ваш **YouTube Channel ID**.
3. Добавьте название и описание, затем нажмите **Save**.
4. На странице **Live Stream Times** создайте служение и выберите вашу постоянную ссылку на прямой эфир в выпадающем списке проповедей.

:::tip
Чтобы найти ID вашего канала YouTube, откройте расширенные настройки вашего канала на YouTube и скопируйте значение Channel ID.
:::

## Настройка цветов и логотипа

Страница прямой трансляции использует настройки [Appearance](../website/appearance) вашего сайта:

- **Светлый акцентный цвет** с тёмным текстом используется для шапки.
- **Тёмный акцентный цвет** со светлым текстом используется для боковой панели.
- Ваш **Light Background Logo** появляется на странице трансляции. Используйте изображение с прозрачным фоном и соотношением сторон 4:1.

Чтобы изменить эти параметры, перейдите в **Website**, затем **Appearance**, и обновите настройки [Color Palette](../website/appearance#color-palette) и [Logo](../website/appearance#logo-and-branding).

## Добавление ведущих трансляции

Чтобы дать членам команды доступ к чату только для ведущих наряду с общедоступным чатом:

1. В меню Jump выберите **Settings > Roles**.
2. Нажмите кнопку с плюсом и выберите **Add Custom Role**.
3. Назовите роль «Streaming Host» и нажмите **Save**.
4. Нажмите на новую роль, затем нажмите **Add** в разделе Members, чтобы добавить людей.
5. Прокрутите вниз до **Edit Permissions**, раскройте раздел **Content** и отметьте **Host Chat**.

Когда ведущие входят на страницу прямой трансляции, рядом с общедоступным чатом появляется закрытая вкладка **Host Chat** для конфиденциальных разговоров персонала во время трансляции.

:::info
Подробнее о создании ролей и управлении правами см. [Roles & Permissions](../settings/roles-permissions.md).
:::

## Устранение неполадок

Если ваша автоматическая прямая трансляция на YouTube не отображается корректно при использовании варианта «Current YouTube Live Stream» с вашим Channel ID, попробуйте следующее:

**Симптомы:**
- Встроенный плеер прямой трансляции показывает «Video unavailable»
- Страница загружается, но видео не появляется
- Прямые встраивания YouTube работают, а автоматическая трансляция канала -- нет

**Решение:**
Проверьте свой канал YouTube на наличие старых или запланированных прямых трансляций и удалите их:

1. Перейдите в YouTube Studio.
2. Откройте **Content**, затем **Live**.
3. Найдите все старые запланированные эфиры и предстоящие запланированные трансляции.
4. Удалите эти старые или запланированные записи прямых эфиров.
5. Снова проверьте страницу прямой трансляции.

:::warning
Автоматическое встраивание прямой трансляции канала YouTube может блокироваться, если в вашем канале есть несколько запланированных или прошедших записей эфиров. Их удаление позволяет YouTube правильно определить и показать текущую прямую трансляцию.
:::

**Дополнительные требования:**
- Ваша прямая трансляция должна быть **Public** (не Unlisted и не Private).
- Встраивание должно быть разрешено в настройках трансляций YouTube.
- Убедитесь, что используете провайдер **Current YouTube Live Stream** (с Channel ID), а не провайдер **YouTube** (с Video ID).
