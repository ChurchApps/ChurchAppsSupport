# Прямой эфир

<div class="article-intro">

Страница Live Stream Times позволяет вам настроить расписание потокового вещания вашей церкви, управлять временем богослужений и настраивать опыт просмотра. Настройте повторяющиеся еженедельные услуги или разовые события, настройте параметры чата и видео и контролируйте, когда ваш поток выходит в эфир.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужно разрешение **contentApi.streamingServices.edit**. См. [Roles & Permissions](../settings/roles-permissions.md), если у вас нет доступа.
- Подготовьте ваш YouTube Channel ID, если вы планируете использовать автоматическое прямое эфирное вещание
- Добавьте по крайней мере одну [проповедь](managing-sermons) или постоянный живой URL для использования в качестве источника потока

</div>

Страница имеет две основные вкладки: **Services** для управления расписанием прямого эфира и **Settings** для настройки вашей страницы потокового вещания.

## Управление услугами

### Добавление услуги

1. В B1 Admin откройте **меню раздела** в верхнем левом углу (название раздела со стрелкой) и выберите **Sermons**, затем нажмите вкладку **Live Stream Times**.
2. Нажмите кнопку **Add Service** для создания новой запланированной услуги.
3. Введите **Service Name** (например, "Sunday Morning").
4. Установите **Service Time** — выберите день и время начала вашей услуги.
5. Установите **Recurs Weekly** на **Yes** для обычных еженедельных услуг или **No** для разовых событий.

### Настройка параметров чата и видео

6. В разделе **Chat Settings** установите, на сколько минут до и после услуги должен быть включен чат. Это позволяет посетителям начать общаться перед началом услуги и продолжить после.
7. В разделе **Video Settings** установите, как рано начать потоковое видео для отсчета или контента перед услугой.
8. Выберите, какую проповедь воспроизводить из раскрывающегося меню:
   - **Latest Sermon** — Автоматически воспроизводит ваше самое недавно добавленное видео.
   - **Current Live Service** — Воспроизводит ваш текущий прямой эфир с YouTube, используя ваш Channel ID.
   - Вы также можете выбрать любую конкретную проповедь, которую вы уже сохранили.
9. Нажмите **Save** для планирования вашей услуги.

:::info
Ваша услуга будет автоматически обновляться каждую неделю, если установлена на повторение. Вы можете добавить столько услуг, сколько вам нужно. Посетители будут видеть следующее запланированное время услуги при посещении вашей страницы потокового вещания.
:::

## Параметры страницы потокового вещания

Нажмите вкладку **Settings** для настройки вкладок и ссылок, которые отображаются рядом с вашим прямым эфиром.

### Добавление вкладок

1. Нажмите кнопку **Add** для добавления новой вкладки на вашу страницу прямого эфира.
2. Выберите предварительно разработанную вкладку **Chat** или добавьте пользовательскую вкладку с внешним URL.
3. Для вкладки Chat просто введите имя в поле **Tab Text** и настройка завершена.
4. Для связанной вкладки введите имя вкладки, выберите значок, нажав кнопку значка, и введите URL.
5. Ваши настроенные вкладки будут отображаться на странице прямого эфира для просмотра дополнительных ресурсов и интерактивных функций.

### Предпросмотр вашего потока

Нажмите кнопку **View Your Stream** для просмотра ровно того, как ваша страница прямого эфира будет выглядеть для посетителей, включая ваш логотип, время услуг и настроенные вкладки.

## Настройка вашего YouTube Live Stream

Для подключения вашего канала YouTube для автоматического прямого эфира:

1. Перейдите в **Sermons** и нажмите **Add Sermon**, затем выберите **Add Permanent Live URL**.
2. Провайдер видео по умолчанию — **Current YouTube Live Stream**. Введите ваш **YouTube Channel ID**.
3. Добавьте заголовок и описание, затем нажмите **Save**.
4. В **Live Stream Times** создайте услугу и выберите ваш постоянный живой URL из раскрывающегося меню проповеди.

:::tip
Чтобы найти ваш YouTube Channel ID, перейдите в дополнительные параметры вашего канала YouTube и скопируйте значение Channel ID.
:::

## Настройка цветов и логотипа

Ваша страница прямого эфира использует параметры [Appearance](../website/appearance) вашего веб-сайта:

- **light accent color** с темным текстом используется для заголовка.
- **dark accent color** с легким текстом используется для боковой панели.
- Ваш **Light Background Logo** отображается на странице потокового вещания. Используйте изображение с прозрачным фоном и соотношением сторон 4:1.

Чтобы изменить их, перейдите в **Website**, затем **Appearance** и обновите вашу [Color Palette](../website/appearance#color-palette) и [Logo](../website/appearance#logo-and-branding) параметры.

## Добавление хостов потокового вещания

Чтобы дать членам команды доступ к чату только для хостов рядом с публичным чатом:

1. Откройте **меню раздела** в верхнем левом углу (название раздела со стрелкой), выберите **Settings** и нажмите **Roles**.
2. Нажмите кнопку плюс и выберите **Add Custom Role**.
3. Назовите роль "Streaming Host" и нажмите **Save**.
4. Нажмите новую роль, затем нажмите **Add** в разделе Members для добавления людей.
5. Прокрутите вниз до **Edit Permissions**, разверните раздел **Content** и установите флажок **Host Chat**.

Когда хосты входят на страницу прямого эфира, рядом с публичным чатом появляется частная вкладка **Host Chat** для разговора только для сотрудников во время трансляции.

:::info
Для получения дополнительной информации о создании ролей и управлении разрешениями см. [Roles & Permissions](../settings/roles-permissions.md).
:::

## Устранение неполадок

Если ваш автоматический прямой эфир YouTube не отображается правильно при использовании опции "Current YouTube Live Stream" с вашим Channel ID, попробуйте следующее:

**Симптомы:**
- Встраивание прямого эфира показывает "Video unavailable"
- Страница загружается, но видео не появляется
- Прямые встраивания YouTube работают, но автоматический прямой эфир канала нет

**Решение:**
Проверьте ваш канал YouTube на наличие старых или предстоящих запланированных прямых эфиров и удалите их:

1. Перейдите в YouTube Studio.
2. Перейдите в **Content**, затем **Live**.
3. Ищите старые запланированные прямые эфиры или предстоящие запланированные потоки.
4. Удалите эти старые или запланированные записи прямого эфира.
5. Проверьте вашу страницу прямого эфира снова.

:::warning
Автоматическое встраивание прямого эфира канала YouTube может быть заблокировано, если в вашем канале есть несколько запланированных или прошлых записей прямого эфира. Удаление этих записей позволяет YouTube правильно идентифицировать и служить вашему текущему прямому эфиру.
:::

**Дополнительные требования:**
- Ваш прямой эфир должен быть установлен на **Public** (не Unlisted или Private).
- Встраивание должно быть разрешено в ваших параметрах потока YouTube.
- Убедитесь, что вы используете провайдер **Current YouTube Live Stream** (с Channel ID), а не провайдер **YouTube** (с Video ID).
