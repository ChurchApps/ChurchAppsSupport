# Массовый импорт

<div class="article-intro">

Страница Bulk Import позволяет вам быстро заполнить вашу библиотеку проповедей путем импорта видео с YouTube или Vimeo. Это самый быстрый способ привести ваш существующий контент проповеди, а не добавлять каждое видео по одному.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужно разрешение **contentApi.streamingServices.edit**. См. [Roles & Permissions](../settings/roles-permissions.md), если у вас нет доступа.
- Создайте по крайней мере один [плейлист](playlists) для импорта ваших проповедей
- Подготовьте ваш YouTube Channel ID или информацию учетной записи Vimeo

</div>

## Выбор вашего источника

1. В B1 Admin откройте **меню раздела** в верхнем левом углу (название раздела со стрелкой) и выберите **Sermons**, затем нажмите вкладку **Bulk Import**.
2. Вы увидите две щелкаемые карточки:
   - **YouTube** (красная) — Импортируйте видео с канала YouTube
   - **Vimeo** (синяя) — Импортируйте видео из учетной записи Vimeo
3. Нажмите карточку для платформы, где размещены ваши проповеди.

:::tip
Вы можете вернуться и переключить источники в любое время, если у вас есть видео на обеих платформах.
:::

## Перед импортом

Перед импортом видео вам нужен по крайней мере один плейлист для их организации. Если вы еще не создали никаких плейлистов:

1. Нажмите вкладку **Playlists**.
2. Нажмите **Create First Playlist** и заполните имя, описание, дату публикации и миниатюру.
3. Нажмите **Save**, затем вернитесь к вкладке **Bulk Import**.

См. [Playlists](playlists) для получения подробных инструкций по созданию и управлению плейлистами.

## Импорт видео

1. После выбора YouTube или Vimeo введите ваш **YouTube Channel ID** или **Vimeo account information** в предоставленное поле.
2. Нажмите кнопку **Fetch** для получения всех доступных видео с вашего канала или учетной записи.
3. После извлечения вы увидите список всех ваших видео с флажками.
4. Установите флажки рядом с видео, которые вы хотите импортировать. Вы можете выбрать все или выбрать конкретные.
5. Опционально включите **Auto Import New Videos** для автоматического добавления будущих загрузок в вашу библиотеку.
6. Нажмите на раскрывающееся меню **Import Into Playlist** для выбора плейлиста, в который должны быть добавлены эти видео.
7. Нажмите кнопку **Import** для завершения массового импорта.

Ваши видео будут импортированы со всеми их деталями, включая заголовки, описания, даты и миниатюры.

:::info
Массовый импорт идеален для начала работы при переходе с другой платформы. Для добавления отдельных проповедей в будущем используйте страницу [Managing Sermons](managing-sermons) вместо этого.
:::
