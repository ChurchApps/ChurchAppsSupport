# Массовый импорт

<div class="article-intro">

Страница "Массовый импорт" позволяет быстро заполнить библиотеку проповедей, импортируя видео с YouTube или Vimeo. Это самый быстрый способ привнести ваш существующий контент проповедей вместо добавления каждого видео по одному.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужно разрешение **contentApi.streamingServices.edit**. Если у вас нет доступа, см. раздел [Роли и разрешения](../settings/roles-permissions.md).
- Создайте хотя бы один [плейлист](playlists), в который будут импортироваться ваши проповеди
- Подготовьте свой ID канала YouTube или информацию учетной записи Vimeo

</div>

## Выбор вашего источника

1. В B1 Admin откройте **меню раздела** в верхнем левом углу (название раздела со стрелкой) и выберите **Проповеди**. Нажмите **Добавить проповедь** и выберите **Массовый импорт** из меню.
2. Вы увидите две интерактивные карточки:
   - **YouTube** (красная) -- Импорт видео с канала YouTube
   - **Vimeo** (синяя) -- Импорт видео с учетной записи Vimeo
3. Нажмите на карточку платформы, где размещены ваши проповеди.

:::tip
Вы можете вернуться и переключать источники в любое время, если у вас есть видео на обеих платформах.
:::

## Перед импортом

Перед импортом видео вам нужен хотя бы один плейлист для их организации. Если вы еще не создали плейлисты:

1. Нажмите вкладку **Плейлисты**.
2. Нажмите **Создать первый плейлист** и заполните название, описание, дату публикации и миниатюру.
3. Нажмите **Сохранить**, затем вернитесь на вкладку **Массовый импорт**.

Подробные инструкции по созданию и управлению плейлистами см. в разделе [Плейлисты](playlists).

## Импорт видео

1. После выбора YouTube или Vimeo введите свой **ID канала YouTube** или **информацию учетной записи Vimeo** в предоставленное поле.
2. Нажмите кнопку **Получить**, чтобы получить все доступные видео с вашего канала или учетной записи.
3. После получения вы увидите список всех ваших видео с флажками.
4. Установите флажки рядом с видео, которые вы хотите импортировать. Вы можете выбрать все или определенные видео.
5. При необходимости включите **Автоматический импорт новых видео**, чтобы автоматически добавлять будущие загрузки в библиотеку.
6. Нажмите на раскрывающееся меню **Импорт в плейлист**, чтобы выбрать, в какой плейлист следует добавить эти видео.
7. Нажмите кнопку **Импорт**, чтобы завершить массовый импорт.

Ваши видео будут импортированы со всеми деталями, включая названия, описания, даты и миниатюры.

:::info
Массовый импорт идеален для начала работы при миграции с другой платформы. Для добавления отдельных проповедей в будущем используйте страницу [Управление проповедями](managing-sermons).
:::
