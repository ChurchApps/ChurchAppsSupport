# Массовый импорт

<div class="article-intro">

Страница Bulk Import позволяет быстро наполнить библиотеку проповедей, импортируя видео с YouTube или Vimeo. Это самый быстрый способ перенести существующий контент проповедей, не добавляя каждое видео по отдельности.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Нужно право **contentApi.streamingServices.edit**. Если у вас нет доступа, см. [Роли и разрешения](../settings/roles-permissions.md).
- Создайте хотя бы один [плейлист](playlists), в который будут импортированы проповеди
- Подготовьте ID вашего канала YouTube или данные учётной записи Vimeo

</div>

## Выбор источника

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **Sermons** и нажмите **Sermons**. Нажмите **Add Sermon** и выберите **Bulk Import** в меню.
2. В разделе **Choose Import Source** доступны два варианта:
   - **YouTube** — импорт видео из канала YouTube
   - **Vimeo** — импорт видео из учётной записи Vimeo
3. Нажмите вариант для платформы, где размещены ваши проповеди (или нажмите **Import from YouTube** / **Import from Vimeo** под её описанием). Нажмите **Back** вверху страницы, чтобы вернуться к выбору источника.

:::tip
Вы можете в любой момент вернуться и сменить источник, если видео есть на обеих платформах.
:::

## Перед импортом

Прежде чем импортировать видео, нужен хотя бы один плейлист, чтобы разложить их по нему. Если плейлистов ещё нет:

1. Вернитесь на страницу **Sermons** и найдите панель **Playlists**.
2. Нажмите **Create First Playlist** и заполните название, описание, дату публикации и миниатюру.
3. Нажмите **Save**, затем вернитесь к Bulk Import, нажав **Add Sermon** и выбрав **Bulk Import**.

Подробные инструкции по созданию и управлению плейлистами см. в разделе [Playlists](playlists).

## Импорт видео

1. После выбора YouTube или Vimeo введите **YouTube Channel ID** или **данные учётной записи Vimeo** в соответствующее поле.
2. Нажмите кнопку **Fetch**, чтобы получить все доступные видео из вашего канала или учётной записи.
3. После получения вы увидите список всех ваших видео с флажками.
4. Отметьте видео, которые хотите импортировать. Можно выбрать все или только некоторые.
5. При желании включите **Auto Import New Videos**, чтобы автоматически добавлять в библиотеку будущие загрузки.
6. Нажмите раскрывающийся список **Import Into Playlist**, чтобы выбрать, в какой плейлист добавить эти видео.
7. Нажмите кнопку **Import**, чтобы завершить массовый импорт.

Видео будут импортированы со всеми их данными, включая названия, описания, даты и миниатюры. Специальные символы в названиях и описаниях YouTube, такие как `&`, апострофы и кавычки, сохраняются как есть, а не превращаются в коды вроде `&amp;`.

:::info
Массовый импорт идеально подходит для старта, если вы переходите с другой платформы. Чтобы добавлять отдельные проповеди в дальнейшем, используйте страницу [Managing Sermons](managing-sermons).
:::
