# Массовый импорт

<div class="article-intro">

Страница "Массовый импорт" позволяет вам быстро заполнить вашу библиотеку проповедей, импортируя видео из YouTube или Vimeo. Это самый быстрый способ привнести ваше существующее содержание проповедей, чем добавлять каждое видео по одному.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам требуется разрешение **contentApi.streamingServices.edit**. См. [Роли и разрешения](../settings/roles-permissions.md), если у вас нет доступа.
- Создайте хотя бы один [плейлист](playlists), в который импортировать ваши проповеди
- Имейте готовыми ID канала YouTube или информацию аккаунта Vimeo

</div>

## Выбор вашего источника

1. В B1 Admin откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **Проповеди**, и щелкните **Проповеди**. Щелкните **Добавить проповедь** и выберите **Массовый импорт** из меню.
2. Вы увидите две кликабельные карточки:
   - **YouTube** (красная) - импортировать видео из канала YouTube
   - **Vimeo** (синяя) - импортировать видео из аккаунта Vimeo
3. Щелкните на карточку для платформы, где размещены ваши проповеди.

:::tip
Вы можете вернуться и переключать источники в любое время, если у вас есть видео на обеих платформах.
:::

## Перед импортом

Перед импортом видео вам нужен хотя бы один плейлист для их организации. Если вы еще не создали никаких плейлистов:

1. Вернитесь на страницу **Проповеди** и найдите панель **Плейлисты**.
2. Щелкните **Создать первый плейлист** и заполните имя, описание, дату публикации и миниатюру.
3. Щелкните **Сохранить**, затем вернитесь к массовому импорту, щелкнув **Добавить проповедь** и выбрав **Массовый импорт**.

См. [Плейлисты](playlists) для получения подробных инструкций по созданию и управлению плейлистами.

## Импорт видео

1. После выбора YouTube или Vimeo введите ваш **ID канала YouTube** или **информацию аккаунта Vimeo** в предоставленное поле.
2. Щелкните кнопку **Получить**, чтобы получить все доступные видео из вашего канала или аккаунта.
3. После получения вы увидите список всех ваших видео с флажками.
4. Установите флажки рядом с видео, которые вы хотите импортировать. Вы можете выбрать все или выбрать конкретные.
5. При необходимости включите **Автоматический импорт новых видео**, чтобы автоматически добавлять будущие загрузки в вашу библиотеку.
6. Щелкните на раскрывающийся список **Импортировать в плейлист**, чтобы выбрать, в какой плейлист должны быть добавлены эти видео.
7. Щелкните кнопку **Импорт**, чтобы завершить массовый импорт.

Ваши видео будут импортированы со всеми их деталями, включая названия, описания, даты и миниатюры.

:::info
Массовый импорт идеален для начала работы при миграции с другой платформы. Для добавления отдельных проповедей в дальнейшем используйте вместо этого страницу [Управление проповедями](managing-sermons).
:::
