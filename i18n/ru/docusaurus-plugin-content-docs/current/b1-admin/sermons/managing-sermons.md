# Управление проповедями

<div class="article-intro">

Страница Sermons отображает вашу полную библиотеку проповедей. Отсюда вы можете добавлять новые проповеди, редактировать существующие записи и организовывать ваш контент по плейлистам. Каждая проповедь может ссылаться на видео или аудио, размещенные на YouTube, Vimeo, Facebook или пользовательском URL.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужно разрешение **contentApi.streamingServices.edit**. См. [Roles & Permissions](../settings/roles-permissions.md), если у вас нет доступа.
- Создайте по крайней мере один [плейлист](playlists) для организации ваших проповедей
- Подготовьте ваши ID видео или URL с YouTube, Vimeo или Facebook

</div>

## Просмотр вашей библиотеки проповедей

1. В B1 Admin откройте **меню раздела** в верхнем левом углу (название раздела со стрелкой) и выберите **Sermons**.
2. Страница Sermons показывает все ваши записи проповедей, организованные по плейлистам. Каждая проповедь отображает свою миниатюру, заголовок и дату.
3. Нажмите на любую проповедь для просмотра или редактирования ее деталей.

## Добавление проповеди

1. Нажмите кнопку **Add Sermon** в верхнем правом углу и выберите **Add Sermon** из раскрывающегося меню.
2. Выберите **Playlist** для назначения проповеди.
3. Выберите ваш **Video Provider** — YouTube, Vimeo, Facebook или Custom URL. Мы рекомендуем YouTube, так как он лучше всего работает с системой B1.
4. Введите ID видео или URL и нажмите **Fetch**. Для YouTube, ID видео — это строка символов после `v=` в URL YouTube.
5. Когда вы нажимаете **Fetch**, детали проповеди импортируются автоматически, включая дату публикации, длительность, заголовок, описание и миниатюру.
6. Внесите любые изменения, которые вы хотите, и нажмите **Save**.

:::tip
Вы также можете добавить постоянный живой URL потока, выбрав **Add Permanent Live URL** из раскрывающегося меню **Add Sermon**. Это создает постоянное подключение к потоку прямого эфира вашего канала YouTube, используя ваш Channel ID. См. [Live Streaming](live-streaming) для получения дополнительной информации.
:::

## Редактирование проповеди

1. Нажмите на любую проповедь в вашей библиотеке для открытия ее деталей.
2. Обновите заголовок, докладчика, дату, описание, миниатюру или ссылки на СМИ по мере необходимости.
3. Нажмите **Save** для применения ваших изменений.

## Детали проповеди

Каждая запись проповеди может включать:

- **Title** — Имя проповеди, отображаемое посетителям
- **Speaker** — Кто предоставил проповедь
- **Date** — Дата публикации или доставки
- **Description** — Резюме содержания проповеди
- **Thumbnail** — Изображение предпросмотра, показанное в вашей библиотеке проповедей
- **Video/Audio Links** — URL в проповедь СМИ на YouTube, Vimeo, Facebook или пользовательском хосте

## Планирование проповеди для прямого эфира

После добавления проповеди вы можете запланировать ее для трансляции на вашей странице прямого эфира:

1. Перейдите на вкладку **Live Stream Times**.
2. Отредактируйте услугу и в разделе **Video Settings** выберите вашу проповедь из раскрывающегося меню.
3. Проповедь будет воспроизводиться в запланированное время услуги.

:::info
Для импорта нескольких проповедей одновременно вместо добавления их по одному используйте инструмент [Bulk Import](bulk-import) для извлечения видео прямо из вашей учетной записи YouTube или Vimeo.
:::
