# Управление проповедями

<div class="article-intro">

Страница Sermons показывает всю вашу библиотеку проповедей. Отсюда вы можете добавлять новые проповеди, редактировать существующие записи и упорядочивать контент по плейлистам. Каждая проповедь может ссылаться на видео или аудио, размещённые на YouTube, Vimeo, Facebook или по произвольной ссылке.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужно разрешение **Edit Services** в разделе **Content** вашей роли. Если у вас нет доступа, см. [Роли и разрешения](../settings/roles-permissions.md).
- Создайте хотя бы один [плейлист](./playlists.md), чтобы упорядочить в нём проповеди
- Подготовьте ID видео или ссылки на YouTube, Vimeo или Facebook

</div>

## Просмотр библиотеки проповедей {#viewing-your-sermon-library}

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), раскройте **Sermons** и нажмите **Sermons**.
2. На странице Sermons записи отображаются в таблице со столбцами **Playlist**, названием (**Sermon**) и **Publish Date**, сначала самые новые, а также с количеством, например «11 of 11 sermons». Введите текст в поле **Search sermons by title or playlist...**, чтобы отфильтровать список. Ваши плейлисты перечислены на панели **Playlists** рядом с таблицей, а под ней расположена панель **Podcast Feed**.
3. Наведите курсор на строку проповеди и нажмите **Edit**, чтобы просмотреть или изменить её данные.

## Добавление проповеди {#adding-a-sermon}

1. Нажмите кнопку **Add Sermon** в правом верхнем углу и выберите **Add Sermon** в выпадающем меню. Над списком откроется форма **Edit Sermon**.
2. Выберите **Playlist**, в который нужно поместить проповедь (или оставьте **None**).
3. Выберите **Video Provider** — **YouTube**, **Vimeo**, **Facebook** или **Custom Embed Url**. Мы рекомендуем YouTube, так как он лучше всего работает с системой B1.
4. Введите **YouTube ID**, **Vimeo ID**, **Sermon ID** (для Facebook) или **Sermon Embed Url** видео. Можно вставить всю ссылку на видео — B1 сохранит только ID. Для YouTube ID видео — это последовательность символов после `v=` в ссылке YouTube.
5. Для YouTube и Vimeo нажмите **Fetch**, чтобы автоматически импортировать данные проповеди, включая дату публикации, продолжительность, название, описание и миниатюру. Если данные не удалось загрузить, появится сообщение, и вы сможете заполнить их вручную.
6. Внесите нужные изменения и нажмите **Save**.

:::tip
Также можно добавить постоянную ссылку на прямую трансляцию, выбрав **Add Permanent Live URL** в выпадающем меню **Add Sermon**. Это создаёт постоянное подключение к прямой трансляции вашего канала YouTube по Channel ID. Подробнее см. в разделе [Прямая трансляция](./live-streaming.md).
:::

## Редактирование проповеди {#editing-a-sermon}

1. Нажмите **Edit** в любой строке проповеди в библиотеке, чтобы открыть её данные.
2. При необходимости измените название, дату, описание, миниатюру, продолжительность или медиассылки.
3. Нажмите **Save**, чтобы применить изменения, или **Cancel**, чтобы закрыть форму.

Чтобы удалить проповедь, откройте её, нажмите **Delete** и подтвердите действие.

### Добавление проповеди в другой плейлист {#adding-a-sermon-to-another-playlist}

Чтобы указать одну и ту же проповедь во втором плейлисте (например, проповедь, которая входит и в серию, и в подборку «Best Of»), откройте проповедь, нажмите **Add to another playlist**, выберите плейлист и нажмите **Add**. При этом в выбранном плейлисте сохраняется копия проповеди.

## Данные проповеди {#sermon-details}

Каждая запись о проповеди может включать:

- **Playlist** — серию, к которой относится проповедь
- **Video Provider** и ID видео — где размещено видео проповеди: YouTube, Vimeo, Facebook или произвольная ссылка для встраивания
- **Publish Date** — дату публикации проповеди; у проповедей без даты в списке отображается **Not scheduled**
- **Total Sermon Duration** — продолжительность проповеди в минутах и секундах
- **Thumbnail** — предварительное изображение, которое показывается в вашей библиотеке проповедей. Нажмите на изображение, чтобы обрезать или заменить его (16:9).
- **Title** — название проповеди, которое видят посетители
- **Description** — краткое описание содержания проповеди
- **Audio File URL (for podcast)** — прямая ссылка на файл MP3/M4A для этой проповеди. Можно вставить URL или, после сохранения проповеди, нажать **Upload Audio**, чтобы загрузить файл и заполнить поле автоматически. В ленту подкаста попадают только проповеди, у которых заполнено это поле (или прямая ссылка на видеофайл).

## Лента подкаста {#your-podcast-feed}

Как только к одной из проповедей будет прикреплён аудио- или видеофайл, B1 Admin автоматически создаёт RSS-ленту подкаста для вашей церкви — включать ничего не нужно. Найдите её на панели **Podcast Feed** рядом со списком проповедей (под панелью **Playlists**): нажмите значок копирования, чтобы скопировать URL ленты, и затем отправьте этот URL в Apple Podcasts, Spotify или любой другой каталог подкастов.

:::info
Проповеди, которые только ссылаются на встроенный плеер (например, по ID видео на YouTube или Vimeo), не появляются в ленте подкаста: приложениям для подкастов нужен прямой файл для скачивания. Чтобы включить проповедь в ленту, добавьте **Audio File URL**.
:::

## Планирование проповеди для прямой трансляции {#scheduling-a-sermon-for-live-stream}

После добавления проповеди её можно запланировать для трансляции на странице прямой трансляции:

1. В меню Jump выберите **Sermons > Live Stream Times**.
2. Откройте службу для редактирования и в разделе **Video Settings** выберите вашу проповедь в выпадающем списке **Sermon**.
3. Проповедь будет воспроизводиться в запланированное время службы.

:::info
Чтобы импортировать сразу несколько проповедей вместо добавления по одной, используйте инструмент [Массовый импорт](./bulk-import.md), который загружает видео непосредственно из вашего аккаунта YouTube или Vimeo.
:::
