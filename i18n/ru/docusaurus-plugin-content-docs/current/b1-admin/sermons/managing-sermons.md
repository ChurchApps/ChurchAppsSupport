# Управление проповедями

<div class="article-intro">

Страница проповедей отображает вашу полную библиотеку проповедей. Отсюда вы можете добавлять новые проповеди, редактировать существующие записи и организовывать ваш контент по плейлистам. Каждая проповедь может ссылаться на видео или аудио, размещенные на YouTube, Vimeo, Facebook или пользовательском URL.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужно разрешение **contentApi.streamingServices.edit**. См. [Роли и разрешения](../settings/roles-permissions.md), если у вас нет доступа.
- Создайте хотя бы один [плейлист](playlists) для организации ваших проповедей
- Подготовьте ID видео или URL с YouTube, Vimeo или Facebook

</div>

## Просмотр вашей библиотеки проповедей

1. В B1 Admin откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **Проповеди** и нажмите на **Проповеди**.
2. Страница проповедей показывает все ваши записи проповедей, организованные по плейлистам. Каждая проповедь отображает свой эскиз, заголовок и дату.
3. Щелкните на любую проповедь, чтобы просмотреть или отредактировать её детали.

## Добавление проповеди

1. Нажмите кнопку **Добавить проповедь** в верхнем правом углу и выберите **Добавить проповедь** из раскрывающегося меню.
2. Выберите **Плейлист** для добавления проповеди.
3. Выберите вашего **Видеопровайдера** -- YouTube, Vimeo, Facebook или пользовательский URL. Мы рекомендуем YouTube, так как он лучше всего работает с системой B1.
4. Введите ID видео или URL и нажмите **Загрузить**. Для YouTube, ID видео - это строка символов после `v=` в URL YouTube.
5. Когда вы нажимаете **Загрузить**, детали проповеди импортируются автоматически, включая дату публикации, продолжительность, заголовок, описание и эскиз.
6. Внесите любые нужные изменения и нажмите **Сохранить**.

:::tip
Вы также можете добавить постоянный URL прямой трансляции, выбрав **Добавить постоянный URL прямой трансляции** из раскрывающегося меню **Добавить проповедь**. Это создает постоянное соединение с прямой трансляцией вашего канала YouTube с использованием вашего ID канала. Подробнее см. в разделе [Прямая трансляция](live-streaming).
:::

## Редактирование проповеди

1. Щелкните на любую проповедь в вашей библиотеке, чтобы открыть её детали.
2. Обновите заголовок, докладчика, дату, описание, эскиз или ссылки на медиа по необходимости.
3. Нажмите **Сохранить**, чтобы применить ваши изменения.

## Детали проповеди

Каждая запись проповеди может включать:

- **Заголовок** -- название проповеди, отображаемое для посетителей
- **Докладчик** -- кто произносил проповедь
- **Дата** -- дата публикации или произнесения
- **Описание** -- краткое описание содержания проповеди
- **Эскиз** -- изображение предпросмотра, показываемое в вашей библиотеке проповедей
- **Ссылки видео/аудио** -- URL адреса проповеди на YouTube, Vimeo, Facebook или пользовательском хосте
- **URL аудиофайла (для подкаста)** -- прямая ссылка на MP3/M4A файл для этой проповеди. Либо вставьте URL, либо нажмите **Загрузить аудио**, чтобы загрузить файл и автоматически его заполнить. В вашей ленте подкаста включены только проповеди с установленным этим полем (или прямой ссылкой на видеофайл).

## Ваша лента подкаста

Как только у хотя бы одной проповеди есть присоединённый аудио или видеофайл, B1 Admin автоматически генерирует RSS ленту подкаста для вашей церкви -- нет ничего, что нужно включать. Найдите её в панели **Лента подкаста** под списком проповедей: нажмите значок копирования, чтобы скопировать URL ленты, затем отправьте этот URL в Apple Podcasts, Spotify или любой другой каталог подкастов.

:::info
Проповеди, которые ссылаются только на встроенный плеер (например, ID видео YouTube или Vimeo), не будут отображаться в ленте подкаста -- приложения подкастов нуждаются в прямом, загружаемом медиафайле. Добавьте **URL аудиофайла**, чтобы включить проповедь.
:::

## Планирование проповеди для прямой трансляции

После добавления проповеди вы можете запланировать её трансляцию на странице прямой трансляции:

1. В меню Jump выберите **Проповеди > Время прямой трансляции**.
2. Отредактируйте богослужение и под **Параметры видео** выберите вашу проповедь из раскрывающегося меню.
3. Проповедь будет воспроизведена в запланированное время богослужения.

:::info
Для импорта нескольких проповедей одновременно вместо их добавления по одной используйте инструмент [Массовый импорт](bulk-import), чтобы загрузить видео непосредственно с вашего аккаунта YouTube или Vimeo.
:::
