# Запустите веб-сайт вашей церкви

<div class="article-intro">

B1.church включает полнофункциональный конструктор веб-сайтов без дополнительных затрат. Это руководство проведет вас через процесс создания веб-сайта вашей церкви с нуля — настройки домашней страницы, настройки внешнего вида, добавления ключевых страниц и опционального подключения сбора пожертвований в Интернете и форм регистрации на события.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Подготовьте логотип вашей церкви (PNG с прозрачным фоном работает лучше всего)
- Выберите 2–3 брендовых цвета для вашего сайта
- Если вы используете пользовательский домен (например, yourchurch.com), имейте доступ к вашему провайдеру DNS (GoDaddy, Cloudflare и т. д.)
- Если вы хотите принимать пожертвования в Интернете на вашем сайте, сначала завершите [Настройку сбора пожертвований](../donations/online-giving-setup.md) (Stripe)

</div>

## Шаг 1: Начальная настройка веб-сайта

Начните с создания домашней страницы и базовой структуры сайта.

Следуйте руководству [Начальная настройка веб-сайта](../website/initial-setup.md):

1. Перейдите на **Веб-сайт** в B1 Admin
2. Создайте домашнюю страницу с героическим разделом, приветственным сообщением и ключевой информацией
3. Добавьте название вашей церкви и слоган

## Шаг 2: Настройка внешнего вида

Установите визуальную идентичность вашего сайта — цвета, шрифты, логотип и нижний колонтитул.

Следуйте руководству [Внешний вид](../website/appearance.md):

1. Загрузите логотип вашей церкви
2. Установите основные и дополнительные цвета
3. Настройте панель навигации и нижний колонтитул
4. Просмотрите ваши изменения

:::tip
Держите цветовую палитру простой — основного цвета плюс один дополнительный цвет обычно достаточно. Конструктор веб-сайтов справится с остальным.
:::

## Шаг 3: Добавление страниц с содержимым

Постройте страницы, которые нужны вашим посетителям больше всего.

Следуйте руководству [Управление страницами](../website/managing-pages.md), чтобы создать страницы, такие как:

- **О нас** — История вашей церкви, убеждения и руководство
- **Проповеди** — Ссылка на вашу [библиотеку проповедей](../sermons/managing-sermons.md)
- **События** — Предстоящие события и регистрация
- **Пожертвовать** — Страница сбора пожертвований в Интернете (требуется [настройка Stripe](../donations/online-giving-setup.md))
- **Контакты** — Местоположение, время служб и информацию о контактах

## Шаг 4: Подключение вашего домена

Если вы хотите использовать свое собственное имя домена (например, yourchurch.com) вместо URL-адреса B1 по умолчанию:

1. Перейдите в **Параметры** в B1 Admin и откройте раздел **Домены**
2. Введите ваш пользовательский домен
3. Обновите записи DNS у вашего провайдера домена, чтобы они указывали на B1

:::info
Изменения DNS могут занять до 48 часов для распространения. Ваш сайт может быть недоступен с вашего пользовательского домена немедленно. URL-адрес B1 по умолчанию будет продолжать работать в течение этого времени.
:::

## Шаг 5: Добавление пожертвований и форм

Улучшите ваш сайт интерактивными элементами:

- **Сбор пожертвований в Интернете** — Добавьте раздел пожертвований, чтобы члены могли делать пожертвования прямо с вашего веб-сайта. См. [Настройку сбора пожертвований](../donations/online-giving-setup.md), чтобы сначала настроить Stripe.
- **Формы регистрации** — Встройте [Самостоятельные формы](../forms/creating-forms.md) для регистрации на события, карточки посетителей или заявки волонтеров. См. [Управление страницами](../website/managing-pages.md), чтобы узнать, как добавить элемент формы на любую страницу.

## Готово!

Веб-сайт вашей церкви запущен. Поделитесь URL-адресом с вашей паствой и в социальных сетях. Вы можете обновлять содержимое, добавлять новые страницы и изменять внешний вид в любое время из панели управления B1 Admin.
