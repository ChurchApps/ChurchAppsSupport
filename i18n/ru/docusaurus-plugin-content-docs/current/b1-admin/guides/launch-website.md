# Запуск сайта вашей церкви

<div class="article-intro">

B1.church включает полноценный конструктор сайтов без дополнительной платы. Это руководство проведёт вас через создание сайта церкви с нуля: настройку главной страницы, оформление внешнего вида, добавление ключевых страниц и, при желании, подключение онлайн-пожертвований и форм регистрации на события.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Подготовьте логотип церкви (лучше всего подходит PNG с прозрачным фоном)
- Выберите 2–3 фирменных цвета для сайта
- Если вы используете собственный домен (например, yourchurch.com), у вас должен быть доступ к вашему DNS-провайдеру (GoDaddy, Cloudflare и т. д.)
- Если вы хотите принимать онлайн-пожертвования на сайте, сначала выполните [настройку онлайн-пожертвований](../donations/online-giving-setup.md) (Stripe)

</div>

## Шаг 1: первоначальная настройка сайта

Начните с создания главной страницы и базовой структуры сайта.

Следуйте руководству [Первоначальная настройка сайта](../website/initial-setup.md), чтобы:

1. Перейти в раздел **Website** в B1 Admin
2. Создать главную страницу с блоком-героем, приветственным сообщением и ключевой информацией
3. Добавить название церкви и слоган

## Шаг 2: настройка внешнего вида

Задайте визуальный облик сайта: цвета, шрифты, логотип и подвал.

Следуйте руководству [Appearance](../website/appearance.md), чтобы:

1. Загрузить логотип церкви
2. Задать основной и акцентный цвета
3. Настроить панель навигации и подвал
4. Просмотреть изменения в предпросмотре

:::tip
Держите цветовую палитру простой -- обычно достаточно основного цвета и одного акцентного. Остальное сделает конструктор сайтов.
:::

## Шаг 3: добавление страниц с контентом

Создайте страницы, которые нужнее всего вашим посетителям.

Следуйте руководству [Managing Pages](../website/managing-pages.md), чтобы создать такие страницы, как:

- **About** -- История вашей церкви, её убеждения и руководство
- **Sermons** -- Ссылка на вашу [библиотеку проповедей](../sermons/managing-sermons.md)
- **Events** -- Предстоящие события и регистрация
- **Give** -- Страница онлайн-пожертвований (требуется [настройка Stripe](../donations/online-giving-setup.md))
- **Contact** -- Адрес, время служений и контактная информация

## Шаг 4: подключение домена

Если вы хотите использовать собственное доменное имя (например, yourchurch.com) вместо адреса B1 по умолчанию:

1. Перейдите в **Settings** в B1 Admin и откройте раздел **Domains**
2. Введите ваш собственный домен
3. Обновите DNS-записи у вашего регистратора домена, чтобы они указывали на B1

:::info
Изменения DNS могут распространяться до 48 часов. Сайт может быть недоступен по вашему собственному домену сразу. Адрес B1 по умолчанию будет продолжать работать в это время.
:::

## Шаг 5: добавление пожертвований и форм

Сделайте сайт интерактивнее:

- **Online Giving** -- Добавьте блок пожертвований, чтобы участники могли жертвовать прямо с вашего сайта. Чтобы сначала настроить Stripe, см. [Настройку онлайн-пожертвований](../donations/online-giving-setup.md).
- **Registration Forms** -- Встройте [формы Stand Alone](../forms/creating-forms.md) для записи на события, карточек гостей или заявок волонтёров. Как добавить элемент формы на любую страницу, см. в [Managing Pages](../website/managing-pages.md).

## Готово!

Сайт вашей церкви запущен. Поделитесь адресом с прихожанами и в социальных сетях. Вы можете обновлять контент, добавлять новые страницы и менять оформление в любое время из панели B1 Admin.
