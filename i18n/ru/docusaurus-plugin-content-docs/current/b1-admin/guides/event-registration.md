# Настройка регистрации на мероприятие

<div class="article-intro">

Создайте форму регистрации на мероприятие, собирайте данные участников и необязательные платежи, встраивайте форму на сайт церкви и обрабатывайте заявки по мере их поступления. В результате у вас будет страница регистрации, которой можно поделиться, для любого церковного мероприятия.

</div>

:::info
**Два способа организовать регистрацию на мероприятие:** В этом руководстве описана **регистрация через формы**, которая даёт полный контроль над пользовательскими полями и сбором платежей. Для простых мероприятий, где нужно лишь отслеживать, кто придёт, используйте **встроенную регистрацию** в календаре — инструкции по настройке см. в разделе [Создание календарей](../calendars/creating-calendars.md#enabling-event-registration). Встроенная регистрация позволяет участникам записываться прямо из [B1.church или приложения B1 App](../../b1-church/events/registering.md), с учётом количества мест, датами открытия записи и подтверждениями по электронной почте.
:::

<div class="prereqs">
<h4>Перед началом</h4>

- Учётная запись B1 Admin с правами администратора
- Для сбора платежей: сначала необходимо [настроить Stripe](../donations/online-giving-setup.md)

</div>

## Шаг 1: Создайте отдельную форму

Отдельные формы (Stand Alone) имеют собственный публичный адрес, доступный любому пользователю, — это идеально подходит для регистрации на мероприятие.

Следуйте руководству [Создание форм](../forms/creating-forms.md), чтобы:

1. Перейти в раздел «Формы» и нажать «Добавить форму»
2. Выбрать тип «Stand Alone» — так форма получит собственный публичный адрес
3. Назвать форму по мероприятию (например, «Регистрация на мужской выезд», «Запись на ВБШ»)

## Шаг 2: Добавьте вопросы

Создайте поля, которые необходимо заполнить участникам.

Следуйте руководству [Создание форм](../forms/creating-forms.md#adding-questions), чтобы добавить вопросы:

1. Перейдите на вкладку «Вопросы» и добавьте поля для нужной информации: имя, электронная почта, телефон, пищевые ограничения, размер футболки, контакт для экстренной связи и т. д.
2. Используйте «Множественный выбор» для вариантов, например предпочтений в питании или выбора занятий

:::warning
Тип поля «Платёж» требует настройки Stripe. Если вы ещё не настроили онлайн-пожертвования, см. раздел [Настройка онлайн-пожертвований](../donations/online-giving-setup.md) перед добавлением полей для платежей.
:::

## Шаг 3: Настройте параметры формы

Укажите, когда и как будет доступна форма регистрации.

1. Задайте даты доступности, если регистрация должна быть открыта только в течение ограниченного времени
2. Скопируйте публичный адрес — им можно поделиться напрямую
3. Добавьте участников формы с ролями «Администратор» или «Только просмотр», чтобы они помогали обрабатывать заявки

## Шаг 4: Встройте форму на сайт

Сделайте форму регистрации легко находимой, добавив её на сайт церкви.

Следуйте руководству [Управление страницами](../website/managing-pages.md), чтобы:

1. В редакторе сайта B1 добавить новый раздел на страницу и выбрать элемент «Форма»
2. Выбрать форму регистрации из списка

:::tip
Также рассылайте отдельный адрес формы по электронной почте, в социальных сетях и в церковных бюллетенях — чем больше мест, где она видна, тем больше будет заявок.
:::

## Шаг 5: Обрабатывайте заявки

Отслеживайте регистрации по мере их поступления и при необходимости экспортируйте данные.

Следуйте руководству [Обработка заявок](../forms/managing-submissions.md), чтобы:

1. Просматривать ответы по мере их поступления на вкладке «Заявки»
2. Экспортировать данные в CSV для таблиц, подсчёта участников или передачи координаторам мероприятия

## Готово!

Ваша регистрация на мероприятие запущена. Поделитесь ссылкой, встройте форму на сайт и отслеживайте заявки в B1 Admin. Когда мероприятие завершится, экспортируйте итоговый список для своих записей.
