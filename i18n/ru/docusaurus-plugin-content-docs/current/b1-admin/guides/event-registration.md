# Настройка регистрации на событие

<div class="article-intro">

Создайте форму регистрации на событие, собирайте данные участников и необязательные платежи, встройте форму на сайт вашей общины и управляйте ответами по мере их поступления. В итоге у вас будет страница регистрации, которой можно поделиться, для любого мероприятия церкви.

</div>

:::info
**Два способа организовать регистрацию на событие:** это руководство описывает **регистрацию через форму** — отдельную форму Stand Alone с собственной публичной ссылкой, пользовательскими вопросами и необязательным полем оплаты. Для события в вашем календаре можно вместо этого использовать **регистрацию на событие**, встроенную в календарь, — см. [Создание календарей](../calendars/creating-calendars.md#enabling-event-registration). Она позволяет участникам записываться напрямую из [B1.church или приложения B1](../../b1-church/events/registering.md) с ограничением вместимости, датами открытия и закрытия, листом ожидания, необязательными вопросами регистрации из формы и платными типами участников (см. [Платные регистрации](../calendars/paid-registrations.md)).
:::

<div class="prereqs">
<h4>Перед началом</h4>

- Учетная запись B1 Admin с административным доступом
- Для приема платежей сначала [нужно настроить Stripe](../donations/online-giving-setup.md)

</div>

## Шаг 1. Создайте форму Stand Alone {#step-1-create-a-stand-alone-form}

У форм Stand Alone есть собственный публичный адрес, доступный каждому, — это идеально подходит для регистрации на события.

Следуйте руководству [Создание форм](../forms/creating-forms.md), чтобы:

1. В [меню Jump](../introduction.md#getting-around-with-the-jump-menu) выбрать **People > Forms** и нажать **Add Form**
2. Назвать форму по событию (например, «Men's Retreat Registration», «VBS Sign-Up»)
3. В **Associate With** выбрать **Stand Alone** — это даст форме собственный публичный адрес
4. Нажать **Save**

## Шаг 2. Добавьте вопросы {#step-2-add-questions}

Создайте поля, которые нужно собрать от участников.

Следуйте руководству [Создание форм](../forms/creating-forms.md#adding-questions), чтобы добавить вопросы:

1. Откройте форму, перейдите на вкладку **Questions** и нажмите **Add Question** для каждой нужной информации: имя, email, телефон, диетические ограничения, размер футболки, контакт для экстренной связи и т. д.
2. Используйте **Multiple Choice** для вариантов вроде предпочтений в питании или выбора занятий
3. Чтобы собрать плату, добавьте вопрос типа **Payment** и выберите его **Fund** и **Amount**

:::warning
Тип поля Payment требует настроенного Stripe. Если вы еще не настроили онлайн-пожертвования, см. [Настройка онлайн-пожертвований](../donations/online-giving-setup.md) перед добавлением полей оплаты.
:::

## Шаг 3. Настройте параметры формы {#step-3-configure-form-settings}

Определите, когда и как доступна форма регистрации. Следуйте разделу [Настройка свойств формы](../forms/creating-forms.md#configuring-form-properties), чтобы:

1. Нажать **Edit Form** и, если регистрация должна быть открыта только в течение ограниченного времени, установить **Set Form Availability Timeframe** в значение **Yes** и выбрать даты начала и окончания
2. Скопировать **публичный адрес**, показанный слева на странице формы, — им можно поделиться напрямую. Нажмите **QR Code** рядом с формой в списке Forms, чтобы скачать QR-код для листовок и слайдов
3. На вкладке **Form Members** добавить людей с ролью **Admin** или **View Only**, чтобы помогать управлять ответами, и включить **Email Notification** для тех, кто должен получать письмо о каждой новой регистрации

## Шаг 4. Встройте форму на сайт {#step-4-embed-on-your-website}

Сделайте форму регистрации легко находимой, добавив ее на сайт вашей общины.

Следуйте руководству [Редактор страниц](../website/page-editor.md), чтобы:

1. Открыть страницу в редакторе сайта B1 и нажать **Add Content**
2. Перетащить элемент **Form** в раздел и выбрать форму регистрации

:::tip
Поделитесь отдельным адресом также по email, в социальных сетях и в церковных бюллетенях — чем больше мест, где он виден, тем больше записей вы получите.
:::

## Шаг 5. Управляйте ответами {#step-5-manage-submissions}

Отслеживайте регистрации по мере их поступления и экспортируйте данные, когда они понадобятся.

Следуйте руководству [Работа с ответами на формы](../forms/managing-submissions.md), чтобы:

1. Просматривать ответы по мере поступления на вкладке **Form Submissions**
2. Нажать **Export**, чтобы скачать CSV для таблиц, учета числа участников или передачи координаторам мероприятия

## Готово! {#youre-done}

Ваша регистрация на событие запущена. Поделитесь ссылкой, встройте форму на сайт и отслеживайте записи в B1 Admin. Когда событие завершится, экспортируйте итоговый список для ваших записей.
