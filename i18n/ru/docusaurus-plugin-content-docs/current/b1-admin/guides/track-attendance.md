# Учёт посещаемости церкви

<div class="article-intro">

Настройте учёт посещаемости для служений и групп: от настройки кампусов и времени служений до ручной отметки или самостоятельной регистрации через приложение и просмотра динамики в отчётах. В результате у вас будет полная картина того, кто и когда присутствует.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Учётная запись B1 Admin с правами администратора
- [Люди, добавленные в ваш каталог](../people/adding-people.md)
- [Созданные группы](../groups/creating-groups.md) для служений, посещаемость которых вы хотите отслеживать

</div>

## Шаг 1: Настройте кампусы и служения {#step-1-configure-campuses--services}

Укажите, где и когда собирается ваша церковь.

Следуйте руководству [Настройка посещаемости](../attendance/setup.md), чтобы:

1. В [меню Jump](../introduction.md#getting-around-with-the-jump-menu) выберите **People > Attendance** и нажмите **Setup**
2. Добавьте ваш кампус (например, «Основной кампус») и его служения
3. Добавьте время служений (например, «Воскресенье 9:00», «Воскресенье 11:00», «Среда 19:00»)

## Шаг 2: Включите учёт посещаемости групп {#step-2-enable-group-attendance-tracking}

Включите учёт посещаемости для групп, которые хотите контролировать.

Следуйте руководству [Создание групп](../groups/creating-groups.md), чтобы:

1. Откройте каждую группу, которую хотите отслеживать, нажмите **Edit** и установите **Track Attendance** в значение **Yes**
2. Если группа собирается во время служения, выберите время в поле **Add Service Time** и нажмите кнопку плюс, чтобы посещаемость записывалась на нужное служение, затем нажмите **Save**

:::info
Учёт посещаемости нужен не всем группам. Включайте его для групп, участие в которых вы хотите отслеживать: детских классов, малых групп, воскресной школы и т. д.
:::

## Шаг 3: Отмечайте посещаемость вручную {#step-3-record-attendance-manually}

Отмечайте, кто присутствовал на каждом служении и в каждой группе.

Следуйте руководству [Запись посещаемости](../attendance/recording-attendance.md), чтобы:

1. Откройте группу, нажмите **All sessions** в разделе **Sessions**, нажмите **New** и выберите **Service Time** и **Session Date**. Отметьте **Also add for the other _N_ groups in _service time_**, чтобы сразу создать сессии для всех классов в это время служения
2. Отметьте присутствующих и нажмите **Save Attendance**

Если нужен только общий итог, а не имена (например, для основного служения), нажмите **Enter headcount** на странице **Attendance** — см. [Ввод количества присутствующих](../attendance/headcount-entry.md).

:::tip
Ручной учёт отлично подходит для взрослых служений, малых групп и любых ситуаций, когда киоск регистрации недоступен.
:::

## Шаг 4: Настройте самостоятельную регистрацию (необязательно) {#step-4-set-up-self-check-in-optional}

Позвольте участникам регистрироваться самостоятельно на планшетном киоске.

Следуйте руководству [Регистрация](../attendance/check-in.md), чтобы:

1. Установите приложение B1 Checkin на планшет для самостоятельной регистрации
2. Участники ищут своё имя и регистрируют себя и свою семью
3. Записи о регистрации появляются вместе с записями, внесёнными вручную, — разницы в данных нет

:::info
Полную настройку детского служения, включая оборудование и настройку принтера, см. в [Руководстве по детской регистрации](./childrens-checkin.md).
:::

## Шаг 5: Просмотрите отчёты о посещаемости {#step-5-view-attendance-reports}

Получите общую картину участия по всей церкви.

Следуйте руководству [Отчёты о посещаемости](../reports/attendance-reports.md). На странице **Attendance** нажмите **All years**, чтобы найти эти отчёты во вкладках:

1. **Attendance Trend** — динамика посещаемости во времени, чтобы заметить рост или снижение
2. **Headcount Trend** — график итогов количества присутствующих, которые вы ввели вручную
3. **Group Attendance** — кто присутствовал на каждой сессии группы за выбранный период, с выгрузкой CSV

Для ежедневного подсчёта по одной группе откройте отчёт **Daily Group Attendance** по адресу **admin.b1.church/reports/dailyGroupAttendance**.

:::info
Отчёты о посещаемости объединяют данные, отмеченные вручную, и данные самостоятельной регистрации. Данные отображаются одинаково: оба способа попадают в одни и те же отчёты.
:::

## Готово! {#youre-done}

Ваш учёт посещаемости настроен. Вы отмечаете посещаемость вручную, используете приложение регистрации или и то, и другое — все данные попадают в одни и те же отчёты, и вы получаете ясную картину участия по всей церкви.
