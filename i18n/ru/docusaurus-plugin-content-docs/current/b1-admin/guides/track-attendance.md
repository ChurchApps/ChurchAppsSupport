# Отслеживание посещаемости

<div class="article-intro">

Настройте отслеживание посещаемости для ваших служб и групп — от настройки кампусов и времени служб до ввода посещаемости вручную или через приложение самообслуживания, до просмотра тенденций в отчётах. К концу вы получите полное представление о том, кто посещает и когда.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Учетная запись B1 Admin с правами администратора
- [Люди добавлены в ваш справочник](../people/adding-people.md)
- [Группы созданы](../groups/creating-groups.md) для служений, которые вы хотите отслеживать

</div>

## Шаг 1: Настройка кампусов и служ

Определите, где и когда встречается ваша церковь.

Следуйте руководству [Настройка посещаемости](../attendance/setup.md):

1. Добавьте ваш кампус (например, "Основной кампус")
2. Добавьте время служб (например, "Воскресенье 9:00 AM", "Воскресенье 11:00 AM", "Среда 7:00 PM")
3. Назначьте группы каждому времени служ, чтобы определить, какие классы/служения проводятся во время этой служ

## Шаг 2: Включение отслеживания посещаемости группы

Включите отслеживание посещаемости для групп, которые вы хотите мониторить.

Следуйте руководству [Создание групп](../groups/creating-groups.md):

1. Отредактируйте каждую группу, которую вы хотите отслеживать, и включите "Track Attendance"
2. Свяжите группы с временем служб, чтобы посещаемость записывалась для правильной служ

:::info
Не каждой группе нужно отслеживание посещаемости. Включите его для групп, где вы хотите мониторить участие — детские классы, малые группы, воскресная школа и т.д.
:::

## Шаг 3: Запись посещаемости вручную

Отметьте, кто посетил каждую служ и группу.

Следуйте руководству [Запись посещаемости](../attendance/recording-attendance.md):

1. Откройте вкладку **Sessions** группы и добавьте сессию для даты и времени служ. Отметьте **Also add for the other groups**, чтобы создать сессии для всех классов во время этой служ сразу.
2. Отметьте, кто посетил каждую группу

:::tip
Ручное отслеживание хорошо работает для служ взрослых, малых групп и любых ситуаций, где киоск регистрации невозможен.
:::

## Шаг 4: Настройка самостоятельной регистрации (дополнительно)

Позвольте членам зарегистрироваться самостоятельно, используя киоск на планшете.

Следуйте руководству [Check-In](../attendance/check-in.md):

1. Установите приложение B1 Checkin на планшет для самообслуживания
2. Члены ищут свое имя и регистрируют себя и свою семью
3. Записи посещаемости check-in появляются рядом с вручную введенными записями — нет никакой разницы в данных

:::info
Для полной настройки детского служения, включая оборудование и конфигурацию принтера, см. [Руководство по регистрации детей](./childrens-checkin.md).
:::

## Шаг 5: Просмотр отчётов по посещаемости

Получите общее представление об участии по всей вашей церкви.

Следуйте руководству [Отчёты по посещаемости](../reports/attendance-reports.md). Доступны три представления отчётов:

1. **Attendance Trend** — смотрите посещаемость с течением времени, чтобы обнаружить рост или спад
2. **Group Attendance** — смотрите, кто посетил каждую сессию группы в диапазоне дат, с загрузкой CSV
3. **Daily Group Attendance** — день за днем для детального анализа

:::info
Отчёты объединяют как вручную записанную, так и самостоятельно отмеченную посещаемость. Нет никакой разницы в том, как данные отображаются — оба метода питают одни и те же отчёты.
:::

## Готово!

Отслеживание посещаемости настроено. Будь то ручное введение посещаемости, использование приложения check-in или обоих — все данные поступают в одни и те же отчёты, чтобы у вас было четкое представление об участии по всей вашей церкви.
