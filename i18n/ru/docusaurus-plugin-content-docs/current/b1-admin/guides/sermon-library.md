# Создание библиотеки проповедей и прямой трансляции

<div class="article-intro">

Разместите архив проповедей в сети и настройте прямую трансляцию — от импорта вашей существующей библиотеки YouTube или Vimeo до планирования регулярных прямых эфиров с интерактивным чатом. В результате ваша община сможет смотреть прошлые проповеди и присоединяться к прямым эфирам на вашем сайте и в мобильном приложении.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Учетная запись B1 Admin с разрешением на управление контентом
- Канал YouTube или Vimeo с видео проповедей (для импорта вашего архива)
- ID канала YouTube (для прямой трансляции — найдите его в настройках YouTube Studio)

</div>

## Шаг 1: Создайте плейлисты проповедей

Плейлисты упорядочивают ваши проповеди по сериям и подборкам для удобного просмотра.

Следуйте руководству [Playlists](../sermons/playlists.md), чтобы:

1. Создать серии/подборки, например «Воскресные проповеди 2024», «Серия о браке», «Рождественские службы»
2. Добавить название, описание, дату публикации и миниатюру для каждого плейлиста

:::tip
Создавайте плейлисты до добавления проповедей. Так будет проще распределять проповеди по нужным сериям по мере их добавления.
:::

## Шаг 2: Импортируйте существующие проповеди

Если у вас уже есть видео проповедей на YouTube или Vimeo, вы можете загрузить их все сразу.

Следуйте руководству [Bulk Import](../sermons/bulk-import.md), чтобы:

1. Ввести URL вашего канала YouTube или Vimeo
2. Просмотреть предварительный список, чтобы увидеть, какие видео будут импортированы
3. Нажать «Import», чтобы добавить их все сразу

## Шаг 3: Добавьте отдельные проповеди

Для единичных добавлений или проповедей, не входящих в массовый импорт, добавляйте их по одной.

Следуйте руководству [Managing Sermons](../sermons/managing-sermons.md), чтобы:

1. Вставить URL видео (YouTube, Vimeo или Facebook)
2. Название, описание, миниатюра и продолжительность заполнятся автоматически из метаданных видео
3. Назначить проповедь плейлисту

## Шаг 4: Настройте прямую трансляцию

Подключите ваш канал YouTube, чтобы сайт B1 автоматически подхватывал ваш прямой эфир.

Следуйте руководству [Live Streaming](../sermons/live-streaming.md), чтобы:

1. Ввести ID канала YouTube в настройках трансляции
2. Настроить расписание регулярных служб (например, по воскресеньям в 10:00)
3. Настроить вкладки страницы трансляции (Chat, Prayer requests и пользовательские ссылки) на странице **Sermons > Settings**

:::info
Когда вы начнете трансляцию на YouTube, страница трансляции B1 автоматически подхватит эфир. В воскресенье утром никаких дополнительных действий не требуется.
:::

## Шаг 5: Разместите на вашем сайте

Сделайте вашу библиотеку проповедей и прямую трансляцию легко доступными для посетителей.

Следуйте руководству [Managing Pages](../website/managing-pages.md), чтобы:

1. Добавить на ваш сайт B1 раздел «Sermons», чтобы посетители могли просматривать библиотеку
2. Добавить раздел «Live Stream» для просмотра прямого эфира

## Шаг 6: Доступ с мобильных устройств

Члены общины могут смотреть проповеди и прямые службы с любого устройства.

1. Члены общины могут смотреть проповеди в [мобильном приложении B1](../../b1-mobile/content/sermons.md) и на [B1.church](../../b1-church/content/sermons.md)
2. Прямая трансляция с чатом работает на обеих платформах

:::info
Функция живого чата позволяет вашей онлайн-общине участвовать в режиме реального времени, как если бы люди были в зале.
:::

## Готово!

Ваша библиотека проповедей доступна онлайн, а прямая трансляция настроена. Члены общины могут посмотреть прошлые проповеди в любое время и присоединиться к прямым службам из любой точки. Новые загрузки проповедей могут синхронизироваться автоматически.
