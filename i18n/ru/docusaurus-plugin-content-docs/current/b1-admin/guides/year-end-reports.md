# Формирование годовых отчётов о пожертвованиях

<div class="article-intro">

Этот материал описывает годовой процесс: завершение учёта пожертвований, проверку настроек фондов и формирование для каждого донора справок о пожертвованиях, учитываемых при налогообложении. Обычно это делают в начале января за предыдущий календарный год.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Учётная запись B1 Admin с доступом к финансовым разделам
- Пожертвования, учтённые в течение года (онлайн через Stripe и/или введённые вручную)
- Доступ к вашей учётной записи Stripe, если вы принимаете онлайн-пожертвования

</div>

## Шаг 1: импорт итоговых транзакций Stripe

Убедитесь, что все онлайн-пожертвования за конец года есть в системе.

Следуйте руководству [Импорт из Stripe](../donations/stripe-import.md), чтобы:

1. Перейти в раздел Donations > Stripe Import
2. Выбрать диапазон дат, охватывающий конец года (например, с 1 по 31 декабря)
3. Сначала нажать Preview, чтобы просмотреть данные, а затем Import Missing для завершения импорта

:::warning
Выполните этот импорт до формирования справок. Транзакции, которые не были импортированы, не появятся в справках доноров.
:::

## Шаг 2: проверка отчётов о пожертвованиях

Перед формированием справок убедитесь, что записи верны.

Следуйте руководству [Отчёты о пожертвованиях](../donations/donation-reports.md), чтобы:

1. Проверить сводную страницу пожертвований за весь год
2. Сравнить итоги по каждому фонду с банковскими выписками и выявить расхождения
3. При необходимости открыть отдельные пакеты (batches) и проверить данные по каждому донору

## Шаг 3: проверка налогового статуса фондов

Убедитесь, что для каждого фонда правильно указана настройка налогового вычета, чтобы справки были точными.

Следуйте руководству [Фонды](../donations/funds.md), чтобы:

1. Открыть каждый фонд и убедиться, что настройка «учитывается при налогообложении» указана верно

:::info
В справки о пожертвованиях попадают только пожертвования в фонды, отмеченные как учитываемые при налогообложении. Если фонд должен быть таким, но не отмечен, обновите его до формирования справок.
:::

## Шаг 4: формирование справок о пожертвованиях

Создайте официальные справки о пожертвованиях для ваших доноров.

Следуйте руководству [Справки о пожертвованиях](../donations/giving-statements.md), чтобы:

1. Перейти в раздел **Donations > Giving Statements**
2. Выбрать год в выпадающем списке и просмотреть сводную статистику
3. Выбрать способ загрузки:
   - **Download ZIP** — отдельные CSV-файлы, по одному на каждого донора
   - **Print All** — версия для печати, где каждая справка начинается с новой страницы и вверху которой расположен логотип церкви (если вы его загрузили)

:::tip
Формируйте справки в начале января, пока данные свежи. Так у вас останется время исправить возможные ошибки до отправки справок.
:::

## Шаг 5: передача донорам

Доставьте справки донорам.

1. Распечатайте справки и отправьте их почтой или отправьте отдельные CSV-файлы донорам по электронной почте
2. Участники также могут просмотреть свою историю пожертвований и распечатать справки на [B1.church или в приложении B1 App](../../b1-church/giving/donation-history.md)

## Готово!

Годовые отчёты о пожертвованиях сформированы. Доноры получили справки о пожертвованиях, учитываемых при налогообложении, а финансовые записи за год закрыты.
