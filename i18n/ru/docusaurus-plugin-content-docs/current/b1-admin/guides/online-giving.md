# Настройка онлайн-пожертвований

<div class="article-intro">

Пройдите все необходимое, чтобы принимать онлайн-пожертвования в вашей общине: от создания фондов пожертвований до подключения Stripe для обработки платежей и публикации страницы пожертвований для вашей общины. В итоге участники смогут жертвовать онлайн через ваш сайт и мобильное приложение.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Учетная запись B1 Admin с административным доступом — см. [Роли и права доступа](../people/roles-permissions.md)
- Учетная запись Stripe (при необходимости создайте бесплатно на [stripe.com](https://stripe.com))

</div>

## Шаг 1. Создайте фонды пожертвований {#step-1-create-donation-funds}

Фонды — это категории, на которые жертвователи могут давать. Прежде чем принимать пожертвования, нужно создать хотя бы один фонд.

Следуйте руководству [Фонды](../donations/funds.md), чтобы настроить категории пожертвований:

1. В [меню Jump](../introduction.md#getting-around-with-the-jump-menu) выбрать **Donations > Funds** и нажать **Add Fund**
2. Создайте самые распространенные фонды (например, «General Fund», «Building Fund», «Missions»)
3. Отметьте **Tax Deductible** для фондов, пожертвования в которые должны попадать в годовые выписки о пожертвованиях, и оставьте **Visible to Donors** отмеченным для фондов, которые жертвователи должны иметь возможность выбрать онлайн

:::tip
Вы можете добавить другие фонды в любое время. Начните с самых распространенных категорий пожертвований.
:::

## Шаг 2. Подключите Stripe {#step-2-connect-stripe}

Stripe обрабатывает все платежи. Вы подключите ваш аккаунт Stripe к B1 Admin, чтобы пожертвования поступали на ваш банковский счет.

Следуйте руководству [Настройка онлайн-пожертвований](../donations/online-giving-setup.md), чтобы подключить Stripe:

1. Войдите в панель Stripe и перейдите в **Developers > API Keys**, чтобы найти Publishable Key и Secret Key
2. В B1 Admin перейдите в **Settings**, нажмите **Edit** в разделе **Giving** и установите **Provider** в значение **Stripe**
3. Вставьте Publishable Key в поле **Public Key**, а Secret Key — в поле **Secret Key**, проверьте **Currency** и нажмите **Save**

B1 также поддерживает **Kingdom Funding** и **Paystack** (для общин в Африке) как провайдеров пожертвований — см. [Настройка онлайн-пожертвований](../donations/online-giving-setup.md).

:::warning
Stripe показывает ваш Secret Key только один раз. Скопируйте и сохраните его, прежде чем покинуть панель Stripe. Если вы его потеряете, придется создать новый.
:::

## Шаг 3. Добавьте страницу пожертвований на ваш сайт {#step-3-add-a-giving-page-to-your-website}

Сделайте пожертвования доступными, добавив страницу пожертвований на ваш сайт B1.

Следуйте руководствам [Настройка онлайн-пожертвований](../donations/online-giving-setup.md) и [Управление страницами](../website/managing-pages.md), чтобы:

1. Добавить вкладку **Donation** на ваш сайт B1.church (или элемент **Donation** на страницу в конструкторе сайтов)
2. Адрес страницы пожертвований будет таким: `https://yoursubdomain.b1.church/donate`
3. Участники могут жертвовать без входа в систему (публичная страница) или войти, чтобы использовать сохраненные способы оплаты и видеть историю пожертвований
4. Чтобы направить жертвователей сразу в один фонд, нажмите **Giving Link** у этого фонда в разделе **Donations > Funds**, чтобы скопировать ссылку (или скачать QR-код) с уже выбранными фондом и суммой

## Шаг 4. Сделайте тестовое пожертвование {#step-4-make-a-test-donation}

Прежде чем объявлять об этом вашей общине, проверьте, что все работает.

1. Сделайте небольшое тестовое пожертвование, чтобы проверить весь процесс от начала до конца
2. Убедитесь, что пожертвование появилось в B1 Admin в разделе **Donations > Batches**

:::tip
Чтобы проверить без реальных списаний, сначала сохраните тестовые ключи Stripe, а затем замените их боевыми в **Settings > Giving** перед объявлением вашей общине.
:::

## Шаг 5. Объявите о пожертвованиях вашей общине {#step-5-announce-to-your-congregation}

Расскажите людям, что они могут жертвовать онлайн.

1. Поделитесь адресом пожертвований через ваш сайт, email-рассылки, бюллетени и социальные сети
2. Участники также могут жертвовать через [приложение B1](../../b1-church/giving/index.md) — функция пожертвований встроена в него

:::info
Участники, которые вошли в систему, могут сохранять способы оплаты, настраивать регулярные пожертвования и просматривать историю пожертвований. Анонимные пожертвования тоже работают — вход в систему не требуется.
:::

## Шаг 6. Текущее управление {#step-6-ongoing-management}

Поддерживайте записи о пожертвованиях в актуальном состоянии и формируйте отчеты в течение года.

1. Онлайн-подарки записываются автоматически. Используйте [Импорт из Stripe](../donations/stripe-import.md), чтобы поймать транзакции Stripe, которые не синхронизировались: нажмите **Preview**, чтобы увидеть, чего не хватает, затем **Import Missing**
2. [Просматривайте отчеты о пожертвованиях](../donations/donation-reports.md) в разделе **Donations > Summary**, чтобы отслеживать тенденции пожертвований и итоги по фондам
3. Проверяйте **Donations > Failed Gifts** для регулярных подарков, по которым карта была отклонена, и нажимайте **Retry**, когда жертвователь обновит способ оплаты
4. [Формируйте годовые выписки о пожертвованиях](../donations/giving-statements.md) для налоговых записей жертвователей

:::tip
Запускайте предпросмотр Stripe Import перед закрытием каждого месяца, чтобы ваши записи совпадали со Stripe. Полный порядок работы в конце года см. в [Руководстве по годовым отчетам](./year-end-reports.md).
:::

## Готово! {#youre-done}

Ваша община теперь принимает онлайн-пожертвования. Участники могут жертвовать через ваш сайт, приложение B1 или любое устройство с веб-браузером. Все пожертвования автоматически учитываются в B1 Admin.
