# Настройка регистрации в детском служении

<div class="article-intro">

Это руководство проведёт вас через все шаги, необходимые для запуска системы регистрации детей в вашей церкви: от внесения семей в базу данных до настройки возрастных групп и печати именных бейджей в воскресное утро. В итоге родители смогут зарегистрировать детей на киоске-планшете и получить соответствующую защитную метку.

</div>

## Шаг 1: Добавьте семьи в базу данных

Прежде чем регистрация сможет работать, системе нужно знать о ваших семьях. Каждый ребёнок должен быть связан с родителем через функцию домохозяйства.

Следуйте руководству [Добавление людей](../people/adding-people.md), чтобы добавить хотя бы одну семью. Обязательно:

- Сначала добавьте родителя (родителей)
- Добавьте каждого ребёнка
- Свяжите их в одном домохозяйстве с помощью [редактора домохозяйств](../people/adding-people.md#managing-households)

:::tip
Если нужно добавить больше нескольких семей, используйте инструмент [импорта CSV](../people/importing-data.md) вместо добавления по одной. Весь каталог можно импортировать за несколько минут.
:::

## Шаг 2: Создайте группы для детей

Группы определяют классы, в которые регистрируются дети. Обычно удобно иметь одну группу на каждый возрастной диапазон.

Следуйте руководству [Создание групп](../groups/creating-groups.md), чтобы создать группы вроде:

- **Nursery** (от 0 до 2 лет)
- **Preschool** (от 3 до 5 лет)
- **Elementary** (от 6 до 10 лет)

Названия и возрастные диапазоны можно изменить в соответствии со структурой вашего служения.

## Шаг 3: Настройте кампусы и служения

Регистрация привязана к конкретным временам служений. Нужны хотя бы один кампус и одно служение.

Следуйте руководству [Настройка посещаемости](../attendance/setup.md), чтобы:

1. Добавить ваш кампус (например, «Main Campus»)
2. Добавить служение (например, «Sunday Morning»)
3. Задать время служения (например, «9:00 AM») и, при желании, [расписание регистрации](../attendance/setup.md#setting-a-check-in-schedule), чтобы регистрация автоматически открывалась перед каждым служением и закрывалась после него
4. Назначить группы детей на служение

## Шаг 4: Настройте приложение регистрации

Теперь свяжите всё, установив приложение регистрации на планшет.

1. Установите **приложение B1 Checkin** -- ссылки для загрузки см. в статье [Регистрация (Check-In)](../attendance/check-in.md)
2. Войдите, используя ваши учётные данные B1 Admin
3. Выберите ваш кампус и время служения

Подробные шаги настройки см. в полной статье [Регистрация (Check-In)](../attendance/check-in.md).

## Шаг 5: Подготовьте оборудование

Для киоска нужен планшет, а для именных бейджей по желанию -- принтер этикеток Brother.

Минимально необходимо:
- **Один планшет Android или Amazon Fire** -- см. [рекомендуемые планшеты](../attendance/check-in.md#recommended-hardware)
- **Один принтер этикеток Brother** -- рекомендуется QL-1110NWB благодаря поддержке Bluetooth и WiFi
- **Этикетки Brother DK-1201** (1-1/7" x 3-1/2")

:::warning
Приложению B1 Checkin совместимы только принтеры этикеток Brother. Принтеры других марок не будут работать.
:::

## Шаг 6: Проведите пробную регистрацию

До воскресного утра проведите пробный запуск:

1. Откройте приложение B1 Checkin на вашем планшете
2. Выберите ваш кампус и нужное время служения
3. Найдите одну из добавленных вами семей
4. Зарегистрируйте ребёнка и проверьте:
   - что посещаемость появляется в B1 Admin в разделе **Attendance**
   - если используете принтер, что именной бейдж печатается правильно

:::tip
Перед запуском проведите обучение для волонтёров службы приёма на процесс регистрации. Обычно достаточно короткого 5-минутного инструктажа.
:::

## Готово!

Регистрация в детском служении готова. Родители могут найти свою семью, выбрать детей и зарегистрироваться на киоске. Посещаемость автоматически записывается в B1 Admin.
