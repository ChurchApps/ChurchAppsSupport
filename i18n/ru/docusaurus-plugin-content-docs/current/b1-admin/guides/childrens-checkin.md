# Настройка регистрации в детском служении

<div class="article-intro">

Это руководство проведёт вас через всё необходимое, чтобы в вашей церкви заработала система регистрации детей: от внесения семей в базу и настройки групп по возрасту до печати именных бейджей в воскресное утро. В итоге родители смогут регистрировать детей на киоске-планшете и получать соответствующий защитный бейдж.

</div>

## Шаг 1. Добавьте семьи в базу данных

Прежде чем регистрация заработает, система должна знать о ваших семьях. Каждый ребёнок должен быть связан с родителем через функцию домохозяйства.

Следуйте руководству [Добавление людей](../people/adding-people.md), чтобы добавить хотя бы одну семью. Обязательно:

- Сначала добавьте родителя (родителей)
- Добавьте каждого ребёнка
- Свяжите их в одном домохозяйстве с помощью [редактора домохозяйств](../people/adding-people.md#managing-households)

:::tip
Если семей больше нескольких, используйте инструмент [CSV Import](../people/importing-data.md) вместо того, чтобы добавлять их по одной. Весь ваш каталог можно импортировать за несколько минут.
:::

## Шаг 2. Создайте группы для детей

Группы определяют классы, в которые регистрируются дети. Обычно стоит сделать одну группу на возрастной диапазон.

Следуйте руководству [Создание групп](../groups/creating-groups.md), чтобы создать группы, например:

- **Ясли** (возраст 0–2)
- **Дошкольники** (возраст 3–5)
- **Младшие школьники** (возраст 6–10)

Названия и возрастные диапазоны можно изменить в соответствии со структурой вашего служения.

## Шаг 3. Настройте кампусы и служения

Регистрация привязана к конкретным временам служений. Нужен хотя бы один кампус и одно служение.

Следуйте руководству [Настройка посещаемости](../attendance/setup.md), чтобы:

1. Добавить ваш кампус (например, «Главный кампус»)
2. Добавить служение (например, «Воскресное утро»)
3. Задать время служения (например, «9:00») и, по желанию, [расписание регистрации](../attendance/setup.md#setting-a-check-in-schedule), чтобы регистрация открывалась автоматически перед каждым служением и закрывалась после него
4. Назначить группы для детей на это служение

## Шаг 4. Настройте приложение регистрации

Теперь соедините всё, установив приложение регистрации на планшет.

1. Установите **приложение B1 Checkin** — ссылки для загрузки см. в статье [Регистрация на службе](../attendance/check-in.md)
2. Войдите, используя учётные данные B1 Admin
3. Выберите ваш кампус и время служения

Полную инструкцию по настройке см. в статье [Регистрация на службе](../attendance/check-in.md).

## Шаг 5. Подготовьте оборудование

Для киоска нужен планшет, а для именных бейджей по желанию — принтер этикеток Brother.

Минимально необходимо:
- **Один планшет Android или Amazon Fire** — см. [рекомендуемые планшеты](../attendance/check-in.md#recommended-hardware)
- **Один принтер этикеток Brother** — рекомендуется QL-1110NWB за поддержку Bluetooth и Wi-Fi
- **Этикетки Brother DK-1201** (1-1/7" x 3-1/2")

:::warning
С приложением B1 Checkin совместимы только принтеры этикеток Brother. Принтеры других марок не будут работать.
:::

## Шаг 6. Проведите пробную регистрацию

Перед воскресным утром проведите тестовый запуск:

1. Откройте приложение B1 Checkin на планшете
2. Выберите ваш кампус и нужное время служения
3. Найдите одну из добавленных вами семей
4. Зарегистрируйте ребёнка и проверьте:
   - что посещаемость появляется в B1 Admin в разделе **Attendance**
   - если используется принтер, что именной бейдж печатается правильно

:::tip
Перед запуском проведите обучение для волонтёров службы приёма. Обычно достаточно короткого 5-минутного инструктажа.
:::

## Готово!

Регистрация в детском служении готова. Родители могут найти свою семью, выбрать детей и зарегистрировать их на киоске. Посещаемость автоматически записывается в B1 Admin.
