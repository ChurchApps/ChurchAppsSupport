# Настройка регистрации в детском служении

<div class="article-intro">

Это руководство проведет вас через все необходимое, чтобы в вашей общине заработала система регистрации детей — от внесения семей в базу до настройки возрастных групп и печати бейджей в воскресное утро. В итоге родители смогут зарегистрировать детей на киоске-планшете и получить соответствующую защитную метку.

</div>

## Шаг 1. Добавьте семьи в базу данных {#step-1-add-families-to-your-database}

Прежде чем регистрация заработает, системе нужно знать о ваших семьях. Каждый ребенок должен быть связан с родителем через функцию домохозяйств.

Следуйте руководству [Добавление людей](../people/adding-people.md), чтобы добавить хотя бы одну семью. Обязательно:

- Сначала добавьте родителя(ей)
- Добавьте каждого ребенка
- Свяжите их в одном домохозяйстве с помощью [редактора домохозяйств](../people/adding-people.md#managing-households)

:::tip
Если семей больше нескольких, используйте инструмент [импорта CSV](../people/importing-data.md) вместо того, чтобы добавлять их по одной. Весь каталог можно импортировать за несколько минут.
:::

## Шаг 2. Создайте детские группы {#step-2-create-childrens-groups}

Группы определяют классы, в которые регистрируются дети. Обычно удобно иметь одну группу на каждый возрастной диапазон.

Следуйте руководству [Создание групп](../groups/creating-groups.md), чтобы создать группы, например:

- **Nursery** (возраст 0–2 года)
- **Preschool** (возраст 3–5 лет)
- **Elementary** (возраст 6–10 лет)

Названия и возрастные диапазоны можно изменить, чтобы они соответствовали структуре вашего служения. Затем откройте настройки каждой группы (нажмите **Edit** на странице группы) и:

- Установите **Track Attendance** в значение **Yes**, чтобы в группу можно было регистрироваться
- Включите **Print Nametag** (и **Parent Pickup**, если печатаете талоны на выдачу)
- При желании задайте ограничения **Age & Grade**, чтобы киоск подсказывал нужную комнату, — см. [Безопасность регистрации](../attendance/checkin-safety.md)

## Шаг 3. Настройте кампусы и службы {#step-3-configure-campuses-and-services}

Регистрация привязана к конкретным временам служб. Нужно настроить хотя бы один кампус и одну службу.

Следуйте руководству [Настройка посещаемости](../attendance/setup.md), чтобы:

1. Перейти в **People > Attendance** и нажать **Setup**
2. Добавить ваш кампус (например, «Main Campus»)
3. Добавить службу (например, «Sunday Morning»)
4. Добавить время службы (например, «9:00 AM») и, при желании, [расписание регистрации](../attendance/setup.md#setting-a-check-in-schedule), чтобы регистрация открывалась автоматически перед каждой службой и закрывалась после нее
5. Связать каждую детскую группу с временем службы: откройте группу, нажмите **Edit**, выберите время в **Add Service Time** и нажмите кнопку «плюс»

## Шаг 4. Настройте приложение регистрации {#step-4-set-up-the-check-in-app}

Теперь соедините все вместе, установив приложение регистрации на планшет.

1. Установите **приложение B1 Checkin** — ссылки для загрузки см. в статье [Регистрация на службу](../attendance/check-in.md)
2. Войдите под учетной записью, у которой есть право посещаемости **Checkin** (или **Edit Attendance**), — см. [Учетные записи киосков регистрации](../settings/roles-permissions.md#check-in-kiosk-accounts)
3. Выберите ваш кампус и время службы

Подробные шаги настройки см. в статье [Регистрация на службу](../attendance/check-in.md).

## Шаг 5. Подготовьте оборудование {#step-5-get-your-hardware}

Нужен планшет для киоска и, по желанию, принтер этикеток Brother для бейджей.

Минимум:
- **Один планшет iPad, Android или Amazon Fire** — см. [рекомендуемые планшеты](../attendance/check-in.md#recommended-hardware)
- **Один принтер этикеток Brother** — рекомендуется QL-1110NWB за поддержку Bluetooth и WiFi
- **Этикетки Brother DK-1201** (1-1/7" x 3-1/2")

:::warning
С приложением B1 Checkin совместимы только принтеры этикеток Brother. Принтеры других марок не работают.
:::

## Шаг 6. Проведите тестовую регистрацию {#step-6-run-a-test-check-in}

До воскресного утра проведите тестовый запуск:

1. Откройте приложение B1 Checkin на планшете
2. Выберите ваш кампус и правильное время службы
3. Найдите одну из добавленных семей
4. Зарегистрируйте ребенка и проверьте:
   - Посещаемость появилась в B1 Admin в разделе **People > Attendance**
   - Если используется принтер, бейдж печатается правильно

:::tip
Перед запуском проведите обучение волонтеров группы приветствия процессу регистрации. Обычно достаточно короткого 5-минутного инструктажа.
:::

## Готово! {#youre-done}

Регистрация в детском служении настроена. Родители могут найти свою семью, выбрать детей и зарегистрировать их на киоске. Посещаемость автоматически записывается в B1 Admin.
