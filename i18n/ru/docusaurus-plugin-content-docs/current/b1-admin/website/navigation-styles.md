# Стили навигации

<div class="article-intro">

Настройте цвета панели навигации сайта вашей церкви, чтобы они соответствовали фирменному стилю. Вы можете задать цвета и для сплошного фона, и для прозрачного наложения, полностью контролируя внешний вид навигации на разных страницах.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Нужно разрешение на редактирование содержимого сайта. Подробности см. в разделе [Роли и разрешения](../settings/roles-permissions.md).
- Подготовьте фирменные цвета, включая hex-коды (например, #03A9F4).
- Поймите разницу между сплошным и прозрачным стилями навигации на вашем сайте.

</div>

## Режимы навигации {#understanding-navigation-modes}

Навигация сайта может выглядеть в двух разных стилях в зависимости от страницы:

- **Сплошная навигация** — панель навигации с цветным фоном, обычно используется на страницах с содержимым
- **Прозрачная навигация** — навигация, которая накладывается поверх содержимого страницы, обычно используется на страницах с большими фоновыми изображениями или полноэкранным фоном

Цвета для обоих режимов можно настраивать независимо.

## Доступ к стилям навигации {#accessing-navigation-styles}

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу) и раскройте **Website**.
2. Нажмите **Appearance**.
3. В списке **Style Settings** нажмите **Navigation**.

В редакторе **Navigation Styling** есть две карточки: **Header (solid)** и **Header over hero (transparent)**.

## Настройка сплошной навигации {#configuring-solid-navigation}

Сплошная навигация отображается с цветным фоном за панелью навигации. Эти настройки находятся в карточке **Header (solid)**. Каждый цвет необязателен: пока его переключатель **Override** выключен, навигация использует обычные цвета вашего сайта. Вы можете настроить:

### Цвет фона {#background-color}

1. Включите переключатель **Override** для **Background color**
2. Нажмите на палитру цветов
3. Выберите нужный цвет фона (палитра по умолчанию начинается с белого, #FFFFFF)

### Цвет ссылок {#link-color}

1. Включите переключатель **Override** для **Link color**
2. Выберите цвет текста ссылок навигации
3. Это влияет на ссылки в обычном состоянии (палитра по умолчанию начинается с тёмно-серого, #555555)

### Цвет ссылок при наведении {#link-hover-color}

1. Включите переключатель **Override** для **Link hover color**
2. Выберите цвет, в который будут окрашиваться ссылки при наведении курсора
3. Это даёт визуальную обратную связь для кликабельных ссылок (палитра по умолчанию начинается с светло-голубого, #03A9F4)

### Цвет активной ссылки {#active-color}

1. Включите переключатель **Override** для **Active link color**
2. Выберите цвет для ссылки на текущую страницу
3. Это помогает посетителям понять, на какой странице они находятся (палитра по умолчанию начинается с светло-голубого, #03A9F4)

## Настройка прозрачной навигации {#configuring-transparent-navigation}

Прозрачная навигация накладывается на содержимое страницы без фона. Эти настройки находятся в карточке **Header over hero (transparent)**. Пока переключатель **Override** выключен, цвет автоматически совпадает с цветом текста в блоке hero. Вы можете настроить:

### Цвет ссылок {#link-color-1}

1. Включите переключатель **Override** для **Link color**
2. Выберите цвет, хорошо контрастирующий с фоном страницы
3. Часто лучше всего над тёмным фоном работают белый или светлые цвета

### Цвет ссылок при наведении {#link-hover-color-1}

1. Включите переключатель **Override** для **Link hover color**
2. Выберите цвет состояния наведения
3. Убедитесь, что он хорошо виден на фоне страницы

### Цвет активной ссылки {#active-color-1}

1. Включите переключатель **Override** для **Active link color**
2. Выберите цвет индикатора активной страницы
3. Он должен выделяться, но при этом соответствовать вашему дизайну

:::info
У прозрачной навигации нет настройки цвета фона, так как она накладывается непосредственно на содержимое страницы.
:::

## Сохранение изменений {#saving-your-changes}

1. Настроив цвета, нажмите **Save Navigation**
2. Изменения сразу применяются к работающему сайту
3. Откройте ваш сайт, чтобы увидеть навигацию в обоих режимах

## Возврат к значениям по умолчанию {#resetting-to-defaults}

Если хотите вернуться к цветам по умолчанию:

1. Выключите переключатели **Override** у всех пользовательских цветов
2. Нажмите **Save Navigation**
3. Навигация вернётся к обычным цветам вашего сайта (а над блоком hero — к цвету текста hero)

Или нажмите **Cancel**, чтобы отменить все изменения без сохранения.

## Рекомендации {#best-practices}

### Контрастность цветов {#color-contrast}

- **Читаемость** — убедитесь, что цвета ссылок достаточно контрастируют с фоном
- **Соответствие WCAG** — стремитесь к коэффициенту контрастности не менее 4.5:1 для доступности
- **Проверяйте оба режима** — просмотрите сайт и со сплошной, и с прозрачной навигацией

### Единство фирменного стиля {#brand-consistency}

- **Используйте фирменные цвета** — подберите их под логотип и тему сайта
- **Ограничивайте палитру** — придерживайтесь 2–3 цветов для цельного вида
- **Учитывайте изображения** — если используете прозрачную навигацию, проверьте её на типичных фонах страниц

### Состояния наведения и активности {#hover-and-active-states}

- **Понятная обратная связь** — состояние наведения должно заметно отличаться от обычной ссылки
- **Выделение активной страницы** — используйте отдельный цвет, чтобы посетители понимали, где они находятся
- **Плавные переходы** — система автоматически анимирует смену цветов

## Устранение неполадок {#troubleshooting}

### Цвета выглядят неправильно {#colors-dont-look-right}

- **Очистите кэш** — кэш браузера может показывать старые цвета
- **Проверьте hex-коды** — убедитесь, что вы ввели корректные hex-коды цветов
- **Проверьте на разных фонах** — цвета могут выглядеть иначе в зависимости от страницы

### Навигация не видна {#navigation-not-visible}

- **Прозрачный режим** — если прозрачная навигация накладывается на светлые изображения, тёмный текст может плохо читаться
- **Решение** — измените цвета ссылок или используйте более тёмный фон страниц
- **Альтернатива** — добавьте лёгкую тень или затемняющее наложение в области навигации

## Технические подробности {#technical-details}

Стили навигации хранятся в формате JSON и применяются с помощью CSS-переменных:

- Изменения вступают в силу сразу, без пересборки сайта
- Цвета распространяются на все элементы навигации
- Переопределения необязательны; незаданные цвета используют значения темы по умолчанию
