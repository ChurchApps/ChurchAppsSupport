# Начальная настройка

<div class="article-intro">

Каждая учетная запись B1 поставляется с готовым к использованию веб-сайтом. Это руководство проведет вас через установку доменного имени вашей церкви, настройку внешнего вида вашего сайта, создание первых страниц и организацию навигации.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужна учетная запись B1.church с административным доступом
- Если вы используете пользовательский домен, подготовьте учетные данные для входа у поставщика DNS (например, GoDaddy, Cloudflare или AWS)
- Подготовьте логотип вашей церкви в формате PNG с прозрачным фоном для лучших результатов

</div>

## Установка вашего домена

Ваша церковь автоматически получает поддомен на B1.church (например, `yourchurch.b1.church`). Вы также можете указать на свой B1 сайт собственный пользовательский домен.

1. Перейдите в **B1.church Admin**, посетив admin.b1.church или нажав меню профиля и выбрав **Переключение приложения**.
2. Откройте **меню раздела** в левом верхнем углу (имя раздела со стрелкой) и выберите **Параметры**.
3. Откройте раздел **Информация о церкви**, чтобы просмотреть ваш поддомен. Установите его на что-то короткое и узнаваемое без пробелов.
4. Чтобы использовать пользовательский домен, войдите в свой поставщик DNS (например, GoDaddy, Cloudflare или AWS) и добавьте две записи:
   - **Запись A** для вашего корневого домена, указывающая на `3.23.251.61`
   - **Запись CNAME** для `www`, указывающая на `proxy.b1.church`
5. Вернитесь в B1.church Admin, добавьте свой пользовательский домен в список и нажмите **Добавить**, затем **Сохранить**. Ваш сайт будет доступен с вашего пользовательского домена в течение нескольких минут.

:::tip
Если вы не видите опцию параметров, попросите человека, который установил вашу учетную запись церкви, предоставить вам разрешение "Редактировать параметры церкви". Подробнее см. в разделе [Роли и разрешения](../settings/roles-permissions.md).
:::

## Создание первой страницы

1. В B1 Admin нажмите **Веб-сайт** в левом меню, чтобы открыть представление страниц веб-сайта.
2. Нажмите **Добавить страницу** в правом верхнем углу.
3. Выберите **Пусто** в качестве типа страницы и назовите ее "Домашняя".
4. Нажмите **Параметры страницы** и установите путь URL на `/` (косую черту без текста) для вашей домашней страницы. Другие страницы используют `/page-name`.
5. Нажмите **Редактировать содержимое**, чтобы начать построение. Каждая страница должна начинаться с **раздела** — это контейнер для всех других элементов.
6. После добавления раздела нажмите **Добавить содержимое** еще раз, чтобы вставить текст, изображения, видео, карточки, формы и многое другое, перетащив их в раздел.

:::info
Для подробных инструкций по работе со страницами и навигацией см. [Управление страницами](managing-pages). Для полного руководства к визуальному редактору см. [Использование редактора страниц](page-editor).
:::

## Настройка внешнего вида сайта

1. Из представления страниц веб-сайта нажмите вкладку **Внешний вид** вверху.
2. Используйте **Цветовую палитру** для установки цветов вашего бренда для основного, вторичного и акцентных тонов.
3. В разделе **Параметры типографики** выберите шрифты заголовков и основного текста из браузера шрифтов.
4. Загрузите логотип вашей церкви в разделе **Логотип** в параметрах стиля. Предоставьте версию для светлого фона и темного фона.
5. Настройте **нижний колонтитул вашего сайта** с контактной информацией и ссылками вашей церкви.

:::info
Изменения, которые вы вносите во внешний вид, применяются ко всему вашему веб-сайту. Подробные инструкции по каждой настройке см. на странице [Внешний вид](appearance).
:::

## Настройка навигации

Ссылки навигации отображаются в представлении страниц веб-сайта. Для их организации:

1. Нажмите **Добавить**, чтобы создать новую ссылку навигации и указать ее на одну из ваших страниц.
2. Перетащите ссылки, чтобы переупорядочить их или вложить их под родительские элементы.
3. Просмотрите ваш сайт, чтобы убедиться, что навигация выглядит правильно.
