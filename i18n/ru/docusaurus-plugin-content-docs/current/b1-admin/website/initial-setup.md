# Первоначальная настройка

<div class="article-intro">

Каждая учётная запись B1 включает готовый к работе сайт. Это руководство проведёт вас через настройку домена церкви, оформление сайта, создание первых страниц и организацию навигации.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Нужна учётная запись B1.church с правами администратора
- Если вы используете собственный домен, подготовьте данные для входа у вашего DNS-провайдера (например, GoDaddy, Cloudflare или AWS)
- Для лучшего результата подготовьте логотип церкви в формате PNG с прозрачным фоном

</div>

## Настройка домена {#setting-up-your-domain}

Вашей церкви автоматически выдаётся поддомен на B1.church (например, `yourchurch.b1.church`). Вы также можете направить собственный домен на ваш сайт B1.

1. Перейдите в **B1.church Admin**, открыв admin.b1.church или выбрав в выпадающем меню профиля пункт **Switch App**.
2. Откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), раскройте **Settings** и нажмите **Settings**.
3. Откройте раздел **Church Information**, чтобы увидеть ваш поддомен. Задайте короткое и узнаваемое имя без пробелов.
4. Чтобы использовать собственный домен, войдите в панель вашего DNS-провайдера (например, GoDaddy, Cloudflare или AWS) и добавьте две записи:
   - **A-запись** для корневого домена, указывающую на `3.23.251.61`
   - **CNAME-запись** для `www`, указывающую на `proxy.b1.church`
5. Вернитесь в B1.church Admin, откройте раздел **Domains** на той же странице Settings, добавьте свой домен в список и нажмите **Add**, затем **Save**. Ваш сайт станет доступен по собственному домену в течение нескольких минут.

:::tip
Если вы не видите пункт Settings, попросите человека, который настраивал учётную запись вашей церкви, выдать вам разрешение «Edit Church Settings». Подробности см. в разделе [Роли и разрешения](../settings/roles-permissions.md).
:::

## Создание первой страницы {#creating-your-first-page}

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), раскройте **Website** и нажмите **Pages**.
2. Нажмите **Add Page** в правом верхнем углу.
3. Выберите **Blank** как тип страницы, введите «Home» в поле **Page Title** и нажмите **Save**.
4. Нажмите **Page Settings** в строке новой страницы и измените **URL Path** на `/` (только косая черта без текста) — это будет главная страница. Остальные страницы используют вид `/page-name`.
5. Нажмите **Edit Content**, чтобы начать работу. Каждая страница должна начинаться с **Section** — это контейнер для всех остальных элементов. Нажмите **Add Content** и перетащите **Section** на страницу, затем выберите готовую схему раздела или **Blank Section**.
6. После добавления раздела снова нажмите **Add Content**, чтобы вставить текст, изображения, видео, карточки, формы и многое другое, перетаскивая их в раздел.

:::info
Подробные инструкции по работе со страницами и навигацией см. в разделе [Управление страницами](./managing-pages.md). Полное руководство по визуальному редактору — в разделе [Использование редактора страниц](./page-editor.md).
:::

## Настройка оформления сайта {#configuring-site-appearance}

1. В меню Jump выберите **Website > Appearance**.
2. С помощью **Color Palette** задайте фирменные цвета — базовые светлый, акцентный и тёмный оттенки, а также цвета основных и вторичных кнопок — и нажмите **Save Palette**.
3. В разделе **Fonts** выберите шрифты для заголовков и основного текста в браузере шрифтов и нажмите **Save Fonts**.
4. Загрузите логотип церкви в разделе **Logo** в Style Settings. Загрузите версии и для светлого, и для тёмного фона, затем нажмите **Save Changes**.
5. Нажмите **Site Footer**, чтобы открыть подвал в редакторе блоков, и добавьте контактные данные церкви и ссылки.

:::info
Изменения, которые вы вносите в Appearance, применяются ко всему сайту. Подробные инструкции по каждой настройке см. на странице [Оформление](./appearance.md).
:::

## Настройка навигации {#setting-up-navigation}

Ссылки навигации отображаются в разделе Pages сайта. Чтобы их организовать:

1. На панели **Main Navigation** нажмите **Add**, введите **Link Text** и путь страницы (например, `/about`) как **URL**, затем нажмите **Save**.
2. Перетаскивайте ссылки, чтобы изменить их порядок или вложить их в родительские пункты.
3. Откройте предпросмотр сайта, чтобы убедиться, что навигация выглядит правильно.
