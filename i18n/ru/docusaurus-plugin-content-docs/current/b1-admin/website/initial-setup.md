# Начальная установка

<div class="article-intro">

Каждая учётная запись B1 поставляется с готовым к использованию веб-сайтом. Это руководство проведёт вас через настройку домена вашей церкви, настройку внешнего вида вашего сайта, создание первых страниц и организацию вашей навигации.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужна учётная запись B1.church с доступом администратора
- Если вы используете пользовательский домен, имейте под рукой учётные данные вашего поставщика DNS (например, GoDaddy, Cloudflare или AWS)
- Подготовьте логотип вашей церкви в формате PNG с прозрачным фоном для лучших результатов

</div>

## Настройка вашего домена

Ваша церковь автоматически получает поддомен на B1.church (например, `yourchurch.b1.church`). Вы также можете указать свой собственный пользовательский домен на свой B1-сайт.

1. Перейдите в **B1.church Admin**, посетив admin.b1.church или нажав на раскрывающееся меню вашего профиля и выбрав **Переключить приложение**.
2. Откройте **меню раздела** в левом верхнем углу (название раздела со стрелкой) и выберите **Параметры**.
3. Нажмите **Управление**, чтобы просмотреть ваш поддомен. Установите его на что-то короткое и узнаваемое без пробелов.
4. Для использования пользовательского домена войдите в ваш поставщик DNS (такой как GoDaddy, Cloudflare или AWS) и добавьте два записи:
   - Запись **A** для вашего корневого домена, указывающую на `3.23.251.61`
   - Запись **CNAME** для `www`, указывающую на `proxy.b1.church`
5. Вернитесь в B1.church Admin, добавьте свой пользовательский домен в список и нажмите **Добавить**, затем **Сохранить**. Ваш сайт будет доступен с вашего пользовательского домена в течение нескольких минут.

:::tip
Если вы не видите опцию параметров, попросите человека, который установил вашу учётную запись церкви, предоставить вам разрешение "Редактировать параметры церкви". Подробности см. в [Роли и разрешения](../settings/roles-permissions.md).
:::

## Создание вашей первой страницы

1. В B1 Admin нажмите **Веб-сайт** в левом меню, чтобы открыть представление "Страницы веб-сайта".
2. Нажмите **Добавить страницу** в правом верхнем углу.
3. Выберите **Пусто** в качестве типа страницы и назовите её "Главная".
4. Нажмите **Параметры страницы** и установите путь URL на `/` (косая черта без текста) для вашей главной страницы. Другие страницы используют `/page-name`.
5. Нажмите **Редактировать содержание**, чтобы начать создание. Каждая страница должна начинаться с **Секции** — это контейнер для всех остальных элементов.
6. После добавления секции нажмите **Добавить содержание** снова, чтобы вставить текст, изображения, видео, карточки, формы и многое другое, перетаскивая их в вашу секцию.

:::info
Для подробных инструкций по работе со страницами и навигацией см. [Управление страницами](managing-pages). Для полного руководства по визуальному редактору см. [Использование редактора страниц](page-editor).
:::

## Настройка внешнего вида сайта

1. Из представления "Страницы веб-сайта" нажмите вкладку **Внешний вид** в верхней части.
2. Используйте **Палитру цветов** для установки цветов вашего бренда для основного, вторичного и акцентных тонов.
3. В разделе **Параметры типографики** выберите шрифты заголовков и тела из браузера шрифтов.
4. Загрузите логотип вашей церкви в разделе **Логотип** параметров стиля. Предоставьте версию как для светлого, так и для тёмного фона.
5. Настройте **Нижний колонтитул сайта** с контактной информацией и ссылками вашей церкви.

:::info
Изменения, которые вы делаете в разделе "Внешний вид", применяются по всему вашему веб-сайту. Подробные инструкции для каждого параметра см. на странице [Внешний вид](appearance).
:::

## Настройка навигации

Ваши ссылки навигации отображаются в представлении "Страницы веб-сайта". Чтобы организовать их:

1. Нажмите **Добавить**, чтобы создать новую ссылку навигации и указать её на одну из ваших страниц.
2. Перетаскивайте и отпускайте ссылки, чтобы переупорядочить их или вложить их под родительские элементы.
3. Просмотрите ваш сайт, чтобы убедиться, что навигация выглядит правильно.
