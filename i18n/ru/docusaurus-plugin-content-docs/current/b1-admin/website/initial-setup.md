# Начальная настройка

<div class="article-intro">

Каждый аккаунт B1 поставляется с готовым к использованию веб-сайтом. Это руководство проходит вас через настройку домена вашей церкви, конфигурацию внешнего вида вашего сайта, создание первых страниц и организацию вашей навигации.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужен аккаунт B1.church с правом администратора
- Если вы используете пользовательский домен, подготовьте учетные данные входа поставщика DNS (например, GoDaddy, Cloudflare или AWS)
- Подготовьте логотип вашей церкви в формате PNG с прозрачным фоном для лучших результатов

</div>

## Настройка вашего домена

Ваша церковь автоматически получает поддомен на B1.church (например, `yourchurch.b1.church`). Вы также можете указать свой пользовательский домен на ваш сайт B1.

1. Перейдите в **B1.church Admin**, посетив admin.b1.church или нажав раскрывающееся меню профиля и выбрав **Переключить приложение**.
2. Откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **Параметры** и нажмите **Параметры**.
3. Откройте раздел **Информация о церкви**, чтобы просмотреть ваш поддомен. Установите что-то короткое и узнаваемое без пробелов.
4. Чтобы использовать пользовательский домен, войдите в свой поставщик DNS (например, GoDaddy, Cloudflare или AWS) и добавьте две записи:
   - **Запись A** для вашего корневого домена, указывающая на `3.23.251.61`
   - **Запись CNAME** для `www`, указывающая на `proxy.b1.church`
5. Вернитесь в B1.church Admin, добавьте свой пользовательский домен в список и нажмите **Добавить**, затем **Сохранить**. Ваш сайт будет доступен с вашего пользовательского домена через несколько минут.

:::tip
Если вы не видите опцию "Параметры", попросите человека, который установил учетную запись вашей церкви, предоставить вам разрешение "Редактировать параметры церкви". Подробнее см. в [Роли и разрешения](../settings/roles-permissions.md).
:::

## Создание вашей первой страницы

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **Веб-сайт** и нажмите **Страницы**.
2. Нажмите **Добавить страницу** в верхнем правом углу.
3. Выберите **Пусто** как тип страницы и назовите его "Главная".
4. Нажмите **Параметры страницы** и установите путь URL на `/` (косая черта без текста) для вашей домашней страницы. Другие страницы используют `/имя-страницы`.
5. Нажмите **Редактировать содержимое**, чтобы начать построение. Каждая страница должна начинаться с **Раздела** — это контейнер для всех остальных элементов.
6. После добавления раздела нажмите **Добавить содержимое** еще раз, чтобы вставить текст, изображения, видео, карточки, формы и многое другое, перетаскивая их в свой раздел.

:::info
Для получения подробных инструкций по работе со страницами и навигацией см. [Управление страницами](managing-pages). Для полного руководства по визуальному редактору см. [Использование редактора страниц](page-editor).
:::

## Конфигурация внешнего вида сайта

1. В меню Jump выберите **Веб-сайт > Внешний вид**.
2. Используйте **Цветовую палитру**, чтобы установить цвета вашего бренда для основных, вторичных и акцентных тонов.
3. В разделе **Параметры типографии** выберите ваши шрифты заголовков и основного текста из браузера шрифтов.
4. Загрузите логотип вашей церкви в разделе **Логотип** в "Параметры стиля". Предоставьте как версию для светлого фона, так и для темного фона.
5. Настройте **Нижний колонтитул сайта** с контактной информацией и ссылками вашей церкви.

:::info
Изменения, которые вы вносите в "Внешний вид", применяются ко всему вашему веб-сайту. Подробные инструкции по каждому параметру см. на странице [Внешний вид](appearance).
:::

## Настройка навигации

Ваши ссылки навигации появляются в представлении "Страницы веб-сайта". Чтобы их организовать:

1. Нажмите **Добавить**, чтобы создать новую ссылку навигации и указать ее на одну из ваших страниц.
2. Перетащите и отпустите ссылки, чтобы переупорядочить их или вложить их под родительские элементы.
3. Просмотрите ваш сайт, чтобы подтвердить, что навигация выглядит правильно.
