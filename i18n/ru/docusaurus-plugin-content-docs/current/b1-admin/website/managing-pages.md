# Управление страницами

<div class="article-intro">

Представление страниц сайта — это ваш центральный узел для создания, редактирования и организации всех страниц на сайте вашей церкви. Вы можете управлять как содержимым страниц, так и навигацией сайта с этого единого экрана.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Завершите [Первоначальную настройку](initial-setup), чтобы настроить домен и основные параметры сайта
- Подготовьте контент и изображения. Сначала используйте менеджер [Файлы](files) для загрузки медиафайлов.

</div>

:::info
Если у вашей церкви несколько сайтов (например, отдельные сайты для каждого кампуса), используйте переключатель сайтов в верхней части представления страниц сайта, чтобы переходить между ними. У каждого сайта свои страницы, навигация и настройки [внешнего вида](appearance).
:::

## Понимание типов страниц

Таблица **Страницы** перечисляет каждую страницу вашего сайта вместе с ее статусом:

- **Сгенерированные** — Страницы, автоматически созданные системой на основе данных вашей церкви (например, страница групп, страница проповедей или отдельная страница для каждой проповеди в вашей библиотеке). Эти страницы обновляются самостоятельно по мере изменения данных.
- **Пользовательские** — Страницы, которые вы создали самостоятельно со своим содержимым и макетом.

Вы можете преобразовать любую автоматически созданную страницу в пользовательскую, если хотите иметь полный контроль над ее содержимым и дизайном.

## Добавление и редактирование страниц

1. Нажмите кнопку **Добавить страницу** в правом верхнем углу таблицы страниц.
2. Выберите тип страницы (пустая или шаблон) и дайте ей название.
3. Нажмите **Редактировать** рядом с любой страницей, чтобы открыть [редактор страниц](page-editor), где вы можете добавлять разделы, текст, изображения и другие элементы.
4. Нажмите **Настройки страницы**, чтобы обновить заголовок страницы, путь URL и другие метаданные.
5. Используйте кнопку **Предпросмотр**, чтобы открыть страницу в новом окне и увидеть, как именно она будет выглядеть для посетителей.

:::tip
Для главной страницы задайте путь URL просто `/`. Для всех остальных страниц используйте описательный путь, например `/about` или `/contact`.
:::

### Настройки страницы

Откройте **Настройки страницы** на любой странице, чтобы настроить:

- **Заголовок и путь URL** — Название страницы и ее адрес на вашем сайте.
- **Видимость** — Выберите, кто может видеть страницу: все, только участники, только сотрудники или участники определенных групп. Это быстрый способ ограничить доступ к приватной странице (например, к странице ресурсов для сотрудников) без отдельного пароля.
- **Мета-описание** — Краткое описание, отображаемое в результатах поисковых систем и в предпросмотре ссылок в соцсетях.
- **Перенаправления** — Направьте старый путь URL на эту страницу, чтобы ссылки и закладки на удаленную страницу продолжали работать.

## Управление навигацией

Левая боковая панель представления страниц сайта отображает ваши навигационные ссылки. Эти ссылки управляют меню, которое посетители видят на вашем сайте.

1. Нажмите **Добавить**, чтобы создать новую навигационную ссылку. Вы можете направить ее на любую страницу вашего сайта или на внешний URL.
2. Чтобы изменить порядок ссылок, перетащите их в нужном порядке. Вы также можете вложить ссылки под родительский элемент, чтобы создать выпадающие меню.
3. Нажмите значок **Редактировать** рядом с любой ссылкой, чтобы изменить ее метку, URL или позицию.
4. Чтобы удалить ссылку из навигации, нажмите значок **Удалить**.

:::info
Удаление навигационной ссылки не удаляет саму страницу. Страница по-прежнему существует и доступна напрямую по своему URL — она просто больше не будет отображаться в меню.
:::

## Советы по организации вашего сайта

- Держите верхнеуровневую навигацию в пределах пяти-шести пунктов, чтобы посетители могли быстро находить нужное.
- Используйте вложенные ссылки для связанных подстраниц (например, выпадающее меню «О нас» с пунктами «Наша команда», «Убеждения» и «История»).
- Проверьте навигацию на мобильных устройствах, нажав **Предпросмотр на мобильном**, чтобы убедиться, что она хорошо работает на маленьких экранах.
- Давайте страницам понятные, описательные названия, которые помогают посетителям понять, что они найдут.

:::tip
Вы можете добавлять [формы](../forms/creating-forms.md) на свои страницы для сбора регистраций, молитвенных просьб или другой информации от посетителей.
:::

## Создание сайта на основе шаблона

Если вы создаете свой сайт с нуля, вы можете использовать **Шаблон сайта** для быстрого старта вместо создания страниц по одной. Шаблон сайта создает набор готовых страниц — главную, о нас, контакты, пожертвования и другие — с уже подготовленным контентом-заполнителем и настроенными навигационными ссылками.

1. На экране страниц нажмите кнопку **Шаблоны сайта** (рядом с кнопкой **Добавить страницу**).
2. Просмотрите доступные шаблоны и нажмите на один из них, чтобы увидеть предпросмотр структуры страниц.
3. Когда найдете подходящий, нажмите **Применить шаблон**.
4. Страницы, которых еще не существует, создаются и добавляются в навигацию. Существующие страницы остаются без изменений.

После применения шаблона откройте каждую страницу в [редакторе страниц](page-editor), чтобы заменить текст-заполнитель и изображения на реальный контент вашей церкви.

:::info
Шаблоны сайта создают структуру страниц и навигацию. Они не переопределяют цветовую схему или шрифты вашего сайта — это управляется настройками [Внешнего вида](appearance).
:::

## Лайтбокс изображений

Когда посетители нажимают на изображение на вашем сайте, оно открывается в полноэкранном оверлее лайтбокса. Это позволяет людям просматривать фотографии в увеличенном размере, не покидая страницу. Настройка не требуется — лайтбокс автоматически включен для изображений в содержимом ваших страниц.
