# Управление страницами

<div class="article-intro">

Представление "Страницы веб-сайта" — это ваш центральный центр для создания, редактирования и организации всех страниц на вашем веб-сайте церкви. Вы можете управлять содержанием страницы и навигацией сайта с этого одного экрана.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Завершите [Начальная установка](initial-setup), чтобы настроить свой домен и основные параметры сайта
- Имейте ваше содержание и изображения готовыми. Используйте менеджер [Файлы](files), чтобы сначала загрузить медиа-активы.

</div>

:::info
Если ваша церковь имеет более одного веб-сайта (например, отдельные сайты для каждого кампуса), используйте переключатель сайтов в верхней части представления "Страницы веб-сайта", чтобы переключаться между ними. Каждый сайт имеет свои страницы, навигацию и параметры [внешнего вида](appearance).
:::

## Понимание типов страниц

Таблица **Страницы** содержит все страницы на вашем сайте вместе с их статусом:

- **Сгенерирована** — страницы, автоматически созданные системой на основе данных вашей церкви (например, страница групп, страница проповедей или отдельная страница для каждой проповеди в вашей библиотеке). Эти страницы обновляются сами по себе по мере изменения ваших данных.
- **Пользовательская** — страницы, которые вы создали сами с собственным содержанием и макетом.

Вы можете преобразовать любую автоматически созданную страницу в пользовательскую страницу, если вы хотите полный контроль над её содержанием и дизайном.

## Добавление и редактирование страниц

1. Нажмите кнопку **Добавить страницу** в правом верхнем углу таблицы "Страницы".
2. Выберите тип страницы (пусто или шаблон) и дайте ей имя.
3. Нажмите **Редактировать** рядом с любой страницей, чтобы открыть [редактор страниц](page-editor), где вы можете добавлять секции, текст, изображения и другие элементы.
4. Нажмите **Параметры страницы**, чтобы обновить название страницы, путь URL и другие метаданные.
5. Используйте кнопку **Предпросмотр**, чтобы открыть вашу страницу в новом окне и увидеть, как именно она будет выглядеть для посетителей.

:::tip
Для вашей главной страницы установите путь URL только на `/`. Для всех остальных страниц используйте описательный путь, такой как `/about` или `/contact`.
:::

### Параметры страницы

Откройте **Параметры страницы** на любой странице для настройки:

- **Название и путь URL** — название страницы и её адрес на вашем сайте.
- **Видимость** — выберите, кто может видеть страницу: все, только члены, только персонал или члены определённых групп. Это быстрый способ защитить приватную страницу (например, страница ресурсов для персонала) без отдельного пароля.
- **Описание Meta** — краткое резюме, показываемое в результатах поисковых систем и предпросмотрах ссылок в социальных сетях.
- **Перенаправления** — укажите старый путь URL на эту страницу, чтобы ссылки и закладки на снятую со снабжения страницу продолжили работать.

## Управление навигацией

Представление "Страницы веб-сайта" отображает ваши ссылки навигации. Эти ссылки контролируют меню, которое посетители видят на вашем веб-сайте.

1. Нажмите **Добавить**, чтобы создать новую ссылку навигации. Вы можете указать её на любую страницу на вашем сайте или на внешний URL.
2. Чтобы переупорядочить ссылки, перетащите и отпустите их в нужном вам порядке. Вы также можете вложить ссылки под родительский элемент, чтобы создать раскрывающиеся меню.
3. Нажмите значок **Редактировать** рядом с любой ссылкой, чтобы изменить её метку, URL или позицию.
4. Чтобы удалить ссылку из навигации, нажмите значок **Удалить**.

:::info
Удаление ссылки навигации не удаляет саму страницу. Страница всё ещё существует и может быть доступна прямо по её URL — она просто не будет отображаться в меню.
:::

## Советы по организации вашего сайта

- Держите навигацию верхнего уровня до пяти или шести элементов, чтобы посетители могли быстро находить вещи.
- Используйте вложенные ссылки для связанных подстраниц (например, раскрывающееся меню "О нас" с "Наша команда", "Вероубеждения" и "История").
- Просмотрите вашу навигацию на мобильном устройстве, нажав **Предпросмотр на мобильном**, чтобы убедиться, что она хорошо работает на меньших экранах.
- Дайте страницам чёткие, описательные имена, которые помогают посетителям понять, что они найдут.

:::tip
Вы можете добавлять [формы](../forms/creating-forms.md) на ваши страницы для сбора регистраций, молитвенных просьб или другой информации от посетителей.
:::

## Начало работы с шаблоном сайта

Если вы строите свой сайт с нуля, вы можете загрузить его, используя **Шаблон сайта** вместо создания страниц одну за другой. Шаблон сайта создаёт набор предварительно созданных страниц — главная, о нас, подключение, пожертвование и другие — с заполнителем содержания и уже подключённой навигацией.

1. На экране страниц нажмите кнопку **Шаблоны сайтов** (рядом с кнопкой **Добавить страницу**).
2. Просмотрите доступные шаблоны и нажмите один, чтобы просмотреть его структуру страницы.
3. Когда вы найдёте понравившийся, нажмите **Применить шаблон**.
4. Создаются страницы, которых ещё нет, и они добавляются в вашу навигацию. Существующие страницы остаются без изменений.

После применения шаблона откройте каждую страницу в [редакторе страниц](page-editor), чтобы заменить текст-заполнитель и изображения на реальное содержание вашей церкви.

:::info
Шаблоны сайтов создают структуру страницы и навигацию. Они не переопределяют цветовую схему вашего сайта или шрифты — они контролируются [Внешний вид](appearance).
:::

## Lightbox для изображений

Когда посетители нажимают на изображение на вашем веб-сайте, оно открывается в полноэкранном наложении lightbox. Это позволяет людям просматривать фотографии в большом размере, не покидая страницу. Никаких конфигураций не требуется — lightbox включен автоматически для изображений в содержании вашей страницы.
