# Внешний вид

<div class="article-intro">

Страница Appearance позволяет настроить общий вид вашего сайта церкви. От цветов и шрифтов до интервалов и пользовательского CSS — все визуальные аспекты сайта контролируются из одного места.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Выполните [первоначальную настройку](initial-setup) для вашего сайта
- Подготовьте логотип церкви в формате PNG с прозрачным фоном и соотношением сторон 4:1
- Узнайте цвета бренда вашей церкви (шестнадцатеричные значения), если у вас есть существующее руководство по стилю

</div>

## Открытие настроек внешнего вида

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу) и разверните **Website**.
2. Нажмите **Appearance**.
3. Загрузится страница **Site Styles**. Карточка **Theme, fonts & footer** показывает список **Style Settings** слева и предварительный просмотр примера сайта справа. Ниже находятся карточки **Announcement & widgets** и **Redirects & analytics**.

## Цветовая палитра {#color-palette}

1. Нажмите **Color Palette** на панели Style Settings.
2. Вы увидите **Base Colors** (светлые, акцентные и темные оттенки) и **Semantic Colors** (Primary, Secondary, Success, Warning и Error).
3. Нажмите на любой цветовой образец, чтобы открыть палитру цветов. Перетащите указатель или введите шестнадцатеричное значение, чтобы выбрать цвет.
4. **Color Combinations Preview** показывает, как выбранные цвета сочетаются друг с другом.
5. Используйте **Suggested Palettes**, чтобы быстро применить готовую цветовую схему.
6. Нажмите **Save Palette**, когда будете удовлетворены результатом.

## Типографика

1. Нажмите **Fonts** на панели Style Settings.
2. Нажмите кнопку **Heading Font** или **Body Font**, чтобы открыть браузер шрифтов. Можно искать по названию или просматривать категории, такие как Serif, Sans Serif, Display, Handwriting и Monospace. Также можно выбрать одну из **Popular Font Combinations**.
3. Нажмите **Save Fonts**, чтобы применить выбранные шрифты.
4. Чтобы настроить иерархию размеров для заголовков с Heading 1 по Heading 4, нажмите **Typography Scale** на панели Style Settings. Используйте поля **Type Scale**, **Base Size** и **Line Height** для точной настройки, затем нажмите **Save Typography**.

## Интервалы

1. Нажмите **Spacing Scale** на панели Style Settings.
2. Настройте значения интервалов от Extra Small до Extra Large. Практические примеры показывают, как каждое значение влияет на макет.
3. Нажмите **Save Spacing**, чтобы применить значения ко всему сайту.

## Логотип и брендинг {#logo-and-branding}

1. Нажмите **Logo** на панели Style Settings.
2. Загрузите **Light Background Logo** и **Dark Background Logo**. Для лучшего результата используйте изображения с прозрачным фоном и соотношением сторон 4:1.
3. Загрузите **Social Media Image** для предпросмотра ссылок и **Favicon** для значка на вкладке браузера.
4. Нажмите **Save Changes**. Загруженные изображения не сохраняются, пока вы не нажмете «Сохранить», поэтому если вы попытаетесь закрыть или перезагрузить вкладку браузера, браузер предупредит о несохраненных изменениях.

:::tip
Для лучшего результата используйте логотип в формате PNG с прозрачным фоном. Так он будет хорошо смотреться и на светлом, и на темном фоне на вашем сайте и в [мобильном приложении](../settings/mobile-app.md).
:::

## Стили навигации

Настройте цвета панели навигации вашего сайта для сплошного и прозрачного режимов:

1. Нажмите **Navigation** на панели Style Settings.
2. Настройте цвета для **Header (solid)** и **Header over hero (transparent)**.
3. Нажмите **Save Navigation**, чтобы применить цвета навигации.

Подробные инструкции см. в разделе [Стили навигации](./navigation-styles.md).

## Объявления и виджеты

Виджеты сайта появляются на каждой странице вашего сайта и плавают над содержимым страницы:

- **Announcement Banner** — полоса вверху сайта, которую можно закрыть, для срочных сообщений, например о предстоящем событии или изменении времени служения.
- **Launcher** — плавающая кнопка, которая открывает меню быстрого доступа, например ссылки на пожертвования, регистрацию или просмотр бюллетеня.

1. Найдите карточку **Announcement & widgets** под панелью Style Settings.
2. Включите нужные виджеты и настройте их текст, ссылки и цвета.
3. Нажмите **Save**.

## Перенаправления и аналитика

Карточка **Redirects & analytics** (под Style Settings) содержит две не связанные между собой, но часто нужные настройки:

- **Analytics** — добавьте ваш **GA4 Measurement ID** (формат `G-XXXXXXXXXX`), чтобы отслеживать посещаемость сайта. Тот же ID также отслеживает просмотры страниц в приложении вашей церкви B1 (портал участников по адресу `/mobile`, включая установленное приложение), с меткой `display_mode` со значением `installed` или `browser`, чтобы в Google Analytics можно было отличить визиты из установленного приложения от визитов через браузер.
- **Redirects** — настройте перенаправление со старого пути на новый, чтобы ссылки на перемещенную или переименованную страницу продолжали работать, а не выдавали ошибку 404. Введите старый путь в поле **From** и новый путь в поле **To**, затем нажмите **Save**. Перенаправление также имеет приоритет над встроенными страницами B1 (`/sermons`, `/stream`, `/donate`, `/bible` и `/votd`), так что вы можете направить этот адрес в другое место (например, на собственную страницу проповедей или канал YouTube). Оно не заменяет страницу, которую вы создали сами по этому адресу. Чтобы перенаправление сработало, сначала удалите эту страницу.

## Пользовательский CSS и JavaScript

1. Нажмите **CSS & Javascript** на панели Style Settings.
2. Добавьте **Custom CSS**, чтобы переопределить стандартные стили для продвинутой настройки.
3. Добавьте **Custom HTML** для кодов отслеживания или других скриптов.
4. Используйте раздел **Common JavaScript Examples** для фрагментов кода, например для интеграции Google Analytics.

:::warning
Пользовательский CSS мощный, но при неправильном использовании может сломать макет вашего сайта. Большинство церквей могут получить нужный вид с помощью встроенных настроек цвета, шрифтов и интервалов. Используйте пользовательский CSS, только если вы уверенно разбираетесь в веб-разработке.
:::

:::info
На вашем сайте действует Content Security Policy, которая блокирует встроенные скрипты из любых других источников. Поле **Custom HTML** здесь и [элемент HTML](page-editor#using-the-html-element) на отдельных страницах — это доверенные исключения: код, который вы сохраните там, выполняется без изменений, поэтому вставляйте скрипты только из источников, которым доверяете (теги аналитики, виджеты чата и подобные встраиваемые элементы).
:::

## Стилевые темы

Если нужна быстрая отправная точка, в разделе Color Palette **Suggested Palettes** предлагает готовые темы, которые одним нажатием задают согласованные цвета. Вы всегда можете точно настроить отдельные параметры после применения темы.
