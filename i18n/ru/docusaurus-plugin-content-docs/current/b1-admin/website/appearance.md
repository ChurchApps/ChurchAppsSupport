# Внешний вид

<div class="article-intro">

На странице "Внешний вид" вы можете настроить общий вид и ощущение от вашего церковного сайта. От цветов и шрифтов до интервалов и пользовательского CSS вы можете контролировать каждый визуальный аспект вашего сайта с одного места.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Завершите [Начальную настройку](initial-setup) для вашего сайта
- Подготовьте логотип вашей церкви в формате PNG с прозрачным фоном и соотношением сторон 4:1
- Знайте цвета бренда вашей церкви (значения в шестнадцатеричной системе), если у вас есть существующее руководство по стилю

</div>

## Доступ к параметрам внешнего вида

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу) и разверните **Веб-сайт**.
2. Нажмите **Внешний вид**.
3. Загружается страница "Стили сайта" с живым предпросмотром вашего веб-сайта слева и параметрами **Параметры стиля** справа.

## Цветовая палитра

1. Нажмите **Цветовая палитра** на панели "Параметры стиля".
2. Вы увидите **Базовые цвета** (светлые, акцентные и темные оттенки) и **Семантические цвета** (Основной, Вторичный, Успех, Предупреждение и Ошибка).
3. Нажмите любой цветной образец, чтобы открыть палитру цветов. Перетащите селектор или введите значение в шестнадцатеричной системе, чтобы выбрать цвет.
4. **Предпросмотр комбинаций цветов** показывает, как выбранные цвета работают вместе.
5. Используйте **Рекомендуемые палитры** для быстрого применения предварительно разработанной цветовой схемы.
6. Нажмите **Сохранить**, когда вы будете довольны.

## Типография

1. Нажмите **Параметры типографии** на панели "Параметры стиля".
2. Нажмите **Выбрать шрифт**, чтобы открыть браузер шрифтов. Вы можете выполнить поиск по названию или просмотреть категории, такие как "Засечки", "Без засечек", "Дисплей", "Рукописный" и "Моноширинный".
3. Установите шрифты как для заголовков, так и для основного текста.
4. Нажмите **Шкала типографии**, чтобы отрегулировать иерархию размеров для Заголовка 1 — Заголовка 4. Используйте поля множителя масштаба и базового размера для точной настройки.
5. Нажмите **Сохранить**, чтобы применить выбранные вами шрифты.

## Интервалы

1. Нажмите **Шкала интервалов** на панели "Параметры стиля".
2. Отрегулируйте значения интервалов для "Очень маленький" — "Очень большой". Практические примеры показывают, как каждое значение влияет на макет.
3. Нажмите **Сохранить интервалы**, чтобы применить значения на всем сайте.

## Логотип и фирменный стиль

1. Нажмите **Логотип** на панели "Параметры стиля".
2. Загрузите **Логотип светлого фона** и **Логотип темного фона**. Используйте изображения с прозрачным фоном и соотношением сторон 4:1 для лучших результатов.
3. Загрузите **Изображение для социальных сетей** для предпросмотров ссылок и **Значок сайта** для значка в вкладке браузера.

:::tip
Для лучших результатов используйте логотип с прозрачным фоном в формате PNG. Это гарантирует, что он выглядит отлично на светлых и темных фонах по всему вашему сайту и [мобильному приложению](../settings/mobile-app.md).
:::

## Стили навигации

Настройте цвета панели навигации вашего веб-сайта как для сплошного, так и для прозрачного режимов:

1. Прокрутите до раздела **Стили навигации**
2. Нажмите **Редактировать стили навигации**
3. Настройте цвета для сплошной навигации (с фоном) и прозрачной навигации (режим наложения)
4. Нажмите **Сохранить**, чтобы применить цвета навигации

Для получения подробных инструкций см. [Стили навигации](./navigation-styles.md).

## Объявление и виджеты

Виджеты сайта появляются на каждой странице вашего сайта, плавая над содержимым страницы:

- **Баннер объявления** — исчезающая полоса вверху вашего сайта для чувствительных по времени сообщений, таких как предстоящее событие или изменение услуги.
- **Средство запуска** — плавающая кнопка, которая открывает меню быстрого доступа, например ссылки для пожертвования, регистрации или просмотра бюллетеня.

1. Нажмите **Объявление и виджеты** на панели "Параметры стиля".
2. Включите нужные вам виджеты и настройте их текст, ссылки и цвета.
3. Нажмите **Сохранить**.

## Перенаправления и аналитика

Панель **Перенаправления и аналитика** в параметрах стиля содержит два несвязанных, но часто необходимых параметра:

- **Аналитика** — добавьте **ID измерения Google Analytics 4**, чтобы отслеживать трафик посетителей на вашем веб-сайте.
- **Перенаправления** — сопоставьте старый путь URL с новым, чтобы ссылки на перемещенную или переименованную страницу продолжали работать вместо ошибки 404. Введите старый путь **От** и новый путь **К**, затем нажмите **Сохранить**.

## Пользовательский CSS и JavaScript

1. Нажмите **CSS и Javascript** на панели "Параметры стиля".
2. Добавьте **Пользовательский CSS**, чтобы переопределить стили по умолчанию для расширенной настройки.
3. Добавьте **Пользовательский HTML** для отслеживания кодов или других скриптов.
4. Используйте раздел **Примеры общего Javascript** для фрагментов, таких как интеграция Google Analytics.

:::warning
Пользовательский CSS — мощный инструмент, но он может нарушить макет вашего сайта, если использован неправильно. Большинство церквей могут достичь желаемого вида, используя встроенные элементы управления цветом, шрифтом и интервалом. Используйте пользовательский CSS только в том случае, если вы знакомы с веб-разработкой.
:::

:::info
Ваш сайт применяет политику безопасности контента, которая блокирует встроенные скрипты из любого другого источника. Поле **Пользовательский JavaScript** — единственное доверенное исключение — код, который вы там сохраняете, выполняется как есть, поэтому вставляйте скрипты только из источников, которым вы доверяете (теги аналитики, чат-виджеты и подобные встраивания).
:::

## Темы стилей

Если вы хотите быстрый отправной пункт, **Рекомендуемые палитры** в разделе "Цветовая палитра" предлагают предварительно построенные темы, которые устанавливают скоординированные цвета одним щелчком. Вы всегда можете точно настроить отдельные параметры после применения темы.
