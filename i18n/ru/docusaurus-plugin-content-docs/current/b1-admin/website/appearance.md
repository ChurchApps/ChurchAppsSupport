# Внешний вид

<div class="article-intro">

На странице внешнего вида вы управляете цветами, шрифтами и общим дизайном вашего сайта B1.church. Это общие настройки, которые применяются ко всему вашему сайту.

</div>

## Доступ к параметрам внешнего вида

1. Перейдите в раздел **Website** в B1 Admin
2. Нажмите на вкладку **Appearance**

## Цветовая схема

Установите основные цвета вашего сайта:

- **Primary Color** — основной цвет для кнопок и акцентов
- **Secondary Color** — вторичный цвет для акцентов
- **Background Color** — цвет фона страниц
- **Text Color** — основной цвет текста

## Шрифты

Выберите шрифты для заголовков и основного текста:

- **Heading Font** — шрифт для заголовков и подзаголовков
- **Body Font** — шрифт для основного текста

## Логотип и изображения

Загрузите:

- **Logo** — ваш логотип церкви
- **Favicon** — маленький значок, отображающийся на вкладке браузера
- **Hero Image** — большое изображение для главной страницы

## Предпросмотр

Во время внесения изменений вы видите предпросмотр вашего сайта в реальном времени, чтобы убедиться, что изменения выглядят хорошо.

## Сохранение изменений

Нажмите **Save** для применения вашего дизайна ко всему сайту.

Ваш сайт обновляется немедленно с новыми цветами и шрифтами.

## Советы по дизайну

- Используйте цвета, которые соответствуют вашему бренду церкви
- Убедитесь, что текст достаточно контрастен с фоном для легкого чтения
- Используйте профессиональные изображения высокого качества
