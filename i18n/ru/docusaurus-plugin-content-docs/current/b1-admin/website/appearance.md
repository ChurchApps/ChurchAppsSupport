# Оформление

<div class="article-intro">

На странице Appearance вы настраиваете общий вид сайта вашей церкви. От цветов и шрифтов до интервалов и пользовательского CSS — вы управляете всеми визуальными аспектами сайта из одного места.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Выполните [первоначальную настройку](./initial-setup.md) вашего сайта
- Подготовьте логотип церкви в формате PNG с прозрачным фоном и соотношением сторон 4:1
- Если у вас есть руководство по стилю, узнайте фирменные цвета церкви (значения hex)

</div>

## Доступ к настройкам оформления {#accessing-appearance-settings}

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу) и раскройте **Website**.
2. Нажмите **Appearance**.
3. Откроется страница **Site Styles**. В карточке **Theme, fonts & footer** слева находится список **Style Settings**, а справа — предпросмотр примерного сайта. Ниже расположены карточки **Announcement & widgets** и **Redirects & analytics**.

## Цветовая палитра {#color-palette}

1. Нажмите **Color Palette** на панели Style Settings.
2. Вы увидите **Base Colors** (светлый, акцентный и тёмный оттенки) и **Semantic Colors** (Primary, Secondary, Success, Warning и Error).
3. Нажмите на любой цветовой образец, чтобы открыть палитру. Перетащите указатель или введите значение hex, чтобы выбрать цвет.
4. **Color Combinations Preview** показывает, как выбранные цвета сочетаются друг с другом.
5. Используйте **Suggested Palettes**, чтобы начать с готовой цветовой схемы. Нажатие на палитру только загружает её цвета в редактор.
6. Нажмите **Save Palette**, чтобы применить цвета к сайту, или **Cancel**, чтобы отменить изменения.

## Типографика {#typography}

1. Нажмите **Fonts** на панели Style Settings.
2. Нажмите кнопку **Heading Font** или **Body Font**, чтобы открыть браузер **Select a Font**, в котором шрифты Google Fonts перечислены по популярности, по десять на страницу. Введите название в поле **Search**, чтобы найти шрифт по имени, или воспользуйтесь **Category Filter** (Serif, Sans Serif, Display, Handwriting или Monospace). Нажмите на шрифт, чтобы выбрать его. Также можно нажать одну из **Popular Font Combinations**, чтобы задать сразу оба шрифта.
3. Нажмите **Save Fonts**, чтобы применить выбранные шрифты.
4. Чтобы настроить иерархию размеров для заголовков с Heading 1 по Heading 4, нажмите **Typography Scale** на панели Style Settings. Используйте поля **Type Scale** (множитель), **Base Size** и **Line Height** для точной настройки, затем нажмите **Save Typography**.

## Интервалы {#spacing}

1. Нажмите **Spacing Scale** на панели Style Settings.
2. Настройте значения интервалов от Extra Small до Extra Large. Практические примеры показывают, как каждое значение влияет на верстку.
3. Нажмите **Save Spacing**, чтобы применить значения ко всему сайту.

## Логотип и брендинг {#logo-and-branding}

1. Нажмите **Logo** на панели Style Settings.
2. Загрузите **Light Background Logo** и **Dark Background Logo**. Для лучшего результата используйте изображения с прозрачным фоном и соотношением сторон 4:1.
3. Загрузите **Social Media Image** для предпросмотра ссылок и **Favicon** для значка во вкладке браузера.
4. При желании введите **PWA Short Name** (до 12 символов) — название, которое отображается под значком приложения церкви, когда его добавляют на главный экран телефона.
5. Нажмите **Save Changes**. Загруженные изображения не сохраняются, пока вы не нажмёте кнопку, поэтому, если вы попытаетесь закрыть или перезагрузить вкладку браузера, браузер предупредит о несохранённых изменениях.

Логотипы используются всеми сайтами вашей церкви, а также вашим приложением и печатными материалами, например списками посещаемости.

:::tip
Для лучшего результата используйте логотип в формате PNG с прозрачным фоном. Так он хорошо смотрится и на светлом, и на тёмном фоне — на вашем сайте и в [мобильном приложении](../settings/mobile-app.md).
:::

## Стили навигации {#navigation-styles}

Настройте цвета панели навигации вашего сайта для обоих режимов — сплошного и прозрачного:

1. Нажмите **Navigation** на панели Style Settings.
2. Задайте цвета для **Header (solid)** и **Header over hero (transparent)**.
3. Нажмите **Save Navigation**, чтобы применить цвета навигации.

Подробные инструкции см. в разделе [Стили навигации](./navigation-styles.md).

## Подвал сайта {#site-footer}

Нажмите **Site Footer** на панели Style Settings, чтобы открыть подвал в редакторе блоков. Соберите его как любой раздел страницы — например, адрес, время служб и ссылки на соцсети — и нажмите **Exit**, когда закончите. Подвал появляется внизу каждой страницы, которая использует макет **Header & Footer**. У каждого из ваших сайтов свой подвал.

## Объявления и виджеты {#announcement--widgets}

Виджеты сайта появляются на каждой странице, плавая над её содержимым:

- **Announcement Banner** — полоса вверху сайта, которую можно закрыть, для срочных сообщений, например о предстоящем событии или изменении службы.
- **Launcher** — плавающая кнопка, которая открывает меню быстрого доступа, например к ссылкам на пожертвования, регистрацию или бюллетень.

1. Найдите карточку **Announcement & widgets** под Style Settings.
2. Для **Announcement Bar** отметьте **Enabled** и заполните **Text**, при желании **Link URL** и **Link Text**, а также **Background Color** и **Text Color**. Задайте **Start Date** и **End Date**, чтобы показывать полосу только в этот период.
3. Для **Launcher** отметьте **Enabled**, затем нажмите **Add Action** для каждой ссылки (до пяти) и укажите **Label**, **URL** и **Icon**. Выберите **Position** (справа внизу или слева внизу) и **Color**.
4. Нажмите **Save**.

Чтобы выключить виджет, снимите отметку **Enabled** и нажмите **Save**. Эти виджеты применяются ко всем сайтам вашей церкви.

## Перенаправления и аналитика {#redirects--analytics}

В карточке **Redirects & analytics** (под Style Settings) собраны две не связанные между собой, но часто нужные настройки:

- **Analytics** — добавьте ваш **GA4 Measurement ID** (формат `G-XXXXXXXXXX`) и нажмите **Save**, чтобы отслеживать посещаемость сайта. Тот же ID также отслеживает просмотры страниц в приложении вашей церкви B1 (кабинет участника по адресу `/mobile`, включая установленное приложение). Они помечаются параметром `display_mode` со значением `installed` или `browser`, чтобы в Google Analytics можно было отличить визиты из установленного приложения от визитов через браузер.
- **Redirects** — перенаправление старого пути URL на новый, чтобы ссылки на переименованную или перенесённую страницу продолжали работать, а не выдавали 404. Введите старый **From Path** и новый **To Path**, затем нажмите **Add**. Перенаправление сохраняется сразу и показывается над полями; чтобы его удалить, нажмите значок удаления. Пути сохраняются в нижнем регистре, с начальным слэшем и без завершающего слэша. Перенаправление также имеет приоритет над встроенными страницами B1 (`/sermons`, `/stream`, `/donate`, `/bible` и `/votd`), так что вы можете направить этот адрес в другое место (например, на собственную страницу проповедей или канал YouTube). Оно не заменяет страницу, которую вы создали сами по этому адресу. Чтобы перенаправление сработало, сначала удалите эту страницу.

## Пользовательский CSS и JavaScript {#custom-css-and-javascript}

1. Нажмите **CSS & Javascript** на панели Style Settings.
2. Добавьте **Custom CSS**, чтобы переопределить стандартные стили для продвинутой настройки.
3. Добавьте **Custom HTML** для кодов отслеживания или других скриптов.
4. Используйте разделы **Common CSS Examples** и **Common JavaScript Examples** с готовыми фрагментами, затем нажмите **Save Changes**.

:::warning
Пользовательский CSS — мощный инструмент, но при неправильном использовании он может нарушить верстку сайта. Большинство церквей могут получить нужный вид с помощью встроенных средств управления цветами, шрифтами и интервалами. Используйте пользовательский CSS, только если вы уверенно работаете с веб-разработкой.
:::

:::info
На вашем сайте действует политика безопасности содержимого (Content Security Policy), которая блокирует встроенные скрипты из любых других источников. Поле **Custom HTML** здесь и [HTML-элемент](./page-editor.md#using-the-html-element) на отдельных страницах — доверенные исключения: код, сохранённый там, выполняется как есть, поэтому вставляйте скрипты только из источников, которым доверяете (теги аналитики, виджеты чатов и подобные встраивания).
:::

## Цветовые темы {#style-themes}

Если нужна быстрая отправная точка, в разделе Color Palette есть **Suggested Palettes** — готовые темы с согласованными цветами. Нажмите на одну, чтобы загрузить её, измените любой цвет по вкусу и нажмите **Save Palette**.
