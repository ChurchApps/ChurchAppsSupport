# Использование редактора страниц

<div class="article-intro">

Редактор страниц B1 — это визуальный конструктор с перетаскиванием, который позволяет создавать страницы сайта вашей церкви без написания кода. Вы можете добавлять секции и блоки содержимого, настраивать стили, просматривать результат и отменять изменения — всё прямо в браузере.

</div>

## Открытие редактора

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните пункт **Сайт** и нажмите **Страницы**.
2. Найдите нужную страницу в таблице страниц и нажмите **Редактировать содержимое**.

Редактор открывается в полноэкранном режиме. В левой панели показана структура страницы и доступные элементы содержимого, а в центральной области — предварительный просмотр страницы в реальном времени.

:::info
Редактор всегда отображается в светлом режиме, независимо от темы оформления B1 Admin, и использует шрифты для заголовков и основного текста, которые вы выбрали в разделе [Оформление](./appearance.md). Это гарантирует, что предварительный просмотр точно совпадает с тем, как страница будет выглядеть для посетителей сайта.
:::

## Структура страницы: секции и элементы

Каждая страница состоит из двух уровней:

- **Секции** — верхнеуровневые контейнеры, которые делят страницу на горизонтальные блоки (например, главный баннер, блок с содержимым или полоса подвала). Перед добавлением содержимого на странице должна быть хотя бы одна секция.
- **Элементы** — отдельные части содержимого внутри секции, такие как текст, изображения, кнопки, карточки, формы и календари.

### Добавление секции

1. Нажмите **Добавить секцию** (или кнопку **+** вверху левой панели).
2. Выберите способ создания:
   - **Из шаблона** — просмотрите галерею шаблонов секций по категориям (Главный баннер, О нас, Служения, Пожертвования и др.) и выберите один, чтобы вставить полностью оформленную секцию с готовым содержимым. После добавления всё можно изменить.
   - **Пустая секция** — выберите схему колонок (одна колонка, две, три и т. д.) и создавайте секцию с нуля.
3. Новая секция появится в предварительном просмотре. Нажмите на неё, чтобы выбрать и настроить цвет фона, отступы и другие параметры оформления.

### Изменение макета секции

Если секция уже создана, но вы хотите другую структуру? Используйте переключатель макета в этой секции, чтобы заменить схему колонок на другую из галереи, сохранив при этом существующее содержимое и элементы.

### Добавление элементов в секцию

1. Нажмите внутри секции в предварительном просмотре, чтобы выбрать её.
2. Нажмите **Добавить содержимое** и выберите тип элемента из списка:
   - **Текст** — заголовки, абзацы и форматированный текст
   - **Изображение** — загрузка фото или ссылка на него
   - **Кнопка** — кликабельная ссылка-призыв к действию
   - **Карточка** — изображение с заголовком и описанием
   - **Форма** — встраивание [формы](../forms/creating-forms.md) прямо на страницу. Если у формы есть [фото в шапке](../forms/creating-forms.md#adding-a-header-photo), оно отображается над вопросами
   - **Календарь** — отображение календаря событий
   - **FAQ** — блоки вопросов и ответов в виде аккордеона
   - **Видео** — встраивание видео по ссылке
   - **Обзор групп** — фильтруемый каталог всех групп церкви с необязательным поиском, фильтром по категории и фильтром по меткам. Его **Макет** может быть **Сетка** (по умолчанию) или **Прокрутка (автоматическая)** — см. [Макеты с прокруткой](#scrolling-layouts)
   - **Список групп** — плитки для открытых групп, необязательно только для групп с определённой меткой. Его **Макет** может быть **Сетка** (по умолчанию; до трёх плиток в ряду) или **Прокрутка (автоматическая)** — см. [Макеты с прокруткой](#scrolling-layouts)
   - **Иконка с описанием** — иконка с заголовком и коротким описанием для выделения особенностей или служений
   - **Галерея** — сетка фотографий или макет «кладка»
   - **Отзыв** — одна или несколько цитат с именем автора, должностью и фото
   - **Значки соцсетей** — ссылки на профили церкви в социальных сетях: Facebook, Instagram, WhatsApp, YouTube, X, TikTok, Vimeo и Podcast. Укажите ссылку для каждой сети, которую хотите показать; для **WhatsApp** используйте ссылку вида `https://wa.me/` с вашим номером или ссылку-приглашение в группу
   - **Обратный отсчёт** — таймер, отсчитывающий время до даты или еженедельного богослужения
   - **Статистика** — ряд крупных чисел с подписями (участники, годы, филиалы)
   - **Прогресс кампании** — индикатор прогресса в реальном времени для кампании пожертвований, показывающий общую сумму, собранную на цель фонда
   - **Сетка сотрудников** — карточки с фото участников группы; у группы должна быть включена опция **публичного списка**
   - **Время богослужений** — расписание богослужений ваших филиалов, автоматически берётся из настройки посещаемости
   - **Проповеди** — ваша библиотека проповедей в виде полного обозревателя, сетки, списка или с выделенной последней проповедью
   - **Карта** — встроенная карта с центром на адресе церкви
   - **Таблица** — простая сетка строк и столбцов для табличных данных
   - **Текст с фото** — текст и изображение рядом
   - **Логотип** — логотип вашей церкви, берётся из раздела [Оформление](./appearance.md)
   - **Прямая трансляция** — плеер прямой трансляции, встроенный прямо на страницу
   - **Подкаст** — список выпусков, загружаемых из внешнего RSS-канала подкаста, URL которого вы указываете; есть настройки количества выпусков и отображения дат и описаний. Для каждого выпуска на опубликованном сайте есть аудиоплеер и ссылка **Скачать**, которая сохраняет аудиофайл выпуска под его названием. Этот элемент предназначен для демонстрации любого канала подкаста на вашем сайте; чтобы публиковать собственные проповеди как подкаст, см. [Управление проповедями](../sermons/managing-sermons.md#your-podcast-feed)
   - **Пожертвование** — кнопка пожертвования или встроенная форма пожертвования
   - **HTML** — ваш собственный HTML-код для продвинутых сценариев, например для встраивания виджета стороннего сервиса (см. [Использование элемента HTML](#using-the-html-element))
   - **iFrame** — встраивание внешнего содержимого по ссылке
3. Настройте элемент в появившейся панели параметров.

### Использование элемента HTML

Элемент **HTML** содержит два поля:

- **Содержимое HTML** — разметка, которая будет показана на странице. Любые теги `<script>`, которые вы здесь укажете, выполняются на опубликованном сайте.
- **JavaScript (без тега script)** — код скрипта, который выполняется при загрузке страницы. Сюда также можно вставить фрагмент для встраивания от поставщика вместе с его тегами `<script>` — он будет выполнен на опубликованном сайте.

Если в поле JavaScript вы вставите только веб-адрес (например, ссылку на изображение), поле станет красным с предупреждением *«Это веб-адрес, а не JavaScript.»* Голый адрес в этом поле ничего не делает. Чтобы показать картинку, используйте элемент **Изображение** или поместите `<img src="...">` в **Содержимое HTML**.

### Использование элемента «Календарь» {#using-the-calendar-element}

Элемент **Календарь** показывает события из одного из ваших календарей:

1. В поле **Выбрать** выберите **Календарь группы** (события одной группы — в списке отображаются группы, в которых вы состоите) или **Составленный календарь** (календарь, который вы создали в разделе **Календари**; см. [Составленный календарь](../calendars/curated-calendar.md)).
2. В поле **Выбрать календарь** укажите группу или календарь.
3. В разделе **Отображение** выберите способ показа:
   - **Календарь на месяц** — сетка месяца, по которой посетители могут переключаться. Каждое событие окрашено в цвет группы, к которой оно относится, поэтому события группы имеют одинаковый цвет во всех календарях. Цвета B1 назначает автоматически, настраивать ничего не нужно.
   - **Ближайшие события** — сетка плиток для ближайших 12 событий; повторяющееся событие показывается один раз — на ближайшей дате. Каждая плитка содержит фото события (или его название на тёмном цвете темы, если фото нет), значок с датой, день и время, а также первую строку описания. Кнопка **Подписаться** над плитками позволяет посетителям скопировать ссылку ICS на календарь или скачать его. Для этого отображения доступна настройка **Макет**: **Сетка** (по умолчанию) или **Прокрутка (автоматическая)** — в этом случае плитки выстраиваются в одну строку, которая прокручивается сама (см. [Макеты с прокруткой](#scrolling-layouts)). Для **Составленного календаря** включите настройку **Метка группы**, чтобы в правом верхнем углу плитки отображалось название группы события цветом календаря этой группы. События из архивных или конфиденциальных групп меток не получают.
4. Чтобы показать только некоторые события, введите тег в поле **Только события с тегом**, например `youth`. Появятся только события, в **Теги** которых есть это слово. Оставьте поле пустым, чтобы показывать все события. Теги задаются для каждого события; см. [Добавление и редактирование событий](../calendars/creating-calendars.md#adding-and-editing-events).

В обоих вариантах отображения нажатие на событие открывает его собственную страницу на вашем сайте. Страница события содержит фото события, название, дату и время, описание, а также блок с полями **Когда** (включая схему повторения для повторяющегося события) и **Где** (забронированные для него помещения). Там также есть кнопка **Зарегистрироваться на это событие**, если регистрация включена, и ссылка **Добавить в мой календарь**, которая скачивает событие в виде файла календаря. Страница устроена так, чтобы поисковые системы могли показывать дату и детали события в результатах поиска. Страницы событий из составленных календарей, которые выводятся на ваши страницы (для событий в ближайшие шесть месяцев), также включаются в карту сайта, чтобы поисковые системы могли их находить.

### Макеты с прокруткой {#scrolling-layouts}

Макет **Прокрутка (автоматическая)** в **Обзоре групп**, **Списке групп** и в отображении **Ближайшие события** элемента «Календарь» располагает плитки в одну строку вместо сетки. На телефоне каждая плитка занимает всю ширину строки, на компьютере рядом помещаются две плитки. Если плиток больше, чем помещается, строка:

- Примерно каждые четыре секунды переходит к следующей плитке и возвращается к первой после последней.
- Останавливается, когда посетитель наводит курсор, касается или переходит на неё клавишей Tab, и продолжает движение через несколько секунд.
- Показывает под строкой ряд точек — по одной на каждую плитку, при этом точка текущей плитки закрашена. Посетитель может нажать на точку, чтобы перейти к нужной плитке.

На устройствах с включённым режимом уменьшения движения строка остаётся неподвижной, и посетители прокручивают её сами, свайпом или колёсиком. Если все плитки помещаются, строка не двигается и точки не появляются.

### Изменение порядка содержимого

Перетаскивайте секции или элементы за значок-маркер (шесть точек) слева от каждого блока, чтобы изменить их порядок. Можно перетаскивать элементы внутри секции или переносить их между секциями.

## Оформление страницы

### Стили секций

Нажмите на любую секцию, чтобы открыть панель её стилей. Можно задать:

- **Фон** — сплошной цвет, градиент или изображение. Если используется фоновое изображение, выбор **Точки фокуса** позволяет щелчком указать, какая часть изображения остаётся по центру при изменении размера секции, а опция **Наложение** добавляет полупрозрачный оттенок поверх изображения для лучшей читаемости текста.
- **Отступы** — верхний и нижний интервалы внутри секции
- **Ширина** — на всю ширину или по центру с ограничением
- **Разделители** — декоративные фигурные разделители (волна, скос, изгиб, треугольник и другие) на верхнем или нижнем краю секции с настройками цвета, высоты и отражения

### Стили элементов

Нажмите на любой элемент, чтобы открыть панель его стилей. Типичные параметры включают размер шрифта, цвет, выравнивание, поля и отступы. Для изображений можно задать альтернативный текст и цель ссылки.

### Пользовательский CSS

Для продвинутого оформления каждая секция и элемент содержат поле **Пользовательский CSS**, где можно написать собственные правила CSS. Они применяются только к этому элементу, поэтому не повлияют непреднамеренно на остальную часть страницы.

:::tip
Если нужно применить стили ко всему сайту — например, пользовательский шрифт или общий цвет, — используйте настройки раздела [Оформление](./appearance.md) вместо пользовательского CSS на отдельных страницах.
:::

## Предварительный просмотр страницы

Используйте элементы управления просмотром на панели инструментов, чтобы проверить, как страница выглядит на разных размерах экрана:

- **Компьютер** — полноширинный вид в браузере
- **Телефон** — узкий вид в размере телефона

На телефонах колонки в строке выстраиваются одна под другой на всю ширину, если только вы не задали для них **Ширину для мобильных** в настройках строки. Списки проповедей и подкастов также показывают текст каждого выпуска под миниатюрой на телефонах.

Чтобы увидеть живую страницу именно так, как её увидят посетители, вернитесь к списку страниц и нажмите на путь страницы. Она откроется в новой вкладке браузера.

## Проверка доступности

Нажмите значок **Доступность** на панели инструментов, чтобы быстро проверить распространённые проблемы: изображения без альтернативного текста, низкий цветовой контраст или нарушенный порядок заголовков. Каждая проблема ведёт непосредственно к элементу, который нужно исправить, так что вы можете исправить её на месте.

## Отмена изменений

Редактор автоматически сохраняет историю правок. Для навигации используйте кнопки на панели инструментов или сочетания клавиш:

- **Отменить** (Ctrl+Z / Cmd+Z) — отменить последнее действие
- **Повторить** (Ctrl+Shift+Z или Ctrl+Y / Cmd+Shift+Z) — повторить отменённое действие

Также можно вернуть страницу к более раннему снимку. Нажмите **Посмотреть историю** на панели инструментов, чтобы увидеть список сохранённых снимков с описаниями, и нажмите на любую запись, чтобы вернуться к этому состоянию.

:::warning
Восстановление снимка заменяет текущее содержимое страницы версией из снимка. Это нельзя отменить стандартной кнопкой «Отменить». Если хотите сохранить возможность вернуться к текущему состоянию, создайте снимок перед восстановлением старого.
:::

## Сохранение и публикация

Изменения сохраняются автоматически по мере работы. Индикатор состояния на панели инструментов показывает, сохранены ли ваши изменения.

### Состояние черновика и публикации

У страниц может быть состояние **публикации**, которое определяет, когда посетители увидят ваши изменения. На панели инструментов отображается значок с текущим состоянием:

- **Сразу после сохранения** — страница не использует процесс публикации. Каждое сохранённое изменение сразу становится доступно на сайте. Это значение по умолчанию для новых страниц.
- **Неопубликованные изменения** — страница уже публиковалась, но после последней публикации вы внесли изменения. Посетители по-прежнему видят предыдущую опубликованную версию.
- **Опубликовано** — страница доступна на сайте, и сохранённое содержимое совпадает с тем, что видят посетители.

Чтобы опубликовать изменения, нажмите кнопку **Опубликовать** на панели инструментов. Страница сразу станет доступна.

Чтобы вернуться к последней опубликованной версии, не затрагивая того, что видят посетители, откройте меню переполнения (⋮) и нажмите **Отменить неопубликованные изменения**.

Чтобы отказаться от процесса публикации, откройте меню переполнения и нажмите **Отключить публикацию**. После этого правки снова будут сразу попадать на сайт.

:::tip
Используйте процесс черновика и публикации, когда хотите подготовить страницу — например, к предстоящему событию — и открыть её в нужный момент. Создайте и просмотрите страницу, а затем нажмите «Опубликовать», когда будете готовы.
:::
