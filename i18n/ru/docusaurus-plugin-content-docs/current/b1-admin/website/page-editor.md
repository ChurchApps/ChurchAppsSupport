# Использование редактора страниц

<div class="article-intro">

Редактор страниц B1 -- это визуальный конструктор с перетаскиванием, который позволяет создавать страницы сайта вашей церкви без написания кода. Вы можете добавлять секции и блоки контента, настраивать стили, просматривать результат и отменять изменения -- всё прямо в браузере.

</div>

## Открытие редактора

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **Website** и нажмите **Pages**.
2. Найдите нужную страницу в таблице Pages и нажмите **Edit Content**.

Редактор открывается на весь экран. В левой панели показана структура страницы и доступные элементы контента; в центральной области отображается предпросмотр страницы в реальном времени.

:::info
Редактор всегда отображается в светлой теме, независимо от настройки темы B1 Admin, и использует шрифты заголовков и основного текста, которые вы выбрали в [Appearance](appearance). Это гарантирует, что предпросмотр точно совпадает с тем, как страница будет выглядеть для посетителей сайта.
:::

## Структура страницы: секции и элементы

Каждая страница состоит из двух уровней:

- **Секции** -- Контейнеры верхнего уровня, которые делят страницу на горизонтальные полосы (например, блок-герой, блок с текстом или полоса подвала). Перед добавлением контента на каждой странице должна быть хотя бы одна секция.
- **Элементы** -- Отдельные части контента внутри секции, например текст, изображения, кнопки, карточки, формы и календари.

### Добавление секции

1. Нажмите **Add Section** (или кнопку **+** вверху левой панели).
2. Выберите, как начать:
   - **From a template** -- Просмотрите галерею шаблонов секций, сгруппированных по категориям (Hero, About, Services, Giving и т. д.), и выберите один, чтобы вставить готовую оформленную секцию с заранее заполненным контентом. Всё можно изменить после добавления.
   - **Blank section** -- Выберите вариант колонок (одна, две, три и т. д.) и создавайте секцию с нуля.
3. Новая секция появится в предпросмотре. Нажмите на неё, чтобы выбрать и настроить цвет фона, отступы и другие параметры стиля.

### Изменение макета секции

Если секция уже создана, но вы хотите другую структуру, используйте переключатель макета этой секции, чтобы заменить расположение колонок на другое из галереи, сохранив существующий контент и элементы.

### Добавление элементов в секцию

1. Нажмите внутри секции в предпросмотре, чтобы выбрать её.
2. Нажмите **Add Content** и выберите тип элемента из списка:
   - **Text** -- Заголовки, абзацы и форматированный текст
   - **Image** -- Загрузка фото или ссылка на него
   - **Button** -- Кликабельная кнопка-призыв (ссылка)
   - **Card** -- Изображение с заголовком и описанием
   - **Form** -- Встраивает [форму](../forms/creating-forms) прямо на страницу. Если у формы есть [фото в шапке](../forms/creating-forms.md#adding-a-header-photo), оно показывается над вопросами
   - **Calendar** -- Выводит календарь событий
   - **FAQ** -- Блоки «вопрос-ответ» в виде аккордеона
   - **Video** -- Встраивает видео по ссылке
   - **Groups Browser** -- Фильтруемый каталог всех групп церкви с необязательным поиском, фильтром по категории и фильтром по меткам
   - **Icon Feature** -- Значок с заголовком и коротким описанием для выделения особенностей или служений
   - **Gallery** -- Сетка из нескольких фото или макет masonry
   - **Testimonial** -- Одна или несколько цитат с именем автора, ролью и фото
   - **Social Icons** -- Значки со ссылками на профили вашей церкви в соцсетях: Facebook, Instagram, WhatsApp, YouTube, X, TikTok, Vimeo и Podcast. Укажите ссылку для каждого, который хотите показать; для **WhatsApp** используйте ссылку вида `https://wa.me/` с вашим номером или ссылку-приглашение в группу
   - **Countdown** -- Таймер обратного отсчёта до даты или времени еженедельного служения
   - **Stats** -- Ряд крупных чисел с подписями (участники, годы, филиалы)
   - **Campaign Progress** -- Живая шкала прогресса для кампании пожертвований, показывающая общую сумму, собранную на цель фонда
   - **Staff Grid** -- Карточки с фото участников группы; у группы должна быть включена опция **public roster**
   - **Service Times** -- Расписание служений ваших филиалов, автоматически берётся из настроек посещаемости
   - **Sermons** -- Ваша библиотека проповедей в виде полного обозревателя или сетки, списка или макета «избранное и последнее»
   - **Map** -- Встроенная карта с центром на адресе вашей церкви
   - **Table** -- Простая сетка строк и столбцов для табличного содержимого
   - **Text with Photo** -- Текст и изображение рядом
   - **Logo** -- Логотип вашей церкви, берётся из [Appearance](appearance)
   - **Live Stream** -- Плеер вашей прямой трансляции, встроенный прямо на страницу
   - **Podcast** -- Список эпизодов из внешней RSS-ленты подкаста, URL которой вы указываете; настраивается количество эпизодов и то, показывать ли даты и описания. Каждый эпизод на опубликованном сайте имеет аудиоплеер и ссылку **Download**, которая сохраняет аудиофайл эпизода под названием эпизода. Элемент предназначен для показа любой ленты подкаста на вашем сайте; чтобы публиковать собственные проповеди как подкаст, см. [Managing Sermons](../sermons/managing-sermons.md#your-podcast-feed)
   - **Donation** -- Кнопка пожертвования или встроенная форма пожертвования
   - **HTML** -- Собственный HTML-код для продвинутого использования, например для встраивания виджета стороннего сервиса (см. [Использование элемента HTML](#using-the-html-element))
   - **iFrame** -- Встраивает внешний контент по URL
3. Настройте элемент в панели настроек, которая появится.

### Использование элемента HTML {#using-the-html-element}

У элемента **HTML** есть два поля:

- **HTML Content** -- Разметка, которая будет показана на странице. Все теги `<script>`, которые вы здесь добавите, выполняются на опубликованном сайте.
- **JavaScript (exclude script tag)** -- Код скрипта, который выполняется при загрузке страницы. Сюда также можно вставить фрагмент для встраивания от поставщика вместе с его тегами `<script>`, и он будет выполнен на опубликованном сайте.

Если в поле JavaScript вы вставите только веб-адрес (например, ссылку на изображение), поле станет красным с предупреждением *«This is a web address, not JavaScript.»* Адрес в этом поле ничего не делает. Чтобы показать картинку, используйте элемент **Image** или поместите `<img src="...">` в **HTML Content**.

### Использование элемента Calendar {#using-the-calendar-element}

Элемент **Calendar** показывает события из одного из ваших календарей:

1. В разделе **Select** выберите **Group Calendar** (события одной группы -- в списке показаны группы, в которых вы состоите) или **Curated Calendar** (календарь, который вы создали в разделе **Calendars**; см. [Curated Calendar](../calendars/curated-calendar)).
2. В разделе **Select Calendar** выберите группу или календарь.
3. В разделе **Display** выберите, как его показать:
   - **Month calendar** -- Сетка месяца, которую посетители могут листать.
   - **Upcoming events** -- Сетка плиток для следующих 12 предстоящих событий; повторяющееся событие показывается один раз, на ближайшей дате. Каждая плитка показывает фото события (или его название на тёмном цвете темы, если фото нет), значок с датой, день и время, а также первую строку описания. Над плитками есть кнопка **Subscribe**, с помощью которой посетители могут скопировать ICS-ссылку календаря или скачать его. Для этого вида отображения появляется настройка **Layout**: **Grid** (по умолчанию) или **Scrolling (automatic)**, при которой плитки располагаются в один ряд, который сам прокручивается.
4. Чтобы показать только некоторые события, введите метку в поле **Only events tagged** -- например, `youth`. Появятся только события, у которых в **Tags** есть это слово. Оставьте поле пустым, чтобы показывать все события. Метки задаются для каждого события; см. [Добавление и редактирование событий](../calendars/creating-calendars.md#adding-and-editing-events).

В любом виде отображения клик по событию открывает его собственную страницу на вашем сайте. На странице события показаны фото события, название, дата и время, описание, а также блок с **When** (включая схему повторения для повторяющегося события) и **Where** (помещения, забронированные для события). Там также есть кнопка **Register for this Event**, если регистрация включена, и ссылка **Add to my calendar**, которая скачивает событие в виде файла календаря. Страница устроена так, чтобы поисковые системы могли показывать дату и подробности события в результатах поиска. Страницы событий из курируемых календарей, которые показаны на ваших страницах (для событий в ближайшие шесть месяцев), также попадают в карту сайта, чтобы поисковые системы могли их найти.

### Изменение порядка содержимого

Перетаскивайте секции или элементы за значок-ручку (шесть точек) слева от каждого элемента, чтобы изменить порядок. Элементы можно перетаскивать внутри секции или перемещать между секциями.

## Оформление страницы

### Стили секций

Нажмите на любую секцию, чтобы открыть панель стилей. Здесь можно задать:

- **Background** -- Сплошной цвет, градиент или изображение. При фоне-изображении выбор **Focal Point** позволяет кликнуть, чтобы указать, какая часть изображения остаётся по центру при масштабировании секции, а опция **Overlay** добавляет полупрозрачный цветовой слой поверх изображения, чтобы улучшить читаемость текста
- **Padding** -- Отступы сверху и снизу внутри секции
- **Width** -- На всю ширину или по центру / в контейнере
- **Dividers** -- Декоративные фигурные разделители (волна, скос, изгиб, треугольник и другие) на верхнем или нижнем краю секции, с настройками цвета, высоты и отражения

### Стили элементов

Нажмите на любой элемент, чтобы открыть панель стилей. Общие настройки включают размер шрифта, цвет, выравнивание, отступы margin и padding. Для изображений можно задать альтернативный текст (alt) и цели ссылок.

### Пользовательский CSS

Для продвинутого оформления у каждой секции и каждого элемента есть поле **Custom CSS**, в котором можно написать собственные правила CSS. Они ограничены этим элементом, поэтому случайно не повлияют на остальную страницу.

:::tip
Если нужно применить стили ко всему сайту -- например, собственный шрифт или общий цвет, -- используйте настройки [Appearance](appearance), а не пользовательский CSS на отдельных страницах.
:::

## Предпросмотр страницы

Используйте элементы управления предпросмотром на панели инструментов, чтобы проверить, как страница выглядит на разных размерах экрана:

- **Desktop** -- Вид во всю ширину браузера
- **Mobile** -- Узкий вид, как на телефоне

На телефонах колонки в строке друг под другом занимают всю ширину, если только для них не задана **Mobile Width** в настройках строки. Списки проповедей и подкастов также выводят текст каждого эпизода под миниатюрой на телефонах.

Чтобы увидеть живую страницу так, как её увидят посетители, вернитесь к списку Pages и нажмите на путь страницы. Она откроется в новой вкладке браузера.

## Проверка доступности

Нажмите значок **Accessibility** на панели инструментов, чтобы запустить быструю проверку на типичные проблемы: изображения без альтернативного текста, низкий цветовой контраст или заголовки в неправильном порядке. Каждая проблема ведёт непосредственно к элементу, который нужно исправить, так что вы можете исправить её на месте.

## Отмена изменений

Редактор автоматически сохраняет историю правок. Используйте кнопки на панели инструментов или сочетания клавиш для навигации:

- **Undo** (Ctrl+Z / Cmd+Z) -- Отменить последнее действие
- **Redo** (Ctrl+Shift+Z или Ctrl+Y / Cmd+Shift+Z) -- Вернуть отменённое действие

Также можно вернуть страницу к более раннему снимку. Нажмите **View history** на панели инструментов, чтобы увидеть список сохранённых снимков с описаниями, и нажмите на любой пункт, чтобы вернуться к этому состоянию.

:::warning
Восстановление снимка заменяет текущий контент страницы версией из снимка. Это нельзя отменить стандартной кнопкой отмены. Если хотите сохранить возможность вернуться, сохраните снимок текущего состояния, прежде чем восстанавливать старый.
:::

## Сохранение и публикация

Изменения сохраняются автоматически по мере работы. Индикатор состояния на панели инструментов показывает, сохранены ли ваши изменения.

### Состояние черновика и публикации

У страниц может быть состояние **published** (опубликовано), которое определяет, когда посетители видят ваши изменения. На панели инструментов отображается значок с текущим состоянием:

- **Live on save** -- Страница не использует процесс публикации. Каждое сохранённое изменение сразу становится видимым. Это значение по умолчанию для новых страниц.
- **Unpublished changes** -- Страница уже публиковалась, но вы внесли изменения после последней публикации. Посетители по-прежнему видят предыдущую опубликованную версию.
- **Published** -- Страница опубликована, и сохранённый контент совпадает с тем, что видят посетители.

Чтобы опубликовать изменения, нажмите кнопку **Publish** на панели инструментов. Страница становится доступна сразу.

Чтобы вернуться к последней опубликованной версии, не затрагивая то, что видят посетители, откройте меню «⋮» и нажмите **Discard unpublished changes**.

Чтобы перестать использовать процесс публикации, откройте меню и нажмите **Turn off publishing**. После этого правки снова сразу становятся видимыми.

:::tip
Используйте процесс черновика и публикации, когда хотите подготовить страницу, например к предстоящему событию, и открыть её в нужный момент. Создайте и просмотрите страницу, а затем нажмите Publish, когда будете готовы.
:::
