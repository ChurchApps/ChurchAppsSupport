# Блог

<div class="article-intro">

Страница Blog позволяет публиковать новости, обновления и духовные размышления на сайте вашей церкви. Публикации отображаются в виде списка карточек на `/blog`, имеют собственный URL и попадают в RSS-ленту, за которой могут следить другие инструменты (например, Zapier), отслеживая новые публикации.

</div>

## Доступ к блогу

1. В B1 Admin нажмите **Website** в левом меню.
2. Нажмите вкладку **Blog** вверху раздела Website Pages.
3. Страница Blog показывает список всех публикаций вместе с их статусом и датой публикации.

## Добавление публикации

1. Нажмите **Add Post** в правом верхнем углу.
2. Введите **Title**. Удобный для URL слаг генерируется автоматически по мере ввода -- при желании вы можете отредактировать его вручную, если нужен другой адрес.
3. Добавьте **Excerpt** -- краткое описание, которое показывается в списке публикаций, мета-описаниях и RSS-ленте. Если оставить поле пустым, описание сгенерируется автоматически из начала текста публикации.
4. Напишите текст публикации в редакторе **Content**, используя Markdown. Нажмите **Preview**, чтобы увидеть, как будет выглядеть отформатированная публикация.
5. Выберите **Category** (существующую или введите новую) и, при желании, **Tags** через запятую.
6. Нажмите **Select Image**, чтобы выбрать фото из вашей галереи [Files](files), или загрузите новое. Загруженные фото открываются во встроенном инструменте обрезки с фиксированным соотношением сторон 16:9, так что вы можете кадрировать любое фото под заголовок публикации и карточки списка.
7. Задайте **Author** -- по умолчанию это вы, но можно найти и выбрать любого человека из вашей базы данных.
8. Включите **Published** и задайте **Publish Date**, когда будете готовы опубликовать материал. Оставьте выключенным, чтобы сохранить публикацию как черновик.

:::tip
Установите **Publish Date** в будущем, чтобы запланировать публикацию. Она останется скрытой от посетителей и будет отмечена меткой **Scheduled** в списке блога до наступления этой даты.
:::

## Статусы публикаций

Каждая публикация в списке отображает один из трёх статусов:

- **Draft** -- не опубликована. Видна только в админ-панели.
- **Scheduled** -- параметр Published включён, но дата публикации ещё не наступила.
- **Published** -- опубликована на сайте и включена в RSS-ленту.

## Редактирование, предпросмотр и удаление публикаций

- Нажмите значок **Edit** рядом с публикацией, чтобы внести изменения.
- Нажмите значок **View** (виден у опубликованных публикаций), чтобы открыть публикацию на сайте в новой вкладке.
- Нажмите значок **Delete**, чтобы удалить публикацию безвозвратно.

## Как посетители видят ваш блог

Опубликованные материалы отображаются по адресу `{yoursite}/blog`, по 10 на странице, со ссылками **Older**/**Newer** для перехода по архиву, а также фильтром по категориям и указанием автора и фото для каждой публикации. Теги тоже отображаются в виде кликабельных чипов, позволяя посетителям фильтровать список по тегу таким же образом. Отдельные публикации доступны по адресу `{yoursite}/blog/{slug}` и включают похожие публикации из той же категории. Страница блога также публикует RSS-ленту, которую автоматически обнаруживают программы для чтения лент и инструменты автоматизации, такие как Zapier.

:::info
Публикации блога -- это отдельный тип контента, отличный от обычных страниц сайта: они не создаются в [редакторе страниц](page-editor) и не отображаются в списке Pages. Это делает ведение блога быстрым и сфокусированным на написании текста.
:::
