# Блог

<div class="article-intro">

Функция блога позволяет вам публиковать статьи на вашем сайте B1.church. Делитесь новостями, размышлениями и объявлениями с вашей общиной.

</div>

## Доступ к блогу

1. Перейдите в раздел **Website** в B1 Admin
2. Нажмите на вкладку **Blog**

## Создание записи блога

1. Нажмите **New Post**
2. Заполните информацию:
   - **Title** — заголовок постьб
   - **Author** — кто написал статью
   - **Date** — дата публикации
   - **Category** — выберите или создайте категорию
   - **Featured Image** — изображение для представления поста
   - **Content** — текст статьи (поддерживает форматирование и медиа)
3. Нажмите **Preview** для предпросмотра
4. Нажмите **Publish** для публикации

## Форматирование контента

При написании статьи вы можете использовать:

- **Bold and Italics** — выделение текста
- **Headings** — структурируйте статью с подзаголовками
- **Lists** — создавайте маркированные или нумерованные списки
- **Images** — добавляйте изображения в статью
- **Links** — создавайте ссылки на другие статьи или веб-сайты

## Управление постами

После публикации вы можете:

- **Edit** — отредактируйте опубликованный пост
- **Delete** — удалите пост
- **Schedule** — настройте пост для публикации в будущем

## Категории

Создавайте категории для организации ваших постов:

1. На странице блога нажмите **Categories**
2. Нажмите **New Category**
3. Дайте категории имя
4. Нажмите **Save**

Члены могут фильтровать блог по категориям на вашем сайте.

## SEO

Для каждого поста вы можете установить:

- **Meta Description** — описание для поисковых систем
- **Slug** — URL-дружественное имя для поста

## Советы для хорошего блога

- Публикуйте регулярно для привлечения читателей
- Используйте привлекательные изображения
- Пишите по темам, интересующим вашу общину
- Включайте вызовы к действию (регистрация на события и т.д.)
