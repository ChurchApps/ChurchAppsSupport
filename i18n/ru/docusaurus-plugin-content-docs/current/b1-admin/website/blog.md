# Блог

<div class="article-intro">

На странице Blog вы публикуете новости, обновления и размышления для своего сайта церкви. Записи появляются в виде карточек на странице `/blog`, по собственному адресу и в ленте RSS, которую могут отслеживать другие инструменты (например, Zapier) для появления новых записей.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Выполните [первоначальную настройку](initial-setup) для вашего сайта
- Если вы хотите, чтобы посетители находили блог через меню, добавьте ссылку на `/blog` в [Managing Pages](managing-pages)

</div>

## Открытие блога

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в левом верхнем углу) и разверните **Website**.
2. Нажмите **Blog**.
3. На странице Blog перечислены все записи с их статусом и датой публикации.

## Добавление записи

1. Нажмите **Add Post** в правом верхнем углу.
2. Введите **Title**. **Web address** (slug) в формате, пригодном для URL, создаётся автоматически по мере ввода — при желании его можно изменить прямо в поле, если нужен другой адрес.
3. Добавьте **Excerpt** — короткое резюме, которое показывается в списке записей, в meta-описаниях и в ленте RSS. Если оставить поле пустым, оно будет создано автоматически из начала текста записи.
4. Напишите текст записи в редакторе **Content** с использованием Markdown. Нажмите **Preview**, чтобы увидеть, как будет выглядеть отформатированная запись.
5. Выберите **Category** (существующую или введите новую) и, при желании, **Tags** через запятую.
6. Нажмите **Select Image», чтобы выбрать фото из галереи [Files](files), или загрузите новое. Загруженные фото открываются во встроенном инструменте обрезки с фиксированным соотношением 16:9, так что вы можете подобрать кадр под шапку записи и карточки в списке.
7. Укажите **Author** — по умолчанию это вы, но можно найти и выбрать любого человека из вашей базы.
8. Включите **Published** и задайте **Publish Date**, когда будете готовы сделать запись публичной. Оставьте выключенным, чтобы сохранить запись как черновик.

:::tip
Задайте **Publish Date** в будущем, чтобы запланировать публикацию. Запись остаётся скрытой от посетителей и показывает метку **Scheduled** в списке блога до наступления этой даты.
:::

## Статусы записей

Каждая запись в списке имеет один из трёх статусов:

- **Draft** — не опубликована. Видна только в административной части.
- **Scheduled** — **Published** включено, но дата публикации в будущем.
- **Published** — опубликована на вашем сайте и включена в ленту RSS.

## Редактирование, предпросмотр и удаление записей

- Нажмите **Edit** рядом с записью, чтобы внести изменения.
- Нажмите **View on Site** (показывается у опубликованных записей), чтобы открыть опубликованную запись на вашем сайте в новой вкладке.
- Нажмите **Delete**, чтобы удалить запись навсегда.

## Как посетители видят ваш блог

Опубликованные записи появляются по адресу `{yoursite}/blog`, по 10 на странице, со ссылками **Older**/**Newer** для перелистывания архива, а также с фильтром по категориям и подписью автора и фото каждой записи. Теги тоже отображаются как кликабельные метки, позволяя посетителям так же фильтровать список по тегам. Отдельные записи находятся по адресу `{yoursite}/blog/{slug}` и включают похожие записи из той же категории. Страница блога также публикует ленту RSS, которую автоматически находят программы для чтения лент и инструменты автоматизации вроде Zapier.

:::info
Записи блога — это отдельный тип контента, отличный от обычных страниц сайта: их нельзя создать в [редакторе страниц](page-editor), и они не появляются в списке Pages. Это позволяет быстро писать записи, сосредоточившись на тексте.
:::

## Комментарии под записями

B1 не размещает комментарии к записям блога сам, но вы можете подключить сервис комментариев. Под каждой записью можно также разместить что-либо ещё, например форму подписки на рассылку или кнопку пожертвования.

1. Зарегистрируйтесь в сервисе комментариев, например [Hyvor Talk](https://talk.hyvor.com), [FastComments](https://fastcomments.com) или [Disqus](https://disqus.com), и скопируйте его код для встраивания.
2. На странице Blog прокрутите до раздела **Below Every Post**.
3. Вставьте код для встраивания и нажмите **Save**.

Код появляется под содержимым каждой опубликованной записи. Сервис комментариев сам отвечает за модерацию и фильтрацию спама, поэтому регулярно проверяйте его панель управления.

:::tip
Очистите поле и нажмите **Save**, чтобы удалить код из всех записей. Видеть это поле могут только те, кто может редактировать настройки церкви.
:::
