# Файлы

<div class="article-intro">

Страница "Файлы" — это центральный репозиторий для всех медиа и документов, используемых на веб-сайте вашей церкви. Отсюда вы можете загружать, просматривать и управлять каждым изображением, документом и файлом медиа, который нужен вашему сайту.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Завершите [Начальную настройку](initial-setup) для вашего сайта
- Оптимизируйте изображения перед загрузкой для более быстрого времени загрузки страницы
- Подготовьте файлы в распространенных веб-форматах (PNG, JPG, PDF и т. д.)

</div>

## Загрузка файлов

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **Веб-сайт** и нажмите **Файлы**.
2. На панели **Загрузка файлов** справа нажмите **Выбрать файл** и выберите файл на компьютере. (Кнопка **Загрузка файлов** вверху страницы открывает ту же панель.)
3. Файл загружается и появляется в таблице файлов.

На панели загрузки также показано, сколько места вы используете. 100 МБ предоставляются бесплатно; чтобы получить больше, подключите собственный Google Drive, Dropbox, OneDrive или S3-бакет в разделе **Настройки**, в секции **Хранилище файлов**.

:::tip
Для лучших результатов оптимизируйте изображения перед загрузкой. Меньший размер файла помогает вашему веб-сайту загружаться быстрее для посетителей. Инструменты, такие как TinyPNG или Squoosh, могут сжимать изображения без заметной потери качества.
:::

## Просмотр файлов {#browsing-files}

В таблице файлов перечислены все загруженные файлы с их **Именем** и **Размером**. Нажмите на имя файла, чтобы открыть его в новой вкладке. Давайте файлам понятные, описательные имена перед загрузкой, чтобы ваша команда могла быстро их найти.

## Использование файлов на вашем веб-сайте

1. Найдите файл в таблице файлов.
2. Нажмите **Копировать ссылку**, чтобы скопировать URL файла. Вы можете вставить этот URL в элементы изображений, ссылки для загрузки или любые другие элементы, которые принимают URL файла.
3. Загруженные здесь файлы доступны для использования на всех страницах и блоках содержимого вашего веб-сайта.

:::info
При создании страниц в [Управлении страницами](managing-pages) вы можете ссылаться на любой загруженный здесь файл по его URL. Это держит все ваши медиа организованными в одном центральном месте.
:::

## Удаление файлов

1. Найдите файл, который хотите удалить, в таблице файлов.
2. Нажмите **Удалить** рядом с ним и подтвердите, чтобы навсегда удалить его из библиотеки.
3. Убедитесь, что файл не используется ни на одной странице перед удалением, так как это разрушит все ссылки или изображения, которые на него ссылаются.

:::warning
Удаленные файлы невозможно восстановить. Дважды проверьте, что файл больше не используется ни на одной странице перед его удалением.
:::
