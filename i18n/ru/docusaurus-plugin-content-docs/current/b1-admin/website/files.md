# Файлы

<div class="article-intro">

Страница "Файлы" — это центральный репозиторий для всех медиа и документов, используемых на веб-сайте вашей церкви. Отсюда вы можете загружать, организовывать, просматривать и управлять каждым изображением, документом и файлом медиа, который нужен вашему сайту.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Завершите [Начальную настройку](initial-setup) для вашего сайта
- Оптимизируйте изображения перед загрузкой для более быстрого времени загрузки страницы
- Подготовьте файлы в распространенных веб-форматах (PNG, JPG, PDF и т. д.)

</div>

## Загрузка файлов

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **Веб-сайт** и нажмите **Файлы**.
2. Перетащите файлы прямо в область загрузки или нажмите кнопку загрузки, чтобы просмотреть компьютер.
3. Ваши файлы загружаются и сразу же появляются в библиотеке файлов.

:::tip
Для лучших результатов оптимизируйте изображения перед загрузкой. Меньший размер файла помогает вашему веб-сайту загружаться быстрее для посетителей. Инструменты, такие как TinyPNG или Squoosh, могут сжимать изображения без заметной потери качества.
:::

## Организация с помощью папок

1. Создайте папки для группировки связанных файлов — например, "Графика проповедей", "Баннеры событий" или "Фотографии персонала".
2. Перемещайте файлы между папками, чтобы ваша библиотека была чистой при ее расширении.
3. Используйте четкие и описательные имена папок, чтобы ваша команда могла быстро найти файлы.

## Просмотр и поиск

- Прокрутите библиотеку файлов, чтобы увидеть миниатюры всех загруженных файлов.
- Используйте функцию **поиска**, чтобы найти файлы по названию, когда ваша библиотека станет большой.
- Нажмите на любой файл, чтобы просмотреть его детали, включая имя файла, размер и URL.

## Использование файлов на вашем веб-сайте

1. Нажмите на файл, чтобы просмотреть его детали.
2. **Скопируйте URL файла**, чтобы использовать его на страницах вашего сайта. Вы можете вставить этот URL в элементы изображений, ссылки для загрузки или любые другие элементы, которые принимают URL файла.
3. Загруженные здесь файлы доступны для использования на всех страницах и блоках содержимого вашего веб-сайта.

:::info
При создании страниц в [Управлении страницами](managing-pages) вы можете ссылаться на любой загруженный здесь файл по его URL. Это держит все ваши медиа организованными в одном центральном месте.
:::

## Удаление файлов

1. Выберите файл, который хотите удалить.
2. Нажмите кнопку **Удалить**, чтобы навсегда удалить его из вашей библиотеки.
3. Убедитесь, что файл не используется ни на одной странице перед удалением, так как это разрушит все ссылки или изображения, которые его ссылаются.

:::warning
Удаленные файлы невозможно восстановить. Дважды проверьте, что файл больше не используется ни на одной странице перед его удалением.
:::
