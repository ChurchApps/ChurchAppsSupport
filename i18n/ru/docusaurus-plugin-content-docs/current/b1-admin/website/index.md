# Веб-сайт

Раздел "Website" позволяет вам управлять сайтом B1.church вашей церкви, включая содержание, дизайн и навигацию.

## Подразделы

- **Appearance** — цвета, шрифты, логотип
- **Blog** — публикация статей и новостей
- **Navigation Styles** — макет и стили меню

## Типичные задачи

- Обновление дизайна сайта
- Публикация блога
- Управление навигацией
- Управление содержимым

## Начало работы

1. Перейдите в раздел **Website** в B1 Admin
2. Выберите нужный подраздел
3. Начните редактирование содержимого

## Советы

- Используйте бренд-согласованный дизайн
- Регулярно обновляйте содержимое
- Тестируйте на мобильных устройствах
- Используйте высокое качество изображений
