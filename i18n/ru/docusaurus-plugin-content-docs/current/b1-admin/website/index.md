# Сайт

<div class="article-intro">

Раздел Website в B1 Admin — это полнофункциональный конструктор сайтов для вашей церкви. Вы можете создавать страницы, настраивать внешний вид сайта, управлять медиафайлами и публиковать календари событий — и всё это без написания кода.

</div>

## Что можно делать {#what-you-can-do}

Конструктор сайтов состоит из следующих основных разделов:

### Страницы {#pages}

Создавайте и управляйте всеми страницами сайта вашей церкви. В таблице **Pages** перечислена каждая страница: страницы, созданные системой автоматически, помечены значком **Generated**, а остальные — это собственные страницы, которые вы создали. Вы можете добавлять новые собственные страницы, редактировать существующие или преобразовывать автоматически созданные страницы в собственные, чтобы полностью контролировать их содержимое.

Ссылки навигации перечислены на панели **Main Navigation** рядом с таблицей Pages. Их можно переупорядочить и вкладывать друг в друга перетаскиванием, чтобы задать нужную иерархию и порядок для посетителей. См. [Управление страницами](./managing-pages.md).

### Блог {#blog}

Публикуйте новости, обновления и размышления как записи блога по адресу `/blog` на вашем сайте, с RSS-лентой. См. руководство [Блог](./blog.md).

### Блоки {#blocks}

Создавайте многоразовые компоненты содержимого, которые можно размещать на нескольких страницах. Блоки экономят время, когда содержимое, например призыв к действию, баннер с объявлением или раздел контактов, появляется в нескольких местах. Обновите блок один раз — и изменение применится везде, где он используется. См. [Многоразовые блоки](./blocks.md).

### Оформление {#appearance}

Настраивайте тему, цвета, шрифты, логотип и интервалы сайта. Для быстрого старта можно применить готовые темы оформления, а для тонкой настройки каждой детали — редактор цветовой палитры, настройки типографики и пользовательский CSS. Подробности см. в руководстве [Оформление](./appearance.md).

### Файлы {#files}

Загружайте и управляйте всеми медиафайлами — изображениями, документами и другими файлами — в одном центральном месте и копируйте ссылки на файлы для использования на любой части сайта. Подробнее см. в разделе [Файлы](./files.md).

### Календари {#calendars}

Публикуйте календари событий на сайте, чтобы посетители видели, что происходит в вашей церкви. Создавайте кураторские календари, которые собирают события из нескольких групп в один вид. У календарей есть собственный пункт **Calendars** в меню B1 Admin, отдельный от **Website**.

:::tip
Если вы впервые настраиваете сайт, начните с [Первоначальной настройки](./initial-setup.md). Там пошагово описаны настройка домена, создание первой страницы и оформление сайта.
:::
