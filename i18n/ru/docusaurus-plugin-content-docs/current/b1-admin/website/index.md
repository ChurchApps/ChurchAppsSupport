# Веб-сайт

<div class="article-intro">

Раздел "Веб-сайт" в B1 Admin предоставляет вам полнофункциональный конструктор веб-сайтов для вашей церкви. Вы можете создавать страницы, настраивать внешний вид и тематику вашего сайта, управлять файлами мультимедиа и публиковать календари событий — всё без написания кода.

</div>

## Что вы можете делать

Конструктор веб-сайтов организован в пять основных областей:

### Страницы

Создавайте и управляйте всеми страницами на вашем веб-сайте церкви. Таблица **Страницы** показывает каждую страницу вместе с её статусом — либо **Сгенерирована** (автоматически созданная системой), либо **Пользовательская** (созданная вами). Вы можете добавлять новые пользовательские страницы, редактировать существующие или преобразовывать автоматически созданные страницы в пользовательские страницы для полного контроля над их содержанием.

Ваши ссылки навигации отображаются в структуре дерева. Вы можете переупорядочивать ссылки, перетаскивая их, чтобы установить точную иерархию и порядок, который посетители будут видеть.

### Блоки

Создавайте повторно используемые компоненты содержания, которые вы можете размещать на нескольких страницах. Блоки экономят время, когда у вас есть содержание, такое как призыв к действию, баннер объявления или секция контактов, которые отображаются в нескольких местах. Обновите блок один раз, и изменение применится везде, где он используется.

### Внешний вид

Настраивайте тему, цвета, шрифты, логотип и интервалы вашего веб-сайта. Вы можете применить предварительно созданные стилевые темы для быстрого старта или тонко настроить все детали с помощью редактора палитры цветов, параметров типографики и пользовательского CSS. Полные сведения см. в руководстве [Внешний вид](appearance).

### Файлы

Загружайте и организуйте все ваши медиа-активы — изображения, документы и другие файлы — в одном центральном месте. Используйте папки, чтобы содержать вещи в порядке, и копируйте URL-адреса файлов для использования в любом месте на вашем сайте. Дополнительную информацию см. в [Файлы](files).

### Календари

Публикуйте календари событий на вашем веб-сайте, чтобы посетители видели, что происходит в вашей церкви. Создавайте отобранные календари, которые объединяют события от нескольких групп в единое представление.

:::tip
Начните с [Начальная установка](initial-setup), если вы впервые настраиваете свой веб-сайт. Она проведёт вас через настройку домена, создание вашей первой страницы и настройку внешнего вида вашего сайта.
:::
