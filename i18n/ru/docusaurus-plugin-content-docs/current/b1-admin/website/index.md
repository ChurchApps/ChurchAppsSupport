# Веб-сайт

<div class="article-intro">

Раздел Веб-сайт в B1 Admin предоставляет полнофункциональный конструктор сайтов для вашей церкви. Вы можете создавать страницы, настраивать внешний вид сайта, управлять медиафайлами и публиковать календари событий — и все это без написания какого-либо кода.

</div>

## Что вы можете делать

Конструктор веб-сайтов состоит из следующих основных разделов:

### Страницы

Создавайте и управляйте всеми страницами сайта вашей церкви. В таблице **Страницы** перечислена каждая страница — страницы, созданные системой автоматически, помечены значком **Generated**, а остальные — это пользовательские страницы, которые вы создали. Вы можете добавлять новые пользовательские страницы, редактировать существующие или преобразовывать автоматически созданные страницы в пользовательские для полного контроля над их содержимым.

Ссылки навигации отображаются в виде древовидной структуры. Вы можете изменять порядок ссылок перетаскиванием, чтобы задать точную иерархию и порядок, которые увидят посетители.

### Блог

Публикуйте новости, обновления и размышления в виде записей блога по адресу `/blog` на вашем сайте, с RSS-лентой. См. руководство [Блог](./blog.md).

### Блоки

Создавайте многоразовые компоненты содержимого, которые можно размещать на нескольких страницах. Блоки экономят время, когда содержимое, например призыв к действию, баннер объявлений или блок контактов, появляется в нескольких местах. Обновите блок один раз, и изменения применятся везде, где он используется.

### Внешний вид

Настраивайте тему сайта, цвета, шрифты, логотип и интервалы. Вы можете применить готовые стилевые темы для быстрого старта или тонко настроить каждую деталь с помощью редактора цветовой палитры, настроек типографики и пользовательского CSS. Полные сведения см. в руководстве [Внешний вид](./appearance.md).

### Файлы

Загружайте и управляйте всеми медиафайлами — изображениями, документами и другими файлами — в одном центральном месте, а также копируйте ссылки на файлы для использования в любом месте сайта. Подробнее см. [Файлы](./files.md).

### Календари

Публикуйте календари событий на вашем сайте, чтобы посетители могли видеть, что происходит в вашей церкви. Создавайте подобранные календари, которые объединяют события из нескольких групп в одном представлении. У календарей есть собственный пункт **Календари** в меню B1 Admin, отдельный от **Веб-сайт**.

:::tip
Начните с [Начальной настройки](./initial-setup.md), если вы настраиваете веб-сайт впервые. Там пошагово описаны настройка домена, создание первой страницы и настройка внешнего вида сайта.
:::
