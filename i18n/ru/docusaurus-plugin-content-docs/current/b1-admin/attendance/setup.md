# Настройка посещаемости

<div class="article-intro">

Перед отслеживанием посещаемости вам нужно рассказать B1 Admin о физических местоположениях, времени служб и группах. Эта одноразовая настройка создает структуру для всего отслеживания.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужен активный аккаунт B1 Admin
- Убедитесь, что ваши [группы созданы](../groups/creating-groups.md)

</div>

## Ключевые концепции

- **Кампус** — физическое место, где собирается ваша церковь (например, «Главный кампус»). Кампусы управляются в разделе **Настройки**.
- **Служение** — повторяющееся собрание на кампусе (например, «Воскресное служение»)
- **Время служения** — конкретное время проведения служения (например, «9:00»)
- **Запланированная группа** — группа, назначенная службе
- **Незапланированная группа** — независимая группа

## Настройка структуры

1. Откройте **B1 Admin**, нажмите **меню разделов** в левом верхнем углу (название раздела с маленькой стрелкой) и выберите **Люди**
2. В панели навигации нажмите вкладку **Посещаемость**. Вкладка **Настройка** выбрана по умолчанию
3. Нажмите **Управление кампусами** (в правом верхнем углу панели настройки). Это откроет **Настройки → Кампусы**. Нажмите **Добавить кампус**, введите название вашего места (адрес и часовой пояс необязательны) и нажмите **Сохранить**
4. Вернитесь в **Люди → Посещаемость → Настройка**. Ваш кампус теперь отображается в таблице настройки
5. Нажмите **кнопку + в колонке «Служение»** под вашим кампусом. Введите название служения, например «Воскресное служение», и нажмите **Сохранить**
6. Нажмите **кнопку + в колонке «Время»** под служением. Введите время, например «9:00», и нажмите **Сохранить**. Повторите для каждого времени служения
7. Чтобы связать группу со временем служения, откройте группу на вкладке **Группы**, нажмите карандаш **Редактировать** и используйте **Добавить время служения** — см. следующий раздел

### Включение отслеживания посещаемости

1. Нажмите **Группы** и выберите группу
2. Нажмите **Редактировать**
3. Установите **Отслеживание посещаемости** на **Да**
4. Нажмите **Сохранить**

## Редактирование

Вы можете обновить настройку в любое время.

:::info
Удаление времени служения не удаляет предыдущие записи.
:::
