# Отслеживание посещаемости

<div class="article-intro">

После настройки кампусов, времени служения и групп B1 Admin упрощает просмотр данных о посещаемости и выявление тенденций. Страница посещаемости предоставляет два представления отчетов — вкладка **Attendance** для тенденций по всей церкви и вкладка **Groups** для деталей на уровне группы. Используйте эти инструменты для понимания закономерностей роста, выявления снижающегося вовлечения и принятия решений на основе данных для вашей церкви.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Ваша структура посещаемости должна быть настроена с минимум одним кампусом и одним временем служения. Если вы еще этого не сделали, см. [Настройка посещаемости](setup.md).
- Данные о посещаемости должны быть записаны, прежде чем отчеты покажут результаты. Данные могут поступить из [ручного ввода](recording-attendance.md) или [самостоятельной регистрации](check-in.md).

</div>

## Просмотр тенденций посещаемости

1. Откройте **B1 Admin**, затем откройте **меню раздела** в верхнем левом углу и выберите **People**.
2. Нажмите вкладку **Attendance**.
3. Отчет запускается автоматически при открытии вкладки, показывая посещаемость за периодом по умолчанию.

## Фильтрация данных

Используйте фильтры в верхней части страницы для сужения результатов:

- **Date Range** — выберите начальную и конечную дату для фокусировки на конкретном периоде.
- **Campus** — выберите кампус, чтобы увидеть посещаемость только для этого местоположения.
- **Service Time** — выберите время служения для детализации конкретного собрания.

График и данные обновляются сразу же при изменении фильтра, поэтому вы можете быстро сравнивать различные периоды времени или местоположения.

:::info
Отчеты автоматически перезапускаются каждый раз, когда вы открываете вкладку "Attendance", поэтому вы всегда будете видеть актуальные цифры без необходимости нажимать кнопку обновления.
:::

## Посещаемость групп

Вкладка **Groups** показывает посещаемость, разбитую по отдельным группам. Это полезно, когда вы хотите мониторить конкретный класс, команду служения или небольшую группу, а не смотреть на общие цифры служений.

1. Выберите вкладку **Groups**.
2. Выберите группу из списка, чтобы увидеть её историю посещаемости.
3. Используйте фильтр диапазона дат для регулировки окна отчета.

:::tip
Посещаемость группы особенно ценна для [лидеров небольших групп](../groups/creating-groups.md), которые хотят отслеживать вовлечение в своей группе с течением времени.
:::

## Советы по использованию данных о посещаемости

- Просматривайте тенденции ежемесячно, чтобы рано заметить сезонные закономерности.
- Сравнивайте данные на уровне кампуса, чтобы понять, какие местоположения растут.
- Используйте отчеты на уровне групп для отслеживания [групп](../groups/group-members.md), которые показывают снижающуюся посещаемость.
- Комбинируйте информацию о посещаемости с инструментом [AI Search](../people/ai-search.md), чтобы найти людей, которые не посещали недавно.
