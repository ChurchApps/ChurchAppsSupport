# Отслеживание посещаемости

<div class="article-intro">

После настройки приходов, времён богослужений и групп, B1 Admin упрощает просмотр данных посещаемости и выявление тенденций. Страница посещаемости предоставляет два представления отчётов — вкладку **Attendance Trend** для общих тенденций церкви и вкладку **Group Attendance** для деталей уровня группы. Используйте эти инструменты, чтобы понять закономерности роста, выявить снижение уровня вовлечённости и принимать решения на основе данных для вашей церкви.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Ваша структура посещаемости должна быть установлена как минимум с одним приходом и временем богослужения. Если вы этого ещё не сделали, см. [Настройка посещаемости](setup.md).
- Данные посещаемости должны быть записаны, прежде чем отчёты будут показывать результаты. Данные могут поступать из [ручного ввода](recording-attendance.md) или [самостоятельной регистрации](check-in.md).

</div>

## Просмотр тенденций посещаемости

1. Откройте **B1 Admin**, откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **People** и нажмите **Attendance**.
2. Щелкните на вкладку **Attendance Trend**.
3. Отчёт запускается автоматически при открытии вкладки, показывая общую посещаемость на каждую неделю.

## Фильтрация данных

Используйте фильтры в поле **Filter Report**, чтобы сузить результаты, а затем нажмите **Run Report**:

- **Campus** — выберите приход, чтобы увидеть посещаемость только для этого местоположения.
- **Service** — ограничьте отчёт одним богослужением.
- **Service Time** — выберите время богослужения, чтобы углубиться в определённое собрание.
- **Group** — показать посещаемость для одной группы.
- **Start Date** и **End Date** — диапазон дат для включения. По умолчанию отчёт охватывает прошлый год, от года назад по сегодняшний день, и конечная дата включена полностью.

Отчёт показывает столбчатую диаграмму и таблицу общего количества посещений в неделю. Каждую неделю обозначает дата воскресенья этой недели. Таблица также имеет столбец **Session Dates**, в котором перечислены фактические даты в этой неделе, которые имели посещаемость (например, «9/27, 9/30»), поэтому вы можете увидеть, когда собрание в середине недели учитывается на той же неделе, что и воскресенье.

:::info
Отчёты автоматически запускаются каждый раз при открытии вкладки Attendance Trend, поэтому вы всегда будете видеть актуальные цифры без необходимости нажимать кнопку обновления.
:::

## Посещаемость группы

Вкладка **Group Attendance** показывает, кто посетил каждый сеанс группы. Это полезно, когда вы хотите отслеживать определённый класс, команду служения или небольшую группу, а не смотреть на общие цифры обслуживания.

1. Выберите вкладку **Group Attendance**.
2. Дополнительно выберите **Campus** и **Service**.
3. Установите **Start Date** и **End Date**. По умолчанию отчёт охватывает последнее воскресенье по сегодняшний день.
4. Нажмите **Run Report**.

Результаты сгруппированы по дате сеанса, затем по времени богослужения и группе, с людьми, которые посетили, внесённые в список под каждой группой. Времена богослужений, группы и имена отсортированы в алфавитном порядке, чтобы каждый заголовок появился один раз. Каждая строка человека также показывает столбец **Checked In** со временем записи его посещения (пусто, если времени нет в файле) и столбец **Membership Status** (например, Member или Visitor), поэтому вы можете заметить гостей с первого взгляда.

Чтобы загрузить данные, нажмите **Download Options** и выберите **Summary**. CSV содержит одну строку на члена группы, отсортированную по группе и затем по имени, и столбец для каждого датированного сеанса в диапазоне (например, «Sunday - 9:00 AM (2026-09-27)»), отмеченный как **present** или **absent**.

:::tip
Посещаемость группы особенно ценна для [лидеров небольших групп](../groups/creating-groups.md), которые хотят отслеживать вовлечённость в их группе с течением времени.
:::

## Советы по использованию данных посещаемости

- Ежемесячно проверяйте тенденции, чтобы выявить сезонные закономерности на ранней стадии.
- Сравнивайте данные на уровне прихода, чтобы понять, какие местоположения растут.
- Используйте отчёты на уровне групп для продолжения [групп](../groups/group-members.md), которые показывают снижение посещаемости.
- Сочетайте информацию о посещаемости с инструментом [AI Search](../people/ai-search.md), чтобы найти людей, которые недавно не посещали.
