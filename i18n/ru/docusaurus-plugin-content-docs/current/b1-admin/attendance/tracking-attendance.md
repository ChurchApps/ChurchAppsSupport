# Отслеживание посещаемости

<div class="article-intro">

После настройки кампусов, времен служб и групп B1 Admin упрощает просмотр данных о посещаемости и выявление трендов. Страница Attendance открывается сводкой посещаемости за эту неделю, а ее отчеты **All years** дают два основных представления — вкладку **Attendance Trend** для общецерковых трендов и вкладку **Group Attendance** для подробностей по группам — а также вкладку **Headcount Trend** для [итогов количества присутствующих](headcount-entry.md). Используйте эти инструменты, чтобы понимать модели роста, выявлять снижение вовлеченности и принимать решения на основе данных для вашей общины.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Структура посещаемости должна быть настроена хотя бы с одним кампусом и временем службы. Если вы еще этого не сделали, см. [Настройку посещаемости](setup.md).
- Данные о посещаемости должны быть записаны, прежде чем отчеты покажут результаты. Данные могут поступать из [ручного ввода](recording-attendance.md) или [самостоятельной регистрации](check-in.md).

</div>

## Просмотр трендов посещаемости {#viewing-attendance-trends}

1. Откройте **B1 Admin**, откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), раскройте **People** и нажмите **Attendance**.
2. Нажмите **All years** в левой колонке. По умолчанию выбрана вкладка **Attendance Trend**.
3. Отчет формируется автоматически при открытии вкладки и показывает общую посещаемость за каждую неделю.

:::tip
Для быстрого взгляда на текущую неделю главная страница Attendance показывает, сколько людей находится в помещении на этой неделе, разбивку по помещениям (группам), гостей и столбчатую диаграмму регистраций за 13 недель — отчет для этого не нужен.
:::

## Фильтрация данных {#filtering-your-data}

Используйте фильтры в блоке **Filter Report**, чтобы сузить результаты, а затем нажмите **Run Report**:

- **Campus** — выберите кампус, чтобы увидеть посещаемость только этого места.
- **Service** — ограничьте отчет одной службой.
- **Service Time** — выберите время службы, чтобы детально рассмотреть конкретное собрание.
- **Group** — покажите посещаемость одной группы.
- **Start Date** и **End Date** — диапазон дат для включения. По умолчанию отчет охватывает последний год: от одного года назад до сегодня, и конечная дата включается полностью.

Отчет показывает столбчатую диаграмму и таблицу общего числа посещений по неделям. Используйте значок печати, чтобы распечатать его, или **Download Options**, чтобы сохранить данные. Каждая неделя подписана датой воскресенья этой недели. В таблице также есть столбец **Session Dates** со списком фактических дат недели, на которые была посещаемость (например, «9/27, 9/30»), так что видно, когда собрание в середине недели учитывается в одной неделе с воскресной службой.

:::info
Отчеты запускаются автоматически каждый раз, когда вы открываете вкладку Attendance Trend, поэтому вы всегда увидите актуальные цифры без необходимости нажимать кнопку обновления.
:::

## Посещаемость групп {#group-attendance}

Вкладка **Group Attendance** показывает, кто посетил каждое занятие группы. Это полезно, когда нужно следить за конкретным классом, командой служения или малой группой, а не смотреть на общие цифры служб.

1. В отчетах **All years** выберите вкладку **Group Attendance**.
2. При необходимости выберите **Campus** и **Service**.
3. Задайте **Start Date** и **End Date**. По умолчанию отчет охватывает период от прошлого воскресенья до сегодня.
4. Нажмите **Run Report**.

Результаты группируются по дате занятия, затем по времени службы и группе, а под каждой группой перечислены люди, которые присутствовали. Времена служб, группы и имена сортируются по алфавиту, так что каждый заголовок появляется один раз. В строке каждого человека также есть столбец **Checked In** с временем, когда записана его посещаемость (пусто, если время не сохранено), и столбец **Membership Status** (например, Member или Visitor), чтобы можно было сразу заметить гостей.

Чтобы скачать данные, нажмите **Download Options** и выберите **Summary**. В CSV-файле одна строка на каждого участника группы, отсортированная по группе, а затем по имени, и столбец для каждого датированного занятия в диапазоне (например, «Sunday - 9:00 AM (2026-09-27)»), отмеченный как **present** (присутствовал) или **absent** (отсутствовал).

:::tip
Посещаемость групп особенно полезна для руководителей [малых групп](../groups/creating-groups.md), которые хотят отслеживать вовлеченность внутри своей группы во времени.
:::

## Советы по использованию данных о посещаемости {#tips-for-using-attendance-data}

- Просматривайте тренды ежемесячно, чтобы заранее замечать сезонные закономерности.
- Сравнивайте данные по кампусам, чтобы понимать, какие места растут.
- Используйте отчеты по группам, чтобы связаться с [группами](../groups/group-members.md), у которых посещаемость снижается.
- Сочетайте данные о посещаемости с инструментом [AI Search](../people/ai-search.md), чтобы находить людей, которые давно не приходили.
