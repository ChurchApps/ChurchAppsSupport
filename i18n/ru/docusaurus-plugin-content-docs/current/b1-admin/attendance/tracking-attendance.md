# Отслеживание посещаемости

<div class="article-intro">

После того как ваши кампусы, время служений и группы настроены, B1 Admin облегчает просмотр данных посещаемости и выявление тенденций. Страница "Посещаемость" предоставляет два представления отчётов -- вкладка **Тенденция посещаемости** для тенденций по всей церкви и вкладка **Посещаемость группы** для подробной информации на уровне группы. Используйте эти инструменты для понимания моделей роста, выявления снижения заинтересованности и принятия обоснованных данными решений для вашей церкви.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Ваша структура посещаемости должна быть установлена с как минимум одним кампусом и временем служения. Если вы этого ещё не сделали, см. [Настройка посещаемости](setup.md).
- Данные посещаемости должны быть записаны перед тем, как отчёты покажут результаты. Данные могут поступить из [ручного ввода](recording-attendance.md) или [самостоятельной регистрации](check-in.md).

</div>

## Просмотр тенденций посещаемости

1. Откройте **B1 Admin**, затем откройте **меню раздела** в верхнем левом углу и выберите **Люди**.
2. Нажмите вкладку **Тенденция посещаемости**.
3. Отчёт выполняется автоматически при открытии вкладки, показывая посещаемость в течение диапазона дат по умолчанию.

## Фильтрация данных

Используйте фильтры в верхней части страницы для сужения результатов:

- **Диапазон дат** -- выберите начальную и конечную дату для сосредоточения на определённом периоде.
- **Кампус** -- выберите кампус, чтобы увидеть посещаемость только для этого местоположения.
- **Время служения** -- выберите время служения для углубления в конкретное собрание.

График и данные обновляются, как только вы измените фильтр, поэтому вы можете быстро сравнивать разные периоды времени или местоположения.

:::info
Отчёты автоматически выполняются каждый раз при открытии вкладки "Тенденция посещаемости", поэтому вы всегда будете видеть актуальные числа без необходимости нажимать кнопку обновления.
:::

## Посещаемость группы

Вкладка **Посещаемость группы** показывает посещаемость, разбитую по отдельным группам. Это полезно, когда вы хотите отслеживать конкретный класс, служебную команду или небольшую группу вместо того чтобы смотреть на общие цифры служений.

1. Выберите вкладку **Посещаемость группы**.
2. Выберите группу из списка, чтобы увидеть её историю посещаемости.
3. Используйте фильтр диапазона дат для корректировки окна отчётности.

:::tip
Посещаемость группы особенно ценна для лидеров [небольших групп](../groups/creating-groups.md), которые хотят отслеживать вовлечённость в пределах их группы с течением времени.
:::

## Советы по использованию данных посещаемости

- Просматривайте тенденции ежемесячно, чтобы рано уловить сезонные закономерности.
- Сравнивайте данные на уровне кампуса, чтобы понять, какие местоположения растут.
- Используйте отчёты на уровне группы для последующих действий с [группами](../groups/group-members.md), которые показывают снижение посещаемости.
- Объедините результаты посещаемости с инструментом [Поиск ИИ](../people/ai-search.md), чтобы найти людей, которые недавно не посещали.
