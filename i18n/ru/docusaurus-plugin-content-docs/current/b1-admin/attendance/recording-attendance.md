# Запись посещаемости

<div class="article-intro">

После того как настроены кампусы, время служений и группы, вы можете вручную фиксировать посещаемость после каждого собрания. B1 Admin организует посещаемость вокруг **сессий** — одна сессия на одну группу на одну дату встречи. Вы создаете сессию, отмечаете, кто пришел, и данные напрямую попадают в ваши отчеты о посещаемости.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Ваши кампусы, время служений и группы должны быть настроены. См. [Настройка посещаемости](setup.md), если вы еще не сделали этого.
- Для групп, посещаемость которых вы хотите отслеживать, должна быть включена опция **Track Attendance**. Подробности см. в [Настройка посещаемости](setup.md).

</div>

## Создание сессии

Сессия представляет собой одно проведение встречи группы — например, занятие вашего класса K–3 в определенное воскресенье.

1. Откройте **B1 Admin**, откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), разверните **People** и нажмите **Groups**.
2. Выберите группу, для которой хотите записать посещаемость.
3. В разделе **Sessions** на странице группы нажмите **All sessions**.
4. Нажмите **New**, чтобы создать новую сессию.
5. Если группе назначено время служения, выберите **Service Time**. Если группа не привязана к расписанию, это поле не появится.
6. Выберите **Session Date** — это может быть сегодня, прошедшая или будущая дата.
7. Нажмите **Save**.

### Добавление сессий для всех классов в time служения

Если в одно и то же время служения собираются другие группы (например, все классы детей в воскресенье в 9:00), вы можете создать их сессии за один шаг, не заходя в каждую группу отдельно.

1. Выполните описанные выше шаги и выберите **Service Time**.
2. Установите флажок **Also add for the other _N_ groups in _service time_**. Флажок показывает, сколько других групп назначено на это время служения. Он появляется только при добавлении новой сессии и только если хотя бы одна другая группа собирается в это время.
3. Нажмите **Save**.

Сессия создается для текущей группы и для каждой из остальных групп на ту же дату и время служения. Группы, у которых уже есть сессия на эту дату и время служения, пропускаются, поэтому дубликатов не появится.

:::tip
Вы можете создавать сессии для прошедших дат, чтобы наверстать посещаемость, которую вы еще не записали, или создавать их заранее, чтобы они были готовы к встрече группы.
:::

## Отметка посещаемости

Выберите сессию, чтобы увидеть список посещаемости. Каждый участник группы указан с флажком; список отсортирован по фамилии, а те, кто уже отмечен как присутствующие, помечены галочкой.

1. Установите флажок напротив каждого, кто пришел. Используйте **Select All** или **Select None**, чтобы изменить отметки у всех сразу.
2. Счетчик над списком (например, «12 of 15 present») обновляется по мере установки флажков.
3. Нажмите **Save Attendance**. Ничего не записывается, пока вы не сохраните, а сообщение подтверждает завершение сохранения.

Если снять отметку с человека, который уже был записан как присутствующий, и сохранить, он будет удален из сессии.

### Добавление гостей

Чтобы записать человека, который не является участником группы, найдите его через поиск людей рядом со списком посещаемости. Если его еще нет в вашей базе данных, вы можете создать его прямо из поиска. В любом случае он добавляется в список уже отмеченным. Нажмите **Save Attendance**, чтобы записать его.

Люди, которые зарегистрировались на киоске, отображаются с меткой **Volunteer** или **Guest**. Люди, которые не являются участниками группы, отображаются с меткой **Guest**.

## Проверка групп, которым еще нужно внести посещаемость

Когда в одно и то же время служения собираются несколько классов, вы можете одним взглядом увидеть, какие из них еще не внесли посещаемость на эту дату.

1. Откройте сессию, для которой указано время служения.
2. Нажмите **Who Still Needs Attendance** вверху списка посещаемости.
3. Появится диалог со всеми группами, назначенными на это время служения, а вверху — сводка, например «5 of 8 groups entered».

Группы, на которых никто не отмечен как присутствующий на эту дату, показываются с меткой **Not entered** и выводятся первыми. Группы, для которых посещаемость уже есть, показываются с меткой **Entered** и количеством отмеченных присутствующих (например, «Entered (12)»). Нажмите на название группы, чтобы открыть сессии этой группы с уже выбранной сессией на ту же дату, и сразу внести её посещаемость. Если у группы еще нет сессии на эту дату, откроется список её сессий, где можно добавить новую.

:::tip
Сочетайте это с **Print All Classes** и [добавлением сессий для всех классов времени служения](#adding-sessions-for-every-class-in-a-service-time): создайте сессии, раздайте ведомости переклички, а затем используйте **Who Still Needs Attendance**, чтобы увидеть, какие ведомости еще не внесены.
:::

## Печать ведомости переклички

Ведомость переклички — это распечатываемый список класса, который учителя могут отметить от руки и вернуть вам, чтобы вы внесли данные позже. На каждом листе отображается логотип вашей церкви (**Light Background Logo** из раздела [Website > Appearance](../website/appearance.md), если вы его загрузили) с названием церкви под ним, название класса, крупная строка **Date** под названием класса и время служения. Участники перечислены в две колонки (читайте сверху вниз сначала левую колонку, затем правую), чтобы на странице поместилось больше имен, и у каждого участника есть флажки **Present** и **Absent**. Есть пустые строки для гостей и область **Teacher / Notes**.

- **Из сессии** — Нажмите значок **Print Roll Sheet** (принтер) вверху списка посещаемости сессии. Ведомость будет датирована датой сессии.
- **Все классы для служения** — Если у сессии указано время служения, нажмите **Print All Classes**, чтобы распечатать по одной ведомости для каждого класса, назначенного на это время служения. Каждый класс печатается на отдельной странице.
- **Из списка участников** — На странице группы нажмите **All members**, затем нажмите значок **Print Roll Sheet** над списком участников и выберите **Attendance Sheet**, чтобы распечатать ведомость без даты. В том же меню есть макет **Contact Roster** с телефоном, электронной почтой и адресом каждого участника — см. [Печать списка участников](../groups/group-members.md#printing-the-member-list).

Лист открывается в новой вкладке, и автоматически появляется диалог печати вашего браузера.

## Экспорт посещаемости в таблицу

Вы можете скачать запись сессии в виде CSV-файла для использования в Excel, Numbers или Google Sheets.

1. Откройте сессию, которую хотите экспортировать.
2. Нажмите кнопку **Export** вверху списка посещаемости.
3. Откройте скачанный файл в вашем приложении для работы с таблицами.

## Просмотр записанной посещаемости

После записи сессий данные появляются в ваших отчетах о посещаемости.

- **Вкладка Attendance Trend** (в разделе **All years** на странице Attendance) — показывает общецерковные тенденции во времени. См. [Отслеживание посещаемости](tracking-attendance.md).
- **Вкладка Group Attendance** — показывает посещаемость с разбивкой по отдельным группам. См. [Отчеты о посещаемости](../reports/attendance-reports.md#group-attendance).

:::tip
Если сессия, которую вы только что создали, не появляется в отчетах сразу, убедитесь, что дата сессии входит в диапазон дат, выбранный в фильтрах отчета.
:::
