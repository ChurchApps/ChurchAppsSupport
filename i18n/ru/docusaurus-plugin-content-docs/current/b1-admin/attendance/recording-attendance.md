# Запись посещаемости

<div class="article-intro">

Когда ваши кампусы, время служений и группы настроены, вы можете вручную записывать посещаемость после каждого собрания. B1 Admin организует посещаемость вокруг **занятий** -- одно занятие на группу на каждую дату встречи. Вы создаете занятие, отмечаете, кто пришел, и данные сразу попадают в отчеты о посещаемости.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Ваши кампусы, время служений и группы должны быть настроены. Если вы еще этого не сделали, см. [Настройка посещаемости](setup.md).
- Для групп, которые вы хотите отслеживать, должна быть включена опция **Отслеживать посещаемость**. Подробности см. в разделе [Настройка посещаемости](setup.md).
- Для сохранения посещаемости нужно разрешение **Редактировать посещаемость**. Волонтеры, у которых есть только разрешение **Просмотр только имен людей** для людей, тоже могут вести посещаемость таким способом -- они открывают классы из раздела **Группы** и видят участников только по именам. См. [Только имена людей](../settings/roles-permissions.md#people-names-only).

</div>

## Создание занятия

Занятие представляет одно собрание группы -- например, класс для учеников с 1 по 3 класс на конкретное воскресенье.

1. Откройте **B1 Admin**, откройте [меню перехода](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), раскройте **Люди** и нажмите **Группы**.
2. Выберите группу, для которой хотите записать посещаемость.
3. В разделе **Занятия** на странице группы нажмите **Все занятия**.
4. Нажмите **Создать**, чтобы создать новое занятие.
5. Если группа закреплена за временем служения, выберите **Время служения**. Если группа не привязана к расписанию, это поле не появится.
6. Выберите **Дату занятия** -- это может быть сегодня, прошедшая или будущая дата.
7. Нажмите **Сохранить**.

### Добавление занятий для всех классов в одном времени служения

Если другие группы собираются в то же время служения (например, все детские классы в воскресенье в 9:00), можно создать для них занятия одним действием, не заходя в каждую группу.

1. Выполните шаги выше и выберите **Время служения**.
2. Отметьте флажок **Также добавить для других групп (_N_) в _времени служения_**. В флажке указано, сколько других групп закреплено за этим временем служения. Он появляется только при создании нового занятия и если хотя бы еще одна группа собирается в это время.
3. Нажмите **Сохранить**.

Занятие создается для текущей группы и для каждой из остальных групп на ту же дату и время служения. Группы, у которых уже есть занятие на эту дату и время служения, пропускаются, поэтому дубликатов не будет.

:::tip
Вы можете создавать занятия на прошедшие даты, чтобы наверстать посещаемость, которую еще не записали, или создавать их заранее, чтобы они были готовы к собранию группы.
:::

## Заметки к занятию {#session-notes}

К каждому занятию можно добавить заметки -- краткое описание пройденного материала, объявления или молитвенные просьбы.

1. При добавлении занятия или после нажатия значка **Редактировать** (карандаш) рядом с занятием в списке введите текст в поле **Заметки (что было пройдено, объявления, молитвенные просьбы)** под датой. На панели инструментов есть полужирный текст, списки и ссылки.
2. Нажмите **Сохранить**.

Заметки отображаются вверху списка посещаемости занятия. Это также заметки о собрании, которые участники группы читают в разделе **Собрания** на странице группы в B1.church, где руководители групп тоже могут их писать и редактировать. См. [Детали группы](../../b1-church/groups/group-details.md#meeting-notes-and-attendance).

## Отметка посещаемости

Выберите занятие, чтобы увидеть список посещаемости. Каждый участник группы указан с флажком, список отсортирован по фамилии, а те, кто уже отмечен как присутствующие, отмечены галочкой.

1. Отметьте флажок напротив каждого, кто пришел. Используйте **Выбрать всех** или **Снять выбор со всех**, чтобы изменить сразу всех.
2. Счетчик над списком (например, «12 из 15 присутствуют») обновляется по мере того, как вы ставите отметки.
3. Нажмите **Сохранить посещаемость**. Ничего не записывается, пока вы не сохраните, и сообщение подтверждает, когда сохранение завершено. Если вы попытаетесь закрыть или перезагрузить вкладку браузера, пока сохранение еще выполняется, браузер сначала предупредит вас, чтобы изменения не потерялись.

Если снять отметку с человека, который уже был записан как присутствующий, и сохранить, он будет удален из занятия.

### Добавление гостей

Чтобы записать человека, который не является участником группы, найдите его через поиск людей рядом со списком посещаемости. Если его еще нет в вашей базе данных, его можно создать прямо из поиска. В любом случае он добавляется в список уже отмеченным. Нажмите **Сохранить посещаемость**, чтобы записать его.

Люди, которые зарегистрировались на киоске, отображаются с меткой **Волонтер** или **Гость**. Люди, которые не являются участниками группы, отображаются с меткой **Гость**.

## Проверка, каким группам еще нужно внести посещаемость

Когда в одно время служения собирается несколько классов, можно сразу увидеть, в каких из них еще нужно внести посещаемость на эту дату.

1. Откройте занятие, для которого указано время служения.
2. Нажмите **Кто еще не отмечен** вверху списка посещаемости.
3. В диалоге появится список всех групп, закрепленных за этим временем служения, а вверху будет сводка, например «Внесено для 5 из 8 групп».

Группы, в которых на эту дату никто не отмечен присутствующим, показаны с меткой **Не внесено** и идут первыми в списке. Группы, для которых посещаемость есть, отображаются с меткой **Внесено** и количеством присутствующих (например, «Внесено (12)»). Нажмите название группы, чтобы открыть ее занятия с уже выбранным занятием на ту же дату, и сразу внести посещаемость. Если у группы еще нет занятия на эту дату, откроется список ее занятий, где его можно добавить.

:::tip
Сочетайте это с **Распечатать все классы** и [добавлением занятий для всех классов в одном времени служения](#adding-sessions-for-every-class-in-a-service-time): создайте занятия, раздайте листы переклички, а затем используйте **Кто еще не отмечен**, чтобы увидеть, какие листы еще не внесены.
:::

## Печать листа переклички

Лист переклички -- это печатный список класса, который учителя могут отмечать от руки и отдавать вам, чтобы вы внесли данные позже. Каждый лист показывает логотип вашей церкви (**Логотип для светлого фона** из раздела [Сайт > Внешний вид](../website/appearance.md), если вы его загрузили) с названием церкви под ним, класс, большую строку **Дата** под названием класса и время служения. Участники указаны в две колонки (читаем сначала левую колонку, затем правую), чтобы на странице помещалось больше имен, и у каждого участника есть флажки **Присутствует** и **Отсутствует**. Есть пустые строки для гостей и область **Учитель / Заметки**.

- **Из занятия** -- нажмите значок **Печать листа переклички** (принтер) вверху списка посещаемости занятия. Лист будет датирован датой занятия.
- **Все классы для служения** -- если у занятия есть время служения, нажмите **Распечатать все классы**, чтобы напечатать по одному листу для каждого класса, закрепленного за этим временем служения. Каждый класс печатается на отдельной странице.
- **Из списка участников** -- на странице группы нажмите **«Все участники»**, затем значок **Печать листа переклички** над списком участников и выберите **Лист посещаемости**, чтобы напечатать лист без даты. В том же меню есть макет **Список контактов** с телефоном, email и адресом каждого участника -- см. [Печать списка участников](../groups/group-members.md#printing-the-member-list).

Лист открывается в новой вкладке, и автоматически появляется диалог печати браузера.

## Экспорт посещаемости в таблицу

Вы можете скачать запись о занятии в виде файла CSV, чтобы открыть его в Excel, Numbers или Google Таблицах.

1. Откройте занятие, которое хотите экспортировать.
2. Нажмите кнопку **Экспорт** вверху списка посещаемости.
3. Откройте скачанный файл в программе для работы с таблицами.

## Просмотр записанной посещаемости

После записи занятий данные появляются в ваших отчетах о посещаемости.

- **Вкладка «Динамика посещаемости»** (в разделе **Все годы** на странице «Посещаемость») -- показывает общую динамику по церкви за время. См. [Отслеживание посещаемости](tracking-attendance.md).
- **Вкладка «Посещаемость групп»** -- показывает посещаемость с разбивкой по отдельным группам. См. [Отчеты о посещаемости](../reports/attendance-reports.md#group-attendance).

:::tip
Если только что созданное занятие сразу не появляется в отчетах, убедитесь, что дата занятия попадает в диапазон дат, выбранный в фильтрах отчета.
:::
