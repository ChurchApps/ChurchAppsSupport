# Запись посещаемости

<div class="article-intro">

После установки ваших кампусов, времени служений и групп вы можете вручную записывать посещаемость после каждого собрания. B1 Admin организует посещаемость вокруг **сеансов** -- один сеанс на группу на дату встречи. Вы создаёте сеанс, отмечаете, кто пришёл, и данные поступают непосредственно в ваши отчёты посещаемости.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Ваши кампусы, время служений и группы должны быть настроены. Если вы этого ещё не сделали, см. [Настройка посещаемости](setup.md).
- Группы, которые вы хотите отслеживать, должны иметь включённую опцию **Отслеживать посещаемость**. Подробности см. в разделе [Настройка посещаемости](setup.md).

</div>

## Создание сеанса

Сеанс представляет один случай встречи группы -- например, ваш класс K--3 класса в конкретное воскресенье.

1. Откройте **B1 Admin**, откройте **меню раздела** в верхнем левом углу и выберите **Люди**, затем нажмите вкладку **Группы**.
2. Выберите группу, для которой вы хотите записать посещаемость.
3. Нажмите вкладку **Сеансы**.
4. Нажмите **Новый**, чтобы создать новый сеанс.
5. Если группа назначена на время служения, выберите **Время служения**. Если это неплановая группа, это поле не будет отображаться.
6. Выберите **Дату сеанса** -- это может быть сегодня, прошлая дата или будущая дата.
7. Нажмите **Сохранить**.

:::tip
Вы можете создавать сеансы на прошлые даты, чтобы наверстать упущенную посещаемость, которую вы не записали, или создавать их заранее, чтобы они были готовы, когда встречается ваша группа.
:::

## Отмечание посещаемости

Выберите сеанс, чтобы увидеть его список посещаемости. Каждый член группы указан с флажком, отсортирован по фамилии, и все, уже записанные как присутствующие, отмечены.

1. Отметьте поле рядом с каждым человеком, который присутствовал. Используйте **Выбрать всех** или **Не выбирать никого**, чтобы изменить всех сразу.
2. Счёт выше списка (например, "12 из 15 присутствуют") обновляется при отметке полей.
3. Нажмите **Сохранить посещаемость**. Ничего не записывается до сохранения, и появляется сообщение, подтверждающее завершение сохранения.

Снятие флажка с человека, который уже был записан как присутствующий, а затем сохранение удаляет его из сеанса.

### Добавление посетителей

Чтобы записать человека, который не является членом группы, выполните поиск в поле поиска рядом со списком посещаемости. Если их ещё нет в вашей базе данных, вы можете создать их из поиска. Они добавляются в список уже отмеченные. Нажмите **Сохранить посещаемость**, чтобы их записать.

Люди, которые зарегистрировались в киоске, показывают фишку **Добровольец** или **Гость**. Люди, которые не являются членами группы, показывают фишку **Гость**.

## Печать листа посещаемости

Лист посещаемости - это печатный список класса, который учителя могут отметить от руки и вернуть вам для последующего ввода. На каждом листе указано имя церкви, класс, время служения и дата. Каждый член имеет поля **Присутствует** и **Отсутствует**, а также есть пустые строки для посетителей и область **Учитель / Заметки**.

- **Из сеанса** -- Нажмите значок **Печать листа посещаемости** (принтер) в верхней части списка посещаемости сеанса. Лист датирован датой сеанса.
- **Все классы для служения** -- Если сеанс имеет время служения, нажмите **Печать всех классов**, чтобы распечатать один лист для каждого класса, назначенного этому времени служения. Каждый класс печатается на своей странице.
- **Со вкладки "Члены"** -- Нажмите значок **Печать листа посещаемости** над списком членов группы, чтобы распечатать недатированный лист.

Лист откроется в новой вкладке, и диалог печати вашего браузера появится автоматически.

## Экспорт посещаемости в электронную таблицу

Вы можете загрузить запись сеанса в виде файла CSV для использования в Excel, Numbers или Google Sheets.

1. Откройте сеанс, который вы хотите экспортировать.
2. Нажмите кнопку **Экспорт** в верхней части списка посещаемости.
3. Откройте загруженный файл в приложении электронной таблицы.

## Просмотр записанной посещаемости

После записи сеансов данные появляются в ваших отчётах посещаемости.

- **Вкладка "Тенденция посещаемости"** -- показывает тенденции по церкви во времени. См. [Отслеживание посещаемости](tracking-attendance.md).
- **Вкладка "Посещаемость группы"** -- показывает посещаемость разбитую по отдельным группам.

:::tip
Если сеанс, который вы только что создали, не появляется в отчётах сразу, убедитесь, что дата сеанса находится в пределах диапазона дат, выбранного в фильтрах отчёта.
:::
