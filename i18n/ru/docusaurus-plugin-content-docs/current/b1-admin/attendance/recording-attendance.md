# Запись посещаемости

<div class="article-intro">

После настройки приходов, времён богослужений и групп вы можете вручную записывать посещаемость после каждого собрания. B1 Admin организует посещаемость вокруг **сеансов** — один сеанс на группу на дату встречи. Вы создаёте сеанс, отмечаете, кто явился, и данные поступают непосредственно в отчёты посещаемости.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Ваши приходы, времена богослужений и группы должны быть настроены. Если вы этого ещё не сделали, см. [Настройка посещаемости](setup.md).
- Группы, которые вы хотите отслеживать, должны иметь включённый **Track Attendance**. Подробности см. в [Настройка посещаемости](setup.md).

</div>

## Создание сеанса

Сеанс представляет один случай встречи группы — например, ваш класс K–3-го класса в определённое воскресенье.

1. Откройте **B1 Admin**, откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **People** и щелкните **Groups**.
2. Выберите группу, для которой вы хотите записать посещаемость.
3. Нажмите вкладку **Sessions**.
4. Нажмите **New**, чтобы создать новый сеанс.
5. Если группа назначена времени богослужения, выберите **Service Time**. Если это незапланированная группа, это поле не появится.
6. Выберите **Session Date** — это может быть сегодня, прошедшая дата или будущая дата.
7. Нажмите **Save**.

### Добавление сеансов для всех классов во время богослужения

Если другие группы встречаются в одно и то же время богослужения (например, все ваши классы для детей в воскресенье в 9:00 утра), вы можете создать их сеансы за один шаг вместо посещения каждой группы.

1. Следуйте приведённым выше шагам и выберите **Service Time**.
2. Установите флажок **Also add for the other _N_ groups in _service time_**. Флажок показывает, сколько других групп назначено этому времени богослужения. Он появляется только при добавлении нового сеанса и когда по крайней мере одна другая группа встречается в это время.
3. Нажмите **Save**.

Сеанс создаётся для текущей группы и для каждой из других групп в одну и ту же дату и время богослужения. Группы, которые уже имеют сеанс на эту дату и время богослужения, пропускаются, поэтому вы не получите дубликаты.

:::tip
Вы можете создавать сеансы на прошедшие даты, чтобы наверстать пропущенную посещаемость, которую вы ещё не записали, или создавать их заранее, чтобы они были готовы, когда встречается ваша группа.
:::

## Отметка посещаемости

Выберите сеанс, чтобы увидеть его список посещаемости. Каждый член группы внесен в список с флажком, отсортирован по фамилии, и любой, кто уже зарегистрирован как присутствующий, отмечен.

1. Установите флажок рядом с каждым человеком, который присутствовал. Используйте **Select All** или **Select None**, чтобы изменить всех одновременно.
2. Счёт выше списка (например, «12 из 15 присутствуют») обновляется по мере установки флажков.
3. Нажмите **Save Attendance**. Ничего не записывается до сохранения, и сообщение подтверждает, когда сохранение завершено.

Снятие флажка с кого-либо, кто уже был зарегистрирован как присутствующий, а затем сохранение удаляет его из сеанса.

### Добавление посетителей

Чтобы записать того, кто не является членом группы, найдите его в поле поиска человека рядом со списком посещаемости. Если их ещё нет в вашей базе данных, вы можете создать их с помощью поиска. Они добавляются в список уже отмеченными. Нажмите **Save Attendance**, чтобы записать их.

Люди, которые зарегистрировались на киоске, показывают чип **Volunteer** или **Guest**. Люди, которые не являются членами группы, показывают чип **Guest**.

## Проверка того, какие группы всё ещё нуждаются в посещаемости

Когда несколько классов встречаются в одно и то же время богослужения, вы можете сразу увидеть, какие из них всё ещё нуждаются в вводе посещаемости на эту дату.

1. Откройте сеанс, который имеет время богослужения.
2. Нажмите **Who Still Needs Attendance** в верхней части списка посещаемости.
3. Диалог содержит все группы, назначенные этому времени богослужения, с резюме, таким как «5 из 8 групп введены» в верхней части.

Группы, у которых никто не отмечен как присутствующий на эту дату, показывают чип **Not entered** и перечислены первыми. Группы, у которых есть посещаемость, показывают **Entered** с числом людей, отмеченных как присутствующие (например, «Entered (12)»). Щелкните имя группы, чтобы перейти к этой группе и записать её посещаемость.

:::tip
Сочетайте это с **Print All Classes** и [добавлением сеансов для всех классов в течение времени богослужения](#adding-sessions-for-every-class-in-a-service-time): создайте сеансы, раздайте листы посещаемости, затем используйте **Who Still Needs Attendance**, чтобы увидеть, какие листы ещё не введены.
:::

## Печать листа посещаемости

Лист посещаемости — это печатный список класса, который учителя могут отметить вручную и отдать вам для последующего ввода. На каждом листе указаны название церкви, класс, большая строка **Date** под названием класса и время богослужения. Члены перечислены в две колонки (читайте вниз левую колонку, затем правую), чтобы больше имён поместилось на одну страницу, и каждый член имеет поля **Present** и **Absent**. Существуют пустые строки для посетителей и область **Teacher / Notes**.

- **From a session** — нажмите значок **Print Roll Sheet** (принтер) в верхней части списка посещаемости сеанса. Лист датирован датой сеанса.
- **All classes for a service** — если сеанс имеет время богослужения, нажмите **Print All Classes**, чтобы распечатать один лист на класс, назначенный этому времени богослужения. Каждый класс печатается на отдельной странице.
- **From the Members tab** — нажмите значок **Print Roll Sheet** над списком членов группы, чтобы распечатать неподписанный лист.

Лист открывается на новой вкладке и диалог печати вашего браузера появляется автоматически.

## Экспорт посещаемости в таблицу

Вы можете скачать запись сеанса в виде CSV-файла для использования в Excel, Numbers или Google Sheets.

1. Откройте сеанс, который вы хотите экспортировать.
2. Нажмите кнопку **Export** в верхней части списка посещаемости.
3. Откройте загруженный файл в приложении электронной таблицы.

## Просмотр записанной посещаемости

После записи сеансов данные появляются в отчётах посещаемости.

- **Attendance Trend tab** — показывает тенденции по всей церкви с течением времени. См. [Tracking Attendance](tracking-attendance.md).
- **Group Attendance tab** — показывает посещаемость по отдельной группе. См. [Attendance Reports](../reports/attendance-reports.md#group-attendance).

:::tip
Если сеанс, который вы только что создали, не появляется в отчётах сразу же, убедитесь, что дата сеанса находится в пределах диапазона дат, выбранного в фильтрах отчёта.
:::
