# Учёт посещаемости и тенденция

<div class="article-intro">

Учёт посещаемости позволяет записывать простое общее число посещения — для богослужения, времени богослужения или группы — без проверки именованного списка. Используйте это, когда вам просто нужно узнать «сколько людей было здесь», и сочетайте его с отчётом о тенденции учёта посещаемости, чтобы отслеживать это число с течением времени.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Ваши приходы, богослужения и времена богослужений должны быть настроены. См. [Настройка посещаемости](setup.md).
- Введение учёта посещаемости требует разрешения **Attendance > Edit**; просмотр отчёта о тенденции требует **Attendance > View**. См. [Roles & Permissions](../settings/roles-permissions.md).

</div>

:::info
Учёты посещаемости — это альтернатива только для итогов [Recording Attendance](recording-attendance.md). Если вам нужно знать **кто** посетил — например, чтобы связаться с людьми, которые не вернулись — продолжайте использовать именованное посещение сеансов в разделе Sessions группы. Учёты посещаемости хранят только число.
:::

## Запись учёта посещаемости

1. Откройте **B1 Admin**, откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **People** и щелкните **Attendance**.
2. Нажмите **Enter headcount** в левой колонке.
3. Заполните форму:
   - **Service** *(required)*
   - **Service Time** — оставьте пустым, чтобы записать итог по всем временам богослужений
   - **Group** — дополнительный; перечислены только группы с включённым отслеживанием посещаемости. Оставьте пустым для «No group (whole service)».
   - **Date**
   - **Headcount** — общее количество присутствующих людей
4. Нажмите **Save**.

Таблица **Recent Headcounts** рядом с формой содержит ваши последние несколько записей с их датой, богослужением, временем богослужения, группой и количеством. Щелкните на строке, чтобы загрузить её обратно в форму, если вам нужно исправить или удалить её.

## Отчёт о тенденции учёта посещаемости

1. На той же странице **Attendance** нажмите **All years** в левой колонке, затем выберите вкладку **Headcount Trend**.
2. Используйте фильтры **Campus**, **Service**, **Service Time** и **Group**, чтобы сузить отчёт.

Отчёт показывает ваши записанные учёты посещаемости, суммированные по неделям, как в виде графика, так и в виде таблицы — тот же стиль отчёта, используемый [вкладками Attendance Trend и Group Attendance](tracking-attendance.md). Учёты посещаемости, внесённые за текущую неделю, также отображаются в разделе **Headcounts this week** на главной странице Attendance.
