# Запись учета посещаемости и тренды

<div class="article-intro">

Подсчет посещаемости позволяет записать простое общее число присутствующих — для службы, времени службы или группы — без регистрации поименного списка. Используйте это, когда вам просто нужно узнать "сколько людей здесь было", и сочетайте это с отчетом о тренде посещаемости, чтобы отслеживать это число во времени.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Ваши кампусы, службы и время служб должны быть настроены. См. [Настройка посещаемости](setup.md).
- Для ввода подсчета посещаемости требуется разрешение **Посещаемость > Редактирование**; для просмотра отчета о тренде требуется **Посещаемость > Просмотр**. См. [Роли и разрешения](../settings/roles-permissions.md).

</div>

:::info
Подсчет посещаемости — это альтернатива только для итогов [Записи посещаемости](recording-attendance.md). Если вам нужно знать **кто** присутствовал — например, чтобы связаться с людьми, которые давно не приходили — продолжайте использовать именованную посещаемость сеанса на вкладке "Сеансы" группы. Подсчет посещаемости хранит только число.
:::

## Запись подсчета посещаемости

1. Откройте **B1 Admin**, откройте **меню раздела** в верхнем левом углу и выберите **Люди**, затем нажмите вкладку **Посещаемость**.
2. Выберите подвкладку **Подсчет посещаемости**.
3. Заполните форму:
   - **Служба** *(обязательно)*
   - **Время службы** — оставьте пусто, чтобы записать итог по всем временам служб
   - **Группа** — опционально; перечислены только группы с включенным отслеживанием посещаемости. Оставьте пусто для "Нет группы (вся служба)".
   - **Дата**
   - **Подсчет посещаемости** — общее число присутствующих людей
4. Нажмите **Сохранить**.

Таблица **Последние подсчеты посещаемости** справа показывает ваши последние записи с датой, службой, временем службы, группой и количеством. Щелкните строку, чтобы загрузить ее обратно в форму, если вам нужно исправить или удалить ее.

## Отчет о тренде посещаемости

1. На той же вкладке **Посещаемость** выберите подвкладку **Тренд посещаемости**.
2. Используйте фильтры **Кампус**, **Служба**, **Время службы** и **Группа**, чтобы сузить отчет.

Отчет показывает ваши записанные подсчеты посещаемости, суммированные по неделям, как в виде графика линий, так и в виде таблицы — тот же стиль отчета, используемый вкладками [Тренды посещаемости и групп](tracking-attendance.md).
