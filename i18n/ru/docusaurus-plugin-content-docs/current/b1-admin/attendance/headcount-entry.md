# Ввод количества присутствующих и тренд

<div class="article-intro">

Количество присутствующих позволяет записать простое общее число посещаемости — для службы, времени службы или группы — без отметки именного списка. Используйте это, когда нужно знать только «сколько людей было», и сочетайте с отчетом Headcount Trend, чтобы следить за этим числом во времени.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Ваши кампусы, службы и времена служб должны быть настроены. См. [Настройку посещаемости](setup.md).
- Для ввода количества присутствующих требуется право **Attendance &gt; Edit**; для просмотра отчета о тренде требуется **Attendance &gt; View**. См. [Роли и права доступа](../settings/roles-permissions.md).

</div>

:::info
Количество присутствующих — это альтернатива [Записи посещаемости](recording-attendance.md) только с общим итогом. Если нужно знать, **кто** присутствовал, — например, чтобы связаться с людьми, которые давно не приходили, — продолжайте использовать именную посещаемость занятий в разделе Sessions группы. Количество присутствующих хранит только число.
:::

## Запись количества присутствующих {#recording-a-headcount}

1. Откройте **B1 Admin**, откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), раскройте **People** и нажмите **Attendance**.
2. Нажмите **Enter headcount** в левой колонке.
3. Заполните форму:
   - **Service** *(обязательно)*
   - **Service Time** — оставьте значение **All service times**, чтобы записать общий итог по всем временам службы
   - **Group** — необязательно; в списке только группы с включенным Track Attendance. Оставьте пустым для значения «No group (whole service)».
   - **Date**
   - **Headcount** — общее число присутствующих (целое число, 0 или больше)
4. Нажмите **Save**.

Таблица **Recent Headcounts** рядом с формой показывает последние записи с датой, службой, временем службы, группой и количеством. Нажмите на строку, чтобы загрузить ее обратно в форму, если нужно исправить или удалить запись.

## Отчет Headcount Trend {#headcount-trend-report}

1. На той же странице **Attendance** нажмите **All years** в левой колонке, затем выберите вкладку **Headcount Trend**.
2. Отчет формируется при открытии вкладки. Чтобы сузить выборку, выберите **Campus**, **Service**, **Service Time** или **Group** и нажмите **Run Report**. Фильтра по дате нет — отчет охватывает каждую неделю, для которой есть количество присутствующих.

В отчете отображаются записанные количества присутствующих, сложенные по неделям, в виде линейного графика и таблицы — в том же стиле, что и [вкладки Attendance Trend и Group Attendance](tracking-attendance.md). Количества, введенные за текущую неделю, также появляются в разделе **Headcounts this week** на главной странице Attendance.
