# Посещаемость

<div class="article-intro">

Раздел Attendance в B1 Admin дает полную картину того, кто приходит в вашу общину и как растут ваши группы со временем. От настройки кампусов и времен служб до просмотра трендов и настройки самостоятельной регистрации — все, что нужно для отслеживания и понимания посещаемости, управляется с этой страницы.

</div>

## Обзор страницы {#page-overview}

Чтобы открыть страницу, откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), раскройте **People** и нажмите **Attendance**. Страница открывается сводкой за **эту неделю** (с воскресенья по субботу).

В левой колонке показаны даты недели и общее число людей **в помещении** — ваш итог количества присутствующих, если они вводились на этой неделе, а иначе — число зарегистрированных людей. Под итогом вы увидите, сколько человек зарегистрировалось, было посчитано и сколько было гостей, а также разбивку по службам, если их больше одной. Если на этой неделе еще никто не зарегистрировался, это указано, и показывается последняя дата, на которую была записана посещаемость (например, «Last recorded Jan 25, 2026: 10»).

Основная область страницы показывает:

- **Rooms** — каждую группу, в которую люди регистрировались на этой неделе, с количеством зарегистрированных (и полосой заполненности для групп с вместимостью регистрации). Нажмите на группу, чтобы ее открыть.
- **Guests** — людей, которые на этой неделе зарегистрировались как гости. Нажмите на имя, чтобы открыть их карточку.
- **Last 13 weeks** — небольшой столбчатый график еженедельных регистраций и количество недель, в которые были регистрации. Ссылка **All years** открывает отчеты.
- **Headcounts this week** — количество присутствующих, введенное для служб этой недели.

## Действия {#actions}

В левой колонке также находятся действия страницы. Каждое открывается в основной области; нажмите ссылку возврата **Attendance**, чтобы вернуться к еженедельной сводке.

### Setup {#setup}

Нажмите **Setup**, чтобы настроить основные элементы учета посещаемости (он появляется только для людей с правом посещаемости **Edit Services**). Здесь вы определяете кампусы, добавляете службы и времена служб к каждому кампусу (включая необязательное расписание регистрации для каждого времени службы) и видите, какие [группы](../groups/creating-groups.md) назначены на эти времена служб. Вверху отображаются счетчики кампусов, времен служб, групп с расписанием и без него, а также общее количество групп. Это нужно сделать один раз, но вы можете обновлять настройки при каждом изменении расписания. Полное пошаговое руководство см. в разделе [Настройка посещаемости](setup.md).

### All years (Reports) {#all-years-reports}

Нажмите **All years**, чтобы открыть отчеты о посещаемости. Вкладки вверху переключают **Attendance Trend** (общецерковые тренды во времени), **Headcount Trend** (итоги количества присутствующих по неделям) и **Group Attendance** (посещаемость, разбитая по отдельным группам). Используйте фильтры, чтобы сузить результаты по диапазону дат, кампусу или времени службы. Подробнее об использовании отчетов и фильтров см. в разделе [Отслеживание посещаемости](tracking-attendance.md).

### Enter headcount {#enter-headcount}

Нажмите **Enter headcount**, чтобы записать простой общий итог для службы, времени службы или группы вместо именного списка. Подробности см. в разделе [Ввод количества присутствующих и тренд](headcount-entry.md).

### Kiosk {#kiosk}

Нажмите **Kiosk**, чтобы открыть настройки **Kiosk Theme**, где задается фоновое изображение киоска регистрации и экран ожидания. Ссылка **Check-in kiosk, QR, and labels** ведет к полным [настройкам B1 CheckIn](check-in.md), которые также охватывают регистрацию гостей по QR-коду и [конструктор этикеток](labels.md). Цвета киоска берутся из **Mobile > App Theme**.
