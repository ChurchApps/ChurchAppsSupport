# Посещаемость

<div class="article-intro">

Раздел "Посещаемость" в B1 Admin дает вам полное представление о том, кто приходит в вашу церковь и как растут ваши группы с течением времени. От настройки кампусов и времени служений до анализа тенденций и настройки самопроверки - всё, что вам нужно для отслеживания и понимания посещаемости, управляется на этой странице.

</div>

## Обзор страницы

Чтобы открыть страницу, откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **People** и нажмите **Attendance**. Страница открывается сводкой за **эту неделю** (с воскресенья по субботу).

В левой колонке показаны даты недели и общее количество людей **в помещении** — итог учёта численности, если она была введена на этой неделе, в противном случае количество зарегистрировавшихся людей. Под общим итогом видно, сколько человек зарегистрировались, было подсчитано и сколько было гостей, а также разбивка по богослужениям, если их несколько. Если на этой неделе никто ещё не зарегистрировался, показывается последняя неделя, в которой была посещаемость.

В основной части страницы отображаются:

- **Rooms** — каждая группа, в которую регистрировались люди на этой неделе, с количеством зарегистрировавшихся (и полосой вместимости для групп с ограничением вместимости). Нажмите на группу, чтобы открыть её.
- **Guests** — люди, которые зарегистрировались как гости на этой неделе. Нажмите на имя, чтобы открыть их запись.
- **Last 13 weeks** — небольшая столбчатая диаграмма еженедельных регистраций с количеством недель, в которые были регистрации.
- **Headcounts this week** — учёты численности, введённые для богослужений этой недели.

## Действия {#actions}

В левой колонке также находятся действия страницы. Каждое открывается в основной области; нажмите ссылку назад **Attendance**, чтобы вернуться к еженедельной сводке.

### Настройка

Нажмите **Setup**, чтобы настроить основные компоненты отслеживания посещаемости. Здесь вы определяете свои кампусы, добавляете службы и времена богослужений к каждому кампусу (включая необязательное расписание регистрации для каждого времени богослужения) и видите, какие [группы](../groups/creating-groups.md) назначены этим временам богослужений. Количество кампусов, времён богослужений, плановых и неплановых групп и всех групп отображается вверху. Вам нужно сделать это только один раз, хотя вы можете обновить настройки в любой момент, когда изменится ваше расписание. Полное руководство смотрите в разделе [Настройка посещаемости](setup.md).

### All years (Reports) {#all-years-reports}

Нажмите **All years**, чтобы открыть отчёты по посещаемости. Вкладки вверху переключают между **Attendance Trend** (общие тенденции по церкви с течением времени), **Headcount Trend** (итоги учёта численности по неделям) и **Group Attendance** (посещаемость с разбивкой по отдельным группам). Используйте фильтры для сужения результатов по диапазону дат, кампусу или времени богослужения. Подробности об отчётах и фильтрах см. в разделе [Отслеживание посещаемости](tracking-attendance.md).

### Enter headcount {#enter-headcount}

Нажмите **Enter headcount**, чтобы записать простой общий подсчёт для богослужения, времени богослужения или группы вместо именного списка. Подробности см. в разделе [Ввод численности и её тенденция](headcount-entry.md).

### Kiosk {#kiosk}

Нажмите **Kiosk**, чтобы открыть настройки **Kiosk Theme**, где вы задаёте фоновые изображения киоска и поведение экрана ожидания. Ссылка **Check-in kiosk, QR, and labels** ведёт к полным [настройкам B1 CheckIn](check-in.md).
