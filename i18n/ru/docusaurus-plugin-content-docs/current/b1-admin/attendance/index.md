# Посещаемость

<div class="article-intro">

Раздел "Посещаемость" в B1 Admin дает вам полное представление о том, кто приходит в вашу церковь и как растут ваши группы с течением времени. От настройки кампусов и времени служений до анализа тенденций и настройки самопроверки - всё, что вам нужно для отслеживания и понимания посещаемости, управляется на этой странице.

</div>

## Обзор страницы

При открытии страницы "Посещаемость" вы увидите заголовок с ключевой статистикой по настройке посещаемости вашей церкви:

- **Кампусы** - количество физических местоположений, которые вы настроили
- **Время служений** - общее количество служений на всех кампусах
- **Плановые группы** - группы, которые назначены на определённое время служения
- **Неплановые группы** - группы, которые отслеживают посещаемость независимо от времени служения

Ниже заголовка три вкладки организуют ваши инструменты отслеживания посещаемости.

## Вкладки

### Настройка

Вкладка **Настройка** - это место, где вы настраиваете основные компоненты отслеживания посещаемости. Здесь вы определяете свои кампусы, добавляете время служений для каждого кампуса и назначаете [группы](../groups/creating-groups.md) этим временам служений. Вам нужно сделать это только один раз, хотя вы можете обновить это в любой момент, когда изменится ваше расписание. Полное руководство смотрите в разделе [Настройка посещаемости](setup.md).

### Посещаемость

Вкладка **Посещаемость** отображает тенденции посещаемости с течением времени. Используйте фильтры для сужения результатов по диапазону дат, кампусу или времени служения и быстро заметьте закономерности в ваших данных. Подробности об использовании отчётов и фильтров см. в разделе [Отслеживание посещаемости](tracking-attendance.md).

### Группы

Вкладка **Группы** разбивает посещаемость по отдельным группам. Это полезно, когда вы хотите увидеть, как дела у конкретной небольшой группы, класса или служебной команды, вместо того чтобы смотреть на общие цифры по церкви.

### Численность и тенденция численности

Вкладка **Численность** позволяет вам записать простое общее количество для служения, времени служения или группы вместо именного списка, а вкладка **Тенденция численности** отображает эти итоги по неделям. Подробности см. в разделе [Ввод численности и её тенденция](headcount-entry.md).

- [Безопасность при регистрации](checkin-safety.md) -- вместимость помещений, соотношение добровольцев, лица для получения и пейджинг
