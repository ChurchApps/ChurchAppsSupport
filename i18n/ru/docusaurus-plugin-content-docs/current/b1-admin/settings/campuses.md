# Кампусы

<div class="article-intro">

Если ваша церковь встречается в более чем одном месте, **Кампусы** позволяют вам отслеживать, к какому месту принадлежит каждый человек и группа. После настройки кампусы появляются как опция в профилях людей, в настройке посещаемости и на панели демографии. Многолокальные церкви могут фильтровать, искать и составлять отчеты по кампусам по всему B1 Admin.

</div>

<div class="prereqs">
<h4>Перед тем как начать</h4>

- Вам необходимо разрешение **Редактировать параметры церкви** для управления кампусами. См. [Роли и разрешения](./roles-permissions.md).

</div>

## Открытие параметров кампуса

В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), выберите **Параметры > Параметры** и выберите карточку **Кампусы**. Вы также можете перейти прямо туда по адресу **/settings/campuses**. Вы увидите список всех настроенных кампусов с их названием, местоположением и часовым поясом.

## Добавление кампуса

1. Нажмите **Добавить кампус** (или кнопку **+**, если кампусы еще не существуют).
2. Заполните детали кампуса:
   - **Название** *(обязательно)* — отображаемое имя, показываемое по всему B1 Admin (например, "Главный кампус" или "Северный кампус").
   - **Адрес** — адрес улицы кампуса (используется для информационного отображения; не то же самое, что ваш основной адрес церкви в параметрах церкви).
   - **Город / Область / Почтовый индекс** — местоположение кампуса.
   - **Часовой пояс** — часовой пояс IANA для этого кампуса (например, *America/Chicago*). Полезно, когда кампусы находятся в разных часовых поясах.
   - **Веб-сайт** — необязательный URL для собственного веб-присутствия этого кампуса.
3. Нажмите **Сохранить**.

## Редактирование кампуса

Нажмите на любую строку кампуса в списке, чтобы открыть его редактор на панели справа. Обновите поля и нажмите **Сохранить**.

## Удаление кампуса

Откройте кампус для редактирования и нажмите **Удалить**. Вас попросят подтвердить. Удаление кампуса не удаляет назначенных ему людей — их поле кампуса просто становится пустым.

## Назначение людей кампусу

После создания кампусов сотрудники могут назначить человека кампусу из его профиля:

1. Откройте запись человека в **Люди**.
2. Нажмите **Редактировать**.
3. Выберите кампус из раскрывающегося списка **Кампус**.
4. Нажмите **Сохранить**.

Вы также можете обновить кампус массово со страницы Люди. Выберите нескольких человек, используйте **Массовое редактирование** и установите поле Кампус для всех одновременно.

## Фильтрование по кампусу

После настройки кампусов вы можете фильтровать по всему B1 Admin по кампусу:

- **Поиск людей** — добавьте условие Кампус в расширенный поиск или загрузьте [Сохраненный список](../people/lists.md), привязанный к кампусу.
- **Демография** — [панель демографии](../people/demographics.md) показывает круговую диаграмму Кампуса, когда по крайней мере одному человеку назначен кампус.
- **Настройка посещаемости** — каждое время службы в Посещаемости может быть привязано к кампусу.

:::tip
Однолокальные церкви не должны настраивать кампусы. Все функции кампуса необязательны — если кампусы не существуют, поля и диаграммы кампуса просто не появляются.
:::
