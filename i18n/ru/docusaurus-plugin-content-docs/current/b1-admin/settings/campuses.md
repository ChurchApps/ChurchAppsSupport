# Кампусы

<div class="article-intro">

Если ваша церковь встречается более чем в одном месте, **Campuses** позволяют вам отслеживать, к какому сайту принадлежит каждый человек и группа. После настройки кампусы появляются как вариант на профилях людей, в настройке посещаемости и на приборной панели Demographics. Многосайтовые церкви могут фильтровать, искать и отчеты по кампусу во всем B1 Admin.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужно разрешение **Edit Church Settings** для управления кампусами. См. [Roles & Permissions](./roles-permissions.md).

</div>

## Открытие параметров кампуса

В B1 Admin откройте **меню раздела** в верхнем левом углу (название раздела со стрелкой), выберите **Settings** и выберите **Campuses** из навигации Settings. Вы увидите список всех настроенных кампусов с их именем, местоположением и часовым поясом.

## Добавление кампуса

1. Нажмите **Add Campus** (или кнопку **+**, если кампусов еще нет).
2. Заполните детали кампуса:
   - **Name** *(required)* — отображаемое имя, показанное по всему B1 Admin (например, "Main Campus" или "North Campus").
   - **Address** — адрес улицы кампуса (используется для информационного отображения; то же самое не как ваш основной адрес церкви в Church Settings).
   - **City / State / Zip** — местоположение кампуса.
   - **Timezone** — часовой пояс IANA для этого кампуса (например, *America/Chicago*). Полезно, когда кампусы находятся в разных часовых поясах.
   - **Website** — опциональный URL для собственного веб-присутствия этого кампуса.
3. Нажмите **Save**.

## Редактирование кампуса

Нажмите любую строку кампуса в списке, чтобы открыть его редактор на панели справа. Обновите поля и нажмите **Save**.

## Удаление кампуса

Откройте кампус для редактирования и нажмите **Delete**. Вас попросят подтвердить. Удаление кампуса не удаляет людей, назначенных ему — их поле кампуса просто становится пустым.

## Назначение людей кампусу

После создания кампусов сотрудники могут назначить человека кампусу из его профиля:

1. Откройте запись человека в **People**.
2. Нажмите **Edit**.
3. Выберите кампус из раскрывающегося меню **Campus**.
4. Нажмите **Save**.

Вы также можете обновить кампус в массе со страницы People. Выберите несколько человек, используйте **Bulk Edit** и установите поле Campus для всех одновременно.

## Фильтрация по кампусу

После настройки кампусов, вы можете фильтровать во всем B1 Admin по кампусу:

- **People search** — добавьте условие Campus в расширенный поиск или загрузите [Saved List](../people/lists.md), охватывающий кампус.
- **Demographics** — приборная панель [Demographics dashboard](../people/demographics.md) показывает диаграмму Campus donut, когда по крайней мере один человек имеет назначенный кампус.
- **Attendance Setup** — каждое время услуги в Attendance может быть привязано к кампусу.

:::tip
Одноместные церкви не нужно настраивать кампусы. Все функции кампуса являются необязательными — если кампусов не существует, поля кампуса и диаграммы просто не отображаются.
:::
