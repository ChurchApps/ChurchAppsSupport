# Кампусы

<div class="article-intro">

Если ваша церковь собирается в нескольких местах, **Campuses** позволяют отслеживать, к какой площадке относится каждый человек и группа. После настройки кампусы появляются как опция в профилях людей, в настройке посещаемости и на панели Demographics. Церкви с несколькими площадками могут фильтровать, искать и формировать отчёты по кампусам во всём B1 Admin.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Для управления кампусами нужно разрешение **Edit Church Settings**. См. [Роли и разрешения](./roles-permissions.md).

</div>

## Открытие настроек кампусов {#opening-campus-settings}

В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), выберите **Settings > Settings** и нажмите **Campuses** в списке слева, чтобы прокрутить до раздела **Campuses**. Можно также сразу перейти по адресу **/settings/campuses**. Вы увидите список всех настроенных кампусов с их названием, местоположением и часовым поясом.

## Добавление кампуса {#adding-a-campus}

1. Нажмите **Add Campus**.
2. Заполните данные кампуса:
   - **Name** *(обязательно)* — отображаемое название, которое показывается во всём B1 Admin (например, «Main Campus» или «North Campus»).
   - **Address** и **Address Line 2** — адрес кампуса (используется для информации; это не то же самое, что основной адрес церкви в Church Settings).
   - **City / State / Zip** — местоположение кампуса.
   - **Time Zone** — часовой пояс IANA для этого кампуса (например, *America/Chicago*). [Расписания регистрации](../attendance/setup.md#setting-a-check-in-schedule) для служб в этом кампусе открываются и закрываются по этому часовому поясу. Если выбрано **None**, используется [часовой пояс](./church-settings.md#time-zone) вашей церкви. Это полезно, когда кампусы находятся в разных часовых поясах.
   - **Website** — необязательная ссылка на собственный веб-сайт кампуса.
3. Нажмите **Save**.

В списке показаны **Name**, **Location** (город и штат) и **Time Zone** каждого кампуса, а пункт **Campuses** в списке слева показывает, сколько у вас площадок.

## Редактирование кампуса {#editing-a-campus}

Нажмите на любую строку кампуса в списке, чтобы открыть его редактор в панели справа. Измените поля и нажмите **Save**, либо **Cancel**, чтобы закрыть редактор без сохранения.

## Удаление кампуса {#deleting-a-campus}

Откройте кампус для редактирования и нажмите **Delete**. Система попросит подтвердить действие. Удаление кампуса не удаляет назначенных на него людей — их поле кампуса просто становится пустым.

## Назначение людей на кампус {#assigning-people-to-a-campus}

После создания кампусов сотрудники могут назначить человека на кампус из его профиля:

1. Откройте запись человека в **People**.
2. Нажмите **Edit**.
3. Выберите кампус в выпадающем списке **Campus**.
4. Нажмите **Save**.

Кампус можно также обновить массово на странице People. Выберите нескольких людей, используйте **Bulk Edit** и задайте поле Campus сразу для всех.

## Фильтрация по кампусу {#filtering-by-campus}

Когда кампусы настроены, вы можете фильтровать по кампусу во всём B1 Admin:

- **Поиск People** — добавьте условие Campus в расширенный поиск или загрузите [сохранённый список](../people/lists.md), ограниченный кампусом.
- **Demographics** — на [панели Demographics](../people/demographics.md) показывается круговая диаграмма по кампусам, если хотя бы у одного человека назначен кампус.
- **Настройка посещаемости** — каждое время службы в Attendance можно привязать к кампусу.

:::tip
Церквям с одной площадкой настраивать кампусы не нужно. Все функции кампусов необязательны: если кампусов нет, поля и диаграммы кампусов просто не появляются.
:::
