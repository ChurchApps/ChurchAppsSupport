# Кампусы

<div class="article-intro">

Если ваша церковь собирается более чем в одном месте, **Campuses** позволяют вам отслеживать, какой сайт принадлежит каждому человеку и группе. Один раз настроенные, кампусы появляются как опция на профилях людей, в установке посещаемости и на панели управления Demographics. Многосайтовые церкви могут фильтровать, искать и отчитываться по кампусам по всему B1 Admin.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужно разрешение **Edit Church Settings**, чтобы управлять кампусами. См. [Roles & Permissions](./roles-permissions.md).

</div>

## Открытие параметров кампуса

В B1 Admin откройте **меню раздела** в левом верхнем углу (название раздела с маленькой стрелкой), выберите **Settings**, и выберите **Campuses** из навигации Settings. Вы увидите список всех настроенных кампусов с их названием, местоположением и часовым поясом.

## Добавление кампуса

1. Нажмите **Add Campus** (или кнопку **+**, если кампусов еще нет).
2. Заполните детали кампуса:
   - **Name** *(required)* -- отображаемое название, показанное по всему B1 Admin (например, "Main Campus" или "North Campus").
   - **Address** -- адрес улицы кампуса (используется для информационного отображения; не то же самое, что ваш основной адрес церкви в Church Settings).
   - **City / State / Zip** -- местоположение кампуса.
   - **Timezone** -- IANA часовой пояс для этого кампуса (например, *America/Chicago*). Полезно, когда кампусы находятся в разных часовых поясах.
   - **Website** -- дополнительный URL для собственного веб-присутствия этого кампуса.
3. Нажмите **Save**.

## Редактирование кампуса

Нажмите на любую строку кампуса в списке, чтобы открыть его редактор на панели справа. Обновите поля и нажмите **Save**.

## Удаление кампуса

Откройте кампус для редактирования и нажмите **Delete**. Вас попросят подтвердить. Удаление кампуса не удаляет людей, назначенных ему -- их поле кампуса просто становится пусто.

## Назначение людей кампусу

После создания кампусов персонал может назначить человека кампусу из его профиля:

1. Откройте запись о человеке в **People**.
2. Нажмите **Edit**.
3. Выберите кампус из раскрывающегося меню **Campus**.
4. Нажмите **Save**.

Вы также можете обновить кампус в массиве со страницы People. Выберите нескольких людей, используйте **Bulk Edit**, и установите поле Campus для всех сразу.

## Фильтрация по кампусу

После настройки кампусов вы можете фильтровать по кампусам по всему B1 Admin:

- **People search** -- добавить условие Campus в продвинутый поиск, или загрузить [Saved List](../people/lists.md) в области кампуса.
- **Demographics** -- панель управления [Demographics](../people/demographics.md) показывает диаграмму Campus donut, когда по крайней мере одному человеку назначен кампус.
- **Attendance Setup** -- каждое время служения в Attendance может быть привязано к кампусу.

:::tip
Однолокационные церкви не должны настраивать кампусы. Все функции кампуса являются необязательными -- если кампусов не существует, поля и диаграммы кампуса просто не появляются.
:::
