# Кампусы

<div class="article-intro">

Если ваша церковь собирается в нескольких местах, **кампусы** позволяют отслеживать, к какому филиалу относится каждый человек и каждая группа. После настройки кампусы появляются как опция в профилях людей, в настройке посещаемости и на панели демографии. Церкви с несколькими площадками могут фильтровать, искать и формировать отчёты по кампусам во всём B1 Admin.

</div>

<div class="prereqs">
<h4>С чего начать</h4>

- Для управления кампусами нужно право **«Редактирование настроек церкви»**. См. [Роли и права](./roles-permissions.md).

</div>

## Открытие настроек кампусов

В B1 Admin откройте [меню перехода](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), выберите **Настройки > Настройки** и нажмите **Кампусы** в левом списке, чтобы перейти к разделу **Кампусы**. Можно также сразу открыть адрес **/settings/campuses**. Вы увидите список всех настроенных кампусов с их названием, местоположением и часовым поясом.

## Добавление кампуса

1. Нажмите **Добавить кампус**.
2. Заполните данные кампуса:
   - **Название** *(обязательно)* — отображаемое название, которое показывается во всём B1 Admin (например, «Главный кампус» или «Северный кампус»).
   - **Адрес** — уличный адрес кампуса (используется для информации; это не то же самое, что основной адрес церкви в настройках церкви).
   - **Город / Область / Индекс** — местоположение кампуса.
   - **Часовой пояс** — часовой пояс IANA для этого кампуса (например, *America/Chicago*). [Расписания регистрации](../attendance/setup.md#setting-a-check-in-schedule) для служений в этом кампусе открываются и закрываются по этому часовому поясу. Если установлено значение **None**, вместо него используется [часовой пояс](./church-settings.md#time-zone) вашей церкви. Полезно, когда кампусы находятся в разных часовых поясах.
   - **Веб-сайт** — необязательный URL собственного веб-представительства кампуса.
3. Нажмите **Сохранить**.

## Редактирование кампуса

Нажмите на любую строку кампуса в списке, чтобы открыть его редактор в панели справа. Измените поля и нажмите **Сохранить**.

## Удаление кампуса

Откройте кампус для редактирования и нажмите **Удалить**. Вас попросят подтвердить действие. Удаление кампуса не убирает людей, которые к нему относятся, — их поле «Кампус» просто станет пустым.

## Назначение людей на кампус

После создания кампусов сотрудники могут назначить человека на кампус из его профиля:

1. Откройте запись человека в разделе **Люди**.
2. Нажмите **Изменить**.
3. Выберите кампус в выпадающем списке **Кампус**.
4. Нажмите **Сохранить**.

Кампус можно также обновить массово на странице «Люди». Выберите нескольких человек, используйте **Массовое редактирование** и задайте поле «Кампус» сразу для всех.

## Фильтрация по кампусу

Когда кампусы настроены, вы можете фильтровать B1 Admin по кампусу:

- **Поиск людей** — добавьте условие «Кампус» в расширенный поиск или загрузите [сохранённый список](../people/lists.md), ограниченный кампусом.
- **Демография** — [панель демографии](../people/demographics.md) показывает круговую диаграмму по кампусам, когда хотя бы у одного человека указан кампус.
- **Настройка посещаемости** — каждое время служения в посещаемости можно привязать к кампусу.

:::tip
Церквям с одним местом проведения настраивать кампусы не нужно. Все функции кампусов необязательны — если кампусов нет, поля и диаграммы по кампусам просто не появляются.
:::
