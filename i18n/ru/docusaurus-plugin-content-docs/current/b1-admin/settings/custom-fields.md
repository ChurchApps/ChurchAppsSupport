# Пользовательские поля

<div class="article-intro">

**Пользовательские поля** позволяют вам отслеживать вашу собственную информацию на каждой записи человека — вещи, которые B1 не имеет встроенного поля для, такие как дата истечения проверки биографии, размер рубашки или статус класса крещения. Вы определяете поле один раз в Параметры, затем заполняете значение в профиле каждого человека и ищете или создаете списки на нем. Это заменяет старый способ создания формы людей только для хранения одного куска пользовательских данных.

</div>

<div class="prereqs">
<h4>Перед тем как начать</h4>

- Вам нужно разрешение **Люди** редактировать для определения полей и заполнения значений, а также доступ к области **Параметры**. Любой человек с разрешением просмотра Люди может видеть значения. См. [Роли и разрешения](./roles-permissions.md).
- Решите, что вы хотите отслеживать и какой тип лучше всего подходит (текст, число, дата, ответ да/нет или список выбора) перед тем как начать.

</div>

## Открытие пользовательских полей

В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), выберите **Параметры > Параметры** и выберите карточку **Пользовательские поля**. Вы также можете перейти прямо туда по адресу **/settings/custom-fields**. Вы увидите список каждого определенного вами поля, показывающий его **Имя** и **Тип поля**. Если вы еще не создали ни одного, панель прочитает *"Пользовательские поля еще не добавлены."*

## Добавление поля

1. Нажмите **Добавить поле**.
2. В редакторе, который откроется справа, введите **Имя** — это метка, которую персонал будет видеть в профилях людей и в поиске (например, *Background check expires*).
3. Выберите **Тип поля**:
   - **Текстовое поле** — свободный короткий текст.
   - **Целое число** — числа без десятичных (например, подсчет).
   - **Десятичное** — числа, которые могут включать десятичные.
   - **Дата** — дата календаря.
   - **Да/Нет** — простой ответ да или нет.
   - **Множественный выбор** — список выбора. Когда вы выбираете этот тип, появляется **редактор выборов**, чтобы вы могли добавить каждую опцию, которую люди могут выбрать.
4. Нажмите **Сохранить**.

Поле теперь доступно в профиле каждого человека.

:::info
Типы полей — это тот же набор, используемый для [вопросов формы](../forms/creating-forms.md), поэтому значения ведут себя согласованно по всему B1.
:::

## Редактирование поля

Нажмите на любую строку поля в списке, чтобы открыть ее снова в редакторе. Измените имя, тип или варианты и нажмите **Сохранить**.

:::warning
Изменение **Типа поля** поля, которое уже имеет значения (например, из Текстового поля в Дата), может оставить ранее введенные значения в формате, который больше не совпадает с новым типом. Измените типы осторожно, как только персонал начал заполнять поле.
:::

## Удаление поля

Откройте поле для редактирования и нажмите **Удалить**. Вас попросят подтвердить: *"Вы уверены, что хотите удалить это пользовательское поле? Его сохраненные значения также будут удалены."* Удаление поля постоянно удаляет его **и каждое значение, сохраненное для него** для всех людей — это не может быть отменено.

## Заполнение значений для человека

После того как существует по крайней мере одно пользовательское поле, его значения живут прямо рядом со встроенными деталями в каждой записи человека — вы просматриваете их в **Личные детали** и редактируете их в той же форме, которую вы используете для остальной информации человека. Ничего особого не появляется, пока вы не определили ваше первое поле.

1. Откройте запись человека в **Люди**.
2. В разделе **Личные детали** нажмите кнопку **Редактировать** (карандаш).
3. Прокрутите вниз до области **Пользовательские поля** в нижней части формы редактирования и заполните значение для каждого поля. Каждое поле показывает ввод, который соответствует его типу — средство выбора даты для полей Дата, раскрывающийся список да/нет для полей Да/Нет, список выбора для Множественного выбора и так далее.
4. Нажмите **Сохранить**. Ваши значения пользовательских полей сохраняются вместе с остальной информацией человека.

Обратно в профиле, любое поле, которое имеет значение, теперь показывает в разделе **Личные детали** (Ответы Да/Нет читаются как *Да* или *Нет*, и Множественный выбор показывает метку опции). Поля, оставленные пустыми, просто скрыты. Чтобы удалить значение, отредактируйте человека, очистите поле и сохраните — пустое значение удаляется из записи вместо того чтобы сохраняться как пусто.

:::tip
Классический вариант использования — безопасность волонтеров: создайте поле **Дата** под названием *Проверка биографии истекает*, запишите дату каждого волонтера, затем создайте [Сохраненный список](../people/lists.md), который помечает любого, чья дата прошла.
:::

## Поиск и создание списков по пользовательским полям

Пользовательские поля полностью доступны для поиска:

1. На странице **Люди** откройте [Расширенный поиск](../people/searching-people.md).
2. Разверните категорию **Пользовательские поля**.
3. Отметьте поле, по которому хотите фильтровать, выберите оператор и введите значение. Предлагаемые операторы соответствуют типу поля:
   - **Текстовое поле** — содержит, равно, начинается с, заканчивается с.
   - **Целое число / Десятичное** — равно, больше, больше или равно, меньше, меньше или равно.
   - **Дата** — равно, после (больше), перед (меньше).
   - **Да/Нет** — равно Да или Нет.
   - **Множественный выбор** — равно или содержит один из вариантов.

Сохраните любой поиск пользовательского поля как [Список](../people/lists.md). Списки — это живые запросы, поэтому список, построенный на *Проверка биографии истекает перед сегодня* перепроверяет каждого человека каждый раз, когда вы его открываете — без ручного обслуживания.

## Показ пользовательского поля как столбца

Чтобы увидеть значения поля для всех одновременно, добавьте его как столбец на странице **Люди**. Откройте выбор столбцов, переключитесь на вкладку **Пользовательский** и отметьте поле. Значение каждого человека появляется в своем столбце рядом со встроенными. См. [Показ пользовательских полей как столбцов](../people/searching-people.md#showing-custom-fields-as-columns).

## Что происходит при объединении

Когда вы [объединяете две записи людей](../people/adding-people.md), значения пользовательских полей переносятся автоматически. Человек, которого вы сохраняете, держит свои собственные значения; для любого поля, где только удаленный человек имел значение, это значение копируется, чтобы ничего не было потеряно.
