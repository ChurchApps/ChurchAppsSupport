# Пользовательские поля

<div class="article-intro">

**Custom Fields** позволяют отслеживать вашу собственную информацию на каждой записи человека -- вещи, которые B1 не имеет встроенного поля для, как дата истечения проверки фона, размер рубашки или статус класса крещения. Вы определяете поле один раз в Settings, затем заполняете значение на профиле каждого человека и ищете или строите на нем списки. Это заменяет старый обходной путь создания формы People только для хранения одного куска пользовательских данных.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужно разрешение **People** edit для определения полей и заполнения значений, и доступ к области **Settings**. Любой с разрешением People view может видеть значения. См. [Roles & Permissions](./roles-permissions.md).
- Решите, что вы хотите отслеживать и какой тип лучше всего подходит (текст, число, дата, ответ да/нет, или список выбора) перед началом.

</div>

## Открытие пользовательских полей

В B1 Admin откройте **меню раздела** в левом верхнем углу (название раздела с маленькой стрелкой), выберите **Settings**, и выберите карточку **Custom Fields**. Вы также можете перейти прямо туда в **/settings/custom-fields**. Вы увидите список каждого поля, которое вы определили, показывая его **Name** и **Field Type**. Если вы еще не создали ни одного, панель гласит *"No custom fields have been added yet."*

## Добавление поля

1. Нажмите **Add Field**.
2. В редакторе, который открывается справа, введите **Name** -- это ярлык, который персонал будет видеть на профилях людей и в поиске (например, *Background check expires*).
3. Выберите **Field Type**:
   - **Textbox** -- свободный форматный короткий текст.
   - **Whole Number** -- числа без десятичных (например, подсчет).
   - **Decimal** -- числа, которые могут включать десятичные.
   - **Date** -- дата календаря.
   - **Yes/No** -- простой ответ да или нет.
   - **Multiple Choice** -- список выбора. Когда вы выбираете этот тип, появляется **choices editor**, чтобы вы могли добавить каждую опцию, которую люди могут выбрать.
4. Нажмите **Save**.

Поле теперь доступно на профиле каждого человека.

:::info
Типы полей - это тот же набор, используемый для [вопросов формы](../forms/creating-forms.md), поэтому значения ведут себя последовательно по B1.
:::

## Редактирование поля

Нажмите на любую строку поля в списке, чтобы повторно открыть его в редакторе. Измените имя, тип или выборы и нажмите **Save**.

:::warning
Изменение **Field Type** поля, которое уже имеет значения (например, от Textbox до Date) может оставить ранее введенные значения в формате, который больше не соответствует новому типу. Измените типы с осторожностью, когда персонал начал заполнять поле.
:::

## Удаление поля

Откройте поле для редактирования и нажмите **Delete**. Вас попросят подтвердить: *"Are you sure you wish to delete this custom field? Its stored values will also be removed."* Удаление поля навсегда удаляет его **и каждое значение, хранящееся для него** на всех людях -- это невозможно отменить.

## Заполнение значений на человеке

Один раз, когда существует по крайней мере одно пользовательское поле, его значения живут прямо рядом со встроенными деталями на каждой записи человека -- вы просматриваете их в **Personal Details** и редактируете их в той же форме, которую вы используете для остального информации человека. Ничего дополнительного не появляется, пока вы не определили свое первое поле.

1. Откройте запись о человеке в **People**.
