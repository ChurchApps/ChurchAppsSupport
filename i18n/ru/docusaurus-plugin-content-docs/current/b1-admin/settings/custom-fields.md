# Пользовательские поля

<div class="article-intro">

**Пользовательские поля** позволяют отслеживать собственную информацию в каждой записи о человеке — данные, для которых B1 не имеет встроенного поля, такие как дата истечения проверки биографии, размер футболки или статус крещенского класса. Вы определяете поле один раз в параметрах, затем заполняете значение на каждом профиле человека и можете искать или создавать списки на основе этих данных. Это заменяет более старый способ создания формы "Люди" только для хранения одного фрагмента пользовательских данных.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужно разрешение редактирования **Люди** для определения полей и заполнения значений, а также доступ к области **Параметры**. Любой с разрешением на просмотр "Люди" может видеть значения. См. [Роли и разрешения](./roles-permissions.md).
- Прежде чем начать, решите, что вы хотите отслеживать и какой тип лучше всего подходит (текст, число, дата, да/нет ответ или раскрывающийся список).

</div>

## Открытие пользовательских полей

В B1 Admin откройте **меню раздела** в левом верхнем углу (название раздела со стрелкой), выберите **Параметры** и выберите карточку **Пользовательские поля**. Вы также можете перейти прямо туда по адресу **/settings/custom-fields**. Вы увидите список каждого определённого вами поля, показывающий его **Название** и **Тип поля**. Если вы ещё не создали ни одного, панель отображает *"Пользовательские поля не добавлены"*.

## Добавление поля

1. Нажмите **Добавить поле**.
2. В открывшемся редакторе справа введите **Название** — это метка, которую персонал будет видеть на профилях людей и при поиске (например, *Проверка биографии истекает*).
3. Выберите **Тип поля**:
   - **Текстовое поле** — свободный короткий текст.
   - **Целое число** — числа без десятичных знаков (например, счётчик).
   - **Десятичное число** — числа, которые могут включать десятичные знаки.
   - **Дата** — дата календаря.
   - **Да/Нет** — простой ответ да или нет.
   - **Множественный выбор** — раскрывающийся список. При выборе этого типа появляется **редактор выборов**, где вы можете добавить каждый вариант, который люди могут выбрать.
4. Нажмите **Сохранить**.

Поле теперь доступно на каждом профиле человека.

:::info
Типы полей — это тот же набор, который используется для [вопросов формы](../forms/creating-forms.md), поэтому значения ведут себя согласованно во всём B1.
:::

## Редактирование поля

Нажмите на любую строку поля в списке, чтобы открыть её в редакторе. Измените название, тип или выборы и нажмите **Сохранить**.

:::warning
Изменение **Типа поля** поля, которое уже имеет значения (например, с текстового поля на дату) может оставить ранее введённые значения в формате, который больше не соответствует новому типу. Будьте осторожны при изменении типов после того, как персонал начнёт заполнять поле.
:::

## Удаление поля

Откройте поле для редактирования и нажмите **Удалить**. Вам будет предложено подтвердить: *"Вы уверены, что хотите удалить это пользовательское поле? Все сохранённые для него значения также будут удалены"*. Удаление поля навсегда удаляет его **и все значения, сохранённые для него** на всех людях — это нельзя отменить.

## Заполнение значений для человека

После того как существует хотя бы одно пользовательское поле, его значения хранятся прямо рядом со встроенными деталями на каждой записи о человеке — вы просматриваете их в разделе **Личные данные** и редактируете их в той же форме, что и остальная информация о человеке. Ничего особенного не появляется, пока вы не определите своё первое поле.

1. Откройте запись человека в **Люди**.
2. В разделе **Личные данные** нажмите кнопку **Редактировать** (карандаш).
3. Прокрутите до области **Пользовательские поля** в нижней части формы редактирования и заполните значение для каждого поля. Каждое поле показывает ввод, соответствующий его типу — средство выбора даты для полей "Дата", раскрывающееся меню да/нет для полей "Да/Нет", раскрывающийся список для "Множественный выбор" и т.д.
4. Нажмите **Сохранить**. Значения пользовательских полей сохраняются вместе с остальными деталями человека.

На профиле любое поле, которое имеет значение, теперь показано в разделе **Личные данные** (ответы "Да/Нет" читаются как *Да* или *Нет*, а "Множественный выбор" показывает метку опции). Поля, оставленные пустыми, просто скрыты. Чтобы удалить значение, отредактируйте человека, очистите поле и сохраните — пустое значение удаляется из записи вместо того, чтобы сохраняться как пусто.

:::tip
Классический вариант использования — безопасность волонтёра: создайте поле **Дата** с названием *Проверка биографии истекает*, записывайте дату каждого волонтёра, а затем создайте [Сохранённый список](../people/lists.md), который отмечает любого, чья дата прошла.
:::

## Поиск и создание списков по пользовательским полям

Пользовательские поля полностью доступны для поиска:

1. На странице **Люди** откройте [Продвинутый поиск](../people/searching-people.md).
2. Разверните категорию **Пользовательские поля**.
3. Отметьте поле, по которому вы хотите фильтровать, выберите оператор и введите значение. Предлагаемые операторы соответствуют типу поля:
   - **Текстовое поле** — содержит, равно, начинается с, заканчивается.
   - **Целое число / Десятичное число** — равно, больше, больше или равно, меньше, меньше или равно.
   - **Дата** — равно, после (больше), до (меньше).
   - **Да/Нет** — равно да или нет.
   - **Множественный выбор** — равно или содержит один из выборов.

Сохраняйте любой поиск по пользовательским полям как [Список](../people/lists.md). Списки — это живые запросы, поэтому список, созданный на основе *Проверка биографии истекает раньше сегодня*, перепроверяет каждого человека каждый раз, когда вы его открываете — никакого ручного ухода.

## Что происходит при слиянии

Когда вы [объединяете две записи о человеке](../people/adding-people.md), значения пользовательских полей передаются автоматически. Человек, которого вы оставляете, сохраняет свои собственные значения; для любого поля, где только удаляемый человек имел значение, это значение копируется, чтобы ничего не потерялось.
