# Пользовательские поля

<div class="article-intro">

**Пользовательские поля** позволяют хранить собственные сведения в каждой карточке человека -- то, для чего в B1 нет встроенного поля, например дату окончания проверки биографических данных, размер футболки или статус прохождения курса крещения. Вы определяете поле один раз в настройках, затем заполняете значение в профиле каждого человека и ищете по нему или составляете списки. Это заменяет старый обходной путь, когда для хранения одного пользовательского значения создавали форму для людей.

</div>

## Открытие пользовательских полей

В B1 Admin откройте [меню быстрого перехода](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), выберите **Настройки > Настройки** и нажмите **Пользовательские поля** в списке слева, чтобы перейти к разделу **Пользовательские поля**. Попасть туда можно и напрямую по адресу **/settings/custom-fields**. Вы увидите список всех определённых полей с их **Названием** и **Типом поля**. Если поля ещё не созданы, в панели появится сообщение *«Пользовательские поля ещё не добавлены»*.

## Обращения

Карточка **Обращения** вверху раздела «Пользовательские поля» содержит список обращений, которые предлагаются в поле **Обращение** при добавлении или редактировании человека -- в B1 Admin и в приложении B1 (редактор профиля и форма регистрации гостя). Исходный список: Mr, Mrs, Miss, Ms, Dr, Prof, Rev и Pastor.

1. Введите обращение в поле **Новое обращение** (до 10 символов), например *Deacon* или *Elder*, и нажмите **Добавить обращение**.
2. Чтобы убрать обращение из списка, нажмите **×** на его метке.
3. Нажмите **Сохранить**.

:::tip
В поле «Обращение» по-прежнему можно ввести любое значение, поэтому сотрудники и участники могут указать обращение, которого нет в списке. Удаление обращения из списка не меняет данные людей, у которых оно уже есть.
:::

## Добавление поля

1. Нажмите **Добавить поле**.
2. В редакторе, который откроется справа, введите **Название** -- это подпись, которую сотрудники увидят в профилях людей и в поиске (например, *Проверка биографических данных истекает*).
3. Выберите **Тип поля**:
   - **Текстовое поле** -- свободный короткий текст.
   - **Целое число** -- числа без десятичных знаков (например, количество).
   - **Десятичное число** -- числа, которые могут содержать дробную часть.
   - **Дата** -- календарная дата.
   - **Да/Нет** -- простой ответ «да» или «нет».
   - **Множественный выбор** -- список выбора. После выбора этого типа появляется **редактор вариантов**, в котором можно добавить каждый вариант, доступный для выбора.
4. Нажмите **Сохранить**.

Поле сразу становится доступным в профиле каждого человека.

:::info
Типы полей те же, что и для [вопросов в формах](../forms/creating-forms.md), поэтому значения работают в B1 единообразно.
:::

## Редактирование поля

Нажмите на строку любого поля в списке, чтобы снова открыть его в редакторе. Измените название, тип или варианты и нажмите **Сохранить**.

:::warning
Изменение **Типа поля** для поля, в котором уже есть значения (например, с текстового поля на дату), может привести к тому, что ранее введённые значения окажутся в формате, не соответствующем новому типу. Меняйте типы осторожно, когда сотрудники уже начали заполнять поле.
:::

## Удаление поля

Откройте поле для редактирования и нажмите **Удалить**. Система попросит подтверждение: *«Вы уверены, что хотите удалить это пользовательское поле? Его сохранённые значения также будут удалены».* Удаление поля необратимо удаляет его **и все значения, сохранённые в нём** у всех людей -- отменить это нельзя.

## Заполнение значений у человека

Когда есть хотя бы одно пользовательское поле, его значения находятся прямо рядом со встроенными сведениями в карточке каждого человека: их можно увидеть вместе с контактными данными слева в профиле и редактировать в той же форме, которой пользуетесь для остальных сведений о человеке. Ничего дополнительного не появляется, пока вы не определите первое поле.

1. Откройте карточку человека в разделе **Люди**.
2. Нажмите кнопку **Изменить** слева в профиле, под контактными данными человека.
3. Прокрутите к области **Пользовательские поля** внизу формы редактирования и заполните значение для каждого поля. Каждое поле показывает ввод, соответствующий его типу: календарь для полей «Дата», выпадающий список «Да/Нет» для полей «Да/Нет», список выбора для «Множественного выбора» и так далее.
4. Нажмите **Сохранить**. Значения пользовательских полей сохраняются вместе с остальными сведениями о человеке.

Вернувшись в профиль, вы увидите, что любое поле с значением отображается под контактными данными человека в виде *Название поля: значение* (ответы «Да/Нет» отображаются как *Да* или *Нет*, а для «Множественного выбора» показывается название варианта). Пустые поля просто скрыты. Чтобы удалить значение, откройте редактирование человека, очистите поле и сохраните -- пустое значение удаляется из записи, а не сохраняется как пустое.

:::tip
Классический пример использования -- безопасность волонтёров: создайте поле типа **Дата** с названием *Проверка биографических данных истекает*, внесите дату для каждого волонтёра, а затем создайте [сохранённый список](../people/lists.md), который отмечает тех, чья дата уже прошла.
:::

## Поиск и составление списков по пользовательским полям

По пользовательским полям можно выполнять полноценный поиск:

1. На странице **Люди** откройте [расширенный поиск](../people/searching-people.md).
2. Раскройте категорию **Пользовательские поля**.
3. Отметьте поле, по которому хотите фильтровать, выберите оператор и введите значение. Доступные операторы зависят от типа поля:
   - **Текстовое поле** -- содержит, равно, начинается с, заканчивается на.
   - **Целое число / Десятичное число** -- равно, больше, больше или равно, меньше, меньше или равно.
   - **Дата** -- равно, после (больше), до (меньше).
   - **Да/Нет** -- равно Да или Нет.
   - **Множественный выбор** -- равно одному из вариантов или содержит его.

Любой поиск по пользовательским полям можно сохранить как [список](../people/lists.md). Списки -- это живые запросы, поэтому список, построенный по условию *Проверка биографических данных истекает раньше сегодняшнего дня*, каждый раз заново проверяет всех людей при открытии -- без ручного обслуживания.

## Показ пользовательского поля как столбца

Чтобы сразу увидеть значения поля у всех людей, добавьте его как столбец на странице **Люди**. Переключите **Вид** на **Таблица**, нажмите значок **Выбрать столбцы** в заголовке страницы, перейдите на вкладку **Пользовательские** и отметьте нужное поле. Значение каждого человека появится в отдельном столбце рядом со встроенными. См. [Показ пользовательских полей как столбцов](../people/searching-people.md#showing-custom-fields-as-columns).

## Что происходит при объединении

Когда вы [объединяете две карточки людей](../people/adding-people.md), значения пользовательских полей переносятся автоматически. У сохраняемого человека остаются его собственные значения; для любого поля, в котором значение было только у удаляемого человека, это значение переносится, чтобы ничего не потерялось.
