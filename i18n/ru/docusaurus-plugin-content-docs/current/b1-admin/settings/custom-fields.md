# Пользовательские поля

<div class="article-intro">

**Custom Fields** позволяют вести собственные данные в записи каждого человека — то, для чего в B1 нет встроенного поля, например дату окончания проверки благонадёжности, размер футболки или статус прохождения курса крещения. Поле вы определяете один раз в Settings, затем заполняете значение в профиле каждого человека и ищете по нему или строите списки. Это заменяет прежний обходной путь, когда для хранения одного пользовательского значения создавали отдельную форму People.

</div>

## Открытие пользовательских полей {#opening-custom-fields}

В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), выберите **Settings > Settings** и нажмите **Custom Fields** в списке слева, чтобы прокрутить до раздела **Custom Fields**. Можно также сразу перейти по адресу **/settings/custom-fields**. Вы увидите список всех определённых полей с их **Name** и **Field Type**. Если поля ещё не созданы, в панели написано *«No custom fields have been added yet.»*

## Титулы {#titles}

Карточка **Titles** вверху раздела Custom Fields содержит список титулов, которые предлагаются в поле **Title**, когда кто-то добавляет или редактирует человека в B1 Admin и в приложении B1 (редактор профиля и форма регистрации гостя). Исходный список: Mr, Mrs, Miss, Ms, Dr, Prof, Rev и Pastor.

1. Введите титул в поле **New title** (до 10 символов), например *Deacon* или *Elder*, и нажмите **Add Title**.
2. Чтобы убрать титул из списка, нажмите **×** на его чипе.
3. Нажмите **Save**. Сообщение *«Titles saved.»* подтвердит изменение. Если добавить титул, который уже есть в списке, появится сообщение *«That title is already in the list.»*

:::tip
В поле Title по-прежнему можно вводить текст вручную, поэтому сотрудники и участники могут указать титул, которого нет в списке. Удаление титула из списка не меняет данные людей, у которых он уже указан.
:::

## Добавление поля {#adding-a-field}

1. Нажмите **Add Field**.
2. В редакторе, который откроется справа, введите **Name** — это подпись, которую сотрудники увидят в профилях людей и в поиске (например, *Background check expires*).
3. Выберите **Field Type**:
   - **Textbox** — короткий свободный текст.
   - **Whole Number** — целые числа без дробной части (например, количество).
   - **Decimal** — числа, которые могут содержать дробную часть.
   - **Date** — календарная дата.
   - **Yes/No** — простой ответ «да» или «нет».
   - **Multiple Choice** — список выбора. Когда вы выбираете этот тип, появляется **редактор вариантов**, в котором можно добавить каждый вариант, который люди смогут выбрать.
4. Нажмите **Save**.

Теперь поле доступно в профиле каждого человека.

:::info
Типы полей такие же, как у [вопросов формы](../forms/creating-forms.md), поэтому значения ведут себя одинаково во всём B1.
:::

## Редактирование поля {#editing-a-field}

Нажмите на любую строку поля в списке, чтобы снова открыть его в редакторе. Измените название, тип или варианты и нажмите **Save**.

:::warning
Изменение **Field Type** у поля, в котором уже есть значения (например, с Textbox на Date), может оставить ранее введённые значения в формате, который больше не соответствует новому типу. Меняйте типы осторожно, когда сотрудники уже начали заполнять поле.
:::

## Удаление поля {#deleting-a-field}

Откройте поле для редактирования и нажмите **Delete**. Система попросит подтвердить: *«Are you sure you wish to delete this custom field? Its stored values will also be removed.»* Удаление поля безвозвратно удаляет его **и все значения, сохранённые в нём** у всех людей — отменить это нельзя.

## Заполнение значений у человека {#filling-in-values-on-a-person}

Когда существует хотя бы одно пользовательское поле, его значения находятся рядом со встроенными данными в записи каждого человека: вы видите их вместе с контактами человека слева от профиля и редактируете в той же форме, что и остальные данные. Пока вы не создали первое поле, ничего дополнительного не появляется.

1. Откройте запись человека в **People**.
2. Нажмите кнопку **Edit** слева от профиля, под контактными данными человека.
3. Прокрутите до области **Custom Fields** внизу формы редактирования и заполните значение для каждого поля. Каждое поле показывает элемент ввода, соответствующий его типу: выбор даты для полей Date, выпадающий список да/нет для Yes/No, список выбора для Multiple Choice и т. д.
4. Нажмите **Save**. Значения пользовательских полей сохраняются вместе с остальными данными человека.

Вернувшись к профилю, любое поле, у которого есть значение, отображается под контактными данными человека в виде *Название поля: значение* (ответы Yes/No читаются как *Yes* или *No*, а у Multiple Choice показывается подпись варианта). Пустые поля просто скрыты. Чтобы удалить значение, отредактируйте человека, очистите поле и сохраните: пустое значение удаляется из записи, а не сохраняется как пустое.

:::tip
Классический случай использования — безопасность волонтёров: создайте поле **Date** под названием *Background check expires*, внесите дату для каждого волонтёра и постройте [сохранённый список](../people/lists.md), который отмечает тех, у кого дата уже прошла.
:::

## Поиск и построение списков по пользовательским полям {#searching-and-building-lists-on-custom-fields}

Пользовательские поля полностью доступны для поиска:

1. На странице **People** откройте [расширенный поиск](../people/searching-people.md).
2. Раскройте категорию **Custom Fields**.
3. Отметьте поле, по которому хотите фильтровать, выберите оператор и введите значение. Доступные операторы зависят от типа поля:
   - **Textbox** — содержит, равно, начинается с, заканчивается на.
   - **Whole Number / Decimal** — равно, больше, больше или равно, меньше, меньше или равно.
   - **Date** — равно, после (больше), до (меньше).
   - **Yes/No** — равно Yes или No.
   - **Multiple Choice** — равно одному из вариантов или содержит его.

Любой поиск по пользовательским полям можно сохранить как [список](../people/lists.md). Списки — это динамические запросы, поэтому список, построенный на условии *Background check expires is before today*, пересчитывает каждого человека при каждом открытии — без ручного обслуживания.

## Вывод пользовательского поля как столбца {#showing-a-custom-field-as-a-column}

Чтобы сразу увидеть значения поля у всех, добавьте его как столбец на странице **People**. Переключите **View as** на **Table**, нажмите значок **Select columns** в заголовке страницы, перейдите на вкладку **Custom** и отметьте поле. Значение каждого человека появится в отдельном столбце рядом со встроенными. См. [Вывод пользовательских полей как столбцов](../people/searching-people.md#showing-custom-fields-as-columns).

## Что происходит при объединении {#what-happens-on-merge}

Когда вы [объединяете две записи людей](../people/adding-people.md), значения пользовательских полей переносятся автоматически. Сохраняемый человек остаётся с собственными значениями; для любого поля, где значение было только у удаляемого человека, оно копируется, так что ничего не теряется.
