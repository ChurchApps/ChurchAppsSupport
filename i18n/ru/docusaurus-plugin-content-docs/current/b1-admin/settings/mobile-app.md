# Параметры мобильного приложения

<div class="article-intro">

Страница "Параметры мобильного приложения" позволяет вам настроить вкладки навигации, которые отображаются в **мобильном опыте B1.church (PWA)** для членов вашей церкви. Вы контролируете, какие вкладки видны, на что они ссылаются и как они отображаются.

</div>

:::info Родное приложение B1 Mobile устарело
Вкладки, настроенные здесь, доставляются через [B1.church Progressive Web App (PWA)](/docs/b1-church/getting-started/installing-pwa), которое заменило родное приложение B1 Mobile. Поделитесь страницей установки вашей церкви — `https://yourchurchname.b1.church/mobile/install` — с членами; это предоставляет им пошаговое руководство по установке приложения на их устройство, без загрузки из App Store или Google Play.
:::

<div class="prereqs">
<h4>Перед тем как начать</h4>

- Вам необходимо разрешение "Редактировать параметры церкви". Если у вас нет доступа, см. [Роли и разрешения](./roles-permissions.md).
- Сначала настройте ваши [Параметры церкви](./church-settings.md), включая название и брендирование вашей церкви

</div>

## Доступ к параметрам навигации

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу) и разверните **Мобильный**.
2. Нажмите **Навигация** (`/mobile/navigation`).
3. Страница Навигация отображает ваши текущие вкладки приложения.

## Добавление новой вкладки

1. Нажмите кнопку **Добавить вкладку** в верхней части страницы.
2. Заполните детали вкладки:
   - **Название** — метка, которая появляется на вкладке (например, "Проповеди" или "Пожертвовать").
   - **Значок** — нажмите выбор значка, чтобы выбрать значок для вашей вкладки. Вы также можете загрузить пользовательское изображение.
   - **Тип вкладки** — выберите из опций, таких как Библия, Прямая трансляция, Пожертвование, Веб-сайт и т.д.
   - **URL** — введите веб-адрес, на который должна ссылаться вкладка.
   - **Видимость** — контролируйте, кто может видеть эту вкладку (все, только члены и т.д.).
3. Нажмите **Сохранить вкладку**, чтобы добавить ее в ваше приложение.

## Редактирование существующей вкладки

1. Нажмите на любую существующую вкладку в списке **Вкладки приложения**.
2. Обновите название, значок, URL, тип или параметры видимости вкладки.
3. Нажмите **Сохранить вкладку**, чтобы применить ваши изменения.

## Переупорядочение вкладок

Вы можете изменить порядок, в котором вкладки отображаются в мобильном приложении. Перетащите и отпустите вкладки в списке, чтобы переупорядочить их. Порядок, показанный на этой странице, совпадает с порядком, который ваши члены увидят в приложении.

:::info
Некоторые вкладки могут появляться автоматически, когда выполняются определенные условия — например, вкладка Прямая трансляция может появиться, когда трансляция активна. Вручную добавленные вкладки дают вам полный контроль над тем, что видят ваши члены все время.
:::

:::tip
Держите количество вкладок управляемым. От трех до пяти вкладок работает хорошо для большинства церквей. Слишком много вкладок может сделать навигацию запутанной для ваших членов.
:::

## Параметры каталога членов и сообщений

Элемент **Портал членов** в том же разделе Мобильный содержит параметры, которые управляют каталогом членов и приватными сообщениями в опыте B1.church:

- **Группа утверждения каталога** — группа, которая рассматривает обновления каталога членов и [запросы удаления учетной записи](../profile/account-deletion.md) перед их вступлением в силу.
- **Показывать в каталоге** — кто может появиться в каталоге членов (только персонал через Все).
- **Предпочтение видимости** — устанавливает значение по умолчанию для всей церкви для членов, которые еще не выбрали свой собственный параметр. **Адрес**, **Номер телефона** и **Электронная почта** каждый имеют свой раскрывающийся список с одинаковыми пятью уровнями, доступными везде, где настроена видимость:
  - **Все** — видно всем, включая анонимных посетителей
  - **Члены** — видно только людям с записью Члена или Персонала
  - **Только группы** — видно только людям, которые делят группу с этим человеком
  - **Мои лидеры групп и персонал** — видно только лидерам группы, к которой принадлежит этот человек, плюс персонал
  - **Только персонал** — видно только персоналу с разрешением Люди > Просмотр, и самому человеку

  Члены могут переопределить эти значения по умолчанию для своей собственной записи из вкладки **Конфиденциальность** их профиля в B1.church PWA — см. [Редактирование вашего профиля](/docs/b1-church/getting-started/me-page).
- **Минимальный возраст для приватных сообщений** — контроль безопасности детей. B1 не откроет **новый** разговор приватных сообщений, когда любой человек моложе этого возраста, основываясь на его дате рождения (роль в домохозяйстве используется в качестве резервного варианта, когда дата рождения отсутствует в файле). Люди младше возраста остаются полностью видны в каталоге — только прямое обмен сообщениями блокируется в **обе стороны** для всех, включая персонал. Групповые разговоры и отправка сообщений родителям ребенка все еще работают. Опции: Отключено, 13, 16 или 18; по умолчанию это **18**. Существующие разговоры не затрагиваются.

:::tip
Потому что проверка минимального возраста опирается на даты рождения, убедитесь, что даты рождения заполнены для детей в вашей общине. Этот параметр принадлежит к той же семье контроля безопасности детей, что и [контрольные функции безопасности](../attendance/checkin-safety.md).
:::

### Приглашение входа на главный экран

Посетители, которые открывают [Главный экран](/docs/b1-church/getting-started/navigating#home) приложения без входа в систему, видят короткое приглашение — по умолчанию, *"Войдите, чтобы увидеть ваши группы, пожертвования и многое другое."* — рядом с кнопкой **Вход**. Параметры **Приглашение входа на главный экран** на той же странице Портал членов (`/mobile/b1-mobile`) позволяют вам изменить его:

- **Показать приглашение входа на главный экран приложения** — отключите это, чтобы скрыть как приглашение, так и кнопку **Вход** из главного экрана. Посетители все равно могут войти из меню приложения.
- **Текст приглашения входа** — замените формулировку по умолчанию вашим собственным сообщением (до 150 символов). Оставьте пусто, чтобы использовать значение по умолчанию. Это поле отключено, пока приглашение отключено.

Нажмите **Сохранить**, чтобы применить. Сохранение обновляет кэшированные параметры приложения, поэтому изменение появляется при следующей загрузке главного экрана.

## Где появляются эти вкладки

Вкладки, которые вы настраиваете здесь, отображаются в **B1.church PWA**, которое члены вашей церкви устанавливают со страницы `https://yourchurchname.b1.church`. Изменения, которые вы вносите на этой странице, отражаются при следующем открытии приложения участником. (Вкладки также отображаются устаревшим [B1 Mobile родным приложением](/docs/b1-mobile/) для любых членов, которые все еще его запускают, но это приложение устарело и больше не обновляется.)
