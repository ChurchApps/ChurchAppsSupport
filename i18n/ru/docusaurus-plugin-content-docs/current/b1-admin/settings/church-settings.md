# Параметры церкви

<div class="article-intro">

На странице параметров церкви вы управляете основной информацией о вашей организации, включая название, адрес, контактную информацию и другие ключевые настройки.

</div>

## Доступ к параметрам церкви

1. Перейдите в раздел **Settings** в B1 Admin
2. Нажмите на плитку **Church Settings**

## Основная информация

Вы можете обновить:

- **Church Name** — официальное название вашей церкви
- **Address** — физический адрес главного кампуса
- **City, State, Zip** — местоположение церкви
- **Phone** — основной номер телефона
- **Email** — основной адрес электронной почты
- **Website** — URL вашего основного сайта
- **Logo** — логотип вашей церкви для использования в отчетах

## Параметры служения

Установите информацию о вашем служении:

- **Service Times** — когда встречается ваша церковь
- **Grade Promotion Date** — когда студенты переходят на следующий класс
- **Timezone** — часовой пояс вашей церкви

## Интеграции

Подключите платежные системы и сторонние сервисы:

- **Giving Provider** — Stripe, PayPal, Kingdom Funding или Paystack
- **Webhooks** — настройте интеграции с Mailchimp, Zapier и другими

## Сохранение изменений

После внесения изменений нажмите **Save** для применения ваших обновлений.

Все изменения обновляются немедленно и влияют на то, как B1 отображает информацию о вашей церкви.

## Советы

- Убедитесь, что ваш часовой пояс правильный для правильного планирования
- Регулярно обновляйте контактную информацию
- Используйте высокое качество логотипа для лучшей печати
