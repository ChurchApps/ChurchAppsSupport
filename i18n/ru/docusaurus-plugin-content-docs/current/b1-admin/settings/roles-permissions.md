# Роли и разрешения

<div class="article-intro">

Роли позволяют вам контролировать, что разные пользователи могут получить в вашей учетной записи ChurchApps. Вы можете создавать пользовательские роли для персонала, добровольцев и других членов команды, каждый со своим уровнем доступа, чтобы обеспечить безопасность ваших данных.

</div>

<div class="prereqs">
<h4>Перед тем как начать</h4>

- Вам требуется доступ Domain Admin или роль с разрешением управлять ролями
- Имейте список членов команды и областей, к которым им требуется доступ
- Проверьте доступные категории разрешений ниже, чтобы спланировать ваши роли

</div>

## Доступ к ролям

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу) и разверните **Параметры**.
2. Нажмите **Роли**.
3. Страница Роли отображает все в настоящее время определенные роли для вашей церкви.

## Понимание страницы ролей

Страница Роли разделена на две панели:

- **Левая сторона** — показывает список членов, назначенных выбранной роли.
- **Правая сторона** — отображает параметры разрешений, которые вы можете настроить для этой роли.

Нажмите на любое имя роли, чтобы просмотреть и управлять ее членами и разрешениями.

## Добавление пользователей в роль

1. Выберите роль, к которой вы хотите добавить членов.
2. Используйте **поле поиска** на левой стороне, чтобы найти человека, которого вы хотите добавить.
3. Выберите человека из результатов поиска.
4. Они будут добавлены в роль сразу.

## Удаление пользователей из роли

1. Выберите роль, содержащую пользователя, которого вы хотите удалить.
2. Найдите человека в списке членов на левой стороне.
3. Нажмите **кнопку удаления** рядом с его именем.

## Настройка разрешений

Каждой роли может быть предоставлен доступ к определенным областям B1 Admin. Разрешения организованы по секциям:

- **Люди** — доступ к каталогу членов и записям людей.
- **Пожертвования** — доступ к записям пожертвований и управлению фондами.
- **Посещаемость** — доступ к отслеживанию посещаемости и отчетам.
- **Содержание** — доступ к управлению веб-сайтом и содержанием.
- И дополнительные области по мере их доступности.

Используйте флажки на правой стороне страницы Роли, чтобы включить или отключить доступ для каждой области.

:::warning
**Domain Admins** имеют полный доступ ко всем областям вашей учетной записи ChurchApps. Их разрешения не могут быть изменены или ограничены. Используйте эту роль только для ваших наиболее доверенных администраторов.
:::

:::tip
Создавайте специальные роли, как "Казначей" только с доступом **Пожертвования**, или "Волонтер контроля входа" только с доступом **Посещаемость**. Это следует принципу наименьших привилегий и обеспечивает безопасность ваших данных. См. [Безопасность данных](./data-security.md) для большего понимания того, как ChurchApps защищает вашу информацию.
:::
