# Роли и разрешения

<div class="article-intro">

Роли позволяют контролировать, к чему имеют доступ разные пользователи в вашей учетной записи ChurchApps. Вы можете создавать собственные роли для сотрудников, волонтеров и других членов команды, каждой из которых задан свой уровень доступа, чтобы ваши данные оставались защищенными.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужен доступ Domain Admin или роль с разрешением на управление ролями
- Подготовьте список членов команды и областей, к которым им нужен доступ
- Ознакомьтесь с доступными категориями разрешений ниже, чтобы спланировать роли

</div>

## Доступ к ролям

1. В B1 Admin откройте [меню перехода](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу) и разверните **Настройки**.
2. Нажмите **Роли**.
3. На странице «Роли» отображаются все роли, определенные для вашей церкви.

## Структура страницы «Роли»

Страница «Роли» разделена на две панели:

- **Левая сторона** — список участников, назначенных выбранной роли.
- **Правая сторона** — настройки разрешений, которые можно задать для этой роли.

Нажмите на название любой роли, чтобы просмотреть и изменить её участников и разрешения.

## Добавление пользователей в роль

1. Выберите роль, в которую хотите добавить участников.
2. Используйте **поле поиска** слева, чтобы найти нужного человека.
3. Выберите человека из результатов поиска.
4. Он сразу будет добавлен в роль.

## Удаление пользователей из роли

1. Выберите роль, в которой есть нужный пользователь.
2. Найдите этого человека в списке участников слева.
3. Нажмите **кнопку удаления** рядом с его именем.

## Настройка разрешений

Каждой роли можно предоставить доступ к определенным областям B1 Admin. В панели **Изменить разрешения** разрешения сгруппированы в разделы, которые можно раскрыть, например **Посещаемость**, **Контент**, **Пожертвования**, **Формы и планы**, **Уроки**, **Сообщения**, **Люди и группы** и **Задачи**. Введите текст в поле **Фильтр разрешений**, чтобы показать только подходящие разрешения.

Установите или снимите флажок с разрешения, чтобы предоставить его роли или отозвать.

### Разрешения для пожертвований

В разделе **Пожертвования** есть следующие разрешения:

- **Просмотр сводки пожертвований** — видеть раздел «Пожертвования», включая страницы «Сводка», «Пакеты», «Фонды», «Кампании» и «Справки о пожертвованиях».
- **Просмотр пожертвований** — видеть отдельные пожертвования, например подарки внутри пакета.
- **Редактирование пожертвований** — полный контроль: добавление, изменение и удаление пожертвований и пакетов, а также [закрытие и повторное открытие пакетов](../donations/batches.md#closing-and-reopening-a-batch).
- **Ввод пожертвований** — добавление пакетов и ввод, изменение или удаление пожертвований, но только в пакетах, которые еще открыты. Люди, у которых есть только это разрешение, не могут удалять пакеты, закрывать или открывать их повторно, а также менять пожертвования, поступившие через онлайн-пожертвования.
- **Изменение настроек** — управление настройками пожертвований.

Пользователь с **Ввод пожертвований**, но без **Просмотр сводки пожертвований**, видит в разделе **Пожертвования** только страницу **Пакеты**. Счетной команде лучше назначать и **Ввод пожертвований**, и **Просмотр пожертвований**, чтобы они могли открыть пакет и увидеть пожертвования, которые внесли. Подробности см. в разделе [Кто может изменять пакет](../donations/batches.md#who-can-change-a-batch).

### Только имена людей

В разделе **Люди и группы** есть разрешение **Просмотр только имен людей**. Используйте его для волонтеров, которым нужно искать людей по имени — например, чтобы выбрать кого-то в поле поиска, — но без доступа к полному каталогу. Только с этим разрешением человек:

- может искать людей по имени и видеть список недавно добавленных людей, но видит только имя, фото и статус членства каждого человека;
- не может искать по электронной почте, видеть контактные данные или открывать каталог **Люди**.

B1 Admin скрывает ссылки и кнопки, для которых у роли нет нужных разрешений. Например, список **Все группы** доступен только тем, кто может редактировать группы, просматривать участников групп или просматривать людей (остальные перенаправляются на Панель управления); настройка посещаемости появляется только с разрешением **Просмотр посещаемости** или **Изменение служений**; кнопка **Email** в группе видна только тем, у кого есть **Редактирование участников группы** (разрешение, необходимое для отправки писем группе); печать списка группы требует **Просмотр участников группы** или роли руководителя этой группы; а для удаления события календаря нужно **Редактирование контента** (или отзыв собственного ожидающего запроса).

:::warning
**Domain Admin** имеет полный доступ ко всем областям вашей учетной записи ChurchApps. Их разрешения нельзя изменить или ограничить. Используйте эту роль только для самых доверенных администраторов.
:::

:::tip
Создавайте специальные роли, например «Казначей» только с доступом к **Пожертвованиям**, «Счетная команда» с **Ввод пожертвований** и **Просмотр пожертвований** или «Волонтер на регистрации» только с доступом к **Посещаемости**. Это соответствует принципу минимальных привилегий и обеспечивает безопасность ваших данных. О том, как ChurchApps защищает вашу информацию, см. в разделе [Безопасность данных](./data-security.md).
:::
