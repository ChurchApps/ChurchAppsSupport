# Роли и разрешения

<div class="article-intro">

Роли позволяют вам контролировать, к чему могут получить доступ различные пользователи в вашей учётной записи ChurchApps. Вы можете создавать пользовательские роли для персонала, волонтёров и других членов вашей команды, каждая с собственным уровнем доступа для защиты ваших данных.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужен доступ администратора домена или роль с разрешением управления ролями
- Имейте список членов команды и областей, к которым им нужен доступ
- Изучите доступные категории разрешений ниже, чтобы спланировать ваши роли

</div>

## Доступ к ролям

1. В B1 Admin откройте **меню раздела** в левом верхнем углу (название раздела со стрелкой) и выберите **Параметры**.
2. Нажмите кнопку **Роли** в заголовке.
3. На странице ролей отображаются все текущие роли, определённые для вашей церкви.

## Понимание страницы ролей

Страница ролей разделена на две панели:

- **Левая сторона** — показывает список членов, назначенных выбранной роли.
- **Правая сторона** — отображает параметры разрешений, которые вы можете настроить для этой роли.

Нажмите на любое название роли, чтобы просмотреть и управлять её членами и разрешениями.

## Добавление пользователей в роль

1. Выберите роль, к которой вы хотите добавить членов.
2. Используйте **поле поиска** на левой стороне, чтобы найти человека, которого вы хотите добавить.
3. Выберите человека из результатов поиска.
4. Он будет добавлен в роль немедленно.

## Удаление пользователей из роли

1. Выберите роль, содержащую пользователя, которого вы хотите удалить.
2. Найдите человека в списке членов на левой стороне.
3. Нажмите **кнопку удаления** рядом с его именем.

## Настройка разрешений

Каждой роли может быть предоставлен доступ к определённым областям B1 Admin. Разрешения организованы по разделам:

- **Люди** — доступ к каталогу членов и записям о людях.
- **Пожертвования** — доступ к записям о пожертвованиях и управлению фондами.
- **Посещаемость** — доступ к отслеживанию посещаемости и отчётам.
- **Содержание** — доступ к управлению веб-сайтом и содержанием.
- И другие области по мере их появления.

Используйте флажки на правой стороне страницы ролей, чтобы включить или отключить доступ для каждой области.

:::warning
**Администраторы домена** имеют полный доступ ко всем областям вашей учётной записи ChurchApps. Их разрешения не могут быть изменены или ограничены. Используйте эту роль только для ваших наиболее доверенных администраторов.
:::

:::tip
Создавайте специфические роли, такие как "Казначей" только с доступом **Пожертвования** или "Волонтёр входа" только с доступом **Посещаемость**. Это следует принципу минимального привилегия и защищает ваши данные. Больше о том, как ChurchApps защищает вашу информацию, см. в [Безопасность данных](./data-security.md).
:::
