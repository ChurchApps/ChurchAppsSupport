# Роли и права доступа

<div class="article-intro">

Роли позволяют контролировать, к чему имеют доступ разные пользователи в вашей учётной записи ChurchApps. Вы можете создавать собственные роли для сотрудников, волонтёров и других членов команды, каждой из которых задан свой уровень доступа, чтобы сохранить безопасность ваших данных.

</div>

## Открытие ролей

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в левом верхнем углу) и разверните **Settings**.
2. Нажмите **Roles**.
3. На странице Roles отображаются все роли, определённые для вашей церкви. В столбце **Members** показано, сколько пользователей в каждой роли, а строка **(Everyone)** показывает **All users**.

## Структура страницы Roles

Страница Roles разделена на две панели:

- **Левая сторона** — список участников, назначенных выбранной роли.
- **Правая сторона** — настройки прав, которые можно задать для этой роли.

Нажмите на название любой роли, чтобы посмотреть и изменить её участников и права.

## Добавление пользователей в роль

1. Выберите роль, в которую хотите добавить участников.
2. Используйте **поле поиска** слева, чтобы найти нужного человека.
3. Выберите человека в результатах поиска.
4. Он сразу будет добавлен в роль.

## Удаление пользователей из роли

1. Выберите роль, в которой находится нужный пользователь.
2. Найдите человека в списке участников слева.
3. Нажмите кнопку **remove** рядом с его именем.

## Настройка прав

Каждой роли можно открыть доступ к определённым разделам B1 Admin. В панели **Edit Permissions** права сгруппированы в разделы, которые можно раскрыть, — например, **Attendance**, **Content**, **Donations**, **Forms and Plans**, **Lessons**, **Messaging**, **People and Groups» и **Tasks**. Введите текст в поле **Filter permissions**, чтобы показать только подходящие права.

Отметьте или снимите флажок с права, чтобы выдать или забрать его у роли. В заголовке каждого раздела показано, сколько прав из раздела есть у роли, например **2 of 5**, и этот счётчик обновляется по мере установки и снятия флажков.

### Права на пожертвования

В разделе **Donations** есть такие права:

- **View Donation Summaries** — видеть раздел Donations, включая страницы Summary, Batches, Funds, Campaigns и Giving Statements.
- **View Donations** — видеть отдельные пожертвования, например подарки внутри пакета.
- **Edit Donations** — полный контроль: добавлять, редактировать и удалять пожертвования и пакеты, а также [закрывать и открывать пакеты](../donations/batches.md#closing-and-reopening-a-batch).
- **Enter Donations** — добавлять пакеты и вносить, редактировать или удалять пожертвования, но только в пакетах, которые ещё открыты. Люди только с этим правом не могут удалять пакеты, закрывать или открывать их, а также изменять пожертвования, поступившие через онлайн-платежи.
- **Edit Settings** — управлять настройками пожертвований.

Пользователь с **Enter Donations», но без **View Donation Summaries**, видит в разделе **Donations** только страницу **Batches**. Дайте роли команды подсчёта оба права — **Enter Donations** и **View Donations», — чтобы они могли открыть пакет и увидеть пожертвования, которые они внесли. Подробности см. в разделе [Кто может изменять пакет](../donations/batches.md#who-can-change-a-batch).

### Только имена людей

В разделе **People and Groups** есть право **View People Names Only**. Используйте его для волонтёров, которым нужно находить людей по имени — например, чтобы выбрать кого-то в поле поиска, — без доступа ко всему каталогу. Только с этим правом человек:

- может искать людей по имени и видеть список недавно добавленных, но видит только имя, фото и статус членства каждого человека;
- не может искать по email, видеть контактные данные или открывать каталог **People**.

Сочетайте **View People Names Only** с **View Attendance** или **Edit Attendance» для волонтёров, которые отмечают посещаемость классов. Тогда пункт **People** в их меню открывает **Groups**, где они могут открыть список **All groups** и увидеть имена участников каждого класса и его сессии. С правом **Edit Attendance** они также могут [записывать посещаемость](../attendance/recording-attendance.md) и добавлять гостей, находя их по имени. Имена не являются ссылками на записи людей, а конфиденциальные группы остаются скрытыми, если волонтёр не является участником.

B1 Admin скрывает ссылки и кнопки, для которых у роли нет нужных прав. Например, список **All groups** доступен только тем, кто может редактировать группы, просматривать их участников или просматривать людей, либо тем, у кого есть **View People Names Only** вместе с **View Attendance** или **Edit Attendance» (остальные возвращаются на Dashboard). Настройка посещаемости появляется только с **View Attendance** или **Edit Services». Кнопка **Email** группы появляется только у людей с правом **Edit Group Members» (необходимым для отправки письма группе). Печать списка группы требует **View Group Members** или руководства этой группой, а удаление события календаря требует **Edit Content» (или отзыва собственного ожидающего запроса).

:::warning
**Domain Admins** имеют полный доступ ко всем разделам вашей учётной записи ChurchApps. Их права нельзя изменить или ограничить. Используйте эту роль только для самых доверенных администраторов.
:::

:::tip
Создавайте узкие роли, например «Казначей» только с доступом к **Donations», «Команда подсчёта» с **Enter Donations** и **View Donations» или «Волонтёр регистрации» только с доступом к **Attendance**. Это соответствует принципу минимальных привилегий и защищает ваши данные. Подробнее о защите ваших данных ChurchApps см. в [Data Security](./data-security.md).
:::
