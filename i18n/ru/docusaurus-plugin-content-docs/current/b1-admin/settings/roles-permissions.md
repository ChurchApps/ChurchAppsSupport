# Роли и разрешения

<div class="article-intro">

Роли позволяют контролировать, к чему имеют доступ разные пользователи в вашей учетной записи ChurchApps. Вы можете создавать собственные роли для сотрудников, волонтеров и других членов команды, каждая с собственным уровнем доступа, чтобы защитить ваши данные.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Нужен доступ Domain Admin или роль с разрешением на управление ролями
- Подготовьте список членов команды и разделов, к которым им нужен доступ
- Ознакомьтесь с доступными категориями разрешений ниже, чтобы спланировать роли

</div>

## Открытие ролей

1. В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу) и разверните **Settings**.
2. Нажмите **Roles**.
3. На странице Roles показаны все роли, определенные для вашей церкви. В столбце **Members** указано, сколько пользователей входит в каждую роль, а строка **(Everyone)** показывает **All users**.

## Структура страницы Roles

Страница Roles разделена на две панели:

- **Левая сторона** — список участников, назначенных выбранной роли.
- **Правая сторона** — настройки разрешений для этой роли.

Нажмите на название любой роли, чтобы просмотреть и настроить ее участников и разрешения.

## Добавление пользователей в роль

1. Выберите роль, в которую хотите добавить участников.
2. Используйте **поле поиска** слева, чтобы найти нужного человека.
3. Выберите человека из результатов поиска.
4. Он сразу будет добавлен в роль.

## Удаление пользователей из роли

1. Выберите роль, в которой находится нужный пользователь.
2. Найдите человека в списке участников слева.
3. Нажмите **кнопку удаления** рядом с его именем.

## Настройка разрешений

Каждой роли можно предоставить доступ к определенным разделам B1 Admin. В панели **Edit Permissions** разрешения сгруппированы в разделы, которые можно развернуть, например **Attendance**, **Content**, **Donations**, **Forms and Plans**, **Lessons**, **Messaging**, **People and Groups** и **Tasks**. Введите текст в поле **Filter permissions**, чтобы показать только подходящие разрешения.

Отметьте или снимите отметку с разрешения, чтобы предоставить его роли или отозвать. У каждого заголовка раздела указано, сколько разрешений из раздела есть у роли, например **2 of 5**; это число обновляется по мере установки и снятия отметок.

### Разрешения раздела Donations

В разделе **Donations** есть следующие разрешения:

- **View Donation Summaries** — просмотр раздела Donations, включая страницы Summary, Batches, Funds, Campaigns и Giving Statements.
- **View Donations** — просмотр отдельных пожертвований, например подарков внутри пачки (batch).
- **Edit Donations** — полный контроль: добавление, редактирование и удаление пожертвований и пачек, а также [закрытие и повторное открытие пачек](../donations/batches.md#closing-and-reopening-a-batch).
- **Enter Donations** — добавление пачек и ввод, редактирование или удаление пожертвований, но только в пачках, которые еще открыты. Люди только с этим разрешением не могут удалять пачки, закрывать или открывать их повторно и изменять подарки, поступившие через онлайн-пожертвования.
- **Edit Settings** — управление настройками пожертвований.

Пользователь с **Enter Donations**, но без **View Donation Summaries**, видит только страницу **Batches** в разделе **Donations**. Команде счетчиков дайте и **Enter Donations**, и **View Donations**, чтобы они могли открыть пачку и увидеть подарки, которые ввели. Подробнее см. [Кто может изменять пачку](../donations/batches.md#who-can-change-a-batch).

### Только имена людей

В разделе **People and Groups** есть разрешение **View People Names Only**. Используйте его для волонтеров, которым нужно находить людей по имени — например, выбирать человека в поле поиска — без доступа к полному каталогу. Только с этим разрешением человек:

- Может искать людей по имени и видеть список недавно добавленных людей, но видит только имя, фото и статус членства каждого человека
- Не может искать по электронной почте, видеть контактные данные или открывать каталог **People**

Сочетайте **View People Names Only** с **View Attendance** или **Edit Attendance** для волонтеров, которые ведут посещаемость классов. Пункт **People** в их меню тогда открывает **Groups**, где они могут открыть список **All groups** и увидеть имена участников и занятия каждого класса. С **Edit Attendance** они также могут [отмечать посещаемость](../attendance/recording-attendance.md) и добавлять посетителей, находя их по имени. Имена не являются ссылками на записи людей, а конфиденциальные группы остаются скрытыми, если волонтер не является их участником.

B1 Admin скрывает ссылки и кнопки, для которых у роли нет нужных разрешений. Например, список **All groups** доступен только тем, кто может редактировать группы, просматривать участников групп или просматривать людей, либо тем, у кого есть **View People Names Only** вместе с **View Attendance** или **Edit Attendance** (остальные перенаправляются на Dashboard). Настройка посещаемости появляется только с **View Attendance** или **Edit Services**; кнопка **Email** в группе отображается только тем, у кого есть **Edit Group Members** (разрешение, необходимое для отправки письма группе); для печати списка группы нужны **View Group Members** или руководство этой группой; а удаление события календаря требует **Edit Content** (или отзыва собственного ожидающего запроса).

:::warning
**Domain Admins** имеют полный доступ ко всем разделам вашей учетной записи ChurchApps. Их разрешения нельзя изменить или ограничить. Используйте эту роль только для самых доверенных администраторов.
:::

:::tip
Создавайте специальные роли, например «Казначей» только с доступом к **Donations**, «Команда счетчиков» с **Enter Donations** и **View Donations** или «Волонтер регистрации» только с доступом к **Attendance**. Это соответствует принципу наименьших привилегий и помогает защитить ваши данные. Подробнее о том, как ChurchApps защищает вашу информацию, см. [Безопасность данных](./data-security.md).
:::
