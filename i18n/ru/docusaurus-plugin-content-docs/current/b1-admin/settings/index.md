# Параметры

<div class="article-intro">

Раздел "Settings" в B1 Admin — это место, где вы настраиваете вашу церковь, управляете разрешениями пользователей и конфигурируете функции, специфичные для вашей организации.

</div>

## Основные параметры

В разделе Settings вы найдете:

### Управление церковью

Основная информация о вашей церкви, включая название, адрес, часовой пояс и логотип.

### Кампусы

Управляйте физическими местоположениями, где встречается ваша церковь.

### Пользователи

Управляйте учетными записями пользователей и назначайте роли администратора.

### Разрешения

Установите ограничения разрешений для пользователей в вашей системе.

### Интеграции

Подключайте сторонние сервисы, такие как Stripe, Mailchimp и другие.

### Пользовательские поля

Создавайте пользовательские поля для хранения дополнительной информации о людях.

## Типичные задачи

- Обновление информации о церкви
- Добавление новых администраторов
- Настройка платежных систем
- Управление интеграциями
- Создание пользовательских полей для вашей церкви
