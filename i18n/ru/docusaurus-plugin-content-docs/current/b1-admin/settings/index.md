# Параметры

<div class="article-intro">

Раздел "Параметры" — это место, где вы настраиваете учетную запись вашей церкви, брендирование и административные опции в B1 Admin. Отсюда вы можете управлять всем, от названия вашей церкви и поддомена до разрешений пользователей и конфигурации мобильного приложения.

</div>

## Что вы найдете здесь

Область Параметры организована в следующие подразделы:

1. **Параметры** — настройте основную информацию о вашей церкви, брендирование, поддомен, регион (формат даты и телефона), поставщика текстовых сообщений и хранилище файлов. Для деталей см. [Параметры церкви](./church-settings.md). Чтобы использовать ваше собственное имя домена (например, yourchurch.org), см. [Пользовательский домен](./custom-domain.md).
2. **Кампусы** — добавьте и управляйте несколькими физическими местоположениями для вашей церкви. После создания кампусы появляются в профилях людей, в установке посещаемости и на панели демографии. Доступно как карточка на главной странице Параметры, а не отдельный элемент навигации. Для деталей см. [Кампусы](./campuses.md).
3. **Пользовательские поля** — определите свои собственные поля для отслеживания людей (дата, число, ответ да/нет или список выбора), затем заполните их в профилях и ищите по ним. Также доступно как карточка на главной странице Параметры. Для деталей см. [Пользовательские поля](./custom-fields.md).
4. **Шаблоны писем** — сохраняйте многократно используемое содержание писем для отправки вручную или из рабочего процесса. Для деталей см. [Шаблоны писем](./email-templates.md).
5. **Администратор сервера** — доступ к расширенным инструментам администрирования для управления параметрами вашего сервера на уровне церкви.

:::info
Конфигурация **Мобильных приложений** и **Формы** теперь имеют свои собственные элементы навигации верхнего уровня — **Мобильный** и **Формы** (находятся в разделе **Люди**) — вместо размещения внутри Параметры. Для деталей см. [Параметры мобильного приложения](./mobile-app.md) и [Создание форм](/docs/b1-admin/forms/creating-forms).
:::

## Главная страница параметров

Когда вы впервые откроете страницу Параметры, вы увидите **название церкви** и **поддомен** вашей церкви, отображаемые в верхней части. Заголовок предоставляет кнопки быстрого доступа для общих задач:

- **Шаблоны писем** — переходите прямо к управлению шаблонами писем.
- **Журнал аудита** — просмотрите журнал изменений, внесенных в учетную запись вашей церкви.
- **Пакеты** — переходите прямо к пакетам пожертвований.
- **Импорт/Экспорт** — передачу данных между системами с использованием инструмента импорта/экспорта.

Ниже заголовка откройте раздел **Информация о церкви**, чтобы отредактировать название, адрес, контактную информацию и брендирование вашей церкви — см. [Параметры церкви](./church-settings.md). Для управления ролями пользователей откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) и выберите **Параметры > Роли** — см. [Роли и разрешения](./roles-permissions.md).

:::tip
Начните с настройки названия вашей церкви и брендирования в разделе **Информация о церкви**, затем установите [Роли](./roles-permissions.md), чтобы пригласить членов вашей команды с правильным уровнем доступа.
:::

:::info
Для информации о том, как ваши данные защищены, см. [Безопасность данных](./data-security.md).
:::
