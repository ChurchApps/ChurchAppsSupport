# Собственный домен

<div class="article-intro">

Вы можете направить собственный домен (например, **`www.yourchurch.org`**) на ваш сайт B1, чтобы гости открывали его по настоящему веб-адресу вашей церкви, а не по адресу по умолчанию yourchurch.b1.church.

</div>

## Шаг 1 — Сначала добавьте DNS-запись {#step-1--add-the-dns-record-first}

Прежде чем добавлять домен в B1, нужно направить его на серверы B1 у вашего регистратора доменов (GoDaddy, Namecheap, Cloudflare и др.).

Добавьте одну из этих записей — предпочтительна CNAME:

| Тип | Хост | Значение |
|------|------|-------|
| CNAME | `www` | `proxy.b1.church` |
| A | `yourchurch.org` | `3.23.251.61` |

Используйте **CNAME** для адреса `www`. Используйте **A-запись**, если ваш регистратор не поддерживает CNAME для корневого домена (без www) или если вы хотите, чтобы корневой домен тоже работал.

Изменения DNS могут вступать в силу от нескольких минут до нескольких часов.

## Шаг 2 — Добавьте домен в B1 {#step-2--add-the-domain-in-b1}

Когда DNS уже указывает на B1:

1. Перейдите в **Settings** в B1 Admin.
2. Нажмите **Domains** в списке слева, затем нажмите **Edit** в разделе **Domains**.
3. Введите свой домен в поле и нажмите **Save**.

Нажимать кнопку **+** заранее не нужно — домен, введённый в поле, добавляется при сохранении. Используйте **+** (или клавишу **Enter**), когда хотите добавить несколько доменов в список перед сохранением. Вводите только домен, например `www.yourchurch.org`, — без `https://` и без пути к странице.

Если у вашей церкви несколько сайтов, у каждого домена появляется выпадающий список **Website**. Оставьте **Main Website** или выберите сайт, который должен открываться по этому домену.

Чтобы удалить домен, нажмите значок удаления в его строке и нажмите **Save**.

B1 обрабатывает SSL автоматически — покупать сертификат не нужно.

:::warning
B1 сохраняет домен, даже если DNS-записи ещё не настроены, но домен не будет открывать ваш сайт, и B1 не сможет выпустить для него SSL-сертификат, пока DNS не будет указывать на B1. Сначала настройте DNS. Домен, который уже используется другой церковью, добавить нельзя.
:::

## Проверка работы {#checking-if-its-working}

После сохранения откройте свой домен в браузере. Если загружается ваш сайт B1, всё готово. Если появляется ошибка, DNS, возможно, ещё распространяется — подождите несколько минут и попробуйте снова.

Проверить распространение DNS можно также на [dnschecker.org](https://dnschecker.org) — введите свой домен и убедитесь, что там отображается ваша CNAME- или A-запись.
