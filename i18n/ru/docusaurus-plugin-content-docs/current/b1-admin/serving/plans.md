# Планы служения

<div class="article-intro">

Планы служения позволяют вам планировать, кто будет служить на предстоящих службах и событиях. Создавайте планы для ваших добровольцев, автоматически отправляйте напоминания и отслеживайте, кто согласился служить.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам необходимо создать [типы планов](plan-templates.md) перед тем как создавать планы
- Убедитесь, что у вас есть люди в вашей системе для планирования
- Для начала см. [Добавление людей](../people/adding-people.md)

</div>

## Создание плана служения

1. Перейдите в раздел **Serving** в B1 Admin
2. Нажмите на вкладку **Plans**
3. Нажмите **New Plan**
4. Выберите типы участников для вашего плана (например, "Worship Team", "Sound Tech")
5. Установите дату и время служения
6. Нажмите **Save**

## Назначение добровольцев

После создания плана добавьте добровольцев:

1. Откройте план
2. Для каждой роли нажмите **Add Volunteer**
3. Выберите человека из вашей базы данных
4. Выберите их роль/позицию
5. Нажмите **Save**

Добровольцы получат уведомление о своем назначении и смогут принять или отклонить.

## Отправка напоминаний

Отправляйте автоматические напоминания добровольцам:

1. На плане нажмите **Send Reminders**
2. Выберите когда отправить напоминание (1 день перед, день события и т.д.)
3. Нажмите **Send**

## Отслеживание ответов

На плане вы можете видеть:

- Кто принял приглашение служить
- Кто еще не ответил
- Кто отклонил

Используйте эту информацию для последующего наблюдения или поиска замены.
