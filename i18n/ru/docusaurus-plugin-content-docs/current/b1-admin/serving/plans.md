# Планы обслуживания

<div class="article-intro">

Планы обслуживания организуют, кто служит и когда. Каждый план привязан к определенной дате и служению, что упрощает координирование ваших волонтерских команд неделя за неделей и обеспечение полной укомплектования каждой услуги.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Настройте ваши служения и команды в области Serving
- Убедитесь, что волонтеры были добавлены в ваш [каталог людей](../people/adding-people.md) и назначены командам

</div>

## Доступ к плану

1. Перейдите в **Serving** из главного меню.
2. Выберите **ministry tab** в верхней части страницы.
3. Нажмите на **plan type** для просмотра списка планов для этого типа.
4. Нажмите на конкретный план для его открытия.

:::info
Полный доступ администратора не требуется для управления планами. Любой, кто является членом служения, может перейти в Serving и создавать, редактировать и планировать планы для своего собственного служения без необходимости разрешения Plans Edit. Редакторы с ролью Plans Edit могут управлять планами во всех служениях.
:::

## Создание плана

1. Из представления типа плана нажмите **New Plan**.
2. Дайте плану имя или используйте дату в качестве имени. Выберите **date** для услуги.
3. Если вы хотели бы скопировать с предыдущего плана, выберите только позиции или позиции и назначения. Если вы не хотите копировать, просто ничего не выбирайте. Вы также можете скопировать порядок услуги из моего предыдущего плана.
4. Сохраните план. Теперь вы можете начать назначать членов команды и создавать [порядок услуги](./service-order.md).

## Страница деталей плана

Когда вы открываете план, вы увидите две вкладки:

- **Assignments** — Управление, какие члены команды назначены этому плану. Вы можете добавить людей из ваших существующих команд и увидеть, кто подтвердил или все еще в ожидании.
- **[Service Order](./service-order.md)** — Создавайте порядок услуги с элементами, такими как гимны поклонения, молитвы, объявления и проповедь.

## Назначение членов команды

1. Откройте план и перейдите на вкладку **Assignments**.
2. Нажмите на **add Position** для его расширения. Заполните информацию в форме добавления позиции. Для имени категории добавьте любую категорию, которая вам нравится.
3. Нажмите на **People Needed** и выберите волонтеров для заполнения этой позиции.
4. Добавьте членов из вашего ростра команды, нажав **Add**.
5. Назначенные члены появятся под своей командой со статусом их назначения.
6. Нажмите notify volunteers для уведомления их в приложении B1 или по электронной почте.

Каждая позиция показывает чип подсчета (например, "2/3"), чтобы вы могли видеть, сколько мест заполнено с первого взгляда. В верхней части вкладки Assignments, полоса прогресса и чип сводки ("X of Y positions filled") показывают ваше общее укомплектование плана, переключаясь на **Fully staffed** один раз каждая позиция покрыта.

:::tip
Настройте ваши команды в параметрах служения перед созданием планов. Таким образом, у вас будет готовый пул волонтеров для назначения.
:::

## Параметры плана

Каждый план имеет дополнительные параметры, которые вы можете настроить, нажав значок редактирования (карандаша) на плане. Они включают:

- **Signup Deadline** — количество часов до услуги, когда волонтерская регистрация закрывается. Введите отрицательное число, чтобы держать регистрацию открытой после времени начала услуги.
- **Show volunteer names on signup page** — когда отмечено, волонтеры могут видеть, кто еще уже зарегистрирован для каждой позиции.
- **Penciled in** — скрывает назначения от волонтеров до тех пор, пока вы не будете готовы опубликовать расписание.
- **Automatically schedule a replacement when a volunteer declines** — когда отмечено, если назначенный волонтер отклоняет свою позицию, B1 автоматически свяжется со следующим доступным человеком в ростре команды и спросит, могут ли они служить. Это продолжается вниз по списку до тех пор, пока кто-то не примет, держа ваши позиции заполненными без ручного последующего действия.

## Напоминания волонтерам

B1 может автоматически напоминать волонтерам об услугах, на которые они запланированы, чтобы вам не пришлось гнаться за вашей командой каждую неделю. Напоминания идут **everyone scheduled** — и тем, кто подтвердил, и тем, кто еще не ответил — по электронной почте и как уведомление в приложении/push. Каждое напоминание включает позицию волонтера, дату услуги, примечания плана и вашу пользовательское сообщение.

Сроки и содержание напоминаний установлены для каждого **plan type**, так что каждый тип услуги может сохранить свое собственное расписание.

1. Из области **Serving** выберите служение, которое содержит тип плана.
2. Нажмите **edit (pencil) icon** рядом с типом плана.
3. В разделе **Reminders** установите:
   - **Reminder days before service** — список, разделенный запятыми, сколько дней впереди отправлять, например `7,1,0`. Используйте `0` для отправки напоминания в день услуги. Оставьте это поле пустым для отключения напоминаний для этого типа плана.
   - **Custom reminder message** *(optional)* — дополнительный текст, добавляемый к напоминанию, такой как "Arrive 30 minutes early to rehearse".
4. Сохраните тип плана.

Новые типы плана напоминают волонтеры **2 days before** каждой услуги по умолчанию, пока вы не измените это.

:::tip
Волонтеры, которые еще не подтвердили, получат кнопки **Accept** и **Decline** прямо внутри письма напоминания, чтобы они могли ответить без входа.
:::

:::info
Каждое напоминание отправляется один раз. Планы, которые все еще имеют карандаш (еще не отправлены команде), не запускают напоминания.
:::

## Связывание групп с типом плана

Ниже списка планов на странице типа плана, раздел **Groups** позволяет вам решить, какие группы могут видеть планы для этого типа плана из портала членов. Это быстрый способ поверхности предстоящих услуг для правых команд без предоставления им доступа администратора.

1. На странице типа плана, прокрутитесь вниз до раздела **Groups**.
2. Нажмите **Add Group** и выберите группу из раскрывающегося меню.
3. В столбце **Shows** выберите, должны ли члены этой группы видеть **Past**, **Future** или **Both** планы для этого типа плана.
4. Повторите для связи дополнительных групп или нажмите значок мусора для удаления группы.

:::info
Только группы, отмеченные как **Standard**, появляются в сборщике. Члены связанной группы автоматически видят планы типа этого плана на вкладке [Plans](/docs/b1-church/plans/) на портале членов B1 — ограничено окном past/future/both, который вы выбрали.
:::

## Планы печати

Вы можете распечатать план для распределения вашей команде. Откройте план, откройте вкладку порядка услуги и используйте опцию **Print** для создания печатной версии, которая включает назначения и порядок услуги. Это полезно для раздачи на репетициях или размещения в общей области.

:::info
Планы организованы по служению. Убедитесь, что вы на правой вкладке служения перед созданием или просмотром планов.
:::

## Следующие шаги

- Используйте [Plans Overview](./plans-overview.md) для просмотра всех предстоящих назначений на нескольких неделях в одной сетке и обнаружения незаполненных позиций — и назначения волонтеров непосредственно из сетки
- Сохраняйте структуру плана как [Plan Template](./plan-templates.md), чтобы вы могли штамповать его на будущих планах одним щелчком

- Добавляйте [songs](./songs.md) из вашей библиотеки непосредственно в порядок услуги
- Используйте [Tasks](./tasks.md) для назначения действий последующего выполнения членам команды
