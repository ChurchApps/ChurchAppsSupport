# Рабочие процессы

<div class="article-intro">

Рабочие процессы позволяют вам автоматизировать назначение добровольцев и управление планированием служений. Создавайте правила, которые автоматически назначают правильных людей правильным ролям.

</div>

## Создание рабочего процесса

1. Перейдите в раздел **Serving** в B1 Admin
2. Нажмите на вкладку **Workflows**
3. Нажмите **New Workflow**
4. Дайте рабочему процессу имя
5. Выберите тип плана для применения
6. Установите правила для автоматического назначения

## Правила рабочего процесса

Вы можете установить правила на основе:

- **Role** — какую роль нужно заполнить
- **Skills** — какие навыки требуются
- **Availability** — проверьте календарь доступности добровольца
- **Preferences** — уважайте предпочтения добровольца

## Активизация рабочего процесса

1. На рабочем процессе нажмите **Activate**
2. B1 будет использовать этот рабочий процесс при создании новых планов
3. При каждом создании плана выбранного типа B1 будет автоматически назначать добровольцев в соответствии с правилами

## Редактирование или отключение

Вы можете отредактировать или отключить рабочий процесс в любое время:

1. Откройте рабочий процесс
2. Нажмите **Edit** для изменения правил или **Deactivate** для отключения

## Полезные советы

- Начните с простых правил и усложняйте по мере необходимости
- Регулярно просматривайте рабочие процессы, чтобы убедиться, что они работают правильно
- Оставляйте возможность для ручного переопределения при необходимости
