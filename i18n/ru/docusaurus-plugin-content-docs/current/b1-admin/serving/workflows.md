# Рабочие процессы

<div class="article-intro">

Рабочие процессы перемещают людей через ряд шагов на визуальной доске. Каждый человек становится карточкой, которая путешествует от одного шага к следующему -- от последующего действия первого посетителя, к процессу членства, к благодарности первого жертвователя, и все остальное, где вам нужно отслеживать много людей через один и тот же набор этапов. Шаг может попросить волонтера что-то сделать (сделать звонок, поговорить) **и** запустить автоматические действия самостоятельно -- отправить письмо, подождать несколько дней, добавить человека в группу -- поэтому рабочие процессы обрабатывают как человеческие следующие действия, так и работа вокруг них. Рабочие процессы расширяют [Tasks](./tasks.md) на доску drag-and-drop Kanban, поэтому ничто и никто не проходит между трещинами.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Убедитесь, что люди, которых вы хотите отслеживать, существуют в B1 Admin
- Познакомьтесь с тем, как работают [Tasks](./tasks.md), так как каждая карточка на доске - это задача
- Для использования действия **Send email**, сначала создайте шаблоны электронной почты, которые вы хотите отправить (управляются под **Messaging → Manage Templates**)
- Вам понадобится соответствующее разрешение Tasks. Просмотр, редактирование карточек и управление рабочими процессами - это отдельные уровни разрешений (см. [Roles & Permissions](../settings/roles-permissions.md))

</div>

## Просмотр рабочих процессов

Перейдите к **Serving**, откройте область **Tasks** и выберите **Workflows** из меню. Вы увидите ваши рабочие процессы, перечисленные и сгруппированные по категориям, с активными рабочими процессами выделены. Нажмите на любой рабочий процесс, чтобы открыть его доску.

## Создание рабочего процесса

1. На странице Workflows нажмите **Add Workflow**.
2. Выберите, как начать:
   - **Blank workflow** -- начните с нуля и создайте свои собственные шаги.
   - **From a template** -- начните с готового набора шагов, которые вы можете редактировать. Встроенные шаблоны включают:
     - **New Visitor Follow-up** -- Send welcome email → Personal phone call → Invite to next step → Connected
     - **Membership Class** -- Express interest → Register for class → Attend class → Complete membership
     - **First-time Giver Thank-you** -- Send thank-you note → Share giving impact → Stewarded
3. Дайте рабочему процессу **Name**.
4. При необходимости назначьте **Category**, чтобы сгруппировать связанные рабочие процессы вместе. Вы можете создать новую категорию прямо из раскрывающегося списка.
5. Оставьте рабочий процесс **Active**, чтобы люди могли быть добавлены в него, или установите его как **Inactive**, чтобы скрыть его из списков добавления в рабочий процесс.
6. Нажмите **Save**.

:::tip
Используйте кнопку **Duplicate** в списке рабочих процессов для копирования существующего рабочего процесса -- включая его шаги, автоматические действия и маршрутизацию -- как начальную точку для новой.
:::

## Построение доски с шагами

Каждая доска рабочего процесса состоит из **steps**, показанных как столбцы слева направо. Откройте рабочий процесс и используйте **Add Step** для создания каждого этапа вашего процесса.

Когда вы добавляете или редактируете шаг, вы можете настроить:

- **Step Name** -- название столбца (например, "Welcome Call" или "Awaiting Registration").
- **Due in (days)** -- автоматически устанавливает срок выполнения, когда карточка попадает на этот шаг. Карточки, прошедшие свой срок, помечены как **Overdue**.
- **Default assignee** -- человек или группа новых карточек на этот шаг автоматически назначаются.
- **Automated actions** -- вещи, которые система делает самостоятельно, когда карточка приходит (см. ниже).
- **Routing** -- где карточка идет, когда она покидает шаг (см. [Routing](#routing-cards-with-outcomes-and-conditions)).

Перетащите столбцы шагов в порядок, который соответствует вашему процессу. Порядок также определяет путь по умолчанию, который карточка берет, когда не применяется другая маршрутизация.

:::info
Сначала сохраните новый шаг. Автоматические действия и маршрутизация присоединяются к шагу, поэтому редактор разблокирует эти разделы, когда шаг существует.
:::

## Автоматические действия

Каждый шаг может нести список **automated actions**, которые запускаются сами по себе в момент, когда карточка **enters** шаг -- прежде чем кто-то коснется его. Таким образом шаг оборачивает волонтера *и* позаботился о рутинной работе вокруг следующего действия.

В редакторе шагов откройте **Automated actions**, нажмите **Add Action**, выберите тип, заполните его параметры и нажмите значок сохранения на этом действии. Добавьте столько, сколько вам нужно; они запускаются **top to bottom in order**.

| Действие | Что оно делает |
|---|---|
| **Send email** | Отправляет человеку шаблон электронной почты по вашему выбору. Вы можете переопределить линию темы. |
| **Wait** | Приостанавливает карточку на несколько дней перед продолжением (см. ниже). |
| **Add to group** | Добавляет человека в [группу](../groups/index.md), которую вы выбираете. |
| **Add to workflow** | Запускает человека на другой рабочий процесс -- полезно для передачи между процессами. |
| **Add note** | Записывает примечание в историю карточки. |
| **Set field** | Обновляет поле в записи человека: Membership Status, Marital Status, Gender, City, State, или Zip. |
| **Webhook** | Отправляет детали карточки на внешний веб-адрес (URL), который вы предоставляете, для подключения к другим системам. |

После завершения всех действий шага карточка **rests on that step**, поэтому человек может работать с ней -- если только шаг не имеет автоматического маршрута, который движет его вперед (см. [Fully automated steps](#fully-automated-steps)).
