# Проверка плана и уведомления волонтёров

<div class="article-intro">

B1 Admin автоматически проверяет ваши планы до воскресенья: незаполненные позиции, конфликты расписания и волонтёров, которые отметили эту дату как недоступную. Когда всё в порядке, вы можете уведомить всю команду одним нажатием.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Создайте [план служения](./plans.md) и назначьте волонтёров на позиции
- Добавьте в план [время служений](./plans.md), чтобы проверка могла находить пересечения
- Убедитесь, что у волонтёров установлено [приложение B1 App](../../b1-church/getting-started/installing-pwa.md), чтобы они могли получать push-уведомления

</div>

## Панель проверки

У каждого плана есть панель **Проверка**, которая запускается автоматически по мере составления плана. Она проверяет три вещи:

### Незаполненные позиции
Если на позицию требуется больше людей, чем назначено сейчас, панель проверки показывает, сколько ещё нужно, например: *«Звукорежиссёр: нужен ещё 1 человек».* Так вы сразу видите, укомплектован ли план полностью до наступления недели.

### Конфликты расписания
Если волонтёр назначен на две позиции, которые пересекаются по времени в одном плане, панель проверки отмечает конфликт, например: *«Jane Smith: конфликт времени между Руководителем прославления и Регистрацией в детском служении во время воскресного служения».* Это помогает заметить двойное бронирование до того, как оно превратится в проблему воскресным утром.

### Даты недоступности
Волонтёры могут указать в приложении B1 App даты, когда они недоступны. Если человек назначен на план, который попадает в одну из таких дат, панель проверки автоматически показывает конфликт, чтобы вы могли найти замену.

### Конфликты между планами
Проверка также охватывает все ваши планы одновременно. Если один и тот же волонтёр назначен в два разных плана, которые пересекаются по времени (например, служение в 9:00 и служение в 10:00, которые оба идут до 10:30), B1 Admin отметит этого человека как двойное бронирование между планами.

:::tip
Ничего запускать не нужно: проверка обновляется автоматически каждый раз, когда вы добавляете или меняете назначение. Просто следите за панелью по ходу составления плана.
:::

## Уведомление волонтёров

Когда план готов, вы можете уведомить всех назначенных волонтёров одновременно прямо из панели проверки.

1. Откройте план и прокрутите до панели **Проверка**
2. Если есть волонтёры, которых ещё не уведомили, вы увидите ссылку с их количеством (например, *«Уведомить 8 волонтёров»*)
3. Нажмите ссылку, чтобы отправить push-уведомления всем, кого ещё не уведомили
4. Волонтёры получат на телефон уведомление о том, что их назначили, и с просьбой подтвердить назначение

:::info
Учитываются только волонтёры, которых ещё не уведомили. Если вы добавите кого-то в план позже, ссылка появится снова, и вы сможете уведомить нового участника, не отправляя повторных уведомлений остальной команде.
:::

### Планы с процессом подтверждения

Если в настройках плана указан [процесс подтверждения](./workflows.md#serving-assignment-confirmations), панель показывает: *«Новые запросы используют процесс подтверждения. Оповещения в приложении остаются включёнными. Напоминания прекращаются, когда каждый запрос принят или отклонён».* В этом случае:

- Ссылка уведомления учитывает только волонтёров, которых ещё не уведомили и которые ещё не ответили.
- При нажатии отправляется обычное оповещение в приложении и создаётся по одной карточке на каждый запрос на доске процесса. Затем процесс отправляет напоминания по электронной почте и SMS и, если нужно, передаёт запрос тому, кто должен позвонить.
- План должен быть опубликован (а не в режиме черновика), а процесс должен быть активен. Иначе панель покажет: *«Не удалось отправить запросы. Проверьте, что выбранный процесс активен и план опубликован, затем попробуйте снова».*

:::warning
Чтобы получать push-уведомления, волонтёры должны установить приложение B1 App на главный экран и разрешить уведомления. Инструкции по настройке см. в разделе [Установка как приложение (PWA)](../../b1-church/getting-started/installing-pwa.md).
:::
