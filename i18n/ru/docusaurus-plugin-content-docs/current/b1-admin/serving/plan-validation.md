# Проверка планов и уведомления волонтеров

<div class="article-intro">

B1 Admin автоматически проверяет ваши планы на наличие проблем до воскресенья — незаполненные позиции, конфликты расписания и волонтеров, которые отметили эту дату как недоступную. Когда всё в порядке, вы можете уведомить всю команду одним нажатием.

</div>

<div class="prereqs">
<h4>С чего начать</h4>

- Создайте [план служения](./plans.md) и назначьте волонтеров на позиции
- Добавьте в план [время служений](./plans.md), чтобы проверка конфликтов могла находить пересечения
- Убедитесь, что у волонтеров установлено приложение B1 Mobile, чтобы они получали push-уведомления

</div>

## Панель проверки

У каждого плана есть панель **Проверка**, которая запускается автоматически по мере его составления. Она проверяет три вещи:

### Незаполненные позиции
Если на позицию требуется больше людей, чем назначено сейчас, панель проверки перечисляет, что ещё нужно — например, *«Звукорежиссер: нужен ещё 1 человек».* Так вы сразу видите, укомплектован ли план полностью до наступления недели.

### Конфликты расписания
Если волонтер назначен на две позиции, которые пересекаются по времени в одном плане, панель проверки отмечает конфликт — например, *«Джейн Смит: конфликт по времени между Ведущим богослужения и Регистрацией детей во время воскресного служения».* Так двойные бронирования обнаруживаются до того, как они станут проблемой в воскресное утро.

### Даты недоступности
Волонтеры могут указать в B1 Mobile даты, когда они недоступны. Если кто-то назначен на план, который попадает в одну из его дат недоступности, панель проверки автоматически показывает конфликт, чтобы вы могли найти замену.

### Конфликты между планами
Проверка также охватывает все ваши планы сразу. Если один и тот же волонтер назначен в два разных плана, которые пересекаются по времени — например, на служение в 9:00 и на служение в 10:00, которые оба идут до 10:30, — B1 Admin отметит этого человека как двойно занятого в разных планах.

:::tip
Запускать проверку не нужно — она обновляется автоматически при каждом добавлении или изменении назначения. Просто следите за панелью по мере составления плана.
:::

## Уведомление волонтеров

Когда план готов, вы можете уведомить всех назначенных волонтеров сразу прямо из панели проверки.

1. Откройте план и прокрутите до панели **Проверка**
2. Если есть волонтеры, которые ещё не уведомлены, вы увидите ссылку с количеством тех, кого нужно уведомить (например, *«Уведомить 8 волонтеров»*)
3. Нажмите ссылку, чтобы отправить push-уведомления всем, кому ещё не отправляли их
4. Волонтеры получат уведомление на телефон, в котором сообщается, что они назначены, и предлагается подтвердить назначение

:::info
Учитываются только волонтеры, которые ещё не были уведомлены. Если вы добавите кого-то в план позже, ссылка появится снова, и вы сможете уведомить нового участника, не уведомляя повторно остальную команду.
:::

### Планы с процессом подтверждения

Если в настройках плана указан [процесс подтверждения](./workflows.md#serving-assignment-confirmations), панель показывает *«Новые запросы используют процесс подтверждения. Уведомления в приложении остаются включенными. Напоминания прекращаются, когда каждый запрос принят или отклонен».* В этом случае:

- Ссылка на уведомление учитывает только волонтеров, которые ещё не были уведомлены и ещё не ответили.
- При нажатии отправляется обычное уведомление в приложении и создаётся по одной карточке на каждый запрос на доске процесса. Затем процесс отправляет напоминания по электронной почте и SMS и, если нужно, передаёт запрос тому, кто должен позвонить.
- План должен быть опубликован (а не в статусе «карандашом»), а процесс должен быть активен. Иначе панель покажет *«Не удалось отправить запросы. Проверьте, что выбранный процесс активен и план опубликован, и повторите попытку».*

:::warning
Волонтеры должны установить мобильное приложение B1.church (PWA на главном экране или устаревшее нативное приложение B1 Mobile для тех, кто его ещё использует) и включить уведомления, чтобы получать push-уведомления. Инструкции по настройке см. в разделе [Установка как приложения (PWA)](/docs/b1-church/getting-started/installing-pwa).
:::
