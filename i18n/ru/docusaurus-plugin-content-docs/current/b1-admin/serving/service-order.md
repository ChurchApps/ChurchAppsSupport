# Порядок служения

<div class="article-intro">

Порядок служения позволяет вам организовать и спланировать потоки вашей воскресной службы, от открытия до закрытия. Структурируйте вашу службу с музыкой, проповедями, объявлениями и другими элементами.

</div>

## Создание порядка служения

1. Перейдите в раздел **Serving** в B1 Admin
2. Нажмите на вкладку **Service Order**
3. Выберите дату службы
4. Нажмите **New Order**

## Добавление элементов служения

Вы можете добавить различные типы элементов:

- **Songs** — добавляйте песни из вашей библиотеки
- **Message** — добавляйте информацию о проповедьб
- **Prayer** — добавляйте молитвы
- **Announcements** — добавляйте объявления
- **Custom Item** — добавляйте пользовательские элементы

Для каждого элемента установите время и другие детали.

## Управление временем

- Установите ожидаемую длительность каждого элемента
- B1 будет отслеживать общее время службы
- Используйте это для обеспечения того, чтобы служба заканчивалась вовремя

## Соделитесь с командой

Вы можете поделиться порядком служения с вашей командой:

1. На порядке служения нажмите **Share**
2. Выберите членов команды для отправки
3. Нажмите **Send**

Они получат уведомление и смогут просмотреть порядок служения.

## Печать порядка служения

1. На порядке служения нажмите **Print**
2. Используйте стандартный диалог печати вашего браузера

Порядок служения отформатирован для легкой печати для раздачи членам команды.
