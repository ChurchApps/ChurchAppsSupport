# Задачи

<div class="article-intro">

Задачи позволяют вам назначать элементы действия людям или группам в вашей церкви. Будь то одноразовое дело или постоянная ответственность, задачи помогают вам отслеживать, что нужно сделать и кто несёт ответственность, чтобы ничего не было упущено.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Убедитесь, что люди или [группы](../groups/creating-groups.md), которым вы хотите назначить задачи, существуют в B1 Admin
- В [Jump меню](../introduction.md#getting-around-with-the-jump-menu) выберите **Служение > Моя работа**, чтобы увидеть задачи

</div>

## Просмотр задач

В меню Jump выберите **Служение > Моя работа** (или найдите "Моя работа"). Вы увидите список ваших открытых задач. Каждая задача показывает свой заголовок, назначенного и статус.

:::tip
По умолчанию отображаются только открытые задачи. Переключите **Показать закрытые**, чтобы также увидеть завершённые задачи.
:::

## Создание задачи

1. На странице задач нажмите **Добавить задачу**.
2. Введите **название** для задачи.
3. Нажмите на поле **Назначить** и введите имя человека, или переключитесь на **Группа** и введите название группы.
4. Нажмите **Поиск** и выберите человека или группу из результатов.
5. Добавьте **примечание** с любыми деталями или инструкциями для назначенного.
6. Нажмите **Сохранить**.

Задача теперь появится в списке задач и будет видна назначенному на его панели управления и мобильном приложении.

## Управление задачей

Нажмите на любую задачу, чтобы открыть её страницу деталей. Отсюда вы можете:

- **Изменить статус** -- переключитесь между **Открытой** и **Закрытой**, используя раскрывающееся меню статуса.
- **Переназначить задачу** -- обновить назначенного на другого человека или группу.
- **Добавить примечания** -- включить дополнительную информацию или обновления для назначенного.
- **Редактировать название** -- обновить название задачи по мере необходимости.

## Жизненный цикл задачи

1. Новая задача начинается со статусом **Открытой**.
2. Назначенный получает уведомление и может просмотреть задачу из своей панели управления, **Служение > Моя работа** или мобильного приложения.
3. После завершения работы назначенный (или администратор) меняет статус на **Закрытую**.
4. Закрытые задачи удаляются из представления по умолчанию, но все ещё могут быть доступны, включив **Показать закрытые**.

:::info
B1 Admin больше не создает повторяющиеся задачи по расписанию. Для повторного последующего действия с людьми используйте [рабочий процесс](./workflows.md) с [триггером расписания](./workflows.md#schedule-triggers).
:::

:::tip
Когда вам нужно переместить многих людей через один и тот же набор этапов -- такие как последующее действие для новых посетителей или процесс членства -- используйте [рабочие процессы](./workflows.md). Рабочие процессы преобразуют задачи в карточки на доске с перетаскиванием с шагами, сроками и маршрутизацией.
:::

:::info
Некоторые задачи создаются автоматически другими частями B1 и открываются в специальную карточку проверки вместо стандартного представления примечание/переназначение -- [запросы присоединения к группе](../groups/group-join-requests.md#approving-from-the-tasks-page), [запросы изменения профиля](../profile/approving-profile-changes.md) и [запросы удаления учётной записи](../profile/account-deletion.md) все работают таким образом.
:::

## Следующие шаги

- Перемещайте людей через многошаговый процесс с [рабочими процессами](./workflows.md)
- Используйте [рабочие процессы](./workflows.md) для автоматического перемещения людей через повторяемые процессы
- Используйте задачи наряду с [планами богослужений](./plans.md) для отслеживания элементов действия подготовки богослужения
