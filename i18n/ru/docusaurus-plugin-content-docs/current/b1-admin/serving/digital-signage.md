# Цифровая информационная панель

<div class="article-intro">

Отправьте контент вашего урока на экран телевизора в вестибюле или коридоре, используя цифровую информационную панель. Каждый тип плана получает URL канала, который всегда воспроизводит контент текущего плана, поэтому нет необходимости обновлять неделю к неделе.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Установите [план type](./plans.md) с [Lessons.church](../content/lessons.md) или другим контентом урока по расписанию
- Имейте учетную запись [SignPresenter](https://www.signpresenter.com) и устройство, установленное для его отображения

</div>

## Получение URL канала

1. Перейдите к **Serving** и откройте служение, содержащее тип вашего плана.
2. Нажмите кнопку **Digital Signage** (значок RSS) на странице типа плана.
3. Скопируйте URL канала, показанный в диалоговом окне.

:::info
URL канала привязан к типу плана, а не к одному плану. Он автоматически отслеживает любой план, запланированный как текущий для этого типа плана, поэтому вам нужно установить его только один раз.
:::

## Подключение к SignPresenter

Канал построен для работы с [SignPresenter](https://www.signpresenter.com), приложение цифровой информационной панели третьей стороны. Вставьте скопированный URL в SignPresenter как внешний канал, чтобы отобразить текущий контент вашего урока на подключенном экране.

Для пошагового руководства по настройке внутри SignPresenter см. [SignPresenter's Lessons.church guide](https://support.signpresenter.com/topics/lessons-dot-church.html).

## Следующие шаги

- Управляйте планами, которые подают это отображение информационной панели, на странице [Plans](./plans.md)
- Планируйте контент с [Lessons.church](./scheduling-lessons.md)
