# Цифровая вывеска

<div class="article-intro">

Отправляйте содержание вашего урока на телевизор в вестибюле или коридоре, используя канал цифровой вывески. Каждый тип плана получает URL-адрес канала, который всегда воспроизводит содержание текущего плана, поэтому вам не нужно ничего обновлять из недели в неделю.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Установите [тип плана](./plans.md) с [Lessons.church](../../b1-church/content/lessons.md) или другим содержанием уроков в расписании
- Имейте учетную запись [SignPresenter](https://www.signpresenter.com) и устройство, установленное для его отображения

</div>

## Получение URL-адреса канала

1. Перейдите в раздел **Служение** и откройте служение, содержащее ваш тип плана.
2. Нажмите кнопку **Цифровая вывеска** (значок RSS) на странице типа плана.
3. Скопируйте URL-адрес канала, показанный в диалоговом окне.

:::info
URL-адрес канала связан с типом плана, а не с одним планом. Он автоматически отслеживает, какой план запланирован как текущий для этого типа плана, поэтому вам нужно настроить его только один раз.
:::

## Подключение к SignPresenter

Канал построен для работы с [SignPresenter](https://www.signpresenter.com), сторонним приложением цифровой вывески. Вставьте скопированный URL-адрес в SignPresenter в качестве внешнего канала, чтобы отобразить текущее содержание вашего урока на подключенном экране.

Пошаговые инструкции настройки внутри SignPresenter см. в разделе [руководство SignPresenter по Lessons.church](https://support.signpresenter.com/topics/lessons-dot-church.html).
