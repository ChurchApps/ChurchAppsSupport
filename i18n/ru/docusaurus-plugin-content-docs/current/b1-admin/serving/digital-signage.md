# Цифровая вывеска

<div class="article-intro">

Функция цифровой вывески позволяет вам отображать информацию о служении на экранах по всей вашей церкви — порядок служения, объявления, расписание групп и многое другое.

</div>

## Установка дисплея

1. Подключите экран к компьютеру или телевизору в месте, где вы хотите отобразить информацию
2. Откройте B1 Signage на экране
3. Введите код аутентификации вашей церкви
4. Выберите, какую информацию отображать

## Выбор контента

Вы можете отображать:

- **Service Order** — порядок служения
- **Announcements** — объявления вашей церкви
- **Calendar** — предстоящие события
- **Groups** — информация о группах
- **Slides** — пользовательские слайды
- **Rotation** — ротация между несколькими контентами

## Управление из B1 Admin

1. Перейдите в раздел **Serving** в B1 Admin
2. Нажмите на вкладку **Digital Signage**
3. Создайте новый дисплей и настройте контент
4. Содержимое обновляется на экранах в реальном времени

## Создание слайдов

Чтобы создать пользовательские слайды для вывески:

1. На странице Digital Signage нажмите **New Slide**
2. Добавьте заголовок и описание
3. Загрузите изображение (необязательно)
4. Установите продолжительность отображения
5. Нажмите **Save**

## Планирование контента

Вы можете спланировать, когда отображается контент:

1. На дисплее нажмите **Schedule**
2. Установите время начала и окончания
3. Выберите дни недели
4. Нажмите **Save**

## Несколько дисплеев

Вы можете управлять несколькими дисплеями по всей церкви:

1. Создайте отдельный дисплей для каждого экрана
2. Настройте уникальный контент для каждого дисплея
3. Все дисплеи управляются из B1 Admin

## Советы для эффективной вывески

- Используйте крупный текст, чтобы контент был видно издалека
- Обновляйте контент регулярно
- Используйте изображения с хорошей контрастностью
- Не переполняйте слайды информацией
