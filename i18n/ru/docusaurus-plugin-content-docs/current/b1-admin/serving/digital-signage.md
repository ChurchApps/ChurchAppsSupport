# Цифровые вывески

<div class="article-intro">

Отправляйте содержимое уроков на телевизор в фойе или коридоре с помощью ленты цифровых вывесок. Каждый тип плана получает URL ленты, который всегда показывает содержимое текущего плана, поэтому каждую неделю ничего обновлять не нужно. Если ваши телевизоры работают на FreePlay, можно вместо этого запланировать тип плана на них в FreePlay Admin.

</div>

<div class="prereqs">
<h4>С чего начать</h4>

- Настройте [тип плана](./plans.md) с [Lessons.church](../../b1-church/content/lessons.md) или запланируйте для него другое содержимое уроков
- Имейте аккаунт [SignPresenter](https://www.signpresenter.com) и устройство, настроенное для его отображения, или телевизор с [FreePlay](../../freeplay/)

</div>

## Получение URL ленты

1. Перейдите в раздел **Служение**, выберите служение, к которому относится ваш тип плана, и нажмите на тип плана, чтобы открыть его.
2. Нажмите **Цифровые вывески** (значок телевизора) вверху страницы типа плана.
3. В диалоговом окне **Лента цифровых вывесок** нажмите кнопку копирования рядом с **URL ленты**.

:::info
URL ленты привязан к типу плана, а не к отдельному плану. Он автоматически отслеживает план, который назначен текущим для этого типа, поэтому настроить его нужно только один раз.
:::

## Подключение к SignPresenter

Лента рассчитана на работу с [SignPresenter](https://www.signpresenter.com) — сторонним приложением для цифровых вывесок. Вставьте скопированный URL в SignPresenter как внешнюю ленту, чтобы показывать текущее содержимое уроков на подключенном экране.

Пошаговую инструкцию по настройке в SignPresenter см. в [руководстве SignPresenter по Lessons.church](https://support.signpresenter.com/topics/lessons-dot-church.html). Диалоговое окно также содержит ссылку на эти инструкции.

## Использование телевизоров FreePlay

Если ваши экраны работают на [FreePlay](../../freeplay/), URL ленты не нужен. Диалоговое окно **Лента цифровых вывесок** содержит ссылку на **admin.freeplay.church/calendar**, где можно запланировать этот тип плана на ваших телевизорах FreePlay:

1. Нажмите ссылку **admin.freeplay.church/calendar** в диалоговом окне. FreePlay Admin использует тот же логин, что и B1 Admin.
2. Выберите группу экранов для ваших телевизоров и нажмите **Добавить расписание**.
3. В разделе **Воспроизведение** выберите ваш тип плана в списке **Планы служений**. Он отмечен как **(текущий план)**.
4. Задайте дни и время, затем нажмите **Сохранить**.

Телевизоры каждую неделю воспроизводят план, который является текущим для этого типа плана, в заданное вами время. Это работает и с уроками Go Curriculum, в том числе с планами, которые вы настроили. FreePlay входит в систему под аккаунтом Go Curriculum, привязанным к служению в разделе **Поставщики контента** (см. [Планирование уроков](./scheduling-lessons.md)), или под подключением Go Curriculum всей церкви, если у служения его нет. Все варианты расписания см. в разделе [Планирование календаря](../../freeplay/scheduled-mode/scheduling-the-calendar), а чтобы добавить телевизор, см. [Подключение экрана](../../freeplay/scheduled-mode/pairing-a-screen).

:::note
URL ленты не включает медиафайлы Go Curriculum, поскольку для этого содержимого нужен логин вашей церкви в Go Curriculum. Чтобы показать урок Go Curriculum на телевизоре в фойе или классе, используйте FreePlay.
:::

## Следующие шаги

- Управляйте планами, которые передают содержимое на эту вывеску, на странице [Планы](./plans.md)
- Планируйте содержимое уроков с помощью [Lessons.church](./scheduling-lessons.md)
- Настройте телевизоры FreePlay по расписанию с помощью [режима расписания](../../freeplay/scheduled-mode/)
