# Цифровые вывески

<div class="article-intro">

Отправляйте материалы вашего урока на телевизор в фойе или коридоре с помощью ленты цифровых вывесок. У каждого типа плана есть URL ленты, который всегда воспроизводит содержимое текущего плана, поэтому каждую неделю ничего не нужно обновлять. Если ваши телевизоры работают на FreePlay, вместо этого можно настроить показ типа плана на них в FreePlay Admin.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Настройте [тип плана](./plans.md) с запланированным [Lessons.church](../../b1-church/content/lessons.md) или другим учебным материалом
- Имейте учётную запись [SignPresenter](https://www.signpresenter.com) и устройство, настроенное для её показа, или телевизор с [FreePlay](../../freeplay/)

</div>

## Получение URL ленты

1. Перейдите в **Serving** (Служение), выберите служение, которому принадлежит ваш тип плана, и нажмите на тип плана, чтобы открыть его.
2. Нажмите **Digital Signage** (значок телевизора) вверху страницы типа плана.
3. В диалоге **Digital Signage Feed** (Лента цифровых вывесок) нажмите кнопку копирования рядом с **Feed Url** (URL ленты).

:::info
URL ленты привязан к типу плана, а не к одному плану. Он автоматически отслеживает тот план, который запланирован как текущий для данного типа плана, поэтому настроить его нужно только один раз.
:::

## Подключение к SignPresenter

Лента рассчитана на работу с [SignPresenter](https://www.signpresenter.com) — сторонним приложением для цифровых вывесок. Вставьте скопированный URL в SignPresenter как внешнюю ленту, чтобы показывать материалы текущего урока на подключённом экране.

Пошаговую настройку внутри SignPresenter см. в [руководстве SignPresenter по Lessons.church](https://support.signpresenter.com/topics/lessons-dot-church.html). Диалог также содержит ссылки на эти инструкции.

## Использование телевизоров FreePlay вместо этого

Если ваши экраны работают на [FreePlay](../../freeplay/), URL ленты не нужен. Диалог **Digital Signage Feed** содержит ссылку на **admin.freeplay.church/calendar**, где можно запланировать показ этого типа плана на ваших телевизорах FreePlay:

1. Нажмите ссылку **admin.freeplay.church/calendar** в диалоге. FreePlay Admin использует тот же логин, что и B1 Admin.
2. Выберите группу экранов для ваших телевизоров и нажмите **Add schedule** (Добавить расписание).
3. В разделе **Play** (Воспроизведение) выберите ваш тип плана из **Service plans** (Планы служения). Он отмечен как **(current plan)** (текущий план).
4. Укажите дни и время, затем нажмите **Save**.

Телевизоры каждую неделю воспроизводят тот план, который является текущим для этого типа плана, в указанное вами время. Все варианты см. в разделе [Планирование календаря](../../freeplay/scheduled-mode/scheduling-the-calendar), а чтобы добавить телевизор, см. [Привязка экрана](../../freeplay/scheduled-mode/pairing-a-screen).
