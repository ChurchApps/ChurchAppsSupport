# Планирование уроков

<div class="article-intro">

Функция планирования уроков позволяет вам плани рова из уроков для ваших групп, убедившись, что есть согласованность и структура в учебных процессах ваших груп у.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Убедитесь, что у вас есть группы, для которых вы хотите планировать уроки
- Для начала см. [Создание групп](../groups/creating-groups.md)

</div>

## Доступ к расписанию уроков

1. Перейдите в раздел **Serving** в B1 Admin
2. Нажмите на вкладку **Lessons**
3. Выберите группу, для которой вы хотите планировать уроки

## Создание плана уроков

1. Нажмите **New Lesson Plan**
2. Выберите дату первого урока
3. Добавьте название и описание урока
4. Установите тему или тип урока
5. Добавьте каких-либо примечаний или ресурсов, которые потребуются лидеру
6. Нажмите **Save**

## Назначение лидеров уроков

После создания плана урока:

1. Выберите урок
2. Нажмите **Assign Teacher**
3. Выберите лидера для этого урока
4. Нажмите **Save**

Лидер получит уведомление о назначении.

## Переиспользование уроков

Если у вас есть урок, который вы использовали раньше:

1. Нажмите **Duplicate** на предыдущем уроке
2. B1 скопирует название, описание и ресурсы
3. Отредактируйте дату по необходимости
4. Нажмите **Save**
