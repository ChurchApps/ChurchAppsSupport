# Обзор планов

<div class="article-intro">

Обзор планов дает вам общий вид всех назначений волонтёров на несколько дат богослужений одновременно. Вместо открытия каждого плана отдельно вы можете увидеть, кто служит в каждой должности в предстоящих неделях в одной таблице -- и быстро заметить любые пробелы, которые всё ещё нужно заполнить.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Создайте по крайней мере одно служение и тип плана в области служения
- Создайте [планы богослужений](./plans.md) с датами и назначениями волонтёров
- Убедитесь, что ваши волонтёры были добавлены в ваш [справочник людей](../people/adding-people.md)

</div>

## Доступ к обзору

1. В B1 Admin откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу), разверните **Служение** и нажмите **Планы**.
2. Выберите **вкладку служения** в верхней части страницы.
3. Нажмите на **тип плана**, чтобы открыть его список планов.
4. Нажмите кнопку **Обзор** рядом с верхней частью страницы.

## Чтение таблицы обзора

Обзор отображает таблицу, где:

- **Строки** представляют каждую должность (например, "Музыка: гитара", "Техника: проекция"), сгруппированные по категориям
- **Столбцы** представляют предстоящие даты богослужений (например, "14 апреля", "21 апреля")
- **Ячейки** показывают имя волонтёра, назначенного на эту должность в эту дату

Ячейки, выделенные **красным цветом**, не заполнены -- волонтёр не был назначен. Это облегчает видение кадровых пробелов с первого взгляда без открытия каждого плана отдельно.

:::tip
Имена волонтёров отображаются в сокращённом формате (имя и последняя начальная буква, например, "Иван В.") для сохранения компактности таблицы, когда у вас много должностей.
:::

## Назначение волонтёров непосредственно из обзора

Вам не нужно открывать отдельные планы, чтобы заполнить пустые слоты. Щелкните на любую ячейку в таблице, чтобы открыть панель назначения для этой должности и даты. Оттуда вы можете:

- Выбрать человека из вашей команды для назначения на должность
- Нажать **Удалить** рядом с кем-либо уже назначенным, чтобы удалить его с этого слота
- Сохранить изменение без выхода из обзора

Это позволяет персоналу на всё расписание за один проход -- работайте в течение недель и должностей, не переходя в отдельные планы и из них.

## Автоматическое планирование из обзора

Нажмите **Автопланирование**, чтобы B1 заполнил каждый открытый, незаполненный слот в текущей таблице сразу. Для каждого плана в представлении он берёт кандидатов из группы, связанной с каждой должностью, и автоматически заполняет пустые слоты, сообщая, сколько из видимых планов он смог заполнить. Планы заполняются по одному за раз, чтобы один волонтёр не был забронирован дважды в двух датах в одном проходе.

:::info
Автопланирование только заполняет слоты, которые уже пусты -- оно никогда не заменяет существующее назначение.
:::

## Отправка писем всем запланированным

Нажмите **Письмо волонтёрам**, чтобы отправить уведомление каждому волонтёру, назначенному в настоящее время отфильтрованный диапазон дат и служение, в одном действии, а не по плану. B1 сообщает, сколько писем было отправлено и сколько не удалось.

## Выделение расписания волонтёра

Используйте раскрывающееся меню **Выделение**, чтобы выбрать человека из вашей команды -- каждая ячейка, где они назначены, выделяется в таблице, чтобы вы могли видеть везде, где они уже служат, перед добавлением их в другой слот. Выберите **Все**, чтобы отключить выделение.

## Фильтрация обзора

Вы можете отрегулировать то, что показывает обзор, используя элементы управления фильтром в верхней части:

- **Дата начала / Дата окончания** -- по умолчанию обзор показывает 12 недель в будущее. Введите пользовательские даты для расширения или сужения диапазона.
- **Служение** -- переключитесь на другое служение, не выходя из обзора.
- **Тип плана** -- отфильтруйте до определённого типа плана в выбранном служении.
- **Только незаполненные** -- переключите это, чтобы скрыть строки, где каждая дата уже заполнена, чтобы вы могли сосредоточиться только на должностях, которые всё ещё нуждаются в волонтёре.

Нажмите **Фильтр** после внесения изменений для обновления таблицы.

## Экспорт в CSV

Нажмите **Экспорт CSV**, чтобы загрузить текущую таблицу в виде электронной таблицы. Экспорт включает все должности и назначения волонтёров для отфильтрованного диапазона дат, что облегчает обмен с лидерами служения или печать для планирования встреч.

:::info
Экспорт CSV отражает любые применяемые в настоящее время фильтры -- только даты и тип плана, показанные в таблице, включены в загрузку.
:::
