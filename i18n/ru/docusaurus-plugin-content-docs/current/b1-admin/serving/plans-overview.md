# Обзор планов

<div class="article-intro">

Обзор планов дает вам общую картину всех назначений волонтеров по нескольким датам служения одновременно. Вместо того чтобы открывать каждый план по отдельности, вы можете увидеть, кто служит на каждой позиции в предстоящие недели, в единой сетке — и быстро обнаружить пробелы, которые еще нужно заполнить.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Создайте хотя бы одно служение (Ministry) и тип плана в разделе «Служение»
- Создайте [планы служения](./plans.md) с датами и назначениями волонтеров
- Убедитесь, что ваши волонтеры добавлены в [справочник людей](../people/adding-people.md)

</div>

## Доступ к обзору

1. Перейдите в раздел **Служение** в главном меню B1 Admin.
2. Выберите вкладку **служения** вверху страницы.
3. Нажмите на **тип плана**, чтобы открыть список планов.
4. Нажмите кнопку **Обзор** в верхней части страницы.

## Чтение сетки обзора

Обзор отображает сетку, в которой:

- **Строки** представляют каждую позицию (например, «Музыка: Гитара», «Техника: Проекция»), сгруппированные по категориям
- **Столбцы** представляют предстоящие даты служений (например, «14 апр», «21 апр»)
- **Ячейки** показывают имя волонтера, назначенного на эту позицию в эту дату

Ячейки, выделенные **красным**, не заполнены — волонтер еще не назначен. Это позволяет с первого взгляда увидеть пробелы в расписании, не открывая каждый план по отдельности.

:::tip
Имена волонтеров показаны в сокращенном формате (имя и первая буква фамилии, например «Иван П.»), чтобы сетка оставалась компактной при большом количестве позиций.
:::

## Назначение волонтеров прямо из обзора

Вам не нужно открывать отдельные планы, чтобы заполнить пустые слоты. Нажмите на любую ячейку в сетке, чтобы открыть панель назначения для этой позиции и даты. Оттуда вы можете:

- Выбрать человека из своей команды для назначения на позицию
- Нажать **Удалить** рядом с уже назначенным человеком, чтобы снять его с этого слота
- Сохранить изменение, не покидая обзор

Это позволяет укомплектовать все расписание за один проход — работать по неделям и позициям, не переходя туда-сюда между отдельными планами.

## Автоматическое планирование из обзора

Нажмите **Автопланирование**, чтобы B1 заполнил все открытые, незаполненные слоты в текущей сетке одним действием. Для каждого плана в поле зрения система берет кандидатов из группы, связанной с каждой позицией, и автоматически заполняет пустые слоты, сообщая, сколько из видимых планов удалось заполнить. Планы заполняются по одному, чтобы один и тот же волонтер не был назначен на две даты одновременно в рамках одного прохода.

:::info
Автопланирование заполняет только уже пустые слоты — оно никогда не заменяет существующее назначение.
:::

## Отправка письма всем назначенным

Нажмите **Отправить письмо волонтерам**, чтобы отправить уведомление каждому волонтеру, назначенному в любом месте текущего отфильтрованного диапазона дат и служения, одним действием, а не по каждому плану отдельно. B1 сообщает, сколько писем было отправлено и сколько не удалось отправить.

## Выделение расписания волонтера

Используйте выпадающий список **Выделить**, чтобы выбрать человека из вашей команды — каждая ячейка, где он назначен, будет выделена в сетке, чтобы вы могли увидеть все места, где он уже служит, прежде чем добавлять его на другой слот. Выберите **Все**, чтобы отключить выделение.

## Фильтрация обзора

Вы можете настроить, что показывает обзор, с помощью элементов управления фильтрами вверху:

- **Дата начала / Дата окончания** — По умолчанию обзор показывает 12 недель вперед. Введите произвольные даты, чтобы расширить или сузить диапазон.
- **Служение** — Переключитесь на другое служение, не покидая обзор.
- **Тип плана** — Отфильтруйте по конкретному типу плана в выбранном служении.
- **Только незаполненные** — Включите этот переключатель, чтобы скрыть строки, где все даты уже заполнены, и сосредоточиться только на позициях, которые все еще нуждаются в волонтере.

Нажмите **Фильтр** после внесения изменений, чтобы обновить сетку.

## Экспорт в CSV

Нажмите **Экспорт CSV**, чтобы скачать текущую сетку в виде электронной таблицы. Экспорт включает все позиции и назначения волонтеров для отфильтрованного диапазона дат, что упрощает обмен с руководителями служений или печать для планерок.

:::info
Экспорт в CSV отражает применяемые в данный момент фильтры — только даты и тип плана, отображаемые в сетке, включаются в скачиваемый файл.
:::
