# Песни

<div class="article-intro">

Библиотека песен позволяет вам хранить и управлять песнями, используемыми в вашей церкви. Организуйте свою библиотеку по альбомам, артистам и жанрам, и добавляйте песни в планы служения.

</div>

## Добавление песни

1. Перейдите в раздел **Serving** в B1 Admin
2. Нажмите на вкладку **Songs**
3. Нажмите **New Song**
4. Заполните информацию о песне:
   - Название
   - Артист
   - Альбом
   - Длительность
   - Жанр
5. Нажмите **Save**

## Организация библиотеки

Вы можете организовать ваши песни по:

- **Artist** — сгруппируйте по артисту
- **Album** — сгруппируйте по альбому
- **Genre** — сгруппируйте по жанру

Используйте эти категории для быстрого поиска при планировании служения.

## Использование в порядке служения

При создании порядка служения:

1. Нажмите **Add Song**
2. Просмотрите вашу библиотеку
3. Выберите песню
4. Нажмите **Add**

Песня добавится в порядок служения с предварительно установленной длительностью.

## Управление авторскими правами

Отслеживайте информацию об авторских правах для каждой песни для целей лицензирования.

## Экспорт списка песен

Вы можете экспортировать вашу библиотеку песен:

1. На странице Songs нажмите **Export**
2. Выберите формат (CSV или PDF)
3. Нажмите **Download**
