# Шаблоны планов

<div class="article-intro">

Шаблоны планов позволяют вам создавать переиспользуемые конфигурации служб, которые запомнят роли, позиции и другие детали, чтобы вы не пришлось настраивать каждый план с нуля.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужно разрешение на управление планами служения

</div>

## Создание шаблона плана

1. Перейдите в раздел **Serving** в B1 Admin
2. Нажмите на вкладку **Plan Templates**
3. Нажмите **New Template**
4. Дайте шаблону имя (например, "Sunday Worship Service")
5. Добавьте позиции/роли для этого типа плана
6. Для каждой позиции укажите название и нужное количество добровольцев
7. Нажмите **Save**

## Использование шаблона при создании плана

1. При создании нового плана выберите шаблон
2. B1 будет использовать роли и позиции из шаблона
3. Просто заполните конкретных добровольцев для этого служения

## Редактирование шаблона

Вы можете отредактировать шаблон в любое время:

1. Откройте шаблон из списка
2. Нажмите **Edit**
3. Добавьте, удалите или отредактируйте позиции
4. Нажмите **Save**

Все будущие планы, созданные из этого шаблона, будут использовать новые конфигурации.

## Типичные шаблоны

- Sunday Worship Service
- Midweek Service
- Special Events
- Children's Ministry
- Youth Group
