# Шаблоны планов

<div class="article-intro">

Шаблоны планов позволяют сохранить снимок порядка служения или позиций плана для повторного использования и применить его к будущим планам одним нажатием. Вместо того чтобы каждую неделю заново собирать одну и ту же структуру, вы сохраняете её один раз и переносите на столько предстоящих планов, сколько нужно.

</div>

## Сохранение плана как шаблона {#saving-a-plan-as-a-template}

1. Откройте существующий план в разделе **Serving**.
2. Нажмите **Edit order of service**, чтобы открыть порядок служения плана, затем нажмите над ним **Save as Template**.
3. Задайте название шаблона (например, «Standard Sunday» или «Worship + Sermon»). По умолчанию оно совпадает с названием плана.
4. Нажмите **Save**. Шаблон сохранит текущий порядок служения, позиции и заметки плана на этот момент.

## Управление шаблонами {#managing-templates}

Нажмите **Templates** над списком планов на любой странице типа плана, чтобы открыть **Plan Templates**. У каждого шаблона есть такие значки:

- **Edit** (карандаш) — переименовать шаблон
- **Update from plan** (круговые стрелки) — заменить содержимое шаблона текущим состоянием плана (полезно после доработки вашей стандартной структуры)
- **Apply** (значок копирования) — применить шаблон к одному или нескольким предстоящим планам
- **Delete** (корзина) — удалить шаблон, который больше не нужен

## Применение шаблона к планам {#applying-a-template-to-plans}

1. Нажмите **Templates** над списком планов на странице типа плана.
2. Нажмите значок **Apply** (значок копирования) рядом с шаблоном, который хотите использовать.
3. Выберите, к каким предстоящим планам его применить, отметив их флажками. Планы с датой раньше сегодняшней не показываются.
4. Выберите, что копировать:
   - **Order of Service** — заменяет элементы порядка служения выбранных планов элементами шаблона
   - **Positions** — заменяет позиции выбранных планов (и их назначения) позициями шаблона
5. Нажмите **Apply**. По умолчанию отмечен **Order of Service**; должен быть отмечен хотя бы один из двух пунктов.

Если в шаблоне есть заметки, их применение также заменяет заметки выбранных планов заметками из шаблона.

:::warning
Применение позиций заменяет все существующие позиции и назначения в выбранных планах. Перед применением убедитесь, что вы ещё не назначили волонтёров на эти позиции.
:::

:::tip
Применяйте порядок служения без позиций, когда вам нужна единая структура песен и проповеди, но волонтёры каждую неделю назначаются по-разному.
:::

## Создание нового плана из шаблона {#starting-a-new-plan-from-a-template}

Шаблоны общие для всех типов планов служения. Когда вы нажимаете **New Plan** и у служения есть шаблоны, в форме нового плана появляется список **Start from template**. Выберите шаблон и сохраните: новый план создастся с порядком служения, позициями и заметками из шаблона. Выбор шаблона заменяет для этого плана варианты **Copy from Previous Plan**.

## Поддержание шаблонов в актуальном состоянии {#keeping-templates-up-to-date}

Если стандартная структура служения изменилась, откройте менеджер шаблонов, нажмите **Update from plan**, выберите план, из которого нужно копировать, и нажмите **Save**, чтобы обновить шаблон из последнего плана, а не собирать его заново. В списке доступны все планы этого типа — прошедшие и предстоящие.
