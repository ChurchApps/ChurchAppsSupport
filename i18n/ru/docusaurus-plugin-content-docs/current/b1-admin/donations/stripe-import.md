# Импорт из Stripe

<div class="article-intro">

Если вы принимаете онлайн-пожертвования через Stripe, инструмент Stripe Import позволяет загрузить эти транзакции в B1 Admin, чтобы все данные о пожертвованиях хранились в одном месте. Это особенно полезно для поиска транзакций, которые не были синхронизированы автоматически.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Выполните [настройку онлайн-пожертвований](online-giving-setup.md), чтобы подключить ваш аккаунт Stripe к B1 Admin. Пункт меню **Stripe Import** и кнопка на странице Batches появляются только тогда, когда платежный шлюз вашей общины — Stripe, и только для людей, которые могут редактировать пожертвования
- Убедитесь, что в вашей панели Stripe есть пожертвования за период, который вы хотите импортировать

</div>

## Как это работает {#how-it-works}

Процесс импорта состоит из двух шагов: сначала вы просматриваете, что будет импортировано, а затем подтверждаете импорт. Такой подход «пробного запуска» позволяет проверить все перед созданием каких-либо данных.

## Импорт транзакций {#importing-transactions}

1. В **B1 Admin** перейдите в **Donations > Stripe Import**. (Также можно нажать **Import missing Stripe transactions** вверху страницы **Batches**.)
2. Откроется страница **Import Stripe Transactions**.
3. В разделе **Select Date Range** задайте **Start Date** и **End Date** для транзакций, которые хотите импортировать. По умолчанию диапазон начинается с 1 января этого года и доходит до сегодняшнего дня.
4. Нажмите **Preview**, чтобы выполнить пробную проверку. Кнопка **Import Missing** остается неактивной, пока предпросмотр не найдет новые транзакции, а изменение любой из дат сбрасывает предпросмотр, так что сначала нужно просмотреть новый диапазон.

## Просмотр предпросмотра {#reviewing-the-preview}

Предпросмотр перечисляет каждое событие Stripe с его **Event ID**, **Type**, **Amount**, **Date** и **Status**:

- **New** — эта транзакция еще не импортирована и будет включена, если вы продолжите.
- **Already Imported** — эта транзакция уже есть в B1 Admin и будет пропущена.
- **Skipped** — эта транзакция исключена по другой причине (например, возврат или неудачное списание).

Сводка вверху показывает общее число событий **Total** и сколько из них **New**, **Already Imported** и **Skipped**. Если какое-либо событие не удалось прочитать, появляется счетчик **Errors**, а в строке события в столбце **Notes** показано сообщение.

:::info
Шаг предпросмотра не создает никаких записей. Это проверка только для чтения, чтобы вы могли увидеть, что произойдет, прежде чем подтвердить действие.
:::

## Завершение импорта {#completing-the-import}

1. Просмотрите результаты предпросмотра и итоговые суммы.
2. Нажмите **Import Missing**, чтобы импортировать все транзакции, помеченные как **New**.
3. После завершения импорта список превращается в **Import Results**: каждая добавленная транзакция показывает **Imported**, а в сводке добавляется счетчик **Imported**.

## Советы по использованию Stripe Import {#tips-for-using-stripe-import}

- Запускайте импорт регулярно (еженедельно или ежемесячно), чтобы ваши записи оставались актуальными.
- Если транзакция показана как **Already Imported**, это значит, что в B1 Admin уже есть соответствующая запись — никаких действий не требуется.
- Используйте фильтр диапазона дат, чтобы сосредоточиться на конкретном периоде, если ищете определенные транзакции.

:::tip
После импорта откройте страницу [Пакеты](batches.md), чтобы проверить, что импортированные пожертвования отображаются правильно, а итоги совпадают с тем, что вы видите в панели Stripe.
:::
