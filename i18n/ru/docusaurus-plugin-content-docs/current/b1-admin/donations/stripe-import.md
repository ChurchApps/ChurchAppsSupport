# Импорт из Stripe

<div class="article-intro">

Если вы принимаете онлайн-пожертвования через Stripe, инструмент Stripe Import позволяет загрузить эти транзакции в B1 Admin, чтобы все данные о пожертвованиях хранились в одном месте. Это особенно полезно, чтобы подхватить транзакции, которые не были синхронизированы автоматически.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Выполните [настройку онлайн-пожертвований](online-giving-setup.md), чтобы подключить вашу учётную запись Stripe к B1 Admin. Пункт меню **Stripe Import** и кнопка на странице Batches появляются только тогда, когда ваш шлюз пожертвований -- Stripe, и только для тех, кто может редактировать пожертвования
- Убедитесь, что в вашей панели Stripe есть пожертвования за нужный период импорта

</div>

## Как это работает

Импорт выполняется в два шага: сначала вы просматриваете, что будет импортировано, затем подтверждаете импорт. Такой предварительный прогон позволяет проверить всё до создания каких-либо данных.

## Импорт транзакций

1. В **B1 Admin** перейдите в **Donations > Stripe Import**. (Также можно нажать **Import missing Stripe transactions** вверху страницы **Batches**.)
2. Откроется страница **Stripe Import**.
3. Выберите **date range** (диапазон дат) для транзакций, которые хотите импортировать.
4. Нажмите **Preview**, чтобы выполнить пробную проверку.

## Просмотр предварительного результата

В предварительном результате каждая транзакция из Stripe выводится с индикатором статуса:

- **New** -- эта транзакция ещё не импортирована и будет включена, если вы продолжите.
- **Already Imported** -- эта транзакция уже есть в B1 Admin и будет пропущена.
- **Skipped** -- транзакция исключена по другой причине (например, возврат или неудачное списание).

Сводка вверху показывает общее количество транзакций в каждой категории и суммы в долларах.

:::info
Шаг предварительного просмотра не создаёт никаких записей. Это проверка только для чтения, чтобы вы могли убедиться, что произойдёт, прежде чем выполнять импорт.
:::

## Завершение импорта

1. Проверьте результаты предварительного просмотра и итоговые суммы.
2. Нажмите **Import Missing**, чтобы импортировать все транзакции со статусом **New**.
3. После завершения импорта значки статуса рядом с каждой транзакцией обновятся и покажут результат.

## Советы по использованию Stripe Import

- Запускайте импорт регулярно (еженедельно или ежемесячно), чтобы ваши записи оставались актуальными.
- Если транзакция отображается как **Already Imported**, это значит, что в B1 Admin уже есть соответствующая запись, никаких действий не требуется.
- Используйте фильтр диапазона дат, чтобы сосредоточиться на определённом периоде, если ищете конкретные транзакции.

:::tip
После импорта откройте страницу [Batches](batches.md), чтобы проверить, что импортированные пожертвования отображаются правильно, а итоги совпадают с тем, что вы видите в панели Stripe.
:::

- Убедитесь, что импортированные пожертвования назначены правильным [фондам](funds.md) для точных [выписок о пожертвованиях](giving-statements.md)
