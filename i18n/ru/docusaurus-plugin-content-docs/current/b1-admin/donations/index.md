# Пожертвования

<div class="article-intro">

Раздел «Пожертвования» в B1 Admin предоставляет всё необходимое для управления финансовыми поступлениями вашей церкви. От записи еженедельных подношений до формирования годовых налоговых справок — все инструменты для пожертвований собраны в одном месте, чтобы вы могли контролировать финансы церкви.

</div>

## Подразделы

В разделе «Пожертвования» вы найдёте следующие страницы:

### Сводка

Страница **Сводка** даёт наглядный обзор всей финансовой активности. Она отображает диаграммы и отфильтрованные отчёты, чтобы вы могли быстро увидеть динамику пожертвований в вашей церкви. Подробнее об использовании сводки и инструментов отчётов см. [Отчёты о пожертвованиях](donation-reports.md).

### Пакеты

**[Пакеты](batches.md)** позволяют объединять пожертвования в группы — например, все чеки и наличные, собранные во время воскресного подношения. Каждый пакет отслеживает количество пожертвований и общую сумму для удобной сверки. Когда пакет подсчитан, пользователь с правом **Редактировать пожертвования** может закрыть его, чтобы волонтёры, занимавшиеся подсчётом, больше не могли вносить в него изменения. Волонтёры с правом **Вносить пожертвования** могут добавлять взносы в открытые пакеты, не видя остальных разделов раздела «Пожертвования».

### Фонды

**[Фонды](funds.md)** классифицируют пожертвования по назначению. Типичные примеры: Общий фонд, Фонд строительства и Миссии. Для каждого фонда можно указать, учитывается ли он при налоговом вычете.

### Справки

Страница **[Справки](giving-statements.md)** формирует годовые справки о пожертвованиях для ваших жертвователей. Вы можете скачать отдельные CSV-файлы или распечатать все справки сразу.

### Импорт из Stripe

Если вы принимаете онлайн-пожертвования через Stripe, инструмент **[Импорт из Stripe](stripe-import.md)** позволяет загрузить эти транзакции в B1 Admin, чтобы всё находилось в одной системе.

## Онлайн-пожертвования

B1 Admin интегрируется со **Stripe** и **PayPal** для приёма онлайн-пожертвований. После настройки участники могут жертвовать через ваш сайт B1.church, и эти пожертвования автоматически появляются в ваших записях. Чтобы начать, см. [Настройка онлайн-пожертвований](online-giving-setup.md).

:::tip
Если вы впервые работаете с пожертвованиями в B1 Admin, начните с [настройки фондов](funds.md), затем [создайте первый пакет](batches.md) и [записывайте пожертвования](recording-donations.md) в него.
:::
