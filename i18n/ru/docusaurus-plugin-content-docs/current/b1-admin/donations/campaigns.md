# Кампании и обещания

<div class="article-intro">

Кампании позволяют проводить сбор средств на конкретную цель — фонд на здание, миссионерскую поездку, специальный проект — и отслеживать обещания участников наряду с реальными пожертвованиями, чтобы видеть ваш прогресс в реальном времени.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Настройте [фонды пожертвований](funds) — каждая кампания привязана к фонду
- У вас должен быть доступ к разделу Donations в B1 Admin

</div>

## Открытие кампаний

В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в левом верхнем углу), разверните **Пожертвования** и нажмите **Кампании**. Вы увидите таблицу всех кампаний с их фондом, датами, целевой суммой, общей суммой обещаний и суммой, уже полученной. Сводная строка над таблицей показывает количество кампаний и общие суммы обещаний и пожертвований.

## Создание кампании

1. Нажмите **Добавить кампанию** вверху страницы.
2. Заполните данные кампании:
   - **Название** *(обязательно)* — отображаемое имя этой кампании (например, «Фонд здания 2026»).
   - **Фонд** — фонд пожертвований, с которым связана эта кампания.
   - **Дата начала** / **Дата окончания** — период сбора средств.
   - **Цель** — целевая сумма в долларах для кампании.
3. Нажмите **Сохранить**.

## Отслеживание прогресса

Каждая строка кампании показывает:

- **Цель** — ваша целевая сумма
- **Обещано** — общая сумма, которую участники обещали пожертвовать
- **Получено** — общая сумма, фактически пожертвованная в фонд этой кампании в течение периода кампании
- **Прогресс** — полоса и процент, показывающие, насколько вы продвинулись к цели

Нажмите на название кампании, чтобы открыть подробное представление. Оно показывает процент достижения цели и список отдельных обещаний с обещанными и полученными суммами каждого жертвователя и статусом (**Не начато**, **В процессе**, **Выполнено**, **Больше обещанного** или **Без обещания** для жертвователей, которые дали без обещания). Жертвователи перечислены по фамилии, затем по имени; нажмите на заголовок столбца, чтобы отсортировать по нему. Нажмите **Экспорт** вверху подробного представления, чтобы скачать список обещаний в формате CSV.

## Добавление обещаний

Обещания — это обязательства участников пожертвовать в пользу кампании. Чтобы записать обещание:

1. Откройте кампанию.
2. Нажмите **Добавить обещание** вверху страницы.
3. Выберите **человека**, который делает обещание.
4. Введите **сумму** обещания.
5. При желании укажите **дату** обещания.
6. Нажмите **Сохранить**.

Обещания отображаются в подробном представлении кампании и учитываются в итоге **Обещано** в списке кампаний. Чтобы изменить обещание, нажмите **Изменить** в его строке.

:::tip
Обещания отделены от реальных пожертвований. Обещание отслеживает обязательство, а пожертвование фиксирует фактический дар. В кампании видны оба показателя, так что вы можете оценить, насколько хорошо выполняются обещания.
:::

## Изменение и удаление кампании

Нажмите **Изменить** в строке любой кампании (или **Изменить кампанию** вверху подробного представления), чтобы обновить её название, цель, даты или фонд. Нажмите **Удалить**, чтобы безвозвратно удалить кампанию и её обещания. Удаление кампании не удаляет пожертвования, которые были записаны в её фонд.
