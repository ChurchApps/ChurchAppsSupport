# Поддержка нескольких валют

<div class="article-intro">

Функция нескольких валют в B1 позволяет вашей церкви принимать и учитывать пожертвования в разных валютах. Это особенно полезно для церквей с международными участниками, миссионерами или филиалами в разных странах.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Вам нужно право управлять пожертвованиями. Подробности см. в разделе [Роли и права доступа](../people/roles-permissions.md).
- Настройте [онлайн-пожертвования](./online-giving-setup.md) через Stripe, который поддерживает операции в нескольких валютах. Церковь без онлайн-пожертвований тоже может выбрать валюту, в которой будут записываться пожертвования, внесённые вручную.
- Разберитесь с бухгалтерскими требованиями вашей церкви к работе с несколькими валютами.

</div>

Валюта вашей церкви по умолчанию соответствует валюте страны, указанной при регистрации церкви (например, кенийские шиллинги для церкви в Кении), и используется, пока валюта не сохранена. Изменить её можно в любое время в разделе **Управление церковью → Пожертвования**. Если ваша страна не распознана, по умолчанию выбираются доллары США.

## Включение поддержки нескольких валют

Поддержка нескольких валют теперь включена в B1 по умолчанию. После включения:

- Участники могут жертвовать в своей местной валюте при онлайн-пожертвованиях
- Вы можете вручную записывать пожертвования в любой валюте
- В отчётах о пожертвованиях суммы показываются в исходной валюте
- Stripe автоматически выполняет пересчёт валюты для онлайн-пожертвований

## Поддерживаемые валюты

Система поддерживает все основные мировые валюты, в том числе:

- **USD** -- доллар США
- **EUR** -- евро
- **GBP** -- фунт стерлингов
- **CAD** -- канадский доллар
- **AUD** -- австралийский доллар
- **MXN** -- мексиканское песо
- **BRL** -- бразильский реал
- **INR** -- индийская рупия
- **CNY** -- китайский юань
- **JPY** -- японская иена
- и многие другие...

Доступные валюты для онлайн-пожертвований зависят от валют, которые поддерживает ваш аккаунт Stripe.

## Запись пожертвований в разных валютах

### Онлайн-пожертвования

Когда участник жертвует онлайн через Stripe:

1. Он выбирает предпочитаемую валюту при оформлении платежа
2. Stripe проводит платёж в этой валюте
3. Пожертвование записывается в B1 с суммой в исходной валюте
4. Stripe автоматически выполняет все необходимые пересчёты валюты в валюту по умолчанию вашего аккаунта

### Ручной ввод

Наличные и чеки, которые вы вводите вручную, записываются в валюте вашей церкви -- в **валюте**, заданной в разделе **Настройки > Пожертвования** (см. [Выбор валюты церкви](./online-giving-setup.md#choosing-your-currency)). Выбрать валюту для каждого пожертвования нельзя. В поле **Сумма** в конце показан код валюты (например, *PHP*), чтобы вы видели, в какой валюте вводите сумму.

1. В B1 Admin перейдите в **Пожертвования > Пакеты** и откройте нужный пакет
2. Нажмите **Добавить пожертвование** вверху страницы пакета
3. Введите сумму в валюте вашей церкви
4. Заполните остальные сведения о пожертвовании
5. Нажмите **Сохранить**

Редактирование существующего пожертвования сохраняет валюту, в которой оно было первоначально записано.

## Просмотр пожертвований в нескольких валютах

### Отчёты о пожертвованиях

В отчётах о пожертвованиях суммы показываются в исходной валюте:

- В записях отдельных пожертвований указан код валюты (например, «$100.00 USD»)
- Итоги подсчитываются отдельно для каждой валюты
- Можно фильтровать данные по конкретным валютам

### Пересчитанные итоги {#converted-totals}

Везде, где B1 показывает одну общую сумму -- карточки с итогами пожертвований, итог пакета пожертвований и итог по фонду, -- пожертвования, записанные в валюте, отличной от валюты церкви по умолчанию, пересчитываются в валюту вашей церкви по текущему курсу обмена. Благодаря этому итог представлен одним понятным числом, а не суммой разных валют. Под итогом появляется примечание **Пересчитано по текущему курсу обмена**, если был выполнен пересчёт. Отдельные строки пожертвований по-прежнему показываются в исходной валюте.

### Справки о пожертвованиях

При создании справок о пожертвованиях:

- Каждое пожертвование указывается в исходной валюте
- Итоги разбиваются по валютам
- Участники видят, сколько они пожертвовали в каждой валюте

## Интеграция со Stripe

Для онлайн-пожертвований Stripe обрабатывает операции в нескольких валютах:

- **Автоматический пересчёт** -- Stripe переводит валюты в валюту по умолчанию вашего аккаунта
- **Курсы обмена** -- Stripe использует текущие рыночные курсы
- **Комиссии** -- пересчёт валюты может включать дополнительные комиссии Stripe
- **Валюта выплат** -- средства зачисляются в валюте по умолчанию вашего аккаунта

:::info
Проверьте в панели управления Stripe текущие курсы пересчёта и комиссии за операции в нескольких валютах.
:::

## Бухгалтерские особенности

При работе с несколькими валютами:

- **Учёт** -- сохраняйте исходные суммы и валюты пожертвований для точной отчётности
- **Курсы обмена** -- имейте в виду, что курсы Stripe могут отличаться от курсов вашего банка
- **Налоговые квитанции** -- проконсультируйтесь с бухгалтером, как отражать пожертвования в разных валютах для целей налогообложения
- **Распределение по фондам** -- пожертвования можно распределять по конкретным фондам независимо от валюты

## Рекомендации

- **Валюта по умолчанию** -- задайте основную валюту церкви в разделе **Настройки > Пожертвования**, чтобы пожертвования, введённые вручную, и итоги использовали её
- **Понятная коммуникация** -- сообщайте жертвователям, в какой валюте они жертвуют, во время оформления платежа
- **Единообразная отчётность** -- общие итоги всегда автоматически пересчитываются в валюту вашей церкви; используйте фильтр по валюте для отдельных пожертвований, когда нужно увидеть исходные суммы
- **Регулярная сверка** -- сверяйте выплаты Stripe с вашими записями о пожертвованиях, учитывая пересчёт валют

## Ограничения

- Пересчёт валют при проведении платежей выполняется Stripe только для онлайн-пожертвований; пожертвования, введённые вручную, записываются так, как введены, без автоматического пересчёта
- В исторических отчётах и в строках отдельных пожертвований всегда показывается исходная валюта, в которой было записано пожертвование
- Общие итоги (карточки с итогами, итоги пакетов и фондов) пересчитываются в валюту вашей церкви по текущим курсам обмена -- эти курсы могут немного отличаться от курсов вашего банка или Stripe на момент зачисления средств
