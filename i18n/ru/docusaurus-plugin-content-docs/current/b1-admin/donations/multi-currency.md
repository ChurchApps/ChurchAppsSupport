# Поддержка множественных валют

<div class="article-intro">

Функция множественных валют B1 позволяет вашей церкви принимать и отслеживать пожертвования в разных валютах. Это особенно полезно для церквей с международными членами, миссионерами или несколькими кампусами в разных странах.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужно разрешение на управление пожертвованиями. Подробности см. в разделе [Роли и разрешения](../people/roles-permissions.md).
- Установите свою [онлайн-благотворительность](./online-giving-setup.md) с помощью Stripe, которая поддерживает транзакции в нескольких валютах.
- Поймите потребности бухгалтерского учёта вашей церкви при работе с несколькими валютами.

</div>

## Включение поддержки множественных валют

Поддержка множественных валют теперь включена по умолчанию в B1. После включения:

- Члены могут давать в своей местной валюте при благотворительности онлайн
- Вы можете вручную записать пожертвования в любой валюте
- Отчёты о пожертвованиях показывают суммы в их исходной валюте
- Stripe автоматически обрабатывает преобразование валюты для онлайн-благотворительности

## Поддерживаемые валюты

Система поддерживает все основные мировые валюты, включая:

- **USD** -- Доллар Соединённых Штатов
- **EUR** -- Евро
- **GBP** -- Британский фунт
- **CAD** -- Канадский доллар
- **AUD** -- Австралийский доллар
- **MXN** -- Мексиканский песо
- **BRL** -- Бразильский реал
- **INR** -- Индийская рупия
- **CNY** -- Китайский юань
- **JPY** -- Японская иена
- И многие другие...

Доступные валюты для онлайн-благотворительности зависят от поддерживаемых валют вашего счёта Stripe.

## Запись пожертвований в разных валютах

### Онлайн пожертвования

Когда член даёт онлайн через Stripe:

1. Они выбирают предпочтительную валюту при оформлении
2. Stripe обрабатывает платёж в этой валюте
3. Пожертвование записывается в B1 с исходной суммой валюты
4. Stripe автоматически обрабатывает любое необходимое преобразование валюты в валюту по умолчанию вашего счёта

### Ручной ввод

Для записи пожертвования наличными или чеком в другой валюте:

1. Перейдите на **Пожертвования** в B1 Admin
2. Нажмите **Добавить пожертвование**
3. Выберите валюту из раскрывающегося списка валют
4. Введите сумму в этой валюте
5. Завершите остальные подробности пожертвования
6. Нажмите **Сохранить**

## Просмотр пожертвований в нескольких валютах

### Отчёты о пожертвованиях

Отчёты о пожертвованиях отображают суммы в их исходной валюте:

- Отдельные записи пожертвований показывают код валюты (например, "$100.00 USD")
- Итоги рассчитываются по каждой валюте
- Вы можете фильтровать по конкретным валютам

### Преобразованные итоги

Везде, где B1 показывает один объединённый итог -- карточки KPI сводки благотворительности, общее пожертвование партии и общее количество фонда -- пожертвования, записанные в валюте, отличной от валюты по умолчанию вашей церкви, преобразуются в валюту вашей церкви, используя текущие обменные курсы, поэтому итог - это одно значимое число вместо добавления разных валют. Примечание **Преобразовано по текущим обменным курсам** появляется под итогом, когда применено преобразование. Отдельные строки пожертвований по-прежнему отображаются в исходной валюте.

### Дарственные ведомости

При создании дарственных ведомостей:

- Каждое пожертвование отображается с его исходной валютой
- Итоги разбиты по валютам
- Члены видят точно, что они дали в каждой валюте

## Интеграция Stripe

Для онлайн-благотворительности Stripe обрабатывает транзакции в нескольких валютах:

- **Автоматическое преобразование** -- Stripe преобразует валюты в валюту по умолчанию вашего счёта
- **Обменные курсы** -- Stripe использует текущие рыночные обменные курсы
- **Комиссии** -- Преобразование валюты может повлечь за собой дополнительные комиссии Stripe
- **Валюта выплаты** -- Средства депонируются в валюте по умолчанию вашего счёта

:::info
Проверьте свою панель управления Stripe, чтобы увидеть текущие обменные курсы и любые комиссии, связанные с транзакциями в нескольких валютах.
:::

## Соображения по бухгалтерскому учёту

При работе с несколькими валютами:

- **Ведение записей** -- Отслеживайте исходные суммы пожертвований и валюты для точной отчётности
- **Обменные курсы** -- Обратите внимание, что коэффициенты преобразования Stripe могут отличаться от коэффициентов вашего банка
- **Налоговые квитанции** -- Проконсультируйтесь с вашим бухгалтером о том, как сообщать пожертвования в разных валютах в целях налогообложения
- **Распределение фондов** -- Вы можете распределять пожертвования в конкретные фонды независимо от валюты

## Лучшие практики

- **Валюта по умолчанию** -- Установите основную валюту церкви как значение по умолчанию для большинства транзакций
- **Чёткая коммуникация** -- Скажите донорам, в какой валюте они дают, во время процесса оформления
- **Согласованная отчётность** -- Объединённые итоги всегда автоматически преобразуются в валюту вашей церкви; используйте фильтр валюты для каждого пожертвования, когда вам нужно увидеть исходные суммы
- **Регулярное согласование** -- Согласуйте выплаты Stripe с вашими записями о пожертвованиях, учитывая преобразования валют

## Ограничения

- Преобразование валюты для обработки платежей обрабатывается Stripe только для онлайн-благотворительности; ручные пожертвования записываются так, как введено, без автоматического преобразования
- Исторические отчёты и отдельные строки пожертвований всегда показывают исходную валюту, в которой был записан подарок
- Объединённые итоги (карточки KPI, итоги партий, итоги фондов) преобразуются в валюту вашей церкви, используя текущие обменные курсы -- эти курсы могут незначительно отличаться от курсов вашего банка или Stripe на момент расчёта средств
