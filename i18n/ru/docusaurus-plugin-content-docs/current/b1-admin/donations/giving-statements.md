# Отчеты о пожертвованиях

<div class="article-intro">

В конце каждого года ваши жертвователи нуждаются в резюме своих налогооблагаемых пожертвований для их записей. B1 Admin упрощает создание этих отчетов для всех жертвователей сразу, сэкономив вам часы ручной работы.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Проверьте, что ваши [фонды](funds.md) правильно отмечены как **Tax Deductible** — только пожертвования в налогооблагаемые фонды появляются в отчетах
- Убедитесь, что все пожертвования [записаны](recording-donations.md) и любые онлайн-транзакции [импортированы из Stripe](stripe-import.md)

</div>

## Доступ к отчетам о пожертвованиях

1. В **B1 Admin** откройте **меню раздела** в верхнем левом углу и выберите **Donations**.
2. Нажмите **Statements**.

## Создание отчетов

1. Выберите **год** из раскрывающегося списка в верхней части страницы. Вы можете выбрать текущий год или любой из пяти предыдущих лет.
2. На странице отображается статистика для этого года, включая:
   - **Total donors** — количество людей, которые давали
   - **Total donations** — количество отдельных записей о пожертвованиях
   - **Total amount** — комбинированная сумма всех пожертвований

## Загрузка отчетов

У вас есть два варианта получения отчетов к вашим жертвователям:

### Загрузить как CSV файлы

Нажмите **Download ZIP** для загрузки ZIP файла, содержащего отдельный CSV файл для каждого жертвователя. Это полезно, если вы хотите отправить отчеты отдельно или импортировать их в другую систему.

### Печать всех отчетов

Нажмите **Print All** для открытия вида для печати каждого отчета жертвователя в вашем браузере. Затем используйте функцию печати вашего браузера для отправки их на принтер. Каждый отчет начинается на новой странице, поэтому они готовы сложить и отправить по почте.

:::tip
Запустите ваши отчеты в начале января, пока ваши записи свежи. Дважды проверьте, что ваши фонды правильно отмечены как налогооблагаемые перед созданием отчетов — только пожертвования в налогооблагаемые фонды включаются.
:::

:::info
Отчеты о пожертвованиях включают только пожертвования, назначенные фондам, которые имеют включенную настройку **Tax Deductible**. Если фонд не отмечен как налогооблагаемый, его пожертвования не будут отображаться в отчете. Вы можете управлять этой настройкой на странице [Фонды](funds.md).
:::
