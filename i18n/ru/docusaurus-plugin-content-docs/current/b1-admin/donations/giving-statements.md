# Дарственные ведомости

<div class="article-intro">

В конце каждого года ваши доноры нуждаются в резюме своих налогоприбыльных пожертвований для своих записей. B1 Admin облегчает создание этих ведомостей для всех доноров сразу, экономя вам часы ручной работы.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Убедитесь, что ваши [фонды](funds.md) правильно отмечены как **Налогоприбыльные** -- только пожертвования в налогоприбыльные фонды появляются в ведомостях
- Убедитесь, что все пожертвования были [записаны](recording-donations.md) и все онлайн-транзакции были [импортированы из Stripe](stripe-import.md)

</div>

## Доступ к дарственным ведомостям

1. В **B1 Admin**, откройте **меню раздела** в верхнем левом углу и выберите **Пожертвования**.
2. Нажмите **Ведомости**.

## Создание ведомостей

1. Выберите **год** из раскрывающегося списка в верхней части страницы. Вы можете выбрать текущий год или любой из пяти предыдущих лет.
2. Страница отображает сводную статистику за этот год, включая:
   - **Общее количество доноров** -- количество людей, которые пожертвовали
   - **Общее количество пожертвований** -- количество отдельных записей пожертвований
   - **Общая сумма** -- объединённая сумма в долларах всей благотворительности

## Загрузка ведомостей

У вас есть два варианта для предоставления ведомостей вашим донорам:

### Загрузка в виде файлов CSV

Нажмите **Загрузить ZIP**, чтобы загрузить файл ZIP, содержащий отдельный файл CSV для каждого донора. Это полезно, если вы хотите отправить ведомости отдельно или импортировать их в другую систему.

### Печать всех ведомостей

Нажмите **Печать всех**, чтобы открыть печатное представление ведомости каждого донора в вашем браузере. Оттуда используйте функцию печати вашего браузера, чтобы отправить их на принтер. Каждая ведомость начинается на новой странице, поэтому она готова к складыванию и отправке по почте.

:::tip
Запустите ваши ведомости в начале января, пока ваши записи свежи. Дважды проверьте, что ваши фонды правильно отмечены как налогоприбыльные перед созданием ведомостей -- только пожертвования в налогоприбыльные фонды включаются.
:::

:::info
Дарственные ведомости включают только пожертвования, назначенные фондам, у которых включена настройка **Налогоприбыльные**. Если фонд не отмечен как налогоприбыльный, его пожертвования не будут появляться в ведомости. Вы можете управлять этой настройкой на странице [Фонды](funds.md).
:::

## Форматы квитанций для Канады, Австралии и Новой Зеландии

Церкви вне Соединённых Штатов могут переключить ведомость на официальный формат квитанции своей страны. Перейдите на **Параметры**, откройте раздел **Благотворительность** и установите **Формат ведомости** на **Канада**, **Австралия** или **Новая Зеландия**, затем заполните появляющиеся поля: ваш регистрационный номер (регистрационный номер CRA, ABN или регистрационный номер благотворительной организации Новой Зеландии), адрес вашей организации, имя человека, уполномоченного подписывать квитанции, и для Канады город, в котором выдаются квитанции.

Ведомости затем содержат формулировки, которые ожидает ваш налоговый орган (для Канады, "Официальная квитанция в целях подоходного налога" со ссылкой CRA), номер квитанции в форме `ГОД-ИДЕНТИФИКАТОРДОНОРА`, приемлемую сумму, рассчитанную только из налогоприбыльных фондов, и отдельную строку для любых подарков в не облагаемые налогом фонды. Доноры видят тот же блок квитанции, когда они печатают свою ведомость из B1.church.
