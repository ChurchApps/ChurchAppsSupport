# Положения о взносах

<div class="article-intro">

В конце каждого года, ваши доноры нуждаются в сводке их вычитаемых налогом взносов за их записи. B1 Admin облегчает создание этих положений для всех доноров одновременно, экономя вам часы ручной работы.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Проверьте, что ваши [фонды](funds.md) правильно отмечены как **Вычитаемые из налогов** -- только взносы вычитаемым налогом фондам появляются на положениях
- Убедитесь, что все взносы были [записаны](recording-donations.md) и любые онлайн-транзакции были [импортированы из Stripe](stripe-import.md)

</div>

## Доступ к положениям о взносах

1. В **B1 Admin** откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (поисковую строку в левом верхнем углу) и разверните **Взносы**.
2. Нажмите **Положения о взносах**.

## Создание положений

1. Выберите **год** из выпадающего списка в верхней части страницы. Вы можете выбрать текущий год или любой из пяти предыдущих лет.
2. Страница отображает сводную статистику за этот год, включая:
   - **Общие доноры** -- количество людей, которые дали
   - **Общие взносы** -- количество отдельных записей взносов
   - **Общая сумма** -- объединенная сумма в долларах всех взносов

## Загрузка положений

У вас есть два варианта для получения положений вашим донорам:

### Загрузите как файлы CSV

Нажмите **Загрузить ZIP**, чтобы загрузить ZIP-файл, содержащий отдельный файл CSV для каждого донора. Это полезно, если вы хотите отправить положения по электронной почте отдельно или импортировать их в другую систему.

### Печать всех положений

Нажмите **Распечатать все**, чтобы открыть печатаемый вид каждого положения донора в вашем браузере. Оттуда используйте функцию печати вашего браузера, чтобы отправить их на принтер. Каждое положение начинается на новой странице, поэтому они готовы к складыванию и отправке по почте.

:::tip
Запустите ваши положения в начале января, пока ваши записи свежи. Дважды проверьте, что ваши фонды правильно отмечены как вычитаемые из налогов перед созданием положений -- только взносы вычитаемым налогом фондам включены.
:::

:::info
Положения о взносах включают только взносы, назначенные фондам с включенной настройкой **Вычитаемые из налогов**. Если фонд не отмечен как вычитаемый из налогов, его взносы не будут появляться на положении. Вы можете управлять этой настройкой на странице [Фонды](funds.md).
:::

## Форматы квитанций для Канады, Австралии и Новой Зеландии

Церкви вне Соединенных Штатов могут переключить положение на официальный макет квитанции их страны. Перейдите к **Параметры**, откройте раздел **Взносы**, и установите **Формат положения** на **Канада**, **Австралия** или **Новая Зеландия**, затем заполните появляющиеся поля: ваш регистрационный номер (номер регистрации CRA, ABN, или номер регистрации благотворительной организации NZ), адрес вашей организации, имя человека, уполномоченного подписывать квитанции, и для Канады город, где выпускаются квитанции.

Положения затем несут текст, который ожидает ваш налоговый орган (для Канады, "Официальная квитанция для целей налога на прибыль" со ссылкой CRA), номер квитанции в форме `ГОД-ДОНОРИДЕНТИФИКАТОР`, приемлемую сумму, считаемую только из вычитаемых налогом фондов, и отдельную строку для любых подарков невычитаемым налогом фондам. Доноры видят тот же блок квитанции, когда они распечатывают свое собственное положение из B1.church.
