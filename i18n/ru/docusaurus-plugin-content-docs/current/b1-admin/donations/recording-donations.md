# Запись пожертвований

<div class="article-intro">

Запись пожертвований в B1 Admin выполняется через систему партий. Вы создаете партию для представления сбора (например, воскресного пожертвования), а затем добавляете отдельные пожертвования в эту партию. Это гарантирует, что ваши записи о пожертвованиях организованы и легко сверяются.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Настройте ваши [фонды](funds.md), чтобы вы могли назначить пожертвования правильным категориям
- Создайте [партию](batches.md) для хранения пожертвований, которые вы собираетесь вводить
- Убедитесь, что жертвователи находятся в вашем [справочнике людей](../people/adding-people.md), чтобы вы могли найти их при вводе дарей

</div>

## Создание партии и добавление пожертвований

1. В **B1 Admin** откройте **меню раздела** в верхнем левом углу и выберите **Donations**, затем нажмите **Batches**.
2. Нажмите **Add Batch**.
3. Введите имя для партии (например, "Sunday Offering - Jan 5") и выберите дату. Нажмите **Save**.
4. Ваша новая партия отображается в списке, показывая ноль пожертвований и $0.00.
5. Нажмите на **имя партии** для его открытия.

## Ввод отдельных пожертвований

1. На странице деталей партии введите имя жертвователя в **поле поиска** для его поиска.
2. После выбора человека форма ввода пожертвования появляется с полями для **Date**, **Payment Method**, **Fund**, **Amount** и **Check Number**.
3. Заполните детали и нажмите **Add Donation**.
4. Пожертвование добавляется в таблицу ниже, и форма сбрасывается, поэтому вы можете ввести следующее.

:::tip
Вы можете быстро вводить несколько пожертвований подряд, не покидая страницу партии. Форма сбрасывается после каждого ввода, поэтому вы можете быстро пройти через стопку чеков или конвертов.
:::

## Разделение пожертвования между несколькими фондами

Иногда один жертвователь дает более чем одному фонду в одной транзакции. Для обработки этого:

1. Нажмите кнопку **Edit** в строке пожертвования.
2. В форме редактирования добавьте суммы к разным фондам. Итоговая сумма будет автоматически рассчитана из отдельных сумм фондов.
3. Нажмите **Save** для обновления пожертвования.

:::info
Разделение пожертвований между фондами является распространенным, когда жертвователь пишет один чек, назначенный для нескольких целей, таких как "General Fund" и "Missions".
:::

## Редактирование или удаление пожертвований

Чтобы отредактировать пожертвование, нажмите кнопку **Edit** в его строке в партии. Вы можете изменить дату, сумму, фонд, способ оплаты или любую другую деталь. Нажмите **Save** когда закончите.

:::tip
Заголовок страницы партии автоматически обновляется, чтобы показать общее количество пожертвований и комбинированную сумму при добавлении или редактировании записей. Используйте это для сверки квитанции о депозите.
:::

## Следующие шаги

- Проверьте ваши записи, используя [Отчеты о пожертвованиях](donation-reports.md) для проверки точности
- В конце года создайте [Отчеты о пожертвованиях](giving-statements.md) для ваших жертвователей
