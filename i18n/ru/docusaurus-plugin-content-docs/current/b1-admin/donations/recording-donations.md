# Запись благожертвований

<div class="article-intro">

Запись благожертвований в B1 Admin осуществляется через систему партий. Вы создаете партию для представления сбора (например, воскресного пожертвования), затем добавляете отдельные благожертвования в эту партию. Это обеспечивает организованное ведение ваших записей о благожертвованиях и простоту выверки.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Настройте ваши [фонды](funds.md), чтобы вы могли назначить благожертвования правильным категориям
- Создайте [партию](batches.md) для размещения благожертвований, которые вы собираетесь ввести
- Убедитесь, что доноры находятся в вашем [справочнике людей](../people/adding-people.md), чтобы вы могли найти их при вводе подарков

</div>

## Создание партии и добавление благожертвований

1. В **B1 Admin** откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (поле поиска в верхнем левом углу), разверните **Donations** и нажмите **Batches**.
2. Нажмите **Add Batch**.
3. Введите имя для партии (например, "Sunday Offering - Jan 5") и выберите дату. Нажмите **Save**.
4. Ваша новая партия появляется в списке, показывая ноль благожертвований и $0.00.
5. Нажмите на **имя партии** для ее открытия.

## Ввод отдельных благожертвований

1. На странице деталей партии введите имя донора в **поле поиска** для его поиска.
2. После выбора человека появляется форма ввода благожертвований с полями для **Date**, **Payment Method**, **Fund**, **Amount** и **Check Number**.
3. Заполните детали и нажмите **Add Donation**.
4. Благожертвование добавляется в таблицу ниже, и форма сбрасывается, чтобы вы могли ввести следующее.

:::tip
Вы можете быстро ввести несколько благожертвований подряд, не покидая страницу партии. Форма сбрасывается после каждого ввода, чтобы вы могли эффективно проходить через стопку чеков или конвертов.
:::

## Распределение благожертвования между несколькими фондами

Иногда один донор дает нескольким фондам в одной транзакции. Чтобы справиться с этим:

1. Нажмите кнопку **Edit** на строке благожертвования.
2. В форме редактирования добавьте суммы разным фондам. Итого будет автоматически рассчитано из отдельных сумм фондов.
3. Нажмите **Save** для обновления благожертвования.

:::info
Распределение благожертвований между фондами обычно встречается, когда донор пишет один чек, предназначенный для нескольких целей, таких как General Fund и Missions.
:::

## Редактирование или удаление благожертвований

Чтобы отредактировать благожертвование, нажмите кнопку **Edit** на его строке в партии. Вы можете изменить дату, сумму, фонд, способ платежа или любые другие детали. Нажмите **Save** когда вы закончите.

:::tip
Заголовок страницы партии автоматически обновляется для отображения общего количества благожертвований и объединенной суммы в долларах при добавлении или редактировании записей. Используйте это для выверки против вашего квитанции о депозите.
:::

## Возврат благожертвования

Если донор был ошибочно начислен или просит вернуть его деньги, вы можете вернуть завершенное благожертвование прямо с его экрана редактирования -- нет необходимости переходить на панель инструментов вашего платежного шлюза.

1. Откройте благожертвование и нажмите **Edit**.
2. Нажмите кнопку **Refund** рядом с Delete в нижней части формы.
3. Подтвердите диалог: "Refund this donation in full through the payment gateway? This cannot be undone."

Благожертвование полностью возвращается через исходный платежный шлюз и отмечается **Refunded** в ваших списках благожертвований.

:::warning
Возвраты - это только полные возвраты -- нет способа вернуть частичную сумму из B1 Admin. Возврат также не может быть отменен после подтверждения.
:::

:::info
Кнопка **Refund** появляется только для благожертвований, которые были оплачены онлайн (они имеют транзакцию шлюза) и находятся в состоянии **Complete**. Вручную введенные благожертвования (наличные, чек) не имеют транзакции шлюза для возврата -- отредактируйте или удалите их вместо этого.
:::

- В конце года создайте [Giving Statements](giving-statements.md) для ваших доноров
