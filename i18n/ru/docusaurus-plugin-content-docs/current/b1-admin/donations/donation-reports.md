# Отчеты о пожертвованиях

Отчеты о пожертвованиях предоставляют подробное представление деятельности по пожертвованиям вашей церкви.

## Типы отчетов

### Сводный отчет

Общее представление всех пожертвований за период:

- Общая сумма пожертвований
- Среднее пожертвование
- Уникальные жертвователи
- Пожертвования по фондам

### Детальный отчет

Разбор по жертвователям и датам:

- Имя жертвователя
- Сумма пожертвования
- Назначенный фонд
- Дата пожертвования
- Способ оплаты

### Отчет по фондам

Анализ пожертвований по каждому фонду:

- Общая сумма по фонду
- Количество пожертвований
- Среднее пожертвование
- Тренды во времени

## Создание отчета

1. Перейдите в раздел **Donations**
2. Выберите **Reports**
3. Выберите тип отчета
4. Установите диапазон дат
5. Нажмите **Generate Report**

## Экспорт отчета

Вы можете экспортировать отчет:

- CSV для Excel
- PDF для печати
- Excel для углубленного анализа

## Фильтры отчета

- Диапазон дат
- Фонд
- Жертвователь
- Способ оплаты

## Сохранение отчетов

Сохраняйте часто используемые отчеты для быстрого доступа:

1. На отчете нажмите **Save**
2. Дайте отчету имя
3. Нажмите **Save**

Отчет будет доступен в разделе **Saved Reports**.
