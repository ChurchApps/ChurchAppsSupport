# Отчеты взносов

<div class="article-intro">

B1 Admin дает вам несколько способов просмотра и анализа данных о взносах вашей церкви. Панель взносов на странице **Сводка** раздела "Взносы" предоставляет визуальный обзор с диаграммами и фильтрами, тогда как раздел "Отчеты" предоставляет более подробный отчет "Сводка взносов". Используйте эти инструменты для отслеживания тенденций взносов, подготовки к встречам совета или сверки ваших записей.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Убедитесь, что взносы были [записаны в партиях](recording-donations.md) или [импортированы из Stripe](stripe-import.md)
- Проверьте, что ваши [фонды](funds.md) установлены правильно, чтобы взносы были правильно категоризированы

</div>

## Панель взносов

Панель взносов - это вкладка **Панель** страницы **Сводка**, первая страница, которую вы видите при открытии раздела **Взносы**.

1. Откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (поисковую строку в левом верхнем углу B1 Admin), разверните **Взносы**, и нажмите **Сводка**. Страница **Сводка** открывается на вкладке **Панель**.
2. Используйте переключатель **Еженедельно**, **Ежемесячно**, и **Ежеквартально** выше отчета, чтобы выбрать, как группируются взносы.
3. На панели **Фильтр отчета** установите **Дату начала** и **Дату окончания** (по умолчанию, прошлый год до вчера) и опционально выберите **Фонд**, затем нажмите **Запустить отчет**. Отчет запускается автоматически с значениями по умолчанию при открытии страницы.
4. Четыре **карточки KPI** отображают ваши показатели взносов за выбранный диапазон:
   - **Общие взносы** -- Общая сумма пожертвована.
   - **Средний подарок** -- Средний размер пожертвования.
   - **Уникальные доноры** -- Количество различных людей, которые дали.
   - **Общие взносы** -- Общее количество отдельных взносов.
5. Ниже KPIs находится столбиковая диаграмма, показывающая взносы за неделю, месяц или квартал, разбитая по фондам.
6. Нажмите **Параметры загрузки** и выберите **Сводка**, чтобы экспортировать CSV итогов по периодам и фондам, или нажмите значок печати, чтобы распечатать отчет. Имя вашей церкви появляется в верхней части распечатанного отчета.

Если взносы в период были сделаны в более чем одной валюте, итоги KPI конвертируются в валюту вашей церкви и под карточками появляется примечание **Конвертировано по текущим курсам обмена**. См. [Поддержка нескольких валют](./multi-currency.md#converted-totals) для деталей.

:::info
Панель показывает совокупные данные о взносах. Она не включает отдельные имена доноров. Для деталей на уровне доноров используйте страницу [Партии](batches.md).
:::

## Неактивные доноры

Вкладка **Неактивные доноры** рядом с вкладкой **Панель** перечисляет людей, которые дали в один период, но не с тех пор. По умолчанию он сравнивает прошлый календарный год с текущим годом до сих пор; измените любой диапазон дат, чтобы расширить или сузить поиск. Каждая строка показывает человека, дату его последнего подарка и его итог за предыдущий период, и **Параметры загрузки > Сводка** загружает список как CSV для последующей рассылки или списка звонков.

## Просмотр деталей на уровне донора

Для разбора того, кто дал, сколько, и на какой фонд:

1. Перейдите к **Взносы > Партии**.
2. Нажмите на **имя партии**, чтобы открыть ее.
3. Страница деталей партии перечисляет каждый взнос с именем донора, суммой, фондом, датой, и методом платежа.
4. Нажмите на **имя донора**, чтобы увидеть разбор того, сколько раз они дали и сколько каждый раз.
5. Нажмите на **ID взноса**, чтобы открыть боковую панель с полными деталями для этого отдельного взноса.
6. Нажмите **Загрузить**, чтобы экспортировать CSV со всей информацией донора и взноса для этой партии.

## Отчет сводки взносов

Отчеты взносов встроены прямо в раздел "Взносы" -- страница "Сводка" служит вашим отчетом о сводке взносов:

1. В Jump меню выберите **Взносы > Сводка**.
2. На вкладке **Панель** установите **Дату начала** и **Дату окончания** на панели **Фильтр отчета** и нажмите **Запустить отчет**.
3. Нажмите **Параметры загрузки** и выберите **Сводка**, чтобы экспортировать отчет как файл CSV.

## Экспортирование данных

Вы можете экспортировать данные взносов из нескольких мест:

- **Страница сводки** -- загрузите CSV итогов взносов по неделям, месяцам, или кварталам и фондам
- **Страница деталей партии** -- загрузите CSV отдельных взносов с деталями донора
- **Страница деталей фонда** -- загрузите историю взносов для определенного фонда

:::tip
Для отчетности в конце года объедините экспорт страницы "Сводка" с инструментом [Положения о взносах](giving-statements.md), чтобы получить как совокупные тенденции, так и отдельные утверждения доноров.
:::

## Следующие шаги

- Создайте [Положения о взносах](giving-statements.md) для ваших доноров в конце года
- Просмотрите отдельные [партии](batches.md), чтобы проверить детали взносов
- Проверьте страницы деталей [фонда](funds.md) для разбора взносов по категориям
