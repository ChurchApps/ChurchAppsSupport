# Отчёты о пожертвованиях

<div class="article-intro">

B1 Admin предоставляет несколько способов просмотра и анализа данных благотворительности вашей церкви. Страница сводки пожертвований предоставляет визуальный обзор с диаграммами и фильтрами, в то время как раздел "Отчёты" предлагает более подробный отчёт о сводке пожертвований. Используйте эти инструменты для отслеживания тенденций благотворительности, подготовки к совещаниям совета или согласования ваших записей.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Убедитесь, что пожертвования были [записаны партиями](recording-donations.md) или [импортированы из Stripe](stripe-import.md)
- Проверьте, что ваши [фонды](funds.md) правильно настроены, чтобы пожертвования были правильно классифицированы

</div>

## Панель благотворительности

**Панель благотворительности** - это первое, что вы видите при открытии раздела **Пожертвования**. Она предоставляет высокоуровневый обзор вашей деятельности по благотворительности с ключевыми показателями эффективности.

1. Откройте **меню раздела** в верхнем левом углу и выберите **Пожертвования**, чтобы открыть панель.
2. В верхней части четыре **карточки KPI** отображают ваши метрики благотворительности с одного взгляда:
   - **Общая благотворительность** -- Общая сумма пожертвована в выбранный период.
   - **Средний подарок** -- Средний размер пожертвования.
   - **Уникальные доноры** -- Количество разных людей, которые пожертвовали.
   - **Общее количество пожертвований** -- Общее количество отдельных пожертвований.
3. Используйте **переключатель периода** для переключения между **еженедельным**, **ежемесячным** и **квартальным** представлениями.
4. Ниже KPI диаграмма отображает тенденции благотворительности для выбранного периода.
5. Нажмите **Загрузить**, чтобы экспортировать файл CSV с итогами благотворительности.

Если пожертвования в этот период были сделаны более чем в одной валюте, итоги KPI преобразуются в валюту вашей церкви и появляется примечание **Преобразовано по текущим обменным курсам** ниже карточек. Подробности см. в разделе [Поддержка множественных валют](./multi-currency.md#converted-totals).

## Прерванные доноры

Вкладка **Прерванные доноры** рядом с панелью перечисляет людей, которые пожертвовали в один период, но не пожертвовали с тех пор. По умолчанию она сравнивает прошлый календарный год с текущим годом на сегодняшний день; измените любой диапазон дат, чтобы расширить или сузить поиск. Каждая строка показывает человека, дату их последнего подарка и их итог за более ранний период, а **Экспорт** загружает список как CSV для последующей рассылки или списка вызовов.

## Страница сводки пожертвований

Страница **Сводка** предоставляет более подробные совокупные данные о благотворительности.

1. Откройте **меню раздела** в верхнем левом углу и выберите **Пожертвования**, чтобы открыть страницу "Сводка".
2. Используйте **фильтр диапазона дат**, чтобы выбрать временной период, который вы хотите просмотреть. Установите более раннюю дату сверху и более позднюю дату снизу.
3. Страница отображает еженедельную диаграмму благотворительности, чтобы вы могли видеть тенденции с одного взгляда.
4. Нажмите **Загрузить**, чтобы экспортировать файл CSV с общей суммой пожертвована, неделей, в которую оно было пожертвовано, и фондом, которому оно было пожертвовано.

:::info
Страница "Сводка" показывает совокупные данные о благотворительности. Она не включает индивидуальные имена доноров. Для подробной информации на уровне доноров используйте страницу [Партии](batches.md).
:::

## Просмотр подробной информации на уровне донора

Для разбивки того, кто пожертвовал, сколько и какому фонду:

1. Перейдите на **Пожертвования > Партии**.
2. Нажмите на **название партии**, чтобы открыть её.
3. Страница деталей партии перечисляет каждое пожертвование с именем донора, суммой, фондом, датой и методом платежа.
4. Нажмите на **имя донора**, чтобы увидеть разбивку того, сколько раз они пожертвовали и сколько каждый раз.
5. Нажмите на **ID пожертвования**, чтобы открыть боковую панель с полными подробностями этого отдельного пожертвования.
6. Нажмите **Загрузить**, чтобы экспортировать CSV со всей информацией о доноре и пожертвованиях для этой партии.

## Отчёт о сводке пожертвований

Отчёты о пожертвованиях встроены непосредственно в раздел "Пожертвования" -- страница "Сводка" служит вашим отчётом о сводке пожертвований:

1. Откройте **меню раздела** в верхнем левом углу и выберите **Пожертвования**, чтобы открыть страницу "Сводка".
2. Используйте **фильтр диапазона дат**, чтобы выбрать период для отчёта.
3. Нажмите **Загрузить**, чтобы экспортировать отчёт в виде файла CSV.

## Экспорт данных

Вы можете экспортировать данные о пожертвованиях из нескольких мест:

- **Страница "Сводка"** -- загрузить CSV еженедельных итогов благотворительности по фондам
- **Страница подробностей партии** -- загрузить CSV отдельных пожертвований с подробностями о доноре
- **Страница подробностей фонда** -- загрузить историю пожертвований для конкретного фонда

:::tip
Для годовой отчётности объедините экспорт страницы "Сводка" с инструментом [Дарственные ведомости](giving-statements.md), чтобы получить как совокупные тенденции, так и индивидуальные ведомости доноров.
:::

## Следующие шаги

- Создайте [Дарственные ведомости](giving-statements.md) для ваших доноров в конце года
- Проверьте отдельные [партии](batches.md), чтобы проверить подробности пожертвований
- Проверьте страницы подробностей [фонда](funds.md) для разбивки благотворительности по категориям
