# Отчет о днях рождения

<div class="article-intro">

Отчет о днях рождения помогает вам оставаться на связи с вашей церковью, показывая членов с предстоящими днями рождения. Используйте его для планирования торжеств, отправки открыток или объявления во время услуг.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Убедитесь, что даты рождения введены в профиль каждого человека. Смотрите [Добавление людей](../people/adding-people.md) для деталей.
- Вам нужны соответствующие [разрешения](../settings/roles-permissions.md) для доступа к отчетам

</div>

## Запуск отчета

1. Перейдите непосредственно на **admin.b1.church/reports/birthdays** в вашем браузере (отчеты не имеют записи в меню навигации — добавление адреса в закладки — это самый простой способ вернуться).
2. Выберите **месяц**, который вы хотите из выпадающего списка. Вы можете по желанию ограничить результаты одной **группой**.
3. Нажмите **Run Report**. В отчете перечислены все люди с днем рождения в этом месяце с датой рождения — готовый к прямому прочтению в бюллетень или список объявлений.

## Что показывает отчет

Отчет о днях рождения отображает:

- **День рождения** -- Дата его дня рождения.
- **Имя** -- Имя человека из вашей базы данных церкви.

Результаты охватывают выбранный месяц, что облегчает просмотр предстоящих дней рождения.

## Практическое применение

- **Еженедельные объявления** -- Запустите отчет на предстоящую неделю и включите дни рождения в ваш бюллетень или объявления.
- **Открытки ко дню рождения** -- Создайте список на месяц и попросите вашу команду отправить личные открытки ко дню рождения.
- **Лидеры малых групп** -- Лидеры групп могут запустить отчет, чтобы помнить дни рождения членов их группы.
- **Торжественные отмечания** -- Фильтруйте по определенным диапазонам дат для планирования торжественных отмечаний дней рождения.

:::tip
Запустите этот отчет в начале каждого месяца для планирования. Вы можете установить диапазон дат, чтобы охватить весь месяц, чтобы у вас было время подготовить открытки или объявления.
:::

:::info
Данные о днях рождения поступают из поля даты рождения в профиле каждого человека. Убедитесь, что ваши [записи о членстве](../people/adding-people.md) актуальны для получения точных результатов.
:::
