# Отчет о днях рождения

<div class="article-intro">

Отчет о днях рождения показывает дни рождения членов вашей церкви, отсортированные по месяцам. Используйте этот отчет для отправки открыток ко дню рождения, организации вечеринок или признания этих особых дней для ваших прихожан.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Члены должны иметь даты рождения в своих профилях.
- Для начала см. [Добавление людей](../people/adding-people.md).

</div>

## Просмотр отчета о днях рождения

1. Перейдите в раздел **Reports** в B1 Admin.
2. Нажмите на **Birthday Report**.
3. Выберите месяц из раскрывающегося списка.
4. Отчет показывает всех членов в вашей церкви, чьи дни рождения падают в этом месяце.

## Информация в отчете

Отчет показывает:

- **Name** — имя члена
- **Birthday** — дата дня рождения
- **Age** — возраст, который они исполняют
- **Contact** — информация контакта (номер телефона и адрес электронной почты)

## Использование отчета

- **Отправка открыток** — используйте список контактов для отправки открыток ко дню рождения
- **Объявления в церкви** — выделите дни рождения в информационном бюллетене
- **Вечеринки** — организуйте групповые празднования дней рождения
- **Молитвенные просьбы** — включите дни рождения в вашу молитвенную жизнь

## Советы

- Убедитесь, что даты рождения членов актуальны
- Установите напоминание для проверки этого отчета каждый месяц
- Подумайте о том, чтобы позвонить или посетить старейших членов в день их рождения
- Используйте информацию для создания функции ежемесячного признания дней рождения
