# Отчеты

<div class="article-intro">

Раздел "Reports" в B1 Admin содержит инструменты для создания и просмотра различных отчетов о деятельности вашей церкви, включая посещаемость, пожертвования, дни рождения, юбилеи и многое другое.

</div>

## Доступные отчеты

- **Attendance Reports** — отслеживайте посещаемость по группам, кампусам и времени служения
- **Donation Reports** — просматривайте пожертвования по фондам и жертвователям
- **Birthday Report** — найдите дни рождения членов по месяцам
- **Anniversary Report** — найдите дни свадьб членов по месяцам
- **Audit Log** — просмотрите все изменения, внесенные в систему

## Типичное использование отчетов

- **Связывание с прихожанами** — используйте отчеты о днях рождения и юбилеях для отправки поздравлений
- **Улучшение посещаемости** — используйте отчеты о посещаемости для выявления тенденций и следов
- **Финансовое планирование** — используйте отчеты о пожертвованиях для бюджетирования и планирования
- **Завершение года** — создавайте отчеты о пожертвованиях в конце года для налоговых целей
