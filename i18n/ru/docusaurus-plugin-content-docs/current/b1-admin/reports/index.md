# Отчеты

<div class="article-intro">

На странице «Отчеты» вы можете быстро получить доступ к готовым отчетам, которые помогут вам понять данные вашей церкви. Используйте эти отчеты для отслеживания тенденций посещаемости, мониторинга дарительской деятельности и взаимодействия с вашей церковью через торжественные отмечания дней рождения.

</div>

## Доступные отчеты

Отчеты не имеют записи в меню навигации B1 Admin -- перейдите непосредственно на URL отчета, который вы хотите (добавление его в закладки -- это самый простой способ вернуться). Каждый отчет открывается прямо на его фильтры.

- **[Отчет о днях рождения](./birthday-report)** (`admin.b1.church/reports/birthdays`) -- Просмотрите предстоящие дни рождения членов вашей церкви.
- **[Отчет об юбилеях](./anniversary-report)** (`admin.b1.church/reports/anniversaries`) -- Просмотрите предстоящие годовщины свадьбы членов вашей церкви.
- **[Тенденция посещаемости](./attendance-reports)** (`admin.b1.church/reports/attendanceTrend`) -- Посмотрите, как закономерности посещаемости меняются с течением времени в ваших услугах.
- **[Посещаемость группы](./attendance-reports)** (`admin.b1.church/reports/groupAttendance`) -- Просмотрите итоги посещаемости по группам за выбранный диапазон дат.
- **[Ежедневная посещаемость группы](./attendance-reports)** (`admin.b1.church/reports/dailyGroupAttendance`) -- Получите разбивку данных о посещаемости группы по дням.
- **[Сводка по пожертвованиям](./donation-summary)** (`admin.b1.church/reports/donationSummary`) -- Просмотрите итоги даров и тенденции для финансового планирования.
- **[Журнал аудита](./audit-log)** -- Отследите все изменения и действия в вашей системе управления церковью (находится в Settings > Audit Log).

## Использование отчетов

1. Перейдите непосредственно на URL отчета, например **admin.b1.church/reports/birthdays**.
2. Используйте **фильтры** в верхней части отчета, чтобы сузить данные по диапазону дат, группе, услуге или другим критериям.
3. Просмотрите результаты, отображаемые в отчете.

:::tip
Регулярно запускайте отчеты, чтобы отслеживать тенденции посещаемости, предстоящие дни рождения и закономерности даров. Эти данные помогают вам планировать служения и аутрич более эффективно.
:::

:::info
Данные отчета зависят от последовательного ввода данных. Убедитесь, что ваша команда [отслеживает посещаемость](../attendance/tracking-attendance.md), [записывает пожертвования](../donations/recording-donations.md) и поддерживает [записи о людях](../people/adding-people.md) в актуальном состоянии для получения наиболее точных результатов.
:::
