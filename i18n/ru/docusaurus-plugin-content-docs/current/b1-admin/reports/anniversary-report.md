# Отчет об юбилеях

<div class="article-intro">

Отчет об юбилеях помогает вам оставаться на связи с вашей церковью, показывая членов с предстоящими годовщинами свадьбы. Используйте его для планирования торжеств, отправки открыток или объявления во время услуг.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Убедитесь, что даты годовщин введены в профиль каждого человека. Смотрите [Добавление людей](../people/adding-people.md) для деталей.
- Вам нужны соответствующие [разрешения](../settings/roles-permissions.md) для доступа к отчетам

</div>

## Запуск отчета

1. Перейдите непосредственно на **admin.b1.church/reports/anniversaries** в вашем браузере (отчеты не имеют записи в меню навигации — добавление адреса в закладки — это самый простой способ вернуться).
2. Выберите **месяц**, который вы хотите из выпадающего списка. Вы можете по желанию ограничить результаты одной **группой**.
3. Нажмите **Run Report**. В отчете перечислены все люди с юбилеем в этом месяце с датой — готовый к прямому прочтению в бюллетень или список объявлений.

## Что показывает отчет

Отчет об юбилеях отображает:

- **Юбилей** -- Дата их свадебного юбилея.
- **Имя** -- Имя человека из вашей базы данных церкви.

Результаты охватывают выбранный месяц, что облегчает просмотр предстоящих юбилеев.

## Практическое применение

- **Еженедельные объявления** -- Запустите отчет на предстоящую неделю и включите юбилеи в ваш бюллетень или объявления.
- **Открытки к юбилею** -- Создайте список на месяц и попросите вашу команду отправить личные открытки к юбилею.
- **Лидеры малых групп** -- Лидеры групп могут запустить отчет, чтобы помнить юбилеи членов их группы.
- **Торжественные отмечания** -- Фильтруйте по определенным диапазонам дат для планирования торжественных отмечаний юбилеев.

:::tip
Запустите этот отчет в начале каждого месяца для планирования. Вы можете установить диапазон дат, чтобы охватить весь месяц, чтобы у вас было время подготовить открытки или объявления.
:::

:::info
Данные о юбилеях поступают из поля юбилея в профиле каждого человека. Убедитесь, что ваши [записи о членстве](../people/adding-people.md) актуальны для получения точных результатов.
:::
