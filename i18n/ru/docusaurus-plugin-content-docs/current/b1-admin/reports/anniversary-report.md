# Список годовщин свадеб

<div class="article-intro">

Нужен список всех, у кого годовщина свадьбы в определённом месяце, — для бюллетеня, открыток или объявлений? Поиск по людям позволяет фильтровать по **Anniversary Month** и показывать даты прямо в результатах.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Убедитесь, что даты годовщин внесены в профиль каждого человека. Подробнее см. в [Добавление людей](../people/adding-people.md).
- Вам нужно право на просмотр People. См. [Роли и права доступа](../settings/roles-permissions.md).

</div>

## Список годовщин за месяц {#getting-an-anniversary-list-for-a-month}

1. Откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в левом верхнем углу B1 Admin), раскройте **People** и нажмите **People**.
2. Под полем поиска нажмите **Advanced**.
3. Раскройте раздел **Demographics**, отметьте **Anniversary Month** и выберите месяц.
4. Результаты обновляются сразу после установки фильтра: появляются все, у кого годовщина в этом месяце.
5. Чтобы увидеть даты, переключите **View as** на **Table**, затем нажмите значок **Select columns** в заголовке страницы и включите столбец **Anniversary**. Если вам удобнее сортировать или печатать список, нажмите **Export**, чтобы скачать его в виде таблицы.

## Практическое применение {#practical-uses}

- **Еженедельные бюллетени** — запускайте список за текущий месяц и включайте годовщины в бюллетень или объявления.
- **Открытки к годовщинам** — выгрузите список за месяц и передайте команде, которая пишет открытки.
- **Памятные даты** — сочетайте с фильтром **Years Married**, чтобы найти круглые годовщины.

:::tip
Запускайте этот список в начале каждого месяца, чтобы успеть подготовить открытки или объявления до наступления годовщин.
:::

:::info
Данные о годовщинах берутся из поля годовщины в профиле каждого человека. Если кого-то нет в списке, нужно просто добавить дату в его профиль. См. [Добавление людей](../people/adding-people.md).
:::
