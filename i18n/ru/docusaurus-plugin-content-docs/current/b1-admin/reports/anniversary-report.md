# Отчет об юбилеях

<div class="article-intro">

Отчет об юбилеях показывает годовщины брака членов вашей церкви, отсортированные по месяцам. Используйте этот отчет для отправки поздравлений и признания особых вех в семейной жизни ваших членов.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Члены должны иметь информацию о браке (дату и статус) в своих профилях.
- Для начала см. [Добавление людей](../people/adding-people.md).

</div>

## Просмотр отчета об юбилеях

1. Перейдите в раздел **Reports** в B1 Admin.
2. Нажмите на **Anniversary Report**.
3. Выберите месяц из раскрывающегося списка.
4. Отчет показывает всех членов в вашей церкви, чей юбилей падает в этом месяце.

## Информация в отчете

Отчет показывает:

- **Name** — имя мужа/жены (супружеской пары)
- **Anniversary Date** — дата годовщины брака
- **Years Together** — сколько лет они вместе
- **Contact** — информация контакта (номер телефона и адрес электронной почты)

## Использование отчета

- **Отправка поздравлений** — используйте список контактов для отправки открыток или электронных писем с поздравлениями
- **Объявления в церкви** — выделите юбилеи в информационном бюллетене или объявлениях
- **Молитвенные просьбы** — включите юбиляров в вашу молитвенную жизнь

## Советы

- Убедитесь, что информация о браке членов актуальна, чтобы отчет был точным
- Установите напоминание для проверки этого отчета каждый месяц
- Подумайте о признании юбилеев в рамках вашего служения
