# Сводка по пожертвованиям

<div class="article-intro">

Отчет о сводке пожертвований дает вам четкую картину дарительской деятельности вашей церкви. Используйте его для отслеживания общего количества пожертвований, мониторинга тенденций даров и подготовки финансовых отчетов для вашей команды лидерства.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Убедитесь, что пожертвования [записываются последовательно](../donations/recording-donations.md) в вашу систему
- Вам нужны соответствующие [разрешения](../settings/roles-permissions.md) для доступа к финансовым отчетам

</div>

## Запуск отчета

1. Перейдите непосредственно на **admin.b1.church/reports/donationSummary** в вашем браузере (отчеты не имеют записи в меню навигации — добавление адреса в закладки — это самый простой способ вернуться).
2. Установите **диапазон дат** для определения периода отчетности.
3. Примените дополнительные фильтры, такие как **фонд** или другие критерии для сужения результатов.
4. В отчете будет отображена сводка по дарам за выбранный период.

## Что показывает отчет

Отчет о сводке пожертвований включает:

- **Всего пожертвований** -- Общая сумма дарения за выбранный период.
- **Количество дарителей** -- Количество уникальных дарителей, которые внесли вклад.
- **Суммы по фондам** -- Разбивка по дарам в разных фондах, если применимо.

## Практическое применение

- **Финансовое планирование** -- Проанализируйте тенденции даров, чтобы прогнозировать будущие доходы и спланировать свой бюджет.
- **Отчеты совета** -- Создавайте сводки для регулярных встреч совета или руководства с четкими данными о дарах.
- **Обзоры за год** -- Запустите отчет на весь год, чтобы подготовить годовые финансовые сводки.
- **Отслеживание кампании** -- Фильтруйте по фонду для отслеживания прогресса специальных кампаний даров или строительных проектов.
- **Сезонный анализ** -- Сравните дары в разные периоды, чтобы понять сезонные закономерности.

:::tip
Запускайте этот отчет ежемесячно, чтобы оставаться информированным о финансовом здоровье вашей церкви. Сравнение данных месяц за месяцем помогает выявлять тенденции на ранней стадии.
:::

:::warning
Данные о пожертвованиях поступают из записанных взносов в вашу систему. Убедитесь, что пожертвования вводятся последовательно -- будь то онлайн-дарение, обработка чеков или ручной ввод -- для получения наиболее точных отчетов. Смотрите [Запись пожертвований](../donations/recording-donations.md) для деталей.
:::
