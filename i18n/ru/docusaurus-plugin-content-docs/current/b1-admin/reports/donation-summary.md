# Сводка пожертвований

<div class="article-intro">

Отчёт Donation Summary даёт ясную картину пожертвований вашей церкви. Используйте его, чтобы отслеживать итоги пожертвований, наблюдать за тенденциями и готовить финансовые отчёты для руководства.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Убедитесь, что пожертвования последовательно [записываются](../donations/recording-donations.md) в системе
- Вам нужно разрешение [View Donation Summaries](../settings/roles-permissions.md)

</div>

## Запуск отчёта {#running-the-report}

1. Откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу B1 Admin), раскройте **Donations** и нажмите **Summary**. Отчёт сразу запускается за прошлый год.
2. Выберите **Weekly**, **Monthly** или **Quarterly**, чтобы задать группировку пожертвований.
3. На панели **Filter Report** укажите **Start Date** и **End Date**, при необходимости выберите **Fund**, и нажмите **Run Report**.
4. Нажмите **Download Options** и выберите **Summary**, чтобы скачать итоги в CSV, или нажмите значок печати, чтобы распечатать отчёт.

Подробнее об этой странице см. в разделе [Отчёты о пожертвованиях](../donations/donation-reports.md#giving-dashboard).

## Что показывает отчёт {#what-the-report-shows}

Сводка пожертвований включает:

- **Total Giving** — общая сумма пожертвований за выбранный период.
- **Average Gift** и **Total Donations** — средний размер пожертвования и количество пожертвований.
- **Unique Donors** — количество уникальных жертвователей.
- **Amounts by fund** — столбчатую диаграмму пожертвований по неделям, месяцам или кварталам с разбивкой по фондам.

## Практическое применение {#practical-uses}

- **Финансовое планирование** — изучайте тенденции пожертвований, чтобы прогнозировать будущие доходы и планировать бюджет.
- **Отчёты для правления** — готовьте сводки для регулярных заседаний правления или руководства с понятными данными о пожертвованиях.
- **Итоги года** — запустите отчёт за весь год, чтобы подготовить годовые финансовые сводки.
- **Отслеживание кампаний** — фильтруйте по фонду, чтобы отслеживать ход специальных кампаний пожертвований или строительных проектов.
- **Сезонный анализ** — сравнивайте пожертвования за разные периоды, чтобы понимать сезонные закономерности.

:::tip
Запускайте этот отчёт ежемесячно, чтобы быть в курсе финансового состояния церкви. Сравнение данных от месяца к месяцу помогает заранее замечать тенденции.
:::

:::warning
Данные о пожертвованиях берутся из записанных взносов в вашей системе. Чтобы отчёты были максимально точными, следите за тем, чтобы пожертвования вносились последовательно — будь то онлайн-пожертвования, обработка чеков или ручной ввод. Подробности см. в разделе [Запись пожертвований](../donations/recording-donations.md).
:::
