# Журнал аудита

<div class="article-intro">

Журнал аудита отслеживает все значительные действия и изменения в вашей системе управления церковью. Используйте его для проверки активности входа, отслеживания того, кто вносил изменения в записи людей, мониторинга обновлений разрешений и поддержания подотчетности в вашей команде.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Учетная запись B1 Admin с доступом администратора сервера
- Перейдите в **Параметры**, чтобы найти журнал аудита

</div>

## Просмотр журнала аудита

1. Откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу B1 Admin) и разверните **Параметры**.
2. Щелкните **Журнал аудита**.
3. Журнал отображает недавние записи в таблице со следующими столбцами:
   - **Дата** - когда произошло действие.
   - **Категория** - тип действия (раскрашено для быстрого сканирования).
   - **Действие** - что было сделано (например, создание, обновление, удаление, login_success).
   - **Сущность** - тип и ID затронутой записи.
   - **IP адрес** - IP адрес пользователя, который выполнил действие.
   - **Детали** - краткое описание конкретных сделанных изменений.

## Фильтрация журнала

Используйте фильтры в верхней части страницы для сужения результатов:

- **Категория** - фильтр по типу действия:
  - **Все категории** - показать все.
  - **Вход** - успешные и неудачные попытки входа.
  - **Люди** - создание, обновление или удаление записей о людях.
  - **Разрешения** - предоставление и отзыв разрешений.
  - **Пожертвования** - изменения в записях о пожертвованиях.
  - **Группы** - действия по управлению группами.
  - **Формы** - активность отправки форм.
  - **Параметры** - изменения конфигурации.
- **Дата начала** - показать записи с этой даты вперед.
- **Дата окончания** - показать записи до этой даты.

Щелкните **Поиск** после установки фильтров, чтобы обновить результаты.

## Понимание категорий

Каждая категория раскрашена для быстрого определения:

- **Вход** - синий чип. Отслеживает успешные и неудачные попытки входа.
- **Люди** - фиолетовый чип. Отслеживает создание, обновление и удаление записей о людях.
- **Разрешения** - красный чип. Отслеживает, когда права доступа предоставляются или отзываются.
- **Пожертвования** - зеленый чип. Отслеживает изменения в записях о пожертвованиях.
- **Группы** - серый чип. Отслеживает операции управления группами.
- **Формы** - оранжевый чип. Отслеживает активность отправки форм.
- **Параметры** - желтый чип. Отслеживает изменения конфигурации.

## Экспорт журнала

Когда отображаются записи журнала, появляется кнопка **Загрузить CSV**. Щелкните ее, чтобы экспортировать текущие отфильтрованные результаты в таблицу для автономного просмотра или ведения записей.

## Постраничная разбивка

Используйте элементы управления постраничной разбивкой в нижней части таблицы для навигации по результатам. Вы можете отображать 25, 50 или 100 записей на странице.

:::info
Записи журнала аудита автоматически сохраняются в течение одного года. Записи старше 365 дней удаляются для сохранения производительности системы.
:::

:::tip
Регулярно просматривайте журнал аудита, особенно после подготовки новых членов команды или внесения значительных изменений конфигурации. Это помогает выявить неожиданную активность на раннем этапе.
:::
