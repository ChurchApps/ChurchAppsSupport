# Отчёты о посещаемости

<div class="article-intro">

B1 Admin предоставляет три отчёта о посещаемости, которые помогают понять, как люди участвуют в ваших служениях и группах. Каждый отчёт даёт свой взгляд на данные о посещаемости — от общих тенденций до разбивки по дням.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Убедитесь, что посещаемость [последовательно учитывается](../attendance/tracking-attendance.md) для ваших служений и групп
- Убедитесь, что ваши [группы](../groups/creating-groups.md) и служения настроены в B1 Admin
- Вам нужны соответствующие [права доступа](../settings/roles-permissions.md), чтобы открывать отчёты

</div>

## Тенденция посещаемости

Отчёт Attendance Trend показывает, как посещаемость ваших служений меняется со временем.

1. Откройте в браузере адрес **admin.b1.church/reports/attendanceTrend** (в меню навигации отчётов нет — проще всего вернуться к нему, сохранив адрес в закладки). Тот же отчёт есть и на странице Attendance: нажмите **All years», затем выберите вкладку **Attendance Trend**.
2. По желанию выберите **Campus**, **Service**, **Service Time** или **Group», чтобы отфильтровать результаты.
3. Задайте **Start Date** и **End Date**. По умолчанию отчёт охватывает последний год — от одного года назад до сегодняшнего дня, а конечная дата включается полностью. Нажмите **Run Report**.
4. Отчёт показывает столбчатую диаграмму и таблицу с общим количеством посещений по неделям. Каждая неделя подписана датой воскресенья этой недели, а в столбце таблицы **Session Dates** перечислены фактические даты недели, в которые была посещаемость (например, «9/27, 9/30»).

Этот отчёт полезен для выявления закономерностей, например сезонных спадов, роста или влияния специальных мероприятий.

## Посещаемость групп

Отчёт Group Attendance показывает, кто посетил каждое занятие группы в заданном диапазоне дат.

1. Откройте в браузере адрес **admin.b1.church/reports/groupAttendance** или на странице Attendance нажмите **All years** и выберите вкладку **Group Attendance**.
2. По желанию выберите **Campus** и **Service**.
3. Задайте **Start Date** и **End Date**. По умолчанию отчёт охватывает период с прошлого воскресенья по сегодняшний день, а конечная дата включается полностью.
4. Нажмите **Run Report**.

Результаты группируются по дате сессии, затем по времени служения, затем по группе, а под каждой группой перечислены присутствовавшие люди. Времена служения, группы и имена отсортированы по алфавиту. Рядом с именем каждого человека столбец **Checked In** показывает время, когда была записана его посещаемость (пусто, если время не сохранено), а столбец **Membership Status** показывает его статус, например Member или Visitor. Сессии групп, которые не собираются в определённое время служения, тоже включены; они отображаются без времени служения.

Чтобы скачать таблицу, нажмите **Download Options** и выберите **Summary**. CSV-файл содержит:

- Одну строку на каждого участника каждой группы, которая собиралась в заданном диапазоне дат, отсортированную по группе, а затем по имени.
- Имя человека и название группы в первых столбцах.
- Один столбец на каждую датированную сессию, название которого включает служение, время служения и дату (например, «Sunday - 9:00 AM (2026-09-27)»), и отметку **present** или **absent** для каждого человека. Сессия без времени служения называется только по дате.

Используйте этот отчёт, чтобы сравнивать посещаемость между группами и выяснять, какие группы растут или требуют внимания.

## Ежедневная посещаемость групп

Отчёт Daily Group Attendance (с заголовком **Group attendance by day**) показывает ежедневный подсчёт того, сколько человек посетили одну группу.

1. Откройте в браузере адрес **admin.b1.church/reports/dailyGroupAttendance**.
2. Используйте выпадающие списки **Campus**, **Service** и **Service Time», чтобы сузить список, затем выберите **Group**, которую хотите проверить.
3. Запустите отчёт. В нём перечислен каждый день, когда собиралась группа, от самых ранних к самым поздним, с **Date** и количеством **Attendees**, записанных в этот день.

Этот отчёт даёт подробные данные, полезные для понимания колебаний от недели к неделе или для выявления конкретных дней с необычно высокой или низкой посещаемостью.

:::tip
Используйте отчёт Attendance Trend для общего обзора, а отчёт Daily Group Attendance — когда нужно разобраться в конкретных датах.
:::

## Практическое применение

- **Планирование** — используйте тенденции посещаемости, чтобы планировать рассадку, персонал и ресурсы для предстоящих служений.
- **Служение людям** — заметьте снижение посещаемости на ранней стадии, чтобы вовремя связаться с участниками.
- **Отчёты для совета** — включайте данные о посещаемости в регулярные отчёты руководству, чтобы показать состояние служений.
- **Оценка мероприятий** — сравнивайте посещаемость до и после специальных мероприятий, чтобы измерить их влияние.

:::warning
Данные о посещаемости фиксируются через процессы регистрации в группах и на служениях. Если посещаемость учитывается непоследовательно, отчёты не будут точно отражать реальное участие. Инструкции по настройке см. в разделе [Tracking Attendance](../attendance/tracking-attendance.md).
:::
