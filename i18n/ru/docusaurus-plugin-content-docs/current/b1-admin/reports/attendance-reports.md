# Отчёты о посещаемости

<div class="article-intro">

B1 Admin предоставляет три отчёта о посещаемости, которые помогут понять, как люди участвуют в ваших службах и группах. Каждый отчёт показывает данные о посещаемости под своим углом: от общих тенденций до ежедневной разбивки.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Убедитесь, что посещаемость последовательно [учитывается](../attendance/tracking-attendance.md) для ваших служб и групп
- Убедитесь, что ваши [группы](../groups/creating-groups.md) и службы настроены в B1 Admin
- Для доступа к отчётам нужны соответствующие [разрешения](../settings/roles-permissions.md)

</div>

## Attendance Trend {#attendance-trend}

Отчёт Attendance Trend показывает, как меняется посещаемость ваших служб со временем.

1. Перейдите напрямую по адресу **admin.b1.church/reports/attendanceTrend** в браузере (в меню навигации у отчётов нет пункта — проще всего добавить адрес в закладки). Этот же отчёт доступен и на странице Attendance: нажмите **All years**, затем выберите вкладку **Attendance Trend**.
2. При необходимости выберите **Campus**, **Service**, **Service Time** или **Group**, чтобы отфильтровать результаты.
3. Укажите **Start Date** и **End Date**. По умолчанию отчёт охватывает прошлый год, от одного года назад до сегодняшнего дня, и конечная дата включается полностью. Нажмите **Run Report**.
4. Отчёт показывает столбчатую диаграмму и таблицу общего количества посещений по неделям. Каждая неделя обозначена датой воскресенья этой недели, а в столбце **Session Dates** таблицы перечислены конкретные даты этой недели, на которые была посещаемость (например, «9/27, 9/30»).

Этот отчёт полезен для выявления закономерностей, таких как сезонные спады, рост или влияние специальных событий.

:::tip
На странице Attendance в режиме **All years** между двумя другими есть вкладка **Headcount Trend**. На ней отображаются итоги количества людей, которые вы вводите вручную (а не отдельные отметки регистрации), по неделям. Для неё доступны те же фильтры **Campus**, **Service**, **Service Time** и **Group**.
:::

## Group Attendance {#group-attendance}

Отчёт Group Attendance показывает, кто посетил каждое групповое занятие за выбранный период.

1. Перейдите напрямую по адресу **admin.b1.church/reports/groupAttendance** в браузере или на странице Attendance нажмите **All years** и выберите вкладку **Group Attendance**.
2. При необходимости выберите **Campus** и **Service**.
3. Укажите **Start Date** и **End Date**. По умолчанию отчёт охватывает период от прошлого воскресенья до сегодняшнего дня, и конечная дата включается полностью.
4. Нажмите **Run Report**.

Результаты группируются по дате занятия, затем по времени службы, затем по группе; под каждой группой перечислены люди, которые пришли. Времена служб, группы и имена отсортированы по алфавиту. Рядом с именем каждого человека столбец **Checked In** показывает время, когда была зафиксирована его посещаемость (пусто, если время не записано), а столбец **Membership Status** показывает его статус, например Member или Visitor. Занятия групп, которые не собираются в определённое время службы, тоже включаются; они отображаются без времени службы.

Чтобы скачать таблицу, нажмите **Download Options** и выберите **Summary**. CSV-файл содержит:

- Одну строку на каждого участника каждой группы, которая собиралась в выбранном периоде, отсортированную по группе, а затем по имени.
- Имя человека и название группы в первых столбцах.
- Один столбец на каждое датированное занятие, название которого включает службу, время службы и дату (например, «Sunday - 9:00 AM (2026-09-27)»); каждый человек отмечен как **present** или **absent**. Занятие без времени службы называется только по дате.

Используйте этот отчёт, чтобы сравнивать посещаемость разных групп и выявлять, какие группы растут или требуют внимания.

## Daily Group Attendance {#daily-group-attendance}

Отчёт Daily Group Attendance (с заголовком **Group attendance by day**) показывает поденный подсчёт того, сколько человек посетили одну группу.

1. Перейдите напрямую по адресу **admin.b1.church/reports/dailyGroupAttendance** в браузере.
2. Используйте выпадающие списки **Campus**, **Service** и **Service Time**, чтобы сузить список, затем выберите **Group**, которую хотите проверить.
3. Запустите отчёт. Он выводит каждый день, когда группа собиралась, от самых ранних к поздним, с **Date** и количеством **Attendees**, записанным в этот день.

Этот отчёт даёт подробную информацию, которая полезна для понимания колебаний от недели к неделе или выявления конкретных дней с необычно высокой или низкой посещаемостью.

:::tip
Используйте отчёт Attendance Trend для общего обзора, а отчёт Daily Group Attendance — когда нужно разобраться в конкретных датах.
:::

## Практическое применение {#practical-uses}

- **Планирование** — используйте тенденции посещаемости, чтобы планировать рассадку, расстановку персонала и ресурсы для предстоящих служб.
- **Работа с людьми** — рано выявляйте снижение посещаемости, чтобы вовремя связаться с участниками.
- **Отчёты для правления** — включайте данные о посещаемости в регулярные отчёты руководству, чтобы показать состояние служения.
- **Оценка событий** — сравнивайте посещаемость до и после специальных событий, чтобы оценить их влияние.

:::warning
Данные о посещаемости фиксируются через процессы регистрации в группах и службах. Если посещаемость учитывается непоследовательно, отчёты не будут точно отражать реальное участие. Инструкции по настройке см. в разделе [Учёт посещаемости](../attendance/tracking-attendance.md).
:::
