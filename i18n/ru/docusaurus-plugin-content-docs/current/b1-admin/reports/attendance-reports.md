# Отчёты о посещаемости

<div class="article-intro">

B1 Admin предоставляет три отчёта о посещаемости, которые помогают понять, как люди участвуют в служениях и группах. Каждый отчёт даёт свой взгляд на данные о посещаемости -- от общих тенденций до разбивки по дням.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Убедитесь, что посещаемость [последовательно учитывается](../attendance/tracking-attendance.md) для ваших служений и групп
- Убедитесь, что ваши [группы](../groups/creating-groups.md) и служения настроены в B1 Admin
- Для доступа к отчётам нужны соответствующие [права](../settings/roles-permissions.md)

</div>

## Тенденция посещаемости

Отчёт Attendance Trend показывает, как посещаемость меняется со временем для ваших служений.

1. Перейдите напрямую по адресу **admin.b1.church/reports/attendanceTrend** в браузере (в меню навигации отчётов нет -- проще всего вернуться к нему, добавив адрес в закладки). Тот же отчёт есть и на странице Attendance: нажмите **All years**, затем выберите вкладку **Attendance Trend**.
2. По желанию выберите **Campus**, **Service**, **Service Time** или **Group**, чтобы отфильтровать результаты.
3. Задайте **Start Date** и **End Date**. По умолчанию отчёт охватывает прошлый год -- от одного года назад до сегодняшнего дня, и конечная дата включается полностью. Нажмите **Run Report**.
4. Отчёт показывает столбчатую диаграмму и таблицу общего количества посещений по неделям. Каждая неделя обозначена датой воскресенья этой недели, а в колонке таблицы **Session Dates** перечислены фактические даты этой недели, в которые была посещаемость (например, «9/27, 9/30»).

Этот отчёт полезен, чтобы замечать закономерности, например сезонные спады, рост или влияние особых событий.

## Посещаемость групп {#group-attendance}

Отчёт Group Attendance показывает, кто посетил занятие каждой группы в заданном диапазоне дат.

1. Перейдите напрямую по адресу **admin.b1.church/reports/groupAttendance** в браузере или на странице Attendance нажмите **All years** и выберите вкладку **Group Attendance**.
2. По желанию выберите **Campus** и **Service**.
3. Задайте **Start Date** и **End Date**. По умолчанию отчёт охватывает период от прошлого воскресенья до сегодняшнего дня, и конечная дата включается полностью.
4. Нажмите **Run Report**.

Результаты группируются по дате занятия, затем по времени служения, затем по группе; под каждой группой перечислены люди, которые присутствовали. Времена служений, группы и имена отсортированы по алфавиту. Рядом с именем каждого человека колонка **Checked In** показывает время, когда была записана его посещаемость (пусто, если время не записано), а колонка **Membership Status** показывает его статус, например Member или Visitor. Занятия групп, которые не собираются в какое-либо время служения, тоже включены; они отображаются без времени служения.

Чтобы скачать таблицу, нажмите **Download Options** и выберите **Summary**. CSV-файл содержит:

- Одну строку на каждого участника каждой группы, которая собиралась в заданном диапазоне дат, отсортированную по группе, затем по имени.
- Имя человека и название группы в первых колонках.
- Одну колонку на каждое датированное занятие с названием служения, времени служения и даты (например, «Sunday - 9:00 AM (2026-09-27)»), где каждый человек отмечен как **present** или **absent**. Занятие без времени служения называется только по дате.

Используйте этот отчёт, чтобы сравнивать посещаемость разных групп и определять, какие группы растут или требуют внимания.

## Ежедневная посещаемость групп

Отчёт Daily Group Attendance (с названием **Group attendance by day**) показывает подневной подсчёт того, сколько людей посетили одну группу.

1. Перейдите напрямую по адресу **admin.b1.church/reports/dailyGroupAttendance** в браузере.
2. Используйте выпадающие списки **Campus**, **Service** и **Service Time**, чтобы сузить список, затем выберите **Group**, которую хотите проверить.
3. Запустите отчёт. Он перечислит каждый день, в который собиралась группа, от самого раннего к позднему, с **Date** и количеством **Attendees**, отмеченных в этот день.

Этот отчёт даёт подробные данные, полезные для понимания колебаний от недели к неделе или для выявления конкретных дней с необычно высокой или низкой посещаемостью.

:::tip
Используйте отчёт Attendance Trend для общего обзора, а отчёт Daily Group Attendance -- когда нужно разобрать конкретные даты.
:::

## Практическое применение

- **Планирование** -- используйте тенденции посещаемости, чтобы планировать рассадку, персонал и ресурсы для предстоящих служений.
- **Служение людям** -- заранее замечайте снижение посещаемости, чтобы связаться с участниками.
- **Отчёты для совета** -- включайте данные о посещаемости в регулярные отчёты руководству, чтобы показать состояние служений.
- **Оценка мероприятий** -- сравнивайте посещаемость до и после особых событий, чтобы измерить их влияние.

:::warning
Данные о посещаемости записываются через процессы учёта групп и регистрации на служениях. Если посещаемость учитывается непоследовательно, отчёты не будут точно отражать реальное участие. Инструкции по настройке см. в разделе [Учёт посещаемости](../attendance/tracking-attendance.md).
:::
