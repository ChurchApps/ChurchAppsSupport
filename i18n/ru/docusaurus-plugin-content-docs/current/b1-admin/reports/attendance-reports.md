# Отчеты о посещаемости

<div class="article-intro">

B1 Admin предоставляет три отчета о посещаемости, чтобы помочь вам понять, как люди взаимодействуют с вашими услугами и группами. Каждый отчет предлагает другую перспективу на ваши данные о посещаемости, от общих тенденций до ежедневных разбивок.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Убедитесь, что посещаемость [отслеживается последовательно](../attendance/tracking-attendance.md) для ваших услуг и групп
- Убедитесь, что ваши [группы](../groups/creating-groups.md) и услуги настроены в B1 Admin
- Вам нужны соответствующие [разрешения](../settings/roles-permissions.md) для доступа к отчетам

</div>

## Тенденция посещаемости

Отчет «Тенденция посещаемости» показывает, как посещаемость меняется с течением времени для ваших услуг.

1. Перейдите непосредственно на **admin.b1.church/reports/attendanceTrend** в вашем браузере (отчеты не имеют записи в меню навигации — добавление адреса в закладки — это самый простой способ вернуться).
2. Установите **диапазон дат** для определения периода времени.
3. Выберите **услугу** или **группу** для фильтрации результатов.
4. В отчете отображается линия тренда, показывающая количество посещаемости в течение выбранного периода.

Этот отчет полезен для выявления закономерностей, таких как сезонные спады, тенденции роста или влияние специальных событий.

## Посещаемость группы

Отчет о посещаемости группы показывает итоги посещаемости по группам за выбранный диапазон дат.

1. Перейдите непосредственно на **admin.b1.church/reports/groupAttendance** в вашем браузере.
2. Установите **диапазон дат** для отчета.
3. Выберите **группу(ы)**, которую вы хотите просмотреть.
4. В отчете отображаются общие цифры посещаемости для каждой группы.

Используйте этот отчет для сравнения посещаемости между группами и определения, какие группы растут или нуждаются во внимании.

## Ежедневная посещаемость группы

Отчет о ежедневной посещаемости группы предоставляет разбивку данных о посещаемости для ваших групп по дням.

1. Перейдите непосредственно на **admin.b1.church/reports/dailyGroupAttendance** в вашем браузере.
2. Установите **диапазон дат** для отчета.
3. Выберите **группу(ы)**, которую вы хотите просмотреть.
4. В отчете показаны цифры посещаемости для каждого отдельного дня в диапазоне.

Этот отчет предоставляет вам детальную информацию, которая полезна для понимания неделей на неделю вариаций или выявления конкретных дней с необычно высокой или низкой посещаемостью.

:::tip
Используйте отчет «Тенденция посещаемости» для общего обзора и отчет «Ежедневная посещаемость группы», когда вам нужно углубиться в конкретные даты.
:::

## Практическое применение

- **Планирование** -- Используйте тенденции посещаемости для планирования мест, штата и ресурсов для предстоящих услуг.
- **Аутрич** -- Выявляйте тенденции снижения посещаемости на ранней стадии, чтобы вы могли следить за членами.
- **Отчеты совета** -- Включите данные о посещаемости в регулярные отчеты руководства, чтобы показать здоровье служения.
- **Оценка событий** -- Сравните посещаемость до и после специальных событий, чтобы оценить их влияние.

:::warning
Данные о посещаемости записываются через ваши процессы регистрации группы и услуги. Если посещаемость не отслеживается последовательно, ваши отчеты не будут точно отражать фактическое участие. Смотрите [Отслеживание посещаемости](../attendance/tracking-attendance.md) для инструкций по настройке.
:::
