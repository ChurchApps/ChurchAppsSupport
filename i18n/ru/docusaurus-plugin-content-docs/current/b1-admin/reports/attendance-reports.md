# Отчёты о посещаемости

<div class="article-intro">

B1 Admin предоставляет три отчёта о посещаемости, которые помогают понять, как люди участвуют в ваших службах и группах. Каждый отчёт даёт свой взгляд на данные о посещаемости: от общих тенденций до разбивки по дням.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Убедитесь, что посещаемость [последовательно учитывается](../attendance/tracking-attendance.md) для ваших служений и групп
- Убедитесь, что ваши [группы](../groups/creating-groups.md) и службы настроены в B1 Admin
- Вам нужны соответствующие [разрешения](../settings/roles-permissions.md) для доступа к отчётам

</div>

## Тенденция посещаемости

Отчёт Attendance Trend показывает, как посещаемость ваших служений меняется со временем.

1. Откройте в браузере адрес **admin.b1.church/reports/attendanceTrend** (в навигационном меню отчётов нет — проще всего добавить адрес в закладки). Этот же отчёт доступен и на странице Attendance: нажмите **All years**, затем выберите вкладку **Attendance Trend**.
2. При желании выберите **Campus**, **Service**, **Service Time** или **Group**, чтобы отфильтровать результаты.
3. Укажите **Start Date** и **End Date**. По умолчанию отчёт охватывает последний год — от одного года назад до сегодняшнего дня, и конечная дата включается полностью. Нажмите **Run Report**.
4. В отчёте отображаются столбчатая диаграмма и таблица с общим количеством посещений по неделям. Каждая неделя подписана датой воскресенья этой недели, а в столбце таблицы **Session Dates** перечислены фактические даты этой недели, в которые были посещения (например, «9/27, 9/30»).

Этот отчёт полезен для выявления закономерностей, таких как сезонные спады, рост или влияние специальных мероприятий.

## Посещаемость групп

Отчёт Group Attendance показывает, кто посетил каждое групповое занятие за выбранный период.

1. Откройте в браузере адрес **admin.b1.church/reports/groupAttendance** или на странице Attendance нажмите **All years** и выберите вкладку **Group Attendance**.
2. При желании выберите **Campus** и **Service**.
3. Укажите **Start Date** и **End Date**. По умолчанию отчёт охватывает период от прошлого воскресенья до сегодняшнего дня, и конечная дата включается полностью.
4. Нажмите **Run Report**.

Результаты группируются по дате занятия, затем по времени служения, затем по группе, а под каждой группой перечислены присутствовавшие люди. Времена служения, группы и имена сортируются по алфавиту. Рядом с именем каждого человека столбец **Checked In** показывает время, когда была зафиксирована его посещаемость (пусто, если время не записано), а столбец **Membership Status** — его статус, например Member или Visitor.

Чтобы скачать таблицу, нажмите **Download Options** и выберите **Summary**. CSV-файл содержит:

- Одну строку на каждого участника каждой группы, которая собиралась в выбранный период, отсортированную по группе, а затем по имени.
- Имя человека и название группы в первых столбцах.
- Один столбец на каждое занятие с датой, названный по служению, времени служения и дате (например, «Sunday - 9:00 AM (2026-09-27)»), где каждый человек отмечен как **present** или **absent**.

Используйте этот отчёт, чтобы сравнивать посещаемость разных групп и выявлять группы, которые растут или требуют внимания.

## Ежедневная посещаемость групп

Отчёт Daily Group Attendance (с названием **Group attendance by day**) показывает количество людей, посетивших одну группу, по дням.

1. Откройте в браузере адрес **admin.b1.church/reports/dailyGroupAttendance**.
2. С помощью раскрывающихся списков **Campus**, **Service** и **Service Time** сузьте список, затем выберите **Group**, которую хотите проверить.
3. Запустите отчёт. Он перечисляет все дни, в которые собиралась группа, начиная с самых ранних, с **Date** и количеством **Attendees**, зафиксированным в этот день.

Этот отчёт даёт подробную картину, которая полезна для понимания колебаний от недели к неделе или для выявления конкретных дней с необычно высокой или низкой посещаемостью.

:::tip
Используйте отчёт Attendance Trend для общего обзора, а Daily Group Attendance — когда нужно подробно разобрать конкретные даты.
:::

## Практическое применение

- **Планирование** — используйте тенденции посещаемости, чтобы планировать рассадку, персонал и ресурсы для предстоящих служений.
- **Работа с общиной** — заметьте падение посещаемости на ранней стадии, чтобы связаться с членами церкви.
- **Отчёты для совета** — включайте данные о посещаемости в регулярные отчёты для руководства, чтобы показать состояние служения.
- **Оценка мероприятий** — сравнивайте посещаемость до и после особых мероприятий, чтобы измерить их влияние.

:::warning
Данные о посещаемости фиксируются через процессы регистрации в группах и службах. Если посещаемость учитывается непоследовательно, отчёты не будут точно отражать реальное участие. Инструкции по настройке см. в разделе [Учёт посещаемости](../attendance/tracking-attendance.md).
:::
