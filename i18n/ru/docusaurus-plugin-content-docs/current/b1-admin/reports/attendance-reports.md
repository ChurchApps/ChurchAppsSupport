# Отчеты по посещаемости

<div class="article-intro">

B1 Admin предоставляет три отчета по посещаемости, которые помогут вам понять, как люди участвуют в ваших служениях и группах. Каждый отчет предлагает различные подходы к данным вашей посещаемости, от высокоуровневых тенденций до ежедневных разбивок.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Убедитесь, что посещаемость [отслеживается последовательно](../attendance/tracking-attendance.md) для ваших служений и групп
- Убедитесь, что ваши [группы](../groups/creating-groups.md) и служения настроены в B1 Admin
- Вам требуются соответствующие [разрешения](../settings/roles-permissions.md) для доступа к отчетам

</div>

## Тенденция посещаемости

Отчет "Тенденция посещаемости" показывает, как посещаемость меняется со временем для ваших служений.

1. Перейдите прямо к **admin.b1.church/reports/attendanceTrend** в вашем браузере (отчеты не имеют записей в меню навигации - добавление адреса в закладки - это самый простой способ вернуться к нему). Тот же отчет также находится на вкладке **Тенденция посещаемости** страницы "Посещаемость".
2. При необходимости выберите **Кампус**, **Служение**, **Время служения** или **Группа**, чтобы отфильтровать результаты.
3. Установите **Дата начала** и **Дата окончания**. По умолчанию отчет охватывает последний год, от года назад до сегодня, и дата окончания включена полностью. Щелкните **Запустить отчет**.
4. Отчет отображает столбчатую диаграмму и таблицу общего количества посещений в неделю. Каждая неделя помечена датой воскресенья этой недели, а столбец **Даты сеансов** таблицы показывает фактические даты на этой неделе, которые имели посещаемость (например, "27/9, 30/9").

Этот отчет полезен для выявления закономерностей, таких как сезонные спады, тенденции роста или влияние специальных событий.

## Посещаемость группы

Отчет "Посещаемость группы" показывает, кто посещал каждый сеанс группы в диапазоне дат.

1. Перейдите прямо к **admin.b1.church/reports/groupAttendance** в вашем браузере, или откройте вкладку **Посещаемость группы** на странице "Посещаемость".
2. При необходимости выберите **Кампус** и **Служение**.
3. Установите **Дата начала** и **Дата окончания**. По умолчанию отчет охватывает прошлое воскресенье до сегодня, и дата окончания включена полностью.
4. Щелкните **Запустить отчет**.

Результаты сгруппированы по дате сеанса, затем по времени служения, затем по группе, с людьми, которые присутствовали, перечисленными под каждой группой. Время служения, группы и имена отсортированы в алфавитном порядке. Рядом с именем каждого человека столбец **Время входа** показывает время, когда их посещаемость была записана (пусто, если время не указано), и столбец **Статус членства** показывает их статус, такой как "Член" или "Посетитель".

Для загрузки таблицы щелкните **Параметры загрузки** и выберите **Сводка**. CSV содержит:

- По одной строке для каждого члена каждой группы, которая собиралась в диапазоне дат, отсортирована по группам и затем по имени.
- Имя человека и имя группы в первых столбцах.
- По одному столбцу на каждый датированный сеанс, названному со служением, временем служения и датой (например, "Воскресенье - 9:00 AM (2026-09-27)"), с каждым человеком, отмеченным как **присутствовал** или **отсутствовал**.

Используйте этот отчет для сравнения посещаемости между группами и определения, какие группы растут или требуют внимания.

## Ежедневная посещаемость группы

Отчет "Ежедневная посещаемость группы" предоставляет ежедневную разбивку данных посещаемости для ваших групп.

1. Перейдите прямо к **admin.b1.church/reports/dailyGroupAttendance** в вашем браузере.
2. Установите **диапазон дат** для отчета.
3. Выберите **группу(ы)**, которую(ые) вы хотите проверить.
4. Отчет показывает числа посещаемости для каждого отдельного дня в диапазоне.

Этот отчет дает вам детальную информацию, которая полезна для понимания недельных вариаций или определения конкретных дней с необычно высокой или низкой посещаемостью.

:::tip
Используйте отчет "Тенденция посещаемости" для высокоуровневого обзора и отчет "Ежедневная посещаемость группы", когда вам нужно углубиться в конкретные даты.
:::

## Практическое применение

- **Планирование** - используйте тенденции посещаемости для планирования мест, персонала и ресурсов для предстоящих служений.
- **Работа с прихожанами** - выявляйте модели снижения посещаемости на ранней стадии, чтобы вы могли связаться с членами.
- **Отчеты правления** - включайте данные по посещаемости в обычные отчеты руководства, чтобы показать здоровье служения.
- **Оценка события** - сравнивайте посещаемость до и после специальных событий, чтобы измерить их влияние.

:::warning
Данные о посещаемости записываются через процессы регистрации вашей группы и служения. Если посещаемость не отслеживается последовательно, ваши отчеты не будут точно отражать фактическое участие. См. [Отслеживание посещаемости](../attendance/tracking-attendance.md) для получения инструкций по настройке.
:::
