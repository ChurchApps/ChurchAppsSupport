# Zapier

<div class="article-intro">

Официальное приложение B1.church в Zapier позволяет Zap реагировать на события в вашей церкви (новый человек, новое пожертвование, новый участник группы, …) и записывать данные обратно в B1. Без программирования и без собственной инфраструктуры -- вы настраиваете всё в визуальном редакторе Zapier, вставляете ключ API и включаете Zap.

</div>

:::caution Ожидается одобрение Zapier
Приложение B1.church создано и работает, но пока ожидает проверки Zapier, прежде чем появиться в публичном каталоге приложений редактора Zap. До одобрения им могут пользоваться только приглашённые учётные записи. Всё описанное ниже объясняет, как это будет работать после одобрения.
:::

<div class="prereqs">
<h4>Перед началом</h4>

- Учётная запись [Zapier](https://zapier.com) (бесплатного тарифа достаточно для нескольких Zap)
- Администратор церкви с правом **Edit Settings** в B1Admin (вы создадите ключ API)
- Понимание того, что вы хотите автоматизировать, например: «когда человек добавляется в B1, добавлять его в мой список Mailchimp»

</div>

## Триггеры и действия

| Тип | Что | Событие B1 / эндпоинт |
|---|---|---|
| **Trigger** | New Person | `person.created` |
| **Trigger** | Updated Person | `person.updated` |
| **Trigger** | New Donation | `donation.created` |
| **Trigger** | New Group Member | `group.member.added` |
| **Trigger** | New Form Submission | `form.submission.created` |
| **Action** | Create Person | добавляет нового человека |
| **Action** | Add Donation | записывает пожертвование |
| **Action** | Add Group Member | добавляет человека в группу |
| **Action** | Find Person | ищет человека по id, email или имени; если никого не найдено, задача завершается с ошибкой |

Их можно свободно комбинировать с любым из более чем 7 000 поддерживаемых приложений Zapier.

## Настройка

### 1. Создайте ключ API B1

1. В B1Admin перейдите в **Settings → Developer → API Keys**.
2. Нажмите **New API Key**, назовите его, например, «Zapier», и выберите области, которые нужны Zap.
3. **Важно:** триггеры Zapier регистрируют вебхук от вашего имени при включении Zap, для этого требуется область **`settings:write`**. Всегда включайте `settings:write`, если в каком-либо из ваших Zap используется триггер B1.
4. Также выдайте области, которые нужны действиям, например, действию «Add Donation» нужна `donations:write`, а «Create Person» -- `people:write`.
5. Сохраните. Полный ключ `cak_…` показывается **один раз** -- скопируйте его.

### 2. Подключите Zapier к B1

1. В Zapier создайте новый Zap.
2. Когда вы впервые выбираете триггер или действие B1, Zapier попросит вас **Sign in to B1.church**.
3. Вставьте ключ API из шага 1 и нажмите **Yes, Continue**. Zapier проверит его для вашей церкви.

Подключение сохраняется в Zapier и используется каждым Zap в вашей учётной записи.

### 3. Создайте Zap

Выберите триггер, затем добавьте один или несколько шагов-действий. Примеры ниже.

## Типовые сценарии

### Добавлять новых людей из B1 в Mailchimp

- **Trigger** -- B1: New Person
- **Action** -- Mailchimp: Add/Update Subscriber. Сопоставьте `name__first`, `name__last`, `contactInfo__email` из B1 с полями First Name / Last Name / Email в Mailchimp.

### Публиковать пожертвования в канал Slack с более насыщенной карточкой, чем у встроенного коннектора

- **Trigger** -- B1: New Donation
- **Action** -- Slack: Send Channel Message. Составьте любой макет -- кнопки, вложения и т. д., -- которого не умеет [встроенный коннектор Slack](./slack-discord.md).

### Добавлять новых участников групп в Google Group

- **Trigger** -- B1: New Group Member (с фильтром по конкретному `groupId`)
- **Action** -- Filter by Zapier: продолжать, только если группа B1 та, которая вам нужна
- **Action** -- B1: Find Person (используйте `personId` из триггера, чтобы получить email)
- **Action** -- Google Groups: Add Member

### Пересылать отправки форм в трекер проектов

- **Trigger** -- B1: New Form Submission
- **Action** -- Notion / Linear / Asana / Trello: Create page / issue / task

## Как работают триггеры

Триггеры работают как **REST hooks**, а не опрос -- Zapier не обращается к B1 каждые 15 минут. Когда вы включаете Zap, Zapier просит B1 зарегистрировать вебхук, указывающий на закрытый URL Zapier; когда происходит событие, B1 отправляет данные в Zapier, и ваш Zap запускается **в течение нескольких секунд**. Если выключить Zap, Zapier попросит B1 удалить вебхук -- никаких «осиротевших» подписок.

Это значит, что триггер срабатывает только для событий, которые произошли **после** включения Zap. Заполнения задним числом нет -- включение Zap не повторяет вчерашние пожертвования.

## Ограничения и примечания

- **Несколько Zap с одним и тем же триггером** регистрируют каждый свой вебхук B1 -- конфликта нет, но полезно знать, если вы смотрите **Settings → Developer → Webhooks** и удивляетесь, почему там три одинаковые строки `Zapier — donation.created`.
- **Тестовые данные при настройке Zap** -- при создании Zap Zapier запрашивает образцы данных для сопоставления полей. Он возьмёт последнее подходящее событие из B1, если оно есть; иначе использует синтетический образец из описания приложения.
- **Ошибки действий отображаются как ошибки Zap** в истории задач Zapier. Частая причина -- ключ API без нужной области (например, действию «Add Donation» нужна `donations:write`). Создайте ключ заново с нужными областями и переподключите Zapier.
- **Квоты исходящих вызовов API** -- каждый вызов API B1 из действия засчитывается в вашу квоту задач Zapier, а не в какие-либо ресурсы на стороне B1.

## Устранение неполадок

- **«Authentication failed»** при подключении -- ключ API неверный, отозван или не имеет областей, которые нужны Zap. Создайте его заново в B1Admin, включив как минимум `settings:write` и области для ресурсов, которых касается Zap, затем обновите подключение.
- **Триггер никогда не срабатывает** -- убедитесь, что вебхук действительно зарегистрирован: в B1Admin в **Settings → Developer → Webhooks** должна появиться строка с названием «Zapier — &lt;event&gt;». Если её нет, скорее всего, при включении Zap у ключа не было `settings:write`. Исправьте ключ, выключите Zap и включите снова.
- **Триггер срабатывает дважды** -- Zapier иногда повторно доставляет событие, если подтверждение было потеряно. Если нужна строгая дедупликация, используйте шаг «Filter by Zapier» по уникальному id (например, `id` человека).
