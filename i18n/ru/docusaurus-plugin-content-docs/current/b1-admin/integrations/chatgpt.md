# ChatGPT

Подключите OpenAI ChatGPT к данным B1 вашей церкви и позвольте ему выполнять сложные задачи.

## Что вы можете попросить

- "Установите классы воскресной школы и поместите каждого учителя в правильную комнату на основе их группы"
- "Покажите мне всех, кто посещал на прошлой неделе, но не был назначен в небольшую группу"
- "Подведите итог пожертвованиям этого месяца по фондам"
- "Кто наши новые члены и мы ли с ними связались?"

## Установка

### Шаг 1 — Создайте ключ API в B1 Admin

1. Перейдите в **Settings → Developer → API Keys**
2. Нажмите **New API Key**
3. Дайте ему имя `ChatGPT`
4. Выберите области (scopes): `people:read`, `groups:read`, `attendance:read`, `donations:read`
5. Нажмите **Save** и скопируйте ключ

### Шаг 2 — Подключите в ChatGPT

1. Перейдите в **Settings → Plugins → MCPs** в ChatGPT
2. Нажмите **Add → Add MCP server**
3. Выберите **Streamable HTTP**
4. Заполните:
   - **Name:** B1 Church
   - **URL:** https://api.churchapps.org/mcp
   - **Authorization Header:** `Bearer ваш_ключ`

### Шаг 3 — Начните использовать

Просто спросите ChatGPT что-нибудь о вашей церкви!

## Безопасность

- Ключ API изолирует вашу церковь
- Разрешения ограничивают доступ ChatGPT
- Вы можете отозвать доступ в любое время

## Стоимость

ChurchApps бесплатна. OpenAI взимает плату за использование ChatGPT.
