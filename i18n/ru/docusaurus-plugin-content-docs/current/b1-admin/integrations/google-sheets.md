# Google Sheets

<div class="article-intro">

**B1 Export** — официальное дополнение для Google Sheets для B1.church. Оно добавляет боковую панель в любую таблицу и выгружает данные People, Donations, Groups или Attendance из вашей церкви B1 в именованные вкладки — по запросу, одним нажатием. Дополнение работает полностью внутри учётной записи Google пользователя; помимо читающих API-вызовов каждого экспорта, оно никак не обращается к серверам ChurchApps.

</div>

:::caution Пока недоступно
Дополнение B1 Export ещё не опубликовано в Google Workspace Marketplace, поэтому установить его сейчас нельзя. До его выпуска экспортируйте людей из B1Admin (см. [Экспорт данных](../people/exporting-data.md)) и импортируйте CSV в Google Sheets. Всё, что описано ниже, показывает, как дополнение будет работать после выпуска.
:::

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Учётная запись Google с правом редактирования таблицы, в которую вы хотите экспортировать данные
- Администратор церкви (или человек с доступом на чтение к данным, которые вы хотите выгрузить), который может создать API-ключ B1
- Дополнение B1 Export, установленное из Google Workspace Marketplace

</div>

## Что экспортируется {#what-it-exports}

| Пункт меню | Вкладка таблицы | Данные |
|---|---|---|
| Export People | `B1 People` | ID, Display Name, First, Last, Email, Membership Status |
| Export Donations | `B1 Donations` | ID, Person ID, Date, Amount, Method, Batch ID |
| Export Groups | `B1 Groups` | ID, Name, Category, Member Count |
| Export Attendance | `B1 Attendance` | ID, Person ID, Visit Date, Service ID, Group ID |

Каждый экспорт **заменяет** содержимое своей именованной вкладки: повторный запуск даёт свежий снимок, а не добавляет строки. Остальные вкладки таблицы не затрагиваются.

## Настройка {#setup}

### 1. Создайте API-ключ B1 с нужными областями доступа {#1-create-a-b1-api-key-with-the-right-scopes}

1. В B1Admin перейдите в **Settings → Developer → API Keys**.
2. Нажмите **New API Key**, назовите его «Sheets Export» и выдайте права **read** для того, что планируете выгружать:
   - `people:read` для экспорта People
   - `donations:read` для Donations
   - `groups:read` для Groups
   - `attendance:read` для Attendance
3. Ключу, который только выгружает данные, **не** нужен `settings:write` — эта область нужна только коннекторам, которые регистрируют веб-хуки (Zapier / Make). Держите этот ключ узким.
4. Сохраните и скопируйте ключ `cak_…`.

### 2. Установите дополнение {#2-install-the-add-on}

1. Откройте таблицу, в которую хотите экспортировать данные.
2. **Extensions → Add-ons → Get add-ons**.
3. Найдите **B1 Export** и установите его. Google попросит предоставить доступ к вашим таблицам и к внешним HTTP-запросам (чтобы дополнение могло вызывать API B1).

После установки пункт **B1 Export** появится в меню **Extensions** каждой таблицы, которую вы открываете с этой учётной записью Google.

### 3. Подключите ключ {#3-connect-the-key}

1. **Extensions → B1 Export → Connect…** (или **B1 Export → Connect…** в строке меню после первого открытия).
2. Вставьте API-ключ в боковую панель, оставьте Base URL как `https://api.churchapps.org` (если только вы не тестируете на staging) и нажмите **Save**.
3. Нажмите **Test Connection** — зелёная надпись «Connection OK» подтвердит, что ключ работает.

Ключ хранится в **пользовательских свойствах** (`PropertiesService.getUserProperties()`): он привязан к вашей учётной записи Google, никогда не записывается в таблицу и не виден другим редакторам таблицы.

## Запуск экспорта {#running-an-export}

Можно либо:

- **Из меню** — **Extensions → B1 Export → Export People** (или Donations / Groups / Attendance)
- **Из боковой панели** — откройте панель (Connect…) и нажмите нужную кнопку набора данных

Всплывающее уведомление подтвердит окончание — «_N_ row(s) written to 'B1 People'.»

## Отчёты поверх данных {#building-reports-on-top}

Выгруженные вкладки — это обычные данные Google Sheets. Постройте собственную аналитику, ссылаясь на вкладки:

- **Сводная вкладка** с `=SUMIF('B1 Donations'!E:E, "card", 'B1 Donations'!D:D)`, чтобы подсчитать пожертвования картой
- **Отфильтрованное представление** только участников с `=FILTER('B1 People'!A:F, 'B1 People'!F:F = "Member")`
- **Диаграмма** динамики посещаемости по данным `B1 Attendance`

Повторный экспорт обновляет нижележащую вкладку, и ваши формулы обновляются автоматически.

## Регулярные экспорты {#scheduling-recurring-exports}

Дополнение по умолчанию работает по запросу. Для еженедельных или ежемесячных экспортов используйте встроенные триггеры Apps Script по времени:

1. **Extensions → Apps Script** в таблице (откроется скрипт, привязанный к дополнению).
2. Нажмите значок **⏰ Triggers** в левой боковой панели.
3. **Add Trigger** для `exportPeople` (или любой другой функции экспорта) — выберите *Time-driven*, *Week timer*, например *Every Monday 6am*.

Экспорт выполняется в фоне под вашей учётной записью Google. Если API-ключ будет перевыпущен или отозван, триггер пришлёт вам письмо при следующем сбое.

## Права и конфиденциальность {#permissions--privacy}

- Дополнение запрашивает только `spreadsheets.currentonly` (оно может работать только с таблицей, которая открыта) и `script.external_request` (чтобы `UrlFetchApp` мог вызывать API B1). Оно **не** имеет доступа к вашему Drive, Gmail или другим данным Google.
- API-ключ B1 хранится для каждого пользователя — другие редакторы той же таблицы не могут его увидеть.
- Все вызовы API B1 выполняются по HTTPS с заголовком `Authorization: Bearer cak_…`.

## Устранение неполадок {#troubleshooting}

- **«No API key set»** — откройте **Extensions → B1 Export → Connect…** и вставьте ключ.
- **«B1 rejected the API key (401)»** — ключ удалён или введён неверно. Создайте новый ключ и вставьте его.
- **«This API key lacks permission for /giving/donations (403)»** — у ключа нет `donations:read`. Области доступа у существующего ключа изменить нельзя, поэтому создайте новый ключ с нужными областями в B1Admin.
- **Таблица не обновляется** после запуска — убедитесь, что смотрите на *правильное* имя вкладки (`B1 People` и т. д.). Экспорт создаёт вкладку, если её не было.
- **«Quota exceeded»** — Apps Script устанавливает ежедневные квоты для каждого пользователя на `UrlFetchApp` (обычно тысячи вызовов в день). Большой церкви с множеством записей может понадобиться разбить экспорт на несколько дней или использовать [Make](./make.md) / собственную интеграцию для синхронизации большого объёма.
