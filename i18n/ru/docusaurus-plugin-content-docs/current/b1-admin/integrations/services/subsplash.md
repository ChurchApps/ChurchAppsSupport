# Subsplash

<div class="article-intro">

Если вы используете Subsplash для приложения церкви, пожертвований или форм, но хотите, чтобы B1 была основной системой учёта людей и пожертвований, Zapier-приложение Subsplash может в реальном времени передавать в B1 пожертвования, новые профили и ответы на формы. Обратите внимание, что Zapier-приложение Subsplash сейчас поддерживает **только триггеры** — связь работает в одну сторону (Subsplash → B1).

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Аккаунт Subsplash с тарифом, который включает доступ к **API + Zapier** (уточните у своего менеджера по работе с клиентами Subsplash — эта функция доступна не на всех тарифах)
- Аккаунт [Zapier](https://zapier.com)
- Пользователь B1Admin с правом **Edit Settings**

</div>

## Что можно подключить

Все триггеры ниже относятся к Subsplash. Действия выполняются в B1.

| Триггер Subsplash | Действие B1 |
|---|---|
| New Donation | Find Person → Add Donation (Create Person, если человек не найден) |
| New Pledge | Add Donation (с `notes` = "Pledge: …") |
| New Person Created | Create Person |
| Person Updated Profile | (прямого действия в B1 нет — записывать в Google Sheet для ручной проверки) |
| New Form Response | Create Person + (при необходимости) Add Group Member в зависимости от формы |

Направление Subsplash → B1 — единственное, которое сейчас поддерживает приложение Subsplash.

## Настройка

### 1. Создайте ключ API B1

В B1Admin: **Settings → Developer → API Keys → New API Key**. Области доступа:

- `people:read` — чтобы найти жертвователя по email
- `people:write` — чтобы создать его, если он ещё не существует
- `donations:write` — чтобы записать пожертвование
- (`settings:write` не нужен — триггер здесь принадлежит Subsplash, а не B1.)

### 2. Подключите Subsplash к Zapier

Следуйте [инструкции по интеграции Subsplash с Zapier](https://support.subsplash.com/en/articles/9825926-zapier-integration). Они выдают API-токен в панели Subsplash, который Zapier использует для аутентификации триггера.

### 3. Создайте Zap «записать пожертвование»

1. **Триггер** — Subsplash: New Donation
2. **Действие** — B1.church: Find Person (по email)
3. **Фильтр / Path** — ветвление по результату «person found»:
   - **Найден:** B1.church: Add Donation. Укажите сумму, дату, фонд, способ = "Online", а в notes — идентификатор транзакции Subsplash.
   - **Не найден:** B1.church: Create Person → B1.church: Add Donation (используя id только что созданного человека).

Включите Zap. Последующие пожертвования через Subsplash появятся в **B1Admin → Donations** в течение нескольких секунд.

## Типовые рецепты

### Отправить благодарность за первое пожертвование

- **Триггер** — Subsplash: New Donation
- **Действие** — Filter by Zapier: продолжать только если это первое пожертвование жертвователя (используйте *Lookup Table* по email жертвователя в Google Sheet со списком прошлых жертвователей или шаг Zapier *Paths* по дате создания жертвователя)
- **Действие** — Mailchimp / SMTP / SendGrid: отправить сообщение с благодарностью за первое пожертвование
- **Действие** — B1.church: Add Donation (как обычно)

### Отделить обещания пожертвований от обычного потока

- **Триггер** — Subsplash: New Pledge
- **Действие** — B1.church: Add Donation с `notes = "Pledge — Subsplash"` и фондом `Pledges` (отдельным от операционного фонда), чтобы можно было отдельно формировать отчёты по обещаниям в **B1Admin → Donations → Summary**.

### Синхронизировать новых пользователей приложения как людей в B1

- **Триггер** — Subsplash: New Person Created
- **Действие** — B1.church: Create Person, заполнив имя, email и телефон. Пометьте человека в B1, добавив его в группу вроде "Subsplash App Users".

## Ограничения и примечания

- **Zapier-приложение Subsplash поддерживает только триггеры.** Если нужны изменения на стороне B1 (например, чтобы новый человек из B1 попадал и в Subsplash), придётся построить этот мост из триггеров Zapier-приложения B1, которые вызывают REST API Subsplash через пользовательское действие *Webhooks by Zapier — POST*. Это самостоятельная интеграция, а не готовый рецепт.
- **Доступ к API зависит от тарифа.** Если подключение Zapier завершается ошибкой `403 Forbidden`, скорее всего, ваш тариф Subsplash не включает доступ к API — обратитесь к менеджеру по работе с клиентами.
- **Сопоставление фондов выполняется вручную.** Subsplash передаёт название кампании или категории, а B1 требует числовой id фонда. Либо жёстко задайте фонд в Zap, либо поддерживайте в Zapier *Lookup Table* соответствие кампаний Subsplash фондам B1.

## Устранение неполадок

- **Триггер не срабатывает после пожертвования** — проверьте в панели Zapier для Subsplash, что подключение всё ещё отображается как *Connected*. Если API-токен был заменён на стороне Subsplash, Zap молча перестанет работать; переподключите его.
- **B1 *Add Donation* завершается с ошибкой 422** — чаще всего из-за отсутствующего или нераспознанного `fundId`. Выведите список фондов через **B1Admin → Donations → Funds** и скопируйте точный id в шаг Zap.
- **Первое пожертвование срабатывает дважды** — Subsplash иногда повторно отправляет триггер, если Zapier не получил подтверждение. Добавьте *Filter by Zapier* по id пожертвования (Subsplash передаёт его в данных) для отсеивания дубликатов.
