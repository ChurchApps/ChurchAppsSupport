# Mailchimp

Синхронизируйте аудиторию Mailchimp с B1 автоматически: люди поступают с их именем, электронной почтой и телефоном; членство в группе становится метками Mailchimp.

## Что синхронизируется

- Люди добавляются и обновляются в Mailchimp
- Членство в группе становится метками
- Удаленные люди архивируются

## Установка

1. В B1Admin перейдите в **Settings → Developer → Webhooks**
2. Нажмите **Add Webhook**
3. Установите **Connector Type** на **Mailchimp**
4. Вставьте ваш **Mailchimp API Key** и **Audience ID**
5. Нажмите **Save**

## Начальный импорт

Функция синхронизирует изменения, но не существующие люди:

1. В B1Admin перейдите в **People**
2. Найдите людей, которых вы хотите импортировать
3. Нажмите **Export** для загрузки CSV
4. В Mailchimp импортируйте CSV в вашу аудиторию

## Ограничения

- Синхронизация только в одном направлении (B1 → Mailchimp)
- Люди без электронной почты пропускаются
- Изменение адреса электронной почты создает новую подписку

## Решение проблем

**Сохранение не удалось:**
- Проверьте, что API ключ верный
- Проверьте, что Audience ID верный

**Люди не синхронизируются:**
- Проверьте историю доставки вебхука
- Убедитесь, что у вас есть адреса электронной почты
