# Mailchimp

<div class="article-intro">

Передавайте новых людей, доноров или участников групп из B1 в аудиторию Mailchimp, чтобы следующая приветственная серия, итоговое годовое обращение или рассылка для волонтеров всегда опирались на актуальный список. В B1 нет встроенной синхронизации с Mailchimp — вся связка полностью находится в Zapier (или Make): B1 генерирует событие, Mailchimp принимает подписчика.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Учетная запись [Mailchimp](https://mailchimp.com) хотя бы с одной аудиторией, в которую вы хотите добавлять людей из B1
- Учетная запись [Zapier](https://zapier.com) (бесплатного тарифа достаточно для небольших церквей)
- Пользователь B1Admin с правом **Редактировать настройки**, чтобы вы могли создать API-ключ

</div>

## Что можно связать

| Направление | Триггер B1 | Действие Mailchimp |
|---|---|---|
| B1 → Mailchimp | `person.created` | Добавить/обновить подписчика |
| B1 → Mailchimp | `donation.created` | Добавить подписчику тег (например, «Пожертвовал(а) в 2026») |
| B1 → Mailchimp | `group.member.added` | Добавить подписчику тег, привязанный к этой группе |
| Mailchimp → B1 | Новый подписчик | B1 *Создать человека* |

Сторона Mailchimp предоставляет гораздо больше (кампании, сегменты, автоматизации) — полный список см. в [триггерах Mailchimp для Zapier](https://zapier.com/apps/mailchimp/integrations). Все, что можно сопоставить из конверта B1, подходит для использования.

## Настройка

### 1. Создайте API-ключ B1

В B1Admin перейдите в **Настройки → Для разработчиков → API-ключи → Новый API-ключ**. Присвойте ему области доступа, необходимые Zap:

- `settings:write` — требуется, чтобы триггер зарегистрировал свой веб-хук
- `people:read` — чтобы Zap мог прочитать имя, фамилию, email и т. д.
- (Необязательно) `people:write`, если вы также планируете направление Mailchimp → B1

Сохраните и скопируйте строку `cak_…` — она показывается только один раз.

### 2. Постройте Zap

1. **Триггер:** `B1.church — Новый человек`. При первом использовании Zapier попросит вас *Войти в B1.church*; вставьте API-ключ.
2. **Действие:** `Mailchimp — Добавить/обновить подписчика`. Сопоставьте вывод триггера:
   - `data.contactInfo.email` → Email-адрес
   - `data.name.first` → Имя
   - `data.name.last` → Фамилия
   - (Необязательно) `data.id` → пользовательское поле Mailchimp, если вы хотите хранить id человека из B1.
3. Включите Zap. Zapier регистрирует веб-хук `person.created` в B1 — проверьте в **Настройки → Для разработчиков → Веб-хуки**, что появилась строка «Zapier — person.created».

Вот и все. Добавьте человека в B1Admin, чтобы подтвердить работу — новый подписчик появится в Mailchimp в течение нескольких секунд.

## Общие рецепты

### Автоматическое присвоение тега донорам

- **Триггер** — B1: Новое пожертвование
- **Действие** — B1: Найти человека (поиск по `personId`), чтобы получить email
- **Действие** — Mailchimp: Добавить подписчику тег (тег `Gave-2026`)

### Запуск приветственной серии для конкретной группы

- **Триггер** — B1: Новый участник группы, отфильтрованный по `data.groupId`
- **Действие** — Mailchimp: Добавить подписчику тег с названием группы; запустить существующую автоматизацию по этому тегу

### Двусторонняя связь: новые подписчики Mailchimp становятся контактами B1

- **Триггер** — Mailchimp: Новый подписчик
- **Действие** — B1: Создать человека (сопоставить имя/фамилию/email)

## Альтернатива на Make

[Приложение Mailchimp](https://www.make.com/en/integrations/mailchimp) в Make охватывает 44 модуля — связка идентична, с триггером B1 *Отслеживать события*, заменяющим триггер Zapier. Сторону B1 см. в [обзорном документе Make](../make).

## Ограничения и заметки

- **Бесплатный тариф Mailchimp ограничивает число контактов и аудиторий** — Zap, наводняющий бесплатную аудиторию сверх лимита, начнет выдавать ошибки `4xx Member limit reached`. Это будет очевидно из журналов Mailchimp.
- **Mailchimp дедуплицирует по email**, поэтому повторный запуск Zap для того же человека из B1 обновляет его на месте; дубликаты не создаются.
- **Отписки в Mailchimp не передаются обратно в B1.** Если вы хотите, чтобы отписки в Mailchimp сбрасывали настройку «Отправлять письма» в B1, постройте обратный Zap явно.

## Устранение неполадок

- **Zap никогда не срабатывает** — проверьте `Настройки → Для разработчиков → Веб-хуки` на наличие строки `Zapier — person.created`. Если ее нет, у API-ключа отсутствовал `settings:write` в момент включения Zap. Переоформите ключ, переподключите, отключите и снова включите Zap.
- **Предупреждение `Member exists` при добавлении/обновлении** — переключите действие с *Добавить подписчика* на *Добавить/обновить подписчика* (важен именно этот вариант). Вариант с апсертом идемпотентен.
- **Имя / фамилия приходят пустыми** — поля `data.name.first` и `data.name.last` в B1 заполняются только если эти поля заданы у человека. Используйте `data.name.display` как запасной вариант.
