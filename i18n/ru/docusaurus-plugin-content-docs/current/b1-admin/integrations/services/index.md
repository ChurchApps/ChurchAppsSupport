# Подключённые сервисы

<div class="article-intro">

Самый быстрый способ подключить B1 к другому инструменту для работы церкви — обычно рецепт Zapier или Make: вам не нужна новая инфраструктура B1, а рабочий процесс размещает сторонний сервис. Эта страница — подобранный список сервисов, подключение которых к B1 мы подтвердили, с короткой инструкцией для каждого, которую можно просто скопировать и вставить.

</div>

## Кратко {#at-a-glance}

| Сервис | Категория | Мост | Что можно связать |
|---|---|---|---|
| [Mailchimp](./mailchimp.md) | Email | Встроен в B1 (вкладка Webhooks) | Поддерживать аудиторию Mailchimp в синхронизации с людьми, группами и сохранёнными списками B1 |
| [Donorbox](./donorbox.md) | Пожертвования | Zapier | Передавать пожертвования и жертвователей Donorbox обратно в B1 |
| [Subsplash](./subsplash.md) | Приложение / пожертвования | Zapier | Загружать пожертвования и людей Subsplash в B1 |
| [VOMO](./vomo.md) | Волонтёрство | Zapier | Синхронизировать записи волонтёров между группами B1 и проектами VOMO |
| [Clearstream](./clearstream.md) | SMS | Zapier | Запускать SMS Clearstream по событиям B1; принимать ответы как записи B1 |
| [Text In Church](./text-in-church.md) | SMS / рабочие процессы | Zapier | Запускать рабочие процессы Text In Church из B1; получать данные Connect Card |
| [Mobile Message](./mobile-message.md) | SMS (Австралия) | Webhooks by Zapier или Make | Отправлять SMS по любому событию B1 |
| [Checkr](./checkr.md) | Проверка биографии | Make | Запускать проверку биографии, когда человек присоединяется к служебной команде |

## Что общего у всех этих сервисов {#what-all-of-these-have-in-common}

1. **Сторона B1 в связке одинакова** — создайте API-ключ с нужными областями в **B1Admin → Settings → Developer → API Keys**, затем либо позвольте мосту зарегистрировать веб-хук для триггера (Zapier / Make делают это автоматически и требуют `settings:write`), либо вызывайте конечные точки REST B1 из последующего действия. Приложение B1.church для Zapier требует `settings:write` в каждом ключе, потому что при подключении оно проверяет ключ по списку веб-хуков B1. (Исключение — Mailchimp: её синхронизация встроена в B1 и настраивается на вкладке **Webhooks**, без API-ключа и моста.)
2. **Мост оплачиваете вы, а не мы.** ChurchApps бесплатна; у Zapier и Make есть бесплатные тарифы, которых хватает на несколько рецептов.
3. **Связку можно проверить, не запуская её в работу.** В Zapier есть кнопка «Test step», которая загружает образцы данных из B1 и показывает их структуру, прежде чем вы включите рецепт.

## Выбор моста {#picking-a-bridge}

- **Zapier** проще в работе и имеет более широкий каталог приложений — используйте его по умолчанию, если стоимость не важна.
- **Make** дешевле при большом объёме и имеет более гибкую логику маршрутизации и фильтров — используйте его, когда в одном процессе есть ветвление, условия или много шагов.
- **Webhooks by Zapier** (используется в документации Mobile Message) — универсальный адаптер, который позволяет отправлять POST на любую конечную точку HTTP из Zap, если получатель не является полноценным приложением Zapier.

Если нужного сервиса в этом списке нет, открыты [REST API](/docs/developer/api) и [веб-хуки](/docs/developer/api/webhooks) B1 — с помощью [`@churchapps/integration-sdk`](https://www.npmjs.com/package/@churchapps/integration-sdk) можно построить собственный мост за несколько часов.

## Чего здесь нет (и почему) {#whats-not-here-and-why}

Несколько популярных инструментов для работы церквей — Tithe.ly, Pushpay, Vanco, PastorsLine, Gloo, Notebird, KidCheck, MinistrySafe — сегодня не имеют опубликованного приложения Zapier или модуля Make. У них есть собственные API, но их подключение к B1 — задача для собственного кода, а не рецепт, поэтому в этот список они не попадают. Если поставщик добавит приложение Zapier или модуль Make, мы добавим и документ.

Мы также намеренно пропустили инструменты, специфичные для Planning Center Services (музыка, презентации), конкурирующие продукты ChMS, консультантов по миграции и инструменты, которые лишь очищают данные, специфичные для PCO: ни у одного из них нет полезного пути подключения к B1.
