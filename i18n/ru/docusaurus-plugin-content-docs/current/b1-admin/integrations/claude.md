# Claude

<div class="article-intro">

Спрашивайте Claude о вашей церкви обычным языком — он отвечает на основе данных B1, включая ваши уроки и классы FreePlay. Вопросы вроде *«сколько гостей, пришедших впервые, было в воскресенье?»* или *«кто присоединился к малой группе в этом месяце?»* — или поручите ему что-то сделать, например *«добавь на сайт новую страницу под названием Events»*. Настройка занимает меньше 3 минут, и для установки не нужны технические навыки или программное обеспечение.

</div>

<div class="prereqs">
<h4>Что понадобится</h4>

- **Аккаунт Claude.** **Бесплатный тариф подходит** — это хороший способ попробовать. Однако у бесплатных аккаунтов есть дневной лимит сообщений, а поиск данных в B1 расходует сообщения быстро, поэтому при регулярном использовании мы рекомендуем **Claude Pro** (около $20 в месяц).
- **Ваш логин B1** — тот же, что вы используете для B1 Admin.

</div>

:::tip Рекомендуется — можно попробовать бесплатно
Claude — самый простой способ подключить B1 к ИИ, и он работает на **бесплатном тарифе** — идеальный вариант, чтобы ваша церковь попробовала его, прежде чем за что-либо платить.
:::

Есть два способа подключения. **Вариант 1 самый простой** — ключ не нужен, ничего устанавливать не требуется.

## Вариант 1 — вход через B1 (самый простой)

Работает на сайте Claude, в настольном приложении Claude и в мобильном приложении Claude — настройте один раз, и подключение будет работать везде.

### Шаг 1 — откройте настройки коннекторов Claude

1. Перейдите на [claude.ai](https://claude.ai) и войдите (или создайте бесплатный аккаунт).
2. Нажмите на своё имя в левом нижнем углу, затем **Settings** → **Connectors**.

### Шаг 2 — добавьте B1

1. Нажмите **Add**, затем **Add custom connector**.
2. **Name:** введите `B1`.
3. **URL:** вставьте `https://api.churchapps.org/mcp`
4. Остальные параметры оставьте как есть и нажмите **Add**.

### Шаг 3 — войдите в B1

1. Нажмите **Connect**. Откроется страница входа в B1.
2. Войдите в свою учётную запись B1. Если вы состоите в нескольких церквях, проверьте, что вверху отображается нужная церковь.
3. B1 покажет, что Claude просит разрешить, и сообщит, что вас вернут на **claude.ai**. Нажмите **Allow**.

Вы вернётесь в Claude, и B1 отобразится как подключённый.

### Шаг 4 — спросите что-нибудь

Начните **новый чат** и попробуйте, например:

- *«Сколько человек в нашей церкви?»*
- *«Перечисли наши активные группы.»*
- *«Подведи итоги пожертвований за этот месяц по фондам.»*
- *«Кто присоединился к церкви за последние 30 дней?»*

В первый раз Claude запросит разрешение на использование B1 — нажмите **Allow**.

## Вариант 2 — настольное расширение с ключом B1

Используйте его, если хотите выдать Claude ключ с ограниченными правами (например, только на чтение). Работает в настольном приложении Claude для Mac или Windows; чтобы создать ключ, вам нужно право управлять настройками церкви в B1.

### Шаг 1 — установите приложение Claude

Скачайте приложение Claude на [claude.com/download](https://claude.com/download), установите его, откройте и войдите.

### Шаг 2 — создайте ключ B1

Ключ открывает Claude доступ к B1 *вашей* церкви — думайте о нём как о пароле только для Claude.

1. Войдите в [B1 Admin](https://admin.b1.church) и перейдите в [Settings → Developer](https://admin.b1.church/settings/developer).
2. На вкладке **API Keys** нажмите **New API Key**.
3. **Name:** введите `Claude`.
4. **Scopes:** отметьте, что Claude может делать. У каждой области есть флажок **read** (только просмотр) и флажок **write** (вносить изменения). Не уверены? Сначала отметьте только флажки **read** — позже можно создать новый ключ с большими правами.
5. Нажмите **Save», затем **Copy» скопируйте ключ. Он показывается только один раз, поэтому сразу переходите к шагу 3.

### Шаг 3 — добавьте B1 в Claude

1. [Скачайте расширение B1](https://github.com/mbyrdLCS/b1-claude-connect/releases/latest/download/b1-churchapps.mcpb).
2. **Дважды щёлкните** скачанный файл (`b1-churchapps.mcpb`). Откроется Claude и покажет **B1 (ChurchApps)**.
3. Нажмите **Install**.
4. Когда появится запрос **B1 API key**, вставьте ключ из шага 2 и сохраните.
5. **Полностью закройте Claude** (Mac: **Cmd+Q** · Windows: щёлкните правой кнопкой по значку Claude на панели задач → **Quit**) и откройте его снова.

Если двойной щелчок не открывает Claude, в Claude перейдите в **Settings → Extensions → Advanced settings → Install Extension…** и выберите скачанный файл. Затем начните новый чат и задайте вопрос.

:::tip Расширение уже установлено?
Ничего делать не нужно — FreePlay работает через то же подключение. Единственное исключение — версия 1.1.0: она запрашивала email и пароль B1. Чтобы обновить её, скачайте и установите расширение заново. Ваш ключ сохранится.
:::

## Безопасно ли это?

- Claude видит только данные **вашей церкви**.
- **Вход (вариант 1):** Claude никогда не может сделать больше, чем может ваш собственный логин B1. Страница входа B1 перечисляет всё, что Claude может делать, до того как вы нажмёте **Allow**.
- **С ключом (вариант 2):** Claude может делать в B1 только то, что разрешает ключ: ключ только с флажками **read** может смотреть, но ничего не изменит. FreePlay работает так же, по тому же ключу.
- **Как отключить:** в B1 Admin перейдите в **Settings → Developer** и отзовите приложение в разделе **Connected Apps** (вариант 1) или удалите ключ в разделе **API Keys** (вариант 2). Доступ прекращается сразу. Также можно нажать **Disconnect** на коннекторе B1 в Claude.

## Сколько это стоит?

Подключение B1 бесплатное — оно входит в ChurchApps. У самого Claude есть бесплатный тариф; Claude Pro (около $20 в месяц) даёт гораздо больше возможностей. См. [claude.com/pricing](https://claude.com/pricing).

## Технические подробности

Остальная часть этой страницы предназначена для технических пользователей и ИИ-ассистентов: области доступа, другие способы подключения и принцип работы.

### Области доступа

Claude обращается к B1 через **сервер Model Context Protocol (MCP)**, встроенный в API B1 (`https://api.churchapps.org/mcp`). Каждый вызов проходит те же правила аутентификации, прав доступа и привязки к церкви, что и запрос из B1 Admin. Claude ограничен **правами и областями** API-ключа и не может обращаться к webhook, административным OAuth-эндпоинтам или другим путям, доступным только оператору.

Типичные наборы областей для начала:

- **Помощник только для чтения:** `people:read`, `groups:read`, `attendance:read`, `donations:read`, `content:read`
- **Чтение + добавление заметок / задач:** добавьте `people:write`
- **Полноценный операционный помощник:** добавьте нужные области с суффиксом `:write`

Ключ с `donations:read` позволяет Claude подводить итоги пожертвований, но не может записать пожертвование. Ключ с `people:write` может добавить человека, но не может видеть пожертвования. Что разрешает каждая область, см. в [API Keys](/docs/developer/api/api-keys).

### Другие способы подключения

#### Claude Code (CLI)

В терминале:

```bash
claude mcp add --scope user --transport http b1 https://api.churchapps.org/mcp \
  --header "Authorization: Bearer cak_<prefix>.<secret>"
```

Вот и всё. В любой сессии Claude Code введите `/mcp`, чтобы убедиться, что сервер `b1` подключён, затем задайте Claude любой вопрос о вашей церкви.

#### Claude Desktop — ручная настройка (для опытных)

Если вы не хотите использовать расширение, отредактируйте файл настроек Claude Desktop:

- **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`

Добавьте запись сервера `b1`, которая соединяется с B1 через `mcp-remote` (требуется [Node.js](https://nodejs.org)):

```json
{
  "mcpServers": {
    "b1": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://api.churchapps.org/mcp",
        "--header", "Authorization:Bearer cak_<prefix>.<secret>"
      ]
    }
  }
}
```

Перезапустите Claude Desktop. В меню коннекторов в поле ввода чата будет показан `b1` с его инструментами.

#### Claude.ai (веб) — пользовательский коннектор

См. **Вариант 1** выше. Коннектор использует OAuth 2.1: Claude находит сервер авторизации B1 по адресу `https://api.churchapps.org/.well-known/oauth-protected-resource`, регистрируется через Dynamic Client Registration и входит с PKCE. На тарифах Team и Enterprise владельцу, возможно, придётся сначала добавить коннектор для организации. Claude не запрашивает конкретные области, поэтому на странице согласия предлагается всё, к чему имеет доступ вошедшая учётная запись B1. Отозвать доступ можно в **Settings → Developer → Connected Apps** в B1 Admin.

### Как это работает

API B1 предоставляет единую конечную точку MCP по адресу `/mcp`. Claude подключается к ней, проходит аутентификацию с вашим ключом `cak_…` и получает доступ к четырём инструментам:

| Инструмент | Что делает |
|---|---|
| `list_endpoints` | Выводит список REST-эндпоинтов, которые Claude может вызывать, с фильтрацией по пути. Используется для поиска. |
| `describe_endpoint` | Возвращает краткое описание и пример запроса/ответа для конкретного эндпоинта. |
| `api_call` | Фактически вызывает REST-эндпоинт от имени аутентифицированного пользователя. |
| `describe_page_builder` | Руководство по созданию и редактированию страниц сайта вашей церкви, которое Claude читает перед работой с содержимым сайта. |

Это та же поверхность `/membership/people`, `/giving/donations`, `/attendance/visits` и т. д., которую использует ваш B1 Admin — каждое правило авторизации применяется одинаково. Эндпоинты FreePlay (lessons.church) перечислены под `/lessons/*`; вызовы Claude к ним пересылаются в FreePlay от имени того же пользователя с теми же правами.

### Безопасность и ограничения

- **Изоляция по церкви.** Ключ API привязан к одной церкви. Claude не может видеть данные других церквей.
- **Ограничение правами.** Если вы уберёте право у человека, создавшего ключ в B1Admin, Claude потеряет его при следующем вызове — мгновенно.
- **Отзыв.** Удалите ключ в **Settings → Developer → API Keys**, и доступ Claude прекратится сразу.
- **Чёрный список.** Вебхуки провайдеров, административные эндпоинты OAuth-клиентов и маршрут `apiEmails`, доступный только оператору, нельзя вызвать через MCP.
- **Ограничение размера ответа.** Один ответ инструмента ограничен 64 КБ, чтобы длинные списки не переполняли контекст Claude — при этом Claude сузит запрос фильтрами.
- **Журнал аудита.** Изменения проходят через тот же журнал аудита, что и действия в B1Admin; их можно просмотреть в **Settings → Audit Log**.

### Устранение неполадок

**Claude просит email и пароль B1, чтобы использовать FreePlay:** у вас версия 1.1.0 настольного расширения. Скачайте и установите его заново, чтобы обновить — новые версии используют только ваш ключ.

**Claude сообщает «Unauthorized» или 401:** токен авторизации отсутствует, повреждён или ключ был отозван. Если вы использовали расширение, откройте в Claude **Settings → Extensions → B1 (ChurchApps)** и вставьте ключ заново. В противном случае проверьте заголовок `Authorization: Bearer cak_…` (обратите внимание на пробел и слово `Bearer` без изменений).

**Вызов инструмента возвращает 403:** у API-ключа нет области для этого эндпоинта. Добавьте область в **Settings → Developer → API Keys** (придётся создать новый ключ — области нельзя изменить на месте) и вставьте новый ключ в настройки расширения или в конфигурацию Claude.

**Claude не может найти эндпоинт:** попросите его вызвать `list_endpoints` с фильтром, например *«используй list_endpoints с фильтром 'donations', чтобы найти нужный путь»*. Список маршрутов формируется из работающего API, так что всё, что доступно через `curl`, там есть.

**Локальная разработка:** замените `https://api.churchapps.org/mcp` на `http://localhost:8084/mcp` — та же авторизация, те же инструменты.
