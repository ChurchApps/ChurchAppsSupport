# Claude

<div class="article-intro">

Спрашивайте Claude о вашей церкви обычным языком -- он отвечает на основе данных B1, включая ваши уроки и классы FreePlay. Вопросы вроде *«сколько гостей, пришедших впервые, было в воскресенье?»* или *«кто присоединился к малой группе в этом месяце?»* -- или поручите ему действия, например *«добавь на наш сайт новую страницу под названием Events»*. Настройка занимает меньше 3 минут, и для установки не нужны технические навыки или программы.

</div>

<div class="prereqs">
<h4>Что понадобится</h4>

- **Учётная запись Claude.** **Бесплатный тариф подходит** -- это хороший способ попробовать. Однако у бесплатных учётных записей есть дневной лимит сообщений, а поиск данных в B1 расходует сообщения быстро, поэтому при регулярном использовании мы рекомендуем **Claude Pro** (около $20 в месяц).
- **Ваш логин B1** -- тот же, что вы используете для B1 Admin.

</div>

:::tip Рекомендуется -- можно попробовать бесплатно
Claude -- самый простой способ подключить B1 к ИИ, и он работает на **бесплатном тарифе** Claude -- отличная возможность для вашей церкви попробовать его, прежде чем платить за что-либо.
:::

Есть два способа подключения. **Вариант 1 -- самый простой**: ключ не нужен и ничего устанавливать не требуется.

## Вариант 1 -- вход через B1 (самый простой)

Работает на сайте Claude, в настольном приложении Claude и в мобильном приложении Claude -- настройте один раз, и подключение будет доступно везде.

### Шаг 1 -- откройте настройки коннекторов Claude

1. Перейдите на [claude.ai](https://claude.ai) и войдите (или создайте бесплатную учётную запись).
2. Нажмите на своё имя в левом нижнем углу, затем **Settings** → **Connectors**.

### Шаг 2 -- добавьте B1

1. Нажмите **Add**, затем **Add custom connector**.
2. **Name:** введите `B1`.
3. **URL:** вставьте `https://api.churchapps.org/mcp`
4. Остальные параметры оставьте как есть и нажмите **Add**.

### Шаг 3 -- войдите в B1

1. Нажмите **Connect**. Откроется страница входа B1.
2. Войдите в свою учётную запись B1. Если вы состоите в нескольких церквях, убедитесь, что вверху показана нужная церковь.
3. B1 перечисляет, что Claude просит сделать, и сообщает, что вас вернут на **claude.ai**. Нажмите **Allow**.

Вы вернётесь в Claude, и B1 будет показан как подключённый.

### Шаг 4 -- задайте вопрос

Начните **новый чат** и попробуйте:

- *«Сколько людей в нашей церкви?»*
- *«Перечисли наши активные группы.»*
- *«Подведи итоги пожертвований за этот месяц по фондам.»*
- *«Кто присоединился к церкви за последние 30 дней?»*

В первый раз Claude запросит разрешение на использование B1 -- нажмите **Allow**.

## Вариант 2 -- расширение для настольного приложения с ключом B1

Используйте этот вариант, если хотите дать Claude ключ с ограниченными правами (например, только на чтение). Он работает в настольном приложении Claude для Mac или Windows, а для создания ключа нужно право управлять настройками церкви в B1.

### Шаг 1 -- получите приложение Claude

Скачайте приложение Claude с [claude.com/download](https://claude.com/download), установите, откройте и войдите.

### Шаг 2 -- создайте ключ B1

Ключ даёт Claude доступ к B1 *вашей* церкви -- думайте о нём как о пароле только для Claude.

1. Войдите в [B1 Admin](https://admin.b1.church) и перейдите в [Settings → Developer](https://admin.b1.church/settings/developer).
2. На вкладке **API Keys** нажмите **New API Key**.
3. **Name:** введите `Claude`.
4. **Scopes:** отметьте, что Claude может делать. У каждой области есть поле **read** (только просмотр) и поле **write** (вносить изменения). Не уверены? Для начала отметьте только поля **read** -- позже вы сможете создать новый ключ с большими правами.
5. Нажмите **Save**, затем **Copy** ключ. Он показывается только один раз, поэтому сразу переходите к шагу 3.

### Шаг 3 -- добавьте B1 в Claude

1. [Скачайте расширение B1](https://github.com/mbyrdLCS/b1-claude-connect/releases/latest/download/b1-churchapps.mcpb).
2. **Дважды щёлкните** скачанный файл (`b1-churchapps.mcpb`). Откроется Claude и покажет **B1 (ChurchApps)**.
3. Нажмите **Install**.
4. Когда попросит ваш **B1 API key**, вставьте ключ из шага 2 и сохраните.
5. **Полностью закройте Claude** (Mac: **Cmd+Q** · Windows: щёлкните правой кнопкой по значку Claude на панели задач → **Quit**) и откройте его снова.

Если двойной щелчок не открывает Claude, откройте в Claude **Settings → Extensions → Advanced settings → Install Extension…** и выберите скачанный файл. Затем начните новый чат и задайте любой вопрос.

:::tip Расширение уже установлено?
Ничего делать не нужно -- FreePlay работает через то же подключение. Исключение -- версия 1.1.0, которая запрашивала email и пароль B1: скачайте и установите расширение заново, чтобы обновить его. Ваш ключ сохранится.
:::

## Безопасно ли это?

- Claude видит только данные **вашей церкви**.
- **Вход (Вариант 1):** Claude никогда не может сделать больше, чем ваш собственный логин B1. Страница входа B1 перечисляет всё, что Claude может делать, прежде чем вы нажмёте **Allow**.
- **С ключом (Вариант 2):** Claude может делать только то, что разрешает ключ в B1, -- ключ только с отмеченными полями **read** может смотреть, но никогда ничего не изменит. FreePlay работает так же, по тому же ключу.
- **Как отключить:** в B1 Admin перейдите в **Settings → Developer** и отзовите приложение в разделе **Connected Apps** (Вариант 1) или удалите ключ в разделе **API Keys** (Вариант 2). Доступ прекращается сразу. Также можно нажать **Disconnect** у коннектора B1 в Claude.

## Сколько это стоит?

Подключение B1 бесплатное -- оно входит в ChurchApps. Сам Claude имеет бесплатный тариф; Claude Pro (около $20 в месяц) даёт гораздо больше возможностей. См. [claude.com/pricing](https://claude.com/pricing).

## Технические подробности

Остальная часть страницы предназначена для технических пользователей и ИИ-ассистентов: области доступа, другие способы подключения и принцип работы.

### Области доступа (scopes) {#scopes}

Claude обращается к B1 через **сервер Model Context Protocol (MCP)**, встроенный в API B1 (`https://api.churchapps.org/mcp`). Каждый вызов проходит через те же правила аутентификации, прав доступа и привязки к церкви, что и запрос из B1 Admin. Claude ограничен **правами и областями** ключа API и не может обращаться к вебхукам, административным OAuth-эндпоинтам или другим путям, доступным только оператору.

Распространённые наборы областей для старта:

- **Только чтение:** `people:read`, `groups:read`, `attendance:read`, `donations:read`, `content:read`
- **Чтение + добавление заметок / задач:** добавьте `people:write`
- **Полный оперативный ассистент:** добавьте нужные вам области с суффиксом `:write`

Ключ с `donations:read` позволяет Claude подводить итоги пожертвований, но не может записать пожертвование. Ключ с `people:write` может добавить человека, но не видит пожертвования. Что разрешает каждая область, см. в [API Keys](/docs/developer/api/api-keys).

### Другие способы подключения

#### Claude Code (CLI)

В терминале:

```bash
claude mcp add --scope user --transport http b1 https://api.churchapps.org/mcp \
  --header "Authorization: Bearer cak_<prefix>.<secret>"
```

Вот и всё. В любой сессии Claude Code введите `/mcp`, чтобы проверить, что сервер `b1` подключён, затем задайте Claude любой вопрос о вашей церкви.

#### Claude Desktop -- ручная настройка (для опытных)

Если не хотите использовать расширение, отредактируйте файл конфигурации Claude Desktop:

- **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`

Добавьте запись сервера `b1`, которая соединяется с B1 через `mcp-remote` (требуется [Node.js](https://nodejs.org)):

```json
{
  "mcpServers": {
    "b1": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://api.churchapps.org/mcp",
        "--header", "Authorization:Bearer cak_<prefix>.<secret>"
      ]
    }
  }
}
```

Перезапустите Claude Desktop. В меню коннекторов в поле ввода чата появится `b1` со своими инструментами.

#### Claude.ai (веб) -- пользовательский коннектор

См. **Вариант 1** выше. Коннектор использует OAuth 2.1: Claude находит сервер авторизации B1 по адресу `https://api.churchapps.org/.well-known/oauth-protected-resource`, регистрирует себя через Dynamic Client Registration и входит с помощью PKCE. В тарифах Team и Enterprise владельцу может понадобиться сначала добавить коннектор для организации. Claude не запрашивает конкретные области, поэтому на странице согласия предлагается всё, к чему имеет доступ вошедшая учётная запись B1. Отозвать доступ можно в **Settings → Developer → Connected Apps** в B1 Admin.

### Как это работает

API B1 предоставляет единую конечную точку MCP по адресу `/mcp`. Claude подключается к ней, проходит аутентификацию с вашим ключом `cak_…` и получает доступ к четырём инструментам:

| Инструмент | Что делает |
|---|---|
| `list_endpoints` | Перечисляет REST-эндпоинты, которые Claude может вызывать, с фильтром по пути. Используется для поиска. |
| `describe_endpoint` | Возвращает краткое описание и пример запроса/ответа для конкретного эндпоинта. |
| `api_call` | Фактически вызывает REST-эндпоинт от имени аутентифицированного пользователя. |
| `describe_page_builder` | Руководство по созданию и редактированию страниц сайта вашей церкви, которое Claude читает перед работой с содержимым сайта. |

Это та же поверхность `/membership/people`, `/giving/donations`, `/attendance/visits` и т. д., которую использует B1 Admin, -- все правила авторизации применяются одинаково. Эндпоинты FreePlay (lessons.church) перечислены в `/lessons/*`; запросы Claude к ним пересылаются в FreePlay от имени того же пользователя и с теми же правами.

### Безопасность и ограничения

- **Изоляция по церквям.** Ключ API привязан к одной церкви. Claude не может увидеть данные других церквей.
- **Ограничение правами.** Если вы уберёте право у человека, который создал ключ в B1 Admin, Claude потеряет его при следующем вызове -- мгновенно.
- **Отзыв.** Удалите ключ в **Settings → Developer → API Keys**, и доступ Claude прекратится сразу.
- **Чёрный список.** Вебхуки провайдеров, административные эндпоинты клиентов OAuth и маршрут `apiEmails`, доступный только оператору, нельзя вызвать через MCP.
- **Ограничение размера ответа.** Один ответ инструмента ограничен 64 КБ, чтобы длинные списки не переполняли контекст Claude -- в таком случае Claude сузит запрос фильтрами.
- **Журнал аудита.** Изменения проходят через тот же журнал аудита, что и действия в B1 Admin; их можно просмотреть в **Settings → Audit Log**.

### Устранение неполадок

**Claude просит email и пароль B1, чтобы использовать FreePlay:** у вас версия 1.1.0 настольного расширения. Скачайте и установите его заново, чтобы обновить -- новые версии используют только ваш ключ.

**Claude сообщает "Unauthorized" или 401:** токен авторизации отсутствует, неверен или ключ отозван. Если вы использовали расширение, откройте в Claude **Settings → Extensions → B1 (ChurchApps)** и вставьте ключ заново. Иначе перепроверьте заголовок `Authorization: Bearer cak_…` (обратите внимание на пробел и слово `Bearer` буквально).

**Вызов инструмента возвращает 403:** у ключа API нет области для этого эндпоинта. Добавьте область в **Settings → Developer → API Keys** (придётся создать новый ключ -- области нельзя изменить на месте) и вставьте новый ключ в настройки расширения или в конфигурацию Claude.

**Claude не может найти эндпоинт:** попросите его вызвать `list_endpoints` с фильтром, например: *«используй list_endpoints с фильтром 'donations', чтобы найти нужный путь»*. Список маршрутов формируется из работающего API, так что всё, до чего можно достучаться через `curl`, там есть.

**Локальная разработка:** замените `https://api.churchapps.org/mcp` на `http://localhost:8084/mcp` -- та же авторизация, те же инструменты.
