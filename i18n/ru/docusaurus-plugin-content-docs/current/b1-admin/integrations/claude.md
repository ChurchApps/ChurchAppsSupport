# Claude

<div class="article-intro">

Задавайте Claude вопросы о своей церкви обычным языком, и он будет отвечать на основе ваших данных B1. Например, *"сколько гостей пришли впервые в это воскресенье?"* или *"кто присоединился к малой группе в этом месяце?"* — или попросите его что-то сделать, например, *"добавь на наш сайт новую страницу под названием Events."* Настройка занимает меньше 3 минут, и для установки не нужны технические навыки или программное обеспечение.

</div>

<div class="prereqs">
<h4>Что понадобится</h4>

- **Аккаунт Claude.** **Бесплатный тариф подходит** — это хороший способ попробовать. Однако в бесплатных аккаунтах есть дневной лимит сообщений, а запросы к B1 расходуют сообщения быстро, поэтому при регулярном использовании мы рекомендуем **Claude Pro** (около $20 в месяц).
- **Ваш логин B1** — тот же, что и для B1 Admin.

</div>

:::tip Рекомендуется — можно попробовать бесплатно
Claude — самый простой способ подключить B1 к ИИ, и он работает на **бесплатном тарифе** Claude, что позволяет вашей церкви попробовать его, прежде чем платить за что-либо.
:::

Есть два способа подключения. **Вариант 1 — самый простой**: не нужен ключ и ничего не нужно устанавливать.

## Вариант 1 — Вход через B1 (самый простой)

Работает на сайте Claude, в настольном приложении Claude и в мобильном приложении Claude — настройте один раз, и подключение будет работать во всех них.

### Шаг 1 — Откройте настройки коннекторов Claude

1. Перейдите на [claude.ai](https://claude.ai) и войдите в аккаунт (или создайте бесплатный).
2. Нажмите на своё имя в левом нижнем углу, затем **Settings** → **Connectors**.

### Шаг 2 — Добавьте B1

1. Нажмите **Add**, затем **Add custom connector**.
2. **Name:** введите `B1`.
3. **URL:** вставьте `https://api.churchapps.org/mcp`
4. Остальные параметры оставьте как есть и нажмите **Add**.

### Шаг 3 — Войдите в B1

1. Нажмите **Connect**. Откроется страница входа в B1.
2. Войдите под своим аккаунтом B1. Если вы состоите в нескольких церквях, проверьте, что вверху отображается нужная.
3. B1 покажет, что Claude собирается делать, и сообщит, что вы вернётесь на **claude.ai**. Нажмите **Allow**.

Вы вернётесь в Claude, и B1 будет отображаться как подключённый.

### Шаг 4 — Задайте вопрос

Откройте **новый чат** и попробуйте:

- *"Сколько людей в нашей церкви?"*
- *"Перечисли наши активные группы."*
- *"Подведи итог пожертвований за этот месяц по фондам."*
- *"Кто присоединился к церкви за последние 30 дней?"*

При первом запросе Claude попросит разрешение на использование B1 — нажмите **Allow**.

## Вариант 2 — Расширение для настольного приложения с ключом B1

Используйте этот способ, если хотите выдать Claude ключ с ограниченными правами (например, только на чтение). Он работает в настольном приложении Claude для Mac или Windows. Чтобы создать ключ, нужно иметь право управлять настройками церкви в B1.

### Шаг 1 — Установите приложение Claude

Скачайте приложение Claude с [claude.com/download](https://claude.com/download), установите его, откройте и войдите в аккаунт.

### Шаг 2 — Создайте ключ B1

Ключ даёт Claude доступ к B1 *вашей* церкви — представьте его как пароль только для Claude.

1. Войдите в [B1 Admin](https://admin.b1.church) и перейдите в [Settings → Developer](https://admin.b1.church/settings/developer).
2. На вкладке **API Keys** нажмите **New API Key**.
3. **Name:** введите `Claude`.
4. **Scopes:** отметьте, что Claude может делать. Для каждой области есть поле **read** (только просмотр) и поле **write** (внесение изменений). Не уверены? Для начала отметьте только поля **read** — позже можно создать новый ключ с большими правами.
5. Нажмите **Save**, затем **Copy**, чтобы скопировать ключ. Он показывается только один раз, поэтому сразу переходите к шагу 3.

### Шаг 3 — Добавьте B1 в Claude

1. [Скачайте расширение B1](https://github.com/mbyrdLCS/b1-claude-connect/releases/latest/download/b1-churchapps.mcpb).
2. **Дважды щёлкните** скачанный файл (`b1-churchapps.mcpb`). Откроется Claude и покажет **B1 (ChurchApps)**.
3. Нажмите **Install**.
4. Когда появится запрос **B1 API key**, вставьте ключ из шага 2 и сохраните.
5. **Полностью закройте Claude** (Mac: **Cmd+Q** · Windows: щёлкните правой кнопкой по значку Claude на панели задач → **Quit**) и откройте его снова.

Если двойной щелчок не открывает Claude, откройте в Claude **Settings → Extensions → Advanced settings → Install Extension…** и выберите скачанный файл. Затем начните новый чат и задайте вопрос.

## Безопасно ли это?

- Claude видит только данные **вашей церкви**.
- **Вход (Вариант 1):** Claude не может делать больше, чем ваш собственный логин B1. Страница входа в B1 перечисляет всё, что Claude может делать, до того как вы нажмёте **Allow**.
- **С ключом (Вариант 2):** Claude может делать только то, что разрешает ключ. Ключ только с отмеченными полями **read** может просматривать данные, но ничего не изменит.
- **Как отключить:** в B1 Admin перейдите в **Settings → Developer** и отзовите приложение в разделе **Connected Apps** (Вариант 1) или удалите ключ в разделе **API Keys** (Вариант 2). Доступ прекращается сразу. Также можно нажать **Disconnect** у коннектора B1 в Claude.

## Сколько это стоит?

Подключение B1 бесплатное — оно входит в состав ChurchApps. У Claude есть бесплатный тариф; Claude Pro (около $20 в месяц) даёт гораздо больше возможностей. См. [claude.com/pricing](https://claude.com/pricing).

## Технические подробности

Остальная часть этой страницы предназначена для технических специалистов и ИИ-ассистентов: области доступа (scopes), другие способы подключения и принцип работы.

### Области доступа (Scopes)

Claude обращается к B1 через **сервер Model Context Protocol (MCP)**, встроенный в API B1 (`https://api.churchapps.org/mcp`). Каждый вызов проходит те же правила аутентификации, разрешений и привязки к церкви, что и запрос из B1 Admin. Claude ограничен **разрешениями и областями доступа** API-ключа и не может обращаться к вебхукам, административным OAuth-эндпоинтам или другим путям, доступным только оператору.

Распространённые наборы областей для начала:

- **Помощник только для чтения:** `people:read`, `groups:read`, `attendance:read`, `donations:read`, `content:read`
- **Чтение + добавление заметок / задач:** добавьте `people:write`
- **Полноценный операционный помощник:** добавьте нужные области с суффиксом `:write`

Ключ с `donations:read` позволяет Claude подводить итоги пожертвований, но не может зарегистрировать пожертвование. Ключ с `people:write` может добавить человека, но не может видеть пожертвования. Подробнее о том, что разрешает каждая область, см. [API Keys](/docs/developer/api/api-keys).

### Другие способы подключения

#### Claude Code (CLI)

В терминале:

```bash
claude mcp add --scope user --transport http b1 https://api.churchapps.org/mcp \
  --header "Authorization: Bearer cak_<prefix>.<secret>"
```

Вот и всё. В любой сессии Claude Code введите `/mcp`, чтобы убедиться, что сервер `b1` подключён, и затем задавайте любые вопросы о вашей церкви.

#### Claude Desktop — ручная настройка (для опытных пользователей)

Если вы не хотите использовать расширение, отредактируйте файл конфигурации Claude Desktop:

- **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`

Добавьте запись сервера `b1`, которая связывает Claude с B1 через `mcp-remote` (требуется [Node.js](https://nodejs.org)):

```json
{
  "mcpServers": {
    "b1": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://api.churchapps.org/mcp",
        "--header", "Authorization:Bearer cak_<prefix>.<secret>"
      ]
    }
  }
}
```

Перезапустите Claude Desktop. В меню коннекторов в поле ввода чата появится `b1` со своими инструментами.

#### Claude.ai (веб) — пользовательский коннектор

См. **Вариант 1** выше. Коннектор использует OAuth 2.1: Claude находит сервер авторизации B1 по адресу `https://api.churchapps.org/.well-known/oauth-protected-resource`, регистрирует себя через Dynamic Client Registration и выполняет вход с PKCE. На тарифах Team и Enterprise владелец организации может сначала добавить коннектор для всей организации. Claude не запрашивает конкретные области доступа, поэтому на странице согласия предлагается всё, к чему имеет доступ вошедший аккаунт B1. Отозвать доступ можно в **Settings → Developer → Connected Apps** в B1 Admin.

### Как это работает

API B1 предоставляет единую конечную точку MCP по адресу `/mcp`. Claude подключается к ней, проходит аутентификацию с вашим ключом `cak_…` и получает доступ к четырём инструментам:

| Инструмент | Что делает |
|---|---|
| `list_endpoints` | Выводит список REST-эндпоинтов, которые может вызывать Claude, с возможностью фильтрации по пути. Используется для поиска. |
| `describe_endpoint` | Возвращает краткое описание и пример запроса/ответа для конкретного эндпоинта. |
| `api_call` | Выполняет вызов REST-эндпоинта от имени авторизованного пользователя. |
| `describe_page_builder` | Руководство по созданию и редактированию страниц сайта вашей церкви; Claude читает его перед работой с содержимым сайта. |

Это та же поверхность `/membership/people`, `/giving/donations`, `/attendance/visits` и т. д., которую использует ваш B1Admin — все правила авторизации применяются одинаково.

### Безопасность и ограничения

- **Изоляция по церкви.** API-ключ привязан к одной церкви. Claude не может видеть данные других церквей.
- **Ограничение разрешениями.** Если вы уберёте разрешение у человека, создавшего ключ, в B1Admin, Claude потеряет его при следующем вызове — мгновенно.
- **Отзыв доступа.** Удалите ключ в **Settings → Developer → API Keys**, и доступ Claude прекратится сразу.
- **Чёрный список.** Вебхуки провайдеров, административные эндпоинты OAuth-клиентов и маршрут `apiEmails`, доступный только оператору, недоступны через MCP.
- **Ограничение размера ответа.** Один ответ инструмента ограничен 64 КБ, чтобы длинные списки не переполняли контекст Claude — в таком случае Claude сузит запрос с помощью фильтров.
- **Журнал аудита.** Изменения проходят через тот же журнал аудита, что и действия в B1Admin; просмотреть их можно в **Settings → Audit Log**.

### Устранение неполадок

**Claude сообщает об ошибке "Unauthorized" или 401:** токен авторизации отсутствует, имеет неверный формат или ключ был отозван. Если вы использовали расширение, откройте в Claude **Settings → Extensions → B1 (ChurchApps)** и вставьте ключ заново. В противном случае проверьте заголовок `Authorization: Bearer cak_…` (обратите внимание на пробел и на написание слова `Bearer`).

**Вызов инструмента возвращает 403:** у API-ключа нет области доступа для этого эндпоинта. Добавьте область в **Settings → Developer → API Keys** (придётся создать новый ключ — области нельзя изменить на месте) и вставьте новый ключ в настройки расширения или в конфигурацию Claude.

**Claude не может найти эндпоинт:** попросите его вызвать `list_endpoints` с фильтром, например, *"используй list_endpoints с фильтром 'donations', чтобы найти нужный путь"*. Список маршрутов формируется из работающего API, поэтому всё, к чему можно обратиться через `curl`, там есть.

**Локальная разработка:** замените `https://api.churchapps.org/mcp` на `http://localhost:8084/mcp` — авторизация и инструменты те же.
