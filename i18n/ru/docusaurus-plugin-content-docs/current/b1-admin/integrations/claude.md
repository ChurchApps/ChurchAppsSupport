# Claude

<div class="article-intro">

Спрашивайте Claude о вашей церкви простым языком — он отвечает на основе ваших данных в B1. Вопросы вроде *"сколько новичков пришло в воскресенье?"* или *"кто присоединился к малой группе в этом месяце?"* — или попросите его что-то сделать, например *"добавь на наш сайт новую страницу под названием «События»."* Настройка занимает меньше 3 минут, и не требуется ни технических навыков, ни установки программ.

</div>

<div class="prereqs">
<h4>Что вам понадобится</h4>

- **Аккаунт Claude.** **Бесплатный план подойдет** — это хороший способ попробовать. Однако у бесплатных аккаунтов есть дневной лимит сообщений, а запросы к B1 быстро его расходуют, поэтому при регулярном использовании мы рекомендуем **Claude Pro** (около $20/месяц).
- **Ваш вход в B1** — тот же, что вы используете для B1 Admin.

</div>

:::tip Рекомендуем — можно попробовать бесплатно
Claude — самый простой способ подключить B1 к ИИ, и он работает на **бесплатном плане** Claude — отличная возможность для вашей церкви попробовать, прежде чем за что-либо платить.
:::

Подключиться можно двумя способами. **Вариант 1 — самый простой**: без ключа и без установки чего-либо.

## Вариант 1 — Вход через B1 (самый простой)

Работает на сайте Claude, в настольном приложении Claude и в мобильном приложении Claude — настройте один раз, и подключение будет работать везде.

### Шаг 1 — Откройте настройки коннекторов Claude

1. Перейдите на [claude.ai](https://claude.ai) и войдите (или создайте бесплатный аккаунт).
2. Нажмите на свое имя в левом нижнем углу, затем **Settings** (Настройки) → **Connectors** (Коннекторы).

### Шаг 2 — Добавьте B1

1. Нажмите **Add** (Добавить), затем **Add custom connector** (Добавить пользовательский коннектор).
2. **Name** (Название): введите `B1`.
3. **URL:** вставьте `https://api.churchapps.org/mcp`
4. Остальные параметры оставьте как есть и нажмите **Add** (Добавить).

### Шаг 3 — Войдите в B1

1. Нажмите **Connect** (Подключить). Откроется страница входа B1.
2. Войдите со своей учетной записью B1. Если вы состоите в нескольких церквях, проверьте, что вверху указана нужная церковь.
3. B1 покажет, что Claude просит разрешения делать, и подтвердит, что вы вернетесь на **claude.ai**. Нажмите **Allow** (Разрешить).

Вы снова в Claude, и B1 отображается как подключенный.

### Шаг 4 — Задайте вопрос

Начните **новый чат** и попробуйте:

- *"Сколько людей в нашей церкви?"*
- *"Перечисли наши активные группы."*
- *"Подведи итоги пожертвований этого месяца по фондам."*
- *"Кто присоединился к церкви за последние 30 дней?"*

В первый раз Claude попросит разрешения использовать B1 — нажмите **Allow** (Разрешить).

## Вариант 2 — Расширение для настольного приложения с ключом B1

Используйте этот способ, если хотите дать Claude ключ с ограниченными правами (например, только для просмотра). Он работает в настольном приложении Claude для Mac или Windows, а чтобы создать ключ, вам нужно право управлять настройками церкви в B1.

### Шаг 1 — Установите приложение Claude

Скачайте приложение Claude с [claude.com/download](https://claude.com/download), установите его, откройте и войдите.

### Шаг 2 — Создайте ключ B1

Ключ — это то, что пускает Claude в B1 *вашей* церкви. Считайте его паролем, предназначенным только для Claude.

1. Войдите в [B1 Admin](https://admin.b1.church) и перейдите в [Settings → Developer](https://admin.b1.church/settings/developer).
2. На вкладке **API Keys** нажмите **New API Key**.
3. **Name:** введите `Claude`.
4. **Scopes (области):** отметьте, что разрешено Claude. В каждом разделе есть флажок **read** (только просмотр) и флажок **write** (внесение изменений). Не уверены? Для начала отметьте только флажки **read** — позже можно создать новый ключ с большими правами.
5. Нажмите **Save**, затем **Copy**, чтобы скопировать ключ. Он показывается только один раз, поэтому сразу переходите к шагу 3.

### Шаг 3 — Добавьте B1 в Claude

1. [Скачайте расширение B1](https://github.com/mbyrdLCS/b1-claude-connect/releases/latest/download/b1-churchapps.mcpb).
2. **Дважды щелкните** скачанный файл (`b1-churchapps.mcpb`). Claude откроется и покажет **B1 (ChurchApps)**.
3. Нажмите **Install**.
4. Когда появится запрос **B1 API key** (ключ API B1), вставьте ключ из шага 2 и сохраните.
5. **Полностью закройте Claude** (Mac: **Cmd+Q** · Windows: щелкните правой кнопкой значок Claude на панели задач → **Quit**) и откройте его снова.

Если двойной щелчок не открывает Claude, перейдите в Claude в **Settings → Extensions → Advanced settings → Install Extension…** и выберите скачанный файл. Затем начните новый чат и задайте вопрос.

## Это безопасно?

- Claude видит только данные **вашей церкви**.
- **Со входом через B1 (вариант 1):** Claude никогда не сможет сделать больше, чем позволяет ваш собственный вход в B1. Страница входа B1 перечисляет все, что будет разрешено Claude, прежде чем вы нажмете **Allow** (Разрешить).
- **С ключом (вариант 2):** Claude может делать только то, что разрешает ключ, — ключ, в котором отмечены только флажки **read**, может просматривать данные, но никогда ничего не изменит.
- **Чтобы отключить доступ:** в B1 Admin перейдите в **Settings → Developer** и отзовите приложение в разделе **Connected Apps** (вариант 1) или удалите ключ в разделе **API Keys** (вариант 2). Доступ прекращается сразу. Также можно нажать **Disconnect** (Отключить) у коннектора B1 в Claude.

## Сколько это стоит?

Подключение к B1 бесплатно — оно входит в ChurchApps. У самого Claude есть бесплатный план; Claude Pro (около $20/месяц) дает гораздо больше возможностей. См. [claude.com/pricing](https://claude.com/pricing).

## Технические подробности

Остальная часть страницы предназначена для технических пользователей и ИИ-ассистентов: области (scopes), другие способы подключения и принцип работы.

### Области (scopes)

Claude взаимодействует с B1 через встроенный в B1 API **сервер Model Context Protocol (MCP)** (`https://api.churchapps.org/mcp`). Каждый вызов проходит через те же правила аутентификации, разрешений и привязки к церкви, что и запрос из B1 Admin. Claude ограничен **разрешениями и областями** API-ключа и не может обращаться к вебхукам, конечным точкам администрирования OAuth и другим путям, доступным только операторам.

Типичные начальные наборы областей:

- **Помощник только для чтения:** `people:read`, `groups:read`, `attendance:read`, `donations:read`, `content:read`
- **Чтение + добавление заметок / задач:** добавьте `people:write`
- **Полноценный рабочий помощник:** добавьте нужные соответствующие области `:write`

Ключ `donations:read` позволяет Claude подводить итоги пожертвований, но не записывать пожертвование. Ключ `people:write` может добавить человека, но не видит пожертвования. Что разрешает каждая область, см. в [API Keys](/docs/developer/api/api-keys).

### Другие способы подключения

#### Claude Code (CLI)

В терминале:

```bash
claude mcp add --scope user --transport http b1 https://api.churchapps.org/mcp \
  --header "Authorization: Bearer cak_<prefix>.<secret>"
```

Вот и все. В любой сессии Claude Code введите `/mcp`, чтобы убедиться, что сервер `b1` подключен, а затем задавайте Claude любые вопросы о вашей церкви.

#### Claude Desktop — ручная настройка (для опытных)

Если вы не хотите использовать расширение, отредактируйте файл конфигурации Claude Desktop:

- **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`

Добавьте запись сервера `b1`, которая подключается к B1 через `mcp-remote` (требуется [Node.js](https://nodejs.org)):

```json
{
  "mcpServers": {
    "b1": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://api.churchapps.org/mcp",
        "--header", "Authorization:Bearer cak_<prefix>.<secret>"
      ]
    }
  }
}
```

Перезапустите Claude Desktop. Меню коннекторов в поле ввода чата покажет `b1` с его инструментами.

#### Claude.ai (веб) — пользовательский коннектор

См. **Вариант 1** выше. Коннектор использует OAuth 2.1: Claude находит сервер авторизации B1 по адресу `https://api.churchapps.org/.well-known/oauth-protected-resource`, регистрируется через Dynamic Client Registration и выполняет вход с PKCE. В планах Team и Enterprise владельцу, возможно, сначала нужно будет добавить коннектор для организации. Claude не запрашивает конкретные области (scopes), поэтому на странице согласия предлагается все, к чему имеет доступ вошедшая учетная запись B1. Отозвать доступ можно в B1 Admin в разделе **Settings → Developer → Connected Apps**.

### Как это работает

B1 API предоставляет одну конечную точку MCP по адресу `/mcp`. Claude подключается к ней, аутентифицируется с вашим ключом `cak_…` и получает доступ к четырем инструментам:

| Инструмент | Что он делает |
|---|---|
| `list_endpoints` | Перечисляет конечные точки REST, которые может вызывать Claude, с фильтром по пути. Используется для обнаружения. |
| `describe_endpoint` | Возвращает краткое описание и пример запроса/ответа для конкретной конечной точки. |
| `api_call` | Собственно вызывает конечную точку REST от имени аутентифицированного пользователя. |
| `describe_page_builder` | Руководство по созданию и редактированию страниц сайта вашей церкви, которое Claude читает перед работой с содержимым сайта. |

Это те же `/membership/people`, `/giving/donations`, `/attendance/visits` и т. д., которые использует ваш B1Admin, — все правила авторизации применяются точно так же.

### Безопасность и ограничения

- **Изоляция по церквям.** API-ключ привязан к одной церкви. Claude никак не может увидеть данные других церквей.
- **Ограничено разрешениями.** Если вы удалите разрешение у человека, который создал ключ в B1Admin, Claude потеряет его при следующем вызове — мгновенно.
- **Отзываемо.** Удалите ключ в **Settings → Developer → API Keys**, и доступ Claude немедленно прекратится.
- **Черный список.** Вебхуки провайдеров, конечные точки администрирования OAuth-клиентов и маршрут `apiEmails`, доступный только операторам, нельзя вызвать через MCP.
- **Лимит размера ответа.** Один ответ инструмента ограничен 64 КБ, чтобы длинные списки не переполняли контекст Claude, — в таком случае Claude сузит запрос с помощью фильтров.
- **Журнал аудита.** Изменения проходят через тот же журнал аудита, что и действия в B1Admin; просмотреть их можно в **Settings → Audit Log**.

### Устранение неполадок

**Claude сообщает "Unauthorized" или 401:** bearer-токен отсутствует, имеет неверный формат или ключ был отозван. Если вы использовали расширение, откройте в Claude **Settings → Extensions → B1 (ChurchApps)** и вставьте ключ снова. В противном случае еще раз проверьте заголовок `Authorization: Bearer cak_…` (обратите внимание на пробел и слово `Bearer`).

**Вызов инструмента возвращает 403:** у API-ключа нет области для этой конечной точки. Добавьте область в **Settings → Developer → API Keys** (придется создать новый ключ — области нельзя изменить у существующего) и вставьте новый ключ в настройки расширения или в конфигурацию Claude.

**Claude не может найти конечную точку:** попросите его вызвать `list_endpoints` с фильтром, например *"используй list_endpoints с фильтром 'donations', чтобы найти правильный путь"*. Список маршрутов формируется из работающего API, поэтому все, к чему можно обратиться через `curl`, там есть.

**Локальная разработка:** замените `https://api.churchapps.org/mcp` на `http://localhost:8084/mcp` — та же аутентификация, те же инструменты.
