# Календарь группы

<div class="article-intro">

У каждой группы в B1 может быть собственный календарь событий. Руководители групп используют его, чтобы планировать встречи, мероприятия и регулярные события, а все участники группы могут просматривать предстоящие события и участвовать в обсуждениях. Календарь помогает группе оставаться организованной и держит всех в курсе предстоящего.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Нужна группа, созданная в B1 Admin, с хотя бы одним участником. См. [Создание групп](creating-groups.md) и [Участники группы](group-members.md).
- Чтобы добавлять или редактировать события календаря, вы должны быть назначены руководителем группы. Инструкции см. в разделе [Назначение руководителей группы](group-members.md#designating-group-leaders).

</div>

## Открытие календаря группы {#accessing-the-group-calendar}

Календарь группы доступен в приложении для участников B1.church:

1. В B1 Admin нажмите **dropdown menu** в правом верхнем углу экрана.
2. Выберите **Switch App**.
3. Выберите **B1.church**.
4. Откройте **Groups** (вкладка в нижней панели на телефоне или в верхней панели на компьютере).
5. Выберите вашу группу из списка.
6. В разделе **Next event** нажмите **All events**, чтобы открыть вид **Events** группы. Используйте там переключатель **Calendar**, чтобы перейти к виду по месяцам.

:::info
Календарь группы управляется через B1.church (приложение для участников), а не через B1 Admin. Руководители групп открывают его, переключая приложение с панели администратора.
:::

## Добавление события {#adding-an-event}

1. В календаре группы нажмите **Add Event**.
2. Введите **title** события.
3. Напишите краткое **description** того, что это за событие.
4. Задайте **start time** и **end time**.
5. Нажмите **Save**, чтобы добавить событие в календарь.

## Настройка регулярных событий {#setting-up-recurring-events}

Если ваша группа собирается по регулярному графику, вы можете настроить повторение событий автоматически:

1. При создании или редактировании события отметьте флажок **Recurring**.
2. Выберите, как должно повторяться событие:
   - **Interval** — количество дней между повторениями. Например, значение «7» повторяет событие каждые 7 дней.
   - **Frequency** — повторять по **day** (дням), **week** (неделям) или **month** (месяцам).
3. Сохраните событие. Теперь оно будет появляться в календаре в каждом запланированном повторении.

:::tip
Для группы, которая собирается каждую субботу, установите частоту «week» и выберите субботу. Событие будет автоматически появляться в календаре и дальше.
:::

## Массовое создание событий в B1 Admin {#bulk-creating-events-in-b1-admin}

На странице группы в B1 Admin также есть раздел **Calendar**, где сотрудники могут запланировать сразу целый сезон встреч:

1. Откройте группу в B1 Admin и в разделе **Calendar** нажмите **All events**.
2. Нажмите **+ Add Events**, чтобы открыть диалог **Add Recurring Events**.
3. Проверьте **Title** (по умолчанию это название группы) и при желании добавьте **Description**.
4. Выберите даты **First Meeting** и **Last Meeting**, время **Start** и **End**, а также частоту **Repeats** — **Weekly** (еженедельно) или **Every 2 Weeks** (раз в 2 недели), в день недели первой встречи. Для одной встречи укажите одну и ту же дату в обоих полях.
5. Выберите **Visibility** — **Public** или **Private**.
6. По умолчанию отмечено **Skip holidays**, поэтому даты встреч, которые приходятся на праздник, снимаются с отметки и подписываются названием праздника.
7. Просмотрите список дат встреч и снимите отметку с тех, которые нужно пропустить.
8. Оставьте **Allow RSVPs** отмеченным, если хотите, чтобы участники могли отвечать на эти события (см. ниже), и нажмите **Save**.

Над списком событий в B1 Admin есть кнопки **Upcoming** и **Past**. **Upcoming** показывает события, которые еще не закончились, а также регулярные серии, которые продолжаются, — ближайшие сначала. **Past** хранит все прошедшие события группы, новейшие сначала. В каждой строке показаны название события, начало, частота повторения, сколько дат пропущено, видимость и RSVP. Нажмите **Delete** в строке и подтвердите, чтобы удалить событие и все его повторения.

## RSVP на события {#event-rsvps}

На событиях группы можно собирать RSVP — ответы **Yes**, **No** или **Maybe** для каждого повторения события.

- **Allow RSVPs** включено по умолчанию для событий, созданных через диалог массового добавления; снимите отметку, чтобы отключить ответы для этих событий. События с отключенными RSVP отображаются как **Disabled** в списке событий группы.
- В списке событий группы в B1 Admin каждое событие показывает сводку ответов (например, «5 yes · 2 maybe · 1 no»). Нажмите на нее, чтобы открыть список **RSVP Responses**, в котором для каждого повторения видно, кто **Going** (придет), **Maybe** (возможно) или **Not Going** (не придет).

:::tip
RSVP дают руководителям подсчет присутствующих без формальности полной регистрации на событие. Для платной записи или событий с ограниченной вместимостью используйте [регистрацию на события](../calendars/creating-calendars.md#enabling-event-registration).
:::

## Просмотр календаря {#viewing-the-calendar}

Календарь группы предлагает несколько видов:

- **Month** — весь месяц на одном экране.
- **Week** — фокус на текущей неделе.
- **Day** — подробный вид одного дня.
- **Agenda** — список предстоящих событий в хронологическом порядке.

Переключайтесь между видами с помощью кнопок вверху календаря.

## Подробности события и обсуждения {#event-details-and-conversations}

Нажмите на любое событие, чтобы посмотреть его подробности. В виде подробностей события:

- **Участники и руководители** могут начинать обсуждения и оставлять комментарии о событии.
- **Руководители** могут редактировать сведения о событии, менять время или удалять событие.

:::warning
Удаление события удаляет его навсегда. Если нужно отменить одно повторение регулярного события, лучше отредактируйте его.
:::

## Подписка на календарь {#subscribing-to-the-calendar}

Вы можете синхронизировать календарь группы с личным календарем:

1. На странице календаря группы нажмите **Subscribe**.
2. Следуйте подсказкам, чтобы добавить календарь в Google Calendar, Apple Calendar, Outlook или любое другое приложение календаря, которое поддерживает подписки.

:::tip
Подписка держит ваше личное расписание в синхронизации с событиями группы, не требуя отдельно заходить в B1. Любые изменения, которые вносят руководители группы, автоматически появятся в вашем синхронизированном календаре.
:::
