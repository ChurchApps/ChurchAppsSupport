# Календарь группы

<div class="article-intro">

У каждой группы в B1 может быть собственный календарь событий. Лидеры группы используют его для планирования встреч, мероприятий и повторяющихся событий, а все участники группы могут просматривать предстоящие события и участвовать в обсуждениях о них. Календарь поддерживает порядок в вашей группе и гарантирует, что все в курсе предстоящих событий.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Вам нужна группа, созданная в B1 Admin, хотя бы с одним участником. См. [Создание групп](creating-groups.md) и [Участники группы](group-members.md).
- Чтобы добавлять или редактировать события календаря, вы должны быть назначены лидером группы. См. [Назначение лидеров группы](group-members.md) для инструкций.

</div>

## Доступ к календарю группы

Календарь группы доступен через приложение B1.church, предназначенное для участников:

1. В B1 Admin нажмите **выпадающее меню** в правом верхнем углу экрана.
2. Выберите **Переключить приложение**.
3. Выберите **B1.church**.
4. Нажмите **Группы** на левой боковой панели.
5. Выберите свою группу из списка.
6. Нажмите **Календарь** в левой части экрана.

:::info
Календарь группы управляется через B1.church (приложение для участников), а не через B1 Admin. Лидеры групп получают к нему доступ, переключая приложения с панели администратора.
:::

## Добавление события

1. В календаре группы нажмите **Добавить событие**.
2. Введите **название** для события.
3. Напишите краткое **описание** того, чему посвящено событие.
4. Установите **время начала** и **время окончания**.
5. Нажмите **Сохранить**, чтобы добавить событие в календарь.

## Настройка повторяющихся событий

Если ваша группа встречается по регулярному расписанию, вы можете настроить автоматическое повторение событий:

1. При создании или редактировании события установите флажок **Повторяющееся**.
2. Выберите, как должно повторяться событие:
   - **Интервал** -- Задайте количество дней между повторениями. Например, ввод «7» повторяет событие каждые 7 дней.
   - **Периодичность** -- Выберите повторение по **дням**, **неделям** или **месяцам**.
3. Сохраните событие. Теперь оно будет отображаться в календаре при каждом запланированном повторении.

:::tip
Для группы, которая встречается каждую субботу, установите периодичность «неделя» и выберите субботу. Событие будет автоматически появляться в календаре в дальнейшем.
:::

## Массовое создание событий в B1 Admin

На странице группы в B1 Admin также есть вкладка **Календарь**, где сотрудники могут запланировать целый сезон встреч одновременно:

1. Откройте группу в B1 Admin и выберите вкладку **Календарь**.
2. Нажмите **Добавить события**, чтобы открыть диалог **Добавить повторяющиеся события**.
3. Выберите расписание (еженедельно, каждые 2 недели, ежемесячно или один раз), даты **первой встречи** и **последней встречи**, а также при желании **Пропускать праздники**.
4. Просмотрите предварительный список дат встреч и снимите флажки с тех, что нужно пропустить.
5. Оставьте флажок **Разрешить подтверждение участия** установленным, если хотите, чтобы участники могли отвечать на эти события (см. ниже), затем сохраните.

## Подтверждение участия в событиях

События группы могут собирать подтверждения участия — **Да**, **Нет** или **Возможно** для каждого повторения события.

- **Разрешить подтверждение участия** включено по умолчанию для событий, созданных через диалог массового добавления; снимите флажок, чтобы отключить ответы для этих событий. События с отключенным подтверждением участия отображаются как **Отключено** на вкладке календаря.
- На вкладке календаря группы в B1 Admin каждое событие показывает сводку ответов (например, «5 да · 2 возможно · 1 нет»). Нажмите, чтобы открыть список **Ответы на подтверждение участия**, в котором перечислены ответившие «да», «возможно» и «нет» для этого повторения.

:::tip
Подтверждение участия дает лидерам представление о числе людей без формальностей полной регистрации на событие. Для платной записи или событий с ограниченной вместимостью используйте вместо этого [регистрацию на событие](../calendars/creating-calendars.md#enabling-event-registration).
:::

## Просмотр календаря

Календарь группы предлагает несколько вариантов отображения:

- **Месяц** -- Просмотр всего месяца целиком.
- **Неделя** -- Фокус на текущей неделе.
- **День** -- Подробный просмотр одного дня.
- **Повестка** -- Список предстоящих событий в хронологическом порядке.

Переключайтесь между видами с помощью кнопок в верхней части календаря.

## Сведения о событии и обсуждения

Нажмите на любое событие, чтобы просмотреть его сведения. В представлении сведений о событии:

- **Участники и лидеры** могут начинать обсуждения и оставлять комментарии о событии.
- **Лидеры** могут редактировать сведения о событии, изменять время или удалять событие.

:::warning
Удаление события удаляет его навсегда. Если вам нужно отменить одно повторение повторяющегося события, рассмотрите вариант редактирования вместо удаления.
:::

## Подписка на календарь

Вы можете синхронизировать календарь группы с вашим личным календарем:

1. На странице календаря группы нажмите **Подписаться**.
2. Следуйте инструкциям, чтобы добавить календарь в Google Calendar, Apple Calendar, Outlook или любое другое приложение календаря, поддерживающее подписки.

:::tip
Подписка поддерживает ваше личное расписание в синхронизации с событиями вашей группы без необходимости отдельно проверять B1. Любые изменения, сделанные лидерами группы, автоматически появятся в вашем синхронизированном календаре.
:::
