# Календарь группы

<div class="article-intro">

У каждой группы в B1 может быть собственный календарь мероприятий. Руководители групп используют его, чтобы планировать встречи, занятия и регулярные мероприятия, а все участники группы могут просматривать предстоящие мероприятия и участвовать в обсуждениях. Календарь помогает держать группу организованной и гарантирует, что все в курсе предстоящих событий.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Вам нужна группа, созданная в B1 Admin, с хотя бы одним участником. См. [Создание групп](creating-groups.md) и [Участники группы](group-members.md).
- Чтобы добавлять или редактировать мероприятия календаря, вы должны быть назначены руководителем группы. Инструкции см. в разделе [Назначение руководителей группы](group-members.md).

</div>

## Открытие календаря группы

Календарь группы доступен в приложении B1.church для участников:

1. В B1 Admin нажмите **выпадающее меню** в правом верхнем углу экрана.
2. Выберите **Переключить приложение**.
3. Выберите **B1.church**.
4. Откройте **Группы** (вкладка в нижней панели на телефоне или в верхней шапке на компьютере).
5. Выберите вашу группу из списка.
6. В разделе **Следующее мероприятие** нажмите **Все мероприятия**, чтобы открыть вид **Мероприятия** группы. Для вида по месяцам используйте переключатель **Календарь** там же.

:::info
Календарь группы управляется через B1.church (приложение для участников), а не через B1 Admin. Руководители групп получают к нему доступ, переключившись на приложение из панели администратора.
:::

## Добавление мероприятия

1. В календаре группы нажмите **Добавить мероприятие**.
2. Введите **название** мероприятия.
3. Напишите краткое **описание** того, о чём мероприятие.
4. Укажите **время начала** и **время окончания**.
5. Нажмите **Сохранить**, чтобы добавить мероприятие в календарь.

## Настройка регулярных мероприятий

Если ваша группа собирается по регулярному графику, вы можете настроить повторение мероприятий автоматически:

1. При создании или редактировании мероприятия отметьте флажок **Повторяющееся**.
2. Выберите, как мероприятие должно повторяться:
   - **Интервал** -- количество дней между повторениями. Например, если ввести «7», мероприятие будет повторяться каждые 7 дней.
   - **Частота** -- повторять по **дням**, **неделям** или **месяцам**.
3. Сохраните мероприятие. Теперь оно будет появляться в календаре в каждом запланированном повторении.

:::tip
Если группа собирается каждую субботу, установите частоту «неделя» и выберите субботу. Мероприятие будет автоматически появляться в календаре и дальше.
:::

## Массовое создание мероприятий в B1 Admin

На странице группы в B1 Admin также есть раздел **Календарь**, в котором сотрудники могут запланировать сразу целый сезон встреч:

1. Откройте группу в B1 Admin и в разделе **Календарь** нажмите **Все мероприятия**.
2. Нажмите **+ Добавить мероприятия**, чтобы открыть диалоговое окно **Добавить повторяющиеся мероприятия**.
3. Выберите расписание (каждую неделю, каждые 2 недели, каждый месяц или однократно), даты **Первой встречи** и **Последней встречи**, а при желании отметьте **Пропускать праздники**.
4. Просмотрите предварительный список дат встреч и снимите отметку с тех, которые нужно пропустить.
5. Оставьте **Разрешить ответы на приглашения** отмеченным, если хотите, чтобы участники могли отвечать на эти мероприятия (см. ниже), и сохраните.

Над списком мероприятий в B1 Admin есть кнопки **Предстоящие** и **Прошедшие**. **Предстоящие** показывает мероприятия, которые ещё не закончились, а также серии повторений, которые ещё продолжаются, начиная с ближайших. **Прошедшие** содержит все более ранние мероприятия группы, начиная с самых новых.

## Ответы на приглашения {#event-rsvps}

На мероприятия группы можно собирать ответы на приглашения: **Да**, **Нет** или **Возможно** для каждого повторения мероприятия.

- **Разрешить ответы на приглашения** по умолчанию включено для мероприятий, созданных через диалоговое окно массового добавления; снимите отметку, чтобы отключить ответы для этих мероприятий. У мероприятий с отключёнными ответами в списке мероприятий группы отображается статус **Отключено**.
- В списке мероприятий группы в B1 Admin каждое мероприятие показывает сводку ответов (например, «5 да · 2 возможно · 1 нет»). Нажмите на неё, чтобы открыть список **Ответы на приглашения**, в котором указано, кто ответил «да», «возможно» и «нет» на это повторение.

:::tip
Ответы на приглашения дают руководителям представление о количестве людей без формальности полной регистрации на мероприятие. Для платной записи или мероприятий с ограничением мест используйте [регистрацию на мероприятие](../calendars/creating-calendars.md#enabling-event-registration).
:::

## Просмотр календаря

Календарь группы предлагает несколько вариантов просмотра:

- **Месяц** -- полный месяц на одном экране.
- **Неделя** -- текущая неделя.
- **День** -- подробный просмотр одного дня.
- **Повестка** -- список предстоящих мероприятий в хронологическом порядке.

Переключайтесь между видами с помощью кнопок вверху календаря.

## Подробности мероприятия и обсуждения

Нажмите на любое мероприятие, чтобы увидеть его подробности. В окне сведений о мероприятии:

- **Участники и руководители** могут начинать обсуждения и оставлять комментарии к мероприятию.
- **Руководители** могут редактировать сведения о мероприятии, менять время или удалять мероприятие.

:::warning
Удаление мероприятия необратимо. Если нужно отменить одно повторение регулярного мероприятия, лучше отредактировать его.
:::

## Подписка на календарь

Вы можете синхронизировать календарь группы с личным календарём:

1. На странице календаря группы нажмите **Подписаться**.
2. Следуйте инструкциям, чтобы добавить календарь в Google Календарь, Календарь Apple, Outlook или любое другое приложение календаря, которое поддерживает подписки.

:::tip
Подписка позволяет держать личное расписание в соответствии с мероприятиями вашей группы без необходимости отдельно проверять B1. Все изменения, которые вносят руководители группы, автоматически появятся в вашем синхронизированном календаре.
:::
