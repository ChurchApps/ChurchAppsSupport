# Календарь группы

<div class="article-intro">

Каждая группа в B1 может иметь собственный календарь событий. Руководители группы используют его, чтобы планировать встречи, мероприятия и регулярные события, а все участники группы могут просматривать предстоящие события и обсуждать их. Календарь помогает держать группу организованной и всех в курсе предстоящих событий.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужна группа, созданная в B1 Admin, хотя бы с одним участником. См. [Создание групп](creating-groups.md) и [Участники группы](group-members.md).
- Чтобы добавлять или редактировать события календаря, вы должны быть назначены руководителем группы. Инструкции см. в разделе [Назначение руководителей группы](group-members.md).

</div>

## Открытие календаря группы

Календарь группы доступен в приложении для участников B1.church:

1. В B1 Admin нажмите **выпадающее меню** в правом верхнем углу экрана.
2. Выберите **Switch App**.
3. Выберите **B1.church**.
4. Откройте **Groups** (вкладка в нижней панели на телефоне или в верхней шапке на компьютере).
5. Выберите свою группу из списка.
6. В разделе **Next event** нажмите **All events**, чтобы открыть представление **Events** группы. Для просмотра по месяцам используйте переключатель **Calendar**.

:::info
Календарь группы управляется через B1.church (приложение для участников), а не через B1 Admin. Руководители группы открывают его, переключая приложение из панели администратора.
:::

## Добавление события

1. В календаре группы нажмите **Add Event**.
2. Введите **title** (название) события.
3. Напишите краткое **description** (описание) того, что будет происходить.
4. Укажите **start time** (время начала) и **end time** (время окончания).
5. Нажмите **Save**, чтобы добавить событие в календарь.

## Настройка повторяющихся событий

Если ваша группа собирается по регулярному расписанию, можно настроить автоматическое повторение событий:

1. При создании или редактировании события отметьте флажок **Recurring**.
2. Выберите, как событие должно повторяться:
   - **Interval** — количество дней между повторами. Например, если ввести «7», событие будет повторяться каждые 7 дней.
   - **Frequency** — повторять по **day** (дням), **week** (неделям) или **month** (месяцам).
3. Сохраните событие. Теперь оно будет появляться в календаре в каждом запланированном повторе.

:::tip
Если группа собирается каждую субботу, установите частоту «week» и выберите субботу. Событие будет автоматически появляться в календаре и дальше.
:::

## Массовое создание событий в B1 Admin

На странице группы в B1 Admin есть раздел **Calendar**, в котором сотрудники могут сразу запланировать весь сезон встреч:

1. Откройте группу в B1 Admin и в разделе **Calendar** нажмите **All events**.
2. Нажмите **+ Add Events**, чтобы открыть диалог **Add Recurring Events**.
3. Выберите расписание (еженедельно, раз в 2 недели, ежемесячно или однократно), даты **First Meeting** и **Last Meeting**, и при необходимости отметьте **Skip holidays**.
4. Просмотрите предварительный список дат встреч и снимите отметку с тех, которые нужно пропустить.
5. Оставьте отмеченным **Allow RSVPs**, если хотите, чтобы участники могли отвечать на эти события (см. ниже), и сохраните.

## RSVP на события

События группы могут собирать RSVP — ответ **Yes**, **No** или **Maybe** на каждое повторение события.

- **Allow RSVPs** включено по умолчанию для событий, созданных через диалог массового добавления; снимите отметку, чтобы отключить ответы для этих событий. События с отключенными RSVP показываются со статусом **Disabled** в списке событий группы.
- В списке событий группы в B1 Admin для каждого события показана сводка ответов (например, «5 yes · 2 maybe · 1 no»). Нажмите на нее, чтобы открыть список **RSVP Responses**, в котором указано, кто ответил yes, maybe и no на это повторение события.

:::tip
RSVP дают руководителям понимание количества участников без формальности полной регистрации на мероприятие. Для платных записей или мероприятий с ограниченным количеством мест используйте [регистрацию на мероприятие](../calendars/creating-calendars.md#enabling-event-registration).
:::

## Просмотр календаря

Календарь группы предлагает несколько вариантов просмотра:

- **Month** — весь месяц целиком.
- **Week** — текущая неделя.
- **Day** — один день подробно.
- **Agenda** — список предстоящих событий в хронологическом порядке.

Переключайтесь между представлениями с помощью кнопок в верхней части календаря.

## Подробности события и обсуждения

Нажмите на любое событие, чтобы посмотреть его подробности. В просмотре события:

- **Участники и руководители** могут начинать обсуждения и оставлять комментарии к событию.
- **Руководители** могут редактировать детали события, менять время или удалять событие.

:::warning
Удаление события безвозвратно. Если нужно отменить только одно повторение регулярного события, лучше отредактировать его.
:::

## Подписка на календарь

Вы можете синхронизировать календарь группы с личным календарем:

1. На странице календаря группы нажмите **Subscribe**.
2. Следуйте инструкциям, чтобы добавить календарь в Google Calendar, Apple Calendar, Outlook или любое другое приложение календаря, поддерживающее подписки.

:::tip
Подписка позволяет держать личное расписание в соответствии с событиями группы без необходимости отдельно проверять B1. Любые изменения, внесенные руководителями группы, автоматически появятся в синхронизированном календаре.
:::
