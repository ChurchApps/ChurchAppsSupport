# Группы

<div class="article-intro">

Раздел **Группы** позволяет организовать членов вашей церкви по служениям, малым группам, библейским исследованиям, комитетам и многому другому. Группы — основа жизни общины в вашей церкви, и этот раздел предоставляет инструменты для создания, управления и общения с каждой группой в одном месте. Обратите внимание, что **Команды** отличаются от Групп — Команды используются для координирования служения и расписания волонтёров.

</div>

## Обзор

Группы организованы по **категориям**. Категория — это верхнеуровневый ярлык, например "Малые группы", "Служения" или "Комитеты". Каждая категория может содержать несколько групп, что облегчает работу со связанными группами.

При открытии страницы Групп вы увидите сводку вверху, показывающую:

- **Всего групп** — количество групп по всем категориям
- **Категории** — количество созданных вами категорий групп
- **Всего членов** — общее количество членов по всем группам

Ниже сводки ваши группы перечислены по категориям с указанием количества членов каждой группы.

## Что вы можете делать

Вот что вы можете выполнить в разделе Группы:

1. **Создание и организация групп** — добавляйте новые группы в категории в соответствии с структурой вашей церкви. См. [Создание групп](./creating-groups.md).

2. **Управление членами группы** — добавляйте и удаляйте членов, назначайте лидеров и общайтесь с вашими группами. См. [Члены группы](./group-members.md).

3. **Планирование событий** — каждая группа может иметь собственный календарь встреч, событий и повторяющихся мероприятий. См. [Календарь группы](./group-calendar.md).

4. **Управление запросами присоединения** — если группа использует политику присоединения **Запрос**, проверяйте и одобряйте или отклоняйте входящие запросы на членство от людей, которые хотят присоединиться. См. [Запросы присоединения к группе](./group-join-requests.md).

5. **Экспорт данных группы** — скачивайте списки членов любой группы в формате CSV для использования в электронных таблицах или рассылках. Инструкции по экспорту см. в [Членах группы](./group-members.md).

## Начало работы

Чтобы получить доступ к Группам, откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (поисковую строку в верхнем левом углу B1 Admin), разверните **People** и щелкните **Groups**. Вы увидите все существующие группы, организованные по категориям.

:::tip
Если вы только начинаете работу, начните с создания нескольких категорий, которые соответствуют структуре вашей церкви (например, "Служения", "Малые группы", "Комитеты"). Затем добавляйте отдельные группы в каждой категории. Пошаговое руководство см. в [Создание групп](./creating-groups.md).
:::

:::info
Члены группы должны существовать в вашем справочнике [People](../people/adding-people.md), прежде чем они смогут быть добавлены в группу. Если вы настраиваете B1 впервые, [импортируйте данные членов](../people/importing-data.md) перед созданием групп.
:::
