# Группы

<div class="article-intro">

Раздел **Groups** позволяет организовать участников вашей общины в служения, малые группы, библейские изучения, комитеты и многое другое. Группы — основа общинной жизни вашей церкви, и этот раздел дает инструменты для создания, управления и общения с каждой группой в одном месте. Обратите внимание, что **Teams** отделены от Groups — Teams используются для служения и планирования волонтеров.

</div>

## Обзор {#overview}

Группы организованы по **категориям**. Категория — это верхний уровень, например «Small Groups», «Ministries» или «Committees». В каждой категории может быть несколько групп, что упрощает хранение связанных групп вместе.

Когда вы открываете страницу Groups, вы видите поле **Search groups...**, ряд кнопок категорий и таблицу ваших групп. Каждая группа показывает категорию и метки под своим названием, а также количество участников. Введите текст в поле поиска, чтобы найти группу по названию или категории, нажмите **All** или название категории, чтобы отфильтровать список (дополнительные категории — под **More categories**), и нажмите заголовок столбца **Name** или **People**, чтобы отсортировать. Нажмите **Clear filters**, чтобы снова показать все группы.

В заголовке страницы есть кнопки для остальных возможностей раздела:

- **Group Health** — сравнение состава и посещаемости всех групп. См. [Состояние групп](./groups-health.md).
- **pending requests** (например, «2 pending requests») — появляется, когда люди ждут вступления в группу. См. [Запросы на вступление в группу](./group-join-requests.md#for-administrators).
- **Export** — скачать список групп в виде CSV-файла.
- **Add Group** — создать группу. См. [Создание групп](./creating-groups.md).

## Что вы можете делать {#what-you-can-do}

В разделе Groups вы можете:

1. **Создавать и организовывать группы** — добавляйте новые группы внутри категорий, чтобы отразить структуру вашей церкви. См. [Создание групп](./creating-groups.md).

2. **Управлять участниками групп** — добавлять и удалять участников, назначать руководителей и общаться с группами. См. [Участники группы](./group-members.md).

3. **Планировать события** — у каждой группы может быть свой календарь встреч, мероприятий и регулярных занятий. См. [Календарь группы](./group-calendar.md).

4. **Управлять запросами на вступление** — когда группа использует порядок вступления **Request**, рассматривайте входящие запросы от людей, которые хотят вступить, и одобряйте или отклоняйте их. См. [Запросы на вступление в группу](./group-join-requests.md).

5. **Экспортировать данные групп** — скачивайте списки участников любой группы в виде CSV-файла для таблиц или рассылок. Инструкции по экспорту см. в разделе [Участники группы](./group-members.md#exporting-group-data).

6. **Проверять состояние групп** — смотрите рост членства, текучесть и посещаемость каждой группы в одной таблице. См. [Состояние групп](./groups-health.md).

## С чего начать {#getting-started}

Чтобы открыть Groups, откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу B1 Admin), раскройте **People** и нажмите **Groups**. Вы увидите все свои существующие группы, которые можно фильтровать по категории.

:::tip
Если вы только начинаете, создайте несколько категорий, которые соответствуют структуре вашей церкви (например, «Ministries», «Small Groups», «Committees»). Затем добавьте отдельные группы внутри каждой категории. Пошаговое руководство см. в разделе [Создание групп](./creating-groups.md).
:::

:::info
Участники групп сначала должны существовать в вашем каталоге [People](../people/adding-people.md), прежде чем их можно будет добавить в группу. Если вы впервые настраиваете B1, [импортируйте данные участников](../people/importing-data.md), прежде чем создавать группы.
:::
