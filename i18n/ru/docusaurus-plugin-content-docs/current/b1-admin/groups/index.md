# Группы

<div class="article-intro">

Раздел **Groups** позволяет вам организовать членов вашей церкви в служения, небольшие группы, библейские исследования, комитеты и многое другое. Группы — это основа общественной жизни в вашей церкви, и этот раздел дает вам инструменты для создания, управления и взаимодействия с каждой группой в одном месте. Обратите внимание, что **Teams** отличаются от Groups — Teams используются для служения и планирования волонтеров.

</div>

## Обзор

Группы организованы по **category**. Категория — это метка верхнего уровня, такая как "Small Groups", "Ministries" или "Committees". Каждая категория может содержать несколько групп, что упрощает сохранение связанных групп вместе.

Когда вы открываете страницу Groups, вы увидите сводку в верхней части, показывающей:

- **Total Groups** — количество групп во всех категориях
- **Categories** — количество созданных категорий групп
- **Total Members** — общее количество членов во всех группах

Ниже сводки ваши группы перечислены по категориям с количеством членов, показанным для каждой группы.

## Что вы можете делать

Вот что вы можете сделать в разделе Groups:

1. **Create and organize groups** — Добавляйте новые группы в категориях для отражения структуры вашей церкви. См. [Creating Groups](./creating-groups.md).

2. **Manage group members** — Добавляйте и удаляйте членов, назначайте лидеров и взаимодействуйте с вашими группами. См. [Group Members](./group-members.md).

3. **Schedule events** — Каждая группа может иметь свой календарь для встреч, мероприятий и повторяющихся действий. См. [Group Calendar](./group-calendar.md).

4. **Manage join requests** — Когда группа использует политику присоединения **Request**, проверяйте и одобряйте или отклоняйте входящие запросы на членство от людей, которые хотят присоединиться. См. [Group Join Requests](./group-join-requests.md).

5. **Export group data** — Загружайте списки членов для любой группы как файл CSV для использования в электронных таблицах или рассылках. См. [Group Members](./group-members.md) для инструкций по экспорту.

## Начало работы

Чтобы получить доступ к Groups, откройте **меню раздела** в верхнем левом углу вашей приборной панели B1 Admin и выберите **People**, затем нажмите вкладку **Groups** в строке навигации. Вы увидите все ваши существующие группы, организованные по категориям.

:::tip
Если вы только начинаете, начните с создания нескольких категорий, которые соответствуют структуре вашей церкви (например, "Ministries", "Small Groups", "Committees"). Затем добавляйте отдельные группы в каждую категорию. См. [Creating Groups](./creating-groups.md) для пошагового руководства.
:::

:::info
Члены группы должны сначала существовать в вашем каталоге [People](../people/adding-people.md), прежде чем их можно добавить в группу. Если вы устанавливаете B1 впервые, [импортируйте ваши данные членов](../people/importing-data.md) перед созданием групп.
:::
