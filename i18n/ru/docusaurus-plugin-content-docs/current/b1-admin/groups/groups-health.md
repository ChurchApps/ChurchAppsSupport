# Здоровье групп

<div class="article-intro">

Панель инструментов Groups Health дает вам общий вид того, как работают все ваши группы — тренды членства, средние показатели посещаемости и рост или убыль за последние 90 дней -- всё в одной сортируемой таблице.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужна хотя бы несколько групп с членами для просмотра значимых данных. См. [Creating Groups](creating-groups).
- Данные посещаемости получаются из записанных сессий. Смотрите раздел [Attendance](../attendance/).

</div>

## Открытие Groups Health

В B1 Admin откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (поле поиска в верхнем левом углу), разверните **People**, нажмите **Groups** и затем нажмите кнопку **Group Health** в заголовке страницы. Панель инструментов загружает таблицу с одной строкой на группу.

## Столбцы

| Столбец | Что он показывает |
|--------|--------------|
| **Name** | Имя группы, связанное со страницей деталей группы |
| **Category** | Категория группы |
| **Members** | Текущий активный счет членов |
| **Joined (90d)** | Члены, которые присоединились за последние 90 дней |
| **Left (90d)** | Члены, которые ушли за последние 90 дней |
| **Churn (90d)** | Чистая ставка текучести как процент за 90 дней |
| **Avg Attendance** | Среднее количество людей на сессию посещаемости |

Нажмите на любой заголовок столбца для сортировки таблицы по этому столбцу. Нажмите снова для обратного направления сортировки.

## Использование данных здоровья

- **Высокая текучесть + низкие присоединения** — группа, которая сжимается и не замещает потерянные члены. Стоит обсудить с лидером группы.
- **Высокие присоединения + низкая посещаемость** — люди регистрируются, но не приходят. Рассмотрите контакт для вовлечения.
- **Высокое среднее посещение** — здоровая, активная группа. Потенциальная модель для других групп.

:::tip
Нажатие на имя группы ведет вас прямо на страницу деталей группы, где вы можете просмотреть отдельных членов, записи посещаемости и события календаря.
:::
