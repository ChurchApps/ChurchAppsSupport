# Здоровье групп

<div class="article-intro">

Панель инструментов "Здоровье групп" дает вам полный обзор того, как работают все ваши группы — тенденции членства, средние показатели посещаемости и рост или отток за последние 90 дней — все в одной сортируемой таблице.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужно несколько групп с членами, чтобы увидеть значимые данные. См. [Создание групп](creating-groups).
- Данные посещаемости извлекаются из записанных сессий. См. раздел [Посещаемость](../attendance/).

</div>

## Открытие "Здоровья групп"

В B1 Admin откройте **меню раздела** в верхнем левом углу и выберите **Люди**, затем щелкните **Группы** в панели навигации и нажмите кнопку **Здоровье группы** в заголовке страницы. Панель инструментов загружает таблицу с одной строкой для каждой группы.

## Столбцы

| Столбец | Что он показывает |
|--------|--------------|
| **Название** | Название группы, связанное со страницей деталей группы |
| **Категория** | Категория группы |
| **Члены** | Текущее количество активных членов |
| **Присоединилось (90d)** | Члены, которые присоединились за последние 90 дней |
| **Ушли (90d)** | Члены, которые ушли за последние 90 дней |
| **Отток (90d)** | Чистая скорость отвала в процентах за 90 дней |
| **Средн. посещаемость** | Среднее количество людей на сессию посещаемости |

Нажмите на заголовок любого столбца, чтобы отсортировать таблицу по этому столбцу. Нажмите еще раз, чтобы обратить порядок сортировки.

## Использование данных о здоровье

- **Высокий отток + низкие присоединения** — группа, которая сокращается и не пополняет потерянных членов. Стоит беседы с лидером группы.
- **Высокие присоединения + низкая посещаемость** — люди регистрируются, но не приходят. Рассмотрите возможность мероприятий по вовлечению.
- **Высокая средняя посещаемость** — здоровая, активная группа. Возможный образец для других групп.

:::tip
Нажатие на название группы переводит вас прямо на страницу деталей группы, где вы можете просмотреть отдельных членов, записи посещаемости и события календаря.
:::
