# Здоровье групп

<div class="article-intro">

Приборная панель Groups Health дает вам общее представление о том, как работают все ваши группы — тенденции членства, средние показатели посещаемости и рост или отток за последние 90 дней — все в одной таблице с возможностью сортировки.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужны по крайней мере несколько групп с членами, чтобы увидеть значимые данные. См. [Creating Groups](creating-groups).
- Данные о посещаемости извлекаются из записанных сеансов. См. раздел [Attendance](../attendance/).

</div>

## Открытие Groups Health

В B1 Admin откройте **меню раздела** в верхнем левом углу и выберите **People**, затем нажмите вкладку **Groups** в строке навигации и выберите **Health**. Приборная панель загружает таблицу с одной строкой на группу.

## Столбцы

| Столбец | Что он показывает |
|--------|--------------|
| **Name** | Имя группы, связанное со страницей детализации группы |
| **Category** | Категория группы |
| **Members** | Текущее количество активных членов |
| **Joined (90d)** | Члены, присоединившиеся за последние 90 дней |
| **Left (90d)** | Члены, ушедшие за последние 90 дней |
| **Churn (90d)** | Процент чистого оттока за 90 дней |
| **Avg Attendance** | Среднее количество участников за сеанс посещаемости |

Нажмите на любой заголовок столбца для сортировки таблицы по этому столбцу. Нажмите снова, чтобы изменить направление сортировки.

## Использование данных Health

- **High churn + low joins** — группа, которая сокращается и не замещает потерянных членов. Стоит обсудить с лидером группы.
- **High joins + low attendance** — люди подписываются, но не приходят. Рассмотрите последующее вовлечение.
- **High average attendance** — здоровая, активная группа. Потенциальная модель для других групп.

:::tip
Щелчок по имени группы выполняет переход непосредственно на страницу деталей группы, где вы можете просмотреть отдельных членов, записи посещаемости и события в календаре.
:::
