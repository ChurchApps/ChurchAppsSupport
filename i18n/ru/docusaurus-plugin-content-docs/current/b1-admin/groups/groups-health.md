# Состояние групп

<div class="article-intro">

Панель Groups Health дает общий обзор того, как идут дела во всех ваших группах: тенденции членства, средние показатели посещаемости, рост или отток за последние 90 дней — и все это в одной таблице с сортировкой.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Нужно хотя бы несколько групп с участниками, чтобы увидеть содержательные данные. См. [Создание групп](./creating-groups.md).
- Данные о посещаемости берутся из записанных занятий. См. раздел [Посещаемость](../attendance/index.md).

</div>

## Открытие состояния групп {#opening-groups-health}

В B1 Admin откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в верхнем левом углу), раскройте **People**, нажмите **Groups**, а затем нажмите кнопку **Group Health** в заголовке страницы. Панель загрузит таблицу, в которой по одной строке на каждую группу.

## Столбцы {#columns}

| Столбец | Что показывает |
|--------|--------------|
| **Name** | Название группы, ведущее на страницу сведений о группе |
| **Category** | Категория группы |
| **Members** | Текущее число активных участников |
| **Joined (90d)** | Участники, вступившие за последние 90 дней |
| **Left (90d)** | Участники, выбывшие за последние 90 дней |
| **Churn (90d)** | Чистая текучесть в процентах за 90 дней |
| **Avg Attendance** | Среднее число присутствующих на одно занятие, или «-», если посещаемость не записывалась |
| **Avg Age** | Средний возраст участников, у которых в базе есть дата рождения |
| **Female** / **Male** | Сколько участников — женщины и сколько — мужчины |

Таблица изначально отсортирована по названию. Нажмите на заголовок любого столбца, чтобы отсортировать таблицу по этому столбцу. Повторное нажатие меняет направление сортировки. Нажмите **Groups** вверху страницы, чтобы вернуться к списку групп.

## Состояние одной группы {#one-groups-health}

На собственной странице каждой группы есть раздел **Health** с краткой сводкой (участники, вступившие и выбывшие за последние 90 дней). Нажмите **See health**, чтобы открыть вид состояния группы: показатели **Members**, **Joined (90d)**, **Left (90d)** и **Churn (90d)**, диаграмму **Membership Changes (12 months)**, диаграмму **Attendance Trend** для групп, которые ведут учет посещаемости, а также диаграммы **Age** и **Gender** участников.

## Использование данных о состоянии {#using-health-data}

- **Высокая текучесть + мало вступлений** — группа сокращается и не восполняет выбывших. Стоит поговорить с руководителем группы.
- **Много вступлений + низкая посещаемость** — люди записываются, но не приходят. Стоит подумать о последующей работе с вовлеченностью.
- **Высокая средняя посещаемость** — здоровая, активная группа. Потенциальный образец для других групп.

:::tip
Нажатие на название группы сразу открывает страницу сведений о группе, где можно просмотреть отдельных участников, записи посещаемости и события календаря.
:::
