# Здоровье групп

<div class="article-intro">

Панель управления Groups Health дает вам обзор того, как работают все ваши группы -- тренды членства, средние посещаемости и рост или отток за последние 90 дней -- все в одной сортируемой таблице.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Вам нужна по крайней мере пара групп с членами, чтобы увидеть значимые данные. См. [Creating Groups](creating-groups).
- Данные посещаемости извлекаются из записанных сеансов. См. раздел [Attendance](../attendance/).

</div>

## Открытие Groups Health

В B1 Admin откройте **меню раздела** в левом верхнем углу и выберите **People**, затем нажмите вкладку **Groups** в строке навигации и выберите **Health**. Панель управления загружает таблицу с одной строкой для каждой группы.

## Столбцы

| Столбец | Что он показывает |
|--------|--------------|
| **Name** | Название группы, связанное со страницей деталей группы |
| **Category** | Категория группы |
| **Members** | Текущее количество активных членов |
| **Joined (90d)** | Члены, которые присоединились в течение последних 90 дней |
| **Left (90d)** | Члены, которые ушли в течение последних 90 дней |
| **Churn (90d)** | Чистая ставка оттока в процентах за 90 дней |
| **Avg Attendance** | Среднее количество посещаемости на сеанс посещаемости |

Нажмите на заголовок любого столбца, чтобы отсортировать таблицу по этому столбцу. Нажмите еще раз, чтобы изменить направление сортировки.

## Использование данных здоровья

- **High churn + low joins** -- группа, которая сокращается и не заменяет потерянных членов. Стоит разговора с лидером группы.
- **High joins + low attendance** -- люди регистрируются, но не появляются. Рассмотрите последующее взаимодействие.
- **High average attendance** -- здоровая, активная группа. Потенциальная модель для других групп.

:::tip
Нажатие на название группы берет вас прямо на страницу деталей группы, где вы можете просмотреть отдельных членов, записи посещаемости и события календаря.
:::
