# Создание групп

<div class="article-intro">

Создать группу в B1 Admin несложно. Вы зададите категорию, назовёте группу и затем настроите её параметры. Группы помогают организовать вашу церковь в осмысленные единицы, такие как малые группы, комитеты и классы.

</div>

<h4>Прежде чем начать</h4>

- У вас должна быть активная учётная запись B1 Admin с правом управлять группами. Если вы не уверены в своём уровне доступа, см. [Роли и права доступа](../people/roles-permissions.md).
- Определите структуру категорий для ваших групп (например, «Малые группы», «Служения», «Комитеты»). Категории помогают держать связанные группы вместе.

## Добавление новой группы

1. Откройте [меню быстрого перехода](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу B1 Admin), разверните пункт **Люди** и нажмите **Группы**.
2. Нажмите **Добавить группу** в заголовке страницы. Под списком откроется форма **Новая группа**. Введите **Название категории**. Категории помогают объединять связанные группы (например, «Малые группы», «Служения» или «Комитеты»). Если категория уже существует, её можно выбрать из списка.
3. Введите **Название** группы.
4. Нажмите **Добавить**. Новая группа появится в списке, а её категория будет показана под названием.

## Настройка параметров группы

После создания группы вы можете добавить дополнительные сведения:

1. Нажмите на **название группы** в списке, чтобы открыть её.
2. Нажмите кнопку **Изменить** слева на странице группы, под сведениями о группе.
3. Настройте следующие параметры:
   - **Описание** -- краткое описание того, чем занимается группа. Оно видно участникам.
   - **Время встреч** -- когда группа обычно собирается (например, «по средам в 19:00»).
   - **Политика присоединения** -- выберите, кто может вступить в группу:
     - **Открытая** -- любой может присоединиться сразу, без одобрения
     - **По запросу** -- люди должны отправить запрос на вступление, который требует одобрения (см. [Запросы на вступление в группы](./group-join-requests.md))
     - **Закрытая** -- участников добавляют вручную руководители или администраторы
   - **Метки** -- назначьте группе одну или несколько описательных меток (например, «Очно», «Онлайн», «Приглашаем новых участников»). Метки -- это свободные теги, которые вы определяете; отметьте все подходящие. Метки можно использовать для фильтрации групп в элементе сайта «Обзор групп», а элемент сайта «Список групп» показывает группы с одной меткой.
   - **Конфиденциальная группа** -- скрывает группу и её состав от публичных страниц, поиска групп и тех, кто не является участником. Используйте это для чувствительных групп, например служений восстановления или консультирования; видеть такую группу могут только её участники и штатные сотрудники церкви.
   - **Обсуждения** -- включает или выключает ленту чата группы, в которой может писать любой участник. По умолчанию включено.
   - **Объявления** -- включает вторую ленту чата только для руководителей: участники могут читать и реагировать, но писать могут только руководители. По умолчанию включено.
   - **Учёт посещаемости** -- включите, если хотите вести [учёт посещаемости](../attendance/tracking-attendance.md) для этой группы.
   - **Время служений** -- при необходимости свяжите группу с определёнными временами богослужений церкви. Подробности о временах служений см. в разделе [Настройка посещаемости](../attendance/setup.md).
4. Нажмите **Сохранить**, чтобы применить изменения.

:::tip
Понятное описание и время встреч помогают участникам понять, чего ожидать, когда они присоединяются к группе.
:::

:::info
Если выключить одновременно **Обсуждения** и **Объявления**, вкладка «Сообщения» полностью исчезнет из группы в портале участника. Если выключить только одну из них, её вкладка скроется, а участники перейдут в ту ленту, которая ещё включена. Существующие сообщения сохраняются в любом случае -- переключатели управляют только публикацией новых сообщений.
:::

## Дублирование группы

Начинаете новый сезон регулярного занятия или служения? Вместо того чтобы заново вводить все параметры, продублируйте существующую группу:

1. Откройте группу и нажмите **Дублировать** (под кнопкой **Изменить** слева на странице группы).
2. Подтвердите дублирование.

В копию переносятся настройки оригинала: категория, описание, время/место встреч, политика присоединения, метки и кампус, но **не** участники. Новой группе присваивается название оригинала с добавлением « (Копия)»; переименуйте её в настройках группы.

## Архивирование группы

Если группа больше не активна, но вы хотите сохранить её историю, а не удалять её:

1. Откройте группу и нажмите **Изменить**, чтобы отредактировать её параметры.
2. Нажмите **Архивировать** и подтвердите действие.

Архивные группы исчезают из основного списка групп. Чтобы найти такую группу снова, нажмите кнопку **Показать архивные** рядом с кнопками категорий вверху страницы «Группы», затем нажмите **Восстановить** рядом с группой, чтобы вернуть её.

:::info
Архивирование группы не удаляет её участников, историю посещаемости или мероприятия календаря -- оно лишь скрывает группу из списка по умолчанию, пока вы её не восстановите.
:::

## Следующие шаги

После создания и настройки группы вы можете:

- **Добавить участников** -- найдите людей и добавьте их в группу. Используйте значок звезды (**Сделать руководителем**), чтобы назначить руководителей группы. См. [Участники группы](./group-members.md).
- **Настроить календарь** -- создайте мероприятия и регулярные встречи для группы. См. [Календарь группы](./group-calendar.md).
- **Общаться** -- отправляйте сообщения всем участникам группы прямо со страницы группы.
- **Экспортировать данные** -- нажмите **Экспорт** над списком участников группы, чтобы скачать его.

:::info
Каждая группа относится к категории, а на главной странице групп можно фильтровать список по категориям. Категории можно переупорядочивать или переименовывать по мере роста вашей церкви.
:::
