# Создание групп

<div class="article-intro">

Создать группу в B1 Admin несложно. Вы создадите категорию, назовёте группу и затем настроите её параметры. Группы помогают организовать вашу церковь в осмысленные объединения: малые группы, комитеты и классы.

</div>

<h4>Перед началом</h4>

- Нужна активная учётная запись B1 Admin с правом управлять группами. Если вы не уверены в своём уровне доступа, см. [Роли и права](../people/roles-permissions.md).
- Продумайте структуру категорий для ваших групп (например, «Small Groups», «Ministries», «Committees»). Категории помогают держать связанные группы организованными.

## Добавление новой группы

1. Откройте [меню перехода](../introduction.md#getting-around-with-the-jump-menu) (строку поиска в левом верхнем углу B1 Admin), разверните **People** и нажмите **Groups**.
2. Нажмите **Add Group** в заголовке страницы. Под списком откроется форма **New Group**. Введите **Category Name**. Категории помогают объединять связанные группы (например, «Small Groups», «Ministries» или «Committees»). Если категория уже существует, её можно выбрать из списка.
3. Введите **Name** группы.
4. Нажмите **Add**. Новая группа появится в списке, а её категория будет показана под названием.

## Настройка параметров группы

Когда группа создана, вы можете добавить дополнительные сведения:

1. Нажмите на **название группы** в списке, чтобы открыть её.
2. Нажмите кнопку **Edit** слева на странице группы, под её сведениями.
3. Настройте следующие параметры:
   - **Description** -- краткое описание того, чем занимается группа. Его видят участники.
   - **Meeting Times** -- когда группа обычно собирается (например, «Wednesdays at 7 PM»).
   - **Join Policy** -- выберите, кто может вступить в группу:
     - **Open** -- любой может вступить сразу, без одобрения
     - **Request** -- люди должны подать заявку на вступление, которую нужно одобрить (см. [Заявки на вступление в группу](./group-join-requests.md))
     - **Closed** -- участников добавляют вручную руководители или администраторы
   - **Labels** -- назначьте группе одну или несколько описательных меток (например, «In-Person», «Online», «New Members Welcome»). Метки -- это свободные теги, которые вы определяете; отметьте все подходящие. Метки можно использовать для фильтрации групп в элементе сайта Groups Browser.
   - **Confidential group** -- скрывает эту группу и её состав от публичных страниц, поиска групп и тех, кто не является участником. Используйте это для чувствительных групп, например служений восстановления или консультирования; видеть группу смогут только её участники и штат церкви.
   - **Discussions** -- включает или выключает ленту чата группы, где любой участник может писать сообщения. По умолчанию включено.
   - **Announcements** -- включает вторую ленту чата, доступную только руководителям: участники могут читать и реагировать, но писать могут только руководители. По умолчанию включено.
   - **Attendance Tracking** -- включите, если хотите вести [посещаемость](../attendance/tracking-attendance.md) для этой группы.
   - **Service Times** -- свяжите группу с конкретными временами служений церкви, если это применимо. Подробнее о временах служений см. в [Настройке посещаемости](../attendance/setup.md).
4. Нажмите **Save**, чтобы применить изменения.

:::tip
Понятное описание и время встреч помогают участникам понять, чего ожидать, когда они присоединяются к группе.
:::

:::info
Если выключить одновременно Discussions и Announcements, вкладка Messages полностью исчезнет из группы в портале участника. Если выключить только один из параметров, его вкладка скроется, а участники перейдут на ту ленту, которая ещё включена. В любом случае существующие сообщения сохраняются -- переключатели управляют только новыми публикациями.
:::

## Дублирование группы

Начинаете новый сезон повторяющегося класса или служения? Вместо повторного ввода всех настроек продублируйте существующую группу:

1. Откройте группу и нажмите **Duplicate** (под кнопкой **Edit** слева на странице группы).
2. Подтвердите дублирование.

В копию переносятся настройки оригинала -- категория, описание, время и место встреч, правила вступления, метки и кампус, -- но **не** участники. Новой группе присваивается название оригинала с добавленным « (Copy)»; переименуйте её в настройках группы.

## Архивирование группы

Если группа больше не активна, но вы хотите сохранить её историю вместо удаления:

1. Откройте группу и нажмите **Edit**, чтобы изменить её настройки.
2. Нажмите **Archive** и подтвердите.

Архивные группы пропадают из основного списка Groups. Чтобы найти такую группу, нажмите кнопку **Show archived** рядом с кнопками категорий вверху страницы Groups, затем нажмите **Restore** рядом с группой, чтобы вернуть её.

:::info
Архивирование группы не удаляет её участников, историю посещаемости или события календаря -- оно только скрывает группу из списка по умолчанию, пока вы её не восстановите.
:::

## Что дальше

После создания и настройки группы вы можете:

- **Добавить участников** -- найдите людей и добавьте их в группу. Значком звезды (**Make Leader**) назначаются руководители группы. См. [Участники группы](./group-members.md).
- **Настроить календарь** -- создайте события и регулярные встречи для группы. См. [Календарь группы](./group-calendar.md).
- **Общаться** -- отправляйте сообщения всем участникам группы прямо со страницы группы.
- **Экспортировать данные** -- нажмите **Export** над списком участников группы, чтобы скачать его.

:::info
Каждая группа относится к какой-либо категории, а на основной странице Groups можно фильтровать список по категории. Вы всегда можете переупорядочить или переименовать категории по мере роста вашей церкви.
:::
