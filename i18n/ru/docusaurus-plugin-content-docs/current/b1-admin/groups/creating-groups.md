# Создание групп

<div class="article-intro">

Создать группу в B1 Admin несложно. Вы настроите категорию, назовете группу и затем укажете ее параметры. Группы помогают организовать церковь в осмысленные единицы: малые группы, комитеты и классы.

</div>

<h4>Перед началом работы</h4>

- Вам нужна активная учетная запись B1 Admin с правом управления группами. Если вы не уверены в своем уровне доступа, см. [Роли и права доступа](../people/roles-permissions.md).
- Определите структуру категорий для ваших групп (например, «Малые группы», «Служения», «Комитеты»). Категории помогают держать связанные группы упорядоченными.

## Добавление новой группы

1. Откройте [меню Jump](../introduction.md#getting-around-with-the-jump-menu) (строка поиска в верхнем левом углу B1 Admin), раскройте пункт **People** и нажмите **Groups**.
2. Нажмите **Add Group** в заголовке страницы. Под списком откроется форма **New Group**. Введите **Category Name**. Категории помогают объединять связанные группы (например, «Малые группы», «Служения» или «Комитеты»). Если категория уже существует, ее можно выбрать из списка.
3. Введите **Name** группы.
4. Нажмите **Add**. Новая группа появится в списке, а ее категория будет показана под названием.

## Настройка параметров группы

Когда группа создана, можно добавить дополнительные сведения:

1. Нажмите на **название группы** в списке, чтобы открыть ее.
2. Нажмите кнопку **Edit** слева на странице группы, под ее данными.
3. Настройте следующие параметры:
   - **Description** — краткое описание того, чем занимается группа. Оно видно участникам.
   - **Meeting Times** — когда группа обычно собирается (например, «По средам в 19:00»).
   - **Join Policy** — выберите, кто может вступить в группу:
     - **Open** — любой может вступить сразу, без одобрения
     - **Request** — люди должны подать заявку на вступление, которую нужно одобрить (см. [Заявки на вступление в группу](./group-join-requests.md))
     - **Closed** — участников добавляют вручную руководители или администраторы
   - **Labels** — назначьте группе одну или несколько описательных меток (например, «Очно», «Онлайн», «Приглашаем новых участников»). Метки — это свободные теги, которые вы задаете сами; отметьте все подходящие. Метки можно использовать для фильтрации групп в элементе сайта Groups Browser.
   - **Confidential group** — скрывает группу и ее состав от публичных страниц, поиска групп и тех, кто не является участником. Используйте для чувствительных групп, например служений восстановления или консультирования; видеть такую группу могут только ее участники и штатные сотрудники церкви.
   - **Discussions** — включает или выключает ленту чата группы, в которой может писать любой участник. По умолчанию включено.
   - **Announcements** — включает вторую ленту чата только для руководителей: участники могут читать и реагировать, но писать могут только руководители. По умолчанию включено.
   - **Attendance Tracking** — включите, если хотите вести [учет посещаемости](../attendance/tracking-attendance.md) для этой группы.
   - **Service Times** — свяжите группу с определенными временами богослужений, если это применимо. Подробности о временах служений см. в [Настройке посещаемости](../attendance/setup.md).
4. Нажмите **Save**, чтобы применить изменения.

:::tip
Понятное описание и время встреч помогают участникам понять, чего ожидать, когда они присоединяются к группе.
:::

:::info
Если выключить одновременно **Discussions** и **Announcements**, вкладка Messages полностью пропадает из портала участника. Если выключить только одну из них, скрывается только ее вкладка, а участники переходят в ту ленту, которая еще включена. Существующие сообщения в любом случае сохраняются — переключатели управляют только публикацией новых.
:::

## Дублирование группы

Начинаете новый сезон повторяющегося занятия или служения? Вместо повторного ввода всех настроек дублируйте существующую группу:

1. Откройте группу и нажмите **Duplicate** (под кнопкой **Edit** слева на странице группы).
2. Подтвердите дублирование.

В копию переносятся настройки оригинала — категория, описание, время и место встреч, политика вступления, метки и кампус, — но **не** участники. Новая группа получает название оригинала с добавленным в конце «(Copy)»; переименовать ее можно в настройках группы.

## Архивация группы

Когда группа больше не активна, но вы хотите сохранить ее историю, а не удалять:

1. Откройте группу и нажмите **Edit**, чтобы изменить ее настройки.
2. Нажмите **Archive** и подтвердите действие.

Архивные группы пропадают из основного списка Groups. Чтобы найти такую группу, нажмите кнопку **Show archived** рядом с кнопками категорий в верхней части страницы Groups, а затем нажмите **Restore** рядом с группой, чтобы вернуть ее.

:::info
Архивация группы не удаляет ее участников, историю посещаемости или события календаря — она лишь скрывает группу из списка по умолчанию, пока вы не восстановите ее.
:::

## Следующие шаги

После создания и настройки группы вы можете:

- **Добавить участников** — найдите людей и добавьте их в группу. Значком звезды (**Make Leader**) назначаются руководители группы. См. [Участники группы](./group-members.md).
- **Настроить календарь** — создайте события и регулярные встречи для группы. См. [Календарь группы](./group-calendar.md).
- **Общаться** — отправляйте сообщения всем участникам группы прямо со страницы группы.
- **Экспортировать данные** — нажмите **Export** над списком участников группы, чтобы скачать его.

:::info
Каждая группа принадлежит к категории, а на главной странице Groups можно отфильтровать список по категории. Категории можно переупорядочивать и переименовывать по мере роста церкви.
:::
