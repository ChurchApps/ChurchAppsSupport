# Создание групп

<div class="article-intro">

Создание группы в B1 Admin просто. Вы будете устанавливать категорию, назовете свою группу и затем настроите её параметры. Группы помогают вам организовать вашу церковь в значимые единицы, такие как малые группы, комитеты и классы.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Вам нужна активная учетная запись B1 Admin с разрешением управлять группами. См. [Roles & Permissions](../people/roles-permissions.md), если вы не уверены в вашем уровне доступа.
- Решите на структуру категорий для ваших групп (например, "Small Groups," "Ministries," "Committees"). Категории помогают сохранять связанные группы в организованном виде.

</div>

## Добавление новой группы

1. Откройте [Jump меню](../introduction.md#getting-around-with-the-jump-menu) (поле поиска в верхнем левом углу B1 Admin), разверните **People** и нажмите **Groups**.
2. Нажмите **Add Group** и введите **Category Name**. Категории помогают вам организовать связанные группы вместе (например, "Small Groups," "Ministries," или "Committees"). Если категория уже существует, вы можете выбрать её из списка.
3. Введите **Group Name**.
4. Нажмите **Add**. Ваша новая группа появится в списке под выбранной категорией.

## Настройка параметров группы

После создания группы вы можете заполнить дополнительные детали:

1. Нажмите на **имя группы** в списке для ее открытия.
2. Нажмите на **значок карандаша** для редактирования параметров группы.
3. Настройте следующие параметры:
   - **Description** -- Краткое описание того, о чем эта группа. Это видимо для членов.
   - **Meeting Times** -- Когда обычно встречается группа (например, "Wednesdays at 7 PM").
   - **Join Policy** -- Выберите, кто может присоединиться к этой группе:
     - **Open** -- Любой может присоединиться сразу без одобрения
     - **Request** -- Люди должны отправить запрос на присоединение, который требует одобрения (см. [Group Join Requests](./group-join-requests.md))
     - **Closed** -- Члены должны быть добавлены вручную лидерами или администраторами
   - **Labels** -- Назначьте одну или несколько описательных меток группе (например, "In-Person", "Online", "New Members Welcome"). Метки - это произвольные теги, которые вы определяете; проверьте все применимые. Метки можно использовать для фильтрации групп в элементе Groups Browser веб-сайта.
   - **Confidential group** -- Скройте эту группу и её список членов с публичных страниц, поиска групп и от не-членов. Используйте это для чувствительных групп, таких как восстановление или консультационные служения; только члены группы и сотрудники церкви могут ее видеть.
   - **Discussions** -- Включает ленту чата группы или выключает, где любой член может публиковать. По умолчанию включено.
   - **Announcements** -- Включает вторую, только для лидеров ленту чата -- члены могут читать и реагировать, но только лидеры могут публиковать. По умолчанию включено.
   - **Attendance Tracking** -- Включите это, если вы хотите записывать [attendance](../attendance/tracking-attendance.md) для этой группы.
   - **Service Times** -- Свяжите группу со специфичными временем церковных служб, если применимо. См. [Attendance Setup](../attendance/setup.md) для подробной информации о временах служб.
4. Нажмите **Save** для применения ваших изменений.

:::tip
Добавление четкого описания и времени встречи помогает членам узнать, чего ожидать, когда они присоединяются к группе.
:::

:::info
Отключение обоих Discussions и Announcements удаляет вкладку Messages из группы полностью в портале членов. Отключение только одного скрывает её вкладку; члены перемещаются на ленту, которая по-прежнему включена. Существующие сообщения сохраняются в любом случае -- переключатели только контролируют новые публикации.
:::

## Дублирование группы

Начинаете новую сессию повторяющегося класса или служения? Вместо переввода всех параметров, дублируйте существующую группу:

1. Откройте группу и нажмите на **значок дублирования** в заголовке группы (рядом с Edit).
2. Подтвердите дублирование.

Копия переносит параметры оригинала -- категорию, описание, время/место встречи, политику присоединения, метки и кампус -- но **не** его членов. Новая группа названа в честь оригинала с " (Copy)" добавленным; переименуйте её из параметров группы.

## Архивирование группы

Когда группа больше не активна, но вы хотите сохранить её историю вместо удаления:

1. Откройте группу и нажмите на **значок карандаша** для редактирования её параметров.
2. Нажмите **Archive** и подтвердите.

Архивированные группы выпадают из основного списка Groups. Чтобы найти одну снова, включите переключатель **Show archived** в верхней части страницы Groups, затем нажмите **Restore** рядом с группой для её восстановления.

:::info
Архивирование группы не удаляет её членов, историю посещаемости или события календаря -- это только скрывает группу из списка по умолчанию, пока вы не восстановите её.
:::

## Дальнейшие шаги

После создания и настройки вашей группы вы готовы:

- **Добавить членов** -- Поищите людей и добавьте их в группу. Используйте зеленый значок ключа для обозначения лидеров группы. См. [Group Members](./group-members.md).
- **Установить календарь** -- Создавайте события и повторяющиеся встречи для группы. См. [Group Calendar](./group-calendar.md).
- **Общаться** -- Отправляйте сообщения всем членам группы прямо со страницы группы.
- **Экспортировать данные** -- Нажмите значок загрузки для экспорта списка членов вашей группы.

:::info
Все ваши церковные группы организованы по категориям на основной странице Groups. Вы всегда можете переделать или переименовать категории по мере роста вашей церкви.
:::
