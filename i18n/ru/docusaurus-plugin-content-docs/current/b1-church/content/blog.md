# Блог

<div class="article-intro">

На странице блога вашего сайта B1.church вы можете просматривать последние статьи, поделиться ими с друзьями и подписаться на новые посты.

</div>

## Просмотр статей

1. Перейдите в раздел **Blog** на вашем сайте B1.church
2. Все опубликованные статьи отображаются в хронологическом порядке
3. Нажмите на статью для чтения полного содержания

## Фильтрация по категориям

Если у вашей церкви есть категории блога:

1. На странице блога вы увидите список категорий
2. Нажмите на категорию для просмотра только статей этой категории
3. Нажмите **All** для возврата ко всем статьям

## Поиск статей

Используйте поле поиска для поиска статей по ключевым словам:

1. Введите поисковый термин в поле поиска
2. Результаты фильтруются по мере ввода
3. Нажмите на результат для чтения статьи

## Обмен статьями

Чтобы поделиться статьей:

1. Откройте статью
2. Нажмите **Share**
3. Выберите социальную сеть или скопируйте ссылку
4. Отправьте друзьям

## Подписка на обновления

Вы можете подписаться на блог по электронной почте:

1. На странице блога прокрутите вниз
2. Введите ваш адрес электронной почты в поле подписки
3. Нажмите **Subscribe**
4. Подтвердите подписку по электронной почте

Вы будете получать уведомления о новых постах.

## Архив статей

Просматривайте старые статьи в архиве:

1. На странице блога найдите виджет **Archive**
2. Выберите месяц и год для просмотра статей за тот период
3. Нажмите на статью для чтения
