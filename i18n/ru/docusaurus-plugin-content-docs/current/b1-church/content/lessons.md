# Уроки

<div class="article-intro">

На странице уроков вашего B1.church сайта вы можете просматривать и изучать уроки, которые опубликовала ваша церковь.

</div>

## Просмотр уроков

1. Перейдите в раздел **Lessons** на вашем сайте B1.church
2. Просмотрите доступные уроки
3. Нажмите на урок для просмотра деталей

## Фильтрация уроков

Вы можете фильтровать уроки по:

- **Series** — уроки из определенного серии
- **Topic** — уроки по определенной теме
- **Date** — уроки за определенный период

Используйте фильтры для поиска именно того урока, который вам нужен.

## Изучение урока

При открытии урока вы видите:

- **Title** — название урока
- **Description** — описание содержания
- **Scripture** — соответствующие стихи из Писания
- **Teaching Notes** — примечания учителя (если предоставлены)
- **Resources** — дополнительные ресурсы или ссылки
- **Video** — видео проповеди, если доступно

## Печать урока

Чтобы распечатать урок:

1. Откройте урок
2. Нажмите **Print**
3. Используйте диалог печати вашего браузера
4. Нажмите **Print**

## Скачивание ресурсов

Если доступны ресурсы для загрузки:

1. Нажмите на ресурс
2. Выберите **Download**
3. Файл сохранится на ваше устройство

## Обмен уроком

Чтобы поделиться уроком:

1. Откройте урок
2. Нажмите **Share**
3. Скопируйте ссылку или выберите социальную сеть
4. Отправьте друзьям
