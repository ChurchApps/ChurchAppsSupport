# Библия

<div class="article-intro">

B1.church включает встроенную читалку Библии, чтобы вы могли читать Писание, не покидая сайт. Читалка встроена прямо в страницу и даёт быстрый доступ к любому отрывку рядом с другими церковными инструментами.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Для чтения Библии вход в систему не нужен. Страница Библии доступна всем.
- Ваша церковь должна добавить страницу Библии в навигацию сайта.

</div>

## Чтение Библии {#reading-the-bible}

1. Перейдите на страницу **Библия** через навигацию сайта вашей церкви.
2. Читалка по умолчанию открывается на Бытие 1.
3. Используйте элементы управления внутри читалки, чтобы перейти к другой книге, главе или стиху.

Читалка Библии работает на основе **YouVersion** и даёт доступ к широкому выбору переводов Библии на многих языках.

## Навигация по отрывкам {#navigating-passages}

Встроенная читалка предоставляет инструменты для перемещения по тексту Писания. Вы можете:

- выбрать нужную книгу Библии;
- перейти к определённой главе;
- прокручивать стихи внутри главы;
- переключиться на другой перевод Библии с помощью выбора версии;
- на сайте вашей церкви использовать кнопки **Предыдущая глава** и **Следующая глава** над текстом, чтобы переходить по главам книги.

Читалка занимает всё содержимое страницы, так что для комфортного чтения есть достаточно места.

:::tip
В портале участника (`/mobile/bible`) выбранные книга, глава и перевод запоминаются на этом устройстве, поэтому читалка открывается с того места, где вы остановились. Читалка на сайте всегда начинает с Бытия 1.
:::

Если читалка не может загрузиться, страница сообщит об этом и предложит кнопку для чтения на Bible.com (портал участника также предлагает Biblia.com).

:::tip
Вы можете добавить страницу Библии в закладки браузера, чтобы быстро возвращаться к ней для ежедневного чтения. Сочетайте её со [стихом дня](./verse-of-the-day.md) для ежедневного вдохновения из Писания.
:::

## Доступность {#availability}

Страница Библии -- это встроенная функция контента B1.church. Если в навигации вашей церкви нет ссылки **Библия**, возможно, администратор церкви не добавил её в меню сайта. Обратитесь к администратору церкви, чтобы попросить его добавить ссылку.
