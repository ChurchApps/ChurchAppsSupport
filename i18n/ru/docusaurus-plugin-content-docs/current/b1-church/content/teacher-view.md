# Режим учителя для уроков

<div class="article-intro">
Режим учителя (Teacher View) предоставляет расширенный полноэкранный интерфейс для просмотра содержимого уроков со структурированными разделами, что упрощает учителям и руководителям навигацию по учебным материалам во время занятия.
</div>

<div class="prereqs">
<h4>Перед началом</h4>

- В вашей церкви в плане должны быть запланированы уроки. Подробности см. в руководстве для B1 Admin [Планирование уроков](../../b1-admin/serving/scheduling-lessons.md).
- Вы должны быть назначены на этот план или иметь доступ к его просмотру на вашем сайте B1.church.
</div>

## Открытие режима учителя

Чтобы открыть расширенный режим учителя для урока:

1. Откройте **Plans** в портале участника B1.church
2. Откройте план, который содержит урок, который вы хотите провести
3. Нажмите кнопку **Teach** вверху страницы плана

Урок откроется в полноэкранном интерфейсе, оптимизированном для преподавания.

:::tip
Режим учителя особенно полезен, когда содержимое урока проецируется на экран или телевизор, чтобы класс мог его видеть, либо когда вы ведете занятие с планшета.
:::

## Возможности режима учителя

### Навигация по разделам

Режим учителя разбивает содержимое урока на разделы:

- Каждый крупный раздел урока отображается как отдельный блок с заголовком
- Нажмите **Sections** вверху, чтобы открыть список разделов, и выберите нужный, чтобы перейти к нему напрямую
- В заголовке показано, в каком вы разделе, например «Section 2 of 5»
- Список разделов позволяет легко перескакивать к разным частям урока

### Прокручиваемое содержимое

Основная область содержимого показывает полные материалы урока:

- Прокручивайте урок естественным образом
- Во время прокрутки заголовок автоматически обновляется в соответствии с разделом, который вы просматриваете
- Весь отформатированный текст, изображения и инструкции отображаются четко

### Воспроизведение медиа

Когда в уроках есть видео, изображения или другие медиафайлы:

- Нажмите на любой медиаэлемент, чтобы открыть его во всплывающем плеере
- Видео воспроизводятся в отдельном видеоплеере со стандартными элементами управления
- Изображения открываются в лайтбоксе для полноэкранного просмотра
- Закройте медиаплеер, чтобы вернуться к содержимому урока

### Загружаемые материалы

Если в уроке есть загружаемые файлы (рабочие листы, раскраски и т. п.):

- Для каждого материала появляются кнопки загрузки
- Нажмите, чтобы загрузить файлы прямо на устройство
- Файлы могут быть в формате PDF, изображениями или другими материалами, предоставленными автором

## Использование режима учителя на занятии

### Перед занятием

1. Откройте урок в режиме учителя до начала занятия
2. Просмотрите все разделы и ознакомьтесь с содержимым
3. Загрузите все нужные материалы для печати
4. Проверьте, воспроизводятся ли видео и медиа без проблем

### Во время занятия

1. Держите режим учителя открытым на устройстве или выведите его на экран
2. Используйте **Sections**, чтобы переходить между разделами по мере продвижения по уроку
3. Воспроизводите видео или показывайте изображения в нужные моменты
4. Прокручивайте инструкции по мере необходимости, не теряя места

### На проецируемом экране

Когда вы проецируете материал для класса:

- Полноэкранный макет убирает отвлекающие элементы
- Крупный, четкий текст виден из любой точки комнаты
- Нажимайте на медиаэлементы, чтобы показать видео или изображения всему классу
- Перемещайтесь с помощью беспроводной мыши или трекпада

## Выход из режима учителя

Чтобы выйти из режима учителя:

- Нажмите кнопку **Close** (X) в углу
- Или нажмите клавишу **Esc** на клавиатуре
- Вы вернетесь к виду деталей плана

## Использование на мобильных устройствах и планшетах

Режим учителя работает на планшетах и мобильных устройствах:

- **Планшеты** — идеальны для учителей, которым нужно портативное руководство по уроку
- **Телефоны** — также поддерживаются, хотя маленький экран может быть менее удобен для преподавания
- **Альбомная ориентация** — обеспечивает лучший режим просмотра на мобильных устройствах

## Отличия от обычного просмотра урока

| Функция | Обычный просмотр | Режим учителя |
|---------|--------------|--------------|
| **Макет** | Компактный, встроен в план | Полноэкранный, отдельный вид |
| **Навигация** | Только прокрутка | Список разделов + прокрутка с заголовком текущего раздела |
| **Медиа** | Встроены на страницу | Всплывающий плеер для сосредоточенного просмотра |
| **Пространство экрана** | Показывает другие элементы плана | Максимально отдано содержимому урока |
| **Лучше всего для** | Просмотра и планирования | Преподавания и презентаций |

## Лучшие практики

- **Готовьтесь заранее** — просматривайте уроки в режиме учителя до занятия, чтобы познакомиться с макетом
- **Отмечайте разделы** — запомните, в каких разделах находятся ключевые задания или обсуждения
- **Проверяйте медиа** — убедитесь, что видео и изображения загружаются правильно до начала занятия
- **Загружайте материалы заранее** — не ждите времени занятия, чтобы загрузить материалы для печати
- **Используйте большой экран** — для лучшего опыта преподавания проецируйте материал или используйте планшет

## Устранение неполадок

### Урок не открывается в режиме учителя

- Убедитесь, что урок правильно запланирован в плане
- Проверьте, есть ли у вас разрешение на просмотр плана
- Обновите страницу и попробуйте снова

### Видео не воспроизводятся

- Проверьте подключение к интернету
- Убедитесь, что ваше устройство разрешает воспроизведение медиа
- Попробуйте открыть видео в отдельной вкладке
- Некоторые поставщики контента могут ограничивать воспроизведение видео

### Содержимое обрезается на мобильном устройстве

- Поверните устройство в альбомную ориентацию
- При необходимости немного уменьшите масштаб
- Используйте планшет или устройство с большим экраном для лучшей видимости
