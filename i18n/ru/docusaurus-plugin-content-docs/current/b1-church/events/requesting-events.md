# Запрос событий

<div class="article-intro">

Если у вас есть идея события для вашей церкви, вы можете подать запрос на его создание. Администраторы вашей церкви рассмотрят запрос и создадут событие, если оно будет одобрено.

</div>

## Подача запроса на событие

1. Перейдите в раздел **Events** на вашем сайте B1.church
2. Нажмите **Request Event**
3. Заполните форму запроса:
   - **Event Name** — название события
   - **Date** — предлагаемая дата
   - **Time** — предлагаемое время
   - **Location** — где вы хотите проводить событие
   - **Description** — описание идеи события
   - **Estimated Attendees** — примерное количество участников
4. Нажмите **Submit**

Администратор получит уведомление о вашем запросе.

## Отслеживание вашего запроса

После подачи запроса:

1. Перейдите в раздел **My Event Requests**
2. Вы видите статус всех ваших запросов
3. Администратор свяжется с вами для обсуждения деталей

## Статусы запроса

Ваш запрос может иметь статусы:

- **Pending** — администратор еще не рассмотрел
- **Approved** — событие было одобрено и будет создано
- **Declined** — администратор решил не создавать событие
- **Created** — событие была создана на основе вашего запроса

## Сообщение от администратора

Если администратор отклонит запрос, он может оставить сообщение с объяснением. Вы получите уведомление по электронной почте.

## Изменение запроса

Пока ваш запрос находится в статусе "Pending":

1. На запросе нажмите **Edit**
2. Обновите детали
3. Нажмите **Save**

После одобрения запрос больше нельзя редактировать.

## Получение справки

Если у вас есть вопросы о процессе запроса событий, свяжитесь с администратором вашей церкви.
