# Запись волонтеров

<div class="article-intro">

Просматривайте доступные должности волонтеров и записывайтесь на предстоящие служения прямо на B1.church. Должности сгруппированы по категориям, чтобы вы могли быстро найти, где нужна помощь, и присоединиться к команде.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Учетная запись B1.church — для записи нужно быть авторизованным
- Администратор вашей церкви должен включить самостоятельную запись хотя бы на одну должность

</div>

## Просмотр доступных должностей

1. Перейдите на страницу **Volunteer** на сайте B1.church вашей церкви.
2. Вы увидите список предстоящих планов служения с открытыми должностями волонтеров. Внутри каждого плана должности перечислены по категориям, а затем по названиям. Если ваша церковь показывает только следующую неделю каждого типа плана, более поздние недели появятся, когда текущая пройдет.
3. Каждый план показывает **название плана**, **дату служения** и **время служения**.

Должности сгруппированы по категориям (например, «Band», «Hospitality», «Kids Ministry»). Для каждой должности показано:

- **Название должности** — роль, которую вы бы выполняли (например, «Drummer», «Greeter», «Coffee Server»).
- **Описание** — подробности о роли, если администратор их указал.
- **Свободные места** — индикатор прогресса, показывающий, сколько мест занято и сколько осталось.
- **Кто записался** — если ваша церковь включила **Show volunteer names on signup page** для плана, строка «Signed up:» перечисляет имена людей, которые уже служат на этой должности. Имена видны только когда вы авторизованы.

## Запись

1. Найдите должность, на которую хотите записаться.
2. Нажмите кнопку **Sign Up** рядом с должностью.
3. Появится сообщение подтверждения: «You're signed up! Thank you for volunteering.»
4. У должности появится зеленый индикатор, подтверждающий вашу запись.

:::info
Чтобы записаться, нужно быть авторизованным. Если вы не вошли в систему, вам сначала будет предложено войти.
:::

## Отмена записи

Если ваши планы изменились и вы больше не можете служить:

1. Найдите должность, на которую вы записались, — на ней будет зеленый индикатор «You're signed up».
2. Нажмите кнопку **Remove**.
3. Подтвердите, что хотите снять себя с должности.
4. Появится сообщение: «You have been removed from this position.»

## Крайние сроки

Администратор вашей церкви может установить крайний срок записи для каждого плана. Крайний срок — это заданное количество часов до даты служения. Когда срок проходит:

- Вы не можете записаться на новые должности.
- Вы не можете удалять существующие записи.
- Вверху плана появляется сообщение о том, что срок записи истек.

## Вместимость должности

У каждой должности ограниченное количество мест. Когда все места заняты:

- Должность отображается как **Full**.
- Кнопка записи становится неактивной.
- Если кто-то удалит свою запись, место снова освобождается.

:::tip
Регулярно проверяйте страницу волонтеров, особенно в начале недели. Популярные должности заполняются быстро, поэтому записавшись заранее, вы получите больше вариантов выбора.
:::
