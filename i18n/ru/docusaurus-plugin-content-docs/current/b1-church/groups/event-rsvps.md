# Ответы на мероприятия группы

<div class="article-intro">

Мероприятия групп могут собирать ответы об участии, чтобы руководители знали, кто придёт. На странице и в календаре вашей группы у каждого предстоящего мероприятия есть кнопки **Приду**, **Возможно** и **Не смогу** -- ответьте одним нажатием, передумайте в любой момент и сразу видите, сколько других людей придут.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Вы должны [войти в систему](../getting-started/logging-in.md) и быть участником группы
- Для мероприятия должны быть разрешены ответы (по умолчанию они включены; руководители могут отключить их для каждого мероприятия)

</div>

## Ответ на мероприятие {#responding-to-an-event}

1. Откройте свою группу в портале участника. Следующее мероприятие группы появляется в разделе **Следующее мероприятие**. Для остальных мероприятий нажмите **Все мероприятия**: в виде **Календарь** нажмите на день, чтобы увидеть его мероприятия, или переключитесь на **Список**, чтобы сразу увидеть все предстоящие мероприятия этого месяца.
2. У каждого предстоящего мероприятия есть три кнопки: **Приду**, **Возможно** и **Не смогу**.
3. Нажмите свой ответ. Ваш выбор подсвечивается, а на каждой кнопке показывается живой счётчик того, сколько людей выбрали этот ответ.
4. Чтобы убрать ответ, нажмите подсвеченный вариант ещё раз, или нажмите другую кнопку, чтобы изменить ответ.

Ваш ответ относится к конкретному проведению мероприятия -- для еженедельной встречи вы отвечаете отдельно на каждое мероприятие недели. Когда мероприятие закончилось, кнопки исчезают; ваш ответ по-прежнему показан значком рядом с мероприятием.

## Для руководителей групп {#for-group-leaders}

- **Просмотр ответов** -- руководители видят ссылку **Смотреть ответы** у каждого мероприятия в календаре группы (**Все мероприятия**), в том числе у уже прошедших. Она открывает лист **Ответы**, где все перечислены по ответу -- Приду, Возможно и Не смогу. Если никто ещё не ответил, показывается «Ответов пока нет».
- **Включение и отключение ответов** -- при создании или редактировании мероприятия используйте переключатель **Разрешить ответы**. У мероприятий с отключёнными ответами нет кнопок. Сотрудники, которые создают мероприятия пакетно в B1 Admin, имеют ту же опцию -- см. [Календарь группы](../../b1-admin/groups/group-calendar.md#event-rsvps).

:::tip
Ответы -- это быстрый подсчёт присутствующих. Если мероприятию нужны данные для записи, управление вместимостью или оплата, используйте [регистрацию на мероприятие](../events/registering.md).
:::
