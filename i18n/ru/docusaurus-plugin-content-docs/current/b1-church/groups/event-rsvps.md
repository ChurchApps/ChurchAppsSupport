# Подтверждение участия в мероприятиях (RSVP)

<div class="article-intro">

Групповые мероприятия могут собирать подтверждения участия (RSVP), чтобы лидеры знали, кто придёт. В календаре вашей группы каждое предстоящее мероприятие спрашивает «Вы придёте?» — ответьте нажатием, измените решение в любой момент и сразу увидите, сколько человек уже согласилось прийти.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Вы должны быть [авторизованы](../getting-started/logging-in.md) и состоять в группе
- Для мероприятия должны быть разрешены RSVP (по умолчанию включены; лидеры могут отключать их для отдельных мероприятий)

</div>

## Ответ на мероприятие

1. Откройте свою группу в портале для участников и перейдите в раздел **Мероприятия** / вид календаря.
2. На карточке каждого предстоящего мероприятия отображается **Вы придёте?** с тремя кнопками: **Приду**, **Возможно** и **Не приду**.
3. Нажмите на свой ответ. Ваш выбор подсветится, и на каждой кнопке появится актуальный счётчик того, сколько людей дали такой ответ.
4. Нажмите на подсвеченный ответ ещё раз, чтобы очистить его, либо нажмите другую кнопку, чтобы изменить ответ.

Ваш ответ RSVP относится к конкретному проведению мероприятия — для еженедельной встречи вы отвечаете на мероприятие каждой недели отдельно.

## Для лидеров групп

- **Просмотр ответов** -- Лидеры видят кнопку **Просмотреть ответы** на каждой карточке мероприятия. Она открывает панель **Ответы** со списком всех участников по типу ответа — Приду, Возможно и Не приду. Если пока никто не ответил, отображается «Пока нет ответов».
- **Включение и отключение RSVP** -- При создании или редактировании мероприятия используйте переключатель **Разрешить RSVP**. У мероприятий с отключённым RSVP кнопки ответа не отображаются. У сотрудников, массово создающих мероприятия в B1 Admin, есть та же опция — см. [Календарь группы](../../b1-admin/groups/group-calendar#event-rsvps).

:::tip
RSVP — это упрощённый подсчёт участников. Если для вашего мероприятия нужны детали регистрации, управление вместимостью или оплата, используйте [регистрацию на мероприятие](../events/registering).
:::
