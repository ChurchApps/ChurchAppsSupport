# Привязка устройства

<div class="article-intro">

Чтобы использовать режим плана, необходимо привязать телевизор к типу плана в B1 Admin. FreePlay генерирует уникальный код привязки, который связывает устройство с планом вашей церкви, обеспечивая автоматическую доставку контента каждую неделю.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Установите и запустите FreePlay -- см. [Начало работы](../getting-started/)
- Выберите **Pair to Plan** на [экране выбора режима привязки](../getting-started/pairing-modes.md)
- Обеспечьте доступ к **B1 Admin** на компьютере или телефоне для завершения привязки

</div>

## Генерация кода привязки

1. На экране **Select Pairing Mode** выберите **Pair to Plan**
2. FreePlay связывается с сервером и генерирует короткий код привязки
3. Код отображается крупными символами в центре экрана
4. Под кодом пульсирующий индикатор показывает **Waiting for connection**

Код отображается в виде отдельных символов для удобного считывания на расстоянии.

## Ввод кода в B1 Admin

1. На компьютере или телефоне перейдите по адресу, показанному под кодом на телевизоре (или отсканируйте QR-код на экране) — это откроет страницу **Authorize Device** в B1 Admin
2. Введите код привязки, если он не был автоматически заполнен из QR-кода
3. В поле **Show Plans For** выберите тип плана, которому должен следовать этот экран (например, «Sunday Service»). Оставьте значение **None**, если хотите, чтобы экран был доступен только для просмотра контента или уведомлений, без привязки к плану
4. Подтвердите устройство

FreePlay опрашивает сервер каждые несколько секунд, проверяя завершение привязки. Как только **B1 Admin** подтверждает подключение, телевизор автоматически переходит на экран загрузки плана.

:::tip
Устройства также можно привязать через **Profile → Devices → Add Device** в B1 Admin, используя тот же код — там доступен тот же выбор типа плана **Show Plans For**.
:::

## Загрузка контента плана

После привязки FreePlay загружает текущий план для данного типа плана. Отображается:

- Название плана и дата служения
- Название связанного урока (если план включает учебный контент)
- Индикатор прогресса, показывающий **Downloading item X of Y**

Когда все медиафайлы загружены, появляется кнопка **Start Plan**. Нажмите **Select** на пульте, чтобы начать воспроизведение.

:::tip
План обновляется автоматически каждый час. Если план обновляется в течение дня, FreePlay подхватывает изменения без какого-либо ручного вмешательства.
:::

## Альтернатива: поиск по названию церкви

Если вы предпочитаете не использовать процесс с кодом привязки, можно выбрать **or search by church name** внизу экрана привязки. Это перенаправит вас на экран поиска церкви, где можно найти свою церковь и подключиться к классу.

## Если привязка не удалась

Если код привязки не может быть сгенерирован (например, из-за проблем с сетью), появится сообщение об ошибке с кнопкой **Try Again**. Убедитесь, что телевизор подключён к интернету, и повторите попытку.

:::warning
Коды привязки действительны ограниченное время. Если вы ждёте слишком долго, сгенерируйте новый код, вернувшись на экран привязки.
:::
