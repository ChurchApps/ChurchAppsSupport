# Привязка устройства

<div class="article-intro">

Чтобы использовать режим плана, вы привязываете телевизор к типу плана в B1 Admin. FreePlay показывает на телевизоре короткий код привязки. Вы вводите этот код в B1 Admin и выбираете тип плана, которому нужно следовать, — и телевизор автоматически получает контент этого плана каждую неделю.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Установите FreePlay и запустите его. См. [Начало работы](../getting-started/)
- Для завершения привязки нужен доступ к **B1 Admin** на компьютере или телефоне

</div>

## Создание кода привязки

1. На телевизоре откройте **Настройки** внизу боковой панели.
2. Выберите **Привязать к календарю**.
3. FreePlay показывает крупными буквами четырехбуквенный код привязки рядом с QR-кодом.
4. Под кодом пульсирующий индикатор **Ожидание подтверждения** показывает, что FreePlay ждет, пока вы завершите привязку.

Тот же код работает для [режима расписания](../scheduled-mode/) в FreePlay Admin и для режима плана в B1 Admin. QR-код и адрес **freeplay.church/pair** на экране открывают FreePlay Admin. Для режима плана игнорируйте их и введите код в B1 Admin, как описано ниже.

## Ввод кода в B1 Admin

1. В B1 Admin перейдите в **Профиль** > **Устройства** и нажмите **Добавить экран**.
2. Введите четыре буквы с телевизора в поле **Код привязки**.
3. В поле **Показывать планы для** выберите тип плана, которому должен следовать этот экран, например «Воскресное служение».
4. Сохраните.

FreePlay каждые несколько секунд проверяет, завершена ли привязка. Как только B1 Admin ее подтверждает, на телевизоре появляется **Подключено!**, и он переходит к экрану загрузки плана.

## Загрузка контента плана

После привязки FreePlay загружает текущий план для этого типа плана. Он показывает:

- Название плана и дату служения
- Название урока, если в плане есть учебный материал
- Индикатор хода загрузки **Загрузка элемента X из Y**

Когда все медиафайлы загружены, появляется кнопка **Начать план**. Нажмите **Выбрать** на пульте, чтобы начать проигрывание.

:::tip
План обновляется автоматически каждый час. Если кто-то изменит план в течение дня, FreePlay подхватит изменения сам.
:::

## Если привязка не удалась

Если FreePlay не может создать код привязки (например, из-за проблем с сетью), вы увидите сообщение об ошибке с кнопкой **Повторить**. Убедитесь, что телевизор подключен к интернету, и попробуйте снова.

:::warning
Коды привязки истекают через 15 минут. Когда старый код заканчивается, FreePlay сам показывает новый, а вы можете выбрать **Создать новый код** в любой момент. Если введенный вами код не работает, используйте тот, который сейчас показан на телевизоре.
:::
