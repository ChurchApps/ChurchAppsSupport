# Режим плана

<div class="article-intro">

Режим плана подключает ваш телевизор к плану богослужения церкви. Вместо того чтобы брать контент по расписанию занятий, он следует плану, который настроило руководство вашей церкви в B1 Admin. Это идеально, когда нужно, чтобы телевизор показывал именно то, что назначено в плане текущей недели.

</div>

## Чем он отличается от других режимов

- **[Режим по расписанию](../scheduled-mode/)** проигрывает плейлисты из календаря в FreePlay Admin в заданное вами время, без нажатия кнопки «Старт»
- **Режим плана** загружает контент, привязанный к типу плана, который может включать уроки, презентации провайдеров, дополнения и другие медиафайлы, расположенные в нужном порядке

Режим плана особенно полезен, когда ваш план служения включает смесь контента из разных источников, собранного в одну последовательность.

:::tip
Хотите, чтобы текущий план проигрывался сам в заданное время? В FreePlay Admin добавьте запись в календарь и выберите тип плана в разделе **Планы служения**. См. [Планирование календаря](../scheduled-mode/scheduling-the-calendar).
:::

## Как это работает

1. На телевизоре откройте **Настройки** > **Привязать к календарю**, чтобы показать код привязки
2. Администратор вводит этот код в **B1 Admin** и выбирает тип плана в разделе **Показывать планы для**
3. После привязки FreePlay загружает текущий план и скачивает весь связанный медиаконтент
4. Нажмите **Начать план**, чтобы начать воспроизведение

Телевизор остаётся привязанным к типу плана. Каждую неделю он автоматически подхватывает последний план и его контент.
