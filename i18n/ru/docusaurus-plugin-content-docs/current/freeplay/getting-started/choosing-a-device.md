# Выбор устройства для FreePlay

<div class="article-intro">

FreePlay работает на устройствах Amazon Fire TV, Android TV и Apple TV. Эта страница точно рассказывает вам, какие устройства покупать для ТВ вашего класса -- и, не менее важно, какие избегать.

</div>

## Быстрый ответ

Для большинства церквей купите **Amazon Fire TV Stick 4K Max**. Он имеет 16 ГБ хранилища (вдвое больше, чем большинство палочек -- важно для загрузки уроков для автономного воспроизведения), быстрый процессор, сильный Wi-Fi и запускает Fire OS, который FreePlay полностью поддерживает.
