# Подключение экрана

<div class="article-intro">

Чтобы поставить телевизор по календарю, подключите его к **FreePlay Admin**. Телевизор показывает четырёхбуквенный код. Вы вводите этот код на [admin.freeplay.church](https://admin.freeplay.church) и выбираете группу экранов, календарь которой он должен отслеживать. Это нужно сделать один раз для каждого телевизора.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Установите и запустите FreePlay на телевизоре. См. [Начало работы](../getting-started/index.md)
- Убедитесь, что у вашей церкви есть учётная запись ChurchApps, чтобы войти в FreePlay Admin
- По желанию: сначала [создайте плейлист](./building-playlists.md) и [запланируйте его](./scheduling-the-calendar.md), чтобы телевизор сразу имел что воспроизводить

</div>

## Показ кода на телевизоре

1. На телевизоре откройте **Settings** внизу боковой панели.
2. Выберите **Pair to a calendar**. В строке написано **Not paired**, пока телевизор не подключён.
3. На экране **Pair this screen** показаны QR-код и четырёхбуквенный код подключения с сообщением **Scan with your phone, or go to freeplay.church/pair and enter this code**.
4. Под кодом пульсирует **Waiting for confirmation**, пока FreePlay ждёт, когда вы завершите подключение.

Код действует 15 минут, а под ним отсчитывается время до окончания. Когда время выходит, FreePlay сам показывает новый код. Также можно выбрать **Generate New Code**, чтобы получить новый, или **Cancel**, чтобы вернуться в Settings.

## Подключение в FreePlay Admin

1. Отсканируйте QR-код телефоном или откройте **freeplay.church/pair** на любом компьютере или телефоне. Войдите в систему, если попросят. FreePlay Admin откроет форму **Pair screen** с уже заполненным кодом.
   - Форму можно открыть и самостоятельно. Перейдите в **Screens** в FreePlay Admin и нажмите **Pair screen**.
2. Проверьте **Pairing code**. Это четыре буквы с экрана телевизора.
3. Введите **Label**, чтобы отличать этот телевизор от других, например «Lobby left». Это необязательно.
4. В поле **Group** выберите группу экранов, календарь которой должен отслеживать этот телевизор. Чтобы создать новую, выберите **＋ New group…** и введите **New group name**.
5. В поле **Mode** оставьте **Scheduled**. Телевизор будет воспроизводить по календарю группы самостоятельно.
6. Нажмите **Pair**.

Телевизор покажет **Connected!**, затем **Loading your schedule...**. Он загрузит запланированное и начнёт воспроизведение. См. [Воспроизведение по расписанию на телевизоре](./scheduled-playback.md).

:::info
Если FreePlay Admin сообщает **That code didn't match a TV**, проверьте код на экране. Если он истёк, используйте новый код, который сейчас показывает телевизор.
:::

### По расписанию или вручную

У настройки **Mode** два варианта:

- **Scheduled** — воспроизводит по календарю группы самостоятельно. Нажимать Start никому не нужно.
- **Manual** — кто-то выбирает контент пультом. Ручной экран по-прежнему появляется в вашем списке **Screens**, но он не следует календарю, поэтому поле **Group** выключено.

Режим экрана можно изменить позже через **Edit** на [странице Screens](./managing-screens.md).

## Подключение к плану служения

Код с экрана **Pair this screen** работает и в B1 Admin. Если ввести его там и выбрать тип плана в поле **Show Plans For**, телевизор будет следовать этому типу плана в [режиме плана](../plan-mode/index.md), а не календарю. См. [Подключение устройства](../plan-mode/device-pairing.md).

## Смена или отключение с телевизора {#changing-or-unpairing-from-the-tv}

Когда телевизор подключён, строка **Pair to a calendar** в **Settings** показывает название группы экранов, которую он отслеживает. Выберите строку, чтобы открыть диалог **Paired to**, в котором три варианта:

- **Back to schedule** — закрыть диалог и вернуться к плееру расписания. Подключение не меняется.
- **Unpair** — прекратить следовать расписанию. FreePlay откроет экран **Content Providers**.
- **Pair to a different calendar** — отключить и показать новый код подключения, чтобы подключить телевизор заново.

:::warning
Отключение удаляет файлы, которые FreePlay загрузил для этого календаря.
:::

## Отключение из FreePlay Admin

1. Перейдите в **Screens** и нажмите на название экрана.
2. Нажмите **More**, затем **Unpair**.
3. Нажмите **Unpair** ещё раз, чтобы подтвердить.

Телевизор снова покажет код подключения. Подключите его снова, когда понадобится.
