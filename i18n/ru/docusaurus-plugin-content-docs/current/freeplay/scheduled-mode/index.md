# Режим расписания

<div class="article-intro">

Режим расписания позволяет телевизору FreePlay работать самостоятельно. Вы создаёте плейлисты и размещаете их в календаре в **FreePlay Admin** по адресу [admin.freeplay.church](https://admin.freeplay.church). Каждый телевизор, привязанный к этому календарю, загружает материалы на неделю вперёд и воспроизводит то, что запланировано, по часам — без того, чтобы кто-то нажимал «Старт». Поскольку файлы уже загружены, воспроизведение продолжается, даже если Wi-Fi пропадает.

</div>

:::tip
FreePlay Admin использует ваш логин ChurchApps — тот же, что и для B1 Admin. Отдельную учётную запись создавать не нужно.
:::

## Как всё устроено

FreePlay Admin имеет четыре основные страницы, перечисленные в верхней части сайта:

- **[Экраны](./managing-screens)** -- подключённые телевизоры, их статус и **группы экранов**, в которые они входят. Экраны одной группы используют общий календарь и общую циклическую подборку по умолчанию
- **[Плейлисты](./building-playlists)** -- циклы изображений и видео, которые вы выбираете у своих провайдеров контента
- **[Календарь](./scheduling-the-calendar)** -- что и когда воспроизводит каждая группа экранов
- **[Провайдеры](./building-playlists#connecting-providers)** -- источники контента, из которых берутся ваши плейлисты. Каждого провайдера вы подключаете один раз для всей церкви

Когда ничего не запланировано, экраны группы воспроизводят её **циклическую подборку по умолчанию**. Если у группы нет такой подборки, экраны гаснут.

## Чем это отличается от режима плана

- **[Режим плана](../plan-mode/)** следует за одним типом плана служения из B1 Admin. Кто-то нажимает **Начать план** на телевизоре, и урок начинает воспроизводиться в этот момент
- **Режим расписания** следует за календарём. Контент запускается и останавливается в заданное вами время, поэтому он хорошо подходит для информационных экранов в холле, циклов объявлений и классов, где урок должен быть на экране до того, как кто-либо войдёт

Запись в календаре может также воспроизводить план служения. Выберите тип плана в разделе **Планы служения** при добавлении расписания, и экран будет воспроизводить тот план, который на текущую неделю указан в B1 Admin.

## Начало работы

Пока вы не выполните каждый из этих шагов, на странице **Экраны** отображается список **«Начало работы»** со ссылкой для каждого шага:

1. **Подключите провайдера** -- добавьте Dropbox, OneDrive, Lessons.church или другой источник на странице **Провайдеры**
2. **Создайте плейлист** -- выберите изображения и видео у провайдера
3. **Добавьте в календарь** -- выберите, что и когда воспроизводить, или задайте циклическую подборку по умолчанию для группы
4. **Привяжите экран** -- введите четырёхбуквенный код, отображаемый на телевизоре

Нажмите **Скрыть**, чтобы убрать список.

:::tip
Нажмите **Ctrl+K** (**⌘K** на Mac) или щёлкните поле поиска в шапке, чтобы открыть командную палитру. Оттуда можно перейти на любую страницу или запустить действие, например **Привязать экран**, **Добавить плейлист** или **Добавить расписание**.
:::
