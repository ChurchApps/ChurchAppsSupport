# Режим по расписанию

<div class="article-intro">

Режим по расписанию позволяет FreePlay TV работать самостоятельно. Вы создаёте плейлисты и размещаете их в календаре в **FreePlay Admin** по адресу [admin.freeplay.church](https://admin.freeplay.church). Каждый телевизор, привязанный к этому календарю, загружает материалы на неделю вперёд и воспроизводит то, что запланировано, по часам — без того, чтобы кто-то нажимал Start. Поскольку файлы уже загружены, воспроизведение продолжается, даже если Wi-Fi пропадает.

</div>

:::tip
FreePlay Admin использует ваш логин ChurchApps — тот же, что и для B1 Admin. Отдельную учётную запись создавать не нужно.
:::

## Как это устроено

FreePlay Admin имеет четыре основных раздела, перечисленных в верхней части сайта:

- **[Экраны](./managing-screens)** — подключённые телевизоры, их статус и **группы экранов**, в которые они входят. Экраны одной группы используют один календарь и один цикл по умолчанию
- **[Плейлисты](./building-playlists)** — циклы изображений и видео, которые вы выбираете у своих поставщиков контента
- **[Календарь](./scheduling-the-calendar)** — что и когда воспроизводит каждая группа экранов
- **[Поставщики](./building-playlists#connecting-providers)** — источники контента, из которых берут материалы ваши плейлисты. Каждого поставщика вы подключаете один раз для всей церкви

Когда ничего не запланировано, экраны группы воспроизводят её **цикл по умолчанию**. Если у группы нет цикла по умолчанию, экраны гаснут.

## Чем отличается от режима плана

- **[Режим плана](../plan-mode/)** следует за одним типом служебного плана из B1 Admin. Кто-то нажимает **Start Plan** на телевизоре, и урок начинает воспроизводиться в этот момент
- **Режим по расписанию** следует за календарём. Материалы начинаются и заканчиваются в заданное вами время, поэтому он хорошо подходит для информационных экранов в фойе, циклов объявлений и классов, где урок должен быть на экране до прихода всех

Запись в календаре всё равно может воспроизводить служебный план. Выберите тип плана в разделе **Service plans** при добавлении расписания, и экран будет воспроизводить тот план, который в этот неделю является текущим в B1 Admin. Сюда входят уроки Go Curriculum, даже те, которые вы изменили в плане. Экран использует логин Go Curriculum, привязанный к служению, которому принадлежит тип плана в B1 Admin, или подключение церкви к Go Curriculum, если у служения его нет.

## Начало работы

Пока вы не выполните каждый из этих шагов, на странице **Screens** будет показан список **Get started** со ссылкой на каждый шаг:

1. **Подключите поставщика** — свяжите Dropbox, OneDrive, Lessons.church или другой источник на странице **Providers**
2. **Создайте плейлист** — выберите изображения и видео у поставщика
3. **Поместите его в календарь** — выберите, что и когда играет, или задайте цикл по умолчанию для группы
4. **Подключите экран** — введите четырёхбуквенный код, который показан на телевизоре

Нажмите **Hide**, чтобы скрыть список.

:::tip
Нажмите **Ctrl+K** (**⌘K** на Mac) или щёлкните поле поиска в шапке, чтобы открыть палитру команд. Оттуда можно перейти на любую страницу или запустить действие, например **Pair screen**, **Add playlist** или **Add schedule**.
:::
