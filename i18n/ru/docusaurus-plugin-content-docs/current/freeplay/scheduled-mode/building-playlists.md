# Подключение провайдеров и создание плейлистов

<div class="article-intro">

Плейлист — это цикл изображений и видео, который вы ставите в календарь. В FreePlay Admin вы подключаете провайдеров контента один раз для всей церкви. Затем создаёте плейлисты, выбирая файлы из этих провайдеров.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Войдите в FreePlay Admin по адресу [admin.freeplay.church](https://admin.freeplay.church)
- Имейте логин для любой учётной записи провайдера, которую хотите подключить, например Dropbox или OneDrive

</div>

## Подключение провайдеров {#connecting-providers}

Страница **Providers** показывает ваши источники контента в двух разделах:

- **Connected** - Провайдеры, которые можно использовать прямо сейчас. Публичные провайдеры, которым не нужен вход, например Lessons.church и Bible Project, всегда отображаются здесь как **Public · no sign-in needed**. Подключённые учётные записи показывают **Account linked** и срок окончания подключения.
- **Available** - Провайдеры, для которых нужно войти в систему, прежде чем их можно будет использовать.

Чтобы подключить провайдера:

1. Перейдите в **Providers**.
2. Найдите провайдера в разделе **Available** и нажмите **Connect**.
3. Войдите в свою учётную запись у этого провайдера:
   - Некоторые провайдеры, например Dropbox, Google Drive и OneDrive, открывают всплывающее окно входа. Если ничего не появилось, разрешите всплывающие окна для admin.freeplay.church.
   - Другие провайдеры показывают ссылку и код. Перейдите по ссылке, введите код и подтвердите доступ. Диалог обновится сам, когда вы закончите.
4. Когда появится сообщение **Account linked successfully!**, провайдер перейдёт в раздел **Connected**.

У подключённых провайдеров есть три действия:

- **Browse** - Просмотреть папки провайдера
- **Refresh** - Продлить вход у провайдера
- **Unlink** - Отключить учётную запись

:::info
Подключения провайдеров в FreePlay Admin принадлежат всей церкви, а не одному человеку или одному телевизору. Запланированные экраны получают файлы через эти подключения, поэтому не нужно входить в каждого провайдера на каждом телевизоре.
:::

**FreeShow** отображается как **On your church network · each TV finds it itself**. Для него в FreePlay Admin ничего подключать не нужно.

## Страница плейлистов

На странице **Playlists** каждый плейлист показан с количеством элементов, общей длительностью, местом использования (**Default loop** для группы или количеством расписаний) и датой последнего обновления. В каждой строке есть такие действия:

- **Present** - Воспроизвести плейлист на весь экран в браузере
- **Edit** - Открыть редактор плейлиста
- **Duplicate** - Создать копию с названием «(copy)»

## Создание плейлиста

1. Перейдите в **Playlists** и нажмите **Add playlist**.
2. Введите **Name**, например «Welcome loop».
3. Нажмите **Add playlist**. Откроется редактор плейлиста.

## Добавление элементов

В редакторе плейлиста слева показаны **Items** вашего плейлиста, а справа — **Add from provider**.

1. Справа выберите вкладку провайдера. Чтобы добавить другой источник, нажмите **Connect another** — откроется страница **Providers**.
2. Нажимайте на папки, чтобы открыть их. Используйте цепочку навигации (breadcrumb), чтобы вернуться назад.
3. Нажмите на файл, чтобы добавить его в конец плейлиста. Файлы, уже находящиеся в плейлисте, отмечены как выбранные.
4. Чтобы добавить сразу всё из текущей папки, нажмите **Add all**. На кнопке показано, сколько файлов ещё не добавлено в плейлист.
5. Нажмите **Save** вверху редактора.

:::warning
Изменения не сохраняются, пока вы не нажмёте **Save**. Нажмите **Cancel**, чтобы выйти без сохранения.
:::

## Упорядочивание элементов

В списке **Items** слева:

- **Reorder** - Перетащите элемент за его маркер слева
- **Image timing** - Изображения показываются по 10 секунд по умолчанию. Измените количество секунд рядом с изображением
- **Videos** - Видео показываются с режимом **Plays to end** и проигрываются на всю свою длину
- **Remove** - Удалить элемент из плейлиста

Сводка вверху показывает количество элементов и общую длительность плейлиста.

## Переименование, дублирование и удаление

Панель слева в редакторе показывает, где используется плейлист. Там также есть такие действия:

- **Present** - Воспроизвести плейлист в браузере
- **Rename** - Изменить название плейлиста
- **Duplicate** - Создать копию для отдельного редактирования
- **Delete** - Удалить плейлист. Расписания, которые его проигрывают, переключаются на стандартный цикл группы (default loop)

## Показ плейлиста в браузере

Нажмите **Present**, чтобы воспроизвести плейлист на весь экран в браузере. Это удобно для предварительного просмотра плейлиста или для показа с ноутбука, подключённого к проектору. Наведите мышь, чтобы появилась панель управления, затем используйте эти клавиши:

| Клавиша | Действие |
|---|---|
| **Space** | Пауза или продолжение |
| **←** / **→** | Предыдущий или следующий элемент |
| **F** | Включить или выключить полноэкранный режим |
| **Esc** | Выход |
