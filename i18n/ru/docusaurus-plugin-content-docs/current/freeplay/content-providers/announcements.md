# Объявления

<div class="article-intro">

FreePlay может зацикливать папку со слайдами объявлений на вашем телевизоре — например, в холле или перед началом занятий. Вы выбираете папку у одного из подключенных провайдеров контента, FreePlay загружает её слайды на устройство, и в боковой панели появляется пункт **Announcements**, чтобы запустить цикл в любой момент.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- [Подключите провайдера контента](./connecting-providers), на котором хранятся ваши слайды объявлений, например Dropbox или OneDrive
- Поместите изображения или видео, которые хотите зацикливать, в одну папку у этого провайдера

</div>

## Выбор папки объявлений

1. Откройте **Settings** внизу боковой панели, затем выберите **Providers**
2. Выберите подключенного провайдера, на котором хранятся слайды (он отмечен значком **Connected**), чтобы открыть его **Provider Settings**
3. Выберите **Use for Announcements**
4. Откроется обозреватель **Choose the Announcements Folder**. Перемещайтесь по папкам, пока не найдете нужную с вашими слайдами, затем выберите эту папку (или любой файл внутри неё)
5. FreePlay загрузит слайды и вернется в **Provider Settings**, где строка теперь показывает **Looping "*название папки*" -- *количество* слайдов загружено**

Одновременно для объявлений используется только одна папка. Если выбрать папку у другого провайдера, она заменит предыдущую.

## Воспроизведение объявлений

Когда слайды загружены, в верхней части боковой панели появляется пункт **Announcements** (ниже **Today's Plan**, если ваш телевизор его показывает). Выберите его, чтобы запустить цикл.

- Изображения остаются на экране 15 секунд, если провайдер не задает файлу собственную длительность
- Видео проигрываются до конца, прежде чем перейти к следующему слайду
- После последнего слайда цикл начинается сначала
- Если в папке одно видео, оно повторяется на месте

Цикл воспроизводится из файлов, сохраненных на устройстве, поэтому работает без подключения к интернету. Для управления можно использовать те же кнопки пульта, что и для любого другого контента — см. [Воспроизведение контента](./playing-content).

## Обновление слайдов

FreePlay проверяет папку объявлений при каждом запуске приложения, загружает новые слайды и удаляет слайды, которые были удалены из папки.

Чтобы проверить сразу, откройте **Provider Settings** провайдера и выберите **Check for Announcement Updates**. По завершении строка покажет **Up to date** с количеством слайдов.

:::info
Если FreePlay не может связаться с провайдером или папка оказывается пустой, он продолжает воспроизводить уже имеющиеся слайды. Чтобы полностью прекратить использование объявлений, отключите их, как описано ниже.
:::

:::warning
Слайд, который заменен новой версией под тем же именем файла, повторно не загружается. Чтобы изменить слайд, добавьте его как новый файл и удалите старый.
:::

## Отключение объявлений

Откройте **Provider Settings** провайдера и снова выберите **Use for Announcements**. FreePlay перестанет использовать папку, удалит загруженные слайды с устройства и уберет **Announcements** из боковой панели.

Отключение провайдера также отключает объявления, которые пришли от него.
