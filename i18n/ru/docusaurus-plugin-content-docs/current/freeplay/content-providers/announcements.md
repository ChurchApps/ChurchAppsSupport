# Объявления

<div class="article-intro">

FreePlay может циклировать папку слайдов объявлений на вашем телевизоре - например, в холле или перед началом занятий. Вы выбираете папку из одного из подключенных поставщиков контента, FreePlay загружает его слайды на устройство, и элемент **Announcements** появляется на боковой панели, чтобы вы могли запустить цикл в любое время.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- [Подключитесь к поставщику контента](./connecting-providers), который хранит ваши слайды объявлений, такой как Google Drive или Dropbox
- Поместите изображения или видео, которые вы хотите циклировать, вместе в одну папку в этом поставщике

</div>

## Выбор папки объявлений

1. Откройте **Settings** в нижней части боковой панели, затем выберите **Providers**
2. Выберите подключенного поставщика, который хранит ваши слайды (он показывает значок **Connected**), чтобы открыть его **Provider Settings**
3. Выберите **Use for Announcements**
4. Открывается браузер **Choose the Announcements Folder**. Перемещайтесь по папкам, пока не достигнете той, которая содержит ваши слайды, затем выберите эту папку (или любой файл внутри нее)
5. FreePlay загружает слайды и возвращается в **Provider Settings**, где строка теперь читает **Looping "*folder name*" -- *number* slides downloaded**

Для объявлений одновременно используется только одна папка. Выбор папки у другого поставщика заменяет предыдущую.

## Воспроизведение объявлений

После загрузки слайдов элемент **Announcements** появляется в верхней части боковой панели (под **Today's Plan**, если ваш телевизор его показывает). Выберите его, чтобы начать цикл.

- Изображения остаются на экране в течение 15 секунд, если поставщик не дает файлу его собственную длительность
- Видео воспроизводятся до конца, прежде чем перейти к следующему слайду
- После последнего слайда цикл начинается с первого
- Если папка содержит один видеофайл, он повторяется на месте

Цикл воспроизводится из файлов, сохраненных на устройстве, поэтому он продолжает работать без подключения к интернету. Вы можете использовать те же средства управления пультом, что и любой другой контент - см. [Playing Lessons](../classroom-mode/playing-lessons).

## Обновление слайдов

FreePlay проверяет папку объявлений каждый раз при запуске приложения, загружает любые новые слайды и удаляет слайды, которые были удалены из папки.

Чтобы проверить прямо сейчас, откройте **Provider Settings** поставщика и выберите **Check for Announcement Updates**. Строка показывает **Up to date** с количеством слайдов по завершении.

:::info
Если FreePlay не может связаться с поставщиком, или папка возвращается пустой, он продолжает воспроизводить уже имеющиеся слайды. Чтобы полностью отключить объявления, отключите их, как описано ниже.
:::

:::warning
Слайд, который заменяется новой версией в том же файле, загружается не снова. Чтобы изменить слайд, добавьте его как новый файл и удалите старый.
:::

## Отключение объявлений

Откройте **Provider Settings** поставщика и снова выберите **Use for Announcements**. FreePlay прекращает использовать папку, удаляет загруженные слайды с устройства и удаляет **Announcements** из боковой панели.

Отключение поставщика также отключает объявления, поступающие от него.
