# Просмотр и загрузка контента

<div class="article-intro">

Подключившись к провайдеру контента, вы можете просматривать его библиотеку, загружать файлы и воспроизводить их на телевизоре. Браузер контента представляет собой наглядную сетку папок и файлов, по которой вы перемещаетесь с помощью пульта телевизора.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Подключитесь хотя бы к одному провайдеру контента -- см. [Подключение провайдеров](./connecting-providers)
- Держите пульт телевизора под рукой для навигации

</div>

## Браузер контента

Браузер контента отображает элементы в виде сетки карточек из 3 столбцов. Каждая карточка показывает миниатюру и название. Есть два типа элементов:

- **Папки** -- представлены миниатюрой или значком папки. Выберите папку, чтобы увидеть её содержимое
- **Файлы** -- отдельные медиафайлы (видео или изображения). На миниатюрах видео отображается значок воспроизведения

Заголовок в верхней части экрана показывает название текущей папки или название провайдера, если вы находитесь в корне.

## Навигация по папкам

1. С помощью пульта выделите папку
2. Нажмите **Select**, чтобы открыть её
3. Браузер загрузит содержимое папки, которое может состоять из других папок или воспроизводимых файлов
4. Нажмите **Back** на пульте, чтобы подняться на один уровень выше

Вы можете углубляться настолько, насколько позволяет структура контента провайдера. Браузер запоминает путь по папкам, чтобы вы могли вернуться назад через каждый уровень.

## Просмотр Lessons.church

Библиотека [Lessons.church](../../lessons-church/) организована так же, как и её сайт. На верхнем уровне вы увидите две папки:

- **Lessons** -- переходите по **программе**, затем по **курсу**, затем по **уроку**. У каждого урока затем указаны его **варианты**, то есть версии урока для определённой возрастной группы или формата, например Дошкольники или Младшие классы. Выберите вариант, чтобы открыть экран загрузки этой версии урока
- **Add-Ons** -- дополнительные видео и материалы, сгруппированные по категориям

На любом уровне нажмите **Back**, чтобы подняться на один шаг.

## Загрузка и воспроизведение контента

Когда вы выбираете папку, содержащую воспроизводимые файлы (или отдельный файл), FreePlay показывает название материала с обложкой и два варианта:

- **Download** -- сохранить все файлы на телевизоре заранее, чтобы воспроизведение не зависело от Wi-Fi. Индикатор прогресса заполняется по мере сохранения каждого файла. Когда всё готово, появляется кнопка **Start** со значком воспроизведения. Нажмите **Select**, чтобы начать воспроизведение
- **Stream** -- начать воспроизведение сразу через интернет без сохранения файлов

:::tip
Загружайте уроки до воскресного утра, пока в вашем здании хорошее интернет-соединение. После загрузки контент воспроизводится офлайн, а при повторном воспроизведении он запускается мгновенно, без повторной загрузки.
:::

## Управление загрузками

Откройте **Settings** внизу боковой панели, затем выберите **Downloads**, чтобы увидеть всё, что сохранено на этом телевизоре:

- Выберите загрузку, чтобы воспроизвести её
- Выделите загрузку и выберите значок удаления в её углу, чтобы удалить её и освободить место

Если на экране написано **No downloads yet**, на этот телевизор ещё ничего не сохранено.

## Воспроизведение контента провайдера

Во время воспроизведения используйте следующие элементы управления:

- **Стрелка вправо** -- следующий элемент
- **Стрелка влево** -- предыдущий элемент
- **Select / Play-Pause** -- пауза или продолжение видео
- **Стрелка вверх** -- открыть выбор сообщений, чтобы перейти к конкретному элементу
- **Back** -- выйти в браузер контента

Когда вы выходите из плеера, вы возвращаетесь в браузер контента на корневом уровне текущего провайдера.

:::info
Полный справочник по всем элементам управления плеером см. в разделе [Воспроизведение контента](./playing-content).
:::

## Переключение между провайдерами

Подключённые провайдеры отображаются как элементы под заголовком **Browse** на боковой панели слева. Чтобы переключиться на другого провайдера:

1. Нажмите стрелку **Влево** на пульте, чтобы развернуть боковую панель
2. Выберите провайдера, библиотеку которого хотите просмотреть
3. Браузер контента обновится и покажет библиотеку этого провайдера

:::warning
Если папка показывает «No content available», у провайдера нет элементов на этом уровне. Попробуйте перейти в другую папку или проверить позже.
:::
