# Просмотр и загрузка контента

<div class="article-intro">

Как только вы подключились к поставщику контента, вы можете просматривать его библиотеку, загружать файлы и воспроизводить их на телевизоре. Браузер контента предоставляет визуальную сетку папок и файлов, которые вы навигируете с помощью пульта ТВ.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Подключитесь по крайней мере к одному поставщику контента -- см. [Подключение к провайдерам](./connecting-providers)
- Держите пульт ТВ готовым для навигации

</div>

## Браузер контента

Браузер контента отображает элементы в 3-столбцовой сетке карточек. Каждая карточка показывает миниатюру изображения и заголовок. Есть два типа элементов:

- **Папки** - Представлены миниатюрой или иконкой папки. Выберите папку, чтобы увидеть его содержимое.
- **Файлы** - Отдельные медиа-элементы (видео или изображения). Видео-файлы отображают иконку воспроизведения на своей миниатюре.

Заголовок вверху экрана показывает имя текущей папки или имя провайдера, если вы находитесь на уровне корня.

## Навигация по папкам

1. Используйте дополнительную клавишу на пульте для выделения папки
2. Нажмите **Select**, чтобы открыть ее
3. Браузер загружает содержимое папки, которое может быть больше папок или воспроизводимых файлов
4. Нажмите **Back** на пульте, чтобы подняться на один уровень

Вы можете проходить столько глубины, сколько позволяет структура контента провайдера. Браузер отслеживает ваш путь папки, чтобы вы могли навигировать назад через каждый уровень.

## Загрузка и воспроизведение контента

Когда вы выбираете папку, которая содержит воспроизводимые файлы (или выбираете отдельный файл), FreePlay переходит на экран загрузки:

1. Заголовок контента появляется на экране с изображением обложки из выбранной папки
2. Полоса прогресса показывает **Downloading item X of Y** при сохранении файлов на устройство
3. После завершения загрузки кнопка **Start** появляется с иконкой воспроизведения
4. Нажмите **Select**, чтобы начать воспроизведение

:::tip
Загруженный контент кэшируется на телевизоре. Если вы воспроизводите тот же контент позже, он загружается мгновенно без пересборки.
:::

## Воспроизведение контента провайдера

Воспроизведение работает так же, как воспроизведение урока. Используйте эти элементы управления:

- **Стрелка вправо** - Следующий элемент
- **Стрелка влево** - Предыдущий элемент
- **Select / Play-Pause** - Пауза или возобновление видео
- **Стрелка вверх** - Откройте selector сообщений для перехода к определенному элементу
- **Back** - Выход в браузер контента

Когда вы выходите из плеера, вы возвращаетесь в браузер контента на уровне корня текущего провайдера.

:::info
Для полной ссылки на все элементы управления плеером см. [Воспроизведение уроков](../classroom-mode/playing-lessons).
:::

## Переключение между провайдерами

Подключенные провайдеры появляются как элементы в разделе **Browse** боковой панели слева. Для переключения на другой провайдер:

1. Нажмите стрелку **Left** на пульте, чтобы развернуть боковую панель
2. Выберите провайдера, который вы хотите просматривать
3. Браузер контента обновляется библиотекой этого провайдера

:::warning
Если папка показывает "No content available", провайдер не имеет никаких элементов на этом уровне. Попробуйте навигировать к другой папке или проверить позже.
:::
