# Просмотр и загрузка контента

<div class="article-intro">

После подключения к поставщику контента вы можете просматривать его библиотеку, загружать файлы и воспроизводить их на телевизоре. Браузер контента показывает визуальную сетку папок и файлов, по которой вы перемещаетесь с помощью пульта телевизора.

</div>

<div class="prereqs">
<h4>Перед началом работы</h4>

- Подключитесь как минимум к одному поставщику контента — см. [Подключение к провайдерам](./connecting-providers.md)
- Убедитесь, что пульт телевизора под рукой для навигации

</div>

## Браузер контента

Браузер контента отображает элементы в виде сетки карточек из 3 столбцов. Каждая карточка показывает миниатюру и название. Существует два типа элементов:

- **Папки** — обозначаются миниатюрой или значком папки. Выберите папку, чтобы увидеть её содержимое.
- **Файлы** — отдельные медиафайлы (видео или изображения). На миниатюрах видеофайлов отображается значок «воспроизведение».

В заголовке в верхней части экрана показано название текущей папки или название провайдера, если вы находитесь на корневом уровне.

## Навигация по папкам

1. С помощью крестовины на пульте выделите папку
2. Нажмите **OK**, чтобы открыть её
3. Браузер загрузит содержимое папки, которое может состоять из других папок или файлов для воспроизведения
4. Нажмите **Назад** на пульте, чтобы подняться на один уровень выше

Вы можете углубляться в структуру контента провайдера настолько, насколько она позволяет. Браузер запоминает путь к папкам, так что вы можете вернуться назад через каждый уровень.

## Просмотр Lessons.church

Библиотека [Lessons.church](../../lessons-church/index.md) организована так же, как и их сайт. На верхнем уровне вы увидите две папки:

- **Lessons** — переходите по **программе**, затем по **исследованию**, затем по **уроку**. Каждый урок затем показывает свои **площадки** — версии урока для определённой возрастной группы или формата, например «Дошкольники» или «Начальная школа». Выберите площадку, чтобы открыть экран загрузки этой версии урока.
- **Add-Ons** — дополнительные видео и материалы, сгруппированные по категориям

Нажмите **Назад** на любом уровне, чтобы вернуться на шаг выше.

## Просмотр Go Curriculum

После того как вы [войдёте в свою учётную запись gocurriculum.com](./connecting-providers.md#phone-sign-in-qr-code-only), Go Curriculum откроется со списком возрастных групп: **Elementary** и **Preschool**. Переходите по возрастной группе, затем по коллекции, затем по уроку, и выберите урок, чтобы открыть его экран загрузки.

Что вы увидите, зависит от вашей подписки Go:

- Отображаются только те возрастные группы, которые входят в вашу подписку. Если в вашей учётной записи нет подписки Go, библиотека будет пустой.
- Некоторые видео доступны только для определённых уровней подписки. Видео, которые не входят в вашу подписку, не будут включены в урок.

## Загрузка и воспроизведение контента

Когда вы выбираете папку, содержащую файлы для воспроизведения (или отдельный файл), FreePlay показывает название контента с обложкой и два варианта:

- **Скачать** — сначала сохранить все файлы на телевизор, чтобы воспроизведение не зависело от Wi-Fi. Индикатор выполнения заполняется по мере сохранения каждого файла. Когда всё готово, появляется кнопка **Старт** со значком воспроизведения. Нажмите **OK**, чтобы начать воспроизведение.
- **Потоковое воспроизведение** — начать воспроизведение сразу через интернет, не сохраняя файлы.

:::tip
Загрузите уроки до воскресного утра, пока в вашем здании стабильное подключение к интернету. После загрузки контент воспроизводится без сети, а при повторном воспроизведении загружается мгновенно, без повторной загрузки.
:::

## Управление загрузками

Откройте **Настройки** внизу боковой панели, затем выберите **Загрузки**, чтобы увидеть всё, что сохранено на этом телевизоре:

- Выберите загрузку, чтобы воспроизвести её
- Выделите загрузку и выберите значок удаления в её углу, чтобы удалить её и освободить место

Если на экране написано **Загрузок пока нет**, на этот телевизор ничего не сохранено.

## Воспроизведение контента провайдера

Во время воспроизведения используйте следующие кнопки:

- **Стрелка вправо** — следующий элемент
- **Стрелка влево** — предыдущий элемент
- **OK / Пауза-Воспроизведение** — приостановить или возобновить видео
- **Стрелка вверх** — открыть выбор сообщений, чтобы перейти к конкретному элементу
- **Назад** — выйти в браузер контента

Когда вы выходите из проигрывателя, вы возвращаетесь в браузер контента на корневом уровне текущего провайдера.

:::info
Полный справочник по всем кнопкам проигрывателя см. в разделе [Воспроизведение контента](./playing-content.md).
:::

## Переключение между провайдерами

Подключённые провайдеры отображаются как элементы в разделе **Обзор** на боковой панели слева. Чтобы переключиться на другого провайдера:

1. Нажмите стрелку **влево** на пульте, чтобы развернуть боковую панель
2. Выберите провайдера, библиотеку которого хотите просмотреть
3. Браузер контента обновится и покажет библиотеку этого провайдера

:::warning
Если папка показывает «Нет доступного контента», у провайдера нет элементов на этом уровне. Попробуйте перейти в другую папку или проверить позже.
:::
