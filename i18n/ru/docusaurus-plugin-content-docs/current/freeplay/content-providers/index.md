# Провайдеры контента

<div class="article-intro">

Провайдеры контента — это внешние сервисы, предоставляющие учебные материалы, видео и изображения для воспроизведения на вашем телевизоре. FreePlay поддерживает несколько провайдеров, позволяя просматривать и загружать контент из разных источников в одном приложении.

</div>

## Доступные провайдеры

В настоящее время FreePlay включает следующих провайдеров:

- **[Lessons.church](../../lessons-church/)** - Бесплатная программа для детского служения с открытым исходным кодом
- **Bible Project** - Видео и материалы для изучения Библии
- **SignPresenter** - Презентации и контент для информационных табло церквей
- **B1.church** - Контент из вашей собственной настройки B1.church
- **Go Curriculum** - Программа с gocurriculum.com, организованная по коллекциям и урокам

:::info
Некоторые провайдеры пока добавляются. Если на карточке провайдера написано «Coming Soon», он ещё недоступен для подключения.
:::

## Как работают провайдеры

У каждого провайдера есть собственная библиотека контента, организованная в папки и файлы. После подключения к провайдеру его контент отображается в обозревателе папок, где можно переходить по категориям, выбирать элементы и загружать их для воспроизведения.

Подключённые провайдеры отображаются в боковой панели слева. Вы можете переключаться между провайдерами, выбирая их в боковой панели, что позволяет легко перемещаться между источниками контента во время настройки.
