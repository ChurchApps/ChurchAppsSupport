# Провайдеры контента

<div class="article-intro">

Провайдеры контента — это внешние сервисы, которые предоставляют учебные материалы, видео и изображения для воспроизведения на вашем телевизоре. FreePlay поддерживает несколько провайдеров, позволяя просматривать и загружать контент из разных источников в одном приложении.

</div>

## Доступные провайдеры

FreePlay сейчас включает следующих провайдеров:

- **[Lessons.church](../../lessons-church/)** - Бесплатная, открытая учебная программа для детского служения
- **Bible Project** - Видео и материалы, исследующие Библию
- **SignPresenter** - Презентации и информационный контент для церквей
- **B1.church** - Контент из вашей собственной настройки B1 church
- **Go Curriculum** - Учебная программа с gocurriculum.com, организованная по коллекциям и урокам
- **Dropbox** - Просмотр и воспроизведение изображений и видео из вашего собственного Dropbox
- **Jesus Film Project** - Фильмы и видеоклипы из Jesus Film Project
- **OneDrive** - Просмотр и воспроизведение изображений, видео и аудио из вашего собственного Microsoft OneDrive

:::note
Google Drive и FreeShow больше не отображаются в приложении FreePlay для ТВ. Чтобы использовать контент из Google Drive на своих телевизорах, подключите его в [FreePlay Admin](../scheduled-mode/building-playlists#connecting-providers), добавьте файлы в плейлист и запланируйте этот плейлист.
:::

:::info
Некоторые провайдеры всё ещё добавляются. Если карточка провайдера показывает «Coming Soon», значит, подключить его пока нельзя.
:::

## Как работают провайдеры

У каждого провайдера есть собственная библиотека контента, организованная в папки и файлы. Как только вы подключаетесь к провайдеру, его контент появляется в браузере папок, где вы можете переходить по категориям, выбирать элементы и загружать их для воспроизведения.

Подключённые провайдеры отображаются на боковой панели слева, в разделе **Browse**. Переключаться между провайдерами можно, выбирая их на боковой панели, что упрощает переход между источниками контента во время настройки.

Вы также можете выбрать папку из любого подключённого провайдера, чтобы зациклить её как [объявления](./announcements) на своём телевизоре.

:::tip
Провайдеры, которых вы подключаете на самом телевизоре, предназначены только для этого телевизора. Если вы используете [Scheduled Mode](../scheduled-mode/), подключайте провайдеров один раз в FreePlay Admin — тогда каждый запланированный экран сможет воспроизводить контент из них.
:::
