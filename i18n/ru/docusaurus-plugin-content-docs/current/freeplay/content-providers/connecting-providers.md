# Подключение к провайдерам

<div class="article-intro">

Прежде чем вы сможете просматривать контент от провайдера, необходимо подключиться к нему. Некоторые провайдеры требуют аутентификации через QR-код или вход по электронной почте, а другие можно подключить одним нажатием.

</div>

<div class="prereqs">
<h4>Прежде чем начать</h4>

- Установите и запустите FreePlay -- см. [Начало работы](../getting-started/)
- Держите пульт от телевизора под рукой для навигации
- Для провайдеров, требующих входа, подготовьте учётные данные вашей учётной записи

</div>

:::tip Настраиваете B1 Admin и FreePlay вместе?
Наше **<a href="/guides/freeplay-b1admin" target="_blank">пошаговое руководство</a>** проведёт вас через привязку B1 Admin, планирование урока и подключение FreePlay — всё в одном месте. Откройте его в новой вкладке, чтобы следовать инструкциям.
:::

## Просмотр доступных провайдеров

1. Откройте экран **Content Providers** в боковой панели (выберите значок **Providers** внизу)
2. Вы увидите сетку карточек провайдеров, на каждой из которых отображается логотип и название провайдера
3. Подключённые провайдеры отображают зелёный значок **Connected** под своим названием
4. Провайдеры, которые пока недоступны, отмечены меткой **Coming Soon**

## Подключение без аутентификации

Некоторые провайдеры не требуют входа. Когда вы выбираете такого провайдера, FreePlay подключается немедленно и открывает браузер контента. Учётные данные не нужны.

## Аутентификация через device flow (QR-код)

Некоторые провайдеры используют device flow, похожий на вход в потоковые приложения на телевизоре:

1. Выберите карточку провайдера на экране **Content Providers**
2. FreePlay отобразит QR-код и URL для подтверждения
3. Отсканируйте QR-код телефоном или откройте показанный URL на любом устройстве
4. Введите код пользователя, показанный на экране телевизора
5. Завершите процесс входа на телефоне или компьютере
6. FreePlay обнаружит успешный вход и отобразит **Connected!**
7. Браузер контента откроется автоматически

:::info
Пульсирующий индикатор **Waiting for authorization** показывает, что FreePlay проверяет ваш вход. Код действителен несколько минут, поэтому завершите процесс как можно быстрее.
:::

**Go Curriculum** использует ту же схему входа по QR-коду -- отсканируйте код и войдите с помощью учётной записи gocurriculum.com, чтобы подключиться.

## Вход через форму

Другие провайдеры используют традиционный вход по электронной почте и паролю:

1. Выберите карточку провайдера
2. Введите **Email** и **Password** с помощью экранной клавиатуры
3. Выберите кнопку **Sign In**
4. Если учётные данные верны, FreePlay отобразит **Connected!** и откроет браузер контента

:::tip
Используйте направленную клавиатуру пульта, чтобы переключаться между полем email, полем пароля и кнопкой входа. Нажмите **Select** на текстовом поле, чтобы открыть экранную клавиатуру.
:::

## Отключение провайдера

Чтобы отключиться от уже подключённого провайдера:

1. Перейдите на экран **Content Providers**
2. Выберите карточку провайдера со значком **Connected**
3. Появится запрос на подтверждение отключения
4. Выберите **Disconnect**, чтобы удалить подключение

После отключения контент провайдера больше не будет отображаться в боковой панели.

:::warning
Отключение удаляет сохранённую аутентификацию с вашего устройства. Чтобы снова подключиться позже, потребуется повторный вход.
:::
