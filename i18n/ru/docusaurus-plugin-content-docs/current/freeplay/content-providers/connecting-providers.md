# Подключение к провайдерам

<div class="article-intro">

Прежде чем просматривать контент провайдера, необходимо подключиться к нему. Некоторые провайдеры требуют авторизации через QR-код или вход по электронной почте, а другие можно подключить одним нажатием.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Установите и запустите FreePlay -- см. [Начало работы](../getting-started/)
- Держите пульт телевизора под рукой для навигации
- Для провайдеров, требующих входа, подготовьте учётные данные своей учётной записи

</div>

:::tip Настраиваете B1 Admin и FreePlay вместе?
Наше **<a href="/guides/freeplay-b1admin" target="_blank">пошаговое руководство</a>** проведёт вас через привязку B1 Admin, планирование урока и подключение FreePlay — всё в одном месте. Откройте его в новой вкладке, чтобы следовать инструкциям.
:::

## Просмотр доступных провайдеров

1. Откройте **Settings** внизу боковой панели, затем выберите **Providers**, чтобы открыть экран **Content Providers**
2. Вы увидите сетку карточек провайдеров, на каждой из которых показан логотип и название провайдера
3. Подключённые провайдеры показывают зелёный значок **Connected** под своим названием
4. У провайдеров, которые пока недоступны, отображается надпись **Coming Soon**

## Подключение без авторизации

Некоторые провайдеры не требуют входа. Когда вы выбираете одного из них, FreePlay подключается сразу и открывает браузер контента. Учётные данные не нужны.

## Авторизация по схеме устройства (QR-код)

Некоторые провайдеры используют схему устройства, похожую на вход в стриминговые приложения на телевизоре:

1. Выберите карточку провайдера на экране **Content Providers**
2. FreePlay покажет экран **Connect to** с названием провайдера, QR-кодом и адресом для подтверждения
3. Отсканируйте QR-код телефоном или откройте указанный адрес на любом устройстве
4. Введите код, показанный на экране телевизора
5. Завершите вход на телефоне или компьютере
6. FreePlay обнаружит успешный вход и отобразит **Connected!**
7. Браузер контента откроется автоматически

:::info
Пульсирующий индикатор **Waiting for confirmation** показывает, что FreePlay проверяет ваш вход. На экране отображается, сколько минут осталось до истечения срока действия кода, поэтому завершите процесс без промедления. Если код истёк, выберите **Generate New Code**.
:::

## Вход через телефон (только QR-код)

**Dropbox**, **OneDrive** и **Go Curriculum** используют немного другой вход по QR-коду, без необходимости вводить код:

1. Выберите карточку провайдера на экране **Content Providers**
2. FreePlay покажет экран **Connect to** с названием провайдера и QR-кодом
3. Отсканируйте QR-код телефоном и войдите в свою учётную запись у этого провайдера (учётная запись Microsoft для OneDrive или учётная запись gocurriculum.com для Go Curriculum)
4. Подтвердите доступ. Телевизор подключится автоматически и отобразит **Connected!**

На экране показано, сколько минут у вас осталось, чтобы завершить вход.

## Вход через форму

Другие провайдеры используют традиционный вход по электронной почте и паролю:

1. Выберите карточку провайдера
2. Введите **Email** и **Password** с помощью экранной клавиатуры
3. Выберите кнопку **Sign In**
4. Если учётные данные верны, FreePlay отобразит **Connected!** и откроет браузер контента

:::tip
Используйте крестовину пульта, чтобы переходить между полем электронной почты, полем пароля и кнопкой входа. Нажмите **Select** в текстовом поле, чтобы открыть экранную клавиатуру.
:::

## Настройки провайдера

Выбор карточки провайдера со значком **Connected** открывает его экран **Provider Settings**:

- **Browse Library** -- показать или скрыть библиотеку этого провайдера на боковой панели
- **Auto-Download Today's Lesson** -- использовать этого провайдера как источник сегодняшнего урока и заранее загрузить его файлы (отображается только для провайдеров, которые предлагают текущий урок)
- **Use for Announcements** -- выбрать папку этого провайдера, которая будет циклически воспроизводиться из пункта **Announcements** на боковой панели. См. [Объявления](./announcements)
- **Check for Announcement Updates** -- появляется после выбора папки объявлений; загружает новые слайды и удаляет удалённые
- **Disconnect** -- разорвать подключение

## Отключение провайдера

Чтобы отключиться от уже подключённого провайдера:

1. Перейдите на экран **Content Providers** (**Settings** > **Providers**)
2. Выберите карточку провайдера со значком **Connected**
3. На экране **Provider Settings** выберите **Disconnect**

После отключения контент провайдера перестанет отображаться на боковой панели. Если вы использовали одну из его папок для объявлений, эти слайды также будут удалены.

:::warning
Отключение удаляет сохранённые данные авторизации с вашего устройства. Чтобы подключиться снова позже, потребуется войти заново.
:::
