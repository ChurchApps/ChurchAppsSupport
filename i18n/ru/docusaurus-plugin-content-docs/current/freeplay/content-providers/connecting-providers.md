# Подключение к провайдерам

<div class="article-intro">

Прежде чем вы сможете просматривать контент от провайдера, вам нужно подключиться к нему. Некоторые провайдеры требуют аутентификацию через QR код или вход по электронной почте, в то время как другие могут быть подключены с одним щелчком.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- Установите и запустите FreePlay -- см. [Начало работы](../getting-started/)
- Держите пульт ТВ готовым для навигации
- Для провайдеров, требующих входа, имейте учетные данные аккаунта в наличии

</div>

## Просмотр доступных провайдеров

1. Откройте **Settings** внизу боковой панели, затем выберите **Providers**, чтобы открыть экран **Content Providers**
2. Вы увидите сетку карточек провайдера, каждая показывающая логотип провайдера и имя
3. Подключенные провайдеры отображают зеленый badge **Connected** под их именем
4. Провайдеры, которые еще не доступны, показывают label **Coming Soon**

## Подключение без аутентификации

Некоторые провайдеры не требуют входа. Когда вы выбираете один из этих провайдеров, FreePlay подключается мгновенно и открывает браузер контента. Учетные данные не требуются.

## Аутентификация Device Flow (QR код)

Определенные провайдеры используют device flow, похожий на то, как вы входите в потоковые приложения на ТВ:

1. Выберите карточку провайдера на экране **Content Providers**
2. FreePlay отображает QR код и URL верификации
3. Отсканируйте QR код с помощью телефона или посетите отображаемый URL на любом устройстве
4. Введите код пользователя, показанный на экране ТВ
5. Завершите процесс входа на телефоне или компьютере
6. FreePlay обнаруживает успешный вход и отображает **Connected!**
7. Браузер контента открывается автоматически

:::info
Пульсирующий indicator **Waiting for authorization** показывает, что FreePlay проверяет ваш вход. Код истекает через несколько минут, поэтому завершите процесс быстро.
:::

**Go Curriculum** использует этот же QR-код шаблон входа -- отсканируйте код и войдите с вашим аккаунтом gocurriculum.com, чтобы подключиться.

## Форма входа

Другие провайдеры используют традиционный вход электронной почты и пароля:

1. Выберите карточку провайдера
2. Введите ваше **Email** и **Password**, используя встроенную клавиатуру
3. Выберите кнопку **Sign In**
4. Если ваши учетные данные верны, FreePlay отображает **Connected!** и открывает браузер контента

:::tip
Используйте дополнительную клавишу на пульте для перемещения между полем электронной почты, полем пароля и кнопкой входа. Нажмите **Select** на текстовом поле, чтобы открыть встроенную клавиатуру.
:::

## Поиск провайдера в вашей сети

**FreeShow** найден в вашей локальной сети вместо входа через sign-in: FreePlay ищет сеть, указывает каждый компьютер, работающий FreeShow, который он находит, и подключается к тому, который вы выбираете (выберите **Scan Again**, если никто не появляется).

## Параметры провайдера

Выбор карточки провайдера, которая показывает badge **Connected**, открывает его экран **Provider Settings**:

- **Browse Library** -- Показать или скрыть библиотеку контента этого провайдера в боковой панели
- **Auto-Download Today's Lesson** -- Используйте этого провайдера как источник урока сегодня и предварительно загрузьте его файлы (показывается только для провайдеров, которые предлагают текущий урок)
- **Use for Announcements** -- Выберите папку из этого провайдера для петли из элемента **Announcements** в боковой панели. См. [Announcements](./announcements)
- **Check for Announcement Updates** -- Показывается после выбора папки объявлений; загружает новые слайды и удаляет удаленные
- **Disconnect** -- Удалить подключение

## Отключение провайдера

Для отключения от провайдера, к которому вы уже подключились:

1. Перейдите на экран **Content Providers** (**Settings** > **Providers**)
2. Выберите карточку провайдера, которая показывает badge **Connected**
3. На экране **Provider Settings** выберите **Disconnect**

После отключения, контент провайдера больше не будет появляться в боковой панели. Если вы использовали одну из его папок для объявлений, эти слайды также удаляются.

:::warning
Отключение удаляет сохраненную аутентификацию с вашего устройства. Вам нужно будет войти снова, если вы хотите повторно подключиться позже.
:::
