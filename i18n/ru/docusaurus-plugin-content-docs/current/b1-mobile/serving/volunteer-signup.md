# Запись волонтеров

<div class="article-intro">

Просматривайте доступные должности волонтеров и записывайтесь на предстоящие служения прямо из B1 Mobile. Смотрите, какие должности нужно заполнить, сколько мест открыто, и присоединяйтесь к команде всего несколькими касаниями.

</div>

<div class="prereqs">
<h4>Перед началом</h4>

- [Установите B1 Mobile](../getting-started/installing) и [войдите](../getting-started/logging-in) в свою учетную запись
- Администратор вашей церкви должен включить самостоятельную запись хотя бы на одну должность

</div>

## Просмотр возможностей для волонтерства

1. Откройте раздел **Volunteer** в навигации приложения.
2. Появится список предстоящих планов служения с открытыми должностями. Если ваша церковь показывает только следующую неделю каждого типа плана, более поздние недели появятся, когда текущая пройдет.
3. Каждая карточка плана показывает:
   - **Название плана** и **дату служения**
   - **Общий индикатор прогресса** с количеством заполненных мест
   - **Статус** — количество оставшихся свободных мест или «Full», если все места заняты
   - **Метки должностей** с каждой ролью и количеством открытых мест
4. Нажмите **View and Sign Up**, чтобы увидеть полный список должностей плана.

## Запись на должность

1. Нажмите на план, чтобы открыть его детали.
2. Должности сгруппированы по категориям (например, «Band», «Hospitality», «Kids Ministry»).
3. Для каждой должности показаны название роли, описание и свободные места.
4. Нажмите **Sign Up** рядом с нужной должностью.
5. Появится подтверждающее уведомление: «You're signed up! Thank you for volunteering.»
6. У должности появится зеленый индикатор, подтверждающий вашу запись.

:::info
Чтобы записаться на должность, нужно быть авторизованным. При необходимости приложение предложит вам войти.
:::

## Отмена записи

1. Найдите должность, на которую вы записались, — на ней показан зеленый индикатор «You're signed up».
2. Нажмите **Remove**.
3. В диалоге подтверждения спросят, уверены ли вы.
4. Подтвердите, чтобы снять себя с должности.

## Сроки и вместимость

- **Сроки** — ваша церковь может установить крайний срок до начала служения. После него нельзя записываться или удалять записи. Баннер вверху плана показывает, что срок прошел.
- **Вместимость** — у каждой должности ограниченное количество мест. Когда мест нет, кнопка записи становится неактивной. Места снова освобождаются, если кто-то отменяет запись.

:::tip
Включите [push-уведомления](../community/notifications.md), чтобы быть в курсе новых возможностей для волонтерства и изменений в ваших назначениях.
:::
