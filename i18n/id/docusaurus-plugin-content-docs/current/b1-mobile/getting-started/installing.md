# Menginstal Aplikasi

:::danger B1 Mobile tidak lagi didukung. Silakan instal PWA sebagai gantinya
Aplikasi native B1 Mobile tidak lagi diperbarui. Kami menyarankan Anda menginstal **Progressive Web App (PWA) B1.church** dari situs gereja Anda (`https://yourchurchname.b1.church`). PWA ini dapat diinstal dari halaman mana pun. PWA dapat ditambahkan ke layar utama di iOS atau Android hanya dalam hitungan detik, dan mencakup semua fitur aplikasi native.

Lihat [Menginstal sebagai Aplikasi (PWA)](../../b1-church/getting-started/installing-pwa.md) untuk petunjuk langkah demi langkah.
:::

<div class="article-intro">

B1 Mobile tersedia untuk perangkat iOS dan Android. Aplikasi ini gratis diunduh dan hanya membutuhkan waktu sebentar untuk diinstal, sehingga Anda dapat mulai terhubung dengan gereja Anda.

</div>

## Unduh

- **iOS** -- Buka **App Store** di iPhone atau iPad Anda, lalu cari **B1.church**. Ketuk **Dapatkan** untuk mengunduh dan menginstal.
- **Android** -- Buka **Google Play Store** di perangkat Android Anda, lalu cari **B1.church**. Ketuk **Instal** untuk mengunduh dan menginstal.

Anda juga dapat mencari "B1 Mobile" jika pencarian pertama tidak menampilkan hasil.

## Setelah Menginstal

Setelah aplikasi terinstal, buka dari layar utama perangkat Anda. Anda akan melihat layar pencarian gereja, tempat Anda dapat menemukan dan memilih gereja Anda. Jika Anda sudah memiliki akun ChurchApps, Anda dapat langsung [masuk](./logging-in). Jika belum, Anda dapat membuat akun dari layar masuk.

Aplikasi akan meminta izin untuk mengirim notifikasi push. Kami menyarankan Anda mengizinkan notifikasi agar dapat menerima pembaruan dari gereja dan grup Anda.

:::tip
Izinkan notifikasi push saat diminta selama pengaturan. Hal ini memastikan Anda menerima pembaruan tepat waktu tentang [aktivitas grup](../groups/group-timeline.md), [pesan](../community/messaging.md), dan [tugas pelayanan](../serving/viewing-plans.md).
:::

## Memperbarui Aplikasi

B1 Mobile menerima pembaruan rutin dengan fitur dan peningkatan baru. Perangkat Anda biasanya memperbarui aplikasi secara otomatis, tetapi Anda juga dapat memeriksa pembaruan secara manual:

1. Buka **App Store** (iOS) atau **Google Play Store** (Android).
2. Cari **B1.church**.
3. Jika pembaruan tersedia, ketuk **Perbarui**.

:::info
B1 Mobile memerlukan iOS 14 atau yang lebih baru untuk perangkat Apple, dan Android 6.0 atau yang lebih baru untuk perangkat Android.
:::

## Gunakan PWA Sebagai Gantinya

Aplikasi native B1 Mobile sudah tidak didukung lagi dan digantikan oleh **Progressive Web App (PWA) B1.church**. PWA diinstal melalui Safari atau Chrome, tanpa perlu mengunduh dari App Store, dan merupakan pilihan yang direkomendasikan untuk setiap instalasi baru. Lihat [Menginstal sebagai Aplikasi (PWA)](/docs/b1-church/getting-started/installing-pwa) untuk petunjuk.
