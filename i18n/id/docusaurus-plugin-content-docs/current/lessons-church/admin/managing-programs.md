# Mengelola Program

<div class="article-intro">

Program adalah wadah tingkat atas untuk kurikulum di Lessons.church. Sebuah program mewakili seluruh rangkaian kurikulum, misalnya "Ark Kids" atau "Youth Foundations". Panduan ini membahas cara membuat, mengedit, dan mengatur program di area admin.

</div>

<div class="prereqs">
<h4>Sebelum Anda Mulai</h4>

- Pastikan Anda memiliki izin admin untuk Lessons.church (lihat [Ikhtisar Administrasi](./index.md))
- Siapkan nama program, deskripsi, dan gambar thumbnail

</div>

## Membuat Program

1. Buka area **Admin**.
2. Klik **Tambah Program**.
3. Isi kolom-kolom berikut:
   - **Nama** -- Nama tampilan untuk program (misalnya, "Ark Kids").
   - **Slug** -- Pengidentifikasi yang ramah URL (misalnya, "ark-kids"). Ini digunakan dalam alamat web.
   - **Deskripsi** -- Ringkasan singkat tentang isi program.
   - **Gambar** -- Unggah gambar thumbnail yang mewakili program.
4. Simpan program.

Program baru Anda sekarang akan muncul dalam daftar program admin dan, setelah memiliki studi dan pelajaran, di situs publik.

## Mengedit Program

1. Klik nama program dalam daftar admin.
2. Perbarui kolom mana pun (**Nama**, **Slug**, **Deskripsi**, atau **Gambar**).
3. Simpan perubahan Anda.

## Mengatur Studi dalam Program

Setelah program dibuat, Anda dapat menambahkan studi ke dalamnya. Studi akan tampil bersarang di bawah program pada tampilan admin. Klik panah perluas di samping program untuk melihat studinya, atau tambahkan studi baru dari sana. Lihat [Mengelola Studi](./managing-studies.md) untuk detailnya.

## Kategori Studi

Jika program Anda memiliki banyak studi, Anda dapat mengelompokkannya ke dalam **kategori**. Kategori mengelompokkan studi berdasarkan topik, rentang usia, atau kriteria lain yang Anda pilih. Hal ini memudahkan pengguna menelusuri program yang besar.

## Mengunggah Sumber Daya Tingkat Program

Anda dapat melampirkan berkas yang dapat diunduh ke sebuah program. Ini adalah sumber daya yang berlaku untuk program secara keseluruhan, bukan untuk studi atau pelajaran tertentu, misalnya dokumen cakupan dan urutan atau buku panduan relawan.

1. Buka program di tampilan admin.
2. Buka bagian **Sumber Daya**.
3. Unggah berkas Anda.

## Menghapus Cache

Setelah membuat perubahan pada program, Anda mungkin perlu menghapus cache agar pembaruan muncul di situs publik. Gunakan opsi **Hapus Cache** di area admin untuk menyegarkan konten.

:::tip
Pilih nama program yang deskriptif dan tulis deskripsi yang jelas. Ini adalah hal pertama yang dilihat gereja saat menelusuri perpustakaan kurikulum, jadi ringkasan yang baik membantu mereka memutuskan apakah program tersebut sesuai dengan kebutuhan mereka.
:::
