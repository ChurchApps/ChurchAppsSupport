# Mengelola Studi

<div class="article-intro">

Studi adalah serangkaian pelajaran yang saling terkait dalam sebuah program. Misalnya, seri empat minggu berjudul "Orang Samaria yang Baik" akan menjadi studi di dalam program pelayanan anak yang lebih besar. Panduan ini membahas cara membuat, mengedit, dan mengatur studi di area admin.

</div>

<div class="prereqs">
<h4>Sebelum Anda Mulai</h4>

- [Buat setidaknya satu program](./managing-programs.md) di area admin
- Miliki izin admin untuk Lessons.church (lihat [Ikhtisar Administrasi](./index.md))

</div>

## Membuat Studi

1. Buka area **Admin** dan perluas program tempat Anda ingin menambahkan studi.
2. Klik **Tambah Studi**.
3. Isi kolom-kolom berikut:
   - **Nama** -- Nama tampilan untuk studi (misalnya, "Orang Samaria yang Baik").
   - **Slug** -- Pengidentifikasi yang ramah URL (misalnya, "orang-samaria-yang-baik").
   - **Deskripsi** -- Ringkasan tentang isi studi ini dan jumlah pelajaran yang disertakan.
   - **Gambar** -- Unggah gambar thumbnail untuk studi.
4. Simpan studi.

## Mengedit Studi

1. Klik nama studi di daftar admin.
2. Perbarui kolom mana pun yang diperlukan.
3. Simpan perubahan Anda.

## Menetapkan Kategori

Jika program induk menggunakan kategori studi, Anda dapat menetapkan studi ke salah satu kategori tersebut:

1. Buka studi di tampilan admin.
2. Pilih **Kategori** dari menu tarik-turun.
3. Simpan.

Kategori membantu pengguna menelusuri program yang memiliki banyak studi. Misalnya, Anda dapat memiliki kategori seperti "Perjanjian Lama", "Perjanjian Baru", dan "Topikal".

## Mengelola Pelajaran dalam Studi

Studi berisi satu atau lebih pelajaran. Perluas studi di tampilan admin untuk melihat pelajarannya, atau klik **Tambah Pelajaran** untuk membuat pelajaran baru. Lihat [Mengelola Pelajaran](./managing-lessons.md) untuk detail tentang menyusun konten pelajaran.

## Mengunggah Sumber Daya Tingkat Studi

Anda dapat melampirkan file yang dapat diunduh dan berlaku untuk seluruh studi -- misalnya, ikhtisar seri, grafik promosi, atau templat buletin untuk orang tua.

1. Buka studi di tampilan admin.
2. Buka bagian **Sumber Daya**.
3. Unggah file Anda.

:::tip
Tulis deskripsi studi dengan mempertimbangkan para pemimpin gereja. Ringkasan yang jelas tentang tema, kelompok usia sasaran, dan jumlah pelajaran membantu gereja memutuskan apakah akan menggunakan seri tersebut.
:::
