# Menjelajahi Konten

<div class="article-intro">

Lessons.church menyediakan perpustakaan kurikulum gereja gratis yang dapat dijelajahi siapa saja. Anda tidak perlu akun atau login untuk melihat konten yang tersedia -- cukup kunjungi situsnya dan mulai menjelajah. Bagian ini membahas semua cara untuk menemukan dan menjelajahi kurikulum.

</div>

## Halaman Beranda

Saat pertama kali membuka Lessons.church, halaman beranda memberi Anda gambaran singkat tentang semua yang tersedia:

- **Program unggulan** -- Seri kurikulum pilihan ditampilkan di bagian atas, sehingga memudahkan Anda menemukan konten yang populer atau baru diperbarui.
- **Semua program** -- Di bawah bagian unggulan, Anda akan menemukan daftar lengkap setiap program kurikulum yang tersedia beserta statistik, seperti jumlah pelajaran dan studi di setiap program.
- **Konten penyedia** -- Konten dari Lessons.church maupun penyedia kurikulum eksternal ditampilkan bersama-sama, sehingga Anda memiliki satu tempat untuk menjelajah.

## Cara Menemukan Konten

Ada beberapa cara untuk menjelajahi perpustakaan kurikulum:

1. **Telusuri berdasarkan program** -- Klik program mana pun di halaman beranda untuk melihat studi dan pelajarannya. Ini adalah cara terbaik jika Anda ingin menjelajahi seri kurikulum tertentu. Lihat [Program dan Studi](./programs-and-studies.md) untuk detailnya.

2. **Pencarian** -- Gunakan halaman pencarian untuk menemukan pelajaran berdasarkan kata kunci di seluruh perpustakaan. Ini berguna jika Anda mengetahui topiknya tetapi tidak yakin program mana yang membahasnya. Lihat [Pencarian](./searching.md) untuk detailnya.

3. **Jelajahi penyedia eksternal** -- Sebagian konten berasal dari penyedia kurikulum pihak ketiga yang menerbitkan dalam Open Lesson Format. Anda dapat menelusuri program dan studi mereka seperti halnya konten bawaan. Lihat [Penyedia Eksternal](./external-providers.md) untuk detailnya.

## Tidak Perlu Login

Penelusuran sepenuhnya terbuka. Anda dapat melihat program, studi, pelajaran, materi yang dapat diunduh, dan video tanpa membuat akun. Jika nanti Anda ingin menjadwalkan pelajaran untuk kelas Anda atau menyesuaikan konten, Anda dapat [membuat akun gratis](../getting-started/creating-account.md) pada saat itu.

:::tip
Mulailah dengan menjelajahi beberapa program di halaman beranda untuk mendapatkan gambaran tentang cara kurikulum disusun sebelum masuk ke studi tertentu.
:::
