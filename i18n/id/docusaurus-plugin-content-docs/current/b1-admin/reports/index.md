# Laporan

<div class="article-intro">

B1 Admin menyediakan beberapa cara untuk mengambil data tentang jemaat, kehadiran, dan persembahan Anda. Pelaporan sudah tersedia di bagian yang relevan dalam aplikasi, bukan di satu halaman Laporan tersendiri.

</div>

## Tempat Menemukan Laporan

### Jemaat
- **[Daftar Ulang Tahun & Ulang Tahun Pernikahan](./birthday-report.md)** -- Filter berdasarkan Bulan Lahir atau Bulan Ulang Tahun Pernikahan di **Jemaat → Pencarian Lanjutan** untuk mendapatkan daftar ulang tahun atau ulang tahun pernikahan yang akan datang.

### Kehadiran
- **[Laporan Kehadiran](./attendance-reports.md)** -- Tren kehadiran dan data kehadiran kelompok dapat ditemukan di bagian **Kehadiran**.

### Donasi
- **[Ringkasan Donasi](./donation-summary.md)** -- Total persembahan dan rincian dana dapat ditemukan di bagian **Donasi**.

### Pengaturan
- **[Log Audit](./audit-log.md)** -- Lacak semua perubahan dan tindakan dalam sistem manajemen gereja Anda (ada di **Pengaturan → Log Audit**).

:::info
Data laporan bergantung pada entri data yang konsisten. Pastikan tim Anda [mencatat kehadiran](../attendance/tracking-attendance.md), [mencatat donasi](../donations/recording-donations.md), dan menjaga [data jemaat](../people/adding-people.md) tetap mutakhir agar hasilnya paling akurat.
:::
