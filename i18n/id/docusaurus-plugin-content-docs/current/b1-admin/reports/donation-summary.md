# Ringkasan Donasi

<div class="article-intro">

Laporan Ringkasan Donasi memberi Anda gambaran yang jelas tentang aktivitas pemberian di gereja Anda. Gunakan laporan ini untuk melacak total donasi, memantau tren pemberian, dan menyiapkan laporan keuangan untuk tim kepemimpinan Anda.

</div>

<div class="prereqs">
<h4>Sebelum Memulai</h4>

- Pastikan donasi [dicatat secara konsisten](../donations/recording-donations.md) di sistem Anda
- Anda memerlukan [izin](../settings/roles-permissions.md) yang sesuai untuk mengakses laporan keuangan

</div>

## Menjalankan Laporan

1. Buka langsung **admin.b1.church/reports/donationSummary** di peramban Anda (laporan tidak memiliki entri di menu navigasi, sehingga menyimpan alamat tersebut sebagai bookmark adalah cara termudah untuk kembali ke sana).
2. Atur **rentang tanggal** untuk menentukan periode pelaporan.
3. Terapkan filter tambahan seperti **dana** atau kriteria lainnya untuk mempersempit hasil.
4. Laporan akan menampilkan ringkasan pemberian untuk periode yang dipilih.

## Isi Laporan

Laporan Ringkasan Donasi mencakup:

- **Total donasi** -- Jumlah pemberian keseluruhan untuk periode yang dipilih.
- **Jumlah donatur** -- Jumlah donatur unik yang memberikan kontribusi.
- **Jumlah per dana** -- Rincian pemberian di berbagai dana, jika berlaku.

## Penggunaan Praktis

- **Perencanaan keuangan** -- Tinjau tren pemberian untuk memperkirakan pendapatan di masa depan dan merencanakan anggaran Anda.
- **Laporan dewan** -- Buat ringkasan untuk rapat dewan atau kepemimpinan secara berkala dengan data pemberian yang jelas.
- **Tinjauan akhir tahun** -- Jalankan laporan untuk satu tahun penuh guna menyiapkan ringkasan keuangan tahunan.
- **Pelacakan kampanye** -- Filter berdasarkan dana untuk melacak kemajuan kampanye pemberian khusus atau proyek pembangunan.
- **Analisis musiman** -- Bandingkan pemberian di berbagai periode untuk memahami pola musiman.

:::tip
Jalankan laporan ini setiap bulan agar tetap mengetahui kondisi keuangan gereja Anda. Membandingkan data bulan ke bulan membantu Anda mengenali tren lebih awal.
:::

:::warning
Data donasi berasal dari kontribusi yang tercatat di sistem Anda. Pastikan donasi dimasukkan secara konsisten -- baik melalui pemberian daring, pemrosesan cek, atau entri manual -- untuk laporan yang paling akurat. Lihat [Mencatat Donasi](../donations/recording-donations.md) untuk detailnya.
:::
