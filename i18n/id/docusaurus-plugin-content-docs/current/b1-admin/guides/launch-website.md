# Meluncurkan Situs Web Gereja Anda

<div class="article-intro">

B1.church menyertakan pembuat situs web lengkap tanpa biaya tambahan. Panduan ini memandu Anda membuat situs web gereja dari awal: menyiapkan halaman beranda, mengatur tampilan dan nuansa, menambahkan halaman-halaman utama, dan secara opsional menghubungkan formulir pemberian daring serta pendaftaran acara.

</div>

<div class="prereqs">
<h4>Sebelum Anda Mulai</h4>

- Siapkan logo gereja Anda (PNG dengan latar belakang transparan paling baik)
- Pilih 2–3 warna merek untuk situs Anda
- Jika menggunakan domain kustom (misalnya, gerejaanda.com), pastikan Anda memiliki akses ke penyedia DNS Anda (GoDaddy, Cloudflare, dll.)
- Jika Anda ingin pemberian daring di situs Anda, selesaikan [Pengaturan Pemberian Daring](../donations/online-giving-setup.md) (Stripe) terlebih dahulu

</div>

## Langkah 1: Pengaturan Awal Situs Web

Mulailah dengan membuat halaman beranda dan struktur situs dasar Anda.

Ikuti panduan [Pengaturan Awal Situs Web](../website/initial-setup.md) untuk:

1. Buka **Website** di B1 Admin
2. Buat halaman beranda Anda dengan bagian hero, pesan selamat datang, dan informasi penting
3. Tambahkan nama gereja dan slogan Anda

## Langkah 2: Mengatur Tampilan

Tetapkan identitas visual situs Anda: warna, font, logo, dan footer.

Ikuti panduan [Tampilan](../website/appearance.md) untuk:

1. Unggah logo gereja Anda
2. Tetapkan warna utama dan warna aksen Anda
3. Atur bilah navigasi dan footer
4. Pratinjau perubahan Anda

:::tip
Jaga palet warna Anda tetap sederhana. Satu warna utama dan satu warna aksen biasanya sudah cukup. Pembuat situs web akan mengurus sisanya.
:::

## Langkah 3: Menambahkan Halaman Konten

Buat halaman-halaman yang paling dibutuhkan pengunjung Anda.

Ikuti panduan [Mengelola Halaman](../website/managing-pages.md) untuk membuat halaman seperti:

- **Tentang** — Kisah, keyakinan, dan kepemimpinan gereja Anda
- **Khotbah** — Tautkan ke [pustaka khotbah](../sermons/managing-sermons.md) Anda
- **Acara** — Acara mendatang dan pendaftaran
- **Beri** — Halaman pemberian daring (memerlukan [pengaturan Stripe](../donations/online-giving-setup.md))
- **Kontak** — Lokasi, jadwal ibadah, dan informasi kontak

## Langkah 4: Menghubungkan Domain Anda

Jika Anda ingin menggunakan nama domain Anda sendiri (seperti gerejaanda.com) alih-alih URL B1 default:

1. Buka **Settings** di B1 Admin dan buka bagian **Domains**
2. Masukkan domain kustom Anda
3. Perbarui catatan DNS Anda di penyedia domain untuk mengarah ke B1

:::info
Perubahan DNS dapat memakan waktu hingga 48 jam untuk berlaku. Situs Anda mungkin belum dapat diakses melalui domain kustom Anda secara langsung. URL B1 default akan tetap berfungsi selama periode ini.
:::

## Langkah 5: Menambahkan Pemberian dan Formulir

Tingkatkan situs Anda dengan elemen interaktif:

- **Pemberian Daring** — Tambahkan bagian pemberian agar anggota dapat berdonasi langsung dari situs web Anda. Lihat [Pengaturan Pemberian Daring](../donations/online-giving-setup.md) untuk mengonfigurasi Stripe terlebih dahulu.
- **Formulir Pendaftaran** — Sematkan [formulir Stand Alone](../forms/creating-forms.md) untuk pendaftaran acara, kartu pengunjung, atau pendaftaran relawan. Lihat [Mengelola Halaman](../website/managing-pages.md) untuk cara menambahkan elemen formulir ke halaman mana pun.

## Selesai!

Situs web gereja Anda sudah aktif. Bagikan URL-nya kepada jemaat Anda dan di media sosial. Anda dapat memperbarui konten, menambahkan halaman baru, dan menyesuaikan tampilan kapan saja dari dasbor B1 Admin.
