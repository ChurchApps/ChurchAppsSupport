# Membangun Perpustakaan Khotbah & Siaran Langsung

<div class="article-intro">

Dapatkan arsip khotbah Anda secara daring dan atur siaran langsung — mulai dari mengimpor pustaka YouTube atau Vimeo Anda yang sudah ada hingga menjadwalkan layanan siaran langsung berulang dengan obrolan interaktif. Pada akhirnya, jemaat Anda dapat menonton khotbah sebelumnya dan bergabung dalam layanan langsung melalui situs web dan aplikasi seluler Anda.

</div>

<div class="prereqs">
<h4>Sebelum Anda Memulai</h4>

- Akun B1 Admin dengan izin pengelolaan konten
- Saluran YouTube atau Vimeo dengan video khotbah (untuk mengimpor arsip Anda)
- ID Saluran YouTube (untuk siaran langsung — temukan di pengaturan YouTube Studio Anda)

</div>

## Langkah 1: Buat Daftar Putar Khotbah

Daftar putar mengatur khotbah Anda ke dalam seri dan koleksi agar mudah dijelajahi.

Ikuti panduan [Daftar Putar](../sermons/playlists.md) untuk:

1. Membuat seri/koleksi seperti "Khotbah Minggu 2024", "Seri Pernikahan", "Kebaktian Natal"
2. Menambahkan nama, deskripsi, tanggal publikasi, dan gambar mini untuk setiap daftar putar

:::tip
Buat daftar putar sebelum menambahkan khotbah. Ini memudahkan Anda mengatur khotbah ke dalam seri yang tepat saat menambahkannya.
:::

## Langkah 2: Impor Khotbah yang Sudah Ada

Jika Anda sudah memiliki video khotbah di YouTube atau Vimeo, Anda dapat mengimpor semuanya sekaligus.

Ikuti panduan [Impor Massal](../sermons/bulk-import.md) untuk:

1. Masukkan URL saluran YouTube atau Vimeo Anda
2. Pratinjau impor untuk melihat video mana yang akan diimpor
3. Klik Impor untuk menambahkan semuanya sekaligus

## Langkah 3: Tambahkan Khotbah Satu per Satu

Untuk penambahan sekali saja atau khotbah yang tidak termasuk dalam impor massal, tambahkan secara individual.

Ikuti panduan [Mengelola Khotbah](../sermons/managing-sermons.md) untuk:

1. Tempelkan URL video (YouTube, Vimeo, atau Facebook)
2. Judul, deskripsi, gambar mini, dan durasi akan terisi otomatis dari metadata video
3. Tetapkan khotbah ke daftar putar

## Langkah 4: Atur Siaran Langsung

Hubungkan saluran YouTube Anda agar situs B1 Anda secara otomatis menampilkan siaran langsung Anda.

Ikuti panduan [Siaran Langsung](../sermons/live-streaming.md) untuk:

1. Masukkan ID Saluran YouTube Anda di pengaturan siaran
2. Atur jadwal layanan berulang Anda (misalnya, Minggu pukul 10.00)
3. Sesuaikan tab halaman siaran (Obrolan, Permintaan doa, dan tautan kustom) di halaman **Sermons > Settings**

:::info
Saat Anda mulai siaran di YouTube, halaman siaran B1 akan otomatis menampilkan siaran tersebut. Tidak perlu langkah tambahan pada Minggu pagi.
:::

## Langkah 5: Tampilkan di Situs Web Anda

Buat perpustakaan khotbah dan siaran langsung Anda mudah diakses oleh pengunjung.

Ikuti panduan [Mengelola Halaman](../website/managing-pages.md) untuk:

1. Tambahkan bagian Khotbah ke situs web B1 Anda agar pengunjung dapat menjelajahi perpustakaan Anda
2. Tambahkan bagian Siaran Langsung untuk pengalaman menonton langsung

## Langkah 6: Akses Seluler

Anggota dapat mengakses khotbah dan layanan langsung dari perangkat apa pun.

1. Anggota dapat menonton khotbah di [aplikasi B1 Mobile](../../b1-church/content/sermons.md) dan di [B1.church](../../b1-church/content/sermons.md)
2. Siaran langsung dengan obrolan berfungsi di kedua platform

:::info
Fitur obrolan langsung memungkinkan jemaat daring Anda berpartisipasi secara real time, seolah-olah berada di dalam ruangan.
:::

## Selesai!

Perpustakaan khotbah Anda sudah online dan siaran langsung Anda sudah dikonfigurasi. Anggota dapat mengejar khotbah sebelumnya kapan saja dan bergabung dalam layanan langsung dari mana saja. Unggahan khotbah baru dapat disinkronkan secara otomatis.
