# Membangun Perpustakaan Khotbah & Siaran Langsung

<div class="article-intro">

Jadikan arsip khotbah Anda tersedia secara daring dan siapkan siaran langsung, mulai dari mengimpor perpustakaan YouTube atau Vimeo yang sudah ada hingga menjadwalkan layanan siaran langsung berulang dengan obrolan interaktif. Setelah selesai, jemaat Anda dapat menonton khotbah sebelumnya dan bergabung dalam layanan siaran langsung di situs web dan aplikasi seluler Anda.

</div>

<div class="prereqs">
<h4>Sebelum Anda Mulai</h4>

- Akun B1 Admin dengan izin pengelolaan konten
- Kanal YouTube atau Vimeo dengan video khotbah (untuk mengimpor arsip Anda)
- ID Kanal YouTube (untuk siaran langsung, temukan di pengaturan YouTube Studio Anda)

</div>

## Langkah 1: Buat Daftar Putar Khotbah

Daftar putar mengatur khotbah Anda ke dalam seri dan koleksi agar mudah dijelajahi.

Ikuti panduan [Daftar Putar](../sermons/playlists.md) untuk:

1. Membuat seri/koleksi seperti "Khotbah Minggu 2024", "Seri Pernikahan", "Kebaktian Natal"
2. Menambahkan nama, deskripsi, tanggal publikasi, dan thumbnail untuk setiap daftar putar

:::tip
Buat daftar putar sebelum menambahkan khotbah. Dengan begitu, lebih mudah mengatur khotbah ke dalam seri yang tepat saat Anda menambahkannya.
:::

## Langkah 2: Impor Khotbah yang Sudah Ada

Jika Anda sudah memiliki video khotbah di YouTube atau Vimeo, Anda dapat mengambil semuanya sekaligus.

Ikuti panduan [Impor Massal](../sermons/bulk-import.md) untuk:

1. Memasukkan URL kanal YouTube atau Vimeo Anda
2. Melihat pratinjau impor untuk melihat video mana yang akan diambil
3. Klik Impor untuk menambahkan semuanya sekaligus

## Langkah 3: Tambahkan Khotbah Satu per Satu

Untuk penambahan satu kali atau khotbah yang tidak termasuk dalam impor massal, tambahkan secara individual.

Ikuti panduan [Mengelola Khotbah](../sermons/managing-sermons.md) untuk:

1. Menempelkan URL video (YouTube, Vimeo, atau Facebook)
2. Judul, deskripsi, thumbnail, dan durasi terisi otomatis dari metadata video
3. Menetapkan khotbah ke daftar putar

## Langkah 4: Siapkan Siaran Langsung

Hubungkan kanal YouTube Anda agar situs B1 Anda otomatis menampilkan siaran langsung Anda.

Ikuti panduan [Siaran Langsung](../sermons/live-streaming.md) untuk:

1. Memasukkan ID Kanal YouTube Anda di pengaturan streaming
2. Mengonfigurasi jadwal layanan berulang Anda (misalnya, Minggu pukul 10.00)
3. Menyesuaikan tab halaman streaming (Obrolan, Permintaan doa, dan tautan kustom) di halaman **Sermons > Settings**

:::info
Saat Anda mulai siaran langsung di YouTube, halaman streaming B1 otomatis menampilkan siaran tersebut. Tidak ada langkah tambahan yang diperlukan pada Minggu pagi.
:::

## Langkah 5: Tampilkan di Situs Web Anda

Buat perpustakaan khotbah dan siaran langsung Anda mudah diakses oleh pengunjung.

Ikuti panduan [Mengelola Halaman](../website/managing-pages.md) untuk:

1. Menambahkan bagian Khotbah ke situs web B1 Anda agar pengunjung dapat menjelajahi perpustakaan Anda
2. Menambahkan bagian Siaran Langsung untuk pengalaman menonton langsung

## Langkah 6: Akses Seluler

Anggota dapat mengakses khotbah dan layanan siaran langsung dari perangkat apa pun.

1. Anggota dapat menonton khotbah di [B1.church dan di Aplikasi B1](../../b1-church/content/sermons.md)
2. Siaran langsung dengan obrolan berfungsi di ponsel maupun komputer

:::info
Fitur obrolan langsung memungkinkan jemaat daring Anda berpartisipasi secara real time, seperti hadir langsung di ruangan.
:::

## Selesai!

Perpustakaan khotbah Anda sudah online dan siaran langsung Anda sudah dikonfigurasi. Anggota dapat mengejar khotbah sebelumnya kapan saja dan bergabung dalam layanan siaran langsung dari mana saja. Unggahan khotbah baru dapat tersinkronisasi secara otomatis.
