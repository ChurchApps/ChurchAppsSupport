# Situs Web

<div class="article-intro">

Bagian Website di B1 Admin menyediakan pembuat situs web lengkap untuk gereja Anda. Anda dapat membuat halaman, menyesuaikan tampilan dan nuansa situs Anda, mengelola file media, dan menerbitkan kalender acara -- semuanya tanpa menulis kode apa pun.

</div>

## Yang Dapat Anda Lakukan

Pembuat situs web diatur ke dalam area utama berikut:

### Halaman

Buat dan kelola semua halaman di situs web gereja Anda. Tabel **Pages** mencantumkan setiap halaman -- halaman yang dibuat otomatis oleh sistem diberi lencana **Generated**, sedangkan sisanya adalah halaman kustom yang Anda buat. Anda dapat menambahkan halaman kustom baru, mengedit halaman yang sudah ada, atau mengubah halaman yang dibuat otomatis menjadi halaman kustom agar Anda memiliki kendali penuh atas kontennya.

Tautan navigasi Anda ditampilkan dalam struktur pohon. Anda dapat mengurutkan ulang tautan dengan seret-dan-lepas (drag-and-drop) untuk menentukan hierarki dan urutan yang tepat yang ingin dilihat pengunjung.

### Blog

Terbitkan berita, pembaruan, dan renungan sebagai postingan blog di `/blog` di situs Anda, lengkap dengan feed RSS. Lihat panduan [Blog](./blog.md).

### Blok

Buat komponen konten yang dapat digunakan kembali dan ditempatkan di beberapa halaman. Blok menghemat waktu Anda ketika memiliki konten seperti ajakan bertindak (call-to-action), banner pengumuman, atau bagian kontak yang muncul di lebih dari satu tempat. Perbarui blok sekali saja dan perubahannya berlaku di semua tempat yang menggunakannya.

### Tampilan

Sesuaikan tema, warna, font, logo, dan spasi situs web Anda. Anda dapat menerapkan tema gaya yang sudah dibuat sebelumnya untuk memulai dengan cepat, atau menyempurnakan setiap detail dengan editor palet warna, pengaturan tipografi, dan CSS kustom. Lihat panduan [Tampilan](./appearance.md) untuk detail lengkapnya.

### File

Unggah dan kelola semua aset media Anda -- gambar, dokumen, dan file lainnya -- di satu lokasi terpusat, lalu salin tautan file untuk digunakan di mana pun di situs Anda. Lihat [File](./files.md) untuk informasi selengkapnya.

### Kalender

Terbitkan kalender acara di situs web Anda agar pengunjung dapat melihat apa yang sedang berlangsung di gereja Anda. Buat kalender terkurasi yang menggabungkan acara dari beberapa grup ke dalam satu tampilan. Kalender memiliki item **Calendars** tersendiri di menu B1 Admin, terpisah dari **Website**.

:::tip
Mulailah dengan [Pengaturan Awal](./initial-setup.md) jika Anda mengonfigurasi situs web untuk pertama kali. Panduan ini akan memandu Anda melalui pengaturan domain, pembuatan halaman pertama, dan konfigurasi tampilan situs Anda.
:::
