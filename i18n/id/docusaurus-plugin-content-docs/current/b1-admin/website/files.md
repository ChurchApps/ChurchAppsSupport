# File

<div class="article-intro">

Halaman File adalah pusat penyimpanan untuk semua media dan dokumen yang digunakan di situs web gereja Anda. Dari sini Anda dapat mengunggah, menelusuri, dan mengelola setiap gambar, dokumen, dan file media yang dibutuhkan situs Anda.

</div>

<div class="prereqs">
<h4>Sebelum Anda Memulai</h4>

- Selesaikan [Pengaturan Awal](./initial-setup.md) untuk situs web Anda
- Optimalkan gambar sebelum mengunggah agar waktu muat halaman lebih cepat
- Siapkan file Anda dalam format web yang umum (PNG, JPG, PDF, dll.)

</div>

## Mengunggah File

1. Di B1 Admin, buka [menu Jump](../introduction.md#getting-around-with-the-jump-menu) (bilah pencarian di pojok kiri atas), perluas **Website**, lalu klik **Files**.
2. Di panel **Upload Files** di sebelah kanan, klik **Choose File** dan pilih file dari komputer Anda. (Tombol **Upload Files** di bagian atas halaman juga membawa Anda ke panel yang sama.)
3. File Anda akan terunggah dan muncul di tabel file.

Panel Upload Files juga menampilkan jumlah penyimpanan yang sedang Anda gunakan. 100 MB disediakan secara gratis; untuk mendapatkan lebih banyak, hubungkan Google Drive, Dropbox, OneDrive, atau bucket S3 Anda sendiri di **Settings**, pada bagian **File Storage**.

:::tip
Untuk hasil terbaik, optimalkan gambar sebelum mengunggah. Ukuran file yang lebih kecil membantu situs Anda dimuat lebih cepat bagi pengunjung. Alat seperti TinyPNG atau Squoosh dapat mengompres gambar tanpa penurunan kualitas yang terlihat.
:::

## Menelusuri File

Tabel file mencantumkan setiap file yang diunggah beserta **Name** dan **Size**-nya. Klik nama file untuk membukanya di tab baru. Berikan nama file yang jelas dan deskriptif sebelum mengunggah agar tim Anda dapat menemukannya dengan cepat.

## Menggunakan File di Situs Web Anda

1. Temukan file di tabel file.
2. Klik **Copy link** untuk menyalin URL file. Anda dapat menempelkan URL ini ke elemen gambar, tautan unduhan, atau tempat lain yang menerima URL file.
3. File yang Anda unggah di sini tersedia untuk digunakan di seluruh halaman situs web dan blok konten Anda.

:::info
Saat membuat halaman di [Mengelola Halaman](./managing-pages.md), Anda dapat merujuk file apa pun yang diunggah di sini melalui URL-nya. Ini membuat semua media Anda tertata di satu lokasi pusat.
:::

## Menghapus File

1. Temukan file yang ingin Anda hapus di tabel file.
2. Klik **Delete** di sebelahnya dan konfirmasi untuk menghapus file secara permanen dari pustaka Anda.
3. Pastikan file tersebut tidak sedang digunakan di halaman mana pun sebelum menghapusnya, karena hal ini akan merusak tautan atau gambar yang merujuk padanya.

:::warning
File yang dihapus tidak dapat dipulihkan. Periksa kembali bahwa file tidak lagi digunakan di halaman mana pun sebelum menghapusnya.
:::
