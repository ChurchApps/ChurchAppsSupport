# Kesehatan Grup

<div class="article-intro">

Dasbor Kesehatan Grup memberi Anda gambaran menyeluruh tentang kondisi semua grup Anda — tren keanggotaan, rata-rata kehadiran, serta pertumbuhan atau penurunan selama 90 hari terakhir — semuanya dalam satu tabel yang dapat diurutkan.

</div>

<div class="prereqs">
<h4>Sebelum Anda Mulai</h4>

- Anda memerlukan setidaknya beberapa grup dengan anggota agar dapat melihat data yang bermakna. Lihat [Membuat Grup](./creating-groups.md).
- Data kehadiran diambil dari sesi yang telah dicatat. Lihat bagian [Kehadiran](../attendance/index.md).

</div>

## Membuka Kesehatan Grup

Di B1 Admin, buka [menu Jump](../introduction.md#getting-around-with-the-jump-menu) (kolom pencarian di pojok kiri atas), perluas **People**, klik **Groups**, lalu klik tombol **Group Health** di header halaman. Dasbor akan memuat tabel dengan satu baris untuk setiap grup.

## Kolom

| Kolom | Isi |
|--------|--------------|
| **Name** | Nama grup, ditautkan ke halaman detail grup |
| **Category** | Kategori grup |
| **Members** | Jumlah anggota aktif saat ini |
| **Joined (90d)** | Anggota yang bergabung dalam 90 hari terakhir |
| **Left (90d)** | Anggota yang keluar dalam 90 hari terakhir |
| **Churn (90d)** | Persentase tingkat churn bersih selama 90 hari |
| **Avg Attendance** | Rata-rata jumlah kehadiran per sesi kehadiran |

Klik header kolom mana pun untuk mengurutkan tabel berdasarkan kolom tersebut. Klik lagi untuk membalik arah pengurutan.

## Memanfaatkan Data Kesehatan

- **Churn tinggi + bergabung rendah** — grup yang menyusut dan tidak menggantikan anggota yang keluar. Layak untuk dibicarakan dengan pemimpin grup.
- **Bergabung tinggi + kehadiran rendah** — orang-orang mendaftar tetapi tidak hadir. Pertimbangkan tindak lanjut untuk meningkatkan keterlibatan.
- **Rata-rata kehadiran tinggi** — grup yang sehat dan aktif. Dapat dijadikan contoh bagi grup lain.

:::tip
Mengklik nama grup akan membawa Anda langsung ke halaman detail grup, tempat Anda dapat meninjau anggota secara individual, catatan kehadiran, dan acara kalender.
:::
