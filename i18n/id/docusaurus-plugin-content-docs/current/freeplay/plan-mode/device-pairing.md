# Memasangkan Perangkat Anda

<div class="article-intro">

Untuk menggunakan Mode Rencana, Anda memasangkan TV dengan jenis rencana di B1 Admin. FreePlay menampilkan kode pemasangan singkat di TV. Anda memasukkan kode tersebut di B1 Admin dan memilih jenis rencana yang akan diikuti, lalu TV otomatis menerima konten rencana tersebut setiap minggu.

</div>

<div class="prereqs">
<h4>Sebelum Memulai</h4>

- Pasang dan jalankan FreePlay. Lihat [Memulai](../getting-started/index.md)
- Pastikan Anda memiliki akses ke **B1 Admin** di komputer atau ponsel untuk menyelesaikan pemasangan

</div>

## Membuat Kode Pemasangan

1. Di TV, buka **Pengaturan** di bagian bawah bilah sisi.
2. Pilih **Pasangkan ke kalender**.
3. FreePlay menampilkan kode pemasangan empat huruf dengan huruf besar, di samping kode QR.
4. Di bawah kode, indikator **Menunggu konfirmasi** yang berdenyut menunjukkan bahwa FreePlay sedang menunggu Anda menyelesaikan pemasangan.

Kode yang sama juga berfungsi untuk [Mode Terjadwal](../scheduled-mode/index.md) di FreePlay Admin dan untuk Mode Rencana di B1 Admin. Kode QR dan alamat **freeplay.church/pair** di layar membuka FreePlay Admin. Untuk Mode Rencana, abaikan keduanya dan masukkan kode di B1 Admin seperti dijelaskan di bawah.

## Memasukkan Kode di B1 Admin

1. Di B1 Admin, buka **Profil** > **Perangkat**, lalu klik **Tambah Layar**.
2. Masukkan empat huruf dari TV di **Kode Pemasangan**.
3. Di bagian **Tampilkan Rencana Untuk**, pilih jenis rencana yang ingin diikuti layar ini, misalnya "Sunday Service".
4. Simpan.

FreePlay memeriksa setiap beberapa detik apakah pemasangan sudah selesai. Setelah B1 Admin mengonfirmasinya, TV menampilkan **Terhubung!** dan beralih ke layar unduhan rencana.

## Mengunduh Konten Rencana

Setelah pemasangan, FreePlay memuat rencana saat ini untuk jenis rencana tersebut. Layar menampilkan:

- Nama rencana dan tanggal layanan
- Nama pelajaran, jika rencana menyertakan konten pelajaran
- Indikator kemajuan yang menampilkan **Mengunduh item X dari Y**

Setelah semua file media selesai diunduh, tombol **Mulai Rencana** muncul. Tekan **Pilih** pada remote Anda untuk memulai pemutaran.

:::tip
Rencana diperbarui secara otomatis setiap jam. Jika seseorang memperbarui rencana di tengah hari, FreePlay akan menerima perubahannya dengan sendirinya.
:::

## Jika Pemasangan Gagal

Jika FreePlay tidak dapat membuat kode pemasangan (misalnya karena masalah jaringan), Anda akan melihat pesan kesalahan dengan tombol **Coba Lagi**. Pastikan TV terhubung ke internet, lalu coba lagi.

:::warning
Kode pemasangan kedaluwarsa setelah 15 menit. FreePlay menampilkan kode baru secara otomatis ketika kode lama habis, dan Anda dapat memilih **Buat Kode Baru** kapan saja. Jika kode yang Anda masukkan tidak berfungsi, gunakan kode yang sedang ditampilkan TV sekarang.
:::
