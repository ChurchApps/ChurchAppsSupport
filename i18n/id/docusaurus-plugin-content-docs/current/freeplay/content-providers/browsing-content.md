# Menelusuri dan Mengunduh Konten

<div class="article-intro">

Setelah terhubung ke penyedia konten, Anda dapat menelusuri pustakanya, mengunduh berkas, dan memutarnya di TV Anda. Penelusur konten menampilkan kisi visual berisi folder dan berkas yang dinavigasi menggunakan remote TV Anda.

</div>

<div class="prereqs">
<h4>Sebelum Memulai</h4>

- Hubungkan setidaknya satu penyedia konten -- lihat [Menghubungkan Penyedia](./connecting-providers.md)
- Siapkan remote TV Anda untuk navigasi

</div>

## Penelusur Konten

Penelusur konten menampilkan item dalam kisi kartu 3 kolom. Setiap kartu menampilkan gambar kecil dan judul. Ada dua jenis item:

- **Folder** - Ditampilkan dengan gambar kecil atau ikon folder. Pilih folder untuk melihat isinya.
- **Berkas** - Item media individual (video atau gambar). Berkas video menampilkan ikon putar di atas gambar kecilnya.

Header di bagian atas layar menampilkan nama folder saat ini, atau nama penyedia jika Anda berada di tingkat root.

## Menavigasi Folder

1. Gunakan tombol arah pada remote Anda untuk menyorot sebuah folder
2. Tekan **Pilih** untuk membukanya
3. Penelusur memuat isi folder, yang mungkin berupa folder lain atau berkas yang dapat diputar
4. Tekan **Kembali** pada remote Anda untuk naik satu tingkat

Anda dapat menelusuri sedalam struktur konten penyedia memungkinkan. Penelusur mencatat jalur folder Anda sehingga Anda dapat kembali melalui setiap tingkat.

## Menelusuri Lessons.church

Pustaka [Lessons.church](../../lessons-church/index.md) diatur dengan cara yang sama seperti situs webnya. Di tingkat teratas, Anda akan melihat dua folder:

- **Lessons** - Masuk berdasarkan **program**, lalu **studi**, lalu **pelajaran**. Setiap pelajaran kemudian mencantumkan **venue**-nya, yaitu versi pelajaran untuk kelompok usia atau setting tertentu, seperti Prasekolah atau SD. Pilih venue untuk membuka layar unduhan untuk versi pelajaran tersebut
- **Add-Ons** - Video dan sumber daya tambahan, dikelompokkan berdasarkan kategori

Tekan **Kembali** di tingkat mana pun untuk naik satu langkah.

## Mengunduh dan Memutar Konten

Saat Anda memilih folder yang berisi berkas yang dapat diputar (atau memilih berkas individual), FreePlay menampilkan judul konten dengan gambar sampul dan dua pilihan:

- **Unduh** - Simpan semua berkas ke TV terlebih dahulu, sehingga pemutaran tidak bergantung pada Wi-Fi. Bilah progres terisi saat setiap berkas tersimpan. Setelah selesai, tombol **Mulai** muncul dengan ikon putar. Tekan **Pilih** untuk memulai pemutaran
- **Streaming** - Mulai memutar segera melalui internet tanpa menyimpan berkas

:::tip
Unduh pelajaran sebelum Minggu pagi selagi gedung gereja Anda memiliki koneksi internet yang kuat. Setelah diunduh, konten dapat diputar secara offline, dan jika Anda memutarnya lagi nanti, konten akan langsung dimuat tanpa diunduh ulang.
:::

## Mengelola Unduhan

Buka **Pengaturan** di bagian bawah bilah sisi, lalu pilih **Unduhan** untuk melihat semua yang tersimpan di TV ini:

- Pilih unduhan untuk memutarnya
- Sorot unduhan lalu pilih ikon hapus di sudutnya untuk menghapusnya dan membebaskan penyimpanan

Jika layar menampilkan **Belum ada unduhan**, berarti belum ada yang tersimpan di TV ini.

## Memutar Konten Penyedia

Gunakan kontrol berikut selama pemutaran:

- **Panah kanan** - Item berikutnya
- **Panah kiri** - Item sebelumnya
- **Pilih / Putar-Jeda** - Jeda atau lanjutkan video
- **Panah atas** - Buka pemilih pesan untuk melompat ke item tertentu
- **Kembali** - Keluar ke penelusur konten

Saat Anda keluar dari pemutar, Anda kembali ke penelusur konten di tingkat root penyedia saat ini.

:::info
Untuk referensi lengkap semua kontrol pemutar, lihat [Memutar Konten](./playing-content.md).
:::

## Berpindah Antar Penyedia

Penyedia yang terhubung muncul sebagai item di bawah judul **Browse** pada bilah sisi kiri. Untuk beralih ke penyedia lain:

1. Tekan panah **Kiri** pada remote Anda untuk memperluas bilah sisi
2. Pilih penyedia yang ingin Anda telusuri
3. Penelusur konten akan memuat ulang dengan pustaka penyedia tersebut

:::warning
Jika sebuah folder menampilkan "Tidak ada konten tersedia," penyedia tidak memiliki item di tingkat tersebut. Coba telusuri folder lain atau periksa kembali nanti.
:::
