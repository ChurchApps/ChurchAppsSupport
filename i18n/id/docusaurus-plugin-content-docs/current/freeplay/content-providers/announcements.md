# Pengumuman

<div class="article-intro">

FreePlay dapat memutar folder slide pengumuman secara berulang di TV Anda, misalnya di lobi atau sebelum kelas dimulai. Anda memilih folder dari salah satu penyedia konten yang terhubung, FreePlay mengunduh slide-nya ke perangkat, dan item **Pengumuman** muncul di bilah sisi agar Anda dapat memulai pemutaran berulang kapan saja.

</div>

<div class="prereqs">
<h4>Sebelum Anda Mulai</h4>

- [Hubungkan ke penyedia konten](./connecting-providers) yang menyimpan slide pengumuman Anda, seperti Dropbox atau OneDrive
- Kumpulkan gambar atau video yang ingin Anda putar berulang dalam satu folder di penyedia tersebut

</div>

## Memilih Folder Pengumuman

1. Buka **Pengaturan** dari bagian bawah bilah sisi, lalu pilih **Penyedia**
2. Pilih penyedia yang terhubung dan menyimpan slide Anda (ditandai lencana **Terhubung**) untuk membuka **Pengaturan Penyedia**-nya
3. Pilih **Gunakan untuk Pengumuman**
4. Penjelajah **Pilih Folder Pengumuman** akan terbuka. Telusuri folder hingga Anda menemukan folder yang berisi slide Anda, lalu pilih folder tersebut (atau file apa pun di dalamnya)
5. FreePlay mengunduh slide dan kembali ke **Pengaturan Penyedia**, tempat baris tersebut kini bertuliskan Mengulang "*nama folder*" -- *jumlah* slide diunduh

Hanya satu folder yang digunakan untuk pengumuman pada satu waktu. Memilih folder dari penyedia lain akan menggantikan folder sebelumnya.

## Memutar Pengumuman

Setelah slide diunduh, item **Pengumuman** akan muncul di dekat bagian atas bilah sisi (di bawah **Rencana Hari Ini**, jika TV Anda menampilkannya). Pilih item tersebut untuk memulai pemutaran berulang.

- Gambar tetap tampil selama 15 detik, kecuali penyedia memberi file tersebut durasinya sendiri
- Video diputar hingga selesai sebelum beralih ke slide berikutnya
- Setelah slide terakhir, pemutaran berulang dimulai lagi dari slide pertama
- Jika folder hanya berisi satu video, video tersebut akan diulang di tempatnya

Pemutaran berulang menggunakan file yang tersimpan di perangkat, sehingga tetap berjalan tanpa koneksi internet. Anda dapat menggunakan kontrol remote yang sama seperti konten lainnya -- lihat [Memutar Konten](./playing-content).

## Memperbarui Slide

FreePlay memeriksa folder pengumuman setiap kali aplikasi dimulai, mengunduh slide baru, dan menghapus slide yang telah dihapus dari folder tersebut.

Untuk memeriksa sekarang juga, buka **Pengaturan Penyedia** dari penyedia tersebut lalu pilih **Periksa Pembaruan Pengumuman**. Baris akan menampilkan **Sudah terbaru** beserta jumlah slide setelah proses selesai.

:::info
Jika FreePlay tidak dapat terhubung ke penyedia, atau folder tersebut kosong, FreePlay akan tetap memutar slide yang sudah dimilikinya. Untuk berhenti menggunakan pengumuman sepenuhnya, matikan seperti dijelaskan di bawah.
:::

:::warning
Slide yang diganti dengan versi baru dengan nama file yang sama tidak akan diunduh ulang. Untuk mengubah slide, tambahkan sebagai file baru dan hapus file lama.
:::

## Mematikan Pengumuman

Buka **Pengaturan Penyedia** dari penyedia tersebut lalu pilih **Gunakan untuk Pengumuman** lagi. FreePlay berhenti menggunakan folder tersebut, menghapus slide yang diunduh dari perangkat, dan menghapus **Pengumuman** dari bilah sisi.

Memutuskan koneksi penyedia juga akan mematikan pengumuman yang berasal darinya.
