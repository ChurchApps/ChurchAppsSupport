# Pengaturan Printer

<div class="article-intro">

B1 Church Checkin dapat mencetak label nama dan slip penjemputan orang tua ke printer label jaringan. Pengaturan printer bersifat opsional -- Anda dapat menggunakan aplikasi tanpa printer hanya untuk pencatatan kehadiran.

</div>

<div class="prereqs">
<h4>Sebelum Memulai</h4>

- [Masuk](./logging-in.md) ke aplikasi B1 Church Checkin dan pilih gereja Anda
- Hubungkan printer label jaringan yang kompatibel ke jaringan Wi-Fi yang sama dengan tablet

</div>

## Label yang Direkomendasikan

Templat label default B1 Checkin dirancang untuk label berukuran **1.1" × 3.5"**.

Jika Anda menggunakan **printer Brother QL**, Anda harus menggunakan label **Brother DK-1201** (1.1" × 3.5"). Printer Brother mendeteksi ukuran label dari gulungan fisik yang dimasukkan ke dalam printer -- jika gulungan tidak sesuai dengan ukuran templat, printer tidak akan mencetak. Jangan menggunakan ukuran lain.

[Label Kompatibel Brother DK-1201 — 12 Gulung (Amazon)](https://www.amazon.com/dp/B0716XB6JG?tag=signpresenter-20)

## Membuka Pengaturan Printer

Anda dapat membuka layar pengaturan printer kapan saja melalui menu **Admin Settings**:

1. Ketuk **logo gereja** di header **tujuh kali** secara berurutan dengan cepat (dalam dua detik).
2. Jika PIN kiosk telah diatur, masukkan PIN saat diminta.
3. Pada layar Admin Settings, ketuk **Change Printer**.

Ini akan membuka layar pengaturan printer tempat Anda dapat memindai printer, memilih salah satu, dan menjalankan cetak uji.

## Memindai Printer

Saat layar pengaturan printer terbuka, aplikasi secara otomatis memindai jaringan lokal Anda untuk mencari printer yang kompatibel. Anda akan melihat indikator pemuatan dengan pesan "Scanning for printers" selama pemindaian berlangsung.

Setelah pemindaian selesai, Anda akan melihat daftar printer yang ditemukan. Setiap kartu printer menampilkan:

- Nama **model printer**
- **Alamat IP** printer di jaringan Anda

Opsi **No Printer** selalu disertakan di bagian bawah daftar.

:::warning
Tablet dan printer harus terhubung ke jaringan lokal yang sama agar pemindaian dapat menemukan printer. Jika printer Anda tidak muncul, pastikan kedua perangkat berada di jaringan Wi-Fi yang sama dan printer dalam keadaan menyala.
:::

## Memilih Printer

1. Ketuk printer yang ingin Anda gunakan. Kartu printer yang dipilih akan disorot dengan tanda centang.
2. Untuk mencetak tanpa printer fisik (untuk pengujian atau mode hanya pencatatan kehadiran), pilih **No Printer**.

## Cetak Uji

Sebelum menyimpan pilihan Anda, Anda dapat memastikan koneksi berfungsi:

1. Pilih printer dari daftar.
2. Ketuk tombol **Test Print** di bagian bawah layar.
3. Aplikasi akan mengirim label uji ke printer. Jika printer terhubung dengan benar, halaman uji akan tercetak.

Jika Anda mengetuk **Test Print** saat **No Printer** dipilih, aplikasi akan menampilkan peringatan yang mengingatkan bahwa belum ada printer yang dipilih.

:::tip
Selalu jalankan cetak uji setelah memilih printer untuk memastikan koneksi berfungsi sebelum ibadah berikutnya.
:::

## Menyimpan Pilihan Anda

Setelah Anda puas dengan pilihan printer:

1. Ketuk tombol **Save & Restart** di bagian bawah layar.
2. Aplikasi akan menyimpan pilihan printer Anda dan memulai ulang untuk menerapkan pengaturan.

Pilihan printer Anda akan tetap tersimpan setelah aplikasi dimulai ulang. Anda tidak perlu mengatur ulang kecuali ingin mengganti printer.

:::info
Jika Anda memindahkan kiosk ke lokasi lain atau mengubah pengaturan jaringan, kembali ke pengaturan printer untuk memindai printer lagi dan memperbarui pilihan Anda.
:::

## Langkah Selanjutnya

Setelah printer dikonfigurasi, Anda siap untuk mulai melakukan check-in. Lihat [alur kerja check-in](../check-in/index.md) untuk mempelajari seluruh prosesnya, dimulai dengan [memilih layanan](../check-in/selecting-service.md).
