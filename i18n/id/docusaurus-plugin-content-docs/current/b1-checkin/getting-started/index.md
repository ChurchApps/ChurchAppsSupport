# Memulai dengan B1 Church Checkin

<div class="article-intro">

Menyiapkan B1 Church Checkin hanya memakan waktu beberapa menit. Bagian ini memandu Anda memasang aplikasi di tablet Android, masuk dengan akun ChurchApps Anda, dan secara opsional mengonfigurasi printer label jaringan.

</div>

## Yang Anda Butuhkan

- **Tablet Android** -- Tablet berukuran 10 inci paling cocok untuk pengalaman kios.
- **Akun ChurchApps** -- Email dan kata sandi yang Anda gunakan untuk B1 Admin atau produk ChurchApps lainnya.
- **Printer label jaringan** (opsional) -- Untuk mencetak label nama dan slip penjemputan orang tua. Aplikasi dapat memindai jaringan lokal untuk menemukan printer yang kompatibel.

## Instalasi

1. Buka **Google Play Store** di tablet Android Anda.
2. Cari **B1 Church Checkin**.
3. Ketuk **Instal** dan tunggu hingga unduhan selesai.
4. Buka aplikasi. Anda akan melihat layar splash saat aplikasi sedang diinisialisasi.

## Pengaturan Pertama Kali

Saat pertama kali membuka aplikasi, Anda akan melewati tiga langkah:

1. **[Masuk](./logging-in)** -- Masukkan email dan kata sandi Anda untuk melakukan autentikasi.
2. **[Pilih gereja Anda](./logging-in)** -- Jika akun Anda terhubung ke beberapa gereja, pilih gereja yang akan dilayani kios ini.
3. **[Atur printer](./printer-setup)** -- Konfigurasikan printer jaringan untuk mencetak label, atau lewati langkah ini jika Anda tidak memerlukan label.

Setelah masuk pertama kali, aplikasi menyimpan kredensial dan pilihan gereja Anda. Pada peluncuran berikutnya, aplikasi akan langsung melewati ke layar layanan secara otomatis.

:::info
Aplikasi memeriksa pembaruan over-the-air setiap kali dimulai. Jika pembaruan tersedia, pembaruan akan diunduh dan diterapkan secara otomatis sebelum Anda mencapai layar masuk.
:::

:::tip
Pastikan administrator gereja Anda telah mengonfigurasi layanan, jadwal layanan, dan grup di B1 Admin sebelum mengatur kios. Lihat [panduan pengaturan absensi](../../b1-admin/attendance/setup.md) untuk detailnya.
:::
