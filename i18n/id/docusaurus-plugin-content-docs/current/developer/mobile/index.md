# Aplikasi Seluler

<div class="article-intro">

Aplikasi seluler ChurchApps dibangun dengan **React Native** dan **Expo**, yang menghadirkan pengalaman native di Android, iOS, dan Android TV. Semua aplikasi seluler menggunakan toolchain berbasis Expo yang sama, jadi jika Anda bisa membangun salah satunya, Anda bisa membangun semuanya.

</div>

## Aplikasi

| Aplikasi | Tujuan | Platform |
|-----|---------|----------|
| [B1 Mobile](./b1-mobile) | Aplikasi utama untuk anggota gereja | Android, iOS |
| B1 Checkin | Aplikasi kiosk untuk stasiun check-in | Android, iOS |
| LessonsScreen | Aplikasi Android TV untuk menampilkan pelajaran di ruang kelas | Android TV |

### B1 Mobile

Aplikasi utama untuk anggota gereja. Anggota dapat melihat direktori, mengakses pemberian persembahan, memeriksa kehadiran, menerima notifikasi, dan berinteraksi dengan komunitas gereja mereka. Lihat [panduan pengaturan B1 Mobile](./b1-mobile) untuk detailnya.

### B1 Checkin

Aplikasi kiosk khusus yang dirancang untuk stasiun check-in di gereja. Aplikasi ini menyediakan antarmuka sederhana yang ramah sentuhan bagi anggota untuk mendaftarkan anak-anak dan mencatat kehadiran pada kebaktian dan acara.

### LessonsScreen

Aplikasi Android TV yang menampilkan konten pelajaran di ruang kelas. Guru dapat mengirim slide pelajaran, video, dan aktivitas ke layar TV, sehingga memudahkan penyajian materi kurikulum selama kelas berlangsung.

:::info
Semua aplikasi seluler menggunakan toolchain berbasis Expo yang sama dan mengikuti pola pengaturan yang serupa. Panduan [B1 Mobile](./b1-mobile) berfungsi sebagai referensi untuk proses pengaturan umum di seluruh proyek seluler.
:::
