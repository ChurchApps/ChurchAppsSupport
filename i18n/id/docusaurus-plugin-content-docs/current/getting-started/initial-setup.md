# Pengaturan Awal

<div class="article-intro">

Setelah membuat akun dan gereja Anda, ada beberapa langkah penting yang perlu dikonfigurasi sebelum mengundang tim Anda. Panduan ini akan memandu Anda melalui urutan pengaturan yang disarankan agar gereja Anda siap digunakan sejak hari pertama.

</div>

<div class="prereqs">
<h4>Sebelum Anda Mulai</h4>

- [Buat akun Anda](./create-account.md) dan daftarkan gereja Anda
- Siapkan logo gereja dan aset branding Anda (opsional tetapi disarankan)

</div>

## Langkah 1: Konfigurasi Informasi Gereja Anda

1. Buka [menu Jump](../b1-admin/introduction.md#getting-around-with-the-jump-menu) (kolom pencarian di pojok kiri atas B1 Admin), perluas **Settings**, lalu klik **Settings**.
2. Di bagian **Church Information**, klik **Edit**.
3. Masukkan **name**, **subdomain**, dan **address** gereja Anda.
4. Klik **Save** untuk menerapkan perubahan Anda.

## Langkah 2: Atur Branding Anda

1. Di menu Jump, pilih **Website > Appearance**.
2. Unggah **logo gereja** Anda.
3. Konfigurasikan opsi branding tambahan lainnya, seperti warna dan gambar.
4. Branding Anda akan muncul di situs web B1.church dan di B1 App.

:::tip
Menyiapkan logo dan branding sebelum mengundang anggota tim memberikan kesan pertama yang rapi saat mereka masuk.
:::

## Langkah 3: Konfigurasi Peran dan Undang Tim Anda

1. Di menu Jump, pilih **Settings > Roles**.
2. Buat peran untuk tim Anda (misalnya, "Pendeta", "Sekretaris", "Bendahara").
3. Berikan izin yang sesuai untuk setiap peran.
4. Tambahkan anggota tim dengan mencari akun mereka dan menugaskannya ke peran.

## Langkah 4: Atur Area Utama Anda

Setelah tim Anda siap, mulailah membangun area inti B1 Admin:

1. **People** -- Tambahkan anggota ke direktori gereja Anda. Ini adalah fondasi untuk segala hal lainnya, jadi mulailah dari sini. Anda dapat menambahkan orang secara manual atau menggunakan alat **Import/Export** dari **Settings**.
2. **Groups** -- Buat grup untuk kelompok kecil, tim pelayanan, kelas, dan pertemuan lainnya.
3. **Attendance** -- Konfigurasikan kampus, layanan, dan jadwal layanan untuk mencatat kehadiran.
4. **Donations** -- Atur dana donasi dan hubungkan gerbang pembayaran Anda (Stripe) untuk menerima pemberian online.
5. **Website** -- Bangun situs web gereja publik Anda menggunakan pembuat situs web B1.church.

:::info
Anda tidak perlu mengatur semua area sekaligus. Banyak gereja memulai dengan **People** dan **Groups**, lalu menambahkan **Attendance** dan **Donations** setelah mereka terbiasa dengan platform ini.
:::

## Urutan yang Disarankan

Untuk pengalaman pengaturan yang paling lancar, kami menyarankan urutan berikut:

1. **People** -- Tambahkan anggota dan jemaat tetap Anda terlebih dahulu.
2. **Groups** -- Kelompokkan orang ke dalam grup yang bermakna.
3. **Attendance** -- Mulai catat siapa yang hadir setiap minggu.
4. **Donations** -- Atur pemberian setelah data orang sudah masuk ke sistem.
5. **Website** -- Bangun situs publik Anda terakhir, setelah data Anda tersedia.

Setelah menyelesaikan langkah-langkah ini, gereja Anda siap digunakan. Jelajahi dokumentasi [B1 Admin](/docs/b1-admin/) untuk panduan rinci tentang setiap area.
