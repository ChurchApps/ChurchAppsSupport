# Erstes Setup

<div class="article-intro">

Nach der Erstellung Ihres Kontos und Ihrer Kirche gibt es einige wichtige Schritte zur Konfiguration, bevor Sie Ihr Team einladen. Dieser Leitfaden führt Sie durch die empfohlene Setup-Reihenfolge, damit Ihre Kirche vom ersten Tag an einsatzbereit ist.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- [Erstellen Sie Ihr Konto](./create-account.md) und registrieren Sie Ihre Kirche
- Halten Sie Ihr Kirchenlogo und Branding-Assets bereit (optional, aber empfohlen)

</div>

## Schritt 1: Konfigurieren Sie die Informationen Ihrer Kirche

1. Öffnen Sie das [Jump-Menü](../b1-admin/introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links in B1 Admin), erweitern Sie **Settings** und klicken Sie auf **Settings**.
2. Klicken Sie auf **Edit Settings**.
3. Geben Sie den **Namen** Ihrer Kirche, **Adresse** und **Kontaktdetails** ein.
4. Klicken Sie auf **Save**, um Ihre Änderungen anzuwenden.

## Schritt 2: Richten Sie Ihr Branding ein

1. Wählen Sie im Jump-Menü **Website > Appearance**.
2. Laden Sie Ihr **Kirchenlogo** hoch.
3. Konfigurieren Sie alle zusätzlichen Branding-Optionen wie Farben und Bilder.
4. Ihr Branding wird auf Ihrer B1.church-Website und in der B1 Mobile App angezeigt.

:::tip
Wenn Sie Ihr Logo und Branding bereit haben, bevor Sie Teammitglieder einladen, erhalten diese einen polierten ersten Eindruck, wenn sie sich anmelden.
:::

## Schritt 3: Konfigurieren Sie Rollen und laden Sie Ihr Team ein

1. Wählen Sie im Jump-Menü **Settings > Roles**.
2. Erstellen Sie Rollen für Ihr Team (z. B. "Pastor", "Secretary", "Treasurer").
3. Weisen Sie jeder Rolle die entsprechenden Berechtigungen zu.
4. Fügen Sie Teammitglieder hinzu, indem Sie nach ihren Konten suchen und sie Rollen zuweisen.

## Schritt 4: Richten Sie Ihre Schlüsselbereiche ein

Mit Ihrem Team an Ort und Stelle beginnen Sie, die Kernbereiche von B1 Admin zu entwickeln:

1. **People** -- Fügen Sie Mitglieder zu Ihrem Kirchenverzeichnis hinzu. Dies ist die Grundlage für alles andere, also fangen Sie hier an. Sie können Personen manuell hinzufügen oder das Werkzeug **Import** unter **Settings** verwenden.
2. **Groups** -- Erstellen Sie Gruppen für Kleingruppen, Ministerieteams, Klassen und andere Versammlungen.
3. **Attendance** -- Konfigurieren Sie Ihre Campusse, Dienstleistungen und Service-Zeiten zum Verfolgen von Anwesenheit.
4. **Donations** -- Richten Sie Spendenfonds ein und verbinden Sie Ihr Payment Gateway (Stripe), um Online-Spenden anzunehmen.
5. **Website** -- Erstellen Sie Ihre öffentliche Kirchenwebsite mit dem B1.church Website-Builder.

:::info
Sie müssen nicht alle Bereiche auf einmal einrichten. Viele Kirchen beginnen mit **People** und **Groups**, dann fügen sie **Attendance** und **Donations** hinzu, wenn sie sich mit der Plattform vertraut machen.
:::

## Empfohlene Reihenfolge

Für die reibungsloseste Setup-Erfahrung empfehlen wir diese Reihenfolge:

1. **People** -- Fügen Sie zuerst Ihre Mitglieder und regelmäßigen Besucher hinzu.
2. **Groups** -- Organisieren Sie Menschen in sinnvolle Gruppen.
3. **Attendance** -- Beginnen Sie zu verfolgen, wer jede Woche auftaucht.
4. **Donations** -- Richten Sie Spenden ein, sobald Ihre Personen im System sind.
5. **Website** -- Erstellen Sie Ihre öffentliche Website zuletzt, nachdem Ihre Daten vorhanden sind.

Sobald Sie diese Schritte abgeschlossen haben, ist Ihre Kirche einsatzbereit. Erkunden Sie die Dokumentation [B1 Admin](/docs/b1-admin/) für detaillierte Leitfäden zu jedem Bereich.
