# Konto erstellen

<div class="article-intro">

Der Einstieg in ChurchApps beginnt mit der Erstellung Ihres Kontos. Der Vorgang dauert nur wenige Minuten und verschafft Ihnen Zugang zu allen ChurchApps-Werkzeugen, darunter B1 Admin, B1.church und Lessons.church.

## Schritt-für-Schritt-Registrierung

1. Öffnen Sie [B1.church](https://b1.church) in Ihrem Webbrowser.
2. Klicken Sie auf die Schaltfläche **Registrieren**.
3. Geben Sie Ihren **Vornamen**, Ihren **Nachnamen** und Ihre **E-Mail-Adresse** ein — oder klicken Sie, falls in Ihrer Kirche Single Sign-on aktiviert ist, auf **Mit Google fortfahren** oder **Mit Microsoft fortfahren**, um direkt zu Schritt 5 zu springen und Ihr bestehendes Konto zu verwenden.
4. Erstellen Sie ein Passwort für Ihr Konto.
5. Senden Sie das Registrierungsformular ab.

:::info
Ein ChurchApps-Konto funktioniert für B1, Lessons.church und die anderen ChurchApps-Apps. Wenn Sie die Meldung **Sie haben bereits ein ChurchApps-Konto. Bitte melden Sie sich stattdessen damit an.** sehen, klicken Sie auf **Anmelden** und melden Sie sich mit dieser E-Mail-Adresse an. Verwenden Sie **Passwort vergessen**, falls Sie das Passwort nicht mehr wissen.
:::

## E-Mail-Adresse bestätigen

Nach der Registrierung erhalten Sie eine Bestätigungs-E-Mail an die von Ihnen angegebene Adresse.

1. Prüfen Sie Ihren Posteingang auf die Bestätigungs-E-Mail von ChurchApps.
2. Klicken Sie in der E-Mail auf den Bestätigungslink.
3. Ihr Konto ist nun bestätigt und einsatzbereit.

:::tip
Wenn Sie die Bestätigungs-E-Mail nicht sehen, prüfen Sie Ihren Spam- oder Junk-Ordner. Die E-Mail stammt von ChurchApps und kann ein bis zwei Minuten brauchen, bis sie ankommt.
:::

## Ihre Kirche einrichten

Nach der Bestätigung Ihrer E-Mail-Adresse und der Anmeldung können Sie entweder eine neue Kirche anlegen oder einer bestehenden Kirche beitreten.

**So legen Sie eine neue Kirche an:**

1. Wählen Sie die Option, eine **neue Kirche anzulegen**.
2. Geben Sie Ihren **Kirchennamen** und die grundlegenden Angaben ein. Das Registrierungsformular füllt Ihre Kirchendaten automatisch aus, sobald eine Übereinstimmung gefunden wird.
3. Schließen Sie den Einrichtungsprozess ab.
4. Sie gelangen zum **Dashboard**, der Startseite von B1 Admin, wo Sie mit der Konfiguration Ihrer Kirche beginnen können.

**So treten Sie einer bestehenden Kirche bei:**

1. Wählen Sie die Option, **einer bestehenden Kirche beizutreten**.
2. Suchen Sie Ihre Kirche anhand des Namens.
3. Senden Sie eine Beitrittsanfrage. Ein Administrator Ihrer Kirche muss Ihre Anfrage genehmigen.

:::info
Wenn Sie sich mit einer E-Mail-Adresse anmelden möchten, die noch nicht registriert ist, werden Sie automatisch zum Registrierungsablauf weitergeleitet, damit Sie ein Konto erstellen können.
:::

:::info
Die Person, die eine neue Kirche anlegt, erhält automatisch die Rolle **Domänenadministrator**, die vollen Zugriff auf alle Einstellungen und Funktionen gewährt. Weitere Administratoren können Sie später auf der Seite **Rollen** hinzufügen.
:::
