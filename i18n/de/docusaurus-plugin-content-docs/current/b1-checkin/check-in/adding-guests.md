# Gäste hinzufügen

<div class="article-intro">

Wenn jemand Ihre Familie besucht und sich zusammen mit Ihrem Haushalt einchecken möchte, können Sie diese Person direkt am Kiosk als Gast hinzufügen. Das ist nützlich für Besuchskinder, Verwandte oder Freunde, die noch nicht im Gemeindesystem erfasst sind.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- [Suchen Sie Ihre Familie](./looking-up-members.md) und wählen Sie ein Mitglied aus den Suchergebnissen aus
- Öffnen Sie den [Haushaltsprüfungsbildschirm](./household-review.md), auf dem Sie die Mitglieder Ihrer Familie sehen

</div>

## So fügen Sie einen Gast hinzu

1. Tippen Sie auf dem **Haushaltsprüfungsbildschirm** auf die Schaltfläche **Gast hinzufügen**, die sich unterhalb der Liste der Haushaltsmitglieder befindet.
2. Das Formular zum Hinzufügen eines Gastes wird angezeigt und enthält zwei Felder:
   - **Vorname** -- Geben Sie den Vornamen des Gastes ein.
   - **Nachname** -- Geben Sie den Nachnamen des Gastes ein.
3. Tippen Sie zum Speichern auf die Schaltfläche **Gast hinzufügen**.

Der Gast wird Ihrem Haushalt hinzugefügt, und Sie gelangen zurück zum Haushaltsprüfungsbildschirm. Der neue Gast erscheint in Ihrer Mitgliederliste neben den anderen Familienmitgliedern.

:::info
Wenn der Name des Gastes mit einer Person übereinstimmt, die bereits im System erfasst ist, aber kein Mitglied ist, verknüpft die App stattdessen diesen vorhandenen Datensatz, anstatt einen Duplikat zu erstellen. So bleibt die Gemeindedatenbank sauber.
:::

## Nach dem Hinzufügen eines Gastes

Sobald der Gast in Ihrer Haushaltsliste erscheint, können Sie:

- **Seine Karte aufklappen** und ihn [einer Gruppe zuweisen](./group-assignment.md), genau wie jedes andere Familienmitglied.
- **Den gesamten Haushalt einschließlich des Gastes [einchecken](./completing-checkin.md).**

## Abbrechen

Wenn Sie es sich anders überlegen, tippen Sie unten im Formular „Gast hinzufügen“ auf die Schaltfläche **Abbrechen**, um zum Haushaltsprüfungsbildschirm zurückzukehren, ohne jemanden hinzuzufügen.

:::tip
Wenn Sie am Kiosk einen Gast hinzufügen, wird ein Personendatensatz in der Gemeindedatenbank angelegt. Ihr Gemeindeadministrator kann die vollständigen Angaben des Gastes später in B1 Admin unter [Personen](../../b1-admin/people/adding-people.md) ergänzen.
:::

## Nächster Schritt

Nachdem Sie Gäste hinzugefügt und bei Bedarf [Gruppen zugewiesen](./group-assignment.md) haben, können Sie den [Check-in abschließen](./completing-checkin.md).
