# Druckereinrichtung

<div class="article-intro">

B1 Church Checkin kann Namensetiketten und Abholscheine an einen Netzwerk-Etikett-Drucker drucken. Die Druckereinrichtung ist optional.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- [Melden Sie sich](./logging-in) bei der B1 Church Checkin App an
- Verbinden Sie einen kompatiblen Netzwerk-Etikett-Drucker mit demselben Wi-Fi-Netzwerk wie das Tablet

</div>

## Empfohlene Etiketten

Das Standard-Etikett-Vorlagenlayout von B1 Checkin ist für **1,1" × 3,5"** Etiketten dimensioniert.

Wenn Sie einen **Brother QL-Drucker** verwenden, müssen Sie **Brother DK-1201** Etiketten (1,1" × 3,5") verwenden.

## Zugriff auf Druckereinstellungen

Sie können die Druckereinstellungen jederzeit über das Menü **Admin-Einstellungen** öffnen:

1. Tippen Sie auf das **Kirchenlogo** in der Kopfzeile **siebenmal** schnell hintereinander
2. Geben Sie die PIN ein, falls eine Kiosk-PIN gesetzt ist
3. Auf dem Bildschirm "Admin-Einstellungen" tippen Sie auf **Drucker ändern**

## Scannen nach Druckern

Das Scannen erfolgt automatisch nach Druckern in Ihrem lokalen Netzwerk.

:::warning
Das Tablet und der Drucker müssen mit dem gleichen lokalen Netzwerk verbunden sein, damit der Scan den Drucker findet.
:::

## Speichern Ihrer Auswahl

1. Tippen Sie auf den Drucker, den Sie verwenden möchten
2. Tippen Sie auf die Schaltfläche **Speichern und Neu starten** am unteren Rand des Bildschirms
