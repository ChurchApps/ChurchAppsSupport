# Gruppenkalender

<div class="article-intro">

Jede Gruppe in B1 kann einen eigenen Veranstaltungskalender haben. Gruppenleitende nutzen ihn, um Treffen, Aktivitäten und wiederkehrende Termine zu planen, während alle Gruppenmitglieder die kommenden Veranstaltungen einsehen und sich an Gesprächen dazu beteiligen können. Der Kalender hält Ihre Gruppe organisiert und sorgt dafür, dass alle über anstehende Termine informiert sind.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen eine in B1 Admin angelegte Gruppe mit mindestens einem Mitglied. Siehe [Gruppen anlegen](creating-groups.md) und [Gruppenmitglieder](group-members.md).
- Um Kalendertermine hinzuzufügen oder zu bearbeiten, müssen Sie als Gruppenleitung festgelegt sein. Anleitung dazu unter [Gruppenleitungen festlegen](group-members.md).

</div>

## Auf den Gruppenkalender zugreifen

Der Gruppenkalender ist über die Mitgliederansicht von B1.church verfügbar:

1. Klicken Sie in B1 Admin oben rechts auf das **Dropdown-Menü**.
2. Wählen Sie **App wechseln**.
3. Wählen Sie **B1.church**.
4. Öffnen Sie **Gruppen** (ein Tab in der unteren Leiste auf dem Smartphone bzw. in der oberen Kopfzeile auf dem Computer).
5. Wählen Sie Ihre Gruppe aus der Liste aus.
6. Klicken Sie unter **Nächste Veranstaltung** auf **Alle Veranstaltungen**, um die Ansicht **Veranstaltungen** der Gruppe zu öffnen. Mit dem Schalter **Kalender** wechseln Sie dort zur Monatsansicht.

:::info
Der Gruppenkalender wird über B1.church (die Mitglieder-App) verwaltet, nicht über B1 Admin. Gruppenleitende erreichen ihn, indem sie im Admin-Dashboard die App wechseln.
:::

## Eine Veranstaltung hinzufügen

1. Klicken Sie im Gruppenkalender auf **Veranstaltung hinzufügen**.
2. Geben Sie einen **Titel** für die Veranstaltung ein.
3. Schreiben Sie eine kurze **Beschreibung**, worum es bei der Veranstaltung geht.
4. Legen Sie die **Startzeit** und die **Endzeit** fest.
5. Klicken Sie auf **Speichern**, um die Veranstaltung dem Kalender hinzuzufügen.

## Wiederkehrende Veranstaltungen einrichten

Wenn sich Ihre Gruppe regelmäßig trifft, können Sie Veranstaltungen automatisch wiederholen lassen:

1. Aktivieren Sie beim Anlegen oder Bearbeiten einer Veranstaltung das Kästchen **Wiederkehrend**.
2. Legen Sie fest, wie sich die Veranstaltung wiederholen soll:
   - **Intervall** – Geben Sie die Anzahl der Tage zwischen den Terminen an. Wenn Sie „7“ eingeben, wiederholt sich die Veranstaltung alle 7 Tage.
   - **Häufigkeit** – Wählen Sie, ob sich die Veranstaltung nach **Tag**, **Woche** oder **Monat** wiederholen soll.
3. Speichern Sie die Veranstaltung. Sie erscheint nun bei jedem geplanten Termin im Kalender.

:::tip
Für eine Gruppe, die sich jeden Samstag trifft, stellen Sie die Häufigkeit auf „Woche“ und wählen Sie Samstag. Die Veranstaltung wird dann automatisch für die Zukunft im Kalender eingetragen.
:::

## Veranstaltungen in B1 Admin in einem Schritt anlegen

Auf der Seite der Gruppe in B1 Admin gibt es außerdem einen Abschnitt **Kalender**, in dem Mitarbeitende gleich eine ganze Serie von Treffen planen können:

1. Öffnen Sie die Gruppe in B1 Admin und klicken Sie im Abschnitt **Kalender** auf **Alle Veranstaltungen**.
2. Klicken Sie auf **+ Veranstaltungen hinzufügen**, um den Dialog **Wiederkehrende Veranstaltungen hinzufügen** zu öffnen.
3. Wählen Sie den Rhythmus (wöchentlich, alle 2 Wochen, monatlich oder einmalig), das Datum des **ersten Treffens** und des **letzten Treffens** sowie optional **Feiertage überspringen**.
4. Prüfen Sie die Vorschau der Termine und entfernen Sie das Häkchen bei allen Terminen, die übersprungen werden sollen.
5. Lassen Sie **RSVPs zulassen** aktiviert, wenn Mitglieder auf diese Veranstaltungen antworten können sollen (siehe unten), und speichern Sie anschließend.

## Teilnahmerückmeldungen (RSVPs)

Gruppenveranstaltungen können Teilnahmerückmeldungen sammeln – ein **Ja**, **Nein** oder **Vielleicht** für jeden Termin der Veranstaltung.

- **RSVPs zulassen** ist bei Veranstaltungen standardmäßig aktiviert, die über den Dialog zum Massenhinzufügen angelegt werden. Entfernen Sie das Häkchen, um Rückmeldungen für diese Veranstaltungen zu deaktivieren. Veranstaltungen ohne RSVPs werden in der Veranstaltungsliste der Gruppe als **Deaktiviert** angezeigt.
- In der Veranstaltungsliste der Gruppe in B1 Admin zeigt jede Veranstaltung eine Zusammenfassung der Rückmeldungen (zum Beispiel „5 Ja · 2 Vielleicht · 1 Nein“). Klicken Sie darauf, um die Liste **RSVP-Antworten** zu öffnen. Sie zeigt, wer für diesen Termin mit Ja, Vielleicht und Nein geantwortet hat.

:::tip
RSVPs geben Leitenden eine Teilnehmerzahl, ohne den Aufwand einer vollständigen Veranstaltungsanmeldung. Für kostenpflichtige Anmeldungen oder Veranstaltungen mit begrenzten Plätzen verwenden Sie stattdessen die [Veranstaltungsanmeldung](../calendars/creating-calendars.md#enabling-event-registration).
:::

## Den Kalender ansehen

Der Gruppenkalender bietet mehrere Ansichten:

- **Monat** – Der ganze Monat auf einen Blick.
- **Woche** – Konzentration auf die aktuelle Woche.
- **Tag** – Ein einzelner Tag im Detail.
- **Agenda** – Eine chronologische Liste der kommenden Veranstaltungen.

Wechseln Sie zwischen den Ansichten über die Schaltflächen oben im Kalender.

## Veranstaltungsdetails und Gespräche

Klicken Sie auf eine Veranstaltung, um deren Details anzuzeigen. In der Detailansicht gilt:

- **Mitglieder und Leitende** können Gespräche beginnen und Kommentare zur Veranstaltung hinterlassen.
- **Leitende** können Veranstaltungsdetails bearbeiten, Zeiten ändern oder die Veranstaltung löschen.

:::warning
Beim Löschen einer Veranstaltung wird sie dauerhaft entfernt. Wenn Sie nur einen einzelnen Termin einer wiederkehrenden Veranstaltung absagen möchten, bearbeiten Sie die Veranstaltung lieber.
:::

## Den Kalender abonnieren

Sie können den Gruppenkalender mit Ihrem persönlichen Kalender synchronisieren:

1. Klicken Sie auf der Seite des Gruppenkalenders auf **Abonnieren**.
2. Folgen Sie den Anweisungen, um den Kalender zu Google Kalender, Apple Kalender, Outlook oder einer anderen Kalender-App hinzuzufügen, die Abonnements unterstützt.

:::tip
Wenn Sie abonnieren, bleibt Ihr persönlicher Terminplan mit den Veranstaltungen Ihrer Gruppe synchron, ohne dass Sie B1 separat aufrufen müssen. Änderungen der Gruppenleitung erscheinen automatisch in Ihrem synchronisierten Kalender.
:::
