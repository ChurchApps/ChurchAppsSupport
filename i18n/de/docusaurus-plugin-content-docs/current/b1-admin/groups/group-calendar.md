# Gruppenkalender

<div class="article-intro">

Jede Gruppe in B1 kann ihren eigenen Ereigniskalender haben. Gruppenleiter verwenden ihn, um Treffen, Aktivitäten und wiederkehrende Ereignisse zu planen, während alle Gruppenmitglieder anstehende Ereignisse anzeigen und über sie sprechen können. Der Kalender hält deine Gruppe organisiert und stellt sicher, dass jeder über das Kommende informiert bleibt.

</div>

<div class="prereqs">
<h4>Bevor du beginnst</h4>

- Du brauchst eine Gruppe, die in B1 Admin mit mindestens einem Mitglied erstellt wurde. Siehe [Gruppen erstellen](creating-groups.md) und [Gruppenmitglieder](group-members.md).
- Um Kalenderereignisse hinzuzufügen oder zu bearbeiten, musst du als Gruppenleiter bestimmt werden. Siehe [Gruppenbücher bestimmen](group-members.md) für Anweisungen.

</div>

## Zugriff auf den Gruppenkalender

Der Gruppenkalender ist über die B1.church-App für Mitglieder verfügbar:

1. Klicke von B1 Admin auf das **Dropdown-Menü** in der oberen rechten Ecke deines Bildschirms.
2. Wähle **App wechseln**.
3. Wähle **B1.church**.
4. Klicke auf **Gruppen** in der linken Seitenleiste.
5. Wähle deine Gruppe aus der Liste.
6. Klicke auf der linken Seite des Bildschirms auf **Kalender**.

:::info
Der Gruppenkalender wird über B1.church (die Member-App) statt über B1 Admin verwaltet. Gruppenleiter greifen darauf zu, indem sie vom Admin-Dashboard aus Apps wechseln.
:::

## Ein Ereignis hinzufügen

1. Klicke auf dem Gruppenkalender auf **Ein Ereignis hinzufügen**.
2. Gib einen **Titel** für das Ereignis ein.
3. Schreibe eine kurze **Beschreibung** des Ereignisinhalts.
4. Stelle die **Startzeit** und **Endzeit** ein.
5. Klicke auf **Speichern**, um das Ereignis zum Kalender hinzuzufügen.

## Wiederkehrende Ereignisse einrichten

Wenn sich deine Gruppe nach einem festen Zeitplan trifft, kannst du Ereignisse automatisch wiederholen lassen:

1. Wenn du ein Ereignis erstellst oder bearbeitest, aktiviere das Kontrollkästchen **Wiederkehrend**.
2. Wähle, wie das Ereignis wiederholt werden soll:
   - **Intervall** -- Lege eine Anzahl von Tagen zwischen Vorkommen fest. Wenn du beispielsweise "7" eingibst, wird das Ereignis alle 7 Tage wiederholt.
   - **Häufigkeit** -- Wähle, ob du täglich, wöchentlich oder monatlich wiederholen möchtest.
3. Speichere das Ereignis. Es wird jetzt bei jedem geplanten Ereignis im Kalender angezeigt.

:::tip
Für eine Gruppe, die sich jeden Samstag trifft, lege die Häufigkeit auf "Woche" fest und wähle Samstag. Das Ereignis wird sich automatisch im Kalender mit Blick nach vorne füllen.
:::

## Massenerstellen von Ereignissen in B1 Admin

Die Seite der Gruppe in B1 Admin hat auch eine Registerkarte **Kalender**, auf der Mitarbeiter eine ganze Saison von Treffen auf einmal planen können:

1. Öffne die Gruppe in B1 Admin und wähle die Registerkarte **Kalender**.
2. Klicke auf **Ereignisse hinzufügen**, um den Dialog **Wiederkehrende Ereignisse hinzufügen** zu öffnen.
3. Wähle den Zeitplan (wöchentlich, alle 2 Wochen, monatlich oder einmalig), die Daten des **Ersten Treffens** und des **Letzten Treffens** und optional **Feiertage überspringen**.
4. Überprüfe die Vorschau der Treffendaten und deaktiviere alle zum Überspringen.
5. Lasse **RSVPs erlauben** aktiviert, wenn Mitglieder auf diese Ereignisse reagieren können (siehe unten), speichere dann.

## Ereignis-RSVPs

Gruppenereignisse können RSVPs sammeln - ein **Ja**, **Nein** oder **Vielleicht** für jedes Ereignisvorkommen.

- **RSVPs erlauben** ist standardmäßig für Ereignisse aktiviert, die über den Massenhinzufügen-Dialog erstellt wurden; deaktiviere dies, um Antworten für diese Ereignisse auszuschalten. Ereignisse mit deaktiviertem RSVP werden auf der Kalenderregisterkarte als **Deaktiviert** angezeigt.
- Auf der Gruppenkalender-Registerkarte von B1 Admin zeigt jedes Ereignis eine Antwortzusammenfassung an (z. B. "5 ja · 2 vielleicht · 1 nein"). Klicke durch, um das Klassenbuch **RSVP-Antworten** zu öffnen, das auflistet, wer für diese Veranstaltung mit ja, vielleicht und nein geantwortet hat.

:::tip
RSVPs geben Führungskräften eine Kopfzahl ohne die Formalität der vollständigen Ereignisregistrierung. Verwende für bezahlte Anmeldungen oder kapazitätsverwaltete Ereignisse stattdessen [Ereignisregistrierung](../calendars/creating-calendars.md#enabling-event-registration).
:::

## Anzeigen des Kalenders

Der Gruppenkalender bietet mehrere Anzeigeoptionen:

- **Monat** -- Sehen Sie den ganzen Monat auf einen Blick.
- **Woche** -- Konzentriere dich auf die aktuelle Woche.
- **Tag** -- Sehen Sie einen einzelnen Tag im Detail.
- **Agenda** -- Sehen Sie eine Liste der anstehenden Ereignisse in chronologischer Reihenfolge.

Wechsle zwischen den Ansichten mithilfe der Schaltflächen oben im Kalender.

## Ereignisdetails und Gespräche

Klicke auf ein Ereignis, um seine Details anzuzeigen. Aus der Ereignisdetailansicht:

- **Mitglieder und Anführer** können Gespräche beginnen und Kommentare zum Ereignis hinterlassen.
- **Leiter** können Ereignisdetails bearbeiten, Zeiten ändern oder das Ereignis löschen.

:::warning
Das Löschen eines Ereignisses entfernt es dauerhaft. Wenn du ein einzelnes Vorkommen eines wiederkehrenden Ereignisses stornieren musst, solltest du es stattdessen bearbeiten.
:::
