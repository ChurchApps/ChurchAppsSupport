# Gruppenkalender

<div class="article-intro">

Jede Gruppe in B1 kann einen eigenen Veranstaltungskalender haben. Gruppenleitungen nutzen ihn, um Treffen, Aktivitäten und wiederkehrende Termine zu planen, während alle Gruppenmitglieder die kommenden Veranstaltungen ansehen und sich an Gesprächen dazu beteiligen können. Der Kalender hält Ihre Gruppe organisiert und sorgt dafür, dass alle über bevorstehende Termine informiert sind.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen eine in B1 Admin angelegte Gruppe mit mindestens einem Mitglied. Siehe [Gruppen erstellen](creating-groups.md) und [Gruppenmitglieder](group-members.md).
- Um Kalendereinträge hinzuzufügen oder zu bearbeiten, müssen Sie als Gruppenleitung festgelegt sein. Anleitung dazu finden Sie unter [Gruppenleitungen festlegen](group-members.md).

</div>

## Auf den Gruppenkalender zugreifen

Der Gruppenkalender ist über die Mitglieder-App B1.church verfügbar:

1. Klicken Sie in B1 Admin oben rechts auf dem Bildschirm auf das **Dropdown-Menü**.
2. Wählen Sie **Switch App**.
3. Wählen Sie **B1.church**.
4. Öffnen Sie **Groups** (ein Reiter in der unteren Reiterleiste auf dem Telefon oder in der oberen Kopfzeile auf dem Computer).
5. Wählen Sie Ihre Gruppe aus der Liste.
6. Klicken Sie unter **Next event** auf **All events**, um die Ansicht **Events** der Gruppe zu öffnen. Verwenden Sie dort den Umschalter **Calendar** für eine Monatsansicht.

:::info
Der Gruppenkalender wird über B1.church (die Mitglieder-App) verwaltet und nicht über B1 Admin. Gruppenleitungen erreichen ihn, indem sie im Admin-Dashboard die App wechseln.
:::

## Eine Veranstaltung hinzufügen

1. Klicken Sie im Gruppenkalender auf **Add Event**.
2. Geben Sie einen **Titel** für die Veranstaltung ein.
3. Schreiben Sie eine kurze **Beschreibung**, worum es bei der Veranstaltung geht.
4. Legen Sie die **Startzeit** und die **Endzeit** fest.
5. Klicken Sie auf **Save**, um die Veranstaltung dem Kalender hinzuzufügen.

## Wiederkehrende Veranstaltungen einrichten

Wenn Ihre Gruppe sich regelmäßig trifft, können Sie Veranstaltungen automatisch wiederholen lassen:

1. Aktivieren Sie beim Erstellen oder Bearbeiten einer Veranstaltung das Kästchen **Recurring**.
2. Wählen Sie, wie sich die Veranstaltung wiederholen soll:
   - **Interval** -- Legen Sie eine Anzahl von Tagen zwischen den Terminen fest. Geben Sie zum Beispiel „7“ ein, wiederholt sich die Veranstaltung alle 7 Tage.
   - **Frequency** -- Wählen Sie, ob sich die Veranstaltung nach **day**, **week** oder **month** wiederholt.
3. Speichern Sie die Veranstaltung. Sie erscheint nun bei jedem geplanten Termin im Kalender.

:::tip
Trifft sich eine Gruppe jeden Samstag, stellen Sie die Frequenz auf „week“ und wählen Sie Samstag. Die Veranstaltung wird dann automatisch für die Zukunft im Kalender eingetragen.
:::

## Veranstaltungen in B1 Admin in einem Schritt anlegen

Auf der Seite der Gruppe in B1 Admin gibt es außerdem einen Abschnitt **Calendar**, in dem Mitarbeitende eine ganze Reihe von Treffen auf einmal planen können:

1. Öffnen Sie die Gruppe in B1 Admin und klicken Sie im Abschnitt **Calendar** auf **All events**.
2. Klicken Sie auf **+ Add Events**, um den Dialog **Add Recurring Events** zu öffnen.
3. Wählen Sie den Rhythmus (wöchentlich, alle 2 Wochen, monatlich oder einmalig), das Datum des **First Meeting** und des **Last Meeting** sowie optional **Skip holidays**.
4. Prüfen Sie die Vorschau der Termine und entfernen Sie das Häkchen bei Terminen, die übersprungen werden sollen.
5. Lassen Sie **Allow RSVPs** aktiviert, wenn Mitglieder auf diese Veranstaltungen antworten können sollen (siehe unten), und speichern Sie dann.

## Rückmeldungen (RSVPs) zu Veranstaltungen

Gruppenveranstaltungen können Rückmeldungen sammeln – ein **Yes**, **No** oder **Maybe** für jeden Termin der Veranstaltung.

- **Allow RSVPs** ist bei Veranstaltungen, die über den Dialog zum Massenhinzufügen erstellt werden, standardmäßig aktiviert; entfernen Sie das Häkchen, um Rückmeldungen für diese Veranstaltungen zu deaktivieren. Veranstaltungen ohne Rückmeldungen werden in der Veranstaltungsliste der Gruppe als **Disabled** angezeigt.
- In der Veranstaltungsliste der Gruppe in B1 Admin zeigt jede Veranstaltung eine Zusammenfassung der Rückmeldungen (zum Beispiel „5 yes · 2 maybe · 1 no“). Klicken Sie darauf, um die Liste **RSVP Responses** zu öffnen, die für diesen Termin aufführt, wer mit Ja, Vielleicht oder Nein geantwortet hat.

:::tip
Rückmeldungen geben Leitungen eine Teilnehmerzahl, ohne den Aufwand einer vollständigen Veranstaltungsanmeldung. Für kostenpflichtige Anmeldungen oder Veranstaltungen mit begrenzten Plätzen nutzen Sie stattdessen die [Veranstaltungsanmeldung](../calendars/creating-calendars.md#enabling-event-registration).
:::

## Den Kalender ansehen

Der Gruppenkalender bietet mehrere Ansichten:

- **Month** -- Der ganze Monat auf einen Blick.
- **Week** -- Konzentriert auf die aktuelle Woche.
- **Day** -- Ein einzelner Tag im Detail.
- **Agenda** -- Eine chronologisch sortierte Liste der kommenden Veranstaltungen.

Wechseln Sie zwischen den Ansichten über die Schaltflächen oben im Kalender.

## Veranstaltungsdetails und Gespräche

Klicken Sie auf eine Veranstaltung, um ihre Details anzuzeigen. In der Detailansicht gilt:

- **Mitglieder und Leitungen** können Gespräche beginnen und Kommentare zur Veranstaltung hinterlassen.
- **Leitungen** können die Details der Veranstaltung bearbeiten, Zeiten ändern oder die Veranstaltung löschen.

:::warning
Das Löschen einer Veranstaltung entfernt sie dauerhaft. Wenn Sie nur einen einzelnen Termin einer wiederkehrenden Veranstaltung absagen möchten, bearbeiten Sie sie lieber.
:::

## Den Kalender abonnieren

Sie können den Gruppenkalender mit Ihrem persönlichen Kalender synchronisieren:

1. Klicken Sie auf der Seite des Gruppenkalenders auf **Subscribe**.
2. Folgen Sie den Anweisungen, um den Kalender zu Google Kalender, Apple Kalender, Outlook oder einer anderen Kalenderanwendung hinzuzufügen, die Abonnements unterstützt.

:::tip
Ein Abonnement hält Ihren persönlichen Terminplan mit den Veranstaltungen Ihrer Gruppe synchron, ohne dass Sie B1 separat prüfen müssen. Änderungen, die Gruppenleitungen vornehmen, erscheinen automatisch in Ihrem synchronisierten Kalender.
:::
