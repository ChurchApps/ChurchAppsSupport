# Gruppen anlegen

<div class="article-intro">

Eine Gruppe in B1 Admin anzulegen ist unkompliziert. Sie richten eine Kategorie ein, benennen Ihre Gruppe und konfigurieren anschließend deren Einstellungen. Gruppen helfen Ihnen, Ihre Kirche in sinnvolle Einheiten zu gliedern, etwa Kleingruppen, Ausschüsse und Kurse.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen ein aktives B1-Admin-Konto mit der Berechtigung, Gruppen zu verwalten. Siehe [Rollen & Berechtigungen](../people/roles-permissions.md), wenn Sie sich über Ihre Zugriffsstufe nicht sicher sind.
- Überlegen Sie sich eine Kategoriestruktur für Ihre Gruppen (zum Beispiel "Kleingruppen", "Dienste", "Ausschüsse"). Kategorien halten zusammengehörige Gruppen übersichtlich.

## Eine neue Gruppe anlegen

1. Öffnen Sie das [Sprungmenü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links in B1 Admin), klappen Sie **Personen** auf und klicken Sie auf **Gruppen**.
2. Klicken Sie im Seitenkopf auf **Gruppe hinzufügen**. Unter der Liste öffnet sich ein Formular **Neue Gruppe**. Geben Sie einen **Kategorienamen** ein. Kategorien helfen Ihnen, zusammengehörige Gruppen zu ordnen (zum Beispiel "Kleingruppen", "Dienste" oder "Ausschüsse"). Existiert eine Kategorie bereits, können Sie sie aus der Liste auswählen.
3. Geben Sie den **Namen** der Gruppe ein.
4. Klicken Sie auf **Hinzufügen**. Ihre neue Gruppe erscheint in der Liste, und ihre Kategorie wird unter ihrem Namen angezeigt.

## Gruppeneinstellungen konfigurieren

Sobald Ihre Gruppe angelegt ist, können Sie weitere Angaben ergänzen:

1. Klicken Sie auf den **Gruppennamen** in der Liste, um die Gruppe zu öffnen.
2. Klicken Sie auf die Schaltfläche **Bearbeiten** auf der linken Seite der Gruppenseite, unterhalb der Angaben zur Gruppe.
3. Konfigurieren Sie die folgenden Optionen:
   - **Beschreibung** -- eine kurze Zusammenfassung, worum es in der Gruppe geht. Sie ist für Mitglieder sichtbar.
   - **Treffzeiten** -- wann sich die Gruppe in der Regel trifft (zum Beispiel "Mittwochs um 19 Uhr").
   - **Beitrittsregel** -- legen Sie fest, wer dieser Gruppe beitreten kann:
     - **Offen** -- Jeder kann sofort ohne Genehmigung beitreten
     - **Anfrage** -- Personen müssen eine Beitrittsanfrage stellen, die genehmigt werden muss (siehe [Gruppenbeitrittsanfragen](./group-join-requests.md))
     - **Geschlossen** -- Mitglieder müssen von Leitungen oder Administratoren manuell hinzugefügt werden
   - **Labels** -- Weisen Sie der Gruppe eine oder mehrere beschreibende Labels zu (zum Beispiel "Vor Ort", "Online", "Neue Mitglieder willkommen"). Labels sind frei definierbare Schlagwörter; markieren Sie alle zutreffenden. Labels können verwendet werden, um Gruppen im Website-Element "Gruppenübersicht" zu filtern.
   - **Vertrauliche Gruppe** -- blendet diese Gruppe und ihre Mitgliederliste auf öffentlichen Seiten, in der Gruppensuche und vor Nichtmitgliedern aus. Verwenden Sie dies für sensible Gruppen wie Suchtberatung oder seelsorgerliche Angebote; nur die Mitglieder der Gruppe und die Mitarbeiter der Kirche können sie sehen.
   - **Diskussionen** -- schaltet den Chat-Verlauf der Gruppe ein oder aus, in dem jedes Mitglied schreiben kann. Standardmäßig eingeschaltet.
   - **Ankündigungen** -- schaltet einen zweiten Chat-Verlauf ein, der nur für Leitungen schreibbar ist -- Mitglieder können lesen und reagieren, aber nur Leitungen können schreiben. Standardmäßig eingeschaltet.
   - **Anwesenheitserfassung** -- aktivieren Sie dies, wenn Sie die [Anwesenheit](../attendance/tracking-attendance.md) für diese Gruppe erfassen möchten.
   - **Gottesdienstzeiten** -- ordnen Sie die Gruppe gegebenenfalls bestimmten Gottesdienstzeiten Ihrer Kirche zu. Details zu Gottesdienstzeiten finden Sie unter [Anwesenheits-Einrichtung](../attendance/setup.md).
4. Klicken Sie auf **Speichern**, um Ihre Änderungen zu übernehmen.

:::tip
Eine klare Beschreibung und eine Treffzeit helfen Mitgliedern zu wissen, was sie erwartet, wenn sie einer Gruppe beitreten.
:::

:::info
Schalten Sie sowohl Diskussionen als auch Ankündigungen aus, entfernt dies den Reiter Nachrichten für die Gruppe im Mitgliederbereich vollständig. Schalten Sie nur eine der beiden aus, verschwindet nur deren Reiter, und Mitglieder gelangen zu dem Verlauf, der noch aktiv ist. Bestehende Nachrichten bleiben in beiden Fällen erhalten -- die Schalter steuern nur das Schreiben neuer Beiträge.
:::

## Eine Gruppe duplizieren

Starten Sie eine neue Durchführung eines wiederkehrenden Kurses oder Dienstes? Anstatt alle Einstellungen erneut einzugeben, duplizieren Sie eine vorhandene Gruppe:

1. Öffnen Sie die Gruppe und klicken Sie auf **Duplizieren** (unterhalb der Schaltfläche **Bearbeiten** auf der linken Seite der Gruppenseite).
2. Bestätigen Sie das Duplizieren.

Die Kopie übernimmt die Einstellungen des Originals -- Kategorie, Beschreibung, Treffzeit/Treffpunkt, Beitrittsregel, Labels und Standort -- aber **nicht** deren Mitglieder. Die neue Gruppe erhält den Namen des Originals mit angehängtem " (Kopie)"; benennen Sie sie in den Gruppeneinstellungen um.

## Eine Gruppe archivieren

Wenn eine Gruppe nicht mehr aktiv ist, Sie aber ihren Verlauf behalten möchten, statt sie zu löschen:

1. Öffnen Sie die Gruppe und klicken Sie auf **Bearbeiten**, um ihre Einstellungen zu ändern.
2. Klicken Sie auf **Archivieren** und bestätigen Sie.

Archivierte Gruppen verschwinden aus der Hauptliste der Gruppen. Um eine archivierte Gruppe wiederzufinden, klicken Sie oben auf der Seite Gruppen neben den Kategorieschaltflächen auf **Archivierte anzeigen** und anschließend neben der Gruppe auf **Wiederherstellen**, um sie zurückzuholen.

:::info
Das Archivieren einer Gruppe löscht nicht deren Mitglieder, Anwesenheitsverlauf oder Kalendertermine -- es blendet die Gruppe nur aus der Standardliste aus, bis Sie sie wiederherstellen.
:::

## Wie geht es weiter?

Nachdem Sie Ihre Gruppe angelegt und konfiguriert haben, können Sie:

- **Mitglieder hinzufügen** -- Suchen Sie Personen und fügen Sie sie der Gruppe hinzu. Verwenden Sie das Sternsymbol (**Zur Leitung machen**), um Gruppenleitungen zu bestimmen. Siehe [Gruppenmitglieder](./group-members.md).
- **Einen Kalender einrichten** -- Legen Sie Termine und wiederkehrende Treffen für die Gruppe an. Siehe [Gruppenkalender](./group-calendar.md).
- **Kommunizieren** -- Senden Sie Nachrichten direkt von der Gruppenseite an alle Gruppenmitglieder.
- **Daten exportieren** -- Klicken Sie oberhalb der Mitgliederliste der Gruppe auf **Exportieren**, um sie herunterzuladen.

:::info
Jede Gruppe gehört zu einer Kategorie, und auf der Hauptseite Gruppen können Sie die Liste nach Kategorie filtern. Sie können Kategorien jederzeit umordnen oder umbenennen, wenn Ihre Kirche wächst.
:::
