# Gruppen erstellen

<div class="article-intro">

Eine Gruppe in B1 Admin anzulegen ist unkompliziert. Sie legen eine Kategorie fest, benennen Ihre Gruppe und konfigurieren anschließend ihre Einstellungen. Gruppen helfen Ihnen, Ihre Gemeinde in sinnvolle Einheiten zu gliedern, etwa Hauskreise, Ausschüsse und Klassen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen ein aktives B1-Admin-Konto mit der Berechtigung, Gruppen zu verwalten. Wenn Sie unsicher sind, welche Zugriffsrechte Sie haben, lesen Sie [Rollen & Berechtigungen](../people/roles-permissions.md).
- Überlegen Sie sich eine Kategoriestruktur für Ihre Gruppen (zum Beispiel „Hauskreise“, „Dienste“, „Ausschüsse“). Kategorien halten zusammengehörige Gruppen übersichtlich.

</div>

## Eine neue Gruppe hinzufügen

1. Öffnen Sie das [Sprungmenü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links in B1 Admin), klappen Sie **Personen** auf und klicken Sie auf **Gruppen**.
2. Klicken Sie im Seitenkopf auf **Gruppe hinzufügen**. Unterhalb der Liste öffnet sich ein Formular **Neue Gruppe**. Geben Sie einen **Kategorienamen** ein. Kategorien helfen Ihnen, zusammengehörige Gruppen zu bündeln (zum Beispiel „Hauskreise“, „Dienste“ oder „Ausschüsse“). Ist eine Kategorie bereits vorhanden, können Sie sie aus der Liste auswählen.
3. Geben Sie den **Namen** der Gruppe ein.
4. Klicken Sie auf **Hinzufügen**. Ihre neue Gruppe erscheint in der Liste, mit ihrer Kategorie unter dem Namen.

## Gruppeneinstellungen konfigurieren

Sobald Ihre Gruppe angelegt ist, können Sie weitere Angaben ergänzen:

1. Klicken Sie in der Liste auf den **Gruppennamen**, um die Gruppe zu öffnen.
2. Klicken Sie links auf der Gruppenseite unterhalb der Angaben zur Gruppe auf die Schaltfläche **Bearbeiten**.
3. Konfigurieren Sie die folgenden Optionen:
   - **Beschreibung** -- Eine kurze Zusammenfassung, worum es in der Gruppe geht. Sie ist für Mitglieder sichtbar.
   - **Treffzeiten** -- Wann sich die Gruppe in der Regel trifft (zum Beispiel „Mittwochs um 19 Uhr“).
   - **Beitrittsregel** -- Legen Sie fest, wer dieser Gruppe beitreten kann:
     - **Offen** -- Jede Person kann sofort ohne Genehmigung beitreten
     - **Anfrage** -- Personen müssen eine Beitrittsanfrage stellen, die genehmigt werden muss (siehe [Beitrittsanfragen zu Gruppen](./group-join-requests.md))
     - **Geschlossen** -- Mitglieder müssen von Leitungen oder Administrator:innen manuell hinzugefügt werden
   - **Labels** -- Weisen Sie der Gruppe eine oder mehrere beschreibende Bezeichnungen zu (zum Beispiel „Vor Ort“, „Online“, „Neue Mitglieder willkommen“). Labels sind frei definierbare Schlagwörter. Wählen Sie alle zutreffenden aus. Labels können verwendet werden, um Gruppen im Website-Element „Gruppen-Browser“ zu filtern. Ein Website-Element „Gruppenliste“ zeigt die Gruppen mit einem bestimmten Label an.
   - **Vertrauliche Gruppe** -- Blendet diese Gruppe und ihre Teilnehmerliste auf öffentlichen Seiten, in der Gruppensuche und für Nicht-Mitglieder aus. Nutzen Sie dies für sensible Gruppen wie Suchtberatung oder Seelsorge. Nur die Mitglieder der Gruppe und das Hauptamt können sie sehen.
   - **Diskussionen** -- Schaltet den Chat-Verlauf der Gruppe ein oder aus. Alle Mitglieder können dort Beiträge verfassen. Standardmäßig eingeschaltet.
   - **Ankündigungen** -- Schaltet einen zweiten Chat-Verlauf ein, in dem nur Leitungen schreiben dürfen. Mitglieder können ihn lesen und darauf reagieren, aber nur Leitungen können Beiträge verfassen. Standardmäßig eingeschaltet.
   - **Anwesenheitserfassung** -- Aktivieren Sie dies, wenn Sie die [Anwesenheit](../attendance/tracking-attendance.md) für diese Gruppe erfassen möchten.
   - **Gottesdienstzeiten** -- Verknüpfen Sie die Gruppe gegebenenfalls mit bestimmten Gottesdienstzeiten. Details zu Gottesdienstzeiten finden Sie unter [Einrichtung der Anwesenheit](../attendance/setup.md).
4. Klicken Sie auf **Speichern**, um Ihre Änderungen zu übernehmen.

:::tip
Eine klare Beschreibung und eine Treffzeit helfen Mitgliedern, zu wissen, was sie beim Beitritt erwartet.
:::

:::info
Wenn Sie sowohl Diskussionen als auch Ankündigungen ausschalten, verschwindet der Reiter Nachrichten für die Gruppe im Mitgliederbereich vollständig. Schalten Sie nur eines der beiden aus, wird nur dessen Reiter ausgeblendet, und Mitglieder landen im verbleibenden Verlauf. Bestehende Nachrichten bleiben in jedem Fall erhalten. Die Schalter steuern nur das Verfassen neuer Beiträge.
:::

## Eine Gruppe duplizieren

Starten Sie eine neue Runde einer wiederkehrenden Klasse oder eines Dienstes? Anstatt alle Einstellungen erneut einzugeben, duplizieren Sie eine bestehende Gruppe:

1. Öffnen Sie die Gruppe und klicken Sie auf **Duplizieren** (unterhalb der Schaltfläche **Bearbeiten** auf der linken Seite der Gruppenseite).
2. Bestätigen Sie das Duplizieren.

Die Kopie übernimmt die Einstellungen des Originals, also Kategorie, Beschreibung, Treffzeit/Treffort, Beitrittsregel, Labels und Standort. Die **Mitglieder** werden jedoch **nicht** übernommen. Die neue Gruppe erhält den Namen des Originals mit dem Zusatz „ (Kopie)“. Benennen Sie sie in den Gruppeneinstellungen um.

## Eine Gruppe archivieren

Wenn eine Gruppe nicht mehr aktiv ist, Sie ihren Verlauf aber behalten möchten statt sie zu löschen:

1. Öffnen Sie die Gruppe und klicken Sie auf **Bearbeiten**, um ihre Einstellungen zu ändern.
2. Klicken Sie auf **Archivieren** und bestätigen Sie.

Archivierte Gruppen verschwinden aus der Hauptliste der Gruppen. Um eine archivierte Gruppe wiederzufinden, klicken Sie oben auf der Seite Gruppen neben den Kategorie-Schaltflächen auf **Archivierte anzeigen**. Klicken Sie anschließend neben der Gruppe auf **Wiederherstellen**, um sie zurückzuholen.

:::info
Das Archivieren einer Gruppe löscht weder ihre Mitglieder, ihren Anwesenheitsverlauf noch ihre Kalenderveranstaltungen. Die Gruppe wird lediglich aus der Standardliste ausgeblendet, bis Sie sie wiederherstellen.
:::

## Nächste Schritte

Nachdem Sie Ihre Gruppe angelegt und konfiguriert haben, können Sie:

- **Mitglieder hinzufügen** -- Suchen Sie nach Personen und fügen Sie sie der Gruppe hinzu. Verwenden Sie das Sternsymbol (**Als Leitung festlegen**), um Gruppenleitungen zu bestimmen. Siehe [Gruppenmitglieder](./group-members.md).
- **Einen Kalender einrichten** -- Legen Sie Veranstaltungen und wiederkehrende Treffen für die Gruppe an. Siehe [Gruppenkalender](./group-calendar.md).
- **Kommunizieren** -- Senden Sie Nachrichten direkt von der Gruppenseite an alle Gruppenmitglieder.
- **Daten exportieren** -- Klicken Sie oberhalb der Mitgliederliste der Gruppe auf **Exportieren**, um sie herunterzuladen.

:::info
Jede Gruppe gehört zu einer Kategorie, und auf der Hauptseite Gruppen können Sie die Liste nach Kategorie filtern. Sie können Kategorien jederzeit neu ordnen oder umbenennen, während Ihre Gemeinde wächst.
:::
