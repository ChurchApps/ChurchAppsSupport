# Gruppengesundheit

<div class="article-intro">

Das Dashboard der Gruppengesundheit gibt Ihnen einen Überblick über den Zustand all Ihrer Gruppen -- Mitgliedschaftstrends, Anwesenheitsdurchschnitte und Wachstum oder Abgang in den letzten 90 Tagen -- all in einer einzigen sortierbaren Tabelle.

</div>

<div class="prereqs">
<h4>Voraussetzungen</h4>

- Sie benötigen mindestens einige Gruppen mit Mitgliedern, um aussagekräftige Daten zu sehen. Siehe [Gruppen erstellen](creating-groups).
- Anwesenheitsdaten werden aus aufgezeichneten Sitzungen gezogen. Siehe den Abschnitt [Anwesenheit](../attendance/).

</div>

## Öffnen der Gruppengesundheit

Öffnen Sie in B1 Admin das **Bereichsmenü** in der oberen linken Ecke und wählen Sie **Personen**, dann klicken Sie auf die **Gruppen**-Registerkarte in der Navigationsleiste und wählen Sie **Gesundheit**. Das Dashboard lädt eine Tabelle mit einer Zeile pro Gruppe.

## Spalten

| Spalte | Was es anzeigt |
|--------|--------------|
| **Name** | Der Gruppenname, verlinkt zur Gruppenergebnis-Seite |
| **Kategorie** | Die Kategorie der Gruppe |
| **Mitglieder** | Aktuelle Mitgliederzahl |
| **Beigetreten (90d)** | Mitglieder, die in den letzten 90 Tagen beigetreten sind |
| **Verlassen (90d)** | Mitglieder, die in den letzten 90 Tagen gegangen sind |
| **Abgang (90d)** | Netto-Abgangssatz als Prozentsatz über 90 Tage |
| **Durchschn. Anwesenheit** | Durchschnittliche Kopfzahl pro Anwesenheitssitzung |

Klicken Sie auf eine beliebige Spaltenüberschrift, um die Tabelle nach dieser Spalte zu sortieren. Klicken Sie erneut, um die Sortierrichtung umzukehren.

## Verwendung von Gesundheitsdaten

- **Hoher Abgang + niedrige Zutritte** -- eine Gruppe, die schrumpft und verlorene Mitglieder nicht ersetzt. Wert ein Gespräch mit dem Gruppenleiter.
- **Hohe Zutritte + niedrige Anwesenheit** -- Menschen treten bei, aber zeigen nicht auf. Erwägen Sie ein Engagementfollow-up.
- **Hohe durchschnittliche Anwesenheit** -- eine gesunde, aktive Gruppe. Potenzielles Modell für andere Gruppen.

:::tip
Das Anklicken eines Gruppennamens führt Sie direkt zur Gruppenergebnis-Seite, auf der Sie einzelne Mitglieder, Anwesenheitsdatensätze und Kalenderveranstaltungen überprüfen können.
:::
