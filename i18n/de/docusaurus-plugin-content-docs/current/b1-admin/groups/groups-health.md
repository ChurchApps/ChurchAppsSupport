# Gruppen-Gesundheit

<div class="article-intro">

Das Gruppen-Gesundheits-Dashboard gibt Ihnen einen Überblick über die Leistung all Ihrer Gruppen — Mitgliedschaftstrends, Durchschnittsanwesenheit und Wachstum oder Rückgang in den letzten 90 Tagen — alles in einer einzigen sortier baren Tabelle.

</div>

<div class="prereqs">
<h4>Vor dem Start</h4>

- Sie benötigen mindestens einige Gruppen mit Mitgliedern, um aussagekräftige Daten zu sehen. Siehe [Creating Groups](creating-groups).
- Anwesenheitsdaten werden aus aufgezeichneten Sitzungen abgeleitet. Siehe den Bereich [Attendance](../attendance/).

</div>

## Öffnen der Gruppen-Gesundheit

Öffnen Sie in B1 Admin das **Bereichsmenü** in der oberen linken Ecke und wählen Sie **People**, klicken Sie dann auf die Registerkarte **Groups** in der Navigationsleiste und wählen Sie **Health**. Das Dashboard lädt eine Tabelle mit einer Zeile pro Gruppe.

## Spalten

| Spalte | Was es anzeigt |
|--------|--------------|
| **Name** | Der Gruppenname, verknüpft mit der Gruppendetailseite |
| **Category** | Die Kategorie der Gruppe |
| **Members** | Aktuelle aktive Mitgliederzahl |
| **Joined (90d)** | Mitglieder, die in den letzten 90 Tagen beigetreten sind |
| **Left (90d)** | Mitglieder, die in den letzten 90 Tagen gegangen sind |
| **Churn (90d)** | Netto-Churn-Rate als Prozentsatz in 90 Tagen |
| **Avg Attendance** | Durchschnittliche Kopfzahl pro Anwesenheitssitzung |

Klicken Sie auf eine beliebige Spaltenüberschrift, um die Tabelle nach dieser Spalte zu sortieren. Klicken Sie erneut, um die Sortierreihenfolge umzukehren.

## Verwendung von Gesundheitsdaten

- **Hoher Churn + niedrige Beitritte** — eine Gruppe, die schrumpft und verlorene Mitglieder nicht ersetzt. Es lohnt sich, ein Gespräch mit dem Gruppenleiter zu führen.
- **Hohe Beitritte + niedrige Anwesenheit** — Menschen melden sich an, aber erscheinen nicht. Erwägen Sie die Verfolgung der Beteiligung.
- **Hohe durchschnittliche Anwesenheit** — eine gesunde, aktive Gruppe. Potenzielles Modell für andere Gruppen.

:::tip
Wenn Sie auf einen Gruppennamen klicken, werden Sie direkt zur Detailseite der Gruppe gelangen, wo Sie einzelne Mitglieder, Anwesenheitsdatensätze und Kalenderereignisse überprüfen können.
:::
