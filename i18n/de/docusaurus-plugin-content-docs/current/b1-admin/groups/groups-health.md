# Gruppengespräche

<div class="article-intro">

Das Dashboard Gruppengespräche bietet dir einen Gesamteindruck davon, wie es allen deinen Gruppen geht -- Mitgliedschaftstrends, Anwesenheitsdurchschnitte und Wachstum oder Abgang in den letzten 90 Tagen -- alles in einer einzigen sortierbaren Tabelle.

</div>

<div class="prereqs">
<h4>Bevor du beginnst</h4>

- Du brauchst mindestens ein paar Gruppen mit Mitgliedern, um aussagekräftige Daten zu sehen. Siehe [Gruppen erstellen](creating-groups).
- Anwesenheitsdaten werden aus aufgezeichneten Sitzungen gezogen. Siehe den Bereich [Anwesenheit](../attendance/).

</div>

## Öffnung von Gruppengesprächen

In B1 Admin öffne das **Menü „Bereich"** in der oberen linken Ecke und wähle **Personen**, klicke dann auf **Gruppen** in der Navigationsleiste und klicke auf die Schaltfläche **Gruppengesundheit** im Seitenkopf. Das Dashboard lädt eine Tabelle mit einer Zeile pro Gruppe.

## Spalten

| Spalte | Was wird angezeigt |
|--------|--------------|
| **Name** | Der Gruppenname, verknüpft mit der Seite Gruppendetails |
| **Kategorie** | Die Kategorie der Gruppe |
| **Mitglieder** | Aktuelle Mitgliederzahl |
| **Beigetreten (90T)** | Mitglieder, die in den letzten 90 Tagen beigetreten sind |
| **Verlassen (90T)** | Mitglieder, die in den letzten 90 Tagen gegangen sind |
| **Abgang (90T)** | Netto-Abgangsrate als Prozentsatz über 90 Tage |
| **Durchschn. Anwesenheit** | Durchschnittliche Kopfzahl pro Anwesenheitssitzung |

Klicke auf eine beliebige Spaltenüberschrift, um die Tabelle nach dieser Spalte zu sortieren. Klicke erneut, um die Sortierrichtung umzukehren.

## Verwendung von Gesundheitsdaten

- **Hoher Abgang + niedrige Beitritte** -- eine Gruppe, die schrumpft und verlorene Mitglieder nicht ersetzt. Es wert, ein Gespräch mit dem Gruppenleiter zu führen.
- **Hohe Beitritte + niedrige Anwesenheit** -- Menschen melden sich an, aber erscheinen nicht. Erwäge Engagement-Nachverfolgung.
- **Hohe durchschnittliche Anwesenheit** -- eine gesunde, aktive Gruppe. Potenzielles Modell für andere Gruppen.

:::tip
Durch Klick auf einen Gruppennamen wirst du direkt zur Seite Gruppendetails dieser Gruppe geleitet, wo du einzelne Mitglieder, Anwesenheitsdatensätze und Kalenderereignisse überprüfen kannst.
:::
