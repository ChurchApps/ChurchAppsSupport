# Einreichungen verwalten

<div class="article-intro">

Sobald Ihr Formular live ist, werden Einreichungen eingehen. Die Registerkarte Einreichungen ermöglicht es Ihnen, jede Antwort zu überprüfen, zu verfolgen, wer eingereicht hat, und die Daten verwenden, um zeitnah mit Ihrer Gemeinde Kontakt aufzunehmen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- [Erstellen Sie ein Formular](./creating-forms.md) mit mindestens einer Frage
- Teilen Sie das Formular über seine öffentliche URL oder betten Sie es auf Ihrer Website ein

</div>

## Anzeigen von Einreichungen

1. Navigieren Sie zu **Formulare** im Hauptmenü.
2. Klicken Sie auf das Formular, das Sie überprüfen möchten.
3. Gehen Sie zur Registerkarte **Einreichungen**.

## Überprüfen einzelner Einreichungen

Klicken Sie auf eine beliebige Einreichung, um die vollständigen Details anzuzeigen.
