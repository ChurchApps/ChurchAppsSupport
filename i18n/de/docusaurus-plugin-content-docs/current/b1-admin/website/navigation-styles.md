# Navigationsstile

<div class="article-intro">

Passen Sie die Navigation Ihrer Kirchen-Website an.

</div>

## Navigationsstile konfigurieren

1. Klicken Sie in B1 Admin im linken Menü auf **Website**.
2. Klicken Sie auf die Registerkarte **Navigationsstile**.
3. Wählen Sie Ihren bevorzugten Navigationsstil aus.
