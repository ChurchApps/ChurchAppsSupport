# Navigationsstile

<div class="article-intro">

Passen Sie die Farben der Navigationsleiste Ihrer Kirchenwebsite an Ihr Branding an. Sie können Farben sowohl für solide als auch für transparente Overlays konfigurieren.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen Berechtigung zum Verwalten Ihrer Kirchenwebsite. Siehe [Rollen & Berechtigungen](../people/roles-permissions.md).
- Halten Sie Ihre Markenfarben bereit (Hexfarbcodes, z. B. #03A9F4).

</div>

## Verstehen von Navigationsmodi

Ihre Website-Navigation kann je nach Seite in zwei verschiedenen Stilen angezeigt werden:

- **Feste Navigation** -- Navigationsleiste mit Hintergrundfarbe
- **Transparente Navigation** -- Navigation, die den Seiteninhalt überlagert

## Zugriff auf Navigationsstile

1. Navigieren Sie zu **Website** in B1 Admin
2. Klicken Sie auf die Registerkarte **Erscheinungsbild**
3. Scrollen Sie zum Abschnitt **Navigationsstile**
4. Klicken Sie auf **Navigationsstile bearbeiten**

## Speichern Ihrer Änderungen

1. Nachdem Sie Ihre Farben konfiguriert haben, klicken Sie auf **Navigationsstile speichern**
2. Ihre Änderungen werden sofort auf Ihre Live-Website angewendet
