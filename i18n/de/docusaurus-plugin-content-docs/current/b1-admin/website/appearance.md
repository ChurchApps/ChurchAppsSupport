# Erscheinungsbild

<div class="article-intro">

Auf der Seite Erscheinungsbild passen Sie das gesamte Aussehen der Website Ihrer Gemeinde an. Von Farben und Schriften bis zu Abständen und eigenem CSS steuern Sie jeden visuellen Aspekt Ihrer Website an einer einzigen Stelle.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Schließen Sie die [Ersteinrichtung](./initial-setup.md) für Ihre Website ab
- Halten Sie das Logo Ihrer Gemeinde im PNG-Format mit transparentem Hintergrund und einem Seitenverhältnis von 4:1 bereit
- Kennen Sie die Markenfarben Ihrer Gemeinde (Hexadezimalwerte), falls Sie einen bestehenden Styleguide haben

</div>

## Auf die Einstellungen des Erscheinungsbilds zugreifen {#accessing-appearance-settings}

1. Öffnen Sie in B1 Admin das [Sprungmenü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links) und klappen Sie **Website** auf.
2. Klicken Sie auf **Erscheinungsbild**.
3. Die Seite **Website-Stile** wird geladen. Die Karte **Design, Schriften und Fußzeile** zeigt links die Liste **Stileinstellungen** und rechts eine Vorschau einer Beispielseite. Darunter stehen die Karten **Ankündigung und Widgets** sowie **Weiterleitungen und Analyse**.

## Farbpalette {#color-palette}

1. Klicken Sie im Bereich Stileinstellungen auf **Farbpalette**.
2. Sie sehen **Grundfarben** (helle, Akzent- und dunkle Töne) und **Semantische Farben** (Primär, Sekundär, Erfolg, Warnung und Fehler).
3. Klicken Sie auf ein beliebiges Farbfeld, um den Farbwähler zu öffnen. Ziehen Sie den Auswahlpunkt oder geben Sie einen Hexadezimalwert ein, um Ihre Farbe zu wählen.
4. Die **Vorschau der Farbkombinationen** zeigt, wie Ihre gewählten Farben zusammenwirken.
5. Nutzen Sie **Vorgeschlagene Paletten**, um von einem vorgefertigten Farbschema aus zu starten. Ein Klick auf eine Palette lädt nur deren Farben in den Editor.
6. Klicken Sie auf **Palette speichern**, um Ihre Farben auf die Website anzuwenden, oder auf **Abbrechen**, um sie zu verwerfen.

## Typografie {#typography}

1. Klicken Sie im Bereich Stileinstellungen auf **Schriften**.
2. Klicken Sie auf die Schaltfläche **Überschriftenschrift** oder **Fließtextschrift**, um den Browser **Schrift auswählen** zu öffnen. Er listet Google Fonts nach Beliebtheit auf, zehn pro Seite. Geben Sie unter **Suche** einen Schriftnamen ein oder verwenden Sie den **Kategoriefilter** (Serifen, Serifenlos, Display, Handschrift oder Nicht-proportional). Klicken Sie auf eine Schrift, um sie zu wählen. Sie können auch eine der **Beliebten Schriftkombinationen** anklicken, um beide Schriften gleichzeitig festzulegen.
3. Klicken Sie auf **Schriften speichern**, um Ihre Schriftwahl anzuwenden.
4. Um die Größenabstufung für Überschrift 1 bis Überschrift 4 anzupassen, klicken Sie im Bereich Stileinstellungen auf **Typografische Skala**. Feintunen Sie mit den Feldern **Skalierungsfaktor**, **Grundgröße** und **Zeilenhöhe** und klicken Sie dann auf **Typografie speichern**.

## Abstände {#spacing}

1. Klicken Sie im Bereich Stileinstellungen auf **Abstandsskala**.
2. Passen Sie die Abstandswerte von Extra klein bis Extra groß an. Praxisbeispiele zeigen, wie sich jeder Wert auf das Layout auswirkt.
3. Klicken Sie auf **Abstände speichern**, um die Werte auf Ihre gesamte Website anzuwenden.

## Logo und Markenauftritt {#logo-and-branding}

1. Klicken Sie im Bereich Stileinstellungen auf **Logo**.
2. Laden Sie Ihr **Logo für helle Hintergründe** und Ihr **Logo für dunkle Hintergründe** hoch. Verwenden Sie für beste Ergebnisse Bilder mit transparentem Hintergrund und einem Seitenverhältnis von 4:1.
3. Laden Sie ein **Bild für soziale Medien** für Linkvorschauen und ein **Favicon** für das Symbol im Browser-Tab hoch.
4. Geben Sie optional einen **Kurznamen für PWA** ein (bis zu 12 Zeichen) – den Namen, der unter dem App-Symbol Ihrer Gemeinde angezeigt wird, wenn jemand es auf dem Startbildschirm seines Telefons ablegt.
5. Klicken Sie auf **Änderungen speichern**. Hochgeladene Bilder werden erst mit dem Speichern übernommen. Wenn Sie den Browser-Tab vorher schließen oder neu laden, warnt Ihr Browser vor nicht gespeicherten Änderungen.

Logos werden von allen Websites Ihrer Gemeinde sowie von Ihrer App und gedruckten Materialien wie Anwesenheitslisten genutzt.

:::tip
Für beste Ergebnisse verwenden Sie ein Logo mit transparentem Hintergrund im PNG-Format. So sieht es sowohl auf hellen als auch auf dunklen Hintergründen auf Ihrer Website und in der [mobilen App](../settings/mobile-app.md) gut aus.
:::

## Navigationsstile {#navigation-styles}

Passen Sie die Farben Ihrer Navigationsleiste für den festen und den transparenten Modus an:

1. Klicken Sie im Bereich Stileinstellungen auf **Navigation**.
2. Konfigurieren Sie die Farben für **Kopfzeile (fest)** und **Kopfzeile über dem Hauptbereich (transparent)**.
3. Klicken Sie auf **Navigation speichern**, um Ihre Navigationsfarben anzuwenden.

Ausführliche Anleitungen finden Sie unter [Navigationsstile](./navigation-styles.md).

## Fußzeile der Website {#site-footer}

Klicken Sie im Bereich Stileinstellungen auf **Fußzeile der Website**, um Ihre Fußzeile im Blockeditor zu öffnen. Gestalten Sie sie wie einen beliebigen Seitenabschnitt – zum Beispiel mit Ihrer Adresse, den Gottesdienstzeiten und Social-Media-Links – und klicken Sie auf **Beenden**, wenn Sie fertig sind. Die Fußzeile erscheint unten auf jeder Seite, die das Layout **Kopfzeile und Fußzeile** verwendet. Jede Ihrer Websites hat eine eigene Fußzeile.

## Ankündigung und Widgets {#announcement--widgets}

Website-Widgets erscheinen auf jeder Seite Ihrer Website und schweben über dem Seiteninhalt:

- **Ankündigungsleiste** -- Eine schließbare Leiste oben auf Ihrer Website für zeitkritische Hinweise, etwa eine bevorstehende Veranstaltung oder eine Änderung des Gottesdienstes.
- **Schnellzugriff** -- Eine schwebende Schaltfläche, die ein Schnellzugriffsmenü öffnet, zum Beispiel mit Links zum Spenden, zum Check-in oder zum Gemeindebrief.

1. Suchen Sie die Karte **Ankündigung und Widgets** unterhalb der Stileinstellungen.
2. Aktivieren Sie für die **Ankündigungsleiste** das Kästchen **Aktiviert** und füllen Sie den **Text**, optional eine **Link-URL** und einen **Linktext** sowie die **Hintergrundfarbe** und **Textfarbe** aus. Legen Sie ein **Startdatum** und ein **Enddatum** fest, damit die Leiste nur in diesem Zeitraum angezeigt wird.
3. Aktivieren Sie für den **Schnellzugriff** das Kästchen **Aktiviert**, klicken Sie dann für jeden Link auf **Aktion hinzufügen** (bis zu fünf) und geben Sie eine **Bezeichnung**, eine **URL** und ein **Symbol** an. Wählen Sie die **Position** (unten rechts oder unten links) und die **Farbe**.
4. Klicken Sie auf **Speichern**.

Entfernen Sie den Haken bei **Aktiviert** und klicken Sie auf **Speichern**, um ein Widget auszuschalten. Diese Widgets gelten für jede Website Ihrer Gemeinde.

## Weiterleitungen und Analyse {#redirects--analytics}

Die Karte **Weiterleitungen und Analyse** (unterhalb der Stileinstellungen) enthält zwei unterschiedliche, aber häufig benötigte Einstellungen:

- **Analyse** -- Tragen Sie Ihre **GA4-Mess-ID** (Format `G-XXXXXXXXXX`) ein und klicken Sie auf **Speichern**, um die Besucherzugriffe auf Ihrer Website zu erfassen. Dieselbe ID erfasst auch Seitenaufrufe in der B1-App Ihrer Gemeinde (dem Mitgliederportal unter `/mobile`, einschließlich der installierten App). Diese Aufrufe sind mit einem `display_mode` von `installed` oder `browser` markiert, damit Sie in Google Analytics Besuche der installierten App von Browserbesuchen unterscheiden können.
- **Weiterleitungen** -- Ordnen Sie einen alten URL-Pfad einem neuen zu, damit Links zu einer verschobenen oder umbenannten Seite weiter funktionieren, statt einen Fehler 404 anzuzeigen. Geben Sie den alten **Von-Pfad** und den neuen **Zu-Pfad** ein und klicken Sie dann auf **Hinzufügen**. Die Weiterleitung wird sofort gespeichert und oberhalb der Felder aufgelistet; klicken Sie auf ihr Löschsymbol, um sie zu entfernen. Pfade werden in Kleinbuchstaben gespeichert, mit einem führenden Schrägstrich und ohne abschließenden Schrägstrich. Eine Weiterleitung hat außerdem Vorrang vor den eingebauten Seiten von B1 (`/sermons`, `/stream`, `/donate`, `/bible` und `/votd`), sodass Sie diese Adresse an ein anderes Ziel senden können (zum Beispiel zu Ihrer eigenen Predigtseite oder einem YouTube-Kanal). Sie überschreibt jedoch keine Seite, die Sie selbst unter derselben Adresse erstellt haben. Löschen Sie diese Seite zuerst, wenn die Weiterleitung greifen soll.

## Eigenes CSS und JavaScript {#custom-css-and-javascript}

1. Klicken Sie im Bereich Stileinstellungen auf **CSS und JavaScript**.
2. Fügen Sie **Eigenes CSS** hinzu, um Standardstile für fortgeschrittene Anpassungen zu überschreiben.
3. Fügen Sie **Eigenes HTML** für Tracking-Codes oder andere Skripte hinzu.
4. Nutzen Sie die Abschnitte **Gängige CSS-Beispiele** und **Gängige JavaScript-Beispiele** für fertige Codeschnipsel und klicken Sie dann auf **Änderungen speichern**.

:::warning
Eigenes CSS ist mächtig, kann aber das Layout Ihrer Website zerstören, wenn es falsch eingesetzt wird. Die meisten Gemeinden erreichen das gewünschte Aussehen mit den eingebauten Steuerelementen für Farben, Schriften und Abstände. Verwenden Sie eigenes CSS nur, wenn Sie mit Webentwicklung vertraut sind.
:::

:::info
Ihre Website setzt eine Content Security Policy durch, die Inline-Skripte aus anderen Quellen blockiert. Das Feld **Eigenes HTML** hier und das [HTML-Element](./page-editor.md#using-the-html-element) auf einzelnen Seiten sind die vertrauenswürdigen Ausnahmen – Code, den Sie dort speichern, wird unverändert ausgeführt. Fügen Sie daher nur Skripte aus Quellen ein, denen Sie vertrauen (Analyse-Tags, Chat-Widgets und ähnliche Einbettungen).
:::

## Designvorlagen {#style-themes}

Wenn Sie einen schnellen Ausgangspunkt möchten, bieten die **Vorgeschlagenen Paletten** im Bereich Farbpalette vorgefertigte Designs mit abgestimmten Farben. Klicken Sie auf eine, um sie zu laden, passen Sie beliebige Farben an und klicken Sie dann auf **Palette speichern**.
