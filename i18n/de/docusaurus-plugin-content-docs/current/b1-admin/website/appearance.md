# Erscheinungsbild {#appearance}

<div class="article-intro">

Auf der Seite Erscheinungsbild passen Sie das gesamte Erscheinungsbild Ihrer Gemeindewebsite an. Von Farben und Schriften bis zu Abständen und benutzerdefiniertem CSS steuern Sie jeden visuellen Aspekt Ihrer Website an einer einzigen Stelle.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Schließen Sie die [Ersteinrichtung](./initial-setup.md) für Ihre Website ab
- Halten Sie Ihr Gemeindelogo im PNG-Format mit transparentem Hintergrund und einem Seitenverhältnis von 4:1 bereit
- Kennen Sie die Markenfarben Ihrer Gemeinde (Hexadezimalwerte), falls Sie einen bestehenden Styleguide haben

</div>

## Zugriff auf die Erscheinungseinstellungen {#accessing-appearance-settings}

1. Öffnen Sie in B1 Admin das [Sprungmenü](../introduction.md#getting-around-with-the-jump-menu) (das Suchfeld oben links) und klappen Sie **Website** auf.
2. Klicken Sie auf **Appearance**.
3. Die Seite **Site Styles** wird geladen. Die Karte **Theme, fonts & footer** zeigt links die Liste **Style Settings** und rechts eine Vorschau einer Beispielwebsite. Darunter befinden sich die Karten **Announcement & widgets** und **Redirects & analytics**.

## Farbpalette {#color-palette}

1. Klicken Sie im Bereich Style Settings auf **Color Palette**.
2. Sie sehen **Base Colors** (helle, Akzent- und dunkle Töne) und **Semantic Colors** (Primary, Secondary, Success, Warning und Error).
3. Klicken Sie auf ein Farbfeld, um den Farbwähler zu öffnen. Ziehen Sie den Auswahlpunkt oder geben Sie einen Hexadezimalwert ein, um Ihre Farbe zu wählen.
4. Die **Color Combinations Preview** zeigt, wie Ihre gewählten Farben zusammenwirken.
5. Verwenden Sie **Suggested Palettes**, um von einem vorgefertigten Farbschema auszugehen. Ein Klick auf eine Palette lädt nur ihre Farben in den Editor.
6. Klicken Sie auf **Save Palette**, um Ihre Farben auf die Website anzuwenden, oder auf **Cancel**, um sie zu verwerfen.

## Typografie {#typography}

1. Klicken Sie im Bereich Style Settings auf **Fonts**.
2. Klicken Sie auf die Schaltfläche **Heading Font** oder **Body Font**, um den Schriftauswahldialog **Select a Font** zu öffnen. Er listet Google Fonts nach Beliebtheit auf, zehn pro Seite. Geben Sie im Feld **Search** den Namen einer Schrift ein oder nutzen Sie den **Category Filter** (Serif, Sans Serif, Display, Handwriting oder Monospace). Klicken Sie auf eine Schrift, um sie auszuwählen. Sie können auch eine der **Popular Font Combinations** anklicken, um beide Schriften gleichzeitig festzulegen.
3. Klicken Sie auf **Save Fonts**, um Ihre Schriftwahl zu übernehmen.
4. Um die Größenabstufung für die Überschriften 1 bis 4 anzupassen, klicken Sie im Bereich Style Settings auf **Typography Scale**. Nutzen Sie die Felder **Type Scale** (Multiplikator), **Base Size** und **Line Height** für die Feinabstimmung und klicken Sie anschließend auf **Save Typography**.

## Abstände {#spacing}

1. Klicken Sie im Bereich Style Settings auf **Spacing Scale**.
2. Passen Sie die Abstandswerte von Extra Small bis Extra Large an. Praxisbeispiele zeigen, wie sich jeder Wert auf das Layout auswirkt.
3. Klicken Sie auf **Save Spacing**, um die Werte auf Ihre gesamte Website anzuwenden.

## Logo und Branding {#logo-and-branding}

1. Klicken Sie im Bereich Style Settings auf **Logo**.
2. Laden Sie Ihr **Light Background Logo** und Ihr **Dark Background Logo** hoch. Für die besten Ergebnisse verwenden Sie Bilder mit transparentem Hintergrund und einem Seitenverhältnis von 4:1.
3. Laden Sie ein **Social Media Image** für Linkvorschauen und ein **Favicon** für das Symbol im Browser-Tab hoch.
4. Optional können Sie einen **PWA Short Name** (bis zu 12 Zeichen) eingeben -- das ist der Name, der unter dem App-Symbol Ihrer Gemeinde angezeigt wird, wenn jemand sie auf dem Startbildschirm seines Telefons speichert.
5. Klicken Sie auf **Save Changes**. Hochgeladene Bilder werden erst mit dem Speichern übernommen. Wenn Sie den Browser-Tab vorher schließen oder neu laden, warnt Ihr Browser Sie vor ungespeicherten Änderungen.

Logos werden von allen Websites Ihrer Gemeinde, von Ihrer App und von gedruckten Materialien wie Anwesenheitslisten gemeinsam genutzt.

:::tip
Verwenden Sie für die besten Ergebnisse ein Logo im PNG-Format mit transparentem Hintergrund. So sieht es sowohl auf hellen als auch auf dunklen Hintergründen auf Ihrer Website und in der [mobilen App](../settings/mobile-app.md) gut aus.
:::

## Navigationsstile {#navigation-styles}

Passen Sie die Farben der Navigationsleiste Ihrer Website sowohl für den festen als auch für den transparenten Modus an:

1. Klicken Sie im Bereich Style Settings auf **Navigation**
2. Konfigurieren Sie die Farben für **Header (solid)** und **Header over hero (transparent)**
3. Klicken Sie auf **Save Navigation**, um Ihre Navigationsfarben zu übernehmen

Ausführliche Anleitungen finden Sie unter [Navigationsstile](./navigation-styles.md).

## Fußzeile der Website {#site-footer}

Klicken Sie im Bereich Style Settings auf **Site Footer**, um Ihre Fußzeile im Blockeditor zu öffnen. Gestalten Sie sie wie jeden anderen Seitenabschnitt -- zum Beispiel mit Adresse, Gottesdienstzeiten und Social-Media-Links -- und klicken Sie auf **Exit**, wenn Sie fertig sind. Die Fußzeile erscheint unten auf jeder Seite, die das Layout **Header & Footer** verwendet. Jede Ihrer Websites hat ihre eigene Fußzeile.

## Ankündigungen und Widgets {#announcement--widgets}

Website-Widgets erscheinen auf jeder Seite Ihrer Website und schweben über dem Seiteninhalt:

- **Announcement Banner** -- Eine ausblendbare Leiste am oberen Rand Ihrer Website für zeitkritische Nachrichten, etwa eine bevorstehende Veranstaltung oder eine Änderung der Gottesdienstzeiten.
- **Launcher** -- Eine schwebende Schaltfläche, die ein Schnellzugriffsmenü öffnet, zum Beispiel mit Links zum Spenden, zum Check-in oder zum Gemeindebrief.

1. Suchen Sie die Karte **Announcement & widgets** unterhalb der Style Settings.
2. Setzen Sie für die **Announcement Bar** das Häkchen bei **Enabled** und füllen Sie **Text**, optional **Link URL** und **Link Text** sowie **Background Color** und **Text Color** aus. Legen Sie ein **Start Date** und ein **End Date** fest, damit die Leiste nur in diesem Zeitraum angezeigt wird.
3. Setzen Sie für den **Launcher** das Häkchen bei **Enabled**, klicken Sie für jeden Link auf **Add Action** (bis zu fünf) und geben Sie jeweils ein **Label**, eine **URL** und ein **Icon** an. Wählen Sie die **Position** (unten rechts oder unten links) und die **Color**.
4. Klicken Sie auf **Save**.

Entfernen Sie das Häkchen bei **Enabled** und klicken Sie auf **Save**, um ein Widget auszuschalten. Diese Widgets gelten für alle Websites Ihrer Gemeinde.

Die Ankündigungsleiste wird auch oben auf der Startseite der B1-App Ihrer Gemeinde angezeigt (das Mitgliederportal unter `/mobile`, einschließlich der installierten App), oberhalb der Begrüßung, mit demselben Text, Link, denselben Farben und Zeiträumen. In der App öffnet eine **Link URL**, die auf eine Ihrer eigenen Seiten verweist (zum Beispiel `/food`), diese Seite innerhalb der App, statt Ihre Website zu laden. Siehe [In B1App navigieren](../../b1-church/getting-started/navigating.md#home).

Einige Details zum Verhalten der Leiste:

- Auf Telefonen umbricht langer Text auf mehrere Zeilen, und der Link rutscht in eine eigene Zeile, wenn er nicht mehr passt.
- Auf Ihrer Website sitzt die Menüleiste direkt unter der Ankündigungsleiste, sodass die Menüschaltfläche sichtbar bleibt. Menüs und Pop-up-Fenster öffnen sich über der Leiste.
- Wenn jemand die Leiste mit der Schaltfläche **×** schließt, bleibt sie auf diesem Gerät einen Tag lang ausgeblendet und erscheint danach wieder. Wenn Sie den **Text** ändern, wird die neue Ankündigung sofort angezeigt, auch für Personen, die die alte geschlossen haben.

## Weiterleitungen und Analyse {#redirects--analytics}

Die Karte **Redirects & analytics** (unterhalb der Style Settings) enthält zwei voneinander unabhängige, aber häufig benötigte Einstellungen:

- **Analytics** -- Tragen Sie Ihre **GA4 Measurement ID** (Format `G-XXXXXXXXXX`) ein und klicken Sie auf **Save**, um die Besucherzahlen Ihrer Website zu erfassen. Dieselbe ID erfasst auch Seitenaufrufe in der B1-App Ihrer Gemeinde (das Mitgliederportal unter `/mobile`, einschließlich der installierten App). Sie werden mit einem `display_mode` von `installed` oder `browser` markiert, damit Sie in Google Analytics Besuche der installierten App von Browserbesuchen unterscheiden können.
- **Redirects** -- Ordnen Sie einen alten URL-Pfad einem neuen zu, damit Links zu einer verschobenen oder umbenannten Seite weiterhin funktionieren und nicht mit einem Fehler 404 enden. Geben Sie den alten **From Path** und den neuen **To Path** ein und klicken Sie auf **Add**. Die Weiterleitung wird sofort gespeichert und oberhalb der Felder aufgelistet; klicken Sie auf das Löschsymbol, um sie zu entfernen. Pfade werden in Kleinbuchstaben gespeichert, mit einem führenden Schrägstrich und ohne abschließenden Schrägstrich. Eine Weiterleitung hat außerdem Vorrang vor den eingebauten Seiten von B1 (`/sermons`, `/stream`, `/donate`, `/bible` und `/votd`), sodass Sie diese Adresse an ein anderes Ziel senden können (zum Beispiel auf Ihre eigene Predigtseite oder einen YouTube-Kanal). Sie überschreibt keine selbst erstellte Seite unter derselben Adresse. Löschen Sie diese Seite zuerst, wenn die Weiterleitung greifen soll.

## Benutzerdefiniertes CSS und JavaScript {#custom-css-and-javascript}

1. Klicken Sie im Bereich Style Settings auf **CSS & Javascript**.
2. Fügen Sie unter **Custom CSS** Stile hinzu, um die Standardstile für fortgeschrittene Anpassungen zu überschreiben.
3. Fügen Sie unter **Custom HTML** Tracking-Codes oder andere Skripte ein.
4. Nutzen Sie die Abschnitte **Common CSS Examples** und **Common JavaScript Examples** für fertige Beispiele und klicken Sie dann auf **Save Changes**.

:::warning
Benutzerdefiniertes CSS ist mächtig, kann aber das Layout Ihrer Website zerstören, wenn es falsch eingesetzt wird. Die meisten Gemeinden erreichen das gewünschte Aussehen mit den eingebauten Einstellungen für Farben, Schriften und Abstände. Verwenden Sie benutzerdefiniertes CSS nur, wenn Sie sich mit Webentwicklung auskennen.
:::

:::info
Ihre Website erzwingt eine Content Security Policy, die Inline-Skripte aus anderen Quellen blockiert. Das Feld **Custom HTML** hier und das [HTML-Element](./page-editor.md#using-the-html-element) auf einzelnen Seiten sind die vertrauenswürdigen Ausnahmen -- Code, den Sie dort speichern, wird unverändert ausgeführt. Fügen Sie daher nur Skripte aus vertrauenswürdigen Quellen ein (Analyse-Tags, Chat-Widgets und ähnliche Einbettungen).
:::

## Stil-Designs {#style-themes}

Wenn Sie einen schnellen Ausgangspunkt suchen, bieten die **Suggested Palettes** im Abschnitt Color Palette vorgefertigte Designs mit aufeinander abgestimmten Farben. Klicken Sie auf eine, um sie zu laden, passen Sie beliebige Farben an und klicken Sie dann auf **Save Palette**.
