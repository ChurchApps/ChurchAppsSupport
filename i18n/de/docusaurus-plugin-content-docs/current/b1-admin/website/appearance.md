# Erscheinungsbild

<div class="article-intro">

Passen Sie das Aussehen und Verhalten Ihrer Kirchen-Website an. Sie können Farben, Schriften, Abstände und mehr steuern.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Schließen Sie das Initial Setup für Ihre Website ab
- Halten Sie Ihr Kirchenlogo bereit

</div>

## Zugriff auf Erscheinungseinstellungen

1. Klicken Sie in B1 Admin im linken Menü auf **Website**.
2. Klicken Sie auf die Registerkarte **Erscheinungsbild**.
3. Konfigurieren Sie Ihre Einstellungen.

## Farbpalette

Passen Sie die Basisfarben und semantischen Farben Ihrer Website an.

## Typografie

Wählen Sie Schriftarten und Größen für Ihre Website.

## Logo und Branding

Laden Sie Ihr Logo und Branding-Bilder hoch.
