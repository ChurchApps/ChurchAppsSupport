# Erscheinungsbild

<div class="article-intro">

Auf der Seite "Erscheinungsbild" können Sie das Gesamterscheinungsbild Ihrer Kirchenwebsite anpassen. Von Farben und Schriftarten bis zum Abstand und benutzerdefiniertem CSS können Sie jeden visuellen Aspekt Ihrer Website von einem Ort aus steuern.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Führen Sie das [Initial Setup](initial-setup) für Ihre Website durch
- Halten Sie Ihr Kirchenlogo bereit (PNG-Format mit transparentem Hintergrund, 4:1 Seitenverhältnis)
- Kennen Sie die Markenfarben Ihrer Kirche (Hexwerte), wenn Sie einen Stilleifaden haben

</div>

## Zugriff auf Erscheinungseinstellungen

1. Klicken Sie in B1 Admin auf **Website** im linken Menü.
2. Klicken Sie auf die Registerkarte **Erscheinungsbild** oben in der Ansicht "Website-Seiten".
3. Die Seite "Website-Stile" wird mit einer Live-Vorschau geladen.

## Farbpalette

1. Klicken Sie auf **Farbpalette** im Bereich "Stileinstellungen".
2. Wählen Sie Ihre Farben basierend auf Basisfarben und semantischen Farben.
3. Klicken Sie auf **Speichern**, wenn Sie zufrieden sind.

## Typographie

1. Klicken Sie auf **Typographie-Einstellungen** im Bereich "Stileinstellungen".
2. Wählen Sie Schriftarten für Überschriften und Bodytext.
3. Passen Sie die Schriftgrößenhierarchie an.
4. Klicken Sie auf **Speichern**.
