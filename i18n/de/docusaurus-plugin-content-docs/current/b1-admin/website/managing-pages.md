# Seiten verwalten

<div class="article-intro">

Die Ansicht "Website-Seiten" ist Ihr zentrales Lager zum Erstellen, Bearbeiten und Organisieren aller Seiten auf Ihrer Kirchenwebsite. Sie können Ihren Seiteninhalt und die Navigation Ihrer Website aus diesem einzelnen Bildschirm verwalten.

</div>

<div class="prereqs">
<h4>Voraussetzungen</h4>

- Schließen Sie die [Anfangseinrichtung](initial-setup) ab, um Ihre Domäne und grundlegenden Website-Einstellungen zu konfigurieren
- Haben Sie Ihren Inhalt und Bilder bereit. Verwenden Sie den [Dateien](files)-Manager, um Medien-Assets zuerst hochzuladen.

</div>

:::info
Wenn Ihre Kirche mehr als eine Website hat (zum Beispiel separate Websites pro Campus), verwenden Sie die Website-Auswahl oben in der Ansicht "Website-Seiten", um zwischen ihnen zu springen. Jede Website hat ihre eigenen Seiten, Navigation und [Erscheinungsbild](appearance)-Einstellungen.
:::

## Verstehen von Seitentypen

Die Tabelle **Seiten** listet alle Seiten auf Ihrer Website zusammen mit ihrem Status auf:

- **Generiert** -- Seiten, die automatisch vom System auf Grundlage Ihrer Kirchendaten erstellt wurden (zum Beispiel eine Gruppen-Seite, eine Predigten-Seite oder eine individuelle Seite für jede Predigt in Ihrer Bibliothek). Diese Seiten aktualisieren sich selbst, wenn sich Ihre Daten ändern.
- **Benutzerdefiniert** -- Seiten, die Sie selbst mit Ihrem eigenen Inhalt und Layout erstellt haben.

Sie können jede automatisch generierte Seite in eine benutzerdefinierte Seite konvertieren, wenn Sie volle Kontrolle über ihren Inhalt und ihr Design wollen.

## Hinzufügen und Bearbeiten von Seiten

1. Klicken Sie auf die Schaltfläche **Seite hinzufügen** in der oberen rechten Ecke der Tabelle "Seiten".
2. Wählen Sie einen Seitentyp (leer oder eine Vorlage) und geben Sie ihm einen Namen.
3. Klicken Sie auf **Bearbeiten** neben einer beliebigen Seite, um den [Seiten-Editor](page-editor) zu öffnen, wo Sie Abschnitte, Text, Bilder und andere Elemente hinzufügen können.
4. Klicken Sie auf **Seiteneinstellungen**, um den Seitentitel, URL-Pfad und andere Metadaten zu aktualisieren.
5. Verwenden Sie die Schaltfläche **Vorschau**, um Ihre Seite in einem neuen Fenster zu öffnen und genau zu sehen, wie sie für Besucher aussieht.

:::tip
Stellen Sie für Ihre Startseite den URL-Pfad auf `/` ein. Für alle anderen Seiten verwenden Sie einen beschreibenden Pfad wie `/about` oder `/contact`.
:::

### Seiteneinstellungen

Öffnen Sie **Seiteneinstellungen** auf einer beliebigen Seite, um Folgendes zu konfigurieren:

- **Titel und URL-Pfad** -- Der Seitenname und seine Adresse auf Ihrer Website.
- **Sichtbarkeit** -- Wählen Sie, wer die Seite sehen kann: alle, nur Mitglieder, nur Personal oder Mitglieder bestimmter Gruppen. Dies ist eine schnelle Möglichkeit, eine private Seite (wie eine Personal-Ressourcen-Seite) ohne separates Passwort zu sperren.
- **Meta-Beschreibung** -- Eine kurze Zusammenfassung, die in Suchmaschinenergebnissen und Social-Media-Link-Vorschau angezeigt wird.
- **Umleitung** -- Zeigen Sie einen alten URL-Pfad auf diese Seite, sodass Links und Lesezeichen zu einer stillgelegten Seite funktionieren.

## Verwalten von Navigation

Die Ansicht "Website-Seiten" zeigt Ihre Navigationslinks an. Diese Links kontrollieren das Menü, das Besucher auf Ihrer Website sehen.

1. Klicken Sie auf **Hinzufügen**, um einen neuen Navigationslink zu erstellen. Sie können ihn auf eine beliebige Seite auf Ihrer Website oder auf eine externe URL verweisen.
2. Um Links neu zu ordnen, ziehen Sie sie per Drag-and-Drop in die Reihenfolge, die Sie mögen. Sie können auch Links unter einem übergeordneten Element verschachteln, um Dropdown-Menüs zu erstellen.
3. Klicken Sie auf das **Bearbeitungs**-Symbol neben einem beliebigen Link, um sein Label, seine URL oder Position zu ändern.
4. Um einen Link aus der Navigation zu entfernen, klicken Sie auf das **Löschen**-Symbol.

:::info
Das Entfernen eines Navigationslinks löscht nicht die Seite selbst. Die Seite existiert noch und kann direkt über ihre URL zugegriffen werden -- sie wird einfach nicht im Menü angezeigt.
:::

## Tipps zum Organisieren Ihrer Website

- Halten Sie Ihre Top-Level-Navigation auf fünf oder sechs Elemente, sodass Besucher Dinge schnell finden können.
- Verwenden Sie verschachtelte Links für verwandte Unterseiten (zum Beispiel ein "Über"-Dropdown mit "Unser Team", "Überzeugungen" und "Geschichte").
- Überprüfen Sie Ihre Navigation auf Mobil, indem Sie **Mobil-Vorschau** klicken, um sicherzustellen, dass es auf kleineren Bildschirmen gut funktioniert.
- Geben Sie Seiten klare, beschreibende Namen, die Besuchern helfen zu verstehen, was sie finden werden.

:::tip
Sie können [Formulare](../forms/creating-forms.md) auf Ihre Seiten hinzufügen, um Registrierungen, Gebetsanfragen oder andere Informationen von Besuchern zu sammeln.
:::

## Beginn mit einem Website-Template

Wenn Sie Ihre Website von Grund auf erstellen, können Sie eine **Website-Vorlage** verwenden, um es mit vordefinierter Seiten-Struktur, anstatt Seiten einzeln zu erstellen, zu starten. Eine Website-Vorlage erstellt eine Reihe von vorgefertigten Seiten -- Startseite, Über, Verbindung, Spende und andere -- mit Platzhalterirhalt und Navigationslinks bereits verdrahtet.

1. Klicken Sie auf der Seite "Seiten" auf die Schaltfläche **Website-Vorlagen** (neben der Schaltfläche **Seite hinzufügen**).
2. Durchsuchen Sie die verfügbaren Vorlagen und klicken Sie auf eine, um ihre Seitenstruktur anzuzeigen.
3. Wenn Sie eine finden, die Ihnen gefällt, klicken Sie auf **Vorlage anwenden**.
4. Seiten, die noch nicht vorhanden sind, werden erstellt und zu Ihrer Navigation hinzugefügt. Bestehende Seiten werden nicht geändert.

Nach dem Anwenden einer Vorlage öffnen Sie jede Seite im [Seiten-Editor](page-editor), um den Platzhalterirhalt und Bilder durch den echten Irhalt Ihrer Kirche zu ersetzen.

:::info
Website-Vorlagen erstellen Seitenstruktur und Navigation. Sie überschreiben nicht Ihr Website-Farbschema oder Ihre Schriftarten -- diese werden durch [Erscheinungsbild](appearance) kontrolliert.
:::

## Bild-Lightbox

Wenn Besucher auf ein Bild auf Ihrer Website klicken, öffnet es sich in einer Vollbild-Lightbox-Überlagerung. Dies ermöglicht es Menschen, Fotos in einer größeren Größe anzuzeigen, ohne die Seite zu verlassen. Keine Konfiguration ist erforderlich -- die Lightbox ist automatisch für Bilder in Ihrem Seiteninhalt aktiviert.
