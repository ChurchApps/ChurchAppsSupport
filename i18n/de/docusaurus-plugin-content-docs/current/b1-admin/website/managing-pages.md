# Seiten verwalten

<div class="article-intro">

Die Ansicht „Website-Seiten" ist Ihr zentraler Hub zum Erstellen, Bearbeiten und Organisieren aller Seiten Ihrer Kirchenwebsite. Sie können sowohl Ihren Seiteninhalt als auch die Navigation Ihrer Website von diesem einzelnen Bildschirm aus verwalten.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Führen Sie die [Ersteinrichtung](initial-setup) aus, um Ihre Domain und grundlegende Site-Einstellungen zu konfigurieren
- Halten Sie Ihren Inhalt und Ihre Bilder bereit. Verwenden Sie den [Dateien](files)-Manager, um zuerst Medien-Assets hochzuladen.

</div>

:::info
Wenn Ihre Kirche mehr als eine Website hat (z. B. separate Sites pro Filiale), verwenden Sie den Site-Umschalter oben in der Ansicht „Website-Seiten", um zwischen ihnen zu wechseln. Jede Site hat ihre eigenen Seiten, Navigation und [Erscheinungsbild](appearance)-Einstellungen.
:::

## Seitentypen verstehen

Die Tabelle **Seiten** listet alle Seiten Ihrer Website zusammen mit ihrem Status auf:

- **Generiert** -- Seiten, die vom System basierend auf Ihren Kirchendaten automatisch erstellt wurden (z. B. eine Gruppenseite, eine Predigtenseite oder eine einzelne Seite für jede Predigt in Ihrer Bibliothek). Diese Seiten aktualisieren sich selbst, wenn sich Ihre Daten ändern.
- **Benutzerdefiniert** -- Seiten, die Sie selbst mit Ihrem eigenen Inhalt und Layout erstellt haben.

Sie können jede automatisch generierte Seite in eine benutzerdefinierte Seite umwandeln, wenn Sie die volle Kontrolle über ihren Inhalt und Design wünschen.

## Seiten hinzufügen und bearbeiten

1. Klicken Sie auf die Schaltfläche **Seite hinzufügen** in der oberen rechten Ecke der Tabelle „Seiten".
2. Wählen Sie einen Seitentyp (leer oder eine Vorlage) und geben Sie ihm einen Namen.
3. Klicken Sie auf **Bearbeiten** neben einer Seite, um den [Seiten-Editor](page-editor) zu öffnen, in dem Sie Abschnitte, Text, Bilder und andere Elemente hinzufügen können.
4. Klicken Sie auf **Seiteneinstellungen**, um den Seitentitel, die URL-Pfad und andere Metadaten zu aktualisieren.
5. Verwenden Sie die Schaltfläche **Vorschau**, um Ihre Seite in einem neuen Fenster zu öffnen und genau zu sehen, wie sie für Besucher aussieht.

:::tip
Setzen Sie für Ihre Startseite den URL-Pfad auf /. Für alle anderen Seiten verwenden Sie einen aussagekräftigen Pfad wie /about oder /contact.
:::

### Seiteneinstellungen

Öffnen Sie **Seiteneinstellungen** auf einer beliebigen Seite, um Folgendes zu konfigurieren:

- **Titel und URL-Pfad** -- Der Seitenname und seine Adresse auf Ihrer Website.
- **Sichtbarkeit** -- Wählen Sie, wer die Seite sehen kann: alle, nur Mitglieder, nur Personal oder Mitglieder bestimmter Gruppen. Dies ist eine schnelle Möglichkeit, eine private Seite zu sperren (z. B. eine Personalressourcenseite), ohne ein separates Passwort.
- **Meta-Beschreibung** -- Eine kurze Zusammenfassung, die in Suchmaschinenergebnissen und Social-Media-Link-Vorschauen angezeigt wird.
- **Umleitungen** -- Zeigen Sie einen alten URL-Pfad auf diese Seite, damit Links und Lesezeichen zu einer eingestellten Seite weiter funktionieren.

## Navigation verwalten

Die linke Seitenleiste der Ansicht „Website-Seiten" zeigt Ihre Navigationslinks. Diese Links steuern das Menü, das Besucher auf Ihrer Website sehen.

1. Klicken Sie auf **Hinzufügen**, um einen neuen Navigationslink zu erstellen. Sie können ihn auf eine beliebige Seite Ihrer Website oder auf eine externe URL verweisen.
2. Um Links neu zu ordnen, ziehen Sie sie per Drag & Drop in die gewünschte Reihenfolge. Sie können Links auch unter einem übergeordneten Element verschachteln, um Dropdown-Menüs zu erstellen.
3. Klicken Sie auf das Symbol **Bearbeiten** neben einem Link, um seine Beschriftung, URL oder Position zu ändern.
4. Um einen Link aus der Navigation zu entfernen, klicken Sie auf das Symbol **Löschen**.

:::info
Das Löschen eines Navigationslinks löscht die Seite selbst nicht. Die Seite existiert immer noch und kann direkt über ihre URL zugegriffen werden -- sie erscheint nur nicht im Menü.
:::

## Tipps zum Organisieren Ihrer Website

- Halten Sie Ihre Navigation auf der obersten Ebene bei fünf oder sechs Elementen, damit Besucher schnell Dinge finden können.
- Verwenden Sie verschachtelte Links für verwandte Unterseiten (z. B. ein Dropdown-Menü „Über" mit „Unser Team", „Überzeugungen" und „Geschichte").
- Überprüfen Sie Ihre Navigation auf Mobilgeräten, indem Sie auf **Handy-Vorschau** klicken, um sicherzustellen, dass sie auf kleineren Bildschirmen funktioniert.
- Geben Sie Seiten klare, aussagekräftige Namen, die Besuchern helfen zu verstehen, was sie finden werden.

:::tip
Sie können [Formulare](../forms/creating-forms.md) zu Ihren Seiten hinzufügen, um Registrierungen, Gebetsanfragen oder andere Informationen von Besuchern zu sammeln.
:::

## Vorlagen von Anfang an starten

Wenn Sie Ihre Website von Grund auf aufbauen, können Sie sie mit einer **Site-Vorlage** bootstrap, anstatt Seiten nacheinander zu erstellen. Eine Site-Vorlage erstellt eine Reihe von vordefinierten Seiten -- Startseite, Über, Verbinden, Spenden und andere -- mit Platzhalterinhalten und bereits verbundenen Navigationslinks.

1. Klicken Sie auf dem Bildschirm „Seiten" auf die Schaltfläche **Site-Vorlagen** (neben der Schaltfläche **Seite hinzufügen**).
2. Durchsuchen Sie die verfügbaren Vorlagen und klicken Sie auf eine, um ihre Seitenstruktur in der Vorschau zu sehen.
3. Wenn Sie eine gefunden haben, die Sie mögen, klicken Sie auf **Vorlage anwenden**.
4. Seiten, die noch nicht vorhanden sind, werden erstellt und zu Ihrer Navigation hinzugefügt. Vorhandene Seiten bleiben unverändert.

Öffnen Sie nach Anwenden einer Vorlage jede Seite im [Seiten-Editor](page-editor), um den Platzhaltertext und die Bilder durch den echten Inhalt Ihrer Kirche zu ersetzen.

:::info
Site-Vorlagen erstellen die Seitenstruktur und Navigation. Sie überschreiben nicht das Farbschema oder die Schriftarten Ihrer Website -- diese werden von [Erscheinungsbild](appearance) gesteuert.
:::

## Bild-Lightbox

Wenn Besucher auf ein Bild auf Ihrer Website klicken, öffnet es sich in einem Vollbild-Lightbox-Overlay. Dies ermöglicht es Personen, Fotos in größerer Größe zu sehen, ohne die Seite zu verlassen. Es ist keine Konfiguration erforderlich -- die Lightbox ist automatisch für Bilder in Ihrem Seiteninhalt aktiviert.
