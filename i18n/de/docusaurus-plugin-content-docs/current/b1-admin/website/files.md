# Dateien

<div class="article-intro">

Die Dateien-Seite ist das zentrale Repository für alle Medien und Dokumente, die auf Ihrer Kirchenwebsite verwendet werden. Von hier aus können Sie jede Datei, jedes Dokument und jede Mediendatei, die Ihre Website benötigt, hochladen, organisieren, durchsuchen und verwalten.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Führen Sie die [Initiale Einrichtung](initial-setup) für Ihre Website durch
- Optimieren Sie Bilder vor dem Hochladen für schnellere Seitenladungszeiten
- Bereiten Sie Ihre Dateien in gängigen Web-Formaten vor (PNG, JPG, PDF, usw.)

</div>

## Dateien hochladen

1. Öffnen Sie in B1 Admin das [Jump-Menü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links), erweitern Sie **Website** und klicken Sie auf **Files**.
2. Ziehen Sie Dateien direkt in den Upload-Bereich, oder klicken Sie auf die Upload-Schaltfläche, um auf Ihrem Computer zu durchsuchen.
3. Ihre Dateien werden hochgeladen und erscheinen sofort in der Dateibibliothek.

:::tip
Optimieren Sie Bilder vor dem Hochladen für beste Ergebnisse. Kleinere Dateigrößen helfen Ihrer Website, schneller für Besucher zu laden. Tools wie TinyPNG oder Squoosh können Bilder ohne nennenswerten Qualitätsverlust komprimieren.
:::

## Organisieren mit Ordnern

1. Erstellen Sie Ordner, um zusammenhängende Dateien zu gruppieren -- zum Beispiel "Sermon Graphics", "Event Banners" oder "Staff Photos".
2. Verschieben Sie Dateien zwischen Ordnern, um Ihre Bibliothek ordentlich zu halten, während sie wächst.
3. Verwenden Sie klare, aussagekräftige Ordnernamen, damit Ihr Team Dateien schnell finden kann.

## Durchsuchen und Suchen

- Scrollen Sie durch die Dateibibliothek, um Miniaturansichten aller hochgeladenen Dateien zu sehen.
- Verwenden Sie die **Suchfunktion**, um Dateien nach Name zu finden, wenn Ihre Bibliothek größer wird.
- Klicken Sie auf eine Datei, um ihre Details anzuzeigen, einschließlich Dateiname, Größe und URL.

## Dateien auf Ihrer Website verwenden

1. Klicken Sie auf eine Datei, um ihre Details anzuzeigen.
2. **Kopieren Sie die Datei-URL**, um sie auf Ihren Website-Seiten zu verwenden. Sie können diese URL in Bildelemente, Download-Links oder überall dort einfügen, wo eine Datei-URL akzeptiert wird.
3. Dateien, die Sie hier hochladen, stehen für die Verwendung auf allen Ihren Website-Seiten und Inhaltsblöcken zur Verfügung.

:::info
Beim Erstellen von Seiten in [Managing Pages](managing-pages) können Sie jede hier hochgeladene Datei über ihre URL referenzieren. Dies hält alle Ihre Medien an einem zentralen Ort organisiert.
:::

## Dateien löschen

1. Wählen Sie die Datei aus, die Sie entfernen möchten.
2. Klicken Sie auf die **Delete**-Schaltfläche, um sie dauerhaft aus Ihrer Bibliothek zu entfernen.
3. Stellen Sie sicher, dass die Datei nicht auf einer Seite verwendet wird, bevor Sie sie löschen, da dies Links oder Bilder, die darauf verweisen, unterbrechen wird.

:::warning
Gelöschte Dateien können nicht wiederhergestellt werden. Überprüfen Sie doppelt, dass eine Datei nicht mehr auf einer Seite verwendet wird, bevor Sie sie entfernen.
:::
