# Blog

<div class="article-intro">

Die Blog-Seite ermöglicht es Ihnen, Nachrichten, Updates und Andachten auf Ihrer Kirchen-Website zu veröffentlichen. Beiträge werden in einer Kartenliste unter /blog, unter ihrer eigenen URL und in einem RSS-Feed angezeigt.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Schließen Sie das Initial Setup für Ihre Website ab
- Fügen Sie einen Navigationslink zu /blog hinzu

</div>

## Zugriff auf den Blog

1. Klicken Sie in B1 Admin im linken Menü auf **Website**.
2. Klicken Sie oben auf die Registerkarte **Blog**.
3. Die Blog-Seite listet jeden Beitrag mit seinem Status auf.

## Hinzufügen eines Beitrags

1. Klicken Sie auf **Beitrag hinzufügen**.
2. Geben Sie einen **Titel** ein.
3. Fügen Sie einen **Auszug** hinzu.
4. Schreiben Sie den Beitragstext mit Markdown.
5. Wählen Sie eine **Kategorie** und **Tags**.
6. Wählen Sie ein Bild aus.
7. Legen Sie den **Autor** fest.
8. Aktivieren Sie **Veröffentlicht** und legen Sie das Datum fest.

## Beitragsstatus

- **Entwurf** – Nicht veröffentlicht
- **Geplant** – Wird auf ein zukünftiges Datum vorbereitet
- **Veröffentlicht** – Live auf Ihrer Website
