# Wiederverwendbare Blöcke

<div class="article-intro">

Blöcke sind Teile von Website-Inhalten, die Sie einmal erstellen und auf beliebig vielen Seiten wiederverwenden – ein Banner mit einem Aufruf zum Handeln, eine Kontaktleiste oder ein Feld mit den Gottesdienstzeiten. Wenn Sie einen Block bearbeiten, zeigt jede Seite, die ihn verwendet, die Änderung.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen die Berechtigung, Website-Inhalte zu bearbeiten
- Verwenden Sie einen Computer oder ein Tablet; der Blockeditor ist derselbe Vollbild-Editor, der auch für Seiten verwendet wird

</div>

## Blöcke öffnen {#opening-blocks}

1. Öffnen Sie in B1 Admin das [Sprungmenü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links) und klappen Sie **Website** auf.
2. Klicken Sie auf **Blöcke**. Die Seite **Wiederverwendbare Blöcke** listet jeden Block mit seinem **Namen** und **Typ** auf.

Hat Ihre Gemeinde mehr als eine Website, nutzen Sie den Website-Umschalter oben auf der Seite, um die Blöcke jeder Website zu sehen. Auch Ihre Fußzeile ist ein Block, sie wird jedoch unter **Fußzeile der Website** im Bereich [Erscheinungsbild](./appearance.md) bearbeitet und nicht hier aufgelistet.

## Einen Block hinzufügen {#adding-a-block}

1. Klicken Sie auf **Block hinzufügen**.
2. Geben Sie einen **Namen** ein, den Ihr Team wiedererkennt.
3. Wählen Sie den **Blocktyp**:
   - **Element(e)** -- ein oder mehrere Elemente (Text, Bilder, Schaltflächen usw.), die Sie in einen Abschnitt auf einer Seite ziehen.
   - **Abschnitt/Abschnitte** -- ein oder mehrere ganze Abschnitte, die Sie auf einer Seite zwischen die übrigen Abschnitte setzen.
4. Klicken Sie auf **Speichern**. Der Block erscheint in der Liste.

## Den Inhalt eines Blocks erstellen {#building-a-blocks-content}

1. Klicken Sie auf den Namen des Blocks oder auf **Bearbeiten** in seiner Zeile. Der Block öffnet sich im [Seiteneditor](./page-editor.md).
2. Fügen Sie Inhalte hinzu und gestalten Sie sie genauso wie auf einer Seite, beginnend mit einem Abschnitt.
3. Änderungen werden automatisch gespeichert. Klicken Sie in der Werkzeugleiste auf **Beenden**, um zur Liste der Blöcke zurückzukehren.

## Einen Block auf einer Seite verwenden {#using-a-block-on-a-page}

1. Öffnen Sie eine Seite im [Seiteneditor](./page-editor.md) und klicken Sie auf **Inhalt hinzufügen**.
2. Wählen Sie im Bereich **Elemente hinzufügen** den Reiter **Blöcke**. (Der Reiter erscheint erst, wenn Sie mindestens einen Block haben.)
3. Ziehen Sie den Block auf die Seite: einen Elementblock in einen Abschnitt, einen Abschnittsblock zwischen zwei Abschnitte.

Die Seite zeigt den aktuellen Inhalt des Blocks. Um ihn zu ändern, bearbeiten Sie den Block selbst auf der Seite **Blöcke**; jede Seite, die ihn verwendet, wird aktualisiert.

## Einen Block umbenennen oder löschen {#renaming-or-deleting-a-block}

1. Klicken Sie in der Zeile des Blocks auf **Umbenennen**.
2. Ändern Sie den **Namen** oder den **Blocktyp** und klicken Sie auf **Speichern**, oder klicken Sie auf **Löschen** und bestätigen Sie, um den Block dauerhaft zu entfernen.

:::warning
Seiten, die einen gelöschten Block verwenden, zeigen dessen Inhalt nicht mehr an. Prüfen Sie Ihre Seiten, bevor Sie einen Block löschen, der noch verwendet wird.
:::
