# Kampagnen & Zusagen

<div class="article-intro">

Kampagnen ermöglichen es Ihnen, eine Spendensammlung auf ein bestimmtes Ziel auszurichten -- ein Gebäudefonds, eine Missionsreise, ein Spezialprojekt -- und Zusagen von Mitgliedern neben tatsächlichen Spenden zu verfolgung, sodass Sie Ihren Echtzeitfortschritt sehen können.

</div>

<div class="prereqs">
<h4>Voraussetzungen</h4>

- Richten Sie Ihre [Spendenfonds](funds) ein -- jede Kampagne ist an einen Fonds gebunden
- Sie benötigen Zugriff auf den Spenden-Bereich von B1 Admin

</div>

## Öffnen von Kampagnen

Öffnen Sie in B1 Admin das **Bereichsmenü** in der oberen linken Ecke (der Bereichsname mit dem kleinen Pfeil) und wählen Sie **Spenden**, dann wählen Sie **Kampagnen**. Sie werden eine Liste aller Kampagnen mit ihren Zielbeträgen, Gesamtzusagen und bisherigen Gesamtspenden sehen.

## Erstellen einer Kampagne

1. Klicken Sie auf **Kampagne hinzufügen**.
2. Füllen Sie die Kampagnendetails aus:
   - **Name** *(erforderlich)* -- der Anzeigename für diese Kampagne (z.B. "Gebäudefonds 2026").
   - **Fonds** -- der Spendenfonds, mit dem diese Kampagne verbunden ist.
   - **Startdatum** / **Enddatum** -- das Spendensammlungsfenster.
   - **Ziel** -- der Zieldollarbetrag für die Kampagne.
3. Klicken Sie auf **Speichern**.

## Verfolgung des Fortschritts

Jede Kampagnenkarte zeigt:

- **Ziel** -- Ihr Zielbeträg
- **Zugesagt** -- der Gesamtbetrag, den Mitglieder zu geben zugesagt haben
- **Gegeben** -- der Gesamtbetrag, der tatsächlich für den Fonds dieser Kampagne während des Kampagnenfensters gespendet wurde
- Ein **Fortschrittsbalken**, der zeigt, wie nah Sie an Ihrem Ziel sind

Klicken Sie auf jede Kampagne, um die Detailansicht zu öffnen, die einzelne Zusagen und deren Erfüllungsstatus auflistet.

## Zusagen hinzufügen

Zusagen sind Verpflichtungen von Mitgliedern, für eine Kampagne zu geben. Um eine Zusage aufzuzeichnen:

1. Öffnen Sie eine Kampagne.
2. Klicken Sie auf **Zusage hinzufügen**.
3. Wählen Sie die **Person** aus, die die Zusage macht.
4. Geben Sie den Zusage-**Betrag** ein.
5. Stellen Sie optional ein **Datum** für die Zusage-Zusage ein.
6. Klicken Sie auf **Speichern**.

Zusagen werden in der Kampagnendetail angezeigt und tragen zum **Zugesagt**-Gesamtbetrag auf der Kampagnenkarte bei.

:::tip
Zusagen sind separate von tatsächlichen Spenden. Eine Zusage verfolgt eine Zusage; eine Spende zeichnet das tatsächliche Geschenk auf. Beide werden in der Kampagne angezeigt, damit Sie sehen können, wie gut Zusagen erfüllt werden.
:::

## Bearbeiten oder Löschen einer Kampagne

Klicken Sie auf das Bearbeitungssymbol auf einer Kampagnenkarte, um ihren Namen, ihr Ziel, ihre Daten oder ihren Fonds zu aktualisieren. Klicken Sie auf **Löschen**, um die Kampagne und ihre Zusagen dauerhaft zu entfernen. Das Löschen einer Kampagne löscht keine Spenden, die für ihren Fonds aufgezeichnet wurden.
