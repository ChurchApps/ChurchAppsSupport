# Kuratierter Kalender

<div class="article-intro">

Ein kuratierter Kalender fasst Ereignisse aus mehreren Gruppen in einer einheitlichen Kalenderansicht zusammen. Das eignet sich ideal für einen gemeindeweiten Kalender, der alles zeigt, was in all Ihren Diensten und Gruppen an einem Ort geschieht.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Richten Sie die [Gruppen](../groups/creating-groups.md) ein, deren Ereignisse Sie aufnehmen möchten
- Stellen Sie sicher, dass Gruppenleitende Ereignisse zu ihren jeweiligen Gruppen hinzugefügt haben
- Machen Sie sich mit den Grundlagen von [Kalender erstellen](./creating-calendars.md) vertraut

</div>

## Einen kuratierten Kalender erstellen {#creating-a-curated-calendar}

1. Öffnen Sie in B1 Admin das [Sprungmenü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links), klappen Sie **Kalender** auf und klicken Sie auf **Kalender**.
2. Klicken Sie auf **Kalender hinzufügen**, um einen neuen kuratierten Kalender anzulegen.
3. Geben Sie Ihrem Kalender einen **Kalendernamen** (zum Beispiel „Veranstaltungen der Kirche“ oder „Diese Woche in unserer Gemeinde“).
4. Klicken Sie auf **Erstellen**, um ihn zu speichern.

## Gruppen zu Ihrem Kalender hinzufügen {#adding-groups-to-your-calendar}

1. Klicken Sie auf den Namen Ihres neuen Kalenders (oder auf **Ereignisse verwalten** in seiner Zeile), um ihn zu öffnen.
2. Klicken Sie über dem Kalender auf **Gruppe hinzufügen**. Hinzugefügte Gruppen erscheinen in der Liste **Gruppen im Kalender** auf der linken Seite.
3. Wählen Sie eine Gruppe unter **Gruppe auswählen**. Jede Gruppe Ihrer Kirche ist aufgelistet, auch Gruppen, denen Sie nicht angehören.
4. Wählen Sie **Alle Ereignisse der Gruppe hinzufügen** oder **Bestimmte Ereignisse hinzufügen** und klicken Sie auf die gewünschten Ereignisse.
5. Klicken Sie auf **Speichern**.
6. Wiederholen Sie diesen Vorgang, bis Sie alle gewünschten Gruppen hinzugefügt haben.

Jedes Ereignis wird nur einmal aufgeführt, auch wenn Sie es einzeln und zusätzlich die ganze Gruppe hinzugefügt haben. Die Liste **Gruppen im Kalender** zeigt nur Gruppen, die mit allen ihren Ereignissen hinzugefügt wurden.

Um etwas aus dem Kalender zu entfernen, klicken Sie auf das Ereignis und wählen Sie **Aus Kalender entfernen**. Das Ereignis bleibt in seiner Gruppe. Stammte das Ereignis aus einer ganzen Gruppe, entfernt diese Aktion alle Ereignisse dieser Gruppe aus diesem Kalender.

:::tip
Fügen Sie alle aktiven Dienstgruppen hinzu, um einen umfassenden Kalender zu erstellen, der Ihrer Gemeinde jede Woche ein vollständiges Bild davon gibt, was in Ihrer Kirche geschieht.
:::

## Ihren Kalender teilen {#sharing-your-calendar}

Sobald Ihr kuratierter Kalender eingerichtet ist, können Sie ihn auf verschiedene Weise teilen:

- **Auf Ihrer Website einbetten** – Fügen Sie einer Seite ein Element **Kalender** hinzu, um den Kalender als Monatsraster oder als Kacheln kommender Ereignisse anzuzeigen, optional beschränkt auf Ereignisse mit einem bestimmten Schlagwort. Jedes Ereignis verlinkt auf seine eigene Seite auf Ihrer Website. Siehe [Das Element Kalender verwenden](../website/page-editor.md#using-the-calendar-element).
- **Per ICS abonnieren** – Klicken Sie über dem Kalender auf **Abonnieren** und wählen Sie **ICS-Link kopieren**. Ihre Gemeinde kann diesen Link in Google Kalender, Apple Kalender, Outlook oder eine andere Kalender-App einfügen, um synchron zu bleiben.
- **ICS-Datei herunterladen** – Klicken Sie auf **Abonnieren** und wählen Sie **ICS-Datei herunterladen**, um den Kalender in eine Kalenderanwendung zu importieren.
- **Drucken** – Klicken Sie auf der Seite des Kalenders auf **Drucken** für eine druckbare Ansicht.

:::info
Wenn Gruppenleitende neue Ereignisse zu ihren [Gruppen](../groups/creating-groups.md) hinzufügen, erscheinen diese Ereignisse automatisch in Ihrem kuratierten Kalender. Sie müssen den kuratierten Kalender nicht jedes Mal manuell aktualisieren, wenn ein neues Ereignis hinzukommt.
:::

:::note Private Ereignisse
Nur **öffentliche** Ereignisse erscheinen im kuratierten Kalender auf Ihrer Website und in seinem ICS-Abonnement. In B1 Admin sehen Mitarbeitende, die Inhalte bearbeiten dürfen, außerdem die **privaten** Ereignisse der Gruppen im kuratierten Kalender. So können sie den vollständigen Terminplan prüfen, während sie den Kalender zusammenstellen.
:::
