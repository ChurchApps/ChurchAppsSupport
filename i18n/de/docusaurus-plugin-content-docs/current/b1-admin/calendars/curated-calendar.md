# Kuratierter Kalender

<div class="article-intro">

Ein kuratierter Kalender fasst Veranstaltungen mehrerer Gruppen in einer gemeinsamen Kalenderansicht zusammen. Das ist ideal für einen kirchenweiten Kalender, der alles zeigt, was in all Ihren Diensten und Gruppen an einem Ort geschieht.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Richten Sie die [Gruppen](../groups/creating-groups.md) ein, deren Veranstaltungen Sie aufnehmen möchten.
- Stellen Sie sicher, dass die Gruppenleitenden Veranstaltungen zu ihren jeweiligen Gruppen hinzugefügt haben.
- Machen Sie sich mit den Grundlagen von [Kalender erstellen](creating-calendars) vertraut.

</div>

## Einen kuratierten Kalender anlegen

1. Öffnen Sie in B1 Admin das [Sprungmenü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links), klappen Sie **Kalender** auf und klicken Sie auf **Kalender**.
2. Klicken Sie auf **Kalender hinzufügen**, um einen neuen kuratierten Kalender anzulegen.
3. Geben Sie Ihrem Kalender einen **Namen** (zum Beispiel "Veranstaltungen der Kirche" oder "Diese Woche in unserer Kirche").
4. Klicken Sie auf **Erstellen**, um ihn zu speichern.

## Gruppen zu Ihrem Kalender hinzufügen

1. Klicken Sie bei Ihrem neuen Kalender auf **Veranstaltungen verwalten**, um ihn zu öffnen.
2. Klicken Sie oberhalb des Kalenders auf **Gruppe hinzufügen**. Hinzugefügte Gruppen erscheinen in der Liste **Gruppen im Kalender** auf der linken Seite der Seite.
3. Wählen Sie eine Gruppe im Dropdown-Menü aus. Jede Gruppe Ihrer Kirche wird aufgeführt, auch Gruppen, deren Mitglied Sie nicht sind.
4. Wählen Sie, ob Sie **alle Veranstaltungen** oder nur **bestimmte Veranstaltungen** dieser Gruppe hinzufügen möchten.
5. Klicken Sie auf **Speichern**.
6. Wiederholen Sie diesen Vorgang, bis Sie alle gewünschten Gruppen hinzugefügt haben.

Jede Veranstaltung wird nur einmal aufgeführt, auch wenn Sie sie einzeln und zusätzlich die ganze Gruppe hinzugefügt haben. Die Liste **Gruppen im Kalender** zeigt nur Gruppen an, die mit allen ihren Veranstaltungen hinzugefügt wurden.

Um etwas aus dem Kalender zu entfernen, klicken Sie auf die Veranstaltung und wählen Sie **Aus Kalender entfernen**. Die Veranstaltung bleibt in ihrer Gruppe. Stammt die Veranstaltung aus einer ganzen Gruppe, entfernt dies alle Veranstaltungen dieser Gruppe aus diesem Kalender.

:::tip
Fügen Sie alle Ihre aktiven Dienstgruppen hinzu, um einen umfassenden Kalender zu erstellen, der Ihrer Gemeinde jede Woche ein vollständiges Bild davon gibt, was in Ihrer Kirche geschieht.
:::

## Ihren Kalender teilen

Sobald Ihr kuratierter Kalender eingerichtet ist, können Sie ihn auf verschiedene Arten teilen:

- **Auf Ihrer Website einbetten** -- Fügen Sie einer Seite ein **Kalender**-Element hinzu, um den Kalender als Monatsraster oder als Kacheln kommender Veranstaltungen anzuzeigen, optional beschränkt auf Veranstaltungen mit einem Schlagwort. Jede Veranstaltung verlinkt auf ihre eigene Seite auf Ihrer Website. Siehe [Verwendung des Kalenderelements](../website/page-editor.md#using-the-calendar-element).
- **Über ICS abonnieren** -- Klicken Sie auf **Abonnieren**, um den ICS-Link zu kopieren. Ihre Gemeinde kann diesen Link in Google Kalender, Apple Kalender, Outlook oder eine andere Kalender-App einfügen, um synchron zu bleiben.
- **ICS-Datei herunterladen** -- Laden Sie die Kalenderdatei herunter, um sie in eine Kalenderanwendung zu importieren.

:::info
Wenn Gruppenleitende neue Veranstaltungen zu ihren [Gruppen](../groups/creating-groups.md) hinzufügen, erscheinen diese Veranstaltungen automatisch in Ihrem kuratierten Kalender. Sie müssen den kuratierten Kalender bei jeder neuen Veranstaltung nicht manuell aktualisieren.
:::

:::note Private Veranstaltungen
Auf dem kuratierten Kalender auf Ihrer Website und in seinem ICS-Abo erscheinen nur **öffentliche** Veranstaltungen. In B1 Admin sehen Mitarbeitende, die Inhalte bearbeiten dürfen, im kuratierten Kalender zusätzlich die **privaten** Veranstaltungen der Gruppen. So können Sie den vollständigen Terminplan prüfen, während Sie den Kalender zusammenstellen.
:::
