# Kuratierter Kalender

<div class="article-intro">

Ein kuratierter Kalender fasst Termine aus mehreren Gruppen in einer einheitlichen Kalenderansicht zusammen. Das eignet sich ideal für einen gemeindeweiten Kalender, der alles zeigt, was in allen Diensten und Gruppen stattfindet – und das an einem einzigen Ort.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Richten Sie die [Gruppen](../groups/creating-groups.md) ein, deren Termine Sie aufnehmen möchten
- Stellen Sie sicher, dass die Gruppenleiter Termine zu ihren jeweiligen Gruppen hinzugefügt haben
- Machen Sie sich mit den Grundlagen von [Kalender erstellen](creating-calendars) vertraut

</div>

## Einen kuratierten Kalender erstellen

1. Navigieren Sie im B1 Admin im Hauptmenü zu **Kalender**.
2. Klicken Sie auf **Kalender hinzufügen**, um einen neuen kuratierten Kalender zu erstellen.
3. Geben Sie Ihrem Kalender einen **Namen** (zum Beispiel „Gemeindetermine" oder „Diese Woche in unserer Gemeinde").
4. Klicken Sie auf **Erstellen**, um ihn zu speichern.

## Gruppen zu Ihrem Kalender hinzufügen

1. Klicken Sie auf Ihren neuen Kalender, um ihn zu öffnen.
2. Klicken Sie im Bereich **Gruppen im Kalender** auf der rechten Seite auf **Hinzufügen**.
3. Wählen Sie eine Gruppe aus dem Dropdown-Menü aus.
4. Wählen Sie aus, ob **alle Termine** dieser Gruppe oder nur **bestimmte Termine** hinzugefügt werden sollen.
5. Klicken Sie auf **Speichern**.
6. Wiederholen Sie diesen Vorgang, um so viele Gruppen hinzuzufügen, wie Sie aufnehmen möchten.

:::tip
Fügen Sie alle Ihre aktiven Dienstgruppen hinzu, um einen umfassenden Kalender zu erstellen, der Ihrer Gemeinde ein vollständiges Bild davon gibt, was jede Woche in Ihrer Gemeinde geschieht.
:::

## Ihren Kalender teilen

Sobald Ihr kuratierter Kalender eingerichtet ist, können Sie ihn auf verschiedene Arten teilen:

- **Auf Ihrer Website einbetten** -- Der Kalender kann direkt auf Ihren B1.church-Website-Seiten angezeigt werden, damit Besucher darin stöbern können.
- **Über ICS abonnieren** -- Klicken Sie auf **Abonnieren**, um den ICS-Link zu kopieren. Ihre Gemeinde kann diesen Link in Google Calendar, Apple Calendar, Outlook oder eine beliebige andere Kalender-App einfügen, um stets auf dem aktuellen Stand zu bleiben.
- **Die ICS-Datei herunterladen** -- Laden Sie die Kalenderdatei herunter, um sie in eine Kalenderanwendung zu importieren.

:::info
Wenn Gruppenleiter neue Termine zu ihren [Gruppen](../groups/creating-groups.md) hinzufügen, erscheinen diese Termine automatisch in Ihrem kuratierten Kalender. Sie müssen den kuratierten Kalender nicht jedes Mal manuell aktualisieren, wenn ein neuer Termin hinzugefügt wird.
:::
