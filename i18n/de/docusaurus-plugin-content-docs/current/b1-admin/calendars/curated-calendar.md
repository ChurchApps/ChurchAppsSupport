# Kuratierter Kalender

<div class="article-intro">

Ein kuratierter Kalender aggregiert Ereignisse von mehreren Gruppen in eine einheitliche Kalenderansicht. Dies ist ideal für die Erstellung eines kirchenweiten Kalenders, der alles zeigt, was in all Ihren Ministerien und Gruppen an einem Ort passiert.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Richten Sie die [Gruppen](../groups/creating-groups.md) ein, deren Ereignisse Sie einbeziehen möchten
- Stellen Sie sicher, dass Gruppenführer Ereignisse zu ihren jeweiligen Gruppen hinzugefügt haben
- Machen Sie sich mit den Grundlagen des [Erstellen von Kalendern](creating-calendars) vertraut

</div>

## Kuratierter Kalender erstellen

1. In B1 Admin öffnen Sie das [Jump-Menü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links), erweitern Sie **Kalender** und klicken Sie auf **Kalender**.
2. Klicken Sie auf **Kalender hinzufügen**, um einen neuen kuratierten Kalender zu erstellen.
3. Geben Sie Ihrem Kalender einen **Namen** (zum Beispiel „Kirchenereignisse" oder „Diese Woche in unserer Kirche").
4. Klicken Sie auf **Erstellen**, um ihn zu speichern.

## Gruppen zu Ihrem Kalender hinzufügen

1. Klicken Sie auf Ihren neuen Kalender, um ihn zu öffnen.
2. Klicken Sie im Bereich **Gruppen im Kalender** auf der rechten Seite auf **Hinzufügen**.
3. Wählen Sie eine Gruppe aus dem Dropdown-Menü.
4. Wählen Sie, ob Sie **alle Ereignisse** aus dieser Gruppe oder nur **bestimmte Ereignisse** hinzufügen möchten.
5. Klicken Sie auf **Speichern**.
6. Wiederholen Sie diesen Vorgang, um so viele Gruppen hinzuzufügen, wie Sie einbeziehen möchten.

:::tip
Fügen Sie alle Ihre aktiven Ministergruppen hinzu, um einen umfassenden Kalender zu erstellen, der Ihrer Gemeinde einen vollständigen Überblick darüber gibt, was jede Woche in Ihrer Kirche passiert.
:::

## Ihren Kalender teilen

Sobald Ihr kuratierter Kalender eingerichtet ist, können Sie ihn auf mehrere Arten teilen:

- **Auf Ihrer Website einbetten** -- Der Kalender kann direkt auf Ihren B1.church-Website-Seiten angezeigt werden, damit Besucher ihn durchsuchen können.
- **Über ICS abonnieren** -- Klicken Sie auf **Abonnieren**, um den ICS-Link zu kopieren. Ihre Gemeinde kann diesen Link in Google Calendar, Apple Calendar, Outlook oder jede andere Kalender-App einfügen, um synchronisiert zu bleiben.
- **ICS-Datei herunterladen** -- Laden Sie die Kalenderdatei herunter, um sie in eine Kalenderanwendung zu importieren.

:::info
Wenn Gruppenführer neue Ereignisse zu ihren [Gruppen](../groups/creating-groups.md) hinzufügen, werden diese Ereignisse automatisch in Ihrem kuratierten Kalender angezeigt. Sie müssen den kuratierten Kalender nicht jedes Mal manuell aktualisieren, wenn ein neues Ereignis hinzugefügt wird.
:::

:::note Private Ereignisse
Nur **öffentliche** Ereignisse erscheinen im kuratierten Kalender auf Ihrer Website und in dessen ICS-Abonnement. In B1 Admin sehen Mitarbeiter, die Inhalte bearbeiten dürfen, im kuratierten Kalender auch die **privaten** Ereignisse der Gruppe, damit Sie beim Zusammenstellen des Kalenders den vollständigen Terminplan prüfen können.
:::
