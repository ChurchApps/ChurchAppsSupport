# Kuratierter Kalender

<div class="article-intro">

Ein kuratierter Kalender fasst Veranstaltungen mehrerer Gruppen in einer gemeinsamen Kalenderansicht zusammen. Das eignet sich ideal für einen gemeindeweiten Kalender, der alles zeigt, was in all Ihren Diensten und Gruppen an einem Ort geschieht.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Richten Sie die [Gruppen](../groups/creating-groups.md) ein, deren Veranstaltungen Sie aufnehmen möchten
- Stellen Sie sicher, dass die Gruppenleitungen Veranstaltungen zu ihren jeweiligen Gruppen hinzugefügt haben
- Machen Sie sich mit den Grundlagen von [Kalender erstellen](creating-calendars) vertraut

</div>

## Einen kuratierten Kalender erstellen

1. Öffnen Sie in B1 Admin das [Jump-Menü](../introduction.md#getting-around-with-the-jump-menu) (das Suchfeld oben links), klappen Sie **Kalender** auf und klicken Sie auf **Kalender**.
2. Klicken Sie auf **Kalender hinzufügen**, um einen neuen kuratierten Kalender zu erstellen.
3. Geben Sie Ihrem Kalender einen **Namen** (zum Beispiel „Gemeindeveranstaltungen“ oder „Diese Woche in unserer Gemeinde“).
4. Klicken Sie auf **Erstellen**, um ihn zu speichern.

## Gruppen zu Ihrem Kalender hinzufügen

1. Klicken Sie auf **Veranstaltungen verwalten** bei Ihrem neuen Kalender, um ihn zu öffnen.
2. Klicken Sie oberhalb des Kalenders auf **Gruppe hinzufügen**. Die Gruppen, die Sie hinzufügen, erscheinen in der Liste **Gruppen im Kalender** auf der linken Seite der Seite.
3. Wählen Sie eine Gruppe aus dem Auswahlmenü.
4. Entscheiden Sie, ob Sie **alle Veranstaltungen** dieser Gruppe oder nur **bestimmte Veranstaltungen** hinzufügen möchten.
5. Klicken Sie auf **Speichern**.
6. Wiederholen Sie diesen Vorgang, bis alle gewünschten Gruppen hinzugefügt sind.

:::tip
Fügen Sie alle aktiven Gruppen Ihrer Dienste hinzu, um einen umfassenden Kalender zu erstellen, der Ihrer Gemeinde ein vollständiges Bild davon gibt, was jede Woche in Ihrer Gemeinde geschieht.
:::

## Ihren Kalender teilen

Sobald Ihr kuratierter Kalender eingerichtet ist, können Sie ihn auf verschiedene Arten teilen:

- **Auf Ihrer Website einbetten** — Fügen Sie einer Seite ein Element **Kalender** hinzu, um den Kalender als Monatsraster oder als Kacheln kommender Veranstaltungen anzuzeigen, optional beschränkt auf Veranstaltungen mit einem Schlagwort. Jede Veranstaltung verlinkt auf ihre eigene Seite auf Ihrer Website. Siehe [Das Kalender-Element verwenden](../website/page-editor.md#using-the-calendar-element).
- **Per ICS abonnieren** — Klicken Sie auf **Abonnieren**, um den ICS-Link zu kopieren. Ihre Gemeinde kann diesen Link in Google Kalender, Apple Kalender, Outlook oder jede andere Kalender-App einfügen, um immer synchron zu bleiben.
- **Die ICS-Datei herunterladen** — Laden Sie die Kalenderdatei herunter, um sie in eine Kalender-App zu importieren.

:::info
Wenn Gruppenleitungen neue Veranstaltungen zu ihren [Gruppen](../groups/creating-groups.md) hinzufügen, erscheinen diese Veranstaltungen automatisch in Ihrem kuratierten Kalender. Sie müssen den kuratierten Kalender nicht jedes Mal manuell aktualisieren, wenn eine neue Veranstaltung hinzukommt.
:::

:::note Private Veranstaltungen
Auf Ihrer Website und im ICS-Abo erscheinen im kuratierten Kalender nur **öffentliche** Veranstaltungen. In B1 Admin sehen Mitarbeitende, die Inhalte bearbeiten dürfen, außerdem die **privaten** Veranstaltungen der Gruppen im kuratierten Kalender, damit Sie den vollständigen Zeitplan prüfen können, während Sie den Kalender zusammenstellen.
:::
