# Räume, Ressourcen & Zeitplanung

<div class="article-intro">

Räume und Ressourcen ermöglichen es Ihnen, die buchbaren Räume und Ausrüstungen Ihrer Kirche zu verfolgen. Wenn eine Gruppe oder ein Team einen Raum nutzen oder eine Ressource für ein Ereignis leihen möchte, können sie dies über B1 anfordern -- und Sie können diese Anfragen genehmigen oder ablehnen, um Doppelbuchungen zu verhindern.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen Administratorzugriff auf den Kalenderbereich in B1 Admin
- Richten Sie [Gruppen](../groups/creating-groups) ein, deren Mitglieder Buchungsanfragen einreichen werden

</div>

## Räume & Ressourcen öffnen

In B1 Admin öffnen Sie das [Jump-Menü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links), erweitern Sie **Kalender** und klicken Sie auf **Räume & Ressourcen**. Die Seite hat vier Reiter: **Räume**, **Ressourcen**, **Blockouts** und **Vorlagen**.

## Räume

Räume sind physische Räume, die zusammen mit Kalenderereignissen reserviert werden können -- ein Heiligtum, ein Gemeinschaftsraum, ein Klassenzimmer, etc.

### Einen Raum hinzufügen

1. Klicken Sie auf der Registerkarte **Räume** auf **Raum hinzufügen**.
2. Geben Sie einen **Namen** für den Raum ein.
3. Legen Sie optional eine **Kapazität** (maximale Personenzahl) fest.
4. Legen Sie eine **Genehmigungsgruppe** fest -- wenn eine Gruppe diesen Raum anfordert, werden die Führungskräfte der gewählten Gruppe benachrichtigt und müssen die Buchung genehmigen. Lassen Sie leer, wenn keine Genehmigung erforderlich ist.
5. Klicken Sie auf **Speichern**.

### Einen Raum bearbeiten oder löschen

Klicken Sie auf das Bearbeitungssymbol neben einem beliebigen Raum, nehmen Sie Ihre Änderungen vor und klicken Sie auf **Speichern**. Verwenden Sie **Löschen**, um einen Raum dauerhaft zu entfernen.

## Ressourcen

Ressourcen sind Gegenstände, die zusammen mit einem Ereignis gebucht werden können -- AV-Ausrüstung, Projektoren, Stühle, ein Van, etc.

### Eine Ressource hinzufügen

1. Klicken Sie auf die Registerkarte **Ressourcen** und dann auf **Ressource hinzufügen**.
2. Geben Sie einen **Namen** und optional eine **Beschreibung** ein.
3. Legen Sie eine **Genehmigungsgruppe** fest, wenn jemand die Ressourcenausleihen genehmigen muss.
4. Klicken Sie auf **Speichern**.

## Blockouts

Blockouts verhindern, dass Räume oder Ressourcen während bestimmter Zeiten gebucht werden -- für Renovierungen, reservierte Zeiträume oder Wartung.

### Ein Blockout hinzufügen

1. Klicken Sie auf die Registerkarte **Blockouts** und dann auf **Blockout hinzufügen**.
2. Wählen Sie, ob ein **Raum**, eine **Ressource** oder alle Räume und Ressourcen blockiert werden sollen.
3. Legen Sie das **Start-** und **Enddatum/Uhrzeit** für das Blockout fest.
4. Fügen Sie optional einen **Grund**-Notiz hinzu.
5. Klicken Sie auf **Speichern**.

## Ereignisvorlagen

Vorlagen ermöglichen es Ihnen, eine wiederverwendbare Ereigniskonfiguration -- Titel, Beschreibung und zugeordnete Gruppen -- zu speichern, damit wiederkehrende Ereignisse konsistent erstellt werden können.

### Eine Vorlage hinzufügen

1. Klicken Sie auf die Registerkarte **Vorlagen** und dann auf **Vorlage hinzufügen**.
2. Geben Sie einen **Namen** für die Vorlage ein.
3. Verknüpfen Sie optional eine **Gruppe**, damit das Ereignis automatisch mit dieser Gruppe verbunden wird, wenn es von der Vorlage erstellt wird.
4. Klicken Sie auf **Speichern**.

Wenn Sie ein neues Ereignis erstellen, können Mitarbeiter eine bestehende Vorlage auswählen, um die Ereignisdetails vorausgefüllt zu haben.
