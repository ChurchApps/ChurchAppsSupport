# Kalender erstellen

<div class="article-intro">

Mit einem Kalender in B1 Admin erstellen Sie eine kuratierte Ansicht von Veranstaltungen, indem Sie eine oder mehrere Gruppen verbinden. Veranstaltungen werden von den Gruppenleitenden in ihren Gruppen verwaltet, und Ihr Kalender zeigt diese Veranstaltungen an einem Ort. Administratoren mit Bearbeitungsrechten können Veranstaltungen für jede Gruppe hinzufügen oder bearbeiten. Gruppenleitende ohne Administratorrechte können nur Veranstaltungen für Gruppen verwalten, die sie leiten.

## Einen neuen Kalender erstellen

1. Öffnen Sie in B1 Admin das [Sprungmenü](../introduction.md#getting-around-with-the-jump-menu) (das Suchfeld oben links), klappen Sie **Kalender** auf und klicken Sie auf **Kalender**.
2. Klicken Sie oben auf der Seite auf **Kalender hinzufügen**. Das Formular für den neuen Kalender öffnet sich unterhalb der Kalenderliste.
3. Geben Sie einen **Namen** für Ihren Kalender ein (zum Beispiel „Veranstaltungen der Jugendarbeit“ oder „Hauptkalender der Kirche“).
4. Fügen Sie optional eine **Beschreibung** hinzu, damit Ihr Team versteht, wofür dieser Kalender gedacht ist.
5. Klicken Sie auf **Erstellen**, um Ihren neuen Kalender zu speichern.

## Die Detailseite des Kalenders

Nach dem Erstellen eines Kalenders klicken Sie in seiner Zeile auf **Veranstaltungen verwalten**, um die Detailseite zu öffnen. Diese Seite hat zwei Hauptbereiche:

- **Linke Spalte** – Der Name des Kalenders mit seinen Aktionen (**Neue Veranstaltung**, **Bearbeiten**, **.ics importieren** und **Drucken**), darunter die Liste **Gruppen im Kalender**, die zeigt, welche Gruppen in diesem Kalender enthalten sind. Klicken Sie neben einer Gruppe auf **Entfernen**, um sie aus dem Kalender zu nehmen.
- **Hauptbereich** – Die Ansicht **Kalenderveranstaltungen** zeigt Veranstaltungen aus verbundenen Gruppen, darüber die Schaltflächen **Abonnieren** und **Gruppe hinzufügen**.

## Gruppen verbinden

Gruppen, die Veranstaltungen im Kalender haben, erscheinen automatisch in der Liste **Gruppen im Kalender** auf der linken Seite der Detailseite.

1. Klicken Sie oberhalb des Kalenders auf **Gruppe hinzufügen**, um dem Kalender eine Gruppe zuzuordnen.
2. Wählen Sie die Gruppe aus dem Dropdown-Menü. Die Liste enthält jede Gruppe Ihrer Kirche, nicht nur die Gruppen, zu denen Sie gehören.
3. Wählen Sie, ob **alle Veranstaltungen** dieser Gruppe oder nur **bestimmte Veranstaltungen** aufgenommen werden sollen.
4. Klicken Sie auf **Speichern**.

Jede Veranstaltung erscheint nur einmal im Kalender. Wenn Sie eine ganze Gruppe hinzufügen, werden alle Veranstaltungen dieser Gruppe, die Sie bereits einzeln hinzugefügt hatten, in den Gruppeneintrag übernommen. Wenn Sie bestimmte Veranstaltungen einer Gruppe auswählen, die bereits im Kalender ist, wird nichts Neues hinzugefügt. Nur als Ganzes hinzugefügte Gruppen werden unter **Gruppen im Kalender** aufgeführt.

### Eine .ics-Datei importieren

Klicken Sie auf **.ics importieren**, um Veranstaltungen aus einem anderen Kalender zu übernehmen. Wählen Sie die **Gruppe**, zu der die Veranstaltungen gehören sollen, klicken Sie dann auf **.ics-Datei auswählen** oder fügen Sie den Inhalt der Datei ein, und klicken Sie auf **Importieren**. Die Veranstaltungen werden in dieser Gruppe angelegt, und die Gruppe wird dem Kalender hinzugefügt, aus dem Sie importiert haben, sodass die Veranstaltungen dort sofort erscheinen.

### Eine Veranstaltung aus dem Kalender entfernen

Klicken Sie auf eine Veranstaltung im Kalender und dann auf **Aus Kalender entfernen**. Dies nimmt die Veranstaltung nur aus diesem Kalender heraus – die Veranstaltung selbst bleibt in ihrer Gruppe. Ist die Veranstaltung im Kalender, weil ihre ganze Gruppe hinzugefügt wurde, entfernt dies alle Veranstaltungen dieser Gruppe aus dem Kalender (sie bleiben weiterhin in der Gruppe). Um eine Veranstaltung endgültig zu löschen, entfernen Sie sie über den [Kalender der Gruppe](../groups/group-calendar.md).

:::tip
Das Verbinden von Gruppen mit Ihrem Kalender ist eine wirkungsvolle Möglichkeit, Veranstaltungen automatisch zusammenzuführen. Wenn eine Gruppenleitung eine Veranstaltung zu ihrer [Gruppe](../groups/creating-groups.md) hinzufügt, kann sie ohne zusätzlichen Aufwand in Ihren kirchenweiten Kalender übernommen werden.
:::

:::info
Wenn Sie einen einzigen Kalender erstellen möchten, der Veranstaltungen aus vielen Gruppen Ihrer Kirche bündelt, lesen Sie [Kuratierter Kalender](./curated-calendar.md) für einen einfacheren Weg.
:::

## Veranstaltungen hinzufügen und bearbeiten {#adding-and-editing-events}

Klicken Sie auf der Detailseite des Kalenders auf **Neue Veranstaltung**, um eine Veranstaltung hinzuzufügen, oder klicken Sie auf eine Veranstaltung im Kalender und dann auf **Bearbeiten**, um sie zu ändern. Das Formular **Neue Veranstaltung** / **Veranstaltung bearbeiten** enthält folgende Felder:

- **Gruppe** – Die Gruppe, zu der die Veranstaltung gehört. Wenn Ihre Kirche Veranstaltungsvorlagen hat, können Sie außerdem eine **Vorlage** auswählen, um das Formular vorzubefüllen.
- **Titel**
- **Veranstaltungsfoto** – Klicken Sie auf **Foto hinzufügen** (oder auf das leere Fotofeld), um ein Bild auszuwählen oder hochzuladen, das auf ein breites 16:9-Format zugeschnitten wird. Klicken Sie auf **Foto ändern**, um es zu ersetzen. Das Foto wird oben auf der Seite der Veranstaltung auf Ihrer Website angezeigt und als ihre Kachel, wenn ein Kalender-Element **Kommende Veranstaltungen** anzeigt (siehe [Veranstaltungen auf Ihrer Website anzeigen](#showing-events-on-your-website)).
- **Beschreibung** – Wird auf der Seite der Veranstaltung auf Ihrer Website angezeigt. Fetter Text, Listen und Links werden unterstützt.
- **Start** und **Ende**, **Wiederholung** und **Sichtbarkeit** (**Öffentlich** oder **Privat**).
- **Schlagwörter** – Durch Kommas getrennte Bezeichnungen, wie `Jugend, Schüler`. Ein Kalender-Element auf Ihrer Website kann so eingestellt werden, dass nur Veranstaltungen mit einem bestimmten Schlagwort angezeigt werden. Dies ist dasselbe Feld **Schlagwörter**, das in den Anmeldeeinstellungen der Veranstaltung erscheint.
- **Wer Notizen sehen kann** und **Wer Notizen verfassen kann** – Wer die Notizen der Veranstaltung lesen und ergänzen darf (siehe [Notizen zu Veranstaltungen](#event-notes)). Wählen Sie **Nur Mitarbeitende** (die Voreinstellung), **Gruppenleitende** (Leitende der Gruppe der Veranstaltung) oder **Gruppenmitglieder** (alle Personen in der Gruppe der Veranstaltung, einschließlich der Leitenden).
- **Räume** und **Ressourcen** – Reservieren Sie Raum und Ausstattung für die Veranstaltung. Siehe [Räume, Ressourcen & Planung](./rooms-resources.md).

Klicken Sie auf **Speichern**. Wiederholt sich die Veranstaltung, bittet B1 um Bestätigung, da beim Speichern alle Termine der Reihe aktualisiert werden.

### Notizen zu Veranstaltungen {#event-notes}

Jede Veranstaltung hat ihren eigenen Notizverlauf für Planung und Nachbereitung. Klicken Sie auf der Detailseite des Kalenders auf eine Veranstaltung; der Dialog zeigt die Angaben zur Veranstaltung, ihre Erinnerungen und darunter die **Notizen**. Schreiben Sie eine Notiz und veröffentlichen Sie sie, um sie dem Verlauf hinzuzufügen.

Mitarbeitende mit der Berechtigung, Inhalte zu bearbeiten oder Kalender zu verwalten, können Notizen zu Veranstaltungen immer lesen und verfassen. Die Einstellungen **Wer Notizen sehen kann** und **Wer Notizen verfassen kann** der Veranstaltung legen fest, ob auch die Leitenden oder Mitglieder der Gruppe der Veranstaltung dies dürfen.

### Veranstaltungen auf Ihrer Website anzeigen {#showing-events-on-your-website}

Um einen Kalender auf Ihrer Website anzuzeigen, fügen Sie einer Seite ein Element **Kalender** hinzu und wählen Sie diesen Kalender. Das Element kann einen Monatskalender oder ein Raster mit Kacheln kommender Veranstaltungen anzeigen und sich auf Veranstaltungen mit einem Schlagwort beschränken. Besucher, die eine Veranstaltung anklicken, öffnen deren eigene Seite. Siehe [Verwendung des Kalender-Elements](../website/page-editor.md#using-the-calendar-element).

## Veranstaltungsanmeldung aktivieren {#enabling-event-registration}

Sie können für jede Kalenderveranstaltung eine Anmeldung aktivieren, damit sich Mitglieder über die B1-Website oder die mobile App anmelden können.

1. Klicken Sie auf eine bestehende Veranstaltung oder legen Sie eine neue an.
2. Schalten Sie im Veranstaltungseditor **Anmeldung** ein.
3. Konfigurieren Sie die Anmeldeeinstellungen:
   - **Kapazität** (optional) – Legen Sie eine maximale Anzahl an Anmeldungen fest. Leer lassen für unbegrenzt.
   - **Anmeldung öffnet** – Datum und Uhrzeit, ab denen die Anmeldung möglich ist.
   - **Anmeldung schließt** – Datum und Uhrzeit, zu denen die Anmeldung endet.
   - **Schlagwörter** – Durch Kommas getrennte Bezeichnungen (z. B. „Jugend, Freizeit, Kinderbibelwoche“), um anmeldbare Veranstaltungen zu kategorisieren.
   - **Fragen zur Anmeldung** – Hängen Sie optional ein [Formular](../forms/creating-forms.md) an, damit Teilnehmende bei der Anmeldung zusätzliche Fragen beantworten (Ernährungseinschränkungen, T-Shirt-Größe, Notfallkontakt usw.). Wählen Sie **Keine**, um Fragen zu überspringen.
   - **Warteliste aktivieren** – Ist die Veranstaltung voll, können zusätzliche Interessierte auf eine Warteliste statt abgewiesen zu werden. Siehe [Kostenpflichtige Anmeldungen](./paid-registrations.md#waitlist).
4. Speichern Sie die Veranstaltung.

Bei kostenpflichtigen Veranstaltungen können Sie auf derselben Einstellungsseite preisierte **Teilnehmertypen**, optionale **Auswahlmöglichkeiten** (Zusatzoptionen) und **Rabattcodes** festlegen. Die Zahlung wird über den bestehenden Spendenanbieter Ihrer Kirche abgewickelt. Die vollständige Anleitung finden Sie unter [Kostenpflichtige Anmeldungen](./paid-registrations.md).

Sobald die Anmeldung aktiviert ist, sehen Mitglieder eine Schaltfläche **Für diese Veranstaltung anmelden**, wenn sie die Veranstaltung auf der [B1-Website](../../b1-church/events/registering.md) oder in der [B1-Mobile-App](../../b1-church/events/registering.md) ansehen. Haben Sie ein Formular angehängt, sehen Angemeldete während der Anmeldung einen Schritt **Fragen**, und ihre Antworten werden mit der Anmeldung gespeichert.

:::info
Fragen zur Anmeldung funktionieren nur mit Formularen, die **nicht** als eingeschränkt markiert sind. Ein eingeschränktes Formular wird bei der Anmeldung automatisch übersprungen statt angezeigt. Verwenden Sie daher ein nicht eingeschränktes Formular, wenn Sie Fragen an eine Veranstaltung anhängen.
:::

### Anmeldungen verwalten

So sehen und verwalten Sie die Anmeldungen zu Ihren Veranstaltungen:

1. Wählen Sie im Sprungmenü **Kalender > Anmeldungen**.
2. Sie sehen eine Tabelle aller Veranstaltungen mit aktivierter Anmeldung, mit Titel, Datum, aktueller Anzahl an Anmeldungen im Verhältnis zur Kapazität und den Schlagwörtern.
3. Klicken Sie auf eine Veranstaltung, um die vollständige Liste der Anmeldungen zu sehen, einschließlich Namen, Anzahl der Mitglieder, Teilnehmertypen, Zahlungsstatus und Anmeldedatum.
4. Auf der Detailseite können Sie:
   - **Teilnehmer hinzufügen** – Jemanden manuell anmelden, der offline oder telefonisch angemeldet wurde.
   - Einzelne Anmeldungen **stornieren**
   - Anmeldungen dauerhaft **löschen**
   - Anmeldungen von der Warteliste **nachrücken lassen**, sobald ein Platz frei wird
   - **CSV exportieren** – Alle Anmeldungen herunterladen, einschließlich Teilnehmertypen, Auswahlmöglichkeiten, Zahlbeträgen und Antworten auf Fragen

Hat die Veranstaltung angehängte Fragen zur Anmeldung, zeigt die Detailseite außerdem einen Filter **Nur unbeantwortete Fragen**, um Angemeldete schnell zu finden, die ihre Antworten noch nicht abgegeben haben, sowie eine Schaltfläche **Antworten ansehen** bei jeder beantworteten Anmeldung, um ihre Antworten einzusehen. Bei kostenpflichtigen Veranstaltungen kommen eine Spalte **Typ**, eine Spalte **Bezahlt / Gesamt**, Zählungen pro Typ und ein Dialog mit Zahlungsdetails hinzu – siehe [Kostenpflichtige Anmeldungen](./paid-registrations.md#the-registration-roster).

:::tip
Nutzen Sie den Fortschrittsbalken der Kapazität, um zu verfolgen, wie schnell sich Veranstaltungen füllen. Der Balken wird rot, sobald eine Veranstaltung die Kapazität erreicht oder überschreitet.
:::
