# Profil

<div class="article-intro">

Der Bereich Profil ermöglicht es Ihnen, Ihre persönlichen Kontoeinstellungen in ChurchApps zu verwalten. Ihr Profil wird von allen ChurchApps-Werkzeugen gemeinsam genutzt, daher gelten Änderungen, die Sie hier vornehmen, überall – von B1 Admin bis zur mobilen App B1 Mobile.

</div>

## Was Sie tun können

Im Bereich Profil können Sie:

- **Name und E-Mail-Adresse aktualisieren** – Halten Sie Ihre Kontaktdaten aktuell.
- **Passwort ändern** – Legen Sie ein neues Passwort für Ihr Konto fest.
- **Zwei-Faktor-Anmeldung einschalten** – Verlangen Sie beim Anmelden einen Code aus einer Authentifizierungs-App. Siehe [Zwei-Faktor-Anmeldung](./managing-profile.md#two-factor-sign-in).
- **Designs wechseln** – Schalten Sie im Benutzermenü (klicken Sie oben rechts auf Ihr Profilbild) zwischen hellem und dunklem Modus um.
- **Verbundene Geräte verwalten** – Sehen und steuern Sie, welche ChurchAppsPlayer-Geräte mit Ihrem Konto verknüpft sind.
- **Verknüpfte Konten einsehen** – Sehen und verwalten Sie externe Dienste, die mit Ihrem ChurchApps-Konto verbunden sind.
- **Änderungswünsche am Profil genehmigen** – Prüfen und übernehmen Sie Aktualisierungen, die Mitglieder eingereicht haben.

## Unterbereiche des Profils

Der Bereich Profil umfasst folgende Seiten:

1. **[Ihr Profil verwalten](./managing-profile.md)** – Bearbeiten Sie Ihre persönlichen Angaben, ändern Sie Ihr Passwort, verwalten Sie verknüpfte Konten, schalten Sie die Zwei-Faktor-Anmeldung ein, passen Sie die Designeinstellungen an und nehmen Sie die Löschung des Kontos vor.
2. **[Änderungen am Profil genehmigen](./approving-profile-changes.md)** – Prüfen und genehmigen Sie Aktualisierungswünsche, die Mitglieder über B1 Mobile eingereicht haben.
3. **[Geräte verwalten](./devices.md)** – Sehen, hinzufügen und verwalten Sie ChurchAppsPlayer-Geräte, die mit Ihrem Konto gekoppelt sind.

:::tip
Halten Sie Ihre E-Mail-Adresse aktuell. Sie wird für die Wiederherstellung des Kontos und für wichtige Mitteilungen Ihrer Kirche verwendet.
:::
