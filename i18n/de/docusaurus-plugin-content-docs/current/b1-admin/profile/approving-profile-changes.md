# Profiländerungen genehmigen

<div class="article-intro">

Wenn Ihre Gemeinde für Profilaktualisierungen die Genehmigung durch eine Administration verlangt, reichen Mitglieder ihre Änderungen über die B1-App ein. Diese Anfragen erscheinen dann als Aufgaben in B1 Admin. Diese Anleitung erklärt, wie Sie sie prüfen und genehmigen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen Mitglied der Gruppe sein, die unter **Mobile &rarr; Mitgliederportal** als **Verzeichnis-Genehmigungsgruppe** festgelegt ist
- Ist keine Genehmigungsgruppe konfiguriert, werden Profiländerungen ohne Prüfung sofort übernommen

</div>

## Wo Sie offene Anfragen finden

Wenn ein Mitglied eine Profiländerung einreicht, erscheint sie als Aufgabe, die Ihrer Genehmigungsgruppe zugewiesen ist. Sie finden sie an zwei Stellen:

**Auf dem Dashboard (Ihrer Startseite):**
1. Melden Sie sich bei B1 Admin an. Das Dashboard wird automatisch geladen.
2. Klicken Sie im Bereich **Meine Aufgaben** auf **Alle Aufgaben**. (Meine Aufgaben zeigt nur offene Aufgaben, die Ihnen persönlich zugewiesen sind.)
3. Klicken Sie auf den Reiter **Meinen Gruppen zugewiesen**. Dort werden alle offenen Anfragen zur Profiländerung aufgelistet.

**Unter Dienste &rarr; Meine Arbeit:**
1. Öffnen Sie das [Sprungmenü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links in B1 Admin) und klappen Sie **Dienste** auf.
2. Klicken Sie auf **Meine Arbeit**.
3. Klicken Sie unter Aufgaben auf den Reiter **Meinen Gruppen zugewiesen**.

## Eine Anfrage prüfen und genehmigen

1. Klicken Sie auf die Aufgabe **Profilaktualisierung**, um sie zu öffnen.
2. Unter **Gewünschte Änderungen** sehen Sie jedes Feld, das das Mitglied ändern möchte, zusammen mit dem neuen Wert, den es eingereicht hat.
3. Prüfen Sie die Änderungen.
4. Klicken Sie auf **Anwenden**, um die Änderungen zu genehmigen und im Profil des Mitglieds zu speichern.

Eine Anfrage, ein Familienmitglied hinzuzufügen, zeigt Anrede, Name, Haushaltsrolle und Mobilnummer der neuen Person in einer Zeile (zum Beispiel *Herr John Smith · Kind · 555-0100*). Beim Anwenden wird diese Person mit diesen Angaben im Haushalt des Mitglieds angelegt.

Die Aufgabe wird automatisch geschlossen, sobald die Änderungen angewendet wurden.

## Die Genehmigungsgruppe einrichten

Soll Ihre Gemeinde Profiländerungen genehmigen lassen, muss zuerst eine Verzeichnis-Genehmigungsgruppe konfiguriert werden.

1. Öffnen Sie das Sprungmenü und klappen Sie **Mobile** auf.
2. Klicken Sie auf **Mitgliederportal** (die Seite „Portal-Einstellungen“).
3. Wählen Sie unter **Verzeichnis-Genehmigungsgruppe** die Gruppe aus, deren Mitglieder Anfragen zur Profiländerung prüfen sollen.
4. Klicken Sie auf **Speichern**.

Jedes Mitglied dieser Gruppe sieht eingehende Anfragen zur Profiländerung unter **Meinen Gruppen zugewiesen** auf seinem Dashboard.

Dieselbe Verzeichnis-Genehmigungsgruppe prüft auch **Anfragen zur Kontolöschung**. Siehe [Anfragen zur Kontolöschung prüfen](./account-deletion.md).

:::tip
Stellen Sie sicher, dass Ihre Genehmigenden tatsächlich Mitglieder der konfigurierten Gruppe sind. Nur Gruppenmitglieder sehen die Anfragen.
:::
