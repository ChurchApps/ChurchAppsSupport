# Profiländerungen genehmigen

<div class="article-intro">

Wenn Ihre Gemeinde für Profilaktualisierungen die Genehmigung durch eine Administration verlangt, reichen Mitglieder ihre Änderungen über die B1-App ein, und diese Anfragen erscheinen in B1 Admin als Aufgaben. Diese Anleitung erklärt, wie Sie sie prüfen und genehmigen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen Mitglied der Gruppe sein, die unter **Mobile &rarr; Mitgliederportal** als **Verzeichnis-Genehmigungsgruppe** festgelegt ist
- Ist keine Genehmigungsgruppe eingerichtet, werden Profiländerungen ohne Prüfung sofort übernommen

</div>

## Wo Sie offene Anfragen finden {#where-to-find-pending-requests}

Reicht ein Mitglied eine Profiländerung ein, erscheint sie als Aufgabe, die Ihrer Genehmigungsgruppe zugewiesen ist. Sie finden sie an zwei Stellen:

**Vom Dashboard (Ihrer Startseite) aus:**
1. Melden Sie sich bei B1 Admin an -- das Dashboard wird automatisch geladen.
2. Klicken Sie im Abschnitt **Meine Aufgaben** auf **Alle Aufgaben**. (Meine Aufgaben zeigt nur offene Aufgaben, die Ihnen persönlich zugewiesen sind.)
3. Klicken Sie auf den Reiter **Meinen Gruppen zugewiesen**. Ausstehende Anfragen zu Profiländerungen werden dort aufgelistet.

**Über Dienst &rarr; Meine Arbeit:**
1. Öffnen Sie das [Sprungmenü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links in B1 Admin) und klappen Sie **Dienst** auf.
2. Klicken Sie auf **Meine Arbeit**.
3. Klicken Sie unter Aufgaben auf den Reiter **Meinen Gruppen zugewiesen**.

## Eine Anfrage prüfen und genehmigen {#reviewing-and-approving-a-request}

1. Klicken Sie auf die Aufgabe **Profilaktualisierung**, um sie zu öffnen.
2. Unter **Gewünschte Änderungen** sehen Sie jedes Feld, das das Mitglied aktualisieren möchte, zusammen mit dem neuen Wert, den es eingereicht hat.
3. Prüfen Sie die Änderungen.
4. Klicken Sie auf **Übernehmen**, um die Änderungen zu genehmigen und im Profil des Mitglieds zu speichern.

Eine Anfrage, ein Familienmitglied hinzuzufügen, zeigt Anrede, Name, Haushaltsrolle und Mobilnummer der neuen Person in einer Zeile (zum Beispiel *Herr John Smith · Kind · 555-0100*). Beim Übernehmen wird diese Person im Haushalt des Mitglieds mit diesen Angaben angelegt.

Die Aufgabe wird automatisch geschlossen, sobald die Änderungen übernommen wurden.

## Die Genehmigungsgruppe einrichten {#setting-up-the-approval-group}

Soll eine Profiländerung eine Genehmigung erfordern, muss zuerst eine Verzeichnis-Genehmigungsgruppe festgelegt werden.

1. Öffnen Sie das Sprungmenü und klappen Sie **Mobile** auf.
2. Klicken Sie auf **Mitgliederportal** (die Seite „Portaleinstellungen“).
3. Wählen Sie unter **Verzeichnis-Genehmigungsgruppe** die Gruppe aus, deren Mitglieder Anfragen zu Profiländerungen prüfen sollen.
4. Klicken Sie auf **Speichern**.

Jedes Mitglied dieser Gruppe sieht eingehende Anfragen zu Profiländerungen auf seinem Dashboard unter **Meinen Gruppen zugewiesen**.

Dieselbe Verzeichnis-Genehmigungsgruppe prüft auch **Anfragen zur Kontolöschung** -- siehe [Anfragen zur Kontolöschung prüfen](./account-deletion.md).

:::tip
Stellen Sie sicher, dass Ihre Genehmigenden tatsächlich Mitglieder der festgelegten Gruppe sind -- nur Gruppenmitglieder sehen die Anfragen.
:::
