# Genehmigung von Profiländerungen

<div class="article-intro">

Wenn Ihre Kirche eine Administratorgenehmigung für Profilein aktualisierungen benötigt, reichen Mitglieder ihre Änderungen über die B1 Mobile App ein und diese Anfragen werden als Aufgaben in B1 Admin angezeigt.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen ein Mitglied der Gruppe sein, die als **Verzeichnisgenehmigungsgruppe** bestimmt ist
- Wenn keine Genehmigungsgruppe konfiguriert wurde, werden Profilein aktualisierungen sofort angewendet

</div>

## Wo Sie ausstehende Anfragen finden

Wenn ein Mitglied eine Profiländerung einreicht, wird sie als Aufgabe angezeigt.

1. Melden Sie sich bei B1 Admin an
2. Im Abschnitt **Aufgaben** klicken Sie auf die Registerkarte **Meinen Gruppen zugewiesen**
3. Ausstehende Profiländerungsanfragen werden dort aufgelistet

## Überprüfung und Genehmigung einer Anfrage

1. Klicken Sie auf die Aufgabe **Profilein aktualisierung**, um sie zu öffnen
2. Unter **Angeforderte Änderungen** sehen Sie jedes Feld, das das Mitglied aktualisieren möchte
3. Überprüfen Sie die Änderungen
4. Klicken Sie auf **Anwenden**, um die Änderungen zu genehmigen und zu speichern

Die Aufgabe wird geschlossen, sobald die Änderungen angewendet werden.
