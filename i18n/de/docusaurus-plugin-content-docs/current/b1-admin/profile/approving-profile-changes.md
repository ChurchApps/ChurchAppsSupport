# Genehmigen von Profiländerungen

<div class="article-intro">

Wenn Ihre Kirche eine Administratorgenehmigung für Profilaktualisierungen erfordert, reichen Mitglieder ihre Änderungen über die B1 Mobile-App ein und diese Anfragen erscheinen als Aufgaben in B1 Admin. Diese Anleitung erläutert, wie Sie sie überprüfen und genehmigen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen ein Mitglied der Gruppe sein, die als **Verzeichnis-Genehmigungsgruppe** in **Mobile → B1 Mobile** ausgewählt wurde
- Falls keine Genehmigungsgruppe konfiguriert wurde, werden Profiländerungen sofort ohne Überprüfung angewendet

</div>

## Wo Sie ausstehende Anfragen finden

Wenn ein Mitglied eine Profiländerung einreicht, wird dies als Aufgabe angezeigt, die Ihrer Genehmigungsgruppe zugewiesen ist. Sie können es an zwei Stellen finden:

**Vom Dashboard aus:**
1. Melden Sie sich bei B1 Admin an – das Dashboard wird automatisch geladen.
2. Klicken Sie im Abschnitt **Aufgaben** auf der rechten Seite auf die Registerkarte **Meinen Gruppen zugewiesen**.
3. Alle ausstehenden Anfragen zur Änderung des Profils werden dort aufgelistet.

**Von Serving → Meine Arbeit:**
1. Klicken Sie in der oberen Navigation auf **Serving**.
2. Klicken Sie auf **Meine Arbeit**.
3. Klicken Sie unter Aufgaben auf die Registerkarte **Meinen Gruppen zugewiesen**.

## Überprüfen und Genehmigen einer Anfrage

1. Klicken Sie auf die Aufgabe **Profilaktualisierung**, um sie zu öffnen.
2. Unter **Angeforderte Änderungen** sehen Sie jedes Feld, das das Mitglied aktualisieren möchte, zusammen mit dem neuen Wert, den es eingereicht hat.
3. Überprüfen Sie die Änderungen.
4. Klicken Sie auf **Anwenden**, um die Änderungen zu genehmigen und auf ihrem Profil zu speichern.

Die Aufgabe wird automatisch geschlossen, nachdem die Änderungen angewendet wurden.

## Einrichten der Genehmigungsgruppe

Wenn Ihre Kirche möchte, dass Profiländerungen genehmigt werden müssen, muss zuerst eine Verzeichnis-Genehmigungsgruppe konfiguriert werden.

1. Klicken Sie in der oberen Navigation auf **Mobile**.
2. Klicken Sie auf **B1 Mobile**.
3. Wählen Sie unter **Verzeichnis-Genehmigungsgruppe** die Gruppe aus, deren Mitglieder Anfragen zur Änderung des Profils überprüfen sollten.
4. Klicken Sie auf **Speichern**.

Alle Mitglieder dieser Gruppe sehen eingehende Anfragen zur Änderung des Profils unter **Meinen Gruppen zugewiesen** in ihrem Dashboard.

:::tip
Stellen Sie sicher, dass Ihre Genehmiger tatsächlich Mitglieder der konfigurierten Gruppe sind – nur Gruppenmitglieder sehen die Anfragen.
:::
