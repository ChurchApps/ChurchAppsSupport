# Ihr Profil verwalten

<div class="article-intro">

Auf der Seite Profil bearbeiten Sie Ihre persönlichen Kontoeinstellungen. Ihr Profil wird von allen ChurchApps-Produkten gemeinsam genutzt, daher gelten Änderungen hier überall, wo Sie ChurchApps verwenden.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen in Ihrem ChurchApps-Konto angemeldet sein.
- Halten Sie Ihre neue E-Mail-Adresse oder Ihr neues Passwort bereit, falls Sie diese ändern möchten.

</div>

## Profilangaben

Die Seite Profil zeigt links Ihren Namen und Ihre E-Mail-Adresse, darunter die Schaltfläche **Bearbeiten**. Klicken Sie auf **Bearbeiten**, um das Formular **Konto bearbeiten** zu öffnen, das Ihre grundlegenden Kontodaten enthält:

1. **E-Mail** -- Ihre E-Mail-Adresse für die Anmeldung und den Empfang von Benachrichtigungen.
2. **Vorname** und **Nachname** -- Ihr Anzeigename in ChurchApps.
3. **Passwort** -- Aktualisieren Sie Ihr Kontopasswort.

Um Ihre Angaben zu aktualisieren, bearbeiten Sie die Felder und klicken Sie auf **Änderungen speichern**. Klicken Sie auf **Abbrechen** (oder auf den Link **Zurück zu** mit Ihrem Namen), um zu Ihrem Profil zurückzukehren, ohne zu speichern.

## Passwort ändern

1. Klicken Sie auf der Seite Profil auf **Bearbeiten**.
2. Geben Sie Ihr **aktuelles Passwort** ein.
3. Geben Sie Ihr neues Passwort im Feld **Neues Passwort** ein.
4. Wiederholen Sie es im Feld **Passwort bestätigen**.
5. Klicken Sie auf **Änderungen speichern**.

:::info
Ihr Passwort muss mindestens 8 Zeichen lang sein. Achten Sie darauf, dass Passwort und Bestätigung genau übereinstimmen. Zum Ändern müssen Sie Ihr aktuelles Passwort bestätigen. Wenn Sie es nicht kennen, nutzen Sie stattdessen den Link **Passwort vergessen** auf der Anmeldeseite.
:::

## Verknüpfte Konten

Der Abschnitt **Verknüpfte Konten** zeigt externe Dienste, die mit Ihrem ChurchApps-Konto verbunden sind. Hier sehen Sie, welche Konten verknüpft sind, und können diese Verbindungen verwalten.

## Zwei-Faktor-Anmeldung

Die Zwei-Faktor-Anmeldung fügt dem Login einen zweiten Schritt hinzu: Nach Ihrem Passwort (oder nach der Anmeldung mit Google, Microsoft oder dem E-Mail-Link) geben Sie zusätzlich einen 6-stelligen Code aus einer Authenticator-App auf Ihrem Telefon ein, etwa Google Authenticator, Microsoft Authenticator, 1Password oder Authy. Sie ist optional und standardmäßig ausgeschaltet. Ist sie eingeschaltet, gilt sie für jede ChurchApps-Anmeldung, die Ihr Konto nutzt -- B1 Admin, die B1.church-Website und -App Ihrer Kirche, B1 Church Checkin, Lessons.church, FreePlay und alle weiteren.

### Einschalten

1. Suchen Sie auf der Seite Profil den Abschnitt **Zwei-Faktor-Anmeldung** und klicken Sie auf **Einschalten**.
2. Scannen Sie den QR-Code mit Ihrer Authenticator-App. Wenn Sie ihn nicht scannen können, geben Sie den Schlüssel, der unter **Scannen nicht möglich? Diesen Schlüssel eingeben:** angezeigt wird, stattdessen in die App ein.
3. Geben Sie den **6-stelligen Code** aus Ihrer App ein und klicken Sie auf **Prüfen**.
4. B1 Admin zeigt Ihnen zehn **Sicherungscodes**. Jeder davon meldet Sie einmal an, falls Sie Ihr Telefon verlieren. Klicken Sie auf **Kopieren** oder schreiben Sie sie auf, bewahren Sie sie sicher auf und klicken Sie auf **Ich habe sie gespeichert**.

:::warning
Die Sicherungscodes werden nur einmal angezeigt. Verlieren Sie Ihr Telefon und haben keine Sicherungscodes mehr, muss ein Serveradministrator von ChurchApps die Zwei-Faktor-Anmeldung für Sie ausschalten, nachdem Ihre Identität bestätigt wurde.
:::

Ist die Zwei-Faktor-Anmeldung eingeschaltet, zeigt der Abschnitt **Ein** und die Anzahl Ihrer verbleibenden Sicherungscodes.

### Mit einem Code anmelden

Nachdem Sie Ihr Passwort eingegeben haben, fragt die Anmeldeseite nach einem Code. Geben Sie den 6-stelligen Code aus Ihrer Authenticator-App oder einen Ihrer Sicherungscodes ein und senden Sie ihn ab. Jeder Sicherungscode funktioniert nur einmal. Ist der Code falsch, erscheint die Meldung "Dieser Code hat nicht funktioniert. Bitte versuchen Sie es erneut." Nach zu vielen falschen Codes wird die Anmeldung für Ihr Konto für eine Weile pausiert.

Auf einem Gerät, auf dem Sie bereits angemeldet waren, wird beim Angemeldetbleiben kein Code erneut verlangt; er wird nur bei einer neuen Anmeldung abgefragt.

### Ausschalten

1. Klicken Sie im Abschnitt **Zwei-Faktor-Anmeldung** auf **Ausschalten**.
2. Geben Sie einen aktuellen Code aus Ihrer Authenticator-App oder einen Sicherungscode ein.
3. Klicken Sie auf **Prüfen**.

:::info
Die Zwei-Faktor-Anmeldung lässt sich bei Demokonten nicht einrichten, daher ist der Abschnitt dort ausgeblendet.
:::

## Design-Einstellungen

B1 Admin ermöglicht es Ihnen, ein Farbdesign sowie den hellen oder dunklen Anzeigemodus zu wählen:

1. Klicken Sie oben rechts in B1 Admin auf Ihr Profilbild, um das Benutzermenü zu öffnen.
2. Wählen Sie unter **Design-Einstellungen** ein Design:
   - **Standard** -- Das aktuelle Aussehen von B1 Admin: Rahmenpanels auf einer klaren Fläche. Neue Benutzer sehen dieses Design, bis sie ein anderes wählen.
   - **Klassisch** -- Das frühere Aussehen von B1 Admin mit farbigem Seitenbanner, Karten mit Schatten und grauem Hintergrund. Haben Sie B1 Admin auf diesem Gerät vor dem neuen Aussehen genutzt und nie ein Design gewählt, bleiben Sie bei Klassisch.
   - **Benutzerdefiniert** -- Das Standard-Aussehen, gebaut aus der eigenen Farbe Ihrer Kirche. Es verwendet die Primärfarbe des hellen Modus aus **Mobil > App-Design** oder, falls keine App-Farbe festgelegt ist, die Primärfarbe Ihrer Website, sodass B1 Admin zur App Ihrer Mitglieder passt.
3. Wählen Sie unterhalb der Designs **Heller Modus** oder **Dunkler Modus**.
4. Die Oberfläche aktualisiert sich sofort entsprechend Ihrer Auswahl.

Ihre Auswahl wird auf diesem Gerät und in diesem Browser gespeichert.

## Konto löschen

Im Abschnitt **Konto löschen** der Seite Profil finden Sie die Option, Ihr Konto zu löschen.

- Hat Ihre Kirche **keine** Freigabegruppe für das Verzeichnis eingerichtet, entfernt **Mein Konto löschen** Ihr Konto und die zugehörigen Daten sofort. Dies kann nicht rückgängig gemacht werden.
- Hat Ihre Kirche eine Freigabegruppe für das Verzeichnis **eingerichtet**, wird Ihre Anfrage stattdessen zur Prüfung an diese Gruppe geschickt. Die Schaltfläche ist deaktiviert, solange die Anfrage offen ist, und Sie werden benachrichtigt, sobald Ihre Kirche sie genehmigt oder abgelehnt hat. Was danach geschieht, lesen Sie unter [Anfragen zur Kontolöschung prüfen](./account-deletion.md).

:::warning
Die Kontolöschung -- ob sofort oder nach Genehmigung durch Ihre Kirche -- ist endgültig und kann nicht rückgängig gemacht werden.
:::

:::info
Sind Sie **Domänenadministrator**, übertragen Sie die Verwaltungsaufgaben an einen anderen Benutzer, bevor Sie Ihr Konto löschen. Details zur Verwaltung von Administratorrollen finden Sie unter [Rollen & Berechtigungen](../settings/roles-permissions.md).
:::

:::info
Die Bearbeitung des Profils ist im Demomodus deaktiviert. Mit einem Demokonto können Sie Ihre Profileinstellungen nicht ändern.
:::
