# Ihr Profil verwalten

<div class="article-intro">

Auf der Profilseite bearbeiten Sie Ihre persönlichen Kontoeinstellungen. Ihr Profil wird über alle ChurchApps-Produkte hinweg geteilt. Änderungen, die Sie hier vornehmen, gelten daher überall, wo Sie ChurchApps verwenden.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen in Ihrem ChurchApps-Konto angemeldet sein
- Halten Sie Ihre neue E-Mail-Adresse oder Ihr neues Passwort bereit, falls Sie diese ändern möchten

</div>

## Profilinformationen

Die Profilseite zeigt links Ihren Namen und Ihre E-Mail-Adresse, darunter befindet sich eine Schaltfläche **Bearbeiten**. Klicken Sie auf **Bearbeiten**, um das Formular **Konto bearbeiten** zu öffnen, das Ihre grundlegenden Kontodaten enthält:

1. **E-Mail** -- Ihre E-Mail-Adresse, die zur Anmeldung und für Benachrichtigungen verwendet wird.
2. **Vorname** und **Nachname** -- Ihr Anzeigename in ChurchApps.
3. **Passwort** -- Aktualisieren Sie Ihr Kontopasswort.

Um Ihre Angaben zu ändern, bearbeiten Sie die Felder und klicken Sie auf die Schaltfläche **Änderungen speichern**. Klicken Sie auf **Abbrechen** (oder auf den Link **Zurück zu** mit Ihrem Namen), um zu Ihrem Profil zurückzukehren, ohne zu speichern.

## Passwort ändern

1. Klicken Sie auf der Profilseite auf **Bearbeiten**.
2. Geben Sie Ihr **Aktuelles Passwort** ein.
3. Geben Sie Ihr neues Passwort im Feld **Neues Passwort** ein.
4. Geben Sie es im Feld **Passwort bestätigen** erneut ein.
5. Klicken Sie auf **Änderungen speichern**.

:::info
Ihr Passwort muss mindestens 8 Zeichen lang sein. Achten Sie darauf, dass das Passwort und die Bestätigung genau übereinstimmen. Um Ihr Passwort zu ändern, müssen Sie Ihr aktuelles Passwort bestätigen. Wenn Sie es nicht kennen, verwenden Sie stattdessen den Link **Passwort vergessen** auf der Anmeldeseite.
:::

## Verknüpfte Konten

Der Bereich **Verknüpfte Konten** zeigt alle externen Dienste, die mit Ihrem ChurchApps-Konto verbunden sind. Hier können Sie einsehen, welche Konten verknüpft sind, und diese Verbindungen verwalten.

## Design-Einstellungen

Mit B1 Admin können Sie ein Farbdesign und einen hellen oder dunklen Anzeigemodus wählen:

1. Klicken Sie oben rechts in B1 Admin auf Ihr Profilbild, um Ihr Benutzermenü zu öffnen.
2. Wählen Sie unter **Design-Einstellungen** ein Design aus:
   - **Standard** -- Das aktuelle Aussehen von B1 Admin: umrandete Felder auf einer klaren Fläche.
   - **Klassisch** -- Das frühere Aussehen von B1 Admin mit einem farbigen Seitenbanner, Karten mit Schatten und einem grauen Hintergrund. Dieses Design sehen Sie, bis Sie ein anderes auswählen.
   - **Benutzerdefiniert** -- Das Standard-Aussehen, angepasst an die Farbe Ihrer Gemeinde. Es verwendet die Primärfarbe für den hellen Modus aus **Mobil > App-Design** oder, falls keine App-Farbe festgelegt ist, die Primärfarbe Ihrer Website, damit B1 Admin zu Ihrer Mitglieder-App passt.
3. Wählen Sie darunter **Heller Modus** oder **Dunkler Modus**.
4. Die Oberfläche wird sofort an Ihre Auswahl angepasst.

Ihre Auswahl wird auf diesem Gerät und in diesem Browser gespeichert.

## Kontolöschung

Im Bereich **Kontolöschung** auf der Profilseite finden Sie die Option, Ihr Konto zu löschen.

- Wenn Ihre Gemeinde **keine** Gruppe für die Verzeichnisfreigabe eingerichtet hat, entfernt ein Klick auf **Mein Konto löschen** Ihr Konto und die zugehörigen Daten sofort. Dies kann nicht rückgängig gemacht werden.
- Wenn Ihre Gemeinde eine Gruppe für die Verzeichnisfreigabe eingerichtet **hat**, wird Ihre Anfrage stattdessen zur Prüfung an diese Gruppe gesendet. Die Schaltfläche ist deaktiviert, solange die Anfrage aussteht, und Sie werden benachrichtigt, sobald Ihre Gemeinde sie genehmigt oder ablehnt. Was danach geschieht, erfahren Sie unter [Anfragen zur Kontolöschung prüfen](./account-deletion.md).

:::warning
Die Löschung eines Kontos ist dauerhaft und kann nicht rückgängig gemacht werden, egal ob sie sofort erfolgt oder von Ihrer Gemeinde genehmigt wurde.
:::

:::info
Wenn Sie ein **Domain-Administrator** sind, übertragen Sie bitte die Administratorrechte an einen anderen Benutzer, bevor Sie Ihr Konto löschen. Details zur Verwaltung von Administratorrollen finden Sie unter [Rollen & Berechtigungen](../settings/roles-permissions.md).
:::

:::info
Das Bearbeiten des Profils ist im Demo-Modus deaktiviert. Wenn Sie ein Demo-Konto verwenden, können Sie Ihre Profileinstellungen nicht ändern.
:::
