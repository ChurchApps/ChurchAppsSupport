# Profil verwalten

<div class="article-intro">

Die Seite Profil ermöglicht es Ihnen, Ihre persönlichen Kontoeinstellungen zu bearbeiten. Ihr Profil wird in allen ChurchApps-Produkten gemeinsam genutzt, daher werden alle hier von Ihnen vorgenommenen Änderungen überall dort angezeigt, wo Sie ChurchApps verwenden.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen in Ihrem ChurchApps-Konto angemeldet sein
- Halten Sie Ihre neue E-Mail-Adresse oder Ihr Passwort bereit, falls Sie diese aktualisieren möchten

</div>

## Profilinformation

Der obere Bereich der Seite Profil enthält Ihre grundlegenden Kontodetails:

1. **E-Mail** – Ihre E-Mail-Adresse für die Anmeldung und den Empfang von Benachrichtigungen.
2. **Vorname** und **Nachname** – Ihr Anzeigename in ChurchApps.
3. **Passwort** – Aktualisieren Sie Ihr Kontopasswort.

Um Ihre Informationen zu aktualisieren, bearbeiten Sie die Felder und klicken Sie auf die Schaltfläche **Änderungen speichern**.

## Ändern Sie Ihr Passwort

1. Scrollen Sie zu den Passwortfeldern auf der Seite Profil.
2. Geben Sie Ihr **aktuelles Passwort** ein.
3. Geben Sie Ihr neues Passwort in das Feld **Passwort** ein.
4. Geben Sie es erneut in das Feld **Passwort bestätigen** ein.
5. Klicken Sie auf **Änderungen speichern**.

:::info
Ihr Passwort muss mindestens 8 Zeichen lang sein. Stellen Sie sicher, dass das Passwort und die Bestätigungsfelder exakt übereinstimmen. Sie müssen Ihr aktuelles Passwort bestätigen, um es zu ändern – wenn Sie es nicht kennen, verwenden Sie stattdessen den Link **Passwort vergessen** auf der Anmeldeseite.
:::

## Verknüpfte Konten

Der Abschnitt **Verknüpfte Konten** zeigt alle externen Dienste an, die mit Ihrem ChurchApps-Konto verbunden sind. Sie können sehen, welche Konten verknüpft sind, und diese Verbindungen in diesem Abschnitt verwalten.

## Design-Einstellungen

ChurchApps unterstützt sowohl helle als auch dunkle Anzeigemodi:

1. Finden Sie den Schalter **Design** auf Ihrer Seite Profil.
2. Wechseln Sie zwischen **Hell** und **Dunkel** Modus.
3. Die Benutzeroberfläche wird sofort aktualisiert, um Ihre Wahl widerzuspiegeln.

Ihre Design-Voreinstellung wird in Ihrem Konto gespeichert und gilt für alle Ihre Sitzungen.

## Kontolöschung

Am unteren Ende der Seite Profil finden Sie die Option zum permanenten Löschen Ihres Kontos. Diese Aktion entfernt Ihr Konto und zugehörige Daten und kann nicht rückgängig gemacht werden.

:::warning
Die Kontolöschung ist dauerhaft und kann nicht rückgängig gemacht werden. Stellen Sie sicher, dass Sie Ihr Konto wirklich entfernen möchten, bevor Sie fortfahren.
:::

:::info
Wenn Sie ein **Domain-Administrator** sind, stellen Sie sicher, dass Sie die administrativen Verantwortungen auf einen anderen Benutzer übertragen, bevor Sie Ihr Konto löschen. Weitere Informationen zum Verwalten von Admin-Rollen finden Sie unter [Rollen & Berechtigungen](../settings/roles-permissions.md).
:::

:::info
Die Profilbearbeitung ist im Demo-Modus deaktiviert. Wenn Sie ein Demo-Konto verwenden, können Sie keine Änderungen an den Profileinstellungen vornehmen.
:::
