# Mein Profil verwalten

<div class="article-intro">

Auf der Profilseite können Sie Ihre persönlichen Kontoeinstellungen bearbeiten. Ihr Profil wird über alle ChurchApps-Produkte hinweg geteilt, daher gelten Änderungen, die Sie hier vornehmen, überall, wo Sie ChurchApps nutzen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen bei Ihrem ChurchApps-Konto angemeldet sein
- Halten Sie Ihre neue E-Mail-Adresse oder Ihr neues Passwort bereit, falls Sie diese ändern möchten

</div>

## Profilangaben

Die Profilseite zeigt links Ihren Namen und Ihre E-Mail-Adresse, darunter eine Schaltfläche **Bearbeiten**. Klicken Sie auf **Bearbeiten**, um das Formular **Konto bearbeiten** zu öffnen, das Ihre grundlegenden Kontodaten enthält:

1. **E-Mail** -- Ihre E-Mail-Adresse für die Anmeldung und den Empfang von Benachrichtigungen.
2. **Vorname** und **Nachname** -- Ihr Anzeigename in ChurchApps.
3. **Passwort** -- Aktualisieren Sie Ihr Kontopasswort.

Um Ihre Angaben zu ändern, bearbeiten Sie die Felder und klicken Sie auf die Schaltfläche **Änderungen speichern**. Klicken Sie auf **Abbrechen** (oder auf den Link **Zurück zu** mit Ihrem Namen), um zu Ihrem Profil zurückzukehren, ohne zu speichern.

## Passwort ändern

1. Klicken Sie auf der Profilseite auf **Bearbeiten**.
2. Geben Sie Ihr **aktuelles Passwort** ein.
3. Geben Sie Ihr neues Passwort im Feld **Neues Passwort** ein.
4. Wiederholen Sie es im Feld **Passwort bestätigen**.
5. Klicken Sie auf **Änderungen speichern**.

:::info
Ihr Passwort muss mindestens 8 Zeichen lang sein. Achten Sie darauf, dass Passwort und Bestätigung genau übereinstimmen. Um das Passwort zu ändern, müssen Sie Ihr aktuelles Passwort bestätigen -- wenn Sie es nicht kennen, verwenden Sie stattdessen den Link **Passwort vergessen** auf der Anmeldeseite.
:::

## Verknüpfte Konten

Der Bereich **Verknüpfte Konten** zeigt alle externen Dienste, die mit Ihrem ChurchApps-Konto verbunden sind. Sie können hier sehen, welche Konten verknüpft sind, und diese Verbindungen verwalten.

## Designeinstellungen

B1 Admin ermöglicht es Ihnen, ein Farbdesign und einen hellen oder dunklen Anzeigemodus zu wählen:

1. Klicken Sie oben rechts in B1 Admin auf Ihr Profilbild, um Ihr Benutzermenü zu öffnen.
2. Wählen Sie unter **Designeinstellungen** ein Design:
   - **Standard** -- Das aktuelle Erscheinungsbild von B1 Admin: Panels mit Rahmen auf einer klaren Fläche. Neue Benutzer sehen zunächst dieses Design, bis sie ein anderes wählen.
   - **Klassisch** -- Das frühere Erscheinungsbild von B1 Admin mit einem farbigen Seitenbanner, Karten mit Schatten und einem grauen Hintergrund. Wenn Sie B1 Admin auf diesem Gerät schon vor dem neuen Erscheinungsbild genutzt und nie ein Design gewählt haben, bleiben Sie beim Klassischen Design.
   - **Benutzerdefiniert** -- Das Standard-Erscheinungsbild, angepasst an die Farbe Ihrer Kirche. Es verwendet die Primärfarbe des hellen Modus unter **Mobil > App-Design** oder die Primärfarbe Ihrer Website, falls keine App-Farbe festgelegt ist, sodass B1 Admin zu Ihrer Mitglieder-App passt.
3. Wählen Sie unterhalb der Designs **Heller Modus** oder **Dunkler Modus**.
4. Die Oberfläche aktualisiert sich sofort entsprechend Ihrer Auswahl.

Ihre Auswahl wird auf diesem Gerät und in diesem Browser gespeichert.

## Konto löschen

Im Bereich **Kontolöschung** der Profilseite finden Sie die Option, Ihr Konto zu löschen.

- Wenn Ihre Kirche **keine** Gruppe zur Freigabe von Verzeichnissen eingerichtet hat, entfernt ein Klick auf **Mein Konto löschen** Ihr Konto und die zugehörigen Daten sofort, und dies lässt sich nicht rückgängig machen.
- Wenn Ihre Kirche eine Gruppe zur **Freigabe von Verzeichnissen** eingerichtet hat, wird Ihre Anfrage stattdessen zur Prüfung an diese Gruppe geschickt. Die Schaltfläche ist deaktiviert, solange die Anfrage aussteht, und Sie werden benachrichtigt, sobald Ihre Kirche sie genehmigt oder abgelehnt hat. Was danach passiert, erfahren Sie unter [Anfragen zur Kontolöschung prüfen](./account-deletion.md).

:::warning
Die Kontolöschung -- ob sofort oder nach Genehmigung durch Ihre Kirche -- ist endgültig und kann nicht rückgängig gemacht werden.
:::

:::info
Wenn Sie ein **Domain-Admin** sind, übertragen Sie die Verwaltungsaufgaben unbedingt an einen anderen Benutzer, bevor Sie Ihr Konto löschen. Einzelheiten zur Verwaltung von Administratorrollen finden Sie unter [Rollen & Berechtigungen](../settings/roles-permissions.md).
:::

:::info
Die Bearbeitung des Profils ist im Demomodus deaktiviert. Wenn Sie ein Demokonto verwenden, können Sie Ihre Profileinstellungen nicht ändern.
:::
