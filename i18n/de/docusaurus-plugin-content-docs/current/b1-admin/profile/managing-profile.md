# Ihr Profil verwalten

<div class="article-intro">

Auf der Seite "Profil" können Sie Ihre persönlichen Kontoeinstellungen bearbeiten. Ihr Profil wird auf alle ChurchApps-Produkte übertragen, daher werden alle Änderungen, die Sie hier vornehmen, überall dort widergespiegelt, wo Sie ChurchApps verwenden.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen in Ihrem ChurchApps-Konto angemeldet sein
- Halten Sie Ihre neue E-Mail-Adresse oder Ihr Passwort bereit, falls Sie diese aktualisieren möchten

</div>

## Profilinformationen

Der obere Teil der Profilseite enthält Ihre grundlegenden Kontodetails:

1. **E-Mail** -- Ihre E-Mail-Adresse, die zum Anmelden und Empfangen von Benachrichtigungen verwendet wird.
2. **Vorname** und **Nachname** -- Ihr Anzeigename in ChurchApps.
3. **Passwort** -- Aktualisieren Sie Ihr Kontopasswort.

Um Ihre Informationen zu aktualisieren, bearbeiten Sie die Felder und klicken Sie auf die Schaltfläche **Änderungen speichern**.

## Passwort ändern

1. Scrollen Sie auf der Profilseite zu den Passwortfeldern.
2. Geben Sie Ihr **aktuelles Passwort** ein.
3. Geben Sie Ihr neues Passwort in das Feld **Passwort** ein.
4. Geben Sie es erneut in das Feld **Passwort bestätigen** ein.
5. Klicken Sie auf **Änderungen speichern**.

:::info
Ihr Passwort muss mindestens 8 Zeichen lang sein. Stellen Sie sicher, dass das Passwort und die Bestätigungsfelder genau übereinstimmen. Sie müssen Ihr aktuelles Passwort bestätigen, um es zu ändern -- wenn Sie es nicht kennen, verwenden Sie stattdessen den Link **Passwort vergessen** auf der Anmeldeseite.
:::

## Verknüpfte Konten

Der Abschnitt **Verknüpfte Konten** zeigt alle externen Dienste, die mit Ihrem ChurchApps-Konto verbunden sind. Sie können von diesem Abschnitt aus sehen, welche Konten verknüpft sind, und diese Verbindungen verwalten.

## Themavorlieben

ChurchApps unterstützt sowohl den hellen als auch den dunklen Anzeigemodus:

1. Suchen Sie den Umschalter **Thema** auf Ihrer Profilseite.
2. Wechseln Sie zwischen **Hell** und **Dunkel** Modus.
3. Die Benutzeroberfläche wird sofort aktualisiert, um Ihre Wahl widerzuspiegeln.

Ihre Themavorliebe wird in Ihrem Konto gespeichert und gilt für alle Ihre Sitzungen.

## Kontolöschung

Am unteren Rand der Profilseite finden Sie die Option, Ihr Konto dauerhaft zu löschen. Diese Aktion entfernt Ihr Konto und zugehörige Daten und kann nicht rückgängig gemacht werden.

:::warning
Die Kontolöschung ist dauerhaft und kann nicht rückgängig gemacht werden. Stellen Sie sicher, dass Sie Ihr Konto wirklich löschen möchten, bevor Sie fortfahren.
:::

:::info
Wenn Sie ein **Domänenadministrator** sind, stellen Sie sicher, dass Sie die administrativen Aufgaben auf einen anderen Benutzer übertragen, bevor Sie Ihr Konto löschen. Siehe [Rollen & Berechtigungen](../settings/roles-permissions.md) für Details zur Verwaltung von Administratorrollen.
:::

:::info
Die Profilbearbeitung ist im Demo-Modus deaktiviert. Wenn Sie ein Demo-Konto verwenden, können Sie keine Änderungen an Ihren Profileinstellungen vornehmen.
:::
