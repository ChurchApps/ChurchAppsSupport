# Ihr Profil verwalten

<div class="article-intro">

Auf der Profilseite bearbeiten Sie Ihre persönlichen Kontoeinstellungen. Ihr Profil wird über alle ChurchApps-Produkte hinweg geteilt. Änderungen, die Sie hier vornehmen, gelten daher überall, wo Sie ChurchApps verwenden.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen in Ihrem ChurchApps-Konto angemeldet sein.
- Halten Sie Ihre neue E-Mail-Adresse oder Ihr neues Passwort bereit, falls Sie diese ändern möchten.

</div>

## Profilinformationen

Die Profilseite zeigt links Ihren Namen und Ihre E-Mail-Adresse, darunter befindet sich eine Schaltfläche **Bearbeiten**. Klicken Sie auf **Bearbeiten**, um das Formular **Konto bearbeiten** zu öffnen, das Ihre grundlegenden Kontodaten enthält:

1. **E-Mail** – Ihre E-Mail-Adresse, die Sie zur Anmeldung und für Benachrichtigungen verwenden.
2. **Vorname** und **Nachname** – Ihr Anzeigename in ChurchApps.
3. **Passwort** – Aktualisieren Sie Ihr Kontopasswort.

Um Ihre Angaben zu ändern, bearbeiten Sie die Felder und klicken Sie auf **Änderungen speichern**. Klicken Sie auf **Abbrechen** (oder auf den Link **Zurück zu** mit Ihrem Namen), um ohne Speichern zu Ihrem Profil zurückzukehren.

## Passwort ändern

1. Klicken Sie auf der Profilseite auf **Bearbeiten**.
2. Geben Sie Ihr **aktuelles Passwort** ein.
3. Geben Sie Ihr neues Passwort im Feld **Neues Passwort** ein.
4. Wiederholen Sie es im Feld **Passwort bestätigen**.
5. Klicken Sie auf **Änderungen speichern**.

:::info
Ihr Passwort muss mindestens 8 Zeichen lang sein. Achten Sie darauf, dass Passwort und Bestätigung genau übereinstimmen. Zum Ändern müssen Sie Ihr aktuelles Passwort bestätigen. Wenn Sie es nicht kennen, verwenden Sie stattdessen den Link **Passwort vergessen** auf der Anmeldeseite.
:::

## Verknüpfte Konten

Der Bereich **Verknüpfte Konten** zeigt alle externen Dienste, die mit Ihrem ChurchApps-Konto verbunden sind. Hier sehen Sie, welche Konten verknüpft sind, und können diese Verbindungen verwalten.

## Designeinstellungen

In B1 Admin können Sie ein Farbdesign sowie den hellen oder dunklen Anzeigemodus wählen:

1. Klicken Sie oben rechts in B1 Admin auf Ihr Profilbild, um Ihr Benutzermenü zu öffnen.
2. Wählen Sie unter **Designeinstellungen** ein Design:
   - **Standard** – Das aktuelle Erscheinungsbild von B1 Admin: Panels mit Rahmen auf einer klaren Fläche. Neue Benutzer sehen dieses Design, bis sie ein anderes wählen.
   - **Klassisch** – Das frühere Erscheinungsbild von B1 Admin mit farbigem Seitenbanner, Karten mit Schatten und grauem Hintergrund. Wenn Sie B1 Admin auf diesem Gerät bereits vor der neuen Ansicht genutzt und nie ein Design gewählt haben, bleiben Sie bei Klassisch.
   - **Benutzerdefiniert** – Das Standard-Erscheinungsbild, das mit der Farbe Ihrer Kirche gestaltet wird. Es verwendet die Primärfarbe für den hellen Modus aus **Mobile > App-Design** oder, falls keine App-Farbe festgelegt ist, die Primärfarbe Ihrer Website. So passt sich B1 Admin an Ihre Mitglieder-App an.
3. Wählen Sie unter den Designs **Heller Modus** oder **Dunkler Modus**.
4. Die Oberfläche aktualisiert sich sofort entsprechend Ihrer Auswahl.

Ihre Auswahl wird auf diesem Gerät und in diesem Browser gespeichert.

## Konto löschen

Im Bereich **Konto löschen** der Profilseite finden Sie die Option, Ihr Konto zu löschen.

- Wenn Ihre Kirche **keine** Gruppe für die Genehmigung von Verzeichniseinträgen eingerichtet hat, entfernt ein Klick auf **Mein Konto löschen** Ihr Konto und die zugehörigen Daten sofort. Dies kann nicht rückgängig gemacht werden.
- Wenn Ihre Kirche **eine** Gruppe für die Genehmigung von Verzeichniseinträgen eingerichtet hat, wird Ihre Anfrage stattdessen zur Prüfung an diese Gruppe gesendet. Die Schaltfläche ist deaktiviert, solange die Anfrage aussteht. Sie werden benachrichtigt, sobald Ihre Kirche sie genehmigt oder abgelehnt hat. Was danach passiert, erfahren Sie unter [Löschanfragen für Konten prüfen](./account-deletion.md).

:::warning
Die Löschung eines Kontos – ob sofort oder nach Genehmigung durch Ihre Kirche – ist endgültig und kann nicht rückgängig gemacht werden.
:::

:::info
Wenn Sie **Domain-Administrator** sind, übertragen Sie die Verwaltungsaufgaben an einen anderen Benutzer, bevor Sie Ihr Konto löschen. Informationen zur Verwaltung von Administratorrollen finden Sie unter [Rollen & Berechtigungen](../settings/roles-permissions.md).
:::

:::info
Die Bearbeitung des Profils ist im Demomodus deaktiviert. Wenn Sie ein Demokonto verwenden, können Sie Ihre Profileinstellungen nicht ändern.
:::
