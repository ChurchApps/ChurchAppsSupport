# Ihr Profil verwalten

<div class="article-intro">

Auf der Profilseite bearbeiten Sie Ihre persönlichen Kontoeinstellungen. Ihr Profil wird von allen ChurchApps-Produkten gemeinsam genutzt, daher gelten Änderungen, die Sie hier vornehmen, überall, wo Sie ChurchApps verwenden.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen in Ihr ChurchApps-Konto angemeldet sein
- Halten Sie Ihre neue E-Mail-Adresse oder Ihr neues Passwort bereit, wenn Sie diese ändern möchten

</div>

## Profilangaben

Die Profilseite zeigt links Ihren Namen und Ihre E-Mail-Adresse, darunter die Schaltfläche **Bearbeiten**. Klicken Sie auf **Bearbeiten**, um das Formular **Konto bearbeiten** zu öffnen, das Ihre grundlegenden Kontodaten enthält:

1. **E-Mail** – Ihre E-Mail-Adresse für die Anmeldung und den Empfang von Benachrichtigungen.
2. **Vorname** und **Nachname** – Ihr Anzeigename in ChurchApps.
3. **Passwort** – Aktualisieren Sie Ihr Kontopasswort.

Um Ihre Angaben zu aktualisieren, bearbeiten Sie die Felder und klicken Sie auf **Änderungen speichern**. Klicken Sie auf **Abbrechen** (oder auf den Link **Zurück zu** mit Ihrem Namen), um ohne Speichern zu Ihrem Profil zurückzukehren.

## Passwort ändern

1. Klicken Sie auf der Profilseite auf **Bearbeiten**.
2. Geben Sie Ihr **aktuelles Passwort** ein.
3. Geben Sie Ihr neues Passwort im Feld **Neues Passwort** ein.
4. Wiederholen Sie es im Feld **Passwort bestätigen**.
5. Klicken Sie auf **Änderungen speichern**.

:::info
Ihr Passwort muss mindestens 8 Zeichen lang sein. Achten Sie darauf, dass Passwort und Bestätigung genau übereinstimmen. Zum Ändern müssen Sie Ihr aktuelles Passwort bestätigen – wenn Sie es nicht kennen, nutzen Sie stattdessen den Link **Passwort vergessen** auf der Anmeldeseite.
:::

## Verknüpfte Konten

Der Bereich **Verknüpfte Konten** zeigt alle externen Dienste, die mit Ihrem ChurchApps-Konto verbunden sind. Sie können hier sehen, welche Konten verknüpft sind, und diese Verbindungen verwalten.

## Zwei-Faktor-Anmeldung {#two-factor-sign-in}

Die Zwei-Faktor-Anmeldung fügt dem Anmeldevorgang einen zweiten Schritt hinzu: Nach Ihrem Passwort (oder nach der Anmeldung über Google, Microsoft oder einen E-Mail-Link) geben Sie zusätzlich einen 6-stelligen Code aus einer Authentifizierungs-App auf Ihrem Telefon ein, etwa Google Authenticator, Microsoft Authenticator, 1Password oder Authy. Sie ist optional und standardmäßig ausgeschaltet. Ist sie eingeschaltet, gilt sie für jede ChurchApps-Anmeldung mit Ihrem Konto – B1 Admin, die B1.church-Seite und App Ihrer Kirche, B1 Church Checkin, Lessons.church, FreePlay und die übrigen.

### Einschalten

1. Suchen Sie auf der Profilseite den Bereich **Zwei-Faktor-Anmeldung** und klicken Sie auf **Einschalten**.
2. Scannen Sie den QR-Code mit Ihrer Authentifizierungs-App. Wenn Sie ihn nicht scannen können, geben Sie den Schlüssel, der unter **Scannen nicht möglich? Diesen Schlüssel eingeben:** angezeigt wird, stattdessen in der App ein.
3. Geben Sie den **6-stelligen Code** ein, den Ihre App anzeigt, und klicken Sie auf **Prüfen**.
4. B1 Admin zeigt zehn **Sicherungscodes**. Jeder meldet Sie einmal an, falls Sie Ihr Telefon verlieren. Klicken Sie auf **Kopieren** oder schreiben Sie sie auf, bewahren Sie sie an einem sicheren Ort auf und klicken Sie auf **Ich habe sie gespeichert**.

:::warning
Die Sicherungscodes werden nur einmal angezeigt. Wenn Sie Ihr Telefon verlieren und keine Sicherungscodes mehr haben, muss ein Serveradministrator von ChurchApps die Zwei-Faktor-Anmeldung nach Prüfung Ihrer Identität für Sie ausschalten.
:::

Ist die Zwei-Faktor-Anmeldung eingeschaltet, zeigt der Bereich **Ein** und die Anzahl der noch verbleibenden Sicherungscodes.

### Mit einem Code anmelden

Nach Eingabe Ihres Passworts fragt die Anmeldeseite nach einem Code. Geben Sie den 6-stelligen Code aus Ihrer Authentifizierungs-App oder einen Ihrer Sicherungscodes ein und senden Sie ihn ab. Jeder Sicherungscode funktioniert nur einmal. Ist der Code falsch, sehen Sie „Dieser Code hat nicht funktioniert. Bitte versuchen Sie es erneut.“ Nach zu vielen falschen Codes werden Anmeldungen für Ihr Konto für eine Weile angehalten.

Wenn Sie auf einem Gerät, auf dem Sie bereits angemeldet waren, angemeldet bleiben, wird nicht erneut nach einem Code gefragt; er wird nur bei einer neuen Anmeldung verlangt.

### Ausschalten

1. Klicken Sie im Bereich **Zwei-Faktor-Anmeldung** auf **Ausschalten**.
2. Geben Sie einen aktuellen Code aus Ihrer Authentifizierungs-App oder einen Sicherungscode ein.
3. Klicken Sie auf **Prüfen**.

:::info
Die Zwei-Faktor-Anmeldung kann für Demokonten nicht eingerichtet werden; der Bereich ist dort daher ausgeblendet.
:::

## Designeinstellungen

B1 Admin ermöglicht es Ihnen, ein Farbdesign sowie den hellen oder dunklen Anzeigemodus zu wählen:

1. Klicken Sie oben rechts in B1 Admin auf Ihr Profilbild, um das Benutzermenü zu öffnen.
2. Wählen Sie unter **Design-Einstellungen** ein Design:
   - **Standard** – Das aktuelle Erscheinungsbild von B1 Admin: umrandete Felder auf einer klaren Fläche. Neue Benutzer sehen dieses Design, bis sie ein anderes wählen.
   - **Klassisch** – Das frühere Erscheinungsbild von B1 Admin mit einem farbigen Seitenbanner, Karten mit Schatten und grauem Hintergrund. Haben Sie B1 Admin auf diesem Gerät vor der neuen Gestaltung genutzt und nie ein Design gewählt, bleiben Sie beim Klassisch-Design.
   - **Benutzerdefiniert** – Das Standard-Erscheinungsbild, das aus der eigenen Farbe Ihrer Kirche aufgebaut wird. Es verwendet die Primärfarbe des hellen Modus aus **Mobil > App-Design** oder, falls keine App-Farbe festgelegt ist, die Primärfarbe Ihrer Website, sodass B1 Admin zur App Ihrer Mitglieder passt.
3. Wählen Sie unterhalb der Designs **Heller Modus** oder **Dunkler Modus**.
4. Die Oberfläche aktualisiert sich sofort entsprechend Ihrer Wahl.

Ihre Auswahl wird auf diesem Gerät und in diesem Browser gespeichert.

## Löschen des Kontos

Im Bereich **Kontolöschung** der Profilseite finden Sie die Option, Ihr Konto zu löschen.

- Hat Ihre Kirche **keine** Freigabegruppe für Verzeichnisse eingerichtet, entfernt ein Klick auf **Mein Konto löschen** Ihr Konto und die zugehörigen Daten sofort; dies lässt sich nicht rückgängig machen.
- Hat Ihre Kirche eine Freigabegruppe für Verzeichnisse eingerichtet, wird Ihre Anfrage stattdessen zur Prüfung an diese Gruppe gesendet. Die Schaltfläche ist deaktiviert, solange die Anfrage offen ist, und Sie werden benachrichtigt, sobald Ihre Kirche sie genehmigt oder abgelehnt hat. Was danach geschieht, erfahren Sie unter [Anfragen zur Kontolöschung prüfen](./account-deletion.md).

:::warning
Die Löschung des Kontos – ob sofort oder nach Genehmigung durch Ihre Kirche – ist endgültig und kann nicht rückgängig gemacht werden.
:::

:::info
Wenn Sie **Domänenadministrator** sind, übertragen Sie die Verwaltungsaufgaben vor dem Löschen Ihres Kontos auf eine andere Person. Details zur Verwaltung von Administratorrollen finden Sie unter [Rollen & Berechtigungen](../settings/roles-permissions.md).
:::

:::info
Die Bearbeitung des Profils ist im Demomodus deaktiviert. Wenn Sie ein Demokonto verwenden, können Sie Ihre Profileinstellungen nicht ändern.
:::
