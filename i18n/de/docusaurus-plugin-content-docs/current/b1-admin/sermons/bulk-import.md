# Massenimport

<div class="article-intro">

Auf der Seite „Massenimport" können Sie schnell Ihre Predigtbibliothek mit Videos von YouTube oder Vimeo füllen. Dies ist der schnellste Weg, um Ihre vorhandenen Predigtinhalte zu importieren, anstatt jedes Video einzeln hinzuzufügen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen die Berechtigung **contentApi.streamingServices.edit**. Weitere Informationen finden Sie unter [Rollen & Berechtigungen](../settings/roles-permissions.md), falls Sie keinen Zugriff haben.
- Erstellen Sie mindestens eine [Playlist](playlists), um Ihre Predigten importieren zu können
- Halten Sie Ihre YouTube-Kanal-ID oder Vimeo-Kontoinformationen bereit

</div>

## Wählen Sie Ihre Quelle

1. In B1 Admin öffnen Sie das [Jump-Menü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links), erweitern **Predigten** und klicken auf **Predigten**. Klicken Sie auf **Predigt hinzufügen** und wählen Sie **Massenimport** aus dem Menü.
2. Sie werden zwei anklickbare Karten sehen:
   - **YouTube** (rot) -- Videos von einem YouTube-Kanal importieren
   - **Vimeo** (blau) -- Videos von einem Vimeo-Konto importieren
3. Klicken Sie auf die Karte für die Plattform, auf der Ihre Predigten gehostet werden.

:::tip
Sie können jederzeit zurückgehen und Quellen wechseln, wenn Sie Videos auf beiden Plattformen haben.
:::

## Bevor Sie importieren

Bevor Sie Videos importieren, benötigen Sie mindestens eine Playlist, um sie zu organisieren. Falls Sie noch keine Playlists erstellt haben:

1. Gehen Sie zurück auf die Seite **Predigten** und finden Sie das Panel **Playlists**.
2. Klicken Sie auf **Erste Playlist erstellen** und füllen Sie Name, Beschreibung, Veröffentlichungsdatum und Thumbnail aus.
3. Klicken Sie auf **Speichern**, kehren Sie dann zu Massenimport zurück, indem Sie auf **Predigt hinzufügen** klicken und **Massenimport** wählen.

Weitere Informationen finden Sie unter [Playlists](playlists) für detaillierte Anweisungen zum Erstellen und Verwalten von Playlists.

## Videos importieren

1. Nach der Auswahl von YouTube oder Vimeo geben Sie Ihre **YouTube-Kanal-ID** oder **Vimeo-Kontoinformationen** in das bereitgestellte Feld ein.
2. Klicken Sie auf die Schaltfläche **Abrufen**, um alle verfügbaren Videos aus Ihrem Kanal oder Konto abzurufen.
3. Nach dem Abrufen wird Ihnen eine Liste aller Ihre Videos mit Kontrollkästchen angezeigt.
4. Aktivieren Sie die Kontrollkästchen neben den Videos, die Sie importieren möchten. Sie können alle auswählen oder spezifische auswählen.
5. Aktivieren Sie optional **Neue Videos automatisch importieren**, um zukünftige Uploads automatisch zu Ihrer Bibliothek hinzuzufügen.
6. Klicken Sie auf das Dropdown-Menü **In Playlist importieren**, um auszuwählen, zu welcher Playlist diese Videos hinzugefügt werden sollen.
7. Klicken Sie auf die Schaltfläche **Importieren**, um den Massenimport abzuschließen.

Ihre Videos werden mit all ihren Details importiert, einschließlich Titeln, Beschreibungen, Daten und Thumbnails.

:::info
Massenimport ist ideal zum Starten, wenn Sie von einer anderen Plattform migrieren. Zum Hinzufügen einzelner Predigten in Zukunft verwenden Sie stattdessen die Seite [Predigten verwalten](managing-sermons).
:::
