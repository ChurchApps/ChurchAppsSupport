# Massenimport

<div class="article-intro">

Auf der Seite Massenimport können Sie Ihre Predigtbibliothek schnell füllen, indem Sie Videos von YouTube oder Vimeo importieren. Das ist der schnellste Weg, Ihre bestehenden Predigtinhalte zu übernehmen, anstatt jedes Video einzeln hinzuzufügen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen die Berechtigung **contentApi.streamingServices.edit**. Siehe [Rollen & Berechtigungen](../settings/roles-permissions.md), wenn Sie keinen Zugriff haben.
- Legen Sie mindestens eine [Playlist](playlists) an, in die Sie Ihre Predigten importieren können
- Halten Sie Ihre YouTube-Kanal-ID bzw. Ihre Vimeo-Kontodaten bereit

</div>

## Ihre Quelle wählen

1. Öffnen Sie in B1 Admin das [Sprungmenü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links), klappen Sie **Predigten** auf und klicken Sie auf **Predigten**. Klicken Sie auf **Predigt hinzufügen** und wählen Sie im Menü **Massenimport**.
2. Unter **Importquelle wählen** stehen Ihnen zwei Optionen zur Verfügung:
   - **YouTube** -- Videos aus einem YouTube-Kanal importieren
   - **Vimeo** -- Videos aus einem Vimeo-Konto importieren
3. Klicken Sie auf die Option der Plattform, auf der Ihre Predigten gehostet werden (oder klicken Sie unter ihrer Beschreibung auf **Von YouTube importieren** bzw. **Von Vimeo importieren**). Klicken Sie oben auf der Seite auf **Zurück**, um zur Auswahl der Quelle zurückzukehren.

:::tip
Sie können jederzeit zurückgehen und die Quelle wechseln, falls Ihre Videos auf beiden Plattformen liegen.
:::

## Vor dem Import

Bevor Sie Videos importieren, benötigen Sie mindestens eine Playlist, in die Sie sie einordnen können. Falls Sie noch keine Playlist angelegt haben:

1. Gehen Sie zurück zur Seite **Predigten** und suchen Sie den Bereich **Playlists**.
2. Klicken Sie auf **Erste Playlist erstellen** und tragen Sie Name, Beschreibung, Veröffentlichungsdatum und Vorschaubild ein.
3. Klicken Sie auf **Speichern** und kehren Sie dann zum Massenimport zurück, indem Sie auf **Predigt hinzufügen** klicken und **Massenimport** wählen.

Ausführliche Anleitungen zum Anlegen und Verwalten von Playlists finden Sie unter [Playlists](playlists).

## Videos importieren

1. Nachdem Sie YouTube oder Vimeo gewählt haben, geben Sie Ihre **YouTube-Kanal-ID** bzw. Ihre **Vimeo-Kontodaten** in das vorgesehene Feld ein.
2. Klicken Sie auf die Schaltfläche **Abrufen**, um alle verfügbaren Videos aus Ihrem Kanal oder Konto zu laden.
3. Danach sehen Sie eine Liste aller Ihrer Videos mit Kontrollkästchen.
4. Markieren Sie die Kästchen neben den Videos, die Sie importieren möchten. Sie können alle auswählen oder einzelne bestimmen.
5. Aktivieren Sie optional **Neue Videos automatisch importieren**, um künftige Uploads automatisch in Ihre Bibliothek aufzunehmen.
6. Klicken Sie auf das Auswahlfeld **In Playlist importieren**, um festzulegen, in welche Playlist diese Videos aufgenommen werden sollen.
7. Klicken Sie auf die Schaltfläche **Importieren**, um den Massenimport abzuschließen.

Ihre Videos werden mit allen Angaben übernommen, einschließlich Titeln, Beschreibungen, Datumsangaben und Vorschaubildern. Sonderzeichen in YouTube-Titeln und -Beschreibungen wie `&`, Apostrophe und Anführungszeichen werden so übernommen, wie sie geschrieben sind, und nicht als Codes wie `&amp;`.

:::info
Der Massenimport eignet sich ideal für den Start, wenn Sie von einer anderen Plattform umziehen. Um künftig einzelne Predigten hinzuzufügen, verwenden Sie stattdessen die Seite [Predigten verwalten](managing-sermons).
:::
