# Massenimport

<div class="article-intro">

Die Seite Massenimport ermöglicht es Ihnen, Ihre Predigtbibliothek schnell zu füllen, indem Sie Videos von YouTube oder Vimeo importieren. Dies ist die schnellste Möglichkeit, Ihren bestehenden Predigtinhalt zu bringen, anstatt jedes Video einzeln hinzuzufügen.

</div>

<div class="prereqs">
<h4>Voraussetzungen</h4>

- Sie benötigen die Berechtigung **contentApi.streamingServices.edit**. Siehe [Rollen & Berechtigungen](../settings/roles-permissions.md), wenn Sie keinen Zugriff haben.
- Erstellen Sie mindestens eine [Wiedergabeliste](playlists), um Ihre Predigten zu importieren
- Halten Sie Ihre YouTube-Kanal-ID oder Vimeo-Kontoinformationen bereit

</div>

## Wählen Sie Ihre Quelle

1. Öffnen Sie in B1 Admin das **Abschnittsmenü** in der oberen linken Ecke (der Abschnittsname mit dem kleinen Pfeil) und wählen Sie **Predigten**. Klicken Sie auf **Predigt hinzufügen** und wählen Sie **Massenimport** aus dem Menü.
2. Sie sehen zwei anklickbare Karten:
   - **YouTube** (rot) -- Importieren Sie Videos von einem YouTube-Kanal
   - **Vimeo** (blau) -- Importieren Sie Videos von einem Vimeo-Konto
3. Klicken Sie auf die Karte für die Plattform, auf der Ihre Predigten gehostet werden.

:::tip
Sie können jederzeit zurückgehen und Quellen wechseln, wenn Sie Videos auf beiden Plattformen haben.
:::

## Vor dem Importieren

Bevor Sie Videos importieren, benötigen Sie mindestens eine Wiedergabeliste, um sie zu organisieren. Wenn Sie noch keine Wiedergabelisten erstellt haben:

1. Gehen Sie zurück zur Seite **Predigten** und suchen Sie das Fenster **Wiedergabelisten**.
2. Klicken Sie auf **Erste Wiedergabeliste erstellen** und füllen Sie Name, Beschreibung, Veröffentlichungsdatum und Miniaturbild aus.
3. Klicken Sie auf **Speichern**, dann gehen Sie zum Massenimport zurück, indem Sie auf **Predigt hinzufügen** klicken und **Massenimport** wählen.

Siehe [Wiedergabelisten](playlists) für detaillierte Anweisungen zum Erstellen und Verwalten von Wiedergabelisten.

## Videos importieren

1. Nachdem Sie YouTube oder Vimeo ausgewählt haben, geben Sie Ihre **YouTube-Kanal-ID** oder **Vimeo-Kontoinformationen** in das bereitgestellte Feld ein.
2. Klicken Sie auf die Schaltfläche **Abrufen**, um alle verfügbaren Videos von Ihrem Kanal oder Konto zu beziehen.
3. Nach dem Abrufen sehen Sie eine Liste aller Ihre Videos mit Kontrollkästchen.
4. Aktivieren Sie die Kontrollkästchen neben den Videos, die Sie importieren möchten. Sie können alle auswählen oder spezifische auswählen.
5. Aktivieren Sie optional **Neue Videos automatisch importieren**, um zukünftige Uploads automatisch Ihrer Bibliothek hinzuzufügen.
6. Klicken Sie auf die Dropdown-Liste **Zu Wiedergabeliste importieren**, um zu wählen, welche Wiedergabeliste diese Videos hinzugefügt werden sollen.
7. Klicken Sie auf die Schaltfläche **Importieren**, um den Massenimport abzuschließen.

Ihre Videos werden mit allen ihren Details importiert, einschließlich Titel, Beschreibungen, Daten und Miniaturbilder.

:::info
Massenimport ist ideal, um zu beginnen, wenn Sie von einer anderen Plattform migrieren. Zum Hinzufügen einzelner Predigten in der Zukunft verwenden Sie stattdessen die Seite [Predigten verwalten](managing-sermons).
:::
