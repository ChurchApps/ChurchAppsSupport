# Massenimport

<div class="article-intro">

Die Seite "Massenimport" ermöglicht es Ihnen, Ihre Predigtbibliothek schnell zu füllen, indem Sie Videos von YouTube oder Vimeo importieren. Dies ist die schnellste Möglichkeit, Ihre vorhandenen Predigteninhalte einzubringen, anstatt jedes Video einzeln hinzuzufügen.

</div>

<div class="prereqs">
<h4>Voraussetzungen</h4>

- Sie benötigen die Berechtigung **contentApi.streamingServices.edit**. Siehe [Rollen & Berechtigungen](../settings/roles-permissions.md), wenn Sie keinen Zugriff haben.
- Erstellen Sie mindestens eine [Wiedergabeliste](playlists), um Ihre Predigten darin zu importieren
- Halten Sie Ihre YouTube-Kanal-ID oder Vimeo-Kontoinformationen bereit

</div>

## Wählen Ihrer Quelle

1. Öffnen Sie in B1 Admin das **Bereichsmenü** in der oberen linken Ecke (der Bereichsname mit dem kleinen Pfeil) und wählen Sie **Predigten**, dann klicken Sie auf die **Massenimport**-Registerkarte.
2. Sie sehen zwei anklickbare Karten:
   - **YouTube** (rot) -- Importieren Sie Videos von einem YouTube-Kanal
   - **Vimeo** (blau) -- Importieren Sie Videos von einem Vimeo-Konto
3. Klicken Sie auf die Karte der Plattform, auf der Ihre Predigten gehostet werden.

:::tip
Sie können jederzeit zurückgehen und Quellen wechseln, wenn Sie Videos auf beiden Plattformen haben.
:::

## Bevor Sie importieren

Bevor Sie Videos importieren, benötigen Sie mindestens eine Wiedergabeliste, um sie zu organisieren. Wenn Sie noch keine Wiedergabelisten erstellt haben:

1. Klicken Sie auf die **Wiedergabelisten**-Registerkarte.
2. Klicken Sie auf **Erste Wiedergabeliste erstellen** und füllen Sie den Namen, die Beschreibung, das Veröffentlichungsdatum und das Miniaturbild aus.
3. Klicken Sie auf **Speichern**, dann kehren Sie zur **Massenimport**-Registerkarte zurück.

Siehe [Wiedergabelisten](playlists) für detaillierte Anweisungen zum Erstellen und Verwalten von Wiedergabelisten.

## Videos importieren

1. Nachdem Sie YouTube oder Vimeo ausgewählt haben, geben Sie Ihre **YouTube-Kanal-ID** oder **Vimeo-Kontoinformationen** in das bereitgestellte Feld ein.
2. Klicken Sie auf die Schaltfläche **Abrufen**, um alle verfügbaren Videos von Ihrem Kanal oder Konto abzurufen.
3. Nach dem Abrufen werden Sie eine Liste aller Ihrer Videos mit Kontrollkästchen sehen.
4. Aktivieren Sie die Kontrollkästchen neben den Videos, die Sie importieren möchten. Sie können alle oder spezifische auswählen.
5. Aktivieren Sie optional **Videos automatisch importieren**, um zukünftige Uploads automatisch zu Ihrer Bibliothek hinzuzufügen.
6. Klicken Sie auf das Dropdown **In Wiedergabeliste importieren**, um zu wählen, in welche Wiedergabeliste diese Videos hinzugefügt werden sollen.
7. Klicken Sie auf die Schaltfläche **Importieren**, um den Massenimport abzuschließen.

Ihre Videos werden mit all ihren Details importiert, einschließlich Titel, Beschreibungen, Daten und Miniaturbildern.

:::info
Massenimport eignet sich ideal für den Anfang bei der Migration von einer anderen Plattform. Zum Hinzufügen einzelner Predigten in Zukunft verwenden Sie stattdessen die [Predigten verwenden](managing-sermons)-Seite.
:::
