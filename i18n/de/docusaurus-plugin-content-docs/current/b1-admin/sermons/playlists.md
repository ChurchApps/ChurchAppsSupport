# Wiedergabelisten

<div class="article-intro">

Wiedergabelisten helfen Ihnen, Ihre Predigten in Reihen oder Sammlungen zu ordnen. Wenn Besucher Ihre Predigtbibliothek auf Ihrer B1.church-Website durchsehen, helfen Wiedergabelisten ihnen, eine vollständige Predigtreihe in der richtigen Reihenfolge zu finden und zu verfolgen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen die Berechtigung **Gottesdienste bearbeiten** im Abschnitt **Inhalt** Ihrer Rolle. Falls Sie keinen Zugriff haben, lesen Sie [Rollen und Berechtigungen](../settings/roles-permissions.md).
- Halten Sie einen Namen, eine Beschreibung und ein Vorschaubild für Ihre Wiedergabeliste bereit

</div>

## Wiedergabelisten anzeigen {#viewing-playlists}

1. Öffnen Sie in B1 Admin das [Sprungmenü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links), klappen Sie **Predigten** auf und klicken Sie auf **Predigten**.
2. Suchen Sie auf der Seite **Predigten** das Feld **Wiedergabelisten** (neben der Predigtliste).
3. Sie sehen eine Liste aller vorhandenen Wiedergabelisten mit ihrem Namen; neben der Überschrift **Wiedergabelisten** steht eine Anzahl. Sobald Sie mehr als fünf haben, erscheint oberhalb der Liste ein Feld **Wiedergabelisten durchsuchen...**.

## Eine Wiedergabeliste erstellen {#creating-a-playlist}

1. Klicken Sie auf die Schaltfläche **Erste Wiedergabeliste erstellen** (wenn Sie noch keine haben) oder auf die Schaltfläche **Wiedergabeliste hinzufügen** im Feld **Wiedergabelisten**. Oberhalb des Felds öffnet sich ein Formular **Neue Wiedergabeliste erstellen**.
2. Geben Sie einen **Titel der Wiedergabeliste** ein – zum Beispiel den Titel einer Predigtreihe wie „Glaubensgrundlagen“ oder „Sommer in den Psalmen“.
3. Fügen Sie eine **Beschreibung** hinzu, um Besuchern einen kurzen Überblick über die Reihe zu geben.
4. Legen Sie ein **Veröffentlichungsdatum** fest, um zu steuern, ab wann die Wiedergabeliste sichtbar ist.
5. Klicken Sie auf **Vorschaubild hinzufügen**, um ein **Vorschaubild** hochzuladen und zuzuschneiden, das die Reihe optisch darstellt (empfohlen: 1280 x 720 Pixel, 16:9).
6. Klicken Sie auf **Speichern**, um Ihre Wiedergabeliste zu erstellen.

## Eine Wiedergabeliste bearbeiten oder löschen {#editing-or-deleting-a-playlist}

Fahren Sie im Feld **Wiedergabelisten** mit der Maus über eine Wiedergabeliste und klicken Sie auf **Bearbeiten**. Ändern Sie beliebige Felder (für ein neues Bild verwenden Sie **Vorschaubild ändern**) und klicken Sie auf **Speichern**. Alternativ klicken Sie auf **Löschen** und bestätigen Sie, um die Wiedergabeliste zu entfernen.

:::tip
Legen Sie Ihre Wiedergabelisten an, bevor Sie Predigten hinzufügen. So können Sie jede Predigt gleich der richtigen Wiedergabeliste zuordnen, statt später umzuordnen.
:::

## Predigten einer Wiedergabeliste hinzufügen {#adding-sermons-to-a-playlist}

Wenn Sie eine [Predigt hinzufügen oder bearbeiten](./managing-sermons.md), ordnen Sie sie über das Dropdown-Menü **Wiedergabeliste** einer Wiedergabeliste zu. Alle Predigten, die derselben Wiedergabeliste zugeordnet sind, werden zusammengefasst und auf Ihrer Website der Reihe nach angezeigt.

:::info
Sie können Predigten während des [Massenimports](./bulk-import.md) auch Wiedergabelisten zuordnen. Wählen Sie beim Import von YouTube oder Vimeo im Dropdown-Menü **In Wiedergabeliste importieren** eine Wiedergabeliste, bevor Sie auf **Importieren** klicken.
:::

## So erscheinen Wiedergabelisten auf Ihrer Website {#how-playlists-appear-on-your-website}

Wiedergabelisten werden auf Ihrer B1.church-Website als durchsuchbare Sammlungen angezeigt. Besucher können:

- Auf einen Blick alle verfügbaren Predigtreihen sehen
- In eine Wiedergabeliste hineinklicken, um alle Predigten dieser Reihe anzusehen
- Predigten der Reihe nach ansehen oder anhören
