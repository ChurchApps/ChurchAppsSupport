# Gespeicherte Listen

<div class="article-intro">

**Gespeicherte Listen** ermöglichen es Ihnen, eine Suchanfrage unter einem Namen zu speichern und sie jederzeit mit einem Klick erneut auszuführen. Erstellen Sie eine Liste einmal -- "Aktive Mitglieder in Campus Nord", "Besucher in den letzten 90 Tagen" oder einen anderen erweiterten Filter -- und sie bleibt im Bereich **Gespeicherte Listen** auf der Seite "Personen", sodass Sie die Abfrage nie wieder neu erstellen müssen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Führen Sie mindestens eine Suche im Abschnitt "Personen" durch, damit Sie Ergebnisse zum Speichern haben. Siehe [Personen durchsuchen](./searching-people.md) oder [KI-Suche](./ai-search.md).

</div>

## Speichern einer Suche als Liste

1. Führen Sie eine Suche auf der Seite **Personen** durch -- eine schnelle Suche, eine KI-Suche oder eine erweiterte Filtersuche.
2. Wenn Ergebnisse angezeigt werden, wird eine Schaltfläche **Als Liste speichern** (Lesezeichensymbol) in der Kopfzeile der Seite "Personen" angezeigt.
3. Klicken Sie auf **Als Liste speichern**.
4. Geben Sie einen **Namen** für die Liste ein (erforderlich).
5. Geben Sie optional eine **Kategorie** ein, um verwandte Listen im Bereich **Gespeicherte Listen** zu gruppieren (z. B. "Outreach" oder "Mitgliedschaft").
6. Klicken Sie auf **Speichern**.

Die Liste wird nun unter dem Konto Ihrer Kirche gespeichert und wird im Bereich **Gespeicherte Listen** auf der linken Seite der Seite "Personen" angezeigt.

:::info
Listen werden auf Ihre Kirche übertragen -- jeder mit Zugriff auf "Personen" kann sie sehen und laden. Nur Mitarbeiter mit der entsprechenden Berechtigung können Listen umbenennen oder löschen.
:::

## Laden einer gespeicherten Liste

Klicken Sie im Bereich **Gespeicherte Listen** auf der linken Seite der Seite "Personen" auf einen Listennamen. Die Suche wird sofort mit der gespeicherten Abfrage erneut ausgeführt und aktualisiert die Ergebnistabelle.

Listen werden nach Kategorie gruppiert (falls Sie eine zugewiesen haben), wobei nicht kategorisierte Listen zuletzt angezeigt werden.

:::tip
Listen sind **Live-Abfragen**, keine Schnappschüsse. Jedes Mal, wenn Sie eine Liste laden, wird die Suche von Grund auf anhand Ihrer aktuellen Daten ausgeführt, sodass neue Personen, die die Kriterien erfüllen, angezeigt werden.
:::

## Umbenennen und Löschen von Listen

Mitarbeiter mit Verwaltungsberechtigung können Listen direkt aus dem Bereich "Gespeicherte Listen" umbenennen oder löschen.

- Klicken Sie auf das **Stiftsymbol** neben einem Listennamen, um ihn umzubenennen.
- Klicken Sie auf das **Papierkorbsymbol**, um es zu löschen (Sie werden aufgefordert, den Vorgang zu bestätigen).

## Anwendungsfälle

| Szenario | So erstellen Sie die Liste |
|---|---|
| Alle Besucher | Erweiterte Suche: Mitgliedschaftsstatus = Besucher |
| Mitglieder in einem bestimmten Standort | Erweiterte Suche: Standort = [Ihr Standort] |
| Personen ohne E-Mail-Adresse | Erweiterte Suche: E-Mail ist leer |
| Freiwillige mit abgelaufenem Hintergrundcheck | Erweiterte Suche: [Benutzerdefiniertes Feld](../settings/custom-fields.md) "Hintergrundcheck verfällt" vor heute |
| Ergebnisse aus einer KI-Frage | Stellen Sie eine Frage in der KI-Suche und speichern Sie sie |
