# Geburtstags- und Jubiläumslisten

<div class="article-intro">

Sie brauchen eine Liste aller Personen mit Geburtstag oder Jubiläum in einem bestimmten Monat – für den Gemeindebrief, die Ankündigungen oder die Karten? Die Personensuche kann Ihre Gemeinde nach **Geburtsmonat** und **Jubiläumsmonat** filtern und die Daten direkt in den Ergebnissen anzeigen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Stellen Sie sicher, dass Geburtstage (und Jubiläen) im Profil jeder Person eingetragen sind. Siehe [Personen hinzufügen](../people/adding-people.md).
- Sie benötigen die Berechtigung, Personen anzuzeigen. Siehe [Rollen und Berechtigungen](../settings/roles-permissions.md).

</div>

## Eine Geburtstagsliste für einen Monat erstellen {#getting-a-birthday-list-for-a-month}

1. Öffnen Sie das [Sprungmenü](../introduction.md#getting-around-with-the-jump-menu) (die Suchleiste oben links in B1 Admin), klappen Sie **Personen** auf und klicken Sie auf **Personen**.
2. Klicken Sie unter dem Suchfeld auf **Erweitert**.
3. Klappen Sie den Abschnitt **Demografie** auf, aktivieren Sie **Geburtsmonat** und wählen Sie den Monat.
4. Die Ergebnisse werden sofort aktualisiert, sobald der Filter aktiviert ist – alle Personen mit Geburtstag in diesem Monat erscheinen.
5. Um die Daten zu sehen, stellen Sie **Anzeigen als** auf **Tabelle** um, klicken Sie dann im Seitenkopf auf das Symbol **Spalten auswählen** und aktivieren Sie die Spalte **Geburtsdatum** (oder **Geburtstag (ohne Jahr)**, um das Jahr wegzulassen). Mit **Exportieren** laden Sie die Liste als Tabelle herunter, wenn Sie sie dort lieber sortieren oder drucken möchten.

## Eine Jubiläumsliste erstellen {#getting-an-anniversary-list}

Die Schritte sind dieselben: Aktivieren Sie im Abschnitt **Demografie** stattdessen (oder zusätzlich) **Jubiläumsmonat**, wählen Sie den Monat und aktivieren Sie in den Ergebnissen die Spalte **Jubiläum**.

## Praktische Anwendungen {#practical-uses}

- **Wöchentlicher Gemeindebrief** -- Führen Sie die Liste des aktuellen Monats aus und übernehmen Sie die Namen direkt in den Gemeindebrief.
- **Geburtstags- und Jubiläumskarten** -- Exportieren Sie die Liste des Monats und geben Sie sie Ihrem Team, das die Karten schreibt.
- **Meilensteine** -- Kombinieren Sie den Filter **Alter**, um runde Geburtstage zu finden.

:::tip
Beide Listen stammen aus den Feldern Geburtsdatum und Jubiläum im Profil jeder Person. Fehlt jemand, muss im Profil nur das Datum ergänzt werden.
:::

:::info
Frühere Versionen von B1 Admin verlinkten im Menü einen gesonderten Bericht Geburtstage. Dieser Link wurde entfernt – die oben beschriebenen Filter der Personensuche sind der aktuelle Weg, und sie umfassen auch Jubiläen.
:::
