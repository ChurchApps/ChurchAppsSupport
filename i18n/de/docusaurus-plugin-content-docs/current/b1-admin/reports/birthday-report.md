# Geburtstags- und Jahrestaglisten

<div class="article-intro">

Benötigen Sie eine Liste von Personen mit Geburtstag oder Jahrestag in einem bestimmten Monat – für das Gemeindeblatt, Ankündigungen oder Karten? Mit der Personensuche können Sie Ihre Gemeinde nach **Geburtsmonat** und **Jahrestag-Monat** filtern und die Daten direkt in den Ergebnissen anzeigen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Stellen Sie sicher, dass Geburtsdaten (und Jahrestage) auf dem Profil jeder Person eingetragen sind. Siehe [Personen hinzufügen](../people/adding-people.md).
- Sie benötigen die Berechtigung zum Anzeigen von Personen. Siehe [Rollen & Berechtigungen](../settings/roles-permissions.md).

</div>

## Abrufen einer Geburtstagsliste für einen Monat

1. Öffnen Sie das **Abschnittsmenü** in der oberen linken Ecke und wählen Sie **Personen**.
2. Klicken Sie unter dem Suchfeld auf **Erweitert**.
3. Erweitern Sie den Abschnitt **Demografie** und aktivieren Sie **Geburtsmonat**, wählen Sie dann den Monat aus.
4. Führen Sie die Suche aus – alle Personen mit einem Geburtstag in diesem Monat werden in den Ergebnissen angezeigt.
5. Um die Daten anzuzeigen, klicken Sie auf das **Spaltensymbol** oben rechts in den Ergebnissen und aktivieren Sie die Spalte **Geburtstag**. Verwenden Sie **Exportieren**, um die Liste als Tabelle herunterzuladen, wenn Sie sie lieber dort sortieren oder drucken möchten.

## Abrufen einer Jahrestagliste

Gleiche Schritte – Im Abschnitt **Demografie** aktivieren Sie stattdessen **Jahrestag-Monat** (oder auch), wählen Sie den Monat aus und aktivieren Sie die Spalte **Jahrestag** in den Ergebnissen.

## Praktische Verwendungen

- **Wöchentliche Gemeindebriefe** – Führen Sie die Liste des aktuellen Monats aus und lesen Sie die Namen direkt ins Gemeindeblatt.
- **Geburtstags- und Jahrestagskartennen** – Exportieren Sie die Liste des Monats und geben Sie sie Ihrem Kartenschreib-Team.
- **Meilensteine** – Kombinieren Sie mit dem Filter **Alter**, um Meilenstein-Geburtstage zu finden.

:::tip
Beide Listen stammen aus den Feldern Geburtsdatum und Jahrestag auf dem Profil jeder Person – wenn jemand fehlt, muss sein Profil einfach das Datum hinzugefügt haben.
:::

:::info
Frühere Versionen von B1 Admin hatten eine separate Seite für Geburtstagberichte. Diese Seite wurde eingestellt – die oben genannten Personensuche-Filter sind die aktuelle Methode und decken auch Jahrestage ab.
:::
