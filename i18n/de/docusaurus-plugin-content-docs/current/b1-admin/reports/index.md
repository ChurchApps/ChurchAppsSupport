# Berichte

<div class="article-intro">

B1 Admin bietet mehrere Wege, Daten über Ihre Gemeinde, Anwesenheit und Spenden abzurufen. Die Berichte sind in die jeweiligen Bereiche der App eingebaut, statt auf einer einzigen Seite Berichte zu bündeln.

</div>

## Wo Sie Berichte finden

### Personen
- **[Geburtstags- & Jubiläumslisten](./birthday-report.md)** -- Filtern Sie nach Geburtsmonat oder Jubiläumsmonat unter **Personen → Erweiterte Suche**, um eine Liste der kommenden Geburtstage oder Jubiläen zu erhalten.

### Anwesenheit
- **[Anwesenheitsberichte](./attendance-reports.md)** -- Anwesenheitstrends und Anwesenheitsdaten von Gruppen finden Sie im Bereich **Anwesenheit**.

### Spenden
- **[Spendenübersicht](./donation-summary.md)** -- Spendensummen und Aufschlüsselungen nach Fonds finden Sie im Bereich **Spenden**.

### Einstellungen
- **[Änderungsprotokoll](./audit-log.md)** -- Verfolgen Sie alle Änderungen und Aktionen in Ihrem Gemeindeverwaltungssystem (zu finden unter **Einstellungen → Änderungsprotokoll**).

:::info
Die Aussagekraft der Berichte hängt von einer konsequenten Datenerfassung ab. Damit die Ergebnisse möglichst genau sind, sorgen Sie dafür, dass Ihr Team die [Anwesenheit erfasst](../attendance/tracking-attendance.md), [Spenden erfasst](../donations/recording-donations.md) und die [Personendatensätze](../people/adding-people.md) aktuell hält.
:::
