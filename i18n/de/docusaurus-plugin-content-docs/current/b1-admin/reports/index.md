# Berichte

<div class="article-intro">

B1 Admin bietet mehrere Möglichkeiten, Daten zu Ihrer Gemeinde, zur Anwesenheit und zu Spenden abzurufen. Die Berichte sind in die jeweiligen Bereiche der App eingebaut, statt auf einer einzigen Berichtsseite zu liegen.

## Wo Sie Berichte finden {#where-to-find-reports}

### Personen {#people}
- **[Geburtstags- und Jubiläumslisten](./birthday-report.md)** -- Filtern Sie unter **Personen → Erweiterte Suche** nach Geburtsmonat oder Jubiläumsmonat, um eine Liste anstehender Geburtstage oder Jubiläen zu erhalten.

### Anwesenheit {#attendance}
- **[Anwesenheitsberichte](./attendance-reports.md)** -- Anwesenheitstrends und Daten zur Gruppenanwesenheit finden Sie im Bereich **Anwesenheit**.

### Spenden {#donations}
- **[Spendenübersicht](./donation-summary.md)** -- Spendensummen und Aufschlüsselungen nach Fonds finden Sie im Bereich **Spenden**.

### Einstellungen {#settings}
- **[Änderungsprotokoll](./audit-log.md)** -- Erfassen Sie alle Änderungen und Aktionen in Ihrem Gemeindeverwaltungssystem (zu finden unter **Einstellungen → Änderungsprotokoll**).

:::info
Die Aussagekraft der Berichte hängt von einer durchgehend sorgfältigen Datenerfassung ab. Achten Sie darauf, dass Ihr Team die [Anwesenheit erfasst](../attendance/tracking-attendance.md), [Spenden einträgt](../donations/recording-donations.md) und die [Personendatensätze](../people/adding-people.md) aktuell hält, damit die Ergebnisse möglichst genau sind.
:::
