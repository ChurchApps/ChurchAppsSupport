# Jahrestags-Liste

<div class="article-intro">

Benötigen Sie eine Liste aller, die einen Hochzeitstag in einem bestimmten Monat haben — für das Bulletin, Karten oder Ankündigungen? Mit der Personensuche können Sie nach **Anniversary Month** filtern und die Daten direkt in den Ergebnissen anzeigen.

</div>

<div class="prereqs">
<h4>Vor dem Start</h4>

- Stellen Sie sicher, dass Jahrestage in den Profilen jeder Person eingegeben werden. Siehe [Adding People](../people/adding-people.md) für Details.
- Sie benötigen die Berechtigung zum Anzeigen von Personen. Siehe [Roles & Permissions](../settings/roles-permissions.md).

</div>

## Abrufen einer Jahrestagsliste für einen Monat

1. Öffnen Sie das **section menu** in der oberen linken Ecke und wählen Sie **People**.
2. Klicken Sie unter dem Suchfeld auf **Advanced**.
3. Erweitern Sie den Abschnitt **Demographics** und aktivieren Sie **Anniversary Month**, wählen Sie dann den Monat.
4. Führen Sie die Suche aus — jeder mit einem Jahrestag in diesem Monat erscheint in den Ergebnissen.
5. Um die Daten anzuzeigen, klicken Sie auf das **columns icon** oben rechts in den Ergebnissen und aktivieren Sie die Spalte **Anniversary**. Verwenden Sie **Export**, um die Liste als Tabelle herunterzuladen, wenn Sie sie lieber sortieren oder drucken möchten.

## Praktische Anwendungen

- **Weekly bulletins** — Führen Sie die Liste des aktuellen Monats aus und beziehen Sie Jahrestage in Ihr Bulletin oder Ihre Ankündigungen ein.
- **Anniversary cards** — Exportieren Sie die Monats-Liste und übergeben Sie sie Ihrem Kartenschreib-Team.
- **Milestone celebrations** — Kombinieren Sie mit dem Filter **Years Married**, um Jahrestags-Meilensteine zu finden.

:::tip
Führen Sie dies zu Beginn eines jeden Monats durch, damit Sie Zeit haben, Karten oder Ankündigungen vorzubereiten, bevor die Jahrestage ankommen.
:::

:::info
Jahrestagsdaten stammen aus dem Jahrestagsfeld im Profil jeder Person. Wenn jemand fehlt, muss in seinem Profil nur das Datum hinzugefügt werden. Siehe [Adding People](../people/adding-people.md).
:::
