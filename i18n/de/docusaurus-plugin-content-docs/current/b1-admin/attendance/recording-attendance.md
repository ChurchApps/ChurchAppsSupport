# Anwesenheit erfassen

<div class="article-intro">

Sobald Ihre Standorte, Gottesdienstzeiten und Gruppen eingerichtet sind, können Sie die Anwesenheit nach jedem Treffen manuell erfassen. B1 Admin organisiert die Anwesenheit über **Sitzungen** -- eine Sitzung pro Gruppe und Treffendatum. Sie erstellen die Sitzung, markieren, wer anwesend war, und die Daten fließen direkt in Ihre Anwesenheitsberichte ein.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Ihre Standorte, Gottesdienstzeiten und Gruppen müssen konfiguriert sein. Siehe [Anwesenheitseinrichtung](setup.md), falls Sie dies noch nicht erledigt haben.
- Für die Gruppen, die Sie erfassen möchten, muss **Anwesenheit erfassen** aktiviert sein. Einzelheiten finden Sie unter [Anwesenheitseinrichtung](setup.md).

</div>

## Eine Sitzung erstellen

Eine Sitzung steht für ein einzelnes Treffen einer Gruppe -- zum Beispiel Ihre Klasse für die Jahrgangsstufen K bis 3 an einem bestimmten Sonntag.

1. Öffnen Sie **B1 Admin**, öffnen Sie das **Bereichsmenü** in der oberen linken Ecke und wählen Sie **Personen**, klicken Sie dann auf den Reiter **Gruppen**.
2. Wählen Sie die Gruppe aus, für die Sie die Anwesenheit erfassen möchten.
3. Klicken Sie auf den Reiter **Sitzungen**.
4. Klicken Sie auf **Neu**, um eine neue Sitzung zu erstellen.
5. Wenn die Gruppe einer Gottesdienstzeit zugeordnet ist, wählen Sie die **Gottesdienstzeit**. Bei einer Gruppe ohne festen Termin wird dieses Feld nicht angezeigt.
6. Wählen Sie das **Sitzungsdatum** -- dies kann der heutige Tag, ein vergangenes Datum oder ein zukünftiges Datum sein.
7. Klicken Sie auf **Speichern**.

:::tip
Sie können Sitzungen für vergangene Daten erstellen, um noch nicht erfasste Anwesenheiten nachzutragen, oder sie im Voraus anlegen, damit sie bereit sind, wenn Ihre Gruppe zusammenkommt.
:::

## Anwesenheit markieren

Nach dem Speichern der Sitzung erscheinen die Mitglieder der Gruppe auf der rechten Seite der Seite.

1. Setzen Sie ein Häkchen neben jeder Person, die anwesend war.
2. Änderungen werden automatisch gespeichert -- für die Anwesenheitsmarkierungen gibt es keine zusätzliche Schaltfläche zum Speichern.

:::info
In der Sitzungsliste erscheinen nur aktuelle Gruppenmitglieder. Wenn jemand anwesend war, aber noch nicht in der Gruppe ist, [fügen Sie die Person zunächst der Gruppe hinzu](../groups/group-members.md) und erfassen Sie dann ihre Anwesenheit.
:::

## Anwesenheit in eine Tabelle exportieren

Sie können eine Aufzeichnung der Sitzung als CSV-Datei herunterladen, um sie in Excel, Numbers oder Google Sheets zu verwenden.

1. Öffnen Sie die Sitzung, die Sie exportieren möchten.
2. Klicken Sie auf die Schaltfläche **CSV herunterladen**.
3. Öffnen Sie die heruntergeladene Datei in Ihrer Tabellenkalkulation.

## Erfasste Anwesenheit anzeigen

Nachdem Sitzungen erfasst wurden, erscheinen die Daten in Ihren Anwesenheitsberichten.

- **Reiter Anwesenheit** -- zeigt gemeindeweite Entwicklungen im Zeitverlauf. Siehe [Anwesenheit verfolgen](tracking-attendance.md).
- **Reiter Gruppen** -- zeigt die Anwesenheit aufgeschlüsselt nach einzelnen Gruppen.

:::tip
Wenn eine soeben erstellte Sitzung nicht sofort in den Berichten erscheint, stellen Sie sicher, dass das Sitzungsdatum innerhalb des in den Berichtsfiltern ausgewählten Zeitraums liegt.
:::
