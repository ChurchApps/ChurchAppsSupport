# Kircheneinstellungen

<div class="article-intro">

Auf der Seite "Kircheneinstellungen" konfigurieren Sie die grundlegenden Informationen, Kontaktdetails und das Branding Ihrer Kirche. Diese Details werden in allen ChurchApps-Tools verwendet.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen die Berechtigung "Kircheneinstellungen bearbeiten". Siehe [Rollen & Berechtigungen](./roles-permissions.md).
- Halten Sie die Adresse, Kontaktinformationen und das Logo Ihrer Kirche bereit

</div>

## Bearbeiten Ihrer Kircheninformationen

1. Öffnen Sie in B1 Admin das **Abschnittsmenü** in der oberen linken Ecke und wählen Sie **Einstellungen**.
2. Klicken Sie auf die Schaltfläche **Einstellungen bearbeiten** in der Kopfzeile.
3. Aktualisieren Sie beliebige Felder für Kirchenname, Adresse und Kontaktinformationen.
4. Klicken Sie auf **Speichern**, um Ihre Änderungen zu übernehmen.

## Einrichten Ihrer Subdomain

Ihre Kirche bekommt eine kostenlose Subdomain unter **yourchurch.b1.church**.

1. Geben Sie auf der Seite "Einstellungen" Ihre bevorzugte Subdomain ein.
2. Speichern Sie Ihre Änderungen.

:::info
Ihre Subdomain muss über alle ChurchApps-Kirchen eindeutig sein.
:::

## Konfigurieren von Branding

Passen Sie an, wie Ihre Kirche in allen ChurchApps-Tools angezeigt wird.

1. Laden Sie Ihr **Kirchenlogo** hoch.
2. Fügen Sie beliebige zusätzliche **Kirchenbilder** hinzu, die auf Ihrer Website verwendet werden.
