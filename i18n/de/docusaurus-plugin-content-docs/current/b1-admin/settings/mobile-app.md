# Mobile-App-Einstellungen

<div class="article-intro">

Die Seite „Mobile-App-Einstellungen" ermöglicht es Ihnen, die Navigationstabs zu konfigurieren, die in der **B1.church Mobile Experience (PWA)** für Ihre Gemeindeglieder angezeigt werden. Sie können steuern, welche Tabs sichtbar sind, worauf sie verlinken und wie sie angezeigt werden.

</div>

:::info Die native B1 Mobile App ist veraltet
Die hier konfigurierten Tabs werden über die [B1.church Progressive Web App (PWA)](/docs/b1-church/getting-started/installing-pwa) bereitgestellt, die die native B1 Mobile App ersetzt hat. Teilen Sie die Installationsseite Ihrer Gemeinde — `https://yourchurchname.b1.church/mobile/install` — mit den Gemeindegliedern; diese führt sie durch die Installation der App auf ihrem Gerät, ohne dass ein App Store oder Google Play erforderlich ist.
:::

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen die Berechtigung „Kircheneinstellungen bearbeiten". Siehe [Rollen & Berechtigungen](./roles-permissions.md), falls Sie keinen Zugriff haben.
- Konfigurieren Sie zunächst Ihre [Kircheneinstellungen](./church-settings.md), einschließlich Ihres Kirchennamens und Ihrer Branding-Elemente

</div>

## Zugriff auf Mobile-App-Einstellungen

1. Navigieren Sie auf der linken Seitenleiste zur Seite **Einstellungen**.
2. Klicken Sie auf die Schaltfläche **Mobile Apps** in der Kopfzeile.
3. Die Seite „Mobile-App-Einstellungen" wird mit Ihren aktuellen App-Tabs angezeigt.

## Einen neuen Tab hinzufügen

1. Klicken Sie auf die Schaltfläche **Tab hinzufügen** oben auf der Seite.
2. Füllen Sie die Tab-Details aus:
   - **Name** -- Die Beschriftung, die auf dem Tab angezeigt wird (z. B. „Predigten" oder „Geben").
   - **Symbol** -- Klicken Sie auf die Symbolauswahl, um ein Symbol für Ihren Tab auszuwählen. Sie können auch ein benutzerdefiniertes Bild hochladen.
   - **Tab-Typ** -- Wählen Sie aus Optionen wie Bibel, Live-Stream, Spende, Website und mehr.
   - **URL** -- Geben Sie die Webadresse ein, auf die der Tab verlinken soll.
   - **Sichtbarkeit** -- Kontrollieren Sie, wer diesen Tab sehen kann (alle, nur Mitglieder usw.).
3. Klicken Sie auf **Tab speichern**, um ihn zu Ihrer App hinzuzufügen.

## Einen vorhandenen Tab bearbeiten

1. Klicken Sie auf einen beliebigen Tab in der Liste **App-Tabs**.
2. Aktualisieren Sie den Namen, das Symbol, die URL, den Typ oder die Sichtbarkeitseinstellungen des Tabs.
3. Klicken Sie auf **Tab speichern**, um Ihre Änderungen anzuwenden.

## Tabs neu ordnen

Sie können die Reihenfolge ändern, in der Tabs in der Mobile App angezeigt werden. Ziehen Sie die Tabs in der Liste per Drag & Drop, um sie neu zu ordnen. Die auf dieser Seite angezeigte Reihenfolge entspricht der Reihenfolge, die Ihre Gläubigen in der App sehen.

:::info
Einige Tabs können automatisch angezeigt werden, wenn bestimmte Bedingungen erfüllt sind -- zum Beispiel kann ein Live-Stream-Tab angezeigt werden, wenn ein Stream aktiv ist. Manuell hinzugefügte Tabs geben Ihnen jederzeit die volle Kontrolle darüber, was Ihre Gläubigen sehen.
:::

:::tip
Halten Sie die Anzahl Ihrer Tabs überschaubar. Drei bis fünf Tabs funktionieren gut für die meisten Gemeinden. Zu viele Tabs können die Navigation für Ihre Gläubigen verwirrend machen.
:::

## Wo diese Tabs angezeigt werden

Die Tabs, die Sie hier konfigurieren, werden in der **B1.church PWA** angezeigt, die Ihre Gläubigen von jeder Seite auf `https://yourchurchname.b1.church` installieren. Änderungen auf dieser Seite werden bei der nächsten Öffnung der App durch ein Gemeindeglied angezeigt. (Tabs werden auch von der veralteten [B1 Mobile native App](/docs/b1-mobile/) für alle Gläubigen gerendert, die sie noch ausführen, aber diese App ist veraltet und wird nicht mehr aktualisiert.)
