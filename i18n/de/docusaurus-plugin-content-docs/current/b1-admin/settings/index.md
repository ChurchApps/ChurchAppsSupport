# Einstellungen

<div class="article-intro">

Der Abschnitt "Einstellungen" ist der Ort, an dem Sie das Konto, das Branding und die Verwaltungsoptionen Ihrer Kirche in B1 Admin konfigurieren.

</div>

## Was Sie hier finden

Der Bereich "Einstellungen" ist in die folgenden Unterabschnitte organisiert:

1. **Einstellungen** -- Konfigurieren Sie die grundlegenden Informationen Ihrer Kirche, das Branding und die Subdomain. Siehe [Kircheneinstellungen](./church-settings.md).
2. **Standorte** -- Fügen Sie mehrere physische Standorte für Ihre Kirche hinzu und verwalten Sie sie.
3. **Benutzerdefinierte Felder** -- Definieren Sie Ihre eigenen Felder zum Nachverfolgen von Personen.
4. **Mobile Apps** -- Richten Sie die Navigationregisterkarten ein, die in der B1.church PWA angezeigt werden.
5. **Rollen & Berechtigungen** -- Verwalten Sie Benutzerrollen und Zugriffskontrolle.
