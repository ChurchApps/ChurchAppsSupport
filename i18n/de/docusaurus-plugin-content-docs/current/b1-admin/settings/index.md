# Einstellungen

<div class="article-intro">

Der Bereich Einstellungen ist der Ort, an dem Sie das Konto, das Branding und die administrativen Optionen Ihrer Kirche in B1 Admin konfigurieren. Von hier aus können Sie alles vom Kirchennamen und der Subdomain bis zu den Benutzerberechtigungen und der Konfiguration der mobilen App verwalten.

</div>

## Was Sie hier finden

Der Einstellungsbereich ist in die folgenden untergeordneten Abschnitte unterteilt, auf die Sie von der Seitenleiste aus zugreifen können:

1. **Einstellungen** – Konfigurieren Sie die grundlegenden Informationen, das Branding und die Subdomain Ihrer Kirche. Siehe [Kircheneinstellungen](./church-settings.md) für Details.
2. **Standorte** – Hinzufügen und Verwalten Sie mehrerer physischer Orte für Ihre Kirche. Sobald erstellt, werden Standorte auf Personenprofilen, in der Anwesenheitseinrichtung und im Dashboard Demografien angezeigt. Siehe [Standorte](./campuses.md) für Details.
3. **Benutzerdefinierte Felder** – Definieren Sie Ihre eigenen Felder zur Verfolgung von Personen (Datum, Zahl, Ja/Nein-Antwort oder Auswahlliste), und füllen Sie sie auf Profilen aus und suchen Sie danach. Siehe [Benutzerdefinierte Felder](./custom-fields.md) für Details.
3. **Mobile Apps** – Richten Sie die Navigations-Registerkarten ein, die in der [B1.church PWA](/docs/b1-church/getting-started/installing-pwa) für Ihre Mitglieder angezeigt werden, und passen Sie sie an (dieselben Registerkarten werden auch von der veralteten B1 Mobile native App gerendert). Siehe [Mobile App Einstellungen](./mobile-app.md) für Details.
4. **E-Mail-Vorlagen** – Speichern Sie wiederverwendbare E-Mail-Inhalte zum manuellen Senden oder aus einem Arbeitsablauf. Siehe [E-Mail-Vorlagen](./email-templates.md) für Details.
5. **Server Admin** – Zugriff auf erweiterte Verwaltungstools zur Verwaltung der Einstellungen Ihres Kirchenservers auf Serverebene.
6. **Formulare** – Erstellen und verwalten Sie benutzerdefinierte Formulare zur Erfassung von Informationen Ihrer Gemeinde.

## Die Hauptseite Einstellungen

Wenn Sie die Seite Einstellungen zuerst öffnen, sehen Sie Ihren **Kirchennamen** und Ihre **Subdomain** oben angezeigt. Der Header bietet Schaltflächen für schnellen Zugriff auf häufige Aufgaben:

- **Einstellungen bearbeiten** – Aktualisieren Sie den Namen, die Adresse, die Kontaktinformationen und das Branding Ihrer Kirche.
- **Mobile Apps** – Gehen Sie direkt zur Konfiguration der mobilen App.
- **Rollen** – Verwalten Sie Benutzerrollen und Berechtigungen für Ihr Team.
- **Importieren/Exportieren** – Übertragen Sie Daten zwischen Systemen mit dem Import/Export Tool.

:::tip
Beginnen Sie mit der Konfiguration Ihres Kirchennamens und Brandings unter **Einstellungen bearbeiten**, dann richten Sie [Rollen](./roles-permissions.md) ein, um Ihre Teammitglieder mit der richtigen Zugriffsstufe einzuladen.
:::

:::info
Informationen zum Schutz Ihrer Daten finden Sie unter [Datensicherheit](./data-security.md).
:::
