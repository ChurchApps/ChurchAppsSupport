# Planvorlagen

<div class="article-intro">

Planvorlagen speichern eine wiederverwendbare Momentaufnahme der Gottesdienstordnung oder der Positionen eines Plans und wenden sie mit einem Klick auf künftige Pläne an. Statt jede Woche dieselbe Struktur neu aufzubauen, speichern Sie sie einmal und übernehmen sie auf so viele kommende Pläne, wie Sie benötigen.

</div>

## Einen Plan als Vorlage speichern {#saving-a-plan-as-a-template}

1. Öffnen Sie einen vorhandenen Plan im Bereich **Dienste**.
2. Klicken Sie auf **Gottesdienstordnung bearbeiten**, um die Gottesdienstordnung des Plans zu öffnen, und klicken Sie dann darüber auf **Als Vorlage speichern**.
3. Geben Sie der Vorlage einen Namen (zum Beispiel „Standard-Sonntag“ oder „Anbetung + Predigt“). Der Name beginnt mit dem Namen des Plans.
4. Klicken Sie auf **Speichern**. Die Vorlage erfasst die Gottesdienstordnung, die Positionen und die Notizen des Plans in diesem Moment.

## Vorlagen verwalten {#managing-templates}

Klicken Sie auf jeder Seite einer Planart oberhalb der Planliste auf **Vorlagen**, um **Planvorlagen** zu öffnen. Jede Vorlage hat diese Symbole:

- **Bearbeiten** (Stift) -- Vorlage umbenennen
- **Aus Plan aktualisieren** (Kreispfeile) -- Inhalt der Vorlage durch den aktuellen Stand eines Plans ersetzen (nützlich, wenn Sie Ihre Standardstruktur verfeinert haben)
- **Anwenden** (Kopiersymbol) -- Vorlage auf einen oder mehrere kommende Pläne übernehmen
- **Löschen** (Papierkorb) -- Eine nicht mehr benötigte Vorlage entfernen

## Eine Vorlage auf Pläne anwenden {#applying-a-template-to-plans}

1. Klicken Sie auf der Seite der Planart oberhalb der Planliste auf **Vorlagen**.
2. Klicken Sie neben der gewünschten Vorlage auf das Symbol **Anwenden** (Kopiersymbol).
3. Wählen Sie durch Ankreuzen die kommenden Pläne aus, auf die sie angewendet werden soll. Pläne mit einem Datum vor heute werden nicht angezeigt.
4. Wählen Sie, was kopiert werden soll:
   - **Gottesdienstordnung** -- ersetzt die Punkte der Gottesdienstordnung der ausgewählten Pläne durch die Punkte der Vorlage
   - **Positionen** -- ersetzt die Positionen der ausgewählten Pläne (samt deren Zuweisungen) durch die Positionen der Vorlage
5. Klicken Sie auf **Anwenden**. **Gottesdienstordnung** ist standardmäßig aktiviert; mindestens eine der beiden Optionen muss ausgewählt sein.

Enthält die Vorlage Notizen, ersetzt das Anwenden außerdem die Notizen der ausgewählten Pläne durch die Notizen der Vorlage.

:::warning
Das Anwenden von Positionen ersetzt alle bestehenden Positionen und Zuweisungen der ausgewählten Pläne. Stellen Sie sicher, dass Sie für diese Positionen noch keine Freiwilligen eingeplant haben, bevor Sie anwenden.
:::

:::tip
Wenden Sie die Gottesdienstordnung ohne Positionen an, wenn Sie einen gleichbleibenden Ablauf aus Liedern und Predigt wünschen, die Freiwilligen aber jede Woche anders eingeteilt sind.
:::

## Einen neuen Plan aus einer Vorlage starten {#starting-a-new-plan-from-a-template}

Vorlagen werden über die Planarten eines Dienstbereichs hinweg geteilt. Klicken Sie auf **Neuer Plan**, enthält das Formular für neue Pläne – sofern der Dienstbereich Vorlagen hat – eine Liste **Aus Vorlage starten**. Wählen Sie eine Vorlage und speichern Sie. Der neue Plan wird dann mit der Gottesdienstordnung, den Positionen und den Notizen der Vorlage erstellt. Wenn Sie eine Vorlage wählen, ersetzt das die Optionen **Aus vorherigem Plan kopieren** für diesen Plan.

## Vorlagen aktuell halten {#keeping-templates-up-to-date}

Ändert sich Ihre Standard-Gottesdienststruktur, öffnen Sie die Vorlagenverwaltung, klicken Sie auf **Aus Plan aktualisieren**, wählen Sie den Plan, aus dem kopiert werden soll, und klicken Sie auf **Speichern**. So synchronisieren Sie die Vorlage mit Ihrem neuesten Plan, statt sie von Grund auf neu zu erstellen. Die Liste bietet alle Pläne dieser Planart an, vergangene und kommende.
