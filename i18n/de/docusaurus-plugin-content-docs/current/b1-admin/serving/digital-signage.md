# Digitale Beschilderung

<div class="article-intro">

Sende deinen Unterrichtsinhalt mithilfe eines Digital-Signage-Feeds an einen Lobby- oder Flur-Fernseher. Jeder Plan-Typ erhält eine Feed-URL, die immer den aktuellen Planinhalt wiedergiert, so dass es nichts zu aktualisieren gibt.

</div>

<div class="prereqs">
<h4>Bevor du beginnst</h4>

- Richte einen [Plan-Typ](./plans.md) mit [Lessons.church](../../b1-church/content/lessons.md) oder anderem Unterrichtsinhalt ein
- Habe ein [SignPresenter](https://www.signpresenter.com)-Konto und ein Gerät eingerichtet, um es anzuzeigen

</div>

## Bekomme die Feed-URL

1. Navigiere zu **Serving** und öffne das Ministerium, das deinen Plan-Typ enthält.
2. Klicke auf die Schaltfläche **Digitale Beschilderung** (das RSS-Symbol) auf der Plan-Typ-Seite.
3. Kopiere die im Dialogfeld angezeigte Feed-URL.

:::info
Die Feed-URL ist an den Plan-Typ gebunden, nicht an einen einzelnen Plan. Es verfolgt automatisch, welcher Plan als aktuell für diesen Plan-Typ geplant ist, so dass du ihn nur einmal einrichten musst.
:::

## Verbindung mit SignPresenter

Der Feed ist so gebaut, dass er mit [SignPresenter](https://www.signpresenter.com), einer Digital-Signage-App eines Drittanbieters, funktioniert. Füge die kopierte URL in SignPresenter als externen Feed ein, um deinen aktuellen Unterrichtsinhalt auf einem angeschlossenen Bildschirm anzuzeigen.

Für eine Schritt-für-Schritt-Einrichtung in SignPresenter siehe [SignPresenter's Lessons.church Leitfaden](https://support.signpresenter.com/topics/lessons-dot-church.html).

## Nächste Schritte

- Verwalte die Pläne, die diese Beschilderungsanzeige auf der Seite [Pläne](./plans.md) speisen
- Plane Inhalt mit [Lessons.church](./scheduling-lessons.md)
