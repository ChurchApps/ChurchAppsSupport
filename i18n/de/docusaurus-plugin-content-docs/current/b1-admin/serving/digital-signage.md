# Digitale Beschilderung

<div class="article-intro">

Senden Sie Ihre Lektionsinhalte über einen Feed für digitale Beschilderung auf einen Fernseher in der Lobby oder im Flur. Jeder Plantyp erhält eine Feed-URL, die immer die Inhalte des aktuellen Plans abspielt, sodass Sie nichts Woche für Woche aktualisieren müssen. Wenn Ihre Fernseher FreePlay verwenden, können Sie den Plantyp stattdessen in FreePlay Admin auf ihnen planen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Richten Sie einen [Plantyp](./plans.md) mit [Lessons.church](../../b1-church/content/lessons.md) oder anderen Lektionsinhalten ein, die geplant sind.
- Sie benötigen ein Konto bei [SignPresenter](https://www.signpresenter.com) und ein Gerät, auf dem es angezeigt wird, oder einen Fernseher mit [FreePlay](../../freeplay/).

</div>

## Die Feed-URL abrufen

1. Gehen Sie zu **Dienste**, wählen Sie den Dienstbereich mit Ihrem Plantyp aus und klicken Sie auf den Plantyp, um ihn zu öffnen.
2. Klicken Sie oben auf der Seite des Plantyps auf **Digitale Beschilderung** (das Fernsehsymbol).
3. Klicken Sie im Dialog **Feed für digitale Beschilderung** neben **Feed-URL** auf die Schaltfläche zum Kopieren.

:::info
Die Feed-URL ist an den Plantyp gebunden, nicht an einen einzelnen Plan. Sie folgt automatisch dem Plan, der für diesen Plantyp als aktuell geplant ist. Sie müssen sie also nur einmal einrichten.
:::

## Verbindung mit SignPresenter

Der Feed ist für die Zusammenarbeit mit [SignPresenter](https://www.signpresenter.com) ausgelegt, einer Drittanbieter-App für digitale Beschilderung. Fügen Sie die kopierte URL in SignPresenter als externen Feed ein, um Ihre aktuellen Lektionsinhalte auf einem angeschlossenen Bildschirm anzuzeigen.

Eine Schritt-für-Schritt-Anleitung zur Einrichtung in SignPresenter finden Sie in [SignPresenters Anleitung zu Lessons.church](https://support.signpresenter.com/topics/lessons-dot-church.html). Auch der Dialog verlinkt auf diese Anleitung.

## Stattdessen FreePlay-Fernseher verwenden

Wenn Ihre Bildschirme [FreePlay](../../freeplay/) verwenden, benötigen Sie die Feed-URL nicht. Der Dialog **Feed für digitale Beschilderung** verlinkt auf **admin.freeplay.church/calendar**. Dort können Sie diesen Plantyp auf Ihren FreePlay-Fernsehern planen:

1. Klicken Sie im Dialog auf den Link **admin.freeplay.church/calendar**. FreePlay Admin verwendet dieselbe Anmeldung wie B1 Admin.
2. Wählen Sie die Bildschirmgruppe für Ihre Fernseher aus und klicken Sie auf **Zeitplan hinzufügen**.
3. Wählen Sie unter **Abspielen** Ihren Plantyp aus **Gottesdienstpläne** aus. Er ist mit **(aktueller Plan)** markiert.
4. Legen Sie die Tage und Uhrzeiten fest und klicken Sie auf **Speichern**.

Die Fernseher spielen jede Woche zu den von Ihnen festgelegten Zeiten den jeweils aktuellen Plan dieses Plantyps ab. Das funktioniert auch mit Go-Curriculum-Lektionen, einschließlich angepasster Pläne. FreePlay meldet sich mit dem Go-Curriculum-Konto an, das dem Dienstbereich unter **Inhaltsanbieter** zugeordnet ist (siehe [Lektionen planen](./scheduling-lessons.md)). Hat der Dienstbereich keines, wird die Go-Curriculum-Verbindung der Kirche verwendet. Alle Optionen finden Sie unter [Kalender planen](../../freeplay/scheduled-mode/scheduling-the-calendar), und um einen Fernseher hinzuzufügen, lesen Sie [Einen Bildschirm koppeln](../../freeplay/scheduled-mode/pairing-a-screen).

:::note
Die Feed-URL enthält keine Medien von Go Curriculum, da diese Inhalte eine Anmeldung bei Go Curriculum für Ihre Kirche benötigen. Um eine Go-Curriculum-Lektion auf einem Fernseher in der Lobby oder im Klassenzimmer zu zeigen, verwenden Sie FreePlay.
:::

## Nächste Schritte

- Verwalten Sie die Pläne, die diese digitale Beschilderung speisen, auf der Seite [Pläne](./plans.md).
- Planen Sie Inhalte mit [Lessons.church](./scheduling-lessons.md).
- Richten Sie FreePlay-Fernseher mit dem [geplanten Modus](../../freeplay/scheduled-mode/) nach einem Kalender ein.
