# Digital Signage

<div class="article-intro">

Senden Sie Ihre Lektionsinhalte über einen Digital-Signage-Feed auf einen Fernseher in Foyer oder Flur. Jeder Plantyp erhält eine Feed-URL, die immer den Inhalt des aktuellen Plans abspielt, sodass Sie diese Woche für Woche nicht aktualisieren müssen. Wenn Ihre Fernseher FreePlay ausführen, können Sie den Plantyp stattdessen in FreePlay Admin auf ihnen planen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Richten Sie einen [Plantyp](./plans.md) mit [Lessons.church](../../b1-church/content/lessons.md) oder anderen Lektionsinhalten mit Terminplanung ein
- Sie benötigen ein [SignPresenter](https://www.signpresenter.com)-Konto und ein eingerichtetes Gerät, das es anzeigt, oder einen Fernseher mit [FreePlay](../../freeplay/)

</div>

## Die Feed-URL abrufen

1. Gehen Sie zu **Dienste**, wählen Sie den Dienstbereich mit Ihrem Plantyp und klicken Sie auf den Plantyp, um ihn zu öffnen.
2. Klicken Sie oben auf der Seite des Plantyps auf **Digital Signage** (das Fernseh-Symbol).
3. Klicken Sie im Dialog **Digital-Signage-Feed** auf die Kopierschaltfläche neben **Feed-URL**.

:::info
Die Feed-URL gehört zum Plantyp, nicht zu einem einzelnen Plan. Sie verfolgt automatisch, welcher Plan für diesen Plantyp gerade als aktuell eingeplant ist, daher müssen Sie sie nur einmal einrichten.
:::

## Mit SignPresenter verbinden

Der Feed ist für die Zusammenarbeit mit [SignPresenter](https://www.signpresenter.com) ausgelegt, einer Digital-Signage-App eines Drittanbieters. Fügen Sie die kopierte URL in SignPresenter als externen Feed ein, um Ihre aktuellen Lektionsinhalte auf einem verbundenen Bildschirm anzuzeigen.

Eine schrittweise Anleitung zur Einrichtung in SignPresenter finden Sie im [Lessons.church-Leitfaden von SignPresenter](https://support.signpresenter.com/topics/lessons-dot-church.html). Auch der Dialog verlinkt auf diese Anleitung.

## Stattdessen FreePlay-Fernseher verwenden

Wenn Ihre Bildschirme [FreePlay](../../freeplay/) ausführen, brauchen Sie die Feed-URL nicht. Der Dialog **Digital-Signage-Feed** verlinkt auf **admin.freeplay.church/calendar**, wo Sie diesen Plantyp auf Ihren FreePlay-Fernsehern planen können:

1. Klicken Sie im Dialog auf den Link **admin.freeplay.church/calendar**. FreePlay Admin verwendet dieselbe Anmeldung wie B1 Admin.
2. Wählen Sie die Bildschirmgruppe für Ihre Fernseher und klicken Sie auf **Zeitplan hinzufügen**.
3. Wählen Sie unter **Wiedergabe** Ihren Plantyp aus **Gottesdienstpläne**. Er ist mit **(aktueller Plan)** markiert.
4. Legen Sie die Tage und Uhrzeiten fest und klicken Sie auf **Speichern**.

Die Fernseher spielen jede Woche zu den von Ihnen festgelegten Zeiten den jeweils aktuellen Plan für diesen Plantyp ab. Alle Optionen finden Sie unter [Den Kalender planen](../../freeplay/scheduled-mode/scheduling-the-calendar), und unter [Einen Bildschirm koppeln](../../freeplay/scheduled-mode/pairing-a-screen) erfahren Sie, wie Sie einen Fernseher hinzufügen.

## Nächste Schritte

- Verwalten Sie die Pläne, die diese Digital-Signage-Anzeige speist, auf der Seite [Pläne](./plans.md)
- Planen Sie Inhalte mit [Lessons.church](./scheduling-lessons.md)
- Setzen Sie FreePlay-Fernseher mit dem [Geplanten Modus](../../freeplay/scheduled-mode/) auf einen Kalender
