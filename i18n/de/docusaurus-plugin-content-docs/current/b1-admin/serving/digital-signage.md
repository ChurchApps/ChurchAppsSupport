# Digitale Beschilderung

<div class="article-intro">

Senden Sie Ihren Lehrinbalt an einen Lobby- oder Flur-Fernseher mit einem Digital-Signage-Feed. Jeder Plantyp erhält eine Feed-URL, die den aktuellen Lehrinbalt des Plans immer abspielt.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Richten Sie einen [Plantyp](./plans.md) mit [Lessons.church](../content/lessons.md) oder anderen geplanten Lehren ein
- Haben Sie ein [SignPresenter](https://www.signpresenter.com) Konto und ein Gerät zum Anzeigen

</div>

## Abrufen der Feed-URL

1. Navigieren Sie zu **Dienst** und öffnen Sie das Ministerium, das Ihren Plantyp enthält
2. Klicken Sie auf die Schaltfläche **Digitale Beschilderung** (RSS-Symbol) auf der Seite des Plantyps
3. Kopieren Sie die im Dialog angezeigte Feed-URL

:::info
Die Feed-URL ist an den Plantyp gebunden, nicht an einen einzelnen Plan. Sie verfolgt automatisch, welcher Plan gerade aktuell ist.
:::

## Verbindung mit SignPresenter

Der Feed ist für die Verwendung mit [SignPresenter](https://www.signpresenter.com) vorbereitet. Fügen Sie die kopierte URL als externen Feed in SignPresenter ein.
