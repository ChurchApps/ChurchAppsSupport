# Digitale Beschilderung

<div class="article-intro">

Senden Sie Ihren Unterrichtsinhalte an einen Fernseh- oder Flur-TV mit einem digitalen Beschilderungs-Feed. Jeder Plantyp erhält eine Feed-URL, die immer den Inhalt des aktuellen Plans abspielt, daher gibt es von Woche zu Woche nichts zu aktualisieren.

</div>

<div class="prereqs">
<h4>Vor dem Start</h4>

- Richten Sie einen [Plantyp](./plans.md) mit [Lessons.church](../content/lessons.md) oder anderen Lehrinhalten auf ein, die geplant sind
- Haben Sie ein [SignPresenter](https://www.signpresenter.com) Konto und ein Gerät zum Anzeigen eingerichtet

</div>

## Abrufen der Feed-URL

1. Navigieren Sie zu **Serving** und öffnen Sie das Ministerium, das Ihren Plantyp enthält.
2. Klicken Sie auf die Schaltfläche **Digital Signage** (das RSS-Symbol) auf der Seite Plantyp.
3. Kopieren Sie die im Dialog angezeigte Feed-URL.

:::info
Die Feed-URL ist an den Plantyp gebunden, nicht an einen einzelnen Plan. Sie verfolgt automatisch, welcher Plan als aktuell für diesen Plantyp geplant ist, daher müssen Sie ihn nur einmal einrichten.
:::

## Verbindung mit SignPresenter

Der Feed ist so konzipiert, dass er mit [SignPresenter](https://www.signpresenter.com), einer Drittanbieter-App für digitale Beschilderung, funktioniert. Fügen Sie die kopierte URL als externen Feed in SignPresenter ein, um Ihren aktuellen Unterrichtsinhalt auf einem verbundenen Bildschirm anzuzeigen.

Eine Schritt-für-Schritt-Anleitung in SignPresenter finden Sie im [SignPresenter's Lessons.church guide](https://support.signpresenter.com/topics/lessons-dot-church.html).

## Nächste Schritte

- Verwalten Sie die Pläne, die diese Beschilderungsanzeige auf der Seite [Plans](./plans.md) speisen
- Planen Sie Inhalte mit [Lessons.church](./scheduling-lessons.md)
