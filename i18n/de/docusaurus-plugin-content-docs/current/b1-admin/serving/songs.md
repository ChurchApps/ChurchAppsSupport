# Lieder

<div class="article-intro">

Die Seite Lieder verwaltet Ihre Anbetungsliedsammlung. Halten Sie alle Ihre Lieddetails, Texte und Arrangements an einem Ort, damit Ihr Anbetungsteam leicht für bevorstehende Gottesdienste üben und ein konsistentes Repertoire beibehalten kann.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Wählen Sie im [Sprungmenü](../introduction.md#getting-around-with-the-jump-menu) in B1 Admin **Dienst > Lieder** aus, um auf die Seite Lieder zuzugreifen
- Optional [Servicepläne](./plans.md) einrichten, damit Sie Lieder direkt in die [Service-Reihenfolge](./service-order.md) verlinken können

</div>

## Ihre Liedsammlung durchsuchen

Wenn Sie die Seite **Lieder** öffnen, werden Ihre Lieder als Karten angezeigt. Jede Karte zeigt das Vorschaubild des Liedes, den Titel, den Künstler und die Dauer an. Scrollen Sie durch die Sammlung oder verwenden Sie die Suche, um zu finden, was Sie benötigen.

## Nach Liedern suchen

1. Klicken Sie auf die Schaltfläche **Suchen** auf der Seite Lieder.
2. Geben Sie einen Lied**titel** oder **Künstler**-Namen ein.
3. Die Ergebnisse werden während des Tippens gefiltert und zeigen übereinstimmende Lieder aus Ihrer Sammlung.

## Ein Lied hinzufügen

1. Klicken Sie auf **Lied hinzufügen** auf der Seite Lieder.
2. Durchsuchen Sie die externe Lied-Datenbank nach Titel oder Künstler.
3. Wählen Sie das Lied aus, das Sie hinzufügen möchten.
4. Das Lied wird Ihrer Sammlung mit vorausgefüllten Grunddetails hinzugefügt.

:::tip
Nachdem Sie ein Lied hinzugefügt haben, klicken Sie darauf, um seine Details zu überprüfen und zu aktualisieren, Arrangements hinzuzufügen oder externe Links wie YouTube-Videos oder Akkord-Diagramme anzufügen.
:::

### Kostenlose Lieder von WorshipCommons

Ihre Suchergebnisse können auch einen Abschnitt **WorshipCommons -- kostenlos** neben den regulären Ergebnissen enthalten. Dies sind Sonntagsbereite Lieder von [WorshipCommons](https://worshipcommons.org), die überprüft und lizenziert für Anbetungsnutzung sind. Jedes Ergebnis zeigt ein Lizenz-Badge -- **Kostenlos für Anbetung** oder **Gemeinfrei** -- damit Sie die Bedingungen kennen, bevor Sie es hinzufügen.

- Klicken Sie auf ein WorshipCommons-Ergebnis, um es wie ein reguläres Suchergebnis zu Ihrer Sammlung hinzuzufügen.
- Klicken Sie auf **Auf WorshipCommons anzeigen**, um die ursprüngliche Auflistung in einem neuen Tab zu öffnen.

Nur Lieder, die den Überprüfungsprozess von WorshipCommons bestanden haben, werden hier angezeigt, daher kann die Auswahl kleiner sein als die Haupt-Lied-Datenbank.

## Ein Lied anzeigen und bearbeiten

Klicken Sie auf eine beliebige Liedkarte, um ihre Detailseite zu öffnen. Von hier aus können Sie:

- **Lieddetails bearbeiten** -- Aktualisieren Sie den Titel, den Künstler, die Dauer und andere Metadaten.
- **Arrangements verwalten** -- Jedes Lied kann mehrere Arrangements haben (z. B. verschiedene Tonarten oder Versionen). Fügen Sie Arrangements nach Bedarf hinzu, bearbeiten Sie sie oder entfernen Sie sie.
- **Texte hinzufügen** -- Geben Sie Texte für jedes Arrangement mit ChordPro-Notation ein oder aktualisieren Sie sie (z. B. `[G]Amazing grace`). Eine Live-Vorschau neben dem Editor rendert das formatierte Akkord-Diagramm während des Tippens, sodass Sie genau sehen können, was Ihr Team sehen wird.
- **Tonart festlegen** -- Geben Sie die musikalische Tonart für jedes Arrangement mit der Tonart-Auswahl neben den Texten an. Das Ändern der Tonart transponiert die angezeigten Akkorde sofort, sowohl auf der Arrangement-Seite als auch beim Öffnen des Liedes von einem Serviceplan, sodass Ihr Team Akkorde immer in der Tonart sieht, in der sie tatsächlich spielen.
- **Externe Links hinzufügen** -- Fügen Sie Links zu Ressourcen wie YouTube-Videos, Akkord-Diagramme oder anderswo gehostete Notenblätter ein.

## Arrangements

Ein Arrangement stellt eine unterschiedliche Version eines Liedes dar -- zum Beispiel eine schnellere moderne Version versus eine langsamere akustische Version, oder das gleiche Lied in einer anderen Tonart für ein anderes Team. Jedes Arrangement des gleichen Liedes teilt den Liedtitel und Künstler, hat aber seine eigenen unabhängigen Einstellungen:

- **Tonart** -- die musikalische Tonart, in der das Arrangement gespielt wird
- **BPM** -- Tempo in Schlägen pro Minute
- **Länge** -- Dauer in Sekunden
- **Takt** -- Taktart (z. B. 4/4, 3/4, 6/8)
- **Sequenz** -- die Akkord-/Abschnittsstruktur (z. B. Intro → Vers → Chor → Bridge)
- **Texte** -- für Anzeige oder Projektion
- **Externe Links** -- Akkord-Diagramme, YouTube-Aufzeichnungen, Notenblätter oder andere Ressourcen

Wenn Sie ein Lied zu einer [Service-Reihenfolge](./service-order.md) hinzufügen, können Sie wählen, welches Arrangement für diesen spezifischen Dienst verwendet werden soll, damit Ihr Team immer die richtige Version übt und spielt.

### Probe-Audio

Anbetungs-Admins können eine Probe-Audiospur an ein Arrangement anfügen, damit das Team vor dem Training vorne hören kann:

1. Öffnen Sie das Lied und wählen Sie das Arrangement aus.
2. Klicken Sie auf **Audio hochladen**.
3. Wählen Sie eine MP3-, M4A- oder AAC-Datei (bis zu 25 MB -- WAV wird nicht akzeptiert, um die Speichernutzung überschaubar zu halten).
4. Speichern. Der Track spielt Inline überall dort ab, wo dieses Arrangement angezeigt wird -- auf der Arrangement-Seite in B1 Admin und im Serviceplan, wenn ein Teamkollege ihn im B1.church-Mitglieder-Portal öffnet. Plan-Elemente mit Audio zeigen ein Musik-Noten-Symbol anstelle einer Vorschau an.

Das Löschen des Arrangements entfernt auch seine hochgeladene Audiodatei.

:::info
Lieder aus Ihrer Sammlung können direkt zu einer [Service-Reihenfolge](./service-order.md) innerhalb eines Plans hinzugefügt werden, wobei die Lieddetails und das gewählte Arrangement mit diesem spezifischen Dienst verlinkt werden.
:::

- Koordinieren Sie mit Ihrem Anbetungsteam mit [Aufgaben](./tasks.md) für Lied-Vorbereitung und Probe
