# Lieder

<div class="article-intro">

Die Seite "Lieder" verwaltet Ihre Bibliothek von Lobpreis-Liedern. Halten Sie alle Songdetails, Texte und Arrangements an einem Ort, damit Ihr Lobpreisteam sich leicht auf kommende Gottesdienste vorbereiten und ein konsistentes Repertoire aufrechterhalten kann.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Navigieren Sie zum Bereich **Serving** in B1 Admin, um auf die Seite "Lieder" zuzugreifen
- Optionalerweise haben Sie Ihre [Service-Pläne](./plans.md) eingerichtet, damit Sie Lieder direkt in die [Service-Reihenfolge](./service-order.md) verknüpfen können

</div>

## Durchsuchen Sie Ihre Liederbibliothek

Wenn Sie die Seite **Lieder** öffnen, werden Ihre Lieder als Karten angezeigt. Jede Karte zeigt das Vorschaubild, den Titel, den Künstler und die Dauer des Liedes. Blättern Sie durch die Bibliothek oder verwenden Sie die Suchfunktion, um zu finden, was Sie benötigen.

## Nach Liedern suchen

1. Klicken Sie auf der Seite "Lieder" auf die Schaltfläche **Suchen**.
2. Geben Sie einen Lied- **Titel** oder **Künstlernamen** ein.
3. Die Ergebnisse werden während der Eingabe gefiltert und zeigen die entsprechenden Lieder aus Ihrer Bibliothek.

## Ein Lied hinzufügen

1. Klicken Sie auf der Seite "Lieder" auf **Lied hinzufügen**.
2. Suchen Sie in der externen Lied-Datenbank nach Titel oder Künstler.
3. Wählen Sie das Lied, das Sie hinzufügen möchten.
4. Das Lied wird Ihrer Bibliothek mit seinen Grunddetails hinzugefügt.

:::tip
Nach dem Hinzufügen eines Liedes klicken Sie darauf, um seine Details zu überprüfen und zu aktualisieren, Arrangements hinzuzufügen oder externe Links wie YouTube-Videos oder Akkorddiagramme anzuhängen.
:::

## Anzeigen und Bearbeiten eines Liedes

Klicken Sie auf eine beliebige Liedkarte, um die Detailseite zu öffnen. Von hier aus können Sie:

- **Song-Details bearbeiten** – Aktualisieren Sie Titel, Künstler, Dauer und andere Metadaten.
- **Arrangements verwalten** – Jedes Lied kann mehrere Arrangements haben (z. B. verschiedene Tonarten oder Versionen). Fügen Sie bei Bedarf Arrangements hinzu, bearbeiten Sie sie oder entfernen Sie sie.
- **Lyrics hinzufügen** – Geben Sie die Liedtexte für jedes Arrangement ein oder aktualisieren Sie sie.
- **Die Tonart einstellen** – Geben Sie die musikalische Tonart für jedes Arrangement mit dem Tonart-Picker neben den Lyrics an. Wenn Sie die Tonart ändern, werden die angezeigten Akkorde sofort transponiert, sowohl auf der Arrangement-Seite als auch beim Öffnen des Liedes aus einem Service-Plan, damit Ihr Team immer Akkorde in der Tonart sieht, in der sie tatsächlich spielen.
- **Externe Links hinzufügen** – Hängen Sie Links zu Ressourcen wie YouTube-Videos, Akkorddiagrammen oder Notenblättern an, die an anderer Stelle gehostet werden.

## Arrangements

Ein Arrangement ist eine unterschiedliche Version eines Liedes – zum Beispiel eine schnellere moderne Version gegenüber einer langsameren akustischen Version oder das gleiche Lied in einer anderen Tonart für ein anderes Team. Jedes Arrangement desselben Liedes teilt sich den Liedtitel und den Künstler, hat aber seine eigenen unabhängigen Einstellungen:

- **Tonart** — die musikalische Tonart, in der das Arrangement gespielt wird
- **BPM** — Tempo in Schlägen pro Minute
- **Länge** — Dauer in Sekunden
- **Taktart** — Zeitpunkt (z. B. 4/4, 3/4, 6/8)
- **Abfolge** — die Akkord-/Abschnittstruktur (z. B. Intro → Vers → Refrain → Bridge)
- **Lyrics** — zur Anzeige oder Projektion
- **Externe Links** — Akkorddiagramme, YouTube-Aufnahmen, Notenblätter oder andere Ressourcen

Wenn Sie einen Song zu einer [Service-Reihenfolge](./service-order.md) hinzufügen, können Sie wählen, welches Arrangement für diesen bestimmten Gottesdienst verwendet werden soll, damit Ihr Team immer die richtige Version probt und spielt.

:::info
Lieder aus Ihrer Bibliothek können direkt zu einer [Service-Reihenfolge](./service-order.md) in einem Plan hinzugefügt werden und verknüpfen die Song-Details und das gewählte Arrangement mit diesem bestimmten Gottesdienst.
:::

## Nächste Schritte

- Fügen Sie Lieder zu Ihrer [Service-Reihenfolge](./service-order.md) hinzu, wenn Sie einen [Service-Plan](./plans.md) erstellen
- Koordinieren Sie mit Ihrem Lobpreisteam mit [Aufgaben](./tasks.md) zur Songvorbereitung und zum Üben
