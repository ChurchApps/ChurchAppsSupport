# Lektionen von Lessons.church planen

<div class="article-intro">

B1 Admin integriert sich direkt mit [Lessons.church](https://lessons.church) damit Sie Lehrplan direkt in Ihren Dienstplänen planen können.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Richten Sie Ihre Ministerien im Abschnitt "Dienst" ein
- Haben Sie ein aktives [Lessons.church](https://lessons.church) Konto

</div>

## Schritt 1 — Verbinden Sie Ihr Lessons.church-Konto

Dies ist ein einmaliges Setup pro Ministerium.

1. Melden Sie sich bei [B1 Admin](https://admin.b1.church/) an und gehen Sie zu **Dienst**
2. Öffnen Sie das Ministerium, das Sie verbinden möchten
3. Scrollen Sie nach unten zum Abschnitt **Content Provider Accounts**
4. Klicken Sie auf **Link New Provider**
5. Wählen Sie **Lessons.church** aus der Liste
6. Ein Geräteautorisierungsbildschirm wird mit einem Code angezeigt
7. Gehen Sie zu [lessons.church](https://lessons.church), melden Sie sich an und geben Sie den Code ein

## Schritt 2 — Planen Sie eine Lektion

Einmal verbunden, können Sie Lektionen direkt aus Plänen planen.

1. Gehen Sie zu **Dienst → Pläne**
2. Wählen Sie Ihr Ministerium und klicken Sie auf **Plan hinzufügen**
3. Klicken Sie auf den Plantyp und klicken Sie auf **Lektion planen**
4. Wählen Sie das **Datum** für die Lektion
5. Klicken Sie auf **Lektion auswählen**
6. Wählen Sie das Programm, die Studie und die Lektion
7. Wählen Sie die **Venue** (Altersgruppe)
8. Klicken Sie auf **Lektion zuordnen**
