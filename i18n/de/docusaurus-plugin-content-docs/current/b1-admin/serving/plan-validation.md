# Plan-Validierung und Freiwilligenbenachrichtigungen

<div class="article-intro">

B1 Admin überprüft automatisch Ihre Pläne auf Probleme vor dem Sonntag — ungefüllte Positionen, Zeitplanungskonflikte und Freiwillige, die das Datum blockiert haben. Wenn alles gut aussieht, können Sie Ihr gesamtes Team mit einem einzigen Klick benachrichtigen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Erstellen Sie einen [Serviceplan](./plans.md) und weisen Sie Freiwillige Positionen zu
- Fügen Sie [Servicezeiten](./plans.md) zum Plan hinzu, damit die Konflikterkennung Überlappungen überprüfen kann
- Stellen Sie sicher, dass Freiwillige die B1 Mobile-App installiert haben, um Push-Benachrichtigungen zu erhalten

</div>

## Das Validierungspanel

Jeder Plan hat ein **Validierungs**-Panel, das automatisch ausgeführt wird, während Sie es aufbauen. Es überprüft drei Dinge:

### Ungefüllte Positionen
Wenn eine Position mehr Personen erfordert, als derzeit zugewiesen sind, listet das Validierungspanel genau auf, was noch benötigt wird — zum Beispiel, *"Sound Tech: 1 weitere Person benötigt."* Sie können auf einen Blick sehen, ob Ihr Plan vor der Woche vollständig besetzt ist.

### Zeitplanungskonflikte
Wenn ein Freiwilliger zwei Positionen zugewiesen wird, die zeitlich überlappen, kennzeichnet das Validierungspanel den Konflikt — zum Beispiel, *"Jane Smith: Zeitkonflikt zwischen Anbetungsleiter und Kindercheck-In während Sonntagsgottesdienst."* Dies erfasst Doppelbuchungen, bevor sie zu einem Sonntagmorgenprob lem werden.

### Blockierungsdatum
Freiwillige können Daten festlegen, an denen sie in B1 Mobile nicht verfügbar sind. Wenn jemand einem Plan zugewiesen wird, der innerhalb eines ihrer Blockierungsdatum fällt, zeigt das Validierungspanel den Konflikt automatisch auf, damit Sie einen Ersatz finden können.

### Planübergreifende Konflikte
Die Validierung überprüft auch alle Ihre Pläne auf einmal. Wenn derselbe Freiwilliger in zwei verschiedenen Plänen zugewiesen ist, die zeitlich überlappen — zum Beispiel ein 9-Uhr-Gottesdienst und ein 10-Uhr-Gottesdienst, die beide bis 10:30 Uhr laufen — kennzeichnet B1 Admin diese Person als planübergreifend doppelt gebucht.

:::tip
Sie müssen nichts tun, um die Validierung auszuführen — sie wird automatisch aktualisiert, jedes Mal wenn Sie eine Zuordnung hinzufügen oder ändern. Halten Sie einfach ein Auge auf das Panel, während Sie den Plan aufbauen.
:::

## Benachrichtigen Sie Freiwillige

Sobald Ihr Plan festgelegt ist, können Sie alle zugewiesenen Freiwilligen auf einmal direkt vom Validierungspanel aus benachrichtigen.

1. Öffnen Sie den Plan und scrollen Sie zum **Validierungs**-Panel
2. Wenn es nicht benachrichtigte Freiwillige gibt, sehen Sie einen Link mit der Anzahl, die benachrichtigt werden muss (z. B., *"8 Freiwillige benachrichtigen"*)
3. Klicken Sie auf den Link, um Push-Benachrichtigungen an alle zu senden, die nicht benachrichtigt wurden
4. Freiwillige erhalten eine Benachrichtigung auf ihrem Telefon, dass sie eingeplant wurden, und werden aufgefordert, ihre Zuordnung zu bestätigen

:::info
Nur Freiwillige, die nicht benachrichtigt wurden, werden einbezogen. Wenn Sie später jemanden zum Plan hinzufügen, erscheint der Link erneut, damit Sie die neue Ergänzung benachrichtigen können, ohne den Rest des Teams erneut zu benachrichtigen.
:::

:::warning
Freiwillige müssen die B1.church-Mobile-App oder das B1.church-PWA (installiert auf dem Startbildschirm) mit aktivierten Benachrichtigungen haben, um Push-Benachrichtigungen zu erhalten. Siehe [Installation als App (PWA)](/docs/b1-church/getting-started/installing-pwa) für Anleitung.
:::
