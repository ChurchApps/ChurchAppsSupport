# Dienstfolge

<div class="article-intro">

Die Dienstfolge definiert die Abfolge der Elemente in Ihrem Gottesdienst. Verwenden Sie sie, um alles von einem Eröffnungslied bis zu einem Schlusgebet anzuordnen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- [Erstellen Sie einen Dienstplan](./plans.md) für das Datum, für das Sie eine Dienstfolge erstellen möchten
- Fügen Sie optional [Lieder](./songs.md) zu Ihrer Bibliothek hinzu

</div>

## Zugriff auf die Dienstfolge

1. Navigieren Sie zu **Dienst** und wählen Sie Ihr Ministerium.
2. Klicken Sie auf einen **Plantyp**, dann öffnen Sie einen bestimmten **Plan**.
3. Klicken Sie auf die Registerkarte **Dienstfolge** auf der Plandetailseite.

## Erstellen Ihrer Dienstfolge

Die Dienstfolge ist eine Liste von Elementen in der Reihenfolge, in der sie während des Gottesdienstes auftreten. Häufige Elemente sind Anbetungslieder, Gebete, Schriftlesungen, Ankündigungen, Predigt und Schließung.

## Hinzufügen von Elementen zur Dienstfolge

1. Klicken Sie auf der Registerkarte **Dienstfolge** auf **Element hinzufügen**.
2. Wählen Sie den Elementtyp.
3. Geben Sie die Details ein, wie Titel und Notizen.
4. Klicken Sie auf **Speichern**.
