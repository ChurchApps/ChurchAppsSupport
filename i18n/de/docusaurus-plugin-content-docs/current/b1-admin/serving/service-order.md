# Servicebestellung

<div class="article-intro">

Die Servicebestellung definiert die Reihenfolge der Elemente in deinem Gottesdienstprogramm. Verwende es, um alles vom Eröffnungslied bis zum Abschlussgebet anzulegen, damit dein gesamtes Team den Fluss des Dienstes im Voraus kennt.

</div>

<div class="prereqs">
<h4>Bevor du beginnst</h4>

- [Erstelle einen Serviceplan](./plans.md) für das Datum, für das du eine Servicebestellung erstellen möchtest
- Optional [füge Lieder](./songs.md) zu deiner Bibliothek hinzu, damit du sie direkt in die Servicebestellung verknüpfen kannst

</div>

## Zugriff auf die Servicebestellung

1. Navigiere zu **Dienst** und wähle dein Ministerium.
2. Klicke auf einen **Plantyp** und öffne dann einen bestimmten **Plan**.
3. Klicke auf die Registerkarte **Servicebestellung** auf der Plandetailseite.

## Aufbau deiner Servicebestellung

Die Servicebestellung ist eine Liste von Elementen, die in der Reihenfolge angeordnet sind, in der sie während des Dienstes auftreten. Häufige Elemente umfassen:

- Anbetungslieder
- Gebete
- Schriftlesung
- Ankündigungen
- Predigt oder Nachricht
- Opferangebot
- Schluss

## Elemente zur Servicebestellung hinzufügen

1. Klicke auf der Registerkarte **Servicebestellung** auf **Element hinzufügen**.
2. Wähle die Art des Elements aus, das du hinzufügen möchtest (z. B. ein Lied aus deiner Bibliothek, ein benutzerdefiniertes Element oder eine Überschrift).
3. Gib die Details für das Element ein, z. B. Titel und Notizen.
4. Klicke auf **Speichern**.

:::tip
Du kannst Lieder direkt aus deiner [Lieder](./songs.md)-Bibliothek hinzufügen. Dies verknüpft die Lieddetails, einschließlich Texte und Arrangements, mit deinem Serviceplan, damit dein Anbetungsteam alles hat, was es braucht.
:::

## Umordnen von Elementen

Ziehe Elemente mit dem Handle auf der linken Seite jeder Zeile, um die Reihenfolge zu ändern - lasse es auf der blauen Linie los, wo das Element landen soll, oder auf einer Abschnittsüberschrift, um es in diesen Abschnitt zu verschieben. Die auf dem Bildschirm angegebene Reihenfolge ist die Reihenfolge, der dein Team während des Dienstes folgt.

## Timing und Medien

Jedes Element und jeder Abschnitt zeigt, wie lange es läuft und wann es beginnt:

- Wenn der Plan eine einzelne Servicezeit ausgewählt hat, zeigt die linke Schiene die tatsächliche **Uhrzeit**, zu der jedes Element beginnt (z. B. 9:14 Uhr). Sonst zeigt es verstrichene Zeit vom Beginn des Dienstes.
- Abschnittsüberschriften addieren die Laufzeit von allem darin.
- Lieder und benutzerdefinierte Elemente zählen zum Zeitplan, sobald du **Minuten**/**Sekunden** auf dem Bearbeitungsbildschirm des Elements eingibst.
- Elemente, die du aus deiner Medienbibliothek hinzufügst (Bilder oder Videoclips), zeigen eine **Miniaturansicht** an und werden automatisch zeitgesteuert - die Dauer eines Videos wird aus der Datei selbst gemessen, während ein Bild zu einer ~5:00-Planungsschätzung beiträgt (in Kursivschrift angezeigt), da es auf dem Bildschirm bleibt, bis ein Bediener es weiterleitet. Du kannst beides immer noch auf eine bestimmte Dauer bearbeiten.

## Bearbeiten und Entfernen von Elementen

- Klicke auf ein Element in der Servicebestellung, um seine Details zu **bearbeiten**.
- Verwende die Option **Löschen**, um ein Element aus der Reihenfolge zu entfernen.

:::info
Die Servicebestellung ist spezifisch für jeden Plan. Änderungen, die du hier vornimmst, wirken sich nur auf den ausgewählten Plan aus und ändern keine anderen Pläne oder deine Liederbibliothek.
:::

## Elemente in bestimmten Servicezeiten einbeziehen

Wenn dein Plan mehr als eine Servicezeit hat (z. B. einen 8-Uhr- und 10-Uhr-Dienst), kannst du wählen, welche Dienste jedes Element angezeigt werden soll. Dies ist nützlich, wenn eine Ankündigung nur für einen Dienst relevant ist oder wenn ein Lied in einem Dienst gesungen wird, aber nicht in einem anderen.

1. Öffne einen Plan, der auf der Registerkarte **Zeiten** zwei oder mehr Servicezeiten definiert hat.
2. Klicke auf der Registerkarte **Servicebestellung** auf ein Element, um es zu bearbeiten.
3. Unter **In Diensten einbeziehen** siehst du ein Kontrollkästchen für jede Servicezeit, mit der Uhrzeit gekennzeichnet.
4. Deaktiviere einen beliebigen Dienst, bei dem das Element übersprungen werden sollte.
5. Klicke auf **Speichern**.

Standardmäßig wird jedes Element in jedem Dienst einbezogen. Ausgeschlossene Servicezeiten werden ausgeblendet, wenn du den Plan gefiltert nach diesem Dienst ausdruckst, sodass jeder Dienst ein sauberes Runsheet mit nur den relevanten Elementen erhält.

:::tip
Der Bereich **In Diensten einbeziehen** wird nur angezeigt, wenn der Plan mehr als eine Servicezeit hat. Wenn du nur einen Dienst siehst, bearbeite die Registerkarte **Zeiten** des Plans, um zuerst zusätzliche Dienste hinzuzufügen.
:::

## Teilen der Servicebestellung

Sobald deine Servicebestellung abgeschlossen ist, kannst du den vollständigen Plan (einschließlich der Servicebestellung) von der Plandetailseite ausdrucken. Dies gibt deinem Team einen vollständigen Überblick über den Dienst.

## Nächste Schritte

- Verwalte dein Anbetungsrepertoire auf der Seite [Lieder](./songs.md)
- Weise Freiwillige der Dienstleistung auf der Registerkarte [Pläne](./plans.md) Zuordnungen zu
- Erstelle [Aufgaben](./tasks.md) für alle folgenden Elemente im Zusammenhang mit dem Dienst
