# Drittanbieter

<div class="article-intro">

Lessons.church unterstützt externe Lehrplananbieter über das Open Lesson Format. Das bedeutet, dass Ihre Gemeinde Lehrpläne anderer Organisationen anbinden und für Ihre Klassenräume planen kann, direkt neben der integrierten Bibliothek. So hat Ihr Team Lehrpläne aus mehreren Quellen an einem Ort.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Melden Sie sich bei Lessons.church mit einem Konto an, das die Klassenraumpläne Ihrer Gemeinde verwalten kann
- Holen Sie sich die Feed-URL des externen Anbieters, den Sie anbinden möchten. Sie muss Lektionen im [Open Lesson Format](./open-lesson-format.md) ausliefern

</div>

## Einen Anbieter hinzufügen

1. Klicken Sie in der Navigation von Lessons.church auf **Externe Anbieter**. Die Seite **Externe Lektionsanbieter** wird geöffnet.
2. Klicken Sie auf **Anbieter hinzufügen**. Falls Sie noch keinen Anbieter angelegt haben, klicken Sie stattdessen auf **Ersten Anbieter hinzufügen**.
3. Geben Sie einen **Anbieternamen** ein. Dieser Name sehen Ihre Teammitglieder, wenn sie den Anbieter auswählen.
4. Geben Sie die **API-URL** ein. Dies ist die Adresse, unter der der Anbieter seinen Lehrplan im Open Lesson Format veröffentlicht.
5. Klicken Sie auf **Speichern**.

Der Anbieter wird nur für Ihre Gemeinde hinzugefügt. Anschließend erscheint er als Auswahlmöglichkeit unter **Anbieter**, wenn Sie eine [Lektion planen](../classrooms/scheduling-lessons.md) für einen Klassenraum, sowie unter **Quelle**, wenn Sie einen [Jahresplan erstellen](./managing-year-plans.md).

## Anbieter verwalten

Auf der Seite **Externe Lektionsanbieter** sind alle Anbieter aufgeführt, die Ihre Gemeinde hinzugefügt hat. So ändern Sie einen Anbieter:

- **Bearbeiten** -- Klicken Sie auf das Symbol **Anbieter bearbeiten** (Stift), ändern Sie den **Anbieternamen** oder die **API-URL** und klicken Sie auf **Speichern**.
- **Löschen** -- Klicken Sie auf das Symbol **Anbieter bearbeiten** und anschließend auf das Papierkorb-Symbol. Bestätigen Sie den Vorgang.

## Was ist das Open Lesson Format?

Das Open Lesson Format ist ein standardisiertes Schema, das Lehrinhalte strukturiert beschreibt -- Programme, Studien, Lektionen, Orte, Abschnitte und Aktionen. Jede Organisation, die ihre Inhalte in diesem Format veröffentlicht, kann als Anbieter in Lessons.church hinzugefügt werden.

Wenn Sie als Inhaltsanbieter Ihren Lehrplan über Lessons.church verfügbar machen möchten, finden Sie die vollständige Schema-Dokumentation in der Anleitung zum [Open Lesson Format](./open-lesson-format.md).

## Warum Drittanbieter nutzen?

- **Mehr Auswahl für Gemeinden** -- Gemeinden können eine größere Vielfalt an Lehrplänen durchsuchen, ohne die Plattform zu verlassen.
- **Alles an einem Ort** -- Ehrenamtliche und Koordinatoren müssen nicht mehrere Webseiten besuchen, um Lektionen zu finden und zu planen.
- **Einfache Einrichtung** -- Einen Anbieter hinzuzufügen erfordert nur einen Namen und eine Feed-URL. Es ist keine manuelle Dateneingabe oder ein Datei-Upload nötig.

:::info
Drittanbieter-Inhalte werden vom externen Anbieter verwaltet. Wenn Ihnen fehlende oder veraltete Inhalte eines Anbieters auffallen, muss das Problem möglicherweise dort behoben werden.
:::

:::tip
Um zu sehen, wie Lektionen eines externen Anbieters nach der Planung aussehen, lesen Sie [Externe Anbieter](../browsing/external-providers.md) im Bereich Durchsuchen.
:::
