# Open Lesson Format

<div class="article-intro">

Das Open Lesson Format ist ein standardisiertes Format für Lektionen in Lessons.church.

</div>

## Überblick

Das Open Lesson Format ermöglicht es Kirchen, Lektionen in einem standardisierten Format zu erstellen und freizugeben.

## Verwendung

Verwenden Sie das Open Lesson Format, um Lektionen zu erstellen, die mit anderen Kirchen geteilt werden können.
