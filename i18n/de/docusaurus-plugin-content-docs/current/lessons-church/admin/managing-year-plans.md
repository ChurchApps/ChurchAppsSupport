# Jahrespläne verwalten

<div class="article-intro">

Jahrespläne organisieren Lektionen über ein ganzes Jahr.

</div>

## Erstellen eines Jahresplans

1. Öffnen Sie Lessons.church Admin
2. Klicken Sie auf "Neuer Jahresplan"
3. Geben Sie den Namen des Jahresplans ein
4. Organisieren Sie Lektionen für das Jahr
5. Speichern Sie den Plan

## Bearbeiten eines Jahresplans

Klicken Sie auf einen Jahresplan, um ihn zu bearbeiten.
