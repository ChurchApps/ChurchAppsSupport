# Jahrespläne verwalten

<div class="article-intro">

Ein Jahresplan ist eine geordnete Liste von Lektionen – Woche 1, Woche 2, Woche 3 – die Kirchen in B1 Admin anwenden. Sie können einen Plan für jeden Lehrplan in der Bibliothek veröffentlichen. Pläne werden in der Datenbank gespeichert und sind nicht an ein Kalenderjahr gebunden.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Haben Sie Admin-Berechtigungen für Lessons.church
- Haben Sie mindestens ein [Programm](./managing-programs.md) mit veröffentlichten Lektionen

</div>

## Erstellen eines Plans

1. Öffnen Sie **Admin → Jahrespläne**.
2. Klicken Sie auf **Hinzufügen**.
3. Geben Sie einen Namen (zum Beispiel, "Elementary 2026–27" oder "High Voltage Jahr 1") und optional Slug ein.
4. Legen Sie optional eine **Standardvenue-Präferenz** fest – komma-getrennte Venuenamen, die verwendet werden, wenn eine Woche keine Venue angibt.
5. Markieren Sie **Veröffentlichen**, wenn Kirchen den Plan in B1 Admin sehen sollen. Lassen Sie es ausgeschaltet für einen Entwurf.
6. Fügen Sie Wochen von jedem Lehrplan hinzu: Wählen Sie eine **Quelle**, dann Programm, Studie, Lektion und Venue. Klicken Sie auf **Hinzufügen**. Ein einzelner Plan kann Programme mischen, wenn Sie möchten. Verwenden Sie die Pfeile, um neu zu ordnen.
7. Speichern.

Kirchen wenden einen veröffentlichten Plan von **B1 Admin → Dienst → Pläne → Lektion planen → Jahresplan anwenden** an. Das füllt die nächsten 12–52 Wochen auf ihrem Dienst-Zeitplan. Sie bearbeiten einzelne Wochen später dort; FreePlay spielt, was immer auf dem Plan ist.
