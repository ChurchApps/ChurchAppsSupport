# Verwaltung

<div class="article-intro">

Der Verwaltungsbereich in Lessons.church ist der Ort, an dem Inhaltsersteller und Administratoren die Lektionsbibliothek pflegen. Von hier aus können Sie Ihre Lehrplanstruktur aufbauen, Ressourcen hochladen, Nutzungsstatistiken einsehen und Anbieter externer Inhalte anbinden.

</div>

:::warning
Für den Zugriff auf den Verwaltungsbereich sind entsprechende Berechtigungen erforderlich. Wenn Sie die Verwaltungsoptionen nicht sehen, wenden Sie sich an Ihren Gemeindeadministrator, um Zugriff anzufordern.
:::

## Was Sie tun können

Der Verwaltungsbereich gibt Ihnen die volle Kontrolle über Ihre Inhalte:

- **Programme erstellen und bearbeiten** -- Richten Sie übergeordnete Lehrplanreihen mit Namen, Beschreibungen, Bildern und Slugs ein.
- **Studien verwalten** -- Organisieren Sie innerhalb jedes Programms Gruppen zusammengehöriger Lektionen.
- **Lektionen erstellen** -- Fügen Sie einzelne Lektionen mit Venues, Abschnitten, Rollen und Aktionen hinzu.
- **Ressourcen hochladen** -- Hängen Sie herunterladbare Dateien (PDFs, Arbeitsblätter, Bilder) auf Programm-, Studien- oder Lektionsebene an.
- **Statistiken einsehen** -- Erfahren Sie, welche Inhalte von wem und von wo heruntergeladen werden.
- **Anbieter konfigurieren** -- Verbinden Sie externe Lehrplananbieter, die das Open Lesson Format verwenden. Dies geschieht auf der Seite **Externe Anbieter** und nicht im Verwaltungsbereich.
- **Jahrespläne** -- Veröffentlichen Sie Abfolgen für Woche 1, 2, 3 … für beliebige Lehrpläne. Gemeinden wenden sie in B1 Admin an.

## Inhaltshierarchie

Als Administrator hilft es, zu verstehen, wie Inhalte strukturiert sind:

1. **Programme** enthalten eine oder mehrere Studien.
2. **Studien** enthalten eine oder mehrere Lektionen.
3. **Lektionen** enthalten eine oder mehrere Venues (Varianten für Altersgruppen).
4. **Venues** enthalten Abschnitte, und Abschnitte enthalten rollenbasierte Aktionen.

Auf jeder Ebene können eigene herunterladbare Ressourcen angehängt werden.
