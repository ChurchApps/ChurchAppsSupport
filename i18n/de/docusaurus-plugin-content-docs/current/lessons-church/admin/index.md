# Lessons.church Admin

<div class="article-intro">

Lessons.church Admin ermöglicht es Kirchen, Lehrplan zu verwalten und bereitzustellen.

</div>

## Funktionen

- Lehrplanerstellung
- Lehrplan-Verwaltung
- Ressourcen-Bibliotheken
- Berichterstattung

## Erste Schritte

Melden Sie sich bei Lessons.church an, um mit der Verwaltung von Lehrplan zu beginnen.
