# Lektionen verwalten

<div class="article-intro">

Lektionen in Lessons.church können erstellt, bearbeitet und organisiert werden.

</div>

## Erstellen einer Lektion

1. Öffnen Sie Lessons.church Admin
2. Klicken Sie auf "Neue Lektion"
3. Füllen Sie Lektionsdetails aus
4. Speichern Sie die Lektion

## Bearbeiten einer Lektion

Klicken Sie auf eine Lektion, um sie zu bearbeiten.

## Löschen einer Lektion

Klicken Sie auf das Löschsymbol neben einer Lektion, um sie zu löschen.
