# Portal-Übersicht

<div class="article-intro">

Nach der Anmeldung bei Lessons.church gelangen Sie zum **Portal** -- dem Dashboard Ihrer Gemeinde für die Verwaltung von Klassen und Lektionsplänen. Hier werden Sie den größten Teil Ihrer Zeit verbringen, wenn Sie den Lehrplan für Ihre Gemeinde organisieren.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- [Konto erstellen](./creating-account.md) und mit Ihrer Gemeinde verbinden
- Bei [Lessons.church](https://lessons.church) anmelden

</div>

## Was Sie sehen

Das Portal öffnet sich auf der Seite **Classroom Management**, die in zwei Hauptbereiche gegliedert ist:

- **Classrooms** (rechte Seite) -- Eine Liste der Klassen Ihrer Gemeinde. Klicken Sie auf einen Klassennamen, um dessen geplante Lektionen anzuzeigen. Außerdem können Sie hier neue Klassen hinzufügen oder bestehende bearbeiten.
- **Lesson Schedule** (linke Seite) -- Sobald Sie eine Klasse ausgewählt haben, zeigt dieser Bereich die dafür geplanten Lektionen an. Wenn Sie noch keine Klassen eingerichtet haben, sehen Sie ein Einrichtungsvideo, das Ihnen den Einstieg erleichtert.

## Was Sie im Portal tun können

Im Portal können Sie:

1. **Klassen verwalten** -- Klassen hinzufügen, bearbeiten oder entfernen. Jede Klasse kann mit einem Ehrenamtsteam verknüpft werden (damit es die bevorstehenden Lektionen in der B1 App sieht) und mit einer Eltern- oder Schülergruppe (damit sie auf aktuelle Lektionen zugreifen kann). Gemeinden, die noch über diesen Klassenplan arbeiten, haben folgende Möglichkeit: Eltern öffnen die Klassenseite (ohne `?upcoming=1`), um Materialien für zu Hause zu sehen. Gemeinden mit B1Admin-Planarten sehen die Karte für Materialien zum Mitnehmen stattdessen auf der Seite der zugehörigen Gruppe in B1.
2. **Geplante Lektionen anzeigen und verwalten** -- Sehen Sie, welche Lektionen für jede Klasse anstehen, und nehmen Sie bei Bedarf Änderungen vor.
3. **Klassen-Feeds abonnieren** -- Klicken Sie neben einer Klasse auf das Feed-Symbol, um eine Playlist-Feed-URL zu erhalten, die Sie in kompatiblen Apps verwenden können.
4. **Auf External Providers zugreifen** -- Nutzen Sie die Seite **External Providers**, um Inhalte von Drittanbietern einzurichten, die das Open Lesson Format unterstützen. So können Sie Lektionen von anderen Anbietern einbinden, zusätzlich zur integrierten Bibliothek von Lessons.church.
5. **Auf den Admin-Bereich zugreifen** -- Wenn Sie Administratorrechte haben, sehen Sie in der Navigation die Option **Admin**. Der Admin-Bereich ermöglicht Ihnen, Programme, Studien und Lektionen auf Inhaltsebene zu verwalten.

## Navigation

Die Navigation des Portals umfasst:

- **Home** -- Zurück zur öffentlichen Startseite von Lessons.church, um Inhalte zu durchsuchen.
- **Schedules** -- Die zentrale Portalansicht zur Verwaltung von Klassen und Lektionsplänen.
- **External Providers** -- Externe Lektionsanbieter einrichten.
- **Admin** -- Programme, Studien und Lektionsinhalte verwalten (nur sichtbar, wenn Sie Administratorrechte haben).

:::info
Die Option **Admin** erscheint nur, wenn Ihrem Konto die Berechtigung zur Bearbeitung von Inhalten erteilt wurde. Die meisten Mitarbeitenden der Gemeinde nutzen für die tägliche Verwaltung die Seiten **Schedules** und **External Providers**.
:::

## Erste Schritte

Wenn Sie das Portal zum ersten Mal besuchen und noch keine Klassen angelegt haben, klicken Sie zunächst im Klassenbereich auf **Add First Classroom**. Geben Sie Ihrer Klasse einen Namen (zum Beispiel „Vorschule“ oder „3.-5. Klasse“) und speichern Sie sie. Danach können Sie [Lektionen planen](../classrooms/scheduling-lessons.md).
