# Anpassung

<div class="article-intro">

Lessons.church bietet eine Bibliothek mit sofort einsetzbaren Lektionsinhalten, aber jede Gemeinde ist anders. Mit den Anpassungsfunktionen können Sie Lektionsinhalte auf Ihre spezifischen Klassen, Ihren Unterrichtsstil und Ihre Altersgruppen zuschneiden, sodass Ihre Ehrenamtlichen nur das sehen, was für sie relevant ist.

</div>

## Warum anpassen?

Lektionsinhalte auf Lessons.church sind flexibel gestaltet. Eine einzelne Lektion kann Abschnitte für mehrere Altersgruppen, optionale Aktivitäten oder Rollen enthalten, die nicht auf jede Klasse zutreffen. Anstatt Ihre Ehrenamtlichen zu bitten, Teile gedanklich zu überspringen, die für sie nicht gelten, können Sie die Lektion so anpassen, dass sie nur das sehen, was für sie relevant ist.

Eine Lektion könnte zum Beispiel eine Bastelaktivität enthalten, die für Vorschulkinder hervorragend funktioniert, aber für Ihre Fünftklässler nicht geeignet ist. Mit der Anpassung können Sie diesen Abschnitt für die ältere Gruppe ausblenden, während er für die jüngere Gruppe erhalten bleibt.

## Was Sie anpassen können

- **Abschnitte entfernen** -- Entfernen Sie ganze Abschnitte einer Lektion, die nicht für eine bestimmte Klasse oder Altersgruppe gelten.
- **Rollen oder Aktionen entfernen** -- Entfernen Sie einzelne Rollen oder Aktionen innerhalb eines Abschnitts, wenn sie nicht benötigt werden.
- **Inhalte neu anordnen** -- Ordnen Sie Abschnitte und Aktionen so um, dass sie dem Ablauf entsprechen, den Sie für Ihre Klasse bevorzugen.

## Klassenspezifisch oder global

Bei jeder Änderung legen Sie fest, wie weitreichend sie gilt:

- **Diese Klasse** -- Die Änderung betrifft nur die aktuelle Klasse. Andere Klassen sehen den ursprünglichen Inhalt.
- **Alle Klassen** -- Die Änderung gilt für alle Klassen in Ihrer Gemeinde.

Diese Flexibilität bedeutet, dass Sie unterschiedliche Ansichten derselben Lektion für verschiedene Altersgruppen einrichten oder eine Änderung vornehmen können, die überall gleichzeitig gilt.

:::tip
Wenn Sie neu bei der Anpassung sind, beginnen Sie mit einer einzelnen Klasse, um zu sehen, wie es funktioniert, bevor Sie Änderungen auf alle Klassen anwenden.
:::
