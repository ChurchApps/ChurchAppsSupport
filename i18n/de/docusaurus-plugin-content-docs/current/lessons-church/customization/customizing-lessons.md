# Lektionen anpassen

<div class="article-intro">

Diese Anleitung führt Sie durch die Anpassung einer Lektion für Ihren Klassenraum. Mit Anpassungen können Sie Inhalte entfernen oder neu anordnen, damit Ihre Ehrenamtlichen genau das sehen, was sie brauchen -- nicht mehr und nicht weniger.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- [Richten Sie mindestens einen Klassenraum](../classrooms/setting-up-classrooms.md) im Portal ein
- [Planen Sie eine Lektion](../classrooms/scheduling-lessons.md) für den Klassenraum, den Sie anpassen möchten
- Lesen Sie die [Übersicht zur Anpassung](./index.md), um zu verstehen, was angepasst werden kann

</div>

## Die Anpassungsansicht öffnen

1. Melden Sie sich an und navigieren Sie zu Ihrem **Portal**.
2. Wählen Sie den **Klassenraum** aus, der die Lektion enthält, die Sie anpassen möchten.
3. Suchen Sie in der Zeitplanansicht des Klassenraums die Lektion und klicken Sie unter ihrem Namen auf **Anpassen**.

Die Seite **Lektion anpassen** listet die Abschnitte der Lektion auf, darunter jeweils die Rollen des Abschnitts und darunter die Aktionen jeder Rolle. Jede Zeile hat rechts Schaltflächen:

- **Pfeil nach oben** und **Pfeil nach unten** -- Verschiebt das Element um eine Position nach oben oder unten innerhalb seiner Nachbarn
- **Löschen** (Papierkorb) -- Entfernt das Element

:::info
**Anpassen** erscheint nur bei Lessons.church-Lektionen. Lektionen, die von einem externen Anbieter geplant wurden, zeigen stattdessen **Lektion anzeigen** an und können nicht angepasst werden.
:::

## Festlegen, wofür eine Änderung gilt

Jedes Mal, wenn Sie auf einen Pfeil oder den Papierkorb klicken, fragt ein Menü: **Ausgewählte Anpassung anwenden auf:**

- **Dieser Klassenraum** -- Die Änderung gilt nur für den aktuellen Klassenraum. Andere Klassenräume bleiben unberührt.
- **Alle Klassenräume** -- Die Änderung gilt für alle Klassenräume in Ihrer Gemeinde.

Wählen Sie eine Option aus, dann wird die Änderung sofort gespeichert. Es gibt keinen separaten Speicherschritt.

## Abschnitte entfernen

Wenn ein Abschnitt nicht zu Ihrem Klassenraum passt, können Sie ihn vollständig entfernen. Das ist hilfreich, wenn eine Lektion Inhalte für mehrere Altersgruppen enthält und Sie nur eine davon benötigen. Wenn eine Lektion beispielsweise sowohl einen Abschnitt „Preschool Activity“ als auch einen Abschnitt „Elementary Activity“ enthält, können Sie den Abschnitt entfernen, der nicht zu Ihrem Raum passt.

1. Suchen Sie den Abschnitt, den Sie entfernen möchten.
2. Klicken Sie auf dessen Schaltfläche **Löschen** (Papierkorb).
3. Wählen Sie **Dieser Klassenraum** oder **Alle Klassenräume**.

Der Abschnitt wird als entfernt angezeigt, zusammen mit allen seinen Rollen und Aktionen, und die Ehrenamtlichen sehen ihn für diese Lektion nicht mehr.

## Rollen oder Aktionen entfernen

Innerhalb eines Abschnitts können Sie einzelne Rollen oder Aktionen entfernen. Wenn ein Abschnitt zum Beispiel eine Rolle „Worship Leader“ enthält, Ihr Klassenraum aber keine solche Rolle benötigt, können Sie nur diese Rolle entfernen, ohne den gesamten Abschnitt zu löschen.

1. Suchen Sie die Rolle oder Aktion in der Liste unter ihrem Abschnitt.
2. Klicken Sie auf deren Schaltfläche **Löschen** (Papierkorb) und wählen Sie aus, wofür die Änderung gilt.

## Inhalte neu anordnen

Sie können Abschnitte, Rollen und Aktionen umordnen, damit sie dem gewünschten Ablauf entsprechen:

1. Klicken Sie auf den **Pfeil nach oben** oder **Pfeil nach unten** beim Element, das Sie verschieben möchten.
2. Wählen Sie, wofür die Änderung gilt. Das Element tauscht den Platz mit seinem Nachbarn.

Wiederholen Sie dies, bis die Elemente in der gewünschten Reihenfolge stehen. Diese neue Reihenfolge sehen Ihre Ehrenamtlichen, wenn sie die Lektion aufrufen.

## Eine Entfernung rückgängig machen

Um ein entferntes Element wiederherzustellen, klicken Sie erneut auf dessen Schaltfläche **Löschen**. Das Menü bietet nun zusätzlich die Option **Keine** an. Wählen Sie **Keine**, um die Entfernung aufzuheben und das Element wieder anzuzeigen, oder wählen Sie die andere Option, um festzulegen, wofür die Entfernung gilt.

:::tip
Beginnen Sie damit, eine einzelne Lektion für einen Klassenraum anzupassen. Sobald Sie mit dem Vorgehen vertraut sind, können Sie Anpassungen auch breiter auf alle Klassenräume anwenden.
:::

## Wann Sie anpassen sollten

Anpassungen sind besonders nützlich, wenn:

- eine Lektion Inhalte für mehrere Altersgruppen enthält und Sie nur die relevanten Teile anzeigen möchten.
- Ihr Klassenraum bestimmte Rollen nicht benötigt (etwa einen eigenen Worship Leader oder einen technischen Helfer).
- Sie eine andere Reihenfolge für den Ablauf der Lektion bevorzugen als die Standardvorgabe.

:::info
Sie müssen nicht jede Lektion anpassen. Wenn die Inhalte für Ihren Klassenraum so passen, wie sie sind, können Sie diesen Schritt ganz überspringen und direkt zur [Präsentation](../presenting/index.md) übergehen.
:::
