# Präsentationsmodus

<div class="article-intro">

Der Präsentationsmodus transformiert eine Lektion in eine Vollbild-, zum Projizieren geeignete Anzeige. Er ist so ausgelegt, dass er Lektionsinhalte auf Klassenzimmer-Bildschirmen, Projektoren oder Fernsehern anzeigt, damit alle im Raum während der Unterrichtszeit folgen können.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- [Planen Sie eine Lektion](../classrooms/scheduling-lessons.md) für ein Klassenzimmer oder navigieren Sie zu einer Lektion durch die [Inhaltsbibliothek](../browsing/index.md)
- Stellen Sie sicher, dass Ihr Display (Projektor, Fernseher oder Monitor) verbunden und konfiguriert ist

</div>

## Eintritt in den Präsentationsmodus

1. Öffnen Sie die Lektion, die Sie präsentieren möchten.
2. Klicken Sie auf die Schaltfläche **Present** auf der Lektionsseite.
3. Die Lektion wechselt zu einer Vollbildansicht mit schwarzem Hintergrund und großem, leicht lesbarem Text.

Sobald Sie im Präsentationsmodus sind, können Sie sich durch die Lektion Abschnitt für Abschnitt mit den On-Screen-Navigationselementen bewegen.

## Wie es aussieht

Der Präsentationsmodus verwendet einen sauberen, dunklen Hintergrund, sodass sich der Inhalt auf einem projizierten Bildschirm abhebt. Jeder Abschnitt der Lektion wird jeweils einer angezeigt, wodurch der Fokus auf die aktuelle Aktivität gehalten wird. Text, Bilder und Video-Einbettungen sind alle so formatiert, dass sie von über einem Raum lesbar sind.

## Verwendung mit FreeShow

Lessons.church integriert sich mit [FreeShow](https://freeshow.app), einer kostenlosen Präsentationsanwendung. FreeShow kann Lektionsinhalte direkt von Lessons.church ziehen, sodass Sie Lektionsfolien in Ihren bestehenden Präsentations-Workflow einbeziehen können. Dies ist besonders nützlich, wenn Sie bereits FreeShow für Anbetungs-Lyrics oder Ankündigungen verwenden.

## Verwendung mit FreePlay

**[FreePlay](https://freeplay.church)** ermöglicht es Ihnen, Lektionen auf einem Fernseher ohne einen separaten Computer anzuzeigen. Installieren Sie die App auf einem Android TV-, Fire TV- oder Apple TV-Gerät, verbinden Sie sie mit Ihrem Lessons.church-Klassenzimmer, und die geplante Lektion wird automatisch angezeigt. Dies ist eine großartige freihändige Option für Klassenzimmer, die einen dedizierten Bildschirm haben. Siehe die [FreePlay-Dokumentation](/docs/freeplay/) zum Setup.

:::tip
Wenn Sie einen Projektor verwenden, stellen Sie sicher, dass Ihr Display vor dem Eintritt in den Präsentationsmodus auf Spiegeln oder Erweitern auf den Projektor eingestellt ist. Dies stellt sicher, dass die Vollbildansicht auf dem richtigen Bildschirm angezeigt wird.
:::

## Beendigung des Präsentationsmodus

Um den Präsentationsmodus zu verlassen, drücken Sie die **Escape**-Taste oder klicken Sie auf die Exit-Schaltfläche in der Ecke des Bildschirms. Sie kehren zur normalen Lektionsansicht zurück.
