# WorshipCommons-Servicepläne

<div class="article-intro">

Ein Serviceplan auf WorshipCommons ist eine Setliste für den Sonntag. Ordnen Sie die Songs an, wählen Sie für jeden die Tonart, das Kapodaster und die Abschnitte und teilen Sie dann einen einzigen Link mit Ihrer Band. Aus dem Plan können Sie eine Bühnenansicht für den Notenständer öffnen, ein Heft drucken oder das gesamte Set in Ihre Präsentationssoftware exportieren.

</div>

:::info
Servicepläne werden im Webbrowser gespeichert, nicht in Ihrem Konto, und Sie müssen sich nicht anmelden, um sie zu verwenden. Ein Freigabelink enthält das gesamte Set. Speichern Sie den Link, wenn Sie das Gerät wechseln. Wenn Ihre Gemeinde Gottesdienste in B1 Admin plant, lesen Sie stattdessen [Pläne](../b1-admin/serving/plans.md).
:::

## Einen Serviceplan erstellen

1. Klicken Sie im oberen Menü auf **Servicepläne**.
2. Geben Sie einen Namen ein, zum Beispiel „Sonntag, 14. September“ oder „Jugendabend“, und klicken Sie auf **Servicoplan erstellen**.

Sie können einen Plan auch von jedem Song aus beginnen. Klicken Sie auf der Songseite auf **+ Zum Serviceplan hinzufügen**, geben Sie unter der Liste einen Namen ein und klicken Sie auf **Erstellen**.

## Songs hinzufügen

1. Öffnen Sie die Seite eines Songs. Legen Sie zuerst die gewünschte Tonart fest, denn der Song wird in der angezeigten Tonart in den Plan aufgenommen.
2. Klicken Sie auf **+ Zum Serviceplan hinzufügen**.
3. Klicken Sie auf den Namen des Plans. Ein Häkchen zeigt an, dass der Song in diesem Plan enthalten ist. Klicken Sie erneut darauf, um ihn wieder zu entfernen.

Die Schaltfläche zeigt dann **✓ In** gefolgt vom Namen des Plans. Klicken Sie im Pop-up auf den Link **Öffnen** mit dem Namen des Plans, um zum Plan zu gelangen.

## Das Set anordnen

Öffnen Sie einen Plan über die Seite **Servicepläne**. Für jeden Song können Sie:

- **Neu ordnen** -- Verwenden Sie die Schaltflächen **↑** und **↓** oder ziehen Sie den Song an eine neue Position. Klicken Sie auf **Entfernen**, um ihn herauszunehmen.
- **Tonart** -- Wählen Sie aus den **veröffentlichten** Tonarten des Songs oder einer beliebigen anderen Tonart (aufgeführt unter **Vorschau (beliebige Tonart)**).
- **Kapodaster** -- Wählen Sie einen Bund für das Kapodaster. Der Plan zeigt, welche Akkordgriffe Sie spielen sollen.
- **Abschnitte** -- Legen Sie die Reihenfolge der Strophen und Refrains fest. Verwenden Sie die Pfeile, um einen Abschnitt zu verschieben, **×**, um ihn zu entfernen, und **+ Abschnitt hinzufügen**, um einen hinzuzufügen (zum Beispiel einen wiederholten Refrain). Klicken Sie auf **Auf Standard zurücksetzen**, um zur üblichen Reihenfolge des Songs zurückzukehren.
- **Arrangement** -- Geben Sie eine kurze Notiz für die Band ein, zum Beispiel „Refrain ×2 am Ende, letzte Strophe a cappella“.

Oben im Plan wird die Anzahl der Songs und die ungefähre Länge des Sets angezeigt. Änderungen werden automatisch gespeichert.

## Mit Ihrem Team teilen

1. Klicken Sie auf **Link teilen**. Der Link wird in Ihre Zwischenablage kopiert.
2. Senden Sie ihn per Textnachricht oder E-Mail an Ihre Band.

Wer den Link öffnet, sieht den Plan mit allen Tonarten, Kapodastern, Abschnitten und Notizen, ohne ein Konto zu benötigen. Mit **Kopie speichern** kann die Person eine eigene, bearbeitbare Kopie in ihrem Browser behalten.

Auf der Seite **Servicepläne** können Sie einen Plan außerdem **teilen**, **umbenennen**, **duplizieren** oder **löschen**.

## Den Plan am Sonntag verwenden

- **Bühnenmodus** -- Zeigt jeweils eine Notenvorlage pro Bildschirm für ein Tablet auf dem Notenständer. Verwenden Sie die Pfeile (oder die Tasten **←** und **→**), um zwischen den Songs zu wechseln, und die Schaltflächen für die Textgröße, um die Vorlage zu vergrößern. Der Bühnenmodus versucht, zu verhindern, dass der Bildschirm in den Ruhezustand wechselt. Die Leiste zeigt an, ob **Bildschirm wird wach gehalten** aktiv ist.
- **Heft drucken** -- Druckt jede Vorlage in der Reihenfolge, eine pro Seite, mit einem Deckblatt, das die Songs und Tonarten auflistet. Wählen Sie **Große Schrift** oder **Akkorde anzeigen** und klicken Sie dann auf **Drucken**.
- **Kopieren für OnSong / Planning Center** -- Kopiert alle Vorlagen in Ihren Tonarten und Abschnitten, bereit zum Einfügen.

## Das Set exportieren

Klicken Sie auf **FreeShow**, **OpenLP**, **ProPresenter** oder **PowerPoint**, um das gesamte Set für das jeweilige Programm in den von Ihnen gewählten Tonarten und Abschnitten herunterzuladen.

Klicken Sie auf **Hauskreis-Paket**, um eine ZIP-Datei herunterzuladen. Sie enthält die Vorlage jedes Songs in Ihrer Tonart, die Liedtexte, Folien, Urheberangaben, eine Setliste und eine Datei LICENSE.txt.

:::warning
Songs unter CC BY-SA werden aus dem Hauskreis-Paket ausgelassen, es sei denn, Sie aktivieren **Paket mit Share-alike (CC-BY-SA-Songs einschließen)**. Wenn Sie sie einschließen, müssen alle Werke, die Sie aus dem Paket erstellen, unter derselben Lizenz weitergegeben werden. Die Vorlagen, der Bühnenmodus und das Heft enthalten diese Songs immer.
:::
