# WorshipCommons-Lieder vortragen und exportieren

<div class="article-intro">

WorshipCommons kann die Liedtexte eines Songs direkt aus dem Browser auf einen Bildschirm bringen, ganz ohne Installation. Wenn deine Gemeinde bereits Präsentationssoftware verwendet, lade stattdessen die Folien des Liedes für FreeShow, OpenLP, ProPresenter oder PowerPoint herunter oder füge das Lied deiner Liedbibliothek in B1 Admin hinzu.

</div>

<div class="prereqs">
<h4>Bevor du beginnst</h4>

- Öffne die Seite des Liedes auf [worshipcommons.org](https://worshipcommons.org). Siehe [Lieder finden](./finding-songs.md).
- Um die Liedtexte auf einem Fernseher oder Projektor anzuzeigen, verbinde deinen Computer mit einem HDMI-Kabel (oder übertrage deinen Bildschirm per Cast).

</div>

## Gottesdienst im Browser leiten

**Gottesdienst leiten** ist eine Vollbildansicht, die die Musik abspielt und die Worte Zeile für Zeile anzeigt, wobei jedes Wort beim Singen hervorgehoben wird. Sie ist für eine kleine Gruppe, einen Unterrichtsraum oder einen Hauskreis ohne Band gedacht.

1. Klicke auf der Liedseite auf **Gottesdienst leiten**. (Die Schaltfläche erscheint, wenn zum Lied eine Musik zum Mitspielen vorhanden ist.)
2. Wähle die **Tonart** und das **Tempo**. Wenn das Lied eine Klavier-Vorschau abspielt, kannst du **Klavier** oder **Orgel** auswählen.
3. Klicke auf **Strophen**, um auszuwählen, welche Strophen gesungen werden, und um ihre Reihenfolge mit den Pfeiltasten zu ändern.
4. Aktiviere **Einzählen**, wenn du vor Beginn der Musik einen Countdown möchtest.
5. Klicke auf **▶ Abspielen**.

Verwende **Leer**, um die Worte auszublenden, **Kontrast** für eine kontrastreiche Anzeige und **Vollbild**, um den Bildschirm zu füllen. Klicke auf **Auf den Fernseher bringen**, um eine Kurzanleitung zur Anzeige auf einem Fernseher zu sehen.

:::tip
Tastenkürzel: **Leertaste** Abspielen/Pause, **← →** eine Zeile verschieben, **↑ ↓** eine Strophe verschieben, **B** Leer, **H** Kontrast, **F** Vollbild, **Esc** zurück zum Lied. Klicke unten auf dem Bildschirm auf **Tasten anzeigen**, um sie zu sehen.
:::

## Liedtexte projizieren

**Projektor öffnen** zeigt jeweils einen Abschnitt der Liedtexte pro Bildschirm, und du blätterst manuell weiter. Verwende diese Ansicht, wenn du Live-Musiker hast.

1. Suche auf der Liedseite das Feld **Projektion** und klicke auf **Projektor öffnen**.
2. Drücke **F** oder klicke auf **Vollbild**, um den Bildschirm zu füllen.
3. Klicke auf den Bildschirm oder drücke die **Leertaste** oder die Taste **→**, um zur nächsten Folie zu gelangen. Drücke **←**, um zurückzugehen. Klicke unten auf einen Abschnittsnamen, um direkt dorthin zu springen.
4. Drücke **B**, um den Bildschirm leer zu schalten, und **H** für hohen Kontrast.
5. Drücke **Esc** (oder klicke auf **← Zurück zum Lied**), wenn du fertig bist.

Die untere Leiste zeigt den aktuellen Abschnitt, die Anzahl der Folien und was als Nächstes kommt. Auch die Zeile mit dem Urheberhinweis des Liedes erscheint auf dem Bildschirm.

## Folien exportieren

Das Feld **Projektion** auf der Liedseite enthält für jedes Werkzeug eine Schaltfläche. Klicke auf eine, um das Lied herunterzuladen:

| Schaltfläche | Was du erhältst |
| --- | --- |
| **FreeShow** | Eine Show-Datei zum Import in [FreeShow](https://freeshow.app) |
| **PowerPoint** | Eine PPTX-Folienpräsentation |
| **OpenLP** | Eine OpenLyrics-Datei zum Import in OpenLP |
| **ProPresenter** | Eine Textdatei zum Import in ProPresenter |
| **OnSong / PCO** | Kopiert das Lied in deine Zwischenablage, um es in OnSong oder Planning Center einzufügen |

Der Hinweis unter den Schaltflächen erklärt, wie die Folien aufgeteilt werden. Wenn für das Lied ein freigegebener Formularplan vorliegt, folgen die Folien diesem; andernfalls folgen die Folien den Strophen so, wie sie geschrieben sind. Jeder Export enthält den Urheberhinweis und die Lizenzangabe des Liedes.

:::tip
Um einen ganzen Satz auf einmal zu exportieren, in den von dir gewählten Tonarten und Abschnitten, erstelle einen [Gottesdienstplan](./service-plans.md) und verwende dort die Exportschaltflächen.
:::

## WorshipCommons-Lieder zu B1 hinzufügen

Wenn deine Gemeinde Gottesdienste in B1 Admin plant, musst du nichts herunterladen. Sonntagsbereite Lieder von WorshipCommons erscheinen in der Liedsuche von B1 Admin unter **WorshipCommons – kostenlos**. Klicke auf eines, um es deiner Liedbibliothek hinzuzufügen; es bleibt mit seiner WorshipCommons-Seite verknüpft.

Die Schritte findest du unter [Lieder in B1 Admin](../b1-admin/serving/songs.md#free-songs-from-worshipcommons).
