# Commons

<div class="article-intro">

Commons ist ein gemeinsamer Speicher für Kircheninhalte und Ressourcen.

</div>

## Funktionen

Commons bietet:

- Content-Sharing zwischen Kirchen
- Ressourcenbibliotheken
- Collaborative Tools

## Zugriff

Autorizedierte Benutzer können auf Commons-Inhalte über die ChurchApps-Anwendungen zugreifen.
