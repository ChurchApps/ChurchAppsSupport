# Architektur

<div class="article-intro">

Dokumentation der ChurchApps-Systemarchitektur für Entwickler.

</div>

## Systemkomponenten

ChurchApps besteht aus mehreren integrierten Komponenten:

- **B1 Admin** -- Verwaltungsanwendung
- **B1 Church** -- Mitgliederportal
- **B1 Checkin** -- Check-in-System
- **APIs** -- Backend-Dienste

## Sicherheit

Alle Systeme verwenden bewährte Sicherheitspraktiken einschließlich Verschlüsselung und Authentifizierung.
