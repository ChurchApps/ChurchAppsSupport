# Caddy-Proxy

<div class="article-intro">

Caddy ist ein moderner Webserver, der als Reverse Proxy für ChurchApps-Bereitstellungen verwendet wird.

</div>

## Konfiguration

Caddy wird verwendet, um:

- HTTPS-Verbindungen zu beenden
- Anfragen an Backend-Services weiterzuleiten
- Caching zu konfigurieren
- Sicherheitsheader zu setzen

## Verwendung

Caddy wird in Self-Hosted-Bereitstellungen von ChurchApps verwendet.
