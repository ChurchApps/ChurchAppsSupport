# Messaging-Endpunkte

<div class="article-intro">

Die Messaging-Endpunkte ermöglichen es, Nachrichten durch die ChurchApps API zu verwalten.

</div>

## Verfügbare Endpunkte

Die Messaging-Endpunkte bieten Funktionen zum Senden und Verwalten von Nachrichten zwischen Kirchenmitgliedern.

Siehe die vollständige API-Dokumentation für Details zu Authentifizierung und verfügbaren Parametern.
