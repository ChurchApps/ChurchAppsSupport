# Pläne

<div class="article-intro">

Im Bereich **Pläne** auf B1.church sehen Sie die Dienstpläne, denen Sie zugewiesen sind. Ob Sie im Lobpreisteam mitwirken, die Kinderarbeit unterstützen oder in einem anderen Bereich dienen: Hier erfahren Sie, wann Sie eingeplant sind, welche Position Sie besetzen und wie der Gottesdienst abläuft.

</div>

## Was Sie finden

Pläne können je nach Einrichtung Ihrer Gemeinde verschiedene Inhalte umfassen:

- **Ihre Zuweisungen** -- Sehen Sie, welchen Positionen Sie zugewiesen sind und wann Sie gebraucht werden. Jede Zuweisung zeigt Ihre Positionsbezeichnung, das Datum des Gottesdienstes und Ihren aktuellen Status (etwa Angenommen, Abgelehnt oder Antwort ausstehend). Sie können neue Zuweisungen annehmen oder ablehnen und eine bereits angenommene Zuweisung zurückgeben, wenn sich Ihre Pläne ändern.
- **Gottesdienstablauf** -- Sehen Sie den Ablauf des Gottesdienstes mit Zeitangaben, Liedinformationen und Beschreibungen der einzelnen Elemente, damit Sie den Verlauf im Voraus kennen.
- **Lehrmaterial** -- Manche Pläne enthalten zugehörige Lektions- oder Lehrinhalte von Anbietern wie [Lessons.church](../content/lessons.md). Diese Inhalte können Sie direkt im Plan ansehen.
- **Sperrtermine** -- Teilen Sie Ihren Teamleitungen mit, wann Sie nicht verfügbar sind, indem Sie Ihre Sperrtermine verwalten.
- **Vorschau auf der Startseite** -- Ihre nächsten Zuweisungen erscheinen auch im Abschnitt **Sie dienen** auf der [Startseite](../getting-started/navigating.md#home). Dort können Sie diejenigen annehmen oder ablehnen, die eine Antwort benötigen.

## Erste Schritte

Um Ihre Pläne aufzurufen, tippen Sie in der Registerleiste oder auf der Seite **Mehr** Ihres Mitgliederportals auf **Pläne**. Sie müssen [angemeldet](../getting-started/logging-in.md) sein, um Ihre Pläne zu sehen. Wenn Sie nicht angemeldet sind, werden Sie zuerst zur Anmeldung aufgefordert.

:::info
Sie sehen nur Pläne, denen Sie zugewiesen sind. Wenn keine Pläne aufgeführt werden, sind Sie noch keinem Dienstteam zugeordnet. Sprechen Sie mit Ihrer Gemeindeverwaltung oder Ihrer Dienstleitung, um sich einzubringen.
:::
