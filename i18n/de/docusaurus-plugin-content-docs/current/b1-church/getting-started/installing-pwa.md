# Als App installieren (PWA)

<div class="article-intro">

B1.church unterstützt die Installation als Progressive Web App (PWA). Damit können Sie das Mitgliederportal Ihrer Gemeinde wie eine native App auf dem Startbildschirm Ihres Telefons ablegen. So erhalten Sie ein Vollbild-Erlebnis im App-Stil, ohne den App Store oder Google Play nutzen zu müssen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen die B1.church-Adresse Ihrer Gemeinde: `https://ihregemeinde.b1.church`
- Verwenden Sie einen unterstützten Browser: **Safari** unter iOS oder **Chrome** unter Android

</div>

## Was ist eine PWA?

Eine Progressive Web App (PWA) ist eine Website, die auf Ihrem Gerät installiert werden kann und sich wie eine native App verhält. Wenn Sie B1.church als PWA installieren, dann:

- öffnet sie sich im Vollbild ohne Navigationsleisten des Browsers
- erscheint sie auf Ihrem Startbildschirm mit dem Symbol und dem Namen Ihrer Gemeinde
- passt sie sich reibungslos dem Erscheinungsbild und den Farben Ihrer Gemeinde an

:::tip
Die PWA ist eine gute Wahl, wenn Sie keine separate App aus dem App Store oder von Google Play installieren möchten. Sie bietet dasselbe Mitgliederportal-Erlebnis wie im Browser, aber in einer bequemeren Form.
:::

## Die Installationsseite

Der einfachste Weg zur Installation ist die eigene Installationsseite Ihrer Gemeinde:

```
https://yourchurchname.b1.church/mobile/install
```

Die Seite erkennt Ihr Gerät und zeigt automatisch die passende Anleitung:

- **iPhone** — Schritt-für-Schritt-Anleitung zu „Zum Home-Bildschirm“ in Safari
- **Android** — eine Schaltfläche **Auf dem Startbildschirm installieren**, die Sie mit einem Tipp in Chrome nutzen können
- **Desktop** — ein QR-Code, den Sie mit Ihrem Telefon scannen können, um dort die Installationsseite zu öffnen

Sie gelangen auf mehreren Wegen zur Installationsseite:

- Tippen Sie im Mitgliederportal auf **Mehr** und unter **Konto** auf **App installieren** (der Eintrag wird ausgeblendet, sobald die App bereits installiert ist)
- Folgen Sie einem Link, den Ihre Gemeinde per Textnachricht, E-Mail oder über den Bildschirm am Sonntag teilt
- Geben Sie die Adresse direkt in Ihren Browser ein

:::tip Für Mitarbeitende der Gemeinde
Teilen Sie den Link zur Installationsseite mit Ihrer Gemeinde -- veröffentlichen Sie ihn im Gemeindebrief, im Newsletter oder auf einer Folie. Die Seite führt jedes Mitglied durch die genauen Schritte für sein Gerät. Außerdem erreichen Sie sie über die Schnellaktion **App herunterladen** auf Ihrem B1-Admin-Dashboard.
:::

Sie können die PWA außerdem manuell über **jede Seite** Ihrer B1.church-Website installieren, indem Sie die unten beschriebenen Schritte im Browser ausführen. Die Installationsseite ist lediglich der geführte Weg dorthin.

Wenn Sie die installierte App öffnen, gelangen Sie direkt zu Ihrem Mitglieder-Dashboard, wo Sie sich anmelden können.

## Installation auf dem iPhone (iOS -- Safari)

1. Öffnen Sie **Safari** auf Ihrem iPhone und rufen Sie `https://ihregemeinde.b1.church/mobile/install` auf (ersetzen Sie `ihregemeinde` durch den Namensbestandteil der Adresse Ihrer Gemeinde).
2. Tippen Sie unten auf dem Bildschirm auf die Schaltfläche **Teilen** (das Kästchen mit dem nach oben zeigenden Pfeil).
3. Scrollen Sie im Teilen-Menü nach unten und tippen Sie auf **Zum Home-Bildschirm**.
4. Der Name wird standardmäßig auf den Namen Ihrer Gemeinde gesetzt. Tippen Sie oben rechts auf **Hinzufügen**.

Das App-Symbol erscheint auf Ihrem Startbildschirm. Tippen Sie darauf, um das Mitgliederportal im Vollbildmodus zu öffnen.

:::info
Die Installation der PWA unter iOS erfordert Safari. Wenn Sie auf Ihrem iPhone Chrome oder einen anderen Browser verwenden, wechseln Sie zuerst zu Safari.
:::

## Installation auf Android (Chrome)

1. Öffnen Sie **Chrome** auf Ihrem Android-Gerät und rufen Sie `https://ihregemeinde.b1.church/mobile/install` auf.
2. Tippen Sie auf die Schaltfläche **Auf dem Startbildschirm installieren**. (Falls die Schaltfläche nicht verfügbar ist, tippen Sie oben rechts auf das Menü mit den drei Punkten (⋮) und wählen Sie **Zum Startbildschirm hinzufügen**.)
3. Tippen Sie auf **Hinzufügen**, sobald Sie dazu aufgefordert werden.

Das App-Symbol erscheint auf Ihrem Startbildschirm. Tippen Sie darauf, um das Mitgliederportal zu öffnen.

## Nach der Installation

Nach der Installation öffnet sich die PWA direkt im Mitgliederportal, in einem eigenen Vollbildfenster. Sie können:

- sich mit Ihrem bestehenden ChurchApps-Konto anmelden
- auf alle Mitgliederfunktionen zugreifen, die Ihre Gemeinde aktiviert hat -- Gruppen, Spenden, Check-in, Dienstpläne und mehr
- jederzeit zurückkehren, indem Sie auf das Symbol auf Ihrem Startbildschirm tippen

Das App-Symbol zeigt ein **Benachrichtigungsabzeichen** (eine kleine Zahl), sobald ungelesene Nachrichten vorliegen. So sehen Sie auf einen Blick, ob etwas Neues auf Sie wartet.

:::info
Die PWA benötigt eine Internetverbindung. Anders als manche native Apps speichert sie nicht alle Inhalte für die Nutzung ohne Internet zwischen.
:::

## Was ist mit der alten B1-Mobile-App?

Die bisherige native App **B1 Mobile** für iOS und Android wurde eingestellt und wird nicht mehr aktualisiert. Die PWA ist künftig der unterstützte Zugang zum Mitgliederportal von B1.church auf dem Telefon. Sie deckt alle mitgliederseitigen Funktionen ab, die die native App bot. Wenn Sie die native App früher installiert haben, wechseln Sie einfach dann zur PWA, wenn es Ihnen passt.

Historische Informationen zur eingestellten App finden Sie auf der [Referenzseite zu B1 Mobile](/docs/b1-mobile/).
