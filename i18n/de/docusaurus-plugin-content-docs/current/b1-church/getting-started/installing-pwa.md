# Installation als App (PWA)

<div class="article-intro">

B1.church unterstützt die Installation als Progressive Web App (PWA). Damit können Sie das Mitgliederportal Ihrer Kirche wie eine native App auf dem Startbildschirm Ihres Telefons ablegen. So erhalten Sie eine Vollbild-Ansicht im Stil einer App, ohne den App Store oder Google Play zu nutzen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen die B1.church-Adresse Ihrer Kirche: `https://yourchurchname.b1.church`
- Verwenden Sie einen unterstützten Browser: **Safari** unter iOS oder **Chrome** unter Android

</div>

## Was ist eine PWA?

Eine Progressive Web App (PWA) ist eine Website, die auf Ihrem Gerät installiert werden kann und sich wie eine native App verhält. Wenn Sie B1.church als PWA installieren, gilt Folgendes:

- Die App öffnet sich im Vollbildmodus ohne Browser-Navigationsleisten
- Sie erscheint auf Ihrem Startbildschirm mit dem Symbol und dem Namen Ihrer Kirche
- Sie passt sich nahtlos an das Erscheinungsbild und die Farbthemen Ihrer Kirche an

:::tip
Die PWA ist eine gute Wahl, wenn Sie keine separate App aus dem App Store oder von Google Play installieren möchten. Sie bietet dasselbe Mitgliederportal-Erlebnis wie im Browser, aber in einer bequemeren Form.
:::

## Die Installationsseite

Der einfachste Weg zur Installation ist die eigens dafür vorgesehene Installationsseite Ihrer Kirche:

```
https://yourchurchname.b1.church/mobile/install
```

Die Seite erkennt Ihr Gerät automatisch und zeigt die passende Anleitung an:

- **iPhone** — Schritt-für-Schritt-Anleitung für „Zum Home-Bildschirm hinzufügen“ in Safari
- **Android** — eine Schaltfläche **Auf dem Startbildschirm installieren**, die Sie in Chrome mit einem Tipp betätigen
- **Desktop** — ein QR-Code, den Sie mit Ihrem Telefon scannen können, um die Installationsseite dort zu öffnen

Sie können die Installationsseite auf verschiedene Arten aufrufen:

- Tippen Sie im Mitgliederportal auf **Mehr** und dann unter **Konto** auf **App installieren** (dieser Eintrag wird ausgeblendet, sobald die App bereits installiert ist)
- Folgen Sie einem Link, den Ihre Kirche per Textnachricht, E-Mail oder über den Sonntagsbildschirm teilt
- Geben Sie die Adresse direkt in Ihren Browser ein

:::tip Für Mitarbeitende der Kirche
Teilen Sie den Link zur Installationsseite mit Ihrer Gemeinde – fügen Sie ihn in den Gemeindebrief, den Newsletter oder auf eine Folie ein. Die Seite führt jedes Mitglied Schritt für Schritt durch die Installation auf dem jeweiligen Gerät. Sie erreichen sie außerdem über die Schnellaktion **Die App herunterladen** auf Ihrem B1Admin-Dashboard.
:::

Sie können die PWA auch manuell von **jeder Seite** Ihrer B1.church-Website aus installieren, indem Sie die unten beschriebenen Browser-Schritte ausführen. Die Installationsseite ist lediglich der geführte Weg dorthin.

Wenn Sie die installierte App starten, öffnet sie sich direkt auf Ihrem Mitglieder-Dashboard, wo Sie sich anmelden können.

## Installation auf dem iPhone (iOS — Safari)

1. Öffnen Sie **Safari** auf Ihrem iPhone und rufen Sie `https://yourchurchname.b1.church/mobile/install` auf (ersetzen Sie `yourchurchname` durch die Adresse Ihrer Kirche).
2. Tippen Sie unten auf dem Bildschirm auf die Schaltfläche **Teilen** (das Feld mit dem nach oben zeigenden Pfeil).
3. Scrollen Sie im Teilen-Menü nach unten und tippen Sie auf **Zum Home-Bildschirm**.
4. Der Name wird standardmäßig auf den Namen Ihrer Kirche gesetzt. Tippen Sie oben rechts auf **Hinzufügen**.

Das App-Symbol erscheint nun auf Ihrem Startbildschirm. Tippen Sie darauf, um das Mitgliederportal im Vollbildmodus zu öffnen.

:::info
Die Installation der PWA unter iOS setzt Safari voraus. Verwenden Sie auf dem iPhone Chrome oder einen anderen Browser, wechseln Sie zunächst zu Safari.
:::

## Installation auf Android (Chrome)

1. Öffnen Sie **Chrome** auf Ihrem Android-Gerät und rufen Sie `https://yourchurchname.b1.church/mobile/install` auf.
2. Tippen Sie auf die Schaltfläche **Auf dem Startbildschirm installieren**. (Falls die Schaltfläche nicht verfügbar ist, tippen Sie oben rechts auf das Drei-Punkte-Menü (⋮) und wählen Sie **Zum Startbildschirm hinzufügen**.)
3. Tippen Sie auf **Hinzufügen**, sobald Sie dazu aufgefordert werden.

Das App-Symbol erscheint nun auf Ihrem Startbildschirm. Tippen Sie darauf, um das Mitgliederportal zu öffnen.

## Nach der Installation

Nach der Installation öffnet sich die PWA direkt im Mitgliederportal, in einem eigenen Vollbildfenster. Sie können dann:

- sich mit Ihrem bestehenden ChurchApps-Konto anmelden
- auf alle Mitgliederfunktionen zugreifen, die Ihre Kirche aktiviert hat – Gruppen, Spenden, Check-in, Dienstpläne und mehr
- jederzeit über das Symbol auf Ihrem Startbildschirm zurückkehren

Das App-Symbol zeigt ein **Benachrichtigungsabzeichen** (eine kleine Zahl), sobald ungelesene Nachrichten vorliegen. So sehen Sie auf einen Blick, ob etwas Neues auf Sie wartet.

:::info
Die PWA benötigt eine Internetverbindung. Anders als manche native Apps speichert sie nicht alle Inhalte für die Offline-Nutzung zwischen.
:::
