# Als App installieren (PWA)

<div class="article-intro">

B1.church unterstützt die Installation als Progressive Web App (PWA). So kannst du das Mitgliederportal deiner Gemeinde genau wie eine native App auf dem Startbildschirm deines Telefons ablegen. Du erhältst ein Vollbild-Erlebnis im App-Stil, ohne den App Store oder Google Play zu nutzen.

</div>

<div class="prereqs">
<h4>Bevor du beginnst</h4>

- Du brauchst die B1.church-Adresse deiner Gemeinde: `https://yourchurchname.b1.church`
- Verwende einen unterstützten Browser: **Safari** auf iOS oder **Chrome** auf Android

</div>

## Was ist eine PWA? {#what-is-a-pwa}

Eine Progressive Web App (PWA) ist eine Website, die auf deinem Gerät installiert werden kann und sich wie eine native App verhält. Wenn du B1.church als PWA installierst, gilt:

- Sie öffnet sich im Vollbild ohne Browser-Navigationsleisten
- Sie erscheint auf deinem Startbildschirm mit dem Symbol und dem Namen deiner Gemeinde
- Sie passt sich reibungslos dem Branding und den Farben deiner Gemeinde an

:::tip
Die PWA ist eine gute Option, wenn du keine separate App aus dem App Store oder von Google Play installieren möchtest. Sie bietet dasselbe Mitgliederportal-Erlebnis wie im Browser, nur in einer praktischeren Form.
:::

## Die Installationsseite {#the-install-page}

Der einfachste Weg zur Installation ist die eigens dafür vorgesehene Installationsseite deiner Gemeinde:

```
https://yourchurchname.b1.church/mobile/install
```

Die Seite erkennt dein Gerät und zeigt automatisch die passende Anleitung:

- **iPhone** -- schrittweise Anleitung in Safari zu "Zum Home-Bildschirm"
- **Android** -- eine Schaltfläche **Auf dem Startbildschirm installieren** zum Antippen in Chrome
- **Desktop** -- ein QR-Code, den du mit deinem Telefon scannen kannst, um die Installationsseite dort zu öffnen, dazu eine Schaltfläche **Auf diesem Computer installieren**, sofern dein Browser die Installation von Web-Apps unterstützt

Es gibt mehrere Wege zur Installationsseite:

- Tippe im Mitgliederportal auf **Mehr** und dann unter **Konto** auf **App installieren** (der Eintrag wird ausgeblendet, sobald die App bereits installiert ist)
- Folge einem Link, den deine Gemeinde per Text, E-Mail oder vom Bildschirm am Sonntag teilt
- Gib die Adresse direkt in deinen Browser ein

:::tip Für Gemeindemitarbeiter
Teile den Link zur Installationsseite mit deiner Gemeinde -- füge ihn in den Gemeindebrief, den Newsletter oder auf eine Folie ein. Die Seite führt jedes Mitglied durch die genauen Schritte für sein Gerät. Du erreichst sie außerdem über die Schnellaktion **App herunterladen** auf deinem B1Admin-Dashboard.
:::

Du kannst die PWA auch manuell von **jeder Seite** der B1.church-Website deiner Gemeinde über die unten beschriebenen Browserschritte installieren -- die Installationsseite ist nur der geführte Weg dafür.

Wenn du die installierte App startest, öffnet sie sich direkt auf deinem Mitglieder-Dashboard, bereit für deine Anmeldung.

## Auf dem iPhone installieren (iOS -- Safari) {#installing-on-iphone-ios--safari}

1. Öffne **Safari** auf deinem iPhone und rufe `https://yourchurchname.b1.church/mobile/install` auf (ersetze `yourchurchname` durch den Kurznamen der Adresse deiner Gemeinde).
2. Tippe unten auf dem Bildschirm auf die Schaltfläche **Teilen** (das Kästchen mit dem nach oben zeigenden Pfeil).
3. Scrolle im Teilen-Menü nach unten und tippe auf **Zum Home-Bildschirm**.
4. Der Name wird standardmäßig auf den Namen deiner Gemeinde gesetzt. Tippe oben rechts auf **Hinzufügen**.

Das App-Symbol erscheint nun auf deinem Startbildschirm. Tippe darauf, um das Mitgliederportal im Vollbildmodus zu öffnen.

:::info
Die Installation der PWA unter iOS erfordert Safari. Wenn du auf deinem iPhone Chrome oder einen anderen Browser verwendest, wechsle zuerst zu Safari.
:::

## Auf Android installieren (Chrome) {#installing-on-android-chrome}

1. Öffne **Chrome** auf deinem Android-Gerät und rufe `https://yourchurchname.b1.church/mobile/install` auf.
2. Tippe auf die Schaltfläche **Auf dem Startbildschirm installieren**. (Falls Chrome noch keine Installationsaufforderung angeboten hat, weist die Seite darauf hin -- tippe in diesem Fall oben rechts auf das Dreipunkt-Menü (⋮) und wähle stattdessen **App installieren**.)
3. Tippe auf **Installieren**, wenn du dazu aufgefordert wirst.

Das App-Symbol erscheint nun auf deinem Startbildschirm. Tippe darauf, um das Mitgliederportal zu öffnen.

## Nach der Installation {#after-installing}

Nach der Installation öffnet sich die PWA direkt im Mitgliederportal in einem eigenen Vollbildfenster. Wenn du die Installationsseite aus der installierten App öffnest, zeigt sie "Alles bereit!" anstelle der Schritte. Du kannst:

- Dich mit deinem bestehenden ChurchApps-Konto anmelden
- Auf alle Mitgliederfunktionen zugreifen, die deine Gemeinde aktiviert hat -- Gruppen, Spenden, Check-in, Dienstpläne und mehr
- Jederzeit durch Tippen auf das Symbol auf deinem Startbildschirm zurückkehren

Das App-Symbol zeigt ein **Benachrichtigungsabzeichen** (eine kleine Zahl), wenn du ungelesene Benachrichtigungen oder Nachrichten hast, sodass du auf einen Blick siehst, ob etwas Neues auf dich wartet.

:::info
Die PWA benötigt eine Internetverbindung. Anders als manche native Apps speichert sie nicht alle Inhalte für die Offline-Nutzung zwischen.
:::
