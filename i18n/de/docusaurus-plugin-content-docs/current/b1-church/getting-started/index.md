# Erste Schritte mit B1.church

<div class="article-intro">

B1.church ist das Online-Zuhause Ihrer Kirche. Hier können Sie in Verbindung mit Ihrer Gemeinde bleiben, Updates einsehen, online spenden, sich zu Services anmelden und vieles mehr. Dieser Abschnitt führt Sie durch die Grundlagen des Zugriffs auf und der Verwendung des Mitgliedertals.

</div>

## Zugriff auf die Website Ihrer Kirche

Ihre Kirche hat ihre eigene B1.church-URL, normalerweise im Format `https://yourchurchname.b1.church`. Sie können diese URL in jedem Webbrowser auf Ihrem Computer, Tablet oder Telefon besuchen. Ihre Kirchenführung oder das Willkommensteam können Ihnen die genaue Adresse mitteilen.

Wenn Sie die Website zum ersten Mal besuchen, sehen Sie die öffentliche Website Ihrer Kirche mit ihrem benutzerdefinierten Branding, Navigationsmenüs und Inhaltsseiten.

## Erstellen Sie ein Konto

Um auf das Mitgliederportal und seine Funktionen zuzugreifen, benötigen Sie ein ChurchApps-Konto.

1. Besuchen Sie die B1.church-URL Ihrer Kirche.
2. Klicken Sie auf die Schaltfläche **Anmelden** in der oberen rechten Ecke der Seite.
3. Wählen Sie auf dem Login-Bildschirm die Option zum **Registrieren** eines neuen Kontos.
4. Geben Sie Ihren **Vornamen**, **Nachnamen**, **E-Mail-Adresse** ein und wählen Sie ein **Passwort**.
5. Füllen Sie das Registrierungsformular aus.

Nach der Registrierung können Sie sich anmelden und auf das Mitgliederportal mit allen seinen Tools zugreifen.

:::tip
Wenn Ihre Kirche Sie bereits in ihr System aufgenommen hat, verwenden Sie die gleiche E-Mail-Adresse, die sie in Ihrer Datei haben. Dies verknüpft Ihr Konto mit Ihrem vorhandenen Kirchenprofil.
:::

## Was Sie tun können

Sobald Sie angemeldet sind, bietet Ihnen das Mitgliederportal Zugriff auf:

- Ihren persönlichen **Timeline** mit Updates aus Ihren Gruppen und Kirche
- **Gruppen**, denen Sie angehören, einschließlich Gespräche und Veranstaltungen
- Online **Spenden** für Spenden
- **Pläne** zeigen Ihren Freiwilligen-Zeitplan und Service-Details
- **Check-In** für Services und Veranstaltungen
- Das **Community** Verzeichnis, um andere Mitglieder zu finden und zu verbinden

## Zugriff auf Ihrem Telefon

B1.church funktioniert in jedem mobilen Browser. Für eine App-ähnlichere Erfahrung installieren Sie das Mitgliederportal Ihrer Kirche als **Progressive Web App (PWA)** – besuchen Sie `https://yourchurchname.b1.church/mobile/install` für geführte, gerätespezifische Schritte, oder fügen Sie es direkt aus Safari oder Chrome zu Ihrem Startbildschirm hinzu. Kein App Store erforderlich. Siehe [Installation als App (PWA)](./installing-pwa.md) für Anweisungen.

:::info
Die veraltete native B1 Mobile-App wurde eingestellt. Die PWA ist die unterstützte Methode zur Verwendung von B1.church auf einem Telefon – siehe die [B1 Mobile Referenzseite](/docs/b1-mobile/) für historische Dokumentation.
:::
