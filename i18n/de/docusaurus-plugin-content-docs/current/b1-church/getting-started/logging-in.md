# Anmelden

<div class="article-intro">

Wenn Sie sich bei B1.church anmelden, erhalten Sie Zugang zum Mitgliederportal, in dem Sie sehen, was für Sie ansteht, Gruppen verwalten, online spenden und alle Werkzeuge nutzen können, die Ihre Kirche eingerichtet hat. Dieser Artikel erklärt, wie Sie sich anmelden, Ihr Benutzermenü verwenden und sich wieder abmelden.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie benötigen ein ChurchApps-Konto. Informationen zum Anlegen finden Sie unter [Erste Schritte](../getting-started/).
- Sie benötigen die B1.church-Adresse Ihrer Kirche (zum Beispiel `https://ihrekirchenname.b1.church`).

</div>

## So melden Sie sich an

1. Rufen Sie die B1.church-Adresse Ihrer Kirche auf (zum Beispiel `https://ihrekirchenname.b1.church`).
2. Klicken Sie oben rechts in der Kopfzeile auf die Schaltfläche **Anmelden**.
3. Geben Sie Ihre **E-Mail-Adresse** und Ihr **Passwort** ein oder klicken Sie auf **Mit Google fortfahren** oder **Mit Microsoft fortfahren**, falls Ihre Kirche die Single-Sign-on-Anmeldung aktiviert hat.
4. Klicken Sie auf **Anmelden**.

Haben Sie die [Zwei-Faktor-Anmeldung](../../b1-admin/profile/managing-profile.md#two-factor-sign-in) aktiviert, fragt der nächste Bildschirm nach einem Code. Geben Sie den 6-stelligen Code aus Ihrer Authentifizierungs-App oder einen Ihrer Sicherungscodes ein und klicken Sie auf **Code bestätigen**. Die B1.church-App fragt den Code auf dieselbe Weise ab.

Nach der Anmeldung werden Sie zu der Seite zurückgeleitet, auf der Sie vor dem Klick auf Anmelden waren. Wenn Sie abgemeldet direkt eine Seite des Mitgliederportals aufgerufen haben, werden Sie nach der Anmeldung automatisch auf diese Seite geleitet.

## Angemeldet bleiben

Sie bleiben auf demselben Browser oder in der installierten App angemeldet, bis Sie sich abmelden -- auch wenn Sie längere Zeit nicht vorbeischauen. Ihre Sitzung wird für etwa 30 Tage Inaktivität aufbewahrt. Wenn Sie sich einmal anmelden, bleiben Sie auch angemeldet, wenn Sie zwischen der Website Ihrer Kirche und dem Mitgliederportal (`/mobile`) wechseln; Sie müssen sich also nicht an jeder Stelle erneut anmelden.

## Auf das Mitgliederportal zugreifen

Sobald Sie angemeldet sind, erreichen Sie das Mitgliederportal, indem Sie oben rechts auf der Seite auf Ihren **Namen** klicken und im Menü **Mitgliederportal** wählen. Im Mitgliederportal finden Sie alle Ihre persönlichen Werkzeuge der Kirche, darunter Ihr [Startbereich](./navigating.md), Ihre [Me-Seite](./me-page.md), die [Gruppen](../groups/), das [Geben](../giving/) und mehr.

## Ihr Benutzermenü

Nach der Anmeldung erscheint Ihr Name als Chip oben rechts. Klicken Sie darauf, um ein Menü mit folgenden Optionen zu öffnen:

- **Mitgliederportal** -- Zu Ihrem persönlichen Dashboard im Mitgliederportal.
- **Profil bearbeiten** -- Ihre Kontoeinstellungen aktualisieren oder Ihr Kirchenprofil bearbeiten.
- **Abmelden** -- Sich von Ihrem Konto abmelden.

## Administratorzugang

Wenn Sie Kirchenadministrator mit den passenden Berechtigungen sind, sehen Sie in Ihrem Benutzermenü außerdem die Option **Admin-Bereich**. Ein Klick darauf führt Sie zu B1 Admin, wo Sie die Einstellungen, Personen, Gruppen und Inhalte Ihrer Kirche verwalten können.

## Passwort vergessen

Wenn Sie Ihr Passwort nicht mehr wissen:

1. Klicken Sie auf der Anmeldeseite auf **Passwort vergessen**.
2. Geben Sie die E-Mail-Adresse ein, die mit Ihrem ChurchApps-Konto verknüpft ist, und senden Sie sie ab.
3. Prüfen Sie Ihr E-Mail-Postfach auf eine Nachricht mit einem **6-stelligen Bestätigungscode**. Der Code ist 15 Minuten gültig.
4. Geben Sie den Code auf dem Bestätigungsbildschirm ein, um sich anzumelden.
5. Sobald Sie angemeldet sind, öffnen Sie Ihr Profil, um ein neues Passwort festzulegen.

:::tip
Falls der Code nicht innerhalb weniger Minuten ankommt, prüfen Sie Ihren Spam-Ordner. Nach fünf falschen Eingaben wird der Code gesperrt -- fordern Sie in diesem Fall über die Seite Passwort vergessen einen neuen an.
:::

## Abmelden

Um sich abzumelden, klicken Sie oben rechts auf Ihren **Namen** und wählen Sie **Abmelden**. Sie werden abgemeldet und zur öffentlichen Website zurückgeleitet.
