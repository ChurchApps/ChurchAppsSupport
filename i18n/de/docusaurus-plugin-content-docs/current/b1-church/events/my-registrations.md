# Meine Registrierungen

<div class="article-intro">

Die Seite **Registrierungen** im Mitgliedsportal ist Ihre Zentrale für alle Veranstaltungen, für die Sie sich angemeldet haben. Von hier aus können Sie Ihren Status überprüfen, ein ausstehender Guthaben bezahlen, bearbeiten, wer kommt und was Sie bestellt haben, oder eine Registrierung ganz stornieren.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen [angemeldet sein](../getting-started/logging-in.md) – Gastregistrierungen werden hier nicht angezeigt
- Sie benötigen mindestens eine Veranstaltungsregistrierung. Siehe [Anmeldung zu Veranstaltungen](./registering).

</div>

## Ihre Registrierungen anzeigen

Öffnen Sie **Registrierungen** im Mitgliedsportal. Jede Registrierung wird als Karte angezeigt, die zeigt:

- Der **Veranstaltungstitel und das Datum**
- Ein **Status**-Chip – **bestätigt**, **ausstehend**, **auf der Warteliste** oder **storniert**
- Die **Mitglieder**, die Sie registriert haben
- Die Zahlungszeile – entweder die bezahlte Summe oder **Fällig** wenn noch Geld zu zahlen ist

Wenn Sie sich noch nicht zu etwas angemeldet haben, sehen Sie „Noch keine Registrierungen".

## Zahlung abschließen

Ein Knopf **Zahlung abschließen** erscheint auf jeder Registrierung mit einem ausstehenden Guthaben – meist, nachdem Sie von einer Warteliste befördert wurden, oder wenn eine Änderung durch den Stab Ihr Gesamtsumme verändert hat.

1. Klicken Sie auf **Zahlung abschließen**.
2. Überprüfen Sie die Bestellzusammenfassung, wählen Sie eine gespeicherte Karte oder geben Sie eine neue ein, und zahlen Sie.
3. Sobald das Guthaben bezahlt ist, wird die Registrierung **bestätigt**.

:::tip
Wenn sich ein Wartelistenplatz für Sie öffnet, enthält die E-Mail, die Ihre Kirche sendet, einen Link direkt zu diesem Zahlungsschritt.
:::

## Registrierung bearbeiten

Pläne ändern sich. Klicken Sie auf **Bearbeiten** einer Registrierung, um das Dialogfeld **Registrierung bearbeiten** zu öffnen, wo Sie können:

- Ihre **Kontaktdaten** aktualisieren
- Den **Namen** jedes Mitglieds und **Teilnehmertyp** ändern
- **Auswahlmengen** anpassen (Add-ons wie T-Shirts oder Mahlzeiten)

Die Kapazität gilt immer noch beim Bearbeiten – wenn ein Teilnehmertyp oder eine Option inzwischen ausverkauft ist, werden Sie aufgefordert, einen anderen zu wählen. Das Speichern berechnet Ihre Summe neu; wenn die Änderung ein Guthaben offen lässt, wird ein Knopf **Zahlung abschließen** auf der Karte angezeigt.

:::info
Das Bearbeiten belastet Ihre Karte nicht automatisch. Wenn Ihre neue Summe höher ist, zahlen Sie die Differenz mit **Zahlung abschließen**; wenn sie niedriger ist, kontaktieren Sie Ihre Kirche bezüglich einer Rückerstattung – Rückerstattungen werden vom Stab über ihren Zahlungsanbieter bearbeitet.
:::

## Registrierung stornieren

1. Klicken Sie auf **Registrierung stornieren** auf der Karte.
2. Bestätigen Sie im Dialogfeld – Die Stornierung kann nicht rückgängig gemacht werden.

Ihr Platz wird sofort freigegeben. Wenn die Veranstaltung eine Warteliste hat, wird die nächste Person automatisch befördert. Jede Zahlung, die Sie geleistet haben, wird nicht automatisch erstattet – kontaktieren Sie Ihr Kirchenbüro bezüglich Rückerstattungen.
