# Veranstaltungen und Räume anfordern

<div class="article-intro">

Wenn Ihre Kirche Buchbare Räume und Ressourcen nachverfolgt, können Sie eine Veranstaltung – mit den Räumen und Ausrüstungen, die sie benötigt – direkt aus dem Mitgliedsportal anfordern. Konflikte mit bestehenden Buchungen werden gekennzeichnet, während Sie auswählen, Ihre Anfrage geht an die Kirche zur Genehmigung, und Sie können sie von Meine Anfragen nachverfolgen oder stornieren.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen [angemeldet sein](../getting-started/logging-in.md) im Mitgliedsportal
- Ihre Kirche muss Räume oder Ressourcen in B1 Admin eingerichtet haben – die Anfrageverknüpfungen erscheinen nur, wenn dies der Fall ist

</div>

## Anfrage einreichen

1. Öffnen Sie die Seite **Mich** im Mitgliedsportal und tippen Sie unter Verknüpfungen auf **Veranstaltung anfordern**.
2. Füllen Sie die Veranstaltungsgrundlagen aus: **Veranstaltungstitel**, optional eine **Beschreibung**, die **Start** und **End**-Zeiten (oder **Ganztägig**), und ob es sich **wiederholt**.
3. Wählen Sie die **Räume** und **Ressourcen**, die Sie benötigen. Für Ressourcen können Sie eine **Menge** festlegen.
4. Achten Sie auf Konflikt-Warnungen – wenn Ihre Uhrzeit eine bestehende Buchung für einen Raum oder eine Ressource überlappt, sehen Sie *"Diese Uhrzeit steht im Konflikt mit einer bestehenden Buchung."* Sie können Ihre Uhrzeit anpassen oder etwas anderes wählen.
5. Tippen Sie auf **Anfrage einreichen**.

Nach dem Einreichen zeigt eine Zusammenfassung **Anfrage eingereicht** den Status jedes Raums und jeder Ressource, den Sie angefordert haben:

- **Genehmigt** – Sofort gebucht (der Raum oder die Ressource hat keine Genehmigungsgruppe).
- **Warte auf Genehmigung** – Jemand aus der Kirche muss zuerst zustimmen.

## Ihre Anfragen nachverfolgen

Öffnen Sie **Meine Anfragen** von der Seite Mich. Jede Anfrage zeigt die Veranstaltung, wann Sie sie angefordert haben, und einen Status-Chip:

- **Ausstehend** – In Wartestellung für eine Entscheidung
- **Genehmigt** – Ihre Buchung ist bestätigt
- **Abgelehnt** – Die Anfrage wurde abgelehnt

Während eine Anfrage noch ausstehend ist, können Sie sie mit **Anfrage stornieren** zurückziehen (Sie werden aufgefordert zu bestätigen – Die Stornierung kann nicht rückgängig gemacht werden).

:::info
Anfragen werden vom Stab auf der B1 Admin [Genehmigungsseite](../../b1-admin/calendars/approvals) überprüft. Welche Räume und Ressourcen Genehmigung erfordern, hängt von Ihrer Kirche ab – siehe [Räume und Ressourcen](../../b1-admin/calendars/rooms-resources).
:::
