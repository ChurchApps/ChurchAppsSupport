# Veranstaltungen & Räume anfragen

<div class="article-intro">

Wenn Ihre Gemeinde buchbare Räume und Ressourcen verwaltet, können Sie direkt im Mitgliederportal eine Veranstaltung anfragen -- mit den Räumen und der Ausstattung, die sie benötigt. Überschneidungen mit bestehenden Buchungen werden bei der Auswahl angezeigt. Ihre Anfrage geht zur Genehmigung an die Gemeinde, und Sie können sie unter Meine Anfragen verfolgen oder stornieren.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen [im Mitgliederportal angemeldet](../getting-started/logging-in.md) sein
- In B1 Admin müssen Räume oder Ressourcen für Ihre Gemeinde eingerichtet sein -- die Links für Anfragen erscheinen nur dann

</div>

## Eine Anfrage stellen

1. Öffnen Sie im Mitgliederportal die Seite **Ich** und tippen Sie im Abschnitt **Anfragen & Anmeldungen** auf **Veranstaltung anfragen**.
2. Füllen Sie die Grunddaten der Veranstaltung aus: **Titel der Veranstaltung**, optional eine **Beschreibung**, die **Beginn-** und **Endzeit** (oder **Ganztägig**) und ob sie sich **wiederholt**.
3. Wählen Sie die **Räume** und **Ressourcen** aus, die Sie benötigen. Bei Ressourcen können Sie eine **Menge** festlegen.
4. Achten Sie auf Konflikthinweise. Überschneidet sich Ihre Zeit mit einer bestehenden Buchung eines Raums oder einer Ressource, sehen Sie: *„Diese Zeit überschneidet sich mit einer bestehenden Buchung.“* Sie können Ihre Zeit anpassen oder etwas anderes wählen.
5. Tippen Sie auf **Anfrage senden**.

Nach dem Absenden zeigt eine Zusammenfassung **Anfrage gesendet** den Status jedes angefragten Raums und jeder Ressource:

- **Genehmigt** -- Sofort gebucht (der Raum bzw. die Ressource hat keine Genehmigungsgruppe).
- **Genehmigung ausstehend** -- Jemand aus der Gemeinde muss zuerst zustimmen.

## Ihre Anfragen verfolgen

Öffnen Sie auf der Seite Ich den Eintrag **Meine Anfragen**. Jede Anfrage zeigt die Veranstaltung, wann Sie sie gestellt haben, und eine Statusmarkierung:

- **Ausstehend** -- Wartet auf eine Entscheidung
- **Genehmigt** -- Ihre Buchung ist bestätigt
- **Abgelehnt** -- Die Anfrage wurde abgelehnt

Solange eine Anfrage noch ausstehend ist, können Sie sie mit **Anfrage zurückziehen** zurückziehen. Sie werden um eine Bestätigung gebeten. Eine Stornierung kann nicht rückgängig gemacht werden.

:::info
Anfragen werden von den Mitarbeitenden Ihrer Gemeinde auf der Seite [Genehmigungen](../../b1-admin/calendars/approvals) in B1 Admin geprüft. Welche Räume und Ressourcen eine Genehmigung benötigen, legt Ihre Gemeinde fest -- siehe [Räume & Ressourcen](../../b1-admin/calendars/rooms-resources).
:::
