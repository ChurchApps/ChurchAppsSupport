# Gruppen durchstöbern

<div class="article-intro">

Die öffentliche Gruppenseite Ihrer Kirche macht es leicht, Gruppen zu entdecken, die Sie interessieren. Gruppen sind nach Kategorien geordnet, sodass Sie schnell verschiedene Arten von Gruppen überblicken und die passende finden.

## Die Gruppenseite finden

Rufen Sie die Seite **Gruppen** auf der B1.church-Website Ihrer Kirche auf. Diese Seite ist öffentlich zugänglich, Sie müssen also nicht angemeldet sein, um zu stöbern.

## So sind die Gruppen geordnet

Gruppen werden nach **Kategorie** (auch Bezeichnung genannt) angezeigt. Kategorien legen die Administratoren Ihrer Kirche fest; sie können Bezeichnungen wie "Kleingruppen", "Dienste", "Jugend" oder "Bibelstunden" enthalten. Jede Kategorie zeigt alle Gruppen, die ihr angehören.

## Gruppenkarten lesen

Jede Gruppe wird als Karte mit folgenden Angaben angezeigt:

- **Gruppenfoto** -- Ein Titelbild, das die Gruppe repräsentiert. Ist noch kein Foto festgelegt, wird ein Standardbild angezeigt.
- **Gruppenname** -- Deutlich sichtbar über dem Foto.
- **Treffzeit** -- Wann sich die Gruppe in der Regel trifft (zum Beispiel "Mittwochs um 19 Uhr"). Ist keine Zeit angegeben, erscheint ein Platzhalter.
- **Treffpunkt** -- Wo sich die Gruppe trifft. Ist kein Ort angegeben, erscheint ein Platzhalter.
- **Beschreibung** -- Eine kurze Vorschau darauf, worum es in der Gruppe geht, auf wenige Zeilen begrenzt. Klicken Sie auf die Gruppe, um die vollständige Beschreibung zu lesen.

## Eine Gruppe ansehen

Klicken Sie auf eine beliebige Gruppenkarte, um die vollständige Detailseite der Gruppe zu öffnen. Dort finden Sie die ausführliche Beschreibung, Informationen über die Leitung der Gruppe, kommende Kalenderveranstaltungen und eine Möglichkeit, Kontakt aufzunehmen.

:::tip
Wenn Sie nach einer bestimmten Art von Gruppe suchen, überfliegen Sie zuerst die Kategorieüberschriften. So springen Sie direkt zu dem Abschnitt, der Sie interessiert, statt durch jede einzelne Gruppe zu scrollen.
:::
