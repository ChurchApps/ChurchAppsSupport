# Veranstaltungs-Zusagen

<div class="article-intro">

Gruppenveranstaltungen können Zusagen einholen, damit die Leiter wissen, wer kommt. Im Kalender Ihrer Gruppe fragt jede bevorstehende Veranstaltung „Nehmen Sie teil?" — antworten Sie mit einem Tipp, ändern Sie jederzeit Ihre Meinung, und sehen Sie auf einen Blick, wie viele andere teilnehmen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen [angemeldet](../getting-started/logging-in.md) und Mitglied der Gruppe sein
- Für die Veranstaltung müssen Zusagen zugelassen sein (standardmäßig aktiviert; Leiter können sie pro Veranstaltung deaktivieren)

</div>

## Auf eine Veranstaltung antworten

1. Öffnen Sie Ihre Gruppe im Mitgliederportal und wechseln Sie zur Ansicht **Veranstaltungen** / Kalender.
2. Jede bevorstehende Veranstaltungskarte zeigt **Nehmen Sie teil?** mit drei Schaltflächen: **Ich nehme teil**, **Vielleicht** und **Ich kann nicht**.
3. Tippen Sie Ihre Antwort an. Ihre Wahl wird hervorgehoben, und jede Schaltfläche zeigt eine laufende Anzahl, wie viele Personen diese Antwort gegeben haben.
4. Tippen Sie erneut auf Ihre hervorgehobene Antwort, um sie zu löschen, oder tippen Sie auf eine andere Schaltfläche, um Ihre Antwort zu ändern.

Ihre Zusage gilt für diesen konkreten Termin — bei einem wöchentlichen Treffen beantworten Sie die Veranstaltung jeder Woche separat.

## Für Gruppenleiter

- **Antworten ansehen** -- Leiter sehen auf jeder Veranstaltungskarte eine Schaltfläche **Antworten ansehen**. Sie öffnet die Übersicht **Antworten**, die alle nach Antwort auflistet — Ich nehme teil, Vielleicht und Ich kann nicht. Falls noch niemand geantwortet hat, wird „Noch keine Antworten" angezeigt.
- **Zusagen ein- oder ausschalten** -- Verwenden Sie beim Erstellen oder Bearbeiten einer Veranstaltung den Schalter **Zusagen zulassen**. Veranstaltungen mit deaktivierten Zusagen zeigen keine Antwortschaltflächen. Mitarbeiter, die Veranstaltungen in B1 Admin im großen Umfang erstellen, haben dieselbe Option — siehe [Gruppenkalender](../../b1-admin/groups/group-calendar#event-rsvps).

:::tip
Zusagen sind eine leichtgewichtige Teilnehmerzählung. Wenn Ihre Veranstaltung Anmeldedetails, Kapazitätsmanagement oder Zahlungen benötigt, verwenden Sie stattdessen die [Veranstaltungsanmeldung](../events/registering).
:::
