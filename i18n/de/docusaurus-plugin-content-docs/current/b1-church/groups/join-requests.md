# Beitrittsgenehmigung beantragen

<div class="article-intro">

Einige Gruppen erfordern Genehmigung, bevor Sie Mitglied werden können. Wenn eine Gruppe diese Einstellung hat, reichen Sie eine Beitragsanfrage ein – optional mit einer Nachricht an den Gruppenleiter – und warten auf die Genehmigung oder Ablehnung des Leiters. Sie können den Status Ihrer ausstehenden Anfragen anzeigen und diese jederzeit stornieren.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen [angemeldet sein](../getting-started/logging-in.md) bei Ihrem B1.church-Konto, um die Beitrittsgenehmigung für eine Gruppe zu beantragen.

</div>

## Beitreten versus Beitrittsgenehmigung anfordern

Gruppen können unterschiedliche Beitrittsrichtlinien haben, die von ihren Administratoren festgelegt wurden:

- **Offen** – Klicken Sie auf der Gruppendetailseite auf **Gruppe beitreten** und Sie werden sofort als Mitglied hinzugefügt.
- **Genehmigung erforderlich** – Klicken Sie auf **Beitrittsgenehmigung beantragen**, um eine Anfrage einzureichen, die ein Gruppenleiter genehmigen muss, bevor Sie Mitglied werden.
- **Geschlossen** – Es wird kein Beitragsknopf angezeigt. Mitglieder müssen manuell von Leitern hinzugefügt werden.

## Beitragsanfrage einreichen

1. Suchen Sie die Gruppe, der Sie beitreten möchten. Siehe [Gruppen durchsuchen](./browsing-groups.md), wenn Sie Hilfe benötigen, um sie zu finden.
2. Öffnen Sie die Detailseite der Gruppe.
3. Klicken Sie auf **Beitrittsgenehmigung beantragen**.
4. Ein Dialogfeld wird angezeigt, in dem Sie optional eine Nachricht an den Gruppenleiter schreiben können, um zu erklären, warum Sie der Gruppe beitreten möchten.
5. Klicken Sie auf **Einreichen**, um Ihre Anfrage zu senden.

Die Leiter der Gruppe erhalten eine Benachrichtigung über Ihre Anfrage. Sobald sie diese überprüft haben, erhalten Sie eine Benachrichtigung mit dem Ergebnis.

:::tip
Eine kurze Nachricht einzufügen – wie zum Beispiel, wie Sie von der Gruppe gehört haben oder was Sie daraus erwarten – kann dem Leiter helfen, schneller eine Entscheidung zu treffen.
:::

## Überprüfung des Status Ihrer Anfragen

Nachdem Sie eine Anfrage eingereicht haben, können Sie den Status auf der Seite **Gruppen** anzeigen:

1. Navigieren Sie zur Seite **Gruppen** auf der B1.church-Website Ihrer Kirche.
2. Scrollen Sie zum Abschnitt **Ausstehende Anfragen** nach unten.
3. Jede ausstehende Anfrage zeigt den Gruppennamen und das Datum, an dem Sie ihn eingereicht haben.

Wenn eine Anfrage genehmigt oder abgelehnt wurde, erhalten Sie eine Benachrichtigung – genehmigte Anfragen machen Sie zum Mitglied der Gruppe.

## Stornierung einer Anfrage

Wenn Sie Ihre Meinung ändern, bevor ein Leiter Ihre Anfrage überprüft:

1. Gehen Sie zur Seite **Gruppen**.
2. Finden Sie Ihre Anfrage im Abschnitt **Ausstehende Anfragen**.
3. Klicken Sie auf **Stornieren** neben der Anfrage.

Die Anfrage wird sofort zurückgezogen und der Leiter wird sie nicht mehr sehen.
