# Gruppen

<div class="article-intro">

Gruppen verbinden Sie mit anderen Mitgliedern Ihrer Kirche. Treten Sie Gruppen bei, um an Aktivitäten teilzunehmen, mit anderen zu kommunizieren, Veranstaltungen zu besuchen und an Ihrer Kirche teilzuhaben.

</div>

## Durchsuchen Sie verfügbare Gruppen

Die Seite **Gruppen** zeigt alle Gruppen in Ihrer Kirche an, die Sie sehen können.

1. Klicken Sie auf die Registerkarte **Gruppen**.
2. Durchsuchen Sie die Liste oder verwenden Sie die Suchleiste, um Gruppen nach Name zu finden.
3. Klicken Sie auf einen Gruppennamen, um weitere Details anzuzeigen.

## Treten Sie einer Gruppe bei

Je nachdem, wie eine Gruppe konfiguriert ist, können Sie möglicherweise sofort beitreten oder müssen die Genehmigung eines Leiters anfordern:

1. Suchen Sie die Gruppe, der Sie beitreten möchten.
2. Klicken Sie auf die Gruppe, um sie zu öffnen.
3. Klicken Sie auf **Der Gruppe beitreten** oder **Beitrittanfrage**.
4. Wenn ein Leiter die Anfrage genehmigen muss, werden Sie benachrichtigt, wenn Ihre Anfrage genehmigt wird.

:::tip
Einige Gruppen können verborgen sein – fragen Sie Ihren Kirchenleiter nach Gruppen, die Sie möglicherweise nicht in der Standardliste sehen.
:::

## Kommunizieren Sie mit Ihrer Gruppe

Nachdem Sie einer Gruppe beigetreten sind, können Sie mit anderen Mitgliedern kommunizieren:

- **Sehen Sie die Mitgliederliste** – Wer ist in dieser Gruppe?
- **Starten Sie eine Konversation** – Senden Sie Nachrichten an die Gruppe
- **Sehen Sie Veranstaltungen** – Kommende Treffen und Aktivitäten

Siehe [Gruppengespräche](./conversations.md) für mehr Details.
