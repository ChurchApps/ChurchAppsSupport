# Gruppengespräche

<div class="article-intro">

Der Tab Gespräche auf Ihrer Gruppenseite ist ein Bereich, in dem Gruppenmitglieder Nachrichten posten und miteinander interagieren können. Nutzen Sie Gespräche, um Themen zu besprechen, Updates zu teilen und zwischen den Treffen mit Ihrer Gruppe in Verbindung zu bleiben.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen bei Ihrem B1.church-Konto [angemeldet](../getting-started/logging-in.md) sein.
- Sie müssen Mitglied der Gruppe sein, um auf den Tab Gespräche zuzugreifen. Siehe [Gruppendetails](./group-details.md) für Informationen zum Beitritt zu einer Gruppe.

</div>

## Zugriff auf Gespräche

1. Navigieren Sie zur Gruppendetailseite, indem Sie auf eine Gruppe auf der [Gruppenseite](./browsing-groups.md) klicken.
2. Stellen Sie sicher, dass Sie angemeldet sind.
3. Klicken Sie in der Seitenleiste auf den Tab **Gespräche**.

## Diskussionen und Ankündigungen

Der Tab Gespräche kann zwei Unter-Tabs anzeigen:

- **Diskussionen** -- Ein Bereich, in dem jedes Gruppenmitglied Nachrichten posten und auf andere antworten kann. Dies ist die Standardansicht und immer verfügbar.
- **Ankündigungen** -- Nachrichten, die von Gruppenleitern gepostet werden und für alle Mitglieder wichtig sind. Reguläre Mitglieder können Ankündigungen lesen, aber nur Leiter können sie erstellen.

Wenn keine Ankündigungen vorhanden sind und Sie kein Leiter sind, sehen Sie nur die Diskussionsansicht ohne Tab-Leiste.

## Eine Nachricht posten

1. Öffnen Sie den Tab **Gespräche** auf Ihrer Gruppenseite.
2. Stellen Sie sicher, dass Sie sich im Unter-Tab **Diskussionen** befinden (falls die Tab-Leiste sichtbar ist).
3. Geben Sie Ihre Nachricht in das Textfeld ein.
4. Senden Sie Ihre Nachricht ab, um sie mit der Gruppe zu teilen.

Ihre Nachricht ist für alle Mitglieder der Gruppe sichtbar.

## Ihre Nachrichten bearbeiten oder löschen

Sie können jede von Ihnen geposteter Nachricht bearbeiten oder löschen:

1. Bewegen Sie den Mauszeiger über Ihre Nachricht (oder tippen Sie sie auf Mobilgeräten an), um die Schaltfläche **Weitere Optionen** (⋮) anzuzeigen.
2. Klicken Sie auf die Schaltfläche, um das Nachrichtenmenü zu öffnen.
3. Wählen Sie **Bearbeiten**, um den Nachrichtentext zu ändern, oder **Löschen**, um sie zu entfernen.
   - Beim Bearbeiten wird der Nachrichtentext wieder in das Eingabefeld geladen. Nehmen Sie Ihre Änderungen vor und senden Sie sie ab, um sie zu speichern.
   - Beim Löschen erscheint ein Bestätigungsdialog. Klicken Sie auf **Bestätigen**, um die Nachricht dauerhaft zu entfernen.

:::info
Sie können nur Ihre eigenen Nachrichten bearbeiten oder löschen. Bei Nachrichten anderer Mitglieder werden die Optionen zum Bearbeiten/Löschen nicht angezeigt.
:::

## Auf Nachrichten reagieren

Im Gruppenchat können Sie auf jede Nachricht mit einem Emoji reagieren:

1. Tippen Sie eine Nachricht an oder bewegen Sie den Mauszeiger darüber und wählen Sie **Reaktion hinzufügen**.
2. Wählen Sie eines von sechs Emojis: 👍 ❤️ 😂 🎉 🙏 😮.

Reaktionen erscheinen als kleine Chips unter der Nachricht mit einer Zählung, wie viele Personen jedes davon verwendet haben. Ihre eigene Reaktion wird hervorgehoben -- tippen Sie auf den Chip (oder wählen Sie erneut dasselbe Emoji), um sie zu entfernen, oder wählen Sie ein anderes Emoji, um eine weitere hinzuzufügen. Reaktionen erscheinen live für alle im Chat.

:::tip
Gruppengespräche erscheinen auch auf Ihrer [Zeitleiste](../community/timeline.md), sodass Sie Diskussionen verfolgen können, ohne jede Gruppe einzeln zu besuchen.
:::

## Funktionen für Leiter

Wenn Sie ein Gruppenleiter sind, verfügen Sie im Tab Gespräche über zusätzliche Möglichkeiten:

- **Ankündigungen posten** -- Wechseln Sie zum Unter-Tab **Ankündigungen** und posten Sie Nachrichten, die alle Gruppenmitglieder lesen können.
- **Diskussionen posten** -- Sie können sich auch wie jedes andere Mitglied an regulären Diskussionen beteiligen.

:::info
Gespräche sind gruppenspezifisch. Nachrichten, die Sie in einer Gruppe posten, erscheinen nicht in den Gesprächen einer anderen Gruppe.
:::
