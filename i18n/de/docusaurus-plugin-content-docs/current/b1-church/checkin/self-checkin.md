# Selbst-Check-in

<div class="article-intro">

Mit dem Selbst-Check-in erfassen Sie in wenigen Schritten Ihre eigene Anwesenheit und die Ihres Haushalts. Es ist eine schnelle Alternative zu einem Kiosk vor Ort in der Gemeinde.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen [angemeldet](../getting-started/logging-in.md) bei Ihrem B1.church-Konto sein.
- Die Mitglieder Ihres Haushalts müssen mit Ihrem Konto verknüpft sein. Fehlt ein Familienmitglied, bitten Sie Ihre Gemeindeadministration, es Ihrem Haushalt hinzuzufügen.

## Der Check-in-Ablauf

Der Check-in folgt einem einfachen Ablauf in drei Schritten. Öffnen Sie **Check-in** über die [Reiterleiste oder die Seite Mehr](../getting-started/navigating.md), um zu beginnen.

### Schritt 1: Einen Gottesdienst auswählen

Wenn Sie die Check-in-Seite öffnen, sehen Sie eine Liste der verfügbaren Gottesdienste (zum Beispiel „Sonntagmorgen“ oder „Mittwochabend“). Jede Gottesdienstkarte zeigt den Namen des Gottesdienstes und, falls Ihre Gemeinde mehrere Standorte hat, den Standort.

Tippen Sie auf einen Gottesdienst, um ihn auszuwählen und zum nächsten Schritt zu gelangen.

### Schritt 2: Haushaltsmitglieder und Gruppen auswählen

Nach der Auswahl eines Gottesdienstes sehen Sie unter **Wer ist hier** die Mitglieder Ihres Haushalts. Für jede anwesende Person gilt:

1. Tippen Sie auf ein Haushaltsmitglied, um seinen Eintrag aufzuklappen.
2. Sie sehen die verfügbaren **Gottesdienstzeiten** für den gewählten Gottesdienst. Hat Ihre Gemeinde für eine Gottesdienstzeit einen Check-in-Zeitplan festgelegt, können Sie sie nur auswählen, solange das Check-in dafür geöffnet ist (zum Beispiel von 30 Minuten vor dem Gottesdienst bis kurz nach dessen Ende). Außerhalb dieses Zeitfensters wird die Gottesdienstzeit als **Geschlossen** angezeigt, mit dem Zeitpunkt der Öffnung, sofern bekannt, zum Beispiel **Geschlossen · öffnet So 9:30**.
3. Tippen Sie neben einer Gottesdienstzeit auf **Gruppe auswählen**, um die Gruppe zu wählen, in die die Person eingecheckt werden soll (etwa „Hauptgottesdienst“, „Kinderraum 1“ oder „Jugendgruppe“).
4. Wiederholen Sie dies für jedes Haushaltsmitglied, das anwesend ist.

Sie müssen nicht jedes Haushaltsmitglied einchecken. Klappen Sie nur die Einträge der Personen auf, die tatsächlich anwesend sind, und weisen Sie nur ihnen Gruppen zu.

Wer für diesen Gottesdienst heute schon eingecheckt ist, zeigt neben dem Namen ein Abzeichen **Bereits eingecheckt**.

### Schritt 3: Bestätigung

Wenn Sie für alle anwesenden Personen eine Gruppe ausgewählt haben, tippen Sie auf die Schaltfläche unten auf der Seite. Sie zählt die ausgewählten Personen, zum Beispiel **1 Person einchecken** oder **3 Personen einchecken**.

Wurde eine der ausgewählten Personen für diesen Gottesdienst heute bereits eingecheckt, nennt ein Fenster **Bereits eingecheckt** diese Personen zuerst. Tippen Sie auf **Erneut einchecken**, um deren Gruppen zu aktualisieren, oder auf **Abbrechen**, um zurückzugehen.

Anschließend sehen Sie eine Bestätigung, dass Ihr Check-in abgeschlossen ist und Ihre Anwesenheit gespeichert wurde. Nach kurzer Zeit kehrt die Seite zur Gottesdienstliste zurück, bereit für den nächsten Check-in.

Druckt Ihre Gemeinde an einer Check-in-Station Namensschilder, sehen Sie stattdessen **Sie sind eingecheckt!** mit einem QR-Code und einem Sicherheitscode. Zeigen Sie den Code an einer Check-in-Station, um Ihre Namensschilder zu drucken, und tippen Sie dann auf **Fertig**. An einem B1-Checkin-Kiosk tippen Sie auf **Code scannen** und halten den QR-Code vor die Kamera. Siehe [Etiketten für einen Telefon-Check-in drucken](../../b1-checkin/check-in/looking-up-members.md#printing-labels-for-a-phone-check-in).

Ist Ihr Haushalt für den gewählten Gottesdienst bereits eingecheckt, erscheint neben der Überschrift **Wer ist hier** ein Link **Check-in-Code anzeigen**. Tippen Sie darauf, um QR-Code und Sicherheitscode erneut anzuzeigen, zum Beispiel wenn Sie die Seite geschlossen haben, bevor Sie eine Check-in-Station erreicht haben.

:::tip
Wenn Sie eine Gruppenauswahl ändern möchten, bevor Sie den Check-in abschließen, tippen Sie neben einer beliebigen Gottesdienstzeit auf die Schaltfläche **Ändern**, um eine andere Gruppe zu wählen.
:::

## Wissenswertes

- Sie können nur Haushaltsmitglieder einchecken, die mit Ihrem Konto verknüpft sind. Fehlt ein Familienmitglied, bitten Sie Ihre Gemeindeadministration, es Ihrem Haushalt hinzuzufügen.
- Erscheinen auf der Check-in-Seite keine Gottesdienste, hat Ihre Gemeinde derzeit möglicherweise keine Gottesdienste für den Check-in eingerichtet.
- Wählen Sie einen Gottesdienst und sehen Sie eine Meldung wie „Check-in öffnet So 9:30.“ (oder „Das Check-in ist für diesen Gottesdienst gerade nicht geöffnet.“), liegt derzeit keine Gottesdienstzeit dieses Gottesdienstes innerhalb ihres Check-in-Zeitfensters. Versuchen Sie es erneut, sobald das Check-in geöffnet ist.
- Hat Ihr Haushalt für eine frühere Gottesdienstzeit eingecheckt, können Sie zurückkommen und für eine spätere Gottesdienstzeit einchecken, sobald diese geöffnet ist, auch wenn die frühere bereits geschlossen ist.
- Ist ein von Ihnen gewählter Raum voll oder für den Check-in geschlossen, sehen Sie die Meldung „Ein von Ihnen gewählter Raum ist voll oder für den Check-in geschlossen. Bitte wenden Sie sich an eine ehrenamtliche Person.“
- Hat ein Kinderraum nicht genug eingecheckte ehrenamtliche Betreuende für ein weiteres Kind, sehen Sie eine Meldung mit dem Namen des Raums, zum Beispiel „Kinderraum 1 hat im Moment nicht genug ehrenamtliche Betreuende für ein weiteres Kind. Bitte wählen Sie einen anderen Raum oder wenden Sie sich an eine ehrenamtliche Person.“

:::warning
Der Check-in ist nur verfügbar, wenn Ihre Gemeinde aktive Gottesdienste eingerichtet hat. Sehen Sie keine Gottesdienste, fragen Sie im Gemeindebüro nach, ob der Selbst-Check-in aktiviert ist.
:::
