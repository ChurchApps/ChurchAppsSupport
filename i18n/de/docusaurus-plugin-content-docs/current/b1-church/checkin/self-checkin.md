# Selbst-Check-in

<div class="article-intro">

Mit dem Selbst-Check-in können Sie die Anwesenheit für sich und Ihren Haushalt in wenigen Schritten erfassen. Es ist eine schnelle Alternative zu einem physischen Kiosk in der Gemeinde.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen bei Ihrem B1.church-Konto [angemeldet](../getting-started/logging-in.md) sein.
- Die Mitglieder Ihres Haushalts müssen mit Ihrem Konto verknüpft sein. Fehlt ein Familienmitglied, bitten Sie Ihren Gemeindeadministrator, es Ihrem Haushalt hinzuzufügen.

</div>

## Der Check-in-Ablauf

Der Selbst-Check-in folgt einem einfachen Ablauf in drei Schritten. Öffnen Sie **Check-in** über die [Registerleiste oder die Seite Mehr](../getting-started/navigating.md), um zu beginnen.

### Schritt 1: Gottesdienst auswählen

Wenn Sie die Check-in-Seite öffnen, sehen Sie eine Liste der verfügbaren Gottesdienste (zum Beispiel „Sonntagmorgen“ oder „Mittwochabend“). Jede Gottesdienstkarte zeigt den Namen des Gottesdienstes und, falls Ihre Gemeinde mehrere Standorte hat, den Standort.

Klicken Sie auf einen Gottesdienst, um ihn auszuwählen und zum nächsten Schritt zu gelangen.

### Schritt 2: Haushaltsmitglieder und Gruppen auswählen

Nach der Auswahl eines Gottesdienstes sehen Sie die Mitglieder Ihres Haushalts unter **Wer ist hier?**. Für jede anwesende Person gilt:

1. Tippen Sie auf ein Haushaltsmitglied, um seinen Eintrag aufzuklappen.
2. Sie sehen die verfügbaren **Gottesdienstzeiten** für den von Ihnen gewählten Gottesdienst. Hat Ihre Gemeinde einen Check-in-Zeitplan für eine Gottesdienstzeit festgelegt, können Sie diese nur auswählen, solange der Check-in dafür geöffnet ist (zum Beispiel von 30 Minuten vor dem Gottesdienst bis kurz nach dessen Ende). Außerhalb dieses Fensters wird die Gottesdienstzeit als **Geschlossen** angezeigt, mit dem Öffnungszeitpunkt, sofern bekannt – zum Beispiel **Geschlossen · öffnet So 9:30 Uhr**.
3. Tippen Sie neben einer Gottesdienstzeit auf **Gruppe auswählen**, um festzulegen, in welche Gruppe die Person eingecheckt werden soll (etwa „Hauptgottesdienst“, „Kinderraum 1“ oder „Jugendgruppe“).
4. Wiederholen Sie dies für jedes anwesende Haushaltsmitglied.

Sie müssen nicht jedes Haushaltsmitglied einchecken – erweitern und weisen Sie Gruppen nur den Personen zu, die tatsächlich anwesend sind.

### Schritt 3: Bestätigung

Sobald Sie allen anwesenden Personen eine Gruppe zugewiesen haben, tippen Sie auf die Schaltfläche am unteren Seitenrand. Sie zeigt die Anzahl der ausgewählten Personen an, zum Beispiel **1 Person einchecken** oder **3 Personen einchecken**.

Anschließend sehen Sie eine Bestätigung, dass Ihr Check-in abgeschlossen ist und Ihre Anwesenheit gespeichert wurde. Nach kurzer Zeit kehrt die Seite zur Gottesdienstliste zurück, bereit für den nächsten Check-in.

Druckt Ihre Gemeinde Namensschilder an einer Check-in-Station, sehen Sie stattdessen **Sie sind eingecheckt!** mit einem QR-Code und einem Sicherheitscode. Zeigen Sie den Code an einer Check-in-Station, um Ihre Namensschilder zu drucken, und tippen Sie dann auf **Fertig**. Am B1-Checkin-Kiosk tippen Sie auf **Code scannen** und halten den QR-Code vor die Kamera – siehe [Etiketten für einen Check-in per Telefon drucken](../../b1-checkin/check-in/looking-up-members#printing-labels-for-a-phone-check-in).

Ist Ihr Haushalt für den von Ihnen gewählten Gottesdienst bereits eingecheckt, erscheint neben der Überschrift **Wer ist hier?** ein Link **Check-in-Code anzeigen**. Tippen Sie darauf, um den QR-Code und den Sicherheitscode wieder anzuzeigen, etwa wenn Sie die Seite geschlossen haben, bevor Sie zu einer Check-in-Station gelangt sind.

:::tip
Wenn Sie eine Gruppenauswahl ändern möchten, bevor Sie den Check-in abschließen, tippen Sie bei einer beliebigen Gottesdienstzeit auf die Schaltfläche **Ändern**, um eine andere Gruppe auszuwählen.
:::

## Wissenswertes

- Sie können nur Haushaltsmitglieder einchecken, die mit Ihrem Konto verknüpft sind. Fehlt ein Familienmitglied, bitten Sie Ihren Gemeindeadministrator, es Ihrem Haushalt hinzuzufügen.
- Erscheinen auf der Check-in-Seite keine Gottesdienste, ist für Ihre Gemeinde derzeit möglicherweise kein Gottesdienst für den Check-in eingerichtet.
- Wählen Sie einen Gottesdienst und sehen Sie eine Meldung wie „Check-in öffnet So 9:30 Uhr.“ (oder „Der Check-in für diesen Gottesdienst ist derzeit nicht geöffnet.“), liegt derzeit keine Gottesdienstzeit dieses Gottesdienstes innerhalb ihres Check-in-Fensters. Versuchen Sie es erneut, sobald der Check-in geöffnet ist.
- Hat Ihr Haushalt für eine frühere Gottesdienstzeit eingecheckt, können Sie später für eine spätere Gottesdienstzeit einchecken, sobald diese geöffnet ist – auch wenn die frühere bereits geschlossen ist.
- Ist ein von Ihnen gewählter Raum voll oder geschlossen, sehen Sie die Meldung „Ein von Ihnen gewählter Raum ist für den Check-in voll oder geschlossen. Bitte wenden Sie sich an eine ehrenamtliche Person.“

:::warning
Der Check-in ist nur verfügbar, wenn für Ihre Gemeinde aktive Gottesdienste eingerichtet sind. Sehen Sie keine Gottesdienste, fragen Sie im Gemeindebüro nach, ob der Selbst-Check-in aktiviert ist.
:::
