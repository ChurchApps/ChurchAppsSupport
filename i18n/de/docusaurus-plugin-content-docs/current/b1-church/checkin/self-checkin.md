# Selbst-Check-in

<div class="article-intro">

Mit dem Selbst-Check-in können Sie Ihre Anwesenheit und die Ihres Haushalts in nur wenigen Schritten erfassen. Es ist eine schnelle Alternative zur Nutzung eines physischen Kiosks in der Gemeinde.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen in Ihrem B1.church-Konto [angemeldet](../getting-started/logging-in.md) sein.
- Ihre Haushaltsmitglieder müssen mit Ihrem Konto verknüpft sein. Fehlt ein Familienmitglied, bitten Sie Ihren Gemeindeadministrator, es Ihrem Haushalt hinzuzufügen.

</div>

## Der Check-in-Ablauf

Der Check-in besteht aus einem einfachen Drei-Schritte-Verfahren. Öffnen Sie **Check-In** über die [Tab-Leiste oder die Seite Mehr](../getting-started/navigating.md), um zu beginnen.

### Schritt 1: Einen Gottesdienst auswählen

Wenn Sie die Check-in-Seite öffnen, sehen Sie eine Liste der verfügbaren Gottesdienste (zum Beispiel „Sonntagmorgen“ oder „Mittwochabend“). Jede Gottesdienstkarte zeigt den Namen des Gottesdienstes und, falls Ihre Gemeinde mehrere Standorte hat, den Campus an.

Klicken Sie auf einen Gottesdienst, um ihn auszuwählen und zum nächsten Schritt zu gelangen.

### Schritt 2: Haushaltsmitglieder und Gruppen auswählen

Nachdem Sie einen Gottesdienst ausgewählt haben, sehen Sie unter **Wer ist hier** Ihre Haushaltsmitglieder. Gehen Sie für jede teilnehmende Person wie folgt vor:

1. Tippen Sie auf ein Haushaltsmitglied, um dessen Eintrag zu erweitern.
2. Sie sehen die verfügbaren **Gottesdienstzeiten** für den gewählten Gottesdienst. Hat Ihre Gemeinde für eine Gottesdienstzeit einen Check-in-Zeitplan festgelegt, können Sie diese nur auswählen, solange der Check-in dafür geöffnet ist (zum Beispiel von 30 Minuten vor dem Gottesdienst bis kurz nach dessen Ende). Außerhalb dieses Zeitfensters wird die Gottesdienstzeit mit **Geschlossen** angezeigt, zusammen mit dem Öffnungszeitpunkt, sofern bekannt – zum Beispiel **Geschlossen · öffnet So. 9:30 Uhr**.
3. Tippen Sie neben einer Gottesdienstzeit auf **Gruppe auswählen**, um festzulegen, in welche Gruppe die Person eingecheckt werden soll (zum Beispiel „Hauptgottesdienst“, „Kinderraum 1“ oder „Jugendgruppe“).
4. Wiederholen Sie dies für jedes anwesende Haushaltsmitglied.

Sie müssen nicht jedes Haushaltsmitglied einchecken. Erweitern Sie nur die Einträge und weisen Sie Gruppen nur den Personen zu, die tatsächlich anwesend sind.

Wer für diesen Gottesdienst heute bereits eingecheckt wurde, erhält neben dem Namen ein Abzeichen **Bereits eingecheckt**.

### Schritt 3: Bestätigung

Sobald Sie für alle anwesenden Personen Gruppen ausgewählt haben, tippen Sie auf die Schaltfläche am unteren Seitenrand. Sie zeigt die Anzahl der ausgewählten Personen an, zum Beispiel **1 Person einchecken** oder **3 Personen einchecken**.

Wenn eine ausgewählte Person für diesen Gottesdienst heute bereits eingecheckt wurde, nennt ein Fenster **Bereits eingecheckt** zuerst diese Person. Tippen Sie auf **Erneut einchecken**, um deren Gruppen zu aktualisieren, oder auf **Abbrechen**, um zurückzukehren.

Anschließend erhalten Sie eine Bestätigung, dass Ihr Check-in abgeschlossen ist und Ihre Anwesenheit gespeichert wurde. Nach kurzer Zeit kehrt die Seite zur Gottesdienstliste zurück, bereit für den nächsten Check-in.

Druckt Ihre Gemeinde an einer Check-in-Station Namensschilder aus, sehen Sie stattdessen **Sie sind eingecheckt!** mit einem QR-Code und einem Sicherheitscode. Zeigen Sie den Code an einer Check-in-Station vor, um Ihre Namensschilder zu drucken, und tippen Sie anschließend auf **Fertig**. An einem B1 Checkin-Kiosk tippen Sie auf **Code scannen** und halten den QR-Code vor die Kamera. Siehe [Drucken von Etiketten für einen Check-in per Telefon](../../b1-checkin/check-in/looking-up-members.md#printing-labels-for-a-phone-check-in).

Ist Ihr Haushalt für den gewählten Gottesdienst bereits eingecheckt, erscheint neben der Überschrift **Wer ist hier** ein Link **Check-in-Code anzeigen**. Tippen Sie darauf, um den QR-Code und den Sicherheitscode erneut anzuzeigen, zum Beispiel wenn Sie die Seite geschlossen haben, bevor Sie eine Check-in-Station erreicht haben.

:::tip
Wenn Sie eine Gruppenauswahl ändern möchten, bevor Sie den Check-in abschließen, tippen Sie neben einer Gottesdienstzeit auf die Schaltfläche **Ändern**, um eine andere Gruppe auszuwählen.
:::

## Wissenswertes

- Sie können nur Haushaltsmitglieder einchecken, die mit Ihrem Konto verknüpft sind. Fehlt ein Familienmitglied, bitten Sie Ihren Gemeindeadministrator, es Ihrem Haushalt hinzuzufügen.
- Erscheinen auf der Check-in-Seite keine Gottesdienste, ist Ihrer Gemeinde derzeit möglicherweise kein Gottesdienst für den Check-in konfiguriert.
- Wenn Sie einen Gottesdienst auswählen und eine Meldung wie „Check-in öffnet So. 9:30 Uhr.“ (oder „Der Check-in ist für diesen Gottesdienst derzeit nicht geöffnet.“) sehen, liegt derzeit keine der Gottesdienstzeiten innerhalb ihres Check-in-Zeitfensters. Versuchen Sie es erneut, sobald der Check-in geöffnet ist.
- Hat sich Ihr Haushalt für eine frühere Gottesdienstzeit eingecheckt, können Sie später zurückkehren und sich für eine spätere Gottesdienstzeit einchecken, sobald diese geöffnet ist, auch wenn die frühere bereits geschlossen ist.
- Ist ein von Ihnen gewählter Raum voll oder geschlossen, sehen Sie: „Ein von Ihnen gewählter Raum ist voll oder für den Check-in geschlossen. Bitte wenden Sie sich an eine ehrenamtliche Person.“
- Hat ein Kinderraum nicht genügend eingecheckte Ehrenamtliche für ein weiteres Kind, sehen Sie eine Meldung mit dem Raumnamen, zum Beispiel: „Kinderraum 1 hat im Moment nicht genügend Ehrenamtliche für ein weiteres Kind. Bitte wählen Sie einen anderen Raum oder wenden Sie sich an eine ehrenamtliche Person.“

:::warning
Der Check-in ist nur verfügbar, wenn Ihre Gemeinde aktive Gottesdienste eingerichtet hat. Sehen Sie keine Gottesdienste aufgelistet, erkundigen Sie sich bei Ihrem Gemeindebüro, ob der Selbst-Check-in aktiviert ist.
:::
