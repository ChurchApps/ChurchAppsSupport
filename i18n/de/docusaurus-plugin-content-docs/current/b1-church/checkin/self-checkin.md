# Self-Check-in

<div class="article-intro">

Mit dem Self-Check-in erfassen Sie Ihre Anwesenheit und die Ihres Haushalts in wenigen Schritten. Es ist eine schnelle Alternative zu einem Check-in-Terminal in der Gemeinde.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Sie müssen [in Ihrem B1.church-Konto angemeldet](../getting-started/logging-in.md) sein.
- Die Mitglieder Ihres Haushalts müssen mit Ihrem Konto verknüpft sein. Wenn ein Familienmitglied fehlt, bitten Sie Ihre Gemeindeverwaltung, es Ihrem Haushalt hinzuzufügen.

</div>

## Der Check-in-Ablauf

Der Check-in folgt einem einfachen Ablauf in drei Schritten. Öffnen Sie **Check-in** über die [Registerleiste oder die Seite Mehr](../getting-started/navigating.md), um zu beginnen.

### Schritt 1: Gottesdienst auswählen

Wenn Sie die Check-in-Seite öffnen, sehen Sie eine Liste der verfügbaren Gottesdienste (zum Beispiel „Sonntagmorgen“ oder „Mittwochabend“). Jede Gottesdienstkarte zeigt den Namen des Gottesdienstes und, falls Ihre Gemeinde mehrere Standorte hat, den Standort.

Tippen Sie auf einen Gottesdienst, um ihn auszuwählen und zum nächsten Schritt zu gelangen.

### Schritt 2: Haushaltsmitglieder und Gruppen auswählen

Nachdem Sie einen Gottesdienst ausgewählt haben, sehen Sie unter **Wer ist hier** die Mitglieder Ihres Haushalts. Für jede teilnehmende Person gilt:

1. Tippen Sie auf ein Haushaltsmitglied, um dessen Eintrag zu öffnen.
2. Sie sehen die verfügbaren **Gottesdienstzeiten** für den gewählten Gottesdienst. Hat Ihre Gemeinde für eine Gottesdienstzeit einen Check-in-Zeitplan festgelegt, erscheint diese nur, während der Check-in dafür geöffnet ist (zum Beispiel von 30 Minuten vor dem Gottesdienst bis kurz nach dessen Ende).
3. Tippen Sie neben einer Gottesdienstzeit auf **Gruppe auswählen**, um die Gruppe festzulegen, in die die Person eingecheckt werden soll (etwa „Hauptgottesdienst“, „Kinderraum 1“ oder „Jugendgruppe“).
4. Wiederholen Sie dies für jedes teilnehmende Haushaltsmitglied.

Sie müssen nicht jedes Haushaltsmitglied einchecken. Öffnen und ordnen Sie nur die Gruppen für Personen zu, die tatsächlich anwesend sind.

### Schritt 3: Bestätigung

Sobald Sie für alle Teilnehmenden eine Gruppe ausgewählt haben, tippen Sie auf die Schaltfläche am unteren Seitenrand. Sie zeigt die Anzahl der ausgewählten Personen an, zum Beispiel **1 Person einchecken** oder **3 Personen einchecken**.

Anschließend sehen Sie eine Bestätigung, dass Ihr Check-in abgeschlossen und Ihre Anwesenheit gespeichert ist. Nach kurzer Zeit kehrt die Seite zur Gottesdienstliste zurück, bereit für den nächsten Check-in.

Wenn Ihre Gemeinde an einer Check-in-Station Namensschilder druckt, sehen Sie stattdessen **Sie sind eingecheckt!** mit einem QR-Code und einem Sicherheitscode. Zeigen Sie den Code an einer Check-in-Station, um Ihre Namensschilder zu drucken, und tippen Sie dann auf **Fertig**. An einem B1-Checkin-Terminal tippen Sie auf **Code scannen** und halten den QR-Code vor die Kamera. Siehe [Etiketten für einen Check-in per Telefon drucken](../../b1-checkin/check-in/looking-up-members#printing-labels-for-a-phone-check-in).

Ist Ihr Haushalt für den gewählten Gottesdienst bereits eingecheckt, erscheint neben der Überschrift **Wer ist hier** ein Link **Check-in-Code anzeigen**. Tippen Sie darauf, um den QR-Code und den Sicherheitscode erneut anzuzeigen, zum Beispiel wenn Sie die Seite geschlossen haben, bevor Sie eine Check-in-Station erreicht haben.

:::tip
Wenn Sie eine Gruppenauswahl ändern möchten, bevor Sie den Check-in abschließen, tippen Sie neben einer Gottesdienstzeit auf die Schaltfläche **Ändern**, um eine andere Gruppe zu wählen.
:::

## Wissenswertes

- Sie können nur Haushaltsmitglieder einchecken, die mit Ihrem Konto verknüpft sind. Wenn ein Familienmitglied fehlt, bitten Sie Ihre Gemeindeverwaltung, es Ihrem Haushalt hinzuzufügen.
- Wenn auf der Check-in-Seite keine Gottesdienste erscheinen, sind für den Check-in derzeit möglicherweise keine Gottesdienste konfiguriert.
- Wenn Sie einen Gottesdienst auswählen und „Der Check-in ist für diesen Gottesdienst gerade nicht geöffnet“ sehen, liegt derzeit keine der Gottesdienstzeiten dieses Gottesdienstes im Check-in-Zeitfenster. Versuchen Sie es näher an der Gottesdienstzeit erneut.
- Wenn eine von Ihnen gewählte Gruppe voll oder geschlossen ist, sehen Sie „Eine von Ihnen gewählte Gruppe ist für den Check-in voll oder geschlossen. Bitte wenden Sie sich an eine freiwillige Helferin bzw. einen freiwilligen Helfer.“

:::warning
Der Check-in ist nur verfügbar, wenn Ihre Gemeinde aktive Gottesdienste konfiguriert hat. Wenn keine Gottesdienste angezeigt werden, erkundigen Sie sich im Gemeindebüro, ob der Self-Check-in aktiviert ist.
:::
