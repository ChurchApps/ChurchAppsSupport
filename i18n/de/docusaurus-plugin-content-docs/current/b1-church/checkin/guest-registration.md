# Gastregistrierung

<div class="article-intro">

Wenn Sie eine Kirche zum ersten Mal besuchen, können Sie sich und Ihre Familie als Gäste mit der Gastregistrierungsseite anmelden. Dies erstellt einen Datensatz im Kirchensystem, damit Freiwillige Sie bei Ihrer Ankunft anmelden können.

</div>

<div class="prereqs">
<h4>Bevor Sie Beginnen</h4>

- Ihre Kirche muss die QR-Gastregistrierung aktiviert haben
- Scannen Sie den QR-Code, der am Check-in-Kiosk angezeigt wird, tippen Sie am Kiosk auf **Hier registrieren**, oder erhalten Sie einen Link von einem Kirchenfreiwilligen

</div>

## Funktionsweise der Gastregistrierung

Die Gastregistrierung ist für Besucher gedacht, die noch kein Konto haben. Tippen Sie am Check-in-Kiosk der Kirche auf **Als Gast registrieren**, um einen QR-Code anzuzeigen, der zur Registrierungsseite führt. Sie können den Link auch von einem Freiwilligen oder Greifer erhalten.

Sie haben kein Telefon dabei? Tippen Sie im gleichen QR-Code-Fenster am Kiosk auf **Hier registrieren**, um das Formular am Kiosk selbst auszufüllen. Siehe [Registrierung als Gast](../../b1-checkin/check-in/looking-up-members#registering-as-a-guest) für weitere Informationen zur Funktionsweise am Kiosk.

## Familie registrieren

1. **Scannen Sie den QR-Code** am Check-in-Kiosk oder öffnen Sie den Gastregistrierungslink auf Ihrem Telefon. (Falls Sie **Hier registrieren** am Kiosk tippten, ist das Formular bereits geöffnet.)
2. Das Gastregistrierungsformular wird mit Feldern für den **Hauptkontakt** angezeigt:
   - **Vorname** (erforderlich)
   - **Nachname** (erforderlich)
   - **E-Mail** (optional)
   - **Telefon** (optional)
3. Um **Familienmitglieder hinzuzufügen**, tippen Sie auf **Familienmitglied hinzufügen** und geben Sie ihren Vor- und Nachnamen ein. Sie können bis zu 10 Familienmitglieder hinzufügen.
4. Um ein Familienmitglied zu entfernen, tippen Sie auf die Entfernen-Schaltfläche neben seinem Namen.
5. Tippen Sie auf **Registrieren**, um einzureichen.

## Nach der Registrierung

Nachdem Sie das Formular eingesendet haben, wird eine Bestätigungsseite mit der Meldung angezeigt: „Registrierung abgeschlossen – Sie sind bereit! Ein Mitarbeiter wird Sie in Kürze anmelden."

Ihre Registrierung erstellt Datensätze in der Kirchendatenbank:

- Ein **Haushalt** wird mit dem Nachnamen des Hauptkontakts erstellt.
- **Personendatensätze** werden für jedes Familienmitglied mit dem Mitgliedschaftsstatus „Gast" erstellt.
- Ein Kirchenfreiwilliger oder Administrator kann Ihre Familie dann mit dem [B1 Checkin](../../b1-checkin/check-in/looking-up-members)-Kiosk anmelden.

:::info
Wenn Ihre E-Mail einem bestehenden Datensatz in der Kirchendatenbank entspricht, verknüpft sich das System mit diesem Datensatz, anstatt ein Duplikat zu erstellen. Dies hält die Daten der Kirche sauber.
:::

:::tip
Die Bereitstellung Ihrer E-Mail-Adresse hilft der Kirche, mit Ihnen nach Ihrem Besuch in Kontakt zu treten. Dies ist optional, aber empfohlen.
:::
