# Lektionen

<div class="article-intro">

Die Lektionen sind auf Ihrer B1 Church Website verfügbar. Eltern können die geplanten Inhalte für ihre Kinder anzeigen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Ihre Kirche muss Lektionen in B1 Admin planen
- Sie müssen auf Ihre B1 Church Website zugreifen können

</div>

## Anzeigen von Lektionen

Lektionen werden auf der Website Ihrer Kirche angezeigt, wenn sie geplant sind.
