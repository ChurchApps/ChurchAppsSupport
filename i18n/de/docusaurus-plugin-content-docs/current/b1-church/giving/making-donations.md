# Eine Spende geben

<div class="article-intro">

Über die B1.church-Website Ihrer Gemeinde können Sie auf zwei Wegen spenden: über die öffentliche Spendenseite (keine Anmeldung erforderlich) und über die Spendenseite für Mitglieder (Anmeldung erforderlich). Beide verwenden ein sicheres Spendenformular, das von Stripe betrieben wird.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Für öffentliche Spenden brauchen Sie kein Konto. Besuchen Sie einfach die Seite **Spenden** Ihrer Gemeinde.
- Für Mitgliederspenden mit Verlaufsübersicht und gespeicherten Zahlungsmethoden [melden Sie sich](../getting-started/logging-in.md) zuerst bei Ihrem Konto an.

</div>

## Öffentliche Spendenseite (keine Anmeldung erforderlich)

Jeder kann spenden, ohne ein Konto anzulegen:

1. Rufen Sie die Seite **Spenden** Ihrer Gemeinde auf.
2. Das Spendenformular wird auf der linken Seite angezeigt. Wählen Sie den **Fonds** aus, für den Sie spenden möchten.
3. Geben Sie Ihre Zahlungsdaten und den Betrag ein, den Sie spenden möchten.
4. Senden Sie das Formular ab, um Ihre Spende abzuschließen.

Auf der rechten Seite der Seite sehen Sie einen Link zu **Anleitung für ACH-Zahlung**, falls Sie lieber per Banküberweisung spenden möchten. Außerdem gibt es eine Schaltfläche **Anmelden**, wenn Sie sich einloggen möchten, um zusätzliche Funktionen wie den Spendenverlauf zu nutzen.

:::tip
Wenn Sie beim Besuch der öffentlichen Spendenseite bereits angemeldet sind, werden Sie automatisch zur Spendenseite für Mitglieder weitergeleitet. Dort haben Sie Zugriff auf Ihren vollständigen Spendenverlauf und Ihre gespeicherten Zahlungsmethoden.
:::

## Spendenseite für Mitglieder (angemeldet)

Wenn Sie angemeldet sind, zeigt die Seite **Spenden** im Mitgliederportal oben eine Schaltfläche **Geben** und eine Schaltfläche **Auszug drucken**, gefolgt von diesen Abschnitten:

- **Dieses Jahr** (mit dem aktuellen Jahr als Überschrift) -- Ihre Spendensumme seit Jahresbeginn und die Anzahl Ihrer Spenden, mit einem Link **Gesamter Verlauf**. Details finden Sie unter [Spendenverlauf](./donation-history.md).
- **Wiederkehrend** -- Ihre geplanten Spenden, mit einem Link **Verwalten**.
- **Letzte Aktivitäten** -- Ihre letzten drei Spenden, mit einem Link **Letzte Spende wiederholen**, der das Spendenformular öffnet.
- **Zahlungsmethoden** -- Ihre gespeicherten Karten und Bankkonten, mit einem Link **Verwalten**, um sie hinzuzufügen, zu entfernen oder als Standard festzulegen.
- Eine Karte mit dem Fortschritt einer Kampagne, sofern Ihre Gemeinde eine aktive Kampagne hat.

So spenden Sie:

1. Öffnen Sie die Spendenseite über den Reiter **Spenden** Ihrer Gemeinde, über die Schaltfläche **Geben** im Abschnitt **Spenden** Ihres [Startseiten-Dashboards](../getting-started/navigating.md#home) oder über **Verlauf** im Abschnitt **Spenden** Ihrer [Me-Seite](../getting-started/me-page.md). Tippen Sie auf der Seite **Spenden** auf **Geben**, um das Spendenformular zu öffnen.
2. Wählen Sie den **Fonds** aus, für den Sie spenden möchten, und geben Sie Ihren Spendenbetrag ein. Die Liste zeigt nur die Fonds, die Ihre Gemeinde Spenderinnen und Spendern anbietet, auch wenn Sie als Mitarbeiter andere Fonds in B1 Admin sehen können.
3. Wählen Sie eine vorhandene gespeicherte Zahlungsmethode aus oder geben Sie neue Zahlungsdaten ein.
4. Senden Sie das Formular ab, um Ihre Spende abzuschließen.

Nachdem Ihre Spende verarbeitet wurde, erscheint eine Erfolgsmeldung, und Ihre Spende wird in Ihrem [Spendenverlauf](./donation-history.md) angezeigt.

:::info
Wurden Ihre Spenden in mehr als einer Währung erfasst, werden Ihre Jahressumme und die Gesamtsumme im Verlauf in die Währung Ihrer Gemeinde umgerechnet. Darunter steht der Hinweis **Umgerechnet zu aktuellen Wechselkursen**. Einzelne Spenden in Ihrem Verlauf werden weiterhin in ihrer ursprünglichen Währung angezeigt.
:::

## Zahlungsmethoden

Spenden werden sicher über **Stripe** abgewickelt. Sie können mit Kredit- oder Debitkarte bezahlen oder eine ACH-Banklastschrift einrichten. Wenn Sie angemeldet sind, können Ihre Zahlungsmethoden für künftige Spenden gespeichert werden, was das nächste Spenden schneller macht.

:::info Spende per Bankkonto ohne Anmeldung
Wenn Sie als Gast (ohne Anmeldung) per Bankkonto spenden, muss das Konto sofort über die Anmeldung bei Ihrer Bank verifiziert werden. Ist das nicht möglich, sehen Sie die Meldung: „Dieses Bankkonto konnte nicht sofort verifiziert werden. Bitte spenden Sie per Karte oder melden Sie sich an und fügen Sie das Bankkonto unter Ihrem Spendenprofil hinzu.“ Bankkonten, deren Verifizierung einige Tage dauert, können erst nach der Anmeldung hinzugefügt werden.
:::

:::warning
Wenn Ihre Spende nicht durchgeht, prüfen Sie Ihre Zahlungsdaten und versuchen Sie es erneut. Besteht das Problem weiterhin, wenden Sie sich für Unterstützung an das Büro Ihrer Gemeinde.
:::
