# Selbst-Check-in

<div class="article-intro">

Das Einchecken über B1 Mobile ist ein einfacher Vorgang mit mehreren Schritten. Mit wenigen Fingertipps können Sie die Anwesenheit für sich selbst und Ihre Haushaltsmitglieder erfassen, ohne an einem Kiosk anstehen zu müssen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- [B1 Mobile installieren](../getting-started/installing) und sich in Ihrem Konto [anmelden](../getting-started/logging-in)
- Stellen Sie sicher, dass Ihre [Haushaltsmitglieder](../profile/household.md) in Ihrem Profil eingerichtet sind

</div>

## Der Check-in-Ablauf

### Schritt 1: Gottesdienst und Uhrzeit auswählen

Wenn Sie den Check-in-Bildschirm öffnen, sehen Sie eine Liste der verfügbaren Gottesdienste und Termine. Diese werden von Ihrer Gemeinde konfiguriert und können Optionen wie „Sonntagmorgen 9:00 Uhr“ oder „Mittwochabend 18:30 Uhr“ enthalten.

1. Sehen Sie sich die verfügbaren Gottesdienstoptionen an.
2. Tippen Sie auf den Gottesdienst und die Uhrzeit, die Sie besuchen.

### Schritt 2: Haushaltsmitglieder auswählen

Nachdem Sie einen Gottesdienst gewählt haben, sehen Sie eine Liste der Mitglieder Ihres Haushalts.

1. Sehen Sie sich die Liste der Haushaltsmitglieder an.
2. Wählen Sie jede Person aus, die am Gottesdienst teilnehmen wird.

Sie müssen nicht alle einchecken – wählen Sie nur die Personen aus, die tatsächlich anwesend sind.

### Schritt 3: Gruppen zuweisen

Für jede ausgewählte Person weisen Sie eine Gruppe für den Gottesdienst zu. Zur Auswahl stehen können Gruppen wie Hauptgottesdienst, Kinderraum 1, Kinderraum 2 oder Jugendgruppe.

1. Tippen Sie für jedes ausgewählte Haushaltsmitglied auf die passende **Gruppe**.
2. Achten Sie darauf, dass jede Person der richtigen Gruppe für ihr Alter oder ihre Rolle zugeordnet ist.

### Schritt 4: Bestätigung

Sobald Sie allen anwesenden Personen Gruppen zugewiesen haben, schließen Sie den Check-in ab.

1. Prüfen Sie Ihre Auswahl, um sicherzustellen, dass alles korrekt ist.
2. Bestätigen Sie den Check-in.
3. Sie sehen einen Bestätigungsbildschirm, der Ihnen mitteilt, dass Ihre Anwesenheit erfasst wurde.

## Wissenswertes

- Sie können nur Haushaltsmitglieder einchecken, die mit Ihrem Konto verknüpft sind. Wenn jemand in der Liste fehlt, bitten Sie Ihren Gemeindeadministrator, die Person zu Ihrem [Haushalt](../profile/household.md) hinzuzufügen.
- Wenn auf dem Check-in-Bildschirm keine Gottesdienste erscheinen, hat Ihre Gemeinde derzeit möglicherweise keine Gottesdienste für den Check-in konfiguriert.
- Wenn Sie eine Auswahl vor der Bestätigung ändern möchten, können Sie zurückgehen und Ihre Auswahl anpassen.

:::warning
Achten Sie darauf, den richtigen Gottesdiensttermin und die richtigen Gruppenzuweisungen auszuwählen, bevor Sie bestätigen. Sobald die Anwesenheit erfasst ist, müssen Änderungen unter Umständen von Ihrem Gemeindeadministrator vorgenommen werden.
:::

:::tip
Öffnen Sie den Check-in-Bildschirm auf dem Weg zur Kirche, damit Sie beim Ankommen sofort einchecken können. Der Vorgang dauert nur wenige Sekunden.
:::
