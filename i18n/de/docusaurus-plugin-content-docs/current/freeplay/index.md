# FreePlay-Übersicht

<div class="article-intro">

FreePlay ist eine TV-App für Gemeinden, die Lektionsinhalte auf Fernsehern in Klassenräumen anzeigt. Sie läuft auf Android TV, Amazon Fire TV und Apple TV und ist so ausgelegt, dass sie am Sonntagmorgen ohne Internetverbindung funktioniert. Ehrenamtliche können Lektionsmaterialien schon während der Woche vorab herunterladen und drücken dann einfach auf Play, sobald der Unterricht beginnt.

</div>

## Hauptfunktionen

- **Offline-Wiedergabe** – Laden Sie Videos und Bildfolien im Voraus herunter, damit Sie während der Gottesdienste niemals auf WLAN angewiesen sind
- **Verwaltung der Downloads** – Alle heruntergeladenen Inhalte anzeigen und verwalten unter **Einstellungen** > **Downloads**
- **Geplanter Modus** – Erstellen Sie Playlists und legen Sie sie im Kalender unter [admin.freeplay.church](https://admin.freeplay.church) ab. Gekoppelte Fernseher spielen sie dann zur richtigen Zeit ab, ohne dass jemand auf Start drücken muss – siehe [Geplanter Modus](./scheduled-mode/)
- **Plankopplung** – Verbinden Sie Ihr Gerät mit einem Gottesdienstplan der Gemeinde, um Inhalte für mehrere Räume abzustimmen
- **Inhaltsanbieter** – Durchsuchen und laden Sie Inhalte aus externen Quellen wie [Lessons.church](/docs/lessons-church/), Bible Project, Dropbox und OneDrive
- **Ankündigungen** – Spielen Sie einen Ordner mit Folien eines verbundenen Anbieters in einer Schleife ab – siehe [Ankündigungen](./content-providers/announcements)
- **Freundlich für die TV-Fernbedienung** – Navigieren Sie durch die gesamte App mit einer üblichen TV-Fernbedienung über die Richtungstasten und die Auswahltaste
- **Einklappbare Seitenleiste** – Eine schlanke Seitenleiste hält die Navigation erreichbar, ohne den Bildschirm zu überladen

## So funktioniert es

Beim Start von FreePlay verbindet sich die App mit Ihren Inhaltsanbietern und prüft, welche Inhalte verfügbar sind. Von dort aus können Sie Ordner durchsuchen, Medien herunterladen und Lektionen abspielen – alles für die Nutzung auf einem großen Fernseher optimiert.
