# FreePlay-Übersicht

<div class="article-intro">

FreePlay ist eine TV-App für Kirchen, die Lektionsinhalte auf Klassenzimmer-Fernsehern anzeigt. Sie läuft auf Android TV, Amazon Fire TV und Apple TV und ist so konzipiert, dass sie an Sonntagmorgen ohne Internetverbindung funktioniert. Freiwillige können Lektionsmaterialien während der Woche vorher herunterladen und einfach die Wiedergabe starten, wenn die Klasse beginnt.

</div>

:::

## Hauptfunktionen

- **Offline-Wiedergabe** - Laden Sie Videos und Bildfolien voraus herunter, damit Sie sich an Gottesdiensten nie auf WLAN verlassen müssen
- **Downloads-Verwaltung** - Zeigen Sie alle heruntergeladenen Inhalte unter **Settings** > **Downloads** an und verwalten Sie diese
- **Klassenzimmer-Pairing** - Verbinden Sie Ihren Fernseher mit einem bestimmten Raum und erhalten Sie automatisch den geplanten Lektionsinhalt
- **Plan-Pairing** - Verknüpfen Sie Ihr Gerät mit einem Kirchendienstplan für koordinierte Inhalte in mehreren Räumen
- **Content-Provider** - Durchsuchen und laden Sie Inhalte von externen Quellen wie [Lessons.church](/docs/lessons-church/) und Bible Project herunter
- **Ankündigungen** - Schleifen Sie einen Ordner von Folien von einem verbundenen Provider -- siehe [Announcements](./content-providers/announcements)
- **TV-Fernbedienung freundlich** - Navigieren Sie die gesamte App mit einer Standard-TV-Fernbedienung mit Richtungstasten und Auswahl
- **Einklappbare Seitenleiste** - Eine dünne Seitenleiste hält die Navigation zugänglich, ohne den Bildschirm zu überladen

## Wie es funktioniert

Wenn Sie FreePlay starten, verbindet es sich mit Ihren Content-Providern und sucht nach verfügbaren Inhalten. Von dort aus können Sie Ordner durchsuchen, Medien herunterladen und Lektionen abspielen -- alles optimiert für ein großes TV-Erlebnis.
