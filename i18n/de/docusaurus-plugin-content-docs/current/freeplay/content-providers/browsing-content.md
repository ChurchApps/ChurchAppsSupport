# Inhalte durchsuchen und herunterladen

<div class="article-intro">

Sobald Sie mit einem Content-Provider verbunden sind, können Sie seine Bibliothek durchsuchen, Dateien herunterladen und auf Ihrem Fernseher abspielen. Der Content-Browser bietet ein visuelles Gitter von Ordnern und Dateien, durch die Sie mit Ihrer Fernbedienung navigieren.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Verbinden Sie sich mit mindestens einem Content-Provider – siehe [Mit Providern verbinden](./connecting-providers)
- Haben Sie Ihre Fernbedienung bereit zum Navigieren

</div>

## Der Content-Browser

Der Content-Browser zeigt Elemente in einem 3-Spalten-Gitter von Karten an. Jede Karte zeigt ein Miniaturbild und einen Titel. Es gibt zwei Arten von Elementen:

- **Ordner** – dargestellt durch ein Miniaturbild oder ein Ordner-Symbol. Wählen Sie einen Ordner, um seinen Inhalt anzuzeigen.
- **Dateien** – einzelne Medienelemente (Videos oder Bilder). Video-Dateien zeigen ein Play-Symbol-Overlay auf ihrem Miniaturbild an.

Die Kopfzeile oben auf dem Bildschirm zeigt den Namen des aktuellen Ordners oder den Provider-Namen, wenn Sie sich auf Root-Ebene befinden.

## Ordner navigieren

1. Verwenden Sie das Richtungsfeld auf Ihrer Fernbedienung, um einen Ordner hervorzuheben
2. Drücken Sie **Auswählen**, um ihn zu öffnen
3. Der Browser lädt den Inhalt des Ordners, was mehr Ordner oder abspielbare Dateien sein können
4. Drücken Sie **Zurück** auf Ihrer Fernbedienung, um eine Ebene nach oben zu gehen

Sie können so tief graben, wie die Inhaltsstruktur des Providers erlaubt. Der Browser verfolgt Ihren Ordner-Pfad, damit Sie durch jede Ebene zurück navigieren können.

## Inhalte herunterladen und abspielen

Wenn Sie einen Ordner auswählen, der abspielbare Dateien enthält (oder ein einzelnes Element auswählen), wechselt FreePlay zu einem Download-Bildschirm:

1. Der Inhaltstitel erscheint auf dem Bildschirm mit einem Titelbild aus dem ausgewählten Ordner
2. Ein Fortschrittsbalken zeigt **Datei X von Y wird heruntergeladen**, während Dateien auf Ihrem Gerät gespeichert werden
3. Sobald der Download abgeschlossen ist, erscheint die **Start**-Schaltfläche mit einem Play-Symbol
4. Drücken Sie **Auswählen**, um die Wiedergabe zu starten

:::tip
Heruntergeladene Inhalte werden auf Ihrem Fernseher gecacht. Wenn Sie den gleichen Inhalt später erneut abspielen, wird er sofort ohne erneuten Download geladen.
:::

## Provider-Inhalte abspielen

Die Wiedergabe funktioniert genauso wie die Lektions-Wiedergabe. Verwenden Sie diese Steuerelemente:

- **Rechtspfeil** – nächstes Element
- **Linkspfeil** – vorheriges Element
- **Auswählen / Play-Pause** – Video pausieren oder fortsetzen
- **Aufwärtspfeil** – Message-Selektor öffnen, um zu einem bestimmten Element zu springen
- **Zurück** – zum Content-Browser beenden

Wenn Sie den Player beenden, kehren Sie zum Content-Browser auf der Root-Ebene des aktuellen Providers zurück.

:::info
Eine vollständige Referenz aller Player-Steuerelemente finden Sie unter [Lektionen abspielen](../classroom-mode/playing-lessons).
:::

## Zwischen Providern wechseln

Verbundene Provider erscheinen als Elemente unter der **Browse**-Überschrift in der Seitenleiste auf der linken Seite. Um zu einem anderen Provider zu wechseln:

1. Drücken Sie die **Linkspfeil**-Taste auf Ihrer Fernbedienung, um die Seitenleiste zu erweitern
2. Wählen Sie den Provider aus, den Sie durchsuchen möchten
3. Der Content-Browser aktualisiert sich mit der Bibliothek dieses Providers

:::warning
Wenn ein Ordner „Kein Inhalt verfügbar" anzeigt, hat der Provider keine Elemente auf dieser Ebene. Versuchen Sie, zu einem anderen Ordner zu navigieren oder überprüfen Sie später erneut.
:::
