# Verbindung zu Anbietern herstellen

<div class="article-intro">

Bevor Sie Inhalte eines Anbieters durchsuchen können, müssen Sie sich mit ihm verbinden. Manche Anbieter verlangen eine Anmeldung per QR-Code oder E-Mail, andere lassen sich mit einem einzigen Klick verbinden.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Installieren und starten Sie FreePlay. Siehe [Erste Schritte](../getting-started/)
- Halten Sie Ihre TV-Fernbedienung für die Navigation bereit
- Für Anbieter mit Anmeldung benötigen Sie Ihre Zugangsdaten

</div>

:::tip B1 Admin und FreePlay gemeinsam einrichten?
Unsere **<a href="/guides/freeplay-b1admin" target="_blank">Schritt-für-Schritt-Anleitung</a>** führt Sie an einer Stelle durch die Verknüpfung von B1 Admin, die Planung einer Lektion und die Verbindung mit FreePlay. Öffnen Sie sie in einem neuen Tab, um mitzuarbeiten.
:::

## Verfügbare Anbieter durchsuchen

1. Öffnen Sie unten in der Seitenleiste **Einstellungen** und wählen Sie **Anbieter**, um den Bildschirm **Inhaltsanbieter** zu öffnen.
2. Sie sehen ein Raster mit Anbieterkarten, die jeweils Logo und Namen des Anbieters zeigen.
3. Verbundene Anbieter zeigen unter ihrem Namen ein grünes Abzeichen **Verbunden**.
4. Anbieter, die noch nicht verfügbar sind, zeigen das Etikett **Demnächst verfügbar**.

## Verbindung ohne Anmeldung

Manche Anbieter verlangen keine Anmeldung. Wenn Sie einen dieser Anbieter auswählen, verbindet sich FreePlay sofort und öffnet den Inhaltsbrowser. Es sind keine Zugangsdaten nötig.

## Geräteanmeldung (QR-Code)

Bestimmte Anbieter nutzen eine Geräteanmeldung, ähnlich wie Sie sich in Streaming-Apps auf einem Fernseher anmelden:

1. Wählen Sie die Anbieterkarte auf dem Bildschirm **Inhaltsanbieter**.
2. FreePlay zeigt einen Bildschirm **Verbinden mit** mit dem Namen des Anbieters, einem QR-Code und einer Bestätigungs-URL.
3. Scannen Sie den QR-Code mit Ihrem Telefon oder öffnen Sie die angezeigte URL auf einem beliebigen Gerät.
4. Geben Sie den Code ein, der auf dem Fernsehbildschirm angezeigt wird.
5. Schließen Sie die Anmeldung auf Ihrem Telefon oder Computer ab.
6. FreePlay erkennt die erfolgreiche Anmeldung und zeigt **Verbunden!** an.
7. Der Inhaltsbrowser öffnet sich automatisch.

:::info
Ein pulsierendes Symbol **Warten auf Bestätigung** zeigt an, dass FreePlay Ihre Anmeldung prüft. Der Bildschirm zeigt, wie viele Minuten bis zum Ablauf des Codes verbleiben. Schließen Sie den Vorgang daher zügig ab. Ist der Code abgelaufen, wählen Sie **Neuen Code erzeugen**.
:::

## Anmeldung per Telefon (nur QR-Code)

**Dropbox**, **OneDrive** und **Go Curriculum** verwenden eine etwas andere Anmeldung per QR-Code, bei der Sie keinen Code eingeben müssen:

1. Wählen Sie die Anbieterkarte auf dem Bildschirm **Inhaltsanbieter**.
2. FreePlay zeigt einen Bildschirm **Verbinden mit** mit dem Namen des Anbieters und einem QR-Code.
3. Scannen Sie den QR-Code mit Ihrem Telefon und melden Sie sich mit Ihrem Konto bei diesem Anbieter an (Ihr Microsoft-Konto für OneDrive oder Ihr gocurriculum.com-Konto für Go Curriculum).
4. Erteilen Sie die Zustimmung. Der Fernseher verbindet sich automatisch und zeigt **Verbunden!** an.

Der Bildschirm zeigt, wie viele Minuten Ihnen zum Abschluss der Anmeldung bleiben.

## Anmeldung mit Formular

Andere Anbieter verwenden eine klassische Anmeldung mit E-Mail-Adresse und Passwort:

1. Wählen Sie die Anbieterkarte.
2. Geben Sie Ihre **E-Mail-Adresse** und Ihr **Passwort** über die Bildschirmtastatur ein.
3. Wählen Sie die Schaltfläche **Anmelden**.
4. Sind Ihre Zugangsdaten korrekt, zeigt FreePlay **Verbunden!** an und öffnet den Inhaltsbrowser.

:::tip
Verwenden Sie das Steuerkreuz Ihrer Fernbedienung, um zwischen den Feldern E-Mail, Passwort und der Schaltfläche Anmelden zu wechseln. Drücken Sie **Auswählen** in einem Textfeld, um die Bildschirmtastatur zu öffnen.
:::

## Anbietereinstellungen

Wenn Sie eine Anbieterkarte mit dem Abzeichen **Verbunden** auswählen, öffnet sich der Bildschirm **Anbietereinstellungen**:

- **Bibliothek durchsuchen**: Blendet die Inhaltsbibliothek dieses Anbieters in der Seitenleiste ein oder aus.
- **Heutige Lektion automatisch herunterladen**: Verwendet diesen Anbieter als Quelle der heutigen Lektion und lädt deren Dateien vorab herunter. Wird nur für Anbieter angezeigt, die eine aktuelle Lektion anbieten.
- **Für Ankündigungen verwenden**: Wählen Sie einen Ordner dieses Anbieters, der über den Eintrag **Ankündigungen** in der Seitenleiste in einer Schleife abgespielt wird. Siehe [Ankündigungen](./announcements)
- **Auf Aktualisierungen der Ankündigungen prüfen**: Wird angezeigt, sobald ein Ankündigungsordner gewählt ist. Lädt neue Folien herunter und entfernt gelöschte.
- **Trennen**: Entfernt die Verbindung.

## Einen Anbieter trennen

So trennen Sie eine bereits bestehende Verbindung:

1. Öffnen Sie den Bildschirm **Inhaltsanbieter** (**Einstellungen** > **Anbieter**).
2. Wählen Sie die Anbieterkarte mit dem Abzeichen **Verbunden**.
3. Wählen Sie auf dem Bildschirm **Anbietereinstellungen** die Option **Trennen**.

Nach dem Trennen erscheinen die Inhalte des Anbieters nicht mehr in Ihrer Seitenleiste. Wurden Ordner dieses Anbieters für Ankündigungen verwendet, werden auch diese Folien entfernt.

:::warning
Beim Trennen wird die gespeicherte Anmeldung von Ihrem Gerät entfernt. Wenn Sie die Verbindung später wieder herstellen möchten, müssen Sie sich erneut anmelden.
:::
