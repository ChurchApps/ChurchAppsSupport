# Anbieter verbinden und Playlists erstellen

<div class="article-intro">

Eine Playlist ist eine Schleife aus Bildern und Videos, die Sie im Kalender einplanen. In FreePlay Admin verbinden Sie Ihre Inhaltsanbieter einmalig für die gesamte Kirche. Danach erstellen Sie Playlists, indem Sie Dateien aus diesen Anbietern auswählen.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Melden Sie sich bei FreePlay Admin unter [admin.freeplay.church](https://admin.freeplay.church) an
- Halten Sie die Zugangsdaten für jedes Anbieterkonto bereit, das Sie verknüpfen möchten, etwa Dropbox oder OneDrive

</div>

## Anbieter verbinden {#connecting-providers}

Die Seite **Anbieter** listet Ihre Inhaltsquellen in zwei Abschnitten auf:

- **Verbunden** – Anbieter, die Sie sofort nutzen können. Öffentliche Anbieter, die keine Anmeldung benötigen, etwa Lessons.church und Bible Project, werden hier immer als **Öffentlich · keine Anmeldung nötig** angezeigt. Verknüpfte Konten zeigen **Konto verknüpft** und an, wann die Verknüpfung abläuft.
- **Verfügbar** – Anbieter, bei denen Sie sich erst anmelden müssen, bevor Sie sie nutzen können.

So verbinden Sie einen Anbieter:

1. Gehen Sie zu **Anbieter**.
2. Suchen Sie den Anbieter unter **Verfügbar** und klicken Sie auf **Verbinden**.
3. Melden Sie sich mit Ihrem Konto bei diesem Anbieter an:
   - Manche Anbieter, etwa Dropbox, Google Drive und OneDrive, öffnen ein Anmeldefenster. Erscheint nichts, erlauben Sie Pop-ups für admin.freeplay.church.
   - Andere Anbieter zeigen einen Link und einen Code. Rufen Sie den Link auf, geben Sie den Code ein und bestätigen Sie den Zugriff. Der Dialog aktualisiert sich danach automatisch.
4. Sobald Sie **Konto erfolgreich verknüpft!** sehen, wechselt der Anbieter nach **Verbunden**.

Verbundene Anbieter bieten drei Aktionen:

- **Durchsuchen** – Die Ordner des Anbieters durchsehen
- **Aktualisieren** – Die Anmeldung beim Anbieter erneuern
- **Trennen** – Das Konto trennen

:::info
Anbieterverbindungen in FreePlay Admin gehören zur gesamten Kirche, nicht zu einer einzelnen Person oder einem einzelnen Fernseher. Die geplanten Bildschirme beziehen ihre Dateien über diese Verbindungen, sodass Sie sich nicht an jedem Fernseher einzeln bei jedem Anbieter anmelden müssen.
:::

**FreeShow** wird als **Im Netzwerk der Kirche · jeder Fernseher findet es selbst** angezeigt. In FreePlay Admin gibt es dafür nichts zu verbinden.

## Die Seite „Playlists“

Die Seite **Playlists** listet jede Playlist mit ihrer Anzahl an Elementen, ihrer Gesamtdauer, ihrer Verwendung (**Standardschleife** für eine Gruppe oder die Anzahl der Zeitpläne) und dem Zeitpunkt der letzten Aktualisierung auf. Jede Zeile enthält diese Aktionen:

- **Präsentieren** – Die Playlist im Browser im Vollbild abspielen
- **Bearbeiten** – Den Playlist-Editor öffnen
- **Duplizieren** – Eine Kopie mit dem Namen „(Kopie)“ erstellen

## Eine Playlist erstellen

1. Gehen Sie zu **Playlists** und klicken Sie auf **Playlist hinzufügen**.
2. Geben Sie einen **Namen** ein, zum Beispiel „Willkommensschleife“.
3. Klicken Sie auf **Playlist hinzufügen**. Der Playlist-Editor öffnet sich.

## Elemente hinzufügen

Der Playlist-Editor zeigt die **Elemente** Ihrer Playlist links und **Vom Anbieter hinzufügen** rechts.

1. Wählen Sie rechts einen Anbieter-Reiter. Um eine weitere Quelle hinzuzufügen, klicken Sie auf **Weiteren verbinden**, wodurch die Seite **Anbieter** geöffnet wird.
2. Klicken Sie auf Ordner, um sie zu öffnen. Mit dem Pfad oben (Brotkrümelnavigation) gelangen Sie wieder nach oben.
3. Klicken Sie auf eine Datei, um sie am Ende der Playlist anzuhängen. Dateien, die bereits in der Playlist sind, sind als ausgewählt markiert.
4. Um alles im aktuellen Ordner auf einmal hinzuzufügen, klicken Sie auf **Alle hinzufügen**. Die Schaltfläche zeigt an, wie viele Dateien noch nicht in der Playlist sind.
5. Klicken Sie oben im Editor auf **Speichern**.

:::warning
Änderungen werden erst gespeichert, wenn Sie auf **Speichern** klicken. Klicken Sie auf **Abbrechen**, um ohne Speichern zu verlassen.
:::

## Elemente anordnen

In der Liste **Elemente** auf der linken Seite:

- **Neu anordnen** – Ziehen Sie ein Element am Griff auf der linken Seite
- **Bilddauer** – Bilder werden standardmäßig 10 Sekunden angezeigt. Ändern Sie die Anzahl der Sekunden neben einem Bild.
- **Videos** – Videos zeigen **Bis zum Ende abspielen** und laufen in voller Länge
- **Entfernen** – Ein Element aus der Playlist nehmen

Die Zusammenfassung oben zeigt die Anzahl der Elemente und die Gesamtlänge der Playlist.

## Umbenennen, Duplizieren und Löschen

Das Feld auf der linken Seite des Editors zeigt, wo die Playlist verwendet wird. Außerdem stehen dort diese Aktionen zur Verfügung:

- **Präsentieren** – Die Playlist im Browser abspielen
- **Umbenennen** – Den Namen der Playlist ändern
- **Duplizieren** – Eine Kopie erstellen, die separat bearbeitet werden kann
- **Löschen** – Die Playlist entfernen. Zeitpläne, die sie abspielen, greifen dann auf die Standardschleife der Gruppe zurück

## Eine Playlist im Browser präsentieren

Klicken Sie auf **Präsentieren**, um die Playlist im Browser im Vollbild abzuspielen. Das ist praktisch, um eine Playlist zu prüfen oder sie von einem Laptop aus abzuspielen, der mit einem Projektor verbunden ist. Bewegen Sie die Maus, um die Steuerleiste einzublenden, und verwenden Sie dann diese Tasten:

| Taste | Aktion |
|---|---|
| **Leertaste** | Pausieren oder fortsetzen |
| **←** / **→** | Vorheriges oder nächstes Element |
| **F** | Vollbild ein- oder ausschalten |
| **Esc** | Beenden |
