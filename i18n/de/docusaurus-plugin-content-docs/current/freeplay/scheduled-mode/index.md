# Geplanter Modus

<div class="article-intro">

Der geplante Modus lässt einen FreePlay-Fernseher selbstständig laufen. Sie erstellen Playlists und legen sie in **FreePlay Admin** unter [admin.freeplay.church](https://admin.freeplay.church) in einen Kalender. Jeder Fernseher, der mit diesem Kalender gekoppelt ist, lädt die kommende Woche herunter und spielt, was geplant ist, nach der Uhr ab, ohne dass jemand auf Start drücken muss. Da die Dateien bereits heruntergeladen sind, läuft die Wiedergabe auch dann weiter, wenn das WLAN ausfällt.

</div>

:::tip
FreePlay Admin verwendet Ihre ChurchApps-Anmeldung, dieselbe, die Sie für B1 Admin verwenden. Sie müssen kein separates Konto anlegen.
:::

## So greift alles ineinander

FreePlay Admin hat vier Hauptseiten, die oben auf der Website aufgelistet sind:

- **[Bildschirme](./managing-screens)**: Die Fernseher, die Sie gekoppelt haben, ihr Status und die **Bildschirmgruppen**, zu denen sie gehören. Bildschirme in einer Gruppe teilen sich einen Kalender und eine Standard-Schleife.
- **[Playlists](./building-playlists)**: Schleifen aus Bildern und Videos, die Sie aus Ihren Inhaltsanbietern auswählen.
- **[Kalender](./scheduling-the-calendar)**: Was jede Bildschirmgruppe wann abspielt.
- **[Anbieter](./building-playlists#connecting-providers)**: Die Inhaltsquellen, aus denen Ihre Playlists schöpfen. Jede Quelle verbinden Sie einmal für die ganze Kirche.

Ist nichts geplant, spielen die Bildschirme einer Gruppe deren **Standard-Schleife**. Hat die Gruppe keine Standard-Schleife, werden die Bildschirme schwarz.

## Unterschied zum Planmodus

- **[Planmodus](../plan-mode/)** folgt einem Gottesdienstplan-Typ aus B1 Admin. Jemand drückt am Fernseher auf **Plan starten**, und die Lektion läuft, sobald er gedrückt wird.
- **Geplanter Modus** folgt einem Kalender. Inhalte starten und enden zu den Zeiten, die Sie festlegen. Das eignet sich gut für Beschilderung in der Eingangshalle, Ankündigungsschleifen und Klassenräume, in denen die Lektion schon laufen soll, bevor jemand hereinkommt.

Ein Kalendereintrag kann auch einen Gottesdienstplan abspielen. Wählen Sie beim Hinzufügen eines Zeitplans den Plantyp unter **Gottesdienstpläne** aus. Der Bildschirm spielt dann den Plan ab, der in B1 Admin in dieser Woche aktuell ist.

## Erste Schritte

Solange Sie die folgenden Schritte nicht abgeschlossen haben, zeigt die Seite **Bildschirme** eine Checkliste **Erste Schritte** mit einem Link für jeden Schritt:

1. **Anbieter verbinden**: Verknüpfen Sie Dropbox, OneDrive, Lessons.church oder eine andere Quelle auf der Seite **Anbieter**.
2. **Playlist erstellen**: Wählen Sie Bilder und Videos aus einem Anbieter aus.
3. **In den Kalender eintragen**: Legen Sie fest, was wann abgespielt wird, oder eine Standard-Schleife für die Gruppe.
4. **Bildschirm koppeln**: Geben Sie den vierstelligen Code ein, der auf dem Fernseher angezeigt wird.

Klicken Sie auf **Ausblenden**, um die Checkliste zu schließen.

:::tip
Drücken Sie **Strg+K** (**⌘K** auf dem Mac) oder klicken Sie auf das Suchfeld in der Kopfzeile, um die Befehlspalette zu öffnen. Von dort aus können Sie zu jeder Seite springen oder eine Aktion starten, etwa **Bildschirm koppeln**, **Playlist hinzufügen** oder **Zeitplan hinzufügen**.
:::
