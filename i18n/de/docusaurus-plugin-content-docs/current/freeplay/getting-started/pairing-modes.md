# Einen Kopplungsmodus wählen

<div class="article-intro">

FreePlay kann einen Fernseher auf drei Arten betreiben. Er kann einem Kalender folgen, den Sie in FreePlay Admin einrichten, einem Gottesdienstplan aus B1 Admin folgen oder das abspielen, was ein Ehrenamtlicher mit der Fernbedienung auswählt. Beide Kopplungsarten beginnen auf demselben Bildschirm des Fernsehers. Wo Sie den Kopplungscode eingeben, entscheidet darüber, welchen Modus der Fernseher verwendet.

</div>

<div class="prereqs">
<h4>Bevor Sie beginnen</h4>

- Installieren Sie FreePlay und starten Sie es zum ersten Mal. Siehe [Erste Schritte](./index.md)
- Halten Sie die Fernbedienung Ihres Fernsehers zur Navigation bereit

</div>

## Einen Kopplungscode abrufen

1. Öffnen Sie auf dem Fernseher **Einstellungen** unten in der Seitenleiste.
2. Wählen Sie **Mit einem Kalender koppeln**.
3. FreePlay zeigt einen vierstelligen Kopplungscode und einen QR-Code an. Der Code ist 15 Minuten gültig, und FreePlay zeigt automatisch einen neuen an, sobald der alte abläuft.

## Geplanter Modus (FreePlay Admin)

Geben Sie den Code in **FreePlay Admin** auf [admin.freeplay.church](https://admin.freeplay.church) ein, wenn der Fernseher selbstständig laufen soll. Sie erstellen Playlists, legen sie für eine Gruppe von Bildschirmen in einen Kalender, und der Fernseher spielt sie zu den geplanten Zeiten ab. Niemand muss auf Start drücken.

**So funktioniert es:** Scannen Sie den QR-Code auf dem Fernseher oder gehen Sie zu **freeplay.church/pair**. Wählen Sie dann die Bildschirmgruppe aus, deren Kalender der Fernseher folgen soll, und klicken Sie auf **Koppeln**. Der Fernseher lädt die kommende Woche herunter und spielt nach der Uhr ab, auch offline.

**Ideal für:** Beschilderung in Foyer und Gängen, Ankündigungsschleifen und Klassenräume, in denen die Lektion schon laufen soll, wenn die Leute hereinkommen.

Die vollständige Anleitung finden Sie unter **[Geplanter Modus](../scheduled-mode/)**.

## Planmodus (B1 Admin)

Geben Sie den Code in **B1 Admin** ein, wenn der Fernseher einem Gottesdienstplan-Typ folgen soll. Der Fernseher lädt die Inhalte des aktuellen Plans herunter, und ein Ehrenamtlicher drückt **Plan starten**, um sie abzuspielen.

**So funktioniert es:** Fügen Sie in B1 Admin den Bildschirm mit dem Code des Fernsehers hinzu und wählen Sie unter **Pläne anzeigen für** den Planungstyp aus. Jede Woche übernimmt der Fernseher den neuesten Plan für diesen Planungstyp.

**Ideal für:** Fernseher, die Inhalte zu Ihrem wöchentlichen Gottesdienstplan zeigen, wenn jemand die Wiedergabe startet, sobald es so weit ist.

Die vollständige Anleitung finden Sie unter **[Planmodus](../plan-mode/)**.

:::tip
Sie können den aktuellen Gottesdienstplan auch nach Zeitplan abspielen. Fügen Sie in FreePlay Admin einen Kalendereintrag hinzu und wählen Sie unter **Gottesdienstpläne** den Planungstyp.
:::

## Inhaltsanbieter (ohne Kopplung)

Wenn Sie den Fernseher überhaupt nicht koppeln müssen, können Sie Inhaltsanbieter direkt durchsuchen. Anbieter wie [Lessons.church](../../lessons-church/) und Bible Project bieten Inhalte, die Sie herunterladen und jederzeit abspielen können.

**Ideal für:** Fernseher, bei denen Ehrenamtliche jede Woche auswählen, was gezeigt wird, oder wenn Sie herausfinden möchten, was verfügbar ist.

:::info
Sie können die Seite **Anbieter** jederzeit über **Einstellungen** unten in der Seitenleiste öffnen. Um Inhalte zu durchsuchen und abzuspielen, müssen Sie den Fernseher nicht koppeln.
:::
