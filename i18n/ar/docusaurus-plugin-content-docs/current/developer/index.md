# توثيق المطورين

<div class="article-intro">

ChurchApps هي مجموعة من حوالي 20 مشروعًا مفتوح المصدر تُشكّل معًا منصة متكاملة لإدارة الكنيسة. تشمل هذه المشاريع واجهات برمجة التطبيقات (APIs) الخلفية، وتطبيقات الويب، وتطبيقات الجوال، وتطبيق سطح المكتب، والمكتبات المشتركة، وكلها مكتوبة بلغة TypeScript. يوفر هذا القسم كل ما تحتاجه لإعداد بيئة تطوير محلية والبدء في المساهمة.

</div>

## نظرة عامة على البنية

المشاريع **مستودعات مستقلة** (وليست مستودعًا واحدًا monorepo). تُنشر الشيفرة المشتركة على npm ضمن النطاق `@churchapps/*` وتُستخدم كتبعيات عادية. وهذا يعني أنه يمكنك العمل على مشروع واحد دون استنساخ المنظومة بأكملها.

أبرز خصائص البنية:

- **اللغة:** TypeScript في كل المشاريع
- **الخلفية:** واجهات Node.js / Express البرمجية، تُنشر على AWS Lambda عبر Serverless Framework
- **الويب:** React 19 (مع Vite وNext.js)، وMaterial-UI 7
- **الجوال:** React Native مع Expo
- **قاعدة البيانات:** MySQL 8.0، مع قاعدة بيانات منفصلة لكل وحدة API
