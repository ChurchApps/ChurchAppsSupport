# توثيق المطورين

<div class="article-intro">

ChurchApps مجموعة من حوالي 20 مشروعًا مفتوح المصدر تُشكّل معًا منصة متكاملة لإدارة الكنيسة. تشمل المشاريع واجهات برمجة التطبيقات الخلفية، وتطبيقات الويب، وتطبيقات الجوال، وتطبيق سطح المكتب، والمكتبات المشتركة، وكلها مكتوبة بلغة TypeScript. يوفر هذا القسم كل ما تحتاجه لإعداد بيئة تطوير محلية والبدء في المساهمة.

</div>

## نظرة عامة على البنية

المشاريع **مستودعات مستقلة** (وليست مستودعًا أحادي المشروع). يُنشر الكود المشترك على npm تحت النطاق `@churchapps/*` ويُستخدم كتبعيات عادية. وهذا يعني أنه يمكنك العمل على مشروع واحد دون استنساخ المنظومة بأكملها.

الخصائص الرئيسية:

- **اللغة:** TypeScript في كل مكان
- **الخلفية:** واجهات برمجة تطبيقات Node.js / Express تُنشر على AWS Lambda عبر Serverless Framework
- **الويب:** React 19 (مع Vite وNext.js)، وMaterial-UI 7
- **الجوال:** React Native مع Expo
- **قاعدة البيانات:** MySQL 8.0، مع قاعدة بيانات واحدة لكل وحدة من وحدات API
