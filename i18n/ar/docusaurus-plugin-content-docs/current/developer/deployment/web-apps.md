# نشر تطبيقات الويب

<div class="article-intro">

تُنشر تطبيقات ويب ChurchApps كمواقع ثابتة على **Amazon S3** مع **CloudFront** كشبكة توصيل محتوى (CDN). تتم عمليات النشر تلقائيًا عبر GitHub Actions، ويمكن تشغيلها يدويًا عند الحاجة.

</div>

<div class="prereqs">
<h4>قبل أن تبدأ</h4>

- قم بإعداد تطبيق الويب محليًا وتأكد من نجاح بنائه -- راجع [تطبيقات الويب](../web-apps/index.md)
- اضبط بيانات اعتماد AWS مع صلاحيات الوصول إلى S3 وCloudFront
- تعرّف على اسم حاوية S3 المستهدفة ومعرّف توزيع CloudFront

</div>

## خطوات النشر

1. **بناء التطبيق** -- أنشئ المخرجات الثابتة:

   ```bash
   npm run build
   ```

2. **المزامنة مع S3** -- ارفع مخرجات البناء إلى حاوية S3:

   ```bash
   aws s3 sync build/ s3://bucket-name
   ```

3. **إبطال ذاكرة CloudFront** -- امسح ذاكرة التخزين المؤقت في الشبكة حتى يحصل المستخدمون على أحدث نسخة:

   ```bash
   aws cloudfront create-invalidation --distribution-id YOUR_DIST_ID --paths "/*"
   ```

## عمليات النشر الآلية

تتولى سير عمل GitHub Actions عملية النشر تلقائيًا عند الدفع إلى الفرع `main`. ينفذ السير الخطوات الثلاث أعلاه -- البناء، ومزامنة S3، وإبطال CloudFront -- دون تدخل يدوي.

:::info
لا تحتاج عادةً إلى تشغيل هذه الأوامر يدويًا. يؤدي دمج طلب السحب في `main` إلى تشغيل خط أنابيب النشر الآلي.
:::

:::tip
إذا احتجت إلى التحقق من البناء محليًا قبل النشر، فشغّل `npm run build` وافحص المخرجات في المجلد `build/`. يمكنك تشغيلها محليًا باستخدام أي خادم ملفات ثابتة للتأكد من أن كل شيء يعمل.
:::
