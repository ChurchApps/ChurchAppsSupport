# الإعداد

<div class="article-intro">

يرشدك هذا القسم خلال إعداد بيئة تطوير محلية لمشاريع ChurchApps. يمكنك إما توجيه واجهتك الأمامية إلى واجهات برمجة التطبيقات التجريبية المشتركة للتطوير السريع، أو تشغيل المنظومة الكاملة محليًا لأعمال الواجهة الخلفية.

</div>

## طريقتان

هناك طريقتان للتطوير محليًا، حسب مقدار المنظومة التي تحتاجها:

### 1. الاتصال بواجهات برمجة التطبيقات التجريبية (الأسهل)

إذا كنت تعمل على **مشروع واجهة أمامية** (تطبيق ويب أو تطبيق جوال أو تطبيق سطح مكتب)، فأسرع طريقة هي توجيه تطبيقك المحلي إلى واجهات برمجة التطبيقات التجريبية المشتركة. لا حاجة إلى إعداد قاعدة بيانات أو واجهة خلفية.

عنوان URL الأساسي لواجهة برمجة التطبيقات التجريبية هو:

```
https://api.demo.churchapps.org
```

كل وحدة من وحدات واجهة برمجة التطبيقات متاحة تحت مسار ضمن هذا العنوان الأساسي، على سبيل المثال:

```
https://api.demo.churchapps.org/membership
https://api.demo.churchapps.org/attendance
https://api.demo.churchapps.org/giving
```

تشغّل البيئة التجريبية أحدث الشيفرة من فرع `main`، ويُعاد ملء بياناتها النموذجية كل ليلة، لذا لا تتوقع أن يبقى أي شيء تنشئه هناك. (لقد أُوقفت بيئة الاختبار السابقة `api.staging.churchapps.org`. قد تظل بعض ملفات `.env` النموذجية تحتوي على عناوين بيئة الاختبار -- استبدلها بعناوين البيئة التجريبية أو العناوين المحلية.)

:::tip
تتيح لك هذه الطريقة البدء في إجراء تغييرات الواجهة الأمامية خلال دقائق. وهي الطريقة الموصى بها لمعظم المساهمين.
:::

### 2. تشغيل كل شيء محليًا

إذا كنت تحتاج إلى تعديل شيفرة واجهة برمجة التطبيقات أو العمل دون اتصال بالإنترنت، يمكنك تشغيل المنظومة الكاملة محليًا. يتطلب ذلك MySQL 8.0 أو أحدث، وإعدادات إضافية. راجع دليل [إعداد واجهة برمجة التطبيقات محليًا](../api/local-setup.md) للحصول على تعليمات مفصلة.

## البدء

اتبع هذه الصفحات بالترتيب:

1. **[المتطلبات الأساسية](./prerequisites.md)** -- ثبّت الأدوات المطلوبة (Node.js وGit وMySQL وغيرها)
2. **[نظرة عامة على المشروع](./project-overview.md)** -- تعرّف على المشاريع الموجودة وما تقوم به كل منها
3. **[متغيرات البيئة](./environment-variables.md)** -- اضبط ملفات `.env` لربط كل شيء معًا

:::info
كل مشروع من مشاريع ChurchApps مستودع Git مستقل. تحتاج فقط إلى استنساخ المشروع أو المشاريع المحددة التي تريد العمل عليها.
:::
