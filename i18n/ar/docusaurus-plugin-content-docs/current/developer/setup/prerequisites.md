# المتطلبات الأساسية

<div class="article-intro">

تعتمد الأدوات التي تحتاجها على المشاريع التي تخطط للعمل عليها. تسرد هذه الصفحة جميع البرامج المطلوبة مرتبةً حسب مجال التطوير، بدءاً من المتطلبات العامة وصولاً إلى سلاسل الأدوات الخاصة بكل منصة.

</div>

<div class="prereqs">
<h4>قبل البدء</h4>

- راجع [نظرة عامة على المشروع](./project-overview.md) لتحديد المشاريع التي تريد العمل عليها
- تأكد من أن لديك صلاحيات المسؤول على جهاز التطوير الخاص بك لتثبيت البرامج

</div>

## جميع المشاريع

هذه الأدوات مطلوبة بصرف النظر عن المشروع الذي تعمل عليه:

| الأداة | الإصدار | ملاحظات |
|------|---------|-------|
| **Node.js** | 20+ | الإصدار 22+ مطلوب لـ B1App وLessonsApp (Next.js 16)؛ والإصدار 24+ مطلوب للواجهة البرمجية (Api) |
| **npm** | يأتي مع Node.js | يُستخدم كمدير حزم في جميع المشاريع |
| **Git** | الأحدث | كل مشروع مستودع منفصل |

:::tip
استخدم مدير إصدارات Node مثل [nvm](https://github.com/nvm-sh/nvm) (macOS/Linux) أو [nvm-windows](https://github.com/coreybutler/nvm-windows) (Windows) للتبديل بين إصدارات Node بسهولة.
:::

## تطوير الواجهة البرمجية الخلفية

إذا كنت تخطط لتشغيل الواجهة البرمجية محلياً (بدلاً من الإشارة إلى الواجهات التجريبية):

| الأداة | الإصدار | ملاحظات |
|------|---------|-------|
| **MySQL** | 8.0+ | يستخدم كل وحدة من وحدات الواجهة البرمجية قاعدة بيانات خاصة بها |

ستحتاج إلى ست قواعد بيانات للواجهة البرمجية الأساسية: `membership` و`attendance` و`content` و`giving` و`messaging` و`doing`. تتضمن الواجهة البرمجية نصوصاً برمجية لتهيئة المخطط -- راجع دليل [الإعداد المحلي للواجهة البرمجية](../api/local-setup.md).

## تطوير تطبيقات الجوال

بالنسبة إلى B1Checkin وLessonsScreen أو تطبيقات React Native / Expo الأخرى:

| الأداة | الإصدار | ملاحظات |
|------|---------|-------|
| **Expo CLI** | الأحدث | التثبيت عالمياً: `npm install -g expo-cli` |
| **Android Studio** | الأحدث | مطلوب لتطوير Android (يتضمن Android SDK) |
| **Xcode** | الأحدث | مطلوب لتطوير iOS (macOS فقط) |

:::info
يمكنك استخدام تطبيق Expo Go على جهاز فعلي للاختبار السريع دون الحاجة إلى Android Studio أو Xcode. ومع ذلك، فإن بناء الملفات التنفيذية للإنتاج يتطلب سلاسل الأدوات الأصلية.
:::

## تطوير FreeShow (تطبيق سطح المكتب)

يحتاج FreeShow إلى تبعيات بناء أصلية إضافية لأنه يترجم وحدات Node الأصلية (مثل `canvas`):

### جميع المنصات

| الأداة | الإصدار | ملاحظات |
|------|---------|-------|
| **Python** | 3.12 | مطلوب بواسطة `node-gyp` لترجمة الوحدات الأصلية |
| **setuptools** | الأحدث | التثبيت عبر `pip install setuptools` |

### Windows

| الأداة | ملاحظات |
|------|-------|
| **Visual Studio** | نسخة Community كافية |
| **حزمة "Desktop development with C++"** | تُحدد أثناء تثبيت Visual Studio |
| **Windows 10 SDK** | مضمّن في حزمة C++؛ تأكد من تحديده |

يمكنك تثبيت أدوات البناء في Visual Studio عبر سطر الأوامر:

```bash
npm install --global windows-build-tools
```

أو ثبّت Visual Studio Community واختر حزمة "Desktop development with C++" أثناء التثبيت.

### Linux

```bash
sudo apt-get install libfontconfig1-dev
```

### macOS

تكفي عادةً أدوات سطر الأوامر لـ Xcode:

```bash
xcode-select --install
```

## التحقق من التثبيت

شغّل هذه الأوامر للتأكد من تثبيت كل شيء:

```bash
node --version    # يجب أن يطبع v20.x.x أو أعلى
npm --version     # يجب أن يطبع 10.x.x أو أعلى
git --version     # يجب أن يطبع git version 2.x.x
mysql --version   # مطلوب فقط للتطوير المحلي للواجهة البرمجية
```
