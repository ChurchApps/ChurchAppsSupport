# المتطلبات الأساسية

<div class="article-intro">

تعتمد الأدوات التي تحتاجها على المشاريع التي تخطط للعمل عليها. تسرد هذه الصفحة جميع البرامج المطلوبة مرتبة حسب مجال التطوير، بدءًا من المتطلبات العامة وصولًا إلى سلاسل الأدوات الخاصة بكل منصة.

## جميع المشاريع

هذه الأدوات مطلوبة بغض النظر عن المشروع الذي تعمل عليه:

| الأداة | الإصدار | ملاحظات |
|------|---------|-------|
| **Node.js** | 20+ | الإصدار 22+ مطلوب لتطبيق B1App وLessonsApp (Next.js 16)؛ والإصدار 24+ مطلوب للواجهة البرمجية Api |
| **npm** | يأتي مع Node.js | يُستخدم كمدير حزم في جميع المشاريع |
| **Git** | أحدث إصدار | كل مشروع مستودع منفصل |

:::tip
استخدم مدير إصدارات Node مثل [nvm](https://github.com/nvm-sh/nvm) (macOS/Linux) أو [nvm-windows](https://github.com/coreybutler/nvm-windows) (Windows) للتبديل بين إصدارات Node بسهولة.
:::

## تطوير الواجهة البرمجية الخلفية

إذا كنت تخطط لتشغيل الواجهة البرمجية محليًا (بدلًا من الاتصال بالواجهات التجريبية):

| الأداة | الإصدار | ملاحظات |
|------|---------|-------|
| **MySQL** | 8.0+ | تستخدم كل وحدة من وحدات الواجهة البرمجية قاعدة بيانات خاصة بها |

ستحتاج إلى ستة قواعد بيانات للواجهة الأساسية: `membership` و`attendance` و`content` و`giving` و`messaging` و`doing`. تتضمن الواجهة البرمجية نصوصًا برمجية لتهيئة المخطط -- راجع دليل [الإعداد المحلي للواجهة البرمجية](../api/local-setup.md).

## تطوير تطبيقات الجوال

لتطبيقات B1Mobile وB1Checkin وLessonsScreen أو أي تطبيقات أخرى مبنية على React Native / Expo:

| الأداة | الإصدار | ملاحظات |
|------|---------|-------|
| **Expo CLI** | أحدث إصدار | للتثبيت عامًا: `npm install -g expo-cli` |
| **Android Studio** | أحدث إصدار | مطلوب لتطوير تطبيقات Android (يتضمن Android SDK) |
| **Xcode** | أحدث إصدار | مطلوب لتطوير تطبيقات iOS (macOS فقط) |

:::info
يمكنك استخدام تطبيق Expo Go على جهاز فعلي للاختبار السريع دون الحاجة إلى Android Studio أو Xcode. ومع ذلك، فإن بناء النسخ النهائية للإنتاج يتطلب سلاسل الأدوات الأصلية.
:::

## تطوير FreeShow (تطبيق سطح المكتب)

يحتاج FreeShow إلى تبعيات بناء أصلية إضافية لأنه يترجم وحدات Node الأصلية (مثل `canvas`):

### جميع المنصات

| الأداة | الإصدار | ملاحظات |
|------|---------|-------|
| **Python** | 3.12 | مطلوب بواسطة `node-gyp` لترجمة الوحدات الأصلية |
| **setuptools** | أحدث إصدار | يُثبَّت عبر `pip install setuptools` |

### Windows

| الأداة | ملاحظات |
|------|---------|
| **Visual Studio** | نسخة Community كافية |
| **حزمة "Desktop development with C++"** | تُختار أثناء تثبيت Visual Studio |
| **Windows 10 SDK** | مضمّن في حزمة C++؛ تأكد من تحديده |

يمكنك تثبيت أدوات البناء الخاصة بـ Visual Studio من سطر الأوامر:

```bash
npm install --global windows-build-tools
```

أو ثبّت Visual Studio Community واختر حزمة "Desktop development with C++" أثناء التثبيت.

### Linux

```bash
sudo apt-get install libfontconfig1-dev
```

### macOS

عادةً ما تكون أدوات سطر أوامر Xcode كافية:

```bash
xcode-select --install
```

## تحقق من التثبيت

شغّل هذه الأوامر للتأكد من تثبيت كل شيء:

```bash
node --version    # يجب أن يظهر v20.x.x أو أعلى
npm --version     # يجب أن يظهر 10.x.x أو أعلى
git --version     # يجب أن يظهر git version 2.x.x
mysql --version   # مطلوب فقط لتطوير الواجهة البرمجية محليًا
```
