# B1 Admin

<div class="article-intro">

B1Admin هي لوحة إدارة الكنيسة، وهي تطبيق صفحة واحدة (SPA) مبني باستخدام React وVite وMaterial-UI. يستخدم موظفو الكنيسة هذه اللوحة لإدارة الأشخاص والمجموعات والحضور والتبرعات والمحتوى وغير ذلك.

</div>

<div class="prereqs">
<h4>قبل أن تبدأ</h4>

- ثبّت **Node.js 22+** و**Git** -- راجع [المتطلبات الأساسية](../setup/prerequisites.md)
- اضبط نقطة الاتصال بواجهة برمجة التطبيقات (التجريبية أو المحلية) -- راجع [متغيرات البيئة](../setup/environment-variables.md)

</div>

## الإعداد

### 1. استنساخ المستودع

```bash
git clone https://github.com/ChurchApps/B1Admin.git
```

### 2. تثبيت التبعيات

```bash
cd B1Admin
npm install
```

### 3. إعداد متغيرات البيئة

```bash
cp dotenv.sample.txt .env
```

افتح الملف `.env` واضبط نقاط نهاية واجهة برمجة التطبيقات. يمكنك توجيهها إلى واجهة البرمجة التجريبية المشتركة (`https://api.demo.churchapps.org`) أو إلى نسختك المحلية من واجهة البرمجة. قد لا يزال الملف النموذجي يسرد عناوين بيئة الاختبار القديمة المُوقفة؛ استبدلها.

### 4. تشغيل خادم التطوير

```bash
npm start
```

يُشغّل هذا الأمر خادم التطوير Vite. سيكون التطبيق متاحًا في متصفحك مع تفعيل ميزة تحديث الوحدات أثناء التشغيل (Hot Module Replacement).

## متغيرات البيئة الرئيسية

| المتغير | الوصف |
|----------|-------------|
| `REACT_APP_STAGE` | اسم البيئة (مثل `demo` كما في الملف النموذجي، أو `prod`، أو `selfhost`) |
| `PORT` | منفذ خادم التطوير (الافتراضي: `3101`) |
| `REACT_APP_*_API` | عناوين نقاط نهاية واجهة البرمجة لكل وحدة |

:::info
يقوم السكربت `postinstall` بنسخ ملفات اللغات وملفات CSS من الحزمة `@churchapps/apphelper`. إذا ظهرت المكونات بدون تنسيق، فشغّل `npm run postinstall` يدويًا.
:::

## الأوامر الرئيسية

| الأمر | الوصف |
|---------|-------------|
| `npm start` | تشغيل خادم تطوير Vite |
| `npm run build` | بناء نسخة الإنتاج عبر Vite |
| `npm run test` | تشغيل اختبارات الطرف إلى الطرف باستخدام Playwright |
| `npm run lint` | تشغيل ESLint مع الإصلاح التلقائي |

## المكدس التقني

- **React 19** مع TypeScript
- **Vite** لأدوات البناء وخادم التطوير
- **Material-UI 7** لمكونات الواجهة
- **React Query 5** لإدارة حالة الخادم
- **`@churchapps/apphelper*`** للحزم المشتركة من المكونات

## النشر

تُنشر نسخ الإنتاج على **S3 + CloudFront**:

1. يُنشئ الأمر `npm run build` الملفات الثابتة
2. تُرفع الملفات إلى دلو S3
3. يُطلب إبطال ذاكرة CloudFront لتقديم النسخة الجديدة

:::tip
للاطلاع على تعليمات النشر التفصيلية، راجع دليل [نشر تطبيقات الويب](../deployment/web-apps.md).
:::
