# B1App

<div class="article-intro">

B1App هو تطبيق الأعضاء الموجّه للجمهور في الكنيسة، مبني باستخدام Next.js. يوفّر تجربة الأعضاء، بما في ذلك الملفات الشخصية، وأدلة المجموعات، والبث المباشر، وصفحات التبرع.

</div>

<div class="prereqs">
<h4>قبل أن تبدأ</h4>

- ثبّت **Node.js 22+** و**Git** -- راجع [المتطلبات الأساسية](../setup/prerequisites.md)
- اضبط نقطة وصول واجهة البرمجة الخاصة بك (التجريبية أو المحلية) -- راجع [متغيرات البيئة](../setup/environment-variables.md)

</div>

:::warning
يتطلب B1App الإصدار 22 من Node.js أو أحدث. الإصدارات الأقدم غير مدعومة.
:::

## الإعداد

### 1. استنساخ المستودع

```bash
git clone https://github.com/ChurchApps/B1App.git
```

### 2. تثبيت الاعتماديات

```bash
cd B1App
npm install
```

### 3. ضبط متغيرات البيئة

```bash
cp dotenv.sample.txt .env
```

افتح الملف `.env` واضبط عناوين نقاط النهاية `NEXT_PUBLIC_*_API`. يمكن أن تشير هذه العناوين إلى واجهة البرمجة التجريبية المشتركة (`https://api.demo.churchapps.org`) أو إلى نسخة واجهة البرمجة المحلية لديك. قد يتضمن الملف النموذجي عناوين بيئة الاختبار المتقاعدة؛ استبدلها.

### 4. تشغيل خادم التطوير

```bash
npm run dev
```

يبدأ خادم التطوير في Next.js على العنوان [http://localhost:3301](http://localhost:3301).

## الأوامر الرئيسية

| الأمر | الوصف |
|---------|-------------|
| `npm run dev` | تشغيل خادم تطوير Next.js على المنفذ 3301 |
| `npm run build` | بناء نسخة الإنتاج عبر Next.js |
| `npm run test` | تشغيل اختبارات شاملة (end-to-end) باستخدام Playwright |
| `npm run lint` | تشغيل أداة الفحص اللغوي لـ Next.js |

## متغيرات البيئة الرئيسية

| المتغير | الوصف |
|----------|-------------|
| `NEXT_PUBLIC_*_API` | عناوين نقاط نهاية واجهة البرمجة لكل وحدة |

:::info
يقوم السكربت `postinstall` بنسخ ملفات اللغات وملفات CSS من `@churchapps/apphelper`. إذا بدت المكوّنات بلا تنسيق بعد التثبيت، فشغّل `npm run postinstall` يدوياً.
:::

## المكدس التقني

- **Next.js 16** مع TypeScript
- **React 19** لمكوّنات الواجهة
- **Material-UI 7** لنظام التصميم
- **React Query 5** لحالة الخادم
- حزم **`@churchapps/apphelper*`** للمكوّنات المشتركة

## النشر

تُنشر نسخ الإنتاج على **S3 + CloudFront**:

1. يقوم `npm run build` بإنشاء نسخة Next.js المحسّنة للإنتاج
2. تتم مزامنة مخرجات البناء مع حاوية S3
3. يُطلق إبطال ذاكرة CloudFront لتقديم النسخة الجديدة

:::tip
للاطلاع على تعليمات النشر التفصيلية، راجع دليل [نشر تطبيقات الويب](../deployment/web-apps.md).
:::
