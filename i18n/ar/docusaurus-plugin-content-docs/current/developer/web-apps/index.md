# تطبيقات الويب

<div class="article-intro">

تتضمن ChurchApps ثلاثة تطبيقات ويب، ولكل منها جمهور وغرض مختلف. وتشترك في أساس تقني واحد يتكون من React 19 وTypeScript وMaterial-UI 7، لكنها تختلف في أدوات البناء ووجهات النشر.

</div>

## نظرة سريعة على التطبيقات

| التطبيق | الغرض | إطار العمل | منفذ التطوير |
|-----|---------|-----------|----------|
| [**B1Admin**](./b1-admin.md) | لوحة إدارة الكنيسة | React 19 + Vite + MUI 7 | 5173 |
| [**B1App**](./b1-app.md) | تطبيق الأعضاء العام للكنيسة | Next.js 16 + React 19 + MUI 7 | 3301 |
| [**LessonsApp**](./lessons-app.md) | إدارة محتوى الدروس | Next.js 16 + React 19 | 3501 |

## حزمة التقنيات المشتركة

تُبنى التطبيقات الويب الثلاثة جميعها باستخدام:

- **TypeScript** -- أمان الأنواع من البداية إلى النهاية
- **React 19** -- مكتبة مكونات واجهة المستخدم
- **Material-UI 7** -- نظام التصميم ومجموعة الأدوات الخاصة بالمكونات
- **React Query 5** -- إدارة حالة الخادم

## المكونات المشتركة

تتشارك التطبيقات مكونات واجهة المستخدم والأدوات المساعدة من خلال عائلة الحزم `@churchapps/apphelper*`:

| الحزمة | الغرض |
|---------|---------|
| `@churchapps/apphelper` | مكونات React الأساسية المشتركة |
| `@churchapps/apphelper-login` | مكونات واجهة المصادقة وتسجيل الدخول |
| `@churchapps/apphelper-donations` | نماذج التبرعات والعطاء |
| `@churchapps/apphelper-forms` | مكونات منشئ النماذج |
| `@churchapps/apphelper-markdown` | عرض محتوى Markdown |
| `@churchapps/apphelper-website` | مكونات الموقع وإدارة المحتوى |

:::tip
للحصول على تفاصيل حول تطوير هذه الحزم المشتركة محليًا، راجع وثائق [AppHelper](../shared-libraries/app-helper.md).
:::

## سكربت ما بعد التثبيت

يحتوي كل تطبيق ويب على سكربت `postinstall` ينسخ ملفات اللغة وأصول CSS من `@churchapps/apphelper` إلى المشروع. يعمل هذا السكربت تلقائيًا بعد تشغيل `npm install`.

:::info
إذا بدت المكونات بدون تنسيق بعد تثبيت الاعتماديات، فقد لا يكون سكربت `postinstall` قد عمل بشكل صحيح. يمكنك تشغيله يدويًا باستخدام الأمر `npm run postinstall`.
:::

## أدوات البناء

تستخدم التطبيقات أداتي بناء مختلفتين:

- **B1Admin** يستخدم **Vite** -- أداة تجميع حديثة وسريعة، مثالية لتطبيقات الصفحة الواحدة
- **B1App** و**LessonsApp** يستخدمان **Next.js** -- ويوفران عرض الخادم والتوجيه القائم على الملفات وبناءات إنتاج محسّنة
