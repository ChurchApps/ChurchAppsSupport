# واجهة برمجة التطبيقات (API)

<div class="article-intro">

واجهة برمجة تطبيقات ChurchApps هي **حِزام معياري متجانس** -- قاعدة شيفرة واحدة تخدم ستة وحدات بيانات، ولكل منها قاعدة بيانات خاصة بها. تمنح هذه البنية المزايا التنظيمية للخدمات المصغّرة (حدود واضحة، ومخازن بيانات مستقلة) مع البساطة التشغيلية لعملية نشر واحدة.

</div>

## الوحدات

| الوحدة | الغرض |
|--------|---------|
| **Membership** | الأشخاص والمجموعات والأسر والصلاحيات |
| **Attendance** | الخدمات والجلسات وسجلات تسجيل الحضور |
| **Content** | الصفحات والأقسام والعناصر والبث المباشر |
| **Giving** | التبرعات والصناديق ومعالجة المدفوعات |
| **Messaging** | المحادثات والإشعارات والبريد الإلكتروني |
| **Doing** | المهام والخطط والتكليفات |

## المكدس التقني

- **بيئة التشغيل:** Node.js 24.x مع TypeScript (وحدات ES)
- **إطار العمل:** Express
- **حقن التبعيات:** Inversify (توجيه قائم على الديكوريترات)
- **قاعدة البيانات:** MySQL -- قاعدة بيانات واحدة لكل وحدة، ولكل منها مجمّع اتصالات خاص بها
- **المصادقة:** مصادقة قائمة على JWT عبر `CustomAuthProvider`
- **النشر:** AWS Lambda باستخدام Serverless Framework v3

## المنافذ

| البروتوكول | المنفذ | الوصف |
|----------|------|-------------|
| HTTP | `8084` | واجهة REST الرئيسية |
| WebSocket | `8087` | اتصالات السوكِت في الوقت الفعلي |

## دوال Lambda

عند النشر على AWS، تعمل واجهة البرمجة كستّ دوال Lambda:

- **`web`** -- يعالج جميع طلبات HTTP
- **`socket`** -- يدير اتصالات WebSocket
- **`timer15Min`** -- يعمل كل 30 دقيقة لإشعارات البريد الإلكتروني (الاسم تاريخي)
- **`timerMidnight`** -- يعمل يومياً لرسائل الملخص البريدي ومهام الصيانة
- **`timerScheduledTasks`** -- يعمل يومياً للأتمتة المستحقة ومعالجة سير العمل المتأخر
- **`timerWebhooks`** -- يعمل كل دقيقة لتسليم خطافات الويب الصادرة المنتظرة

## المكتبات المشتركة

تعتمد واجهة البرمجة على حزمتين مشتركتين من ChurchApps:

- **[`@churchapps/helpers`](../shared-libraries/helpers)** -- أدوات أساسية (DateHelper وApiHelper وغيرهما)
- **[`@churchapps/apihelper`](../shared-libraries/api-helper)** -- أدوات خادم Express، تشمل المصادقة ومساعدات قاعدة البيانات وتكاملات AWS

:::info
تستخدم واجهة البرمجة وحدات ES (`"type": "module"` في `package.json`). تأكد من أن عمليات الاستيراد لديك تستخدم صياغة وحدات ES.
:::
