# نقاط نهاية المحتوى

<div class="article-intro">

تدير وحدة المحتوى صفحات الموقع والأقسام والعناصر والكتل ومقالات المدونة وعمليات إعادة التوجيه والعظات وقوائم التشغيل وخدمات البث والفعاليات والتقويمات المنسقة والملفات والمعارض وترجمات الكتاب المقدس والبحث عن الآيات والترانيم والتوزيعات الموسيقية والأنماط العامة وصور المخزون والإعدادات. وهي أكبر وحدة في الواجهة البرمجية، وتشغّل نظام إدارة المحتوى وميزات الوسائط والبث وتخطيط العبادة وميزات الكتاب المقدس في جميع تطبيقات ChurchApps.

</div>

**المسار الأساسي:** `/content`

## الصفحات

المسار الأساسي: `/content/pages`

| الطريقة | المسار | المصادقة | الصلاحية | الوصف |
|--------|------|------|------|------|
| GET | `/:churchId/tree?url=&id=` | عامة | — | تحميل شجرة الصفحة الكاملة (الأقسام والعناصر والكتل) حسب الرابط أو المعرّف. تُزال المعرّفات الداخلية عند الجلب حسب الرابط. تطبّق عمليات الجلب المعتمدة على الرابط القيد `pages.visibility`، فتُرجع الصفحة المقيّدة `{ restricted: true, visibility }` ما لم يستوفِ رمز JWT الاختياري هذا القيد |
| GET | `/public/:churchId` | عامة | — | عرض الصفحات العامة (`url` و`title` و`metaDescription`) فقط التي قيمة `visibility` فيها `everyone` |
| GET | `/:id` | JWT | — | جلب صفحة حسب المعرّف |
| GET | `/` | JWT | — | عرض جميع صفحات الكنيسة |
| POST | `/duplicate/:id` | JWT | Content.Edit | نسخ صفحة مع جميع أقسامها وعناصرها |
| POST | `/temp/ai` | JWT | Content.Edit | حفظ صفحة مُنشأة بالذكاء الاصطناعي (الصفحة والأقسام والعناصر في استدعاء واحد) |
| POST | `/importTree` | JWT | Content.Edit | إنشاء صفحة من شجرة متداخلة (`title` و`url` و`sections[].elements[]…`). تُدرج دائماً ضمن كنيسة المستدعي، وتُتجاهل المعرّفات الواردة في الطلب. يجب أن تتضمن الصفوف عناصرها الفرعية `column`. الحد الأقصى 30 قسماً و500 عنصر |
| POST | `/` | JWT | Content.Edit | إنشاء الصفحات أو تحديثها (دفعات) |
| DELETE | `/:id` | JWT | Content.Edit | حذف صفحة |

### مثال: تحميل شجرة الصفحة

```
GET /content/pages/abc-church-id/tree?url=/about
```

```json
{
  "name": "About",
  "url": "/about",
  "sections": [
    {
      "background": "#FFFFFF",
      "textColor": "dark",
      "elements": [
        { "elementType": "textWithPhoto", "answers": { "text": "Welcome" } }
      ]
    }
  ]
}
```

## عمليات إعادة التوجيه

المسار الأساسي: `/content/redirects`

عمليات إعادة توجيه عناوين URL لكل كنيسة (`fromPath` ← `toPath`)، بحد أقصى 200 لكل كنيسة. تُوحَّد المسارات (أحرف صغيرة، وشرطة مائلة في البداية، وبدون شرطة مائلة في النهاية)، والقيمة `fromPath` فريدة لكل كنيسة. يحلّ B1App هذه المسارات عند حدوث أخطاء 404 محتملة، ويُصدر استجابة HTTP 308.

| الطريقة | المسار | المصادقة | الصلاحية | الوصف |
|--------|------|------|------|------|
| GET | `/public/:churchId?path=` | عامة | — | حلّ مسار (أو عرض جميع عمليات إعادة التوجيه عند حذف `path`) |
| GET | `/:id` | JWT | — | جلب عملية إعادة توجيه حسب المعرّف |
| GET | `/` | JWT | — | عرض جميع عمليات إعادة التوجيه للكنيسة |
| POST | `/` | JWT | Content.Edit | إنشاء عمليات إعادة التوجيه أو تحديثها. يرفض `fromPath = toPath` ويفرض الحد الأقصى البالغ 200 صف |
| DELETE | `/:id` | JWT | Content.Edit | حذف عملية إعادة توجيه |

## الكتب المقدسة

المسار الأساسي: `/content/bibles`

جميع نقاط نهاية الكتاب المقدس عامة (لا تتطلب مصادقة). تُجلب البيانات من مصادر خارجية وتُخزَّن مؤقتاً محلياً. تنتهي مهلة الطلبات إلى api.bible بعد 15 ثانية، وتُرجع المهلة المنتهية **504**.

| الطريقة | المسار | المصادقة | الصلاحية | الوصف |
|--------|------|------|------|------|
| GET | `/` | عامة | — | عرض جميع ترجمات الكتاب المقدس (تُجلب من المصدر إذا كانت الذاكرة المؤقتة فارغة) |
| GET | `/stats?startDate=&endDate=` | عامة | — | جلب إحصاءات البحث في الكتاب المقدس لنطاق تاريخي |
| GET | `/availableTranslations/:source` | عامة | — | عرض الترجمات المتاحة من مصدر (مثل api.bible) |
| GET | `/updateTranslations` | عامة | — | مزامنة جميع الترجمات من جميع المصادر |
| GET | `/updateTranslations/:source` | عامة | — | مزامنة الترجمات من مصدر محدد |
| GET | `/updateCopyrights` | عامة | — | تحديث معلومات حقوق النشر للترجمات التي تفتقر إليها |
| GET | `/:translationKey/updateCopyright` | عامة | — | تحديث حقوق النشر لترجمة محددة |
| GET | `/:translationKey/search?query=&limit=` | عامة | — | البحث عن الآيات في ترجمة |
| GET | `/:translationKey/books` | عامة | — | جلب أسفار ترجمة (تُخزَّن مؤقتاً محلياً) |
| GET | `/:translationKey/:bookKey/chapters` | عامة | — | جلب إصحاحات سِفر (تُخزَّن مؤقتاً محلياً) |
| GET | `/:translationKey/chapters/:chapterKey/verses` | عامة | — | جلب آيات إصحاح (تُخزَّن مؤقتاً محلياً) |
| GET | `/:translationKey/verses/:startVerseKey-:endVerseKey` | عامة | — | جلب نص الآيات لنطاق. تُسجَّل عمليات البحث. تتجاوز بعض الترجمات الذاكرة المؤقتة لأسباب تتعلق بالترخيص |

```
GET /content/bibles/de4e12af7f28f599-02/verses/GEN.1.1-GEN.1.3
```

```json
  { "verseKey": "GEN.1.2", "content": "Now the earth was formless and empty...", "bookKey": "GEN", "chapterNumber": 1, "verseNumber": 2 },
  { "verseKey": "GEN.1.3", "content": "And God said, \"Let there be light,\" and there was light.", "bookKey": "GEN", "chapterNumber": 1, "verseNumber": 3 }
]
```
