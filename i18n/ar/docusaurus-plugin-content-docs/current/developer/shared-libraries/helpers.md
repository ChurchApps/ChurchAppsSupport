# Helpers

<div class="article-intro">

تُوفّر حزمة `@churchapps/helpers` الأدوات الأساسية المشتركة التي تستخدمها جميع مشاريع ChurchApps، سواء في الواجهات الأمامية أو الخلفية. وهي مستقلة عن أي إطار عمل، وتتضمن أدوات مساعدة شائعة مثل `DateHelper` و`ApiHelper` و`CurrencyHelper`، إلى جانب واجهات TypeScript المشتركة التي تشكّل عقد البيانات بين التطبيقات وواجهات البرمجة.

</div>

<div class="prereqs">
<h4>قبل أن تبدأ</h4>

- ثبّت **Node.js** و**Git** -- راجع [المتطلبات الأساسية](../setup/prerequisites)
- تعرّف على إعداد [مساحة عمل الحزم](./index.md) وسير عمل الإصدار

</div>

## من يستخدم هذه الحزمة

تعتمد كل واجهات برمجة ChurchApps (الواجهة الأساسية Api وAskApi وLessonsApi) وكل واجهة أمامية للويب (B1Admin وB1App وB1Transfer وLessonsApp) على هذه الحزمة مباشرةً. كما تحصل الواجهات الأمامية على كثير من صادراتها (`ApiHelper` و`DateHelper` و`UserHelper` وواجهات أخرى) عبر إعادة التصدير من خلال [`@churchapps/apphelper`](./app-helper). وتعلن الحزم المشتركة الأخرى هذه الحزمة كتبعية نظيرة (peer dependency) حتى يحلّ كل تطبيق نسخةً واحدةً بالضبط منها.

## الإعداد للتطوير المحلي

تقع هذه الحزمة في [مساحة عمل Packages](https://github.com/ChurchApps/Packages) إلى جانب المكتبات المشتركة الأخرى:

1. انسخ مساحة العمل:

   ```bash
   git clone https://github.com/ChurchApps/Packages.git
   ```

2. ثبّت التبعيات في جذر مساحة العمل:

   ```bash
   cd Packages && yarn install
   ```

3. ابنِ الحزمة (يُترجم TypeScript إلى `dist/`):

   ```bash
   yarn workspace @churchapps/helpers build
   ```

   أو شغّل `yarn build` في الجذر لبناء كل الحزم بالترتيب الذي تفرضه التبعيات.

لاختبار التغييرات داخل مشروع مستهلك، استخدم بوابة Yarn مؤقتة -- راجع [التطوير المحلي مع تطبيق مستهلك](./index.md#local-development-against-a-consuming-app).

## النشر

تمرّ الإصدارات عبر changesets بدلًا من رفع الإصدارات يدويًا:

1. شغّل `yarn changeset` في جذر مساحة العمل واختر `@churchapps/helpers` مع نوع الترقية المناسب؛ ثم أودِع ملف changeset الناتج مع تغييرك.
2. عند الاستعداد للإصدار، شغّل `yarn publish-all` في الجذر -- فهو يرفع الإصدارات، ويكتب ملفات CHANGELOG، ويبني الحزم بترتيب التبعيات، وينشرها على npm.

تُضاف الواجهات المشتركة الجديدة إلى `helpers/src/interfaces/` وتُعاد تصديرها عبر الملف الرئيسي للحزمة (barrel). كما يوجد هنا أيضًا كتالوج أنواع العناصر لمنشئ المواقع (`ElementTypes.ts` -- 35 نوعًا مع مخططات إجاباتها)، وهو العقد المشترك بين عارضات apphelper ونماذج المحرر في B1Admin وتعليمات توليد الذكاء الاصطناعي (راجع [بنية منشئ المواقع](../architecture/website-builder)).

:::warning
بما أن هذه الحزمة تُستخدم في كل مشاريع ChurchApps، فإن لأي تغيير هنا أثرًا واسعًا. يؤدي إصدار `helpers` تلقائيًا إلى رفع إصدارات `apihelper` و`apphelper` حتى تبقى نطاقات تبعياتها محدّثة. اختبر باستخدام بوابة Yarn في واجهة برمجية مستهلكة واحدة على الأقل وتطبيق ويب مستهلك واحد على الأقل قبل النشر.
:::
