# Digital signaler

<div class="article-intro">

Send leksjons innhold til ett lobby eller gang TV ved bruk av ett digital signaler feed. Hver plan type får ett feed URL som alltid spiller gjeldende plans innhold.

</div>

<div class="prereqs">
<h4>Før du starter</h4>

- Sett opp en plan type med Lessons.church eller annet leksjons innhold planlagt
- Ha en SignPresenter konto og en enhet satt opp for å vise det

</div>

## Få feed URL

1. Naviger til betjening og åpne ministeriet som inneholder plan typen
2. Klikk digital signaler knappen på plan type siden
3. Kopier feed URL vist i dialogen
