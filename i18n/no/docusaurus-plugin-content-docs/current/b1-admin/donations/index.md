# Gaver

<div class="article-intro">

Gaver-seksjonen i B1 Admin gir deg alt du trenger for å administrere menighetens giving. Fra å registrere ukentlige offergaver til å generere årsoppgaver for skatt er alle gaveverktøyene samlet på ett sted, slik at du kan holde oversikt over menighetens økonomi.

</div>

## Undersider

Du finner følgende sider i Gaver-seksjonen:

### Oversikt

Siden **Oversikt** gir deg en visuell oppsummering av all giving-aktivitet. Den viser diagrammer og filtrerte rapporter, slik at du raskt kan se givertrender i menigheten din. Se [Gaverapporter](donation-reports.md) for mer om bruk av oversikten og rapportverktøyene.

### Batcher

**[Batcher](batches.md)** lar deg gruppere gaver sammen – for eksempel alle sjekker og kontanter som samles inn under en søndagsoffer. Hver batch registrerer antall gaver og totalbeløp for enkel avstemming. Når en batch er talt opp, kan noen med tillatelsen **Rediger gaver** lukke den, slik at tellefrivillige ikke lenger kan endre den. Frivillige med tillatelsen **Registrer gaver** kan legge til gaver i åpne batcher uten å se resten av Gaver-seksjonen.

### Fond

**[Fond](funds.md)** kategoriserer gavene dine etter formål. Vanlige eksempler er Generelt fond, Byggefond og Misjon. Du kan merke hvert fond som skattefradragsberettiget eller ikke.

### Gaveoppgaver

Siden **[Gaveoppgaver](giving-statements.md)** lager årsoppgaver over gaver for giverne dine. Du kan laste ned enkeltvise CSV-filer, eller skrive ut alle oppgavene samtidig.

### Stripe-import

Hvis du tar imot nettgaver via Stripe, lar verktøyet **[Stripe-import](stripe-import.md)** deg hente disse transaksjonene inn i B1 Admin, slik at alt ligger i ett system.

## Nettgaver

B1 Admin integrerer med **Stripe** og **PayPal** for å ta imot nettgaver. Når det er satt opp, kan medlemmer gi via B1.church-nettstedet ditt, og disse gavene havner automatisk i registrene dine. Se [Oppsett av nettgaver](online-giving-setup.md) for å komme i gang.

:::tip
Hvis du er ny med gaver i B1 Admin, start med å [sette opp fondene dine](funds.md), deretter [opprette din første batch](batches.md) og [registrere gaver](recording-donations.md) i den.
:::
