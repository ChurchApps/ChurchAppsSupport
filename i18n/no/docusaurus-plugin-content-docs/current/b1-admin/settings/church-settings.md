# Kirke innstillinger

<div class="article-intro">

Kirke innstillinger siden er hvor du konfigurerer kirkens grunnleggende informasjon, kontakt detalj og branding. Disse detaljer brukes på tvers av alle ChurchApps verktøy.

</div>

<div class="prereqs">
<h4>Før du starter</h4>

- Du trenger "rediger kirke innstillinger" tillatelsen.
- Ha kirkens adresse, kontakt informasjon og logo klar

</div>

## Redigering av kirke informasjon

1. I B1 Admin, åpne seksjonsmeny og velg innstillinger
2. Klikk rediger innstillinger knappen i header
3. Oppdater alle felt som trengs
4. Klikk lagre for å bruke endringene
