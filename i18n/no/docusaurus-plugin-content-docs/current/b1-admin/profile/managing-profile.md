# Administrering av profil

<div class="article-intro">

Profil siden lar deg redigere personlige konto innstillinger. Profilen ditt er delt på tvers av alle ChurchApps produkter, slik at endringer gjøres vil bli reflektert overalt.

</div>

<div class="prereqs">
<h4>Før du starter</h4>

- Du må være innlogget på ChurchApps kontoen
- Ha ny e-post adresse eller passord klar hvis du planlegger å oppdatere dem

</div>

## Profil informasjon

Topp delen av profil siden inneholder grunnleggende konto detaljer dine.

1. E-post -- Din e-post adresse brukt for innlogging
2. Fornavn og etternavn -- Visning navn på tvers av ChurchApps
3. Passord -- Oppdater konto passord
