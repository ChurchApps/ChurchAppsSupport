# Godkjenning av profil endringer

<div class="article-intro">

Når kirken din krever administrator godkjenning for profil oppdateringer, sender medlemmer endringer gjennom B1 mobilappen og disse forespørslene vises som oppgaver i B1 Admin.

</div>

<div class="prereqs">
<h4>Før du starter</h4>

- Du må være medlem av gruppen utpekt som katalog godkjennings gruppe
- Hvis ingen godkjennings gruppe er konfigurert, brukes profil endringer umiddelbar

</div>

## Hvor du finner ventende forespørsler

Når ett medlem sender inn ett profil endring, vises det som ett oppgave tildelt godkjennings gruppen din.
