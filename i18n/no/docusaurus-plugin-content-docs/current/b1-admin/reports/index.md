# Rapporter

<div class="article-intro">

B1 Admin gir deg flere måter å trekke data om menigheten, oppmøte og givergang. Rapportering er bygget inn i de relevante seksjonene av appen i stedet for en enkelt rapporter side.

</div>

## Hvor du finner rapporter

### Mennesker
Fødselsdag & jubileums lister -- Filtrer etter fødselsmåned eller jubileumsånedom

### Oppmøte
Oppmøte rapporter -- Oppmøte trender og gruppe oppmøte data

### Donasjoner
Donasjons sammendrag -- Givergang totaler og fond sammenbrudd

### Innstillinger
Revisjon logg -- Spor alle endringer og handlinger på tvers av kirke administrasjons systemet
