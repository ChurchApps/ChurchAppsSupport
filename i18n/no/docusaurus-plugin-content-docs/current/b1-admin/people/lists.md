# Lagrede lister

<div class="article-intro">

Lagrede lister lar deg lagre ett søk spørsmål under ett navn og kjøre det igjen med ett klikk når som helst. Bygg ett liste en gang og det forblir i de lagrede lister panelet på mennesker siden.

</div>

<div class="prereqs">
<h4>Før du starter</h4>

- Kjør minst ett søk i mennesker delen slik at du har resultater å lagre.

</div>

## Lagring av ett søk som ett liste

1. Kjør ett søk på mennesker siden.
2. Når resultatene vises, vises en Lagre som liste knapp i siden header.
3. Klikk Lagre som liste.
4. Skriv inn ett navn for listen.
5. Valgfritt skriv inn en kategori.
6. Klikk Lagre.
