# Mailchimp

<div class="article-intro">

Hold en Mailchimp publikum i synk med B1 automatisk: mennesker flyter inn med navn, e-post og telefon; gruppe og liste medlemskap blir Mailchimp merker; slettede mennesker er arkivert.

</div>

<div class="prereqs">
<h4>Før du starter</h4>

- En Mailchimp konto med publikum du vil B1 skal administrere
- En Mailchimp API nøkkel
- Din publikums ID
- En B1Admin bruker med rediger innstillinger tillatelse

</div>

## Hva synks

B1 endringer blir synkronisert til Mailchimp med medlems navn, e-post, telefon og merker basert på gruppe medlemskap.
