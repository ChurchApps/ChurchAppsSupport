# Navigasjons stiler

<div class="article-intro">

Tilpass kirkens nettsteds navigasjons bar farger for å samsvare med merkingen. Du kan konfigurere farger for både solide bakgrunner og transparente overlegg.

</div>

<div class="prereqs">
<h4>Før du starter</h4>

- Du trenger tillatelse til å administrere kirkens nettsted.
- Ha merkefargene dine klare, inkludert hex farger koder
- Forstå forskjellen mellom solid og transparent navigasjons stiler

</div>

## Forståelse av navigasjons modus

Nettstedets navigasjon kan vises i to ulike stiler:

- Solid navigasjon - navigasjons bar med bakgrunns farge
- Transparent navigasjon - navigasjon som overlegger siden innhold
