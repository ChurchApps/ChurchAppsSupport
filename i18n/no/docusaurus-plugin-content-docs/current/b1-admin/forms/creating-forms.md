# Opprett skjemaer

<div class="article-intro">

Bygg egendefinerte skjemaer for å samle informasjon fra menigheten. Du kan opprette skjemaer for hendelses registreringer, undersøkelser, besøks kort, medlemskap søknader og mer. Skjemaer kan knyttes til mennesker i databasen eller brukes som selvstendige sider med deres egne offentlige URL.

</div>

<div class="prereqs">
<h4>Før du starter</h4>

- For mennesker skjemaer (knyttet til person poster), trenger du mennesker i databasen først.
- For skjemaer som samler betalinger, må du ha Stripe konfigurert for online givergang.

</div>

## Opprett et nytt skjema

1. Naviger til Skjemaer fra hoved menyen.
2. Klikk Legg til skjema.
3. Skriv inn ett navn for skjemaet.
4. Velg skjema type fra rullegardinlisten.
5. Klikk Lagre for å opprette skjemaet.

## Legger til spørsmål

1. Åpne skjemaet og gå til Spørsmål fanen.
2. Klikk Legg til spørsmål.
3. Velg ett felt type fra rullegardinlisten.
4. Skriv inn ett tittel og valgfri beskrivelse for spørsmålet.
5. Kontroller Krev et svar hvis feltet er obligatorisk.
6. Klikk Lagre.
7. Gjenta for å legge til flere spørsmål.
