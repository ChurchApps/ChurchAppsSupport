# B1.church

<div class="article-intro">

B1.church er medlemsportalen for kirken din. Det er stedet der menigheten går for å holde kontakt, få tilgang til kirkeverktøy og engasjere seg i fellesskapet gjennom uken. Hver kirke får sin egen adresse på `https://yourchurchname.b1.church`.

</div>

Når medlemmer besøker B1.church-nettstedet ditt, ser de kirkens offentlige nettsted med din profil, navigasjonslenker og innholdssider. Etter innlogging kan de åpne **Medlemsportalen**, der alle deres personlige kirkeverktøy ligger samlet på ett sted.

## Viktige funksjoner

- **Hjem og Meg** — medlemsportalen åpnes på et [Hjem-dashbord](./getting-started/navigating.md) med forhåndsvisninger av dine kommende tjenesteoppdrag, gruppene dine og gavene dine i år, og [Meg-siden](./getting-started/me-page.md) lister opp det som kommer for deg — tjenesteoppdrag, arrangementspåmeldinger, gruppearrangementer — sammen med dine nyeste varsler, skjemaene du har sendt inn og oppmøtehistorikken din.
- **Grupper** — se gruppene du tilhører, se gruppemedlemmer, delta i samtaler, følg oppmøte og fyll ut skjemaer knyttet til gruppen din (ledere kan lese og skrive ut svarene).
- **Gaver** — gi gaver til kirken din på nett og se gavehistorikken og oppgavene dine, selv om kirken din ikke tar imot gaver på nett.
- **Arrangementer** — bla gjennom kommende arrangementer og meld deg selv og familien din på.
- **Tjeneste** — se planer for gudstjenester, dine frivilligposisjoner og meld deg på ledige frivillige oppdrag. Velg å få tjeneste- og arrangementspåminnelser som tekst i dine [varslingsinnstillinger](./getting-started/notification-preferences.md) (svar STOPP når som helst for å slutte).
- **Planer** — se kommende gudstjenesteplaner, aksepter eller avslå dine tildelte posisjoner, og få tilgang til sangdetaljer og gudstjenesteprogrammer.
- **Innsjekking** — sjekk deg selv og husstandsmedlemmene dine inn til gudstjenester og arrangementer. Gjester kan registrere seg via QR-kode, og gjenkommende gjester kobles til sin eksisterende profil i stedet for å bli lagt til to ganger.
- **Fellesskapskatalog** — bla gjennom kirkens medlemskatalog, se profiler og send direktemeldinger. Kontroller hvem som kan se din egen kontaktinformasjon fra [seksjonen Personvern i profilen din](./getting-started/editing-your-profile.md#privacy).
- **Innloggingssikkerhet** — logg inn med en kode fra autentiseringsappen i tillegg til passordet ditt når du har slått på [tofaktorpålogging](../b1-admin/profile/managing-profile.md#two-factor-sign-in).
- **Innhold** — få tilgang til taler, les Bibelen, se direktesendinger, og vis, del eller last ned dagsverset (og tidligere vers), alt fra kirkens nettsted. (Avspilling av læreplaner ligger nå i [FreePlay](/docs/freeplay/) — fanen Leksjoner i portalen er avviklet.)
