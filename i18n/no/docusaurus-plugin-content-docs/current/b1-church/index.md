# B1.church

<div class="article-intro">

B1.church er medlemsportalen for menigheten din. Det er stedet der menigheten din går for å holde seg i kontakt, få tilgang til kirkeverktøy og engasjere seg i fellesskapet gjennom hele uken. Hver menighet får sin egen nettadresse på `https://yourchurchname.b1.church`.

</div>

Når medlemmer besøker B1.church-nettstedet ditt, ser de menighetens offentlige nettsted med din profilering, navigasjonslenker og innholdssider. Etter innlogging kan de få tilgang til **medlemsportalen**, der alle deres personlige kirkeverktøy ligger samlet på ett sted.

## Viktige funksjoner

- **Hjem og Me** -- medlemsportalen åpnes på et [Hjem-dashbord](./getting-started/navigating.md) med forhåndsvisninger av dine kommende tjenesteoppdrag, grupper og gaver i år. [Me-siden](./getting-started/me-page.md) viser hva som kommer opp for deg, som tjenesteoppdrag, arrangementspåmeldinger og gruppearrangementer, sammen med nylige varsler, skjemaer du har sendt inn og oppmøtehistorikken din.
- **Grupper** -- se gruppene du tilhører, se gruppemedlemmer, delta i samtaler, før oppmøte og fyll ut skjemaer som er koblet til gruppen din (ledere kan lese og skrive ut svarene).
- **Gaver** -- gi gaver til menigheten din på nett, og se gavehistorikken og oppgavene dine, selv om menigheten din ikke tar imot gaver på nett.
- **Arrangementer** -- bla gjennom kommende arrangementer og meld deg selv og familien din på.
- **Tjeneste** -- se tjenesteplaner, dine frivillige verv og meld deg på åpne frivillige oppgaver. Velg å få påminnelser om tjeneste og arrangementer på SMS i dine [varslingsinnstillinger](./getting-started/notification-preferences.md). Svar STOPP når som helst for å slutte.
- **Planer** -- se kommende tjenesteplaner, aksepter eller avslå dine tildelte verv, og få tilgang til sangdetaljer og tjenesteordener.
- **Innsjekking** -- sjekk deg selv og husstandsmedlemmene dine inn til gudstjenester og arrangementer. Gjester kan registrere seg via QR-kode.
- **Medlemskatalog** -- bla gjennom menighetens medlemskatalog, se profiler og send direktemeldinger. Kontroller hvem som kan se din egen kontaktinformasjon fra [profilens personvernseksjon](./getting-started/editing-your-profile.md#privacy).
- **Innhold** -- få tilgang til preker, les Bibelen, se direktesendinger og vis, del eller last ned dagens vers (og tidligere vers), alt fra menighetens nettsted. (Avspilling av læreplan ligger nå i [FreePlay](/docs/freeplay/). Fanen Leksjoner i portalen er utgått.)
