# B1.church {#b1church}

<div class="article-intro">

B1.church er medlemsportalen for kirken din, rettet mot menigheten. Det er stedet der medlemmene går for å holde kontakten, få tilgang til kirkeverktøy og engasjere seg i fellesskapet gjennom uken. Hver kirke får sin egen nettadresse på `https://yourchurchname.b1.church`.

</div>

Når medlemmer besøker B1.church-siden din, ser de kirkens offentlige nettside med din profil, navigasjonslenker og innholdssider. Etter innlogging får de tilgang til **Medlemsportalen**, der alle deres personlige kirkeverktøy ligger samlet på ett sted.

## Hovedfunksjoner {#key-features}

- **Hjem og Meg** – Medlemsportalen åpnes på et [Hjem-dashbord](./getting-started/navigating.md) med forhåndsvisninger av dine kommende tjenesteoppdrag, gruppene dine og gavene dine i år. [Meg-siden](./getting-started/me-page.md) lister opp det som kommer for deg – tjenesteoppdrag, arrangementspåmeldinger og gruppearrangementer – sammen med de nyeste varslene dine, skjemaene du har sendt inn og oppmøtehistorikken din.
- **Grupper** – Se gruppene du er med i, se gruppemedlemmer, bli med i samtaler og følg oppmøte.
- **Gaver** – Gi gaver til kirken din på nett og se gavehistorikken din.
- **Arrangementer** – Bla gjennom kommende arrangementer og meld deg og familien din på.
- **Tjeneste** – Se tjenesteplaner, dine frivillige verv, og meld deg på åpne frivilligmuligheter. Velg å få tjeneste- og arrangementspåminnelser som SMS i [varslingsinnstillingene](./getting-started/notification-preferences.md) (svar STOPP når som helst for å slutte).
- **Planer** – Se kommende tjenesteplaner, aksepter eller avslå dine tildelte verv, og få tilgang til sangdetaljer og gudstjenesteordener.
- **Innsjekking** – Sjekk deg selv og husstandsmedlemmene dine inn til gudstjenester og arrangementer. Gjester kan registrere seg via QR-kode.
- **Medlemskatalog** – Bla i kirkens medlemskatalog, se profiler og send direktemeldinger. Styr hvem som kan se din egen kontaktinformasjon fra [profilens personverndel](./getting-started/editing-your-profile.md#privacy).
- **Innhold** – Få tilgang til prekener, les Bibelen, se direktesendinger og se dagens vers, alt fra kirkens side. (Avspilling av læremateriell ligger nå i [FreePlay](/docs/freeplay/). Fanen Leksjoner i portalen er utgått.)
