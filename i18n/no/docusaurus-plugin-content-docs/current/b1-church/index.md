# B1.church

<div class="article-intro">

B1.church er medlemsportalen for kirken din. Det er stedet menigheten går for å holde kontakten, få tilgang til kirkeverktøy og engasjere seg i fellesskapet gjennom uken. Hver kirke får sin egen URL på `https://dinkirkenavn.b1.church`.

</div>

Når medlemmer besøker B1.church-nettstedet ditt, ser de kirkens offentlige nettsted med profilen din, navigasjonslenker og innholdssider. Etter innlogging kan de åpne **Medlemsportalen**, der alle deres personlige kirkeverktøy ligger samlet på ett sted.

## Viktige funksjoner

- **Hjem og Meg** -- Medlemsportalen åpner på en [hjemmeoversikt](./getting-started/navigating.md) med forhåndsvisninger av dine kommende tjenesteoppdrag, gruppene dine og gavene dine i år, og [Meg-siden](./getting-started/me-page.md) viser det som kommer for deg -- tjenesteoppdrag, arrangementspåmeldinger, gruppearrangementer -- sammen med de nyeste varslene dine, skjemaene du har sendt inn, og oppmøtehistorikken din.
- **Grupper** -- Se gruppene du er medlem av, se gruppemedlemmer, delta i samtaler, følg oppmøte og fyll ut skjemaer knyttet til gruppen din (ledere kan lese og skrive ut svarene).
- **Gaver** -- Gi gaver til kirken din på nett, og se gavehistorikken og giveroppgavene dine, selv om kirken din ikke tar imot gaver på nett.
- **Arrangementer** -- Bla gjennom kommende arrangementer og meld deg selv og familien din på.
- **Tjeneste** -- Se tjenesteplaner, dine frivillige posisjoner, og meld deg på ledige frivillige oppgaver. Velg å få påminnelser om tjeneste og arrangementer per SMS i [varslingsinnstillingene dine](./getting-started/notification-preferences.md) (svar STOPP når som helst for å slutte).
- **Planer** -- Se kommende tjenesteplaner, godta eller avslå dine tildelte posisjoner, og få tilgang til sangdetaljer og gudstjenesteordener.
- **Innsjekking** -- Sjekk deg selv og husstanden din inn til gudstjenester og arrangementer. Gjester kan registrere seg via QR-kode, og tilbakevendende gjester kobles til sin eksisterende profil i stedet for å bli lagt til to ganger.
- **Fellesskapskatalog** -- Bla i kirkens medlemskatalog, se profiler og send direktemeldinger. Kontroller hvem som kan se kontaktopplysningene dine via [personvernseksjonen i profilen din](./getting-started/editing-your-profile.md#privacy).
- **Sikkerhet ved innlogging** -- Logg inn med en kode fra en autentiseringsapp i tillegg til passordet ditt når du har slått på [tofaktorinnlogging](../b1-admin/profile/managing-profile.md#two-factor-sign-in).
- **Innhold** -- Få tilgang til prekener, les Bibelen, se direktesendinger, og se, del eller last ned dagens vers (og tidligere), alt fra kirkens nettsted. (Avspilling av læreplaner ligger nå i [FreePlay](/docs/freeplay/) -- fanen Leksjoner i portalen er utfaset.)
