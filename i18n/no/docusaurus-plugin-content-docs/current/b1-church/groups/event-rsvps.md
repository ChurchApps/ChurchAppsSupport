# Hendelses svar

<div class="article-intro">

Gruppe hendelser kan samle svar slik ledere vet hvem som kommer. På gruppens kalender, hver kommende hendelse spør "Vil du delta?" - svar med ett trykk.

</div>

<div class="prereqs">
<h4>Før du starter</h4>

- Du må være innlogget og medlem av gruppen
- Hendelsen må ha svar tillatt

</div>

## Svar på en hendelse

1. Åpne gruppen i medlems portal og gå til dens hendelser eller kalender visning
2. Hvert kommende hendelse kort viser "Vil du delta?" med tre knapper
3. Trykk svaret ditt
