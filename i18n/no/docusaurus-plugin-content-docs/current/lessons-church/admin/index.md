# Administrasjon

<div class="article-intro">

Administrasjonsområdet i Lessons.church er der innholdsskapere og administratorer håndterer leksjonsbiblioteket. Herfra kan du bygge opp læreplanstrukturen din, laste opp ressurser, se bruksstatistikk og koble til tredjepartsleverandører av innhold.

</div>

:::warning
Tilgang til administrasjon krever riktige tillatelser. Hvis du ikke ser administrasjonsalternativene, kontakt kirkeadministratoren din for å be om tilgang.
:::

## Hva du kan gjøre

Administrasjonsområdet gir deg full kontroll over innholdet ditt:

- **Opprette og redigere programmer** -- Sett opp læreplanserier på toppnivå med navn, beskrivelser, bilder og slugs.
- **Administrere studier** -- Organiser grupper av relaterte leksjoner innenfor hvert program.
- **Bygge leksjoner** -- Legg til enkeltleksjoner med varianter, seksjoner, roller og handlinger.
- **Laste opp ressurser** -- Legg ved nedlastbare filer (PDF-er, aktivitetsark, bilder) på program-, studie- eller leksjonsnivå.
- **Se statistikk** -- Se hvilket innhold som lastes ned, av hvem og hvor.
- **Konfigurere leverandører** -- Koble til eksterne læreplanleverandører som bruker Open Lesson Format. Dette gjøres fra siden **Eksterne leverandører**, ikke fra administrasjonsområdet.
- **Årsplaner** -- Publiser sekvenser for uke 1, 2, 3… for en hvilken som helst læreplan. Kirker bruker dem i B1 Admin.

## Innholdshierarki

Som administrator er det nyttig å forstå hvordan innholdet er strukturert:

1. **Programmer** inneholder ett eller flere studier.
2. **Studier** inneholder én eller flere leksjoner.
3. **Leksjoner** inneholder en eller flere varianter (tilpasninger for aldersgrupper).
4. **Varianter** inneholder seksjoner, og seksjoner inneholder rollebaserte handlinger.

Hvert nivå kan ha sine egne nedlastbare ressurser lagt ved.
