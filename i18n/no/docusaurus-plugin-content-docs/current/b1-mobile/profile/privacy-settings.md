# Personverninnstillinger

<div class="article-intro">

Fanen **Synlighet** på profilskjermen lar deg styre hva andre kirkemedlemmer kan se om deg i katalogen. Du bestemmer hvilke personlige opplysninger som deles offentlig, og hvilke som forblir private.

</div>

<div class="prereqs">
<h4>Før du begynner</h4>

- [Installer B1 Mobile](../getting-started/installing) og [logg inn](../getting-started/logging-in) på kontoen din

</div>

## Styre synligheten din

1. Åpne sidemenyen og trykk på **Profil**.
2. Velg fanen **Synlighet**.
3. Gå gjennom hvert felt og velg om det skal være synlig for andre medlemmer.
4. Lagre endringene.

Du kan styre synligheten for opplysninger som:

- **Telefonnummer** -- Om andre medlemmer kan se telefonnummeret ditt
- **E-postadresse** -- Om e-posten din vises i [katalogen](../community/member-directory.md)
- **Adresse** -- Om hjemmeadressen din er synlig for andre

Som standard kan kirken din ha enkelte felt synlige eller skjulte. Du kan justere disse innstillingene når som helst, slik at de passer deg.

:::tip
Hvis du er usikker på hva andre kan se, gå til fanen **Synlighet** og gjennomgå de gjeldende innstillingene dine. Du kan alltid endre dem senere.
:::

## Ventende endringer

Fanen **Venter** viser profiloppdateringer du har sendt inn, og som venter på godkjenning fra en administrator. Noen kirker krever at en administrator går gjennom og godkjenner visse endringer før de trer i kraft. Hvis du har gjort en endring som krever godkjenning, vises den her sammen med statusen.

:::info
Hvis en endring du gjorde ennå ikke har trådt i kraft, sjekk fanen **Venter**. Kirkeadministratoren din må kanskje godkjenne den først.
:::

## Kontoinnstillinger

Fanen **Konto** gir tilgang til sikkerhetsinnstillingene dine. Bruk denne fanen til å administrere innstillinger knyttet til tilgang til kontoen og sikkerheten.

## Oversikt over profilfanene

| Fane | Formål |
|---|---|
| **Profil** | [Rediger personopplysningene dine](./editing-profile) og bilde |
| **Husstand** | [Se familiemedlemmene dine](./household) |
| **Synlighet** | Styr hva andre ser i katalogen |
| **Venter** | Se profilendringer som venter på godkjenning |
| **Konto** | Administrer sikkerhetsinnstillinger |

Disse fanene fungerer sammen for å gi deg full kontroll over personopplysningene dine og hvordan de deles innad i kirkefellesskapet ditt.
