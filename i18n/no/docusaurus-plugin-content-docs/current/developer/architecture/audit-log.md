# Revisjon logg & omgjørbare partier

<div class="article-intro">

Hver bruker initialisert mutasjon i api blir registrert - hvem, hva, når og hvorfra - på tvers av alle moduler uten noen per-kontroller ledning. Dette er strukturert som en revisjon logg som sporer alle endringer på tvers av systemet.

</div>

Revisjonslokalen registrerer: hvem, hva, når, hvor, modul og enhet type.
