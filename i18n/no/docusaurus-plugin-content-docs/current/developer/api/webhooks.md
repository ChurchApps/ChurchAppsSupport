# Webhooks

<div class="article-intro">

Webhooks lar en kirke skyve sanntids varsler til tredjepartsverktøy - automatiserings plattformer, CRMs, regnskaps systemer eller hva som helst som aksepterer HTTP POST.

</div>

<div class="prereqs">
<h4>Før du starter</h4>

- En kirke admin med rediger kirke innstillinger tillatelse registrerer og administrerer webhooks
- Mottaks endepunktet ditt må være tilgjengelig over HTTPS på en offentlig adresse

</div>

Webhooks er utadgående bare: B1 ringer endepunktet ditt.
