# Ylläpito

<div class="article-intro">

Lessons.church-sivuston ylläpitoalue on paikka, jossa sisällöntuottajat ja ylläpitäjät hallinnoivat opetusmateriaalikirjastoa. Täältä voit rakentaa opetussuunnitelmasi rakenteen, lähettää materiaaleja, tarkastella käyttötilastoja ja yhdistää kolmannen osapuolen sisällöntarjoajia.

</div>

:::warning
Ylläpitokäyttö edellyttää asianmukaisia oikeuksia. Jos et näe ylläpitovaihtoehtoja, ota yhteyttä seurakuntasi ylläpitäjään ja pyydä käyttöoikeutta.
:::

## Mitä voit tehdä

Ylläpitoalue antaa sinulle täyden hallinnan sisällöstäsi:

- **Luo ja muokkaa ohjelmia** -- Perusta ylimmän tason opetussarjoja nimien, kuvausten, kuvien ja slugien kanssa.
- **Hallinnoi opintoja** -- Järjestä kunkin ohjelman sisällä toisiinsa liittyviä oppituntiryhmiä.
- **Rakenna oppitunteja** -- Lisää yksittäisiä oppitunteja paikkojen, osioiden, roolien ja toimintojen kanssa.
- **Lähetä materiaaleja** -- Liitä ladattavia tiedostoja (PDF-tiedostoja, toimintalomakkeita, kuvia) ohjelman, opintojen tai oppitunnin tasolle.
- **Tarkastele tilastoja** -- Näe, mitä sisältöä ladataan, kuka lataa sitä ja mistä.
- **Määritä tarjoajat** -- Yhdistä ulkoisia opetussuunnitelmien tarjoajia, jotka käyttävät Open Lesson Format -muotoa.
- **Vuosisuunnitelmat** -- Julkaise viikko 1, 2, 3… -sarjoja mille tahansa opetussuunnitelmalle. Seurakunnat ottavat ne käyttöön B1 Adminissa.

## Sisältörakenne

Ylläpitäjänä on hyödyllistä ymmärtää, miten sisältö on jäsennelty:

1. **Ohjelmat** sisältävät yhden tai useamman opinnon.
2. **Opinnot** sisältävät yhden tai useamman oppitunnin.
3. **Oppitunnit** sisältävät yhden tai useamman paikan (ikäryhmäkohtaiset versiot).
4. **Paikat** sisältävät osioita, ja osiot sisältävät roolikohtaisia toimintoja.

Jokaiselle tasolle voidaan liittää omat ladattavat materiaalit.
