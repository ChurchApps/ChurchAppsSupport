# Hallinnointi

<div class="article-intro">

Lessons.church-sovelluksen hallintanäkymä on paikka, jossa sisällöntuottajat ja ylläpitäjät hallinnoivat oppituntikirjastoa. Täältä voit rakentaa opetussuunnitelman rakenteen, lähettää resursseja, tarkastella käyttötilastoja ja yhdistää kolmannen osapuolen sisällöntuottajia.

</div>

:::warning
Hallintanäkymän käyttö edellyttää asianmukaisia oikeuksia. Jos et näe hallintavaihtoehtoja, ota yhteyttä seurakuntasi ylläpitäjään ja pyydä käyttöoikeutta.
:::

## Mitä voit tehdä

Hallintanäkymä antaa sinulle täyden hallinnan sisältöösi:

- **Luo ja muokkaa ohjelmia** -- Määritä ylimmän tason opetussuunnitelmasarjat nimien, kuvausten, kuvien ja tunnisteiden (slugien) kanssa.
- **Hallinnoi opintoja** -- Järjestä saman ohjelman sisällä olevat, toisiinsa liittyvät oppitunnit ryhmiksi.
- **Rakenna oppitunteja** -- Lisää yksittäisiä oppitunteja paikkojen, osioiden, roolien ja toimintojen kanssa.
- **Lähetä resursseja** -- Liitä ladattavia tiedostoja (PDF-tiedostoja, toimintalomakkeita, kuvia) ohjelma-, opinto- tai oppituntitasolle.
- **Tarkastele tilastoja** -- Katso, mitä sisältöä ladataan, kuka lataa sitä ja mistä.
- **Määritä palveluntarjoajat** -- Yhdistä ulkoisia opetussuunnitelmatoimittajia, jotka käyttävät Open Lesson Format -muotoa. Tämä tehdään **Ulkoiset palveluntarjoajat** -sivulta, ei hallintanäkymästä.
- **Vuosisuunnitelmat** -- Julkaise viikon 1, 2, 3… jaksot mille tahansa opetussuunnitelmalle. Seurakunnat ottavat ne käyttöön B1 Adminissa.

## Sisältöhierarkia

Ylläpitäjänä on hyödyllistä ymmärtää, miten sisältö on jäsennelty:

1. **Ohjelmat** sisältävät yhden tai useamman opinnon.
2. **Opinnot** sisältävät yhden tai useamman oppitunnin.
3. **Oppitunnit** sisältävät yhden tai useamman paikan (ikäryhmäkohtaiset versiot).
4. **Paikat** sisältävät osioita, ja osiot sisältävät roolikohtaisia toimintoja.

Jokaiselle tasolle voidaan liittää omat ladattavat resurssit.
