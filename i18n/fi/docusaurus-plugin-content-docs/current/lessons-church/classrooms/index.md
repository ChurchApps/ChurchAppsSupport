# Luokkahuoneet

<div class="article-intro">

Luokkahuoneet ovat perusta sille, miten järjestät opetuksen kirkossasi Lessons.churchissa. Luokkahuone edustaa fyysistä tai virtuaalista tilaa, jossa oppitunteja pidetään -- esimerkiksi "Esikoululuokka", "Alakoulu 1.-2. luokka" tai "Aikuisten Raamatun tutkistelu". Tämä osio käsittelee luokkahuoneiden luomista ja oppituntien ajoittamista niihin.

</div>

## Miksi luokkahuoneilla on merkitystä

Kun perustat luokkahuoneita, luot selkeän rakenteen lastenohjaukselle, nuorisoryhmille tai mille tahansa opetusympäristölle. Jokaisella luokkahuoneella on oma aikataulunsa, joten vapaaehtoiset tietävät aina tarkalleen, mitä opettaa ja milloin. Sen sijaan, että kierrättäisit paperisia aikatauluja tai lähettäisit viime hetken sähköposteja, kaikki voivat tarkistaa portaalista, mitä on tulossa.

## Mitä luokkahuoneilla voi tehdä

- **Luo rajattomasti luokkahuoneita** -- Perusta niin monta luokkahuonetta kuin seurakuntasi tarvitsee. Rajoitusta ei ole, joten voit pitää erillisiä luokkahuoneita jokaiselle ikäryhmälle, toimipisteelle tai ohjelmalle.
- **Ajoita oppitunnit** -- Määritä tietyt oppitunnit kullekin luokkahuoneelle tiettyinä päivinä. Aikataulusi näyttää yhdellä silmäyksellä sekä menneet että tulevat oppitunnit.
- **Mukauta sisältöä** -- Räätälöi oppitunnin sisältö kullekin luokkahuoneelle, jotta vapaaehtoiset näkevät vain oman ikäryhmänsä kannalta olennaisen. Lisätietoja: [Mukauttaminen](../customization/index.md).

## Miten luokkahuoneet liittyvät yhteen

Luokkahuoneet yhdistävät Lessons.churchin oppitunnisisällön seurakuntasi todelliseen opetusaikatauluun. Tyypillinen työnkulku on seuraava:

1. [Selaa](../browsing/index.md) Lessons.churchin saatavilla olevia ohjelmia ja tutkistelumateriaaleja.
2. Perusta luokkahuoneet vastaamaan seurakuntasi tiloja ja ikäryhmiä.
3. Ajoita oppitunnit kullekin luokkahuoneelle tuleville päiville.
4. Vapaaehtoiset avaavat luokkahuoneensa nähdäkseen, mitä on ajoitettu, ja valmistautuvat.
