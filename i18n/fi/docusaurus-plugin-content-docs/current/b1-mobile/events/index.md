# Tapahtumat

<div class="article-intro">

B1 Mobilen Tapahtumat-toiminnon avulla voit selata tulevia seurakunnan tapahtumia ja ilmoittautua niihin suoraan puhelimellasi. Kun seurakuntasi ottaa ilmoittautumisen käyttöön tapahtumalle, voit ilmoittautua itse ja perheenjäsenesi muutamalla napautuksella.

</div>

## Ilmoittautumista vaativat tapahtumat

Ilmoittautuminen käytössä olevat tapahtumat näkyvät ryhmiesi kalentereissa. Kun napautat tapahtumaa, johon on mahdollista ilmoittautua, näet tapahtuman tiedoissa **Ilmoittaudu**-painikkeen.

Tapahtumilla voi olla eri tilanteita:

- **Avoin** -- Ilmoittautuminen on käytettävissä ja voit ilmoittautua.
- **Ei vielä avoinna** -- Ilmoittautumisaika ei ole vielä alkanut.
- **Suljettu** -- Ilmoittautumisen määräaika on ohi.
- **Täynnä** -- Kaikki vapaat paikat on varattu.
