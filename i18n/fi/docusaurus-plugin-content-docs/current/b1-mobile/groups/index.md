# Ryhmät

<div class="article-intro">

Ryhmät B1 Mobile -sovelluksessa auttavat sinua pysymään yhteydessä ihmisiin ja palvelutehtäviin, jotka ovat sinulle tärkeitä. Olitpa sitten pienryhmän, raamattuopiskelun, vapaaehtoistiimin tai palvelutehtävän jäsen, Ryhmät-näkymä on keskus kaikelle, mitä seurakuntayhteisössäsi tapahtuu.

</div>

## Mitä näet

Kun avaat **Ryhmät**-näkymän, ryhmäsi on järjestetty sen mukaan, kuinka usein vierailet niissä:

- **Pääryhmä** -- Useimmin käyttämäsi ryhmä näkyy näytön yläosassa suurena pääkorttina. Napauta sitä, niin pääset suoraan ryhmän tietosivulle.
- **Suositut ryhmät** -- Seuraavaksi eniten käyttämäsi ryhmät näkyvät suosituissa korteissa pääryhmän alapuolella. Niiden kautta pääset nopeasti ryhmiin, joissa olet eniten aktiivinen.
- **Kaikki ryhmät** -- Suositun osion alapuolella voit selata seurakuntasi muita ryhmiä.

Tämä asettelu helpottaa tärkeimpien ryhmien avaamista yhdellä napautuksella ja antaa silti pääsyn kaikkeen muuhun.

## Mitä voit tehdä

Näin voit toimia Ryhmät-näkymästä:

- **Selaa ryhmiä** -- Selaa seurakuntasi saatavilla olevia ryhmiä ja löydä uusia, joihin voit liittyä.
- **Tarkastele ryhmän tietoja** -- Napauta mitä tahansa ryhmää nähdäksesi sen täydellisen profiilin, mukaan lukien julkaisut, jäsenet ja ryhmän tiedot.
- **Seuraa aikajanaa** -- Yhdistetty aikajana näyttää kaikkien ryhmiesi julkaisut ja toiminnan yhdessä paikassa, joten et missään tapauksessa jää paitsi päivityksistä.
- **Pysy yhteydessä** -- Katso, mitä ryhmäsi jäsenet jakavat, seuraa keskusteluja ja osallistu ryhmän sisältöön.

:::tip
Ryhmät-näkymä mukautuu käyttötottumuksiisi, aivan kuten [etusivu](../dashboard/index.md). Useimmin käyttämäsi ryhmät nostetaan ylimpään osaan nopeaa käyttöä varten.
:::
