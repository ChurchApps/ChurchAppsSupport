# Aloitus

:::danger B1 Mobile on poistettu käytöstä
Natiivi B1 Mobile -sovellus on korvattu [B1.church Progressive Web App (PWA) -sovelluksella](../../b1-church/getting-started/installing-pwa.md). Uusien käyttäjien kannattaa asentaa PWA mistä tahansa sivusta osoitteessa `https://yourchurchname.b1.church` sen sijaan, että lataisivat B1 Mobilen App Storesta tai Google Playsta.
:::

<div class="article-intro">

B1 Mobilen käyttöönotto vie vain muutaman minuutin. Lataa sovellus, kirjaudu ChurchApps-tililläsi, valitse seurakuntasi, ja olet valmis.

</div>

## Pikaohje

1. **Lataa** sovellus [App Storesta](https://apps.apple.com) (iOS) tai [Google Play Kaupasta](https://play.google.com) (Android). Hae hakusanalla "B1.church".
2. **Kirjaudu sisään** olemassa olevalla ChurchApps-tililläsi -- sama sähköpostiosoite ja salasana, joita käytät B1.churchissa. Jos sinulla ei ole vielä tiliä, napauta **Rekisteröidy** luodaksesi sellaisen.
3. **Valitse seurakuntasi** hakemalla sitä nimellä. Kirjoita vähintään 3 merkkiä nähdäksesi tulokset.
4. **Tutustu etusivuun** -- henkilökohtainen aloitusnäkymäsi näyttää pikalinkit seurakuntasi tarjoamiin ominaisuuksiin.

Siinä kaikki. Kun olet valinnut seurakuntasi, sovellus lataa seurakuntasi brändäyksen, navigointilinkit ja sisällön. Voit alkaa käyttää ryhmiä, lahjoituksia, sisäänkirjautumista ja kaikkea muuta, minkä seurakuntasi on ottanut käyttöön.
