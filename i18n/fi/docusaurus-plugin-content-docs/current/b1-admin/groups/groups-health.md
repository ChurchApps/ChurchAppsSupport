# Ryhmien terveys

<div class="article-intro">

Ryhmien terveys -kojelauta antaa sinulle yleiskuvan kaikkien ryhmiesi tilanteesta: jäsenmäärien kehityksestä, keskimääräisestä osallistumisesta sekä kasvusta ja vähenemisestä viimeisen 90 päivän ajalta. Kaikki tieto on yhdessä lajiteltavassa taulukossa.

</div>

<div class="prereqs">
<h4>Ennen aloittamista</h4>

- Tarvitset vähintään muutaman ryhmän, jossa on jäseniä, jotta tiedoista on hyötyä. Katso [Ryhmien luominen](./creating-groups.md).
- Osallistumistiedot haetaan tallennetuista tapaamisista. Katso [Osallistuminen](../attendance/index.md) -osio.

</div>

## Ryhmien terveyden avaaminen

Avaa B1 Adminissa [Hyppyvalikko](../introduction.md#getting-around-with-the-jump-menu) (hakupalkki vasemmassa yläkulmassa), laajenna kohta **People**, valitse **Groups** ja klikkaa sivun yläosassa olevaa **Group Health** -painiketta. Kojelauta lataa taulukon, jossa on yksi rivi per ryhmä.

## Sarakkeet

| Sarake | Mitä se näyttää |
|--------|--------------|
| **Name** | Ryhmän nimi, linkitettynä ryhmän tietosivulle |
| **Category** | Ryhmän kategoria |
| **Members** | Nykyinen aktiivisten jäsenten määrä |
| **Joined (90d)** | Viimeisen 90 päivän aikana liittyneet jäsenet |
| **Left (90d)** | Viimeisen 90 päivän aikana lähteneet jäsenet |
| **Churn (90d)** | Nettovaihtuvuus prosentteina 90 päivän ajalta |
| **Avg Attendance** | Keskimääräinen osallistujamäärä tapaamista kohden |

Lajitte taulukon klikkaamalla mitä tahansa sarakeotsikkoa. Klikkaa uudelleen, jos haluat kääntää lajittelusuunnan.

## Terveystietojen käyttäminen

- **Korkea vaihtuvuus + vähän liittymisiä** – ryhmä pienenee eikä korvaa menetettyjä jäseniä. Kannattaa keskustella ryhmän johtajan kanssa.
- **Paljon liittymisiä + vähän osallistumista** – ihmiset ilmoittautuvat, mutta eivät tule paikalle. Harkitse osallistumisen seurantaa.
- **Korkea keskimääräinen osallistuminen** – terve ja aktiivinen ryhmä. Se voi toimia mallina muille ryhmille.

:::tip
Kun klikkaat ryhmän nimeä, pääset suoraan ryhmän tietosivulle. Siellä voit tarkastella yksittäisiä jäseniä, osallistumistietoja ja kalenteritapahtumia.
:::
