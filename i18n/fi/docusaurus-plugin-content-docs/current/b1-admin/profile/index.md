# Profiili

<div class="article-intro">

Profiili-osiossa voit hallita henkilökohtaisia tilisi asetuksia ChurchAppsissa. Profiilisi on yhteinen kaikille ChurchAppsin työkaluille, joten tässä tekemäsi muutokset näkyvät kaikkialla -- B1 Administa B1 Mobile -sovellukseen asti.

</div>

## Mitä voit tehdä

Profiili-osiossa voit:

- **Päivittää nimesi ja sähköpostiosoitteesi** -- Pidä yhteystietosi ajan tasalla.
- **Vaihtaa salasanasi** -- Aseta tilillesi uusi salasana.
- **Ottaa käyttöön kaksivaiheisen kirjautumisen** -- Vaadi koodi todennussovelluksesta kirjautuessasi sisään. Katso [Kaksivaiheinen kirjautuminen](./managing-profile.md#two-factor-sign-in).
- **Vaihtaa teemaa** -- Vaihda vaalean ja tumman tilan välillä käyttäjävalikosta (napsauta profiilikuvaasi oikeassa yläkulmassa).
- **Hallita yhdistettyjä laitteita** -- Tarkastele ja hallitse, mitkä ChurchAppsPlayer-laitteet on linkitetty tiliisi.
- **Tarkastella linkitettyjä tilejä** -- Näe ja hallitse ChurchApps-tilisi yhdistettyjä ulkoisia palveluita.
- **Hyväksyä profiilimuutospyynnöt** -- Tarkista jäsenten lähettämät päivitykset ja ota ne käyttöön.

## Profiilin alaosiot

Profiili-alueella on seuraavat sivut:

1. **[Profiilin hallinta](./managing-profile.md)** -- Muokkaa henkilötietojasi, vaihda salasanasi, hallitse linkitettyjä tilejä, ota käyttöön kaksivaiheinen kirjautuminen, säädä teema-asetuksia ja hoida tilin poistaminen.
2. **[Profiilimuutosten hyväksyminen](./approving-profile-changes.md)** -- Tarkista ja hyväksy B1 Mobilen kautta jäsenten lähettämät profiilipäivityspyynnöt.
3. **[Laitteiden hallinta](./devices.md)** -- Tarkastele, lisää ja hallitse tiliisi yhdistettyjä ChurchAppsPlayer-laitteita.

:::tip
Pidä sähköpostiosoitteesi ajan tasalla. Sitä käytetään tilin palauttamiseen ja seurakuntasi tärkeisiin ilmoituksiin.
:::
