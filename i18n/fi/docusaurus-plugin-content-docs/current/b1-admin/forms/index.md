# Lomakkeet

<div class="article-intro">

Lomakkeet-osiossa voit luoda mukautettuja lomakkeita ilmoittautumisiin, kyselyihin, tietojen keräämiseen ja muuhun. Tarvitsitpa kävijäkortin, tapahtumailmoittautumisen tai rukouspyyntölomakkeen, voit luoda sen täällä ja jakaa sen seurakuntalaisille julkisen linkin tai B1.church-verkkosivustosi kautta.

</div>

## Lomakkeet-sivu

Kun avaat **Lomakkeet**-sivun, näet nämä välilehdet:

- **Lomakkeet** -- Näyttää kaikki aktiiviset lomakkeesi.
- **Arkistoidut lomakkeet** -- Näyttää arkistoidut lomakkeet. Voit palauttaa arkistoituja lomakkeita milloin tahansa. Tämä välilehti näkyy vasta, kun vähintään yksi lomake on arkistoitu.

Jokaisessa luettelon lomakkeessa näkyy sen nimi ja, jos se on määritetty, julkinen URL-osoite, jonka voit jakaa ulkopuolisille.

## Mitä voit tehdä

Lomakkeet-sivulta voit:

- **Lisätä lomakkeen** -- Luo uusi mukautettu lomake napsauttamalla **Lisää lomake**.
- **Etsiä lomaketta** -- Kirjoita **Etsi lomaketta** -kenttään suodattaaksesi luettelon nimen perusteella.
- **Muokata lomaketta** -- Avaa lomake napsauttamalla sen nimeä ja muokkaa kysymyksiä, jäseniä tai asetuksia.
- **Arkistoida lomakkeen** -- Siirrä tarpeettomat lomakkeet **Arkistoidut lomakkeet** -välilehdelle, jotta luettelosi pysyy selkeänä.
- **Palauttaa lomakkeen** -- Siirry **Arkistoidut lomakkeet** -välilehdelle ja palauta haluamasi lomake aktiiviseksi.

## Lomakkeen käsittely

Avaa lomake napsauttamalla mitä tahansa lomakkeen nimeä. Lomake-editorissa on enintään kolme välilehteä:

- **Kysymykset** -- Rakenna lomakkeen rakenne lisäämällä kenttiä eri tyypeillä. Katso lisätietoja kohdasta [Lomakkeiden luominen](./creating-forms.md).
- **Lomakkeen jäsenet** -- Hallitse, kuka voi käyttää ja hallita lomaketta (vain itsenäiset lomakkeet).
- **Lomakkeen vastaukset** -- Näytä lähetetyt vastaukset. Katso lisätietoja kohdasta [Vastausten hallinta](./managing-submissions.md).

:::tip
Lomakkeet, joilla on julkinen URL-osoite, voidaan jakaa linkillä, upottaa verkkosivustollesi tai sisällyttää sähköposteihin. Tämä helpottaa tietojen keräämistä ihmisiltä, joilla ei ehkä ole seurakunnan tiliä.
:::

:::info
Voit hallita, kuka pääsee kuhunkin lomakkeeseen, **Lomakkeen jäsenet** -välilehdellä. Määritä **Ylläpitäjä**- tai **Vain katselu** -roolit, jotta tiimilläsi on oikea käyttöoikeustaso.
:::
