# Raportit

<div class="article-intro">

B1 Admin tarjoaa useita tapoja hakea tietoja seurakuntasi jäsenistä, osallistumisesta ja lahjoituksista. Raportointi on rakennettu sovelluksen vastaaviin osiin, eikä sillä ole yhtä erillistä Raportit-sivua.

</div>

## Mistä raportit löytyvät

### Henkilöt
- **[Syntymäpäivä- ja hääpäivälistat](./birthday-report)** -- Suodata syntymäkuukauden tai hääpäivän kuukauden mukaan kohdassa **Henkilöt → Laajennettu haku**, niin saat listan tulevista syntymäpäivistä tai hääpäivistä.

### Osallistuminen
- **[Osallistumisraportit](./attendance-reports)** -- Osallistumistrendit ja ryhmien osallistumistiedot löytyvät osiosta **Osallistuminen**.

### Lahjoitukset
- **[Lahjoitusyhteenveto](./donation-summary)** -- Lahjoitusten kokonaissummat ja rahastokohtaiset erittelyt löytyvät osiosta **Lahjoitukset**.

### Asetukset
- **[Tarkastusloki](./audit-log)** -- Seuraa kaikkia muutoksia ja toimia seurakunnan hallintajärjestelmässäsi (löytyy kohdasta **Asetukset → Tarkastusloki**).

:::info
Raporttien tiedot ovat yhtä luotettavia kuin tietojen syöttö. Varmista, että tiimisi [kirjaa osallistumisen](../attendance/tracking-attendance.md), [kirjaa lahjoitukset](../donations/recording-donations.md) ja pitää [henkilötiedot](../people/adding-people.md) ajan tasalla, jotta tulokset ovat mahdollisimman tarkkoja.
:::
