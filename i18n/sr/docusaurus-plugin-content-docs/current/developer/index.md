# Документација за програмере

<div class="article-intro">

ChurchApps је скуп од око 20 пројеката отвореног кода који заједно пружају комплетну платформу за управљање црквом. Пројекти обухватају серверске API сервисе, веб апликације, мобилне апликације, десктоп апликацију и дељене библиотеке, а сви су написани у TypeScript-у. Овај одељак пружа све што вам је потребно за подешавање локалног развојног окружења и почетак доприноса.

</div>

## Архитектура у кратком прегледу

Пројекти су **независни репозиторијуми** (а не монорепо). Дељени код се објављује на npm-у под `@churchapps/*` опсегом и користи се као обичне зависности. То значи да можете радити на једном пројекту без клонирања целог екосистема.

Кључне карактеристике:

- **Језик:** TypeScript кроз сав код
- **Серверски део:** Node.js / Express API сервиси распоређени на AWS Lambda помоћу Serverless Framework-а
- **Веб:** React 19 (Vite и Next.js), Material-UI 7
- **Мобилно:** React Native са Expo-ом
- **База података:** MySQL 8.0, једна база по API модулу
