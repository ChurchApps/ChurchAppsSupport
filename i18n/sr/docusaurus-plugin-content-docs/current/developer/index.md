# Документација за програмере

<div class="article-intro">

ChurchApps је колекција од приближно 20 пројеката отвореног кода који заједно чине потпуну платформу за управљање црквом. Пројекти обухватају позадинске API-је, веб апликације, мобилне апликације, апликацију за десктоп и дељене библиотеке, а сви су написани у TypeScript-у. Овај одељак садржи све што вам је потребно за подешавање локалног развојног окружења и почетак доприноса.

</div>

## Преглед архитектуре

Пројекти су **независни репозиторијуми** (а не монорепо). Дељени код се објављује на npm-у под опсегом `@churchapps/*` и користи се као уобичајена зависност. То значи да можете радити на једном пројекту без клонирања целог екосистема.

Кључне карактеристике:

- **Језик:** TypeScript у свим деловима
- **Позадина:** Node.js / Express API-ји, распоређени на AWS Lambda помоћу Serverless Framework-а
- **Веб:** React 19 (Vite и Next.js), Material-UI 7
- **Мобилне апликације:** React Native са Expo-ом
- **База података:** MySQL 8.0, једна база по API модулу
