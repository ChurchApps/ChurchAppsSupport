# Веб апликације

<div class="article-intro">

ChurchApps укључује три веб апликације, од којих свака служи другој публици и има другачију намену. Све три деле заједничку технолошку основу: React 19, TypeScript и Material-UI 7, али се разликују по алатима за изградњу и циљним окружењима за објављивање.

</div>

## Апликације укратко

| Апликација | Намена | Оквир | Развојни порт |
|-----|---------|-----------|----------|
| [**B1Admin**](./b1-admin.md) | Административна контролна табла за цркву | React 19 + Vite + MUI 7 | 5173 |
| [**B1App**](./b1-app.md) | Јавна апликација за чланове цркве | Next.js 16 + React 19 + MUI 7 | 3301 |
| [**LessonsApp**](./lessons-app.md) | Управљање садржајем лекција | Next.js 16 + React 19 | 3501 |

## Заједнички технолошки стек

Све три веб апликације изграђене су помоћу:

- **TypeScript** -- Потпуна безбедност типова од краја до краја
- **React 19** -- Библиотека за UI компоненте
- **Material-UI 7** -- Систем дизајна и алатка за компоненте
- **React Query 5** -- Управљање стањем на серверу

## Заједничке компоненте

Апликације деле UI компоненте и помоћне функције кроз породицу пакета `@churchapps/apphelper*`:

| Пакет | Намена |
|---------|---------|
| `@churchapps/apphelper` | Основне дељене React компоненте |
| `@churchapps/apphelper-login` | UI компоненте за пријаву |
| `@churchapps/apphelper-donations` | Обрасци за донације и давање |
| `@churchapps/apphelper-forms` | Компоненте за креирање образаца |
| `@churchapps/apphelper-markdown` | Приказ Markdown садржаја |
| `@churchapps/apphelper-website` | Компоненте за веб сајт и CMS |

:::tip
За детаље о локалном развоју ових дељених пакета погледајте документацију за [AppHelper](../shared-libraries/app-helper).
:::

## Postinstall скрипта

Свака веб апликација има `postinstall` скрипту која копира фајлове локализације и CSS ресурсе из `@churchapps/apphelper` у пројекат. Ова скрипта се аутоматски покреће након `npm install`.

:::info
Ако компоненте изгледају без стилова након инсталације зависности, `postinstall` скрипта можда није исправно покренута. Можете је ручно покренути командом `npm run postinstall`.
:::

## Алати за изградњу

Апликације користе два различита алата за изградњу:

- **B1Admin** користи **Vite** -- брз и модеран сабирач, идеалан за апликације са једном страницом
- **B1App** и **LessonsApp** користе **Next.js** -- који обезбеђује рендеровање на серверу, рутирање засновано на фајловима и оптимизоване продукционе изградње
