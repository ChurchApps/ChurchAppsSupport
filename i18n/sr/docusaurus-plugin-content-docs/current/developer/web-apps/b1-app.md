# B1App

<div class="article-intro">

B1App је јавна апликација за чланове цркве изграђена помоћу Next.js-а. Пружа искуство за чланове, укључујући профиле, директоријуме група, емитовање уживо и странице за донације.

</div>

<div class="prereqs">
<h4>Пре него што почнете</h4>

- Инсталирајте **Node.js 22+** и **Git** -- погледајте [Предуслове](../setup/prerequisites.md)
- Конфигуришите свој API циљ (демо или локални) -- погледајте [Променљиве окружења](../setup/environment-variables.md)

</div>

:::warning
B1App захтева Node.js 22 или noviju verziju. Раније верзије нису подржане.
:::

## Подешавање

### 1. Клонирајте репозиторијум

```bash
git clone https://github.com/ChurchApps/B1App.git
```

### 2. Инсталирајте зависности

```bash
cd B1App
npm install
```

### 3. Конфигуришите променљиве окружења

```bash
cp dotenv.sample.txt .env
```

Отворите `.env` и конфигуришите `NEXT_PUBLIC_*_API` URL-ове крајњих тачака. Они могу да упућују на заједнички демо API (`https://api.demo.churchapps.org`) или на вашу локалну API инстанцу. Пример фајла може и даље да наводи повучене стејџинг URL-ове; замените их.

### 4. Покрените развојни сервер

```bash
npm run dev
```

Next.js развојни сервер се покреће на [http://localhost:3301](http://localhost:3301).

## Кључне команде

| Команда | Опис |
|---------|------|
| `npm run dev` | Покреће Next.js развојни сервер на порту 3301 |
| `npm run build` | Производна верзија помоћу Next.js-а |
| `npm run test` | Покреће end-to-end тестове помоћу Playwright-а |
| `npm run lint` | Покреће Next.js lint |

## Кључне променљиве окружења

| Променљива | Опис |
|------------|------|
| `NEXT_PUBLIC_*_API` | URL-ови API крајњих тачака за сваки модул |

:::info
Скрипта `postinstall` копира фајлове локализације и CSS фајлове из `@churchapps/apphelper`. Ако компоненте изгледају без стилова након инсталације, ручно покрените `npm run postinstall`.
:::

## Технолошки стек

- **Next.js 16** са TypeScript-ом
- **React 19** за UI компоненте
- **Material-UI 7** за систем дизајна
- **React Query 5** за серверско стање
- **`@churchapps/apphelper*`** пакети за дељене компоненте

## Постављање

Производне верзије се постављају на **S3 + CloudFront**:

1. `npm run build` генерише оптимизовану Next.js верзију
2. Излаз буилда се синхронизује са S3 бакетом
3. Покреће се CloudFront инвалидација да би се послужила нова верзија

:::tip
За детаљна упутства о постављању погледајте водич [Постављање веб апликација](../deployment/web-apps.md).
:::
