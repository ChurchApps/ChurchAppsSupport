# B1 Admin

<div class="article-intro">

B1Admin је табла за администрацију цркве, React једностранична апликација изграђена помоћу Vite-а и Material-UI-ја. Црквено особље је користи за управљање особама, групама, присуством, донацијама, садржајем и још много тога.

</div>

<div class="prereqs">
<h4>Пре почетка</h4>

- Инсталирајте **Node.js 22+** и **Git**, видите [Предуслови](../setup/prerequisites.md)
- Подесите циљ API-ја (демо или локални), видите [Променљиве окружења](../setup/environment-variables.md)

</div>

## Подешавање

### 1. Клонирајте репозиторијум

```bash
git clone https://github.com/ChurchApps/B1Admin.git
```

### 2. Инсталирајте зависности

```bash
cd B1Admin
npm install
```

### 3. Подесите променљиве окружења

```bash
cp dotenv.sample.txt .env
```

Отворите `.env` и подесите крајње тачке API-ја. Можете их усмерити ка заједничком демо API-ју (`https://api.demo.churchapps.org`) или ка својој локалној инстанци API-ја. Пример датотеке можда још увек наводи укинуте URL-ове тест окружења, па их замените.

### 4. Покрените развојни сервер

```bash
npm start
```

Ово покреће Vite развојни сервер. Апликација ће бити доступна у вашем прегледачу, са омогућеним топлим заменама модула (hot module replacement).

## Кључне променљиве окружења

| Променљива | Опис |
|----------|-------------|
| `REACT_APP_STAGE` | Назив окружења (нпр. `demo` као у примерној датотеци, `prod` или `selfhost`) |
| `PORT` | Порт развојног сервера (подразумевано: `3101`) |
| `REACT_APP_*_API` | URL-ови крајњих тачака API-ја за сваки модул |

:::info
Скрипта `postinstall` копира датотеке локализације и CSS датотеке из `@churchapps/apphelper`. Ако компоненте изгледају без стилова, ручно покрените `npm run postinstall`.
:::

## Кључне команде

| Команда | Опис |
|---------|-------------|
| `npm start` | Покреће Vite развојни сервер |
| `npm run build` | Продукцијска изградња помоћу Vite-а |
| `npm run test` | Покреће end-to-end тестове помоћу Playwright-а |
| `npm run lint` | Покреће ESLint са аутоматским исправкама |

## Технолошки стек

- **React 19** са TypeScript-ом
- **Vite** за алате за изградњу и развојни сервер
- **Material-UI 7** за UI компоненте
- **React Query 5** за стање на серверу
- **`@churchapps/apphelper*`** пакети за дељене компоненте

## Постављање

Продукцијске изградње се постављају на **S3 + CloudFront**:

1. `npm run build` генерише статичке ресурсе
2. Ресурси се синхронизују са S3 bucket-ом
3. Покреће се CloudFront инвалидација како би се послала нова верзија

:::tip
За детаљна упутства о постављању видите водич [Постављање веб апликација](../deployment/web-apps.md).
:::
