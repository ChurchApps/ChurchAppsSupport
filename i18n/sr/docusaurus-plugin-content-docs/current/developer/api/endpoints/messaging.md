# Крајње тачке за поруке

<div class="article-intro">

Модул за поруке управља разговорима у реалном времену, порукама у ћаскању, push обавештењима, испоруком SMS-а и е-поште, WebSocket везама, приватним порукама, регистрацијом уређаја и провајдерима за текстуалне поруке. Он пружа слој комуникације који користе све ChurchApps апликације, и за ћаскање током преноса уживо и за асинхрона обавештења.

</div>

**Базна путања:** `/messaging`

### Контрола приступа белешкама о особама

Разговори са `contentType: "person"` (картица Белешке на профилу особе) или `contentType: "personConfidential"` (одељак Поверљиве белешке) ограничени су на свакој путањи читања и уписа, укључујући и горе наведене јавне путање, које за ове типове садржаја враћају `401`. За `person` је потребна дозвола MembershipApi **People / Edit**; за `personConfidential` потребна је дозвола **People / View Confidential Notes**. За API кључеве са ограниченим опсегом, `people:write` обухвата обе радње (корисник кључа и даље мора имати основну дозволу улоге).

### Контрола приступа белешкама о групама и догађајима {#group-and-event-notes-access-control}

Још два типа белешки имају исто ограничење на свакој путањи читања и уписа (укључујући горње јавне путање) и никада нису отворени за анонимно објављивање:

- **`groupNote`** (`contentId` = ID групе) -- фид **Белешке водитеља** на групи. Само водитељи те групе (`leaderGroupIds` у JWT-у) могу да читају или објављују. Ниједна особљна дозвола не даје приступ, укључујући `content.edit` и дозволе чланства у групи.
- **`eventNote`** (`contentId` = ID догађаја) -- белешке на догађају у календару. Особље са `content.edit` или **Calendars / Admin** увек може да чита и објављује. Иначе приступ прати `notesViewRole` (читање) и `notesPostRole` (објављивање) догађаја: `staff` (подразумевано, када је поље `null`) не дозвољава ником другом, `leaders` дозвољава водитељима групе догађаја, а `members` дозвољава члановима и водитељима групе догађаја. Догађај без `groupId` доступан је само особљу.

### Контрола приступа белешкама на картицама тока рада

Разговоре са `contentType: "workflowCard"` (белешке на картици тока рада, где је `contentId` ID задатка картице) могу да читају и уписују само они који могу да отворе ту картицу: корисник са дозволом DoingApi **Tasks / View**, или особа или група којој је картица додељена, коју је створила или на коју се односи. Сви остали добијају `401` на свакој путањи читања, укључујући горње јавне путање. Разговор се везује за картицу преко саме картице помоћу `POST /doing/tasks/:id/conversation` (тело `{ "conversationId": "..." }`; прво повезани разговор остаје), коју могу да позивају уредници картице и особа којој је додељена.

### Пример: Покретање разговора

```
POST /messaging/conversations/start
Authorization: Bearer <token>

{
  "groupId": "group-123",
  "contentType": "group",
  "contentId": "group-123",
  "title": "Weekly Discussion",
  "comment": "Welcome to this week's discussion thread!"
}
```

```json
{
  "id": "conv-456",
  "churchId": "church-789",
  "contentType": "group",
  "contentId": "group-123",
  "title": "Weekly Discussion",
  "dateCreated": "2026-02-17T10:00:00.000Z",
  "visibility": "public",
  "allowAnonymousPosts": false,
  "groupId": "group-123"
}
```

## Поруке

Базна путања: `/messaging/messages`

| Метода | Путања | Аутентификација | Дозвола | Опис |
|--------|------|------|------|------|
| GET | `/conversation/:conversationId` | JWT | — | Учитава све поруке у разговору |
| GET | `/catchup/:churchId/:conversationId` | Јавно | — | Учитава све поруке у разговору (јавно допуњавање за ћаскање уживо) |
| GET | `/:churchId/:id` | Јавно | — | Учитава једну поруку по ID-ју |
| POST | `/` | JWT | — | Чува поруке (групно). Шаље ажурирања у реалном времену и покреће обавештења. За измену постојеће поруке потребно је да будете њен аутор или да имате `content.edit`; сачувани аутор никада не може да се промени |
| POST | `/send` | Јавно | — | Шаље поруке (групно, јавно). Шаље ажурирања у реалном времену преко WebSocket-а и покреће обавештења |
| POST | `/setCallout` | JWT | — | (застарело) Емитује истакнуту поруку у реалном времену. Нема активног клијента; ћаскање током преноса уживо више не приказује истакнуте поруке |
| DELETE | `/:churchId/:id` | JWT | — | Брише поруку и у реалном времену емитује брисање. Погледајте [Модерацију порука](#message-moderation) |

### Модерација порука

Брисање поруке дозвољено је за:

- аутора поруке;
- особље са `content.edit` (било где у цркви);
- **водитеље групе**, за разговоре са `contentType` вредношћу `group` или `groupAnnouncement` чији је `contentId` група коју воде (`leaderGroupIds` у JWT-у).

Разговори у белешкама о особама (`person` / `personConfidential`) никада не модерирају водитељи; за њих се користе дозволе за белешке (`people.edit`, `people.viewConfidentialNotes`).

Водитељи могу само да бришу, не и да мењају: измена туђе поруке и даље је ограничена на аутора и особље са `content.edit`.

### Пример: Слање поруке

```
POST /messaging/messages/send

[
  {
    "churchId": "church-789",
    "conversationId": "conv-456",
    "personId": "person-123",
    "displayName": "John Smith",
    "content": "Hello everyone!",
    "messageType": "comment"
  }
]
```

```json
[
  {
    "id": "msg-001",
    "churchId": "church-789",
    "conversationId": "conv-456",
    "personId": "person-123",
    "displayName": "John Smith",
    "timeSent": "2026-02-17T10:05:00.000Z",
    "content": "Hello everyone!",
    "messageType": "comment"
  }
]
```

## Текстуалне поруке

Базна путања: `/messaging/texting`

Управља провајдерима за SMS, слањем текстуалних порука групама и праћењем испоруке.

| Метода | Путања | Аутентификација | Дозвола | Опис |
|--------|------|------|------|------|
| GET | `/providers` | JWT | — | Учитава провајдере за текстуалне поруке за цркву (акредитиви су маскирани) |
| GET | `/status` | JWT | — | `{ enabled }` — да ли црква има укљученог провајдера за текстуалне поруке. Може га користити било који пријављени корисник цркве; користи се за приказ опција **Text** само када се поруке могу слати |
| GET | `/inboundUrl` | JWT | `texting.send` или `settings.edit` | `{ url }` — улазни (STOP) webhook URL цркве који треба залепити у провајдера |
| POST | `/inbound/:churchId/:token` | Јавно | — | Улазни webhook провајдера за поруке. `token` је HMAC од ID-ја цркве. Одговор који је тачно једна од речи за прекид (`STOP`, `STOPALL`, `UNSUBSCRIBE`, `CANCEL`, `END`, `QUIT`, `OPTOUT`, `REVOKE`) обележава сваку одговарајућу особу као `optedOut` и искључује њен `allowSms`. | GET | `/preview/:groupId` | JWT | — | Прегледа примаоце текстуалне поруке за групу (број подобних, одјављених и без телефона) |
| GET | `/sent` | JWT | — | Учитава све евиденције послатих текстуалних порука за цркву |
| GET | `/sent/:id/details` | JWT | — | Учитава послату текстуалну поруку са евиденцијом испоруке по примаоцу |
| POST | `/providers` | JWT | — | Чува провајдере за текстуалне поруке (групно). Шифрује API акредитиве |
| POST | `/send` | JWT | — | Шаље SMS свим подобним члановима групе. Тело: `{ groupId, message }`. Поља за спајање (`{{firstName}}`, `{{lastName}}`, `{{displayName}}`, `{{churchName}}`) се разрешавају за сваког примаоца |
| POST | `/sendPerson` | JWT | — | Шаље SMS једној особи. Тело: `{ personId, phoneNumber, message }`. Поља за спајање се разрешавају, а разрешени текст је оно што се бележи |
| DELETE | `/providers/:id` | JWT | — | Брише провајдера за текстуалне поруке |

## Шаблони е-поште

Базна путања: `/messaging/emailTemplates`

Управља вишекратно употребљивим шаблонима е-поште и слањем шаблонске е-поште групама.

| Метода | Путања | Аутентификација | Дозвола | Опис |
|--------|------|------|------|------|
| GET | `/` | JWT | — | Учитава све шаблоне е-поште за цркву |
| GET | `/:id` | JWT | — | Учитава један шаблон е-поште по ID-ју |
| GET | `/sendStatus` | JWT | `groupMembers.edit` или `tasks.admin` | Статус е-поште група за цркву: `{ approved, paused, remaining, requested }`. Дијалог Send Email у B1Admin-у и радња тока рада **Send email** користе га за упозорење када е-пошта неће бити послата |
| POST | `/requestApproval` | JWT | `groupMembers.edit` | Тражи од подршке одобрење цркве за е-пошту групама (највише једном недељно по цркви) |
| GET | `/preview/:groupId` | JWT | — | Прегледа испоруку е-поште за групу (број подобних прималаца, чланови без е-поште) |
| POST | `/` | JWT | — | Креира или ажурира шаблоне е-поште (групно) |
| POST | `/send` | JWT | — | Шаље шаблонску е-пошту свим члановима групе. Тело: `{ groupId, subject, htmlContent }` |
| DELETE | `/:id` | JWT | — | Брише шаблон е-поште |

### Пример: Слање е-поште групи

```
POST /messaging/emailTemplates/send
Authorization: Bearer <token>

{
  "groupId": "group-123",
  "subject": "This Week's Update - {{churchName}}",
  "htmlContent": "<p>Hello {{firstName}},</p><p>Here's what's happening this week...</p>"
}
```

```json
{
  "totalMembers": 50,
  "recipientCount": 45,
  "successCount": 44,
  "failCount": 1,
  "noEmailCount": 5
}
```

**Подржана поља за спајање:** `{{firstName}}`, `{{lastName}}`, `{{displayName}}`, `{{email}}`, `{{churchName}}`

## Блокиране IP адресе

Базна путања: `/messaging/blockedips`

(застарело) Блокирање IP адреса за ћаскање током преноса уживо. Клијент B1App више не позива `POST /` — блокирање IP адреса је уклоњено у миграцији јединствене испоруке. Путању `/clear` и даље сервер-на-сервер позива `StreamingServiceController` када се преноси уживо чувају.

| Метода | Путања | Аутентификација | Дозвола | Опис |
|--------|------|------|------|------|
| POST | `/` | JWT | — | (застарело) Чува блокиране IP адресе (групно). Нема активног клијента |
| POST | `/clear` | JWT | — | Брише све блокиране IP адресе за одређене услуге. Тело: `[{ serviceId, churchId }]` |

## Евиденција испоруке

Базна путања: `/messaging/deliverylogs`

Прати статус испоруке послатих порука (SMS, push обавештења, е-пошта).

| Метода | Путања | Аутентификација | Дозвола | Опис |
|--------|------|------|------|------|
| GET | `/content/:contentType/:contentId` | JWT | — | Учитава евиденцију испоруке по типу садржаја и ID-ју |
| GET | `/person/:personId` | JWT | — | Учитава евиденцију испоруке за особу. Опциони филтери `?startDate=&endDate=` |
| GET | `/recent` | JWT | — | Учитава недавну евиденцију испоруке за цркву. Опционално `?limit=` (подразумевано 100) |
| GET | `/:id` | JWT | — | Учитава евиденцију испоруке по ID-ју |
