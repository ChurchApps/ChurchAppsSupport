# Крајње тачке садржаја

<div class="article-intro">

Модул Content управља веб-страницама, секцијама, елементима, блоковима, блог постовима, преусмеравањима, проповедима, плејлистама, стриминг сервисима, догађајима, курираним календарима, фајловима, галеријама, преводима Библије и претрагама стихова, песмама, аранжманима, глобалним стиловима, стоковним фотографијама и подешавањима. То је највећи модул у API-ју и покреће CMS, медијске и стриминг функције, планирање богослужења и функције Библије у свим ChurchApps апликацијама.

</div>

**Основна путања:** `/content`

## Странице

Основна путања: `/content/pages`

| Метода | Путања | Аутентификација | Дозвола | Опис |
|--------|------|------|------|------|
| GET | `/:churchId/tree?url=&id=` | Јавно | — | Учитава комплетно стабло странице (секције, елементе, блокове) по URL-у или ID-ју. Уклања интерне ID-јеве када се учитава по URL-у. Учитавања по URL-у примењују `pages.visibility`: страница са ограниченим приступом враћа `{ restricted: true, visibility }`, осим ако (опциони) JWT задовољава услов |
| GET | `/public/:churchId` | Јавно | — | Листа јавних страница (`url`, `title`, `metaDescription`); само `visibility = everyone` |
| GET | `/:id` | JWT | — | Учитава страницу по ID-ју |
| GET | `/` | JWT | — | Листа свих страница за цркву |
| POST | `/duplicate/:id` | JWT | Content.Edit | Дуплира страницу са свим секцијама и елементима |
| POST | `/temp/ai` | JWT | Content.Edit | Чува страницу генерисану вештачком интелигенцијом (страница, секције и елементи у једном позиву) |
| POST | `/importTree` | JWT | Content.Edit | Креира страницу из угнежденог стабла (`title`, `url`, `sections[].elements[]…`). Увек се убацује под црквом пошиљаоца; ID-јеви из тела захтева се занемарују. Редови морају укључивати своју децу `column`. Максимум 30 секција / 500 елемената |
| POST | `/` | JWT | Content.Edit | Креира или ажурира странице (групно) |
| DELETE | `/:id` | JWT | Content.Edit | Брише страницу |

### Пример: учитавање стабла странице

```
GET /content/pages/abc-church-id/tree?url=/about
```

```json
{
  "name": "About",
  "url": "/about",
  "sections": [
    {
      "background": "#FFFFFF",
      "textColor": "dark",
      "elements": [
        { "elementType": "textWithPhoto", "answers": { "text": "Welcome" } }
      ]
    }
  ]
}
```

## Постови (блог)

Основна путања: `/content/posts`

Блог постови су самостални редови: `title`, `slug` (јединствен по цркви), `excerpt`, `content` (тело у markdown-у), `authorId`, `photoUrl`, `publishDate`, `category` и `tags`. Пост се објављује када је `publishDate` постављен и у прошлости. Крајње тачке за читање обогаћују сваки пост са `authorName`, који се разрешава из `authorId`. Погледајте [Архитектуру изградње веб-сајта](../../architecture/website-builder#blog).

| Метода | Путања | Аутентификација | Дозвола | Опис |
|--------|------|------|------|------|
| GET | `/public/:churchId?category=&tag=&page=&pageSize=` | Јавно | — | Листа објављених постова, са страницама (максимум 50 по страници) |
| GET | `/public/:churchId/categories` | Јавно | — | Различите категорије међу објављеним постовима |
| GET | `/public/:churchId/slug/:slug` | Јавно | — | Учитава објављен пост по slug-у |
| GET | `/rss/:churchId?siteUrl=` | Јавно | — | RSS 2.0 фид објављених постова (линкови се граде као `{siteUrl}/blog/{slug}`) |
| GET | `/:id` | JWT | — | Учитава пост по ID-ју |
| GET | `/` | JWT | — | Листа свих постова за цркву |
| POST | `/` | JWT | Content.Edit | Креира или ажурира постове (групно) |
| DELETE | `/:id` | JWT | Content.Edit | Брише пост |

## Преусмеравања

Основна путања: `/content/redirects`

URL преусмеравања по цркви (`fromPath` → `toPath`), ограничена на 200 по цркви. Путање се нормализују (мала слова, водећа коса црта, без завршне косе црте), а `fromPath` је јединствен по цркви. B1App их разрешава на могућим 404 грешкама и шаље HTTP 308.

| Метода | Путања | Аутентификација | Дозвола | Опис |
|--------|------|------|------|------|
| GET | `/public/:churchId?path=` | Јавно | — | Разрешава путању (или листа свих преусмеравања када се `path` изостави) |
| GET | `/:id` | JWT | — | Учитава преусмеравање по ID-ју |
| GET | `/` | JWT | — | Листа свих преусмеравања за цркву |
| POST | `/` | JWT | Content.Edit | Креира или ажурира преусмеравања. Одбија `fromPath = toPath` и примењује ограничење од 200 редова |
| DELETE | `/:id` | JWT | Content.Edit | Брише преусмеравање |

## Догађаји

Основна путања: `/content/events`

| Метода | Путања | Аутентификација | Дозвола | Опис |
|--------|------|------|------|------|
| GET | `/timeline/group/:groupId?eventIds=` | JWT | — | Учитава догађаје временске линије за групу (укључује датуме изузетака, па се обрисана појављивања могу прескочити) |
| GET | `/timeline?eventIds=` | JWT | — | Учитава догађаје временске линије за групе тренутног корисника (укључује датуме изузетака) |
| GET | `/subscribe?churchId=&groupId=&curatedCalendarId=` | Јавно | — | Претплата на догађаје као ICS фид календара |
| GET | `/group/:groupId` | JWT | — | Догађаји за групу (укључује датуме изузетака) |
| GET | `/public/group/:churchId/:groupId` | Јавно | — | Јавни догађаји за групу |
| GET | `/public/:churchId/:id` | Јавно | — | Учитава један догађај за његову јавну страницу, са `roomNames` (просторије из резервација које нису одбијене). Враћа `null` за догађаје на чекању или одбијене и за приватне догађаје који не прихватају пријаве |
| GET | `/public/:churchId/:id/ical` | Јавно | — | Преузима тај догађај као `.ics` фајл (`text/calendar`, примењени датуми изузетака). `404` када је догађај сакривен истим правилима |
| GET | `/:id` | JWT | — | Учитава догађај по ID-ју |
| POST | `/` | JWT | — | Креира или ажурира догађаје (групно) |
| DELETE | `/:id` | JWT | Content.Edit, Calendars.Admin или водитељ групе | Брише догађај и његове резервације. Водитељи групе догађаја могу га обрисати, а подносилац захтева може повући свој захтев на чекању |

Записи догађаја укључују `photoUrl` (фотографију догађаја у формату 16:9 која се приказује на јавној страници догађаја и на плочицама предстојећих догађаја), `tags` (раздвојене зарезима, користи их филтер ознака елемента Календар на веб-сајту) и `notesViewRole` / `notesPostRole` (`staff` када је `null`, `leaders` или `members`), који контролишу приступ разговору `eventNote` за догађај. Погледајте [Контрола приступа белешкама групе и догађаја](./messaging.md#group-and-event-notes-access-control). Одговори курираних догађаја за јавност такође садрже `photoUrl` и `tags` сваког догађаја.

| GET | `/availableTranslations/:source` | Јавно | — | Листа доступних превода из извора (нпр. api.bible) |

| GET | `/:translationKey/updateCopyright` | Јавно | — | Ажурира ауторска права за одређени превод |
| GET | `/:translationKey/search?query=&limit=` | Јавно | — | Претражује стихове у преводу |
