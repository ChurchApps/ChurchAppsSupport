# API

<div class="article-intro">

ChurchApps API је **модуларни монолит** -- једна кодна база која служи шест модула за податке, од којих сваки има сопствену базу. Ова архитектура пружа организационе предности микросервиса (јасне границе, независна складишта података) уз оперативну једноставност једног постављања.

</div>

## Модули

| Модул | Намена |
|-------|--------|
| **Чланство** | Људи, групе, домаћинства, дозволе |
| **Присуство** | Службе, сесије, записи о пријави |
| **Садржај** | Странице, одељци, елементи, стриминг |
| **Прилози** | Донације, фондови, обрада плаћања |
| **Размена порука** | Разговори, обавештења, имејл |
| **Задаци** | Задаци, планови, задужења |

## Технологије

- **Извршно окружење:** Node.js 24.x са TypeScript-ом (ES модули)
- **Оквир:** Express
- **Инјекција зависности:** Inversify (рутирање засновано на декораторима)
- **База података:** MySQL -- једна база по модулу, свака са сопственим пулом веза
- **Аутентификација:** JWT аутентификација преко `CustomAuthProvider`
- **Постављање:** AWS Lambda преко Serverless Framework v3

## Портови

| Протокол | Порт | Опис |
|----------|------|------|
| HTTP | `8084` | Главни REST API |
| WebSocket | `8087` | Везе преко сокета у реалном времену |

## Lambda функције

Када се постави на AWS, API ради као шест Lambda функција:

- **`web`** -- обрађује све HTTP захтеве
- **`socket`** -- управља WebSocket везама
- **`timer15Min`** -- покреће се сваких 30 минута за имејл обавештења (назив је историјски)
- **`timerMidnight`** -- покреће се свакодневно за дневне прегледе путем имејла и задатке одржавања
- **`timerScheduledTasks`** -- покреће се свакодневно за аутоматизације којима је дошао рок и обраду закашњелих токова рада
- **`timerWebhooks`** -- покреће се сваки минут ради слања webhook порука из реда чекања

## Дељене библиотеке

API зависи од два дељена ChurchApps пакета:

- **[`@churchapps/helpers`](../shared-libraries/helpers)** -- Основне помоћне функције (DateHelper, ApiHelper, итд.)
- **[`@churchapps/apihelper`](../shared-libraries/api-helper)** -- Помоћне функције за Express сервер, укључујући аутентификацију, помоћне алате за базу података и AWS интеграције

:::info
API користи ES модуле (`"type": "module"` у `package.json`). Уверите се да ваши импорти користе синтаксу ES модула.
:::
