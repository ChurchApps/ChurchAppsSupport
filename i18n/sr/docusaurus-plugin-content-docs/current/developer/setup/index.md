# Подешавање

<div class="article-intro">

Овај одељак вас води кроз подешавање локалног окружења за развој ChurchApps пројеката. Можете или усмерити свој фронтенд на заједничке демо API-је за брз развој, или покренути комплетан стек локално за рад на бекенду.

</div>

## Два приступа

Постоје два начина за локални развој, у зависности од тога колико вам је стека потребно:

### 1. Усмерите на демо API-је (најлакше)

Ако радите на **фронтенд пројекту** (веб апликација, мобилна апликација или desktop апликација), најбржи пут је да своју локалну апликацију усмерите на заједничке демо API-је. Није потребна база података нити подешавање бекенда.

Основна адреса демо API-ја је:

```
https://api.demo.churchapps.org
```

Сваки API модул је доступан на путањи испод ове основе, на пример:

```
https://api.demo.churchapps.org/membership
https://api.demo.churchapps.org/attendance
https://api.demo.churchapps.org/giving
```

Демо окружење покреће најновији код са `main` гране, а његови примерни подаци се обнављају сваке ноћи, па немојте очекивати да ће било шта што тамо креирате остати сачувано. (Некадашње окружење за стејџинг, `api.staging.churchapps.org`, је укинуто. Неки примерни `.env` фајлови и даље могу наводити стејџинг адресе -- замените их демо или локалним адресама.)

:::tip
Овај приступ вам омогућава да почнете да правите измене на фронтенду за неколико минута. Препоручена је путања за већину сарадника.
:::

### 2. Покрените све локално

Ако треба да мењате API код или радите без интернета, можете покренути комплетан стек локално. Ово захтева MySQL 8.0+ и додатна подешавања. Детаљна упутства потражите у водичу [Локално подешавање API-ја](../api/local-setup.md).

## Почетак рада

Пратите ове странице редом:

1. **[Предуслови](./prerequisites.md)** -- Инсталирајте потребне алате (Node.js, Git, MySQL, итд.)
2. **[Преглед пројеката](./project-overview.md)** -- Сазнајте који пројекти постоје и шта раде
3. **[Променљиве окружења](./environment-variables.md)** -- Подесите своје `.env` фајлове како бисте све повезали

Сваки ChurchApps пројекат је независан Git репозиторијум. Потребно је да клонирате само конкретне пројекте на којима желите да радите.
:::
