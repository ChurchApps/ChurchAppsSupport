## Сви пројекти

Ово је потребно без обзира на то на ком пројекту радите:

| Алат | Верзија | Напомене |
|------|---------|----------|
| **Node.js** | 20+ | Верзија 22+ је потребна за B1App и LessonsApp (Next.js 16); 24+ за Api |
| **npm** | Долази уз Node.js | Користи се као менаџер пакета у свим пројектима |
| **Git** | Најновија | Сваки пројекат је засебан репозиторијум |

:::tip
Користите менаџер верзија Node.js-а, као што су [nvm](https://github.com/nvm-sh/nvm) (macOS/Linux) или [nvm-windows](https://github.com/coreybutler/nvm-windows) (Windows), да бисте лако прелазили између верзија Node.js-а.
:::

## Развој бекенд API-ја

Ако планирате да локално покрећете API (а не да се повезујете на демо API-је):

| Алат | Верзија | Напомене |
|------|---------|----------|
| **MySQL** | 8.0+ | Сваки модул API-ја користи сопствену базу података |

За основни API су вам потребне шест база података: `membership`, `attendance`, `content`, `giving`, `messaging` и `doing`. API укључује скрипте за иницијализацију шеме -- погледајте водич [Локално подешавање API-ја](../api/local-setup.md).

## Развој мобилне апликације

За B1Mobile, B1Checkin, LessonsScreen или друге React Native / Expo апликације:

| Алат | Верзија | Напомене |
|------|---------|----------|
| **Expo CLI** | Најновија | Инсталирајте глобално: `npm install -g expo-cli` |
| **Android Studio** | Најновија | Потребна за развој за Android (укључује Android SDK) |
| **Xcode** | Најновија | Потребна за развој за iOS (само macOS) |

:::info
Можете да користите апликацију Expo Go на физичком уређају за брзо тестирање без Android Studio-а или Xcode-а. Међутим, за прављење продукцијских бинарних датотека потребни су нативни алати.
:::

## Развој FreeShow-а (десктоп апликација)

FreeShow има додатне зависности за изградњу нативних модула, јер компајлира нативне Node.js модуле (као што је `canvas`):

### Све платформе

| Алат | Верзија | Напомене |
|------|---------|----------|
| **Python** | 3.12 | Потребан за `node-gyp` при компајлирању нативних модула |
| **setuptools** | Најновија | Инсталирајте помоћу `pip install setuptools` |

### Windows

| Алат | Напомене |
|------|----------|
| **Visual Studio** | Community издање је довољно |
| **„Desktop development with C++“ радно оптерећење** | Изаберите током инсталације Visual Studio-а |
| **Windows 10 SDK** | Укључен је у C++ радно оптерећење; проверите да је означен |

Алате за изградњу за Visual Studio можете инсталирати преко командне линије:

```bash
npm install --global windows-build-tools
```

Или инсталирајте Visual Studio Community и током инсталације изаберите радно оптерећење „Desktop development with C++“.

### Linux

```bash
sudo apt-get install libfontconfig1-dev
```

### macOS

Xcode Command Line Tools су обично довољни:

```bash
xcode-select --install
```

## Провера инсталације

Покрените ове команде да бисте потврдили да је све инсталирано:

```bash
node --version    # Should print v20.x.x or higher
npm --version     # Should print 10.x.x or higher
git --version     # Should print git version 2.x.x
mysql --version   # Only needed for local API development
```
