## Сви пројекти

Ово је потребно без обзира на то на ком пројекту радите:

| Алат | Верзија | Напомене |
|------|---------|----------|
| **Node.js** | 20+ | Верзија 22+ је потребна за B1App и LessonsApp (Next.js 16); 24+ за Api |
| **npm** | Долази уз Node.js | Користи се као менаџер пакета у свим пројектима |
| **Git** | Најновија | Сваки пројекат је засебан репозиторијум |

:::tip
Користите менаџер верзија Node-а, као што је [nvm](https://github.com/nvm-sh/nvm) (macOS/Linux) или [nvm-windows](https://github.com/coreybutler/nvm-windows) (Windows), да бисте лако прелазили између верзија Node-а.
:::

## Развој backend API-ја

Ако планирате да покрећете API локално (а не да се повезујете на демо API-је):

| Алат | Верзија | Напомене |
|------|---------|----------|
| **MySQL** | 8.0+ | Сваки модул API-ја користи сопствену базу података |

За основни API су вам потребне шест база података: `membership`, `attendance`, `content`, `giving`, `messaging` и `doing`. API укључује скрипте за иницијализацију шеме -- погледајте водич [Локално подешавање API-ја](../api/local-setup.md).

## Развој мобилне апликације

За B1Checkin, LessonsScreen или друге React Native / Expo апликације:

| Алат | Верзија | Напомене |
|------|---------|----------|
| **Expo CLI** | Најновија | Инсталирајте глобално: `npm install -g expo-cli` |
| **Android Studio** | Најновија | Потребна за развој за Android (укључује Android SDK) |
| **Xcode** | Најновија | Потребна за развој за iOS (само macOS) |

:::info
За брзо тестирање можете користити апликацију Expo Go на физичком уређају, без Android Studio-а или Xcode-а. Међутим, за прављење производних бинарних датотека потребни су нативни алати.
:::

## FreeShow (desktop апликација) развој

FreeShow има додатне зависности за нативну израду јер компајлира нативне Node модуле (као што је `canvas`):

### Све платформе

| Алат | Верзија | Напомене |
|------|---------|----------|
| **Python** | 3.12 | Потребан за `node-gyp` при компајлирању нативних модула |
| **setuptools** | Најновија | Инсталирајте помоћу `pip install setuptools` |

### Windows

| Алат | Напомене |
|------|----------|
| **Visual Studio** | Community издање је довољно |
| **Радно оптерећење „Desktop development with C++”** | Изаберите током инсталације Visual Studio-а |
| **Windows 10 SDK** | Укључен у C++ радно оптерећење; проверите да је означен |

Алате за изградњу Visual Studio-а можете инсталирати из командне линије:

```bash
npm install --global windows-build-tools
```

Или инсталирајте Visual Studio Community и изаберите радно оптерећење „Desktop development with C++” током инсталације.

### Linux

```bash
sudo apt-get install libfontconfig1-dev
```

### macOS

Xcode Command Line Tools је обично довољан:

```bash
xcode-select --install
```

## Проверите инсталацију

Покрените ове команде да бисте потврдили да је све инсталирано:

```bash
node --version    # Требало би да испише v20.x.x или више
npm --version     # Требало би да испише 10.x.x или више
git --version     # Требало би да испише git version 2.x.x
mysql --version   # Потребно само за локални развој API-ја
```
