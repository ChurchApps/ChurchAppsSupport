# Распоређивање веб апликације

<div class="article-intro">

ChurchApps веб апликације се распоређују као статички сајтови на **Amazon S3**, а **CloudFront** служи као CDN. Распоређивање је аутоматизовано помоћу GitHub Actions, али се може покренути и ручно када је то потребно.

</div>

<div class="prereqs">
<h4>Пре почетка</h4>

- Подесите веб апликацију локално и проверите да се успешно прави -- погледајте [Веб апликације](../web-apps/)
- Конфигуришите AWS акредитиве са приступом за S3 и CloudFront
- Знајте назив циљног S3 бакета и ID CloudFront дистрибуције

</div>

## Кораци распоређивања

1. **Направите апликацију** -- генеришите статички излаз:

   ```bash
   npm run build
   ```

2. **Синхронизујте са S3** -- отпремите излаз билда у S3 бакет:

   ```bash
   aws s3 sync build/ s3://bucket-name
   ```

3. **Поништите CloudFront кеш** -- обришите CDN кеш како би корисници добили најновију верзију:

   ```bash
   aws cloudfront create-invalidation --distribution-id YOUR_DIST_ID --paths "/*"
   ```

## Аутоматско распоређивање

GitHub Actions токови рада аутоматски обрађују распоређивање при слању на грану `main`. Ток рада извршава сва три корака из претходног дела -- билд, синхронизацију са S3 и поништавање CloudFront кеша -- без ручне интервенције.

:::info
Обично не морате ручно покретати ове команде. Спајање pull request-а у `main` покреће аутоматски процес распоређивања.
:::

:::tip
Ако желите да проверите билд локално пре распоређивања, покрените `npm run build` и прегледајте излаз у директоријуму `build/`. Можете га послужити било којим сервером за статичке датотеке да бисте потврдили да све ради.
:::
