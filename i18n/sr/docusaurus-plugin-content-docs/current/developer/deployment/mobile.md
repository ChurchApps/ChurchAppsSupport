# Постављање мобилне апликације

<div class="article-intro">

ChurchApps мобилне апликације се граде и постављају помоћу **Expo EAS Build** алата и дистрибуирају се кроз продавнице апликација. Ова страница описује изградњу, слање и објављивање ажурирања путем ваздуха (OTA) за Android и iOS.

</div>

<div class="prereqs">
<h4>Пре почетка</h4>

- Подесите мобилну апликацију локално -- погледајте [B1 Mobile](../mobile/b1-mobile)
- Инсталирајте и подесите [EAS CLI](https://docs.expo.dev/eas/)
- Имајте приступ Google Play Console-у (Android) и/или Apple App Store Connect-у (iOS)

</div>

## Изградња

### Android

```bash
npm run build:android
```

### iOS

```bash
eas build --platform ios --profile production
```

## Слање у продавнице апликација

### Android -- Google Play Store

Након успешне EAS изградње, Android бинарна датотека (AAB) се шаље у Google Play Store преко Play Console-а.

### iOS -- Apple App Store

Пошаљите iOS изградњу директно помоћу EAS-а:

```bash
eas submit --platform ios
```

## OTA ажурирања

За измене само у JavaScript-у које не захтевају преглед у продавници апликација, користите ажурирања путем ваздуха (OTA):

```bash
npm run update:production
```

Ова команда користи EAS Update за слање измена директно корисницима, без слања у продавницу.

:::tip
OTA ажурирања су знатно брža од изградњи за продавнице -- измене могу стићи до корисника за неколико минута, а не за дане. Користите их за исправке грешака, измене текста и мање измене корисничког интерфејса које не укључују измене нативног кода.
:::

## Бројеви верзија

Пре креирања изградње за продавницу, бројеве верзија треба ажурирати у више датотека:

- `package.json`
- `app.config.js`
- `android/app/build.gradle`
- `ios/*/Info.plist`
- `ios/*/project.pbxproj`

:::warning
Ако не ажурирате број верзије у свим наведеним датотекама, изградња ће пасти или продавница апликација може одбити апликацију. Пре почетка изградње за продукцију, још једном проверите сваку датотеку наведену горе.
:::
