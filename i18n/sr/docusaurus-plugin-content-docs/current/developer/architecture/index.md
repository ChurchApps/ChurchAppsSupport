# Архитектура

<div class="article-intro">

Ове странице су системске мапе преко више репозиторијума: документују како функционише основни ChurchApps систем од почетка до краја, кроз апликације, API модуле и дељене библиотеке, а не како је подешен један појединачни пројекат. Прочитајте их пре него што промените понашање система. Прочитајте [Подешавање](../setup/index.md) да бисте покренули пројекат и [одељак о API-ју](../api/index.md) за референцу на нивоу крајњих тачака.

</div>

## Екосистем укратко

ChurchApps чини око 20 независних репозиторијума (није монорепо). Клијентске апликације комуницирају са малим скупом позадинских API-ја преко HTTPS-а и WebSocket-а, а код деле кроз npm пакете објављене под `@churchapps` опсегом.

```
┌────────────────────────────────┐            ┌──────────────────────────────────────────────┐
│  Клијенти                      │            │ Api — језгро модуларног монолита (AWS Lambda)│
│                                │            │                                              │
│  B1Admin    табла особља       │   HTTPS    │   чланство    присуство    садржај           │
│  B1App      портал чланова +   │ ─────────▶ │   прилози        поруке     служења          │
│             веб-сајтови цркава │            │                                              │
│  B1Checkin  пријава на киоску  │ ◀───WS───▶ │   једна MySQL база по модулу (укупно 6)      │
│                                │            └──────────────────────────────────────────────┘
│  FreePlay   ТВ плејер садржаја │            ┌──────────────────────────────────────────────┐
└───────────────┬────────────────┘            │  LessonsApi — позадина Lessons.church        │
                │                             └──────────────────────────────────────────────┘
                │  дељени код преко npm (@churchapps/*)
                ▼
   helpers (интерфејси између апликација) · apphelper (React компоненте) · apihelper (Express/серверске помоћне функције)
```

Два структурална правила опредељују све што је документовано у овом одељку:

1. **Модули су изоловани.** Сваки Api модул поседује своју базу података и своје табеле. Други модули и апликације приступају његовим подацима само преко његових REST крајњих тачака. Погледајте [Структура модула](../api/module-structure.md).
2. **Дељени код се испоручује као npm пакети.** Апликације никада не увозе изворни код једна друге. Све што се поново користи прелази границе репозиторијума преко `@churchapps/helpers`, `@churchapps/apphelper` или `@churchapps/apihelper`. Погледајте [Дељене библиотеке](../shared-libraries/index.md).
