# Архитектура

<div class="article-intro">

Ове странице су системске мапе које покривају више репозиторијума. Документују како функционише основни ChurchApps систем од почетка до краја, кроз апликације, API модуле и дељене библиотеке, а не како се подешава појединачни пројекат. Прочитајте их пре него што промените понашање система. Прочитајте [Подешавање](../setup/index.md) да бисте покренули пројекат, и [API одељак](../api/index.md) за референцу на нивоу крајњих тачака.

## Екосистем у кратком прегледу

ChurchApps чини око 20 независних репозиторијума (није монорепо). Клијентске апликације комуницирају са малим скупом бекенд API-ја преко HTTPS-а и WebSocket-а, а код деле кроз npm пакете објављене под `@churchapps` опсегом.

```
┌────────────────────────────────┐            ┌──────────────────────────────────────────────┐
│  Clients                       │            │  Api — core modular monolith (AWS Lambda)    │
│                                │            │                                              │
│  B1Admin    staff dashboard    │   HTTPS    │   membership    attendance    content        │
│  B1App      member portal +    │ ─────────▶ │   giving        messaging     doing          │
│             church websites    │            │                                              │
│  B1Checkin  check-in kiosk     │ ◀───WS───▶ │   one MySQL database per module (6 total)    │
│  B1Mobile   (maintenance-only) │            └──────────────────────────────────────────────┘
│  FreePlay   TV content player  │            ┌──────────────────────────────────────────────┐
└───────────────┬────────────────┘            │  LessonsApi — Lessons.church backend         │
                │                             └──────────────────────────────────────────────┘
                │  shared code via npm (@churchapps/*)
                ▼
   helpers (cross-app interfaces) · apphelper (React components) · apihelper (Express/server utilities)
```

Две структурална правила обликују све што је документовано у овом одељку:

1. **Модули су изоловани.** Сваки Api модул поседује своју базу података и своје табеле. Други модули и апликације до његових података долазе искључиво преко његових REST крајњих тачака. Видите [Структура модула](../api/module-structure.md).
2. **Дељени код се испоручује као npm пакети.** Апликације никад не увозе изворни код једна друге. Све што се поново користи прелази границе репозиторијума преко `@churchapps/helpers`, `@churchapps/apphelper` или `@churchapps/apihelper`. Видите [Дељене библиотеке](../shared-libraries/index.md).
