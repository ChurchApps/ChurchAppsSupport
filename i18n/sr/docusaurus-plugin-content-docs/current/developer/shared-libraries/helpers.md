# Помоћне функције

<div class="article-intro">

Пакет `@churchapps/helpers` пружа основне помоћне функције које користе сви ChurchApps пројекти, и фронтенд и бекенд. Не везује се за одређени оквир и укључује уобичајене помоћне функције, као што су `DateHelper`, `ApiHelper` и `CurrencyHelper`, као и заједничке TypeScript интерфејсе који чине уговор о подацима између апликација и API-ја.

</div>

<div class="prereqs">
<h4>Пре почетка</h4>

- Инсталирајте **Node.js** и **Git** -- видите [Предуслови](../setup/prerequisites.md)
- Упознајте се с [радним простором Packages](./index.md) и током објављивања

</div>

## Ко га користи

Сваки ChurchApps API (основни Api, AskApi и LessonsApi) и сваки веб фронтенд (B1Admin, B1App, B1Transfer, LessonsApp) директно зависи од овог пакета. Фронтенди такође добијају многе његове извозе (`ApiHelper`, `DateHelper`, `UserHelper` и друге интерфејсе) поново извезене кроз [`@churchapps/apphelper`](./app-helper.md). Остали заједнички пакети га декларишу као peer dependency, тако да свака апликација учитава тачно једну копију.

## Подешавање за локални развој

Овај пакет се налази у радном простору [Packages](https://github.com/ChurchApps/Packages), заједно с осталим заједничким библиотекама:

1. Клонирајте радни простор:

   ```bash
   git clone https://github.com/ChurchApps/Packages.git
   ```

2. Инсталирајте зависности у корену радног простора:

   ```bash
   cd Packages && yarn install
   ```

3. Изградите пакет (компајлира TypeScript у `dist/`):

   ```bash
   yarn workspace @churchapps/helpers build
   ```

   Или покрените `yarn build` у корену да бисте изградили све пакете оним редоследом којим зависе једни од других.

Да бисте тестирали измене у пројекту који користи пакет, користите привремени Yarn portal -- видите [Локални развој са апликацијом која користи пакет](./index.md#local-development-against-a-consuming-app).

## Објављивање

Објаве иду кроз changesets, а не ручним повећавањем верзија:

1. Покрените `yarn changeset` у корену радног простора, изаберите `@churchapps/helpers` и одговарајућу врсту повећања верзије, па комитујте генерисану changeset датотеку заједно са вашом изменом.
2. Када будете спремни за објаву, покрените `yarn publish-all` у корену -- он повећава верзије, записује CHANGELOG-ове, гради пакете по редоследу зависности и објављује их на npm.

Нови заједнички интерфејси иду у `helpers/src/interfaces/` и реекспортују се кроз package barrel. Каталог типова елемената градитеља сајта (`ElementTypes.ts` — 35 типова с њиховим шемама одговора) такође се налази овде. Он је уговор који деле apphelper рендерери, обрасци уређивача у B1Admin и AI промптови за генерисање (видите [Архитектура градитеља сајта](../architecture/website-builder.md)).

:::warning
Пошто овај пакет користи сваки ChurchApps пројекат, измене овде имају велики утицај. Објава `helpers` аутоматски повећава `apihelper` и `apphelper` да би њихови опсези зависности остали ажурни. Пре објаве тестирајте с Yarn portal-ом у најмање једном API-ју и једној веб апликацији која га користи.
:::
