# VOMO

<div class="article-intro">

VOMO је платформа за укључивање волонтера. Људи се пријављују на пројекте, пријављују се на киоску и сакупљају сате. Ако користите VOMO за заказивање волонтера, а B1 за евиденцију особа, Zapier може да синхронизује чланство и пријаве између њих, тако да ниједна страна не одступа од друге.

</div>

<div class="prereqs">
<h4>Пре почетка</h4>

- Налог на [VOMO](https://vomo.org) на пакету који укључује Zapier (ако нисте сигурни, проверите код VOMO подршке)
- Налог на [Zapier](https://zapier.com)
- Корисник B1Admin са дозволом **Edit Settings**

</div>

## Шта можете повезати

VOMO Zapier апликација нуди четири тренутна окидача и четири радње. Рецепти које већина цркава најчешће жели:

| Смер | Окидач | Радња |
|---|---|---|
| VOMO → B1 | VOMO Membership (created) | B1: Find Person → Create Person (ако је особа нова) |
| VOMO → B1 | VOMO Kiosk check-in | B1: Add Group Member у групу „Currently Serving” или евидентирај као присуство |
| B1 → VOMO | B1 `person.created` | VOMO: Find Organizer (по имејлу); иначе прилагођени корак |
| Било који | VOMO Participation (пријаве) | B1: Add Group Member у групу везану за пројекат |

VOMO радње су ограничене на **креирање нацрта пројеката** и **претрагу** постојећих организатора и пројеката. Тренутно не постоји радња „додај ову особу на VOMO пројекат”. Најкориснија веза је углавном смер VOMO → B1.

## Подешавање

### 1. Креирајте B1 API кључ

**Settings → Developer → API Keys → New API Key**. Дозволе:

- `people:read`, `people:write`: за претрагу и креирање волонтера као B1 особа
- `groups:write`: за додавање у групе служби
- (Опционо) `attendance:write` ако киоск пријаве третирате као присуство

### 2. Направите Zap за синхронизацију чланства

1. **Окидач**: VOMO: Membership (event = `created`).
2. **Радња**: B1.church: Find Person, по имејлу.
3. **Филтер / путања**: гранање према томе да ли је особа пронађена:
   - Није пронађена → B1.church: Create Person, па Add Group Member у одговарајућу групу волонтера.
   - Пронађена → B1.church: Add Group Member директно.
4. Укључите Zap. Нови VOMO волонтери сада се појављују у B1 са одговарајућим чланством у групи.

### 3. (Опционо) Направите Zap за пријаву на киоску

1. **Окидач**: VOMO: Kiosk
2. **Радња**: B1.church: Find Person (по имејлу)
3. **Радња**: по вашем избору:
   - *Ако пријаву третирате као присуство*: Webhooks by Zapier шаље POST на B1 крајњу тачку `/attendance/visits` (B1 Zapier апликација још нема засебну радњу *Record Attendance*). B1 [API кључ](/docs/developer/api/api-keys) иде у заглавље `Authorization: Bearer cak_…`.
   - *Ако пријаву третирате као чланство у групи*: B1.church: Add Group Member у групу „Currently Serving (Today)”. Други Zap касније током дана уклања их путем заказаног чишћења.

## Уобичајени рецепти

### Синхронизација групе по пројекту

- **Окидач**: VOMO: Participation (created)
- **Радња**: Filter by Zapier по ID-ју пројекта, па
- **Радња**: B1.church: Add Group Member у B1 групу чије име прати VOMO пројекат.

Када VOMO пројекат заврши, ручно испразните B1 групу или ово спојите са окидачем *Participation deleted* који их уклања.

### Пошаљите SMS поруку „хвала на пријави”

Повежите VOMO Participation → Clearstream Send Text или Text In Church Send Message у истом Zap-у. Обе имају засебне Zapier радње. Погледајте [Clearstream](./clearstream.md) и [Text In Church](./text-in-church.md).

### Откријте напуштање

Покрените дневни Zapier окидач *Schedule* који позива Find Organizer у VOMO за листу B1 особа које су се овог месеца придружиле тиму служби. Ако VOMO врати „није пронађено”, те особе нису активирале VOMO налог и треба их подсетити.

## Ограничења и напомене

- **Имејл је кључ за спајање.** VOMO подаци откривају имејл корисника, али не и B1 ID особе. Донатори који у сваком систему користе различите имејл адресе створиће дупликате.
- **Тренутно нема радње „Add to Project” у VOMO Zapier апликацији.** Ако вам је потребно уписивање у VOMO пројекат из B1, слали бисте POST на VOMO REST API из корака *Webhooks by Zapier*. То је прилагођена интеграција.
- **VOMO бесплатни или нижи пакети можда не укључују Zapier.** Потврдите код VOMO подршке пре него што обећате датум повезивања.

## Решавање проблема

- **Окидач се никада не активира.** VOMO тренутни окидачи захтевају да API токен остане важећи. Поново тестирајте Zap, а поново повежите VOMO ако је токен промењен.
- **B1 *Add Group Member* не успева са 422.** ID групе у радњи не постоји. Отворите **B1Admin → Groups**, кликните на групу и копирајте сегмент ID-ја из URL-а у корак Zap-а.
- **Дупликати B1 особа из једног VOMO волонтера.** Вероватно су се пријавили са другом имејл адресом од оне коју већ имају у B1. Или стандардизујте имејл адресе, или додајте Zapier *Path* који пре креирања претражује и по телефону.
