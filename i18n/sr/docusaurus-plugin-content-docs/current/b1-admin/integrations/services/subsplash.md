# Subsplash

<div class="article-intro">

Ако користите Subsplash за своју црквену апликацију, давање или обрасце, али желите да B1 буде главни систем за евиденцију људи и прилога, Subsplash-ова Zapier апликација може у реалном времену да преноси прилоге, нове профиле и одговоре на обрасце у B1. Имајте на уму да Subsplash-ова Zapier апликација тренутно подржава **само окидаче**, па је веза једносмерна (Subsplash → B1).

</div>

<div class="prereqs">
<h4>Пре почетка</h4>

- Налог на Subsplash-у на пакету који укључује приступ **API + Zapier** (проверите код свог Subsplash менаџера за успех клијената, јер ово зависи од нивоа пакета)
- Налог на [Zapier](https://zapier.com)
- Корисник B1Admin са дозволом **Edit Settings**

</div>

## Шта можете повезати

Сви окидачи у наставку припадају Subsplash-у. Радње припадају B1.

| Окидач у Subsplash-у | Радња у B1 |
|---|---|
| Нови прилог | Пронађи особу → Додај прилог (Креирај особу ако не постоји) |
| Нова обећана донација | Додај прилог (са `notes` = "Pledge: …") |
| Креирана нова особа | Креирај особу |
| Ажуриран профил особе | (нема директне радње у B1, евидентирајте у Google табели за ручни преглед) |
| Нови одговор на образац | Креирај особу + (по избору) Додај члана групе на основу обрасца |

Subsplash → B1 је једини смер који Subsplash-ова апликација тренутно подржава.

## Подешавање

### 1. Направите B1 API кључ

У B1Admin-у: **Подешавања → Програмер → API кључеви → Нови API кључ**. Опсези:

- `people:read` за претрагу донатора по имејлу
- `people:write` за креирање особе ако не постоји
- `donations:write` за евидентирање прилога
- (`settings:write` није потребан, јер окидач овде припада Subsplash-у, а не B1.)

### 2. Повежите Subsplash са Zapier-ом

Пратите [Subsplash-ов водич за Zapier интеграцију](https://support.subsplash.com/en/articles/9825926-zapier-integration). Они издају API токен унутар Subsplash контролне табле, који Zapier користи за аутентификацију стране окидача.

### 3. Направите Zap за евидентирање прилога

1. **Окидач**: Subsplash: Нови прилог
2. **Радња**: B1.church: Пронађи особу (по имејлу)
3. **Филтер / путања**: гранање према исходу „особа пронађена":
   - **Пронађена:** B1.church: Додај прилог. Повежите поља: износ, датум, фонд, метод = "Online", notes = ID трансакције у Subsplash-у.
   - **Није пронађена:** B1.church: Креирај особу → B1.church: Додај прилог (коришћењем ID-а новокреиране особе).

Укључите Zap. Будући прилози из Subsplash-а ће се за неколико секунди појављивати у **B1Admin → Прилози**.

## Уобичајени рецепти

### Пошаљите захвалницу када стигне први прилог

- **Окидач**: Subsplash: Нови прилог
- **Радња**: Zapier филтер: наставите само ако је то први прилог донатора (користите *Lookup Table* по имејлу донатора у односу на Google табелу претходних донатора, или корак *Paths* у Zapier-у према датуму креирања донатора)
- **Радња**: Mailchimp / SMTP / SendGrid: пошаљите поруку захвалнице за први прилог
- **Радња**: B1.church: Додај прилог (као и обично)

### Издвојите обећане донације из редовног тока давања

- **Окидач**: Subsplash: Нова обећана донација
- **Радња**: B1.church: Додај прилог са `notes = "Pledge — Subsplash"` и фондом под називом `Pledges` (одвојеним од вашег оперативног фонда), како бисте могли независно да извештавате о обећаним донацијама у **B1Admin → Прилози → Резиме**.

### Синхронизујте нове кориснике апликације као особе у B1

- **Окидач**: Subsplash: Креирана нова особа
- **Радња**: B1.church: Креирај особу, уз попуњавање имена, имејла и телефона. Означите нову особу у B1 тако што ћете је додати у групу, као што је „Subsplash App Users".

## Ограничења и напомене

- **Subsplash-ова Zapier апликација подржава само окидаче.** Ако желите измене на страни B1 (нпр. да се нова особа из B1 појави и у Subsplash-у), морали бисте сами да изградите ту везу помоћу окидача из Zapier апликације за B1, који позивају Subsplash-ов REST API преко прилагођене радње *Webhooks by Zapier — POST*. То је прилагођена интеграција, а не рецепт.
- **Приступ API-ју зависи од пакета.** Ако повезивање са Zapier-ом не успе са `403 Forbidden`, ваш Subsplash пакет највероватније не укључује приступ API-ју. Обратите се свом менаџеру за успех клијената.
- **Повезивање фондова је ручно.** Subsplash преноси назив кампање или категорије, а B1 захтева нумерички ID фонда. Или фиксно унесите фонд у Zap, или одржавајте Zapier *Lookup Table* која повезује кампање из Subsplash-а са фондовима у B1.

## Решавање проблема

- **Окидач се не активира након прилога**: проверите на Subsplash-овој Zapier контролној табли да веза и даље приказује *Connected*. Ако је API токен промењен на страни Subsplash-а, Zap без упозорења престаје да ради, па везу треба поново успоставити.
- **B1 *Додај прилог* не успева са грешком 422**: најчешће је узрок недостајући или непрепознат `fundId`. Прикажите своје фондове преко **B1Admin → Прилози → Фондови** и тачан ID унесите у корак Zap-а.
- **Први прилог активира окидач два пута**: Subsplash повремено поново шаље окидач ако Zapier није потврдио пријем. Додајте *Filter by Zapier* на ID прилога (Subsplash га шаље у садржају захтева) да бисте уклонили дупликате.
