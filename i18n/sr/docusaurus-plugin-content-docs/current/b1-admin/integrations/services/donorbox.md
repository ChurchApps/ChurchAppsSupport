# Donorbox

<div class="article-intro">

Ако ваша црква прима донације преко Donorbox-а, али прати особе и изводе у B1, можете подесити да Donorbox-ови тренутни Zapier окидачи креирају одговарајуће записе о донацијама унутар B1 и да креирају донатора као B1 особу ако већ не постоји. Нема ручног усклађивања, нема месечног извоза.

</div>

<div class="prereqs">
<h4>Пре почетка</h4>

- Налог на [Donorbox](https://donorbox.org) са најмање једном кампањом
- Налог на [Zapier](https://zapier.com)
- B1Admin корисник са дозволом **Edit Settings**

</div>

## Шта можете да повежете

| Смер | Donorbox окидач | B1 радња |
|---|---|---|
| Donorbox → B1 | New or Updated Donation (тренутни) | Find Person → Add Donation |
| Donorbox → B1 | New or Updated Donor | Create Person |
| Donorbox → B1 | New or Updated Plan (понављајући) | Find Person → Add Donation (користите ID плана као белешку) |

Donorbox објављује своје окидаче као **тренутне**. Они се активирају у року од неколико секунди након стварне донације, без кашњења при провери.

## Подешавање

### 1. Направите B1 API кључ

У B1Admin-у: **Settings → Developer → API Keys → New API Key**. Опсези:

- `people:read` за претрагу донатора по имејлу
- `people:write` за креирање донатора ако је нов
- `donations:write` за евидентирање поклона

Окидачи у овом смеру припадају Donorbox-у, а не B1, тако да `settings:write` овде није потребан.

### 2. Направите Zap за евидентирање донације

1. **Окидач**: Donorbox: New Donation. Повежите га са Donorbox API кључем (у Donorbox-у: *Account → Profile → API Settings*).
2. **Радња**: B1.church: Find Person. Мапирајте имејл донатора из окидача на поље за претрагу *Email*.
3. **Радња**: Filter by Zapier (опционо): настави само ако донатор није пронађен, па онда…
4. **Радња**: B1.church: Create Person. Мапирајте име, презиме и имејл тако да донатор буде евидентиран као члан, а не само као запис о поклону.
5. **Радња**: B1.church: Add Donation. Мапирајте:
   - Износ → `data.amount`
   - Датум донације → датум донације из окидача
   - Фонд → изаберите B1 фонд који одговара Donorbox кампањи (Zapier омогућава промену фонда на основу филтера или корака Formatter)
   - Метод → „Online”
   - Белешка → Donorbox ID трансакције (корисно при усклађивању)

Укључите Zap. Следећа уживо донација преко Donorbox-а аутоматски се појављује у **B1Admin → Donations**.

## Уобичајени рецепти

### Један Zap по фонду

Ако водите више Donorbox кампања које се мапирају на засебне B1 фондове, најчистији распоред је један Zap по кампањи, са филтером *campaign* из Donorbox-а на врху. Тако је мапирање фонда фиксно и прескачете корак претраге.

### Ажуриране донације третирајте као исправке

*New or Updated Donation* из Donorbox-а активира се и при изменама. Користите корак Zapier *Path* над `event_type` да бисте разграničили токове: „new” → Add Donation, „updated” → Find Donation + Update. Напомена: B1 Zapier апликација тренутно нема радњу Update Donation, па за сада догађаје „updated” евидентирајте у Slack канал за ручни преглед.

### Синхронизујте промене понављајућих планова у Slack канал

- **Окидач**: Donorbox: New or Updated Plan
- **Радња**: Slack: Send Message у `#donations` (нпр. „План је промењен, месечни поклон Саре сада износи $200”)

## Ограничења и напомене

- **Упаривајте донаторе по имејлу.** Donorbox не дели B1 ID особе, па је имејл једини трајни кључ за повезивање. Донатори који дају под другом адресом створиће нову B1 особу, па их ваше месечно усклађивање треба да тражи.
- **Повраћаји нису посебно приказани.** Donorbox шаље ажурирање статуса за исту донацију. B1 Zapier апликација тренутно нема радњу *Update Donation*, па је безбедан образац за сада да евидентирате догађаје повраћаја ван система и ручно прилагодите донацију.
- **Прво тестирајте у Donorbox sandbox-у** да не бисте створили лажне поклоне у продукционом B1. Donorbox обезбеђује тест акредитиве одвојене од живих.

## Решавање проблема

- **Упозорење „Person not found” при сваком покретању**: то је у реду ако сте кораке поређали тако да се *Create Person* извршава у грани „not found”. Ако се ни корак Create Person никада не извршава, проверите да API кључ има `people:write`.
- **Износ донације изгледа 100× превелик или премали**: Donorbox у неким варијантама шаље центе, а у другим доларе. Користите корак *Formatter by Zapier — Numbers* за дељење са 100 ако је потребно.
- **Дупле донације из једног поклона**: Donorbox активира и *New Donation* и *Updated Donation*. Или филтрирајте на `event_type = "donation.succeeded"`, или направите два Zap-а са неповезаним филтерима.
