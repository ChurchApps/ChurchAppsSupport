# Text In Church

<div class="article-intro">

[Text In Church](https://textinchurch.com) објединјује SMS и постепене токове рада и аутоматизацију картица за везу. Његова Zapier апликација омогућава оба смера: да B1 догађаје пренесете у ток рада Text In Church, и да окидаче за картице за везу или нове контакте пренесете из њега у B1.

</div>

<div class="prereqs">
<h4>Пре почетка</h4>

- Налог на [Text In Church](https://textinchurch.com) са планом који укључује Zapier интеграцију
- Налог на [Zapier](https://zapier.com)
- Корисник B1Admin са дозволом **Измена подешавања**

</div>

## Шта можете повезати

| Смер | Окидач | Радња |
|---|---|---|
| B1 → Text In Church | B1 `person.created` | Креирај/ажурирај особу + Додај у групу |
| B1 → Text In Church | B1 `form.submission.created` | Пошаљи SMS поруку преко одговарајућег тима |
| B1 → Text In Church | B1 `group.member.added` | Додај у групу (огледај чланство у групи) |
| Text In Church → B1 | Послата картица за везу | B1: Креирај особу + Додај члана групе |
| Text In Church → B1 | Креирана особа | B1: Креирај особу |
| Text In Church → B1 | Особа се придружила групи | B1: Додај члана групе |

Радње Text In Church укључују и *Пошаљи SMS поруку*, *Пошаљи гласовно емитовање*, *Креирај задатак*, *Пронађи особу/групу*, као и додавање и уклањање из групе.

## Подешавање

### 1. Креирајте B1 API кључ

**Подешавања → Програмер → API кључеви → Нови API кључ**:

- `settings:write`: обавезно за Zap-ове које покреће B1
- `people:read`, `people:write`: за проналажење или креирање особе
- `groups:write`: за синхронизацију група
- (Опционално) `donations:write` ако повезујете потврде о поклонима са TIC-ом

### 2. Повежите Text In Church са Zapier-ом

Пратите [упутство за Zapier интеграцију Text In Church-а](https://help.textinchurch.com/en/articles/3943363-text-in-church-s-zapier-integration). Они генеришу API токен унутар TIC контролне табле.

### 3. Направите Zap од картице за везу до B1

Најчешћи смер. Картице за везу послате из TIC-а аутоматски постају нове особе у B1.

1. **Окидач**: Text In Church: Послата картица за везу.
2. **Радња**: B1.church: Пронађи особу (по имејлу).
3. **Путања**: гранање према томе да ли је особа пронађена:
   - Није пронађена → B1.church: Креирај особу.
   - Пронађена → настави.
4. **Радња**: B1.church: Додај члана групе у групу „Нови контакт“.

Укључите Zap. Следећа картица за везу послата преко TIC-а аутоматски се појављује у **B1Admin → Особе**.

## Уобичајени рецепти

### Покрените ток рада у стилу картице за везу из B1 обрасца

- **Окидач**: B1.church: Нова попуњена форма (филтрирајте по ID-ју обрасца „Нов сам овде“)
- **Радња**: Text In Church: Креирај/ажурирај особу, мапирајући одговоре из обрасца за имејл, телефон и име
- **Радња**: Text In Church: Додај у групу, где група има унапред направљен ток рада за добродошлицу

### Огледај чланство у групи

- **Окидач**: B1.church: Нови члан групе, филтриран по одређеном `groupId`
- **Радња**: Text In Church: Додај у групу (иста особа, огледна група). Упарите са Zap-ом за `group.member.removed` ако желите потпуну синхронизацију.

### Обавестите вођу када се неко придружи

- **Окидач**: B1.church: Нови члан групе
- **Радња**: Text In Church: Пошаљи SMS поруку, прималац = телефон вође групе, текст = `"{first} {last} се управо придружује групи {group}"`.

## Ограничења и напомене

- **TIC-ова Zapier апликација зависи од нивоа плана.** Ако је Zapier интеграција сива на TIC контролној табли, обратите се TIC подршци да је омогуће за ваш план.
- **ID-јеви група су TIC-ови, а не B1.** Приликом огледања морате негде да одржавате табелу мапирања (Zapier *Lookup Table*, или фиксно уписано у сваки Zap).
- **Слање SMS поруке troши кредите.** Сваки Zap који покрене *Send Text* троши из ваше TIC SMS квоте.

## Решавање проблема

- **Окидач картице за везу не реагује**: TIC мора имати укључену Zapier интеграцију. Такође проверите да је образац који сте тестирали подешен као „Картица за везу“, а не као општи упитник.
- **Креирање особе у B1 не успева са грешком 401**: API кључ је погрешан, опозван или нема `people:write`. Поново креирајте кључ.
- **Дупликати особа у B1**: TIC шаље и *Креирана особа* и *Послата картица за везу* за исти догађај. Изаберите једну као извор истине и додајте Zapier филтер на другу.
