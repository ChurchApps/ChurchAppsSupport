# Гугл табеле

<div class="article-intro">

**B1 Export** је званични додатак за Гугл табеле за B1.church. Он додаје бочну траку у било коју табелу која извози особе, донације, групе или присуство из ваше B1 цркве у именоване картице, на захтев и једним кликом. Додатак ради у потпуности унутар корисниковог Гугл налога. Осим услова за само читање API позива које свaки извоз прави, ништа у вези с њим не дотиче серверe ChurchApps.

</div>

<div class="prereqs">
<h4>Пре почетка</h4>

- Гугл налог са правом уређивања табеле у коју желите да извозите податке
- Администратор цркве (или особа са правом читања података које желите да извезете) која може да направи B1 API кључ
- Додатак B1 Export инсталиран из Google Workspace Marketplace-а

</div>

## Шта се извози

| Ставка менија | Картица табеле | Подаци |
|---|---|---|
| Export People | `B1 People` | ID, Display Name, First, Last, Email, Membership Status |
| Export Donations | `B1 Donations` | ID, Person ID, Date, Amount, Method, Batch ID |
| Export Groups | `B1 Groups` | ID, Name, Category, Member Count |
| Export Attendance | `B1 Attendance` | ID, Person ID, Visit Date, Service ID, Group ID |

Сваки извоз **замењује** садржај своје именоване картице. Поновним покретањем извоза добијате нову слику стања, а не додате редове. Остале картице у табели остају нетакнуте.

## Подешавање

### 1. Направите B1 API кључ с одговарајућим дозволама

1. У B1Admin идите на **Settings → Developer → API Keys** (Подешавања → Програмер → API кључеви).
2. Кликните на **New API Key**, назовите га „Sheets Export” и доделите дозволе **read** за оно што планирате да извезете:
   - `people:read` за извоз особа
   - `donations:read` за донације
   - `groups:read` за групе
   - `attendance:read` за присуство
3. Кључ који служи само за извоз **не треба** да има `settings:write`. Та дозвола је потребна само за конекторе који региструју webhook-ове (Zapier / Make). Држите овај кључ што ужим.
4. Сачувајте и копирајте кључ `cak_…`.

### 2. Инсталирајте додатак

1. Отворите табелу у коју желите да извезете податке.
2. **Додаци → Додаци → Преузми додатке** (Extensions → Add-ons → Get add-ons).
3. Потражите **B1 Export** и инсталирајте га. Гугл тражи дозволу за приступ вашим табелама и за спољне HTTP захтеве (како би додатак могао да позива B1 API).

Након инсталације, ставка **B1 Export** појављује се у менију **Додаци** сваке табеле коју отворите с овим Гугл налогом.

### 3. Повежите кључ

1. **Додаци → B1 Export → Connect…** (или **B1 Export → Connect…** из траке менија након првог отварања).
2. Налепите API кључ у бочну траку, оставите Base URL као `https://api.churchapps.org` (осим ако тестирате на окружењу за припрему) и кликните на **Save**.
3. Кликните на **Test Connection**. Зелена порука „Connection OK” потврђује да кључ ради.

Кључ се чува у **корисничким својствима** (`PropertiesService.getUserProperties()`). Везан је за ваш Гугл налог, никад се не уписује у табелу и није видљив другим уредницима табеле.

## Покретање извоза

Може се на један од два начина:

- **Из менија**: **Додаци → B1 Export → Export People** (или Donations / Groups / Attendance)
- **Из бочне траке**: отворите бочну траку (Connect…) и кликните на одговарајуће дугме за скуп података

Порука се појављује када је извоз завршен: „_N_ ред(ова) упisано у 'B1 People'.”

## Прављење извештаја на основу података

Извезене картице су обичне Гугл табеле. Своју аналитику градите тако што референцирате те картице:

- **Картица са збиром** с формулом `=SUMIF('B1 Donations'!E:E, "card", 'B1 Donations'!D:D)` за збир донација картицом
- **Филтрирани преглед** само чланова с формулом `=FILTER('B1 People'!A:F, 'B1 People'!F:F = "Member")`
- **Графикон** трендова присуства који повлачи податке из картице `B1 Attendance`

Поновни извоз освежава основну картицу, а ваше формуле се аутоматски ажурирају.

## Заказивање периодичних извоза

Додатак по подразумеваној поставци ради на захтев. За недељне или месечне извозе користите уграђене временски окидаче Apps Script-а:

1. **Додаци → Apps Script** у табели (отвара се скрипта повезана с додатком).
2. Кликните на икону **⏰ Triggers** (Окидачи) у левој бочној траци.
3. **Add Trigger** за `exportPeople` (или било коју функцију извоза). Изаберите *Time-driven*, *Week timer*, нпр. *Every Monday 6am* (Сваког понедељка у 6 ујутру).

Извоз се извршава у позадини под вашим Гугл налогом. Ако се API кључ замени или опозове, окидач вам пошаље имејл при следећем неуспеху.

## Дозволе и приватност

- Додатак тражи само `spreadsheets.currentonly` (може да приступи само табели у којој је отворен) и `script.external_request` (како би `UrlFetchApp` могао да позива B1 API). **Не** види ваш Drive, Gmail нити друге Гугл податке.
- B1 API кључ се чува по кориснику. Други уредници исте табеле не могу да га виде.
- Сви B1 API позиви се шаљу преко HTTPS-а с заглављем `Authorization: Bearer cak_…`.

## Решавање проблема

- **„No API key set”**: отворите **Додаци → B1 Export → Connect…** и налепите кључ.
- **„B1 rejected the API key (401)”**: кључ је опозван или је погрешан. Направите нови и поново га налепите.
- **„This API key lacks permission for /giving/donations (403)”**: кључ нема дозволу `donations:read`. Ажурирајте дозволе кључа у B1Admin-у.
- **Табела се не освежава** након покретања: проверите да гледате у *исправну* картицу (`B1 People` итд.). Извоз креира картицу ако она не постоји.
- **„Quota exceeded”**: Apps Script ограничава дневни број позива `UrlFetchApp` по кориснику (обично хиљаде позива дневно). Велика црква с много записа можда треба да подели извоз на више дана или да користи [Make](./make.md) или прилагођену интеграцију за синхронизацију велике количине података.

## Прилагођавање додатка

Додатак је отвореног кода. Apps Script пројекат налази се у репозиторијуму `B1Integrations/GoogleSheetsAddon/`. Ако вам треба колона која се не извози, додатни скуп података или други формат излаза, отворите issue или PR у том репозиторијуму.
