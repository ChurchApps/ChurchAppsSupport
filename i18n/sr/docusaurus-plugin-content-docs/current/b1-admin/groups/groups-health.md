# Здравље група

<div class="article-intro">

Контролна табла Здравље група пружа преглед стања свих ваших група: трендове чланства, просечну посећеност и раст или одлив у последњих 90 дана, све у једној табели која се може сортирати.

</div>

<div class="prereqs">
<h4>Пре почетка</h4>

- Потребно је да имате бар неколико група са члановима да бисте видели смислене податке. Погледајте [Креирање група](./creating-groups.md).
- Подаци о посећености преузимају се из забележених састанака. Погледајте одељак [Посећеност](../attendance/index.md).

</div>

## Отварање Здравља група

У B1 Admin-у отворите [Jump мени](../introduction.md#getting-around-with-the-jump-menu) (поље за претрагу у горњем левом углу), проширите **Људи**, кликните на **Групе**, а затим на дугме **Здравље група** у заглављу странице. Контролна табла учитава табелу с једним редом за сваку групу.

## Колоне

| Колона | Шта приказује |
|--------|--------------|
| **Назив** | Назив групе, повезан са страницом са детаљима групе |
| **Категорија** | Категорија групе |
| **Чланови** | Тренутни број активних чланова |
| **Учлањени (90д)** | Чланови који су се учланили у последњих 90 дана |
| **Напустили (90д)** | Чланови који су напустили групу у последњих 90 дана |
| **Одлив (90д)** | Нето стопа одлива у процентима за период од 90 дана |
| **Просечна посећеност** | Просечан број присутних по састанку са евиденцијом посећености |

Кликните на заглавље било које колоне да бисте сортирали табелу по тој колони. Кликните поново да бисте променили смер сортирања.

## Коришћење података о здрављу

- **Висок одлив + ниска учлањења** — група која се смањује и не замењује изгубљене чланове. Вреди разговора с вођом групе.
- **Много учлањења + ниска посећеност** — људи се пријављују, али не долазе. Размислите о додатном ангажовању.
- **Висока просечна посећеност** — здрава, активна група. Потенцијални узор за друге групе.

:::tip
Клик на назив групе води вас директно на страницу са детаљима групе, где можете прегледати појединачне чланове, записе о посећености и догађаје у календару.
:::
