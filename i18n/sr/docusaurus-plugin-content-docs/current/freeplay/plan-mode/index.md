# Режим плана

<div class="article-intro">

Режим плана повезује ваш телевизор са планом богослужења. Уместо да преузима садржај према распореду часова, прати план који је подесило црквено руководство у B1 Admin. Ово је идеално када желите да телевизор приказује тачно оно што је додељено у плану за текућу недељу.

</div>

## Како се разликује од других режима

- **[Режим по распореду](../scheduled-mode/)** пушта листе за репродукцију из календара у FreePlay Admin у време које подесите, без потребе да неко притисне Start
- **Режим плана** преузима садржај повезан са типом плана, што може укључивати часове, презентације добављача, додатке и другу медијску грађу распоређену у прилагођеном редоследу

Режим плана је posebno koristan kada vaš plan богослужења укључује мешавину садржаја из различитих извора, сав organizovan у један низ.

:::tip
Желите да се текући план пушта сам у одређено време? У FreePlay Admin додајте унос у календар и изаберите тип плана под **Service plans**. Видите [Заказивање календара](../scheduled-mode/scheduling-the-calendar).
:::

## Како функционише

1. На телевизору отворите **Settings** > **Pair to a calendar** да бисте приказали код за упаривање
2. Администратор уноси тај код у **B1 Admin** и бира тип плана под **Show Plans For**
3. Када је упаривање завршено, FreePlay учитава текући план и преузима сву повезану медијску грађу
4. Притисните **Start Plan** да бисте започели репродукцију

Телевизор остаје упарен са типом плана. Сваке недеље аутоматски преузима најновији план и његов садржај.
