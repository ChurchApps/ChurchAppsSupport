# Почетак рада

:::danger B1 Mobile је застарео
Нативну апликацију B1 Mobile заменила је [B1.church прогресивна веб-апликација (PWA)](../../b1-church/getting-started/installing-pwa.md). Нови корисници треба да инсталирају PWA са било које странице на `https://yourchurchname.b1.church`, уместо да преузимају B1 Mobile из App Store-а или Google Play-а.
:::

<div class="article-intro">

Почетак рада са B1 Mobile траје само неколико минута. Преузмите апликацију, пријавите се својим ChurchApps налогом, изаберите своју цркву и спремни сте.

</div>

## Брзи почетак

1. **Преузмите** апликацију из [App Store-а](https://apps.apple.com) (iOS) или [Google Play Store-а](https://play.google.com) (Android). Потražите „B1.church”.
2. **Пријавите се** постојећим ChurchApps налогом, тј. истом адресом е-поште и лозинком које користите на B1.church. Ако још немате налог, додирните **Региструј се** да га направите.
3. **Изаберите своју цркву** претрагом по имену. Унесите најмање 3 знака да бисте видели резултате.
4. **Погледајте почетну страницу** — ваш персонализовани почетни екран приказује брзе везе до функција које ваша црква нуди.

То је све. Када изаберете своју цркву, апликација учитава брендирање, навигационе везе и садржај ваше цркве. Можете почети да користите групе, давања, пријаву и све остало што је ваша црква омогућила.

:::
