# Navigazione e Scaricamento di Contenuto

<div class="article-intro">

Una volta che ti sei collegato a un provider di contenuto, puoi navigare nella sua biblioteca, scaricare file e riprodurli sulla tua TV. Il browser di contenuto fornisce una griglia visiva di cartelle e file che navighi con il telecomando della tua TV.

</div>

<div class="prereqs">
<h4>Prima di Iniziare</h4>

- Collegati ad almeno un provider di contenuto -- vedi [Connessione a Provider](./connecting-providers)
- Tieni il telecomando della TV pronto per la navigazione

</div>

## Il Browser di Contenuto

Il browser di contenuto visualizza gli elementi in una griglia a 3 colonne di schede. Ogni scheda mostra un'immagine in miniatura e un titolo. Ci sono due tipi di elementi:

- **Cartelle** - Rappresentate da un'immagine in miniatura o un'icona di cartella. Seleziona una cartella per vederne i contenuti.
- **File** - Elementi multimediali individuali (video o immagini). I file video visualizzano un'icona di riproduzione sovrapposta alla loro miniatura.

L'intestazione in cima allo schermo mostra il nome della cartella corrente, o il nome del provider se sei al livello radice.

## Navigazione Cartelle

1. Usa il pad direzionale sul telecomando per evidenziare una cartella
2. Premi **Select** per aprirla
3. Il browser carica i contenuti della cartella, che possono essere più cartelle o file riproducibili
4. Premi **Back** sul telecomando per salire di un livello

Puoi perforare il più profondamente possibile che la struttura di contenuto del provider consenta. Il browser tiene traccia del tuo percorso di cartella in modo che tu possa navigare indietro attraverso ogni livello.

## Scaricamento e Riproduzione di Contenuto

Quando selezioni una cartella che contiene file riproducibili (o selezioni un singolo file), FreePlay si sposta in una schermata di download:

1. Il titolo del contenuto appare sullo schermo con un'immagine di copertina dalla cartella selezionata
2. Una barra di progresso mostra **Downloading item X of Y** mentre i file vengono salvati sul tuo dispositivo
3. Una volta completato il download, il pulsante **Start** appare con un'icona di riproduzione
4. Premi **Select** per iniziare la riproduzione

:::tip
Il contenuto scaricato è memorizzato nella cache sulla tua TV. Se riproduci lo stesso contenuto di nuovo più tardi, si carica istantaneamente senza ri-scaricare.
:::

## Riproduzione di Contenuto Provider

La riproduzione funziona allo stesso modo della riproduzione di lezioni. Usa questi controlli:

- **Right arrow** - Elemento successivo
- **Left arrow** - Elemento precedente
- **Select / Play-Pause** - Pausa o riprendi il video
- **Up arrow** - Apri il selettore di messaggi per saltare a un elemento specifico
- **Back** - Esci al browser di contenuto

Quando esci dal lettore, torni al browser di contenuto al livello radice del provider corrente.

:::info
Per un riferimento completo di tutti i controlli del lettore, vedi [Riproduzione di Lezioni](../classroom-mode/playing-lessons).
:::

## Commutazione Tra Provider

I provider collegati appaiono come elementi sotto l'intestazione **Browse** nella barra laterale a sinistra. Per passare a un provider diverso:

1. Premi il tasto **Left** sul telecomando per espandere la barra laterale
2. Seleziona il provider che desideri navigare
3. Il browser di contenuto si aggiorna con la biblioteca di quel provider

:::warning
Se una cartella mostra "No content available," il provider non ha elementi a quel livello. Prova a navigare a una cartella diversa o torna a verificare più tardi.
:::
