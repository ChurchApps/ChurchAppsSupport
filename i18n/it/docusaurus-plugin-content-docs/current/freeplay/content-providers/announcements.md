# Annunci

<div class="article-intro">

FreePlay può ripetere in loop una cartella di diapositive di annunci sulla tua TV — ad esempio, in un atrio o prima dell'inizio delle lezioni. Scegli una cartella da uno dei fornitori di contenuti collegati, FreePlay scarica le sue diapositive sul dispositivo e nella barra laterale compare una voce **Annunci**, così puoi avviare il loop in qualsiasi momento.

</div>

<div class="prereqs">
<h4>Prima di iniziare</h4>

- [Collega un fornitore di contenuti](./connecting-providers) che contenga le tue diapositive di annunci, ad esempio Dropbox o OneDrive
- Metti insieme, in una sola cartella di quel fornitore, le immagini o i video che vuoi ripetere in loop

</div>

## Scegliere la cartella degli annunci

1. Apri **Impostazioni** dalla parte inferiore della barra laterale, poi seleziona **Fornitori**
2. Seleziona il fornitore collegato che contiene le tue diapositive (mostra un badge **Connesso**) per aprire le sue **Impostazioni fornitore**
3. Seleziona **Usa per gli annunci**
4. Si apre il browser **Scegli la cartella degli annunci**. Spostati tra le cartelle fino a trovare quella con le tue diapositive, poi seleziona quella cartella (o un file qualsiasi al suo interno)
5. FreePlay scarica le diapositive e torna alle **Impostazioni fornitore**, dove la riga ora riporta **In loop "*nome cartella*" -- *numero* diapositive scaricate**

Viene usata una sola cartella per gli annunci alla volta. Scegliere una cartella da un altro fornitore sostituisce la precedente.

## Riprodurre gli annunci

Una volta scaricate le diapositive, nella parte alta della barra laterale compare una voce **Annunci** (sotto **Piano di oggi**, se la tua TV lo mostra). Selezionala per avviare il loop.

- Le immagini restano sullo schermo per 15 secondi, a meno che il fornitore non assegni al file una propria durata
- I video vengono riprodotti fino alla fine prima di passare alla diapositiva successiva
- Dopo l'ultima diapositiva, il loop ricomincia dalla prima
- Se la cartella contiene un solo video, questo viene ripetuto sul posto

Il loop riproduce i file salvati sul dispositivo, quindi continua a funzionare senza connessione internet. Puoi usare gli stessi comandi del telecomando di qualsiasi altro contenuto — consulta [Riproduzione dei contenuti](./playing-content).

## Aggiornare le diapositive

FreePlay controlla la cartella degli annunci ogni volta che l'app si avvia, scarica le nuove diapositive e rimuove quelle eliminate dalla cartella.

Per verificare subito, apri le **Impostazioni fornitore** del fornitore e seleziona **Controlla aggiornamenti degli annunci**. La riga mostra **Aggiornato** con il numero di diapositive al termine.

:::info
Se FreePlay non riesce a raggiungere il fornitore, oppure la cartella risulta vuota, continua a riprodurre le diapositive che ha già. Per smettere del tutto di usare gli annunci, disattivali come descritto più sotto.
:::

:::warning
Una diapositiva sostituita con una nuova versione dello stesso file non viene scaricata di nuovo. Per cambiare una diapositiva, aggiungila come nuovo file ed elimina quella vecchia.
:::

## Disattivare gli annunci

Apri le **Impostazioni fornitore** del fornitore e seleziona di nuovo **Usa per gli annunci**. FreePlay smette di usare la cartella, elimina dal dispositivo le diapositive scaricate e rimuove **Annunci** dalla barra laterale.

Scollegare il fornitore disattiva anche gli annunci provenienti da esso.
