# Integrazioni

<div class="article-intro">

Le integrazioni collegano ChurchApps a servizi di terze parti — Mailchimp per la sincronizzazione del pubblico, Zapier per l'automazione, Lessons.church per il contenuto didattico e altro ancora.

</div>

## Tipi di Integrazione

### Connettori Nativi

Alcuni servizi hanno connettori integrati in B1 Admin (Mailchimp, Zapier, Make). Questi richiedono una chiave API e una configurazione della chiesa.

### Webhook-Triggered

Molte integrazioni utilizzano webhook di B1 per attivare azioni esterne. Ad esempio:
- Un webhook di donazione può attivare una zappa per scrivere in un CRM
- Un webhook di membro aggiunto al gruppo può attivare un'email di benvenuto

### Fornitori di Contenuti

Le integrazioni come Lessons.church forniscono il contenuto didattico che può essere programmato nei piani di servizio.

## Configurazione

Le integrazioni sono configurate per chiesa in B1Admin → Impostazioni → Integrazioni. La maggior parte richiede:
- Una chiave API dal servizio di terze parti
- Autorizzazione che specifici dati possono essere condivisi
- Test di connessione per convalidare le credenziali
