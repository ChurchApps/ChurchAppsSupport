# Amministrazione

<div class="article-intro">

L'area di amministrazione di Lessons.church è il luogo in cui i creatori di contenuti e gli amministratori gestiscono la libreria delle lezioni. Da qui è possibile costruire la struttura del curriculum, caricare risorse, consultare le statistiche di utilizzo e collegare fornitori di contenuti di terze parti.

</div>

:::warning
L'accesso all'amministrazione richiede le autorizzazioni appropriate. Se non vedi le opzioni di amministrazione, contatta l'amministratore della tua chiesa per richiedere l'accesso.
:::

## Cosa puoi fare

L'area di amministrazione ti offre il pieno controllo sui tuoi contenuti:

- **Creare e modificare i programmi** -- Configura le serie di curriculum di primo livello con nomi, descrizioni, immagini e slug.
- **Gestire gli studi** -- Organizza gruppi di lezioni correlate all'interno di ciascun programma.
- **Costruire le lezioni** -- Aggiungi singole lezioni con sedi, sezioni, ruoli e azioni.
- **Caricare risorse** -- Allega file scaricabili (PDF, schede attività, immagini) a livello di programma, studio o lezione.
- **Visualizzare le statistiche** -- Scopri quali contenuti vengono scaricati, da chi e da dove.
- **Configurare i fornitori** -- Collega fornitori di curriculum esterni che utilizzano l'Open Lesson Format. Questa operazione si esegue dalla pagina **Fornitori esterni**, non dall'area di amministrazione.
- **Piani annuali** -- Pubblica le sequenze settimana 1, 2, 3… per qualsiasi curriculum. Le chiese le applicano in B1 Admin.

## Struttura dei contenuti

In qualità di amministratore, è utile capire come sono strutturati i contenuti:

1. **I programmi** contengono uno o più studi.
2. **Gli studi** contengono una o più lezioni.
3. **Le lezioni** contengono una o più sedi (varianti per fascia d'età).
4. **Le sedi** contengono sezioni, e le sezioni contengono azioni basate sui ruoli.

Ogni livello può avere le proprie risorse scaricabili allegate.
