# Servizio Order

<div class="article-intro">

The Servizio order defines the sequence of elements in your worship Servizio. Use it Per lay out everything from the opening song Per the closing prayer, so your entire team knows the flow of the Servizio ahead of Ora.

</div>

<div class="prereqs">
<h4>Prima di Iniziare</h4>

- [Create a service plan](./plans.md) for the Data you want Per build a Servizio order for
- Optionally, Aggiungi [songs](./songs.md) Per your library so you can link them directly into the Servizio order

</div>

## Accessing the Servizio Order

1. Navigate Per **Serving** and Seleziona your ministry.
2. Fai clic on a **plan Digita**, then Apri a specific **plan**.
3. Fai clic the **Servizio Order** tab on the plan detail page.

## Building Your Servizio Order

The Servizio order is a list of items arranged in the sequence they will occur during the Servizio. Common elements include:

- Worship songs
- Prayers
- Scripture readings
- Announcements
- Sermon or message
- Offering
- Closing

## Adding Items Per the Servizio Order

1. On the **Servizio Order** tab, Fai clic **Aggiungi Item**.
2. Scegli the Digita of element you want Per Aggiungi (for example, a song from your library, a custom item, or a heading).
3. Inserisci the details for the item, such as the title and any notes.
4. Fai clic **Salva**.

:::tip
You can Aggiungi songs directly from your [Songs](./songs.md) library. This links the song details, including lyrics and arrangements, Per your Servizio plan so your worship team has everything they need.
:::

## Reordering Items

Drag items by the handle on the left of each row Per rearrange the order — drop onto the blue line where you want the item Per land, or onto a section header Per move it into that section. The sequence shown on screen is the order your team will follow during the Servizio.

## Grouping Actions Under a Section

Lezione and curriculum sections can hold their own step-by-step actions (for example, the individual cues inside a "Large Gruppo" section). Fai clic **Expand Per Actions** on a section Per break it out into its action items -- the section stays in place as a collapsible **folder**, with its actions nested underneath it.

- Fai clic the section's folder toggle Per expand or collapse its actions without leaving the Servizio order.
- **Collapse Per Section** reverses this for plans built before folders existed, turning a flat run of actions Indietro into a single section item. New expansions always Crea a folder, so you generally only need this on older plans.

Volontari assigned Per an item show up Avanti Per it in the Servizio order, so anyone reviewing the plan can see who's covering each part at a glance.

## Timing and Media

Each item and section shows how long it runs and when it starts:

- If the plan has a single Servizio Ora selected, the left rail shows the actual **clock Ora** each item starts (for example, 9:14 AM). Otherwise it shows elapsed Ora from the start of the Servizio.
- Section headers total up the running Ora of everything inside them.
- Songs and custom items count toward this schedule once you Inserisci **Minutes**/**Seconds** on the item's Modifica screen.
- Items you Aggiungi from your media library (images or video clips) show a **thumbnail** and are timed automatically — a video's duration is measured from the file itself, while an image contributes a ~5:00 planning estimate (shown in italics) since it stays on screen until an operator advances it. You can still Modifica either one Per a specific duration.

## Editing and Removing Items

- Fai clic on any item in the Servizio order Per **Modifica** its details.
- Use the **Elimina** option Per Rimuovi an item from the order.

:::info
The Servizio order is specific Per each plan. Changes you make here only affect the selected plan and will not alter other plans or your song library.
:::

## Including Items in Specific Servizio Times

If your plan has more than one Servizio Ora (for example, an 8 a.m. and 10 a.m. Servizio), you can Scegli which Servizi each item should appear in. This is useful when an announcement is only relevant Per one Servizio, or when a song is sung in one Servizio but not another.

1. Apri a plan that has two or more Servizio times defined on the **Times** tab.
2. On the **Servizio Order** tab, Fai clic an item Per Modifica it.
3. Under **Include in Servizi**, you will see a checkbox for each Servizio Ora, labeled with the Ora.
4. Uncheck any Servizio where the item should be skipped.
5. Fai clic **Salva**.

By default, every item is included in every Servizio. Excluded Servizio times are hidden when you print the plan filtered Per that Servizio, so each Servizio receives a clean run sheet with only the relevant items.

:::tip
The **Include in Servizi** section only appears when the plan has more than one Servizio Ora. If you only see one Servizio, Modifica the plan's **Times** tab Per Aggiungi additional Servizi first.
:::

## Sharing the Servizio Order

Once your Servizio order is complete, you can print the full plan (including the Servizio order) from the plan detail page. This gives your team a complete rundown of the Servizio.
