# File

<div class="article-intro">

La pagina File è il repository centrale per tutti i media e i documenti utilizzati sul sito web della tua chiesa. Da qui puoi caricare, organizzare, sfogliare e gestire ogni immagine, documento e file multimediale di cui il tuo sito ha bisogno.

</div>

<div class="prereqs">
<h4>Prima di Iniziare</h4>

- Completa la [Configurazione Iniziale](initial-setup) per il tuo sito web
- Ottimizza le immagini prima di caricarle per tempi di caricamento della pagina più veloci
- Prepara i tuoi file in formati web comuni (PNG, JPG, PDF, ecc.)

</div>

## Caricamento di File

1. In B1 Admin, apri il [menu Jump](../introduction.md#getting-around-with-the-jump-menu) (la barra di ricerca in alto a sinistra), espandi **Website** e fai clic su **File**.
2. Trascina e rilascia i file direttamente nell'area di caricamento, oppure fai clic sul pulsante di caricamento per sfogliare il tuo computer.
3. I tuoi file caricheranno e appariranno nella libreria di file immediatamente.

:::tip
Per i migliori risultati, ottimizza le immagini prima di caricarle. Dimensioni di file più piccole aiutano il tuo sito web a caricarsi più velocemente per i visitatori. Strumenti come TinyPNG o Squoosh possono comprimere le immagini senza notevole perdita di qualità.
:::

## Organizzazione con Cartelle

1. Crea cartelle per raggruppare i file correlati insieme -- ad esempio, "Grafica Sermone", "Banner Evento" o "Foto Staff".
2. Sposta i file tra le cartelle per mantenere la tua libreria ordinata man mano che cresce.
3. Usa nomi di cartella chiari e descrittivi in modo che il tuo team possa trovare i file rapidamente.

## Sfogliatura e Ricerca

- Scorri attraverso la libreria di file per vedere le miniature di tutti i tuoi file caricati.
- Usa la funzione **ricerca** per trovare i file per nome quando la tua libreria diventa grande.
- Fai clic su qualsiasi file per visualizzare i suoi dettagli, incluso il nome del file, le dimensioni e l'URL.

## Utilizzo di File sul Tuo Sito Web

1. Fai clic su un file per visualizzare i suoi dettagli.
2. **Copia l'URL del file** per usarlo nelle pagine del tuo sito web. Puoi incollare questo URL in elementi immagine, link di download o ovunque accetti un URL di file.
3. I file che carichi qui sono disponibili per l'uso su tutte le pagine del sito web e i blocchi di contenuto.

:::info
Quando costruisci le pagine in [Gestione Pagine](managing-pages), puoi fare riferimento a qualsiasi file caricato qui dal suo URL. Questo mantiene tutti i tuoi media organizzati in un'unica posizione centrale.
:::

## Eliminazione di File

1. Seleziona il file che desideri rimuovere.
2. Fai clic sul pulsante **Elimina** per rimuoverlo permanentemente dalla tua libreria.
3. Assicurati che il file non sia attualmente utilizzato su nessuna pagina prima di eliminarlo, poiché questo interromperà tutti i link o le immagini che lo referenziano.

:::warning
I file eliminati non possono essere recuperati. Verifica due volte che un file non sia più utilizzato su nessuna pagina prima di rimuoverlo.
:::
