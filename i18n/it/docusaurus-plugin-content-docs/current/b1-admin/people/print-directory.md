# Print Directory

<div class="article-intro">

The Print Directory feature generates a formatted, printable Membro directory for your church. It organizes Membri by household, includes contact information and photos, and is designed Per look professional when printed on standard letter-size paper.

</div>

<div class="prereqs">
<h4>Prima di Iniziare</h4>

- You need an Attivo B1 Admin Account with Permesso Per Visualizza people.
- People in your directory should have photos and contact information filled in for the best results.

</div>

## Opening the Print Directory

1. Navigate Per **People** in B1 Admin.
2. Fai clic the **print icon** (printer icon) in the toolbar at the top of the People results card. It appears Avanti Per the Esporta button.
3. The Print Directory opens in a new browser tab and begins loading your directory data.
4. After about 1.5 seconds, your browser's print dialog will appear automatically.

:::tip
The directory opens in a separate tab so you can print it without leaving the People page. After the print dialog appears, the tab navigates Indietro automatically.
:::

## What Gets Included

The print directory includes all **Attivo Membri** of your church. Specifically:

- People with an **Inattivo** or **Visitor** membership status are automatically excluded.
- People who have **opted out** of the directory are excluded.
- Everyone else is grouped by **household**.

## Directory Layout

The printed directory has two parts:

### Cover Pagina

The first page includes:
- Your church name
- The title "Membro Directory"
- The current Anno
- Your church's location
- A count of total households included

### Membro Listings

The remaining pages list households alphabetically by last name. Each household card shows:

- **Photos** -- Circular thumbnails for each household Membro, with their name below
- **Household display name** -- For example, "The Smith Family", "John & Jane Doe", or just the person's name for individuals
- **Address** -- Street address, city, state, and zip
- **Phone** -- Home or mobile number
- **Email** -- Primary email address
- **Birthdays** -- Formatted as individual dates for each household Membro
- **Anniversary** -- If recorded

Households are organized into **alphabetical sections** (A, B, C, ...) with a decorative section header before each letter Gruppo. Two household cards appear side by side on each row.

## Print Impostazioni

The directory is formatted for **letter-size paper** (8.5" × 11") with 0.5-inch margins. When the browser print dialog appears:

- Leave the paper size set Per **Letter**
- Enable **Background graphics** (sometimes called "Print backgrounds") in your browser's print Impostazioni if you want section headers Per print with their color styling
- Portrait orientation is recommended

:::info
The directory respects page breaks — household cards and section headers will not be split across pages.
:::
