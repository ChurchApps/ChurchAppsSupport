# Directory da Stampare

<div class="article-intro">

La funzione Print Directory genera una directory di membri formattata e stampabile per la tua chiesa. Organizza i membri per famiglia, include informazioni di contatto e foto, ed è progettata per apparire professionale quando stampata su carta di formato lettera standard.

</div>

<div class="prereqs">
<h4>Prima di Iniziare</h4>

- Hai bisogno di un account B1 Admin attivo con permesso di visualizzare le persone.
- Le persone nella tua directory dovrebbero avere foto e informazioni di contatto compilate per i migliori risultati.

</div>

## Apertura della Directory da Stampare

1. Vai a **People** in B1 Admin.
2. Fai clic sull'**icona di stampa** (icona della stampante) nella barra degli strumenti in alto della scheda dei risultati People. Appare accanto al pulsante Export.
3. La Print Directory si apre in una nuova scheda del browser e inizia a caricare i dati della tua directory.
4. Dopo circa 1,5 secondi, la finestra di dialogo di stampa del tuo browser apparirà automaticamente.

:::tip
La directory si apre in una scheda separata in modo che tu possa stamparla senza lasciare la pagina People. Dopo che la finestra di dialogo di stampa appare, la scheda torna indietro automaticamente.
:::

## Cosa Viene Incluso

La directory di stampa include tutti i **membri attivi** della tua chiesa. Nello specifico:

- Le persone con uno stato di adesione **Inactive** o **Visitor** sono automaticamente escluse.
- Le persone che hanno **optato per escludersi** dalla directory sono escluse.
- Tutti gli altri vengono raggruppati per **famiglia**.

## Layout della Directory

La directory stampata ha due parti:

### Pagina di Copertina

La prima pagina include:
- Il nome della tua chiesa
- Il titolo "Member Directory"
- L'anno corrente
- La posizione della tua chiesa
- Un conteggio del totale delle famiglie incluse

### Elenchi dei Membri

Le pagine rimanenti elencano le famiglie in ordine alfabetico per cognome. Ogni scheda di famiglia mostra:

- **Foto** -- Miniature circolari per ogni membro della famiglia, con il loro nome sotto
- **Nome di visualizzazione della famiglia** — Ad esempio, "The Smith Family", "John & Jane Doe" o solo il nome della persona per individui
- **Indirizzo** — Indirizzo stradale, città, stato e CAP
- **Telefono** — Numero di casa o cellulare
- **Email** — Indirizzo email principale
- **Compleanni** — Formattati come date individuali per ogni membro della famiglia
- **Anniversario** — Se registrato

Le famiglie sono organizzate in **sezioni alfabetiche** (A, B, C, ...) con un'intestazione di sezione decorativa prima di ogni gruppo di lettere. Due schede di famiglia appaiono fianco a fianco su ogni riga.

## Impostazioni di Stampa

La directory è formattata per **carta di formato lettera** (8,5" × 11") con margini di 0,5 pollici. Quando la finestra di dialogo di stampa del browser appare:

- Lascia il formato della carta impostato su **Letter**
- Abilita **Background graphics** (a volte chiamato "Print backgrounds") nelle impostazioni di stampa del tuo browser se desideri che le intestazioni di sezione si stampino con il loro stile di colore
- L'orientamento verticale è consigliato

:::info
La directory rispetta le interruzioni di pagina — le schede di famiglia e le intestazioni di sezione non verranno divise tra le pagine.
:::
