# Importazione dei Dati

<div class="article-intro">

Lo strumento B1 Transfer rende facile portare i tuoi dati esistenti in B1, che tu stia iniziando da zero da un foglio di calcolo, migrando da un'altra piattaforma di gestione della chiesa o importando record di donazione. Può anche essere utilizzato per esportare o eseguire il backup dei tuoi dati in qualsiasi momento.

</div>

<div class="prereqs">
<h4>Prima di Iniziare</h4>

- Hai bisogno di un account B1 Admin attivo con accesso a **Impostazioni**.
- Hai i tuoi dati esportati e pronti dal tuo sistema precedente prima di iniziare.
- Questo strumento è destinato alla migrazione iniziale dei dati. Se stai utilizzando B1 da un po', l'importazione di nuovo potrebbe creare record duplicati.

</div>

## Accesso allo Strumento di Trasferimento

1. Accedi a **B1 Admin**.
2. Apri il **menu della sezione** nell'angolo in alto a sinistra (il nome della sezione con la piccola freccia) e scegli **Impostazioni**.
3. Fai clic sul pulsante **Importazione/Esportazione** nell'angolo in alto a destra dell'intestazione della pagina.
4. Questo aprirà lo strumento **B1 Transfer** in una nuova scheda su [transfer.b1.church](https://transfer.b1.church).

Lo strumento di trasferimento ti guida attraverso quattro passaggi: Fonte, Anteprima, Destinazione e Esecuzione.

---

## Passaggio 1 - Scegli la Tua Fonte

Seleziona da dove provengono i tuoi dati. Ci sono sette opzioni:

- **Database B1** — Estrae i dati direttamente dalla tua chiesa B1 esistente.
- **Importazione Zip B1** — Un file zip nel suo stesso formato.
- **Importazione Zip Breeze** — Un file zip contenente file esportati da Breeze ChMS.
- **Zip Planning Center** — Un file zip o CSV esportato da Planning Center.
- **CSV/Excel Personalizzato** — Qualsiasi file CSV o Excel contenente dati di persone.
- **CSV Tithe.ly** — Un file di esportazione di persone o donazioni da Tithe.ly.
- **CSV CCB / Pushpay** — Un CSV di persone o donazioni da Church Community Builder o Pushpay.

Puoi trascinare e rilasciare il tuo file sull'area di caricamento, o fare clic per sfogliarla.

---

## Passaggio 2 - Anteprima dei Tuoi Dati

Dopo il caricamento, lo strumento visualizza un'anteprima di tutto quello che verrà importato. Usa le schede per rivedere ogni tipo di dati:

- **Persone** — Elencate per famiglia, con foto se incluse.
- **Gruppi** — Organizzati per campus, servizio, ora e categoria.
- **Presenza** — Date di sessione, gruppi e conteggi di visite.
- **Donazioni** — Lotti, fondi, donatori e importi.
- **Moduli** — Nomi di moduli e tipi di contenuto.

Rivedi attentamente prima di procedere. Se qualcosa sembra sbagliato, fai clic su **Ricomincia** e correggi il tuo file di origine.

---

## Passaggio 3 - Scegli la Tua Destinazione

Seleziona dove desideri che vadano i dati:

- **Database B1** — Importa direttamente nel database B1 della tua chiesa.
- **Esportazione Zip B1** — Scarica i tuoi dati come file zip in formato B1.
- **Esportazione Zip Breeze** — Converti i tuoi dati nel formato Breeze.
- **Zip Planning Center** — Converti i tuoi dati nel formato Planning Center.

:::warning
La fonte e la destinazione non possono essere lo stesso formato. Se corrispondono, lo strumento ti avviserà per evitare la duplicazione accidentale.
:::

---

## Passaggio 4 - Esecuzione

Lo strumento elabora il trasferimento e mostra il progresso per ogni passaggio. Non chiudere il browser mentre il trasferimento è in corso.

:::warning
Non chiudere il browser mentre il trasferimento è in corso. Aspetta fino a quando tutti i passaggi non mostrino il completamento.
:::

---

## Dopo l'Importazione

Una volta completato il trasferimento, prenditi qualche minuto per verificare i tuoi dati:

1. Sfoglia la pagina [Persone](../people/adding-people.md) e verifica alcuni profili.
2. Conferma che nomi, email, numeri di telefono e indirizzi siano stati trasferiti correttamente.
3. Controlla che le connessioni domestiche siano intatte.
4. Rivedi eventuali gruppi importati e record di donazione.
