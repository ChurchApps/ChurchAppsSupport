# Riepilogo donazioni

<div class="article-intro">

Il report Riepilogo donazioni ti dà un'immagine chiara dell'attività di donazione della tua chiesa. Usalo per tracciare i totali di donazione, monitorare le tendenze di donazione e preparare report finanziari per il tuo team di leadership.

</div>

<div class="prereqs">
<h4>Prima di iniziare</h4>

- Assicurati che le donazioni siano [registrate in modo coerente](../donations/recording-donations.md) nel tuo sistema
- Hai bisogno dei [permessi](../settings/roles-permissions.md) appropriati per accedere ai report finanziari

</div>

## Esecuzione del report

1. Vai direttamente a **admin.b1.church/reports/donationSummary** nel tuo browser (i report non hanno una voce nel menu di navigazione — aggiungere l'indirizzo ai segnalibri è il modo più semplice per tornare).
2. Imposta l'**intervallo di date** per definire il periodo di reporting.
3. Applica filtri aggiuntivi come **fondo** o altri criteri per restringere i risultati.
4. Il report visualizzerà il riepilogo delle donazioni per il periodo selezionato.

## Cosa mostra il report

Il report Riepilogo donazioni include:

- **Donazioni totali** -- L'importo totale di donazione per il periodo selezionato.
- **Conteggio donatori** -- Il numero di donatori unici che hanno contribuito.
- **Importi per fondo** -- Un dettaglio delle donazioni tra diversi fondi, se applicabile.

## Usi pratici

- **Pianificazione finanziaria** -- Esamina le tendenze di donazione per prevedere il reddito futuro e pianificare il tuo budget.
- **Report di consiglio** -- Genera riepiloghi per riunioni regolari di consiglio o leadership con dati di donazione chiari.
- **Revisioni di fine anno** -- Esegui il report per l'intero anno per preparare riepiloghi finanziari annuali.
- **Tracciamento della campagna** -- Filtra per fondo per tracciare il progresso di campagne di donazione speciali o progetti di costruzione.
- **Analisi stagionale** -- Confronta le donazioni tra diversi periodi per comprendere i modelli stagionali.

:::tip
Esegui questo report mensilmente per rimanere informato sulla salute finanziaria della tua chiesa. Confrontare i dati mese dopo mese ti aiuta a individuare le tendenze presto.
:::

:::warning
I dati di donazione provengono dai contributi registrati nel tuo sistema. Assicurati che le donazioni siano inserite in modo coerente -- sia tramite donazioni online, elaborazione di assegni o inserimento manuale -- per i report più accurati. Vedi [Registrazione delle donazioni](../donations/recording-donations.md) per i dettagli.
:::
