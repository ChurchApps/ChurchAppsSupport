# Pangkalahatang-tanaw ng B1 Church Checkin

<div class="article-intro">

Ang B1 Church Checkin ay isang self-service kiosk app para sa iPad at Android tablet. Pinapayagan nito ang mga miyembro ng simbahan na hanapin ang kanilang pamilya, italaga ang mga bata sa mga grupo o klase, at mag-print ng name label at parent pickup slip -- nang hindi kailangan ng volunteer sa desk.

</div>

## Paano Ito Gumagana

Maglagay ng iPad o Android tablet sa iyong lobby o welcome area. Lalapit ang mga miyembro, hahanapin ang kanilang household sa pamamagitan ng numero ng telepono o apelyido, susuriin ang kanilang pamilya, pipiliin kung aling grupo ang dapat puntahan ng bawat tao, at pipindutin ang **Check-in**. Awtomatikong nag-iimprenta ang app ng name label at pickup slip, pagkatapos ay nagre-reset para sa susunod na pamilya.

## Mga Pangunahing Tampok

- **Self-service na paghahanap ng miyembro** -- Maghanap sa pamamagitan ng numero ng telepono o apelyido para mabilis na mahanap ang iyong household.
- **Pagsusuri ng household** -- Makita ang lahat ng miyembro ng pamilya na may mga larawan at kasalukuyang pagtatalaga ng grupo sa isang sulyap.
- **Pagtatalaga ng grupo** -- Italaga ang bawat miyembro ng pamilya sa tamang klase o grupo para sa napiling service time.
- **Guest check-in** -- Magdagdag ng bisita sa iyong household sa mismong lugar gamit ang unang pangalan at apelyido.
- **QR guest registration** -- Magpakita ng QR code na maaaring i-scan ng mga bisita para [magparehistro ng kanilang sarili](../b1-church/checkin/guest-registration) sa sarili nilang telepono bago mag-check in, o hayaan silang pindutin ang **Register here** para punan ang parehong form sa kiosk.
- **Pag-iimprenta ng label** -- Mag-print ng name label para sa mga bata at parent pickup slip na may natatanging security code.
- **Suporta sa network printer** -- Tuklasin at i-configure ang mga network printer nang direkta mula sa app.
- **Auto-login** -- Pagkatapos ng unang pag-log in, naaalala ng app ang iyong mga kredensyal at dumidiretso sa services screen sa mga susunod na paglunsad.
- **Suporta sa maraming simbahan** -- Kung naka-link ang iyong account sa higit sa isang simbahan, maaari mong piliin kung aling simbahan ang papasukan.
- **Branding ng simbahan** -- Ipinapakita ng app ang logo ng iyong simbahan sa header kapag napili na ang simbahan.

Kunin ang app mula sa [Apple App Store](https://apps.apple.com/us/app/b1-church-check-in/id6775081998), [Google Play Store](https://play.google.com/store/apps/details?id=church.b1.checkin), o [Amazon App Store](https://www.amazon.com/Live-Church-Solutions-B1-Check-In/dp/B0FW5HKRB5/).
:::
