# Pagpili ng Serbisyo

<div class="article-intro">

Ang unang hakbang sa bawat check-in ay ang pagpili kung aling serbisyo ang dadaluhan mo. Lumalabas ang screen ng mga serbisyo kaagad pagkatapos ma-load ng app, at tinutukoy nito kung aling mga oras ng serbisyo at grupo ang available para sa natitirang bahagi ng check-in flow.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- [Mag-log in](../getting-started/logging-in) sa B1 Church Checkin app at piliin ang iyong simbahan
- Tiyaking na-[configure na ng iyong church administrator ang mga serbisyo at oras ng serbisyo](../../b1-admin/attendance/setup.md) sa B1 Admin

</div>

## Paano Ito Gumagana

1. Pagkatapos mag-log in (o pagkatapos ng auto-login sa mga susunod na pagbisita), ipinapakita ng app ang **screen ng mga serbisyo**.
2. Makikita mo ang listahan ng lahat ng serbisyong na-configure para sa iyong simbahan. Ang bawat serbisyo ay lumalabas bilang card na may pangalan ng serbisyo (halimbawa, "Sunday Morning" o "Wednesday Evening").
3. I-tap ang serbisyong dadaluhan mo.

Ni-load ng app ang mga oras ng serbisyo at grupong nauugnay sa serbisyong iyon, at dinadala ka nito sa [screen ng paghahanap ng miyembro](./looking-up-members).

## Kapag Hindi Bukas ang Check-In {#when-check-in-isnt-open}

Kung binigyan ng iyong administrator ng oras ng serbisyo ang isang [iskedyul ng check-in](../../b1-admin/attendance/setup#setting-a-check-in-schedule), ang app ay nag-aalok lamang ng oras ng serbisyong iyon habang bukas ang check-in window nito. Ang mga oras ng serbisyong sarado ang window sa kasalukuyan ay nakatago, para hindi ito mapili ng mga pamilya sa susunod na bahagi ng flow.

Kung sarado ang lahat ng oras ng serbisyo para sa serbisyong na-tap mo, ipinapakita ng app ang **"Hindi bukas ang check-in para sa serbisyong ito ngayon."** I-tap ang **Back** para bumalik sa listahan ng mga serbisyo at pumili ng ibang serbisyo, o maghintay hanggang bumukas ang window at subukan ulit.

:::info
Sumusunod ang mga check-in window sa time zone ng iyong simbahan. Kung walang naka-set na time zone ang iyong simbahan, ang time zone ng iyong campus ang gagamitin. Kung tila mali ang oras ng pagbukas ng isang oras ng serbisyo, hilingin sa iyong administrator na tingnan ang time zone sa mga setting ng simbahan o campus mo.
:::

:::info
Ang mga serbisyo ay kino-configure ng administrator ng iyong simbahan sa B1 Admin sa ilalim ng seksyong Attendance. Kung hindi mo makita ang serbisyong inaasahan mo, hilingin sa iyong admin na tiyaking nagawa na ito sa [attendance setup](../../b1-admin/attendance/setup.md).
:::

## Ano ang Nangyayari sa Likod ng Eksena

Kapag pumili ka ng serbisyo, kumukuha ang app ng tatlong bagay mula sa server:

- Ang **mga oras ng serbisyo** para sa serbisyong iyon (halimbawa, ang isang serbisyo ay maaaring may 9:00 AM at 11:00 AM na time slot).
- Ang **mga grupong available** sa bawat oras ng serbisyo (halimbawa, Nursery, Preschool, Elementary).
- Ang **mga link sa pagitan ng grupo at oras ng serbisyo** na nagtatakda kung aling mga grupo ang available sa aling mga oras.

Naka-cache nang lokal ang datos na ito para mabilis at responsive ang natitirang bahagi ng check-in process.

:::tip
Kung isa lamang ang serbisyong naka-configure sa iyong simbahan, kailangan mo pa rin itong i-tap para magpatuloy. Hindi awtomatikong pumipili ng iisang serbisyo ang app.
:::

## Susunod na Hakbang

Pagkatapos pumili ng serbisyo, [hahanapin mo ang iyong pamilya](./looking-up-members) gamit ang numero ng telepono o pangalan.
