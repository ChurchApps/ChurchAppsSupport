# Paghahanap ng mga Miyembro

<div class="article-intro">

Pagkatapos pumili ng service, mapupunta ka sa screen ng paghahanap ng miyembro. Dito mo hahanapin ang iyong pamilya para makapag-check in. Sinusuportahan ng app ang paghahanap gamit ang numero ng telepono o pangalan.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- [Pumili ng service](./selecting-service) mula sa screen ng mga service
- Siguraing naidagdag na ang inyong sambahayan [sa system](../../b1-admin/people/adding-people.md) ng isang administrator ng simbahan

</div>

## Mga Paraan ng Paghahanap

May dalawang paraan ng paghahanap ang lookup screen. Maaari kang lumipat sa pagitan nila sa pamamagitan ng pag-tap sa toggle sa itaas ng screen:

- **Phone** -- Maghanap gamit ang numero ng telepono. Ito ang default na paraan.
- **Name** -- Maghanap gamit ang pangalan.

## Paghahanap Gamit ang Numero ng Telepono

1. Tiyaking **Phone** ang aktibong paraan ng paghahanap (naka-highlight ito sa itaas).
2. I-tap ang search field at ilagay ang hindi bababa sa **4 na digit** ng iyong numero ng telepono gamit ang on-screen keypad.
3. I-tap ang button na **Search** o pindutin ang search key sa keyboard.

Hinahanap ng app ang mga miyembrong tugma ang numero ng telepono sa mga digit na inilagay mo. Kung mahigit 4 na digit ang inilagay mo, gagamitin nito ang buong numero. Kung eksaktong 4, itutugma nito sa huling 4 na digit ng mga numero ng telepono na nakatala.

## Paghahanap Gamit ang Pangalan

1. I-tap ang toggle na **Name** sa itaas ng screen para lumipat sa paghahanap gamit ang pangalan.
2. Maglagay ng hindi bababa sa **2 character** ng pangalan ng tao sa search field.
3. I-tap ang button na **Search**.

Hinahanap ng app ang mga miyembrong tugma ang pangalan sa itinype mo.

## Pagpili ng Tao

Lumalabas ang mga resulta ng paghahanap bilang mga card sa ibaba ng search field. Ipinapakita ng bawat card ang **pangalan** at **larawan** ng tao (kung mayroong nakatala).

I-tap ang card ng tao para piliin siya. Ilo-load ng app ang lahat ng miyembro ng sambahayan ng taong iyon at dadalhin ka sa [screen ng pagrepaso ng sambahayan](./household-review).

:::tip
Ang paghahanap gamit ang huling 4 na digit ng numero ng telepono ang pinakamabilis na paraan para mahanap ang inyong pamilya. Himukin ang mga miyembro na gamitin ang paraang ito para mas mabilis ang check-in.
:::

:::warning
Kung walang makitang resulta, magpapakita ang app ng mensahe para ipaalam ito. Suriing muli ang mga digit o pangalang inilagay mo, o subukan ang kabilang paraan ng paghahanap. Kung unang beses mong bumisita, humingi ng tulong sa isang volunteer para [maidagdag sa system](../../b1-admin/people/adding-people.md).
:::

## Pagrerehistro bilang Bisita

Kung naka-on ang QR guest registration ng inyong simbahan, lalabas ang link na **Register as guest** sa ibaba ng paghahanap sa lookup screen. Magagamit ito ng mga unang beses na bisita para maidagdag ang kanilang pamilya sa system ng simbahan bago mag-check in.

1. I-tap ang **Register as guest**. Magbubukas ang isang window na may QR code at mensaheng "Scan to register as a guest."
2. Piliin kung paano pupunan ang [form ng pagpaparehistro ng bisita](../../b1-church/checkin/guest-registration):
   - **Sa iyong telepono** -- I-scan ang QR code, punan ang form sa iyong telepono, at i-tap ang **OK** para isara ang window.
   - **Sa kiosk** -- I-tap ang **Register here** para buksan ang parehong form mismo sa tablet. Punan ito at i-tap ang **Register**, pagkatapos ay i-tap ang **Done** (o ang back arrow) para bumalik sa lookup screen.
3. Kapag nakarehistro na, hanapin ang inyong pamilya gamit ang pangalan o numero ng telepono para makapag-check in.

:::info
Nananatili sa pahina ng pagpaparehistro ng bisita ang form na binuksan gamit ang **Register here** -- hindi makakapunta ang mga bisita sa ibang bahagi ng website ng simbahan mula sa kiosk. Kung walang humipo o nag-type sa form sa loob ng 2 minuto, isasara ito ng kiosk at babalik sa lookup screen. Sa tuwing nagsasara ang form, buburahin ang anumang itinype rito para blangko ang form na makikita ng susunod na pamilya.
:::

## Pag-print ng mga Label para sa Check-In sa Telepono

Ang mga pamilyang nag-check in na sa kanilang telepono sa pamamagitan ng [self check-in ng B1 Church](../../b1-church/checkin/self-checkin) ay maaaring i-print ang kanilang mga name tag sa kiosk nang hindi na kailangang hanapin ang sarili.

1. Sa lookup screen, i-tap ang button na **Scan code** (ang icon ng QR code).
2. Itapat ang QR code mula sa iyong telepono sa camera. Kung humingi ang app ng access sa camera, i-tap ang **Allow Camera**. Ang front camera ang default na gamit; i-tap ang flip button para magpalit.
3. Hahanapin ng kiosk ang check-in at ipi-print ang mga label, pagkatapos ay babalik sa lookup screen.

Mga label lang ang ipi-print ng pag-scan -- naitala na ang attendance noong nag-check in ang pamilya sa kanilang telepono. Kung hindi tumutugma ang code sa aktibong check-in, magpapakita ang kiosk ng mensahe at babalik sa lookup screen.

## Susunod na Hakbang

Pagkatapos pumili ng tao, [irerepaso mo ang iyong sambahayan](./household-review) at aayusin ang mga group assignment.
