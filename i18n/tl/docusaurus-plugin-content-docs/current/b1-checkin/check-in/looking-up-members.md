# Paghahanap ng mga Miyembro

<div class="article-intro">

Pagkatapos mong pumili ng serbisyo, dadalhin ka sa screen ng paghahanap ng miyembro. Dito mo hahanapin ang iyong pamilya para makapag-check in. Sinusuportahan ng app ang paghahanap gamit ang numero ng telepono o pangalan.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- [Pumili ng serbisyo](./selecting-service.md) mula sa screen ng mga serbisyo
- Siguraduhing naidagdag na ng isang church administrator ang iyong sambahayan [sa sistema](../../b1-admin/people/adding-people.md)

</div>

## Mga Mode ng Paghahanap {#search-modes}

May dalawang mode ng paghahanap ang screen ng paghahanap. Maaari kang lumipat sa pagitan ng mga ito sa pamamagitan ng pag-tap sa toggle sa itaas ng screen:

- **Phone** -- Maghanap gamit ang numero ng telepono. Ito ang default na mode.
- **Name** -- Maghanap gamit ang pangalan.

## Paghahanap gamit ang Numero ng Telepono {#searching-by-phone-number}

1. Siguraduhing aktibo ang **Phone** na mode (naka-highlight ito sa itaas).
2. I-tap ang search field at ilagay ang hindi bababa sa **4 na digit** ng numero ng iyong telepono gamit ang on-screen na keypad.
3. I-tap ang button na **Search** o pindutin ang search key sa keyboard.

Hahanapin ng app ang mga miyembrong tumutugma sa mga digit na inilagay mo. Kung maglalagay ka ng higit sa 4 na digit, gagamitin ng app ang buong numero. Kung eksaktong 4 ang ilalagay mo, itutugma ito sa huling 4 na digit ng mga numero ng telepono sa talaan.

## Paghahanap gamit ang Pangalan {#searching-by-name}

1. I-tap ang toggle na **Name** sa itaas ng screen para lumipat sa mode ng paghahanap gamit ang pangalan.
2. Ilagay ang hindi bababa sa **2 karakter** ng pangalan ng tao sa search field.
3. I-tap ang button na **Search**.

Hahanapin ng app ang mga miyembrong tumutugma sa iyong na-type.

## Pagpili ng Tao {#selecting-a-person}

Lumilitaw ang mga resulta ng paghahanap bilang mga card sa ilalim ng search field. Ipinapakita ng bawat card ang **pangalan** at **larawan** ng tao (kung may nakatalang larawan).

I-tap ang card ng isang tao para piliin siya. Ilo-load ng app ang lahat ng miyembro ng sambahayan ng taong iyon at dadalhin ka sa [screen ng pagrepaso ng sambahayan](./household-review.md).

:::tip
Ang paghahanap gamit ang huling 4 na digit ng numero ng telepono ang pinakamabilis na paraan para mahanap ang iyong pamilya. Hikayatin ang mga miyembro na gamitin ang paraang ito para mas mabilis ang check-in.
:::

:::warning
Kung walang makitang resulta, magpapakita ang app ng mensaheng nagsasabi nito. Suriing mabuti ang mga digit o pangalang inilagay mo, o subukan ang kabilang mode ng paghahanap. Kung unang beses kang bumibisita, humingi ng tulong sa isang volunteer para maidagdag ka [sa sistema](../../b1-admin/people/adding-people.md).
:::

## Pagpaparehistro bilang Guest {#registering-as-a-guest}

Kung naka-on sa simbahan mo ang QR guest registration, may lalabas na link na **Register as guest** sa ilalim ng search sa lookup screen. Maaaring gamitin ito ng mga unang beses na bisita para idagdag ang kanilang pamilya sa sistema ng simbahan bago mag-check in.

1. I-tap ang **Register as guest**. Magbubukas ang isang window na may QR code at mensaheng "Scan to register as a guest."
2. Piliin kung paano punan ang [guest registration form](../../b1-church/checkin/guest-registration.md):
   - **Sa iyong telepono** -- I-scan ang QR code, punan ang form sa iyong telepono, at i-tap ang **OK** para isara ang window.
   - **Sa kiosk** -- I-tap ang **Register here** para buksan ang parehong form mismo sa tablet. Punan ito at i-tap ang **Register**, pagkatapos i-tap ang **Done** (o ang back arrow) para bumalik sa lookup screen.
3. Kapag nakarehistro na, hanapin ang iyong pamilya gamit ang pangalan o numero ng telepono para mag-check in.

:::info
Ang form na binuksan gamit ang **Register here** ay mananatili sa guest registration page -- hindi makakapag-browse ang mga bisita sa ibang bahagi ng website ng simbahan mula sa kiosk. Kung walang humahawak o nagta-type sa form sa loob ng 2 minuto, isasara ito ng kiosk at ibabalik sa lookup screen. Sa bawat pagsasara ng form, nabubura ang anumang na-type dito para ang susunod na pamilya ay magsisimula sa blankong form.
:::

## Pag-print ng Label para sa Check-In sa Telepono {#printing-labels-for-a-phone-check-in}

Ang mga pamilyang nakapag-check in na sa telepono nila sa pamamagitan ng [B1 Church self check-in](../../b1-church/checkin/self-checkin.md) ay maaaring mag-print ng kanilang name tag sa kiosk nang hindi hinahanap ang sarili nila.

1. Sa lookup screen, i-tap ang button na **Scan code** (ang icon ng QR code).
2. Itapat ang QR code mula sa telepono mo sa camera. Kung humingi ang app ng access sa camera, i-tap ang **Allow Camera**. Ang front camera ang ginagamit bilang default; i-tap ang flip button para lumipat.
3. Hahanapin ng kiosk ang check-in at ipi-print ang mga label, pagkatapos ibabalik ka sa lookup screen.

Nagpi-print lamang ng label ang pag-scan -- naitala na ang attendance noong nag-check in ang pamilya sa telepono nila. Kung hindi tumutugma ang code sa aktibong check-in, magpapakita ang kiosk ng mensahe at ibabalik ka sa lookup screen.
