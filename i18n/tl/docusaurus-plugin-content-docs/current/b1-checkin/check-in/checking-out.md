# Check-Out & Child Safety

<div class="article-intro">

Ang check-out screen ay ang kiosk interface kung saan ang mga pamilya ay kumukuha ng kanilang mga bata, at kung saan ang mga staff ay nagsisiguro na ang tamang tao ang sumasagot sa kanilang bata. Ang screen na ito ay sumusuporta sa trusted pickup verification, page-a-parent messaging, at emergency broadcast.

</div>

<div class="prereqs">
<h4>Babo Magsimula</h4>

- I-setup ang [Trusted Pickup People](../attendance/checkin-safety.md#trusted-and-not-authorized-pickup-people) sa bawat household
- I-configure ang texting provider para sa page-a-parent at emergency broadcast

</div>

Tingnan ang buong dokumentasyon sa B1 Admin.
