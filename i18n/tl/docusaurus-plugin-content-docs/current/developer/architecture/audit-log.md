# Audit Log

Ang **Audit Log** ay nag-track ng lahat ng mga pagbabago sa B1 data - kung sino ang nagbago, kung ano ang nagbago, at kailan ito nangyari. Ito ay mahalaga para sa compliance at pag-track ng mga aksyon sa sistema.
