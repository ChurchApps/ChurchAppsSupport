# Bring Your Own Storage (BYOS)

Ang **BYOS** ay nagbibigay-daan sa mga simbahan na mag-imbak ng kanilang mga file at larawan sa kanilang sariling Amazon S3 account sa halip na sa mga server ng ChurchApps.
