# Webhooks

Ang **Webhooks** ay nagbibigay-daan sa iyo na makatanggap ng real-time na mga kaganapan mula sa B1 API at mag-trigger ng mga aksyon sa ibang mga sistema. Ang mga kaganapan ay kasama ang paglikha ng tao, pagbabago ng grupo, at iba pang mga aksyon sa loob ng B1.

Tingnan ang buong developer documentation para sa mga detalye tungkol sa webhook format at event types.
