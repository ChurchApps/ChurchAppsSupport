# Curated Calendar

<div class="article-intro">

Pinagsasama-sama ng curated calendar ang mga event mula sa maraming grupo sa iisang pinag-isang view ng calendar. Mainam ito para sa paggawa ng calendar ng buong simbahan na nagpapakita ng lahat ng nangyayari sa lahat ng iyong ministry at grupo sa iisang lugar.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- I-set up ang [mga grupo](../groups/creating-groups.md) na ang mga event ay gusto mong isama
- Siguraduhing nagdagdag na ng mga event ang mga group leader sa kani-kanilang grupo
- Pamilyarin ang sarili sa mga batayan ng [Creating Calendars](./creating-calendars.md)

</div>

## Paggawa ng Curated Calendar {#creating-a-curated-calendar}

1. Sa B1 Admin, buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas), i-expand ang **Calendars**, at i-click ang **Calendars**.
2. I-click ang **Add Calendar** para gumawa ng bagong curated calendar.
3. Bigyan ng **Calendar Name** ang iyong calendar (halimbawa, "Church Events" o "This Week at Our Church").
4. I-click ang **Create** para i-save ito.

## Pagdaragdag ng Mga Grupo sa Iyong Calendar {#adding-groups-to-your-calendar}

1. I-click ang pangalan ng bago mong calendar (o ang **Manage Events** sa row nito) para buksan ito.
2. I-click ang **Add Group** sa itaas ng calendar. Lumalabas sa listahan ng **Groups in Calendar** sa kaliwang bahagi ng pahina ang mga grupong idinagdag mo.
3. Pumili ng grupo sa **Select a Group**. Nakalista ang bawat grupo sa iyong simbahan, kasama ang mga grupong hindi ka miyembro.
4. Piliin ang **Add all the events of the group**, o ang **Add specific events** at i-click ang mga event na gusto mo.
5. I-click ang **Save**.
6. Ulitin ang prosesong ito para magdagdag ng kasing dami ng grupong gusto mong isama.

Nakalista nang isang beses ang bawat event, kahit idinagdag mo ito nang mag-isa at idinagdag mo rin ang buong grupo nito. Ang listahan ng **Groups in Calendar** ay nagpapakita lamang ng mga grupong naidagdag kasama ang lahat ng kanilang event.

Para alisin ang isang bagay sa calendar, i-click ang event at piliin ang **Remove from Calendar**. Mananatili ang event sa grupo nito. Kung nagmula ang event sa buong grupo, ang pag-alis nito ay mag-aalis ng lahat ng event ng grupong iyon sa calendar na ito.

:::tip
Idagdag ang lahat ng iyong aktibong ministry group para makagawa ng komprehensibong calendar na nagbibigay sa kongregasyon ng kumpletong larawan ng nangyayari sa iyong simbahan bawat linggo.
:::

## Pagbabahagi ng Iyong Calendar {#sharing-your-calendar}

Kapag na-set up na ang iyong curated calendar, maaari mo itong ibahagi sa ilang paraan:

- **Ilagay sa iyong website** -- Magdagdag ng **Calendar** element sa isang page para ipakita ang calendar bilang month grid o bilang mga tile ng paparating na event, opsyonal na limitado sa mga event na may isang tag. Bawat event ay nagli-link sa sarili nitong page sa iyong site. Tingnan ang [Using the Calendar element](../website/page-editor.md#using-the-calendar-element).
- **Mag-subscribe sa pamamagitan ng ICS** -- I-click ang **Subscribe** sa itaas ng calendar at piliin ang **Copy ICS Link**. Maaaring i-paste ng kongregasyon ang link na ito sa Google Calendar, Apple Calendar, Outlook, o anumang ibang calendar app para manatiling naka-sync.
- **I-download ang ICS file** -- I-click ang **Subscribe** at piliin ang **Download ICS File** para i-import ang calendar sa isang calendar application.
- **Print** -- I-click ang **Print** sa page ng calendar para sa printable na view.

:::info
Kapag nagdagdag ng bagong event ang mga group leader sa kanilang [mga grupo](../groups/creating-groups.md), awtomatikong lumilitaw ang mga event na iyon sa iyong curated calendar. Hindi mo kailangang manu-manong i-update ang curated calendar sa tuwing may idinadagdag na bagong event.
:::

:::note Mga pribadong event
Tanging ang **public** na event lamang ang lumilitaw sa curated calendar sa iyong website at sa ICS subscription nito. Sa B1 Admin, nakikita rin ng staff na maaaring mag-edit ng content ang mga **private** na event ng grupo sa curated calendar, para masuri mo ang buong iskedyul habang binubuo mo ang calendar.
:::
