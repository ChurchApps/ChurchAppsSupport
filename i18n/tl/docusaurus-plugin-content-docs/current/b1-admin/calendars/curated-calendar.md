# Curated Calendar

<div class="article-intro">

Pinagsasama ng curated calendar ang mga event mula sa maraming grupo sa iisang pinag-isang calendar view. Mainam ito para sa calendar ng buong simbahan na nagpapakita ng lahat ng nangyayari sa lahat ng iyong ministeryo at grupo sa iisang lugar.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- I-set up ang mga [grupo](../groups/creating-groups.md) na gusto mong isama ang mga event
- Tiyaking nakapagdagdag na ang mga group leader ng mga event sa kani-kanilang grupo
- Pamilyarin ang sarili mo sa mga batayan ng [Creating Calendars](creating-calendars)

</div>

## Paggawa ng Curated Calendar

1. Sa B1 Admin, buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa itaas-kaliwa), i-expand ang **Calendars**, at i-click ang **Calendars**.
2. I-click ang **Add Calendar** para gumawa ng bagong curated calendar.
3. Bigyan ng **name** ang iyong calendar (halimbawa, "Church Events" o "This Week at Our Church").
4. I-click ang **Create** para i-save ito.

## Pagdagdag ng mga Grupo sa Iyong Calendar

1. I-click ang **Manage Events** sa bago mong calendar para buksan ito.
2. I-click ang **Add Group** sa itaas ng calendar. Lalabas sa listahang **Groups in Calendar** sa kaliwang bahagi ng pahina ang mga grupong idinagdag mo.
3. Pumili ng grupo mula sa dropdown menu. Nakalista ang bawat grupo sa iyong simbahan, kasama ang mga grupong hindi ka miyembro.
4. Piliin kung idadagdag ang **lahat ng event** mula sa grupong iyon o **mga partikular na event** lamang.
5. I-click ang **Save**.
6. Ulitin ang prosesong ito para idagdag ang kasing dami ng grupong gusto mong isama.

Nakalista ang bawat event nang isang beses, kahit idinagdag mo ito nang mag-isa at idinagdag mo rin ang buong grupo nito. Ipinapakita lang ng listahang **Groups in Calendar** ang mga grupong idinagdag kasama ang lahat ng kanilang event.

Para alisin ang isang bagay sa calendar, i-click ang event at piliin ang **Remove from Calendar**. Nananatili ang event sa sarili nitong grupo. Kung nagmula ang event sa buong grupo, ang pag-alis nito ay mag-aalis ng lahat ng event ng grupong iyon sa calendar na ito.

:::tip
Idagdag ang lahat ng iyong aktibong ministry group para makagawa ng komprehensibong calendar na nagbibigay sa kongregasyon ng kumpletong larawan ng nangyayari sa iyong simbahan bawat linggo.
:::

## Pagbabahagi ng Iyong Calendar

Kapag na-set up na ang iyong curated calendar, maaari mo itong ibahagi sa ilang paraan:

- **I-embed sa iyong website** -- Magdagdag ng **Calendar** element sa isang pahina para ipakita ang calendar bilang buwanang grid o bilang mga tile ng paparating na event, opsyonal na limitado sa mga event na may isang tag. Nagli-link ang bawat event sa sarili nitong pahina sa iyong site. Tingnan ang [Using the Calendar element](../website/page-editor.md#using-the-calendar-element).
- **Mag-subscribe sa pamamagitan ng ICS** -- I-click ang **Subscribe** para kopyahin ang ICS link. Maaaring i-paste ng iyong kongregasyon ang link na ito sa Google Calendar, Apple Calendar, Outlook, o anumang ibang calendar app para manatiling naka-sync.
- **I-download ang ICS file** -- I-download ang calendar file para i-import ito sa calendar application.

:::info
Kapag nagdagdag ang mga group leader ng bagong event sa kanilang [mga grupo](../groups/creating-groups.md), awtomatikong lalabas ang mga event na iyon sa iyong curated calendar. Hindi mo kailangang manu-manong i-update ang curated calendar sa tuwing may bagong event na idinadagdag.
:::

:::note Private events
Tanging **public** na event lang ang lumalabas sa curated calendar sa iyong website at sa ICS subscription nito. Sa B1 Admin, nakikita rin ng mga staff na may permiso na mag-edit ng content ang mga **private** na event ng grupo sa curated calendar, para masuri mo ang buong iskedyul habang binubuo mo ang calendar.
:::
