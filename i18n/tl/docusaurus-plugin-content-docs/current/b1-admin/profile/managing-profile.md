# Pamamahala ng Iyong Profile

<div class="article-intro">

Hinahayaan ka ng pahina ng Profile na i-edit ang iyong personal na account settings. Ibinabahagi ang iyong profile sa lahat ng ChurchApps product, kaya anumang pagbabagong gagawin mo rito ay makikita kahit saan mo ginagamit ang ChurchApps.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Dapat naka-log in ka sa iyong ChurchApps account
- Ihanda ang iyong bagong email address o password kung plano mong palitan ang mga ito

</div>

## Impormasyon ng Profile

Ipinapakita ng pahina ng Profile ang iyong pangalan at email address sa kaliwa, na may **Edit** button sa ilalim ng mga ito. I-click ang **Edit** upang buksan ang **Edit Account** form, na naglalaman ng iyong pangunahing detalye ng account:

1. **Email** -- Ang iyong email address na ginagamit sa pag-log in at pagtanggap ng mga notification.
2. **First Name** at **Last Name** -- Ang pangalang ipinapakita sa iyo sa buong ChurchApps.
3. **Password** -- I-update ang password ng iyong account.

Upang i-update ang iyong impormasyon, i-edit ang mga field at i-click ang **Save Changes** button. I-click ang **Cancel** (o ang link na **Back to** kasama ang iyong pangalan) upang bumalik sa iyong profile nang hindi nagse-save.

## Pagpapalit ng Password

1. Sa pahina ng Profile, i-click ang **Edit**.
2. Ilagay ang iyong **Current password**.
3. Ilagay ang bagong password sa **New password** field.
4. Ulitin ito sa **Verify password** field.
5. I-click ang **Save Changes**.

:::info
Dapat hindi bababa sa 8 karakter ang iyong password. Siguraduhing eksaktong magkapareho ang password at ang confirmation field. Kailangan mong kumpirmahin ang kasalukuyan mong password upang mapalitan ito -- kung hindi mo ito maalala, gamitin ang link na **Forgot Password** sa login page.
:::

## Mga Naka-link na Account

Ipinapakita ng seksyong **Linked Accounts** ang mga external na serbisyong nakakonekta sa iyong ChurchApps account. Maaari mong tingnan kung aling mga account ang naka-link at pamahalaan ang mga koneksyong ito mula sa seksyong ito.

## Mga Kagustuhan sa Theme

Hinahayaan ka ng B1 Admin na pumili ng color theme at ng light o dark display mode:

1. I-click ang iyong profile picture sa kanang itaas ng B1 Admin upang buksan ang iyong user menu.
2. Sa ilalim ng **Theme Preferences**, pumili ng theme:
   - **Default** -- Ang kasalukuyang itsura ng B1 Admin: mga panel na may border sa malinis na canvas.
   - **Classic** -- Ang dating itsura ng B1 Admin, na may kulay na page banner, mga card na may anino, at kulay-abuhing background. Ito ang makikita mo hanggang pumili ka ng theme.
   - **Custom** -- Ang Default na itsura na binuo mula sa kulay ng iyong simbahan. Ginagamit nito ang light-mode primary color mula sa **Mobile > App Theme**, o ang primary color ng iyong website kung walang kulay ng app na nakatakda, kaya tumutugma ang B1 Admin sa member app mo.
3. Sa ibaba ng mga theme, piliin ang **Light Mode** o **Dark Mode**.
4. Agad na maa-update ang interface upang ipakita ang iyong pinili.

Naaalala ang iyong mga pinili sa device at browser na iyon.

## Pagbura ng Account

Sa seksyong **Account Deletion** ng pahina ng Profile, makikita mo ang opsyong burahin ang iyong account.

- Kung **hindi** nag-configure ang iyong simbahan ng Directory Approval Group, ang pag-click sa **Delete my account** ay agad na mag-aalis ng iyong account at kaugnay na datos, at hindi ito na maibabalik.
- Kung **may** naka-configure na Directory Approval Group ang iyong simbahan, ipapadala ang iyong kahilingan sa grupong iyon para sa review. Mada-disable ang button habang may nakabinbing kahilingan, at aabisuhan ka kapag inaprubahan o tinanggihan ito ng iyong simbahan. Tingnan ang [Reviewing Account Deletion Requests](./account-deletion.md) para sa susunod na mangyayari.

:::warning
Ang pagbura ng account -- kaagad man o naaprubahan ng iyong simbahan -- ay permanente at hindi na maibabalik.
:::

:::info
Kung ikaw ay **Domain Admin**, siguraduhing ilipat ang mga administratibong responsibilidad sa ibang user bago burahin ang iyong account. Tingnan ang [Roles & Permissions](../settings/roles-permissions.md) para sa mga detalye tungkol sa pamamahala ng admin role.
:::

:::info
Naka-disable ang pag-edit ng profile sa demo mode. Kung gumagamit ka ng demo account, hindi ka makakagawa ng mga pagbabago sa iyong profile settings.
:::
