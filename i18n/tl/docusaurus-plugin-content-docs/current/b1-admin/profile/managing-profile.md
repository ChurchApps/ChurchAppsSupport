# Pamamahala ng Iyong Profile

<div class="article-intro">

Hinahayaan ka ng pahinang Profile na i-edit ang iyong personal na account settings. Ibinabahagi ang iyong profile sa lahat ng produkto ng ChurchApps, kaya ang anumang pagbabagong gagawin mo rito ay makikita sa lahat ng lugar na ginagamit mo ang ChurchApps.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Dapat naka-log in ka sa iyong ChurchApps account
- Ihanda ang iyong bagong email address o password kung plano mong palitan ang mga ito

</div>

## Impormasyon ng Profile

Ipinapakita ng pahinang Profile ang iyong pangalan at email address sa kaliwa, na may button na **Edit** sa ilalim ng mga ito. I-click ang **Edit** para buksan ang form na **Edit Account**, na naglalaman ng iyong pangunahing detalye ng account:

1. **Email** -- Ang iyong email address na ginagamit sa pag-log in at pagtanggap ng mga notification.
2. **First Name** at **Last Name** -- Ang iyong display name sa buong ChurchApps.
3. **Password** -- I-update ang password ng iyong account.

Para i-update ang iyong impormasyon, baguhin ang mga field at i-click ang button na **Save Changes**. I-click ang **Cancel** (o ang link na **Back to** kasama ang iyong pangalan) para bumalik sa iyong profile nang hindi nagse-save.

## Pagpapalit ng Iyong Password

1. Sa pahinang Profile, i-click ang **Edit**.
2. Ilagay ang iyong **Current password**.
3. Ilagay ang iyong bagong password sa field na **New password**.
4. Ulitin ito sa field na **Verify password**.
5. I-click ang **Save Changes**.

:::info
Dapat hindi bababa sa 8 karakter ang iyong password. Siguraduhing eksaktong magkatugma ang password at ang mga field ng kumpirmasyon. Kailangan mong kumpirmahin ang iyong kasalukuyang password para mapalitan ito — kung hindi mo ito alam, gamitin ang link na **Forgot Password** sa pahina ng pag-log in.
:::

## Mga Naka-link na Account

Ipinapakita ng seksyong **Linked Accounts** ang anumang panlabas na serbisyong nakakonekta sa iyong ChurchApps account. Makikita mo rito kung aling mga account ang naka-link at mapamamahalaan mo ang mga koneksyong iyon mula sa seksyong ito.

## Mga Kagustuhan sa Tema

Hinahayaan ka ng B1 Admin na pumili ng kulay na tema at light o dark na display mode:

1. I-click ang iyong profile picture sa kanang itaas na sulok ng B1 Admin para buksan ang iyong user menu.
2. Sa ilalim ng **Theme Preferences**, pumili ng tema:
   - **Default** -- Ang kasalukuyang itsura ng B1 Admin: mga panel na may hangganan sa malinis na canvas. Ito ang nakikita ng mga bagong user hanggang pumili sila ng ibang tema.
   - **Classic** -- Ang naunang itsura ng B1 Admin, na may kulay na banner ng pahina, mga card na may anino, at kulay-abong background. Kung ginamit mo ang B1 Admin sa device na ito bago dumating ang bagong itsura at hindi ka kailanman pumili ng tema, mananatili ka sa Classic.
   - **Custom** -- Ang itsura ng Default na binuo mula sa sariling kulay ng iyong simbahan. Ginagamit nito ang primary color ng light mode mula sa **Mobile > App Theme**, o ang primary color ng iyong website kung walang kulay ng app na nakatakda, para tumugma ang B1 Admin sa iyong member app.
3. Sa ibaba ng mga tema, pumili ng **Light Mode** o **Dark Mode**.
4. Agad na ina-update ng interface ang sarili nito ayon sa iyong pinili.

Naaalala ang iyong mga pinili sa device at browser na iyon.

## Pagbura ng Account

Sa seksyong **Account Deletion** ng pahinang Profile, makikita mo ang opsyong burahin ang iyong account.

- Kung **hindi** nag-configure ang iyong simbahan ng Directory Approval Group, ang pag-click sa **Delete my account** ay agad na magbubura ng iyong account at kaugnay na datos, at hindi na ito mababawi.
- Kung **may** naka-configure na Directory Approval Group ang iyong simbahan, ipapadala ang iyong kahilingan sa grupong iyon para sa pagrepaso. Naka-disable ang button habang nakabinbin ang kahilingan, at aabisuhan ka kapag inaprubahan o tinanggihan ito ng iyong simbahan. Tingnan ang [Reviewing Account Deletion Requests](./account-deletion.md) para sa susunod na mangyayari.

:::warning
Permanente ang pagbura ng account — maging agaran man ito o inaprubahan ng iyong simbahan — at hindi na ito mababawi.
:::

:::info
Kung ikaw ay isang **Domain Admin**, siguraduhing ilipat ang mga responsibilidad sa pangangasiwa sa ibang user bago burahin ang iyong account. Tingnan ang [Roles & Permissions](../settings/roles-permissions.md) para sa mga detalye sa pamamahala ng mga tungkulin ng admin.
:::

:::info
Naka-disable ang pag-e-edit ng profile sa demo mode. Kung gumagamit ka ng demo account, hindi ka makakagawa ng anumang pagbabago sa mga setting ng iyong profile.
:::
