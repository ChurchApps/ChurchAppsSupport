# Pamamahala ng Iyong Profile

<div class="article-intro">

Hinahayaan ka ng pahinang Profile na i-edit ang mga setting ng iyong personal na account. Ibinabahagi ang iyong profile sa lahat ng produkto ng ChurchApps, kaya makikita sa lahat ng lugar kung saan mo ginagamit ang ChurchApps ang anumang pagbabagong gagawin mo rito.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Dapat naka-log in ka sa iyong ChurchApps account
- Ihanda ang iyong bagong email address o password kung plano mo itong i-update

</div>

## Impormasyon ng Profile

Ipinapakita ng pahinang Profile ang iyong pangalan at email address sa kaliwa, na may butones na **Edit** sa ilalim nila. I-click ang **Edit** para buksan ang form na **Edit Account**, na naglalaman ng pangunahing detalye ng iyong account:

1. **Email** -- Ang iyong email address na ginagamit sa pag-log in at pagtanggap ng mga notification.
2. **First Name** at **Last Name** -- Ang iyong display name sa buong ChurchApps.
3. **Password** -- I-update ang password ng iyong account.

Para i-update ang iyong impormasyon, i-edit ang mga field at i-click ang butones na **Save Changes**. I-click ang **Cancel** (o ang link na **Back to** kasama ang iyong pangalan) para bumalik sa iyong profile nang hindi nagse-save.

## Pagpapalit ng Iyong Password

1. Sa pahinang Profile, i-click ang **Edit**.
2. Ilagay ang iyong **Current password**.
3. Ilagay ang bago mong password sa field na **New password**.
4. Ulitin ito sa field na **Verify password**.
5. I-click ang **Save Changes**.

:::info
Dapat hindi bababa sa 8 character ang iyong password. Siguraduhing eksaktong magkatugma ang password at ang kumpirmasyon. Kailangan mong kumpirmahin ang kasalukuyan mong password para mapalitan ito -- kung hindi mo ito alam, gamitin ang link na **Forgot Password** sa login page sa halip.
:::

## Mga Naka-link na Account

Ipinapakita ng seksyong **Linked Accounts** ang anumang external na serbisyong nakakonekta sa iyong ChurchApps account. Makikita mo rito kung aling mga account ang naka-link at maaari mong pamahalaan ang mga koneksyong iyon.

## Two-Factor Sign-In {#two-factor-sign-in}

Nagdaragdag ang two-factor sign-in ng ikalawang hakbang sa pag-log in: pagkatapos ng iyong password (o sign-in gamit ang Google, Microsoft, o email link), maglalagay ka rin ng 6-digit na code mula sa authenticator app sa iyong telepono, gaya ng Google Authenticator, Microsoft Authenticator, 1Password, o Authy. Opsyonal ito at naka-off bilang default. Kapag naka-on na, nalalapat ito sa bawat ChurchApps login na gumagamit ng iyong account -- B1 Admin, ang B1.church site at app ng iyong simbahan, B1 Church Checkin, Lessons.church, FreePlay, at iba pa.

### Pag-on Nito

1. Sa pahinang Profile, hanapin ang seksyong **Two-Factor Sign-In** at i-click ang **Turn on**.
2. I-scan ang QR code gamit ang iyong authenticator app. Kung hindi mo ito ma-scan, i-type na lang sa app ang key na nakalagay sa ilalim ng **Can't scan? Enter this key:**.
3. Ilagay ang **6-digit code** na ipinapakita ng iyong app at i-click ang **Verify**.
4. Magpapakita ang B1 Admin ng sampung **backup code**. Ang bawat isa ay magpapapasok sa iyo nang isang beses kung mawala ang iyong telepono. I-click ang **Copy** o isulat ang mga ito, itago sa ligtas na lugar, at i-click ang **I saved them**.

:::warning
Isang beses lang ipinapakita ang mga backup code. Kung mawala ang iyong telepono at wala nang natitirang backup code, kailangang i-off ng isang server administrator ng ChurchApps ang two-factor sign-in para sa iyo pagkatapos kumpirmahin kung sino ka.
:::

Kapag naka-on ang two-factor sign-in, ang seksyon ay magpapakitang **On** at ipapakita kung ilang backup code pa ang natitira mo.

### Pag-sign In Gamit ang Code

Pagkatapos mong ilagay ang iyong password, hihingi ng code ang login screen. Ilagay ang 6-digit na code mula sa iyong authenticator app, o isa sa iyong mga backup code, at i-submit. Gumagana lang nang isang beses ang bawat backup code. Kung mali ang code, makikita mo ang "That code didn't work. Please try again." Pagkatapos ng sobrang dami ng maling code, pansamantalang ihihinto ang mga login para sa iyong account.

Ang pananatiling naka-sign in sa device na dati mo nang ginamit para mag-log in ay hindi na muling hihingi ng code; lalabas lang ito kapag bagong mag-log in.

### Pag-off Nito

1. Sa seksyong **Two-Factor Sign-In**, i-click ang **Turn off**.
2. Ilagay ang kasalukuyang code mula sa iyong authenticator app, o isang backup code.
3. I-click ang **Verify**.

:::info
Hindi maaaring i-set up ang two-factor sign-in sa mga demo account, kaya nakatago ang seksyon doon.
:::

## Mga Theme Preference

Hinahayaan ka ng B1 Admin na pumili ng color theme at light o dark na display mode:

1. I-click ang iyong larawan sa profile sa kanang itaas ng B1 Admin para buksan ang iyong user menu.
2. Sa ilalim ng **Theme Preferences**, pumili ng theme:
   - **Default** -- Ang kasalukuyang itsura ng B1 Admin: mga panel na may hangganan sa malinis na canvas. Ito ang nakikita ng mga bagong user hanggang pumili sila ng iba.
   - **Classic** -- Ang naunang itsura ng B1 Admin, na may kulay na banner sa pahina, mga card na may anino, at kulay-abong background. Kung ginamit mo ang B1 Admin sa device na ito bago dumating ang bagong itsura at hindi ka kailanman pumili ng theme, mananatili ka sa Classic.
   - **Custom** -- Ang itsura ng Default na binuo mula sa sariling kulay ng iyong simbahan. Ginagamit nito ang primary color sa light mode mula sa **Mobile > App Theme**, o ang primary color ng iyong website kung walang kulay ng app na nakatakda, para tumugma ang B1 Admin sa member app mo.
3. Sa ibaba ng mga theme, pumili ng **Light Mode** o **Dark Mode**.
4. Agad mag-a-update ang interface para ipakita ang iyong pinili.

Naaalala ang iyong mga pinili sa device at browser na iyon.

## Pagbura ng Account

Sa seksyong **Account Deletion** ng pahinang Profile, makikita mo ang opsyon na burahin ang iyong account.

- Kung **hindi** naka-configure ang Directory Approval Group ng iyong simbahan, ang pag-click sa **Delete my account** ay agad magbubura ng iyong account at kaugnay na datos, at hindi na ito mababawi.
- Kung naka-configure na ang Directory Approval Group ng iyong simbahan, ipapadala ang iyong request sa grupong iyon para suriin. Hindi magagamit ang butones habang nakabinbin ang request, at aabisuhan ka kapag inaprubahan o tinanggihan ito ng iyong simbahan. Tingnan ang [Reviewing Account Deletion Requests](./account-deletion.md) para malaman ang susunod na mangyayari.

:::warning
Permanente at hindi na mababawi ang pagbura ng account -- maging ito ay agaran o inaprubahan ng iyong simbahan.
:::

:::info
Kung ikaw ay **Domain Admin**, tiyaking ilipat muna ang mga responsibilidad sa pag-administer sa ibang user bago burahin ang iyong account. Tingnan ang [Roles & Permissions](../settings/roles-permissions.md) para sa mga detalye sa pamamahala ng mga admin role.
:::

:::info
Naka-disable ang pag-edit ng profile sa demo mode. Kung gumagamit ka ng demo account, hindi mo maaaring baguhin ang mga setting ng iyong profile.
:::
