# Pamamahala ng Iyong Profile

<div class="article-intro">

Hinahayaan ka ng pahinang Profile na i-edit ang iyong personal na setting ng account. Ibinabahagi ang iyong profile sa lahat ng produkto ng ChurchApps, kaya ang anumang pagbabagong gagawin mo rito ay makikita saanman mo ginagamit ang ChurchApps.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Dapat ay naka-log in ka sa iyong ChurchApps account
- Ihanda ang iyong bagong email address o password kung plano mong palitan ang mga ito

</div>

## Pagbukas ng Iyong Profile {#opening-your-profile}

I-click ang iyong profile picture sa kanang itaas ng B1 Admin at piliin ang **Edit Profile**. Nasa kaliwa ng pahinang Profile ang iyong pangalan at email, at nasa kanan ang mga seksyong **Linked Accounts**, **Two-Factor Sign-In**, at **Account Deletion**.

## Impormasyon ng Profile {#profile-information}

Ipinapakita ng pahinang Profile ang iyong pangalan at email address sa kaliwa, kasama ang button na **Edit** sa ilalim nila. I-click ang **Edit** para buksan ang form na **Edit Account**, na naglalaman ng iyong pangunahing detalye ng account:

1. **Email** -- Ang email address na ginagamit sa pag-log in at pagtanggap ng mga notification.
2. **First Name** at **Last Name** -- Ang iyong display name sa buong ChurchApps.
3. **Current password**, **New password**, at **Verify password** -- Punan lamang ang mga ito kung papalitan mo ang iyong password; iwanang blangko kung gusto mong manatili ang kasalukuyan.

Para i-update ang iyong impormasyon, i-edit ang mga field at i-click ang button na **Save Changes**. Kukumpirmahin ng mensaheng **Changes saved.** ang update. I-click ang **Cancel** (o ang link na **Back to** kasama ang iyong pangalan) para bumalik sa iyong profile nang hindi nagse-save. I-click ang icon na mata sa field ng password para ipakita o itago ang iyong tinype.

## Pagpapalit ng Password {#changing-your-password}

1. Sa pahinang Profile, i-click ang **Edit**.
2. Ilagay ang iyong **Current password**.
3. Ilagay ang bago mong password sa field na **New password**.
4. Ilagay itong muli sa field na **Verify password**.
5. I-click ang **Save Changes**.

:::info
Dapat hindi bababa sa 8 character ang iyong password. Siguraduhing eksaktong tumutugma ang password at ang field ng kumpirmasyon. Kailangan mong kumpirmahin ang iyong kasalukuyang password para mapalitan ito -- kung hindi mo ito alam, gamitin ang link na **Forgot Password** sa login page sa halip.
:::

## Mga Naka-link na Account {#linked-accounts}

Ipinapakita ng seksyong **Linked Accounts** ang mga panlabas na serbisyong maaari mong ikonekta sa iyong ChurchApps account. Sa ngayon, ang **PraiseCharts** lamang, na ginagamit para humanap ng mga kanta at mag-download ng chart at sheet music para sa [mga kanta](../serving/songs.md) sa Serving. Ipinapakita nito ang **Linked** o **Not linked**:

- I-click ang **Link** at mag-sign in sa PraiseCharts sa window na bubukas para ikonekta ang iyong account.
- I-click ang **Sign Up** para gumawa muna ng PraiseCharts account.
- I-click ang **Unlink** para idiskonekta ito.

## Two-Factor Sign-In {#two-factor-sign-in}

Nagdaragdag ang two-factor sign-in ng ikalawang hakbang sa pag-log in: pagkatapos ng iyong password (o ng sign-in link sa Google, Microsoft, o email), maglalagay ka rin ng 6-digit na code mula sa authenticator app sa iyong telepono, gaya ng Google Authenticator, Microsoft Authenticator, 1Password, o Authy. Opsyonal ito at naka-off bilang default. Kapag naka-on na, nalalapat ito sa bawat login ng ChurchApps na gumagamit ng iyong account -- B1 Admin, ang B1.church site at app ng iyong simbahan, B1 Church Checkin, Lessons.church, FreePlay, at iba pa.

### Pag-on Nito {#turning-it-on}

1. Sa pahinang Profile, hanapin ang seksyong **Two-Factor Sign-In** at i-click ang **Turn on**.
2. I-scan ang QR code gamit ang iyong authenticator app. Kung hindi mo ito ma-scan, i-type na lang sa app ang key na nakalagay sa ilalim ng **Can't scan? Enter this key:**.
3. Ilagay ang **6-digit code** na ipinapakita ng iyong app at i-click ang **Verify**.
4. Magpapakita ang B1 Admin ng sampung **backup codes**. Bawat isa ay magpapapasok sa iyo nang isang beses kung mawala mo ang iyong telepono. I-click ang **Copy** o isulat ang mga ito, itago sa ligtas na lugar, at i-click ang **I saved them**.

:::warning
Isang beses lang ipinapakita ang mga backup code. Kung mawala mo ang iyong telepono at wala ka nang natitirang backup code, kailangang i-off ng isang server administrator ng ChurchApps ang two-factor sign-in para sa iyo matapos kumpirmahin kung sino ka.
:::

Kapag naka-on ang two-factor sign-in, magiging **On** ang nakasaad sa seksyon at ipinapakita kung ilang backup code pa ang natitira mo.

### Pag-sign In Gamit ang Code {#signing-in-with-a-code}

Pagkatapos mong ilagay ang iyong password, hihingi ng code ang login screen. Ilagay ang 6-digit na code mula sa iyong authenticator app, o isa sa iyong mga backup code, at isumite ito. Isang beses lang gumagana ang bawat backup code. Kung mali ang code, makikita mo ang "That code didn't work. Please try again." Pagkatapos ng sobrang dami ng maling code, pansamantalang mapapahinto ang mga login para sa iyong account.

Hindi na hihingi ng code muli ang pananatiling naka-sign in sa device na dati mo nang napasukan; lalabas lamang ito kapag bagong login ang gagawin mo.

### Pag-off Nito {#turning-it-off}

1. Sa seksyong **Two-Factor Sign-In**, i-click ang **Turn off**.
2. Ilagay ang kasalukuyang code mula sa iyong authenticator app, o isang backup code.
3. I-click ang **Verify**.

:::info
Hindi maaaring i-set up ang two-factor sign-in sa mga demo account, kaya nakatago ang seksyon doon.
:::

## Theme Preferences {#theme-preferences}

Hinahayaan ka ng B1 Admin na pumili ng color theme at light o dark na display mode:

1. I-click ang iyong profile picture sa kanang itaas ng B1 Admin para buksan ang iyong user menu.
2. Sa ilalim ng **Theme Preferences**, pumili ng theme:
   - **Default** -- Ang kasalukuyang itsura ng B1 Admin: mga panel na may border sa malinis na canvas. Ito ang nakikita ng mga bagong user hanggang pumili sila ng iba.
   - **Classic** -- Ang naunang itsura ng B1 Admin, may kulay na page banner, mga card na may anino, at kulay-abong background. Kung dati mong ginamit ang B1 Admin sa device na ito bago dumating ang bagong itsura at hindi ka pa nakapili ng theme, mananatili ka sa Classic.
   - **Custom** -- Ang itsurang Default na binuo gamit ang sariling kulay ng iyong simbahan. Ginagamit nito ang primary color ng light mode mula sa **Mobile > App Theme**, o ang primary color ng iyong website kung walang kulay ng app na nakatakda, para magtugma ang B1 Admin sa member app mo.
3. Sa ilalim ng mga theme, pumili ng **Light Mode** o **Dark Mode**.
4. Agad na maa-update ang interface para ipakita ang iyong pinili.

Naaalala ang iyong mga pinili sa device at browser na iyon.

## Pagbura ng Account {#account-deletion}

Sa seksyong **Account Deletion** ng pahinang Profile, makikita mo ang opsyon para burahin ang iyong account.

- Kung **hindi** nag-configure ang iyong simbahan ng Directory Approval Group, may babalang *"Careful, these actions are permanent"* ang seksyon. I-click ang **Delete my account** at kumpirmahin, at agad na made-delete ang iyong account at kaugnay na datos at mag-si-sign out ka. Hindi ito maibabalik.
- Kung **may** naka-configure na Directory Approval Group ang iyong simbahan, sinasabi ng seksyon na sinusuri ng iyong simbahan ang mga kahilingan sa pagbura. I-click ang **Delete my account**, pagkatapos ay **Send request**, at ang kahilingan ay mapupunta sa grupong iyon para suriin. Naka-disable ang button habang nakabinbin ang kahilingan, at aabisuhan ka kapag inaprubahan o tinanggihan ito ng iyong simbahan. Tingnan ang [Reviewing Account Deletion Requests](./account-deletion.md) para sa susunod na mangyayari.

:::warning
Permanente ang pagbura ng account -- maging agad man ito o aprubado ng iyong simbahan -- at hindi ito maibabalik.
:::

:::info
Kung ikaw lamang ang **Domain Admin** ng iyong simbahan, hindi buburahin ng B1 ang iyong account. Magpapakita ito ng "You are the only Domain Admin for *church*. Make someone else a Domain Admin before deleting your account." Idagdag muna ang isa pang user sa **Domain Admins**. Tingnan ang [Roles & Permissions](../settings/roles-permissions.md) para sa mga detalye sa pamamahala ng admin role.
:::

:::info
Naka-disable ang pag-edit ng profile sa demo mode. Kung gumagamit ka ng demo account, hindi ka makakagawa ng pagbabago sa mga setting ng iyong profile.
:::
