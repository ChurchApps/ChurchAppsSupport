# Pamamahala ng mga Device

<div class="article-intro">

Hinahayaan ka ng pahinang Devices na pamahalaan ang mga ChurchAppsPlayer at FreePlay device na nakakonekta sa iyong account. Ginagamit ang mga device na ito sa pag-stream ng nilalaman at pagpapakita ng media ng simbahan sa mga screen sa iyong lokasyon.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Dapat naka-on at nakakonekta sa internet ang isang ChurchAppsPlayer o FreePlay device
- Tandaan ang pairing code na ipinapakita sa screen ng device
- Suriin ang iyong [profile settings](./managing-profile.md) kung hindi mo pa ito nagagawa

</div>

## Pagbukas ng Pahinang Devices {#opening-the-devices-page}

Buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas ng B1 Admin), i-type ang **Devices**, at piliin ito. Habang nasa pahina ka ng iyong Profile, nakalista rin sa Jump menu ang **Profile** at **Devices** nang magkatabi.

## Pagtingin sa Iyong mga Device {#viewing-your-devices}

Kapag binuksan mo ang pahinang Devices, makikita mo ang isang table na naglilista ng mga ChurchAppsPlayer at FreePlay screen na ipinares sa iyong account, kasama ang sumusunod na impormasyon:

- **Label** -- Ang pangalang itinalaga mo sa device (**Device** hanggang bigyan mo ito ng pangalan).
- **Registration Date** -- Kailan unang ipinares ang device sa iyong account.
- **Last Active Date** -- Ang pinakahuling beses na kumonekta ang device sa iyong account.

## Pagdaragdag ng Bagong Device {#adding-a-new-device}

1. I-click ang button na **Add Screen** sa itaas ng pahinang Devices.
2. Hanapin ang pairing code na ipinapakita sa ChurchAppsPlayer o FreePlay device na gusto mong ikonekta.
3. Ilagay ito sa field na **Pairing Code**.
4. Kung naka-set up na ang iyong simbahan ng [plan types](../serving/plans.md), hinahayaan ka ng dropdown na **Show Plans For** na piliin ang plan type na dapat sundan ng FreePlay screen -- iwanan ito sa **None (notifications only)** kung ang device ay para lang sa pag-browse at mga notification.
5. I-click ang **Save**. Lalabas ang device sa iyong table ng mga device kapag naipares na ito. Kung mali o expired na ang code, makikita mo ang *"Invalid pairing code"*.

:::tip
Siguraduhing naka-on at nakakonekta sa internet ang device bago subukang ipares ito. Ipinapakita ang pairing code sa screen ng device.
:::

## Pag-edit ng Label ng Device {#editing-a-device-label}

1. I-click ang **Edit** sa tabi ng device sa table ng mga device.
2. I-update ang **Label** sa isang pangalang naglalarawan (halimbawa, "Sanctuary Main Screen" o "Lobby Display").
3. I-click ang **Save**.

May listahan din ang form na **Edit Device** ng **Associated Content** na naglalaman ng mga classroom ng Lessons.church ng iyong simbahan. Lagyan ng check ang isang classroom para iugnay ito sa screen; agad na nase-save ang bawat checkbox kapag na-click mo ito.

:::tip
Ang malinaw at naglalarawang mga label ay nagpapadali sa pagkilala kung aling device ang alin, lalo na kung maraming screen ang naka-set up sa iyong simbahan.
:::

## Pamamahala ng Access ng Device {#managing-device-access}

Gamitin ang pahinang Devices para subaybayan kung aling mga device ang may access sa streaming at nilalaman ng iyong simbahan. Kung hindi na ginagamit ang isang device, alisin ito sa iyong account:

1. I-click ang **Edit** sa tabi ng device.
2. I-click ang **Remove**, pagkatapos ay **Remove** muli para kumpirmahin.

Kakailanganin ng screen ng bagong pairing code para muling kumonekta.

:::warning
Regular na suriin ang mga nakakonektang device para matiyak na tanging aktibo at awtorisadong device lang ang naka-link sa iyong account. Alisin ang mga device na hindi na ginagamit para mapanatili ang seguridad.
:::
