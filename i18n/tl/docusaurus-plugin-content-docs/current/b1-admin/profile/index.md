# Profile

<div class="article-intro">

Hinahayaan ka ng seksyong Profile na pamahalaan ang iyong personal na setting ng account sa ChurchApps. Buksan ito sa pamamagitan ng pag-click sa iyong profile picture sa kanang itaas ng B1 Admin at pagpili ng **Edit Profile**. Ibinabahagi ang iyong profile sa lahat ng tool ng ChurchApps, kaya ang mga pagbabagong gagawin mo rito ay mapapalapat saanman -- mula sa B1 Admin hanggang sa B1 App.

</div>

## Ano ang Puwede Mong Gawin {#what-you-can-do}

Mula sa seksyong Profile, puwede mong:

- **I-update ang iyong pangalan at email** -- Panatilihing napapanahon ang iyong impormasyon ng contact.
- **Palitan ang iyong password** -- Magtakda ng bagong password para sa iyong account.
- **I-on ang two-factor sign-in** -- Hingin ang code mula sa authenticator app kapag nag-log in ka. Tingnan ang [Two-Factor Sign-In](./managing-profile.md#two-factor-sign-in).
- **Magpalit ng theme** -- Lumipat sa pagitan ng light at dark mode mula sa user menu (i-click ang iyong profile picture sa kanang itaas).
- **Pamahalaan ang mga nakakonektang device** -- Tingnan, ipares, palitan ang pangalan, at alisin ang mga ChurchAppsPlayer at FreePlay screen na nakakabit sa iyong account.
- **Tingnan ang mga naka-link na account** -- Makita at pamahalaan ang anumang external na serbisyong nakakonekta sa iyong ChurchApps account.
- **Aprubahan ang mga kahilingan sa pagbabago ng profile** -- Suriin at i-apply ang mga update na isinumite ng mga miyembro.
- **Suriin ang mga kahilingan sa pagbura ng account** -- Aprubahan o tanggihan ang mga kahilingan ng miyembro na burahin ang kanilang account.

## Mga Sub-Seksyon ng Profile {#profile-sub-sections}

May mga sumusunod na pahina ang bahagi ng Profile:

1. **[Pamamahala ng Iyong Profile](./managing-profile.md)** -- I-edit ang iyong personal na impormasyon, palitan ang password, pamahalaan ang mga naka-link na account, i-on ang two-factor sign-in, ayusin ang theme preference, at hawakan ang pagbura ng account.
2. **[Pag-aprubah ng mga Pagbabago sa Profile](./approving-profile-changes.md)** -- Suriin at aprubahan ang mga kahilingan sa pag-update ng profile na isinumite ng mga miyembro sa pamamagitan ng B1 App.
3. **[Pagsusuri ng mga Kahilingan sa Pagbura ng Account](./account-deletion.md)** -- Aprubahan o tanggihan ang mga kahilingan ng miyembro na burahin ang kanilang account.
4. **[Pamamahala ng mga Device](./devices.md)** -- Tingnan, idagdag, palitan ang pangalan, at alisin ang mga ChurchAppsPlayer at FreePlay screen na ipinares sa iyong account.

:::tip
Panatilihing napapanahon ang iyong email address. Ginagamit ito sa pagbawi ng account at sa mahahalagang notification mula sa iyong simbahan.
:::
