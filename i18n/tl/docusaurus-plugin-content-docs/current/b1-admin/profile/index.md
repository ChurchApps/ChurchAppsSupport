# Profile

<div class="article-intro">

Hinahayaan ka ng seksyong Profile na pamahalaan ang iyong personal na mga setting ng account sa ChurchApps. Ang iyong profile ay ibinabahagi sa lahat ng tool ng ChurchApps, kaya ang mga pagbabagong gagawin mo rito ay ilalapat sa lahat ng dako -- mula sa B1 Admin hanggang sa B1 App.

</div>

## Ano ang Maaari Mong Gawin

Mula sa seksyong Profile, maaari mong:

- **I-update ang iyong pangalan at email** -- Panatilihing napapanahon ang iyong impormasyon sa pakikipag-ugnayan.
- **Palitan ang iyong password** -- Magtakda ng bagong password para sa iyong account.
- **I-on ang two-factor sign-in** -- Hingin ang code mula sa authenticator app kapag nag-log in ka. Tingnan ang [Two-Factor Sign-In](./managing-profile.md#two-factor-sign-in).
- **Magpalit ng tema** -- Lumipat sa pagitan ng light at dark mode mula sa user menu (i-click ang iyong larawan sa profile sa kanang itaas na sulok).
- **Pamahalaan ang mga nakakonektang device** -- Tingnan at kontrolin kung aling mga ChurchAppsPlayer device ang nakakabit sa iyong account.
- **Tingnan ang mga naka-link na account** -- Tingnan at pamahalaan ang anumang panlabas na serbisyong nakakonekta sa iyong ChurchApps account.
- **Aprubahan ang mga kahilingan sa pagbabago ng profile** -- Suriin at ilapat ang mga update na isinumite ng mga miyembro.

## Mga Sub-Seksyon ng Profile

Ang lugar ng Profile ay may mga sumusunod na pahina:

1. **[Pamamahala ng Iyong Profile](./managing-profile.md)** -- I-edit ang iyong personal na impormasyon, palitan ang iyong password, pamahalaan ang mga naka-link na account, i-on ang two-factor sign-in, isaayos ang mga kagustuhan sa tema, at pangasiwaan ang pagtanggal ng account.
2. **[Pag-aapruba ng mga Pagbabago sa Profile](./approving-profile-changes.md)** -- Suriin at aprubahan ang mga kahilingan sa pag-update ng profile na isinumite ng mga miyembro sa pamamagitan ng B1 App.
3. **[Pamamahala ng mga Device](./devices.md)** -- Tingnan, idagdag, at pamahalaan ang mga ChurchAppsPlayer device na naka-pair sa iyong account.

:::tip
Panatilihing napapanahon ang iyong email address. Ginagamit ito para sa pagbawi ng account at mahahalagang abiso mula sa iyong simbahan.
:::
