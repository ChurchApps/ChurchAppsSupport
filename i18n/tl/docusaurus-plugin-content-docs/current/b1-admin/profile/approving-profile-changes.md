# Approving Profile Changes

<div class="article-intro">

Kapag ang iyong simbahan ay nangangailangan ng administrator approval para sa profile updates, ang mga miyembro ay nagsumite ng kanilang mga pagbabago sa pamamagitan ng B1 Mobile app at ang mga request na iyon ay lumalabas bilang mga gawain sa B1 Admin. Ang gabay na ito ay nagpapaliwanag kung paano suriin at aprubahan ang mga ito.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Dapat ka ay isang miyembro ng grupo na itinalagang **Directory Approval Group** sa **Mobile → B1 Mobile**
- Kung walang approval group na naka-configure, ang mga pagbabago ng profile ay agad na inilapat nang walang review

</div>

## Kung Saan Makikita ang Pending Requests

Kapag ang isang miyembro ay nagsumite ng isang pagbabago ng profile, ito ay lumalabas bilang isang gawain na itinalaga sa iyong approval group. Maaari mong hanapin ito sa dalawang lugar:

**Mula sa Dashboard:**
1. Mag-log in sa B1 Admin — ang Dashboard ay awtomatikong nag-load.
2. Sa **Tasks** section sa kanang bahagi, i-click ang **Assigned to My Groups** tab.
3. Ang kahit anong pending profile change requests ay magiging listahan doon.

**Mula sa Serving → My Work:**
1. Sa tuktok na navigation, i-click ang **Serving**.
2. I-click ang **My Work**.
3. I-click ang **Assigned to My Groups** tab sa ilalim ng Tasks.

## Pag-review at Pag-approve ng Isang Request

1. I-click ang **Profile Update** task upang buksan ito.
2. Sa ilalim ng **Requested Changes**, makikita mo ang bawat field na gusto ng miyembro na i-update kasama ng bagong halaga na kanilang isinumite.
3. Suriin ang mga pagbabago.
4. I-click ang **Apply** upang aprubahan at i-save ang mga pagbabago sa kanilang profile.

Ang task ay awtomatikong sasara kapag ang mga pagbabago ay inilapat.

## Pag-setup ng Approval Group

Kung ang iyong simbahan ay nais na ang mga pagbabago ng profile ay mangangailangan ng approval, isang Directory Approval Group ay dapat na i-configure muna.

1. Sa tuktok na navigation, i-click ang **Mobile**.
2. I-click ang **B1 Mobile**.
3. Sa ilalim ng **Directory Approval Group**, piliin ang grupo na ang mga miyembro nito ay dapat suriin ang mga profile change request.
4. I-click ang **Save**.

Ang kahit anong miyembro ng grupo na iyon ay makakakita ng mga papasok na profile change request sa ilalim ng **Assigned to My Groups** sa kanilang dashboard.

:::tip
Tiyakin na ang iyong mga approver ay tunay na mga miyembro ng naka-configure na grupo — lamang ang mga miyembro ng grupo ay makakakita ng mga request.
:::
