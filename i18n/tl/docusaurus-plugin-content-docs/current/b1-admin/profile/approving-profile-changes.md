# Pag-apruba ng mga Pagbabago sa Profile

<div class="article-intro">

Kapag nangangailangan ang inyong simbahan ng pag-apruba ng administrator para sa mga update sa profile, isinusumite ng mga miyembro ang kanilang mga pagbabago sa pamamagitan ng B1 Mobile app at lumalabas ang mga kahilingang iyon bilang mga task sa B1 Admin. Ipinapaliwanag ng gabay na ito kung paano ito susuriin at aaprubahan.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Dapat kayong miyembro ng group na itinalaga bilang **Directory Approval Group** sa **Mobile &rarr; Member portal**
- Kung walang na-configure na approval group, agad na ilalapat ang mga pagbabago sa profile nang walang pagsusuri

</div>

## Saan Makikita ang mga Nakabinbing Kahilingan

Kapag nagsumite ang isang miyembro ng pagbabago sa profile, lalabas ito bilang task na nakatalaga sa inyong approval group. Makikita ninyo ito sa dalawang lugar:

**Mula sa Dashboard (inyong home page):**
1. Mag-log in sa B1 Admin — awtomatikong magbubukas ang Dashboard.
2. Sa seksyong **Tasks** sa kanang bahagi, i-click ang tab na **Assigned to My Groups**.
3. Nakalista roon ang anumang nakabinbing kahilingan sa pagbabago ng profile.

**Mula sa Serving &rarr; My Work:**
1. Buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas ng B1 Admin) at palawakin ang **Serving**.
2. I-click ang **My Work**.
3. I-click ang tab na **Assigned to My Groups** sa ilalim ng Tasks.

## Pagsusuri at Pag-apruba ng Kahilingan

1. I-click ang task na **Profile Update** para buksan ito.
2. Sa ilalim ng **Requested Changes**, makikita ninyo ang bawat field na gustong i-update ng miyembro kasama ang bagong halagang isinumite nila.
3. Suriin ang mga pagbabago.
4. I-click ang **Apply** para aprubahan at i-save ang mga pagbabago sa kanilang profile.

Awtomatikong magsasara ang task kapag nailapat na ang mga pagbabago.

## Pag-set Up ng Approval Group

Kung gusto ng inyong simbahan na kailanganin ng pag-apruba ang mga pagbabago sa profile, kailangan munang i-configure ang isang Directory Approval Group.

1. Buksan ang Jump menu at palawakin ang **Mobile**.
2. I-click ang **Member portal** (ang pahinang "Portal settings").
3. Sa ilalim ng **Directory Approval Group**, piliin ang group na ang mga miyembro ang dapat magsuri ng mga kahilingan sa pagbabago ng profile.
4. I-click ang **Save**.

Makikita ng sinumang miyembro ng group na iyon ang mga papasok na kahilingan sa pagbabago ng profile sa ilalim ng **Assigned to My Groups** sa kanilang Dashboard.

Ang parehong Directory Approval Group din ang sumusuri sa mga **kahilingan sa pagbura ng account** — tingnan ang [Pagsusuri sa mga Kahilingan sa Pagbura ng Account](./account-deletion.md).

:::tip
Tiyaking talagang miyembro ng na-configure na group ang inyong mga taga-apruba — mga miyembro lang ng group ang makakakita ng mga kahilingan.
:::
