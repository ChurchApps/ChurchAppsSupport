# Pag-apruba sa pagbabago ng profile

<div class="article-intro">

Kapag ang iyong simbahan ay nangangailangan ng administrator na pag-apruba para sa mga update ng profile, ang mga miyembro ay nagsusumite ng kanilang mga pagbabago sa pamamagitan ng B1 Mobile app at ang mga kahilingang ito ay lumilitaw bilang mga gawain sa B1 Admin. Ang gabay na ito ay nagpapaliwanag kung paano susuriin at aprubahan ang mga ito.

</div>

<div class="prereqs">
<h4>Bago ka magsimula</h4>

- Dapat kang maging miyembro ng grupo na itinalagang **Directory Approval Group** sa **Mobile &rarr; Member portal**
- Kung walang approval group na na-configure, ang mga pagbabago ng profile ay agad na naipatupad nang walang review

</div>

## Kung saan makikita ang mga kahilingang naghihintay

Kapag ang isang miyembro ay nagsumite ng pagbabago ng profile, ito ay lumalitaw bilang isang gawain na itinalaga sa iyong approval group. Mahahanap mo ito sa dalawang lugar:

**Mula sa Dashboard (ang iyong home page):**
1. Mag-log in sa B1 Admin — ang Dashboard ay awtomatikong nag-load.
2. Sa **Tasks** section sa kanang bahagi, i-click ang **Assigned to My Groups** tab.
3. Ang anumang pending profile change requests ay magiging listed doon.

**Mula sa Serving &rarr; My Work:**
1. Sa top navigation, i-click ang **Serving**.
2. I-click ang **My Work**.
3. I-click ang **Assigned to My Groups** tab sa ilalim ng Tasks.

## Pagsusuri at pag-apruba ng isang kahilingan

1. I-click ang **Profile Update** task upang buksan ito.
2. Sa ilalim ng **Requested Changes**, makikita mo ang bawat field na nais i-update ng miyembro kasama ang bagong halaga na kanilang isinumite.
3. Suriin ang mga pagbabago.
4. I-click ang **Apply** upang aprubahan at i-save ang mga pagbabago sa kanilang profile.

Ang gawain ay awtomatikong magsasara kapag ang mga pagbabago ay na-apply.

## Pag-setup ng Approval Group

Kung ang iyong simbahan ay nais na ang mga pagbabago ng profile ay mangangailangan ng pag-apruba, ang isang Directory Approval Group ay dapat munang i-configure.

1. Sa top navigation, i-click ang **Mobile**.
2. I-click ang **Member portal** (ang "Portal settings" page).
3. Sa ilalim ng **Directory Approval Group**, piliin ang grupo na ang mga miyembro ay dapat sumagot sa profile change requests.
4. I-click ang **Save**.

Ang sinumang miyembro ng grupo na iyon ay makikita ang mga papasok na profile change requests sa ilalim ng **Assigned to My Groups** sa kanilang Dashboard.

Ang parehong Directory Approval Group ay sumusuri din sa **account deletion requests** — tingnan ang [Reviewing Account Deletion Requests](./account-deletion.md).

:::tip
Siguraduhin na ang iyong mga approvers ay tunay na mga miyembro ng configured group — lamang ang mga miyembro ng grupo ang makakakita ng mga kahilingan.
:::
