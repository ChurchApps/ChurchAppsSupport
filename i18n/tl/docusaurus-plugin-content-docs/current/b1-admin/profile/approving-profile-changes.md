# Pag-aprubah ng mga Pagbabago sa Profile {#approving-profile-changes}

<div class="article-intro">

Kapag kailangan ng iyong simbahan ng pag-apruba ng administrator para sa mga update ng profile, isinusumite ng mga miyembro ang kanilang mga pagbabago sa pamamagitan ng B1 App, at lumalabas ang mga kahilingang iyon bilang mga task sa B1 Admin. Ipinapaliwanag ng gabay na ito kung paano ito susuriin at aaprubahan.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Dapat ay miyembro ka ng grupong itinalagang **Directory Approval Group** sa **Mobile &rarr; Member portal**
- Kung walang naka-configure na approval group, ang mga pagbabago sa profile ay agad na ina-apply nang walang pagsusuri

</div>

## Saan Makikita ang mga Nakabinbing Kahilingan {#where-to-find-pending-requests}

Kapag nagsumite ang isang miyembro ng pagbabago sa profile, lalabas ito bilang task na nakatalaga sa iyong approval group. Makikita mo ito sa dalawang lugar:

**Mula sa Dashboard (iyong home page):**
1. Mag-log in sa B1 Admin -- awtomatikong magla-load ang Dashboard.
2. Sa seksyong **My tasks**, i-click ang **All tasks**. (Ang My tasks ay naglilista lamang ng mga bukas na task na personal na nakatalaga sa iyo.)
3. I-click ang tab na **Assigned to My Groups**. Nakalista roon ang anumang nakabinbing kahilingan sa pagbabago ng profile.

**Mula sa Serving &rarr; My Work:**
1. Buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas ng B1 Admin) at palawakin ang **Serving**.
2. I-click ang **My Work**.
3. I-click ang tab na **Assigned to My Groups** sa ilalim ng Tasks.

## Pagsusuri at Pag-aprubah ng Kahilingan {#reviewing-and-approving-a-request}

1. I-click ang task na **Profile Update** para buksan ito.
2. Sa ilalim ng **Requested Changes**, makikita mo ang bawat field na gustong i-update ng miyembro kasama ang bagong halagang isinumite nila.
3. Suriin ang mga pagbabago.
4. I-click ang **Apply** para aprubahan at i-save ang mga pagbabago sa kanilang profile.

Ang kahilingang magdagdag ng miyembro ng pamilya ay nagpapakita ng title, pangalan, household role, mobile phone, at email ng bagong tao sa iisang linya (halimbawa, *Mr John Smith · Child · 555-0100 · john@example.com*), kasama ang kanilang larawan sa tabi nito kung idinagdag ito ng miyembro. Kapag in-apply ito, gagawin ang taong iyon sa household ng miyembro na may mga detalyeng iyon at larawan.

Awtomatikong magsasara ang task kapag na-apply na ang mga pagbabago.

## Pag-set up ng Approval Group {#setting-up-the-approval-group}

Kung gusto ng iyong simbahan na nangangailangan ng pag-apruba ang mga pagbabago sa profile, kailangan munang i-configure ang Directory Approval Group.

1. Buksan ang Jump menu at palawakin ang **Mobile**.
2. I-click ang **Member portal** (ang pahinang "Portal settings").
3. Sa ilalim ng **Directory Approval Group**, piliin ang grupong ang mga miyembro ay dapat magsuri ng mga kahilingan sa pagbabago ng profile.
4. I-click ang **Save**.

Makikita ng sinumang miyembro ng grupong iyon ang mga papasok na kahilingan sa pagbabago ng profile sa ilalim ng **Assigned to My Groups** sa kanilang Dashboard.

Ang parehong Directory Approval Group ay sumusuri rin ng **mga kahilingan sa pagbura ng account** -- tingnan ang [Reviewing Account Deletion Requests](./account-deletion.md).

:::tip
Siguraduhing tunay na miyembro ng naka-configure na grupo ang iyong mga approver -- tanging mga miyembro ng grupo ang makakakita ng mga kahilingan.
:::
