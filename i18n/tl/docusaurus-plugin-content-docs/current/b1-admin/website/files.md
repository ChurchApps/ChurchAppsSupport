# Files

<div class="article-intro">

Ang pahinang Files ang sentral na lalagyan ng lahat ng media at dokumentong ginagamit sa website ng iyong simbahan. Mula rito, maaari mong i-upload, i-browse, at pamahalaan ang bawat larawan, dokumento, at media file na kailangan ng iyong site.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kumpletuhin ang [Initial Setup](./initial-setup.md) para sa iyong website
- I-optimize ang mga larawan bago mag-upload para mas mabilis mag-load ang mga pahina
- Ihanda ang iyong mga file sa karaniwang web format (PNG, JPG, PDF, atbp.)

</div>

## Pag-upload ng Mga File {#uploading-files}

1. Sa B1 Admin, buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa itaas-kaliwa), palawakin ang **Website**, at i-click ang **Files**.
2. I-click ang **Upload Files** sa itaas ng pahina, o ang **Choose File** sa panel na **Upload Files** sa kanan, at pumili ng file mula sa iyong computer.
3. Agad na ina-upload ang file pagkapili mo rito at lumalabas ito sa table ng mga file.

Ipinapakita rin ng panel na Upload Files kung gaano na karami ang storage na nagamit mo. Libre ang 100 MB; kapag puno na ito, nakatago ang mga upload button hanggang magbura ka ng mga file o magdagdag ng espasyo. Para makakuha ng higit pa, i-link ang sarili mong Google Drive, Dropbox, OneDrive, o S3 bucket sa ilalim ng **Settings**, sa seksyong **File Storage**. Mapupunta na ang mga file sa iyong naka-link na account, at ipapakita ng panel ang **Stored in your linked account**.

:::tip
Para sa pinakamagandang resulta, i-optimize ang mga larawan bago mag-upload. Mas maliliit na file ang nakakatulong para mas mabilis mag-load ang iyong website para sa mga bisita. Makakapag-compress ng larawan nang walang halatang pagkawala ng kalidad ang mga tool gaya ng TinyPNG o Squoosh.
:::

## Pag-browse ng Mga File {#browsing-files}

Inililista ng files table ang bawat na-upload na file kasama ang **Name** at **Size** nito. I-click ang pangalan ng file para buksan ito sa bagong tab. Bigyan ng malinaw at mapaglarawang pangalan ang mga file bago mag-upload para mabilis itong mahanap ng iyong team.

## Paggamit ng Mga File sa Iyong Website {#using-files-on-your-website}

1. Hanapin ang file sa files table.
2. I-click ang **Copy link** para kopyahin ang URL ng file (magbabago ang button sa **Copied**). Maaari mong i-paste ang URL na ito sa mga image element, download link, o kahit saan na tumatanggap ng file URL.
3. Ang mga file na ina-upload mo rito ay magagamit sa lahat ng pahina at content block ng iyong website.

:::info
Kapag gumagawa ng mga pahina sa [Managing Pages](./managing-pages.md), maaari mong i-reference ang anumang file na na-upload dito gamit ang URL nito. Pinananatiling nakaayos ng ganito ang lahat ng iyong media sa iisang sentral na lugar.
:::

## Pagbura ng Mga File {#deleting-files}

1. Hanapin ang file na gusto mong alisin sa files table.
2. I-click ang **Delete** sa tabi nito at kumpirmahin para tuluyan itong alisin sa iyong library.
3. Siguraduhing hindi ginagamit ang file sa anumang pahina bago ito burahin, dahil masisira nito ang anumang link o larawang tumutukoy dito.

:::warning
Hindi na maibabalik ang mga binurang file. I-double-check na wala nang ginagamit na pahina ang file bago ito alisin.
:::
