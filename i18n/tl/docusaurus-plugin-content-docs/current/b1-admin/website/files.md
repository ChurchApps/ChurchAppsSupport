# Mga File

<div class="article-intro">

Ang pahinang Files ang sentrong imbakan ng lahat ng media at dokumentong ginagamit sa website ng inyong simbahan. Mula rito, maaari kang mag-upload, mag-browse, at mamahala ng bawat larawan, dokumento, at media file na kailangan ng iyong site.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Kumpletuhin ang [Initial Setup](initial-setup) para sa iyong website
- I-optimize ang mga larawan bago i-upload para mas mabilis mag-load ang mga pahina
- Ihanda ang iyong mga file sa karaniwang web format (PNG, JPG, PDF, atbp.)

</div>

## Pag-upload ng mga File

1. Sa B1 Admin, buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas), i-expand ang **Website**, at i-click ang **Files**.
2. Sa panel na **Upload Files** sa kanan, i-click ang **Choose File** at pumili ng file mula sa iyong computer. (Dadalhin ka rin ng **Upload Files** button sa itaas ng pahina sa parehong panel.)
3. Maa-upload ang iyong file at lalabas ito sa files table.

Ipinapakita rin ng Upload Files panel kung gaano na karami ang storage na nagamit mo. May 100 MB na libre; para makakuha ng higit pa, i-link ang sarili mong Google Drive, Dropbox, OneDrive, o S3 bucket sa ilalim ng **Settings**, sa section na **File Storage**.

:::tip
Para sa pinakamagandang resulta, i-optimize ang mga larawan bago i-upload. Ang mas maliliit na file size ay tumutulong para mas mabilis mag-load ang iyong website para sa mga bisita. Ang mga tool tulad ng TinyPNG o Squoosh ay kayang mag-compress ng mga larawan nang walang kapansin-pansing pagbaba ng kalidad.
:::

## Pag-browse ng mga File {#browsing-files}

Inililista ng files table ang bawat na-upload na file kasama ang **Name** at **Size** nito. I-click ang pangalan ng file para buksan ito sa bagong tab. Bigyan ng malinaw at naglalarawang pangalan ang mga file bago i-upload para madali itong mahanap ng iyong team.

## Paggamit ng mga File sa Iyong Website

1. Hanapin ang file sa files table.
2. I-click ang **Copy link** para kopyahin ang URL ng file. Maaari mong i-paste ang URL na ito sa mga image element, download link, o saanmang tumatanggap ng file URL.
3. Ang mga file na ina-upload mo rito ay magagamit sa lahat ng pahina at content block ng iyong website.

:::info
Kapag bumubuo ng mga pahina sa [Pamamahala ng mga Pahina](managing-pages), maaari mong i-reference ang anumang file na na-upload dito gamit ang URL nito. Dahil dito, nananatiling organisado ang lahat ng iyong media sa iisang sentrong lokasyon.
:::

## Pagtanggal ng mga File

1. Hanapin ang file na gusto mong alisin sa files table.
2. I-click ang **Delete** sa tabi nito at kumpirmahin para permanenteng tanggalin ito sa iyong library.
3. Tiyaking hindi pa ginagamit ang file sa anumang pahina bago ito tanggalin, dahil masisira nito ang anumang link o larawang tumutukoy dito.

:::warning
Hindi na mababawi ang mga natanggal na file. Siguraduhing hindi na ginagamit ang file sa anumang pahina bago ito alisin.
:::
