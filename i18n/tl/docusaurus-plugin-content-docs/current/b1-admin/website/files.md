# Mga File

<div class="article-intro">

Ang pahinang Files ang sentrong imbakan ng lahat ng media at dokumentong ginagamit sa website ng inyong simbahan. Mula rito, maaari kang mag-upload, mag-organisa, mag-browse, at mamahala ng bawat larawan, dokumento, at media file na kailangan ng iyong site.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Kumpletuhin ang [Initial Setup](initial-setup) para sa iyong website
- I-optimize ang mga larawan bago i-upload para mas mabilis mag-load ang mga pahina
- Ihanda ang iyong mga file sa karaniwang web format (PNG, JPG, PDF, atbp.)

</div>

## Pag-upload ng mga File

1. Sa B1 Admin, buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas), i-expand ang **Website**, at i-click ang **Files**.
2. I-drag at i-drop ang mga file nang direkta sa upload area, o i-click ang upload button para mag-browse sa iyong computer.
3. Maa-upload ang iyong mga file at agad na lalabas sa file library.

:::tip
Para sa pinakamagandang resulta, i-optimize ang mga larawan bago i-upload. Ang mas maliliit na file size ay tumutulong para mas mabilis mag-load ang iyong website para sa mga bisita. Ang mga tool tulad ng TinyPNG o Squoosh ay kayang mag-compress ng mga larawan nang walang kapansin-pansing pagbaba ng kalidad.
:::

## Pag-oorganisa gamit ang mga Folder

1. Gumawa ng mga folder para pagsama-samahin ang magkakaugnay na file -- halimbawa, "Sermon Graphics," "Event Banners," o "Staff Photos."
2. Ilipat ang mga file sa pagitan ng mga folder para manatiling maayos ang iyong library habang lumalaki ito.
3. Gumamit ng malinaw at naglalarawang pangalan ng folder para madaling mahanap ng iyong team ang mga file.

## Pag-browse at Paghahanap

- Mag-scroll sa file library para makita ang mga thumbnail ng lahat ng na-upload mong file.
- Gamitin ang **search** function para maghanap ng file ayon sa pangalan kapag malaki na ang iyong library.
- I-click ang anumang file para makita ang mga detalye nito, kasama ang pangalan ng file, laki, at URL.

## Paggamit ng mga File sa Iyong Website

1. I-click ang isang file para makita ang mga detalye nito.
2. **Kopyahin ang URL ng file** para gamitin ito sa mga pahina ng iyong website. Maaari mong i-paste ang URL na ito sa mga image element, download link, o saanmang tumatanggap ng file URL.
3. Ang mga file na ina-upload mo rito ay magagamit sa lahat ng pahina at content block ng iyong website.

:::info
Kapag bumubuo ng mga pahina sa [Pamamahala ng mga Pahina](managing-pages), maaari mong i-reference ang anumang file na na-upload dito gamit ang URL nito. Dahil dito, nananatiling organisado ang lahat ng iyong media sa iisang sentrong lokasyon.
:::

## Pagtanggal ng mga File

1. Piliin ang file na gusto mong alisin.
2. I-click ang **Delete** button para permanente itong tanggalin sa iyong library.
3. Tiyaking hindi pa ginagamit ang file sa anumang pahina bago ito tanggalin, dahil masisira nito ang anumang link o larawang tumutukoy dito.

:::warning
Hindi na mababawi ang mga natanggal na file. Siguraduhing hindi na ginagamit ang file sa anumang pahina bago ito alisin.
:::
