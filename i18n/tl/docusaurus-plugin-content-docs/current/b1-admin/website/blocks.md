# Mga Reusable Block

<div class="article-intro">

Ang mga block ay mga bahagi ng nilalaman ng website na ginagawa mo nang isang beses at magagamit muli sa kasing-dami ng pahinang gusto mo -- isang call-to-action banner, contact strip, o service-times panel. Kapag nag-edit ka ng block, makikita ng bawat pahinang gumagamit nito ang pagbabago.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan mo ng permiso na mag-edit ng nilalaman ng website
- Gumamit ng computer o tablet; pareho ang block editor sa full-screen editor na ginagamit para sa mga pahina

</div>

## Pagbubukas ng Mga Block {#opening-blocks}

1. Sa B1 Admin, buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa itaas-kaliwa) at palawakin ang **Website**.
2. I-click ang **Blocks**. Ipinapakita ng pahinang **Reusable Blocks** ang bawat block kasama ang **Name** at **Type** nito.

Kung may higit sa isang website ang simbahan mo, gamitin ang site switcher sa itaas ng pahina para makita ang mga block ng bawat site. Isa ring block ang footer ng iyong site, pero ine-edit ito mula sa **Site Footer** sa [Appearance](./appearance.md) at hindi nakalista rito.

## Pagdaragdag ng Block {#adding-a-block}

1. I-click ang **Add Block**.
2. Maglagay ng **Name** na makikilala ng iyong team.
3. Piliin ang **Block Type**:
   - **Element(s)** -- isa o higit pang elemento (teksto, larawan, button, at iba pa) na inilalagay mo sa loob ng isang seksyon sa isang pahina.
   - **Section(s)** -- isa o higit pang buong seksyon na inilalagay mo sa isang pahina sa pagitan ng iba pang seksyon nito.
4. I-click ang **Save**. Lalabas ang block sa listahan.

## Pagbuo ng Nilalaman ng Block {#building-a-blocks-content}

1. I-click ang pangalan ng block, o ang **Edit** sa row nito. Magbubukas ang block sa [page editor](./page-editor.md).
2. Magdagdag at mag-istilo ng nilalaman gaya ng gagawin mo sa pahina, simula sa isang seksyon.
3. Awtomatikong nase-save ang mga pagbabago. I-click ang **Exit** sa toolbar para bumalik sa listahan ng Blocks.

## Paggamit ng Block sa Pahina {#using-a-block-on-a-page}

1. Magbukas ng pahina sa [page editor](./page-editor.md) at i-click ang **Add Content**.
2. Piliin ang tab na **Blocks** sa panel na **Add Elements**. (Lumilitaw lamang ang tab kapag mayroon ka nang kahit isang block.)
3. I-drag ang block papunta sa pahina: ang element block ay sa loob ng isang seksyon, at ang section block ay sa pagitan ng mga seksyon.

Ipinapakita ng pahina ang kasalukuyang nilalaman ng block. Para baguhin ito, i-edit ang mismong block mula sa pahinang **Blocks**; magna-update ang bawat pahinang gumagamit nito.

## Pagpapalit ng Pangalan o Pagbura ng Block {#renaming-or-deleting-a-block}

1. I-click ang **Rename** sa row ng block.
2. Baguhin ang **Name** o **Block Type** at i-click ang **Save**, o i-click ang **Delete** at kumpirmahin para tuluyang alisin ang block.

:::warning
Ang mga pahinang gumagamit ng naburang block ay hindi na magpapakita ng nilalaman nito. Suriin ang iyong mga pahina bago magbura ng block na ginagamit pa.
:::
