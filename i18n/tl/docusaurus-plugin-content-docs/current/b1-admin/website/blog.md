# Blog

<div class="article-intro">

Ang Blog feature ay nagbibigay-daan sa iyo na maglathala ng mga article sa iyong church website. Bawat post ay maaaring may mga larawan, video, at formatted na text na makikita ng iyong mga miyembro at mga bisita.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Kailangan mo ng access sa Website section sa B1 Admin
- Ang iyong simbahan ay dapat na mayroong website na na-setup

</div>

## Lumilikha ng Isang Blog Post

1. Sa B1 Admin, bumukod sa **Website** at piliin ang **Blog**.
2. I-click ang **New Post**.
3. Magpasok ng pamagat at nilalaman.
4. I-publish ang post upang ito ay makita sa iyong website.

Para sa kompletong detalye, mangyaring tingnan ang admin guide.
