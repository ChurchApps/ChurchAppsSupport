# Mga Template ng Plan

<div class="article-intro">

Hinahayaan ka ng mga plan template na mag-save ng magagamit muli na kopya ng order of service o mga posisyon ng isang plan at ilapat ito sa mga susunod na plan sa isang click lang. Sa halip na buuin muli ang parehong istruktura kada linggo, i-save mo ito nang isang beses at ilagay ito sa lahat ng paparating na plan na kailangan mo.

## Pag-save ng Plan Bilang Template

1. Buksan ang umiiral na plan mula sa lugar na **Serving**.
2. Sa seksyong **Order of Service** ng plan, i-click ang **Save as Template**.
3. Bigyan ng pangalan ang template (halimbawa, "Standard Sunday" o "Worship + Sermon").
4. I-save. Kinukuha ng template ang kasalukuyang order of service, mga posisyon, at mga note ng plan sa sandaling iyon.

## Pamamahala ng Mga Template

I-click ang **Templates** sa itaas ng listahan ng plan sa anumang pahina ng uri ng plan para buksan ang **Plan Templates**. Mula roon, maaari mong:

- **Rename** -- palitan ang display name ng template
- **Update from plan** -- palitan ang nilalaman ng template ng kasalukuyang estado ng isang plan (kapaki-pakinabang pagkatapos mong pinuhin ang iyong karaniwang istruktura)
- **Apply** -- ilagay ang template sa isa o higit pang paparating na plan
- **Delete** -- alisin ang template na hindi mo na kailangan

## Pag-apply ng Template sa Mga Plan

1. I-click ang **Templates** sa itaas ng listahan ng plan sa pahina ng uri ng plan.
2. I-click ang **Apply** icon (icon ng kopya) sa tabi ng template na gusto mong gamitin.
3. Piliin kung aling mga paparating na plan ang paglalapatan sa pamamagitan ng paglalagay ng check sa kanilang mga kahon.
4. Piliin kung ano ang kokopyahin:
   - **Order of Service** -- papalitan ang mga service order item ng mga napiling plan ng mga item ng template
   - **Positions** -- papalitan ang mga posisyon ng mga napiling plan (at ang mga takda nito) ng mga posisyon ng template
5. I-click ang **Apply**.

Kung may mga note ang template, papalitan din ng pag-apply nito ang mga note ng mga napiling plan ng mga note ng template.

:::warning
Ang pag-apply ng mga posisyon ay papalit sa lahat ng umiiral na posisyon at takda sa mga napiling plan. Siguraduhing hindi mo pa naiiskedyul ang mga boluntaryo para sa mga posisyong iyon bago mag-apply.
:::

:::tip
I-apply ang Order of Service nang walang Positions kapag gusto mo ng pare-parehong istruktura ng awit/sermon pero iba-iba ang pagkakatakda ng mga boluntaryo kada linggo.
:::

## Pagsisimula ng Bagong Plan Mula sa Template

Ibinabahagi ang mga template sa mga uri ng plan sa loob ng isang ministry. Kapag nag-click ka ng **New Plan** at may mga template ang ministry, may kasamang listahang **Start from template** ang bagong plan form. Pumili ng template at i-save, at gagawin ang bagong plan na may order of service, mga posisyon, at mga note ng template. Ang pagpili ng template ay papalit sa mga opsyong **Copy from Previous Plan** para sa planong iyon.

## Pagpapanatiling Updated ng Mga Template

Kung magbago ang iyong karaniwang istruktura ng serbisyo, buksan ang template manager at gamitin ang **Update from plan** para i-sync ang template mula sa pinakabago mong plan sa halip na buuin ulit ito mula sa simula.
