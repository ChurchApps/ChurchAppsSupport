# Mga Plan Template

<div class="article-intro">

Hinahayaan ka ng mga plan template na mag-save ng reusable na kopya ng order of service o mga posisyon ng isang plan at ilapat ito sa mga susunod na plan sa isang click. Sa halip na buuin muli ang parehong istruktura kada linggo, i-save mo ito nang isang beses at ilapat sa kasing-dami ng paparating na plan na kailangan mo.

## Pag-save ng Plan bilang Template {#saving-a-plan-as-a-template}

1. Magbukas ng umiiral na plan mula sa **Serving** area.
2. I-click ang **Edit order of service** para buksan ang order of service ng plan, pagkatapos i-click ang **Save as Template** sa itaas nito.
3. Bigyan ng pangalan ang template (halimbawa, "Standard Sunday" o "Worship + Sermon"). Nagsisimula ito sa pangalan ng plan.
4. I-click ang **Save**. Kinukuha ng template ang kasalukuyang order of service, mga posisyon, at mga tala ng plan sa sandaling iyon.

## Pamamahala ng mga Template {#managing-templates}

I-click ang **Templates** sa itaas ng listahan ng plan sa anumang plan type page para buksan ang **Plan Templates**. May mga icon ang bawat template na ito:

- **Edit** (lapis) -- palitan ng pangalan ang template
- **Update from plan** (pabilog na arrow) -- palitan ang nilalaman ng template ng kasalukuyang estado ng isang plan (kapaki-pakinabang pagkatapos mong pinuhin ang iyong karaniwang istruktura)
- **Apply** (copy icon) -- ilapat ang template sa isa o higit pang paparating na plan
- **Delete** (basurahan) -- alisin ang template na hindi mo na kailangan

## Pagla-lapat ng Template sa mga Plan {#applying-a-template-to-plans}

1. I-click ang **Templates** sa itaas ng listahan ng plan sa plan type page.
2. I-click ang icon na **Apply** (copy icon) sa tabi ng template na gusto mong gamitin.
3. Piliin kung aling paparating na plan ang paglalapatan sa pamamagitan ng paglalagay ng check sa kanilang mga kahon. Hindi nakalista ang mga plan na may petsang bago ngayon.
4. Piliin kung ano ang kokopyahin:
   - **Order of Service** -- papalitan ang mga item ng service order ng mga napiling plan ng mga item ng template
   - **Positions** -- papalitan ang mga posisyon (at ang mga assignment nito) ng mga napiling plan ng mga posisyon ng template
5. I-click ang **Apply**. Naka-check ang **Order of Service** bilang default; kailangang may check ang kahit isa sa dalawa.

Kung may mga tala ang template, papalitan din ng paglalapat nito ang mga tala ng mga napiling plan ng mga tala ng template.

:::warning
Ang paglalapat ng posisyon ay nagpapalit sa lahat ng umiiral na posisyon at assignment sa mga napiling plan. Siguraduhing hindi mo pa naiiskedyul ang mga volunteer sa mga posisyong iyon bago ilapat.
:::

:::tip
Ilapat ang Order of Service nang walang Positions kapag gusto mo ng pare-parehong istruktura ng kanta/sermon, pero iba-iba ang naitatalagang volunteer kada linggo.
:::

## Pagsisimula ng Bagong Plan mula sa Template {#starting-a-new-plan-from-a-template}

Pinagbabahagi ang mga template sa mga plan type ng isang ministry. Kapag na-click mo ang **New Plan** at may mga template ang ministry, may kasamang listahang **Start from template** ang bagong plan form. Pumili ng template at i-save, at gagawin ang bagong plan kasama ang order of service, mga posisyon, at mga tala ng template. Ang pagpili ng template ay pumapalit sa mga opsyong **Copy from Previous Plan** para sa plan na iyon.

## Pagpapanatiling Updated ng mga Template {#keeping-templates-up-to-date}

Kung nagbago ang iyong karaniwang istruktura ng serbisyo, buksan ang template manager, i-click ang **Update from plan**, piliin ang plan na kokopyahan, at i-click ang **Save** para i-sync ang template mula sa pinakabago mong plan sa halip na buuin muli ito mula sa simula. Nag-aalok ang listahan ng bawat plan ng uring ito, nakaraan man o paparating.
