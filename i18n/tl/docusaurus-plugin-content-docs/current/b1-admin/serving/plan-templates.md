# Plan Templates

<div class="article-intro">

Ang mga template ng plan ay nagbibigay-daan sa iyo na mag-save ng isang reusable snapshot ng order ng serbisyo o mga posisyon ng isang plan at ilapat ito sa mga hinaharap na plan sa isang click. Sa halip na muling itayo ang parehong istruktura bawat linggo, iyong ito minsan at i-stamp ito sa maraming darating na mga plan na kailangan mo.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Lumikha ng hindi bababa sa isang [service plan](plans.md) na may order ng serbisyo o mga posisyon na tinukoy
- Kailangan mo ng access sa Serving area sa B1 Admin

</div>

## Pag-save ng Isang Plan bilang Isang Template

1. Buksan ang isang umiiral na plan mula sa **Serving** area.
2. Sa seksyong **Order of Service** ng plan, i-click ang **Save as Template**.
3. Bigyan ng pangalan ang template (halimbawa, "Standard Sunday" o "Worship + Sermon").
4. I-save. Ang template ay kumukuha ng order ng serbisyo, mga posisyon, at mga tala ng plan sa sandaling iyon.

## Pag-manage ng Mga Template

I-click ang **Templates** sa itaas ng listahan ng plan sa kahit anong pahina ng uri ng plan para buksan ang **Plan Templates**. Mula roon ay maaari mong:

- **Rename** — baguhin ang pangalan ng display ng template
- **Update from plan** — palitan ang nilalaman ng template ng kasalukuyang kalagayan ng isang plan (kapaki-pakinabang pagkatapos ng pag-refine ng iyong standard structure)
- **Apply** — i-stamp ang template sa isa o maraming darating na mga plan
- **Delete** — alisin ang template na hindi mo na kailangan

## Paglalapat ng Template sa Plans

1. I-click ang **Templates** sa itaas ng listahan ng plan sa pahina ng uri ng plan.
2. I-click ang **Apply** icon (copy icon) sa tabi ng template na gusto mong gamitin.
3. Piliin kung aling mga darating na plan ang ilalapat sa pamamagitan ng pagsuri sa kanilang mga kahon.
4. Pumili kung ano ang kopya:
   - **Order of Service** — palitan ang mga item ng order ng serbisyo ng mga napiling plan sa mga item ng template
   - **Positions** — palitan ang mga posisyon ng mga napiling plan (at ang kanilang assignments) sa mga posisyon ng template
5. I-click ang **Apply**.

Kung may mga tala ang template, ang pag-apply nito ay papalitan din ang mga tala ng mga napiling plan ng mga tala ng template.

:::warning
Ang paglalapat ng mga posisyon ay nagpapalitan sa lahat ng umiiral na mga posisyon at assignment sa mga napiling plan. Tiyakin na hindi mo pa na-schedule ang mga volunteer para sa mga posisyong iyon bago mag-apply.
:::

:::tip
Ilapat ang Order of Service nang walang Positions kapag gusto mo ng isang pare-parehong kanta/sermon structure ngunit ang mga volunteer ay na-assign na nang iba bawat linggo.
:::

## Pagsisimula ng Bagong Plan mula sa Template {#starting-a-new-plan-from-a-template}

Nakabahagi ang mga template sa mga plan type sa loob ng isang ministry. Kapag na-click ninyo ang **New Plan** at may mga template ang ministry, may kasamang listahan na **Start from template** ang form ng bagong plan. Pumili ng template at i-save, at gagawin ang bagong plan kasama ang order of service, mga posisyon, at mga tala ng template. Ang pagpili ng template ay papalitan ang mga opsyon na **Copy from Previous Plan** para sa plan na iyon.

## Panatilihing Updated ang Mga Template

Kung ang iyong standard na istruktura ng serbisyo ay nagbabago, buksan ang template manager at gamitin ang **Update from plan** upang i-sync ang template mula sa iyong pinakabagong plan sa halip na muling itayo ito mula simula.
