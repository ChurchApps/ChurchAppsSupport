# Mga Kanta

<div class="article-intro">

Pinamamahalaan ng pahinang Songs ang iyong library ng worship song. Panatilihin ang lahat ng detalye, lyrics, at arrangement ng kanta sa iisang lugar para madaling makapaghanda ang iyong worship team para sa mga paparating na serbisyo at mapanatili ang pare-parehong repertoire.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Sa [Jump menu](../introduction.md#getting-around-with-the-jump-menu) ng B1 Admin, piliin ang **Serving > Songs** para mapuntahan ang pahinang Songs
- Opsyonal, i-set up muna ang iyong [service plans](./plans.md) para direktang maiugnay ang mga kanta sa [service order](./service-order.md)

</div>

## Pag-browse sa Iyong Song Library {#browsing-your-song-library}

Kapag binuksan mo ang pahinang **Songs**, nakalista ang iyong mga kanta sa isang table. Ipinapakita ng bawat row ang thumbnail image, pamagat, artist, at tagal ng kanta. Gamitin ang mga kontrol ng pahina sa ilalim ng listahan para mag-navigate sa malaking library, o maghanap para mahanap ang kailangan mo.

## Paghahanap ng Kanta {#searching-for-songs}

1. I-click ang kahong **Search Songs** sa itaas ng pahinang Songs.
2. I-type ang **pamagat** ng kanta o pangalan ng **artist**.
3. Nag-fi-filter ang listahan habang nagta-type ka, at ipinapakita ang mga kantang tumutugma mula sa iyong library at kung ilan ang tumugma. I-click ang **Clear** para ipakitang muli ang lahat ng kanta.

## Pagdaragdag ng Kanta {#adding-a-song}

1. I-click ang **Add Song** sa itaas ng pahinang Songs.
2. Sa **Search for a Song**, hanapin ang external na song database ayon sa **Title or Artist**.
3. Piliin ang kantang gusto mong idagdag, o i-click ang **Create Manually** kung hindi mo ito makita.
4. Idadagdag ang kanta sa iyong library na may mga pangunahing detalye na nakapuno na.

:::tip
Pagkatapos magdagdag ng kanta, i-click ito para suriin at i-update ang mga detalye nito, magdagdag ng arrangement, o maglakip ng mga external link gaya ng mga video sa YouTube o chord chart.
:::

### Mga Libreng Kanta mula sa WorshipCommons {#free-songs-from-worshipcommons}

Maaaring may kasama ring seksyong **WorshipCommons — free** ang iyong mga resulta ng paghahanap, sa tabi ng karaniwang resulta. Ito ay mga kantang handa na para sa Linggo mula sa [WorshipCommons](https://worshipcommons.org) na nasuri at nalisensyahan na para sa paggamit sa pagsamba. Ang bawat resulta ay nagpapakita ng license badge -- **Free for worship** o **Public domain** -- para malaman mo ang mga tuntunin bago mo ito idagdag.

- I-click ang isang resulta ng WorshipCommons para idagdag ito sa iyong library, gaya ng karaniwang resulta ng paghahanap.
- I-click ang **View on WorshipCommons** para buksan ang orihinal na listing sa bagong tab.

Tanging ang mga kantang pumasa sa proseso ng pagsusuri ng WorshipCommons ang lumalabas dito, kaya maaaring mas kaunti ang pagpipilian kaysa sa pangunahing song database.

Para mag-browse sa buong library ng WorshipCommons, mag-print ng chart, o mag-export ng slide, tingnan ang [WorshipCommons docs](../../worship-commons/index.md).

## Pagbura ng Kanta {#deleting-songs}

Lagyan ng check ang kahon sa tabi ng isa o higit pang kanta (o ang kahon sa header para piliin ang lahat ng kantang nakikita), pagkatapos i-click ang **Delete Selected** sa bar na lalabas at kumpirmahin. I-click ang **Clear** para alisin ang pagkakapili.

## Pagtingin at Pag-edit ng Kanta {#viewing-and-editing-a-song}

I-click ang pamagat ng kanta para buksan ang detail page nito. Lalabas sa kaliwa ang pamagat, artist, at mga detalye ng kanta gaya ng album, susi, haba, BPM, at meter, kasama ang mga arrangement at external link nito. Pupunuin ng napiling arrangement, kasama ang lyrics at mga susi nito, ang natitirang bahagi ng pahina. Mula rito, maaari kang:

- **I-edit ang detalye ng kanta** -- I-click ang **Edit** para i-update ang pamagat, artist, tagal, at iba pang metadata. I-click ang **Done** kapag tapos ka na. Para alisin ang kanta sa iyong library, i-click ang **Edit** at pagkatapos ang **Delete song**.
- **Pamahalaan ang mga arrangement** -- Maaaring magkaroon ng maraming arrangement ang bawat kanta (halimbawa, iba't ibang susi o bersyon). I-click ang **Add Arrangement** para gumawa ng isa, at i-click ang pangalan ng isang arrangement sa ilalim ng **Arrangements** para buksan ito.
- **Magdagdag ng lyrics** -- I-click ang **Edit** sa tabi ng pangalan ng arrangement para baguhin ang pangalan, BPM, meter, haba, sequence, at lyrics nito. Ilagay ang lyrics gamit ang ChordPro notation (halimbawa, `[G]Amazing grace`). Ang live preview sa tabi ng editor ay nagre-render ng naka-format na chord chart habang nagta-type ka, kaya makikita mo nang eksakto ang makikita ng iyong team.
- **Itakda ang susi** -- Tukuyin ang musical key ng bawat arrangement gamit ang **Key** picker sa itaas ng lyrics. Inililista ng picker ang mga susi ayon sa karaniwang pagkakasulat ng mga musikero (C, Db, D, Eb, E, F, F#, G, Ab, A, Bb, B). Ang pagbago ng susi ay agad na nagta-transpose ng ipinapakitang chord, kapwa sa arrangement page at kapag binuksan ang kanta mula sa service plan, kaya laging nakikita ng iyong team ang mga chord sa susing talagang tinutugtog nila. Binabaybay ang mga chord ayon sa susi: ang mga flat na susi gaya ng Bb o Eb ay nagpapakita ng flat na pangalan ng chord (Bb, Eb, Ab) sa halip na sharp.
- **Magdagdag ng external link** -- I-click ang **Edit** sa tabi ng **External Links** sa kaliwa para i-link ang kanta sa mga serbisyo gaya ng YouTube, Spotify, Apple, CCLI, o Hymnary. Ang mga link sa chord chart o sheet music na naka-host sa ibang lugar ay inilalagay sa isang susi (tingnan ang **Manage keys**).
- **Pamahalaan ang mga susi** -- Sa ilalim ng **Keys**, i-click ang **Add key** para magdagdag ng susi kung saan tinutugtog ang arrangement (isang **Key Signature** at opsyonal na label, gaya ng "John's Key"). Pumili ng susi at i-click ang **Add Files** para sa **Import from PraiseCharts**, **Add External Link** para sa susing iyon (gaya ng chord chart sa susing iyon), o **Upload Audio**.

## Mga Arrangement {#arrangements}

Ang arrangement ay kumakatawan sa isang natatanging bersyon ng kanta -- halimbawa, mas mabilis na modernong bersyon laban sa mas mabagal na acoustic na bersyon, o ang parehong kanta sa ibang susi para sa ibang team. Ang bawat arrangement ng parehong kanta ay nagbabahagi ng pamagat at artist ng kanta, pero may sariling independenteng settings:

- **Key** -- ang musical key kung saan tinutugtog ang arrangement
- **BPM** -- tempo sa beats kada minuto
- **Length** -- tagal sa segundo
- **Meter** -- time signature (hal., 4/4, 3/4, 6/8)
- **Sequence** -- ang istruktura ng chord/seksyon (hal., Intro → Verse → Chorus → Bridge)
- **Lyrics** -- para sa display o projection
- **External links** -- mga chord chart, YouTube recording, sheet music, o iba pang mapagkukunan

Kapag nagdagdag ka ng kanta sa isang [Service Order](./service-order.md), maaari mong piliin kung aling arrangement ang gagamitin para sa partikular na serbisyong iyon, para palagi nang nagpa-practice at tumutugtog ang iyong team ng tamang bersyon.

### Rehearsal Audio {#rehearsal-audio}

Maaaring maglakip ang mga worship admin ng rehearsal audio track sa isang arrangement para makapakinig nang maaga ang team bago mag-practice:

1. Buksan ang kanta at piliin ang arrangement.
2. Sa ilalim ng **Keys**, pumili ng susi (i-click muna ang **Add key** kung walang susi ang arrangement), i-click ang **Add Files**, at piliin ang **Upload Audio**.
3. Pumili ng MP3, M4A, o AAC file (hanggang 25 MB -- hindi tinatanggap ang WAV, para manatiling madali ang paggamit ng storage).
4. I-click ang **Save**. Tumutugtog ang track nang inline saanman lumitaw ang arrangement na iyon -- sa arrangement page sa B1 Admin at sa service plan kapag binuksan ito ng isang miyembro ng team sa B1.church member portal. Ang mga plan item na may audio ay nagpapakita ng music-note icon sa halip na thumbnail.

Kapag binura ang arrangement, nabubura rin ang na-upload nitong audio file.

:::info
Maaaring idagdag nang diretso sa [Service Order](./service-order.md) sa loob ng isang plan ang mga kanta mula sa iyong library, at iniuugnay ang mga detalye ng kanta at ang napiling arrangement sa partikular na serbisyong iyon.
:::
