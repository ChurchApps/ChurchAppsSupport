# Mga Kanta

<div class="article-intro">

Ang pahina ng Mga Kanta ang namamahala sa iyong koleksyon ng mga kanta para sa pagsamba. Itago ang lahat ng detalye ng kanta, liriko, at mga ayos sa iisang lugar upang madaling maihanda ng iyong worship team ang mga darating na serbisyo at mapanatili ang pare-parehong repertoryo.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Sa [Jump menu](../introduction.md#getting-around-with-the-jump-menu) sa B1 Admin, piliin ang **Serving > Songs** upang pumunta sa pahina ng Mga Kanta
- Opsyonal, ihanda muna ang iyong [mga plano ng serbisyo](./plans.md) upang direktang maidagdag ang mga kanta sa [pagkakasunod-sunod ng serbisyo](./service-order.md)

</div>

## Pagbrowse sa Iyong Koleksyon ng Kanta

Kapag binuksan mo ang pahina ng **Songs**, nakalista ang iyong mga kanta sa isang talahanayan. Ipinapakita ng bawat hilera ang thumbnail na larawan, pamagat, artist, at tagal ng kanta. Gamitin ang mga kontrol ng pahina sa ilalim ng listahan upang lumipat sa malaking koleksyon, o maghanap upang mahanap ang kailangan mo.

## Paghahanap ng mga Kanta

1. I-click ang kahon na **Search Songs** sa itaas ng pahina ng Mga Kanta.
2. I-type ang **pamagat** ng kanta o pangalan ng **artist**.
3. Nagfi-filter ang listahan habang nagta-type ka, at ipinapakita ang mga kantang tugma mula sa iyong koleksyon at kung ilan ang tumugma. I-click ang **Clear** upang ipakitang muli ang lahat ng kanta.

## Pagdaragdag ng Kanta

1. I-click ang **Add Song** sa itaas ng pahina ng Mga Kanta.
2. Sa **Search for a Song**, hanapin ang external na database ng mga kanta sa pamamagitan ng **Title or Artist**.
3. Piliin ang kantang nais mong idagdag, o i-click ang **Create Manually** kung hindi mo ito makita.
4. Idadagdag ang kanta sa iyong koleksyon kasama ang mga pangunahing detalye nito na naka-pre-fill na.

:::tip
Pagkatapos magdagdag ng kanta, i-click ito upang suriin at i-update ang mga detalye nito, magdagdag ng mga ayos, o maglakip ng mga external na link gaya ng mga video sa YouTube o mga chord chart.
:::

### Mga Libreng Kanta mula sa WorshipCommons

Maaaring may kasama ring seksyong **WorshipCommons — free** ang iyong mga resulta ng paghahanap, sa tabi ng karaniwang mga resulta. Ito ay mga kantang handa nang gamitin tuwing Linggo mula sa [WorshipCommons](https://worshipcommons.org) na nasuri na at nalisensyahan para sa pagsamba. Ipinapakita ng bawat resulta ang badge ng lisensya -- **Free for worship** o **Public domain** -- upang malaman mo ang mga tuntunin bago mo ito idagdag.

- I-click ang resulta mula sa WorshipCommons upang idagdag ito sa iyong koleksyon, katulad ng karaniwang resulta ng paghahanap.
- I-click ang **View on WorshipCommons** upang buksan ang orihinal na listahan sa bagong tab.

Tanging ang mga kantang pumasa sa proseso ng pagsusuri ng WorshipCommons ang lumalabas dito, kaya maaaring mas maliit ang seleksyon kaysa sa pangunahing database ng kanta.

Upang i-browse ang buong koleksyon ng WorshipCommons, mag-print ng mga chart, o mag-export ng mga slide, tingnan ang [mga dokumento ng WorshipCommons](../../worship-commons/index.md).

## Pagbubura ng Mga Kanta

Lagyan ng tsek ang kahon sa tabi ng isa o higit pang kanta (o ang kahon sa header upang piliin ang lahat ng kantang ipinapakita), pagkatapos ay i-click ang **Delete Selected** sa bar na lilitaw at kumpirmahin. I-click ang **Clear** upang alisin ang pagpili.

## Pagtingin at Pag-edit ng Kanta

I-click ang pamagat ng kanta upang buksan ang detail page nito. Lumalabas sa kaliwa ang pamagat, artist, at mga detalye gaya ng album, key, haba, BPM, at meter ng kanta, kasama ang mga ayos at external na link nito. Mula rito, maaari mong:

- **I-edit ang mga detalye ng kanta** -- I-click ang **Edit** upang i-update ang pamagat, artist, tagal, at iba pang metadata. I-click ang **Done** kapag tapos ka na. Upang alisin ang kanta sa iyong koleksyon, i-click ang **Edit** at pagkatapos ay ang **Delete song**.
- **Pamahalaan ang mga ayos** -- Maaaring magkaroon ng maraming ayos ang bawat kanta (halimbawa, magkaibang key o bersyon). I-click ang **Add Arrangement** upang gumawa ng isa, at i-click ang pangalan ng ayos sa ilalim ng **Arrangements** upang buksan ito.
- **Magdagdag ng liriko** -- Ilagay o i-update ang liriko para sa bawat ayos gamit ang notasyong ChordPro (halimbawa, `[G]Amazing grace`). Ipinapakita ng live preview sa tabi ng editor ang naka-format na chord chart habang nagta-type ka, kaya makikita mo nang eksakto ang makikita ng iyong team.
- **Itakda ang key** -- Tukuyin ang musical key ng bawat ayos gamit ang key picker sa tabi ng liriko. Nakalista sa picker ang mga key ayon sa karaniwang pagsulat ng mga musikero (C, Db, D, Eb, E, F, F#, G, Ab, A, Bb, B). Kapag binago ang key, agad na nagta-transpose ang mga ipinapakitang chord, kapwa sa pahina ng ayos at kapag binuksan ang kanta mula sa plano ng serbisyo, kaya laging nakikita ng iyong team ang mga chord sa key na aktwal nilang tutugtugin. Binabaybay ang mga chord ayon sa key: ang mga flat key gaya ng Bb o Eb ay nagpapakita ng flat na pangalan ng chord (Bb, Eb, Ab) sa halip na sharp.
- **Magdagdag ng external na link** -- Maglakip ng mga link sa mga mapagkukunan gaya ng mga video sa YouTube, chord chart, o sheet music na naka-host sa ibang lugar.

## Mga Ayos

Ang ayos ay kumakatawan sa natatanging bersyon ng isang kanta -- halimbawa, isang mas mabilis na modernong bersyon kumpara sa mas mabagal na acoustic na bersyon, o ang parehong kanta sa ibang key para sa ibang team. Nagbabahagi ng pamagat at artist ng kanta ang bawat ayos ng iisang kanta, ngunit may sarili itong independiyenteng mga setting:

- **Key** -- ang musical key kung saan itinatanghal ang ayos
- **BPM** -- tempo sa beats per minute
- **Length** -- tagal sa segundo
- **Meter** -- time signature (hal., 4/4, 3/4, 6/8)
- **Sequence** -- ang istruktura ng chord/seksyon (hal., Intro → Verse → Chorus → Bridge)
- **Lyrics** -- para sa pagpapakita o projection
- **External links** -- chord chart, mga recording sa YouTube, sheet music, o iba pang mapagkukunan

Kapag nagdagdag ka ng kanta sa isang [Service Order](./service-order.md), maaari mong piliin kung aling ayos ang gagamitin para sa partikular na serbisyong iyon, upang laging maeensayo at matutugtog ng iyong team ang tamang bersyon.

### Audio para sa Pag-eensayo

Maaaring maglakip ang mga worship admin ng audio track para sa pag-eensayo sa isang ayos upang makapakinig nang maaga ang team bago ang practice:

1. Buksan ang kanta at piliin ang ayos.
2. I-click ang **Upload Audio**.
3. Pumili ng MP3, M4A, o AAC na file (hanggang 25 MB -- hindi tinatanggap ang WAV upang mapanatiling mababa ang paggamit ng storage).
4. I-save. Tutugtog ang track sa mismong lugar kung saan lumilitaw ang ayos na iyon -- sa pahina ng ayos sa B1 Admin at sa plano ng serbisyo kapag binuksan ito ng miyembro ng team sa member portal ng B1.church. Ang mga item ng plano na may audio ay nagpapakita ng icon na nota ng musika sa halip na thumbnail.

Kapag binura ang ayos, binubura rin ang na-upload nitong audio file.

:::info
Ang mga kanta mula sa iyong koleksyon ay maaaring direktang idagdag sa isang [Service Order](./service-order.md) sa loob ng isang plano, na nagli-link sa mga detalye ng kanta at sa piniling ayos para sa partikular na serbisyong iyon.
:::
