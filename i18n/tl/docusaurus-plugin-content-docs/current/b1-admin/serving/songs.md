# Mga Kanta

<div class="article-intro">

Ang Songs page ay namamahala sa iyong worship song library. Panatilihin ang lahat ng iyong mga detalye ng kanta, lyrics, at mga arrangement sa isang lugar upang ang iyong worship team ay maaaring madaling maghanda para sa mga susunod na serbisyo at mapanatili ang isang consistent na repertoire.

</div>

<div class="prereqs">
<h4>Bago Kang Magsimula</h4>

- Mag-navigate sa **Serving** section sa B1 Admin upang ma-access ang Songs page
- Opsyonal, magkaroon ng iyong [service plans](./plans.md) na na-set up upang maaari mong direktang iugnay ang mga kanta sa [service order](./service-order.md)

</div>

## Pagbrowse sa Iyong Song Library

Kapag binuksan mo ang **Songs** page, ang iyong mga kanta ay ipinapakita bilang mga card. Bawat card ay nagpapakita ng thumbnail image ng kanta, pamagat, artist, at tumatagal. Mag-scroll sa library o gumamit ng search upang makahanap ng kung ano ang kailangan mo.

## Paghahanap ng Mga Kanta

1. I-click ang **Search** button sa Songs page.
2. I-type ang kanta **title** o **artist** name.
3. Ang mga resulta ay fil-filter habang nag-type ka, na nagpapakita ng mga kanta na tumutugma mula sa iyong library.

## Pagdaragdag ng Isang Kanta

1. I-click ang **Add Song** sa Songs page.
2. Maghanap sa external song database sa pamamagitan ng pamagat o artist.
3. Pumili ng kanta na gusto mong idagdag.
4. Ang kanta ay maidadagdag sa iyong library na may mga pangunahing detalye na pre-filled.

:::tip
Pagkatapos magdagdag ng kanta, i-click ito upang suriin at i-update ang mga detalye nito, magdagdag ng mga arrangement, o mag-attach ng mga external link tulad ng YouTube videos o chord charts.
:::

## Pagtingin at Pag-edit ng Isang Kanta

I-click ang anumang card ng kanta upang buksan ang detalye nito. Mula dito maaari mong:

- **Edit song details** -- I-update ang pamagat, artist, tumatagal, at ibang metadata.
- **Manage arrangements** -- Bawat kanta ay maaaring magkaroon ng maraming mga arrangement (halimbawa, iba't ibang mga susi o bersyon). Magdagdag, mag-edit, o alisin ang mga arrangement ayon sa pangangailangan.
- **Add lyrics** -- Magpasok o mag-update ng lyrics para sa bawat arrangement.
- **Set the key** -- Tukuyin ang musical key para sa bawat arrangement gamit ang key picker sa tabi ng lyrics. Ang pagbabago ng key ay transpose ang ipinapakitang chords kaagad, kapwa sa arrangement page at kapag bumubukas ng kanta mula sa service plan, kaya ang iyong team ay laging nakakakita ng chords sa susi na aktwal nilang ginagamit.
- **Add external links** -- Mag-attach ng mga link sa mga mapagkukunan tulad ng YouTube videos, chord charts, o sheet music na ino-host sa ibang lugar.

## Arrangements

Ang arrangement ay kumakatawan sa isang natatanging bersyon ng isang kanta — halimbawa, isang mas mabilis na modernong bersyon kumpara sa isang mas malambot na acoustic take, o ang parehong kanta sa ibang susi para sa ibang team. Bawat arrangement ng parehong kanta ay nagbabahagi ng pamagat ng kanta at artist ngunit may sariling mga setting:

- **Key** — ang musical key na ginagamit ang arrangement
- **BPM** — tempo sa beats per minute
- **Length** — tumatagal sa mga segundo
- **Meter** — time signature (halimbawa, 4/4, 3/4, 6/8)
- **Sequence** — ang chord/section structure (halimbawa, Intro → Verse → Chorus → Bridge)
- **Lyrics** — para sa display o projection
- **External links** — chord charts, YouTube recordings, sheet music, o iba pang mga mapagkukunan

Kapag nagdagdag ka ng kanta sa isang [Service Order](./service-order.md), maaari mong piliin kung aling arrangement ang gamitin para sa partikular na serbisyo, upang ang iyong team ay laging nagsasanay at tumutugtog ng tamang bersyon.

### Rehearsal Audio

Ang mga worship admins ay maaaring mag-attach ng rehearsal audio track sa isang arrangement upang ang team ay maaaring makinig nang maaga bago ang pagsasanay:

1. Buksan ang kanta at piliin ang arrangement.
2. I-click ang **Upload Audio**.
3. Pumili ng isang MP3, M4A, o AAC file (hanggang 25 MB -- ang WAV ay hindi tinatanggap, upang panatilihing manageable ang storage usage).
4. I-save. Ang track ay tumutugtog inline kahit saan lumilitaw ang arrangement na ito -- sa arrangement page sa B1 Admin at sa service plan kapag binuksan ito ng isang miyembro ng team sa B1.church member portal. Ang mga item ng plano na may audio ay nagpapakita ng isang music-note icon sa halip na isang thumbnail.

Ang pagtanggal ng arrangement ay naglalakbay din ng naka-upload na audio file nito.

:::info
Ang mga kanta mula sa iyong library ay maaaring direktang idagdag sa isang [Service Order](./service-order.md) sa loob ng isang plano, na nag-link ng mga detalye ng kanta at ang piniling arrangement sa partikular na serbisyo.
:::
