# Plans Overview

<div class="article-intro">

Binibigyan kayo ng Plans Overview ng malawak na tanaw sa lahat ng assignment ng inyong mga boluntaryo sa maraming petsa ng service nang sabay-sabay. Sa halip na buksan ang bawat plano nang isa-isa, makikita ninyo kung sino ang naglilingkod sa bawat posisyon sa mga darating na linggo sa iisang grid -- at mabilis ninyong makikita ang anumang kulang na kailangan pang punan.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Gumawa ng kahit isang Ministry at Plan Type sa lugar ng Serving
- Gumawa ng [mga plano ng service](./plans.md) na may mga petsa at assignment ng boluntaryo
- Tiyaking naidagdag na ang inyong mga boluntaryo sa [direktoryo ng mga tao](../people/adding-people.md)

</div>

## Pag-access sa Overview

1. Sa B1 Admin, buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas), i-expand ang **Serving**, at i-click ang **Plans**.
2. Pumili ng **tab ng ministry** sa itaas ng pahina.
3. I-click ang isang **plan type** para buksan ang listahan ng mga plano nito.
4. I-click ang button na **Overview** malapit sa itaas ng pahina.

## Pagbasa sa Overview Grid

Nagpapakita ang overview ng grid kung saan:

- Ang **Rows** ay kumakatawan sa bawat posisyon (hal., "Music: Guitar", "Tech: Projection") na naka-grupo ayon sa kategorya
- Ang **Columns** ay kumakatawan sa mga paparating na petsa ng service (hal., "Apr 14", "Apr 21")
- Ipinapakita ng **Cells** ang pangalan ng boluntaryong nakatalaga sa posisyong iyon sa petsang iyon

Ang mga cell na naka-highlight ng **pula** ay hindi pa napupunan -- wala pang boluntaryong naitalaga. Dahil dito, madali ninyong makikita ang mga kulang sa tauhan sa isang tingin nang hindi binubuksan ang bawat plano.

:::tip
Ipinapakita ang mga pangalan ng boluntaryo sa pinaikling format (unang pangalan at inisyal ng apelyido, hal., "John D.") para manatiling compact ang grid kapag marami kayong posisyon.
:::

## Direktang Pagtatalaga ng mga Boluntaryo mula sa Overview

Hindi ninyo kailangang buksan ang mga indibidwal na plano para punan ang mga bakanteng slot. I-click ang anumang cell sa grid para buksan ang assignment panel para sa posisyon at petsang iyon. Mula roon, maaari ninyong:

- Pumili ng isang tao mula sa inyong team na itatalaga sa posisyon
- I-click ang **Remove** sa tabi ng sinumang nakatalaga na para alisin sila sa slot na iyon
- I-save ang pagbabago nang hindi umaalis sa overview

Dahil dito, posibleng mapunan ang buong iskedyul nang minsanan -- magtrabaho sa iba't ibang linggo at posisyon nang hindi pabalik-balik sa mga indibidwal na plano.

## Auto-Scheduling mula sa Overview

I-click ang **Auto-Schedule** para punan ng B1 ang bawat bakante at hindi pa napupunang slot sa kasalukuyang grid nang sabay-sabay. Para sa bawat planong nakikita, kumukuha ito ng mga kandidato mula sa grupong naka-link sa bawat posisyon at awtomatikong pinupunan ang mga bakanteng slot, at iuulat kung ilan sa mga nakikitang plano ang nagawa nitong punan. Pinupunan ang mga plano nang isa-isa para hindi ma-double-book ang parehong boluntaryo sa dalawang petsa sa iisang pagkakataon.

:::info
Pinupunan lamang ng Auto-Schedule ang mga slot na bakante na -- hindi nito kailanman pinapalitan ang kasalukuyang assignment.
:::

## Pag-email sa Lahat ng Naka-iskedyul

I-click ang **Email Volunteers** para magpadala ng abiso sa bawat boluntaryong nakatalaga saanman sa kasalukuyang naka-filter na saklaw ng petsa at ministry, sa isang aksyon lamang, sa halip na mag-email plano por plano. Iuulat ng B1 kung ilang email ang naipadala at ilan ang nabigo.

## Pag-highlight sa Iskedyul ng Isang Boluntaryo

Gamitin ang dropdown na **Highlight** para pumili ng isang tao mula sa inyong team -- bawat cell kung saan sila nakatalaga ay ipo-point out sa grid, para makita ninyo kung saan-saan na sila naglilingkod bago sila idagdag sa isa pang slot. Piliin ang **Everyone** para i-off ang highlight.

## Pag-filter sa Overview

Maaari ninyong ayusin kung ano ang ipinapakita ng overview gamit ang mga filter control sa itaas:

- **Start Date / End Date** -- Bilang default, ipinapakita ng overview ang susunod na 12 linggo. Maglagay ng sariling mga petsa para palawakin o paliitin ang saklaw.
- **Ministry** -- Lumipat sa ibang ministry nang hindi umaalis sa overview.
- **Plan Type** -- I-filter sa isang partikular na plan type sa loob ng napiling ministry.
- **Unfilled only** -- I-on ito para itago ang mga row kung saan napunan na ang lahat ng petsa, para makapag-focus lamang kayo sa mga posisyong kailangan pa ng boluntaryo.

I-click ang **Filter** pagkatapos gumawa ng mga pagbabago para i-update ang grid.

## Pag-export sa CSV

I-click ang **Export CSV** para i-download ang kasalukuyang grid bilang spreadsheet. Kasama sa export ang lahat ng posisyon at assignment ng boluntaryo para sa naka-filter na saklaw ng petsa, kaya madali itong ibahagi sa mga lider ng ministry o i-print para sa mga pulong sa pagpaplano.

:::info
Sinasalamin ng CSV export ang anumang filter na kasalukuyang naka-apply -- tanging ang mga petsa at plan type na ipinapakita sa grid ang kasama sa download.
:::
