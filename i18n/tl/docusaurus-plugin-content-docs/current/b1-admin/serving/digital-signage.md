# Digital Signage

<div class="article-intro">

Ipadala ang iyong nilalaman ng lesson sa TV sa lobby o pasilyo gamit ang digital signage feed. Bawat uri ng plan ay may feed URL na palaging nagpapakita ng nilalaman ng kasalukuyang plan, kaya walang kailangang i-update linggo-linggo. Kung ang iyong mga TV ay gumagamit ng FreePlay, maaari mo na lang iiskedyul ang uri ng plan sa kanila sa FreePlay Admin.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Mag-set up ng [uri ng plan](./plans.md) gamit ang [Lessons.church](../../b1-church/content/lessons.md) o iba pang nilalaman ng lesson na naka-iskedyul
- Magkaroon ng account sa [SignPresenter](https://www.signpresenter.com) at device na naka-set up para ipakita ito, o TV na may [FreePlay](../../freeplay/)

</div>

## Pagkuha ng Feed URL

1. Pumunta sa **Serving**, piliin ang ministry na naglalaman ng iyong uri ng plan, at i-click ang uri ng plan para buksan ito.
2. I-click ang **Digital Signage** (ang icon ng TV) sa itaas ng pahina ng uri ng plan.
3. Sa dialog na **Digital Signage Feed**, i-click ang copy button sa tabi ng **Feed Url**.

:::info
Ang feed URL ay naka-ugnay sa uri ng plan, hindi sa isang partikular na plan. Awtomatiko nitong sinusubaybayan kung aling plan ang kasalukuyang naka-iskedyul para sa uri ng plan na iyon, kaya kailangan mo lang itong i-set up nang isang beses.
:::

## Pagkonekta sa SignPresenter

Ginawa ang feed para gumana kasama ang [SignPresenter](https://www.signpresenter.com), isang third-party na digital signage app. I-paste ang kinopyang URL sa SignPresenter bilang external feed para maipakita ang kasalukuyang nilalaman ng lesson sa konektadong screen.

Para sa hakbang-hakbang na setup sa loob ng SignPresenter, tingnan ang [gabay ng SignPresenter para sa Lessons.church](https://support.signpresenter.com/topics/lessons-dot-church.html). Naka-link din sa dialog ang mga tagubiling ito.

## Paggamit ng FreePlay TV sa Halip

Kung ang iyong mga screen ay gumagamit ng [FreePlay](../../freeplay/), hindi mo na kailangan ang feed URL. Naka-link sa dialog na **Digital Signage Feed** ang **admin.freeplay.church/calendar**, kung saan maaari mong iiskedyul ang uri ng plan na ito sa iyong mga FreePlay TV:

1. I-click ang link na **admin.freeplay.church/calendar** sa dialog. Ginagamit ng FreePlay Admin ang parehong login ng B1 Admin.
2. Piliin ang screen group para sa iyong mga TV at i-click ang **Add schedule**.
3. Sa ilalim ng **Play**, piliin ang iyong uri ng plan mula sa **Service plans**. Makikita ang markang **(current plan)**.
4. Itakda ang mga araw at oras, pagkatapos i-click ang **Save**.

Ipinapakita ng mga TV ang kasalukuyang plan para sa uri ng plan na iyon tuwing linggo, sa mga oras na itinakda mo. Gumagana rin ito sa mga lesson ng Go Curriculum, kasama ang mga plan na in-customize mo. Nag-sa-sign in ang FreePlay gamit ang Go Curriculum account na naka-link sa ministry sa ilalim ng **Content Providers** (tingnan ang [Scheduling Lessons](./scheduling-lessons.md)), o ang koneksyon ng simbahan sa Go Curriculum kung walang naka-link sa ministry. Tingnan ang [Scheduling the Calendar](../../freeplay/scheduled-mode/scheduling-the-calendar) para sa lahat ng opsyon, at ang [Pairing a Screen](../../freeplay/scheduled-mode/pairing-a-screen) para magdagdag ng TV.

:::note
Hindi kasama sa feed URL ang media ng Go Curriculum, dahil kailangan ng nilalamang iyon ang login ng simbahan mo sa Go Curriculum. Para maipakita ang lesson ng Go Curriculum sa TV sa lobby o classroom, gamitin ang FreePlay.
:::

## Mga Susunod na Hakbang

- Pamahalaan ang mga plan na nagpapakain sa signage display na ito sa pahinang [Plans](./plans.md)
- Mag-iskedyul ng nilalaman gamit ang [Lessons.church](./scheduling-lessons.md)
- Ilagay ang mga FreePlay TV sa kalendaryo gamit ang [Scheduled Mode](../../freeplay/scheduled-mode/)
