# Workflows

<div class="article-intro">

Ang mga workflow ay gumagalaw ng mga tao sa pamamagitan ng isang serye ng mga hakbang sa isang visual board. Bawat tao ay nagiging isang card na bumibiyahe mula sa isang hakbang tungo sa susunod -- mula sa isang first-time guest follow-up, tungo sa isang membership process, tungo sa isang first-time giver thank-you, at kahit anong iba pang kung saan kailangan mong subaybayan ang maraming mga tao sa pamamagitan ng parehong hanay ng yugto. Ang isang hakbang ay maaaring magtanong sa isang volunteer na gumawa ng isang bagay (gumawa ng tawag, makipag-usap) **at** magpatakbo ng mga automated na aksyon sa sarili nito -- magpadala ng email, maghintay ng ilang araw, idagdag ang tao sa isang grupo -- upang ang Workflows ay humawak ng parehong tao follow-up at ang busywork sa paligid nito.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Tiyakin na ang mga taong nais mong subaybayan ay umiiral sa B1 Admin
- Pamilyarisahin ang iyong sarili sa kung paano gumagana ang [Tasks](./tasks.md), dahil bawat card sa isang board ay isang gawain
- Upang gumamit ng **Send email** action, lumikha ng mga email template na nais mong magpadala muna (pinamamahalaan sa **Messaging → Manage Templates**)
- Kailangan mo ng naaasahang Tasks permission. Ang pagtingin, pag-edit ng mga card, at pag-manage ng mga workflow ay hiwalay na permission levels (tingnan ang [Roles & Permissions](../settings/roles-permissions.md))

</div>

## Pagtingin sa Mga Workflow

Mag-navigate sa **Serving**, buksan ang **Tasks** area, at piliin ang **Workflows** mula sa menu. Makikita mo ang iyong mga workflow na nakalista at naka-grupo sa pamamagitan ng kategorya, na ang mga active workflow ay naka-highlight. I-click ang kahit anong workflow upang buksan ang board nito.

## Lumilikha ng Workflow

1. Sa Workflows page, i-click ang **Add Workflow**.
2. Pumili kung paano magsimula:
   - **Blank workflow** -- magsimula mula simula at bumuo ng iyong sariling mga hakbang.
   - **From a template** -- magsimula sa isang ready-made na hanay ng mga hakbang na maaari mong i-edit. Ang mga built-in na template ay kasama ang:
     - **New Visitor Follow-up** -- Magpadala ng welcome email → Personal phone call → Mag-invite sa susunod na hakbang → Connected
     - **Membership Class** -- Ipahayag ang interes → Mag-register para sa klase → Dumalo sa klase → Kumpletuhin ang pagiging miyembro
     - **First-time Giver Thank-you** -- Magpadala ng thank-you note → Ibahagi ang giving impact → Stewarded
3. Bigyan ang workflow ng **Name**.
4. Opsyonal na magtalaaga ng **Category** upang pagsama-samahin ang mga kaugnay na workflow. Maaari kang lumikha ng bagong kategorya nang direkta mula sa dropdown.
5. Iwanan ang workflow **Active** upang ang mga tao ay maaaring idagdag dito, o itakda ito sa **Inactive** upang itago ito mula sa mga listahan ng add-to-workflow.
6. I-click ang **Save**.

Tingnan ang buong dokumentasyon para sa mga advanced features tulad ng Automated Actions at Routing.
