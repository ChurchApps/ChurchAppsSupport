# Service Order

<div class="article-intro">

Tinutukoy ng service order ang pagkakasunod-sunod ng mga elemento sa iyong worship service. Gamitin ito para ilatag ang lahat, mula sa unang kanta hanggang sa panapos na panalangin, para malaman ng buong team mo ang daloy ng serbisyo nang maaga.

## Pag-access sa Service Order {#accessing-the-service-order}

1. Pumunta sa **Serving** at piliin ang iyong ministry.
2. I-click ang isang **plan type**, pagkatapos buksan ang partikular na **plan**.
3. Ipinapakita ng plan page ang preview ng **Order of Service**. I-click ang **Edit order of service** (o **View order of service** kung hindi mo mae-edit ang plan) para buksan ang buong order of service sa sarili nitong pahina. I-click ang **Back to plan** para bumalik.

## Pagbuo ng Iyong Service Order {#building-your-service-order}

Ang service order ay listahan ng mga item na nakaayos ayon sa pagkakasunod-sunod ng mga ito sa serbisyo. Kabilang sa mga karaniwang elemento ang:

- Mga worship song
- Mga panalangin
- Mga pagbasa mula sa Kasulatan
- Mga anunsyo
- Sermon o mensahe
- Handog
- Pangwakas

## Pagdaragdag ng Item sa Service Order {#adding-items-to-the-service-order}

1. Sa pahinang **Order of Service**, i-click ang **Add** at piliin ang idadagdag: **Add Section** (heading na nagpapangkat ng mga item), **Item** (custom na item), **Song** (mula sa iyong library), o **Add From Lesson**. Maaari mo ring direktang i-click ang **Add Section**.
2. Para magdagdag ng bagay sa loob ng seksyon, gamitin ang add menu sa header ng seksyong iyon at piliin ang **Song**, **Item**, o **External Item**.
3. Ilagay ang mga detalye ng item, gaya ng pamagat at anumang tala.
4. I-click ang **Save**.

:::tip
Maaari kang magdagdag ng mga kanta nang direkta mula sa iyong [Songs](./songs.md) library. Iniuugnay nito ang mga detalye ng kanta, kabilang ang lyrics at arrangement, sa iyong service plan para may lahat ng kailangan ang iyong worship team. Kapag pumili ka ng kanta, ipinapakita ng bawat susing pagpipilian ang pangalan ng arrangement sa tabi ng susi, kaya madaling makilala ang mga arrangement na magkapareho ng susi.
:::

### Pag-import ng Maraming Item mula sa External Provider {#importing-multiple-items-from-an-external-provider}

Ang pagpili sa **External Item** (o **Add From Lesson**) ay nagbubukas ng browser para sa mga naka-link mong lesson provider sa halip na iisang form ng item. Mag-browse (o maghanap) sa content ng provider, at lagyan ng check ang kahon sa tabi ng bawat seksyon o aksyong gusto mo. Binibilang ng dialog kung ilan ang napili mo (halimbawa, "3 selected") -- i-click ang **Import (3)** para idagdag silang lahat sa service order nang sabay-sabay, sa halip na ulitin ang add-item flow para sa bawat isa.

Ang ilang provider, gaya ng GO! Curriculum, Dropbox, Google Drive, at OneDrive, ay naghahatid ng aralin bilang hanay ng mga file (video, slide, larawan) sa halip na mga seksyon. Kapag nag-browse ka sa isa sa mga ito sa **Add From Lesson**, lalabas ang mga file kasama ng mga folder -- i-click ang isang file para idagdag ito sa service order bilang sarili nitong item.

:::tip
Ito ang pinakamabilis na paraan para mailipat ang buong seksyon at cue ng isang aralin sa service order sa isang pagdaan lang, sa halip na idagdag ang bawat item nang isa-isa.
:::

### Pag-customize ng Naka-link na Aralin {#customizing-a-linked-lesson}

Para i-link ang buong aralin sa plan, i-click ang **Associate Lesson** sa itaas ng order of service at piliin ang aralin. Lilitaw ang pangalan ng aralin sa itaas ng order of service na may link na **Unlink** para alisin ito. (Ang mga planong ginawa gamit ang [Schedule Lesson](./scheduling-lessons.md) ay naka-link na.)

Kapag may naka-link na aralin ang isang plan, ipinapakita muna ng order of service ang **Lesson Preview** ng aralin. I-click ang **Customize** (o magdagdag ng seksyon, item, o kanta) para kopyahin ang mga seksyon ng aralin sa plan para maaari mong i-edit ang mga ito. Para sa mga araling listahan lamang ng mga file, gaya ng mga aralin ng GO! Curriculum, ang mga file ay pinagpapangkat sa ilalim ng seksyong ipinapangalan sa aralin, kaya mayroon ka pa ring section bar na pagdadagdagan ng sarili mong mga item.

## Pag-aayos ng Mga Item {#reordering-items}

I-drag ang mga item sa handle sa kaliwa ng bawat row para baguhin ang pagkakasunod-sunod -- i-drop sa asul na linya kung saan mo gustong pumunta ang item, o sa header ng seksyon para ilipat ito sa loob ng seksyong iyon. Ang pagkakasunod-sunod na nakikita sa screen ang siyang susundin ng iyong team habang nagseserbisyo.

## Pag-edit ng Seksyon ng Aralin {#editing-a-lesson-section}

Ang mga seksyon ng aralin at curriculum (halimbawa, "Large Group" o "Engage 1") ay naglalaman ng sarili nilang linya ng script, slide, at video. Para baguhin ang laman nito, i-click ang seksyon sa service order. Bubukas ang seksyon at ipapakita ang lahat ng nasa loob nito: ang mga linyang binibigkas at mga tagubilin ay lalabas bilang buong teksto na may markang **Say**, **Do**, o **Note**, at ang mga slide o video ay lalabas na may thumbnail.

- I-click ang **x** sa tabi ng anumang linya para alisin ito sa plan mo. Mananatili ito sa listahan, naka-strikethrough, na may arrow para ibalik ito.
- I-click ang alinmang teksto para baguhin ang pagkakasulat nito. Ang binagong linya ay nag-aalok ng **restore original wording**.
- I-click ang **Save**. Mananatiling iisang row ang seksyon sa service order mo, na may maliit na label gaya ng **6 of 8 items** para ipakitang na-customize mo ito, at nag-a-update ang tagal nito.

Buksan muli ang seksyon anumang oras para makita ang iyong mga pagbabago, ibalik ang mga linya, o piliin ang **Restore original section** para bawiin ang lahat ng ito. Ang iyong mga pag-edit ay nakakaapekto lamang sa plan mo -- hindi kailanman nababago ang orihinal na aralin -- at napupunta ang mga ito sa mga naka-print na plan at sa nakikita ng iyong mga volunteer.

Kung kailangan mo ng item mula sa seksyon bilang sarili nitong row (halimbawa, para maglagay ng kanta sa pagitan ng dalawang linya), i-click ang arrow sa kanang dulo ng row ng seksyon para ipakita ang laman nito bilang magkakahiwalay na row. I-click ang arrow sa unang row ng mga iyon para itupi silang muli sa iisang row. Gumagana ito sa parehong paraan para sa content ng anumang konektadong provider.

Ang mga volunteer na naitalaga sa isang item ay lumalabas sa tabi nito sa service order, para makita ng sinumang sumusuri sa plan kung sino ang sumasaklaw sa bawat bahagi sa isang tingin.

## Oras at Media {#timing-and-media}

Ipinapakita ng bawat item at seksyon kung gaano katagal ito at kung kailan ito magsisimula:

- Kung may service times ang plan, may lalabas na listahang **Viewing as** sa itaas ng order of service. Kapag may napiling service time (ang una ang awtomatikong napili para sa iyo), ipinapakita ng kaliwang rail ang aktwal na **clock time** kung kailan magsisimula ang bawat item sa serbisyong iyon (halimbawa, 9:14 AM). Piliin ang **Run Times** para makita ang lumipas na oras mula sa simula ng serbisyo, na siya ring ipinapakita ng rail kapag walang service times ang plan.
- Ang mga header ng seksyon ay nagbubuod ng kabuuang oras ng lahat ng nasa loob nito.
- Ang mga kanta at custom na item ay nabibilang sa iskedyul na ito kapag inilagay mo ang **Minutes**/**Seconds** sa edit screen ng item.
- Ang mga item na idinagdag mo mula sa media library (mga larawan o video clip) ay nagpapakita ng **thumbnail** at awtomatikong tinatayan ang oras -- sinusukat ang tagal ng video mula mismo sa file, habang ang larawan ay nag-aambag ng ~5:00 na tantiya sa pagpaplano (ipinapakita nang naka-italic) dahil nananatili ito sa screen hanggang ito ay i-advance ng operator. Maaari mo pa ring i-edit ang alinman sa dalawa sa partikular na tagal.

## Pag-edit at Pag-alis ng Mga Item {#editing-and-removing-items}

- I-click ang pencil icon sa alinmang item (o sa header ng seksyon) para **i-edit** ang mga detalye nito.
- Sa edit dialog, i-click ang **Delete** para alisin ang item sa order, o ang **Duplicate** para magdagdag ng kopya nito.

:::info
Partikular sa bawat plan ang service order. Ang mga pagbabagong gagawin mo rito ay nakakaapekto lamang sa napiling plan at hindi nito babaguhin ang ibang plan o ang iyong song library.
:::

### Pagpili at Pagbura ng Maraming Item nang Sabay {#bulk-selecting-and-deleting-items}

Para burahin ang ilang item sa isang seksyon nang sabay-sabay sa halip na isa-isa:

1. I-click ang **Select items** sa header ng seksyon.
2. Lagyan ng check ang mga item na gusto mong alisin, o lagyan ng check ang **Select all in section** para kunin ang lahat ng direktang nasa ilalim ng seksyong iyon.
3. I-click ang **Delete Selected** at kumpirmahin.
4. I-click ang **Done selecting** para lumabas sa selection mode.

:::info
Ang bulk select ay para lamang sa mga direktang anak ng isang seksyon, hindi sa mga item na nasa loob ng sub-section folder.
:::

## Pagsasama ng mga Item sa Partikular na Service Time {#including-items-in-specific-service-times}

Kung may higit sa isang service time ang iyong plan (halimbawa, serbisyong 8 a.m. at 10 a.m.), maaari mong piliin kung aling serbisyo dapat lumabas ang bawat item. Kapaki-pakinabang ito kapag isang serbisyo lamang ang may kaugnayan sa anunsyo, o kapag inaawit ang isang kanta sa isang serbisyo pero hindi sa isa pa.

1. Magbukas ng plan na may dalawa o higit pang service time. Nakalista ang mga ito sa ilalim ng **Times** sa plan page, kung saan maaari ka ring magdagdag pa (tingnan ang [Service Times](./plans.md#service-times)).
2. Sa pahinang **Order of Service**, i-click ang pencil icon ng isang item para i-edit ito.
3. Sa ilalim ng **Include in Services**, makikita mo ang isang checkbox para sa bawat service time, may label na oras nito.
4. Alisan ng check ang anumang serbisyo kung saan dapat laktawan ang item.
5. I-click ang **Save**.

Bilang default, kasama ang bawat item sa bawat serbisyo. Kapag nag-print ka ng plan, may sariling time column ang bawat serbisyo, at ang item na hindi kasama sa isang serbisyo ay nagpapakita ng dash sa column na iyon sa halip na oras ng simula.

:::tip
Lalabas lamang ang seksyong **Include in Services** kapag may higit sa isang service time ang plan. Kung isa lang ang nakikita mong serbisyo, i-click muna ang **Add time** sa ilalim ng **Times** sa plan page para magdagdag ng karagdagang serbisyo.
:::

### Pagpapakita ng Ibang Posisyon sa Bawat Serbisyo {#showing-a-different-position-per-service}

Kung may nakatakdang **Position** ang isang item, ang bawat napiling service time sa **Include in Services** ay may sarili ring dropdown na **Position for this service**. Gamitin ito kapag iba-iba ang volunteer na sumasaklaw sa parehong seksyon sa bawat serbisyo -- iwan itong nakatakda sa **Same as above** para panatilihin ang default na posisyon ng item, o pumili ng ibang posisyon para i-override ito para sa serbisyong iyon lamang.

## Pagbabahagi ng Service Order {#sharing-the-service-order}

Kapag kumpleto na ang iyong service order, maaari mong i-print ang buong plan (kasama ang service order) gamit ang button na **Print** sa itaas ng plan page. Nagbibigay ito sa iyong team ng kumpletong buod ng serbisyo, may heading ng pangalan ng iyong simbahan at pangalan ng plan. Kapag naka-on ang setting ng plan na **Show volunteer names on signup page** (tingnan ang [Plan Settings](./plans.md#plan-settings)), ang bawat item at header ng seksyon na may **Position** ay mai-print din kasama ang mga pangalan ng mga volunteer na naitalaga sa posisyong iyon sa tabi nito (o ang pangalan ng posisyon, kung wala pang naitalaga), para makita ng iyong team kung sino ang sumasaklaw sa seksyong iyon nang hindi binubuksan ang app. Kung ang posisyon ng isang heading ay na-override para sa partikular na mga serbisyo, ipinapakita ng print ang bawat natatanging resulta sa mga serbisyo ng plan na iyon (halimbawa, "Worship Team / Youth Team").
