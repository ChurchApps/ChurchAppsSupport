# Settings

<div class="article-intro">

Ang seksyong Settings ang kinaroroonan para i-configure ang account, branding, at mga opsyong pang-administrasyon ng iyong simbahan sa B1 Admin. Mula rito, maaari mong pamahalaan ang lahat, mula sa pangalan ng simbahan at subdomain hanggang sa mga permiso ng user at configuration ng mobile app.

</div>

## Ano ang Makikita Dito {#what-you-will-find-here}

Nakaayos ang lugar ng Settings sa mga sumusunod na sub-section:

1. **Settings** -- I-configure ang pangunahing impormasyon ng simbahan, subdomain, rehiyon (format ng petsa at telepono), giving, texting provider, file storage, at iba pa. Tingnan ang [Church Settings](./church-settings.md) para sa mga detalye. Para gamitin ang sarili mong domain name (hal. yourchurch.org), tingnan ang [Custom Domain](./custom-domain.md).
2. **Campuses** -- Magdagdag at mamahala ng maraming pisikal na lokasyon ng simbahan. Kapag nagawa na, lumalabas ang mga campus sa mga profile ng tao, sa attendance setup, at sa Demographics dashboard. Mapupuntahan ito bilang seksyon sa pangunahing Settings page, hindi bilang hiwalay na navigation item. Tingnan ang [Campuses](./campuses.md) para sa mga detalye.
3. **Custom Fields** -- Mag-define ng sarili mong mga field na susubaybayan sa mga tao (petsa, numero, oo/hindi na sagot, o pick-list), pagkatapos punan ang mga ito sa mga profile at maghanap gamit ang mga ito. Mapupuntahan din ito bilang seksyon sa pangunahing Settings page. Tingnan ang [Custom Fields](./custom-fields.md) para sa mga detalye.
4. **Roles** -- Kontrolin kung ano ang nakikita at mababago ng bawat staff at volunteer. Tingnan ang [Roles & Permissions](./roles-permissions.md).
5. **Email Templates** -- Mag-save ng reusable na email content para sa manwal na pagpapadala o mula sa workflow. Tingnan ang [Email Templates](./email-templates.md) para sa mga detalye.
6. **Audit Log** at **Batches** -- Suriin ang mga pagbabagong ginawa sa buong account ([Audit Log](../reports/audit-log.md)), at suriin o i-undo ang mga bulk import at aksyon (**Batches**).
7. **Server Admin** -- Mga advanced na tool sa administrasyon, para lamang sa mga server administrator ng ChurchApps.

:::info
Ang configuration ng **Mobile Apps** at **Forms** ay may sarili nang top-level na navigation item -- ang **Mobile** at **Forms** (makikita sa ilalim ng **People**) -- sa halip na nasa loob ng Settings. Tingnan ang [Mobile App Settings](./mobile-app.md) at [Creating Forms](/docs/b1-admin/forms/creating-forms) para sa mga detalye.
:::

## Ang Pangunahing Settings Page {#the-main-settings-page}

Kapag binuksan mo ang pahinang Settings sa unang pagkakataon, ipinapakita ng panel sa kaliwa ang **pangalan ng simbahan**, **subdomain**, at address mo, kasama ang link na **Import/Export** na nagbubukas sa tool para sa paglilipat ng datos sa pagitan ng mga sistema.

Sa ibaba nito, may listahang **Configuration** na nagli-link sa bawat seksyon ng settings: **Church Information**, **General**, **Region**, **Giving**, **Texting**, **File Storage**, **Domains**, **Grade Promotion**, **Check-In**, **Volunteer Signup**, **Giving privacy**, **Campuses**, **Custom Fields**, at **Developer**. Bawat item ay nagpapakita ng isang linyang buod ng kasalukuyang setting nito, at ang mga seksyong kailangan pang i-set up (gaya ng Giving, Texting, o Domains) ay minamarkahan ng maliit na tuldok. Ang **Giving** ay lumalabas lamang para sa mga taong maaaring mag-edit ng giving settings. Sa telepono, nakatago ang listahan; mag-scroll ng pahina para marating ang bawat seksyon. Nasa iisang pahina ang lahat ng seksyon -- i-click ang pangalan sa listahan para mag-scroll dito, o mag-scroll lang pababa. Ipinapakita ng bawat seksyon ang kasalukuyang settings nito; i-click ang **Edit** sa seksyon para baguhin ang mga ito.

May tatlong tab ang seksyong **Developer**: **API Keys**, **Webhooks**, at **Connected Apps**. Tingnan ang [API Keys](../../developer/api/api-keys.md), [Webhooks](../../developer/api/webhooks.md), at [Connected Apps](../../developer/api/connected-apps.md).

Ang **Email Templates**, **Audit Log**, at **Batches** ay magkakahiwalay na pahina -- buksan ang mga ito mula sa [Jump menu](../introduction.md#getting-around-with-the-jump-menu) sa ilalim ng **Settings**.

Simulan sa seksyong **Church Information** para i-edit ang pangalan, address, at contact information ng simbahan mo -- tingnan ang [Church Settings](./church-settings.md). Para pamahalaan ang mga user role, buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) at piliin ang **Settings > Roles** -- tingnan ang [Roles & Permissions](./roles-permissions.md).

:::tip
Simulan sa pag-configure ng pangalan at branding ng simbahan mo sa ilalim ng **Church Information**, pagkatapos i-set up ang [Roles](./roles-permissions.md) para maimbitahan ang mga miyembro ng team mo na may tamang antas ng access.
:::

:::info
Para sa impormasyon kung paano pinoprotektahan ang iyong datos, tingnan ang [Data Security](./data-security.md).
:::
