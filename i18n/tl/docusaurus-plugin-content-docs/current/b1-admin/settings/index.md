# Mga Setting

<div class="article-intro">

Ang seksyon ng Settings ay kung saan mo ina-configure ang account, branding, at mga opsyon sa pangangasiwa ng iyong simbahan sa B1 Admin. Mula dito maaari mong pamahalaan ang lahat mula sa pangalan at subdomain ng iyong simbahan hanggang sa mga pahintulot ng user at pagsasaayos ng mobile app.

</div>

## Ano ang Iyong Makikita Dito

Ang lugar ng Settings ay isinasaayos sa mga sumusunod na sub-seksyon:

1. **Settings** -- I-configure ang pangunahing impormasyon, branding, at subdomain ng iyong simbahan. Tingnan ang [Church Settings](./church-settings.md) para sa mga detalye. Upang gamitin ang iyong sariling pangalan ng domain (halimbawa yourchurch.org), tingnan ang [Custom Domain](./custom-domain.md).
2. **Campuses** -- Magdagdag at pamahalaan ang maraming pisikal na lokasyon para sa iyong simbahan. Kapag na-create na, ang mga campus ay lilitaw sa mga profile ng tao, sa pag-setup ng attendance, at sa dashboard ng Demographics. Naaabot bilang card sa pangunahing pahina ng Settings sa halip na isang hiwalay na item sa navigation. Tingnan ang [Campuses](./campuses.md) para sa mga detalye.
3. **Custom Fields** -- Tukuyin ang iyong sariling mga field upang subaybayan sa mga tao (isang petsa, numero, oo/hindi na sagot, o pick-list), pagkatapos ay punan ang mga ito sa mga profile at hanapin ang mga ito. Naaabot din bilang card sa pangunahing pahina ng Settings. Tingnan ang [Custom Fields](./custom-fields.md) para sa mga detalye.
4. **Email Templates** -- Mag-save ng nilalaman ng email na maaaring gamitin muli para sa pagpapadala nang manu-mano o mula sa isang workflow. Tingnan ang [Email Templates](./email-templates.md) para sa mga detalye.
5. **Server Admin** -- I-access ang mga advanced na tool sa pangangasiwa para sa pamamahala ng mga setting sa antas ng server ng iyong simbahan.

:::info
**Mobile Apps** configuration at **Forms** ay mayroon na ngayong kanilang sariling top-level navigation items -- **Mobile** at **Forms** (makikita sa ilalim ng **People**) -- sa halip na nananatili sa loob ng Settings. Tingnan ang [Mobile App Settings](./mobile-app.md) at [Creating Forms](/docs/b1-admin/forms/creating-forms) para sa mga detalye.
:::

## Ang Pangunahing Pahina ng Settings

Kapag unang binuksan mo ang pahina ng Settings, makikita mo ang iyong **pangalan ng simbahan** at **subdomain** na ipinapakita sa tuktok. Ang header ay nagbibigay ng mga pindutan para sa mabilis na pag-access sa mga karaniwang gawain:

- **Email Templates** -- Direktang lumipat sa pamamahala ng email template.
- **Audit Log** -- Tingnan ang isang log ng mga pagbabago na ginawa sa buong account ng iyong simbahan.
- **Batches** -- Direktang lumipat sa mga donation batch.
- **Import/Export** -- Maglipat ng datos sa pagitan ng mga sistema gamit ang tool na import/export.

Sa ibaba ng header, buksan ang seksyon ng **Church Information** upang i-edit ang pangalan, address, impormasyon sa kontak, at branding ng iyong simbahan -- tingnan ang [Church Settings](./church-settings.md). Upang pamahalaan ang mga role ng user, i-click ang **Roles** sa navigation bar ng Settings -- tingnan ang [Roles & Permissions](./roles-permissions.md).

:::tip
Magsimula sa pamamagitan ng pag-configure ng pangalan at branding ng iyong simbahan sa ilalim ng **Church Information**, pagkatapos ay i-set up ang [Roles](./roles-permissions.md) upang imbitahan ang mga miyembro ng iyong koponan nang may tamang antas ng access.
:::

:::info
Para sa impormasyon tungkol sa kung paano protektado ang iyong datos, tingnan ang [Data Security](./data-security.md).
:::
