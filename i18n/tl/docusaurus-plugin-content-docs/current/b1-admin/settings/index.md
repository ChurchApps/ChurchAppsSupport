# Mga Setting

<div class="article-intro">

Sa seksyong Settings mo ikinokonpigura ang account, branding, at mga opsyon sa pangangasiwa ng iyong simbahan sa B1 Admin. Mula rito, maaari mong pamahalaan ang lahat mula sa pangalan at subdomain ng iyong simbahan hanggang sa mga pahintulot ng user at pagsasaayos ng mobile app.

</div>

## Ano ang Iyong Makikita Dito

Nakaayos ang lugar ng Settings sa mga sumusunod na sub-seksyon na naa-access mula sa sidebar:

1. **Settings** -- Ikonpigura ang pangunahing impormasyon, branding, at subdomain ng iyong simbahan. Tingnan ang [Church Settings](./church-settings.md) para sa mga detalye.
2. **Campuses** -- Magdagdag at pamahalaan ang maraming pisikal na lokasyon para sa iyong simbahan. Kapag nagawa na, lilitaw ang mga campus sa mga profile ng tao, sa pag-set up ng attendance, at sa dashboard ng Demographics. Tingnan ang [Campuses](./campuses.md) para sa mga detalye.
3. **Custom Fields** -- Tukuyin ang iyong sariling mga field na susubaybayan sa mga tao (isang petsa, numero, sagot na oo/hindi, o pick-list), pagkatapos ay punan ang mga ito sa mga profile at hanapin gamit ang mga ito. Tingnan ang [Custom Fields](./custom-fields.md) para sa mga detalye.
3. **Mobile Apps** -- I-set up at i-customize ang mga tab ng navigation na lumilitaw sa [B1.church PWA](/docs/b1-church/getting-started/installing-pwa) para sa iyong mga miyembro (parehong mga tab din ang ipinapakita ng deprecated na native na B1 Mobile app). Tingnan ang [Mobile App Settings](./mobile-app.md) para sa mga detalye.
4. **Email Templates** -- Mag-save ng magagamit-muling nilalaman ng email para sa pagpapadala nang manu-mano o mula sa isang workflow. Tingnan ang [Email Templates](./email-templates.md) para sa mga detalye.
5. **Server Admin** -- Ma-access ang mga advanced na tool sa pangangasiwa para sa pamamahala ng mga setting sa antas ng server ng iyong simbahan.
6. **Forms** -- Gumawa at pamahalaan ang mga custom na form para sa pangongolekta ng impormasyon mula sa iyong kongregasyon.

## Ang Pangunahing Pahina ng Settings

Kapag unang binuksan mo ang pahina ng Settings, makikita mo sa itaas ang **pangalan ng iyong simbahan** at ang **subdomain**. Nagbibigay ang header ng mga pindutan para sa mabilisang pag-access sa mga karaniwang gawain:

- **Edit Settings** -- I-update ang pangalan, tirahan, impormasyon sa pakikipag-ugnayan, at branding ng iyong simbahan.
- **Mobile Apps** -- Direktang pumunta sa pagsasaayos ng mobile app.
- **Roles** -- Pamahalaan ang mga tungkulin at pahintulot ng user para sa iyong koponan.
- **Import/Export** -- Maglipat ng datos sa pagitan ng mga sistema gamit ang tool na import/export.

:::tip
Magsimula sa pagkonpigura ng pangalan at branding ng iyong simbahan sa ilalim ng **Edit Settings**, pagkatapos ay i-set up ang [Roles](./roles-permissions.md) upang imbitahan ang mga miyembro ng iyong koponan nang may tamang antas ng access.
:::

:::info
Para sa impormasyon kung paano protektado ang iyong datos, tingnan ang [Data Security](./data-security.md).
:::
