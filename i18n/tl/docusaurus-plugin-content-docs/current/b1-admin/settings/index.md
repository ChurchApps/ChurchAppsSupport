# Settings

<div class="article-intro">

Ang seksyong Settings ay kung saan mo isinasaayos ang account, branding, at mga administratibong opsyon ng iyong simbahan sa B1 Admin. Mula rito, mapamamahalaan mo ang lahat mula sa pangalan at subdomain ng iyong simbahan hanggang sa mga pahintulot ng user at configuration ng mobile app.

</div>

## Ano ang Makikita Rito

Nakaayos ang lugar ng Settings sa mga sumusunod na sub-seksyon:

1. **Settings** -- I-configure ang pangunahing impormasyon ng iyong simbahan, branding, subdomain, rehiyon (format ng petsa at telepono), texting provider, at file storage. Tingnan ang [Church Settings](./church-settings.md) para sa mga detalye. Para gamitin ang sarili mong domain name (hal. yourchurch.org), tingnan ang [Custom Domain](./custom-domain.md).
2. **Campuses** -- Magdagdag at mamahala ng maraming pisikal na lokasyon para sa iyong simbahan. Kapag nagawa na, lilitaw ang mga campus sa mga profile ng tao, sa setup ng attendance, at sa Demographics dashboard. Mararating ito bilang seksyon sa pangunahing pahina ng Settings sa halip na hiwalay na item sa nabigasyon. Tingnan ang [Campuses](./campuses.md) para sa mga detalye.
3. **Custom Fields** -- Mag-define ng sarili mong mga field na susubaybayan sa mga tao (petsa, numero, sagot na oo/hindi, o pick-list), pagkatapos ay punan ang mga ito sa mga profile at maghanap gamit ang mga ito. Mararating din ito bilang seksyon sa pangunahing pahina ng Settings. Tingnan ang [Custom Fields](./custom-fields.md) para sa mga detalye.
4. **Email Templates** -- Mag-save ng email na magagamit muli para sa manu-manong pagpapadala o mula sa isang workflow. Tingnan ang [Email Templates](./email-templates.md) para sa mga detalye.
5. **Audit Log** at **Batches** -- Suriin ang mga pagbabagong ginawa sa buong account ninyo ([Audit Log](../reports/audit-log.md)), at suriin o i-undo ang mga bulk import at aksyon (**Batches**).
6. **Server Admin** -- I-access ang mga advanced na tool sa pangangasiwa para sa pamamahala ng mga setting ng iyong simbahan sa antas ng server.

:::info
Ang configuration ng **Mobile Apps** at ang **Forms** ay mayroon na ngayong sarili nilang top-level na item sa nabigasyon -- **Mobile** at **Forms** (makikita sa ilalim ng **People**) -- sa halip na nasa loob ng Settings. Tingnan ang [Mobile App Settings](./mobile-app.md) at [Paggawa ng mga Form](/docs/b1-admin/forms/creating-forms) para sa mga detalye.
:::

## Ang Pangunahing Pahina ng Settings

Kapag unang binuksan mo ang pahina ng Settings, ang panel sa kaliwa ay nagpapakita ng **pangalan ng simbahan**, **subdomain**, at address, kasama ang link na **Import/Export** na nagbubukas ng import/export tool para sa paglilipat ng datos sa pagitan ng mga sistema.

Sa ibaba nito, may listahang **Configuration** na nagli-link sa bawat seksyon ng settings: **Church Information**, **General**, **Region**, **Giving**, **Texting**, **File Storage**, **Domains**, **Grade Promotion**, **Check-In**, **Campuses**, **Custom Fields**, at **Developer**. Ang mga seksyong kailangan pang i-set up (gaya ng Giving, Texting, o Domains) ay minamarkahan ng maliit na tuldok. Nasa iisang pahina ang lahat ng seksyon -- i-click ang pangalan sa listahan para mag-scroll dito, o mag-scroll pababa lang. Ipinapakita ng bawat seksyon ang kasalukuyang setting nito; i-click ang **Edit** sa isang seksyon para baguhin ang mga ito.

Ang **Email Templates**, **Audit Log**, at **Batches** ay magkakahiwalay na pahina -- buksan ang mga ito mula sa [Jump menu](../introduction.md#getting-around-with-the-jump-menu) sa ilalim ng **Settings**.

Magsimula sa seksyong **Church Information** para i-edit ang pangalan, address, at contact information ng iyong simbahan -- tingnan ang [Church Settings](./church-settings.md). Para pamahalaan ang mga tungkulin ng user, buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) at piliin ang **Settings > Roles** -- tingnan ang [Mga Tungkulin at Pahintulot](./roles-permissions.md).

:::tip
Magsimula sa pag-configure ng pangalan at branding ng iyong simbahan sa ilalim ng **Church Information**, pagkatapos ay i-set up ang [Roles](./roles-permissions.md) para imbitahan ang iyong team na may tamang antas ng access.
:::

:::info
Para sa impormasyon kung paano pinoprotektahan ang iyong datos, tingnan ang [Seguridad ng Datos](./data-security.md).
:::
