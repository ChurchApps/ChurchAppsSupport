# Exporting Data

<div class="article-intro">

Ang B1 Admin ay nagbibigay-daan sa iyo na i-export ang data ng iyong simbahan upang maaari mo itong gamitin sa spreadsheet, ibahagi sa iyong team, o panatilihin ang backup. Kung kailangan mo ng mabilis na listahan ng pangalan at email o isang kumpletong database export, may mga opsyon upang tumugma sa iyong pangangailangan.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Kailangan mo ng active B1 Admin account na may pahintulot na tingnan ang data na gusto mong i-export. Tingnan ang [Roles & Permissions](roles-permissions.md) kung hindi ka sigurado tungkol sa iyong access level.
- Para sa isang buong database export, kailangan mo ng access sa **Settings** area.

</div>

## Pag-export mula sa People Page

Ang pinakamabilis na paraan upang i-export ang iyong direktoryo ay direkta mula sa **People** page:

1. Buksan ang **section menu** sa top-left corner at piliin ang **People**.
2. Gamitin ang search bar o filter upang mababawi ang resulta na gusto mong i-export (o iwanan itong unfiltered upang i-export ang lahat). Tingnan ang [Searching People](searching-people.md) para sa tip sa pag-filter.
3. Gamitin ang **column selector** upang pumili kung aling mga column ang gusto mong isama sa export (halimbawa, Name, Email, Phone, Address).
4. I-click ang **Export** button.
5. Ang CSV file ay mag-download sa iyong computer na may data na kasalukuyang ipinakita sa table.

:::tip
I-customize ang iyong column bago mag-export. Ang CSV file ay magsasama ng eksakto ang column na nakikita mo, kaya maaari mong i-tailor ang export sa iyong pangangailangan nang hindi na-edit ang file pagkatapos.
:::

## Buong Data Export mula sa Setting

Para sa isang kumpletong export ng lahat ng iyong B1 data (hindi lamang mga tao), gamitin ang export tool sa Settings:

1. Buksan ang **section menu** sa top-left corner at piliin ang **Settings**.
2. I-click ang **Import/Export** sa top navigation.
3. Piliin ang **B1 Database** mula sa **Data Source** dropdown.
4. Suriin ang data preview at i-click ang **Continue to Destination**.
5. Piliin ang **B1 Export Zip** bilang export destination.
6. Monitor ang export progress hanggang sa lahat ng item ay nagpakita ng green checkmark.
7. Ang export file ay mag-download nang awtomatiko. Tukuyin ang `B1Export` file sa iyong downloads folder.
8. I-unzip ang file upang ma-access ang individual na CSV files (tulad ng `people.csv`) na maaari mong buksan sa Excel, Google Sheets, o Numbers.

:::info
Ang buong data export ay sumasaklaw sa mga tao, grupo, donation, attendance, at marami pang iba -- lahat sa iyong B1 database. Ito ay isang mahusay na paraan din upang lumikha ng periodic na backup ng iyong church record.
:::

## Pag-export ng Group Data

Maaari mo ring i-export ang member list para sa individual na grupo. Mula sa **Groups** page, buksan ang isang grupo at i-click ang **download icon** upang i-export ang member list ng grupo na iyon. Tingnan ang [Group Members](../groups/group-members.md) para sa higit pang detalye.

:::info
Ang nae-export na CSV file ay gumagana sa lahat ng pangunahing spreadsheet application kabilang ang Microsoft Excel, Google Sheets, at Apple Numbers.
:::
