# Mga Tao

<div class="article-intro">

Ang seksyong **People** ang puso ng pamamahala ng inyong simbahan sa B1 Admin. Dito mo pinapanatili ang direktoryo ng simbahan -- naghahanap ng mga miyembro, nagdaragdag ng mga bagong tao, tumitingin at nag-e-edit ng mga profile, at sumusubaybay ng mga sambahayan. Maliit man o malaki ang inyong kongregasyon, ang maayos na pagkaka-organisa ng mga record ng inyong mga tao ang pundasyon ng bawat iba pang tampok sa B1.

</div>

## Ano ang Magagawa Mo

Narito ang pangkalahatang-ideya ng mga pangunahing tampok sa seksyong People:

1. **Hanapin sa iyong direktoryo** -- Gamitin ang quick search bar para hanapin ang sinuman ayon sa pangalan, o samantalahin ang mga advanced na filter at AI-powered na natural language search para mahanap ang eksaktong taong kailangan mo. Tingnan ang [Paghahanap ng mga Tao](./searching-people.md) at [AI Search](./ai-search.md) para sa mga detalye.

2. **I-save ang mga search query bilang Lists** -- I-save ang anumang paghahanap o filter bilang may pangalang listahan para mabalikan mo ito sa isang click lang. Tingnan ang [Mga Saved List](./lists.md).

3. **Tingnan ang Demographics** -- Tingnan ang biswal na hati ng inyong kongregasyon ayon sa edad, kasarian, katayuang sibil, katayuan ng pagiging miyembro, at campus — at i-click ang anumang bahagi ng chart para tingnan nang mas malalim ang mga taong iyon. Tingnan ang [Demographics](./demographics.md).

4. **Magdagdag ng mga bagong tao** -- Mabilis na magdagdag ng mga indibidwal sa iyong direktoryo at punan ang kanilang mga detalye sa profile, impormasyon sa pakikipag-ugnayan, at koneksyon sa sambahayan. Tingnan ang [Pagdaragdag ng mga Tao](./adding-people.md) para sa hakbang-hakbang na tagubilin.

5. **Mag-bulk edit ng mga tao** -- Mag-update ng maraming tao nang sabay-sabay sa pamamagitan ng pagbabago ng kanilang katayuan ng pagiging miyembro, katayuang sibil, kasarian, mga kagustuhang opt-out, o pagiging miyembro sa mga grupo. Nakakatipid ito ng oras kapag pareho ang pagbabago sa maraming indibidwal. Tingnan ang [Bulk Editing](./bulk-editing.md).

6. **I-print ang iyong direktoryo** -- Gumawa ng naka-format at napi-print na direktoryo ng mga miyembro na nakapangkat ayon sa sambahayan, kumpleto sa mga larawan at impormasyon sa pakikipag-ugnayan. Tingnan ang [Print Directory](./print-directory.md).

7. **Mag-import at mag-export ng datos** -- Magdala ng datos ng mga miyembro mula sa CSV file o lumipat mula sa ibang church management system tulad ng Breeze. Maaari mo ring i-export ang iyong direktoryo sa CSV anumang oras. Tingnan ang [Pag-import ng Datos](./importing-data.md) at [Pag-export ng Datos](./exporting-data.md).

8. **Pamahalaan ang mga profile** -- Tingnan at i-edit ang detalyadong profile ng bawat tao, kasama ang impormasyon sa pakikipag-ugnayan, mga miyembro ng sambahayan, [pagiging miyembro sa mga grupo](../groups/group-members.md), [kasaysayan ng attendance](../attendance/tracking-attendance.md), [mga donasyon](../donations/recording-donations.md), at [mga custom na form](../forms/creating-forms.md). Ilagay ang cursor sa isang email, address, o numero ng telepono sa asul na header ng profile para makopya ito sa isang click.

9. **Magtalaga ng mga tungkulin at pahintulot** -- Kontrolin kung sino sa iyong team ang makaka-access sa iba't ibang bahagi ng B1 Admin sa pamamagitan ng pagtatalaga ng mga tungkulin. Tingnan ang [Pagtatalaga ng mga Tungkulin](./roles-permissions.md).

## Pagsisimula

Para buksan ang seksyong People, buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas ng B1 Admin), i-expand ang **People**, at i-click ang **People**. Makikita mo ang buong direktoryo ng inyong simbahan na may search bar sa itaas at listahan ng mga miyembro sa ibaba.

:::tip
Kung unang beses mong ise-set up ang B1, magsimula sa [pag-import ng umiiral mong datos ng mga miyembro](./importing-data.md). Pagkatapos, suriin at ayusin ang mga profile kung kinakailangan.
:::
