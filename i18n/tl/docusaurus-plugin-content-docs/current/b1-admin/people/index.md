# People

<div class="article-intro">

Ang seksyong **People** ang puso ng pamamahala ng simbahan sa B1 Admin. Dito mo pinapanatili ang directory ng iyong simbahan — paghahanap ng mga miyembro, pagdaragdag ng mga bagong tao, pagtingin at pag-edit ng mga profile, at pagsubaybay sa mga household. Maliit man o malaki ang iyong kongregasyon, ang maayos na pag-oorganisa ng mga record ng tao ang pundasyong nagpapagana sa bawat ibang feature ng B1.

</div>

## Ano ang Puwede Mong Gawin {#what-you-can-do}

Narito ang pangkalahatang-tanaw ng mga pangunahing feature na available sa seksyong People:

1. **Hanapin ang iyong directory** -- Gamitin ang mabilisang search bar para hanapin ang sinuman ayon sa pangalan, o gamitin ang mga advanced filter at AI-powered na natural language search para mahanap ang eksaktong kailangan mo. Tingnan ang [Searching People](./searching-people.md) at [AI Search](./ai-search.md) para sa mga detalye.

2. **I-save ang mga search query bilang Lists** -- I-save ang anumang search o filter bilang pinangalanang listahan para mai-load mo ito gamit ang isang click. Tingnan ang [Saved Lists](./lists.md).

3. **Tingnan ang Demographics** -- Makita ang visual na breakdown ng iyong kongregasyon ayon sa edad, kasarian, marital status, membership status, at campus — at i-click ang alinmang bahagi ng chart para mag-drill down sa mga taong iyon. Tingnan ang [Demographics](./demographics.md).

4. **Magdagdag ng mga bagong tao** -- Mabilisang magdagdag ng mga indibidwal sa iyong directory at punan ang kanilang mga detalye sa profile, impormasyon ng contact, at mga koneksyon sa household. Tingnan ang [Adding People](./adding-people.md) para sa mga hakbang-hakbang na tagubilin.

5. **Maramihang i-edit ang mga tao** -- I-update ang maraming tao nang sabay-sabay sa pamamagitan ng pagpalit ng kanilang membership status, marital status, kasarian, directory opt-out, campus, o membership sa grupo, o sa pagdagdag sa kanila sa isang workflow. Nakakatipid ito ng oras kapag pareho ang pagbabagong ginagawa sa maraming indibidwal. Tingnan ang [Bulk Editing](./bulk-editing.md).

6. **I-print ang iyong directory** -- Gumawa ng naka-format at naka-print na member directory na nakapangkat ayon sa household, kumpleto sa mga larawan at impormasyon ng contact. Tingnan ang [Print Directory](./print-directory.md).

7. **Mag-import at mag-export ng datos** -- Magdala ng datos ng miyembro mula sa CSV file o lumipat mula sa ibang church management system gaya ng Breeze. Puwede mo ring i-export ang iyong directory sa CSV anumang oras. Tingnan ang [Importing Data](./importing-data.md) at [Exporting Data](./exporting-data.md).

8. **Pamahalaan ang mga profile** -- Tingnan at i-edit ang detalyadong profile ng bawat tao, kabilang ang impormasyon ng contact, mga miyembro ng household, [membership sa grupo](../groups/group-members.md), [kasaysayan ng attendance](../attendance/tracking-attendance.md), [donasyon](../donations/recording-donations.md), at [custom form](../forms/creating-forms.md). Nasa kaliwa ng profile ang pangalan, detalye ng contact, at household ng tao, habang nasa tabi nito ang mga buod ng kanilang attendance, giving, grupo, note, at form. I-hover ang isang address o numero ng telepono sa bahay o trabaho para kopyahin ito gamit ang isang click.

9. **Basahin ang mga kamakailang note** -- Basahin ang pinakabagong mga note na isinulat tungkol sa mga tao, grupo, event, at workflow card sa iisang listahan. Tingnan ang [Notes](./notes.md).

10. **Magtalaga ng mga role at pahintulot** -- Kontrolin kung sino sa iyong team ang may access sa iba't ibang bahagi ng B1 Admin sa pamamagitan ng pagtatalaga ng mga role. Tingnan ang [Assigning Roles](./roles-permissions.md).

## Pagsisimula {#getting-started}

Para mapasok ang seksyong People, buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas ng B1 Admin), buksan ang **People**, at i-click ang **People**. Makikita mo ang directory ng iyong simbahan na nakalista ayon sa household, na may search bar sa itaas. Gamitin ang toggle na **View as** para lumipat sa pagitan ng listahang **Households** at **Table** ng mga indibidwal na tao.

:::tip
Kung unang beses mong ise-set up ang B1, magsimula sa [pag-import ng umiiral mong datos ng miyembro](./importing-data.md). Pagkatapos, suriin at linisin ang mga profile kung kinakailangan.
:::
