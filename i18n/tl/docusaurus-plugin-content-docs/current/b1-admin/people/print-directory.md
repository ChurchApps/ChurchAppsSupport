# Print Directory

<div class="article-intro">

Ang Print Directory feature ay lumilikha ng isang formatted, printable na member directory para sa iyong simbahan. Ito ay nag-organize ng mga miyembro ayon sa sambahayan, kasama ang impormasyon sa pakikipag-ugnayan at mga larawan, at ito ay idinisenyo upang mukhang propesyonal kapag na-print sa standard na letter-size na papel.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Kailangan mo ng aktibong B1 Admin account na may permission na tingnan ang mga tao.
- Ang mga tao sa iyong direktoryo ay dapat na may mga larawan at impormasyon sa pakikipag-ugnayan na puno para sa best results.

</div>

## Pagbubukas ng Print Directory

1. Mag-navigate sa **People** sa B1 Admin.
2. I-click ang **print icon** (printer icon) sa toolbar sa tuktok ng People results card. Ito ay lumalabas sa tabi ng Export button.
3. Ang Print Directory ay bumubukas sa isang bagong browser tab at nagsisimulang mag-load ng data ng direktoryo.
4. Pagkatapos ng humigit-kumulang 1.5 segundo, ang print dialog ng iyong browser ay awtomatikong ililitaw.

:::tip
Ang direktoryo ay bumubukas sa isang hiwalay na tab upang makagawa ka ng print nito nang hindi umalis sa People page. Pagkatapos ililitaw ang print dialog, ang tab ay awtomatikong bumabalik.
:::

## Kung Ano Ang Kasama

Ang print directory ay nagsasama ng lahat ng **active members** ng iyong simbahan. Partikular:

- Ang mga taong may **Inactive** o **Visitor** membership status ay awtomatikong hindi kasama.
- Ang mga taong **opted out** ng direktoryo ay hindi kasama.
- Lahat ng iba ay naka-grupo ayon sa **sambahayan**.

## Directory Layout

Ang na-print na direktoryo ay may dalawang bahagi:

### Cover Page

Ang unang pahina ay kasama ang:
- Ang pangalan ng iyong simbahan
- Ang pamagat na "Member Directory"
- Ang kasalukuyang taon
- Ang lokasyon ng iyong simbahan
- Isang bilang ng kabuuang sambahayan na kasama

### Member Listings

Ang natitirang mga pahina ay naglilista ng mga sambahayan sa alphabetically ayon sa apelyido. Bawat card ng sambahayan ay nagpapakita ng:

- **Photos** -- Circular thumbnails para sa bawat miyembro ng sambahayan, na may kanilang pangalan sa ibaba
- **Household display name** -- Halimbawa, "The Smith Family", "John & Jane Doe", o lamang ang pangalan ng tao para sa mga indibidwal
- **Address** -- Street address, siyudad, estado, at zip
- **Phone** -- Tahanan o mobile number
