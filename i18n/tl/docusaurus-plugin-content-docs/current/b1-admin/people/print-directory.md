# I-print ang Directory

<div class="article-intro">

Gumagawa ang feature na Print Directory ng naka-format at naka-print na member directory para sa iyong simbahan. Inaayos nito ang mga miyembro ayon sa household, kasama ang impormasyon ng contact at mga larawan, at dinisenyo para magmukhang propesyonal kapag na-print sa karaniwang letter-size na papel.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan mo ng aktibong B1 Admin account na may pahintulot na tingnan ang mga tao.
- Dapat may mga larawan at impormasyon ng contact ang mga tao sa iyong directory para sa pinakamagandang resulta.

</div>

## Pagbukas ng Print Directory {#opening-the-print-directory}

1. Pumunta sa **People** sa B1 Admin.
2. I-click ang **Print Directory** sa header ng pahinang People.
3. Magbubukas ang Print Directory sa bagong browser tab at magsisimulang i-load ang datos ng iyong directory.
4. Pagkaraan ng mga 1.5 segundo, awtomatikong lalabas ang print dialog ng iyong browser.

:::tip
Nagbubukas ang directory sa hiwalay na tab para mai-print mo ito nang hindi umaalis sa pahinang People. Pagkasara ng print dialog, lilipat ang tab na iyon sa pahinang People, kaya puwede mo itong isara o doon magpatuloy sa trabaho.
:::

## Ano ang Kasama {#what-gets-included}

Kasama sa print directory ang lahat ng **aktibong miyembro** ng iyong simbahan. Partikular:

- Awtomatikong hindi kasama ang mga taong may membership status na **Inactive**, **Visitor**, o **Deceased**.
- Hindi kasama ang mga taong **nag-opt out** sa directory.
- Ang lahat ng iba pa ay pinagpapangkat ayon sa **household**.

### Pag-print ng Mga Resulta ng Search Lamang {#printing-only-your-search-results}

Pagkatapos magpatakbo ng search sa pahinang People -- quick search, [Advanced Search](./searching-people.md#advanced-search), [Saved List](./lists.md), o [AI Search](./ai-search.md) -- magiging **Print Results** ang button na **Print Directory**. Kapag na-click ito, mag-pi-print ito ng directory ng mga tao lamang sa iyong mga resulta sa halip na ang buong simbahan, gamit ang parehong layout.

Kapag nagpi-print ng mga resulta ng search, hindi nalalapat ang filter ng membership-status sa itaas: kasama ang lahat ng hinanap mo, kahit ang mga Visitor o Inactive na tao. Hindi pa rin kasama ang mga taong nag-opt out sa directory. Para bumalik sa pag-print ng buong directory, burahin muna ang iyong search.

## Layout ng Directory {#directory-layout}

Dalawang bahagi ang naka-print na directory:

### Cover Page {#cover-page}

Kasama sa unang pahina ang:
- Ang logo ng iyong simbahan, kung may nakatakda
- Ang pangalan ng iyong simbahan
- Ang pamagat na "Member Directory"
- Ang kasalukuyang taon
- Ang lungsod at estado ng iyong simbahan
- Ang petsa ng pag-print at bilang ng mga household na kasama

### Mga Listahan ng Miyembro {#member-listings}

Ang natitirang mga pahina ay naglilista ng mga household ayon sa alpabeto ng apelyido. Ipinapakita ng bawat household card ang:

- **Mga larawan** -- Mga bilog na thumbnail para sa bawat miyembro ng household, na may pangalan sa ilalim
- **Display name ng household** -- Halimbawa, "The Smith Family", "John & Jane Doe", o pangalan lang ng tao para sa mga indibidwal
- **Address** -- Street address, lungsod, estado, at zip
- **Telepono** -- Ang home number, o mobile number kung walang home number ang sinuman sa household
- **Email** -- Pangunahing email address
- **Mga kaarawan** -- Unang pangalan at kaarawan ng bawat miyembro (buwan at araw)
- **Anibersaryo** -- Kung nakatala

Nakaayos ang mga household sa **alphabetical section** (A, B, C, ...) na may pandekorasyong section header bago ang bawat pangkat ng titik. Dalawang household card ang magkatabi sa bawat hilera.

## Mga Setting ng Print {#print-settings}

Nakaayos ang directory para sa **letter-size na papel** (8.5" × 11") na may 0.5-inch na margin. Kapag lumabas ang print dialog ng browser:

- Itira ang laki ng papel sa **Letter**
- I-enable ang **Background graphics** (minsan tinatawag na "Print backgrounds") sa print settings ng browser mo kung gusto mong maka-print ang mga section header na may kulay na istilo
- Inirerekomenda ang portrait na oryentasyon

:::info
Sinusunod ng directory ang mga page break -- hindi mahahati sa magkaibang pahina ang mga household card at section header.
:::
