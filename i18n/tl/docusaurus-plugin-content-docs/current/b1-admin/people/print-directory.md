# Print Directory

<div class="article-intro">

Ang tampok na Print Directory ay gumagawa ng naka-format at napi-print na direktoryo ng mga miyembro para sa inyong simbahan. Inaayos nito ang mga miyembro ayon sa sambahayan, kasama ang impormasyon sa pakikipag-ugnayan at mga larawan, at dinisenyo para magmukhang propesyonal kapag ini-print sa karaniwang letter-size na papel.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Kailangan mo ng aktibong B1 Admin account na may pahintulot na tingnan ang mga tao.
- Para sa pinakamagandang resulta, dapat may mga larawan at impormasyon sa pakikipag-ugnayan ang mga tao sa iyong direktoryo.

</div>

## Pagbubukas ng Print Directory

1. Pumunta sa **People** sa B1 Admin.
2. I-click ang **icon ng print** (icon ng printer) sa toolbar sa itaas ng results card ng People. Lumilitaw ito sa tabi ng button na Export.
3. Magbubukas ang Print Directory sa bagong tab ng browser at magsisimulang i-load ang datos ng iyong direktoryo.
4. Pagkaraan ng mga 1.5 segundo, awtomatikong lilitaw ang print dialog ng iyong browser.

:::tip
Nagbubukas ang direktoryo sa hiwalay na tab para makapag-print ka nang hindi umaalis sa pahina ng People. Pagkalitaw ng print dialog, awtomatikong babalik ang tab.
:::

## Ano ang Isinasama

Kasama sa print directory ang lahat ng **aktibong miyembro** ng inyong simbahan. Partikular:

- Awtomatikong hindi isinasama ang mga taong may katayuang **Inactive** o **Visitor** sa pagiging miyembro.
- Hindi isinasama ang mga taong **nag-opt out** sa direktoryo.
- Ang lahat ng iba pa ay pinagpapangkat ayon sa **sambahayan**.

### Pag-print ng Iyong mga Resulta ng Paghahanap Lamang

Pagkatapos mong magpatakbo ng paghahanap sa pahina ng People -- isang quick search, isang [Advanced Search](./searching-people.md#advanced-search), isang [Saved List](./lists.md), o isang [AI Search](./ai-search.md) -- magiging **Print Results** ang icon ng print. Kapag na-click ito, magpi-print ng direktoryo ng mga taong nasa iyong mga resulta lamang sa halip na ng buong simbahan, gamit ang parehong layout.

Kapag nagpi-print ng mga resulta ng paghahanap, hindi nalalapat ang filter ng katayuan ng pagiging miyembro sa itaas: kasama ang lahat ng hinanap mo, kahit ang mga Visitor o Inactive. Hindi pa rin isinasama ang mga taong nag-opt out sa direktoryo. Para bumalik sa pag-print ng buong direktoryo, i-clear muna ang iyong paghahanap.

## Layout ng Direktoryo

May dalawang bahagi ang naka-print na direktoryo:

### Cover Page

Kasama sa unang pahina ang:
- Ang pangalan ng inyong simbahan
- Ang pamagat na "Member Directory"
- Ang kasalukuyang taon
- Ang lokasyon ng inyong simbahan
- Ang bilang ng kabuuang sambahayang kasama

### Mga Listahan ng Miyembro

Inililista ng mga natitirang pahina ang mga sambahayan ayon sa alpabeto ng apelyido. Ipinapakita ng bawat household card ang:

- **Mga Larawan** -- Bilog na thumbnail para sa bawat miyembro ng sambahayan, na may pangalan sa ibaba
- **Display name ng sambahayan** -- Halimbawa, "The Smith Family", "John & Jane Doe", o ang pangalan lang ng tao para sa mga indibidwal
- **Address** -- Street address, lungsod, estado, at zip
- **Telepono** -- Numero sa bahay o mobile
- **Email** -- Pangunahing email address
- **Mga Kaarawan** -- Naka-format bilang indibidwal na petsa para sa bawat miyembro ng sambahayan
- **Anibersaryo** -- Kung naitala

Inaayos ang mga sambahayan sa **mga seksyon ayon sa alpabeto** (A, B, C, ...) na may pandekorasyong header ng seksyon bago ang bawat pangkat ng titik. Dalawang household card ang magkatabi sa bawat hilera.

## Mga Setting ng Pag-print

Naka-format ang direktoryo para sa **letter-size na papel** (8.5" × 11") na may 0.5-pulgadang margin. Kapag lumitaw ang print dialog ng browser:

- Iwanang naka-set sa **Letter** ang laki ng papel
- I-enable ang **Background graphics** (minsan tinatawag na "Print backgrounds") sa mga setting ng pag-print ng iyong browser kung gusto mong mai-print ang mga header ng seksyon na may kanilang kulay
- Inirerekomenda ang portrait na orientation

:::info
Iginagalang ng direktoryo ang mga page break — hindi mahahati sa pagitan ng mga pahina ang mga household card at header ng seksyon.
:::
