# Paghahanap ng Tao

<div class="article-intro">

Ipinapakita ng pahinang **People** ang directory ng iyong simbahan bilang nahahanap na listahan ng mga household, o bilang maaayos na table ng mga indibidwal na tao. Mabilis mong mahahanap ang sinumang nasa kongregasyon mo, mapipili kung anong impormasyon ang ipinapakita, at maie-export ang iyong mga resulta. Mahalaga ang mabilis na paghahanap sa pang-araw-araw na administrasyon ng simbahan, tulad ng pag-follow up sa mga bisita, paghahanda ng mga contact list, at pamamahala ng mga tala ng miyembro.

</div>

## Mga Household at Table View

Inililista ng pahinang People ang iyong directory ayon sa **household**, pinagpapangkat nang alpabetiko. Ipinapakita ng bawat hilera ang mga larawan ng household, ang pangalan nito (halimbawa, "The Smith Family"), at ang pangalan ng lahat ng nasa loob nito. I-click ang isang household para buksan ang profile ng head of household, o i-click ang pangalan ng sinumang miyembro para buksan ang taong iyon. Ipinapakita ng bilang sa itaas ng listahan kung ilang household at tao ang nakikita.

Gamitin ang toggle na **View as** sa itaas ng listahan para lumipat sa pagitan ng **Households** at **Table**. Isang tao bawat hilera ang view na **Table** at dito mo maaaring i-sort at piliin ang mga column (tingnan sa ibaba). Naaalala ng B1 ang iyong pinili sa device na iyon.

Bilang default, ang unang bahagi lamang ng iyong directory ang nilo-load ng pahina. Kung mas maraming tao ka, i-click ang **Show All Members** sa ibaba ng listahan para i-load ang lahat.

## Mabilis na Paghahanap

Ang kahon na **Find a household or person** sa itaas ng pahinang People ay nagpapahintulot na hanapin ang mga miyembro nang real time:

1. I-click ang **search box** sa itaas ng pahinang People.
2. Magsimulang mag-type ng pangalan.
3. Awtomatikong sasala ang mga resulta habang nagta-type ka (may maikling pagkaantala na mga kalahating segundo para hindi tumakbo ang paghahanap sa bawat keystroke).
4. Ina-update ng listahan sa ibaba para ipakita lamang ang mga tugmang resulta.

I-click ang **Clear** (sa ibaba ng search box) para i-reset ang paghahanap at ipakitang muli ang buong directory mo.

:::tip
Hindi mo kailangang pindutin ang Enter. Awtomatikong tumatakbo ang paghahanap pagkatapos mong huminto sa pag-type.
:::

## Pag-aayos ng Resulta

Sa view na **Table**, nakalista ang mga tao ayon sa apelyido, pagkatapos ayon sa unang pangalan. Maaari mong ayusin nang iba ang directory sa pamamagitan ng pag-click sa anumang column header:

1. I-click ang **column header** (halimbawa, **Name** o **Email**) para i-sort ayon sa column na iyon.
2. I-click muli ang parehong header para baligtarin ang pagkakasunod ng pag-sort.

Madali nitong mahahanap ang mga tao nang alpabetiko, ayon sa edad, o ayon sa anumang nakikitang column.

## Pag-customize ng mga Column

Hindi kailangang nakikita nang sabay-sabay ang lahat ng impormasyon. Maaari mong piliin kung aling mga column ang lumalabas sa table:

1. I-click ang icon na **Select columns** sa header ng pahinang People. (Nalalapat ang mga column sa view na **Table**.)
2. Lagyan o alisin ang check ng mga column para ipakita o itago ang mga ito. Kabilang sa mga available na column:
   - **Photo**
   - **Name**
   - **Email**
   - **Phone**
   - **Address**
   - **Birth Date**
   - **Age**
   - **Gender**
   - **Membership Status**
   - **Campus**
3. Agad na ina-update ng table ang ipinapakita ayon sa iyong mga pinili. I-click ang **Done** para isara ang dialog na **Select Columns**.

### Pagpapakita ng Custom Fields bilang mga Column

May dalawang tab ang column chooser: ang **Standard** ay naglalaman ng mga built-in na column na nakalista sa itaas, at ang **Custom** ay naglalaman ng mga [Custom Field](../settings/custom-fields.md) ng iyong simbahan kasama ang mga tanong mula sa anumang People form. Lagyan ng check ang custom field sa tab na **Custom** para idagdag ito bilang column, at lalabas sa table ang halaga ng bawat tao para sa field na iyon. Ipinapakita ang mga halaga sa parehong paraan gaya sa profile ng tao — ang mga Yes/No field ay nagpapakita ng *Yes* o *No*, ang mga Multiple Choice field ay nagpapakita ng label ng pagpipilian, at ang mga petsa ay ipinapakita bilang maikling petsa. Ang mga taong walang halaga para sa field ay may blangkong cell.

## Pag-export ng mga Resulta ng Paghahanap

Maaari mong i-download ang kasalukuyang mga resulta ng paghahanap bilang CSV file anumang oras:

1. Maglapat ng anumang paghahanap o filter na gusto mo.
2. I-click ang button na **Export** sa header ng pahinang People.
3. Ida-download ang CSV file sa iyong computer, handa nang buksan sa Excel, Google Sheets, o anumang spreadsheet application.

Para sa karagdagang detalye sa pag-export, tingnan ang [Exporting Data](./exporting-data.md).

:::tip
Para sa mas advanced na query — tulad ng paghahanap sa lahat ng hindi dumalo sa nakalipas na tatlong buwan — subukan ang feature na [AI Search](./ai-search.md), na nagpapahintulot maghanap gamit ang mga tanong sa simpleng salita.
:::

## Advanced Search

Pinapayagan ka ng Advanced Search na bumuo ng tumpak na mga filter sa pamamagitan ng pagsasama-sama ng mga kondisyon. Buksan ito sa pamamagitan ng pag-click sa **Advanced** sa ibaba ng search box sa pahinang People, pagkatapos ay buksan ang isang kategorya at lagyan ng check ang mga field na gusto mong i-filter (maaari mong i-click ang pangalan ng field o ang checkbox nito), pumipili ng operator at halaga para sa bawat isa. Kabilang sa mga kategorya ang **Names**, **Demographics**, **Contact**, **Membership**, **Activity** (donations at attendance), at **Custom Fields**.

Inililista ng kategoryang **Custom Fields** ang mga [Custom Field](../settings/custom-fields.md) ng iyong simbahan — ang mga field na itinakda mo sa Settings para subaybayan ang sarili mong impormasyon (gaya ng petsa ng pag-expire ng background check). Tumutugma ang mga operator na inaalok sa uri ng bawat field: sinusuportahan ng mga text field ang *contains / equals / starts with / ends with*, sinusuportahan ng mga number field ang mga comparison operator, sinusuportahan ng mga date field ang *equals / after / before*, at pinapayagan ka ng mga Yes/No at Multiple Choice field na pumili ng halaga. Anumang field na maaari mong i-filter dito ay maaaring i-save bilang buhay na [List](./lists.md).

## Pag-save ng mga Paghahanap bilang mga List

Pagkatapos magpatakbo ng paghahanap, lalabas ang button na **Save as List** sa header ng pahinang People. I-click ito para i-store ang kasalukuyan mong query sa ilalim ng pangalan at opsyonal na kategorya, para mabilis itong ma-load muli sa mga susunod na session. Tingnan ang [Saved Lists](./lists.md) para sa kumpletong detalye.
