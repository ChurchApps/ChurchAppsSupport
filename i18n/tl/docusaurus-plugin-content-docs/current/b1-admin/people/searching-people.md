# Paghahanap ng mga Tao

<div class="article-intro">

Ipinapakita ng pahinang **People** ang directory ng inyong simbahan sa isang talahanayang maaaring hanapan at i-sort. Mabilis ninyong mahahanap ang sinuman sa inyong kongregasyon, mako-customize kung anong impormasyon ang ipapakita, at mae-export ang mga resulta. Mahalaga ang mahusay na paghahanap sa pang-araw-araw na gawain ng administrasyon ng simbahan, tulad ng pag-follow up sa mga bisita, paghahanda ng mga listahan ng contact, at pamamahala ng mga talaan ng miyembro.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Kailangan ninyo ng aktibong B1 Admin account na may pahintulot na tumingin ng mga tao. Tingnan ang [Mga Role at Pahintulot](roles-permissions.md) kung hindi kayo sigurado sa inyong antas ng access.
- Dapat may laman ang directory ng inyong simbahan. Kung wala pa kayong naidaragdag, tingnan ang [Pagdaragdag ng mga Tao](adding-people.md) o [Pag-import ng Datos](importing-data.md).

</div>

## Mabilis na Paghahanap

Ang search bar sa itaas ng pahinang People ay nagbibigay-daan para mahanap ang mga miyembro nang real time:

1. I-click ang **search box** sa itaas ng pahinang People.
2. Simulang mag-type ng pangalan, email, o iba pang keyword.
3. Awtomatikong sasala ang mga resulta habang nagta-type kayo (may maikling pagitan na humigit-kumulang kalahating segundo para hindi tumakbo ang paghahanap sa bawat pindot ng key).
4. Mag-a-update ang talahanayan sa ibaba para ipakita lang ang mga tumutugmang resulta.

:::tip
Hindi ninyo kailangang pindutin ang Enter. Awtomatikong tatakbo ang paghahanap kapag tumigil na kayo sa pagta-type.
:::

## Pag-sort ng mga Resulta

Maaari ninyong i-sort ang directory sa pamamagitan ng pag-click sa header ng alinmang column sa talahanayan:

1. I-click ang **header ng column** (halimbawa, **Name** o **Email**) para i-sort ayon sa column na iyon.
2. I-click muli ang parehong header para baligtarin ang pagkakasunod-sunod.

Dahil dito, madali ninyong mahahanap ang mga tao ayon sa alpabeto, edad, o alinmang nakikitang column.

## Pag-customize ng mga Column

Hindi kailangang makita nang sabay-sabay ang lahat ng impormasyon. Maaari ninyong piliin kung aling mga column ang lalabas sa talahanayan:

1. Hanapin ang **dropdown ng column selector** malapit sa itaas ng talahanayan.
2. Lagyan o alisan ng check ang mga column para ipakita o itago ang mga ito. Kabilang sa mga available na column ang:
   - **Photo**
   - **Name**
   - **Email**
   - **Phone**
   - **Address**
   - **Birth Date**
   - **Age**
   - **Gender**
   - **Membership Status**
   - **Campus**
3. Agad na mag-a-update ang talahanayan ayon sa inyong mga pinili.

### Pagpapakita ng mga Custom Field bilang mga Column

May dalawang tab ang column chooser: ang **Standard** ay naglalaman ng mga built-in na column na nakalista sa itaas, at ang **Custom** ay naglalaman ng [Mga Custom Field](../settings/custom-fields.md) ng inyong simbahan kasama ang mga tanong mula sa anumang People form. Lagyan ng check ang isang custom field sa tab na **Custom** para idagdag ito bilang column, at lalabas sa talahanayan ang halaga ng bawat tao para sa field na iyon. Ipinapakita ang mga halaga sa parehong paraan tulad sa profile ng tao -- ang mga Yes/No field ay nagbabasa ng *Yes* o *No*, ang mga Multiple Choice field ay nagpapakita ng label ng opsyon, at ang mga petsa ay ipinapakita bilang maikling petsa. Ang mga taong walang halaga para sa field ay may blangkong cell.

:::info
Nakakaapekto ang inyong mga pinili sa column sa kung ano ang isasama kapag nag-export kayo sa CSV. I-customize ang mga column bago mag-export para makuha ang eksaktong datos na kailangan ninyo.
:::

## Pagination

Kapag maraming talaan ang inyong directory, hahatiin ang mga resulta sa ilang pahina. Gamitin ang **mga kontrol ng pagination** sa ibaba ng talahanayan para lumipat-lipat ng pahina. Ipinapakita ang kasalukuyang pahina at ang kabuuang bilang ng mga talaan para lagi ninyong alam kung nasaan kayo sa listahan.

:::tip
Kung gusto ninyong makakita ng mas maraming resulta nang sabay-sabay, paliitin ang inyong paghahanap para paikliin ang listahan sa halip na magpalipat-lipat ng pahina sa malaking directory.
:::

## Pag-export ng mga Resulta ng Paghahanap

Maaari ninyong i-download ang kasalukuyang mga resulta ng paghahanap bilang CSV file anumang oras:

1. Ilapat ang anumang paghahanap o filter na gusto ninyo.
2. I-customize ang inyong mga column para isama ang datos na kailangan ninyo.
3. I-click ang button na **Export**.
4. Magda-download ang isang CSV file sa inyong computer, handa nang buksan sa Excel, Google Sheets, o anumang spreadsheet application.

Para sa karagdagang detalye tungkol sa pag-export, tingnan ang [Pag-export ng Datos](./exporting-data.md).

:::tip
Para sa mas masalimuot na mga query -- tulad ng paghahanap sa lahat ng hindi dumalo sa nakalipas na tatlong buwan -- subukan ang [AI Search](./ai-search.md), na nagbibigay-daan sa inyong maghanap gamit ang mga tanong sa simpleng wika.
:::

## Advanced Search

Hinahayaan kayo ng Advanced Search na bumuo ng eksaktong mga filter sa pamamagitan ng pagsasama-sama ng mga kondisyon. Buksan ito mula sa pahinang People, pagkatapos ay palawakin ang isang kategorya at lagyan ng check ang mga field na gusto ninyong i-filter, at pumili ng operator at halaga para sa bawat isa. Kabilang sa mga kategorya ang **Names**, **Demographics**, **Contact**, **Membership**, **Activity** (mga donasyon at attendance), at **Custom Fields**.

Inililista ng kategoryang **Custom Fields** ang [Mga Custom Field](../settings/custom-fields.md) ng inyong simbahan — ang mga field na binubuo ninyo sa Settings para subaybayan ang sarili ninyong impormasyon (tulad ng petsa ng pag-expire ng background check). Tumutugma ang mga inaalok na operator sa uri ng bawat field: sinusuportahan ng mga text field ang *contains / equals / starts with / ends with*, sinusuportahan ng mga number field ang mga comparison operator, sinusuportahan ng mga date field ang *equals / after / before*, at hinahayaan kayo ng mga Yes/No at Multiple Choice field na pumili ng halaga. Anumang field na maaari ninyong i-filter dito ay maaaring i-save bilang live na [List](./lists.md).

## Pag-save ng mga Paghahanap bilang mga List

Pagkatapos magpatakbo ng paghahanap, may lalabas na button na **Save as List** (icon na bookmark) sa header ng pahinang People. I-click ito para i-save ang kasalukuyan ninyong query sa ilalim ng isang pangalan at opsyonal na kategorya, para agad ninyo itong mabuksan sa mga susunod na session. Tingnan ang [Mga Naka-save na List](./lists.md) para sa buong detalye.
