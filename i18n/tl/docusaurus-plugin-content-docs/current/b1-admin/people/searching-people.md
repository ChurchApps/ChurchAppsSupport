# Paghahanap ng mga Tao

<div class="article-intro">

Ipinapakita ng pahinang **People** ang direktoryo ng simbahan mo bilang listahang maaaring hanapin ng mga sambahayan, o bilang talahanayang maaaring i-sort ng mga indibidwal na tao. Mabilis mong mahahanap ang sinumang nasa kongregasyon mo, maia-customize kung anong impormasyon ang ipinapakita, at maie-export ang mga resulta. Mahalaga ang mahusay na paghahanap sa pang-araw-araw na gawain sa administrasyon ng simbahan, gaya ng pag-follow up sa mga bisita, paghahanda ng listahan ng contact, at pamamahala ng mga talaan ng miyembro.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan mo ng aktibong account sa B1 Admin na may pahintulot na tingnan ang mga tao. Tingnan ang [Roles & Permissions](roles-permissions.md) kung hindi ka sigurado sa antas ng access mo.
- Dapat may mga tao sa direktoryo ng simbahan mo. Kung wala ka pang naidadagdag, tingnan ang [Adding People](adding-people.md) o [Importing Data](importing-data.md).

</div>

## Mga Sambahayan at Table View

Inililista ng pahinang People ang direktoryo mo ayon sa **sambahayan**, nakaayos alpabetiko. Ipinapakita ng bawat row ang mga larawan ng sambahayan, ang pangalan nito (halimbawa, "The Smith Family"), at ang mga pangalan ng lahat ng nasa loob nito. I-click ang isang sambahayan para buksan ang profile ng head of household, o i-click ang pangalan ng sinumang miyembro para buksan ang taong iyon. Ipinapakita ng bilang sa itaas ng listahan kung ilang sambahayan at tao ang kasalukuyang nakikita.

Gamitin ang toggle na **View as** sa itaas ng listahan para lumipat sa pagitan ng **Households** at **Table**. Naglilista ang view na **Table** ng isang tao bawat row at dito mo maaaring i-sort at piliin ang mga column (tingnan sa ibaba). Naaalala ng B1 ang pinili mo sa device na iyon.

Bilang default, ang pahina ay nag-l-load ng unang bahagi ng direktoryo mo. Kung marami kang tao, i-click ang **Show All Members** sa ibaba ng listahan para i-load ang lahat.

## Mabilisang Paghahanap

Ang kahong **Find a household or person** sa itaas ng pahinang People ay nagbibigay-daan sa iyong hanapin ang mga miyembro nang real time:

1. I-click ang **search box** sa itaas ng pahinang People.
2. Simulang mag-type ng pangalan.
3. Awtomatikong nagfi-filter ang mga resulta habang nagta-type ka (may kaunting paghihintay na mga kalahating segundo para hindi tumakbo ang search sa bawat keystroke).
4. Ina-update ng listahan sa ibaba para ipakita lamang ang mga tugmang resulta.

I-click ang **Clear** (sa ilalim ng search box) para i-reset ang paghahanap at ipakitang muli ang buong direktoryo mo.

:::tip
Hindi mo kailangang pindutin ang Enter. Awtomatikong tumatakbo ang search pagkatapos mong tumigil sa pag-type.
:::

## Pag-sort ng mga Resulta

Sa view na **Table**, nakalista ang mga tao ayon sa apelyido, pagkatapos ang pangalan. Maaari mong i-sort ang direktoryo sa ibang paraan sa pamamagitan ng pag-click sa anumang column header:

1. I-click ang **column header** (halimbawa, **Name** o **Email**) para i-sort ayon sa column na iyon.
2. I-click muli ang parehong header para baligtarin ang ayos ng pag-sort.

Ginagawang madali nitong hanapin ang mga tao nang alpabetiko, ayon sa edad, o ayon sa anumang nakikitang column.

## Pag-customize ng mga Column

Hindi kailangang nakikita ang lahat ng impormasyon nang sabay-sabay. Maaari mong piliin kung aling column ang lalabas sa talahanayan:

1. I-click ang icon na **Select columns** sa header ng pahinang People. (Nalalapat ang mga column sa view na **Table**.)
2. Lagyan ng check o alisin ang check sa mga column para ipakita o itago ang mga ito. Kabilang sa mga available na column ang:
   - **Photo** (Larawan)
   - **Name** (Pangalan)
   - **Email**
   - **Phone** (Telepono)
   - **Address**
   - **Birth Date** (Petsa ng Kapanganakan)
   - **Age** (Edad)
   - **Gender** (Kasarian)
   - **Membership Status** (Katayuan ng Pagiging Miyembro)
   - **Campus**
3. Agad na ina-update ang talahanayan para ipakita ang mga pinili mo.

### Pagpapakita ng Custom Field bilang Column {#showing-custom-fields-as-columns}

May dalawang tab ang column chooser: ang **Standard** ay may mga built-in na column na nakalista sa itaas, at ang **Custom** ay may mga [Custom Fields](../settings/custom-fields.md) ng simbahan mo kasama ang mga tanong mula sa anumang People form. Lagyan ng check ang isang custom field sa tab na **Custom** para idagdag ito bilang column, at lalabas ang halaga ng bawat tao para sa field na iyon sa talahanayan. Ipinapakita ang mga halaga gaya ng sa profile ng tao -- ang mga Yes/No field ay nagbabasa ng *Yes* o *No*, ang mga Multiple Choice field ay nagpapakita ng label ng opsyon, at ipinapakita ang mga petsa bilang maikling petsa. Ang mga taong walang halaga para sa field ay nagpapakita ng blangkong cell.


## Pag-export ng mga Resulta ng Paghahanap

Maaari mong i-download ang kasalukuyang resulta ng paghahanap bilang CSV file anumang oras:

1. Maglapat ng anumang paghahanap o filter na gusto mo.
2. I-click ang button na **Export** sa header ng pahinang People.
3. Magda-download ang CSV file sa computer mo, handa nang buksan sa Excel, Google Sheets, o anumang spreadsheet application.

Para sa mas detalyadong impormasyon tungkol sa pag-export, tingnan ang [Exporting Data](./exporting-data.md).

:::tip
Para sa mas advanced na query -- tulad ng paghahanap sa lahat ng hindi dumalo sa nakalipas na tatlong buwan -- subukan ang feature na [AI Search](./ai-search.md), na nagbibigay-daan sa iyong maghanap gamit ang mga tanong sa natural na wika.
:::

## Advanced na Paghahanap {#advanced-search}

Nagbibigay-daan ang Advanced Search sa iyo na bumuo ng tumpak na filter sa pamamagitan ng pagsasama-sama ng mga kondisyon. Buksan ito sa pag-click sa **Advanced** sa ilalim ng search box sa pahinang People, pagkatapos ay palawakin ang isang kategorya at lagyan ng check ang mga field na gusto mong i-filter, pumipili ng operator at halaga para sa bawat isa. Kabilang sa mga kategorya ang **Names** (Mga Pangalan), **Demographics** (Demograpiko), **Contact** (Kontak), **Membership** (Pagiging Miyembro), **Activity** (Aktibidad -- donations at attendance), at **Custom Fields**.

Inililista ng kategoryang **Custom Fields** ang mga [Custom Fields](../settings/custom-fields.md) ng simbahan mo -- ang mga field na itinakda mo sa Settings para subaybayan ang sarili mong impormasyon (gaya ng petsa ng pag-expire ng background check). Ang mga operator na inaalok ay tumutugma sa uri ng bawat field: sinusuportahan ng mga text field ang *naglalaman / katumbas ng / nagsisimula sa / nagtatapos sa*, sinusuportahan ng mga number field ang mga comparison operator, sinusuportahan ng mga date field ang *katumbas ng / pagkatapos / bago*, at hinahayaan ka ng mga Yes/No at Multiple Choice field na pumili ng halaga. Anumang field na maaari mong i-filter dito ay maaaring i-save bilang buhay na [List](./lists.md).

## Pag-save ng mga Paghahanap bilang mga List

Pagkatapos magpatakbo ng paghahanap, lumilitaw ang button na **Save as List** sa header ng pahinang People. I-click ito para itago ang kasalukuyang query mo sa ilalim ng pangalan at opsyonal na kategorya, para mabilis mo itong mai-load sa mga susunod na sesyon. Tingnan ang [Mga Naka-save na List](./lists.md) para sa buong detalye.
