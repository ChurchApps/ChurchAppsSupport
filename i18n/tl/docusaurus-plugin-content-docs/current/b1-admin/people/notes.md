# Mga Note

<div class="article-intro">

Pinagsasama-sama ng pahinang **Notes** ang mga kamakailang note mula sa buong B1 Admin sa iisang lugar, para makasabay ka sa pastoral care, follow-up, at pagpaplano nang hindi binubuksan ang bawat record. Inililista nito ang mga note na isinulat sa mga tao, sa mga grupong pinamumunuan mo, sa mga event sa calendar, at sa mga workflow card, mula pinakabago, at nagli-link ng bawat isa pabalik sa lugar kung saan ito isinulat.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Lumalabas ang pahinang **Notes** sa menu kung mayroon kang permiso na **Edit People** o namumuno ka sa kahit isang grupo. Tingnan ang [Assigning Roles](./roles-permissions.md).
- Ipinapakita lang ng pahina ang mga note na pinapayagan ka nang basahin. Sumusunod ang bawat tab sa parehong panuntunan ng record na pinagmulan ng mga note (tingnan ang [What Each Tab Shows](#what-each-tab-shows)).

</div>

## Pagbubukas ng Pahina ng Notes

1. Buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas ng B1 Admin) at palawakin ang **People**.
2. I-click ang **Notes**.
3. Bumubukas ang pahina sa tab na **People**. Gamitin ang mga tab sa header ng pahina para lumipat sa pagitan ng **People**, **Groups**, **Events**, at **Workflows**.

## Pagbasa ng Listahan

Ipinapakita ng bawat note sa listahan ang:

- **Saan ito isinulat** -- ang pangalan ng tao, pangalan ng grupo, pamagat ng event, o pamagat ng workflow card. I-click ang pangalan para buksan ang record at basahin ang buong thread o magdagdag ng note.
- **Confidential** -- isang badge sa mga note ng tao na galing sa Confidential Notes section ng tao.
- **Sino ang sumulat at kailan** -- "By" ang pangalan ng may-akda, kasunod ang petsa at oras ng pag-post.
- **Ang mismong note** -- pinaikli sa listahan ang mahahabang note. Buksan ang record para basahin ang buong note.

Ipinapakita muna ang pinakabagong mga note. I-click ang **Load more** sa ibaba para makita ang mas lumang mga note.

Ang mga note na isinulat sa taong nabura na, o pinagsama na sa ibang record, ay hindi lumalabas sa tab na **People**.

Read-only ang pahina ng Notes. Para magdagdag, mag-edit, o sumagot sa isang note, i-click ang pangalan ng record para buksan ito.

## Ano ang Ipinapakita ng Bawat Tab {#what-each-tab-shows}

| Tab | Mga note na ipinapakita | Sino ang makakakita | Ang pag-click sa pangalan ay magbubukas ng |
|-----|-------------|------------------|-------------------------|
| **People** | Mga note sa person record | Mga taong may **Edit People**. Kailangan din ng mga confidential note ang **View Confidential Notes** | Ang mga note ng tao |
| **Groups** | [Leader notes](../groups/group-members.md#leader-notes) sa mga grupo | Tanging mga leader ng bawat grupo, kahit para sa mga administrator | Ang mga note ng grupo |
| **Events** | [Event notes](../calendars/creating-calendars.md#event-notes) | Mga staff na maaaring mag-edit ng content o mag-administer ng calendar, pati sinumang pinapayagan ng setting na **Who can view notes** ng event | Ang calendar ng grupo ng event |
| **Workflows** | Mga note sa [workflow cards](../serving/workflows.md#working-the-board) | Sinumang makakabukas ng card, kabilang ang tao o grupong itinalaga rito | Ang workflow board ng card |

Kung walang makikita kang note sa tab, sinasabi iyon -- halimbawa, "No notes yet for groups you lead."

:::tip
May icon na kampana ang mga thread ng note para sa mga notification. I-click ito para ma-notify ka sa mga bagong note sa thread na iyon (agad magbabago ang icon), at i-click ulit para i-mute. Hindi kailanman lumalabas bilang note sa pahina ng Notes ang mga on/off setting na ito.
:::
