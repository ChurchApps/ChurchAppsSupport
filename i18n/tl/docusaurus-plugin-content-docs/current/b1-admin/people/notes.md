# Mga Tala

<div class="article-intro">

Pinagsasama-sama ng pahinang **Notes** ang mga kamakailang tala mula sa buong B1 Admin sa iisang lugar, para makasabay ka sa pastoral care, mga follow-up, at pagpaplano nang hindi binubuksan ang bawat record. Inililista nito ang mga tala na isinulat sa mga tao, sa mga grupong pinamumunuan mo, sa mga event sa kalendaryo, at sa mga workflow card, mula sa pinakabago, at nagli-link ng bawat isa pabalik sa lugar kung saan ito isinulat.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Lumalabas ang pahinang **Notes** sa menu kung mayroon kang pahintulot na **Edit People** o namumuno ka sa kahit isang grupo. Tingnan ang [Assigning Roles](./roles-permissions.md).
- Ipinapakita lamang ng pahina ang mga tala na pinapayagan ka nang basahin. Sumusunod ang bawat tab sa parehong panuntunan ng record kung saan kabilang ang mga tala (tingnan ang [What Each Tab Shows](#what-each-tab-shows)).

</div>

## Pagbukas ng Pahina ng Notes

1. Buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas ng B1 Admin) at i-expand ang **People**.
2. I-click ang **Notes**.
3. Bumubukas ang pahina sa tab na **People**. Gamitin ang mga tab sa header ng pahina para lumipat sa pagitan ng **People**, **Groups**, **Events**, at **Workflows**.

## Pagbasa ng Listahan

Ang bawat tala sa listahan ay nagpapakita ng:

- **Saan ito isinulat** -- ang pangalan ng tao, pangalan ng grupo, pamagat ng event, o pamagat ng workflow card. I-click ang pangalan para buksan ang record at basahin ang buong thread o magdagdag ng tala.
- **Confidential** -- isang badge sa mga tala ng tao na galing sa seksyong Confidential Notes ng tao.
- **Sino ang sumulat at kailan** -- "By" ang pangalan ng author, kasunod ang petsa at oras ng pagpo-post.
- **Mismong tala** -- pinaiikli sa listahan ang mahahabang tala. Buksan ang record para basahin ang buong tala.

Ipinapakita ng listahan ang pinakabagong tala muna. I-click ang **Load more** sa ibaba para makita ang mas lumang mga tala.

Read-only ang pahina ng Notes. Para magdagdag, mag-edit, o sumagot sa isang tala, i-click ang pangalan ng record para buksan ito.

## Ano ang Ipinapakita ng Bawat Tab {#what-each-tab-shows}

| Tab | Mga tala na ipinapakita | Sino ang makakakita | Ang pag-click sa pangalan ay nagbubukas ng |
|-----|-------------|------------------|-------------------------|
| **People** | Mga tala sa person record | Mga may **Edit People**. Kailangan din ng **View Confidential Notes** para sa mga confidential na tala | Ang mga tala ng tao |
| **Groups** | [Leader notes](../groups/group-members.md#leader-notes) sa mga grupo | Ang mga lider lamang ng bawat grupo, kahit mga administrator | Ang mga tala ng grupo |
| **Events** | [Event notes](../calendars/creating-calendars.md#event-notes) | Staff na may pahintulot na mag-edit ng content o mag-administer ng mga kalendaryo, pati ang sinumang pinapayagan ng setting ng event na **Who can view notes** | Ang kalendaryo ng grupo ng event |
| **Workflows** | Mga tala sa [workflow cards](../serving/workflows.md#working-the-board) | Sinumang makakabukas ng card, kasama ang taong o grupong nakatalaga rito | Ang workflow board ng card |

Kapag wala pang nakikita kang tala sa isang tab, sasabihin ito -- halimbawa, "No notes yet for groups you lead."

:::tip
May icon na kampana ang mga thread ng tala para sa mga notification. I-click ito para makatanggap ng abiso tungkol sa mga bagong tala sa thread na iyon (agad na magbabago ang icon), at i-click ulit para i-mute ang mga ito. Hindi kailanman lumalabas bilang mga tala sa pahina ng Notes ang mga on/off setting na ito.
:::
