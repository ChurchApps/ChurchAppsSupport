# Mga Batch ng Donasyon

<div class="article-intro">

Pinagsasama-sama ng mga batch ang iyong mga donasyon para mas madaling subaybayan at i-reconcile. Karaniwang kumakatawan ang isang batch sa iisang koleksyon, tulad ng handog tuwing Linggo o espesyal na event. Nakakatulong ang paggamit ng mga batch para manatili kang organisado at madaling ma-verify na tugma ang mga talaan mo sa aktwal na mga deposito.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Tiyaking [naka-set up na ang iyong mga fund](funds.md) para magamit ang mga ito sa pagtatala ng mga donasyon
- Kakailanganin mo ng access sa seksyong **Donations** sa B1 Admin

</div>

## Ang Pahina ng Batches

Kapag pumunta ka sa **Donations > Batches**, makikita mo ang listahan ng lahat ng batch mo. Bawat row ay nagpapakita ng:

- **Name** -- ang label na ibinigay mo sa batch
- **Date** -- ang petsa ng koleksyon
- **Donations** -- ang bilang ng mga indibidwal na donasyon sa batch
- **Total** -- ang pinagsamang halaga sa dolyar

Ang header sa itaas ay nagpapakita ng buod na estadistika kasama ang kabuuang bilang ng mga batch, kabuuang bilang ng mga donasyon sa lahat ng batch, at kabuuang halaga sa dolyar.

## Paggawa ng Bagong Batch

1. I-click ang **Add Batch** sa itaas ng pahina.
2. Maglagay ng naglalarawang pangalan (hal., "Sunday Offering - Feb 9").
3. Piliin ang petsa ng koleksyon.
4. I-click ang **Save**.

Lalabas sa listahan ang bago mong batch, handa nang dagdagan ng mga donasyon.

## Paggamit ng mga Batch

- **Tingnan ang mga donasyon** -- i-click ang pangalan ng batch para buksan ito at makita ang lahat ng indibidwal na donasyong nilalaman nito. Mula rito, maaari kang magdagdag, mag-edit, o mag-alis ng mga donasyon.
- **I-edit ang detalye ng batch** -- i-click ang button na **Edit** sa row ng batch para palitan ang pangalan o petsa nito.
- **Mag-sort** -- gamitin ang mga header ng column para i-sort ang mga batch ayon sa pangalan o petsa.
- **Mag-export** -- i-click ang **Export** para i-download ang listahan ng batch mo bilang spreadsheet (CSV).

## Pag-print ng Batch

Buksan ang isang batch at i-click ang icon na **Print** (printer) sa itaas ng listahan ng mga donasyon para mag-print ng papel na kopya para sa counting team mo o sa mga talaan ng deposito. Kasama sa printout ang:

- Ang pangalan ng iyong simbahan, ang pangalan ng batch, at ang petsa ng batch
- Bawat donasyon sa batch, kasama ang pangalan ng nagbigay, paraan, mga tala, petsa, at halaga (ang mga na-refund na handog ay may guhit at may markang na-refund)
- **Fund Subtotals** -- ang kabuuang naibigay sa bawat fund sa batch
- **Batch Total** -- ang pinagsamang halaga ng buong batch

Lalabas lamang ang Print icon kapag may kahit isang donasyon na ang batch.

### Pag-print ng Ilang Batch nang Sabay-sabay

Para i-print ang bawat batch mula sa isang panahon nang minsanan -- halimbawa, lahat ng deposito noong nakaraang buwan -- i-click ang icon na **Print** (printer) sa header ng listahan ng **Batches**, katabi ng **Export**. Magbubukas ang pahinang **Print Batches** na may **Start Date** at **End Date** na naka-default sa nakaraang 30 araw. Palitan ang alinman sa dalawang petsa para pumili ng ibang saklaw.

Ipi-print ayon sa pagkakasunod ng petsa ang bawat batch na may petsang nasa loob ng saklaw (kasama ang start at end date), isang batch kada pahina, gamit ang parehong layout ng printout ng iisang batch. Hindi isinasama ang mga batch na walang donasyon, at kung walang donasyon ang alinman sa mga batch sa saklaw, makikita mo ang "No batches with donations in this date range." I-click ang **Print** para buksan ang print dialog ng iyong browser, o **Close** para bumalik sa listahan ng batch.

## Pag-export ng Batch sa QuickBooks Online

Buksan ang isang batch at i-click ang **Export for QuickBooks** para i-download ang batch bilang journal entry na maaaring i-import ng QuickBooks Online (**Settings > Import Data > Journal Entries**). Naglalaman ang file ng isang debit sa **Undeposited Funds** para sa kabuuan ng batch at isang credit kada fund, gamit ang pangalan ng bawat fund bilang pangalan ng account. Hihilingin ng QuickBooks na itugma mo ang mga pangalang iyon sa iyong chart of accounts habang nag-i-import, kaya pangalanan ang mga fund mo gaya ng pagpapangalan ng bookkeeper mo sa mga income account, o i-map ang mga ito nang isang beses sa pag-import.

:::tip
Pangalanan nang pare-pareho ang mga batch mo para madali itong mahanap sa susunod. Ang paglalagay ng petsa at uri ng koleksyon (hal., "Sunday AM - 2025-02-09") ay nagpapanatiling organisado ng listahan mo habang dumarami ito.
:::

## Mga Susunod na Hakbang

Kapag mayroon ka nang batch, tingnan ang [Pagtatala ng mga Donasyon](recording-donations.md) para malaman kung paano magdagdag ng mga indibidwal na donasyon dito. Maaari mo ring [i-import ang mga transaksyon sa Stripe](stripe-import.md) para awtomatikong gumawa ng mga batch mula sa online giving.
