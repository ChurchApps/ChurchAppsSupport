# Mga Donasyon

<div class="article-intro">

Ang seksyong Donations sa B1 Admin ay nagbibigay ng lahat ng kailangan mo para pamahalaan ang giving ng iyong simbahan. Mula sa pagtatala ng lingguhang handog hanggang sa paggawa ng taunang tax statement, nakaayos sa iisang lugar ang lahat ng iyong kasangkapan sa donasyon para manatili kang nakakatutok sa pananalapi ng iyong simbahan.

</div>

## Mga Sub-Section {#sub-sections}

Makikita mo ang mga sumusunod na pahina sa seksyong Donations:

### Summary {#summary}

Nagbibigay ang pahinang **Summary** ng visual na pangkalahatang-tanaw ng lahat ng aktibidad sa giving. Nagpapakita ito ng mga chart at naka-filter na report para mabilis mong makita ang mga trend ng donasyon sa iyong simbahan. Tingnan ang [Donation Reports](donation-reports.md) para sa karagdagang detalye sa paggamit ng summary at mga kasangkapan sa pag-uulat.

### Batches {#batches}

Hinahayaan ka ng **[Batches](batches.md)** na pagsamahin ang mga donasyon -- halimbawa, lahat ng tseke at cash na nakolekta sa handog tuwing Linggo. Sinusubaybayan ng bawat batch ang bilang ng donasyon at kabuuang halaga nito para madaling i-reconcile. Kapag nabilang na ang batch, maaaring isara ito ng sinumang may **Edit Donations** para hindi na ito mabago ng mga boluntaryong nagbibilang. Maaaring magdagdag ng handog sa mga bukas na batch ang mga boluntaryong may permission na **Enter Donations** nang hindi nakikita ang iba pang bahagi ng seksyong Donations.

### Funds {#funds}

Ikinakategorya ng **[Funds](funds.md)** ang iyong mga donasyon ayon sa layunin. Kabilang sa mga karaniwang halimbawa ang General Fund, Building Fund, at Missions. Maaari mong markahan ang bawat fund bilang tax-deductible o hindi.

### Campaigns {#campaigns}

Sinusubaybayan ng **[Campaigns](campaigns.md)** ang isang fundraising drive tungo sa isang layunin, kasama ang mga pledge ng mga miyembro kasabay ng aktwal na handog sa fund ng campaign.

### Giving Statements {#giving-statements}

Gumagawa ang pahinang **[Giving Statements](giving-statements.md)** ng taunang giving statement para sa iyong mga donor. Maaari kang mag-download ng hiwalay na CSV file o mag-print ng lahat ng statement nang sabay-sabay.

### Failed Gifts {#failed-gifts}

Inililista ng **Failed Gifts** ang mga paulit-ulit na online na handog na hindi nakolekta ng payment gateway, kasama ang donor, halaga, petsa, at mensahe ng gateway, at may button na **Retry**. Tingnan ang [Failed Recurring Gifts](online-giving-setup.md#failed-recurring-gifts).

### Stripe Import {#stripe-import}

Kung tumatanggap ka ng online na donasyon sa pamamagitan ng Stripe, hinahayaan ka ng **[Stripe Import](stripe-import.md)** tool na ilipat ang mga transaksyong iyon sa B1 Admin para nasa iisang sistema ang lahat.

## Online Giving {#online-giving}

Nakakonekta ang B1 Admin sa **Stripe**, **Kingdom Funding** at **Paystack** para sa pagtanggap ng online na donasyon. Kapag na-configure na, maaaring magbigay ang mga miyembro sa pamamagitan ng iyong B1.church site at awtomatikong lalabas sa iyong mga talaan ang mga donasyong iyon. Tingnan ang [Online Giving Setup](online-giving-setup.md) para makapagsimula.

:::tip
Kung bago ka pa lang sa donasyon sa B1 Admin, magsimula sa [pag-set up ng iyong mga fund](funds.md), pagkatapos [gumawa ng unang batch](batches.md) at [magtala ng mga donasyon](recording-donations.md) dito.
:::
