# Mga Campaign at Pledge

<div class="article-intro">

Hinahayaan ka ng mga campaign na magsagawa ng fundraising drive tungo sa partikular na layunin -- isang building fund, missions trip, o espesyal na proyekto -- at subaybayan ang mga pledge ng mga miyembro kasabay ng aktwal na donasyon para makita mo ang iyong progreso sa real-time.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- I-set up ang iyong [mga donation fund](./funds.md) -- nakatali ang bawat campaign sa isang fund
- Kailangan mo ng **View Donation Summaries** na permission para makita ang mga campaign, at **Edit Donations** para magdagdag o magpalit ng campaign at pledge

</div>

## Pagbubukas ng Campaigns {#opening-campaigns}

Sa B1 Admin, buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas), i-expand ang **Donations**, at i-click ang **Campaigns**. Makikita mo ang table ng lahat ng campaign kasama ang kanilang fund, mga petsa, goal amount, kabuuang na-pledge, at kabuuang naibigay hanggang ngayon. Ang linyang buod sa itaas ng table ay nagpapakita ng bilang ng campaign at pinagsamang halaga ng pledge at bigay.

## Paggawa ng Campaign {#creating-a-campaign}

1. I-click ang **Add Campaign** sa itaas ng pahina.
2. Punan ang mga detalye ng campaign:
   - **Name** *(kinakailangan)* -- ang display name ng campaign (halimbawa, "Building Fund 2026").
   - **Fund** *(kinakailangan)* -- ang donation fund na nauugnay sa campaign na ito.
   - **Goal Amount** *(opsyonal)* -- ang target na halaga ng campaign. Kapag walang goal, walang progress bar na ipapakita ang campaign.
   - **Start Date** *(kinakailangan, nagsisimula sa petsa ngayon)* at **End Date** *(opsyonal)* -- ang panahon ng fundraising. Kapag walang end date, lalabas na **Ongoing** ang campaign.
   - **Description** -- maikling paglalarawan ng campaign.
   - **Show progress on giving page** -- ipakita sa mga donor ang progreso ng campaign sa iyong giving page.
   - **Allow donors to pledge** -- payagan ang mga donor na gumawa ng sarili nilang pledge sa campaign.
3. I-click ang **Save**. Kung nawawala ang pangalan, fund, o start date, sasabihin ng form kung alin ang pupunan.

## Pagsubaybay ng Progreso {#tracking-progress}

Ipinapakita ng bawat row ng campaign ang:

- **Goal** -- ang target mong halaga
- **Pledged** -- ang kabuuang halagang ipinangako ng mga miyembrong ibigay
- **Given** -- ang kabuuang aktwal na naidonate sa fund ng campaign na ito sa loob ng panahon ng campaign
- **Progress** -- bar at porsyento na nagpapakita kung gaano na kalayo ang narating mo tungo sa goal

I-click ang pangalan ng campaign para buksan ang detail view. Ipinapakita nito ang porsyento ng goal na naabot at inililista ang bawat pledge kasama ang ipinangakong halaga at naibigay ng bawat donor, at isang status (**Not Started**, **In Progress**, **Fulfilled**, **Beyond Pledged**, o **Non-Pledged** para sa mga donor na nagbigay nang walang pledge). Nakalista ang mga donor ayon sa apelyido, saka ayon sa pangalan; i-click ang column header para i-sort ayon sa column na iyon. I-click ang **Export** sa itaas ng detail view para i-download ang listahan ng pledge bilang CSV.

## Pagdaragdag ng Pledge {#adding-pledges}

Ang pledge ay pangako ng mga miyembro na magbigay para sa isang campaign. Para magtala ng pledge:

1. Buksan ang isang campaign.
2. I-click ang **Add Pledge** sa itaas ng pahina.
3. Hanapin ang **person** na gagawa ng pledge at idagdag sila.
4. Ilagay ang **Pledge Amount**. Dapat itong mas malaki sa zero.
5. I-click ang **Save**.

Lumalabas ang mga pledge sa detail ng campaign at nakakatulong sa kabuuang **Pledged** sa listahan ng campaign. Para baguhin ang halaga ng pledge, i-click ang **Edit** sa row nito; para alisin ang pledge, i-click ang **Edit** at pagkatapos ang **Delete**.

:::tip
Hiwalay ang mga pledge sa aktwal na donasyon. Sinusubaybayan ng pledge ang pangako; itinatala naman ng donasyon ang aktwal na handog. Parehong ipinapakita sa campaign para makita mo kung gaano kahusay natutupad ang mga pledge.
:::

## Pag-edit o Pagbura ng Campaign {#editing-or-deleting-a-campaign}

I-click ang **Edit** sa anumang row ng campaign (o ang **Edit Campaign** sa itaas ng detail view ng campaign) para i-update ang alinman sa mga detalye nito. Sa edit form, i-click ang **Delete** para permanenteng alisin ang campaign at ang mga pledge nito; babalik ka sa listahan ng campaign. Hindi nabubura ng pagbura ng campaign ang anumang donasyong naitala sa fund nito.
