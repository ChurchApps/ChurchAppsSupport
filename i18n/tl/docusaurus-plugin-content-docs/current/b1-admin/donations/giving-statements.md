# Mga Statement ng Pagbibigay

<div class="article-intro">

Sa pagtatapos ng bawat taon, ang iyong mga donor ay kailangan ng isang buod ng kanilang tax-deductible na pagbibigay para sa kanilang mga talaan. Ang B1 Admin ay ginagawang madali ang paglikha ng mga statement na ito para sa lahat ng donor nang sabay-sabay, na nagtitipid sa iyo ng maraming oras ng manu-manong paggawa.

</div>

<div class="prereqs">
<h4>Bago ka magsimula</h4>

- Suriin na ang iyong [funds](funds.md) ay tama na minarkahan bilang **Tax Deductible** -- ang mga donasyon sa tax-deductible na funds lamang ang lumalabas sa mga statement
- Tiyakin na ang lahat ng donasyon ay [naitala](recording-donations.md) at ang anumang online transactions ay [na-import mula sa Stripe](stripe-import.md)

</div>

## Pag-access sa Mga Statement ng Pagbibigay

1. Sa **B1 Admin**, buksan ang **section menu** sa itaas na sulok sa kaliwa at piliin ang **Donations**.
2. I-click ang **Statements**.

## Paglikha ng mga Statement

1. Pumili ng **taon** mula sa dropdown sa tuktok ng pahina. Maaari kang pumili ng kasalukuyang taon o alinman sa limang nakaraang taon.
2. Ang pahina ay nagpapakita ng mga istatistika ng buod para sa taong iyon, kabilang:
   - **Total donors** -- ang bilang ng mga taong nagbigay
   - **Total donations** -- ang bilang ng mga indibidwal na talaan ng donasyon
   - **Total amount** -- ang pinagsama-samang halaga ng dolyar ng lahat ng pagbibigay

## Pag-download ng mga Statement

Mayroon kang dalawang opsyon para makakuha ng mga statement sa iyong mga donor:

### Mag-download bilang CSV Files

I-click ang **Download ZIP** upang mag-download ng ZIP file na naglalaman ng isang indibidwal na CSV file para sa bawat donor. Ito ay kapaki-pakinabang kung nais mong magpadala ng mga statement nang indibidwal o mag-import sa ibang sistema.

### Mag-print ng Lahat ng Mga Statement

I-click ang **Print All** upang magbukas ng isang printable na paningin ng statement ng bawat donor sa iyong browser. Mula doon, gamitin ang print function ng iyong browser upang ipadala sa iyong printer. Bawat statement ay nagsisimula sa isang bagong pahina kaya handa na ang mga ito upang tukupin at ipadala sa koreo.

:::tip
Patakbuhin ang iyong mga statement nang maaga sa Enero habang sariwang mga talaan mo. Dalawang beses na suriin na ang iyong mga funds ay tama na minarkahan bilang tax-deductible bago lumikha ng mga statement -- ang mga donasyon sa tax-deductible na funds lamang ang kasama.
:::

:::info
Ang mga statement ng pagbibigay ay kasama lamang ang mga donasyon na nakatalagang sa mga funds na may enabled na **Tax Deductible** setting. Kung ang isang fund ay hindi minarkahan bilang tax-deductible, ang mga donasyon nito ay hindi lalabas sa statement. Maaari mong pamahalaan ang setting na ito sa [Funds](funds.md) page.
:::

## Mga Format ng Resibo para sa Canada, Australia at New Zealand

Ang mga simbahan sa labas ng United States ay maaaring baguhin ang statement sa opisyal na receipt layout ng kanilang bansa. Pumunta sa **Settings**, buksan ang **Giving** section, at itakda ang **Statement Format** sa **Canada**, **Australia** o **New Zealand**, pagkatapos ay punan ang mga field na lumalabas: ang iyong numero ng pagsasang-ayon (CRA registration number, ABN, o NZ charity registration number), ang address ng iyong organisasyon, ang pangalan ng taong inilalawak na mag-sign ng mga resibo, at para sa Canada ang lungsod kung saan inilalabas ang mga resibo.

Ang mga statement ay dadalhin ang wording na inaasahan ng iyong tax authority (para sa Canada, "Official Receipt for Income Tax Purposes" na may CRA reference), isang numero ng resibo sa anyo ng `YEAR-DONORID`, ang eligible amount na kinukuha mula sa tax-deductible na funds lamang, at isang hiwalay na linya para sa anumang mga regalo sa mga non-deductible na funds. Ang mga donor ay nakikita ang parehong bloke ng resibo kapag nag-print ng kanilang sariling statement mula sa B1.church.

## Mga Susunod na Hakbang

Kung kailangan mong suriin ang mga detalye ng donasyon bago lumikha ng mga statement, bisitahin ang [Donation Reports](donation-reports.md) page o suriin ang indibidwal na [batches](batches.md).
