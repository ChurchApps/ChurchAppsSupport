# Pamahalaan ang mga Boluntaryo sa Linggo

<div class="article-intro">

I-set up ang iyong mga koponan ng boluntaryo, gumawa ng lingguhang plano ng serbisyo, magtalaga ng mga posisyon, bumuo ng pagkakasunod-sunod ng serbisyo na may mga awit ng pagsamba, at magtalaga ng mga gawain sa Linggo. Sa pagtatapos, makikita na ng iyong mga boluntaryo ang kanilang mga atas sa B1 website at mobile app, at maaari na nilang tanggapin o tanggihan ang mga ito nang direkta.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Account sa B1 Admin na may admin access
- Mga boluntaryong [naidagdag na sa iyong direktoryo ng mga tao](../people/adding-people.md)

</div>

## Hakbang 1: Gumawa ng mga Koponan ng Boluntaryo

Ayusin ang iyong mga boluntaryo sa mga koponan para mapamahalaan ang mga atas ayon sa larangan ng ministeryo.

Sundin ang mga gabay na [Creating Groups](../groups/creating-groups.md) at [Group Members](../groups/group-members.md) para:

1. Gumawa ng kategorya (hal., "Mga Koponan sa Linggo ng Umaga")
2. Gumawa ng mga grupo tulad ng "Koponan ng Pagsamba", "Sound at Media", "Mga Tagasalubong", "Mga Boluntaryo sa Ministeryo ng mga Bata"
3. Idagdag ang mga boluntaryo sa bawat grupo sa pamamagitan ng paghahanap ng kanilang pangalan at pag-click sa **Add**

:::tip
Italaga ang mga lider ng koponan gamit ang icon na bituin (**Make Leader**) sa listahan ng mga miyembro ng grupo (i-click ang **All members** sa pahina ng grupo). Maaaring pamahalaan ng mga lider ang kalendaryo ng sarili nilang grupo at ikoordina ang kanilang koponan.
:::

## Hakbang 2: Buuin ang Iyong Library ng Awit

Magdagdag ng mga awit ng pagsamba para maisama mo ang mga ito sa mga plano ng serbisyo bawat linggo.

Sundin ang gabay na [Songs](../serving/songs.md) para:

1. Magdagdag ng mga awit ng pagsamba kasama ang mga pamagat, artista, at haba nito
2. Para sa bawat awit, magdagdag ng mga arrangement na may lyrics at mga key
3. Magdagdag ng mga panlabas na link sa mga pagtatanghal sa YouTube, chord chart, o sheet music

:::info
Ang mga awit na idinagdag dito ay maisasama sa anumang plano ng serbisyo sa hinaharap. Buuin ang library nang minsan, at gamitin ito tuwing linggo.
:::

## Hakbang 3: Gumawa ng Plano ng Serbisyo

Ang mga plano ay ang lingguhang atas na nagsasabi sa mga boluntaryo kung saan sila kailangan.

Sundin ang gabay na [Plans](../serving/plans.md) para:

1. Pumunta sa Serving, piliin ang iyong tab ng ministeryo, at buksan ang iyong uri ng plano
2. I-click ang **New Plan** at piliin ang petsa ng serbisyo. Para mag-set up ng ilang Linggo nang sabay, kopyahin mula sa nakaraang plano at ilagay ang bilang sa **Number of plans**
3. Sa seksyong **Serving Team Assignments** ng plano, magdagdag ng mga posisyon at italaga ang mga boluntaryo sa mga ito
4. Makikita ng mga boluntaryo ang kanilang katayuan ng atas (Requested, Confirmed, Pending)
5. I-on ang [mga paalala para sa boluntaryo](../serving/plans.md#volunteer-reminders) para sa uri ng plano para mapaalalahanan ang mga boluntaryo sa pamamagitan ng push notification, email, o text bago ang bawat serbisyo

## Hakbang 4: Buuin ang Pagkakasunod-sunod ng Serbisyo

Ilatag ang daloy ng iyong serbisyo mula simula hanggang wakas.

Sundin ang gabay na [Service Order](../serving/service-order.md) para:

1. Buksan ang iyong plano at hanapin ang seksyong **Order of Service** sa itaas
2. I-click ang **Add** para magdagdag ng mga bahagi: mga awit ng pagsamba (mula sa iyong library), panalangin, pagbasa ng kasulatan, anunsyo, mensahe, handog, at pangwakas
3. I-drag at i-drop ang mga item para baguhin ang ayos ng daloy ng serbisyo

:::info
Ang mga pagkakasunod-sunod ng serbisyo ay tiyak sa bawat plano. Ang mga pagbabago rito ay hindi nakakaapekto sa ibang plano o sa master library ng mga awit.
:::

## Hakbang 5: Magtalaga ng mga Gawain sa Linggo

Subaybayan ang mga natatanging responsibilidad sa Linggo para walang makaligtaan.

Sundin ang gabay na [Tasks](../serving/tasks.md) para:

1. Gumawa ng mga gawain para sa mga responsibilidad tulad ng "Ihanda ang mga elemento ng komunyon", "Mag-print ng bulletin", o "I-set up ang kagamitan sa sound"
2. Italaga ang bawat gawain sa taong o grupong responsable
3. Lalabas ang mga gawain sa ilalim ng **Serving > My Work**, sa dashboard ng itinalagang tao, at sa mobile app

:::info
Hindi na gumagawa ng mga gawaing paulit-ulit sa iskedyul ang B1 Admin. Para sa mga paulit-ulit na proseso na naglilipat ng mga tao sa mga hakbang, gamitin ang [Workflows](../serving/workflows.md) na may schedule trigger.
:::

## Hakbang 6: I-enable ang Self-Service Signup (Opsyonal)

Hayaang mag-sign up ang mga boluntaryo sa mga posisyon nang sila mismo, sa halip na maghintay ng atas mula sa admin.

1. Kapag gumagawa o nag-e-edit ng plano, magtakda ng **Signup Deadline** (ilang oras bago ang serbisyo) para kontrolin kung kailan magsasara ang self-signup. Ang mga oras ay binibilang paatras mula sa unang oras ng serbisyo ng plano. Iwanang blangko kung walang deadline. Ang mga bagong plano ay magsisimula sa deadline ng nakaraang plano.
2. Opsyonal, i-toggle ang **Show volunteer names on signup page** para makita ng mga boluntaryo kung sino pa ang nakapag-sign up.
3. Para sa bawat posisyon, lagyan ng check ang checkbox na **Allow Self-Signup** para maging available ito para sa self-service.
4. Magdagdag ng **Description** sa bawat posisyon para malaman ng mga boluntaryo kung ano ang kasama sa tungkulin.

Kapag nagawa na ang mga posisyon para sa self-signup, awtomatiko na itong lalabas sa mga pahina ng pag-sign up ng boluntaryo sa [B1.church at sa B1 App](../../b1-church/serving/volunteer-signup.md). Makakapagbasa ang mga miyembro ng mga bukas na posisyon, makikita kung ilan pang puwesto ang natitira, at makakapag-sign up sa isang pindot lamang.

:::tip
Paghaluin ang mga posisyong itinalaga ng admin at mga posisyong para sa self-signup sa iisang plano. Halimbawa, italaga nang direkta ang iyong lider ng pagsamba, ngunit hayaang pumili ng sarili ang mga tagasalubong at tagapaghain ng kape.
:::

## Hakbang 7: Ipaalam sa mga Boluntaryo

Awtomatikong makikita ng mga naitalagang boluntaryo ang kanilang mga plano at makakasagot sila.

1. Makikita ng mga boluntaryo ang kanilang mga plano sa [B1.church at sa B1 App](../../b1-church/plans/viewing-plans.md)
2. Maaari nilang tanggapin o tanggihan nang direkta ang mga atas mula sa kanilang telepono o kompyuter
3. Maaari silang magtakda ng mga blockout date para sa mga linggong hindi sila available
4. Maaaring i-print ang mga plano para sa mga rehearsal o ipaskil sa likod ng entablado
5. Maaaring magbasa at mag-sign up ang mga boluntaryo para sa mga bukas na posisyon sa pamamagitan ng [pahina ng pag-sign up ng boluntaryo](../../b1-church/serving/volunteer-signup.md)

:::tip
Nagpapadala ang B1 App ng push notification para alertuhan ang mga boluntaryo kapag may bago silang atas o may nagbago sa kanilang plano.
:::

## Tapos Ka Na!

Naka-set up na ang iyong sistema ng pamamahala ng boluntaryo. Bawat linggo, gumawa lamang ng bagong plano, magtalaga ng mga posisyon, at makikita na ng iyong koponan ang lahat sa kanilang telepono o kompyuter.
