# Pamahalaan ang Mga Boluntaryo sa Linggo

<div class="article-intro">

I-set up ang iyong mga team ng boluntaryo, gumawa ng lingguhang service plan, magtalaga ng mga posisyon, bumuo ng service order na may mga awit ng pagsamba, at magtalaga ng mga gawain tuwing Linggo. Pagkatapos nito, makikita na ng iyong mga boluntaryo ang kanilang mga takdang-gawain sa B1 website at mobile app, at maaari nilang tanggapin o tanggihan ang mga ito nang direkta.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- B1 Admin account na may admin access
- Mga boluntaryong [naidagdag na sa iyong people directory](../people/adding-people.md)

</div>

## Hakbang 1: Gumawa ng Mga Team ng Boluntaryo

Ayusin ang iyong mga boluntaryo sa mga team para mapamahalaan mo ang mga takdang-gawain ayon sa lugar ng ministry.

Sundin ang mga gabay na [Creating Groups](../groups/creating-groups.md) at [Group Members](../groups/group-members.md) para:

1. Gumawa ng kategorya (halimbawa, "Sunday Morning Teams")
2. Gumawa ng mga grupong gaya ng "Worship Team", "Sound & Media", "Greeters", "Kids Ministry Volunteers"
3. Idagdag ang mga boluntaryo sa bawat grupo sa pamamagitan ng paghahanap ng kanilang pangalan at pag-click sa Add

:::tip
Magtalaga ng mga team leader gamit ang star icon (**Make Leader**) sa listahan ng miyembro ng grupo (i-click ang **All members** sa pahina ng grupo). Maaaring pamahalaan ng mga leader ang sarili nilang group calendar at i-coordinate ang kanilang team.
:::

## Hakbang 2: Buuin ang Iyong Song Library

Magdagdag ng mga awit ng pagsamba para maisama mo ang mga ito sa mga service plan tuwing linggo.

Sundin ang gabay na [Songs](../serving/songs.md) para:

1. Magdagdag ng mga awit ng pagsamba kasama ang mga pamagat, artista, at tagal
2. Para sa bawat awit, magdagdag ng mga arrangement na may lyrics at key
3. Magdagdag ng mga external link sa mga pagtatanghal sa YouTube, chord chart, o sheet music

:::info
Maaaring isama sa anumang service plan sa hinaharap ang mga awit na idinagdag dito. Buuin ang iyong library nang isang beses, at gamitin muli ito kada linggo.
:::

## Hakbang 3: Gumawa ng Service Plan

Ang mga plan ay ang mga takdang-gawain kada linggo na nagsasabi sa mga boluntaryo kung saan sila kailangan.

Sundin ang gabay na [Plans](../serving/plans.md) para:

1. Pumunta sa Serving, piliin ang iyong ministry tab, at buksan ang iyong uri ng plan
2. I-click ang **New Plan** at piliin ang petsa ng serbisyo. Para mag-set up ng ilang Linggo nang sabay, kopyahin mula sa nakaraang plan at ilagay kung ilan sa **Number of plans**
3. Sa seksyong **Serving Team Assignments** ng plan, magdagdag ng mga posisyon at italaga ang mga boluntaryo sa mga ito
4. Makikita ng mga boluntaryo ang kanilang status ng takdang-gawain (Requested, Confirmed, Pending)
5. I-on ang [volunteer reminders](../serving/plans.md#volunteer-reminders) para sa uri ng plan para mapaalalahanan ang mga boluntaryo sa pamamagitan ng push, email, o text bago ang bawat serbisyo

## Hakbang 4: Buuin ang Service Order

Ilatag ang daloy ng iyong serbisyo mula simula hanggang katapusan.

Sundin ang gabay na [Service Order](../serving/service-order.md) para:

1. Buksan ang iyong plan at hanapin ang seksyong **Order of Service** sa itaas
2. I-click ang **Add** para magdagdag ng mga elemento: mga awit ng pagsamba (mula sa iyong library), panalangin, pagbasa ng kasulatan, anunsyo, sermon, offering, pagtatapos
3. I-drag at i-drop ang mga item para muling ayusin ang daloy ng serbisyo

:::info
Partikular sa plan ang mga service order. Hindi nito naaapektuhan ang ibang plan o ang master song library.
:::

## Hakbang 5: Magtalaga ng Mga Gawain Tuwing Linggo

Subaybayan ang mga one-off na responsibilidad tuwing Linggo para walang mapabayaan.

Sundin ang gabay na [Tasks](../serving/tasks.md) para:

1. Gumawa ng mga gawain para sa mga responsibilidad gaya ng "Prepare communion elements", "Print bulletins", o "Set up sound equipment"
2. Italaga ang bawat gawain sa taong responsable o sa grupo
3. Lumalabas ang mga gawain sa ilalim ng **Serving > My Work**, sa dashboard ng itinalagang tao, at sa mobile app

:::info
Hindi na gumagawa ng mga gawain ang B1 Admin nang paulit-ulit ayon sa iskedyul. Para sa mga paulit-ulit na proseso na naglilipat ng tao sa mga hakbang, gamitin ang [Workflows](../serving/workflows.md) na may schedule trigger.
:::

## Hakbang 6: I-enable ang Self-Service Signup (Opsyonal)

Hayaang magpatala ang mga boluntaryo sa mga posisyon nang sila mismo sa halip na maghintay ng takdang-gawain mula sa admin.

1. Kapag gumagawa o nag-e-edit ng plan, magtakda ng **Signup Deadline** (ilang oras bago ang serbisyo) para kontrolin kung kailan magsasara ang self-signup. Binibilang ang mga oras pabalik mula sa unang oras ng serbisyo ng plan. Iwanang blangko para walang deadline. Ang mga bagong plan ay nagsisimula sa deadline ng nakaraang plan.
2. Opsyonal, i-toggle ang **Show volunteer names on signup page** para makita ng mga boluntaryo kung sino pa ang nakapagpatala.
3. Para sa bawat posisyon, lagyan ng check ang kahon na **Allow Self-Signup** para maging available ito para sa self-service.
4. Magdagdag ng **Description** sa bawat posisyon para malaman ng mga boluntaryo kung ano ang kinasasangkutan ng tungkulin.

Kapag nagawa na ang mga self-signup na posisyon, awtomatiko silang lilitaw sa mga volunteer signup page sa [B1.church](../../b1-church/serving/volunteer-signup.md) at sa [B1 Mobile app](../../b1-mobile/serving/volunteer-signup.md). Maaaring tingnan ng mga miyembro ang mga bukas na posisyon, makita kung ilan pang puwesto ang natitira, at magpatala gamit ang isang click.

:::tip
Paghaluin ang mga posisyong itinatalaga ng admin at ang mga self-signup sa iisang plan. Halimbawa, italaga nang direkta ang iyong worship leader pero hayaang pumili ng sarili ang mga greeter at coffee server.
:::

## Hakbang 7: Ipaalam sa Mga Boluntaryo

Awtomatikong nakikita ng mga itinalagang boluntaryo ang kanilang mga plan at makakasagot sila.

1. Makikita ng mga boluntaryo ang kanilang mga plan sa [B1.church](../../b1-church/plans/viewing-plans.md) at sa [B1 Mobile app](../../b1-mobile/serving/viewing-plans.md)
2. Maaari nilang tanggapin o tanggihan ang mga takdang-gawain nang direkta mula sa alinmang platform
3. Maaari silang magtakda ng blockout date para sa mga linggong hindi sila available
4. Maaaring i-print ang mga plan para sa rehearsal o i-post sa backstage
5. Maaaring tingnan at magpatala ang mga boluntaryo sa mga bukas na posisyon sa pamamagitan ng [volunteer signup page](../../b1-church/serving/volunteer-signup.md)

:::tip
Nagbibigay ng push notification sa mobile app na nagpapaalam sa mga boluntaryo kapag may bago silang takdang-gawain o nagbago ang mga plan.
:::

## Tapos Ka Na!

Naka-set up na ang iyong sistema ng pamamahala ng boluntaryo. Kada linggo, gumawa ng bagong plan, magtalaga ng mga posisyon, at makikita ng iyong team ang lahat sa kanilang telepono o computer.
