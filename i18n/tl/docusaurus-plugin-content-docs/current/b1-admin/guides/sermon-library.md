# Buuin ang Iyong Aklatan ng Sermon at Live Stream

<div class="article-intro">

Ilagay online ang iyong archive ng sermon at i-set up ang live streaming — mula sa pag-import ng iyong kasalukuyang YouTube o Vimeo library hanggang sa pag-iskedyul ng paulit-ulit na live na serbisyo na may interaktibong chat. Sa pagtatapos, makakapanood na ang iyong kongregasyon ng mga nakaraang sermon at makakasali sa mga live na serbisyo sa iyong website at mobile app.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Account sa B1 Admin na may pahintulot sa pamamahala ng nilalaman
- YouTube o Vimeo channel na may mga video ng sermon (para sa pag-import ng iyong archive)
- YouTube Channel ID (para sa live streaming — hanapin ito sa iyong YouTube Studio settings)

</div>

## Hakbang 1: Gumawa ng Playlist ng Sermon

Inaayos ng mga playlist ang iyong mga sermon sa mga serye at koleksyon para madaling mabrowse.

Sundin ang gabay na [Playlists](../sermons/playlists.md) upang:

1. Gumawa ng mga serye/koleksyon tulad ng "2024 Sunday Messages", "Marriage Series", "Christmas Services"
2. Magdagdag ng pangalan, paglalarawan, petsa ng paglathala, at thumbnail para sa bawat playlist

:::tip
Gumawa ng mga playlist bago magdagdag ng mga sermon. Mas madaling ayusin ang mga sermon sa tamang serye habang idinadagdag mo ang mga ito.
:::

## Hakbang 2: I-import ang Iyong Kasalukuyang mga Sermon

Kung mayroon ka nang mga video ng sermon sa YouTube o Vimeo, maaari mo itong kunin nang sabay-sabay.

Sundin ang gabay na [Bulk Import](../sermons/bulk-import.md) upang:

1. Ilagay ang URL ng iyong YouTube o Vimeo channel
2. I-preview ang import para makita kung aling mga video ang kukunin
3. I-click ang Import para idagdag silang lahat nang sabay-sabay

## Hakbang 3: Magdagdag ng Indibidwal na mga Sermon

Para sa mga pansamantalang karagdagan o sermon na wala sa bulk import, idagdag ang mga ito nang isa-isa.

Sundin ang gabay na [Managing Sermons](../sermons/managing-sermons.md) upang:

1. I-paste ang URL ng video (YouTube, Vimeo, o Facebook)
2. Awtomatikong mapupunan ang pamagat, paglalarawan, thumbnail, at tagal mula sa metadata ng video
3. Italaga ang sermon sa isang playlist

## Hakbang 4: Mag-set up ng Live Streaming

Ikonekta ang iyong YouTube channel para awtomatikong makuha ng iyong B1 site ang iyong live stream.

Sundin ang gabay na [Live Streaming](../sermons/live-streaming.md) upang:

1. Ilagay ang iyong YouTube Channel ID sa streaming settings
2. I-configure ang iskedyul ng iyong paulit-ulit na serbisyo (hal., Linggo nang 10:00 AM)
3. I-customize ang mga tab ng streaming page (Chat, Prayer requests, at mga custom link) sa pahinang **Sermons > Settings**

:::info
Kapag nag-live ka sa YouTube, awtomatikong makukuha ng B1 streaming page ang stream. Walang kailangang karagdagang hakbang tuwing Linggo ng umaga.
:::

## Hakbang 5: Ipakita sa Iyong Website

Gawing madaling ma-access ng mga bisita ang iyong library ng sermon at live stream.

Sundin ang gabay na [Managing Pages](../website/managing-pages.md) upang:

1. Magdagdag ng seksyong Sermons sa iyong B1 website para makapagbrowse ang mga bisita sa iyong library
2. Magdagdag ng seksyong Live Stream para sa karanasan ng live na panonood

## Hakbang 6: Access sa Mobile

Maaaring ma-access ng mga miyembro ang mga sermon at live na serbisyo mula sa anumang device.

1. Maaaring manood ng mga sermon ang mga miyembro sa [B1.church at sa B1 App](../../b1-church/content/sermons.md)
2. Gumagana ang live streaming na may chat sa mga telepono at computer

:::info
Pinapayagan ng live chat feature ang iyong online na kongregasyon na makilahok nang real time, parang nasa loob mismo ng silid.
:::

## Tapos Ka Na!

Online na ang iyong library ng sermon at naka-configure na ang iyong live stream. Maaaring habulin ng mga miyembro ang mga nakaraang sermon anumang oras at sumali sa mga live na serbisyo mula saanman. Maaaring awtomatikong mag-sync ang mga bagong upload ng sermon.
