# Subaybayan ang Attendance sa Simbahan

<div class="article-intro">

I-set up ang pagsubaybay ng attendance para sa inyong mga serbisyo at grupo — mula sa pag-configure ng mga campus at oras ng serbisyo, hanggang sa manu-manong pag-record ng attendance o paggamit ng self-service check-in app, at sa pagtingin ng mga trend sa mga report. Pagkatapos nito, malinaw mo nang makikita kung sino ang dumadalo at kailan.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- B1 Admin account na may admin access
- [Mga taong naidagdag na sa iyong direktoryo](../people/adding-people.md)
- [Mga grupong nalikha na](../groups/creating-groups.md) para sa mga ministeryong gusto mong subaybayan

</div>

## Hakbang 1: I-configure ang mga Campus at Serbisyo

Itakda kung saan at kailan nagtitipon ang inyong simbahan.

Sundin ang gabay sa [Attendance Setup](../attendance/setup.md) para:

1. Idagdag ang inyong campus (hal., "Main Campus")
2. Idagdag ang mga oras ng serbisyo (hal., "Linggo 9:00 AM", "Linggo 11:00 AM", "Miyerkules 7:00 PM")
3. Magtalaga ng mga grupo sa bawat oras ng serbisyo para matukoy kung anong mga klase/ministeryo ang nagtitipon sa serbisyong iyon

## Hakbang 2: I-enable ang Pagsubaybay ng Attendance ng Grupo

I-on ang pagsubaybay ng attendance para sa mga grupong gusto mong bantayan.

Sundin ang gabay sa [Paglikha ng mga Grupo](../groups/creating-groups.md) para:

1. I-edit ang bawat grupong gusto mong subaybayan at i-on ang "Track Attendance"
2. Iugnay ang mga grupo sa mga oras ng serbisyo para maitala ang attendance sa tamang serbisyo

:::info
Hindi kailangang subaybayan ang attendance ng bawat grupo. I-enable ito para sa mga grupong gusto mong bantayan ang pakikilahok — mga klase ng mga bata, small group, Sunday school, at iba pa.
:::

## Hakbang 3: Manu-manong I-record ang Attendance

Markahan kung sino ang dumalo sa bawat serbisyo at grupo.

Sundin ang gabay sa [Pag-record ng Attendance](../attendance/recording-attendance.md) para:

1. Buksan ang tab na **Sessions** ng isang grupo at magdagdag ng session para sa petsa at oras ng serbisyo. I-check ang **Also add for the other groups** para lumikha ng mga session para sa bawat klase sa oras ng serbisyong iyon nang sabay-sabay.
2. Markahan kung sino ang dumalo sa bawat grupo

:::tip
Mahusay ang manu-manong pagsubaybay para sa mga serbisyo ng mga nasa hustong gulang, small group, at anumang sitwasyon kung saan hindi praktikal ang check-in kiosk.
:::

## Hakbang 4: I-set Up ang Self Check-In (Opsyonal)

Hayaang mag-check in ang mga miyembro gamit ang tablet kiosk.

Sundin ang gabay sa [Check-In](../attendance/check-in.md) para:

1. I-install ang B1 Checkin app sa isang tablet para sa self-service check-in
2. Hahanapin ng mga miyembro ang kanilang pangalan at sila mismo ang magche-check in para sa kanilang sarili at pamilya
3. Lumilitaw ang mga record ng check-in attendance kasama ng mga manu-manong ipinasok na record — walang pagkakaiba sa datos

:::info
Para sa kumpletong setup ng ministeryo ng mga bata, kasama ang hardware at configuration ng printer, tingnan ang [Gabay sa Check-In ng mga Bata](./childrens-checkin.md).
:::

## Hakbang 5: Tingnan ang mga Attendance Report

Tingnan ang kabuuang larawan ng pakikilahok sa buong simbahan ninyo.

Sundin ang gabay sa [Mga Attendance Report](../reports/attendance-reports.md). May tatlong report view na magagamit:

1. **Attendance Trend** — tingnan ang attendance sa paglipas ng panahon para makita ang paglago o pagbaba
2. **Group Attendance** — tingnan kung sino ang dumalo sa bawat session ng grupo sa isang saklaw ng petsa, na may CSV download
3. **Daily Group Attendance** — araw-araw na detalye para sa mas malalim na pagsusuri

:::info
Pinagsasama ng mga report ang manu-manong naitalang attendance at ang self-check-in attendance. Walang pagkakaiba kung paano lumilitaw ang datos — pareho silang napupunta sa iisang mga report.
:::

## Tapos Ka Na!

Naka-set up na ang pagsubaybay mo ng attendance. Manu-mano mo man itong i-record, gamitin ang check-in app, o pareho — lahat ng datos ay napupunta sa iisang mga report kaya malinaw ang larawan ng pakikilahok sa buong simbahan ninyo.
