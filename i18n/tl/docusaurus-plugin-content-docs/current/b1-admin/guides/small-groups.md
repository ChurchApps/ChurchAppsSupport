# Patakbuhin ang mga Small Group

<div class="article-intro">

I-set up ang mga small group, Bible study, o ministry team gamit ang pamamahala ng miyembro, kalendaryo ng grupo, at mga usapan. I-publish ang church-wide na kalendaryo ng event sa iyong website para makita ng mga bisita kung ano ang nangyayari, at manatiling konektado ang mga miyembro sa pamamagitan ng web portal at mobile app.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- B1 Admin account na may admin access
- [Mga taong naidagdag sa iyong directory](../people/adding-people.md) (kailangan munang umiral ang mga miyembro ng grupo)

</div>

## Hakbang 1: Gumawa ng Group Categories at Grupo

Ayusin ang iyong mga grupo sa mga kategorya para madaling mahanap ng mga miyembro ang hinahanap nila.

Sundin ang gabay na [Creating Groups](../groups/creating-groups.md) para:

1. Gumawa ng mga kategorya para ayusin ang iyong mga grupo (hal., "Small Groups", "Bible Studies", "Ministry Teams", "Committees")
2. Gumawa ng mga grupo sa loob ng bawat kategorya (hal., "Tuesday Night Men's Group", "Women's Bible Study", "Youth Ministry")
3. Maglagay ng paglalarawan at oras ng pagpupulong para sa bawat grupo

## Hakbang 2: Magdagdag ng mga Miyembro at Lider

Punan ang iyong mga grupo ng mga miyembro at magtalaga ng mga lider na makapamamahala sa sarili nilang team.

Sundin ang gabay na [Group Members](../groups/group-members.md) para:

1. Maghanap ng mga tao at idagdag sila sa angkop na mga grupo
2. Magtalaga ng mga group leader gamit ang star icon (**Make Leader**). May dagdag na pahintulot ang mga lider

:::tip
Maaaring pamahalaan ng mga group leader ang sarili nilang kalendaryo ng grupo, mag-post ng mga usapan, at mag-coordinate ng mga event nang hindi nangangailangan ng buong admin access.
:::

## Hakbang 3: I-set Up ang mga Kalendaryo ng Grupo

Bigyan ang bawat grupo ng sarili nitong kalendaryo para sa mga pagpupulong at event.

Sundin ang gabay na [Group Calendar](../groups/group-calendar.md) para:

1. Magdagdag ng mga paulit-ulit na pagpupulong (hal., "Every Tuesday at 7 PM") at mga one-time na event (hal., "Group Cookout - March 15")
2. Maaaring magdagdag at mamahala ng mga event ang mga group leader para sa sarili nilang grupo

## Hakbang 4: Gumawa ng Church-Wide na Kalendaryo

Pagsamahin ang mga event mula sa lahat ng iyong grupo sa iisang kalendaryo para sa buong simbahan.

Sundin ang mga gabay na [Creating Calendars](../calendars/creating-calendars.md) at [Curated Calendar](../calendars/curated-calendar.md) para:

1. Gumawa ng curated calendar na kumukuha ng mga event mula sa maraming grupo at ipinapakita sa iisang pinag-isang view
2. Ibahagi ang ICS subscription link para maidagdag ng mga miyembro ang mga event sa sarili nilang calendar app (Google Calendar, Apple Calendar, Outlook)

:::info
Awtomatikong pinagsasama ng curated calendar ang mga event mula sa mga grupong ikinonekta mo. Kapag nagdagdag ng event ang isang group leader, lumalabas din ito sa kalendaryo ng simbahan.
:::

## Hakbang 5: I-publish sa Iyong Website

Gawing nakikita ng mga bisita at miyembro ang iyong mga grupo at kalendaryo sa iyong B1 website.

Sundin ang gabay na [Managing Pages](../website/managing-pages.md) para:

1. Magdagdag ng Calendar section sa iyong B1 website para ipakita ang curated calendar
2. Magdagdag ng Groups section para makapag-browse ang mga bisita ng mga available na grupo at matutunan kung paano sumali

## Hakbang 6: Karanasan ng Miyembro

Maaaring makita, salihan, at makilahok sa mga grupo ang mga miyembro mula sa kanilang telepono o computer.

1. Nagba-browse at sumasali ang mga miyembro sa mga grupo sa [B1.church](../../b1-church/groups/browsing-groups.md)
2. Maaaring tingnan ng mga miyembro ng grupo ang mga detalye at kalendaryo, at mag-post sa [conversations](../../b1-church/groups/conversations.md)
3. Available din sa [B1 App](../../b1-church/groups/index.md) ang lahat ng feature ng grupo

:::info
Nakikita ng mga miyembro ang kanilang mga grupo, paparating na event, at mga usapan ng grupo sa web at mobile. Nananatiling naka-sync ang lahat.
:::

## Tapos Ka Na!

Naka-set up at konektado na ang iyong mga small group. Makakahanap ng mga grupo ang mga miyembro, makakatingin ng mga event, at mananatiling konektado sa pamamagitan ng mga usapan, lahat sa iyong website at mobile app. Maaaring pamahalaan ng mga group leader ang sarili nilang team nang hiwalay.
