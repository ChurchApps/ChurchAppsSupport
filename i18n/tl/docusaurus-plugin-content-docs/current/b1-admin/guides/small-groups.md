# Pamahalaan ang mga Small Group

<div class="article-intro">

Mag-set up ng mga small group, Bible study, o ministry team gamit ang pamamahala ng miyembro, kalendaryo ng grupo, at mga usapan. I-publish ang kalendaryo ng mga event ng buong simbahan sa iyong website para makita ng mga bisita kung ano ang nangyayari, at manatiling konektado ang mga miyembro sa pamamagitan ng web portal at mobile app.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- B1 Admin account na may admin access
- [Mga taong naidagdag sa iyong directory](../people/adding-people.md) (kailangan munang umiral ang mga miyembro ng grupo)

</div>

## Hakbang 1: Gumawa ng mga Kategorya at Grupo {#step-1-create-group-categories--groups}

Ayusin ang iyong mga grupo sa mga kategorya para madaling mahanap ng mga miyembro ang hinahanap nila.

Sundin ang gabay na [Creating Groups](../groups/creating-groups.md) para:

1. Sa [Jump menu](../introduction.md#getting-around-with-the-jump-menu), piliin ang **People > Groups** at i-click ang **Add Group**
2. Ilagay ang **Category Name** para ayusin ang iyong mga grupo (hal., "Small Groups", "Bible Studies", "Ministry Teams", "Committees") at ang **Name** ng grupo (hal., "Tuesday Night Men's Group", "Women's Bible Study"), pagkatapos ay i-click ang **Add**
3. Buksan ang grupo, i-click ang **Edit**, at punan ang **Meeting Time**, **Meeting Location**, at **Description**. Itakda ang **Enrollment** para piliin kung puwedeng sumali agad ang mga tao, kailangan munang humiling na sumali, o idinadagdag lang ng mga leader

## Hakbang 2: Magdagdag ng mga Miyembro at Leader {#step-2-add-members--leaders}

Punan ang iyong mga grupo ng mga miyembro at magtalaga ng mga leader na puwedeng mamahala sa sarili nilang team.

Sundin ang gabay na [Group Members](../groups/group-members.md) para:

1. Sa pahina ng grupo, i-click ang **All members** at maghanap ng mga tao sa kahon na **Add Person** para idagdag sila
2. Magtalaga ng mga group leader gamit ang star icon (**Make Leader**) — may dagdag na pahintulot ang mga leader

:::tip
Maaaring pamahalaan ng mga group leader ang sarili nilang kalendaryo ng grupo, mag-post ng mga usapan, at mag-ayos ng mga event nang hindi kailangan ng buong admin access.
:::

## Hakbang 3: Mag-set up ng mga Kalendaryo ng Grupo {#step-3-set-up-group-calendars}

Bigyan ang bawat grupo ng sariling kalendaryo para sa mga pulong at event.

Sundin ang gabay na [Group Calendar](../groups/group-calendar.md) para:

1. Magdagdag ng mga paulit-ulit na pulong (hal., "Every Tuesday at 7 PM") at mga one-time na event (hal., "Group Cookout - March 15")
2. Puwedeng magdagdag at pamahalaan ng mga group leader ang mga event para sa sarili nilang grupo sa B1.church
3. Sa B1 Admin, puwede kang mag-iskedyul ng buong season ng mga pulong nang sabay-sabay: buksan ang grupo, i-click ang **All events** sa seksyong **Calendar**, at i-click ang **+ Add Events**

## Hakbang 4: Gumawa ng Kalendaryo ng Buong Simbahan {#step-4-create-a-church-wide-calendar}

Pagsamahin ang mga event mula sa lahat ng iyong grupo sa isang kalendaryo para sa buong simbahan.

Sundin ang gabay na [Creating Calendars](../calendars/creating-calendars.md) at [Curated Calendar](../calendars/curated-calendar.md) para:

1. Sa Jump menu, piliin ang **Calendars > Calendars**, i-click ang **Add Calendar**, ilagay ang **Calendar Name**, at i-click ang **Create**
2. Buksan ang kalendaryo, i-click ang **Add Group**, pumili ng grupo, at piliin ang **Add all the events of the group** (o mga partikular na event lang). Ulitin para sa bawat grupo
3. I-click ang **Subscribe** para ibahagi ang ICS subscription link para maidagdag ng mga miyembro ang mga event sa kanilang personal na calendar app (Google Calendar, Apple Calendar, Outlook)

:::info
Kapag idinagdag mo ang lahat ng event ng isang grupo, awtomatikong makukuha ng curated calendar ang mga bagong event — kapag nagdagdag ng event ang isang group leader, lalabas din ito sa kalendaryo ng simbahan.
:::

## Hakbang 5: I-publish sa Iyong Website {#step-5-publish-to-your-website}

Gawing nakikita ng mga bisita at miyembro ang iyong mga grupo at kalendaryo sa iyong B1 website.

Sundin ang gabay na [Page Editor](../website/page-editor.md) para:

1. Magdagdag ng **Calendar** element sa isang pahina ng iyong B1 website para ipakita ang curated calendar
2. Magdagdag ng **Groups Browser** (o **Group List**) element para makapagbrowse ang mga bisita ng mga available na grupo at matutunan kung paano sumali

## Hakbang 6: Karanasan ng Miyembro {#step-6-member-experience}

Puwedeng matuklasan, salihan, at salihan ng mga miyembro ang mga grupo mula sa kanilang telepono o computer.

1. Nagbabrowse at sumasali ang mga miyembro sa mga grupo sa [B1.church](../../b1-church/groups/browsing-groups.md)
2. Makikita ng mga miyembro ng grupo ang mga detalye, kalendaryo, at makakapag-post sa [mga usapan](../../b1-church/groups/conversations.md)
3. Available din sa [B1 App](../../b1-church/groups/index.md) ang lahat ng feature ng grupo

:::info
Nakikita ng mga miyembro ang kanilang mga grupo, paparating na event, at mga usapan ng grupo sa web at mobile — laging magkakasabay ang lahat.
:::

## Tapos Ka Na! {#youre-done}

Naka-set up at konektado na ang iyong mga small group. Puwedeng matuklasan ng mga miyembro ang mga grupo, tingnan ang mga event, at manatiling konektado sa pamamagitan ng mga usapan — lahat sa iyong website at mobile app. Puwedeng pamahalaan ng mga group leader ang sarili nilang team nang hiwalay.
