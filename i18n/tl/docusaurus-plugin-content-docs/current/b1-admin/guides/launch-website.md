# Ilunsad ang Iyong Church Website

<div class="article-intro">

Ang B1.church ay may kasamang full website builder nang walang dagdag na bayad. Ang gabay na ito ay gumagabay sa iyo sa paglikha ng iyong church website mula sa simula -- pag-setup ng iyong home page, pag-configure ng iyong look and feel, pagdaragdag ng mga pangunahing pahina, at opsyonal na pagkonekta ng online giving at event registration forms.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Handa na ang iyong church logo (PNG na may transparent na background ang pinakamahusay)
- Pumili ng 2–3 na brand colors para sa iyong site
- Kung gumagamit ng custom domain (hal., yourchurch.com), mayroon kang access sa iyong DNS provider (GoDaddy, Cloudflare, atbp.)
- Kung nais mo ang online giving sa iyong site, kumpletuhin muna ang [Online Giving Setup](../donations/online-giving-setup.md) (Stripe)

</div>

## Hakbang 1: Paunang Website Setup

Magsimula sa pamamagitan ng paglikha ng iyong home page at basic site structure.

Sundin ang gabay na [Website Initial Setup](../website/initial-setup.md) para:

1. Pumunta sa **Website** sa B1 Admin
2. Lumikha ng iyong home page na may hero section, welcome message, at mahahalagang impormasyon
3. Idagdag ang pangalan ng iyong simbahan at tagline

## Hakbang 2: I-configure ang Hitsura

Itakda ang visual identity ng iyong site -- mga kulay, fonts, logo, at footer.

Sundin ang gabay na [Appearance](../website/appearance.md) para:

1. Mag-upload ng iyong church logo
2. Itakda ang iyong pangunahin at accent na mga kulay
3. I-configure ang navigation bar at footer
4. I-preview ang iyong mga pagbabago

:::tip
Panatilihing simple ang iyong color palette -- isang pangunahing kulay at isang accent color ay karaniwan nang sapat. Ang website builder na ang bahalang magsaayos ng iba.
:::

## Hakbang 3: Magdagdag ng Mga Pahina ng Content

Buuin ang mga pahinang pinakakailangan ng iyong mga bisita.

Sundin ang gabay na [Managing Pages](../website/managing-pages.md) para gumawa ng mga pahina tulad ng:

- **About** -- Ang kuwento ng iyong simbahan, mga paniniwala, at pamumuno
- **Sermons** -- Link sa iyong [sermon library](../sermons/managing-sermons.md)
- **Events** -- Mga paparating na event at registration
- **Give** -- Online giving page (kinakailangan ang [Stripe setup](../donations/online-giving-setup.md))
- **Contact** -- Lokasyon, oras ng serbisyo, at contact info

## Hakbang 4: Ikonekta ang Iyong Domain

Kung nais mong gumamit ng sarili mong domain name (tulad ng yourchurch.com) sa halip na default na B1 URL:

1. Pumunta sa **Settings** sa B1 Admin at buksan ang seksyong **Domains**
2. Ilagay ang iyong custom domain
3. I-update ang iyong DNS records sa iyong domain provider para tumuro sa B1

:::info
Maaaring tumagal ng hanggang 48 na oras bago kumalat ang mga DNS change. Maaaring hindi agad ma-access ang iyong site mula sa custom domain mo. Patuloy na gagana ang default na B1 URL sa panahong ito.
:::

## Hakbang 5: Magdagdag ng Giving at Mga Form

Palakasin ang iyong site gamit ang mga interactive na elemento:

- **Online Giving** -- Magdagdag ng giving section para makapag-donate ang mga miyembro nang direkta mula sa iyong website. Tingnan ang [Online Giving Setup](../donations/online-giving-setup.md) para i-configure muna ang Stripe.
- **Registration Forms** -- I-embed ang [Stand Alone forms](../forms/creating-forms.md) para sa event signups, visitor cards, o volunteer applications. Tingnan ang [Managing Pages](../website/managing-pages.md) para sa kung paano magdagdag ng form element sa anumang pahina.

## Tapos Ka Na!

Live na ang iyong church website. Ibahagi ang URL sa iyong kongregasyon at sa social media. Maaari mong i-update ang content, magdagdag ng mga bagong pahina, at ayusin ang hitsura anumang oras mula sa B1 Admin dashboard.
