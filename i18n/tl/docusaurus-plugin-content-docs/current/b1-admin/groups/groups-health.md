# Groups Health

<div class="article-intro">

Ang Groups Health dashboard ay nagbibigay sa iyo ng bird's-eye view ng kung paano ang lahat ng iyong mga grupo ay gumagana — mga trend sa pagiging miyembro, average na dumalo, at paglaki o attrition sa nakaraang 90 araw — lahat sa isang solong sortable table.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Kailangan mo ng hindi bababa sa iilan na mga grupo na may mga miyembro upang makita ang makabuluhang data. Tingnan ang [Creating Groups](creating-groups).
- Ang attendance data ay kinukuha mula sa mga naka-record na session. Tingnan ang [Attendance](../attendance/) section.

</div>

## Pagbubukas ng Groups Health

Sa B1 Admin, buksan ang **section menu** sa top-left corner at pumili ng **People**, pagkatapos ay i-click ang **Groups** tab sa navigation bar at piliin ang **Health**. Ang dashboard ay nag-load ng isang tala na may isang row bawat grupo.

## Mga Kolum

| Kolum | Kung ano ito ay nagpapakita |
|--------|--------------|
| **Name** | Ang pangalan ng grupo, na naka-link sa pahina ng detalye ng grupo |
| **Category** | Ang kategorya ng grupo |
| **Members** | Kasalukuyang active member count |
| **Joined (90d)** | Mga miyembro na sumali sa nakaraang 90 araw |
| **Left (90d)** | Mga miyembro na umalis sa nakaraang 90 araw |
| **Churn (90d)** | Net churn rate bilang percentage sa 90 araw |
| **Avg Attendance** | Average headcount bawat attendance session |

I-click ang kahit anong column header upang i-sort ang table ng ganitong kolum. I-click muli upang baligtarin ang sort direction.

## Paggamit ng Health Data

- **High churn + low joins** — isang grupo na bumababa at hindi na nagpapalit ng mga nawaling miyembro. Karapat-dapat ng pag-uusap sa leader ng grupo.
- **High joins + low attendance** — ang mga tao ay nag-sign up ngunit hindi dumalo. Isaalang-alang ang engagement follow-up.
- **High average attendance** — isang malusog, aktibong grupo. Potensyal na modelo para sa ibang mga grupo.

:::tip
Ang pag-click sa pangalan ng grupo ay dadalhin ka direkta sa pahina ng detalye ng grupo kung saan maaari mong suriin ang mga indibidwal na miyembro, mga attendance record, at mga calendar event.
:::
