# Groups

<div class="article-intro">

Hinahayaan ka ng seksyong **Groups** na ayusin ang mga miyembro ng iyong simbahan sa mga ministry, small group, Bible study, committee, at iba pa. Ang mga grupo ang gulugod ng buhay-komunidad sa iyong simbahan, at binibigyan ka ng seksyong ito ng mga kasangkapang gumawa, mamahala, at makipag-usap sa bawat grupo sa iisang lugar. Tandaan na hiwalay ang **Teams** sa Groups -- ginagamit ang Teams para sa paglilingkod at pag-iiskedyul ng boluntaryo.

</div>

## Pangkalahatang-tanaw {#overview}

Nakaayos ang mga grupo ayon sa **kategorya**. Ang kategorya ay pangunahing label gaya ng "Small Groups," "Ministries," o "Committees." Maaaring maglaman ng maraming grupo ang bawat kategorya, kaya madaling pagsama-samahin ang magkakaugnay na grupo.

Kapag binuksan mo ang Groups page, makikita mo ang kahong **Search groups...**, isang hilera ng mga button ng kategorya, at isang table ng iyong mga grupo. Ipinapakita ng bawat grupo ang kategorya at mga label nito sa ilalim ng pangalan, kasama ang bilang ng miyembro. I-type sa search box para mahanap ang grupo ayon sa pangalan o kategorya, i-click ang **All** o pangalan ng kategorya para i-filter ang listahan (may mga karagdagang kategorya sa ilalim ng **More categories**), at i-click ang heading ng column na **Name** o **People** para mag-sort. I-click ang **Clear filters** para ipakitang muli ang lahat ng grupo.

May mga button sa header ng pahina para sa natitirang bahagi ng seksyon:

- **Group Health** -- Ihambing ang pagiging miyembro at attendance sa lahat ng grupo. Tingnan ang [Groups Health](./groups-health.md).
- **pending requests** (halimbawa, "2 pending requests") -- Lumalabas kapag may mga taong naghihintay na sumali sa grupo. Tingnan ang [Group Join Requests](./group-join-requests.md#for-administrators).
- **Export** -- I-download ang listahan ng mga grupo bilang CSV file.
- **Add Group** -- Gumawa ng grupo. Tingnan ang [Creating Groups](./creating-groups.md).

## Ano ang Maaari Mong Gawin {#what-you-can-do}

Narito ang maaari mong magawa sa seksyong Groups:

1. **Gumawa at mag-ayos ng mga grupo** -- Magdagdag ng bagong grupo sa loob ng mga kategorya para maipakita ang istruktura ng iyong simbahan. Tingnan ang [Creating Groups](./creating-groups.md).

2. **Pamahalaan ang mga miyembro ng grupo** -- Magdagdag at mag-alis ng miyembro, magtalaga ng mga lider, at makipag-usap sa iyong mga grupo. Tingnan ang [Group Members](./group-members.md).

3. **Mag-iskedyul ng mga event** -- Maaaring magkaroon ng sariling calendar ang bawat grupo para sa mga pagpupulong, event, at paulit-ulit na aktibidad. Tingnan ang [Group Calendar](./group-calendar.md).

4. **Pamahalaan ang mga join request** -- Kapag gumagamit ang grupo ng **Request** na join policy, rebyuhin at aprubahan o tanggihan ang mga papasok na request sa pagiging miyembro mula sa mga taong gustong sumali. Tingnan ang [Group Join Requests](./group-join-requests.md).

5. **Mag-export ng datos ng grupo** -- I-download ang listahan ng miyembro ng alinmang grupo bilang CSV file para sa mga spreadsheet o mailing. Tingnan ang [Group Members](./group-members.md#exporting-group-data) para sa mga tagubilin sa pag-export.

6. **Tingnan ang kalusugan ng grupo** -- Makita ang paglago ng pagiging miyembro, churn, at attendance ng bawat grupo sa iisang table. Tingnan ang [Groups Health](./groups-health.md).

## Pagsisimula {#getting-started}

Para mapuntahan ang Groups, buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas ng B1 Admin), i-expand ang **People**, at i-click ang **Groups**. Makikita mo ang lahat ng umiiral mong grupo, na maaari mong i-filter ayon sa kategorya.

:::tip
Kung nagsisimula ka pa lang, magsimula sa paggawa ng ilang kategoryang tumutugma sa istruktura ng iyong simbahan (halimbawa, "Ministries," "Small Groups," "Committees"). Pagkatapos, magdagdag ng mga indibidwal na grupo sa bawat kategorya. Tingnan ang [Creating Groups](./creating-groups.md) para sa hakbang-hakbang na gabay.
:::

:::info
Kailangang umiral na muna ang mga miyembro ng grupo sa iyong [People](../people/adding-people.md) directory bago sila maidagdag sa grupo. Kung ngayon mo lang sine-set up ang B1, [i-import ang datos ng iyong mga miyembro](../people/importing-data.md) bago gumawa ng mga grupo.
:::
