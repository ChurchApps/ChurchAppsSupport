# Mga Miyembro ng Grupo

<div class="article-intro">

Pagkatapos ng paglikha ng isang grupo, ang susunod na hakbang ay ang pagdagdag ng mga miyembro. Mula sa pahina ng detalye ng grupo ay maaari kang maghanap ng mga tao, idagdag sila sa grupo, magkasama ng mga lider, magpadala ng mga mensahe, at i-export ang listahan ng mga miyembro. Ang pag-manage ng pagiging miyembro ng grupo ay mahalaga para sa pag-coordinate ng maliit na grupo, komite, at klase.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan mo ng kahit isang grupo na naka-setup sa B1 Admin. Tingnan ang [Paglikha ng Mga Grupo](creating-groups.md) kung hindi ka pa nakagawa.
- Ang mga taong nais mong idagdag ay dapat na mayroon na sa iyong [Mga Tao](../people/adding-people.md) directory.

</div>

## Pagdagdag ng Mga Miyembro sa isang Grupo

1. Mag-navigate sa pahina ng **Mga Grupo** at i-click ang grupo na nais mong pamahalaan.
2. I-click ang tab na **Mga Miyembro**.
3. Sa search box, i-type ang pangalan ng taong gusto mong idagdag.
4. I-click ang **Idagdag** sa tabi ng pangalan ng tao sa mga resulta ng paghahanap.
5. Ang tao ay lumilitaw na sa listahan ng mga miyembro ng grupo.

:::tip
Iwanan ang search box na walang laman at i-click ang **Maghanap** upang tuklasin ang buong directory. Ito ay nakakatulong kung hindi ka sigurado sa eksaktong spelling ng pangalan ng isang tao.
:::

## Pagtatalaga ng Mga Lider ng Grupo

Ang mga lider ng grupo ay may mga espesyal na pribilehiyo -- maaari nilang i-edit ang [group calendar](group-calendar.md), pamahalaan ang mga kaganapan, at tumulong sa pag-coordinate ng grupo.

1. Sa listahan ng mga miyembro ng grupo, hanapin ang taong nais mong gawing lider.
2. I-click ang **green key icon** sa tabi ng kanilang pangalan.
3. Ang tao ay ngayon ay itinalaga bilang lider ng grupo.

Upang alisin ang status ng lider, i-click ang green key icon ulit.

:::info
Kahit sinong miyembro ng grupo ay maaaring tingnan ang group calendar at mga kaganapan, ngunit lamang ang mga lider ang makakapag-dagdag o mag-edit ng mga kaganapan ng calendar.
:::

## Pagpadala ng mga Mensahe sa mga Miyembro ng Grupo

Maaari kang makipag-ugnayan sa lahat ng mga miyembro ng isang grupo nang direkta mula sa B1 Admin:

1. Mula sa pahina ng detalye ng grupo, hanapin ang messaging area.
2. I-type ang iyong mensahe sa text box.
3. I-click ang **Magpadala**.

Ang iyong mensahe ay ihahatid sa lahat ng mga miyembro ng grupo.

## Pagpapadala ng Email sa mga Miyembro ng Grupo

Maaari kang magpadala ng mga nakaformat na email sa lahat ng mga miyembro ng isang grupo:

1. Mula sa pahina ng detalye ng grupo, i-click ang **email icon**.
2. Ang dialog na Magpadala ng Email ay bubuksan, na nagpapakita kung gaano karaming mga miyembro ang makakatanggap ng email at gaano karami ang walang email address sa file.
3. Opsyonal na pumili ng **email template** mula sa dropdown, o bumuo ng mensahe mula sa simula. I-click ang **Pamahalaan ang Mga Template** upang lumikha o mag-edit ng mga template.
4. Magpasok ng **subject line**. Maaari kang magsingit ng mga merge field sa pamamagitan ng pag-click sa mga field chip: `{{firstName}}`, `{{lastName}}`, `{{displayName}}`, `{{email}}`, `{{churchName}}`.
5. Bumuo ng **email body** gamit ang HTML editor. Ang parehong mga merge field ay available dito.
6. I-click ang **Magpadala**.
7. Ang isang summary ay nagpapakita kung gaano karaming mga email ang matagumpay na ipinadala at gaano karaming mga miyembro ang napabayaan (walang email sa file).

:::tip
Lumikha ng mga reusable na email template para sa mga paulit-ulit na komunikasyon tulad ng mga bulterang update, mga abiso ng kaganapan, o mga kahilingan para sa panalangin. Ang mga template ay nakakatipid ng oras at nagsisiguro ng pare-parehong mensahe.
:::

### Pagbubukas ng Group Email para sa Iyong Simbahan

Lahat ng mga simbahan sa B1 ay nagpapadala ng email mula sa parehong address, kaya nagbabahagi sila ng isang pagpapadala ng reputasyon. Upang panatilihing ang email ng bawat isa ay malayo sa spam folders, ang koponan ng ChurchApps ay sinusuri ang bawat simbahan minsa bago makapagpadala ng group email.

Kung ang iyong simbahan ay hindi pa na-review, ang dialog na Magpadala ng Email ay nagpapakita ng **Ang group email ay kailangan ng mabilis na pagsusuri** sa halip ng editor ng mensahe:

1. I-click ang **Humiling ng review**. Ang koponan ng suporta ng ChurchApps ay makakatanggap ng notipikasyon.
2. Ang dialog ay nagbabago sa **Review requested**. Maaari mong isara ito.
3. Ang group email ay karaniwang nakabukas sa loob ng isang araw ng negosyo. Buksan ang dialog na Magpadala ng Email ulit pagkatapos nito upang magpadala ng iyong mensahe.

Hanggang sa ang iyong simbahan ay aprubahan, ang B1 ay hindi rin nagpapadala ng [form follow-up emails](../forms/creating-forms.md#sending-a-follow-up-email) o ang hakbang na **Magpadala ng email** sa [workflows](../serving/workflows.md).

:::info Mga limitasyon sa pagpapadala
Pagkatapos ng pagsang-ayon, isang simbahan ay maaaring magpadala ng hanggang 150 na church-written na email araw. Ang limitasyon ay lumalaki habang ang iyong simbahan ay bumubuo ng isang malinis na kasaysayan ng pagpapadala, hanggang sa 2,000 araw. Kung ang mga nakaraang mensahe ay nag-bounce o ay minarkahan bilang spam, ang group email ay tumitigil at ang dialog ay naghihiling sa iyo na makipag-ugnayan sa suporta. Kung ang pagpadala ay lalampas sa iyong pang-araw-araw na limitasyon, ang B1 ay hindi ito nagpapadala at nagpapakita ng isang error.
:::

## Pag-export ng Mga Data ng Grupo

Upang i-download ang listahan ng mga miyembro ng grupo bilang isang file:

1. Mula sa pahina ng detalye ng grupo, i-click ang **download icon**.
2. Ang CSV file na may impormasyon tungkol sa mga miyembro ng grupo ay ide-download sa iyong computer.

Upang mag-print ng sign-in sheet para sa isang klase, gamitin ang **Print Roll Sheet** -- tingnan ang [Pag-print ng isang Roll Sheet](../attendance/recording-attendance.md#printing-a-roll-sheet).

Ang CSV export ay kapaki-pakinabang para sa pag-import ng data sa ibang mga tool, o pagpanatili ng offline na mga record. Para sa higit pang mga opsyon sa pag-export, tingnan ang [Pag-export ng Data](../people/exporting-data.md).

## Pagpadala ng Push Notifications sa mga Miyembro ng Grupo

Maaari kang magpadala ng push notification nang direkta sa lahat ng mga miyembro ng grupo na may naka-install na B1.church app sa kanilang device na may push notifications na naka-enable.

1. Mula sa pahina ng detalye ng grupo, i-click ang **bell icon** sa header toolbar (sa tabi ng email at SMS icons).
2. Ang isang dialog ay bubuksan na nagpapakita kung gaano karaming mga miyembro ng iyong grupo ang may push enabled.
3. Punan ang mga detalye ng notipikasyon:
   - **Pamagat** *(kinakailangan)* -- Isang maikling buod, hanggang 80 na mga character.
   - **Mensahe** *(kinakailangan)* -- Ang katawan ng notipikasyon, hanggang 240 na mga character.
   - **Buksan ang link o flyer URL** *(opsyonal)* -- Isang relatibong app path (halimbawa, `/mobile/groups`) o isang buong `https://` URL na bubuksan ang notipikasyon kapag na-tap.
   - **URL ng Imahe** *(opsyonal)* -- Isang `https://` URL sa isang imahe na lumalitaw sa tabi ng notipikasyon sa mga sinusuportahang device.
4. Ang isang live preview ay nagpapakita kung paano ang notipikasyon ay lilitaw sa device.
5. I-click ang **Magpadala ng Notipikasyon**.

:::info
Ang mga push notification ay ihahatid lamang sa mga miyembro ng grupo na may naka-install na B1.church PWA at ay hindi nag-disable ng push notification. Ang mga miyembro na walang naka-register na push device o na may push na naka-off ay binibilang bilang napabayaan, at ang pagpapadala ng summary ay nagpapakita kung gaano karaming naaabot versus napabayaan.
:::

:::tip
Pagkatapos ng pagpadala, ang dialog ay nagpapakita kung gaano karaming mga notipikasyon ay matagumpay na na-queue. Kung karamihan ng mga miyembro ay nagpapakita bilang napabayaan, paalahanin sila na bumisita sa kanilang B1.church site, i-install ito bilang isang home-screen app, at payagan ang mga notipikasyon kapag hinahanap.
:::

## Pag-aalis ng Mga Miyembro

Upang alisin ang isang tao mula sa isang grupo, hanapin ang kanilang pangalan sa listahan ng mga miyembro at i-click ang **remove** button sa tabi ng kanilang entry.

:::info
Ang pag-aalis ng isang tao mula sa isang grupo ay hindi nag-delete sa kanila mula sa iyong church directory. Sila ay lilitaw pa rin sa seksyon ng [Mga Tao](../people/adding-people.md) at maaaring maging idagdag sa grupo anumang oras.
:::
