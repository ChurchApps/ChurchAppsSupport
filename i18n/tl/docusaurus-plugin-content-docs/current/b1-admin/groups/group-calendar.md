# Calendar ng Grupo

<div class="article-intro">

Bawat grupo sa B1 ay maaaring magkaroon ng sarili nitong calendar ng event. Ginagamit ito ng mga lider ng grupo para mag-iskedyul ng mga pagpupulong, aktibidad, at paulit-ulit na event, habang maaaring tingnan ng lahat ng miyembro ng grupo ang mga paparating na event at lumahok sa mga usapan tungkol dito. Pinananatiling organisado ng calendar ang iyong grupo at tinitiyak na alam ng lahat ang mga paparating na gawain.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan mo ng grupong nagawa na sa B1 Admin na may kahit isang miyembro. Tingnan ang [Creating Groups](creating-groups.md) at [Group Members](group-members.md).
- Para makapagdagdag o makapag-edit ng calendar event, kailangan mong italaga bilang lider ng grupo. Tingnan ang [Designating Group Leaders](group-members.md#designating-group-leaders) para sa mga tagubilin.

</div>

## Pagpunta sa Calendar ng Grupo {#accessing-the-group-calendar}

Available ang calendar ng grupo sa member-facing app ng B1.church:

1. Mula sa B1 Admin, i-click ang **dropdown menu** sa kanang itaas ng iyong screen.
2. Piliin ang **Switch App**.
3. Piliin ang **B1.church**.
4. Buksan ang **Groups** (isang tab sa bottom tab bar sa telepono, o sa itaas na header sa kompyuter).
5. Piliin ang iyong grupo mula sa listahan.
6. Sa ilalim ng **Next event**, i-click ang **All events** para buksan ang **Events** view ng grupo. Gamitin ang **Calendar** toggle doon para sa month view.

:::info
Pinamamahalaan ang calendar ng grupo sa pamamagitan ng B1.church (ang member app) at hindi sa B1 Admin. Pumupunta ang mga lider ng grupo dito sa pamamagitan ng pagpapalit ng app mula sa admin dashboard.
:::

## Pagdaragdag ng Event {#adding-an-event}

1. Mula sa calendar ng grupo, i-click ang **Add Event**.
2. Maglagay ng **title** para sa event.
3. Sumulat ng maikling **description** tungkol sa event.
4. Itakda ang **start time** at **end time**.
5. I-click ang **Save** para idagdag ang event sa calendar.

## Pag-set Up ng Mga Paulit-ulit na Event {#setting-up-recurring-events}

Kung regular na nagkikita ang iyong grupo, maaari mong itakda ang mga event na awtomatikong umulit:

1. Kapag gumagawa o nag-e-edit ng event, lagyan ng check ang kahon na **Recurring**.
2. Piliin kung paano uulitin ang event:
   - **Interval** -- Magtakda ng bilang ng araw sa pagitan ng bawat occurrence. Halimbawa, ang paglalagay ng "7" ay uulit sa event tuwing 7 araw.
   - **Frequency** -- Piliin kung uulit ayon sa **day**, **week**, o **month**.
3. I-save ang event. Lalabas na ito sa calendar sa bawat nakaiskedyul na occurrence.

:::tip
Para sa grupong nagkikita tuwing Sabado, itakda ang frequency sa "week" at piliin ang Sabado. Awtomatikong lalabas ang event sa calendar mula ngayon.
:::

## Maramihang Pag-create ng Event sa B1 Admin {#bulk-creating-events-in-b1-admin}

May seksyong **Calendar** din ang pahina ng grupo sa B1 Admin kung saan maaaring mag-iskedyul ang staff ng buong season ng mga pagpupulong nang sabay-sabay:

1. Buksan ang grupo sa B1 Admin at, sa seksyong **Calendar**, i-click ang **All events**.
2. I-click ang **+ Add Events** para buksan ang dialog na **Add Recurring Events**.
3. Suriin ang **Title** (nagsisimula ito sa pangalan ng grupo) at magdagdag ng opsyonal na **Description**.
4. Piliin ang petsa ng **First Meeting** at **Last Meeting**, ang oras ng **Start** at **End**, at kung gaano kadalas ito **Repeats** -- **Weekly** o **Every 2 Weeks**, sa araw ng linggo ng unang pagpupulong. Para sa iisang pagpupulong, gamitin ang parehong petsa sa dalawa.
5. Piliin ang **Visibility** -- **Public** o **Private**.
6. Naka-check bilang default ang **Skip holidays**, kaya ang mga petsa ng pagpupulong na tumatapat sa holiday ay hindi lalagyan ng check at lalagyan ng pangalan ng holiday.
7. Suriin ang listahan ng mga petsa ng pagpupulong at alisin ang check sa sinumang gusto mong laktawan.
8. Iwanang naka-check ang **Allow RSVPs** kung gusto mong makasagot ang mga miyembro sa mga event na ito (tingnan sa ibaba), pagkatapos i-click ang **Save**.

May mga button na **Upcoming** at **Past** sa itaas ng listahan ng event sa B1 Admin. Ipinapakita ng **Upcoming** ang mga event na hindi pa natatapos, kasama ang mga paulit-ulit na serye na tumatakbo pa, pinakamalapit muna. Itinatago ng **Past** ang bawat nakaraang event ng grupo, pinakabago muna. Ipinapakita ng bawat row ang title ng event, simula, kung paano ito umuulit, ilang petsa ang nilaktawan, visibility nito, at mga RSVP nito. I-click ang **Delete** sa isang row at kumpirmahin para alisin ang event at lahat ng occurrence nito.

## Mga RSVP ng Event {#event-rsvps}

Maaaring mangolekta ng RSVP ang mga event ng grupo -- isang **Yes**, **No**, o **Maybe** para sa bawat occurrence ng event.

- Naka-on bilang default ang **Allow RSVPs** para sa mga event na ginawa gamit ang bulk-add dialog; alisin ang check para i-off ang mga tugon sa mga event na iyon. Ang mga event na naka-off ang RSVP ay nagpapakitang **Disabled** sa listahan ng event ng grupo.
- Sa listahan ng event ng grupo sa B1 Admin, ipinapakita ng bawat event ang buod ng tugon (halimbawa, "5 yes · 2 maybe · 1 no"). I-click ito para buksan ang roster na **RSVP Responses**, na naglilista, para sa bawat occurrence, kung sino ang **Going**, **Maybe**, o **Not Going**.

:::tip
Nagbibigay ang RSVP sa mga lider ng bilang ng dadalo nang hindi na kailangan ng pormal na event registration. Para sa mga bayad na sign-up o event na may limitadong capacity, gamitin ang [event registration](../calendars/creating-calendars.md#enabling-event-registration) sa halip.
:::

## Pagtingin sa Calendar {#viewing-the-calendar}

May maraming opsyon sa view ang calendar ng grupo:

- **Month** -- Tingnan ang buong buwan sa isang sulyap.
- **Week** -- Tumutok sa kasalukuyang linggo.
- **Day** -- Tingnan nang detalyado ang isang araw.
- **Agenda** -- Tingnan ang listahan ng mga paparating na event ayon sa pagkakasunod ng petsa.

Lumipat sa pagitan ng mga view gamit ang mga button sa itaas ng calendar.

## Mga Detalye ng Event at Usapan {#event-details-and-conversations}

I-click ang anumang event para tingnan ang mga detalye nito. Mula sa event detail view:

- Maaaring magsimula ng usapan at mag-iwan ng komento tungkol sa event ang **mga miyembro at lider**.
- Maaaring mag-edit ng detalye ng event, magpalit ng oras, o burahin ang event ang **mga lider**.

:::warning
Permanenteng inaalis ng pagbura ng event ang event. Kung kailangan mo lamang kanselahin ang isang occurrence ng paulit-ulit na event, mas mabuting i-edit na lang ito.
:::

## Pag-subscribe sa Calendar {#subscribing-to-the-calendar}

Maaari mong i-sync ang calendar ng grupo sa iyong personal na calendar:

1. Mula sa pahina ng calendar ng grupo, i-click ang **Subscribe**.
2. Sundin ang mga prompt para idagdag ang calendar sa Google Calendar, Apple Calendar, Outlook, o anumang ibang calendar application na sumusuporta sa subscription.

:::tip
Pinananatiling naka-sync ng subscription ang iyong personal na iskedyul sa mga event ng iyong grupo nang hindi na kailangang tingnan ang B1 nang hiwalay. Awtomatikong lalabas sa naka-sync mong calendar ang anumang pagbabagong gagawin ng mga lider ng grupo.
:::
