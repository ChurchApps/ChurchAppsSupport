# Kalendaryo ng Grupo

<div class="article-intro">

Bawat grupo sa B1 ay maaaring magkaroon ng sarili nitong kalendaryo ng event. Ginagamit ito ng mga group leader para mag-iskedyul ng mga pulong, aktibidad, at paulit-ulit na event, habang ang lahat ng miyembro ng grupo ay makakatingin sa mga paparating na event at makakasali sa mga usapan tungkol dito. Pinananatiling maayos ng kalendaryo ang iyong grupo at tinitiyak na alam ng lahat kung ano ang paparating.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan mo ng grupong nagawa na sa B1 Admin na may kahit isang miyembro. Tingnan ang [Creating Groups](creating-groups.md) at [Group Members](group-members.md).
- Para makapagdagdag o makapag-edit ng mga event sa kalendaryo, dapat ay itinalaga kang group leader. Tingnan ang [Designating Group Leaders](group-members.md) para sa mga tagubilin.

</div>

## Pag-access sa Kalendaryo ng Grupo

Makukuha ang kalendaryo ng grupo sa app ng B1.church para sa mga miyembro:

1. Mula sa B1 Admin, i-click ang **dropdown menu** sa kanang itaas ng iyong screen.
2. Piliin ang **Switch App**.
3. Piliin ang **B1.church**.
4. Buksan ang **Groups** (isang tab sa ibabang tab bar sa telepono, o sa itaas na header sa kompyuter).
5. Piliin ang iyong grupo mula sa listahan.
6. Sa ilalim ng **Next event**, i-click ang **All events** para buksan ang view na **Events** ng grupo. Gamitin ang toggle na **Calendar** doon para sa month view.

:::info
Pinamamahalaan ang kalendaryo ng grupo sa pamamagitan ng B1.church (ang member app) sa halip na sa B1 Admin. Ina-access ito ng mga group leader sa pamamagitan ng pag-switch ng app mula sa admin dashboard.
:::

## Pagdaragdag ng Event

1. Mula sa kalendaryo ng grupo, i-click ang **Add Event**.
2. Maglagay ng **title** para sa event.
3. Sumulat ng maikling **description** tungkol sa event.
4. Itakda ang **start time** at **end time**.
5. I-click ang **Save** para idagdag ang event sa kalendaryo.

## Pagtatakda ng Paulit-ulit na Event

Kung regular na nagkikita ang iyong grupo, maaari mong itakda ang mga event na awtomatikong uulit:

1. Kapag gumagawa o nag-e-edit ng event, lagyan ng check ang kahong **Recurring**.
2. Piliin kung paano uulit ang event:
   - **Interval** -- Itakda ang bilang ng araw sa pagitan ng bawat pag-ulit. Halimbawa, ang paglalagay ng "7" ay uulit sa event tuwing 7 araw.
   - **Frequency** -- Piliin kung uulit kada **day**, **week**, o **month**.
3. I-save ang event. Lalabas na ito sa kalendaryo sa bawat nakatakdang pag-ulit.

:::tip
Para sa grupong nagkikita tuwing Sabado, itakda ang frequency sa "week" at piliin ang Saturday. Awtomatikong lalabas ang event sa kalendaryo mula ngayon.
:::

## Sabayang Paggawa ng mga Event sa B1 Admin

Ang pahina ng grupo sa B1 Admin ay mayroon ding seksyong **Calendar** kung saan maaaring mag-iskedyul ang staff ng buong season ng mga pulong nang sabay-sabay:

1. Buksan ang grupo sa B1 Admin at, sa seksyong **Calendar**, i-click ang **All events**.
2. I-click ang **+ Add Events** para buksan ang dialog na **Add Recurring Events**.
3. Piliin ang iskedyul (weekly, every 2 weeks, monthly, o one time), ang mga petsang **First Meeting** at **Last Meeting**, at opsyonal ang **Skip holidays**.
4. Suriin ang preview ng mga petsa ng pulong at alisan ng check ang sinumang gusto mong laktawan.
5. Iwanang naka-check ang **Allow RSVPs** kung gusto mong makasagot ang mga miyembro sa mga event na ito (tingnan sa ibaba), saka i-save.

Ang listahan ng event sa B1 Admin ay may mga button na **Upcoming** at **Past** sa itaas. Ipinapakita ng **Upcoming** ang mga event na hindi pa natatapos, kasama ang mga serye ng paulit-ulit na event na tumatakbo pa, pinakamalapit muna. Ipinapakita naman ng **Past** ang bawat nakaraang event ng grupo, pinakabago muna.

## Mga RSVP sa Event {#event-rsvps}

Maaaring mangolekta ng RSVP ang mga event ng grupo -- isang **Yes**, **No**, o **Maybe** para sa bawat pag-ulit ng event.

- Naka-on bilang default ang **Allow RSVPs** para sa mga event na ginawa sa pamamagitan ng bulk-add dialog; alisan ng check para i-off ang mga tugon sa mga event na iyon. Ang mga event na naka-off ang RSVP ay ipinapakitang **Disabled** sa listahan ng event ng grupo.
- Sa listahan ng event ng grupo sa B1 Admin, ipinapakita ng bawat event ang buod ng tugon (halimbawa, "5 yes · 2 maybe · 1 no"). I-click ito para buksan ang roster na **RSVP Responses**, na naglilista kung sino ang sumagot ng yes, maybe, at no para sa pag-ulit na iyon.

:::tip
Nagbibigay ang mga RSVP sa mga lider ng bilang ng dadalo nang hindi na kailangan ng pormal na event registration. Para sa mga bayad na pagpaparehistro o event na may limitadong kapasidad, gamitin ang [event registration](../calendars/creating-calendars.md#enabling-event-registration) sa halip.
:::

## Pagtingin sa Kalendaryo

Maraming opsyon sa pagtingin ang kalendaryo ng grupo:

- **Month** -- Makita ang buong buwan sa isang sulyap.
- **Week** -- Pagtuunan ang kasalukuyang linggo.
- **Day** -- Tingnan nang detalyado ang isang araw.
- **Agenda** -- Makita ang listahan ng mga paparating na event ayon sa pagkakasunod-sunod ng oras.

Lumipat sa pagitan ng mga view gamit ang mga button sa itaas ng kalendaryo.

## Mga Detalye ng Event at mga Usapan

I-click ang anumang event para makita ang mga detalye nito. Mula sa detail view ng event:

- Maaaring magsimula ng usapan at mag-iwan ng komento tungkol sa event ang **mga miyembro at lider**.
- Maaaring i-edit ng mga **lider** ang mga detalye ng event, baguhin ang oras, o burahin ang event.

:::warning
Permanenteng nabubura ang event kapag binura ito. Kung kailangan mo lang kanselahin ang isang pag-ulit ng paulit-ulit na event, mas mainam na i-edit na lang ito.
:::

## Pag-subscribe sa Kalendaryo

Maaari mong i-sync ang kalendaryo ng grupo sa iyong personal na kalendaryo:

1. Mula sa pahina ng kalendaryo ng grupo, i-click ang **Subscribe**.
2. Sundin ang mga prompt para idagdag ang kalendaryo sa Google Calendar, Apple Calendar, Outlook, o anumang ibang calendar application na sumusuporta sa subscription.

:::tip
Pinapanatiling sabay ng pag-subscribe ang iyong personal na iskedyul at ang mga event ng iyong grupo nang hindi na kailangang tingnan ang B1 nang hiwalay. Awtomatikong lilitaw sa naka-sync mong kalendaryo ang anumang pagbabagong gagawin ng mga group leader.
:::
