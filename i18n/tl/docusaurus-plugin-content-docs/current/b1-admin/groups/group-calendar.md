# Kalendaryo ng Group

<div class="article-intro">

Ang bawat group sa B1 ay maaaring magkaroon ng sarili nitong kalendaryo ng event. Ginagamit ito ng mga lider ng group para magplano ng mga pagpupulong, aktibidad, at umuulit na event, habang ang lahat ng miyembro ng group ay makakatingin sa mga paparating na event at makakasali sa mga usapan tungkol dito. Pinananatiling maayos ng kalendaryo ang iyong group at tinitiyak na alam ng lahat kung ano ang paparating.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan mo ng group na nagawa sa B1 Admin na may kahit isang miyembro. Tingnan ang [Creating Groups](creating-groups.md) at [Group Members](group-members.md).
- Para makapagdagdag o makapag-edit ng mga event sa calendar, dapat ay itinalaga kang lider ng group. Tingnan ang [Designating Group Leaders](group-members.md) para sa mga tagubilin.

</div>

## Pag-access sa Kalendaryo ng Group

Makukuha ang kalendaryo ng group sa app ng B1.church na para sa mga miyembro:

1. Mula sa B1 Admin, i-click ang **dropdown menu** sa kanang itaas ng iyong screen.
2. Piliin ang **Switch App**.
3. Piliin ang **B1.church**.
4. Buksan ang **Groups** (isang tab sa ibabang tab bar sa telepono, o sa itaas na header sa kompyuter).
5. Piliin ang iyong group mula sa listahan.
6. Sa ilalim ng **Next event**, i-click ang **All events** para buksan ang **Events** view ng group. Gamitin ang **Calendar** toggle doon para sa month view.

:::info
Ang kalendaryo ng group ay pinamamahalaan sa pamamagitan ng B1.church (ang app para sa miyembro) sa halip na sa B1 Admin. Ina-access ito ng mga lider ng group sa pamamagitan ng pag-switch ng app mula sa admin dashboard.
:::

## Pagdaragdag ng Event

1. Mula sa kalendaryo ng group, i-click ang **Add Event**.
2. Maglagay ng **title** para sa event.
3. Sumulat ng maikling **description** tungkol sa event.
4. Itakda ang **start time** at **end time**.
5. I-click ang **Save** para idagdag ang event sa kalendaryo.

## Pagtatakda ng Umuulit na Event

Kung regular na nagkikita ang iyong group, maaari mong itakda ang mga event na awtomatikong umulit:

1. Kapag gumagawa o nag-e-edit ng event, lagyan ng check ang kahon na **Recurring**.
2. Piliin kung paano uulitin ang event:
   - **Interval** -- Itakda ang bilang ng araw sa pagitan ng bawat pag-ulit. Halimbawa, ang paglalagay ng "7" ay uulit sa event tuwing 7 araw.
   - **Frequency** -- Piliin kung uulitin kada **day**, **week**, o **month**.
3. I-save ang event. Lalabas na ito sa kalendaryo sa bawat nakaiskedyul na pag-ulit.

:::tip
Para sa group na nagkikita tuwing Sabado, itakda ang frequency sa "week" at piliin ang Saturday. Awtomatikong lalabas ang event sa kalendaryo mula ngayon.
:::

## Sabay-sabay na Paggawa ng Event sa B1 Admin

Ang pahina ng group sa B1 Admin ay mayroon ding seksyong **Calendar** kung saan maaaring mag-iskedyul ang staff ng buong season ng mga pagpupulong nang sabay-sabay:

1. Buksan ang group sa B1 Admin at, sa seksyong **Calendar**, i-click ang **All events**.
2. I-click ang **+ Add Events** para buksan ang dialog na **Add Recurring Events**.
3. Piliin ang iskedyul (weekly, every 2 weeks, monthly, o one time), ang mga petsang **First Meeting** at **Last Meeting**, at opsyonal ang **Skip holidays**.
4. Suriin ang preview ng mga petsa ng pagpupulong at alisan ng check ang sinumang nais laktawan.
5. Iwanang naka-check ang **Allow RSVPs** kung nais mong makasagot ang mga miyembro sa mga event na ito (tingnan sa ibaba), saka i-save.

## Mga RSVP ng Event

Maaaring mangolekta ng RSVP ang mga event ng group -- isang **Yes**, **No**, o **Maybe** para sa bawat pag-ulit ng event.

- Naka-on bilang default ang **Allow RSVPs** para sa mga event na ginawa sa pamamagitan ng bulk-add dialog; alisan ng check para i-off ang mga tugon sa mga event na iyon. Ang mga event na naka-off ang RSVP ay ipinapakitang **Disabled** sa listahan ng event ng group.
- Sa listahan ng event ng group sa B1 Admin, ipinapakita ng bawat event ang buod ng mga tugon (halimbawa, "5 yes · 2 maybe · 1 no"). I-click ito para buksan ang **RSVP Responses** roster, na naglilista kung sino ang sumagot ng yes, maybe, at no para sa pag-ulit na iyon.

:::tip
Nagbibigay ang mga RSVP sa mga lider ng bilang ng dadalo nang hindi na kailangan ng pormal na event registration. Para sa mga bayad na pagpaparehistro o event na may limitadong kapasidad, gamitin ang [event registration](../calendars/creating-calendars.md#enabling-event-registration) sa halip.
:::

## Pagtingin sa Kalendaryo

Maraming opsyon sa pagtingin ang kalendaryo ng group:

- **Month** -- Makita ang buong buwan sa isang sulyap.
- **Week** -- Pagtuunan ang kasalukuyang linggo.
- **Day** -- Tingnan nang detalyado ang isang araw.
- **Agenda** -- Makita ang listahan ng mga paparating na event ayon sa pagkakasunod-sunod ng petsa.

Lumipat sa pagitan ng mga view gamit ang mga button sa itaas ng kalendaryo.

## Mga Detalye ng Event at Usapan

I-click ang anumang event para makita ang mga detalye nito. Mula sa detail view ng event:

- Maaaring magsimula ng usapan at mag-iwan ng komento tungkol sa event ang **mga miyembro at lider**.
- Maaaring i-edit ng mga **lider** ang mga detalye ng event, baguhin ang oras, o burahin ang event.

:::warning
Permanenteng nabubura ang event kapag binura ito. Kung kailangan mo lang kanselahin ang isang pag-ulit ng umuulit na event, mas mainam na i-edit na lang ito.
:::

## Pag-subscribe sa Kalendaryo

Maaari mong i-sync ang kalendaryo ng group sa personal mong kalendaryo:

1. Mula sa pahina ng kalendaryo ng group, i-click ang **Subscribe**.
2. Sundin ang mga prompt para idagdag ang kalendaryo sa Google Calendar, Apple Calendar, Outlook, o alinmang ibang calendar application na sumusuporta sa subscription.

:::tip
Ang pag-subscribe ay nagpapanatiling sabay ng personal mong iskedyul at ng mga event ng iyong group nang hindi na kailangang tingnan ang B1 nang hiwalay. Ang anumang pagbabagong gagawin ng mga lider ng group ay awtomatikong lilitaw sa naka-sync mong kalendaryo.
:::
