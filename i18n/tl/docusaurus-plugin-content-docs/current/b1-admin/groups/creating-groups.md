# Paggawa ng Mga Grupo

<div class="article-intro">

Madali lang ang paggawa ng grupo sa B1 Admin. Gagawa ka ng kategorya, pangalanan ang iyong grupo, at pagkatapos i-configure ang mga setting nito. Nakakatulong ang mga grupo para ayusin ang iyong simbahan sa mga makabuluhang yunit gaya ng maliliit na grupo, komite, at klase.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan mo ng aktibong B1 Admin account na may permiso sa pamamahala ng mga grupo. Tingnan ang [Roles & Permissions](../people/roles-permissions.md) kung hindi ka sigurado sa antas ng iyong access.
- Magpasya kung paano ayusin ang mga kategorya ng iyong mga grupo (halimbawa, "Small Groups," "Ministries," "Committees"). Nakakatulong ang mga kategorya para manatiling organisado ang magkakaugnay na grupo.

</div>

## Pagdaragdag ng Bagong Grupo

1. Buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas ng B1 Admin), palawakin ang **People**, at i-click ang **Groups**.
2. I-click ang **Add Group** sa header ng pahina. Bubukas ang form na **New Group** sa ilalim ng listahan. Maglagay ng **Category Name**. Nakakatulong ang mga kategorya para pagsama-samahin ang magkakaugnay na grupo (halimbawa, "Small Groups," "Ministries," o "Committees"). Kung may umiiral nang kategorya, maaari mo itong piliin mula sa listahan.
3. Ilagay ang **Name** ng grupo.
4. I-click ang **Add**. Lalabas ang bago mong grupo sa listahan, kasama ang kategorya nito sa ilalim ng pangalan.

## Pag-configure ng Mga Setting ng Grupo

Kapag nagawa na ang iyong grupo, maaari mong punan ang iba pang detalye:

1. I-click ang **pangalan ng grupo** sa listahan para buksan ito.
2. I-click ang butones na **Edit** sa kaliwang bahagi ng pahina ng grupo, sa ilalim ng mga detalye ng grupo.
3. I-configure ang mga sumusunod na opsyon:
   - **Description** -- Maikling buod ng tungkol sa grupo. Nakikita ito ng mga miyembro.
   - **Meeting Times** -- Kailan karaniwang nagpupulong ang grupo (halimbawa, "Wednesdays at 7 PM").
   - **Join Policy** -- Piliin kung sino ang maaaring sumali sa grupong ito:
     - **Open** -- Sinuman ay maaaring sumali kaagad nang walang pag-apruba
     - **Request** -- Dapat magsumite ng join request ang mga tao na nangangailangan ng pag-apruba (tingnan ang [Group Join Requests](./group-join-requests.md))
     - **Closed** -- Dapat idagdag nang manual ng mga leader o administrator ang mga miyembro
   - **Labels** -- Maglagay ng isa o higit pang mapaglarawang label sa grupo (halimbawa, "In-Person", "Online", "New Members Welcome"). Malayang tag ang mga label na ikaw ang nagtatakda; lagyan ng check ang lahat ng naaangkop. Maaaring gamitin ang mga label para i-filter ang mga grupo sa Groups Browser website element.
   - **Confidential group** -- Itago ang grupong ito at ang roster nito sa mga pampublikong pahina, sa group finder, at sa mga hindi miyembro. Gamitin ito para sa mga sensitibong grupo gaya ng recovery o counseling ministry; tanging mga miyembro ng grupo at staff ng simbahan lang ang makakakita nito.
   - **Discussions** -- Ino-on o i-o-off ang chat feed ng grupo, kung saan maaaring mag-post ang sinumang miyembro. Naka-on bilang default.
   - **Announcements** -- Ino-on ang pangalawang chat feed na para lang sa leader -- nababasa at napapatugunan ng mga miyembro, pero leader lang ang maaaring mag-post. Naka-on bilang default.
   - **Attendance Tracking** -- I-enable ito kung gusto mong i-record ang [attendance](../attendance/tracking-attendance.md) ng grupong ito.
   - **Service Times** -- I-link ang grupo sa partikular na oras ng serbisyo ng simbahan, kung naaangkop. Tingnan ang [Attendance Setup](../attendance/setup.md) para sa mga detalye tungkol sa oras ng serbisyo.
4. I-click ang **Save** para ilapat ang iyong mga pagbabago.

:::tip
Ang malinaw na deskripsyon at oras ng pagpupulong ay nakakatulong sa mga miyembro na malaman kung ano ang aasahan kapag sumali sila sa grupo.
:::

:::info
Kapag pinatay mo ang parehong Discussions at Announcements, aalisin ang tab na Messages sa grupo sa member portal. Kapag isa lang ang pinatay mo, mawawala ang tab nito; ililipat ang mga miyembro sa feed na nananatiling naka-on. Nananatili ang mga umiiral na mensahe sa alinmang kaso -- ang mga toggle ay kumokontrol lang sa bagong pag-post.
:::

## Pagkopya ng Grupo

Magsisimula ka ba ng bagong sesyon ng paulit-ulit na klase o ministry? Sa halip na i-type muli ang lahat ng setting, kopyahin ang umiiral na grupo:

1. Buksan ang grupo at i-click ang **Duplicate** (sa ilalim ng butones na **Edit** sa kaliwang bahagi ng pahina ng grupo).
2. Kumpirmahin ang pagkopya.

Dinadala ng kopya ang mga setting ng orihinal -- kategorya, deskripsyon, oras/lokasyon ng pagpupulong, join policy, label, at campus -- pero **hindi** ang mga miyembro nito. Ang bagong grupo ay pinangalanan ayon sa orihinal na may dagdag na " (Copy)"; palitan ang pangalan nito mula sa mga setting ng grupo.

## Pag-archive ng Grupo

Kapag hindi na aktibo ang isang grupo pero gusto mong panatilihin ang kasaysayan nito sa halip na burahin:

1. Buksan ang grupo at i-click ang **Edit** para i-edit ang mga setting nito.
2. I-click ang **Archive** at kumpirmahin.

Nawawala sa pangunahing listahan ng Groups ang mga naka-archive na grupo. Para mahanap ulit ang isa, i-click ang butones na **Show archived** sa tabi ng mga butones ng kategorya sa itaas ng pahina ng Groups, pagkatapos i-click ang **Restore** sa tabi ng grupo para ibalik ito.

:::info
Hindi nabubura ng pag-archive ng grupo ang mga miyembro, kasaysayan ng attendance, o mga event sa calendar nito -- itinatago lang nito ang grupo sa karaniwang listahan hanggang maibalik mo ito.
:::

## Mga Susunod na Hakbang

Pagkatapos gumawa at mag-configure ng iyong grupo, handa ka nang:

- **Magdagdag ng mga miyembro** -- Maghanap ng mga tao at idagdag sila sa grupo. Gamitin ang star icon (**Make Leader**) para magtalaga ng mga group leader. Tingnan ang [Group Members](./group-members.md).
- **Mag-set up ng calendar** -- Gumawa ng mga event at paulit-ulit na pagpupulong para sa grupo. Tingnan ang [Group Calendar](./group-calendar.md).
- **Makipag-usap** -- Magpadala ng mensahe sa lahat ng miyembro ng grupo nang direkta mula sa pahina ng grupo.
- **Mag-export ng datos** -- I-click ang **Export** sa itaas ng listahan ng miyembro ng grupo para i-download ito.

:::info
Ang bawat grupo ay kabilang sa isang kategorya, at maaari mong i-filter ang listahan sa pangunahing pahina ng Groups ayon sa kategorya. Maaari mo ring muling ayusin o palitan ang pangalan ng mga kategorya habang lumalaki ang iyong simbahan.
:::
