# Paggawa ng Mga Group

<div class="article-intro">

Madali lang ang paggawa ng group sa B1 Admin. Magtatakda ka ng kategorya, papangalanan ang iyong group, at saka iko-configure ang mga setting nito. Tumutulong ang mga group na ayusin ang iyong simbahan sa mga makabuluhang yunit tulad ng maliliit na grupo, komite, at klase.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan mo ng aktibong B1 Admin account na may pahintulot na pamahalaan ang mga group. Tingnan ang [Roles & Permissions](../people/roles-permissions.md) kung hindi ka sigurado sa antas ng iyong access.
- Magpasya ng istruktura ng kategorya para sa iyong mga group (halimbawa, "Small Groups," "Ministries," "Committees"). Nakakatulong ang mga kategorya para mapanatiling maayos ang magkakaugnay na group.

</div>

## Pagdaragdag ng Bagong Group

1. Buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas ng B1 Admin), i-expand ang **People**, at i-click ang **Groups**.
2. I-click ang **Add Group** sa header ng pahina. May bubukas na **New Group** form sa ilalim ng listahan. Maglagay ng **Category Name**. Nakakatulong ang mga kategorya para pagsama-samahin ang magkakaugnay na group (halimbawa, "Small Groups," "Ministries," o "Committees"). Kung may umiiral nang kategorya, maaari mo itong piliin mula sa listahan.
3. Maglagay ng **Name** ng group.
4. I-click ang **Add**. Lalabas ang bago mong group sa listahan, na may kategorya nito sa ilalim ng pangalan.

## Pag-configure ng Mga Setting ng Group

Kapag nagawa na ang iyong group, maaari mong punan ang mga karagdagang detalye:

1. I-click ang **pangalan ng group** sa listahan para buksan ito.
2. I-click ang button na **Edit** sa kaliwang bahagi ng pahina ng group, sa ilalim ng mga detalye ng group.
3. I-configure ang mga sumusunod na opsyon:
   - **Description** -- Maikling buod kung ano ang tungkol sa group. Nakikita ito ng mga miyembro.
   - **Meeting Times** -- Kailan karaniwang nagkikita ang group (halimbawa, "Miyerkules at 7 PM").
   - **Join Policy** -- Piliin kung sino ang maaaring sumali sa group na ito:
     - **Open** -- Sinuman ay maaaring sumali kaagad nang walang pag-apruba
     - **Request** -- Kailangang magsumite ng join request ang mga tao na nangangailangan ng pag-apruba (tingnan ang [Group Join Requests](./group-join-requests.md))
     - **Closed** -- Kailangang idagdag nang manwal ng mga lider o administrator ang mga miyembro
   - **Labels** -- Maglagay ng isa o higit pang deskriptibong label sa group (halimbawa, "In-Person", "Online", "New Members Welcome"). Malayang tag ang mga label na ikaw mismo ang nagtatakda; lagyan ng check ang lahat ng angkop. Maaaring gamitin ang mga label para i-filter ang mga group sa Groups Browser website element.
   - **Confidential group** -- Itago ang group na ito at ang roster nito sa mga pampublikong pahina, sa group finder, at sa mga hindi miyembro. Gamitin ito para sa mga sensitibong group tulad ng recovery o counseling ministries; tanging ang mga miyembro ng group at staff ng simbahan lang ang makakakita nito.
   - **Discussions** -- Ino-on o i-o-off ang chat feed ng group, kung saan maaaring mag-post ang sinumang miyembro. Naka-on bilang default.
   - **Announcements** -- Ino-on ang pangalawang chat feed na para sa lider lamang -- maaaring magbasa at mag-react ang mga miyembro, pero mga lider lang ang maaaring mag-post. Naka-on bilang default.
   - **Attendance Tracking** -- I-enable ito kung nais mong itala ang [attendance](../attendance/tracking-attendance.md) para sa group na ito.
   - **Service Times** -- I-associate ang group sa mga partikular na oras ng serbisyo ng simbahan kung naaangkop. Tingnan ang [Attendance Setup](../attendance/setup.md) para sa mga detalye tungkol sa service times.
4. I-click ang **Save** para ilapat ang mga pagbabago.

:::tip
Nakakatulong ang malinaw na paglalarawan at oras ng pagkikita para malaman ng mga miyembro kung ano ang aasahan kapag sumali sila sa group.
:::

:::info
Kapag pinatay mo ang parehong Discussions at Announcements, mawawala ang Messages tab ng group sa member portal. Kapag isa lang ang pinatay mo, mawawala lang ang tab nito at mapupunta ang mga miyembro sa feed na nakabukas pa. Mananatili ang mga umiiral na mensahe sa alinmang kaso -- ang mga toggle ay kumokontrol lamang sa bagong pag-post.
:::

## Pagkopya ng Group

Magsisimula ka ba ng bagong session ng umuulit na klase o ministry? Sa halip na ilagay muli ang lahat ng setting, kopyahin ang umiiral na group:

1. Buksan ang group at i-click ang **Duplicate** (sa ilalim ng button na **Edit** sa kaliwang bahagi ng pahina ng group).
2. Kumpirmahin ang pagkopya.

Dinadala ng kopya ang mga setting ng orihinal -- kategorya, paglalarawan, oras/lugar ng pagkikita, join policy, labels, at campus -- pero **hindi** ang mga miyembro nito. Ang pangalan ng bagong group ay ang sa orihinal na may idinagdag na " (Copy)"; palitan ang pangalan nito mula sa mga setting ng group.

## Pag-archive ng Group

Kapag hindi na aktibo ang isang group pero gusto mong panatilihin ang kasaysayan nito sa halip na burahin:

1. Buksan ang group at i-click ang **Edit** para i-edit ang mga setting nito.
2. I-click ang **Archive** at kumpirmahin.

Hindi na lumalabas sa pangunahing listahan ng Groups ang mga naka-archive na group. Para mahanap muli ang isa, i-click ang button na **Show archived** sa tabi ng mga button ng kategorya sa itaas ng pahina ng Groups, pagkatapos ay i-click ang **Restore** sa tabi ng group para maibalik ito.

:::info
Hindi binubura ng pag-archive ng group ang mga miyembro, kasaysayan ng attendance, o mga event sa calendar nito -- itinatago lang nito ang group sa karaniwang listahan hanggang maibalik ito.
:::

## Mga Susunod na Hakbang

Pagkatapos gawin at i-configure ang iyong group, handa ka nang:

- **Magdagdag ng mga miyembro** -- Maghanap ng mga tao at idagdag sila sa group. Gamitin ang star icon (**Make Leader**) para italaga ang mga lider ng group. Tingnan ang [Group Members](./group-members.md).
- **Mag-set up ng calendar** -- Gumawa ng mga event at umuulit na pagpupulong para sa group. Tingnan ang [Group Calendar](./group-calendar.md).
- **Makipag-usap** -- Magpadala ng mensahe sa lahat ng miyembro ng group nang direkta mula sa pahina ng group.
- **Mag-export ng datos** -- I-click ang **Export** sa itaas ng listahan ng miyembro ng group para i-download ito.

:::info
Bawat group ay kabilang sa isang kategorya, at hinahayaan ka ng pangunahing pahina ng Groups na i-filter ang listahan ayon sa kategorya. Maaari mong ayusin muli o palitan ang pangalan ng mga kategorya habang lumalaki ang iyong simbahan.
:::
