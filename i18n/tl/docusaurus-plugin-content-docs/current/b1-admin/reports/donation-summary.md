# Donation Summary

<div class="article-intro">

Ang Donation Summary report ay nagbibigay sa iyo ng malinaw na larawan ng iyong church's giving activity. Gamitin ito upang subaybayan ang donation totals, subaybayan ang giving trends, at maghanda ng financial reports para sa iyong leadership team.

</div>

<div class="prereqs">
<h4>Bago Kang Magsimula</h4>

- Siguraduhin na ang mga donasyon ay [recorded consistently](../donations/recording-donations.md) sa iyong sistema
- Kailangan mo ng tamang [permissions](../settings/roles-permissions.md) upang ma-access ang mga financial reports

</div>

## Pagpapatakbo ng Ulat

1. Pumunta direkta sa **admin.b1.church/reports/donationSummary** sa iyong browser (ang mga ulat ay walang entry sa navigation menu — ang pag-bookmark sa address ay ang pinakamadaling paraan upang bumalik dito).
2. Itakda ang **date range** upang tukuyin ang panahon ng pag-ulat.
3. Mag-apply ng karagdagang mga filter tulad ng **fund** o iba pang mga pamantayan upang mapaliit ang mga resulta.
4. Ang ulat ay magpapakita ng giving summary para sa napiling panahon.

## Ano ang Ipinapakita ng Ulat

Ang Donation Summary report ay kinabibilangan ng:

- **Total donations** -- Ang kabuuang halaga ng pagbibigay para sa napiling panahon.
- **Donor count** -- Ang bilang ng mga natatanging donors na nag-ambag.
- **Amounts by fund** -- Isang breakdown ng giving sa iba't ibang funds, kung naaangkop.

## Practical Uses

- **Financial planning** -- Suriin ang giving trends upang mag-forecast ng hinaharap na kita at magplano ng iyong budget.
- **Board reports** -- Bumuo ng mga buod para sa regular na board o leadership meetings na may malinaw na giving data.
- **Year-end reviews** -- Patakbuhin ang ulat para sa buong taon upang maghanda ng annual financial summaries.
- **Campaign tracking** -- I-filter ayon sa fund upang subaybayan ang pag-unlad sa mga espesyal na giving campaigns o building projects.
- **Seasonal analysis** -- Ihambing ang giving sa iba't ibang panahon upang maunawaan ang seasonal patterns.

:::tip
Patakbuhin ang ulat na ito buwanan upang manatiling informed tungkol sa kalusugan ng iyong church's financial. Ang paghahambing ng month-over-month data ay tumutulong sa iyo na makita ang mga trends nang maaga.
:::

:::warning
Ang donation data ay nagmula sa mga nai-record na kontribusyon sa iyong sistema. Siguraduhin na ang mga donasyon ay naisaad nang consistent -- alinman sa pamamagitan ng online giving, check processing, o manual entry -- para sa pinakamaayos na mga ulat. Tingnan ang [Recording Donations](../donations/recording-donations.md) para sa mga detalye.
:::
