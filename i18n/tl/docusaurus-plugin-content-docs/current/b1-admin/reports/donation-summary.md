# Donation Summary

<div class="article-intro">

Nagbibigay ang Donation Summary report ng malinaw na larawan ng giving activity ng iyong simbahan. Gamitin ito para subaybayan ang kabuuan ng donasyon, bantayan ang giving trend, at maghanda ng financial report para sa iyong leadership team.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Tiyaking tuloy-tuloy na [nire-record ang mga donasyon](../donations/recording-donations.md) sa iyong sistema
- Kailangan mo ng [permiso](../settings/roles-permissions.md) na **View Donation Summaries**

</div>

## Pagpapatakbo ng Report {#running-the-report}

1. Buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa itaas-kaliwa ng B1 Admin), palawakin ang **Donations**, at i-click ang **Summary**. Agad tatakbo ang report para sa nakaraang taon.
2. Piliin ang **Weekly**, **Monthly**, o **Quarterly** para itakda kung paano pinagpapangkat ang giving.
3. Sa panel na **Filter Report**, itakda ang **Start Date** at **End Date**, opsyonal na pumili ng **Fund**, at i-click ang **Run Report**.
4. I-click ang **Download Options** at piliin ang **Summary** para i-download ang mga total bilang CSV, o i-click ang print icon para i-print ang report.

Tingnan ang [Donation Reports](../donations/donation-reports.md#giving-dashboard) para sa iba pang impormasyon tungkol sa pahinang ito.

## Ano ang Ipinapakita ng Report {#what-the-report-shows}

Kasama sa Donation Summary ang:

- **Total Giving** -- Ang kabuuang halaga ng giving para sa napiling panahon.
- **Average Gift** at **Total Donations** -- Ang karaniwang laki ng regalo at ang bilang ng mga regalo.
- **Unique Donors** -- Ang bilang ng natatanging donor na nag-ambag.
- **Amounts by fund** -- Isang bar chart ng giving kada linggo, buwan, o quarter, hati ayon sa fund.

## Mga Praktikal na Gamit {#practical-uses}

- **Pagpaplano sa pananalapi** -- Suriin ang giving trend para mahulaan ang kita sa hinaharap at mapagplanuhan ang budget.
- **Board reports** -- Gumawa ng buod para sa regular na board o leadership meeting, gamit ang malinaw na datos ng giving.
- **Pagsusuri sa katapusan ng taon** -- Patakbuhin ang report para sa buong taon para makapaghanda ng taunang financial summary.
- **Pagsubaybay sa campaign** -- I-filter ayon sa fund para masubaybayan ang progreso ng mga espesyal na giving campaign o building project.
- **Seasonal na pagsusuri** -- Ikumpara ang giving sa iba't ibang panahon para maunawaan ang mga seasonal na pattern.

:::tip
Patakbuhin ang report na ito buwan-buwan para manatiling updated sa kalusugang pinansyal ng iyong simbahan. Nakakatulong ang paghahambing ng datos buwan-sa-buwan para maagang matukoy ang mga trend.
:::

:::warning
Galing sa mga naitalang kontribusyon sa iyong sistema ang datos ng donasyon. Siguraduhing tuloy-tuloy ang pag-encode ng mga donasyon -- online giving man, check processing, o manual na pag-encode -- para sa pinakatumpak na mga report. Tingnan ang [Recording Donations](../donations/recording-donations.md) para sa mga detalye.
:::
