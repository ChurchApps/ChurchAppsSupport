# Listahan ng Anibersaryo

<div class="article-intro">

Kailangan mo ba ng listahan ng lahat ng may anibersaryo ng kasal sa isang buwan -- para sa bulletin, card, o anunsyo? Hinahayaan ka ng People search na mag-filter ayon sa **Anniversary Month** at ipakita agad ang mga petsa sa resulta.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Siguraduhing nailagay ang mga petsa ng anibersaryo sa profile ng bawat tao. Tingnan ang [Adding People](../people/adding-people.md) para sa mga detalye.
- Kailangan mo ng pahintulot na tingnan ang People. Tingnan ang [Roles & Permissions](../settings/roles-permissions.md).

</div>

## Pagkuha ng Listahan ng Anibersaryo para sa Isang Buwan {#getting-an-anniversary-list-for-a-month}

1. Buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas ng B1 Admin), buksan ang **People**, at i-click ang **People**.
2. Sa ilalim ng search box, i-click ang **Advanced**.
3. Buksan ang seksyong **Demographics** at lagyan ng check ang **Anniversary Month**, pagkatapos ay piliin ang buwan.
4. Agad na maa-update ang mga resulta kapag na-check ang filter -- lalabas ang lahat ng may anibersaryo sa buwang iyon.
5. Para makita ang mga petsa, palitan ang **View as** sa **Table**, pagkatapos ay i-click ang icon na **Select columns** sa header ng pahina at i-enable ang column na **Anniversary**. Gamitin ang **Export** para i-download ang listahan bilang spreadsheet kung gusto mo itong i-sort o i-print.

## Praktikal na Gamit {#practical-uses}

- **Lingguhang bulletin** -- Patakbuhin ang listahan ng kasalukuyang buwan at isama ang mga anibersaryo sa iyong bulletin o anunsyo.
- **Mga card ng anibersaryo** -- I-export ang listahan ng buwan at ibigay sa iyong team na sumusulat ng card.
- **Pagdiriwang ng milestone** -- Pagsamahin sa filter na **Years Married** para mahanap ang mga milestone na anibersaryo.

:::tip
Patakbuhin ito sa simula ng bawat buwan para may panahon kang maghanda ng mga card o anunsyo bago dumating ang mga anibersaryo.
:::

:::info
Galing ang datos ng anibersaryo sa anniversary field ng profile ng bawat tao. Kung may nawawala, kailangan lang idagdag ang petsa sa kanilang profile. Tingnan ang [Adding People](../people/adding-people.md).
:::
