# Listahan ng Anibersaryo

<div class="article-intro">

Kailangan ba ninyo ng listahan ng lahat ng may anibersaryo ng kasal sa isang partikular na buwan — para sa bulletin, mga card, o mga anunsyo? Hinahayaan kayo ng People search na mag-filter ayon sa **Anniversary Month** at ipakita ang mga petsa mismo sa mga resulta.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Tiyaking nailagay ang mga petsa ng anibersaryo sa profile ng bawat tao. Tingnan ang [Pagdaragdag ng mga Tao](../people/adding-people.md) para sa detalye.
- Kailangan ninyo ng pahintulot na tumingin ng People. Tingnan ang [Mga Role at Pahintulot](../settings/roles-permissions.md).

</div>

## Pagkuha ng Listahan ng Anibersaryo para sa Isang Buwan

1. Buksan ang [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas ng B1 Admin), palawakin ang **People**, at i-click ang **People**.
2. Sa ilalim ng search box, i-click ang **Advanced**.
3. Palawakin ang seksyong **Demographics** at lagyan ng check ang **Anniversary Month**, pagkatapos piliin ang buwan.
4. Patakbuhin ang paghahanap — lalabas sa mga resulta ang lahat ng may anibersaryo sa buwang iyon.
5. Para makita ang mga petsa, i-click ang **icon ng columns** sa kanang itaas ng mga resulta at i-enable ang column na **Anniversary**. Gamitin ang **Export** para i-download ang listahan bilang spreadsheet kung mas gusto ninyong i-sort o i-print ito.

## Mga Praktikal na Gamit

- **Lingguhang bulletin** -- Patakbuhin ang listahan ng kasalukuyang buwan at isama ang mga anibersaryo sa inyong bulletin o mga anunsyo.
- **Mga anniversary card** -- I-export ang listahan ng buwan at ibigay ito sa inyong team na sumusulat ng mga card.
- **Mga pagdiriwang ng mahahalagang taon** -- Isama sa filter na **Years Married** para mahanap ang mahahalagang anibersaryo.

:::tip
Patakbuhin ito sa simula ng bawat buwan para may oras kayong maghanda ng mga card o anunsyo bago dumating ang mga anibersaryo.
:::

:::info
Nagmumula ang datos ng anibersaryo sa field ng anibersaryo sa profile ng bawat tao. Kung may kulang na tao, kailangan lang idagdag ang petsa sa kanyang profile. Tingnan ang [Pagdaragdag ng mga Tao](../people/adding-people.md).
:::

## Tingnan Din
