# Mga Ulat ng Dumalo

<div class="article-intro">

Ang B1 Admin ay nagbibigay ng tatlong attendance reports upang tulungan kang maunawaan kung paano ang mga tao ay nakikipag-ugnayan sa iyong mga serbisyo at grupo. Bawat ulat ay nag-aalok ng ibang pananaw sa iyong attendance data, mula sa high-level trends hanggang sa daily breakdowns.

</div>

<div class="prereqs">
<h4>Bago Kang Magsimula</h4>

- Siguraduhin na ang attendance ay [tracked consistently](../attendance/tracking-attendance.md) para sa iyong mga serbisyo at grupo
- Siguraduhin na ang iyong [groups](../groups/creating-groups.md) at services ay na-configure sa B1 Admin
- Kailangan mo ng tamang [permissions](../settings/roles-permissions.md) upang ma-access ang mga ulat

</div>

## Attendance Trend

Ang Attendance Trend report ay nagpapakita kung paano nagbabago ang attendance sa paglipas ng panahon para sa iyong mga serbisyo.

1. Pumunta direkta sa **admin.b1.church/reports/attendanceTrend** sa iyong browser (ang mga ulat ay walang entry sa navigation menu — ang pag-bookmark sa address ay ang pinakamadaling paraan upang bumalik dito).
2. Itakda ang **date range** upang tukuyin ang panahon.
3. Pumili ng **service** o **group** upang saliin ang mga resulta.
4. Ang ulat ay nagpapakita ng isang trend line na nagpapakita ng mga bilang ng attendance sa nakalilipas na panahon.

Ang ulat na ito ay kapaki-pakinabang para sa pagtuklas ng mga pattern tulad ng seasonal dips, growth trends, o ang epekto ng mga espesyal na kaganapan.

## Group Attendance

Ang Group Attendance report ay nagpapakita ng attendance totals ayon sa grupo para sa isang napiling date range.

1. Pumunta direkta sa **admin.b1.church/reports/groupAttendance** sa iyong browser.
2. Itakda ang **date range** para sa ulat.
3. Pumili ng **group(s)** na gusto mong suriin.
4. Ang ulat ay nagpapakita ng kabuuang mga bilang ng attendance para sa bawat grupo.

Gamitin ang ulat na ito upang ihambing ang attendance sa mga grupo at tukuyin kung aling mga grupo ang lumalaki o nangangailangan ng atensyon.

## Daily Group Attendance

Ang Daily Group Attendance report ay nagbibigay ng day-by-day breakdown ng attendance data para sa iyong mga grupo.

1. Pumunta direkta sa **admin.b1.church/reports/dailyGroupAttendance** sa iyong browser.
2. Itakda ang **date range** para sa ulat.
3. Pumili ng **group(s)** na gusto mong suriin.
4. Ang ulat ay nagpapakita ng attendance numbers para sa bawat indibidwal na araw sa loob ng range.

Ang ulat na ito ay nagbibigay sa iyo ng granular detail, na kapaki-pakinabang para sa pag-unawa sa week-to-week variation o pagtuklas ng mga specific na araw na may hindi pangkaraniwang mataas o mababang attendance.

:::tip
Gamitin ang Attendance Trend report para sa high-level overview at ang Daily Group Attendance report kapag kailangan mong mag-drill sa mga specific na petsa.
:::

## Practical Uses

- **Planning** -- Gamitin ang attendance trends upang magplano ng seating, staffing, at resources para sa mga susunod na serbisyo.
- **Outreach** -- Tukuyin ang mga pattern ng bumabagal na attendance nang maaga upang maaari kang sumunod sa mga miyembro.
- **Board reports** -- Isama ang attendance data sa iyong regular na leadership reports upang ipakita ang kalusugan ng ministry.
- **Event evaluation** -- Ihambing ang attendance bago at pagkatapos ng mga espesyal na kaganapan upang sukatin ang kanilang epekto.

:::warning
Ang attendance data ay nire-record sa pamamagitan ng iyong grupo at service check-in processes. Kung ang attendance ay hindi consistently tracked, ang iyong mga ulat ay hindi tumpak na magpapakita ng aktwal na pagsali. Tingnan ang [Tracking Attendance](../attendance/tracking-attendance.md) para sa setup instructions.
:::
