# Mga Report

<div class="article-intro">

Maraming paraan ang B1 Admin para kumuha ng datos tungkol sa iyong kongregasyon, attendance, at giving. Naka-built-in ang pag-uulat sa mga kaugnay na seksyon ng app sa halip na sa iisang Reports page.

</div>

## Saan Makikita ang mga Report {#where-to-find-reports}

### People {#people}
- **[Mga Listahan ng Kaarawan at Anibersaryo](./birthday-report.md)** -- I-filter ayon sa Birth Month o Anniversary Month sa **People → Advanced Search** para makakuha ng listahan ng mga paparating na kaarawan o anibersaryo.

### Attendance {#attendance}
- **[Mga Ulat ng Attendance](./attendance-reports.md)** -- Makikita sa seksyong **Attendance** ang attendance trend at datos ng attendance ng grupo.

### Donations {#donations}
- **[Donation Summary](./donation-summary.md)** -- Makikita sa seksyong **Donations** ang kabuuan ng giving at breakdown ayon sa fund.

### Settings {#settings}
- **[Audit Log](./audit-log.md)** -- Subaybayan ang lahat ng pagbabago at aksyon sa iyong church management system (makikita sa ilalim ng **Settings → Audit Log**).

:::info
Nakadepende ang datos ng report sa tuloy-tuloy na pag-encode. Siguraduhing [sinusubaybayan ng iyong team ang attendance](../attendance/tracking-attendance.md), [nire-record ang mga donasyon](../donations/recording-donations.md), at napapanatiling updated ang [mga talaan ng tao](../people/adding-people.md) para sa pinakatumpak na resulta.
:::
