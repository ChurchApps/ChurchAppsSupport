# Mga Ulat

<div class="article-intro">

Nagbibigay ang B1 Admin ng ilang paraan para kumuha ng datos tungkol sa iyong kongregasyon, pagdalo, at giving. Nakabuild ang pag-uulat sa mga kaugnay na seksyon ng app sa halip na isang iisang pahinang Reports.

</div>

## Saan Makikita ang mga Ulat

### People
- **[Birthday & Anniversary Lists](./birthday-report)** -- I-filter ayon sa Birth Month o Anniversary Month sa **People → Advanced Search** para makakuha ng listahan ng mga darating na kaarawan o anibersaryo.

### Attendance
- **[Attendance Reports](./attendance-reports)** -- Ang mga trend ng pagdalo at datos ng group attendance ay makikita sa seksyong **Attendance**.

### Donations
- **[Donation Summary](./donation-summary)** -- Ang mga kabuuan ng giving at breakdown ayon sa fund ay makikita sa seksyong **Donations**.

### Settings
- **[Audit Log](./audit-log)** -- Subaybayan ang lahat ng pagbabago at aksyon sa iyong church management system (makikita sa ilalim ng **Settings → Audit Log**).

:::info
Nakadepende ang datos ng ulat sa tuloy-tuloy na pagpasok ng datos. Siguraduhing [sinusubaybayan ng iyong team ang pagdalo](../attendance/tracking-attendance.md), [itinatala ang mga donasyon](../donations/recording-donations.md), at napapanatiling updated ang [mga tala ng tao](../people/adding-people.md) para sa pinakatumpak na resulta.
:::
