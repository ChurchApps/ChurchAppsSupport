# Mga Ulat

<div class="article-intro">

Nagbibigay ang B1 Admin ng ilang paraan para kumuha ng datos tungkol sa iyong kongregasyon, attendance, at giving. Nakabuild ang pag-uulat sa mga kaugnay na seksyon ng app sa halip na sa isang iisang pahinang Reports.

</div>

## Saan Makikita ang mga Ulat

### People
- **[Birthday & Anniversary Lists](./birthday-report.md)** -- I-filter ayon sa Birth Month o Anniversary Month sa **People → Advanced Search** para makakuha ng listahan ng mga paparating na kaarawan o anibersaryo.

### Attendance
- **[Attendance Reports](./attendance-reports.md)** -- Makikita sa seksyong **Attendance** ang mga trend ng attendance at datos ng attendance ng grupo.

### Donations
- **[Donation Summary](./donation-summary.md)** -- Makikita sa seksyong **Donations** ang mga kabuuan ng giving at breakdown ayon sa fund.

### Settings
- **[Audit Log](./audit-log.md)** -- Subaybayan ang lahat ng pagbabago at aksyon sa iyong church management system (makikita sa ilalim ng **Settings → Audit Log**).

:::info
Nakadepende ang datos ng ulat sa tuloy-tuloy na pagpasok ng datos. Siguraduhing [sinusubaybayan ng iyong team ang attendance](../attendance/tracking-attendance.md), [itinatala ang mga donasyon](../donations/recording-donations.md), at napapanatiling updated ang [mga tala ng tao](../people/adding-people.md) para sa pinakatumpak na resulta.
:::
