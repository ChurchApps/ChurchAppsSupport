# Mga Ulat

<div class="article-intro">

Ang Reports page ay nagbibigay sa iyo ng mabilis na access sa pre-built na mga ulat na tumutulong sa iyo na maunawaan ang iyong church data. Gamitin ang mga ulatong ito upang subaybayan ang attendance trends, subaybayan ang giving activity, at manatiling konektado sa iyong congregation sa pamamagitan ng mga selebrasyon ng kaarawan.

</div>

## Available Reports

Ang mga ulat ay walang entry sa B1 Admin navigation menu -- pumunta direkta sa URL para sa ulat na gusto mo (ang pag-bookmark nito ay ang pinakamadaling paraan upang bumalik). Bawat ulat ay bumubukas direkta sa mga filter nito.

- **[Birthday Report](./birthday-report)** (`admin.b1.church/reports/birthdays`) -- Tingnan ang mga paparating na kaarawan para sa iyong mga miyembro ng congregation.
- **[Anniversary Report](./anniversary-report)** (`admin.b1.church/reports/anniversaries`) -- Tingnan ang mga paparating na wedding anniversaries para sa iyong mga miyembro ng congregation.
- **[Attendance Trend](./attendance-reports)** (`admin.b1.church/reports/attendanceTrend`) -- Tuklasin kung paano nagbabago ang mga pattern ng dumalo sa paglipas ng panahon sa iyong mga serbisyo.
- **[Group Attendance](./attendance-reports)** (`admin.b1.church/reports/groupAttendance`) -- Tingnan ang attendance totals ayon sa grupo para sa isang napiling date range.
- **[Daily Group Attendance](./attendance-reports)** (`admin.b1.church/reports/dailyGroupAttendance`) -- Makakuha ng isang day-by-day breakdown ng attendance data sa mga grupo.
- **[Donation Summary](./donation-summary)** (`admin.b1.church/reports/donationSummary`) -- Suriin ang giving totals at trends para sa financial planning.
- **[Audit Log](./audit-log)** -- Subaybayan ang lahat ng pagbabago at aksyon sa buong iyong church management system (nakahanap sa ilalim ng Settings > Audit Log).

## Using Reports

1. Pumunta direkta sa URL ng ulat, tulad ng **admin.b1.church/reports/birthdays**.
2. Gamitin ang **filters** sa tuktok ng ulat upang mapaliit ang data ayon sa date range, grupo, serbisyo, o iba pang mga pamantayan.
3. Suriin ang mga resulta na ipinapakita sa ulat.

:::tip
Magpatakbo ng mga ulat nang regular upang manatiling nangunguna sa attendance trends, mga paparating na kaarawan, at giving patterns. Ang data na ito ay tumutulong sa iyo na magplano ng mga ministry at outreach nang mas epektibo.
:::

:::info
Ang ulat data ay umaasa sa consistent data entry. Siguraduhin na ang iyong team ay [tracking attendance](../attendance/tracking-attendance.md), [recording donations](../donations/recording-donations.md), at pinapanatili ang [people records](../people/adding-people.md) up to date para sa pinakamaayos na mga resulta.
:::
