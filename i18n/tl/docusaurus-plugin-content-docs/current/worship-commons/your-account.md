# Ang Iyong Account sa WorshipCommons at ang Writer Page

<div class="article-intro">

Maaari kang mag-browse, mag-play, mag-print, at mag-project ng mga kanta sa WorshipCommons nang walang account. Ang libreng account ay nagbibigay-daan sa iyong mag-save ng mga kanta, magbahagi ng sarili mong mga kanta, magmungkahi ng mga pagbabago, at subaybayan ang lahat ng ipinadala mo. Kung sumusulat ka ng mga kanta, magagamit mo rin ang iyong account para i-edit ang writer page na nakikita ng mga simbahan.

</div>

## Pag-sign In o Paggawa ng Account

Gumagamit ang WorshipCommons ng mga ChurchApps account. Kung mayroon ka na nito (halimbawa, mula sa B1), maaari mong gamitin ang parehong email at password.

1. I-click ang **Sign in** sa itaas na menu.
2. Ilagay ang iyong **Email** at **Password**, pagkatapos ay i-click ang **Sign in**.

**Para gumawa ng account:**

1. Sa sign-in page, i-click ang **Create an account**.
2. Ilagay ang iyong **First name**, **Last name**, at **Email**, pagkatapos ay i-click ang **Create account**.
3. Tingnan ang iyong email para sa 6-digit na code, i-type ito, at i-click ang **Verify code**.
4. Pumili ng password na may hindi bababa sa 8 karakter, i-type itong muli sa ilalim ng **Verify password**, at i-click ang **Set password & sign in**.

**Nakalimutan ang iyong password?** I-click ang **Forgot password?** sa sign-in page, ilagay ang iyong email, at i-click ang **Send code**. Pagkatapos, ilagay ang code mula sa iyong email at magtakda ng bagong password.

Kapag naka-sign in ka na, lalabas ang iyong first name sa itaas na menu. I-click ito para buksan ang **My submissions** o **Report**, o para mag-**Sign out**.

## Mga Naka-save na Kanta

I-click ang puso sa anumang pahina ng kanta para i-save ito. I-click ang **Saved songs** sa itaas na menu para makita ang lahat ng kantang na-save mo. Naka-imbak ang mga na-save na kanta sa iyong account, kaya lumalabas ang mga ito sa bawat device na pinag-signing-inan mo. I-click ang **Remove** para alisin ang kanta sa listahan.

:::tip
Ang mga naka-save na kanta ay simpleng listahan ng mga paborito. Para magplano ng set para sa isang partikular na Linggo, kasama ang mga key at seksyon, gamitin ang [Service Plans](./service-plans.md).
:::

## Aking mga Isinumite

I-click ang iyong pangalan sa itaas na menu at piliin ang **My submissions** para makita ang bawat kanta at pagbabagong sinimulan o ipinadala mo, at kung nasaan na ang bawat isa. Gamitin ang mga tab sa itaas -- **All**, **Drafts**, **In review**, **Live**, at **Not accepted** -- para i-filter ang listahan.

Ipinapakita ng bawat entry ang uri nito (gaya ng **New song**, **Translation**, **Arrangement**, **Correction**, o **Removal request**) at ang katayuan nito:

| Status | Ibig sabihin |
| --- | --- |
| **Draft** | Sinimulan pero hindi pa naipadala. I-click ang **Continue** para tapusin ito, o ang **Delete draft** para alisin ito. |
| **Changes requested** | Humiling ang reviewer ng mga pagbabago. I-click ang **Continue**, gawin ang mga ito, at ipadala muli. |
| **In review** | Binabasa ng isang tao ang bawat kanta bago ito mailabas, karaniwan sa loob ng ilang araw. I-click ang **Withdraw** para ibalik ito sa draft. |
| **Live** | Nasa library at libre para magamit ng mga simbahan. Makikita mo ang bilang ng download nito at ang link nito. |
| **Not accepted** | Hindi ito napasama sa library. Ipinapakita ang dahilan ng reviewer. |
| **Withdrawn** | Binawi mo ito bago ito nasuri. |
| **Taken down** | Inalis ang kanta sa library, ayon sa iyong hiling. |

Para sa isang live na kanta, i-click ang **Copy link** para ibahagi ang pahina nito, ang **Propose a change** para magpadala ng pag-edit, o ang **Request removal** para hilingin itong alisin. Tingnan ang [Pagmumungkahi ng Pag-edit at Pag-uulat ng Kanta](./proposing-edits.md).

:::info
Kung idinagdag ka ng WorshipCommons team bilang co-publisher ng isang kanta -- halimbawa, kantang isinulat mo kasama ng iba at in-upload ng iba -- lalabas ito sa **My submissions** bilang **Live**, kahit hindi mo ito ipinadala mismo. Bilang publisher ng kanta, maaari kang gumawa ng mga pagbabago kahit sarado ito sa publiko dahil sa lisensya nito.
:::

## Mga Writer Page

Bawat writer sa library ay may writer page na naglilista ng kanilang mga kanta, kasama ang taon, key, tema, at lisensya ng bawat kanta. Naaabot ito ng mga simbahan sa pamamagitan ng pag-click sa pangalan ng writer sa pahina ng kanta. Kapag maraming writer ang isang kanta, bawat pangalan ay nagli-link sa sarili nitong pahina.

Maaari ring magpakita ang writer page ng larawan, maikling bio, mga link, at mga support link kung saan masusuportahan ng mga simbahan ang iba pang gawain ng writer.

### Pag-edit ng Iyong Writer Page

Magkakaroon ka ng writer page kapag live na ang isa sa iyong mga kanta at ikaw mismo ang nakalistang may-akda nito.

1. I-click ang iyong pangalan sa itaas na menu at piliin ang **My submissions**.
2. I-click ang **Writer profile**.
3. Sa ilalim ng **About you**, sumulat ng ilang pangungusap tungkol sa iyo at sa mga kantang isinusulat mo (hanggang 2,000 karakter).
4. Sa ilalim ng **Links**, magdagdag ng hanggang limang link, gaya ng iyong website. Bigyan ang bawat isa ng **Label** at web address nito. I-click ang **Add a link** para sa karagdagang hanay.
5. Sa ilalim ng **Support links**, magdagdag ng mga lugar kung saan masusuportahan ng mga simbahan ang iyong gawain, gaya ng tindahan o ministry page. I-click ang **Add a support link** para sa karagdagang hanay.
6. I-click ang **Save profile**.

I-click ang **View your writer page** para makita ito gaya ng pagkakita ng mga simbahan. Lalabas din ang iyong mga support link bilang **Songwriter's page** na button sa bawat pahina ng iyong kanta.

:::tip
Isinulat mo ang iyong mga kanta kasama ng iba, o may writer page ka na hindi pa naka-link sa iyong account? Mag-email sa [support@churchapps.org](mailto:support@churchapps.org) at hilingin na i-link ito.
:::
