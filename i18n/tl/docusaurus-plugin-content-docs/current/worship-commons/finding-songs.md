# Paghahanap ng mga Kanta sa WorshipCommons

<div class="article-intro">

Ang pahinang **Discover** ang aklatan ng mga kanta ng WorshipCommons. Maghanap ng kantang alam mo na, o paliitin ang listahan gamit ang mga filter para makahanap ng bago para sa Linggo. Hindi mo kailangang mag-sign in para maghanap o magpatugtog ng mga kanta.

</div>

## Paghahanap sa Aklatan

1. Pumunta sa [worshipcommons.org](https://worshipcommons.org) at i-click ang **Discover** (o **Browse Songs**) sa itaas ng pahina.
2. Mag-type sa search box. Maaari kang maghanap ayon sa pamagat, unang linya, pangalan ng himig, tema, sanggunian sa banal na kasulatan, o manunulat. Nag-a-update ang mga resulta habang nagta-type ka.
3. Gamitin ang menu na **Sort by** para ayusin ang mga resulta ayon sa **Most downloaded**, **Most saved**, **Newest**, o **Title A–Z**.
4. I-click ang pamagat ng kanta para buksan ang [pahina ng kanta](./song-page.md).

:::tip
Pindutin ang `/` na susi kahit saan sa pahina ng Discover para tumalon sa search box.
:::

Ipinapakita ng bawat hanay ang manunulat ng kanta, taon, sanggunian sa banal na kasulatan (kung mayroon), bilang ng mga download at save, hanggang tatlong tema, susi nito, at tempo nito sa BPM. I-click ang play button sa simula ng isang hanay para pakinggan ang demo recording o piano preview nang hindi umaalis sa listahan.

## Pag-filter ng mga Kanta

I-click ang **Filters** para buksan o isara ang filter panel (bukas ito bbilang default sa mas malalaking screen). Sa loob ng isang grupo, maaari kang pumili ng higit sa isang halaga; sa pagitan ng mga grupo, dapat tumugma ang kanta sa lahat ng filter na itinakda mo. Ipinapakita ng numerong nasa tabi ng bawat opsyon kung ilang kanta ang tumutugma.

- **Theme** -- Mga paksa gaya ng Praise, Grace, Hope, o Christmas. I-click ang **Show more** para sa buong listahan.
- **Confidence** -- Kung gaano kakumpleto ang materyales ng kanta: **Sunday-ready**, **Score**, **Unchecked score**, **Chart only**, o **Lyrics only**.
- **Ready to use** -- **Works with just a guitar**, **Has accompaniment**, **Has chart**, **Has score**, at **Has stems**.
- **Key** at **Meter** -- Pumili ng partikular na susi o sukat ng himno.
- **Tempo** -- **Slow** (mas mababa sa 73 BPM), **Moderate** (73–100), o **Upbeat** (higit sa 100).
- **Language** -- Mga kanta sa isang partikular na wika.
- **Source** -- Lisensya ng kanta, gaya ng **Public domain**, **Free for worship**, o isang Creative Commons license. Ang mga lisensyang may markang ⚠ ay para sa hindi pangkomersyal na gamit.
- **Extras** -- **Has demo recording**.

Lumalabas sa itaas ng mga resulta ang mga aktibong filter bilang mga chip. I-click ang **X** ng isang chip para alisin ito, o i-click ang **Clear all filters** para magsimula muli.

:::info
Ang filter na **Language** ay nagsisimula sa wikang pinili mo para sa site, kaya unang makikita mo ang mga kanta sa sarili mong wika. Para makita ang mga kanta sa lahat ng wika, alisin ang language chip sa itaas ng mga resulta. Para baguhin ang wika ng site, gamitin ang globe picker sa ibaba ng anumang pahina.
:::

## Kapag Wala ang Kanta

Kung walang tumutugma, paluwagin ang isang filter o burahin ang iyong paghahanap. Ang WorshipCommons ay naglalaman lamang ng mga kantang nasa public domain o ibinahagi ng mga manunulat, kaya karamihan sa mga kantang may copyright ay wala rito. Kapag walang lumabas sa paghahanap, i-click ang **Search SongSelect →** para hanapin ang kanta sa katalogo ng CCLI.

## Iba Pang Paraan ng Pag-browse

Ang mga link sa ibaba ng bawat pahina ay nagdadala sa mga handang listahan:

- **New songs** -- Bawat kantang idinagdag sa aklatan, mula sa pinakabago.
- **Public domain hymns** -- Mga himnong malayang magagamit para sa lahat ng layunin.
- **No CCLI needed** -- Mga kantang magagamit ng iyong simbahan nang hindi nag-uulat sa CCLI.
- **Christmas songs** -- Isang koleksyon para sa panahon ng Pasko.

I-click ang **Listen** sa itaas na menu para pakinggan ang mga kamakailang ibinahaging kanta ng mga manunulat, hinalo at isa-isang tumutugtog. I-click ang **+ Save song** habang tumutugtog ang isa para idagdag ito sa iyong mga naka-save na kanta (hihilingin sa iyong mag-sign in).
