# Pagpapakita at Pag-export ng mga Kanta mula sa WorshipCommons

<div class="article-intro">

Maaaring ipakita ng WorshipCommons ang lyrics ng kanta sa screen mismo mula sa iyong browser, nang walang kailangang i-install. Kung gumagamit na ng presentation software ang iyong simbahan, i-download na lamang ang mga slide ng kanta para sa FreeShow, OpenLP, ProPresenter, o PowerPoint, o idagdag ang kanta sa iyong song library sa B1 Admin.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Buksan ang pahina ng kanta sa [worshipcommons.org](https://worshipcommons.org). Tingnan ang [Paghahanap ng Kanta](./finding-songs.md).
- Para maipakita ang lyrics sa TV o projector, ikonekta ang iyong computer dito gamit ang HDMI cable (o i-cast ang iyong screen).

</div>

## Pangunguna sa Pagsamba mula sa Browser

Ang **Lead worship** ay isang full-screen na view na nagpapatugtog ng musika at nagpapakita ng mga salita nang linya-por-linya, at itinatampok ang bawat salita habang kinakanta. Ginawa ito para sa maliit na grupo, klase, o house church na walang banda.

1. Sa pahina ng kanta, i-click ang **Lead worship**. (Lumalabas ang button kapag may musikang masasabayan ang kanta.)
2. Piliin ang **Key** at **Tempo**. Kapag may piano preview ang kanta, maaari kang pumili ng **Piano** o **Organ**.
3. I-click ang **Verses** para piliin kung aling mga talata ang kakantahin at baguhin ang kanilang pagkakasunod-sunod gamit ang mga arrow button.
4. I-on ang **Count-in** kung gusto mo ng bilang bago magsimula ang musika.
5. I-click ang **▶ Play**.

Gamitin ang **Blank** para itago ang mga salita, ang **Contrast** para sa screen na mataas ang contrast, at ang **Fullscreen** para punuin ang screen. I-click ang **Put this on the TV** para sa mabilisang hakbang sa pagpapakita nito sa TV.

:::tip
Mga keyboard shortcut: **Space** para i-play/i-pause, **← →** para ilipat ang linya, **↑ ↓** para ilipat ang talata, **B** para sa blank, **H** para sa contrast, **F** para sa fullscreen, **Esc** para bumalik sa kanta. I-click ang **Show keys** sa ibaba ng screen para makita ang mga ito.
:::

## Pag-project ng Lyrics

Ang **Open projector** ay nagpapakita ng isang seksyon ng lyrics kada screen, at ikaw mismo ang lumilipat sa mga ito. Gamitin ito kung may mga live na musikero.

1. Sa pahina ng kanta, hanapin ang panel na **Projection** at i-click ang **Open projector**.
2. Pindutin ang **F** o i-click ang **Fullscreen** para punuin ang screen.
3. I-click ang screen, o pindutin ang **Space** o ang **→** key, para pumunta sa susunod na slide. Pindutin ang **←** para bumalik. I-click ang pangalan ng seksyon sa ibaba para dumiretso doon.
4. Pindutin ang **B** para i-blank ang screen at ang **H** para sa mataas na contrast.
5. Pindutin ang **Esc** (o i-click ang **← Back to song**) kapag tapos ka na.

Ipinapakita ng ibabang bar ang kasalukuyang seksyon, ang bilang ng slide, at kung ano ang susunod. Lumalabas din sa screen ang linya ng pagkilala sa kanta.

## Pag-export ng mga Slide

May button para sa bawat tool ang panel na **Projection** sa pahina ng kanta. I-click ang isa para i-download ang kanta:

| Button | Ano ang makukuha mo |
| --- | --- |
| **FreeShow** | Isang show file na ii-import sa [FreeShow](https://freeshow.app) |
| **PowerPoint** | Isang PPTX na slide deck |
| **OpenLP** | Isang OpenLyrics file na ii-import sa OpenLP |
| **ProPresenter** | Isang text file na ii-import sa ProPresenter |
| **OnSong / PCO** | Kinokopya ang kanta sa iyong clipboard para i-paste sa OnSong o Planning Center |

Ipinapaliwanag ng note sa ilalim ng mga button kung paano hinahati ang mga slide. Kung may naaprubahang form map ang kanta, sumusunod ang mga slide dito; kung wala, sumusunod ang mga slide sa mga talata gaya ng nakasulat. Kasama sa bawat export ang pagkilala sa may-akda at ang credit ng lisensya ng kanta.

:::tip
Para i-export ang buong set nang sabay-sabay, sa mga key at seksyong pinili mo, gumawa ng [service plan](./service-plans.md) at gamitin ang mga export button doon.
:::

## Pagdaragdag ng mga Kanta mula sa WorshipCommons sa B1

Kung nagpaplano ng mga serbisyo ang iyong simbahan sa B1 Admin, hindi mo na kailangang mag-download ng anuman. Lumalabas sa paghahanap ng kanta sa B1 Admin, sa ilalim ng **WorshipCommons — free**, ang mga kantang handa na para sa Linggo mula sa WorshipCommons. I-click ang isa para idagdag ito sa iyong song library, na naka-link pabalik sa pahina nito sa WorshipCommons.

Tingnan ang [Mga Kanta sa B1 Admin](../b1-admin/serving/songs.md#free-songs-from-worshipcommons) para sa mga hakbang.
