# Mga Service Plan sa WorshipCommons

<div class="article-intro">

Ang service plan sa WorshipCommons ay listahan ng mga kanta para sa Linggo. Ilagay ang mga kanta ayon sa pagkakasunod-sunod, piliin ang key, capo, at mga seksyon para sa bawat isa, saka ibahagi ang iisang link sa iyong banda. Mula sa plan, maaari kang magbukas ng stage view para sa music stand, mag-print ng booklet, o i-export ang buong set papunta sa iyong presentation software.

</div>

:::info
Ang mga service plan ay naka-save sa iyong web browser, hindi sa iyong account, at hindi mo kailangang mag-sign in para magamit ang mga ito. Dala ng share link ang buong set, kaya i-save ang link kung magpapalit ka ng device. Kung ang iyong simbahan ay nagpaplano ng mga serbisyo sa B1 Admin, tingnan na lang ang [Mga Plan](../b1-admin/serving/plans.md).
:::

## Paggawa ng Service Plan

1. I-click ang **Service plans** sa itaas na menu.
2. I-type ang pangalan, gaya ng "Sunday 14 Sept" o "Youth night", at i-click ang **Create service plan**.

Maaari ka ring magsimula ng plan mula sa anumang kanta. Sa pahina ng kanta, i-click ang **+ Add to service plan**, i-type ang pangalan sa ilalim ng listahan, at i-click ang **Create**.

## Pagdaragdag ng mga Kanta

1. Buksan ang pahina ng kanta. Itakda muna ang key na gusto mo, dahil papasok ang kanta sa plan sa key na nakikita sa screen.
2. I-click ang **+ Add to service plan**.
3. I-click ang pangalan ng plan. Lalabas ang check mark na nagpapakitang nasa plan na iyon ang kanta. I-click ulit ito para alisin.

Pagkatapos, magiging **✓ In** na ang button, kasunod ang pangalan ng plan. I-click ang **Open** na link na may pangalan ng plan sa pop-up para pumunta sa plan.

## Pag-aayos ng Set

Buksan ang plan mula sa pahinang **Service plans**. Para sa bawat kanta, maaari mong:

- **Ayusin ang pagkakasunod-sunod** -- Gamitin ang mga button na **↑** at **↓**, o i-drag ang kanta sa bagong puwesto. I-click ang **Remove** para alisin ito.
- **Key** -- Pumili mula sa mga **Published** na key ng kanta o anumang ibang key (nakalista sa ilalim ng **Preview (any key)**).
- **Capo** -- Pumili ng capo fret. Ipinapakita ng plan kung aling chord shapes ang tutugtugin.
- **Mga seksyon** -- Itakda ang pagkakasunod-sunod ng mga verse at chorus. Gamitin ang mga arrow para ilipat ang seksyon, ang **×** para alisin ito, at ang **+ Add section** para magdagdag ng isa (halimbawa, paulit-ulit na chorus). I-click ang **Reset to default** para bumalik sa karaniwang ayos ng kanta.
- **Arrangement** -- Mag-type ng maikling tala para sa banda, gaya ng "Chorus ×2 sa dulo, huling verse a cappella".

Ipinapakita sa itaas ng plan ang bilang ng mga kanta at tinatayang haba ng set. Awtomatikong nase-save ang mga pagbabago.

## Pagbabahagi sa Iyong Team

1. I-click ang **Share link**. Makokopya ang link sa iyong clipboard.
2. Ipadala ito sa iyong banda sa pamamagitan ng text o email.

Ang sinumang magbukas ng link ay makikita ang plan kasama ang bawat key, capo, seksyon, at tala, nang hindi kailangan ng account. Maaari nilang i-click ang **Save a copy** para itago ang sarili nilang editable na kopya sa kanilang browser.

Sa pahinang **Service plans**, maaari ka ring mag-**Share**, **Rename**, **Duplicate**, o **Delete** ng plan.

## Paggamit ng Plan sa Linggo

- **Stage mode** -- Nagpapakita ng isang chart kada screen para sa tablet sa music stand. Gamitin ang mga arrow (o ang mga key na **←** at **→**) para lumipat sa pagitan ng mga kanta, at ang mga text-size button para palakihin ang chart. Sinusubukan ng stage mode na huwag patayin ang screen; ipinapakita ng bar kung **Keeping the screen awake** ito.
- **Print booklet** -- Ini-print ang bawat chart ayon sa pagkakasunod-sunod, isa kada pahina, kasama ang cover na naglilista ng mga kanta at key. Piliin ang **Large text** o **Show chords**, saka i-click ang **Print**.
- **Copy for OnSong / Planning Center** -- Kinokopya ang bawat chart sa iyong mga key at seksyon, handa nang i-paste.

## Pag-e-export ng Set

I-click ang **FreeShow**, **OpenLP**, **ProPresenter**, o **PowerPoint** para i-download ang buong set para sa tool na iyon, sa mga key at seksyong pinili mo.

I-click ang **House-church pack** para mag-download ng ZIP na may chart ng bawat kanta sa iyong key, ang lyrics, mga slide, attribution, listahan ng set, at isang LICENSE.txt file.

:::warning
Hindi isinasama sa house-church pack ang mga kantang may lisensyang CC BY-SA maliban kung lagyan mo ng check ang **Share-alike pack (include CC BY-SA songs)**. Kapag isinama mo ang mga ito, anumang gawin mo mula sa pack ay dapat ibahagi sa parehong lisensya. Palaging kasama ang mga kantang ito sa mga chart, stage mode, at booklet.
:::
