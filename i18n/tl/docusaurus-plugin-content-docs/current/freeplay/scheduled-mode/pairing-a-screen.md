# Pagpapares ng Screen

<div class="article-intro">

Para ilagay ang TV sa isang kalendaryo, ipares ito sa **FreePlay Admin**. Nagpapakita ang TV ng apat na letrang code. Ilalagay mo ang code na iyon sa [admin.freeplay.church](https://admin.freeplay.church) at pipiliin ang screen group na dapat sundan ng kalendaryo nito. Gagawin mo lang ito nang isang beses para sa bawat TV.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- I-install at ilunsad ang FreePlay sa TV. Tingnan ang [Getting Started](../getting-started/)
- Magkaroon ng ChurchApps login para sa simbahan mo para makapag-sign in sa FreePlay Admin
- Opsyonal, [gumawa ng playlist](./building-playlists) at [iiskedyul ito](./scheduling-the-calendar) muna para may maipe-play agad ang TV

</div>

## Pagpapakita ng Code sa TV

1. Sa TV, buksan ang **Settings** sa ibaba ng sidebar.
2. Piliin ang **Pair to a calendar**. Ipinapakita ng row ang **Not paired** kapag hindi pa naipapares ang TV.
3. Ipinapakita ng screen na **Pair this screen** ang QR code at apat na letrang pairing code, na may mensaheng **Scan with your phone, or go to freeplay.church/pair and enter this code**.
4. Sa ilalim ng code, pumipintig ang **Waiting for confirmation** habang naghihintay ang FreePlay na matapos mo ang pagpapares.

Ang code ay tumatagal ng 15 minuto, at may countdown sa ilalim nito na nagpapakita kung gaano na katagal ang natitira. Kapag naubos ang oras, awtomatikong nagpapakita ang FreePlay ng bagong code. Maaari mo ring piliin ang **Generate New Code** para sa bago, o **Cancel** para bumalik sa Settings.

## Pagpapares sa FreePlay Admin

1. I-scan ang QR code gamit ang telepono mo, o pumunta sa **freeplay.church/pair** sa anumang computer o telepono. Mag-sign in kung hihilingin. Bubuksan ng FreePlay Admin ang form na **Pair screen** na nakalagay na ang code.
   - Maaari mo ring buksan ang form nang mag-isa. Pumunta sa **Screens** sa FreePlay Admin at i-click ang **Pair screen**.
2. Suriin ang **Pairing code**. Ito ang apat na letra sa TV.
3. Maglagay ng **Label** para matukoy mo ang TV na ito mula sa iba, halimbawa "Lobby left". Opsyonal ito.
4. Sa ilalim ng **Group**, piliin ang screen group na dapat sundan ng kalendaryo ng TV na ito. Para gumawa ng bago, piliin ang **＋ New group…** at ilagay ang **New group name**.
5. Sa ilalim ng **Mode**, iwanang nakapili ang **Scheduled**. Susunod ang TV sa kalendaryo ng group nang mag-isa.
6. I-click ang **Pair**.

Ipinapakita ng TV ang **Connected!** at pagkatapos ang **Loading your schedule...**. Dina-download nito ang nakaiskedyul at nagsisimulang mag-play. Tingnan ang [Scheduled Playback on the TV](./scheduled-playback).

:::info
Kung sinabi ng FreePlay Admin na **That code didn't match a TV**, tingnan ang code sa screen. Kung nag-expire na ito, gamitin ang bagong code na ipinapakita na ngayon ng TV.
:::

### Scheduled vs. Manual

May dalawang opsyon ang setting na **Mode**:

- **Scheduled** - Naglalaro ayon sa kalendaryo ng group nang mag-isa. Walang kailangang pumindot ng Start.
- **Manual** - Pumipili ang isang tao ng content gamit ang remote. Lalabas pa rin ang manual na screen sa listahan mo ng **Screens**, pero hindi ito sumusunod sa kalendaryo, kaya naka-off ang field na **Group**.

Maaari mong baguhin ang mode ng screen sa ibang pagkakataon mula sa **Edit** sa [Screens page](./managing-screens).

## Pagpapares sa Service Plan sa Halip

Gumagana rin ang code sa screen na **Pair this screen** sa B1 Admin. Kung ilalagay mo ito doon at pipili ng uri ng plano sa ilalim ng **Show Plans For**, susundan ng TV ang uri ng planong iyon sa [Plan Mode](../plan-mode/) sa halip na kalendaryo. Tingnan ang [Pairing Your Device](../plan-mode/device-pairing).

## Pagpalit o Pag-unpair mula sa TV {#changing-or-unpairing-from-the-tv}

Kapag naipares na ang TV, ipinapakita ng row na **Pair to a calendar** sa **Settings** ang pangalan ng screen group na sinusundan nito. Piliin ang row para buksan ang dialog na **Paired to**, na may tatlong opsyon:

- **Keep** - Isara ang dialog. Walang magbabago.
- **Unpair** - Itigil ang pagsunod sa iskedyul. Bubuksan ng FreePlay ang screen na **Content Providers**.
- **Pair to a different calendar** - I-unpair, pagkatapos magpakita ng bagong pairing code para maipares muli ang TV.

:::warning
Inaalis ng pag-unpair ang mga file na na-download ng FreePlay para sa kalendaryong iyon.
:::

## Pag-unpair mula sa FreePlay Admin

1. Pumunta sa **Screens** at i-click ang label ng screen.
2. I-click ang **More**, pagkatapos ang **Unpair**.
3. I-click muli ang **Unpair** para kumpirmahin.

Bumabalik ang TV sa pagpapakita ng pairing code. Ipares ito muli kapag gusto mo itong ibalik.
