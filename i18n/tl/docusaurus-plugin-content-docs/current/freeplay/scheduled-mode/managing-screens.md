# Pamamahala ng mga Screen at Group

<div class="article-intro">

Ipinapakita ng pahinang **Mga Screen** sa FreePlay Admin ang bawat TV na naka-pair sa simbahan mo, kasama ang kasalukuyang pinapatugtog nito at kung handa na ito para sa Linggo. Dito mo rin pinamamahalaan ang mga **screen group**. Ang mga screen sa iisang group ay nagbabahagi ng iisang kalendaryo at iisang default loop.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Mag-sign in sa FreePlay Admin sa [admin.freeplay.church](https://admin.freeplay.church)
- [I-pair ang kahit isang screen](./pairing-a-screen)

</div>

## Ang Pahinang Screens

Sa itaas, tatlong numero ang nagbibigay ng mabilisang pagsusuri sa kalusugan:

- **Online ngayon** -- Mga screen na nag-check in sa huling 15 minuto
- **Handa para sa Linggo** -- Ilan sa mga naka-schedule na screen ang nakadownload na ng lahat hanggang sa darating na Linggo
- **Nangangailangan ng atensyon** -- Mga screen na offline o kulang ang mga file

Sa ibaba nito, gamitin ang **Maghanap ng screen** para mahanap ang screen ayon sa label, group, o kung ano ang pinapatugtog nito. Pinapaliit ng mga filter chip ang listahan sa **Lahat**, **Naka-iskedyul**, **Manual**, **Nangangailangan ng atensyon**, o isang partikular na group. Lumipat sa pagitan ng mga view na **Table** at **Grid** gamit ang toggle sa kanan.

Ipinapakita ng bawat screen ang:

- **Label** at modelo ng device
- **Group**
- **Mode** -- **Naka-iskedyul** o **Manual**
- **Kasalukuyang pinapatugtog** -- Ang nasa screen ngayon. Ang mga manual screen ay nagpapakitang **Classroom · pinipindot ng guro ang Start**
- **Handa hanggang** -- Ang petsang nadownload na ng screen. Kung hindi nadownload ang mga file, ipapakita nito ang **N nawawalang file** sa halip. Ang bagong screen ay magpapakitang **Naghihintay sa unang sync**
- **Huling nakita** -- Kailan huling nag-check in ang screen. Ang screen na matagal nang hindi nag-check in ay magpapakitang **Offline**, at ang hindi pa nakakakonekta kailanman ay magpapakitang **Hindi pa nakita kailanman**

Gamitin ang **I-present** para i-play ang kalendaryo ng screen sa browser mo, o ang **I-edit** para baguhin ang mga setting nito.

## Pagtingin sa Isang Screen

I-click ang label ng screen para buksan ang pahina nito. Sa kaliwa:

- **I-present sa browser** -- I-play ang kalendaryo ng screen na ito nang full screen sa browser mo, gaya ng itsura nito sa TV. Tingnan ang [Presenting from a Browser](./scheduled-playback#presenting-from-a-browser)
- **I-edit** -- Baguhin ang label, group, o mode
- **Higit pa** > **I-unpair** -- Idiskonekta ang TV. Babalik ito sa pagpapakita ng pairing code

Ang natitira sa pahina ay may mga seksyong ito:

- **Ngayon at susunod** -- Ano ang pinapatugtog ngayon at hanggang kailan, kasunod ng lahat ng naka-schedule para sa susunod na 7 araw. I-click ang **Buksan ang kalendaryo** para pumunta sa kalendaryo ng group na ito
- **Mga Download** -- **Handa hanggang** ng isang petsa kapag nadownload na ang lahat, o listahan ng mga file na nawawala
- **Device** -- Device ID, platform, modelo, bersyon ng FreePlay app, IP address, storage na nagamit at natitira, huling check-in, at mode
- **Kamakailan** -- Ang pinakabagong aktibidad na iniulat ng screen

:::tip
Kung may nawawalang file ang isang screen, siguraduhing online ito at may natitirang storage. Idodownload ng TV ang mga nawawalang file nang kusa sa susunod nitong pag-check in.
:::

## Pag-edit ng Screen

1. I-click ang **I-edit** sa tabi ng screen, o sa pahina nito.
2. Baguhin ang **Label**, **Group**, o **Mode** (**Naka-iskedyul** o **Manual**).
3. I-click ang **I-save**.

Kapag inilipat ang screen sa ibang group, lilipat ito sa kalendaryo ng group na iyon.

## Mga Screen Group {#screen-groups}

Ang screen group ay isang set ng mga screen na nagpapatugtog ng parehong bagay sa parehong oras, gaya ng "Lobby" o "Kids Wing". May sariling kalendaryo ang bawat group at maaaring magkaroon ng **default loop** na tumatakbo kapag walang naka-schedule.

Para pamahalaan ang mga group, i-click ang **Mga Group** sa itaas ng pahinang **Mga Screen**. Ipinapakita ng listahang **Mga screen group** ang pangalan ng bawat group, kung ilang screen ang nasa loob nito, at ang default loop nito. I-click ang **Mga Screen** para bumalik.

### Pagdagdag ng Group

1. Sa view na **Mga screen group**, i-click ang **Magdagdag ng group**.
2. Ilagay ang **Pangalan**, halimbawa "Lobby".
3. Pumili ng playlist para sa **Default loop**, o iwan sa **Wala — mamamatay ang screen**.
4. I-click ang **I-save**.

Maaari ka ring gumawa ng group habang nagpa-pair ng screen sa pamamagitan ng pagpili ng **＋ New group…** sa field na **Group**.

### Pag-edit o Pagbura ng Group

1. I-click ang **I-edit** sa tabi ng group.
2. Baguhin ang pangalan o default loop, pagkatapos i-click ang **I-save**.
3. Para alisin ang group, i-click ang **Burahin** at kumpirmahin.

:::warning
Kapag binura ang isang group, mabubura rin ang schedule nito. Mamamatay ang mga screen sa group na iyon hanggang ilipat mo sila sa ibang group.
:::
