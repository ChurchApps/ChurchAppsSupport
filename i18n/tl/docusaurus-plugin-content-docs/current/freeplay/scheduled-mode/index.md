# Scheduled Mode

<div class="article-intro">

Hinahayaan ka ng Scheduled Mode na patakbuhin ang isang FreePlay TV nang mag-isa. Gumagawa ka ng mga playlist at inilalagay ang mga ito sa kalendaryo sa **FreePlay Admin** sa [admin.freeplay.church](https://admin.freeplay.church). Dina-download ng bawat TV na nakapareha sa kalendaryong iyon ang susunod na isang linggo at pinapatugtog ang anumang naka-iskedyul, ayon sa orasan, nang walang pumipindot ng Start. Dahil na-download na ang mga file, tuloy-tuloy ang pag-playback kahit mawala ang Wi-Fi.

</div>

:::tip
Ginagamit ng FreePlay Admin ang iyong ChurchApps login, ang parehong ginagamit mo sa B1 Admin. Walang hiwalay na account na kailangang gawin.
:::

## Paano Ito Nagkakasama-sama

Apat na pangunahing pahina ang FreePlay Admin, nakalista sa itaas ng site:

- **[Screens](./managing-screens)** -- Ang mga TV na iyong ipinares, ang kanilang status, at ang **screen groups** na kinabibilangan ng mga ito. Ang mga screen sa isang grupo ay nagbabahagi ng iisang kalendaryo at iisang default loop
- **[Playlists](./building-playlists)** -- Mga loop ng mga larawan at video na pinipili mo mula sa iyong content providers
- **[Calendar](./scheduling-the-calendar)** -- Kung ano ang pinapatugtog ng bawat screen group, at kailan
- **[Providers](./building-playlists#connecting-providers)** -- Ang mga pinagmumulan ng content na ginagamit ng iyong mga playlist. Ikinokonekta mo ang bawat isa nang isang beses para sa buong simbahan

Kapag walang naka-iskedyul, pinapatugtog ng mga screen ng isang grupo ang **default loop** nito. Kung walang default loop ang grupo, papatayin ang mga screen.

## Paano Ito Naiiba sa Plan Mode

- **[Plan Mode](../plan-mode/)** ay sumusunod sa isang uri ng service plan mula sa B1 Admin. Pinipindot ng isang tao ang **Start Plan** sa TV, at tumutugtog ang lesson kapag ginawa nila ito
- **Scheduled Mode** ay sumusunod sa isang kalendaryo. Nagsisimula at humihinto ang content sa mga oras na itinakda mo, kaya mainam ito para sa lobby signage, announcement loop, at mga classroom kung saan dapat nakabukas na ang lesson bago pa pumasok ang sinuman

Puwede pa ring magpatugtog ng service plan ang isang entry sa kalendaryo. Piliin ang plan type sa ilalim ng **Service plans** kapag nagdagdag ka ng schedule, at patutugtugin ng screen ang anumang plan na kasalukuyan sa B1 Admin sa linggong iyon.

## Pagsisimula

Hangga't hindi mo pa nagagawa ang bawat isa sa mga ito, magpapakita ang pahinang **Screens** ng checklist na **Get started** na may link para sa bawat hakbang:

1. **Connect a provider** -- Ikonekta ang Dropbox, OneDrive, Lessons.church, o ibang pinagmulan sa pahinang **Providers**
2. **Build a playlist** -- Pumili ng mga larawan at video mula sa isang provider
3. **Put it on the calendar** -- Piliin kung ano ang tutugtog at kailan, o magtakda ng default loop para sa grupo
4. **Pair a screen** -- Ilagay ang apat na letter na code na ipinapakita sa TV

I-click ang **Hide** para itago ang checklist.

:::tip
Pindutin ang **Ctrl+K** (**⌘K** sa Mac), o i-click ang search box sa header, para buksan ang command palette. Mula roon, makakapunta ka sa anumang pahina o makakapagsimula ng aksyon tulad ng **Pair screen**, **Add playlist**, o **Add schedule**.
:::
