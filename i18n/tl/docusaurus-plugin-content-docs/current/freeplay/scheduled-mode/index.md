# Scheduled Mode

<div class="article-intro">

Hinahayaan ng Scheduled Mode na tumakbo nang kusa ang isang FreePlay TV. Gumagawa ka ng mga playlist at inilalagay ang mga ito sa kalendaryo sa **FreePlay Admin** sa [admin.freeplay.church](https://admin.freeplay.church). Dina-download ng bawat TV na nakapares sa kalendaryong iyon ang susunod na linggo at pinapatugtog kung ano ang nakaiskedyul, ayon sa orasan, nang walang pumipindot ng Start. Dahil nakadownload na ang mga file, tuloy-tuloy ang pag-playback kahit mawala ang Wi-Fi.

</div>

:::tip
Ginagamit ng FreePlay Admin ang iyong ChurchApps login, ang parehong ginagamit mo sa B1 Admin. Walang hiwalay na account na kailangang gawin.
:::

## Paano Ito Nagkakasama-sama

May apat na pangunahing pahina ang FreePlay Admin, nakalista sa itaas ng site:

- **[Screens](./managing-screens)** - Ang mga TV na napares mo, ang kanilang status, at ang **screen group** na kinabibilangan ng mga ito. Ang mga screen sa isang grupo ay nagbabahagi ng iisang kalendaryo at iisang default loop
- **[Playlists](./building-playlists)** - Mga loop ng larawan at video na pinipili mo mula sa iyong content provider
- **[Calendar](./scheduling-the-calendar)** - Kung ano ang pinapatugtog ng bawat screen group, at kailan
- **[Providers](./building-playlists#connecting-providers)** - Ang mga content source na kinukuha ng iyong mga playlist. Ikinokonekta mo ang bawat isa nang isang beses para sa buong simbahan

Kapag walang nakaiskedyul, pinapatugtog ng mga screen ng isang grupo ang **default loop** nito. Kapag walang default loop ang grupo, papatayin ang mga screen.

## Paano Ito Naiiba sa Plan Mode

- **[Plan Mode](../plan-mode/)** ay sumusunod sa isang service plan type mula sa B1 Admin. Pinipindot ng isang tao ang **Start Plan** sa TV, at tumutugtog ang lesson kapag pinindot nila ito
- **Scheduled Mode** ay sumusunod sa isang kalendaryo. Nagsisimula at humihinto ang content sa mga oras na itinakda mo, kaya mainam ito para sa lobby signage, announcement loop, at mga classroom kung saan dapat nakalabas na ang lesson bago pa pumasok ang sinuman

Maaari pa ring magpatugtog ng service plan ang isang entry sa kalendaryo. Piliin ang plan type sa ilalim ng **Service plans** kapag nagdaragdag ka ng schedule, at ipapatugtog ng screen ang anumang plan na kasalukuyan sa B1 Admin sa linggong iyon. Kasama rito ang mga aralin ng Go Curriculum, kahit ang mga na-customize mo sa plan. Ginagamit ng screen ang Go Curriculum login na naka-link sa ministry ng plan type sa B1 Admin, o ang Go Curriculum connection ng simbahan kung walang ministry na nakatakda.

## Pagsisimula

Hangga't hindi mo pa natatapos ang bawat isa sa mga ito, magpapakita ang pahinang **Screens** ng **Get started** na checklist na may link para sa bawat hakbang:

1. **Ikonekta ang isang provider** - I-link ang Dropbox, OneDrive, Lessons.church, o ibang source sa pahinang **Providers**
2. **Gumawa ng playlist** - Pumili ng mga larawan at video mula sa isang provider
3. **Ilagay sa kalendaryo** - Piliin kung ano ang tutugtog at kailan, o magtakda ng default loop para sa grupo
4. **Ipares ang isang screen** - Ilagay ang apat na letrang code na lumalabas sa TV

I-click ang **Hide** para itago ang checklist.

:::tip
Pindutin ang **Ctrl+K** (**⌘K** sa Mac), o i-click ang search box sa header, para buksan ang command palette. Mula roon, maaari kang tumalon sa anumang pahina o magsimula ng aksyon tulad ng **Pair screen**, **Add playlist**, o **Add schedule**.
:::
