# Pagkonekta ng Provider at Pagbuo ng Playlist

<div class="article-intro">

Ang playlist ay isang loop ng mga larawan at video na inilalagay mo sa kalendaryo. Sa FreePlay Admin, ikokonekta mo nang minsan ang iyong mga content provider para sa buong simbahan. Pagkatapos, bubuo ka ng mga playlist sa pamamagitan ng pagpili ng mga file mula sa mga provider na iyon.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Mag-sign in sa FreePlay Admin sa [admin.freeplay.church](https://admin.freeplay.church)
- Magkaroon ng login para sa anumang account ng provider na nais mong ikonekta, gaya ng Dropbox o OneDrive

</div>

## Pagkonekta ng Mga Provider {#connecting-providers}

Nakalista sa pahinang **Providers** ang iyong mga pinagmumulan ng content sa dalawang seksyon:

- **Connected** - Mga provider na maaari mong gamitin ngayon. Ang mga pampublikong provider na hindi nangangailangan ng sign-in, gaya ng Lessons.church at Bible Project, ay laging nakalista rito bilang **Public · no sign-in needed**. Ang mga naka-link na account ay nagpapakita ng **Account linked** at kung kailan mag-e-expire ang link.
- **Available** - Mga provider na kailangan mo munang mag-sign in bago magamit.

Para ikonekta ang isang provider:

1. Pumunta sa **Providers**.
2. Hanapin ang provider sa ilalim ng **Available** at i-click ang **Connect**.
3. Mag-sign in sa iyong account sa provider na iyon:
   - May ilang provider, gaya ng Dropbox, Google Drive, at OneDrive, na nagbubukas ng sign-in popup. Kung walang lumabas, payagan ang mga popup para sa admin.freeplay.church.
   - May ibang provider na nagpapakita ng link at code. Bisitahin ang link, ilagay ang code, at aprubahan ang access. Kusang nag-a-update ang dialog kapag tapos ka na.
4. Kapag nakita mo ang **Account linked successfully!**, lilipat ang provider sa **Connected**.

Tatlong aksyon ang available para sa mga naka-connect na provider:

- **Browse** - Tingnan ang mga folder ng provider
- **Refresh** - I-renew ang sign-in ng provider
- **Unlink** - Idiskonekta ang account

:::info
Ang mga koneksyon ng provider sa FreePlay Admin ay pag-aari ng buong simbahan, hindi ng isang tao o isang TV lamang. Nakukuha ng mga naka-iskedyul na screen ang kanilang mga file sa pamamagitan ng mga koneksyong ito, kaya hindi mo kailangang mag-sign in sa bawat provider sa bawat TV.
:::

Ang **FreeShow** ay nakalista bilang **On your church network · each TV finds it itself**. Walang kailangang ikonekta para dito sa FreePlay Admin.

## Ang Pahina ng Mga Playlist

Ipinapakita ng pahinang **Playlists** ang bawat playlist kasama ang bilang ng item nito, kabuuang tagal, saan ito ginagamit (**Default loop** para sa isang grupo, o ang bilang ng mga schedule), at kung kailan ito huling na-update. Ang bawat hilera ay may mga aksyon na ito:

- **Present** - I-play ang playlist nang full screen sa iyong browser
- **Edit** - Buksan ang editor ng playlist
- **Duplicate** - Gumawa ng kopya na may pangalang "(copy)"

## Paggawa ng Playlist

1. Pumunta sa **Playlists** at i-click ang **Add playlist**.
2. Maglagay ng **Name**, halimbawa "Welcome loop".
3. I-click ang **Add playlist**. Bubukas ang editor ng playlist.

## Pagdaragdag ng Mga Item

Ipinapakita ng editor ng playlist ang **Items** ng iyong playlist sa kaliwa at ang **Add from provider** sa kanan.

1. Sa kanan, pumili ng tab ng provider. Para magdagdag ng isa pang pinagmulan, i-click ang **Connect another**, na magbubukas sa pahinang **Providers**.
2. I-click ang mga folder para pumasok sa loob. Gamitin ang breadcrumb trail para bumalik paitaas.
3. I-click ang isang file para idagdag ito sa dulo ng playlist. Ang mga file na nasa playlist na ay minamarkahang napili.
4. Para idagdag ang lahat ng nasa kasalukuyang folder nang sabay-sabay, i-click ang **Add all**. Ipinapakita ng button kung ilang file ang wala pa sa playlist.
5. I-click ang **Save** sa itaas ng editor.

:::warning
Hindi nase-save ang mga pagbabago hangga't hindi mo i-click ang **Save**. I-click ang **Cancel** para umalis nang hindi nagse-save.
:::

## Pag-aayos ng Mga Item

Sa listahan ng **Items** sa kaliwa:

- **Reorder** - I-drag ang item sa pamamagitan ng handle nito sa kaliwa
- **Image timing** - Ipinapakita ang mga larawan nang 10 segundo bilang default. Palitan ang bilang ng segundo sa tabi ng larawan
- **Videos** - Ipinapakita ng mga video ang **Plays to end** at tumatakbo sa buong haba nila
- **Remove** - Alisin ang isang item sa playlist

Ipinapakita ng buod sa itaas ang bilang ng mga item at ang kabuuang haba ng playlist.

## Pagpapalit ng Pangalan, Pagkopya, at Pagbura

Ipinapakita ng panel sa kaliwang bahagi ng editor kung saan ginagamit ang playlist. Mayroon din itong mga aksyong ito:

- **Present** - I-play ang playlist sa iyong browser
- **Rename** - Palitan ang pangalan ng playlist
- **Duplicate** - Gumawa ng kopya para i-edit nang hiwalay
- **Delete** - Alisin ang playlist. Ang mga schedule na nagpe-play nito ay babalik sa default loop ng grupo

## Pag-present ng Playlist sa Iyong Browser

I-click ang **Present** para i-play ang playlist nang full screen sa iyong browser. Kapaki-pakinabang ito para sa pag-preview ng playlist, o para patakbuhin ito mula sa laptop na nakakonekta sa projector. Igalaw ang mouse para ipakita ang control bar, pagkatapos ay gamitin ang mga key na ito:

| Key | Aksyon |
|---|---|
| **Espasyo** | I-pause o ipagpatuloy |
| **←** / **→** | Nakaraan o susunod na item |
| **F** | I-toggle ang fullscreen |
| **Esc** | Lumabas |
