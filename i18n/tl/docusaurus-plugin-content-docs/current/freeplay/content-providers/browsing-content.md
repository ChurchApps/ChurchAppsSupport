# Pag-browse at Pag-download ng Nilalaman

<div class="article-intro">

Kapag nakakonekta ka na sa isang content provider, maaari mong i-browse ang library nito, mag-download ng mga file, at i-play ang mga ito sa TV mo. Ang content browser ay nagbibigay ng visual na grid ng mga folder at file na nina-navigate mo gamit ang TV remote mo.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kumonekta sa kahit isang content provider -- tingnan ang [Pagkonekta sa mga Provider](./connecting-providers.md)
- Ihanda ang TV remote mo para sa navigation

</div>

## Ang Content Browser

Ipinapakita ng content browser ang mga item sa isang grid na may 3 column ng mga card. Ang bawat card ay may thumbnail na larawan at pamagat. May dalawang uri ng item:

- **Mga Folder** - Kinakatawan ng thumbnail o folder icon. Piliin ang folder para makita ang laman nito.
- **Mga File** - Mga indibidwal na media item (video o larawan). Ang mga video file ay may play icon sa ibabaw ng thumbnail nila.

Ang header sa itaas ng screen ay nagpapakita ng pangalan ng kasalukuyang folder, o ang pangalan ng provider kung nasa root level ka.

## Pag-navigate sa mga Folder

1. Gamitin ang directional pad ng remote mo para i-highlight ang isang folder
2. Pindutin ang **Select** para buksan ito
3. Ilo-load ng browser ang laman ng folder, na maaaring mga folder pa o mga file na maaaring i-play
4. Pindutin ang **Back** sa remote mo para bumalik sa nakaraang level

Maaari kang mag-drill nang kasing-lalim ng pinapayagan ng istruktura ng content ng provider. Sinusubaybayan ng browser ang folder path mo para makabalik ka sa bawat level.

## Pag-browse sa Lessons.church

Ang library ng [Lessons.church](../../lessons-church/index.md) ay nakaayos gaya ng website nito. Sa top level, makikita mo ang dalawang folder:

- **Lessons** - Mag-drill in ayon sa **program**, pagkatapos ay **study**, pagkatapos ay **lesson**. Ang bawat lesson ay naglilista ng mga **venue** nito, na mga bersyon ng lesson para sa partikular na age group o setting, gaya ng Preschool o Elementary. Piliin ang venue para buksan ang download screen ng bersyong iyon ng lesson.
- **Add-Ons** - Mga karagdagang video at resource, nakapangkat ayon sa kategorya

Pindutin ang **Back** sa anumang level para umakyat ng isang hakbang.

## Pag-browse sa Go Curriculum

Pagkatapos mong [mag-sign in gamit ang account mo sa gocurriculum.com](./connecting-providers.md#phone-sign-in-qr-code-only), magbubukas ang Go Curriculum sa mga age group nito, ang **Elementary** at **Preschool**. Mag-drill in ayon sa age group, pagkatapos ay collection, pagkatapos ay lesson, at piliin ang lesson para buksan ang download screen nito.

Ang makikita mo ay nakadepende sa Go membership mo:

- Ang mga age group lang na sakop ng membership mo ang nakalista. Kung walang Go membership ang login mo, walang laman ang library.
- May ilang video na para lang sa ilang membership level. Ang mga video na hindi kasama sa membership mo ay hindi isasama sa lesson.

## Pag-download at Pag-play ng Nilalaman

Kapag pumili ka ng folder na may mga file na maaaring i-play (o pumili ng indibidwal na file), ipapakita ng FreePlay ang pamagat ng content kasama ang cover image at dalawang pagpipilian:

- **Download** - I-save muna ang lahat ng file sa TV para hindi nakadepende ang playback sa Wi-Fi. Mapupuno ang progress bar habang sine-save ang bawat file. Kapag tapos na, lalabas ang **Start** button na may play icon. Pindutin ang **Select** para simulan ang playback.
- **Stream** - Magsimulang mag-play agad sa internet nang hindi sine-save ang mga file.

:::tip
I-download ang mga lesson bago ang Linggo ng umaga habang may malakas na internet connection ang gusali ninyo. Kapag na-download na, maaaring i-play ang content offline, at kung i-play mo ulit ito sa susunod, agad itong magla-load nang hindi na muling mag-download.
:::

## Pamamahala ng mga Download

Buksan ang **Settings** sa ibaba ng sidebar, pagkatapos ay piliin ang **Downloads** para makita ang lahat ng naka-save sa TV na ito:

- Piliin ang isang download para i-play ito
- I-highlight ang isang download at piliin ang delete icon sa sulok nito para tanggalin ito at magbakante ng storage

Kung ang screen ay nagsasabing **No downloads yet**, walang naka-save sa TV na ito.

## Pag-play ng Content ng Provider

Gamitin ang mga kontrol na ito habang nagpe-playback:

- **Right arrow** - Susunod na item
- **Left arrow** - Nakaraang item
- **Select / Play-Pause** - I-pause o ipagpatuloy ang video
- **Up arrow** - Buksan ang message selector para tumalon sa partikular na item
- **Back** - Lumabas at bumalik sa content browser

Kapag lumabas ka sa player, babalik ka sa content browser sa root level ng kasalukuyang provider.

:::info
Para sa kumpletong sanggunian ng lahat ng kontrol ng player, tingnan ang [Pag-play ng Nilalaman](./playing-content.md).
:::

## Paglipat sa Pagitan ng mga Provider

Lumalabas ang mga nakakonektang provider bilang mga item sa ilalim ng heading na **Browse** sa kaliwang sidebar. Para lumipat sa ibang provider:

1. Pindutin ang **Left** arrow sa remote mo para i-expand ang sidebar
2. Piliin ang provider na gusto mong i-browse
3. Magre-refresh ang content browser at ipapakita ang library ng provider na iyon

:::warning
Kung nagpapakita ang folder ng "No content available," walang item ang provider sa level na iyon. Subukang mag-navigate sa ibang folder o bumalik na lang mamaya.
:::
