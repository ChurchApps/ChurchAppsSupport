# Mga Anunsyo

<div class="article-intro">

Maaaring i-loop ng FreePlay ang isang folder ng slide ng anunsyo sa TV mo -- halimbawa, sa lobby o bago magsimula ang klase. Pumipili ka ng folder mula sa isa sa mga nakakonektang content provider mo, dina-download ng FreePlay ang mga slide nito sa device, at lumilitaw ang item na **Announcements** sa sidebar para masimulan mo ang loop anumang oras.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- [Kumonekta sa content provider](./connecting-providers) na naglalaman ng mga slide ng anunsyo mo, gaya ng Dropbox o OneDrive
- Ilagay ang mga larawan o video na gusto mong i-loop sa iisang folder sa provider na iyon

</div>

## Pagpili ng Folder ng mga Anunsyo

1. Buksan ang **Settings** mula sa ibaba ng sidebar, pagkatapos piliin ang **Providers**
2. Piliin ang nakakonektang provider na naglalaman ng mga slide mo (may badge na **Connected**) para buksan ang **Provider Settings** nito
3. Piliin ang **Use for Announcements**
4. Bubukas ang browser na **Choose the Announcements Folder**. Lumipat sa mga folder hanggang sa marating ang may mga slide mo, pagkatapos piliin ang folder na iyon (o anumang file sa loob nito)
5. Dina-download ng FreePlay ang mga slide at bumabalik sa **Provider Settings**, kung saan nagbabasa na ang row ng **Looping "*pangalan ng folder*" -- *bilang* na slide ang na-download**

Isang folder lang ang ginagamit para sa mga anunsyo sa isang pagkakataon. Ang pagpili ng folder mula sa ibang provider ay papalitan ang nauna.

## Pag-play ng mga Anunsyo

Kapag na-download na ang mga slide, lumilitaw ang item na **Announcements** malapit sa itaas ng sidebar (sa ilalim ng **Today's Plan**, kung ipinapakita ito ng TV mo). Piliin ito para simulan ang loop.

- Nananatili sa screen ang mga larawan nang 15 segundo maliban kung ang provider ay nagbigay sa file ng sarili nitong tagal
- Nagpe-play ang mga video hanggang sa dulo bago lumipat sa susunod na slide
- Pagkatapos ng huling slide, magsisimula muli ang loop sa una
- Kung iisang video lang ang folder, paulit-ulit itong mag-p-play sa parehong lugar

Nagpe-play ang loop mula sa mga file na naka-save sa device, kaya tuloy-tuloy itong tumatakbo kahit walang internet connection. Maaari mong gamitin ang parehong remote control gaya ng ibang content -- tingnan ang [Playing Content](./playing-content).

## Pag-update ng mga Slide

Tinitingnan ng FreePlay ang folder ng mga anunsyo sa tuwing magsisimula ang app, nagda-download ng anumang bagong slide, at inaalis ang mga slide na binura sa folder.

Para tingnan kaagad, buksan ang **Provider Settings** ng provider at piliin ang **Check for Announcement Updates**. Ipinapakita ng row ang **Up to date** kasama ang bilang ng slide kapag natapos ito.

:::info
Kung hindi maabot ng FreePlay ang provider, o walang laman ang folder, ipagpapatuloy nito ang pag-play ng mga slide na mayroon na ito. Para itigil nang tuluyan ang paggamit ng mga anunsyo, i-off ang mga ito gaya ng nakasaad sa ibaba.
:::

:::warning
Ang slide na pinalitan ng bagong bersyon sa ilalim ng parehong file ay hindi na muling dina-download. Para baguhin ang isang slide, idagdag ito bilang bagong file at burahin ang luma.
:::

## Pag-off ng mga Anunsyo

Buksan ang **Provider Settings** ng provider at piliin muli ang **Use for Announcements**. Ititigil ng FreePlay ang paggamit ng folder, buburahin ang mga na-download na slide sa device, at aalisin ang **Announcements** sa sidebar.

Ang pag-disconnect sa provider ay nag-o-off din ng mga anunsyong galing dito.
