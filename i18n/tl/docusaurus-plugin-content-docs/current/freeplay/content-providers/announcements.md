# Mga Anunsyo

<div class="article-intro">

Kayang i-loop ng FreePlay ang isang folder ng mga slide ng anunsyo sa inyong TV -- halimbawa, sa lobby o bago magsimula ang klase. Pipili kayo ng folder mula sa isa sa inyong mga nakakonektang content provider, dadownload ng FreePlay ang mga slide nito sa device, at lalabas ang item na **Announcements** sa sidebar para masimulan ninyo ang loop anumang oras.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- [Kumonekta sa isang content provider](./connecting-providers) na naglalaman ng inyong mga slide ng anunsyo, tulad ng Google Drive o Dropbox
- Ilagay sa iisang folder sa provider na iyon ang mga larawan o video na gusto ninyong i-loop

</div>

## Pagpili ng Folder para sa Announcements

1. Buksan ang **Settings** mula sa ibaba ng sidebar, pagkatapos ay piliin ang **Providers**
2. Piliin ang nakakonektang provider na naglalaman ng inyong mga slide (may badge itong **Connected**) para buksan ang **Provider Settings** nito
3. Piliin ang **Use for Announcements**
4. Magbubukas ang browser na **Choose the Announcements Folder**. Dumaan sa mga folder hanggang makarating sa folder na may inyong mga slide, saka piliin ang folder na iyon (o anumang file sa loob nito)
5. Dina-download ng FreePlay ang mga slide at bumabalik sa **Provider Settings**, kung saan ang hilera ay mababasa na ngayong **Looping "*pangalan ng folder*" -- *bilang* slides downloaded**

Iisang folder lang ang ginagamit para sa announcements sa bawat pagkakataon. Ang pagpili ng folder mula sa ibang provider ay papalit sa dating folder.

## Pag-play ng mga Announcement

Kapag na-download na ang mga slide, lalabas ang item na **Announcements** malapit sa itaas ng sidebar (sa ibaba ng **Today's Plan**, kung ipinapakita ito ng inyong TV). Piliin ito para simulan ang loop.

- Nananatili ang mga larawan sa screen nang 15 segundo maliban kung bigyan ng provider ang file ng sarili nitong tagal
- Pini-play ang mga video hanggang sa dulo bago lumipat sa susunod na slide
- Pagkatapos ng huling slide, magsisimula muli ang loop mula sa una
- Kung iisang video lang ang nasa folder, uulit-ulitin ito sa mismong lugar

Pini-play ang loop mula sa mga file na naka-save sa device, kaya patuloy itong tumatakbo kahit walang internet. Magagamit ninyo ang parehong mga remote control tulad ng sa iba pang nilalaman -- tingnan ang [Pag-play ng mga Leksyon](../classroom-mode/playing-lessons).

## Pag-update ng mga Slide

Tinitingnan ng FreePlay ang folder ng announcements sa bawat pagsisimula ng app, dina-download ang anumang bagong slide, at inaalis ang mga slide na na-delete mula sa folder.

Para tingnan agad, buksan ang **Provider Settings** ng provider at piliin ang **Check for Announcement Updates**. Ipapakita ng hilera ang **Up to date** kasama ang bilang ng slide kapag natapos na ito.

:::info
Kung hindi maabot ng FreePlay ang provider, o walang laman ang folder na lumabas, patuloy nitong ipe-play ang mga slide na mayroon na ito. Para tuluyang ihinto ang paggamit ng announcements, i-off ang mga ito ayon sa nakasaad sa ibaba.
:::

:::warning
Ang slide na pinalitan ng bagong bersyon sa ilalim ng parehong file ay hindi na muling dina-download. Para baguhin ang isang slide, idagdag ito bilang bagong file at i-delete ang luma.
:::

## Pag-off ng Announcements

Buksan ang **Provider Settings** ng provider at piliin muli ang **Use for Announcements**. Titigil ang FreePlay sa paggamit ng folder, buburahin nito sa device ang mga na-download na slide, at aalisin ang **Announcements** sa sidebar.

Ang pag-disconnect sa provider ay nag-o-off din ng announcements na nagmula rito.
