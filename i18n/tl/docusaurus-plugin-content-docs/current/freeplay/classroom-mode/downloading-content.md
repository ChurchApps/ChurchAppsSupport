# Pag-download ng Nilalaman ng Aralin

<div class="article-intro">

Kapag napili mo na ang simbahan at classroom, awtomatikong kukunin ng FreePlay ang aralin na naka-iskedyul para sa araw na ito at sisimulang i-download ang lahat ng media file nito. Sa screen na ito ka maghihintay hanggang handa na ang nilalaman bago simulan ang aralin.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Piliin ang iyong simbahan at classroom -- tingnan ang [Pagpili ng Iyong Simbahan at Silid](./selecting-room)
- Siguraduhing nakakonekta sa internet ang iyong TV para sa unang download

</div>

## Paano Gumagana ang Pag-download

1. Sinusuri ng FreePlay ang iskedyul ng iyong classroom at nilo-load ang nakatalagang aralin
2. Lumalabas sa screen ang pangalan, pamagat, at paglalarawan ng aralin, nakapatong sa cover image ng aralin
3. Ipinapakita ng progress indicator ang **Downloading item X of Y** habang sine-save ang bawat file sa device
4. Kapag na-download na ang lahat ng file, lalabas ang button na **Start Lesson** na may play icon

Wala kang kailangang gawin habang nagda-download. Awtomatikong hinahawakan ng FreePlay ang lahat.

## Resolution

Nagda-download ang FreePlay ng nilalaman sa 720p bilang default. Ang resolution setting (720p o 1080p) ang nagtatakda ng kalidad ng mga na-download na video at image file. Mas malinaw ang mas mataas na resolution sa malalaking TV pero mas matagal i-download at mas malaki ang gamit na storage.

:::info
Naka-set sa 720p ang resolution bilang default. Dina-download ang nilalaman sa resolution na naka-configure para sa iyong device.
:::

## Pagsisimula ng Aralin

Kapag tapos na ang pag-download, unti-unting lalabas ang button na **Start Lesson** sa ibaba ng screen. Gamitin ang TV remote para i-highlight ito at pindutin ang **Select** para simulan ang playback.

## Awtomatikong Pag-refresh

Sinusuri ng FreePlay kung may bagong nilalaman bawat oras. Kung magbago ang iskedyul sa loob ng araw, awtomatikong kukunin ng app ang bagong aralin. Maaari mo ring pindutin ang **Back** sa remote para bumalik sa screen ng pagpili ng silid at pumasok muli sa download screen para pilitin ang refresh.

:::tip
I-download ang mga aralin bago ang umaga ng Linggo habang malakas ang internet connection ng inyong gusali. Kapag na-download na, tumutugtog ang nilalaman nang offline at hindi na umaasa sa network.
:::

## Downloads Screen

May **Downloads** screen ang FreePlay kung saan makikita at mapapamahalaan mo ang lahat ng nilalamang na-download sa device. Buksan ang **Settings** sa ibaba ng sidebar, pagkatapos ay piliin ang **Downloads**. Dito mo makikita kung ano ang nakaimbak sa device at handa para sa offline playback. Gamitin ang Downloads screen para tiyaking ganap na na-download ang mga aralin bago ang umaga ng Linggo o para magbakante ng storage sa pamamagitan ng pagtanggal ng lumang nilalaman.

## Kung Walang Laman ang Iskedyul

Kung walang aralin na naka-iskedyul para sa napiling classroom, makikita mo ang mensaheng "The schedule could not be loaded. Make sure a lesson is scheduled for this class." Tingnan ang iyong iskedyul sa [freeplay.church](https://freeplay.church) at siguraduhing tama ang aralin na nakatalaga sa silid na ito.
