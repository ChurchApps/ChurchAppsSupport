# Pangangasiwa

<div class="article-intro">

Ang admin area sa Lessons.church ay kung saan pinamamahalaan ng mga tagalikha ng nilalaman at mga administrador ang aklatan ng mga leksyon. Mula rito, maaari mong buuin ang istruktura ng iyong kurikulum, mag-upload ng mga mapagkukunan, suriin ang mga estadistika ng paggamit, at ikonekta ang mga third-party na tagapagbigay ng nilalaman.

</div>

:::warning
Ang pag-access sa admin ay nangangailangan ng naaangkop na pahintulot. Kung hindi mo makita ang mga opsyon ng admin, makipag-ugnayan sa administrador ng iyong simbahan upang humiling ng access.
:::

## Ano ang Maaari Mong Gawin

Ang admin area ay nagbibigay sa iyo ng buong kontrol sa iyong nilalaman:

- **Gumawa at mag-edit ng mga programa** -- Mag-set up ng mga serye ng kurikulum sa pinakamataas na antas, na may mga pangalan, paglalarawan, larawan, at slug.
- **Pamahalaan ang mga pag-aaral** -- Ayusin ang mga grupo ng magkakaugnay na leksyon sa loob ng bawat programa.
- **Bumuo ng mga leksyon** -- Magdagdag ng mga indibidwal na leksyon na may mga venue, seksyon, tungkulin, at aksyon.
- **Mag-upload ng mga mapagkukunan** -- Maglakip ng mga file na maaaring i-download (PDF, activity sheet, larawan) sa antas ng programa, pag-aaral, o leksyon.
- **Tingnan ang mga estadistika** -- Tingnan kung aling nilalaman ang dina-download, ng sino, at saan.
- **I-configure ang mga provider** -- Ikonekta ang mga panlabas na tagapagbigay ng kurikulum na gumagamit ng Open Lesson Format. Ginagawa ito mula sa pahinang **External Providers**, hindi sa admin area.
- **Mga plano ng taon** -- Mag-publish ng mga pagkakasunod-sunod na Linggo 1, 2, 3… para sa anumang kurikulum. Ginagamit ito ng mga simbahan sa B1 Admin.

## Istruktura ng Nilalaman

Bilang admin, makakatulong na maunawaan kung paano nakaayos ang nilalaman:

1. **Ang mga programa** ay naglalaman ng isa o higit pang pag-aaral.
2. **Ang mga pag-aaral** ay naglalaman ng isa o higit pang leksyon.
3. **Ang mga leksyon** ay naglalaman ng isa o higit pang venue (mga pagkakaiba ayon sa pangkat-edad).
4. **Ang mga venue** ay naglalaman ng mga seksyon, at ang mga seksyon ay naglalaman ng mga aksyong nakabatay sa tungkulin.

Maaaring maglakip ng sarili nitong mga mapagkukunang maaaring i-download ang bawat antas.
