# Mga Third-Party Provider

<div class="article-intro">

Sinusuportahan ng Lessons.church ang mga external na curriculum provider sa pamamagitan ng Open Lesson Format. Ibig sabihin, maaaring ikonekta ng iyong simbahan ang curriculum mula sa ibang mga organisasyon at iiskedyul ito para sa iyong mga classroom, katabi ng built-in na library, para magkaroon ang iyong team ng curriculum mula sa maraming pinagmulan sa iisang lugar.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Mag-log in sa Lessons.church gamit ang account na may kakayahang mamahala ng mga iskedyul ng classroom ng iyong simbahan
- Kunin ang feed URL mula sa external provider na nais mong ikonekta. Dapat itong magbalik ng mga aralin sa [Open Lesson Format](./open-lesson-format.md)

</div>

## Pagdaragdag ng Provider

1. I-click ang **External Providers** sa navigation ng Lessons.church. Magbubukas ang pahinang **External Lesson Providers**.
2. I-click ang **Add Provider**. Kung wala ka pang naidadagdag na provider, i-click na lang ang **Add First Provider**.
3. Ilagay ang **Provider Name**. Ito ang pangalang makikita ng iyong team kapag pumipili ng provider.
4. Ilagay ang **API URL**. Ito ang address kung saan inilalathala ng provider ang kanilang curriculum sa Open Lesson Format.
5. I-click ang **Save**.

Ang provider ay idinadagdag para lamang sa iyong simbahan. Lilitaw ito bilang pagpipilian sa ilalim ng **Provider** kapag [nag-iskedyul ka ng aralin](../classrooms/scheduling-lessons.md) para sa isang classroom, at sa ilalim ng **Source** kapag bumubuo ka ng [year plan](./managing-year-plans.md).

## Pamamahala ng mga Provider

Nakalista sa pahinang **External Lesson Providers** ang bawat provider na naidagdag ng iyong simbahan. Para baguhin ang isa:

- **I-edit** -- I-click ang icon na **Edit provider** (lapis), baguhin ang **Provider Name** o **API URL**, pagkatapos ay i-click ang **Save**.
- **Burahin** -- I-click ang icon na **Edit provider**, pagkatapos ay i-click ang icon na delete (basurahan) at kumpirmahin.

## Ano ang Open Lesson Format?

Ang Open Lesson Format ay isang standardized na schema na naglalarawan ng nilalaman ng curriculum -- mga programa, pag-aaral, aralin, venue, seksyon, at aksyon -- sa isang estrukturadong paraan. Anumang organisasyong naglalathala ng kanilang nilalaman gamit ang format na ito ay maaaring idagdag bilang provider sa Lessons.church.

Kung ikaw ay content provider na interesadong gawing available ang iyong curriculum sa pamamagitan ng Lessons.church, makikita mo ang buong dokumentasyon ng schema sa gabay na [Open Lesson Format](./open-lesson-format.md).

## Bakit Gumamit ng Third-Party Provider?

- **Mas maraming pagpipilian para sa mga simbahan** -- Makakapag-browse ang mga simbahan ng mas malawak na uri ng curriculum nang hindi umaalis sa platform.
- **Iisang lugar para sa lahat** -- Hindi na kailangang bumisita ng mga boluntaryo at koordinator sa maraming website para hanapin at iiskedyul ang mga aralin.
- **Madaling i-setup** -- Pangalan at feed URL lamang ang kailangan para magdagdag ng provider. Walang manual na pag-encode ng datos o pag-upload ng file.

:::info
Ang third-party na nilalaman ay pinamamahalaan ng external provider. Kung mapansin mong may nawawala o lumang nilalaman mula sa isang provider, maaaring kailangang ayusin ito sa panig nila.
:::

:::tip
Para matutunan kung paano lumalabas ang mga aralin mula sa external provider kapag naiskedyul na ang mga ito, tingnan ang [External Providers](../browsing/external-providers.md) sa seksyong Browsing.
:::
