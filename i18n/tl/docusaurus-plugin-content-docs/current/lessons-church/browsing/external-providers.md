# Mga External Provider

<div class="article-intro">

Hindi limitado ang Lessons.church sa sarili nitong kurikulum. Maaaring mag-publish ang mga third-party na tagapagbigay ng kurikulum ng kanilang nilalaman sa pamamagitan ng **Open Lesson Format**. Kapag naidagdag na ng iyong simbahan ang isang provider, maaari mong iiskedyul ang mga aralin nito para sa iyong mga classroom, katabi lamang ng library ng Lessons.church.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Unawain kung paano inaayos ang nilalaman sa pamamagitan ng pagbasa sa [Mga Programa at Pag-aaral](./programs-and-studies.md)
- Para magdagdag ng koneksyon sa provider, kailangan mo ng [account sa Lessons.church](../getting-started/creating-account.md) na may access sa mga iskedyul ng classroom ng iyong simbahan

</div>

## Ano ang mga External Provider?

Ang external provider ay anumang organisasyong nagpa-publish ng kurikulum ng simbahan gamit ang Open Lesson Format -- isang pamantayan na nagpapahintulot na maibahagi ang nilalaman ng aralin sa iba't ibang plataporma. Kapag ginawang available ng isang provider ang kanilang nilalaman sa format na ito, mababasa ito ng Lessons.church at maipapakita ang mga aralin nito gamit ang parehong layout ng sarili nitong mga aralin.

Ibig sabihin nito, makakakuha ka ng mas malawak na pagpipilian ng kurikulum nang hindi kinakailangang bumisita sa maraming website.

## Pagdaragdag ng Koneksyon sa Provider

Kung gumagamit ang iyong simbahan ng curriculum provider na sumusuporta sa Open Lesson Format:

1. Mag-log in sa iyong account sa Lessons.church.
2. I-click ang **External Providers** sa navigation.
3. I-click ang **Add Provider**, ilagay ang **Provider Name** at ang **API URL** ng provider, at i-click ang **Save**.

Tingnan ang [Third-Party Providers](../admin/third-party-providers.md) para sa buong hakbang.

:::info
Ang external provider ay idinadagdag para lamang sa iyong simbahan. Hindi lumalabas ang mga programa nito sa pampublikong home page ng Lessons.church o sa paghahanap.
:::

## Paggamit ng External na Nilalaman

Kapag naidagdag na ang isang provider, available na ang mga programa, pag-aaral, at aralin nito kapag nag-iiskedyul ka:

1. Kapag [nagdaragdag ka ng aralin sa iskedyul ng classroom](../classrooms/scheduling-lessons.md), piliin ang provider sa ilalim ng **Provider**.
2. Piliin ang **Program**, **Study**, **Lesson**, at **Venue** sa parehong paraan ng gagawin mo para sa aralin ng Lessons.church.
3. Sa iskedyul ng classroom, i-click ang **View Lesson** sa ilalim ng nakaiskedyul na external na aralin para buksan ito. Gumagamit ito ng parehong layout ng mga built-in na aralin -- mga seksyon, tungkulin, aksyon, video, at mga materyal na maaaring i-download.

:::note
Hindi maaaring [i-customize](../customization/customizing-lessons.md) ang mga aralin mula sa external provider. Tanging ang mga aralin ng Lessons.church lamang ang nagpapakita ng link na **Customize**.
:::

## Para sa mga Content Creator

Kung ikaw ay publisher ng kurikulum na interesadong gawing available ang iyong nilalaman sa Lessons.church, nagbibigay ang Open Lesson Format ng standardized na paraan para ibahagi ang iyong mga programa, pag-aaral, at aralin. Makipag-ugnayan sa koponan ng Lessons.church o bisitahin ang developer documentation para sa mga detalye ng integrasyon.

:::tip
Para sa hakbang-hakbang na gabay sa pagdaragdag, pag-e-edit, at pagtanggal ng provider, tingnan ang [Third-Party Providers](../admin/third-party-providers.md).
:::
