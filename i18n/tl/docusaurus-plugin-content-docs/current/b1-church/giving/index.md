# Pagbibigay

<div class="article-intro">

Pinadadali ng B1App ang pagsuporta sa iyong simbahan sa pamamagitan ng online na donasyon. Kung gusto mong magbigay ng mabilisang isang beses o pamahalaan ang paulit-ulit na pagbibigay, makukuha mo ang lahat ng kailangan mo mula sa site ng iyong simbahan sa B1.church.

</div>

## Pangkalahatang-ideya

Sinusuportahan ng B1App ang dalawang paraan ng pagbibigay:

- **Public donations** -- Sinumang makakapag-donate nang hindi naka-log in. Bisitahin ang donate page ng iyong simbahan, pumili ng fund, at ilagay ang iyong detalye sa pagbabayad. Hindi kailangan ng account.
- **Authenticated giving** -- Kapag [nag-log in](../getting-started/logging-in.md) ka bago magdonate, naka-link ang iyong mga bigay sa iyong account. Nakukuha mo rito ang buong kasaysayan ng donasyon, mga naiimprentang giving statement, pamamahala ng paulit-ulit na donasyon, at mga naka-save na paraan ng pagbabayad.

## Ano ang Maaari Mong Gawin

Narito ang available sa seksyon ng pagbibigay:

- **Magbigay sa mga partikular na fund** -- Maaaring may maraming fund ang iyong simbahan, tulad ng General Fund, Building Fund, o Missions Fund. Maaari mong piliin kung saan mapupunta ang iyong donasyon.
- **Magbayad gamit ang card o bank account** -- Ligtas na pinoproseso ang mga donasyon sa pamamagitan ng Stripe. Maaari kang magbayad gamit ang credit o debit card. Available din ang mga tagubilin sa ACH bank payment.
- **Mag-set up ng paulit-ulit na donasyon** -- Maaaring mag-iskedyul ng awtomatikong paulit-ulit na donasyon ang mga naka-log in na miyembro para hindi ka makaligtaan ng bigay.
- **Tingnan ang kasaysayan ng donasyon** -- Makita ang kumpletong listahan ng iyong mga nakaraang donasyon, kasama ang petsa, paraan, fund, at halaga.
- **Mag-print ng giving statement** -- Gumawa ng naiimprentang giving statement para sa kasalukuyan o nakaraang taon para sa iyong mga tala sa buwis.
- **Pamahalaan ang mga paraan ng pagbabayad** -- Mag-save at mamahala ng iyong mga paraan ng pagbabayad para mas mabilis magbigay sa hinaharap.

Maaaring limitahan ng iyong simbahan kung aling mga taon ng giving history ang makikita ng mga miyembro, o itago ito, at makapagdagdag ng giving note na lumalabas sa iyong pahinang Giving at mga statement. Tingnan ang [Donation History](./donation-history.md#if-your-church-limits-giving-history).

:::info
Ligtas na pinoproseso ang mga donasyon sa pamamagitan ng **Stripe**. Hindi kailanman itinatago ang iyong impormasyon sa pagbabayad sa mga server ng B1.church.
:::
