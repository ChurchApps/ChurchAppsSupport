# Pagbibigay

<div class="article-intro">

Pinapadali ng B1App ang pagsuporta sa iyong simbahan sa pamamagitan ng online na donasyon. Kung gusto mo ng mabilisang isahang regalo o pamamahalaan ang paulit-ulit na pagbibigay, makukuha mo ang lahat ng kailangan mo mula sa site ng B1.church ng iyong simbahan.

</div>

## Pangkalahatang-tanaw {#overview}

Sumusuporta ang B1App ng dalawang paraan ng pagbibigay:

- **Pampublikong donasyon** -- Sinuman ay maaaring gumawa ng isahan o paulit-ulit na donasyon nang hindi nag-lo-log in. Bisitahin ang donate page ng iyong simbahan, pumili ng pondo, at ilagay ang detalye ng iyong pagbabayad. Walang kinakailangang account, at maaari kang pumiling magbigay nang hindi nagpapakilala.
- **Naka-authenticate na pagbibigay** -- Kapag [naka-log in](../getting-started/logging-in.md) ka bago magbigay, nakakabit ang iyong mga regalo sa iyong account. Binibigyan ka nito ng access sa buo mong kasaysayan ng donasyon, mga printable na giving statement, pamamahala ng paulit-ulit na donasyon, at mga naka-save na paraan ng pagbabayad.

## Ano ang Maaari Mong Gawin {#what-you-can-do}

Narito ang available sa seksyon ng pagbibigay:

- **Magbigay sa partikular na pondo** -- Maaaring may ilang pondo ang iyong simbahan, gaya ng General Fund, Building Fund, o Missions Fund. Maaari mong piliin kung saang pondo itutuon ang iyong donasyon.
- **Magbayad gamit ang card o bank account** -- Ligtas na pinoproseso ang mga donasyon ng payment provider ng iyong simbahan (karamihan ng simbahan ay gumagamit ng Stripe). Maaari kang magbayad gamit ang credit o debit card, at depende sa provider, bank account, mobile money, o PayPal at Venmo. Available din ang mga tagubilin sa ACH bank payment.
- **Mag-set up ng paulit-ulit na donasyon** -- Maaaring mag-iskedyul ng awtomatikong paulit-ulit na donasyon ang mga naka-log in na miyembro para hindi ka makaligtaan ng regalo.
- **Tingnan ang kasaysayan ng donasyon** -- Makita ang kumpletong listahan ng iyong mga nakaraang donasyon, kasama ang petsa, paraan, pondo, at halaga.
- **Mag-print ng giving statement** -- Gumawa ng printable na giving statement para sa kasalukuyan o nakaraang taon para sa iyong mga talaan sa buwis.
- **Pamahalaan ang mga paraan ng pagbabayad** -- Mag-save at mamahala ng iyong mga paraan ng pagbabayad para mas mabilis magbigay sa hinaharap.

Maaaring limitahan ng iyong simbahan kung aling mga taon ng kasaysayan ng pagbibigay ang nakikita ng mga miyembro, o itago ito, at maaari itong magdagdag ng giving note na makikita sa iyong pahinang Giving at mga statement. Tingnan ang [Kasaysayan ng Donasyon](./donation-history.md#if-your-church-limits-giving-history).

:::info
Ligtas na pinoproseso ang mga donasyon ng payment provider ng iyong simbahan, gaya ng **Stripe**. Hindi kailanman iniimbak sa mga server ng B1.church ang detalye ng iyong card at bank.
:::
