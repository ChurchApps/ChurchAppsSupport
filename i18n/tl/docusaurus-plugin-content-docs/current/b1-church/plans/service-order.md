# Service Order

<div class="article-intro">

Kapag binuksan mo ang isang plano, ipinapakita ng seksyong **Service Order** ang unang ilang item ng serbisyong iyon -- i-tap ang **Full service order** para makita ang buong pagkakasunod-sunod. Nagbibigay ito sa iyo at sa iyong team ng magkakatulad na pagtingin sa daloy ng serbisyo, kasama ang oras, detalye ng kanta, at paglalarawan ng bawat bahagi.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan kang [naka-log in](../getting-started/logging-in.md) sa iyong B1.church account.
- Magbukas ng plano mula sa iyong [listahan ng Plans](./viewing-plans.md) para makita ang service order nito.

</div>

## Ano ang Ipinapakita ng Service Order {#what-the-service-order-shows}

Ipinapakita ang service order bilang listahan ng mga item ayon sa pagkakasunod-sunod ng mga ito sa serbisyo. Bawat item ay may kasamang:

- **Kumulatibong oras** -- Ang tumatakbong oras mula sa simula ng serbisyo, para malaman mo kung kailan inaasahang magsisimula ang bawat bahagi.
- **Label at paglalarawan ng item** -- Ang pangalan ng bahagi (gaya ng pamagat ng kanta, panalangin, o anunsyo) kasama ang anumang tala o paglalarawan.
- **Tagal** -- Gaano katagal inaasahang tatagal ang item.

Nakaayos ang mga item sa ilalim ng **mga header** na nagpapangkat ng mga kaugnay na bahagi (halimbawa, "Worship Set" o "Message"). Ipinapakita ng bawat header ang kabuuang oras ng mga item nito. Dahil dito, madaling makita ang kabuuang istruktura ng serbisyo.

Ang mga kanta ay nagpapakita ng music note at ang key kung saan tutugtugin (halimbawa, "Key of G"). Ang item na may nakakabit na link ay ipinapakita ang pangalan nito bilang link -- i-tap ito para buksan ang link (direktang nagpe-play sa pahina ang mga audio link).

Ang mga seksyon ng aralin at curriculum ay maaari ring lumawak bilang folder ng mga indibidwal na aksyon na nakalagay sa ilalim ng mga ito -- i-click ang seksyon para palawakin o itupi ang mga aksyon nito at makita ang bawat hakbang na dadaanan ng iyong team.

## Pagtingin sa Lyrics at Chord ng Kanta {#viewing-song-lyrics-and-chords}

I-click ang isang kanta sa service order para buksan ang mga detalye nito: ang artist, ang mga button na **Key Signature**, ang **Lyrics** (kasama ang mga chord kung mayroon ang kanta), mga katotohanan tungkol sa kanta gaya ng album, BPM, key, meter, at haba, at mga **Links** sa kanta sa mga serbisyo gaya ng Spotify, YouTube, o PraiseCharts. I-tap ang isang key sa ilalim ng **Key Signature** para i-transpose agad ang mga chord -- kapaki-pakinabang kung ang iyong instrumento o saklaw ng boses ay nangangailangan ng ibang key kaysa sa pinlano ng worship leader. I-tap ang **Close** kapag tapos ka na.

## Curriculum at Nilalaman ng Aralin {#curriculum-and-lesson-content}

Kung ang plano ay may kaugnay na curriculum o nilalaman ng aralin mula sa provider gaya ng [Lessons.church](../content/lessons.md), makikita mo ang preview ng nilalamang iyon sa loob ng service order. Maaaring kasama rito ang mga seksyon ng aralin, materyal sa presentasyon, at iba pang resource na kailangan ng iyong team para sa serbisyo.

## Pag-print ng Service Order {#printing-the-service-order}

Walang opsyong mag-print ng mga plano ang B1.church member app. Kung kailangan mo ng nakalimbag na kopya na may listahan ng team at buong service order, hilingin sa isang staff member na i-print ito mula sa B1 Admin. Tingnan ang [Pag-print ng mga Plano](../../b1-admin/serving/plans.md#printing-plans).
