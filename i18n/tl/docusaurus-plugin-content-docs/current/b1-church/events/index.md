# Mga Event

<div class="article-intro">

Hinahayaan ka ng seksyong Events sa B1.church na mag-browse ng mga paparating na event ng simbahan at magparehistro sa mga ito nang direkta mula sa website. Kapag pinayagan ng iyong simbahan ang pagpaparehistro para sa isang event, maaari kang magparehistro para sa sarili mo at sa mga miyembro ng iyong pamilya sa ilang hakbang lamang -- at para sa mga bayad na event, pumili ng mga uri ng dadalo at mga opsyon, maglagay ng discount code, at magbayad nang ligtas bilang bahagi ng pagpaparehistro.

</div>

## Pag-browse ng Mga Event {#browsing-events}

Lumalabas ang mga event sa website ng iyong simbahan, alinman sa isang buwanang calendar o bilang mga tile ng paparating na event. I-click ang isang event para buksan ang sarili nitong pahina, na nagpapakita ng:

- **Larawan ng event** -- Kung may idinagdag ang simbahan.
- **Pamagat at paglalarawan ng event** -- Tungkol sa event.
- **Kailan** -- Ang petsa at oras ng susunod na pagdaraos, o ang pattern ng pag-uulit para sa paulit-ulit na event.
- **Saan** -- Ang mga kwartong nakareserba para sa event, kung mayroon.
- **Register for this Event** -- Isang button na magdadala sa iyo sa form ng pagpaparehistro. Ipinapakita lamang ito kapag naka-on ang pagpaparehistro para sa event.
- **Add to my calendar** -- Nagda-download ng event bilang calendar file na mabubuksan mo sa Google Calendar, Apple Calendar, Outlook, o ibang calendar app.

I-tap ang **All events** sa itaas ng pahina para bumalik. Sa itaas ng mga tile ng paparating na event, may button na **Subscribe** na nagbibigay-daan sa iyong kopyahin ang ICS link ng buong calendar o i-download ito, para lumabas ang mga bagong event sa sarili mong calendar app.

## Status ng Pagpaparehistro {#registration-status}

Kapag binuksan mo ang pahina ng pagpaparehistro ng isang event, depende sa oras at kapasidad ang makikita mo:

- **Open** -- Lumalabas ang form ng pagpaparehistro, kasama ang bar na nagpapakita kung ilan ang napuno nang puwesto (halimbawa, "4 / 50 spots filled") kapag may limitasyon sa kapasidad ang event.
- **Registration Not Open** -- Hindi pa nagsisimula ang panahon ng pagpaparehistro. Ipinapakita ng pahina ang petsa ng pagbubukas, halimbawa "Registration opens Nov 16, 2026." Bumalik sa petsang iyon.
- **Closed** -- Sinasabi ng pahina ang "Registration Not Open" at "Registration for this event has closed." Lumipas na ang deadline ng pagpaparehistro.
- **Event Full** -- Lahat ng available na puwesto ay napuno na: "This event has reached its capacity of 50."

:::tip
Kung puno na ang event, maaari ka pa ring sumali sa **waitlist** kapag naka-enable ito ng iyong simbahan -- awtomatiko kang padadalhan ng email kung magkaroon ng bakanteng puwesto. Kung hindi, bumalik na lang mamaya; maaaring magkaroon ng bakante kung may magkansela.
:::

## Ano ang Kailangan Mo {#what-you-need}

- Isang B1.church account (o maaari kang magparehistro bilang bisita)
- Access sa website ng B1.church ng iyong simbahan
