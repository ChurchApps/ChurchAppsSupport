# My Registrations

Ang **My Registrations** page ay nagpapakita ng lahat ng event na nag-register ang miyembro. Mula dito, makikita nila ang kanilang mga status, maaaring mag-edit ng kanilang registration, o magbabayad ng mga balanse.
