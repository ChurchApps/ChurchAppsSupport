# Paghiling ng mga Event at Kwarto

<div class="article-intro">

Kung nagta-track ang iyong simbahan ng mga kwarto at resources na maaaring i-book, maaari kang humiling ng event -- kasama ang mga kwarto at kagamitang kailangan nito -- direkta mula sa member portal. Namamarkahan ang mga banggaan sa mga umiiral na booking habang pumipili ka, dumidiretso sa simbahan ang iyong kahilingan para sa pag-apruba, at maaari mo itong subaybayan o kanselahin mula sa My Requests.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan kang [naka-log in](../getting-started/logging-in.md) sa member portal
- Dapat may naka-set up na mga kwarto o resources sa B1 Admin ang iyong simbahan -- lumalabas lamang ang mga link ng kahilingan kapag mayroon

</div>

## Pagsusumite ng Kahilingan {#submitting-a-request}

1. Buksan ang pahinang **Me** sa member portal at i-tap ang **Request an Event** sa seksyong **Requests & registrations**.
2. Punan ang pangunahing detalye ng event: **Event title**, opsyonal na **Description**, at ang mga oras ng **Start** at **End**. I-on ang **All day** para mga petsa lamang ang piliin.
3. Piliin ang mga **Rooms** at **Resources** na kailangan mo (maaari kang pumili ng marami sa bawat isa). Kapag may napili ka na, maaari kang maglagay ng **Setup (min before)** at **Teardown (min after)** na minuto, o i-on ang **Custom reservation window** at ikaw mismo ang magtakda ng **Reserve from** at **Reserve until**.
4. Bantayan ang mga babala ng banggaan -- kung ang iyong oras ay nagko-overlap sa umiiral na booking ng isang kwarto o resource, makikita mo ang *"Some selections may already be booked at this time."* Maaari mong baguhin ang iyong oras o pumili ng iba.
5. Kung mauulit ang event nang higit sa isang beses, i-on ang **Repeats** at itakda ang pattern.
6. I-tap ang **Submit Request**. Mananatiling kulay-abo ang button hanggang maglagay ka ng event title. I-tap ang **Cancel** para umalis nang hindi nagsusumite.

Pagkatapos magsumite, lalabas ang buod na **Request submitted** na nagpapakita ng status ng bawat kwarto at resource na hiniling mo (i-tap ang **My Requests** para pumunta sa iyong listahan):

- **Approved** -- Agad na naka-book (ang kwarto o resource ay walang approval group).
- **Pending approval** -- Kailangan muna itong aprubahan ng isang tao mula sa simbahan.

## Pagsubaybay sa Iyong Mga Kahilingan {#tracking-your-requests}

Buksan ang **My Requests** mula sa pahinang Me. Hinahati ang mga kahilingan sa **Upcoming** at **Past** ayon sa petsa ng event (i-tap ang **All past** para makita ang mas luma). Ipinapakita ng bawat kahilingan ang pamagat ng event at kung kailan ito magsisimula, ang status ng bawat kwarto at resource na hiniling mo, at isang status pill:

- **Pending** -- Naghihintay ng desisyon
- **Approved** -- Kumpirmado ang iyong booking
- **Rejected** -- Tinanggihan ang kahilingan

Habang pending pa ang kahilingan, maaari mo itong bawiin gamit ang **Cancel request**. Magtatanong ang kumpirmasyon ng "Cancel this request? This cannot be undone." -- i-tap ang **Cancel request** para kumpirmahin o **Keep** para iwan ito.

Maaari ka ring magsimula ng bagong kahilingan gamit ang button na **Request an Event** sa itaas ng My Requests.

:::info
Sinusuri ng staff ng simbahan ang mga kahilingan sa [pahina ng Approvals](../../b1-admin/calendars/approvals.md) ng B1 Admin. Nasa pasya ng iyong simbahan kung aling mga kwarto at resource ang nangangailangan ng pag-apruba -- tingnan ang [Rooms & Resources](../../b1-admin/calendars/rooms-resources.md).
:::
