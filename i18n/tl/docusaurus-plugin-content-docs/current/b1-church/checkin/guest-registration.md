# Pagpaparehistro ng Bisita

<div class="article-intro">

Kung unang beses mong bumisita sa isang simbahan, maaari mong irehistro ang iyong sarili at ang iyong pamilya bilang mga bisita gamit ang pahina ng pagpaparehistro ng bisita. Lilikha ito ng talaan sa system ng simbahan para ma-check in ka ng mga volunteer pagdating mo.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Kailangang naka-enable ang QR guest registration ng inyong simbahan
- I-scan ang QR code na ipinapakita sa check-in kiosk, i-tap ang **Register here** sa kiosk, o tumanggap ng link mula sa isang volunteer ng simbahan

</div>

## Paano Gumagana ang Pagpaparehistro ng Bisita

Ang pagpaparehistro ng bisita ay para sa mga bisitang wala pang account. Sa check-in kiosk ng simbahan, i-tap ang **Register as guest** para ipakita ang QR code na may link sa pahina ng pagpaparehistro. Maaari ka ring tumanggap ng link mula sa isang volunteer o greeter.

Walang dalang telepono? Sa parehong QR code window sa kiosk, i-tap ang **Register here** para punan ang form mismo sa kiosk. Tingnan ang [Pagrerehistro bilang Bisita](../../b1-checkin/check-in/looking-up-members#registering-as-a-guest) para malaman kung paano ito gumagana sa kiosk.

## Pagrerehistro ng Inyong Pamilya

1. **I-scan ang QR code** sa check-in kiosk o buksan ang link ng pagpaparehistro ng bisita sa iyong telepono. (Kung ni-tap mo ang **Register here** sa kiosk, bukas na ang form.)
2. Lalabas ang form ng pagpaparehistro ng bisita na may mga field para sa **pangunahing contact**:
   - **First Name** (kailangan)
   - **Last Name** (kailangan)
   - **Email** (opsyonal)
   - **Phone** (opsyonal)
3. Para magdagdag ng **mga miyembro ng pamilya**, i-tap ang **Add Family Member** at ilagay ang kanilang pangalan at apelyido. Maaari kang magdagdag ng hanggang 10 miyembro ng pamilya.
4. Para mag-alis ng miyembro ng pamilya, i-tap ang remove button sa tabi ng kanilang pangalan.
5. I-tap ang **Register** para isumite.

## Pagkatapos Magrehistro

Kapag naisumite mo na ang form, lalabas ang confirmation screen na may mensaheng: "Registration Complete -- You're all set! A staff member will check you in shortly."

Lumilikha ang iyong pagpaparehistro ng mga talaan sa database ng simbahan:

- Isang **sambahayan** ang nililikha gamit ang apelyido ng pangunahing contact.
- Nililikha ang mga **talaan ng tao** para sa bawat miyembro ng pamilya na may membership status na "Guest".
- Pagkatapos, maaaring i-check in ng isang volunteer o administrator ng simbahan ang inyong pamilya gamit ang kiosk ng [B1 Checkin](../../b1-checkin/check-in/looking-up-members).

:::info
Kung tumutugma ang iyong email sa umiiral na talaan sa database ng simbahan, ili-link ng system ang talaang iyon sa halip na lumikha ng kopya. Pinapanatili nitong maayos ang datos ng simbahan.
:::

:::tip
Nakakatulong ang pagbibigay ng iyong email address para makapag-follow up sa iyo ang simbahan pagkatapos ng iyong pagbisita. Opsyonal ito ngunit inirerekomenda.
:::
