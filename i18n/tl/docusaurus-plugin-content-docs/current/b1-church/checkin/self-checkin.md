# Self Check-In

<div class="article-intro">

Hinahayaan ka ng self check-in na itala ang attendance para sa iyong sarili at sa iyong sambahayan sa ilang simpleng hakbang. Mabilis itong alternatibo sa paggamit ng pisikal na kiosk sa simbahan.

## Ang Daloy ng Check-In {#the-check-in-flow}

Sumusunod ang check-in sa simpleng tatlong-hakbang na proseso. Buksan ang **Check-In** mula sa [tab bar o sa More page](../getting-started/navigating.md) para magsimula.

### Hakbang 1: Pumili ng Serbisyo {#step-1-select-a-service}

Kapag binuksan mo ang check-in page, makikita mo ang listahan ng mga available na serbisyo (halimbawa, "Sunday Morning" o "Wednesday Evening"). Ipinapakita ng bawat service card ang pangalan ng serbisyo at campus kung maraming lokasyon ang simbahan.

I-click ang isang serbisyo para piliin ito at lumipat sa susunod na hakbang.

### Hakbang 2: Pumili ng mga Miyembro ng Sambahayan at Grupo {#step-2-select-household-members-and-groups}

Pagkatapos piliin ang serbisyo, makikita mo ang mga miyembro ng iyong sambahayan sa ilalim ng **Who's here**. Para sa bawat taong dadalo:

1. I-tap ang isang miyembro ng sambahayan para palawakin ang kanyang entry.
2. Makikita mo ang mga available na **service time** para sa serbisyong pinili mo. Kung nagtakda ang simbahan mo ng check-in schedule para sa isang service time, mapipili lamang ito habang bukas ang check-in para dito (halimbawa, mula 30 minuto bago magsimula ang serbisyo hanggang sandali pagkatapos nitong matapos). Sa labas ng panahong iyon, ililista ang service time bilang **Closed**, kasama kung kailan ito magbubukas kung alam -- halimbawa, **Closed · opens Sun 9:30 AM**.
3. I-tap ang **Select Group** sa tabi ng service time para piliin ang grupong dapat i-check in ang tao (gaya ng "Main Worship," "Kids Room 1," o "Youth Group"). Nakalista ang mga grupo sa ilalim ng kanilang category heading (**General Groups** para sa mga walang category). I-tap ang **No Group** para alisin ang pagpili, o **Back** para bumalik nang hindi binabago ito.
4. Ulitin para sa bawat miyembro ng sambahayan na dadalo.

Hindi mo kailangang i-check in ang bawat miyembro ng sambahayan -- palawakin at magtakda lamang ng grupo para sa mga taong talagang naroroon.

Ang sinumang na-check in na para sa serbisyong ito ngayong araw ay magpapakita ng badge na **Already Checked In** sa tabi ng pangalan niya.

### Hakbang 3: Kumpirmasyon {#step-3-confirmation}

Kapag napili mo na ang mga grupo para sa lahat ng dadalo, i-tap ang button sa ibaba ng pahina. Binibilang nito ang mga taong napili mo -- halimbawa, **Check in 1 person** o **Check in 3 people**.

Kung may napili kang taong na-check in na para sa serbisyong ito ngayong araw, unang babanggitin siya ng isang window na **Already Checked In**. I-tap ang **Check In Again** para i-update ang kanyang mga grupo, o **Cancel** para bumalik.

Makikita mo ang **Check-in Complete** na may listahang **Where everyone is** na nagpapakita ng grupo (at service time) kung saan na-check in ang bawat tao. Pagkaraan ng sandali, babalik ang pahina sa listahan ng serbisyo, handa para sa susunod na check-in.

Kung nagpi-print ng name tag ang simbahan mo sa check-in station, makikita mo sa halip ang **You're checked in!** kasama ang QR code, security code, at listahang **Where everyone is**. Ipakita ang code sa check-in station para i-print ang name tag mo, pagkatapos i-tap ang **Done**. Sa B1 Checkin kiosk, i-tap ang **Scan code** at itapat ang QR code sa camera -- tingnan ang [Printing Labels for a Phone Check-In](../../b1-checkin/check-in/looking-up-members.md#printing-labels-for-a-phone-check-in).

Kung na-check in na ang sambahayan mo para sa serbisyong pipiliin mo, lalabas ang link na **Show check-in code** sa tabi ng heading na **Who's here**. I-tap ito para maibalik ang QR code at security code -- halimbawa, kung nagsara ka ng pahina bago makarating sa check-in station.

:::tip
Kung kailangan mong baguhin ang pagpili ng grupo bago tapusin ang check-in, i-tap ang button na **Change** sa tabi ng alinmang service time para pumili ng ibang grupo.
:::

## Mga Dapat Malaman {#things-to-know}

- Mga miyembro lamang ng sambahayang naka-link sa iyong account ang maaari mong i-check in. Kung may kulang na miyembro ng pamilya, hilingin sa iyong church administrator na idagdag sila sa sambahayan mo.
- Kung walang lumalabas na serbisyo sa check-in page, maaaring walang nakatakdang serbisyo para sa check-in ang simbahan sa ngayon.
- Kung pumili ka ng serbisyo at makakita ng mensaheng gaya ng "Check-in opens Sun 9:30 AM." (o "Check-in isn't open for this service right now."), wala sa mga service time ng serbisyong iyon ang nasa loob ng check-in window nito sa kasalukuyan. Subukan ulit kapag nagbukas na ang check-in.
- Kung nag-check in ang sambahayan mo para sa naunang service time, maaari kang bumalik at mag-check in para sa mas huling service time kapag nagbukas na ito, kahit natapos na ang naunang isa.
- Kung puno o sarado ang kuwartong napili mo, makikita mo ang "A room you picked is full or closed for check-in. Please see a volunteer."
- Kung walang sapat na volunteer na naka-check in ang children's room para sa isa pang bata, makakakita ka ng mensaheng nagbabanggit ng kuwarto -- halimbawa, "Kids Room 1 doesn't have enough volunteers for another child right now. Please pick a different room or see a volunteer."

:::warning
Available lamang ang check-in kapag may aktibong serbisyong naka-configure ang simbahan mo. Kung walang nakalistang serbisyo, tanungin ang opisina ng simbahan kung naka-enable ang self check-in.
:::
