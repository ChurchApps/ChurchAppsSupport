# Pag-install bilang App (PWA)

<div class="article-intro">

Sinusuportahan ng B1.church ang pag-install bilang Progressive Web App (PWA), na nagpapahintulot na idagdag ang member portal ng iyong simbahan sa home screen ng iyong telepono na parang isang native na app. Nagbibigay ito ng karanasang full-screen na parang app nang hindi dumaraan sa App Store o Google Play.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan mo ang B1.church URL ng iyong simbahan: `https://yourchurchname.b1.church`
- Gumamit ng suportadong browser: **Safari** sa iOS o **Chrome** sa Android

</div>

## Ano ang PWA?

Ang Progressive Web App (PWA) ay isang website na maaaring i-install sa iyong device at kumikilos na parang native na app. Kapag na-install mo ang B1.church bilang PWA, ito ay:

- Nagbubukas nang full-screen nang walang navigation bar ng browser
- Lumalabas sa iyong home screen kasama ang icon at pangalan ng iyong simbahan
- Maayos na gumagana kasama ang branding at mga theme color ng iyong simbahan

:::tip
Mainam ang PWA kung mas gusto mong huwag mag-install ng hiwalay na app mula sa App Store o Google Play. Ibinibigay nito ang parehong karanasan sa member portal na makukuha mo sa browser, sa mas maginhawang anyo.
:::

## Ang Install Page

Ang pinakamadaling paraan ng pag-install ay ang dedikadong install page ng iyong simbahan:

```
https://yourchurchname.b1.church/mobile/install
```

Awtomatikong nade-detect ng pahina ang iyong device at ipinapakita ang tamang tagubilin:

- **iPhone** -- hakbang-hakbang na tagubilin sa Safari na "Add to Home Screen"
- **Android** -- isang tap na button na **Install on Home Screen** sa Chrome
- **Desktop** -- isang QR code na maaari mong i-scan gamit ang iyong telepono upang buksan doon ang install page

Maaari mong marating ang install page sa ilang paraan:

- I-tap ang **More** sa member portal at i-tap ang **Install App** sa ilalim ng **Account** (nakatago ang item na ito kapag na-install na ang app)
- Sundin ang link na ibinahagi ng iyong simbahan sa pamamagitan ng text, email, o mula sa Sunday screen
- I-type nang direkta ang URL sa iyong browser

:::tip For church staff
Ibahagi ang link ng install page sa iyong kongregasyon -- ilagay ito sa iyong bulletin, newsletter, o sa isang slide. Ginagabayan nito ang bawat miyembro sa eksaktong mga hakbang para sa kanilang device. Maaari mo rin itong marating mula sa **Download the App** quick action sa iyong B1Admin dashboard.
:::

Maaari mo ring i-install nang manu-mano ang PWA mula sa **alinmang pahina** ng site ng B1.church ng iyong simbahan gamit ang mga hakbang sa browser sa ibaba -- ang install page ay isa lamang gabay na paraan para gawin ito.

Kapag binuksan mo ang naka-install na app, didiretso ito sa iyong member dashboard, handa para sa pag-log in mo.

## Pag-install sa iPhone (iOS -- Safari)

1. Buksan ang **Safari** sa iyong iPhone at pumunta sa `https://yourchurchname.b1.church/mobile/install` (palitan ang `yourchurchname` ng slug ng URL ng iyong simbahan).
2. I-tap ang **Share** button (ang kahon na may arrow na nakaturo pataas) sa ibaba ng screen.
3. Mag-scroll pababa sa share sheet at i-tap ang **Add to Home Screen**.
4. Ang pangalan ay magiging default na pangalan ng iyong simbahan. I-tap ang **Add** sa kanang itaas.

Lalabas ang icon ng app sa iyong home screen. I-tap ito upang buksan ang member portal sa full-screen mode.

:::info
Nangangailangan ng Safari ang pag-install ng PWA sa iOS. Kung gumagamit ka ng Chrome o ibang browser sa iPhone, lumipat muna sa Safari.
:::

## Pag-install sa Android (Chrome)

1. Buksan ang **Chrome** sa iyong Android device at pumunta sa `https://yourchurchname.b1.church/mobile/install`.
2. I-tap ang **Install on Home Screen** button. (Kung hindi available ang button, i-tap ang three-dot menu (⋮) sa kanang itaas at piliin ang **Add to Home screen**.)
3. I-tap ang **Add** kapag hiniling.

Lalabas ang icon ng app sa iyong home screen. I-tap ito upang buksan ang member portal.

## Pagkatapos ng Pag-install

Kapag na-install na, didiretso ang PWA sa member portal sa dedikadong full-screen na window. Maaari mong:

- Mag-log in gamit ang iyong umiiral na ChurchApps account
- I-access ang lahat ng feature ng miyembro na in-enable ng iyong simbahan -- mga group, giving, check-in, serving plan, at iba pa
- Bumalik dito anumang oras sa pamamagitan ng pag-tap sa icon sa iyong home screen

Magpapakita ang icon ng app ng **notification badge** (maliit na numero) kapag may hindi pa nababasang mensahe ka, kaya makikita mo agad kung may bagong naghihintay sa iyo.

:::info
Nangangailangan ng koneksyon sa internet ang PWA. Hindi tulad ng ilang native na app, hindi nito iniimbak ang lahat ng nilalaman para sa offline na paggamit.
:::

## Paano ang Lumang B1 Mobile App?

Hindi na ginagamit at hindi na ina-update ang lumang native na **B1 Mobile** app sa iOS at Android. Ang PWA na ang suportadong paraan ng pag-access sa member portal ng B1.church sa telepono sa hinaharap, at sakop nito ang bawat feature ng miyembro na inalok ng native app. Kung dati mong na-install ang native app, lumipat sa PWA kapag maginhawa na para sa iyo.

Tingnan ang [B1 Mobile reference page](/docs/b1-mobile/) para sa makasaysayang dokumentasyon tungkol sa hindi na ginagamit na app.
