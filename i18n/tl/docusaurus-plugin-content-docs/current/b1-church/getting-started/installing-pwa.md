# Pag-install bilang App (PWA)

<div class="article-intro">

Sinusuportahan ng B1.church ang pag-install bilang Progressive Web App (PWA), na nagbibigay-daan sa iyong idagdag ang member portal ng iyong simbahan sa home screen ng iyong telepono, tulad ng isang native na app. Nagbibigay ito ng full-screen at parang app na karanasan nang hindi dumadaan sa App Store o Google Play.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan mo ang B1.church URL ng iyong simbahan: `https://yourchurchname.b1.church`
- Gumamit ng suportadong browser: **Safari** sa iOS o **Chrome** sa Android

</div>

## Ano ang PWA? {#what-is-a-pwa}

Ang Progressive Web App (PWA) ay isang website na maaaring i-install sa iyong device at kumikilos na parang native na app. Kapag na-install mo ang B1.church bilang PWA, ito ay:

- Nagbubukas nang full-screen nang walang navigation bar ng browser
- Lumalabas sa home screen mo kasama ang icon at pangalan ng iyong simbahan
- Maayos na gumagana kasabay ng branding at mga kulay ng tema ng iyong simbahan

:::tip
Mainam ang PWA kung mas gusto mong huwag mag-install ng hiwalay na app mula sa App Store o Google Play. Ibinibigay nito ang parehong karanasan ng member portal na makukuha mo sa browser, sa mas maginhawang anyo.
:::

## Ang Install Page {#the-install-page}

Ang pinakamadaling paraan para mag-install ay ang nakalaang install page ng iyong simbahan:

```
https://yourchurchname.b1.church/mobile/install
```

Awtomatikong nade-detect ng pahina ang iyong device at ipinapakita ang tamang tagubilin:

- **iPhone** -- hakbang-hakbang na tagubilin ng Safari na "Add to Home Screen"
- **Android** -- isang button na **Install on Home Screen** na isang tap lang sa Chrome
- **Desktop** -- isang QR code na maaari mong i-scan gamit ang iyong telepono para buksan doon ang install page, kasama ang button na **Install on this computer** kung sinusuportahan ng iyong browser ang pag-install ng web app

Maaari mong marating ang install page sa iba't ibang paraan:

- I-tap ang **More** sa member portal at i-tap ang **Install App** sa ilalim ng **Account** (nakatago ang item na ito kapag na-install na ang app)
- Sundin ang link na ibinahagi ng iyong simbahan sa pamamagitan ng text, email, o mula sa screen tuwing Linggo
- I-type ang URL direkta sa iyong browser

:::tip Para sa staff ng simbahan
Ibahagi ang link ng install page sa iyong kongregasyon -- ilagay ito sa iyong bulletin, newsletter, o sa isang slide. Ginagabayan nito ang bawat miyembro sa eksaktong mga hakbang para sa kanilang device. Maaari mo rin itong marating mula sa aksyong **Download the App** sa iyong B1Admin dashboard.
:::

Maaari mo ring i-install nang manu-mano ang PWA mula sa **anumang pahina** ng site ng iyong B1.church gamit ang mga hakbang sa browser sa ibaba -- ang install page ay ginabayang paraan lamang para gawin ito.

Kapag binuksan mo ang naka-install na app, dederetso ito sa iyong member dashboard, handa para sa iyong pag-log in.

## Pag-install sa iPhone (iOS -- Safari) {#installing-on-iphone-ios--safari}

1. Buksan ang **Safari** sa iyong iPhone at pumunta sa `https://yourchurchname.b1.church/mobile/install` (palitan ang `yourchurchname` ng URL slug ng iyong simbahan).
2. I-tap ang button na **Share** (ang kahon na may arrow na nakaturo pataas) sa ibaba ng screen.
3. Mag-scroll pababa sa share sheet at i-tap ang **Add to Home Screen**.
4. Ang pangalan ay default na magiging pangalan ng iyong simbahan. I-tap ang **Add** sa kanang itaas na sulok.

Lalabas ang icon ng app sa home screen mo. I-tap ito para buksan ang member portal sa full-screen mode.

:::info
Nangangailangan ng Safari ang pag-install ng PWA sa iOS. Kung gumagamit ka ng Chrome o ibang browser sa iPhone, lumipat muna sa Safari.
:::

## Pag-install sa Android (Chrome) {#installing-on-android-chrome}

1. Buksan ang **Chrome** sa iyong Android device at pumunta sa `https://yourchurchname.b1.church/mobile/install`.
2. I-tap ang button na **Install on Home Screen**. (Kung hindi pa nag-aalok ng install prompt ang Chrome, sasabihin ito ng pahina -- i-tap ang three-dot menu (⋮) sa kanang itaas na sulok at piliin ang **Install app** sa halip.)
3. I-tap ang **Install** kapag tinanong.

Lalabas ang icon ng app sa home screen mo. I-tap ito para buksan ang member portal.

## Pagkatapos ng Pag-install {#after-installing}

Kapag na-install na, direktang bubukas ang PWA sa member portal sa isang nakalaang full-screen window. Kung bubuksan mo ang install page mula sa naka-install na app, ipapakita nito ang "You're all set!" sa halip na ang mga hakbang. Maaari mong:

- Mag-log in gamit ang umiiral mong ChurchApps account
- I-access ang lahat ng feature ng miyembro na na-enable ng iyong simbahan -- mga grupo, pagbibigay, check-in, serving plans, at iba pa
- Bumalik dito anumang oras sa pamamagitan ng pag-tap sa icon sa home screen mo

Ipapakita ng icon ng app ang isang **notification badge** (maliit na numero) kapag may hindi mo pa nababasang abiso o mensahe, para madali mong makita kung may bagong naghihintay sa iyo.

:::info
Nangangailangan ng internet connection ang PWA. Hindi tulad ng ilang native na app, hindi nito ina-cache ang lahat ng content para magamit offline.
:::
