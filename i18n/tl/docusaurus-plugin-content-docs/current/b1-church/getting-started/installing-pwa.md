# Pag-install bilang App (PWA)

<div class="article-intro">

Sinusuportahan ng B1.church ang pag-install bilang Progressive Web App (PWA), na nagbibigay-daan sa iyong idagdag ang member portal ng iyong simbahan sa home screen ng iyong telepono, tulad ng isang native app. Nagbibigay ito ng full-screen at parang app na karanasan nang hindi dumadaan sa App Store o Google Play.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan mo ang URL ng B1.church ng iyong simbahan: `https://yourchurchname.b1.church`
- Gumamit ng suportadong browser: **Safari** sa iOS o **Chrome** sa Android

</div>

## Ano ang PWA?

Ang Progressive Web App (PWA) ay isang website na maaaring i-install sa iyong device at kumikilos na parang native app. Kapag na-install mo ang B1.church bilang PWA, ito ay:

- Nagbubukas nang full-screen nang walang navigation bar ng browser
- Lumalabas sa iyong home screen kasama ang icon at pangalan ng iyong simbahan
- Maayos na gumagana kasama ang branding at theme colors ng iyong simbahan

:::tip
Mainam ang PWA kung mas gusto mong huwag mag-install ng hiwalay na app mula sa App Store o Google Play. Nagbibigay ito ng parehong karanasan sa member portal na makukuha mo sa browser, sa mas maginhawang anyo.
:::

## Ang Install Page

Ang pinakamadaling paraan ng pag-install ay ang dedicated install page ng iyong simbahan:

```
https://yourchurchname.b1.church/mobile/install
```

Awtomatikong nade-detect ng page ang iyong device at ipinapakita ang tamang mga tagubilin:

- **iPhone** — hakbang-hakbang na tagubilin ng Safari na "Add to Home Screen"
- **Android** — isang **Install on Home Screen** na button sa Chrome na isang tap lang
- **Desktop** — isang QR code na maaari mong i-scan gamit ang iyong telepono upang buksan doon ang install page

Maaari mong marating ang install page sa ilang paraan:

- I-tap ang **More** sa member portal at i-tap ang **Install App** sa ilalim ng **Account** (nakatago ang item na ito kapag na-install na ang app)
- Sundin ang link na ibinahagi ng iyong simbahan sa pamamagitan ng text, email, o mula sa Sunday screen
- I-type nang direkta ang URL sa iyong browser

:::tip Para sa mga staff ng simbahan
Ibahagi ang link ng install page sa iyong kongregasyon — ilagay ito sa iyong bulletin, newsletter, o sa isang slide. Ginagabayan nito ang bawat miyembro sa eksaktong mga hakbang para sa kanilang device. Maaari mo rin itong marating mula sa **Download the App** quick action sa iyong B1Admin dashboard.
:::

Maaari mo ring i-install nang manu-mano ang PWA mula sa **anumang pahina** ng site ng iyong simbahan sa B1.church gamit ang mga hakbang sa browser sa ibaba — ang install page ay gabay lamang na paraan para gawin ito.

Kapag binuksan mo ang naka-install na app, direkta itong magbubukas sa iyong member dashboard, handa para sa iyong pag-log in.

## Pag-install sa iPhone (iOS — Safari)

1. Buksan ang **Safari** sa iyong iPhone at pumunta sa `https://yourchurchname.b1.church/mobile/install` (palitan ang `yourchurchname` ng URL slug ng iyong simbahan).
2. I-tap ang **Share** button (ang kahon na may nakaturong arrow pataas) sa ibaba ng screen.
3. Mag-scroll pababa sa share sheet at i-tap ang **Add to Home Screen**.
4. Ang pangalan ay awtomatikong magiging pangalan ng iyong simbahan. I-tap ang **Add** sa kanang bahagi sa itaas.

Lalabas ang icon ng app sa iyong home screen. I-tap ito upang buksan ang member portal sa full-screen mode.

:::info
Nangangailangan ang pag-install ng PWA sa iOS ng Safari. Kung gumagamit ka ng Chrome o ibang browser sa iPhone, lumipat muna sa Safari.
:::

## Pag-install sa Android (Chrome)

1. Buksan ang **Chrome** sa iyong Android device at pumunta sa `https://yourchurchname.b1.church/mobile/install`.
2. I-tap ang **Install on Home Screen** na button. (Kung hindi available ang button, i-tap ang three-dot menu (⋮) sa kanang bahagi sa itaas at piliin ang **Add to Home screen**.)
3. I-tap ang **Add** kapag hiniling.

Lalabas ang icon ng app sa iyong home screen. I-tap ito upang buksan ang member portal.

## Pagkatapos ng Pag-install

Kapag na-install na, direktang magbubukas ang PWA sa member portal sa isang hiwalay na full-screen window. Maaari ka:

- Mag-log in gamit ang umiiral mong ChurchApps account
- Ma-access ang lahat ng feature para sa miyembro na pinagana ng iyong simbahan — groups, giving, check-in, serving plans, at iba pa
- Bumalik dito anumang oras sa pamamagitan ng pag-tap sa icon sa iyong home screen

Ipapakita ng icon ng app ang isang **notification badge** (maliit na numerong badge) kapag may hindi pa nababasang mensahe ka, para madali mong makita kung may bagong naghihintay sa iyo.

:::info
Nangangailangan ang PWA ng koneksyon sa internet. Hindi tulad ng ilang native app, hindi nito kinakatas ang lahat ng nilalaman para sa offline na paggamit.
:::
