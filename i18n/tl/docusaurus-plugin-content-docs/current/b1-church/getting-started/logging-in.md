# Pag-log In

<div class="article-intro">

Ang pag-log in sa B1.church ay nagbibigay sa iyo ng access sa member portal kung saan makikita mo ang mga paparating para sa iyo, mamamahala ng mga grupo, makakapagbigay online, at magagamit ang lahat ng tool na naka-set up ng iyong simbahan. Tinatalakay ng artikulong ito kung paano mag-sign in, mag-navigate sa iyong user menu, at mag-log out.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan mo ng ChurchApps account. Tingnan ang [Getting Started](../getting-started/) para gumawa ng isa.
- Kailangan mo ang B1.church URL ng iyong simbahan (halimbawa, `https://yourchurchname.b1.church`).

</div>

## Paano Mag-log In

1. Pumunta sa B1.church URL ng iyong simbahan (halimbawa, `https://yourchurchname.b1.church`).
2. I-click ang butones na **Login** sa kanang itaas ng header.
3. Ilagay ang iyong **email address** at **password**, o i-click ang **Continue with Google** o **Continue with Microsoft** kung naka-enable ang single sign-on ng iyong simbahan.
4. I-click ang **Sign In**.

Kung in-on mo ang [two-factor sign-in](../../b1-admin/profile/managing-profile.md#two-factor-sign-in), hihingi ng code ang susunod na screen. Ilagay ang 6-digit na code mula sa iyong authenticator app, o isa sa iyong backup code, at i-click ang **Verify code**. Ganito rin humihingi ng code ang B1.church app.

Pagkatapos mag-sign in, ibabalik ka sa pahinang pinanggalingan mo bago mo i-click ang login. Kung dumiretso ka sa pahina ng member portal habang naka-log out, awtomatiko kang ibabalik sa pahinang iyon pagkatapos mag-sign in.

## Pananatiling Naka-sign In

Mananatili kang naka-sign in sa parehong browser o naka-install na app hanggang mag-log out ka, kahit hindi ka bumisita nang ilang panahon -- pinananatili ang iyong session nang hanggang humigit-kumulang 30 araw na hindi aktibo. Ang pag-sign in nang isang beses ay nagpapanatili ring naka-sign in ka kapag lumipat ka sa pagitan ng website ng iyong simbahan at ng member portal (`/mobile`), kaya hindi mo kailangang mag-log in muli sa bawat lugar.

## Pag-access sa Member Portal

Kapag naka-log in na, maa-access mo ang member portal sa pamamagitan ng pag-click sa iyong **pangalan** sa kanang itaas ng pahina at pagpili ng **Member Portal** mula sa menu. Nandito ang lahat ng iyong personal na tool ng simbahan, kabilang ang iyong [Home dashboard](./navigating.md), [Me page](./me-page.md), [mga grupo](../groups/), [giving](../giving/), at iba pa.

## Ang Iyong User Menu

Pagkatapos mag-log in, lumilitaw ang iyong pangalan bilang chip sa kanang itaas. I-click ito para buksan ang menu na may sumusunod na opsyon:

- **Member Portal** -- Pumunta sa iyong personal na dashboard ng member portal.
- **Edit Profile** -- I-update ang mga setting ng iyong account o i-edit ang profile mo sa simbahan.
- **Logout** -- Mag-sign out sa iyong account.

## Access ng Admin

Kung ikaw ay administrator ng simbahan na may angkop na permiso, makikita mo rin ang opsyong **Admin Portal** sa iyong user menu. Ang pag-click dito ay dadalhin ka sa B1 Admin kung saan maaari mong pamahalaan ang mga setting, tao, grupo, at nilalaman ng iyong simbahan.

## Nakalimutan ang Iyong Password

Kung hindi mo maalala ang iyong password:

1. I-click ang **Forgot Password** sa login page.
2. Ilagay ang email address na nakakabit sa iyong ChurchApps account at isumite.
3. Tingnan ang iyong email para sa mensaheng may **6-digit na verification code**. Valid ang code sa loob ng 15 minuto.
4. Ilagay ang code sa verification screen para mag-sign in.
5. Kapag naka-sign in ka na, bisitahin ang iyong profile para pumili ng bagong password.

:::tip
Kung hindi dumating ang code sa loob ng ilang minuto, tingnan ang iyong spam folder. Pagkatapos ng limang maling pagsubok, naka-lock ang code -- humiling ng bago mula sa pahinang Forgot Password kung mangyari ito.
:::

## Pag-log Out

Para mag-log out, i-click ang iyong **pangalan** sa kanang itaas at piliin ang **Logout**. Made-sign out ka at ibabalik sa pampublikong site.
