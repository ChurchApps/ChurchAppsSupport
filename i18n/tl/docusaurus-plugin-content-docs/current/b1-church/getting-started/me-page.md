# Ang Me Page

<div class="article-intro">

Ang **Me** page ay ang iyong personal na dashboard sa member portal — isang chronological na tanawin ng lahat ng darating para sa iyo: mga serving assignment, event registration, at ang mga paparating na event ng iyong mga grupo, kasama ang iyong mga pinakabagong notification.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan mong maka-[log in](./logging-in.md) — lalabas lang ang Me page para sa mga naka-sign-in na miyembro

</div>

## Pagbukas ng Me Page

Buksan ang portal menu at i-tap ang **Me**. Malo-load ang page kasama ang iyong personal na impormasyon na naka-organisa sa mga seksyon.

## Upcoming

Nakalista sa seksyong **Upcoming** ang lahat ng darating para sa iyo ayon sa petsa, na may type chip ang bawat item:

- **Serving** -- Ang iyong mga volunteer position sa mga paparating na service plan. I-tap ang isa para buksan ang plan.
- **Registration** -- Mga event na iyong [na-register-an](../events/registering). I-tap para tumungo sa iyong [mga registration](../events/my-registrations).
- **Event** -- Mga paparating na event mula sa mga grupong kinabibilangan mo. I-tap ang isa para buksan ang mga event ng grupo.

Kung walang naka-iskedyul, makikita mo ang "Nothing coming up" — lalabas dito ang iyong mga oras ng serving, event, at registration habang sila ay naka-iskedyul.

## Mga Kamakailang Notification

Sa ibaba ng Upcoming, ipinapakita ng seksyong **Recent Notifications** ang iyong mga pinakabagong notification para maka-catch up ka nang hindi na kailangang buksan ang bawat bahagi ng portal.

## Mga Shortcut

Kapag may mga bookable na room o resource ang iyong simbahan, magpapakita rin ang Me page ng seksyong **Shortcuts**:

- **Request an Event** -- Humiling na mag-reserba ng event kasama ang mga room at kagamitang kailangan mo. Tingnan ang [Requesting Events & Rooms](../events/requesting-events).
- **My Requests** -- Subaybayan ang status ng iyong mga request at kanselahin ang mga nakabinbing (pending) request.

Kung hindi pa nag-se-set up ng mga room o resource ang iyong simbahan, nakatago ang mga shortcut na ito.
