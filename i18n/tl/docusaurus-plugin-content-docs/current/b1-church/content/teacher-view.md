# Teacher View para sa Mga Aralin

<div class="article-intro">
Nagbibigay ang Teacher View ng pinalawak na full-screen na interface para sa pagtingin ng nilalaman ng aralin na may nakaayos na mga seksyon, para mas madaling makapag-navigate ang mga guro at lider sa mga materyal ng aralin habang may klase.
</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Dapat may nakaiskedyul na mga aralin ang iyong simbahan sa isang plan. Tingnan ang B1 Admin guide na [Scheduling Lessons](../../b1-admin/serving/scheduling-lessons.md) para sa mga detalye.
- Kailangan kang nakatalaga sa plan o may access ka para tingnan ito sa iyong B1.church site.
</div>

## Pagbubukas ng Teacher View

Para mapuntahan ang pinalawak na teacher view ng isang aralin:

1. Buksan ang **Plans** sa B1.church member portal
2. Buksan ang plan na naglalaman ng araling gusto mong ituro
3. I-click ang butones na **Teach** sa itaas ng pahina ng plan

Bubukas ang aralin sa full-screen na interface na naka-optimize para sa pagtuturo.

:::tip
Lalo na kapaki-pakinabang ang Teacher View kapag ipinoprojekto ang nilalaman ng aralin sa screen o TV para makita ng klase, o kapag nagtuturo mula sa tablet.
:::

## Mga Feature ng Teacher View

### Pag-navigate sa Mga Seksyon

Inaayos ng teacher view ang nilalaman ng aralin sa mga seksyon:

- Bawat pangunahing seksyon ng aralin ay lumilitaw bilang sariling block na may pamagat
- I-click ang **Sections** sa itaas para buksan ang listahan ng mga seksyon, pagkatapos pumili ng isa para diretsong tumalon dito
- Ipinapakita ng heading kung nasaang seksyon ka, gaya ng "Section 2 of 5"
- Madaling lumipat-lipat sa iba't ibang bahagi ng aralin dahil sa listahan ng mga seksyon
- Kapag may higit sa isang seksyon ang aralin, nananatiling nakapin sa ibaba ng screen ang mga butones na nauna at susunod, may label ayon sa pangalan ng mga katabing seksyon, habang nag-i-scroll ka

### Nilalamang Maaaring I-scroll

Ipinapakita ng pangunahing content area ang buong materyal ng aralin:

- Mag-scroll sa aralin nang natural
- Habang nag-i-scroll ka, awtomatikong nagbabago ang heading para tumugma sa seksyong tinitingnan mo
- Malinaw na ipinapakita ang lahat ng naka-format na teksto, larawan, at tagubilin

### Pag-playback ng Media

Kapag may kasamang video, larawan, o iba pang media ang mga aralin:

- I-click ang alinmang media item para buksan ito sa popup player
- Tumatakbo ang mga video sa nakalaang video player na may karaniwang kontrol
- Bumubukas ang mga larawan sa lightbox para sa full-screen na pagtingin
- Isara ang media player para bumalik sa nilalaman ng aralin

### Mga Downloadable na Resource

Kung may kasamang mga file na maaaring i-download ang aralin (activity sheet, coloring page, atbp.):

- Lumalabas ang mga download button para sa bawat resource, pagkatapos ng huling seksyon ng aralin
- I-click para direktang i-download ang mga file sa iyong device
- Maaaring kasama sa mga file ang PDF, larawan, o iba pang materyal na ibinigay ng gumawa ng nilalaman

## Paggamit ng Teacher View sa Silid-Aralan

### Bago ang Klase

1. Buksan ang aralin sa Teacher View bago magsimula ang klase
2. Suriin ang lahat ng seksyon at pamilyarisin ang sarili sa nilalaman
3. I-download ang anumang printable na resource na kailangan mo
4. Subukan ang anumang video o media para masiguradong tama ang pag-play nito

### Habang Nasa Klase

1. Panatilihing bukas ang Teacher View sa iyong device o iprojekto ito sa screen
2. Gamitin ang **Sections** para lumipat-lipat sa mga seksyon habang umuusad ka sa aralin
3. Patugtugin ang mga video o ipakita ang mga larawan sa tamang oras
4. Mag-scroll sa mga tagubilin kung kailangan nang hindi nawawala ang iyong pinagbabasahan

### Sa Naprojektong Screen

Kapag nagpoprojekto para sa klase:

- Inaalis ng full-screen na layout ang mga nakakagambala
- Ang malalaki at madaling basahing teksto ay nakikita mula sa buong kuwarto
- I-click ang mga media item para ipakita ang mga video o larawan sa buong klase
- Mag-navigate gamit ang wireless mouse o trackpad

## Pagsasara ng Teacher View

Para lumabas sa teacher view:

- I-click ang butones na **Close** (X) sa sulok sa itaas
- O pindutin ang **Esc** key sa iyong keyboard
- Babalik ka sa view ng detalye ng plan

## Paggamit sa Mobile at Tablet

Gumagana ang Teacher View sa mga tablet at mobile device:

- **Tablet** -- Mainam para sa mga gurong gustong may portable na gabay sa aralin
- **Telepono** -- Suportado rin, pero maaaring hindi gaanong maganda ang mas maliit na screen para sa pagtuturo
- **Landscape mode** -- Nagbibigay ng pinakamagandang karanasan sa pagtingin sa mga mobile device

## Pagkakaiba sa Regular na Lesson View

| Feature | Regular View | Teacher View |
|---------|--------------|--------------|
| **Layout** | Compact, kasama sa plan | Full-screen, nakalaang view |
| **Navigation** | Scroll lang | Listahan ng seksyon + scroll na may heading ng kasalukuyang seksyon |
| **Media** | Naka-embed sa pahina | Popup player para sa nakatutok na pagtingin |
| **Screen space** | Nagpapakita ng iba pang item ng plan | Pinakamalaking espasyo para sa nilalaman ng aralin |
| **Best for** | Pag-browse at pagpaplano | Pagtuturo at pagpresenta |

## Mga Mabuting Kasanayan

- **Maghanda nang maaga** -- Suriin ang mga aralin sa Teacher View bago ang klase para maging pamilyar sa layout
- **Markahan ang mga seksyon** -- Tandaan kung aling mga seksyon ang may mahahalagang aktibidad o talakayan
- **Subukan ang media** -- Siguraduhing tama ang pag-load ng mga video at larawan bago ang oras ng klase
- **I-download nang maaga ang mga resource** -- Huwag hintayin ang oras ng klase para i-download ang mga printable
- **Gumamit ng mas malaking screen** -- Iprojekto o gumamit ng tablet para sa pinakamagandang karanasan sa pagtuturo

## Troubleshooting

### Hindi bumubukas ang aralin sa Teacher View

- Siguraduhing tama ang pagkakaiskedyul ng aralin sa plan
- Tiyaking may permiso kang tingnan ang plan
- I-refresh ang pahina at subukan muli

### Hindi nagpe-play ang mga video

- Suriin ang iyong koneksyon sa internet
- Siguraduhing pinapayagan ng iyong device ang media playback
- Subukang buksan ang video sa hiwalay na tab
- Maaaring may mga paghihigpit sa pag-playback ng video ang ilang content provider

### Mukhang naputol ang nilalaman sa mobile

- I-rotate ang iyong device sa landscape mode
- Mag-zoom out nang bahagya kung kailangan
- Isaalang-alang ang paggamit ng tablet o mas malaking device para mas makita nang maayos
