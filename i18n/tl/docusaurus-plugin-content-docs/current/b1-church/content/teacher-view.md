# Teacher View para sa mga Aralin

<div class="article-intro">
Nagbibigay ang Teacher View ng pinalawak, full-screen na interface para tingnan ang content ng aralin na may nakaayos na mga seksyon, na ginagawang mas madali para sa mga guro at lider na mag-navigate sa mga materyal ng aralin habang may klase.
</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Dapat may nakaiskedyul na mga aralin sa isang plano ang iyong simbahan. Tingnan ang gabay ng B1 Admin sa [Pag-iskedyul ng mga Aralin](../../b1-admin/serving/scheduling-lessons.md) para sa mga detalye.
- Kailangan kang naka-assign sa plano o may access para tingnan ito sa iyong B1.church site.
</div>

## Pagbukas ng Teacher View {#opening-teacher-view}

Para ma-access ang pinalawak na teacher view ng isang aralin:

1. Buksan ang **Plans** sa B1.church member portal
2. Buksan ang plano na naglalaman ng aralin na nais mong ituro
3. I-click ang button na **Teach** sa itaas ng pahina ng plano

Magbubukas ang aralin sa isang full-screen na interface na ino-optimize para sa pagtuturo.

Lumalabas ang button na **Teach** kapag ang service order ng plano ay direktang galing sa nakaiskedyul na aralin. Kung na-customize ng iyong simbahan ang service order ng plano, hindi ipapakita ang button, ngunit lumalabas pa rin ang mga printable na file ng aralin sa seksyong **Downloads** ng plano.

:::tip
Lalo na kapaki-pakinabang ang Teacher View kapag ipinoproyekto ang content ng aralin sa screen o TV para makita ng klase, o kapag nagtuturo mula sa tablet.
:::

## Mga Feature ng Teacher View {#teacher-view-features}

### Nabigasyon sa Seksyon {#section-navigation}

Inaayos ng teacher view ang content ng aralin sa mga seksyon:

- Ang bawat pangunahing seksyon ng aralin ay lumalabas bilang sariling may pamagat na block
- I-click ang **Sections** sa itaas para buksan ang listahan ng mga seksyon, pagkatapos ay pumili ng isa para direktang tumalon dito
- Ipinapakita ng heading kung nasaang seksyon ka, gaya ng "Section 2 of 5"
- Pinapadali ng listahan ng seksyon ang paglaktaw-laktaw sa iba't ibang bahagi ng aralin
- Kapag may higit sa isang seksyon ang aralin, nananatiling nakapirmi sa ibaba ng screen ang mga button na nakaraan at susunod, na may label ayon sa pangalan ng mga katabing seksyon, habang nag-i-scroll ka

### Scrollable na Content {#scrollable-content}

Ipinapakita ng pangunahing content area ang buong materyal ng aralin:

- Mag-scroll sa aralin nang natural
- Habang nag-i-scroll ka, awtomatikong nag-a-update ang heading para tumugma sa seksyong tinitingnan mo
- Malinaw na ipinapakita ang lahat ng naka-format na teksto, larawan, at tagubilin

### Pag-play ng Media {#media-playback}

Kapag may kasamang video, larawan, o iba pang media ang mga aralin:

- I-click ang alinmang media item para buksan ito sa popup player
- Nagpe-play ang mga video sa dedikadong video player na may karaniwang kontrol
- Nagbubukas ang mga larawan sa lightbox para sa full-screen na pagtingin
- Isara ang media player para bumalik sa content ng aralin

### Mga Maida-download na Materyal {#downloadable-resources}

Kung ang aralin ay may kasamang mga file na maaaring i-download (activity sheet, coloring page, at iba pa):

- Lumalabas ang mga download button para sa bawat materyal, pagkatapos ng huling seksyon ng aralin
- I-click para direktang mag-download ng mga file sa iyong device
- Maaaring kasama sa mga file ang PDF, larawan, o iba pang materyal na ibinigay ng gumawa ng content

## Paggamit ng Teacher View sa Silid-Aralan {#using-teacher-view-in-the-classroom}

### Bago ang Klase {#before-class}

1. Buksan ang aralin sa Teacher View bago magsimula ang klase
2. Suriin ang lahat ng seksyon at pamilyarisahin ang sarili sa content
3. Mag-download ng mga printable na materyal na kailangan mo
4. Subukan ang mga video o media para masigurong tama ang pag-play nito

### Habang Nasa Klase {#during-class}

1. Panatilihing bukas ang Teacher View sa iyong device o ipoproyekto ito sa screen
2. Gamitin ang **Sections** para lumipat sa pagitan ng mga seksyon habang umuusad ka sa aralin
3. Mag-play ng mga video o magpakita ng mga larawan sa tamang oras
4. Mag-scroll sa mga tagubilin kung kinakailangan nang hindi nawawala ang iyong pwesto

### Sa Projected na Screen {#on-a-projected-screen}

Kapag nagpoproyekto para sa klase:

- Tinatanggal ng full-screen na layout ang mga abala
- Ang malalaki at madaling basahing teksto ay nakikita mula sa kabilang dulo ng silid
- I-click ang mga media item para ipakita ang mga video o larawan sa buong klase
- Mag-navigate gamit ang wireless mouse o trackpad

## Pagsasara ng Teacher View {#closing-teacher-view}

Para lumabas sa teacher view:

- I-click ang button na **Close** (X) sa itaas na sulok
- O pindutin ang **Esc** key sa iyong keyboard
- Babalik ka sa view ng mga detalye ng plano

## Paggamit sa Tablet at Mobile {#mobile-and-tablet-use}

Gumagana ang Teacher View sa mga tablet at mobile device:

- **Mga tablet** -- Mainam para sa mga gurong gustong may portable na gabay sa aralin
- **Mga telepono** -- Suportado rin, bagama't maaaring hindi gaanong maganda ang mas maliit na screen para sa pagtuturo
- **Landscape mode** -- Nagbibigay ng pinakamagandang karanasan sa pagtingin sa mga mobile device

## Mga Pagkakaiba sa Regular na View ng Aralin {#differences-from-regular-lesson-view}

| Feature | Regular View | Teacher View |
|---------|--------------|--------------|
| **Layout** | Compact, kasabay ng plano | Full-screen, dedikadong view |
| **Navigation** | Scroll lamang | Listahan ng seksyon + scroll na may heading ng kasalukuyang seksyon |
| **Media** | Naka-embed sa pahina | Popup player para sa nakatutok na pagtingin |
| **Screen space** | Ipinapakita ang iba pang item ng plano | Pinalaki para sa content ng aralin |
| **Pinakamainam para sa** | Pag-browse at pagpaplano | Pagtuturo at pagpresenta |

## Mga Pinakamahusay na Gawi {#best-practices}

- **Maghanda nang maaga** -- Suriin ang mga aralin sa Teacher View bago ang klase para pamilyarisahin ang layout
- **Markahan ang mga seksyon** -- Tandaan kung aling mga seksyon ang may mahahalagang aktibidad o talakayan
- **Subukan ang media** -- Siguraduhing tama ang pag-load ng mga video at larawan bago magsimula ang klase
- **Mag-download ng materyal nang maaga** -- Huwag hintayin ang oras ng klase para mag-download ng mga printable
- **Gumamit ng mas malaking screen** -- Mag-proyekto o gumamit ng tablet para sa pinakamagandang karanasan sa pagtuturo

## Pag-troubleshoot {#troubleshooting}

### Hindi nabubuksan ang aralin sa Teacher View {#lesson-doesnt-open-in-teacher-view}

- Siguraduhing tama ang pagkakaiskedyul ng aralin sa plano
- Kung na-customize ang service order ng plano, nakatago ang button na **Teach** -- tingnan ang [Pagbukas ng Teacher View](#opening-teacher-view)
- Tiyaking may pahintulot kang tingnan ang plano
- I-refresh ang pahina at subukan muli

### Hindi nagpe-play ang mga video {#videos-wont-play}

- Suriin ang iyong koneksyon sa internet
- Siguraduhing pinapayagan ng iyong device ang pag-play ng media
- Subukang buksan ang video sa hiwalay na tab
- Maaaring may mga paghihigpit ang ilang content provider sa pag-play ng video

### Naputol ang content sa mobile {#content-appears-cut-off-on-mobile}

- I-rotate ang iyong device sa landscape mode
- Mag-zoom out nang bahagya kung kinakailangan
- Isaalang-alang ang paggamit ng tablet o mas malaking device para sa mas magandang visibility
