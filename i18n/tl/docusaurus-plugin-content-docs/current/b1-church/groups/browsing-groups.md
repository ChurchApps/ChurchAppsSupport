<div class="article-intro">

Pinapadali ng pampublikong pahina ng mga grupo ng iyong simbahan ang paghahanap ng mga grupong interesado ka. Maghanap ayon sa pangalan o paliitin ang listahan ayon sa kategorya o campus para mahanap ang tamang akma.

## Paghahanap sa Pahina ng mga Grupo {#finding-the-groups-page}

Pumunta sa pahinang **Find a Group** (`/groups`) sa site ng B1.church ng iyong simbahan. Bukas sa publiko ang pahinang ito, kaya hindi mo kailangang naka-log in para mag-browse. Sa member portal, binubuksan ng button na **Find a Group** sa screen na **Groups** ang parehong pahina.

## Paghahanap at Pag-filter {#searching-and-filtering}

Ipinapakita nang magkakasama ang lahat ng pampublikong grupo ng simbahan. Gamitin ang mga kontrol sa itaas ng listahan para paliitin ito:

- **Search groups by name or description** -- I-type ang isang salita para ipakita lamang ang mga grupong may ganoong salita sa pangalan, paglalarawan, o kategorya.
- **Category** -- Pumili ng kategorya, gaya ng "Small Groups," "Youth," o "Music," para ipakita lamang ang mga grupo nito. Piliin ang **All categories** para makita muli ang lahat. Itinatakda ng mga administrator ng iyong simbahan ang mga kategorya, at lumalabas lamang ang filter na ito kapag higit sa isa ang mga ito.
- **Campus** -- Kung may higit sa isang campus ang iyong simbahan, pumili ng isa para makita lamang ang mga grupong nakatalaga rito, o **All campuses** para makita ang lahat.

Kung walang tumutugma, sinasabi ng pahina ang "No groups match your filters."

Maaari ring mag-link ang iyong simbahan sa pahina ng isang label ng grupo, gaya ng `/groups/youth`, na naglilista lamang ng mga grupong may label na iyon.

## Pagbasa ng Mga Group Card {#reading-group-cards}

Ipinapakita ang bawat grupo bilang card na may sumusunod na impormasyon:

- **Larawan ng grupo** -- Isang cover image na kumakatawan sa grupo. Kung walang nakatakdang larawan, ipinapakita ang default na larawan.
- **Pangalan ng grupo** -- Naka-display nang kitang-kita sa ibabaw ng larawan.
- **Oras ng pagpupulong** -- Kailan karaniwang nagpupulong ang grupo (halimbawa, "Wednesdays at 7 PM"). Kung walang nakatakdang oras, ipinapakita ang "--".
- **Lokasyon ng pagpupulong** -- Saan nagpupulong ang grupo, sa kanan. Kung walang nakatakdang lokasyon, ipinapakita ang "--".
- **Paglalarawan** -- Maikling preview ng tungkol sa grupo, nakalimita sa ilang linya. Kung walang paglalarawan ang grupo, sinasabi ng card ang "No Description Provided." I-click ang grupo para basahin ang buong paglalarawan.

## Pagtingin sa Isang Grupo {#viewing-a-group}

I-click ang alinmang group card para buksan ang buong detail page ng grupo sa member portal. Doon mo makikita ang kumpletong paglalarawan, mga lider ng grupo, mga paparating na event, at paraan para sumali.

:::tip
Kung naghahanap ka ng partikular na uri ng grupo, piliin muna ito mula sa filter na **Category**. Nakakatipid ito ng oras sa pag-scroll sa bawat grupo.
:::

## Ang Iyong Mga Grupo sa Member Portal {#your-groups-in-the-member-portal}

Inililista ng screen na **Groups** sa member portal ang mga grupong kinabibilangan mo. Ipinapakita ng heading kung ilang grupo ang sinasalihan mo (at kung ilan ang nakabinbing kahilingan sa pagsali).

- **Search your groups** -- I-filter ang iyong mga grupo ayon sa pangalan.
- **Your groups** -- Ang mga grupong madalas mong binubuksan, hanggang lima, bawat isa ay may oras at lokasyon ng pagpupulong. I-tap ang isa para buksan ito.
- **Other Groups** -- Ang natitira mong mga grupo.
- **Pending Requests** -- Mga grupong hiniling mong salihan na naghihintay ng lider. Tingnan ang [Paghiling na Sumali sa Grupo](./join-requests.md).
- **Upcoming Events** -- Mga event ng simbahan na tumatanggap ng pagpaparehistro, bawat isa ay may link na **Register**. Tingnan ang [Pagpaparehistro sa mga Event](../events/registering.md).

I-tap ang **Find a Group** para mag-browse ng lahat ng grupo ng simbahan. Kung wala ka pang grupo, sinasabi ng screen ang "No groups yet" kasama ang button na **Browse groups**; kung hindi ka naka-sign in, hihilingin nito na mag-sign in ka para makita ang iyong mga grupo, pero ipinapakita pa rin nito ang mga **Upcoming Events** ng simbahan na tumatanggap ng registration para makapagpatala ka.
