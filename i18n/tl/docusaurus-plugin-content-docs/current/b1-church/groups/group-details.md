# Mga Detalye ng Grupo

<div class="article-intro">

Kapag nag-click ka sa isang grupo mula sa pahina ng mga grupo, ikaw ay dadalhin sa pahina ng mga detalye ng grupo. Ang makikita mo ay nakadepende sa kung ikaw ay naka-log in o hindi, na ang mga naka-log in na miyembro ay may access sa karagdagang mga tab at mga katangian.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Maghanap ng isang grupo upang tingnan sa pamamagian ng [pag-browse ng mga grupo](./browsing-groups.md).
- Para sa buong access sa lahat ng tab, [mag-log in](../getting-started/logging-in.md) sa iyong account.

</div>

## Pagtingin ng Bisita (Hindi Naka-log In)

Kung hindi ka naka-log in, makikita mo ang sumusunod:

- **Hero section** -- Isang malaking banner area na nagpapakita ng larawan ng grupo, pangalan, oras ng pagpupulong, at lokasyon ng pagpupulong.
- **Paglalarawan** -- Ang buong paglalarawan ng grupo na nagpapaliwanag ng layunin nito at kung ano ang inaasahan.
- **Mga Lider** -- Mga larawan ng avatar at mga pangalan ng mga lider ng grupo. Maaari mong i-click ang pangalan ng isang lider upang tingnan ang kanilang profile.
- **Mga kaganapan ng kalendaryo** -- Hanggang sa tatlong mga paparating na kaganapan para sa grupo ay ipinakita, bawat isa ay nagpapakita ng petsa at pamagat ng kaganapan. Kung ang grupo ay walang mga paparating na kaganapan, ang seksyon na ito ay nakatagong.
- **Anyo ng makipag-ugnayan** -- Isang anyo na nagbibigay-daan sa iyo na magpadala ng isang mensahe nang direkta sa mga lider ng grupo. Punan ang iyong **unang pangalan**, **pangalawang pangalan**, **email**, **numero ng telepono**, at **mensahe**, pagkatapos ay i-click ang **Ipadala**. Kung mayroon kang maraming mga lider, maaari mong piliin kung alin ang makipag-ugnayan mula sa isang dropdown.

## Pagtingin ng Miyembro (Naka-log In)

Kapag ikaw ay naka-log in, ang pahina ng mga detalye ng grupo ay nagpapakita ng hero section kasama ng isang sidebar ng mga tab. Kung ang iyong grupo ay naiugnay sa isang Lessons.church plan type at ang araling ito ng linggo ay may parent take-home content, isang **Ang araling ito ng linggo** card ay lumalitaw sa pagitan ng hero at ng mga tab (mga miyembro lamang).

Ang mga available na tab ay:

- **Tungkol** -- Ang buong paglalarawan ng grupo, na ginawa gamit ang mayamang text formatting. Ipinakita lamang kung ang grupo ay may paglalarawan.
- **Mga Plano** -- Ang mga plano ng serbisyo ng grupo. Ipinakita lamang kung ang grupo ay may mga plano.
- **Mga Mensahe** -- Isang espasyo para sa mga miyembro ng grupo na magpadala ng mga mensahe at makipag-ugnayan sa isa't isa. Ipinakita lamang sa mga miyembro, at lamang kung ang iyong simbahan ay nag-on ng pang-grupo na chat para sa grupo na ito. Tingnan ang [Mga Usapan ng Grupo](./conversations.md) para sa higit pang mga detalye.
- **Mga Miyembro** -- Isang listahan ng lahat ng miyembro sa grupo, na nagpapakita ng kanilang larawan at pangalan. Maaari mong i-click ang pangalan ng isang miyembro upang bisitahin ang kanilang profile sa [member directory](../community/member-directory.md).
- **Dumalo** -- Nakikita ng mga lider ng grupo (at staff na may pahintulot sa dumalo) lamang. Nagpapahintulot ng pag-track ng sino ang dumalo sa mga pagpupulong ng grupo.
- **Mga Kaganapan** -- Ang kalendaryo ng grupo na nagpapakita ng mga pagpupulong at mga kaganapan. Maaari kang mag-browse ng mga paparating at nakaraang kaganapan.
- **Mga Mapagkukunan** -- Mga ibinabahaging file at link na naglabas para sa grupo. Maaari kang mag-download ng mga nag-upload na file o magbukas ng mga linked na mapagkukunan.

## Mga Kakayahan ng Lider

Kung ikaw ay isang lider ng grupo, mayroon kang karagdagang kakayahan sa pag-edit:

- **Lumikha at mag-edit ng mga kaganapan** -- Magdagdag ng mga kaganapan sa kalendaryo ng grupo mula sa tab ng **Mga Kaganapan**. Kapag lumilikha ng isang kaganapan, maaari mong ilaan ang mga kuwarto at mapagkukunan kasama nito — pumili mula sa mga available na kuwarto at mapagkukunan, magtakda ng mga opsyonal na oras ng setup at teardown, at ang isang kahilingan sa pagbabati ay awtomatikong isinumite para sa pagkumpirma.
- **Pamahalaan ang mga mapagkukunan** -- Mag-upload ng mga file (hanggang sa 100 MB ng pag-iimbak), magdagdag ng mga link, o burahin ang mga umiiral na mapagkukunan.
- **Subaybayan ang dumalo** -- Itala ang dumalo para sa mga sesyon ng grupo mula sa tab ng **Dumalo**.

Upang baguhin ang pangalan, paglalarawan, o listahan ng miyembro ng grupo, gamitin ang B1 Admin. Tingnan ang [Mga Miyembro ng Grupo](../../b1-admin/groups/group-members.md).

## Sumali sa isang Grupo

Kapag ikaw ay naka-log in at hindi pa isang miyembro, isang sumali na knob ay lumalitaw sa pahina ng mga detalye ng grupo. Ang label ng knob ay nakadepende sa patakaran ng sumali ng grupo:

- **Sumali sa Grupo** -- Ang grupo ay bukas. Ang pag-click nito ay kaagad na nagdadagdag sa iyo bilang isang miyembro.
- **Humingi na Sumali** -- Ang grupo ay nangangailangan ng pagkumpirma. Ang pag-click nito ay nagbubukas ng isang dialog kung saan maaari kang isama ng isang opsyonal na mensahe sa lider ng grupo, pagkatapos ay ipadala ang iyong kahilingan. Tingnan ang [Humihiling na Sumali sa isang Grupo](./join-requests.md) para sa mga detalye sa pag-manage ng iyong mga kahilingan.

Kung walang mga knob na lumalitaw, ang grupo ay sarado at ang mga miyembro ay dapat idagdag nang manu-mano ng isang lider o administrator.

:::info
Kung ang isang grupo ay sarado at nais mong sumali, gamitin ang anyo ng makipag-ugnayan sa pagtingin ng bisita upang makipag-ugnayan sa mga lider ng grupo.
:::
