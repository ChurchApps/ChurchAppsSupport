# Mga RSVP sa Event

<div class="article-intro">

Maaaring mangolekta ng mga RSVP ang mga event ng grupo para malaman ng mga lider kung sino ang dadalo. Sa kalendaryo ng iyong grupo, tinatanong ng bawat paparating na event ang "Will you attend?" -- sumagot sa isang tap, magbago ng isip anumang oras, at makita agad kung ilan pa ang pupunta.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Dapat ay [naka-log in](../getting-started/logging-in.md) ka at miyembro ng grupo
- Dapat pinapayagan ang mga RSVP sa event (naka-on ang mga ito bilang default; maaaring i-off ng mga lider ang mga ito kada event)

</div>

## Pagtugon sa isang Event

1. Buksan ang iyong grupo sa member portal at pumunta sa tab na **Events** nito. Sa **Month view**, i-tap ang isang araw para makita ang mga event nito, o lumipat sa **List view** para makita nang sabay-sabay ang lahat ng paparating na event ngayong buwan.
2. Ipinapakita ng bawat card ng paparating na event ang **Will you attend?** na may tatlong button: **Going**, **Maybe**, at **Can't go**.
3. I-tap ang iyong sagot. Magha-highlight ang iyong pinili, at magpapakita ang bawat button ng live na bilang kung ilang tao ang nagbigay ng sagot na iyon.
4. I-tap muli ang naka-highlight mong sagot para i-clear ito, o mag-tap ng ibang button para palitan ang iyong tugon.

Naaangkop ang iyong RSVP sa partikular na okasyong iyon -- para sa lingguhang pagtitipon, hiwalay mong sinasagot ang event ng bawat linggo.

## Para sa mga Lider ng Grupo

- **Pagtingin sa mga tugon** -- May makikitang button na **View responses** ang mga lider sa bawat card ng event. Binubuksan nito ang sheet na **Responses** na naglilista sa lahat ayon sa sagot -- Going, Maybe, at Can't go. Kung wala pang sumasagot, ipinapakita nito ang "No responses yet."
- **Pag-on o pag-off ng mga RSVP** -- Kapag gumagawa o nag-e-edit ng event, gamitin ang switch na **Allow RSVPs**. Walang ipinapakitang response button ang mga event na naka-off ang RSVP. Ganito rin ang opsyon ng mga staff na gumagawa ng mga event nang maramihan mula sa B1 Admin -- tingnan ang [Kalendaryo ng Grupo](../../b1-admin/groups/group-calendar#event-rsvps).

:::tip
Ang mga RSVP ay magaan na bilang ng dadalo. Kung kailangan ng iyong event ang mga detalye ng signup, pamamahala ng kapasidad, o bayad, gamitin na lang ang [event registration](../events/registering).
:::
