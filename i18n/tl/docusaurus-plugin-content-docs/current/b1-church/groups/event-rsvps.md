# Mga RSVP sa Event

<div class="article-intro">

Maaaring mangolekta ng RSVP ang mga event ng grupo para malaman ng mga lider kung sino ang darating. Sa pahina at calendar ng iyong grupo, bawat paparating na event ay may mga button na **Going**, **Maybe**, at **Can't go** -- sumagot sa isang tap lamang, magbago ng isip anumang oras, at makita agad kung ilan pa ang pupunta.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan kang [naka-log in](../getting-started/logging-in.md) at miyembro ng grupo
- Dapat pinapayagan ang RSVP sa event (naka-on ang mga ito bilang default; maaaring i-off ng mga lider para sa bawat event)

</div>

## Pagsagot sa Isang Event {#responding-to-an-event}

1. Buksan ang iyong grupo sa member portal. Lumalabas ang susunod na event ng grupo sa seksyong **Next event**. Para sa iba pang event, i-tap ang **All events**: sa view na **Calendar**, i-tap ang isang araw para makita ang mga event nito, o lumipat sa **List** para makita ang lahat ng paparating na event ngayong buwan nang sabay-sabay.
2. Ang bawat paparating na event ay may tatlong button: **Going**, **Maybe**, at **Can't go**.
3. I-tap ang iyong sagot. Naka-highlight ang pinili mo, at ipinapakita ng bawat button ang live na bilang ng mga taong nagbigay ng ganoong sagot.
4. I-tap muli ang naka-highlight mong sagot para burahin ito, o i-tap ang ibang button para baguhin ang iyong sagot.

Partikular sa pagkakataong iyon ang iyong RSVP -- para sa lingguhang pagpupulong, sumasagot ka sa event ng bawat linggo nang hiwalay. Kapag tapos na ang isang event, mawawala ang mga button nito; mananatiling nakikita ang iyong sagot bilang badge sa tabi ng event.

## Para sa mga Lider ng Grupo {#for-group-leaders}

- **Pagtingin sa mga sagot** -- Makikita ng mga lider ang link na **View responses** sa bawat event sa calendar ng grupo (**All events**), kasama ang mga event na tapos na. Binubuksan nito ang sheet na **Responses** na naglilista ng lahat ayon sa sagot -- Going, Maybe, at Can't go. Kung wala pang sumasagot, ipinapakita nito ang "No responses yet."
- **Pag-on o pag-off ng mga RSVP** -- Kapag gumagawa o nag-e-edit ng event, gamitin ang switch na **Allow RSVPs**. Ang mga event na naka-off ang RSVP ay walang mga button ng pagsagot. Ang staff na gumagawa ng mga event nang maramihan mula sa B1 Admin ay may parehong opsyon -- tingnan ang [Group Calendar](../../b1-admin/groups/group-calendar.md#event-rsvps).

:::tip
Magaan na bilang lamang ang mga RSVP. Kung kailangan ng iyong event ng detalye sa pagpapatala, pamamahala ng kapasidad, o bayad, gamitin na lang ang [pagpaparehistro sa event](../events/registering.md).
:::
