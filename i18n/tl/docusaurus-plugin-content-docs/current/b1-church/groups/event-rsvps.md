# Mga RSVP sa Event

<div class="article-intro">

Maaaring mangolekta ng RSVP ang mga event ng group upang malaman ng mga lider kung sino ang darating. Sa pahina at kalendaryo ng iyong group, bawat paparating na event ay may mga button na **Going**, **Maybe**, at **Can't go** -- sumagot sa pamamagitan ng isang tap, magbago ng isip anumang oras, at makita agad kung ilan ang iba pang pupunta.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Dapat ka [naka-log in](../getting-started/logging-in.md) at miyembro ng group
- Dapat pinapayagan ang RSVP para sa event (naka-on ito bilang default; maaaring i-off ng mga lider ang RSVP para sa bawat event)

</div>

## Pagsagot sa Isang Event

1. Buksan ang iyong group sa member portal. Lalabas ang susunod na event ng group sa seksyong **Next event**. Para sa iba pang event, i-tap ang **All events**: sa view na **Calendar**, i-tap ang isang araw upang makita ang mga event nito, o lumipat sa **List** upang makita ang lahat ng paparating na event ngayong buwan nang sabay-sabay.
2. Ang bawat paparating na event ay may tatlong button: **Going**, **Maybe**, at **Can't go**.
3. I-tap ang iyong sagot. Made-highlight ang iyong pinili, at ang bawat button ay nagpapakita ng live na bilang kung ilang tao ang nagbigay ng sagot na iyon.
4. I-tap muli ang iyong naka-highlight na sagot upang alisin ito, o i-tap ang ibang button upang baguhin ang iyong tugon.

Ang iyong RSVP ay nalalapat sa partikular na pangyayaring iyon -- para sa lingguhang pagpupulong, sumasagot ka sa bawat event ng linggo nang hiwalay.

## Para sa Mga Lider ng Group

- **Pagtingin sa mga tugon** -- Makikita ng mga lider ang link na **View responses** sa bawat event sa kalendaryo ng group (**All events**). Bubukas ito ng sheet na **Responses** na naglilista ng lahat ayon sa sagot -- Going, Maybe, at Can't go. Kung wala pang sumasagot, ipinapakita nito ang "No responses yet."
- **Pag-on o pag-off ng RSVP** -- Kapag gumagawa o nag-e-edit ng event, gamitin ang switch na **Allow RSVPs**. Ang mga event na naka-off ang RSVP ay hindi nagpapakita ng mga button ng tugon. May parehong opsyon ang mga staff na gumagawa ng event nang maramihan mula sa B1 Admin -- tingnan ang [Group Calendar](../../b1-admin/groups/group-calendar#event-rsvps).

:::tip
Magaan na bilang lamang ang mga RSVP. Kung kailangan ng iyong event ng detalye sa pag-sign up, pamamahala ng kapasidad, o pagbabayad, gamitin ang [event registration](../events/registering) sa halip.
:::
