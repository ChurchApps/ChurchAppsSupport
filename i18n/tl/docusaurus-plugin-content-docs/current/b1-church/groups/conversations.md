# Mga Usapan ng Grupo

<div class="article-intro">

Ang group chat ay isang espasyo kung saan maaaring mag-post ng mga mensahe at makipag-ugnayan ang mga miyembro ng grupo sa isa't isa. Gamitin ang mga usapan para talakayin ang mga paksa, magbahagi ng mga update, at manatiling konektado sa iyong grupo sa pagitan ng mga pagpupulong.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Dapat ka munang [naka-log in](../getting-started/logging-in.md) sa iyong B1.church account.
- Dapat ka ring miyembro ng grupo para ma-access ang group chat. Tingnan ang [Mga Detalye ng Grupo](./group-details.md) para malaman kung paano sumali sa isang grupo.

</div>

## Pag-access sa mga Usapan

1. Pumunta sa pahina ng detalye ng grupo sa pamamagitan ng pag-click sa isang grupo mula sa [pahina ng mga grupo](./browsing-groups.md).
2. Siguraduhing naka-log in ka.
3. I-tap ang **Buksan ang chat** sa ilalim ng pangalan ng grupo, o sa seksyong **Mga Mensahe**, na nagpapakita ng preview ng mga pinakabagong mensahe. Magbubukas ang chat nang buong screen; i-tap ang back arrow para bumalik sa grupo.

## Mga Usapan at Anunsyo

Maaaring may dalawang feed ang group chat, depende sa kung alin sa mga ito ang na-enable ng iyong simbahan para sa grupong ito. Ang label sa itaas ng pangalan ng grupo sa itaas ng chat ay nagpapakita kung nasaan ka:

- **Chat** -- Mga talakayan, kung saan maaaring mag-post ng mga mensahe at sumagot sa iba ang sinumang miyembro ng grupo.
- **Mga Anunsyo** -- Mga mensaheng ipinost ng mga lider ng grupo na mahalaga para sa lahat ng miyembro. Maaaring basahin ng mga regular na miyembro ang mga anunsyo at mag-react sa mga ito, ngunit mga lider lang ang maaaring mag-post; sa halip na kahon ng mensahe, makikita ng mga regular na miyembro ang "Mga lider ng grupo lang ang maaaring mag-post ng mga anunsyo."

Kapag parehong naka-on ang dalawang feed, may **Anunsyo** na strip sa itaas ng chat na nagpapakita ng pinakabagong anunsyo. I-tap ang **Lahat ng anunsyo** para buksan ang feed ng mga anunsyo, at ang **Bumalik sa chat** para bumalik sa mga talakayan. (Makikita lang ng mga miyembro ang strip kapag may kahit isang anunsyo na ang grupo.)

Kung isa lang sa dalawang feed ang na-enable ng iyong simbahan para sa grupong ito, diretsong bubukas ang chat sa feed na iyon. Kung parehong naka-off, walang chat ang grupo at walang seksyong **Mga Mensahe**.

## Pag-post ng Mensahe

1. I-tap ang **Buksan ang chat** sa iyong pahina ng grupo.
2. Siguraduhing nasa feed ka ng **Chat** (i-tap ang **Bumalik sa chat** kung nagbabasa ka ng mga anunsyo).
3. I-type ang iyong mensahe sa kahong **Magpadala ng mensahe…**.
4. I-tap ang send button para ibahagi ito sa grupo. Sa telepono o tablet, ang return key ay nagsisimula ng bagong linya; sa computer, ang **Enter** ang nagpapadala at ang **Shift+Enter** ang nagsisimula ng bagong linya.

Makikita ng lahat ng miyembro ng grupo ang iyong mensahe. Ipinapakita ng bawat mensahe kung kailan ito ipinadala: ang oras para sa mga mensaheng ngayong araw, "kahapon" at ang oras para sa mga kahapon, o ang petsa at oras para sa mas matatandang mensahe.

## Pag-format ng Iyong Mensahe {#formatting-your-message}

Maaari kang maglagay ng bold na teksto, italics, at mga listahan sa isang mensahe:

1. I-type ang iyong mensahe, pagkatapos ay i-highlight ang mga salita o linyang gusto mong i-format.
2. May lalabas na maliit na toolbar sa itaas ng kahon ng mensahe na may mga button na **Bold**, **Italic**, **Bulleted list**, at **Numbered list**. I-tap ang isa para ilapat ito. I-tap ulit ang parehong button habang naka-highlight pa rin ang teksto para alisin ito.
3. Ipadala ang mensahe gaya ng karaniwan.

Sa computer, maaari mo ring pindutin ang **Ctrl+B** (o **Cmd+B** sa Mac) para sa bold at **Ctrl+I** (**Cmd+I**) para sa italic.

Nagdaragdag ang toolbar ng simpleng markdown sa iyong teksto: `**bold**`, `_italic_`, isang `- ` sa simula ng linya para sa bulleted list, at `1. ` para sa numbered list. Maaari mo rin itong i-type nang mag-isa. Nakikita ng lahat sa chat ang naka-format na mensahe, nananatiling clickable ang mga web link, at napapanatili ang mga line break. Gumagana rin ang parehong formatting sa mga anunsyo, [mga tala ng lider](./group-details.md#leader-notes), at mga pribadong mensahe.

## Pag-edit o Pagtanggal ng Iyong mga Mensahe

Maaari mong i-edit o tanggalin ang anumang mensaheng ipinost mo:

1. I-tap ang button na **more options** (⋮) sa ilalim ng iyong mensahe para buksan ang menu ng mensahe.
2. Piliin ang **I-edit** para baguhin ang teksto ng mensahe, o ang **Tanggalin** para alisin ito.
   - Kapag nag-e-edit, mailo-load pabalik ang teksto ng mensahe sa input field na may tala na **Ine-edit ang mensahe** sa itaas nito (i-tap ang **Kanselahin** para huminto sa pag-e-edit). Gawin ang iyong mga pagbabago at ipadala para i-save ang mga ito.
   - Kapag nagtatanggal, lalabas ang kumpirmasyong **Tanggalin ang mensahe?**. I-tap ang **Tanggalin** para permanenteng alisin ang mensahe para sa lahat ng nasa usapan.

:::info
Maaari mo lang i-edit ang sarili mong mga mensahe. Maaari ring magtanggal ng mensahe ng ibang miyembro ang mga lider ng grupo; nakikita lang ng mga regular na miyembro ang mga opsyon sa sarili nilang mga mensahe.
:::

## Pag-react sa mga Mensahe

Sa group chat, maaari kang mag-react sa anumang mensahe gamit ang isang emoji:

1. I-tap ang button na **Magdagdag ng reaction** sa ilalim ng isang mensahe.
2. Pumili ng isa sa anim na emoji: 👍 ❤️ 😂 🎉 🙏 😮.

Lalabas ang mga reaction bilang maliliit na chip sa ilalim ng mensahe, kasama ang bilang ng mga taong gumamit ng bawat isa. Naka-highlight ang sarili mong reaction. I-tap ang chip (o piliin ulit ang parehong emoji) para alisin ito, o pumili ng ibang emoji para magdagdag ng isa pa. Live na lumalabas ang mga reaction para sa lahat ng nasa chat.

:::tip
Ang mga usapan ng grupo ay nasa chat ng bawat grupo. Wala na ang dating pinagsamang [Timeline](../community/timeline.md) feed. Ang mga aktibidad na nangangailangan ng iyong atensyon ay dumarating bilang notification sa ilalim ng **bell** icon sa app bar.
:::

## Mga Tampok para sa Lider

Kung ikaw ay lider ng grupo, may karagdagang kakayahan ka sa group chat:

- **Mag-post ng mga anunsyo** -- I-tap ang **Lahat ng anunsyo** (o buksan ang chat kapag mga anunsyo lang ang naka-on) at mag-post ng mga mensaheng mababasa ng lahat ng miyembro ng grupo.
- **Mag-alis ng mga mensahe** -- Tanggalin ang mensahe ng sinumang miyembro mula sa menu ng mensahe (⋮).
- **Mag-post sa mga talakayan** -- Maaari ka ring lumahok sa mga regular na talakayan gaya ng sinumang miyembro.

:::info
Tiyak sa bawat grupo ang mga usapan. Hindi lalabas sa usapan ng ibang grupo ang mga mensaheng ipinost mo sa isang grupo.
:::
