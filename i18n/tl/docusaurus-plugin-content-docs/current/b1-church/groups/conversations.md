# Mga Usapan ng Grupo

<div class="article-intro">

Ang group chat ay isang espasyo kung saan maaaring mag-post ng mensahe ang mga miyembro ng grupo at makipag-ugnayan sa isa't isa. Gamitin ang mga usapan para talakayin ang mga paksa, magbahagi ng update, at manatiling konektado sa iyong grupo sa pagitan ng mga pagpupulong.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan kang [naka-log in](../getting-started/logging-in.md) sa iyong B1.church account.
- Dapat miyembro ka ng grupo para ma-access ang group chat. Tingnan ang [Mga Detalye ng Grupo](./group-details.md) para malaman kung paano sumali sa grupo.

</div>

## Pag-access sa Mga Usapan {#accessing-conversations}

1. Pumunta sa detail page ng grupo sa pamamagitan ng pag-click sa isang grupo mula sa [pahina ng mga grupo](./browsing-groups.md).
2. Siguraduhing naka-log in ka.
3. I-tap ang **Open chat** sa ilalim ng pangalan ng grupo, o sa seksyong **Messages**, na nagpapakita ng preview ng pinakabagong mga mensahe. Bubukas ang chat sa full screen; i-tap ang back arrow para bumalik sa grupo.

## Mga Talakayan at Anunsyo {#discussions-and-announcements}

Maaaring magkaroon ng dalawang feed ang group chat, depende sa kung alin ang in-on ng iyong simbahan para sa grupong ito. Ipinapakita ng label sa itaas ng pangalan ng grupo sa itaas ng chat kung alin ang nasa iyo:

- **Chat** -- Mga talakayan, kung saan maaaring mag-post ng mensahe at sumagot sa iba ang sinumang miyembro ng grupo.
- **Announcements** -- Mga mensaheng ipino-post ng mga lider ng grupo na mahalaga para makita ng lahat ng miyembro. Maaaring basahin ng mga regular na miyembro ang mga anunsyo at mag-react sa mga ito, ngunit mga lider lamang ang maaaring mag-post; sa halip na message box, makikita ng mga regular na miyembro ang "Only group leaders can post announcements."

Kapag parehong naka-on ang dalawang feed, may strip na **Announcement** sa itaas ng chat na nagpapakita ng pinakabagong anunsyo. I-tap ang **All announcements** para buksan ang feed ng mga anunsyo, at ang **Back to chat** para bumalik sa mga talakayan. (Makikita lamang ng mga miyembro ang strip kapag may kahit isang anunsyo ang grupo.)

Kung isa lamang sa dalawang feed ang in-on ng iyong simbahan para sa grupong ito, direktang bubukas ang chat sa feed na iyon. Kung parehong naka-off, walang chat ang grupo at walang seksyong **Messages**.

## Pag-post ng Mensahe {#posting-a-message}

1. I-tap ang **Open chat** sa pahina ng iyong grupo.
2. Siguraduhing nasa feed ka ng **Chat** (i-tap ang **Back to chat** kung nagbabasa ka ng mga anunsyo).
3. I-type ang iyong mensahe sa kahon na **Send a message…**.
4. I-tap ang send button para ibahagi ito sa grupo. Sa telepono o tablet, ang return key ay nagsisimula ng bagong linya; sa computer, ang **Enter** ay nagpapadala at ang **Shift+Enter** ay nagsisimula ng bagong linya.

Makikita ng lahat ng miyembro ng grupo ang iyong mensahe. Ipinapakita ng bawat mensahe kung kailan ito ipinadala: ang oras para sa mga mensahe ngayong araw, "yesterday" at ang oras, o ang petsa at oras para sa mas lumang mensahe.

## Pag-format ng Iyong Mensahe {#formatting-your-message}

Maaari kang magdagdag ng bold na teksto, italics, at listahan sa isang mensahe:

1. I-tap ang message box. Habang ito ay napili, may lalabas sa ilalim nitong hanay ng mga button na **Bold**, **Italic**, **Bulleted list**, at **Numbered list**.
2. I-type ang iyong mensahe, i-highlight ang mga salita o linyang nais mong i-format, at i-tap ang isang button para ilapat ito. I-tap muli ang parehong button habang naka-highlight pa rin ang teksto para alisin ito. Kapag walang naka-highlight, ina-format ng mga list button ang linyang kinaroroonan mo.
3. Ipadala ang mensahe gaya ng karaniwan.

Sa computer, maaari mo ring pindutin ang **Ctrl+B** (o **Cmd+B** sa Mac) para sa bold at **Ctrl+I** (**Cmd+I**) para sa italic.

Nagdaragdag ang toolbar ng simpleng markdown sa iyong teksto: `**bold**`, `_italic_`, ang `- ` sa simula ng linya para sa bulleted list, at `1. ` para sa numbered list. Maaari mo rin itong i-type nang mag-isa. Nakikita ng lahat sa chat ang naka-format na mensahe, nananatiling clickable ang mga web link (nagbubukas ang mga ito sa bagong tab), ang link sa larawan (.jpg, .png, .gif, at katulad) ay nagpapakita ng larawan sa ilalim ng mensahe, at pinananatili ang mga line break. Gumagana rin ang parehong format sa mga anunsyo, [mga tala ng lider](./group-details.md#leader-notes), at mga pribadong mensahe.

## Pag-edit o Pagbura ng Iyong Mga Mensahe {#editing-or-deleting-your-messages}

Maaari mong i-edit o burahin ang alinmang mensaheng ipinost mo:

1. I-tap ang button na **more options** (⋮) sa ilalim ng iyong mensahe para buksan ang menu ng mensahe.
2. Piliin ang **Edit** para baguhin ang teksto ng mensahe, o **Delete** para alisin ito.
   - Kapag nag-e-edit, babalik sa input field ang teksto ng mensahe na may tala na **Editing message** sa itaas (i-tap ang **Cancel** para itigil ang pag-edit). Gawin ang iyong mga pagbabago at ipadala para i-save ang mga ito.
   - Kapag nagbubura, lalabas ang kumpirmasyong **Delete message?**. I-tap ang **Delete** para permanenteng alisin ang mensahe para sa lahat sa usapan.

:::info
Mga sarili mo lamang na mensahe ang maaari mong i-edit. Maaari ring burahin ng mga lider ng grupo ang mga mensahe ng ibang miyembro; nakikita lamang ng mga regular na miyembro ang mga opsyon sa sarili nilang mensahe.
:::

## Pag-react sa Mga Mensahe {#reacting-to-messages}

Sa group chat, maaari kang mag-react sa alinmang mensahe gamit ang emoji:

1. I-tap ang button na **Add reaction** sa ilalim ng isang mensahe.
2. Pumili ng isa sa anim na emoji: 👍 ❤️ 😂 🎉 🙏 😮.

Lumilitaw ang mga reaction bilang maliliit na chip sa ilalim ng mensahe, kasama ang bilang ng mga taong gumamit ng bawat isa. Naka-highlight ang sarili mong reaction -- i-tap ang chip (o piliin muli ang parehong emoji) para alisin ito, o pumili ng ibang emoji para magdagdag ng isa pa. Agad na nakikita ng lahat sa chat ang mga reaction.

:::tip
Nasa chat ng bawat grupo ang mga usapan ng grupo -- wala na ang dating pinagsamang [Timeline](../community/timeline.md) feed. Ang mga aktibidad na nangangailangan ng iyong pansin ay dumarating bilang abiso sa ilalim ng icon na **kampana** sa app bar.
:::

## Mga Feature ng Lider {#leader-features}

Kung ikaw ay lider ng grupo, may karagdagang kakayahan ka sa group chat:

- **Mag-post ng anunsyo** -- I-tap ang **All announcements** (o buksan ang chat kapag announcements lamang ang naka-on) at mag-post ng mga mensaheng mababasa ng lahat ng miyembro ng grupo.
- **Mag-alis ng mga mensahe** -- Burahin ang mensahe ng sinumang miyembro mula sa message menu (⋮).
- **Mag-post ng mga talakayan** -- Maaari ka ring lumahok sa regular na talakayan gaya ng alinmang miyembro.

:::info
Tiyak sa bawat grupo ang mga usapan. Hindi lilitaw sa usapan ng ibang grupo ang mga mensaheng ipo-post mo sa isang grupo.
:::
