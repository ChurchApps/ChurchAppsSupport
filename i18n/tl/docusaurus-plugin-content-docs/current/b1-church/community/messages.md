# Mga Mensahe at Abiso

<div class="article-intro">

Pinagsasama ng member portal ang iyong mga pribadong usapan at ang iyong mga abiso. Magpadala ng pribadong mensahe sa sinumang nasa direktoryo ng iyong simbahan, at gamitin ang iyong **Inbox** para malaman ang lahat ng nangangailangan ng iyong pansin -- mga post ng grupo, mga kahilingan sa paglilingkod, mga gawain, at iba pa.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Kailangan kang [naka-log in](../getting-started/logging-in.md). Kung naka-sign out ka, ang mga screen na ito ay magpapakita ng button na **Sign In** sa halip.

</div>

## Pagbukas ng Iyong Mga Mensahe {#opening-your-messages}

I-tap ang **kampana** sa app bar para makita agad ang iyong pinakabagong usapan at mga abiso (tingnan ang [Mga Abiso at Mensahe](../getting-started/navigating.md#notifications-and-messages)). Para sa buong listahan ng mga usapan, buksan ang **Messages** (`/mobile/messages`) -- mula sa **Messages** sa seksyong Inbox ng iyong [Me page](../getting-started/me-page.md#inbox), o sa **View all messages** sa iyong inbox.

Nakalista sa pahina ng **Messages** ang iyong mga usapan, mula sa pinakabago. Ipinapakita ng bawat hilera ang pangalan at larawan ng kabilang tao, preview ng pinakabagong mensahe, at kung kailan ito ipinadala. Ang mga usapang may hindi mo pa nababasa ay ipinapakita nang naka-bold na may badge na **New**, at ang bilang ng mga hindi pa nababasang usapan ay lumalabas sa ilalim ng pamagat ng pahina. I-type sa **Search conversations** para i-filter ayon sa pangalan o text ng mensahe.

## Pagsisimula ng Usapan {#starting-a-conversation}

1. I-tap ang **New message** sa pahina ng Messages (o ang **New message** sa panel ng kampana).
2. Nakalista muna ang iyong mga kamakailang **Recent** na contact. Para maghanap ng iba, i-type ang kanilang pangalan sa **Search for a person to message** at piliin sila mula sa **Matches**.
3. I-type ang iyong mensahe at i-tap ang send button.

Maaari ka ring magsimula ng usapan mula sa profile ng isang tao sa [direktoryo ng miyembro](./member-directory.md#viewing-a-member-profile) sa pamamagitan ng pag-tap sa **Message**.

## Pagpapadala at Pag-format ng Mga Mensahe {#sending-and-formatting-messages}

I-type sa kahon na **Type a message…** sa ibaba ng usapan. I-tap ang smiley-face button para magdagdag ng emoji. Sa computer, ang **Enter** ang nagpapadala ng mensahe at ang **Shift+Enter** ay nagsisimula ng bagong linya; sa telepono, ang **Enter** ay nagsisimula ng bagong linya at kailangan mong i-tap ang send button para magpadala.

Para gawing bold o italic ang text, o magdagdag ng listahan, i-highlight ito at gamitin ang hanay ng mga button sa ilalim ng message box -- pareho sa paraan sa [group chat](../groups/conversations.md#formatting-your-message).

Lumalabas agad ang mga bagong mensahe para sa parehong tao habang bukas ang usapan, at ipinapakita ng bawat mensahe kung kailan ito ipinadala. I-tap ang pangalan ng tao sa itaas ng usapan para buksan ang kanyang profile sa direktoryo.

## Pag-edit o Pagbura ng Iyong Mga Mensahe {#editing-or-deleting-your-messages}

I-tap ang button na **⋮** sa tabi ng isa sa sarili mong mensahe, pagkatapos ay:

- **Edit** -- ibinabalik ang mensahe sa message box. Baguhin ito at ipadala muli; i-tap ang **Cancel** sa tabi ng **Editing message** para itigil ang pag-edit.
- **Delete** -- humihingi ng kumpirmasyon, pagkatapos ay binubura ang mensahe para sa lahat sa usapan.

Mga mensaheng ipinadala mo lamang ang maaari mong i-edit o burahin.

## Pagbura ng Usapan {#deleting-a-conversation}

Sa pahina ng Messages, i-tap ang trash icon sa tabi ng usapan at kumpirmahin sa pamamagitan ng **Delete**. Inaalis nito ang usapan sa iyong listahan.

## Kapag Hindi Ka Makapagpadala ng Mensahe sa Isang Tao {#when-you-cant-message-someone}

- Kung ang isang tao ay nasa ilalim ng [pinakamababang edad para sa pribadong mensahe](/docs/b1-admin/settings/mobile-app#member-directory--messaging-settings) ng iyong simbahan, walang button na **Message** sa kanyang profile, at ang usapan sa kanila ay magpapakita ng "Messaging isn't available for this profile." sa halip na message box.
- Kung hindi maipadala ang mensahe, makikita mo ang "Message failed to send." Suriin ang iyong koneksyon at subukan muli.

## Ang Iyong Inbox {#your-inbox}

I-tap ang **See all** sa ibaba ng panel ng kampana, o ang **Open inbox** sa iyong Me page, para buksan ang iyong **Inbox** (`/mobile/notifications`). Sa ilalim ng pamagat, ipinapakita nito kung ilan ang hindi mo pa nababasang mensahe at bagong abiso, kasama ang button na **Notification Preferences** para piliin [kung ano ang gusto mong ipaalam sa iyo](../getting-started/notification-preferences.md).

- **Messages** -- ang iyong pinakabagong usapan, kasama ang **View all messages** para buksan ang pahina ng Messages.
- **Notifications** -- ang iyong pinakabagong abiso, na may badge na **New** sa mga hindi pa nababasa. I-tap ang isang abiso para pumunta sa grupo, plano, usapan, o pahinang pinanggalingan nito.
- **Push notifications** -- i-on o i-off ang push notifications para sa device na ginagamit mo. Tingnan ang [Push Notifications sa Device na Ito](../getting-started/notification-preferences.md#push-notifications-on-this-device).

I-tap ang **View all notifications** para makita ang lahat ng abiso, na nakapangkat sa ilalim ng **Today**, **This week**, at **Earlier**. I-tap ang **Unread** para ipakita lamang ang mga hindi mo pa nababasa, o ang **All** para makita muli ang lahat. I-tap ang trash icon sa tabi ng isang abiso para burahin ito, o i-tap ang **Clear All** at kumpirmahin para permanenteng alisin ang lahat ng abiso sa iyong listahan. I-tap ang **Back to Inbox** para bumalik.
