# Direktoryo ng Miyembro

<div class="article-intro">

Ang direktoryo ng miyembro ay nagbibigay-daan sa iyong mag-browse at maghanap ng mga tao sa iyong simbahan. Kailangan mo mang hanapin ang isang kapwa miyembro ng grupo o makahanap ng bagong kakilala, pinapadali ng direktoryo ang pagkonekta sa pamilya ng iyong simbahan.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- Dapat kang naka-[log in](../getting-started/logging-in.md) sa iyong account sa B1.church.
- Available lamang ang direktoryo sa **mga miyembro at tauhan**. Makakakita ng mensaheng "Members Only" ang mga bisita at dumadalo na hindi pa naging miyembro.

</div>

## Pag-access sa Direktoryo

1. I-click ang **Community** sa [sidebar navigation](../getting-started/navigating.md).
2. Nilo-load ang direktoryo na may listahan ng lahat ng nakikitang miyembro ng simbahan sa kaliwang bahagi ng pahina.

## Paghahanap ng mga Miyembro

Gumagamit ang pahina ng isang master-detail na layout. Sa kaliwang bahagi, mayroon kang dalawang paraan upang makahanap ng mga tao:

### Maghanap ayon sa Pangalan

1. Tiyaking napili ang filter na **People** sa itaas ng lugar ng paghahanap.
2. I-type ang isang pangalan sa search box.
3. I-click ang **Search** o pindutin ang **Enter** upang makita ang mga resulta.

Kung iiwan mong blangko ang search box at i-click ang **Search**, ipinapakita ang buong listahan ng direktoryo.

### Maghanap ayon sa Grupo

1. I-click ang filter na **Groups** sa itaas ng lugar ng paghahanap.
2. Pumili ng grupo mula sa dropdown list.
3. I-click ang **Search** upang makita ang lahat ng miyembro ng grupong iyon.

:::tip
Ang paghahanap ayon sa grupo ay isang mabilisang paraan upang mahanap ang isang taong nakilala mo sa isang [pagpupulong ng grupo](../groups/browsing-groups.md) ngunit hindi mo masyadong maalala ang pangalan.
:::

## Pagba-browse sa Direktoryo

Nakalista ang mga miyembro nang alpabetiko ayon sa apelyido at nakagrupo sa ilalim ng mga letter heading (A, B, C, at iba pa). Ipinapakita ng bawat entry ang larawan ng miyembro, display name, at pangalan ng sambahayan, kaya madaling maiskan ang listahan.

## Pagtingin sa Profile ng isang Miyembro

I-click ang sinumang miyembro sa listahan upang buksan ang kanilang profile sa detail panel sa kanan. Ipinapakita ng profile ang impormasyon ng miyembro ayon sa nakonpigura ng iyong simbahan, na maaaring kasama ang mga detalye ng contact, mga miyembro ng sambahayan, at mga pagkasapi sa grupo.

Maaari mong i-click ang mga miyembro ng sambahayan sa loob ng isang profile upang mag-navigate din sa kanilang mga profile.

:::info
Nakadepende ang impormasyong nakikita sa bawat profile sa mga setting ng privacy at direktoryo ng iyong simbahan. Hindi lahat ng field ay maaaring ipakita para sa bawat miyembro.
:::
