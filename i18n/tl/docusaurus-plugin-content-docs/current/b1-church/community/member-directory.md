# Member Directory

<div class="article-intro">

Hinahayaan ka ng member directory na mag-browse at maghanap ng mga tao sa iyong simbahan. Kailangan mo mang hanapin ang kapwa miyembro ng grupo o may bagong taong nais kilalanin, pinapadali ng directory ang pakikipag-ugnayan sa iyong pamilya sa simbahan.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- Dapat ka nang [naka-log in](../getting-started/logging-in.md) sa iyong B1.church account.
- Sinusunod ng kung sino ang maaaring magbukas ng directory ang setting ng iyong simbahan na **Show in Directory**: **Admins Only**, **Members and Above** (ang default), **Regular Attendees and Above**, o **Visitors and Above**. Ang mga nasa ibaba ng antas na iyon ay makakakita ng mensaheng "Members Only" sa halip. Palaging makakabukas ng directory ang mga staff na may People > View permission, at kapag **Admins Only** ang naka-set, sila lamang ang makakabukas nito -- kahit ang mga may Staff membership status ay hindi makakabukas. Hindi kailanman makakabukas nito ang mga may Guest o Inactive status. Tingnan ang [Member Directory & Messaging Settings](../../b1-admin/settings/mobile-app.md#member-directory--messaging-settings).

</div>

## Pagbubukas ng Directory

1. I-tap ang **Community** sa [tab bar o sa pahinang More](../getting-started/navigating.md) (maaaring nabigyan ito ng ibang pangalan ng iyong simbahan).
2. Magbubukas ang **Directory** na may bilang ng mga tao at listahan ng lahat ng nakikitang miyembro ng simbahan.

## Paghahanap ng Mga Miyembro

I-type ang pangalan sa kahong **Search Members** sa itaas ng listahan. Nagfi-filter ang listahan habang nagta-type ka, at naka-highlight ang tumutugmang bahagi ng bawat pangalan. I-clear ang kahon para makita muli ang buong directory.

## Pag-browse ng Directory

Nakapangkat ang mga miyembro sa ilalim ng mga letter heading (A, B, C, at iba pa) ayon sa unang letra ng kanilang unang pangalan, at naka-sort ayon sa apelyido sa loob ng bawat letra. Ipinapakita ng bawat entry ang larawan ng miyembro, display name, at membership status, kaya madaling i-scan ang listahan.

## Pagtingin sa Profile ng Miyembro

I-tap ang alinmang miyembro sa listahan para buksan ang kanyang profile. Ipinapakita ng profile ang pangalan, larawan, at membership status ng miyembro, kasama ang mga button para **Message** siya, **Call** siya, o magpadala ng **Text** kapag available ang impormasyong iyon. Sa ibaba nito, ipinapakita ng seksyong **Contact Information** ang mga detalyeng ibinahagi ng iyong simbahan at ng miyembro, gaya ng email, telepono, at address, at ipinapakita ng **Household Members** ang iba pang tao sa kanyang household.

Maaari mong i-tap ang mga miyembro ng household sa loob ng isang profile para pumunta rin sa kanilang mga profile. Sa sarili mong profile, dadalhin ka ng button na **Edit profile** sa [Editing Your Profile](../getting-started/editing-your-profile.md).

:::info
Nakadepende sa mga setting ng privacy at directory ng iyong simbahan ang impormasyong nakikita sa bawat profile. Maaaring hindi lahat ng field ay ipinapakita para sa bawat miyembro.
:::

:::info
Nananatiling nakikita sa directory ang mga miyembrong nasa ilalim ng [minimum age para sa private messages](/docs/b1-admin/settings/mobile-app#member-directory--messaging-settings) ng iyong simbahan, ngunit hindi available ang opsyong magpadala sa kanila ng pribadong mensahe.
:::
