# Paunang Setup

<div class="article-intro">

Pagkatapos gumawa ng iyong account at simbahan, may ilang mahahalagang hakbang na kailangan mong i-configure bago mag-imbita ng iyong team. Ginagabayan ka ng gabay na ito sa inirerekomendang pagkakasunod-sunod ng setup para handa na ang iyong simbahan mula sa unang araw.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- [Gumawa ng iyong account](./create-account.md) at iparehistro ang iyong simbahan
- Ihanda ang logo ng iyong simbahan at mga branding asset (opsyonal ngunit inirerekomenda)

</div>

## Hakbang 1: I-configure ang Impormasyon ng Iyong Simbahan

1. Buksan ang [menu ng Jump](../b1-admin/introduction.md#getting-around-with-the-jump-menu) (ang search bar sa kaliwang itaas ng B1 Admin), i-expand ang **Settings**, at i-click ang **Settings**.
2. Sa seksyong **Church Information**, i-click ang **Edit**.
3. Ilagay ang **pangalan**, **subdomain**, at **address** ng iyong simbahan.
4. I-click ang **Save** para ma-apply ang iyong mga pagbabago.

## Hakbang 2: I-setup ang Branding Mo

1. Sa menu ng Jump, piliin ang **Website > Appearance**.
2. I-upload ang iyong **logo ng simbahan**.
3. I-configure ang iba pang opsyon sa branding gaya ng mga kulay at larawan.
4. Lalabas ang iyong branding sa iyong B1.church website at sa B1 App.

:::tip
Ang pagkakaroon ng logo at branding na handa bago mag-imbita ng mga miyembro ng team ay nagbibigay ng magandang unang impresyon kapag nag-log in sila.
:::

## Hakbang 3: I-configure ang mga Role at Mag-imbita ng Iyong Team

1. Sa menu ng Jump, piliin ang **Settings > Roles**.
2. Gumawa ng mga role para sa iyong team (halimbawa, "Pastor", "Secretary", "Treasurer").
3. Magtalaga ng naaangkop na pahintulot sa bawat role.
4. Magdagdag ng mga miyembro ng team sa pamamagitan ng paghahanap sa kanilang account at pagtatalaga sa kanila sa mga role.

## Hakbang 4: I-setup ang Iyong Mga Pangunahing Bahagi

Kapag nasa lugar na ang iyong team, simulan ang pagbuo ng mga pangunahing bahagi ng B1 Admin:

1. **People** -- Idagdag ang mga miyembro sa direktoryo ng iyong simbahan. Ito ang pundasyon ng lahat, kaya dito ka magsimula. Maaari mong idagdag nang manwal ang mga tao, o gamitin ang tool na **Import/Export** mula sa **Settings**.
2. **Groups** -- Gumawa ng mga grupo para sa maliliit na grupo, ministry team, klase, at iba pang pagtitipon.
3. **Attendance** -- I-configure ang iyong mga campus, serbisyo, at oras ng serbisyo para sa pagsubaybay ng attendance.
4. **Donations** -- I-setup ang mga donation fund at ikonekta ang iyong payment gateway (Stripe) para makatanggap ng online giving.
5. **Website** -- Gumawa ng iyong pampublikong website ng simbahan gamit ang website builder ng B1.church.

:::info
Hindi mo kailangang i-setup nang sabay-sabay ang lahat ng bahagi. Maraming simbahan ang nagsisimula sa **People** at **Groups**, at saka idinadagdag ang **Attendance** at **Donations** habang nasasanay sila sa platform.
:::

## Inirerekomendang Pagkakasunod-sunod

Para sa pinakamaayos na karanasan sa setup, iminumungkahi namin ang sumusunod na pagkakasunod-sunod:

1. **People** -- Idagdag muna ang iyong mga miyembro at regular na dumadalo.
2. **Groups** -- Ayusin ang mga tao sa mga makabuluhang grupo.
3. **Attendance** -- Simulan ang pagsubaybay kung sino ang dumadalo bawat linggo.
4. **Donations** -- I-setup ang giving kapag nasa sistema na ang iyong mga tao.
5. **Website** -- Gawin ang iyong pampublikong site sa huli, pagkatapos mailagay ang iyong datos.

Kapag natapos mo na ang mga hakbang na ito, handa na ang iyong simbahan. Tingnan ang dokumentasyon ng [B1 Admin](/docs/b1-admin/) para sa detalyadong gabay sa bawat bahagi.
