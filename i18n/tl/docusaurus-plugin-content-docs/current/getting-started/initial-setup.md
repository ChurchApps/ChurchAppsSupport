# Paunang Pag-set Up

<div class="article-intro">

Matapos gawin ang inyong account at simbahan, may ilang mahahalagang hakbang na dapat i-configure bago imbitahan ang inyong team. Ginagabayan ka ng gabay na ito sa inirerekomendang pagkakasunod-sunod ng pag-set up para handa na ang inyong simbahan mula pa sa unang araw.

</div>

<div class="prereqs">
<h4>Bago Magsimula</h4>

- [Gawin ang inyong account](./create-account.md) at irehistro ang inyong simbahan
- Ihanda ang logo at mga branding asset ng inyong simbahan (opsyonal ngunit inirerekomenda)

</div>

## Hakbang 1: I-configure ang Impormasyon ng Inyong Simbahan

1. Buksan ang [Jump menu](../b1-admin/introduction.md#getting-around-with-the-jump-menu) (ang search bar sa itaas na kaliwa ng B1 Admin), i-expand ang **Settings**, at i-click ang **Settings**.
2. I-click ang **Edit Settings**.
3. Ilagay ang **pangalan**, **address**, at **mga detalye ng contact** ng inyong simbahan.
4. I-click ang **Save** para ilapat ang inyong mga pagbabago.

## Hakbang 2: I-set Up ang Inyong Branding

1. Sa Jump menu, piliin ang **Website > Appearance**.
2. I-upload ang **logo ng inyong simbahan**.
3. I-configure ang iba pang opsyon sa branding tulad ng mga kulay at larawan.
4. Lalabas ang inyong branding sa inyong B1.church website at sa B1 Mobile app.

:::tip
Ang pagkakaroon ng handa nang logo at branding bago mag-imbita ng mga miyembro ng team ay nagbibigay ng maayos na unang impresyon pagka-log in nila.
:::

## Hakbang 3: I-configure ang mga Role at Imbitahan ang Inyong Team

1. Sa Jump menu, piliin ang **Settings > Roles**.
2. Gumawa ng mga role para sa inyong team (halimbawa, "Pastor", "Secretary", "Treasurer").
3. Itakda ang naaangkop na mga pahintulot sa bawat role.
4. Magdagdag ng mga miyembro ng team sa pamamagitan ng paghahanap sa kanilang mga account at pagtatalaga sa kanila sa mga role.

## Hakbang 4: I-set Up ang Inyong mga Pangunahing Bahagi

Kapag buo na ang inyong team, simulang buuin ang mga pangunahing bahagi ng B1 Admin:

1. **People** -- Magdagdag ng mga miyembro sa direktoryo ng inyong simbahan. Ito ang pundasyon ng lahat ng iba pa, kaya dito magsimula. Maaari kayong magdagdag ng tao nang manu-mano o gamitin ang tool na **Import** mula sa **Settings**.
2. **Groups** -- Gumawa ng mga grupo para sa maliliit na grupo, mga ministry team, mga klase, at iba pang pagtitipon.
3. **Attendance** -- I-configure ang inyong mga campus, serbisyo, at oras ng serbisyo para masubaybayan ang attendance.
4. **Donations** -- I-set up ang mga donation fund at ikonekta ang inyong payment gateway (Stripe) para makatanggap ng online giving.
5. **Website** -- Buuin ang pampublikong website ng inyong simbahan gamit ang B1.church website builder.

:::info
Hindi ninyo kailangang i-set up ang lahat ng bahagi nang sabay-sabay. Maraming simbahan ang nagsisimula sa **People** at **Groups**, saka idinaragdag ang **Attendance** at **Donations** habang nasasanay sila sa platform.
:::

## Inirerekomendang Pagkakasunod-sunod

Para sa pinakamaayos na karanasan sa pag-set up, iminumungkahi namin ang pagkakasunod-sunod na ito:

1. **People** -- Idagdag muna ang inyong mga miyembro at regular na dumadalo.
2. **Groups** -- Ayusin ang mga tao sa makabuluhang mga grupo.
3. **Attendance** -- Simulang subaybayan kung sino ang dumadalo bawat linggo.
4. **Donations** -- I-set up ang giving kapag nasa sistema na ang inyong mga tao.
5. **Website** -- Buuin ang pampublikong site sa huli, kapag nasa lugar na ang inyong data.

Kapag natapos na ninyo ang mga hakbang na ito, handa na ang inyong simbahan. Tuklasin ang dokumentasyon ng [B1 Admin](/docs/b1-admin/) para sa mga detalyadong gabay sa bawat bahagi.
