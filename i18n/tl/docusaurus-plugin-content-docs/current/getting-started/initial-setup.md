# Paunang Setup

<div class="article-intro">

Pagkatapos lumikha ng iyong account at simbahan, may ilang mahalagang mga hakbang upang i-configure bago imbitahan ang iyong koponan. Ang gabay na ito ay gagabay sa iyo sa inirerekomendang order ng setup upang ang iyong simbahan ay handa na sa unang araw.

</div>

<div class="prereqs">
<h4>Bago Ka Magsimula</h4>

- [Lumikha ng iyong account](./create-account.md) at iparehistro ang iyong simbahan
- Handa na ang logo ng iyong simbahan at mga asset ng tatak (optional pero inirekomenda)

</div>

## Hakbang 1: I-configure ang Impormasyon ng Iyong Simbahan

1. Buksan ang **menu ng seksyon** sa sulok sa itaas-kaliwa (ang pangalan ng seksyon na may maliit na arrow) at pumili ng **Mga Ayos**.
2. I-click ang **Edit Settings**.
3. Ipasok ang **pangalan**, **address**, at **detalye ng pakikipag-ugnayan** ng iyong simbahan.
4. I-click ang **Magsave** upang i-apply ang iyong mga pagbabago.

## Hakbang 2: Mag-setup ng Iyong Tatak

1. Mula sa **Dashboard**, mag-navigate sa **Website**, pagkatapos ay pumili ng **Appearance**.
2. I-upload ang **logo ng iyong simbahan**.
3. I-configure ang anumang karagdagang mga opsyon ng tatak tulad ng mga kulay at mga larawan.
4. Ang iyong tatak ay lilitaw sa iyong website sa B1.church at sa B1 Mobile app.

:::tip
Ang pagkakaroon ng iyong logo at tatak na handa bago imbitahan ang mga miyembro ng koponan ay nagbibigay ng polished na unang impression kapag sila ay nag-login.
:::

## Hakbang 3: I-configure ang Mga Rol at Imbitahan ang Iyong Koponan

1. I-click ang **Mga Rol** mula sa pahina ng **Mga Ayos**.
2. Lumikha ng mga rol para sa iyong koponan (halimbawa, "Pastol", "Sekretarya", "Treasurer").
3. Magtalag ng angkop na mga pahintulot sa bawat rol.
4. Magdagdag ng mga miyembro ng koponan sa pamamagitan ng paghahanap ng kanilang mga account at pagtatalaga sa kanila sa mga rol.

## Hakbang 4: Mag-setup ng Iyong Mga Pangunahing Lugar

Na may iyong koponan na sa lugar, magsimulang bumuo sa mga pangunahing lugar ng B1 Admin:

1. **Mga Tao** -- Magdagdag ng mga miyembro sa iyong direktoryo ng simbahan. Ito ang pundasyon para sa lahat ng iba, kaya magsimula dito. Maaari kang magdagdag ng mga tao nang manu-mano o gamitin ang **Import** tool mula sa **Mga Ayos**.
2. **Mga Grupo** -- Lumikha ng mga grupo para sa mga maliit na grupo, koponan ng ministrya, mga klase, at iba pang mga pagtitipon.
3. **Pagdalo** -- I-configure ang iyong mga kampus, mga serbisyo, at mga oras ng serbisyo para sa pagsubaybay ng pagdalo.
4. **Mga Donasyon** -- Mag-setup ng mga pondo ng donasyon at kumonekta sa iyong gateway ng pagbabayad (Stripe) upang tumanggap ng online giving.
5. **Website** -- Bumuo ng iyong pampublikong website ng simbahan gamit ang B1.church website builder.

:::info
Hindi mo kailangang mag-setup ng bawat lugar nang sabay-sabay. Maraming mga simbahan ay nagsisimula sa **Mga Tao** at **Mga Grupo**, pagkatapos ay magdagdag ng **Pagdalo** at **Mga Donasyon** habang nagiging komportable sila sa platform.
:::

## Inirerekomendang Order

Para sa pinakamadaling karanasan ng pag-setup, iminumungkahi namin ang order na ito:

1. **Mga Tao** -- Magdagdag muna ng iyong mga miyembro at regular na mga dumalo.
2. **Mga Grupo** -- Ayusin ang mga tao sa mga makabuluhang mga grupo.
3. **Pagdalo** -- Magsimulang subaybayan kung sino ang dumarating bawat linggo.
4. **Mga Donasyon** -- Mag-setup ng giving kapag ang iyong mga tao ay nasa sistema.
5. **Website** -- Bumuo ng iyong pampublikong site huli, pagkatapos ang iyong data ay nasa lugar.

Kapag natapos mo na ang mga hakbang na ito, ang iyong simbahan ay handa nang magsimula. Tuklasin ang [B1 Admin](/docs/b1-admin/) documentation para sa detalyadong gabay sa bawat lugar.
