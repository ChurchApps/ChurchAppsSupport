# Songs

<div class="article-intro">

Ang Songs page ay pinamamahalaan ang iyong worship song library. Panatilihin ang lahat ng detalye ng iyong kanta, lyrics, at arrangements sa isang lugar upang ang iyong worship team ay maaaring madaling maghanda para sa mga paparating na serbisyo at mapanatili ang isang pare-parehong repertoire.

</div>

<h4>Before You Begin</h4>

- Mag-navigate sa **Serving** section sa B1 Admin upang ma-access ang Songs page
- Opsyonal, magkaroon ng iyong [service plans](./plans.md) na naka-set up upang maaari mong direktang i-link ang mga kanta sa [service order](./service-order.md)

</div>

## Browsing Your Song Library

Kapag bubuksan mo ang **Songs** page, ang iyong mga kanta ay ipinapakita bilang mga card. Bawat card ay nagpapakita ng thumbnail image ng kanta, pamagat, artist, at tumatagal. Mag-scroll sa pamamagitan ng library o gamitin ang search upang mahanap kung ano ang kailangan mo.

## Searching para sa Mga Kanta

1. I-click ang **Search** button sa Songs page.
2. Mag-type ng isang kanta **title** o **artist** name.
3. Ang mga resulta ay mag-filter habang nag-type ka, na nagpapakita ng mga tugmang kanta mula sa iyong library.

## Adding a Song

1. I-click ang **Add Song** sa Songs page.
2. Maghanap sa pang-external na song database ayon sa pamagat o artist.
3. Pumili ng kanta na gusto mong idagdag.
4. Ang kanta ay idadagdag sa iyong library na may basic details na pre-filled.

:::tip
Pagkatapos magdagdag ng isang kanta, i-click ito upang suriin at i-update ang mga detalye nito, magdagdag ng arrangements, o mag-attach ng mga external links tulad ng YouTube videos o chord charts.
:::

## Viewing at Editing a Song

I-click ang anumang song card upang buksan ang detail page nito. Mula dito ay maaari mo:

- **Mag-edit ng song details** -- I-update ang pamagal, artist, tumatagal, at ibang metadata.
- **Pamahalaan ang arrangements** -- Bawat kanta ay maaaring magkaroon ng maraming arrangements (halimbawa, iba't ibang mga susi o bersyon). Magdagdag, mag-edit, o mag-aalis ng mga arrangement na kinakailangan.
- **Magdagdag ng lyrics** -- Ilagay o i-update ang lyrics para sa bawat arrangement gamit ang ChordPro notation (halimbawa, `[G]Amazing grace`). Ang isang live preview sa tabi ng editor ay nag-render ng formatted chord chart habang nag-type ka, upang makita mo nang eksakto kung ano ang makikita ng iyong team.
- **Itakda ang key** -- Tukuyin ang musical key para sa bawat arrangement gamit ang key picker sa tabi ng lyrics. Ang pagbabago ng key ay transposing ang mga display ng chord nang agad, parehong sa arrangement page at kapag bumubukas ang kanta mula sa service plan, kaya ang iyong team ay palaging nakikita ang mga chord sa key na tunay nilang ginagamit.
- **Magdagdag ng external links** -- Mag-attach ng mga link sa mga resource tulad ng YouTube videos, chord charts, o sheet music na nag-host sa ibang lugar.

## Arrangements

Ang isang arrangement ay kumakatawan sa isang natatanging bersyon ng isang kanta -- halimbawa, isang mas mabilis na modernong bersyon laban sa isang mas mabagal na acoustic take, o ang parehong kanta sa ibang key para sa iba't ibang team. Bawat arrangement ng parehong kanta ay nagbabahagi ng song title at artist ngunit may sariling independent na setting:

- **Key** — ang musical key na ginawa ng arrangement
- **BPM** — tempo sa beats bawat minuto
- **Length** — tumatagal sa segundo
- **Meter** — time signature (hal., 4/4, 3/4, 6/8)
- **Sequence** — ang chord/section structure (hal., Intro → Verse → Chorus → Bridge)
- **Lyrics** — para sa display o projection
- **External links** — chord charts, YouTube recordings, sheet music, o ibang mga resource

Kapag nagdagdag ka ng isang kanta sa [Service Order](./service-order.md), maaari kang pumili kung aling arrangement ang gamitin para sa partikular na serbisyo, upang ang iyong team ay palaging nagsasanay at naglalaro ng tamang bersyon.

### Rehearsal Audio

Ang mga worship admin ay maaaring mag-attach ng rehearsal audio track sa isang arrangement upang ang team ay makakinig nang maaga ng practice:

1. Buksan ang kanta at pumili ng arrangement.
2. I-click ang **Upload Audio**.
3. Pumili ng isang MP3, M4A, o AAC file (hanggang 25 MB -- ang WAV ay hindi tinatanggap, upang panatilihing mamalayang ang storage usage).
4. I-save. Ang track ay tumutugtog inline saanman na lumilitaw ang arrangement na iyon -- sa arrangement page sa B1 Admin at sa service plan kapag bumubukas ng isang team member sa B1.church member portal. Ang mga plan item na may audio ay nagpapakita ng isang music-note icon sa halip na isang thumbnail.

Ang pag-delete ng arrangement ay nag-aalis din ng uploaded audio file nito.

:::info
Ang mga kanta mula sa iyong library ay maaaring direktang idagdag sa [Service Order](./service-order.md) sa loob ng isang plan, pag-link ng song details at piniling arrangement sa partikular na serbisyo.
:::
