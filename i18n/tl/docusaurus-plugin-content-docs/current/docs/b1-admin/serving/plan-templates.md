# Plan Templates

<div class="article-intro">

Ang mga plan template ay nagpapahintulot sa iyo na magsave ng isang reusable snapshot ng order ng serbisyo o mga posisyon ng isang plan at ilapat ito sa mga hinaharap na plan sa isang click. Sa halip na itayo muli ang parehong istruktura bawat linggo, i-save mo ito minsan at stamp ito sa maraming paparating na mga plan tulad ng kailangan mo.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Lumikha ng hindi bababa sa isang [service plan](plans.md) na may order ng serbisyo o mga posisyon na tinukoy
- Kailangan mo ng access sa Serving area sa B1 Admin

</div>

## Saving a Plan as a Template

1. Buksan ang isang umiiral na plan mula sa **Serving** area.
2. I-click ang **Templates** button (tuktok ng plan page).
3. Pumili ng **Save as Template**.
4. Bigyan ng pangalan ang template (halimbawa, "Standard Sunday" o "Worship + Sermon").
5. I-save. Ang template ay kumukuha ng order ng serbisyo at mga posisyon ng plan sa sandaling iyon.

## Managing Templates

Mula sa **Templates** button sa anumang plan type page maaari mo:

- **Rename** — baguhin ang display name ng template
- **Update from plan** — palitan ang content ng template ng kasalukuyang state ng plan (kapaki-pakinabang pagkatapos i-refine ang standard structure)
- **Apply** — stamp ang template sa isa o maraming paparating na mga plan
- **Delete** — alisin ang template na hindi mo na kailangan

## Applying a Template to Plans

1. I-click ang **Templates** button sa plan type page.
2. I-click ang **Apply** icon (copy icon) sa tabi ng template na gusto mong gamitin.
3. Pumili kung aling mga paparating na plan ang ilalapat ito sa pamamagitan ng pagsuri sa kanilang mga kahon.
4. Pumili kung ano ang kopyahin:
   - **Order of Service** — pinapalitan ang order ng serbisyo ng mga napiling plan sa mga item ng template
   - **Positions** — pinapalitan ang mga posisyon ng mga napiling plan (at kanilang mga assignment) sa mga posisyon ng template
5. I-click ang **Apply**.

:::warning
Ang paglalapat ng mga posisyon ay pinapalitan ang lahat ng mga umiiral na posisyon at assignment sa mga napiling plan. Siguraduhin na hindi mo pa naka-schedule ang mga boluntaryo para sa mga posisyon na iyon bago mag-apply.
:::

:::tip
I-apply ang Order of Service nang walang Positions kapag gusto mo ng pare-parehong kanta/sermon structure ngunit ang mga boluntaryo ay naka-assign na ng iba sa bawat linggo.
:::

## Keeping Templates Up to Date

Kung ang iyong standard na istruktura ng serbisyo ay nagbabago, buksan ang template manager at gamitin ang **Update from plan** upang i-sync ang template mula sa iyong pinakabagong plan sa halip na itayo ito mula sa simula.
