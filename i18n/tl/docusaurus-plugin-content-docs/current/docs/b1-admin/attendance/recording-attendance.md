# Recording Attendance

<div class="article-intro">

Pagkatapos na i-configure ang iyong mga campus, oras ng serbisyo, at mga grupo, maaari kang manu-manong mag-record ng attendance pagkatapos ng bawat pagtitipon. Nag-organize ang B1 Admin ng attendance sa paligid ng **sessions** -- isang session sa bawat grupo bawat petsa ng pagtitipon. Lumilikha ka ng session, minmarkahan kung sino ang dumalo, at ang data ay direktang nakakarating sa iyong attendance reports.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Ang iyong mga campus, oras ng serbisyo, at mga grupo ay dapat na na-configure. Tingnan ang [Attendance Setup](setup.md) kung hindi mo pa ito nagawa.
- Ang mga grupo na gusto mong subaybayan ay dapat na may **Track Attendance** na naka-enable. Tingnan ang [Attendance Setup](setup.md) para sa mga detalye.

</div>

## Creating a Session

Ang session ay kumakatawan sa isang pagkakataon ng pagtitipon ng grupo -- halimbawa, ang iyong K--3rd grade class sa isang partikular na Linggo.

1. Buksan ang **B1 Admin**, buksan ang **section menu** sa tuktok na sulok ng kaliwa at piliin ang **People**, pagkatapos i-click ang **Groups** tab.
2. Piliin ang grupo kung saan mo gustong mag-record ng attendance.
3. I-click ang **Sessions** tab.
4. I-click ang **New** upang lumikha ng bagong session.
5. Kung ang grupo ay itinalaga sa isang oras ng serbisyo, piliin ang **Service Time**. Kung ito ay isang walang-oras na grupo, ang field na ito ay hindi lilitaw.
6. Piliin ang **Session Date** -- ito ay maaaring ngayon, nakaraang petsa, o hinaharap na petsa.
7. I-click ang **Save**.

:::tip
Maaari kang lumikha ng mga session para sa mga nakaraang petsa upang makuha ang attendance na hindi mo pa na-record, o lumikha ng mga ito nang maaga upang handa na sila kapag nagsasama ang iyong grupo.
:::

## Marking Attendance

Pagkatapos magsave ng session, ang mga miyembro ng grupo ay makikita sa kanang bahagi ng pahina.

1. I-check ang kahon sa tabi ng bawat taong nag-attend.
2. Ang mga pagbabago ay nase-save nang awtomatiko -- walang karagdagang Save button para sa attendance marks.

:::info
Ang mga kasalukuyang miyembro ng grupo lamang ang lilitaw sa session list. Kung dumalo ang isang tao ngunit hindi pa sila nasa grupo, [idagdag sila sa grupo](../groups/group-members.md) muna, pagkatapos mag-record ng kanilang attendance.
:::

## Exporting Attendance to a Spreadsheet

Maaari kang mag-download ng record ng session bilang CSV file upang gamitin sa Excel, Numbers, o Google Sheets.

1. Buksan ang session na gusto mong i-export.
2. I-click ang **Download CSV** button.
3. Buksan ang downloaded file sa iyong spreadsheet application.

## Viewing Recorded Attendance

Pagkatapos mag-record ng mga session, ang data ay lalitaw sa iyong attendance reports.

- **Attendance tab** -- nagpapakita ng church-wide trends sa paglipas ng panahon. Tingnan ang [Tracking Attendance](tracking-attendance.md).
- **Groups tab** -- nagpapakita ng attendance na nahati sa pamamagitan ng indibidwal na grupo.

:::tip
Kung ang session na kakapag-likha mo ay hindi lilitaw sa mga reports kaagad, siguraduhin na ang session date ay nasa loob ng date range na pinili sa report filters.
:::
