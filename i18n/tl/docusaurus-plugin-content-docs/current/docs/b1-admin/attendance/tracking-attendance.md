# Tracking Attendance

<div class="article-intro">

Kapag na-configure na ang iyong mga campus, oras ng serbisyo, at mga grupo, ginagawang madali ng B1 Admin na suriin ang attendance data at tingnan ang mga trends. Ang Attendance page ay nagbibigay ng dalawang reporting views -- ang **Attendance** tab para sa church-wide trends at ang **Groups** tab para sa group-level detail. Gamitin ang mga tool na ito upang maintindihan ang mga pattern ng paglaki, makilala ang bumabagong engagement, at gumawa ng data-driven decisions para sa iyong simbahan.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Ang iyong attendance structure ay dapat na ma-setup na may hindi bababa sa isang campus at oras ng serbisyo. Tingnan ang [Attendance Setup](setup.md) kung hindi mo pa ito nagawa.
- Ang attendance data ay kailangang i-record bago magpakita ng mga resulta ang reports. Ang data ay maaaring galing sa [manual entry](recording-attendance.md) o [self check-in](check-in.md).

</div>

## Viewing Attendance Trends

1. Buksan ang **B1 Admin**, pagkatapos buksan ang **section menu** sa tuktok na sulok ng kaliwa at piliin ang **People**.
2. I-click ang **Attendance** tab.
3. Ang report ay tumatakbo nang awtomatiko kapag bumubukas ang tab, na nagpapakita ng attendance sa isang default na date range.

## Filtering Your Data

Gamitin ang mga filter sa tuktok ng pahina upang paliitin ang mga resulta:

- **Date Range** -- pumili ng start at end date upang matuon ang isang partikular na panahon.
- **Campus** -- piliin ang isang campus upang makita ang attendance para lamang sa lokasyong iyon.
- **Service Time** -- pumili ng isang oras ng serbisyo upang mag-drill sa isang partikular na pagtitipon.

Ang chart at data ay nag-update sa lalong madaling oras na baguhin mo ang isang filter, upang maaari kang mabilis na magcompare ng iba't ibang panahon o lokasyon.

:::info
Ang mga reports ay automatic na tumatakbo sa bawat oras na bumuksan mo ang Attendance tab, kaya lagi mong makikita ang up-to-date na mga numero nang hindi kinakailangang mag-click ng refresh button.
:::

## Group Attendance

Ang **Groups** tab ay nagpapakita ng attendance na nahati sa pamamagitan ng indibidwal na grupo. Ito ay kapaki-pakinabang kapag gusto mong subaybayan ang isang partikular na klase, ministry team, o small group sa halip na tingnan ang kabuuang mga numero ng serbisyo.

1. Piliin ang **Groups** tab.
2. Pumili ng isang grupo mula sa listahan upang makita ang attendance history nito.
3. Gamitin ang date range filter upang i-adjust ang reporting window.

:::tip
Ang group attendance ay partikular na mahalaga para sa [small group](../groups/creating-groups.md) leaders na gustong subaybayan ang engagement sa loob ng kanilang grupo sa paglipas ng panahon.
:::

## Tips for Using Attendance Data

- Suriin ang mga trends buwanan upang makuha ang seasonal patterns nang maaga.
- Ihambing ang campus-level data upang maintindihan kung aling mga lokasyon ang lumalaki.
- Gamitin ang group-level reports upang sumunod sa [mga grupo](../groups/group-members.md) na nagpapakita ng bumabagong attendance.
- Pagsamahin ang attendance insights sa [AI Search](../people/ai-search.md) tool upang mahanap ang mga taong hindi dumalo kamakailan.
