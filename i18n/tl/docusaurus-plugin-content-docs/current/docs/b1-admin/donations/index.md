# Donations

<div class="article-intro">

Ang Donations section sa B1 Admin ay nagbibigay ng lahat ng kailangan mo upang pamahalaan ang giving ng iyong simbahan. Mula sa pag-record ng weekly offerings hanggang sa paglikha ng year-end tax statements, ang lahat ng iyong donation tools ay nag-organize sa isang lugar upang manatiling on top ka ng mga finasyal ng iyong simbahan.

</div>

## Sub-Sections

Makikita mo ang mga sumusunod na pahina sa Donations section:

### Summary

Ang **Summary** page ay nagbibigay sa iyo ng isang visual overview ng lahat ng giving activity. Ito ay nagpapakita ng mga chart at filtered reports upang mabilis mong makita ang donation trends sa buong iyong simbahan. Tingnan ang [Donation Reports](donation-reports.md) para sa higit pang detalye sa paggamit ng summary at report tools.

### Batches

Ang **[Batches](batches.md)** ay nagpapahintulot sa iyo na mag-grupo ng mga donasyon -- halimbawa, ang lahat ng mga tsek at barya na nakolekta sa isang Sunday offering. Bawat batch ay sumusubaybay sa count ng donasyon at kabuuang halaga para sa madaling reconciliation.

### Funds

Ang **[Funds](funds.md)** ay nag-categorize ng iyong mga donasyon ayon sa layunin. Ang mga karaniwang halimbawa ay kasama ang General Fund, Building Fund, at Missions. Maaari mong markahan ang bawat fund bilang tax-deductible o hindi.

### Statements

Ang **[Statements](giving-statements.md)** page ay lumilikha ng year-end giving statements para sa iyong mga donor. Maaari kang mag-download ng mga indibidwal na CSV file o mag-print ng lahat ng mga statement nang sabay-sabay.

### Stripe Import

Kung tumatanggap ka ng online donations sa pamamagitan ng Stripe, ang **[Stripe Import](stripe-import.md)** tool ay nagpapahintulot sa iyo na i-pull ang mga transaction sa B1 Admin upang lahat ay nasa isang sistema.

## Online Giving

Ang B1 Admin ay isang integrated sa **Stripe** at **PayPal** para sa pagtatanggap ng online donations. Kapag na-configure na, ang mga miyembro ay maaaring magbigay sa pamamagitan ng iyong B1.church site at ang mga donasyon ay awtomatikong lumilitaw sa iyong mga record. Tingnan ang [Online Giving Setup](online-giving-setup.md) upang magsimula.

:::tip
Kung bago ka sa mga donasyon sa B1 Admin, magsimula sa pamamagitan ng [pag-setup ng iyong mga fund](funds.md), pagkatapos [lumikha ng iyong unang batch](batches.md) at [mag-record ng mga donasyon](recording-donations.md) sa ito.
:::
