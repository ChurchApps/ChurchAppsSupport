# Giving Statements

<div class="article-intro">

Sa pagtatapos ng bawat taon, ang iyong mga donor ay kailangan ng isang buod ng kanilang tax-deductible giving para sa kanilang mga record. Ang B1 Admin ay ginagawang madali na lumikha ng mga statement para sa lahat ng mga donor nang sabay-sabay, na nakakatipid sa iyo ng maraming oras ng manual na gawain.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- I-verify na ang iyong [funds](funds.md) ay tama na minarkahan bilang **Tax Deductible** -- ang mga donasyon lamang sa tax-deductible funds ay lilitaw sa mga statement
- Siguraduhin na ang lahat ng mga donasyon ay na-[recorded](recording-donations.md) at ang anumang online transactions ay na-[imported mula sa Stripe](stripe-import.md)

</div>

## Accessing Giving Statements

1. Sa **B1 Admin**, buksan ang **section menu** sa tuktok na sulok ng kaliwa at pumili ng **Donations**.
2. I-click ang **Statements**.

## Generating Statements

1. Piliin ang **year** mula sa dropdown sa tuktok ng pahina. Maaari mong piliin ang kasalukuyang taon o kahit isa sa limang mga nakaraang taon.
2. Ang pahina ay nagpapakita ng summary statistics para sa taong iyon, kasama ang:
   - **Total donors** -- ang bilang ng mga taong nagbigay
   - **Total donations** -- ang bilang ng mga indibidwal na donation records
   - **Total amount** -- ang pinagsama-samang halaga ng lahat ng giving

## Downloading Statements

Mayroon kang dalawang pagpipilian para sa pagkuha ng mga statement sa iyong mga donor:

### Download as CSV Files

I-click ang **Download ZIP** upang mag-download ng isang ZIP file na naglalaman ng isang indibidwal na CSV file para sa bawat donor. Ito ay kapaki-pakinabang kung gusto mong mag-email ng mga statement nang indibidwal o i-import ang mga ito sa ibang sistema.

### Print All Statements

I-click ang **Print All** upang magbukas ng isang printable view ng bawat statement ng donor sa iyong browser. Mula doon, gamitin ang print function ng iyong browser upang ipadala ang mga ito sa isang printer. Bawat statement ay nagsisimula sa isang bagong pahina upang handa na silang tikman at ipadala.

:::tip
Patakbuhin ang iyong mga statement nang maaga sa Enero habang ang iyong mga record ay bago pa. Double-check na ang iyong mga fund ay tama na minarkahan bilang tax-deductible bago lumikha ng mga statement -- ang mga donasyon lamang sa tax-deductible funds ay kasama.
:::

:::info
Ang mga giving statements ay kasama lamang ang mga donasyon na itinalaga sa mga fund na may naka-enable ang **Tax Deductible** setting. Kung ang isang fund ay hindi minarkahan bilang tax-deductible, ang mga donasyon nito ay hindi lilitaw sa statement. Maaari mong pamahalaan ang setting na ito sa [Funds](funds.md) page.
:::

## Next Steps

Kung kailangan mong suriin ang mga detalye ng donasyon bago lumikha ng mga statement, bisitahin ang [Donation Reports](donation-reports.md) page o suriin ang indibidwal na [batches](batches.md).
