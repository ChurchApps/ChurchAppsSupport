# Donation Reports

<div class="article-intro">

Ang B1 Admin ay nagbibigay sa iyo ng mga paraan upang tingnan at suriin ang giving data ng iyong simbahan. Ang Donations Summary page ay nagbibigay ng isang visual overview na may mga chart at filter, habang ang Reports section ay nag-aalok ng isang mas detalyadong Donation Summary report. Gamitin ang mga tool na ito upang subaybayan ang giving trends, maghanda para sa board meetings, o i-reconcile ang iyong mga record.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Siguraduhin na ang mga donasyon ay na-[recorded sa mga batch](recording-donations.md) o [imported mula sa Stripe](stripe-import.md)
- I-verify na ang iyong [funds](funds.md) ay naka-setup nang tama upang ang mga donasyon ay maayos na naka-categorize

</div>

## Giving Dashboard

Ang **Giving Dashboard** ay ang unang bagay na makikita mo kapag binuksan mo ang **Donations** section. Ito ay nagbibigay ng isang mataas na antas ng pag-view ng iyong giving activity na may mga key performance indicator.

1. Buksan ang **section menu** sa tuktok na sulok ng kaliwa at pumili ng **Donations** upang buksan ang dashboard.
2. Sa tuktok, ang apat na **KPI cards** ay nagpapakita ng iyong giving metrics sa isang sulyap:
   - **Total Giving** -- Ang kabuuang halaga na ibinigay sa napiling panahon.
   - **Average Gift** -- Ang average donation amount.
   - **Unique Donors** -- Ang bilang ng mga natatanging taong nagbigay.
   - **Total Donations** -- Ang kabuuang bilang ng mga indibidwal na donasyon.
3. Gamitin ang **period toggle** upang magpalit sa pagitan ng **Weekly**, **Monthly**, at **Quarterly** views.
4. Sa ibaba ng mga KPI, ang isang chart ay nagpapakita ng giving trends para sa napiling panahon.
5. I-click ang **Download** upang mag-export ng isang CSV file na may giving totals.

## Donations Summary Page

Ang **Summary** page ay nagbibigay ng mas detalyadong aggregate giving data.

1. Buksan ang **section menu** sa tuktok na sulok ng kaliwa at pumili ng **Donations** upang buksan ang Summary page.
2. Gamitin ang **date range filter** upang piliin ang panahon na gusto mong suriin. Itakda ang mas maaga na petsa sa tuktok at ang mas kasalukuyang petsa sa ilalim.
3. Ang pahina ay nagpapakita ng isang weekly giving chart upang makita mo ang mga trend sa isang sulyap.
4. I-click ang **Download** upang mag-export ng isang CSV file na may kabuuang halaga na ibinigay, ang linggo na ibinigay, at ang fund na ibinigay.

:::info
Ang Summary page ay nagpapakita ng aggregate giving data. Hindi ito kasama ang mga indibidwal na pangalan ng donor. Para sa donor-level details, gamitin ang [Batches](batches.md) page.
:::

## Viewing Donor-Level Details

Para sa isang breakdown ng sino ang nagbigay, gaano kalaki, at sa kung aling fund:

1. Mag-navigate sa **Donations > Batches**.
2. I-click ang isang **batch name** upang buksan ito.
3. Ang batch detail page ay naglilista ng bawat donasyon na may pangalan ng donor, halaga, fund, petsa, at paraan ng pagbabayad.
4. I-click sa **pangalan ng donor** upang makita ang isang breakdown ng ilang beses nilang inibigay at gaano kalaki ang bawat oras.
5. I-click sa isang **donation ID** upang magbukas ng isang side panel na may buong detalye para sa indibidwal na donasyon.
6. I-click ang **Download** upang mag-export ng isang CSV na may lahat ng donor at donation information para sa batch na iyon.

## Donation Summary Report

Ang donation reporting ay direktang itinayo sa Donations section -- ang Summary page ay gumaganap bilang iyong donation summary report:

1. Buksan ang **section menu** sa tuktok na sulok ng kaliwa at pumili ng **Donations** upang buksan ang Summary page.
2. Gamitin ang **date range filter** upang piliin ang panahon na gusto mong iulat.
3. I-click ang **Download** upang mag-export ng report bilang isang CSV file.

## Exporting Data

Maaari kang mag-export ng donation data mula sa maraming lugar:

- **Summary page** -- mag-download ng isang CSV ng weekly giving totals ayon sa fund
- **Batch detail page** -- mag-download ng isang CSV ng indibidwal na mga donasyon na may detalye ng donor
- **Funds detail page** -- mag-download ng donation history para sa isang partikular na fund

:::tip
Para sa year-end reporting, pagsamahin ang Summary page export sa [Giving Statements](giving-statements.md) tool upang makakuha ng parehong aggregate trends at indibidwal na statement ng donor.
:::
