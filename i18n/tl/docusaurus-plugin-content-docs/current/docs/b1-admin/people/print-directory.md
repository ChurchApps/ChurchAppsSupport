# Print Directory

<div class="article-intro">

Ang Print Directory feature ay lumilikha ng isang format, printable member directory para sa iyong simbahan. Ito ay nag-organize ng mga miyembro ayon sa sambahayan, kasama ang contact information at mga larawan, at idinisenyo upang mukhang propesyonal kapag na-print sa standard letter-size paper.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Kailangan mo ng isang aktibong B1 Admin account na may pahintulot na tingnan ang mga tao.
- Ang mga taong nasa iyong direktoryo ay dapat na may mga larawan at contact information na na-fill in para sa mga pinakamahusay na resulta.

</div>

## Opening the Print Directory

1. Mag-navigate sa **People** sa B1 Admin.
2. I-click ang **print icon** (printer icon) sa toolbar sa tuktok ng People results card. Ito ay lilitaw sa tabi ng Export button.
3. Ang Print Directory ay bumubukas sa isang bagong browser tab at nagsisimulang nag-load ng iyong directory data.
4. Pagkatapos ng humigit-kumulang 1.5 segundo, ang dialog ng print ng iyong browser ay awtomatikong lilitaw.

:::tip
Ang direktoryo ay bumubukas sa isang hiwalay na tab upang maaari mo itong i-print nang hindi iniwan ang People page. Pagkatapos lumitaw ang print dialog, ang tab ay awtomatikong bumabalik.
:::

## What Gets Included

Ang print directory ay nagsasama ng lahat ng **active members** ng iyong simbahan. Partikular:

- Ang mga taong may **Inactive** o **Visitor** membership status ay awtomatikong hindi kasama.
- Ang mga taong nag-**opted out** ng direktoryo ay hindi kasama.
- Ang lahat ay naka-grupo ayon sa **sambahayan**.

## Directory Layout

Ang naka-print na direktoryo ay may dalawang bahagi:

### Cover Page

Ang unang pahina ay nagsasama ng:
- Ang pangalan ng iyong simbahan
- Ang pamagat "Member Directory"
- Ang kasalukuyang taon
- Ang lokasyon ng iyong simbahan
- Isang bilang ng kabuuang mga sambahayan na kasama

### Member Listings

Ang natitirang mga pahina ay naglilista ng mga sambahayan nang alphabetically ayon sa pangalawang pangalan. Bawat household card ay nagpapakita ng:

- **Photos** -- Mga circular thumbnails para sa bawat miyembro ng sambahayan, na may pangalan sa ilalim
- **Household display name** -- Halimbawa, "The Smith Family", "John & Jane Doe", o ang pangalan ng tao lamang para sa mga indibidwal
- **Address** -- Street address, city, state, at zip
- **Phone** -- Home o mobile number
- **Email** -- Pangunahing email address
- **Birthdays** -- Formatted bilang mga indibidwal na petsa para sa bawat miyembro ng sambahayan
- **Anniversary** -- Kung naitala

Ang mga sambahayan ay nag-organize sa **alphabetical sections** (A, B, C, ...) na may isang dekoratibong section header bago ang bawat letter group. Dalawang household cards ay lilitaw nang magkatabi sa bawat hilera.

## Print Settings

Ang direktoryo ay naka-format para sa **letter-size paper** (8.5" × 11") na may 0.5-inch margins. Kapag lilitaw ang browser print dialog:

- Iwanan ang paper size na nakatakda sa **Letter**
- Mag-enable ng **Background graphics** (minsan ay tinatawag na "Print backgrounds") sa iyong browser's print settings kung gusto mong mag-print ang mga section headers na may kanilang kulay styling
- Ang portrait orientation ay inirerekomenda

:::info
Ang direktoryo ay nag-respect sa page breaks -- ang household cards at section headers ay hindi hihiwalay sa mga pahina.
:::
