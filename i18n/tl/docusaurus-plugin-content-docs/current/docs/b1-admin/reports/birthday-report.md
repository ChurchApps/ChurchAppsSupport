# Birthday & Anniversary Lists

<div class="article-intro">

Kailangan ka ba ng isang listahan ng lahat na may kaarawan o anibersaryo sa isang binigay na buwan -- para sa bulletin, mga anunsyo, o mga card? Ang People search ay maaaring mag-filter sa iyong congregasyon ayon sa **Birth Month** at **Anniversary Month** at ipakita ang mga petsa nang direkta sa mga resulta.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Siguraduhin na ang mga petsa ng pagsilang (at mga anibersaryo) ay ipinapasok sa profile ng bawat tao. Tingnan ang [Adding People](../people/adding-people.md).
- Kailangan mo ng pahintulot upang tingnan ang Mga Tao. Tingnan ang [Roles & Permissions](../settings/roles-permissions.md).

</div>

## Getting a Birthday List for a Month

1. Buksan ang **section menu** sa tuktok na sulok ng kaliwa at pumili ng **People**.
2. Sa ilalim ng search box, i-click ang **Advanced**.
3. Palawakin ang **Demographics** section at suriin ang **Birth Month**, pagkatapos pumili ng buwan.
4. Patakbuhin ang search -- ang lahat na may kaarawan sa buwan na iyon ay lilitaw sa mga resulta.
5. Upang makita ang mga petsa, i-click ang **columns icon** sa tuktok na kanang bahagi ng mga resulta at i-enable ang **Birthday** column. Gamitin ang **Export** upang mag-download ng listahan bilang isang spreadsheet kung mas gusto mong mag-sort o mag-print doon.

## Getting an Anniversary List

Ang parehong mga hakbang -- sa **Demographics** section, suriin ang **Anniversary Month** sa halip (o din), pumili ng buwan, at i-enable ang **Anniversary** column sa mga resulta.

## Practical Uses

- **Weekly bulletins** -- Patakbuhin ang listahan ng kasalukuyang buwan at basahin ang mga pangalan nang direkta sa bulletin.
- **Birthday & anniversary cards** -- I-export ang listahan ng buwan at ibigay ito sa iyong card-writing team.
- **Milestones** -- Pagsamahin sa **Age** filter upang mahanap ang milestone birthdays.

:::tip
Ang parehong mga listahan ay nagmumula sa fields ng birth date at anibersaryo sa profile ng bawat tao -- kung nawawala ang isang tao, ang kanilang profile ay kailangan lamang na idagdag ang petsa.
:::

:::info
Ang mga naunang bersyon ng B1 Admin ay may isang hiwalay na Reports page para sa mga kaarawan. Ang pahirang na iyon ay nire-retire -- ang mga People search filters sa itaas ay ang kasalukuyang paraan, at sumasaklaw din ang mga anibersaryo.
:::
