# Anniversary List

<div class="article-intro">

Kailangan ka ba ng isang listahan ng lahat na may wedding anniversary sa isang binigay na buwan -- para sa bulletin, mga card, o mga anunsyo? Ang People search ay nagpapahintulot sa iyo na mag-filter ayon sa **Anniversary Month** at ipakita ang mga petsa nang direkta sa mga resulta.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Siguraduhin na ang mga petsa ng anibersaryo ay ipinapasok sa profile ng bawat tao. Tingnan ang [Adding People](../people/adding-people.md) para sa mga detalye.
- Kailangan mo ng pahintulot upang tingnan ang Mga Tao. Tingnan ang [Roles & Permissions](../settings/roles-permissions.md).

</div>

## Getting an Anniversary List for a Month

1. Buksan ang **section menu** sa tuktok na sulok ng kaliwa at pumili ng **People**.
2. Sa ilalim ng search box, i-click ang **Advanced**.
3. Palawakin ang **Demographics** section at suriin ang **Anniversary Month**, pagkatapos pumili ng buwan.
4. Patakbuhin ang search -- ang lahat na may anibersaryo sa buwan na iyon ay lilitaw sa mga resulta.
5. Upang makita ang mga petsa, i-click ang **columns icon** sa tuktok na kanang bahagi ng mga resulta at i-enable ang **Anniversary** column. Gamitin ang **Export** upang mag-download ng listahan bilang isang spreadsheet kung mas gusto mong mag-sort o mag-print.

## Practical Uses

- **Weekly bulletins** -- Patakbuhin ang listahan ng kasalukuyang buwan at isama ang mga anibersaryo sa iyong bulletin o mga anunsyo.
- **Anniversary cards** -- I-export ang listahan ng buwan at ibigay ito sa iyong card-writing team.
- **Milestone celebrations** -- Pagsamahin sa **Years Married** filter upang mahanap ang milestone anniversaries.

:::tip
Patakbuhin ito sa simula ng bawat buwan upang mayroon kang oras na maghanda ng mga card o mga anunsyo bago dumating ang mga anibersaryo.
:::

:::info
Ang data ng anibersaryo ay nagmumula sa anniversary field sa profile ng bawat tao. Kung nawawala ang isang tao, ang kanilang profile ay kailangan lamang na idagdag ang petsa. Tingnan ang [Adding People](../people/adding-people.md).
:::
