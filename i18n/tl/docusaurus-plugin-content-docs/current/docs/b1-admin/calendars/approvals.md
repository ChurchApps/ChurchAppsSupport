# Calendar Approvals

<div class="article-intro">

Ang Approvals page ay kung saan sinusuri at kumikilos ang mga administrator sa mga naghihintay na room at resource booking requests, pati na rin ang mga calendar events na nangangailangan ng approval bago i-publish.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- I-configure ang mga room o resource na may **Approval Group** sa [Rooms & Resources](rooms-resources)
- Kailangan mo ng **Calendars Admin** permission o ang **content.edit** permission

</div>

## Opening Approvals

Sa B1 Admin, magpunta sa **Calendars** at piliin ang **Approvals**. Ang mga naghihintay na booking requests at events na naghihintay ng review ay nakalista dito.

## Booking Requests

Kapag lumilikha ang isang grupo ng event at nag-request ng isang room o resource, ang request ay lilitaw sa **Booking Requests** panel. Bawat hilera ay nagpapakita ng:

- Ang room o resource na hinihiling
- Ang pangalan ng event at date/time
- Ang grupo na nag-request

### Conflict Indicators

Kung mag-overlap ang dalawang request para sa parehong room o resource, isang conflict warning icon ay lilitaw. Tukuyin nang mabuti ang mga nakakasalungat na request bago aprubahan ang alinman.

### Approving or Rejecting

I-click ang **✓** (approve) o **✗** (reject) icon sa anumang booking request. Ang grupo na nag-request ay notipikado ng desisyon. Ang mga aprubadong booking ay naka-lock sa room o resource na iyon para sa event; ang mga tinatanggihang booking ay nagpapalaya ng slot para sa iba.

## Pending Events

Kung ang iyong calendar workflow ay nangangailangan ng event approval bago ang mga event ay maging visible sa publiko, ang mga naghihintay na event ay lilitaw sa **Pending Events** panel. Aprubahan ang isang event upang i-publish ito sa kalendaryo, o tanggihan ito upang notipahan ang submitter na kailangan ng mga pagbabago.

:::tip
I-setup ang isang Approval Group sa isang room sa [Rooms & Resources](rooms-resources) upang maging required ang approval para sa room na iyon. Ang mga grupo na may access ay maaaring mag-request ng room kapag lumilikha ng mga event, at ang mga request na iyon ay dumaadaloy sa pahirang ito.
:::
