# Rooms, Resources & Scheduling

<div class="article-intro">

Ang Rooms at Resources ay nagpapahintulot sa iyo na subaybayan ang bookable spaces at equipment ng iyong simbahan. Kapag ang isang grupo o team ay gustong gumamit ng isang room o hiramin ng isang resource para sa isang event, maaari nilang i-request ito sa pamamagitan ng B1 -- at maaari mong aprubahan o tanggihan ang mga request na iyon upang maiwasan ang double-booking.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Kailangan mo ng administrative access sa Calendars section sa B1 Admin
- I-setup ang [mga grupo](../groups/creating-groups) na ang mga miyembro ay magsusumite ng mga booking request

</div>

## Opening Rooms & Resources

Sa B1 Admin, magpunta sa **Calendars** at piliin ang **Rooms & Resources**. Ang pahina ay may apat na tab: **Rooms**, **Resources**, **Blockouts**, at **Templates**.

## Rooms

Ang mga kuwarto ay mga pisikal na espasyo na maaaring i-reserve kasama ang mga event sa kalendaryo -- isang sanctuary, isang fellowship hall, isang classroom, atbp.

### Adding a Room

1. Sa **Rooms** tab, i-click ang **Add Room**.
2. Magpasok ng isang **name** para sa kuwarto.
3. Opsyonal na itakda ang **capacity** (maximum na bilang ng mga tao).
4. Itakda ang **Approval Group** -- kapag nag-request ang isang grupo ng kuwartong ito, ang mga leader ng piniling grupo ay notipikado at dapat aprubahan ang booking. Iwanan ang blank kung walang approval ang kailangan.
5. I-click ang **Save**.

### Editing or Deleting a Room

I-click ang edit icon sa tabi ng anumang kuwarto, gumawa ng iyong mga pagbabago, at i-click ang **Save**. Gamitin ang **Delete** upang alisin ang isang kuwarto nang permanente.

## Resources

Ang mga resource ay mga item na maaaring i-book kasama ang isang event -- AV equipment, projectors, chairs, isang van, atbp.

### Adding a Resource

1. I-click ang **Resources** tab, pagkatapos **Add Resource**.
2. Magpasok ng isang **name** at opsyonal na **description**.
3. Itakda ang **Approval Group** kung may kailangan ng mag-sign off sa resource loans.
4. I-click ang **Save**.

## Blockouts

Ang mga blockouts ay pumipigil sa mga kuwarto o resource mula i-book sa ilang oras -- para sa renovations, reserved periods, o maintenance.

### Adding a Blockout

1. I-click ang **Blockouts** tab, pagkatapos **Add Blockout**.
2. Pumili kung i-block ang isang **Room**, isang **Resource**, o lahat ng mga kuwarto at resource.
3. Itakda ang **start** at **end** date/time para sa blockout.
4. Opsyonal na magdagdag ng isang **reason** note.
5. I-click ang **Save**.

## Event Templates

Ang mga template ay nagpapahintulot sa iyo na magsave ng isang reusable event configuration -- title, description, at associated groups -- upang ang mga recurring events ay malikha nang pare-pareho.

### Adding a Template

1. I-click ang **Templates** tab, pagkatapos **Add Template**.
2. Magpasok ng isang **name** para sa template.
3. Opsyonal na iugnay ang isang **grupo** upang ang event ay awtomatikong nakonekta sa grupo na iyon kapag ginawa mula sa template.
4. I-click ang **Save**.

Kapag lumilikha ng isang bagong event, ang staff ay maaaring pumili ng isang umiiral na template upang puno ang event details.
