# Approving Profile Changes

<div class="article-intro">

Kapag ang iyong simbahan ay nangangailangan ng administrator approval para sa profile updates, ang mga miyembro ay nag-submit ng kanilang mga pagbabago sa pamamagitan ng B1 Mobile app at ang mga request na iyon ay lumilitaw bilang mga task sa B1 Admin. Ang gabay na ito ay nagpapaliwanag kung paano suriin at aprubahan ang mga ito.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Dapat kang maging miyembro ng grupo na itinalaga bilang **Directory Approval Group** sa **Mobile → B1 Mobile**
- Kung walang approval group na na-configure, ang mga profile changes ay inilalapat kaagad nang walang review

</div>

## Where to Find Pending Requests

Kapag nag-submit ang isang miyembro ng isang profile change, ito ay lumalitaw bilang isang task na nakatalagang sa iyong approval group. Maaari mong hanapin ito sa dalawang lugar:

**Mula sa Dashboard:**
1. Mag-log in sa B1 Admin — ang Dashboard ay nag-load nang awtomatiko.
2. Sa **Tasks** section sa kanang bahagi, i-click ang **Assigned to My Groups** tab.
3. Ang anumang mga naghihintay na profile change request ay nakakalista doon.

**Mula sa Serving → My Work:**
1. Sa tuktok na navigation, i-click ang **Serving**.
2. I-click ang **My Work**.
3. I-click ang **Assigned to My Groups** tab sa ilalim ng Tasks.

## Reviewing at Approving a Request

1. I-click ang **Profile Update** task upang buksan ito.
2. Sa ilalim ng **Requested Changes**, makikita mo ang bawat field na gusto ng miyembro na i-update kasama ang bagong halaga na kanilang isinumite.
3. Suriin ang mga pagbabago.
4. I-click ang **Apply** upang aprubahan at i-save ang mga pagbabago sa kanilang profile.

Ang task ay automatically na magsasara kapag na-apply ang mga pagbabago.

## Setting Up the Approval Group

Kung ang iyong simbahan ay gusto na ang mga profile changes ay mangangailangan ng approval, dapat munang ma-configure ang isang Directory Approval Group.

1. Sa tuktok na navigation, i-click ang **Mobile**.
2. I-click ang **B1 Mobile**.
3. Sa ilalim ng **Directory Approval Group**, pumili ng grupo na ang mga miyembro ay dapat na suriin ang mga profile change request.
4. I-click ang **Save**.

Ang anumang miyembro ng grupo na iyon ay makikita ang mga darating na profile change request sa ilalim ng **Assigned to My Groups** sa kanilang dashboard.

:::tip
Siguraduhin na ang iyong mga approver ay aktwal na mga miyembro ng configure na grupo -- ang lamang ang mga miyembro ng grupo ay makikita ang mga request.
:::
