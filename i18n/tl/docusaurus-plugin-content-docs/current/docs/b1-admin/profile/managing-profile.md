# Managing Your Profile

<div class="article-intro">

Ang Profile page ay nagpapahintulot sa iyo na i-edit ang iyong mga personal na account settings. Ang iyong profile ay ibinabahagi sa lahat ng ChurchApps products, kaya ang anumang pagbabago na iyong ginagawa dito ay makikita kahit saan ka gumagamit ng ChurchApps.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Dapat kang naka-log in sa iyong ChurchApps account
- Magkaroon ng handa ang iyong bagong email address o password kung plano mong i-update ang mga ito

</div>

## Profile Information

Ang tuktok na seksyon ng Profile page ay naglalaman ng iyong mga pangunahing account details:

1. **Email** -- Ang iyong email address na ginagamit para sa pag-log in at pagtanggap ng mga notification.
2. **First Name** at **Last Name** -- Ang iyong display name sa buong ChurchApps.
3. **Password** -- I-update ang iyong account password.

Upang i-update ang iyong impormasyon, i-edit ang mga field at i-click ang **Save Changes** button.

## Changing Your Password

1. Mag-scroll sa password fields sa Profile page.
2. Magpasok ng iyong **Current Password**.
3. Magpasok ng iyong bagong password sa **Password** field.
4. Muling ipasok ito sa **Confirm Password** field.
5. I-click ang **Save Changes**.

:::info
Ang iyong password ay dapat na hindi bababa sa 8 character. Siguraduhin na ang password at confirmation fields ay tumutugma nang eksakto. Dapat mong kumpirmahin ang iyong kasalukuyang password upang baguhin ito -- kung hindi mo alam, gamitin ang **Forgot Password** link sa login page sa halip.
:::

## Linked Accounts

Ang **Linked Accounts** section ay nagpapakita ng anumang external services na konektado sa iyong ChurchApps account. Maaari mong tingnan kung aling mga account ang naka-link at pamahalaan ang mga koneksyong iyon mula sa seksyong ito.

## Theme Preferences

Ang ChurchApps ay sumusuporta sa parehong light at dark display modes:

1. Hanapin ang **Theme** toggle sa iyong Profile page.
2. Lumipat sa pagitan ng **Light** at **Dark** mode.
3. Ang interface ay agad na ina-update upang ipakita ang iyong pagpipilian.

Ang iyong theme preference ay nase-save sa iyong account at ilalapat sa lahat ng iyong mga session.

## Account Deletion

Sa ilalim ng Profile page, makikita mo ang opsyon upang permanenteng tanggalin ang iyong account. Ang aksyong ito ay nag-aalis ng iyong account at kaugnay na data at hindi maaaring i-undo.

:::warning
Ang account deletion ay permanente at hindi maaaring bawiin. Siguraduhin na tunay mong gustong alisin ang iyong account bago magpatuloy.
:::

:::info
Kung ikaw ay isang **Domain Admin**, siguraduhin na ilipat ang mga administrative responsibilidad sa ibang user bago tanggalin ang iyong account. Tingnan ang [Roles & Permissions](../settings/roles-permissions.md) para sa mga detalye sa pag-manage ng mga admin role.
:::

:::info
Ang profile editing ay naka-disable sa demo mode. Kung gumagamit ka ng isang demo account, hindi mo makakagawa ng mga pagbabago sa iyong mga profile settings.
:::
