# Announcements

<div class="article-intro">

FreePlay can loop a folder of announcement slides on your TV -- for example, in a lobby or before class starts. You pick a folder from one of your connected content providers, FreePlay downloads its slides to the device, and an **Announcements** item appears in the sidebar so you can start the loop at any time.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- [Connect to a content provider](./connecting-providers) that holds your announcement slides, such as Google Drive or Dropbox
- Put the images or videos you want to loop together in one folder in that provider

</div>

## Choosing the Announcements Folder

1. Open **Settings** from the bottom of the sidebar, then select **Providers**
2. Select the connected provider that holds your slides (it shows a **Connected** badge) to open its **Provider Settings**
3. Select **Use for Announcements**
4. The **Choose the Announcements Folder** browser opens. Move through the folders until you reach the one with your slides, then select that folder (or any file inside it)
5. FreePlay downloads the slides and returns to **Provider Settings**, where the row now reads **Looping "*folder name*" -- *number* slides downloaded**

Only one folder is used for announcements at a time. Choosing a folder from another provider replaces the previous one.

## Playing Announcements

Once slides have been downloaded, an **Announcements** item appears near the top of the sidebar (below **Today's Plan**, if your TV shows it). Select it to start the loop.

- Images stay on screen for 15 seconds unless the provider gives the file its own duration
- Videos play to the end before moving to the next slide
- After the last slide, the loop starts over from the first one
- If the folder has a single video, it repeats in place

The loop plays from the files saved on the device, so it keeps running without an internet connection. You can use the same remote controls as any other content -- see [Playing Lessons](../classroom-mode/playing-lessons).

## Updating the Slides

FreePlay checks the announcements folder each time the app starts, downloads any new slides, and removes slides that were deleted from the folder.

To check right away, open the provider's **Provider Settings** and select **Check for Announcement Updates**. The row shows **Up to date** with the slide count when it finishes.

:::info
If FreePlay cannot reach the provider, or the folder comes back empty, it keeps playing the slides it already has. To stop using announcements entirely, turn them off as described below.
:::

:::warning
A slide that is replaced with a new version under the same file is not downloaded again. To change a slide, add it as a new file and delete the old one.
:::

## Turning Announcements Off

Open the provider's **Provider Settings** and select **Use for Announcements** again. FreePlay stops using the folder, deletes the downloaded slides from the device, and removes **Announcements** from the sidebar.

Disconnecting the provider also turns off announcements that came from it.
