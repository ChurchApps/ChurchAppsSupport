# Choosing a Pairing Mode

<div class="article-intro">

FreePlay can run a TV in three ways. It can follow a calendar you set up in FreePlay Admin, follow a service plan from B1 Admin, or play whatever a volunteer picks with the remote. Both kinds of pairing start from the same screen on the TV. Where you enter the pairing code decides which mode the TV uses.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Install FreePlay and launch it for the first time. See [Getting Started](./index.md)
- Have your TV remote ready for navigation

</div>

## Getting a Pairing Code

1. On the TV, open **Settings** at the bottom of the sidebar.
2. Select **Pair to a calendar**.
3. FreePlay shows a four-letter pairing code and a QR code. The code lasts 15 minutes, and FreePlay shows a new one on its own when it runs out.

## Scheduled Mode (FreePlay Admin)

Enter the code in **FreePlay Admin** at [admin.freeplay.church](https://admin.freeplay.church) when you want the TV to run itself. You build playlists, put them on a calendar for a group of screens, and the TV plays them at the scheduled times. Nobody has to press Start.

**How it works:** Scan the QR code on the TV, or go to **freeplay.church/pair**. Then choose the screen group whose calendar the TV should follow and click **Pair**. The TV downloads the week ahead and plays by the clock, even offline.

**Best for:** Lobby and hallway signage, announcement loops, and classrooms where the lesson should already be playing when people walk in.

See **[Scheduled Mode](../scheduled-mode/)** for the full guide.

## Plan Mode (B1 Admin)

Enter the code in **B1 Admin** when you want the TV to follow a service plan type. The TV downloads the content for the current plan, and a volunteer presses **Start Plan** to play it.

**How it works:** In B1 Admin, add the screen with the code from the TV and pick the plan type under **Show Plans For**. Each week, the TV picks up the latest plan for that plan type.

**Best for:** TVs that show content tied to your weekly service plan, where someone starts playback when it's time.

See **[Plan Mode](../plan-mode/)** for the full guide.

:::tip
You can also play the current service plan on a schedule. In FreePlay Admin, add a calendar entry and choose the plan type under **Service plans**.
:::

## Content Providers (No Pairing)

If you don't need to pair the TV at all, you can browse content providers directly. Providers like [Lessons.church](../../lessons-church/) and Bible Project have content you can download and play whenever you like.

**Best for:** TVs where volunteers choose what to play each week, or when you want to explore what's available.

:::info
You can open the **Providers** screen any time from **Settings** at the bottom of the sidebar. You don't need to pair the TV to browse and play content.
:::
