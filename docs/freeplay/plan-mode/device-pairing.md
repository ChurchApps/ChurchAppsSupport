# Pairing Your Device

<div class="article-intro">

To use Plan Mode, you pair your TV with a plan type in B1 Admin. FreePlay shows a short pairing code on the TV. You enter that code in B1 Admin and choose the plan type to follow, and the TV gets that plan's content automatically each week.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Install and launch FreePlay. See [Getting Started](../getting-started/)
- Have access to **B1 Admin** on a computer or phone to complete the pairing

</div>

## Generating the Pairing Code

1. On the TV, open **Settings** at the bottom of the sidebar.
2. Select **Pair to a calendar**.
3. FreePlay shows a four-letter pairing code in large letters, next to a QR code.
4. Below the code, a pulsing **Waiting for confirmation** indicator shows that FreePlay is waiting for you to finish pairing.

The same code works for [Scheduled Mode](../scheduled-mode/) in FreePlay Admin and for Plan Mode in B1 Admin. The QR code and the **freeplay.church/pair** address on the screen open FreePlay Admin. For Plan Mode, ignore them and enter the code in B1 Admin as described below.

## Entering the Code in B1 Admin

1. In B1 Admin, go to **Profile** > **Devices** and click **Add Screen**.
2. Enter the four letters from the TV in **Pairing Code**.
3. Under **Show Plans For**, choose the plan type you want this screen to follow, for example "Sunday Service".
4. Save.

FreePlay checks every few seconds to see whether the pairing is done. Once B1 Admin confirms it, the TV shows **Connected!** and moves to the plan download screen.

## Downloading Plan Content

After pairing, FreePlay loads the current plan for that plan type. It shows:

- The plan name and service date
- The lesson name, if the plan includes lesson content
- A progress indicator showing **Downloading item X of Y**

When all the media files are downloaded, the **Start Plan** button appears. Press **Select** on your remote to start playback.

:::tip
The plan refreshes automatically every hour. If someone updates the plan during the day, FreePlay picks up the changes on its own.
:::

## If Pairing Fails

If FreePlay can't generate a pairing code (for example, because of a network problem), you'll see an error message with a **Try Again** button. Make sure the TV is connected to the internet and try again.

:::warning
Pairing codes expire after 15 minutes. FreePlay shows a new code on its own when the old one runs out, and you can select **Generate New Code** at any time. If the code you entered doesn't work, use the one the TV is showing now.
:::
