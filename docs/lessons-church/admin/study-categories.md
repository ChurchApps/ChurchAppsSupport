# Study Categories

<div class="article-intro">

A program with dozens of studies is easier to browse when they are grouped. Categories are named lists of studies within a program, shown as tabs on the public program page next to **All**. A study can belong to more than one category, and each category has its own order.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- [Create the program](./managing-programs.md) and [add its studies](./managing-studies.md)

</div>

## Opening the Categories Page

1. In **Admin**, click the program in the left column to open its panel.
2. In the **Edit Program** header, click **Edit Categories**. The page is titled **Categories for** followed by the program name.

The page has two boxes: **Categories** on the right lists the category names; the box on the left shows the selected category's studies.

## Creating a Category

1. In the **Categories** box, click the **+** button.
2. Type the name in the **Category Name** prompt (for example, "Old Testament" or "Series for Easter") and click OK.
3. The new category is selected. It does not appear in the list or on the public site until it contains at least one study.

## Adding Studies to a Category

1. Click a category name in the **Categories** box. The left box heading changes to the category name.
2. Under **Available Studies**, click the **+** button next to each study to include. It moves into **Included Studies** at the end of the list.
3. Use the up and down arrows next to an included study to change its position. This order is what the public program page uses inside that tab.
4. Click the **remove** (minus) button to take a study out of the category. The study itself is not deleted.

Changes save as you click; there is no separate save step.

## What Churches See

On the program page, studies appear under tabs: **All** first, then each category name in alphabetical order. **All** shows every live study in the program; a category tab shows only its studies, in the order you set. Programs with no categories show no tabs.

:::tip
Categories are optional. Programs with fewer than about ten studies usually read fine under **All** alone.
:::
