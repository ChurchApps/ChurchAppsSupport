# Managing Add-ons

<div class="article-intro">

Add-ons are media that are not tied to one lesson: worship songs, scripture songs, games, and Christmas or Easter videos. They live in a single library under **Admin** and can be dropped into any venue with an **Add-on** action, so a worship set can be reused across every study.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Have admin permissions for Lessons.church (see the [Administration overview](./index.md))
- Have the video on Vimeo, or the file ready to upload

</div>

## Opening the Add-ons Library

1. Open **Admin**.
2. In the secondary menu, click **Add-ons**. The **Add-ons Library** lists every add-on with its category.

## Adding an Add-on

1. Click **Add New Add-on**.
2. Fill in the **Edit Add-on** form:
   - **Category** -- One of **Slow Worship**, **Slow Worship with Actions**, **Fast Worship**, **Fast Worship with Actions**, **Scripture Song**, **Scripture Song with Actions**, **Game**, **Christmas**, or **Easter**. The category is shown with the add-on wherever it is listed.
   - **Name** -- Required.
   - **Add-on Type** -- **External Video** for a Vimeo video, or **File** for an uploaded video, image, or document.
   - For **External Video**: leave **Provider** on **Vimeo**, enter the **Video Id**, and set **Looping Video** if it should repeat.
   - For **File**: click **Choose File** and select the file. It uploads when you save.
   - **Add-on Image** -- Click the image box to upload and crop a 16:9 thumbnail. It is used as the add-on's thumbnail on lesson pages.
3. Click **Save**.

## Editing or Deleting

Click an add-on in the library to reopen the form. Change any field and click **Save**, or click the delete (trash can) button to remove it.

## Using an Add-on in a Lesson

On a venue's structure page, add an action, set **Action Type** to **Add-on**, and choose the add-on. It plays exactly like a Play action in the lesson, in Presenter Mode, and on FreePlay. See [Building Venue Content](./sections-roles-actions.md).

:::info
Add-ons are shared across the whole library, not scoped to a program. Churches do not browse the add-on library directly; they only see add-ons through the lessons that use them.
:::
