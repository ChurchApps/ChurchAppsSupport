# Managing Year Plans

<div class="article-intro">

A year plan is an ordered list of lessons — week 1, week 2, week 3 — that churches apply in B1 Admin. You can publish a plan for any curriculum in the library. Optional calendar fields tell B1 Admin which month week 1 belongs to and which weeks must land on Easter or Christmas.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Have admin permissions for Lessons.church
- Have at least one [program](./managing-programs.md) with published lessons

</div>

## Creating a Plan

1. Open **Admin → Year Plans**.
2. Click **Add**.
3. Enter a name (for example, "Elementary 2026–27" or "High Voltage Year 1") and optional slug.
4. Optionally set a **default venue preference** — comma-separated venue names used when a week does not specify a venue.
5. Optionally set **Year starts in** (for example January) so churches apply the plan against a real calendar year instead of a bare start date.
6. Check **Publish** when churches should see the plan in B1 Admin. Leave it off for a draft.
7. Add weeks from any curriculum: choose a **source**, then program, study, lesson, and venue. Click **Add**. A single plan can mix programs if you want. Use the arrows to reorder.
8. For seasonal studies, set a week's **Anchor** to Easter or Christmas. Anchor the last week of the study so the series lands on the Sundays leading up to that holiday.
9. Save.

Churches apply a published plan from **B1 Admin → Serving → Plans → Schedule Lesson → Apply Year Plan**. Calendar-anchored plans ask for a target year and date range; other plans still use a first class date and week count. They edit individual weeks there afterward; FreePlay plays whatever is on the plan.
