# WorshipCommons Keyboard Shortcuts

<div class="article-intro">

The screens you use during a service -- **Lead worship**, the lyrics projector, and service plan **Stage mode** -- can be driven entirely from the keyboard, so a presentation remote or a wireless keyboard works from the back of the room. This page lists every shortcut in one place.

</div>

:::info
Shortcuts are ignored while you're typing in a text box or using a menu, so they never interfere with a form. Letter keys work in upper or lower case.
:::

## Discover Page

| Key | What it does |
| --- | --- |
| `/` | Jumps to the search box |

See [Finding Songs](./finding-songs.md).

## Lead Worship

| Key | What it does |
| --- | --- |
| **Space** | Play or pause (during a count-in, cancels it) |
| **→** / **←** | Next or previous line |
| **↓** / **↑** | Next or previous section (**↑** first returns to the start of the current one) |
| **B** | Blank the screen, or bring the words back |
| **H** | High-contrast screen on or off |
| **F** | Fullscreen on or off |
| **Esc** | Closes the **Verses** or **Put this on the TV** panel if one is open; otherwise returns to the song page |

Click **Show keys** at the bottom of the screen to see the legend, or **Hide keys** to hide it. See [Leading Worship from the Browser](./presenting-and-exporting.md#leading-worship-from-the-browser).

## Lyrics Projector

| Key | What it does |
| --- | --- |
| **Space**, **→**, **↓**, **Page Down** | Next slide (clicking the screen does the same) |
| **←**, **↑**, **Page Up**, **Backspace** | Previous slide |
| **Home** / **End** | First or last slide |
| **B** or **.** | Blank the screen, or bring the words back |
| **H** | High-contrast screen on or off |
| **F** | Fullscreen on or off |
| **Esc** | Returns to the song page (when not in fullscreen) |

Most presentation remotes send **Page Down** and **Page Up**, or **→** and **←**, so they work out of the box. See [Projecting Lyrics](./presenting-and-exporting.md#projecting-lyrics).

## Service Plan Stage Mode

| Key | What it does |
| --- | --- |
| **→**, **Page Down**, **Space** | Next song |
| **←**, **Page Up** | Previous song |

Text size and fullscreen are buttons in the bar (**A−**, **A+**, **Fullscreen**). See [Using the Plan on Sunday](./service-plans.md#using-the-plan-on-sunday).

## Everywhere Else

| Where | Key | What it does |
| --- | --- | --- |
| Chords & lyrics tab | **Tab** to a chord | Shows the guitar and piano diagram for that chord, the same as hovering over it |
| Renaming a service plan | **Enter** / **Esc** | Saves or cancels the new name |
| **+ Add to service plan** pop-up | **Esc** | Closes the pop-up |
| **Songwriter's pages** menu | **Esc** | Closes the menu |
| Print pages | **Ctrl+P** (or **Cmd+P**) | Your browser's print dialog, the same as the **Print** button |
