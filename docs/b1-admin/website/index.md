# Website

<div class="article-intro">

The Website section in B1 Admin gives you a full-featured website builder for your church. You can create pages, customize your site's look and feel, manage media files, and publish event calendars -- all without writing any code.

</div>

## What You Can Do

The Website builder is organized into these main areas:

### Pages

Create and manage all the pages on your church website. The **Pages** table lists each page -- pages automatically created by the system carry a **Generated** badge, and the rest are custom pages you created. You can add new custom pages, edit existing ones, or convert auto-generated pages into custom pages for full control over their content.

Your navigation links are listed in the **Main Navigation** panel beside the Pages table. You can reorder and nest links using drag-and-drop to set the exact hierarchy and order you want visitors to see. See [Managing Pages](./managing-pages.md).

### Blog

Publish news, updates, and devotionals as blog posts at `/blog` on your site, with an RSS feed. See the [Blog](./blog.md) guide.

### Blocks

Build reusable content components that you can place on multiple pages. Blocks save you time when you have content like a call-to-action, announcement banner, or contact section that appears in more than one place. Update a block once and the change applies everywhere it is used. See [Reusable Blocks](./blocks.md).

### Appearance

Customize your website's theme, colors, fonts, logo, and spacing. You can apply pre-built style themes for a quick start or fine-tune every detail with the color palette editor, typography settings, and custom CSS. See the [Appearance](./appearance.md) guide for full details.

### Files

Upload and manage all your media assets -- images, documents, and other files -- in one central location, and copy file links for use anywhere on your site. See [Files](./files.md) for more information.

### Calendars

Publish event calendars on your website so visitors can see what is happening at your church. Create curated calendars that pull events from multiple groups into a single view. Calendars have their own **Calendars** item in the B1 Admin menu, separate from **Website**.

:::tip
Start with [Initial Setup](./initial-setup.md) if you are configuring your website for the first time. It walks you through domain setup, creating your first page, and configuring your site's appearance.
:::
