# Files

<div class="article-intro">

The Files page is the central repository for all media and documents used on your church website. From here you can upload, browse, and manage every image, document, and media file your site needs.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- Complete the [Initial Setup](initial-setup) for your website
- Optimize images before uploading for faster page load times
- Prepare your files in common web formats (PNG, JPG, PDF, etc.)

</div>

## Uploading Files

1. In B1 Admin, open the [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (the search bar at the top-left), expand **Website**, and click **Files**.
2. In the **Upload Files** panel on the right, click **Choose File** and pick a file from your computer. (The **Upload Files** button at the top of the page takes you to the same panel.)
3. Your file uploads and appears in the files table.

The Upload Files panel also shows how much storage you are using. 100 MB is provided free; to get more, link your own Google Drive, Dropbox, OneDrive, or S3 bucket under **Settings**, in the **File Storage** section.

:::tip
For best results, optimize images before uploading. Smaller file sizes help your website load faster for visitors. Tools like TinyPNG or Squoosh can compress images without noticeable quality loss.
:::

## Browsing Files

The files table lists every uploaded file with its **Name** and **Size**. Click a file's name to open it in a new tab. Give files clear, descriptive names before uploading so your team can find them quickly.

## Using Files on Your Website

1. Find the file in the files table.
2. Click **Copy link** to copy the file's URL. You can paste this URL into image elements, download links, or anywhere else that accepts a file URL.
3. Files you upload here are available for use across all your website pages and content blocks.

:::info
When building pages in [Managing Pages](managing-pages), you can reference any file uploaded here by its URL. This keeps all your media organized in one central location.
:::

## Deleting Files

1. Find the file you want to remove in the files table.
2. Click **Delete** next to it and confirm to permanently remove it from your library.
3. Make sure the file is not currently being used on any page before deleting it, as this will break any links or images that reference it.

:::warning
Deleted files cannot be recovered. Double-check that a file is no longer in use on any page before removing it.
:::
