# Notes

<div class="article-intro">

The **Notes** page gathers recent notes from across B1 Admin into one place, so you can catch up on pastoral care, follow-ups, and planning without opening each record. It lists notes written on people, on groups you lead, on calendar events, and on workflow cards, newest first, and links each one back to where it was written.

</div>

<div class="prereqs">
<h4>Before You Begin</h4>

- The **Notes** page appears in the menu if you have the **Edit People** permission or you lead at least one group. See [Assigning Roles](./roles-permissions.md).
- The page only shows notes you are already allowed to read. Each tab follows the same rules as the record the notes belong to (see [What Each Tab Shows](#what-each-tab-shows)).

</div>

## Opening the Notes Page

1. Open the [Jump menu](../introduction.md#getting-around-with-the-jump-menu) (the search bar at the top-left of B1 Admin) and expand **People**.
2. Click **Notes**.
3. The page opens on the **People** tab. Use the tabs in the page header to switch between **People**, **Groups**, **Events**, and **Workflows**.

## Reading the List

Each note in the list shows:

- **Where it was written** -- the person's name, group name, event title, or workflow card title. Click the name to open that record and read the full thread or add a note.
- **Confidential** -- a badge on person notes that came from the person's Confidential Notes section.
- **Who wrote it and when** -- "By" the author's name, followed by the date and time it was posted.
- **The note itself** -- long notes are shortened in the list. Open the record to read the whole note.

The list shows the most recent notes first. Click **Load more** at the bottom to see older ones.

The Notes page is read-only. To add, edit, or reply to a note, click the record's name to open it.

## What Each Tab Shows {#what-each-tab-shows}

| Tab | Notes shown | Who can see them | Clicking the name opens |
|-----|-------------|------------------|-------------------------|
| **People** | Notes on person records | People with **Edit People**. Confidential notes also need **View Confidential Notes** | The person's notes |
| **Groups** | [Leader notes](../groups/group-members.md#leader-notes) on groups | Only the leaders of each group, even for administrators | The group's notes |
| **Events** | [Event notes](../calendars/creating-calendars.md#event-notes) | Staff who can edit content or administer calendars, plus anyone the event's **Who can view notes** setting allows | The calendar of the event's group |
| **Workflows** | Notes on [workflow cards](../serving/workflows.md#working-the-board) | Anyone who can open the card, including the person or group it's assigned to | The card's workflow board |

If a tab has nothing you can see yet, it says so -- for example, "No notes yet for groups you lead."

:::tip
Notes threads have a bell icon for notifications. Click it to get notified about new notes in that thread (the icon changes right away), and click it again to mute them. These on/off settings never appear as notes on the Notes page.
:::
